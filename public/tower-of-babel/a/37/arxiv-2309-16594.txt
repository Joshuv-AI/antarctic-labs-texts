Deterministic Fully Dynamic SSSP and More
Jan van den Brand, Adam Karczmarz

Abstract
We present the first non-trivial fully dynamic algorithm maintaining exact single-source distances in unweighted graphs. This resolves an open problem stated in [ San05 , BN19 ] . Previous fully dynamic single-source distances data structures were all approximate, but so far, non-trivial dynamic algorithms for the exact setting could only be ruled out for polynomially weighted graphs [ AW14 ] . The exact unweighted case remained the main case for which neither a subquadratic dynamic algorithm nor a quadratic lower bound was known. Our dynamic algorithm works on directed graphs and is deterministic, and can report a single-source shortest paths tree in subquadratic time as well. Thus we also obtain the first deterministic fully dynamic data structure for reachability (transitive closure) with subquadratic update and query time. This answers an open problem from [ BNS19 ] . Finally, using the same framework we obtain the first fully dynamic data structure maintaining all-pairs ( 1 + ϵ ) (1+\epsilon) -approximate distances within non-trivial sub- n ω n^{\omega} worst-case update time while supporting optimal-time approximate shortest path reporting at the same time. This data structure is also deterministic and therefore implies the first known non-trivial deterministic worst-case bound for recomputing the transitive closure of a digraph.

1.3
Technical ideas

Our results are obtained via a combination of (inevitable) algebraic methods and a wide range of purely combinatorial techniques. The fully dynamic single-source shortest distances data structures follow the high-level approach of the data structures for obtaining worst-case update bounds for exact fully dynamic
all-pairs shortest paths

[
ACK17
,
GW20b
,
Tho05
,
CZ23
,
Mao23
]
.
These purely combinatorial data structures are, however, super-quadratic in many different aspects and in fact seem to not be able to break through the
\Omega(n^{2.5})
barrier for the problem they solve.

We observe that a majority of computational bottlenecks therein can be delegated to the algebraic data structures based on dynamic matrix inverse
[
BNS19
,
San04
]
– again, with a few purely combinatorial extensions applied on top, such as the recent path-reporting techniques
[
KMS22
]
.
The power of algebraic data structures is also exploited to a greater extent than before.
Previous work relied on maintaining either the entire matrix inverse (e.g.
[
San04
]
), querying single cells or rows (
[
BN19
,
BNS19
,
San04
]
) or
maintaining well-structured (e.g., square) submatrices
[
San05
,
BFN22
]
.
On the other hand, we crucially need maintaining
unstructured and dynamic
subsets of cells of the inverse of subquadratic size and adapt the algebraic tools to this scenario.

Finally, a common theme of all our deterministic algorithms
is using weaker notions of hitting sets of ’’long‘‘ shortest paths between pairs of vertices whose distance exceeds some threshold
h
. In previous dynamic shortest paths data structures,
\widetilde{O}(n/h)
-sized hitting sets are typically randomly sampled (once) or deterministically recomputed (after an update) to hit paths in the
current graph
.

Our single-source distances data structure, on the other hand, only employs a (deterministically computed) hitting set to sparsify an explicit
static
collection of
\Theta(n^{2})
paths
that is reinitialized not very often. As a result, we completely avoid the bottleneck of all previous dynamic algebraic distance data structures for directed graphs: maintaining the
current
exact
h
-bounded distances between all pairs of vertices from the hitting set.
For example, it is not clear how this component can be derandomized while keeping the update time subquadratic.

In the data structure of Theorem
1.3
, a different relaxation of hitting sets (specific to reachability, where hitting
shortest paths
is not required for vertices far apart) is exploited. In particular, we describe a deterministic trade-off between the size of such a relaxed hitting set and the time needed to compute it, which we believe may be of independent interest.

In the following we review how the state-of-the art randomized data structures for

Let

Just like all previously described algebraic data structures maintaining shortest paths, we leverage dynamic matrix inverse data structures

Path counting

The main idea behind algebraic
h
-bounded distances data structures is counting (possibly implicitly) paths
of given lengths
0,\ldots,h
for all source-target pairs. Note that the number of length-
k

a given pair of vertices of an unweighted graph is no more than

,
i.e., could take
\widetilde{O}(k)
bits to be represented.
As a result, storing the required path counts for a given pair might require
up to
\widetilde{O}(h^{2})
bits.
It is the most convenient to represent the counts as a degree-
h
-polynomial matrix, where
the coefficient of
x^{k}
of the polynomial in the cell
(s,t)
equals the count of
s\to t

k

As originally observed by
[
San05
]
, such a matrix equals the inverse
of the matrix
I-x\cdot A
modulo
x^{h+1}
, where
A
is the adjacency matrix of
G
.
Since the single-edge updates to
G
correspond to single-element updates to

maintaining the required path counts reduces to maintaining matrix inverse under
single-element updates. This enables using dynamic matrix inverse data structures
[
San04
,
BNS19
,
BFN22
]

with
\widetilde{O}(h^{2})
arithmetic operation cost incurred by working with
h
-degree polynomials with
\widetilde{O}(h)
-bit coefficients.

For deciding whether a path of a given length exists, it is enough to be able to test whether a path count is non-zero.
By operating modulo a random
\Theta(\log{n})
-bit prime number, whether the individual counts are non-zero can be maintained by operating on
\widetilde{O}(1)
-bit polynomial coefficients instead (see, e.g.,
[
KS02
,
DI05
]
).
This saves a factor of

in the time cost, but inevitably leads to a Monte Carlo randomized algorithm correct with high probability.
The previous fully dynamic reachability data structures in DAGs
[

,

]

-distances

]

path in

can be decomposed into subpaths of length at most
h
with both endpoints
in
H\cup\{s,t\}
. Therefore, given
\delta^{h}_{G}(u,v)
for all
u,v\in H\cup\{s,t\}
,
we can find a shortest
s\to t
path in
G
using Dijkstra‘s algorithm on a digraph on
H\cup\{s,t\}

with
O(|H|^{2})=\widetilde{O}((n/h)^{2})
edges. Maintaining the
\widetilde{O}((n/h)^{2})
pairwise

h
-bounded distances between the vertices
H\cup\{s,t\}
requires at least
\widetilde{O}((n/h)^{2}\cdot h)=\widetilde{O}(n^{2}/h)
bits when using path counting modulo a prime.

This simple approach seems hopeless if we either wanted to make it work for the more
general single-source distances maintenance, or to have a deterministic dynamic
st
-distance data structure. In the former case, we would need to maintain
h
-bounded distances between
O(n^{2}/h)
pairs
{(H\cup\{s\})\times V}
. But the current path counting techniques assume at least
\Theta(h)
’’arithmetic‘‘ overhead for maintaining one value
\delta^{h}_{G}(u,v)
even when counting modulo a random prime. This makes the single-source case inherently quadratic using this approach.
Similarly, deterministic maintenance of a single value
\delta^{h}_{G}(u,v)
has
\widetilde{\Theta}(h^{2})
’’arithmetic‘‘ overhead, which makes the approach
of
[
San05
,
BFN22
]
inapplicable not only for maintaining
st
-distance deterministically,
but also for fully dynamic deterministic
st
-reachability which is likely an easier problem.

Our
h
-bounded distances data structure

At the end of the day, we do not overcome the aforementioned inherent arithmetic overheads
of either
\widetilde{\Theta}(h)
(randomized) and
\widetilde{\Theta}(h^{2})
(deterministic). Instead, we rely, in a crucial way, on the ability of the dynamic matrix inverse data structure
[
San04
]
to maintain an arbitrary
dynamic

k
-cell
submatrix of interest
of the inverse, possibly with no structure whatsoever, using a subquadratic number of field operations, unless
k=n^{2-o(1)}
or significantly more than
\Theta(n)
cells of interest are added per element update.
Specifically, we show the following:

Theorem 3.1

(Modification to
[
San05
]
, proof in
Appendix

A
)
.

Let
G=(V,E)
be a fully dynamic unweighted digraph. Let
h\in[1,n]
.
Let
{Y\subseteq V\times V}
be a dynamic set.
For any
\mu,\delta\in[0,1]
, there exists a deterministic data structure maintaining the values
\delta_{G}^{h}(s,t)
for all
(s,t)\in Y

and supporting:

•

single-edge updates to
G
in
\widetilde{O}(h^{2}\cdot(n^{\omega(1,\mu,1)-\mu}+n^{1+\mu}+|Y|))
worst-case time,

•

batches of at most
n^{\delta}

vertex updates
to
G
in
\widetilde{O}(h^{2}n^{\omega(1,\delta,1)})
worst-case time,

•

single-element insertions to
Y
in
\widetilde{O}(h^{2}n^{\mu})
time,

•

removing elements from
Y
in
O(1)
time.

Crucially, for small-polynomial values of
h
, sets
Y
of size
n^{2-O(1)}/h^{2}
, and appropriately chosen
\mu
, say
\mu=1/2
, the single-edge update time bound of this data structure is subquadratic in
n
.

To the best of our knowledge, previous algebraic dynamic graph data structures required
only very structured submatrices
Y
of the inverse to operate. For example, the aforementioned

st
-distance data structures
[
San05
,
BFN22
]
use a square submatrix
with rows and columns

{H\cup\{s,t\}}
. In fact,
[
BFN22
]
show
a more efficient (than Theorem
3.1
) data structure
for square inverse submatrix maintenance: the dependence on
n
in the single-edge update bound
of Theorem
3.1
is at least
n^{1.529}
(
n^{1.5}
if
\omega=2
), whereas
[
BFN22
]
achieve the dependence of
n^{1.406}
(
n^{1.25}
if
\omega=2
).

3.2
Combinatorial plug-ins to the algebraic data structure

On top of the data structure Theorem
3.1
, we apply
two crucial black-box enhancements.

Induced subgraph operations or vertex switching

First, we will need to maintain
h
-bounded distances not only in the graph
G
,
but also in an
induced subgraph

G[W]
, where the set
W\subseteq V

is also subject to updates. This functionality models temporarily switching some vertices off,
or, equivalently, removing all their incident edges.

A very simple but powerful observation is that in directed graphs, switching vertices
can be modeled using single-edge updates. This follows by applying a standard reduction
of splitting a vertex
v
into an in-copy
v^{+}
and an out-copy
v^{-}
, connected
by an edge
v^{+}v^{-}
switched on iff
v\in W
.
As a result, even though switching a vertex off forbids using up to
n

edges, modeling it costs no more than a single-edge update to the data structure
maintaining the graph. Recall that the single-edge update cost in Theorem
3.1
is subquadratic if the parameters are appropriately set.

Path reporting via grouping into blocks

A well-known shortcoming
of path-counting
h
-bounded distances data structures is that they do not
allow, out-of-the-box, reporting the shortest
h
-bounded paths.
The data structures we develop internally require the path-reporting functionality (against an adaptive adversary) even for maintaining the single-source distances only.

To this end, we make use of a recent technique of
[
KMS22
]
used therein for DAGs to convert
a fully dynamic single-source reachability data structure into a fully dynamic single-source
reachability tree
reporting data structure. We apply this technique
in the case of
h
-bounded distances.

The overall idea is as follows. Having fixed a parameter
b\in[1,n]
, the
block size
, the vertex set
V
is split into
\ell\leq\lceil n/b\rceil
blocks
V_{1},\ldots,V_{\ell}
of no more than
b
vertices.
Via vertex-splitting, we can construct
\ell
related graphs
G_{1},\ldots,G_{\ell}
such that
a shortest
h
-bounded
s\to t
path in
G
is preserved in
G_{i}
iff
the penultimate vertex is in the blocks
V_{1}
through
V_{i}
.

Suppose we maintain the
h
-bounded distances data structures (of Theorem
3.1
) on the graphs
G_{1},\ldots,G_{\ell}
. Then, given a source
s\in V
and single-source
h
-bounded distances
\delta^{h}_{G_{i}}(s,\cdot)
for all
i
, we can
identify, for each
t\in T
, at most
b
potential predecessors
p
for which
some shortest
h
-bounded
s\to t
path has a penultimate vertex
p
.
Given those, the single-source shortest
h
-bounded paths tree can be constructed in
O(nb)
time
by simply running BFS on an
O(nb)
-sized subgraph of
G
.

Overall, if the dynamic
h
-bounded distances data structure has update time
U(n,h)
and
can compute single-source
h
-bounded distances in
Q(n,h)
time, then grouping
into blocks yields a data structure with update time
O\left(\frac{n}{b}\cdot U(n,h)\right)

reporting single-source
h
-bounded shortest paths in
O\left((n/b)Q(n,h)+nb\right)
time.
In Section
4
we also describe a refinement of this reduction that can produce better running times; see Lemma
4.2
.

Although we need path reporting even internally for the sole purpose of maintaining single-source distances, note that grouping into blocks allows for converting – in a
deterministic
and black-box way – any
truly subquadratic
single-source distances data structure into a SSSP-tree reporting data structure. For example, if the single-source distances data structure (i.e.,
h=n
) has
U(n,h),Q(n,h)\in O(n^{1.98})
, it is enough to set
h=n
and
b=n^{0.99}
to get
O(n^{1.99})
-time SSSP tree reporting.
Therefore, in the remaining part of this outline we only discuss maintaining single-source distances deterministically.

3.3
Maintaining most
h
-bounded shortest paths under deletions

Overall, our fully dynamic single-source distances data structure follows
the high-level idea of the known
combinatorial
fully dynamic APSP data structures with subcubic
worst-case
update time, first shown by
[
Tho05
]
and subsequently developed in
[
ACK17
,
CZ23
,
GW20b
,
Mao23
]
.

The data structure operates in phases of
\Delta=n^{\delta}
updates, where
\delta\in(0,1)
.
At any moment of time, let
G
denote the current graph (with all updates issued so far applied), and let
G_{0}
reflect how
G
looked like when
the current phase started.
While the phase proceeds, let
D
denote the set of
\leq 2\Delta

affected vertices
, i.e.,
those constituting the endpoints of all the edges inserted or deleted in the current phase.
Note that we have
G-D=G_{0}-D\subseteq G
at any time.

Each phase starts with a relatively costly preprocessing step
whose purpose is to find a certain collection
of
O(n^{2})
paths
\Pi
in
G_{0}
accomplishing the following informal goals:

1.

\Pi
contains all-pairs
h
-bounded shortest paths in a
large
subgraph of
G_{0}-D
.

2.

removing
D
from
G
keeps
most
of the paths in
\Pi
intact.

More precisely, we use the following lemma inspired by the preprocessing in
[
GW20b
]
.

Lemma 3.2
.

Let
G=(V,E)
be a directed graph. Let
h,\tau\in[1,n]
.
Assume one has constructed a
deterministic
data structure storing
G
and a subset
W\subseteq V
initially equal to
V
, and supporting:

1.

updates removing a vertex from
W
,

2.

queries computing shortest
h
-bounded paths in
G[W]
from a query vertex
s
to
all

v\in V
.

Suppose one can perform updates in
U(n,h)

worst-case
time, and queries in
Q(n,h)
time.

In
O(n^{2}h+(n/\tau)\cdot U(n,h)+n\cdot Q(n,h))
time one can compute a set
C\subseteq V
of
size
O(n/\tau)
, and a collection of paths
\Pi
in
G
, containing at most one path
\pi_{s,t}

for all
s,t\in V
, such that:

1.

For any
s,t\in V
, if
\delta_{G-C}^{h}(s,t)\neq\infty
, then
\pi_{s,t}\in\Pi
exists and is an
s\to t
path in
G
of length at most
\delta_{G-C}^{h}(s,t)
.

2.

For any
u\in V
, there exist at most
O(hn\cdot\tau)
paths
\pi_{s,t}\in\Pi
with
u\in V(\pi_{s,t})
.

After the algorithm completes, the assumed data structure is reverted back to the state when
W=V
.

We call
\tau
and
C
in Lemma
3.2
the
congestion threshold
and the
congested subset
, respectively.
The preprocessing of Lemma
3.2
, applied to
G_{0}
with a small-polynomial
\tau
and
h
, achieves the goal (a) since the obtained collection
\Pi
contains paths at least as
short as shortest
h
-bounded paths in
G_{0}-(C\cup D)
. Note that
G_{0}-(C\cup D)
forms a

large
subgraph of
G_{0}-D
because the obtained set of congested vertices
C
has sublinear size.
It also achieves the goal (b) since the
O(hn\cdot\tau\cdot\Delta)
paths in
\Pi
containing
a vertex from
D
(let us denote them by
\Pi_{D}
) constitute a relatively small portion of the entire collection

\Pi
containing typically
\Theta(n^{2})
paths.

Using purely combinatorial data structures, the preprocessing of Lemma
3.2
takes
\Theta(n^{3})
time for dense graphs, which is prohibitive in our case since it is meant to be applied
once per
\Delta
updates.
However, by plugging in the data structure
\mathcal{T}
of Theorem
3.1
, extended with induced subgraph operations and path-reporting capabilities (with an appropriately chosen block size
b\in[1,n]
, as explained in Section
3.2
), we can manage to compute the pair
(\Pi,C)
in subcubic time upon the start of the phase.
For large enough
\Delta
, this incurs a subquadratic
amortized
update cost.
However, we remark that the heavy super-quadratic preprocessing (which constitutes the only source of amortization here) is scheduled precisely every
\Delta
updates and consequently the data structure can be deamortized using a standard technique; see, e.g.,
[
ACK17
,
BNS19
,
Tho05
]
.

3.4
Maintaining
h
-bounded distances beyond the preprocessed pairs

The preprocessing of Lemma
3.2
applied at the beginning of a phase guarantees that
h
-bounded distances in
G_{0}-(C\cup D)=G-(C\cup D)
are maintained for all
(s,t)
such that either
\delta_{G_{0}-C}(s,t)=\infty
holds, or
\pi_{s,t}\in\Pi\setminus\Pi_{D}
,
that is, we have
\delta_{G_{0}-(C\cup D)}^{h}(s,t)=|\pi_{s,t}|
.

We delegate maintaining
h
-bounded distances (in
G
) either corresponding to paths going
through

C\cup D
and/or for the
affected pairs

(s,t)
such that
\pi_{s,t}\in\Pi_{D}
to a separate data structure

\mathcal{A}
of Theorem
3.1
maintaining the current graph
G
.
More specifically, we define the set
Y\subseteq V\times V
(identified with the submatrix
Y
of interest in
\mathcal{A}
, see Theorem
3.1
)
to contain, at any time:

•

all pairs
((C\cup D)\times V)\cup(V\times(C\cup D))
,

•

all pairs
(s,t)
such that
\pi_{s,t}\in\Pi_{D}
.

Note that the size of
Y
is bounded by
O(n^{2}/\tau+n\Delta+\Delta hn\tau)
at all times,
which incurs a per-update cost of
O(h^{2}n^{2}/\tau+\Delta h^{3}n\tau)

for maintaining
\delta_{G}^{h}(s,t)
for all
(s,t)\in Y
in the data structure
\mathcal{A}
.
Moreover, we crucially rely on the low-recourse property of the set
Y
: it grows by at most
O(hn\tau)

elements (worst-case) per update, as
D
grows by at most two elements per update.
This allows to augment the submatrix of interest in
\mathcal{A}
in
O(h^{3}n^{1+\mu}\tau)
time per update.
We point out that it is the affected pairs that cause the submatrix
of interest
Y
to be of a rather arbitrary shape beyond our control;
the remaining part of
Y
is composed of some
O(n/\tau+\Delta)
full rows and columns.

3.5
Speeding up queries by hitting set-based sparsification

Let
s\in V
be some query vertex. Suppose we want to compute single-source
distances from
s
in
G
.
First of all, using the data structure
\mathcal{A}
we can temporarily add
all pairs
(s,t)
,
t\in V
, to the set
Y
so that we can also access
single-source
h
-bounded distances from
s
.
This costs
\widetilde{O}(h^{3}n^{1+\mu})
time.

With such an augmented set
Y
, one can prove (see Lemma
6.2
) that for each
t
, there exists a shortest path
P=s\to t
in
G
obtained by stitching paths of one of the following kinds:

1.

a shortest
h
-bounded path
u\to v
, where
(u,v)\in Y
,

2.

a path
\pi_{u,v}\in\Pi\setminus\Pi_{D}
such that
|\pi_{u,v}|\geq h/2
.

Consequently, we could build a graph
X
with edges
(u,v)\in Y
of weight
\delta_{G}^{h}(u,v)
(maintained by
\mathcal{A}
) and edges
(u,v)
for all non-affected pairs with
\pi_{u,v}\in\Pi\setminus\Pi_{D}
, and run Dijkstra‘s algorithm on
X
to obtain single-source distances from
s
in
G
.
The number of edges of the former kind is
O(n^{2}/\tau+hn\Delta\tau)
, i.e., subquadratic.
However, the number of edges of the latter kind can be still
\Theta(n^{2})
.
Fortunately, these edges represent relatively long
\Theta(h)
-hop paths, and this can be exploited as follows.
During the preprocessing at the beginning of a phase, after computing the collection
\Pi
,
we compute an
\widetilde{O}(n/h)
-sized hitting set
H
of the paths in
\Pi

composed of at least
h/2
edges. This can be done deterministically in
\widetilde{O}(n^{2}h)

time using a folklore greedy algorithm. For each of these paths
\pi_{u,v}
,
we pick one
z_{u,v}\in H\cap V(\pi_{u,v})
as a representative of the hitting set
for that path.

To be able to efficiently compute single-source distances upon query,
we sparsify the lengths of the
O(n^{2})
paths of type (ii) using only
\widetilde{O}(n^{2}/h)
edges.
For each
(z,v)\in H\times V
, we use an edge
zv
of weight equal to the
minimum length of the
z\to v
suffix of a path
\pi_{u,v}\in\Pi\setminus\Pi_{D}
such that
z_{u,v}=z
. Similarly, for each
(u,z)\in V\times H
,
we use an edge
uz
of weight equal to the minimum length of the
u\to z
prefix
of a path
\pi_{u,v}\in\Pi\setminus\Pi_{D}
with
z_{u,v}=z
.
These auxiliary edges can be efficiently maintained subject to insertions to
D

(equivalently, deletions from
\Pi\setminus\Pi_{D}
).
Using the auxiliary edges in place of explicit edges for all the non-affected
paths decreases the size of the graph
X
to
O(n^{2}/\tau+hn\Delta\tau+n^{2}/h)

which is subquadratic for a proper choice of parameters.

We remark that our usage of hitting sets is conceptually different compared to previous dynamic
shortest paths algorithms.
There, hitting sets are typically used to hit long-hop paths in the
current
graph,
most commonly by using randomization to ensure a once-sampled hitting
set is valid for
\operatorname{poly}(n)
(future) versions of the graph (e.g., in
[
ACK17
,
San05
,
BFN22
]
).
In our case, we use it merely for the sake of sparsification of some statically precomputed
set of paths and do not require maintaining the current all-pairs
h
-bounded distances between the vertices of the hitting set.

3.6
Fully dynamic
(1+\epsilon)
-approximate APSP with non-trivial worst-case update bound and optimal path-reporting

In order to obtain the deterministic all-pairs data structures supporting optimal-time path reporting, we build upon the framework that we have used for single-source distances.
First of all, to be competitive with the known all-pairs reachability and APSP data structures, we need to support more complex
vertex updates
. Fortunately, the SSSP framework can be seen to
allow decremental vertex updates within a phase, and only relies on the single-edge updates assumption (i.e., that every updated edge has
both
endpoints in
D
)
in the query procedure.
Moreover, the data structure of Theorem
3.1
supports batch-vertex updates, which we leverage when advancing to the next phase.

In our all-pairs data structures, the single-source query procedure is replaced by
explicitly rebuilding

a collection
\Pi^{\prime}
(containing, in particular, the unaffected paths
\Pi\setminus\Pi_{D}
) of
h
-bounded paths
\pi^{\prime}_{u,v}
for the
O(hn\Delta\tau)
affected pairs
(u,v)
(with
\pi_{u,v}\in\Pi_{D}
) satisfying similar guarantees wrt. the
h
-bounded distances in
G-(C\cup D)
.
This is achieved via another application of the data structure of Theorem
3.1
, enhanced as described in Section
3.2
.
Importantly, this allows for optimal-time reporting of
h
-bounded paths
in
G
that are at least as short as those appearing in
G-(C\cup D)
.

With the shortest
h
-bounded paths
\Pi^{\prime}
improving upon those in
G-(C\cup D)
rebuilt,
we deterministically compute an
\widetilde{O}(n/h)
-sized hitting set
H
of
the
\Theta(h)
-hop paths in
\Pi^{\prime}
.
One can show that for every pair
(s,t)
, either
\pi^{\prime}_{s,t}\in\Pi^{\prime}

is a shortest
s\to t
path in
G
, or there is a shortest path
P=s\to t

in
G

with a vertex in
C\cup D\cup H
appearing
on each
h
-hop segment of
P
.
If
|C\cup D\cup H|\leq n^{\alpha}
, for some
\alpha<1
,
then this allows computing all-pairs shortest paths of the latter kind
using
O(\log{n})
min-plus products of matrices whose at least one dimension
is bounded by
O(n^{\alpha})
.
Such products can be computed polynomially faster than products of full
n\times n

matrices, even without resorting to non-trivial rectangular matrix multiplication algorithms
[
GU18
,
HP98
]
.
Sadly, in our case, using exact min-plus product for this task does not yield
an improved worst-case update bound over the known exact APSP data structures
[
ACK17
,
GW20b
]
with subcubic worst-case update bounds.

However, if we use the
(1+\epsilon)
-approximate min-plus product
[
Zwi02
]
(where
\epsilon\in(0,1]
)
we can perform this computation approximately
in sub-
n^{\omega}
time
\widetilde{O}(n^{\omega(1,\alpha,1)}/\epsilon)
.
The approximate min-plus product can also produce matrix multiplication
witnesses within the same bound deterministically.
Those, in turn, can be used to recover, for any query pair
(s,t)
, some

s\to t
path of length at most
(1+\epsilon)\cdot\delta_{G}(s,t)

in optimal
O(\delta_{G}(s,t))
time.

For the special case of all-pairs reachability (i.e., any
finite approximation of shortest paths), another application
of matrix multiplication witnesses can yield a stronger
path-reporting interface. Namely, within
O(n^{\omega(1,\alpha,1)})
time
we can also explicitly recompute all-pairs reachability trees.

Finally, we remark that, at the end of the day, due to the overheads of the preprocessing and rebuilding
short-hop paths, the worst-case update time of this data structure
is faster than the recompute-from-scratch bound
\widetilde{O}(n^{\omega}/\epsilon)
only
conditionally, if
\omega\geq 2.12
.

3.7
Deterministic fully-dynamic transitive closure with an unconditional sub-
n^{\omega}
update bound

For the fully dynamic transitive closure problem, we show that the deterministic sub-
n^{\omega}
worst-case update time can be attained unless
\omega=2
.
We achieve that using a different and simpler approach.

Recall that a randomly sampled hitting set of size
\widetilde{O}(n/h)
hits some polynomial
number of fixed
\geq h
-hop
shortest paths
with high probability.
Roughly speaking, given any such hitting set
H
of size at most
n^{\alpha}
,
\alpha<1
,
we can separately compute reachability through
H
using rectangular
matrix multiplication in
O(n^{\omega(1,\alpha,1)})
time, and delegate
maintaining all-pairs
h
-bounded distances to the deterministic data structure of Theorem
3.1
with
\widetilde{O}(h^{2}n^{2})
worst-case update time per vertex update.
However, whereas such a hitting set
H
is trivial to obtain using randomization,
it is not clear whether it can be computed deterministically
even in
O(n^{\omega})
time.

Our main idea is to use a weaker – both qualitatively and quantitatively – notion of a hitting set of
\geq h
-hop paths.
First of all, for the purposes of reachability, it is enough that for any
s,t\in V
with
\delta_{G}(s,t)\geq h
, the hitting set

H
hits an
h
-edge prefix of
some
(not necessarily shortest)
s\to t
path.
Such a qualitatively weaker hitting set of size
\widetilde{O}(n/h)
can be computed based on all-pairs reachability trees, computable in
\widetilde{O}(n^{\omega})
deterministic time
[
AGMN92
]
.

Second, a larger (but still sublinear) hitting set with the same guarantee can be computed more efficiently. Specifically, we show that if we are willing
to accept a hitting set of size
\widetilde{O}((n/d)\cdot(n/h))
, for a parameter
d\in[1,n]
, where
d\cdot h=\Omega(n)
, then it can be constructed deterministically in
\widetilde{O}(n^{2}+nd^{\omega-1})
time. We show that for any value of
\omega>2
,
the parameters
h
and
d
can be set so that the worst-case update time
of the data structure is polynomially smaller than
n^{\omega}
.

A drawback of this data structure is that it cannot report

s\to t
paths in time linear in the length of the reported path, let
alone in optimal
O(\delta_{G}(s,t))
time.
That being said, paths can still be reported in
O(n)
time
using a path reporting procedure of
[
KMS22
]
.

3.8
Randomized improvements

Using randomization, we can slightly improve the update bounds
of both the SSSP data structure and the
(1+\epsilon)
-approximate
APSP data structure. First of all, in both cases, using
path counting modulo a prime shaves an
h
-factor from
most of the terms in the update bounds.
Then, the obtained data structures become Monte Carlo randomized
(correct with high probability) but can still work against
an adaptive adversary since the path counts are never revealed.

With randomization, the update/query bound of the fully dynamic SSSP data structure can be improved even further.
Using standard
\widetilde{O}(n/h)
-sized
randomly sampled hitting sets, one can
replace the
O(n^{2})
-sized path collection of Lemma
3.2

with a different
O(n^{2}/h)
-sized collection
as used in the fully dynamic APSP data structure of
[
ACK17
]
(see Lemma
9.1
).
Overall, the powerful sampled hitting set makes it possible
to avoid two components crucial in the deterministic data structure:
(a) the explicit sublinear congested subset, and (b) sparsifying
the surviving paths from the collection (since the collection has subquadratic size).
It is worth noting that since the distances output by the data
structure are exact (and thus uniquely determined by the graph),
the data structure still works against an adaptive adversary.
See Section
9
for details.

6
Fully dynamic single-source shortest paths

In this section we describe our deterministic fully dynamic SSSP data structure for unweighted graphs
with truly subquadratic update and query time.

Phases and global data structures.

Let
h,\tau,\Delta,b\in[1,n]
and
\mu,\nu\in[0,1]
be parameters to be set later.
The data structure operates in phases of
\Delta

single-edge
updates. It also maintains
two
global
dynamic data structures shared between the phases:

•

A data structure
\mathcal{A}
of
Theorem

3.1
with
\mu:=\nu
always storing the
current graph
G
. Every edge update issued to
G
is immediately passed to
\mathcal{A}
.
The dynamic set

of vertex pairs of interest in
\mathcal{A}
, to be defined later, is initialized
at the beginning of
a phase. Moreover, the set
Y
grows by at most
O(\tau hn)
pairs per update in the worst-case.
However, we will guarantee that the size of
Y
is bounded by
O(n^{2}/\tau+\Delta\tau hn)
at all times.
By
Theorem

3.1
, the worst-case update time of

is:

\widetilde{O}(h^{2}\cdot(n^{\omega(1,\nu,1)-\nu}+n^{1+\nu}+|Y|)+h^{2}\cdot\tau hn^{1+\nu})=\widetilde{O}\left(h^{2}n^{\omega(1,\nu,1)-\nu}+\frac{h^{2}n^{2}}{\tau}+h^{3}\tau n\cdot(\Delta+n^{\nu})\right).

•

A data structure
\mathcal{T}
, as required by Theorem
5.1
and described in Section
5
,
with parameters
h,b,\mu
.
Every edge update issued to
G
is immediately passed to
\mathcal{T}
.
Recall that the cost of updating
\mathcal{T}
incurred by a single update to

is:

U(n,h)=O\left(\frac{h^{2}n^{1+\omega(1,\mu,1)-\mu}}{b}+\frac{h^{2}n^{2+\mu}}{b}\right).

While the phase proceeds, the set
W
in the data structure
\mathcal{T}
(describing the induced subgraph of interest)
equals

and it is only manipulated when a phase initializes.
Similarly, queries to
\mathcal{T}
will only be issued at the beginning of a phase.

Initializing a phase.

For a fixed current phase, let

denote the graph

at the beginning of that phase.
We always use

to refer to the
current graph
, i.e.,
with all updates issued so far applied.
Moreover, when a phase proceeds, let

At the beginning of a phase, we apply Theorem

.
By Theorem

, the amortized cost of such a preprocessing step, happening once per

\Delta

\widetilde{O}\left(\frac{n^{2}h}{\Delta}+\frac{h^{2}n^{2+\omega(1,\mu,1)-\mu}}{b\tau\Delta}+\frac{h^{2}n^{3+\mu}}{b\tau\Delta}+\frac{n^{2}b}{\Delta}\right).

(1)

We next deterministically compute an
\widetilde{O}(n/h)
-sized hitting set

of
those paths

that have at least

.

Lemma 6.1

The total size of

O(n^{2}h/\Delta)

which is asymptotically the same as the first term in (

With the hitting set

\begin{split}\widetilde{O}\left(\frac{n^{2}h}{\Delta}+\frac{h^{2}n(n^{\omega(1,\mu,1)-\mu}+n^{1+\mu})}{b}\cdot\left(1+\frac{n}{\tau\Delta}\right)+\frac{n^{2}b}{\Delta}+h^{2}n^{\omega(1,\nu,1)-\nu}+\frac{h^{2}n^{2}}{\tau}\right.\\

Lemma 6.2

For all

Let us now prove that
\delta_{X}(s,t)\leq\delta_{G}(s,t)
.
Consider any shortest

in

First, split

not passing through any

P_{i}=u_{i}\to v_{i}
, we have
V(P_{i})\cap(C\cup D)\subseteq\{u_{i},v_{i}\}

and
u_{i}\in C\cup D\cup\{s\}
.
We will prove that
\delta_{X}(u_{i},v_{i})\leq\delta_{G}(u_{i},v_{i})
. By summing through
i
,
\delta_{X}(s,t)\leq\delta_{G}(s,t)
will follow easily.

Consider some
P_{i}
. We have
|P_{i}|=\delta_{G}(u_{i},v_{i})
.
If
|P_{i}|\leq h
, then
\delta_{G}(u_{i},v_{i})=\delta_{G}^{h}(u_{i},v_{i})

and by
u_{i}\in C\cup D\cup\{s\}
,
(u_{i},v_{i})\in Y_{s}
. As a result,
there is an edge
u_{i}v_{i}
of weight
\delta_{G}(u_{i},v_{i})
in
X
.

Suppose
|P_{i}|>h
. Split
P_{i}
arbitrarily into subpaths
Q_{1},\ldots,Q_{l}

such that
\lfloor h/2\rfloor\leq|Q_{j}|\leq h
for all
j=1,\ldots,l
.
Consider some
j
and
let
Q_{j}
be an
x_{j}\to y_{j}
path.
We will prove that
\delta_{X}(x_{j},y_{j})\leq|Q_{j}|=\delta_{G}^{h}(x_{j},y_{j})
.
It will follow that

\delta_{X}(u_{i},v_{i})\leq\sum_{j}\delta_{X}(x_{i},y_{j})\leq\sum_{j}\delta_{G}^{h}(x_{j},y_{j})=\sum_{j}\delta_{G}(x_{j},y_{j})=\delta_{G}(u_{i},v_{i}),

as desired.

If
(x_{j},y_{j})\in Y_{s}
, then there is an edge
x_{j}y_{j}
of weight
\delta_{G}^{h}(x_{j},y_{j})=\delta_{G}(x_{j},y_{j})

in
X
which immediately implies
\delta_{X}(x_{j},y_{j})\leq\delta_{G}^{h}(x_{j},y_{j})
.
Otherwise, we have
(x_{j},y_{j})\notin Y_{s}
.
Then by the definition of
P_{i}
and
Y_{s}
, we obtain that
V(Q_{j})\cap(C\cup D)=\emptyset
.
This means that
Q_{j}\subseteq G-(C\cup D)\subseteq G_{0}-C
and thus
\delta_{G_{0}-C}^{h}(x_{j},y_{j})\leq\delta_{G}(x_{j},y_{j})

as
Q_{j}
is a shortest path in
G
.
Moreover, since
(x_{j},y_{j})\notin Y_{s}
and
\delta_{G_{0}-C}^{h}(x_{j},y_{j})<\infty
,
\pi_{x_{j},y_{j}}\in\Pi\setminus\Pi_{D}
, i.e.,

\pi_{x_{j},y_{j}}
exists and does not contain a vertex from
D
.
As a result,
\pi_{x_{j},y_{j}}\subseteq G
, i.e.,
\delta_{G}(x_{j},y_{j})\leq|\pi_{x_{j},y_{j}}|
.
But we also have
|\pi_{x_{j},y_{j}}|\leq\delta_{G_{0}-C}^{h}(x_{j},y_{j})
by Theorem
3.2
, so we obtain:

\delta_{G}(x_{j},y_{j})\leq|\pi_{x_{j},y_{j}}|\leq\delta_{G_{0}-C}^{h}(x_{j},y_{j})\leq\delta_{G}(x_{j},y_{j}).

All the inequalities above have to be in fact equalities. This
proves that
\pi_{x_{j},y_{j}}
is a shortest
x_{j}\to y_{j}
path in
G
.
Finally, recall that
|\pi_{x_{j},y_{j}}|=\delta_{G}(x_{j},y_{j})\geq\lfloor h/2\rfloor
. Consequently, there exists a vertex
{z=\beta(\pi_{x_{j},y_{j}})\in H}

on the path
\pi_{x_{j},y_{j}}\in\Pi\setminus\Pi_{D}
.
We conclude
\delta_{G}(x_{j},y_{j})=|\pi_{x_{j},y_{j}}[x_{j},z]|+|\pi_{x_{j},y_{j}}[z,y_{j}]|
.
By the definition of the multisets
{\Psi^{\mathrm{from}}_{z}}(x_{j})
and
{\Psi^{\mathrm{to}}_{z}}(y_{j})
,

|\pi_{x_{j},y_{j}}[x_{j},z]|\in{\Psi^{\mathrm{from}}_{z}}(x_{j})
and
|\pi_{x_{j},y_{j}}[z,y_{j}]|\in{\Psi^{\mathrm{to}}_{z}}(y_{j})
.
Consequently,
w_{X}(x_{j},z)\leq|\pi_{x_{j},y_{j}}[x_{j},z]|

and
w_{X}(z,y_{j})\leq|\pi_{x_{j},y_{j}}[z,y_{j}]|
, and thus
there is a path
x_{j}\to y_{j}

of weight
w_{X}(x_{j},z)+w_{X}(z,y_{j})\leq\delta_{G}(x_{j},y_{j})
in
X
.
∎

Setting the parameters.

Let us now try to set the parameters so that the maximum of the update and query time is minimized.
The only term incurred by the query procedure that is not dominated by the terms of the
previously obtained update bound is
\widetilde{O}(n^{2}/h)
.
Moreover, it can be easily verified that it is best to set
\mu:=\rho
, where
\rho\approx 0.529
is the unique value
such that
\omega(1,\rho,1)=1+\rho
.

This way, we obtain the following combined updated/query bound:

O\left(\frac{n^{2}h}{\Delta}+\frac{h^{2}n^{2+\rho}}{b}\cdot\left(1+\frac{n}{\tau\Delta}\right)+\frac{n^{2}b}{\Delta}+h^{2}n^{\omega(1,\nu,1)-\nu}+\frac{h^{2}n^{2}}{\tau}+h^{3}\tau n\cdot(\Delta+n^{\nu})+\frac{h^{2}n^{2+\nu}}{\tau\Delta}+\frac{n^{2}}{h}\right).

By setting the parameters
h=n^{0.031}
,
\Delta=n^{0.78}
,
t=n^{0.093}
,
b=n^{0.749}
,
\nu=\rho

obtained using the online balancing tool
[
Bra
]
,
we get an
O(n^{1.969})
worst-case update and query bounds.

It is also interesting to see what is the exact dependence on
\omega
we can get.
One can prove that for large enough
\Delta
it is optimal to
set
\nu:=\rho
so that
n^{\nu}<\Delta
, and also
b:=\Delta/h
, and
\tau:=h^{3}
.
Then, we get the bound

\widetilde{O}\left(\frac{hn^{2+\rho}}{\Delta}+\frac{n^{3+\rho}}{\Delta^{2}}+\Delta h^{6}n+\frac{n^{2}}{h}\right)

By balancing the two last terms, we get
\Delta=n/h^{7}
.
Then the first term (
h^{8}n^{1+\rho}
) becomes dominated by the second (
h^{14}n^{1+\rho}
).
By further balancing the latter with
n^{2}/h
we get
h=n^{(1-\rho)/15}
.
The final bound becomes (by
\rho\leq\frac{1}{4-\omega}
):

\widetilde{O}\left(n^{2-\frac{1-\rho}{15}}\right)\subseteq\widetilde{O}\left(n^{2-\frac{3-\omega}{60-15\omega}}\right).

This bound is subquadratic assuming any truly subcubic
matrix multiplication algorithm is used and equals
\widetilde{O}(n^{2-1/30})
if
\omega=2
(then,
\rho=0.5
).

Deamortization.

The heavy super-quadratic preprocessing invoking Theorem
5.1
, initializing the set
Y
, and constructing the hitting set (which are the only source of amortization here) happens in a coordinated
way, once every
\Delta
updates.
Consequently, the data structure can be deamortized using a standard technique
of running two copies of the data structure in parallel and spreading out the reset computation over several updates. While one copy of the algorithm is performing the reset, the other copy is used to answer the queries.
For details, we refer to e.g.,
[
ACK17
,
BNS19
,
Tho05
]
.

We have thus proved:

Theorem 6.3
.

Let
G=(V,E)
be unweighted digraph. There exists a deterministic data structure supporting
fully dynamic single-edge updates to
G
and computing exact distances from an arbitrary query source
s\in V

to all other vertices in
G

in
O(n^{1.969})
worst-case time.

If
\omega=2
, the bound becomes
\widetilde{O}(n^{2-1/30})
.

SSSP tree reporting.

We now explain how the data structure of Theorem
6.3
can be extended to also
output a single-source shortest paths tree in subquadratic time, albeit at the cost of an additional polynomial overhead.

We apply Lemma
4.1
with
h:=n
on top of the obtained data structure maintaining
single-source distances. In terms of Lemma
4.1
, we have
Q_{\mathrm{source}}(n,n)=O(n^{1.969})
by Theorem
6.3
,
and we want to support queries of the form
S=\{s\}
,
Y=\{s\}\times V
,
for a query source
s\in V
.
As a result, for any
b\in[1,n]
, there exists a data structure supporting single-edge updates
to
G
in
O(n^{2.969}/b)
time and reporting predecessors of shortest
n
-bounded paths from any
source vertex
s
in
O(n^{2.969}/b+nb)
time.
Clearly, the predecessors yield an SSSP tree from
s
.
By setting
b=0.985
, we obtain a deterministic tree-reporting SSSP data structure
with
O(n^{1.985})
worst-case update and query time.

7
Fully dynamic path-reporting transitive closure and approximate APSP

In this section, we consider the fully dynamic transitive closure and
(1+\epsilon)
-approximate
APSP problems (in unweighted digraphs)
under
vertex updates
to
G
.
Under the assumption that
\omega\geq 2.12
,
we describe a deterministic data structure with
O(n^{\omega-\gamma})
worst-case update
time, for some
\gamma>0
dependent on
\omega
, that explicitly maintains
the transitive closure of a matrix of distance estimates.
In the case of approximate distances, the data structure also supports
reporting any
s\to t
path of length at most
(1+\epsilon)\cdot\delta_{G}(s,t)

in optimal
O(\delta_{G}(s,t))
time.
For reachability, an even stronger reporting interface is achieved:
reachability trees in
G
from all possible sources
s\in V

are explicitly stored after each update.
Clearly, this also allows for reporting paths in
G
between arbitrary pairs of vertices
in optimal time.

The overall approach is similar
as in the fully dynamic SSSP data structure from Section
6
.
Namely, we will operate in phases of length
\Delta
and
use analogous global data structures shared among the phases.
Every phase starts by computing a pair
(C,\Pi)
as given by Theorem
5.1
.

The data structure
\mathcal{T}
.

Recall that the global data structures
\mathcal{A}
and
\mathcal{T}
in Section
6
, both implemented
as data structures of
Theorem

3.1
(with possibly some extensions of Section
4
),
rely only on
single-edge
updates (so that they reflect
G
at all times) and vertex switch-offs.
Here, we will use the data structure
\mathcal{T}
from Section
6
, required by Theorem
5.1
,
in a slightly different way.

Instead of passing the updates to
G
to
\mathcal{T}
immediately,
we will only do so at the end of a phase, that is, in a batch of at most
\Delta
updates.
This is done with the vertex batch-update operation of
Theorem

3.1
.
To see that this is sufficient,
recall that the only purpose of
\mathcal{T}

was to construct the set
C
and a collection of paths
\Pi
.
For this task,
\mathcal{T}
only required supporting switching vertices
off interleaved with
h
-bounded-shortest paths queries from a single source.
We thus require
\mathcal{T}
to reflect the current graph
G
only once per
\Delta
updates.
Since a batch update is performed on
\mathcal{T}
only once per
\Delta=n^{\delta}
updates,
this incurs an
\widetilde{O}\left(h^{2}n^{\omega(1,\delta,1)+1}/(\Delta b)\right)
worst-case cost per update.
As a result, the total per-update cost of initializing a phase
is now:

O\left(\frac{h^{2}n^{\omega(1,\delta,1)+1}}{\Delta b}+\frac{h^{2}n^{2+\rho}}{b}\cdot\left(1+\frac{n}{\Delta\tau}\right)+\frac{n^{2}b}{\Delta}\right).

The set
Y
.

We also redefine the set
Y\subseteq V\times V
, for a fixed phase, to only contain
the pairs
(s,t)
such that
\pi_{s,t}\in\Pi_{D}
.
As a result, by Theorem
5.1
, we have
|Y|=O(\Delta h\tau n)
at all times.

The predecessor reporting data structure
\mathcal{B}
.

Let
\mathcal{S}
and
\mathcal{P}
be two data structures of Theorem
3.1
, for
the parameter
\mu
to be set later, responsible for maintaining
h
-bounded distances
in
G
.
While the phase proceeds, these data structures will not accept edge/vertex updates.
Only at the end of the phase they are updated with a batch of
\Delta
vertex updates
from the current phase.

The data structures
\mathcal{S}
and
\mathcal{P}
have different purposes.

\mathcal{S}
is initialized so that it can maintain
\delta_{G}^{h}(s,t)

explicitly

for all
n^{2}
pairs
s,t\in V
(i.e.,
Y:=V\times V
in terms of Theorem
3.1
),
whereas
\mathcal{P}
is capable of answering arbitrary
\delta_{G}^{h}(s,t)
queries
in
\widetilde{O}(h^{2}n^{\mu})
time.
This way,
\mathcal{S}
allows very fast queries at the cost of
\widetilde{O}(h^{2}n^{2})
worst-case update time,
whereas
\mathcal{P}
answers queries slower, but can handle updates
more efficiently, in
\widetilde{O}(h^{2}(n^{\omega(1,\mu,1)-\mu}+n^{\mu}))
worst-case time.

We use data structures
\mathcal{S}
and
\mathcal{P}
to construct a predecessor reporting data structure
\mathcal{B}

of Lemma
4.2
storing the graph
G-D
, for
b:=\beta
, where
\beta\in[1,n]

is a parameter to be set later.
Specifically, we first apply Lemma
4.2
, and then also Lemma
4.4

on top of that to enable cheap insertions to
D
(we model

G-D
as the induced subgraph
G[W]
with
W:=V\setminus D
).
The general purpose of
\mathcal{B}
is to reconstruct
h
-bounded shortest paths in
G-D
.
Note that in terms of the quantities used in Lemma
4.2
, we have

Q_{\mathrm{source}}(n,h)=O(n)
,
U_{\mathrm{source}}(n,h)=\widetilde{O}(h^{2}n^{2})
,
Q_{\mathrm{pair}}(n,h)=\widetilde{O}(h^{2}n^{\mu})
and
U_{\mathrm{pair}}(n,h)=\widetilde{O}(h^{2}(n^{\omega(1,\mu,1)-\mu}+n^{1+\mu}))
.
Therefore, by issuing a query with
S=V
(which trivially guarantees
Y\subseteq S\times V
),

\mathcal{B}
can compute a predecessor vertex
q_{s,t}
on some shortest
h
-bounded
s\to t
paths
for all
(s,t)\in Y
such that
\delta_{G-D}^{h}(s,t)<\infty
in time

\widetilde{O}(n^{2}+(h^{2}n^{\mu}+\beta)\cdot|Y|).

Adding new vertices to
D
corresponds to removal of a vertex from the subset
W
issued to the data structure
\mathcal{B}
,
and thus costs

\widetilde{O}(h^{2}n^{2}+(n/\beta)\cdot h^{2}(n^{\omega(1,\mu,1)-\mu}+n^{1+\mu}))

time.
Similarly, the batch-vertex update to
\mathcal{B}
at the end of a phase
costs
\widetilde{O}\left(\frac{h^{2}n^{\omega(1,\delta,1)+1}}{\beta\Delta}\right)
amortized time per update.

Computing all-pairs distance estimates upon update.

After an update, we compute the respective predecessors
q_{s,t}
for all
(s,t)\in Y
using
\mathcal{B}
.
We now introduce a certain collection of paths
\Pi^{\prime}=(\pi^{\prime})_{s,t\in V}
derived from
\Pi
,
D
, and the computed predecessors.
For each
s,t\in V
,
\pi^{\prime}_{s,t}
is either
a path in
G-D
, or is left undefined (set to
\perp
).
Specifically, we set:

\pi^{\prime}_{s,t}=\begin{cases}\pi_{s,t}&\text{ if }\pi_{s,t}\in\Pi\setminus\Pi_{D},\\
\pi^{\prime}_{s,q_{s,t}}\cdot q_{s,t}t&\text{ if }\pi_{s,t}\in\Pi_{D}\text{ and }\delta_{G-D}^{h}(s,t)\neq\infty\text{ and }\pi^{\prime}_{s,q_{s,t}}\neq\perp,\\
\perp&\text{ otherwise. }\end{cases}

The definition is valid since
\pi_{s,t}\in\Pi_{D}
and
\delta_{G-D}^{h}(s,t)\neq\infty
implies
that
(s,t)\in Y
and thus
\delta^{h}_{G-D}(s,q_{s,t})=\delta^{h}_{G-D}(s,t)-1
.
Note that the collection
\Pi^{\prime}
can be explicitly constructed from
the definition in
O(n^{2}h)
time once the predecessors
q_{s,t}
are computed.
For simplicity, define
|\perp|=\infty
.

Lemma 7.1
.

For any
s,t\in V
such that no shortest
h
-bounded
s\to t
path in
G
goes
through
C\cup D
, we have
|\pi_{s,t}^{\prime}|=\delta_{G}^{h}(s,t)
.

Proof.

Recall that we denote by
G_{0}
the graph at the beginning of the current phase.

First consider the case
\delta_{G}^{h}(s,t)=\infty
. Then either
\pi_{s,t}\notin\Pi
which implies
\pi^{\prime}_{s,t}=\perp
,
or
\delta_{G_{0}-C}^{h}(s,t)<\infty
and thus
\pi_{s,t}\in\Pi_{D}
by
\delta_{G-D}^{h}(s,t)=\infty
.
However, in such a case we set
\pi^{\prime}_{s,t}:=\perp
as well.

Now let us assume that
\delta_{G}^{h}(s,t)
is finite. We prove the claim by induction
on
\delta_{G}^{h}(s,t)
.
Since no shortest
s\to t
path goes through
C\cup D
,
\delta_{G}^{h}(s,t)=\delta_{G-D}^{h}(s,t)=\delta_{G-(C\cup D)}^{h}(s,t)\geq\delta_{G_{0}-C}^{h}(s,t)
.
Hence, we obtain that
\pi_{s,t}\in\Pi
exists and has length at most
\delta_{G_{0}-C}^{h}(s,t)\leq\delta_{G}^{h}(s,t)
.
If
\pi_{s,t}\in\Pi\setminus\Pi_{D}
, then
\pi^{\prime}_{s,t}=\pi_{s,t}\subseteq G-D\subseteq G
,
so indeed we have
|\pi^{\prime}_{s,t}|=\delta_{G}^{h}(s,t)
.
Otherwise,
\pi_{s,t}\in\Pi_{D}
.
By
\delta_{G-D}^{h}(s,t)<\infty
,
q_{s,t}
exists and
\delta_{G}^{h}(s,q_{s,t})=\delta_{G}^{h}(s,t)-1
.
Since no shortest
h
-bounded
s\to t
path in
G
goes through
C\cup D
, neither
does any shortest
h
-bounded
s\to q_{s,t}
path in
G
.
By the inductive assumption we have that
|\pi^{\prime}_{s,q_{s,t}}|=\delta_{G}^{h}(s,q_{s,t})
.
As a result, the path
\pi^{\prime}_{s,t}=\pi^{\prime}_{s,q_{s,t}}\cdot q_{s,t}t
indeed
has length
\delta_{G}^{h}(s,t)
.
∎

With the collection
\Pi^{\prime}
in hand, in
O(n^{2}h)
time we can deterministically compute an
\widetilde{O}(n/h)
-sized hitting set
H\subseteq V

of all
\pi^{\prime}_{s,t}
satisfying
|\pi_{s,t}^{\prime}|=h
using Lemma
6.1
.

Lemma 7.2
.

Let
s\in V\setminus(C\cup D\cup H)
and
t\in V
be such that
\delta_{G}(s,t)<\infty
. Some shortest
s\to t
path in
G

either:

1.

is equal to
\pi^{\prime}_{s,t}
, or

2.

has a prefix
\pi^{\prime}_{s,q}\cdot qr
for some
r\in C\cup D\cup H
, where
q=r
or
qr\in E(G)
and
|\pi^{\prime}_{s,q}\cdot qr|\geq 1
.

Proof.

First suppose that
\delta_{G}(s,t)\leq h
, i.e.,
\delta_{G}^{h}(s,t)\neq\infty
.

If no shortest
s\to t
path in
G
goes through
C\cup D
, then by Lemma
7.1
,

\pi^{\prime}_{s,t}
is a shortest path, i.e., item (a) is satisfied.

Let us thus assume that some shortest
s\to t
path goes through
C\cup D
.
There exists an
r\in C\cup D
such that
\delta_{G}(s,t)=\delta_{G}(s,r)+\delta_{G}(r,t)
;
if there are many such
r
, pick one with minimal
\delta_{G}(s,r)
.
By
s\notin C\cup D
,
\delta_{G}(s,r)\geq 1
.
If
\delta_{G}(s,r)=1
, then some shortest
s\to t
path starts with the edge
sr
,
i.e., item (b) is satisfied with
q=s
.
Otherwise, if
\delta_{G}(s,r)\geq 2
,
then by the choice of
r
, any
s\to r
path has no vertices
in
C\cup D
except
r
. As a result, if
q\in V\setminus(C\cup D)
is the penultimate
vertex on one such
s\to r
path, we obtain that no
s\to q
path in
G
contains
a vertex from
C\cup D
.
By applying Lemma
7.1
to
(s,q)
, we obtain that
\pi^{\prime}_{s,q}

is a shortest
s\to q
path in
G
.
Therefore, we conclude that some shortest
s\to t
path in
G

has a prefix
\pi^{\prime}_{s,q}\cdot qr
, where
r\in C\cup D
, as desired.

Now consider the case
\delta_{G}(s,t)>h
.
Let
x\in V
be such that
\delta_{G}(s,t)=\delta_{G}(s,x)+\delta_{G}(x,t)
and
\delta_{G}(s,x)=h
.
We have already proved the lemma for the pair
(s,x)
.
If there is a shortest
s\to x
path satisfying (b), there is
also clearly a shortest
s\to t
path satisfying (b).
It may also happen that
\pi^{\prime}_{s,x}
is a shortest
s\to x
path in
G
.
But then, there exists a vertex
u\in H
,
u\neq s
, on
\pi^{\prime}_{s,x}
.
By applying the lemma once again to the pair
(s,u)
satisfying
\delta_{G}(s,u)\leq h
, we obtain
that either (b) holds for
(s,u)
and thus also for
(s,t)
,
or (a) holds for
(s,u)
, which together with
s\notin H
implies that
|\pi^{\prime}_{s,u}|\geq 1
and
thus (b) holds for
(s,t)
with
q=r=u\in H
.
∎

By proceeding symmetrically, one can prove a ’’suffix‘‘ version of Lemma
7.2
:

Lemma 7.3
.

Let
s\in V
and
t\in V\setminus(C\cup D\cup H)
be such that
\delta_{G}(s,t)<\infty
. Some shortest
s\to t
path in
G

either:

1.

is equal to
\pi^{\prime}_{s,t}
, or

2.

has a suffix
rq\cdot\pi^{\prime}_{q,t}
for some
r\in C\cup D\cup H
, where
q=r
or
rq\in E(G)
and
|rq\cdot\pi^{\prime}_{q,t}|\geq 1
.

Let us now recall the definition of the min-plus product
\star
. If
A
is an
a\times b
matrix
and
B
is an
b\times c
matrix, then
A\star B
is a
a\times c
matrix such that

(A\star B)_{i,j}=\min_{k=1}^{b}\{A_{i,k}+B_{k,j}\}
.

Define a matrix
A\in\{0,\ldots,h,\infty\}^{n\times n}
as follows:

A_{u,v}=\begin{cases}0&\text{ if }u=v\\
1&\text{ if }u\neq v\text{ and }uv\in E(G),\\
|\pi^{\prime}_{u,v}|&\text{ if }u\neq v\text{ and }uv\notin E(G)\text{ and }\pi^{\prime}_{u,v}\neq\perp,\\
\infty&\text{ otherwise. }\end{cases}

Let
A[S,T]
denote the submatrix of
A
with rows
S

Proof.

Suppose

By Lemma

Finally, if

Randomized improvements

In this section we show sketch how one can obtain sharper worst-case update bounds for SSSP
and transitive closure if randomization is used.

First of all, in all the components that use path counting, each
h^{2}
term in the update/query bounds
can be replaced with a
h
term in a standard way (see, e.g.,
[

only require testing whether the maintained path counts are zero or non-zero.
Hence, instead of using
\widetilde{\Theta}(h)

one can perform counting modulo a random
\Theta(\log{n})
-bit prime number
which is enough to differentiate between zero and non-zero counts
with high probability.
Arithmetic operations on numbers from such a range cost
\widetilde{O}(1)
time as opposed to
\widetilde{O}(h)
time
required in the deterministic path counting data structures.

In the case of path-reporting data structure of Section

it is not clear how to exploit randomization further (beyond reducing the cost

\left.+\frac{hn(n^{\omega(1,\mu,1)-\mu}+n^{1+\mu})}{\beta}+\frac{hn^{\omega(1,\delta,1)+1}}{\beta\Delta}+n^{\omega(1,\alpha,1)}\right).\end{split}

Using the online balancing tool
[

Lemma A.1

Let

be a dynamic

Let

be a dynamic set.
For any

for all

•

single-entry updates to

in

•

•

•

removing elements from

Proof.

The data structure internally maintains
n\times n
matrices
\mathbf{N}
and
n\times k
matrices
\mathbf{L},\mathbf{R}
(with
k\leq n^{\mu}
) such that

\displaystyle\mathbf{M}^{-1}=\mathbf{N}-\mathbf{L}\mathbf{R}^{\top}.

(3)

Further, the data structure explicitly maintains the values
\mathbf{M}^{-1}_{s,t}
for all
s,t\in Y
.

Initialization.

During initialization, the data structure computes
\mathbf{M}^{-1}
in
O(n^{\omega})
operations and stores this inverse as
\mathbf{N}
. The matrices
\mathbf{L},\mathbf{R}
are initialized as all-0 matrices.
In particular, since we compute
\mathbf{M}^{-1}
explicitly, we know
\mathbf{M}^{-1}_{s,t}
for all
s,t\in Y
.

Update to set
Y
.

When an index pair
(s,t)
is added to set
Y
, we must compute
\mathbf{M}^{-1}_{s,t}
.
By representation (
3
) and matrices
\mathbf{L},\mathbf{R}
consisting of at most
n^{\mu}
columns, this takes
O(n^{\mu})
operations.
When deleting an index pair from
Y
, we do not need to compute anything so such an update takes
O(1)
time.

Entry update to
\mathbf{M}
.

When matrix
\mathbf{M}
changes, we must update the representation (
3
).
By the Sherman-Morrison identity we have for any two vectors

that

\displaystyle(\mathbf{M}+uv^{\top})^{-1}=\mathbf{M}^{-1}-\frac{\mathbf{M}^{-1}u~v^{\top}\mathbf{M}^{-1}}{1+v^{\top}\mathbf{M}^{-1}u}.

(4)

When
\mathbf{M}
changes in a single entry, then vectors
u
,
v
have only one non-zero entry so the products
\mathbf{M}^{-1}u
and
v^{\top}\mathbf{M}^{-1}
consist of reading one row and column of
\mathbf{M}^{-1}
.
By the representation (
3
) and
\mathbf{R},\mathbf{L}
having at most
n^{\mu}
columns, this takes
O(n^{1+\mu})
operations.

Let
u^{\prime}:=\mathbf{M}^{-1}u/(1+v^{\top}\mathbf{M}^{-1}u)
and
v^{\prime}=(v^{\top}\mathbf{M}^{-1})^{\top}
, then we can set
\mathbf{L}\leftarrow[\mathbf{L}|u^{\prime}]
,
\mathbf{R}\leftarrow[\mathbf{R}|v^{\prime}]
(i.e. append these vectors to matrices
\mathbf{L},\mathbf{R}
) and thus have

\displaystyle(\mathbf{M}+uv^{\top})^{-1}=

\displaystyle~\mathbf{M}^{-1}-\frac{\mathbf{M}^{-1}u~v^{\top}\mathbf{M}^{-1}}{1+v^{\top}\mathbf{M}^{-1}u}

\displaystyle=

\displaystyle~\mathbf{M}^{-1}-u^{\prime}v^{\prime\top}

\displaystyle=

\displaystyle~\mathbf{N}-\mathbf{L}\mathbf{R}^{\top}-u^{\prime}v^{\prime\top}

\displaystyle=

\displaystyle~\mathbf{N}-[\mathbf{L}|u^{\prime}][\mathbf{R}|v^{\prime}]^{\top}

so we again satisfy (
3
).

Note that every
n^{\mu}
updates, the matrices
\mathbf{L},\mathbf{R}
have
n^{\mu}
columns.
To guarantee these matrices never have more columns than that, we set

using

At last, note that we must maintain

for all

\displaystyle(\mathbf{M}+uv^{\top})^{-1}_{s,t}=

\displaystyle~\mathbf{M}^{-1}_{s,t}-u^{\prime}_{s}v^{\prime}_{t}.

Which takes
O(|Y|)
time per update.

Low rank update to
\mathbf{M}

Consider a rank

in (

or

The Woodbury identity states that

\displaystyle(\mathbf{M}+\mathbf{U}\mathbf{V}^{\top})^{-1}=\mathbf{M}^{-1}-\mathbf{M}^{-1}\mathbf{U}(\mathbf{I}+\mathbf{V}^{\top}\mathbf{M}^{-1}\mathbf{U})^{-1}\mathbf{V}^{\top}\mathbf{M}^{-1}.

(5)

Here we can compute

and
\mathbf{V}^{\top}\mathbf{M}^{-1}=\mathbf{V}^{\top}(\mathbf{N}-\mathbf{L}\mathbf{R}^{\top})

In total, computing

We subtract the result from

in
O(n^{2})
operations, which is subsumed by the previous complexity terms. After this update, we still satisfy (

\displaystyle(\mathbf{M}+\mathbf{U}\mathbf{V}^{\top})^{-1}=

\displaystyle~\mathbf{M}^{-1}-\mathbf{M}^{-1}\mathbf{U}(\mathbf{I}+\mathbf{V}^{\top}\mathbf{M}^{-1}\mathbf{U})^{-1}\mathbf{V}^{\top}\mathbf{M}^{-1}

\displaystyle=

\displaystyle~\underbrace{\mathbf{N}-\mathbf{M}^{-1}\mathbf{U}(\mathbf{I}+\mathbf{V}^{\top}\mathbf{M}^{-1}\mathbf{U})^{-1}\mathbf{V}^{\top}\mathbf{M}^{-1}}_{\text{new }\mathbf{N}}-\mathbf{L}\mathbf{R}^{\top}.

Worst-case update time

or

element updates.
