Sharp estimates for the unique solution of the Hadamard-type two-point fractional boundary value problems Thanks: Mathematics Subject Classifications: 34A08, 34A40, 26A33.
Zaid Laadjal, Adjeroud Nacer

Abstract
In this short note, we present the sharp estimate for the existence of a unique solution for a Hadamard-type fractional differential equations with two-point boundary value conditions. The method of analysis is obtained by using the integral of the Green’s function and the Banach contraction principle. Further, we will also obtain a sharper lower bound of the eigenvalues for an eigenvalue problem. Two examples are presented to clarify the applicability of the essential results.

In the book
[

Kelley and Peterson considered the following
classical two-point boundary value problems:

\left\{\begin{array}[]{ll}u^{\prime\prime}(x)={\mathcal{F}}(x,u(x)),&a<x<b,\\
u(a)=A,\text{ }u(b)=B,&A,B\in\mathds{R},\end{array}\right.

(1)

Theorem 1
(
[

Let
{\mathcal{F}}:[a,b]\times\mathds{R}\rightarrow\mathds{R}
be a continuous function satisfying the assumption:

(H_{1})

There exists
K>0
such that
\left|{\mathcal{F}}(x,\omega)-{\mathcal{F}}(x,\varpi)\right|\leq K\left|\omega-\varpi\right|
for all
(x,\omega),(x,\varpi)\in[a,b]\times\mathds{R}.

Then the boundary value problem (
1
) has a unique solution on
[a,b]

if
b-a<2\sqrt{2/K}.

Ferreira in 2016
[
2

discussed the existence and uniqueness of

Reimman-Liouville fractional derivative:

\left\{\begin{array}[]{ll}{}^{\mathcal{R}}\mathfrak{D}_{a}^{\sigma}u(x)=-{\mathcal{F}}(x,u(x)),&a<x<b,1<\sigma\leq 2,\\
u(a)=0,\text{\ }u(b)=B,&B\in\mathds{R},\end{array}\right.

(2)

so he included this result given by:

Theorem 2
(
[

Let
{\mathcal{F}}:[a,b]\times\mathds{R}\rightarrow\mathds{R}

(H_{1}).
Then the

2

[a,b]
if
b-a<(\sigma^{(\sigma+1)/\sigma}\Gamma^{1/\sigma}(\sigma))/(K^{1/\sigma}(\sigma-1)^{(\sigma-1)/\sigma}).

In 2019, Ferreira
[
3
]
corrected a recent uniqueness result

[
4
]

\left\{\begin{array}[]{ll}{}^{\mathcal{C}}{\mathfrak{D}}_{a}^{\sigma}u(x)=-{\mathcal{F}}(x,u(x)),&a<x<b,1<\sigma\leq 2,\\

(3)

Theorem 3

[

Let
{\mathcal{F}}:[a,b]\times\mathds{R}\rightarrow\mathds{R}

(H_{1}).
Then the

3

[a,b]

M(\sigma,a,b)<1/K,

M(\sigma,a,b)=\frac{1}{\Gamma(\sigma+1)}\underset{x\in[a,b]}{\max}\Big(-2(x-\varphi(x))^{\sigma}+2\frac{(x-a)(b-\varphi(x))^{\sigma}}{b-a}+(x-a)^{\sigma}-(x-a)(b-a)^{\sigma-1}\Big),

Definition 4
(
[

,

]
)

Let
0<a\leq b
and
\sigma\in\mathds{R}^{+}
where
\ n-1<\sigma\leq n

The Hadamard fractional integral of ordre
\sigma
for a function
g
is
defined by:
{}^{\mathcal{H}}{\mathcal{I}}_{a}^{0}g(x)=g(x)
and

{}^{\mathcal{H}}{\mathcal{I}}_{a}^{\sigma}g(x)=\frac{1}{\Gamma(\sigma)}\int_{a}^{x}\left(\ln\frac{x}{\tau}\right)^{\sigma-1}g(\tau)\frac{d\tau}{\tau}\text{\ for }\sigma>0.

(6)

Definition 5
(
[
8
,
9
]
)

Let
0<a<b;

\delta=x\frac{d}{dx}
and let
AC[a,b]
be the space of functions
g
which are absolutely continuous on
[a,b],
and
AC_{\delta}^{n}[a,b]=\{g:[a,b]\times\mathds{R}\rightarrow\mathds{R}

\delta^{n-1}[g(x)]\in AC[a,b]\}.
The Hadamard fractional
derivative of order

for a function
g\in AC_{\delta}^{n}[a,b]

{}^{\mathcal{H}}{\mathfrak{D}}_{a}^{0}g(x)=g(x),

n-1<\sigma\leq n,

Lemma 6
(
[
8
,
9
]

Let
0<a\leq b
, and
\sigma>0

n-1<\sigma\leq n

n\in\mathds{N}

{}^{\mathcal{H}}{\mathfrak{D}}_{a}^{\sigma}u(x)=0

u(x)=\sum_{i=1}^{i=n}c_{i}\left(\ln\frac{x}{a}\right)^{\sigma-i},\;x\in[a,b],

(8)

moreover

{}^{\mathcal{H}}{\mathcal{I}}_{a}^{\sigma}{}^{\mathcal{H}}{\mathfrak{D}}_{a}^{\sigma}u(x)=u(x)+\sum_{i=1}^{i=n}c_{i}\left(\ln\frac{x}{a}\right)^{\sigma-i}.

(9)

Lemma 7

Let
y\in C([a,b],\mathds{R})\cap L^{1}([a,b],\mathds{R})
, the solution of following linear fractional boundary value problem

\left\{\begin{array}[]{ll}{}^{\mathcal{H}}{\mathfrak{D}}_{a}^{\sigma}u(x)=-y(x),&0<a<x<b,1<\sigma\leq 2,\\
u(a)=0,\text{ }u(b)=B,&B\in\mathds{R},\end{array}\right.

(10)

is given by

u(x)=\int_{a}^{b}G(x,\tau)y(\tau)d\tau+B\left(\frac{\ln\frac{x}{a}}{\ln\frac{b}{a}}\right)^{\sigma-1},

where

G(x,\tau)=\frac{1}{\Gamma(\sigma)}\left\{\begin{array}[]{ll}\left(\frac{\ln\frac{x}{a}}{\ln\frac{b}{a}}\right)^{\sigma-1}\left(\ln\frac{b}{\tau}\right)^{\sigma-1}\frac{1}{\tau}-\left(\ln\frac{x}{\tau}\right)^{\sigma-1}\frac{1}{\tau},&a\leq\tau\leq x\leq b,\\
&\\
\left(\frac{\ln\frac{x}{a}}{\ln\frac{b}{a}}\right)^{\sigma-1}\left(\ln\frac{b}{\tau}\right)^{\sigma-1}\frac{1}{\tau},&a\leq x\leq\tau\leq b.\end{array}\right.

(11)

Proof.
Applying the operator
{}^{\mathcal{H}}{\mathcal{I}}_{a}^{\sigma}
on the equation
{}^{\mathcal{H}}{\mathfrak{D}}_{a}^{\sigma}u(x)=-y(x)
, we get

u(x)=-\dfrac{1}{\Gamma(\sigma)}\int_{a}^{x}\left(\ln\frac{x}{\tau}\right)^{\sigma-1}y(\tau)\,\frac{d\tau}{\tau}+c_{1}\left(\ln\frac{x}{a}\right)^{\sigma-1}+c_{2}\left(\ln\frac{x}{a}\right)^{\sigma-2},

(12)

where
c_{1},c_{2}\in\mathds{R}
.

Using the boundary conditions
u(a)=0
and
u(b)=B,
we get
c_{2}=0
and

c_{1}=\dfrac{1}{\Gamma(\sigma)}\left(\ln\frac{b}{a}\right)^{1-\sigma}\int_{a}^{b}\left(\ln\frac{b}{\tau}\right)^{\sigma-1}y(\tau)\frac{d\tau}{\tau}+B\left(\ln\frac{b}{a}\right)^{1-\sigma}.

Substituting the values of
c_{1}
and
c_{2}
in (
12
), we obtain

\displaystyle u(x)

\displaystyle=\frac{1}{\Gamma(\sigma)}\left(\frac{\ln\frac{x}{a}}{\ln\frac{b}{a}}\right)^{\sigma-1}\int_{a}^{b}\left(\ln\frac{b}{\tau}\right)^{\sigma-1}y(\tau)\frac{d\tau}{\tau}-\frac{1}{\Gamma(\sigma)}\int_{a}^{x}\left(\ln\frac{x}{\tau}\right)^{\sigma-1}y(\tau)\frac{d\tau}{\tau}+B\left(\frac{\ln\frac{x}{a}}{\ln\frac{b}{a}}\right)^{\sigma-1}

\displaystyle=\frac{1}{\Gamma(\sigma)}\int_{a}^{x}\left[\left(\frac{\ln\frac{x}{a}}{\ln\frac{b}{a}}\right)^{\sigma-1}\left(\ln\frac{b}{\tau}\right)^{\sigma-1}-\left(\ln\frac{x}{\tau}\right)^{\sigma-1}\right]y(\tau)\frac{d\tau}{\tau}+\frac{1}{\Gamma(\sigma)}\int_{x}^{b}\left(\frac{\ln\frac{x}{a}}{\ln\frac{b}{a}}\right)^{\sigma-1}

\displaystyle\times\left(\ln\frac{b}{\tau}\right)^{\sigma-1}y(\tau)\frac{d\tau}{\tau}+B\left(\frac{\ln\frac{x}{a}}{\ln\frac{b}{a}}\right)^{\sigma-1}

\displaystyle=\int_{a}^{b}G(x,\tau)\;d\tau+B\left(\frac{\ln\frac{x}{a}}{\ln\frac{b}{a}}\right)^{\sigma-1}.

Hence, the proof is completed.

Lemma 8

The Green’s function
G
defined in Lemma
7
has the
following property:

\underset{x\in[a,b]}{\max}\int_{a}^{b}\left|G\left(x,\tau\right)\right|d\tau=\frac{\left(\sigma-1\right)^{\sigma-1}\left(\ln\frac{b}{a}\right)^{\sigma}}{\sigma^{\sigma+1}\Gamma(\sigma)}.

(13)

Proof.
From Lemma 4 of
[
5
]
, we have
G(x,\tau)\geq 0
for all
(x,\tau)\in[a,b]\times[a,b].
Therefore,

\displaystyle\Gamma(\sigma)\int_{a}^{b}|G\left(x,\tau\right)|d\tau

\displaystyle=

\displaystyle\int_{a}^{x}\left[\left(\frac{\ln\frac{x}{a}}{\ln\frac{b}{a}}\right)^{\sigma-1}\left(\ln\frac{b}{\tau}\right)^{\sigma-1}-\left(\ln\frac{x}{\tau}\right)^{\sigma-1}\right]\frac{d\tau}{\tau}

\displaystyle+\int_{x}^{b}\left(\frac{\ln\frac{x}{a}}{\ln\frac{b}{a}}\right)^{\sigma-1}\left(\ln\frac{b}{\tau}\right)^{\sigma-1}\frac{d\tau}{\tau}

\displaystyle=

\displaystyle\left(\frac{\ln\frac{x}{a}}{\ln\frac{b}{a}}\right)^{\sigma-1}\int_{a}^{b}\left(\ln\frac{b}{\tau}\right)^{\sigma-1}\frac{d\tau}{\tau}-\int_{a}^{x}\left(\ln\frac{x}{\tau}\right)^{\sigma-1}\frac{d\tau}{\tau}

\displaystyle=

\displaystyle\frac{1}{\sigma}\left(\ln\frac{b}{a}\right)^{1-\sigma}\left(\ln\frac{x}{a}\right)^{\sigma-1}\left(\ln\frac{b}{a}\right)^{\sigma}-\frac{1}{\sigma}\left(\ln\frac{x}{a}\right)^{\sigma},

which yields

\Gamma(\sigma+1)\int_{a}^{b}G\left(x,\tau\right)d\tau=\left(\ln\frac{b}{a}\right)\left(\ln\frac{x}{a}\right)^{\sigma-1}-\left(\ln\frac{x}{a}\right)^{\sigma}.

(14)

It follows that we need to get the maximum value of the function

g(x)=\left(\ln\frac{b}{a}\right)\left(\ln\frac{x}{a}\right)^{\sigma-1}-\left(\ln\frac{x}{a}\right)^{\sigma},\ \ x\in[a,b].

(15)

Observe that

and

Now we differentiate

from which follows that

It is easily seen that
x^{\ast}\in(a,b).
Because
g(x)
is continuous

x^{\ast}\in(a,b)

\displaystyle\underset{x\in[a,b]}{\max}g(x)

\displaystyle=

\displaystyle g(x^{\ast})

(16)

\displaystyle=

\displaystyle\left(\ln\frac{b}{a}\right)\left(\ln\left(\frac{b}{a}\right)^{\left(\sigma-1\right)/\sigma}\right)^{\sigma-1}-\left(\ln\left(\frac{b}{a}\right)^{\left(\sigma-1\right)/\sigma}\right)^{\sigma}

\displaystyle=

\displaystyle\frac{1}{\sigma-1}\left(\frac{\sigma-1}{\sigma}\ln\frac{b}{a}\right)^{\sigma}

\displaystyle=

\displaystyle\frac{\left(\sigma-1\right)^{\sigma-1}\left(\ln\frac{b}{a}\right)^{\sigma}}{\sigma^{\sigma}}.

By (

Theorem 9

Let
{\mathcal{F}}:[a,b]\times\mathds{R}\rightarrow\mathds{R}
be a continuous function satisfying the assumption
(H_{1}).
If

\frac{b}{a}<\exp\left(\frac{\sigma^{(\sigma+1)/\sigma}\Gamma^{1/\sigma}(\sigma)}{\left(\sigma-1\right)^{(\sigma+1)/\sigma}K^{1/\sigma}}\right).

(17)

Then the Fractional boundary value problem (
4
) has a unique solution
on
[a,b].

Proof.
Let
E=C\left([a,b],\mathds{R}\right)
be the Banach space endowed with the norm
\left\|u\right\|=\sup_{x\in[a,b]}\left|u(x)\right|
(see Proposition 2.18 in
[
16
]
), and we define the
operator
\mathfrak{R}:E\rightarrow E

by

\mathfrak{R}u(x)=\int_{a}^{b}G(x,\tau)u(\tau)d\tau+B\left(\frac{\ln\frac{x}{a}}{\ln\frac{b}{a}}\right)^{\sigma-1},

where the function
G
is given by (
11
).

Notice that the prolem (
4
) has a solution
u
if only if
u
is fixed
point of the operator
\mathfrak{R}
.

For all
(x,u),(x,v)\in[a,b]\times E,
we have

\displaystyle\left|\mathfrak{R}u\left(x\right)-\mathfrak{R}v\left(x\right)\right|

\displaystyle\leq

\displaystyle\int_{a}^{b}G(x,\tau)\left|{\mathcal{F}}(\tau,u(\tau))-{\mathcal{F}}(\tau,v(\tau))\right|d\tau

\displaystyle\leq

\displaystyle\int_{a}^{b}KG(x,\tau)\left|u\left(\tau\right)-v\left(\tau\right)\right|d\tau

\displaystyle\leq

\displaystyle K\int_{a}^{b}G\left(x,\tau\right)d\tau\left\|u-v\right\|,

using the formula (
13
) yields

\left\|\mathfrak{R}u-\mathfrak{R}v\right\|\leq\frac{K\left(\sigma-1\right)^{\sigma-1}\left(\ln\frac{b}{a}\right)^{\sigma}}{\sigma^{\sigma+1}\Gamma(\sigma)}\left\|u-v\right\|.

Can be easily check that the assumption (
17
) leads to principle of
contraction mapping. Hence, the operator
\mathfrak{R}
is contraction
mapping, we conclude that the problem (
4
) has a unique solution.

Theorem 10

If the eigenvalue problem (
5
) has a non-trivial
continuous solution, then

|\lambda|\geq\frac{\sigma^{\sigma+1}\Gamma(\sigma)}{\left(\sigma-1\right)^{\sigma-1}\left(\ln\frac{b}{a}\right)^{\sigma}},

(18)

Proof.
From Lemma
7
, the solution of the problem (
5
) can be written
as follows

u\left(x\right)=\int_{a}^{b}\lambda G\left(x,\tau\right)u\left(\tau\right)d\tau.

which yields

\left\|u\right\|\leq|\lambda|\left\|u\right\|\underset{x\in[a,b]}{\max}\int_{a}^{b}\left|G\left(x,\tau\right)\right|d\tau

Since
u
is non-trivial, then
\left\|u\right\|\neq 0.
So, using
now to the formula of the Green function
G
proved in Lemma
8
, we
get

1\leq|\lambda|\underset{x\in[a,b]}{\max}\int_{a}^{b}\left|G\left(x,\tau\right)\right|d\tau=|\lambda|\frac{\left(\sigma-1\right)^{\sigma-1}\left(\ln\frac{b}{a}\right)^{\sigma}}{\sigma^{\sigma+1}\Gamma(\sigma)},

from which the inequality (
18
) follows. The proof is completed.

We have the following result about the nonexistence for solutions of the

Corollary 11

If

|\lambda|<\frac{\sigma^{\sigma+1}\Gamma(\sigma)}{\left(\sigma-1\right)^{\sigma-1}\left(\ln\frac{b}{a}\right)^{\sigma}},

Then the boundary value problem (

Assume the contrary. Then the boundary value problem (

) has a
non-trivial solution
u.
By Theorem

This contradicts assumption (

Example 12

\left\{\begin{array}[]{l}{}^{\mathcal{H}}{\mathfrak{D}}_{a}^{{3/2}}u(x)=(x-1)^{2}+\sqrt{x-1+u^{2}(x)},\text{ }1<x<e,\\
