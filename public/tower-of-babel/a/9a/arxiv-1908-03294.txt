Characterization and classification of optimal LCD codes
Makoto Araya, Masaaki Harada, Ken Saito

Abstract
Linear complementary dual (LCD) codes are linear codes that intersect with their dual trivially. We give a characterization of LCD codes over 𝔽 q \mathbb{F}_{q} having large minimum weights for q ∈ { 2 , 3 } q\in\{2,3\} . Using the characterization, for arbitrary n n , we determine the largest minimum weights among LCD [ n , k ] [n,k] codes over 𝔽 q \mathbb{F}_{q} , where ( q , k ) ∈ { ( 2 , 4 ) , ( 3 , 2 ) , ( 3 , 3 ) } (q,k)\in\{(2,4),(3,2),(3,3)\} . Moreover, for arbitrary n n , we give a complete classification of optimal LCD [ n , k ] [n,k] codes over 𝔽 q \mathbb{F}_{q} , where ( q , k ) ∈ { ( 2 , 3 ) , ( 2 , 4 ) , ( 3 , 2 ) , ( 3 , 3 ) } (q,k)\in\{(2,3),(2,4),(3,2),(3,3)\} .

2.1
Definitions and notations

We denote the finite field of order
q
by
\mathbb{F}_{q}
, where
q
is a prime power.
A (linear)
[n,k]

code

C
over
\mathbb{F}_{q}
is a
k
-dimensional subspace of
\mathbb{F}_{q}^{n}
.
Codes over
\mathbb{F}_{2}
and
\mathbb{F}_{3}
are called
binary
codes and

ternary
codes, respectively.
The parameters
n
and
k
are called the
length
and the

dimension
of
C
, respectively.
A
generator matrix
of an
[n,k]
code
C
is a
k\times n
matrix whose rows are basis of
C
.
The
support
of a vector
x=(x_{1},x_{2},\ldots,x_{n})\in\mathbb{F}_{q}^{n}
is the subset
\{i\mid x_{i}\neq 0\}
of
\{1,2,\ldots,n\}
.
The
weight
of a vector
x\in\mathbb{F}_{q}^{n}
is the cardinality of the support of
x
.
A vector of
C
is called a
codeword
of
C
.
The minimum nonzero weight of all codewords in
C
is called the
minimum weight

d(C)
of
C
.
An
[n,k]
code with minimum weight
d
is called an
[n,k,d]
code.
Two
[n,k]
codes
C_{1}
and
C_{2}
over
\mathbb{F}_{q}
are
equivalent
,
denoted
C_{1}\cong C_{2}
,
if there is an
n\times n
monomial matrix
P
over
\mathbb{F}_{q}
such that
C_{2}=\{cP\mid c\in C_{1}\}
.

The
dual
code
C^{\perp}
of an
[n,k]
code
C
over
\mathbb{F}_{q}
is defined as
C^{\perp}=\{x\in\mathbb{F}_{q}^{n}\mid x\cdot y=0\text{ for all }y\in C\}
, where
x\cdot y
is the standard inner product.
A code
C
is called
self-orthogonal
if
C\subset C^{\perp}
.
A code
C
is called a
linear complementary dual

(LCD for short)
code if
C\cap C^{\perp}=\{\mathbf{0}_{n}\}
,
where
\mathbf{0}_{n}
denotes the zero vector of length
n
.
The following characterization is due to Massey
[
18
]
.
Throughout this paper, we use the following proposition
without mentioning this,
when we determine whether a given code is LCD or not.

Proposition 2.1
.

Let
G
be a generator matrix of a code
C
over
\mathbb{F}_{q}
.
Then
C
is LCD if and only if
GG^{T}
is nonsingular,
where
G^{T}
denotes the transpose of
G
.

We use the following notations throughout this paper.
Let
\mathbb{Z}_{\geq 0}
denote the set of nonnegative integers.
Let
I_{k}
denote the identity matrix of order
k
,
and let
O
denote the zero matrix of appropriate size.
For a positive integer
s
and a matrix
A
, let
A^{(s)}
denote
the juxtaposition

\begin{pmatrix}&A&A&\cdots&A&\end{pmatrix}

of
s
-copies of
A
.
Let
\mathbf{1}_{n}
denote the all-one vector of length
n
.
For
q
,
n
,
k
and
d
, we use the following notations:

\displaystyle[k]_{q}

\displaystyle=\frac{q^{k}-1}{q-1},

(1)

\displaystyle r_{q,n,k,d}

\displaystyle=q^{k-1}n-[k]_{q}\cdot d,

(2)

\displaystyle g_{q}(n,k)

\displaystyle=\max\left\{d\in\mathbb{Z}_{\geq 0}~\middle|~n\geq\sum_{i=0}^{k-1}\left\lceil\frac{d}{q^{i}}\right\rceil\right\},

(3)

\displaystyle d_{q}(n,k)

\displaystyle=\max\left\{d\in\mathbb{Z}_{\geq 0}\mid\text{ there is an LCD $[n,k,d]$ code over $\mathbb{F}_{q}$}\right\}.

(4)

By the Griesmer bound, any
[n,k]
code over
\mathbb{F}_{q}
has minimum weight at most
g_{q}(n,k)
.
An LCD
[n,k,d_{q}(n,k)]
code over
\mathbb{F}_{q}
is called
optimal
.
The minimum weight of the dual code
C^{\perp}
of a code
C
is called
the
dual distance
of
C
and it is denoted by
d^{\perp}
.
Let
N_{q}(n,k)
denote the number of all inequivalent optimal LCD

[n,k]
codes over
\mathbb{F}_{q}
with dual distances
d^{\perp}\geq 2
.

2.2
Some observations on generator matrices

Lemma 2.2
.

Let
C
and
C^{\prime}
be
[n,k]
codes over
\mathbb{F}_{q}
.
Let
M
and
M^{\prime}
be generator matrices of
C
and
C^{\prime}
, respectively.
If
C\cong C^{\prime}
, then
there is a nonsingular matrix

and there is a monomial
matrix
P
such that
M=UM^{\prime}P
.

Proof.

It is trivial.
∎

Although the following lemma is somewhat trivial,
we give a proof for the sake of completeness.

Lemma 2.3
.

Let
A
be a
k\times\ell

\mathbb{F}_{q}
-matrix.
Let
B
and
B^{\prime}
be
k\times m

\mathbb{F}_{q}
-matrices.
If there is an
(\ell+m)\times(\ell+m)
monomial matrix
P
such that

\begin{pmatrix}&A&B^{\prime}&\end{pmatrix}=\begin{pmatrix}&A&B&\end{pmatrix}P
,
then there is an
m\times m
monomial matrix
P^{*}
such that

B^{\prime}=BP^{*}
.

Proof.

The proof is by induction on
\ell
.
It is sufficient to show the case
\ell=1
.
Let
a
be a vector of
\mathbb{F}_{q}^{k}
.
Suppose that there is an
(m+1)\times(m+1)
monomial matrix
P=(p_{i,j})
such that

\begin{pmatrix}&a^{T}&B^{\prime}&\end{pmatrix}=\begin{pmatrix}&a^{T}&B&\end{pmatrix}P.

(5)

Suppose that
p_{1,1}\neq 0
.
Let
P^{\prime}
be the
m\times m
monomial matrix obtained from
P

by deleting the first row and the first column.
Since
p_{1,j}=0
for each
j\in\{2,3,\ldots,m+1\}
,
we have
B^{\prime}=BP^{\prime}
.

Now suppose that
p_{1,1}=0
.
Then
p_{1,j_{0}}\neq 0
for some
j_{0}\in\{2,3,\ldots,m+1\}
.
From (
5
), the
(j_{0}-1)
-th column of
B^{\prime}
is equal to
p_{1,j_{0}}a^{T}
.
Let
Q=(q_{i,j})
be the
(m+1)\times(m+1)
monomial matrix such that

q_{i,i}=1
for each
i\in\{2,3,\ldots,m+1\}\setminus\{j_{0}\}
, and

(q_{1,j_{0}},q_{j_{0},1})=(p_{1,j_{0}},p_{1,j_{0}}^{-1})
.
Then we have

\begin{pmatrix}&a^{T}&B^{\prime}&\end{pmatrix}Q=\begin{pmatrix}&a^{T}&B^{\prime}&\end{pmatrix}\text{ and }PQ=\begin{pmatrix}1&0&\cdots&0\\
0&&&\\
\vdots&&P^{*}&\\
0&&&\\
\end{pmatrix},

(6)

for some
m\times m
monomial matrix
P^{*}
,
where the blanks are filled up with zero’s.
From (
5
) and (
6
), we have

\displaystyle\begin{pmatrix}&a^{T}&B^{\prime}&\end{pmatrix}=\begin{pmatrix}&a^{T}&B^{\prime}&\end{pmatrix}Q=\begin{pmatrix}&a^{T}&B&\end{pmatrix}PQ=\begin{pmatrix}&a^{T}&BP^{*}&\end{pmatrix}.

Hence, we have
B^{\prime}=BP^{*}
, which gives the desired conclusion.
∎

Throughout this paper,
we remark that the blanks are filled up with zero’s
for each matrix.

3
Basic properties on LCD codes

In this section, we
give some basic results related to LCD codes. In particular, we

3.6

This is a key idea for our characterization of LCD codes with

Throughout this section, we assume that

3.1
Equivalence classes

Let
C
be an LCD
[n,k,d]
code over
\mathbb{F}_{q}
.
Define an
[n+1,k,d]
code
\overline{C}
over
\mathbb{F}_{q}
as

\overline{C}=\{(x,0)\mid x\in C\}
.
It is trivial that
\overline{C}
is an LCD code with dual distance
1
.

Lemma 3.1

(
[
1
, Proposition 3]
)
.

Let
\mathcal{C}^{q}_{n,k,d}
denote all equivalence classes of LCD
[n,k,d]

codes over
\mathbb{F}_{q}
.
Let
\mathcal{D}^{q}_{n,k,d}
denote all equivalence classes of LCD
[n,k,d]

codes over
\mathbb{F}_{q}
with dual distances
d^{\perp}\geq 2
.
Let
\overline{\mathcal{C}^{q}_{n-1,k,d}}
denote
all equivalence classes containing
\overline{C_{1}},\overline{C_{2}},\ldots,\overline{C_{t}}
,
where

C_{1},C_{2},\ldots,C_{t}
denote representatives of

\mathcal{C}^{q}_{n-1,k,d}
, and

t=|\overline{\mathcal{C}^{q}_{n-1,k,d}}|
.
Then

\mathcal{C}^{q}_{n,k,d}=\mathcal{D}^{q}_{n,k,d}\cup\overline{\mathcal{C}^{q}_{n-1,k,d}}
.

For a classification of LCD
[n,k,d]
codes over
\mathbb{F}_{q}
,
by the above lemma, it is sufficient to consider
a classification of LCD
[n,k,d]
codes over
\mathbb{F}_{q}

with dual distances
d^{\perp}\geq 2
.
In addition,
if there is an LCD
[n,k,d]
code
C
over
\mathbb{F}_{q}
and

d_{q}(n-1,k)\leq d-1
, then
d(C^{\perp})\geq 2

(see (
4
) for the notation
d_{q}(n,k)
).

3.2
Relation between LCD codes with
d^{\perp}\geq 2
and
LCD codes with
d^{\perp}=1

Lemma 3.2
.

Suppose that
q\in\{2,3\}
and
k\geq 2
.
If there is an LCD
[n,k,d_{0}]
code over
\mathbb{F}_{q}
with dual
distance
d^{\perp}\geq 2
,
then there is an LCD
[n+1,k,d]
code over
\mathbb{F}_{q}
with

d\in\{d_{0},d_{0}+1\}
and dual distance
d^{\perp}\geq 2
.

Proof.

Suppose that there is an LCD
[n,k,d_{0}]
code
C_{0}
over
\mathbb{F}_{q}
with
dual distance
d(C_{0}^{\perp})\geq 2
.

Suppose that
q=2
.
Recall that a binary code is called
even
if the weights
of all codewords are even and
a binary code which is not even is called
odd
.
If
C_{0}
is odd,
then there is a generator matrix
G_{0}
of
C_{0}

such that
G_{0}G_{0}^{T}=I_{k}

[
8
, Theorem 3]
.
If
C_{0}
is even,
then
k
is even and there is a generator matrix
G^{\prime}_{0}
of
C_{0}
such that

G^{\prime}_{0}{G^{\prime}_{0}}^{T}=\begin{pmatrix}J_{2}&&\\
&\ddots&\\
&&J_{2}\end{pmatrix},

where

J_{2}=\begin{pmatrix}0&1\\
1&0\end{pmatrix}

[
8
, Theorem 5]
.

Suppose that
q=3
.
From the proof of
[
13
, Proposition 4]
,

C_{0}
has generator matrix of form

G_{0}=\left(\begin{array}[]{ccc}&x&\\
&G_{1}&\\
\end{array}\right)
,
satisfying that

and
xG_{1}^{T}=\mathbf{0}_{k-1}
.
The code

with generator matrix

is a ternary LCD
[n,k-1]
code.

•

k=2
:

G_{1}
is regarded as a codeword

with

,
since

is LCD.

•

k\geq 3
: Since

is LCD,

C_{1}
has generator matrix of form

G^{\prime}_{1}=\left(\begin{array}[]{ccc}&x^{\prime}&\\
&G_{2}^{\prime}&\\
\end{array}\right)
,
satisfying that

x^{\prime}\cdot x^{\prime}\neq 0

x^{\prime}{G_{2}^{\prime}}^{T}=\mathbf{0}_{k-2}
.
Since both matrices

and

G^{\prime}_{0}=\left(\begin{array}[]{ccc}&x&\\
&G^{\prime}_{1}&\\
\end{array}\right)=\left(\begin{array}[]{ccc}&x&\\
&x^{\prime}&\\
&G^{\prime}_{2}&\\
\end{array}\right)

.
Since

and

.

Finally, consider the following
k\times(n+1)

\mathbb{F}_{q}
-matrix

G=\begin{cases}\begin{pmatrix}&G_{0}&h_{2}^{T}&\end{pmatrix}&\text{if }q=2\text{ and }C_{0}\text{ is odd},\\
\begin{pmatrix}&G^{\prime}_{0}&h_{2}^{T}&\end{pmatrix}&\text{if }q=2\text{ and }C_{0}\text{ is even},\\

\begin{pmatrix}&G^{\prime}_{0}&h_{3}^{T}&\end{pmatrix}&\text{if }q=3\text{ and }k\geq 3,\\
\end{cases}

\displaystyle h_{2}

\displaystyle=\begin{cases}(1,1)&\text{if }k=2,\\
(1,1,\mathbf{0}_{k-2})&\text{if }k\geq 3,\\
\end{cases}

\displaystyle h_{3}

\displaystyle=\begin{cases}(1,0)&\text{if }k=2\text{ and }x\cdot x=1,\\
(0,1)&\text{if }k=2,x\cdot x=2\text{ and }x^{*}\cdot x^{*}=1,\\
(1,1)&\text{if }k=2\text{ and }x\cdot x=x^{*}\cdot x^{*}=2,\\

(1,1,\mathbf{0}_{k-2})&\text{if }k\geq 3\text{ and }x\cdot x=x^{\prime}\cdot x^{\prime}=2.\end{cases}

It is not difficult to show that

is nonsingular.
Hence, the code with generator matrix

is an LCD
[n+1,k,d]

\mathbb{F}_{q}
with

d\in\{d_{0},d_{0}+1\}
and dual distance

.

Suppose that

[n,k,d]

[n,k,d]

Suppose that there is an LCD
[n,k,d]
code

over
\mathbb{F}_{q}
with

and dual distance

By deleting all zero columns of a generator matrix of

[n-\ell,k,d]

\mathbb{F}_{q}
with dual distance

Then an LCD
[n,k,d]
code over
\mathbb{F}_{q}

with
d\geq d_{0}
and dual distance

by Lemma

Let

.
For any
[n,k]

[n,k,g_{q}(n,k)]

\mathbb{F}_{q}
.

Lemma 3.5
.

Suppose that
(q,k_{0})\in\{(2,3),(3,2)\}
,

,

[\sum_{i=1}^{[k]_{q}}m_{i},k,d_{0}]

.

The code

with generator matrix

is a self-orthogonal
[[k]_{q}\cdot s,k,q^{k-1}s]

From the assumption,

is an LCD

[\sum_{i=1}^{[k]_{q}}m_{i},k,d_{0}]

∎

Now we give definitions concerning symmetric designs.
A

(v,\ell,\lambda)

-th block

(v,\ell,\lambda)

.

.
For undefined terms concerning designs, see e.g.
[

]
.

Suppose that there is a symmetric

-
(v,\ell,\lambda)

be the incidence matrix of

.

-matrix

\frac{\ell d-\lambda\sum_{j=1}^{v}m_{j}}{\ell-\lambda}\leq m_{i}\leq\sum_{j=1}^{v}m_{j}-\frac{v-\ell}{\ell-\lambda}d,

Suppose that

4.1
Theorem
4.5
and its proof

Lemma 4.1
.

Suppose that
(q,k_{0})\in\{(2,3),(3,2)\}
,

k\geq k_{0}
and
qd-(q-1)n\geq 1
.
Let

denote the integer defined in (
2

(i)

If

then there is no LCD
[n,k,d]
code over
\mathbb{F}_{q}

with dual distance
d^{\perp}\geq 2

(ii)

If there is an LCD
[n,k,d]

C
over
\mathbb{F}_{q}
with

then there is an LCD
[n,k,d]
code
C^{\prime}
such that

has generator matrix of the following form:

(10)

where

G_{0}
is a generator matrix of some LCD

[q\cdot r_{q,n,k,d},k,(q-1)r_{q,n,k,d}]

Proof.

Since
C
is an
[n,k]
code over
\mathbb{F}_{q}

with dual distance

there is a vector
m=(m_{1},m_{2},\ldots,m_{[k]_{q}})\in\mathbb{Z}_{\geq 0}^{[k]_{q}}

n=\sum_{i=1}^{[k]_{q}}m_{i}

Since the minimum weight of

Since the generator matrix

of

for each

of form (

(11)

This proves the assertion (i).

is an LCD code of dimension

with generator matrix

,

This completes the proof.
∎

.

Let

and

be the codes described as above.

Since

and

\displaystyle\left(\begin{array}[]{cccc}&S_{q,k}^{(qd-(q-1)n)}&G_{0}&\end{array}\right)

\displaystyle=\left(\begin{array}[]{cccc}&(US_{q,k}Q)^{(qd-(q-1)n)}&UG^{\prime}_{0}P&\end{array}\right)

&\ddots&&\\
\ &&Q&\\
&&&P\end{pmatrix}.

Suppose that
