On the Origins of Objects by Means of Careful Selection CCS: Object-Oriented Programming
Yegor Bugayenko

Abstract
. We introduce a taxonomy of objects for EO programming language. This taxonomy is designed with a few principles in mind: non-redundancy, simplicity, and so on. The taxonomy is supposed to be used as a navigation map by EO programmers. It may also be helpful as a guideline for designers of other object-oriented languages or libraries for them.

2.
Principles

We adhere to a few principles:

(1)

We tend to minimize the global scope, keeping the number of global objects to the absolute possible minimum.

(2)

Wherever possible, objects must be implemented in EO, instead of being atoms.

(3)

There should be no functionality implemented two or more times in the entire taxonomy.

(4)

Object names must not be abbreviated and must constitute an English sentence when being used through dot notation, for example:

means “
x
times
y
is
z
.”
There are a few exceptions though, like
eq
,
seq
,
lt
, and a few others.

In case of any runtime error, an object is supposed to “return” an error
object, with the
message
attribute present (attached to any object) and
the
@
attribute absent.

3.
Bytes

The center of the taxonomy is the
bytes
data object, which is an abstraction
of a sequence of bytes. The sequence can either be empty or contain a
theoretically unlimited number of bytes. A byte is a unit of information that
consists of eight adjacent binary digits (bits), each of which consists of a
0

or
1
. In
EO
syntax, a sequence of bytes is denoted as either
--

(double dash) for an empty one or as a concatenation of
xx-
, where

xx
is a hexadecimal representation of a byte. For example, the
2A-
is
a one-byte sequence, where the only byte equals to the number 42.

The

object has these four attributes, to turn itself into
one of four primitive data objects:

\star
as-int

\star
as-bool
,

\star

\star
as-string

The attribute
\star
as-int
expects the size of the sequence to be eight bytes.
The attribute
\star
as-bool
expects exactly one byte in the sequence and is

FALSE

The attribute
\star
as-float
expects exactly eight bytes.

There are also attributes for bitwise operations:

\star
and

\star
or

\star

\star

\star

\star

The object also has the
\star

itself with another sequence of bytes.

The
\star

The
\star
slice
attribute represents a sub-sequence inside the current one.

The
\star
concat
attribute is a new sequence, which is a concatenation
of two byte sequences: the current and the provided one.
