Abstract
In this article the time evolution operator of two interacting quantum oscillators, whose Hamiltonian is an element of the complex { h ( 1 ) ⊕ h ( 1 ) } 3 \roundcap u ( 2 ) \left\{h(1)\oplus h(1)\right\}\mathbin{\mathchoice{\makebox[9.44443pt]{\raisebox{-0.83333pt}{\begin{picture}\displaystyle\displaystyle 3 \roundcap\put(0.5,0.5){\pic@makebox@{\makebox}{}(0.0,0.0){\raisebox{0.83333pt}{$\displaystyle+$}}} \put(0.5,0.5){\arc[-90,90]{0.5}} \end{picture}}}}{\makebox[9.44443pt]{\raisebox{-0.83333pt}{\begin{picture}\textstyle\displaystyle 3 \roundcap\put(0.5,0.5){\pic@makebox@{\makebox}{}(0.0,0.0){\raisebox{0.83333pt}{$\textstyle+$}}} \put(0.5,0.5){\arc[-90,90]{0.5}} \end{picture}}}}{\makebox[7.80554pt]{\raisebox{-0.83334pt}{\begin{picture}\scriptstyle\displaystyle 3 \roundcap\put(0.5,0.5){\pic@makebox@{\makebox}{}(0.0,0.0){\raisebox{0.83334pt}{$\scriptstyle+$}}} \put(0.5,0.5){\arc[-90,90]{0.5}} \end{picture}}}}{\makebox[6.8056pt]{\raisebox{-0.83336pt}{\begin{picture}\scriptscriptstyle\displaystyle 3 \roundcap\put(0.5,0.5){\pic@makebox@{\makebox}{}(0.0,0.0){\raisebox{0.83336pt}{$\scriptscriptstyle+$}}} \put(0.5,0.5){\arc[-90,90]{0.5}} \end{picture}}}}}u(2) algebra, is analyzed using the Feynman time ordering operator techniques. This method is consistently used to generate the conditions and to formally find explicit disentangled expressions for such operator. In this way, it is shown that all the problem reduces to solve a complex Riccati-type differential equation. Some closed solutions to this differential equation are found and then concrete disentangling expressions for the time-ordered evolution operator are given. Finally, the time evolution of the coherent states linked to the isotropic 2D quantum oscillator are analyzed under alternative time-independent an time-dependent Hamiltonian systems.

2
Unitary time evolution operator

In quantum mechanics, the connection between theory and experiment is given by the expectation values of the dynamical variables. For a system represented by the Hamiltonian
\hat{H}(t),
if
\hat{\Lambda}
denotes a dynamical variable, its expectation value is given by

\langle\Lambda\rangle(t)=\langle\Psi(t)\mid\hat{\Lambda}\mid\Psi(t)\rangle,

(2.1)

where the state
\mid\Psi(t)\rangle
is determined by the Schrödinger equation

i\hbar\frac{d}{dt}\mid\Psi(t)\rangle=\hat{H}(t)\mid\Psi(t)\rangle

(2.2)

and the initial condition, when
t=t_{0},

\mid|\psi(t_{0})\rangle.

The solution of (
2.2
) can be written in the form

\mid\Psi(t)\rangle=\hat{U}(t,t_{0})\mid\Psi(t_{0})\rangle,

(2.3)

where
\hat{U}(t,t_{0})
is the time-ordered unitary operator of the system which verifies the differential equation

i\hbar\frac{d}{dt}\hat{U}(t,t_{0})=\hat{H}\hat{U}(t,t_{0}),

(2.4)

with the initial condition
\hat{U}(t_{0},t_{0})=\hat{I}.

The solution of (
2.4
) can be formally written as

\hat{U}(t,t_{0})=e^{-\;\frac{i}{\hbar}\intop\nolimits_{t_{0}}^{t}\left[\hat{H}(s)\right]_{+}ds},

(2.5)

where the subscript
+
in the integral factor indicates that, when expanding the exponential operator, the order of action of the Hamiltonian
\hat{H}(t)
on the states depends on the value of the parameter
s,
that is, the Hamiltonian evaluated at an earlier time acts first than a Hamiltonian evaluated at a later time.
There are several important properties this operator verifies, among them we have

\hat{U}(t,0)=\hat{U}(t,t_{0})\hat{U}(t_{0},0),\quad{\rm which\;is\;equivalent\;to}\quad\hat{U}(t,t_{0})=\hat{U}(t,0)\hat{U}^{-1}(t_{0},0),

(2.6)

where
t\geq t_{0}\geq 0.

2.1
Feynman’s disentangling rule and unitary transformations

In this section we use the Feynman’s disentangling rule to factorize a the time-ordered unitary operator in terms of exponential factors. To do that, let us start with any generic time-ordered operator of the form

\hat{V}(t,t_{0})=e^{-\frac{i}{\hbar}\intop\nolimits_{t_{0}}^{t}\left[\hat{W}(s)\right]_{+}ds}.

(2.7)

Let us now rewrite this operator in the form

\hat{V}(t,t_{0})=e^{-\frac{i}{\hbar}\intop\nolimits_{t_{0}}^{t}\left[\hat{W}(s)-i\hbar\hat{\gamma}(s)+i\hbar\gamma(s)\right]_{+}ds},

(2.8)

where we only have added to
\hat{W}(s)
the null operator
i\hat{\gamma}(s)-i\hat{\gamma}(s).

Now, applying the Feynman’s disentangling rule to this last operator we get

\hat{V}(t,t_{0})=\hat{S}_{t}e^{-\frac{i}{\hbar}\intop\nolimits_{t_{0}}^{t}\left[\hat{S}^{-1}_{s}\left(\hat{W}(s)-i\hbar\gamma(s)\right)\hat{S}_{s}\right]_{+}ds}\;\hat{S}^{-1}_{t_{0}},

(2.9)

where the
\hat{S}_{s}
operator verifies

\frac{d\hat{S}_{s}}{ds}=\hat{\gamma}(s)\hat{S}_{s},

(2.10)

i.e.,
\hat{S}_{s}
is the time-ordered operator

\hat{S}_{s}=e^{\intop\nolimits_{t_{0}}^{s}[\hat{\gamma}(\tau)]_{+}d\tau}\;\hat{S}_{t_{0}}

(2.11)

Finally, by combining equations (
2.9
) and (
2.10
), we obtain

\hat{V}(t,t_{0})=\hat{S}_{t}e^{-\frac{i}{\hbar}\intop\nolimits_{t_{0}}^{t}\left[\hat{S}^{-1}_{s}\hat{W}(s)\hat{S}_{s}+i\hbar\left(\frac{d}{ds}\hat{S}^{-1}_{s}\right)\hat{S}_{s}\ \right]_{+}ds}\;\hat{S}_{t_{0}}.

(2.12)

We note that if
i\hat{\gamma}_{s}
is Hermitian then
\hat{S}_{s}
is unitary, that is,
{\hat{S}}_{s}^{-1}={\hat{S}}_{s}^{\dagger}.
The expressions (
2.9
) and (
2.12
) are certainly equivalent, but while the former is more useful for practical purposes, to generate conditions under which a determined exponential operator can be factorized, for example, the latter is more indicated at the moment of analyzing the general structure of the quantum system we are studying.

3.1
Disentangling with the help of a unitary displacement operator

In this section we factorize the two mode time evolution operator with the help of a unitary displacement operator. In accordance with equation (
2.6
) we only need to compute
\hat{U}(t,0).
Thus, by using the Feynman disentangling rules, we can write this time evolution operator in the form

\displaystyle\hat{U}(t,0)

\displaystyle=

\displaystyle\hat{S}(t)\exp\left[-\;\frac{i}{\hbar}\;\intop\nolimits_{0}^{t}\hat{S}^{-1}(s)\left[\sumop\displaylimits_{\sigma,\lambda=1}^{2}\hbar w_{\sigma\lambda}(s)\;\hat{a}^{\dagger}_{\sigma}\hat{a}_{\lambda}\right.\right.

(3.4)

\displaystyle+

\displaystyle\left.\left.\sumop\displaylimits_{\sigma=1}^{2}\;[(F_{\sigma}(s)-i\hbar\gamma_{\sigma}(s))\;\hat{a}^{\dagger}_{\sigma}+(F^{\ast}_{\sigma}(s)+i\hbar\gamma^{\ast}_{\sigma}(s))\;\hat{a}_{\sigma}]+\beta(s)\right]\hat{S}(s)ds\right]_{+},

where

\hat{S}(s)=\exp{\intop\nolimits_{0}^{s}\sumop\displaylimits_{\sigma=1}^{2}[\gamma_{\sigma}(\tau)\hat{a}^{\dagger}_{\sigma}-\gamma^{\ast}_{\sigma}(\tau)\hat{a}_{\sigma}]_{+}d\tau},

(3.5)

with the choice
\hat{S}(0)=\hat{I}.

The unitary displacement operator
\hat{S}(s)
is by itself an exponential operator that need to be disentangled for operating on the states or for combining with the other operators. Then, its disentangled form can be reached by using again the Feyman factorization rules:

\hat{S}(s)=\hat{V}(s)\exp{\left[-\intop\nolimits_{0}^{s}\sumop\displaylimits_{\sigma=1}^{2}\hat{V}^{-1}(\tau)\gamma^{\ast}_{\sigma}(\tau)\hat{a}_{\sigma}\hat{V}(\tau)d\tau\right]}

(3.6)

where

\hat{V}(\tau)=\exp{\left[\intop\nolimits_{0}^{\tau}\sumop\displaylimits_{\sigma=1}^{2}[\gamma_{\sigma}(\nu)\hat{a}^{\dagger}_{\sigma}d\nu\right]},

(3.7)

with the choice
\hat{V}(0)=\hat{I}.
We note that according to the commutation relations (
3.2
), no subscript
+
is needed in (
3.6
) and (
3.7
). Indeed,

\hat{V}(\tau)=\exp{\left[\sumop\displaylimits_{\sigma=1}^{2}c_{\sigma}(\tau)\hat{a}^{\dagger}_{\sigma}\right]},

(3.8)

where
c_{\sigma}(\tau)=\intop\nolimits_{0}^{\tau}\gamma_{\sigma}(\nu)d\nu,
or
\frac{d}{d\tau}c_{\sigma}(\tau)=\gamma_{\sigma}(\tau).
Thus, by inserting (

e^{-c_{\mu}(\tau)\hat{a}^{\dagger}}\hat{a}_{\sigma}e^{c_{\mu}(\tau)\hat{a}^{\dagger}}=\hat{a}_{\sigma}+c_{\sigma}(\tau)\delta_{\sigma\mu},
we get

\hat{S}(s)=\exp{\left[\sumop\displaylimits_{\sigma=1}^{2}c_{\sigma}(s)\hat{a}^{\dagger}_{\sigma}\right]}\exp{\left[-\sumop\displaylimits_{\sigma=1}^{2}c^{\ast}_{\sigma}(s)\hat{a}_{\sigma}-\sumop\displaylimits_{\sigma=1}^{2}\intop\nolimits_{0}^{s}\gamma^{\ast}_{\sigma}(\tau)c_{\sigma}(\tau)d\tau\right]},

(3.9)

which after some manipulation becomes

\hat{S}(s)=\exp\left[\sumop\displaylimits_{\sigma=1}^{2}[c_{\sigma}(s)\hat{a}^{\dagger}_{\sigma}-c^{\ast}_{\sigma}(s)\hat{a}_{\sigma}]\right]\exp\left[\frac{1}{2}\sumop\displaylimits_{\sigma=1}^{2}\intop\nolimits_{0}^{s}[\gamma_{\sigma}(\tau)c^{\ast}_{\sigma}(\tau)-\gamma^{\ast}_{\sigma}(\tau)c_{\sigma}(\tau)]d\tau\right].

\displaystyle\hat{U}(t,0)

\displaystyle=

\displaystyle\exp\left[\sumop\displaylimits_{\sigma=1}^{2}[c_{\sigma}(s)\hat{a}^{\dagger}_{\sigma}-c^{\ast}_{\sigma}(s)\hat{a}_{\sigma}]\right]

\displaystyle\times

In this article, we write the two-modes creation and annihilation operators in the following simplified form:
\hat{a}_{1}\equiv\hat{a}_{1}\otimes\hat{I}_{2},

\hat{a}_{2}\equiv\hat{I}_{1}\otimes\hat{a}_{2},

\hat{a}_{1}^{\dagger}\equiv\hat{a}_{1}^{\dagger}\otimes\hat{I}_{2}
and
\hat{a}_{2}^{\dagger}\equiv\hat{I}_{1}\otimes\hat{a}_{2}^{\dagger},
then, par example,
\hat{a}_{1}^{\dagger}\hat{a}_{2}=(\hat{a}_{1}^{\dagger}\otimes\hat{I}_{2})(\hat{I}_{1}\otimes\hat{a}_{2})=\hat{a}_{1}^{\dagger}\otimes\hat{a}_{2}.
Sometimes, we will also write

for example.

\hat{J}_{+}=\hat{a}_{1}^{\dagger}\hat{a}_{2},\quad\hat{J}_{-}=\hat{a}_{1}\hat{a}_{2}^{\dagger},\quad\hat{J}_{3}=\frac{1}{2}(\hat{a}_{1}^{\dagger}\hat{a}_{1}-\hat{a}_{2}^{\dagger}\hat{a}_{2}),

(3.14)

which verify the commutation relations

[\hat{J}_{3},\hat{J}_{\pm}]=\pm\;\hat{J}_{\pm},\quad[\hat{J}_{+},\hat{J}_{-}]=2\hat{J}_{3},

(3.15)

\hat{N}=\frac{1}{2}(\hat{a}_{1}^{\dagger}\hat{a}_{1}+\hat{a}_{2}^{\dagger}\hat{a}_{2}),

(3.16)

which commutes with all them.
Thus the unitary operator assumes the form

\hat{U}_{0}(t,0)=\exp\left[-\;i\;\intop\nolimits_{0}^{t}\left[\frac{d\alpha(s)}{ds}\hat{N}+\frac{d\rho(s)}{ds}\hat{J}_{3}+w_{12}(s)\hat{J}_{+}+w_{21}(s)\hat{J}_{-}\right]_{+}ds\right]

At this stage, to untangle (

All these choices are completely equivalent with respect to the complexity of the differential equations that we finally have to solve to obtain the final untangled form of the unitary time evolution operator. In fact, once such a unitary operator has been completely untangled following a determined choice, we can move from one to another simply by using appropriate similarity transformations formed from the untangled exponential factors.

3.2.1
A simple and direct choice of disentangling

For example, we could start by isolating an exponential factor raised to a factor proportional to
\hat{N},
followed by another exponential factor raised to a factor proportional to
\hat{J}_{3},
to finally disentangle the remaining exponential factor raised to a given linear combination of the ladder operators
\hat{J}_{\pm}.
As
\hat{N}

\hat{U}_{0}(t,0)=e^{-i\alpha(t)\hat{N}}\;e^{-i\rho(t)\hat{J}_{3}}\exp\left[\;\intop\nolimits_{0}^{t}\left[\eta(s)\hat{J}_{+}-\eta^{\ast}(s)\hat{J}_{-}\right]_{+}ds\right],

(3.18)

where
\alpha(s)=\intop\nolimits_{0}^{s}[w_{11}(s)+w_{22}(s)]ds,

\rho(s)=\intop\nolimits_{0}^{s}[w_{11}(s)-w_{22}(s)]ds
and
\eta(s)=-iw_{12}(s)e^{i\rho(s)}.

The disentangling of the last factor

\hat{T}(t)=\exp\left[\intop\nolimits_{0}^{t}\left[\eta(s)\hat{J}_{+}-\eta^{\ast}(s)\hat{J}_{-}\right]_{+}ds\right],

(3.19)

is not always possible, it depend on the form of the functions
w_{12}(s)=w^{\ast}_{21}(s)
and of the real functions

w_{11}(s)
and
w_{22}(s).
Indeed, a first factorization in terms of exponential operators is

\hat{T}(t)=e^{\Lambda(t)\hat{J}_{+}}\exp\left[\intop\nolimits_{0}^{t}e^{-\Lambda(s)\hat{J}_{+}}\left[(\eta(s)-\lambda(s))\hat{J}_{+}-\eta^{\ast}(s)\hat{J}_{-}\right]e^{\Lambda(s)J_{+}}ds\right],

(3.20)

where
\Lambda(s)=\intop\nolimits_{0}^{s}\lambda(\tau)d\tau
or
\lambda(s)=\frac{d\Lambda(s)}{ds}.
By using in (
3.20
) the relation
e^{-\Lambda(s)\hat{J}_{+}}\;\hat{J}_{-}\;e^{\Lambda(s)\hat{J}_{+}}=\hat{J}_{-}-2\Lambda(s)\hat{J}_{3}-(\Lambda(s))^{2}\hat{J}_{+}
and making a suitable regrouping of the terms we get

\hat{T}(t)=e^{\Lambda(t)\hat{J}_{+}}\exp\left\{\intop\nolimits_{0}^{t}\left[[\eta(s)-\lambda(s)+\eta^{\ast}(s)(\Lambda(s))^{2}]\hat{J}_{+}-\eta^{\ast}(s)[\hat{J}_{-}-2\Lambda(s)\hat{J}_{3}]\right]_{+}ds\right\}.

(3.21)

By forcing the coefficient of
\hat{J}_{+}
in the second exponential factor to be null, we get

\hat{T}(t)=e^{\Lambda(t)\hat{J}_{+}}\exp\left\{-\intop\nolimits_{0}^{t}\;\eta^{\ast}(s)\;\left[\hat{J}_{-}-2\Lambda(s)\hat{J}_{3}]\right]_{+}ds\right\}.

(3.22)

with the condition

\frac{d\Lambda(s)}{ds}-\eta(s)-\eta^{\ast}(s)(\Lambda(s))^{2}=0,\quad\Lambda(0)=0,

(3.23)

which a differential equation of the Riccati type.

Finally, by performing the disentangling of the remaining exponential terms we get

\hat{T}(t)=e^{\Lambda(t)\hat{J}_{+}}e^{\Omega(t)\hat{J}_{3}}e^{\Gamma(t)\hat{J}_{-}},

(3.24)

where

\Omega(t)=2\intop\nolimits_{0}^{t}\eta^{\ast}(s)\Lambda(s)\;ds\quad\text{ and}\quad\Gamma(t)=-\intop\nolimits_{0}^{t}\eta^{\ast}(s)e^{\Omega(s)}ds.

(3.25)

4
A closed solution of the complex Riccati type equation

It is clear if we were able to solve equation (
3.23
) for any arbitrary value of the time dependent functions
w_{\sigma\lambda}(s)
we would have succeed in our task, but a closed solution of this differential is not always possible. For a formal discussion about it see
[
13
]
–
[
14
]
, and references therein, for example. Here we will generate some closed solutions of this equation by appealing to some structural criteria of the operator algebra.

4.1
Standard
su(2)
type structure

A first good criterion to consider is the unitary character the operator
\hat{T}
and its counterbalanced exponential structure in terms of the
su(2)
generators. Then, similarly to the case when all coefficients are time-independent constants, we can choose
\Omega(t)
to be real at any time, which implies that, as we will see in the following development,
\Gamma(t)=-\Lambda^{\ast}(t).

A sufficient condition for
\Omega(t)
to be real is

\eta^{\ast}(s)\Lambda(s)=\eta(s)\Lambda^{\ast}(s).

(4.1)

Taking into account this condition in equation (
3.23
) we get

\frac{d\Lambda(s)}{ds}=\eta(s)(1+\|\Lambda(s)\|^{2}).

(4.2)

Now, if in this last equation we use the polar forms
\Lambda(s)=R(s)e^{i\theta(s)}
and
\eta(s)=\|\eta(s)\|e^{i\phi(s)}
, where
R(s),\theta(s)
and
\phi(s)
are real functions, and we separate it into its real and imaginary parts, we get

\frac{dR(s)}{ds}=(-1)^{k}\;\|\eta(s)\|(1+R^{2}(s)),\quad k=0,\pm 1,\cdots,\quad

(4.3)

and the condition
\theta(s)=\theta_{0},\forall s
and
\phi(s)=\phi_{0}=\theta_{0}-k\pi,\;k=0,\pm 1,\cdots,\;\forall s,
where
\phi_{0}
and
\theta_{0}
are real constants.
Thus by integrating equation (
4.3
) we obtain

R(s)=(-1)^{k}\;\tan[\intop\nolimits_{0}^{s}\|\eta(\tau)\|d\tau],\quad k=0,\pm 1,\cdots.

(4.4)

Finally, taking into account all these results, we find a solution of equation (
3.23
), that is,

\Lambda(s)=\tan[\intop\nolimits_{0}^{s}\|\eta(\tau)\|d\tau]\;e^{i\phi_{0}},

(4.5)

provided that

\eta(s)=\|\eta(s)\|\;e^{i\phi_{0}}.

(4.6)

Hence, the
\Omega(t)
function writes

\Omega(t)=2\intop\nolimits_{0}^{t}\|\eta(s)\|\tan[\intop\nolimits_{0}^{\tau}\|\eta(\tau)\|\;d\tau]ds=2\ln\left(\sec[\intop\nolimits_{0}^{s}\|\eta(\tau)\|d\tau]\right)

(4.7)

and the
\Gamma(t)

\Gamma(t)=-\intop\nolimits_{0}^{t}\|\eta(s)\|e^{-i\phi_{0}}\sec^{2}[\intop\nolimits_{0}^{t}\|\eta(\tau)\|d\tau]ds=-\;e^{-i\phi_{0}}\tan[\intop\nolimits_{0}^{t}\|\eta(s)\|\;ds]=-\Lambda^{\ast}(t).

(4.8)

Then, if condition (
4.1
) is met, the disentangled structure of the unitary operator (
3.19

\hat{T}(t,0)=e^{\tan[\intop\nolimits_{0}^{t}\|w_{12}(\tau)\|d\tau]\;e^{i\phi_{0}}\;\hat{J}_{+}}e^{2\ln\left(\sec[\intop\nolimits_{0}^{t}\|w_{12}(\tau)\|d\tau]\right)\hat{J}_{3}}e^{-\tan[\intop\nolimits_{0}^{t}\|w_{12}(\tau)\|d\tau]\;e^{-i\phi_{0}}\hat{J}_{-}},

(4.9)

where we have used
\|\eta(\tau)\|=\|w_{12}(\tau)\|,\;\forall\;\tau,

\eta(\tau)=-iw_{12}(\tau)e^{i\intop\nolimits_{0}^{\tau}(w_{11}(s)-w_{22}(s))ds}.

It is easy now to rewrite this last operator in the usual form

(4.10)

Thus the completely disentangled form of (

\displaystyle=

We have proven that the complete disentangling of that time evolution operator depends exclusively on our capacity to solve a standard Riccati-type equation with time dependent coefficients, which are related directly with the time-dependent frequencies, or set of coefficients, of the

All that because we know that not always is possible to have a closed solution for such non-linear differential equation. Nevertheless, we have found some relations among the frequencies that allow us to solve that differential equation and disentangle completely the unitary time evolution operator. By the way, these relations are not the only ones that work. Here, in section

Another important fact we have illustrated in this article is that once that the disentangling of the

That because it have been shown that the differential equation system, which serve to untangle the exponential factor containing the linear terms in the unitary time evolution operator, can be expressed as a time ordered operator equation. It is in this sense that we say that the Feynman disentanglement method is self-consistent in dealing with this problem.

By way of example, we have computed the time evolution of a class of coherent states linked to the 2 D isotropic harmonic oscillator as well as to a class of coherent states linked to a system of two time-dependent
u(2)

Appendix A
Solving a differential equation system by using the concept of time ordering operator

The untangled closed form of the general time evolution operator of the system we are dealing with will not be possible until the solution of the differential equation system (
3.12
) is available. I have been shown in the literature, see
[
11
]
, that (
3.12
) can be solved for any number of interacting oscillators using the concept of time ordering operator. Indeed, let us consider a complete orthonormal set of states
\left\{\mid\psi_{\sigma}\rangle\right\}
where the functions
c_{\sigma}(t),

w_{\sigma\lambda}(t)
and
F_{\sigma}(t)
be represented by

c_{\sigma}(t)=\langle\psi_{\sigma}\mid\chi(t)\rangle,\quad w_{\sigma\lambda}(t)=\langle\psi_{\sigma}\mid\hat{W(t)}(t)\mid\psi_{\lambda}\rangle,\quad{\rm and}\quad F_{\sigma}(t)=\langle\psi_{\sigma}\mid F(t)\rangle,

(A.1)

where
\hat{W}
is an appropriate operator acting on these basis states. Then, with these definitions (
3.12
) assumes the form

i\hbar\frac{d}{dt}\mid\chi(t)\rangle-\hbar\hat{W}(t)\mid\chi(t)\rangle-\mid F(t)\rangle=0.

(A.2)

The associated homogeneous associated equation of this latter is given by

i\frac{d}{dt}\mid\Phi(t)\rangle=\hat{W}(t)\mid\Phi(t)\rangle,

(A.3)

which is a equation of the Schrödinger type, whose solution can be found using the time ordering technique, that is

\mid\Phi(t)\rangle=\hat{S}(t,t_{0})\mid\Phi(t_{0})\rangle,

(A.4)

where

\hat{S}(t,t_{0})=e^{-i\intop\nolimits_{t_{0}}^{t}\left[\hat{W}(s)\right]_{+}ds}.

(A.5)

Now, if we try in (
A.2
) a particular solution
\mid\chi_{p}(t)\rangle
of the type

\mid\chi_{p}(t)\rangle=\hat{S}(t,t_{0})\mid Z(t)\rangle,

(A.6)

and then we perform some reductions to the resulting expressions, we get

i\hbar\frac{d}{dt}\mid Z(t)\rangle=\hat{S}^{\dagger}(t,t_{0})\mid F(t)\rangle,

(A.7)

from where

\mid Z(t)\rangle=-\frac{i}{\hbar}\intop\nolimits_{t_{0}}^{t}\hat{S}^{\dagger}(s,t_{0})\mid F(s)\rangle ds,

(A.8)

and by consequence

\mid\chi_{p}(t)\rangle=-\frac{i}{\hbar}\hat{S}(t,t_{0})\;\intop\nolimits_{t_{0}}^{t}\hat{S}^{\dagger}(s,t_{0})\mid F(s)\rangle ds.

(A.9)

In this way we obtain the general solution of (
A.2
) in the operator form

\mid\chi(t)\rangle=\hat{S}(t,t_{0})\mid\chi(t_{0})\rangle-\frac{i}{\hbar}\hat{S}(t,t_{0})\intop\nolimits_{t_{0}}^{t}\hat{S}^{\dagger}(s,t_{0})\mid F(s)\rangle ds.

(A.10)

By projecting this general expression on the basis states
\mid\psi_{\sigma}\rangle,
we finally arrive to

c_{\sigma}(t)=\sumop\displaylimits_{\lambda}S_{\sigma\lambda}(t,t_{0})\tilde{c}_{\lambda}(t_{0})-\frac{i}{\hbar}\sumop\displaylimits_{\lambda\nu}S_{\sigma\lambda}(t,t_{0})\intop\nolimits_{t_{0}}^{t}S^{\ast}_{\nu\lambda}F_{\nu}(s)ds,

(A.11)

where the superscripts under the sum symbols run from 1 to the total number of time-dependent oscillators, in our case it is equal to 2.
