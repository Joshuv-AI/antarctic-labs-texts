Krzysztof Winowski

Abstract
We establish a result which provides the criteria for a divergence operator dependent both on the gradient and the function itself, to satisfy the S+ property. The result is complemented by several examples and an application.



1
Introduction

We begin the paper from reminding the definition of S+ property.

Definition 1.1

(S+ property)
.

Let
X
be a normed space and
A:X\to X^{*}
be an operator. We say that the operator
A
has S+ property if for every sequence
\{x_{n}\}_{n\in\mathbb{N}}\subset X
and for every

if

x_{n}\rightharpoonup x\quad\textrm{weakly in}\quad X

and

\limsup_{n\to+\infty}\langle A(x_{n}),x_{n}-x\rangle\leq 0

then

x_{n}\to x\quad\textrm{strongly in}\quad X.

The above property is a valuable tool in analysis of boundary value problems. We continue by presenting some of its applications.

[

]

Assuming that the operator

\{u_{n}\}_{n\in\mathbb{N}}\subset W^{1,p(\cdot)}(\Omega)
and a function
u\in W^{1,p(\cdot)}(\Omega)
such that

u_{n}\rightharpoonup u\quad\textrm{weakly in}\quad W^{1,p(\cdot)}(\Omega).

Lemma 3.4
.

If the function
a
satisfies condition A1, then from the sequence
\{u_{n}\}_{n\in\mathbb{N}}

we can choose a subsequence
\{u_{n_{k}}\}_{k\in\mathbb{N}}
such that

\lim_{k\to+\infty}\int_{\Omega}|(a(z,u_{n_{k}}(z),\nabla u(z))-a(z,u(z),\nabla u(z)),\nabla u_{n_{k}}(z)-\nabla u(z))_{\mathbb{R}^{N}}|dz=0.

Proof.

First we show that for every
n\in\mathbb{N}
the function

a(\cdot,u_{n}(\cdot),\nabla u(\cdot))-a(\cdot,u(\cdot),\nabla u(\cdot))\in L^{q(\cdot)}(\Omega).

Indeed using inequalities (
3.1
), (
3.2
) and condition A1 we have

\displaystyle\int_{\Omega}|a(z,u_{n}(z),\nabla u(z))-a(z,u(z),\nabla u(z))|^{q(z)}dz

\displaystyle\quad\leq\int_{\Omega}2^{q(z)-1}\left(|a(z,u_{n}(z),\nabla u(z))|^{q(z)}+|a(z,u(z),\nabla u(z))|^{q(z)}\right)dz

\displaystyle\quad\leq\int_{\Omega}2^{q(z)-1}\left(|k_{0}(z)|+c_{0}(|u_{n}(z)|^{r_{1}(z)}+|\nabla u(z)|^{p(z)-1}\right)^{q(z)}dz

\displaystyle\qquad+\int_{\Omega}2^{q(z)-1}\left(|k_{0}(z)|+c_{0}(|u(z)|^{r_{1}(z)}+|\nabla u(z)|^{p(z)-1}\right)^{q(z)}dz

\displaystyle\quad\leq\int_{\Omega}2^{q(z)-1}3^{q(z)-1}\left(|k_{0}(z)|^{q(z)}+c_{0}^{q(z)}(|u_{n}(z)|^{r_{1}(z)q(z)}+|\nabla u(z)|^{p(z)}\right)dz

\displaystyle\qquad+\int_{\Omega}2^{q(z)-1}3^{q(z)-1}\left(|k_{0}(z)|^{q(z)}+c_{0}^{q(z)}(|u(z)|^{r_{1}(z)q(z)}+|\nabla u(z)|^{p(z)}\right)dz.

For every
n\in\mathbb{N}
using Schwarz inequality and Hölder’s inequality we obtain

\displaystyle\int_{\Omega}|(a(z,u_{n}(z),\nabla u(z))-a(z,u(z),\nabla u(z)),\nabla u_{n}(z)-\nabla u(z))_{\mathbb{R}^{N}}|dz

(3.10)

\displaystyle\quad\leq\int_{\Omega}|(a(z,u_{n}(z),\nabla u(z))-a(z,u(z),\nabla u(z))|\cdot|\nabla u_{n}(z)-\nabla u(z)|dz

(3.11)

\displaystyle\quad\leq 2\|(a(z,u_{n}(z),\nabla u(z))-a(z,u(z),\nabla u(z))\|_{q(\cdot)}\cdot\|\nabla u_{n}-\nabla u\|_{p(\cdot)}

(3.12)

Let us observe that the sequence
\{\|\nabla u_{n}-\nabla u\|_{p(\cdot)}\}_{n\in\mathbb{N}}
is bounded.

Using Lemma
2.11
it is enough to find such subsequence
\{u_{n_{k}}\}_{k\in\mathbb{N}}
that

\lim_{k\to+\infty}\int_{\Omega}|a(z,u_{n_{k}}(z),\nabla u(z))-a(z,u(z),\nabla u(z))|^{q(z)}dz=0.

Using Remark
2.19
we know that

u_{n}\to u\quad\textrm{strongly in}\quad L^{r_{1}(\cdot)q(\cdot)}(\Omega).

So we can choose a subsequence

\{u_{n_{k}}\}_{k\in\mathbb{N}}
and find a function

g\in L^{r_{1}(\cdot)q(\cdot)}(\Omega)
such that

u_{n_{k}}(z)\to u(z)\quad\textrm{for almost all}\quad z\in\Omega

(3.14)

and

|u_{n_{k}}(z)|\leq|g(z)|\quad\textrm{for almost all}\quad z\in\Omega\quad\textrm{and}\quad\forall k\in\mathbb{N}.

(3.15)

We check that the assumptions of the Lebesgue convergence theorem are satisfied for this subsequence. Using (
3.14
) and the fact that function
a
is a Carathéodory function we have for almost all
z\in\Omega

\lim_{k\to+\infty}|a(z,u_{n_{k}}(z),\nabla u(z))-a(z,u(z),\nabla u(z))|^{q(z)}=0.

Using inequalities (
3.1
), (
3.2
), condition A1 and (
3.15
) for every
k\in\mathbb{N}
and for almost all
z\in\Omega
we get

\displaystyle|a(z,u_{n_{k}}(z),\nabla u(z))-a(z,u(z),\nabla u(z))|^{q(z)}

\displaystyle\ \leq 2^{q(z)-1}3^{q(z)-1}\cdot

\displaystyle\ \cdot\left(2|k_{0}(z)|^{q(z)}+c_{0}^{q(z)}(|u_{n_{k}}(z)|^{r_{1}(z)q(z)}+c_{0}^{q(z)}(|u(z)|^{r_{1}(z)q(z)}+2c_{0}^{q(z)}|\nabla u(z)|^{p(z)}\right)

\displaystyle\ \leq 2^{q(z)-1}3^{q(z)-1}\cdot

\displaystyle\ \cdot\left(2|k_{0}(z)|^{q(z)}+c_{0}^{q(z)}(|g(z)|^{r_{1}(z)q(z)}+c_{0}^{q(z)}(|u(z)|^{r_{1}(z)q(z)}+2c_{0}^{q(z)}|\nabla u(z)|^{p(z)}\right).

So using the Lebesgue convergence theorem we finally get

\lim_{k\to+\infty}\int_{\Omega}|a(z,u_{n_{k}}(z),\nabla u(z))-a(z,u(z),\nabla u(z))|^{q(z)}dz=0.

∎

Let us denote for all
z\in\Omega
and for all
n\in\mathbb{N}

\theta^{1}_{n}(z)=(a(z,u_{n}(z),\nabla u_{n}(z))-a(z,u_{n}(z),\nabla u(z)),\nabla u_{n}(z)-\nabla u(z))_{\mathbb{R}^{N}}

(3.16)

and

\theta^{2}_{n}(z)=(a(z,u_{n}(z),\nabla u(z))-a(z,u(z),\nabla u(z)),\nabla u_{n}(z)-\nabla u(z))_{\mathbb{R}^{N}}.

(3.17)

We will use this notation in Lemma
3.5
and Lemma
3.6
.

Lemma 3.5
.

If the function
a
satisfies conditions A1 and A2, then from the sequence
\{u_{n}\}_{n\in\mathbb{N}}\subset W^{1,p(\cdot)}(\Omega)
such that

\limsup_{n\to+\infty}\langle A(x_{n}),x_{n}-x\rangle\leq 0

we can choose a subsequence
\{u_{n_{k}}\}_{k\in\mathbb{N}}
such that

\lim_{k\to+\infty}\langle A(u_{n_{k}})-A(u),u_{n_{k}}-u\rangle=0.

Proof.

Because
u_{n}\rightharpoonup x
converges weakly in
W^{1,p(\cdot)}(\Omega)
so
\langle A(u),x_{u}-u\rangle\to 0
and in a consequence we have

\limsup_{n\to+\infty}\langle A(u_{n})-A(u),u_{n}-u\rangle\leq 0.

(3.18)

Next using Lemma
3.4
we can find such subsequence
\{u_{n_{k}}\}_{k\in\mathbb{N}}
that

\int_{\Omega}\theta^{2}_{n_{k}}(z)dz\to 0.

(3.19)

Using condition A2 we see that for every
n\in\mathbb{N}

\int_{\Omega}\theta^{1}_{n}(z)dz\geq 0.

(3.20)

On the other hand for every
n\in\mathbb{N}
we can write

\langle A(u_{n})-A(u),u_{n}-u\rangle=\int_{\Omega}\theta^{1}_{n}(z)dz+\int_{\Omega}\theta^{2}_{n}(z)dz.

(3.21)

Now using (
3.19
), (
3.20
) and (
3.21
) we can conclude that

\liminf_{k\to+\infty}\langle A(u_{n_{k}})-A(u),u_{n_{k}}-u\rangle\geq 0

(3.22)

and finally combining (
3.18
) and (
3.22
) we get

\lim_{k\to+\infty}\langle A(u_{n_{k}})-A(u),u_{n_{k}}-u\rangle=0.

∎

Let us denote for every
n\in\mathbb{N}
and for every
z\in\Omega

\xi_{n}(z)=(a(z,u_{n}(z),\nabla u_{n}(z))-a(z,u(z),\nabla u(z)),\nabla u_{n}(z)-\nabla u(z))_{\mathbb{R}^{N}}.

Lemma 3.6
.

If the function
a
satisfies conditions A1 and A2, then we can find a subsequence
\{\xi_{n_{k}}\}_{k\in\mathbb{N}}
and a function
l\in L^{1}(\Omega)_{+}
such that

\xi_{n_{k}}(z)\to 0\quad\textrm{for almost all}\quad z\in\Omega

and

|\xi_{n_{k}}(z)|\leq l(z)\quad\textrm{for almost all}\quad z\in\Omega\quad\textrm{and}\quad\forall k\in\mathbb{N}.

Proof.

Using Lemma
3.4
we know that we can find a subsequence
\{x_{n_{k}}\}_{k\in\mathbb{N}}
such that

\theta^{2}_{n_{k}}\to 0\quad\textrm{strongly in}\quad L^{1}(\Omega).

(3.23)

Using condition A2 we see that for every
n\in\mathbb{N}
and for almost all
z\in\Omega
we have

\theta^{1}_{n}(z)\geq 0.

(3.24)

We know from Lemma
3.5
that

\int_{\Omega}\xi_{n_{k}}(z)dz\to 0.

(3.25)

Because for all
z\in\Omega
and for all
n\in\mathbb{N}
we have

\xi_{n}(z)=\theta^{1}_{n}(z)+\theta^{2}_{n}(z)

(3.26)

so combining (
3.23
), (
3.25
) and (
3.26
) we can conclude that

\theta^{1}_{n_{k}}\to 0\quad\textrm{strongly in}\quad L^{1}(\Omega)

(3.27)

and hence using (
3.24
) and (
3.27
) we have

\xi_{n_{k}}\to 0\quad\textrm{strongly in}\quad L^{1}(\Omega).

At the end we can extract a subsubsequence
\{\xi_{n_{k_{j}}}\}_{j\in\mathbb{N}}
and find a function

such that

\xi_{n_{k_{j}}}(z)\to 0\quad\textrm{for almost all}\quad z\in\Omega

and

|\xi_{n_{k_{j}}}(z)|\leq l(z)\quad\textrm{for almost all}\quad z\in\Omega\quad\textrm{and}\quad\forall j\in\mathbb{N}.

∎

4
Main result

Theorem 4.1
.

Let
\Omega
be a bounded set with Lipschitz continuous boundary
\partial\Omega
. Let us assume that function
p\in C(\overline{\Omega})
with
1<p(z)
for all
z\in\overline{\Omega}
and let
a:\Omega\times\mathbb{R}\times\mathbb{R}^{N}\to\mathbb{R}^{N}
be a Carathéodory function such that it satisfies conditions A1 - A3. Let us also assume that one of the following conditions hold

p(z)<N\quad\forall z\in\overline{\Omega}

p(z)=N\quad\forall z\in\overline{\Omega}

p(z)>N\quad\forall z\in\overline{\Omega}.

Then the operator

A:W^{1,p(\cdot)}(\Omega)\to W^{1,p(\cdot)}(\Omega)^{*}

\langle A(u),v\rangle=\int_{\Omega}(a(z,u(z),\nabla u(z)),\nabla v(z))_{\mathbb{R}^{N}}dz\quad\forall u,v\in W^{1,p(\cdot)}(\Omega)

has S+ property.

Proof.

Let us take a sequence
\{u_{n}\}_{n\in\mathbb{N}}\subset W^{1,p(\cdot)}(\Omega)
such that

u_{n}\rightharpoonup u\quad\textrm{weakly in}\quad W^{1,p(\cdot)}(\Omega)

and

\limsup_{n\to+\infty}\langle A(u_{n}),u_{n}-u\rangle\leq 0.

First let us observe that by Remark
2.19
the convergence holds

u_{n}\to u\quad\textrm{strongly in}\quad L^{p(\cdot)}(\Omega).

Now by Remark
2.14
it is enough to show that

\nabla u_{n}\to\nabla u\quad\textrm{strongly in}\quad L^{p(\cdot)}(\Omega;\mathbb{R}^{N}).

(4.1)

Let us observe that using the Urysohn subsequence principle it is enough to find some subsequence
\{u_{n_{k}}\}_{k\in\mathbb{N}}
such that

\nabla u_{n_{k}}\to\nabla u\quad\textrm{strongly in}\quad L^{p(\cdot)}(\Omega;\mathbb{R}^{N}).

Now we show how to find such subsequence. Using Remark
2.19
and Lemma
3.6
we can choose a subsequence

\{u_{n_{k}}\}_{k\in\mathbb{N}}
and find functions
g_{1}\in L^{r_{1}(\cdot)}(\Omega)
,
g_{2}\in L^{r_{2}(\cdot)}(\Omega)
and
l\in L^{1}(\Omega)_{+}
such that for almost all
z\in\Omega
and for every
k\in\mathbb{N}
:

u_{n_{k}}(z)\to u(z)

(4.2)

|u_{n_{k}}(z)|\leq g_{1}(z)

(4.3)

|u_{n_{k}}(z)|\leq g_{2}(z)

(4.4)

(a(z,u_{n_{k}}(z),\nabla u_{n_{k}}(z))-a(z,u(z),\nabla u(z)),\nabla u_{n_{k}}(z)-\nabla u(z))_{\mathbb{R}^{N}}\to 0

(4.5)

l(z)\geq(a(z,u_{n_{k}}(z),\nabla u_{n_{k}}(z))-a(z,u(z),\nabla u(z)),\nabla u_{n_{k}}(z)-\nabla u(z))_{\mathbb{R}^{N}}.

(4.6)

We set
\zeta_{k}=u_{n_{k}}
for all
k\in\mathbb{N}
. We want to show that

\nabla\zeta_{k}\to\nabla u\quad\textrm{strongly in}\quad L^{p(\cdot)}(\Omega;\mathbb{R}^{N}).

To prove this we use the Vitali convergence theorem. In the first step we show that

\nabla\zeta_{k}(z)\to\nabla u(z)\quad\textrm{for almost all}\quad z\in\Omega.

Using conditions A1 and A3 we have for every
k\in\mathbb{N}
and for almost all
z\in\Omega

\displaystyle l(z)\geq(a(z,\zeta_{k}(z),\nabla\zeta_{k}(z))-a(z,u(z),\nabla u(z)),\nabla\zeta_{k}(z)-\nabla u(z))_{\mathbb{R}^{N}}

(4.7)

\displaystyle\quad\ \ \geq c_{1}|\nabla\zeta_{k}(z)|^{p(z)}-c_{2}|\zeta_{k}(z)|^{r_{2}(z)}-|k_{1}(z)|

(4.8)

\displaystyle\qquad\ +c_{1}|\nabla u(z)|^{p(z)}-c_{2}|u(z)|^{r_{2}(z)}-|k_{1}(z)|

(4.9)

\displaystyle\qquad\ -(|k_{0}(z)|+c_{0}(|\zeta_{k}(z)|^{r_{1}(z)}+|\nabla\zeta_{k}(z)|^{p(z)-1}))|\nabla u(z)|

(4.10)

\displaystyle\qquad\ -(|k_{0}(z)|+c_{0}(|u(z)|^{r_{1}(z)}+|\nabla u(z)|^{p(z)-1}))|\nabla\zeta_{k}(z)|

(4.11)

\displaystyle\quad\ \ \geq c_{1}|\nabla\zeta_{k}(z)|^{p(z)}-c_{2}|g_{2}(z)|^{r_{2}(z)}-|k_{1}(z)|

(4.12)

\displaystyle\qquad\ +c_{1}|\nabla u(z)|^{p(z)}-c_{2}|u(z)|^{r_{2}(z)}-|k_{1}(z)|

(4.13)

\displaystyle\qquad\ -(|k_{0}(z)|+c_{0}(|g_{1}(z)|^{r_{1}(z)}+|\nabla\zeta_{k}(z)|^{p(z)-1}))|\nabla u(z)|

(4.14)

\displaystyle\qquad\ -(|k_{0}(z)|+c_{0}(|u(z)|^{r_{1}(z)}+|\nabla u(z)|^{p(z)-1}))|\nabla\zeta_{k}(z)|.

(4.15)

Let us denote the set

\Omega_{0}=\{z\in\Omega\quad|\quad\{\nabla\zeta_{k}(z)\}_{k\in\mathbb{N}}\quad\textrm{is bounded in}\quad\mathbb{R}^{N}\}.

From inequality (
4.7
) we can conclude that the set
\Omega_{0}
is of full measure in
\Omega
. For all
z\in\Omega_{0}

let us fix an arbitrary subsequence
\{\nabla\zeta_{k_{j_{z}}}(z)\}_{j_{z}\in\mathbb{N}}
depending on
z
. Now we can choose some subsubsequence
\{\nabla\zeta_{k_{j_{w_{z}}}}(z)\}_{w_{z}\in\mathbb{N}}
such that it converges in
\mathbb{R}^{N}
. Let us define the function
\beta:\Omega\to\mathbb{R}^{N}

\beta(z)=\lim_{w_{z}\to+\infty}\nabla\zeta_{k_{j_{w_{z}}}}(z)\quad\textrm{for almost all}\quad z\in\Omega.

From (
4.5
) we know that

(a(z,\zeta_{k_{j_{w_{z}}}}(z),\nabla\zeta_{k_{j_{w_{z}}}}(z))-a(z,u(z),\nabla u(z)),\nabla\zeta_{k_{j_{w_{z}}}}(z)-\nabla u(z))_{\mathbb{R}^{N}}\to 0.

(4.17)

Now passing to the limit in (
4.17
), using (
4.2
) and the fact that function
a
is Carathéodory we obtain for almost all
z\in\Omega

(a(z,u(z),\beta(z))-a(z,u(z),\nabla u(z)),\beta(z)-\nabla u(z))_{\mathbb{R}^{N}}=0.

(4.18)

Now combining (
4.18
) and condition A2 we get

\nabla u(z)=\beta(z)\quad\textrm{for almost all}\quad z\in\Omega.

Finally using the Urysohn subsequence principle this proves that

\nabla\zeta_{k}(z)\to\nabla u(z)\quad\textrm{for almost all}\quad z\in\Omega.

In the second step we prove the uniform integrability.
We will need the following fact from measure theory.

Remark 4.2
.

Let function
k\in L^{1}(\Omega)
then for every
\epsilon>0
we can find
\delta(\epsilon)>0
such that for every measurable set
C\subset\Omega
such that
\mu(C)<\delta(\epsilon)

\int_{C}|k(z)|dz<\epsilon.

Let

be such that
\|\nabla\zeta_{k}\|_{p(\cdot)}<A
for all

. Using the inequality (
4.7
) and Hölder’s inequality for every measurable set

we have

\displaystyle c_{1}\int_{C}|\nabla\zeta_{k}(z)|^{p}dz

(4.19)

\displaystyle\leq\int_{C}l(z)dz+2\|k_{0}\|_{q(\cdot)}\|\nabla u\|_{p(\cdot)}+2c_{0}\|g_{1}^{r_{1}}\|_{q(\cdot)}\|\nabla u\|_{p(\cdot)}+2c_{0}A\|\nabla u\|_{p(\cdot)}

(4.20)

\displaystyle+2A\|k\|_{q(\cdot)}+2c_{0}A\|x^{r_{1}}\|_{q(\cdot)}+2c_{0}A\|\nabla x\|_{p(\cdot)}

(4.21)

\displaystyle+c_{1}\int_{C}|g_{1}(z)|^{r_{2}(z)}dz+c_{1}\int_{C}|u(z)|^{r_{2}(z)}dz+2\int_{C}|k_{1}(z)|dz.

(4.22)

Now combining (
4.19
),
4.2
and
2.11
we finish the proof.
∎
