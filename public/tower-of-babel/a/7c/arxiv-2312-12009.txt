Active Preference Inference using Language Models and Probabilistic Reasoning
Wasu Top Piriyakulkij, Volodymyr Kuleshov, Kevin Ellis

Abstract
Actively inferring user preferences, for example by asking good questions, is important for any human-facing decision-making system. Active inference allows such systems to adapt and personalize themselves to nuanced individual preferences. To enable this ability for instruction-tuned large language models (LLMs), one may prompt them to ask users questions to infer their preferences, transforming the language models into more robust, interactive systems. However, out of the box, these models are not efficient at extracting preferences: the questions they generate are not informative, requiring a high number of user interactions and impeding the usability of the downstream system. In this work, we introduce an inference-time algorithm that helps LLMs quickly infer preferences by using more informative questions. Our algorithm uses a probabilistic model whose conditional distributions are defined by prompting an LLM, and returns questions that optimize expected entropy and expected model change. Results in a simplified interactive web shopping setting with real product items show that an LLM equipped with our entropy reduction algorithm outperforms baselines with the same underlying LLM on task performance while using fewer user interactions.



1
Introduction

For any decision-making AI system, knowing each user’s task preferences is crucial for the system to be most helpful to individual users. Ideally, in the context of language-based AI systems, we might naively hope for users to fully specify a task in natural language. However, while human speakers can be very effective at selecting their utterances
[
7
]
, they often fail to fully specify their task preferences to human or AI listeners. Designing language-supported AI systems that can actively infer users’ task preferences (e.g., by asking questions when they are uncertain) could help make these technologies more aligned, more personalized, and ultimately more broadly applicable.

Recently, large language models (LLMs)
[
2
,
14
]
, enhanced with instruction tuning
[
3
,
11
]
, have shown impressive performance at following natural language task instructions. While LLMs are not natively trained to be good active learners, we can prompt them, leveraging their in-context learning ability, to ask users questions to infer their preferences.
Concurrent work
[
8
]
has shown that prompting LLMs to elicit user preferences indeed helps improve performances over various tasks. Using language models to first elicit user preferences before carrying out the tasks provides a promising path toward enabling these models in domains that require fine-grained understanding of user preferences.

Nevertheless, a simple conversation with these off-the-shelf LLMs (
Figure

4
) reveals their poor ability to efficiently learn user preferences from few questions.
Although these LLMs are able to ask relevant questions when prompted, they do not ask the more informative questions, given the current context. This increases the amount of
model-human interaction needed to infer the user’s preferences.

We propose an inference-time algorithm for active inference of user preferences by LLMs.
Our algorithm is motivated by the observation that while out-of-the-box LLMs are suboptimal at interactively inferring user preferences, they are decent at generating diverse questions for extracting preferences, and can generate plausible answers to each such question.
Moreover, given an ongoing interaction with a user, LLMs can reasonably score how likely the user will answer a question in certain ways.
Thus, we can use the LLM-defined scores to define a full probabilistic generative model of what question to ask, how the user might respond, and how those responses update the system’s probabilistic beliefs.
Concretely, our algorithm samples a finite set of questions from the LLM and chooses the one that maximizes information gain.

We evaluate our approach in a simplified web shopping setting using data from a realistic web shopping benchmark
[
16
]
.
Each task consists of a list of products, together with a user who has a latent preference for a specific target product from that list.
LLMs will ask a series of yes/no questions to infer the target product. We compare our inference-time active inference method against a vanilla instruction-tuned LLM
[
3
,
11
]
and ReAct
[
17
]
, finding that our approach outperforms both baselines while using fewer questions. In line with recent work
[
5
,
20
,
6
]
, our results should be seen as a way of augmenting LLMs with inference-time probabilistic reasoning.

Active Preference Inference

2.1
Task formulation

We first introduce the active preference inference formulation. For decision-making tasks, human preferences can be viewed as reward functions that map decisions to a scalar,
R:\mathcal{X}\rightarrow\mathcal{R}
where
\mathcal{X}
is the space of decisions. The human user can be described with a reward function and an answer model
(R^{*},p_{\text{human}}(a|q))
where
q,a\in\Sigma^{*}
.
q
and
a
are a natural language question and answer, and
\Sigma^{*}
is the space of natural language. Active preference inference task boils down to a task of asking a series of questions
q_{1},..,q_{k}
, to which the answers
a_{i}\sim p_{\text{human}}(a|q_{i})
will be generated, to infer the unknown target reward
R^{*}
.

Active preference inference resembles active learning but differs in a few key ways.
First, active preference inference separates the answer model
p_{human}(a|q)
from the reward function
R^{*}
. This formulation allows the flexibility of asking arbitrary questions to the user. We also note that the question
q
can be of the form "Is the following example positive or negative:
{example}
", which means active preference inference can be seen as a generalization of active learning. Second, active learning usually assumes access to unlabeled data points that an algorithm can query, while active preference inference asks an algorithm to generate its own questions.

2.2
Existing approaches

Prior to the advent of LLMs, there were attempts at training NLP systems specifically for interactive inference
[
12
,
18
]
. Although these works do not consider the question of how to infer the reward function from the final result conversation, we can easily define the predicted reward function as LLM conditioned with that conversation. The main downside of these methods, however, is that they require expensive task-specific data collection for training. Having to gather data for every new task severely limits the usability of these methods.

LLM-based approaches to active preference inference promise to bypass the data collection process with its zero-shot learning capability. With instruction-tuned LLMs, we can directly prompt the models to ask users questions to infer preferences. However, as mentioned and confirmed later in our experiments, these models turn out to be ineffective at preference inference off-the-shelf and require many interactions with the users before arriving at a good prediction of the reward function.

In this work, we equip LLMs with inference-time probabilistic reasoning algorithm defined in
Section

3
to address this core issue, extracting as much information from the user as possible in as few questions as needed.
This essentially minimizes human-user effort, at the expense of more LLM computation.
As LLMs inference will likely become cheaper in the future, we believe this is the right tradeoff to make.

Inference-time probabilistic reasoning for asking informative question

In this section, we define the relevant models and present two measures from the active learning literature
[
13
]
that one may use to pick an informative question.

3.1
Model definition

To develop our model, we make an assumption that the target reward function
R^{*}
is a binary function that is 1 only at the target decision
x^{*}\in\mathcal{X}
and 0 everywhere else. With this assumption, we only need to infer the target decision
x^{*}
to know
R^{*}
.

We define the joint distribution as
p(x,q,a)=p(a|x,q)p(x)p(q)
. The distributions needed to compute the joint are defined by prompting an LLM:

\displaystyle p(q)

\displaystyle=\text{Uniform}(\Sigma^{*})

\displaystyle p(x)

\displaystyle=\text{Uniform}(\mathcal{X})

\displaystyle p(a|x,q)

\displaystyle=\;\left[\begin{array}[]{cc}&\text{a binary 0/1 score output by prompting an LLM}\\
&\text{whether the answer $a$ to the question $q$ is consistent}\\
&\text{with the product description of $x$}\end{array}\right]

With these defined distributions, we know that
p(x|q,a)\propto p(a|x,q)
because
p(x|q)=p(x)=\mathcal{U}(X)
. We can also easily calculate
p(a|q)=\sum_{x\in X}p(a|x,q)p(x)
. In addition, we define a question proposal distribution
r(q)
by asking an LLM to generate a finite number of possible questions given all product information
X
. Prompts used for obtaining
p(a|x,q)
and
r(q)
can be founded in
Section

A.3
.

We can easily extend our model to the setting where we have multiple pairs of questions and answers. Let
\mathbf{c}
denote a conversation containing a sequence of questions and answers
\mathbf{c}=\{(q^{(c)}_{1},a^{(c)}_{1}),...,(q^{(c)}_{m},a^{(c)}_{m})\}
. Our model becomes
p(x,\mathbf{c})=p(x)\prod_{i}p(a^{(c)}_{i}|x,q^{(c)}_{i})p(q^{(c)}_{i})
. With this new model,
p(x|\mathbf{c})\propto\prod_{i}p(a^{(c)}_{i}|x,q^{(c)}_{i})
, and
p(a|\mathbf{c},q)\propto\sum_{x\in X}(p(a|x,q)\prod_{i}p(a^{(c)}_{i}|x,q^{(c)}_{i}))
. We also modify the prompt for
r(q)
to take into account the conversation, notated
r(q|\mathbf{c})
.

3.2
Objectives for choosing informative questions

With the distributions defined in
Section

3.1
, we sample a finite set of questions from the proposal distribution
r(q|\mathbf{c})
, calculate the amount of information each question would reveal in expectation, and subsequently pick the question with the highest amount of expected information. We consider two objectives, commonly used in the active learning field
[
13
]
, to measure how informative a question is: expected entropy minimization and expected model change maximization.

Expected Entropy Minimization.

The most informative question could be thought as the question which reduces the most amount of uncertainty in expectation. This notion can be captured with the expected entropy minimization objective. The objective is as follows:

\argmin_{q\sim r(q|\mathbf{c})}E_{p(a|\mathbf{c},q)}[H(p(x|\mathbf{c},q,a)]

(1)

Expected Model Change Maximization.

Another approach is to think about model parameter/belief and consider the most informative question as the question that would make the most change to the model parameter/belief. For our tasks, we can let belief be a decision
x\in\mathcal{X}
, representing the notion that we believe
x
is the decision with a positive reward. We can use KL divergence to measure the change in belief. The objective is as follows:

\argmax_{q\sim r(q|\mathbf{c})}E_{p(a|\mathbf{c},q)}[D_{\mathrm{KL}}(p(x|\mathbf{c},q,a)||p(x|\mathbf{c}))]

(2)

Equivalence between the two objectives.

In our specific setting, it can be shown that expected entropy minimization and expected model change maximization are in fact equivalent. This is due to the fact that the expected cross-entropy
E_{p_{\text{model}}(a|\mathbf{c},q)}[E_{p(h|\mathbf{c},q,a)}[-\log p(h|\mathbf{c})]
is the same for all
q,a
because by our definition,
p(h|\mathbf{c},q,a)>0
if
p(h|\mathbf{c})>0
, and if
p(h|\mathbf{c})>0
, then
p(h|\mathbf{c})=f(\mathbf{c})
is constant to
h
. More details can be founded at

Experiments

Figure 2:
(Left) Average expected binary reward at increasing number of number of questions. (Right) Average expected soft reward at increasing number of number of questions.

We evaluate an LLM augmented with our entropy reduction algorithm (entropy reduction LLM) on 150 simplified web shopping tasks, each task consisting of 10 product items from WebShop
[
16
]
. The products in each task come from the same product type, e.g., hair growth serum oil, HDMI cable, phone case, etc.
While the goal of active preference inference is to infer the target reward function
R^{*}
, it is more realistic in web-shopping settings to make algorithms return a single product
\hat{x}
and evaluate them based on the reward of the returned product
R^{*}(\hat{x})
, so we employ this evaluation in this work. This evaluation can still be seen as implicitly inferring reward function
\hat{R}
and then return
\hat{x}=\argmax_{x\in\mathcal{X}}\hat{R}(x)
. We consider two types of reward functions: binary and soft reward. Both are constructed based on a target product
x^{*}
randomly chosen from the task’s list of products. More details on task creation can be found at
Section

A.2
. We simulate human users
p_{\text{human}}(a|q)
with GPT-4
[
10
]
by inputting target product
x^{*}
in the prompt. We make a simplifying assumption that only yes/no questions to users are allowed.

Two baselines we consider are vanilla instruction-tuned LLM
[
3
,
11
]
and ReAct LLM
[
17
]
. All methods use the same
p(x|q,a)
to choose a product given questions and answers; the differences in these methods lie in the questions they choose to ask. Vanilla instruction-tuned LLM is prompted to roleplay to be a product seller and ask questions. Our entropy reduction method samples 8 questions from the proposal distribution
r(q|\mathbf{c})
but would reduce down to vanilla instruction-tuned LLM if we only sample one question from the proposal distribution. ReAct is a prompting method for LLM Agents where thinking is part of the action space. In our question-asking scenario, asking a question can be seen as an action. We write a prompt that has a thinking process on what question is best to ask at each point. Prompts for both of these methods can be found at
Section

A.3
. When more than one product has positive probability
p(x|q,a)
at the end of the questioning, we assume the methods return the positive-probability products at random and actually calculate the expected reward on them. The underlying LLM for all methods is GPT-4. We sample at zero temperature (For the proposal distribution, we actually prompt LLM to return a list of diverse questions instead of sampling questions from LLM with positive temperature).

4.1
Binary Reward

Average information gain at each question. Confidence intervals are computed over 150 diffent tasks.

First, we consider a binary reward setting where the reward is 1 if the target product is retrieved and 0 otherwise. This binary reward is consistent with our modeling assumption.

Figure

2
(left) shows that entropy reduction LLM significantly outperforms both baselines when the number of questions is greater than one.
In fact, our algorithm after three questions even surpasses the two baselines after four questions.

Figure

3
reports average information gain at each round of questioning. For the first three questions, we can see that entropy reduction LLM gains more information than both baselines. At the last question, vanilla instruction-tuned LLM gets more information, but all methods do not receive much information gain at this point. There are 10 products in the list of products for each task, and at the fourth question, not much information is left to be extracted from human users.

4.2
Soft Reward

We also consider a more realistic, soft reward setting. In practical scenarios, it is likely that user preferences for product items are not all-or-nothing, and user satisfaction upon receiving each product item as output is more fine-grained. We adopt the reward used in the Webshop benchmark
[
16
]
. We exclude product price and options from the original reward calculation as they are not relevant in our task setting. The reward is then calculated based on Webshop’s text matching heuristics and the attribute overlap between the target product and the returned product. The reward falls within the range of 0 to 1, with an exact match yielding a reward of 1.

Similar to the binary reward,
Figure

2
(right) shows that entropy reduction LLM outperforms both baselines when the number of questions is greater than one. Even though the soft reward is different from our modeling assumption, the inference-time entropy reduction algorithm is still better at preference inference than the two baselines.

Related Work

Learning to ask clarifying question.

There are many prior works in learning to ask clarification questions
[
12
,
1
,
18
,
19
]
.
[
12
]
relies on the idea that a good clarification question is the one whose answer will be useful. They use Q&A forum data to train neural networks to be an answer model and an answer utility calculator and choose question that maximizes expected utility.
[
1
]
looks at the problem of asking good clarifying questions from an information retrieval perspective, and train models with question-answer pairs data to retrieve good questions from a crowdsourced dataset.

[
18
]
studies interactive classification where questions are selected based on the entropy minimization principle similar to our work. They crowdsource non-interactive data to train neural networks used to define their probability distributions. The main difference between our work and these work is that we do not require any sort of training data and instead rely on the powerful zero-shot learning capability of LLMs to define rich distributions, which we can probabilistically reason over at inference time.

Probabilistic reasoning with LLMs.

[
5
]
provides a unifying framework of seeing recent inference-time LLM algorithms
[
9
,
15
,
4
]
as performing reasoning with probabilistic programs.
[
20
]
utilizes LLM to define prior distributions in a probabilistic graphical model and performs inference in the model to solve navigation, action recognition, and image segmentation. Our work studies inference-time probabilistic reasoning with LLM in the context of active preference inference.

6
Conclusion and Discussion

In this work, we present an inference-time algorithm to enhance the efficiency of actively inferring preferences of LLMs and demonstrate that in our web shopping setting, our method performs better than the baselines using fewer user interactions.

There are several future directions for this work. The most obvious one is to let the allowed questions be open-ended. Even though this modification will not call for any change to the model definition, this generalization will necessitate an approximation to the objective calculation as there might be infinitely many answers to an open-ended question. One needs to test empirically how much computation is needed before the Monte Carlo approximation is close enough to the true expected value. Another direction is to come up with a more flexible probabilistic model that does not assume the target reward function is binary. While this assumption works well in the web shopping setting, as evidently shown in both binary and soft reward evaluation, it may result in poor performance for other tasks that involve a full prediction of the reward function.
