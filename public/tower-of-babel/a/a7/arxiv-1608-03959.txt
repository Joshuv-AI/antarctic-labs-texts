Novel Special Function Obtained from a Delay Differential Equation


Abstract
This paper deals with the series solution of a linear delay differential equation (DDE) y ′ ​ ( x ) = a ​ y ​ ( x ) + b ​ y ​ ( q ​ x ) , 0 < q < 1 y^{\prime}(x)=ay(x)+by(qx),\quad 0<q<1 (0.1) with proportional delay. We discuss the convergence of this novel series. We establish the relation between the special function given in terms of this series and its differentials. We also discuss the bounds on this function and present the relation with other special functions viz. Kummer’s functions, generalized Laguerre polynomials, incomplete gamma function, beta function and regularized incomplete beta function. Further, we discuss various properties and contiguous relations for the novel special function. Finally, we generalize this series by solving fractional order DDE and a system of DDE.

3
New Special Function

Consider the differential equation with proportional delay

y^{\prime}(x)=ay(x)+by(qx),\quad y(0)=1,

(3.1)

where
0<q<1
,
a\in\mathbb{R}
and
b\in\mathbb{R}
.

Integrating (
3.1
), we get

y(x)=1+\int_{0}^{x}\left(ay(t)+by(qt)\right)dt

(3.2)

which is of the form Eq.(
2.16
). Applying DJM, we obtain

\displaystyle y_{0}(x)

\displaystyle=

\displaystyle 1,

\displaystyle y_{1}(x)

\displaystyle=

\displaystyle\int_{0}^{x}\left(ay_{0}(t)+by_{0}(qt)\right)dt

\displaystyle=

\displaystyle(a+b)\frac{x}{1!},

\displaystyle y_{2}(x)

\displaystyle=

\displaystyle\int_{0}^{x}\left(ay_{1}(t)+by_{1}(qt)\right)dt

\displaystyle=

\displaystyle\int_{0}^{x}\left(a(a+b)t+b(a+b)tq\right)dt

\displaystyle=

\displaystyle(a+b)(a+bq)\frac{x^{2}}{2!},

\displaystyle y_{3}(x)

\displaystyle=

\displaystyle\int_{0}^{x}\left(ay_{2}(t)+by_{2}(qt)\right)dt

\displaystyle=

\displaystyle(a+b)(a+bq)(a+bq^{2})\frac{x^{3}}{3!},

\displaystyle y_{n}(x)

\displaystyle=

\displaystyle\frac{x^{n}}{n!}\prod_{j=0}^{n-1}\left(a+bq^{j}\right),\quad n=1,2,3\cdots.

(3.3)

\therefore
The DJM solution of (
3.1
) is

\displaystyle y(x)

\displaystyle=

\displaystyle y_{0}(x)+y_{1}(x)+y_{2}(x)+\cdots

\displaystyle=

\displaystyle 1+(a+b)\frac{x}{1!}+(a+b)(a+bq)\frac{x^{2}}{2!}+\cdots

\displaystyle y(x)

\displaystyle=

\displaystyle 1+\sum_{n=1}^{\infty}\frac{x^{n}}{n!}\prod_{j=0}^{n-1}\left(a+bq^{j}\right).

(3.4)

The power series solution (
3.4
) of DDE (
3.1
) generates a novel special function

\mathcal{R}(a,b,q,x)=1+\sum_{n=1}^{\infty}\frac{x^{n}}{n!}\prod_{j=0}^{n-1}\left(a+bq^{j}\right).

(3.5)

We call this function as Ramanujan function in the memory of S. Ramanujan
[
50
]
.

Theorem 4.1
.

If
0<q<1
, then the power series

\mathcal{R}(a,b,q,x)=1+\sum_{n=1}^{\infty}\frac{x^{n}}{n!}\prod_{j=0}^{n-1}\left(a+bq^{j}\right)

(4.1)

has infinite radius of convergence.

Proof.

Suppose

a_{n}=\frac{1}{n!}\prod_{j=0}^{n-1}\left(a+bq^{j}\right),\quad n=1,2,\cdots.

(4.2)

If
R
is radius of convergence of (
4.1
) then by using ratio test
[
51
]

\displaystyle\frac{1}{R}=\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_{n}}\right|

\displaystyle=

\displaystyle\lim_{n\to\infty}\left|\frac{\frac{1}{{(n+1)!}}\prod_{j=0}^{n}\left(a+bq^{j}\right)}{\frac{1}{n!}\prod_{j=0}^{n-1}\left(a+bq^{j}\right)}\right|

\displaystyle=

\displaystyle\lim_{n\to\infty}\left|\frac{a}{(n+1)}+\frac{bq^{n}}{(n+1)}\right|

\displaystyle\Rightarrow\frac{1}{R}

\displaystyle=

\displaystyle 0\quad(\because 0<q<1)

Thus the series has infinite radius of convergence.
∎

B\in M_{n\times n}
is convergent for
x\in\mathbb{R}
.

Proof.

By ratio test
[
55
]
,

\displaystyle\left\|\left(\frac{x^{n+1}}{(n+1)!}\prod_{j=1}^{n+1}\left(A+Bq^{n+1-j}\right)\right)\left(\frac{x^{n}}{n!}\prod_{j=1}^{n}\left(A+Bq^{n-j}\right)\right)^{-1}\right\|

\displaystyle=

\displaystyle\frac{\mid x\mid}{n+1}\left\|\left(\prod_{j=1}^{n+1}\left(A+Bq^{n+1-j}\right)\right)\left(\prod_{j=1}^{n}\left(A+Bq^{n-j}\right)\right)^{-1}\right\|

\displaystyle=

\displaystyle\frac{\mid x\mid}{n+1}\left\|A+Bq^{n}\right\|

\displaystyle=

\displaystyle 0,\quad\textrm{as}\;n\longrightarrow\infty.

\therefore
The power series (
6.11
) is convergent for
x\in\mathbb{R}
.
∎

7
Conclusions

In this article, we have presented a series solution for a differential equation with proportional delay. It is shown that the series is analytical on
\mathbb{R}
. The novel function
\mathcal{R}(a,b,q,x)=1+\sum_{n=1}^{\infty}\frac{x^{n}}{n!}\prod_{j=0}^{n-1}\left(a+bq^{j}\right)
is independent from hypergeometric functions because it is obtained as a solution of DDE where as hypergeometric functions are obtained from ODEs. It is observed that the
n^{\textrm{th}}
derivative of this function can be represented as the linear combination of
\mathcal{R}(a,b,q,q^{r}x)
for
0\leq r\leq n
with Gaussian binomial coefficients. The function
\mathcal{R}
is shown to be bounded by exponential functions. The new function
\mathcal{R}
shows relation with Kummer’s functions, with generalized Laguerre polynomials and with incomplete gamma function when integrated with a kernel
e^{-t}
. Further, we have discussed some identities and contiguous relations of
\mathcal{R}
. We also have generalized this function by solving fractional order DDE and a system of DDEs. We hope that our work will encourage researchers to dig for more properties of this new function and to work on DDEs with proportional delay.
