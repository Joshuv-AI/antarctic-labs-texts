Abstract
. We make advances towards a structural characterisation of the signed graphs H H for which the list switch H H -colouring problem LSwHom ⁡ ( H ) \operatorname{LSwHom}(H) can be solved in polynomial time. We conjecture a characterisation in the case that the graph H H can be switched to a graph in which every negative edge is also positive, and prove the characterisation in the case that the signed graph is reflexive.

Henceforth,

are undirected graphs in which loops– edges of the form

A

is a graph

to each edge. Introduced by Harary in
[
11

in 1955, there are numerous results about signed graphs. For our purposes, it will be enough to view a signed graph

simply as a
\mathrm{br}
-graph
(for blue-red): a pair of graphs–
G^{B}
, whose edges are called

, and
G^{R}
, whose edges are

– on the same vertex set. Signed graphs, as defined by Harary, were irreflexive and simple. But as is done in
[
3

4

we allow loops, and allow

to be non-empty. An edge in
G^{B}\cap G^{R}
is technically two edges in

purple edge
. If all edges of a
\mathrm{br}
-graph

are red (or purple) we call
G

red
(or
purple
). If an edge is red (or blue) but not purple, we call it
pure
red (or pure blue). A
\mathrm{br}
-graph

underlying graph

is. We write

to mean that

G^{R}\cup G^{B}
. Many results about signed graphs deal with the operation of

\mathrm{br}
-graph that is switching-equivalent to a graph with no pure blue edges is a

As a

2.1.
Structures, CSP, and List Homomorphism

A (relational) structure
\mathcal{H}
consists of a set
V=V(\mathcal{H})
of vertices with a finite ordered set of finite arity relations
R_{i}\subset V^{k}
on
V
. The corresponding ordered set of the arities of the structure is called its
type
. A
homomorphism
between two structures of the same type is a vertex map that preserves each relation. The problem
{\mathsf{CSP}}(\mathcal{H})
for a structure
\mathcal{H}
is the problem of deciding if an instance structure
\mathcal{G}
of the same type admits a homomorphism to
\mathcal{H}
.

A graph
H
is viewed as a structure with one symmetric binary relation
E
, an edge
uv
corresponding to the pairs
(u,v)
and
(v,u)
in
E
. A vertex map
V(G)\to V(H)
of graphs is a homomorphism between two graphs if and only if it is a homomorphism of the corresponding symmetric binary structures. So
{\mathsf{Hom}}(H)
is polynomially equivalent to
{\mathsf{CSP}}(H)
.

In the list variation
{\mathsf{LHom}}(H)
of the homomorphism problem
{\mathsf{Hom}}(H)
, an instance
G
comes attached with a list
L(v)\subset V(H)
for each vertex
v\in V(G)
, and one must decide if there is a homomorphism
\phi:G\to H
such that
\phi(v)\in L(v)
for each vertex
v
of
G
.
This is equivalent to
{\mathsf{CSP}}(H_{c})
where
\mathcal{H}_{c}
is the relational structure one gets from a structure
\mathcal{H}
by adding a new unary relation
L_{S}=\{(s)\mid s\in S\}
for each subset
S\subset V(\mathcal{H})
.

The
core

\mathcal{C}(\mathcal{H})
of a structure
\mathcal{H}
is the unique minimum induced substructure to which it admits a homomorphism. It is basic that
{\mathsf{CSP}}(\mathcal{C}(\mathcal{H}))
is polynomially equivalent to
{\mathsf{CSP}}(\mathcal{H})
.

A
k
-ary polymorphism
\phi
of
\mathcal{H}
is a homomorphism
\phi:\mathcal{H}^{k}\to\mathcal{H}
(that is, a map preserving all relations of
\mathcal{H}
), where
\mathcal{H}^{k}
is the
k
-time categorical product of
\mathcal{H}
with itself. It is
idempotent
if
\phi(h,h,\dots,h)=h
for all
h\in V(\mathcal{H})
, and it is
conservative
if

\phi(v_{1},\dots,v_{k})\in\{v_{1},\dots,v_{k}\}
. An idempotent polymorphism
\phi:\mathcal{H}^{k}\to\mathcal{H}
, for
k\geq 3
is
weak near unanimity
or
{\mathsf{WNU}}
if for every choice of
x,y\in V(\mathcal{H})
we have

\phi(x,x,\dots,x,y)=\phi(x,x,\dots,y,x)=\dots\phi(y,x,\dots,x,x).

Theorem 2.1

(The
{\mathsf{CSP}}
-dichotomy,
[
5
,
17
]
)
.

For a relational structure
\mathcal{H}
the problem
{\mathsf{CSP}}(\mathcal{H})
is in
{\mathsf{P}}
if the core of
\mathcal{H}
admits a
{\mathsf{WNU}}
-polymorphism, and is otherwise in
{\mathsf{NPC}}
.

In general it is difficult to find the core of a structure
\mathcal{H}
, and tends to be difficult to give a non-algebraic description of the structures
\mathcal{H}
for which
{\mathsf{CSP}}(\mathcal{H})
is in
{\mathsf{P}}
. For list colouring, it gets a little easier. For one, the structure

is always a core. It is easy to see that any polymorphism of

is conservative, so for list colouring problems we get the following corollary of Theorem

which Bulatov actually proved years earlier in
[
6
]
.

Corollary 2.2
.

For a relational structure
\mathcal{H}
the problem
{\mathsf{CSP}}(\mathcal{H}_{c})
is in
{\mathsf{P}}
if and only if the core of
\mathcal{H}
admits a conservative
{\mathsf{WNU}}
-polymorphism.

2.4.

Our goal is a nice characterisation of the

A polymorphism

4.
