Moser-Tardos Algorithm with small number of random bits
Endre Csóka, Łukasz Grabowski, András Máthé, Oleg Pikhurko, Konstantinos Tyros

Abstract
We study a variant of the parallel Moser-Tardos Algorithm. We prove that if we restrict attention to a class of problems whose dependency graphs have subexponential growth, then the expected total number of random bits used by the algorithm is constant; in particular, it is independent from the number of variables. This is achieved by using the same random bits to resample variables which are far enough in the dependency graph. There are two corollaries. First, we obtain a deterministic algorithm for finding a satisfying assignment, which for any class of problems as in the previous paragraph runs in time O ⁡ ( n ) O(n) , where n n is the number of variables. Second, we present a Borel version of the Lovász Local Lemma.



1
Introduction

In this article, we are interested in vertex colouring problems on graphs. An instance of such a problem consists of a digraph
G
, a natural number
b\in\mathbb{N}
which is the number of colours which we use, and a system of constraints
\mathbf{R}
which we call a
local rule
, i.e. for
x\in V(G)
we have that
\mathbf{R}(x)
is a set of
b
-valued functions defined on the out-neighbourhood of
x
, where we use
b
also to denote the set
\{0,\dots,b-1\}
. We say that
f\in b^{V(G)}

satisfies
\mathbf{R}
if for every
x\in V(G)
the restriction of
f
to the out-neighbourhood of
x
belongs to
\mathbf{R}(x)
.

One of the most useful tools for deducing that a colouring that satisfies a given local rule exists is the

Lovász Local Lemma
(LLL for short) first proved in
[
14
]
. Let us state the version of it which follows from
[
30
]
.

Let
G
be a digraph and let
\operatorname{Rel}(G)
be the symmetric digraph whose vertex set is
V(G)
and such that there is an edge between
x
and
y
if there is
z
such that
(x,z),(y,z)\in E(G)
(we allow
x
and
y
to be equal, so there may be self-loops in
\operatorname{Rel}(G)
).

Theorem 1.1

(Lovász Local Lemma
[
30
]
)
.

Let
G
be a digraph and let
{\Delta}
be the maximal vertex degree in
\operatorname{Rel}(G)
. If for every
x\in V(G)
we have

1-\frac{|\mathbf{R}(x)|}{b^{|\operatorname{Var}(x)|}}<\frac{1}{\mathrm{e}{\Delta}},

(1.2)

where
\operatorname{Var}(x)
denotes the out-neighbourhood of
x
, then there exists
f\in b^{V(G)}
which satisfies
\mathbf{R}
.

Remark 1.3
.

Usually, LLL is stated for a “satisfying assignment of variables” instead of a satisfying colouring. Let us explain this alternative point of view and why it is equivalent to the formulation with satisfying colourings.

Let
W
be a set of variables and let
C
be a set of logical clauses, each of which depends on some of the variables in
W
. The problem asks whether there exists an assignment
a\in b^{W}
of values to the variables which makes all of the clauses true. The translation from such a “satisfying assignment” problem to a digraph colouring problem is by considering the bipartite digraph
G
with
V(G):=C\sqcup W
, where
(x,y)\in C\times W
is an edge if and only if
y
is a variable which appears in the clause
x
. For
x\in W
the set
\operatorname{Var}(x)
is empty and we set
\mathbf{R}(x):=b^{\emptyset}
, so that
\mathbf{R}(x)
does not impose any restrictions on satisfying colourings. For
x\in C
we let
\mathbf{R}(x)
be the set of those assignments on
\operatorname{Var}(x)
which make the clause
x
satisfied. In the graph
\operatorname{Rel}(G)
two clauses are adjacent if and only if they share a common variable, while all elements of
W
are isolated vertices of
\operatorname{Rel}(G)
.

One of the key developments related to LLL is the Moser-Tardos Algorithm (MTA for short) studied by Moser and Tardos
[
24
]
(with a different version analysed earlier by Moser
[
25
]
). The MTA is a randomised algorithm for
finding
a satisfying colouring under the assumption that (
1.2
) holds. Moser and Tardos
[
24
]
proved that if we restrict attention to a class of colouring problems where the difference between the sides in the inequality (
1.2
) is at least a fixed constant
c>0
, then the MTA finds a satisfying assignment on a graph
G
after using
O(|V(G)|)
random bits in expectation.

Main result.

It is convenient to fix, for the rest of the article, a natural number
b>1
which is the number of colours in our colouring problems. With this in mind, a
colouring problem
is a pair
(G,\mathbf{R})
, where
G
is a digraph and
\mathbf{R}
is a local rule on
G
.

The main aim of this article is to present a parallel version of the MTA and to show, in Theorem
2.5
below, that it has the following property. Let
f\colon\mathbb{N}\to\mathbb{N}
be a
subexponential function
, i.e. such that for every
{\varepsilon}>0
it holds that
\lim_{n\to\infty}\frac{f(n)}{(1+{\varepsilon})^{n}}=0
. Consider the class
{\mathcal{C}}={\mathcal{C}}(f)
of graphs in which any ball of a radius
r
contains at most
f(r)
vertices. For example, we could take
f(n):=(2n+1)^{2}
, in which case
{\mathcal{C}}
would contain all subgraphs of the infinite
2
-dimensional grid. Let us also fix some
c>0
and let
{\mathcal{P}}={\mathcal{P}}(f,c)
be the class of colouring problems
(G,\mathbf{R})
such that
G\in{\mathcal{C}}
and

\max_{x\in V(G)}\left(1-\frac{|\mathbf{R}(x)|}{b^{\deg(x)}}\right)\leqslant\frac{1}{\mathrm{e}{\Delta}}-c.

(1.4)

Then there exists a constant
K>0
such that for every colouring problem
(G,\mathbf{R})\in{\mathcal{P}}
the expected number of random bits which the algorithm uses is at most
K
. In particular,
the expected number of random bits used is independent from the number of vertices in
G
. This is the crucial difference when compared to previous algorithmic versions of LLL. As a consequence, we obtain, in Corollary
2.10
, a sequential
deterministic
algorithm which runs in time
O(|V(G)|)
for colouring problems
(G,\mathbf{R})
in any class
{\mathcal{P}}
of the kind we have just described.

Connections to descriptive combinatorics and distributed algorithms.

Our results can be also used to derive a Borel version of the Lovász Local Lemma. In brief, we say that a colouring problem
(G,\mathbf{R})
is
Borel
if the vertex set
V(G)
is a standard Borel space and both the edge set
E(G)\subset V(G)^{2}
and the function
x\mapsto\mathbf{R}(x)
are Borel.
In Theorem
4.5
we show that if
G
has a uniformly subexponential growth and
(G,\mathbf{R})
is a Borel colouring problem for which the inequality (
1.4
) holds, then there is a satisfying colouring
V(G)\to b
which is a Borel function. This result appeared as the main result in the preprint
[
13
, Theorem 4.7]
, which is now superseded by this paper.

Our Borel LLL is a result in
descriptive combinatorics
, an emerging field that studies, in particular, colourings of infinite graphs which are “constructive” in the sense of descriptive set theory. We refer the reader to an extensive survey of this field by Kechris and Marks
[
19
]
.

Other descriptive versions of LLL were proved by Bernshteyn
[
2
,
4
,
3
]
, Bernshteyn and Weilacher
[
5
]
and Kun
[
21
]
. For quick comparison with our Borel LLL, let us mention that the versions proved in
[
21
,
2
,
3
]
allow a null-set of errors, and the versions in
[
4
,
5
]
, while producing an error-free satisfying colouring which is respectively continuous and Borel, require a stronger condition than (
1.4
).

On the other hand, our version of LLL requires that the underlying graph has subexponential growth. This might seem like a very strong assumption, especially since other descriptive versions of LLL mentioned in the previous paragraph do not need it. However, the assumption of subexponential growth cannot be removed in the Borel context in full generality (see Remark
4.6
). Also, there is a considerable number of recent articles where graphs of subexponential growth are studied from the point of view of descriptive combinatorics, see e.g.
[
12
,
17
,
18
,
31
]
.

Our Borel LLL from
[
13
]
has already found some interesting applications. For example, it was crucially used by Bernshteyn and Yu
[
1
]
to resolve some open problems on large-scale geometry of Borel graphs.
Also, Bernshteyn
[
3
, Theorem 2.15]
used our lemma to show that, for graphs of subexponential growth, if a colouring problem on a graph
G
can be solved by a randomised
LOCAL
algorithm (a model of distributed computing introduced by Linial
[
22
]
) in
O(\log|V(G)|)
rounds, then the corresponding Borel colouring problem admits a Borel solution.

In fact, the Lovász Local Lemma plays a very important role in the
LOCAL
complexity landscape.
More specifically, efficient distributed algorithms for solving LLL can be used for proving
automatic speedup theorems
(i.e. results that rule out whole intervals of possible complexities) for locally checkable labelling problems. In particular, if there exist distributed LLL algorithms matching the lower bound of Brandt et al
[
7
]
(as conjectured by Chang and Pettie
[
10
, Conjecture 5.1]
), then a certain interval of complexity classes collapses to one point in the
LOCAL
complexity landscape for general bounded-degree graphs.
We refer the reader to Chang and Pettie
[
10
]
for more detailed information.
The best known upper complexity bounds for LLL (coming from the method of Fischer and Ghaffari
[
15
]
combined with the improved network decomposition algorithms by Ghaffari, Grunau and Rozhoň
[
28
,
16
]
) are still polynomially far away from the conjectured values. The
LOCAL
complexity of LLL is not fully understood also for the class of subexponential growth graphs.
It would be interesting to see if the ideas introduced in this paper could shed some light on this problem.

2
Algorithm and the results

2.a
Notation and conventions

We let
\mathbb{N}:=\{0,1,2,\ldots\}
and
\mathbb{N}_{+}:=\mathbb{N}\setminus\{0\}
. The cardinality of a set
X

is denoted by
|X|
. "Either… or…" is non-exclusive. We recall that if
n\in\mathbb{N}
, then
n=\{0,1,\ldots,n-1\}
.

Given a set
X
, we denote by
\operatorname{Pow}(X)
the power set of
X
, i.e. the set of all subsets of
X
. Given another set
Y
, we let
X^{Y}
be the set of all functions from
Y
to
X
. In particular, we have the following notational clash: for
b,n\in\mathbb{N}
, the symbol
b^{n}
can either denote a number (and hence a set of numbers) or the set of all functions from
\{0,1,\ldots,n-1\}
to
\{0,1,\ldots,b-1\}
. We believe that resolving this ambiguity will never cause any difficulty for the reader. A convenient informal way of thinking about it is that if
k\in b^{n}
then
k
is both a number smaller than
b^{n}
and a function from
n=\{0,\ldots,n-1\}
to
b=\{0,\ldots,b-1\}
, and the translation between the two interpretations is that the
b
-ary expansion of the number
k
can be thought of as a function from
\{0,\ldots,n-1\}
to
\{0,\ldots,b-1\}
.

Given a function
f
with domain
D
and a set
C\subset D
we denote by
f\restriction C
the restriction of
f
to
C
.

By a
digraph
we mean a pair
G=(V,E)
where
V
is a non-empty set, and
E\subset V\times V
. In other words, our digraphs are without multiple edges, and each vertex is allowed to have at most one self-loop. A digraph
G=(V,E)
is
symmetric
if
E
is a symmetric subset of
V\times V
. A reader who is not interested in the applications to Borel combinatorics in Section
4
may safely assume that
V
is a finite set. In any case, each digraph that we consider has a finite maximal vertex degree.

A set
I\subset V(G)
is
independent in
G
if there are no edges in
G
, other than self-loops, which connect elements of
I
.

The
graph distance
between vertices
x
and
y
is the minimal number of edges in a (not necessarily directed) path that connects
x
and
y
. For
x\in V(G)
and
R\in\mathbb{N}
we let
N_{G}(x,R)
be the
ball of radius
R
around
x
, i.e. the set of those
y\in V(G)
whose graph distance to
x
is at most
R
.

We use some non-standard notation for neighbourhoods of vertices. The motivation for it will become clear in the next subsection when we discuss local rules. For
x\in V(G)
we define

(a)

\operatorname{Var}(x):=\{y\in V(G)\colon(x,y)\in E(G)\}
,

(b)

\operatorname{Cla}(x):=\{y\in V(G)\colon(y,x)\in E(G)\}
,

(c)

N(x):=\operatorname{Var}(x)\cup\operatorname{Cla}(x)
,
\deg(x):=|N(x)|
, and

(d)

\operatorname{max-deg}(G):=\max_{x\in V(G)}\deg(x)
,
\operatorname{max-outdeg}(G):=\max_{x\in V(G)}|\operatorname{Var}(x)|
.

If we need to point the dependence on
G
we use the notation
\operatorname{Var}_{G}(x)
,
\operatorname{Cla}_{G}(x)
,
N_{G}(x)
, and
\deg_{G}(x)
. Let us stress again that we allow self-loops; in particular,
x
may or may not be a member of either
\operatorname{Var}(x)
or
\operatorname{Cla}(x)
.

If
A
is a set of vertices then we let
\operatorname{Var}(A):=\bigcup_{x\in A}\operatorname{Var}(x)
,
\operatorname{Cla}(A):=\bigcup_{x\in A}\operatorname{Cla}(x)
, and
N(A):=\bigcup_{x\in A}N(x)
.

We define
\operatorname{Rel}(G)
to be the digraph on the same set of vertices as
G
, and such that
(x,y)\in E(\operatorname{Rel}(G))
if and only if
\operatorname{Var}_{G}(x)\cap\operatorname{Var}_{G}(y)\neq\emptyset
. Clearly
\operatorname{Rel}(G)
is a symmetric digraph, and there is a self-loop at every
x
such that
\operatorname{Var}_{G}(x)\neq\emptyset
.

2.b
Description of the algorithm

Our variant of the MTA depends on several choices. Some of them have very little influence on our analysis of the algorithm, but in this subsection, we take some time to spell out all the ingredients explicitly.

(a)

We recall that we have fixed a natural number
b>1
, which is the number of colours in our colouring problems. A
local rule
for a digraph
G
is a function
\mathbf{R}
whose domain is
V(G)
and such that for every
x\in V(G)
it holds that (i)
\mathbf{R}(x)\subset b^{\operatorname{Var}(x)}
, and (ii) if
\operatorname{Var}(x)=\emptyset
then
|\mathbf{R}(x)|=1
, or equivalently
\mathbf{R}(x)=b^{\operatorname{Var}(x)}
. A
colouring problem
is a pair
(G,\mathbf{R})
, where
G
is a digraph and
\mathbf{R}
is a local rule on
G
.

Given a function
f\in b^{V(G)}
and
x\in V(G)
, we let
\operatorname{res}_{x}(f)\in b^{\operatorname{Var}(x)}
be the restriction of
f
to
\operatorname{Var}(x)
. We say that
f

satisfies

\mathbf{R}
if for every
x\in V(G)
we have
\operatorname{res}_{x}(f)\in\mathbf{R}(x)
.

Remark 2.1
.

1.

Let us explain our choice of the notation
\operatorname{Var}(x)
and
\operatorname{Cla}(x)
. First, a vertex
x\in V(G)
has a colouring constraint attached to it, namely the set
\mathbf{R}(x)
. As such, we think of
\mathbf{R}(x)
as a logical clause whose variables are the vertices in
\operatorname{Var}(x)
. Second, it might be that
x\in\operatorname{Var}(y)
for some
y\in V(G)
. In this case
\mathbf{R}(y)
is a clause in which
x
“appears as a variable”, and this is the reason for the notation
\operatorname{Cla}(x)
: it is “the set of all clauses which contain
x
as a variable”.

2.

The condition (ii) in the definition of a local rule is to assure that if
x
is a clause without variables then
\mathbf{R}(x)
does not impose any constraints on colourings.

Given
\mathbf{R}
, we let
\mathbf{R}^{c}(x):=b^{\operatorname{Var}(x)}\setminus\mathbf{R}(x)
. For
f\colon V(G)\to b
we set

\operatorname{B}_{\mathbf{R}}(f):=\{x\in V(G)\colon\operatorname{res}_{x}(f)\in\mathbf{R}^{c}(x)\}.

We note that if
\operatorname{Var}(x)=\emptyset
then for all
f
we have
x\notin\operatorname{B}_{\mathbf{R}}(f)
. When
\mathbf{R}
is clear from the context we write
\operatorname{B}(f)
instead of
\operatorname{B}_{\mathbf{R}}(f)
. The notation
\operatorname{B}
comes from “bad set”, as
\operatorname{B}(f)
is the “bad set of
f
” i.e. the set of those clauses where
f
does not fulfil
\mathbf{R}
.

(b)

An
independence function
on a digraph
G=(V,E)
is a function
\operatorname{I}=\operatorname{I}_{G}\colon\operatorname{Pow}(V)\to\operatorname{Pow}(V)
with the property that for every
X\in{\mathcal{\operatorname{Pow}}}(V)
the set
\operatorname{I}(X)
is a maximal subset of
X
which is independent in
G
.

To avoid clutter, we will write
\operatorname{IB}(f)
instead of
\operatorname{I}_{\operatorname{Rel}(G)}(\operatorname{B}_{\mathbf{R}}(f))
throughout the article. Thus
\operatorname{IB}(f)
is a maximal collection of clauses violated by
f
such that no two share a variable.

(c)

A
partition
of
V(G)
is a finite set
\pi
of pairwise disjoint subsets of
V(G)
such that
V(G)=\bigcup_{W\in\pi}W
. We let
S_{\pi}\colon V(G)\to\pi
be the function defined by demanding that
x\in S_{\pi}(x)
for all
x\in V(G)
. We say that a partition
\pi
is
r
-sparse
if for every
x\in V(G)
the different points of
N_{G}(x,r)
belong to different elements of
\pi
. Equivalently,
\pi
is
r
-sparse if whenever
x\neq y
and
x
and
y
are in the same part then the graph distance between
x
and
y
is greater than
2r
.

A
Moser-Tardos tuple
is a tuple
(G,\mathbf{R},\pi)
, where
G
is a digraph,
\mathbf{R}
is a local rule on
G
and
\pi
is a partition of
V(G)
. Our version of the MTA depends on a Moser-Tardos tuple
{\mathcal{M}}=(G,\mathbf{R},\pi)
, an element
{\texttt{rnd}}\in b^{\pi\times\mathbb{N}}
which can be thought of as the source of random bits, and an independence function on
\operatorname{Rel}(G)
.

Remark 2.2
.

Although the algorithm depends on the choice of the independence function
\operatorname{I}
on
\operatorname{Rel}(G)
, we do not want to incorporate
\operatorname{I}
in the notation, because the details of how independent sets are constructed on a particular graph are irrelevant for the analysis of the algorithm. As such we will just tacitly assume that we have a function
\operatorname{I}
for every
({\mathcal{M}},{\texttt{rnd}})
; in fact it does not have to be a single function for the duration of the whole algorithm, it might also depend on the time, which will be useful in the proof of Corollary
2.10
below.

The outcome of the MTA is a sequence of functions
\operatorname{M}^{i}=\operatorname{M}^{i}_{{\mathcal{M}},{\texttt{rnd}}}\in b^{V(G)}
defined as follows.
We let
\operatorname{M}^{0}(x):={\texttt{rnd}}(S_{\pi}(x),0)
for all
x\in V(G)
, and we proceed to define the functions
\operatorname{M}^{i}
inductively.

Informally, if
\operatorname{M}^{i}
is already defined, then we take a maximal independent set of clauses where
\operatorname{M}^{i}
does not satisfy
\mathbf{R}
(i.e. a maximal subset of
\operatorname{B}_{\mathbf{R}}(\operatorname{M}^{i})
which is independent in
\operatorname{Rel}(G)
), and we use
rnd
to assign new values to the variables which are in those clauses. In other words, we resample the values for variables in
\operatorname{Var}(\operatorname{IB}(\operatorname{M}^{i}))
.

Let us write it in symbols now. We need a sequence of auxiliary functions
h^{j}=h^{j}_{{\mathcal{M}},{\texttt{rnd}}}\colon V(G)\to\mathbb{N}
counting the number of resamplings which the algorithm made at a given variable when defining
\operatorname{M}^{0},\operatorname{M}^{1},\ldots,\operatorname{M}^{j-1}
. We let
h^{0}(x):=0
and
h^{1}(x):=1
for all
x\in V(G)
.

Now suppose that for some
j\in\mathbb{N}
the functions
\operatorname{M}^{j}
and
h^{j+1}
are defined. For
x\in V(G)
we let

\operatorname{M}^{j+1}(x):=\left\{\begin{array}[]{l l}{\texttt{rnd}}(S_{\pi}(x),h^{j+1}(x))&\quad\mbox{if $x\in\operatorname{Var}(\operatorname{IB}(\operatorname{M}^{j}))$,}\\
\operatorname{M}^{j}(x)&\quad\mbox{otherwise,}\\
\end{array}\right.

(2.3)

and

h^{j+2}(x):=\left\{\begin{array}[]{l l}h^{j+1}(x)+1&\quad\mbox{if $x\in\operatorname{Var}(\operatorname{IB}(\operatorname{M}^{j}))$,}\\
h^{j+1}(x)&\quad\mbox{otherwise. }\\
\end{array}\right.

This finishes the description of the algorithm.

Let us define
h^{\infty}=h^{\infty}_{{\mathcal{M}},{\texttt{rnd}}}\colon V(G)\to\mathbb{N}\cup\{\infty\}
by setting
h^{\infty}(x):=\lim_{k\to\infty}h^{k}(x)
. For
{\texttt{rnd}}\in b^{\pi\times\mathbb{N}}
, we let
{\texttt{rnd}}_{l}\in b^{\pi\times l}
be the restriction of
rnd
to the set
\pi\times l=\pi\times\{0,\ldots,l-1\}
.

Remark 2.4
.

(a)

The algorithm described by (
2.3
) takes as its input a pair
({\mathcal{M}},{\texttt{rnd}})
, where
{\mathcal{M}}=(G,\mathbf{R},\pi)
is a Moser-Tardos tuple and
{\texttt{rnd}}\in b^{\pi\times\mathbb{N}}
. Frequently it will be convenient to think of
{\mathcal{M}}
as being fixed and regard the algorithm as depending only on
rnd
.

(b)

As described, the algorithm never terminates. This is because it is convenient in the proofs to have the functions
\operatorname{M}^{i}
defined for all
i\in\mathbb{N}
. However, by convention we say that our algorithm
succeeds
after
i
steps if
\operatorname{B}(\operatorname{M}^{i-1})=\emptyset
. Note that if this is the case then
\operatorname{M}^{j}=\operatorname{M}^{i-1}
for all
j\geqslant i-1
, and
\operatorname{M}^{i-1}
satisfies
\mathbf{R}
.

It will sometimes be convenient to only consider the first
k
steps of the algorithm, i.e. the algorithm described by (
2.3
) terminated after producing
\operatorname{M}^{k-1}
. This
k
-step MTA depends only on
{\texttt{rnd}}_{k}\in b^{\pi\times k}
.

(c)

We note that
h^{i}(x)
is defined so that the initial setting
\operatorname{M}^{0}(x)={\texttt{rnd}}(S_{\pi}(x),0)
is counted as a resampling of every variable. By definition,
h^{\infty}(x)
is the total number of resamplings that the algorithm makes at the variable
x
.

(d)

If for some
{\texttt{rnd}}\in b^{\pi\times\mathbb{N}}
we have
l:=\max_{x\in V(G)}h^{\infty}_{{\mathcal{M}},{\texttt{rnd}}}(x)<\infty
, then the algorithm succeeds for this instance of
rnd
, and furthermore the algorithm depends only on
{\texttt{rnd}}_{l}\in b^{\pi\times l}
.

2.c
Statement of the main result

For
R,d\in\mathbb{N}_{+}
and
{\varepsilon}>0
let
\operatorname{SubExp}(R,{\varepsilon},d)
be the class
of all digraphs
G
with
\operatorname{max-deg}(G)\leqslant d
, and such that for all
x\in V(G)
we have

|N_{G}(x,3R)|\leqslant(1+{\varepsilon})^{R}.

Our main result is the following theorem.

Theorem 2.5
.

Let
{\mathcal{M}}=(G,\mathbf{R},\pi)
be a Moser-Tardos tuple, let
{\Delta}:=\operatorname{max-deg}(\operatorname{Rel}(G))
, and let integers
R,d\in\mathbb{N}
and reals
{\varepsilon},\delta>0
be such that

(a)

G\in\operatorname{SubExp}(R,{\varepsilon},d)
,

(b)

the partition
\pi
is
3R
-sparse, and

(c)

we have

\max_{x\in V(G)}\frac{|\mathbf{R}^{c}(x)|}{b^{|\operatorname{Var}(x)|}}\leqslant\frac{1}{(\mathrm{e}{\Delta})^{1+\delta}\,b^{{\varepsilon}d}}.

(2.6)

Then there is a constant

Proof of Corollary
2.10
.

Let us describe the algorithm. Let
(G,\mathbf{R})
be its input. We start by finding a
3R
-sparse partition of
V(G)
with
|\pi|\leqslant d^{6R}
. This can be done in a linear time by first computing the graph power
G^{6R}
and applying the greedy algorithm for finding a vertex colouring in
G^{6R}
. Let
m
be a sufficently large constant to satisfy (
2.9
). Thus
m
depends only on
b,R,d
and
{\delta}
.

Let
{\mathcal{M}}:=(G,\mathbf{R},\pi)
. By the choice of
m
, there exists
{\texttt{rnd}}\in b^{\pi\times\mathbb{N}}
such that the algorithm’s run on
({\mathcal{M}},{\texttt{rnd}})
succeeds and accesses only
{\texttt{rnd}}_{m}\in b^{\pi\times m}
.

We have the following deterministic algorithm. The first “external loop" runs over all (constantly many) choices of
{\texttt{rnd}}_{m}\in b^{\pi\times m}
. For each such
rnd
, the “internal loop” runs our algorithm on
({\mathcal{M}},{\texttt{rnd}}_{m})
so that each pass of the internal loop does a single step of the MTA algorithm. We run the internal loop
until one of the two things happens: either
IB(\operatorname{M}^{i})
is empty at some moment, in which case we halt the whole algorithm and output
\operatorname{M}^{i}
, or the algorithm needs to access
{\texttt{rnd}}(\ast,m)
, that is, the
(m+1)
-st bit of some vertex, in which case we move to the next
{\texttt{rnd}}_{m}\in b^{\pi\times m}
. Note the internal loop resamples at most
|V(G)|\cdot m
variables and thus stops after at most
|V(G)|\cdot m
passes.

Let us describe in more detail how a single pass of the internal loop can be implemented.

Before the internal loop starts we define two lists: Currently-Violated and Potentially-Violated. Currently-Violated is the list of all clauses which are violated by
\operatorname{M}_{0}
; to define Potentially-Violated we start with Currently-Violated and we append all neighbours in
\operatorname{Rel}(G)
of the elements in Currently-Violated. The role of Potentially-Violated is that if a clause will be violated by
\operatorname{M}_{1}
then it is necessarily in Potentially-Violated. The lists Currently-Violated and Potentially-Violated will be updated at the end of each pass of the internal loop.

For each pass of the internal loop, we go through the clauses in Currently-Violated, and for each clause
C
we check if we have already encountered, in the current pass, a resampled clause
D
which is a neighbour of
C
in
\operatorname{Rel}(G)
. If this is the case then we move to the next clause in Currently-Violated, and otherwise, we resample the variables of
C
using
rnd
.

At the end of the pass, we define new lists Currently-Violated and Potentially-Violated as follows: first, we let new Currently-Violated consist of the entries of old Potentially-Violated which are violated, and then we let new Potentially-Violated consist of the new list Currently-Violated and all the neighbours in
\operatorname{Rel}(G)
of the elements of the new list Currently-Violated.

We terminate the internal loop if 1) at any point
{\texttt{rnd}}(\ast,m)
needs to be accessed, and then we move to the next
rnd
in the external loop, or 2) after some pass the list Currently-Violated is empty (which means that we found a satisfying assignment).

This finishes the description of the sequential deterministic algorithm. Let us argue that the internal loop indeed implements a single step of the parallel deterministic algorithm, that is, we resample variables corresponding to a maximal independent set of violated clauses. Since we resample each inspected clause if and only if it is violated and has no previously resampled neighbours in
\operatorname{Rel}(G)
, it remains to argue that every violated clause was inspected.
For this we note that for every
i\in\mathbb{N}
we have that before the
i
-th pass of the internal loop commences, the list Potentially-Violated contains all the clauses that are violated, together with all clauses that might be violated after the
i
-th pass finishes. Thus before the
i
-th pass commences, the list Currently-Violated contains all the violated clauses.

Let us show that
the presented sequential deterministic algorithm runs in linear time in
|V(G)|
. Of course, the initial computation of the lists Currently-Violated and Potentially-Violated from
\operatorname{M}_{0}
takes linear time. Also, in order to update these two lists during the
i
-th pass (when we compute and resample a maximal independent subset of
\operatorname{M}_{i-1}
) for
i=1,2,\ldots
, the algorithm needs to check only those clauses that share a variable with at least one clause in
\operatorname{B}(\operatorname{M}_{i-1})
, which is exactly the list Currently-Violated at the beginning of the pass.
Thus the total number of clause re-evaluations in our sequential algorithm (after
\operatorname{M}^{0}
and
\operatorname{B}(\operatorname{M}^{0})
have been computed) is at most

d^{2}\sum_{i=1}^{\infty}|\operatorname{B}(\operatorname{M}_{i-1})|\leqslant d^{4}\sum_{i=1}^{\infty}|\operatorname{IB}(\operatorname{M}_{i-1})|\leqslant d^{4}m\,|V(G)|,

where the second inequality uses the fact that the internal loop resamples at most
m\,|V(G)|
variables. Thus the sequential algorithm indeed runs in linear time.∎

3
Analysis of the algorithm

Let
{\mathcal{M}}=(G,\mathbf{R},\pi)
be a Moser-Tardos tuple.

Remark 3.1
.

We will first give the proof of Theorem
2.5

As such, the analysis of the algorithm is very similar to the analysis of other versions of the MTA that exist in the literature: we associate to each

which was utilised in the run of the algorithm on

. This, together with bounds on the number of landscapes of a given size, will lead to the desired bound.

The main reason to prove Theorem
2.5
first under the extra assumptions is to explain what needs to be modified for the general case of Theorem
2.5
. This explanation is presented at the end of Subsection

and we hope that it motivates well the remaining constructions which involve landscapes, which are presented in Subsections

Let

We say that

k
-complements

Remark 3.2
.

We will use several times the following simple observation: if we fix

for all

.

Let

and let

and have

. For

we define

\textsc{Used}^{k}_{{\mathcal{M}},{\texttt{rnd}}}(x)
to be the sequence

{\texttt{rnd}}(S_{\pi}(x),0),\ldots,{\texttt{rnd}}(S_{\pi}(x),h^{k}(x)-1).

If

then we let
\textsc{Unused}^{k}_{{\mathcal{M}},{\texttt{rnd}}}(x)

We note that
{\texttt{rnd}}_{k}(S_{\pi}(x),x)

3.a
Landscapes

Remark 3.3
.

A landscape is a combinatorial gadget which arises from
({\mathcal{M}},{\texttt{rnd}})
roughly as follows.
Recall that the algorithm at every step takes a maximal independent set
S
of
clauses that are violated, and resamples all variables which appear in
these clauses. After this, every invalid clause shares variables with some clause in
S
.

This leads to a structure of a directed graph: vertices are the pairs
(C,i)
, where
i
is a step, and

C
is a clause that is invalid after step
i
; and edges

(C,i)\to(D,i+1)
correspond to the “causal relation” which could
be very informally thought of as “
C
was invalid after step
i
; we resampled
C
in step
i+1
and this made
D
invalid after step
i+1
”.

We trim this directed graph to a forest and then add some decorations: (a) each variable remembers its final assignment, (b) each vertex
(C,i)
remembers the values of the variables of
C
from after
i
-th step.

The main point of associating a landscape to
({\mathcal{M}},{\texttt{rnd}})
is that it is possible to recover the function
\textsc{Used}^{k}_{{\mathcal{M}},{\texttt{rnd}}}
from the landscape.

Let us now proceed with precise definitions. Let
G
be a digraph. We define a digraph
\operatorname{Canvas}(G)
as follows. The set of vertices of
\operatorname{Canvas}(G)
is
V(G)\times\mathbb{N}
. For every edge
(x,y)
in
\operatorname{Rel}(G)
and every
i\in\mathbb{N}
we add an edge
((x,i),(y,i+1))
to
\operatorname{Canvas}(G)
. Note that, since the digraph
\operatorname{Rel}(G)
is symmetric, the edge
((y,i),(x,i+1))
is also added to
\operatorname{Canvas}(G)
.
If
(x,i)\in V(G)\times\mathbb{N}
then we refer to
i
as the
level
of
(x,i)
.

A
G
-forest
is a subdigraph
{\mathcal{F}}
of
\operatorname{Canvas}(G)
such that each vertex of
{\mathcal{F}}
has in-degree equal to either
0
or
1
. We note that
{\mathcal{F}}
is a forest, and we let
\operatorname{Trees}({\mathcal{F}})
be the set of connected components of
{\mathcal{F}}
. For
\tau\in\operatorname{Trees}({\mathcal{F}})
we let
\rho(\tau)\in V(\tau)
be the
root
, i.e. the unique vertex with minimal level, and we define
\ell(\tau)\in\mathbb{N}
to be the level of
\rho(\tau)
. If for all
\tau\in\operatorname{Trees}({\mathcal{F}})
we have
\ell(\tau)=0
then we say that
{\mathcal{F}}
is
grounded
.

The
height
of
{\mathcal{F}}
is the minimal
j\in\mathbb{N}\cup\{\infty\}
such that for all
(x,i)\in V({\mathcal{F}})
we have
i<j
. In particular, the unique
G
-forest with no vertices has height
0
.

We say that
{\mathcal{F}}
is
independent
if for all
i\in\mathbb{N}
the set
\{x\in V(G)\colon(x,i)\in V({\mathcal{F}})\}
is an independent set in
\operatorname{Rel}(G)
.

Let
{\mathcal{M}}=(G,\mathbf{R},\pi)
be a Moser-Tardos tuple. An
{\mathcal{M}}
-landscape
is a pair
{\mathcal{L}}=({\mathcal{F}},\operatorname{\textsc{Viol}})
, where
{\mathcal{F}}
is an independent
G
-forest, and
\operatorname{\textsc{Viol}}
is a function with domain
V({\mathcal{F}})
such that for all
(x,i)\in V({\mathcal{F}})
we have
\operatorname{\textsc{Viol}}(x,i)\in\mathbf{R}^{c}(x)
.

Remark 3.4
.

Let us informally motivate the choice of the name
\operatorname{\textsc{Viol}}
. It is a shorthand for “Violation”. We will shortly see that in the landscape associated to a run of the algorithm, we have that
\operatorname{\textsc{Viol}}(x,i)
encodes the way in which the clause
x
is violated in
\operatorname{M}^{i}
.

We say that a landscape
{\mathcal{L}}=({\mathcal{F}},\operatorname{\textsc{Viol}})
is
grounded
, or of

, if
{\mathcal{F}}
has the respective property. Furthermore we define
V({\mathcal{L}}):=V({\mathcal{F}})
and
\operatorname{Trees}({\mathcal{L}}):=\operatorname{Trees}({\mathcal{F}})
.

A
finalised
{\mathcal{M}}
-landscape
is a tuple
({\mathcal{F}},\operatorname{\textsc{Viol}},\operatorname{\textsc{Final}})
where
({\mathcal{F}},\operatorname{\textsc{Viol}})
is an
{\mathcal{M}}
-landscape of finite height, and
\operatorname{\textsc{Final}}\in b^{V(G)}
.

3.a.1
Landscapes associated to a run of the MTA

Let
{\mathcal{M}}=(G,\mathbf{R},\pi)
be a Moser-Tardos tuple, and let
{\texttt{rnd}}\in b^{\pi\times\mathbb{N}}
. Let
<
be a total order on
V(G)
. We now proceed to define an
{\mathcal{M}}
-landscape associated to the run of the algorithm on
({\mathcal{M}},{\texttt{rnd}},<)
. The order plays a very minor role in the definition of this landscape and the subsequent analysis, so we will be slightly imprecise and denote it by
{\mathcal{L}}_{{\mathcal{M}},{\texttt{rnd}}}

We start with defining an independent
G
-forest
{\mathcal{F}}={\mathcal{F}}_{{\mathcal{M}},{\texttt{rnd}}}
. First, we let

V({\mathcal{F}}):=\bigcup_{i\in\mathbb{N}}\left(\operatorname{IB}(\operatorname{M}^{i})\times\{i\}\right).

Let us now describe the edges in
{\mathcal{F}}
. First, we need the following lemma.

Lemma 3.5
.

If
(x,i+1)\in V({\mathcal{F}})
then
there exists
(y,i)\in V({\mathcal{F}})
such that
\operatorname{Var}_{G}(x)\cap\operatorname{Var}_{G}(y)\neq\emptyset
(we do not demand that
x\neq y
).

Proof.

First note that if
(x,i+1)\in V({\mathcal{F}})
then in particular
\operatorname{Var}(x)\neq\emptyset
, and hence
\operatorname{Var}(x)\cap\operatorname{Var}(x)\neq\emptyset

Let us now assume, by way of contradiction, that there is no
(y,i)\in V({\mathcal{F}})
such that
\operatorname{Var}(x)\cap\operatorname{Var}(y)\neq\emptyset

x\notin\operatorname{IB}(\operatorname{M}^{i})

It follows that no variables of the clause

were resampled when passing from
\operatorname{M}^{i}
to
\operatorname{M}^{i+1}
. Hence,
x\in\operatorname{B}(\operatorname{M}^{i})

\operatorname{IB}(\operatorname{M}^{i})\not\ni x

\operatorname{B}(\operatorname{M}^{i})\ni x

\operatorname{IB}(\operatorname{M}^{i})
must include some

, a contradiction.
∎

Now given

we take the minimal element

(which is nonempty by the previous lemma), and we add the edge

. This finishes the definition of

Now let

We also define, for every

3.a.2
The sequence encoded by a finalised landscape

Let
{\mathcal{M}}=(G,\mathbf{R},\pi)

\textsc{Used}_{{\mathcal{L}}}\colon V(G)\to b^{\oplus\mathbb{N}}

If there is
(y,i)\in V({\mathcal{F}})

,

Let

For any

\operatorname{H}({\mathcal{F}}):=|V(G)|+\sum_{(x,i)\in V({\mathcal{F}})}|\operatorname{Var}(x)|\in\mathbb{N}\cup\{\infty\},

Lemma 3.8
.

Let
{\mathcal{M}}=(G,\mathbf{R},\pi)
be a Moser-Tardos tuple, and let
{\mathcal{L}}=({\mathcal{F}},\operatorname{\textsc{Viol}},\operatorname{\textsc{Final}})
be a finalised
{\mathcal{M}}
-landscape. We have

\operatorname{len}(\textsc{Used}_{{\mathcal{L}}})=\operatorname{H}({\mathcal{F}}).

(3.9)

Furthermore, if
{\mathcal{L}}={\mathcal{L}}^{k}_{{\mathcal{M}},{\texttt{rnd}}}

\sum_{x\in V(G)}h^{k}_{{\mathcal{M}},{\texttt{rnd}}}(x)=\operatorname{len}(\textsc{Used}_{{\mathcal{L}}}).

(3.10)

Proof.

The equality (

|V(G)|+\sum_{(y,i)\in V({\mathcal{F}})}|\operatorname{Var}(y)|,

whereas the left-hand side is equal to

\sum_{x\in V(G)}\operatorname{len}(\textsc{Used}_{{\mathcal{L}}}(x))=\sum_{x\in V(G)}\big(1+|\{(y,i)\in V({\mathcal{F}})\colon x\in\operatorname{Var}(y)\}|\big).

such that
x\in\operatorname{Var}(y)

).

We note that

h^{k}_{{\mathcal{M}},{\texttt{rnd}}}(x)=\operatorname{len}(\textsc{Used}^{k}_{{\mathcal{M}},{\texttt{rnd}}}(x)),

and so the left-hand side of (

) is equal to
\operatorname{len}(\textsc{Used}^{k}_{{\mathcal{M}},{\texttt{rnd}}})
. Since Lemma

shows that
\textsc{Used}_{{\mathcal{M}},{\texttt{rnd}}}^{k}=\textsc{Used}_{{\mathcal{L}}^{k}_{{\mathcal{M}},{\texttt{rnd}}}}

3.b
Counting landscapes

Let
{\mathcal{M}}=(G,\mathbf{R},\pi)
be a Moser-Tardos tuple. For a given
m\in\mathbb{N}
, we want to bound the number of grounded finalised
{\mathcal{M}}
-landscapes
({\mathcal{F}},\operatorname{\textsc{Viol}},\operatorname{\textsc{Final}})
such that
|V({\mathcal{F}})|=m
. The most important part is counting the possibilities for
{\mathcal{F}}
, and this is what we proceed to do now.

Let
{\Delta}\in\mathbb{N}
. A
{\Delta}
-labelled tree
is a finite directed tree such that at each vertex the in-degree is either
0
or
1
, and such that the edges are labelled by the elements of
{\Delta}=\{0,\ldots,{\Delta}-1\}
, in such a way that at each vertex all the out-going edges have different labels. The
root
of a
{\Delta}
-labelled tree is the unique vertex whose in-degree is equal to
0
.

It is convenient to regard the empty digraph as a
{\Delta}
-labelled tree on
0
vertices. An
isomorphism
between two
{\Delta}
-labelled trees is a graph isomorphism that preserves directions and edge labels (and thus, in particular, it preserves the root). By the
iso-class
of
T
we will mean the class of all trees isomorphic to
T
.

Lemma 3.11
.

(a)

For
i\in\mathbb{N}_{+}
let
P_{i}
be the number of iso-classes of
{\Delta}
-labelled trees with
i
vertices. We have
P_{i}\leqslant(\mathrm{e}{\Delta})^{i}
.

(b)

For
k,i\in\mathbb{N}
let
R_{k,i}
be the number of all finite sequences
(T_{0},\ldots,T_{k-1})
of iso-classes of
{\Delta}
-labelled trees such that
\sum_{j=0}^{k-1}|V(T_{j})|=i
. We have
R_{k,i}\leqslant(i+1)^{k-1}(\mathrm{e}{\Delta})^{i}
.

Proof.

(a)

This proof is based on the presentation in
[
29
]
. In fact, we will show that
P_{i}\leqslant\left(\frac{{\Delta}^{\Delta}}{({\Delta}-1)^{{\Delta}-1}}\right)^{i}
, which implies the claim by
(\frac{{\Delta}}{{\Delta}-1})^{{\Delta}-1}\leqslant\mathrm{e}
for every
{\Delta}\geqslant 1
.

Let us consider the formal power series:

P(X):=\sum_{i=0}^{\infty}P_{i}\cdot X^{i}.

Let
\rho:=\frac{({\Delta}-1)^{{\Delta}-1}}{{\Delta}^{\Delta}}
. Since
P_{i}\geqslant 0
and
P_{0}=1
, it is enough to show that
P
converges at
\rho
and
P(\rho)\leqslant P_{0}+1=2
. In fact we will show that
P(\rho)\leqslant\frac{{\Delta}}{{\Delta}-1}
.

For
i,j\in\mathbb{N}
let us define the numbers
Q_{i,j}\in\mathbb{N}
as follows. For all
i,j\in\mathbb{N}
let
Q_{i,j}
be the number of
{\Delta}
-labelled trees with
j
vertices and such that all vertices are at the distance at most
i
from the root. By convention we set
Q_{i,0}:=1
for all
i\in\mathbb{N}
.
Let

Q_{i}(X):=\sum_{j=0}^{\infty}Q_{i,j}X^{j}.

We have that
Q_{i}
’s are polynomials since
Q_{i,j}=0
when
j
is large enough. The following claim is clear from the definitions.

Claim
.

The polynomials
Q_{i}
have non-negative real coefficients, and for all
n\in\mathbb{N}
and all
i>n
we have that the first
n
coefficients of
Q_{i}(X)
are equal to the first
n
coefficients of
P(X)
.∎

Since both
Q_{i}
’s and
P
have non-negative coefficients, we obtain the following claim as a corollary.

Claim
.

If for some
x>0
the sequence
Q_{0}(x),Q_{1}(x),\ldots
is bounded by
y\in\mathbb{R}
, then the power series
P(X)
converges at
x
and we have
P(x)\leqslant y
.∎

We proceed to use the above claim to establish that
P(\rho)\leqslant\frac{{\Delta}}{{\Delta}-1}
. For this let us show by induction that for all
i\in\mathbb{N}
we have
Q_{i}(\rho)\leqslant\frac{{\Delta}}{{\Delta}-1}
. Since
Q_{0}(X)=1+X
, we have
Q_{0}(\rho)=1+\rho\leqslant 1+\frac{1}{{\Delta}-1}=\frac{{\Delta}}{{\Delta}-1}
. Thus let us assume that for some
i\in\mathbb{N}
we have
Q_{i}(\rho)\leqslant\frac{{\Delta}}{{\Delta}-1}
.

Note that a
\Delta
-labelled tree whose all vertices are at a distance at most
i+1
from the root is either the empty tree, or consists of the root and a sequence of exactly
{\Delta}
trees (some of which might be empty), each of which has all vertices at distance at most
i
from its root. This leads us to the following equation valid for all
i\in\mathbb{N}
:

Q_{i+1}(X)=1+XQ_{i}(X)^{\Delta}.

Thus, using the inductive assumption, we have

Q_{i+1}(\rho)\leqslant 1+\rho\cdot\left(\frac{{\Delta}}{{\Delta}-1}\right)^{\Delta}=\frac{{\Delta}}{{\Delta}-1},

which finishes the proof of (a).

(b)

Let us set
R_{k}(X):=\sum_{i=0}^{\infty}R_{k,i}X^{i}
. Then we have
R_{k}(X)=P(X)^{k}
. Thus by the previous part, we can bound the coefficients of
R_{k}
from above by the respective coefficients of the series

S_{k}(X):=\left(\sum_{i=0}^{\infty}(\mathrm{e}{\Delta}X)^{i}\right)^{k}.

Let us show by induction on
k
that the
i
-th coefficient
S_{k,i}
of
S_{k}(X)=\sum_{i=0}^{\infty}S_{k,i}X^{i}
is bounded from above by
(i+1)^{k-1}(\mathrm{e}{\Delta})^{i}
. The inductive statement is clearly true for
k=1
, so let us assume that it is true for some
k
. We write

S_{k+1}(X)=S_{k}(X)\cdot\left(\sum_{i=0}^{\infty}(\mathrm{e}{\Delta}X)^{i}\right),

and so

\displaystyle S_{k+1,i}=\sum_{j=0}^{i}S_{k,j}\,(\mathrm{e}{\Delta})^{i-j}

\displaystyle\leqslant\sum_{j=0}^{i}(j+1)^{k-1}(\mathrm{e}{\Delta})^{j}(\mathrm{e}{\Delta})^{i-j}

\displaystyle\leqslant(i+1)(i+1)^{k-1}(\mathrm{e}{\Delta})^{i}

\displaystyle=(i+1)^{k}(\mathrm{e}{\Delta})^{i},

which finishes the proof of the inductive statement, and the proof of (b).∎

Lemma 3.12
.

Let
G
be a finite digraph, let
{\mathcal{M}}=(G,\mathbf{R},\pi)
be a Moser-Tardos tuple, let
{\beta}:=\max_{x\in V(G)}\frac{|\mathbf{R}^{c}(x)|}{|b^{\operatorname{Var}(x)}|}
, and let

be a

-forest of finite height. The number of

-landscapes

is at most

{\beta}^{|V({\mathcal{F}})|}\cdot b^{\operatorname{H}({\mathcal{F}})-|V(G)|}.
∎

Proof.

For every
(x,i)\in V({\mathcal{F}})
we have that
\operatorname{\textsc{Viol}}(x)\in\mathbf{R}^{c}(x)
. As such there are

\prod_{(x,i)\in V({\mathcal{F}})}|\mathbf{R}^{c}(x)|=\prod_{(x,i)\in V({\mathcal{F}})}\left(\frac{|\mathbf{R}^{c}(x)|}{|b^{\operatorname{Var}(x)}|}\cdot|b^{\operatorname{Var}(x)}|\right)

possibilities for

, which is bounded from above by

{\beta}^{|V({\mathcal{F}})|}\cdot b^{\sum_{(x,i)\in V({\mathcal{F}})}\operatorname{Var}(x)}={\beta}^{|V({\mathcal{F}})|}\cdot b^{\operatorname{H}({\mathcal{F}})-|V(G)|}.

This finishes the proof.
∎

Let

3.c
Interlude: Analysis of the classical MTA

We are now in a position to prove a variant of Theorem

under the assumption that
G
is finite and
\pi
consists of singletons of all vertices in
V(G)
.

The following theorem essentially replicates the known results about the standard MTA. Presenting the proof in this special case will allow us to motivate better the upcoming subsections.

Theorem 3.14
.

Let
G
be a finite digraph, let
{\mathcal{M}}=(G,\mathbf{R},\pi)
be a Moser-Tardos tuple such that
\pi
consists of the singletons of all vertices of
G
. Let
{\Delta}:=\operatorname{max-deg}(\operatorname{Rel}(G))
and

. Suppose that

{\beta}:=\max_{x\in V(G)}\frac{|\mathbf{R}^{c}(x)|}{|b^{\operatorname{Var}(x)}|}\leqslant\frac{1}{(\mathrm{e}{\Delta})^{1+\delta}}.

(3.15)

Then for all

\operatorname{\mathbb{P}}_{{\texttt{rnd}}}\left(|V({\mathcal{L}}^{k}_{{\mathcal{M}},{\texttt{rnd}}})|=m\right)\leqslant\frac{d\,|V(G)|\,(m+1)^{|V(G)|}}{(\mathrm{e}{\Delta})^{\delta\cdot m}}.

Remark 3.17
.

(a)

We note that the event

means exactly that the number of clauses resampled in the process of constructing

is equal to

.

(b)

The expected total number of resampled clauses is the quantity

.
Note there is

(which does not depend on

) such that if we define

then the right-hand side of (

) (which decreases exponentially fast with

for

and, for each

, decreases by factor at least

when we increase

by

. It follows that the expectation of
\operatorname{\mathbb{E}}_{{\texttt{rnd}}}(|V({\mathcal{L}}^{k}_{{\mathcal{M}},{\texttt{rnd}}})|)
is at most

. As such we deduce that
\operatorname{\mathbb{E}}_{{\texttt{rnd}}}(|V({\mathcal{L}}_{{\mathcal{M}},{\texttt{rnd}}})|)
is also bounded by
O(m_{0})=O(|V(G)|\log|V(G)|)
.

Proof of Theorem
3.14
.

Take any
k\in\mathbb{N}
. Recall that
{\mathcal{L}}_{{\mathcal{M}},{\texttt{rnd}}}
is the
{\mathcal{M}}
-landscape associated to

.

Claim
.

Let
{\mathcal{L}}
be a finalised grounded
{\mathcal{M}}
-landscape of height

. The number of functions
{\varphi}\colon V(G)\to b^{\oplus\mathbb{N}}
such that

Let
{\varphi}
come from some

. Then, for all

, we have that

is a sequence of length

\operatorname{len}(\textsc{Unused}_{{\mathcal{L}}^{k}_{{\mathcal{M}},{\texttt{rnd}}}}(x))=k-\operatorname{len}(\textsc{Used}_{{\mathcal{L}}^{k}_{{\mathcal{M}},{\texttt{rnd}}}}(x))=k-\operatorname{len}(\textsc{Used}_{{\mathcal{L}}}(x)).

If we sum this over all

by Lemma

. Now the claim follows from Remark
3.2
.
∎

Let us fix

. For

let

P_{m,v}:=\operatorname{\mathbb{P}}_{{\texttt{rnd}}}\left(|V({\mathcal{L}}^{k}_{{\mathcal{M}},{\texttt{rnd}}})|=m,\operatorname{H}({\mathcal{L}}^{k}_{{\mathcal{M}},{\texttt{rnd}}})=v\right),

and let

which is the same as the left-hand side of (

Note that by our assumption on

, the probability space of which

This implies that we have

\displaystyle P_{m,v}\leqslant\frac{1}{b^{k|V(G)|}}\cdot|\{({\mathcal{L}},{\varphi})\colon

{\mathcal{L}}

-landscape,

(3.18)

\displaystyle|V({\mathcal{L}})|=m,\operatorname{H}({\mathcal{L}})=v,

\displaystyle\text{$({\mathcal{L}},{\varphi})=({\mathcal{L}}^{k}_{{\mathcal{M}},{\texttt{rnd}}},\textsc{Unused}^{k}_{{\mathcal{M}},{\texttt{rnd}}})$ for some ${\texttt{rnd}}\in b^{V(G)\times\mathbb{N}}$}\}|.

3.d
Some ideas behind re-using random bits

Let us informally describe what needs to be modified in order to prove Theorem
2.5
. In Theorem
3.14
we had an element
{\texttt{rnd}}\in b^{V(G)\times\mathbb{N}}
, i.e. each vertex has “its own stream of randomness”. In Theorem
2.5
this is no longer the case since
{\texttt{rnd}}\in b^{\pi\times\mathbb{N}}
, so there are only
|\pi|
streams of randomness, no matter how big the digraph
G
is. However the number of landscapes is still exponential in
|V(G)|
, because the number of
G
-forests is exponential in
|V(G)|
. Since the inequality (
3.18
) would start with
\frac{1}{b^{k|\pi|}}
on the right-hand side, it would not provide any interesting information because the right-hand side would be strictly larger than
1
(in fact exponentially large in
|V(G)|
).

The remedy is to restrict the landscape to a carefully chosen subset
U\subset V(G)
on which
\pi
induces a singleton partition. The choice of this subset is different for different
{\texttt{rnd}}\in b^{\pi\times k}
; essentially, we take a ball
U
of carefully chosen (bounded) radius
r

around one of the most resampled vertices
y
. Although the restriction of the finalised landscape to
U
does not in general allow us to reconstruct all random bits used at
U
, it does determine the used bits for every
x\in U
such that all clauses containing
x
are entirely inside
U
.
By choosing
r
carefully (using the assumption of subexponential growth), we can ensure that the number of “boundary” clauses is much smaller than the number of “internal” clauses and, additionally, the restriction of
\pi
to
U
is injective. The main new idea is roughly to restrict the argument of Theorem
3.14
to the set
U
(where no input bit is re-used), using the trivial upper bound of
b
for the number of choices of each unknown random bit inside
U
and doing the union bound over all possible restrictions of
G
to
U
(where there are only bounded many choices up to a
\pi
-preserving isomorphism).

However, when we restrict a grounded landscape to
U
, it does not need to be grounded anymore, while the bounds in Corollary
3.13
are valid only for grounded landscapes. As such we have to find a grounded landscape on
U
which is equivalent (meaning that the functions that turns landscape decorations into sequences of used bits are the same for the two landscapes).

The next two subsections of this section are about defining the restrictions of landscapes and finding equivalent grounded landscapes, respectively. After discussing these preliminaries, we will prove Theorem
2.5
in the third remaining subsection.

3.e

Let
{\mathcal{M}}=(G,\mathbf{R},\pi)

3.f
Equivalent landscapes

Let
{\mathcal{M}}=(G,\mathbf{R},\pi)

{\mathcal{M}}
-landscapes. We say that

\operatorname{H}({\mathcal{L}})=\operatorname{H}({\mathcal{K}})
, since
\operatorname{H}({\mathcal{L}})=\operatorname{len}(\textsc{Used}_{{\mathcal{L}}})

The purpose of this subsection is to prove the following proposition.

Proposition 3.23
.

Let
{\mathcal{M}}=(G,\mathbf{R},\pi)
be a Moser-Tardos tuple with finite

, and let
{\mathcal{L}}
be a finalised
{\mathcal{M}}
-landscape. There exists a grounded finalised landscape

which is equivalent to

Borel version of the Lovász Local Lemma

In this section, we derive a Borel version of the Lovász Local Lemma (Theorem
4.5
here). A derivation of Theorem
4.5
from Theorem
2.5
is rather routine for experts; however, we present some details for the sake of completeness.

Let
G=(V,\mathcal{B},E)
be a
Borel digraph
, that is,
(V,E)
is a digraph,
(V,\mathcal{B})
is a standard Borel space and the edge set
E
is Borel as a subset of
V\times V
. (We refer the reader to
[
27
]
for all omitted
definitions.) As always throughout the article, we assume that
\operatorname{max-deg}(G)<\infty
. Also, for
r\in\mathbb{N}
and Borel functions
\ell
and
\ell^{\prime}
defined on
V
, we say that
\ell^{\prime}
is an
r
-local function
of
(G,\ell)
if the value of
\ell^{\prime}
on any vertex
x\in V
depends only on the isomorphism type of the restriction of the labelled rooted graph
(G,\ell,x)
to the
r
-ball
N_{G}(x,r)
.

We say that a finite partition
\pi
of
V
is
Borel
if all elements of
\pi
are Borel as subsets of
V
. If
\pi
is Borel then the map
S_{\pi}\colon V\to\pi
is Borel.

Lemma 4.1
.

Let
G=(V,\mathcal{B},E)
be a Borel digraph with all degrees bounded. Then, for any
r\in\mathbb{N}
there exists a Borel finite partition of
V
which is
r
-sparse.

Proof.

Consider the unordered graph
\tilde{G}=(V,\tilde{E})
where

\tilde{E}:=(E\cup\{(y,x)\mid(y,x)\in E\})\setminus\{(x,x)\mid x\in V\},

(4.2)

that is, we ignore the loops and the orientation of the arcs of
G
. The edge set
\tilde{E}
is a Borel subset of
V^{2}
as a Boolean
combination of Borel sets. (For example, the diagonal
\{(x,x)\mid x\in V\}
is a closed and thus Borel subset of
V^{2}
.)
By
[
20
, Proposition 4.6]
(or by
[
27
, Corollary 5.9]
),
the graph
\tilde{G}
, which is Borel and of bounded degree, admits a Borel
r
-sparse finite partition
\pi
. By definition,
the partition
\pi
is also
r
-sparse with respect to the digraph
G
.
∎

Next, we are going to define when a local rule
\mathbf{R}
is Borel.
Let us fix a Borel
2
-sparse partition
\pi
of
G
. The
2
-sparseness ensures that, for each
x\in V
, the labelling
S_{\pi}:V\to\pi
is injective on
\operatorname{Var}(x)
.
Thus, in order to specify the rule
\mathbf{R}(x)
at
x\in V
, it is enough to specify the set
\{\psi\in b^{\pi}\mid\psi\circ(S_{\pi})_{|\operatorname{Var}(x)}\in\mathbf{R}(x)\}
. Clearly, this set uniquely determines
\mathbf{R}(x)
. This gives a natural encoding of
\mathbf{R}
by a function
\ell_{\mathbf{R}}:V\to\operatorname{Pow}(b^{\pi})
. We say that the local rule
\mathbf{R}
is
Borel
if the function
\ell_{\mathbf{R}}
is Borel.

Let us argue that this definition (whether
\mathbf{R}
is Borel or not) does not depend on the choice of
\pi
.
Let
\pi^{\prime}
be another Borel
2
-sparse partition, with the corresponding encoding
\ell^{\prime}_{\mathbf{R}}
. We can compute
\ell^{\prime}_{\mathbf{R}}
at any
x\in V
from
\ell_{\mathbf{R}}(x)
and the restriction of
(S_{\pi},S_{\pi^{\prime}}):V\to\pi\times\pi^{\prime}
to the
1
-ball
N(x,1)
around
x
. This means that
\ell^{\prime}_{\mathbf{R}}
is a 1-local function of
(G,(\ell_{\mathbf{R}},S_{\pi},S_{\pi^{\prime}}))
. Now the fact that
\ell^{\prime}_{\mathbf{R}}
is Borel if and only if
\ell_{\mathbf{R}}
is Borel follows from the following general result.

Lemma 4.3
.

Let
G=(V,\mathcal{B},E)
be a Borel digraph with bounded degrees,
r\in\mathbb{N}
, and
\ell
be a Borel vertex labelling of
G
that assumes countably many values. Let
\ell^{\prime}
be an
r
-local function of
(G,\ell)
. Then the labelling
\ell^{\prime}
is Borel.

Proof.

This is a folklore result whose formal proof for (unordered) graphs can be found in
[
27
, Lemma 5.17]
. In order to apply it to our digraph
G
, we consider
the bipartite graph
H
whose vertex set is
V\times\{0,1\}
and whose edge set consists of (unordered) pairs
\{(x,0),(x,1)\,\}
for every
x\in V
as well as pairs
\{\,(x,0),(y,1)\,\}
for every
(x,y)\in E
. It is routine to show that
H
is a Borel graph. It comes with the Borel vertex labelling
\ell_{H}
that maps
(x,i)\in V(H)
to
(\ell(x),i)
. Note that
(x,i)\mapsto\ell^{\prime}(x)
is a
2r
-local function of
(H,\ell_{H})
. (Indeed, a walk along an arc
(x,y)\in E(G)
can be replaced by the length-2 path in
H
visiting the vertices
(x,0),(y,1),(y,0)
in this order and isomorphism type of the restriction of
(G,\ell,x)
to the
r
-ball round
x
is determined by the isomorphism type of the restriction of
(H,\ell_{H},(x,0))
to the
2r
-ball around
(x,0)
.)
Thus the labelling
\ell^{\prime}
is Borel
by
[
27
, Lemma 5.17]
.
∎

Lemma 4.4
.

Let
G=(V,\mathcal{B},E)
be a Borel digraph with
\operatorname{max-deg}(G)<\infty
.

(a)

For every Borel
A\subset V
there is a maximal independent set
B\subset A
which is a Borel subset of
V
.

(b)

If
\mathbf{R}
is a Borel local rule on
G
then, for every Borel labelling
f:V\to b
, the set
B_{\mathbf{R}}(f)\subset V
of failed clauses is Borel.

Proof.

Recall that by an independent set in the digraph
G
we mean an independent set in the underlying loopless Borel graph
\tilde{G}=(V,\tilde{E})
, where
\tilde{E}
is defined in (
4.2
). Thus Part (a) follows from the corresponding graph result of Kechris, Solecki and Todorcevic
[
20
, Proposition 4.2]
(which is Theorem 5.6 in
[
27
]
).

For Part (b), fix a Borel
2
-sparse partition
\pi
of
V
and use it to encode the local rule
\mathbf{R}
by the Borel labelling
\ell_{\mathbf{R}}
as above. For a clause
x\in V
, we can decide if it is failed by
f
by knowing the restriction of
(G,(f,\ell_{\mathbf{R}},S_{\pi}),x)
to
\operatorname{Var}(x)\subset B_{1}(x)
.
Thus
B_{\mathbf{R}}(f)
is Borel by the case
r=1
of Lemma
4.3
.
∎

A
Borel Moser-Tardos tuple
is a tuple
(G,\mathbf{R},\pi)

where
G
is a Borel digraph with finite
\operatorname{max-deg}(G)
,
\mathbf{R}
is a Borel local rule on
G

and
\pi
is a Borel partition. Let
\Delta\in\mathbb{N}
be an upper bound on the maximum degree of
\operatorname{Rel}(G)
. Given
{\texttt{rnd}}\in b^{\pi\times\mathbb{N}}
we
define the function
\operatorname{M}^{i+1}_{{\mathcal{M}},{\texttt{rnd}}}
by the formulas in
Subsection
2.b
where we apply Part (b) of Lemma
4.4
to find a maximal Borel subset of
B_{\mathbf{R}}(\operatorname{M}^{i}_{{\mathcal{M}},{\texttt{rnd}}})
. Part (b) of Lemma
4.1
gives by induction on
i
that each function
\operatorname{M}^{i}_{{\mathcal{M}},{\texttt{rnd}}}
is Borel.

A
Borel colouring problem
is a pair
({\mathcal{G}},\mathbf{R})
where
G
is a Borel digraph and
\mathbf{R}
is a Borel local rule on
G
.

Theorem 4.5
.

Let
(G,\mathbf{R})
be a Borel colouring problem such that
G\in\operatorname{SubExp}(R,{\varepsilon},d)
. Let
{\Delta}:=\operatorname{max-deg}(\operatorname{Rel}(G))
and let us assume that

\max_{x\in V(G)}\frac{b^{{\varepsilon}d}\,|\mathbf{R}^{c}(x)|}{b^{|\operatorname{Var}(x)|}}<\frac{1}{\mathrm{e}{\Delta}}.

Then there exists a satisfying colouring
f\in b^{V(G)}
which is Borel.

Proof.

Let
{\delta}>0
be such that

\max_{x\in V(G)}\frac{b^{{\varepsilon}d}\,|\mathbf{R}^{c}(x)|}{b^{|\operatorname{Var}(x)|}}=\frac{1}{(\mathrm{e}{\Delta})^{1+\delta}},

and let
\pi
be a
3R
-sparse Borel partition of
V(G)
with finitely many parts, which exists by Lemma
4.1
. Let
{\mathcal{M}}
be the Borel Moser-Tardos tuple
(G,\mathbf{R},\pi)
. Now by Theorem
2.5
, it holds for a.e.
{\texttt{rnd}}\in b^{\pi\times\mathbb{N}}
that
h^{\infty}_{{\mathcal{M}},{\texttt{rnd}}}(x)<\infty
for every
x\in V(G)
. Let us fix one such
rnd
. In particular, we obtain a sequence of Borel colourings
\operatorname{M}^{0},\operatorname{M}^{1},\ldots
of
V(G)
. Furthermore, for each
x\in V(G)
, the statement that
h^{\infty}_{{\mathcal{M}},{\texttt{rnd}}}(x)<\infty
implies that the values
\operatorname{M}^{k}(x)
stabilise from some moment on; define
\operatorname{M}^{\infty}(x):=\lim_{k\to\infty}\operatorname{M}^{k}(x)
to be this eventual colour.
Clearly the function
\operatorname{M}^{\infty}
is Borel.

It remains to verify that
\operatorname{M}^{\infty}
is a satisfying colouring. Take any
x\in V(G)
. Let
k\in\mathbb{N}
be such that
no clause sharing a variable with the clause
x
is resampled after the
k
-th pass; such
k
exists since these clauses involve finitely many (namely, at most
d^{3}
) variables in total.
Thus, for every
l
larger than
k
, we have that
N_{\operatorname{Rel}(G)}(x)\cap\operatorname{IB}(\operatorname{M}^{l})=\emptyset
. By the maximality of
\operatorname{IB}(\operatorname{M}^{l})
we have that
x\notin\operatorname{B}(\operatorname{M}^{l})
. Since,
\operatorname{M}^{\infty}
coincides with
\operatorname{M}^{l}
on all variables of
x
for
l>k
, we deduce that
x\notin\operatorname{B}(\operatorname{M}^{\infty})
, as desired. This finishes the proof of the theorem.
∎

Remark 4.6
.

Let us note that the Borel LLL does not hold in full generality on graphs of exponential growth. Marks
[
23
]
constructed, for every
d\geqslant 3
, a
d
-regular acyclic Borel graph
F=(V,E)
with a Borel
d
-edge-colouring
\ell:E\to d
such that for every Borel vertex-colouring
c:V\to d
there is a
bad pair
, namely adjacent vertices
x,y\in V
with
c(x)=c(y)=\ell(xy)
. Given
F
and
\ell
, the problem of finding a colouring
c
without bad pairs fits into the LLL framework (where the variables and the clauses correspond to the vertices and edges of
F
respectively, with the clause
\mathbf{R}(xy)
for
xy\in E(F)
stating that the pair
xy
is not bad).
Clearly, for a uniform
d
-colouring, the probability that a given pair is bad is
p:=1/d^{2}
while the corresponding dependency graph (with self-loops) has maximum degree
\Delta:=2d-1
. Thus the LLL condition in (
1.4
), namely that
p<1/(\mathrm{e}\Delta)
, is satisfied if
d\geqslant 5
. However, there is no Borel satisfying colouring.
Conley et al
[
11
]
strengthened the above result of Marks
[
23
]
by showing that the Borel graph
F
can be additionally assumed to be hyperfinite. (A new and shorter proof of this is presented by Brandt et al
[
6
]
.) Thus there are hyperfinite counterexamples to a Borel LLL.
