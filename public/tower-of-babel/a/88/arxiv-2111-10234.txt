Command Governors with Inexact Optimization and without Invariance
Emanuele Garone, Ilya V. Kolmanovsky

Abstract




1
Introduction

R
eference Governors (RGs)
[
1
]
are add-on schemes to nominal closed-loop systems used
to enforce pointwise-in-time state and control constraints. An RG acts as a safety supervisor for the reference commands (set-points) given to the closed-loop system by a human
operator or by a higher-level planner in autonomous vehicles. The RG monitors reference commands to which the controller responds and modifies them if they create a danger of constraint violation to preserve safety.

RGs are an attractive option for practitioners as it enables them to use a variety of techniques for control system design that do not explicitly handle constraints while relying on RG for constraint enforcement.
Reference
[
1
]

surveys the literature on aerospace and other proposed applications of RGs, the RG theory
and compares RG with alternative approaches to constraint handling such as Model Predictive Control
[
2
]
; we do not replicate this survey here due to limited space.

A Command Governor (CG), first proposed in
[
3
]
for linear discrete-time systems,
is a particular type of RG that modifies the reference command by finding a minimum norm projection of the original reference command
onto a safe set of commands for the given state, i.e., a cross section of the safe set of state-command pairs. This safe set is constructed as an invariant subset of the maximum output admissible set (MOAS)
[
4
]
, i.e., the set of all initial states and constant commands that yield response satisfying the imposed constraints. When this safe set is polyhedral (this is the case, e.g., if CG is designed based on a linear discrete-time model and state and control constraints are linear), the minimum norm projection is computed by solving a quadratic programming (QP) problem at each discrete-time instant. Even though this QP problem is low dimensional, it typically has a large number of constraints due to the typically large number of affine inequalities needed to define the safe set. Consequently, solving this QP problem online is challenging. Extensions of CG to nonlinear systems have been presented in
[
5
]
.

In this Note we present a simple but very meaningful modification of the CG which enables it to operate with non-invariant safe sets and ensures feasibility and convergence properties even in the case the optimization is inexact. This modification significantly extends the applicability of the CG to practical problems where the construction of accurate invariant approximations of the MOAS and/or exact optimization may not be feasible due to model complexity or limited available onboard computing power. We will illustrate the impact of this modification on an F-16 aircraft longitudinal flight control example in terms of computational time and memory reduction.

The paper is organized as follows.
In Section
2
we formally introduce the CG and further explain the significance of our contribution.
In Section
3
we highlight
the mechanism by which convergence of the modified by CG reference command to the original reference command is achieved in the existing CG theory.This informs the modification to CG presented in Section
4
for which
we prove similar convergence results. A simulation example of
longitudinal control of F-16 aircraft is reported in Section
5
.
Finally, concluding remarks are made in Section
6
.

Preliminaries

A CG is an add-on algorithm to a nominal closed-loop system (Plant + Controller) represented by a discrete-time model (system of difference equations),

\boldsymbol{x}(t+1)=f(\boldsymbol{x}(t),\boldsymbol{v}(t)),

t\in\mathbb{Z}_{\geq 0}

The CG enforces pointwise-in-time constraints expressed as

(\boldsymbol{x}(t),\boldsymbol{v}(t))\in\mathcal{C}~~\mbox{for all $t\in\mathbb{Z}_{\geq 0}$},

(2)

where
\mathcal{C}\subset\mathbb{R}^{n+m}
is a specified constraint set.
This is done by monitoring and modifying the original reference command (set-point)
\boldsymbol{r}(t)\in\mathbb{R}^{m}
to a safe reference command
\boldsymbol{v}(t)\in\mathbb{R}^{m}
, see Figure
1
.
Note that as Eq. (

The MOAS, typically denoted as
O_{\infty},
is the set of all initial states and constant reference commands for which the subsequent response satisfies the constraints for all future times

4
]
,

O_{\infty}=\{(\boldsymbol{x}(0),\boldsymbol{v}):~\big(\boldsymbol{x}(t;\boldsymbol{x}(0),\boldsymbol{v}\big)\in\mathcal{C},\,\forall t\in\mathbb{Z}_{\geq 0}\},

denotes the state trajectory of the system represented by Eq. (

\boldsymbol{x}(0)
and the application of a constant reference command,

\boldsymbol{v}(t)=\boldsymbol{v}
for all
t\in\mathbb{Z}_{\geq 0}
.
Any subset

“invariant for a fixed

The Scalar Reference Governor (SRG) is the simplest RG algorithm, which searches for the closest admissible reference along the line segment connecting
\boldsymbol{v}(t-1)
and
\boldsymbol{r}(t)

\displaystyle\mathmakebox[\widthof{$\underset{\displaystyle}{\mathrm{subject~to}}$}][l]{\underset{\displaystyle}{\mathrm{maximize}}}\quad\kappa~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~\hfil\hfil\displaystyle\displaystyle\hfil\hfil\displaystyle\displaystyle

(3)

\displaystyle\mathmakebox[\widthof{$\underset{\displaystyle\phantom{}}{\mathrm{subject~to}}$}][c]{{\mathrm{subject~to}}}\quad

\displaystyle 0\leq\kappa\leq 1,\hfil\hfil\displaystyle\displaystyle

\displaystyle\big(\boldsymbol{x}(t),\boldsymbol{v}(t-1)+\kappa(\boldsymbol{r}(t)-\boldsymbol{v}(t-1))\big)\in P

At each time instant
t

\boldsymbol{v}(t)
is assigned as the optimal
\boldsymbol{v}^{*},
i.e.
\boldsymbol{v}(t)=\boldsymbol{v}^{*}=\boldsymbol{v}(t-1)+\kappa^{*}(\boldsymbol{r}(t)-\boldsymbol{v}(t-1)),
where

The first SRG proposed in the literature for discrete-time systems considered
Eq. (
1
) as a linear system and

in the optimization problem (
3
) was chosen equal to
\tilde{O}_{\infty}
– a finitely-determined, invariant, constraint-admissible, inner approximation of
O_{\infty}
.
In later versions of the SRG, the requirement for
P
in the optimization problem (
3
) to be

\tilde{O}_{\infty}
or even
invariant was removed
[
6
]
, allowing a much greater freedom in selecting
P\subseteq\tilde{O}_{\infty}
. Note that in this case, the optimization problem (
3
) is not guaranteed to be recursively feasible. However, under reasonable assumptions, it is possible to prove that if no feasible solution to (
3
) exists and the reference is held constant,
\boldsymbol{v}(t)=\boldsymbol{v}(t-1),
then the optimization problem (
3
) will be feasible again after a finite number of steps.
This property is particularly useful when,
to reduce the computational time and memory,
sets
P
that are simple subsets of
\tilde{O}_{\infty}
are used. Systematic procedures to generate
simpler
P
from
\tilde{O}_{\infty}
by removing almost redundant inequalities from its description and applying a pull-in transformation have been proposed
[
6
]
.

One of the main strengths of SRG is its capability to manage constraints while being very computationally efficient. This is mainly due to the fact that in the SRG the selection of
\boldsymbol{v}(t)
is reduced to the selection of the single scalar variable
\kappa\in[0,\,1]
which can be performed very efficiently (often in closed form) for many types of constraints, see e.g.
[
7
]
.
Unfortunately, in the case
m>1
, this comes at the price of potentially slowing down the system response as certain
v_{i}(t)
may be able to converge to the corresponding
r_{i}(t)
,
i=1,\cdots,m,
faster than others and thus
\boldsymbol{v}(t)
could be made closer to
\boldsymbol{r}(t)
if not constrained to the line segment between
\boldsymbol{v}(t-1)
and
\boldsymbol{r}(t).

The above limitation can be overcome making use of the CG instead of SRG. Unlike SRG, the CG has more flexibility in choosing the reference
v(t)
as
the solution to the following optimization problem:

\displaystyle\boldsymbol{v^{*}}=

\displaystyle\mathmakebox[\widthof{$\underset{\displaystyle\boldsymbol{v}}{\mathrm{subject~to}}$}][l]{\underset{\displaystyle\boldsymbol{v}}{\mathrm{arg~min}}}\quad\|\boldsymbol{r}(t)-\boldsymbol{v}\|^{2}_{Q}\hfil\hfil\displaystyle\displaystyle\hfil\hfil\displaystyle\displaystyle

(4)

\displaystyle\mathmakebox[\widthof{$\underset{\displaystyle\phantom{\boldsymbol{v}}}{\mathrm{subject~to}}$}][c]{{\mathrm{subject~to}}}\quad

\displaystyle(\boldsymbol{x}(t),\boldsymbol{v})\in P

where
Q=Q^{\rm T}\succ 0
,
\|\boldsymbol{r}(t)-\boldsymbol{v}\|^{2}_{Q}=(\boldsymbol{r}(t)-\boldsymbol{v})^{\rm T}Q(\boldsymbol{r}(t)-\boldsymbol{v}),

and
P\subseteq O_{\infty}
is invariant. In this case, at each time instant

the applied command is
\boldsymbol{v}(t)=\boldsymbol{v^{*}}.

The price to be paid for using a CG instead of an SRG is that the optimization problem to be solved is not anymore a simple single variable optimization problem as in the SRG case, and, typically,
it must be solved making use of an iterative
optimization algorithm. For this reason, in practice, the CG is used almost exclusively when the set
P\subseteq O_{\infty}
is convex in
v
for any fixed
x.
Furthermore, to ensure the correct behaviour of the CG scheme (e.g., recursive feasibility of the optimization problem (
4
)), the set
P
must be invariant.

The primary objective of this paper is to propose a modification of the conventional CG
(
4
) which:

1.

Allows the CG to use a non-invariant set
P\subseteq O_{\infty}
;

2.

Allows to solve the optimization problem (
4
) inexactly while still ensuring constraints satisfaction and finite-time convergence.

This modification significantly extends the applicability of the CG to practical problems where finding invariant sets may be problematic and where exact optimization may not be feasible due to unreliability of the optimizers or limited computing power.

3
CG Convergence

The Conventional CG convergence theory makes use of the following assumptions:

A1

P
is positively invariant for any fixed
\boldsymbol{v}
, i.e.,
(\boldsymbol{x},\boldsymbol{v})\in P
implies
(f(\boldsymbol{x},\boldsymbol{v}),\boldsymbol{v})\in P
;

A2

For each
\boldsymbol{v}
there exists a unique equilibrium
\boldsymbol{x_{v}}
associated to a constant reference
\boldsymbol{v}
such that
f(\boldsymbol{x_{v}},\boldsymbol{v})=\boldsymbol{x_{v}}
and

\boldsymbol{x_{v}}
is Lipschitz continuous with respect to
\boldsymbol{v}
. It is further assumed that the sets
R_{P}=\{\boldsymbol{v}|(\boldsymbol{x_{v}},\boldsymbol{v})\in P\}
and
P_{x}=\{\boldsymbol{v}|(\boldsymbol{x},\boldsymbol{v})\in P\}
are closed and convex
for all
\boldsymbol{x}
;

A3

There exists a scalar
\varepsilon>0
such that for any fixed
\boldsymbol{v}\in R_{P}
the set
P_{v}=\{\boldsymbol{x}|(\boldsymbol{x},\boldsymbol{v})\in P\}
contains a ball of radius
\varepsilon
centered at
\boldsymbol{x_{v}}
;

A4

P\subseteq O_{\infty}\subseteq\mathcal{C}
;

A5

If
\boldsymbol{v}(t)-\boldsymbol{v}(t-1)\to 0
as
t\to\infty
then the solutions of
Eq. (
1
) satisfy

\boldsymbol{x}(t)\to\boldsymbol{x}_{\boldsymbol{v}(t)}
as
t\to\infty
.

Assumptions A1-A4 are reasonable and are typically
made in the study of reference and command governors.
The assumption A5 is also reasonable. For instance, if the discrete-time dynamics are linear,

\boldsymbol{x}(t+1)=A\boldsymbol{x}(t)+B\boldsymbol{v}(t)
, and
A
is Schur (all eigenvalues are inside the unit disk of complex plane), then

\bar{x}_{\boldsymbol{v}}=(I-A)^{-1}B\boldsymbol{v}
,

\boldsymbol{x}(t+1)-\boldsymbol{x}_{\boldsymbol{v}(t+1)}=A(\boldsymbol{x}(t)-\boldsymbol{x}_{\boldsymbol{v}(t)})+(I-A)^{-1}B(\boldsymbol{v}(t)-\boldsymbol{v}(t+1)),

and A5 holds.
For general nonlinear systems this property is similar to the discrete-time incremental Input-to-State (ISS) property
[
8
]
.

Under these assumptions it is possible to prove the following properties:

Theorem 1

Let the applied reference
\boldsymbol{v}(t)
be managed by a CG based on solving at each sampling time the optimization problem in Eq. (
4
)
and let A1-A5 hold. If a
\boldsymbol{v}(0)
exists such that
(\boldsymbol{x}(0),\boldsymbol{v}(0))\in P
then:

Constraints are satisfied at all time instants,
t\geq 0
;

If the desired reference is constant,
\boldsymbol{r}(t)=\boldsymbol{r_{0}}
for
t\geq\hat{t}
,
and, moreover,
\boldsymbol{r_{0}}\in R_{P},
then the sequence of
\boldsymbol{v}(t)
converges in finite time to
\boldsymbol{r_{0}}
;

If the desired reference is constant,
\boldsymbol{r}(t)=\boldsymbol{r_{0}}
for
t\geq\hat{t}
, and

\boldsymbol{r_{0}}\notin R_{P},
then the sequence of
\boldsymbol{v}(t)
converges in finite time to the best approximation of
\boldsymbol{r_{0}}
in
R_{P},
, i.e., to
\boldsymbol{r^{*}}=arg\min_{\boldsymbol{v}\in R_{P}}||\boldsymbol{v}-\boldsymbol{r}||_{Q}^{2}

Here we review several elements of the proof as they inform subsequent modifications to the CG:

Proof 3.2
.

1) Because of assumption A1,
P
is invariant for any fixed
\boldsymbol{v}
. Then
(\boldsymbol{x}(t),\boldsymbol{v}(t-1))
is always a feasible solution for the optimization problem (
4
). Constraints satisfaction at all time instants can be concluded from assumption A4.

2),3) The starting point is to note that, because of assumption A1 and since
\boldsymbol{v}(t-1)
is feasible at time
t
, the function
V(t)=||\boldsymbol{v}(t)-\boldsymbol{r_{0}}||_{Q}^{2}
for
t>\hat{t}
is non-increasing and bounded from above and below. Consequently,
\lim_{t\rightarrow\infty}V(t)
exists and is finite, which also implies that

\lim_{t\rightarrow\infty}\big[V(t)-V(t-1)\big]=0.

Note that in the general case this does not imply that

\lim_{t\rightarrow\infty}\boldsymbol{v}(t)
exists.
However, because of the convexity and closeness of
P_{\boldsymbol{x}(t)}
(assumption A2) it is possible to prove that

V(t-1)\geq V(t)+||\boldsymbol{v}(t)-\boldsymbol{v}(t-1)||_{Q}^{2},

(5)

which implies that
\lim_{t\rightarrow\infty}\big[\boldsymbol{v}(t)-\boldsymbol{v}(t-1)\big]=0
,
and hence
\boldsymbol{x}(t)\to\boldsymbol{x}_{\boldsymbol{v}(t)}
as
t\to\infty
(assumption A5).

The rest of the proof is completed using assumption A3, that ensures feasibility, i.e., that
(\boldsymbol{x}(t),\boldsymbol{v})\in P
, of any
\boldsymbol{v}
such that
\|\boldsymbol{v}-\boldsymbol{v}(t-1)\|<\delta
where
\delta>0
is sufficiently small. Hence the only possible value for
\lim_{t\rightarrow\infty}\boldsymbol{v}(t)
is
\boldsymbol{r_{0}}
in the case
\boldsymbol{r_{0}}\in R_{P}
and

\lim_{t\rightarrow\infty}\boldsymbol{v}(t)=\boldsymbol{r^{*}}
otherwise. Furthermore, these limits are reached in finite time.

A key argument of the entire proof is inequality (
5
). To prove this inequality, the first step is to note that
since
P
is invariant,
\boldsymbol{v}(t-1)
is a feasible solution to optimization problem (
4
) while
\boldsymbol{v}(t)
is the optimal solution. Note that
P_{\boldsymbol{x}(t)}
is closed and convex,
\boldsymbol{v^{-}}=\boldsymbol{v}(t-1)\in P_{\boldsymbol{x}(t)}
and
\boldsymbol{v^{*}}=\boldsymbol{v}(t)
is the minimizer of
F(\boldsymbol{v})=\|\boldsymbol{r_{0}}-\boldsymbol{v}\|_{Q}^{2}
over
\boldsymbol{v}\in P_{\boldsymbol{x}(t)}
. Then the necessary condition for optimality of
\boldsymbol{v^{*}}
implies that,
d_{+}F(\boldsymbol{v^{*}};\boldsymbol{v}-\boldsymbol{v^{*}})=(\nabla F(\boldsymbol{v}))^{\rm T}(\boldsymbol{v}-\boldsymbol{v^{*}})\geq 0
for any
\boldsymbol{v}\in P_{\boldsymbol{x}(t)}
where
d_{+}
stands for the Gateaux differential (directional derivative). Thus

d_{+}f(\boldsymbol{v^{*}};\boldsymbol{v^{-}}-\boldsymbol{v^{*}})=-2(\boldsymbol{r_{0}}-\boldsymbol{v^{*}})^{\rm T}Q(\boldsymbol{v^{-}}-\boldsymbol{v^{*}})\geq 0,

and hence,

(\boldsymbol{r_{0}}-\boldsymbol{v(t)})^{\rm T}Q(\boldsymbol{v^{-}}-\boldsymbol{v}(t))\leq 0.

(6)

Transforming inequality (
6
) as

(\boldsymbol{r_{0}}-\boldsymbol{v}(t)-\boldsymbol{v^{-}}+\boldsymbol{v^{-}})^{\rm T}Q(\boldsymbol{v^{-}}-\boldsymbol{r_{0}}+\boldsymbol{r_{0}}-\boldsymbol{v}(t))\leq 0,

expanding and applying inequality (
6

||\boldsymbol{v^{-}}-\boldsymbol{r_{0}}||_{Q}^{2}\geq||\boldsymbol{v}(t)-\boldsymbol{r_{0}}||_{Q}^{2}+||\boldsymbol{v^{-}}-\boldsymbol{v}(t)||_{Q}^{2},

(7)

which implies the inequality (
5
).

Remark 1:
It is worth to remark that unlike the SRG, which requires at time zero the knowledge of a feasible
\boldsymbol{v}(0)
to start the algorithm, the CG only requires that a feasible
\boldsymbol{v}(0)
exists as the CG itself will be able compute it. This not only simplifies the start-up relative to the SRG, but also means that the CG has some implicit reconfiguration capability in case of impulsive disturbances. Indeed, if an impulsive disturbance changes the state of the system in such a way that the previously applied reference
\boldsymbol{v}(t-1)
is not feasible anymore (i.e.
(\boldsymbol{x}(t),\boldsymbol{v}(t-1))\notin P
), the CG is able (whenever possible) to reconfigure the reference
\boldsymbol{v}(t)
in such a way that
(\boldsymbol{x}(t),\boldsymbol{v}(t))\in P
. For this reason, the CG has also been used in Fault Tolerant control schemes
[
9
]
. However it must be mentioned that, depending on the application, erratic jumps in
\boldsymbol{v}(t)
due to occasional infeasibility caused by model mismatch or impulsive disturbances may not be necessarily preferable to maintaining
previously applied reference, provided it is not permanently stuck, so this property is not necessarily an advantage.

The proof of Theorem
1
reveals that the convergence results follow from the condition (
7

P
and the assumption that the CG is able to compute the optimal solution of the optimization problem (

The key observation behind this note is that if the condition (

A simple way to ensure that the condition (

•

\boldsymbol{v^{\prime}}

6
Concluding Remarks

The Command Governor (CG) is an add-on scheme to a nominal closed-loop system used to satisfy state and control constraints through reference command modification to maintain state-command pair in a safe set. By modifying the CG logic, it is possible to implement CG without requiring this safe set to be invariant or relying on exact optimization, while retaining constant command finite time convergence properties typical of CG. An F-16 longitudinal flight control simulation example has been reported that demonstrated the potential of the proposed approach for significant reduction in the computation time and in ROM size required for implementation.
