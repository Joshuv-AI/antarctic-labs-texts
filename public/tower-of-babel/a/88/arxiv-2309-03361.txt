Linear Programming by Conical Projection
Evgeni Nurminski, Roman Tarasov

Abstract
Эта статья посвящена численной эффективности проекционных алгоритмов для решения задач линейной оптимизации. Теоретическая основа для этого подхода обеспечивается основным результатом, состоящим в том, что ограниченная конечномерная задача линейной оптимизации может быть решена с помощью одной операции проецирования на допустимый политоп. Дальнейшее упрощение превращает эту задачу в проекцию определённой точки на выпуклый полиэдральный конус, порожденный в основном неравенствами исходной задачи линейной оптимизации.



Introduction

Линейная оптимизация остается важной задачей для многих практических приложений, и современные симплексные алгоритмы промышленного качества общего назначения и методы внутренних точек продемонстрировали значительный успех в этой области.
Тем не менее, разрабатываются новые подходы, которые могут найти свое применение в тех или иных ситуациях.
В данной статье мы рассматриваем проекционный алгоритм решения задач линейной оптимизации в стандартной форме

{\begin{array}[t]{c}\min\\

2
Inside out

The subject of this section is the least norm problem

\min_{x\in X}\|x\|^{2}

in an
n
-dimensional euclidean space
E

for a bounded closed convex polyhedron
X
.
Here we do not make a great distinction between row and column vectors which are assumed of
any type depending on context.
Polyhedron
X
most commonly
described as the intersection of half-spaces

{X=\{x:a^{i}x\leq\beta_{i},i=1,2,\dots,m\}=\{x:Ax\leq b\}}

(15)

where vectors
a^{i},i=1,2,\dots,m
of the dimensionality
n
can be considered as rows of the matrix
A
,
and the
m
-vector
b=(\beta_{1},\beta_{2},\dots,\beta_{m})
is the corresponding right-hand side vector.
It can be considered as the ”outer” description of
X
in contrast with the ”inner” description

{X=\co(\hat{x}^{j},\hat{x}^{j}\in\mathrm{Ext}(X),j=1,2,\dots,J)}

(16)

as the convex hull of the set
\mathrm{Ext}(X)
of extreme points of the same set
X
.
The later is often considered as ”polytope” description.
These are equivalent descriptions for this class of polyhedrons/polytopes,
but direct conversion between them is complicated as any of them may be exponentially long
even for the polynomially long in
n,m
counterparts.

The polyhedron description is more common so the vast majority of computational algorithms is developed
namely for this description of
X
.
The notable exceptions are possibly game problems with probability simplexes and nondifferentiable optimization
algorithms in which subdifferentials are approximated by convex hulls of known subgradients.
However convex hull-like description has its own computational advantages, for instance as linear optimization problem over
convex hulls is has low
nm
complexity for the trivial direct algorithm and can be reduced to logarithmic complexity
if parallel computations allowed.
In
we considered the transformation of the least norm problem with
the polyhedral description (
15
) into
the close relative of (
16
) with practically the same data-size as (
15
).

The original version of this transformation was rather convoluted
and here we present its alternative derivation which
uses basically only standard duality arguments.

To begin with we expand our basic space
E
with one additional variable into
\bar{E}=E\times\mathbb{R}
and
transform the initial least norm problem into something which is almost homogeneous:

{\begin{array}[t]{c}\min\\
Ax\leq b\end{array}\frac{1}{2}(\|x\|^{2}+1)=\begin{array}[t]{c}\min\\
\bar{A}\bar{x}\leq 0\\
\bar{e}\bar{x}=1\end{array}\frac{1}{2}\|\bar{x}\|^{2}}

(17)

with
\bar{A}=|A,-b|
,
\bar{x}=(x,\xi)
, and vector
\bar{e}=(0,0,\dots,0,1)\in\bar{E}
.
The saddle point reformulation of this problem goes as follows:

\begin{array}[]{c}\begin{array}[t]{c}\min\\
\bar{A}\bar{x}\leq 0\\
\bar{e}\bar{x}=1\end{array}\frac{1}{2}\|\bar{x}\|^{2}=\frac{1}{2}\|\bar{x}^{\star}\|^{2}=\begin{array}[t]{c}\max\\
u\geq 0,\penalty\ \theta\end{array}\begin{array}[t]{c}\min\\
\bar{x}\end{array}\{\frac{1}{2}\|\bar{x}\|^{2}+\theta(1-\bar{e}\bar{x})+u\bar{A}\bar{x}\}=\\
\begin{array}[t]{c}\max\\
u\geq 0,\penalty\ \theta\end{array}\{\theta+\begin{array}[t]{c}\min\\
\bar{x}\end{array}\{\frac{1}{2}\|\bar{x}\|^{2}+(u\bar{A}-\theta\bar{e})\bar{x}\}=\begin{array}[t]{c}\max\\
u\geq 0,\penalty\ \theta\end{array}\{\theta-\frac{1}{2}\|u\bar{A}-\theta\bar{e}\|^{2}\}\end{array}

Introducing the cone
{\cal{K}}=\{z:z=u\bar{A},u\geq 0\}
we can rewrite the last problem as

-\begin{array}[t]{c}\min\\
\theta\end{array}\{\frac{1}{2}\min_{z\in{\cal{K}}}\|z-\theta\bar{e}\|^{2}-\theta\}=-\begin{array}[t]{c}\min\\
\theta\end{array}\{\frac{1}{2}\theta^{2}\min_{z\in{\cal{K}}}\|z-\bar{e}\|^{2}-\theta\}=-\begin{array}[t]{c}\min\\
\theta\end{array}\{\frac{1}{2}\gamma^{2}\theta^{2}-\theta\}=1/2\gamma^{2},

where we made use of
\alpha{\cal{K}}={\cal{K}}
for any
\alpha>0
and denoted
\gamma^{2}=\min_{z\in{\cal{K}}}\|z-\bar{e}\|^{2}
.
The solution of the last minimum is attained for
\theta^{\star}=1/\gamma^{2}
.
As solution of
\min_{z\in{\cal{K}}}\|z-\bar{e}\|^{2}=\|z^{\star}-\bar{e}\|^{2}
is unique we obtain

\bar{x}^{\star}=\theta^{\star}(z^{\star}-\bar{e})
.
