On the error control of invariant causal prediction
Jinzhou Li, Jelle J Goeman

Abstract
Invariant causal prediction (ICP, Peters et al., 2016 ) provides a novel way for identifying causal predictors of a response by utilizing heterogeneous data from different environments. One notable advantage of ICP is that it guarantees to make no false causal discoveries with high probability. Such a guarantee, however, can be overly conservative in some applications, resulting in few or no causal discoveries. This raises a natural question: Can we use less conservative error control guarantees for ICP so that more causal information can be extracted from data? We address this question in the paper. We focus on two commonly used and more liberal guarantees: false discovery rate control and simultaneous true discovery bound. Unexpectedly, we find that false discovery rate does not seem to be a suitable error criterion for ICP. The simultaneous true discovery bound, on the other hand, proves to be an ideal choice, enabling users to explore potential causal predictors and extract more causal information. Importantly, the additional information comes for free, in the sense that no extra assumptions are required and the discoveries from the original ICP approach are fully retained. We demonstrate the practical utility of our method through simulations and a real dataset about the educational attainment of teenagers in the US.



1
Introduction

Discovering causal predictors of the response of interest is one of the principal goals of scientific research. However, based solely on observational data, causal relationships might be unidentifiable. In such cases, heterogeneous data from different environments can enhance identifiability and thus is a valuable source for causal discovery.
In the multi-environment setting,
Peters et al., 2016
proposed a novel method called invariant causal prediction (ICP), which identifies causal predictors by exploiting the invariance of the conditional distribution of the response given its causal predictors across environments.
Specifically, ICP generates p-values
p_{S}
for each set
S\subseteq[m]=\{1,\dots,m\}
, where
m
is the number of variables, by testing whether
S
is invariant across environments (see (
1
)). The estimated set of causal predictors,
\widehat{S}^{\text{ICP}}
(see (
3
)), is then obtained based on these p-values.

One notable advantage of ICP is that it
guarantees, with high probability, that all its discoveries are true causal predictors:

\displaystyle P\left(\widehat{S}^{\text{ICP}}\subseteq S^{*}\right)=P\left(|\widehat{S}^{\text{ICP}}\cap\mathcal{N}^{*}|=0\right)\geq 1-\alpha,

where
\alpha\in(0,1)
is a nominal level,
S^{*}
denotes the set of true causal predictors, and
\mathcal{N}^{*}=[m]\setminus S^{*}
denotes the set of null causal predictors.
This guarantee is known as familywise error rate (FWER) control.

Controlling the FWER, however, can be overly conservative in some applications, particularly when causal predictors are highly correlated with non-causal ones. In such cases, ICP may result in few or no causal discoveries.
This raises the question:
Is it possible to control more liberal error rates for ICP, thereby extracting more causal information?

To answer this question, we focus on two commonly used, less conservative error control guarantees:
false discovery rate (FDR) control
(
Benjamini and Hochberg, 1995
;
Benjamini and Yekutieli, 2001
)

and the
simultaneous true discovery bound
(
Genovese and Wasserman, 2006
;
Goeman and Solari, 2011
)
.
Formally, based on the p-values
p_{S}
generated by ICP,
we study the following two problems:

1.

FDR control: Can we obtain a discovery set
\widehat{S}
satisfying the FDR control guarantee

\displaystyle\mathbb{E}\left[\frac{|\widehat{S}\cap\mathcal{N}^{*}|}{\max\{1,|\widehat{S}|\}}\right]\leq\alpha?

In particular, since FWER control implies FDR control (so
\widehat{S}^{\text{ICP}}
already guarantees FDR control), the goal here is not merely to obtain a set
\widehat{S}
with FDR control, but also to have
\widehat{S}
contain more discoveries than
\widehat{S}^{\text{ICP}}
.

2.

Simultaneous true discovery bound: Can we obtain a function
t_{\alpha}:2^{[m]}\rightarrow[0,1]
, where
2^{[m]}
denotes the power set of
[m]
, such that

\displaystyle P(|R\cap S^{*}|\geq t_{\alpha}(R)\text{ for any }R\subseteq[m])\geq 1-\alpha?

This bound enables users to freely check any set
R
they consider interesting, which may be formed based on applying some machine learning methods or their expertise, with
t_{\alpha}(R)
providing a high probability lower bound on the number of true discoveries in
R
.

To address these two problems, our main idea is to consider a multiple testing problem (see (
4
)) that directly tests whether causal predictors are null, and propose p-values based on
p_{S}
generated by ICP. We can then apply false discovery rate control procedures or construct simultaneous true discovery bounds using these p-values.
To this end, we propose valid p-values
p_{i}^{*}
(see (
5
)). Furthermore, we prove that the original ICP method is equivalent to directly comparing certain p-values (see (
6
)), which are slightly more conservative than
p_{i}^{*}
, to the significance level.

For the first problem, our answer is negative. We find that directly comparing
p_{i}^{*}
to the nominal level already controls the FWER, which is somewhat uncommon because multiple testing procedures, such as Bonferroni’s correction, are typically required to control the FWER.
Given this, there is no reason to further applying FDR control procedures to
p_{i}^{*}
, and the only hope for obtaining more causal discoveries through FDR control would be if
p^{*}_{i}
were conservative.
If that were the case, we may propose better p-values and obtain more causal discoveries by applying FDR control methods to them.
As a result,
we investigate whether
p_{i}^{*}
is conservative in a special setting where the optimal
p_{S}
can be obtained by ICP. We show that
p_{i}^{*}
is not conservative in this setting, indicating that obtaining smaller valid p-values is unlikely.
Consequently, we believe that
it is unlikely to obtain more causal discoveries by controlling the FDR for ICP.

For the second problem, our answer is positive.
The multiple testing framework provides a convenient way to apply the closed testing procedure from
Goeman and Solari, 2011
to obtain simultaneous true discovery bounds.
Furthermore, we show that due to the special construction of
p_{i}^{*}
, the closed testing adjustment step is unnecessary,
which significantly reduces computation as we do not need to implement all steps of the standard closed testing procedure.
We also present a simultaneous bound based on the original ICP formulation,
and we prove its equivalence to the one obtained by closed testing.
This connection is useful as it provides a better understanding of the statistical properties, such as admissibility, of the simultaneous true discovery bound. These properties are less evident in the original ICP formulation but have been well-studied in the context of closed testing
(
Goeman et al., 2021
)
.

The simultaneous true discovery bound preserves the same causal information obtained by the original ICP approach, and it can extract additional causal insights. Hence, it is always beneficial to use it in practice.
As a quick illustration, for a simulated dataset with nine predictors shown in Section
5.1
, no information is obtained by the original ICP approach as it returns zero discoveries. However, more causal information can be extracted by using the simultaneous true discovery bounds. For example, we can know that with a probability larger than
0.95
, there is at least one causal
predictor in
\{X_{3},X_{7}\}
, at least two causal predictors in
\{X_{3},X_{5},X_{7},X_{8}\}
, and at least four causal predictors in all nine predictors.
More simulations and a real data application can be found in Section
5
.

We note that the simultaneous true discovery bound
t_{\alpha}(R)
is equivalent to the simultaneous false discovery bound, in the sense that based on
t_{\alpha}(R)
, we can obtain simultaneous false discovery bound
|R|-t_{\alpha}(R)
satisfying

\displaystyle P(|R\cap\mathcal{N}^{*}|\leq|R|-t_{\alpha}(R)\text{ for any }R\subseteq[m])\geq 1-\alpha.

We focus on the simultaneous true discovery bound throughout this paper because it offers a more convenient interpretation for applications.
Many other error rates, such as k-FWER
(
Lehmann and Romano, 2005
;
Sarkar, 2007
)
and false discovery exceedance
(
Dudoit et al., 2004
;
Korn et al., 2004
;
Romano and Shaikh, 2006
)
, can be seen as special cases of the simultaneous true discovery bound, see
Goeman et al., 2021
for further discussions.

At last,
Heinze-Deml et al., 2018
also investigated the question of mitigating the conservativeness of FWER control for ICP,
and they proposed the so-called defining sets to tackle this problem. Defining sets are the smallest sets guaranteed to contain at least one true causal predictor, making them particularly useful when ICP returns an empty set.
As we will see later, the true discovery bound encompasses defining sets as special cases.

2
A brief recap of invariant causal prediction

For the sake of simplicity, we use linear models
(
Peters et al., 2016
)
for illustration.
Our results can also be applied to non-linear cases
(
Heinze-Deml et al., 2018
)
directly.
Consider the following linear structural equation model:

Y^{e}\leftarrow\beta_{1}X^{e}_{1}+\cdots\beta_{m}X^{e}_{m}+\epsilon^{e}=\beta_{S^{*}}^{T}X^{e}_{S^{*}}+\epsilon^{e},

where
S^{*}=\{i\in[m]:\beta_{i}\neq 0\}
is the set of causal predictors of
Y
,

e\in\mathcal{E}
denotes one environment,

\epsilon^{e}\sim F_{\epsilon}
,
\epsilon^{e}\mathchoice{\mathrel{\hbox to0.0pt{$\displaystyle\perp$\hss}\mkern 2.0mu{\displaystyle\perp}}}{\mathrel{\hbox to0.0pt{$\textstyle\perp$\hss}\mkern 2.0mu{\textstyle\perp}}}{\mathrel{\hbox to0.0pt{$\scriptstyle\perp$\hss}\mkern 2.0mu{\scriptstyle\perp}}}{\mathrel{\hbox to0.0pt{$\scriptscriptstyle\perp$\hss}\mkern 2.0mu{\scriptscriptstyle\perp}}}X^{e}_{S^{*}}
, and
X^{e}_{i}
can have arbitrary distribution for different
e
.
The goal is to estimate the set of causal predictors
S^{*}
.

The key idea of ICP is to test whether the conditional distribution of
Y^{e}
is invariant across environments given predictors
X^{e}_{S}
for each
S\subseteq[m]
. This leads to the following null hypothesis:

\displaystyle H_{0,S}(\mathcal{E}):

\displaystyle\text{there exists a distribution $F_{\epsilon}$ and a vector }\gamma\in\mathbb{R}^{m}\text{ with support }S\text{ such that }

(1)

\displaystyle\text{for all }e\in\mathcal{E},Y^{e}=\gamma^{T}X^{e}+\epsilon^{e},\text{where }\epsilon^{e}\sim F_{\epsilon}\text{ and }\epsilon^{e}\mathchoice{\mathrel{\hbox to0.0pt{$\displaystyle\perp$\hss}\mkern 2.0mu{\displaystyle\perp}}}{\mathrel{\hbox to0.0pt{$\textstyle\perp$\hss}\mkern 2.0mu{\textstyle\perp}}}{\mathrel{\hbox to0.0pt{$\scriptstyle\perp$\hss}\mkern 2.0mu{\scriptstyle\perp}}}{\mathrel{\hbox to0.0pt{$\scriptscriptstyle\perp$\hss}\mkern 2.0mu{\scriptscriptstyle\perp}}}X^{e}_{S}.

Under the assumptions that there is no latent variables and
\mathcal{E}
does not contain the environment where
Y
is intervened,
it is clear that
H_{0,S^{*}}(\mathcal{E})
is true.
However, there may be other set
S
than
S^{*}
for which
H_{0,S}(\mathcal{E})
is true, causing an identifiability issue.
To this end,
Peters et al., 2016
defined the so-called identifiable causal predictors under
\mathcal{E}
as follows:

\displaystyle S(\mathcal{E})=\bigcap_{S:H_{0,S}(\mathcal{E})\text{ is true }}S.

(2)

Note that
S(\mathcal{E})\subseteq S^{*}
as
H_{0,S^{*}}(\mathcal{E})
is true.

ICP estimates the causal predictors by using the sample version of
S(\mathcal{E})
in two steps:

(i)

For each
S\subseteq[m]
, test
H_{0,S}(\mathcal{E})
at level
\alpha\in(0,1)
to obtain p-value
p_{S}
.

(ii)

Obtain the estiamted causal predictors by

\widehat{S}^{\text{ICP}}(\mathcal{E})=\underset{S:H_{0,S}(\mathcal{E})\text{ is not rejected }}{\bigcap}S.

(3)

The FWER guarantee of
\widehat{S}^{\text{ICP}}(\mathcal{E})
holds at level
\alpha
because

\displaystyle P\left(\widehat{S}^{\text{ICP}}(\mathcal{E})\subseteq S^{*}\right)=P\left(\underset{S:H_{0,S}(\mathcal{E})\text{ is not rejected }}{\bigcap}S\subseteq S^{*}\right)\geq P(H_{0,S^{*}}(\mathcal{E})\text{ is not rejected })\geq 1-\alpha.

3
A multiple testing formulation of ICP

The original formulation of ICP described in Section
2
,
while elegant and concise, may not be the most suitable for addressing the two problems described in Section
1
.
In this section, we provide a multiple testing perspective on the original ICP approach, which offers additional insights for addressing the considered problems.

Specifically, instead of directly estimating
S(\mathcal{E})
as in (
3
),
another natural approach is to consider the following multiple testing problem:

\displaystyle H^{*}_{0,i}:i\in\mathcal{N}^{*},\quad i\in[m].

(4)

Recall that
\mathcal{N}^{*}=[m]\setminus S^{*}
is the set of null causal predictors.
The idea is to obtain valid p-values for these hypotheses, then apply false discovery rate control procedures, such as the Benjamini-Yekutieli procedure
(
Benjamini and Yekutieli, 2001
)
, or construct simultaneous true discovery bounds using these p-values. These approaches may lead to more discoveries compared to
\widehat{S}^{\text{ICP}}(\mathcal{E})
, because they are less conservative than controlling the FWER.

To this end, based on the p-values
p_{S}
generated by the first step of ICP,
we propose the following p-value for
H^{*}_{0,i}
:

\displaystyle p^{*}_{i}=\max_{S\subseteq[m]\setminus\{i\}}p_{S}.

(5)

All p-values in this paper depend on the environment set
\mathcal{E}
, but we surpress this dependence for simplicity in notation.
We take the p-values
p_{S}
as given from the ICP approach and do not elaborate on their calculation. For more details, please refer to
Peters et al., 2016
.

As shown in the following proposition,
p^{*}_{i}
is a valid p-value.

Proposition 3.1
.

For any
c\in(0,1)
,

P_{H^{*}_{0,i}}(p^{*}_{i}\leq c)\leq c
.

One may wonder how the original ICP method
connects to this multiple testing formulation, and we now establish this connection.
Since the original ICP method controls the FWER, one might guess that applying some FWER control procedure, such as the Bonferroni correction or Holm’s procedure
(
Holm, 1979
)
, would yield a set equivalent to
\widehat{S}^{\text{ICP}}(\mathcal{E})
. However, this is not the case. Perhaps surprisingly,
\widehat{S}^{\text{ICP}}(\mathcal{E})
is almost equivalent to the set obtained by directly comparing
p^{*}_{i}
to the nominal level, without applying any multiple testing corrections.

We need to introduce a slightly more complicated p-value than
p^{*}_{i}
in order to establish the connection. For a given
\tau\in(0,1)
, let

\displaystyle\tilde{p}^{*}_{i}(\tau)=\max\{p^{*}_{i},\Pi_{S\subseteq[m]}\mathbbm{1}_{p_{S}\leq\tau}\}.

(6)

Note that
\tilde{p}^{*}_{i}(\tau)
is also a valid p-value because
\tilde{p}^{*}_{i}(\tau)\geq p^{*}_{i}
.
Then, as the following proposition shows, the discovery set
\widehat{S}^{\text{ICP}}(\mathcal{E})
obtained by ICP is equivalent to the set obtained by directly comparing
\tilde{p}^{*}_{i}(\alpha)

to the nominal level
\alpha
.

Proposition 3.2
.

For
\alpha\in(0,1)
,
let
\tilde{S}(\mathcal{E})=\{i:\tilde{p}^{*}_{i}(\alpha)\leq\alpha\}
.
Then
\tilde{S}(\mathcal{E})=\widehat{S}^{\text{ICP}}(\mathcal{E})
.

As a result,
\tilde{S}(\mathcal{E})
possesses the FWER control guarantee.
In fact, the discovery set

\displaystyle\widehat{S}(\mathcal{E})=\{i:p^{*}_{i}\leq\alpha\}

(7)

obtained by directly comparing
p^{*}_{i}
to the nominal level
\alpha

also controls the FWER, as shown in the following proposition.

Proposition 3.3
.

For
\alpha\in(0,1)
,
we have

P\left(\widehat{S}(\mathcal{E})\subseteq S^{*}\right)\geq 1-\alpha.

Note that
\widehat{S}^{\text{ICP}}(\mathcal{E})=\tilde{S}(\mathcal{E})\subseteq\widehat{S}(\mathcal{E})
as
p^{*}_{i}\leq\tilde{p}^{*}_{i}(\alpha)
.
Given that both
\widehat{S}(\mathcal{E})
and
\widehat{S}^{\text{ICP}}(\mathcal{E})
control the FWER,
using
\widehat{S}(\mathcal{E})
seems to improve upon the original ICP approach.
However,
p^{*}_{i}<\tilde{p}^{*}_{i}(\alpha)
only occurs when
p_{S}\leq\alpha
for all
S\subseteq[m]
.
In such cases,
\widehat{S}^{\text{ICP}}(\mathcal{E})=\emptyset
and
\widehat{S}(\mathcal{E})=[m]
,
which seems useless because even
p_{S^{*}}\leq\alpha
, leading to a false rejection of
H_{0,S^{*}}(\mathcal{E})
.
In practice,
\widehat{S}(\mathcal{E})
and
\widehat{S}^{\text{ICP}}(\mathcal{E})
are generally equivalent.

4
Can we control less conservative errors for ICP?

4.1
FDR control does not seem well-suited for ICP

Proposition
3.3
shows that
directly comparing
p^{*}_{1},\dots,p^{*}_{m}
to the nominal level automatically ensures FWER control,
as if there were no multiple testing issue.
This is somewhat unexpected, as one would typically need to apply multiple testing adjustments (e.g., Bonferroni correction) to control the FWER.
Consequently, there is no need to further apply FDR control procedures to
p^{*}_{1},\dots,p^{*}_{m}
.

Given this,
the only remaining hope for obtaining more causal discoveries through FDR control is that
the construction (
5
) of
p^{*}_{i}
based on
p_{S}
is conservative.
Then,
if a more powerful method for obtaining smaller p-values for
H^{*}_{0,i}
based on
p_{S}
can be proposed,
we might return to the “normal” situation where directly comparing these p-values to the nominal level no longer controls the FWER.
If this could be achieved, applying FDR control procedures may lead to more causal discoveries.
Unfortunately, as we will show below,
p^{*}_{i}
defined by (
5
) does not appear to be conservative.

We consider a special case where the optimal
p_{S}
can be obtained for testing
H_{0,S}(\mathcal{E})
.
That is, we have
p_{S}\sim U(0,1)
for true null hypothesis and
p_{S}=0
for false null hypothesis.
This represents the most desirable scenario, where powerful tests for
H_{0,S}(\mathcal{E})
are available.
It is also called the Dirac-uniform configuration
(
Finner et al., 2009
)
.
Note that obtaining these
p_{S}
values is a separate task from constructing a valid p-value for the hypothesis (
4
) based on them.

Then, for
i\in S(\mathcal{E})
(see (
2
)), which is an identifiable causal predictor based on ICP, the construction (
5
) yields

\displaystyle p^{*}_{i}=\max_{S\subseteq[m]\setminus\{i\}}p_{S}=0,

because
H_{0,S}(\mathcal{E})
is false for any set
S
that does not contain
i
, implying that
p_{S}=0
.
In other words, for any identifiable causal predictor, the corresponding p-value will be
0
, which is the best possible outcome.
Therefore, (
5
) does not seem to be a conservative construction for
p^{*}_{i}
.

Furthermore, if we are willing to additionally assume the following weak Assumption
4.1
, then in the case where the environment set is sufficiently rich, we can show that
p^{*}_{i}
is admissible, as demonstrated below.

Assumption 4.1

(Common null events)
.

For every measurable event
E
and every possible data distribution
P_{1}
and
P_{2}
, if
P_{1}(E)=0
, then
P_{2}(E)=0
.

This assumption means that the collection of null events is common across all considered possible distributions.
It is satisfied by most models, provided that some deterministic corner cases are excluded.
For more discussion, see the Appendix A of
Goeman et al., 2021
.

In addition, assume that we are in a scenario where the only true null hypothesis is
H_{0,S^{*}}(\mathcal{E})
.
This is the desirable setting in which all causal predictors are identifiable, and it can occur, for example, when the environment set is sufficiently rich.
In this scenario, for any
i
such that
H^{*}_{0,i}
is true, we have

p^{*}_{i}=\max_{S\subseteq[m]\setminus\{i\}}p_{S}=p_{S^{*}}.

In this special case, all null p-values are equal to
p_{S^{*}}
, providing a scenario where it is clear that directly comparing the p-values to the nominal level controls the FWER.
Then, we have

P_{H^{*}_{0,i}}(p^{*}_{i}\leq\alpha)=P_{H^{*}_{0,i}}(p_{S^{*}}\leq\alpha)=\alpha.

By the following Lemma
4.1
,
p^{*}_{i}
is admissible.
Note that both obtaining optimal
p_{S}
and having a sufficiently rich environment set
\mathcal{E}
are independent of the underlying truth regarding which variables are true causal predictors.
The admissibility
p^{*}_{i}
suggests that its construction does not seem to be conservative.

Lemma 4.1

(Lemma
7
in the Appendix A of
Goeman et al., 2021
)
.

Under Assumption
4.1
, a p-value
p
of hypothesis
H
is admissible if there exist a distribution
P
under
H
such that
P_{H}(p\leq\alpha)=\alpha
.

In general settings where
p_{S}
is not optimal,
we can not fully exclude the possibility of constructing a more powerful (i.e., smaller)
p^{*}_{i}
.
However, based on the discussions above, we believe it is unlikely that
p^{*}_{i}
can be significantly improved to yield more discoveries after applying FDR control procedures to the new p-values.
Therefore, our response to the first question raised in the introduction is negative: FDR control does not seem well-suited for ICP, and the idea of obtaining more discoveries by controlling the FDR in the context of ICP appears unpromising.

4.2
Simultaneous true discovery bound for ICP

Now, we address the second question about simultaneous true discovery bound.
Fortunately, this time, the answer is positive: we can obtain a simultaneous true discovery bound and use it to extract more causal information. Below, we present how to obtain this bound.

Based on the multiple testing formulation (
4
),
a straightforward way to obtain simultaneous true discovery bound is to apply the closed testing procedure
(
Marcus et al., 1976
;
Goeman and Solari, 2011
)
(see Appendix
A
for a brief recap).
This requires testing the intersection hypothesis

\displaystyle H^{*}_{0,S}:i\in\mathcal{N}^{*}\text{ for all }i\in S

(8)

for each
S\subseteq[m]
.
To this end, we generalize the p-value (
5
) and propose the following p-value for testing
H^{*}_{0,S}
:

\displaystyle p^{*}_{S}=\max_{I\subseteq[m]\setminus S}p_{I}.

(9)

The validity of
p^{*}_{S}
is shown in the following proposition.

Proposition 4.1
.

For any
c\in(0,1)
,

P_{H^{*}_{0,S}}(p^{*}_{S}\leq c)\leq c
.

With valid p-values
p^{*}_{S}
in hand, we can implement the closed testing procedure to obtain simultaneous true discovery bounds.
A key observation here is that due to the special construction of
p^{*}_{S}
, there is no need to implement closed testing adjustments.
To see this, if
p^{*}_{S}\leq\alpha
, we must have
p^{*}_{S’}\leq\alpha
for all
S\subseteq S’
,
indicating that if a hypothesis is locally rejected, it must be rejected by closed testing.
On the other hand, by definition, if a hypothesis is rejected by closed testing, it must be locally rejected.
Therefore, a hypothesis is rejected by closed testing if and only if it is locally rejected,
hence no closed testing adjustment is needed in this case.
This leads to the following simultaneous true discovery bound:

\displaystyle t_{\alpha}(R)=\min\{|R\setminus I|:I\subseteq R\text{ and }p^{*}_{I}>\alpha\}.

(10)

In words,
t_{\alpha}(R)
is the size of the smallest subset of
R
whose corresponding complement in
R
has a p-value larger than
\alpha
. It can be seen as a shortcut of the standard closed testing procedure, which simplifies the computation by not requiring the full implementation of all the steps in closed testing.

The theorem below formally shows that
t_{\alpha}(R)
is a simultaneous true discovery bound.

Theorem 4.1
.

Let
\alpha\in(0,1)
,
then

\displaystyle P(|R\cap S^{*}|\geq t_{\alpha}(R)\text{ for any }R\subseteq[m])\geq 1-\alpha.

(11)

Based on the simultaneous guarantee (
11
),
users can freely check any set
R
they regard as interesting, and calculate a high-probability lower bound
t_{\alpha}(R)
on the true discoveries.

The simultaneous true discovery bound encompasses both FWER control and the defining sets
(
Heinze-Deml et al., 2018
)
as special cases.
Specifically, by searching for the largest set
R
whose
t_{\alpha}(R)=|R|
, we obtain a set with FWER control; by searching for all the smallest sets
R
with
t_{\alpha}(R)=1
, we obtain the defining sets.
In particular, it is easy to check that for
\widehat{S}^{\text{ICP}}
, we have

t_{\alpha}(\widehat{S}^{\text{ICP}})=|\widehat{S}^{\text{ICP}}|
, thereby recovering the FWER control guarantee of ICP.
Hence, the same causal discoveries and information obtained from the original ICP approach are fully retained.
This indicates that using our proposed simultaneous true discovery bound to check more sets is always beneficial, which will only extract additional useful information from data. See Section
5
for illustrations.

In fact, one can also obtain a simultaneous true discovery bound based on the original ICP formulation, without resorting to the multiple testing framework

. Specifically, let

\displaystyle\tilde{t}_{\alpha}(R)=\underset{S\subseteq[m]\text{ with }p_{S}>\alpha}{\min}|R\cap S|,\quad\text{for all }R\subseteq[p].

(12)

Then, we have

P(|R\cap S^{*}|\geq\tilde{t}_{\alpha}(R)\text{ for any }R\subseteq[m])\geq P(H_{0,S^{*}}(\mathcal{E})\text{ is not rejected})\geq 1-\alpha,

where the first inequality holds by the definition of
\tilde{t}_{\alpha}(R)
.

Although obtained based on different ideas,
t_{\alpha}(R)
and
\tilde{t}_{\alpha}(R)
(see (
10
) and (
12
)) are actually equivalent, as shown in the following theorem.

Theorem 4.2
.

Let
\alpha\in(0,1)
.
For any
R\subseteq[m]
,

\displaystyle t_{\alpha}(R)=\tilde{t}_{\alpha}(R).

It is not uncommon in the literature that two seemingly different methods are actually equivalent.
For example, the simultaneous bound based on closed testing from
Goeman and Solari, 2011
is equivalent to the bound from
Genovese and Wasserman, 2006
, which does not use closed testing
(
Goeman et al., 2021
)
.
Recognizing such connections is valuable because it provides different perspectives on the same method and allows insights to be gained from different angles.
For example, in our case, understanding that
\tilde{t}_{\alpha}(R)
is equivalent to a closed testing bound helps clarify its admissibility
(
Goeman et al., 2021
)
, which is rather unclear from its original formulation (
12
).

5
Simulations and a real data application

5.1
Numerical simulations

We implement simulations to verify the simultaneous guarantee (
11
) and to illustrate the extra information one may obtain by using the simultaneous true discovery bound, compared to the original ICP approach.
All simulations were carried out in R, and the code is available at
https://github.com/Jinzhou-Li/ICPsimultaneousBounds
.

We generate samples based on the following linear structural equation model:

X^{e}\leftarrow BX^{e}+\epsilon^{e}+b^{e},

where
X^{e}=(X^{e}_{1},\dots,X^{e}_{10})^{T}
,
B
is a strict lower-triangular matrix,

6
Discussion

Motivated by the issue that FWER control in the original ICP approach can be overly conservative for some applications, resulting in few or no causal discoveries and the loss of valuable causal information, we address the error control problem of ICP in this paper.
We focus on two commonly used and more liberal error control guarantees: FDR control and simultaneous true discovery bounds. We investigate whether it is possible to generalize the original ICP approach to possess these two guarantees, thereby revealing more causal information.
The main idea is to reformulate ICP within the framework of multiple testing.
We propose valid p-values for this multiple testing problem and show the equivalence of this formulation to the original ICP approach.
Our answer for FDR control problem is negative: in this special multiple testing problem where the p-values are constructed based on ICP, FDR seems not a suitable error criterion.
However, for simultaneous true discovery bounds, we provide a positive answer and propose such bounds based on closed testing.
Through simulations and a real dataset, we demonstrate that using simultaneous true discovery bounds can indeed uncover more valuable causal information compared to the original ICP approach.
Importantly, this additional information comes at no cost, as the original information is fully retained, making it always advantageous to use in practice.

The original ICP method has been generalized to various settings, including non-linear models
(
Heinze-Deml et al., 2018
)
, sequential data
(
Pfister et al., 2019
)
, and transformation models
(
Kook et al., 2023
)
.
It would be interesting to either directly apply or generalize our proposed simultaneous true discovery bound in these settings.

When testing the null hypothesis
H^{*}_{0,i}
(see (
4
)), p-values based on the ICP approach are constructed by testing for invariance across different environments.
However, other sources of information, such as testing for conditional independence, may also provide evidence to reject
H^{*}_{0,i}
.
If new p-values can be obtained by combining information from different principles when testing
H^{*}_{0,i}
, then the simultaneous false discovery bound based on closed testing can be directly applied to provide causal discoveries with error control guarantees, and FDR control may become suitable again.
Note that it is unclear how to achieve this with the original ICP formulation.
This is another advantage of the multiple testing formulation (
4
).
For future research, it would be interesting to develop concrete methods for combining information based on different principles when testing
H^{*}_{0,i}
to achieve error-controlled causal discoveries.

Finally, we note that calculating the simultaneous true discovery bound (
10
) can become computationally intractable for large
|R|
(or large
m
). This computational challenge is also inherent in the original ICP approach, which requires testing
2^{|m|}
hypotheses. Various strategies have been proposed to address this issue, including reducing the set of potential causal predictors through pre-screening methods such as Lasso (see
Peters et al., 2016
for further discussion). Addressing this computational challenge is another interesting direction for future research.

Appendix A
A brief recap on closed testing

The closed testing procedure was originally introduced for controlling the familywise error rate
(
Marcus et al., 1976
)
. Later,
Goeman and Solari, 2011
proposed simultaneous false discovery bounds based on it.
Below, we present the three main steps of the closed testing procedure.

Consider a multiple testing problem with hypotheses
H_{1},\dots,H_{m}
.
For any
I\subseteq[m]
,
let
H_{I}=\cap_{i\in I}H_{i}
be an intersection hypothesis,
where
H_{I}
is true if and only if
H_{i}
is true for all
i\in I
.
The closed testing procedure proceeds as follows:

1.

Obtain local test results:
Locally test all intersection hypotheses
H_{I}
for
I\subseteq[m]
at level
\alpha\in(0,1)
.

2.

Implement the closed testing adjustment:
H_{I}
is rejected by closed testing if and only if
H_{J}
is locally rejected in Step 1 for all
J\supseteq I
.

3.

Obtain simultaneous false discovery bound
u^{ct}(R)
:
For any set
R\subseteq[m]
, let
u^{ct}(R)
be the size of the largest subset of
R
that is not rejected by closed testing in Step 2.

Then,
Goeman and Solari, 2011
proved that
u^{ct}(R)
is a simultaneous false discovery bound. That is,

\displaystyle{\mathbb{P}}(|R\cap\mathcal{N}|\leq u^{ct}(R),\forall R\subseteq[m])\geq 1-\alpha,

where
\mathcal{N}\subseteq[m]
is the set of null hypotheses.

Equivalently,
t^{ct}(R)=|R|-u^{ct}(R)
is a simultaneous true discovery bound satisfying

\displaystyle{\mathbb{P}}(|R\cap S^{*}|\geq t^{ct}(R),\forall R\subseteq[m])\geq 1-\alpha,

where
S^{*}=[m]\setminus\mathcal{N}
is the set of true hypotheses.
In particular, by the definition of
u^{ct}(R)
, we have that
t^{ct}(R)
is the smallest subset of
R
whose complement in
R
is not rejected by closed testing.

Proof.

(Theorem

)

\displaystyle u_{\alpha}(R)=|R|-t_{\alpha}(R)=\max\{|I|:I\subseteq R\text{ and }p^{*}_{I}>\alpha\}.

and

\displaystyle\tilde{u}_{\alpha}(R)=|R|-\tilde{t}_{\alpha}(R)=\underset{S\subseteq[m]\text{ with }p_{S}>\alpha}{\max}|R\setminus S|

Then, to show that

\displaystyle u_{\alpha}(R)=\max\{|I|:I\subseteq R\text{ and }p^{*}_{I}>\alpha\}=\max\{|I|:I\in A(R)\}

\displaystyle\tilde{u}_{\alpha}(R)=\max\{|R\setminus S|:S\subseteq[m]\text{ and }p_{S}>\alpha\}=\max\{|R\setminus S|:S\in B\}.

and

be the sets for which
