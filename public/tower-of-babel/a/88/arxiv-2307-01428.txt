Linear-time Computation of DAWGs, Symmetric Indexing Structures, and MAWs for Integer Alphabets
Yuta Fujishige, Yuki Tsujimaru, Shunsuke Inenaga, Hideo Bannai, Masayuki Takeda

Abstract
The directed acyclic word graph ( DAWG ) of a string y y of length n n is the smallest (partial) DFA which recognizes all suffixes of y y with only O ⁡ ( n ) O(n) nodes and edges. In this paper, we show how to construct the DAWG for the input string y y from the suffix tree for y y , in O ⁡ ( n ) O(n) time for integer alphabets of polynomial size in n n . In so doing, we first describe a folklore algorithm which, given the suffix tree for y y , constructs the DAWG for the reversed string y ^ \hat{y} in O ⁡ ( n ) O(n) time. Then, we present our algorithm that builds the DAWG for y y in O ⁡ ( n ) O(n) time for integer alphabets, from the suffix tree for y y . We also show that a straightforward modification to our DAWG construction algorithm leads to the first O ⁡ ( n ) O(n) -time algorithm for constructing the affix tree of a given string y y over an integer alphabet. Affix trees are a text indexing structure supporting bidirectional pattern searches. We then discuss how our constructions can lead to linear-time algorithms for building other text indexing structures, such as linear-size suffix tries and symmetric CDAWGs in linear time in the case of integer alphabets. As a further application to our O ⁡ ( n ) O(n) -time DAWG construction algorithm, we show that the set 𝖬𝖠𝖶 ⁡ ( y ) \mathsf{MAW}(y) of all minimal absent words ( MAWs ) of y y can be computed in optimal , input- and output-sensitive O ⁡ ( n + | 𝖬𝖠𝖶 ⁡ ( y ) | ) O(n+|\mathsf{MAW}(y)|) time and O ⁡ ( n ) O(n) working space for integer alphabets.



1
Introduction

1.1
Constructing DAWGs for integer alphabets

Text indexes are fundamental data structures that allow for efficient processing of string data,
and have been extensively studied. Although there are several alternative data structures which can be
used as an index, such as suffix trees
[
1
]
and suffix arrays
[
2
]
(and their compressed versions
[
3
,
4
,
5
]
),
in this paper, we focus on
directed acyclic word graphs
(
DAWGs
)
[
6
]
, which are a fundamental data structure for string processing.
Intuitively, the DAWG of string
y
,
denoted
\mathsf{DAWG}(y)
, is an edge-labeled DAG obtained by
merging isomorphic subtrees of the trie representing
all suffixes of string
y
, called the suffix trie of
y
.
Hence,
\mathsf{DAWG}(y)
can be seen as an automaton
recognizing all suffixes of
y
.
Let
n
be the length of the input string
y
.
Despite the fact that the number of nodes and edges of the suffix trie
is
\Omega(n^{2})
in the worst case,
Blumer et al.
[
6
]
proved that, surprisingly,

\mathsf{DAWG}(y)
has at most
2n-1
nodes and
3n-4
edges for
n>2
.
Crochemore
[
7
]
showed that

\mathsf{DAWG}(y)
is the smallest (partial) automaton
recognizing all suffixes of
y
,
namely, the sub-tree merging operation
which transforms the suffix trie to
\mathsf{DAWG}(y)
indeed minimizes the automaton.

Since
\mathsf{DAWG}(y)
is a DAG,
more than one string can be represented by the same node in general.
It is known that every string represented by the same node of
\mathsf{DAWG}(y)

has the same set of ending positions in the string
y
.
Due to this property, if
z
is the longest string represented by
a node
v
of
\mathsf{DAWG}(y)
, then any other string represented by
the node
v
is a proper suffix of
z
.
Hence, the
suffix link
of each non-root node of
\mathsf{DAWG}(y)

is well-defined; if
ax
is the shortest string represented
by node
v
where
a
is a single character and
x
is a string,
then the suffix link of
ax
points to the node of
\mathsf{DAWG}(y)

that represents string
x
.

One of the most intriguing properties of DAWGs
is that the suffix links of
\mathsf{DAWG}(y)
for any string
y

forms the suffix tree
[
1
]
of the reversed string of
y
.
Hence,
\mathsf{DAWG}(y)
augmented with suffix links can be seen
as a
bidirectional
text indexing data structure.
This line of research was followed by other types of
bidirectional text indexing data structures such as

symmetric compact DAWGs
(
SCDAWGs
)
[
8
]

and
affix trees

[
9
,
10
]
.

In this paper, we are particularly interested in
input strings of length
n
over an
integer alphabet
of polynomial size in
n
.
Farach-Colton et al.
[
12
]
proposed
the first
O(n)
-time suffix tree construction algorithm for
integer alphabets.
Since the out-edges of every node of the suffix tree
constructed by McCreight’s
[
11
]
and
Farach-Colton et al.’s algorithms
are lexicographically sorted,
and since sorting is an obvious
lower-bound for constructing edge-sorted suffix trees,
the above-mentioned suffix-tree construction algorithms are optimal
for ordered and integer alphabets, respectively.
Since the suffix array of
y
can be easily obtained
in
O(n)
time from the edge-sorted suffix tree of
y
,
suffix arrays can also be constructed in optimal time.
In addition, since the edge-sorted suffix tree of
y

can easily be constructed in
O(n)
time from the edge-sorted CDAWG of
y
,
and since the edge-sorted CDAWG of
y
can be constructed in
O(n)
time
from the edge-sorted DAWG of
y

[
8
]
,
sorting is also a lower-bound for constructing
edge-sorted DAWGs and edge-sorted CDAWGs.
Using the technique of Narisawa et al.
[
13
]
,
edge-sorted CDAWGs can be constructed in optimal
O(n)
time for
integer alphabets.
On the other hand,
the only known algorithm to construct DAWGs was Blumer et al.’s

O(n\log\sigma)
-time online algorithm
[
6
]

for ordered alphabets of size
\sigma
,
which results in
O(n\log n)
-time DAWG construction for integer alphabets.
In this paper, we show that the gap between the upper and lower bounds
for DAWG construction can be closed,
by introducing how to construct edge-sorted DAWGs in
O(n)
time for integer alphabets,
in two alternative ways.

It is known that the suffix tree can be augmented with
Weiner links
,
which are a generalization of the reversed suffix links.
The DAG consisting of the nodes of the suffix tree for a string
y
and its Weiner links
coincides with the DAWG of the reversed string
\hat{y}

[
6
,
15
]
.
In this paper, we first describe an
O(n)
-time folklore algorithm which computes the
sorted Weiner links
for integer alphabets, given that the suffix tree of the string is already computed.
This immediately gives us an
O(n)
-time algorithm for constructing
the edge-sorted DAWG for the reversed string
\hat{y}
over an integer alphabet.

It was still left open whether one could efficiently construct the DAWG for a string
y

from the suffix tree for
y
, in the case of integer alphabets.
We close this question by proposing an
O(n)
-time algorithm
that builds the edge-sorted DAWG for the input (forward) string
y
.
Our algorithm builds
\mathsf{DAWG}(y)
for a given string
y

by transforming the suffix tree of
y
to
\mathsf{DAWG}(y)
.
In other words, our algorithm simulates the minimization
of the suffix trie of
y
to
\mathsf{DAWG}(y)
using only
O(n)
time and space.
Our algorithm also computes the suffix links of the DAWG,
and can thus be applied to various kinds of string processing problems.
This also means that we can construct the suffix tree for the reversed string
\hat{y}
,
as a byproduct.

A simple modification to our
O(n)
-time DAWG construction algorithm
also leads us to the first
O(n)
-time algorithm to construct edge-sorted affix trees
for integer alphabets.
We remark that the previous best known affix-tree construction
algorithm of Maaß
[
10
]
requires

O(n\log n)
time for integer alphabets.

In addition, we show that our construction algorithms
for DAWGs and affix trees lead to linear-time constructions
of other indexing structures such as
symmetric CDAWGs
[
8
]
and linear-size suffix tries
[
14
]
in the case of integer alphabets.

1.2
Computing Minimal Absent Words for Integer Alphabets

As yet another application of our
O(n)
-time DAWG construction algorithm,
we present an optimal time algorithm
to compute
minimal absent words
for a given string.
There are a number of applications to minimal absent words,
including data compression
[
16
,
17
]

and molecular biology
[
18
,
19
,
20
,
21
,
22
,
23
,
24
]
.
Hence, it is important to develop
efficient algorithms for computing minimal absent words from a given string.

Let
\mathsf{MAW}(y)
be the set of minimal absent words of a string
y
.
Crochemore et al.
[
25
]
proposed
an algorithm to compute
\mathsf{MAW}(y)

in
\Theta(n\sigma)
time and
O(n)
working space.
Their algorithm first constructs
\mathsf{DAWG}(y)
with suffix links
in
O(n\log\sigma)
time and computes
\mathsf{MAW}(y)
in
\Theta(n\sigma)
time
using
\mathsf{DAWG}(y)
and its suffix links.
Since
|\mathsf{MAW}(y)|=O(n\sigma)

[
26
]
,
the output size
|\mathsf{MAW}(y)|
is hidden in the running time of their algorithm.

Later, Barton et al. proposed an alternative algorithm that computes
\mathsf{MAW}(y)

using the suffix array, in
\Theta(n\sigma)
time and space
[
27
]
.
The algorithm presented in
[
28
]
can be seen as
a parallel version of this Barton et al.’s algorithm using suffix arrays.
While all of these algorithms achieve
O(n)
running time
in the case of constant-size alphabets (
\sigma\in O(1)
),
it can require
O(n^{2})
time when
\sigma\in\Omega(n)
.

Mignosi et al.
[
26
]
gave a tight bound on
|\mathsf{MAW}(y)|

such that
\sigma\leq|\mathsf{MAW}(y)|\leq(\sigma_{y}-1)(|y|-1)+\sigma
,
where
\sigma
is the size of the underlying alphabet
and
\sigma_{y}
is the number of distinct characters occurring in
y
.
However,
|\mathsf{MAW}(y)|
can be
o(n\sigma)
for many strings.
Thus, it is important to develop an algorithm whose running time is

output-sensitive
, namely, linear in the output size
|\mathsf{MAW}(y)|
.

In this paper, we show that
\mathsf{MAW}(y)
can be computed in

optimal

O(n+|\mathsf{MAW}(y)|)
time given that
the edge-sorted DAWG of
y
is already computed.
In more detail,
given the edge-sorted DAWG for
y
,
which can be computed in
O(n)
time as above,
our algorithm computes
\mathsf{MAW}(y)
in
O(n+|\mathsf{MAW}(y)|)
optimal time.
We remark that our algorithm for computing
\mathsf{MAW}(y)
itself works within this time for general ordered alphabets.

Our algorithm is a modification of
Crochemore et al.’s algorithm
[
25
]

for finding
\mathsf{MAW}(y)
.
We emphasize that for non-constant-size alphabets Crochemore et al.’s algorithm
takes super-linear time in terms of the input string length
independently of the output size
|\mathsf{MAW}(y)|
,
and thus our result greatly improves the efficiency for integer alphabets.

1.2.1
Other efficient algorithms for computing MAWs

Belazzougui et al.
[
29
]
showed that
using a representation of the bidirectional BWT of the input string
y
of length
n
,

\mathsf{MAW}(y)
can be computed in
O(n+|\mathsf{MAW}(y)|)
time.
Although the construction time for the representation
of the bidirectional BWT was not given in
[
29
]
,
it was later shown by Belazzougui and Cunial
[
30
]

that the bidirectional BWT of a given string
y
over an integer alphabet
can be incrementally constructed in
O(n)
time.

Independently of our work,
Charalampopoulos et al.
[
31
]

proposed an
O(n)
-space data structure
which, given a positive integer
l
, computes the set
\mathsf{MAW}_{l}(y)
of
all minimal absent words of length
l

in
O(1+|\mathsf{MAW}_{l}(y)|)
query time.
This data structure can be constructed in
O(n)
time and space.
By querying this data structure for all possible
l=1,\ldots,n+1
,
one can compute
\mathsf{MAW}(y)=\bigcup_{l=1}^{n+1}\mathsf{MAW}_{l}(y)

in
O(n+|\mathsf{MAW}(y)|)
total time.

Fici and Gawrychowski
[
32
]
showed an optimal

O(N+|\mathsf{MAW}(T)|)
-time algorithm for computing all MAWs
for a rooted tree
T
of size
N
in the case of integer alphabets.
It is known that the DAWG of a tree of size
N

can have
\Omega(N^{2})
edges while its number of nodes is still
O(N)

[
33
,
34
]
.
Instead of explicitly building the DAWG for
T
,
the algorithm of Fici and Gawrychowski
[
32
]

simulates DAWG transitions by cleverly using lowest common ancestor queries
on the suffix tree of the reversed input tree
\hat{T}
.
In this view, their method can be seen as a tree input version
of our linear-time algorithm for computing MAWs.

Recently, Akagi et al.
[
35
]
proposed a space-efficient
representation of all MAWs for the input string
y
which is
based on the
run length encoding
(
RLE
).
Their data structure takes
O(m)
space and can output all MAWs in
O(|\mathsf{MAW}(y)|)
time, where
m
is the RLE size of
y
.

Preliminaries

2.1
Strings

Let
\Sigma
denote the alphabet.
An element of
\Sigma^{*}
is called a
string
.
Let
\varepsilon
denote the empty string,
and let
\Sigma^{+}=\Sigma^{*}\setminus\{\varepsilon\}
.
For any string
y
, we denote its length by
|y|
.
For any
1\leq i\leq|y|
, we use
y[i]
to denote the

i
th character of
y
.
For any string
y
, let
\hat{y}
denote the reversed string of
y
.
If
y=uvw
with
u,v,w\in\Sigma^{*}
,
then
u
,
v
, and
w
are said to be
a
prefix
,
substring
, and
suffix
of
y
,
respectively.
For any
1\leq i\leq j\leq|y|
,

y[i..j]
denotes the substring of
y

which begins at position
i
and ends at position
j
.
For convenience, let
y[i..j]=\varepsilon
if
i>j
.
Let
\mathsf{Substr}(y)
and
\mathsf{Suffix}(y)
denote
the set of all substrings and that of all suffixes of
y
, respectively.

Throughout this paper, we will use
y
to denote the input string.
For any string
x\in\Sigma^{*}
, we define
the sets of beginning and ending positions of occurrences of
x
in
y
,
respectively, by

\displaystyle\mathsf{BegPos}(x)

\displaystyle=

\displaystyle\{i\mid i\in[1,|y|-|x|+1],y[i..i+|x|-1]=x\},

\displaystyle\mathsf{EndPos}(x)

\displaystyle=

\displaystyle\{i\mid i\in[|x|,|y|],y[i-|x|+1..i]=x\}.

For any strings
u,v
, we write

u\equiv_{\mathit{L}}v
(resp.
u\equiv_{\mathit{R}}v
) when
\mathsf{BegPos}(u)=\mathsf{BegPos}(v)
(resp.
\mathsf{EndPos}(u)=\mathsf{EndPos}(v)
).
For any string
x\in\Sigma^{*}
, the equivalence classes with respect to

\equiv_{\mathit{L}}
and
\equiv_{\mathit{R}}
to which
x
belong, are respectively denoted by

[{x}]_{L}
and
[{x}]_{R}
.
Also,
\overrightarrow{x}
and
\overleftarrow{x}
respectively denote the longest elements
of
[{x}]_{L}
and
[{x}]_{R}
.

For any set
S
of strings where no two strings are of the same length,
let
\mathsf{long}(S)=\arg\max\{|x|\mid x\in S\}
and

\mathsf{short}(S)=\arg\min\{|x|\mid x\in S\}
.

In this paper, we assume that the input string
y
of length
n

is over the integer alphabet
[1,n^{c}]
for some constant
c
, and that
the last character of
y
is a unique character denoted by
\mathtt{\$}

that does not occur
elsewhere in
y
.
Our model of computation is a standard word RAM of machine word size

\log_{2}n
.
Space complexities will be evaluated by the number of words (not bits).

2.2
Suffix trees and DAWGs

Suffix trees
[
1
]
and
directed acyclic word graphs (
DAWGs
)
[
6
]

are fundamental text data structures.
Both of these data structures are based on suffix tries.
The
suffix trie
for string
y
,
denoted
\mathsf{STrie}(y)
, is a trie representing
\mathsf{Substr}(y)
,
formally defined as follows.

Definition 1
.

\mathsf{STrie}(y)
for string
y
is an edge-labeled
rooted tree
(\mathsf{V_{T}},\mathsf{E_{T}})
such that

\displaystyle\mathsf{V_{T}}

\displaystyle=

\displaystyle\{x\mid x\in\mathsf{Substr}(y)\}

\displaystyle\mathsf{E_{T}}

\displaystyle=

\displaystyle\{(x,b,xb)\mid x,xb\in\mathsf{V_{T}},b\in\Sigma\}.

The second element
b
of each edge
(x,b,xb)
is the label of the edge.
We also define the set
\mathsf{L_{T}}
of labeled “reversed” edges called the suffix links of
\mathsf{STrie}(y)

by

\mathsf{L_{T}}=\{(ax,a,x)\mid x,ax\in\mathsf{Substr}(y),a\in\Sigma\}.

As can be seen in the above definition,
each node
v
of
\mathsf{STrie}(y)
can be identified with the substring of
y

that is represented by
v
.
Assuming that string
y
terminates with a unique character
that appears nowhere else in
y
,
for each non-empty suffix
y[i..|y|]\in\mathsf{Suffix}(y)

there is a unique leaf
\ell_{i}
in
\mathsf{STrie}(y)

such that the suffix
y[i..|y|]
is spelled out by the path
from the root to
\ell_{i}
.

It is well known that
\mathsf{STrie}(y)
may require
\Omega(n^{2})
space.
One idea to reduce its space to
O(n)
is to contract
each path consisting only of non-branching edges
into a single edge labeled with a non-empty string.
This leads to the suffix tree
\mathsf{STree}(y)
of string
y
.
Following conventions from
[
8
,
37
]
,

\mathsf{STree}(y)
is defined as follows.

Definition 2
.

\mathsf{STree}(y)
for string
y
is an edge-labeled
rooted tree
(\mathsf{V_{S}},\mathsf{E_{S}})
such that

\displaystyle\mathsf{V_{S}}

\displaystyle=

\displaystyle\{\overrightarrow{x}\mid x\in\mathsf{Substr}(y)\}

\displaystyle\mathsf{E_{S}}

\displaystyle=

\displaystyle\{(x,\beta,x\beta)\mid x,x\beta\in\mathsf{V_{S}},\beta\in\Sigma^{+},b=\beta[1],\overrightarrow{xb}=x\beta\}.

The second element
\beta
of each edge
(x,\beta,x\beta)
is the label of the edge.
We also define the set
\mathsf{L_{S}}
of labeled “reversed” edges called the suffix links of
\mathsf{STree}(y)

by

\mathsf{L_{S}}=\{(ax,a,x)\mid x,ax\in\mathsf{V_{S}},a\in\Sigma\},

and denote the tree
(\mathsf{V_{S}},\mathsf{L_{S}})
of the suffix links by
\mathsf{SLT}(y)
.

Observe that each internal node of
\mathsf{STree}(y)
is a branching internal node in
\mathsf{STrie}(y)
.
Note that for any
x\in\mathsf{Substr}(y)

the leaves in the subtree rooted at
\overrightarrow{x}
correspond to
\mathsf{BegPos}(x)
.
By representing each edge label
\beta
with a pair of
integers
(i,j)
such that
y[i..j]=\beta
,

\mathsf{STree}(y)
can be represented with
O(n)
space.

An alternative way to reduce the size of
\mathsf{STrie}(y)
to
O(n)

is to regard
\mathsf{STrie}(y)
as a partial DFA
which recognizes
\mathsf{Suffix}(y)
, and to minimize it.
This leads to the directed acyclic word graph
\mathsf{DAWG}(y)
of string
y
.
Following conventions from
[
8
,
37
]
,

\mathsf{DAWG}(y)
is defined as follows.

Definition 3
.

\mathsf{DAWG}(y)
of string

y
is an edge-labeled DAG
(\mathsf{V_{D}},\mathsf{E_{D}})
such that

\displaystyle\mathsf{V_{D}}

\displaystyle=

\displaystyle\{[{x}]_{R}\mid x\in\mathsf{Substr}(y)\}

\displaystyle\mathsf{E_{D}}

\displaystyle=

\displaystyle\{([{x}]_{R},b,[{xb}]_{R})\mid x,xb\in\mathsf{Substr}(y),b\in\Sigma\}.

We also define the set
\mathsf{L_{D}}
of labeled “reversed” edges called the suffix links of
\mathsf{DAWG}(y)

by

\mathsf{L_{D}}=\{([{ax}]_{R},a,[{x}]_{R})\mid x,ax\in\mathsf{Substr}(y),a\in\Sigma,[{ax}]_{R}\neq[{x}]_{R}\}.

See Figure
1

for examples of
\mathsf{STrie}(y)
,
\mathsf{STree}(y)
,
\mathsf{DAWG}(y)
, and
\mathsf{CDAWG}(y)
.

Theorem 1

(
[
6
]
)
.

For any string
y
of length
n>2
,
the number of nodes in
\mathsf{DAWG}(y)
is at most
2n-1

and the number of edges in
\mathsf{DAWG}(y)
is at most
3n-4
.

Minimization of
\mathsf{STrie}(y)
to
\mathsf{DAWG}(y)
can be done by
merging isomorphic subtrees of
\mathsf{STrie}(y)
which are rooted
at nodes connected by a chain of suffix links of
\mathsf{STrie}(y)
.
Since the substrings represented by these merged nodes
end at the same positions in
y
,
each node of
\mathsf{DAWG}(y)
forms an equivalence class
[{x}]_{R}
.
We will make an extensive use of this property
in our
O(n)
-time construction algorithm
for
\mathsf{DAWG}(y)
over an integer alphabet.

2.3
Minimal Absent Words

A string
x
is said to be an
absent word
of another string
y

if
x\notin\mathsf{Substr}(y)
.
An absent word
x
of
y
is said to be
a
minimal absent word
(
MAW
) of
y

if
\mathsf{Substr}(x)\setminus\{x\}\subset\mathsf{Substr}(y)
.
The set of all MAWs of
y
is denoted by
\mathsf{MAW}(y)
.
For example, if

\Sigma=\{\mathtt{a},\mathtt{b},\mathtt{c}\}

and
y=\mathtt{abaab}
, then
\mathsf{MAW}(y)=\{\mathtt{aaa},\mathtt{aaba},\mathtt{bab},\mathtt{bb},\mathtt{c}\}
.

Lemma 1

(
[
26
]
)
.

For any string
y\in\Sigma^{*}
,

\sigma\leq|\mathsf{MAW}(y)|\leq(\sigma_{y}-1)(|y|-1)+\sigma
,
where
\sigma=|\Sigma|
and
\sigma_{y}
is the number of distinct
characters occurring in
y
.
These bounds are tight.

The next lemma follows from the definition of MAWs.

Lemma 2
.

Let
y
be any string.
For any characters
a,b\in\Sigma

and string
x\in\Sigma^{*}
,

axb\in\mathsf{MAW}(y)
iff
axb\notin\mathsf{Substr}(y)
,

ax\in\mathsf{Substr}(y)
, and
xb\in\mathsf{Substr}(y)
.

By Lemma
2
,
we can encode each MAW
axb
of
y
in
O(1)
space by
(i,j,b)
,
where
ax=y[i..j]
.

3
Folklore Algorithm to Construct
\mathsf{DAWG}(\hat{y})
from
\mathsf{STree}(y)
in
O(n)
Time for Integer Alphabet

For the suffix tree
\mathsf{STree}(y)=(\mathsf{V_{S}},\mathsf{E_{S}})
,
we define the set
\mathsf{WL}
of edges called
Weiner links
of
\mathsf{STree}(y)
by

\mathsf{WL}=\{(x,a,ax\beta)\mid a\in\Sigma,\beta\in\Sigma^{*},x\in\mathsf{V_{S}},\overrightarrow{ax}=ax\beta\in\mathsf{V_{S}}\}.

The following lemma on the relation between Weiner links and DAWG is well known.

Lemma 3

(
[
6
,
15
]
)
.

For the suffix tree
\mathsf{STree}(y)=(\mathsf{V_{S}},\mathsf{E_{S}})
of a string
y
,

(\mathrm{V},\mathrm{E})
is the DAWG of
\hat{y}
,
where
\mathrm{V}=\{[{x}]_{L}\mid x\in\mathsf{V_{S}}\}
and

\mathrm{E}=\{([{x}]_{L},a,[{ax\beta}]_{L})\mid(x,a,ax\beta)\in\mathsf{WL}\}
,
and
\mathrm{L}=\{([{xb\beta}]_{L},b,[{x}]_{L})\mid b\in\Sigma,x,\beta\in\Sigma^{*},(x,b\beta,xb\beta)\in\mathsf{E_{S}}\}
are the suffix links of the DAWG
(\mathrm{V},\mathrm{E})
of
\hat{y}
.

Each Weiner-link
(x,a,ax\beta)\in\mathsf{WL}
is called
explicit

if
\beta=\varepsilon
(namely,
ax\in\mathsf{V_{S}}
or equivalently
\overrightarrow{ax}=ax
),
and it is called
implicit
otherwise.
By definition, the explicit Weiner links are identical to the reversed suffix links.
Figure
2
shows a concrete example of suffix links and Weiner links.

Figure 2:

(Left): Illustration of the suffix tree
\mathsf{STree}(y)
for
y=\mathtt{aabcabcab}\$
with its suffix links.
(Right): Illustration of the suffix tree
\mathsf{STree}(y)
for
y
with its Weiner links.

By the above argument, what is left is to compute the implicit Weiner links.
In this section, we describe a folklore algorithm for computing the Weiner links
in linear time, from a given suffix tree
\mathsf{STree}(y)
augmented with the suffix links.

Let
\mathsf{p}^{1}(x)
be
\mathsf{p}(x)
and
\mathsf{p}^{i}(x)
be the parent of
\mathsf{p}^{i-1}(x)
for
i>1
in the suffix tree
\mathsf{STree}(y)
.
Then the following properties hold.

Observation 1

(
[
38
]
)
.

For each implicit Weiner link
(x,a,ax\beta)\in\mathsf{WL}
of
\mathsf{STree}(y)
with
\beta\in\Sigma^{+}
,
there exists the explicit Weiner link
(x\beta,a,ax\beta)
.
For each explicit Weiner link
(w,a,aw)
,
if
k
is the smallest integer such that
\mathsf{p}(aw)=a\mathsf{p}^{k}(w)

(i.e.
k
is the smallest integer such that
(\mathsf{p}^{k}(w),a,\mathsf{p}(aw))
is an explicit Weiner link),
then
(\mathsf{p}^{i}(w),a,aw)
is an implicit Weiner link for each
1\leq i<k
.
See Figure
3
and Figure
4
.

From Observation
1
,
every implicit Weiner link of
\mathsf{STree}(y)
is of the form
(\mathsf{p}^{i}(w),a,aw)
described above
for some explicit Weiner link
(w,a,aw)
.
Thus we can obtain all implicit Weiner links in linear time by computing
(\mathsf{p}^{i}(w),a,aw)
for
all explicit Weiner links
(w,a,aw)
which are the reversed edges of
\mathsf{L_{S}}
of
\mathsf{STree}(y)
.
This computation takes
O(n)
total time.

Theorem 2
.

Given
\mathsf{STree}(y)
and its suffix links
\mathsf{L_{S}}
of string
y
of length
n
over an integer alphabet,
the Weiner links
\mathsf{WL}
of
\mathsf{STree}(y)
can be computed in
O(n)
time.

We can obtain
\mathsf{DAWG}(\hat{y})
from
\mathsf{STree}(y)
by Lemma
3
and Theorem
2
.
We remark however that the edges of
\mathsf{DAWG}(\hat{y})

might not be sorted, since the Weiner links
\mathsf{WL}
of
\mathsf{STree}(y)
might not be sorted.
Still, we can easily sort all the edges of
\mathsf{DAWG}(\hat{y})
in
O(n)
total time
after they are constructed:
First, extract all edges of
\mathsf{DAWG}(\hat{y})
by a standard traversal on

\mathsf{DAWG}(\hat{y})
, which takes
O(n)
time.
Next, radix sort them by their labels,
which takes
O(n)
time because we assumed an integer alphabet
of polynomial size in
n
.
Finally, re-insert the edges to their respective nodes
in the sorted order.

Theorem 3
.

Given
\mathsf{STree}(y)
and its suffix links
\mathsf{L_{S}}
of string
y
of length
n
over an integer alphabet,
the edge-sorted
\mathsf{DAWG}(\hat{y})
of the reversed string
\hat{y}
with suffix links can be constructed in
O(n)
time and space.

In some applications such as bidirectional pattern searches,
it is preferable that the in-coming suffix links at each node of
\mathsf{DAWG}(\hat{y})

are also sorted in lexicographical order,
but the algorithm described above does not sort the suffix links.
However, one can sort the suffix links in
O(n)
time
by the same technique applied to the edges of
\mathsf{DAWG}(\hat{y})
.

Remark
.

It is noteworthy that the parallel DAWG construction algorithm
proposed by Breslauer and Hariharan
[
39
]

can be seen as a parallel version of the above folklore algorithm.

4
Constructing
\mathsf{DAWG}(y)
from
\mathsf{STree}(y)
in
O(n)
Time for Integer Alphabet

In this section, we present an optimal
O(n)
-time algorithm
to construct
\mathsf{DAWG}(y)
with suffix links
\mathsf{L_{D}}

for a given string
y
of length
n
over an integer alphabet.
Our algorithm constructs
\mathsf{DAWG}(y)
with suffix links
\mathsf{L_{D}}

from
\mathsf{STree}(y)
with suffix links
\mathsf{L_{S}}
.
The following result is known.

Theorem 4

(
[
12
]
)
.

Given a string
y
of length
n
over an integer alphabet,
edge-sorted
\mathsf{STree}(y)
with suffix links
\mathsf{L_{S}}
can be computed in
O(n)
time.

Figure 5:
Illustration of
\mathsf{STree^{\prime}}(y)
with string
y=\mathtt{aabcabcab\$}
.

Let
\mathcal{L}
and
\mathcal{R}

be, respectively, the sets of longest elements of all equivalence classes
on
y
w.r.t.
\equiv_{\mathit{L}}
and
\equiv_{\mathit{R}}
, namely,

\mathcal{L}=\{\overrightarrow{x}\mid x\in\mathsf{Substr}(y)\}
and

\mathcal{R}=\{\overleftarrow{x}\mid x\in\mathsf{Substr}(y)\}
.
Let
\mathsf{STree^{\prime}}(y)=(\mathsf{V_{S}^{\prime}},\mathsf{E_{S}^{\prime}})
be the edge-labeled rooted tree
obtained by adding extra nodes for strings in
\mathcal{R}
to
\mathsf{STree}(y)
, namely,

\displaystyle\mathsf{V_{S}^{\prime}}

\displaystyle=

\displaystyle\{x\mid x\in\mathcal{L}\cup\mathcal{R}\},

\displaystyle\mathsf{E_{S}^{\prime}}

\displaystyle=

\displaystyle\{(x,\beta,x\beta)\mid x,x\beta\in\mathsf{V_{S}^{\prime}},\beta\in\Sigma^{+},1\leq\forall i<|\beta|,x\cdot\beta[1..i]\notin\mathsf{V_{S}^{\prime}}\}.

Notice that the size of
\mathsf{STree^{\prime}}(y)
is
O(n)
,
since
|\mathcal{L}\cup\mathcal{R}|\leq|\mathsf{V_{S}}|+|\mathsf{V_{D}}|=O(n)
,
where
\mathsf{V_{S}}
and
\mathsf{V_{D}}
are respectively the sets of nodes of

\mathsf{STree}(y)
and
\mathsf{DAWG}(y)
.

A node
x\in\mathsf{V_{S}^{\prime}}
of
\mathsf{STree^{\prime}}(y)
is called
black

iff
x\in\mathcal{R}
.
See Figure
5
for an example of
\mathsf{STree^{\prime}}(y)
.

Lemma 4
.

For any
x\in\mathsf{Substr}(y)
,
if
x
is represented by a black node in
\mathsf{STree^{\prime}}(y)
,
then every prefix of
x
is also represented by a black node in
\mathsf{STree^{\prime}}(y)
.

Proof.

Since
x
is a black node,
x=\overleftarrow{x}
.
Assume on the contrary that there is a proper prefix
z
of
x

such that
z
is not represented by a black node.
Let
zu=x
with
u\in\Sigma^{+}
.
Since
z\equiv_{\mathit{R}}\overleftarrow{z}
, we have
x=zu\equiv_{\mathit{R}}\overleftarrow{z}u
.
On the other hand, since
z
is not black, we have
|\overleftarrow{z}|>|z|
.
However, this contradicts that
x
is the longest member
\overleftarrow{x}
of
[{x}]_{R}
.
Thus, every prefix of
x
is also represented by a black node.
∎

Lemma 5
.

For any string
y
,
let
\mathsf{BT}(y)
be the trie consisting only of the
black nodes of
\mathsf{STree^{\prime}}(y)
.
Then, every leaf
\ell
of
\mathsf{BT}(y)
is a node of the original suffix tree

\mathsf{STree}(y)
.

Proof.

Assume on the contrary that
some leaf
\ell
of
\mathsf{BT}(y)
corresponds to
an internal node of
\mathsf{STree^{\prime}}(y)
that has exactly one child.
Since any substring in
\mathcal{L}
is represented
by a node of the original suffix tree
\mathsf{STree}(y)
,
we have
\ell\in\mathcal{R}
.
Since
\ell=\overleftarrow{\ell}
,

\ell
is the longest substring of
y

which has ending positions
\mathsf{EndPos}(\ell)
in
y
.
This implies one of the following situations:
(1) occurrences of
\ell
in
y
are immediately preceded
by at least two distinct characters
a\neq b
,
(2)
\ell
occurs as a prefix of
y
and
all the other occurrences of
\ell
in
y
are immediately preceded by
a unique character
a
, or
(3)
\ell
occurs exactly once in
y
as its prefix.
Let
u
be the only child of
\ell
in
\mathsf{STree^{\prime}}(y)
,
and let
\ell z=u
, where
z\in\Sigma^{+}
.
By the definition of
\ell
,
u
is not black.
On the other hand, in any of the situations (1)-(3),

u=\ell z
is the longest substring of
y
which has ending positions

\mathsf{EndPos}(u)
in
y
.
Hence we have
u=\overleftarrow{u}
and
u
must be black, a contradiction.
Thus, every leaf
\ell
of
\mathsf{BT}(y)
is a node of the original suffix tree

\mathsf{STree}(y)
.
∎

Lemma 6

(
[
13
]
)
.

For any node
x\in\mathsf{V_{S}}
of the original suffix tree
\mathsf{STree}(y)
,
its corresponding node in
\mathsf{STree^{\prime}}(y)
is black iff
(1)
x
is a leaf of the suffix link tree
\mathsf{SLT}(y)
, or
(2)
x
is an internal node of
\mathsf{SLT}(y)
and
for any character
a\in\Sigma
such that
ax\in\mathsf{V_{S}}
,

|\mathsf{BegPos}(ax)|\neq|\mathsf{BegPos}(x)|
.

Using Lemma
5
and
Lemma
6
,
we can compute all leaves of
\mathsf{BT}(y)
in
O(n)
time
by a standard traversal on the suffix link tree
\mathsf{SLT}(y)
.
Then, we can compute all internal black nodes of
\mathsf{BT}(y)

in
O(n)
time using Lemma
4
.
Now, by Theorem
4
, the next lemma holds:

Lemma 7
.

Given a string
y
of length
n
over an integer alphabet,
edge-sorted
\mathsf{STree^{\prime}}(y)
can be constructed in
O(n)
time.

We construct
\mathsf{DAWG}(y)
with suffix links
\mathsf{L_{D}}
from
\mathsf{STree^{\prime}}(y)
,
as follows.
First, we construct a DAG
D
, which is initially
equivalent to the trie
\mathsf{BT}(y)

consisting only of the black nodes of
\mathsf{STree^{\prime}}(y)
.
Our algorithm adds edges and suffix links to
D
,
so that the DAG
D
will finally become
\mathsf{DAWG}(y)
.
In so doing, we traverse
\mathsf{STree^{\prime}}(y)
in post order.
For each black node
x
of
\mathsf{STree^{\prime}}(y)
visited in the post-order traversal,
which is either an internal node or a leaf of the original suffix tree
\mathsf{STree}(y)
,
we perform the following:
Let
\mathsf{p}(x)
be the parent of
x
in the
original suffix tree

\mathsf{STree}(y)
.
It follows from Lemma
4
that
every prefix
x^{\prime}
of
x
with
|\mathsf{p}(x)|\leq|x^{\prime}|\leq|x|

is represented by a black node.
For each black node
x^{\prime}
in the path from
\mathsf{p}(x)
to
x
in the DAG
D
,
we compute the in-coming edges to
x^{\prime}
and the suffix link of
x^{\prime}
.

Figure 6:

(Left): Illustration for a part of
\mathsf{STree^{\prime}}(y)
,
where the branching nodes are those
that exist also in the original suffix tree
\mathsf{STree}(y)
.
Suppose we have just visited node
x=s_{0}
(marked by a star)
in the post-order traversal on
\mathsf{STree^{\prime}}(y)
.
Here,
s_{0},\ldots,s_{9}
are connected by a chain of suffix links
starting from
s_{0}
, and
s_{9}
is the first black node after
s_{0}
in the chain.
In the corresponding DAG
D
,
we will add in-coming edges to the black nodes
in the path from
\mathsf{p}(x)
to
x
,
and will add suffix links from these black nodes in the path.
The sequence
s_{0},\ldots,s_{m}
of nodes in
\mathsf{STree^{\prime}}(y)
is partitioned into blocks,
such that the parents of the nodes in the same block belong to the
same equivalence class w.r.t.
\equiv_{\mathit{R}}
.
(Right): The in-coming edges and the suffix links have been added
to the nodes in the path from
\mathsf{p}(x)
to
x=s_{0}
.

Let
s_{0},\ldots,s_{m}
be the sequence of nodes
connected by a chain of suffix links starting from
s_{0}=x
,
such that
|\mathsf{BegPos}(s_{i})|=|\mathsf{BegPos}(s_{0})|
for all
0\leq i\leq m-1

and
|\mathsf{BegPos}(s_{m})|>|\mathsf{BegPos}(s_{0})|

(see the left diagram of Figure
6
).
In other words,
s_{m}
is
the first black node after
s_{0}
in the chain of suffix links
(this is true by Lemma
6
).
Since
|s_{i}|=|s_{i-1}|-1
for every
1\leq i\leq m-1
,

\mathsf{EndPos}(s_{i})=\mathsf{EndPos}(s_{0})
.
Thus,
s_{0},\ldots,s_{m-1}
form a single equivalence class w.r.t.
\equiv_{\mathit{R}}

and are represented by the same node as
x=s_{0}
in the DAWG.

For any
0\leq i\leq m-1
, let
d(s_{i})=|s_{i}|-|\mathsf{p}(s_{i})|
.
Observe that the sequence
d(s_{0}),\ldots,d(s_{m})

is monotonically non-increasing by the property of suffix trees.
We partition the sequence
s_{0},\ldots,s_{m}
of nodes
into blocks so that the parents of all nodes in the same block
belong to the same equivalence class w.r.t.
\equiv_{\mathit{R}}
.
Let
r
be the number of such blocks,
and for each
0\leq k\leq r-1
,
let
B_{k}=s_{i_{k}},\ldots,s_{i_{k+1}-1}
be the
k
th such block.
We can easily compute all these blocks by comparing
|\mathsf{p}(s_{i-1})|

and
|\mathsf{p}(s_{i})|
for each pair
s_{i-1}
and
s_{i}
of consecutive elements in the sequence
s_{1},\ldots,s_{m}
of nodes.
Note that for each block
B_{k}
,

\mathsf{p}(s_{i_{k}})
is the only black node among the parents

\mathsf{p}(s_{i_{k}}),\ldots,\mathsf{p}(s_{i_{k+1}-1})
of the nodes in
B_{k}
,
since it is the longest one in its equivalence class
[{\mathsf{p}(s_{i_{k}})}]_{R}
.
Also, every node in the same block has the same value for function
d
.
Thus, for each block
B_{k}
,
we add a new edge
(\mathsf{p}(s_{i_{k}}),b_{k},q_{k})
to the DAG
D
,
where
q_{k}
is the (black) ancestor of
x
such that

|q_{k}|=|x|-d(s_{i_{k}})+1
,
and
b_{k}
is the first character of the label of the edge
from
\mathsf{p}(s_{i_{k}})
to
s_{i_{k}}
in
\mathsf{STree^{\prime}}(y)
.
Notice that this new edge added to
D
corresponds to the edges
between the nodes in the block
B_{k}
and their parents in
\mathsf{STree^{\prime}}(y)
.
We also add a suffix link
(\mathsf{p}(q_{k}),a,\mathsf{p}(s_{i_{k}}))
to
D
,
where
a=s_{i_{k}-1}[1]
.
See also the right diagram of Figure
6
.

For each
2\leq k\leq r-1
,
let
P_{k}
be the path from
q_{k-1}
to
g_{k}
,
where
g_{k}=\mathsf{p}(\mathsf{p}(q_{k}))
for
2\leq k\leq r-2

and
g_{r-1}=x=s_{0}
.
Each
P_{k}
is a sub-path of the path from
\mathsf{p}(s_{0})
to
s_{0}
,
and every node in
P_{k}
has not been given their suffix link yet.
For each node
v
in
P_{k}
,
we add the suffix link from
v
to the
ancestor
u
of
s_{i_{k}}
such that
|s_{i_{k}}|-|u|=|s_{0}|-|v|
.
See also the right diagram of Figure
6
.

Repeating the above procedure for all black nodes of
\mathsf{STree^{\prime}}(y)

that are either internal nodes or leaves of the original suffix tree
\mathsf{STree}(y)

in post order,
the DAG
D
finally becomes
\mathsf{DAWG}(y)
with suffix links
\mathsf{L_{D}}
.
We remark however that the edges of
\mathsf{DAWG}(y)

might not be sorted, since the edges that exist in
\mathsf{STree^{\prime}}(y)

were firstly inserted to the DAG
D
.
Still, we can easily sort all the edges and suffix links of
\mathsf{DAWG}(y)
in
O(n)
total time
after they are constructed by the same technique as in Section
3
.

Theorem 5
.

Given a string
y
of length
n
over an integer alphabet,
we can compute edge-sorted
\mathsf{DAWG}(y)
with suffix links
\mathsf{L_{D}}

in
O(n)
time and space.

Proof.

The correctness can easily be seen if one recalls
that minimizing
\mathsf{STrie}(y)
based on its suffix links produces
\mathsf{DAWG}(y)
.
The proposed algorithm simulates this minimization
using only the subset of the nodes of
\mathsf{STrie}(y)

that exist in
\mathsf{STree^{\prime}}(y)
.
The out-edges of each node of
\mathsf{DAWG}(y)
are sorted in lexicographical order
as previously described.

We analyze the time complexity of our algorithm.
We can compute
\mathsf{STree^{\prime}}(y)
in
O(n)
time by Lemma
7
.
The initial trie for
D
can easily be computed in
O(n)
time
from
\mathsf{STree^{\prime}}(y)
.
Let
x
be any node visited in the post-order traversal on
\mathsf{STree^{\prime}}(y)

that is either an internal node or a leaf of the original suffix tree
\mathsf{STree}(y)
.
The cost of adding the new in-coming edges
to the black nodes in the path from
\mathsf{p}(x)
to
x=s_{0}

is linear in the number of nodes in the sequence

Definition 4
.

\mathsf{ATree}(y)

\displaystyle\mathsf{V_{A}}

\displaystyle=

\displaystyle\{(x,\hat{x})\mid x\in\mathcal{L}\cup\mathcal{R}\},

\displaystyle\mathsf{E}_{\mathsf{A}}^{F}

\displaystyle=

\displaystyle\{((x,\hat{x}),\beta,(x\beta,\hat{\beta}\hat{x}))\mid x,x\beta\in\mathsf{V_{A}}[1],

\displaystyle\{((x,\hat{x}),\hat{\alpha},(\alpha x,\hat{x}\hat{\alpha}))\mid\hat{x},\hat{x}\hat{\alpha}\in\mathsf{V_{A}}[2],

\displaystyle\phantom{\{}\alpha\in\Sigma^{+},1\leq\forall i<|\alpha|,\hat{x}\cdot\hat{\alpha}[1..i]\notin\mathsf{V_{A}}[2]\}.

Theorem 6
.

Given a string
y
of length
n
over an integer alphabet of polynomial size in

Proof.

Clearly, there is a one-to-one correspondence between

(x,\hat{x})\in\mathsf{V_{A}}
of

of

of Section
4

(see also Figure

and Figure

Moreover, there is a one-to-one correspondence between
each forward edge
(x,\beta,x\beta)\in\mathsf{E}_{\mathsf{A}}^{F}
of
\mathsf{ATree}(y)

and each edge
(x,\beta,x\beta)\in\mathsf{E_{S}^{\prime}}
of
\mathsf{STree^{\prime}}(y)

Hence, what remains is to construct the backward edges in

for
\mathsf{ATree}(y)

A straightforward modification to our DAWG construction algorithm
of Section

can construct

\mathsf{ATree}(y)

instead of working on the DAG

we directly add the suffix links to the

Since the suffix links are reversed edges,

6
Constructions of other text indexing structures

In this section, we present how our algorithms for building
DAWGs and affix trees can be applied to constructing other text indexing data structures in linear time.

6.1
DAWG for the reversed string

Here we show that the algorithm that computes affix trees from Section

can also be regarded as
a linear-time algorithm which computes the Weiner links for the forward and reversed strings simultaneously.
This will be a key to our efficient construction of other text indexing structures, which will be shown later in this section.

For the sake of simplicity,
we here use a slightly different version of Weiner links than
\mathsf{WL}
in Section

and are defined as follows:

\mathsf{mWL}=\{(x,a,ax)\mid a\in\Sigma,x\in\mathsf{V_{S}},ax\in\mathsf{Substr}(y)\}.

As in the case with (normal) Weiner links

For each implicit modified Weiner link

We note that such auxiliary nodes

are
exactly the type-2 nodes of linear-size suffix tries
[
14
]

The following theorem holds for the modified Weiner links.

For any edge

The

[

Theorem 8

[

Corollary 1

time and space.

Corollary 2

8
Conclusions

In this paper, we proposed
O(n)
-time algorithms for constructing
\mathsf{DAWG}(y)

and
\mathsf{ATree}(y)
of a given string
y
of length
n
,
over an integer alphabet of size polynomial in
n
.
These algorithms transform the suffix tree of
y
to
\mathsf{DAWG}(y)
and
\mathsf{ATree}(y)
.
We also showed how to build the symmetric CDAWG and linear-size suffix trie
for the input string over an integer alphabet.

As a further application of
\mathsf{DAWG}(y)
,
we presented an optimal
O(n+|\mathsf{MAW}(y)|)
-time algorithm to compute the set

\mathsf{MAW}(y)
of all minimal absent words of
y
when the edge-sorted DAWG for
y
is already computed.
