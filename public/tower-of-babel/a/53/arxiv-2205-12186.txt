Enhancing Continual Learning with Global Prototypes: Counteracting Negative Representation Drift
Xueying Bai, Jinghuan Shang, Yifan Sun, Niranjan Balasubramanian

Abstract
Continual learning (CL) aims to learn a sequence of tasks over time, with data distributions shifting from one task to another. When training on new task data, data representations from old tasks may drift. Some negative representation drift can result in catastrophic forgetting, by causing the locally learned class prototypes and data representations to correlate poorly across tasks. To mitigate such representation drift, we propose a method that finds global prototypes to guide the learning, and learns data representations with the regularization of the self-supervised information. Specifically, for NLP tasks, we formulate each task in a masked language modeling style, and learn the task via a neighbor attention mechanism over a pre-trained language model. Experimental results show that our proposed method can learn fairly consistent representations with less representation drift, and significantly reduce catastrophic forgetting in CL without resampling data from past tasks.

1
Introduction

Compared to a single task, machine learning with multiple tasks is more challenging as it requires handling different data distributions across tasks. Continual learning (CL), which aims to continually learn from a sequence of tasks, is a special case. Although humans naturally learn to perform multiple tasks over time, this remains an unsolved problem in machine learning
(
Flesch et al. 2018
)
. The main challenges in CL are to prevent catastrophic forgetting, in which models forget what was learned in old tasks after learning new tasks; and manage forward and backward knowledge transfer across tasks
(
Lopez-Paz & Ranzato 2017
)
.

Negative representation drift is one of the causes of catastrophic forgetting. Representation drift is a phenomenon that data representations for the old tasks change and drift after learning new tasks
(
Caccia et al. 2022
)
. When negative drift happens, the representational separability for the old tasks could reduce under their original decision boundaries, resulting in forgetting.
For example, in
Figure 1
(a), learning Task 2 causes model updates which result in the classes of the task being overly separated. This forces all data representations for Task 1 to drift to one class in Task 2. In the end, data representations for Task 1 are less separable, and the original decision boundary can no longer classify the drifted representations. Without retraining involving data from Task 1, such representation drift will cause forgetting.

Our goal is to mitigate the negative representation drift.
For classification, the class prototypes

and the data representations work together to learn a task. Class prototypes decide the decision boundary, and data representations are learned with reference to the boundary.
To mitigate the representation drift, it is desirable to control the prototypes and representations to maintain reasonable relationships across tasks, instead of overfitting the current task.
For example, in
Figure 1
(b), the classification for Task 2 is controlled.
In this case, data representations for Task 1 can still retain their separability under the original decision boundary. Such cross-task relationship control is difficult because the learning of each task in CL is local, with no data from other tasks.
In this paper, we propose to overcome the locality by regularizing each task’s learning over shared
global prototypes
.
The global prototypes themselves should be task-agnostic, but can be used to describe task-specific information.
Then the cross-task relationships will be implicitly utilized in each task’s learning by referring to those global prototypes.

For NLP tasks, we can define the global prototypes from the token level, because any text data come from tokens in a fixed vocabulary and the task-specific information can also be summarized by a set of tokens from the data.
For example, in the data ‘
Do you know about
servers
? A server is a
system
that provides services over a
network
’ from the ‘
Computer
’ class, the tokens {‘
servers
’, ‘
system
’, ‘

’} are those to classify the data as about computers. Formally, we define the data tokens which are crucial for predicting the corresponding task as
task tokens
.
Therefore,
the task-specific information can be addressed by predicting task tokens based on global prototypes of tokens

2

In this paper, prototypes of tokens in a fixed vocabulary are vectors in the weight matrix of the decoder.
, which are usually pre-trained via self-supervised learning (e.g., masked language modeling
(
Devlin et al. 2018
)
).
The idea of learning task-specific information based on global prototypes takes inspiration from neuroscience. The brain (which arguably is a successful CL system) prefers not to create new neurons, but rewires connections to existing neurons to learn new tasks
(
Gurbuz & Dovrolis 2022
)
. Analogously, predicting task tokens can be viewed as activating specific units in the fixed vocabulary net given the stimulus of input.

To regularize each task’s learning, we can encourage the learning of data representations that are able to explicitly predict task tokens based on global prototypes.
However, the ground truth task tokens may not be available for learning, because the annotation is expensive or the task-specific information required for CL is usually beyond the current task
(
Guo et al. 2022
)
.
In this case, we find an implicit way to the regularization by learning representations that can predict task tokens without direct supervision.
In Section
2
, we show that the masked language modeling (MLM) objective
(
Devlin et al. 2018
)
, which is used to pre-train the language model, is indeed an unsupervised variant of our explicit regularization.
Therefore, we can implicitly regularize the learning by relying on a pre-trained language model, with carefully designed adaptation to target tasks. The tasks are also formulated in an MLM style. To adapt to target tasks while greatly preserving the pre-trained information, we design a neighbor attention module adding to the pre-trained model. The module searches for task-specific information from the neighborhood of data, and control the ratio of task-specific information mixing up with the pre-trained information. We evaluate the regularization effect by using the learned representations to predict task tokens on an annotated dataset.

Previous studies show that mitigating negative representation drift can also benefit existing CL frameworks. For example,
Caccia et al. 2022
pointed out that the abrupt representation change may cause problems in Experience Replay
(
Chaudhry et al. 2019b
)
. Methods retrieving relevant past data
(
Sprechmann et al. 2018
;
de Masson D’Autume et al. 2019
)
by comparing the end-of-training representations to those stored in the memory are also sensitive to the representation drift.

In conclusion, our contributions in this paper are:

(i)
proposing a regularization objective to mitigate negative representation drift for CL, which is realized by a reformulated prediction task and a neighbor attention model based on the pre-trained language model;

(ii)
experimental results on different parameter-efficient models and CL frameworks show that our method is well-regularized over global prototypes and significantly reduces the forgetting in CL even without the memory of past data.

2
Learning over Global Prototypes

We consider the scenario of task-aware CL with a sequence of tasks. Each task consists of a task descriptor
\tau
and the corresponding data
\mathcal{D}_{\tau}=\{(\mathbf{x}_{\tau}^{(i)},y_{\tau}^{(i)})_{i=1}^{n_{\tau}}\}
, where
\mathbf{x}
is the input data and
y\in\mathbb{R}
is the class label. We also provide the set of label tokens (e.g.
\{positive,\,negative\}
) for each task. The goal of this paper is to learn data representations with mitigated drift in CL. Our main model consists of two components: an encoder
f_{\theta}
to generate data representations and a classifier
g_{\gamma}
for prediction.

Notation
Some notations used in this section:
C_{\tau}
represents all classes for each task
\tau
,
C=\{C_{1},...C_{\tau},...\}
represents all classes for all tasks.
V
represents the vocabulary that contains all tokens.
w(\mathbf{x})
is a set of task tokens for
\mathbf{x}

.

2.1
The Local Classification Objective

For each task
\tau
, the typical classification objective is to minimize the cross-entropy loss:

\displaystyle\mathcal{L}_{c}(\mathbf{x}_{\tau})=-\sum_{\mathbf{x}_{\tau}}\log\frac{\exp\big(\mathbf{W}_{\gamma}^{y_{\tau}}f_{\theta}(\mathbf{x}_{\tau})\big)}{\sum_{c\in C_{\tau}}\exp\big(\mathbf{W}_{\gamma}^{c}f_{\theta}(\mathbf{x}_{\tau})\big)},

(1)

where
f_{\theta}(\mathbf{x}_{\tau})\in\mathbb{R}^{d}
is the representation of
\mathbf{x}_{\tau}
,
\mathbf{W}_{\gamma}\in\mathbb{R}^{{|C|}\times{d}}
is the weight matrix of the classifier (trainable).
\mathbf{W}^{c}_{\gamma}
can be viewed as the prototype of each class
c\in C_{\tau}
.

The loss in Eq. (
1
) is local, which considers data and classes only from task
\tau
. This may result in the learned class prototypes and data representations also being local, which either are not globally well-scattered after learning the current task, or can be abruptly changed after learning later tasks.

2.2
Explicit Regularization Based on Global Prototypes

To mitigate negative representation drift caused by the local learning, we propose to describe the class-related information based on some well-correlated global prototypes, and regularize the learning based on them. Naturally, global prototypes for NLP data can be the prototypes of tokens in a vocabulary. After pre-training by MLM, the global prototypes which are semantically correlated can be given by the pre-trained decoder. We can describe the task-specific information for data
\mathbf{x}_{\tau}
by a set of task tokens
w(\mathbf{x}_{\tau})
, where the size
|w(\mathbf{x_{\tau}})|=m
can vary for different data. To regularize the learning with task-specific information based on global prototypes, we can minimize the loss for predicting
w(\mathbf{x}_{\tau})
:

\displaystyle\hskip-5.69046pt\mathcal{L}_{w}(\mathbf{x}_{\tau})=-\sum_{\mathbf{x}_{\tau}}\sum_{i=1}^{m}\log\frac{\exp\big(\mathbf{W}_{\delta}^{w_{i}(\mathbf{x}_{\tau})}f_{\theta}(\mathbf{x}_{\tau})\big)}{\sum_{w\in V}\exp\big(\mathbf{W}_{\delta}^{w}f_{\theta}(\mathbf{x}_{\tau})\big)},

(2)

here
w_{i}(\mathbf{x}_{\tau})
is the
i
-th token in
w(\mathbf{x}_{\tau})
,
\mathbf{W}_{\delta}\in\mathbb{R}^{{|V|}\times{d}}
is the weight matrix of the pretrained decoder (fixed).
\mathbf{W}^{w}_{\delta}
can be viewed as the prototype of each token
w\in V
, which is shared across all tasks. Therefore, the cross-task relationships will be considered in each task’s learning by referring to those global prototypes.

With this regularization, the overall CL objective for
\mathbf{x}_{\tau}
is to minimize the loss:

\displaystyle\mathcal{L}(\mathbf{x}_{\tau})=\mathcal{L}_{c}(\mathbf{x}_{\tau})+\mathcal{L}_{w}(\mathbf{x}_{\tau}),

(3)

which is the sum of Eq. (
1
) and Eq. (
2
). However, Eq. (
2
) is hard to estimate because the ground truth
w(\mathbf{x}_{\tau})
is usually unavailable. We then show that one can implicitly achieve the regularization effect using a pre-trained language model.

2.3
Implicit Regularization via Pre-trained Model

Language models are typically pre-trained over large corpora using MLM to learn contextual information for general purposes
(
Devlin et al. 2018
;
Liu et al. 2019b
)
.
The pre-training loss on masked data can be viewed as an unsupervised variant of Eq. (
2
), in which the masked token is the task token at each masked place
. Bridging the gap between pre-training and task learning,
Brown et al. 2020
pointed out that supervised NLP tasks can also be uniformly framed in a language modeling style, and a pre-trained language model can realize zero-shot learning on target tasks with appropriate prompts. Considering such connections, it is possible that a pre-trained model with light task adaptations can learn representations that are able to predict task tokens.

For a pre-trained encoder
F_{\phi}
, the representation of data
\mathbf{x}_{\tau}
is denoted as
F_{\phi}(\mathbf{x}_{\tau})
. Adapting the pre-trained model for the task, the data representation
f_{\theta}(\mathbf{x}_{\tau})
can be described as
F_{\phi}([\mathbf{x}_{\tau},\Delta_{\theta}(\mathbf{x}_{\tau})])
, where
\Delta_{\theta}(\mathbf{x}_{\tau})
is a learnable adaptation function with parameter
\theta
, and
[\cdot,\cdot]
is some combination function. The reliance on the pre-trained model and the design of the adaptation together serve as implicit regularization of task learning. Therefore, instead of minimizing Eq. (
3
), we minimize Eq. (
1
) with an adaptation model for implicit regularization. Then the overall loss is:

\displaystyle\mathcal{L}(\mathbf{x}_{\tau})=-\sum_{\mathbf{x}_{\tau}}\log\frac{\exp\big(\mathbf{W}_{\gamma}^{y_{\tau}}F_{\phi}([\mathbf{x}_{\tau},\Delta_{\theta}(\mathbf{x}_{\tau})])\big)}{\sum_{c\in C_{\tau}}\exp\big(\mathbf{W}_{\gamma}^{c}F_{\phi}([\mathbf{x}_{\tau},\Delta_{\theta}(\mathbf{x}_{\tau})])\big)}.

(4)

The implicit regularization, ideally, can approximate the effect of the explicit regularization in Eq. (
2
). We evaluate the regularization effect in Section 4.2.

Connection to Other Works
In recent prompt tuning works, the classification task is reformulated as predicting label tokens instead of class logits
(
Lester et al. 2021
)
. Such reformulation can be viewed as formulating the classification loss for
\mathbf{x}_{\tau}
as
\mathcal{L}_{c}(\mathbf{x}_{\tau}):=\mathcal{L}_{w}(\mathbf{x}_{\tau})
, with the label token being the only task token in
w(\mathbf{x}_{\tau})
. However, by summarizing the data with only one task token, the representation may have less ability to contain holistic information of data for future use
(
Guo et al. 2022
)
. Our objective with implicit regularization, on the other hand, does not restrict the task tokens to be contained in
w(\mathbf{x}_{\tau})
. So it can better preserve the holistic information of data. Moreover, predicting label tokens may require text-to-text models
(
Brown et al. 2020
;
Raffel et al. 2019
)
, which is not required for our objective.

The final loss
\mathcal{L}(\mathbf{x}_{\tau})
using the pre-trained model is also related to that of parameter-efficient tuning. However, most parameter-efficient models focus on reducing trainable parameters without sacrificing task performance.
Although we also use pre-trained models for implicit regularization, unlike parameter-efficient models, learning each task thoroughly is more important than reducing trainable parameters in our case.
Moreover, some existing parameter-efficient models show inferior performance in regularizing the learning (Section
4.2
). The design of the adaptation module will highly influence the effect of the regularization. We discuss more about this in Section
3
.

3.1
Single Task Formulation

In this paper, we focus on sentence classification tasks. For the task
\tau
, each sample
(\mathbf{x}_{\tau},y_{\tau})
consists of a sentence pair
\mathbf{x}_{\tau}=[\mathbf{x}_{\tau 1},\mathbf{x}_{\tau 2}]

(
Devlin et al. 2018
)
, and a class label
y_{\tau}\in C_{\tau}
where
C_{\tau}
represents all classes in
\tau
. We denote
|C_{\tau}|=p_{\tau}
which is the number of classes in
\tau
. The sentence representation of
\mathbf{x}_{\tau}
is given by any encoder and is passed to a classifier to predict
y_{\tau}
.

In the typical setup, the input has a format of
[CLS]

\mathbf{x}_{\tau 1}

[SEP]

\mathbf{x}_{\tau 2}

[SEP]
, and the sentence representation is the
[CLS]
representation. However, in our work, we formulate classification tasks to be close to the MLM task to better guide the model for implicit regularization. Specifically, we add a
[MASK]
token in the input and get the sentence representation from it. Label tokens
\{Y_{1},Y_{2},...,Y_{p_{\tau}}\}
in the task descriptor
\tau
is also added at the front of the input. So the input for the task has the format:

\vskip-2.0pt\hskip-8.5359pt\texttt{[CLS]}\;Y_{1}\text{ or }Y_{2}\text{ or }...\text{ or }Y_{p_{\tau}}\text{ of }\;\texttt{[MASK]}\;\texttt{[SEP]}\\
\mathbf{x_{\tau 1}}\;\texttt{[SEP]}\;\mathbf{x_{\tau 2}}\;\texttt{[SEP]}

(5)

The added label tokens help to identify inputs from different tasks, and incorporate the task information in a token level.

3.2
Transformer with Neighbor Attentions

The design of the pretrained-model-based adaptation, i.e.
F_{\phi}([\mathbf{\cdot},\Delta_{\theta}(\mathbf{\cdot})])
in Eq. (
4
), will highly influence the effect of the implicit regularization. According to
He et al. 2021
, different adaptations of the pre-trained model can be viewed as learning different modification vectors
\Delta\mathbf{h}
on each hidden representation
\mathbf{h}\in\mathbb{R}^{d}
, where
\mathbf{h}
is generated by the pre-trained model and
\Delta\mathbf{h}
is generated by the added structure. To get representations comparable in the scale of pre-trained representations, we design our module based on the composition
\mathbf{h}\leftarrow(1-\lambda)\mathbf{h}+\lambda\Delta\mathbf{h}
, where
\lambda\in[0,1]
can depend on
\mathbf{h}
and
\Delta\mathbf{h}
. To control the adaptation to contain more information of potential task tokens over global prototypes, we propose a neighbor attention module which learns task-specific information based on neighbors of data token representations, and explicitly sets
\lambda=0.1
to control the influence of
\Delta\bf{h}
. The module is added to specific transformer layers. An overall view is shown in
Figure 2
.

Neighbor Selection

Before feeding hidden representations into the first neighbor attention layer, we select the initial neighborhood of the hidden representation
\mathbf{h}
by comparing it to token embeddings
\mathbf{E}\in\mathbb{R}^{|V|\times d}
from the pre-trained embedding layer . The similarity between the
i
-th token embedding
{\bf{e}}_{i}
and
{\bf{h}}
is defined as:
\texttt{sim}({{{\bf{e}}_{i}}},{\bf{h}})={{{{\bf{e}}_{i}}^{T}}{\bf{h}}}
. We randomly select
k
embeddings out of top-
K
candidates as neighbors of
{\bf{h}}
, where
K
controls the range of the initial neighborhood. The positional embedding at
\bf{h}
’s place will also be added to get final neighbor embeddings.

We then simply add a deviation to transform neighbor embeddings to the hidden space
3
3

3

Better choices for this transformation (e.g. additional linear transformations) may further benefit the representation learning.
. The transformed neighbour representation
{\bf{m}}_{i}
is:

{\bf{m}}_{i}=\text{LN}_{e}\big({\bf{e}}_{i}-{\bf{e}}+{\bf{h}}\big),

where
{\bf{e}}
is the embedding of the token of
\bf{h}
, LN
e
is a layer normalization term
(
Ba et al. 2016
)
. The neighbor selection is only performed once, before the first neighbor attention layer.

Neighbor Attention Layer

In a neighbor attention layer, we separately calculate the self-attention output and the neighbor attention output, then mix them up for layer output.

Given inputs of hidden representations
{\bf{H}}=[{\bf{h}}_{1},...,{\bf{h}}_{n}]
, the self-attention output for each
{\bf{h}}_{i}
is:

\displaystyle{\bf{h}}^{\prime}_{i}

\displaystyle=f\big(\text{MHA}\big({\bf{Q}}({\bf{h}}_{i}),{\bf{K}}({\bf{H}}),{\bf{V}}({\bf{H}})\big)\big),

where MHA is the multi-head attention function (Appendix
B.1
),
f
is a linear function,
{\bf{Q}}
,
{\bf{K}}
,
{\bf{V}}
are query, key, value functions. All parameters above are pre-trained and fixed.

Denoting the neighbor representations of
{\bf{h}}_{i}
as
{{\bf{M}}_{i}}=[{\bf{m}}_{i1},...,{\bf{m}}_{ik}]
, the neighbor attention output is:

\displaystyle\Delta{\bf{h}}^{\prime}_{i}

\displaystyle=f\big(\text{MHA}\big({\bf{Q}}({\bf{h}}_{i}),{\bf{K}}_{\theta}({\bf{M}}_{i}||{\bf{h}}_{i}),{\bf{V}}_{\theta}({\bf{M}}_{i}||{\bf{h}}_{i})\big)\big),

where
||
denotes the concatenation operation,
{\bf{K}}_{\theta},{\bf{V}}_{\theta}
are learnable key and value functions. We also put
{\bf{h}}_{i}
in the neighborhood because it is the nearest neighbor of itself.

Combining
{\bf{h}}^{\prime}_{i}
and
\Delta{\bf{h}}^{\prime}_{i}
, we get the updated
{\bf{h}}_{i}
:

\displaystyle{\bf{h}}^{\prime}_{i}

\displaystyle\leftarrow(1-\lambda){\bf{h}}^{\prime}_{i}+\lambda\Delta{\bf{h}}^{\prime}_{i}

\displaystyle{\bf{h}}_{i}\leftarrow\text{LN}({\bf{h}}^{\prime}_{i}+{\bf{h}}_{i})

where
\lambda=0.1
, LN is a pre-trained layer normalization.

The neighbor representation
{\bf{M}}_{i}
is also updated at each neighbor attention layer. For the
j
-th neighbor representation
{\bf{m}}_{ij}
of
{\bf{h}}_{i}
, the updated representation is:

\displaystyle{\bf{m}}^{\prime}{{}_{ij}}\leftarrow f\big(\text{MHA}

\displaystyle({\bf{Q}}({\bf{m}}_{ij}),{\bf{K}}_{b}({\bf{M}}_{i}||\tilde{{\bf{h}}}_{i}),{\bf{V}}_{b}({\bf{M}}_{i}||\tilde{{\bf{h}}}_{i}))\big)

\displaystyle{\bf{m}}_{ij}\leftarrow\text{LN}({\bf{m}}^{\prime}{{}_{ij}}+{\bf{m}}_{ij}),

where
\tilde{{\bf{h}}}_{i}
means ‘stop gradient’ for
{\bf{h}}_{i}
. We stop gradients here to reduce deviation from the pre-trained model.

Adding neighbor attention on more layers will increase the model capacity, but also cause more risk of biased learning and over-smoothing
(
Shi et al. 2022
)
, i.e., neighbor tokens all have same representations. In practice, we add neighbor attention to less than half of the transformer layers, and always leave the last layer frozen as a guidance. In CL, the optimal selection of layers for each task may vary. We leave the flexibility of layer selection for future work.

4
Experiment

In experiments, we mainly evaluate two abilities of models: (1) the capacity to learn tasks in the single-task and CL scenarios; (2) the ability to learn representations that are able to predict task tokens based on global prototypes. By default, all tasks are formulated by our formulation Eq. (
5
).

4.1
Model and CL Framework

Model
The effect of our implicit regularization directly depends on the model structure. We compare our model against standard fully fine-tuned models, prompt-based models, and other parameter-efficient models. For all models, we use BERT-base as the pre-trained model.

Models we compare are:
(1)
NeiAttn
: our standard neighbor attention model.
(2)
NeiReg
: our neighbor attention model with extra regularization for holistic information (Appendix
B.2
).
(3)
Fine-tuning (FT)
: the model in which all parameters are learnable.
(4)
Prompt Tuning (ProT)

(
Lester et al. 2021
)
: the model in which only prompts added to inputs are learnable. We set 100 as the prompt length.
(5)
Prefix Tuning v2 (PT2)

(
Liu et al. 2021a
)
: the model that has prompts added in inputs of all attention layers. Only prompts are learnable. We set 50 as the prompt length.
(6)
Adapter

(
Houlsby et al. 2019
)
: a parameter-efficient model with learnable adapters injected in each layer.
(7)
BitFit

(
Zaken et al. 2021
)
: a parameter-efficient model which only tunes bias terms in the pre-trained model for tasks.

For our neighbor attention models, we train with learning rates selected from {2e-4, 5e-4, 1e-3} and for {5, 8} epochs for each task. Neighbor attentions are added on the 7-11
th
layers of the pre-trained model. And we take the number of neighbors
k=5
. For prompt-based models (ProT and PT2), we train for {10, 20, 50} epochs for each task. Prompt lengths are selected according to corresponding papers.

CL Framework
We consider six frameworks for the CL evaluation: (1)
Vanilla
: the vanilla online learning framework; (2)
MBPA
: an episodic memory framework which retrieves stored samples to locally adapt the model at inference time
(
Sprechmann et al. 2018
)
. Instead of using pre-trained representations as in
de Masson D’Autume et al. 2019
, we use learned representations as keys; (3)
ER
: an ideal experience replay framework which stores all seen samples and performs sparse (1%) experience replay. For each replay, we randomly pick 32 samples from the memory for one step gradient update; (4)
A-GEM
: an episodic memory framework with constraints on gradients to not degrade average performance of previous tasks
(
Chaudhry et al. 2019a
)
; (5)
Probing
: a framework which tunes the classifier for each task at the end of CL using all training data of that task. This is used to evaluate the discrimination of data representations; (6).
MTL
: a muti-task framework which jointly trains on all tasks (for upperbound performance).

4.2
Regularization Effect Evaluated on Single Tasks

Models in the paper do not require cross-task information (e.g., data from other tasks) for each task learning, so they can also be applied to single-task setting. On single task, we evaluate models’ performance on the classification and task token prediction for regularization.

Task and Metric

For classification, we test on five tasks from the GLUE benchmark
(
Wang et al. 2019
)
, where the semantics of classes can be clearly specified via simple label tokens. The tasks include text entailment tasks (RTE, MNLI)
(
Williams et al. 2018
)
; question entailment task (QNLI)
(
Rajpurkar et al. 2016
)
, duplicate question detection (QQP)
(
Quora 2017
)
; and sentiment analysis (SST-2) on movie reviews
(
Socher et al. 2013
)
. We also use SNLI
(
Bowman et al. 2015
)
dataset for the textual entailment task. Scores reported are accuracies on development sets.

To evaluate the regularization ability, we decode the learned representations by the pre-trained decoder, and output the top-20 predicting tokens to compare with the human-annotated task tokens. The human annotated tokens are from the e-SNLI dataset
(
Camburu et al. 2018
)
, in which tokens that are essential for the task are highlighted for each SNLI data. We compute Recall@20, which is the recall of the highlighted tokens in the top-20 predictions.

Classification and Regularization Balance

Figure 3
shows the classification performance on different target tasks, with the recall for regularization evaluated on e-SNLI. For results on different ratios of SNLI data (the bottom), NeiReg performs best in achieving the balance between classification and regularization, while NeiAttn has a drop in the recall when the training data increases. For prompt tuning models, ProT performs the best for regularization, while its classification accuracies remain to be the lowest. PT2 achieves good performance for both classification and regularization. For other parameter-efficient models, BitFit has moderate performance in both classification and regularization, but does not achieve top scores on any side. The performance of Adapter is close to that of FT, with the highest classification scores but low regularization scores. When training data increases, most models suffer from the performance drop for regularization while enjoying better classification scores. Neighbor attention models have a more rapid performance drop for regularization compared to prompt tuning methods. This may be because they have more parameters on linear transformations, which make them converge faster on the target task but also become easier to be biased to the local classification signals.

For results on GLUE (the top), no other model performs better on both classification and regularization than NeiAttn, while NeiReg does not perform well for regularization in this cross-task evaluation (i.e., training on GLUE while evaluating on e-SNLI). PT2 also achieves a good balance between classification and regularization with high scores. However, ProT loses its advantage for regularization in this setting. Overall, NeiAttn and PT2 perform best in both classification and regularization evaluations. We then mainly use them in the CL evaluation to see whether good regularization ability can lead to good CL performance.

Continual Learning Evaluation

Based on results in Section
4.2
, we select
FT
,

and

as base models for most CL evaluations. The
FT

Tasks and Metrics

We create four sequences of tasks: (1)
Yahoo 1
: a split of Yahoo dataset for news question-answer categorization
(
Zhang et al. 2015
)
with 5 disjoint tasks containing 2 classes each; (2)
Yahoo 2
: a Yahoo sequence with the same split as (1) but with more data; (3)
DB
: a split of DBPedia data for wikipedia article classification
(
Zhang et al. 2015
)
with 7 disjoint tasks containing 2 classes each; (4)
News Series
: a sequence of tasks on news-related data, including AG_news (news classification, 4 classes), MRPC (paraphrase detection, 2 classes)
(
Dolan & Brockett 2005
)
, RTE (text entailment, 2 classes) and SST (sentiment analysis, 2 classes). For the above sequences except (2), we randomly sample 1245 samples per class, which is the least number of class samples in our datasets. For (2), we sample 10000 samples per class. For MBPA, we perform local adaptation on 113 randomly sampled dev data per class.

We measure the average accuracy (
Acc

\uparrow
) which is the average dev accuracy of all tasks at the end of training; and average forgetting (
Forget

\downarrow
), which is the average performance decrease of each task between its maximum accuracy and the accuracy at the end. For each sequence of data, we perform five runs with the randomized ordering of tasks, and report the average and standard deviation on above metrics.

Results

The quantitative results are shown in Table
1
. Even in the vanilla setting, both PT2 and NeiAttn significantly outperform the FT model, with very limited forgetting for all sequences.
With MBPA, FT performs even worse than the vanilla setting for most task sequences. However, for PT2 and NeiAttn, MBPA consistently helps to improve performance. We believe that the improvement of MBPA relies on the quality of the learned representation. In this case, a model that performs well in the vanilla setting is more likely to be better improved by MBPA. With ER, the forgetting problem in FT is marginally mitigated on 3/4 sequences, while on Yahoo 1 it becomes more severe. This might result from the overfitting of the replay buffer. Interestingly, we observe that both FT and NeiAttn improve with ER. Whenever ER benefits FT even if marginally, it usually also benefits NeiAttn. Such a trend might indicate that NeiAttn shares some properties of FT. With Probing, FT performs worse than NeiAttn and PT2, which shows there is a loss of task-specific information in its representation. In general, NeiAttn performs on-par with PT2, and both of them consistently outperform FT under different CL frameworks. These improvements come not just from having fewer parameters. The Adapter and Pre-trained models, with limited or no parameter tuning, do not achieve comparable performance in most cases.

On News Series which has correlated text distributions across different tasks, although PT2 performs best with vanilla and MBPA, it has a performance drop with ER. This may indicate that PT2 can be disrupted when training with similar data from different tasks. On the other hand, NeiAttn performs less well in the vanilla and MBPA setting, but can be effectively improved by ER. Also, results under the Probing framework show that the representations from NeiAttn preserve most information for predicting each task.

5
Related Work

Continual Learning

Models for CL can be divided into three main categories: regularization-based models minimize the deviation of new parameters from the older ones
(
Kirkpatrick et al. 2017
;
Zenke et al. 2017
;
Aljundi et al. 2018
;
Lee et al. 2017
)
; rehearsal-based models reduce catastrophic forgetting by rehearsal on real or pseudo samples from previous tasks with episodic memory
(
Lopez-Paz & Ranzato 2017
;
Chaudhry et al. 2019a
)
or generative models
(
Shin et al. 2017
;
Kemker & Kanan 2017
)
; architecture-based models learn
evolving architectures for CL, with their capacity for each task carefully assigned
(
Rusu et al. 2016
;
Yoon et al. 2017
)
. Recently, there are CL works addressing representation problems
(
Caccia et al. 2022
;
Madaan et al. 2021
;
Javed & White 2019
)
. Especially,
Caccia et al. 2022
propose to separate losses on the current and buffered data to mitigate the representation drift problem in Experience Replay. However, it does not target the general setting.

CL for NLP is a relatively new field
(
Biesialska et al. 2020
)
.
Liu et al. 2019a
introduce a sentence encoder with matrix conceptors; MBPA++
(
d’Autume et al. 2019
)
uses an episodic memory with replay and local adaptation to mitigate catastrophic forgetting. LAMOL
(
Sun et al. 2019
)
learns to generate training samples for replay. There are also works focusing on knowledge transfer
(
Ke et al. 2021
)
with a task capsule network. Most methods above require cross-task information (e.g. data in memory), while we show learning consistent representations with a global prototype can naturally mitigate catastrophic forgetting.

Parameter Efficient Tuning
Parameter efficient tuning learns for target tasks by tuning limited trainable parameters constructed on a pretrained model. Different methods include adding trainable parameters on the frozen transformer layer
(
Houlsby et al. 2019
;
Pfeiffer et al. 2021
;
He et al. 2021
;
Hu et al. 2021
)
; or selectively updating existed parameters during training
(
Radiya-Dixit & Wang 2020
;
Zaken et al. 2021
)
. Recently, prompt tuning
(
Li & Liang 2021
;
Lester et al. 2021
;
Liu et al. 2021b
)
is proposed to learn continuous prompt embeddings in inputs, via backpropagation through a frozen language model. However, pursuing parameter efficiency is not our goal. Instead, we show that with some design, pre-trained models can be directly utilized to benefit CL.

6
Conclusion

Negative representation drift is one of the causes of catastrophic forgetting, because the locally learned class prototypes and data representations may correlate poorly across tasks. To reduce this, we learn task-specific information based on some global prototypes shared across tasks. For NLP data, we reformulate the prediction task to be close to the masked language modeling task, and add a neighbor attention module on the pre-trained model to learn tasks with implicit regularization of global prototypes. Experiments show that our method can mitigate negative representation drift in CL, and can significantly reduce catastrophic forgetting even without data from past tasks.
We consider the main limitations of our work as: (1) requiring extra memory to compute neighbor attentions; and (2) the optimal number of neighbor attention layers may vary for different tasks.

Appendix B
Additional Details of the Model

B.1
Multi-Head Self-Attention

In single-head self-attention, we compute attention based on queries
{\bf{Q}}\in\mathbb{R}^{p\times d_{s}}
, keys
{\bf{K}}\in\mathbb{R}^{g\times d_{s}}
and values
{\bf{V}}\in\mathbb{R}^{g\times d_{s}}
:

\displaystyle\text{Attn}({\bf{Q}},{\bf{K}},{\bf{V}})=\text{softmax}(\frac{{\bf{Q}{{\bf{K}}^{T}}}}{{\sqrt{d_{s}}}}){\bf{V}},

(6)

where
p
,
g
are lengths of query and key-value representations, usually we have
p=g
.
d_{s}
is the dimension of the query/key/value features. In multi-head attentions, we define the query, key, value functions of the
i
-th head for a sequence of representations
\bf{X}
as:

\displaystyle{{\bf{Q}}_{i}}({\bf{X}})

\displaystyle={\bf{X}}{\bf{W}}_{q}^{(i)}

\displaystyle{{\bf{K}}_{i}}({\bf{X}})={\bf{X}}{\bf{W}}_{k}^{(i)}

\displaystyle,\,{{\bf{V}}_{i}}({\bf{X}})={\bf{X}}{\bf{W}}_{v}^{(i)}

where
{\bf{X}}\in\mathbb{R}^{p\times d_{h}}
is a sequence of
p
hidden representations with the dim
d_{h}
,
{\bf{W}}_{q}^{(i)},{\bf{W}}_{k}^{(i)},{\bf{W}}_{v}^{(i)}\in\mathbb{R}^{d_{h}\times d_{s}}
are projection matrices of queries, keys and values, respectively. The output of the multi-head attention is a concatenation of outputs of all heads:

\displaystyle\text{MHA}({\bf{Q}}({\bf{X}}),

\displaystyle{\bf{K}}({\bf{X}}),{\bf{V}}({\bf{X}}))=\text{cat}(\text{head}_{1},...,\text{head}_{t})

\displaystyle\text{head}_{i}

\displaystyle=\text{Attn}({\bf{Q}}_{i}({\bf{X}}),{\bf{K}}_{i}({\bf{X}}),{\bf{V}}_{i}({\bf{X}}))

where
t
is the number of heads, and typically we have
d_{h}=td_{s}
. The output is then projected by a linear
f
:
\mathbb{R}^{d_{h}}\rightarrow\mathbb{R}^{d_{h}}
, and followed by the layer normalization and residual connection to get the final output of the layer.

B.2
Regularization For NeiReg

One advantage of the neighbor attention model is that neighborhood representations correspond directly to each input token, which makes it easier to guide the training of those representations, compared to prompt tuning. Based on this, we can further guide sentence representations to contain more information about the data.

Context Regularization

To encourage sentence representations to be close to text token representations, we encourage
{\bf{h}}_{\texttt{[MASK]}}
at each layer
l
to be close to neighbor representations of the context tokens, which is measured by cosine similarity:

\displaystyle L_{m}^{(l)}

\displaystyle=\mathbb{E}_{i\in\{{\bf{x_{\tau 1}}},{\bf{x_{\tau 2}}},Y\}}\mathbb{E}_{j}\big[\text{cos}\big({\bf{h}}^{(l)}_{\texttt{[MASK]}},sg({\bf{m}}^{(l)}_{ij})\big)\big],

where
sg
means ‘stop gradient’. We estimate the expectation on neighbors of any hidden representation
{\bf{h}}_{i}
by uniformly sampling a neighbor from the
k
neighbors of
{\bf{h}}_{i}
at each time, when calculating the cosine similarity.

Neighborhood Regularization

L_{m}
above is directly correlated to neighbor representations. To better control the correlation, we can add regularization to discourage neighbor representations from moving too far away from context representations. The regularization term is:

\displaystyle L_{n}^{(l)}=\mathbb{E}_{ij}\text{cos}\big(sg({\bf{h}}^{(l)}_{i}),{\bf{m}}^{(l)}_{ij}\big).

This encourages each neighborhood
{\bf{M}}_{i}=[{\bf{m}}_{i1},...{\bf{m}}_{ik}]
to stay nearby to its hidden representation
\bf{h}_{i}
, and not easily migrate to arbitrary spaces. The overall objective with the regularization is then to maximize
-\mathcal{L}({\bf{x}}_{\tau})
+
\mathbb{E}[L_{m}^{(l)}]
+
\mathbb{E}[L_{n}^{(l)}]
.

Appendix C
Evaluation Metric

Recall@
k

Denote the set of task tokens of the
i
-th sample as
\text{rel}_{i}
, the set of top-
k
tokens predicted from the learned sentence representation as
\text{pred}_{i}\text{@}k
. The metric recall@
k
calculates the proportion of task tokens
\text{rel}_{i}
that are predicted in
\text{pred}_{i}\text{@}k
, which is defined as:

\text{recall@}k={\mathbb{E}_{i}}\big[{|\text{pred}_{i}\text{@}k\cap\text{rel}_{i}|}\big/{{|\text{rel}_{i}|}}\big].

In this paper, we use recall@20.

Average Accuracy and Forgetting

We use the average accuracy and average forgetting similar in
(
Chaudhry et al. 2019b
)
to evaluate the performance in CL scenarios. The specific definitions are described below.

•

Average Accuracy (
Acc

\in
[0,1])
: Let
a_{i,j}
be the performance of the model on the test set of task ‘
j
’ after the model is trained on task ‘
i
’. The average accuracy after training on the task
T
is:

\displaystyle Acc_{T}=\frac{1}{T}\sum_{j=1}^{T}a_{T,j}.

In this paper, we select
T
as the end task of CL.

•

Average Forgetting (
Forget

\in
[-1,1])
: Denote
f_{i,j}
as the forgetting on task ‘
j
’ after the model is trained on task ‘
i
’.
f_{i,j}
is calculated by:

\displaystyle f_{i,j}=\max_{l\in\{1,...,i-1\}}a_{l,j}-a_{i,j}.

And the forgetting after training on the task
T
is:

\displaystyle Forget_{T}=\frac{1}{T}\sum_{j=1}^{T-1}f_{T,j}.

D.2
The Effect of Hyperparameters for Neighbor Attentions

In this section, we evaluate the influence of hyperparameters in the Neighbor Attention model, including the number of neighbor attention layers, the number of selected neighbors and the range of the initial neighborhood. All of these experiments are conducted on 10% of SNLI dataset. Results are shown in
Figure 8
.

Number of Applied Layers

Figure 8
(a) shows the influence of the number of layers that neighbor attention are applied on. In this part, we set the number of neighbors as 10, and the
K
for the initial neighborhood as 100. With the increase of neighbor attention layers, for both NeiAttn and NeiReg, the classification accuracy keeps increasing, while the recall@20 for regularization comes down at the first stage and then tends to be stable. We hypothesize that it may be because including more neighbor attention layers will introduce more trainable parameters, which makes the regularization from the pre-trained knowledge become weaker. This may result in the model succeeding in the classification but losing the ability to predict related tokens based on the global prototype.

Number of Neighbors
k

Figure 8
(b) shows the influence of the number of neighbors
k
in neighbor attention modules. In this part, we set the
K
for the initial neighborhood as 100, and the neighbor attention modules are applied on the 7
th
-11
th
pre-trained layers. For both NeiAttn and NeiReg, adding neighbors (i.e.
k>0
) will improve the classification scores. However, for regularization, NeiAttn also has an improvement with neighbors added while NeiReg has a regularization performance drop.

In NeiAttn, generally more neighbors will bring better performance for both classification and regularization. However, in NeiReg, more neighbors may downgrade the overall performance. The dynamics of further regularization used in NeiReg is not clear, so it’s hard to analyze how the change of neighbors will influence the regularization and therefore influence the performance of NeiReg. For NeiAttn, we can see that adding limited neighbors (e.g.
k=5
) can already benefit both the classification and regularization. And the performance will not change much when introducing more neighbors. So we select the
k=5
which can fit the memory requirement and achieve a relatively fast computation speed.

Range of Initial Neighborhood
K

Figure 8
(c) shows the influence of the initial neighborhood range
K
. In this part, we set the number of neighbors as 10, and the neighbor attention modules are applied to the 7
th
-11
th
pre-trained layers. With larger neighborhoods, the classification scores for both NeiReg and NeiAttn have a trend to first increase and then decrease. While the regularization scores become stable when having larger neighborhoods. Again, NeiReg and NeiAttn have similar trends in classification but different trends in regularization. In this paper, we select
K=100
to achieve an overall balance between classification and regularization.

Appendix E
Convex Hull of Self Attention

Here we show the detailed difference between our neighbor attention model and the prompt tuning. In transformer models, the single-head self-attention output of a layer can be expressed as

h^{\prime}_{i}=\sum_{j=1}^{n}\lambda_{i}^{j}f_{v}(h_{j}),

with
\lambda_{i}^{j}\geq 0
and
\sum_{j}\lambda_{i}^{j}=1
. Here
\{h_{0},...,h_{n}\}
are input representations,
\{h_{0}^{\prime},...,h_{n}^{\prime}\}
are output representations,
f_{v}
is a linear function, and
\lambda_{i}^{j}
is the attention weight measuring the attention of
h_{j}
on
h_{i}
. Imposing
\lambda_{i}^{j}\geq 0
and
\sum_{j}\lambda_{i}^{j}=1
by the softmax function means that each output representation
h_{i}^{\prime}
is within the convex hull of a linear transformation of input representations
(
Rockafellar 2015
)
. Since feed-forward functions added on the self-attention outputs afterward are independent at each token’s place, we only analyze representations after the self-attention module.

Figure 9
shows a comparison among pre-trained representations, representations of prompt-tuning on a task reformulation that predicting label tokens, and representations from the neighbor attention model on our task formulation with Eq. (2).

The representation of
[MASK]
is pre-trained to address semantic correlations among the input tokens (
Figure 9
(a)). When tuning the model for target tasks, with the standard fine-tuning objective, the label tokens are hidden to the model. In prompt tuning,
(
Lester et al. 2021
)
reformulate the prediction task into predicting label tokens instead of class logits. By adding trainable embeddings (i.e. prompts) in the input, some of the prompts may be trained to be close to the label tokens (
Figure 9
(b)). However, since the
[MASK]
representation is decoded to predict the label token, there’s no guarantee that it will contain information about other input tokens. In
Figure 9
(c), with our task formulation in Eq. (2), we explicitly tell the model about the label tokens (in the task description), thus the model can search for task-specific information considering the information of label tokens, which is especially useful for tasks in which the task description can not be easily inferred from the pre-trained knowledge. For example, for text entailment tasks, ‘I’m good today.’ and ‘Amazing day I have!’ entails to each other. But in the pre-training data, neither of these two sentences might directly correlate to tokens close to ‘entailment’. In this case, explicitly telling the model to consider the token ‘entailment’ with the data will be beneficial. Moreover, by predicting the class logit instead of specific label tokens, we can learn representations that fuse information from both sentence and label tokens, which may result in a more informative representation. The neighbor attention model further controls the integration of task-specific information and pre-trained information in the sentence representation.
