LTLDoG: Satisfying Temporally-Extended Symbolic Constraints for Safe Diffusion-based Planning
Zeyu Feng, Hao Luan, Pranav Goyal, Harold Soh

Abstract
Operating effectively in complex environments while complying with specified constraints is crucial for the safe and successful deployment of robots that interact with and operate around people. In this work, we focus on generating long-horizon trajectories that adhere to static and temporally-extended constraints/instructions at test time. We propose a data-driven diffusion-based framework, LTLDoG , that modifies the inference steps of the reverse process given an instruction specified using finite linear temporal logic ( LTL f \textnormal{LTL}_{f} ). LTLDoG leverages a satisfaction value function on LTL f \textnormal{LTL}_{f} and guides the sampling steps using its gradient field. This value function can also be trained to generalize to new instructions not observed during training, enabling flexible test-time adaptability. Experiments in robot navigation and manipulation illustrate that the method is able to generate trajectories that satisfy formulae that specify obstacle avoidance and visitation sequences. Code and supplementary material are available online at https://github.com/clear-nus/ltldog .

II
Preliminaries and Notation

In this work, our focus is to extend diffusion-based planning methods towards generating trajectories that comply with specified
\textnormal{LTL}_{f}
formulae.
Here, we provide a concise introduction to diffusion methods in the context of planning and finite linear temporal logic.

II-A

Planning with Diffusion

Many tasks in planning, reinforcement learning, and imitation learning require generating trajectories under some specific objective. Let
\mathcal{S}
and
\mathcal{A}
denote the state and action space, respectively. We use
\bm{\tau}=\left(\mathbf{s}_{0},\mathbf{a}_{0},\mathbf{s}_{1},\mathbf{a}_{1},\ldots,\mathbf{s}_{T},\mathbf{a}_{T}\right)
to refer to a trajectory, where
T
is the planning horizon. The environment transitions to a new state
\mathbf{s}_{t+1}
when an agent executes action
\mathbf{a}_{t}
at state
\mathbf{s}_{t}
. Let the abbreviation
\mathcal{J}(\bm{\tau}|g)
denote the objective value function conditioned on a goal state where the trajectory must terminate at, for example, (discounted) cumulative rewards in reinforcement learning, cumulative error of actions in imitation learning, or cost for safety constraints.

Diffusion-based planning methods directly generate partial or entire trajectories by using diffusion models pre-trained on a dataset of trajectories. Let
p_{0}\left(\bm{\tau}^{0}\right)
denote the distribution of trajectories in dataset, where
\bm{\tau}^{0}
represents a noiseless trajectory. Given an
N
-step discrete approximation of forward diffusion process
p\left(\bm{\tau}^{i}|\bm{\tau}^{i-1}\right)
that slowly corrupts data by adding prespecified noise, diffusion models learn an iterative denoising procedure by approximating the score function
\nabla_{\bm{\tau}^{i}}\log p_{i}\left(\bm{\tau}^{i}\right)
using a step-dependent neural network
s_{\theta}
trained with denoising score matching
[
10
]
:

\theta^{*}=\argmin_{\theta}\mathbb{E}_{i,\bm{\tau}^{i},\bm{\tau}^{0}}\left[\left\lVert s_{\theta}\left(\bm{\tau}^{i},i\right)-\nabla_{\bm{\tau}^{i}}\log p\left(\bm{\tau}^{i}|\bm{\tau}^{0}\right)\right\rVert^{2}\right],

(1)

in which
i\sim\mathcal{U}\{1,2,\ldots,N\}
is the diffusion timestep, and
\bm{\tau}^{i}\sim p\left(\bm{\tau}^{i}|\bm{\tau}^{0}\right)
is the trajectory
\bm{\tau}^{0}
corrupted with noise. Throughout the paper, we adopt Denoising Diffusion Probabilistic Models (DDPM)
[
5
]
as the sampling method, where
p\left(\bm{\tau}^{i}|\bm{\tau}^{0}\right)=\mathcal{N}\left(\sqrt{\bar{\alpha}_{i}}\bm{\tau}^{0},\left(1-\bar{\alpha}_{i}\right)\bm{I}\right)
,
\bar{\alpha}_{i}\mathrel{\mathop{:}}=\prod_{j=1}^{i}\alpha_{i}
,
\alpha_{i}\mathrel{\mathop{:}}=1-\beta_{i}
and
\{\beta_{i}\}
is a sequence of positive noise scales
0<\beta_{1},\beta_{2},\dots,\beta_{N}<1
.

II-B

Linear Temporal Logic (LTL)

Given a finite set of propositional symbols
\mathcal{P}
, the formula set
\Psi
of
\textnormal{LTL}_{f}
contains formulas recursively defined in Backus-Naur form as follows
[
11
,
12
]
:

\varphi\mathrel{\mathop{:}}=p\;|\;\neg\varphi\;|\;\varphi\wedge\psi\;|\;\bigcirc\varphi\;|\;\varphi\operatorname{\mathsf{U}}{}\psi,

where
p\in\mathcal{P}
and
\varphi,\psi\in\Psi
.
Intuitively, the formula
\bigcirc\varphi
(
next

\varphi
) is satisfied if
\varphi
is satisfied at the next time step.

\varphi\operatorname{\mathsf{U}}{}\psi
(
\varphi

until

\psi
) is satisfied if
\varphi
is satisfied until
\psi
is satisfied, and
\psi
is satisfied by the end of the sequence.
From these, other commonly used logical connectives and temporal operators can be defined according to the following equivalences:

\varphi\vee\psi=\neg\left(\neg\varphi\wedge\neg\psi\right)
,

\Diamond\varphi=\mathsf{true}{}\operatorname{\mathsf{U}}{}\varphi
(
eventually

\varphi
) and

\Box\varphi=\neg\Diamond\left(\neg\varphi\right)
(
always

\varphi
).
The symbols
\mathsf{true}{}
and
\mathsf{false}{}
can also be in the formula set defined by

\mathsf{true}{}=\varphi\vee\neg\varphi
and

\mathsf{false}{}=\neg\mathsf{true}{}
.

In contrast to propositional logic, these formulas are evaluated over finite sequences of observations
\bm{\sigma}=\langle\sigma_{0},\sigma_{1},\sigma_{2},\ldots\sigma_{T}\rangle
(
i.e.
,
truth assignments
to the propositional symbols in
\mathcal{P}
), where
\sigma_{t}\in\{0,1\}^{|\mathcal{P}\rvert}
and
\sigma_{t,p}=1
iff proposition
p\in\mathcal{P}
is satisfied at time step
t
.
\mathsf{true}{}
(
\mathsf{false}{}
) is always satisfied (not satisfied) by any assignment. Formally,
\bm{\sigma}

satisfies

\varphi
at time
t\geq 0
, denoted by
\langle{\bm{\sigma},t}\rangle\models\varphi
, as follows:

•

\langle{\bm{\sigma},t}\rangle\models p
iff
\sigma_{t,p}=1
, where
p\in\mathcal{P}

•

\langle{\bm{\sigma},t}\rangle\models\neg\varphi
iff
\langle{\bm{\sigma},t}\rangle\not\models\varphi

•

\langle{\bm{\sigma},t}\rangle\models(\varphi\wedge\psi)
iff
\langle{\bm{\sigma},t}\rangle\models\varphi
and
\langle{\bm{\sigma},t}\rangle\models\psi

•

\langle{\bm{\sigma},t}\rangle\models\bigcirc\varphi
iff
\langle{\bm{\sigma},t+1}\rangle\models\varphi

•

\langle{\bm{\sigma},t}\rangle\models\varphi\operatorname{\mathsf{U}}{}\psi
iff
\exists t_{2}\in[t,T]
s.t.
\langle{\bm{\sigma},t_{2}}\rangle\models\psi
and
\forall t_{1}\in[t,t_{2})
,
\langle{\bm{\sigma},t_{1}}\rangle\models\varphi

A sequence
\bm{\sigma}
is then said to
satisfy

\varphi
,
i.e.
,
\bm{\sigma}\models\varphi
, iff
\langle{\bm{\sigma},0}\rangle\models\varphi
.

III
Method

In this section, we describe our primary contribution,
LTLDoG
, a diffusion-based framework for generating trajectories that satisfy
\textnormal{LTL}_{f}
formulae. We first discuss how to conditionally sample using diffusion models, followed by how
\textnormal{LTL}_{f}
formulae can be used to guide the diffusion process.

III-A

Conditional Sampling in Diffusion Models

Given a trained score function from (
1
) such that
s_{\theta}\approx\nabla_{\bm{\tau}^{i}}\log p_{i}\left(\bm{\tau}^{i}\right)
, a diffusion model denoises
samples
according to the distribution

p_{\theta}\left(\bm{\tau}^{i-1}|\bm{\tau}^{i}\right)=\mathcal{N}\left(\frac{1}{\sqrt{\alpha_{i}}}\left(\bm{\tau}^{i}+\left(1-\alpha_{i}\right)s_{\theta}\left(\bm{\tau}^{i},i\right)\right),\left(1-\alpha_{i}\right)\bm{I}\right)

starting from a Gaussian prior
\bm{\tau}^{N}\sim\mathcal{N}\left(\bm{0},\bm{I}\right)
. For example,
Diffuser

[
1
]
samples a trajectory
\bm{\tau}^{0}
from a diffusion model, which an agent then executes. However, this original sampling process is unable to control detailed properties of generated context.

Here, we are interested in sampling trajectories that satisfy both the final goal and the specified instructions encoded as an
\textnormal{LTL}_{f}
formula
\varphi
that is provided during deployment. In other words, we aim to sample trajectories under an objective function
\mathcal{J}_{\varphi}\left(\bm{\tau}^{0}|g\right)
. For example,
\mathcal{J}
can have a high value if the events induced by
\bm{\tau}^{0}
satisfy
\varphi
and have a low value otherwise.

Formally, given a set of atomic propositions
\mathcal{P}
, the assignments for
\bm{\tau}
are given by a labeling function
L:\mathcal{S}\times\mathcal{A}\rightarrow 2^{\lvert\mathcal{P}\rvert}
, where each timestep of
\bm{\tau}
induces an assignment to the propositional symbols in
\mathcal{P}
. For example, in navigation task,
\mathcal{P}
can represent multiple regions to avoid and
L
is a function indicating whether
(\mathbf{s}_{t},\mathbf{a}_{t})
in
\bm{\tau}
are inside these regions or not. We will slightly abuse notation and write
\bm{\tau}\models\varphi
to indicate that
\bm{\tau}
’s assignments
\bm{\sigma}
satisfy a
\textnormal{LTL}_{f}
formula.

We aim to sample from the posterior
p_{0}\left(\bm{\tau}^{0}|\bm{\tau}^{0}\models\varphi,g\right)
with the diffusion model as the prior. In this work, the constraint of goal state conditioning
g
can be either achieved by inpainting (similarly on the start state
\mathbf{s}_{0}
) or implicitly encoded in the dataset, which does not require separate modeling in conditional sampling. Therefore, we mainly target the posterior
p_{0}\left(\bm{\tau}^{0}|\bm{\tau}^{0}\models\varphi\right)
. Let
y_{0}
denote a binary random variable indicating the likelihood of
\bm{\tau}^{0}
satisfying
\varphi
. Hence, the denoising process requires a score function conditioned on
y_{0}=1
and by Bayes’ rule:
\nabla_{\bm{\tau}^{i}}\log p_{i}\left(\bm{\tau}^{i}|y_{0}=1\right)=\nabla_{\bm{\tau}^{i}}\log p_{i}\left(\bm{\tau}^{i}\right)+\nabla_{\bm{\tau}^{i}}\log p_{i}\left(y_{0}=1|\bm{\tau}^{i}\right)
. The first term on the right-hand side has been learned by a neural network in diffusion. However, the latter term requires an integration over all possible values of
\bm{\tau}^{0}
:
p_{i}\left(y_{0}|\bm{\tau}^{i}\right)=\int p\left(y_{0}|\bm{\tau}^{0}\right)p_{i}\left(\bm{\tau}^{0}|\bm{\tau}^{i}\right)\mathop{}\!\mathrm{d}\bm{\tau}^{0}
.
We consider the plug-and-play conditional generation setting and approximating this integration with sample estimation
[
13
]
,
e.g.
, point estimation with
p_{i}\left(y_{0}|\bm{\tau}^{i}\right)\approx p\left(y_{0}|\hat{\bm{\tau}}^{0}\right)
where the noiseless trajectory
\hat{\bm{\tau}}^{0}
is estimated via Tweedie’s formula
[
14
]

\hat{\bm{\tau}}^{0}=\frac{1}{\sqrt{\bar{\alpha}_{i}}}\left(\bm{\tau}^{i}+\left(1-\bar{\alpha}_{i}\right)\nabla_{\bm{\tau}^{i}}\log p_{i}\left(\bm{\tau}^{i}\right)\right)
. We model the likelihood term as
p\left(y|\bm{\tau}\right)=Ze^{\mathds{1}\left[y=\mathds{1}\left[\bm{\tau}\models\varphi\right]\right]}
, where
Z
is a normalizing constant and
\mathds{1}\left[\cdot\right]
is the indicator function. Putting the above elements together, the conditional score function can be computed as follows,

\begin{split}\nabla_{\bm{\tau}^{i}}\log p_{i}\left(y_{0}|\bm{\tau}^{i}\right)&\approx\nabla_{\bm{\tau}^{i}}\log p\left(y_{0}|\hat{\bm{\tau}}^{0}\right)\\
&=\nabla_{\bm{\tau}^{i}}\log\left(Ze^{\mathds{1}\left[y=\mathds{1}\left[\hat{\bm{\tau}}^{0}\models\varphi\right]\right]}\right)\\
&=\nabla_{\bm{\tau}^{i}}\mathds{1}\left[y=\mathds{1}\left[\hat{\bm{\tau}}^{0}\models\varphi\right]\right].\end{split}

(2)

Unfortunately, both the indicator function and the satisfaction evaluation (performed by techniques like model checking with finite automata) are non-differentiable — this prohibits application in the gradient-based sampling process of diffusion models. We address this problem in the next subsection.

III-B

Differentiable Evaluation of
\textnormal{LTL}_{f}

Our key approach is to “soften” the satisfaction evaluation.
To make the evaluation differentiable, we modify our formula evaluator to output positive real values if a trajectory satisfies the
\textnormal{LTL}_{f}
formula, and negative real values otherwise. Instead of using a binary labeling functions, we assume real valued assignments of atomic propositions can be obtained through computation on the generated trajectories. As a specific example, consider a navigation task where a robot has to avoid obstacles; one can determine the assignment for proposition
p
at timestep
t
using the Euclidean distance between
\mathbf{s}_{t}
and the centers of the region
\mathbf{c}_{p}
(assuming a circular shape). A positive value of
\ell(p,t)=r_{p}-\lVert\mathbf{s}_{t}-\mathbf{c}_{p}\rVert_{2}
, where
r_{p}
is the radius of the circle, indicates a true assignment. Consequently, the labeling function for the entire trajectory
L:(\mathcal{S}\times\mathcal{A})^{T+1}\rightarrow\mathbb{R}^{\lvert\mathcal{P}\rvert\times(T+1)}
is differentiable and the assignments are
\bm{\sigma}=L(\bm{\tau})
.

A binary version of
\bm{\sigma}
through a sign function
\text{sgn}(\bm{\sigma})
satisfies the definition of
satisfy
defined in Section
II-B
, but the sign operation breaks differentiability. As such, we employ a formula evaluator
f_{t}\left(\varphi,\bm{\sigma}_{t:T}\right):\Psi\times\mathbb{R}^{\lvert\mathcal{P}\rvert\times(T-t+1)}\rightarrow\mathbb{R}
to check satisfaction
[
15
]
, with positive values implying
\langle{\bm{\sigma},t}\rangle\models\varphi
, similar to signal temporal logic
[
16
]
. As such,
f
is differentiable with the evaluation process defined as follows:

•

f_{t}(\mathsf{true}{},\bm{\sigma})=+\infty

•

f_{t}(\mathsf{false}{},\bm{\sigma})=-\infty

•

f_{t}(p,\bm{\sigma})=\bm{\sigma}_{t,p}

•

f_{t}(\neg\varphi,\bm{\sigma})=-f_{t}(\varphi,\bm{\sigma})

•

f_{t}(\varphi\wedge\psi,\bm{\sigma})=\min^{\gamma}\left\{f_{t}(\varphi,\bm{\sigma}),f_{t}(\psi,\bm{\sigma})\right\}

•

f_{t}(\varphi\vee\psi,\bm{\sigma})=\max^{\gamma}\{f_{t}(\varphi,\bm{\sigma}),f_{t}(\psi,\bm{\sigma})\}

•

f_{t}(\bigcirc\varphi,\bm{\sigma})=f_{t+1}(\varphi,\bm{\sigma})

•

f_{t}(\Box\varphi,\bm{\sigma})=\min^{\gamma}\{f_{t:T}(\varphi,\bm{\sigma})\}

•

f_{t}(\Diamond\varphi,\bm{\sigma})=\max^{\gamma}\{f_{t:T}(\varphi,\bm{\sigma})\}

•

f_{t}(\varphi\operatorname{\mathsf{U}}{}\psi,\bm{\sigma})=\min^{\gamma}\{f_{t:k}(\varphi,\bm{\sigma}),f_{t}\left(\Diamond\psi,\bm{\sigma}\right)\}
, where
k\geq t
is the smallest integer s.t.
f_{k}(\psi,\bm{\sigma})>0

Note that the
\min
and
\max
functions are likewise “soft” to maintain differentiability. To reduce clutter, we have omitted the subscript
t
when
t=0
. With these operations,
f
maintains
quantitative semantics
, which preserves the relative values between different
\bm{\sigma}
such that trajectories with larger margin to a satisfying assignment have larger values.

Given
L
and
f
, we can obtain a differentiable score function by replacing the likelihood term in (
2
) with
p\left(y|\bm{\tau}\right)=Ze^{(2y-1)f\left(\varphi,L\left(\bm{\tau}\right)\right)}
. The conditional score is then

\begin{split}\nabla_{\bm{\tau}^{i}}\log p_{i}\left(y_{0}=1|\bm{\tau}^{i}\right)&\approx\nabla_{\bm{\tau}^{i}}\log\left(Ze^{f\left(\varphi,L\left(\hat{\bm{\tau}}^{0}\right)\right)}\right)\\
&=\nabla_{\bm{\tau}^{i}}f\left(\varphi,L\left(\hat{\bm{\tau}}^{0}\right)\right).\end{split}

(3)

This approximation of the conditional score function can be directly used with a pre-trained diffusion model to sample trajectories conditioned on an
\textnormal{LTL}_{f}
formula. We call this method
LTLDoG-S
, since it performs the above posterior sampling in the reverse process (Algorithm
1
). The gradient ascent step is controlled by a stepsize
\{\zeta_{i}\}_{i=1}^{N}
; in practice, the stepsize for each denoise step can be adaptive such that
\bm{\tau}^{i-1}
remains valid according to the formula evaluator
f\left(\varphi,L\left(\hat{\bm{\tau}}^{0}\right)\right)
.

III-C

Classifier Guidance over
\textnormal{LTL}_{f}

One limitation of
LTLDoG-S
is that it necessitates a known (and differentiable) expression for the formula evaluator
f\left(\varphi,L\left(\hat{\bm{\tau}}^{0}\right)\right)
. This requirement can be challenging to meet in scenarios where the truth assignments of propositions are uncertain, for example, when the ground-truth physical dynamics are unknown. Here, we circumvent this problem by employing classifier guidance using a trained formula evaluator.

We propose a variant of
LTLDoG
with
regressor guidance
, which we abbreviate as
LTLDoG-R
. Using an
\ell_{2}
loss, we train a neural network to predict the satisfaction values from noisy trajectories conditioned on
\textnormal{LTL}_{f}
instructions. In other words, our neural network approximates the conditional score function
\nabla_{\bm{\tau}^{i}}\log p_{i}\left(y_{0}=1|\bm{\tau}^{i}\right)
. Note that in contrast to learning a binary classifier for trajectory satisfaction, we apply the labeling function in Section
III-B
on the dataset and associate with each trajectory its objective value
\mathcal{J}_{\varphi}\left(\bm{\tau}^{0}\right)
.
We conduct ablation study in Section
V-D
to show that using real values performs better than using binary labels.

To generalize over different
\textnormal{LTL}_{f}
, the neural network takes both noisy trajectory and
\textnormal{LTL}_{f}
formula embedding as input.
Multiple methods exist for embedding
\textnormal{LTL}_{f}
formulae. For instance, one can use Graph Neural Networks (GNNs)
[
17
,
18
]
to embed the tree representation of an
\textnormal{LTL}_{f}
formula directly. Alternatively, the deterministic finite-state automaton (DFA)
[
19
,
20
]
associated with the formulae can be embedded
[
21
]
.
In this work we employ
\textnormal{LTL}_{f}
tasks from
[
22
]
and embed the directed graph of an
\textnormal{LTL}_{f}
formula using the Relational Graph Convolutional Network (R-GCN)
[
23
]
, which can generalize to
\textnormal{LTL}_{f}
formulae with same template structure. The model that approximates the score function
s_{\phi}(\phi,\bm{\tau}^{i},i)\approx\nabla_{\bm{\tau}^{i}}\log p_{i}\left(y_{0}|\bm{\tau}^{i}\right)
after training can be plugged into the conditional reverse process using regressor guidance as summarized in Algorithm
2
.

IV
Related Work

LTLDoG
builds upon prior work in diffusion-based planning and symbolic reasoning using
\textnormal{LTL}_{f}
for robotics. In the following, we give a brief overview of related work.

Learning and Planning under
\textnormal{LTL}_{f}
.

As an expressive language for specifying high-level planning requirements
[
24
,
25
,
26
]
,
\textnormal{LTL}_{f}
has been extensively used in various robotic tasks to express temporally extended goals
[
27
,
28
]
.
These methods usually require the information about the environment’s dynamics,
e.g.
, a model or an abstraction, to effectively plan under a given formula. Reinforcement learning agent learn in a model-free way under
\textnormal{LTL}_{f}
objectives or constraints
[
29
,
30
,
31
]
with the ability to generalize over different formulae
[
22
]
.
However, these methods operate agent in an online manner via trial and error, which can lead to expensive or even unsafe interactions.

Planning and Policy Learning with Diffusion.

Recent diffusion-based planning methods are flexible that only rely on offline datasets without access or interaction to environments. They have been successfully applied to long-horizon planning problems by generating states or actions for control
[
1
,
3
,
2
]
, but not tasks with test-time temporal requirements.
Recent work has looked into safety critical tasks
e.g.
, the aforementioned CBF-based methods
[
7
,
8
]
. As discussed above, these methods were designed for static safety criteria, and the lack the ability to satisfy temporally extended behaviors. Our work inherits the advantages of diffusion based methods and can fulfill
\textnormal{LTL}_{f}
requirements.

Inverse Problems in Diffusion.
Our proposed method formulates conditional measurement under
\textnormal{LTL}_{f}
with differentiable loss function using the unnormalized likelihood
[
13
,
32
]
for posterior sampling and can guide the sampling process in a plug-and-play fashion.
The most popular methods to guide diffusion models during inference is classifier guidance
[
33
]
and classifier-free guidance
[
34
]
. However, these methods cannot be applied in a plug-and-play fashion for new conditioning factors. Our work is also related to inverse task that infers a posterior distribution over data given a measurement.
Inverse methods
[
35
,
36
,
37
,
38
]
do not require training a conditional model in diffusion and can directly leverage pre-trained neural networks.

VI
Conclusion, Discussion and Future Work

In this work, we presented
LTLDoG
, an approach towards generating safe trajectories that comply with
\textnormal{LTL}_{f}
specifications at test time. Within our overall scheme, we presented two methods:
LTLDoG-S
guides the sampling process under any
\textnormal{LTL}_{f}
formula while
LTLDoG-R
uses a trained model that we show generalizes to new formulae with similar structure. To our knowledge, this work is the first that successfully incorporates model checking using a formal language with diffusion models for safe planning. Notably,
LTLDoG
does not require data collection for each potential
\textnormal{LTL}_{f}
instruction; rather, we control the sampling process during diffusion using “soft” model checking to generate new trajectories using existing information provided by the training dataset.

Limitations and Future Work.

LTLDoG
is a step towards trustworthy trajectory planning using generative models. There are several areas where
LTLDoG
can be improved. Similar to other diffusion models,
LTLDoG
is generally unable to generate realistic trajectories when the context (environment/goal) is far from the training distribution. As such, the dataset should preferably contain trajectories with a variety of complex behaviors that can potentially satisfy different test-time
\textnormal{LTL}_{f}
formulae. It would be interesting to develop methods to ensure the sampling process of
LTLDoG-S
adheres to the data manifold. Additionally,
LTLDoG
plans in an open-loop fashion, where the entire trajectory is generated conditioned on the constraints.
This is mainly because the evaluation of an
\textnormal{LTL}_{f}
formula depends on the entire trajectory. We plan to further explore planning using receding horizon control using partial evaluations on an incomplete trajectory.
Finally, diffusion models usually require significant amounts of training data and many diffusion steps during inference. Recent work on interpolant diffusion methods
[
40
]
leverages source policies to reduce data and computation costs. We aim to explore how integrating this approach with conditional sampling using
\textnormal{LTL}_{f}
can enhance the generation of safe trajectories.

Prompt

In a robot navigation task, the robot is required to visit four key regions (referred to as p_0, p_1, p_2 and p_3) in specific temporal orders. The constraints on the robot’s trajectory concerning the visitation (or non-visitation) of these regions can be specified using finite Linear Temporal Logic (LTLf). Please generate several LTLf formulas (e.g., 10) that are realistic in real-world environments and tasks involving robot navigation. The details of the task and additional requirements are as follows:

1. The LTLf operators that can be used are:
\neg
(Negate),
\wedge
(And),
\vee
(Or), F (Eventually), G (Always), U (Until). Avoid using other LTL operators. Also, avoid using X (Next) since the number of timesteps needed to move from one region to another is unknown.

2. The atomic propositions are determined by whether the robot is inside p_0, p_1, p_2 and p_3. Therefore, the labelling function returns assignments with a 4-dimensional 0-1 vector at each timestep of the robot’s trajectory.

3. Only one proposition can be true at each timestep because these regions are disjoint. The robot cannot be inside any two regions simultaneously. An assignment at a timestep can be a zero vector (0, 0, 0, 0), indicating that the robot is not currently in any of these regions. This occurs when the robot is initially not in these regions and all atomic propositions are False.

4. The robot cannot move directly from one region to another as the regions might not be connected. Therefore, LTLf formulas such as p_0 U p_1 are not valid since both propositions will be False when the robot is not inside these two regions.

5. The robot’s trajectory is finite, so the robot cannot repeatedly visit different regions.

6. The LTLf formulas are supposed to apply from the first timestep of the assignment.

7. When generating an LTLf formula, please analyze the generated formula first to ensure that it is valid and that there exist assignments that can satisfy it.

On the other hand, the neural network in regressor guidance is trained on noised intermediate samples, which are linked to the data manifold. Gradients ascent on noise space will likely push the noised example to a place where both the satisfaction value and likelihood are high.
