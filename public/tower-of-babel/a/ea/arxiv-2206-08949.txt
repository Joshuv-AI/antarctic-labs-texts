Some identities for the Narayana polynomial and its derivatives
Nguyen Tien Dung

Abstract
In this note, by employing a nice property of semicircular distributions, we derive some identities for the Narayana polynomial and its derivatives.



Keywords:
Narayana polynomials, Semicircular distribution.

2020 Mathematics Subject Classification:
11B83, 60C05.

1
Introduction

The Narayana numbers
N(r,k)
and the Narayana polynomials
\mathcal{N}_{r}(z)
are defined by

N(r,k)=\frac{1}{r}\binom{r}{k-1}\binom{r}{k},

(1.1)

\mathcal{N}_{r}(z)=\sum_{k=1}^{r}N(r,k)z^{k-1}.

(1.2)

Because of their applications in Combinatorics theory, the Narayana numbers and the Narayana polynomials have been investigated by several authors. There is a large number of combinatorial properties can be found in the literature, see
[
1
,
2
,
3
,
4
]
and references therein.

The main result of this paper can be formulated as follows.

Theorem 1.1
.

For every
r\geq 3,
we have

\mathcal{N}_{r}(z)=\frac{2r-1}{r+1}(1+z)\mathcal{N}_{r-1}(z)-\frac{r-2}{r+1}(1-z)^{2}\mathcal{N}_{r-2}(z),

(1.3)

\mathcal{N}^{\prime}_{r}(z)=\frac{r-1}{2z}\mathcal{N}_{r}(z)+\frac{(r-1)(z-1)}{2z}\mathcal{N}_{r-1}(z),

(1.4)

\mathcal{N}^{\prime\prime}_{r}(z)=-\frac{r-1}{z^{2}}\mathcal{N}_{r}(z)+\left(\frac{(r-1)^{2}}{z}+\frac{r-1}{z^{2}}\right)\mathcal{N}_{r-1}(z).

(1.5)

The proof of the above theorem is deferred to Section
2
. Let us end up this Section with some remarks.

Remark 1.1
.

In his paper
[
3
]
, Lasalle established the following recurrence

(z+1)\mathcal{N}_{r}(z)-\mathcal{N}_{r+1}(z)=\sum_{n\geq 1}(-z)^{n}\binom{r-1}{2n-1}A_{n}\mathcal{N}_{r-2n+1}(z),

(1.6)

where the numbers
A_{n}
satisfies the recurrence

(-1)^{n-1}A_{n}=C_{n}+\sum_{j=1}^{n-1}(-1)^{j}\binom{2n-1}{2j-1}A_{j}C_{n-j},

with
A_{1}=1
and
C_{n}=\frac{1}{n+1}\binom{2n}{n}
the Catalan number. Interestingly, our relation (
1.3
) is simpler than (
1.6
).

Remark 1.2
.

From (
1.3
) and (
1.4
) we obtain the following recurrence for the first order derivative

\mathcal{N}^{\prime}_{r}(z)=\frac{r-1}{2r+2}\frac{r-2+3rz}{z}\mathcal{N}_{r-1}(z)-\frac{(r-1)(r-2)}{2r+2}\frac{(1-z)^{2}}{z}\mathcal{N}_{r-2}(z).

Similarly, we can express
\mathcal{N}^{\prime\prime}_{r}(z)
in term of
\mathcal{N}_{r-1}(z)
and
\mathcal{N}_{r-2}(z).

Remark 1.3
.

It is known that
C_{r}:=\mathcal{N}_{r}(1),r\geq 1
is the sequence of the Catalan numbers. Hence, by choosing
z=1,
we obtain from (
1.3
), (
1.4
) and (
1.5
) the following identities

C_{r}=\frac{4r-2}{r+1}C_{r-1},

\sum_{k=1}^{r}(k-1)N(r,k)=\frac{r-1}{2}C_{r},

\sum_{k=1}^{r}(k-1)(k-2)N(r,k)=-(r-1)C_{r}+r(r-1)C_{r-1}.

Similarly, by choosing
z=2,
we also obtain the identities for the sequence of the large Schröder numbers
S_{r}:=\frac{1}{2}\mathcal{N}_{r}(2),r\geq 1.

2
Proofs

Let
X
be a random variable with the semicircular distribution, i.e.
X
has a density function
f(x)
given by

f(x)=\begin{cases}\frac{2}{\pi}\sqrt{1-x^{2}}&\quad\text{ if }-1\leq x\leq 1\\
0&\quad\text{ otherwise}.\end{cases}

(2.1)

It is known from
[
1
]
that the Narayana polynomial can be expressed as follows

\mathcal{N}_{r}(z)=\mathbb{E}[(1+z+2\sqrt{z}X)^{r-1}],

(2.2)

where
\mathbb{E}
denotes the expectation operator.

In order to prove Theorem
1.1
, we need to use the following property of semicircular distributions.

Lemma 2.1
.

For any continuously differentiable function
h,
we have

\mathbb{E}[h(X)X]=\frac{1}{3}\mathbb{E}[h^{\prime}(X)(1-X^{2})].

Proof.

We observe that

F(x):=\int_{x}^{1}yf(y)dy=\frac{2}{\pi}\int_{x}^{1}y\sqrt{1-y^{2}}dy=\frac{2}{3\pi}(1-x^{2})\sqrt{1-x^{2}},\,\,-1\leq x\leq 1.

Hence, by integrating by parts, we obtain

\displaystyle\mathbb{E}[h(X)X]

\displaystyle=\int_{-1}^{1}h(x)xf(x)dx=-\int_{-1}^{1}h(x)dF(x)

\displaystyle=\int_{-1}^{1}F(x)h^{\prime}(x)dx=\int_{-1}^{1}\frac{1}{3}(1-x^{2})h^{\prime}(x)f(x)dx

\displaystyle=\frac{1}{3}\mathbb{E}[h^{\prime}(X)(1-X^{2})].

The proof of the lemma is complete.
∎

We now are ready to present the proof of Theorem
1.1
.

Proof of (
1.3
).
Using the representation (
2.2
), we have

\displaystyle\mathcal{N}_{r}(z)

\displaystyle=\mathbb{E}[(1+z+2\sqrt{z}X)^{r-2}(1+z+2\sqrt{z}X)]

\displaystyle=(1+z)\mathcal{N}_{r-1}(z)+2\sqrt{z}\mathbb{E}[(1+z+2\sqrt{z}X)^{r-2}X],

and hence,

\mathcal{N}_{r}(z)-(1+z)\mathcal{N}_{r-1}(z)=2\sqrt{z}\mathbb{E}[(1+z+2\sqrt{z}X)^{r-2}X].

(2.3)

Furthermore, by using Lemma
2.1
and the relation (
2.3
), we deduce

\displaystyle\mathcal{N}_{r}(z)-(1+z)\mathcal{N}_{r-1}(z)

\displaystyle=\frac{4(r-2)}{3}z\mathbb{E}[(1+z+2\sqrt{z}X)^{r-3}(1-X^{2})].

This gives us the following

z\mathbb{E}[(1+z+2\sqrt{z}X)^{r-3}X^{2}]=-\frac{3}{4(r-2)}\left(\mathcal{N}_{r}(z)-(1+z)\mathcal{N}_{r-1}(z)\right)+z\mathcal{N}_{r-2}(z).

(2.4)

Once again we use the representation (
2.2
) to get

\displaystyle\mathcal{N}_{r}(z)

\displaystyle=\mathbb{E}[(1+z+2\sqrt{z}X)^{r-3}(1+z+2\sqrt{z}X)^{2}]

\displaystyle=(1+z)^{2}\mathcal{N}_{r-2}(z)+4(1+z)\sqrt{z}\mathbb{E}[(1+z+2\sqrt{z}X)^{r-3}X]+4z\mathbb{E}[(1+z+2\sqrt{z}X)^{r-3}X^{2}],

which, together with (
2.3
) and (
2.4
), yields

\displaystyle\mathcal{N}_{r}(z)

\displaystyle=(1+z)^{2}\mathcal{N}_{r-2}(z)+2(1+z)\left(\mathcal{N}_{r-1}(z)-(1+z)\mathcal{N}_{r-2}(z)\right)

\displaystyle-\frac{3}{r-2}\left(\mathcal{N}_{r}(z)-(1+z)\mathcal{N}_{r-1}(z)\right)+4z\mathcal{N}_{r-2}(z).

So it holds that

\frac{r+1}{r-2}\mathcal{N}_{r}(z)=\frac{2r-1}{r-2}(1+z)\mathcal{N}_{r-1}(z)-(1-z)^{2}\mathcal{N}_{r-2}(z)

and (
1.3
) follows.

Proof of (
1.4
).
It follows from the representation (
2.2
) that

\mathcal{N}^{\prime}_{r}(z)=(r-1)\mathbb{E}\left[(1+z+2\sqrt{z}X)^{r-2}\left(1+\frac{X}{\sqrt{z}}\right)\right],

which implies that

\mathcal{N}^{\prime}_{r}(z)-(r-1)\mathcal{N}_{r-1}(z)=\frac{r-1}{\sqrt{z}}\mathbb{E}\left[(1+z+2\sqrt{z}X)^{r-2}X\right].

(2.5)

Combining (
2.3
) and (
2.5
) yields

\mathcal{N}^{\prime}_{r}(z)-(r-1)\mathcal{N}_{r-1}(z)=\frac{r-1}{2z}\left(\mathcal{N}_{r}(z)-(1+z)\mathcal{N}_{r-1}(z)\right).

So (
1.4
) follows.

Proof of (
1.5
).
We have

\displaystyle N^{\prime\prime}_{r}(z)

\displaystyle=(r-1)(r-2)\mathbb{E}\left[(1+z+2\sqrt{z}X)^{r-3}\left(1+\frac{X}{\sqrt{z}}\right)^{2}\right]

\displaystyle-\frac{r-1}{2}\mathbb{E}\left[(1+z+2\sqrt{z}X)^{r-2}\frac{X}{z\sqrt{z}}\right]

\displaystyle=(r-1)(r-2)\mathbb{E}\left[(1+z+2\sqrt{z}X)^{r-3}\left(1+\frac{2X}{\sqrt{z}}+\frac{X^{2}}{z}\right)\right]

\displaystyle-\frac{r-1}{2}\mathbb{E}\left[(1+z+2\sqrt{z}X)^{r-2}\frac{X}{z\sqrt{z}}\right].

Hence, recalling the relations (
2.3
) and (
2.4
), we obtain

\displaystyle\mathcal{N}^{\prime\prime}_{r}(z)

\displaystyle=(r-1)(r-2)\bigg(\mathcal{N}_{r-2}(z)+\frac{1}{z}\left(\mathcal{N}_{r-1}(z)-(1+z)\mathcal{N}_{r-2}(z)\right)

\displaystyle-\frac{3}{4(r-2)z^{2}}\left(\mathcal{N}_{r}(z)-(1+z)\mathcal{N}_{r-1}(z)\right)+\frac{1}{z}\mathcal{N}_{r-2}(z)\bigg)

\displaystyle-\frac{r-1}{4z^{2}}\left(\mathcal{N}_{r}(z)-(1+z)\mathcal{N}_{r-1}(z)\right).

Rearranging the terms we get

\mathcal{N}^{\prime\prime}_{r}(z)=-\frac{r-1}{z^{2}}\mathcal{N}_{r}(z)+\left(\frac{(r-1)^{2}}{z}+\frac{r-1}{z^{2}}\right)\mathcal{N}_{r-1}(z).

Thus the proof of (
1.5
) is complete.
