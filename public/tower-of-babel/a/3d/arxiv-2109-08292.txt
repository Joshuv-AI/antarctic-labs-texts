exp(ASP c ): Explaining ASP Programs with Choice Atoms and Constraint Rules † † thanks: The second would like to acknowledge the partial support of the NSF 1812628 grant.
Ly Ly Trieu Tran Cao Son, Marcello Balduccini

Abstract
We present an enhancement of exp(ASP) , a system that generates explanation graphs for a literal ℓ ℓ \ell —an atom a 𝑎 a or its default negation ∼ a similar-to absent 𝑎 \sim{a} —given an answer set A 𝐴 A of a normal logic program P 𝑃 P , which explain why ℓ ℓ \ell is true (or false) given A 𝐴 A and P 𝑃 P . The new system, exp(ASP c ) , differs from exp(ASP) in that it supports choice rules and utilizes constraint rules to provide explanation graphs that include information about choices and constraints.

Introduction

Answer Set Programming (ASP)

[
5
,
6
]
is a popular paradigm for decision making and problem solving in Knowledge Representation and Reasoning.
It has been successfully applied in a variety of applications such as robotics, planning, diagnosis, etc. ASP is an attractive programming paradigm as it is a declarative language, where programmers focus on the representation of a specific problem as a set of rules in a logical format, and then leave computational solutions of that problem to an answer set solver. However, this mechanism typically gives little insight into
why
something is a solution and
why
some proposed set of literals is not a solution. This type of reasoning falls within the scope of
explainable Artificial Intelligence
and is useful to enhance the understanding of the resulting solutions as well as for debugging programs. So far, only a limited number of approaches have been proposed

[
2
,
7
,
8
]
. To the best of our knowledge, no system deals directly with ASP programs with choice atoms.

Minimal assumption set

The idea of the algorithm for computing minimal assumption sets is as follows.

•

A tentative assumption set
TA

[
7
,
10
]
is computed, which is the superset of minimal assumption sets.

•

in Sec.

is utilized to compute all derivation paths

of

.
Then, the derivation paths
M
are examined whether they satisfy the cycle condition in the definition of explanation graph. During the examination of a derivation path

, the other tentative assumption atoms derived from
a
are stored in a set

, which is appended to

(

is an associative array)
if

is satisfied.
If
a

. A set

•

We calculate a set of minimal atoms,

can be more than one.

•

Finally, the minimal assumption set
