Pseudocentralizers and The Chermak-Delgado Measure of the mod p n p^{n} Heisenberg Group
David Allen, José J. La Luz, Stephen Majewicz, Marcos Zyman

Abstract
. In this paper we compute the Chermak-Delgado measure of the mod p n p^{n} Heisenberg Group for any prime p . p. To achieve this we introduce the notion of the pseudocentralizer and prove various results about it.

1.
Introduction

Let
G
be a finite group. The
Chermak-Delgado measure
of a subgroup
H
of
G,
denoted by
m(H),
is defined by
m(H)=|H||C(H)|.
The maximum of the set
\{m(H)\,|\,H\leq G\}
is termed the
Chermak-Delgado measure
of
G
and is denoted by
m^{\ast}(G).
In
[
CD
]
, A. Chermak and A. Delgado defined these measures and established a certain sublattice of the lattice of all subgroups of
G.
This sublattice has been studied in many instances. In particular, certain properties of subgroups of finite simple groups have been established using it.

Various papers in the literature deal with theoretical implications of the concept (for example, see
[
BW
]
for the relation between the Chermak-Delgado lattice of a group and its subnormal subgroups and
[
W
]
for some basic calculations). The purpose of this paper is to obtain an explicit calculation of the Chermak-Delgado measure for
\mathcal{H}(p^{n}),
the Heisenberg group with entries in the ring
\mathbb{Z}_{p^{n}}
for any prime
p
and
n>0.
To achieve this we resort to some simple homological techniques.

We begin by introducing a new notion called the pseudocentralizer and developing some of its properties in order to obtain our computational results. If
G
and
K
are groups and
q:G\rightarrow K
is a homomorphism, then the
q
-pseudocentralizer
of a non-empty subset
S
of
G
is

P(S;\,q)=\{g\in G\,|\,[s,\,g]\in\ker q\hbox{ for all }s\in S\}.

If
S=\{s\},
then we write
P(s;\,q).
For simplicity, we write
P(S)
for
P(S;\,q)
when
q
is fixed and call
P(S)
the
pseudocentralizer
of
S.
For our purposes, the homomorphism
q
will be from the short exact sequence of groups

\textstyle{1\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\textstyle{\mathbb{Z}_{p}^{3}\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\scriptstyle{f}
\textstyle{\mathcal{H}(p^{n})\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\scriptstyle{q}
\textstyle{\mathcal{H}\left(p^{n-1}\right)\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\textstyle{1}

where
f\left(a_{1},\,a_{2},\,a_{3}\right)=\left(a_{1}p^{n-1},\,a_{2}p^{n-1},\,a_{3}p^{n-1}\right)
and

q\left(b_{1},\,b_{2},\,b_{3}\right)=\left(b_{1}\hbox{ mod }p^{n-1},\,b_{2}\hbox{ mod }p^{n-1},\,b_{3}\hbox{ mod }p^{n-1}\right)
where the elements of the Heisenberg groups are naturally expressed using vector notation.

The reason for introducing the pseudocentralizer of a set
S
is to study its relation to
C(S),
the centralizer of
S.
After showing that
C(S)\unlhd P(S)
for any
S\subseteq\mathcal{H}(p^{n})
in the short exact sequence above (see Lemma
5.1
), we prove the first important theorem in this direction:

Theorem
5.7
.

If
h
is a non-central element of
\mathcal{H}\left(p^{n}\right),
then
|P(h)|=p|C(h)|
. Hence,
P(h)/C(h)\cong\mathbb{Z}_{p}.

Using this theorem, we prove that if
H\leq\mathcal{H}(p^{n})
and
H
is not in the center of
\mathcal{H}(p^{n}),
then
P(H)/C(H)
is isomorphic to either
\mathbb{Z}_{p}
or
\mathbb{Z}_{p}\times\mathbb{Z}_{p}
(see Lemma
5.13
). It turns out that under certain conditions, we know exactly when
P(H)/C(H)
is isomorphic to
\mathbb{Z}_{p}\times\mathbb{Z}_{p},
and thus, when
|P(H)|=p^{2}|C(H)|.
This is the purpose of Theorem
5.39
.

After introducing the concept of an
injective set
for a
special
generating set of
H,
we generalize Theorem
5.39
. More precisely, we prove:

Theorem
5.45
.

Let
S
be a special generating set for
H\leq\mathcal{H}\left(p^{n}\right)
and
I
an injective set for
S.

(1)

If
|I|=0,
then
|P(H)|=|C(H)|.

(2)

If
|I|=1,
then
|P(H)|=p|C(H)|.

(3)

If
|I|=2,
then
|P(H)|=p^{2}|C(H)|.

This theorem plays a major role in proving various computational results about the the Chermak-Delgado measure of subgroups of
\mathcal{H}(p^{n}).
In addition, we define and study an analogue of the Chermak-Delgado measure termed the
pseudo Chermak-Delgado measure
. We provide numerous results in Section 7 that relate the two notions. These lead us to the main theorem in this paper:

Theorem
.

For any prime
p,
we have
m^{\ast}(\mathcal{H}\left(p^{n}\right))=p^{4n}.

Lemma 3.2
.

If
S\subseteq G
and
H\lhd G
in the short exact sequence (

P(S;\,q)\leq G
and
P(H;\,q)\lhd G.

Proof.

Let

Using the commutator identities (see Lemma 1.4 of
[

]
), we see that

\Bigl[s,\,g_{1}g^{-1}_{2}\Bigr]=\Bigl[s,\,g_{2}^{-1}\Bigr]\Bigl[s,\,g_{1}\Bigr]^{g_{2}^{-1}}=\Bigl([s,\,g_{2}]^{g_{2}^{-1}}\Bigr)^{-1}[s,\,g_{1}]^{g^{-1}_{2}}.

[s,\,g_{1}]\in\ker q,

[s,\,g_{2}]\in\ker q,
and

we have that
[s,\,g_{1}]^{g^{-1}_{2}}\in\ker q
and
[s,\,g_{2}]^{g_{2}^{-1}}\in\ker q.
It follows that

Next let

If

and

then

because

Hence,

And so,

4.
the mod
r
-Heisenberg group

From this point on,
r>1
will always be some natural number and
p
is a fixed prime number.

Definition 4.1
.

For any ring
\mathbb{Z}_{r},

\mathcal{H}(r)=\left\{\begin{bmatrix}1&a_{1}&a_{2}\\
0&1&a_{3}\\
0&0&1\end{bmatrix}\,\middle|\,a_{1},\,a_{2},\,a_{3}\in\mathbb{Z}_{r}\right\}

is the
mod
r
Heisenberg group
with matrix multiplication as the group operation.

Notation 4.2
.

The matrix
a=\begin{bmatrix}1&a_{1}&a_{2}\\
0&1&a_{3}\\
0&0&1\end{bmatrix}

will be written in the vector form
a=(a_{1},\,a_{2},\,a_{3}).
We call
a_{i}
the
i^{th}

component
of
a.

Using this notation and standard matrix multiplication, we get

\displaystyle(a_{1},\,a_{2},\,a_{3})(b_{1},\,b_{2},\,b_{3})

\displaystyle=

\displaystyle(a_{1}+b_{1},\,a_{2}+b_{2}+a_{1}b_{3},\,a_{3}+b_{3})\hbox{ \ \ and }

\displaystyle(a_{1},\,a_{2},\,a_{3})^{-1}

\displaystyle=

\displaystyle(-a_{1},\,a_{1}a_{3}-a_{2},-a_{3}).

In the above, all calculations are obviously done in the ring
\mathbb{Z}_{r}.
Observe that the vector
(0,\,0,\,0)
represents the multiplicative identity in
\mathcal{H}(r)
.

Notation 4.3
.

The
i^{th}
component of
g\in\mathcal{H}(r)
will usually be written as
g|_{i}.

•

When we use this notation
outside
of a vector, we will write “mod” to emphasize that we are calculating modulo
r
in a component. Thus, for the vector
c=(a_{1}+b_{1},\,a_{2}+b_{2}+a_{1}b_{3},\,a_{3}+b_{3})\hbox{ in }\mathcal{H}(r),
we write

\indent c|_{i}=(a_{i}+b_{i})\hbox{ mod }r\hbox{ for }i=1,\,3\hbox{ \ \ and \ \ }c|_{2}=(a_{2}+b_{2}+a_{1}b_{3})\hbox{ mod }r.

Note that we did not write “
c|_{i}\hbox{ mod }r
”.

•

Unless ambiguity arises, when this notation is used
inside
of a vector (see Lemma
4.4
for example), operations are understood to be modulo
r
without mention and we will not write “mod”.

A simple calculation and induction on
n
give:

Lemma 4.4
.

For any natural number
n>1
and
a\in\mathcal{H}(r),
we have

a^{n}=\left(na|_{1},\,na|_{2}+{n\choose 2}a|_{1}a|_{3},\,na|_{3}\right).

The proof of the next lemma is straightforward.

Lemma 4.5
.

Suppose that
a,\,b\in\mathcal{H}(r).

(1)

[a,\,b]=(0,\,a|_{1}b|_{3}-a|_{3}b|_{1},\,0).

(2)

Z(\mathcal{H}(r))=[\mathcal{H}(r),\,\mathcal{H}(r)]=\{(0,\,x,\,0)\,|\,x\in\mathbb{Z}_{r}\}.

(3)

\mathcal{H}(r)
is nilpotent of class
2.

Corollary 4.6
.

Let
S\subseteq\mathcal{H}(r)
and
h\in\mathcal{H}(r)
.

(1)

C(S)=\{g\in\mathcal{H}(r)\,|\,[a,\,g]|_{2}=0\hbox{ mod }r\,\hbox{ for all }a\in S\};

(2)

C(h)=\{g\in\mathcal{H}(r)\,|\,[h,\,g]|_{2}=0\hbox{ mod }r\}.

Proof.

It follows from Lemma
4.5
.
∎

Lemma 4.7
.

Suppose that
x,\,y,\,z,\,w\in\mathcal{H}(r).
The following hold:

(1)

[[x,\,y],\,z]=(0,\,0,\,0)
;

(2)

[x,\,yz]=[x,\,z][x,\,y]
and
[xy,\,z]=[x,\,z][y,\,z]
;

(3)

([x,\,y][z,\,w])|_{2}=[x,\,y]|_{2}+[z,\,w]|_{2}
;

(4)

[x,\,y]|_{2}+\left[x,\,y^{-1}\right]|_{2}=0
.

Proof.

This is a consequence of the commutator identities (see Lemma 1.4 of
[
CMZ
]
) and Lemma
4.5
.
∎

Let

Most of these relationships are in terms of the center of

Lemma 5.1
.

For any

in the short exact sequence (

C(S)\unlhd P(S)
.

Compare this to Lemma

(1). Note that our proof actually shows that

Proof.

Let

By Lemma

Thus,

by Corollary

∎

Lemma 5.2
.

Let

Then

if and only if
P(H)=C(H).

Proof.

If

then

It follows from Lemma

(1) that
P(H)=C(H).
The proof of the converse will be given after Definition
.
∎

Lemma 5.3
.

For all

if and only if

Proof.

If
h\in Z(\mathcal{H}(p^{n})),
then
C(h)=\mathcal{H}(p^{n}).
By Lemma
3.5
(1),
C(h)\leq P(h)
and, thus,
P(h)=C(h).

Suppose now that
h\notin Z(\mathcal{H}(p^{n})).
Then either
h|_{1}\neq 0
or
h|_{3}\neq 0.
If
h|_{1}\neq 0,
then there exist

and

such that

and
h|_{1}=rp^{k}
. Let

We claim that
g\in P(h)\setminus C(h).
Well, by Lemma
4.5
,

Non-central elements play an important role in what follows. We introduce some notation.

Next we determine the relationship between

For any

Theorem 5.7

If

then
|P(h)|=p|C(h)|
. Hence,

Proof.

Since
h
is not central, then either
h|_{1}\neq 0
or
h|_{3}\neq 0.
Assume first that

There exist
0\leq k<n
and
0<r<p^{n}
such that
p\nmid r
and
h|_{1}=rp^{k}.
Note that

is a unit in the ring
\mathbb{Z}_{p^{n}}.

We concoct set maps between

and
P_{\ell}(h)
for each
\ell.
First observe that if

then for each
\ell,

4.5
and Corollary

Next observe that if

Thus, using Lemma

\left[h,\,\left(y|_{1},\,y|_{2},\,y|_{3}-r^{-1}\ell p^{n-k-1}\right)\right]|_{2}=0.

(1)

and
z_{1}\in C(h_{2})

(2)

and

Since

and

5.5

The theorem will follow from Lemma

Definition 5.40
.

Let
S
be a special generating set for a subgroup
H
of
\mathcal{H}\left(p^{n}\right).
A set

is termed an

for

if it is a subset of
S^{\dagger}
of maximal cardinality satisfying the following conditions:

(1)

|I|\leq 2
;

(2)

If
\left|S^{\dagger}\right|>0,
then
\nu(I)=\nu\left(S^{\dagger}\right)=\nu(h_{1})
for some

;

(3)

If

then
\mu(h_{1},\,h_{2})\leq\mu(h_{1},\,h_{j})
for all
h_{j}\in S^{\dagger}-\{h_{1}\}
.

Lemma 5.41
.

Every special generating set for a subgroup of
\mathcal{H}\left(p^{n}\right)
contains an injective set.

Proof.

Let
S
be a special generating set for
H\leq\mathcal{H}\left(p^{n}\right).
If
H
is central, then
I=\emptyset
is an injective set for
S.
If
\left|S^{\dagger}\right|=1,
then
I=S^{\dagger}
is an injective set for
S.
Finally, suppose
\left|S^{\dagger}\right|>1
and let
h_{1}\in S^{\dagger}
be such that
\nu\left(S^{\dagger}\right)=\nu(h_{1}).
Choose
h_{2}\in S^{\dagger}-\{h_{1}\}
such that

for all
h_{j}\in S^{\dagger}-\{h_{1}\}
. Then

is an injective set for

.
∎

.

Suppose that

and

is an injective set for any special generating set for

. Then

is central if and only if

Proof.

Let
S
be any special generating set for
H
. If

is central, then

.

Suppose now that

. Without loss of generality, we can assume

. Thus,

is central.
