On rigid q q -plurisubharmonic functions and q q -pseudoconvex tube domains in ℂ n \mathbb{C}^{n}
Thomas Pawlaschyk

Abstract
In the spirit of Lelong and Bochner, we show that an upper semi-continuous function defined on a open tube set Ω = ω + i ​ ℝ n \Omega=\omega+i\mathbb{R}^{n} in ℂ n \mathbb{C}^{n} , where ω \omega is an open set in ℝ n \mathbb{R}^{n} , and which is invariant in its imaginary part, is q q -plurisubharmonic on Ω \Omega (in the sense of Hunt and Murray) if and only if it is real q q -convex on ω \omega , i.e., it admits the local maximum property with respect to affine linear functions on real ( q + 1 ) (q+1) -dimensional affine subspaces. From this, we conclude that, for a > 0 a>0 , the set ω + i ​ ( − a , a ) n \omega+i(-a,a)^{n} is q q -pseudoconvex in ℂ n \mathbb{C}^{n} if and only if ω \omega is a real q q -convex set in ℝ n \mathbb{R}^{n} , i.e., ω \omega admits a real q q -convex exhaustion function on ω \omega . We apply these results to complements of graphs of affine linear maps and to Reinhardt domains.

Introduction

The classes of convex and plurisubharmonic functions are among the most important families of functions in real and complex analysis in several variables, respectively. Both are closely related, as was thoroughly demonstrated in the classical paper by Lelong
[
Lel52
]
. On the one hand, every locally convex function is plurisubharmonic, but the converse is false in general. On the other hand, an upper semi-continuous function defined on a tube domain
\Omega=\omega+i\mathbb{R}^{n}
, which is invariant in its imaginary parts, is plurisubharmonic on
\Omega
if and only if it is locally convex on the open set
\omega
in
\mathbb{R}^{n}
. From this, Lelong deduced that
\Omega
is a domain of holomorphy (or, equivalently, pseudoconvex) if and only if
\omega
is a convex set in
\mathbb{R}^{n}
. Lelong further extended this result by replacing the tube domain
\Omega
with a cylinder of the form
\omega+i(-a,a)^{n}
for
a>0
. Earlier results in this direction were obtained by Bochner
[
Boc38
]
.

In this paper, we extend Lelong’s results to the class of
q
-plurisubharmonic functions in the sense of Hunt-Murray
[
HM78
]
and
q
-pseudoconvex domains in the sense of Słodkowski
[
Sło86
]
. For this, we introduce the notion of real
q
-convex functions on open sets in
\mathbb{R}^{n}
. These are upper semi-continuous functions that satisfy the local maximum property with respect to affine linear functions on real
(q+1)
-dimensional affine subspaces. In this sense, they generalize locally convex functions and serve as the real analogues to weakly
q
-convex functions in the sense of Grauert, in the following way: a
\mathcal{C}^{2}
-function is real
q
-convex if and only if its real Hessian has at most
q
negative eigenvalues at each point. Moreover, they possess approximation properties similar to those developed by Słodkowski
[
Sło84
]
for
q
-plurisubharmonic functions. Using real
q
-convex functions, we introduce real
q
-convex sets and establish equivalent characterizations of such sets in Theorem
5.11
. From this, we obtain the main results of our paper (Theorem
4.8
and Theorem
5.17
):

First Main Theorem.

Let
\omega
be an open subset in
\mathbb{R}^{n}
. An upper semi-continuous function
\psi
defined on the open tube set
\Omega=\omega+i\mathbb{R}^{n}
in
\mathbb{C}^{n}
with
\psi(z)=\psi(\operatorname{Re}{(z)})
is
q
-plurisubharmonic if and only if it is real
q
-convex on
\omega
.

Second Main Theorem.

An open set
\omega
in
\mathbb{R}^{n}
is real
q
-convex if and only the set
\omega+i(-a,a)^{n}
is
q
-pseudoconvex in
\mathcal{C}^{n}
for some/any
a\in(0,+\infty]
.

Real
q
-convex functions

Throughout this paper, the set
\omega
denotes an open set in
\mathbb{R}^{n}
. The Euclidean scalar product on
\mathbb{R}^{n}
is given by
\langle x,y\rangle_{2}:=\sum_{j=1}^{n}x_{j}y_{j}
which induces the norm
\|x\|_{2}=\sqrt{\langle x,x\rangle_{2}}
on
\mathbb{R}^{n}
. The boundary distance of a point
p
in
\omega
to the boundary
\partial\omega
of
\omega
is defined by
d_{2}(p,\partial\omega)=\inf\{\|x-p\|_{2}:x\in\partial\omega\}
. The balls
B^{n}_{r}(p)=B_{r}(p)
in
\mathbb{R}^{n}
are given by
B_{r}(p):=\{x\in\mathbb{R}^{n}:\|x-p\|_{2}^{2}<r\}
.

Especially in this section, we omit most proofs, since they either follow easily from the definitions or can be found in detial in
[
Paw15
]
for the interested reader.

We begin with the definition of real
q
-convex functions in the Euclidean space
\mathbb{R}^{n}
, which is based on classical convexity.

Definition 2.1
.

Let
\omega
be an open set in
\mathbb{R}^{n}
and let
q\in\{0,\ldots,n-1\}
.

1.

We call an upper semi-continuous function
u:\omega\to[-\infty,+\infty)
to be
real
q
-convex
, if, for short, it
fulfills the local maximum property on
\omega
with respect to affine linear functions on
(q+1)
-dimensional subspaces
,
i.e., if for every
(q+1)
-dimensional affine subspace
\pi
, every ball
B\Subset\omega
and every affine linear function
\ell
on
\pi
with
u\leq\ell
on
\partial B\cap\pi
we already have that
u\leq\ell
on
\overline{B}\cap\pi
.

2.

If
m\geq n
, each upper semi-continuous function is automatically real
m
-convex by convention.

The subsequent properties follow immediately from the definition of real
q
-convexity.

Proposition 2.2
.

Let all functions mentioned below be defined on an open set
\omega
in
\mathbb{R}^{n}
with image in
[-\infty,+\infty)
.

1.

If
u
is real-valued, then it is locally convex if and only if it is real
0
-convex.

2.

Every real
q
-convex function is real
(q+1)
-convex.

3.

If
\lambda\geq 0
,
c\in\mathbb{R}
, and
u
is real
q
-convex, then
\lambda u+c
is also real
q
-convex.

4.

The limit of a decreasing sequence
\{u_{k}\}_{k\in\mathbb{N}}
of real
q
-convex functions is again real
q
-convex.

5.

If
\{u_{i}\}_{i\in I}
is a family of locally bounded real
q
-convex functions, then the upper semi-continuous regularization
u^{*}(x):=\limsup_{y\to x}u(y)
of
u:=\sup_{i\in I}u_{i}
is real
q
-convex. In particular, the maximum of finitely many real
q
-convex functions is again real
q
-convex.

6.

A real
q
-convex function remains real
q
-convex after a linear change of coordinates.

7.

An upper semi-continuous function
u
is real
q
-convex if and only if
u+\ell
is real
q
-convex for every affine linear function
\ell
on
\mathbb{R}^{n}
.

The next statement corresponds essentially to Lemma 4.5 in
[
Sło84
]
.

Lemma 2.3
.

Let
X
be a vector space over the field
\mathbb{K}\in\{\mathbb{R},\mathbb{C}\}
equipped with the inner product
\langle\cdot,\cdot\rangle
. Let
\|\cdot\|
denote its induced norm and let
u
be an upper semi-continuous function on a compact set
K
in
X
. Suppose that there is another compact set
L
in
K
with
\max_{L}u<\max_{K}u
. Then there are a point
p
in
K\setminus L
, a real number
\varepsilon>0
and an
\mathbb{R}
-linear function
\ell:X\to\mathbb{R}
such that

u(p)+\ell(p)=0\quad\hbox{and}\quad u(x)+\ell(x)<-\varepsilon\|x-p\|^{2}\ \hbox{for\ every}\ x\in K\setminus\{p\}.

From the preceding lemma, we conclude that real
q
-convexity is a local property.

Corollary 2.4
.

Let
u
be upper semi-continuous on an open set
\omega
in
\mathbb{R}^{n}
. Then
u
is real
q
-convex on
\omega
if and only if it is locally real
q
-convex on
\omega
, i.e., for every point
p
in
\omega
there is a neighborhood
V
of
p
in
\omega
such that
u
is real
q
-convex on
V
.

Lemma
2.3
has another important consequence for real
q
-convex functions.

Theorem 2.5
(Maximum principle).

Let
q\in\{0,\ldots,n-1\}
and let
\omega
be a relatively compact open set in
\mathbb{R}^{n}
. If
u
is real
q
-convex on
\omega
and upper semi-continuous up to the closure of
\omega
, then

\max\{u(x):x\in\overline{\omega}\}=\max\{u(x):x\in\partial\omega\}.

Using the maximum principle, two real
q
-convex functions can be patched together to obtain a new real
q
-convex function.

Theorem 2.6
.

Let
\omega_{1}
and
\omega
be two open sets in
\mathbb{R}^{n}
with
\omega_{1}\subset\omega
. Let
u
be a real
q
-convex function on
\omega
and
u_{1}
be a real
q
-convex function on
\omega_{1}
such that

\displaystyle\displaystyle\limsup_{\begin{subarray}{c}y\to x\\
y\in\omega_{1}\end{subarray}}u_{1}(y)\leq u(x)\ \hbox{for\ every}\ x\in\partial\omega_{1}\cap\omega.

Then the following function is real
q
-convex on
\omega
,

\psi(x):=\left\{\begin{array}[]{ll}\max\{u(x),u_{1}(x)\},&x\in\omega_{1}\\
u(x),&x\in\omega\setminus\omega_{1}\end{array}\right\}.

Proof.

It is obvious that the function
\psi
is upper semi-continuous on
\omega
. Let
\pi
be a real
(q+1)
-dimensional affine subspace in
\mathbb{R}^{n}
,
B
be a ball lying relatively compact in
\pi\cap\omega
and let
\ell
be an affine linear function on
\pi
such that
\psi\leq\ell
on
\partial B
. Since
\psi
coincides with
u
on
\omega\setminus\overline{\omega_{1}}
and since it is a maximum of the two real
q
-convex functions
u
and
u_{1}
on
\omega_{1}
,
\psi
is real
q
-convex on
\omega\setminus\partial\omega_{1}
. Thus, we can assume that
B\cap\partial\omega_{1}\neq\emptyset
. Since
u
is real
q
-convex on
\omega
and by the inequalities
u\leq\psi\leq\ell
on
\partial B
, we obtain that
u\leq\ell
on
B
. Therefore, we have that
\psi=u\leq\ell
on
B\cap(\omega\setminus\omega_{1})
. In particular, we have that
\psi=u\leq\ell
on
B\cap\partial\omega_{1}
. This implies that
\psi\leq\ell
on
\partial(B\cap\omega_{1})
. Since
\psi
is real
q
-convex on
\omega_{1}
, the maximum principle from the previous theorem yields
\psi\leq\ell
on
B\cap\omega_{1}
. By the previous discussion, we have that
\psi\leq\ell
on
B
. Finally, we can conclude that
\psi
is real
q
-convex on
\omega
.

Next, we provide another characterization of real
q
-convexity in terms of eigenvalues of its real Hessian. Before that, we define real
q
-convex functions that are stable under small perturbations by convex functions.

Definition 2.7
.

Let
\omega
be an open set in
\mathbb{R}^{n}
. We say that an upper semi-continuous function
u
on
\omega
is
strictly real
q
-convex
if for every point
p
in
\omega
there exist a neighborhood
U
of
p
and a positive number
\varepsilon_{0}>0
such that
x\mapsto u(x)+\varepsilon\|x-p\|_{2}^{2}
is real
q
-convex on
U
for every
\varepsilon\in(-\varepsilon_{0},\varepsilon_{0})
.

In the case of
\mathcal{C}^{2}
-smooth functions, we have the following characterization of (strict) real
q
-convexity.

Theorem 2.8
.

Let
q\in\{0,\ldots,n-1\}
and
\omega
be an open set in
\mathbb{R}^{n}
. A
\mathcal{C}^{2}
-smooth function
u
on
\omega
is (strictly) real
q
-convex if and only if for every point
p\in\omega
the real Hessian
\mathcal{H}_{u}(p)=\left(\frac{\partial^{2}u}{\partial x_{k}\partial x_{\ell}}(p)\right)_{k,\ell=1}^{n}
of
u
at
p
has at most
q
negative (non-positive, resp.) eigenvalues.

Proof.

By Corollary
2.4
, real
q
-convexity is a local property, so all considerations can be made in a small neighborhood of some fixed point
p\in\omega
. Due to Proposition
2.2
(
3
) and (
6
), we can assume without loss of generality that
p=0
,
u(p)=0
and that
u
has the following Taylor expansion in some neighborhood of the origin,

u(x)=A(x)+\frac{1}{2}x^{t}\mathcal{H}_{u}(0)x+o(\|x\|^{2}_{2}),

where
A(x)=\nabla u(0)x
is considered as a linear function
\mathbb{R}^{n}\to\mathbb{R}
. According to Proposition
2.2
(
7
), by replacing
u
by
u-A
, we can further assume without loss of generality that
u
has the following form near the origin,

u(x)=\frac{1}{2}x^{t}\mathcal{H}_{u}(0)x+o(\|x\|^{2}_{2}).

Now if the real Hessian of
u
has at least
q+1
negative eigenvalues at the origin, then we can find a real
(q+1)
-dimensional affine subspace
\pi
in
\mathbb{R}^{n}
and a ball
B
inside
\pi\cap\omega
such that
u
is strictly negative at every point on the boundary of
B
but vanishes inside
B
at the origin. Thus, in view of the maximum principle, it cannot be real
q
-convex on
\omega
.

On the other hand, if
u
is not real
q
-convex, then there are a point
p_{0}\in\omega
, a real
(q+1)
-dimensional affine subspace
\pi
, a ball
B
in
\pi\cap\omega
containing
p_{0}
and an affine linear function
\ell_{1}
on
\pi
such that
u(x)\leq\ell_{1}(x)
for every
x\in\partial B
, but
u(p_{0})>\ell_{1}(p_{0})
. Then by Lemma
2.3
there are a point
p_{1}
inside
B
, a positive number
\varepsilon>0
and another linear function
\ell_{2}
on
\pi
such that

u(p_{1})-\ell_{1}(p_{1})-\ell_{2}(p_{1})=0\quad\hbox{and}\quad u(x)-\ell_{1}(x)-\ell_{2}(x)<-\varepsilon\|x-p_{1}\|^{2}_{2}.

for every
x\in\overline{B}\setminus\{p_{1}\}
. Hence, the function
u-\ell_{1}-\ell_{2}
attains a strict local maximum at
p_{1}
. Therefore, the real Hessian of
u
at
p_{1}
, which corresponds to the real Hessian of
u-\ell_{1}-\ell_{2}
at
p_{1}
, has at least
q+1
negative eigenvalues.

Theorem
2.8
allows us easily to construct examples of real

-convex functions in
\mathbb{R}^{n}
.

Example 2.9
.

Consider the subsequent functions defined on
\mathbb{R}^{2}
.

1.

The functions
u(x,y)=-x^{2}
and

are both real 1-convex, but their sum
(u+v)(x,y)=-x^{2}-y^{2}
is

2.

The real 1-convex functions

decrease point-wise for

, which is real 1-convex due to Proposition

(
4
).

3.

By the same argument, the characteristic function
\raisebox{2.5pt}{$\chi$}_{S}=\left\{\begin{array}[]{ll}1,&x\in S\\
0,&x\notin S\end{array}\right\}
of the real line
S=\{(x,0)\in\mathbb{R}^{2}:x\in\mathbb{R}\}
in

is real 1-convex (as a decreasing limit of the real 1-convex functions

.

4.

This demonstrates that, in general, real-valued real

-convex functions are not necessarily continuous, if

, whereas every real-valued 0-convex, i.e., locally convex function, is continuous (see Theorem 10.1 in

Motivated by the previous examples, we can construct further real
q
-convex functions.

Lemma 2.10
.

Let
q\in\{0,1,\ldots,n-1\}
and let
\{\pi_{\alpha}\}_{\alpha\in A}
be a collection of real
(n-q)
-dimensional affine subspaces
\pi_{\alpha}
in
\mathbb{R}^{n}
such that
\bigcup_{\alpha\in A}\pi_{\alpha}=\mathbb{R}^{n}
. Let
u
be a continuous function on an open set
\omega
in
\mathbb{R}^{n}
such that
u
is locally convex on each intersection
\pi_{\alpha}\cap\omega
,
\alpha\in A
. Then
u
is real
q
-convex on
\omega
.

Proof.

Observe that if
\pi=\mathbb{R}^{n-q}\times\{0\}^{q}
, then by similar arguments as in Example
2.9
(
2
), we can show that

v_{\pi}(x)=\left\{\begin{array}[]{ll}0,&x\in\pi\\
-\infty,&x\notin\pi\end{array}\right\}

is real
q
-convex on
\mathbb{R}^{n}
. Since real
q
-convexity is invariant under linear changes of coordinates, we have that
v_{\pi_{\alpha}}
is real
q
-convex on
\mathbb{R}^{n}
for each
\alpha\in A
.

Now if
u
is locally convex on
\pi_{\alpha}\cap\omega
, we can extend
u
to a locally convex function
\hat{u}_{\alpha}
defined on open neighborhood
U
of
\pi_{\alpha}\cap\omega
in
\omega
. By Proposition
7
(7), the sum

u_{\alpha}(x):=(\hat{u}_{\alpha}+v_{\pi_{\alpha}})(x)=\left\{\begin{array}[]{ll}u,&x\in\pi_{\alpha}\\
-\infty,&x\notin\pi_{\alpha}\end{array}\right\}

is real
q
-convex on
\omega
. Finally, observe that
u=\sup_{\alpha\in A}u_{\alpha}
, so that
u
is real
q
-convex on
\omega
due to Proposition
2.2
(
5
).

Theorem
2.8
also yields a technique similar to Lemma
2.3
, which we will use later.

Lemma 2.11
.

Let
\omega
be an open set in
\mathbb{R}^{n}
. Assume that
u
is not real
q
-convex on
\omega
. Then there is a ball
B\Subset\omega
, a point
x_{1}\in B
, a number
\varepsilon>0
and a
\mathcal{C}^{\infty}
-smooth real
(n{-}q{-}1)
-convex function

on
\mathbb{R}^{n}
such that

(u+v)(x_{1})=0\quad\hbox{and}\quad(u+v)(x)<-\varepsilon\|x-x_{1}\|^{2}_{2}\quad\ \hbox{for\ every}\ x\in B\setminus\{x_{1}\}.

Proof.

Since
u
is not real
q
-convex on
\omega
, there exist a ball
B\Subset\omega
, a point
x_{0}
in
B
, a
(q+1)
-dimension affine subspace
\pi
and an affine linear function
\ell:\mathbb{R}^{n}\to\mathbb{R}
such that
u+\ell<0
on
\partial B\cap\pi
and
u(x_{0})+\ell(x_{0})>0
. Let
h:\mathbb{R}^{n}\to\mathbb{R}^{n-q-1}
be a linear map such that
\pi=\{h=0\}
and fix a number
c>0
. In view of Theorem
2.8
, it is easy to verify that the
\mathcal{C}^{\infty}
-smooth function
v_{c}(x):=\ell(x)-c\|h(x)\|^{2}_{2}
is real
(n{-q-}1)
-convex on
\mathbb{R}^{n}
. Moreover, it equals

on

and tends to

outside

when

goes to

. Therefore, if we choose

on
\partial B
and
u(x_{0})+v_{c}(x_{0})>0
. Now it follows from Lemma

that there is another linear function
\ell_{1}:\mathbb{R}^{n}\to\mathbb{R}
, a point

and
\varepsilon>0
such that
(u+v_{c}+\ell_{1})(x_{1})=0
, but

for every

(

).

3
Approximation of real
q
-convex functions

We present an approximation method for real
q
-convex functions by almost everywhere twice differentiable ones. It is based on the ideas developed by Słodkowski’s in
[
Sło84
]
.

Theorem 3.1
(Busemann-Feller-Alexandroff, cf.
[
BCP96
]
).

Let
u
be a real-valued locally convex function on an open set
\omega
in
\mathbb{R}^{n}
. Then, almost everywhere on
\omega
, the function
u
is twice differentiable and its gradient
\nabla u
is differentiable.

This important theorem motivates the introduction of the following family of functions.

Definition 3.2
.

Let
\omega
be an open set in
\mathbb{R}^{n}
and
L\geq 0
.

1.

The symbol
\mathcal{C}_{L}^{1}(\omega)
is the family of all real valued functions
g
on
\omega
such that
u(x):=g(x)+\frac{1}{2}L\|x\|^{2}_{2}
is locally convex on
\omega
.

2.

Let
g
be a function in
\mathcal{C}_{L}^{1}(\omega)
. In view of the Busemann-Feller-Alexandroff theorem, the real Hessian
\mathcal{H}_{g}(x)
of
g
exists at almost every point
x
in
\omega
. At these points, the smallest eigenvalue is bounded from below by
-L
. It is therefore reasonable to say that functions in
\mathcal{C}^{1}_{L}(\omega)
have a
lower bounded Hessian
.

3.

The collection of all functions on
\omega
with lower bounded Hessian is denoted by
\mathcal{C}^{1}_{\bullet}(\omega)
.

Integral convolution provides an important method to approximate convex functions, but it is not suitable for real
q
-convex functions. An alternative is given by a convolution method based on taking a supremum rather than an integral.

Definition 3.3
.

Let
u,v
be two non-negative functions defined on possibly different subsets of
\mathbb{R}^{n}
. Then for every
x\in\mathbb{R}^{n}
the
supremum convolution
of
u
and
v
is defined by

(u\ast v)(x):=\sup\{\hat{u}(y)\hat{v}(x-y):y\in\mathbb{R}^{n}\},

where
\hat{u}
and
\hat{v}
denote the trivial extensions of
u
and
v
by zero into the whole space
\mathbb{R}^{n}
.

Applying the supremum convolution to functions with lower bounded Hessian, we obtain the following statement (cf. Proposition 2.6 in
[
Sło84
]
).

Proposition 3.4
.

Let
M>0
be a positive number. Let
u
and
g
be two non-negative bounded upper semi-continuous functions on
\mathbb{R}^{n}
. If
g\in\mathcal{C}_{L}^{1}(\mathbb{R}^{n})
, then
u\ast g
lies in
\mathcal{C}^{1}_{ML}(\mathbb{R}^{n})
, where
M:=\sup\{u(x):x\in\mathbb{R}^{n}\}
. In particular,
u\ast g
is continuous on
\mathbb{R}^{n}
and twice differentiable almost everywhere on
\mathbb{R}^{n}
.

Our next goal is to characterize twice differentiable real
q
-convex functions by a certain quantity that represents exactly the largest eigenvalue of the real Hessian of a
\mathcal{C}^{2}
-smooth function at a given point.

Theorem 3.5
.

If
u
is a locally convex function on an open set
\omega
in
\mathbb{R}^{n}
such that for the maximal eigenvalue of the Hessian of
u
at
x
,

\lambda_{u}(x):=2\limsup_{\varepsilon\to 0}(\max\{u(x+\varepsilon h)-u(x)-\varepsilon\nabla u(x)h:h\in\mathbb{R}^{n},\ \|h\|_{2}=1\})/\varepsilon^{2},

we have that
\lambda_{u}(x)\geq M
for almost every
x\in\omega
, then
\lambda_{u}(x)\geq M
for every
x\in\omega
.

The preceding statements permit us to generalize Theorem
2.8
to twice differentiable real
q
-convex functions.

Theorem 3.6
.

Let
q\in\{0,\ldots,n-1\}
and let
u
be upper semi-continuous on an open set
\omega
in
\mathbb{R}^{n}
.

1.

If
u
is real
q
-convex on
\omega
and twice differentiable at a point
p
in
\omega
, then the real Hessian of
u
at
p
has at most
q
negative eigenvalues.

2.

If
u\in\mathcal{C}^{1}_{L}(\omega)
and its real Hessian at almost every point in
\omega
has at most
q
negative eigenvalues, then
u
is real
q
-convex on
\omega
.

Proof.

1. Pick a point
p
in
\omega
such that
\mathcal{H}_{u}(p)
exists. Let
B_{r}(p)\Subset\omega
be a ball centered in
p
with radius
r>0
. Then for
t\in(0,1)
the function
u_{t}
given by

B_{r}(0)\ni x\ \mapsto\ u_{t}(x):=\big(u(p+tx)-u(p)-t\langle\nabla u(p),x\rangle\big)/t^{2}

is real
q
-convex on
B_{r}(0)
due to Proposition
2.2
(
3
) and (
7
). Since
u
is twice differentiable at
p
, the family
\{u_{t}\}_{t\in(0,1)}
tends uniformly to
x\mapsto u_{0}(x):=x^{t}\mathcal{H}_{u}(p)x
in a small neighborhood of the origin as
t
tends to zero. Therefore, the function
u_{0}
is real
q
-convex and
\mathcal{C}^{2}
-smooth on a neighborhood of the origin. By Theorem
2.8
the real Hessian of
u_{0}
at the origin has at most
q
negative eigenvalues. Since
\mathcal{H}_{u_{0}}(0)=\mathcal{H}_{u}(p)
, the proof of the first statement is finished.

2. If
u
is not real
q
-convex on
\omega
, then it follows from Lemma
2.11
that, without loss of generality, there exist a ball
B_{r}(0)\Subset\omega
, a number
\varepsilon>0
and a
\mathcal{C}^{\infty}
-smooth real
(n{-}q{-}1)
-convex function
v
on
\mathbb{R}^{n}
which satisfies
(u+v)(0)=0
and

\displaystyle(u+v)(x)<-\varepsilon\|x\|^{2}_{2}\ \hbox{for\ every}\ x\in\overline{B_{r}(0)}\setminus\{0\}.

(3.1)

Recall that
u\in\mathcal{C}^{1}_{L}(\omega)
and define

f:=u+v,\quad M_{v}:=\sup\{\lambda_{v}(x):x\in\overline{B_{r}(0)}\}\quad\quad M:=L+M_{v}.

Then
f
is non-positive and belongs to
\mathcal{C}^{1}_{M}(\omega)
, so
g(x):=f(x)+\frac{1}{2}M\|x\|^{2}_{2}
is convex on
B_{r}(0)
. Therefore, for every
x\in\overline{B_{r}(0)}
we have that

0=2g(0)\leq g(x)+g(-x)=f(x)+f(-x)+M\|x\|^{2}_{2}\leq f(x)+M\|x\|^{2}_{2}.

Thus,
-M\|x\|^{2}_{2}\leq f(x)
. On the other hand,
f(x)\leq-\varepsilon\|x\|^{2}_{2}
, so the gradient of
f
at
0
exists and vanishes there. Of course, the same is also true for the function
g
. Thus, in view of property (
3.1
), we can estimate the maximal eigenvalue of
g
at 0 as follows:

\displaystyle\displaystyle\lambda_{g}(0)=2\limsup_{\varepsilon\to 0}\big(\max\{g(\varepsilon h):h\in\mathbb{R}^{n},\ \|h\|_{2}=1\}\big)/\varepsilon^{2}\leq M-2\varepsilon.

(3.2)

By the Busemann-Feller-Alexandroff theorem (see Theorem
3.1
), the real Hessian of
f
exists almost everywhere on
\omega
. Moreover, since
\mathcal{H}_{u}
has at most
q
negative and
\mathcal{H}_{v}
has at most
n{-q-}1
negative eigenvalues, the real Hessian of the sum
f=u+v
has at least one non-negative eigenvalue almost everywhere on
\omega
. Therefore, since the the largest eigenvalue of the function
x\mapsto\frac{1}{2}M\|x\|^{2}_{2}
is exactly
M
, we derive the estimate
\lambda_{g}(x)\geq M
at almost every point in
B_{r}(0)
. Then it follows from Theorem
3.5
that
\lambda_{g}\geq M
everywhere on
B_{r}(0)
. In particular,
\lambda_{g}(0)\geq M
, which is a contradiction to (
3.2
).

We show that any real
q
-convex function can be approximated from above by a decreasing sequence of real
q
-convex functions being continuous everywhere and twice differentiable almost everywhere.

Theorem 3.7
.

Let
u
be a non-negative bounded real
q
-convex function on an open set
\omega
in
\mathbb{R}^{n}
. Let
g\in\mathcal{C}^{1}_{L}(\mathbb{R}^{n})
be a non-negative function with compact support in some ball
B_{r}(0)
. Define the set
\omega_{r}:=\{x\in\omega:d_{2}(x,\partial\omega)>r\}
and the number
M_{r}:=\sup\{u(x):x\in\omega_{r}\}
. Then
u\ast g
lies in
\mathcal{C}_{LM_{r}}^{1}(\mathbb{R}^{n})
and it is real
q
-convex on
\omega_{r}
.

Proof.

Recall that
\hat{u}
denotes the trivial extension of
u
by zero to the whole of
\mathbb{R}^{n}
. The supremum convolution of
u
and
g
at
x\in\omega_{r}
can be rewritten as follows,

\displaystyle(u\ast g)(x)

\displaystyle=

\displaystyle\sup\{\hat{u}(y)g(x-y):y\in\mathbb{R}^{n}\}

\displaystyle=

\displaystyle\sup\{\hat{u}(x-t)g(t):t\in\mathbb{R}^{n}\}

\displaystyle=

\displaystyle\sup\{u(x-t)g(t):t\in B_{r}(0)\}.

It follows from Proposition
2.2
(
3
) and (
6
) that
x\mapsto g(t)u(x-t)
is real
q
-convex on
\omega_{r}
for every
t\in B_{r}(0)
. Since, in view of Remark
3.2
and Proposition
3.4
, the function
u\ast g
is continuous, Proposition
2.2
(
5
) implies that
u\ast g
is real
q
-convex on
\omega_{r}
. Finally, it follows directly from Proposition
3.4
that
u\ast g
belongs to
\mathcal{C}_{LM_{r}}^{1}(\mathbb{R}^{n})
.

This leads to the following important approximation technique.

Proposition 3.8
.

Let
u
be a real
q
-convex function on an open set
\omega
in
\mathbb{R}^{n}
and let
D
be a relatively compact open set in
\omega
. Assume that
f
is a continuous function on
\omega
and satisfies
u<f
on a neighborhood of
\overline{D}
. Then there is a positive number
L>0
and a continuous function
\tilde{u}\in\mathcal{C}^{1}_{L}(\mathbb{R}^{n})
which is real
q
-convex in a neighborhood of
\overline{D}
and which fulfills
u<\tilde{u}<f
on
\overline{D}
.

Proof.

Let
r
be a positive number so small that that
\overline{D}
is contained in
D_{r}:=\omega_{r}\cap B_{1/r}(0)
, where
\omega_{r}:=\{x\in\omega:d_{2}(x,\partial\omega)>r\}
. Given
k\in\mathbb{N}
, we set
v:=\max\{u,-k\}+k+1/k
. Then
u<v-k
and
v
is positive. Since the sequence
(v-k)_{k\in\mathbb{N}}
decreases to
u
, we can find a large enough integer
k\in\mathbb{N}
such that
v-k<f
on
\overline{D}
. By upper semi-continuity of
v
and compactness of
\overline{D}
, we can choose another radius
r^{\prime}\in(0,r)
so small that
D\Subset\omega_{r^{\prime}}
and

\sup\{v(y)-k:y\in B_{r^{\prime}}(x)\}<f(x)\quad\ \hbox{for\ every}\ x\in\overline{D}.

Now pick a
\mathcal{C}^{\infty}
-smooth function
g
with compact support in the ball
B_{r^{\prime}}(0)
such that
0\leq g\leq 1
and
g(0)=1
. We set
\tilde{u}(x):=(v\ast g)(x)-k
for
x\in\omega
. Then we obtain for every
x\in\overline{D}
that

\displaystyle u(x)

\displaystyle<

\displaystyle v(x)-k

\displaystyle=

\displaystyle v(x)g(0)-k

\displaystyle\leq

\displaystyle\sup\{v(y)g(x-y):y\in B_{r^{\prime}}(x)\}-k

\displaystyle=

\displaystyle(v\ast g)(x)-k

\displaystyle=

\displaystyle\tilde{u}(x)

\displaystyle\leq

\displaystyle\sup\{v(y):y\in B_{r^{\prime}}(x)\}-k

\displaystyle=

\displaystyle\sup\{v(y)-k:y\in B_{r^{\prime}}(x)\}<f(x).

The rest of the properties of
\tilde{u}
follow now from the previous Theorem
3.4
.

As a consequence, we obtain an approximation property for real
q
-convex functions by twice differentiable ones.

Corollary 3.9
.

Let
\omega
be an open set in
\mathbb{R}^{n}
, let
K
be a compact set in
\omega
and let
u
be a real
q
-convex function on
\omega
. Then there exists a sequence
\{u_{k}\}_{k\geq 1}
of functions
u_{k}\cap\mathcal{C}^{1}_{\bullet}(\mathbb{R}^{n})
which are real
q
-convex functions near
K
and decrease on
K
to
u
. In particular,
u_{k}
are continuous on
K
and twice differentiable almost everywhere on
K
.

As an application of Theorem
3.6
and Corollary
3.9
, we obtain a result concerning sums of real
q
-convex functions. This result was proved in
[

]
for
q
-plurisubharmonic functions.

Theorem 3.10
.

Given a real
q
-convex function
u_{1}
and a real

-convex function

on an open set

in
\mathbb{R}^{n}
, their sum

is real
(q+r)
-convex on

.

Proof.

By the previous Theorem
3.9
and since real

-convexity is a local property, we can assume that
u_{1}
and
u_{2}
have lower bounded Hessian and that they are twice differentiable almost everywhere on
\omega
. Then in view of the first statement of Theorem
3.6
, the real Hessian of

has at most

and the real Hessian of

has at most

. Now it is easy to verify that the sum of the Hessians of

have at most

certainly also has lower bounded Hessian and is twice differentiable almost everywhere on

is real

-convex on

.

Theorem 3.11
.

Let

be an open set in

there exists a sequence

of real

4
Real
q
-convex and
q
-plurisubharmonic functions

We give the the definition and basic properties of
q
-plurisubharmonic functions in the sense of Hunt-Murray
[
HM78
]
. It turns out that they are closely related to real
q
-convex functions in the same way as plurisubharmonic functions are related to convex functions
[

]
.

Definition 4.1
.

Let
q\in\{0,\ldots,n-1\}
and let
\psi
be an upper semi-continuous function on an open set
\Omega
in
\mathbb{C}^{n}
.

1.

The function
\psi
is
q
-plurisubharmonic
on
\Omega
if it
fulfills the local maximum property on
\Omega
with respect to pluriharmonic functions on complex
(q+1)
-dimensional subspaces
, i.e., for every complex
(q+1)
-dimensional affine subspace
\Pi
, every ball
B\Subset\Omega
and every pluriharmonic function
h
on defined in the neighborhood of
\overline{B}
with
\psi\leq h
on
\partial B\cap\Pi
we already have that
u\leq\ell
on
\overline{B}\cap\Pi
.
3
3

3

This type of function was called
pseudoconvex of order
n-q
by O. Fujita
[
Fuj92
]
. Smooth
q
-plurisubharmonic functions are exactly the
weakly
(q+1)
-convex
ones in the sense of Grauert.

2.

If
m\geq n
, every upper semi-continuous function on
\Omega
is by convention
m
-plurisubharmonic.

The following properties and results are derived from Hunt-Murray’s paper
[
HM78
]
. For additional properties, we refer to
[

]
and
[

]
.

Proposition 4.2
.

1.

The
0
-plurisubharmonic functions are exactly the plurisubharmonic functions.

2.

It follows directly from the definition of
q
-plurisubharmonicity that a function
\psi
is
q
-plurisubharmonic on an open set
\Omega
in
\mathbb{C}^{n}
if and only if
\psi+\varphi
is
q
-plurisubharmonic for every pluriharmonic function
h
on
\Omega
.

3.

A function is
q
-plurisubharmonic if and only if it is locally
q
-plurisubharmonic.

4.

A
q
-plurisubharmonic function remains
q
-plurisubharmonic after a holomorphic change of coordinates.

We have the following characterization of smooth
q
-plurisubharmonic functions.

Theorem 4.3
.

Let
q\in\{0,\ldots,n-1\}
and let
\psi
be a
\mathcal{C}^{2}
-smooth function on an open subset
\Omega
in
\mathbb{C}^{n}
. Then
\psi
is

-plurisubharmonic if and only if the complex Hessian
\mathcal{H}^{\mathbb{C}}_{\psi}(p)=\left(\frac{\partial^{2}\psi}{\partial z_{k}\partial\overline{z}_{\ell}}(p)\right)_{k,\ell=1}^{n}
has at most
q
negative eigenvalues at every point
p
in
\Omega
.

The maximum principle holds for
q
-plurisubharmonic functions.

Theorem 4.4
(Maximum principle).

Let
q\in\{0,\ldots,n-1\}
and
\Omega
be a relatively compact open set in
\mathbb{C}^{n}
. Then any function
u
which is upper semi-continuous on
\overline{\Omega}
and
q
-plurisubharmonic on
\Omega
fulfills

\max\{\psi(z):z\in\overline{\Omega}\}=\max\{\psi(z):z\in\partial\Omega\}.

As a first step toward proving our main results, we show that real
q
-convex functions are indeed
q
-plurisubharmonic.

Theorem 4.5
.

Let
\Omega
be an open subset in
\mathbb{C}^{n}=\mathbb{R}^{2n}
. Then every real
q
-convex function
u
on
\Omega
is
q
-plurisubharmonic.

Proof.

If
q\geq n
, then the statement is trivial, since every upper semi-continuous function on
\Omega
is
q
-plurisubharmonic by convention. Otherwise, by Theorem
3.9
, we can locally approximate
u
by a sequence of real
q
-convex functions which are twice differentiable almost everywhere. Thus, since
q
-plurisubharmonicity is a local property, we can assume without loss of generality that
u
is twice differentiable almost everywhere on
\Omega
. Since
u
is
q
-plurisubharmonic on
\Omega
if and only if it is
q
-plurisubharmonic on every complex affine subspace of dimension
q+1
, and since the restriction of a real
q
-convex function to an affine subspace clearly remains real
q
-convex, it is enough to prove the statement in the case of
q=n-1
.

Thus, let us assume that
q=n-1
and that the real Hessian
\mathcal{H}_{u}(p)
of
u
at
p
exists for some point
p
in
\Omega
. By Theorem
3.6
(1), the real Hessian
\mathcal{H}_{u}(p)
of
u
at
p
has at least
2n-(n-1)=n+1
non-negative eigenvalues. This means that there is a real
n+1
dimensional subspace
V
of
\mathbb{C}^{n}=\mathbb{R}^{2n}
such that
\mathcal{H}_{u}(p)
is positive semi-definite on
V
. Since
V
is not totally real, there is a vector
v
in
V
such that
iv
also lies in
V
. Therefore, since
v^{t}\mathcal{H}_{u}(p)v
and
(iv)^{t}\mathcal{H}_{u}(p)(iv)
are both non-negative by assumption, it follows that the complex Hessian of
u
at
p
is non-negative due to the following identity,

\overline{v}^{t}\mathcal{H}^{\mathbb{C}}_{u}(p)v=\frac{1}{4}\Big(v\mathcal{H}_{u}(p)v+(iv)^{t}\mathcal{H}_{u}(p)(iv)\Big).

Hence, the Levi matrix
\mathcal{H}^{\mathbb{C}}_{u}(p)
of
u
at
p
has at least one non-negative eigenvalue. By the choice of
p
, we deduce that
\mathcal{H}^{\mathbb{C}}_{u}
has at least one non-negative eigenvalue almost everywhere on
\Omega
. Then Theorem 4.1 in
[
Sło84
]
implies that the function
u
is
(n-1)
-plurisubharmonic on
\Omega
.

The previous result cannot be improved.

Example 4.6
.

Consider the function
z\mapsto\operatorname{Re}(z)^{2}-\operatorname{Im}(z)^{2}=\operatorname{Re}(z^{2})
. It is harmonic on
\mathbb{C}
(i.e., 0-plurisubharmonic), but not locally convex (i.e, real 0-convex).

However, under certain additional assumptions, we obtain a converse statement to Theorem
4.5
. For this, we have to restrict to functions that are invariant in their imaginary parts.

Definition 4.7
.

Let
\omega
be an open set in
\mathbb{R}^{n}
.

1.

A function
\psi=\psi(z)
on a
tube set

\omega+i\mathbb{R}^{n}
in
\mathbb{C}^{n}
is called

if
\psi(z)=\psi(\operatorname{Re}(z))
for every
z\in\omega+i\mathbb{R}^{n}
.

2.

By the definition, a rigid function
\psi
on a tube set
\omega+i\mathbb{R}^{n}
can be naturally considered as a function
x\mapsto\psi(x)
on
\omega
. On the other hand, every function
u
on
\omega
induces a well defined rigid function on
\omega+i\mathbb{R}^{n}
via
z\mapsto u(\operatorname{Re}(z))
for every
z\in\omega+i\mathbb{R}^{n}
.

We generalize Lelong’s observation
[
Lel52
]
that every rigid plurisubharmonic function is locally convex (case
q=0
) to the general case

.

Theorem 4.8
(First main theorem).

Let
\omega
be an open set in
\mathbb{R}^{n}
. Then every rigid function on
\Omega=\omega+i\mathbb{R}^{n}
is
q
-plurisubharmonic if and only if it is real
q
-convex on
\omega
.

Proof.

Using the approximation techniques for real
q
-convex functions from Section
3
and by counting the eigenvalues of the involved Hessians, we can easily deduce that, if a function
u
is real
q
-convex on
\omega
, then it is also real
q
-convex on
\omega+i\mathbb{R}^{n}
. Then it follows directly from Theorem
4.5
that
u
is
q
-plurisubharmonic on
\Omega
.

For the converse statement, consider a rigid
q
-plurisubharmonic function
\psi
on
\Omega:=\omega+i\mathbb{R}^{n}
. Pick a real affine subspace
\pi
in
\mathbb{R}^{n}
of dimension
q+1
, a ball
B\Subset\pi\cap\omega
and an affine linear function
\ell
on
\pi
such that
\psi\leq\ell
on
\partial B
. After a complex linear change of coordinates of the form
z\mapsto\lambda z+p
, where
\lambda\in\mathbb{R}
and
p\in\mathbb{C}^{n}
, we may assume that
\pi
contains the origin and that
B=B^{n}_{1}(0)\cap\pi
. Given a positive number
R>0
, which will be specified later, and another ball
B_{R}:=B_{R}^{n}(0)\cap\pi
in
\pi
, consider the set

D_{R}:=B+iB_{R}
. Since
\Omega
is a tube set,
B\Subset\omega\cap\pi
and since

, the set
D_{R}
contains

and lies relatively compact in
\Omega\cap\pi^{\mathbb{C}}
, where
\pi^{\mathbb{C}}:=\pi+i\pi
. Moreover, the boundary of
D_{R}
in
\pi^{\mathbb{C}}
splits into two parts,

A_{1}:=\partial B+i\overline{B_{R}}\quad\hbox{and}\quad A_{2}:=\overline{B}+i(\partial B_{R}).

Since
\ell
is affine linear,
\psi
is
q
-plurisubharmonic on
\Omega
and since
z\mapsto\|x\|^{2}_{2}-\|y\|^{2}_{2}=\sum_{j=1}^{n}\hbox{Re}(z_{j}^{2})
is pluriharmonic on
\mathbb{C}^{n}_{z}=\mathbb{R}^{n}_{x}+i\mathbb{R}^{n}_{y}
, it follows from Remark
4.2
that for every integer

the function

\psi_{k}(z):=\psi(x)-\ell(x)+\left(\|x\|^{2}_{2}-\|y\|^{2}_{2}\right)/k

is

-plurisubharmonic on
\Omega
. The assumption
\psi\leq\ell
on

and the choice of

now yield the subsequent estimates for

\psi_{k}\leq 1/k\quad\hbox{on}\ A_{1}\quad\hbox{and}\quad\psi_{k}\leq\psi-\ell+(1-R^{2})/k\quad\hbox{on}\ A_{2}.

Thus, if we choose
R>0
to be large enough, then
\psi_{k}
becomes negative on

. Hence, the function
\psi_{k}
is bounded by
1/k
on the boundary of
D_{R}
. Since
\psi_{k}
is

-plurisubharmonic, the maximum principle implies that the function
\psi_{k}
is bounded from above by

on the closure of

in

. In particular,
\psi_{k}\leq 1/k
on

. But the last inequality holds for every integer

. This yields
\psi-\ell\leq 0
on

\psi
is real

-convex on
\omega
.

As an application, we obtain a result for

Corollary 4.9
.

Let

We recall various notions of boundary distance functions and investigate their mutual relations.

Definition 5.1
.

Let

and let

be some arbitrary real norm on

.

1.

The

\omega\ni x\mapsto d_{\|\cdot\|}(x,\partial\omega):=\inf\big\{\|x-y\|:y\in\partial\omega\big\}.

We set

, if

is empty.

2.

We write

for the boundary distance induced by the Euclidean norm

.

3.

Let

be a fixed vector in
\mathbb{R}^{n}
with
\|v\|_{2}=1
and let

be the real line in
\mathbb{R}^{n}
that passes through

. We define the

\omega\ni x\mapsto R_{v}(x,\partial\omega):=d_{2}\big(x,\partial\omega\cap(x+\mathbb{R}v)\big).

We list the following elementary and well-known properties of these distance functions.

Proposition 5.2
.

Let
\omega\subset\mathbb{R}^{n}
be open,

,
\|\cdot\|
some real norm on
\mathbb{R}^{n}
. Then:

1.

\displaystyle d_{\|\cdot\|}(x,\partial\omega)=\inf\big\{R_{v}(x,\partial\omega)\cdot\|v\|:v\in\mathbb{R}^{n},\ \|v\|_{2}=1\big\}

2.

d_{v}(x,\partial\omega)=d_{\|\cdot\|}(x,\partial\omega\cap(x+\mathbb{R}v))/\|v\|

.

3.

The boundary distance

\omega
.

4.

For every vector

with

the boundary distance in

is lower semi-continuous on

.

We will need the next property for our second main theorem.

Lemma 5.3

Let

be an open set in
\mathbb{R}^{n}

-convex on

If

-convex on

Proof.

By Proposition

are both real

We can now deduce the real

Proposition 5.4
.

Let
\omega\subset\mathbb{R}^{n}
be open and let
\|\cdot\|
be an arbitrary real norm on

Proof.

Fix

We have seen in the proof that the one-dimensional case is special.

t_{0}\in(-1,1)
such that

f_{1}\Big(\frac{1-t_{0}}{2}x_{1}+\frac{1+t_{0}}{2}x_{2}\Big)>\frac{1-t_{0}}{2}f_{1}(x_{1})+\frac{1+t_{0}}{2}f_{1}(x_{2})=:y_{0}.

Let
x_{0}:=\frac{1-t_{0}}{2}x_{1}+\frac{1+t_{0}}{2}x_{2}
and
r_{0}:=f_{1}(x_{0})-y_{0}
. Consider the one-parameter family of real
k
-planar sets
\pi_{r}=\psi_{r}([-1,1]^{k})
defined as the trace of the parametrization
\psi_{r}:[-1,1]^{k}\to\mathbb{R}^{n+k}
via

\displaystyle\psi_{r}(t,s_{2},\ldots,s_{k})

\displaystyle:=\Big(\frac{1-t}{2}x_{1}+\frac{1+t}{2}x_{2},\ \frac{1-t}{2}f_{1}(x_{1})+\frac{1+t}{2}f_{1}(x_{2})+r,\ f_{2}(x_{0})+s_{2},\ldots,f_{k}(x_{0})+s_{k}\Big)

where
t,s_{2},\ldots,s_{k}\in[-1,1]
and
r\geq r_{0}
. Then it is easy to verify that
\{\pi_{r}\}_{r_{0}\leq r\leq 2r_{0}}
violates the
(k{-}1)
-continuity principle in Theorem
5.11
(
1
) as
r\downarrow r_{0}
. Thus,
\Gamma(f)^{c}
cannot be
(k-1)
-convex, a contradiction. Therefore, each
f_{j}
has to be affine linear which means that
f=(f_{1},f_{2},\ldots,f_{k})
in total is affine linear on
\mathbb{R}^{n}
.

We now compare real

-convex sets to generalized pseudoconvex sets. The following definition is adapted from

Definition 5.14
.

Let
q\in\{0,1\ldots,n-1\}
. An open set
\Omega
in
\mathbb{C}^{n}
is called
q
-pseudoconvex if
z\mapsto-\ln d_{2}(z,\partial\Omega)
is
q
-plurisubharmonic on
\Omega
.

Since we will only use the above definition here, for equivalent notions or lists of properties of

An open set

-pseudoconvex if and only if for each boundary point

of

and a

-plurisubharmonic function

whenever

in

For the special case

Every open set in

Our next main result clarifies the relationship between real
q
-convex and
q
-pseudoconvex sets.

Theorem 5.17
(Second main theorem).

Let
\omega
be an open set in
\mathbb{R}^{n}
.

1.

If
\omega
is a real
q
-convex set in
\mathbb{R}^{n}
, then the set
\Omega=\omega+i(-a,a)^{n}
is
q
-pseudoconvex for any
a\in(0,+\infty]
.

2.

If the set
\Omega=\omega+i(-a,a)^{n}
is
q
-pseudoconvex for some
a\in(0,+\infty]
, then
\omega
is a real
q
-convex set in
\mathbb{R}^{n}
.

Proof.

If
q=n-1
, there is nothing to show, since every open set in
\mathbb{C}^{n}
is
(n-1)
-pseudoconvex according Theorem
5.16
, and every open set in
\mathbb{R}^{n}
is
(n-1)
-convex due to our Corollary
5.8
. Hence, from now on we assume that
q<n-1
. The convex/pseudoconvex case
q=0
is due to Lelong
[
Lel52
]
.

Case
\mathbf{a=+\infty}
.
In this case, we are in the setting of a tube set of the form
\Omega=\omega+i\mathbb{R}^{n}
. Since
d_{2}(z,\partial\Omega)=d_{2}(\operatorname{Re}(z),\partial\omega)
for every
z\in\Omega
, the function
z\mapsto d_{2}(z,\partial\Omega)
is rigid on
\Omega
. Then it follows from Theorem
4.8
that the function
x\mapsto-\ln d_{2}(x,\partial\omega)
is real
q
-convex on
\omega
if and only if
z\mapsto-\ln d_{2}(z,\partial\Omega)
is
q
-plurisubharmonic on
\Omega
. Hence,
\omega
is a real
q
-convex set in
\mathbb{R}^{n}
if and only if
\Omega
is a
q
-pseudoconvex set in
\mathbb{C}^{n}
.

Case
\mathbf{a>0}
.
Assume that
\omega
is real
q
-convex. Then, in view of the previous case (
a=+\infty
), the set
\omega+i\mathbb{R}^{n}
is
q
-pseudoconvex. Since the set
\mathbb{R}^{n}+i(-a,a)^{n}=\left(\mathbb{R}+i(-a,a)\right)^{n}
is pseudoconvex as a product of pseudoconvex sets, it follows from Proposition
5.12
(
3
), that the following intersection is
q
-pseudoconvex,

(\mathbb{R}^{n}+i(-a,a)^{n})\cap(\omega+i\mathbb{R}^{n})=\omega+i(-a,a)^{n}.

In order to prove the converse direction, assume that
\Omega
is
q
-pseudoconvex. Theorem 4.3.2 in
[
Paw15
]
implies that, for every vector
v=u+i0
with
u\in\mathbb{R}^{n}
and
\|u\|_{2}=1
, the function
-\ln R_{v}(z,\partial\Omega)
is
q
-plurisubharmonic on
\Omega
. Since
\Omega
is of the form
\omega+i(-a,a)^{n}
, we have that

(\mathbb{R}^{n}+i\{0\}^{n})\cap\Omega=\omega+i\{0\}^{n}.

But this means that
R_{v}(z,\partial\Omega)=R_{u}(\operatorname{Re}(z),\partial\omega)
. Hence,
-\ln R_{v}(z,\partial\Omega)
is a well-defined rigid function on
\omega+i\mathbb{R}^{n}
. In view of Theorem
4.8
, we obtain that for every
u
with
\|u\|_{2}=1
the function
-\ln R_{u}(x,\partial\omega)
is real
q
-convex on
\omega
. By Theorem
5.11
(
2
),
\omega
is a real
q
-convex set in
\mathbb{R}^{n}
.

We obtain a result similar to Corollary
4.9
, but formulated for sets rather than for functions.

Corollary 5.18
.

Let
V
be an open set in
\mathbb{R}^{n}
and let
\Omega_{V}:=\{z\in\mathbb{C}^{n}:(\ln|z_{1}|,\ldots,\ln|z_{n}|)\in V\}
. Then
V
is real
q
-convex in
\mathbb{R}^{n}
if and only if
\Omega_{V}
is
q
-pseudoconvex in
\mathbb{C}^{n}
.

Proof.

By Theorem
5.17
we know that
V
is a real
q
-convex set in
\mathbb{R}^{n}
if and only if
V+i\mathbb{R}^{n}
is
q
-pseudoconvex in
\mathbb{C}^{n}
. Consider the locally biholomorphic map
\Phi:V+i\mathbb{R}^{n}\to\Omega_{V}
defined by
\Phi(w_{1},\ldots,w_{n})=(e^{w_{1}},\ldots,e^{w_{n}})=z
. It is obvious that
w\to\partial(V+i\mathbb{R}^{n})
in
V+i\mathbb{R}^{n}
if and only if
\Phi(w)=z\to\partial\Omega_{V}
in
\Omega_{V}
. Observe also that
\psi
is
q
-plurisubharmonic on an open subset
U
of
\Omega_{V}
if and only if
\psi\circ\Phi
is
q
-plurisubharmonic on the open subset
W:=\Phi^{-1}(U)
in
V+i\mathbb{R}^{n}
, whenever
\Phi
is biholomorphic on
W
. Then the result follows from Thoerem
5.15
.

From this, we derive a generalized version of the classical fact on logarithmically convex Reinhardt domains (case
q=0
).

Corollary 5.19
.

Let
D
be a Reinhardt domain in
\mathbb{C}^{n}
. Then
D
is
q
-pseudoconvex if and only if
\log D:=\{(\ln|z_{1}|,\ldots,\ln|z_{n}|)\in\mathbb{R}^{n}:z\in D\}
is a real
q
-convex set in
\mathbb{R}^{n}
.

Proof.

Simply put
V:=\log D
. Then clearly
D=\Omega_{V}
, so that the statement follows directly from the previous corollary.
