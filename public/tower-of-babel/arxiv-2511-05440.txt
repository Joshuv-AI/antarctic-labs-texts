Shortest self-orthogonal embeddings of binary linear codes PubID: pubid: 0000–0000 © 2023 IEEE
Junmin An, Nathan Kaplan, Jon-Lark Kim, Jinquan Luo, Guodong Wang

Abstract
There has been recent interest in the study of shortest self-orthogonal embeddings of binary linear codes, since many such codes are optimal self-orthogonal codes. Several authors have studied the length of a shortest self-orthogonal embedding of a given binary code 𝒞 \cal C , or equivalently, the minimum number of columns that must be added to a generator matrix of 𝒞 \cal C to form a generator matrix of a self-orthogonal code. In this paper, we use properties of the hull of a linear code to determine the length of a shortest self-orthogonal embedding of any binary linear code. We focus on the examples of Hamming codes and Reed-Muller codes. We show that a shortest self-orthogonal embedding of a binary Hamming code is self-dual, and propose two algorithms to construct self-dual codes from Hamming codes ℋ r \mathcal{H}_{r} . Using these algorithms, we construct a self-dual [ 22 , 11 , 6 ] [22,11,6] code, called the shortened Golay code, from the binary [ 15 , 11 , 3 ] [15,11,3] Hamming code ℋ 4 \mathcal{H}_{4} , and construct a self-dual [ 52 , 26 , 8 ] [52,26,8] code from the binary [ 31 , 26 , 3 ] [31,26,3] Hamming code ℋ 5 \mathcal{H}_{5} . We use shortest SO embeddings of linear codes to obtain many inequivalent optimal self-orthogonal codes of dimension 7 7 and 8 8 for several lengths. Four of the codes of dimension 8 8 that we construct are codes with new parameters such as [ 91 , 8 , 42 ] , [ 98 , 8 , 46 ] , [ 114 , 8 , 54 ] [91,8,42],\,[98,8,46],\,[114,8,54] , and [ 191 , 8 , 94 ] [191,8,94] .

Introduction

Since the beginning of coding theory, the dual of a linear code has been a central topic of study. A code is self-orthogonal if it is a subset of its own dual. The highly interesting combinatorial properties of this special class of codes have led to applications in various other fields including
t
-designs
[
12
,
1
]
, lattices
[
13
,
4
]
and graphs
[
7

[
9
,
16
,
17
,
20

24

[
6
]
transformed the problem of finding quantum error-correcting codes into the problem of finding self-orthogonal codes over
\mathbb{F}_{4}

[
36
]
. Indeed, some codes in the Best Known Linear Codes (BKLC) database in MAGMA
[
5
]
are self-orthogonal. For all of these reasons, constructions and characterizations of self-orthogonal codes have been continuously studied.

In this line of research, Pless
[
29
]
enumerated the number of self-orthogonal codes over a finite field
\mathbb{F}_{q}
in terms of finite geometry, and using this result, she proved the uniqueness of the Golay codes. After this foundational work, enumeration and characterization of self-orthogonal codes have been studied over various rings such as
\mathbb{Z}_{4}
,
\mathbb{Z}_{p^{2}}
, Galois rings and finite chain rings
[
2
,
8
,
21
,
27
,
28
,
34
,
35
]
. In addition to enumeration, efforts were also focused on the classification of self-orthogonal codes. Pless
[
31
]
and Sloane
[
32
]
classified self-orthogonal and self-dual codes with certain lengths and dimensions. Bouyukliev et al.
[
3
]
provide a classification of optimal self-orthogonal codes of length less than or equal to
40

[
22
]
characterized optimal self-orthogonal codes of dimension
4
. Beyond binary codes, the classification of self-orthogonal codes has been extended to larger fields and rings such as
\mathbb{F}_{3}
,
\mathbb{F}_{4}
,
\mathbb{Z}_{4}
and
\mathbb{F}_{2}+u\mathbb{F}_{2}

Recently, Kim et al.
[
18
]
devised an algorithm to construct optimal self-orthogonal codes by adding columns to the generator matrix of a linear code
\mathcal{C}
, which they call self-orthogonal embedding (abbr. SO embedding). They proved that only 3 or fewer columns are needed to embed a linear code of dimension 3 into a self-orthogonal code, and 5 or fewer columns are required to embed a linear code of dimension 4 into a self-orthogonal code. However, the algorithm they suggested can only be applied to linear codes with dimensions less than or equal to 4. Kim and Choi
[
19
]
extended this result, providing an algorithm to find a shortest self-orthogonal embedding of a linear code with dimension 5 or 6 by using a special matrix called a self-orthogonality matrix. They also proved that the minimal number of columns to be added to embed an
[n,k]
linear code into a self-orthogonal code is at most
k
if
k
is odd, and at most
k+1
if
k
is even.

In this paper, we extend the results of
[
19
]
by investigating the exact value of the length of a shortest SO embedding of
C
. The hull of a linear code
\mathcal{C}
, denoted
\operatorname{Hull}(\mathcal{C})
, is the intersection of
\mathcal{C}
and its dual,
\mathcal{C}^{\perp}
. Let
\ell=\dim(\operatorname{Hull}(\mathcal{C}))

k-\ell
is odd, then a shortest SO embedding of
\mathcal{C}
has length
n+k-\ell
, and if
k-\ell
is even, then the length of a shortest SO embedding of
\mathcal{C}
is
n+k-\ell
or
n+k-\ell+1
. Furthermore, we determine which of these two possibilities occurs, depending on whether
\cal C
is an even code or an odd code. We find the lengths of shortest SO embeddings of binary Reed-Muller codes and binary Hamming codes. We also propose an efficient algorithm to find the shortest SO embedding of a linear code. With this algorithm, we found all possible shortest SO embeddings of the binary Hamming code
\mathcal{H}_{4}
up to equivalence. Among these embeddings, we show that one corresponds to the shortened Golay code, which provides an interesting connection between two important classes of codes, the Hamming codes and Golay codes. Finally, using shortest SO embeddings, we construct many new optimal self-orthogonal codes of dimension
7
with lengths up to
126
and of dimension
8
with lengths up to
254
, respectively. We also obtained several codes of dimension
8
with new, previously unknown parameters including
[91,8,42],\,[98,8,46],\,[114,8,54]

[191,8,94]

This paper is organized as follows. Section 2 provides some preliminaries on coding theory and introduces previous results on SO embeddings. In Section 3, we present our main results on the length of a shortest SO embedding of a binary linear code. We consider separate cases based on whether
k-\ell
is even or odd. We also provide the exact length of shortest SO embeddings of Reed-Muller codes and Hamming codes. Section 4 describes an algorithm to embed Hamming codes into self-orthogonal codes. In Section 5, we apply our results about shortest SO embeddings to construct optimal self-orthogonal codes in dimension
7
and
8
, identifying several codes with new parameters. We conclude our paper in Section 6.

Preliminaries

For a general reference on coding theory we recommend
[
30
,
26
,
15
]
.

Let
\mathbb{F}_{2}
be the finite field with two elements.
A subspace
{\mathcal{C}}
of
\mathbb{F}_{2}^{n}
with dimension
k
is called a
linear code
of length
n
and dimension
k
, and say that
\cal C
is an
[n,k]
code.
The elements of
{\mathcal{C}}
are called
codewords
. A
generator matrix
for
{\mathcal{C}}
, denoted by
G({\mathcal{C}})
, is a
k\times n
matrix whose rows form a basis for
{\mathcal{C}}
. For a
k\times n
matrix
G
, we denote the linear code generated by the rows of
G
by
\langle G\rangle
. Two codes
\mathcal{C}_{1}
and
\mathcal{C}_{2}
are said to be
(permutation) equivalent
if there exists a permutation of columns
\sigma
such that
\sigma\mathcal{C}_{1}=\mathcal{C}_{2}
. Throughout this paper, we write
\mathcal{O}
to denote the all zero matrix where the dimensions of the matrix are usually understood from context. We write
{\bf{1}}
to denote the all ones vector and
{\bf{0}}
to denote the all zero vector.

Let
{\mathbf{x}}=(x_{1},x_{2},\ldots,x_{n}),{\mathbf{y}}=(y_{1},y_{2},\ldots,y_{n})\in\mathbb{F}_{2}^{n}
. Define
{\mathbf{x}}\cdot{\mathbf{y}}:=\sum_{i=1}^{n}x_{i}y_{i}
. For a linear code
{\mathcal{C}}
, the
dual
of
{\mathcal{C}}
is defined by

{\mathcal{C}}^{\perp}:=\left\{{\mathbf{x}}\in\mathbb{F}_{2}^{n}\;\middle|\;{\mathbf{x}}\cdot{\mathbf{y}}=0\>{\mbox{for all }}{\mathbf{y}}\in{\mathcal{C}}\right\}
.
A linear code
{\mathcal{C}}
satisfying
{\mathcal{C}}\subseteq{\mathcal{C}}^{\perp}
(resp.
{\mathcal{C}}={\mathcal{C}}^{\perp}
) is called
self-orthogonal
(resp.
self-dual
). The
hull

\mbox{Hull}(\mathcal{C})
of a linear code
\mathcal{C}
is defined as the intersection of
\mathcal{C}
and its dual
\mathcal{C}^{\perp}
. If
\mbox{Hull}(\mathcal{C})=\{0\}
, then
\mathcal{C}
is called
linear complementary dual
(LCD).

For
{\mathbf{x}}\in\mathbb{F}_{2}^{n}
, the
(Hamming) weight

{\rm wt}({\mathbf{x}})
is the number of nonzero coordinates in
{\mathbf{x}}
. For
{\mathbf{x}},{\mathbf{y}}\in\mathbb{F}_{2}^{n}
, the
(Hamming) distance

d({\mathbf{x}},{\mathbf{y}})
between
{\mathbf{x}}
and
{\mathbf{y}}
is defined as
d({\mathbf{x}},{\mathbf{y}})={\rm wt}({\mathbf{x}}-{\mathbf{y}})
. A linear code
\cal C
is called an
even code
if the weight of every codeword in
\cal C
is even. A binary codes that is not even is called an odd code. The
minimum distance
of
{\mathcal{C}}
is the minimum of the distances between any two distinct codewords.
An
[n,k,d]
code

{\mathcal{C}}
is an
[n,k]
code with minimum distance
d
.
A linear
[n,k]
code
{\mathcal{C}}
is called
\it optimal
if its minimum distance
d
is the highest among all
[n,k]
codes. A self-orthogonal
[n,k]
code with the highest minimum distance among all self-orthogonal
[n,k]
codes is called an
optimal SO code
. For a given length
n
and dimension
k
, we denote the minimum distance of an optimal
[n,k]
self-orthogonal code by
d_{SO}(n,k)
.

In what follows, we give a general definition of an SO embedding of
{\mathcal{C}}
from
[
18
]
, which does not depend on a choice of generator matrix for
\cal C
.

Definition 1
.

Let
{\mathcal{C}}
be a binary
[n,k]
code.

(i)

An
SO embedding
of
{\mathcal{C}}
is a self-orthogonal code
\tilde{\mbox{$\cal C$}}\subset\mathbb{F}_{2}^{n^{\prime}}
(
n^{\prime}\geq n
) such that there exists a subset of coordinates of
\tilde{\mbox{$\cal C$}}
for which
\tilde{\mbox{$\cal C$}}
punctured on this set of coordinates is
\cal C
.

(ii)

An SO embedding of
{\mathcal{C}}
is called a
shortest SO embedding
of
{\mathcal{C}}
if its length is shortest among all SO embeddings of
{\mathcal{C}}
.

Note that any SO embedding
\tilde{\mbox{$\cal C$}}
of
\cal C
is permutation equivalent to a SO embedding of
\cal C
for which puncturing on its last
n^{\prime}-n
coordinates gives
\cal C
. Thus, we have the following.

Lemma II.1
.

Let
G
be a generator matrix for
\cal C
. Then
\tilde{\mbox{$\cal C$}}
is a SO embedding of
\cal C
if and only if
\tilde{\mbox{$\cal C$}}
is self-orthogonal and is permutation equivalent to a code with a generator matrix equal to
[G~|~S]
for some matrix
S
.

Therefore, in order to obtain a SO embedding of a binary linear code
\cal C
with generator matrix
G
, it is enough to add columns to the right of
G
until we get a self-orthogonal code.

Kim et al.
[
18
, p. 3705]
applied complicated algorithms to show the following.

(i)

Let
\cal C
be a binary
[n,2]
code or a binary
[n,3]
code. A shortest SO embedding of
\cal C
has length at most
n+3
.

(ii)

Let
\cal C
be a binary
[n,4]
code. A shortest SO embedding of
\cal C
has length at most
n+5
.

We first consider shortest SO embeddings of
\mathbb{F}_{2}^{n}
.

Lemma II.2
.

Let
\mathbb{F}_{2}^{n}
be the binary code with generator matrix
I_{n}
.

(i)

Any shortest SO embedding of
\mathbb{F}_{2}^{n}
is equivalent to a self-dual
[2n,n]
code with generator matrix
[I_{n}~|~A]
, where
AA^{T}=I_{n}
.

(ii)

Conversely, any binary self-dual
[2n,n]
code is equivalent to a shortest SO embedding of
\mathbb{F}_{2}^{n}
.

Proof.

(i) Let
n+m
be the length of a shortest SO embedding
\mathcal{C}
of
\mathbb{F}_{2}^{n}
. Let
[I_{n}~|~A]
be a generator matrix for
\mathcal{C}
where
A
is an
n\times m
matrix. Since
\cal C
is self-orthogonal, we have
n+m\geq 2n
, that is,
m\geq n
. We choose
A=I_{n}
and see that the matrix
[I_{n}~|~I_{n}]
generates a self-dual code. Hence
m=n
. So any shortest SO embedding of
\mathbb{F}_{2}^{n}
is equivalent to a self-dual
[2n,n]
code whose generator matrix
[I_{n}~|~A]
satisfies
AA^{T}=I_{n}
.

(ii) Conversely, any binary self-dual
[2n,n]
code is equivalent to a binary code
\mathcal{C}^{\prime}
with generator matrix
[I_{n}~|~A]
, where
A
is an
n\times n
matrix. Clearly,
\mathcal{C}^{\prime}
is a SO embedding of
\mathbb{F}_{2}^{n}
. It is one of shortest length since we have just shown that a shortest SO embedding has length
2n
.
∎

Therefore, the relationship between a binary linear code
\cal C
and a shortest SO embedding
\tilde{\mbox{$\cal C$}}
of
\cal C
is a natural generalization of the relation between
\mathbb{F}_{2}^{n}
and a self-dual
[2n,n]
code. In what follows, we investigate the details of shortest SO embeddings of linear codes.

III
Shortest self-orthogonal embeddings of linear codes

Lemma III.1
.

(
[
19
, Theorem 13]
)

Let
\mathcal{C}
be any binary
[n,k]
code. The length of a shortest SO embedding
\tilde{\mathcal{C}}
is at most

(i)

n+k
if
k
is odd, or

(ii)

n+k+1
if
k
is even.

Lemma III.2
.

Suppose that
\mathcal{C}
is an
[n,k]
binary code with

\ell=\dim({\rm{Hull}}(\mathcal{C}))
. Then the following hold.

(i)

\mathcal{C}
has a generator matrix of the form

\left[\begin{array}[]{cc}G(\mathcal{\rm{Hull}}(\mathcal{C}))\\
A\\
\end{array}\right].

(ii)

The length of a shortest SO embedding of
\mathcal{C}
equals the length of a shortest SO embedding of the code
\left<A\right>
.

Proof.

The first statement is clear, so we now prove (ii).

Let
\mathcal{C}^{\prime}
be a shortest SO embedding of
\mathcal{C}
. Then
\mathcal{C}^{\prime}
has a generator matrix of the form

G^{\prime}=\left[\begin{array}[]{cc}G(\mathcal{\mbox{Hull}}(\mathcal{C}))&B\\
A&D\\
\end{array}\right].

Since
\left<[A~D]\right>
is a subcode of a self-orthogonal code
\mathcal{C}^{\prime}
,

\left<[A~D]\right>
is self-orthogonal. So the length of a shortest SO embedding of
\left<A\right>
is at most the length of the shortest SO embedding of
\mathcal{C}
.

Suppose
D
is a matrix such that
\left<[A~D]\right>
is self-orthogonal. Then

G^{\prime\prime}=\left[\begin{array}[]{cc}G(\mathcal{\mbox{Hull}}(\mathcal{C}))&\mathcal{O}\\
A&D\\
\end{array}\right]

is a generator matrix of a SO embedding of
\mathcal{C}
. We see that the length of a shortest SO embedding of
\mathcal{C}
is at most the length of a shortest SO embedding of
\left<A\right>
. Therefore, the length of a shortest SO embedding of
\mathcal{C}
equals the length of a shortest SO embedding of
\left<A\right>
.
∎

When a binary linear code contains its dual we can prove a stronger version of Lemma
III.1
.

Theorem III.3
.

Let
\mathcal{C}
be a binary
[n,k]
code which contains its dual, that is,
\mathcal{C}^{\perp}\subset\mathcal{C}
. Then the length of a shortest SO embedding of
\mathcal{C}
is

\begin{cases}2k&{\mbox{ if }}n{\mbox{ is odd, }}\\
2k{\mbox{ or }}2k+1&{\mbox{ if }}n{\mbox{ is even. }}\end{cases}

Proof.

Let
\tilde{{\mathcal{C}}}
be a shortest self-orthogonal embedding of
\mathcal{C}
with parameters
[n^{\prime},k]
. Then
n^{\prime}\geq 2k
. Let
n^{\prime}=n+s
. Then we have
s\geq 2k-n
.

By Lemma
III.2
(i),
\mathcal{C}
has a generator matrix of the form

G(\mathcal{C})=\left[\begin{array}[]{c}G(\mathcal{C}^{\perp})\\
A\\
\end{array}\right].

Lemma
III.2
(ii) implies that to determine the length of a shortest SO embedding of
\mathcal{C}
, it suffices to determine the length of a shortest SO embedding of
\left<A\right>
.

By Lemma
III.1
,
\left<A\right>
can be embedded into a self-orthogonal code by adding at most
2k-n
columns if
2k-n
is odd, or at most
2k-n+1
columns if
2k-n
is even. Let
B
be the matrix consisting of these new columns. Then the matrix

G(\tilde{{\mathcal{C}}})=\left[\begin{array}[]{cc}G(\mathcal{C}^{\perp})&\mathcal{O}\\
A&B\\
\end{array}\right]

generates a self-orthogonal code with length at most
n+(2k-n)=2k
if
2k-n
is odd, or length at most
n+(2k-n+1)=2k+1
if
2k-n
is even. Since
s\geq 2k-n
, this implies the conclusion of the theorem.
∎

Corollary III.4
.

Let
\mathcal{H}_{r}
be the binary Hamming
[n=2^{r}-1,k=n-r,3]
code where
r\geq 3
. Then the smallest number
s
of columns to be added to
G(\mathcal{H}_{r})
for an embedding of
\mathcal{H}_{r}
into a self-orthogonal
[n^{\prime},k]
code
\tilde{\mathcal{H}_{r}}
is

k-r=n-2r=2^{r}-1-2r.

Since
n^{\prime}=n+(n-2r)=2(n-r)
and
k=n-r
,
\tilde{\mathcal{H}_{r}}
is a self-dual code.

Proof.

We first recall that
\mathcal{H}_{r}
contains the simplex code
\mathcal{S}_{r}
, which is also the dual of
\mathcal{H}_{r}
. We note that
2k-n=n-2r=2^{r}-1-2r
is odd.
Therefore, by Theorem
III.3
, we need to add exactly
s=2^{r}-1-2r
columns to produce a shortest SO embedding of
\mathcal{H}_{r}
. It is easy to see that
\tilde{\mathcal{H}_{r}}
is a self-dual code.
∎

To get an explicit form of the SO embedding, let
G(\mathcal{S}_{r})
denote a generator matrix for
\mathcal{S}_{r}
and let
A
be a
(n-2r)\times n
matrix so that

\left[\begin{array}[]{c}G(\mathcal{S}_{r})\\
A\end{array}\right]

is a generator matrix for
\mathcal{H}_{r}
. Let
[A~B]
be a generator matrix for a shortest SO embedding of
\left<A\right>
. Then the matrix

G(\tilde{\mathcal{H}_{r}})=\left[\begin{array}[]{cc}G(\mathcal{S}_{r})&\mathcal{O}\\
A&B\\
\end{array}\right]

generates a self-orthogonal code with length at most
n+(n-2r)=2(n-r)
and dimension
k=n-r
.

The dimension of the hull of a code will be a major tool in our arguments. We recall how to determine the dimension of the hull of a code in terms of the rank of a certain matrix.

Proposition III.5
.

(
[
11
, Proposition 3.1]
)

Let
C\subseteq\mathbb{F}_{q}^{N}
be a linear code of dimension
K
and let
G
be a generator matrix for
\cal C
. Then
\operatorname{rank}(GG^{T})=K-\dim(\operatorname{Hull}(\mbox{$\cal C$}))
.

In particular,
\cal C
is self-orthogonal if and only if
GG^{T}=\mathcal{O}
, and
\cal C
is LCD if and only if
GG^{T}
is invertible.

We now see how the dimension of the hull of a code can change when we add a column to a generator matrix.

Lemma III.6
.

Let
G
be a
k\times n
matrix over a field and
{\bf{v}}
be a
k\times 1
matrix. Let
G_{1}=[G~|~{\bf{v}}]
, the concatenation of
G
by
{\bf{v}}
. Then

{\rm{rank}}(GG^{T})-1\leq{\rm{rank}}(G_{1}G_{1}^{T})\leq{\rm{rank}}(GG^{T})+1.

Let
\mathcal{C}
(resp.
\mathcal{C}_{1}
) be a linear code with generator matrix
G
(resp.
G_{1}
).
Let
\ell
be the dimension of
\rm{Hull}(\mathcal{C})
and
\ell_{1}
be the dimension of
\rm{Hull}(\mathcal{C}_{1})
. Then

\ell-1\leq\ell_{1}\leq\ell+1.

Proof.

It is easy to see that
G_{1}G_{1}^{T}=GG^{T}+{\bf{v}}{\bf{v}}^{T}
. If
{\bf v}={\bf 0}
the conclusion is trivial, so suppose
{\bf v}\neq{\bf 0}
.

Note that for any two matrices
A
and
B
of the same size over a field,
{\rm{rank}}(A+B)\leq{\rm{rank}}(A)+{\rm{rank}}(B)
. Let
A=GG^{T}
and
B={\bf{v}}{\bf{v}}^{T}
. We have
{\rm{rank}}(G_{1}G_{1}^{T})\leq{\rm{rank}}(GG^{T})+1
since
\operatorname{rank}({\bf{v}}{\bf{v}}^{T})=1
. Similarly, letting
A=GG^{T}+{\bf{v}}{\bf{v}}^{T}
and
B=-{\bf{v}}{\bf{v}}^{T}
, we have

{\rm{rank}}(GG^{T})={\rm{rank}}(A+B)\leq{\rm{rank}}(A)+{\rm{rank}}(B)={\rm{rank}}(GG^{T}+{\bf{v}}{\bf{v}}^{T})+1.

Therefore,

{\rm{rank}}(G_{1}G_{1}^{T})\geq{\rm{rank}}(GG^{T})-1
. This completes the first part of the proof.

Applying Proposition
III.5
proves the second statement.
∎

We can improve Theorem
III.3
, and
[
19
, Theorem 13]
, by using information about the dimension of the hull of a linear code.

Theorem III.7
.

Let
\mathcal{C}
be a binary
[n,k]
code with generator matrix
G(\mathcal{C})
and let
\ell=\dim({\rm{Hull}}(\mathcal{C}))
. Then the smallest number of columns to be added to
G(\mathcal{C})
for the embedding of
\mathcal{C}
into a self-orthogonal
[n^{\prime},k]
code
\tilde{\mathcal{C}}
is

\begin{cases}k-\ell&{\mbox{ if }}k-\ell{\mbox{ is odd, }}\\
k-\ell{\mbox{ or }}k-\ell+1&{\mbox{ if }}k-\ell{\mbox{ is even. }}\end{cases}

Proof.

Let us start from
G(\mathcal{C})
and add a column
{\bf{v}}
to it to get
G_{1}=[G(\mathcal{C})~|~{\bf{v}}]
. Let
\mbox{$\cal C$}_{1}=\left<G_{1}\right>
and let
\ell_{1}=\dim(\operatorname{Hull}(\mbox{$\cal C$}_{1}))
. Lemma
III.6
implies that
\ell_{1}\leq\ell+1
. We repeat this process, adding
i
columns to
G(\mathcal{C})
to get
G_{2}
. Let
\mbox{$\cal C$}_{2}=\left<G_{2}\right>
and let
\ell_{2}=\dim(\operatorname{Hull}(\mbox{$\cal C$}_{2}))
. We know that
\ell_{2}\leq\ell+i
. If
\mbox{$\cal C$}_{2}
is self-orthogonal, we must have
\ell_{2}=k
, so we see that the length of a shortest SO embedding of
\cal C
is at least
n+k-\ell
.

On the other hand, We apply an argument similar to the proof of Theorem
III.3
. We start from a generator matrix for
\cal C
of the form

\left[\begin{array}[]{c}G(\mathcal{C})\\
A\end{array}\right].

Let
\left<[A~B]\right>
be a shortest SO embedding of
\left<A\right>
. Since
\left<A\right>
has dimension

III.1
and Lemma

\left[\begin{array}[]{cc}G(\mathcal{\mbox{Hull}}(\mathcal{C}))&\mathcal{O}\\
A&B\\
\end{array}\right]

generates a self-orthogonal embedding
\tilde{\mathcal{C}}
of
\cal C
. This completes the proof.
∎

Lemma III.8
.

Consider the generator matrix

for the even weight subcode

(i)

Suppose that

2n-2
.

(ii)

Suppose that

\mathcal{E}_{n}

2n-1

Proof.

We first prove (i). Note that
\operatorname{Hull}(\mathcal{E}_{n})=\left<{\bf{1}}\right>
. If there were an SO embedding of
\mathcal{E}_{n}
of length
2n-2
, then Lemma
III.6
implies that each time we add a column to

, the dimension of the hull of the code that we generate would have to increase by

(c_{1},\dots,c_{n})\in\operatorname{Hull}(\mathcal{C})

Next we prove (ii). Note that

Corollary III.9

Let

(i)

\mathcal{C}^{\prime}

[2n,n-1,4]

Proof.

For convenience, we choose the generator matrix

\mathcal{E}_{n}^{\perp}=\left<{\bf 1}\right>
. Since

Theorem III.10
.

\mathcal{C}
be a binary even
[n,k,d]

Then, the following hold.

(i)

is even, then
\mathcal{C}

whose parameters are
[n^{\prime}=n+(k-\ell+1),k,d^{\prime}\geq d]

Statement (i) follows directly from Theorem
III.7
, so we now prove Statement (ii).

We know that the length of a shortest SO embedding of
\mathcal{C}
is either
n+k-\ell
or
n+k-\ell+1
.
We want to show that
\mathcal{C}
does not have an SO embedding of length

By Lemma

(i),
\mathcal{C}
has a generator matrix of the form

\left[\begin{array}[]{cc}G(\mathcal{\mbox{Hull}}(\mathcal{C}))\\
A\\
\end{array}\right],

where

is a

(ii), it is enough to show that

Theorem III.11
.

Let
\mathcal{C}
be a binary odd
[n,k,d]
code with
\dim(\operatorname{Hull}(\mathcal{C}))=\ell
. Then,
\mathcal{C}
has a shortest SO embedding
\mathcal{C}^{\prime}
whose parameters are
[n^{\prime}=n+(k-\ell),k,d^{\prime}\geq d]
.

Proof.

Since
\cal C
is odd, it has a generator matrix of the form

G(\mathcal{C})=\left[\begin{array}[]{c}G({\mbox{{\rm{Hull}}}}(\mathcal{C}))\\
{\bf{x}}\\
A_{0}\\
\end{array}\right]

where
\operatorname{wt}({\bf{x}})
is odd and
\left<A_{0}\right>=\mathcal{C}_{0}
is an even code with dimension
k-\ell-1
.

We consider three cases.

(i) Suppose that
k-\ell
is odd. Theorem
III.7
implies that a shortest SO embedding of
\cal C
has length
n+k-\ell
.

(ii-1) Suppose that
k-\ell
is even and that
{\bf{x}}\perp\mathcal{C}_{0}
. Consider the matrix

A_{1}=\left[\begin{array}[]{cc}{\bf{x}}&1\\
A_{0}&{\bf{0}}\\
\end{array}\right].

Since
{\bf x}
is orthogonal to every row of
A_{0}
, we see that
\operatorname{Hull}(\left<A_{0}~{\bf{0}}\right>)
is trivial. The vector
({\bf{x}}~1)
is even and orthogonal to the rows of
[A_{0}~{\bf{0}}]
. We see that
\operatorname{Hull}(\left<A_{1}\right>)=\left<({\bf{x}}~1)\right>
. Lemma
III.2
(ii) implies that the length of a shortest SO embedding of
\cal C
is equal to the length of a shortest SO embedding of
\left<A_{0}~{\bf{0}}\right>
.

Since
\left<A_{0}~{\bf{0}}\right>
is an even code with length
n+1
and dimension
k-\ell-1
, which is odd, Theorem
III.10
implies that a shortest SO embedding of
\left<A_{0}~{\bf{0}}\right>
has length
(n+1)+k-\ell-1
. Therefore, a shortest SO embedding of
\cal C
has length
n+k-\ell
.

(ii-2) Suppose that
k-\ell
is even and that
{\bf{x}}
is not orthogonal to every vector in
\mathcal{C}_{0}
. Let
{\bf y}
be a row of
A_{0}
such that
{\bf x}\cdot{\bf y}\neq 0
. The matrix

\left[\begin{array}[]{c}G({\mbox{{\rm{Hull}}}}(\mathcal{C}))\\
{\bf{x}}\\
A_{0}\\
\end{array}\right]

is row equivalent to a matrix

\left[\begin{array}[]{c}G({\mbox{{\rm{Hull}}}}(\mathcal{C}))\\
{\bf{x}}\\
{\bf{y}}\\
B_{0}\end{array}\right]

where every row of
B_{0}
is orthogonal to
{\bf x}
. We construct this matrix by replacing each row
{\bf z}\neq{\bf y}
of
A_{0}
that is not orthogonal to
{\bf x}
with
{\bf z}+{\bf y}
. We consider the matrix

\tilde{A_{1}}=\left[\begin{array}[]{cc}{\bf{x}}&1\\
{\bf{y}}&1\\
B_{0}&{\bf{0}}\\
\end{array}\right].

By construction,
\operatorname{Hull}(\tilde{A_{1}})=\left<({\bf{x}}~1)\right>
. Hence the column
(1~1~{\bf{0}})^{T}
added to

A^{\prime}=\left[\begin{array}[]{c}{\bf{x}}\\
{\bf{y}}\\
B_{0}\\
\end{array}\right]

increases the dimension of the hull of
A^{\prime}
by 1. Next, let us consider the submatrix consisting of
{\bf{y}}
and
B_{0}
. We want to embed the code generated by this matrix into a self-orthogonal code of the shortest length by adding exactly
k-\ell-1
columns.

Let

B_{1}=\left[\begin{array}[]{cc}{\bf{y}}&1\\
B_{0}&{\bf{0}}\\
\end{array}\right].

It is clear that the dimension of
\left<B_{1}\right>
is
k-\ell-1
, which is odd. Furthermore,
\operatorname{Hull}(\left<B_{1}\right>)
is trivial because we explained above that
\operatorname{Hull}(\tilde{A_{1}})=\left<({\bf{x}}~1)\right>
. Theorem
III.7
now implies that a shortest SO embedding of
\left<B_{1}\right>
has length
n+1+(k-\ell-1)
.

Altogether, we need exactly
1+(k-\ell-1)=k-\ell
columns to embed
\mathcal{C}
into a self-orthogonal code of the shortest length.
∎

Lemma III.12
.

Let
\cal C
be a binary even
[n,k]
code satisfying
\mbox{$\cal C$}^{\perp}\subset\mbox{$\cal C$}
. Then
n
is even.

Proof.

As
\cal C
is an even code, we have
(1,1,\dots,1)\in\mbox{$\cal C$}^{\perp}\subset\mbox{$\cal C$}
. Since

, we see that

Theorems
III.10
and
III.11
together imply the following.

Corollary III.13
.

Let
\mathcal{C}
be a binary
[n,k]
code.

•

If
\cal C
is odd, then a shortest SO embedding of
\cal C
is self-dual if and only if
\mathcal{C}^{\perp}\subset\mathcal{C}
.

•

If
\cal C
is even, the a shortest SO embedding of
\cal C
is self-dual if and only if
\cal C
is itself self-dual.

Proof.

A shortest SO embedding of
\mathcal{C}
is self-dual if and only if it has length
2k
.

Consider the case when
\cal C
is odd. By Theorem
III.11
, the length of a shortest SO embedding of
\cal C
is
n+k-\ell
where
\ell=\dim({\rm{Hull}}(\mathcal{C}))
. We have
\ell\leq\dim(\mbox{$\cal C$}^{\perp})=n-k
with equality if and only if Hull
(\mbox{$\cal C$})=\mbox{$\cal C$}^{\perp}
, or equivalently
\mbox{$\cal C$}^{\perp}\subset\mbox{$\cal C$}
. Since
n+k-\ell\geq 2k
with equality if and only if
\ell=n-k
, we see that a shortest SO embedding of
\cal C
is self-dual if and only if
\mbox{$\cal C$}^{\perp}\subset\mbox{$\cal C$}
.

Next consider the case when
\cal C
is even. Theorem
III.10
implies that a shortest SO embedding
\tilde{\mbox{$\cal C$}}
of
\cal C
has length either
n+k-\ell
or
n+k-\ell+1
. Since
\ell\leq\dim(\mbox{$\cal C$}^{\perp})=n-k
, if
\tilde{\mbox{$\cal C$}}
is self-dual, then its length must be
n+k-\ell
, and
\ell=n-k
. This implies that
\mbox{$\cal C$}^{\perp}\subset\mbox{$\cal C$}
. By Lemma
III.12
,
n
is even, so
k-\ell
is even. Theorem
III.10
(ii) implies that if
k-\ell=2k-n\neq 0
, then the length of a shortest SO embedding of
\cal C
is
n+k-\ell+1>2k
, which is a contradiction. If
k-\ell=2k-n=0
, then since
\cal C
satisfies
\mbox{$\cal C$}^{\perp}\subset\mbox{$\cal C$}
, we see that
\cal C
is self-dual.

This completes the proof.
∎

The following two theorems show that a self-dual embedding and a shortest SO embedding of a linear code
\cal C
has a generator matrix of the form presented in the proof of Lemma
III.2
(ii).

Theorem III.14
.

Let
\mathcal{C}
be a binary
[n,k,d]
code with
\ell=\dim(\rm{Hull}(\mathcal{C}))
. Consider a generator matrix
G(\mathcal{C})
of
\cal C
of the form

G(\mathcal{C})=\begin{bmatrix}G(\textup{Hull}(\mathcal{C}))\\
A\end{bmatrix}.

Let
\tilde{\mathcal{C}}
be a SO embedding of
\mathcal{C}
that is self-dual and suppose that

G^{\prime}=\begin{bmatrix}G(\textup{Hull}(\mathcal{C}))&B_{H}\\
A&B_{A}\end{bmatrix}

is a generator matrix for for
\tilde{\mbox{$\cal C$}}
. Then
B_{H}=\mathcal{O}
.

Proof.

Let
H=[G(\mbox{Hull}(\mathcal{C}))~|~\mathcal{O}]
.
Then we have

H(G^{\prime})^{T}=[G(\mbox{Hull}(\mathcal{C}))G(\mbox{Hull}(\mathcal{C}))^{T}~|~G(\mbox{Hull}(\mathcal{C}))A^{T}]=\mathcal{O}.

This implies
\langle H\rangle\subseteq\tilde{\mathcal{C}}^{\perp}=\tilde{\mathcal{C}}
. The
2^{k}
sums of rows of
G^{\prime}
must be distinct in their first
n
coordinates. This forces every row of
B_{H}
to be
0
, since otherwise we would have two different elements of
\tilde{\mbox{$\cal C$}}
that agreed in their first
n
positions.

∎

Theorem III.15
.

Let
\mathcal{C}
be a binary
[n,k,d]
code with
\ell=\dim(\operatorname{Hull}(\mathcal{C}))
. Choose a generator matrix of the form

G(\mathcal{C})=\begin{bmatrix}G(\textup{Hull}(\mathcal{C}))\\
A\end{bmatrix}.

Let
\tilde{\mbox{$\cal C$}}
be a shortest SO embedding of
\cal C
and suppose
\tilde{\mbox{$\cal C$}}
has a generator matrix of the form

G^{\prime}=\begin{bmatrix}G(\textup{Hull}(\mathcal{C}))&B_{H}\\
A&B_{A}\end{bmatrix}.

Then
B_{H}=\mathcal{O}
.

Proof.

Since
\tilde{C}
is self-orthogonal, we see that

\displaystyle G^{\prime}G^{\prime T}

\displaystyle=\begin{bmatrix}G(\mbox{Hull}(\mathcal{C}))G(\mbox{Hull}(\mathcal{C}))^{T}+B_{H}B_{H}^{T}&G(\mbox{Hull}(\mathcal{C}))A^{T}+B_{H}B_{A}^{T}\\
A(G(\mbox{Hull}(\mathcal{C}))^{T})+B_{A}B_{H}^{T}&AA^{T}+B_{A}B_{A}^{T}\end{bmatrix}

\displaystyle=\begin{bmatrix}B_{H}B_{H}^{T}&B_{H}B_{A}^{T}\\
B_{A}B_{H}^{T}&AA^{T}+B_{A}B_{A}^{T}\end{bmatrix}=\mathcal{O}.

Consider the
[n,k-\ell]
code
\left<A\right>
. Proposition
III.5
implies that

0=\dim(\operatorname{Hull}(\langle A\rangle))=k-\ell-\textup{rank}(AA^{T}),

which shows that
\operatorname{rank}(AA^{T})=k-\ell
and so
\det(AA^{T})=1
.

Theorem
III.7
implies that a shortest SO embedding of
\tilde{\mbox{$\cal C$}}
has length
n+k-\ell
or
n+k-\ell+1
. We consider each case.

Suppose that the length of
\tilde{\mbox{$\cal C$}}
is
n+k-\ell
. This means that
B_{A}
is a square matrix. Since
AA^{T}+B_{A}B_{A}^{T}=\mathcal{O}
, we have

1=\det(AA^{T})=\det(B_{A}B_{A}^{T})=\det(B_{A})^{2}=\det(B_{A}).

So,
\operatorname{rank}(B_{A})=k-\ell
. Since
B_{H}B_{A}^{T}=\mathcal{O}
and
B_{A}
is invertible, we conclude that
B_{H}=\mathcal{O}
.

Next, suppose that the length of
\tilde{\mbox{$\cal C$}}
is
n+k-\ell+1
, that is,
B_{A}
is a
(k-\ell)\times(k-\ell+1)
matrix. Since
\det(B_{A}B_{A}^{T})=1
, we have

k-\ell=\textup{rank}(B_{A}B_{A}^{T})\leq\textup{rank}(B_{A})\leq k-\ell,

which gives
\textup{rank}(B_{A})=k-\ell
. Then we have
\dim(\left<B_{A}\right>^{\perp})=1
.

Suppose
\mathbf{v}\in\langle B_{A}\rangle^{\perp}
is nonzero and
\mathbf{v}\cdot\mathbf{v}=0
. Let
B^{\prime}
be the
(k-\ell+1)\times(k-\ell+1)
matrix obtained by concatenating
\mathbf{v}
to
B_{A}
, that is,

B^{\prime}=\begin{bmatrix}B_{A}\\
\mathbf{v}\end{bmatrix}.

Then we have

B^{\prime}(B^{\prime})^{T}=\begin{bmatrix}B_{A}\\
\mathbf{v}\end{bmatrix}\begin{bmatrix}B_{A}^{T}&\mathbf{v}\end{bmatrix}=\begin{bmatrix}B_{A}B_{A}^{T}&\mathbf{0}\\
\mathbf{0}&0\end{bmatrix}.

This gives
0=\det(B^{\prime}(B^{\prime})^{T})=\det(B^{\prime})
. Since
\operatorname{rank}(B_{A})=k-\ell
we see that
\mathbf{v}
is in the row space of
B_{A}
, that is,
\mathbf{v}\in\left<B_{A}\right>
. So, we have
\mathbf{v}\in\operatorname{Hull}(\langle B_{A}\rangle^{\perp})
. Proposition
III.5
implies that

\dim(\operatorname{Hull}(\langle B_{A}\rangle^{\perp}))=k-\ell-\textup{rank}(B_{A}B_{A}^{T})=0,

so this is a contradiction. We conclude that any nonzero vector orthogonal to every row of
B_{A}
must have odd weight. We conclude that every row of
B_{H}
must be equal to
0
.
∎

In what follows, we consider self-orthogonal embeddings of binary Reed-Muller codes
\mathcal{R}(r,m)

.

. Suppose that

IV-B

Embedding Hamming codes using orthogonal matrices

In this section, use orthogonal matrices to provide an algorithm to determine all of the shortest SO embeddings of the binary
[2^{r}-1,2^{r}-1-r,3]

\mathcal{H}_{r}

Then

Since simplex codes are self-orthogonal, we have

\end{array}\right]

(1)

\displaystyle A^{T}A=I_{r},\ \ \ A^{T}B=\mathcal{O},\ \ \ B^{T}B=I_{k-r}.

VI
Conclusion

In this paper, we have obtained the minimal length of a self-orthogonal embedding of a binary linear code
\cal C
, or equivalently, the minimum number of columns that must be added to a generator matrix of
\cal C
to produce a generated matrix for a self-orthogonal code. Let
\cal C
be an
[n,k]
code with
\dim(\operatorname{Hull}(\mathcal{C}))=\ell
. If
k-\ell
is odd, then a shortest SO embedding of
\cal C
has length
n+k-\ell
. If
k-\ell
is even, then a shortest SO embedding of
\cal C
has length
n+k-\ell
when
\cal C
is odd, and has length
n+k-\ell+1
when
\cal C
is even. We have shown that a shortest SO embedding of a Reed-Muller code
\mathcal{R}(r,m)
has length
2k+1
columns are required to embed it into a shortest self-orthogonal code, and that a shortest SO embedding of a binary Hamming code
\mathcal{H}_{r}
is a self-dual code of length
2k
. We have determined all of the shortest self-dual embedding Hamming code
\mathcal{H}_{4}
up to equivalence, and have found that one of those is equivalent to the shortened Golay code. Using shortest SO embeddings, we have obtained many inequivalent optimal self-orthogonal codes of dimension
7
and
8
for some lengths. Four of these codes with dimension
8
are codes with new parameters.

One of the main problems in coding theory is to find the optimal self-orthogonal or self-dual codes with given parameters. Determining the possible minimum distances of the shortest SO embedding of a linear code, or constructing an algorithm to produce a shortest SO embedding of a code with largest possible minimum distance, would be interesting topics for further study.
