. Introduction

The Fourier restriction problem to the unit sphere
\mathbb{S}^{d-1}\subset\mathbb{R}^{d}
aims at finding exactly those triples
(p,q,d)
for which the inequality

(1.1)

\|\widehat{f}\|_{L^{q}(\mathbb{S}^{d-1})}\leq{{\bf R}_{\mathbb{S}^{d-1}}}(p\to q)\|f\|_{L^{p}(\mathbb{R}^{d})}

holds, where
{\bf R}_{\mathbb{S}^{d-1}}(p\to q):=\sup_{\|f\|_{p}=1}\|\widehat{f}\|_{L^{q}(\mathbb{S}^{d-1})}
denotes the best constant. The Fourier transform is given by

(1.2)

\widehat{f}(\xi):=\int_{\mathbb{R}^{d}}f(x)e^{-2\pi ix\cdot\xi}\,\,{\rm d}x.

Stein’s restriction conjecture
[
26

if and only if

This has been established when

Inequality (

\displaystyle{\bf R}_{\mathbb{S}^{d-1}}(p\to q;\textup{rad})

\displaystyle:=\sup_{\|f\|_{p}=1,f\text{ radial}}\|\widehat{f}\|_{L^{q}(\mathbb{S}^{d-1})}.

Proposition 3
.

Given
\nu\geq 2

Questions about dimension-free estimates for various classes of operators constitute an important research theme in harmonic analysis. Even though the topic has been investigated for several decades, many questions remain open. The main classes of operators which have been studied in this context include Riesz transforms and Hardy–Littlewood maximal operators. Given

The inverse of the Fourier transform

given by (

\|\widehat{f}\|_{2}=\|f^{\vee}\|_{2}=\|f\|_{2}

Lemma 5

(2.7)

I_{3}\leq|p(\alpha-\tfrac{1}{2})+1|^{-1}\times\left\{\begin{array}[]{ll}\nu^{p(\alpha-\frac{1}{2})+1},&1\leq p<4;\\

\displaystyle{\bf R}_{\mathbb{S}^{d-1}}(p\to q)\leq\sigma(\mathbb{S}^{d-1})^{\frac{1}{q}-\frac{1}{q(p)}}{\bf R}_{\mathbb{S}^{d-1}}(p\to q(p))\leq\sigma(\mathbb{S}^{d-1})^{\frac{1}{q}-\frac{1}{q(p)}}(C\sqrt{d})^{1-\theta}\sigma(\mathbb{S}^{d-1})^{\frac{\theta}{d+1}}

(4.8)

\displaystyle=\sigma(\mathbb{S}^{d-1})^{\frac{1}{p}+\frac{1}{q}-1-\frac{1}{d+1}}\sigma(\mathbb{S}^{d-1})^{\frac{2}{d-1}(\frac{1}{p}-\frac{1}{p_{\bullet}})}(C\sqrt{d})^{1-2\frac{d+1}{d-1}(\frac{1}{p}-\frac{1}{p_{\bullet}})}.

To pass to the last line, we used identities (
4.5
) and (
4.7
). Note that in (
4.8
) both exponents on powers of
\sigma(\mathbb{S}^{d-1})
are positive in light of (
4.3
), whereas the exponent on
C\sqrt{d}
is nonnegative since
p\geq 1
, and strictly positive if
p>1
.
From formula (
1.15
) and Lemma
4
, it follows that the right-hand side of (
4.8
) tends to 0 as
d\to\infty
, as long as
\frac{1}{p}+\frac{1}{q}>1
.

4.2.
Proof of (
1.6
)

As usual, let
\nu=\frac{d}{2}-1.
By (
1.15
) and Lemma
4
, we have

(4.9)

\sigma(\mathbb{S}^{d-1})\simeq(\pi e)^{\nu}\nu^{-(\nu+\frac{1}{2})},\text{ as }d\to\infty.

Let
\alpha:=\frac{d}{2}-\frac{d-1}{p},
and note that
\alpha=\nu(1-\frac{2}{p})+\frac{1}{p^{\prime}}.
For large enough
d
, we then have

(\nu+\alpha)p^{\prime}+1=d>1,\text{ and }

(4.10)

p^{\prime}\left(\alpha-\tfrac{1}{2}\right)+1=p^{\prime}(d-1)\left(\tfrac{1}{2}-\tfrac{1}{p}\right)+1<-1.

Thus estimate (
1.11
) applied with
\alpha
defined as above, and
p^{\prime}\geq 2
in place of
p
, yields

(4.11)

\left(\int_{0}^{\infty}\big|J_{\nu}(r)\,r^{\alpha}\big|^{p^{\prime}}\,\,{\rm d}r\right)^{\frac{1}{p^{\prime}}}\lesssim_{p^{\prime}}2^{-\alpha}\nu^{\alpha+\frac{1}{2}}\leq 2^{-\nu(1-\frac{2}{p})+\frac{1}{p^{\prime}}}\nu^{\nu(1-\frac{2}{p})+1}

Recalling (
3.15
) and using (
4.9
)–(
4.11
), we then obtain

{\bf R}_{\mathbb{S}^{d-1}}(p\to q;\textup{rad})\lesssim(\pi e)^{\nu(\frac{1}{q}-\frac{1}{p})}\nu^{-(\nu+\frac{1}{2})(\frac{1}{q}-\frac{1}{p})}2^{-\nu(1-\frac{2}{p})+\frac{1}{p^{\prime}}}\nu^{\nu(1-\frac{2}{p})+1}.

Now,
q=p^{\prime}
implies
\frac{1}{q}-\frac{1}{p}=1-\frac{2}{p}.
Thus we may continue with

{\bf R}_{\mathbb{S}^{d-1}}(p\to q;\textup{rad})\lesssim\nu^{2}\left(\frac{\pi e}{2}\right)^{\nu(1-\frac{2}{p})},

which tends to
0
, as
d\to\infty
, because
1\leq p<2
and
\pi e>2.

4.3.
Proof of (
1.7
)

Let
\nu,\alpha
be defined as in §
4.2
. Again (
4.10
) holds for all sufficiently large
d,
and so the lower bound (
1.13
) from Proposition
3
implies

(4.12)

\left(\int_{0}^{\infty}\big|J_{\nu}(r)\,r^{\alpha}\big|^{p^{\prime}}\,\,{\rm d}r\right)^{\frac{1}{p^{\prime}}}\gtrsim 30^{\alpha}\nu^{\alpha-\frac{1}{2}}\geq 30^{\nu(1-\frac{2}{p})}\nu^{\nu(1-\frac{2}{p})-\frac{1}{2}}

Now, using (
3.15
) together with (
4.9
) and (
4.12
) we obtain

{\bf R}_{\mathbb{S}^{d-1}}(p\to q;\textup{rad})\gtrsim(\pi e)^{\nu(\frac{1}{q}-\frac{1}{p})}\nu^{-(\nu+\frac{1}{2})(\frac{1}{q}-\frac{1}{p})}30^{\nu(1-\frac{2}{p})}\nu^{\nu(1-\frac{2}{p})-\frac{1}{2}}.

Since
-1<\frac{1}{q}-\frac{1}{p}<1
and
1-\frac{2}{p}-(\frac{1}{q}-\frac{1}{p})=1-\frac{1}{p}-\frac{1}{q}
, we continue with

{\bf R}_{\mathbb{S}^{d-1}}(p\to q;\textup{rad})\gtrsim\nu^{-1}(30\pi e)^{-\nu}\nu^{\nu(1-\frac{1}{p}-\frac{1}{q})}.

Finally, noting that
q>p^{\prime}
implies
1-\frac{1}{p}-\frac{1}{q}>0
, we obtain
{\bf R}_{\mathbb{S}^{d-1}}(p\to q;\textup{rad})\to\infty
as
d\to\infty.

This concludes the proof of Theorem
1
.
