You (Almost) Can’t Beat Brute Force for 3 3 -Matroid Intersection
Ilan Doron-Arad, Ariel Kulik, Hadas Shachnai

Abstract
The ℓ \ell -matroid intersection ( ℓ \ell -MI) problem asks if ℓ \ell given matroids share a common basis. Already for ℓ = 3 \ell=3 , notable canonical NP-complete special cases are 3 3 -Dimensional Matching and Hamiltonian Path on directed graphs. However, while these problems admit exponential-time algorithms that improve the simple brute force significantly (e.g., Eiben-Koana-Wahlström (SODA’24)), the fastest known algorithm for 3 3 -MI on general matroids is exactly brute force with runtime 2 n / poly ​ ( n ) 2^{n}/\textnormal{poly}(n) , where n n is the number of elements. Our main result shows that, in fact, brute force cannot be significantly improved, by ruling out an algorithm for ℓ \ell -MI with runtime o ⁡ ( 2 n − 5 ⋅ n 1 ℓ − 1 ⋅ log ⁡ ( n ) ) o\left(2^{n-5\cdot n^{\frac{1}{\ell-1}}\cdot\log(n)}\right) , for any fixed ℓ ≥ 3 \ell\geq 3 . For 3 3 -MI, this gives a lower bound of o ⁡ ( 2 n − 5 ⋅ n ⋅ log ⁡ ( n ) ) o\left(2^{n-5\cdot\sqrt{n}\cdot\log(n)}\right) . Our negative result raises the following natural questions: (i) Is there an algorithm for 3 3 -MI with runtime strictly better than brute force? (ii) Can we separate the parameterized complexity of 3 3 -MI from the important special case on linear matroids (parameterized by the rank of the matroids k k )? In particular, can a lower bound match the existing c k 2 ⋅ poly ​ ( n ) c^{k^{2}}\cdot\textnormal{poly}(n) algorithm of Huang-Ward (SIDMA’23) for general ℓ \ell -MI parameterized by the rank? We make progress towards obtaining affirmative answers to the above questions. In particular, we present (i) an algorithm which solves ℓ \ell -MI faster than brute force in time 2 n − Ω ⁡ ( log 2 ⁡ ( n ) ) 2^{n-\Omega\left(\log^{2}(n)\right)} for any ℓ ≥ 3 \ell\geq 3 , and (ii) a parameterized running time lower bound of 2 ( ℓ − 2 ) ⋅ k ⋅ log ⁡ k ⋅ poly ​ ( n ) 2^{(\ell-2)\cdot k\cdot\log k}\cdot\textnormal{poly}(n) for ℓ \ell -MI, for any ℓ ≥ 3 \ell\geq 3 . We obtain these results by generalizing the Monotone Local Search technique of Fomin-Gaspers-Lokshtanov-Saurabh (J. ACM’19). Broadly speaking, given a subset problem , our generalization transforms any algorithm parameterized by solution size, with runtime of the form f ​ ( k ) ⋅ poly ​ ( n ) f(k)\cdot\textnormal{poly}(n) , into an exponential-time algorithm with runtime depending on f f . This implies that any f ​ ( k ) ⋅ poly ​ ( n ) f(k)\cdot\textnormal{poly}(n) time parameterized algorithm for a subset problem yields a 2 n − ω ⁡ ( log ⁡ n ) 2^{n-\omega(\log n)} time algorithm beating brute force, which may be of independent interest.

Relation to Parameterized Complexity

Theorem

gives a nearly tight lower bound for

This raises the following natural questions.

(i)

Is there an algorithm for

More specifically,

(ii)

We answer both questions affirmatively, using a generalization of the

Monotone Local Search tackles a wide range of problems which can be cast as

. In such problems the input encodes a set system
(E,{\mathcal{F}})

E
is an arbitrary ground set, and
{\mathcal{F}}\subseteq 2^{E}
is a collection of subsets of the ground set.
It is assumed that the ground set
E
can be computed from the input in polynomial time, and it can be determined if
S\in{\mathcal{F}}
for every
S\subseteq E
in polynomial time.
The objective is to decide if
{\mathcal{F}}=\emptyset
. Numerous problems, including Vertex Cover, Feedback Vertex Set and Multicut on Trees, can be cast as implicit set systems (see
[
FGLS19
]
for additional problems).

For example, the input for

is a graph
G
and a number
k\in\mathbb{N}

(E,{\mathcal{F}})
, where
E
is the set of
vertices
of
G
and
{\mathcal{F}}
is the set of all the
vertex covers
of

of size
k

(u,v)
of
G

u\in S
or

has a vertex cover of size

if and only if
{\mathcal{F}}\neq\emptyset

E
can be easily computed given the graph
G

S\in{\mathcal{F}}
in polynomial time. That is, Vertex Cover can be cast as an implicit set system.

Fomin et al.
[

]
show how to convert an

for an implicit set system

into an exponential time algorithm for

An extension algorithm of time

instance

and a number

The algorithm either returns a set

is the set system associated with the instance

Furthermore, the algorithm runs in time

The main result of

is the size of the ground set associated with the instance.
For example, this means that the parameterized

The technique has been extended to approximation algorithms

,
EKM+24

A

Matroids Overview

We give below a brief overview of matroid classes and fundamental problems related to our study.

Matroid Classes

Perhaps the simplest class is the one of
uniform
matroids. In such matroids, the independent sets
{\mathcal{I}}
are all subsets of the ground set
E
containing at most
k\in{\mathbb{N}}
elements. These matroids are often used to model a

, commonly studied in various algorithmic settings (e.g.,
[
NW81
,
CKPP00
]

To model the more general constraints of spanning trees, one needs

[

,
Bir35
]

E
is the set of edges of an undirected graph
G=(V,E)

{\mathcal{I}}
consists of all acyclic subsets of edges.

In this paper we make an extensive use of
partition

E_{1},\ldots,E_{t}
of the ground set
E
and integer bounds
b_{1},\ldots,b_{t}\in{\mathbb{N}}
, the set (of independent sets)
{\mathcal{I}}
contains subsets of
E
consisting of at most
b_{i}
elements in
E_{i}
for all
i\in\{1,\ldots,t\}
. Finally,
linear
matroids
[
Ste13
]
generalize all of the above examples: the ground set
E
represents columns of a matrix, and
{\mathcal{I}}
represents all subsets of linearly independent columns.

We note the existence of
non-linear
matroids. One
example is the Vámos matroid
[
V6́8
]
. In fact, asymptotically, the number of linear matroids
-
compared to the number of non-linear matroids
-
is negligible
[
Nel16
]
. Our main results are based on
paving
matroids;
this is the family of all matroids
(E,{\mathcal{I}})
with rank

S\subseteq E
with cardinality

belongs to
{\mathcal{I}}
.
A well-known conjecture of
[

]
asserts that asymptotically almost all matroids belong to the class of paving matroids.

4

Technically, we take the

The bound of each set in the partition for both matroids is

defined over the underlying undirected graph of

While we focus in this paper on the decision version of

1.3
Our Techniques

Our lower bound for
\ell
-MI combines a paving matroid (see
Section

1.2
) with
d=\ell-1
partition matroids. At a high level, we consider a
d
-dimensional grid as the common ground set of the matroids. The
d
partition matroids, one for each dimension of the
d
-dimensional grid, enforce the solution to take a specified number of elements
L_{i,j}
, having a specific value
i
in the
j
-th entry of the grid. This idea is formalized in detail in later sections.

The additional paving matroid is designed to
hide
a certain collection of subsets
{\mathcal{G}}
of the grid. Specifically, the bases of this matroid,
which are also common bases of the partition matroids, belong to
{\mathcal{G}}
.
Together with the partition matroids’ constraints, finding a common basis for the
\ell
matroids requires to decide if
{\mathcal{G}}\neq\emptyset
.
In the oracle model, it is a computationally challenging task to decide if
{\mathcal{G}}\neq\emptyset
. Thus, essentially, to accomplish this task, an algorithm for
\ell
-MI has to enumerate over all common bases of the
\ell-1
partition matroids.

The above gives the intuition behind the reduction in
Theorem

1.1
.
Notably, the
d
-dimensional grid ground set (with
d\geq 2
) plays a crucial role in the construction of the paving matroid. This structure is key to achieving significantly stronger query lower bounds for
3
-MI, compared to the best possible lower bounds known for
2
-matroid intersection
[
BMNT23
]
.
Hiding a property in the bases of a paving matroid has been used in previous works on matroid problems
[
JK82
,
Lov80
,
Sot11
,
BS21
,
DAKS24
,
HIM+24
]
. Nonetheless, these constructions alone are insufficient to obtain a
2^{n-o(n)}
lower bound for
\ell
-MI.
In addition, in contrast to the lower bounds derived for a single matroid
[
JK82
,
KUW85
]
, a matroid and a matching constraint
[
Lov80
,
Sot11
]
, or a matroid and a linear constraint
[
DAKS24
]
, our construction focuses on an
arbitrary
number
\ell\geq 3
of matroids and our bounds become stronger as
\ell
increases.

Monotone Local Search
[
FGLS19
]
suggests a novel approach for converting an extension algorithm to an exponential time algorithm for an arbitrary implicit set system.
Recall that in implicit set systems the input instance encodes a set system
(E,{\mathcal{F}})
, and the objective is to determine if
{\mathcal{F}}\neq\emptyset
.
If
{\mathcal{F}}\neq\emptyset
then one can find
S\in{\mathcal{F}}
by guessing
k=|S|
, sampling a random set
X\subseteq{\mathcal{F}}
of size
t\leq k
using a uniform distribution, and checking if
X
can be extended to a solution for the problem using the
extension algorithm
. If
X\subseteq S
then the process terminates with ‘success’, and the algorithm finds a set in
{\mathcal{F}}
. The above procedure has to be repeated sufficiently many times to ensure a constant success probability.

The running time of monotone local search hinges on the value of
t
. If we select
t=k
, then the algorithm basically guesses a set with hope it is in
{\mathcal{F}}
. This leads to a running time similar to that of brute force due to a large number of required repetitions. On the other hand, decreasing the value of
t
reduces the number of required repetitions, while increasing the running time of the extension algorithm used in each repetition. A main observation in the analysis of monotone local search is that the optimal value of
t
is bounded away from
k
, implying that the resulting running time is better than brute force. This property was previously known for the case in which the running time of the extension algorithm was of the form
f(k)=c^{k}
times a polynomial factor
[
FGLS19
]
. We show that, interestingly,
the same property holds for arbitrary
f
.

is the
encoding
of the instance and
\textnormal{{oracle}}:2^{E}\times\mathbb{N}\rightarrow\{0,1\}
is the
oracle
of the instance.
The instance
(E,{\mathcal{F}},B,\textnormal{{oracle}})
is a “yes” instance if
{\mathcal{F}}\neq\emptyset
and is a “no” instance if
{\mathcal{F}}=\emptyset
.
An algorithm for
{\mathcal{P}}
is given the encoding
B
as input and runs in the computational model of an oracle Turing machine in which the oracle is
oracle
.
The objective of the algorithm is to determine if
{\mathcal{F}}\neq\emptyset
, while the set
{\mathcal{F}}
is only implicitly given to the algorithm through the encoding
B
and the oracle
oracle
.

We say that an implicit set problem
{\mathcal{P}}
is
polynomial time computable
if the following two conditions hold:

•

There is an algorithm in an oracle Turing machine model
such that for every
(E,{\mathcal{F}},B,\textnormal{{oracle}})\in{\mathcal{P}}
, given
B
as the input and
oracle
as the oracle, computes the set
E
in time
\textnormal{poly}(|B|)
.

•

There is an algorithm in an oracle Turing machine model such that for every
(E,{\mathcal{F}},B,\textnormal{{oracle}})\in{\mathcal{P}}
, given
B
and
S\subseteq E
as the input and
oracle
as the oracle, decides whether
S\in{\mathcal{F}}
in time
\textnormal{poly}(|B|)
.

For simplicity, we assume that all the implicit set problems considered in this section are polynomial time computable.

The
\ell
-matroid intersection problem can be easily cast as an implicit set problem
{\mathcal{P}}_{\ell\textnormal{-MI}}
.
For every
\ell
-matroid intersection instance
(E,{\mathcal{I}}_{1},\ldots,{\mathcal{I}}_{2})
we add to
{\mathcal{P}}_{\ell-\textnormal{MI}}
the instance
(E,{\mathcal{F}},B,\textnormal{{oracle}})
where
{\mathcal{F}}=\textnormal{bases}({\mathcal{I}}_{1},\ldots,{\mathcal{I}}_{\ell})
, the encoding
B
is an arbitrary encoding of the set
E
and
\textnormal{{oracle}}(S,j)=1
if
S\in{\mathcal{I}}_{j}
and
\textnormal{{oracle}}(S,j)=0
otherwise. That is,
oracle
is a unified representation of the membership oracles for
{\mathcal{I}}_{1},\ldots,{\mathcal{I}}_{\ell}
. We assume the encoding
B
satisfies
|E|\leq|B|\leq|E|^{2}
. It can be easily verified that
{\mathcal{P}}_{\ell\textnormal{-MI}}
is also polynomial time computable. The set
E
can be easily computed in polynomial time as it is explicitly encoded in
B
, and given
S\subseteq E
it can be determined whether
S\in\textnormal{bases}({\mathcal{I}}_{1},\ldots,{\mathcal{I}}_{\ell})
by verifying
S\in{\mathcal{I}}_{j}
and is maximal independent set for every
j\in[\ell]
via queries to the oracle.

The definition of an implicit set problem given above is a natural generalization of the
implicit set systems
defined in
[
FGLS19
]
.
The difference is that in implicit set systems the instance does not contain an oracle.
As the main focus of this paper is the oracle
\ell
-MI problem, this extension is required.
We further note that all the result in
[
FGLS19
]
also hold for implicit set problems which involve oracles.

The purpose of Monotone Local Search is to convert an extension algorithm for
{\mathcal{P}}
into an exponential time algorithm for
{\mathcal{P}}
. For many problems, such as
\ell
-matroid intersections, Vertex Cover and Feedback Vertex Set, such algorithms can be easily derived from parameterized algorithms. A list of classic problems which can be cast as implicit set problems and for which an extension algorithm can be derived from a parameterized algorithm can be found in

]
.

The definition of extension algorithms relies on the notion of

Definition 5.1

(
\ell
-extension)
.

Let
{\mathcal{P}}
be an implicit set problem and
(E,{\mathcal{F}},B,\textnormal{{oracle}})\in{\mathcal{P}}
be an instance of the problem. Also, let

,

and
\ell\in\mathbb{N}
. We say that

is an
\ell
-extension of

if

and
{\left|S\right|}=\ell
.

For an implicit set problem
{\mathcal{P}}
and a function
g:\mathbb{N}\rightarrow\mathbb{N}
, a
random extension algorithm
for
{\mathcal{P}}
of time
g
is an algorithm in which runs in an oracle Turing machine model.
The input for the algorithm is
B\in\{0,1\}^{*}
, the encoding of an instance
(E,{\mathcal{F}},B,\textnormal{{oracle}})\in P
, a set
X\subseteq{\mathcal{F}}
and
\ell\in\mathbb{N}
. Furthermore, the oracle of the Turing machine is
oracle
. The algorithm either returns
S\subseteq E
or a special symbol

and satisfies the following properties.

•

If
X
has an
\ell
-extension then the algorithm returns an
\ell
-extension of
X
with probability at least
1/2
.

•

If the algorithm returns a set

then
S
is an
\ell
-extension of
S
.

Furthermore, the algorithm runs in time
g(\ell)\cdot\textnormal{poly}(|B|)
.

Indeed, we can show that a parameterized algorithm for oracle
\ell
-MI
which runs in time

, implies an extension algorithm for

of time

(E\setminus X,{\mathcal{I}}_{1}/X,\ldots,{\mathcal{I}}_{\ell}/X)
following some trivial checks.

-MI which is faster than brute force.

Our generalization of monotone local search needs to be able to optimize its use of the extension oracle. This is done by solving a discrete optimization problem over the function
g
, the running time of the extension algorithm. We therefore require
g
to be a function for which the optimization problem can be solved efficiently, as stated by the following definition.

Definition 5.4
.

We say a function
g
is optimizable if for every
n\in\mathbb{N}
and
0\leq k\leq n
the value

\argmin_{0\leq t\leq k}\frac{\binom{n}{t}}{\binom{k}{t}}\cdot g(k-t)

can be computed in polynomial time in
n
.

In case
g(n)
can be computed in polynomial time in
n
then
g
is trivially optimizable as
\argmin_{0\leq t\leq k}\frac{\binom{n}{t}}{\binom{k}{t}}\cdot g(k-t)
can be computed in polynomial time by iterating over all possible values of
t
. In other cases, such as
g(n)=2^{2^{n}}
the value of
g
cannot be represented using polynomial number of bits (in standard representation), and hence a slight sophistication is required in order to show that
g
is still optimizable.

Our extension for monotone local search is the following.

Theorem 5.5

(Monotone Local Search)
.

Let
{\mathcal{P}}
be a implicit set problem which has a random extension algorithm of time

such that

is optimizable and

{\mathcal{P}}
which runs in time

where

is the ground set of the instance,

is the encoding of the instance, and

\Phi_{g}(n)=\max\left\{\ell\cdot\log\left(\frac{n}{4\cdot\ell}\right)-\log g(\ell)~\big|~0\leq\ell\leq n/4,~\ell\in\mathbb{N}\right\}.

(7)

5.2
Monotone Local Search: The Algorithm

The algorithm we use to prove
Theorem

5.5
is nearly identical to the
Monotone Local Search
algorithm of Fomin, Gaspers, Lokshtanov and Saurabh
[

]
. The key distinction is in the analysis which considers different running times for the extension algorithm.
Let
{\mathcal{P}}
be an implicit set problem. We assume
{\mathcal{P}}
is fixed throughout the section. Our goal is to design an algorithm for
{\mathcal{P}}
for which there is a random extension algorithm
Ext
of time
g
, where the function
g
satisfies the conditions in
Theorem

5.5
. We further assume
Ext
and
g
are fixed throughout the section.

Recall that an instance of
{\mathcal{P}}
is of the form
(E,{\mathcal{F}},B,\textnormal{{oracle}})
where the encoding
B
is given to the algorithm as input and the algorithm can access
oracle
as an oracle.

Consider the case in which
{\mathcal{F}}\neq\emptyset
, then there is
S^{*}\in{\mathcal{F}}
. Let that
{\left|S^{*}\right|}=k
. The algorithm guesses
k
by iterating over all values from
0
to
|E|
. Now, if one samples a uniformly random set
X
of
[n]
of size
t
, then with probability
\frac{\binom{k}{t}}{\binom{n}{t}}
it holds that
X\subseteq S^{*}
(there are
\binom{n}{t}
subsets of
[n]
of size
t
, and
\binom{k}{t}
of these subsets only contain items in
S^{*}
).
Furthermore, if
X\subseteq S^{*}
then
\textnormal{{Ext}}(B,X,k-t)
returns a set
S
such that
X\cup S\in{\mathcal{F}}
with probability at least
\frac{1}{2}
.
Therefore, if the algorithm randomly samples a set
X
of size
t
and invokes
\textnormal{{Ext}}(B,X,k-t)
for
2\cdot\frac{\binom{n}{t}}{\binom{k}{t}}
many times, with probability at least
\frac{1}{2}
one of the calls for
Ext
returns a
(k-t)
-extension (and not the symbol
\perp
). In such a case, the algorithm can safely conclude that
{\mathcal{F}}\neq\emptyset
. Otherwise, the algorithm may return that
{\mathcal{F}}=\emptyset
, and be right with high probability.
The value of
t
is simply selected so the overall running time is minimized.

The pseudo-code of the algorithm is given in

2
. The algorithm finds the optimal value for

and initiates multiple calls to the

.

for

.

of size

. We can therefore conclude that the algorithm returns “yes” with probability at least

.

Overall, we showed that

is indeed a randomized algorithm for

.
∎

Our next goal is to prove

Lemma 5.16
.

Proof.

Let
(E,{\mathcal{F}},B,\textnormal{{oracle}})

and
consider an execution of

2
with the input

and the oracle

. Also, let

.
We first bound the running time of each of the iterations of the loop in

2
of

of

\displaystyle 2\cdot\frac{\binom{n}{t}}{\binom{k}{t}}\cdot g(k-t)\cdot\textnormal{poly}(|B|)

\displaystyle=\textnormal{poly}(|B|)\cdot\min_{0\leq t^{\prime}\leq k}\frac{\binom{n}{t^{\prime}}}{\binom{k}{t^{\prime}}}\cdot g(k-t^{\prime}),

in

We use standard estimators of binomial coefficients to upper bound
\Psi_{g}
.
Define

\mathcal{H}\left(x\right)=-x\cdot\log(x)-(1-x)\cdot\log(1-x)

as the binary entropy function.
We use the following entropy based estimation for binomial coefficients (Example 11.1.3 in
[
CT06
]
):

\frac{1}{n+1}\cdot 2^{n\cdot\mathcal{H}\left(\frac{k}{n}\right)}\,\leq\,\binom{n}{k}\,\leq\,2^{n\cdot\mathcal{H}\left(\frac{k}{n}\right)}.

(10)

We also use the following inequality for the entropy function:

\frac{\mathcal{H}\left(x\right)}{x}=\frac{-x\cdot\log(x)-(1-x)\cdot\log(1-x)}{x}=-\log x-\frac{(1-x)\cdot\log(1-x)}{x}\geq-\log(x).

(11)

The last equality follows from
(1-x)\cdot\log(1-x)<0
.

Lemma 5.17
.

For every
n\in\mathbb{N}
it holds that

\Psi_{g}(n)\leq 2^{n-\Phi_{g}(n)+\log(n)}.

Proof.

We can write
\Psi_{g}
as the maximum between two functions. Define,

A(n)=\max_{0\leq k<\frac{1}{4}\cdot n\textnormal{ or }\frac{3}{4}\cdot n<k\leq n}\,\min_{0\leq t\leq k}\frac{\binom{n}{t}}{\binom{k}{t}}\cdot g(k-t)

and

B(n)=\max_{\frac{1}{4}\cdot n\leq k\leq\frac{3}{4}\cdot n}\,\min_{0\leq t\leq k}\frac{\binom{n}{t}}{\binom{k}{t}}\cdot g(k-t).

(12)

The function
A
considers values of
k
which are far from
\frac{1}{2}\cdot n
. In these cases selecting
t=k
suffices to attain the upper bound in the lemma. The function
B
considers values of
k
which may be close to
\frac{1}{2}\cdot n
, for which we use a more subtle argument to upper bound
\Psi_{g}
.
By (
9
) we have

\Psi_{g}(n)=\max_{0\leq k\leq n}\,\min_{0\leq t\leq k}\frac{\binom{n}{t}}{\binom{k}{t}}\cdot g(k-t)=\max\left\{A(n),B(n)\right\}.

(13)

We bound
A(n)
and
B(n)
separately.

Claim 5.18
.

A(n)\leq 2^{0.85\cdot n}

Proof.

Let
0\leq k\leq n
such that
k\leq\frac{1}{4}\cdot n
or
k\geq\frac{3}{4}\cdot n
. Then by selecting
t=k
we have

\displaystyle\min_{0\leq t\leq k}\frac{\binom{n}{t}}{\binom{k}{t}}\cdot g(k-t)\leq\frac{\binom{n}{k}}{\binom{k}{k}}\cdot g(0)=\binom{n}{k}\leq 2^{n\cdot\mathcal{H}\left(\frac{k}{n}\right)}\leq 2^{0.85\cdot n},

where the second equality follows from (
10
), the equality uses
g(0)=1
, and the last inequality follows from
\mathcal{H}\left(x\right)\leq 0.85
for
x\in[0,1/4]\cup[3/4,1]
as
\mathcal{H}\left(x\right)
is increasing in
[0,1/2]
, decreasing in
[1/2,1]
, and
\mathcal{H}\left(1/4\right)=\mathcal{H}\left(3/4\right)<0.85
. Therefore,

A(n)=\max_{0\leq k<\frac{1}{4}\cdot n\textnormal{ or }\frac{3}{4}\cdot n<k\leq n}\,\min_{0\leq t\leq k}\frac{\binom{n}{k}}{\binom{n-t}{k-t}}\cdot g(k-t)\leq 2^{0.85\cdot n}

\square

Next, we bound
B(n)
.

Claim 5.19
.

B(n)\leq 2^{n-\Psi_{g}(n)+\log(n)}

Proof.

Let
\frac{1}{4}\cdot n\leq k\leq\frac{3}{4}\cdot n
. Then,

\displaystyle\log

\displaystyle\left(\min_{1\leq t\leq k}\frac{\binom{n}{t}}{\binom{k}{t}}\cdot g(k-t)\right)=\min_{0\leq t\leq k}\left(\log\binom{n}{t}-\log\binom{k}{t}+\log\left(g(k-t)\right)\right)

(14)

\displaystyle\leq\min_{0\leq t\leq k}\left(n\cdot\mathcal{H}\left(\frac{t}{n}\right)-k\cdot\mathcal{H}\left(\frac{t}{k}\right)+\log(k+1)+\log g(k-t)\right)

\displaystyle\leq\min_{0\leq t\leq k}\left(n-k\cdot\mathcal{H}\left(\frac{t}{k}\right)+\log(n)+\log g(k-t)\right)

where the first inequality follows from (
10
), and the second holds as
k<n
and
\mathcal{H}\left(x\right)\leq 1
for all
0\leq x\leq 1
.
By (
11
), for every
0\leq t\leq k
, we have

-k\cdot\mathcal{H}\left(\frac{t}{k}\right)=-(k-t)\cdot\frac{k}{k-t}\cdot\mathcal{H}\left(\frac{k-t}{k}\right)\leq(k-t)\cdot\log\left(\frac{k-t}{k}\right)\leq(k-t)\cdot\log\left(4\cdot\frac{k-t}{n}\right),

where the first inequality follows from
\mathcal{H}\left(x\right)=\mathcal{H}\left(1-x\right)
and the last inequality holds as
k\geq\frac{1}{4}\cdot n
.
Incorporating the above into (
14
) we get

\displaystyle\log\left(\min_{1\leq t\leq k}\frac{\binom{n}{t}}{\binom{k}{t}}\cdot g(k-t)\right)

\displaystyle\leq\min_{0\leq t\leq k}\left(n-k\cdot\mathcal{H}\left(\frac{t}{k}\right)+\log(n)+\log g(k-t)\right)

(15)

\displaystyle\leq\min_{0\leq t\leq k}\left(n+(k-t)\cdot\log\left(4\cdot\frac{k-t}{n}\right)+\log(n)+\log g(k-t)\right)

We use several auxiliary functions in order to bound
B(n)
. Define

\varphi(\ell,n)=\ell\cdot\log\left(\frac{n}{4\cdot\ell}\right)-\log g(\ell)

and

p(n)=\argmax_{0\leq\ell\leq n/4}\varphi(\ell,n).

(16)

Therefore, by
(
7
) it holds that

\Phi_{g}(n)=\varphi(p(n),n).

(17)

We use
t=k-p(n)
to upper bound the expression in (
15
). Observe that since
p(n)\leq\frac{n}{4}\leq k
it holds that
k-p(n)\geq 0
. That is,

\displaystyle\log\left(\min_{1\leq t\leq k}\frac{\binom{n}{t}}{\binom{k}{t}}\cdot g(k-t)\right)

\displaystyle\leq\min_{0\leq t\leq k}\left(n+(k-t)\cdot\log\left(4\cdot\frac{k-t}{n}\right)+\log(n)+\log g(k-t)\right)

\displaystyle\leq n+p(n)\cdot\log\left(\frac{4\cdot p(n)}{n}\right)+\log(n)+\log g(p(n))

\displaystyle\leq n-\varphi\left(p(n),n\right)+\log(n).

Overall, we showed that

\log\left(\min_{1\leq t\leq k}\frac{\binom{n}{t}}{\binom{k}{t}}\cdot g(k-t)\right)\leq n-\varphi\left(p(n),n\right)+\log(n)

(18)

for all
\frac{n}{4}\leq k\leq\frac{3\cdot n}{4}
.

By the above we have,

B(n)=\max_{\frac{1}{4}\cdot n\leq k\leq\frac{3}{4}\cdot n}\,\min_{0\leq t\leq k}\frac{\binom{n}{t}}{\binom{k}{t}}\cdot g(k-t)\leq 2^{n-\varphi\left(p(n),n\right)+\log(n)}=2^{n-\Phi_{g}(n)+\log(n)},

where the first equality is by (
12
), the first inequality is by (
18
), and the last equality is by (
17
).

\square

By
Claim

5.18
,
Claim

5.19
and (
13
) we have,

\Psi_{g}(n)=\max\left\{A(n),B(n)\right\}=\max\left\{2^{0.85\cdot n},~2^{n-\Phi_{g}(n)+\log(n)}\right\}.

(19)

To complete the proof we use the following claim.

Claim 5.20
.

\Phi_{g}(n)\leq 0.15\cdot n
for all
n\in{\mathbb{N}}
.

Proof.

Assume towards contradiction that there is
n\in\mathbb{N}
such that
\Phi_{g}(n)>0.15\cdot n
. Then,

0.15\cdot n<\Psi_{g}(n)=\varphi(p(n),n)=p(n)\cdot\log\left(\frac{n}{4\cdot p(n)}\right)-\log g(p(n))\leq p(n)\cdot\log\left(\frac{n}{4\cdot p(n)}\right).

Therefore,

\frac{p(n)}{n}\cdot\log\left(\frac{n}{4\cdot p(n)}\right)>0.15.

However, the function
r(x)=\frac{1}{x}\log\left(\frac{1}{4}x\right)
has a global maximum of
0.132\approx\frac{1}{4\cdot e\cdot\ln 2}<0.15
at
x=4e\approx 10.87
. Therefore, there is no

for which
\Phi_{g}(n)>0.15n
.

\square

By (
19
) and
Claim

5.20
it follows that

\Psi_{g}(n)=\max\left\{2^{0.85\cdot n},~2^{n-\Phi_{g}(n)+\log(n)}\right\}=2^{n-\Phi_{g}(n)+\log(n)}

∎

5.13
is an immediate consequence of

and

5.3

In this section we prove

See

Proof.

Recall that

\displaystyle\ell(n)\cdot\log\left(\frac{n}{4\cdot\ell(n)}\right)

\displaystyle=\frac{n^{\frac{1}{1+\alpha}}}{c}\cdot\left(\log\left(c\right)-\log(4)+\frac{\alpha}{1+\alpha}\cdot\log(n)\right)-\log\left(\frac{c}{4}\cdot n^{\frac{\alpha}{1+\alpha}}\right).

\displaystyle\leq\alpha\cdot\frac{n^{\frac{1}{1+\alpha}}}{c}\cdot\log\left(\frac{n^{\frac{1}{1+\alpha}}}{c}\right)

\displaystyle=\frac{n^{\frac{1}{1+\alpha}}}{c}\cdot\left(\frac{\alpha}{1+\alpha}\cdot\log(n)-\alpha\cdot\log(c)\right),

where the first inequality follows from

and due to (

Plugging both (

\displaystyle\Phi_{g_{\alpha}}(n)

\displaystyle\geq\frac{n^{\frac{1}{1+\alpha}}}{c}\cdot\left(\log\left(c\right)-\log(4)+\frac{\alpha}{1+\alpha}\cdot\log(n)\right)-\log\left(\frac{c}{4}\cdot n^{\frac{\alpha}{1+\alpha}}\right)

\displaystyle-\frac{n^{\frac{1}{1+\alpha}}}{c}\cdot\left(\frac{\alpha}{1+\alpha}\cdot\log(n)-\alpha\cdot\log(c)\right)

\displaystyle=\frac{n^{\frac{1}{1+\alpha}}}{c}\cdot\bigg((1+\alpha)\cdot\log(c)-\log(4)\bigg)-\log\left(\frac{c}{4}\cdot n^{\frac{\alpha}{1+\alpha}}\right).

\displaystyle=\frac{n^{\frac{1}{1+\alpha}}}{c}-\log\left(\frac{c}{4}\cdot n^{\frac{\alpha}{1+\alpha}}\right).

\displaystyle=\Omega\left(n^{\frac{1}{1+\alpha}}\right),

where second equality holds as

.

Proof.

5.4
An Extension Algorithm for
{\mathcal{P}}_{\ell\textnormal{-MI}}

We are left to show how an extension algorithm for

{\mathcal{P}}_{\ell\textnormal{-MI}}
can be derived from a random parameterized algorithm for oracle
\ell
-MI.

See
5.2

The proof of
Lemma

5.2
relies on the contraction operation of matroids which has been defined in
Section

2
. We note that if
(E,{\mathcal{I}})
is a matroid and
S\cup X
is a basis of
(E,{\mathcal{I}})
such that
S\cap X=\emptyset
then
S
is a basis of
(E,{\mathcal{I}})/X=(E\setminus X,{\mathcal{I}}/X)
, the contraction of
(E,{\mathcal{I}})
by
X
. This is also true in the opposite direction - if
S
is a basis of
(E,{\mathcal{I}})/X=(E\setminus X,{\mathcal{I}}/X)
then
X\cup S
is a basis of
(E,{\mathcal{I}})
.
The core idea in the proof of
Lemma

5.2
is that if a set
X
has an
\ell
-extension
S
, that is,
X\cup S
is a common basis of
(E,{\mathcal{I}}_{1}),\ldots,(E,{\mathcal{I}}_{\ell})
and
|S|=\ell
then
S
is a common basis of
(E,{\mathcal{I}}_{1})/X,\ldots,(E,{\mathcal{I}}_{\ell})/X
.

Proof of
Lemma

5.2
.

Let
{\mathcal{A}}
be a randomized parameterized algorithm for oracle
\ell
-MI which runs in time
g(k)\cdot\textnormal{poly}(|E|)
.
We assume that
{\mathcal{A}}
returns a common basis of the matroids if there is one.
We define an extension algorithm
{\mathcal{D}}
for
{\mathcal{P}}_{\ell\textnormal{-MI}}
.
Recall that an instance
(E,{\mathcal{F}},B,\textnormal{{oracle}})\in{\mathcal{P}}_{\ell\textnormal{-MI}}
is associated with an
\ell
-matroid intersection instance
(E,{\mathcal{I}}_{1},\ldots,{\mathcal{I}}_{\ell})
where

6
Discussion and Open Problems

In this paper, we obtained an almost tight running time lower bound for
\ell
-matroid intersection for any
\ell\geq 3
, even if randomization is allowed. In addition, we generalized the monotone local search technique of Fomin et al.
[
FGLS19
]
for a wider class of parameterized algorithms, and used it (i) to obtain an algorithm for
\ell
-MI that is faster than brute force by a super-polynomial factor, and (ii) to derive a parameterized lower bound for
\ell
-MI. A few intriguing questions remain open:

Strengthening our Results

We derived several running time lower bounds for
\ell
-MI. While these bounds are close to the state-of-the-art algorithmic results, they do not fully match. More specifically, we showed a lower bound of
2^{n-5\cdot n^{\frac{1}{\ell-1}}\cdot\log n}
while we presented only a
2^{n-\Omega\left(\log^{2}n\right)}
algorithm. Also,
we showed a running time lower bound of
2^{(\ell-2-{\varepsilon})\cdot k\cdot\log k}\cdot\textnormal{poly}(n)
for parameterized
\ell
-MI, while the best known algorithm of Huang and Ward
[
HW23
]
runs in time
c^{k^{2}}\cdot\textnormal{poly}(n)
. Observe that these gaps are related: a faster parameterized algorithm would imply a faster exponential time algorithm, and a stronger exponential time lower bound would imply a stronger lower bound in the parameterized setting. This is due to our generalization of monotone local search. Can the algorithms be improved? Alternatively, can the lower bounds be strengthened?

Monotone Local Search

Our generalization of the monotone local search allows only for randomized algorithms.
While the original monotone local search paper
[
FGLS19
]
presents also a derandomization of the technique, the derandomization came with a cost of
o(n)
overhead in the exponent, i.e., running time of
\left(2-\frac{1}{c}\right)^{n+q(n)}
instead of
\left(2-\frac{1}{c}\right)^{n}\cdot\textnormal{poly}(n)
, where
q(n)=\Theta\left(\frac{n}{\log n}\right)=o(n)
. While this overhead can be claimed to be insignificant in the setting of
[
FGLS19
]
, in our setting this may be harmful to the extent that the overall runtime becomes higher than brute force. Thus, obtaining a useful derandomized algorithm for our generalization is an interesting direction for futue work.

Beating Brute Force for other Problems

We have studied
3
-MI as an example for a problem with no algorithm
of running time
c^{n}\cdot\textnormal{poly}(n)
for any
c<2
, which still admits an algorithm faster than brute force by a factor of
n^{\log n}
, where
n
is the size of the instance.
The monotone local search technique used to derive this algorithm
is generic and can be applied to a wide range of problems which admit parameterized algorithms. Are there other such problems, for which the best known (brute force) exponential-time algorithm can be improved using monotone local search?
