Faster algorithms for k k -Orthogonal Vectors in low dimension
Anita Dürr, Evangelos Kipouridis, Karol Węgrzycki

Abstract
In the Orthogonal Vectors problem (OV), we are given two families A , B {{A}},{{B}} of subsets of { 1 , … , d } \{1,\ldots,d\} , each of size n n , and the task is to decide whether there exists a pair a ∈ A {\textbf{a}}\in{{A}} and b ∈ B {\textbf{b}}\in{{B}} such that a ∩ b = ∅ {\textbf{a}}\cap{\textbf{b}}=\emptyset . Straightforward algorithms for this problem run in 𝒪 ⁡ ( n 2 ⋅ d ) \mathcal{O}(n^{2}\cdot d) or 𝒪 ⁡ ( 2 d ⋅ n ) \mathcal{O}(2^{d}\cdot n) time, and assuming SETH, there is no 2 o ⁡ ( d ) ⋅ n 2 − ε 2^{o(d)}\cdot n^{2-\varepsilon} time algorithm that solves this problem for any constant ε > 0 \varepsilon>0 . Williams (FOCS 2024) presented a 𝒪 ~ ​ ( 1.35 d ⋅ n ) \tilde{\mathcal{O}}(1.35^{d}\cdot n) -time algorithm for the problem, based on the succinct equality-rank decomposition of the disjointness matrix. In this paper, we present a combinatorial algorithm that runs in randomized time 𝒪 ~ ​ ( 1.25 d ​ n ) \tilde{\mathcal{O}}(1.25^{d}n) . This can be improved to 𝒪 ⁡ ( 1.16 d ⋅ n ) \mathcal{O}(1.16^{d}\cdot n) using computer-aided evaluations. We generalize our result to the k k -Orthogonal Vectors problem, where given k k families A 1 , … , A k {{A}}_{1},\ldots,{{A}}_{k} of subsets of { 1 , … , d } \{1,\ldots,d\} , each of size n n , the task is to find elements a i ∈ A i {\textbf{a}}_{i}\in{{A}}_{i} for every i ∈ { 1 , … , k } i\in\{1,\ldots,k\} such that a 1 ∩ a 2 ∩ … ∩ a k = ∅ {\textbf{a}}_{1}\cap{\textbf{a}}_{2}\cap\ldots\cap{\textbf{a}}_{k}=\emptyset . We show that for every fixed k ⩾ 2 k\geqslant 2 , there exists ε k > 0 \varepsilon_{k}>0 such that the k k -OV problem can be solved in time 𝒪 ⁡ ( 2 ( 1 − ε k ) ⋅ d ⋅ n ) \mathcal{O}(2^{(1-\varepsilon_{k})\cdot d}\cdot n) . We also show that, asymptotically, this is the best we can hope for: for any ε > 0 \varepsilon>0 there exists a k ⩾ 2 k\geqslant 2 such that 2 ( 1 − ε ) ⋅ d ⋅ n 𝒪 ⁡ ( 1 ) 2^{(1-\varepsilon)\cdot d}\cdot n^{\mathcal{O}(1)} time algorithm for k k -Orthogonal Vectors would contradict the Set Cover Conjecture.

Binomial Coefficients

The binary entropy function is defined as
h(\alpha)\coloneq-\alpha\log_{2}(\alpha)-(1-\alpha)\log_{2}(1-\alpha)

2^{h(\alpha)n}\geqslant\binom{n}{\alpha n}\geqslant\Omega\left(2^{h(\alpha)n}\cdot n^{-1/2}\right),

h(\alpha_{1},\ldots,\alpha_{k})\coloneqq-\sum_{i=1}^{k}\alpha_{i}\log_{2}\alpha_{i}.

The multinomial coefficient can be approximated with the function

2^{h(\alpha_{1},\ldots,\alpha_{k})n}\cdot n^{-\mathcal{O}(k)}\leqslant\binom{n}{\alpha_{1}n,\ldots,\alpha_{k}n}\leqslant 2^{h(\alpha_{1},\ldots\alpha_{k})n}.

Lemma 2.2
.

The Orthogonal Vectors problem can be solved deterministically in
\widetilde{\mathcal{O}}(2^{d/2}\cdot n)

Proof.

Partition the universe

{\textbf{x}}_{L}={\textbf{x}}\cap{\textbf{u}}_{L}

{\textbf{x}}_{H}={\textbf{x}}\cap{\textbf{u}}_{H}

Consider the following sets of vectors:

\displaystyle{{S}}_{A}:=

\displaystyle\left\{{\textbf{a}}_{L}\uplus{\textbf{x}}_{H}\subseteq[d]\ \mid\ {\textbf{a}}_{L}\uplus{\textbf{a}}_{H}\in{{A}},\,{\textbf{x}}_{H}\subseteq{\textbf{u}}_{H},\,{\textbf{x}}_{H}\cap{\textbf{a}}_{H}=\emptyset\right\},

\displaystyle{{S}}_{B}:=

\displaystyle\left\{{\textbf{x}}_{L}\uplus{\textbf{b}}_{H}\subseteq[d]\ \mid\ {\textbf{b}}_{L}\uplus{\textbf{b}}_{H}\in{{B}},\,{\textbf{x}}_{L}\subseteq{\textbf{u}}_{L},\,{\textbf{x}}_{L}\cap{\textbf{b}}_{L}=\emptyset\right\}.

We claim that

if and only if an orthogonal pair exists.
Assume that there exist orthogonal vectors

{\textbf{a}}_{L}\uplus{\textbf{b}}_{H}

and

For the converse, assume that

Since

Observe that both

are at most

and

k^{\prime}
-OV instance
for smaller
k^{\prime}<k
. Since
Lemma

2.2
proves the statement for
k=2
with value
\varepsilon_{2}=1/2
, we only need to show that the value of
\varepsilon_{k}
stays positive.

Assume that there exists a solution
({\textbf{a}}_{1},\dots,{\textbf{a}}_{k})\in{{A}}_{1}\times\dots\times{{A}}_{k}
such that
{\textbf{a}}_{1}\cap\dots\cap{\textbf{a}}_{k}=\emptyset
.
Let
\alpha_{1},\dots,\alpha_{k}\in[0,1]
be such that
|{\textbf{a}}_{i}|=\alpha_{i}d
for every
i\in[k]
. By enumerating all possible sizes, we can guess
the values of
\alpha_{1},\dots,\alpha_{k}
in
\mathcal{O}(d^{k})
time.
This factor will be negligible compared to
2^{(1-\varepsilon_{k})d}
as
k\geqslant 2
is a
fixed constant. After guessing
\alpha_{1},\ldots,\alpha_{k}
, we assume that the
family
{{A}}_{i}
contains only sets of cardinality exactly
\alpha_{i}d
for every
i\in[k]
.
Next, we distinguish between two cases.

If
\alpha_{i}\leqslant(1-\varepsilon_{k})
for every
i\in[k]
, then we can bound the
size of the down-closure of
{{A}}_{i}
by
|{\downarrow}{{A}}_{i}|=\mathcal{O}(2^{\alpha_{i}d}\cdot|{{A}}_{i}|)
. It means that we can solve the
k
-OV instance
{{A}}_{1},\dots,{{A}}_{k}
using the algorithm of
Lemma

4.1
in time
\mathcal{O}(2^{(1-\varepsilon_{k})d}\cdot n\cdot d)
.

If there exists
i\in[k]
such that
\alpha_{i}>(1-\varepsilon_{k})
, then we recurse as follows. By reordering the families, we can assume that
\alpha_{1}\leqslant\dots\leqslant\alpha_{k}
.
Let
\ell\in[k]
be the smallest index such that
\alpha_{\ell}>(1-\varepsilon_{k})
, i.e.
\alpha_{1}\leqslant\dots\leqslant\alpha_{\ell-1}\leqslant(1-\varepsilon_{k})<\alpha_{\ell}\leqslant\dots\leqslant\alpha_{k}
.
Note that
({\textbf{a}}_{\ell},\dots,{\textbf{a}}_{k})\in{{A}}_{\ell}\times\dots\times{{A}}_{k}
. Furthermore, for every
i\in\{\ell,\dots,k\}
, since
\varepsilon_{k}\leqslant 1/2
, we can bound
|{{A}}_{i}|\leqslant\sum_{j=(1-\varepsilon_{k})d}^{d}\binom{d}{j}\leqslant\binom{d}{(1-\varepsilon_{k})d}\cdot d=\binom{d}{\varepsilon_{k}d}\cdot d
. By
Equation

1
we thus get
|{{A}}_{i}|\leqslant 2^{h(\varepsilon_{k})d}\cdot d
.
Hence we can enumerate
{{A}}_{\ell}\times\dots\times{{A}}_{k}
to guess the
sets
{\textbf{a}}_{\ell},\dots,{\textbf{a}}_{k}
in time
\mathcal{O}\left(2^{h(\varepsilon_{k})d(k-\ell+1)}\right)
. To find the remaining sets
{\textbf{a}}_{1},\dots,{\textbf{a}}_{\ell-1}
,
observe that we can restrict the universe to
{\textbf{r}}\coloneq{\textbf{a}}_{\ell}\cap\dots\cap{\textbf{a}}_{k}
as we have
{\textbf{a}}_{1}\cap\dots\cap{\textbf{a}}_{k}={\textbf{a}}_{1}\cap\dots\cap{\textbf{a}}_{\ell-1}\cap{\textbf{r}}=({\textbf{a}}_{1}\cap{\textbf{r}})\cap\dots\cap({\textbf{a}}_{\ell-1}\cap{\textbf{r}})
. So we recursively solve the
(\ell-1)
-OV
instance
{{A}}_{1}^{r},\dots,{{A}}_{\ell-1}^{r}
where
{{A}}_{i}^{r}\coloneq\{{\textbf{a}}\cap{\textbf{r}}\ \mid\ {\textbf{a}}\in{{A}}_{i}\}
for all
i\in\{1,\dots,\ell-1\}
. By induction, this takes time
\widetilde{\mathcal{O}}(2^{(1-\varepsilon_{\ell-1})d}\cdot n)
.
In total, we solve the
k
-OV instance
{{A}}_{1},\dots,{{A}}_{k}
in time

\widetilde{\mathcal{O}}(2^{h(\varepsilon_{k})d(k-\ell+1)}\cdot 2^{(1-\varepsilon_{\ell-1})d}\cdot n)=\widetilde{\mathcal{O}}(2^{(1-\varepsilon_{k})d}\cdot n)
for
\varepsilon_{k}\leqslant\varepsilon_{\ell-1}-h(\varepsilon_{k})\cdot(k-\ell+1)
.
Note that since
\varepsilon_{k}\leqslant 1/2
, the function
\varepsilon_{k}\mapsto\varepsilon_{k}+h(\varepsilon_{k})\cdot(k-\ell+1)
is increasing.
Furthermore,
\lim_{\varepsilon_{k}\rightarrow 0^{+}}\varepsilon_{k}+h(\varepsilon_{k})\cdot(k-\ell+1)=0
.
Since
\varepsilon_{2}>0
by
Section

1
, we can set
\varepsilon_{k}
to a positive value satisfying
\varepsilon_{k}\leqslant\min\{1/2,\varepsilon_{\ell-1}-h(\varepsilon_{k})\cdot(k-\ell+1)\}
.
Achieving running time
\mathcal{O}(2^{(1-\varepsilon_{k})d}\cdot n)
, instead of
\widetilde{\mathcal{O}}(2^{(1-\varepsilon_{k})d}\cdot n)
follows directly by scaling all
\varepsilon_{k}
(e.g. by
0.99
).
∎

Appendix A
Lower bound under Set Cover Conjecture

In the Set Cover problem, we are given a universe
u
, a set family
{{F}}

and a positive integer
t
, and have to determine if there exist
t
sets in

{{F}}
whose union is
u
.
The Set Cover Conjecture implies that there is no
\varepsilon>0
for which Set Cover
is solvable in
\mathcal{O}^{\star}(2^{(1-\varepsilon)\cdot{|{\textbf{u}}|}})
time.
Assuming the Set Cover Conjecture, we show a lower bound on the time complexity of
k
-Orthogonal Vectors.
See
1

Proof.

Let
({\textbf{u}},{{F}},t)
be an instance of Set Cover,
\varepsilon>0
be a fixed constant, and assume that
t
-Orthogonal Vectors is solvable in
2^{(1-\varepsilon)\cdot d}\cdot n^{c}
time.
We create an instance
{{A}}_{1},\ldots,{{A}}_{t}
of
t
-Orthogonal Vectors such that

{\textbf{a}}\subseteq{\textbf{u}}
is in
{\textbf{a}}_{1}
iff
{\textbf{u}}\setminus{\textbf{a}}\in{{F}}
and
{{A}}_{1}=\ldots={{A}}_{t}
.

It suffices to show that there exists a solution for the Set Cover instance iff there exists a solution for the
t
-Orthogonal Vectors instance.
If there exists a solution
{\textbf{a}}_{1},\ldots,{\textbf{a}}_{t}
for the
t
-Orthogonal
Vectors instance, then
\bigcap_{i=1}^{t}{\textbf{a}}_{i}=\emptyset
, meaning that

\bigcup_{i=1}^{t}{\textbf{u}}\setminus{\textbf{a}}_{i}={\textbf{u}}
. But
{\textbf{u}}\setminus{\textbf{a}}_{i}\in{{F}}
by construction, therefore there exists a solution for the Set Cover instance.

Similarly, if there exists a solution
{\textbf{s}}_{1},\ldots,{\textbf{s}}_{t}
for the Set Cover
instance, then
\bigcup_{i=1}^{t}{\textbf{s}}_{i}={\textbf{u}}
, meaning that
\bigcap_{i=1}^{t}{\textbf{u}}\setminus{\textbf{s}}_{i}=\emptyset
. But
{\textbf{u}}\setminus{\textbf{s}}_{i}\in{\textbf{a}}_{i}
by construction, therefore there exists a solution for the
t
-Orthogonal Vectors problem.
∎
