Foreign-Trade Zone (FTZ) 138, Notification of Proposed Production 
Activity; Shiseido Americas Corporation; (Cosmetic and Beauty 
Products); Groveport, Ohio

    Shiseido Americas Corporation. submitted a notification of proposed 
production activity to the FTZ Board (the Board) for its facilities in 
Groveport, Ohio within Subzone 138N. The notification conforming to the 
requirements of the Board's regulations (15 CFR 400.22) was received on 
May 14, 2026.
    Pursuant to 15 CFR 400.14(b), FTZ production activity would be 
limited to the specific foreign-status material(s)/component(s) and 
specific finished product(s) described in the submitted notification 
(summarized below) and subsequently authorized by the Board. The 
benefits that may stem from conducting production activity under FTZ 
procedures are explained in the background section of the Board's 
website--accessible via www.trade.gov/ftz.
    The proposed finished products include: set including perfume; set 
including lip make-up; set including skincare for lip; set including 
eye make-up; set including skincare for eye; set including manicure 
products; set including pedicure products; set including manicure & 
pedicure products; set including non-rouge powder; set including rouge 
powder; set including eye & cheek make-up; set including face 
complexion make-up; set including lip & cheek make-up; set including 
lip & eye make-up; set including lip, eye & cheek make-up; set 
including skincare for face; set including skincare masks; set 
including sunscreen products; set including skincare for face & body; 
set including skincare for body; set including haircare products; set 
including aftershave; set including deodorant; set including wipes for 
body; set including wipes for face; set including wipes for face & 
body; set including bar soap; set including led (light-emitting diode) 
wearable mask device; set including led (light-emitting diode) wearable 
mask device & skincare for face; set including cosmetic brush tools; 
set including eyelash curler tools; set including cosmetic puff (duty 
rate ranges from duty-free to 8.10%).
    The proposed foreign-status materials/components include: perfume;

    The request indicates that certain materials/components are subject 
to duties under section 122 of the Trade Act of 1974 (Section 122), 
section 232 of the Trade Expansion Act of 1962 (section 232), or 
section 301 of the Trade Act of 1974 (section 301), depending on the 
country of origin. The applicable section 122, section 232, and section 
301 decisions require subject merchandise to be admitted to FTZs in 
privileged foreign status (19 CFR 146.41).
