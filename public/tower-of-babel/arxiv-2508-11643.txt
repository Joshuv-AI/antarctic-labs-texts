Recurrence Relations for β ⁡ ( 2 ​ k ) \beta(2k) and ζ ⁡ ( 2 ​ k + 1 ) \zeta(2k+1)
Tobias Kyrion

Abstract
In this work we study integrals of the form ∫ 0 ∞ tanh ⁡ ( x ) x ​ sech ⁡ ( x ) L ​ exp ⁡ ( − T ​ x ) ​ 𝑑 x . \int_{0}^{\infty}\frac{\tanh(x)}{x}\sech(x)^{L}\exp(-Tx)dx. For L ∈ ℕ L\in\mathbb{N} , L ≤ 4 L\leq 4 and T ∈ ℝ T\in\mathbb{R} we give explicit expressions in terms of derivatives of the Hurwitz zeta function at negative integers. We use these expressions to evaluate these integrals for T ∈ ℕ 0 T\in\mathbb{N}_{0} exactly. For the special case T = 0 T=0 we give explicit evaluations for any L ∈ ℕ L\in\mathbb{N} based on the functional equations for β ⁡ ( s ) \beta(s) and ζ ⁡ ( s ) \zeta(s) . As it turns out the value of ∫ 0 ∞ tanh ⁡ ( x ) x ​ sech ⁡ ( x ) 2 ​ N + 1 ​ 𝑑 x \int_{0}^{\infty}\frac{\tanh(x)}{x}\sech(x)^{2N+1}dx is a linear combination of β ⁡ ( 2 ) \beta(2) , …, β ⁡ ( 2 ​ N + 2 ) \beta(2N+2) and the value of ∫ 0 ∞ tanh ⁡ ( x ) x ​ sech ⁡ ( x ) 2 ​ N ​ 𝑑 x \int_{0}^{\infty}\frac{\tanh(x)}{x}\sech(x)^{2N}dx a linear combination of ζ ⁡ ( 3 ) \zeta(3) , …, ζ ⁡ ( 2 ​ N + 1 ) \zeta(2N+1) . We give recursive formulae for the coefficients in these linear combinations.

Integrals of the Form
\int_{0}^{\infty}\frac{\tanh(x)}{x}\sech(x)^{L}\exp(-Tx)dx

We introduce a slightly more general integral as suggested in the title given by

\int_{0}^{\infty}\left(\frac{\tanh(x)}{x}\right)^{N}\tanh(x)^{K}\sech(x)^{L}\exp(-Tx)dx.

(1.1)

Then we can show by partial integration

Lemma 1.1
.

Let
N
,
K
,
L
and
T\in\mathbb{R}
. Then there holds for the integral from (
1.1
) the following:

\begin{split}&N\int_{0}^{\infty}\left(\frac{\tanh(x)}{x}\right)^{N+1}\tanh(x)^{K}\sech(x)^{L}\exp(-Tx)dx\\
=\;\;&(N+K+1)\int_{0}^{\infty}\left(\frac{\tanh(x)}{x}\right)^{N}\tanh(x)^{K}\sech(x)^{L+2}\exp(-Tx)dx\\
-&L\int_{0}^{\infty}\left(\frac{\tanh(x)}{x}\right)^{N}\tanh(x)^{K+2}\sech(x)^{L}\exp(-Tx)dx\\
-&T\int_{0}^{\infty}\left(\frac{\tanh(x)}{x}\right)^{N}\tanh(x)^{K+1}\sech(x)^{L}\exp(-Tx)dx\end{split}

(1.2)

Our first step towards determining
\int_{0}^{\infty}\frac{1}{x}\tanh(x)\sech(x)^{L}\exp(-Tx)dx
is to evaluate the more simple integral
\int_{0}^{\infty}\sech(x)^{L}\exp(-Tx)dx
. Now we show that it solves a two-step recurrence relation.

Proposition 1.2
.

Let
L,T\in\mathbb{R}
. Then there holds

\begin{split}&(L+2)(L+3)\int_{0}^{\infty}\sech(x)^{L+4}\exp(-Tx)dx\\
=\;\;&\left((L+1)(2L+3)-T^{2}+1\right)\int_{0}^{\infty}\sech(x)^{L+2}\exp(-Tx)dx\\
+&\left(T^{2}-L^{2}\right)\int_{0}^{\infty}\sech(x)^{L}\exp(-Tx)dx.\end{split}

(1.3)

Proof
.

Setting
N=0
and
K=0
in (
1.2
) gives

\begin{split}&\int_{0}^{\infty}\sech(x)^{L+2}\exp(-Tx)dx-L\int_{0}^{\infty}\tanh(x)^{2}\sech(x)^{L}\exp(-Tx)dx\\
=\;\;&T\int_{0}^{\infty}\tanh(x)\sech(x)^{L}\exp(-Tx)dx.\end{split}

(1.4)

From this follows using the elementary identity
\tanh(x)^{2}+\sech(x)^{2}=1

\begin{split}&(L+1)\int_{0}^{\infty}\sech(x)^{L+2}\exp(-Tx)dx-L\int_{0}^{\infty}\sech(x)^{L}\exp(-Tx)dx\\
=\;\;&T\int_{0}^{\infty}\tanh(x)\sech(x)^{L}\exp(-Tx)dx.\end{split}

(1.5)

Expanding
\tanh(x)^{2}=\frac{1}{4}(\exp(2x)-2+\exp(-2x))\sech(x)^{2}
and combining (
1.4
) and (
1.5
) give

\displaystyle\int_{0}^{\infty}\sech(x)^{L+2}\exp(-Tx)dx-\frac{1}{4}L\bigg(\int_{0}^{\infty}\sech(x)^{L+2}\exp(-(T-2)x)dx

\displaystyle-

\displaystyle 2\int_{0}^{\infty}\sech(x)^{L+2}\exp(-Tx)dx+\int_{0}^{\infty}\sech(x)^{L+2}\exp(-(T+2)x)dx\bigg)

\displaystyle=\;\;

\displaystyle(L+1)\int_{0}^{\infty}\sech(x)^{L+2}\exp(-Tx)dx-L\int_{0}^{\infty}\sech(x)^{L}\exp(-Tx)dx.

We subtract
\int_{0}^{\infty}\sech(x)^{L+2}\exp(-Tx)dx
on both sides and then divide both sides by
L
. Furthermore we use that
\exp(2x)-1=2\sinh(x)\exp(x)
and obtain

\begin{split}&\frac{1}{2}\bigg(\int_{0}^{\infty}\sech(x)^{L+1}\tanh(x)\exp(-(T-1)x)dx-\int_{0}^{\infty}\sech(x)^{L+1}\tanh(x)\exp(-(T+1)x)dx\bigg)\\
=\;\;&\int_{0}^{\infty}\sech(x)^{L}\exp(-Tx)dx-\int_{0}^{\infty}\sech(x)^{L+2}\exp(-Tx)dx.\end{split}

(1.6)

Utilizing (
1.5
) we can expand the left hand side of (
1.6
) as follows:

\displaystyle\frac{1}{2}\bigg(\int_{0}^{\infty}\sech(x)^{L+1}\tanh(x)\exp(-(T-1)x)dx-\int_{0}^{\infty}\sech(x)^{L+1}\tanh(x)\exp(-(T+1)x)dx\bigg)

\displaystyle=\;\;

\displaystyle\frac{1}{2}\bigg(\frac{1}{T-1}\big((L+2)\int_{0}^{\infty}\sech(x)^{L+3}\exp(-(T-1)x)dx-(L+1)\int_{0}^{\infty}\sech(x)^{L+1}\exp(-(T-1)x)dx\big)

\displaystyle-

\displaystyle\frac{1}{T+1}\big((L+2)\int_{0}^{\infty}\sech(x)^{L+3}\exp(-(T+1)x)dx-(L+1)\int_{0}^{\infty}\sech(x)^{L+1}\exp(-(T+1)x)dx\big)\bigg)

\displaystyle=\;\;

\displaystyle\frac{(L+2)T}{T^{2}-1}\int_{0}^{\infty}\tanh(x)\sech(x)^{L+2}\exp(-Tx)dx+\frac{L+2}{T^{2}-1}\int_{0}^{\infty}\sech(x)^{L+2}\exp(-Tx)dx

\displaystyle-

\displaystyle\frac{(L+1)T}{T^{2}-1}\int_{0}^{\infty}\tanh(x)\sech(x)^{L}\exp(-Tx)dx-\frac{L+1}{T^{2}-1}\int_{0}^{\infty}\sech(x)^{L}\exp(-Tx)dx

We apply again (
1.5
) to write

\displaystyle T\int_{0}^{\infty}\tanh(x)\sech(x)^{L+2}\exp(-Tx)dx

\displaystyle=\;\;

\displaystyle(L+3)\int_{0}^{\infty}\sech(x)^{L+4}\exp(-Tx)dx-(L+2)\int_{0}^{\infty}\sech(x)^{L+2}.

By eleminating
\int_{0}^{\infty}\tanh(x)\sech(x)^{L}\exp(-Tx)dx
in the same manner, comparing with (
1.6
) and rearranging we finally obtain the result.

\square

With a small calculation we can show:

Proposition 1.3
.

Let
P_{L}(T)
fulfill the recurrence relation

L(L+1)P_{L+1}(T)=\left(L^{2}-T^{2}\right)P_{L}(T)+g(T),

(1.7)

where
g(T)
is an arbitrary but fixed function. Then
P_{L}(T)
also fulfills

(L+2)(L+3)P_{L+2}(T)=\left((L+1)(2L+3)-T^{2}+1\right)P_{L+1}(T)+\left(T^{2}-L^{2}\right)P_{L}(T).

(1.8)

Now we have every tool to state
\int_{0}^{\infty}\sech(x)^{L}\exp(-Tx)dx
for all
L\in\mathbb{N}
exactly.

Corollary 1.4
.

Let
L\in\mathbb{N}
. Then we have

\begin{split}\int_{0}^{\infty}\sech(x)^{2L}\exp(-Tx)dx\;=\;&\frac{1}{(2L-1)!}\left\{\prod_{j=1}^{L-1}\left((2j)^{2}-T^{2}\right)\right\}\left(-\frac{1}{2}T\left(\psi\left(\frac{T+4}{4}\right)-\psi\left(\frac{T+2}{4}\right)\right)+1\right)\\
+\;&\sum_{j=1}^{L-1}\left\{\prod_{k=j+1}^{L-1}\frac{(2k)^{2}-T^{2}}{2k(2k+1)}\right\}\frac{T}{2j(2j+1)}\end{split}

(1.9)

and for
L\in\mathbb{N}_{0}

\begin{split}\int_{0}^{\infty}\sech(x)^{2L+1}\exp(-Tx)dx\;=\;&\frac{1}{(2L)!}\left\{\prod_{j=0}^{L-1}\left((2j+1)^{2}-T^{2}\right)\right\}\frac{1}{2}\left(\psi\left(\frac{T+3}{4}\right)-\psi\left(\frac{T+1}{4}\right)\right)\\
+\;&\sum_{j=0}^{L-1}\left\{\prod_{k=j+1}^{L-1}\frac{(2k+1)^{2}-T^{2}}{(2k+1)(2k+2)}\right\}\frac{T}{(2j+1)(2j+2)}.\end{split}

(1.10)

Proof
.

From

\int_{0}^{\infty}\sech(x)\exp(-x)dx=\log(2)

and

\quad\int_{0}^{\infty}\sech(x)\exp(-(2k+1)x)dx+\int_{0}^{\infty}\sech(x)\exp(-(2k+3)x)dx=\frac{1}{k+1}\quad\mathrm{for}\;\;k\in\mathbb{N}_{0}

follows

\displaystyle\int_{0}^{\infty}\sech(x)\exp(-(4s+1)x)dx

\displaystyle=\sum_{k=1}^{2s}\frac{(-1)^{k}}{k}+\log(2)

\displaystyle=H_{s}-H_{2s}+\log(2)

\displaystyle=\psi(s+1)-\psi(2s+1)+\log(2)

\displaystyle=\frac{1}{2}\left(\psi(s+1)-\psi(s+\textstyle{\frac{1}{2}})\right)\quad\mathrm{for}\;\;s\in\mathbb{N}_{0},

where
H_{s}
is the
s
-th harmonic number. Then analytic continuation gives

\int_{0}^{\infty}\sech(x)\exp(-Tx)dx=\frac{1}{2}\left(\psi\left(\frac{T+3}{4}\right)-\psi\left(\frac{T+1}{4}\right)\right)

(1.11)

for all
T\in\mathbb{R}_{\geq 0}
.

Setting
L=0
in (
1.5
) gives

\begin{split}\int_{0}^{\infty}\sech(x)^{2}\exp(-Tx)dx&=T\int_{0}^{\infty}\tanh(x)\exp(-Tx)dx\\
&=\frac{T}{2}\left(\int_{0}^{\infty}\sech(x)\exp(-(T-1)x)dx-\int_{0}^{\infty}\sech(x)\exp(-(T+1)x)dx\right)\\
&=-\frac{1}{2}T\left(\psi\left(\frac{T+4}{4}\right)-\psi\left(\frac{T+2}{4}\right)\right)+1,\end{split}

(1.12)

where we used (
1.11
) in the last step.

Similarly we can show

\int_{0}^{\infty}\sech(x)^{3}\exp(-Tx)dx=\frac{1}{4}\left(1-T^{2}\right)\left(\psi\left(\frac{T+3}{4}\right)-\psi\left(\frac{T+1}{4}\right)\right)+\frac{1}{2}T

(1.13)

and

\int_{0}^{\infty}\sech(x)^{4}\exp(-Tx)dx=\frac{1}{6}\left(4-T^{2}\right)\left(-\frac{1}{2}T\left(\psi\left(\frac{T+4}{4}\right)-\psi\left(\frac{T+2}{4}\right)\right)+1\right)+\frac{1}{6}T.

(1.14)

By setting

P_{L}(T)=\int_{0}^{\infty}\sech(x)^{2L}\exp(-Tx)dx

we obtain

P_{1}(T)=-\frac{1}{2}T\left(\psi\left(\frac{T+4}{4}\right)-\psi\left(\frac{T+2}{4}\right)\right)+1

from (
1.12
) and
g(T)=T
from (
1.14
). Then (
1.9
) follows from (
1.7
) by induction.

In the same manner by setting

we get

P_{0}(T)=\frac{1}{2}\left(\psi\left(\frac{T+3}{4}\right)-\psi\left(\frac{T+1}{4}\right)\right)

\square

3
Integrals of the Form
\int_{0}^{\infty}\frac{\tanh(x)}{x}\sech(x)^{2N+1}dx
or Recurrence Identity for the
\beta(2k)^{\prime}s

In this section we prove

Theorem 3.1
.

For every
N\in\mathbb{N}_{0}
there holds

\begin{split}&\int_{0}^{\infty}\frac{\tanh(x)}{x}\sech(x)^{2N+1}dx=\frac{\binom{2N}{N}}{(2N+1)2^{2N}}\sum_{k=1}^{N+1}2^{2k}(2k-1)!g_{k,N+1}\frac{\beta(2k)}{\pi^{2k-1}},\\
\mathrm{with}\;\;&g_{1,N}=1,\;\;g_{k,N}=\sum_{j=k-1}^{N-1}\frac{1}{(2j-1)^{2}}g_{k-1,j},\;\;k\geq 2.\end{split}

(3.1)

Our first step is:

Proposition 3.2
.

Let
N\in\mathbb{N}_{0}
. Then there holds

\int_{0}^{\infty}\frac{1}{x}\frac{\partial^{2N+1}}{\partial x^{2N+1}}\sech(x)dx=(-1)^{N+1}2^{2N+2}(2N+1)!\frac{\beta(2N+2)}{\pi^{2N+1}}.

(3.2)

Proof
.

Our starting point is the integral

2\Gamma(s)\beta(s)=\int_{0}^{\infty}x^{s-1}\sech(x)dx.

We introduce a parameter
\alpha\in\mathbb{R}_{>0}
and perform a change of variables in above integral, resulting in

2\Gamma(s)\beta(s)\alpha^{-s}=\int_{0}^{\infty}x^{s-1}\sech(\alpha x)dx.

Applying
\frac{\partial^{2N+1}}{\partial\alpha^{2N+1}}
on the last finding gives

-2\Gamma(s+2N+1)\beta(s)\alpha^{-s-2N-1}=\int_{0}^{\infty}x^{s+2N}\frac{\partial^{2N+1}}{\partial y^{2N+1}}\sech(y)\bigg\rvert_{y=\alpha x}dx.

(3.3)

Now multiplying the functional equation for
\beta(s)

\beta(1-s)=\left(\textstyle{\frac{\pi}{2}}\right)^{-s}\sin(\textstyle{\frac{\pi}{2}}s)\Gamma(s)\beta(s)

on both sides with
(s,2N+1)=s(s+1)\cdot...\cdot(s+2N)
and rearranging give

\Gamma(s+2N+1)\beta(s)=(s,2N+1)\left(\textstyle{\frac{\pi}{2}}\right)^{s}\frac{\beta(1-s)}{\sin(\textstyle{\frac{\pi}{2}}s)}.

(3.4)

Then taking the limit
s\rightarrow-2N-1
in (
3.3
) using (
3.4
) proves the claim. Note that the parameter
\alpha
vanishes in the left hand side of (
3.3
), i.e. it can be chosen arbitrarily. Setting
\alpha=1
gives the claim in its stated form.

\square

We see that the derivatives
\frac{\partial^{2N+1}}{\partial x^{2N+1}}\sech(x)
occuring in (
3.2
) play a crucial role in the proof of Theorem
3.1
. It is therefore helpful to compute them explicitly:

Lemma 3.3
.

For ervery
N\in\mathbb{N}_{0}
the identity

\frac{\partial^{2N+1}}{\partial x^{2N+1}}\sech(x)=\tanh(x)\sum_{k=0}^{N}\left(\frac{1}{4^{k}}\sum_{j=0}^{k}\binom{2k+1}{k-j}\left(-1\right)^{j+1}\left(2j+1\right)^{2N+1}\right)\sech(x)^{2k+1}

(3.5)

is fulfilled.

Proof
.

We utilize an ansatz of the form

\frac{\partial^{2N+1}}{\partial x^{2N+1}}\sech(x)=\tanh(x)\sum_{k=0}^{N}c_{N,k}\sech(x)^{2k+1}.

After computing
\frac{\partial^{2N+3}}{\partial x^{2N+1}}\sech(x)
with above ansatz and equating coefficients, we find that the
c_{N,k}
’s fulfill the recurrence relation

\begin{split}c_{N,0}&=\;\;-1\\
\mathrm{and}\quad c_{N+1,k}&=\;\;(2k+1)^{2}c_{N,k}-2k(2k+1)c_{N,k-1}.\end{split}

(3.6)

Now the calculation

\displaystyle\;\;(2k+1)^{2}\frac{1}{4^{k}}\sum_{j=0}^{k}\binom{2k+1}{k-j}\left(-1\right)^{j+1}\left(2j+1\right)^{2N+1}

\displaystyle-

\displaystyle\;\;2k(2k+1)\frac{1}{4^{k-1}}\sum_{j=0}^{k-1}\binom{2k-1}{k-1-j}\left(-1\right)^{j+1}\left(2j+1\right)^{2N+1}

\displaystyle=

\displaystyle\;\;\frac{1}{4^{k}}\sum_{j=0}^{k}\left((2k+1)^{2}\binom{2k+1}{k-j}-8k(2k+1)\binom{2k-1}{k-1-j}\right)\left(-1\right)^{j+1}\left(2j+1\right)^{2N+1}

\displaystyle=

\displaystyle\;\;\frac{1}{4^{k}}\sum_{j=0}^{k}\binom{2k+1}{k-j}\left(-1\right)^{j+1}\left(2j+1\right)^{2N+3}

shows that the choice

c_{N,k}=\frac{1}{4^{k}}\sum_{j=0}^{k}\binom{2k+1}{k-j}\left(-1\right)^{j+1}\left(2j+1\right)^{2N+1}

(3.7)

indeed fulfills above recurrence relation.

\square

Corollary 3.4
.

The matrix
\left(c_{N,k}\right)
for
k,N\in\mathbb{N}_{0}
is a lower triangular matrix with diagonal entries
c_{N,N}=(-1)^{N+1}(2N+1)!
.

Proof
.

We have

\displaystyle\frac{\partial}{\partial x}x^{2k+1}\left(1-\frac{1}{x^{2}}\right)^{2k+1}\bigg\rvert_{x=1}=\;\;

\displaystyle\sum_{j=0}^{2k+1}\binom{2k+1}{j}\left(-1\right)^{j+1}\left(2k+1-2j\right)

\displaystyle=\;\;

\displaystyle\sum_{j=0}^{k}\binom{2k+1}{j}\left(-1\right)^{j+1}\left(2k+1-2j\right)+\sum_{j=0}^{k}\binom{2k+1}{j+k+1}\left(-1\right)^{j+1}\left(2j+1\right)

\displaystyle=\;\;

\displaystyle 2(-1)^{k}\sum_{j=0}^{k}\binom{2k+1}{k-j}\left(-1\right)^{j+1}\left(2j+1\right),

which yields
c_{0,k}=0
for
k\geq 1
. This finding is the initial case for an induction over
N
using
3.6
, which both shows

c_{N,k}=0\;\;\mathrm{for}\;\;k>N\quad\mathrm{and}\quad c_{N,N}=(-1)^{N+1}(2N+1)!.

\square

The next step towards proving Theorem
3.1
is

Proposition 3.5
.

Let the matrix
\left(u_{N,k}\right)
for
N,k\in\mathbb{N}_{0}
be defined by
u_{N,k}:=\frac{\left(-1\right)^{N+1}}{(2N+1)!}c_{N,k}
with the
c_{N,k}
from
(
3.7
)
, i.e.
u_{N,N}=1
. Let
\left(v_{N,k}\right)
be the inverse of
\left(u_{N,k}\right)
. Then the matrix entries
u_{N,k}
and
v_{N,k}
fulfill the recurrence relations

u_{N,k}=-\frac{(2k+1)^{2}}{2N(2N+1)}u_{N-1,k}+\frac{2k(2k+1)}{2N(2N+1)}u_{N-1,k-1}

(3.8)

and

v_{N,k}=\frac{(2N-1)^{2}}{2N(2N+1)}v_{N-1,k}+\frac{2k(2k+1)}{2N(2N+1)}v_{N-1,k-1}.

(3.9)

Proof
.

The first recurrence (
3.8
) follows directly from (
3.6
).

We prove (
3.9
) by induction over the row index
N
of
\left(v_{N,k}\right)
. By definition we have
u_{0,0}=1
and
u_{0,k}=0
for
k>0
. Since
\left(v_{N,k}\right)
is the inverse of
\left(u_{N,k}\right)
, this directly yields
v_{0,0}=1
. Now fix a column index
s
. If we assume (
3.9
) to be true for a row index
N
, we can compute

\displaystyle\sum_{k=s}^{N}v_{N,k}u_{k,s}=

\displaystyle\;\;\sum_{k=s}^{N}\frac{(2N-1)^{2}}{2N(2N+1)}v_{N-1,k}u_{k,s}+\sum_{k=s}^{N}\frac{2k(2k+1)}{2N(2N+1)}v_{N-1,k-1}u_{k,s}

\displaystyle=

\displaystyle\;\;\frac{(2N-1)^{2}}{2N(2N+1)}\sum_{k=s}^{N}v_{N-1,k}u_{k,s}-\sum_{k=s}^{N}\frac{2k(2k+1)}{2N(2N+1)}v_{N-1,k-1}\frac{(2s+1)^{2}}{2k(2k+1)}u_{k-1,s}

\displaystyle+\sum_{k=s}^{N}\frac{2k(2k+1)}{2N(2N+1)}v_{N-1,k-1}\frac{2s(2s+1)}{2k(2k+1)}u_{k-1,s-1}

\displaystyle=

\displaystyle\;\;\frac{(2N-1)^{2}}{2N(2N+1)}\sum_{k=s}^{N}v_{N-1,k}u_{k,s}+\frac{2s(2s+1)}{2N(2N+1)}\sum_{k=s}^{N}v_{N-1,k-1}u_{k-1,s-1}

\displaystyle\sum_{k=N-1}^{N}v_{N,k}u_{k,N-1}=

\displaystyle\;\;\frac{(2N-1)^{2}}{2N(2N+1)}v_{N-1,N-1}u_{N-1,N-1}+\frac{2s(2s+1)}{2N(2N+1)}\sum_{k=N-2}^{N-1}v_{N-1,k}u_{k,N-2}

\displaystyle-\frac{(2N-1)^{2}}{2N(2N+1)}v_{N-1,N-1}u_{N-1,N-1}

\displaystyle=

\displaystyle\;\;0,

where the sum in the middle vanishes because of the induction hypothesis. Finally for

\displaystyle\sum_{k=N}^{N}v_{N,k}u_{k,N}=

\displaystyle\;\;0+\frac{2N(2N+1)}{2N(2N+1)}v_{N-1,N-1}u_{N-1,N-1}+0

\displaystyle=

\displaystyle\;\;1,

.

Finally with this last finding we can solve the linear system for the integrals

\alpha

\Gamma(s+1)(2^{-s+1}-2^{-2s+2})\zeta(s)\alpha^{-s-1}=\int_{0}^{\infty}x^{s}\sech(\alpha x)^{2}dx.

(4.3)

(s,2N)

\Gamma(s+2N)\zeta(s)=(s,2N)2^{s-1}\pi^{s}\frac{\zeta(1-s)}{\cos(\textstyle{\frac{\pi}{2}}s)}.

s\rightarrow-2N

\alpha

\alpha=1
or alternatively be eleminated using a change of variables from

\frac{1}{\alpha}x

\square

We see that the derivatives
\frac{\partial^{2N}}{\partial x^{2N}}\tanh(x)

4.1
. We give them in explicitly in the following proposition:

Proposition 4.3
.

Let
N\in\mathbb{N}
. Then we have

\frac{\partial^{2N}}{\partial x^{2N}}\tanh(x)=\tanh(x)\sum_{k=1}^{N}\left(\frac{2}{4^{k}}\sum_{j=1}^{k}\binom{2k}{k-j}\left(-1\right)^{j}(2j)^{2N}\right)\sech(x)^{2k}.

(4.5)

Proof
.

We use an ansatz of the form

\frac{\partial^{2N}}{\partial x^{2N}}\tanh(x)=\tanh(x)\sum_{k=1}^{N}d_{N,k}\sech(x)^{2k}.

Computing
\frac{\partial^{2N+2}}{\partial x^{2N+2}}\tanh(x)
with above ansatz and comparing coefficients gives for the
d_{N,k}
’s the recurrence relations

\begin{split}d_{N,1}=&\;\;-2^{2N-1}\\
\mathrm{and}\quad d_{N+1,k}=&\;\;4k^{2}d_{N,k}-(2k-1)(2k)d_{N,k-1}\quad\mathrm{for}\;\;k\geq 2.\end{split}

(4.6)

We proceed with

\displaystyle\;\;4k^{2}\frac{2}{4^{k}}\sum_{j=1}^{k}\binom{2k}{k-j}(-1)^{j}(2j)^{2N}

\displaystyle-

\displaystyle\;\;(2k-1)(2k)\frac{2}{4^{k-1}}\sum_{j=1}^{k-1}\binom{2k-2}{k-1-j}(-1)^{j}(2j)^{2N}

\displaystyle=

\displaystyle\;\;\frac{2}{4^{k}}\sum_{j=1}^{k}\left(4k^{2}\binom{2k}{k-j}-4(2k-1)(2k)\binom{2k-2}{k-1-j}\right)(-1)^{j}(2j)^{2N}

\displaystyle=

\displaystyle\;\;\frac{2}{4^{k}}\sum_{j=1}^{k}\binom{2k}{k-j}(-1)^{j}(2j)^{2N+2}

and see that the choice

d_{N,k}=\frac{2}{4^{k}}\sum_{j=1}^{k}\binom{2k}{k-j}\left(-1\right)^{j}(2j)^{2N}

indeed fulfills (
4.6
).

\square

Corollary 4.4
.

The matrix
\left(d_{N,k}\right)
for
N,k\in\mathbb{N}
is a lower triangular matrix with diagonal entries
d_{N,N}=(-1)^{N}(2N)!
.

Proof
.

First note that (
4.6
) also holds for
N=0
. From

\sum_{j=0}^{2k}\binom{2k}{j}(-1)^{j}=0

follows

\displaystyle(-1)^{k}\binom{2k}{k}=

\displaystyle\;\;2\sum_{j=0}^{k-1}\binom{2k}{j-1}(-1)^{j+1}=2\sum_{j=1}^{k}\binom{2k}{j-1}(-1)^{j}=2\sum_{j=1}^{k}\binom{2k}{k-j}(-1)^{k-j+1},

which yields

d_{0,k}=\frac{1}{4^{k}}\binom{2k}{k}.

Then (
4.6
) yields

\displaystyle d_{1,k}=4k^{2}d_{0,k}-(2k-1)(2k)d_{0,k-1}=4k^{2}\frac{1}{4^{k}}\binom{2k}{k}-(2k-1)(2k)\frac{1}{4^{k-1}}\binom{2k-2}{k-1}=0,

for
k\geq 2
. This last finding forms the initial case of an induction over
N
using (
4.6
), which both proves

\displaystyle d_{N,k}=0\;\;\mathrm{for}\;\;k>N\quad\mathrm{and}\quad d_{N,N}=(-1)^{N}(2N)!.

\square

Proposition 4.5
.

Let the matrix
\left(x_{N,k}\right)
for
N,k\in\mathbb{N}
be defined by
x_{N,k}:=\frac{(-1)^{N}}{(2N)!}d_{N,k}
with the
d_{N,k}
from (
4.6
), i.e.
x_{N,N}=1
. Let
\left(y_{N,k}\right)
be the inverse of
\left(x_{N,k}\right)
. Then the matrix entries
x_{N,k}
and
y_{N,k}
fulfill the recurrence relations

x_{N,k}=-\frac{4k^{2}}{(2N-1)2N}x_{N-1,k}+\frac{(2k-1)2k}{(2N-1)2N}x_{N-1,k-1}

(4.7)

and

y_{N,k}=\frac{4(N-1)^{2}}{(2N-1)2N}y_{N-1,k}+\frac{(2k-1)2k}{(2N-1)2N}y_{N-1,k-1}.

(4.8)

Proof
.

The proof of (
4.7
) follows directly from (
4.6
). We proceed to prove (
4.8
) by induction over the row index
N
of
\left(y_{N,k}\right)
. Since
\left(x_{N,k}\right)
is a lower triangular matrix, its inverse
\left(y_{N,k}\right)
is one as well. Then
x_{1,1}=1
directly yields
y_{1,1}=1
. Now fix a column index
s
. If we assume (
4.8
) to be true for a row index
N
, we can compute:

\displaystyle\sum_{k=s}^{N}y_{N,k}x_{k,s}=\;\;

\displaystyle\sum_{k=s}^{N}\frac{4(N-1)^{2}}{(2N-1)(2N)}y_{N-1,k}x_{k,s}+\sum_{k=s}^{N}\frac{(2k-1)(2k)}{(2N-1)(2N)}y_{N-1,k-1}x_{k,s}

\displaystyle=\;\;

\displaystyle\frac{4(N-1)^{2}}{(2N-1)(2N)}\sum_{k=s}^{N}y_{N-1,k}x_{k,s}-\sum_{k=s}^{N}\frac{(2k-1)(2k)}{(2N-1)(2N)}y_{N-1,k-1}\frac{4s^{2}}{(2k-1)(2k)}x_{k-1,s}

\displaystyle+\sum_{k=s}^{N}\frac{(2k-1)(2k)}{(2N-1)(2N)}y_{N-1,k-1}\frac{(2s-1)(2s)}{(2k-1)(2k)}x_{k-1,s-1}

\displaystyle=\;\;

\displaystyle\frac{4(N-1)^{2}}{(2N-1)(2N)}\sum_{k=s}^{N}y_{N-1,k}x_{k,s}+\frac{(2s-1)(2s)}{(2N-1)(2N)}\sum_{k=s}^{N}y_{N-1,k-1}x_{k-1,s-1}

\displaystyle-\frac{4s^{2}}{(2N-1)(2N)}\sum_{k=s+1}^{N}y_{N-1,k-1}x_{k-1,s}

All of the last three sums vanish for
s<N-1
because of the induction hypothesis. For
s=N-1
we obtain

\displaystyle\sum_{k=s}^{N}y_{N,k}x_{k,N-1}=\;\;

\displaystyle\frac{4(N-1)^{2}}{(2N-1)(2N)}+\frac{(2N-3)(2N-2)}{(2N-1)(2N)}\sum_{k=N-2}^{N-1}y_{N-1,k}x_{k,N-2}

\displaystyle-\frac{4(N-1)^{2}}{(2N-1)(2N)}y_{N-1,N-1}x_{N-1,N-1}

\displaystyle=\;\;

\displaystyle 0,

where the sum in the middle vanishes because of the induction hypothesis. Finally for
s=N
we get

\displaystyle\sum_{k=s}^{N}y_{N,k}x_{k,N}=\;\;

\displaystyle 0+\frac{(2N-1)(2N)}{(2N-1)(2N)}y_{N-1,N-1}x_{N-1,N-1}+0

\displaystyle=\;\;

\displaystyle 1,

then we can conclude that (
4.8
) indeed must be true.

\square

At last we can complete the proof of Theorem
4.1
with

Corollary 4.6
.

The matrix entries
y_{N,k}
fulfilling (
4.8
) are explicitly given by

y_{N,k}=(2k)!\frac{2^{2N-2k}}{N^{2}\binom{2N}{N}}h_{k,N},

(4.9)

with the
h_{k,N}
as defined in (
4.1
).

Proof
.

Plugging (
4.9
) into (
4.8
) and simplifying gives

h_{k,N}=h_{k,N-1}+\frac{1}{(N-1)^{2}}h_{k-1,N-1},

which is equivalent to the definition of the
h_{k,N}
’s in (
4.1
).

\square

Now we can explicitly invert the linear system of equations for the integrals
\int_{0}^{\infty}\frac{1}{x}\tanh(x)\sech(x)^{2N}dx
given by (
4.2
) and the claim of Theorem
4.1
is finally proved.

5
Relation to known Results

Over the years, a plethora of recurrence relations for the zeta values
\zeta(2k+1)
for
k\in\mathbb{N}
was discovered. One of the earliest examples already found by Euler, which involves the double zeta function

\displaystyle\zeta_{2}(s,t):=\sum_{n>m>0}\frac{1}{n^{s}m^{t}}=\sum_{n=1}^{\infty}\frac{1}{n^{s}}\sum_{m=1}^{n-1}\frac{1}{m^{t}},

is outlined
[
3
]
in and given for integer
s>1
and even
a>0
and odd
b>1
by

\displaystyle\zeta_{2}(s,1)

\displaystyle=\frac{1}{2}s\zeta(s+1)-\frac{1}{2}\sum_{k=1}^{s-2}\zeta(k+1)\zeta(s-k),

\displaystyle\zeta_{2}(a,b)

\displaystyle=\zeta(a)\zeta(b)+\frac{1}{2}\left\{\binom{a+b}{a}-1\right\}\zeta(a+b)

\displaystyle-\sum_{j=1}^{\frac{1}{2}(a+b-3)}\left\{\binom{2j}{a-1}+\binom{2j}{b-1}\right\}\zeta(a+b-2j-1)\zeta(2j+1),

\displaystyle\zeta_{2}(b,a)

\displaystyle=-\frac{1}{2}\left\{1+\binom{a+b}{a}\right\}\zeta(a+b)

\displaystyle+\sum_{j=1}^{\frac{1}{2}(a+b-3)}\left\{\binom{2j}{a-1}+\binom{2j}{b-1}\right\}\zeta(a+b-2j-1)\zeta(2j+1).

Another recurrence relation for the
\zeta(2k+1)
is found in
[
4
]
and given by

\displaystyle\zeta(2m+1)=

\displaystyle\frac{1}{2^{2m+1}-1}\bigg((-1)^{m+1}\frac{(2\pi)^{2m}\log(2)}{(2m)!}-\sum_{r=1}^{m-1}(-1)^{r}\frac{(2\pi)^{2r}\left(2^{2m-2r}-1\right)}{(2r)!}\zeta(2m+1-2r)

\displaystyle+(-1)^{m}\frac{4^{2m}}{(2m)!}\int_{0}^{\frac{\pi}{2}}z^{2m}\cot(z)dz\bigg).

Finally relations both involving
\zeta(2n+1)
and
\beta(2n)
are found in
[
5
]
and given by

\displaystyle\psi^{(2n-1)}\left(\frac{1}{4}\right)

\displaystyle=\frac{4^{2n-1}}{2n}\left(\pi^{2n}\left(2^{2n}-1\right)\left|B_{2n}\right|+2(2n)!\beta(2n)\right),

\displaystyle\psi^{(2n-1)}\left(\frac{3}{4}\right)

\displaystyle=\frac{4^{2n-1}}{2n}\left(\pi^{2n}\left(2^{2n}-1\right)\left|B_{2n}\right|-2(2n)!\beta(2n)\right),

\displaystyle\psi^{(2n)}\left(\frac{1}{4}\right)

\displaystyle=2^{2n-1}\left(-\pi^{2n+1}\left|E_{2n}\right|-2(2n)!\left(2^{2n+1}-1\right)\zeta(2n+1)\right),

\displaystyle\psi^{(2n)}\left(\frac{3}{4}\right)

\displaystyle=2^{2n-1}\left(\pi^{2n+1}\left|E_{2n}\right|-2(2n)!\left(2^{2n+1}-1\right)\zeta(2n+1)\right).

Here
\psi^{(k)}(z):=\frac{d^{k+1}}{dz^{k+1}}\log(\Gamma(z))
denotes the polygamma function,
B_{2n}
are the Bernoulli numbers and
E_{2n}
are the Euler numbers.

All of the above formulae involve “error terms” like
\zeta_{2}(a,b)
,
\int_{0}^{\frac{\pi}{2}}z^{2m}\cot(z)dz
and
\psi^{(2n-1)}\left(\frac{1}{4}\right)
, which are to this day not known to have simple evaluations in terms of common mathematical constants. The same is true for the recurrence relations for
\zeta(2k+1)
and
\beta(2k)
derived in this work, so the algebraic nature of these constants still remains a mystery.

In
[
6
]
Iaroslav Blagouchine presented the integral representations

\beta(2)=\frac{\pi}{2}\int_{1}^{\infty}\frac{x^{4}-6x^{2}+1}{(x^{2}+1)^{3}}\log(\log(x))dx

(5.1)

and

\zeta(3)=\frac{8\pi^{2}}{7}\int_{1}^{\infty}\frac{(x^{4}-4x^{2}+1)x}{(x^{2}+1)^{4}}\log(\log(x))dx.

(5.2)

By first performing a change of variables from
x
to
y=\log(x)
and then applying partial integration using
\frac{d}{dx}\log(\log(x))=\frac{1}{x\log(x)}
one can show for any
L>0
that

\int_{0}^{\infty}\frac{\tanh(x)}{x}\sech(x)^{L}dx=2^{L}\int_{1}^{\infty}\frac{(Lx^{4}-2(L+2)x^{2}+L)x^{L-1}}{(x^{2}+1)^{L+2}}\log(\log(x))dx.

(5.3)

For
N\in\mathbb{N}
, using above finding and by combining (
3.2
) with (
3.5
), we can generalize (
5.1
) to

\displaystyle\beta(2N)=

\displaystyle(-1)^{N}\frac{\pi^{2N-1}}{2^{2N-1}(2N-1)!}\int_{1}^{\infty}\sum_{k=0}^{N-1}\Bigg(\sum_{j=0}^{k}\binom{2k+1}{k-j}\left(-1\right)^{j+1}\left(2j+1\right)^{2N-1}

\displaystyle\times\frac{((2k+1)x^{4}-2(2k+3)x^{2}+2k+1)x^{2k}}{(x^{2}+1)^{2k+3}}\Bigg)\log(\log(x))dx

and analogously we can generalize (
5.2
) by combining (
4.2
) with (
4.5
) to

\displaystyle\zeta(2N+1)=

\displaystyle(-1)^{N}\frac{2\pi^{2N}}{\left(2^{2N+1}-1\right)(2N)!}\int_{1}^{\infty}\sum_{k=1}^{N}\Bigg(\sum_{j=1}^{k}\binom{2k}{k-j}\left(-1\right)^{j}(2j)^{2N}

\displaystyle\times\frac{(2kx^{4}-2(2k+2)x^{2}+2k)x^{2k-1}}{(x^{2}+1)^{2k+2}}\Bigg)\log(\log(x))dx.

6
Background and Motivation

The hyperbolic-cotangent-version of Ramanujan’s famous formula for
\zeta(2k+1)

\begin{split}&\pi\alpha^{-N}\sum_{n=1}^{\infty}\frac{\coth(\alpha\pi n)}{n^{2N+1}}-\pi(-\alpha)^{N}\sum_{n=1}^{\infty}\frac{\coth(\frac{1}{\alpha}\pi n)}{n^{2N+1}}\\
=\;\;&\zeta(2N+2)\alpha^{-N-1}\\
-&\;2\sum_{k=1}^{N}(-1)^{k}\zeta(2k)\zeta(2N+2-2k)\alpha^{2k-N-1}\\
+&\;\zeta(2N+2)(-\alpha)^{N+1},\end{split}

(6.1)

which holds true for all
\alpha\in\mathbb{R}\setminus\{0\}
and
N\in\mathbb{N}
, c.f.
[
7
]
, was the starting point for a first proof of
(
4.1
)
. By repeatedly applying the operator
\alpha^{2}\frac{\partial}{\partial\alpha}
on
(
6.1
)
and after some computations the limit identity

\lim_{\alpha\to 0_{+}}\sum_{n=1}^{\infty}\frac{1}{n}\frac{\sinh(\alpha n)}{\cosh(\alpha n)^{2N+1}}=\frac{2^{2N}}{N^{2}\binom{2N}{N}}\sum_{k=1}^{N}(2-2^{-2k})(2k)!h_{k,N}\frac{\zeta(2k+1)}{\pi^{2k}}

(6.2)

was obtained, where the
h_{k,N}
are defined as in
(
4.1
)
. Then applying the Abel-Plana summation formula on the left hand side of
(
6.2
)
, taking the limit
\alpha\to 0_{+}
and a simple change of variables finally yielded
(
4.1
)
.

For a proof of
(
3.1
)
the author tried in vain a similar strategy on the identity

\begin{split}&\frac{\pi}{4}\alpha^{-N}\sum_{n=0}^{\infty}\frac{(-1)^{n}\sech(\alpha\pi(n+\frac{1}{2}))}{(2n+1)^{2N+1}}+\frac{\pi}{4}(-\alpha)^{N}\sum_{n=0}^{\infty}\frac{(-1)^{n}\sech(\frac{1}{\alpha}\pi(n+\frac{1}{2}))}{(2n+1)^{2N+1}}\\
=\;\;&\sum_{k=0}^{N}(-1)^{k}\beta(2k+1)\beta(2N+1-2k)\alpha^{2k-N},\end{split}

(6.3)

which is valid for all
\alpha\in\mathbb{R}\setminus\{0\}
and
N\in\mathbb{N}_{0}
. Neither was such an attempt fruitful for

\begin{split}&\pi\alpha^{-N}\sum_{n=1}^{\infty}\frac{(-1)^{n}\csch(\alpha\pi n)}{n^{2N+1}}-\pi(-\alpha)^{N}\sum_{n=1}^{\infty}\frac{(-1)^{n}\csch(\frac{1}{\alpha}\pi n)}{n^{2N+1}}\\
=\;-&\;\big(1-2^{-2N-1}\big)\zeta(2N+2)\alpha^{-N-1}\\
-&\;2\sum_{k=1}^{N}(-1)^{k}\big(1-2^{1-2k}\big)\zeta(2k)\big(1-2^{2k-2N-1}\big)\zeta(2N+2-2k)\alpha^{2k-N-1}\\
-&\;\big(1-2^{-2N-1}\big)\zeta(2N+2)(-\alpha)^{N+1}\end{split}

(6.4)

and for

\begin{split}&\frac{\pi}{4}\alpha^{-N}\sum_{n=0}^{\infty}\frac{\tanh(\alpha\pi(n+\frac{1}{2}))}{(2n+1)^{2N+1}}-\frac{\pi}{4}(-\alpha)^{N}\sum_{n=0}^{\infty}\frac{\tanh(\frac{1}{\alpha}\pi(n+\frac{1}{2}))}{(2n+1)^{2N+1}}\\
=\;\;&\sum_{k=1}^{N}(-1)^{k+1}\big(1-2^{-2k})\zeta(2k)\big(1-2^{2k-2N-2}\big)\zeta(2N+2-2k)\alpha^{2k-N-1}\end{split}

(6.5)

which are true for all
\alpha\in\mathbb{R}\setminus\{0\}
and
N\in\mathbb{N}
. As a conclusion the author proceeded to prove
(
3.1
)
and
(
4.1
)
by elementary means using the functional equations of
\beta(s)
and
\zeta(s)
respectively.

Note that all the equations
(
6.1
)
-
(
6.5
)
can be proved elementarily using the series expansions

\displaystyle\coth(x)

\displaystyle=\frac{1}{x}+\sum_{k=1}^{\infty}\frac{2x}{k^{2}\pi^{2}+x^{2}},

\displaystyle\tanh(x)

\displaystyle=\sum_{k=0}^{\infty}\frac{8x}{(2k+1)^{2}\pi^{2}+4x^{2}},

\displaystyle\sech(x)

\displaystyle=\sum_{k=0}^{\infty}(-1)^{k}\frac{(8k+4)\pi}{(2k+1)^{2}\pi^{2}+4x^{2}},

\displaystyle\csch(x)

\displaystyle=\frac{1}{x}+\sum_{k=1}^{\infty}(-1)^{k}\frac{2x}{k^{2}\pi^{2}+x^{2}}

paired with

\displaystyle\zeta(s)

\displaystyle=\sum_{n=1}^{\infty}\frac{1}{n^{s}},

\displaystyle\lambda(s)

\displaystyle=\sum_{n=0}^{\infty}\frac{1}{(2n+1)^{s}}=\left(1-2^{-s}\right)\zeta(s),

\displaystyle\beta(s)

\displaystyle=\sum_{n=0}^{\infty}\frac{(-1)^{n}}{(2n+1)^{s}},

\displaystyle\eta(s)

\displaystyle=\sum_{n=1}^{\infty}\frac{(-1)^{n}}{n^{s}}=\left(1-2^{1-s}\right)\zeta(s)

respectively and repeatedly utilizing the simple algebraic identities

\frac{1}{\alpha^{2}n^{2}\pi^{2}}\;\frac{1}{k^{2}\pi^{2}+\alpha^{2}n^{2}\pi^{2}}=\frac{1}{k^{2}\pi^{2}}\left(\frac{1}{\alpha^{2}n^{2}\pi^{2}}-\frac{1}{k^{2}\pi^{2}+\alpha^{2}n^{2}\pi^{2}}\right)

and

\begin{split}&\frac{1}{\alpha^{2}(2n+1)^{2}\pi^{2}}\;\frac{1}{(2k+1)^{2}\pi^{2}+4\alpha^{2}(n+\frac{1}{2})^{2}\pi^{2}}\\
=\;&\frac{1}{(2k+1)^{2}\pi^{2}}\left(\frac{1}{\alpha^{2}(2n+1)^{2}\pi^{2}}-\frac{1}{(2k+1)^{2}\pi^{2}+4\alpha^{2}(n+\frac{1}{2})^{2}\pi^{2}}\right).\end{split}
