Edge station deployment by fewest covered user first for cost improvement
Authors: Kaili Shao, Yuping Wang, Bo Wang, Yongxuan Sang
Published: 2026

ABSTRACT
AbstractIn this paper, we address the edge station deployment problem (ESDP), which aims to determine optimal sites for deploying edge stations so as to maximize user coverage and minimize deployment cost. We first formulate the ESDP as a binary linear programming model and prove its NP-hardness by reducing the set covering problem to a specialized instance of ESDP. To solve the ESDP in polynomial time, we propose a novel heuristic algorithm that prioritizes covering users who are within range of the fewest candidate sites. Our algorithm iteratively selects the site that can cover the most users from among the candidate sites capable of covering those least-covered users. To evaluate the performance of our algorithm, we conduct simulation experiments based on a real-world dataset. Experimental results demonstrate that our algorithm achieves 100% user coverage with lower deployment cost compared to several classical and state-of-the-art algorithms.Keywords: Edge cloud, Edge computing, Placement, DeploymentSubject terms: Engineering, Mathematics and computing

Introduction

Edge computing has gained significant traction in both academia and industry, largely driven by advances in smart devices and communication technologies1,2. As a complement to cloud computing, it enables real-time services by deploying server resources closer to end users, thereby facilitating ultra-low latency communication between service requesters (user devices) and service processors (edge servers)3–5. To enhance service quality and resource efficiency, considerable research has focused on task scheduling and resource management. However, only a limited number of studies have addressed the edge station deployment problem (ESDP).

ESDP represents a fundamental decision that must be made prior to delivering services in edge computing environments. It involves determining where to deploy edge stations equipped with various access points (e.g., 5G base stations and Wi-Fi routers), such that users can communicate with edge resources while minimizing the provider’s deployment costs. Existing research has primarily focused on improving service provisioning in edge computing, covering areas such as edge server placement6,7, edge service caching8,9, and task offloading10, often assuming that a solution to ESDP is already given. Therefore, our work complements these studies by explicitly addressing ESDP.

The primary objective of ESDP is to optimize user coverage, i.e., to maximize the number of users within the signal range of at least one edge station. This is essential because a user can only benefit from edge computing services if it can communicate with an edge station. Consequently, to ensure service quality, it is desirable to cover all users with edge stations. While maximizing coverage, it is also crucial to minimize the cost of deployed edge stations, as profitability remains a key concern for service providers. Given that edge stations typically incur similar deployment costs, we treat the number of deployed stations as a secondary optimization objective in this paper. Reducing the number of stations also helps lower operational costs by simplifying edge resource management.

Existing approaches for solving ESDP can be broadly categorized into three types: heuristic-based11,12, cluster-based13–15, and meta-heuristic-based algorithms16–18. Heuristic-based methods typically iteratively select the candidate site covering the most users until all users are covered or no sites remain. However, this greedy strategy may lead to an excessive number of stations being deployed in later stages to cover geographically scattered users. Cluster-based approaches first group users based on location and then select candidate sites closest to the cluster centers as deployment positions. A drawback of such methods is that some users may fall outside the signal range of their assigned cluster center, thereby reducing coverage. Meta-heuristic algorithms employ global search strategies inspired by social or natural phenomena to seek optimal solutions. Nevertheless, when applied to ESDP, these methods often suffer from performance instability due to randomness, and they may be prone to local optima depending on parameters and instance size.

To address the aforementioned limitations, this paper proposes a novel heuristic algorithm for ESDP called fewest covered user first (FCUF). The core idea of FCUF is to prioritize covering users that are within range of the fewest candidate sites, as such users are more likely to require dedicated stations for coverage in later stages. In each iteration, FCUF identifies the user covered by the fewest candidate sites and selects, from among those covering this user, the candidate site that covers the largest number of users. we consider a static set of users, identical types of edge stations with a deterministic, circular coverage radius. These assumptions allow us to focus on the fundamental trade-off between coverage and deployment cost in a tractable model, which serves as the crucial first step in strategic network planning. Subsequent operational optimizations, such as dynamic resource allocation or handling heterogeneous hardware, can build upon this foundational placement solution. Related work

With advantages in security, ultra-low latency, and high reliability, edge computing has garnered significant attention in recent years. Extensive research has focused on enhancing services through edge computing across various dimensions, such as task offloading, service placement, and edge caching. This paper addresses the edge station deployment problem (ESDP), aiming to optimize deployment costs while ensuring satisfactory user coverage.

Direct studies on ESDP remain limited. Gui et al.12 adopted a best-fit-like strategy, prioritizing stations that offer the greatest performance improvement. Xing et al.16 proposed a hybrid meta-heuristic named PGSAO to optimize both coverage and the number of deployed stations. Their method integrates concepts from genetic algorithms (GA) and particle swarm optimization (PSO), utilizing GA’s evolutionary framework while allowing chromosomes to crossover with their personal best and the global best positions to leverage both self and social intelligence. Shen et al.17 enhanced PSO for ESDP by introducing a splitting mechanism, where each particle splits into two offspring with distinct positions for coordinated updates. Li and Jia18 applied the non-dominated sorting genetic algorithm III (NSGA-III) to simultaneously minimize the number of stations and maximize coverage.

By viewing candidate sites as potential locations for edge servers, ESDP aligns closely with the edge server placement problem (ESPP), which decides where to deploy servers to process user requests. Chen et al.11 introduced a heuristic for ESPP that iteratively selects the station covering the most uncovered users. Qiu et al.19 presented a greedy access point placement strategy, associating each station with the strongest-signal access point to maximize coverage. Jasim and Al-Raweshidy20 proposed an ESPP algorithm that prioritizes stations with the highest connectivity. Li et al.13 developed two ESPP methods: a top-k approach that deploys servers at the k busiest stations, and a clustering approach using K-Means++ to group stations and place k servers nearest to k cluster centers.

While heuristic algorithms offer quick solutions with modest performance due to their local search nature, some studies employ global optimization techniques to better balance solution quality and computation time. Zhang et al.21 combined k-means clustering under distance constraints with a genetic algorithm to select optimal server locations. Lu et al.22 modeled ESPP as a Markov decision process and applied deep Q-Networks to optimize coverage, load balance, and delay. Tiwari et al.23 utilized the grey wolf optimizer, showing superior performance over greedy, random, and k-means baselines on a real-world dataset. Wang et al.24 hybridized a genetic algorithm with a grey wolf-inspired mutation strategy. For delay-minimizing ESPP, Li et al.25 designed an improved genetic algorithm incorporating elite preservation, tabu search, and niche sharing to ensure convergence and avoid premature stagnation.

Several works consider dynamic server repositioning. Chen and Guo26 and Jiang et al.27 employed deep reinforcement learning to adjust placements for energy and cost efficiency, respectively. However, in practice, post-deployment server migration is often prohibitively expensive, limiting the immediate applicability of such dynamic approaches.

Most aforementioned studies either overlook computational latency or assume homogeneous server capabilities, thereby restricting their applicability in scenarios with uneven user densities, variable workloads, and diverse server options. To address this, Tiwari et al.28 studied ESPP with heterogeneous servers, using particle swarm optimization for deployment and dynamic programming for capacity allocation. Despite their potential, global optimization methods are computationally intensive and offer no performance guarantees, especially at scale. For instance, on the EUA dataset, PGSAO16 requires roughly five hours to produce a solution needing over 3000 stations for full coverage. In contrast, our proposed FCUF achieves 100% coverage with only about 2,000 stations in approximately 20 min, demonstrating superior efficiency and scalability.

Motivation

In this section, we use a simple ESDP case, depicted in Fig. 1a, to illustrate the motivation behind our proposed method. The case consists of 6 users (represented by small solid circles) and 3 candidate edge stations (triangles). The large dashed circles indicate the coverage area of each station.

A simple ESDP case. (a) The distribution of users and candidate stations. (b) The intermediate result of conventional heuristic algorithms. (c) The (intermediate) result of cluster-based algorithms. (d) The result of our approach.

For conventional heuristic algorithms, the candidate station covering the most users is selected first. In this example, the Station 2 would be chosen for deployment, as shown in Fig. 1b. Consequently, the remaining two stations must also be deployed to cover the leftmost and rightmost users (shown as blue-filled circles). Thus, following this heuristic approach, all three candidate stations would be required to achieve full user coverage.

In cluster-based approaches, stations are deployed at locations closest to the centers of user clusters. In the Fig. 1 example, this leads to selecting Stations 2 and 3, which fails to cover the leftmost user (Fig. 1c). This demonstrates a common failure mode: peripheral users may lie outside the coverage radius of the station assigned to their cluster center.

In contrast to existing methods, our proposed FCUF algorithm introduces a distinct strategy centered on a key metric: the number of candidate sites covering a user. This metric identifies users who are the hardest to serve, those with the fewest connection options. By prioritizing coverage for these “bottleneck” users early in the process, the algorithm proactively prevents the inefficiency encountered by methods like Greedy, which often must deploy numerous extra stations in later stages to cover sparse, isolated users.

The simplified illustrative case in Fig. 1d demonstrates this logic. Here, users at the periphery are covered by only one candidate site each. FCUF prioritizes these users, leading to the deployment of Station 1 and Station 3. Remarkably, this two-station deployment covers all six users, avoiding the need for a third station, which the greedy strategy would require.

Problem formulation

For the ESDP, a multitude of candidate sites are typically available for deploying edge stations to serve users. Generally constrained by geographical conditions and urban planning, these candidate sites are geographically dispersed. For instance, China Tower Company manages over 2.1 million candidate sites across China, which are planned for construction or upgrade into 5G base stations to support various edge service providers, such as Chinese telecommunications companies29. Since wireless network equipment has limited signal transmission ranges, each deployed edge station can only communicate with and accept requests from users within its circular coverage area. Thus, the objective of ESDP is to maximize the number of users covered by the deployed edge stations, i.e., user coverage, thereby enabling more users to benefit from edge resources for improved service quality. Additionally, to ensure the profitability of service providers, the deployment cost of edge stations should also be minimized. Fewest covered user first deployment method

Having established the NP-completeness of ESDP in the previous section, it is clear that no polynomial-time exact algorithm can guarantee an optimal solution. To address this challenge, this section presents a heuristic algorithm designed to overcome a key limitation of existing approaches, specifically their tendency to require an excessive number of edge stations to cover geographically scattered users in later stages.

Our proposed algorithm, named fewest covered user first (FCUF), is guided by a straightforward principle: it prioritizes serving the user covered by the fewest candidate sites. The complete procedure is detailed in Algorithm 1. In line with common engineering objectives, our method aims to minimize the number of deployed stations while maintaining full user coverage. This not only aligns with reducing deployment costs but also helps lower operational complexity, which typically increases with system scale. Accordingly, FCUF iteratively selects the candidate site that covers the most users from among those capable of serving the currently least-covered user.

First, FCUF computes the distance between each candidate site and every user using Eq. (1) (line 2). Based on the maximum communication range of an edge station, it then determines the coverage relationships between users and candidate sites according to Eq. (2) (line 3). Following this initialization, FCUF enters a loop (line 4) in which it repeatedly selects a candidate site for deployment until all users are covered or no candidate sites remain. Each iteration consists of three steps:

FCUF counts, for each still-uncovered user, how many candidate sites can cover that user (line 5). It then identifies the uncovered user that is covered by the fewest candidate sites (line 6).

For every candidate site that covers the user found in the previous step, FCUF counts how many uncovered users that site can cover (line 7). The candidate site that covers the largest number of uncovered users is selected for deployment (line 8).

Experiment environment

We conduct simulations based on the EUA dataset30,31 to evaluate algorithm performance. The dataset contains geographical locations of 9,318 cellular base stations (candidate sites) and 131,312 synthetically generated users distributed across the Melbourne metropolitan area. To reduce computational overhead, spherical coordinates are converted to a cylindrical projection, where one degree of longitude or latitude corresponds to approximately 111,111 meters. The communication range of each edge station is set to 1,000 meters.

Experiment results

Comparison with optimal solutions on small-scale instances

The small-scale ESDP instances was configured with 5, 10, 15, and 20 randomly generated candidate site locations, and user locations were randomly generated at a ratio of ten times the number of candidate sites. The coverage and deployment cost results are summarized in Figs. 2 and 3.

The coverage achieved by various algorithms including the optimum (higher is better).

The number of deployed edge stations achieved by various algorithms including the optimum (less is better).

The optimal solution, Greedy, FF, Kmeans-R, GA, and FCUF consistently achieve 100% coverage across all scales. In contrast, Kmeans and Kmeans-B show significant coverage deficiencies, particularly with fewer candidate sites (e.g., 55.6% for Kmeans and 0% for Kmeans-B with 5 sites), validating their inherent flaw in leaving peripheral users uncovered. PSO also fails to guarantee full coverage as the problem scale increases, dropping to 86% with 20 candidate sites, indicating its solution quality can be unstable. This instability stems from two factors. First, the small-scale random instances lack spatial structure, creating irregular coverage patterns that increase the risk of premature convergence to local optima. Second, PSO’s swarm dynamics rely heavily on the attraction of global and personal best positions, which can cause the population to converge prematurely when the search space is small and diversity is limited.

FCUF and GA deliver the most cost-effective solutions, matching the optimal deployment count in 3 out of 4 cases and deviating by only 1 station in the remaining case. This demonstrates their superior ability to closely approximate the global optimum. Greedy and FF exhibit a consistent but small optimality gap, requiring 1-2 more stations than the optimum, which aligns with their known performance bounds. Kmeans and Kmeans-B sometimes deploy fewer stations (e.g., 12 vs. 14), but this comes at the severe expense of coverage, making their solutions infeasible for the full-coverage objective. This highlights a critical trade-off. PSO shows irregular cost performance; while it finds a low-cost solution with 15 sites (11 stations), this corresponds to a poor coverage of only 90.9%, again showing a compromise between objectives. Kmeans-R guarantees coverage but incurs the highest cost among feasible solvers (18 stations for 20 sites), indicating inefficiency.

This small-scale analysis provides two key insights: First, it confirms that FCUF is a highly effective heuristic, consistently achieving full coverage at a cost nearly identical to the proven global optimum and outperforming other heuristics and meta-heuristics in balancing both objectives. Second, it clearly exposes the fundamental limitations of standard clustering-based methods (Kmeans, Kmeans-B) in ensuring coverage and the potential instability of pure meta-heuristics like PSO in consistently finding high-quality, feasible solutions.

Performance with complete dataset

Figure 4 presents the coverage achieved by each algorithm. As shown, Greedy, FF, Kmeans-R, and FCUF consistently achieve 100% coverage. This is because their search processes continue until all users are covered. In contrast, Kmeans and Kmeans-B achieve approximately 99.96% coverage, meaning about 45 user locations remain uncovered by the deployed edge stations. This occurs primarily because both algorithms first cluster user locations and then deploy stations at the candidate sites closest to the cluster centers. Consequently, some users located on the peripheries of clusters may fall outside the coverage range of their assigned stations. For Kmeans-B, although it ensures that the distance from every user to its cluster center does not exceed the station’s signal range, the actual candidate site may not coincide with the cluster center, so full coverage is still not guaranteed.

Following the idea behind Kmeans-B, one could modify Kmeans to enforce a full coverage constraint by bounding user distances to the candidate sites nearest to the cluster centers, rather than to the centers themselves. However, this constraint is often too restrictive, potentially leading to two issues: the absence of a feasible clustering solution and an excessive number of resulting clusters, which corresponds to an unnecessarily high number of deployed stations.

Figure 4 indicates that both the PSO and GA algorithms consistently achieve a 100% coverage rate. This result effectively demonstrates their powerful global search capability in exploring the solution space and identifying feasible deployment schemes that satisfy the comprehensive coverage constraint. Their success confirms the potential of meta-heuristic approaches for solving ESDP and inspires several promising directions for future investigation. While they can find high-quality solutions, their relatively high computational cost highlights the need for efficiency improvements. A compelling research path is the hybridisation of methods. For instance, we will consider to use efficient deterministic heuristics like FCUF to generate high-quality initial solutions for meta-heuristics, or design adaptive mechanisms that balance global exploration with local exploitation. These observations provide valuable insights for guiding the design of more effective and efficient algorithms in future work.

Figure 5 reports the number of deployed edge stations required by each algorithm to achieve the coverages described above. The results indicate that FCUF uses between 6.75% and 72.0% fewer stations than the other algorithms. Therefore, FCUF attains full user coverage with the fewest deployed stations, demonstrating the superior performance of our ESDP solution. This advantage stems mainly from its strategy of selecting the candidate site that covers the most users from among those covering the hardest-to-serve user. This approach helps avoid the situation where sparsely distributed users in later stages require many additional stations, which is the main reason greedy requires more stations than FCUF. As for the K-means-based algorithms, although user density is high near cluster centers, many users often reside on cluster peripheries, leading to a similar issue as observed in Greedy.

Compared with PSO and GA, FCUF reduces the number of deployed edge stations by 59.0% and 53.1%, respectively. This result highlights a key observation: although PSO and GA possess strong global search capabilities, their performance in solving large-scale ESDP instances is outperformed not only by FCUF but also by simpler heuristic approaches such as greedy and FF. The primary reason lies in the nature of meta-heuristic algorithms when applied to high-dimensional, large-scale optimization problems, i.e., the curse of dimensionality. Depending on instance characteristics, parameter settings, and available computational budget, meta-heuristics such as PSO and GA may converge prematurely to local optima, making it challenging to consistently guarantee the global optimum. In contrast, deterministic heuristics like FCUF, with their problem-aware greedy-like mechanisms, can more reliably produce competitive solutions for deployment-oriented scenarios where both coverage guarantee and cost efficiency are critical.

Figure 6 compares the computation time consumed by each algorithm for solving ESDP. FF is the fastest, while FCUF is faster than all other methods except FF. The reasons are as follows. FF has a worst-case time complexity of O(US), as it examines the coverage of all users for one candidate site per iteration. Greedy shares the same O(USI) complexity as FCUF, where I denotes the number of iterations, because it searches for the candidate site covering the most users in each round. Since both greedy and FCUF select one site per iteration, . Kmeans has a complexity of O(USL), where L is its clustering iteration count, because it computes distances between users and cluster centers repeatedly. Hence, FF requires the least time. Greedy takes longer than FCUF mainly because it undergoes more iterations, as it leaves behind scattered users that demand extra stations in later stages. Kmeans runs faster than greedy primarily because its iteration count L is typically lower than Greedy’s I. FCUF outperforms Kmeans in speed for two key reasons: first, FCUF usually requires fewer iterations (); second, the numbers of uncovered users and available candidate sites gradually decrease during FCUF’s execution, whereas they remain constant in Kmeans. Finally, Kmeans-B is considerably slower than Kmeans because it executes Kmeans multiple times and must verify the distance constraint for each clustering outcome.

Regarding PSO and GA, their runtimes are greater than those of FF and FCUF but less than greedy and Kmeans-B. This is because, as population-based meta-heuristics, their computational overhead per iteration is higher than that of simple heuristics, involving fitness evaluation of multiple candidate solutions and updates of population states. However, they often converge within a controllable number of generations without requiring the exhaustive, incremental station selection of greedy or the repeated clustering of Kmeans-B, thus avoiding the most extreme time costs.

As shown in Fig. 7, all algorithms except Kmeans-B achieve 100% coverage. Meta-heuristic algorithms PSO and GA, along with heuristic methods Greedy, FF, Kmeans-R, and FCUF, terminate only when every user is covered, which explains their consistent perfect coverage. Kmeans also attains full coverage in this set of experiments, likely because the fraction of users it leaves uncovered is very small (below 0.05%, as indicated in Fig. 4), making uncovered users a rare occurrence in these trials. For Kmeans-B, although it enforces a distance bound between each user and its cluster center, the actual candidate site selected may not coincide exactly with the center. This offset can leave some peripheral users outside the coverage of deployed stations. The slight improvement in Kmeans-B’s coverage as user count rises is due to the decreasing proportion of uncovered users when the total number of users increases.

Figure 8 illustrates how the number of deployed edge stations varies with increasing user counts. As expected, a larger user population generally requires more stations to ensure coverage. In all tested scenarios, FCUF consistently deploys the fewest edge stations while still achieving full coverage, further confirming its superior performance in solving ESDP compared to the other benchmark algorithms. Notably, all algorithms exhibit a sub-linear growth in the number of deployed stations as users increase, indicating favorable scalability with respect to user scale. This sub-linear trend suggests that the marginal cost of covering additional users decreases as the system expands, reflecting efficient resource utilization in larger-scale deployments.

Figure 9 shows that the running time of every algorithm grows linearly with the number of users. This observation aligns with the time complexity analysis provided in the Method section and the Overall Performance subsection, further confirming the scalability of these algorithms with respect to user scale. Among them, the time consumed by greedy increases more rapidly than that of all other algorithms except Kmeans-B. The main reason is that during the later stages of Greedy, the remaining uncovered users tend to be sparsely distributed. In this situation, greedy selects a candidate site covering very few users in each of the final iterations, resulting in a large total number of iterations. This inefficiency becomes more pronounced as the number of users grows. In comparison, while PSO and GA also exhibit linear time growth, their per-iteration overhead is higher than that of FF or FCUF due to population maintenance and global operations; however, they typically converge in fewer iterations than Greedy, resulting in overall runtimes that are lower than greedy but higher than the fastest heuristics.

As shown in Fig. 10, Greedy, FF, Kmeans-R, FCUF, PSO, and GA consistently achieve 100% coverage across all candidate site scales. This result aligns with their design principles: the heuristic and meta-heuristic algorithms continue selecting sites until every user is covered. In contrast, Kmeans and Kmeans-B fail to reach full coverage. The underlying reasons are consistent with the earlier analysis: both algorithms rely on clustering users and selecting the candidate site nearest to each cluster center. Since the selected site may not perfectly coincide with the cluster center, users located near the cluster periphery can remain outside the effective signal range, leading to persistent coverage gaps even as the pool of candidate sites expands.

Figure 11 demonstrates that the number of deployed edge stations increases with the number of candidate sites. This trend can be explained by the experimental setup: while the total user count was fixed at 10,000, the number of users that are actually coverable by at least one candidate site rises as the pool of available sites expands, from an average of 5313 to 8605 in our tests. Consequently, with more candidate sites, a larger subset of users becomes eligible for coverage, which in turn generally necessitates deploying more stations to serve them. Notably, across all tested scales, FCUF consistently deploys the fewest edge stations compared to the other algorithms. This observation confirms FCUF’s effectiveness in minimizing deployment size regardless of the number of candidate sites available.

For similar reasons, as shown in Fig. 12, the running time of all algorithms except Kmeans-B grows linearly with the number of candidate sites. The computational overhead introduced by evaluating more candidate sites is directly reflected in their time complexity. In contrast, the time consumed by Kmeans-B remains relatively stable across different numbers of candidate sites. This is because the additional time required to process more candidate sites (less than 1 h) is negligible compared to the dominant cost of its repeated clustering iterations, which already exceeds 12 h in our experiments. Thus, the scaling effect of candidate sites is masked by Kmeans-B’s inherently high and iteration-driven runtime.

Performance ranking

In this subsection, we adopt the bi-objective lexicographical ranking scheme proposed in33 to aggregate the experimental results across all test scenarios and derive a statistical performance ranking for each algorithm. For any given experimental instance, the comparison between two algorithms follows the rules below:

If either algorithm lacks a valid coverage or station count value (i.e., Best in solving not small-scale ESDP), the two are considered equivalent in coverage and station count for that instance.

If either algorithm lacks a valid coverage or station count value (i.e., Best in solving not small-scale ESDP), the two are considered equivalent in coverage and station count for that instance.

If Algorithm A achieves a higher coverage than Algorithm B, then A is considered superior to B.

If Algorithm A achieves a higher coverage than Algorithm B, then A is considered superior to B.

If both algorithms achieve the same coverage, and Algorithm A uses fewer deployed stations than Algorithm B, then A is considered superior to B.

If both algorithms achieve the same coverage, and Algorithm A uses fewer deployed stations than Algorithm B, then A is considered superior to B.

If both algorithms achieve the same coverage and the same number of deployed stations, they are considered equal in performance.

If both algorithms achieve the same coverage and the same number of deployed stations, they are considered equal in performance.

Conclusion

In this paper, we address the edge station deployment problem (ESDP) with the aim of minimizing deployment costs while guaranteeing user coverage, thereby complementing existing research on service enhancement in edge computing. We first formulate ESDP as a dual-objective discrete optimization model that seeks to maximize user coverage and minimize the number of deployed edge stations, and prove its NP-completeness. To overcome the limitation of existing methods that often require an excessive number of stations to cover sparsely distributed users in later stages, we propose a heuristic algorithm based on the principle of prioritizing users covered by the fewest candidate sites. The performance of the proposed algorithm is evaluated through simulations based on a real-world dataset. Experimental results demonstrate that our algorithm achieves 100% user coverage while deploying the fewest edge stations compared to several state-of-the-art benchmarks.

This work addresses the ESDP with a lexicographic focus, prioritizing coverage over cost. A valuable direction for future research is to explore the full Pareto front of solutions trading off coverage percentage against deployment cost using dedicated multi-objective algorithms (e.g., NSGA-II). This would provide a complete decision spectrum for planners with varying budget and coverage requirements.
