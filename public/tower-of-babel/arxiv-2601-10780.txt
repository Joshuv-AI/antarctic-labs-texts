Adaptive algorithm for microsensor in sustainable environmental monitoring
Nursultan Daupayev, Christian Engel, Ricky Bendyk, Prof. Dr.-Ing. Sören Hirsch

Abstract




Introduction

Continuous collection of environmental data in sensors plays an important role for example for anomaly detection in building structures [1]. However, regular data collection results in high energy consumption and data redundancy, where it is necessary to either optimize data in the hardware storage or delete them, which leads to a loss of data quality [2].

Modeling

Following this, the developed algorithm is aimed at reducing the number of measurements by finding important peaks and excluding insignificant measurement points. To achieve this, by applying Fast Fourier Transform (FFT), algorithm transforms the data from the time domain to the frequency domain, which made it possible to identify the periodic characteristics of the sensor signals:

X[k]=\sum_{n=0}^{N-1}x[n]e^{-j\frac{2\pi}{N}kn},\quad k=0,1,\ldots,N-1.

(1)

Then, it determines the optimal number of harmonics to achieve a reduction in sensor measurement, where the optimal number of harmonics is selected. In this case, there are 26 optimal harmonics:

A[k]=|X[k]|=\sqrt{(\operatorname{Re}\{X[k]\})^{2}+(\operatorname{Im}\{X[k]\})^{2}}

(2)

After selecting the optimal harmonics, an algorithm uses an inverse fast Fourier transform (IFFT) to reconstruct the signal (Fig 4.). It is expected to be close to the original data, showing minor deviations from them:

x[n]=\frac{1}{N}\sum_{k=0}^{N-1}X[k]e^{j\frac{2\pi}{N}kn}

(3)
