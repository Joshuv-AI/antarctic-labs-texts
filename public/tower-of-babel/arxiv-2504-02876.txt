Multimodal Reference Visual Grounding
Yangxiao Lu, Ruosen Li, Liqiang Jing, Jikai Wang, Xinya Du, Yunhui Guo

Abstract
Visual grounding focuses on detecting objects from images based on language expressions. Recent Large Vision-Language Models (LVLMs) have significantly advanced visual grounding performance by training large models with large-scale datasets. However, the problem remains challenging, especially when similar objects appear in the input image. For example, an LVLM may not be able to differentiate Diet Coke and regular Coke in an image. In this case, if additional reference images of Diet Coke and regular Coke are available, it can help the visual grounding of similar objects. In this work, we introduce a new task named Multimodal Reference Visual Grounding (MRVG). In this task, a model has access to a set of reference images of objects in a database. Based on these reference images and a language expression, the model is required to detect a target object from a query image. We first introduce a new dataset to study the MRVG problem. Then we introduce a novel method, named MRVG-Net, to solve this visual grounding problem. We show that by efficiently using reference images with few-shot object detection and using Large Language Models (LLMs) for object matching, our method achieves superior visual grounding performance compared to the state-of-the-art LVLMs such as Qwen2.5-VL-7B. Our approach bridges the gap between few-shot detection and visual grounding, unlocking new capabilities for visual understanding. 1 1 1 Project page with our code and dataset: https://irvlutd.github.io/MultiGrounding

Introduction

Figure 1:
Comparison of three visual grounding tasks: (a) Visual grounding identifies objects in a query image based on a textual expression. (b) In-context visual grounding utilizes reference images to specify the target object in addition to the language expression, where the reference images must contain the target object. (c) Multimodal reference visual grounding uses a set of reference images alongside a referring expression to identify the target, where the target only represents one object in the reference images.

In the visual grounding task, the goal is to localize an object in a given query image that matches a given textual expression (see Fig.
1
(a)). As an example application, in the robotics domain, a user might instruct a robot bartender to “bring me a Diet Coke.”
To correctly complete the task, the robot bartender must open the refrigerator and find a Diet Coke among the many possibly similar items, e.g., regular Coke, zero Coke, or other soft drinks. More generally, to be a competent bartender, the robot must be able to accurately distinguish between the many similar types of beverages and ingredients required in cocktail recipes.

Recent Large Vision-Language Models (LVLMs)
(
Wang et al. 2023
;
Bai et al. 2025b
;
Chen et al. 2024b
;
Wang et al. 2024
)
have demonstrated impressive performance on the visual grounding task. However, in settings with very similar objects, such as in the robotics scenario above, these same LVLMs can struggle to differentiate them, which indicates that the LVLMs may not pay attention to the fine-grained details necessary to correctly identify the target object.

To overcome this limitation, one idea is to incorporate visual references into the query:
For example, we can download images of Diet Coke and regular Coke from the Internet, and provide these reference images along with the textual expression for visual grounding. In this way, the model should be able to detect a target object based on a referring expression and the reference images of objects. However, many LVLMs
(
Liu et al. 2024
;
Bai et al. 2025b
;
Chen et al. 2024b
;
Wang et al. 2024
)
operate in a zero-shot manner. They generate bounding boxes solely based on the provided referring expression. These models do not support the use of reference images to aid inference, and as a result, while they may be effective at distinguishing between different object categories, their ability to differentiate highly similar object instances is often quite limited.

To incorporate visual references, recent LVLMs such as DeepSeek-VL2
(
Wu et al. 2024b
)
enable one-shot in-context visual grounding: Given a reference image and an optional text prompt, DeepSeek-VL2 identifies a target object in a query image. The in-context visual grounding task is illustrated in Fig.
1
(b). However, their approach assumes that the target object must be present in the reference image. When provided with a large number of reference images containing potential target objects, DeepSeek-VL2 struggles to perform in-context visual grounding if only a subset of these targets appears in the query image. This can be a significant limitation in practice. Consider again the robot bartender example. It is reasonable to assume that the robot possesses visual references for all of the items it has stocked. As such, it would be convenient to be able to pass its entire stock, which could include thousands of items, as visual references for any visual grounding task.

In this work, we propose the Multimodal Reference Visual Grounding (MRVG) task, which requires a model to generate bounding boxes or segmentation masks of target objects based on textual queries and multiple reference images. The MRVG task is illustrated in Fig.
1
(c). The textual query can be either explicitly or implicitly relevant to the target object such as “A bottle of black liquid with a gray cap and a diet cola label on its side” or “The leftmost bottle”. The reference images contain all potential objects that are relevant to an underlying application. For example, we can use the images of objects in an inventory list in a grocery store as reference images. Or if a robot needs to recognize a set of objects, we can capture images of these objects and use them as the reference images for visual grounding. To address this task, the model must possess the capability to process reference images efficiently to extract visual cues and comprehend the associated query texts.

Second, as there is no existing dataset designed for the MRVG task, we constructed a dataset consisting of 1,400 reference images, 250 query images, and 855 associated referring expressions for 100 everyday objects across 4 different scenes, both indoor and outdoor. We chose objects that are commonly found in daily life as we anticipate that visual grounding of these objects could be useful in a variety of robotics and VR/AR applications.

Finally, we propose a new method, MRVG-Net, to tackle the multimodal reference visual grounding task. In our method, given reference images of target objects, an LVLM such as GPT-4o-mini
(
Hurst et al. 2024
)
is used to extract text descriptions such as color, shape, and usage of these objects. This step only needs to be run once. Then we obtain textual descriptions of all the objects in the reference images. Given a query image during inference, a few-shot detector, e.g., NIDS-Net
(
Lu et al. 2024
)
, is first used to detect target objects from the query image. NIDS-Net uses the reference images as a support set for few-shot object detection. Consequently, it only detects objects that are present in the reference images. Using the predicted object instance IDs from NIDS-Net, we can retrieve the corresponding object descriptions of the detected objects. Finally, an LLM such as GPT-4o
(
Hurst et al. 2024
)
performs reasoning to match the object descriptions with the input textual query to generate the final object grounding results.
Instead of relying on an LVLM to process the reference images as in in-context visual grounding, our method utilizes a few-shot object detector to detect objects based on the reference images. As a result, our method can handle a large number of reference images. In addition, object matching is achieved using text only, where we can leverage the state-of-the-art LLMs for robust matching.

We evaluated MRVG-Net on our new dataset, and we compared it with several visual grounding methods such as GroundingDINO
(
Liu et al. 2024
)
, InternVL2.5
(
Chen et al. 2024b
)
, and Qwen2.5-VL
(
Bai et al. 2025b
)
. Our method achieves superior visual grounding performance compared to these methods, which demonstrates the effectiveness of our method in solving the MRVG task and exemplifies the novelty of the task.

In summary, the contributions of this work are as follows.

•

We introduce the task of multimodal reference visual grounding, where reference images of target objects are available for visual grounding.

•

We contribute a new dataset for multimodal reference visual grounding that contains 100 everyday objects such as drink bottles and snack boxes.

•

We introduce a new method for multimodal reference visual grounding that leverages few-shot object detection and LVLM/LLM for object matching.

Related Work

Visual Grounding (VG)
, also known as Referring Expression Comprehension (REC), is the task of identifying a region in an image according to a query text. This task requires understanding free-form text to locate objects from any open-set category. REC benchmarks, such as RefCOCO, RefCOCO+, and RefCOCOg
(
Yu et al. 2016
)
, provide a large number of annotations. However, these datasets do not provide reference images that explicitly highlight the objects referred to by the query text within the images. Specialized VG models have been proposed in previous works
(
Yu et al. 2018
;
Kamath et al. 2021
;
Yan et al. 2023
;
Wu et al. 2022
)
. Recently, Large Vision-Language Models
(
Liu et al. 2024
;
Chen et al. 2024b
;
Bai et al. 2025b
;
Wu et al. 2024b
;
Zhang et al. 2024
)
have demonstrated significant performance improvements on the traditional VG datasets due to their large training data. These models primarily focus on localizing objects using only the referring expression, without relying on visual cues as references. In contrast, we develop a new framework to utilize reference images as additional contextual information.

Novel instance detection
identifies and labels unseen object instances in a query image using template/reference images. VoxDet
(
Li et al. 2024
)
leverages multi-view templates to provide geometry-invariant 3D representations.
Shen et al. 2023
introduce a high-resolution dataset and utilize SAM
(
Kirillov et al. 2023
)
and DINOv2
(
Oquab et al. 2023
)
to detect instances. NIDS-Net
(
Lu et al. 2024
)
uses Grounded-SAM
(
Ren et al. 2024
)
for object proposals and refines DINOv2 embeddings with a weight adapter. We adopt NIDS-Net in our method based on its strong practical performance.

LLM Reasoning
capabilities can be substantially enhanced during inference using various test-time prompting techniques. Approaches such as Chain of Thought
(
Wei et al. 2022
)
have been shown to significantly improve reasoning performance. Additionally, Process Reward Models (PRMs) can effectively guide the inference process through diverse strategies such as Majority Voting
(
Wang et al. 2022
)
, Tree-of-Thought
(
Yao et al. 2023
)
, Beam Search
(
Lewis et al. 2019
)
, and Lookahead Search
(
Snell et al. 2024
)
. We leverage the reasoning ability of LLMs to better understand the relationships between item descriptions and user queries.

Large Vision-Language Model.

Large Vision-Language Models (LVLMs) have garnered significant attention for their impressive visual understanding capabilities. For instance, LLaVA
(
Liu et al. 2023
)
integrates a visual encoder with a large language model to enable vision-centric multi-turn dialogue. Most existing LVLMs
(
Gong et al. 2023
;
Ye et al. 2023
;
Jing & Du 2024
;
Dai et al. 2023
)
adopt a common architecture that includes a visual encoder, a language decoder, and a projection layer to align modalities. Although these models have achieved remarkable success across a wide range of visual understanding tasks, their ability to perform grounded understanding, i.e., precisely predicting bounding boxes based on the language instruction, remains limited.
To address this limitation, LLaVA-Grounding
(
Zhang et al. 2024
)
introduces a new grounded visual dialogue dataset to enhance grounding performance during visual conversations. In contrast to existing grounding-capable LVLMs such as DeepSeek-VL2
(
Wu et al. 2024a
)
and Qwen2.5-VL
(
Bai et al. 2025a
)
, our work uniquely focuses on how to predict bounding boxes of objects in a scene image with both textual natural language instructions and reference images.

3
Multimodal Reference Visual Grounding

Visual grounding tasks traditionally identify and localize objects within an image based on a referring expression. In-context visual grounding enhances this by using one or more reference images to more accurately locate the target object within the query image. However, this method assumes the presence of the target object in the reference images, which is not always practical. As illustrated in Fig.
1
, we propose a new task, termed Multimodal Reference Visual Grounding, which expands the scope from using a limited number of relevant reference images to potentially a large number of reference images. The model must autonomously select pertinent reference images to effectively gather visual context for language grounding.

Specifically, in multimodal reference visual grounding, we are provided with a set of
N
target instances, where each instance is represented by
K
reference images. We denote all the reference images as
I_{T}\in\mathbb{R}^{N\times K\times 3\times W\times H}
, where
W
and
H
denote the width and height of the images, respectively. Each reference image contains only one object with a segmentation mask of the object. We denote all segmentation masks of the reference images as
M_{T}\in\mathbb{R}^{N\times K\times W\times H}
. The objective is to locate and segment a specific target object described by a referring expression
r
within a query image
I_{Q}\in\mathbb{R}^{3\times W\times H}
. The referring expression
r
provides a natural language description that unambiguously identifies one of the
N
target objects that appears in the query image. Each of the
K
template images associated with a target object serves as a visual reference, which the model utilizes to match the referred object in the query image.
The output consists of a bounding box
b
and an optional instance segmentation mask
m\in\mathbb{R}^{W\times H}
that precisely delineates the boundary of the object.

3.1
The MultimodalGround Dataset

Figure 2:
Illustration of the four different scenes in our MultimodalGround dataset. Each target object is annotated with an object instance ID, a bounding box, a segmentation mask, and a referring expression.

We introduce a new dataset called
MultimodalGround
which can be used to evaluate models on two tasks: standard visual grounding and multimodal reference visual grounding. The dataset consists of four types of scenes, containing 250 RGB-D query images and 855 object annotations manually labeled by humans. These images are captured using one Intel RealSense D455 camera. Each annotation includes a bounding box, a segmentation mask, and a referring expression as shown in Fig.
2
. The average lengths of query texts in RefCOCO, RefCOCO+, and RefCOCOg
(
Yu et al. 2016
)
are 3.6, 3.6, and 8.4 words, respectively, while the average referring expression length in our dataset is 9.4 words to include specific object details. When constructing these annotations and query images, we imagine that a robot or an AI agent is instructed to locate specific objects and engage in further interactions, such as grasping and manipulation in real-world scenarios. Hence, these annotations can be used to assess the real-world performance of various models.

The objects in the query images represent 100 common daily items that can be found in supermarkets. For each object instance, the dataset provides 14 real-world RGB-D template images captured from seven viewpoints using seven Intel RealSense D455 cameras, along with one RGB image sourced from the Internet to support the generation of detailed object descriptions. For each RGB-D reference image, we provide a corresponding mask for each object, as illustrated in Fig.
3
. These reference images are used to provide visual references for language grounding. To facilitate future research in RGB-D visual grounding, novel instance detection and segmentation, we provide both camera intrinsic parameters and depth images in our dataset.

Figure 3:
Our MultimodalGround dataset comprises 100 everyday object instances. Each instance is annotated with a class label and instance ID, and is accompanied by one detailed image, 14 multi-view RGB-D reference images, and corresponding segmentation masks. Point clouds can be generated using the provided camera intrinsics and depth images.

4
Method

Our framework MRVG-Net adopts a detection-and-matching paradigm, as illustrated in Fig.
4
. For each of the
N
objects, a representative image
I_{i}
is used to generate a detailed object profile
D_{i}
using a Large Vision-Language Model (LVLM), where
i=1,\ldots,N
.
These profiles
\{D_{i}\}_{i=1}^{N}
serve as the basis for object matching.
Given a query image
I_{Q}
, the few-shot detector NIDS-Net
(
Lu et al. 2024
)
identifies relevant objects by producing a set of object instance IDs
\{c_{j}\}
and their corresponding bounding boxes
\{b_{j}\}
, where
j=1,\ldots,M
for
M
detections, based on the reference images.
Using the predicted object instance IDs, we retrieve the corresponding object descriptions
\{D_{c_{j}}\}
and spatial positions
\{b_{j}\}
to form a set of candidate objects
\mathcal{C}=\{(D_{c_{j}},b_{j})\}_{j=1}^{M}
.
Finally, a LLM performs matching between the candidates
\mathcal{C}
and the referring expression
R
to identify the target object.

Figure 4:
Architecture of our MRVG-Net. Only the weight adapter of NIDS-Net
(
Lu et al. 2024
)
is trained using the reference images. After the NIDS-Net produces detection results in a few-shot fashion, the corresponding object descriptions are retrieved from a pre-stored file. The Large Language Model (LLM) then matches these descriptions with the referring expression to select the most relevant description and its associated bounding box.

4.1
Object Descriptions

To support accurate object grounding, we employ a Large Vision-Language Model (LVLM) to generate detailed natural language descriptions for
N=100
daily objects, each represented by a high-quality Internet image
I_{i}
, where
i=1,\ldots,N
. For each object, the LVLM produces a descriptive profile
D_{i}
that captures fine-grained visual attributes such as shape, color, material, and function. These descriptions
\{D_{i}\}_{i=1}^{N}
are context-aware, align well with natural referring expressions, and enhance cross-modal retrieval performance. The object descriptions can be precomputed using an LVLM and stored in a file, such that the LVLM is not utilized during inference. Detailed LVLM prompts and generation examples are provided in the Appendix
A.3
.

4.2
Novel Instance Detection

Given reference images
I_{T}
of the target instances, NIDS-Net
(
Lu et al. 2024
)
detects corresponding objects in a query image
I_{Q}
through the following steps. First, it applies Grounding DINO
(
Liu et al. 2024
)
to
I_{Q}
using a generic text prompt (e.g., “objects”) to obtain a set of initial bounding boxes
\{b_{j}\}_{j=1}^{M}
for foreground objects. For each bounding box
b_{j}
, the Segment Anything Model (SAM)
(
Kirillov et al. 2023
)
is employed to generate a precise segmentation mask
m_{j}
, resulting in object proposals represented as
(b_{j},m_{j})
. Each reference image and proposal is then encoded into an instance embedding. Specifically, NIDS-Net extracts average foreground features from the DINOv2 ViT patch embeddings
(
Oquab et al. 2023
)
, denoted as
\mathbf{e}_{i}
for reference instances and
\mathbf{e}_{j}
for proposals. A weight adapter is applied to refine these embeddings by encouraging clustering among similar instances and separation among dissimilar ones. Finally, the method matches proposal embeddings
\{\mathbf{e}_{j}\}
with target embeddings
\{\mathbf{e}_{i}\}
to classify each proposal, yielding predicted labels along with their corresponding bounding boxes
\{b_{j}\}
and masks
\{m_{j}\}
. In NIDS-Net,
only the weight adapter is trained using these reference images, while all other components remain frozen
.

4.3
LLM Reasoning for Matching

To identify the target object referred to in a natural language expression
r
within a query image
I_{Q}
, we construct a candidate set
\mathcal{C}=\{(D_{c_{j}},p_{j},b_{j},m_{j})\}_{j=1}^{M}
, where each element consists of a retrieved object description
D_{c_{j}}
, a top left position
p_{j}=(x_{j},y_{j})
of a predicted bounding box
b_{j}
, and its optional corresponding segmentation mask
m_{j}
. The object description
D_{c_{j}}
is obtained by mapping the predicted instance ID
c_{j}
to its associated LVLM-generated profile from the reference set. To perform matching, we prompt a Large Language Model (LLM) with
r
and the candidate set, asking it to select the most likely match based on relative spatial position, semantic similarity and contextual cues. For simplicity, the matching process considers only the object description
D_{c_{j}}
and position
p_{j}
, omitting the bounding box
b_{j}
and mask
m_{j}
. This method leverages the LLM’s capacity for nuanced language understanding and reasoning, enabling accurate resolution of referring expressions, even in the presence of visually similar objects or ambiguous phrasing. Our approach is interpretable and aligned with human-like comprehension, thereby improving grounding accuracy in complex scenes.

Evaluation metrics
. Given a query image, a referring expression, and a set of reference images, a model predicts a bounding box described by the expression. To evaluate the grounding performance, we calculate the Intersection over Union (IoU) between the predicted and ground-truth bounding boxes. Predictions with an IoU greater than 0.5 are classified as true positives, and those below the threshold are false positives. This accuracy (
Acc0.5
) is computed as the number of all true positives divided by the total number of all testing samples. To comprehensively evaluate the localization capabilities of models, as suggested by
Chen et al. 2024a
, we calculate accuracy at different IoU thresholds:
Acc0.75
,
Acc0.9
, and
mAcc
, which calculates the average accuracy between IoU thresholds 0.5 and 0.9, in increments of 0.05.

Ablation Study

Object description models.
We evaluate different LVLMs for generating object descriptions using the same prompt. As shown in Table
2
, GPT-4o
(
Hurst et al. 2024
)
outperforms GPT-4o-mini
(
Hurst et al. 2024
)
when the matching strategy and matching model are the same, indicating its strong ability in the description generation task. Furthermore, upon reviewing the descriptions generated by both models, GPT-4o generally provides more detailed and informative descriptions than GPT-4o-mini.

Matching strategies and matching models.
Two matching strategies are employed for associating a set of object descriptions with a set of referring expressions.
Joint Matching
entails simultaneously matching both sets, where each referring expression is compared to the entire set of object descriptions within a collective context. Therefore, joint matching processes all the referring expressions in a query image parallelly. In contrast,
Independent Matching
involves independently matching each referring expression with the set of object descriptions, treating each expression separately without accounting for the interactions between the referring expressions. The prompts of the two matching strategies are presented in Appendix
A.4
. Table
2
demonstrates that independent matching yields superior performance, as incorrect matches do not impact the accuracy of other matches. Table
2
also shows that GPT-4o outperforms GPT-4o-mini for the matching task in most cases on the MultimodalGround dataset, due to its superior capabilities.

5.3
Failure Cases

The failure cases of our method are primarily due to detection errors in NIDS-Net, as shown in Fig.
6
. NIDS-Net achieves an Average Precision (AP) of 60.6, AP at IoU threshold 0.50 of 65.5, and AP at IoU threshold 0.75 of 65.2. Incorrect class label predictions lead to mismatches between object descriptions and referring expressions. The use of a more advanced few-shot detector than NIDS-Net is expected to improve our framework’s performance. More details of the detection performance of NIDS-Net can be found in Appendix
A.1
.

Failure analysis.
NIDS-Net has 318 misclassifications out of 855 predictions, while MRVG experiences only 165 failures. This discrepancy arises because misclassifications from NIDS-Net do not always result in grounding failures. For instance, phrases like “the leftmost bottle” depend on relative spatial relationships, which can be inferred from the bounding boxes of predictions. Additionally, NIDS-Net may misclassify one instance as another similar one, where the descriptions are close enough for LLMs to still correctly locate the target object.

6
Conclusion

In this work, we introduced the Multimodal Reference Visual Grounding (MRVG) task, which incorporates both textual queries and multiple reference images to enhance visual grounding. Given the object descriptions from an LVLM, our proposed MRVG-Net method leverages a few-shot object detector to process reference images, followed by an LLM for matching between object descriptions and referring expressions. MRVG-Net outperforms existing models on our introduced MultimodalGround dataset, demonstrating its potential for real-world applications. This work opens new avenues for developing more robust and context-aware visual grounding systems.

Limitations.
Few-shot detectors like NIDS-Net can have errors in object detection. During inference, processing referring expressions sequentially can be computationally intensive and token-consuming. As a result, our method may incur high computational costs and extended processing times when the query image contains a large number of items.
