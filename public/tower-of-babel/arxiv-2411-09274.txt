On some Liouville theorems for p p -Laplace type operators
Michel Chipot, Daniel Hauer

Abstract
The goal of this note is to consider Liouville type theorem for p p -Laplacian type operators. In particular guided by the Laplacian case one establishes analogous results for the p p -Laplacian and operators of this type.

1
Introduction and notation

It is well known, and it goes back to Liouville, that if
u
is an
harmonic, bounded function in
\mathbb{R}^{n}
then
u
has to be a constant,
i.e. if

-\Delta u=0~~\text{ in }~~{\cal D}^{\prime}({\mathbb{R}}^{n})

and
u
is bounded, then
u
is constant (see for instance
[
8
]
,

[
14
]
). The problem is much more saddle when the equation above has
a lower order term, i.e. if
u
is a solution to the Schrödinger
equation

-\Delta u+bu=0~~\text{ in }~~{\cal D}^{\prime}({\mathbb{R}}^{n})

(1.1)

for some function
b\geq 0
. If
n=2
,
b\not=0
then every bounded
solution to (
1.1
) is equal to
0
. The situation is radically
different when
n>2
. To sketch the situation, if
b
is not decaying
too quickly at infinity, then bounded solutions to (
1.1
) are
vanishing. On the contrary for
b
’s with fast decay (
1.1
) can
have bounded non trivial solution (see
[
3
]
,
[
9
]
,

[
10
]
,
[
13
]
).

The goal of this note is to investigate the situation when the Laplacian
is replaced by the
p
-Laplacian. The expectation in this case is that
for
p\geq n
every bounded solution to

-\Delta_{p}u=0~~\text{ in }~~{\cal D}^{\prime}({\mathbb{R}}^{n})

has to be constant but when
p<n
and
b
decays fast enough one can
exhibit nontrivial bounded solutions to

-\Delta_{p}u+b|u|^{p-2}u=0~~\text{ in }~~{\cal D}^{\prime}({\mathbb{R}}^{n}).

This is what we would like to investigate in a slightly more general
framework. Recall that the
p
-Laplacian is defined as

\Delta_{p}u:=\partial_{x_{i}}\{|\nabla u|^{p-2}\partial_{x_{i}}u\}=\nabla\cdot\{|\nabla u|^{p-2}\nabla u\}

with the summation convention in
i
, i.e. in the above formula one sums
in
i
for
i=1,\cdots,n
. We will address these issues for

p
-Laplacian type operator which archetype could be

-\nabla\cdot\{a(x,u)|\nabla u|^{p-2}\nabla u\}.

But we also discuss cases for sums of
p
-Laplace operators

\partial_{x_{k}}\big(\sum_{i=1}^{N}a_{i}(x,u)|\nabla u|^{p_{i}-2}\partial_{x_{k}}u\big),

which includes the prototype operator involved in double phase problems
(see, for example,
[
1
]
and references therein).

The paper is divided as follows. The two next sections provide Liouville
type results in different situations getting in particular inspiration
from the case of the Laplacian where
b
is chosen with a relatively
slow decay at infinity. In the Section 4 we give an example of a
nontrivial bounded solution when the lower order term of the operator
vanishes at infinity. Finally, in the last section, we briefly explain
how the arguments developped in Theorem 3.1 can be extended in the case
of several operators.

2
p
-Laplacian type operators
``p\geq n"

Let us denote by
a_{i}(x,u)
,
i=1,\cdots,N
Carathéodory functions
such that for some positive constants
\lambda,\Lambda
one has for

i=1,\cdots,N

\lambda\leq a_{i}(x,u)\leq\Lambda~~\text{ a.e. }x\in\mathbb{R}^{n},~\forall u\in\mathbb{R}.

Denote also by
b(x,u)
a bounded Carathéodory function satisfying

b(x,u)u\geq 0~~\text{ a.e. }x\in\mathbb{R}^{n},~\forall u\in\mathbb{R}.

(2.1)

Let
p_{1},\cdots,p_{N}
be real numbers such that

1<p_{1}\leq p_{2}\leq\cdots\leq p_{N}.

Suppose now that
u
is a
solution
to

-\partial_{x_{k}}\big(\sum_{i=1}^{N}a_{i}(x,u)|\nabla u|^{p_{i}-2}\partial_{x_{k}}u\big)+b(x,u)=0\qquad\text{in $\mathcal{D}^{\prime}(\mathbb{R}^{n})$,}

(2.2)

i.e.
u\in W^{1,p_{N}}_{\ell oc}(\mathbb{R}^{n})
and for every bounded open
subset
\Omega
of
\mathbb{R}^{n}

\int_{\Omega}\sum_{i=1}^{N}a_{i}(x,u)|\nabla u|^{p_{i}-2}\nabla u\cdot\nabla v+b(x,u)v=0\qquad\forall v\in W^{1,p_{N}}_{0}(\Omega).

(2.3)

Then, one can show :

Theorem 2.1
.

Suppose that
p_{i}\geq n
, for all
i=1,\cdots,N
. Then
the only bounded solutions to (
2.2
) are the constants.

Proof.

Set

A(x,u(x),\xi)=\sum_{i=1}^{N}a_{i}(x,u(x))|\xi|^{p_{i}-2}\xi

for a.e.
x\in\Omega
, and every
\xi\in\mathbb{R}^{n}
. One has, if we denote by a dot the scalar product

A(x,u(x),\xi)\cdot\xi\geq\lambda\sum_{i=1}^{N}|\xi|^{p_{i}},

(2.4)

and

|A(x,u(x),\xi)|\leq\Lambda\sum_{i=1}^{N}|\xi|^{p_{i}-1}

(2.5)

for a.e.
x\in\Omega
, and every
\xi\in\mathbb{R}^{n}
. Let us denote by
\rho
a
smooth function such that

\rho=1\text{ on }B_{\frac{1}{2}},~~\rho=0\text{ outside }B_{1},~~|\nabla\rho|\leq K

(2.6)

for some constant
K
(
B_{r}
denote the ball of center
0
and radius

r
). If
u
is a weak solution to (
2.2
) and if
p\geq p_{N}
, then
one has that

v:=u\,\rho^{p}\left(\frac{\cdot}{r}\right)\in W^{1,p_{N}}_{0}(B_{r}).

Thus from (
2.3
) one derives dropping the measures of integration

\int_{B_{r}}A(x,u(x),\nabla u(x))\cdot\nabla\{u\rho^{p}(\frac{x}{r})\}+b(x,u(x))u(x)\rho^{p}(\frac{x}{r})=0,

which is equivalent to

\int_{B_{r}}A(x,u(x),\nabla u(x))\cdot\nabla u~\rho^{p}(\frac{x}{r})+b(x,u(x))u(x)\rho^{p}(\frac{x}{r})\\
=-p\int_{B_{r}\backslash B_{\frac{r}{2}}}A(x,u(x),\nabla u(x))\cdot\nabla\{\rho(\frac{x}{r})\}\rho^{p-1}(\frac{x}{r})u.

Using (
2.4
)-(
2.6
), recalling that
\nabla\{\rho(\frac{x}{r})\}=\frac{1}{r}\nabla\rho(\frac{x}{r})
we get by
(
2.1
) that

\displaystyle\lambda\int_{B_{r}}\sum_{i=1}^{N}|\nabla u|^{p_{i}}~\rho^{p}(\frac{x}{r})

\displaystyle\leq\frac{pK\Lambda}{r}\sum_{i=1}^{N}\int_{B_{r}\backslash B_{\frac{r}{2}}}|\nabla u|^{p_{i}-1}\rho^{p-1}(\frac{x}{r})|u|

\displaystyle\leq\frac{pK\Lambda}{r}\sum_{i=1}^{N}\int_{B_{r}\backslash B_{\frac{r}{2}}}|\nabla u|^{p_{i}-1}\rho^{\frac{p(p_{i}-1)}{p_{i}}}\rho^{p-\frac{p(p_{i}-1)}{p_{i}}-1}|u|

\displaystyle=\frac{pK\Lambda}{r}\sum_{i=1}^{N}\int_{B_{r}\backslash B_{\frac{r}{2}}}|\nabla u|^{p_{i}-1}\rho^{\frac{p}{p^{\prime}_{i}}}\rho^{\frac{p-p_{i}}{p_{i}}}|u|

with
p^{\prime}_{i}=\frac{p_{i}}{p_{i}-1}
. Using Hölder’s inequality in this last integral, it comes

\lambda\int_{B_{r}}\sum_{i=1}^{N}|\nabla u|^{p_{i}}~\rho^{p}(\frac{x}{r})\leq\sum_{i=1}^{N}\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}|\nabla u|^{p_{i}}\rho^{p}(\frac{x}{r})\right]^{\frac{1}{p^{\prime}_{i}}}\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}\rho^{p-p_{i}}(\frac{x}{r})|u|^{p_{i}}\right]^{\frac{1}{p_{i}}}\frac{pK\Lambda}{r}.

(2.7)

Then, using the Young inequality

\sum_{i}a_{i}b_{i}\leq\varepsilon\sum_{i}a_{i}^{p^{\prime}_{i}}+C_{\varepsilon}\sum_{i}b_{i}^{p_{i}}

(2.8)

holding for all
\varepsilon>0
,
a_{i},b_{i}\geq 0
with some constant

C_{\varepsilon}>0
, we get

\displaystyle\lambda\int_{B_{r}}\sum_{i=1}^{N}|\nabla u|^{p_{i}}~\rho^{p}(\frac{x}{r})

\displaystyle\leq\varepsilon\int_{B_{r}\backslash B_{\frac{r}{2}}}\sum_{i=1}^{N}|\nabla u|^{p_{i}}\rho^{p}(\frac{x}{r})+C_{\varepsilon}\sum_{i=1}^{N}\int_{B_{r}\backslash B_{\frac{r}{2}}}\frac{1}{r^{p_{i}}}\rho^{p-p_{i}}(\frac{x}{r})|u|^{p_{i}}

\displaystyle\leq\varepsilon\int_{B_{r}\backslash B_{\frac{r}{2}}}\sum_{i=1}^{N}|\nabla u|^{p_{i}}\rho^{p}(\frac{x}{r})+C_{\varepsilon}\sum_{i=1}^{N}\int_{B_{r}\backslash B_{\frac{r}{2}}}\frac{1}{r^{p_{i}}}|u|^{p_{i}}.

Recall that
p\geq p_{i}

\forall i
. Let us assume that

\sum_{i=1}^{N}\frac{1}{r^{p_{i}}}\int_{B_{r}\backslash B_{\frac{r}{2}}}|u|^{p_{i}}~~\text{ is bounded independently of r. }

(2.9)

Then, choosing
\varepsilon=\frac{\lambda}{2}
, one derives that

\int_{B_{\frac{r}{2}}}\sum_{i=1}^{N}|\nabla u|^{p_{i}}~~\text{ is bounded independently of r}

and thus, since this integral is nondecreasing in
r
for every
i
, we
can conclude that

\lim_{r\to\infty}\int_{B_{r}}|\nabla u|^{p_{i}}~~\text{exists.}

Going back to (
2.7
), applying (
2.9
), one derives easily that for some constants
C
,

\displaystyle\lambda\int_{B_{\frac{r}{2}}}\sum_{i=1}^{N}|\nabla u|^{p_{i}}

\displaystyle\leq C\,\sum_{i=1}^{N}\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}|\nabla u|^{p_{i}}\right]^{\frac{1}{p^{\prime}_{i}}}\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}\frac{1}{r^{p_{i}}}|u|^{p_{i}}\right]^{\frac{1}{p_{i}}}

\displaystyle\leq C\,\sum_{i=1}^{N}\left[\int_{B_{r}}|\nabla u|^{p_{i}}-\int_{B_{\frac{r}{2}}}|\nabla u|^{p_{i}}\right]^{\frac{1}{p^{\prime}_{i}}}\to 0~~\text{ when }r\to\infty.

Thus in case (
2.9
) holds,
\nabla u=0
and so,
u
is
constant. It is easy to see that when
u
is bounded (
2.9
) holds
when
p_{i}\geq n
for every
i
. This completes the proof of the
theorem.
∎

Remark 1
.

Somehow the condition (
2.9
) is weaker than
u

bounded. Of course, if
b(x,u)
is not identical equal to 0, the
constant in Theorem 2.1 vanishes. Also using the structure assumptions
(
2.4
) and (
2.5
), one sees that the theorem above can be
extended to more general operators. For instance, with a summation in
k
for

-\sum_{i=1}^{N}\big(\partial_{x_{k}}a_{i}^{k}(x,u)|\nabla u|^{p_{i}-2}\partial_{x_{k}}u\big).

In this case the
k
-component of
A(x,u,\xi)
is given by

-\sum_{i=1}^{N}a_{i}^{k}(x,u)|\xi|^{p_{i}-2}\xi_{k}

and provided
a_{i}^{k}\geq\lambda
one has

A(x,u,\xi)\cdot\xi\geq\lambda\sum_{i=1}^{N}|\xi|^{p_{i}}

(
2.5
) being easy to establish if the
a_{i}^{k}
are bounded.

Similarly for instance for the anisotropic Laplace operator,

-\partial_{x_{k}}\{a^{k}(x,u)|\partial_{x_{k}}u|^{p_{k}-2}\partial_{x_{k}}u\}

(see, for example,

[
19
,
18
,
2
]
)
the
k
-component of
A(x,u,\xi)
is given by

a^{k}(x,u)|\xi_{k}|^{p_{k}-2}\xi_{k}

and provided
a^{k}\geq\lambda
it holds

A(x,u,\xi)\cdot\xi=\sum_{k=1}^{n}a^{k}(x,u)|\xi_{k}|^{p_{k}}\geq\lambda\sum_{k=1}^{n}|\xi_{k}|^{p_{k}}.

The proof of theorem 2.1 follows the same pattern in this case, (
2.7
) being replaced by

\lambda\sum_{k=1}^{n}\int_{B_{r}}|\partial_{x_{k}}u|^{p_{k}}~\rho^{p}(\frac{x}{r})\leq\frac{C}{r}\sum_{k=1}^{n}\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}|\partial_{x_{k}}|^{p_{k}}\rho^{p}(\frac{x}{r})\right]^{\frac{1}{p^{\prime}_{k}}}\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}\rho^{p-p_{k}}(\frac{x}{r})|u|^{p_{k}}\right]^{\frac{1}{p_{k}}}

and the result holds for
p_{k}\geq n
,
\forall k
.

3
p
-Laplacian type operators, “p” arbitrary

In this section we would like to show that, in case that the lower order
term
b(x,u)
in equation (
2.2
) is stronger, one can extend
Theorem
2.1
to every
1<p<\infty
. To avoid technicalities we
will restrict ourselves to the case of one single operator of
p
-Laplacian
type postponing to the last section (Section
5
) the possible extensions. Thus for
some
p>1
, we suppose that
u
is a
solution
to

-\partial_{x_{k}}\big(a(x,u)|\nabla u|^{p-2}\partial_{x_{k}}u\big)+b(x,u)=0\qquad\text{in $\mathcal{D}^{\prime}(\mathbb{R}^{n})$,}

(3.1)

i.e.
u\in W^{1,p}_{\ell oc}(\mathbb{R}^{n})
and for every bounded open subset
\Omega
of
\mathbb{R}^{n}
,

\int_{\Omega}a(x,u)|\nabla u|^{p-2}\nabla u\cdot\nabla v+b(x,u)v=0\qquad\forall v\in W^{1,p_{N}}_{0}(\Omega).

(3.2)

We suppose, of course, that
a(x,u)
is a Carathéodory function satisfying

\lambda\leq a(x,u)\leq\Lambda~~\text{ a.e. }x\in\mathbb{R}^{n},~\forall u\in\mathbb{R}.

(3.3)

Theorem 3.1
.

Suppose, in addition to (
2.1
), that for some constant
c
and
r
large enough

b(x,u)u\geq\frac{c}{r^{\ell}}|u|^{p}

(3.4)

with
\ell<p
. Then every bounded solution to (
3.1
) vanishes.

Proof.

Let
\rho
be a function satisfying (
2.6
). Taking as test function in (
3.2
)

v=u\,\rho^{p}(\frac{\cdot}{r}),

we get

\int_{B_{r}}a(x,u)|\nabla u|^{p-2}\nabla u\cdot\nabla\{u\rho^{p}(\frac{x}{r})\}+b(x,u)u\rho^{p}(\frac{x}{r})=0.

This implies easily

\int_{\Omega}a(x,u)|\nabla u|^{p}\rho^{p}(\frac{x}{r})+b(x,u)u\rho^{p}(\frac{x}{r})=-p\int_{\Omega}a(x,u)|\nabla u|^{p-2}\nabla u\cdot\nabla\{\rho(\frac{x}{r})\}\rho^{p-1}u.

(3.5)

Arguing as in the previous section, one derives (see (
3.3
), (
3.4
))

\int_{B_{r}}\lambda|\nabla u|^{p}\rho^{p}+b(x,u)u\rho^{p}\leq\frac{pK\Lambda}{r}\int_{B_{r}\backslash B_{\frac{r}{2}}}|\nabla u|^{p-1}\rho^{p-1}|u|.

(3.6)

Applying Hölder’s inequality, it comes

\displaystyle\int_{B_{r}}\lambda|\nabla u|^{p}\rho^{p}+b(x,u)u\rho^{p}

\displaystyle\leq\frac{pK\Lambda}{r}\,\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}|\nabla u|^{p}\rho^{p}\right]^{\frac{1}{p^{\prime}}}\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}|u|^{p}\right]^{\frac{1}{p}}

(3.7)

\displaystyle\leq\frac{pK\Lambda}{r}\,\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}|\nabla u|^{p}\rho^{p}\right]^{\frac{1}{p^{\prime}}}\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}\frac{r^{\ell}}{c}b(x,u)u\right]^{\frac{1}{p}}

\displaystyle\leq\frac{pK\Lambda}{c^{\frac{1}{p}}r^{1-\frac{\ell}{p}}}\,\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}|\nabla u|^{p}\rho^{p}\right]^{\frac{1}{p^{\prime}}}\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}b(x,u)u\right]^{\frac{1}{p}}.

Using now the Young inequality

ab\leq\frac{1}{p^{\prime}}a^{p^{\prime}}+\frac{1}{p}a^{p},~~~\forall\,a,b\geq 0,

we get

\int_{B_{\frac{r}{2}}}\lambda|\nabla u|^{p}+b(x,u)u\leq\frac{pK\Lambda}{\lambda p^{\prime}c^{\frac{1}{p}}r^{1-\frac{\ell}{p}}}\int_{B_{r}\backslash B_{\frac{r}{2}}}\lambda|\nabla u|^{p}\rho^{p}+\frac{pK\Lambda}{pc^{\frac{1}{p}}r^{1-\frac{\ell}{p}}}\int_{B_{r}\backslash B_{\frac{r}{2}}}b(x,u)u.

Thus, for some constant
C>0
,

\int_{B_{\frac{r}{2}}}\lambda|\nabla u|^{p}+b(x,u)u\ \leq\frac{C}{r^{1-\frac{\ell}{p}}}\int_{B_{r}}\lambda|\nabla u|^{p}+b(x,u)u.

Iterating this formula, one derives

\int_{B_{\frac{r}{2^{k+1}}}}\lambda|\nabla u|^{p}+b(x,u)u\leq\frac{C^{k}}{r^{k({1-\frac{\ell}{p}})}}\int_{B_{\frac{r}{2}}}\lambda|\nabla u|^{p}+b(x,u)u.

(3.8)

Going back to (
3.7
) we have

\displaystyle\int_{B_{r}}\lambda|\nabla u|^{p}\rho^{p}+b(x,u)u\rho^{p}

\displaystyle\leq\frac{pK\Lambda}{r}\,\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}|\nabla u|^{p}\rho^{p}\right]^{\frac{1}{p^{\prime}}}\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}|u|^{p}\right]^{\frac{1}{p}}

\displaystyle\leq\frac{pK\Lambda}{r}\frac{1}{\lambda^{\frac{1}{p^{\prime}}}}\,\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}\lambda|\nabla u|^{p}\rho^{p}\right]^{\frac{1}{p^{\prime}}}\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}|u|^{p}\right]^{\frac{1}{p}}

\displaystyle\leq\frac{pK\Lambda}{r}\frac{1}{\lambda^{\frac{1}{p^{\prime}}}}\,\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}\lambda|\nabla u|^{p}\rho^{p}+b(x,u)u\rho^{p}\right]^{\frac{1}{p^{\prime}}}\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}|u|^{p}\right]^{\frac{1}{p}}

and thus for some constant
C>0
,

\left[\int_{B_{r}}\lambda|\nabla u|^{p}\rho^{p}+b(x,u)u\rho^{p}\right]^{\frac{1}{p}}\leq\frac{C}{r}\left[\int_{B_{r}\backslash B_{\frac{r}{2}}}|u|^{p}\right]^{\frac{1}{p}}

which leads to

\int_{B_{\frac{r}{2}}}\lambda|\nabla u|^{p}+b(x,u)u\ \leq\left(\frac{C}{r}\right)^{p}\,\int_{B_{r}\backslash B_{\frac{r}{2}}}|u|^{p}.

If
u
is supposed to be uniformly bounded, then one gets

\int_{B_{\frac{r}{2}}}\lambda|\nabla u|^{p}+b(x,u)u\leq Cr^{n-p}.

(3.9)

for some other constant
C
. From (
3.8
), we derive then

\int_{B_{\frac{r}{2^{k+1}}}}\lambda|\nabla u|^{p}+b(x,u)u\leq\frac{C}{r^{k({1-\frac{\ell}{p}})}}r^{n-p}\to 0\text{ when }r\to\infty\text{ and }k({1-\frac{\ell}{p}})>p-n.

This completes the proof of Theorem
3.1
.
∎

4
Existence of a nontrivial solution

In this section, we would like to construct a nontrivial bounded
solution to the equation

-\Delta_{p}u+b\,u=0\qquad\text{in $\mathcal{D}^{\prime}(\mathbb{R}^{n})$,}

(4.1)

when
b=b(x)
is nonnegative. Here, a function
u
is call a

solution
to (
4.1
) if
u\in W^{1,p}_{\ell oc}(\mathbb{R}^{n})
and
for every open bounded subset
\Omega\subseteq\mathbb{R}^{n}
,

\int_{\Omega}|\nabla u|^{p-2}\nabla u\cdot\nabla v+b(x)|u|^{p-2}uv=0~~\forall v\in W^{1,p}_{0}(\Omega).

(4.2)

Recall that
B_{k}
denotes the ball of center
0
and radius
k
. Then,
for every
k\in\mathbb{N}
, there exists a unique solution
u_{k}
to the variational inequality

\begin{cases}u_{k}\in K=\{v\in W^{1,p}(B_{k}):v=1\text{ on }\partial B_{k}\},\cr\cr\displaystyle\int_{B_{k}}|\nabla u_{k}|^{p-2}\nabla u_{k}\cdot\nabla(v-u_{k})+b(x)|u_{k}|^{p-2}u_{k}(v-u_{k})\geq 0~~\forall v\in K.\cr\end{cases}

(4.3)

We refer, for instance, to
[
11
]
,
[
4
]
or to the
Remark
3
below.

1. Claim:
0\leq u_{k}\leq 1
on
B_{k}

Recall that
w^{+}(x):=\max\{0,w(x)\}
denotes the
positive part of a function
w
and
w^{-}:=(-w)^{+}
the negative
part. Then, taking
v=u_{k}^{+}
as a test function in (
4.3
) and by using
that
u_{k}^{+}-u_{k}=u_{k}^{-}
, it comes

\int_{B_{k}}|\nabla u_{k}|^{p-2}\nabla u_{k}\cdot\nabla u_{k}^{-}+b|u_{k}|^{p-2}u_{k}u_{k}^{-}=-\int_{B_{k}}|\nabla u_{k}^{-}|^{p-2}\nabla u_{k}^{-}\cdot\nabla u_{k}^{-}+b|u_{k}|^{p-2}u_{k}^{-}u_{k}^{-}\geq 0,

from where we can conclude that

\int_{B_{k}}|\nabla u_{k}^{-}|^{p}+b|u_{k}^{-}|^{p}\leq 0.

Thus,
u_{k}^{-}=0
on
B_{k}
, which implies that
u_{k}\geq 0
on
B_{k}
.

Taking
v=u_{k}\pm(u_{k}-1)^{+}
in (
4.3
), one gets

\int_{B_{k}}|\nabla u_{k}|^{p-2}\nabla u_{k}\cdot\nabla(u_{k}-1)^{+}+b|u_{k}|^{p-2}u_{k}(u_{k}-1)^{+}=0

and hence,

\int_{B_{k}}|\nabla u_{k}|^{p-2}\nabla(u_{k}-1)\cdot\nabla(u_{k}-1)^{+}=-\int_{B_{k}}b|u_{k}|^{p-2}u_{k}(u_{k}-1)^{+}\leq 0.

Thus
(u_{k}-1)^{+}=0
, i.e.
u_{k}\leq 1
.

2. Claim:
u_{k+1}\leq u_{k}
on
B_{k}

Clearly
(u_{k+1}-u_{k})^{+}\in W^{1,p}_{0}(B_{k})
. We now suppose that this
function is extended by
0
on
B_{k+1}
. Taking
v=u_{k}\pm(u_{k+1}-u_{k})^{+}
in (
4.3
), we get that

\int_{B_{k}}|\nabla u_{k}|^{p-2}\nabla u_{k}\cdot\nabla(u_{k+1}-u_{k})^{+}+b|u_{k}|^{p-2}u_{k}(u_{k+1}-u_{k})^{+}=0.

Similarly, taking
v=u_{k+1}\pm(u_{k+1}-u_{k})^{+}
in (
4.3
) gives

\int_{B_{k}}|\nabla u_{k+1}|^{p-2}\nabla u_{k+1}\cdot\nabla(u_{k+1}-u_{k})^{+}+b|u_{k+1}|^{p-2}u_{k+1}(u_{k+1}-u_{k})^{+}=0.

By subtraction, it comes

\displaystyle\int_{B_{k}}\{|\nabla u_{k+1}|^{p-2}\nabla u_{k+1}-

\displaystyle|\nabla u_{k}|^{p-2}\nabla u_{k}\}\cdot\nabla(u_{k+1}-u_{k})^{+}

\displaystyle+b\{|u_{k+1}|^{p-2}u_{k+1}-|u_{k}|^{p-2}u_{k}\}(u_{k+1}-u_{k})^{+}=0.

Thus for some constant
c_{p}>0
, it comes (see, for example,
[
4
]
)

c_{p}\int_{B_{k}}\big(|\nabla u_{k+1}|+|\nabla u_{k}|\big)^{p-2}|\nabla(u_{k+1}-u_{k})^{+}|^{2}\leq 0,

implying that
(u_{k+1}-u_{k})^{+}=0
on
B_{k}
, which is
u_{k+1}\leq u_{k}
on
B_{k}
.

From the Claim 1. and Claim 2., we derive that

u_{k}(x)\to u(x)\qquad\text{pointwise for a.e. $x\in\mathbb{R}^{n}$,}

(4.4)

where
u:\mathbb{R}^{n}\to\mathbb{R}
is a function satisfying

0\leq u\leq 1\qquad\text{on $\mathbb{R}^{n}$}.

3. Claim: If
b
is radially symmetric, so is
u_{k}
and
u
.

If
R=(R_{j,k})
is an orthogonal transformation, then one has with the summation convention

\displaystyle\nabla\{v(Rx)\}

\displaystyle=(\partial_{y_{j}}v(Rx)\partial_{x_{i}}R_{j,k}x_{k})

\displaystyle=(R_{j,i}\partial_{y_{j}}v(Rx))=R^{T}\{\nabla v\}(Rx).

Thus one has, by a change of variable

\displaystyle\int_{B_{k}}|\nabla\{u_{k}(Rx)\}|^{p-2}\nabla\{u_{k}(Rx)\}

\displaystyle\cdot\nabla\{(v(Rx)-u_{k}(Rx))\}

\displaystyle+b|u_{k}(Rx)|^{p-2}u_{k}(Rx)(v(Rx)-u_{k}(Rx))\geq 0

for any
v\in W^{1,p}_{0}(B_{k}),~v=1
on
\partial B_{k}
. Choosing
v(R^{T}x)
we see, by uniqueness of
u_{k}
that

u_{k}(Rx)=u_{k}(x)

for any orthogonal transformation
R
.

Remark 3
.

Taking
v=u_{k}\pm\varphi
for

in (

), one sees that
u_{k}

u_{k}\in K\quad\text{ and }\quad\int_{B_{k}}|\nabla u_{k}|^{p-2}\nabla u_{k}\cdot\nabla\varphi+b|u_{k}|^{p-2}u_{k}\varphi=0~~\forall\varphi\in W^{1,p}_{0}(B_{k}),

(4.5)

that is,
u_{k}
is a
weak solution
of the nonlinear Dirichlet problem

\displaystyle-\Delta_{p}u_{k}+b\,|u_{k}|^{p-2}u_{k}

\displaystyle=0\quad

\displaystyle\text{in $B_{k}$,}

\displaystyle u_{k}

\displaystyle=1\quad

\displaystyle\text{on $\partial B_{k}$.}

Note that
u_{k}
is also the unique minimiser on
K
to

J(v)=\int_{B_{k}}|\nabla v|^{p}+b|v|^{p}.

From now on, we suppose that

\displaystyle b\text{ is radially symmetric with compact support, i.e. }

(4.6)

\displaystyle b(x)=b(|x|)=0\qquad\text{ for all}~|x|=r\geq r_{0}.

Since the function

, one has then

\int_{B_{k}}|\nabla u_{k}|^{p}+b|u_{k}|^{p}=J(u_{k})\leq J(1)=\int_{\mathbb{R}^{n}}b<+\infty.

Thus, up to a subsequence,

\nabla u_{k}\rightharpoonup\nabla u\text{ in }L^{p}(\Omega)

(4.7)

for every bounded subdomain

\mathbb{R}^{n}
.

4. Differential equation satisfied by
u_{k}
and
u
.

If
u_{k}=u_{k}(r)
, then

\nabla u_{k}=u^{\prime}_{k}(r)\nabla r=u^{\prime}_{k}(r)\frac{x}{r}\quad\text{ and
}\quad|\nabla u_{k}|=|u^{\prime}_{k}(r)|.

From this, it follows that

\displaystyle\nabla\cdot(|\nabla u_{k}|^{p-2}\nabla u_{k})

\displaystyle=\partial_{x_{i}}(|u^{\prime}_{k}|^{p-2}u^{\prime}_{k}\frac{x_{i}}{r})

\displaystyle=|u^{\prime}_{k}|^{p-2}u^{\prime}_{k}\partial_{x_{i}}\{\frac{x_{i}}{r}\}+(|u^{\prime}_{k}|^{p-2}u^{\prime}_{k})^{\prime}\frac{x_{i}}{r}\frac{x_{i}}{r}

\displaystyle=|u^{\prime}_{k}|^{p-2}u^{\prime}_{k}(\frac{n}{r})+|u^{\prime}_{k}|^{p-2}u^{\prime}_{k}x_{i}\big(-\frac{1}{r^{2}}\big)\frac{x_{i}}{r}\ +(|u^{\prime}_{k}|^{p-2}u^{\prime}_{k})^{\prime}

\displaystyle=|u^{\prime}_{k}|^{p-2}u^{\prime}_{k}(\frac{n-1}{r})+(|u^{\prime}_{k}|^{p-2}u^{\prime}_{k})^{\prime}

\displaystyle=\frac{1}{r^{n-1}}\Big(|u^{\prime}_{k}|^{p-2}u^{\prime}_{k}(n-1)r^{n-2}+r^{n-1}(|u^{\prime}_{k}|^{p-2}u^{\prime}_{k})^{\prime}\Big)

\displaystyle=\frac{1}{r^{n-1}}(|u^{\prime}_{k}|^{p-2}u^{\prime}_{k}r^{n-1})^{\prime}.

Thus from (
4.5
), one derives that
u_{k}
satisfies

\displaystyle\frac{1}{r^{n-1}}(|u^{\prime}_{k}|^{p-2}u^{\prime}_{k}r^{n-1})^{\prime}

\displaystyle=b|u_{k}|^{p-2}u_{k}\qquad\text{for $0<r<k$,}

which is equivalent to

\displaystyle(|u^{\prime}_{k}|^{p-2}u^{\prime}_{k}r^{n-1})^{\prime}

\displaystyle=r^{n-1}b|u_{k}|^{p-2}u_{k}\qquad\text{for $0<r<k$,}

and again, equivalent to

\displaystyle|u^{\prime}_{k}(r)|^{p-2}u^{\prime}_{k}(r)

\displaystyle=\frac{1}{r^{n-1}}\int_{0}^{r}s^{n-1}b|u_{k}|^{p-2}u_{k}ds\qquad\text{for $0<r<k$.}

Setting
\Psi(x)=|x|^{p-2}x
for
x\in\mathbb{R}
, then
\psi
is bijective on
\mathbb{R}
and
its inverse is
\Psi^{-1}(x)=|x|^{\frac{1}{p-1}}\sign x
, where
\sign x

denotes the sign of
x
. One gets

u^{\prime}_{k}=\Psi^{-1}(\frac{1}{r^{n-1}}\int_{0}^{r}s^{n-1}b|u_{k}|^{p-2}u_{k}ds)\qquad\text{for $0<r<k$.}

(4.8)

From (
4.7
), one has up to a subsequence still labelled by
k

\nabla u_{k}=u^{\prime}_{k}\frac{x}{r}\rightharpoonup u^{\prime}\frac{x}{r}\text{ in }L^{p}(\Omega)

(4.9)

for every open and bounded subset
\Omega\subseteq\mathbb{R}^{n}
. Thus and by
using (
4.4
), multiplying (
4.8
) with
x/r

for
r>0
and subsequently passing to the limit, we arrive
to

\displaystyle u^{\prime}(r)\frac{x}{r}

\displaystyle=\frac{x}{r}\Psi^{-1}(\frac{1}{r^{n-1}}\int_{0}^{r}s^{n-1}b|u|^{p-2}uds)\qquad\text{for $r>0$,}

which is equivalent to

\displaystyle u^{\prime}(r)

\displaystyle=\Psi^{-1}(\frac{1}{r^{n-1}}\int_{0}^{r}s^{n-1}b|u|^{p-2}uds)\qquad\text{for $r>0$,}

and

\displaystyle\Psi(u^{\prime})=|u^{\prime}|^{p-2}u^{\prime}

\displaystyle=\frac{1}{r^{n-1}}\int_{0}^{r}s^{n-1}b|u|^{p-2}uds\qquad\text{for $r>0$.}

Multiplying the last equation by
r^{n-1}
and subsequently,
differentiating it, shows that
u
satisfies

-\frac{1}{r^{n-1}}(|u^{\prime}|^{p-2}u^{\prime}r^{n-1})^{\prime}+b|u|^{p-2}u=0\qquad\text{in $(0,\infty)$,}

that is,

satisfies the same equation as
u_{k}
in all

We would like to show now that
u
is nontrivial.

5. The limit of
u_{k}
cannot be identically
0
, that is,
u
is nontrivial.

Due to the definition of
b
, one has that

(|u^{\prime}_{k}|^{p-2}u^{\prime}_{k}r^{n-1})^{\prime}=0\text{ for }r\geq r_{0}.

Thus

|u^{\prime}_{k}|^{p-2}u^{\prime}_{k}r^{n-1}=C_{k}\text{ for }r\geq r_{0}.

where

is some constant. Thus for

one has

u^{\prime}_{k}=\Psi^{-1}(\frac{C_{k}}{r^{n-1}})=|C_{k}|^{\frac{1}{p-1}}\sign C_{k}\frac{1}{r^{\frac{n-1}{p-1}}}.

Integrating between
r_{0}
and
r
, we get

u_{k}(r)-u_{k}(r_{0})=|C_{k}|^{\frac{1}{p-1}}\sign C_{k}\,\int_{r_{0}}^{r}\frac{1}{r^{\frac{n-1}{p-1}}}.

(4.10)

Now, if
u_{k}(r)\to 0
pointwise, (
4.10
)
implies that
C_{k}\to 0
. On the other hand, choosing

in (

) gives that

1-u_{k}(r_{0})=|C_{k}|^{\frac{1}{p-1}}\sign C_{k}\,\int_{r_{0}}^{k}\frac{1}{r^{\frac{n-1}{p-1}}}

(4.11)

for every

. If

, then the integral above converges
and so, we arrive to a contradiction when we send

in (
4.11
). Thus we have proved

.

In the case

(

5
Concluding remark

We would like to show briefly here how Theorem
3.1
can be
extended in the case of several
p
-Laplacian type operators. Suppose
that
u
is a solution to (
2.2
). Arguing as in (
3.5
) and
(
3.6
), one gets that

\int_{B_{r}}\lambda\sum_{i=1}^{N}|\nabla u|^{p_{i}}~\rho^{p}(\frac{x}{r})+b(x,u)u\rho^{p}(\frac{x}{r})\leq\frac{pK\Lambda}{r}\int_{B_{r}\backslash B_{\frac{r}{2}}}\sum_{i=1}^{N}|\nabla u|^{p_{i}-1}\rho^{\frac{p}{p^{\prime}_{i}}}\rho^{\frac{p-p_{i}}{p_{i}}}|u|.

(5.1)

Using the Hölder inequality we derive

\displaystyle\int_{B_{r}}\lambda\sum_{i=1}^{N}|\nabla u|^{p_{i}}~\rho^{p}(\frac{x}{r})

\displaystyle+b(x,u)u\rho^{p}(\frac{x}{r})

\displaystyle\leq\frac{pK\Lambda}{r}\sum_{i=1}^{N}\Big(\int_{B_{r}\backslash B_{\frac{r}{2}}}|\nabla u|^{p_{i}}\rho^{p}\Big)^{\frac{1}{p^{\prime}_{i}}}\Big(\int_{B_{r}\backslash B_{\frac{r}{2}}}\rho^{p-p_{i}}|u|^{p_{i}}\Big)^{\frac{1}{p_{i}}}.

Assuming then for
x
large enough and for all
i

b(x,u)u\geq\frac{c}{r^{\ell}}|u|^{p_{i}},~~c>0,\ell<p_{1}\leq p_{i}

we get

\displaystyle\int_{B_{r}}\lambda\sum_{i=1}^{N}|\nabla u|^{p_{i}}~\rho^{p}(\frac{x}{r})

\displaystyle+b(x,u)u\rho^{p}(\frac{x}{r})

\displaystyle\leq\frac{pK\Lambda}{r^{1-\frac{\ell}{p_{1}}}}\sum_{i=1}^{N}\Big(\int_{B_{r}\backslash B_{\frac{r}{2}}}|\nabla u|^{p_{i}}\rho^{p}\Big)^{\frac{1}{p^{\prime}_{i}}}\Big(\int_{B_{r}\backslash B_{\frac{r}{2}}}\rho^{p-p_{i}}\frac{1}{c}b(x,u)u\Big)^{\frac{1}{p_{i}}}.

Then applying the Young inequality

ab\leq\frac{1}{p^{\prime}_{i}}a^{p^{\prime}_{i}}+\frac{1}{p_{i}}b^{p_{i}},~~a,b\geq 0

it comes easily for some constant
C

\int_{B_{r}}\lambda\sum_{i=1}^{N}|\nabla u|^{p_{i}}~\rho^{p}(\frac{x}{r})+b(x,u)u\rho^{p}(\frac{x}{r})\leq\frac{C}{r^{1-\frac{\ell}{p_{1}}}}\int_{B_{r}\backslash B_{\frac{r}{2}}}\sum_{i=1}^{N}\lambda|\nabla u|^{p_{i}}\rho^{p}+\rho^{p-p_{i}}b(x,u)u

and thus, if

, for some constant

, we get

\int_{B_{\frac{r}{2}}}\lambda\sum_{i=1}^{N}|\nabla u|^{p_{i}}+b(x,u)u\leq\frac{C}{r^{1-\frac{\ell}{p_{1}}}}\int_{B_{r}}\lambda\sum_{i=1}^{N}|\nabla u|^{p_{i}}+b(x,u)u.

Iterating this formula, one gets

\int_{B_{\frac{r}{2^{k+1}}}}\lambda\sum_{i=1}^{N}|\nabla u|^{p_{i}}+b(x,u)u\leq\frac{C^{k}}{r^{k(1-\frac{\ell}{p_{1}})}}\int_{B_{\frac{r}{2}}}\lambda\sum_{i=1}^{N}|\nabla u|^{p_{i}}+b(x.u)u.

(5.2)

Going back to (
5.1
) and using (
2.8
) (taking

), we obtain that

\int_{B_{r}}\lambda\sum_{i=1}^{N}|\nabla u|^{p_{i}}\rho^{p}+b(x,u)u\rho^{p}\leq\varepsilon\int_{B_{r}}\lambda\sum_{i=1}^{N}|\nabla u|^{p_{i}}\rho^{p}+C_{\varepsilon}\int_{B_{r}}\sum_{i=1}^{N}\frac{|u|^{p_{i}}}{r^{p_{i}}}

and

If

By (

\int_{B_{\frac{r}{2^{k+1}}}}\lambda\sum_{i=1}^{N}|\nabla u|^{p_{i}}+b(x,u)u\leq C\sum_{i=1}^{N}\frac{1}{r^{k(1-\frac{\ell}{p_{1}})+p_{i}-n}}\to 0\text{ for }k(1-\frac{\ell}{p_{1}})>n-p_{i}.
