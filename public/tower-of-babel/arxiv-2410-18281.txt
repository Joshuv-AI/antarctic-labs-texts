Abstract
. We construct a set of 2 n 2^{n} points in ℝ n \mathbb{R}^{n} such that all pairwise Manhattan distances are odd integers, which improves the recent linear lower bound of Golovanov, Kupavskii and Sagdeev. In contrast to the Euclidean and maximum metrics, this shows that the odd-distance set problem behaves very differently to the equilateral set problem under the Manhattan metric. Moreover, all coordinates of the points in our construction are integers or half-integers, and we show that our construction is optimal under this additional restriction.

To prove the lower bound on
\odd_{1}(n)

2^{n}

\mathbb{R}^{n+1}

Lemma 4

For every
x\in\frac{1}{2}\cdot\mathbb{Z}

\mathcal{P}\subseteq(\frac{1}{2}\cdot\mathbb{Z})^{2}
of size

such that the coordinates of each point sum to

Proof.

If

\mathcal{P}=\bigg\{\biggl(\frac{x}{2}+\frac{1}{2},\frac{x}{2}-\frac{1}{2}\biggr),\biggl(\frac{x}{2},\frac{x}{2}\biggr)\bigg\}.

x\in\mathbb{Z}+\frac{1}{2}

\mathcal{P}=\bigg\{\biggl(\frac{x}{2}+\frac{1}{4},\frac{x}{2}-\frac{1}{4}\biggr),\biggl(\frac{x}{2}-\frac{1}{4},\frac{x}{2}+\frac{1}{4}\biggr)\bigg\}.

Clearly, in both cases

satisfies the claim.

Finally, we show that we may assume all points in
\ell_{1}
-odd-distance sets
\mathcal{P}
have rational coordinates.
Indeed, the pairwise distances between the points of
\mathcal{P}
can be expressed by a system of linear equations on the coordinates of the points of
\mathcal{P}
.
Solutions to this system of linear equations can be characterised by a set of free variables whose choice determines all other variables.
If we now replace all coordinates corresponding to free variables by nearby rational numbers, this determines all remaining coordinates, and those coordinates will also be rational since the coefficients of the linear equations were rational.
This gives a point set with rational coefficients, and if the order of the coordinates did not change, then the distances between the points remain the same.
So, the point set will be an odd-distance set.

Lemma 5
.

For any
\ell_{1}
-odd-distance set
\mathcal{P}\subseteq\mathbb{R}^{n}
, there exists an odd-distance set
\mathcal{Q}\subseteq\mathbb{Q}^{n}
of the same size as
\mathcal{P}
.

Proof.

By iteratively translating coordinates as in the proof of
Theorem

1
, we may assume that
\lvert p_{i}-q_{i}\rvert\geqslant 2
for all distinct points
\boldsymbol{\mathsf{p}},\boldsymbol{\mathsf{q}}\in\mathcal{P}
and all
i\in[n]
.
Let
s_{i}^{\boldsymbol{\mathsf{p}},\boldsymbol{\mathsf{q}}}\coloneqq 1
if
p_{i}>q_{i}
and
s_{i}^{\boldsymbol{\mathsf{p}},\boldsymbol{\mathsf{q}}}\coloneqq-1
otherwise.
Then,

\lVert\boldsymbol{\mathsf{p}}-\boldsymbol{\mathsf{q}}\rVert_{1}=\sum_{i=1}^{n}s_{i}^{\boldsymbol{\mathsf{p}},\boldsymbol{\mathsf{q}}}(p_{i}-q_{i}).

Write
d_{\boldsymbol{\mathsf{p}},\boldsymbol{\mathsf{q}}}\coloneqq\lVert\boldsymbol{\mathsf{p}}-\boldsymbol{\mathsf{q}}\rVert_{1}
and introduce a variable
x_{\boldsymbol{\mathsf{p}},i}
for all
\boldsymbol{\mathsf{p}}\in\mathcal{P}
and all
i\in[n]
.
This means that the system of linear equations

\sum_{i=1}^{n}s_{i}^{\boldsymbol{\mathsf{p}},\boldsymbol{\mathsf{q}}}\left(x_{\boldsymbol{\mathsf{p}},i}-x_{\boldsymbol{\mathsf{q}},i}\right)=d_{\boldsymbol{\mathsf{p}},\boldsymbol{\mathsf{q}}}

for all distinct
\boldsymbol{\mathsf{p}},\boldsymbol{\mathsf{q}}\in\mathcal{P}
has a solution given by
x_{\boldsymbol{\mathsf{p}},i}=p_{i}
for all
\boldsymbol{\mathsf{p}}\in\mathcal{P}
and all
i\in[n]
.

Since all coefficients and all
d_{\boldsymbol{\mathsf{p}},\boldsymbol{\mathsf{q}}}
are integers, the reduced row echelon form of this system of linear equations only has rational coefficients.
Thus, in the reduced row echelon form, there exists a set of indices
\mathcal{F}\subseteq\mathcal{P}\times[n]
such that
x_{f}
is a free variable for all
f\in\mathcal{F}
while
x_{g}
is a dependent variable for all
g\notin\mathcal{F}
, with
x_{g}=a_{g}+\sum_{f\in\mathcal{F}}b_{f,g}x_{f}
for some

.

Let
C\coloneqq\max_{f\in\mathcal{F},g\notin\mathcal{F}}\lvert b_{f,g}\rvert
.
For each
(\boldsymbol{\mathsf{p}},i)\in\mathcal{F}
, choose

so that
\lvert y_{\boldsymbol{\mathsf{p}},i}-p_{i}\rvert<1/(C\lvert\mathcal{P}\rvert n)
.
For each
(\boldsymbol{\mathsf{p}},i)\notin\mathcal{F}
let
y_{\boldsymbol{\mathsf{p}},i}=a_{\boldsymbol{\mathsf{p}},i}+\sum_{f\in\mathcal{F}}b_{f,(\boldsymbol{\mathsf{p}},i)}y_{f}
, and note that
y_{\boldsymbol{\mathsf{p}},i}\in\mathbb{Q}
and

\displaystyle\lvert y_{\boldsymbol{\mathsf{p}},i}-p_{i}\rvert

\displaystyle=\left\lvert\left(a_{\boldsymbol{\mathsf{p}},i}+\sum_{(\boldsymbol{\mathsf{q}},j)\in\mathcal{F}}b_{(\boldsymbol{\mathsf{q}},j),(\boldsymbol{\mathsf{p}},i)}y_{\boldsymbol{\mathsf{q}},j}\right)-\left(a_{\boldsymbol{\mathsf{p}},i}+\sum_{(\boldsymbol{\mathsf{q}},j)\in\mathcal{F}}b_{(\boldsymbol{\mathsf{q}},j),(\boldsymbol{\mathsf{p}},i)}q_{j}\right)\right\rvert

\displaystyle\leqslant\sum_{(\boldsymbol{\mathsf{q}},j)\in\mathcal{F}}\left\lvert b_{(\boldsymbol{\mathsf{q}},j),(\boldsymbol{\mathsf{p}},i)}\left(y_{\boldsymbol{\mathsf{q}},j}-q_{j}\right)\right\rvert<\frac{\lvert\mathcal{F}\rvert C}{C\lvert\mathcal{P}\rvert n}\leqslant 1,

where the first equality used the fact that
x_{\boldsymbol{\mathsf{p}},i}=p_{i}
is a solution to the system of equations.

For each
\boldsymbol{\mathsf{p}}\in\mathcal{P}
, let
\boldsymbol{\mathsf{p}}^{\prime}\in\mathbb{Q}^{n}
be the point with
p^{\prime}_{i}=y_{\boldsymbol{\mathsf{p}},i}
.

\boldsymbol{\mathsf{p}},\boldsymbol{\mathsf{q}}\in\mathcal{P}
.
For each
i

, then
p_{i}+2\leqslant q_{i}
by assumption, and since
\lvert p^{\prime}_{i}-p_{i}\rvert<1

, this implies that
p^{\prime}_{i}<q^{\prime}_{i}
.
Similarly, if
p_{i}>q_{i}
, then
p^{\prime}_{i}>q^{\prime}_{i}
.
Therefore,

\lVert\boldsymbol{\mathsf{p}}^{\prime}-\boldsymbol{\mathsf{q}}^{\prime}\rVert_{1}=\sum_{i=1}^{n}s_{i}^{\boldsymbol{\mathsf{p}},\boldsymbol{\mathsf{q}}}(p^{\prime}_{i}-q^{\prime}_{i})=d_{\boldsymbol{\mathsf{p}},\boldsymbol{\mathsf{q}}},

where the last equality uses the fact that

is a solution to the system of equations.

\mathcal{P}
.
