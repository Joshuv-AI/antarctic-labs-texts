Minimal simplicial spherical mappings with a given degree
Ksenia Apolonskaya, Oleg R. Musin

Abstract
This paper studies the minimal number of vertices λ ⁡ ( n ​ ; ​ d ) \lambda(n\mathord{\mathchar 59\relax}d) required in a triangulation of the n n -sphere to admit a simplicial map to the boundary of a ( n + 1 ) (n+1) -simplex with a given degree d d . We establish upper bounds for λ ⁡ ( n ​ ; ​ d ) \lambda(n\mathord{\mathchar 59\relax}d) in dimensions n ≥ 3 n\geq 3 and introduce a new function α ⁡ ( n ) := lim sup d → ∞ λ ⁡ ( n ​ ; ​ d ) d . \alpha(n):=\limsup_{d\to\infty}{\frac{\lambda(n\mathord{\mathchar 59\relax}d)}{d}}. Our main result establishes that it does not exceed n + 2 n \frac{n+2}{n} . Furthermore, we provide exact formulas for small values of d d , showing that λ ⁡ ( n ​ ; ​ d ) = n + d + 3 \lambda(n\mathord{\mathchar 59\relax}d)=n+d+3 for n ≥ 3 n\geq 3 and d = 2 ​ ; ​ 3 ​ ; ​ 4 d=2\mathord{\mathchar 59\relax}3\mathord{\mathchar 59\relax}4 . A key technical result is the identity λ ⁡ ( n ​ ; ​ d ) = λ ⁡ ( d − 1 ​ ; ​ d ) + n − d + 1 \lambda(n\mathord{\mathchar 59\relax}d)=\lambda(d-1\mathord{\mathchar 59\relax}d)+n-d+1 for n ≥ d n\geq d , which allows us to reduce higher-dimensional cases to lower-dimensional ones. The proofs involve constructive methods based on local modifications of triangulations and combinatorial arguments.

Proof of the main theorems

2.1
Auxiliary lemmas.

Lemma 1
.

\lambda(n+1\mathord{\mathchar 59\relax}d)\leq\lambda(n\mathord{\mathchar 59\relax}d)+1

Proof.

Let
K
be a triangulation of
S^{n}
with
\lambda(n\mathchar 59\relax d)
vertices. Triangulate the interior of
K
arbitrarily. Let us add a new vertex
x
and consider the join with the boundary. This gives a triangulation
K^{\prime}
of
S^{n+1}
with
\lambda(n\mathchar 59\relax d)+1
vertices. The degree will remain the same because, if a simplex in K was positively oriented, then the simplex with the added vertex x will also be positively oriented. The same reasoning holds for the negative case.
∎

Lemma 2
.

If
\lambda(n\mathchar 59\relax d)\leq 2n+3
, then
\lambda(n\mathchar 59\relax d)\geq\lambda(n-1\mathord{\mathchar 59\relax}d)+1

Proof.

\Delta^{n+1}
contains
n+2
vertices. If the triangulation of the second sphere has no more than
2n+3
vertices, then some vertex has a single preimage. Removing it and the interior of the remaining disk, we reduce the dimension by 1, while the degree remains unchanged.
∎

Lemma 3
.

If
n\geq d-1
, then
\lambda(n\mathord{\mathchar 59\relax}d)\geq\lambda(d-1\mathchar 59\relax d)+n-d+1

Proof.

We know that for
n\geq d
,
\lambda(n\mathord{\mathchar 59\relax}d)\leq n+d+3
from Article
[
1
]
. Then
\lambda(n\mathord{\mathchar 59\relax}d)\leq n+d+3\leq 2n+3
, and from the previous statement it follows that
\lambda(n\mathord{\mathchar 59\relax}d)\geq\lambda(n-1\mathord{\mathchar 59\relax}d)+1
. Similarly, descending to
n=d
, we obtain that
\lambda(n\mathord{\mathchar 59\relax}d)\geq\lambda(d-1\mathord{\mathchar 59\relax}d)+n-d+1
.
∎

Lemma 4
.

\lambda(3\mathord{\mathchar 59\relax}4)=10

Proof.

First prove that

\lambda(3\mathord{\mathchar 59\relax}4)\geq 10.

\Delta^{4}
contains five vertices. Each vertex with number

has a set of preimages, let’s call it

. If all

, then
\lambda(3\mathchar 59\relax 4)\geq 10
. Now consider the case when

. Then

is connected by edges to some vertices. Remove
U_{1}
, as well as the vertices not connected to it and the edges. We obtain a triangulation of

, the degree of the mapping remains equal to 4, but the number of vertices in it is at least
\lambda(2\mathord{\mathchar 59\relax}4)=10
. So, together with

we have 11 vertices.

We now present an example with 10 vertices. Let’s take the standard simplex with vertices
u_{1}\mathchar 59\relax u_{2}\mathchar 59\relax u_{3}\mathchar 59\relax u_{4}\mathchar 59\relax u_{5}
. Let’s observe the
