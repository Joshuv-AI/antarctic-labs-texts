Scalable joint non-negative matrix factorization for paired single cell gene expression and chromatin accessibility data
Authors: William Morgans, Andrew D Sharrocks, Mudassar Iqbal
Published: 2026

ABSTRACT
AbstractSingle-cell multi-modal technologies provide powerful means to simultaneously profile cellular states. These are now being employed to study gene regulatory mechanisms in a variety of biological systems. Tailored computational methods for integration and analysis of these data are much needed, with desirable properties in terms of efficiency—to cope with high dimensionality of the data, interpretability—for downstream biological discovery and hypothesis generation, and flexibility—to easily incorporate future modalities. Existing methods cover some but not all of the desirable properties for effective integration and analysis of these data. Here, we present a highly efficient method, q-intNMF, for representation and integration of single-cell multi-modal data using joint non-negative matrix factorization, which can facilitate discovery of linked regulatory topics in each modality. We provide thorough benchmarking using large publicly available datasets against five popular existing methods. q-intNMF performs comparably against the current state-of-the-art methods across a range of metrics. Additionally, q-intNMF provides advantages in terms of computational efficiency and interpretability of discovered regulatory topics in the original feature space. We illustrate this enhanced interpretability in providing insights into cell state changes associated with Alzheimer’s disease. q-intNMF is available as a Python package with extensive documentation and use cases at https://github.com/wmorgans/quick_intNMF.

Introduction

High-throughput single-cell ’omics technologies have emerged as important tools in studying single-cell states in complex tissues, ranging from developmental studies to complex diseases such as cancer. Recently, technologies have been developed that enable simultaneous omics measurements in single cells [1]. For example, methylome and transcriptome [2]; chromatin and transcriptome [3, 4]; as well as triplets, chromatin, transcriptome, and surface proteins [5]. These technologies help reveal regulatory changes that drive different gene expression programmes and hence better determine cellular identity and function. With 10X Genomics releasing the first commercially available solution (10X Genomics Chromium Single Cell Multiome ATAC + Gene Expression), it is likely the amount of paired ATAC–RNA (chromatin–transcriptome) data will increase. One recent paper identified factors determining lineage plasticity in prostate cancer [6], and another identified genes and genomic regions associated with Alzheimer’s disease [7], both using 10X Multiome data. Given the broad applicability of these technologies, their uptake for studying a variety of biological systems is likely to increase significantly. Hence, new computational methods are required that jointly analyse single-cell RNA and ATAC count matrices and help discover underlying gene regulatory networks.

A key step in multi-modal single-cell integrative analysis is finding a low-dimensional and informative joint embedding from multiple distinct sets of features that capture biologically interesting sources of variation [8]. This is important as it enables all modalities to be used in cell type identification. However, due to high noise levels and differences in features of different modalities, this is a challenging task. Most existing multi-omic integration methods focus on bulk data or single-cell experiments carried out on different cells from the same population [9]. There are a handful of methods for integration of parallel ’omics measurements from single cells. These are either based on metric learning (machine learning to identify a distance metric between data points) to generate multi-modal cell similarity metrics or latent variable modelling/matrix factorization (MF) (finding lower-dimensional matrices whose product recreates the original matrix). Metric learning approaches include Schema [10] and weighted nearest neighbour (Seurat WNN) [11]. Schema applies a quadratic programming formulation to linearly weight features from a secondary modality to maximize agreement with the primary modality. WNN is part of the popular single-cell analysis R package Seurat [11], it calculates cell-specific modality weighting, which is used to create a joint nearest neighbour graph. The cell-specific modality weighting is based on a cell’s similarity to its neighbours in a given modality. These methods are fast but the joint embedding is a large and sparse cell–cell similarity matrix, and importantly, these methods do not link measured features to the embedding and are therefore less interpretable.

MF-based approaches include multi-omic factor analysis (MOFA+) [12, 13], scAI [14], scREG [15], jrSiCKLSNMF [16], LIGER [17–19], MultiVI [20], and MOJITOO [21]. MOFA+ performs probabilistic MF using Bayesian group factor analysis with a variational inference scheme for the updates. This is analogous to probabilistic PCA and produces interpretable results. However, it can take longer to run than gradient descent methods. MultiVI also performs probabilistic MF using a variational autoencoder, facilitating the use of a deep generative model. However, as the method uses a non-linear decoder, there is no direct link between the features and the joint low-dimensional embedding. This trades off biological interpretability to learn non-linear relationships and to better deal with technical sources of noise such as batch effects. MOJITOO uses canonical correlation analysis to create a joint embedding by linearly weighting separate low-dimensional embeddings to maximize their correlation. This method is computationally efficient but the factors of the joint embedding are constructed from modality-specific embeddings, not the original features, making them less interpretable.

Non-negative matrix factorization (NMF) can perform fast and interpretable dimensionality reduction, enabling the speed of metric learning approaches to be combined with the interpretability of MF. NMF-based methods have been successfully applied to bulk multi-omics analysis [22, 23], uni-modal single-cell analysis [24], unpaired single-cell multi-omics (i.e. not measured in the same cells) analysis [17, 25, 26], and, very recently, paired multi-omic analysis [14–16]. scAI [14] applies NMF with a smoothed epigenetics matrix (i.e. pseudo-bulking ATAC data for inference). LIGER [18] was developed to learn a joint representation from unpaired scRNA-seq and scATAC-seq, as a result, it uses a shared feature dimension to integrate the modalities. To achieve this, chromatin accessibility is converted to gene scores, removing intergenic regions, which are informative and often highly cell-type-specific. scREG [15] is also NMF-based; however, it introduces a third matrix based on genomic region and gene pairs (called cis-regulatory potential matrix) and jrSiCKLSNMF, which applies NMF with a Kullback–Leibler (KL) divergence loss term. These methods (with the exception of LIGER) rely on multiplicative updates to perform gradient descent for factorization; however, other update schemes exist that converge faster and more reliably [27]. More recently a method called Mowgli has been developed, which uses optimal transport to optimize a joint NMF model [28]. However, the authors do not recommend running the method on datasets with >1000 cells without GPUs. Additionally, both scAI and scREG require the entire dataset to be loaded into memory, limiting the size of dataset to which they can be applied to.

There are therefore several different options emerging in single-cell multi-modal analysis, but none are ideal, and there is no clear optimal approach that has been adopted by the community. Here, we propose an NMF-based method, called q-intNMF, for the dimensionality reduction and downstream analysis of paired multi-omic single-cell data. It implements a novel joint factorization scheme, with no transformations leading to loss in chromatin accessibility information. It is computationally efficient in terms of memory and time allowing it to scale to large numbers of cells and features. q-intNMF generates an interpretable joint embedding to represent cells from multiple modalities, which can be useful in downstream analysis. The method is implemented in Python and is compatible with the Python single-cell ecosystem (e.g. Scanpy/anndata/MUON [29–31]). Given this, it is also easy to use R for certain downstream analysis tasks due to ease of conversion between anndata objects and Seurat objects with the SeuratDisk R package or anndata2ri Python package.

We quantitatively evaluate q-intNMF against Seurat WNN, scAI, scReg, MOFA+, jrSiCKLSNMF, Mowgli, and MOJITOO on two multiome datasets containing paired gene expression and chromatin accessibility data. q-intNMF and MOFA+ are then applied to a third dataset to compare the biological interpretability of the low-dimensional embeddings by extracting biological insight from the learned topics.

Datasets

Two datasets were used to benchmark q-intNMF against existing methods and third as an example to showcase q-intNMF’s capabilities. All datasets were generated with the 10X multiome kit, and an overview of them is shown in Table 1. The first dataset (PBMC-Multiome) was generated from human peripheral blood mononuclear cells (PBMCs) taken from a female donor and was published by 10X Genomics (website). The second dataset (BMMC-Multiome) was generated from bone marrow mononuclear cells (BMMC) and includes data from 12 healthy human donors processed across multiple sites ([33], GSE194122). This dataset was created for the NeurIPS 2021 Data Integration challenge and was purposefully designed to create batch effects [8]. A third dataset was taken from a recent publication of a post-mortem study of samples taken from the dorsolateral prefrontal cortex (DLPFC) of Alzheimer’s-positive (7 samples) and -negative (8 samples) individuals ([7], GSE214637).

For the RNA modality, this typically involved library-sized normalization followed by log(x+1) transformation, and for the ATAC modality, Term Frequency-Inverse Document Frequency (TF-IDF) transformation the data. Benchmarking

To compare the effectiveness of different methods, a range of metrics was used. The compactness of cell types in the joint embedding was calculated using the silhouette score [34]. This measures the distance (measured in the joint embedding) between cells annotated with the same type relative to the other cell types. The reported value is the normalized value (0–1) given by scIB [35].

Additionally, the ability of the joint embedding to cluster cells was measured, either by generating cell–cell similarity matrices (from the joint embedding), which are then used to perform Leiden clustering or by a cell’s max topic/factor score. The clustering method that produces the best scoring metric (for a given method) is reported here. Cell clusters are compared to known labels and evaluated using normalized mutual information (NMI) [36] and Adjusted Rand Index (ARI) [37]. ARI measures the proportion of cells correctly clustered, adjusted for chance. NMI arises from information theory and describes how much information about the ground truth labels is obtained from the calculated clusters.

Graph connectivity and cell Local Inverse Simpson’s Index (cLISI) were calculated using scIB [35]. They provide a measure of whether neighbours in the nearest neighbour graph share a cell label.

Additionally, we computed metrics that measure methods’ ability to conserve biological variation while removing variation due to batch (iLISI graph, cell cycle, and silhouette score batch), and metrics that quantify clustering performance for cell types found in a small number of batches (isolated labels ASW and isolated labels F1). All of these metrics were calculated using the scIB package [35].

Rank selection

The number of topics is an important hyperparameter to select. By default it is left to the user to select the value based on prior knowledge of the dataset, for example, a good starting point is slightly more than the expected number of cell types and sub-types. However, q-intNMF also provides two functions for model selection. Both methods require multiple models with different numbers of topics to be fit to the data. The number of topics is then selected based on either Bayesian Information Criterion (BIC) or the knee point of the loss as function of topic number.

Results

Benchmarking computational methods for joint embedding of multiome data

We first benchmarked q-intNMF’s ability to generate an informative latent embedding against other published methods for joint analysis of single-cell multi-omics data, using a publicly available 10X Multiome dataset of ~12 000 PBMCs with ground truth cell types annotated (Table 1). Prior to benchmarking, we demonstrated q-intNMF’s stability on the PBMC dataset-multiome (with and without the same random seed) in terms of the cell-topic matrix, topic-feature matrices, and cell clustering (Supplementary Figs S1–S3). The quality of the embedding was measured by its ability to recapture the ground truth cell labels. This was done in two ways, firstly by performing clustering using the embedding and comparing this with the ground truth labels (MI and ARI metrics) and secondly by measuring how compact cells of the same type are in the joint embedding (Silhouette score). The methods included in the benchmark are summarized in Table 2.

Additionally, similar cell types are typically found in adjacent clusters; e.g. B cell progenitor cells and pre-B cells are closely juxtapositioned by the different methods. This indicates the methods can not only identify clusters but also similarities between cell types in these clusters. MOJITOO, MOFA+, and q-intNMF-l1 (topic) have the best overall performance when measured by ARI. All variants of q-intNMF perform comparably to other methods when measured via MI. However, q-intNMF (all variants) and MOFA+ both show superior performance, relative to the other methods, when measured by silhouette score (Fig. 1A). Connectivity and cLISI scores have a small dynamic range, with all methods scoring above 0.9 (max 1, Supplementary Fig. S4A). q-intNMF methods and MOFA show best performance across both metrics. Additionally, we compared q-intNMF and Mowgli on subsets of the PBMC-multiome data. q-intNMF outperforms Mowgli in terms of speed, memory usage and clustering performance (Supplementary Figs S5 and S6). We also note that the metric scores are relatively stable across subsets of the dataset.

Next, we benchmarked the methods on a larger dataset, the BMMC-Multiome, consisting of 69 249 cells and 22 distinct cell types (Table 1). scREG, scAI, and jrSiCKLSNMF are omitted from this analysis, as they encountered memory errors when run on this entire dataset. One example of q-intNMF without L1 regularization is given where k = 15 and epochs = 10. UMAPs generated from each method’s embedding can be found in Supplementary Fig. S8. q-intNMF-l1 (topic) has the best clustering performance measured by ARI, whereas MOJITOO performs best as measured by MI. q-intNMF-l1 (topic), q-intNMF, and MOFA+ have comparable Silhouette Scores. As with the PBMC-multiome data, all methods score above 0.9 on the graph connectivity and cLISI metrics, with q-intNMF-l1 Leiden and MOJITOO performing the best across both metrics (Supplementary Fig. S4B). The BMMC-Multiome also contains batches, so we evaluated the method’s abilities to distinguish biological variation from batch variation. q-intNMF-l1 (topic) best mixes batches in the neighbourhood graph as measured by iLISI graph, and q-intNMF-l1 (topic) and MOFA+ best preserve cell cycle variation (Supplementary Fig. S4C). Whereas q-intNMF and Seurat are best able to identify cell clusters only found in a small number of batches (Supplementary Fig. S4D).

We compared the run time and memory requirements for all methods by sampling increasing number of cells from BMMC-Multiome data (Fig. 1C). All q-intNMF models have similar memory requirements to MOJITOO and Seurat, outperforming existing MF methods jrSiCKLSNMF, scAI, MOFA+, and scREG. This difference is most pronounced compared with the existing NMF methods jrSiCKLSNMF, scAI, and scREG, where results are only shown up to the point where they encounter memory errors (Fig. 1C). q-intNMF’s run time is faster than MOJITOO and Seurat for the k = 15 and epochs = 10 run, equivalent for k = 22, epochs = 75, and β= 20 run (q-intNMF-l1 topic) and slower for k = 80, epochs = 50, and β= 0.1 (q-intNMF-l1 leiden). All q-intNMF methods outperform MOFA+, scREG, and scAI in terms of run time. q-intNMF’s run time and memory requirements are sensitive to the number of topics, k, and epochs, increasing roughly linearly with both (Supplementary Fig. S9). Additionally, the run time of the methods depends on the number of features which they are applied to. MOJITOO acts on hundreds of features (separately low-dimensional representations of the modalities), MOFA+ acts on thousands of selected highly variable features, whereas q-intNMF is applied to all features in the dataset (i.e. 13 431 genes and 116 490 regions). This has the downside of reducing the speed of the method but the benefit that topics are linked to all features in the original data. However, q-intNMF still runs quickly compared to other methods.

Collectively, this benchmarking analysis shows that q-intNMF has competitive performance in terms of clustering of cells; matrix factorization methods, q-intNMF and MOFA+, show superior performance by structure metrics, and q-intNMF has superior run time and memory usage compared to MOFA+ and other NMF-based methods. A typical run of q-intNMF on ~70 000 cells takes ~3–23 min (q-intNMF versus q-intNMF-l1 topic) on a computer with 4 nodes with 16 GB of RAM each. In comparison, with the same setup MOFA+ takes 199 min and Seurat WNN takes 20 min. Besides these performance measures, q-intNMF output is highly interpretable, which greatly facilitates downstream analysis—we show a detailed example through its application on brain multiome data (multiple post-mortem samples, with/without Alzheimer’s disease) in the next section.

Application to dorsolateral prefrontal cortex multiome data

To highlight q-intNMF’s ability to generate a biologically informative joint embedding and topic definitions, it was applied to a recently published 10X multiome dataset comprising ~100 000 brain cells from the DLPFC from post-mortem tissue of donors with and without Alzheimer’s [7]. We compared q-intNMF’s performance to the next best-performing tool, MOFA+. For ease of comparison, the latent dimensions from each method’s embedding are referred to as topics, rather than factors traditionally associated with MOFA+. q-intNMF was run with 25 topics as this was the number of topics that produced the lowest BIC value and was the elbow point of the loss as a function of number of topics (Supplementary Fig. S10C). q-intNMF was run with L1 regularization with β =20 as this level of regularization performed well in the benchmarking and L1 regularization should help the method learn informative features (indicated by sparse and uncorrelated rows of \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{upgreek} \usepackage{mathrsfs} \setlength{\oddsidemargin}{-69pt} \begin{document} $\mathbf {H}$\end{document}, Supplementary Fig. S12). MOFA+ was run with default settings. The proportion of cell types in each sample by disease status and donor can be seen in Supplementary Fig. S13.

UMAPs generated from both q-intNMF and MOFA+ clearly resolve the annotated cell types in the dataset (Fig. 2A). The topics generated by q-intNMF are more cell-type- or even sub-cell-type-specific than the MOFA+ topics, which tend to associate with multiple clusters (Fig. 2B and C and Supplementary Figs S14D and S15D). For example, q-intNMF topic 11 specifies astrocytes on the UMAP and topic 1 highlights a subset of the excitatory neurons (Fig. 2B and Supplementary Fig. S14D). In contrast, MOFA+ topics 4, 6, and 7 have positive and negative weights in the same cell type (Fig. 2C and Supplementary Fig. S15D). While q-intNMF topics are generally cell type-specific, there are a small minority of topics active across cell types, for example, topic 12. In contrast, the majority of MOFA+ topics have positive weights in multiple cell types (Fig. 2D). q-intNMF topics are active in similar cell types, which might be expected to share gene expression programs e.g. topic 5 for inhibitory and excitatory neurons (Fig. 2D). A more detailed analysis of the q-intNMF-derived topic contributions to each cell in the dataset can be seen in Fig. 2E. This further illustrates the specificity of topic-mediated cell designations. A full list of q-intNMF topic-cell type associations can be found in Table 3. Multiple topics may map to the same cell type. Topics are correlated groups of features, and so differential activity within a single cell type could indicate subcell types or different environments or disease states.

To investigate whether the genes and regions with high weights in a topic are associated with each other, we ran PEGS analysis [40]. This takes sets of genes and genomic regions and tests whether they are mutually enriched at different spatial resolutions. Generally, the top gene expression features and chromatin accessibility features from a topic are more spatially proximal than expected by chance, as indicated by the strong purple diagonal in Fig. 3B. This shows strong spatial genomic concordance among corresponding topics in two modalities. Additionally, where there is signal off this diagonal, this is often due to topics jointly contributing to the same cell type. For example, topics 10 and 24 both contribute to defining OPCs, and topics 11 and 16 both contribute to defining the astrocyte cluster (Table 3).

Next, we investigated whether the top RNA features of q-intNMF’s topics defined genes that contribute to particular biological or disease-associated processes. We asked whether topic-defined gene sets are enriched among identified gene sets associated with either biological processes (BP) within the gene ontology (GO) framework or with disease ontologies (DO). We compare the number of enriched GO and DO terms in q-intNMF topics and MOFA+ topics (Fig. 3C–E). q-intNMF’s genesets have more associated biological processes and disease ontologies than MOFA+ topics, and this advantage is retained irrespective of whether top negative weights, top positive weights or top absolute weights are used in MOFA+ analysis. This indicates that q-intNMF’s topics likely identify biologically important sets of genes. Additionally, canonical marker genes have high weights in the appropriate topics (Supplementary Fig. S21). This is exemplified by the astrocyte marker gene AQP4, which is a top feature in topic 11 that defines the astrocyte cluster.

q-intNMF topics elucidate disease-relevant biology

The original study [7] was not able to clearly separate cell types in normal versus Alzheimer’s samples. We therefore asked whether the topics discovered by q-intNMF could further resolve transcriptional regulatory information about Alzheimer’s disease. First, we identified which topics are more strongly activated in Alzheimer’s versus cells from normal samples within the cell types with which they are associated. Figure 4A shows the difference in median topic score (elements of \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{upgreek} \usepackage{mathrsfs} \setlength{\oddsidemargin}{-69pt} \begin{document} $\mathbf {W}$\end{document}) between cells of the same type from Alzheimer’s and disease-free donors. Of the three oligodendrocyte-associated topics, 19 is more strongly associated with Alzheimer’s, whereas 14 and 20 are more strongly associated with normal samples. Additionally, among the two topics associated with astrocytes and two topics associated with microglia, there is one topic more associated with Alzheimer’s (astrocytes topic 11 and microglia topic 18, Fig. 4A) and another with healthy cells (astrocytes topic 16 and microglia topic 8). This can be seen in more detail in Supplementary Fig. S22. Several genes have been shown to be differentially expressed between Alzheimer’s and control within specific cell types, for example, SAMD4A is upregulated in Alzheimer-positive astrocytes [7]. q-intNMF topics capture these genes through differential feature weights within topics associated with the same cell type but different disease status, e.g. SAMD4A’s feature weight is higher in topic 11 versus topic 16 (Supplementary Fig. S23).

The top genes in the q-intNMF topics are associated with GO terms relevant to the cell types associated with the given topic and the Alzheimer’s disease state (Fig. 4B). For example, the top GO terms for excitatory and inhibitory neuron-associated topics 0 and 6 both include ‘synapse organization’, and individually, ‘ion transmembrane transport’ is associated with topic 0, whereas topic 6 is associated with ‘regulation of synapse organization’. Genes associated with synapse organization have previously been found to be upregulated in excitatory neurons in late-stage Alzheimer’s [41]. Topic 8, associated with non-Alzheimer’s microglia cells, has GO terms associated with lymphocyte differentiation and T cell activation, in line with their function as the DLPFC’s resident immune cell population, whereas top genes in topic 18 (associated with Alzheimer’s microglia cells) are enriched for genes involved with ‘positive regulation of GTPase activity’, which is consistent with a previously identified increased inflammatory response in Alzheimer’s-associated microglia [42]. In addition, the top genes of q-intNMF topics are associated with relevant disease ontologies (DO) (Fig. 4C). For example, topic 8, associated with microglial cells, shows enrichment of a range of immune system-related diseases. More relevant to potential neuronal cell dysfunction, topic 21 is enriched for Alzheimer’s and tauopathy, and topic 23 (which is more prevalent in excitatory neurons in Alzheimer’s patients) is enriched for mood and bipolar disorders. There are brain-related diseases associated with topics for all cell types.

We also asked whether the chromatin accessibility data from the ATAC-seq features associated with topics gave informative regulatory information. The top ATAC features for topics are enriched for transcription factor (TF) motifs relevant to the cell types the topic is active in. For example, PU.1 is a factor known to be highly expressed in microglia and reduced PU.1 expression is implicated in Alzheimer’s disease onset [43]. Its motif is significantly enriched in both microglia-associated topics (8 and 18), but significantly more so in the non-Alzheimer’s microglia topic (topic 8) (Fig. 4D and Supplementary Fig. S24). PU.1 (otherwise referred to as SPI1) was identified as being ubiquitously activated across microglial cell states in a recent analysis of the DLPFC tissue [44]. Another recently published paper [45] identified SPI1 and ELF2 as two TFs with the most enriched motifs at Alzheimer’s genetic risk loci, although it is worth noting these TFs bind similar DNA motifs. Other motifs define known master transcription factors of neural-related lineages, such as the motif of a key marker of motor neuron and oligodendrocyte differentiation, OLIG2, which is enriched in the top accessible regions of two excitatory neuron-defining topics (4 and 15).

Finally, we investigated genomic regions analysed in the original paper by looking at the chromatin accessibility feature scores of q-intNMF topics. KANSL1 is a gene that displays reduced expression during Alzheimer’s pathogenesis [7] and has been linked with progressive supranuclear palsy [46]. KANSL1’s promoter loses accessibility in Alzheimer’s samples relative to control samples. This is captured by q-intNMF’s topics, as the region is accessible in topic 13 (a non-Alzheimer’s excitatory cell topic) but is inaccessible in topic 5 (an Alzheimer’s excitatory cell topic, Fig. 4E). APP encodes amyloid precursor protein, another protein central to Alzheimer’s pathogenesis. The APP locus can be seen in Fig. 4F. The highlighted regions are regions found to have regulatory potential via a luciferase assay. The left-most regulatory region exhibited silencer-like properties and is accessible in the non-Alzheimer’s-defining topics in excitatory neurons (blue tracks) but not the ones associated with Alzheimer’s (orange tracks). This suggests a lost repressive regulatory element during Alzheimer’s pathogenesis, although this is paired with a loss in accessibility of APP’s promoter, suggesting changes in regulation are more complicated than a single lost regulatory element.

These results demonstrate that q-intNMF topics can identify cell types and subtle differences between disease and normal cells of the same type. Furthermore, q-intNMF’s topic definitions are biologically interpretable and identify important molecular features associated with cell and sub-cell types.

Discussion

Here, we present q-intNMF, a new computationally efficient NMF-based tool for integration of single-cell paired gene expression and chromatin accessibility data to cluster cells and identify important genes and regions. The presented method is benchmarked against other popular methods for single-cell multiomics data integration. q-intNMF shows superior clustering performance as measured by ARI and comparable clustering performance as measured by MI to other methods when using the two different-sized datasets. q-intNMF and MOFA+ show superior performance to other methods as measured by Silhouette Score, the metric quantifying the structure. However, q-intNMF has the further advantage over other benchmarked matrix factorization methods of having a significantly faster run time. This excludes MOJITOO, which runs quickly and is a matrix factorization method but learns canonical components (equivalent of topics), which aren’t linked to the original feature space, but instead to latent representations of the original feature space, trading off some interpretability for speed. Non-linear methods have many strengths, they are typically better at imputation, batch harmonization and inferring missing modalities [35]; however, it is harder to link features to the learned representation, making biological discovery harder. In the presented benchmarking work, non-linear methods, e.g. multiVI, were not included. Instead, the evaluation focuses on interpretable matrix factorization approaches (with the exception of Seurat, given its widespread use in the community).

Having determined q-intNMF’s suitability via benchmarking, we next performed an analysis on an example dataset of 100 000 cells from DLPFC from Alzheimer’s-positive and -negative donors [7]. Through further analysis of q-intNMF output, we demonstrate that the discovered topics resolve the original cell types identified in the original study and link them to relevant molecular features. Additionally, the flexibility and granularity of topics, as opposed to overall clustering, help elucidate subtle differences in transcriptional regulation between Alzheimer’s and non-Alzheimer’s cells. In this analysis we compared q-intNMF to one of the best-performing existing methods, MOFA+, and highlighted how the difference in the underlying models, PCA-based versus NMF-based, leads to topics that are more cell type-specific and can identify important biological features when using q-intNMF.

q-intNMF’s implementation, based on a BCD framework, is efficient in terms of time and memory requirements. Importantly, the gene expression and chromatin accessibility matrices are never fully loaded into memory directly, allowing q-intNMF to work on datasets larger than the computers RAM. q-intNMF is implemented with an L2 loss (element-wise Euclidean distance between the original data and the NMF reconstructed data), this is a practical decision (similar to MOFA+’s recommendation to use a Gaussian loss for large datasets) due to the efficient update schemes available given an L2 loss. Other cost functions such as the KL divergence [16] or L1/Poisson could also be applied, which are likely to attend less to highly expressed genes [47, 48]. Additionally, not transforming the counts data to continuous data, i.e. log transforming, can better preserve the differences between small and zero values [16, 49]. This comes with the trade-off that KL-NMF is not amenable to efficient BCD frameworks [50]. Given the results presented here, using a Poisson KL loss does not improve performance but significantly increases run time and memory requirements.

Additionally, there are flavours of NMF with probabilistic interpretations (primarily by adding sum-to-one constraints for each cell and each feature) [51], which may further enhance the interpretability of the models. Inference schemes using EM (Expectation Maximization) or VI (Variational Inference) for updates could be implemented, but they are usually impractical for large datasets. For example, a recent scRNA-seq NMF-based method implements an EM algorithm but favours the use of ADAM (a gradient descent-based method) due to long run times [47]. A potential extension for q-intNMF, capitalizing on its speed, is iterative learning—e.g. fitting NMF, adding additional topics, removing topics, or even fitting topics to subsets of the data. There are existing algorithms that can speed up the process of fitting an NMF model with additional or fewer topics given an NMF model already fit to the data [52]. These techniques could also be utilized to speed up q-intNMF’s model selection via BIC. Due to q-intNMFs computational efficiency, it could enable the application of consensus NMF [53], potentially identifying more robust transcriptional programs. This is an interesting avenue of future work.

q-intNMF shows best performance (by the metrics presented here) when run with L1 regularization and a number of topics roughly equal to or slightly more than the true number of different cell types, although this is a fairly rough guide (Supplementary Fig. S10). We found the Alzheimer’s dataset, which is composed of 8 major cell types, to be best represented by 25 topics (by both the loss and BIC elbow), although this is likely due to the presence of major sub-cell types in the dataset. In practice it is likely users of q-intNMF will need to interactively fine-tune their analysis to find a biologically appropriate number of topics, further illustrating the importance of q-intNMF’s fast run time. Use of L1 regularization helps to induce sparsity in \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{upgreek} \usepackage{mathrsfs} \setlength{\oddsidemargin}{-69pt} \begin{document} $\mathbf {W}$\end{document} and \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{upgreek} \usepackage{mathrsfs} \setlength{\oddsidemargin}{-69pt} \begin{document} $\mathbf {H}$\end{document} matrices, which better reflects single-cell ’omics data. It also helps ensure that meaningful features are identified in the feature loading matrices (\documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{upgreek} \usepackage{mathrsfs} \setlength{\oddsidemargin}{-69pt} \begin{document} $\mathbf {H}$\end{document}).

All the presented applications here are of paired chromatin accessibility and gene expression data; however, with minor modifications to preprocessing, q-intNMF could be applied to other bi-modal types of data e.g. paired protein and RNA expression data. An adaptation of q-intNMF for paired spatial gene expression and H&E images has already been developed [54]. Furthermore, with a slight change to the updates of \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{upgreek} \usepackage{mathrsfs} \setlength{\oddsidemargin}{-69pt} \begin{document} $\mathbf {W}$\end{document}, q-intNMF it could be applied to tri-modal datasets e.g. chromatin accessibility, gene expression, and protein expression. Given the ability of q-intNMF to identify important sets of genes and accessible chromatin regions in populations of cells, a further avenue of development for q-intNMF could be using the topics for regulatory network inference as has been done with regNMF [15], or biological process discovery, as has been done recently with Spectra (a method developed for scRNA-seq) [47].

In conclusion, q-intNMF is a fast and accurate method for analysis of single-cell multiome data that provides rich low-dimensional representation, facilitates custom downstream analysis (we have shown a flavour in this study) and provides avenues for methodological extensions for further combinations of single-cell data modalities.
