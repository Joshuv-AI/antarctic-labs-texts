A Learning Perspective on Random-Order Covering Problems
Anupam Gupta, Marco Molinaro, Matteo Russo

Abstract
In the random-order online set cover problem, the instance with m m sets and n n elements is chosen in a worst-case fashion, but then the elements arrive in a uniformly random order. Can this random-order model allow us to circumvent the bound of O ⁡ ( log ⁡ m ​ log ⁡ n ) O(\log m\log n) -competitiveness for the adversarial arrival order model? This long-standing question was recently resolved by GKL 21 , who gave an algorithm that achieved an O ⁡ ( log ⁡ m ​ n ) O(\log mn) -competitive ratio. While their LearnOrCover was inspired by ideas in online learning (and specifically the multiplicative weights update method), the analysis proceeded by showing progress from first principles. In this work, we show a concrete connection between random-order set cover and stochastic mirror-descent/online convex optimization. In particular, we show how additive/multiplicative regret bounds for the latter translate into competitiveness for the former. Indeed, we give a clean recipe for this translation, allowing us to extend our results to covering integer programs, set multicover, and non-metric facility location in the random order model, matching (and giving simpler proofs of) the previous applications of the LearnOrCover framework.

Introduction

In the online
set cover
problem, the adversary chooses a set system

({\mathcal{U}},{\mathcal{S}})
, and reveals the elements of the universe one by
one. Upon seeing an element
e\in{\mathcal{U}}
, the algorithm learns which
sets contain this element, and must ensure that
e
is covered, i.e.,
it has picked at least one of the sets containing element
e
. The goal is to
pick the fewest sets, or the cheapest collection of sets, if sets have
non-negative costs. The offline version of this problem admits a

(1+\ln n)
-approximation, where
n=|{\mathcal{U}}|
, and this is best possible
(up to lower order terms) unless
\text{P}=\text{NP}
(see, e.g.,

WS 11
). However, the algorithms that
achieve this approximation guarantee require knowing the set system
up-front. What can we do in an online setting?

In a landmark paper, Alon et
al.
AAA+ 09
gave an

O(\log m\log n)
-competitive randomized online algorithm; they also
showed that one cannot do much better using deterministic algorithms,
even if the set structure was known up-front, but only a subset of the
elements of
{\mathcal{U}}
would arrive online. Subsequently, Korman
Kor 04
showed that no polynomial-time algorithms could
beat this double-logarithmic bound. The question of doing better
beyond the worst-case was considered soon thereafter: Grandoni et
al.
GGL+ 13
gave an

O(\log mn)
-competitive algorithm if the set system was known, and
the requests were drawn i.i.d. from an fixed distribution over the
elements of
{\mathcal{U}}
.

The question of extending it to the random-order model remained open
for considerably longer. It was finally resolved when an

O(\log mn)
-competitive algorithm was given even when the set system
was fixed and unknown, but the elements arrived in uniformly random
order
GKL 21
. They also generalized their techniques to
covering integer programs without box-constraints, set multicover, and
non-metric facility location
GKL 21
;
GKL 24
. These
random-order algorithms (whom we refer to as the
LearnOrCover
family) were all
based on the multiplicative weights update method
to learn the optimal solution using the random-order samples. They
were inspired by stochastic gradient/mirror descent—that of using the
elements arriving in random order—as random samples, from which to
learn a good solution.

However, this connection between
LearnOrCover
algorithms and online learning
was more in spirit than at a technical level: the proofs in

GKL 21
;
GKL 24
proceeded from first-principles, showing
that the KL divergence to the optimal solution plus the (logarithm of
the) number of uncovered elements decreased in expectation fast
enough. Again, the guiding principle was that these algorithms either
make progress towards learning the optimal solution, or towards
covering elements, at each step. However, each problem required a
somewhat involved potential-function calculation, and it was difficult
to see the intuition for how the algorithmic decisions were informing
the technical details and the convergence proofs.

1.1
Our Results

In this work, we make the connection between random-order online algorithms and online learning—particularly regret minimization—explicit, modular, and arguably conceptually cleaner. We isolate the online learning component, showing that any (stochastic) online convex optimization algorithm with suitable additive/multiplicative regret bounds can be used as a black box subroutine to yield an online algorithm with optimal competitiveness guarantees.

This general approach yields the following unified result:

Theorem
.

There exist
O(\log mn)
-competitive algorithms for the following random-order covering problems:

(i)

(weighted) Set Cover,

(ii)

(unweighted) Set Multicover,

(iii)

Covering Integer Programs (without box constraints), and

(iv)

Non-metric Facility Location.

While prior work
(
GKL 21
;
GKL 24
)
established the existence of
O(\log mn)
-competitive algorithms for these problems, our contribution is a conceptual simplification:
the same
OCO algorithm—used entirely as a black box—applies uniformly across all settings. The only problem-specific component are the concave gain functions fed to the OCO routine.

1.2
Our Techniques

To illustrate the ideas, consider the case of unweighted online set
cover, in the random-order model. Recall that while the adversary
fixes the set system
({\mathcal{U}},{\mathcal{S}})
up-front, we know nothing apart from

m
, the number of sets in
{\mathcal{S}}
, at the beginning. (For this
particular discussion, assume also that we know
|\textup{{Opt}}|
, the cost of the
optimal solution.) Crucially, we do not know which elements belong to
which sets: only when an element arrives we known which sets contain it.

As mentioned above, our algorithms follow the
LearnOrCover
framework
of
GKL 21
. In this framework, at each timestep
t
we maintain a probability distribution

q^{t}\in[0,1]^{m}
over the sets in
{\mathcal{S}}
. If the arriving element
e^{t}
is not yet covered, we add to our solution any
set that covers it, and, crucially, sample and add to our solution one
more set according to the distribution
q^{t}
. The intuition for the sampling is that,
by paying a cost of two (sets) instead of one in this iteration, we will help
covering
future
elements.

The key is how to choose—or indeed, “learn”—the distribution

q^{t}
, after we have seen
t-1
elements from
{\mathcal{U}}
, given that we do
not know which sets cover the future elements. Let
{\mathcal{V}}^{t}

denote the elements of
{\mathcal{U}}
which are yet to arrive and have not been
already covered by sets chosen at steps
1,\ldots,t-1
. Suppose we
define

{\sf gain}_{t}(q)=\sum_{S\in{\mathcal{S}}}q_{S}\cdot\frac{\textrm{\# elements $S$ covers
from ${\mathcal{V}}^{t}$}}{|{\mathcal{V}}^{t}|}
; this measures exactly the fraction
of uncovered future elements that we expect to cover if we sample a
set using the distribution
q
. Note that, since we do not know the set
structure, we do not know the function
{\sf gain}_{t}(q)
—but more about
that soon.

Now, if we magically knew the optimal solution
\textup{{Opt}}\subseteq{\mathcal{S}}
, we
could use the uniform distribution

q^{\star}:=\frac{\bm{1}(S\in\textup{{Opt}})}{|\textup{{Opt}}|}
over
Opt
’s sets and
get that
{\sf gain}_{t}(q^{\star})\geq\frac{1}{|\textup{{Opt}}|}
. And hence, after
about
\log n\cdot|\textup{{Opt}}|
steps sampling from this distribution, we
would reduce the fraction of uncovered elements to less than

(1-\frac{1}{|\textup{{Opt}}|})^{(\log n)|\textup{{Opt}}|}\leq\frac{1}{n}
, i.e., all

n
elements would be covered!

There are two obvious issues with this thought experiment:

1.

We do not know the optimal solution, and hence the fractional
solution
q^{\star}
. The key idea here is to use
online convex
optimization
to learn
q^{\star}
. More precisely, OCO allows us to
choose a sequence of distributions
\{q^{t}\}_{t=1}^{n}
that perform
almost as well as
q^{\star}
for the expected coverage; namely

\sum_{t}{\sf gain}_{t}(q^{t})\gtrsim\frac{1}{2}\sum_{t}{\sf gain}_{t}(q^{\star})-O(\log m);

we use a multiplicative/additive regret
guarantee to avoid the typical dependence of
\sqrt{n}
.

2.

We do not know the function
{\sf gain}_{t}(\cdot)
, since we do not
know which sets contain which future elements and hence we don’t
know
{\mathcal{V}}^{t}
.) But here’s the second key observation: if we see
a random uncovered element
e^{t}
at timestep
t
, we can use it to
compute an unbiased stochastic approximation of (the gradient of)
this function
{\sf gain}_{t}
; this is where we rely on the random-order
model. More precisely, the linear function

{\sf gain}_{t,e^{t}}(q)=\sum_{S}q_{S}\cdot\bm{1}(e^{t}\in{\mathcal{V}}^{t}\textrm{ and }e^{t}\in S)

satisfies

{\mathbb{E}}\,_{e^{t}}[\,{\sf gain}_{t,e^{t}}(q)\,]={\sf gain}_{t,{\mathcal{V}}^{t}}(q)
; moveover, when

e^{t}
arrives, we know whether it is uncovered, and which sets cover
it, so we can compute
{\sf gain}_{t,e^{t}}
using the information at hand,
and feed this stochastic gradient to the OCO algorithm.

While the approach sketched above is true in spirit to our algorithm
(which is essentially the same for all problems),
the details have some crucial technical differences. Firstly, instead
of maintaining a probability distribution
q^{t}
over sets/resources,
we maintain a vector
p^{t}\in[0,1]^{m}
(whose coordinates do not need to
add up to 1), and may sample multiple sets/resources while controlling for
their expected costs. Secondly, instead of tracking the
number/fraction of uncovered future elements, we use a potential
function that takes into account the cost of covering these
elements. Finally, the “real” gain, which is the actual decrease in the
potential, is somewhat complicated and so we have to “linearize”
before using it in our OCO algorithm. Moreover, to ensure that these
OCO algorithms suffer low-regret, it is crucial that this linearized
gain functions have bounded gradients.

2
Online Convex Optimization

Online Convex Optimization (OCO) is a fundamental model of optimization under uncertainty with fascinating applications to learning and algorithms that generalizes the classic problem of “prediction with expert advice” to convex loss (or concave gain) functions
AHK 12
;
Ora 19
. Multiple OCO models are available, but for our purposes we focus on adversarial arrivals and stochastic first-order oracle feedback.

Definition 2.1

(OCO with Stochastic First-Order Feedback)
.

Let
M
be a nonnegative real number and consider the scaled simplex

\overline{\scalebox{1.3}{$\blacktriangle$}}=\{y\in[0,1]^{d}\mid\langle c,y\rangle\leq M\}
. At each time, we
need to play an action
y_{t}\in\overline{\scalebox{1.3}{$\blacktriangle$}}
with respect to an

a priori
unknown concave function
h_{t}
, to maximize the long-term
gain
\sum_{t}h_{t}(y_{t})
. However, the feedback is stochastic: instead
of getting a subgradient
\partial h_{t}(y_{t})\in{\mathbb{R}}^{d}
at timestep

t
, we get a random estimate
H_{t}\in{\mathbb{R}}^{d}
such that its expectation conditioned on everything that happened up to this point (including
y_{t}
and
h_{t}
) equals
\partial h_{t}(y_{t})
.

The key results in this area are online strategies that obtain gain comparable to the best action
y^{\star}\in\overline{\scalebox{1.3}{$\blacktriangle$}}
that knows all the gain functions in hindsight. We will make use of the following such result; because of its specifics (e.g., multiplicative/additive guarantee, scaled simplex, availability of only stochastic subgradient, etc.) we did not find this exact result in the literature, but it follows from known regret arguments based on local norms (Appendix
A
).

Theorem 2.2

(OCO Algorithm)
.

Suppose the functions
h_{t}
are concave and the stochastic gradients are “
\ell_{\infty}
-bounded”: i.e.,

H_{t,i}\cdot(\nicefrac{{M}}{{c_{i}}})\in[0,1]
for each coordinate

i\in[d]
, with probability
1
. Then for any
\eta\in(0,1]
and any stopping time
\tau
,
the stochastic online mirror descent (OMD) algorithm ensures
that for all
y^{\star}\in\overline{\scalebox{1.3}{$\blacktriangle$}}
, we have

\displaystyle{\mathbb{E}}\,\bigg[\sum_{t\leq\tau}h_{t}(y_{t})\bigg]\geq(1-\eta)\cdot{\mathbb{E}}\,\bigg[\sum_{t\leq\tau}h_{t}(y^{\star})\bigg]-\frac{O(\log d)}{\eta}.

Note that the randomness is over the subgradient estimates, which in
turn affect our iterates and thus possibly the future

h_{t}
’s. We will use
Theorem

2.2
with
\eta=\nicefrac{{1}}{{2}}
.

to denote the cost of set
S\in{\mathcal{S}}
.

Let
{\mathcal{U}}^{t}
be the random subset of elements not seen until time

By using guess-and-double, we assume that we know an over-estimate

We then have

3.2
Analysis of
ROSC-OCO

The main guarantee in this section is the following:

Theorem 3.1
.

ROSC-OCO
is
O(\log(mn))
-competitive for random-order (weighted) set cover.

To prove this, consider any timestep
t
, and
let
{\mathcal{H}}^{t}
denote the history strictly before time
t
. We claim
that, for any choice of
{\mathcal{H}}^{t}
, the (conditional) expected cost of
the algorithm at time
t
is at most

2{\mathbb{E}}\,_{e\sim{\mathcal{U}}^{t}}[X^{t}_{e}\kappa_{e}]
. Indeed, the element
e

arriving at time
t
is a uniformly random element of
{\mathcal{U}}^{t}
, and
if it is not covered, we incur cost
\kappa_{e}
in
Line
1
, and an expected cost of at most
\kappa_{e}

in Line
1
. The randomness in the algorithm’s decisions
at time
t
is denoted as
\omega^{t}
in the remainder.

To track the progress of the algorithm, define the potential as the sum of the minimal individual covering costs for the remaining elements:

\displaystyle\Phi^{t}:=\sum_{e\in{\mathcal{U}}^{t}}\kappa^{t}_{e};

(3.1)

this equals
\sum_{e\in{\mathcal{U}}}\kappa^{t}_{e}
, since all elements in

{\mathcal{U}}\setminus{\mathcal{U}}^{t}
are already covered by time
t
. Define the
stopping time
\tau
to be the first time
t
when

\Phi^{t}\leq\textsc{Est}
. By the discussion above, the expected cost
incurred at all timesteps
t\geq\tau
is at most

2\Phi^{\tau}\leq 2\textsc{Est}
, which is at most
O(c(\textup{{Opt}}))
by assumption.

3.2.1
The “Real Gain” captures the Potential Reduction

We now bound the cost incurred in timesteps
t<\tau
. Define the
“real gain” at time
t
to be the expected proportional reduction in
potential due to a random element from
{\mathcal{U}}^{t}
:

\displaystyle{\sf Rgain}_{t}:=\frac{1}{|{\mathcal{U}}^{t}|}\cdot\frac{1}{\Phi^{t}}\cdot\sum_{e,f\in{\mathcal{U}}^{t}}\kappa^{t}_{f}\cdot\Pr[f\text{ covered by
sampling step $t$}\mid e^{t}=e].

(3.2)

The first lemma simply uses this definition and the
inequality
1-z\leq e^{-z}
to get:

Lemma 3.2

(Bounding the Real Gain)
.

\displaystyle{\mathbb{E}}\,\bigg[\sum_{t<\tau}{\sf Rgain}_{t}\bigg]\leq 1+\underset{}{\mathbb{E}}\left[\log\left(\frac{\Phi^{0}}{\Phi^{\tau-1}}\right)\right]\leq O(\log n).

(3.3)

Proof.

Consider time
t
, and condition on the history
{\mathcal{H}}^{t}
of sets
selected thus far. The expected change in potential is

\displaystyle\underset{\omega^{t},\;e^{t}\sim{\mathcal{U}}^{t}}{\mathbb{E}}\left[\Phi^{t}-\Phi^{t+1}\right]

\displaystyle\geq\sum_{e\in{\mathcal{U}}^{t}}\frac{1}{|{\mathcal{U}}^{t}|}\sum_{f\in{\mathcal{U}}^{t}}\kappa^{t}_{f}\cdot\Pr[f\text{ covered by sampling step $t$}\mid e^{t}=e]

\displaystyle=\Phi^{t}\cdot{\sf Rgain}_{t},

by the definition of
{\sf Rgain}_{t}
. (We have an inequality since the
potential may also drop due to the set chosen in Line
1
.)
Since the value of
\Phi^{t}
is completely fixed by the choices in

{\mathcal{H}}^{t}
, we get that

\underset{\omega^{t},\;e^{t}\sim{\mathcal{U}}^{t}}{\mathbb{E}}\left[\Phi^{t+1}\right]=\Phi^{t}\cdot\left(1-{\sf Rgain}_{t}\right)\leq\Phi^{t}\cdot\exp\left(-{\sf Rgain}_{t}\right).

Taking logarithms and using Jensen’s inequality:

\underset{\omega^{t},\;e^{t}\sim{\mathcal{U}}^{t}}{\mathbb{E}}\left[\log(\Phi^{t+1})\right]\leq\log\Big(\underset{\omega^{t},\;e\sim{\mathcal{U}}^{t}}{\mathbb{E}}\left[\Phi^{t+1}\right]\Big)\leq\log(\Phi^{t})-{\sf Rgain}_{t}.

Since this is true for each conditioning
{\mathcal{H}}^{t}
, we get that

\underset{}{\mathbb{E}}\left[\log(\Phi^{t+1})\right]\leq\underset{}{\mathbb{E}}\left[\log(\Phi^{t})\right]-\underset{}{\mathbb{E}}\left[{\sf Rgain}_{t}(p^{t})\right]
.
Finally, summing over all times up until the stopping time
\tau-2
,
we obtain

\displaystyle{\mathbb{E}}\,\bigg[\sum_{t<\tau-1}{\sf Rgain}_{t}(p^{t})\bigg]\leq\underset{}{\mathbb{E}}\left[\log\left(\frac{\Phi^{0}}{\Phi^{\tau-1}}\right)\right]\leq O(\log n),

where in the last inequality we used that

\Phi^{\tau-1}>\textsc{Est}\geq c(\textup{{Opt}})
by definition of
\tau
and

Est
and

\Phi^{0}=\sum_{e\in{\mathcal{U}}}\kappa_{e}\leq n\cdot c(\textup{{Opt}})
.
Finally,
{\sf Rgain}_{t}\leq 1
for each time
t
; using this for
t=\tau-1
completes the proof.
∎

3.2.2
Simplifying the “Real Gain”

The “real gain” function is difficult for us to work with, so we
define a “decoupled” version where we essentially linearize the probability of covering element
f
during the sampling step as
\frac{\kappa^{t}_{f}}{\textsc{Est}}\cdot\sum_{S:f\in S}p_{S}
:

\displaystyle{\sf gain}_{t}(p):=\underset{f\sim{\mathcal{U}}^{t}}{\mathbb{E}}\left[{\sf gain}_{t,f}(p)\right]\qquad\text{where}\qquad{\sf gain}_{t,f}(p):=\frac{\kappa^{t}_{f}}{\textsc{Est}}\cdot\min\Big(1,\sum_{S:f\in S}p_{S}\Big).

(3.4)

Note that the gain function
{\sf gain}_{t}
is an expectation over

{\sf gain}_{t,f}
functions, and hence convenient to use in a stochastic
gradient descent subroutine; indeed, this is precisely what we used in
Line
1
of the algorithm.

Lemma 3.3

(Gain vs. Real Gain)
.

{\sf gain}_{t}(p^{t})\leq\frac{e}{e-1}\cdot{\sf Rgain}_{t}
.

Proof.

Using the sampling probability in Line
1
of the
algorithm in the definition (
3.2
),

\displaystyle{\sf Rgain}_{t}

\displaystyle=\frac{1}{|{\mathcal{U}}^{t}|\cdot\Phi^{t}}\sum_{e,f\in{\mathcal{U}}^{t}}\kappa^{t}_{f}\cdot\bigg(1-\prod_{S:f\in S}\bigg(1-\frac{p^{t}_{S}\kappa^{t}_{e}}{\textsc{Est}}\bigg)\bigg).

Define
a_{S}=\frac{p_{S}^{t}\kappa_{e}^{t}}{\textsc{Est}}
; we can use that

1-\prod_{S}(1-a_{S})\geq(1-\nicefrac{{1}}{{e}})\min(1,\sum_{S}a_{S})
(see

B.1
) to get

\displaystyle{\sf Rgain}_{t}

\displaystyle\geq(1-\nicefrac{{1}}{{e}})\cdot\frac{1}{|{\mathcal{U}}^{t}|\cdot\Phi^{t}}\sum_{e,f\in{\mathcal{U}}^{t}}\kappa^{t}_{f}\cdot\min\Big(1,\sum_{S:f\in S}\frac{p^{t}_{S}\kappa^{t}_{e}}{\textsc{Est}}\Big)

(3.5)

\displaystyle\geq(1-\nicefrac{{1}}{{e}})\cdot\frac{1}{|{\mathcal{U}}^{t}|\cdot\Phi^{t}}\sum_{e,f\in{\mathcal{U}}^{t}}\kappa^{t}_{f}\cdot\frac{\kappa^{t}_{e}}{\textsc{Est}}\cdot\min\Big(1,\sum_{S:f\in S}p^{t}_{S}\Big).

(3.6)

where we used that
\kappa_{e}^{t}\leq c(\textup{{Opt}})\leq\textsc{Est}
to
get (
3.6
). Now using that

\Phi^{t}=\sum_{e\in{\mathcal{U}}^{t}}\kappa^{t}_{e}
, and the definition of

{\sf gain}_{t}
shows that
{\sf Rgain}_{t}\geq(1-\nicefrac{{1}}{{e}})\cdot{\sf gain}_{t}(p^{t})

and completes the proof.
∎

3.3
Sufficient Static Gains

Lemmas

3.2
and
3.3
bounded the sum of our gains over all timesteps by

Lemma 3.4
.

If

\displaystyle{\mathbb{E}}\,\bigg[\sum_{t<\tau}c(\textup{{Alg}}^{t})\bigg]\leq 4c(\textup{{Opt}})\cdot{\mathbb{E}}\,\bigg[\sum_{t<\tau}{\sf gain}_{t}(p^{\star})\bigg].

Proof.

. By definition of
{\sf gain}_{t,f}

\displaystyle{\sf gain}_{t,f}(p^{\star})

\displaystyle=\frac{\kappa^{t}_{f}}{\textsc{Est}}\cdot\min\Big(1,\sum_{S\in{\mathcal{S}}:S\ni f}p^{\star}_{S}\Big)=\frac{\kappa^{t}_{f}}{\textsc{Est}},

where we used that

is a fractional set cover and hence

at to an extent of at least
1
. Now substituting
into (
3.4

\displaystyle{\sf gain}_{t}(p^{\star})

3.4
The Guess-and-Double Framework

We have assumed that we know an estimate
Est
of the optimal value satisfying
c(\textup{{Opt}})\leq\textsc{Est}\leq 2c(\textup{{Opt}})
. If computational complexity is not a concern, this can be accomplished by using the guess-and-double framework, namely starting with the estimate
Est
being the cost of the cheapest set, and doubling
Est
and restarting the algorithm whenever the (integral) optimum of the instance seen thus far exceeds
Est
.

In order to obtain a polynomial-time algorithm, one can replace

c(\textup{{Opt}})
throughout for the use the cost of the linear programming
relaxation
c(\textup{{LP}})
(i.e.,
c(\textup{{LP}}):=\min\{\sum_{S\in{\mathcal{S}}}c_{S}x_{S}:\sum_{S:e\in S}x_{S}\geq 1,~\forall e\in{\mathcal{U}}\}
) instead of

c(\textup{{Opt}})
. Notice that indeed the solution
p^{\star}
used in the
proof of
Lemma

3.4
was already the fractional optimal
solution. The only other place where any property of the optimal
solution is used is in upper bounding the (log of) the initial
potential
\Phi^{0}
at the end of
Lemma

3.2
, but it still
holds that
\Phi^{0}=\sum_{e\in{\mathcal{U}}}\kappa_{e}\leq n\cdot c(\textup{{LP}})
,
since even the fractional optimum is at least the minimum cost set
containing each element.
Moreover, this bound becomes

\Phi^{0}=\sum_{e\in{\mathcal{U}}}\kappa_{e}\leq n\cdot\textsc{IPGap}\cdot c(\textup{{LP}})
, where
\textsc{IPGap}=\nicefrac{{c(\textup{{Opt}})}}{{c(\textup{{LP}})}}
; as long as this is at most polynomial in
n
, this only changes
constant factors in the bound of

\log(\nicefrac{{\Phi^{0}}}{{\Phi^{\tau-1}}})
. Since the fractional optimum
for the instance seen thus far can be computed in polytime, one can
then use the above guess-and-double strategy and be able to assume the
estimate
c(\textup{{LP}})\leq\textsc{Est}\leq 2c(\textup{{LP}})
.

In the following section, we abstract out aspects of the set cover
analysis to get a general recipe for the class of monotone covering
problems.

4
OCO for Random-Order Monotone Problems

We now give our framework for monotone covering problems in the
random order setting. Our goal will be to abstract out the generic
steps from the problem-specific ones, which can help focus on the
essential core of these problems.

4.1
General Problem Formulation

We study the following class of covering problems, which are online
minimization problems characterized by (i) a (finite) set of

resources

{\mathcal{S}}
(with
|{\mathcal{S}}|=m
), and (ii) a (finite) set of

elements

{\mathcal{U}}
(with
|{\mathcal{U}}|=n
). For set cover, the resources
are subsets of elements in some given family, which can be used to
cover elements they contain, and for facility location the resources are the possible facilities.

Each element needs to be “satisfied” or “covered”, and for that we
need to buy resources and pay the augmentation cost. More precisely,
each resource
R\in{\mathcal{S}}
has a cost
c_{R}
. For every element

e\in{\mathcal{U}}
and (multi)set of resources
{\mathcal{R}}
, the augmentation cost
incurred if resources
{\mathcal{R}}
have already been bought is denoted by

{\sf aug}(e,{\mathcal{R}})\geq 0
. For example, for set cover
{\sf aug}(e,{\mathcal{R}})
is

0
if
e
belongs to some set in
{\mathcal{R}}
, otherwise it is the cost of
the cheapest set containing
e
. In facility location,
{\sf aug}(e,{\mathcal{R}})

is the minimum between connecting element/demand
e
to a facility in

{\mathcal{R}}
or opening and connecting to a new facility outside of
{\mathcal{R}}
; we
give more details in
Section

5.3
.

We assume the following
monotonicity
and
minimality
properties of the augmentation cost; the first says that the fewer resources we have, the higher the augmentation cost is, and the second says that it is possible to “buy new resources to reduce the augmentation cost”:

1.

(monotonicity)
{\sf aug}(e,{\mathcal{R}})\geq{\sf aug}(e,{\mathcal{R}}^{\prime})
if
{\mathcal{R}}\subseteq{\mathcal{R}}^{\prime}
.

2.

(minimality)
{\sf aug}(e,{\mathcal{R}})\leq{\sf aug}(e,{\mathcal{R}}^{\prime})+\sum_{R\in{\mathcal{R}}^{\prime}\setminus{\mathcal{R}}}c_{R}
if
{\mathcal{R}}\subseteq{\mathcal{R}}^{\prime}
.

The online setting is then: the costs
c
and
{\sf aug}(\cdot,\cdot)
are
given upfront, and items
e^{1},e^{2},\ldots,e^{n}\in{\mathcal{U}}
arrive
one-by-one. At time
t
, we assume that the
multiset of resources previously bought is denoted by
{\mathcal{R}}^{t}
. When element
e^{t}
arrives, the algorithm does the following:

(i)

it decides which (if any) additional resources it wants to buy,
updating the (multi)set of obtained resources to

{\mathcal{R}}^{t+1}\supseteq{\mathcal{R}}^{t}
and incurring cost
\sum_{R\in{\mathcal{R}}^{t+1}\setminus{\mathcal{R}}^{t}}c_{R}
, and

(ii)

it also incurs the additional augmentation cost

{\sf aug}(e^{t},{\mathcal{R}}^{t+1})
. Often we consider the larger quantity

{\sf aug}(e^{t},{\mathcal{R}}^{t})
instead, since the two differ by at most the cost
incurred in
(i)
due to the minimality property above.

The goal is to minimize the total amount spent on buying the resources
plus the per-step augmentation costs, namely

\sum_{R\in{\mathcal{R}}^{n}}c_{R}+\sum_{t\leq n}{\sf aug}(e^{t},{\mathcal{R}}^{t+1})
. As always,

Opt
denotes the set of resources
of the offline optimal solution, and
c(\textup{{Opt}})
its cost. We note that the “minimality”
property of the augmentation cost implies that the initial
augmentation cost
{\sf aug}(e,\emptyset)
of an element
e
is upper
bounded by
Opt
, as

{\sf aug}(e,\emptyset)\leq\sum_{R\in\textup{{Opt}}}c_{R}+{\sf aug}(e,\textup{{Opt}})\leq c(\textup{{Opt}})
.

4.2
The General Framework

The
ROSC-OCO
algorithm for random order (weighted) set cover
can be extended to a general framework for more general covering
problems. As before, let
{\mathcal{U}}^{t}
be the elements which have not
been seen in the first
t-1
timesteps, so that
{\mathcal{U}}^{1}={\mathcal{U}}
.
Let
{\mathcal{R}}^{t}\subseteq{\mathcal{S}}
be the resources that have been chosen by the
algorithm by the beginning of the
t^{th}
timestep, and hence

{\mathcal{R}}^{1}=\emptyset
. Again we assume we know an estimate
Est
such that

c(\textup{{Opt}})\leq\textsc{Est}\leq 2c(\textup{{Opt}})
, following the discussion from
Section

3.4
; as in the previous section, let

\overline{\scalebox{1.3}{$\blacktriangle$}}:=\{p\in[0,1]^{m}\mid\langle c,p\rangle\leq\textsc{Est}\}
.

In our framework, we define an
augmentation cost estimate

\kappa_{e}^{t}
, with the property that

\displaystyle{\sf aug}(e,{\mathcal{R}}^{t})/\alpha\leq\kappa_{e}^{t}\leq{\sf aug}(e,{\mathcal{R}}^{t})

(4.7)

for some parameter
\alpha\geq 1
. We require that
\kappa_{e}^{t}

should be efficiently computable given
e
and
{\mathcal{R}}^{t}
, and that we
have access to an augmentation algorithm

that, given any

and
{\mathcal{R}}^{t}
, can output an augmentation set

with cost at most

\alpha\kappa_{e}^{t}
. Our algorithm, given in
Algorithm

2

for set cover. Akin to set cover, the randomness in the algorithm’s decisions at time

is denoted by
\omega^{t}
.

Define
{\mathcal{U}}^{1}={\mathcal{U}}

foreach

time
t=1,2,\ldots

do

1

Let
e^{t}
be the next element, which is a uniformly random element of
{\mathcal{U}}^{t}
.

2

Cover
e^{t}
by using augmentation algorithm
Aug
paying
\leq\alpha\kappa^{t}_{e^{t}}

;

//
Backup

3

Buy each resource
S\in{\mathcal{S}}
independently w.p.
(\nicefrac{{\kappa^{t}_{e^{t}}}}{{\textsc{Est}}})\cdot p^{t}_{S}

;

//
Sampling

4

Feed a suitable function
{\sf gain}_{t,e^{t}}
to
OCO-Alg
to get
p^{t+1}\in\overline{\scalebox{1.3}{$\blacktriangle$}}

;

//
OCO

5

{\mathcal{U}}^{t+1}\leftarrow{\mathcal{U}}^{t}\setminus\{e^{t}\}

Algorithm 2

Mono-OCO

Line
2
is not fully specified—the gain function

{\sf gain}_{t,e}

2
the OCO algorithm from
Theorem

2.2
with
\eta=\nicefrac{{1}}{{2}}
.

4.3
The Analysis

Define the potential
function

\displaystyle\Phi^{t}=\sum_{e\in{\mathcal{U}}^{t}}\kappa_{e}^{t},

(4.8)

which is, up to the parameter
\alpha
, the total augmentation costs
{\sf aug}(e,{\mathcal{R}}^{t})
of future items
e\in{\mathcal{U}}^{t}
given the current resources
{\mathcal{R}}^{t}
. The analysis framework is again similar to that for set cover:

1.

The expected cost at any timestep
t
is at most

(\alpha+1)\,\kappa_{e}^{t}
, since we spend at most

\alpha\kappa_{e}^{t}
in Line
2
, and at most

\kappa_{e}^{t}
in expectation in Line
2
.

2.

We define the stopping time
\tau
to be the first timestep for
which
\Phi^{\tau}\leq\textsc{Est}
. Consider the elements
e^{\tau},\ldots,e^{n}
in the order they appear after time
\tau
: the
expected cost incurred is at most

\sum_{t\geq\tau}(\alpha+1)\cdot\kappa_{e^{t}}^{t}\leq\sum_{t\geq\tau}(\alpha+1)\cdot\kappa_{e^{t}}^{\tau}=(\alpha+1)\cdot\Phi^{\tau}.

This is at most
2(\alpha+1)c(\textup{{Opt}})
using the definition of
\tau
. Hence we
now bound the cost incurred prior to the stopping time.

3.

Consider timestep
t
, and condition on the history
{\mathcal{H}}^{t}
of
everything that happened before timestep
t
. Now define the real
gain function to be

\displaystyle{\sf Rgain}_{t}:=\frac{1}{|{\mathcal{U}}^{t}|}\cdot\frac{1}{\Phi^{t}}\cdot\sum_{e,f\in{\mathcal{U}}^{t}}\underset{\omega^{t}}{{\mathbb{E}}\,}[\kappa^{t}_{f}-\kappa^{t+1}_{f}\mid e^{t}=e],

(4.9)

where
\kappa^{t+1}_{f}
depends on the sampled set of resources chosen in Line
2
of the algorithm.

4.

The expected change in potential at timestep is captured by the real gain:

\displaystyle\underset{\omega^{t},\;e\sim{\mathcal{U}}^{t}}{\mathbb{E}}\left[\Phi^{t}-\Phi^{t+1}\right]

\displaystyle\geq\sum_{e\in{\mathcal{U}}^{t}}\frac{1}{|{\mathcal{U}}^{t}|}\sum_{f\in{\mathcal{U}}^{t}}\underset{\omega^{t}}{{\mathbb{E}}\,}[\kappa^{t}_{f}-\kappa^{t+1}_{f}\mid e^{t}=e]

\displaystyle=\Phi^{t}\cdot{\sf Rgain}_{t},

by the definition of
{\sf Rgain}_{t}
. Then, the same analysis as in

Section

3.2
shows that

\displaystyle{\mathbb{E}}\,\bigg[\sum_{t<\tau}{\sf Rgain}_{t}\bigg]\leq 1+\underset{}{\mathbb{E}}\left[\log\left(\frac{\Phi^{0}}{\Phi^{\tau-1}}\right)\right]\leq O(\log n),

(4.10)

where again the last inequality uses that

\Phi^{\tau-1}>\textsc{Est}\geq c(\textup{{Opt}})
by definition of
\tau
and

Est
and

\Phi^{0}=\sum_{e\in{\mathcal{U}}}\kappa^{0}_{e}\leq\sum_{e\in{\mathcal{U}}}{\sf aug}(e,\emptyset)\leq n\cdot c(\textup{{Opt}})
.

Thus far, the analysis has been completely generic, and applies to any
monotone augmentation cost. We finally need some problem-dependent
properties to upper bound the cost of the algorithm by this sum of real gains
\sum_{t}{\sf Rgain}_{t}
, connecting to the
{\sf gain}_{t,e^{t}}
employed in the algorithm. The following lemma captures the properties we need to
turn a low-regret guarantee for the
OCO-Alg
subroutine into one
showing bounded competitive ratio.

Lemma 4.1
.

Assume that for each
t
, there exists a
gain function
{\sf gain}_{t}(p):\overline{\scalebox{1.3}{$\blacktriangle$}}\rightarrow{\mathbb{R}}_{+}
such that:

(A1)

(Lower Bound on Real Gain)
There exists a constant

\gamma\in(0,1]
such that for all
t\in[n]
, we have

\gamma\,{\sf gain}_{t}(p^{t})\leq{\sf Rgain}_{t};

(A2)

(Unbiasedness)
the gain function can
be written as

{\sf gain}_{t}(p)=\underset{e\sim{\mathcal{U}}^{t}}{{\mathbb{E}}\,}[{\sf gain}_{t,e}(p)],

and hence
the subgradient
G_{t}=\partial{\sf gain}_{t,e^{t}}(p^{t})
gives an
unbiased estimate of
\partial{\sf gain}_{t}(p^{t})
;

(A3)

(Bounded Gradients)
These unbiased estimates

G_{t}
satisfy
(G_{t})_{i}\in[0,c_{i}/\textsc{Est}]
, and

(A4)

(Sufficient Static Gains)
There exists a vector

p^{\star}\in\overline{\scalebox{1.3}{$\blacktriangle$}}
and some
\beta,\delta>0
such that

{\mathbb{E}}\,\bigg[\sum_{t<\tau}c(\textup{{Alg}}_{t})\bigg]\leq c(\textup{{Opt}})\cdot\bigg(\beta\;{\mathbb{E}}\,\bigg[\sum_{t<\tau}{\sf gain}_{t}(p^{\star})\bigg]+\delta\bigg).

Then, it holds that the cost
c(\textup{{Alg}})
of
Algorithm

1
is bounded by

\underset{}{\mathbb{E}}\left[c(\textup{{Alg}})\right]\leq\Big(O(\alpha)+\frac{O(\beta\,\log mn)}{\gamma}+\delta\Big)\cdot c(\textup{{Opt}}).

Proof.

Since
G_{t}=\partial{\sf gain}_{t,e^{t}}(p)
is an unbiased estimate of

\partial{\sf gain}_{t}(p^{t})
by Assumption
(A2)
, and

G_{t,i}\in[0,c_{i}/\textsc{Est}]
by Assumption
(A3)
, we can
use
Theorem

2.2
with
\eta=\nicefrac{{1}}{{2}}
to infer that for any vector

p^{\star}\in\overline{\scalebox{1.3}{$\blacktriangle$}}
,

{\mathbb{E}}\,\bigg[\sum_{t<\tau}{\sf gain}_{t}(p^{t})\bigg]\geq(1-\eta)\cdot{\mathbb{E}}\,\bigg[\sum_{t<\tau}{\sf gain}_{t}(p^{\star})\bigg]-\frac{O(\log m)}{\eta}=\frac{1}{2}\cdot{\mathbb{E}}\,\bigg[\sum_{t<\tau}{\sf gain}_{t}(p^{\star})\bigg]-O(\log m).

Moreover, combining Assumption
(A1)
with (
4.10
):

{\mathbb{E}}\,\bigg[\sum_{t<\tau}{\sf gain}_{t}(p^{t})\bigg]\leq\frac{1}{\gamma}\cdot{\mathbb{E}}\,\bigg[\sum_{t<\tau}{\sf Rgain}_{t}\bigg]\leq\nicefrac{{1}}{{\gamma}}\cdot O(\log n).

Combining the two inequalities above with Assumption
(A4)
gives

\sum_{t<\tau}\underset{}{\mathbb{E}}\left[c(\textup{{Alg}}_{t})\right]\leq c(\textup{{Opt}})\cdot\bigg(\frac{O(\beta\,\log mn)}{\gamma}+\delta\bigg).

Finally, adding in the
O(\alpha\cdot c(\textup{{Opt}}))
cost after the
stopping time completes the proof.
∎

To summarize, using this framework to get

-competitive
algorithms requires the following:

(i)

Define a suitable proxy

which is an under-estimate
for the augmentation cost

, and also show an

that covers
e
with cost at most

\alpha\,\kappa_{e}^{t}
.

(ii)

Give a “decoupled” function

which satisfies the
four assumptions in
Lemma

4.1
, for values

\gamma,\beta\in\Theta(1)
. Recall this gain function is the one

.

In the random-order (unweighted) set multicover problem, the resources

are again, but now each element

arrives with an
integer demand

\displaystyle\min\;\langle\bm{1},x\rangle

\displaystyle~\text{s.t.}~Ax\geq b

(

\displaystyle\qquad x\in\{0,1\}^{m},

where
A\in\{0,1\}^{n\times m}
is the set-element incidence
matrix, and
b\in{\mathbb{Z}}^{n}_{+}
is the vector of demands. Recall that
{\mathcal{R}}^{t}
denotes the resources/sets picked by the algorithm before time
t

t

let
b^{t}_{e}:=\max(0,b_{e}-\sum_{S\in{\mathcal{R}}^{t}}A_{eS}x^{t}_{S})
denote the “uncoverage”
for element

at time

have

—i.e., elements are

5.1.1
Augmentation Costs and the Potential

Since we have unit set costs, we can pick
b^{t}_{e}

as-yet-unpicked sets to cover
e
, and hence we have

{\sf aug}(e,{\mathcal{R}}^{t}):=b^{t}_{e}
. Define the augmentation cost estimate as the cost itself, namely
\kappa^{t}_{e}=b^{t}_{e}

in (

). Conditioning on the

{\mathcal{H}}^{t}
until time

is

\displaystyle{\sf Rgain}_{t}

\displaystyle=\frac{1}{\Phi^{t}\cdot|{\mathcal{U}}^{t}|}\sum_{e,f\in{\mathcal{U}}^{t}}\underset{\omega^{t}}{{\mathbb{E}}\,}\big[b^{t}_{f}-b^{t+1}_{f}~\big|~e^{t}=e\big].

(5.11)

Define its linearization/decoupling as:

\displaystyle{\sf gain}_{t}(p)=\underset{f\sim{\mathcal{U}}^{t}}{{\mathbb{E}}\,}[{\sf gain}_{t,f}(p)]\qquad\text{where}\qquad{\sf gain}_{t,f}(p)=\frac{1}{\textsc{Est}}\min\Big(b_{f}^{t},\sum_{S\not\in{\mathcal{R}}^{t}}A_{fS}\;p_{S}\Big).

Using this definition of

and the gain function, we can

5.1.2
Competitiveness

Theorem 5.1
.

There exists an

Proof.

Fix time

until time

(

(

\displaystyle{\sf gain}_{t,f}(p^{\star})

\displaystyle=\frac{1}{\textsc{Est}}\min\Big(b_{f}^{t},\sum_{S\not\in{\mathcal{R}}^{t}}A_{fS}\;p^{\star}_{S}\Big)=\frac{b_{f}^{t}}{\textsc{Est}}=\frac{\kappa_{f}^{t}}{\textsc{Est}},

(5.13)

where we used the feasible of
p^{\star}
to infer that it must
(fractionally) pick at least
b_{f}^{t}
sets from
{\mathcal{S}}\setminus{\mathcal{R}}^{t}
containing
f
. Using
(
5.13
), that, as before, the algorithm’s expected cost in Lines
2
and
2
is at most
\mathbb{E}_{f\in{\mathcal{U}}^{t}}[\kappa_{f}^{t}]+\mathbb{E}_{f\in{\mathcal{U}}^{t}}[\kappa_{f}^{t}]
and
\textsc{Est}\leq 2c(\textup{{Opt}})
in the definition of

{\sf gain}_{t}
, we get

{\sf gain}_{t}(p^{\star})=\frac{1}{\textsc{Est}}\cdot\underset{f\sim{\mathcal{U}}^{t}}{{\mathbb{E}}\,}[\kappa_{f}^{t}]\geq\frac{{\mathbb{E}}\,[c(\textup{{Alg}}_{t})]}{4c(\textup{{Opt}})},

thereby satisfying
the final property
(A4)
. The competitive ratio of the algorithm from
Theorem

5.1
now follows from
Lemma

4.1
.
∎

5.2
Covering Integer Programs

Our second application is to random-order covering integer programs
(CIPs): each element
e
requires a coverage of
1
, and each
resource/set provides
A_{eS}\in[0,1]
amount of coverage for
it. Our goal is to find the cheapest set of resources that cover all
elements. In the random order model, the instance is chosen by the
adversary, and then the elements arrive in random order. Formally, we
want to solve the following IP:

\displaystyle\min\;\langle c,x\rangle

\displaystyle~\text{s.t.}~Ax\geq 1

(
CIP
)

\displaystyle\qquad x\in{\mathbb{Z}}^{m}_{+},

where
A\in[0,1]^{n\times m}
; the restriction of
A
to
[0,1]
is
without loss of generality, since the RHS is
1
. Note that we do not
have upper bounds on the variables
x
, and hence this does not
generalize set multicover. Indeed, we can pick multiple copies of each
resource, and hence, instead of
{\mathcal{R}}^{t}
, we now use
x^{t}\in{\mathbb{Z}}^{m}_{+}
to indicate how many copies of each set the algorithm has picked before time
t
. To reduce notation, let

\langle A_{e},x\rangle=\sum_{S\in{\mathcal{S}}}A_{eS}x_{S}
denote the coverage of the
resource
e
by solution
x
.

5.2.1
Half-Covering and the Augmentation Function

It will be convenient to consider a “half-coverage” variant of the
problem: we will consider the element
e
covered by a solution
x\in{\mathbb{Z}}_{+}^{m}

if the coverage
\langle A_{e},x\rangle
is at least
1/2
. Since we do not have
any upper bounds, we can always transform such a “half-solution” to
a full solution by taking the solution
2x
(i.e., by actually picking
two units of the resource when the algorithm picks one), at the
expense of doubling the cost. Henceforth, we focus on this
half-coverage variant. For an element
e
, we define

b_{e}^{t}:=\begin{cases}1-\langle A_{e},x^{t}\rangle&\text{if $\langle A_{e},x^{t}\rangle\leq\nicefrac{{1}}{{2}}$}\\
0&\text{otherwise}.\end{cases}

Observe that
b_{e}^{t}\in\{0\}\cup[\nicefrac{{1}}{{2}},1]
. Next, define

\displaystyle{\sf aug}(e,x^{t}):=\min\{y\in{\mathbb{Z}}_{+}^{m}\mid\langle A_{e},y\rangle\geq b_{e}^{t}\}.

(5.14)

Let
S(e):=\arg\min_{S\in{\mathcal{S}}}\frac{c_{S}}{A_{eS}}
be the set that
maximizes the bang-per-buck for element
e
, and
let the optimal density be
\rho_{e}=c_{S(e)}/A_{eS(e)}
. Define the augmentation cost estimate

\kappa_{e}^{t}=\begin{cases}b_{e}^{t}\cdot\rho_{e}&\text{if $b_{e}^{t}\geq\nicefrac{{1}}{{2}}$}\\
0&\text{otherwise}.\end{cases}

The (fractional) solution which chooses
b_{e}^{t}/A_{eS(e)}
copies of
set
S(e)
is the optimal solution to the fractional relaxation of
(
5.14
) with cost
\kappa_{e}^{t}
; this shows that

\kappa_{e}^{t}\leq{\sf aug}(e,x^{t})
. Moreover, choosing

\lceil b_{e}^{t}/A_{eS(e)}\rceil
copies of set
S(e)
is an integer
solution, and since
b_{e}^{t}\geq\nicefrac{{1}}{{2}}
and
A_{eS}\leq 1
, we get
that
{\sf aug}(e,x^{t})/4\leq\kappa_{e}^{t}
, giving us
\alpha=4
in
the inequality (
4.7
).

For a generic element
f\in{\mathcal{U}}^{t}
, it holds that

\kappa^{t}_{f}-\kappa^{t+1}_{f}=\rho_{f}\cdot(b^{t}_{f}-b^{t+1}_{f})

The real gain function at time
t
is

\displaystyle{\sf Rgain}_{t}(p^{t})

\displaystyle=\frac{1}{\Phi^{t}\cdot|{\mathcal{U}}^{t}|}\sum_{e,f\in{\mathcal{U}}^{t}}\underset{\omega^{t}}{{\mathbb{E}}\,}\big[\kappa^{t}_{f}-\kappa^{t+1}_{f}~\big|~e^{t}=e\big]=\frac{1}{\Phi^{t}\cdot|{\mathcal{U}}^{t}|}\sum_{e,f\in{\mathcal{U}}^{t}}\rho_{f}\cdot\underset{\omega^{t}}{{\mathbb{E}}\,}\big[b^{t}_{f}-b^{t+1}_{f}~\big|~e^{t}=e\big].

We now define the decoupled gain function:

\displaystyle{\sf gain}_{t}(p)=\underset{f\sim{\mathcal{U}}^{t}}{{\mathbb{E}}\,}[\,{\sf gain}_{t,f}(p)\,]\qquad\text{where}\qquad{\sf gain}_{t,f}(p)=\frac{\rho_{f}}{\textsc{Est}}\cdot\min\Big(b_{f}^{t},\langle A_{f},p\rangle\Big).

(5.15)

Using this definition of

\kappa_{e}^{t}
and
{\sf gain}_{t}(p)
, we instantiate the framework
Mono-OCO

on the polytope

\{p\in[0,1]^{n}\mid\langle c,p\rangle\leq\textsc{Est}\}
.

5.2.2
Competitiveness

Theorem 5.2
.

There exists an
O(\log(mn))
-competitive algorithm for
random-order CIPs.

Proof.

It suffices to verify the properties
in
Lemma

4.1
. The unbiasedness
condition
(A2)
is satisfied by definition. For the
others, fix a time
t
, and condition on the history
{\mathcal{H}}^{t}
until
time
t
.

(
Lower Bound on Real Gain
): Using
B.2
again and

\kappa_{e}^{t}\leq\textsc{Est}
, we get that

\displaystyle{\mathbb{E}}\,[b^{t}_{f}

\displaystyle-b^{t+1}_{f}\mid e^{t}=e]={\mathbb{E}}\,\Big[\min\Big(b_{f}^{t},\sum_{S\in{\mathcal{S}}}A_{fS}\cdot\mathbbm{1}\!\left(S\text{ is sampled at time }t\right)\Big)~\Big|~e^{t}=e\Big]

\displaystyle\geq\nicefrac{{1}}{{168}}\cdot\min\Big(b_{f}^{t},\sum_{S\in{\mathcal{S}}}A_{fS}\cdot\Pr[S\text{ is sampled at time }t\mid e^{t}=e]\Big)=\nicefrac{{1}}{{168}}\cdot\min\Big(b_{f}^{t},\sum_{S\in{\mathcal{S}}}A_{fS}\cdot\frac{p_{S}^{t}\;\kappa^{t}_{e}}{\textsc{Est}}\Big)

\displaystyle\geq\nicefrac{{1}}{{168}}\cdot\frac{\kappa^{t}_{e}}{\textsc{Est}}\cdot\min\Big(b_{f}^{t},\langle A_{f},p^{t}\rangle\Big)=\nicefrac{{1}}{{168}}\cdot\frac{\kappa^{t}_{e}}{\rho_{f}}\cdot{\sf gain}_{t,f}(p^{t}).

To prove property
(A1)
we substitute the above

) and recall

to get

\displaystyle{\sf Rgain}_{t}(p^{t})

\displaystyle\geq\nicefrac{{1}}{{168}}\cdot\underset{f\sim{\mathcal{U}}^{t}}{{\mathbb{E}}\,}[{\sf gain}_{t,f}(p^{t})]=\nicefrac{{1}}{{168}}\cdot{\sf gain}_{t}(p^{t}).

(
Bounded Gradients
): To prove property
(A3)
, we
observe that
\nicefrac{{\partial}}{{\partial p_{S}}}\;{\sf gain}_{t,f}(p)=0
if

b^{t}_{f}
is the minimum in the
{\sf gain}_{t,f}(p)
expression. Otherwise,
using that

\displaystyle\frac{\partial}{\partial p_{S}}{\sf gain}_{t,f}(p)

\displaystyle=\frac{\rho_{f}}{\textsc{Est}}\cdot A_{fS}\leq\frac{c_{S}}{\textsc{Est}}.

(
Sufficient Static Gains
): As in previous applications,
define
p^{\star}
to be the optimal (fractional) solution to the
linear programming relaxation of (
CIP
). The argument is a familiar one:
since
p^{\star}
is feasible, we have
\langle A_{f},p^{\star}\rangle\geq b_{f}
,
and hence

{\sf gain}_{t,f}(p^{\star})=b_{f}^{t}\rho_{f}/\textsc{Est}=\kappa_{f}^{t}/\textsc{Est}
. Property
(A4)

{\sf gain}_{t}(p^{\star})=\frac{1}{\textsc{Est}}\cdot\underset{f\sim{\mathcal{U}}^{t}}{{\mathbb{E}}\,}[\kappa_{f}^{t}]\geq\frac{{\mathbb{E}}\,[c(\textup{{Alg}}_{t})]}{2(\alpha+1)\,c(\textup{{Opt}})}.

5.3
Non-Metric Facility Location

As the third and final application, we consider random-order
non-metric facility location. There are clients/elements
{\mathcal{U}}
and
facilities
{\mathcal{S}}
, which are all points in a distance space (which is
not required to satisfy the triangle inequality). Opening a facility
at location
i\in{\mathcal{S}}
incurs a cost of
c_{i}
; each client

e\in{\mathcal{U}}
can then be connected to some open facility
i
,
incurring a cost of
d_{ie}
. Formally, we want a solution to the
following IP:

\displaystyle\min\quad

\displaystyle\sum_{i\in{\mathcal{S}}}c_{i}y_{i}+\sum_{i\in{\mathcal{S}}}\sum_{e\in{\mathcal{U}}}d_{ie}x_{ie}

s.t.

\displaystyle\sum_{i\in{\mathcal{S}}}x_{ie}=1

\displaystyle\forall e\in{\mathcal{U}}

(
NMFL
)

\displaystyle x_{ie}\leq y_{i}

\displaystyle\forall i\in{\mathcal{S}},e\in{\mathcal{U}}

\displaystyle y_{i},x_{ie}\in\{0,1\}

\displaystyle\forall i\in{\mathcal{S}},e\in{\mathcal{U}}.

Above,
y_{i}
indicates that facility
i
is opened, and
x_{ie}
indicates that client
e
is connected to facility
i
.
In the random-order
version of the problem, clients
e\in{\mathcal{U}}
arrive according to a
uniform permutation; we may open some facilities when a client
arrives, but then have to connect it to an open facility and pay the
connection cost.

5.3.1
Augmentation Costs and the Potential

Let
{\mathcal{R}}^{t}
represent the facilities opened by the algorithm before
time step
t
. The augmentation cost for a generic client
e
at time

t
with respect to collection
{\mathcal{R}}^{t}
of facilities is:

{\sf aug}(e,{\mathcal{R}}^{t})=\min_{i\in{\mathcal{S}}}(\mathbbm{1}\!\left(i\notin{\mathcal{R}}^{t}\right)c_{i}+d_{ie})=\min\big(\min_{i\in{\mathcal{R}}^{t}}d_{ie},\min_{i\not\in{\mathcal{R}}^{t}}(c_{i}+d_{ie})\big).

That is, we can either choose the closest open facility in
{\mathcal{R}}^{t}
, or
open a new facility and connect to it. We define the augmentation cost estimate to be the cost itself, namely
\kappa^{t}_{e}={\sf aug}(e,{\mathcal{R}}^{t})
, which means the approximation factor in
equation (
4.7
) is
\alpha=1
.

Next, conditioned on the algorithm’s history
{\mathcal{H}}^{t}
up to time
t
, the expected real gain at step
t
is given by:

{\sf Rgain}_{t}=\frac{1}{\Phi^{t}\cdot|{\mathcal{U}}^{t}|}\sum_{e,f\in{\mathcal{U}}^{t}}\underset{\omega^{t}}{{\mathbb{E}}\,}\big[\kappa^{t}_{f}-\kappa^{t+1}_{f}\mid e^{t}=e\big].

(5.16)

As we did in previous applications, we introduce the
linearized/decoupled version of the gain for the problem at hand so
that it fits into the general framework described in
Section
4
. To this end, let

\Gamma^{t}_{f}:=\{i\in{\mathcal{S}}\mid d_{if}\leq\nicefrac{{\kappa^{t}_{f}}}{{2}}\}
denote the set of facilities which, once
opened, make the cost of satisfying
f
half (or less) than its
current cost
\kappa^{t}_{f}
, and let
\chi^{t}_{f}\in\{0,1\}^{m}
be the
indicator vector of the set
\Gamma^{t}_{f}
. We define the linearized/decoupled gain as:

\displaystyle{\sf gain}_{t}(p):=\mathbb{E}_{f\sim{\mathcal{U}}^{t}}\left[{\sf gain}_{t,f}(p)\right],\quad\text{where}\quad{\sf gain}_{t,f}(p):=\frac{\kappa^{t}_{f}}{2\textsc{Est}}\cdot\min\big(1,\langle\chi^{t}_{f},p\rangle\big).

Using this definition of

\kappa_{e}^{t}
and
{\sf gain}_{t}(p)
, we instantiate the framework
Mono-OCO

on the polytope

\{p\in[0,1]^{n}\mid\langle c,p\rangle\leq\textsc{Est}\}
.

5.3.2
Competitiveness

Theorem 5.3
.

There exists an
O(\log(mn))
-competitive algorithm for random-order non-metric facility location.

Proof.

Let us fix a time
t
, and condition on the history
{\mathcal{H}}^{t}
until time
t
. We check all properties in
Lemma

4.1
, except property
(A2)
(unbiasedness), since this is satisfied by definition of the
{\sf gain}_{t}
function.

(
Lower Bound on Real Gain
) Fix a client
f
and observe that if in iteration
t
the algorithm samples some facility in
\Gamma^{t}_{f}
, then
\kappa^{t+1}_{f}\leq\nicefrac{{\kappa^{t}_{f}}}{{2}}
by definition. Therefore,

\displaystyle\underset{\omega^{t}}{{\mathbb{E}}\,}[\,\kappa^{t}_{f}

\displaystyle-\kappa^{t+1}_{f}\mid e^{t}=e]\geq\nicefrac{{\kappa^{t}_{f}}}{{2}}\cdot\Pr(\textrm{some $i\in\Gamma^{t}_{f}$ is sampled at time $t$}\mid e^{t}=e)

\displaystyle=\nicefrac{{\kappa^{t}_{f}}}{{2}}\cdot\bigg(1-\prod_{i\in\Gamma^{t}_{f}}(1-(\nicefrac{{\kappa^{t}_{e}}}{{\textsc{Est}}})\cdot p^{t}_{i})\bigg)\geq\frac{1-\nicefrac{{1}}{{e}}}{2}\cdot\kappa^{t}_{f}\cdot\min\bigg(1,(\nicefrac{{\kappa^{t}_{e}}}{{\textsc{Est}}})\cdot\sum_{i\in\Gamma^{t}_{f}}p^{t}_{i}\bigg)

\displaystyle\geq\frac{1-\nicefrac{{1}}{{e}}}{2}\cdot\kappa^{t}_{f}\cdot\frac{\kappa^{t}_{e}}{\textsc{Est}}\cdot\min\big(1,\langle\chi^{t}_{f},p^{t}\rangle\big)=(1-\nicefrac{{1}}{{e}})\cdot\kappa^{t}_{e}\cdot{\sf gain}_{t,f}(p^{t}),

where the first equality uses that, conditioned on
e^{t}=e
, the
sampling probability of facility
i
is

(\nicefrac{{\kappa^{t}_{e}}}{{\textsc{Est}}})\cdot p^{t}_{i}
. Substituting back, we
get that

\displaystyle{\sf Rgain}_{t}\geq(1-\nicefrac{{1}}{{e}})\cdot{\sf gain}_{t}(p^{t}),

showing property
(A1)
.

(
Bounded Gradients
): We have that the subgradient

\nicefrac{{\partial}}{{\partial p_{i}}}\,{\sf gain}_{t,f}(p)=0
if

\sum_{i\in\Gamma^{t}_{f}}p^{t}_{i}\geq 1
or if
i\notin\Gamma^{t}_{f}
. Otherwise, if facility
i\in\Gamma^{t}_{f}
, we have

d_{if}\leq\nicefrac{{\kappa^{t}_{f}}}{{2}}
. Moreover, since
\kappa^{t}_{f}
is
the minimal augmentation cost for client
f
, we get that

\kappa^{t}_{f}\leq c_{i}+d_{if}
. Combining the two inequalities, we
infer
\kappa^{t}_{f}\leq 2c_{i}
and therefore

\displaystyle\frac{\partial}{\partial p_{i}}{\sf gain}_{t,f}(p)

\displaystyle\leq\frac{\kappa^{t}_{f}}{2\textsc{Est}}\leq\frac{c_{i}}{\textsc{Est}},

which shows property
(A3)
.

(
Sufficient Static Gains
): To show this property, set

p^{\star}=y^{\star}
, i.e., the optimal fractional solution to the
linear programming relaxation of (
NMFL
).
Let
\textsc{Easy}^{t}
be the set of remaining clients

f\in{\mathcal{U}}^{t}
such that
\langle\chi^{t}_{f},p^{\star}\rangle\geq\nicefrac{{1}}{{2}}
,
i.e., the optimal fractional solution opens at least half a facility
in
\Gamma^{t}_{f}
. This means

\displaystyle{\sf gain}_{t}(p^{\star})

\displaystyle=\underset{f\sim{\mathcal{U}}^{t}}{\mathbb{E}}\left[{\sf gain}_{t,f}(p^{\star})\right]\geq\frac{1}{|{\mathcal{U}}^{t}|}\sum_{f\in\textsc{Easy}^{t}}\frac{\kappa^{t}_{f}}{2\textsc{Est}}\cdot\min(1,\langle\chi^{t}_{f},p^{t}\rangle)

\displaystyle\geq\frac{1}{2\textsc{Est}\cdot|{\mathcal{U}}^{t}|}\sum_{f\in\textsc{Easy}^{t}}\kappa^{t}_{f}\cdot\nicefrac{{1}}{{2}}=\frac{1}{4\textsc{Est}\cdot|{\mathcal{U}}^{t}|}\Bigg(\sum_{f\in{\mathcal{U}}^{t}}\kappa^{t}_{f}-\sum_{f\in\textsc{Hard}^{t}}\kappa^{t}_{f}\Bigg),

where
\textsc{Hard}^{t}:={\mathcal{U}}^{t}\setminus\textsc{Easy}^{t}
. If

f\in\textsc{Hard}
, then in the optimal fractional solution at
least half of
f
’s connection has to come from facilities outside

\Gamma^{t}_{f}
, i.e., at distance at least
\nicefrac{{\kappa^{t}_{f}}}{{2}}
.
This means the optimal fractional connection cost for
f
is at
least
\nicefrac{{\kappa^{t}_{f}}}{{4}}
.

Observe that
{\mathbb{E}}\,_{f\sim{\mathcal{U}}^{t}}[\kappa^{t}_{f}]\leq 2{\mathbb{E}}\,[c(\textup{{Alg}}_{t})]
, and so we get

\displaystyle{\sf gain}_{t}(p^{\star})\geq\frac{{\mathbb{E}}\,[c(\textup{{Alg}}_{t})]}{8\textsc{Est}}-\frac{1}{4\textsc{Est}\cdot|{\mathcal{U}}^{t}|}\sum_{f\in\textsc{Hard}^{t}}\kappa^{t}_{f}.

By the discussion above, any client
f\in\textsc{Hard}^{t}
has
that its augmentation cost
\kappa^{t}_{f}
is at most four times the fractional connection cost
for
f
in
Opt
, and hence

\sum_{f\in\textsc{Hard}^{t}}\kappa^{t}_{f}\leq 4c(\textup{{Opt}})
. Moreover, the
cardinality of
{\mathcal{U}}^{t}
is
n-t+1
, and hence the above
expression becomes

\displaystyle{\sf gain}_{t}(p^{\star})\geq\frac{{\mathbb{E}}\,[c(\textup{{Alg}}_{t})]}{8\textsc{Est}}-\frac{c(\textup{{Opt}})}{\textsc{Est}\cdot(n-t+1)}.

(5.17)

Finally, the fact that

c(\textup{{Opt}})\leq\textsc{Est}\leq 2c(\textup{{Opt}})
gives

\displaystyle{\sf gain}_{t}(p^{\star})\geq\frac{\underset{}{\mathbb{E}}\left[c(\textup{{Alg}}_{t})\right]}{16\,c(\textup{{Opt}})}-\frac{1}{n-t+1}.

(5.18)

Adding over all times
t<\tau\leq n
and taking expectations,
we get

\underset{}{\mathbb{E}}\left[\sum_{t<\tau}c(\textup{{Alg}}_{t})\right]\leq 16\,c(\textup{{Opt}})\cdot\bigg(\underset{}{\mathbb{E}}\left[\sum_{t<\tau}{\sf gain}_{t}(p^{\star})\right]+\log n\bigg).

thereby establishing property
(A4)
.
Theorem

5.3
is, thus, implied by
Lemma

4.1
.
∎

6
Closing Remarks

In this work, we present a unified and modular framework connecting random-order online algorithms to online learning. By isolating the learning component, we show that any suitable OCO algorithm can be used as a black-box subroutine to achieve optimal competitiveness. This approach recovers
O(\log mn)
-competitive algorithms for classic problems—Weighted Set Cover, Unweighted Set Multicover, Covering Integer Programs, and Non-metric Facility Location—through a single, clean template.

Future Directions.

The framework outlined above appears conceptually general and opens several promising directions for future work. A primary challenge lies in extending it to broader classes of problems with box constraints—for example, unweighted
multiset
multicover (i.e., unweighted set multicover where the matrix
A
is not Boolean). For such settings, it remains unclear how to establish the requisite bounds, in particular, designing a function
{\sf gain}_{t,f}
that both has bounded gradients (property
(A3)
) and satisfies the static gains condition (property
(A4)
). This is a key open question and a compelling direction for further understanding the workings and limitations of the technique.

A.1

Lemma A.1

Given the above setup, define

\displaystyle x_{t+1}\in\operatorname{argmin}_{x\in{\mathcal{V}}}\langle\partial\ell_{t}(x_{t}),x\rangle+\frac{1}{\eta_{t}}B_{\psi}(x,x_{t})\quad\text{and}

(A.19)

\displaystyle\tilde{x}_{t+1}\in\operatorname{argmin}_{x\in{\mathcal{X}}}\langle\partial\ell_{t}(x_{t}),x\rangle+\frac{1}{\eta_{t}}B_{\psi}(x,x_{t});

(A.20)

\displaystyle\ell_{t}(x_{t})-\ell_{t}(u)\leq\frac{1}{\eta_{t}}\big(B_{\psi}(u;x_{t})-B_{\psi}(u;x_{t+1})\big)+\frac{\eta_{t}}{2}\|\partial\ell_{t}(x_{t})\|^{2}_{(\nabla^{2}\psi(\tilde{z}_{t}))^{-1}}.

(A.21)

Applying this with

\text{uKL}(p;q)=\sum_{i}p_{i}\log\nicefrac{{p_{i}}}{{q_{i}}}-p_{i}+q_{i}

Lemma

[-1,1]
by assumption. Since
\tilde{z}_{t}
lies on
the line segment between
x_{t}
and
\tilde{x}_{t+1}
, its coordinates are
sandwiched between those of the two vectors, and hence

\frac{\eta_{t}}{2}\|\partial\ell_{t}(x_{t})\|^{2}_{(\nabla^{2}\psi(\tilde{z}_{t}))^{-1}}\leq\frac{e\eta}{2}\cdot\sum_{i}(\partial_{i}\ell_{t}(x_{t}))^{2}\cdot x_{t,i}.

The result then follows from
Lemma

A.1
.
∎

When we are given a linear
gain
function
\langle a_{t},x\rangle

for
a_{t}\in[0,1]^{d}
, we can define
\ell_{t}(x)=-\langle a_{t},x\rangle
, and use
the fact that
\partial\ell_{t}(x)=-a_{t}

and
a_{t,i}^{2}\leq a_{t,i}
to derive that for any
u\in{\mathcal{V}}
,

\displaystyle(1+O(\eta))\langle a_{t},x_{t}\rangle-\langle a_{t},u\rangle\geq-\frac{1}{\eta}\big(\textup{uKL}(u;x_{t})-\textup{uKL}(u;x_{t+1})\big).

Summing over all times
t
, and simplifying,

\displaystyle\sum_{t}\langle a_{t},x_{t}\rangle\geq(1-O(\eta))\sum_{t}\langle a_{t},u\rangle-O(1)\cdot\frac{\textup{uKL}(u;x_{0})}{\eta}.

Choosing
x_{0}=\nicefrac{{1}}{{d}}\cdot\mathbf{1}
, and
u\in{\mathcal{V}}\subseteq\scalebox{1.3}{$\blacktriangle$}
, the last term is at
most
O(\log d)
; suitably changing the constants in the value of

\eta
, we get the familiar regret bound for linear gain functions: for every
T
,

\displaystyle\forall u\in{\mathcal{V}},\qquad\sum_{t\leq T}\langle a_{t},x_{t}\rangle\geq(1-\eta)\sum_{t\leq T}\langle a_{t},u\rangle-\frac{O(\log d)}{\eta},

(A.22)

but now for constrained optimization over
{\mathcal{V}}
instead of over the full simplex.

A.2
Extending to Stochastic Gradients

We now extend to the setting where we get unbiased estimates of the
(sub)gradient, instead of getting the subgradient itself. In our
application, at each time
t
,

1.

The algorithm plays some action
x_{t}\in{\mathcal{V}}
, which depends on

{\mathcal{H}}^{t}
, the history of everything that has happened at timesteps
before
t
.

2.

Then the adversary chooses a
concave
gain function

g_{t}:{\mathbb{R}}^{d}\to{\mathbb{R}}_{+}
; this may depend on the history
{\mathcal{H}}^{t}
and
also the algorithm’s action
x_{t}
.

3.

The algorithm sees a random vector
G_{t}\in{\mathbb{R}}^{d}
whose expectation conditioned on the history
{\mathcal{H}}^{t}
and the action
x_{t}
equals
\partial g_{t}(x_{t})
. We assume that
G_{t}\in[0,1]^{d}
with probability 1.

Let
\tau
be any stopping time adapted to the history sequence
{\mathcal{H}}^{1},{\mathcal{H}}^{2},\ldots
. The first observation is that for any particular sample path, the
bound from (
A.22
) gives us that for any
x^{*}\in{\mathcal{V}}
,

\displaystyle\sum_{t\leq\tau}\langle G_{t},x_{t}\rangle\geq(1-\eta)\,\sum_{t\leq\tau}\langle G_{t},x^{*}\rangle-\frac{O(\log d)}{\eta}.

(A.23)

Since
\tau
is a stopping time adapted to
({\mathcal{H}}^{t})_{t}
and
x_{t}
is completely determined by the history
{\mathcal{H}}^{t}
, we have
\underset{}{\mathbb{E}}\left[\langle G_{t},x_{t}\rangle\cdot\bm{1}(t\leq\tau)\mid{\mathcal{H}}^{t}\right]=\langle\underset{}{\mathbb{E}}\left[G_{t}\mid{\mathcal{H}}^{t}\right],x_{t}\rangle\cdot\bm{1}(t\leq\tau)=\langle\partial g_{t}(x_{t}),x_{t}\rangle\cdot\bm{1}(t\leq\tau)
, and similarly if we replace
x_{t}
for
x^{*}
. Then adding (
A.23
) over all
t
and taking expectations we get that

\displaystyle{\mathbb{E}}\,\Big[\sum_{t\leq\tau}\langle\partial g_{t}(x_{t}),x_{t}\rangle\Big]\geq(1-\eta)\,{\mathbb{E}}\,\Big[\sum_{t\leq\tau}\langle\partial g_{t}(x_{t}),x^{*}\rangle\Big]-\frac{O(\log d)}{\eta}.

(A.24)

Note that we have expectations on both sides, since the choice of

h_{t}
is allowed to depend on the algorithm’s actions, which are
themselves random.

But now, for the concave function
g_{t}
, we have the property that

\displaystyle g_{t}(x_{t})-g_{t}(x^{*})\geq\langle\partial g_{t}(x_{t}),x_{t}-x^{*}\rangle,\quad\text{and}

\displaystyle g_{t}(x_{t})-g_{t}(0)\geq\langle\partial g_{t}(x_{t}),x_{t}\rangle.

Using that
g_{t}(0)\geq 0
, multiplying the first inequality by

(1-\eta)
and the second by
\eta
, and summing, we get

\displaystyle g_{t}(x_{t})-(1-\eta)\,g_{t}(x^{*})\geq\langle\partial g_{t}(x_{t}),x_{t}\rangle-(1-\eta)\,\langle\partial g_{t}(x_{t}),x^{*}\rangle.

(A.25)

Combining this with (
A.24
) gives that for any
x^{*}\in{\mathcal{V}}
,

\displaystyle{\mathbb{E}}\,\Big[\sum_{t\leq\tau}g_{t}(x_{t})\Big]\geq(1-\eta)\,{\mathbb{E}}\,\Big[\sum_{t\leq\tau}g_{t}(x^{*})\Big]-\frac{O(\log d)}{\eta},

(A.26)

which is what we wanted to prove.

A.3
Scaled Simplex

We now need to extend this to the action space

\overline{\scalebox{1.3}{$\blacktriangle$}}:=\{y\in[0,1]^{d}\mid\langle c,y\rangle\leq M\}
, and concave functions
h_{t}
whose stochastic gradient estimates
H_{t}
satisfy
H_{t,i}\in[0,\frac{c_{i}}{M}]
for each coordinate
i\in[d]
.

For that, one can just linearly transform the space. More precisely,
we define
{\mathcal{V}}
as the truncated simplex
\{x\in[0,\frac{c_{i}}{M}]:\sum_{i}x_{i}\leq 1\}
, which is just the scaling of the playing set

\overline{\scalebox{1.3}{$\blacktriangle$}}
given by
x_{i}:=\frac{c_{i}y_{i}}{M}
, and define the
function
g_{t}(x):=h_{t}(\frac{Mx}{c})
(where
\frac{Mx}{c}
is
defined coordinate-wise, i.e., its
i
th coordinate is
\frac{Mx_{i}}{c_{i}}
). Using the chain rule, we have
\partial_{i}g_{t}(x)=\frac{M}{c_{i}}\cdot\partial_{i}h_{t}(\frac{Mx}{c})=\frac{M}{c_{i}}\cdot\partial_{i}h_{t}(y)
, the last equation using the mapping between
x
- and
y
-space. Thus, the value
G_{t}:=\frac{M}{c}\cdot H_{t}
is an unbiased estimator of
\partial g_{t}(x_{t})
(given that
H_{t}
is an unbiased estimator of
\partial h_{t}(y_{t})
) and
G_{t}\in[0,1]^{d}
(given that
H_{t,i}\in[0,\frac{c_{i}}{M}]
).

Let
y^{\star}:=\frac{Mx^{*}}{c}
; note that since
x^{*}
ranges over all
{\mathcal{V}}
,
y^{\star}
ranges over all
\overline{\scalebox{1.3}{$\blacktriangle$}}
.
The bound (
A.26
) translates into the following guarantee:

\displaystyle\forall y^{\star}\in\overline{\scalebox{1.3}{$\blacktriangle$}},\qquad{\mathbb{E}}\,\Big[\sum_{t\leq\tau}h_{t}(y_{t})\big]\geq(1-\eta){\mathbb{E}}\,\Big[\sum_{t\leq\tau}h_{t}(y^{\star})\Big]-\frac{O(\log d)}{\eta}\,.

This finally concludes the proof of
Theorem

2.2
.

Appendix B
Probabilistic Inequalities

The following claim is quite standard, but we give a proof here for
completeness.

Claim B.1
.

For non-negative reals
a_{1},a_{2},\ldots
,
we have
1-\prod_{k}(1-a_{k})\geq(1-\nicefrac{{1}}{{e}})\cdot\min(1,\sum_{k}a_{k})
.

Proof.

Without loss of generality, assume that
\sum_{k}a_{k}\leq 1
, else we
can reduce some of
a_{k}
values until this is satisfied; this only
reduces the LHS without reducing the RHS. Now,

1-\prod_{k}(1-a_{k})\geq 1-\exp\Big(-\sum_{k}a_{k}\Big)\geq(1-\nicefrac{{1}}{{e}})\sum_{k}a_{k},

where the first inequality uses
1+y\leq e^{y}

for all reals
y
, and the second follows by minimizing

(1-e^{-y})/y
, for
y\in(0,1]
.
∎

Fact B.2

(Fact 4.4 in
(
GKL 21
)
)
.

Let
\pi_{j}\in[0,1]
be probabilities and
\lambda_{j}\in[0,1]
be corresponding weights. Define

\Lambda=\sum_{j}\lambda_{j}\cdot\textup{Ber}(\pi_{j}),

as the sum of independent Bernoulli random variables scaled by the weights
\lambda_{j}
. Then, for any constant
C\geq\nicefrac{{1}}{{(e-1)}}
, it holds that

\mathbb{E}\left[\min(\Lambda,C)\right]\geq\frac{1}{168}\cdot\min\left(\mathbb{E}[\Lambda],C\right).
