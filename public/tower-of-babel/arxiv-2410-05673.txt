Learning Equilibria in Adversarial Team Markov Games: A Nonconvex-Hidden-Concave Min-Max Optimization Problem
Fivos Kalogiannis, Jingming Yan, Ioannis Panageas

Abstract
We study the problem of learning a Nash equilibrium (NE) in Markov games which is a cornerstone in multi-agent reinforcement learning (MARL). In particular, we focus on infinite-horizon adversarial team Markov games (ATMGs) in which agents that share a common reward function compete against a single opponent, the adversary . These games unify two-player zero-sum Markov games and Markov potential games, resulting in a setting that encompasses both collaboration and competition. Kalogiannis et al. (2023a) provided an efficient equilibrium computation algorithm for ATMGs which presumes knowledge of the reward and transition functions and has no sample complexity guarantees. We contribute a learning algorithm that utilizes MARL policy gradient methods with iteration and sample complexity that is polynomial in the approximation error ϵ \epsilon and the natural parameters of the ATMG, resolving the main caveats of the solution by ( Kalogiannis et al., 2023a ) . It is worth noting that previously, the existence of learning algorithms for NE was known for Markov two-player zero-sum and potential games but not for ATMGs. Seen through the lens of min-max optimization, computing a NE in these games consists a nonconvex–nonconcave saddle-point problem. Min-max optimization has received extensive study. Nevertheless, the case of nonconvex-nonconcave landscapes remains elusive: in full generality, finding saddle-points is computationally intractable ( Daskalakis et al., 2021 ) . We circumvent the aforementioned intractability by developing techniques that exploit the hidden structure of the objective function via a nonconvex–concave reformulation. However, this introduces the challenge of a feasibility set with coupled constraints. We tackle these challenges by establishing novel techniques for optimizing weakly-smooth nonconvex functions, extending the framework of ( Devolder et al., 2014 ) .

Multi-agent reinforcement learning (MARL) investigates behaviors of multiple interacting agents within a dynamic, shared environment where the actions of each agent not only impact their individual rewards but also the overall state of the system. MARL has introduced several practical techniques that have justifiably captured public interest in recent years, particularly in skill-intensive games like starcraft, go, chess, and poker

1.1
Our Contributions

Let us provide some context before stating our main results. An infinite-horizon adversarial team Markov game (ATMG) is characterized by a finite state-space
\mathcal{S}
,
n
team players, each equipped with a finite action-space
\mathcal{A}_{i},~i\in\{1,\dots,n\}
, and one adversary with a finite action-space
\mathcal{B}
. Each of the team players receives the same reward which is equal to minus the reward of the adversary. The adversary’s value function is defined as the discounted expected sum of their rewards, where the discount factor is
\gamma\in[0,1)
. An approximate Nash equilibrium is a product distribution over policy space such that no agent can improve their value by unilaterally deviating. We propose a learning algorithm that has both iteration and sample complexity polynomial in the parameters of the Markov Game and returns approximate Nash equilibria.

Theorem 1.1

(Informal Version of
Theorem

3.3
)
.

There is a learning algorithm (
ISPNG
) that uses bandit feedback and guarantees convergence to an
\epsilon
-approximate Nash equilibrium in adversarial team Markov games, the sample and iteration complexities of which are

\mathsf{poly}\left(\frac{1}{\epsilon},|\mathcal{S}|,\sum_{k=1}^{n}|\mathcal{A}_{i}|+|\mathcal{B}|,\frac{1}{1-\gamma}\right).

We deem noteworthy that our algorithm manages to compute a Nash equilibrium in a Markov game, which combines opposing and shared agent interests, by only using a number of iterations and samples that is polynomial in the approximation error and the description of the game. Further, it manages to beat the
curse of multi-agents

(
Jin et al., 2021
)
—
i.e.,
its iteration and sample complexity depends on
\sum_{k=1}^{n}|\mathcal{A}_{i}|
instead of
\prod_{k=1}^{n}|\mathcal{A}_{i}|
.

In order to achieve the latter contribution, we acquired convergence guarantees for stochastic projected gradient descent in nonconvex functions when the gradient is Hölder-continuous—a notion of continuity weaker than that of Lipschitz. Finally, we contribute a general result that guarantees convergence to a saddle-point in functions that are nonconvex–hidden-strongly-concave.

1.2
Technical Overview

The problem of computing an approximate Nash equilibrium in an adversarial team Markov game boils down to computing an approximate saddle-point
({\bm{x}}^{*},{\bm{y}}^{*})
of the adversary’s value function
V({\bm{x}},{\bm{y}})
; see Definition
2.3
. The variables
{\bm{x}}
denote the policies of the team, each member of which aims to individually minimize
V
. Moreover,
{\bm{y}}
denotes the policy of the adversary who aims to maximize
V
. The equivalence between saddle-points and equilibria is due to

(i)

the game being
zero-sum
between the team and the adversary and

(ii)

the
gradient domination property
(see
Lemma

C.7
) that holds per player, and has already been established in prior works
(
Agarwal et al., 2021
;
Leonardos et al., 2021
;
Zhang et al., 2021b
)
. In words, gradient domination in our setting implies that any approximate first-order stationary policy is also an approximate best response for that player.

The problem of computing an approximate saddle-point
({\bm{x}}^{*},{\bm{y}}^{*})
of the objective
V({\bm{x}},{\bm{y}})
poses computational challenges due to its nonconvex–nonconcave nature. Previous work
(
Kalogiannis et al., 2023a
)
showed that one can compute an approximate saddle-point
({\bm{x}}^{*},{\bm{y}}^{*})
of
V
, by first obtaining an approximate stationary point
{\bm{x}}^{*}
of
\Phi({\bm{x}})=\max_{{\bm{y}}}V({\bm{x}},{\bm{y}})
through a Moreau envelope argument and then extending it to
({\bm{x}}^{*},{\bm{y}}^{*})
. The proof of extendibility uses involved arguments that utilize the Lagrange multipliers of a carefully chosen nonlinear program (for the stationary point
{\bm{x}}^{*}
), while the computation of
{\bm{y}}^{*}
requires solving another linear program. It is worth noting that the aforementioned linear program presumes access to the full description of the reward function and the transition model of the underlying Markov game when the team plays policy
{\bm{x}}^{*}
. This fact prevents the possibility of casting this approach into a learning algorithm.

Our proposed (learning) algorithm bypasses the requirement for knowledge of the reward function and the transition model, and works under the bandit feedback framework. The first idea behind our algorithm is to consider the adversary’s value function as a function
F
of the
adversary’s
state-action visitation measure
\bm{\lambda}
,
F\left({\bm{x}},\bm{\lambda}\right)\coloneqq V({\bm{x}},{\bm{y}})
, and the addition of a regularizing term
-\frac{\nu}{2}\left\|\bm{\lambda}\right\|^{2}
(
\nu
can be thought of as a small positive scalar). As a result, the max function of the regularized value function,
\Phi^{\nu}({\bm{x}})\coloneqq\max_{\bm{\lambda}\in\Lambda({\bm{x}})}\left\{F\left({\bm{x}},\bm{\lambda}\right)-\frac{\nu}{2}\left\|\bm{\lambda}\right\|^{2}\right\}
, is differentiable,
where
\Lambda({\bm{x}})\subseteq\Delta^{|\mathcal{S}||\mathcal{B}|}
denotes the feasibility set of
\bm{\lambda}
and depends on
{\bm{x}}
. Effectively, different policies,
{\bm{x}}
, for the team induce a different single agent Markov decision process for the adversary. The addition of the regularizer allows us to apply Danskin’s theorem on a function with a unique maximizer circumventing the necessity of solving a linear program; one only needs to approach that unique solution. To the best of our knowledge, this is the first work introducing a function of
\bm{\lambda}
as a regularizing term.

By reformulating the regularized value function using state-action visitation measure
\bm{\lambda}
, the problem boils down to learning an approximate saddle-point of a nonconvex–strongly-concave function with
coupled constraints
. Coupled constraints are a type of constraints that cannot be expressed as a Cartesian product (the main well-studied setting in min-max optimization
(
Jin et al., 2020
)
),
i.e.
, the feasibility set
\Lambda({\bm{x}})
, depends on
{\bm{x}}
.
The first challenge towards handling the coupled constraints is to argue that
\nabla\Phi^{\nu}
is Hölder-continuous which is a notion of continuity weaker than Lipschitz continuity (see
Definition

2.1
). Specifically, in
Theorem

3.2
, we show that
\Phi^{\nu}({\bm{x}})
is weakly-smooth, or equivalently,
\nabla\Phi^{\nu}
is Hölder-continuous. It seems unlikely that we could use Moreau envelope techniques to prove convergence of stochastic projected gradient descent on a weakly-smooth function. The next step of our proof is to transfer the weakly-smooth nonconvex optimization problem into a smooth optimization problem with inexact gradient oracles, extending the techniques from
(
Devolder et al., 2014
)
to nonconvex and constrained settings. Since we only allow each player to observe the reward they received and not the action chosen by the other players (including the adversary), one last challenge we have to deal with is the inability to estimate the state-action visitation measure
\bm{\lambda}
of the adversary, making the gradient inexact when computing
\nabla\Phi^{\nu}(x)
in both deterministic and stochastic settings.

2.1
Basic Definitions and Facts

We commence this subsection by introducing a number of concepts and statements of mathematical analysis and optimization. We define Hölder continuity and the notion of a stationary point in constrained minimization and min-max optimization.

The notion of Hölder continuity of the gradient is a weaker notion of Lipschitz gradient continuity.

Definition 2.1

(
p
-Hölder continuous gradient)
.

A function
\phi:\mathbb{R}^{d}\to\mathbb{R}
is said to have a
(\ell_{p},p)
-Hölder continuous gradient if for every

\|\nabla\phi({\bm{z}})-\nabla\phi({\bm{z}}^{\prime})\|_{2}\leq\ell_{p}\|{\bm{z}}-{\bm{z}}^{\prime}\|_{2}^{p}.

(2)

When

, we retrieve the definition of an
\ell
-smooth function.

Throughout, following standard conventions, we will refer to functions for which the gradient is
p
-Hölder continuous with a

as

. We state the notions of first-order stationarity relevant to our work.

Definition 2.2

(
\epsilon
-FOSP)
.

In the context of the constrained minimization problem
\min_{{\bm{z}}\in\mathcal{Z}}\phi({\bm{z}})
, a point
{{\bm{z}}}\in\mathcal{Z}
is said to be an
\epsilon
-approximate stationary point if,

\displaystyle\left\langle-\nabla_{{\bm{z}}}\phi({{\bm{z}}}),{\bm{z}}^{\prime}-{{\bm{z}}}\right\rangle\leq\epsilon,\quad\forall{\bm{z}}^{\prime}\in\mathcal{Z}.

(3)

Similarly, we will define an
\epsilon
-approximate saddle-point for the constrained min-max optimization problem
\min_{\mathcal{X}}\max_{\mathcal{Y}}f({\bm{x}},{\bm{y}})

Definition 2.3

(
\epsilon
-SP)
.

Let a function

2.2
Adversarial Team Markov Games

An adversarial team Markov game is the Markov game extension of normal-form adversarial team games
(
Stengel and Koller, 1997
)
. The game takes place in an infinite-horizon discounted setting where a team of identically-interested players compete against one adversarial player, the
adversary
. We can formally define an adversarial team Markov game as a tuple
\Gamma(\mathcal{S},[n+1],\mathcal{A},\mathcal{B},r,\pr,\gamma,\bm{\rho})
, where:

•

\mathcal{S}
is the finite set of states, or
state-space
, with cardinality
S\coloneqq|\mathcal{S}|
;

•

[n+1]
is the set of players, with the first
n
players belonging to the team and the last one being the adversary;

•

\mathcal{A}=\bigtimes_{i=1}^{n}\mathcal{A}_{i}
is the finite set of the team’s joint actions (or, team’s
action-space
), while
\mathcal{A}_{i}
is the
i
-th player’s
action-space
; respectively
\mathcal{B}
is the adversary’s action-space; further,
A\coloneqq\max_{i\in[n]}|\mathcal{A}_{i}|
and
B\coloneqq|\mathcal{B}|
;

•

r:\mathcal{S}\times\mathcal{A}\times\mathcal{B}\to[0,1]
is the adversary’s reward function;

•

\pr:\mathcal{S}\times\mathcal{A}\times\mathcal{B}\to\Delta(\mathcal{S})
is transition probability function;

•

\gamma\in[0,1)
is the discount factor;

•

\bm{\rho}\in\Delta(\mathcal{S})
is the initial state distribution. We assume that
\bm{\rho}
is of full-support,
\rho(s)>0,~\forall s\in\mathcal{S}
.

Every team player
i\in[n]
gets the same reward and the sum of team players’ rewards are equal to the adversary’s loss,
i.e.
,
\sum_{i=1}^{n}r_{i}(s,{\bm{a}},b)=-r(s,{\bm{a}},b)
.

Policies, Value Function, and Visitation Measures

In this part, we describe policy classes, the value function, and the state-action visitation measures. All of these notions are indispensable for our analysis.

Policy Definitions.

For any agent

In the context of our work, we assume the strategy of

The

The important quantity of state-action visitation measures, or the expected discounted sum of visitations of a state-action pair.

(State-Action Visit. Measure)

3.1
Stochastic Weakly-Smooth Nonconvex Optimization with Inexact Gradients

In this subsection we prove that projected gradient descent with a stohcastic inexact gradient oracle converges to an
\epsilon
-FOSP in nonconvex functions with Hölder continuous gradients. We will use this key result in subsequent sections. We begin by defining the inexact gradient oracle and its stochastic version.

Definition 3.1

(Inexact Gradient Oracle)
.

Let a differentiable function
\phi({\bm{z}})
and its gradient
\nabla\phi({\bm{z}})
. We call the vector-valued function
{\bm{g}}({\bm{z}})
a
\vartheta
-inexact gradient oracle if,

\displaystyle\left\|{\bm{g}}({\bm{z}})-\nabla\phi({\bm{z}})\right\|\leq\vartheta,\quad\forall{\bm{z}}.

(11)

Further, given a random variable
\xi
in some sample space
\Xi
, we define a stochastic inexact gradient oracle
G:\mathcal{Z}\times\Xi\to\mathbb{R}^{d}
. We assume that the expected value of this oracle will be equal to a
\vartheta
-inexact gradient oracle
{\bm{g}}({\bm{z}})
. Additionally to being unbiased (with respect to a
\vartheta
-inexact gradient oracle), we assume its variance to be bounded.

Assumption 3.1

(Unbiased and Bounded Variance)
.

For a variance parameter
\sigma^{2}>0
, the gradient oracle
G
, satisfies

\displaystyle\mathbb{E}_{\xi}[{G}({\bm{z}},\xi)]={\bm{g}}({\bm{z}})\quad\text{and}\quad\mathbb{E}_{\xi}\left[\left\|G({\bm{z}},\xi)-{\bm{g}}({\bm{z}})\right\|^{2}\right]\leq\sigma^{2}.

(12)

Following, we consider the simple update rule of
Mini-Batch Inexact Stochastic Projected Gradient Descent
, with a batch size
M>0
and
\hat{{\bm{g}}}^{t}=\frac{1}{M}\sum_{j=1}^{M}G\left({\bm{z}}^{t},\xi^{t}_{j}\right)
,

\displaystyle{\bm{z}}^{t+1}=\mathrm{Proj}_{\mathcal{Z}}\left({\bm{z}}^{t}-\eta\hat{{\bm{g}}}^{t}\right).

(Inexact Stoch-PGD)

We can now state our convergence Theorem for (

) whose proof we defer to the appendix.

Theorem 3.1

(Convergence to
\epsilon
-FOSP; Formally in
Theorem

.

Let
\phi:\mathcal{Z}\to\mathbb{R}

(\ell_{p},p)

\epsilon

Analyzing Independent Stochastic Policy-Nested-Gradient

Algorithm

1

As we have already informally stated,

\Phi^{\nu}({\bm{x}})=\max_{\bm{\lambda}\in\Lambda({\bm{x}})}\left\{{\bm{r}}({\bm{x}})^{\top}\bm{\lambda}-\frac{\nu}{2}\left\|\bm{\lambda}\right\|^{2}\right\}

. Formally we state that:

Theorem 3.2

(Grad. Contunuity of Reg-Max Function)
.

Let function
\Phi^{\nu}({\bm{x}})
be the maximum function of the regularized value function of an ATMG, with regularization coefficient
\nu>0
. It is the case that,

(i)

\Phi^{\nu}
is differentiable,

(ii)

\nabla_{\bm{x}}\Phi^{\nu}
is
(1/2,\ell_{1/2})

\left\|\nabla_{{\bm{x}}}\Phi^{\nu}({\bm{x}})-\nabla_{{\bm{x}}}\Phi^{\nu}(\overline{{\bm{x}}})\right\|\leq\ell_{1/2}\left\|{\bm{x}}-{\bm{x}}^{\prime}\right\|^{\frac{1}{2}}

with

manages to run gradient descent on function

though the agents can never observe the exact gradient of

. This is not only due to the randomness of gradient estimators but mainly because they cannot observe the adversary’s actions and thus do not know the gradient w.r.t the regularizing term. Fortunately, the regularization coefficient plays a second role in bounding the inexactness error of the gradient estimates. For that reason, parameter
\nu
admits a careful tuning.

Finally, the differentiability of
\Phi^{\nu}
and the per-player gradient domination property of the

Given a desired accuracy

Minimax in Nonconvex–Hidden-Strongly-Concave Functions

Finally, we would state a more general result compared to that of
Theorem

3.3
. We consider the general min-max nonconvex–nonconcave optimization problem,
\min_{{\bm{x}}\in\mathcal{X}}\max_{{\bm{y}}\in\mathcal{Y}}f({\bm{x}},{\bm{y}}),

when an additional structural assumption holds,
i.e.,
when
f
is nonconvex–hidden-strongly-concave. In particular, function
f
admits a reformulation of the form,

\displaystyle H({\bm{x}},{\bm{u}})\coloneqq f\left({\bm{x}},c^{-1}({\bm{u}};{\bm{x}})\right),

(16)

where function
H
is a nonconvex–strongly-concave function defined on
\mathcal{X}\times\mathcal{U}
. The sets
\mathcal{X}
and
\mathcal{U}
are closed and convex, while
c(\cdot;{\bm{x}}):\mathcal{Y}\to\mathcal{U}
is an invertible mapping parametrized by
{\bm{x}}
.
Moreover, we will denote
\mathcal{U}({\bm{x}})\coloneqq\{{\bm{u}}|{\bm{u}}=c({\bm{y}};{\bm{x}}),~\forall{\bm{y}}\in\mathcal{Y}\}
.
We further assume that the mapping
c
and its inverse are Lipschitz-continuous. Specifically,

Assumption 4.1
.

For the mapping
c
and its inverse,
c^{-1}
, it holds that

\displaystyle\begin{array}[]{rcll}\left\|c({\bm{y}};{\bm{x}})-c({\bm{y}}^{\prime};{\bm{x}}^{\prime})\right\|&\leq&L_{c}(\left\|{\bm{x}}-{\bm{x}}^{\prime}\right\|+\left\|{\bm{y}}-{\bm{y}}^{\prime}\right\|),&\forall{\bm{x}},{\bm{x}}^{\prime}\in\mathcal{X};{\bm{y}},{\bm{y}}^{\prime}\in\mathcal{Y}\\
\left\|c^{-1}({\bm{u}};{\bm{x}})-c^{-1}({\bm{u}}^{\prime};{\bm{x}}^{\prime})\right\|&\leq&L_{c^{-1}}(\left\|{\bm{x}}-{\bm{x}}^{\prime}\right\|+\left\|{\bm{u}}-{\bm{u}}^{\prime}\right\|),&\forall{\bm{x}},{\bm{x}}^{\prime}\in\mathcal{X};{\bm{u}},{\bm{u}}^{\prime}\in\mathcal{U}.\end{array}

If this is the case, the maximizer
{\bm{u}}^{\star}({\bm{x}})\coloneqq\argmax_{{\bm{u}}\in\mathcal{U}({\bm{x}})}H({\bm{x}},{\bm{u}})
, is Hölder continuous w.r.t.
{\bm{x}}
as stated by the following Theorem.

Theorem 4.1

(Formally in
Theorem

D.2
)
.

Let function
f({\bm{x}},{\bm{y}})
be nonconvex–hidden-strongly-concave with a modulus of
\nu>0
. Let also function
H
be a
L_{H}
-Lipschitz continuous and
\ell_{H}
-smooth nonconvex–strongly-concave reformulation of

with an invertible mapping

for which

\displaystyle\left\|{\bm{u}}^{\star}({\bm{x}})-{\bm{u}}^{\star}({\bm{x}}^{\prime})\right\|\leq L_{\star}\left\|{\bm{x}}-{\bm{x}}^{\prime}\right\|^{\frac{1}{2}},\quad\forall{\bm{x}},{\bm{x}}^{\prime}\in\mathcal{X}.

(19)

5
Conclusion and Future Work

Conclusions

We expanded stochastic gradient techniques to be able to compute a stationary point in constrained optimization of nonconvex with weakly-smooth functions. We applied that result to design the first learning algorithm that computes an
\epsilon
-approximate Nash equilibrium in adversarial team Markov games using a finite number of samples and iterations that scale polynomially with
1/\epsilon
and the natural parameters of the game.

Future Work

We believe that some questions that require further investigations are the following:

(i)

Is it possible to extend the techniques of
(
Davis and Drusvyatskiy, 2019
)
to establish convergence guarantees of stochastic gradient descent on nonconvex functions with Hölder-continuous gradient without batch-sampling of the gradient?

(ii)

Can we design a two-timescale gradient descent-ascent scheme for ATMGs that converges to a Nash equilibrium with best-iterate guarantees?

(iii)

Can we utilize some variance-reduction techniques to achieve a better sample complexity for learning an
\epsilon
-NE in ATMGs?

Appendix

Appendix A
Further Related Work

We accommodate this section to mention a brief collection of related literature in the fields of team games, reinforcement learning, and optimization. The literature is vast and we can only manage to mention some representative works.

A.1
Team Games

Research on team games has been a major focus in economic and group decision theory for decades
(
Marschak, 1955
;
Groves, 1973
;
Radner, 1962
;
Ho and Chu, 1972
)
. A key modern reference is
(
Stengel and Koller, 1997
)
, which introduced the
team-maxmin equilibrium (TME)
for normal-form games, where the team’s strategy maximizes their minimal expected payoff against any adversary response. Despite their optimality, TMEs are computationally intractable even for
3
-player team games
(
Hansen et al., 2008
;
Borgs et al., 2010
)
. Recently, practical algorithms have been developed for multiplayer games
(
Zhang and An, 2020b
;
Zhang and An, 2020a
;
Basilico et al., 2017
)
. Team equilibria are also relevant to two-player zero-sum games with imperfect recall
(
Piccione and Rubinstein, 1997
)
.

Due to TME’s intractability,
TMECor
, a relaxed equilibrium concept involving a
correlation device
, has been studied
(
Farina et al., 2018
;
Celli and Gatti, 2018
;
Basilico et al., 2017
;
Zhang and An, 2020b
;
Zhang and Sandholm, 2021
;
Zhang et al., 2022
;
Carminati et al., 2022
)
. TMECor permits correlated strategies but can be impractical in certain scenarios
(
Stengel and Koller, 1997
)
. TMECor is also
\mathsf{NP}
-hard for
imperfect-information
extensive-form games (EFGs)
(
Chu and Halpern, 2001
)
, although fixed-parameter-tractable (
\mathsf{FPT}
) algorithms have been developed for specific EFG classes
(
Zhang and Sandholm, 2021
;
Zhang et al., 2022
)
.

The computational aspects of standard Nash equilibrium (NE) in adversarial team games are not well-understood, even in normal-form games. Von Neumann’s
minimax theorem

(
von Neumann and Morgenstern, 2007
)
does not apply to team games, rendering traditional methods ineffective.
(
Schulman and Vazirani, 2017
)
characterized the
duality gap
between teams, while in
(
Kalogiannis et al., 2023b
)
it was shown that standard no-regret learning dynamics, such as gradient descent and optimistic Hedge, may fail to converge to mixed NE in binary-action adversarial team games.

A.2
Reinforcement Learning

Multiagent RL

Nash equilibrium computation has been central in multiagent RL. Notable algorithms, such as Nash-Q
(
Hu and Wellman, 1998
;
Hu and Wellman, 2003
)
, guarantee convergence to Nash equilibria only under strict game conditions. The behavior of independent policy gradient methods
(
Schulman et al., 2015
)
remains poorly understood. The impossibility result by the authors of
(
Hart and Mas-Colell, 2003
)
precludes universal convergence to Nash equilibria even in normal-form games, aligning with the computational intractability (
\mathsf{PPAD}
-completeness) of Nash equilibria in two-player general-sum games
(
Daskalakis et al., 2009
;
Chen et al., 2009
)
. Surprisingly, recent work shows similar hardness in turn-based stochastic games, making (stationary) CCEs intractable
(
Daskalakis et al., 2022
;
Jin et al., 2022
)
.

Thus, research has focused on specific game classes, like Markov potential games
(
Leonardos et al., 2021
;
Ding et al., 2022
;
Zhang et al., 2021b
;
Chen et al., 2022
;
Maheshwari et al., 2022
;
Fox et al., 2022
)
or two-player zero-sum Markov games
(
Daskalakis et al., 2020
;
Wei et al., 2021
;
Sayin et al., 2021
;
Cen et al., 2021
;
Sayin et al., 2020
)
. As noted, adversarial Markov team games can unify and extend these settings. Identifying multi-agent settings where Nash equilibria are efficiently computable is a key open problem (see,
e.g.
,
(
Daskalakis et al., 2020
)
). Recent guarantees for convergence to Nash equilibria have been found in symmetric games, including symmetric team games
(
Emmons et al., 2022
)
. Additionally, weaker solution concepts, relaxing either Markovian or stationarity properties, have gained attention
(
Daskalakis et al., 2022
;
Jin et al., 2021
)
.

Convex RL

Maximizing a value function regularized by a term that is strongly-concave with respect to the state-action visitation measure is an instance of a convex RL problem. In that sense, our work is also related to that strain of literature. Convex RL
(
Zahavy et al., 2021
;
Zhang et al., 2020
)
is a framework that generalizes standard MDP problems by considering the optimization of an objective function that is convex (or concave) in the state (or state-action) visitation measures that the agent’s policies induce. The value function of standard RL has an objective function linear to that measure. Common well-known problems that are unified below the lens of convex are

(i)

“pure-exploration” RL
(
Hazan et al., 2019
)
, where the agent maximizes the entropy of the state visitation measure,

(ii)

imitation learning
(
Abbeel and Ng, 2004
)
, where an agent minimizes the distance of the state visitation measure their policy induces and the one induced by an expert,

(iii)

risk-averse RL
(
Garcıa and Fernández, 2015
)
where the agent optimizes an objective function that is sensitive to the tail behavior of the agent and not merely their expected behavior
(
Tamar and Mannor, 2013
;
Tamar et al., 2015
;
Chow et al., 2015
;
Bisi et al., 2019
;
Zhang et al., 2021c
;
Mutti et al., 2022
)
,

(iv)

constrained RL
(
Altman, 2021
)
, where an agent optimizes their value function while making sure to satisfy a number of constraints that are dependent on their state-action visitation measure

(
Bai et al., 2022
;
Yu et al., 2021
;
Brantley et al., 2020
;
Achiam et al., 2017
)
,

(v)

diverse skills discovery, where the goal is to drive learning agents to acquire a diverse set of emergent skills
(
Campos et al., 2020
;
Eysenbach et al., 2018
;
Gregor et al., 2016
;
Hansen et al., 2019
;
He et al., 2022
;
Liu and Abbeel, 2021
;
Sharma et al., 2019
;
Zahavy et al., 2022
)
.

A.3
Optimization

Min-max Optimization

Min-max optimization studies problems of the form
\min_{{\bm{x}}\in\mathcal{X}}\max_{{\bm{y}}\in\mathcal{Y}}f({\bm{x}},{\bm{y}})
. When the objective function
f
is convex in
{\bm{x}}
and concave in
{\bm{y}}
, the corresponding variational inequality (VI) is monotone, and a wide range of algorithms have been proposed for computing an approximate saddle-point — see,
e.g.
,
(
Nemirovski, 2004
;
Lin et al., 2014
)
.

It is also known that standard Gradient Descent/Ascent (GDA) exhibits time-averaged convergence while the actual trajectory of iterates might cycle
(
Daskalakis et al., 2018
;
Daskalakis and Panageas, 2018
)
. Methods like Extra Gradient or techniques such as optimism are used to ensure convergence
(
Daskalakis et al., 2018
;
Daskalakis and Panageas, 2018
;
Daskalakis and Panageas, 2019
;
Mertikopoulos et al., 2019
;
Mokhtari et al., 2020
;
Cai et al., 2022
;
Gorbunov et al., 2022
)
.

For more general objectives, we know how to compute approximate saddle-points when the weak Minty Property is satisfied
(
Diakonikolas et al., 2021
)
and for functions where one (or both) side satisfies the PŁcondition
(
Nouiehed et al., 2019
;
Fiez et al., 2021
;
Yang et al., 2020
)
. On the negative side, we know that the problem in its full generality (nonconvex–nonconcave landscape with coupled linear constraints) is computationally intractable
(
Daskalakis et al., 2021
)
.

Hidden-Convex Optimization

This nascent field of optimization
(
Fatkhullin et al., 2023
;
Ghai et al., 2022

Appendix B
Nonconvex Weakly-Smooth Constrained Optimization

In this section we prove that stochastic projected gradient descent with an stochastic inexact oracle converges to an
\epsilon
-FOSP in functions with Hölder continuous gradient. We complement this section with the proof of folklore lemmas of constrained optimization that show that the “gradient mapping” (
Definition

B.1
) is an appropriate surrogate of stationarity also for the family of functions we consider.

Definition B.1

(Gradient Mapping)
.

We define the gradient mapping and stochastic gradient mapping,
{\bm{r}}_{\eta}
and
\hat{{\bm{r}}}_{\eta},
to be:

•

{\bm{r}}_{\eta}({\bm{z}})\coloneqq\frac{1}{\eta}\left({\bm{z}}-\mathrm{Proj}_{\mathcal{Z}}\left({\bm{z}}-\eta{\bm{g}}\left({\bm{z}}\right)\right)\right)
, with a shorthand notation,
{\bm{r}}_{\eta}^{t}\coloneqq{\bm{r}}_{\eta}({\bm{z}}^{)}
;

•

\hat{{\bm{r}}}_{\eta}({\bm{z}})\coloneqq\frac{1}{\eta}\left({\bm{z}}-\mathrm{Proj}_{\mathcal{Z}}\left({\bm{z}}-\eta\hat{{\bm{g}}}({\bm{z}})\right)\right)
, similarly,
\hat{{\bm{r}}}_{\eta}^{t}\coloneqq\hat{{\bm{r}}}_{\eta}({\bm{z}}^{)}
.

B.1
Auxiliary Lemmas

In general, demonstrating that the gradient mapping is an adequate surrogate of stationarity in differentiable constraint optimization relies on the Lipschitz continuity of the function. We make sure that this is the case when the gradient is only Hölder continuous with
p<1
.

Lemma B.1

(Inexact-Gradient Mapping as a Stationarity Surrogate)
.

If
\left\|{\bm{r}}_{\eta}({\bm{z}})\right\|\leq\epsilon
for some
{\bm{z}}\in\mathcal{Z}
, it holds that:

\displaystyle\max_{{\bm{z}}^{\prime}\in\mathcal{Z},\left\|{\bm{z}}^{\prime}-{\bm{z}}^{+}\right\|\leq 1}\left\langle-\nabla\phi({\bm{z}}^{+}),{\bm{z}}^{\prime}-{\bm{z}}^{+}\right\rangle\leq\vartheta+\eta^{2}\epsilon+\ell_{p}\eta^{p}\epsilon^{p},

(20)

where
{\bm{z}}^{+}\coloneqq\mathrm{Proj}_{\mathcal{Z}}\left({\bm{z}}-\eta{\bm{g}}({\bm{z}})\right)
.

Proof.

In (
Inexact Stoch-PGD
),
\left\|{\bm{g}}({\bm{z}})-\nabla\phi({\bm{z}})\right\|\leq\vartheta,~\forall{\bm{z}}\in\mathcal{Z}
. Since
{\bm{z}}^{+}\coloneqq\mathrm{Proj}_{\mathcal{Z}}\left({\bm{z}}-\eta{\bm{g}}({\bm{z}})\right)
, it holds that

\displaystyle{\bm{z}}^{+}=\argmin_{{\bm{z}}^{\prime}\in\mathcal{Z}}\left\{\left\|{\bm{z}}^{\prime}-\left({\bm{z}}-\eta{\bm{g}}({\bm{z}})\right)\right\|^{2}\right\}.

(21)

Due to the optimality condition, we have

\displaystyle-\left({\bm{z}}^{+}-{\bm{z}}+\frac{1}{\eta}{\bm{g}}({\bm{z}})\right)\in N_{\mathcal{Z}}({\bm{z}}^{+}),

(22)

where
N_{\mathcal{Z}}({\bm{z}})
is the normal cone of
\mathcal{Z}
at
{\bm{z}}
,
N_{\mathcal{Z}}({\bm{z}})\coloneqq\{{\bm{v}}|\left\langle{\bm{v}},{\bm{z}}^{\prime}-{\bm{z}}\right\rangle\leq 0,\forall{\bm{z}}^{\prime}\in\mathcal{Z}\}
. From the latter, we can conclude that

\displaystyle-\left({\bm{z}}^{+}-{\bm{z}}+\frac{1}{\eta}\nabla\phi({\bm{z}})\right)-\frac{1}{\eta}\left(-\nabla\phi({\bm{z}})+{\bm{g}}({\bm{z}})\right)\in N_{\mathcal{Z}}({\bm{z}}^{+})

(23)

\displaystyle-\left({\bm{z}}^{+}-{\bm{z}}+\frac{1}{\eta}\nabla\phi({\bm{z}})\right)\in N_{\mathcal{Z}}({\bm{z}}^{+})+B\left(\frac{\vartheta}{\eta}\right)

(24)

\displaystyle-\frac{1}{\eta}\nabla\phi({\bm{z}}^{+})-\left({\bm{z}}^{+}-{\bm{z}}+\frac{1}{\eta}\nabla\phi({\bm{z}})-\frac{1}{\eta}\nabla\phi({\bm{z}}^{+})\right)\in N_{\mathcal{Z}}({\bm{z}}^{+})+B\left(\frac{\vartheta}{\eta}\right).

(25)

Now, we bound
\left\|{\bm{z}}^{+}-{\bm{z}}+\frac{1}{\eta}\nabla\phi({\bm{z}})-\frac{1}{\eta}\nabla\phi({\bm{z}}^{+})\right\|
,

\displaystyle\left\|{\bm{z}}^{+}-{\bm{z}}+\frac{1}{\eta}\nabla\phi({\bm{z}})-\frac{1}{\eta}\nabla\phi({\bm{z}}^{+})\right\|

\displaystyle\leq\left\|{\bm{z}}^{+}-{\bm{z}}\right\|+\frac{1}{\eta}\left\|\nabla\phi({\bm{z}})-\nabla\phi({{\bm{z}}^{+}})\right\|

(26)

\displaystyle\leq\left\|{\bm{z}}^{+}-{\bm{z}}\right\|+\frac{\ell_{p}}{\eta}\left\|{\bm{z}}^{+}-{\bm{z}}\right\|^{p}

(27)

\displaystyle\leq\eta\epsilon+\frac{\ell_{p}}{\eta^{1-p}}\epsilon^{p}.

(28)

Therefore we have

\displaystyle-\nabla\phi({\bm{z}}^{+})\in N_{\mathcal{Z}}({\bm{z}}^{+})+B\left(\vartheta+\eta^{2}\epsilon+\ell_{p}\eta^{p}\epsilon^{p}\right).

(29)

The latter display implies the statement of the lemma.
∎

We immediately have the following corollary,

Corollary B.1
.

For any
{\bm{z}}\in\mathcal{Z},
denote
{\bm{z}}^{+}\coloneqq\mathrm{Proj}_{\mathcal{Z}}\left({\bm{z}}-\eta{\bm{g}}({\bm{z}})\right)
.
\mathbb{E}\left[\left\|{\bm{r}}_{\eta}({\bm{z}})\right\|\right]\leq\epsilon
implies that

\displaystyle\mathbb{E}\left[\max_{{\bm{z}}^{\prime}\in\mathcal{Z},\left\|{\bm{z}}^{\prime}-{\bm{z}}^{+}\right\|\leq 1}\left\langle-\nabla\phi({\bm{z}}^{+}),{\bm{z}}^{\prime}-{\bm{z}}^{+}\right\rangle\right]\leq\vartheta+\eta^{2}\epsilon+\ell_{p}\eta^{p}\epsilon^{p}.

(30)

B.2
Stochastic PGD with Inexact Gradients

The folklore proof of gradient descent for nonconvex functions relies on the Lipschitz continuity of the gradient to prove convergence to a first-order stationary point. When the gradient are not Lipschitz continuous but continuous in the weaker notion of Hölder continuity implies the following fact that we will eventually use to prove a “descent lemma”.

Fact B.1
.

Let a function
\phi:\mathcal{Z}\to\mathbb{R}
with
(p,\ell_{p})
-Hölder continuous gradient. Then, it is the case that for all
{\bm{z}},{\bm{z}}^{\prime}
,

\left|\phi({\bm{z}}^{\prime})-\phi({\bm{z}})+\left\langle\nabla f({\bm{z}}),{\bm{z}}^{\prime}-{\bm{z}}\right\rangle\right|\leq\frac{\ell_{p}}{1+p}\left\|{\bm{z}}^{\prime}-{\bm{z}}\right\|^{1+p}.

(31)

Following
(
Devolder et al., 2014
)
, we discuss functions with Hölder-continuous gradient (see
Definition

2.1
) through the framework of inexact oracle. We show that the answer
\left(\phi({\bm{z}}),\nabla\phi({\bm{z}})\right)
of an
exact oracle for a nonconvex function satisfying Hölder gradient continuity can be translated into some “inexact” information for a smooth function. Parameters
\delta,\ell^{\prime}
in
Proposition

B.1
can be treated as “inexactness” parameters and will be chosen as appropriate parameters of the exponent
p
of Hölder continuity.

Proposition B.1
.

For given
\delta
,
\ell_{p}
, and a tuning of
\ell^{\prime}\coloneqq\frac{\ell_{p}^{\frac{2}{1+p}}}{\delta^{\frac{1-p}{1+p}}}
, it holds that for any
{\bm{x}},{\bm{x}}^{\prime},

\displaystyle\frac{\ell_{p}}{1+p}\left\|{\bm{x}}-{\bm{x}}^{\prime}\right\|^{{1+p}}\leq\frac{\ell^{\prime}}{2}\left\|{\bm{x}}-{\bm{x}}^{\prime}\right\|^{2}+\delta.

(32)

Proof.

We let
\chi\coloneqq\left\|{\bm{x}}-{\bm{x}}^{\prime}\right\|
. By choosing the optimal
\ell^{\prime}
we can verify that

\displaystyle 2\max_{\chi\geq 0}\left\{\frac{\ell_{p}}{1+p}\chi^{-1+p}-\delta\chi^{-2}\right\}

\displaystyle=\ell_{p}\left(\frac{\ell_{p}}{2\delta}\cdot\frac{1-p}{1+p}\right)^{\frac{1-p}{1+p}}\leq\frac{\ell_{p}^{\frac{2}{1+p}}}{\delta^{\frac{1-p}{1+p}}}.

(33)

Where in the inequality we use the fact that
\left(\frac{1-p}{2(1+p)}\right)^{\frac{1-p}{1+p}}\leq 1
for
0\leq p\leq 1
. Setting
\ell^{\prime}=\frac{\ell_{p}^{\frac{2}{1+p}}}{\delta^{\frac{1-p}{1+p}}}
yields the desired inequality.
∎

Now, we can use
Proposition

B.1
as in place of the “descent-lemma” to
Theorem

C.3
to prove convergence to an
\epsilon
-FOSP.

Theorem B.1
.

Let
\phi:\mathcal{Z}\to\mathbb{R}
be a
(p,\ell_{p})
-weakly smooth nonconvex function. Further, assume a stochastic inexact gradient oracle
\hat{{\bm{g}}}
. I.e., it holds that
\mathbb{E}\left[\hat{{\bm{g}}}({\bm{z}})-{\bm{g}}({\bm{z}})\right]=0
and

\displaystyle\frac{1}{T}\sum_{t=0}^{T-1}\mathbb{E}\left[\left\|\hat{{\bm{r}}}_{\eta}^{t}\right\|^{2}\right]\leq\frac{8\ell_{p}^{\frac{2}{1+p}}\left(\mathbb{E}\left[\phi\left({\bm{z}}^{0}\right)\right]-{\phi}^{*}\right)}{\delta^{\frac{1-p}{1+p}}T}+\frac{8\sigma^{2}}{M}+8\ell_{p}^{\frac{2}{1+p}}\delta^{\frac{2p}{1+p}}+4\vartheta^{2}.

(34)

We postpone the proof to state a corollary that might help the reader gain some intuition on how the iteration complexity scales with

Corollary B.2

Let
\phi

\hat{{\bm{g}}}
, the update rule of (

\displaystyle\frac{1}{T}\sum_{t=0}^{T-1}\mathbb{E}\left[\left\|\hat{{\bm{r}}}_{\eta}^{t}\right\|^{2}\right]

\displaystyle\leq\frac{8\ell^{\prime}\left(\mathbb{E}\left[\phi\left({\bm{z}}^{0}\right)\right]-{\phi}^{*}\right)}{T}+\frac{8\sigma^{2}}{M}+8\ell^{\prime}\delta+4\vartheta^{2}

(72)

\displaystyle=\frac{8\ell_{p}^{\frac{2}{1+p}}\left(\mathbb{E}\left[\phi\left({\bm{z}}^{0}\right)\right]-{\phi}^{*}\right)}{\delta^{\frac{1-p}{1+p}}T}+\frac{8\sigma^{2}}{M}+8\ell_{p}^{\frac{2}{1+p}}\delta^{\frac{2p}{1+p}}+4\vartheta^{2}.

(73)

This completes the proof.

C.1
Further Background on Markov Decision Processes

We need additional preliminaries on Markov decision processes (MDPs). Specifically, we will discuss the properties of the
(discounted) state and state-action visitation measure
. These measures represent the “discounted” expected amount of time the Markov chain—induced by the players’ fixed policies—spends at state
s
(respectively, at a state action pair
(s,b)
) starting from initial state
s^{\prime}
. Each visit is weighted by a discount factor
\gamma^{h}
, where
h
is the visit time. Notably, in
(
Agarwal et al., 2021
)
it is defined as a probability measure, meaning that for an initial state distribution
\bm{\rho}
, the discounted state visitation distribution sums to 1. For convenience, we will use the unnormalized definition from
(
Puterman, 2014
, Chapter 6.10)
, which sums to
\frac{1}{1-\gamma}
. This is why we refer to it as a
measure
instead of a
distribution
.

Definition C.1

(State Visit. Measure)
.

Given an initial state distribution
\bm{\rho}\in\Delta(\mathcal{S})
and a stationary joint policy
\bm{\pi}\in\Pi
, we define the state visitation frequency
d_{\overline{s}}^{\bm{\pi}}
as follows:

d^{\bm{\pi}}_{\overline{s}}(s)=\sum_{h=0}^{\infty}\gamma^{h}\pr(s_{h}=s|\bm{\pi},s_{0}=\overline{s}).

(74)

Additionally, expanding the definition, we define
d^{\bm{\pi}}_{\bm{\rho}}(s)=\mathbb{E}_{\overline{s}\sim\bm{\rho}}\left[d^{\bm{\pi}}_{\overline{s}}(s)\right].

For convenience, the expression
d^{{\bm{x}},{\bm{y}}}_{\bm{\rho}}(s)
is utilized to represent the state visitation measure resulting from the policies
({\bm{x}},{\bm{y}})\in\mathcal{X}\times\mathcal{Y}
.

Fact C.1
.

Let MDP,
\mathcal{M}(\mathcal{S},\mathcal{B},\pr,r,\gamma)
. Let a policy
\bm{\pi}\in\Delta(\mathcal{B})^{|\mathcal{S}|}
. For the corresponding state-action visitation measure
\bm{\lambda}\in\mathbb{R}^{S\times B}
and the state visitation measure
{\bm{d}}_{\bm{\rho}}^{\bm{\pi}}\in\mathbb{R}^{S}
, it holds that,

\lambda_{s,b}(\bm{\pi})=d^{\bm{\pi}}_{\bm{\rho}}(s)\pi(s,b),\quad\forall s\in\mathcal{S},\forall b\in\mathcal{B}.

(75)

A quantity that is important in contemporary RL literature is that of the mismatch coefficient which we formally define here.

Definition C.2

(Distribution Mismatch Coefficient)
.

Let
\bm{\rho}\in\Delta(\mathcal{S})
be a full-support distribution over states, and
\Pi
be the joint set of policies. We define the distribution mismatch coefficient
D
as

D_{\mathrm{m}}\coloneqq\sup_{\bm{\pi}\in\Pi}\left\|\frac{{\bm{d}}^{\bm{\pi}}_{\bm{\rho}}}{\bm{\rho}}\right\|_{\infty},

(76)

where
\frac{{\bm{d}}^{\bm{\pi}}_{\bm{\rho}}}{\bm{\rho}}
denotes element-wise division.

The following theorem that relates policies and visitation measures is essential to our analysis.

Theorem C.1

(
(
Puterman, 2014
, Theorem 6.9.1)
)
.

Consider an adversarial Markov game
\Gamma
and a fixed team policy
{\bm{x}}
,

(i)

Any
\bm{y}\in\mathcal{Y}
defines a feasible state-action visitation measure
\bm{\lambda}\in\mathbb{R}^{|\mathcal{S}|\times|\mathcal{B}|}
; namely,

\lambda_{s,b}({\bm{y}};{\bm{x}})\coloneqq\sum_{\overline{s}\in\mathcal{S}}\rho(\overline{s})\cdot\mathbb{E}_{\bm{y}}\left[\gamma^{t}\pr(s^{(t)}=s,b^{(t)}=b~|~\bm{x},s^{(0)}=\overline{s})\right].

(77)

(ii)

Any feasible state-action visitation measure
\bm{\lambda}
defines a feasible
\bm{y}\in\mathcal{Y}
; namely,

y_{s,b}\coloneqq\frac{\lambda(s,b)}{\sum_{b^{\prime}\in\mathcal{B}}\lambda(s,b^{\prime})},~\forall(s,b)\in\mathcal{S}\times\mathcal{B}.

(78)

Further, for any such
\bm{y}\in\mathcal{Y}
it holds that
\lambda_{s,b}({\bm{y}};{\bm{x}})=\lambda(s,b),~\forall(s,b)\in\mathcal{S}\times\mathcal{B}
, where
\bm{\lambda}({\bm{y}};{\bm{x}})
is the induced discounted state-action measure.

An implication of the latter theorem is the fact that
\bm{\lambda}(\cdot;{\bm{x}})
is a “1–1” mapping between policies and visitation measures. Following, we see that this mapping is also Lipschitz-continuous and smooth (see
Lemmas

C.1
,
C.2
and
C.3
).

.

For any initial distribution
\bm{\rho}\in\Delta(\mathcal{S})

is

Proof.

The proof follows from Lemma 4.4 in

Lemma C.3
.

Consider
\lambda_{\mathrm{inv}}(\bm{\lambda}({\bm{y}};{\bm{x}})):=\frac{\lambda_{s,b}({\bm{y}};{\bm{x}})}{\sum_{b^{\prime}}\lambda_{s,b^{\prime}}({\bm{y}};{\bm{x}})}

\bm{\lambda}({\bm{y}};{\bm{x}})\in\Lambda({\bm{x}})

-Lipschitz continuous with respect
\bm{\lambda}

Specifically, it holds that

\displaystyle\left\|{\bm{y}}-{\bm{y}}^{\prime}\right\|\leq L_{\lambda_{\mathrm{inv}}}\left\|\bm{\lambda}({\bm{y}};{\bm{x}})-\bm{\lambda}({\bm{y}}^{\prime};{\bm{x}})\right\|.

(94)

Proof.

Take the partial derivative of
\lambda_{\mathrm{inv}}(\bm{\lambda}),
we have

\displaystyle\left|\frac{\partial}{\partial\lambda_{s,b}}\frac{\lambda_{s,b}}{\sum_{b^{\prime}}\lambda_{s,b^{\prime}}}\right|

\displaystyle=\left|\frac{1}{\sum_{b^{\prime}}\lambda_{s,b^{\prime}}}-\frac{\lambda_{s,b}}{(\sum_{b^{\prime}}\lambda_{s,b^{\prime}})}\right|

(95)

(96)

(98)

This implies the Lipschitz continuity.

The Regularized Value Function.

Lemma C.4
.

Function
V_{\bm{\rho}}^{\nu}({\bm{x}},{\bm{y}})\coloneqq V_{\bm{\rho}}^{\nu}({\bm{x}},{\bm{y}})-\frac{\nu}{2}\left\|\bm{\lambda}\left({\bm{y}};{\bm{x}}\right)\right\|^{2}

\displaystyle\left|V^{\nu}_{\bm{\rho}}({\bm{x}},{\bm{y}})-V^{\nu}_{\bm{\rho}}({\bm{x}}^{\prime},{\bm{y}}^{\prime})\right|

(99)

\displaystyle\leq\left|V_{\bm{\rho}}({\bm{x}},{\bm{y}})-V_{\bm{\rho}}({\bm{x}}^{\prime},{\bm{y}}^{\prime})\right|+\frac{\nu}{2}\max_{{\bm{x}},{\bm{y}}}\left\|\bm{\lambda}\left({\bm{y}};{\bm{x}}\right)\right\|\cdot\Big|\left\|\bm{\lambda}\left({\bm{y}};{\bm{x}}\right)\right\|-\left\|\bm{\lambda}\left({\bm{y}}^{\prime};{\bm{x}}^{\prime}\right)\right\|\Big|

(100)

(101)

\displaystyle\leq\left(L+\frac{\nu L_{\lambda}}{2(1-\gamma)}\right)\cdot\left(\left\|{\bm{x}}-{\bm{x}}^{\prime}\right\|+\left\|{\bm{y}}-{\bm{y}}^{\prime}\right\|\right).

(102)

\bm{\lambda}({\bm{y}};{\bm{x}})
w.r.t to
({\bm{x}},{\bm{y}})

\displaystyle\left\|\nabla_{{\bm{x}}}\left\|\bm{\lambda}\left({\bm{y}};{\bm{x}}\right)\right\|^{2}-\nabla_{{\bm{x}}}\left\|\bm{\lambda}\left({\bm{y}}^{\prime};{\bm{x}}^{\prime}\right)\right\|^{2}\right\|

(104)

(105)

\displaystyle\leq\left\|\bm{\lambda}\left({\bm{y}};{\bm{x}}\right)\right\|\left\|\mathbf{J}_{\bm{\lambda}}({\bm{x}},{\bm{y}})-\mathbf{J}_{\bm{\lambda}}({\bm{x}}^{\prime},{\bm{y}}^{\prime})\right\|+\left\|\bm{\lambda}\left({\bm{y}};{\bm{x}}\right)-\bm{\lambda}\left({\bm{y}}^{\prime};{\bm{x}}^{\prime}\right)\right\|\left\|\mathbf{J}_{\bm{\lambda}}({\bm{x}}^{\prime},{\bm{y}}^{\prime})\right\|

(106)

(107)

\displaystyle\leq\left(\frac{\ell_{\lambda}}{1-\gamma}+L_{\lambda}\cdot L_{\lambda}\right)\cdot(\left\|{\bm{x}}-{\bm{x}}^{\prime}\right\|+\left\|{\bm{y}}-{\bm{y}}^{\prime}\right\|).

(109)

\displaystyle\leq\left\|\nabla V_{\bm{\rho}}({\bm{x}},{\bm{y}})-\nabla V_{\bm{\rho}}({\bm{x}}^{\prime},{\bm{y}}^{\prime})\right\|+\frac{\nu}{2}\left\|\nabla_{{\bm{x}}}\left\|\bm{\lambda}\left({\bm{y}};{\bm{x}}\right)\right\|^{2}-\nabla_{{\bm{x}}}\left\|\bm{\lambda}\left({\bm{y}}^{\prime};{\bm{x}}^{\prime}\right)\right\|^{2}\right\|

(110)

Lemma C.5
.

Let
{\bm{r}}({\bm{x}})
be the reward function for the adversary when the team is playing policy

Then it holds that

\left\|{\bm{r}}({\bm{x}})-{\bm{r}}({\bm{x}}^{\prime})\right\|\leq L_{r}\left\|{\bm{x}}-{\bm{x}}^{\prime}\right\|,

where
L_{r}=\sqrt{S}\left(\sum_{i=1}^{n}|\mathcal{A}_{i}|+B\right).

Proof.

\displaystyle\|{\bm{r}}({\bm{x}})-{\bm{r}}({\bm{x}}^{\prime})\|

\displaystyle\leq\sqrt{|\mathcal{S}||\mathcal{B}|}\|r({\bm{x}})-r({\bm{x}}^{\prime})\|_{\infty}

(112)

\displaystyle=\sqrt{|\mathcal{S}||\mathcal{B}|}\max_{s,b}|r(s,{\bm{x}},b)-r(s,{\bm{x}}^{\prime},b)|

(113)

\displaystyle=\sqrt{|\mathcal{S}||\mathcal{B}|\sum_{i=1}|\mathcal{A}_{i}|}\|{\bm{x}}-{\bm{x}}^{\prime}\|

(114)

\displaystyle\leq\sqrt{|\mathcal{S}|}\left(\sum_{i=1}^{n}|\mathcal{A}_{i}|+B\right)\|{\bm{x}}-{\bm{x}}^{\prime}\|.

(115)

Where (
114
) follows from Claim D.9. in
(
Kalogiannis et al., 2023a
)
.

C.2
Auxiliary Lemmas

Bounding the stationarity error on the truncated simplex.

The
\zeta
-truncated simplex,
\Delta^{m,\zeta}
is defined a the set of all probability vectors with no entry smaller than
\zeta>0
. More formally, for a given dimension
m
and a
0<\zeta\leq\frac{1}{m}
, the
\zeta
-truncated simplex is defined to be

\Delta^{m,\zeta}=\left\{{\bm{x}}~\left|x_{i}\geq\zeta,\sum_{i=1}^{m}x_{i}=1\right.\right\}.

Lemma C.6
.

(
Erez et al., 2023
, Lemma 15)

Let
\Delta^{m,\zeta}
be the
\zeta
-truncated
m
-simplex. If
0\leq\zeta\leq\frac{1}{2m}
, then for all
{\bm{x}}\in\Delta^{m}
, there exists a
{\bm{x}}_{\zeta}\in\Delta^{m,\zeta}
such that
\left\|{\bm{x}}-{\bm{x}}_{\zeta}\right\|\leq 2\zeta m
.

Proposition C.1

(Stationarity on the trunc. simplex)
.

Let an
L_{f}
-Lipschitz continuous differentiable function
f:\Delta^{m}\to\mathbb{R}
. Also, let an
\epsilon
-approximate stationary point
{{\bm{x}}}_{\zeta}
when the feasibility set is the truncated simplex
\Delta^{m,\zeta}
such that

\displaystyle\left\langle-\nabla f({{\bm{x}}}_{\zeta}),{\bm{x}}_{\zeta}^{\prime}-{{\bm{x}}}_{\zeta}\right\rangle\leq\epsilon,\quad\forall{\bm{x}}_{\zeta}^{\prime}\in\Delta^{m,\zeta}.

(116)

Then,
{{\bm{x}}}_{\zeta}
is an
(\epsilon+2\zeta mL_{f})
-stationary point when the entire simplex is considered,
i.e,

\displaystyle\left\langle-\nabla f({{\bm{x}}}_{\zeta}),{\bm{x}}-{{\bm{x}}}_{\zeta}\right\rangle

\displaystyle\leq\epsilon+2\zeta mL_{f},\quad\forall{\bm{x}}\in\Delta^{m}.

(117)

Proof.

Consider
{\bm{x}}_{\zeta}^{\prime}\in\Delta^{m,\zeta}
such that
\left\|{\bm{x}}-{\bm{x}}_{\zeta}^{\prime}\right\|\leq 2\zeta m
, such point exists due to
Lemma

C.6
, we have

\displaystyle\left\langle-\nabla f({{\bm{x}}}_{\zeta}),{\bm{x}}-{{\bm{x}}}_{\zeta}\right\rangle

\displaystyle=\left\langle-\nabla f({{\bm{x}}}_{\zeta}),{\bm{x}}_{\zeta}^{\prime}-{{\bm{x}}}_{\zeta}\right\rangle+\left\langle-\nabla f({{\bm{x}}}_{\zeta}),{\bm{x}}-{{\bm{x}}}_{\zeta}^{\prime}\right\rangle

(118)

\displaystyle\leq\epsilon+2\zeta mL_{f}.

(119)

Where in the last inequality we use the fact that for all
{\bm{x}}_{\zeta}^{\prime}\in\Delta^{m,\zeta}
, we have
\left\langle-\nabla f({{\bm{x}}}_{\zeta}),{\bm{x}}_{\zeta}^{\prime}-{{\bm{x}}}_{\zeta}\right\rangle\leq\epsilon
and
\left\|\nabla f({{\bm{x}}}_{\zeta})\right\|\leq L_{f}.

∎

From stationarity to optimality.

Lemma C.7

(Gradient Domination)

Let a single-agent MDP with action-space
\mathcal{A}
and directly-parametrized policy

\displaystyle\max_{{\bm{x}}^{\star}\in{\Delta}\left(\mathcal{A}\right)^{|\mathcal{S}|}}V_{\bm{\rho}}({\bm{x}}^{\star})-V_{\bm{\rho}}({{\bm{x}}})\leq\frac{1}{1-\gamma}D_{\mathrm{m}}\max_{{\bm{x}}^{\prime}\in{{\Delta^{\zeta}}\left(\mathcal{A}\right)^{|\mathcal{S}|}}}({\bm{x}}^{\prime}-{{\bm{x}}})^{\top}\nabla_{\bm{x}}V_{\bm{\rho}}({{\bm{x}}})+\frac{2D_{\mathrm{m}}\zeta|\mathcal{S}||\mathcal{A}|L}{1-\gamma}.

(120)

Proof.

The proof follows easily from
Proposition

C.1
and the gradient domination property
(
Agarwal et al., 2021
, Lemma 4.1)
.

C.3
Continuity of the maximizers

We begin this section by firstly introducing a proposition which we will leverage in
Lemma

C.8
.

Proposition C.2
.

Consider the inequality of the form
\alpha\lambda^{2}\leq\beta\lambda\chi+\gamma\chi
where
\lambda
and
\chi
are variables and
\alpha,\beta,\gamma
are coefficients. Under the constraints that
\alpha,\beta,\gamma,\lambda,\chi\geq 0,
there is no solution of the form
\lambda\leq c\chi
for any finite constant
c\geq 0.

Proof.

Solving the quadratic inequality for
\lambda
gives:

\displaystyle 0\leq\lambda\leq\frac{\beta\chi+\sqrt{\chi(4\alpha\gamma+\beta^{2}\chi)}}{2\alpha}.

(121)

We search for a positive constant
c
such that
\lambda\leq\frac{\beta\chi+\sqrt{\chi(4\alpha\gamma+\beta^{2}\chi)}}{2\alpha}\leq c\chi,

or equivalently,

\displaystyle\frac{1}{2\alpha}\left(\beta+\sqrt{\frac{4\alpha\gamma}{\chi}+\beta^{2}}\right)\leq c.

(122)

By observing that when
\alpha,\beta,\gamma
are all positive constants and as
\chi\to 0,

c\to\infty,
we conclude that no such finite constant
c
exists.
∎

We first define the maximizer for the regularized function
{\bm{r}}({\bm{x}})^{\top}\bm{\lambda}-\frac{\nu}{2}\left\|\bm{\lambda}\right\|^{2}.
Since the function is strongly-concave w.r.t.
\bm{\lambda}
, the maximizing
\bm{\lambda}
is unique. Specifically we denote

\displaystyle\bm{\lambda}^{\star}({\bm{x}})\coloneqq\argmax_{\bm{\lambda}\in\Lambda({\bm{x}})}\left\{{\bm{r}}({\bm{x}})^{\top}\bm{\lambda}-\frac{\nu}{2}\left\|\bm{\lambda}\right\|^{2}\right\}.

(123)

Now we are ready to show an important lemma regarding to
\bm{\lambda}^{\star}({\bm{x}}).

Lemma C.8

(Continuity of the max. of reg. functions)
.

For any adversarial Markov game
\Gamma
,
\bm{\lambda}^{\star}({\bm{x}})
defined in (
123
) is
(1/2,L_{\star})
-Hölder continuous, specifically

\displaystyle\left\|\bm{\lambda}^{*}({\bm{x}}_{1})-\bm{\lambda}^{*}({\bm{x}}_{2})\right\|\leq L_{\star}\left\|{\bm{x}}_{1}-{\bm{x}}_{2}\right\|^{1/2},

(124)

where
L_{\star}\coloneqq{\frac{2(n)^{1/4}}{\nu(1-\gamma)^{3/2}}}{|\mathcal{S}|^{1/2}\left(\sum_{k=1}^{n}|\mathcal{A}_{k}|+|\mathcal{B}|\right)^{\frac{3}{4}}}
.

Proof.

Consider team policies,
{\bm{x}}_{1},{\bm{x}}_{2}
. It holds true for the unique maximizers
\bm{\lambda}^{\star}({\bm{x}}_{1}),\bm{\lambda}^{\star}({\bm{x}}_{2})
of the adversary’s regularized value function that,

\displaystyle\Big({\bm{r}}({\bm{x}}_{1})-\nu\bm{\lambda}^{\star}({\bm{x}}_{1})\Big)^{\top}(\bm{\lambda}_{1}-\bm{\lambda}^{\star}({\bm{x}}_{1}))\leq 0,~\quad\forall\bm{\lambda}_{1}\in\Lambda({\bm{x}}_{1});

(125)

\displaystyle\Big({\bm{r}}({\bm{x}}_{2})-\nu\bm{\lambda}^{\star}({\bm{x}}_{2})\Big)^{\top}(\bm{\lambda}_{2}-\bm{\lambda}^{\star}({\bm{x}}_{2}))\leq 0,~\quad\forall\bm{\lambda}_{2}\in\Lambda({\bm{x}}_{2}),

(126)

where
\Lambda({\bm{x}})
is the set of feasible state-action visitation measures of the adversary given team’s policy
{\bm{x}}
. To bound the distance between the two vectors
\bm{\lambda}^{\star}({\bm{x}}_{1}),\bm{\lambda}^{\star}({\bm{x}}_{2})
, we observe that for any measure
\overline{\bm{\lambda}}\in\Lambda({\bm{x}}_{1})\cup\Lambda({\bm{x}}_{2}),
there exist a measure
\overline{\bm{\lambda}}_{1}\in\Lambda({\bm{x}}_{1})
that shares the same adversary’s policy
{\bm{y}}
as in
\overline{\bm{\lambda}}.
It then follows from

C.2
that
\left\|\overline{\bm{\lambda}}_{1}-\overline{\bm{\lambda}}\right\|\leq L_{\lambda}\left\|{\bm{x}}_{1}-{\bm{x}}_{2}\right\|
. Therefore we have for all

\displaystyle\left({\bm{r}}({\bm{x}}_{1})-\nu\bm{\lambda}^{\star}({\bm{x}}_{1})\right)^{\top}\left(\overline{\bm{\lambda}}-\bm{\lambda}^{\star}({\bm{x}}_{1})\right)

\displaystyle=\left({\bm{r}}({\bm{x}}_{1})-\nu\bm{\lambda}^{\star}({\bm{x}}_{1})\right)^{\top}\left(\overline{\bm{\lambda}}-\overline{\bm{\lambda}}_{1}\right)

(127)

\displaystyle\quad+\left({\bm{r}}({\bm{x}}_{1})-\nu\bm{\lambda}^{\star}({\bm{x}}_{1})\right)^{\top}\left(\overline{\bm{\lambda}}_{1}-\bm{\lambda}^{\star}({\bm{x}}_{1})\right)

(128)

\displaystyle\leq L_{\lambda}\sqrt{|\mathcal{S}||\mathcal{B}|}\left(1+\frac{\nu}{1-\gamma}\right)\|{\bm{x}}_{1}-{\bm{x}}_{2}\|.

(129)

Where the last inequality follows from (
125

\left\|{\bm{r}}({\bm{x}})-\nu\bm{\lambda}^{\star}({\bm{x}})\right\|\leq\sqrt{|\mathcal{S}||\mathcal{B}|}\left(1+\frac{\nu}{1-\gamma}\right)
for any
{\bm{x}}\in\mathcal{X}
. Similarly, it also holds that for all

\displaystyle\Big({\bm{r}}({\bm{x}}_{2})-\nu\bm{\lambda}^{\star}({\bm{x}}_{2})\Big)^{\top}\left(\overline{\bm{\lambda}}-\bm{\lambda}^{\star}({\bm{x}}_{2})\right)\leq L_{\lambda}\sqrt{|\mathcal{S}||\mathcal{B}|}\left(1+\frac{\nu}{1-\gamma}\right)\|{\bm{x}}_{1}-{\bm{x}}_{2}\|.

(130)

Plugging in
\overline{\bm{\lambda}}\leftarrow\bm{\lambda}^{\star}({\bm{x}}_{2})

into (

\displaystyle\Big({\bm{r}}({\bm{x}}_{1})-\nu\bm{\lambda}^{\star}({\bm{x}}_{1})\Big)^{\top}\left(\bm{\lambda}^{\star}({\bm{x}}_{2})-\bm{\lambda}^{\star}({\bm{x}}_{1})\right)\leq L_{\lambda}\sqrt{|\mathcal{S}||\mathcal{B}|}\left(1+\frac{\nu}{1-\gamma}\right)\|{\bm{x}}_{1}-{\bm{x}}_{2}\|,

(131)

\displaystyle\Big({\bm{r}}({\bm{x}}_{2})-\nu\bm{\lambda}^{\star}({\bm{x}}_{2})\Big)^{\top}\left(\bm{\lambda}^{\star}({\bm{x}}_{1})-\bm{\lambda}^{\star}({\bm{x}}_{2})\right)\leq L_{\lambda}\sqrt{|\mathcal{S}||\mathcal{B}|}\left(1+\frac{\nu}{1-\gamma}\right)\|{\bm{x}}_{1}-{\bm{x}}_{2}\|.

(132)

Adding the two inequalities results in

\displaystyle\Big(\left({\bm{r}}({\bm{x}}_{1})-\nu\bm{\lambda}^{\star}({\bm{x}}_{1})\right)-\left({\bm{r}}({\bm{x}}_{2})-\nu\bm{\lambda}^{\star}({\bm{x}}_{2})\right)\Big)^{\top}\left(\bm{\lambda}^{\star}({\bm{x}}_{1})-\bm{\lambda}^{\star}({\bm{x}}_{2})\right)

\displaystyle\quad\leq 2L_{\lambda}\sqrt{|\mathcal{S}||\mathcal{B}|}\left(1+\frac{\nu}{1-\gamma}\right)\|{\bm{x}}_{1}-{\bm{x}}_{2}\|.

(134)

On the other hand, since

\nu

\bm{\lambda}_{1}\in\Lambda({\bm{x}}_{1}).

\displaystyle\left(\bm{\lambda}_{1}-\bm{\lambda}^{\star}({\bm{x}}_{1})\right)^{\top}\Big(\left({\bm{r}}({\bm{x}}_{1})-\nu\bm{\lambda}_{1}\right)-\left({\bm{r}}({\bm{x}}_{1})-\nu\bm{\lambda}^{\star}({\bm{x}}_{1})\right)\Big)+\nu\|\bm{\lambda}_{1}-\bm{\lambda}^{\star}({\bm{x}}_{1})\|^{2}\leq 0.

(135)

We again use the fact that for every

\displaystyle 0

\displaystyle\geq\left(\overline{\bm{\lambda}}_{1}+(\overline{\bm{\lambda}}-\overline{\bm{\lambda}})-\bm{\lambda}^{\star}({\bm{x}}_{1})\right)^{\top}\Big(\left({\bm{r}}({\bm{x}}_{1})-\nu\overline{\bm{\lambda}}_{1}+(\overline{\bm{\lambda}}-\overline{\bm{\lambda}})\right)-\left({\bm{r}}({\bm{x}}_{1})-\nu\bm{\lambda}^{\star}({\bm{x}}_{1})\right)\Big)

(136)

\displaystyle\quad+\nu\|\overline{\bm{\lambda}}_{1}+(\overline{\bm{\lambda}}-\overline{\bm{\lambda}})-\bm{\lambda}^{\star}({\bm{x}}_{1})\|^{2}

(138)

\displaystyle\quad+\nu\|\overline{\bm{\lambda}}_{1}-\overline{\bm{\lambda}}\|^{2}+\nu\|\overline{\bm{\lambda}}-\bm{\lambda}^{\star}({\bm{x}}_{1})\|^{2}+2\nu\left\langle\overline{\bm{\lambda}}_{1}-\overline{\bm{\lambda}},\overline{\bm{\lambda}}-\bm{\lambda}^{\star}({\bm{x}}_{1})\right\rangle

(140)

\displaystyle\quad+\nu\|\overline{\bm{\lambda}}_{1}-\overline{\bm{\lambda}}\|^{2}+\nu\|\overline{\bm{\lambda}}-\bm{\lambda}^{\star}({\bm{x}}_{1})\|^{2}+2\nu\left\langle\overline{\bm{\lambda}}_{1}-\overline{\bm{\lambda}},\overline{\bm{\lambda}}-\bm{\lambda}^{\star}({\bm{x}}_{1})\right\rangle

\displaystyle\quad+\left(\overline{\bm{\lambda}}_{1}-\overline{\bm{\lambda}}\right)^{\top}\Big(\left({\bm{r}}({\bm{x}}_{1})-\nu\overline{\bm{\lambda}}_{1}+(\overline{\bm{\lambda}}-\overline{\bm{\lambda}})\right)-\left({\bm{r}}({\bm{x}}_{1})-\nu\bm{\lambda}^{\star}({\bm{x}}_{1})\right)\Big).

Rearranging, we have

\displaystyle{\left(\overline{\bm{\lambda}}-\bm{\lambda}^{\star}({\bm{x}}_{1})\right)^{\top}\Big(\left({\bm{r}}({\bm{x}}_{1})-\nu\overline{\bm{\lambda}}\right)-\left({\bm{r}}({\bm{x}}_{1})-\nu\bm{\lambda}^{\star}({\bm{x}}_{1})\right)\Big)}+\nu\|\overline{\bm{\lambda}}-\bm{\lambda}^{\star}({\bm{x}}_{1})\|^{2}

(144)

Where we use the fact that

(150)

•

For

\displaystyle\Omega_{3}

Finally, by putting the bounds of

Concluding, we plug

We are now ready to show that
\Phi^{\nu}({\bm{x}})
is weakly-smooth.

Theorem C.2

(Hölder Continuous Max Value Func.)
.

Let function
\Phi^{\nu}({\bm{x}})
be the maximum function of the regularized value function,
\Phi^{\nu}({\bm{x}})\coloneqq\max_{{\bm{y}}\in\mathcal{Y}}V^{\nu}_{\bm{\rho}}({\bm{x}},{\bm{y}})
. It is the case that,

•

\Phi^{\nu}
is differentiable,

•

\nabla_{\bm{x}}\Phi^{\nu}
is
(1/2,\ell_{1/2})
-Hölder continuous, i.e,

\left\|\nabla_{{\bm{x}}}\Phi^{\nu}({\bm{x}})-\nabla_{{\bm{x}}}\Phi^{\nu}({\bm{x}}^{\prime})\right\|\leq\ell_{1/2}\left\|{\bm{x}}-{\bm{x}}^{\prime}\right\|^{1/2},

with
\ell_{1/2}\coloneqq\frac{30n^{\frac{1}{4}}|\mathcal{S}|^{\frac{5}{4}}\left(\sum_{i}|\mathcal{A}_{i}|+|\mathcal{B}|\right)^{2}}{\nu\min_{s}\rho(s)(1-\gamma)^{\frac{13}{2}}}
.

Proof.

Since
\Phi^{\nu}({\bm{x}})
has a unique maximizer
\bm{\lambda}\in\Lambda({\bm{x}}),
by applying Danskin’s Theorem
(
Bernhard and Rapaport, 1995
)
and the “
1
–
1
” correspondence between
\bm{\lambda}
and
{\bm{y}}
(
Theorem

C.1
), we have

\left\|\mathbb{E}\left[\hat{{\bm{g}}}_{{\bm{y}}}^{(t)}\right]-\nabla_{{\bm{y}}}F^{\nu}(\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}}))\right\|\leq\left(\frac{H+1}{(1-\gamma)\zeta}+\frac{\nu H+\nu+1}{(1-\gamma)^{2}\zeta}+\frac{\nu}{(1-\gamma)^{3}\zeta}\right)\cdot\gamma^{H}.

Proof.

From the definition, we have

\mathbb{E}_{\tau\sim{\bm{y}}}\left[\tilde{\bm{\lambda}}(\tau|{\bm{y}})\right]=\bm{\lambda}_{H}({{\bm{y}}};{\bm{x}}),\quad\mathbb{E}_{\tau\sim{\bm{y}}}\left[\tilde{{\bm{g}}}(\tau|{\bm{y}};{\bm{r}})\right]=\left[\nabla_{{\bm{y}}}\bm{\lambda}_{H}({{\bm{y}}};{\bm{x}})\right]^{\top}{\bm{r}}.

Therefore,

\mathbb{E}\left[\hat{\bm{\lambda}}^{(t)}\right]=\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}}),\quad\mathbb{E}\left[\hat{{\bm{g}}}_{{\bm{y}}}^{(t)}\right]=\left[\nabla_{{\bm{y}}}\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}})\right]^{\top}{\bm{r}}^{(t)}.

Then it holds that

\displaystyle\left\|\mathbb{E}\left[\hat{\bm{\lambda}}^{(t)}\right]-\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}})\right\|

\displaystyle=\left\|\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}})-\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}})\right\|

(257)

\displaystyle=\left\|\sum_{h=H}^{\infty}\gamma^{h}\cdot\pr(s_{h}=s,b_{h}=b|{\bm{y}}^{(t)},s_{0}\sim\bm{\rho})\cdot{\bm{e}}_{s_{h},b_{h}}\right\|

(258)

\displaystyle\leq\gamma^{H}\cdot\sum_{h=0}^{\infty}(\gamma^{h}\cdot 1)

(259)

\displaystyle=\frac{\gamma^{H}}{1-\gamma}.

(260)

Similarly, we have

\displaystyle\left\|\mathbb{E}\left[\hat{{\bm{g}}}_{{\bm{y}}}^{(t)}\right]-\nabla_{{\bm{y}}}F^{\nu}(\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}}))\right\|

(261)

\displaystyle=

\displaystyle\left\|\left[\nabla_{{\bm{y}}}\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}})\right]^{\top}{\bm{r}}^{(t)}-\nabla_{{\bm{y}}}F^{\nu}(\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}}))\right\|

(262)

\displaystyle=

\displaystyle\left\|\left[\nabla_{{\bm{y}}}\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}})\right]^{\top}\nabla_{\bm{\lambda}}F^{\nu}(\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}}))-\left[\nabla_{{\bm{y}}}\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}})\right]^{\top}\nabla_{\bm{\lambda}}F^{\nu}(\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}}))\right\|

(263)

\displaystyle\leq

\displaystyle\left\|\left[\nabla_{{\bm{y}}}\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}})\right]^{\top}\left(\nabla_{\bm{\lambda}}F^{\nu}(\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}}))-\nabla_{\bm{\lambda}}F(\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}}))\right)\right\|

(264)

\displaystyle\quad+\left\|\left(\left[\nabla_{{\bm{y}}}\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}})\right]^{\top}-\left[\nabla_{{\bm{y}}}\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}})\right]^{\top}\right)\nabla_{\bm{\lambda}}F^{\nu}(\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}}))\right\|.

(265)

For the first part in the above inequality, we have

\displaystyle\left\|\left[\nabla_{{\bm{y}}}\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}})\right]^{\top}\left(\nabla_{\bm{\lambda}}F^{\nu}(\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}}))-\nabla_{\bm{\lambda}}F^{\nu}(\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}}))\right)\right\|

(266)

\displaystyle=

\displaystyle\left\|\sum_{h=0}^{H-1}\gamma^{h}\cdot\left(\frac{\partial F^{\nu}(\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}}))}{\partial\lambda_{s_{h},b_{h}}}-\frac{\partial F^{\nu}(\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}}))}{\partial\lambda_{s_{h},b_{h}}}\right)\cdot\left(\sum_{h^{\prime}=0}^{h}\nabla_{{\bm{y}}}\log y^{(t)}(b_{h^{\prime}}|s_{h^{\prime}})\right)\right\|

(267)

\displaystyle\leq

\displaystyle\sum_{h=0}^{\infty}\gamma^{h}\cdot\left\|\nabla_{\bm{\lambda}}F^{\nu}(\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}}))-\nabla_{\bm{\lambda}}F^{\nu}(\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}}))\right\|_{\infty}\cdot\left\|\left(\sum_{h^{\prime}=0}^{\infty}\nabla_{{\bm{y}}}\log y^{(t)}(b_{h^{\prime}}|s_{h^{\prime}})\right)\right\|

(268)

\displaystyle\leq

\displaystyle\sum_{h=0}^{\infty}\gamma^{h}\cdot\left\|\nu\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}})-\nu\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}})\right\|_{\infty}\cdot\left\|\left(\sum_{h^{\prime}=0}^{\infty}\nabla_{{\bm{y}}}\log y^{(t)}(b_{h^{\prime}}|s_{h^{\prime}})\right)\right\|

(269)

\displaystyle\leq

\displaystyle\sum_{h=0}^{\infty}\gamma^{h}\cdot\nu\|\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}})-\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}})\|_{1}\cdot(h+1)\cdot\frac{1}{\zeta}

(270)

\displaystyle\leq

\displaystyle\frac{\nu}{(1-\gamma)^{2}\zeta}\cdot\|\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}})-\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}})\|_{1}

(271)

\displaystyle\leq

\displaystyle\frac{\nu}{(1-\gamma)^{2}\zeta}\cdot\left(\sum_{s,b}\sum_{h=H}^{\infty}\gamma^{h}\cdot\pr(s_{h}=s,b_{h}=b|{\bm{y}},s_{0}\sim\bm{\rho})\right)

(272)

\displaystyle\leq

\displaystyle\frac{\nu}{(1-\gamma)^{3}\zeta}\cdot\gamma^{H}.

(273)

For the second part in (
265
), we have

\displaystyle\left\|\left(\left[\nabla_{{\bm{y}}}\bm{\lambda}_{H}({{\bm{y}}^{(t)}};{\bm{x}})\right]^{\top}-\left[\nabla_{{\bm{y}}}\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}})\right]^{\top}\right)\nabla_{\bm{\lambda}}F^{\nu}(\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}}))\right\|

(274)

\displaystyle=

\displaystyle\left\|\mathbb{E}\left[\sum_{h=H}^{\infty}\gamma^{h}\cdot\frac{\partial F^{\nu}(\bm{\lambda}({{\bm{y}}^{(t)}};{\bm{x}}))}{\partial\lambda_{s_{h},b_{h}}}\cdot\left(\sum_{h^{\prime}=0}^{h}\nabla_{{\bm{y}}}\log y^{(t)}(b_{h^{\prime}}|s_{h^{\prime}})\right)\right]\right\|

(275)

\displaystyle\leq

\displaystyle\sum_{h=H}^{\infty}\gamma^{h}\cdot\left(1+\frac{\nu}{1-\gamma}\right)\cdot(h+1)\cdot\frac{1}{\zeta}

(276)

\displaystyle\leq

\displaystyle\left(1+\frac{\nu}{1-\gamma}\right)\cdot\left(\frac{H+1}{1-\gamma}+\frac{1}{(1-\gamma^{2})}\right)\cdot\frac{1}{\zeta}\cdot\gamma^{H}

(277)

\displaystyle=

\displaystyle\left(\frac{H+1}{(1-\gamma)\zeta}+\frac{\nu H+\nu+1}{(1-\gamma)^{2}\zeta}+\frac{\nu}{(1-\gamma)^{3}\zeta}\right)\cdot\gamma^{H}.

(278)

Combining (

), (

), and (

), we get the result.

Remark 2
.

It has been shown that when a function
f
enjoys a hidden-strongly-concave reformulation, it satisfies global the Proximal-PŁ condition (or equivalently, global KŁ condition)
(
Fatkhullin et al., 2023
;
Karimi et al., 2016
)
. While the equivalence between global KŁ condition and quadratic growth condition has been proven
(
Bolte et al., 2016
;
Drusvyatskiy and Lewis, 2018
)
when
f
is concave, to the authors’ best knowledge, this equivalence still remains unclear when
f
is nonconcave. This means that we cannot use
Nouiehed et al. (2019)
to prove the smoothness of the maximum function when the feasibility set of the maximizing variable is constrained.
