Surface code scaling on heavy‑hex superconducting quantum processors
Arian Vezvaee, Cesar Benito, Mario Morford-Oberst, Alejandro Bermudez, Daniel A. Lidar

Abstract
Demonstrating subthreshold scaling of a surface-code quantum memory on hardware whose native connectivity does not match the code remains a central challenge. We address this on IBM heavy-hex superconducting processors by co-designing the code embedding and control: a depth-minimizing SWAP-based “fold-unfold” embedding that uses bridge ancillas, together with robust, gap-aware dynamical decoupling (DD). On Heron-generation devices we perform anisotropic scaling from a uniform distance 3 3 code to anisotropic distance ( d x , d z ) = ( 3 , 5 ) (d_{x},d_{z})=(3,5) and ( 5 , 3 ) (5,3) codes. We find that increasing d z d_{z} ( d x d_{x} ) improves the protection of Z Z -basis ( X X -basis) logical states across multiple quantum error correction cycles. Even if global subthreshold code scaling for arbitrary logical initial states is not yet achieved, we argue that it is within reach with minor hardware improvements. We show that DD plays a major role: it suppresses coherent Z ​ Z ZZ crosstalk and non-Markovian dephasing that accumulate during idle gaps on heavy-hex layouts, and it eliminates spurious subthreshold claims that arise when scaled codes without DD are compared against smaller codes with DD. To quantify performance, we derive an entanglement fidelity metric that is computed directly from X X - and Z Z -basis logical-error data and provides per-cycle, SPAM-aware bounds. The entanglement fidelity metric reveals that widely used single-parameter fits used to compute suppression factors can mischaracterize or obscure code performance when their assumptions are violated; we identify the strong assumptions of stationarity, unitality, and negligible logical SPAM required for those fits to be valid and show that they do not hold for our data. Our results establish a concrete path to robust tests of subthreshold surface-code scaling under biased, non-Markovian noise by integrating QEC with optimized DD on non-native architectures.

The inaccessibility of all six cardinal logical states prevents a complete model-independent estimate of the average channel fidelity

We critically assess whether this basis-averaged suppression factor, which is furthermore based on a phenomenological one-parameter fit that assumes stationary (cycle-independent) errors, functions as a reliable and robust performance metric.
In the case of IBM QPUs, we show that this is not the case and provide a first-principles derivation of an alternative metric based on the entanglement fidelity (EF)
Nielsen 2002
that, under fairly general logical error model assumptions (clarified below), allows for a faithful and accurate characterization of our QEC experiments. We use this metric to identify a three-parameter fitting model that separates SPAM from the QEC per-cycle logical error, and use it to demonstrate a reduction in logical error probabilities as we integrate our SWAP-based embedding with robust DD while scaling to the two larger surface codes.

In all QPUs used in this work, we identify non-Markovian dephasing and coherent
ZZ
-crosstalk as the main sources of hardware errors, leading to a dominance of
Z
-type logical errors.
We demonstrate that the incorporation of robust DD in QEC circuits is essential for subthreshold performance. DD suppresses coherent errors, which are underestimated by randomized benchmarking
Tripathi et al. 2025
.
Additionally, DD suppresses incoherent non-Markovian errors occurring during the extra idle gaps of the SWAP-embedding circuits,
which are particularly biased towards single- and two-qubit dephasing.
DD suppresses these errors to a level where the surface code can correct the remaining Markovian errors, and to the point where the benefits of anisotropic surface code scaling become more important.

We also find that claiming genuine subthreshold scaling requires careful consideration of DD effects. Without DD, logical error rates can decrease with increasing code distance, apparently demonstrating subthreshold behavior. However, when DD is applied, this trend may reverse: although DD reduces errors across all code distances, it can benefit smaller codes disproportionately, eliminating the apparent scaling advantage of larger codes. This reveals the possibility of
spurious
claims of subthreshold scaling: behavior that appears subthreshold without DD but ceases to be so when DD is properly included.
Thus, our results offer insight into the interplay between QEC and error suppression, and the importance of fully optimizing the latter before a claim of subthreshold scaling is made.
The non-native heavy-hex architecture is key to unveiling these results, since native surface code implementations parallelize operations and leave no idling gaps that would lead to this subtle interplay of QEC and DD.

The findings presented here constitute a key step in the demonstration of subthreshold surface code scaling in non-native architectures, paving the way for future experiments with near-term QPUs and larger codes.

Methods

.1
Surface code on heavy-hex QPUs

The distance parameter
d
of an
[[n,k,d]]
stabilizer code can be characterized as the smallest possible weight of physical Pauli operators appearing in the logical operators
{X}_{L},{Z}_{L}

Z

;
Calderbank and Shor 1996

can support a SWAP-based embedding of exactly three odd-distance such surface code sizes:

(3,5)

(5,3)

The operation of the surface code as a quantum memory involves encoding, syndrome extraction, error decoding, and recovery operations. We next describe the syndrome extraction step, i.e., the measurement of plaquette and vertex stabilizers of the surface code.
Ref.
Benito et al. 2025
devised a SWAP-based protocol of this step on the heavy-hex lattice, which was found to be the best performing strategy compared to several other embeddings and promising native codes. Instead of using a naive CNOT-gate compilation of SWAP operations
Nielsen and Chuang 2011
, which must be applied before and after the syndrome-extraction CNOTs to transfer the state of the non-neighboring data qubits that form a specific stabilizer, the SWAP-based protocol uses a folding-unfolding scheme minimizing circuit depth.

The circuits initially follow the middle-out ancilla-free measurement scheme described in Ref.
McEwen et al. 2023
, and start by applying a first layer of CNOT gates between data qubits to fold weight-4 stabilizers into weight-2 operators. The middle-out protocol would then apply another CNOT layer to further fold these
to one-body operators, which can then be measured. Instead, in light of the heavy-hex layout, it is better to use an ancilla qubit to measure the weight-2 parity check directly. Afterwards, the weight-2 checks are unfolded back into the original weight-4 stabilizers by a sequence of CNOTs. Denoting
A
-
F
as the bulk data qubits (see
Fig.

1
), the stabilizers
Z_{A}Z_{B}Z_{C}Z_{D}
and
X_{B}X_{C}X_{E}X_{F}
are mapped to
Z_{B}Z_{C}
and
X_{E}X_{F}
during the first step, respectively. Then
Z_{B}Z_{C}
and
X_{E}X_{F}
are measured using an ancilla qubit. Finally, the original stabilizers are restored (unfolded) by using consecutive CNOTs. This step can be further optimized by executing the first two steps of the following QEC round with the last ones from the previous round (see
Fig.

1
), minimizing the overall circuit depth
Benito et al. 2025
.
We further optimize the circuits by removing reset gates, instead tracking the previous measurement outcomes in software
Gehér et al. 2025
. Removing the resets significantly shortens the duration of the syndrome extraction round, thus also reducing idling errors. As most CNOT gates that implement the SWAP operation cancel out, the result is a compact depth-
7
circuit, shown in
Fig.

1
(b).
Note that in this scheme, only half of the stabilizers can be measured in parallel, requiring two rounds to perform a full syndrome extraction cycle.

We note that Ref.
Hetényi and Wootton 2024
ran syndrome extraction circuits by effectively connecting next-nearest-neighbor qubits, which required translating each CNOT gate into a sequence of four consecutive CNOT gates. This contributes to overhead and partly explains why their surface code experiments did not achieve subthreshold behavior. The lack of optimized DD is likely another major reason. A noteworthy aspect of Ref.
Hetényi and Wootton 2024
is the interesting idea of recycling the spare qubits for an additional code, allowing for novel fault-tolerant entangling gates.

.3
Calibrated non-uniform noise model and decoding

Our experiments are decoded using Stim
Gidney 2021
and the minimum-weight perfect-matching (MWPM) decoder
Higgott and Gidney 2025
, which define the logical observable for each measurement shot resulting from the corresponding Pauli frame updates. A logical failure is recorded when this observable disagrees with the measured logical observable, as this signals that the quantum memory has been altered. The logical error probability
\overline{p}_{N,\alpha}
is then estimated as the fraction of failures over all shots.

In order to predict the logical observable, the decoder must be provided with a circuit-level noise model. In our case, this is a multichannel Markovian noise model that includes depolarizing channels for the gates;
biased dephasing channels that depend on the
T_{1}
and
T_{2}
values adapted to the different idling times; and bit-flip channels for the measurements (see
Appendix

D
in
sup
for details).
The rates of these channels are obtained from the calibration data of each qubit and qubit pair and display a characteristic non-uniformity (rates depend on per-qubit
T_{1}/T_{2}
, gate fidelities, etc.), as each qubit and coupler acquire different specifications during fabrication.

Given the use of optimized, robust DD sequences that suppress pulse angle and axis errors to a certain order, our decoder assumes ideal single-qubit gates. When our decoding includes DD, we report the performance based on the experimentally-optimized DD for each data point.

Suppression factor metric for assessing subthreshold scaling

To quantify evidence of subthreshold behavior, we begin with the conventional suppression factor between consecutive distances,

\Lambda_{\varepsilon}^{(d)}\equiv\frac{\varepsilon_{d}}{\varepsilon_{d+2}}

where
\varepsilon_{d}

;

;

;

;

\varepsilon_{d}\approx Ce^{-\kappa d}

\Lambda_{\varepsilon}^{(d)}\approx e^{2\kappa}
that is approximately constant in

\kappa=\frac{1}{2}\ln\Lambda_{\varepsilon}

or even teraquop

In current quantum-memory experiments, reported suppression factors lie in the range
\Lambda_{\varepsilon}^{(d)}\sim[1.56,2.15]

;

To estimate

(1)

Z

\{\overline{p}_{N,0}^{\bm{d}},\overline{p}_{N,1}^{\bm{d}},\overline{p}_{N,+}^{\bm{d}},\overline{p}_{N,-}^{\bm{d}}\}
, corresponding to logical
X
and
Z
errors, respectively, since
Y
basis preparation and readout require significantly more complicated methods
Gidney 2024
. Nevertheless, under reasonable assumptions about the logical error channel, we can derive compact expressions for the EF that go beyond a simple averaging of the basis-dependent logical errors and approximate the contributions from the
Y
-basis states.
Our model describes the logical quantum channel as consisting of independent logical Pauli
X
and
Z
errors, logical amplitude damping, and logical SPAM errors, and assumes a CP‑divisible (cycle-composable) logical channel across cycles. Under this model, we derive expressions for the EF
F_{\mathrm{e}}^{\bm{d}}(N)
, as well as rigorous upper and lower bounds so that
F_{{\rm e},<}^{\bm{d}}(N)\leq F_{\mathrm{e}}^{\bm{d}}(N)\leq F^{\bm{d}}_{{\rm e},>}(N)
, which solely use the decoder-provided (measured) probabilities (see
Appendix

E
in
sup
):

\displaystyle F_{\mathrm{e}}^{\bm{d}}(N)=F_{{\rm e},<}^{\bm{d}}(N)+\Bigl(\frac{1}{\Gamma^{(N)}}-1\Bigr)r(N),

(2)

where
r(N)\equiv\frac{\Sigma^{\bm{d}}_{x}(N)\Sigma^{\bm{d}}_{z}(N)}{4\Sigma_{x}^{\bm{d}}(0)\Sigma_{z}^{\bm{d}}(0)}
and

\displaystyle F_{{\rm e},<}^{\bm{d}}(N)

\displaystyle=\frac{1}{4}\left(1+\frac{\Sigma^{\bm{d}}_{x}(N)}{\Sigma_{x}^{\bm{d}}(0)}\right)\left(1+\frac{\Sigma_{z}^{\bm{d}}(N)}{\Sigma_{z}^{\bm{d}}(0)}\right),

(3a)

\displaystyle F_{\rm e,>}^{\bm{d}}(N)

\displaystyle=F_{\rm e,<}^{\bm{d}}(N)+\left(\frac{\Sigma_{z}^{\bm{d}}(0)}{\Sigma_{z}^{\bm{d}}(N)}-1\right)r(N),

(3b)

Here,
\Sigma_{x}^{\bm{d}}(N)=1-\overline{p}^{\bm{d}}_{N,+}-\overline{p}^{\bm{d}}_{N,-}
and
\Sigma_{z}^{\bm{d}}(N)=1-\overline{p}^{\bm{d}}_{N,0}-\overline{p}^{\bm{d}}_{N,1}
. Their values at
N=0
account for SPAM renormalization, which we calibrate at the very first cycle. The factor
\Gamma^{(N)}
accounts for logical amplitude damping and is discussed in detail in
Appendix

E
in
sup
; it cannot be estimated based purely on
X
and
Z
-basis data, which is why we require the upper and lower bounds.

The EF has a simple interpretation: it lower-bounds the probability that after
N
steps the cumulative Pauli error is the identity, i.e.,
1-F_{\mathrm{e}}^{\bm{d}}(N)
upper bounds the probability of a logical error. Further, we note that the lower bound improves upon a baseline four‑state truncation of the EF,
F^{\bm{d}}_{\rm e,trunc}(N)=(1+\Sigma^{\bm{d}}_{x}(N)/\Sigma^{\bm{d}}_{x}(0)+\Sigma^{\bm{d}}_{z}(N)/\Sigma^{\bm{d}}_{z}(0))/4

Nielsen 2002
, by incorporating
Y
-basis results modeled as the uncorrelated concatenation of
X
and
Z
errors, yielding the above expression of
F^{\rm low}_{\rm e}(N)
. The upper bound
F^{\rm high}_{\rm e}(N)
assumes the most non‑unital channel consistent with the
X/Z
tallies.

The EF naturally lends itself as a metric for assessing subthreshold scaling: comparing a family codes with different
\bm{d}
values can be done by computing their respective
F_{\mathrm{e}}^{\bm{d}}(N)
’s. Let
\tilde{F}_{\mathrm{e}}\equiv\max_{\{\text{DD,noDD}\}}F_{\mathrm{e}}
so that each code is separately optimized with respect to the inclusion of DD. If
\tilde{F_{\mathrm{e}}}^{(d_{x},d_{z})}(N)>\tilde{F_{\mathrm{e}}}^{(d^{\prime}_{x},d^{\prime}_{z})}(N)
for all
N
, where
d_{x}>d^{\prime}_{x}
or
d_{z}>d^{\prime}_{z}
, or if the ratio of infidelities

\displaystyle\Lambda_{F}^{(\bm{d},\bm{d}^{\prime})}(N)\equiv\frac{1-\tilde{F}_{\mathrm{e}}^{\bm{d}^{\prime}}(N)}{1-\tilde{F}_{\mathrm{e}}^{\bm{d}}(N)}

(4)

satisfies
\Lambda_{F}^{(\bm{d},\bm{d}^{\prime})}(N)>1
for all
N
under the same distance ordering, then this constitutes evidence of subthreshold scaling. Maximization over the inclusion or exclusion of DD ensures that each code is compared in its optimally configured form, an important point that we highlighted in the Introduction and discuss in more detail below. In applying
Eq.

4
in the context of individual sublattices, we define the top-performing sublattice code as the code that has the highest fidelity averaged over all cycles. This is consistent with keeping the logical qubit fidelity as high as possible for as long as possible.

We advocate for the use of
\Lambda_{F}^{(\bm{d},\bm{d}^{\prime})}(N)
in lieu of
\Lambda_{\varepsilon}^{(d)}
, as it is a fitting-model-free metric that, moreover, does not require the assumption of stationarity and can be computed directly from the logical error probabilities output by the decoder. In fact, it is by carefully considering the EF that we can identify the implicit assumptions underlying the suppression factor, and the required generalizations of fitting error models and logical basis averaging.

.6
Reduction to fitting models

As shown in
Appendix

E
, when we assume (1) stationarity (the noise channel is independent of the cycle number
N
), (2) unitality (the noise consists purely of Pauli errors), and (3) no logical SPAM errors, the single-parameter error model
Eq.

1
is recovered from first principles. The EF in this case coincides exactly with the lower bound for
\Sigma_{x}^{\bm{d}}(0)=\Sigma_{z}^{\bm{d}}(0)=1
and, after expanding the EF to leading order in the logical error probabilities, gives
F^{\bm{d}}_{\rm e}(N)=\frac{1}{4}\big([1+\Sigma^{\bm{d}}_{x}(N)][1+\Sigma^{\bm{d}}_{z}(N)]\big)\approx 1-p^{\bm{d}}_{N}
, with
\overline{p}^{\bm{d}}_{N}=\frac{1}{4}\sum_{\alpha}\overline{p}^{\bm{d}}_{N,\alpha}
as the logical error probability after
N
cycles averaged over the four basis states. Note that each of these error probabilities is described by the single-parameter error model
Eq.

1
, and that only for
N=1
one recovers an expression with the per-cycle error rates averaged over basis states
F_{\mathrm{e}}^{\bm{d}}(1)=1-\epsilon_{\bm{d}}
, where
\epsilon_{\bm{d}}=\frac{1}{4}\sum_{\alpha}\epsilon^{\bm{d}}_{\alpha}
. For generic
N
, it is not the averaged
\epsilon_{\bm{d}}
which determines the EF and the average channel infidelity, but a linear combination of the different exponential decays per basis state, in addition to non-linear contributions due to the
Y
-basis states.
When the specific assumptions above do not hold, the complete expression
Eq.

2
gives a more informative metric.

The non-stationary, non-unital, SPAM-inclusive model used to derive
Eq.

2
is actually crucial in our case, as our QEC experiments show evidence of cycle-dependence as well as logical amplitude damping and SPAM errors.
The same first-principles model can also be used to derive a generalization of
Eq.

1
with three free but stationary (cycle-independent) parameters
\{a_{\alpha},b_{\alpha},\varepsilon^{\bm{d}}_{\alpha}\}
that can be used to fit the logical error probability

\overline{p}^{\bm{d}}_{N,\alpha}=a_{\alpha}+b_{\alpha}\bigl(1-\varepsilon^{\bm{d}}_{\alpha}/a_{\alpha}\bigr)^{N},

(5)

where
\varepsilon^{\bm{d}}_{\alpha}
is the per-cycle error rate (a probability) and
a_{\alpha},b_{\alpha}
account for non-unital and SPAM errors. Interestingly, the same result can also be derived from a physically motivated difference equation for the logical error probabilities, relating the free parameters to specific logical error sources (see
Appendix

E
in
sup
). The aforementioned reduction to the one-parameter model
Eq.

1
by imposing additional assumptions is particularly clear when

Eq.

5
is used as the starting point: neglecting SPAM errors
sets
b_{\alpha}=-a_{\alpha}
, and restricting to unital Pauli errors further fixes
a_{\alpha}=1/2
. For the IBM QPUs, we report different values for
a_{\alpha}
and
b_{\alpha}
below as required for a best-fit to
Eq.

5
, attesting that the logical error model is not a simple Pauli channel.

Entanglement fidelity QEC metric

So far, we have mostly considered the effect of code scaling on the
\{\overline{\ket{0}},\overline{\ket{1}},\overline{\ket{+}},\overline{\ket{-}}\}
states separately. For the scaling of the suppression factor, this is motivated by the fact that different fitting parameters are required for each of the states [recall

A common approach based on the logical error rate

or the suppression factor

QEC cycle, and in the limit of small logical Pauli errors. For larger cycle numbers, a more complicated expression is needed that would in addition require the measurement of all six cardinal states.

.4
Role of DD and spurious subthreshold scaling

As mentioned above, our results require careful integration of optimized DD into embedded surface code circuits.
Figure

Summary and Conclusions

We implemented a surface-code quantum memory on IBM heavy-hex QPUs using a lightweight SWAP-based embedding integrated with robust dynamical decoupling (DD). With this hardware-aware co-design we observe directional suppression of logical errors under anisotropic distance scaling: increasing
d_{x}
(
d_{z}
) improves protection against
X
-type (
Z
-type) logical errors, despite increases in circuit width and depth.

To benchmark code scaling without model-fit ambiguities, we introduced an entanglement-fidelity (EF) metric that (i) combines all four accessible basis states; (ii) accounts for SPAM and non-unital effects; and (iii) remains valid under cycle-dependent noise. Using EF, we did not find global, state-independent subthreshold scaling for the full logical channel on current IBM QPUs, with the exception of the onset of such scaling at late QEC cycles for
ibm_marrakesh
. Our results clarify the limits of inferences drawn from widely used single-parameter, basis-averaged suppression factors, whose assumptions (cycle-independence, unitality, no SPAM) are not fully met in our experiments.

DD is essential in this setting. It suppresses dominant
Z
-biased mechanisms—including coherent
ZZ
crosstalk and correlated dephasing, thus pushing the residual noise closer to what the surface code can effectively correct. We showed that threshold assessment must optimize each code instance, before comparison, over using or not using DD: using an unoptimized reference can yield spurious indications of subthreshold scaling. In practice, our recommended metric is the entanglement infidelity ratio computed from the best configuration per code.

Circuit-level simulations calibrated to experiment indicate that a modest,
\sim 30\%
reduction in current noise rates, together with access to a slightly larger heavy-hex device that can host a
(5,5)
code, would achieve genuine subthreshold scaling under the EF metric.

Our results establish a practical path for the demonstration of surface code scaling: (i) minimize depth via connectivity-aware embedding; (ii) integrate robust DD to suppress non-Markovian and coherent error components; and (iii) evaluate scaling using EF-based, SPAM-aware metrics. This combination delivers concrete, device-level targets for realizing below-threshold operation on non-native surface-code architectures, and provides a model-free benchmark for future progress toward fault-tolerant quantum computing.

Appendix C
DD optimization

As discussed in the main text, the implementation of a surface code on a heavy-hex lattice inevitably introduces idle gaps due to the lattice’s specific connectivity. This stands in contrast to surface code implementations on square-lattice QPUs, such as the Willow processor, where parallelization eliminates idle periods, and DD is employed only during readout and exclusively on data qubits. A straightforward, but naive, strategy for heavy-hex lattices would be to fill
all
idle gaps with the same DD sequence. However, such an approach can actually degrade the fidelity as the idle gaps vary in duration. For example, a four-pulse sequence such as XY4

Appendix D
Circuit-level noise and decoding

A faithful noise model is required to realistically simulate code performance numerically and make comparative assessments of different possible strategies. In addition, a faithful noise model is also useful as input to the decoder of the experimental data. We generate the so-called detector error model (DEM) for decoding using Stim, a high-performance stabilizer circuit simulator
Gidney 2021
.
Stim builds the DEM by calculating how the faults of each elementary gate, idle period, or measurement, all sampled stochastically from a Markovian Pauli channel, lead to specific flips of the code stabilizers. Since Pauli operators can be propagated very efficiently through Clifford circuits, these independent elementary faults yield a weighted graph where nodes are detectors (syndrome changes in space-time), edges represent the specific pairs of detectors that are flipped through the actual noisy circuit simulation, and the weights are connected to the probabilities of the circuit-level Pauli channel through the error propagation. The DEM allows for more efficient minimum-weight matching decoding, as the Pauli channel can be fed with actual calibration data, including inhomogeneous error rates, instead of assuming uniform uncorrelated flips.
A model that accurately captures the noise in the real device can thus boost the logical fidelity, as it can be more effective in identifying the correct recovery operations. We use a non-uniform circuit-level noise model with the following error channels:

•

Two-qubit depolarizing channel
with rate
p_{2q}^{i,j}
after any two-qubit gate between qubits
i
and
j
.

•

Bit-flip channel
with rate
1-\sqrt{1-p_{\text{m}}^{i}}
before measuring qubit
i
.

•

Classical bit flip channel
with rate
1-\sqrt{1-p_{\text{m}}^{i}}
for measurements, flipping the measurement outcome without affecting the measured qubit. Thus, the total probability of an error happening while measuring qubit
i
is
p_{m}^{i}
.

•

Biased dephasing channel
during idle periods, obtained by Pauli twirling the amplitude and phase damping errors, with rates
Geller and Zhou 2013

p_{\text{id},x}^{i}=p_{\text{id},y}^{i}=\frac{t_{\text{id}}^{i}}{4T_{1}},\quad p_{\text{id},z}^{i}=\frac{t_{\text{id}}^{i}}{2}\left(\frac{1}{T_{2}}-\frac{1}{2T_{1}}\right),

(6)

where
t_{\text{id}}^{i}
is the time during which qubit
i
is idling.

•

No error channel
for single-qubit gates: since they are much more accurate than measurements and CNOTs, we consider them ideal.

Aside from DD pulses, we only use single-qubit gates to perform
X
-basis measurements and to transpile the CNOT gate into a native two-qubit gate; the durations and fidelities of those operations are minimally impacted by the extra single-qubit gates. Moreover, given the use of optimized robust sequences that suppress pulse area/axis errors to a certain order, our decoder assumes ideal single-qubit gates in the DD sequences.
Future improvements of the decoder may consider the higher-order errors of the single-qubit gates, which could be used for further optimization of the DD sequences considered in this work, provided that the decoder is provided with a noise model adapted to the non-uniform and cycle-dependent DD.

To determine idle errors, the circuit is sliced into layers, ensuring that at most one gate is applied to each qubit inside a layer. These layers are preserved when the circuit is transpiled for execution in real hardware. The length of each layer equals the duration of the slowest gate within it. If the duration of the gate applied to qubit
i
is
t_{\text{op}}^{i}
, the qubit will idle for a time equal to

t_{\text{id}}^{i}=\max_{j}\left(t_{\text{op}}^{j}\right)-t_{\text{op}}^{i},

(7)

undergoing errors according to
Eq.

6

Error rates

(8)

A logical error occurs when the corrected measurement disagrees with the value of the logical operator in the absence of noise. Experimentally, the logical error probability

\overline{p}_{N}=N_{\text{fail}}/N_{\text{shots}}.

\Delta_{\overline{p}_{N}}=\frac{\sigma_{\overline{p}_{N}}}{\sqrt{N_{\text{shots}}}}=\sqrt{\frac{\overline{p}_{N}\left(1-\overline{p}_{N}\right)}{N_{\text{shots}}}}.

(10)

by passing it into the Gaussian Process Regression (GPR) bootstrap function process
Rasmussen et al. 2004
. GPR treats these points as noisy observations of an underlying smooth function, defined by a mean and a covariance (kernel) function. A single sample from the GPR posterior results in a synthetic replicate that preserves the inferred correlations among the
\overline{p}_{N}
.

Appendix E
CPTP map model for the logical error probability and entanglement fidelity

Here we rigorously derive an expression for the entanglement fidelity starting directly from the general completely positive trace-preserving (CPTP) map setting. We obtain the phenomenological fitting model as a special case and, moreover, go beyond the basis- and parameter-dependent fitting results to provide a more robust metric to assess the performance of QEC.

E.1
General Model

We assume a model where a single qubit is subject to a sequence of CPTP maps
\{\Phi_{n}\}_{n=1}^{N}
, each corresponding to a QEC cycle and described by Kraus operators
\{E^{(n)}_{i}\}_{i}
that act on the
logical
code subspace, satisfying the completeness condition
\sum_{i}E^{(n)\dagger}_{i}E^{(n)}_{i}=\mathbb{I}
.
This is a reasonable model since the system is effectively projected into a stabilizer subspace after each syndrome readout, and is effectively re-projected to the code space via the final Pauli-frame update after
N
cycles.
Hence, the initial system-bath state at the beginning of each cycle is a product state, and as long as slow temporal correlations such as parameter drift can be ignored between cycles, the evolution is described by a CP-divisible map
Rivas et al. 2010
at the beginning of each new cycle. Then

\Psi_{N}\equiv\Phi_{N}\circ\dots\circ\Phi_{2}\circ\Phi_{1}

(11)

is the overall composed map after
N
QEC cycles. Note that we do not assume that the individual CPTP maps are equal, nor that they are of a particular Pauli type with a constant error rate per cycle.

E.2
Entanglement fidelity

The average channel fidelity of a CPTP
\Phi
with Kraus operators
\{E_{i}\}
is
Nielsen 2002

F_{\mathrm{ave}}\equiv\int d\psi\bra{\psi}\Phi(|{\psi}\rangle\!\langle\psi|)\ket{\psi}\\
=\frac{F_{\mathrm{e}}+1/D}{1+1/D},

(12)

where
d\psi
is the Haar measure on a Hilbert space of dimension
D
, and
F_{\mathrm{e}}
is the entanglement fidelity:

F_{\mathrm{e}}=\bra{\phi}\bigl(\mathcal{I}\otimes\Phi\bigr)\bigl(|{\phi}\rangle\!\langle\phi|\bigr)\ket{\phi}\\
=\frac{1}{D^{2}}\sum_{i}\Bigl|\mathrm{Tr}\bigl(E_{i}\bigr)\Bigr|^{2},

(13)

where

\ket{\phi}=\frac{1}{\sqrt{d}}\sum_{j=0}^{D-1}\ket{j}\otimes\ket{j}

is the maximally entangled purification of the fully mixed state.

The average channel fidelity has an intuitive interpretation as the probability of preserving a pure state
\ket{\psi}
after the action of the channel
\Phi
, averaged over all pure states.
In the main text we used the entanglement fidelity as a metric for assessing code performance that is independent of a fitting model and is appropriate under biased noise. Here we derive an expression that relates it to the logical error probabilities output by the decoder. We also show that the entanglement fidelity has a simple operational meaning in the Pauli-noise, SPAM-free limit: it equals the probability that the cumulative logical Pauli is the identity.

E.3
General expression for the entanglement fidelity

We use the Pauli-transfer matrix (PTM) representation of the channel in the normalized logical Pauli basis

A_{0}=I/\sqrt{2}
,
A_{i}=\sigma_{i}/\sqrt{2}
, so that

\mathrm{Tr}(A_{i}^{\dagger}A_{j})=\delta_{ij}
,
i,j\in\{x,y,z\}\equiv\{1,2,3\}
.
For a single-qubit state
\rho=(I+\mathbf{r}\cdot\bm{\sigma})/2
with Bloch vector

\mathbf{r}=(r_{x},r_{y},r_{z})^{T}
(we use a superscript
T
to denote the transpose) and components
r_{i}=\mathrm{Tr}(\sigma_{i}\rho)
, the PTM
S^{(n)}
of the CPTP channel of the
n
’th QEC cycle
\Phi_{n}
is the unique real
4\times 4
matrix satisfying

\begin{pmatrix}1\\
\mathbf{r}^{\prime}\end{pmatrix}=S^{(n)}\begin{pmatrix}1\\
\mathbf{r}\end{pmatrix},\qquad S^{(n)}=\begin{pmatrix}1&0\\
\mathbf{t}^{(n)}&T^{(n)}\end{pmatrix},

(14)

so that
\mathbf{r}^{\prime}=\mathbf{t}^{(n)}+T^{(n)}\mathbf{r}
.
The matrix elements are given explicitly by

T^{(n)}_{ij}=\mathrm{Tr}\bigl[A_{i}\Phi_{n}(A_{j})\bigr],\qquad t^{(n)}_{i}=\mathrm{Tr}\bigl[A_{i}\Phi_{n}(A_{0})\bigr].

(15)

Trace preservation enforces
S^{(n)}_{00}=1
and
S^{(n)}_{0i}=0
for all
i
, giving the first row
[1\ 0\ 0\ 0]
. Unital channels further satisfy
\Phi_{n}(I)=I
and hence
\mathbf{t}^{(n)}=\mathbf{0}
. The
3\times 3
real (not necessarily symmetric) block
T^{(n)}
captures contractions, rotations, and cross-axis couplings. In our context, the off-diagonal entries
T^{(n)}_{ij}
(
i\neq j
) are cross-logical terms.

After a total of
N
cycles, the composed PTM is

S^{(N)}_{\mathrm{eff}}=S^{(N)}\cdots S^{(2)}S^{(1)}=\begin{pmatrix}1&0\\
\mathbf{t}^{(N)}_{\mathrm{eff}}&T^{(N)}_{\mathrm{eff}}\end{pmatrix},

(16)

where

T^{(N)}_{\mathrm{eff}}=T^{(N)}\cdots T^{(2)}T^{(1)},

(17)

with affine shift

\mathbf{t}^{(N)}_{\mathrm{eff}}=\sum_{n=1}^{N}\Bigl(\prod_{j=n+1}^{N}T^{(j)}\Bigr)\mathbf{t}^{(n)}.

(18)

With the initial Bloch vector being
\mathbf{r}_{0}
, the composed map yields

\mathbf{r}_{N}=\mathbf{t}_{\mathrm{eff}}^{(N)}+T_{\mathrm{eff}}^{(N)}\mathbf{r}_{0}.

(19)

We use a result due to Ref.
Bowdrey et al. 2002
(see also Ref.
Nielsen 2002
):

Lemma 1
.

For a given PTM, the entanglement fidelity depends only on the
3\times 3
block

F_{\mathrm{e}}=\frac{1+\mathrm{Tr}(T)}{4}.

(20)

Proof.

Using
Eq.

15
we have

T_{jj}=\mathrm{Tr}\bigl[A_{j}\Phi(A_{j})\bigr]=\mathrm{Tr}\bigl[A_{j}\sum_{i}E_{i}A_{j}E_{i}^{\dagger}\bigr]
, so that

\mathrm{Tr}(T)=\sum_{i}\mathrm{Tr}\bigl[\sum_{j=1}^{3}A_{j}E_{i}A_{j}E_{i}^{\dagger}\bigr].

(21)

Using the Pauli completeness identity
\sum_{j=x,y,z}\sigma_{j}E\sigma_{j}=2\mathrm{Tr}(E)I-E
(valid for any
2\times 2
matrix
E
), and recalling that
A_{j}=\sigma_{j}/\sqrt{2}
, we find

\displaystyle\mathrm{Tr}(T)

\displaystyle=\frac{1}{2}\sum_{i}\left(2\bigl|\mathrm{Tr}(E_{i})\bigr|^{2}-\mathrm{Tr}(E_{i}^{\dagger}E_{i})\right)

(22a)

\displaystyle=\sum_{i}\bigl|\mathrm{Tr}(E_{i})\bigr|^{2}-1,

(22b)

where we used trace preservation
\sum_{i}E_{i}^{\dagger}E_{i}=I
so
\sum_{i}\mathrm{Tr}(E_{i}^{\dagger}E_{i})=\mathrm{Tr}(I)=2
.
Therefore, using
Eq.

13
with
d=2
,

F_{\mathrm{e}}=\frac{1}{d^{2}}\sum_{i}\bigl|\mathrm{Tr}(E_{i})\bigr|^{2}=\frac{1}{4}\sum_{i}\bigl|\mathrm{Tr}(E_{i})\bigr|^{2}=\frac{1+\mathrm{Tr}(T)}{4}.

(23)

∎

In particular, for any composition of
N
noise channels, the final entanglement fidelity is given by

F_{\mathrm{e}}(N)=\frac{1+\mathrm{Tr}(T^{(N)}_{\mathrm{eff}})}{4},

(24)

with
T^{(N)}_{\mathrm{eff}}
given by
Eq.

17
.

E.4
General connection between entanglement fidelity and decoder output

In general, each
T^{(n)}
in
Eq.

17
is a real matrix, i.e., can have up to
9
independent matrix elements. We do not have access to data that fully characterizes all
9
elements per QEC cycle, as this would requires full process tomography at the logical level and repeated over
N
cycles.
However, if we assume that each
T^{(n)}
is diagonal with entries
\eta^{(n)}_{i}\equiv[T^{(n)}]_{ii}
(
i\in\{x,y,z\})
, then the final entanglement fidelity is given by

F_{\mathrm{e}}(N)=\frac{1}{4}\left[1+\prod_{n=1}^{N}\eta^{(n)}_{x}+\prod_{n=1}^{N}\eta^{(n)}_{y}+\prod_{n=1}^{N}\eta^{(n)}_{z}\right].

(25)

Next, we explain how to relate these expressions for the entanglement fidelity to the data we obtain from our experiments, and clarify the assumptions required to have such a diagonal
T^{(n)}
.

Experimentally, we have direct access to the decoder-reported logical error probabilities after
N
QEC cycles of four cardinal logical states:

\overline{p}_{N,\alpha}\ \text{from }\ \overline{\ket{\alpha}}\ \text{runs},\quad\alpha\in\{0,1,+,-\}.

(26)

Note that encoding logical
\overline{\ket{\pm{\rm i}}}
states, and measuring in the corresponding
\overline{Y}
basis is not straightforward in the surface code; including those states on an equal footing in a QEC metric lies beyond the reach of current hardware capabilities.

The PTM formalism uses
per-cycle
quantities, whereas the decoder returns
cumulative
(after
N
cycles) logical error probabilities
\overline{p}_{N,\alpha}
. Note that in the main text we use the notation
\overline{p}_{N,\alpha}^{\bm{d}}
for
\overline{p}_{N,\alpha}
; here we drop the code distance parameters
\bm{d}
, as they do not play a role in our calculations.

Lemma 2
.

The connection between the experimental quantities
\overline{p}_{N,\alpha}
and the diagonal PTM elements is

\displaystyle\eta^{(N)}_{x}

\displaystyle=\frac{1-\overline{p}_{N,-}-\overline{p}_{N,+}}{1-\overline{p}_{N-1,-}-\overline{p}_{N-1,+}}

(27a)

\displaystyle\eta^{(N)}_{z}

\displaystyle=\frac{1-\overline{p}_{N,1}-\overline{p}_{N,0}}{1-\overline{p}_{N-1,1}-\overline{p}_{N-1,0}},

(27b)

with the convention
\overline{p}_{0,\alpha}=0
so that the
N=1
case reduces to
\eta_{x}^{(1)}=1-\overline{p}_{1,-}-\overline{p}_{1,+}
and
\eta_{z}^{(1)}=1-\overline{p}_{1,1}-\overline{p}_{1,0}
.

Proof.

Assume the composed
N
-cycle logical channel has diagonal Pauli-transfer form

T_{\mathrm{eff}}^{(N)}=\mathrm{diag}\bigl([T_{\mathrm{eff}}^{(N)}]_{xx},[T_{\mathrm{eff}}^{(N)}]_{yy},[T_{\mathrm{eff}}^{(N)}]_{zz}\bigr)
,
with an arbitrary affine shift
\mathbf{t}_{\mathrm{eff}}^{(N)}=(t^{(N)}_{x},t^{(N)}_{y},t^{(N)}_{z})^{T}
.

Consider the initial state
\rho_{0,\pm j}=\frac{I\pm\sigma_{j}}{2}
, i.e., the logical qubit is prepared in the
\pm 1
eigenstate of
\sigma_{j}
. Let
\Psi_{N}=\Phi_{N}\circ\cdots\circ\Phi_{1}
and let
\rho_{N,\pm j}=\Psi_{N}(\rho_{0,\pm j})
denote the resulting state after
N
cycles. Define the “conditional magnetization”

m_{i}^{(N)}(\pm j)\equiv\mathrm{Tr}(\sigma_{i}\rho_{N,\pm j}),

(28)

i.e., the expectation value of
\sigma_{i}
after
N
QEC cycles, given that the initial state is the
\pm 1
eigenstate of
\sigma_{j}
.
The corresponding PTM is given by
Eq.

16
, and the composed map yields
\mathbf{r}_{N}=\mathbf{t}_{\mathrm{eff}}^{(N)}+T_{\mathrm{eff}}^{(N)}\mathbf{r}_{0}
[
Eq.

19
]. Recall that the
i
’th Bloch vector component is
r_{N,i}=[\mathbf{r}_{N}]_{i}=\mathrm{Tr}(\sigma_{i}\rho_{N})
, and note that this is also the magnetization defined in
Eq.

28
. Thus, for
i\in\{x,y,z\}
:

\displaystyle m_{i}^{(N)}(\pm j)

\displaystyle=\mathrm{Tr}(\sigma_{i}\rho_{N,\pm j})=t^{(N)}_{i}\pm[T_{\mathrm{eff}}^{(N)}]_{ij}

(29a)

\displaystyle=t^{(N)}_{i}\pm[T_{\mathrm{eff}}^{(N)}]_{ii}\delta_{ij},

(29b)

since by assumption the PTM blocks
T^{(n)}
are diagonal.

Let
G_{N}\in\{I,X,Y,Z\}
be the net logical Pauli returned by the decoder after
N
cycles. From the corresponding tallies, we compute
\overline{p}_{N,\alpha}
, the error probability of
not
ending in
\ket{\alpha}
after
N
cycles, having initialized in
\ket{\alpha}
, for
\alpha\in\{0,1,+,-\}
. Thus,

\overline{p}_{N,+}=\mathrm{Pr}[G_{N}\in\{Z,Y\}]
for
\ket{+}
and
\overline{p}_{N,-}=\mathrm{Pr}[G_{N}\in\{Z,Y\}]
for
\ket{-}
runs, and

\overline{p}_{N,0}=\mathrm{Pr}[G_{N}\in\{X,Y\}]
and
\overline{p}_{N,1}=\mathrm{Pr}[G_{N}\in\{X,Y\}]
for
\ket{0}
and
\ket{1}
runs, respectively.

For
i\in\{x,y,z\}
define

C_{i}(G_{N})=\begin{cases}+1,&[G_{N},\sigma_{i}]=0\ \ (G_{N}\in\{I,\sigma_{i}\}),\\
-1,&\{G_{N},\sigma_{i}\}=0\ \ (G_{N}\in\{\sigma_{j}\mathrel{\mathop{\mathchar 58\relax}}\ j\neq i\}).\end{cases}

(30)

For a logical qubit prepared in the
\pm
eigenstate of
\sigma_{i}
, define the binary random variable

A_{i,\pm}(G_{N})\equiv\pm C_{i}(G_{N}).

(31)

Then the conditional magnetization after
N
cycles is

\displaystyle m_{i}^{(N)}(\pm i)=\mathbb{E}\bigl[A_{i,\pm}(G_{N})\bigr]

(32a)

\displaystyle\quad=\pm\Bigl(\mathrm{Pr}([G_{N},\sigma_{i}]=0)-\mathrm{Pr}(\{G_{N},\sigma_{i}\}=0)\Bigr)

(32b)

\displaystyle\quad=\pm\bigl(1-2\mathrm{Pr}(\{G_{N},\sigma_{i}\}=0)\bigr).

(32c)

In the case of the four basis states used in our experiments:

\displaystyle m_{x}^{(N)}(+x)

\displaystyle=1-2\mathrm{Pr}[G_{N}\in\{Z,Y\}]=1-2\overline{p}_{N,+},

(33a)

\displaystyle m_{x}^{(N)}(-x)

\displaystyle=-\bigl(1-2\mathrm{Pr}[G_{N}\in\{Z,Y\}]\bigr)=2\overline{p}_{N,-}-1

(33b)

\displaystyle m_{z}^{(N)}(+z)

\displaystyle=1-2\mathrm{Pr}[G_{N}\in\{X,Y\}]=1-2\overline{p}_{N,0},

(33c)

\displaystyle m_{z}^{(N)}(-z)

\displaystyle=-\bigl(1-2\mathrm{Pr}[G_{N}\in\{X,Y\}]\bigr)=2\overline{p}_{N,1}-1.

(33d)

Comparing
Eqs.

29
and
33
, we obtain

\displaystyle[T_{\mathrm{eff}}^{(N)}]_{xx}

\displaystyle=1-\overline{p}_{N,-}-\overline{p}_{N,+}

(34a)

\displaystyle[T_{\mathrm{eff}}^{(N)}]_{zz}

\displaystyle=1-\overline{p}_{N,1}-\overline{p}_{N,0}

(34b)

\displaystyle t^{(N)}_{\mathrm{eff},x}

\displaystyle=\overline{p}_{N,-}-\overline{p}_{N,+}

(34c)

\displaystyle t^{(N)}_{\mathrm{eff},z}

\displaystyle=\overline{p}_{N,1}-\overline{p}_{N,0}.

(34d)

These identities are purely combinatorial statements about the decoder’s Pauli-frame tallies and do not assume any particular noise model.

Since
T^{(n)}
is diagonal for all
n
, we have
[T_{\mathrm{eff}}^{(N)}]_{jj}=\prod_{n=1}^{N}\eta_{j}^{(n)}
, yielding

\eta_{x}^{(N)}=\frac{[T_{\mathrm{eff}}^{(N)}]_{xx}}{[T_{\mathrm{eff}}^{(N-1)}]_{xx}},\quad\eta_{z}^{(N)}=\frac{[T_{\mathrm{eff}}^{(N)}]_{zz}}{[T_{\mathrm{eff}}^{(N-1)}]_{zz}},

(35)

whenever the denominators are nonzero. Substituting
Eqs.

34a
and
34b
yields
Eq.

27
, as claimed. Note that an entirely analogous relation holds for
\eta_{y}^{(N)}
if
\overline{\ket{\pm i}}
runs are available.
∎

With access restricted to
\overline{\ket{\pm 1}}
and
\overline{\ket{0/1}}
experiments, a diagonal-
T
model is the minimal assumption that makes
[T_{\mathrm{eff}}^{(N)}]_{xx}
and
[T_{\mathrm{eff}}^{(N)}]_{zz}
identifiable from our data; off-diagonal PTM elements would require
\overline{\ket{\pm i}}
.

E.5
Independent
X
,
Z
, and amplitude-damping model, without SPAM

We now consider a model in which the logical noise channel comprises a combination of logical bit-flips, phase-flips, and a non-unital logical contribution in the form of amplitude damping (AD). We defer to the next subsection the incorporation of SPAM and generalized AD (i.e., when
\overline{\ket{0}}
is not the equilibrium state), which more fully accounts for all sources of error observed in our experiments.

Fix a cycle index
n\in\{1,\dots,N\}
and let

p_{x}(n),\quad p_{z}(n),\quad\gamma_{n}\in[0,1]

(36)

denote, respectively, the per-cycle logical
X
-flip,
Z
-flip, and amplitude-damping parameters. Note that these are different from the decoder outputs
\bar{p}_{N,\alpha}
, and we will establish the relation between them below.

Independent
X
/
Z
flips [with
Y
occurring with probability
p_{x}(n)p_{z}(n)
] have Kraus operators given by

\displaystyle E^{(N)}_{0}

\displaystyle=\sqrt{[1-p_{x}(N)][1-p_{z}(N)]}I,

(37a)

\displaystyle E^{(N)}_{1}

\displaystyle=\sqrt{p_{x}(N)[1-p_{z}(N)]}X,

(37b)

\displaystyle E^{(N)}_{2}

\displaystyle=\sqrt{p_{z}(N)[1-p_{x}(N)]}Z,

(37c)

\displaystyle E^{(N)}_{3}

\displaystyle=\sqrt{p_{x}(N)p_{z}(N)}Y,

(37d)

forming the Pauli channel
\Phi^{\mathrm{P}}_{n}
.
Zero-temperature amplitude damping (
\ket{1}\to\ket{0}
with probability
\gamma_{n}
, but
\ket{0}\to\ket{0}
with probability
1
) is described by the Kraus operators

\displaystyle A^{(n)}_{0}

\displaystyle=|{0}\rangle\!\langle 0|+\sqrt{1-\gamma_{n}}|{1}\rangle\!\langle 1|,

(38a)

\displaystyle A^{(n)}_{1}

\displaystyle=\sqrt{\gamma_{n}}|{0}\rangle\!\langle 1|,

(38b)

forming the channel
\Phi^{\mathrm{AD}}_{n}
.
We take the per-cycle logical channel as the composition

\Phi_{n}=\Phi^{\mathrm{P}}_{n}\circ\Phi^{\mathrm{AD}}_{n},

(39)

so a valid Kraus set for
\Phi_{n}
is
\{E^{(n)}_{\mu}A^{(n)}_{k}\}
with
\mu=0,1,2,3
and
k=0,1
.

Define

\xi_{n}\equiv 1-2p_{x}(n),\quad\zeta_{n}\equiv 1-2p_{z}(n),

(40)

both of which are in
[-1,1]
, i.e., they are Bloch-
x
and
z
contractions.
The independent-
X/Z
Pauli channel is unital and diagonal, and in the normalized Pauli basis
\{A_{i}\}_{i=0}^{3}
it has PTM form

T^{\mathrm{P}}_{n}=\mathrm{diag}(\zeta_{n},\zeta_{n}\xi_{n},\xi_{n}),\quad\mathbf{t}^{\mathrm{P}}_{n}=\mathbf{0},

(41)

while amplitude damping has PTM form

\displaystyle T^{\mathrm{AD}}_{n}

\displaystyle=\mathrm{diag}(\sqrt{1-\gamma_{n}},\sqrt{1-\gamma_{n}},1-\gamma_{n})

(42a)

\displaystyle\mathbf{t}^{\mathrm{AD}}_{n}

\displaystyle=(0,0,\gamma_{n})^{T}.

(42b)

For the composed map
Eq.

39
we have:

T^{(n)}=T^{\mathrm{P}}_{n}T^{\mathrm{AD}}_{n},\quad\mathbf{t}^{(n)}=\mathbf{t}^{\mathrm{P}}_{n}+T^{\mathrm{P}}_{n}\mathbf{t}^{\mathrm{AD}}_{n},

(43)

and
\mathbf{t}^{\mathrm{P}}_{n}=\mathbf{0}
, so explicitly

\displaystyle T^{(n)}

\displaystyle=\mathrm{diag}\bigl(\zeta_{n}\sqrt{1-\gamma_{n}},\zeta_{n}\xi_{n}\sqrt{1-\gamma_{n}},\xi_{n}(1-\gamma_{n})\bigr)

(44a)

\displaystyle\mathbf{t}^{(n)}

\displaystyle=(0,0,\xi_{n}\gamma_{n})^{T}.

(44b)

We now consider the composition over
N
cycles.
Using
Eqs.

16
,
17
and
18
and the diagonal form
Eq.

44
, we obtain

T^{(N)}_{\mathrm{eff}}=T^{(N)}\cdots T^{(1)}=\mathrm{diag}\bigl(A_{x}^{(N)},A_{y}^{(N)},A_{z}^{(N)}\bigr),

(45)

where

\displaystyle A_{x}^{(N)}\equiv\bigl[T^{(N)}_{\mathrm{eff}}\bigr]_{xx}

\displaystyle=\prod_{n=1}^{N}\ \zeta_{n}\sqrt{1-\gamma_{n}},

(46a)

\displaystyle A_{y}^{(N)}\equiv\bigl[T^{(N)}_{\mathrm{eff}}\bigr]_{yy}

\displaystyle=\prod_{n=1}^{N}\ \zeta_{n}\xi_{n}\sqrt{1-\gamma_{n}},

(46b)

\displaystyle A_{z}^{(N)}\equiv\bigl[T^{(N)}_{\mathrm{eff}}\bigr]_{zz}

\displaystyle=\prod_{n=1}^{N}\ \xi_{n}(1-\gamma_{n}),

(46c)

and

\displaystyle\mathbf{t}^{(N)}_{\mathrm{eff}}

\displaystyle=(0,0,t^{(N)}_{\mathrm{eff},z})^{T}

(47a)

\displaystyle t^{(N)}_{\mathrm{eff},z}

\displaystyle=\sum_{n=1}^{N}\xi_{n}\gamma_{n}\prod_{j=n+1}^{N}\xi_{j}(1-\gamma_{j}).

(47b)

We also define

\Gamma^{(N)}\equiv\prod_{n=1}^{N}(1-\gamma_{n}),\quad\xi^{(N)}\equiv\prod_{n=1}^{N}\xi_{n},

(48)

so that

A_{y}^{(N)}=A_{x}^{(N)}\xi^{(N)}=\frac{A_{x}^{(N)}A_{z}^{(N)}}{\Gamma^{(N)}}.

(49)

Equating
Eqs.

34a
and
34b
with
Eqs.

46a
and
46c
, respectively, and repeating
Eq.

34d
, we obtain

\displaystyle A_{x}^{(N)}

\displaystyle=1-\bigl(\overline{p}_{N,+}+\overline{p}_{N,-}\bigr)

(50a)

\displaystyle A_{z}^{(N)}

\displaystyle=1-\bigl(\overline{p}_{N,0}+\overline{p}_{N,1}\bigr)

(50b)

\displaystyle t^{(N)}_{\mathrm{eff},z}

\displaystyle=\overline{p}_{N,1}-\overline{p}_{N,0}.

(50c)

This establishes the promised relation between the decoder outputs and the model parameters.

Now, using
Eq.

24
, we obtain the entanglement fidelity after
N
QEC cycles

\displaystyle F_{\mathrm{e}}(N)

\displaystyle=\frac{1}{4}\left[1+A_{x}^{(N)}+A_{y}^{(N)}+A_{z}^{(N)}\right]

(51a)

\displaystyle=\frac{1}{4}\Bigl(1+A_{x}^{(N)}\Bigr)\Bigl(1+A_{z}^{(N)}\Bigr)

\displaystyle\quad+\frac{1}{4}\Bigl[\frac{1}{\Gamma^{(N)}}-1\Bigr]A_{x}^{(N)}A_{z}^{(N)},

(51b)

where in the second equality we used
Eq.

49
.
Thus, using
Eq.

50
, we finally obtain the entanglement fidelity in terms of the decoder outputs:

\displaystyle F_{\mathrm{e}}(N)=\left(1-\frac{\overline{p}_{N,0}+\overline{p}_{N,1}}{2}\right)\left(1-\frac{\overline{p}_{N,+}+\overline{p}_{N,-}}{2}\right)

\displaystyle\quad+\frac{1}{4}\left[\frac{1}{\Gamma^{(N)}}-1\right]\bigl(1-\overline{p}_{N,0}-\overline{p}_{N,1}\bigr)\bigl(1-\overline{p}_{N,+}-\overline{p}_{N,-}\bigr),

(52)

which is a precursor to
Eq.

2
of the main text.

Since
\Gamma^{(N)}\leq 1
, the second term is nonnegative [assuming
p_{x}(n),p_{z}(n)\leq 1/2
, which is satisfied in our experiments] and we have the lower bound

F_{\mathrm{e}}(N)\ \geq\ \left(1-\frac{\overline{p}_{N,0}+\overline{p}_{N,1}}{2}\right)\left(1-\frac{\overline{p}_{N,+}+\overline{p}_{N,-}}{2}\right).

(53)

Let us now show how we can also express
\Gamma^{(N)}
in terms of the decoder outputs.
Using
Eq.

50
, both
A_{z}^{(N)}
and

are obtained directly from the decoder output. It follows from

that

\lambda_{N}\equiv\frac{A_{z}^{(N)}}{A_{z}^{(N-1)}}=\xi_{N}(1-\gamma_{N}),\quad A_{z}^{(0)}\equiv 1.

(54)

Using
Eq.

47b
, we can write

\displaystyle t^{(N)}_{\mathrm{eff},z}

\displaystyle=\xi_{N}\gamma_{N}+\bigl[\sum_{n=1}^{N-1}\xi_{n}\gamma_{n}\prod_{j=n+1}^{N-1}\xi_{j}(1-\gamma_{j})\bigr]\xi_{N}(1-\gamma_{N})

(55a)

\displaystyle=\xi_{N}\gamma_{N}+t^{(N-1)}_{\mathrm{eff},z}\lambda_{N}.

(55b)

Therefore,

a_{N}\equiv t^{(N)}_{\mathrm{eff},z}-\lambda_{N}t^{(N-1)}_{\mathrm{eff},z}=\xi_{N}\gamma_{N},\quad t^{(0)}_{z}\equiv 0.

(56)

Equations

54
and
56
allow us to express
\gamma_{N}
in terms of the two decoder-data-derived quantities

and
\lambda_{N}
:

1-\gamma_{N}=\frac{1}{a_{N}/\lambda_{N}+1}=\frac{1}{t^{(N)}_{\mathrm{eff},z}/\lambda_{N}-t^{(N-1)}_{\mathrm{eff},z}+1}.

(57)

Therefore,

\displaystyle\Gamma^{(N)}

\displaystyle=\prod_{n=1}^{N}(1-\gamma_{n})=\prod_{n=1}^{N}\frac{1}{a_{n}/\lambda_{n}+1}

(58a)

\displaystyle=\prod_{n=1}^{N}\frac{1}{t^{(n)}_{\mathrm{eff},z}\frac{A_{z}^{(n-1)}}{A_{z}^{(n)}}-t^{(n-1)}_{\mathrm{eff},z}+1}.

(58b)

Upon substituting
Eqs.

50b
and
50c
, this expresses
\Gamma^{(N)}
entirely in terms of the decoder outputs at each cycle
n
. Hence, the entanglement fidelity in
Section

E.5
is also given entirely in terms of experimental quantities.

Note that if we choose the opposite ordering convention from
Eq.

39
, i.e., let
\Phi_{n}=\Phi^{\mathrm{AD}}_{n}\circ\Phi^{\mathrm{P}}_{n}
, the
T^{(n)}
block in
Eq.

44
is unchanged (both factors are diagonal), while the affine shift becomes
\mathbf{t}^{(n)}=(0,0,\gamma_{n})^{T}
. In this case, we have
a_{N}=\gamma_{N}
instead, so that
\Gamma^{(N)}=\prod_{n=1}^{N}(1-a_{n})
.

E.6
Independent
X
,
Z
, and generalized amplitude-damping model, with SPAM

The problem with the model in the previous subsection is that it predicts that
\overline{p}_{N,-}=\overline{p}_{N,+}
[combine
Eqs.

34c
and
47a
]. However, this is not what we observe, as can be seen in
Fig.

2
(c) and (d) of the main text. Therefore, in this subsection we present a model that agrees with the AIC-based conclusion that we need the three-parameter fitting model, and is capable of explaining our data: we account for SPAM, and also replace zero-temperature amplitude damping by nonzero-temperature generalized amplitude damping (GAD). We then derive the entanglement fidelity and show that it can still be computed entirely in terms of the decoder outputs.

E.6.1
Generalized Amplitude Damping

We start by replacing zero-temperature AD by nonzero-temperature GAD with

\gamma_{n}\in[0,1],\quad u_{n}\in[-1,1],

(59)

where
\gamma_{n}
is the damping strength and
u_{n}
is the equilibrium Bloch-
z
polarization. The equilibrium excited-state population
p^{\infty}_{n}=\frac{1+u_{n}}{2}
;
u_{n}=+1
recovers zero-temperature AD toward
\ket{0}
,
u_{n}=-1
is “inverted” AD toward
\ket{1}
;
|u_{n}|<1
corresponds to temperature
T>0
, and
u_{n}=0
is the infinite-temperature limit of zero polarization.

A Kraus set for GAD is
Nielsen 2002

\displaystyle K^{(n)}_{0}=\sqrt{p^{\infty}_{n}}\begin{pmatrix}1&0\\
0&\sqrt{1-\gamma_{n}}\end{pmatrix},\quad K^{(n)}_{1}=\sqrt{p^{\infty}_{n}}\begin{pmatrix}0&\sqrt{\gamma_{n}}\\
0&0\end{pmatrix},

(60)

\displaystyle K^{(n)}_{2}=\sqrt{q^{\infty}_{n}}\begin{pmatrix}\sqrt{1-\gamma_{n}}&0\\
0&1\end{pmatrix},\quad K^{(n)}_{3}=\sqrt{q^{\infty}_{n}}\begin{pmatrix}0&0\\
\sqrt{\gamma_{n}}&0\end{pmatrix},

where
q^{\infty}_{n}\equiv 1-p^{\infty}_{n}
.
In the normalized Pauli basis
A_{0}=I/\sqrt{2}
,
A_{1,2,3}=\sigma_{x,y,z}/\sqrt{2}
, GAD has PTM form

\displaystyle T^{\mathrm{GAD}}_{n}

\displaystyle=\mathrm{diag}(\sqrt{1-\gamma_{n}},\sqrt{1-\gamma_{n}},1-\gamma_{n})

(61a)

\displaystyle\mathbf{t}^{\mathrm{GAD}}_{n}

\displaystyle=(0,0,\gamma_{n}u_{n})^{T}.

(61b)

We retain the composition ordering
\Phi_{n}=\Phi^{\mathrm{P}}_{n}\circ\Phi^{\mathrm{GAD}}_{n}
, so that
T^{(n)}=T^{\mathrm{P}}_{n}T^{\mathrm{GAD}}_{n}
and
\mathbf{t}^{(n)}=T^{\mathrm{P}}_{n}\mathbf{t}^{\mathrm{GAD}}_{n}
; then

\displaystyle T^{(n)}

\displaystyle=\mathrm{diag}\bigl(\zeta_{n}\sqrt{1-\gamma_{n}},\zeta_{n}\xi_{n}\sqrt{1-\gamma_{n}},\xi_{n}(1-\gamma_{n})\bigr),

(62a)

\displaystyle\mathbf{t}^{(n)}

\displaystyle=(0,0,\xi_{n}\gamma_{n}u_{n})^{T}.

(62b)

After
N
cycles we again obtain
Eqs.

45
and
46
, but now
Eq.

47b
becomes

t^{(N)}_{\mathrm{eff},z}=\sum_{n=1}^{N}\ \xi_{n}\gamma_{n}u_{n}\ \prod_{j=n+1}^{N}\xi_{j}(1-\gamma_{j}).

(63)

We remark that GAD differs from AD only in the appearance of the factor
u_{n}
in
Eqs.

61
and
62
; setting
u_{n}=1
recovers the AD model, specifically
Eqs.

42
and
44
.

E.6.2
SPAM

Next, we model SPAM errors as a non-unital channel that modifies the logical state before QEC cycles, affecting the observed PTM:

\displaystyle t^{(N)}_{\mathrm{obs},i}=t^{(N)}_{\mathrm{eff},i}+b_{i}[T^{(N)}_{\mathrm{eff}}]_{ii}

(64a)

\displaystyle[T^{(N)}_{\mathrm{obs}}]_{ii}=a_{i}[T^{(N)}_{\mathrm{eff}}]_{ii},

(64b)

with
|a_{i}|\leq 1
and
|b_{i}|\leq 1-|a_{i}|
. Imperfect initial-state preparation means
b_{i}\neq 0
at
N=0
. Note that in our experimental setup the very first cycle corresponds to logical state preparation starting from the physical all-
\ket{0}
state, which is why we label our cycles starting at
N=0
; this way
N=0
is the cycle which we use to calibrate the logical SPAM parameters, and for which by definition we normalize the EF to
1
. Subsequent cycles (
N\geq 1
) are the ones we use to assess fidelity decay.

With
h(\alpha)\in\{x,z\}
and
s(\alpha)\in\{+1,-1\}
for
\alpha\in\{0,1,+,-\}
, let
h(+)=h(-)=x
,
h(0)=h(1)=z
,
s(+)=s(0)=+1
, and
s(-)=s(1)=-1
.
We can then write the four cases in
Eq.

33
as a single identity:

\overline{p}_{N,\alpha}=\frac{1-s(\alpha)m_{h(\alpha)}^{(N)}\bigl(s(\alpha)h(\alpha)\bigr)}{2}.

(65)

It is convenient to define the sum/difference combinations

\displaystyle\Sigma_{x}(N)

\displaystyle\equiv 1-(\overline{p}_{N,+}+\overline{p}_{N,-})

(66a)

\displaystyle\Sigma_{z}(N)

\displaystyle\equiv 1-(\overline{p}_{N,0}+\overline{p}_{N,1})

(66b)

\displaystyle\Delta_{x}(N)

\displaystyle\equiv\overline{p}_{N,-}-\overline{p}_{N,+}

(66c)

\displaystyle\Delta_{z}(N)

\displaystyle\equiv\overline{p}_{N,1}-\overline{p}_{N,0}.

(66d)

Note that these quantities are determined purely by the decoder outputs, i.e., they are directly measurable.

Using
Eq.

65
we then have, for
i\in\{x,z\}
:

\displaystyle\Sigma_{i}(N)

\displaystyle=\frac{1}{2}\left[m_{i}^{(N)}(+i)-m_{i}^{(N)}(-i)\right]

(67a)

\displaystyle\Delta_{i}(N)

\displaystyle=\frac{1}{2}\left[m_{i}^{(N)}(+i)+m_{i}^{(N)}(-i)\right].

(67b)

Using
Eq.

64
and
m_{i}^{(N)}(\pm i)=t^{(N)}_{\mathrm{obs},i}\pm[T^{(N)}_{\mathrm{obs}}]_{ii}
[
Eq.

29
], we obtain

\displaystyle\Sigma_{i}(N)

\displaystyle=a_{i}[T^{(N)}_{\mathrm{eff}}]_{ii}=a_{i}A_{i}^{(N)}

(68a)

\displaystyle\Delta_{i}(N)

\displaystyle=t^{(N)}_{\mathrm{eff},i}+b_{i}[T^{(N)}_{\mathrm{eff}}]_{ii}=t^{(N)}_{\mathrm{eff},i}+b_{i}A_{i}^{(N)}

(68b)

Thus, even if the channel has
t^{(N)}_{\mathrm{eff},x}=0
(true for the Pauli-AD model above), a nonzero SPAM error
b_{x}
yields
\Delta_{x}(N)\neq 0
and hence

\overline{p}_{N,-}\neq\overline{p}_{N,+}
. Likewise, finite-temperature GAD (
u_{n}\neq 0
) gives
t^{(N)}_{\mathrm{eff},z}\neq 0
[
Eq.

63
], which yields
\Delta_{z}(N)\neq 0
and hence

\overline{p}_{N,0}\neq\overline{p}_{N,1}
; any additional nonzero SPAM error
b_{z}
adds to that splitting.
Both effects are what we observe in
Fig.

2
(c) and (d) of the main text.

Since
[T^{(0)}_{\mathrm{eff}}]_{ii}=1
and
t^{(0)}_{\mathrm{eff},i}=0
, combining
Eq.

64
and
Eq.

67
gives us that the SPAM coefficients
a_{i}
and biases
b_{i}
can be calibrated at
N=0
as

a_{i}=\Sigma_{i}(0),\quad b_{i}=\Delta_{i}(0),

(69)

and as already implied by
Eq.

64
, we assume that these values are cycle-independent.

E.6.3
Non-unitality witnesses

Let us define the SPAM-free “non-unitality witnesses”

\widetilde{\Delta}_{i}(N)\equiv\ \Delta_{i}(N)-\frac{b_{i}}{a_{i}}\Sigma_{i}(N),\quad i\in\{x,z\}.

(70)

Then, by construction, using
Eqs.

68
and
69
, where
A_{i}^{(N)}=[T^{(N)}_{\mathrm{eff}}]_{ii}
are the diagonal PTM contractions
and
t^{(N)}_{\mathrm{eff},i}
are the affine (non-unital) shifts after
N
cycles,

\widetilde{\Delta}_{i}(N)=t^{(N)}_{\mathrm{eff},i}.

(71)

Thus, any statistically significant deviation of
\widetilde{\Delta}_{i}(N)
from zero
is direct evidence of non-unitality along the
i=x,z
axis.

The witnesses in
Eq.

70
can be computed directly in terms of the decoder-reported logical error probabilities. Rather than reporting these witnesses, to boost the SNR we report their cumulative sums

\delta_{i}(N)\equiv\sum_{n=1}^{N}\widetilde{\Delta}_{i}(n).

(72)

A systematic drift away from zero is evidence of non-unitality. This is what we plot in
Fig.

2
(c) and (d).

E.6.4
Entanglement fidelity with GAD and SPAM

The entanglement fidelity is still given, via
F_{\mathrm{e}}(N)=\frac{1}{4}\bigl(1+\mathrm{Tr}T^{(N)}_{\mathrm{eff}}\bigr)
, by
Eq.

51
.
Using
Eqs.

49
and
68a
, we can write this entirely in terms of the decoder outputs and the two SPAM coefficients
a_{x}
and
a_{z}
:

\displaystyle F_{\mathrm{e}}(N)

\displaystyle=\frac{1}{4}\left[1+\frac{\Sigma_{x}(N)}{a_{x}}+\frac{\Sigma_{z}(N)}{a_{z}}+\frac{\Sigma_{x}(N)\Sigma_{z}(N)}{a_{x}a_{z}\Gamma^{(N)}}\right]

(73a)

\displaystyle=\frac{1}{4}\Bigl(1+\frac{\Sigma_{x}(N)}{a_{x}}\Bigr)\Bigl(1+\frac{\Sigma_{z}(N)}{a_{z}}\Bigr)

\displaystyle\quad+\frac{1}{4}\Bigl[\frac{1}{\Gamma^{(N)}}-1\Bigr]\frac{\Sigma_{x}(N)\Sigma_{z}(N)}{a_{x}a_{z}},

(73b)

where the decoder outputs appear via the
\Sigma_{i}(N)
[
Eqs.

66a
and
66b
]. This is
Eq.

2
of the main text.

Throughout,
F_{\mathrm{e}}(N)
is the entanglement fidelity of the logical
channel after logical state preparation. We calibrate the
SPAM coefficients at the logical start (
N=0
) via
a_{i}=\Sigma_{i}(0)
and

b_{i}=\Delta_{i}(0)
, and divide them out, so
F_{\mathrm{e}}(0)=1
by construction.

Since
\Gamma^{(N)}\leq 1
and
\Sigma_{i}(N)\geq 0
in the physically relevant regime (
p_{i}(n)\leq\frac{1}{2}
), the second term in
Eq.

73
is nonnegative and

F_{\mathrm{e}}(N)\ \geq\ \frac{1}{4}\Bigl(1+\frac{\Sigma_{x}(N)}{a_{x}}\Bigr)\Bigl(1+\frac{\Sigma_{z}(N)}{a_{z}}\Bigr)\equiv F_{\mathrm{e},<}(N),

(74)

i.e., the Pauli-only fidelity lower-bounds the Pauli-GAD fidelity. This is
Eq.

3a
of the main text.

Let us now show how we can express
\Gamma^{(N)}
(almost entirely) in terms of the decoder outputs. We have four cycle-dependent unknowns:
\{\xi_{N},\zeta_{N},\gamma_{N},u_{N}\}
. At first sight, we have enough information to determine all, since the decoder returns the four probabilities
\{\overline{p}_{0},\overline{p}_{1},\overline{p}_{+},\overline{p}_{-}\}
. However, in fact we can only form three SPAM-free quantities from these, as can be seen from

Eq.

68b
: since
t_{\mathrm{eff},x}^{(N)}=0
for the Pauli-GAD channel, we find that
\Delta_{x}(N)=b_{x}
, i.e., is pure SPAM. The other three sum/difference combinations,
\{\Sigma_{x}(N),\Sigma_{z}(N),\Delta_{z}(N)\}
, can form SPAM-free quantities that we can use to extract
\{\xi_{N},\zeta_{N},\gamma_{N}\}
, as we show next.

As in
Eq.

54
, define

\displaystyle\lambda_{N}

\displaystyle\equiv\frac{\Sigma_{z}(N)}{\Sigma_{z}(N-1)}=\frac{A_{z}^{(N)}}{A_{z}^{(N-1)}}=\xi_{N}(1-\gamma_{N}),\quad A_{z}^{(0)}\equiv 1

(75a)

\displaystyle\mu_{N}

\displaystyle\equiv\frac{\Sigma_{x}(N)}{\Sigma_{x}(N-1)}=\frac{A_{x}^{(N)}}{A_{x}^{(N-1)}}=\zeta_{N}\sqrt{1-\gamma_{N}},\quad A_{x}^{(0)}\equiv 1

(75b)

where in both lines, in the second equality we used
Eq.

68a
and
Eq.

46c
in the third equality. Note that the SPAM coefficients
a_{z}
and
a_{x}
cancel out, so both
\lambda_{N}
and
\mu_{N}
are SPAM-free quantities.

Using
Eq.

63
, we can write

\displaystyle t^{(N)}_{\mathrm{eff},z}

\displaystyle=\xi_{N}\gamma_{N}u_{N}

(76a)

\displaystyle\quad+\bigl[\sum_{n=1}^{N-1}\xi_{n}\gamma_{n}u_{n}\prod_{j=n+1}^{N-1}\xi_{j}(1-\gamma_{j})\bigr]\xi_{N}(1-\gamma_{N})

\displaystyle=\xi_{N}\gamma_{N}u_{N}+t^{(N-1)}_{\mathrm{eff},z}\lambda_{N},\quad t^{(0)}_{\mathrm{eff},z}\equiv 0.

(76b)

Therefore,

\displaystyle a_{N}

\displaystyle\equiv\tilde{\Delta}_{z}(N)-\lambda_{N}\tilde{\Delta}_{z}(N-1)

(77a)

\displaystyle=t^{(N)}_{\mathrm{eff},z}-\lambda_{N}t^{(N-1)}_{\mathrm{eff},z}=\xi_{N}\gamma_{N}u_{N},

(77b)

Clearly,
a_{N}
is also SPAM-free.

We can solve for
\gamma_{N}
using
Eqs.

75a
and
77
, which allows us to express it in terms of the two decoder-data-derived quantities
\lambda_{N}
and
a_{N}
:

1-\gamma_{N}=\frac{1}{a_{N}/(\lambda_{N}u_{N})+1}.

(78)

Thus,

\Gamma^{(N)}=\prod_{n=1}^{N}\frac{1}{1+a_{n}/(\lambda_{n}u_{n})},

(79)

which (apart from
u_{n}
) expresses
\Gamma^{(N)}
in terms of the decoder outputs at each cycle
n
: each
\lambda_{n}
is given by
Eq.

75a
in terms of the ratio of
\Sigma_{z}
’s, which are entirely determined by the decoder output via
Eq.

66b
. Likewise, each
a_{n}
is given by
Eq.

77
in terms of the
\Delta_{z}
’s, which are quantities that are entirely determined by the decoder output via
Eq.

66d
. The SPAM parameters
a_{z}
and
b_{z}
needed to compute
a_{n}
are determined using
Eq.

69
.

Figure 15:
The entanglement infidelity calculated from
Eq.

2
, along with the lower [
Eq.

3a
] and upper [
Eq.

3b
] bounds for (a) scaling the
(3,5)
code and (b) scaling the
(5,3)
code. Same quantities are also shown for the average of (3,3) codes in each case. In both cases, the entanglement infidelity is very close to the lower bounds, suggesting that non-unital logical errors play a minor role.

The only quantity which we do not have enough information to determine from the decoder output (without measuring
\pm Y
) is the equilibrium Bloch-
z
polarization
u_{n}
. To estimate it we would need to assume a relation between
\xi_{n}
and
\zeta_{n}
, i.e., a relation between the unital contractions for
X
and
Z
.
Without assuming any relation between
\xi_{n}
and
\zeta_{n}
, we can still bound
\Gamma^{(N)}
from below. Using
Eq.

75
,

\Gamma^{(N)}=\prod_{n=1}^{N}(1-\gamma_{n})\geq\prod_{n=1}^{N}\xi_{n}(1-\gamma_{n})=\prod_{n=1}^{N}\lambda_{n}=\frac{\Sigma_{z}(N)}{\Sigma_{z}(0)}.

(80)

Using this in
Eq.

73
and combining with
Eq.

74
,
we obtain the upper and lower bounds

F_{\mathrm{e},<}(N)\leq F_{\mathrm{e}}(N)\leq F_{\mathrm{e},>}(N),

(81)

with

F_{\mathrm{e},>}(N)=F_{\mathrm{e},<}(N)+\frac{1}{4}\left(\frac{\Sigma_{z}(0)}{\Sigma_{z}(N)}-1\right)\frac{\Sigma_{x}(N)\Sigma_{z}(N)}{a_{x}a_{z}},

(82)

which is
Eq.

3b
of the main text.
This uses only SPAM-calibrated decoder outputs.

In practice, since we have no information about
u_{n}
, we compute the EF via
Eq.

73
by assuming that
u_{n}=1
, i.e., the AD model. We ensure, via a data regularization procedure, that
Eq.

81
is always obeyed, despite shot noise. Namely, we replace

(a_{N},\lambda_{N})\mapsto(\tilde{a}_{N},\tilde{\lambda}_{N})

(83)

with

\tilde{a}_{N}=\max\{0,a_{N}\},\quad\tilde{\lambda}_{N}=\mathrm{Clip}(\lambda_{N},[0,1]),

(84)

where
\mathrm{Clip}[x,\{\min,\max\}]
gives
x
for
\min\leq x\leq\max
,
\min
for
x<\min
and
\max
for
x>\max
. Also, if
\tilde{a}_{N}+\tilde{\lambda}_{N}>1
, we scale both by

\text{scale}=(1-10^{-9})/(\tilde{a}_{N}+\tilde{\lambda}_{N}).

(85)

The result of this regularization procedure is plotted in
Fig.

3
.

As shown in
Fig.

15
, we find that in all cases
F_{\mathrm{e}}(N)
is very close to its lower bound
F_{\mathrm{e},<}(N)
, which means that the effect of logical AD errors is very small.

E.6.5
Derivation of three-parameter fitting model from the stationary
X/Z+
GAD
+
SPAM model

We now simplify the previous cycle-dependent model and assume that the per-cycle logical channel is constant and diagonal in the PTM formalism, with

r_{N+1}^{\rm true}(i)=t_{i}+\eta_{i}r_{N}^{\rm true}(i),\quad i\in\{x,z\},

(86)

where
r_{N}^{\rm true}(i)=\mathrm{Tr}(\sigma_{i}\rho_{N})
is the true Bloch component after
N
QEC cycles, and

\displaystyle(\eta_{x},t_{x})

\displaystyle=\bigl(\zeta\sqrt{1-\gamma},0\bigr)

(87a)

\displaystyle(\eta_{z},t_{z})

\displaystyle=\bigl(\xi(1-\gamma),\xi\gamma u\bigr)

(87b)

for the standard
X/Z+
GAD composition (GAD followed by Pauli). The analog of
Eq.

64
is

m_{i}^{\mathrm{obs}(N)}(\pm i)=a_{i}r_{N}^{\rm true}(i)+b_{i},

(88)

with cycle‑independent coefficients
a_{i}
and
b_{i}
. We note that this assumption can be in conflict with the strategy of consecutive stabilizer readouts and a final Pauli frame update, as the projected states at each intermediate QEC cycle can lie in different stabilizer subspaces and, in principle, be subject to different effects of noise, e.g., in the case of logical AD.

For preparation in the
\pm 1
eigenstate of
\sigma_{i}
we take
r_{0}^{\rm true}(i)=\pm 1
.
Write
Eq.

88
for
m_{i}^{\mathrm{obs}(N+1)}(\pm i)
, substitute
Eq.

86
, and replace
r_{N}^{\rm true}(i)
using
Eq.

88
. This yields

m_{i}^{\mathrm{obs}(N+1)}(\pm i)=\eta_{i}m_{i}^{\mathrm{obs}(N)}(\pm i)+\bigl[a_{i}t_{i}+(1-\eta_{i})b_{i}\bigr].

(89)

We can use this to derive a linear recurrence for
\overline{p}_{N,\alpha}
.

Equation

65
still applies, and can be written as

\overline{p}_{N,\alpha}=\frac{1-s(\alpha)M_{N}(\alpha)}{2}

(90)

with

M_{N}(\alpha)\equiv m_{h(\alpha)}^{\mathrm{obs}(N)}(s(\alpha)h(\alpha)).

(91)

Thus, using
Eq.

89
:

\displaystyle M_{N+1}(\alpha)

\displaystyle\equiv m_{h(\alpha)}^{\mathrm{obs}(N+1)}(s(\alpha)h(\alpha))

(92a)

\displaystyle=\eta_{h(\alpha)}M_{N}(\alpha)+\bigl[a_{h(\alpha)}t_{h(\alpha)}+(1-\eta_{h(\alpha)})b_{h(\alpha)}\bigr]

(92b)

Using
Eq.

90
in the form
\overline{p}_{N+1,\alpha}=\frac{1-s(\alpha)M_{N+1}(\alpha)}{2}
and
M_{N}(\alpha)=(1-2\overline{p}_{N,\alpha})/s(\alpha)
, we obtain

\displaystyle\overline{p}_{N+1,\alpha}

\displaystyle=\frac{1}{2}\Bigl(1-s(\alpha)\Bigl[\eta_{h(\alpha)}M_{N}(\alpha)

\displaystyle\quad+a_{h(\alpha)}t_{h(\alpha)}+(1-\eta_{h(\alpha)})b_{h(\alpha)}\Bigr]\Bigr)

(93a)

\displaystyle=\eta_{h(\alpha)}\overline{p}_{N,\alpha}+\varepsilon_{\alpha}.

(93b)

This difference equation is in the standard inhomogeneous first‑order form, with

\varepsilon_{\alpha}\equiv\frac{1-\eta_{h(\alpha)}-s(\alpha)\left[a_{h(\alpha)}t_{h(\alpha)}+(1-\eta_{h(\alpha)})b_{h(\alpha)}\right]}{2}

(94)

a constant independent of
N
.
The solution of
Eq.

93
is

\displaystyle\overline{p}_{N,\alpha}

\displaystyle=a_{\alpha}+b_{\alpha}\Bigl(1-\frac{\varepsilon_{\alpha}}{a_{\alpha}}\Bigr)^{N}

(95a)

\displaystyle a_{\alpha}

\displaystyle=\frac{\varepsilon_{\alpha}}{1-\eta_{h(\alpha)}}

(95b)

\displaystyle b_{\alpha}

\displaystyle=\overline{p}_{0,\alpha}-a_{\alpha},

(95c)

which is exactly the three-parameter fitting model
Eq.

5
of the main text. We note that, in the following section, we derive this solution from
the expected update of the logical error probabilities in consecutive QEC cycles.

From here we can obtain the explicit parameters in the
X/Z+
GAD
+
SPAM case.
For
\alpha\in\{+,-\}
we have
h(\alpha)=x
,
s(\pm)=\pm 1
,
\eta_{x}=\zeta\sqrt{1-\gamma}
, and
t_{x}=0
[
Eq.

87a
], so using
Eq.

95b

\varepsilon_{\alpha}=a_{\alpha}\bigl(1-\zeta\sqrt{1-\gamma}\bigr),

(96)

and using
Eq.

94
:

\displaystyle a_{\alpha}

\displaystyle=\frac{\varepsilon_{\alpha}}{1-\eta_{x}}=\frac{1-\eta_{x}-s(\alpha)(1-\eta_{x})b_{x}}{2(1-\eta_{x})}

(97a)

\displaystyle=\frac{1-s(\alpha)b_{x}}{2}.

(97b)

For
\alpha\in\{0,1\}
we have
h(\alpha)=z
,
s(0)=+1
,
s(1)=-1
,

\eta_{z}=\xi(1-\gamma)
, and
t_{z}=\xi\gamma u
[
Eq.

87b
], so similarly, using
Eq.

95b

\varepsilon_{\alpha}=a_{\alpha}\bigl[1-\xi(1-\gamma)\bigr],

(98)

and using
Eq.

94

\displaystyle a_{\alpha}

\displaystyle=\frac{\varepsilon_{\alpha}}{1-\eta_{z}}

(99a)

\displaystyle=\frac{1-\eta_{z}-s(\alpha)\left[a_{z}t_{z}+(1-\eta_{z})b_{z}\right]}{2(1-\eta_{z})}

(99b)

\displaystyle=\frac{1}{2}\left(1-s(\alpha)\left[b_{z}+\frac{a_{z}t_{z}}{1-\eta_{z}}\right]\right).

(99c)

As for
b_{\alpha}
, at
N=0
we take
m_{i}^{\mathrm{true}(0)}(\pm i)=\pm 1
.
Hence, using
Eqs.

64
and
91

M_{0}(\alpha)=m_{h(\alpha)}^{\mathrm{obs}(0)}\bigl(s(\alpha)h(\alpha)\bigr)=a_{h(\alpha)}s(\alpha)+b_{h(\alpha)}.

(100)

Substituting this into
Eq.

90
gives

\displaystyle\overline{p}_{0,\alpha}=\frac{1-s(\alpha)M_{0}(\alpha)}{2}=\frac{1-a_{h(\alpha)}-s(\alpha)b_{h(\alpha)}}{2},

(101)

where we used
s(\alpha)^{2}=1
.
By definition,
b_{\alpha}=\overline{p}_{0,\alpha}-a_{\alpha}
[
Eq.

95c
],
so that in both cases

b_{\alpha}=\frac{1}{2}\Bigl[1-a_{h(\alpha)}-s(\alpha)b_{h(\alpha)}\Bigr]-a_{\alpha},

(102)

which is fixed by the measured
N=0
point, and reduces to

in the absence of SPAM. More generally,

is the initial offset from the steady-state value
a_{\alpha}
and sets the amplitude of the transient relaxation to this steady state.

E.6.6
Recovering
(a_{\alpha},b_{\alpha},\varepsilon_{\alpha})
from the measured
\overline{p}_{N,\alpha}

Let us write the stationary three-parameter model in the form

\overline{p}_{N,\alpha}=a_{\alpha}+b_{\alpha}q_{\alpha}^{N},\quad q_{\alpha}\equiv 1-\frac{\varepsilon_{\alpha}}{a_{\alpha}}.

(103)

Assume that this holds for all
N\geq 0
and note that since
\overline{p}_{N,\alpha}
is a probability, we must have
0\leq q_{\alpha}\leq 1
. Define

\delta p_{N}^{(\alpha)}\equiv\overline{p}_{N+1,\alpha}-\overline{p}_{N,\alpha}.

(104)

Then
\delta p_{N}^{(\alpha)}=b_{\alpha}(q_{\alpha}-1)q_{\alpha}^{N}
, so the ratio of successive differences is constant for any
N\geq 0
with
\delta p_{N}^{(\alpha)}\neq 0
:

q_{\alpha}=\frac{\delta p_{N+1}^{(\alpha)}}{\delta p_{N}^{(\alpha)}}=\frac{\overline{p}_{N+2,\alpha}-\overline{p}_{N+1,\alpha}}{\overline{p}_{N+1,\alpha}-\overline{p}_{N,\alpha}}.

(105)

Once
q_{\alpha}
is known [e.g., by averaging
Eq.

105
over
N
to reduce noise],
a_{\alpha}
and
b_{\alpha}
follow from any two consecutive
N\geq 0
points:

\displaystyle a_{\alpha}

\displaystyle=\frac{\overline{p}_{N+1,\alpha}-q_{\alpha}\overline{p}_{N,\alpha}}{1-q_{\alpha}}

(106a)

\displaystyle b_{\alpha}

\displaystyle=\frac{\overline{p}_{N,\alpha}-a_{\alpha}}{q_{\alpha}^{N}}.

(106b)

Finally, the logical error rate is

\varepsilon_{\alpha}=a_{\alpha}(1-q_{\alpha}).

(107)

Note that this implies
0\leq\varepsilon_{\alpha}\leq 1
, confirming that
\varepsilon_{\alpha}
is a probability. Also note that by eliminating
b_{\alpha}
between the
N=0,1
versions of
Eq.

103
, we have

\overline{p}_{1,\alpha}=\varepsilon_{\alpha}+q_{\alpha}\overline{p}_{0,\alpha},

(108)

so that, without SPAM (i.e.,
\overline{p}_{0,\alpha}=0
), we obtain
\overline{p}_{1,\alpha}=\varepsilon_{\alpha}
. This means that the logical error rate
\varepsilon_{\alpha}
is just the error probability after a single cycle in the absence of SPAM.

Because
\delta p_{N}^{(\alpha)}
can be small and noisy, a robust estimator is to compute
q_{\alpha}
by a linear fit of

\log|\delta p_{N}^{(\alpha)}|
versus
N
:

\log|\delta p_{N}^{(\alpha)}|=\mathrm{const}+N\log|q_{\alpha}|,

(109)

using only indices with
\delta p_{N}^{(\alpha)}\neq 0
. We can then obtain
a_{\alpha}
from

Eq.

106a
by least squares over all
N
, and finally

\varepsilon_{\alpha}
from
Eq.

107
.

Equation

103
imposes the constraint that for each
\alpha
, the quantities on the r.h.s. in
Eqs.

105
and
106
are independent of
N
. In fact, note that using
Eq.

95b
, we have

q_{\alpha}\equiv 1-\frac{\varepsilon_{\alpha}}{a_{\alpha}}=\eta_{h(\alpha)}
. Therefore,

q_{+}=q_{-}=\eta_{x},\quad q_{0}=q_{1}=\eta_{z}.

(110)

Moreover, using
Eq.

97b
with
s(\pm)=\pm 1
, and similarly using
Eq.

99c
with
s(0)=+1
and
s(1)=-1
, we have

a_{+}+a_{-}=a_{0}+a_{1}=1.

(111)

These are testable predictions of the stationary (cycle-independent noise) model. A plot of the quantities on the r.h.s. in
Eqs.

106
and
107
is given in

,
17
and
18
. The deviation from constancy and the constraints in

and

(112d)

E.7
Difference equation and three fitting models

E.7.1
Derivation of
Eq.

95a
via a difference equation

As noted in the previous subsection, we can derive the three-parameter fitting model
Eq.

95a
by generalizing the ad hoc assumptions of the difference equations for the logical error rates in consecutive QEC cycles briefly discussed in
Google Quantum AI and collaborators 2024
.

We assume that logical errors are incoherent and, moreover, independent between consecutive QEC cycles. This gives a recursive expression for the logical error probability after
N
cycles, considering a quantum memory encoded in the
\alpha\in\{0,1,+,-\}
basis:

\overline{p}_{N+1,\alpha}=\bigl(1-\beta_{\alpha}\bigr)\overline{p}_{N,\alpha}+\varepsilon_{\alpha}\bigl(1-\overline{p}_{N,\alpha}\bigr),

(114)

where
\varepsilon_{\alpha}
is the per-cycle logical error rate, and
\beta_{\alpha}
is the per-cycle recovery rate (we use the term “rate” since these are per-cycle quantities, even though both quantities are dimensionless probabilities). That is,
\varepsilon_{\alpha}
represents the probability that a QEC cycle causes a logical error in the logical
\alpha
-basis state, and
\beta_{\alpha}
is the probability of recovering from a previous logical error.
This inhomogeneous first-order linear difference equation can be solved exactly to yield
Eq.

95a
,
with
a_{\alpha}={\varepsilon_{\alpha}}/({\varepsilon_{\alpha}+\beta_{\alpha}})
(assuming
\varepsilon_{\alpha}+\beta_{\alpha}<1
to ensure convergence), and an integration constant
b_{\alpha}
.

For example, if logical errors arise solely from a non-unital amplitude damping channel with dimensionless error rate
\gamma=1-\exp(-\Gamma t)=1-\exp(-t/T_{1})
at the logical level, then for an initial state
\overline{\ket{1}}
that decays under the channel, we have
\beta_{1}=0
and
\varepsilon_{1}=\gamma
, leading to
a_{1}=\lim_{N\to\infty}\overline{p}_{N,1}=1
. In contrast, if the initial memory state is
\overline{\ket{0}}
, which is unaffected by logical amplitude damping, then
\beta_{0}=\gamma
and
\varepsilon_{0}=0
, resulting in
a_{0}=\lim_{N\to\infty}\overline{p}_{N,0}=0
.

Our derivation above is based on reasoning about the effect of non-Pauli errors such as amplitude damping at the logical level, as well as the generic effect of SPAM errors at the logical level.
The derivation of
Eq.

95a
from a CPTP map model in
Section

E.6.5
is significantly longer and more elaborate, but it provides explicit expressions for the phenomenological parameters
(a_{\alpha},\beta_{\alpha},\varepsilon_{\alpha})
in terms of the parameters of the CPTP map, which assumes
X
and
Z
Pauli errors, generalized amplitude damping, and SPAM errors.

E.7.2
Assessment of the three fitting models using the Akaike Information Criterion

We now identify the additional assumptions that need to be made to arrive at previous logical-error fitting models
Google Quantum AI and collaborators 2021
;
Google Quantum AI and collaborators 2023
;
Google Quantum AI and collaborators 2024
.
If logical SPAM errors are neglected, then
\overline{p}_{N=0,\alpha}=0
, since in that case the quantum memory at
N=0
cycles has not had time to accumulate any errors from the environment or the controls. This sets
b_{\alpha}=-a_{\alpha}
and therefore, without SPAM, the logical error probability reduces to a two-parameter model

\overline{p}_{N,\alpha}=a_{\alpha}(1-\bigl(1-\varepsilon_{\alpha}/a_{\alpha}\bigr)^{N}).

(115)

The asymptotic limit
a_{\alpha}=\lim_{N\to\infty}\overline{p}_{N,\alpha}
is entirely determined by the ratio between
\varepsilon_{\alpha}
and
\beta_{\alpha}
, which itself depends on the noise channel and the initial state. Assuming a logical Pauli channel, then if the same Pauli error occurs twice, it cancels out. Therefore, the recovery and error rates must be equal regardless of the initial encoded state, i.e.,
\beta_{\alpha}=\varepsilon_{\alpha}
. In this case,
a_{\alpha}=\lim_{N\to\infty}\overline{p}_{N,\alpha}=1/2
giving

\overline{p}_{N,\alpha}=\frac{1}{2}-\frac{1}{2}\bigl(1-2\varepsilon_{\alpha}\bigr)^{N},

(116)

which coincides with the single-parameter exponential fitting model of Refs.
Google Quantum AI and collaborators 2021
;
Google Quantum AI and collaborators 2023
;
Google Quantum AI and collaborators 2024
. Hence,
the latter assume a logical Pauli channel with independent logical errors per QEC cycle and no SPAM.

Equation

116
corresponds to the probability of having an odd number of errors after
N
rounds
O’Brien et al. 2017
, and also agrees with the (infinite-temperature) steady state of unital channels
Lidar 2020
.

An obvious requirement for estimating the error suppression factor
\Lambda_{\varepsilon}^{d}
from the per-cycle logical error rate,
\varepsilon_{d}
, is to infer the latter from the experimental data of consecutive QEC cycles on a quantum memory benchmark. This can be achieved through a fitting procedure considering some of the above expressions; and different experiments have employed varying fitting strategies, focusing on the single-parameter fitting model. For example, Ref.
Google Quantum AI and collaborators 2021
fits the logical error rate to an exponential decay, while Ref.
Google Quantum AI and collaborators 2023
fits the logical fidelity to an exponential. In contrast, Ref.
Google Quantum AI and collaborators 2024
applies a logarithmic-scale fit to the logical fidelity. These differences reflect a clear dependence on the nature of the data, with fitting choices somewhat arbitrarily tailored to optimize interpretability or accuracy in a given experimental context.

Rather than making an arbitrary choice, we fit our data to the one-, two-, and three-parameter versions of
Eqs.

116
,
115
and
95a
, respectively. To make an unbiased selection, we then evaluate the quality of each fit by computing and comparing their Akaike Information Criterion (AIC)
Akaike 1974
scores. The AIC estimates the relative quality of statistical models by balancing the accuracy of fit against model complexity, penalizing models with more free parameters to avoid overfitting. A lower AIC value indicates a more parsimonious fit.
Fig.

19
shows the resulting AIC scores of the three different models.

We find that the AIC score for each fit varies depending on the code, measurement basis, and sublattice. Although in some instances the AIC scores for the three models fall within a similar range, in most cases the three-parameter model clearly yields the best result. This implies the presence of both logical SPAM errors and logical AD, which violates the assumptions underlying the single- and two-parameter models.
While AIC prefers a stationary three‑parameter model (indicative of non‑unital features and SPAM when stationarity is enforced), the EF analysis, which allows cycle‑dependence and removes SPAM, shows the EF tracks its Pauli lower bound closely (
Fig.

15
). Thus, any effective non‑unital component (e.g., logical AD) is subdominant for the EF in our datasets. We therefore rely on EF, rather than stationary fits, to assess subthreshold behavior.

Appendix F
Error budget from coherent errors

In addition to decoherence, other error mechanisms, particularly coherent errors introduced by single- and two-qubit gates used in QEC circuits, can significantly impact code performance. These coherent errors have been extensively studied in the context of surface codes
Marton and Asbsth 2023
. Recent experimental work has shown that for single-qubit gates, such errors can be effectively characterized using
deterministic benchmarking
(DB)
Tripathi et al. 2025
, a technique that amplifies coherent errors using a small set of DD-like experiments, drastically reducing the effort required to make such errors detectable compared to randomized benchmarking
Knill et al. 2008
;
Magesan et al. 2011
, which often misses them entirely.

For a single-qubit transmon, coherent errors are most simply modeled as arising from a driven two-level system, analyzed in the drive frame under the rotating wave approximation. Letting
\{\sigma_{i}\}
represent the set of Pauli matrices, the time-dependent system Hamiltonian generating single-qubit
X
rotation gates is given by:

\displaystyle H(t)

\displaystyle=\varepsilon_{\mathrm{tot}}(t)\frac{\sigma_{x}}{2}+H_{\mathrm{err}},

(117a)

\displaystyle H_{\mathrm{err}}

\displaystyle=\varepsilon_{\mathrm{err}}\frac{\sigma_{x}}{2}+\Delta_{\mathrm{err}}\frac{\sigma_{z}}{2}.

(117b)

Here,
\varepsilon_{\mathrm{tot}}(t)
is the intended time-dependent control field and
\varepsilon_{\mathrm{err}}
and
\Delta_{\mathrm{err}}
are errors. Ideally,
\varepsilon_{\mathrm{err}}=\Delta_{\mathrm{err}}=0
. In reality, both are present and give rise to rotation and phase errors

\delta\theta\equiv\varepsilon_{\mathrm{err}}t_{g}\ ,\quad\delta\varphi\equiv\frac{\Delta_{\mathrm{err}}}{\bar{\varepsilon}}=\frac{1}{\theta}\Delta_{\mathrm{err}}t_{g}

(118)

respectively, with
t_{g}
denoting the gate duration,

\theta\equiv\int_{0}^{t_{g}}\varepsilon_{\mathrm{tot}}(t)dt,

(119)

and
\bar{\varepsilon}=\theta/t_{g}
the
average pulse amplitude. An open system single-qubit gate includes both rotation and phase errors, as well as a system-bath interaction term that is always present while the gate is being generated. Ref.
Tripathi et al. 2025

identified simple DD sequences that are susceptible either to phase errors
or to rotation errors. Such sequences can be used to deterministically detect the presence of these errors (in contrast to randomized benchmarking).

Two-qubit gates, in our case, are
CZ
gates implemented using tunable couplers
Stehlik et al. 2021
. The effective Hamiltonian governing these gates is given by:

H_{\mathrm{CZ}}=\frac{\pi}{4}(ZZ-IZ-ZI).

(120)

Each component of this Hamiltonian may be susceptible to coherent errors, and a full investigation of their interplay in
CZ
gates is beyond the scope of this work. For the present discussion, it suffices to note that repeated application of the
CZ
gate amplifies coherent errors, leading to characteristic oscillation patterns, as demonstrated in Ref.
Kjaergaard et al. 2022
.

As an example, we study the effects of these single- and two-qubit coherent errors on qubits 21 and 22 of
ibm_marrakesh
.

G.1

Ref.

\varepsilon_{N,\alpha}=\frac{1}{2}-\frac{1}{2}\bigl(1-2\overline{p}_{N,\alpha}\bigr)^{N},

\Lambda^{\bm{d}}_{\varepsilon_{N,\alpha}}=\varepsilon_{N,\alpha}^{(3,3)}/\varepsilon_{N,\alpha}^{\bm{d}}

Eq.

121
implicitly imposes several assumptions about the experimental setup (see
Section

E.7
). In contrast,
\Lambda^{\bm{d}}_{p,\alpha}(N)
depends solely on empirical data from each experiment.

Appendix H
Simulating a distance-5 code

As we reported, we observed subthreshold behavior when scaling the surface code for a single error type. We evaluated the logical error probabilities of a
(3,3)
code against a
(3,5)
(
(5,3)
) code and found enhanced performance against phase flip (bit flip) errors. On the other hand, we found an expected decrease of the protection against bit flip (phase flip) errors, as the
(3,5)
(
(5,3)
) code is not scaled in that direction, and hence degrades from the increased complexity of the circuits. To achieve universal subthreshold behavior, it is necessary for logical error rates to be concurrently reduced for both error types, thereby increasing the protection of any logical state. This necessitates a
(5,5)
code, which is infeasible with the qubit-count and connectivity of current IBM QPUs.

In light of this, we instead turn to numerical simulations of a
(5,5)
code, comparing its performance to that of the
(3,3)
code. This task requires an accurate noise model that matches the experimental results. However, individual per-qubit error probabilities are currently unavailable at the scale of the
(5,5)
code. Instead, we can use a noise model in which all physical qubits have identical performance, set to the median performance of all qubits in the device, as per
Eq.

8
. However, we find that the noise model defined in this way does not agree with our experimental data for the smaller codes. To mitigate this, we multiply all error probabilities appearing in the Pauli channels of the noise model by a scaling factor
\chi
.
In doing so, we obtain a noise-scaled model with
p_{i}\rightarrow\chi p_{i}
,
p_{ij}\rightarrow\chi p_{ij}
for all noise channels. In order to determine
\chi
, we perform numerical simulations to find the optimal value that maximizes the agreement with the experimental data.

~50\%

Zhou et al. 2025

Tripathi et al. 2025
