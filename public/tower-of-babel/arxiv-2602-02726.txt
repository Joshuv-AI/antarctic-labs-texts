Vector Quantized Latent Concepts: A Scalable Alternative to Clustering-Based Concept Discovery
Xuemin Yu, Ankur Garg, Samira Ebrahimi Kahou, Hassan Sajjad

Abstract
Deep Learning models encode rich semantic information in their hidden representations. However, it remains challenging to understand which parts of this information models actually rely on when making predictions. A promising line of post-hoc concept-based explanation methods relies on clustering token representations. However, commonly used approaches such as hierarchical clustering are computationally infeasible for large-scale datasets, and K-Means often yields shallow or frequency-dominated clusters. We propose the vector quantized latent concept (VQLC) method, a framework built upon the vector quantized-variational autoencoder (VQ-VAE) architecture that learns a discrete codebook mapping continuous representations to concept vectors. We perform thorough evaluations and show that VQLC improves scalability while maintaining comparable quality of human-understandable explanations.



Figure 1
:
Architecture overview: Contextual token representations extracted from a deep learning model are first passed through an adaptive residual encoder to preserve the semantic structure of the input while enabling stable vector quantization. The adaptive representations are then fed into a vector quantizer, where each token is assigned to its nearest codebook vector to obtain a quantized representation. Finally, a decoder reconstructs the contextual representations from the quantized codebook vectors.

1
Introduction

Current deep learning models are trained on trillions of tokens, achieving impressive capabilities but also making it challenging to understand their internal representations and model’s prediction
(
38
;
20
;
42
)
. These models often work as a “black box” where the relationship between inputs and outputs becomes increasingly opaque and difficult to interpret
(
9
;
41
)
. Previous research has attempted to explain these models using
input attribution
methods
(
36
;
44
;
43
;
32
)
. However, explanations based solely on input tokens cannot adequately represent the high-level semantic information encoded within the model’s hidden states.

Another line of work aims to interpret deep learning models through
latent concepts extracted from representations

(
24
;
13
;
7
;
22
;
53
;
52
;
26
;
40
)
. The main idea is that contextualized representations capture different facets of a word, and these facets are referred to as
concepts

(
7
)
. Most of these approaches use clustering to identify concepts in the representation space. For instance,
latent concept attribution (LACOAT)
, proposed by
52
, applies agglomerative hierarchical clustering to token representations to identify semantic concepts. While hierarchical clustering is effective in capturing meaningful concepts, it has a high computational cost, making it impractical for large-scale datasets.
Alternatively, K-Means is another widely used clustering method that is more efficient but relies on Euclidean geometry. Recent work by
34
suggests that the latent representation spaces learned by deep learning models may exhibit non-Euclidean structures. Also,
21
notes that K-Means tends to force distinct outliers into spherical clusters, introducing noise and reducing the interpretability of the discovered concepts.

To solve these issues, we propose the Vector Quantized Latent Concept (
VQLC
) method, which
directly maps continuous representations onto a discrete, learnable codebook, enabling a conceptual interpretation of the model’s internal representations. We hypothesize that each codebook vector serves as a latent concept vector, with input tokens assigned to the same vector collectively forming a latent concept. Given a test instance,
VQLC
maps salient input token representations to these codebook vectors, revealing the latent concepts that the model relies on for its prediction.

We conduct an extensive evaluation comparing hierarchical clustering, K-Means clustering, and
VQLC
to analyze their strengths and limitations in latent concept discovery.
We observe that hierarchical clustering produces label-aligned concepts, but their quadratic complexity prevents them from scaling to large datasets. In contrast, while K-Means is computationally efficient, it often yields shallow or frequency-dominated concepts. Our results demonstrate that
VQLC
strikes a balance, achieving scalability while maintaining comparable performance in generating human-understandable explanations.

2
Problem Formulation

We consider a deep learning model
\mathbb{M}
with
l\in L
layers. Given an input instance
s={w_{1},w_{2},...,w_{N}}
, the contextual representation of a token
w_{i}
in layer
l
is denoted

h_{w_{i}}^{(\ell)}
. Let
H^{(\ell)}
denote the set of all contextual representations extracted from the layer
l
in the training dataset
\mathbb{D}
.
Our goal is to learn a discrete set of latent concept vectors:

\displaystyle\mathcal{V}=\{v_{1},\dots,v_{K}\},

where each contextual representation
h_{w_{i}}^{(\ell)}\in H^{(\ell)}
is assigned to one latent concept vector
v_{k}\in\mathcal{V}
.

We define a set of latent concepts as

\mathcal{C}=\{c_{1},\dots,c_{K}\}
,
where each latent concept
c_{k}
is defined as the collection of tokens whose contextual representations are mapped to the same latent concept vector
v_{k}
at the end of training. Tokens assigned to the same latent concept vector are expected to encode similar semantic facets. At inference time, for a given test instance, the latent concept associated with the salient token is used as the explanation of the model’s prediction.

3
Methodology

The architecture of
VQLC
follows the
VQ-VAE
framework
(
49
)
, which consists
of three main modules:

•

Encoder
: A lightweight single-layer encoder with a learnable residual mixing mechanism that projects to a representation space for stable vector quantization.

•

Vector Quantizer
: A mapping from the encoder output representation space to a set of learnable codebook vectors.

•

Decoder
: A decoder that reconstructs the contextual representations from the quantized codebook vectors.

As Figure
1
shows,
VQLC
provides latent concept explanations for a chosen layer of the model. For each instance in a training dataset, we extract the contextual representations at the target layer from the model. These representations are passed through an encoder that is trained to preserve their semantic distribution while adaptively adjusting them to a space that is more suitable for stable codebook learning, as supported by a sensitivity analysis in Appendix
F
. The resulting representations are quantized and assigned to their nearest codebook vectors, which are updated during training using the
exponentially moving average (EMA)
method. At inference time, we identify the salient input token and use the codebook vector assigned to it as the latent concept explanation for the model’s prediction.

3.1
Encoder

We employ an adaptive residual encoder consisting of a linear layer and an adaptive residual connection (Equation
1
). The residual connection preserves the semantic structure of the original contextual representations, ensuring that the encoder output remains faithful to the model used for prediction or generation. The linear layer
provides controlled adjustment to the representation space, enabling the encoder output to support stable codebook learning. Let
h_{w_{i}}^{(\ell)}
denote the contextual representation of a token
w_{i}
extracted from layer
l
. The encoder outputs an adaptive representation
z_{e}(w_{i})
defined as:

\displaystyle\tilde{h}_{w_{i}}^{(\ell)}

\displaystyle=\operatorname{LN}(Wh_{w_{i}}^{(\ell)}+b),

(1a)

\displaystyle z_{e}(w_{i})

\displaystyle=(1-\alpha)h_{w_{i}}^{(\ell)}+\alpha\tilde{h}_{w_{i}}^{(\ell)},

(1b)

where
\alpha
is a learnable adaptive coefficient constrained to the range
(0,0.5)
to avoid excessive modification of the original representation.
W
and
b
are learnable parameters of the linear transformation, and
LN
denotes layer normalization.

3.2
Vector Quantizer

A vector quantizer uses a learnable codebook to assign each contextual representation generated from the encoder to its nearest codebook vector. The codebook contains
K
vectors, which are updated during training. We refer to the learned codebook vectors as latent concept vectors, denoted by
\mathcal{V}=\{v_{1},\dots,v_{K}\}
. Tokens mapped to the same codebook vector form the content of the corresponding concept.

Codebook Initialization

The codebook is initialized using K-Means clustering over token representations from the training dataset. Prior work indicates that density-based and spectral methods face limitations in high-dimensional spaces, while hierarchical clustering requires pairwise similarity computations that scale poorly with dataset size
(
21
)
. In contrast, K-Means is computationally efficient, and the linear growth of K-Means with respect to the number of representations makes it feasible to initialize a codebook
(
17
)
. These centroids serve as initial codebook vectors, providing a structured starting point that captures high-density regions of the representation space. This initialization yields better initial coverage of the data distribution compared to random initialization (See Appendix
I
).

Codebook Learning

We update the codebook using the
EMA
-based method proposed by
23
, which provides stable and smooth updates compared to the gradient-based approach. For each codebook vector
v_{j}
,
EMA
maintains both an accumulated usage frequency
n_{j}
and a moving average of the encoder outputs assigned to it.

The usage frequency of each vector
v_{j}
is calculated as:

\displaystyle n_{j}\leftarrow\lambda n_{j}+(1-\lambda)\sum_{i}\mathds{1}\left[z_{q}\left(w_{i}\right)=v_{j}\right],

(2)

where
z_{q}\left(w_{i}\right)
denotes the codebook vector assigned to token
w_{i}
,
\mathds{1}
is indicator function, and
\lambda
is a decay parameter.

The corresponding codebook vector
v_{j}
is updated towards the average of its assigned encoder outputs:

\displaystyle m_{j}

\displaystyle\leftarrow\lambda m_{j}+(1-\lambda)\sum_{i}\mathds{1}\left[z_{q}\left(w_{i}\right)=v_{j}\right]z_{e}(w_{i}),

(3)

\displaystyle v_{j}

\displaystyle\leftarrow\frac{m_{j}}{n_{j}},

(4)

where
z_{e}(w_{i})
is the encoder output representation of the token
w_{i}
. The decay parameter
\lambda
controls how much the codebook relies on the previous codebook state, and we set
\lambda=0.999
in the experiments.

Codebook Mapping

During quantization, we compute the cosine distance between each encoder output representation
z_{e}(w_{i})
and all codebook vectors:

\displaystyle D(z_{e}(w_{i}),v_{j})=1-\frac{z_{e}(w_{i})\cdot v_{j}}{\left\|z_{e}(w_{i})\right\|\,\left\|v_{j}\right\|}.

(5)

To mitigate codebook collapse and encourage exploration during training, we adopt a temperature-based sampling mechanism following
45
. We first select the top-k closest codebook vectors and convert their distances into a probability distribution using a softmax function with a temperature parameter. We then sample a codebook vector according to its probability (Equation
6
).

\displaystyle p(j|z_{e}(w_{i}))=\frac{\exp(-D(z_{e}(w_{i}),v_{j})/\tau)}{\sum_{j^{\prime}\in\text{top-}k}\exp(-D(z_{e}(w_{i}),v_{j^{\prime}})/\tau)},

(6)

where
\tau
is a temperature parameter to control the exploration level of the codebook vectors during the training.

At inference time, we assign each encoder output
z_{e}(w_{i})
to its nearest codebook vector. We obtain the index of the nearest codebook vector
j^{*}
, and then use the corresponding codebook vector
v_{j^{*}}
as the quantized representation:

\displaystyle j^{*}

\displaystyle=\arg\min_{j}D(z_{e}(w_{i}),v_{j}),

(7)

\displaystyle z_{q}(w_{i})

\displaystyle=v_{j^{*}}.

(8)

Latent Concept Content Extraction

Each learned codebook vector represents a latent concept vector. We group all tokens mapped to the same codebook vector, and the resulting token set forms the content of the latent concept. This grouping includes both words and representative classification tokens. We generally visualize the concept using wordcloud. For concepts dominated by representative classification tokens, we instead randomly sample five representative classification tokens (e.g.
[CLS]
) from the concept and display their original sentences.

During inference, we use a
latent concept assigned to the salient input token to explain the model’s prediction.
Following literature
(
52
)
,
we focus on the explanation using the last layer representation. For decoder-only models, the last token is treated as the salient token. While for encoder-based models, the representative classification token (e.g.
[CLS]
) is used. To extend the method beyond the last layer, we apply
integrated gradients (IG)

(
44
)
to select the token with the highest attribution score as the salient token. An additional analysis on the intermediate layer is reported in Appendix
M
.

3.3
Decoder

The decoder is used to reconstruct the original encoder output representations from the mapped quantized codebook vectors. It consists of three components: a linear down projection, a transformer encoder, and a linear up projection. Let
T
denote the sequence length. Given quantized vectors
z_{q}\in\mathbb{R}^{T\times d}
, we first apply a linear down projection to obtain projected quantized vectors
\tilde{z}_{q}\in\mathbb{R}^{T\times d^{\prime}}
:

\displaystyle\tilde{z}_{q}=z_{q}W_{d},\quad W_{d}\in\mathbb{R}^{d\times d^{\prime}},

(9)

where
W_{d}
projects original quantized vector from dimension
d
to a lower dimensional space
d^{\prime}
(
d^{\prime}\leq d
).
This design is inspired by
39
’s work, which employs linear layers to encode and decode features in a low-dimensional space while reducing computation and preserving useful information. For moderate-dimensional quantized vectors (e.g.,
d=768
), the projection functions are similar to linear adapters
(
18
)
, learning a linear change of basis to align the codebook space with the decoder’s feature space. We provide an ablation study in Appendix
H
to demonstrate the necessity of the linear projection. We then process the projected quantized vectors by a 4-layer transformer encoder to reconstructed quantized vectors
\tilde{H}
:

\displaystyle\tilde{H}=\text{Transformer}(\tilde{z}_{q}),

(10)

which captures contextual information across quantized vectors via self-attention. Finally, we apply a linear up projection to obtain the final reconstructed representations
\hat{z}_{e}\in\mathbb{R}^{T\times d}
:

\displaystyle\hat{z}_{e}=\tilde{H}W_{u},\quad W_{u}\in\mathbb{R}^{d^{\prime}\times d},

(11)

where
W_{u}
maps reconstructed quantized vectors
H
back to the original dimension. This ensures the reconstructed representations are aligned with the encoder output space for loss computation.

3.4
Training Objective

The overall training objective consists of two components, as shown in Equation
12
. The
reconstruction loss
trains the decoder to accurately reconstruct the encoder output representations. Because gradients propagate back to the encoder, this objective also shapes the encoder to generate representations that preserve contextual information and facilitate vector quantization. The
commitment loss
encourages the encoder outputs to remain close to their assigned code vectors, preventing them drifting away during training.

\displaystyle\mathcal{L}

\displaystyle=\mathcal{L}_{\textbf{rec}}+\beta\mathcal{L}_{\textbf{commit}}

(12)

\displaystyle\mathcal{L}_{\textbf{rec}}

\displaystyle=\left\|z_{e}(w_{i})-\hat{z}_{e}(w_{i})\right\|_{2}^{2}

(13)

\displaystyle\mathcal{L}_{\textbf{commit}}

\displaystyle=\left\|z_{e}(w_{i})-\operatorname{sg}\!\left[z_{q}(w_{i})\right]\right\|_{2}^{2},

(14)

where
\operatorname{sg}
is the stop-gradient operator, which prevents gradient updates on the codebook.
\beta
is used to control the strength of the commitment constraint. We set
\beta=0.25
in our experiments and had a sensitivity analysis of
\beta
in Appendix
D
.

Experiment Setup

We conduct experiments using three sequence classification tasks. We use the ERASER Movie Reviews dataset

)
for the sentiment classification task, the Jigsaw Toxicity dataset
(
4
)
for the toxic classification task, and the AG News dataset
(

)
for the multi-class news topic classification. The Appendix
B
provides detailed dataset information.

Models

We evaluate our method on two fine-tuned 12-layered pre-trained models, BERT-base-cased
(
8
)
and RoBERTa
(
31
)
, both finetuned on the training datasets. The fine-tuning performance is provided in Appendix

. In addition, we include two decoder-only
large language models (LLMs)
, Llama-2-7b-chat-hf
(

)
and Qwen2.5-3B
(

, which are evaluated in a zero-shot prompt setting.

Module-specific hyperparameters

We employ the NeuroX toolkit
(

)
to extract token activations for a given dataset. To facilitate a fair comparison with the method proposed by
52

, codebook size

Baselines

•

LACOAT

(
52
)
: uses agglomerative hierarchical clustering to discover latent concepts and trains a classifier to map tokens to concepts. Latent concept vectors are computed by averaging token representations within a cluster. This baseline tests whether
VQLC
achieves comparable concept quality with better scalability.

•

K-Means
: applies K-Means clustering directly to token representations to obtain concepts, and assigns tokens to the nearest concept vector using cosine similarity at inference. This baseline assesses whether
VQLC
improves the interpretability of K-Means.

Given that both
VQLC
and K-Means are sensitive to initialization seeds, we conduct the experiments using three different random seeds and report their best performance.

Evaluation

LACOAT
(

on the scalability axis to compare the practicality of both approaches. Moreover, we perform
a faithfulness evaluation, a

-based evaluation, and a qualitative evaluation to assess the faithfulness, and interpretability of
VQLC
. Prior works have found that the last layer contains the most task-aligned representation
(
2
;
37
;

)
. Our experiments focus on the explanations extracted from the last layer.

Scalability Evaluation

We evaluate scalability by comparing the computational cost of the
LACOAT

VQLC
method. Experiments are conducted on five dataset sizes, with the number of tokens set to
10k
,
50k
,
100k
,
200k
, and
300k
. Each token representation is a 2048-dimensional vector. We use peak memory usage as the computational cost metric. Since two methods are designed to run on different devices, we record both peak CPU and GPU memory. The maximum memory allocated to run is
512\text{GB}
.

Figure
2
illustrates the peak memory usage during the latent concept discovery phase for both methods. The results demonstrate that
VQLC
provides a memory efficiency advantage over
LACOAT
, particularly when scaling to larger datasets. The memory consumption of
LACOAT
grows nearly quadratically with respect to the number of tokens. It consumes around
300\text{GB}
for
200k
tokens and exceeds the
512\text{GB}
limits before reaching
300k
tokens, triggering an
out-of-memory (OOM)
error. This indicates the practical limitation of
LACOAT
in handling large-scale datasets with limited memory resources. In contrast,
VQLC
shows a stable and modest increase in memory consumption. Even at
300k
tokens, the peak memory usage remains around
50\text{GB}
, which is substantially lower than the
512\text{GB}
capacity. These results indicate that
VQLC
effectively mitigates the scalability issue.

Beyond empirical memory usage, these methods differ fundamentally in computational complexity.
LACOAT
relies on hierarchical clustering, which requires computing and storing all pairwise distances. This leads to
O(N^{2})
memory and time cost, where
N
is the number of tokens. In contrast,
VQLC
uses K-Means to initialize the codebook. K-Means has
O(NKT)
complexity, where
K
is the codebook size and
T
is the number of K-Means iterations.
VQLC
then assigns each token to its nearest codebook vector with
O(NK)
cost. Since both
K
and
T
are fixed constants, the concept discovery of
VQLC
scales nearly linearly with
N
, which enables
VQLC
to handle large-scale datasets.

5.3
LLMs
-Based Evaluation

To assess the interpretability of the discovered latent concept, we employ
LLMs
to judge how well each method’s concept explains the model’s prediction. For each test instance, we provide the sentence, ground-truth label, predicted label, and concept contents generated by
VQLC
,
LACOAT
, and K-Means. The
LLM
evaluators rank the latent concepts of each method from 1 to 3 based on its’ relevance
to
model’s prediction. We mitigate any potential position bias by randomly shuffling the order with which the latent concepts of each method are input to the
LLMs
. The same rank can be assigned to multiple methods. The final rank for each sample is determined by majority vote across three
LLM
evaluators. We report the average rank over all samples. We also measure inter-LLM agreement on the ranking decisions by Krippendorff’s Alpha
(
25
)
. Details of the ranking metric are provided in Appendix
K
.

We use three
LLMs
: Claude 3.5 Haiku, Gemini 2.0 Flash, and DeepSeek Chat
(
30
)
, and evaluate 50 samples per dataset. Latent concepts are presented in two formats to handle
concepts that
may contain both words, special tokens including sentence tokens like
[CLS]
or both. When a concept is dominated by special tokens (more than half), we randomly sample five tokens and use their original sentences. Otherwise, we provide the ten most frequent tokens due to the API context length limitations. Prompt templates are provided in Appendix
L
.

Table
2
reports the average rank (top) and agreement scores (bottom).
LACOAT
achieves lower rank values than other methods in most settings, with average values around
1.4
on AG news and Jigsaw toxicity datasets, indicating that it is usually ranked first. Compared to K-Means,
VQLC
obtains lower average ranks in nearly all settings, typically ranked second, demonstrating
improved concept interpretability compared to K-Means. The inter-
LLM
agreement ranges from
Moderate
to
Reliable
for encoder-based models and
Fair
to
Moderate
for decoder-only models, demonstrating that
LLM
evaluators provide consistent ranking judgments. The difference of trend compared to probing-based faithfulness aligns with our hypothesis in Section
5.2
that K-Means tends to settle the centroids in dense regions of the representations. Although such centroids can influence task performance, they do not necessarily correspond to semantically meaningful and human-interpretable concepts.

Early interpretability methods focused on attributing input features to predictions, such as
IG

(

)
, smoothGrad
(

, SHAP
(

, and LIME
(

. Former concept-based works like TCAV
(
24
)
and CEBab
(
1
)
interpret models using human-defined concepts, while later works like ACE
(
13
)
automatically discover concepts via clustering. More recent methods extract the latent concepts directly from hidden representations to enable higher-level semantic explanations
(
35
;
7
;

;

;
52
;
26
;
40
)
.

Motivated by the superposition hypothesis,
Sparse Autoencoders (SAE)
have recently become a popular tool in mechanistic interpretability
(
5
;
16
;
47
;
27
)
to decompose representations into sparse feature directions
(
10
)

VQ-VAE

(
49
)
learns discrete latent representations via a finite codebook, enabling a natural discretization of the feature space. Prior works has mainly applied it to representation learning and compression
(

;
15
;
51
;
3

19

. We instead adopt it for latent concept discovery in
LLM
interpretability.

7
Conclusion

This work introduced
VQLC
, a vector quantization-based framework for latent concept discovery. We performed a thorough comparative study comparing it with commonly used clustering based methods for concept discovery. Our results suggested that hierarchical clustering-based concept discovery methods such as
LACOAT
remain effective on small- to medium-sized datasets (fewer than
100k
tokens). They can recover coarse-level and label-aligned concepts. However, their
O(N^{2})
memory and time complexity make them impractical for large-scale datasets. In contrast,
VQLC
scales near-linearly with respect to the number of tokens, enabling efficient concept discovery on large datasets. Moreover, both
LLMs
-based evaluation and qualitative evaluation highlight the necessity of the codebook training. Unlike K-Means,
VQLC
generates more interpretable and fine-grained concepts by leveraging vector quantization. Overall,
VQLC
provides a scalable approach for generating latent concept-based explanations, offering a balance of scalability, faithfulness, and plausibility.

8
Limitation

A limitation of the
VQLC
method is its reliance on K-Means initialization. Since K-Means clustering is sensitive to the random seed, the initial codebook centroids would differ across runs, which leads to differences in the discovered centroids. A more robust initialization may further improve the VQLC performance.
The other major limitation is that this method introduces additional hyperparameters, such as the commitment loss weight and codebook size, which need to be tuned carefully to ensure stable codebook learning. Finally, the current study focuses on classification tasks. Since generative models rely on token-by-token generation and reasoning, understanding the model generation steps by latent concept-based explanation is an essential direction for future work.

Impact

This paper advances the field of model interpretability for large language models. While general concerns about AI interpretability exist (e.g., incomplete or incorrect explanations, potential misuse of the approach’s insights), our approach focuses on the theoretical foundations of concept discovery and operates at a scale that poses no specific risks.

Appendix J
Faithfulness Evaluation: Orthogonal Projection for Concept Ablation

To measure whether a concept vector encodes a direction that the underlying model relies on for prediction, we remove the salient latent concept from a sentence representation via orthogonal projection. Given a salient latent concept vector
v_{j}
from the codebook and a sentence representation
h_{w_{i}}^{(\ell)}
, the projection of
h_{w_{i}}^{(\ell)}
onto
v_{j}
is defined as:

\displaystyle\operatorname{proj}_{v_{j}}\!\left(h_{w_{i}}^{(\ell)}\right)

\displaystyle=\frac{h_{w_{i}}^{(\ell)}\cdot v_{j}}{\lVert v_{j}\rVert^{2}}\,v_{j}

(15)

This projection isolates the component of the representation that aligns with the concept direction.

To remove this concept direction, we subtract the projection from the original representation:

\displaystyle h_{w_{i},\perp}^{(\ell)}

\displaystyle=h_{w_{i}}^{(\ell)}-\operatorname{proj}_{c_{j}}\!\left(h_{w_{i}}^{(\ell)}\right)

(16)

The resulting representation
h_{w_{i},\perp}^{(\ell)}
preserves information of the original representation except for the contribution along the concept direction.

Appendix K
LLMs
-Based Evaluation: Average Ranking Formula

Let
S
denote the set of samples,
A
the set of method approaches, and
E
the set of the
LLM
evaluators. For each sample
i\in S
, each evaluator
e
assigns a ranking value
r^{(e)}_{i,a}\in\{1,2,3\}
for each method
a\in A
. For each sample
i
and method
a
, we have an aggregated rank value
\hat{r}_{i,a}
by the majority of votes among the evaluators. A valid majority voting rank exists if and only if at least two of the three evaluators assign the same rank value to a method. Let
S_{a}
denote the samples for which method
a
has a valid majority voting rank.

Then, we compute the average rank value for each method:

\displaystyle\text{AvgRank}(a)=\frac{1}{|S_{a}|}\sum_{i\in S_{a}}\hat{r}_{i,a},

(17)

where
|S_{a}|
denotes the number of samples having a valid majority voting ranking value for method
a
. A lower average rank value indicates the method is preferred more often.
