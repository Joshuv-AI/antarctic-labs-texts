Tug-of-war games related to p p -Laplace type equations with lower order terms
Jeongmin Han

Abstract
. In this paper, we investigate a class of tug-of-war games that incorporate a constant payoff discount rate at each turn. The associated model problems are p p -Laplace type partial differential equations with zeroth-order terms. We establish existence, uniqueness, and regularity results for the corresponding game value functions. Furthermore, we explore properties of the solutions to the model PDEs, informed by the analysis of the underlying games.

1.
Introduction

This paper focuses on a class of tug-of-war games that incorporate a fixed discount rate at each turn.
Specifically, we study the game associated with the following dynamic programming principle (DPP)

(1.1)

\displaystyle u_{\varepsilon}(x)=(1-\gamma\varepsilon^{2})\bigg\{\frac{\alpha}{2}\bigg(\sup_{B_{\varepsilon}(x)}u_{\varepsilon}+\inf_{B_{\varepsilon}(x)}u_{\varepsilon}\bigg)+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}u_{\varepsilon}(y)dy\bigg\}

Over the past decade, a variety of significant results have been established in the study of tug-of-war games.
Much of the existing literature has focused on cases involving only terminal payoffs or running payoffs.
However, it is also natural and mathematically interesting to consider games that incorporate a discount (or surcharge) at each turn.
In this paper, we extend the discussion to include such games with discounting mechanisms.
The discount factor in the game setting corresponds to a zeroth-order term in the associated PDE problem.
In PDE theory, for example, it is well-known that the second-order equation

a_{ij}D_{ij}u-cu=0,

where
a_{ij}
satisfies
\lambda|\xi|^{2}\leq a_{ij}\xi_{i}\xi_{j}\leq\Lambda|\xi|^{2}

0<\lambda\leq\Lambda
any
\xi\in\mathbb{R}^{n}

has the existence and uniqueness when
c\geq 0
.
We investigate a parallel theory in the context of the tug-of-war game value functions.
Specifically, the condition
\gamma\geq 0
in the DPP (
1.1
) plays a crucial role in establishing the existence, uniqueness, and regularity of the corresponding value functions.

As a simple example, we can consider a value function of the tug-of-war with constant payoff on the boundary strip.
When
\gamma=0
, i.e., there is no discount, one can guess without difficulty that the value function of the game (or the function satisfying (
1.1
)) would also be constant
in the domain.
However, if
\gamma>0
, the behavior of the value function would be quite different.
In that case, our intuition gives that if the token is near the boundary, the game will be finished soon and hence the discounted amount would be relatively small.
In contrast, if the token is far from the boundary, it requires a lot of turns to finish the game and this will reduce the payoff significantly.

Preliminaries

2.1.
Heuristics

We give a heuristic description of the relation between the DPP (
1.1
) and the model problem (
1
) here.
This is closely linked to mean value characterizations of solutions to (
1
).
For discussions on the mean value characterizations for the
p
-Laplace equation and its related problems, we refer to the previous results, such as
[
MPR10b
,
MPR10a
,
FLM14
]
.

Let
u\in C^{2}(\overline{\Omega})
be a function solving the problem (
1.1
).
Assume that
x\in\Omega
with
B_{\varepsilon}(x)\subset\subset\Omega
with small
\varepsilon>0
.
By using Taylor expansion, we first see that

\displaystyle\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}u(y)dy=u(x)+\frac{\Delta u(x)}{2(n+2)}\varepsilon^{2}+o(\varepsilon^{2}).

On the other hand, if
Du\neq 0
, we can consider the following rough approximation:

\displaystyle\frac{1}{2}\bigg(\sup_{B_{\varepsilon}(x)}u+\inf_{B_{\varepsilon}(x)}u\bigg)

\displaystyle\approx\frac{1}{2}\bigg\{u\bigg(x+\varepsilon\frac{Du(x)}{|Du(x)|}\bigg)+u\bigg(x-\varepsilon\frac{Du(x)}{|Du(x)|}\bigg)\bigg\}

\displaystyle=u(x)+\frac{\langle D^{2}u(x)Du(x),Du(x)\rangle}{2|Du(x)|^{2}}\varepsilon^{2}+o(\varepsilon^{2})

\displaystyle=u(x)+\frac{\Delta_{\infty}^{N}u(x)}{2}\varepsilon^{2}+o(\varepsilon^{2}).

Thus, for
\alpha=\frac{p-2}{p+n}
and
\beta=\frac{n+2}{p+n}
, we see that

\displaystyle(1-\gamma\varepsilon^{2})\bigg\{\frac{\alpha}{2}\bigg(\sup_{B_{\varepsilon}(x)}u+\inf_{B_{\varepsilon}(x)}u\bigg)+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}u(y)dy\bigg\}

\displaystyle\approx(1-\gamma\varepsilon^{2})\bigg(u(x)+\frac{\Delta_{p}^{N}u(x)}{2(p+n)}\varepsilon^{2}+o(\varepsilon^{2})\bigg)

\displaystyle=u(x)+\frac{1}{2}\bigg(\frac{\Delta_{p}^{N}u(x)}{p+n}-\gamma u\bigg)\varepsilon^{2}+o(\varepsilon^{2}).

Since
u
solves

\Delta_{p}^{N}u-(p+n)\gamma u=0

in
\Omega
, we derive

\displaystyle u(x)\approx(1-\gamma\varepsilon^{2})\bigg\{\frac{\alpha}{2}\bigg(\sup_{B_{\varepsilon}(x)}u+\inf_{B_{\varepsilon}(x)}u\bigg)+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}u(y)dy\bigg\}+o(\varepsilon^{2}).

From this observation, one can expect that
u_{\varepsilon}
satisfying (
1.1
) has similar behaviors to
u
.
Indeed, we will discuss the convergence issue of
u_{\varepsilon}
in Section
5
.
We also give a regularity result of
u
, Theorem
5.4
, by employing the estimates in Section
4
.

2.2.
Tug-of-war game with discounts on the payoff

Now we describe a stochastic game associated with (
1.1
).
We construct a two-player zero-sum stochastic game.
Let
\Omega\subset\mathbb{R}^{n}
be a bounded domain,

\Gamma_{\varepsilon}:=\{x\in\mathbb{R}^{n}\backslash\Omega:\operatorname{dist}(x,\partial\Omega)\leq\varepsilon\}

and
\Omega_{\varepsilon}:=\Omega\cup\Gamma_{\varepsilon}
.
We begin with the game at a starting point
x_{0}\in\Omega
.
Each round, players decide their strategies on how to move the token;
S_{I}
for Player I and
S_{II}
for Player II, respectively.
Then with a probability
\alpha
, there is a fair coin toss and the winner gets the right to move the token in
B_{\varepsilon}(x_{0})
.
On the other hand, with a probability
\beta
, the token is moved randomly in
B_{\varepsilon}(x_{0})
according to the uniform distribution.
Let the new position of the token be
x_{1}
. If
x_{1}\not\in\Omega
, Player II pays Player I the payoff
(1-\gamma\varepsilon^{2})F(x_{1})
.
Otherwise, the players repeat the above procedures until the token goes outside
\Omega

and then we can define
x_{2},x_{3},\dots
, and so on.
After the game is over, Player II pays Player I the payoff
(1-\gamma\varepsilon^{2})^{\tau}F(x_{\tau})
,
where
x_{\tau}\in\Gamma_{\varepsilon}
is the end point of the game.
We refer to
[
AHP17
,
ALPR20
]
, which considered the case
\gamma=0
, that is, there is no discount at each turn.

We can write this game setting more rigorously.
We first define a strategy as a Borel-measurable function giving the next position of the token.
Then, for
j\in\{I,II\}
, we set

S_{j}^{k}\in B_{1}

for each
k=0,1,\dots

and
S_{j}=\{S_{j}^{k}\}_{k=0}
.
We also consider sequences of random variables
\{\xi_{k}\}_{k=0}\subset[0,1]
and
\{w_{k}\}_{k=0}\subset B_{1}
, where each
\xi_{k}
and
w_{k}
are randomly selected according to the uniform distribution in
[0,1]
and
B_{1}
, respectively.
Thus, we set a sequence of vector-valued random variables
\{X_{k}^{x_{0}}\}_{k=0}
with

X_{0}^{x_{0}}\equiv x_{0}
and

(2.1)

X_{k}^{x_{0}}=\left\{\begin{array}[]{llll}X_{k-1}^{x_{0}}+\varepsilon S_{I}^{k-1}&\textrm{if $0\leq\xi_{k-1}<\frac{\alpha}{2}$,}\\
X_{k-1}^{x_{0}}+\varepsilon S_{II}^{k-1}&\textrm{if $\frac{\alpha}{2}\leq\xi_{k-1}<\alpha$,}\\
X_{k-1}^{x_{0}}+\varepsilon w_{k}&\textrm{if $\alpha<\xi_{k-1}\leq 1$}.\\
\end{array}\right.

In this case, the stopping time
\tau
is defined by

\tau=\min\{k\geq 0:X_{k}\in\Gamma_{\varepsilon}\}.

Now the value functions for Player I and II are given by

u_{\varepsilon}^{I}(x_{0})=\sup_{S_{I}}\inf_{S_{II}}\mathbb{E}_{S_{I},S_{II}}^{x_{0}}[(1-\gamma\varepsilon^{2})^{\tau}F(X_{\tau})]

and

u_{\varepsilon}^{II}(x_{0})=\inf_{S_{II}}\sup_{S_{I}}\mathbb{E}_{S_{I},S_{II}}^{x_{0}}[(1-\gamma\varepsilon^{2})^{\tau}F(X_{\tau})],

respectively.
We directly see that
u_{\varepsilon}^{I}\leq u_{\varepsilon}^{II}
by the definition.
If those two functions coincide, we can define the game value function
u_{\varepsilon}:=u_{\varepsilon}^{I}=u_{\varepsilon}^{II}
.

Remark 2.1
.

Since
\gamma>0
, we directly see that
u_{\varepsilon}
satisfies the following maximum principle

||u_{\varepsilon}||_{L^{\infty}(\Omega)}\leq||F||_{L^{\infty}(\Gamma_{\varepsilon})}

by the definition.
Suppose that
u_{\varepsilon}
and
v_{\varepsilon}
satisfy the DPP (
1.1
) with the payoff functions
F_{1}
and
F_{2}
. respectively. Then if
F_{1}\leq F_{2}
in
\Gamma_{\varepsilon}
, we also have

u_{\varepsilon}\leq v_{\varepsilon}\qquad\textrm{in}\ \ \Omega_{\varepsilon}.

We also consider the history of the game, which is defined to be a vector of the first
k+1
game states and
k
coin tosses.
It can be written as

\big(x_{0},(c_{1},x_{1}),\dots,(c_{k},x_{k})\big),

where
c_{i}\in\{I,II,0\}
denotes the result of each round;
I
if Player I wins,
II
if Player II wins and
0
if a random walk occurs.
We remark that the history of the game is associated with the filtration
\{\mathcal{F}_{k}\}_{k=0}
, where

\mathcal{F}_{0}:=\sigma(x_{0})
and

\mathcal{F}_{k}:=\sigma\big(x_{0},(c_{1},x_{1}),\dots,(c_{k},x_{k})\big)\qquad\textrm{for}\quad k\geq 1.

3.
The existence and uniqueness of the value function

We consider the existence and uniqueness of our value function for the game under the setting in the previous section.
This issue was mainly dealt with for the case
\gamma=0
in
[
LPS14
]
.
We first consider the existence and uniqueness of the function satisfying (
1.1
),
and then we also clarify that the function indeed coincides with the game value of our tug-of-war game.
We remark that the condition
\gamma\geq 0
is necessary to verify existence and uniqueness.

3.1.
The existence and uniqueness of the solution to (
1.1
)

As we mentioned above, we investigate the existence and uniqueness of the function satisfying our DPP.

We first discuss the existence. To this end,
let
\mathcal{F}_{\varepsilon}
be the set of all Borel measurable and bounded functions defined on
\Omega_{\varepsilon}
.
We define an operator
\mathcal{T}_{\varepsilon}
by

\displaystyle\mathcal{T}_{\varepsilon}u(x)=\left\{\begin{array}[]{ll}(1-\gamma\varepsilon^{2})\bigg\{\frac{\alpha}{2}\big(\sup_{B_{\varepsilon}(x)}u+\inf_{B_{\varepsilon}(x)}u\big)+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}u(y)dy\bigg\}&\textrm{if $x\in\Omega$,}\\
u(x)&\textrm{if $x\in\Gamma_{\varepsilon}$.}\\
\end{array}\right.

Then we directly see that
\mathcal{T}_{\varepsilon}u\in\mathcal{F}_{\varepsilon}
for every
u\in\mathcal{F}_{\varepsilon}
since

\mathcal{T}_{\varepsilon}u
is bounded from Remark
2.1
and
\sup_{B_{\varepsilon}(x)}v
,
\inf_{B_{\varepsilon}(x)}v

are Borel in
\Omega
for any bounded Borel function
v
in
\Omega_{\varepsilon}
(see (2.4) in
[
LPS14
]
).

We use an iteration to investigate the existence of a function satisfying (
1.1
).
Let

\displaystyle u_{0}(x)=\left\{\begin{array}[]{ll}-||F||_{L^{\infty}(\Gamma_{\varepsilon})}&\textrm{if $x\in\Omega$,}\\
F(x)&\textrm{if $x\in\Gamma_{\varepsilon}$,}\\
\end{array}\right.

and define
u_{k}=\mathcal{T}_{\varepsilon}u_{k-1}

for
k=1,2,\dots
.
We first need to show that
u_{k}
converges pointwise.
For each
k\geq 1
and
x\in\Omega
, we observe that

u_{k}(x)\leq u_{k+1}(x)
since
u_{0}\leq\mathcal{T}_{\varepsilon}u_{0}
and
\mathcal{T}_{\varepsilon}
preserves the monotonicity, i.e.,

u\leq v\qquad\textrm{implies}\qquad\mathcal{T}_{\varepsilon}u\leq\mathcal{T}_{\varepsilon}v.

We also see that
|u_{k}|\leq||F||_{L^{\infty}(\Gamma_{\varepsilon})}
without difficulty and hence,
it follows that there exists a function
\underline{u}
defined on
\Omega_{\varepsilon}
such that

\underline{u}(x)=\lim_{k\to\infty}u_{k}(x)

by the monotone convergence theorem and this yields
\underline{u}=\mathcal{T}_{\varepsilon}\underline{u}
.
The uniform convergence of
\underline{u}
can also be shown by using a similar argument in the proof of
[
LPS14
, Theorem 2.1]
.

Next, we consider the uniqueness. To do this, it is enough to show the following lemma.

Lemma 3.1
.

Suppose that
u_{1}
and
u_{2}
satisfy the DPP (
1.1
) with boundary data
F_{1}
and
F_{2}
in
\Gamma_{\varepsilon}
, respectively.
Then, we have

\sup_{\Omega}|u_{1}-u_{2}|\leq\sup_{\Gamma_{\varepsilon}}|F_{1}-F_{2}|.

Proof.

Without loss of generality, we can assume that
F_{1}\leq F_{2}
in
\Gamma_{\varepsilon}
.
Then, we only need to show that

\displaystyle M:=\sup_{\Omega}(u_{2}-u_{1})\leq\sup_{\Gamma_{\varepsilon}}(F_{2}-F_{1})=:m.

Suppose not.
In that case, we have
M>m
and this implies for any
x\in\Omega

(3.3)

\displaystyle\begin{split}u_{2}(x)-u_{1}(x)&\leq(1-\gamma\varepsilon^{2})\bigg\{\alpha\sup_{B_{\varepsilon}(x)}(u_{2}-u_{1})+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}(u_{2}-u_{1})(y)dy\bigg\}\\
&\leq(1-\gamma\varepsilon^{2})\bigg\{\alpha M+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}(u_{2}-u_{1})(y)dy\bigg\}.\end{split}

Now we set

S:=\{x\in\Omega_{\varepsilon}:u_{2}(x)-u_{1}(x)=M\}.

Since we assumed that
m<M
, we have
S\subset\Omega
.
We are going to prove that
S=\varnothing
.
By the boundedness of
\Omega
, we observe that
\overline{\Omega}
is compact.
Thus, if
S\neq\varnothing
, we can take a sequence
\{x_{k}\}\subset\Omega
such that

\displaystyle\lim_{k\to\infty}(u_{2}-u_{1})(x_{k})=M\qquad\textrm{and}\qquad\lim_{k\to\infty}x_{k}=x_{0}.

Then we can deduce

\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x_{0})}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x_{0})}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x_{0})}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x_{0})}}(u_{2}-u_{1})(y)dy=\lim_{k\to\infty}\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x_{k})}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x_{k})}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x_{k})}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x_{k})}}(u_{2}-u_{1})(y)dy

by the absolute continuity of the Lebesgue integral.
On the other hand, it also follows that

\displaystyle M

\displaystyle=\lim_{k\to\infty}(u_{2}-u_{1})(x_{k})

\displaystyle\leq(1-\gamma\varepsilon^{2})\bigg\{\alpha M+\beta\lim_{k\to\infty}\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x_{k})}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x_{k})}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x_{k})}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x_{k})}}(u_{2}-u_{1})(y)dy\bigg\}

\displaystyle=(1-\gamma\varepsilon^{2})M=M-\gamma\varepsilon^{2}M

by (
3.3
).
However, we have already assumed that
\gamma>0
and

M>m=\sup_{\Gamma_{\varepsilon}}(F_{2}-F_{1})=0,

and this is a contradiction.
Therefore, we have
M\leq m
and we can finish the proof.
∎

We can directly observe the uniqueness of the solution to (
1.1
) by applying the above lemma with
F_{1}=F_{2}
.

3.2.
The existence of the game value

We have observed the existence and uniqueness of the function satisfying (
1.1
) in the previous subsection.
It remains to verify that the function indeed coincides with the value function of the game introduced in Section
2.2
.
We can show this by constructing a sub(or super)martingale (see also
[
LPS14
, Theorem 3.2]
).

Theorem 3.2
.

Let
u_{\varepsilon}
be the function satisfying the DPP (
1.1
) with boundary data
F
and

u_{\varepsilon}^{I}
and
u_{\varepsilon}^{II}
are the corresponding game values for Player I and Player II, respectively.
Then, we have
u_{\varepsilon}=u_{\varepsilon}^{I}=u_{\varepsilon}^{II}
in
\Omega_{\varepsilon}
.

Proof.

We will give the proof of

u_{\varepsilon}^{II}\leq u_{\varepsilon}\qquad\textrm{in}\ \Omega

and then this also gives us
u_{\varepsilon}^{I}\geq u_{\varepsilon}
in
\Omega
by symmetry.
Since we already know that
u_{\varepsilon}=u_{\varepsilon}^{I}=u_{\varepsilon}^{II}=F
in
\Gamma_{\varepsilon}
, we can obtain our desired result in that case.

We consider the following situation: Each turn, Player II takes a strategy which almost minimizes
u_{\varepsilon}
.
More precisely, for some fixed
\eta>0
and given
x_{k}\in\Omega
, Player II takes a point
x_{k+1}\in B_{\varepsilon}(x_{k})
such that

u_{\varepsilon}(x_{k+1})\leq\inf_{B_{\varepsilon}(x_{k})}u_{\varepsilon}+\eta 2^{-k}.

We denote by
S_{II}^{0}
this strategy.
Then, we have for any strategy
S_{I}
,

\displaystyle\mathbb{E}_{S_{I},S_{II}^{0}}^{x_{0}}[(1-\gamma\varepsilon^{2})^{k+1}u_{\varepsilon}(x_{k+1})+\eta 2^{-k}|\mathcal{F}_{k}]

\displaystyle\leq(1-\gamma\varepsilon^{2})^{k+1}\bigg\{\frac{\alpha}{2}\bigg(\inf_{B_{\varepsilon}(x_{k})}u_{\varepsilon}+\eta 2^{-k}+\sup_{B_{\varepsilon}(x_{k})}u_{\varepsilon}\bigg)+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x_{k})}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x_{k})}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x_{k})}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x_{k})}}u_{\varepsilon}(y)dy\bigg\}+\eta 2^{-k}

\displaystyle\leq(1-\gamma\varepsilon^{2})^{k}u_{\varepsilon}(x_{k})+\eta 2^{-(k-1)},

and this yields that
M_{k}=(1-\gamma\varepsilon^{2})^{k}u_{\varepsilon}(x_{k})+\eta 2^{-(k-1)}
is a supermartingale.
Since
F
is bounded, we can observe that
M_{k}
is also bounded.
Therefore, by the optional stopping theorem, we have

\displaystyle u_{II}^{\varepsilon}(x_{0})

\displaystyle=\inf_{S_{II}}\sup_{S_{I}}\mathbb{E}_{S_{I},S_{II}}^{x_{0}}[(1-\gamma\varepsilon^{2})^{\tau}F(X_{\tau})]

\displaystyle\leq\sup_{S_{I}}\mathbb{E}_{S_{I},S_{II}^{0}}^{x_{0}}[(1-\gamma\varepsilon^{2})^{\tau}F(X_{\tau})+\eta 2^{-\tau}]

\displaystyle\leq\sup_{S_{I}}\mathbb{E}_{S_{I},S_{II}^{0}}^{x_{0}}[u(x_{0})+2\eta]

\displaystyle=u(x_{0})+2\eta,

and hence, we can finish the proof.
∎

4.
Regularity estimates

Regularity is one of the important research subjects in PDE theory; It gives us some information about the behavior of solutions.
Strictly, the DPP problems are different from PDE problems, nevertheless, we can still discuss the regularity of solutions.
There have been a number of regularity results for game values of tug-of-war games, for example,
[
PR16
,
APR17
,
LP18
,
ALPR20
]
.
In this section, we investigate the regularity issue for (
1.1
).
In particular, we present interior and boundary regularity estimates of our game value function
u_{\varepsilon}
satisfying (
1.1
).
This is important in itself and also essential for discussing the convergence of the value function.

We first state and prove our interior regularity result. Our method is based on the coupling method, which has been used in previous studies, for example,
[
LP18
,
PR16
]
.

Theorem 4.1
.

Assume that
B_{2}(0)\subset\Omega
.
Suppose that
u_{\varepsilon}
satisfies (
1.1
) for
0<\alpha<1
and
\varepsilon>0
with
\gamma\varepsilon^{2}<\frac{1}{2}
.
Then we have

|u_{\varepsilon}(x)-u_{\varepsilon}(z)|\leq C||u_{\varepsilon}||_{L^{\infty}(B_{2})}(|x-z|+\varepsilon),

where
x,z\in B_{1}(0)
and
C>0
only depends on
\alpha,\gamma
and
n
.

Proof.

To set an appropriate auxiliary function, we first define

\omega(t)=t-\omega_{0}t^{\frac{3}{2}}\qquad\textrm{for}\quad 0\leq t\leq\omega_{1}:=(3\omega_{0})^{-2},

where
\omega_{0}
is a fixed constant with
\omega_{0}>1/2
.
Observe that

\omega^{\prime}(t)=1-\frac{3}{2}\omega_{0}t^{\frac{1}{2}}\in\bigg[\frac{1}{2},1\bigg]\qquad\textrm{for}\ \ 0\leq t\leq\omega_{1}

and

\omega^{\prime\prime}(t)=-\frac{3}{4}\omega_{0}t^{-\frac{1}{2}}<0\qquad\textrm{for}\ \ 0\leq t\leq\omega_{1}.

Then we see that
\omega
is increasing and strictly concave and
C^{2}
in
(0,\infty)
.
Let
f_{1}
and
f_{2}
be as follows:

\begin{split}f_{1}(x,z)=C\omega(|x-z|)+|x+z|^{2}\,\end{split}

and

f_{2}(x,z)=\left\{\begin{array}[]{ll}C^{2(N-i)}\varepsilon&\textrm{if $(x,z)\in A_{i}$,}\\
0&\textrm{if $|x-z|>N\varepsilon/10$,}\end{array}\right.

where
C>1
and

A_{i}=\{(x,z)\in\mathbb{R}^{2n}:(i-1)\varepsilon/10<|x-z|\leq i\varepsilon/10\}

for
i=0,1,...,N
, where
N
is a sufficiently large number to be determined later.
Then we consider
f=f_{1}-f_{2}
as an auxiliary function.

Now we assume that

\sup_{B_{2}\times B_{2}}(u_{\varepsilon}(x)-u_{\varepsilon}(z))\leq 1

by using a normalization.
Let
T:=\{(x,x):x\in\Omega\}
be the diagonal set of
\Omega
.
By using
f_{1}\geq 1
in
(B_{2}\times B_{2})\backslash(B_{1}\times B_{1})
,
we see that

(4.1)

\begin{split}u_{\varepsilon}(x)-u_{\varepsilon}(z)-f(x,z)&=u_{\varepsilon}(x)-u_{\varepsilon}(z)-f_{1}(x,z)+f_{2}(x,z)\\
&\leq\max f_{2}\leq C^{2N}\varepsilon\end{split}

for
(x,z)\in(B_{2}\times B_{2})\backslash((B_{1}\times B_{1})\backslash T)
.
Since we can assume
x=-z
with an appropriate translation, it is sufficient to show that

(4.2)

\displaystyle\sup_{(x,z)\in B_{2}\times B_{2}}(u_{\varepsilon}(x)-u_{\varepsilon}(z)-f(x,z))\leq C^{2N}\varepsilon

to derive our desired regularity result.

Suppose not. Then we have

(4.3)

\displaystyle M:=\sup_{(x,z)\in(B_{1}\times B_{1})\backslash T}(u_{\varepsilon}(x)-u_{\varepsilon}(z)-f(x,z))>C^{2N}\varepsilon.

We can obtain (
4.2
) if we show that contradicts.
Observe that

\displaystyle M=\sup_{(x,z)\in B_{2}\times B_{2}}(u_{\varepsilon}(x)-u_{\varepsilon}(z)-f(x,z))

in this case.
Set
g(x,z)=u_{\varepsilon}(x)-u_{\varepsilon}(z)
.
Then for small enough
\eta>0
, we can select
(x_{1},z_{1})\in(B_{1}\times B_{1})\backslash T
such that

\displaystyle M\leq u_{\varepsilon}(x_{1})-u_{\varepsilon}(z_{1})-f(x_{1},z_{1})+\eta=g(x_{1},z_{1})-f(x_{1},z_{1})+\eta.

For
x\in\mathbb{R}^{n}
,
\nu\in B_{1}
and a measurable function
\psi
, we define

\mathcal{A}_{\varepsilon}\psi(x,\nu)=\alpha\psi(x+\varepsilon\nu)+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{1}}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{1}}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{1}}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{1}}}\psi(x+\varepsilon y)dy.

We see that

\displaystyle\mathcal{A}_{\varepsilon}u_{\varepsilon}(x,\nu)-\mathcal{A}_{\varepsilon}u_{\varepsilon}(z,\mu)=\alpha g(x+\varepsilon\nu,z+\varepsilon\mu)+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{1}}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{1}}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{1}}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{1}}}g(x+\varepsilon y,z+\varepsilon y)dy.

If we set a functional
G_{\varepsilon}
such that

G_{\varepsilon}\Psi(x,z,\nu,\mu)=\alpha\Psi(x+\varepsilon\nu,z+\varepsilon\mu)+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{1}}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{1}}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{1}}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{1}}}\Psi(x+\varepsilon y,z+\varepsilon y)dy,

we have

\mathcal{A}_{\varepsilon}u_{\varepsilon}(x,\nu)-\mathcal{A}_{\varepsilon}u_{\varepsilon}(z,\mu)=G_{\varepsilon}g(x,z,\nu,\mu).

We can also check without difficulty that
\Psi_{1}\leq\Psi_{2}
implies
G_{\varepsilon}\Psi_{1}\leq G_{\varepsilon}\Psi_{2}
.
Since we have assumed

g\leq f+M
in
B_{2}\times B_{2}
, we get

\displaystyle G_{\varepsilon}g(x_{1},z_{1},\nu,\mu)\leq M+G_{\varepsilon}f(x_{1},z_{1},\nu,\mu).

Observe that

(4.4)

\displaystyle\begin{split}g(x,z)=(1-\gamma\varepsilon^{2})\bigg\{\frac{\alpha}{2}\bigg(&\sup_{B_{\varepsilon}(x)\times B_{\varepsilon}(z)}g+\inf_{B_{\varepsilon}(x)\times B_{\varepsilon}(z)}g\bigg)\\
&+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{1}}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{1}}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{1}}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{1}}}g(x+\varepsilon h,z+\varepsilon h)dy\bigg\}.\end{split}

It can be represented by

(4.5)

\displaystyle g(x,z)=\frac{1-\gamma\varepsilon^{2}}{2}\bigg(\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}g(x,z,\nu,\mu)+\inf_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}g(x,z,\nu,\mu)\bigg).

Then, we can derive

\displaystyle M

\displaystyle\leq g(x_{1},z_{1})-f(x_{1},z_{1})+\eta

\displaystyle=\frac{1-\gamma\varepsilon^{2}}{2}\bigg(\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}g(x_{1},z_{1},\nu,\mu)+\inf_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}g(x_{1},z_{1},\nu,\mu)\bigg)-f(x_{1},z_{1})+\eta

\displaystyle\leq\frac{1-\gamma\varepsilon^{2}}{2}\bigg(\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f(x_{1},z_{1},\nu,\mu)+\inf_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f(x_{1},z_{1},\nu,\mu)\bigg)-f(x_{1},z_{1})

\displaystyle\qquad\qquad+(1-\gamma\varepsilon^{2})M+\eta

and this is rearranged as

\displaystyle\gamma\varepsilon^{2}M\leq\frac{1-\gamma\varepsilon^{2}}{2}\bigg(\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f(x_{1},z_{1},\nu,\mu)+\inf_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f(x_{1},z_{1},\nu,\mu)\bigg)-f(x_{1},z_{1})+\eta.

Hence, we deduce the contradiction if we show

(4.6)

\displaystyle(1-\gamma\varepsilon^{2})\bigg(\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f(x,z,\nu,\mu)+\inf_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f(x,z,\nu,\mu)\bigg)-2f(x,z)<2\gamma\varepsilon^{2}M

for any
(x,z)\in B_{2}\times B_{2}
.
Since
M>0
, it is enough to prove that

(4.7)

\displaystyle(1-\gamma\varepsilon^{2})\bigg(\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f(x,z,\nu,\mu)+\inf_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f(x,z,\nu,\mu)\bigg)-2f(x,z)<0.

In the proof of
[
ALPR20
, Lemma 5.2]
, one can find that
f_{1}
satisfies

(4.8)

\displaystyle\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f_{1}(x,z,\nu,\mu)+\inf_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f_{1}(x,z,\nu,\mu)-2f_{1}(x,z)<0.

This yields (
4.7
).

Next, we consider the other case.
If
|x-z|<N\varepsilon/10
,
we first observe that

u(x)-u(x)-f(x,x)=C^{2N}\varepsilon-4|x|^{2}<M

and thus (
4.3
) cannot occur when
x=z
.
Hence, we only need to show (
4.7
) when
0<|x-z|\leq\frac{N}{10}\varepsilon
.
Since

\displaystyle\big||a|-|b|\big|\leq|a-b|

for any
a,b\in\mathbb{R}^{n}
,
it follows that

\displaystyle\big||(x+\varepsilon v)-(z+\varepsilon w)|-|x-z|\big|\leq\varepsilon|v-w|.

Now we get

\displaystyle|f_{1}((x,z)+\varepsilon(v,w))-f_{1}(x,z)|

\displaystyle\leq C\varepsilon|v-w|+2\varepsilon|\langle x+z,v+w\rangle|+\varepsilon^{2}|v+w|^{2}

\displaystyle\leq 2C\varepsilon+8\varepsilon+4\varepsilon^{2}

\displaystyle\leq 3C\varepsilon

for any unit vectors
v
and
w
, and sufficiently large
C
.
Then we obtain

(4.9)

\displaystyle\begin{split}&(1-\gamma\varepsilon^{2})\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f_{1}(x,z,\nu,\mu)-f_{1}(x,z)\\
&=(1-\gamma\varepsilon^{2})\bigg(\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f_{1}(x,z,\nu,\mu)-f_{1}(x,z)\bigg)+\gamma\varepsilon^{2}f_{1}(x,z)\\
&\leq(1-\gamma\varepsilon^{2})3C\varepsilon+\gamma\varepsilon^{2}(2C+4)\\
&\leq 3(1+\gamma)C\varepsilon.\end{split}

On the other hand, we see that

\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f(x,z,\nu,\mu)\leq\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f_{1}(x,z,\nu,\mu)

since
f_{2}\geq 0
and
f=f_{1}-f_{2}
.
We also get

\inf_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f(x,z,\nu,\mu)\leq\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f_{1}(x,z,\nu,\mu)-\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f_{2}(x,z,\nu,\mu).

Recall that we have assumed that
(x,z)\in A_{i}
for some
i=1,\cdots,N
.
Then we can select
\nu,\mu
with
|\nu|=|\mu|=1
such that
(x,z)+\varepsilon(\nu,\mu)\in A_{i-1}
.
This implies

\displaystyle\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f_{2}(x,z,\nu,\mu)

\displaystyle\geq\alpha f_{2}((x,z)+\varepsilon(\nu,\mu))

\displaystyle=\alpha C^{2(N-i+1)}\varepsilon

\displaystyle=\alpha C^{2(N-i)}\varepsilon\bigg(C^{2}-\frac{2}{\alpha(1-\gamma\varepsilon^{2})}\bigg)+\frac{2}{1-\gamma\varepsilon^{2}}f_{2}(x,z).

Choose
C
large enough such that

C^{2}-\frac{4}{\alpha}>12(1+\gamma)C.

In this case, we see that
C
satisfies

C^{2}-\frac{2}{\alpha(1-\gamma\varepsilon^{2})}>6\frac{1+\gamma}{1-\gamma\varepsilon^{2}}C,

and hence, we obtain

(4.10)

\displaystyle\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f_{2}(x,z,\nu,\mu)>6C\frac{1+\gamma}{1-\gamma\varepsilon^{2}}\varepsilon+\frac{2f_{2}(x,z)}{1-\gamma\varepsilon^{2}}.

Now we observe that

(4.11)

\displaystyle\begin{split}&(1-\gamma\varepsilon^{2})\inf_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f(x,z,\nu,\mu)\\
&\leq(1-\gamma\varepsilon^{2})\bigg(\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f_{1}(x,z,\nu,\mu)-\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f_{2}(x,z,\nu,\mu)\bigg)\\
&<(1-\gamma\varepsilon^{2})\bigg(\sup_{\begin{subarray}{c}|\nu|\leq 1\\
|\mu|\leq 1\end{subarray}}G_{\varepsilon}f(x,z,\nu,\mu)-6C\frac{1+\gamma}{1-\gamma\varepsilon^{2}}\varepsilon-\frac{2f_{2}(x,z)}{1-\gamma\varepsilon^{2}}\bigg)\\
&\leq(f_{1}(x,z)+3C(1+\gamma)\varepsilon)-6C(1+\gamma)\varepsilon-2f_{2}(x,z)\\
&=f_{1}(x,z)-2f_{2}(x,z)-3C(1+\gamma)\varepsilon.\end{split}

Combining (
4.9
) and (
4.11
), we finally obtain (
4.7
)
and the proof is completed.
∎

It is also important to observe how the value function
u_{\varepsilon}
behaves near the boundary.
We derive a boundary regularity result for (
1
) here.

To discuss boundary regularity, we first need to introduce several assumptions.
We first assume that
\Omega
satisfies an exterior sphere condition, that is,
for any
y\in\partial\Omega
, there exists
B_{\delta}(z)\subset\mathbb{R}^{n}\backslash\Omega
with
\delta>0
such that
y\in\partial B_{\delta}(z)
.
Moreover, we also assume that the payoff function
F
satisfies

(4.12)

\displaystyle|F(x)-F(z)|\leq L_{F}|x-z|

for some
L_{F}>0
and any
x,z\in\Gamma_{\varepsilon}
.

In
[
MPR12b
]
, the key step to the proof of the boundary regularity result was to estimate the stopping time
\tau
.
To this end, the authors considered an auxiliary stochastic process with a longer stopping time than the original game.
We utilize a similar approach to obtain our desired result.
Let us construct a stochastic process as follows:
Let
y\in\partial\Omega
and take
z\in\mathbb{R}^{n}\backslash\Omega
with
B_{\delta}(z)\subset\mathbb{R}^{n}\backslash\Omega
and
y\in\partial B_{\delta}(z)
.
And we assume that
\Omega\subset B_{R}(z)
for some large
R>0
.
We consider the game in
B_{R}(z)\backslash\overline{B}_{\delta}(z)
, and fix the strategy of Player I to pull toward
z
(we denote the strategy by
S_{I}^{z}{}
).
We set the token cannot escape outside
\overline{B}_{R}(z)
in this process,
and hence, it ends only if the token is located in
\overline{B}_{\delta}(z)
.
We denote by

\tau^{\ast}=\inf\{k:x_{k}\in\overline{B}_{\delta}(z)\}.

Then one can obtain the following estimate of
\tau^{\ast}
by using a similar argument to
[
MPR12b
, Lemma 4.5]

and
[
Han22
, Lemma 5.2]
.

Lemma 4.2
.

Under the setting above, we have

\mathbb{E}^{x_{0}}[\tau^{\ast}]\leq\frac{C(n,\alpha,R/\delta)(\operatorname{dist}(\partial B_{\delta}(y),x_{0})+o(1))}{\varepsilon^{2}}

for any
x_{0}\in\Omega\subset B_{R}(z)\backslash\overline{B}_{\delta}(z)
.
Here
o(1)\to 0
as
\varepsilon\to 0
.

By using Lemma
4.2
, we can derive a boundary estimate for the value function.

Theorem 4.3
.

Assume that
\Omega
satisfies the exterior sphere condition and
F
satisfies (
4.12
).
Then for the value function
u_{\varepsilon}
with boundary data
F
, we have

(4.13)

\displaystyle|u_{\varepsilon}(x)-u_{\varepsilon}(z)|\leq C(n,R/\delta,\gamma)||F||_{C^{0,1}(\Gamma_{\varepsilon})}(|x_{0}-y|+o(1))+||F||_{C^{0,1}(\Gamma_{\varepsilon})}\delta

for any
x\in\Omega
and
z\in\Gamma_{\varepsilon}
.

Proof.

Since the boundary data
F
satisfies (
4.12
), it is sufficient to estimate

\sup_{S_{I}}\inf_{S_{II}}\mathbb{E}_{S_{I},S_{II}}^{x_{0}}[|x_{\tau}-z|].

In the proof of
[
MPR12b
, Lemma 4.6]
, we can find the following estimates:

\mathbb{E}_{S_{I}^{z},S_{II}}^{x_{0}}[|x_{\tau}-z|]\leq|x_{0}-z|+C\varepsilon\mathbb{E}_{S_{I}^{z},S_{II}}^{x_{0}}[\tau]

for some universal constant
C>0
and

\varepsilon^{2}\mathbb{E}_{S_{I}^{z},S_{II}}^{x_{0}}[\tau]\leq\varepsilon^{2}\mathbb{E}_{S_{I}^{z},S_{II}}^{x_{0}}[\tau^{\ast}]\leq C(n,R/\delta)(\operatorname{dist}(\partial B_{\delta}(y),x_{0})+o(1)).

We also have
y\in B_{\delta}(z)
and this implies

\mathbb{E}_{S_{I}^{z},S_{II}}^{x_{0}}[|x_{\tau}-z|]\leq C(n,R/\delta)(|x_{0}-y|+o(1))+\delta.

Now we observe that

\displaystyle\mathbb{E}_{S_{I}^{z},S_{II}}^{x_{0}}\big[F(x_{\tau})-

\displaystyle\big|F(x_{\tau})\big(1-(1-\gamma\varepsilon^{2})^{\tau}\big)\big|\big]

\displaystyle\leq\mathbb{E}_{S_{I}^{z},S_{II}}^{x_{0}}[(1-\gamma\varepsilon^{2})^{\tau}F(x_{\tau})]

\displaystyle\leq\mathbb{E}_{S_{I}^{z},S_{II}}^{x_{0}}\big[F(x_{\tau})+\big|F(x_{\tau})\big(1-(1-\gamma\varepsilon^{2})^{\tau}\big)\big|\big]

and

\displaystyle\mathbb{E}_{S_{I}^{z},S_{II}}^{x_{0}}\big[\big|F(x_{\tau})\big(1-

\displaystyle(1-\gamma\varepsilon^{2})^{\tau}\big)\big|\big]

\displaystyle\leq\gamma||F||_{L^{\infty}(\Gamma_{\varepsilon})}\mathbb{E}_{S_{I}^{z},S_{II}}^{x_{0}}[\tau\varepsilon^{2}]

\displaystyle\leq\gamma||F||_{L^{\infty}(\Gamma_{\varepsilon})}C(n,R/\delta)(|x_{0}-y|+o(1)).

On the other hand, we can also deduce that

\displaystyle F(z)-

\displaystyle C(n,R/\delta,L_{F})(|x_{0}-y|+o(1))-L_{F}\delta

\displaystyle\leq\mathbb{E}_{S_{I}^{z},S_{II}}^{x_{0}}[F(x_{\tau})]\leq F(z)+C(n,R/\delta,L_{F})(|x_{0}-y|+o(1))+L_{F}\delta

since we have assumed (
4.12
).
Therefore, it follows that

\displaystyle\sup_{S_{I}}\inf_{S_{II}}\mathbb{E}_{S_{I},S_{II}}^{x_{0}}\big[(1-\gamma\varepsilon^{2})^{\tau}F(x_{\tau})\big]

\displaystyle\geq\inf_{S_{II}}\mathbb{E}_{S_{I}^{z},S_{II}}^{x_{0}}\big[(1-\gamma\varepsilon^{2})^{\tau}F(x_{\tau})\big]

\displaystyle\geq F(z)-C(n,R/\delta,\gamma)||F||_{C^{0,1}(\Gamma_{\varepsilon})}(|x_{0}-y|+o(1))-||F||_{C^{0,1}(\Gamma_{\varepsilon})}\delta.

Similarly, we can also obtain

\displaystyle\sup_{S_{I}}\inf_{S_{II}}\mathbb{E}_{S_{I},S_{II}}^{x_{0}}\big[(1-\gamma\varepsilon^{2})^{\tau}F(x_{\tau})\big]

\displaystyle\leq F(z)+C(n,R/\delta,\gamma)||F||_{C^{0,1}(\Gamma_{\varepsilon})}(|x_{0}-y|+o(1))+||F||_{C^{0,1}(\Gamma_{\varepsilon})}\delta.

by fixing the strategy of Player II.
Then we complete the proof because

u(x_{0})=\sup_{S_{I}}\inf_{S_{II}}\mathbb{E}_{S_{I},S_{II}}^{x_{0}}\big[(1-\gamma\varepsilon^{2})^{\tau}F(x_{\tau})\big].

∎

5.
Convergence result for (
1
)

The convergence of value functions is also an important issue for studies on stochastic games.
In this section, we investigate the convergence of our value function as the step size
\varepsilon
goes to zero.
We will show this by using the notion of viscosity solutions (cf.
[
MPR12b
,
KMP12
,
Ruo16
]
, etc).
Meanwhile, such a convergence result can give us a corresponding regularity result for the model problem (
1
).
To this end, we also need to verify the uniqueness of the solution to (
1
).

We begin this section with the definition of a viscosity solution.

Definition 5.1
.

A function
u\in C(\Omega)
is a viscosity solution to (
1
) if
the following conditions hold:

(a)

for all
\varphi\in C^{2}(\Omega)
touching
u
from above at
x_{0}\in\Omega
,

\displaystyle\left\{\begin{array}[]{ll}\Delta_{p}^{N}\varphi(x_{0})\geq(p+n)\gamma\varphi(x_{0})\qquad\qquad\textrm{if $D\varphi(x_{0})\neq 0$,}\\
\lambda_{\max}((p-2)D^{2}\varphi(x_{0}))+\Delta\varphi(x_{0})\geq(p+n)\gamma\varphi(x_{0})\qquad\textrm{if $D\varphi(x_{0})=0$.}\\
\end{array}\right.

(b)

for all
\varphi\in C^{2}(\Omega)
touching
u
from below at
x_{0}\in\Omega
,

\displaystyle\left\{\begin{array}[]{ll}\Delta_{p}^{N}\varphi(x_{0})\leq(p+n)\gamma\varphi(x_{0})\qquad\qquad\textrm{if $D\varphi(x_{0})\neq 0$,}\\
\lambda_{\min}((p-2)D^{2}\varphi(x_{0}))+\Delta\varphi(x_{0})\leq(p+n)\gamma\varphi(x_{0})\qquad\textrm{if $D\varphi(x_{0})=0$.}\\
\end{array}\right.

Here, the notations
\lambda_{\max}(X)
and
\lambda_{\min}(X)
mean the largest and the smallest eigenvalues of a symmetric matrix
X
.

The following Arzelà-Ascoli criterion is essential to show the convergence of
u_{\varepsilon}
.
One can find the proof of this lemma in
[
MPR12b
, Lemma 4.2]
.

Lemma 5.2
.

Let
\{u_{\varepsilon}:\overline{\Omega}\to\mathbb{R},\varepsilon>0\}
be a set of functions such that

(a)

there exists a constant
C>0
so that
|u_{\varepsilon}(x)|<C
for every
\varepsilon>0
and every
x\in\overline{\Omega}
.

(b)

given
\eta>0
, there are constants
r_{0}
and
\varepsilon_{0}
so that for every
\varepsilon>0
and
x,z\in\overline{\Omega}
with
|x-z|<r_{0}
, it holds

|u_{\varepsilon}(x)-u_{\varepsilon}(z)|<\eta.

Then, there exists a uniformly continuous function
u:\overline{\Omega}\to\mathbb{R}
and a subsequence
\{u_{\varepsilon_{i}}\}
such that
u_{\varepsilon_{i}}
uniformly converges to
u
in
\overline{\Omega}
, as
i\to\infty
.

By combining the above lemma and the regularity results in the previous section (Theorem
4.1
and Theorem
4.3
),
we can prove the convergence of the value function under the assumption of Theorem
4.3
.

Theorem 5.3
.

Assume that
\Omega
satisfies the exterior sphere condition and
F\in C^{1}(\Gamma_{\varepsilon})

satisfies (
4.12
).
Let
u_{\varepsilon}
denote the solution to (
1.1
) with boundary data
F
for each
\varepsilon>0
.
Then, there exist a function
u:\overline{\Omega}_{\varepsilon}\to\mathbb{R}
and a subsequence

\{\varepsilon_{i}\}
such that

u_{\varepsilon_{i}}\to u\qquad\textrm{uniformly in}\quad\overline{\Omega}.

Proof.

We first observe the existence of a uniform convergent subsequence of
\{u_{\varepsilon}\}
.
By using the definition of
u_{\varepsilon}
, we have

||u_{\varepsilon}||_{L^{\infty}(\Omega)}\leq||F||_{L^{\infty}(\Omega)}<\infty

for any
\varepsilon>0
and thus
u_{\varepsilon}
are uniformly bounded.
We also see the equicontinuity in the sense of Lemma
5.2
by Theorem
4.1
and Theorem
4.3
,
and hence we can apply the Arzelà-Ascoli criterion.
Therefore, we can find a uniformly convergent subsequence, still denoted by
u_{\varepsilon}
, to a function
u\in C(\overline{\Omega})
.

Next, we verify that
u
is a viscosity solution to (
1
).
We first observe that

u(x)=\lim_{\varepsilon\to 0}u_{\varepsilon}(x)=F(x)

for any
x\in\partial\Omega
.
Thus, it is sufficient to show that
u
is a solution to

\Delta_{p}^{N}u-(p+n)\gamma u=0\qquad\textrm{in}\ \Omega

in the viscosity sense.
Without loss of generality, it is enough to prove that
u
satisfies (b) in Definition
5.1
.

We fix
x\in\Omega
and consider a small neighborhood of
x
such that

B_{R}(x)\subset\Omega
for some
R>0
.
For each
\varepsilon>0
, we can consider a function
\varphi\in C^{2}(B_{R}(x))
touching
u
from below at
x
.
Since
u_{\varepsilon}
converges uniformly to
u
, for sufficiently small
\varepsilon>0
, we can find a convergent sequence
\{x_{\varepsilon}\}

satisfying the following property

(u_{\varepsilon}-\varphi)(z)\geq(u_{\varepsilon}-\varphi)(x_{\varepsilon})-\eta_{\varepsilon}\qquad\textrm{for any}\ \ z\in B_{R}(x)

for some
x_{\varepsilon}\in B_{R}(x)
and small
\eta_{\varepsilon}>0
.
We observe that
x_{\varepsilon}\to x
as
\varepsilon\to 0
in that case.

Recall (
3.1
). For
x\in\Omega
,
we have

\displaystyle u_{\varepsilon}(x)=\mathcal{T}_{\varepsilon}u_{\varepsilon}(x)=(1-\gamma\varepsilon^{2})\bigg\{\frac{\alpha}{2}\bigg(\sup_{B_{\varepsilon}(x)}u_{\varepsilon}+\inf_{B_{\varepsilon}(x)}u_{\varepsilon}\bigg)+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}u_{\varepsilon}(y)dy\bigg\}.

Set
\psi=\varphi+(u_{\varepsilon}-\varphi)(x_{\varepsilon})
.
Then we observe that

u_{\varepsilon}\geq\psi-\eta_{\varepsilon}
in
B_{R}(x)
.
By using this, it follows that

\displaystyle u_{\varepsilon}(x_{\varepsilon})=\mathcal{T}_{\varepsilon}u_{\varepsilon}(x_{\varepsilon})\geq\mathcal{T}_{\varepsilon}\big(\psi(x_{\varepsilon})-\eta_{\varepsilon})=\mathcal{T}_{\varepsilon}\psi(x_{\varepsilon})-(1-\gamma\varepsilon^{2})\eta_{\varepsilon}

and

\displaystyle\mathcal{T}_{\varepsilon}\psi(x_{\varepsilon})=\mathcal{T}_{\varepsilon}\varphi(x_{\varepsilon})+(1-\gamma\varepsilon^{2})(u_{\varepsilon}-\varphi)(x_{\varepsilon}).

Hence, we get

\displaystyle u_{\varepsilon}(x_{\varepsilon})\geq\mathcal{T}_{\varepsilon}\varphi(x_{\varepsilon})+(1-\gamma\varepsilon^{2})\big((u_{\varepsilon}-\varphi)(x_{\varepsilon})-\eta_{\varepsilon}\big)

and this yields

(5.1)

\displaystyle\gamma\varepsilon^{2}(u_{\varepsilon}-\varphi)(x_{\varepsilon})+(1-\gamma\varepsilon^{2})\eta_{\varepsilon}\geq\mathcal{T}_{\varepsilon}\varphi(x_{\varepsilon})-\varphi(x_{\varepsilon}).

By the Taylor expansion, we can compute that

\displaystyle(1-\gamma\varepsilon^{2})

\displaystyle\bigg\{\frac{\alpha}{2}\bigg(\sup_{B_{\varepsilon}(x)}\varphi+\inf_{B_{\varepsilon}(x)}\varphi\bigg)+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}\varphi(y)dy\bigg\}

\displaystyle=\varphi(x)+\frac{1}{2}\bigg(\frac{\Delta_{p}^{N}\varphi(x)}{p+n}-\gamma\varphi(x)\bigg)\varepsilon^{2}+o(\varepsilon^{2}).

Since we have assumed that
\varphi
has the
C^{2}
-regularity,
\varphi
attains its local minimum at a point
x_{\varepsilon}^{1}
in
\overline{B}_{\varepsilon}(x)
, that is,

\varphi(x_{\varepsilon}^{1})=\inf_{B_{\varepsilon}(x)}\varphi.

Assume that
x_{\varepsilon}^{1}\neq x
. Then for
\tilde{x}_{\varepsilon}^{1}=2x-x_{\varepsilon}^{1}
(the mirror point of
x_{\varepsilon}^{1}
with respect to
x
), we have

\displaystyle(1-\gamma\varepsilon^{2})\bigg\{\frac{\alpha}{2}\bigg(\sup_{B_{\varepsilon}(x)}\varphi+\inf_{B_{\varepsilon}(x)}\varphi\bigg)+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}\varphi(y)dy\bigg\}-\varphi(x)

\displaystyle\geq(1-\gamma\varepsilon^{2})\bigg\{\frac{\alpha}{2}\big(\varphi(x_{\varepsilon}^{1})+\varphi(\tilde{x}_{\varepsilon}^{1})\big)+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}\varphi(y)dy\bigg\}-\varphi(x)

\displaystyle=\frac{1}{2}\varepsilon^{2}\bigg(\frac{(p-2)\langle D^{2}\varphi(x)\nu_{\varepsilon},\nu_{\varepsilon}\rangle+\Delta\varphi(x)}{p+n}-\gamma\varphi(x)\bigg)+o(\varepsilon^{2}),

where
\nu_{\varepsilon}=(x-x_{\varepsilon}^{1})/|x-x_{\varepsilon}^{1}|
.
By (
5.1
), we obtain

(5.2)

\displaystyle\begin{split}\gamma\varepsilon^{2}(u_{\varepsilon}-\varphi)(x_{\varepsilon})&+(1-\gamma\varepsilon^{2})\eta_{\varepsilon}\\
&\geq\frac{1}{2}\varepsilon^{2}\bigg(\frac{(p-2)\langle D^{2}\varphi(x)\nu_{\varepsilon},\nu_{\varepsilon}\rangle+\Delta\varphi(x)}{p+n}-\gamma\varphi(x)\bigg)+o(\varepsilon^{2}).\end{split}

Suppose that
D\varphi(x)\neq 0
. Since
x_{\varepsilon}\to x
when
\varepsilon\to 0
, it follows that

\nu_{\varepsilon}\to-\frac{D\varphi(x)}{|D\varphi(x)|}

as
\varepsilon\to 0
(we remark that we can find a proper subsequence of
\{\nu_{\varepsilon}\}
in that case due to
D\varphi(x)\neq 0
).
and this implies

(p-2)\langle D^{2}\varphi(x)\nu_{\varepsilon},\nu_{\varepsilon}\rangle+\Delta\varphi(x)\to\Delta_{p}^{N}\varphi(x).

Meanwhile, we also have

(u_{\varepsilon}-\varphi)(x_{\varepsilon})\to(u-\varphi)(x)=0

by the uniform convergence of
u_{\varepsilon}
.
We take
\eta=o(\varepsilon^{2})
and
divide both side in (
5.2
) by
\varepsilon^{2}
.
By letting
\varepsilon\to 0
, we finally get

0\geq\Delta_{p}^{N}\varphi(x)-(p+n)\gamma\varphi(x).

On the other hand, if
D\varphi(x)=0
,
we observe that

\displaystyle(1-\gamma\varepsilon^{2})\bigg\{\frac{\alpha}{2}\bigg(\sup_{B_{\varepsilon}(x)}\varphi+\inf_{B_{\varepsilon}(x)}\varphi\bigg)+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}\varphi(y)dy\bigg\}-\varphi(x)

\displaystyle\geq(1-\gamma\varepsilon^{2})\bigg\{\frac{\alpha}{2}\big(\varphi(x_{\varepsilon}^{1})+\varphi(\tilde{x}_{\varepsilon}^{1})\big)+\beta\mathchoice{\mathop{\kern 1.99997pt\vrule width=6.00006pt,height=3.0pt,depth=-2.49997pt\kern-8.00003pt\intop}\nolimits_{\kern-3.27773ptB_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}{\mathop{\kern 1.00006pt\vrule width=5.0pt,height=3.0pt,depth=-2.59996pt\kern-6.00006pt\intop}\nolimits_{B_{\varepsilon}(x)}}\varphi(y)dy\bigg\}-\varphi(x)

\displaystyle\geq\frac{1}{2}\varepsilon^{2}\bigg(\frac{(p-2)\lambda_{\min}(D^{2}\varphi(x))+\Delta\varphi(x)}{p+n}-\gamma\varphi(x)\bigg)+o(\varepsilon^{2}).

By using
x_{\varepsilon}\to x
as
\varepsilon\to 0
and the continuity of the map
z\mapsto\lambda_{\min}(D^{2}\varphi(z))
, we can verify that

(5.3)

\displaystyle 0\geq\frac{1}{p+n}\big\{\Delta\varphi(x)+(p-2)\lambda_{\min}(D^{2}\varphi(x))\big\}-\gamma\varphi(x)

by a similar computation in the previous case.

We can also show the inequality in the opposite direction by considering a function
\varphi
touching
u
from above
and using a similar argument.
Then we complete the proof.
∎

For the uniqueness, we can find the relevant result for (
1
) in
[
APR17
, Appendix D]
.
Combining the regularity estimates, the convergence for (
1.1
) and the uniqueness result, we get the following regularity result of
u
solving (
1
).

Theorem 5.4
.

Let
u
be the solution of (
1
) for
2<p<\infty
.
Then we have

|u(x)-u(z)|\leq C||F||_{L^{\infty}(\partial\Omega)}\frac{|x-z|}{r},

where
x,z\in B_{r}(y)
for some
y\in\Omega
with
B_{r}(y)\subset\subset\Omega
and
C>0
only depends on
\alpha,\gamma
and
n
.
