Learning Small Decision Trees with Few Outliers: A Parameterized Perspective
Harmender Gahlawat, Meirav Zehavi

Abstract
Decision trees are a fundamental tool in machine learning for representing, classifying, and generalizing data. It is desirable to construct “small” decision trees, by minimizing either the size ( s s ) or the depth ( d ) (d) of the decision tree ( DT ). Recently, the parameterized complexity of Decision Tree Learning has attracted a lot of attention. We consider a generalization of Decision Tree Learning where given a classification instance E E and an integer t t , the task is to find a “small” DT that disagrees with E E in at most t t examples. We consider two problems: DTSO and DTDO , where the goal is to construct a DT minimizing s s and d d , respectively. We first establish that both DTSO and DTDO are W[1]-hard when parameterized by s + δ m ​ a ​ x s+\delta_{max} and d + δ m ​ a ​ x d+\delta_{max} , respectively, where δ m ​ a ​ x \delta_{max} is the maximum number of features in which two differently labeled examples can differ. We complement this result by showing that these problems become FPT if we include the parameter t t . We also consider the kernelization complexity of these problems and establish several positive and negative results for both DTSO and DTDO .

For

Classification Problems.

An example

is a function
e\penalty\ :\penalty\ F(e)\rightarrow D
defined over a finite set

of

and a (possibly infinite) linearly ordered

A

F(e_{1})=F(e_{2})
. Here,
F(E)=F(e)
for some
e\in E
. A set of examples

is
uniform
if
X\in E^{+}
or
X\in E^{-}
; otherwise,
X
is
non-uniform
. When it is clear from the context, we denote

by
F
.
For two examples
e_{1},e_{2}\in E
and some feature

, if
f(e_{1})=f(e_{2})
, then we say that
e_{1}
and
e_{2}

agree
on
f
, else, we say that
e_{1}
and
e_{2}

disagree
on
f
. A subset

of

if any two examples

and

disagree in at least one feature of

[
21
]

For two examples

, let
\lambda(e,e^{\prime})
denote the set of features where

and
e^{\prime}
disagree. Moreover, let
\lambda_{max}(E)=\max_{e^{+}\in E^{+}\wedge e^{-}\in E^{-}}|\lambda(e^{+},e^{-})|
denote the maximum number of features any two non-uniform examples disagree on.

For a feature

, let

denote the set of domain values appearing in any example of

. Moreover, let

Let

denote the set of examples that agree with the assignment
\alpha\penalty\ :\penalty\ F^{\prime}\rightarrow D
, where

E[\alpha]=\left\{e\penalty\ |\penalty\ e(f)=\alpha(f)\wedge f\in F^{\prime}\right\}

A

of

Parameterized Complexity.

In the framework of parameterized complexity, each problem instance is associated with a non-negative integer, called a
parameter
. A parametrized problem
\Pi
is
fixed-parameter tractable
(
\mathsf{FPT}
) if there is an algorithm that, given an instance
(I,k)
of
\Pi
, solves it in time
f(k)\cdot|I|^{\mathcal{O}(1)}
for some computable function
f(\cdot)
. Central to parameterized complexity is the W-hierarchy of complexity classes:

\mathsf{FPT}\subseteq\mathsf{W[1]}\subseteq\mathsf{W[2]}\subseteq\ldots\subseteq\mathsf{XP}.
Specifically,
\mathsf{FPT}

\neq
W[1], unless
\mathsf{ETH}
fails.

Two instances
I
and
I^{\prime}
are
equivalent
when
I
is a Yes-instance iff
I^{\prime}
is a Yes-instance. A
compression
of a parameterized problem
\Pi_{1}
into a (possibly non-parameterized) problem
\Pi_{2}
is a polynomial-time algorithm that maps each instance
(I,k)
of
\Pi_{1}
to an equivalent instance
I^{\prime}
of
\Pi_{2}
such that size of
I^{\prime}
is bounded by
g(k)
for some computable function
g(\cdot)
. If
g(\cdot)
is polynomial, then the problem is said to admit a
polynomial compression
.
A
kernelization algorithm
is a compression where
\Pi_{1}=\Pi_{2}
. Here, the output instance is called a
kernel
.
Let
\Pi_{1}
and
\Pi_{2}
be two parameterized problems. A
polynomial parameter transformation
from
\Pi_{1}
to
\Pi_{2}
is a polynomial-time algorithm that, given an instance
(I,k)
of
\Pi_{1}
, generates an equivalent instance
(I^{\prime},k^{\prime})
of
\Pi_{2}

such that
k^{\prime}\leq p(k)
, for some polynomial
p(\cdot)
. It is well-known that if
\Pi_{1}
does not admit a polynomial compression, then
\Pi_{2}
does not admit a polynomial compression
[
6
]
. An
AND-composition
from a problem
P
to a parameterized problem
Q
is an algorithm that takes as input
N
instances
I_{1},\ldots,I_{N}
of
P
, and in time polynomial in
\sum_{j\in[N]}|I_{j}|
, outputs an instance
(\mathcal{I},k)
of
Q
such that: (1)
(\mathcal{I},k)
is a Yes-instance iff
I_{j}
is a Yes-instance for each
j\in[N]
, and (2)
k
is bounded by a polynomial in
\max_{j\in[N]}|I_{j}|+\log N
. It is well known that if
P
is NP-hard, then
Q
does not admit a polynomial compression parameterized by
k
, unless
NP

\subseteq

coNP
/
poly

[
13
]
. We refer to the books
[
6
,
13
]
for details on parameterized complexity.

Lemma 5.1

e^{\prime}\notin T^{\prime}_{E}(l)
. Targeting contradiction, let there be some
j\neq i
such that
j\in[2N]
,
e^{\prime}\in B_{j}
, and
e^{\prime}\in T^{\prime}_{E}(l)
. Then, due to Observation
5.4
,
B_{j}\subseteq T^{\prime}_{E}(l)
. WLOG assume that
i<j
. Then, we claim that
B_{i+1}
(possibly
i+1=j
) is also contained in
T^{\prime}_{E}(l)
. This is easy to see since for every dummy test node
v
on the unique
(v_{0},l)
-path, if
\lambda(v)>e(d_{0})=i
and
\lambda(v)>e^{\prime}(d_{0})=j
(resp.,
\lambda(v)\leq e(d_{0})=i
and
\lambda(v)\leq e^{\prime}(d_{0})=j
), then
\lambda(v)>i+1
(resp.,
\lambda(v)\leq i+1
) as well. Hence,
B_{i+1}\in T^{\prime}_{e}(l)
. Therefore,
T^{\prime}_{E}(l)
contains two examples
e_{i}\in B_{i}
and
e_{i+1}\in B_{i+1}
such that for each vertex feature
f_{j}
, for
j\in[2n]
,
e_{i}(f_{j})=e_{i+1}(f_{j})=0
, and
e_{i}
is a positive example and
e_{i+1}
is a negative example.

Let
l^{\prime}
is a leaf of
T
such that
e_{i}\in T_{E}(l^{\prime})
. Since each test node in the unique
(l,l^{\prime})
-path is a vertex test node and
e_{i}
and
e_{i+1}
agree on every vertex feature,
e_{i+1}\in T_{E}(l^{\prime})
. Hence
T_{E}(l^{\prime})
is non-uniform, which contradicts the fact that
T
classifies
E
. This completes proof of our claim.

\diamond

Next, we claim that
T^{\prime}
is a complete binary tree of depth
p=\log_{2}(N)+1
.

Claim 5.11
.

T^{\prime}
is a complete binary tree and
dep(T^{\prime})=p
.

Proof of Claim.

Due to Claim
5.10
, since each
B_{i}
, for
i\in[2N]
, is contained in a unique leaf of
T^{\prime}
, we know that
T^{\prime}
has at least
2N
leaves. Therefore, it is easy to see that
dep(T^{\prime})\geq p
, as any binary tree of depth at most
p-1=\log_{2}(N)
can have at most
N
leaves.

Next, we establish that
dep(T^{\prime})\leq p
. Targeting contradiction, let
dep(T^{\prime})\geq p+1
and let
l
be a leaf of
T^{\prime}
that maximizes the number of (dummy) test nodes in the
(v_{0},l)
-path. Moreover, let
p
be the parent of
l
, and
l^{\prime}
be the other child of
p
. Observe that
l^{\prime}
is also a leaf of
T^{\prime}
. Moreover, let
B_{i}=T^{\prime}_{E}(l)
and
B_{j}=T^{\prime}_{E}(l^{\prime})
. We claim that either
i
is odd or
j
is odd. Note that
B_{i}\cup B_{j}=T_{E}(p)
. Now, it can be established using arguments used in the proof of Claim
5.10
that
i
and
j
are consecutive numbers, i.e., either
i=j+1
or
i=j-1
. Therefore, either
i
or
j
is odd.

WLOG assume that
i
is odd. Since
T_{E}(l)=B_{i}
and
T
classifies
E
, the subtree
T_{l}
should classify
B_{i}
. It follows from Observation
5.2
that the depth of
T_{l}
is at least
k
since
i
is odd and
T_{l}
classifies
B_{i}
. Let
l^{\prime\prime}
be a leaf of
T_{l}
that maximizes the number of test nodes in the
(l,l^{\prime\prime})
-path in
T_{l}
. Then,
dep(T)
is at least the number of test nodes in
(v_{0},l)
-path in
T^{\prime}
plus the number of test nodes in the
(l,l^{\prime\prime})
-path in
T
. Therefore,
dep(T)\geq p+1+k>d
, which is a contradiction since
dep(T)\leq d
. This establishes that
dep(T^{\prime})=p
.

Finally, since there are
2N=2^{p}
blocks in
E
and each block is contained in a unique leaf of
T^{\prime}
, we have that
T^{\prime}
has at least
2^{p}
leaves. Since the depth of
T^{\prime}
is
p
, it is only possible if
T^{\prime}
is a complete binary tree.

\diamond

Finally, we have the following claim.

Claim 5.12
.

Each
I_{j}=(G_{j},k)
,
j\in[N]
, is a Yes-instance of
Vertex Cover
.

Proof of Claim.

Targeting contradiction, let there be some
j\in[N]
such that
(G_{j},k)
is a No-instance of
Vertex Cover
, and hence,
(\mathcal{I}_{j},k)
is a No-instance of
HS
. Therefore, due to Proposition
2.3
,
(E(\mathcal{I}_{j}),k)
is a No-instance of
DTD
. Hence, for every
\mathsf{DT}

T_{j}
such that
T_{j}
classifies
E(\mathcal{I}_{j})
,
dep(T_{j})>k
. Moreover, recall that
T_{j}
classifies
E(\mathcal{I}_{j})
iff
T_{j}
classifies the examples of
B_{j}
.

Now, let
l
be the leaf of
T^{\prime}
such that
T^{\prime}_{E}(l)=B_{j}
. Since the subtree
T_{l}
of
T
classifies examples of
B_{j}
, we have that
dep(T_{l})>k
. Moreover, since
T^{\prime}
is a complete binary tree of depth
p
(Claim
5.11
), we have that
dep(T)>p+k=d
, a contradiction to the fact that
dep(T)=d
. This completes the proof of our claim.

\diamond

Therefore, due to Claim
5.12
, we have that each
I_{j}=(G_{j},k)
,
j\in[N]
, is a Yes-instance of
Vertex Cover
. This completes our proof.
∎

Finally, our construction and Lemmas
5.5
and
5.9
imply that
DTD
is AND-compositional. Moreover, since
\lambda_{max}\leq 3
for
E
,
|F|=2|V(G_{i})|+1
, and
d=\log_{2}N+k
, we have the following theorem as a consequence.

Theorem 5.13
.

DTD
parameterized by
d+|F|
is AND-compositional. Hence,
DTD
parameterized by
d+|F|
does not admit a polynomial compression even when
\delta_{max}\leq 3
, unless
NP

\subseteq

coNP
/
poly
.

6
Conclusion

We considered a generalization of
Decision Tree Learning
where the constructed
\mathsf{DT}
is allowed to disagree with the input
\mathsf{CI}
on a “
few
” examples. We considered
DTDO
and
DTSO
which are generalizations of
DTD
and
DTS
, respectively, from both parameterized and kernelization perspectives.
DTSO
and
DTDO
consider additive errors in accuracy. As pointed out by
[
22
]
, it may be desirable to design algorithms to respect Pareto-optimal trade-offs between size and measures of accuracy. In this regard,
Theorems

1.1
and
1.2
imply that some of the existing
\mathsf{FPT}
algorithms for
DTS
and
DTD
cannot be directly generalized, and one needs to consider the number of misclassified examples as a parameter. One interesting question in this direction can be if including number of features instead of
\delta_{max}
as a parameter remove the dependence on
t
, i.e., are
DTSO
and
DTDO

\mathsf{FPT}
parameterized by
s+|F|
and
d+|F|
, respectively. Moreover, one interesting open question in regard of kernelization complexity of
DTS
is the following.

Question 6.1
.

Does
DTS
parameterized by
s+|F|
admit a polynomial kernel when
\delta_{max}
is a fixed constant?

To establish the incompressibility of
DTD
in
Theorem

1.5
, we use a
\mathsf{DT}
of depth
\log N+1
to filter out blocks of examples; each leaf of this “filter tree” gets a unique block. The size of this filter tree is
2N
, and hence our construction directly cannot be used to prove the same result for
DTS
parameterized by
s+|F|
(since the parameter cannot have linear dependency on the number of instances in AND-composition).

Komusiewicz et al.
[
23
]
recently considered the parameterized complexity of two generalizations of
DTS
where the task is to design
\ell

\mathsf{DT}
s such that for each example, the majority of the trees agree with it. For
\ell=1
both these generalizations model
DTS
. They provided
\mathsf{FPT}
algorithms parameterized by
s+\delta_{max}+\ell+D_{max}
and asked as an open question if these problems admit a polynomial kernel parameterized by the same parameters. Notice that Observation
1.3
answers this question negatively since the incompressibility is implied for these problems even by fixing
\ell=1
and
D_{max}=2
. Moreover, note that since the trivial kernel in Theorem
1.4
is obtained by establishing an upper bound on the size of the
\mathsf{CI}
, the kernelization result applies to their generalizations as well.

Sometimes, in practice, it might be desirable that some examples are
marked
ineligible to be outliers. For example, while examples from some
noisy
part of the data are allowed to be outliers, an example from the
robust
part of the data must never be misclassified. We can model this setup using
DTSO
and
DTDO
by making
t+1
copies of each robust example if we allow
E
to be a multiset. Otherwise, if we need
E
to be a set, we think that our algorithm can be adjusted to restrict outliers to be only from the “noisy” part of the data.

Since the appearance of the conference version of this paper, there have been some interesting developments. Staus et al.
[
35
]
designed Witty, a fast and practical solver to compute minimum-sized decision trees, which is an heuristic-augmented implementation of an
\mathsf{FPT}
algorithm of Komusiewicz et al.
[
23
]
. Moreover, it is worth mentioning that Witty can solve
DTSO
(with some extra overhead).
