Hybrid deep learning and machine learning framework for automated pneumonia detection in chest X-ray images
Authors: Akshay S, Sneha Kashyap, Danikk Patel H N, Pavan Kumar Y R
Published: 2025

ABSTRACT
Pneumonia is a dangerous respiratory illness that has to be precisely and promptly diagnosed in order to be treated effectively and prevent consequences. In order to distinguish between pneumonic and normal chest X-ray pictures, a hybrid deep learning technique is proposed in this study. For efficient and complementary feature extraction, the proposed system leverages the strengths of two popular convolutional neural networks, VGG16 and ResNet. Before training the model, the image is enhanced and the lungs are segmented by performing histogram equalisation, normalising contrast, and converting to grayscale. A richer feature representation of input photos is produced by fusing the features of VGG16 and ResNet. A model for identifying pneumonia is classified using the fused feature set. The system processes X-rays of new patients in order to extract features and categorise them using Random Forest (RF) and Support Vector Machine (SVM) classifiers. To increase accuracy and efficiency, feature dimensions are optimised using Principal Component Analysis (PCA). Key Contributions:1. Dual-CNN feature fusion (VGG16 + ResNet) instead of single-model learning2. PCA-based dimensionality optimization retaining 95% variance3. Background

The evolution of pneumonia identification in chest X-rays has transitioned from manual diagnosis to an automated AI-based system. Initial methods were limited to using hand-crafted features that would be combined with classic machine learning classifiers such as SVM [14], and Random Forest [15]. As deep learning started to gain popularity, researchers began using CNNs such as VGG16 [11], ResNets, and DenseNets that could learn the spatial features directly from the raw images [1]. With the existence of transfer learning, the pre-trained deep learning models could be fine-tuned on medical datasets to optimize the identification task. Eventually, attention mechanisms were introduced to encompass the Lung region and better model pneumonia disease [2]. Subsequently, Ensemble models would be proposed, further boosting robustness by drawing from the strength of the model architectures. It was very common that after training CNN models, high-dimensional features would need to be evaluated. Several researchers introduced dimensionality reduction techniques such as PCA to manage these high-dimensional MM features [3]. Other approaches fusing CNN-based feature extraction with machine learning classifiers would be termed hybrid approaches. Other researchers used clustering algorithms such as k-means to classify either disease severity levels or even categorize the distinguished outcomes [4]. Most recently, there is an increasing demand for explainable AI tools such as Grad-CAM and LIME that improve the latency behind the prediction and gain greater acceptance by the clinical community [5].

The process of image processing is essential in pneumonia detection, as it focuses on improving the quality of chest X-ray images and reducing difficulty in interpreting images. Most medical images are raw and can contain noise, artifacts, or low contrast, making certain pathological features challenging to detect [6]. Preprocessing processes such as turning the image to grayscale, binarization, and contrast enhancement make lung structures and abnormal areas more visible [7]. Threshold and morphological processing of images home in on areas of interest, such as nodules or kinks within the lungs, allowing for better analysis and interpretation of physiological information [8]. Segmentation allows the model to only focus on the lung fields while minimizing unwanted background information. These processes can reduce variant information presented from image to image, thereby allowing for improved consistency of training within deep learning models. When images are enhanced, more reliable means of feature extraction can occur with deep learning models [9]. Image processing can also lessen the computational efficiency of models by standardizing inputsImage processing is crucial to building reliable and efficient classification [16] algorithms, especially when combined with deep learning [17] convolutional neural networks (CNNs). This process allows diagnostic-based machine learning models to be more interpretable and clinically useful [10].

This method combines state-of-the-art deep learning (VGG16 and ResNet) [18,19] with considerable feature extraction, dimension reduction through Principal Component Analysis (PCA) [12,13], and a classifier that has machine learning capabilities (Support Vector Machine and Random Forest). This method resolves relevant problems that existing diagnostic systems face, which include noise in the imaging obtained, high dimensionality of features, and processing inefficiency.

Moreover, the component of the image preprocessing pipeline consisting of converting a color image to grayscale for the original nodule X-ray, thresholding a query candidate of a nodule, and ultimately also extracting a nodule, assures that the appropriate system can reliably discriminate "medically relevant" regions of the X-ray [20]. The proposed model can also capture novel and additional complex features. The exploration of features from three complementary CNN-architecture models (latent representation vectors) is compared to improve the overall model to provide more informative image features that are associated with pneumonia. The main goal of this approach is to create a scalable, interpretable, and highly reliable diagnosis tool that can help clinicians, accelerate decision-making, and improve patient outcomes in circumstances where access to experienced radiologists may be scarce.

Image preprocessing

To reduce the input complexity from three channels to one, each raw chest X-ray image is first transformed from RGB to grayscale. To distinguish lung areas from the background, we then use Otsu's thresholding for automated binarization. To further refine these segmented areas, morphological operations such as erosion and dilation are used to remove small artifacts and enhance the lung contours. Additionally, edge detection (using, for example, the Canny method) isolates fine structures, and region-growing algorithms extract nodular features that may indicate localized pneumonia infections. This multi-step preprocessing ensures that the network focuses on the lung fields, minimizing noise and irrelevant details.

Feature extraction

Preprocessed images are then fed into two pre-trained convolutional neural networks—VGG16 and ResNet. Both models, originally trained on ImageNet, are fine-tuned on our chest X-ray dataset. The feature extraction process is carried out by capturing outputs from the last convolutional blocks of both networks, after applying global average pooling, which encapsulates high-level, discriminative features. These features represent the complex textures, shapes, and lesion patterns present in pneumonia. The outputs of both VGG16 and ResNet are then combined to form fused feature extraction, which is a stronger and more detailed representation. Fusion is achieved by leveraging the complementary strengths of both architectures to obtain an enhanced representation of image features. Together, the feature representation forms a high-dimensional representation of each image that is used to extract detailed and high-level information that is critical for obtaining accurate pneumonia detection and classification. PCA based feature reduction

Since the concatenated feature vectors have a high dimension, Principal Component Analysis (PCA) is performed, which reduces the feature space to 100 principal components, which are chosen to preserve approximately 95 % of the variance. The important benefit of this step is that the subsequent computation becomes easier, and the likelihood of overfitting is reduced since redundant information is eliminated. Histogram equalization.

Histogram equalization is an enhancement technique used for chest X-ray image processing to increase the contrast of structures. It redistributes the values of pixels of their intensity so that the full intensity range is available for imaging, and dark areas are made lighter and light areas darker. This increases contrast between the lung and bone tissues and helps in the diagnosis and analysis of abnormalities. Histogram equalization used to enhance contrast and highlight lung structures is depicted in Fig. 7.

Contrast stretching is an image enhancement technique that increases the range of intensity values in chest X-ray images by mapping the input pixel values to a broader range. This increases the contrast between dark and light areas in the images. Crossing the median contrast between the dark and white areas helps to highlight important anatomical structures and abnormalities in the images and makes them easier to interpret later in the medical career. Feature extraction validation

In this study, the feature extraction process is the most important part of the study, which comprises the use of deep learning models to identify and classify pneumonia from chest X-ray images. For feature extraction, two pretrained convolutional neural networks, VGG16 and ResNet, are used with the chest X-ray data using models that were originally trained using ImageNet data. The authors extracted features using the output from the last convolutional blocks of the networks after applying global average pooling. The authors indicated that this will retain the most discriminative, high-level features that represent complicated textures and lesion characteristics vital to pneumonia.

To improve representation power, features from VGG16 and ResNet are fused by concatenation to combine the spatial sensitivity of VGG16 with the residual learning capability of ResNet. Fused features are a high-dimensional representation where diagnostic information of the images will be adequately represented.

Dimensionality reduction validation

In the perspective framework, dimension reduction is an integral task that will enhance the performance and efficiency of the pneumonia detection system. After obtaining high-dimensional feature vectors from chest X-ray images from the fused outputs of two self-supervised pre-trained convolutional neural networks (VGG16 and ResNet), the authors apply Principal Component Analysis (PCA) to condense the feature space. This is an important operation in terms of mitigating the inherent difficulties in working with high-dimensional data (specifically, the increased computational cost and overfitting).

PCA is utilized to keep 100 principal components, with 100 carefully selected principal components retaining approximately 95 % of the total variance of the data. All the principal components indicate the informative attributes of the image data and the most diagnostically relevant components, while removing the redundant and less important components. The reduced feature space allows the classifiers – Support Vector Machine (SVM) and Random Forest (RF)—to be trained more robustly and efficiently.

Classification and hyperparameter tuning

The proposed approach to automatic pneumonia detection incorporates two supervised machine learning classifiers, Support Vector Machine (SVM) and Random Forest (RF), which classify the deep features that have been extracted from VGG16 and ResNet and reduced to 100 principal components through PCA. The classifiers use the refined deep features as inputs. In the case of SVM, a Radial Basis Function (RBF) kernel was employed, which allows SVM to work effectively on non-linear distributions of data and works well on the dataset, producing high performance. The Random Forest classifier works via ensemble learning with multiple decision trees, and performs quite well on the dataset also Both classification algorithms were hyperparameter tuned using cross-validation so as to optimize the algorithm performance and to avoid overfitting through values of the actual parameter.

Performance evaluation metrics

Performance assessment of the hybrid deep and machine learning framework for pneumonia detection implemented here is performed using multiple well-recognized metrics. Accuracy, precision, recall, F1-score, and AUC-ROC (Area Under the Receiver Operating Characteristic Curve) can be calculated using a confusion matrix that shows the true positives, false positives, true negatives, and false negatives, which helps us see the strengths and weaknesses of the model. In summary, the SVM classifier had an accuracy of 98.8 %, with an associated precision of 0.99, a recall of 0.98, and an associated F1-score of 0.98, indicating a good predictive ability with an exceedingly low expected false positive rate and false negative rate. The RF classifier had an accuracy of 95.8 %, an associated precision of 0.96, a recall of 0.94, and an associated F1-score of 0.95. AUC-ROC of the classifiers reached values of 0.92, which indicates a strong discriminative ability between pneumonia and non-pneumonia classes. Confusion metrics refer to metrics that quantify the performance of a classifier and are usually stored in a confusion matrix. Confusion metrics show the misfit in the prediction model by counting actual positives, exaggerated positives, real negatives, and fake negatives. The metrics on the confusion matrix, including accuracy, precision, recall, and F1-score, can be used to identify the benefits and shortcomings of the classifier, to inform improvements, and to achieve more reliable models.

Clinical interpretation

The performance metrics of the proposed framework are not only statistically strong but also meaningful when viewed from a clinical decision-making perspective. In the context of pneumonia, delayed or missed diagnosis can rapidly lead to complications such as respiratory distress, septic shock, and increased mortality. Therefore, the usefulness of an AI-assisted diagnostic tool must be evaluated based on how well it reduces clinical risk, rather than on numerical accuracy alone.

The Support Vector Machine (SVM) classifier recorded a recall of 0.98, which indicates that almost every pneumonia case in the test set was correctly detected. This is clinically crucial because a false negative (undiagnosed pneumonia) carries significantly higher risk than a false positive. When an infected patient is incorrectly classified as “normal,” antibiotic treatment, chest physiotherapy, or hospitalization may be postponed, worsening the patient’s prognosis. Thus, the model’s bias toward higher recall directly supports safer clinical decision pathways.

Likewise, the model achieved a precision value of 0.99, meaning that very few healthy patients were incorrectly labeled as having pneumonia. While false positives are less dangerous from a medical standpoint, they still impact healthcare by triggering unnecessary imaging reviews, medication prescriptions, and patient anxiety. The high precision therefore reduces clinical workload and resource consumption, which is especially beneficial in overburdened healthcare environments.

The confusion matrix analysis (Fig. 11, Fig. 12) confirms that both misclassification types are minimized, with only a small number of errors across thousands of images. This level of reliability suggests that the system can act as a supportive screening tool for radiologists, particularly in emergency departments, remote clinics, or screening camps where expert radiologists may not always be present.

Another practical benefit is the use of PCA, which reduces the feature dimensions while retaining 95 % of meaningful variation. This not only improves computational speed but also shortens model inference time—an essential requirement when decisions must be made rapidly, such as during outbreaks or in point-of-care settings.

Finally, the inclusion of interpretable machine learning models (SVM and Random Forest), rather than a black-box CNN softmax output, allows decision boundaries to be examined and justified. This aligns with current expectations in clinical AI deployment, where explainability and traceability are increasingly required by medical regulators and hospital ethics committees. Limitations

Dependence on image quality and homogeneity

The framework presupposes a minimum quality standard of input chest X-ray images. In cases of low-quality images (e.g., blurred, underexposed, or overexposed scans), there is the potential of failure in the preprocessing steps of thresholding and nodule extraction, which will not reliably segment lung regions.

Differences in images derived from different X-ray machines or clinical settings with differing (e.g., scanner-dependent, or clinical post-processing) resolutions and modalities may cause variation that could compromise model quality.

Sensitivity to contrast enhancement parameters

While there are some processes, such as Histogram Equalization and Contrast Stretching, which work effectively to increase visual contrast, there is the potential to over-amplify noise or falsely-defined structures in any of the individual scans, particularly in children or elderly patients who have differing anatomical considerations.

In circumstances where lung opacities are faint or diffused, such models would amplify the proximal structures, could be misleading, and distort relevant regions in a manner that would jeopardize feature extraction.

Limited generalizability across varied clinical datasets

The model was trained on a dataset of 5000 chest X-rays. The dataset size is decent; however, it may not adequately capture the entirety of the variability of the populations of patients (e.g., age, sex, comorbidities), appreciate the various pathologies (e.g., viral pneumonia or bacterial pneumonia), or administer treatment uniquely based on regional clinical practices.

To apply to datasets from populations with different characteristics or use typical pneumonia presentations may render the qualities of the model less accurate, leading to false-positive or false-negative results.

Lack of explainability and clinical interpretability

Despite fused features from VGG16 and ResNet being highly discriminative, they are still “black box” representations. The model does not currently have any explainable AI tools (e.g., Grad-CAM or SHAP) to support clinical trust and usability. The issue of explainability and validation is especially critical in medical applications, where visual explanation of a diagnosis is essential for physicians' corroboration and decision-making.

Performance in overlapping and multi-label cases

The present classification system is binary (pneumonia vs. non-pneumonia), and the severity stage is determined via k-means clustering. The machine can not be certain of multi-label scenarios (e.g., tuberculosis, fibrosis, co-occurrence, or overlaps) of thoracic pathologies. Some false classifications may likely occur when there are multiple thoracic pathologies because relevant feature patterns will overlap.

Computational requirements

The dimensionality of data will be reduced first through PCA; however, both the initial feature extraction through a CNN, as well as the training of the model, will use significant computational capacity and GPU acceleration.

This may hinder deployment in low-resource or point-of-care settings, particularly in rural health contexts.

Conclusion

This study presents a hybrid deep learning and machine learning framework that combines dual-CNN feature fusion, dimensionality reduction, and interpretable classification for automated pneumonia detection from chest X-ray images. Unlike single-network approaches, the proposed method integrates VGG16 and ResNet feature representations, followed by PCA to reduce redundancy while preserving 95 % of the variance. The reduced feature vectors are then classified using SVM and Random Forest, achieving accuracies of 98.8 % and 95.8 %, respectively.

The major contribution of this work is the shift from end-to-end CNN classification toward a more explainable and computationally efficient pipeline that supports clinical decision-making. The high recall score of the SVM model minimizes the risk of missed pneumonia cases, while the use of interpretable classifiers provides a transparent diagnostic pathway suitable for real-world medical environments. Future work will focus on extending the framework to multi-class disease classification, incorporating explainable AI tools such as Grad-CAM or SHAP, and validating the model on multi-center clinical datasets to ensure generalizability across diverse imaging conditions.
