Elementary closed-forms for non-trivial divisors
Mihai Prunescu, Joseph M. Shunia

Abstract
We present several elementary closed-forms that express a non-trivial divisor for every composite integer n > 1 n>1 . Each closed-form consists of a fixed number of elementary arithmetic operations drawn from the set: addition, subtraction, multiplication, integer division, and exponentiation. Two families of closed-forms are developed. First, direct application of the hypercube method yields closed-forms T 1 ​ ( n ) T_{1}(n) , T 2 ​ ( n ) T_{2}(n) , T 3 ​ ( n ) T_{3}(n) , and T 4 ​ ( n ) T_{4}(n) expressing the smallest prime divisor, largest non-trivial divisor, largest prime divisor, and greatest prime ≤ n \leq n , respectively. The factorial-unwinding technique underlying these hypercube constructions leads to extreme symbolic complexity, motivating our main result: An alternative closed-form T ⁡ ( n ) T(n) that avoids factorial-unwinding by synthesizing the quadratic residue invariants χ ⁡ ( n ) \chi(n) (largest r r such that r 2 r^{2} is a divisor) and ω ⁡ ( n ) \omega(n) (number of distinct prime divisors) with integer root extraction. Although evaluating these closed-forms requires exponential time, the number of arithmetic operations performed remains constant and independent of the input size n n . This sharply contrasts with traditional algorithmic methods, where the number of operations required to locate a non-trivial divisor necessarily scales with n n . 2020 Mathematics Subject Classification: 11A51 (primary), 11A25 (secondary). Keywords: integer factorization, Kalmar function, arithmetic term, semiprime, squarefree integer, nonsquarefree integer.

Introduction

The
integer factorization problem
is the computational task of decomposing a given natural number
n
into its prime factors. Formally, given an integer
n>1
, the objective is to find a set of primes
\{p_{1},p_{2},\dots,p_{k}\}
such that
n=p_{1}^{e_{1}}\cdot p_{2}^{e_{2}}\cdots p_{k}^{e_{k}}
, where
e_{i}\geq 1
are integer exponents. This problem is fundamental in computational number theory and has broad implications in fields such as cryptography, where the security of widely used protocols like RSA is based on the difficulty of factorizing large
semiprimes

[
14
]
, natural numbers
n=pq
that are the product of two prime numbers.

The problem is often presented in the following way:
Given a natural number
n
, find a proper divisor
d
with
1<d<n
, respectively decide that such a divisor does not exist.

If such an algorithm is applied for the numbers
d
and
n/d
, and the procedure is repeated as far as possible, one obtains a binary tree of results. Its terminal nodes are then the prime divisors of
n
, with the given multiplicity, and the factorization is done.

At this point it is worth to remark that a fast decision (polynomial time) about the primality of
n
is possible by the AKS algorithm
[
1
,
2
,
3
]
, but we don’t know how to efficiently find a non-trivial divisor of
n
, when
n
is not a prime number, by a fast deterministic algorithm. On the other hand, Shor’s quantum factorization algorithm, see
[
16
]
, promises to find a proper divisor
d
by constructing and running a quantum circuit of polynomial complexity.

Arithmetic terms
are defined in
[
11
,
12
]
as functions constructed in the language

\displaystyle L=\{+,\dot{-},\ast,/,\textup{\textasciicircum}\},

by the usual construction rules of term construction in the first-order logic. The constants
0
,
1
and the variables are arithmetic terms. Further, if
t_{1}
and
t_{2}
are arithmetic terms, then the following expressions are arithmetic terms:
(t_{1}+t_{2})
,
(t_{1}\dot{-}t_{2})
,
(t_{1}\ast t_{2})
,
(t_{1}/t_{2})
and
2^{t_{1}}
are arithmetic terms.
Here (
/
) denotes the quotient obtained by the integer division and the
monus
operator (
\dot{-}
) denotes bounded subtraction:
t_{1}\dot{-}t_{2}=\max(t_{1}-t_{2},0)
. In this article, the notation
\dot{-}
will be used only if it is important to distinguish this operation from the normal subtraction.

Put simply: Arithmetic terms are
fixed-length elementary closed-form expressions
and might informally be referred to as
formulas
.

We present the first arithmetic terms that return a non-trivial divisor for every composite integer
n>1
. Previous work has explored arithmetic terms for factoring semiprimes. For instance, in
[
17
]
Shunia presented an arithmetic for factoring semiprimes by direct application of a term for
\left\lfloor\sqrt{n}\right\rfloor
. A semiprime factoring term was also done independently by Prunescu and Sauras-Altuzarra in
[
12
]
, who instead utilized a term for Euler’s totient function
\varphi(n)
to obtain factors. It could be said that our general purpose factoring terms represent the logical conclusion of these earlier semiprime-only factoring terms.

Remark 1.1
.

Our results also extend prior work by Shamir
[
5
]
(the same Shamir who contributed the “S” in RSA
[
14
]
), who gave an algorithmic method for factoring integers using
O_{\textup{ops}}(\log n)
arithmetic operations, where each exponentiation
n^{m}
is counted as a single operation. Under this same accounting, our closed-form expressions represent only
O_{\textup{ops}}(1)
operations, and thus achieve the minimal possible count. However, this does not imply practical efficiency: The symbolic evaluation of our expressions incurs exponential time complexity
O(2^{n})
due to subterms whose bit complexity grows exponentially in the input size.

Preliminaries

We denote by
\mathbb{N}
the set of natural numbers, including
0
.

Kalmar functions
are functions
f:\mathbb{N}^{k}\to\mathbb{N}
that can be computed deterministically in iterated exponential time.

Mazzanti proved in
[
8
]
that every Kalmar function can be expressed as an arithmetic term (See also Marchenkov
[
4
]
and Prunescu et al.
[
9
]
). Mazzanti’s approach, known as the
hypercube method
, provides a complete characterization of Kalmar functions within the framework of arithmetic terms.

The function
\nu_{2}(n)
returns the
2
-adic order
of
n
, which is highest exponent of
2
dividing
n
. The function
\operatorname{HW}(n)
returns the
Hamming weight
of
n
, which is the number of
1
s in the binary representation of
n
.

We will make use of the following number theoretic arithmetic terms, which are proved in
[
8
,
4
,
10
,
13
]
:

\displaystyle\binom{a}{b}

\displaystyle=\left\lfloor\frac{(2^{a}+1)^{a}}{2^{ab}}\right\rfloor\bmod 2^{a},

\displaystyle\binom{a}{b}

\displaystyle=\left\lfloor\frac{2^{2(a+2)((a+1)^{2}+b+1)}}{2^{2(a+2)^{2}}-2^{2(a+2)}-1}\right\rfloor\bmod 2^{2(a+2)},

\displaystyle\gcd(a,b)

\displaystyle=\left(\left\lfloor\frac{2^{ab(ab+a+b)}}{(2^{a^{2}b}-1)(2^{ab^{2}}-1)}\right\rfloor\bmod 2^{ab}\right)-1

\displaystyle\nu_{2}(n)

\displaystyle=\left\lfloor\frac{\gcd(n,2^{n})^{n+1}\bmod(2^{n+1}-1)^{2}}{2^{n+1}-1}\right\rfloor,

\displaystyle\operatorname{HW}(n)

\displaystyle=\nu_{2}\left(\binom{2n}{n}\right).

Remark that Mazzanti gave a slightly more complicated
\gcd
-formula in
[
8
]
. The term
\operatorname{HW}(n)
displayed above is a consequence of Kummer’s Theorem, see Matiyasevich
[
7
, Appendix]
.

Matiyasevich also shows that the generalized geometric series are represented by arithmetic terms:

\displaystyle G_{r}(q,t)=\sum_{j=0}^{t-1}j^{r}q^{j}.

(1)

The corresponding term in the variables
q
and
t
will be called
G_{r}(q,t)
as well.

Consider
a,b\in\mathbb{N}:0\leq a<2^{b}
. We define the function

\displaystyle\delta(a,b):=(2^{b}-1)(2^{b}-a+1)=2^{2b}-2^{b}a+a-1.

(2)

It is proved in Mazzanti
[
8
]
that:

\displaystyle\operatorname{HW}(\delta(a,b))=\begin{cases}2b,&\text{if }a=0,\\
b,&\text{if }a\neq 0.\end{cases}

Consider integers
t,u>0
and a function
f:[0,t-1]^{k}\rightarrow\mathbb{N}
that satisfies the condition:

\forall\,\vec{a}\in[0,t-1]^{k}\,\,\,\,0\leq f(\vec{a})<2^{u}.

We count the points with integer coordinates in the cube
[0,t-1]^{k}
by the function:

\displaystyle\beta(\vec{a})=a_{1}+a_{2}t(\vec{n})+\cdots+a_{k}t(\vec{n})^{k-1}.

We define the quantity:

\displaystyle M(f,t,u)=\sum_{\vec{a}\in\{0,\dots,t-1\}^{k}}2^{2u\beta(\vec{a})}\delta(f(\vec{a}),u).

If represented in binary form, the number
M
consists of concatenated values
\delta(f(\vec{a}),u)
. In particular, the number of lattice points:

\{\vec{a}\in[0,t-1]^{k}:f(\vec{a})=0\}

is exactly:

\frac{HW(M(f,t,u))}{u}-t^{k}.

Now, suppose that the function
f(\vec{x})
is a so called
simple
exponential polynomial, i.e. a sum of monomials:

\displaystyle m(\vec{x})=cv_{1}^{x_{1}}\cdots v_{k}^{x_{k}}x_{1}^{r_{1}}\cdots x_{k}^{r_{k}},

where
r_{1},\ldots,r_{k}\geq 0
,
v_{1},\ldots,v_{k}\geq 1
are integers, and
c\in\mathbb{Z}
. For summation we use the identity:

\displaystyle\sum_{\vec{a}\in\{0,\dots,t-1\}^{k}}a_{1}^{r_{1}}v_{1}^{a_{1}}\cdots a_{k}^{r_{k}}v_{k}^{a_{k}}=G_{r_{1}}(v_{1},t)\cdots G_{r_{k}}(v_{k},t)=\prod_{i=1}^{k}G_{r_{i}}(v_{i},t).

We define the arithmetic term:

\displaystyle\mathcal{A}_{k}(m(\vec{x}),t,u)

\displaystyle=-(2^{u}-1)\cdot c\cdot\prod_{i=1}^{k}G_{r_{i}}(2^{2ut^{i-1}}v_{i},t)

(3)

which depends only on
t
and
u
, the argument
m(\vec{x})
being just a symbol, and not a value. Also, to the free term
c_{0}
of the exponential polynomial, meaning the term
m(\vec{x})
corresponding to
v_{1}=\cdots=v_{k}=1
and
r_{1}=\cdots=r_{k}=0
, it corresponds the term:

\displaystyle\mathcal{C}_{k}(c_{0},t,u)=\frac{(2^{u}-c+1)(2^{2ut^{k}}-1)}{2^{u}+1}.

(4)

It follows that in the case that
f(\vec{x})
is a simple exponential polynomial, the expression
M(f,t,u)
introduced above
becomes an arithmetic term depending on
t
and
u
, but also in all coefficients of
f(\vec{x})
:

M(f,t,u)=\mathcal{C}_{k}(c_{0},t,u)+\sum\mathcal{A}_{k}(m(\vec{x}),t,u).

This fact will be applied in the following form. Suppose that one considers some arithmetic term
t(\vec{n})>0
and some exponential Diophantine equation:

f(\vec{n},\vec{x})=0

in parameters
\vec{n}
, such that:

(i)

All the coefficients of
f
are given arithmetic terms in
\vec{n}
.

(ii)

Various basis of exponentiation
v_{i}
are themselves
arithmetic terms (or even other kind of functions) in
\vec{n}
.

(iii)

There is some arithmetic term
u(\vec{n})>0
such that

\forall\,\vec{a}\in[0,t(\vec{n})-1]^{k},\quad 0\leq f(\vec{n},\vec{a})<2^{u(\vec{n})}.

Altogether, we proved the following:

Theorem 2.1
.

For all
\vec{n}
, the number of lattice points:

\{\vec{a}\in[0,t(\vec{n})-1]^{k}:f(\vec{n},\vec{a})=0\}

is given by the following arithmetic term in
\vec{n}
:

\frac{HW(M(f,\vec{n},t(\vec{n}),u(\vec{n})))}{u(\vec{n})}-t(\vec{n})^{k}.

Arithmetic terms expressing the factorial function and the binomial coefficients go back to Julia Robinson
[
15
]
. Such a term was constructed and used by Prunescu and Sauras-Altuzarra in
[
11
]
. Here we may use the version from Prunescu and Shunia
[
13
]
:

\displaystyle n!

\displaystyle=\left\lfloor 8^{n^{3}}\Big/\binom{8^{n^{2}}}{n}\right\rfloor.

where we recall that
\binom{a}{b}
is itself representable by an arithmetic term.

3
Direct applications of the hypercube method

In this section we demonstrate how direct applications of the hypercube method presented in
section

2
yield closed-forms
T_{1}(n)
,
T_{2}(n)
,
T_{3}(n)
, and
T_{4}(n)
that compute various prime divisors and related quantities for composite integers
n
.

We start with a Lemma which was extensively proved by the authors in
[
13
]
. For the convenience of the reader, we will sketch the main ideas of the proof below.

Lemma 3.1
.

There exists
k\in\mathbb{N}
and a positive exponential polynomial
P(n,\vec{x},a)
, simple in
\vec{x}\in\mathbb{N}^{k}
, such that for all
n,a\in\mathbb{N}
, one has:

a=n!\longleftrightarrow\exists\,\vec{x}\,\,\,\,P(n,\vec{x},a)=0.

Moreover, this representation is single-fold, in the sense that if
a=n!
, then the tuple
\vec{x}\in\mathbb{N}^{k}
that satisfies this exponential Diophantine equation is unique. Also, the exponential polynomial
P(n,\vec{x},a)
is a sum of squares.

Proof.

We start with the fact that

n!=\left\lfloor 8^{n^{3}}\Big/\binom{8^{n^{2}}}{n}\right\rfloor.

We apply the definition for division with remainder and we find out that:

a=n!\longleftrightarrow\exists\,x_{1},x_{2},x_{3},x_{4},x_{5}

(x_{1}-n^{2})^{2}+(x_{2}-nx_{1})^{2}+\left(x_{3}-\binom{2^{3x_{1}}}{n}\right)^{2}+(2^{3x_{2}}-ax_{3}-x_{4})^{2}+(x_{3}-x_{4}-x_{5}-1)^{2}=0.

Indeed,
x_{4}<x_{3}
is the remainder of the division of
2^{3x_{2}}
by the number
x_{3}
, and
a
will be the quotient of this division with remainder. Now, by using the formula:

\binom{a}{b}=\left\lfloor\frac{2^{2(a+2)((a+1)^{2}+b+1)}}{2^{2(a+2)^{2}}-2^{2(a+2)}-1}\right\rfloor\bmod 2^{2(a+2)},

a similar positive single-fold exponential Diophantine representation is written for the relation:

x_{3}=\binom{2^{3x_{1}}}{n}.

This representation is basically the conjunction of two divisions with remainder, one for the quotient and the other one for the remainder represented by the
\bmod
operation. It will be also a sum of squares, and the variables can be chosen from
x_{6}
upwards. If we replace the squared binomial defining
x_{3}
with this sum of squares, we obtain the representation we were looking for.
∎

In the following lines, we show that there exists an arithmetic term
T_{1}(n)
which computes the smallest prime divisor of
n
.

Lemma 3.2
.

If
n\in\mathbb{N}
is a composite number, let
k
be the number of tuples
(a,b,c,d,e,f)\in\mathbb{N}^{6}
satisfying the following system of Diophantine equations:

\displaystyle(a+b+2)c

\displaystyle=

\displaystyle n

\displaystyle d\cdot(a+b+1)!+1

\displaystyle=

\displaystyle en

\displaystyle d+f

\displaystyle=

\displaystyle n

Then
D=k+1
is the smallest nontrivial divisor of
n
.

If
n\in\mathbb{N}
is a prime number, then the system has
n-1
solutions.

Proof.

Consider a tuple
(a,b,c,d,e,f)\in\mathbb{N}^{6}
, and define
D:=a+b+2
. We will prove the following claims:

Claim 1:
D
is the smallest non-trivial divisor of
n
. In particular, the value of
a+b
is the same for all solutions of the system.

Claim 2:
D=k+1
.

To prove
Claim 1
, we see that
D\geq 2
and
D\mid n
, so
D\neq 1
is indeed a divisor of
n
. By the second equation, the numbers
(D-1)!
and
n
are relatively prime, so there does not exist any smaller divisor different of
1
.

To prove
Claim 2
, we observe that the values
D
,
c
,
d
,
e
,
f
are uniquely determined by the composite number
n
. Indeed, the smallest nontrivial divisor
D
is uniquely determined by
n
, and so is also
c:=\left\lfloor n/D\right\rfloor
. The number
d\leq n
has the property that its class
d\bmod n
multiplied with the class
(D-1)!\bmod n
equals the class of
(n-1)\bmod n
. Such a unit
d\in\mathbb{Z}_{n}
is uniquely determined by
n
. The numbers
e
and
f
are uniquely determined by
d
. It follows that, given
n
composite, in the tuple
(a,b,c,d,e,f)
, only the natural numbers
a
and
b
can vary. The pair
(a,b)
can take the following values:

(D-2,0);\,\,(D-3,1);\,\,\dots;(0,D-2).

As there are exactly
(D-2)+1=D-1
such pairs, it follows that the number of tuples
(a,b,c,d,e,f)\in\mathbb{N}^{6}
that satisfy the system, is
k=D-1
. Hence
D=k+1
.

We also observe that if
n
is a prime number, then
D=n
is the only possible divisor. Then
(n-1)!+1
is a multiple of
n
by Wilson’s Theorem, and the system is solvable. The number of solutions will be in this case
n-1
.
∎

Theorem 3.1
.

There is an arithmetic term
T_{1}
such that for every natural number
n\geq 2
, the value
T_{1}(n)
is equal with the smallest prime dividing
n
.

Proof.

As the smallest proper divisor of
n
is always the smallest prime number dividing
n
, we have to encode only this information. The system of equations from Lemma
3.2
is equivalent with the equation:

((a+b+2)c-n)^{2}+(d\cdot(a+b+1)!+1-en)^{2}+(d+f-n)^{2}=0.

We introduce a new variable
g
for
(a+b+1)!
and the corresponding monomial:

((a+b+2)c-n)^{2}+(g-(a+b+1)!)^{2}+(dg-en+1)^{2}+(d+f-n)^{2}=0.

Using Lemma
3.1
, we know that
g=(a+b+1)!
if and only if there exists a tuple
\vec{x}\in\mathbb{N}^{k}
such that
P(a+b+1,\vec{x},g)=0
. As this exponential polynomial is a sum of squares, we can substitute the squared binomial
(g-(a+b+1)!)^{2}
with
P(a+b+1,\vec{x},g)
. So we obtain the exponential polynomial:

Q(n,a,b,c,d,e,f,g,\vec{x}):=

=((a+b+2)c-n)^{2}+P(a+b+1,\vec{x},g)+(dg-en+1)^{2}+(d+f-n)^{2}.

The exponential polynomial
Q
is a positive function on
\mathbb{N}^{k+8}
being a sum of squares. It is simple in
(a,b,c,d,e,f,g,\vec{x})
. Also, for all composite numbers
n
the number of
(k+6)
-tuples which satisfy the equation
Q=0
is equal with
D-1
, where
D
is the smallest nontrivial divisor of
n
; respectively with
n-1
when
n
is prime. By the hypercube method there is an arithmetic term
\theta(n)
counting the solutions of the equation
Q=0
. We take
T_{1}(n):=\theta(n)+1
.
∎

Corollary 3.1
.

There is an arithmetic term
T_{2}
such that for every composite number
n
, the value
T_{2}(n)
is equal with the greatest nontrivial divisor of
n
, and for every prime number
p
,
T_{2}(p)=1
.

Proof.

Let
t_{1}
be the term constructed in Theorem
3.1
. We define the arithmetic term
T_{2}
by the formula:

\displaystyle T_{2}(n)=\left\lfloor\frac{n}{T_{1}(n)}\right\rfloor.

∎

Further we show that there exists an arithmetic term
T_{3}(n)
which, for every natural number
n
, computes the greatest prime divisor of
n
.

Lemma 3.3
.

If
n\in\mathbb{N}

, let
k

satisfying the following system of Diophantine equations:

\displaystyle(a+b+2)c

\displaystyle=

\displaystyle n

\displaystyle(a+b+1)!+1

\displaystyle=

\displaystyle d(a+b+2)

\displaystyle((a+b+2)!)^{n}

\displaystyle=

\displaystyle ne

Then
D=k+1
is the greatest prime divisor of
n
.

If
n\in\mathbb{N}
is a prime number, then the system has
n-1
solutions.

Proof.

Consider a tuple
(a,b,c,d,e)\in\mathbb{N}^{5}
, and define
D:=a+b+2
. We will prove the following claims:

Claim 1:
D
is the greatest prime divisor of
n
. In particular, the value of

4
Two quadratic equations modulo n

In this section,
\mathbb{Z}_{n}=\mathbb{Z}/n\mathbb{Z}
means the ring consisting of the remainder classes modulo
n\geq 2
. By the Chinese Remainder Theorem, if the prime-number decomposition of
n
is
n=p_{1}^{k_{1}}\dots p_{t}^{k_{t}}
, then the following rings are isomorphic:

\displaystyle\mathbb{Z}/n\mathbb{Z}\cong\mathbb{Z}/p_{1}^{k_{1}}\mathbb{Z}\times\cdots\times\mathbb{Z}/p_{t}^{k_{t}}\mathbb{Z}.

We consider the function
\chi:\mathbb{N}\setminus\{0\}\rightarrow\mathbb{N}
defined as:

\chi(n)=\max\{s\in\mathbb{N}:s^{2}|n\}.

Theorem 4.1
.

For all
n\geq 1
,

\chi(n)=|\{a\in\mathbb{Z}_{n}:a^{2}=0\textup{ in }\mathbb{Z}_{n}\}|

Proof.

Consider
n=p^{2k}
where
p
is a prime and
k\geq 1
.
Let
x\in\{0,1,\dots,p^{2k}-1\}
be the representative of a solution of the equation
x^{2}=0
in
\mathbb{Z}_{p^{2k}}
.
Then

\displaystyle p^{2k}\mid x^{2}\iff p^{k}\mid x.

A multiple of
p^{k}
which is smaller than
p^{2k}
is of the form

\displaystyle s\cdot p^{k}<p^{2k}\iff s<p^{k}.

So there are exactly
p^{k}
many solutions, corresponding to all values
s\in\{0,\dots,p^{k}-1\}
.

Next, consider
n=p^{2k+1}
, with
p
prime and
k\geq 1
. Let
x\in\{0,1,\dots,p^{2k+1}-1\}
be the representative of a solution of the equation
x^{2}=0
in
\mathbb{Z}_{p^{2k+1}}
.
Then

\displaystyle p^{2k+1}\mid x^{2}\iff p^{k+1}\mid x.

A multiple of
p^{k+1}
which is smaller than
p^{2k+1}
is of the form

\displaystyle s\cdot p^{k+1}<p^{2k+1}\iff s<p^{k}.

So there are again exactly
p^{k}
many solutions.

If
n=p
is a prime, then the condition
a^{2}\equiv 0\pmod{p}
implies
p\mid a
. Since
a
must be in
\{0,1,\dots,p-1\}
, the only value that satisfies this condition is
a=0
. Hence, there is exactly one solution.

Finally, consider the general case where:

\displaystyle n=p_{1}^{2k_{1}+b_{1}}\cdots p_{t}^{2k_{t}+b_{t}}\quad\text{ with }b_{i}\in\{0,1\}.

By the Chinese Remainder Theorem, there exists an isomorphism of rings:

\displaystyle\mathbb{Z}/n\mathbb{Z}\cong\mathbb{Z}/(p_{1}^{2k_{1}+b_{1}})\mathbb{Z}\times\cdots\times\mathbb{Z}/(p_{t}^{2k_{t}+b_{t}})\mathbb{Z}.

The total number of solutions for
x^{2}\equiv 0\pmod{n}
is the product of the numbers of solutions for each prime power component:

\displaystyle\prod_{i=1}^{t}p_{i}^{k_{i}}.

This product is precisely the square root of the largest square dividing
n
:

\displaystyle\sqrt{p_{1}^{2k_{1}}\cdots p_{t}^{2k_{t}}}=\chi(n).

∎

We also consider the function
\omega:\mathbb{N}\setminus\{0\}\rightarrow\mathbb{N}
defined as:

\omega(n)=|\{p\textup{ prime }:\,\,p\mid n\}|.

The following Theorem has been also proved and used by the authors in
[
13
]
. We sketch it here only to be compared with the proof above.

Theorem 4.2
.

For all
n\geq 1
,

2^{\omega(n)+1}=|\{a\in\mathbb{Z}_{4n}:a^{2}=1\textup{ in }\mathbb{Z}_{4n}\}|.

Proof.

If
p
is an odd prime and
k\geq 1
, then the equation
x^{2}=1
has in
\mathbb{Z}_{p^{k}}
only the solutions
\{1,-1\}
. The same is true for the ring
\mathbb{Z}_{4}
. In
\mathbb{Z}_{2^{k}}
with
k\geq 3
, there are four solutions:
\{1,2^{k-1}-1,2^{k-1}+1,2^{k}-1\}
. Now suppose that
n
is odd and has
k
prime divisors. The number of solutions of the equation
x^{2}=1
in
\mathbb{Z}_{4n}
will be then

. If
n
is even and has

prime divisors, the number of solutions of
x^{2}=1
in
\mathbb{Z}_{4k}
is
2^{2}\cdot 2^{k-1}=2^{k+1}
.
∎

Another function needed to construct the factoring formula is

Alternatively

We observe that:

This definition leads to a family of arithmetic terms, another one for every

. Therefore, we need a two-variable term expressing

As this operation has to be unwinded in a logic formula, we prefer a simpler expression, that contains less additions.

Lemma 6.1

For all

Proof.

For

2^{3mx-1}>2^{mx}>x^{m}.

So,

2^{3m^{2}x}=(x+2^{3mx}-x)^{m},

2^{3m^{2}x}\bmod(2^{3mx}-x)=x^{m}.

We observe that for

Let
n,m\in\mathbb{N}
such that
n>2
,
\left\lfloor\log_{2}(n)\right\rfloor+1\geq m>1
, and
\not\exists k\in\mathbb{N}\,|\,k^{m}=n
. Then

\displaystyle\left\lfloor\sqrt[m]{n}\right\rfloor

\displaystyle=\left\lfloor\frac{(n^{2nm}+1)^{2nm+1}\bmod{(n^{2nm^{2}}-n)}}{(n^{2nm}+1)^{2nm}\bmod{(n^{2nm^{2}}-n)}}-1\right\rfloor.

If proven, this term could significantly simplify the symbolic representation of our main result.

7
A formula for factoring n

In this section, we synthesize the arithmetic terms developed in
section

4
–
section

6
to construct our main result: An arithmetic term
T(n)
that yields a non-trivial divisor of any composite integer
n>1
. Unlike the factorial-unwinding approaches of
section

3
, this construction combines the quadratic residue-based invariants
\chi(n)
(the largest square divisor) and
\omega(n)
(the number of distinct prime divisors) with root extraction and greatest common divisor operations. By avoiding repeated factorial constructions,
T(n)
achieves a comparatively more efficient structure, though it remains computationally infeasible for large
n
in absolute terms. We also present an alternative formulation
U(n)
using the truncated difference operation.

Lemma 7.1
.

Let
n=p_{1}p_{2}\cdots p_{k}
be a composite, squarefree integer with
k=\omega(n)
distinct prime factors, where
p_{1}<p_{2}<\dots<p_{k}
. Then
p_{1}\leq\left\lfloor\sqrt[k]{n}\right\rfloor<p_{k}
.

Theorem 7.1
.

Let
n\in\mathbb{N}
such that
n
is composite and squarefree. Then a non-trivial divisor of
n
is given by:

\displaystyle q=\gcd(n,\left\lfloor\sqrt[\omega(n)]{n}\right\rfloor!).

Proof.

Consider
n=p_{1}p_{2}\cdots p_{k}
which is squarefree and the product of
k
distinct primes. Now, let

\displaystyle r=\left\lfloor\sqrt[\omega(n)]{n}\right\rfloor.

By
lemma

7.1
, we know that

\displaystyle\min(p_{1},\ldots,p_{k})\leq r<\max(p_{1},\ldots,p_{k}).

It follows immediately that

\displaystyle q=\gcd(n,r!)=\gcd(n,\left\lfloor\sqrt[\omega(n)]{n}\right\rfloor!)

is a non-trivial divisor of
n
.
∎

Theorem 7.2
.

Let
n\in\mathbb{N}
such that
n>1
is composite. Then a non-trivial divisor of
n
is given by:

\displaystyle q=\gcd\left(\frac{n}{\chi(n)},\left\lfloor\sqrt[\omega(n)]{n}\right\rfloor!\right):=T(n).

Proof.

If
\chi(n)=1
then
n
is square-free, the expression gets the form

\gcd\left(n,\left\lfloor\sqrt[\omega(n)]{n}\right\rfloor!\right)

and we apply
theorem

7.1
. If
\chi(n)\neq 1
then
n/\chi(n)<n
, so
q<n
. Also
n/\chi(n)
is a divisor of
n
by
theorem

5.1
. We must show that
q\neq 1
. Let
p_{1}
be the smallest prime that divides
n
. The exponent of
p_{1}
in the prime-number decomposition of
n
is
2k+b
with
b\in\{0,1\}
such that if
b=0
then
k\geq 1
.
The exponent of
p_{1}
in
\chi(n)
is
k
. The exponent of
p_{1}
in
n/\chi(n)
is
k+b\geq 1
, so

p_{1}\mid\frac{n}{\chi(n)}.

Now we look at the number
\left\lfloor\sqrt[\omega(n)]{n}\right\rfloor
. Denote
\omega(n)
with
\omega
. Then:

n=p_{1}^{\alpha_{1}}\dots p_{\omega}^{\alpha_{\omega}}

where all
\alpha_{i}\geq 1
. It follows:

n\geq p_{1}^{\omega},

\left\lfloor\sqrt[\omega(n)]{n}\right\rfloor\geq p_{1},

p_{1}\mid\left\lfloor\sqrt[\omega(n)]{n}\right\rfloor!

So
p_{1}\mid q
, which implies that
q\neq 1
.
∎

Remark 7.1
.

Let
n\in\mathbb{N}
such that
n>1
is composite. Then a non-trivial divisor of
n
is also given by:

\displaystyle q=(2\dot{-}\chi(n))\cdot\gcd(n,\left\lfloor\sqrt[\omega(n)]{n}\right\rfloor!)+(1\dot{-}(2\dot{-}\chi(n)))\cdot\chi(n):=U(n).

Proof.

This remark is another way to aggregate the results given in
theorem

7.1
and
theorem

5.1
. Following Marchenkov
[
4
]
, we use a somewhat artificial feature of the modified difference:

a\dot{-}b=0\iff a\leq b.

So
2\dot{-}\chi(n)=1
if and only if
\chi(n)=1
if and only if
n
is square-free; otherwise
2\dot{-}\chi(n)=0
. Also,
1\dot{-}(2\dot{-}\chi(n))=1
if and only if
\chi(n)>1
if and only if
n
is divisible by nontrivial squares, otherwise
1\dot{-}(2\dot{-}\chi(n))=0
.
∎

As the functions
\gcd(a,b)
,
\chi(n)
,
\omega(n)
,
\left\lfloor\sqrt[m]{n}\right\rfloor
and
k!
are all represented by arithmetic terms, our both formulas for a divisor of
n
are arithmetic terms.

To compute some examples,

T(10)=\gcd\left(\frac{10}{\chi(10)},\left\lfloor\sqrt[2]{10}\right\rfloor!\right)=\gcd\left(\frac{10}{1},\left\lfloor\sqrt[2]{10}\right\rfloor!\right)=\gcd(10,6)=2,

T(20)=\gcd\left(\frac{20}{\chi(20)},\left\lfloor\sqrt[2]{20}\right\rfloor!\right)=\gcd\left(\frac{20}{2},\left\lfloor\sqrt[2]{20}\right\rfloor!\right)=\gcd(10,24)=2,

T(50)=\gcd\left(\frac{50}{\chi(50)},\left\lfloor\sqrt[2]{50}\right\rfloor!\right)=\gcd\left(\frac{50}{5},\left\lfloor\sqrt[2]{50}\right\rfloor!\right)=\gcd(10,5040)=10.

Appendix: More details about the formulas

For the function
\chi(n)
, one has:

\displaystyle\forall n\in\mathbb{Z}^{+},\quad\chi(n)=\frac{\operatorname{HW}(M(f,n,t,u))}{u}-t^{2},

where
t=n
,
u=n+4
, and

\displaystyle M(f,n,t,u)=\mathcal{C}_{2}(0,t,u)+\mathcal{A}_{2}(x_{1}^{4},t,u)+\mathcal{A}_{2}(-2nx_{1}^{2}x_{2},t,u)+\mathcal{A}_{2}(n^{2}x_{2}^{2},t,u).

Indeed,

(x^{2}-ny)^{2}=x^{4}-2nx^{2}y+n^{2}y^{2}.

For example,

\mathcal{A}_{2}(x_{1}^{4},t,u)=-(2^{u}-1)G_{4}(2^{2u},t)G_{0}(2^{2ut},t)=-(2^{n+4}-1)G_{4}(2^{2(n+4)},n)G_{0}(2^{2n(n+4)},n).

For the function
\omega(n)
, one has:

\displaystyle\forall n\in\mathbb{Z}^{+},\quad\omega(n)=\nu_{2}\left(\frac{\operatorname{HW}(M(g,4n,t,u))}{u}-t^{2}\right)-1.

where
t=4n
,
u=4n+4
, and

\displaystyle\begin{array}[]{llll}M(g,n,t,u)&=\mathcal{C}_{2}(1,t,u)&+\mathcal{A}_{2}(x_{1}^{4},t,u)&+\mathcal{A}_{2}(-2x_{1}^{2},t,u)\\
&+\mathcal{A}_{2}(-2nx_{1}^{2}x_{2},t,u)&+\mathcal{A}_{2}(n^{2}x_{2}^{2},t,u)&+\mathcal{A}_{2}(2nx_{2},t,u).\end{array}

Indeed,

(x^{2}-ny-1)^{2}=n^{4}+n^{2}y^{2}+1-2nx^{2}y+2ny-2x^{2}.

For example,

\mathcal{A}_{2}(-2nx_{1}^{2}x_{2},t,u)=2n(2^{u}-1)G_{2}(2^{2u},t)G_{1}(2^{2ut},t)=2n(2^{4n+4}-1)G_{2}(2^{8(n+1)},4n)G_{1}(2^{16n(n+1)},4n).

Lemma 8.1
.

The function
\left\lfloor\sqrt[m]{n}\right\rfloor
(for integer arguments
n\geq 1
and
m\geq 2
) can be represented by the arithmetic term

\operatorname{HW}(M(m,n))/(2^{nm^{2}+nm+2}+2(nm^{2}+nm)+9)-2^{7(nm^{2}+nm+1)}-1,

where
M(m,n)
is equal to

\begin{array}[]{llll}\mathcal{C}_{7}(2+n^{2},t,u)&+\mathcal{A}_{7}(-2mx_{1}x_{2},t,u)&+\mathcal{A}_{7}((m^{2}+1)x_{1}^{2},t,u)&+\mathcal{A}_{7}(-x_{4}2^{x_{1}+1},t,u)\\
+\mathcal{A}_{7}(-2x_{1},t,u)&+\mathcal{A}_{7}(-2(m+1)x_{1}x_{7},t,u)&+\mathcal{A}_{7}(x_{2}^{2},t,u)&+\mathcal{A}_{7}(-x_{5}2^{x_{1}+1},t,u)\\
+\mathcal{A}_{7}(2x_{5},t,u)&+\mathcal{A}_{7}(2x_{4}x_{5},t,u)&+\mathcal{A}_{7}(3x_{4}^{2},t,u)&+\mathcal{A}_{7}(-x_{7}2^{x_{1}+1},t,u)\\
+\mathcal{A}_{7}(2(1-n)x_{4},t,u)&+\mathcal{A}_{7}(2x_{4}x_{6},t,u)&+\mathcal{A}_{7}(x_{5}^{2},t,u)&+\mathcal{A}_{7}(-x_{4}2^{x_{2}+1},t,u)\\
+\mathcal{A}_{7}(-2nx_{6},t,u)&+\mathcal{A}_{7}(2x_{4}x_{7},t,u)&+\mathcal{A}_{7}(x_{6}^{2},t,u)&+\mathcal{A}_{7}(x_{3}x_{4}2^{x_{1}+1},t,u)\\

from

)

Arithmetic terms for

(

) and

(

)

3.

Supporting terms for binomial coefficients, factorial, and greatest common divisor

4.

The complete factoring terms

(

(

5.

Verification tests demonstrating that both terms successfully produce proper divisors for composite integers

The arithmetic term formulas presented in this paper are computationally infeasible for large
n
in practice, so the purpose of this code is merely to provide concrete verification that the constructions are mathematically sound. To make verifications practical, the code uses SageMath’s built-in functions where appropriate (e.g. for factorial and GCD operations), as the full arithmetic term implementations become intractable even for moderate values. However, the arithmetic term versions of these functions (see

from sage.all import *

def print_values(values, title=’’):
"""Print values in a comma-separated format."""
if title != ’’: print(f’{title}:’)
for v in values: print(f’{v}’, end=’,’)
print(’’)

def nu2(a):
"""2-adic valuation of a."""
if a == 0: return +Infinity
return Integer(a).valuation(2)

def HW(a):
"""Hamming weight (number of 1s in binary representation)."""
return bin(Integer(a)).count(’1’)

def G0(q, t):
"""G_0(q,t): geometric series."""
if q == 1: return t
return (q**t - 1) / (q - 1)

def G1(q, t):
"""G_1(q,t): weighted geometric series with j."""
if q == 1: return t*(t-1)/2
t1 = t - 1
return q * (t1 * q**t - t * q**t1 + 1) / (q - 1)**2

def G2(q, t):
"""G_2(q,t): weighted geometric series with j^2."""
if q == 1: return t*(t-1)*(2*t-1)/6
t1 = t - 1
return q * (
t1**2 * q**(t1 + 2)
- (t1**2 * 2 + t1 * 2 - 1) * q**(t1 + 1)
+ (t1 + 1)**2 * q**t1 - q - 1
) / (q - 1)**3

def G4(q, t):
"""G_4(q,t): weighted geometric series with j^4."""
if q == 1:
s = sum(j**4 for j in range(t))
return s
t1 = t - 1
return q * (
t1**4 * q**(t1 + 4)
+ (t1**4 * (-4) - 12 * t1**3 - 6 * t1**2 + t1 * 12 + 11) * q**(t1 + 1)
+ (t1**4 * 6 + 12 * t1**3 - 6 * t1**2 - t1 * 12 + 11) * q**(t1 + 2)
+ (t1**4 * (-4) - 4 * t1**3 + 6 * t1**2 - t1 * 4 + 1) * q**(t1 + 3)
+ (t1 + 1)**4 * q**t1 - q**3 - q**2 * 11 - q * 11 - 1
) / (q - 1)**5

def G(r, q, t):
"""Generalized geometric series G_r(q,t) = sum_{j=0}^{t-1} j^r * q^j."""
if r == 0: return G0(q, t)
elif r == 1: return G1(q, t)
elif r == 2: return G2(q, t)
elif r == 4: return G4(q, t)
else:
# Fallback for other powers
g = QQ(0)
qj = QQ(1)
for j in range(t):
g += qj * j**r
qj *= q
return g

def C(a, k, t, u):
"""Free term C_k(a, t, u)."""
return ((2**u - a + 1) * (2**(u * 2 * t**k) - 1)) / (2**u + 1)

def A(a, P, B, V, k, t, u):
"""Arithmetic term A_k for monomial from equation.

Parameters:
- a: coefficient
- P: list of powers [r_1, ..., r_k]
- B: list of bases (usually [2,2,...])
- V: list of exponential powers for bases
- k: dimension
- t, u: parameters
"""
result = -(2**u - 1) * a
for i in range(k):
q = B[i]**V[i] * 2**(u * t**i * 2)
g = G(P[i], q, t)
result *= g
return result

def M_chi(n):
"""Construct M(f, n, n, n+4) for chi function.

Based on f(x,y) = (x^2 - ny)^2 = x^4 - 2n*x^2*y + n^2*y^2
"""
k = 2
t = n
u = n + 4
B = [2, 2] # Bases
V = [0, 0] # Exponential powers for bases

return (C(0, k, t, u)
+ A(1, [4, 0], B, V, k, t, u) # x^4
+ A(-2*n, [2, 1], B, V, k, t, u) # -2n*x^2*y
+ A(n**2, [0, 2], B, V, k, t, u)) # n^2*y^2

def Chi(n):
"""Chi(n): largest s such that s^2 divides n."""
if n == 0: return 0
M = M_chi(n)
return Integer(HW(M) / (n + 4) - n**2)

def M_omega(n):
"""Construct M(g, 4n, 4n, 4n+4) for omega function.

Based on g(x,y) = (x^2 - ny - 1)^2 = x^4 - 2x^2 - 2n*x^2*y + n^2*y^2 + 2ny + 1
"""
k = 2
t = n
u = n + 4
B = [2, 2]
V = [0, 0]

return (C(1, k, t, u)
+ A(1, [4, 0], B, V, k, t, u) # x^4
+ A(-2, [2, 0], B, V, k, t, u) # -2x^2
+ A(-2*n, [2, 1], B, V, k, t, u) # -2n*x^2*y
+ A(n**2, [0, 2], B, V, k, t, u) # n^2*y^2
+ A(2*n, [0, 1], B, V, k, t, u)) # 2ny

def Omega(n):
"""Omega(n): number of distinct prime divisors of n."""
if n == 0 or n == 1: return 0
M = M_omega(4*n)
N = HW(M) / (4*n + 4) - (4*n)**2
return nu2(Integer(N)) - 1

def Binomial_term(a, b):
"""Binomial coefficient using arithmetic term formula."""
if b > a or b < 0: return 0
numerator = 2**(2*(a+2)*((a+1)**2 + b + 1))
denominator = 2**(2*(a+2)**2) - 2**(2*(a+2)) - 1
return Integer(floor(numerator / denominator) % 2**(2*(a+2)))

def Factorial_term(n):
"""Factorial using arithmetic term formula."""
if n == 0: return 1
binom = Binomial_term(8*n**2, n)
return Integer(floor(8**(n**3) / binom))

def Gcd_term(a, b):
"""GCD using arithmetic term formula."""
if a == 0: return b
if b == 0: return a
numerator = 2**(a*b*(a*b + a + b))
denominator = (2**(a**2 * b) - 1) * (2**(a*b**2) - 1)
return Integer((floor(numerator / denominator) % 2**(a*b)) - 1)

def FloorRoot_simple(m, n):
"""Simplified m-th root using native computation.

Note: The full arithmetic term implementation is extremely
complex. For verification purposes, we use Sage’s built-in computation.
"""
if n == 0: return 0
if m == 0: return 1
return Integer(floor(n**(1/m)))

def T(n):
"""Main factoring term T(n).

T(n) = gcd(n/chi(n), floor(omega(n)-th root of n)!)

For composite n, returns a non-trivial divisor.
"""
if n <= 1: return n

chi_n = Chi(n)
if chi_n == 0: chi_n = 1 # Avoid division by zero

omega_n = Omega(n)
if omega_n == 0: omega_n = 1 # Handles prime case

# Compute floor(omega(n)-th root of n)
root_val = FloorRoot_simple(omega_n, n)
fact_val = factorial(root_val) # Use built-in factorial for practical computation

# Compute GCD
arg1 = Integer(n / chi_n)
result = gcd(arg1, fact_val) # Use built-in gcd for practical computation

return result

def U(n):
"""Alternative factoring term U(n).

U(n) = (2 - chi(n)) * gcd(n, floor(omega(n)-th root of n)!)
+ (1 - (2 - chi(n))) * chi(n)

Uses truncated difference (monus operation).
"""
if n <= 1: return n

chi_n = Chi(n)
omega_n = Omega(n)
if omega_n == 0: omega_n = 1

root_val = FloorRoot_simple(omega_n, n)
fact_val = factorial(root_val) # Use built-in factorial for practical computation
gcd_val = gcd(n, fact_val)

# Monus operation: a - b if a >= b else 0
monus1 = max(2 - chi_n, 0)
monus2 = max(1 - monus1, 0)

result = monus1 * gcd_val + monus2 * chi_n
return Integer(result)
