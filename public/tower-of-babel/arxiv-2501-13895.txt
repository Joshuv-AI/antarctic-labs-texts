Scalar field source Teleparallel Robertson-Walker F ⁡ ( T ) F(T) -gravity solutions
A. Landry

Abstract
This paper investigates the teleparallel Robertson–Walker (TRW) F ⁡ ( T ) F(T) gravity solutions for a scalar field source. We use the TRW F ⁡ ( T ) F(T) gravity field equations (FEs) for each k k -parameter value case added by a scalar field to find new teleparallel F ⁡ ( T ) F(T) solutions. For k = 0 k=0 , we find an easy-to-compute F ⁡ ( T ) F(T) solution formula applicable for any scalar field source. Then, we obtain, for k = − 1 k=-1 and + 1 +1 situations, some new analytical F ⁡ ( T ) F(T) solutions, only for specific n n -parameter values and well-determined scalar field cases. We can find by those computations a large number of analytical teleparallel F ⁡ ( T ) F(T) solutions independent of any scalar potential V ⁡ ( ϕ ) V(\phi) expression. The V ⁡ ( ϕ ) V(\phi) independence makes the FE solving and computations easier. The new solutions will be relevant for future cosmological applications in dark matter, dark energy (DE) quintessence, phantom energy and quintom models of physical processes.

The present work first allowed us to solve the TRW
