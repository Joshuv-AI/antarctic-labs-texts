A tight meta-theorem for LOCAL certification of MSO 2 properties within bounded treewidth graphs
Linda Cook, Eun Jung Kim, Tomáš Masařík

Abstract
Distributed networks are prone to errors so verifying their output is critical. Hence, we develop LOCAL certification protocols for graph properties in which nodes are given certificates that allow them to check whether their network as a whole satisfies some fixed property while only communicating with their local network. Most known LOCAL certification protocols are specifically tailored to the problem they work on and cannot be translated more generally. Thus we target general protocols that can certify any property expressible within a certain logical framework. We consider Monadic Second Order Logic (MSO 2 ), a powerful framework that can express properties such as non- k k -colorability, Hamiltonicity, and H H -minor-freeness. Unfortunately, in general, there are MSO 2 -expressible properties that cannot be certified without huge certificates. For instance, non-3-colorability requires certificates of size Ω ⁡ ( n 2 / log ⁡ n ) \Omega(n^{2}/\log n) on general n n -vertex graphs (Göös, Suomela 2016). Hence, we impose additional structural restrictions on the graph. Inspired by their importance in centralized computing and Robertson-Seymour Graph Minor theory, we consider graphs of bounded treewidth. We provide a LOCAL certification protocol for certifying any MSO 2 -expressible property on graphs of bounded treewidth and, consequently, a LOCAL certification protocol for certifying bounded treewidth. That is for each integer k k and each MSO 2 -expressible property Π \Pi we give a LOCAL Certification protocol to certify that a graph satisfies Π \Pi and has treewidth at most k k using certificates of size 𝒪 ⁡ ( log ⁡ n ) \mathcal{O}(\log n) (which is asymptotically optimal). Our LOCAL certification protocol requires only one round of distributed communication, hence it is also proof-labeling scheme. Our result improves upon work by Fraigniaud, Montealegre, Rapaport, and Todinca (Algorithmica 2024), Bousquet, Feuilloley, Pierron (PODC 2022), and the very recent work of Baterisna and Chang.

Introduction

Distributed communication networks are increasingly vital in practical applications and consequently, the demand for distributed graph algorithms has likewise increased. Communication is a bottleneck in distributed systems, inspiring the need for algorithms where individuals only access local information about their network.
In the 1980s, Linial introduced the LOCAL model of computation to capture this notion of locality
[
Lin87
,
Lin92
]
.
Since then the LOCAL model has become a standard model for distributed graph algorithms.
A LOCAL algorithm is a distributed graph algorithm running in a
constant
synchronous number of rounds regardless of the network size.

Distributed networks are liable to errors and changes so certifying their solutions and network properties is critical. This motivates the need for “LOCAL certification protocols” (also called locally checkable proofs). These are protocols in which vertices are given “certificates of a graph property” that allow the vertices to check whether their network has this global property while only communicating within their local network.

Informally, a LOCAL certification for a graph property
\mathcal{P}
is a pair of algorithms called Prover and Verifier. Prover is a centralized algorithm which, upon a graph
G\in\mathcal{P}
, outputs a “certificate” for every vertex
v\in V(G)
. Verifier is a LOCAL algorithm that runs on each vertex
v
simultaneously with some certificate on the local network around
v
as input.
The key property of a LOCAL certification is that if certificates are corrupted, some vertex in the network should be able to detect this.
That is, in a LOCAL certification of a graph property
\mathcal{P}
if
G
does not satisfy
\mathcal{P}
then for any certificate assignment some vertex in
G
will output
No
when running the Verifier algorithm on the local instance.
On the other hand, if
G
satisfies
\mathcal{P}
then Prover will provide a truthful certificate, so to speak so that every vertex will output
Yes
when running the verification algorithm on the local instance. (We postpone all formal definitions until
Section

2
.)

Motivated by the fact that distributed networks may need to check their global properties often, LOCAL certification protocols are required to be both time and memory efficient.
Time efficiency is encapsulated by the fact that the Verifier is a LOCAL (i.e., constant round distributed) algorithm.
When a LOCAL certification protocol requires only exchanging certificates between neighbors, it is called a
proof labeling scheme

[
KKP10
]
. Note, a proof labeling scheme runs in a
single
round of distributed communication.
Our LOCAL certification protocols in this paper are proof labeling schemes.
Since time efficiency is hard-wired into the definition of LOCAL certification, the performance of a LOCAL certification protocol is measured by its memory efficiency.
The
size
of a LOCAL certification is the size of a maximum certificate assigned by Prover to a vertex (as a function of the number of vertices in the network). The primary goal in LOCAL certification is to minimize the
size
of a certification.
A survey by Feuilloley
[
Feu21
]
can be consulted for further background on LOCAL certification and an exposition of its relationship with other areas including
self-stabilization
.

It is well-known that
every
graph property has a trivial LOCAL certification using
\mathcal{O}(n^{2})
bits, where
n
is the total number of vertices
[
Feu21
]
.
Many interesting graph properties can be certified with just
\mathcal{O}(\log n)
bits, including planarity
[
FFM+20
]
,
or more generally embeddability on
any
fixed surface
[
FFM+23
,
EL22
]
,
(minimum weight) spanning tree
[
GS16
,
KKP10
,
KK06
]
,
maximum matching
[
GS16
,
CHPP20
]
, and bounded treedepth
[
FBP22
]
.
On the other hand, many simple graph properties require
\Omega(\log n)
bits.
For instance, in
[
GS16
]
Göös and Suomola showed that a LOCAL certification protocol for acyclicity, a spanning tree, or for having an odd number of vertices requires at least
\Omega(\log n)
bits.
In the same paper, the authors identified
\mathcal{O}(\log n)
certificates as a particularly important case.
\mathcal{O}(\log n)
has since become the gold-standard for certificate size in LOCAL certification;
In the literature, LOCAL certifications are called
compact
if they are of size
\mathcal{O}(\log n)
.

Most LOCAL certification protocols are specifically tailored to the problem they work on and cannot be translated more generally
[
FBP22
]
.
Hence, it is desirable to target general protocols in which
all
properties expressible within a particular framework can be certified with compact certificates.
In this paper, we consider general LOCAL certification protocols that can be used to certify any property expressible within “monadic second-order logic” (
MSO
2
).
MSO
2
-expressible properties include non-
k
-colorability,
non-Hamiltonicity, containing an
H
-minor for any fixed graph
H
, the existence of a subcubic spanning forest, and, of course, the complements of these properties.
Some
MSO
2
-expressible properties are known
not
to allow a compact LOCAL certification.
For example, certifying non-3-colorability already requires certificates of size
\Omega(n^{2}/\log n)

[
GS16
]
.
Hence, we need to impose additional structural conditions on the network in order to obtain compact certifications.

Inspired by their importance in algorithms and in graph structure, we consider bounded treewidth graphs in this paper.
Treewidth is a parameter measuring “close” a graph is to be a tree and having bounded treewidth has many practical and theoretical implications.
(see e.g., Epstein’s recent introductory article to treewidth
[
Epp25
]
).
In a seminal result in
centralized
computing, Courcelle showed there is a polynomial-time algorithm to test for any property expressible in
MSO
2
on graphs of bounded treewidth
[
Cou90b
]
.
In this paper, we obtain a
tight
LOCAL certification analog to this result.
Our main result is a compact proof labeling scheme for having
any

MSO
2
-expressible property in addition to having bounded treewidth.
As is standard in distributed computing all graphs considered here are
finite
and
connected
.

Theorem 1.1
.

For every integer
k
and for every
MSO
2
-sentence
\psi
on graphs, there is a proof labeling scheme
(\mathsf{P},\mathsf{V})
of size
O(\log n)

for the class of graphs which has treewidth at most
k

and satisfies the sentence
\psi.

As a consequence, we obtain:

Corollary 1.2
.

For any positive integer
k
, there is a proof labeling scheme of size
O(\log n)
for graphs of bounded treewidth.

Note that
\mathcal{O}(\log n)
is optimal in both
Theorem

1.1
and
Corollary

1.2
, even if we allow any fixed
constant
number of rounds. Connected graphs of treewidth one are trees. So any LOCAL certification that a graph has treewidth at most one is a LOCAL certification of acyclicity, which requires
\Omega(\log n)
bits
[
GS16
]
.

Our main result improves upon

The main result of

Certifying minor-closed properties

Robertson-Seymour Graph Minor Theory
[
Lov06
]
and Graph Product Structure Theory
[
DHJ+21
]
use bounded treewidth graphs as the “building blocks” of more general minor-closed classes. Hence, our main result is an important step towards finding a compact certification for (graph) minor-closed properties in general.
Minor closed properties play an important role in algorithm design and in structural graph theory (see surveys by Bienstock and Langston
[
BL95
]
, Lovász
[
Lov06
]
).
In their paper presenting a compact LOCAL certification for planarity (a minor-closed property)
Feuilloley, Fraigniaud, Montealegre, Rapaport, Rémila, and Todinca
[

]

asked the following question, which has since been reiterated in
[

,
Esp21
,
BFP24
,
FFM+20
,
FFM+23
]
.

Question 1.3
.

Is it true that every minor-closed property has a compact proof labeling scheme?

Question
1.3
is only known in certain special cases, such as bounded genus,
[
FFM+23
,
EL22
]
,
H
-minor-free for certain graphs
H
on at most five vertices
[
BFP24
]
.
Note,
H
-minor freeness is expressible in
MSO
2
[
CE12
]
.
Baterisna and Chang’s proof labeling scheme of
MSO
2
properties for graphs of bounded pathwidth implies that there is a compact certification for
F
-minor-freeness for any forest
F
by way of the “Excluding a Forest” theorem of Robertson and Seymour

]
.
Our main result extends this to all planar graphs:

Corollary 1.4
.

For any planar graph

there is a compact certification of

-minor-freeness.

Theorem

implies

In

In what has since become known as the Robertson-Seymour Graph Minor Theorem, Robertson and Seymour

Hence,

For any minor-closed family of graphs

Preliminaries

We use standard terminology for graph theory, e.g.,
[
Die05
]
. For further information on monadic second-order logic on graphs, see

]
.

Treewidth.
A
tree-decomposition
of a graph
G
is a pair
(T,\chi)
, consisting of a tree
T
and a mapping

\chi:V(T)\rightarrow 2^{V(G)}
, such that the following conditions are satisfied:

1.

for every vertex
v
of
G
, there is a node
t
of
T
with
v\in\chi(t),

2.

for every edge
uv
of
G
, there is a node
t
of
T
such that
\chi(t)
contains both
u
and
v,
and

3.

for every vertex
v
of
G
, the set of nodes
t
of
T
with
v\in\chi(t)
is connected in
T.

The
width
of a tree-decomposition
(T,\chi)
is defined as the maximum of
\lvert\chi(t)-1\rvert
taken over all nodes
t
of
T
,
and the
treewidth
, denoted as
\mathsf{tw}(G)
, of a graph
G
is the minimum width of a tree-decomposition of
G
.
For a tree-decomposition
(T,\chi)
of a graph
G
, we call each
t\in V(T)
a
tree node
, or simply a node, to distinguish it from the vertices of the underlying graph of the tree-decomposition. When
T
has a distinguished node called the
root
, we say that
T
is rooted and

(T,\chi)
is said to be a
rooted tree-decomposition
. Throughout this paper, any tree decomposition we consider shall be rooted.
We also use the standard terminology for a rooted tree such as
parent, child, ancestor, descendant
.
For a node
t
of
T
, we denote by
T_{t}
the subtree of
T
rooted at
t
, namely the subtree consisting of tree nodes whose path to the root on
T
traverses
t.

We use further notations for a tree-decomposition
(T,\chi)
of
G
from
[
Die05
,
BP16
]
. The set
\chi(t)
is called the
bag
of
t.

The
adhesion
of
t
(
\mathsf{adhesion}(t)
) is the set
\chi(t)\cap\chi(t^{\prime})
, where
t^{\prime}
is the parent of
t
if one exists, or defined as
\emptyset
if
t
is the root of
T
.
The
margin
of
t
(
\mathsf{margin}(t)
) is the set
\chi(t)\setminus\mathsf{adhesion}(t)
.
The
component
of
t
(
\mathsf{component}(t)
)is the set
\bigcup_{x\in V(T_{t})}\chi(x)\setminus\mathsf{adhesion}(t)
.
Now, a (rooted) tree-decomposition
(T,\chi)
is a
sane tree-decomposition
if for every node
t
of
T
,

•

the margin of
t
is nonempty,

•

every vertex in the adhesion of
t
has a neighbor in the component of
t,
and

•

the subgraph of
G
induced by the component of
t
is connected.

It is known that every graph admits an optimal tree decomposition that is sane.

Lemma 2.1

(
[
BP16
, Lemma 2.8]
)
.

For a tree-decomposition
(T,\chi)
of
G
of width at most
k
,
there is a sane tree-decomposition
(T^{\prime},\chi^{\prime})
of

of width at most

such that every bag of
(T^{\prime},\chi^{\prime})

is a subset of some bag in
(T,\chi)
.

Elimination Tree.

Graphs of bounded treewidth can be alternatively witnessed via the notion called an
elimination tree

[
Sch82
,
BP22
]
(also called a

), which is also routinely used for defining the treedepth of a graph

]

An
elimination tree

of a graph

is a rooted tree such that
V(F)=V(G)
and
for any edge

of
G
, either

is an ancestor of

or

is an ancestor of

.

Let

be the subtree of

to be the set of ancestors of

(including

The

is defined as

\max_{v\in V(T)}\lvert\mathsf{str}(v)\rvert-1.

The
width
of an elimination tree

is the maximum width of

Given an elimination tree

,
we can define the set

as the union of

It is routine to verify that

is a tree-decomposition of width at most

It is known
[

,

]
that the treewidth of

equals the minimum width of an elimination forest of

Proof Labeling Scheme.

We assume
that each vertex
v
of an
n
-vertex graph is given a unique identifier, written as
\mathsf{id}(v)
, from
\{1,\ldots,n\}
.

A

on a graph

is a mapping
\varphi:V(G)\rightarrow\{0,1\}^{*}
.
We say that
\varphi(v)
is a
label
of
v
of length
\lvert\varphi(v)\rvert
. The
size of a labeling

of

is the maximum length of
\varphi(v)
over all

For an
n
-vertex graph

,
we often express the size of a labeling of

as a function of

. That is to say, if
\max_{v\in V(G)}\lvert\varphi(v)\rvert=\mathcal{O}(t(n))
,
we say that
\varphi

.

Let
\Pi
be a graph property and we assume each graph
G
of
\Pi
is equipped with
an (arbitrary) identifier
\mathsf{id}:V(G)\rightarrow\{1,\ldots,\lvert V(G)\rvert\}
.
A

\mathsf{P}
for

is an algorithm that produces a labeling on a graph of
\Pi
.
For an input graph
G\in\Pi
equipped with
\mathsf{id}
, we denote by
\varphi_{\mathsf{P},G,\mathsf{id}}

the labeling
\mathsf{P}(G)
produced by the prover
\mathsf{P}
run on
G
.
When the prover
\mathsf{P}
and the input graph
G
with
\mathsf{id}
are clear in the context, we omit the subscript and simply write as
\varphi.

A
verifier

\mathsf{V}
is an algorithm which, given a number
i\in\mathbb{N}
and
a subset of
\mathbb{N}\times\{0,1\}^{*}
as input, outputs
Yes
or
No
.
A graph
G
equipped with
\mathsf{id}
and a labeling
\varphi
on
G

induce a canonical
local
instance to an arbitrary
\mathsf{V}
at each
v
, defined as

(\mathsf{id}(v),\{(\mathsf{id}(w),\varphi(w))\}_{w\in N[v]})

which we call the
local instance of
G
and

at

.

A
proof labeling scheme
(
PLS

\Pi

is a pair
(\mathsf{P},\mathsf{V})
consisting of a

\mathsf{P}
for
\Pi

and a

\mathsf{V}
, satisfy the following two properties together:

Completeness.
For every
(G,\mathsf{id})\in\Pi
, the verifier
\mathsf{V}
run on
the local instance of
G
and
\varphi_{\mathsf{P},G,\mathsf{id}}
at

Soundness.
For every
(G,\mathsf{id})\notin\Pi
and for every labeling
\varphi
on
G
,
there exists a vertex

such that the verifier
\mathsf{V}
on the local

G
and

at

outputs

.

A proof labeling scheme
(\mathsf{P},\mathsf{V})
is said to have size

for each

.

We make some remarks on the terminology.
In the context of local/distributed certification, we consider an algorithm that is run at each vertex
v
based on the information at
v
(in the form of a label
\varphi(v)
of
v
) as well as the information locally communicated with
v
. On the other hand, some of the local information may refer to
a faraway vertex
w
and neither
v
nor its neighbors do not even
know
whether
w
exists in reality or not. On this premise,
the reference to
w
at
v
is made by its identifier. So,
v
will be aware (by its label) of
some (unknown)
vertex with identifier

, and the vertex

Monadic Second Order Logic, relational structure,
MSO
2
-expressible property.

A
vocabulary

\Sigma
is a set of relation names, or
predicates
. Each predicate
R\in\Sigma
is associated with a number
\mathsf{ar}(R)\in\mathbb{N}
, called the
arity
of
R
.

Let
\Sigma
be a vocabulary. We assume that there is an infinite supply of symbols, all distinct from symbols in
\Sigma
, for
individual variables
and for
unary relation variables
(a.k.a.
set variables
). We typically use a lowercase to denote an individual variable and an uppercase letter for a set variable.

A
formula in monadic second-order logic
, simply put
mso
-formula, over a vocabulary
\Sigma
, is a string that can be built recursively using the logical connectives
\neg,\wedge,\vee,\rightarrow
, the
quantifiers

\forall,\exists
as well as the predicates in
\Sigma.

A string in the form
x=y
,
X(x)
for some set variable
X
or
R(x_{1},\ldots,x_{\mathsf{ar}(R)})
for some predicate
R\in\Sigma
is an

.
For two formulae
\psi
and
\phi
, the strings
\neg\psi
,
\psi\wedge\phi
,
\psi\vee\phi
and
\psi\rightarrow\phi
are formulae. For a formula
\psi
,
and for an individual variable
x
and a set variable
X
,

\forall x\psi
,
\exists x\psi
,
\forall X\psi
and
\exists X\psi
are all formulae. A variable in a formula
\psi
is
free
if it does not appear next to a quantifier. We often write the free variables of a formula
\psi
inside a parenthesis, e.g.,
\psi(x,y,Z)
, to highlight the free variables of
\psi
. A formula without a free variable is called a
sentence
and a formula without a quantifier is said to be

.
A formula is in

if it is in the form
Q_{1}x_{1}\cdots Q_{\ell}x_{\ell}\psi
such that
Q_{i}
is either the universal quantifier
\forall
or the existential quantifier
\exists
,

is an individual or a set variable, and

Let
\Sigma
be a vocabulary. For a set
U

, an

of a predicate

is a subset of
U^{\mathsf{ar}}(R)
.
A
relational structure over
\Sigma
, or
\Sigma
-structure, is a tuple
\mathbb{A}=(U,(R^{\mathbb{A}})_{R\in\Sigma})
consisting of a
universe

U
, and an interpretation
R^{\mathbb{A}}\subseteq U^{\mathsf{ar}(R)}
for each
R\in\Sigma
.

Fix a vocabulary
\Sigma
and let
\mathbb{A}
be a
\Sigma
-structure on the universe
U
.
An
interpretation
of an
mso
-formula
\psi
in
\mathbb{A}
is an assignment
s
of each variable in
\psi
to an element of
U
, in the case of an individual variable, or to a subset of
U
in the case of a set variable.
An interpretation
s
of
\psi
in
\mathbb{A}

evaluates
to

\mathbb{A}\models_{s}\psi
, or

, which can be determined as follows.
The atomic formulae

,

and

for some

will be evaluated

if and only if
s(x)\in s(X)
,
s(x)=s(y)

and
(s(x_{1}),\ldots,s(x_{\mathsf{ar}(R)}))\in R^{\mathbb{A}}.
For a formula such as
\neg\psi
and
\psi_{1}\wedge\psi_{2}
, the evaluation is determined by the evaluation of each subformula (such as
\psi
in the former, and
\psi_{i}
in the latter) in the given interpretation and the logical connective as a boolean operator. For
\psi=\exists x\varphi
, the formula
\psi
is evaluated to
true
in an interpretation

if and only if there is an interpretation

3.2
Locally verifiable treewidth and key statements

The result in
Section

3.1
holds when
G
admits
an elimination forest
F
of
0pt
as a subgraph of
G
.
In general, however, we cannot expect this condition to hold. In fact, even much weaker versions of this condition may not be satisfiable. In
[
BCH+24
]
it is shown that for
any
function
f
there exists a graph
G
which does not admit tree-decomposition
(T,\beta)
of width at most
f(\mathsf{tw}(G))
and

is a minor of

. For such graph

, any elimination

which is also a minor of

has the width larger than

.

In order to circumvent the issue that the edge of an elimination tree

may be absent in
G
,
we want to
simulate every edge of

by an actual path in
G
.
An

over

is a set of oriented paths between vertices of
G
, where each path in
\mathcal{P}
is obtained
by orienting the edges of some path of
G
. The

of a vertex

of

in the oriented path system

is the number of paths in
\mathcal{P}
which traverses
v
as a starting or internal vertex. Note that
even if
v
has congestion at most
0pt
, there may be arbitrarily many paths in
\mathcal{P}
having
v
as a destination vertex.
The
congestion
of
\mathcal{P}

is defined as the maximum congestion taken over all vertices of
G.

An oriented path system
\mathcal{P}
over
G
is to said to
witness an elimination tree

T
if the following holds.

(\star)
for every vertex

with a parent
\mathsf{p}(v)
in
F
,

either

and
\mathsf{p}(v)
are adjacent in

or there is a path in
\mathcal{P}
oriented from

to
\mathsf{p}(v)
.

We say that a graph

has

if
G
admits an elimination tree

of width at most
k
and
an oriented path system
\mathcal{P}
over

of congestion at most

for each connected component.

The proof labeling scheme for
\mathcal{G}_{t}
presented in the previous subsection is not difficult to generalize for graphs of small locally verifiable treewidth.

.

For each

To prove

, we use the notion of a guidance system introduced by Bojańczyk and
Pilipczuk
[

]
.
A
guidance system

\Lambda
over a graph
G
is a family of in-trees of
G
, where
each in-tree of
\Lambda
is an oriented tree obtained by orienting all the edges of a subtree of

toward a unique distinguished vertex denoted as the

.
For a vertex

of
G
, we define the set
\mathsf{roots}_{\Lambda}(x)
as

\{y\in V(G):\text{$y$ is a root of an in-tree in $\Lambda$ containing $x$}\}.

A guidance system
\Lambda

captures
a vertex set

if there is a vertex
u
such that

A\subseteq\mathsf{roots}_{\Lambda}(u).
We also say that

captures
A
in the guidance system
\Lambda.

For a family
\mathcal{A}
of vertex subsets of
V(G)
, a guidance system
\Lambda

captures

\mathcal{A}
if every set
A\in\mathcal{A}
is captured by
\Lambda.

We say that two in-trees of
G

intersect
if they share a vertex which is not the root in both in-trees. Notice that if two in-trees share a vertex
v
which is the root in one in-tree and not the root in another one then they intersect.
A guidance system
\Lambda
is

-colorable
if its intersection graph admits a proper
k
-coloring, or equivalently,
one can assign colors to the in-trees of
\Lambda
so that two in-trees have the same color only if they are vertex-disjoint
or the unique common vertex is the root in each in-tree.

There is a limitation in applying Lemma
4.2
to an arbitrary tree-decomposition
as such a guidance system might not exist for every tree-decomposition.
For example, consider a cycle
C_{n}
of length
n
and a path-decomposition of
C_{n}
in which each bag is a ‘triangle’ so that the resulting triangulation makes a triangulated ladder. One can quickly convince oneself that any guidance system capturing all adhesions of this tree-decomposition requires
\Omega(n)
colors. In contrast, a path-decomposition of
C_{n}
in which every bag is in the form
\{v,x_{i},x_{i+1}\}
for some vertex
v
and an edge
x_{i}x_{i+1}
of the path
C_{n}-v
, on the vertices
x_{1},x_{2},\cdots,x_{n-1}
in order, admits a guidance system of low chromatic number as observed also in
[
BP16
]
. Indeed, let
\vec{e_{i}}
be the trivial in-tree obtained by orienting the edge
x_{i}x_{i+1}
from
x_{i}
and
x_{i+1}
and let
\vec{P}
be the in-tree (directed path) obtained from the path
C_{n}-vx_{1}
by taking
v
as the root. Then the guidance system
\Gamma=\{\vec{P}\}\cup\{\vec{e_{i}}\mid i\in[n-2]\}
can be colored using three colors and it certainly captures all adhesions.
This indicates that one may need to locally change the given tree-decomposition in order to construct a guidance system with a low chromatic number.

Before we dive into the proof of the core argument of this section we need to introduce some model-checking notation and explain the main tool we will be using for the local certification.
Our approach is based on a proof published in the lecture notes

The approach uses objects called “evaluation trees” which play the role of remembering a structure of all possible assignments of vertices of a graph to variables of a formula.
The advantage of the evaluation trees is that in each node of the elimination tree, we can deal with a single object, the evaluation tree, that we modify bottom up on the elimination tree.
We only evaluate it in the root

The evaluation tree technique was recently formalized for the cliquewidth

and we will follow the notation established in this paper.
Due to the robustness of this technique, we are able to separate the model-checking part into a self-contained statement and use it as a black box for the local certification procedure.
Therefore, we present at this point only the necessary terminology before showing the proof of the local certification part.
For ease of discussion and without loss of generality, we assume for the whole paper that the formula

Definition 5.3

(Evaluation tree)

The

We define the first level to be a single node.
For each

We can observe that the evaluation tree contains all the information needed to successfully evaluate a given formula on a given graph (as a relational structure), but a big drawback is that it is astronomically large.

The goal will be to identify the isomorphism classes of subtrees of the partial evaluation tree, so we can reduce its size while keeping all the necessary information that we need to evaluate the formula.
In order to do it, we formulate what are the properties we can express about the leaves which allows us to forget some information while preserving the logical value of the formula. The aim is to create definitions such that the logical value of isomorphic subtrees is identical.

Definition 5.6

(Configuration)
.

Let
F
be an elimination tree of width
0pt

be a partial evaluation tree for a formula

with

A

of a leaf is a tuple consisting of:

•

a subgraph

of
G[V(G_{t})\cup\mathsf{str}(t)]
induced by at most

4
4

4

Note that we care only about the shape of such a subgraph and not about any specific vertex names.
,

•

an assignment of values from
V(G_{t}^{\prime})\cup\{ext\}
to the individual variables such that each vertex of
V(G_{t}^{\prime})
is assigned to some individual variable at least once,

•

an assignment of subsets of
V(G_{t}^{\prime})
to set variables,

This tuple satisfies the following properties:

•

non-external vertices of
G_{t}^{\prime}
could be additionally marked by labels corresponding to vertices in
\mathsf{str}(t)
, but those markings are disjoint (i.e., no two vertices of

.

Note that we use labels of size

to describe the markers by vertices in

many such distinct markers.
Observe that for any node

of the elimination tree, configurations of leaves in a partial evaluation tree can be determined.
However, we would like to go further and store in the leafs the configuration and keep on the edges only labels

in case of vertex variables.
In order to do that, we define a configuration evaluation tree.

A
Configuration evaluation tree
of an evaluation tree

such that it satisfies the following consistency requirements:
For each subtree

of depth
\ell<q
the value of the first
\ell

T^{\prime}

A vertex variable

, or

•

for all

, or

•

for all

a(z)\neq ext
.

•

Additionally, for all variables
z_{1},\ldots,z_{\ell^{\prime}}

A set variable

Note that a configuration evaluation tree can be easily obtained from a (partial) evaluation tree.
That means there is an algorithm converting a partial evaluation tree to a configuration tree.

Now, we can define the isomorphism.
We say that two configurations are

(denoted using
\sim
) if the corresponding graphs are isomorphic including all the labels and markings.
Building on that we define the isomorphism of configuration trees.

Definition 5.7

(Isomorphism between configuration evaluation trees)
.

Two configuration evaluation (sub)trees
Q
and
Q^{\prime}
of height
h\in[q]\cup\{0\}
for the same formula
\psi
and the same graph
G
, are

(also denoted using
\sim
) if

•

If
h=0
, the configuration of
Q
is isomorphic to the configuration of
Q^{\prime}

•

and if
h>0
, for all children of
Q
there is an isomorphic child of
Q^{\prime}
and vice-versa.

Now, we define our main object which is the reduced evaluation tree because a reduced evaluation tree does not need to be partial.
Hence, we define a compact evaluation tree as a shortcut to capture both properties together.

Definition 5.8

(Compact evaluation tree)
.

Reduced evaluation tree
is a tree where each leaf contains a configuration, and such that no two of its siblings are isomorphic.
For brevity, we say that we
reduced
a configuration evaluation tree.
We denote a configuration evaluation tree that is both partial and reduced as
compact evaluation tree
.

Note that whenever there is a configuration evaluation tree that is not reduced, we can perform a series of reductions exhaustively, so that the resulting tree is a reduced evaluation tree.

Observe that the number of non-isomorphic compact evaluation trees is bounded solely by a function of
q+0pt
.
In particular, the number of non-isomorphic leaves is at most
3^{q_{v}\choose 2}\cdot(q_{v}+1)^{q_{v}}\cdot(2^{q_{v}})^{q_{s}}\cdot(q_{v}+0pt)^{\underline{0pt-1}}
, where
q=q_{v}+q_{S}
is the sum of number of vertex quantifiers
q_{v}
and set quantifiers
q_{S}
.
We formalize this observation in the following lemma.

Lemma 5.9
.

Let
\phi
be an
MSO
1
-sentence using
q=q_{v}+q_{S}
quantifiers.
There is a computable function

such that for each node

of the elimination tree

of width

is bounded by
f(q+0pt)\cdot\log(n)
.

Proof.

We proceed by induction on
q

We already observed that the number of non-isomorphic configurations of leaves is bounded by
f^{\prime}(q+\omega)
for some computable function
f^{\prime}
.
Now, assume that such number is bounded by
b
for
q^{\prime}<q

q^{\prime}+1
level compact evaluation subtree by

.
Indeed, the node

is determined by the subset of the isomorphism types present as its children.
Hence, the final bound

The factor

where

while their number is bounded by

which was used to determine the number of different configurations in the leaves.
∎

In other words,
