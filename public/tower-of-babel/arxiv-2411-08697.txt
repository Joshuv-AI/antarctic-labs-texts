Local generation of tilings
Juliette Favereau and Mathieu Hoyrup

Abstract
In this article, we investigate the possibility of generating all the configurations of a subshift in a local way. We propose two definitions of local generation, explore their properties and develop techniques to determine whether a subshift satisfies these definitions. We illustrate the results with several examples.

Introduction

If ones fixes a Wang tileset, then the problem of generating a tiling of a plane is difficult in general. In the worst case, Hanf and Myers
[
Han74
,
Mye74
]
showed the existence of tilesets that tile the plane, but for which no algorithm can produce any tiling. On the other end of the spectrum, certain tilesets admit a simple procedure that can generate any tiling of the plane, in which the choices of the tiles in each cell only require local interaction (we give an example in the next paragraphs).

In this article, we investigate the problem, given a fixed Wang tileset or a more general subshift, of generating all the tilings of the plane in a local way, i.e. with a minimal amount of communication between the cells. Of course, one expects that only very few tilesets admit such local generation procedures. Our goal is to give precise definitions capturing this idea of local generation, and then to settle whether each given tileset or subshift satisfies these definitions. Let us stress that our perspective is orthogonal to the viewpoints provided by computability and complexity theory, and that the locality of a procedure is a form of combinatorial rather than computational simplicity.

Let us start by illustrating a simple local generation procedure on a motivating example, which is the Wang tileset shown in Figure
1
. It is the tileset with two colors (on the picture, an edge is either white or crossed by a black line) containing all the tiles having an even number of each color.

Figure 1:
A tileset admitting a local generation procedure

There is a simple local way of generating any tiling of the plane. First assign arbitrary bits to the points of the grid
\mathbb{Z}^{2}
, then for each edge
(a,b)
between two adjacent points, draw a black line crossing that edge if and only if the bits assigned to
a
and
b
differ. Intuitively, the bit assignment partitions
\mathbb{Z}^{2}
into connected components on which the assignment is constant, and the black lines are the boundaries between these regions. This construction is local in the sense that if two cells are not neighbors (horizontally, vertically or diagonally), then the choices of the tiles that are placed in those cells are made independently. The procedure that generates a tiling takes as input an arbitrary assignment of bits to the points of the grid, each cell then reads the bits assigned to its
4
corners and determines its tile. Note that this procedure enables adjacent cells to communicate in the sense that they share some input information. Similar procedures are used in computer graphics to generate textures in an efficient and local way
[
Lag09
]
.

A first natural definition, that would capture this generation procedure would be that the subshift is a factor of a fullshift, i.e. the image of a fullshift by a so-called sliding block code
[
LM95
]
, which is a finite rule determining the output content of a cell from the input content of a neighborhood of that cell. Indeed, the set of all possible assignments of bits is the fullshift
\{0,1\}^{\mathbb{Z}^{2}}
, and the function that converts this color assignment to the assignment of tiles to the cells can be evaluated in a local way. Equivalently, a sliding block code is a continuous function that commutes with the shift and can be seen as cellular automata with possibly different input and output alphabets.

However, this tentative definition would be very restrictive in several ways:

•

Only nearby cells can communicate, i.e. share input information,

•

All the cells are required to have the same rule.

We will relax these restrictions in our definitions. However, there is an important feature that we want to keep:

•

The content of each cell is determined by an input region whose
size
is uniformly bounded across the cells.

When this restriction is met, it gives rise to a procedure in which all the cells can determine their contents in parallel, reading a constant number of input symbols, so this procedure runs in constant parallel time.

We introduce two possible formalizations of the intuitive idea of local generation by defining two classes of subshifts
\mathscr{L}^{0}\subseteq\mathscr{L}^{1}
. The class
\mathscr{L}^{0}
is defined as the smallest class of subshifts containing certain basic subshifts (to be defined) including fullshifts, and closed under finite products and factors. The class
\mathscr{L}^{1}
is based on the notion of
narrow
function which is a relaxation of sliding block codes, in which the content of each output cell is determined by the content of a finite region of input cells whose size is bounded, but whose shape is arbitrary. The definition of
\mathscr{L}^{1}
is purely combinatorial in that it does not interact with the dynamical structure of the subshift. We never address the computability or complexity of the underlying procedures, and only focus on some sort of combinatorial complexity.

We develop the theories of the classes
\mathscr{L}^{0}
and
\mathscr{L}^{1}
, identify two obstructions to being in these classes, and apply these techniques to a number of subshifts. We also show that one-dimensional subshifts of finite type (SFTs) all belong to
\mathscr{L}^{0}
. It is not surprising as those subshifts are known to have many good properties. In particular, their configurations are nothing else than bi-infinite walks in a finite graph, which are intuitively easy to generate; the result shows that the class
\mathscr{L}^{0}
is sufficiently rich to capture this intuition. In a forthcoming article
[
FH24
]
, we apply the techniques develop in this article to classify all the Wang tilesets made with bicolor tiles having an even number of each color. We briefly summarize this classification at the end of this article.

The study of the class
\mathscr{L}^{0}
is related to the problem of expressing a subshift as a factor of another subshift, which was investigated in
[
Mar79
,
Boy83
,
BPS10
,
BMP18
]
, but our results are rather orthogonal.

The article is organized as follows. In Section
2
we present the definition of the two classes of subshifts
\mathscr{L}^{0}
and
\mathscr{L}^{1}
. In Section
3
we introduce the notions from symbolic dynamics that will play an important role in our analysis, recalling classical definitions and stating useful properties. In Section
4
we investigate several properties of our two classes. In Section
5
we develop a technique to prove that a subshift does not belong to
\mathscr{L}^{0}
, and apply it to a number of subshifts. We carry out an analogous development for
\mathscr{L}^{1}
in Section
6
, using different arguments. In Section
7
, we identify several subshifts that belong to
\mathscr{L}^{0}
, among which the one-dimensional SFTs. In Section
8
, we summarize the classification of the even bicolor tilesets. We end with Section
9
where we suggest future research directions. We also include an appendix, Section
A
, containing classical results that are used in the proofs.

Local generation

Let us first recall the minimal amount of definitions needed to introduce our notions of local generation.

Preliminaries

For

,
(\mathbb{Z}^{d},+,0)
is an abelian group. A

\mathbb{Z}^{d}

. A

X

X

\mathbb{Z}^{d}
-space
. A
\mathbb{Z}^{d}

2.2
The class
\mathscr{L}^{0}

We start with the strongest notion of local generation. The definition is motivated by the following observations:

•

Certain particular subshifts have a generation procedure that is intuitively local,

•

If two subshifts
X
and
Y
can be locally generated, then so is their product
X\times Y
(which is indeed a subshift), because the content of a cell is simply a pair whose components can be locally generated,

•

If a subshift
X
can be locally generated, then so is any factor
Y
of
X
. Indeed, if
f:X\to Y
is a factor map then the value of
f(x)_{p}
is determined by the values of
x
in finitely many cells around
p
, which in turn can be locally generated.

We then define the class
\mathscr{L}^{0}
as the smallest class of subshifts containing the basic subshifts from the first item, and that is closed under finite products and factors. We first need to choose basic subshifts to start with. We propose the following three families and explain why they can be considered as locally generated:

•

Fullshifts

A^{\mathbb{Z}^{d}}
: the contents of the cells can be chosen independently of each other.

•

Periodic shifts
: given a subgroup
H\subseteq\mathbb{Z}^{d}
, let
X_{H}\subseteq A^{\mathbb{Z}^{d}}
be the subshift containing all the
H
-periodic configurations, i.e.
x\in X_{H}
if
x(p+h)=x(p)
for all
p\in\mathbb{Z}^{d}
and
h\in H
. First, an element of
A^{\mathbb{Z}^{d}/H}
can be generated by independent choices, and then the content of a cell
p\in\mathbb{Z}^{d}
is determined by the symbol assigned to its equivalence class in
\mathbb{Z}^{d}/H
. We will denote
X_{H}
by
A^{\mathbb{Z}^{d}/H}
.

•

Countable subshifts
: the configurations of a countable subshift can be indexed by
\mathbb{N}
, so a configuration can be produced by first choosing a natural number
n
shared by all the cells, and then all the cells determine their contents in parallel. We do not address the computability or complexity of this procedure (it was shown in
[
ST13
]
that countable subshifts can be very uncomputable).

Definition 2.1

(The class
\mathscr{L}^{0}
)
.

Let
d\geq 1
. We define
\mathscr{L}^{0}_{d}
as the smallest class of subshifts containing the
\mathbb{Z}^{d}
-fullshifts, the periodic
\mathbb{Z}^{d}
-shifts and the countable
\mathbb{Z}^{d}
-subshifts, and which is closed under finite products and factors. Let
\mathscr{L}^{0}=\bigsqcup_{d\geq 1}\mathscr{L}^{0}_{d}
.

First, subshifts in
\mathscr{L}^{0}
can be presented in a simple form.

Proposition 2.1

(Canonical form)
.

One has
X\in\mathscr{L}^{0}
if and only if
X
is a factor of a finite product of basic subshifts. Moreover, we can assume that this finite product is

K\times A^{\mathbb{Z}^{d}}\times A^{\mathbb{Z}^{d}/H_{1}}\times\ldots\times A^{\mathbb{Z}^{d}/H_{k}}

where
K
is countable,
A
is finite and
H_{1},\ldots,H_{k}
are non-trivial subgroups of
\mathbb{Z}^{d}
of ranks at most
d-1
(and possibly
k=0
).

Proof.

We first show that every
X\in\mathscr{L}^{0}
is a factor of a finite product of basic subshifts, by induction on the finite tree describing the construction of
X
. If
X
is a basic subshift, then there is nothing to do. If
X=X_{0}\times X_{1}
with
X_{0},X_{1}\in\mathscr{L}^{0}
then by induction
X_{0}=f_{0}(P_{0})
and
X_{1}=f_{1}(P_{1})
where
f_{0},f_{1}
are factor maps and
P_{0},P_{1}
are finite products of basic subshifts. Therefore
X=f(P_{0}\times P_{1})
where
f(x_{0},x_{1})=(f_{0}(x_{0}),f_{1}(x_{1}))
, and note that
f
is a factor map and
P_{0}\times P_{1}
is a finite product of basic subshifts. If
X=f(Y)
where
Y\in\mathscr{L}^{0}
and
f
is a factor map, then by induction
Y=g(P)
for some finite product
P
of basic subshifts and some factor map
g
, so
x=f\circ g(P)
and
f\circ g
is a factor map.

Finally, a finite product of countable subshifts is a countable subshift, a finite product of fullshifts is a fullshift, and one can replace all the involved alphabets by the largest one because if
A\subseteq B
and
H\subseteq\mathbb{Z}^{d}
, then
A^{\mathbb{Z}^{d}/H}
is a factor of
B^{\mathbb{Z}^{d}/H}
. If
H
is trivial then
A^{\mathbb{Z}^{d}/H}
is a fullshift. If
H
has rank
d
, then
A^{\mathbb{Z}^{d}/H}
is finite hence countable so it can be merged with
K
.
∎

Note that the presence of a periodic shift
A^{\mathbb{Z}^{d}/H}
in the canonical form intuitively allows output cells that differ by an element of
H
to “communicate”, in the sense that they share some amount of input information and can make their choices in tandem with each other.

It will be convenient to present a canonical form in a more condensed way, as follows.

Proposition 2.2
.

One has
X\in\mathscr{L}^{0}
if and only if
X
is a factor of
K\times A^{E}
where
K
is a countable subshift,
A
is finite and
E
is a countable
\mathbb{Z}^{d}
-set.

It is understood that
A^{E}
is endowed with the
\mathbb{Z}^{d}
-action
(u\cdot a)_{p}=a_{u\cdot p}
for
a\in A^{E}
, and that
K\times A^{E}
is endowed with the product
\mathbb{Z}^{d}
-action
u\cdot(k,a)=(u\cdot k,u\cdot a)
.

Proof.

If
X\in\mathscr{L}^{0}
then by Proposition
2.1
,
X
is a factor of
K\times A^{\mathbb{Z}^{d}}\times A^{\mathbb{Z}^{d}/H_{1}}\times\ldots\times A^{\mathbb{Z}^{d}/H_{k}}=K\times A^{E}
where
E=\mathbb{Z}^{d}\sqcup\mathbb{Z}^{d}/H_{1}\sqcup\ldots\sqcup\mathbb{Z}^{d}/H_{k}

-action.

Conversely, if

is a factor of

for some countable
\mathbb{Z}^{d}
-set

, then by the orbit-stabilizer theorem (Theorem

), one has

where

is a subgroup of

. By compactness of

and continuity of

, there exists a finite set

such that

is determined by the values of

on

is a factor map, for any

is determined by the values of

is determined by the values of

on the obits of elements of

is a factor of

is a finite disjoint union of quotients of

is a finite product of

Example 2.1

(Cellular automaton)
.

A cellular automaton is a continuous function
f:A^{\mathbb{Z}^{d}}\to A^{\mathbb{Z}^{d}}
which commutes with the shift action, so its image is a factor of a fullshift and always belongs to

.

2.3
The class
\mathscr{L}^{1}

We present the second definition of local generation, which is a relaxation of the first one in which we forget the dynamical aspects of subshifts. We first need the following notions in order to formulate the definition of
\mathscr{L}^{1}
.

Let
E,F
be countable sets,
A,B
be finite alphabets and
f:A^{E}\to B^{F}
be continuous. The following notion is a restriction on the continuity of

, in which each output position has a narrow view on the input of

Definition 2.2

(Narrow function)
.

We say that
q\in F
is
determined
by

if for all inputs

that coincide on
R
,
f(x)
and
f(y)
coincide at position

.

Let

. The function
f:A^{E}\to B^{F}
is

-narrow
if each

is determined by a region of size at most

. We say that

is
narrow
if

is
r
-narrow for some

.

Note that a function is
0
-narrow if and only if it is constant. The identity
f:A^{E}\to A^{E}
is
1
-narrow. Every factor map is narrow. The composition of two narrow functions is narrow.

Example 2.2

(Non-uniform cellular automaton)
.

A non-uniform cellular automaton
[
DFP12
]
is a continuous function
f:A^{\mathbb{Z}^{d}}\to A^{\mathbb{Z}^{d}}
such that each
q\in\mathbb{Z}^{d}
is determined by
\mathcal{N}(q,r)=\{p\in\mathbb{Z}^{d}:d(p,q)\leq r\}
for some
r\in\mathbb{N}
(the metric

is defined by
d(p,q)=\max_{i}|p_{i}-q_{i}|
where
p_{i},q_{i}
are the coordinates of
p,q
respectively). The size of
\mathcal{N}(q,r)
is constant so

is narrow.

We come to the second notion of local generation. Let
\Sigma
be finite and
F
be countable.

Definition 2.3

(The class
\mathscr{L}^{1}
)
.

A compact set
X\subseteq\Sigma^{F}
belongs to
\mathscr{L}^{1}
if it is a countable union of images of narrow functions, i.e.
X=\bigcup_{n\in\mathbb{N}}X_{n}
where
X_{n}=\mathrm{im}(f_{n})
and
f_{n}:A_{n}^{\mathbb{N}}\to X
is
r_{n}
-narrow.

Note that
\mathbb{N}
can be replaced by any countable set. We will mostly consider the case when

and

is a
\mathbb{Z}^{d}
-subshift, but the definition makes sense more generally.

Finally, this notion of local generation is indeed a relaxation of the previous one.

Proposition 2.3
.

One has
\mathscr{L}^{0}\subseteq\mathscr{L}^{1}
.

Proof.

Let
X\in\mathscr{L}^{0}
, let
f:K\times A^{E}\to X
be a factor map given by Proposition
2.2
. For each
k\in K
, let

send

to

. As

is narrow, each

is narrow so

belongs to
\mathscr{L}^{1}
, as

is countable.
∎

The following notion will be useful to analyze narrow functions.

Proposition 2.4

(Input window)
.

Let
f:A^{E}\to B^{F}
be continuous. For each
q\in F
, there is a minimal subset of
E
that determines
q
. It is denoted by
\mathcal{W}_{f}(q)
and is called the

of

.

Proof.

Let
\mathcal{W}_{f}(q)
be the intersection of all the sets that determine
q
. We show that
\mathcal{W}_{f}(q)
determines
q
. Let
x,y\in A^{E}
coincide on
\mathcal{W}_{f}(q)
. As
f
is continuous, there is a finite set
R
that determines
q
, so
\mathcal{W}_{f}(q)\subseteq R
. Let
R\setminus\mathcal{W}_{f}(q)=\{r_{1},\ldots,r_{n}\}
. For each

, there exists

that determines

, and such that
r_{i}\notin R_{i}
. We inductively define

as follows. Let

and for

, let
x_{i+1}
coincide with

everywhere except possibly at

, where it takes the same value as

. As
x_{i+1}
and
x_{i}
coincide on

which determines

,
f(x_{i+1})
and

coincide at

. As

coincides with

on

,

and

coincide at

. As a result,

and
f(y)
coincide at

, so

indeed determines

.
∎

One should think of each output position

as observing the input of
f
through its input window

, and then choosing its content according to what it sees. A function

is

for all

.

2.3.1
Relevance of the definition

We now discuss why a compact set in
\mathscr{L}^{1}
always admits a generation procedure which is in a sense local.

Let
X\in\mathscr{L}^{1}
, i.e.
X=\bigcup_{n\in\mathbb{N}}X_{n}
where
X_{n}
is the image of some
r_{n}
-narrow function
f_{n}:A_{n}^{\mathbb{N}}\to\Sigma^{\mathbb{Z}^{d}}
. The procedure producing a configuration
x\in X
runs as follows:

•

Choose a number
n\in\mathbb{N}
and an arbitrary sequence of symbols
a\in A^{\mathbb{N}}_{n}
,

•

For each cell
p\in\mathbb{Z}^{d}
, read the values of
a
in at most
r_{n}
positions, determine the value of
f_{n}(a)
at position
p
, and fill
p
with that value.

Therefore, each cell has its own procedure, which takes a bounded amount of input information and outputs its content, and all the cells run their procedures in parallel with no explicit communication. Some bounded amount of communication is implicitly made possible as the cells share limited pieces of input information, via the number
n
and the overlaps between the windows of the cells.

Again we do not address the computability or complexity of computing the finite input window of each position and applying the rule that determines the output, and our results only focus on the “combinatorial” complexity of subshifts. In practice, the class
\mathscr{L}^{1}
will mainly be used to prove that particular subshifts do not belong to that class, which a fortiori prevents the existence of efficiently computable windows and rules. Conversely, for every particular subshift
X\in\mathscr{L}^{1}
considered in this article, the windows and rules will be explicit and efficiently computable.

3
Symbolic dynamics

We recall the classical vocabulary associated to subshifts.

3.1
Definitions

Let
d\geq 1
and
\Sigma
a finite alphabet.

We endow
\mathbb{Z}^{d}
with the metric

, for

Let

-pattern

is an

-pattern for some

of

extending
\pi

\pi^{\prime}
. A

If

F^{\prime}=F-p

\pi^{\prime}(q)=\pi(p+q)
for

. If
p\in\mathbb{Z}^{d}
and

is a configuration, then we say that a pattern
\pi

appears at position

in

if
\sigma^{p}(x)
extends
\pi
.

A
subshift
is a closed subset
X
of
\Sigma^{\mathbb{Z}^{d}}
which is
shift-invariant
, i.e. satisfies
\sigma^{p}(X)=X
for all
p\in\mathbb{Z}^{d}
. We fix a subshift
X\subseteq\Sigma^{\mathbb{Z}^{d}}
. All the subsequent notions are relative to
X
, but we do not mention
X
which will always be clear from the context. A
valid configuration
is an element
x\in X
. A
valid pattern
is a pattern appearing in some valid configuration, at any position or equivalently at the origin. Two disjoint regions

are

if for every valid

-pattern
\pi
and every valid
G
-pattern
\pi^{\prime}
,
\pi\cup\pi^{\prime}
is valid.

A
subshift of finite type (SFT)
is the subshift induced by a finite set
P
of finite patterns, called forbidden patterns, and defined as the set of configurations in which no
\pi\in P
appears. Let
C
be a finite set of colors. A
Wang tile
over

associates to each edge of the unit square a color in

. A
Wang tileset
over

is a set

of Wang tiles over

. It induces a
\mathbb{Z}^{2}
-subshift of finite type

which is the set of configurations in which neighbor cells have the same color on their common edge.

3.2
Dynamical properties

We recall classical dynamical properties of subshifts, that can be found in
[
Fur67
]
or
[
dV13
]
.

Definition 3.1
.

A subshift
X\subseteq\Sigma^{\mathbb{Z}^{d}}
is
transitive
if for every pair of valid finite patterns
\pi,\pi^{\prime}
, there exists
p\in\mathbb{Z}^{d}
such that
\pi\cup\sigma^{p}(\pi^{\prime})
is a valid pattern; in other words,
\pi
and
\pi^{\prime}
appear in a common configuration.

A subshift
X\subseteq\Sigma^{\mathbb{Z}^{d}}
is
strongly irreducible
if there exists
n\in\mathbb{N}
such that all regions
F,G\subseteq\mathbb{Z}^{d}
satisfying
d(F,G)\geq n
are independent.

A subshift
X\subseteq\Sigma^{\mathbb{Z}^{d}}
is
mixing
if for every
m\in\mathbb{N}
there exists
n\in\mathbb{N}
such that all regions
F,G\subseteq\mathbb{Z}^{d}
satisfying
\mathop{\mathrm{diam}}(F)\leq m,\mathop{\mathrm{diam}}(G)\leq m
and
d(F,G)\geq n
are independent.

A subshift
X\subseteq\Sigma^{\mathbb{Z}^{d}}
is
weakly mixing
if
X\times X
is transitive.

Transitive systems are called ergodic in
[
Fur67
]
and are also referred as irreducible in the literature. In the definitions of transitivity, weak mixing and mixing, one can equivalently replace finite regions by cubes
Q_{m}
. However, the version of strong irreducibility restricted to cubes is strictly weaker in general and is called block-gluing. One has the following chain of implications:

strongly irreducible
\implies
mixing
\implies
weakly mixing
\implies
transitive.

Strong irreducibility is a simple necessary condition for a subshift to be a factor of a fullshift.

The notion of weak mixing will be important in this article. Its meaning might not be clear at first, but the characterization given condition (3) in the next proposition is much more intuitive, easier to work with and is more apparently a relaxation of the mixing property. A part of this result was proved by Furstenberg
[
Fur67
]
in the context of continuous
\mathbb{Z}
-actions.

(Characterizations of weak mixing)

In order to prove mixing properties, it is often convenient to consider regions having certain prescribed shapes.

3.3
Weak factors and weak conjugacies

Usually, two
\mathbb{Z}^{d}
-subshifts
X
and
Y
are considered equivalent when they are
conjugate
, which means that there exists a homeomorphism
f:X\to Y
that commutes with the shift actions:
\sigma^{u}\circ f=f\circ\sigma^{u}
for all
u\in\mathbb{Z}^{d}
.

We will consider more flexible notions of factor and conjugacy, which allow one to move the group elements by a homomorphism, and are the natural notions of homomorphisms and isomorphisms in the category of continuous group actions, when the group is not fixed.

The main interest of these notions is that the classes
\mathscr{L}^{0}
and
\mathscr{L}^{1}
are preserved by taking weak factors, as we will show in the next section.

Definition 3.2
.

Let
X
be a
\mathbb{Z}^{d}
-subshift and
Y
a
\mathbb{Z}^{e}
-subshift. We say that
Y
is a
weak factor
of
X
if there exists a continuous surjective function
f:X\to Y
and a homomorphism
\varphi:\mathbb{Z}^{e}\to\mathbb{Z}^{d}
such that

\sigma^{p}\circ f=f\circ\sigma^{\varphi(p)}

for all
p\in\mathbb{Z}^{e}
.

Two subshifts
X,Y
are
weakly conjugate
if moreover
f
is a homeomorphism and
\varphi
an isomorphism (which is possible only when
d=e
).

Note that a weak factor (resp. weak conjugacy) map
f:X\to Y
can be seen as a factor (resp. conjugacy) map
f^{\prime}:X^{\prime}\to Y
where
X^{\prime}
is
X
endowed with the
\mathbb{Z}^{e}
-action
p\star x:=\varphi(p)\cdot x
.

The Curtis-Hedlund-Lyndon theorem
[
LM95
, Theorem 6.2.9]
, stating that factor maps are equivalent to sliding block codes, immediately extends to weak factor maps.

Proposition 3.3

(Curtis-Hedlund-Lyndon theorem)
.

Let
\varphi:\mathbb{Z}^{e}\to\mathbb{Z}^{d}
be a group homomorphism and
f:A^{\mathbb{Z}^{d}}\to B^{\mathbb{Z}^{e}}
be a function. The following conditions are equivalent:

•

f
is continuous and satisfies
\sigma^{p}\circ f=f\circ\sigma^{\varphi(p)}
,

•

There exists
N\geq 0
and a function
\rho:Q_{N}\to B
, where
Q_{N}=[-N,N]^{d}
, such that
f(x)_{p}=\rho(x|_{\varphi(p)+Q_{N}})
.

We will call the function
\rho
a
rule
. When
d=e
and
\varphi
is the identity, we are back to the notion of sliding block code.

Proof.

The usual proof when
\varphi
is the identity extends immediately as follows.

Assume the first conditions. As
f
is continuous, there exist
N
and
\rho
such that
f(x)_{0}=\rho(x|_{Q_{N}})
. One has
f(x)_{p}=(\sigma^{p}\circ f(x))_{0}=(f(\sigma^{\varphi(p)}(x))_{0}=\rho(\sigma^{\varphi(p)}(x)|_{Q_{N}})=\rho(x|_{\varphi(p)+Q_{N}})
.

Conversely, if
f
is given by
N
and
\rho
, then
f
is continuous and
(\sigma^{q}\circ f(x))_{p}=f(x)_{p+q}=\rho(x|_{\varphi(p)+\varphi(q)+Q_{N}})=\rho(\sigma^{\varphi(q)}(x)|_{\varphi(p)+Q_{N}})=f(\sigma^{\varphi(q)}(x))_{p}
, so
\sigma^{q}\circ f=f\circ\sigma^{\varphi(q)}
.
∎

Let us illustrate the notions of weak factor and weak conjugacy on several examples.

Example 3.1

(Fullshifts of different dimensions)
.

If
d>e
, then the fullshift
X_{e}:=\Sigma^{\mathbb{Z}^{e}}
is a weak factor of the fullshift
X_{d}:=\Sigma^{\mathbb{Z}^{d}}
. Let
\varphi:\mathbb{Z}^{e}\to\mathbb{Z}^{d}
be any injective homomorphism and
f:X_{d}\to X_{e}
be defined by
f(x)=x\circ\varphi
. One can check that
\sigma^{p}\circ f=f\circ\sigma^{\varphi(p)}
and
f
is surjective because for every
y\in X_{e}
, one can build a pre-image

by filling the positions in
\mathrm{im}(\varphi)
(without any conflict as
\varphi
is injective) and filling the rest arbitrarily.

However,
X_{d}
is not a weak factor of
X_{e}
. Indeed, if
f:X_{e}\to X_{d}
is a weak factor map via a homomorphism
\varphi:\mathbb{Z}^{d}\to\mathbb{Z}^{e}
, then
\varphi
is non-injective and if

then
f(X_{e})
only contains
p
-periodic configurations, as
\sigma^{p}\circ f=F\circ\sigma^{\varphi(p)}=f
.

Example 3.2

(Geometric transformation)
.

Let
\varphi:\mathbb{Z}^{d}\to\mathbb{Z}^{d}
be an isomorphism. It induces a homeomorphism
f:\Sigma^{\mathbb{Z}^{d}}\to\Sigma^{\mathbb{Z}^{d}}
defined by
f(x)=x\circ\varphi
. If
X\subseteq\Sigma^{\mathbb{Z}^{d}}
is a subshift, then

is also a subshift. It is usually not conjugate to
X
, but it is weakly conjugate because again,
\sigma^{p}\circ f=f\circ\sigma^{\varphi(p)}
for all
p\in\mathbb{Z}^{d}
.

For instance, a
\mathbb{Z}^{2}
-subshift can be reflected accross an axis, or rotated by

Example 3.3

(Higher power presentation)
.

Let
X\subseteq\Sigma^{\mathbb{Z}^{d}}
be a subshift,
a=(a_{1},\ldots,a_{d})\in\mathbb{Z}^{d}
have positive coordinates and

. The
a
-higher power presentation of

is the subshift
[X]_{a}\subseteq\Gamma^{\mathbb{Z}^{d}}
, where

, obtained by dividing
\mathbb{Z}^{d}
into a regular grid of copies of the rectangle

and seeing each pattern in such a rectangle as a symbol in the alphabet
\Gamma
(it can be found in
[
LM95
, Definition 1.4.4]
in the one-dimensional case). More formally,
[X]_{a}
is the image of

by the function

defined by

where

is the

-pattern appearing at position

in

.

One has

, so
[X]_{a}
is a weak factor of

via the homomorphism
\varphi(p)=ap
.

Example 3.4

(Fullshifts on different alphabets)
.

Let
X=\Sigma^{\mathbb{Z}^{d}}
and
Y=\Gamma^{\mathbb{Z}^{d}}
be
\mathbb{Z}^{d}
-fullshifts, with
|\Sigma|<|\Gamma|
. First,

is a factor of

: fix some surjective function

and extend it from

to

. Conversely,

is not a factor of

which is strictly larger than the entropy of

(see
[

]
). However,

is a weak factor of

Contrary to factors, weak factors do not preserve most of the dynamical properties, except the mixing property in some cases, as stated in the next result.

Proposition 3.4
.

Let
X
be a mixing subshift. If a subshift

is a weak factor of

satisfies at least one of the two following properties:

•

•

Or

Let

Now assume that

4
Properties of the classes
\mathscr{L}^{0}
and
\mathscr{L}^{1}

We investigate general properties of the classes.

First, belonging to
\mathscr{L}^{0}
implies the existence of strongly periodic configurations. A configuration
x\in\Sigma^{\mathbb{Z}^{d}}
is
strongly periodic
if its orbit
\{\sigma^{p}(x):p\in\mathbb{Z}^{d}\}
is finite, equivalently if there exists

such that

for all

. It is known that every countable subshift contains a strongly periodic configuration

Dol95

]
(indeed, any configuration of maximal Cantor-Bendixson rank is strongly periodic).

Proposition 4.1
.

Every subshift in
\mathscr{L}^{0}
has strongly periodic configurations.

Proof.

Let
f:K\times A^{E}\to X
be a factor map. As

is countable, it contains a strongly periodic configuration

. Let
a
be a constant sequence in
A^{e}
. The orbit of
(x,a)
is finite, so the orbit of
y=f(x,a)
is finite as well.∎

The next result investigates simple closure properties of narrow functions. It will only be used in Section
6.3.2
, and can be skipped at first reading.

Proposition 4.2
.

Let
\Sigma
be a finite alphabet,

and

be compact.

•

If
X,Y
are images of narrow functions, then so is

,

•

X
is the image of a narrow function and

is a finite pattern, then

is the image of a narrow function,

•

such that

is the image of a narrow function.

Proof.

Let
f:A^{\mathbb{N}}\to X
and

be surjective narrow functions with
|A|\geq 2
(we can indeed assume that they start from the same alphabet). Let

and note that

to

if

, to

otherwise. For any

Assume that

is the image of a narrow function

and let
\pi
be a finite pattern with domain

be a pattern on the input window

which is sent to

by

. As
X_{i}
is the image of a narrow function, so is
X_{i}\cap[\pi]
by the second assertion.
∎

4.1
Closure by weak factors

We now show that the classes
\mathscr{L}^{0}
and
\mathscr{L}^{1}
are closed under weak factors.

It is easier to prove this result by first showing that one can relax the definition of
\mathscr{L}^{0}
by replacing countable
\mathbb{Z}^{d}
-subshifts by any
\mathbb{Z}^{d}
-space which is countable, compact and zero-dimensional, giving an equivalent definition.

Proposition 4.3
.

Let
K
be a countable compact zero-dimensional
\mathbb{Z}^{d}
-space and
E
a countable
\mathbb{Z}^{d}
-set. If a
\mathbb{Z}^{d}
-subshift
X
is a factor of
K\times A^{E}
, then
X\in\mathscr{L}^{0}
.

Proof.

We build an intermediate countable
\mathbb{Z}^{d}
-subshift
K^{\prime}
which is a factor of
K
, and such that
X
is a factor of
K^{\prime}\times A^{E}
. The idea is to choose a finite clopen partition
\Gamma
of
K
and to build the corresponding symbolic dynamics: to each
k\in K
is associated the sequence of cells in
\Gamma
to which the iterates of
k
belong; the set of such sequences is a subshift.

Let
\Sigma
be the alphabet of
X
. By compactness of
K
and
A^{E}
, and zero-dimensionality of
K
, there exists a finite set
\Gamma
and continuous maps
g:K\to\Gamma
and
f:\Gamma\times A^{E}\to\Sigma
such that
F(k,a)_{0}=f(g(k),a)
(the preimages of elements of
\Gamma
by
g
form a clopen partition of
K
). Let
G:K\to\Gamma^{\mathbb{Z}^{d}}
be defined by
G(k)_{p}=g(p\cdot k)
and let
K^{\prime}=G(K)
. As
K
is countable, so is
K^{\prime}
. As
K
is compact and
G
is continuous,
K^{\prime}
is compact. One easily checks that
\sigma^{p}(G(k))=G(p\cdot k)
, so
G
is a factor map and
K^{\prime}
is shift-invariant. Therefore,
K^{\prime}
is a countable compact
\mathbb{Z}^{d}
-subshift.

One has
F(k,a)_{p}=f(G(k)_{p},p\cdot a)
. Indeed,

\displaystyle F(k,a)_{p}

\displaystyle=(p\cdot F(k,a))_{0}

\displaystyle=(F(p\cdot k,p\cdot a)_{0}

\displaystyle=f(g(p\cdot k),p\cdot a)

\displaystyle=f(G(k)_{p},p\cdot a).

Let
H:K^{\prime}\times A^{E}\to X
be defined by
H(k^{\prime},a)_{p}=f(k^{\prime}_{p},p\cdot a)
. The previous equality shows that for any
k\in K
and
a\in A^{E}
, one has
F(k,a)=H(G(k),a)
. That
H
is a factor map easily follows from the fact that
F
and
G
are factor maps. Therefore,
X
is a factor of
K^{\prime}\times A^{E}
, so
X\in\mathscr{L}^{0}
.
∎

We then derive the announced result.

Proposition 4.4

(
\mathscr{L}^{0}
is closed under weak factors)
.

If
Y
is a weak factor of
X
and
X\in\mathscr{L}^{0}
, then
Y\in\mathscr{L}^{0}
.

Proof.

Let
K
be a countable
\mathbb{Z}^{d}
-subshift and
E
a countable
\mathbb{Z}^{d}
-set. A weak factor of a factor of
K\times A^{E}
is a weak factor of
K\times A^{E}
, so it is sufficient to show that any weak factor of
K\times A^{E}
belongs to
\mathscr{L}^{0}
.

Let then
X\subseteq\Sigma^{\mathbb{Z}^{e}}
a
\mathbb{Z}^{e}
-subshift,
\varphi:\mathbb{Z}^{e}\to\mathbb{Z}^{d}
a group homomorphism and
F:K\times A^{E}\to X
a continuous surjective map such that
\sigma^{u}\circ F(k,a)=F\circ\sigma^{\varphi(u)}(k,a)
.

We build a countable compact
\mathbb{Z}^{e}
-space
K^{\prime}
and a countable
\mathbb{Z}^{e}
-set
E^{\prime}
such that
X
is a factor of
K^{\prime}\times A^{E^{\prime}}
. Let
K^{\prime}=K
with the continuous
\mathbb{Z}^{e}
-action
p\star k=\varphi(p)\cdot k
and
E^{\prime}=E
with the
\mathbb{Z}^{e}
-action
p\star e=\varphi(p)\star e
. One has
\sigma^{u}\circ F(k,a)=F(u\star(k,a))
so
F
is indeed a factor map for the
\star
action. Note that
K^{\prime}
is not necessarily a
\mathbb{Z}^{d}
-subshift, but it is a countable compact zero-dimensional
\mathbb{Z}^{d}
-space, so
X\in\mathscr{L}^{0}
by Proposition
4.3
.
∎

A similar result holds for
\mathscr{L}^{1}
.

Proposition 4.5

(
\mathscr{L}^{1}
is closed under weak factors)
.

Let
Y
is a weak factor of
X
. If
X
is the image of a narrow function, then so is
Y
. If
X\in\mathscr{L}^{1}
, then
Y\in\mathscr{L}^{1}
.

Proof.

Every weak factor map is narrow, and a composition of narrow functions is narrow.
∎

Example 4.1

(Building a
\mathbb{Z}^{2}
-subshift from a
\mathbb{Z}
-subshift)
.

To a
\mathbb{Z}
-subshift
X\subseteq\Sigma^{\mathbb{Z}}
we can associate a
\mathbb{Z}^{2}
-subshift
Y
, obtained by taking any configuration
x\in X
and copying it on each row. More precisely, let
F:\Sigma^{\mathbb{Z}}\to\Sigma^{\mathbb{Z}^{2}}
be defined by
F(x)=y
where
y_{(i,j)}=x_{i}
. The function
F:X\to Y
is a weak factor map via the homomorphism
\varphi:\mathbb{Z}^{2}\to\mathbb{Z}
sending
(i,j)
to
i
. Therefore, if
X\in\mathscr{L}^{i}
then
Y\in\mathscr{L}^{i}
as well.

4.2
Weak mixing and countable unions

Most of the subshifts that we consider in this article are weakly mixing. It turns out that this dynamical property makes it significantly simpler to prove that a subshift does not belong to
\mathscr{L}^{0}
or
\mathscr{L}^{1}
.

4.2.1
Compact classes of functions

We first state general results that we will apply to local functions (to be defined) and narrow functions.

If
A
is a finite alphabet and
E
is countably infinite, then
A^{E}
can be identified with
A^{\mathbb{N}}
, endowed with the metric
d(x,y)=2^{-n}
where
n
is minimal such that
x(n)\neq y(n)
.

Let
A,B
be finite alphabets and
Y\subseteq A^{\mathbb{N}}
be a compact set. The space of continuous functions
f:Y\to B^{\mathbb{N}}
is endowed with the
compact-open
topology, generated by the sets
\{f:f[u]\subseteq[v]\}
as a subbasis, where
u\in A^{*}
and
v\in B^{*}
are finite sequences and
[u],[v]
are the corresponding cylinders. For a function
h:\mathbb{N}\to\mathbb{N}
, the class

\mathcal{K}_{h}:=\{f:d(x,y)\leq 2^{-h(n)}\implies d(f(x),f(y))\leq 2^{-n}\}

is compact in this topology. The function
h
is called a modulus of uniform continuity for the functions in
\mathcal{K}_{h}
, and expresses that the first
n
symbols of
f(x)
depend on the first
h(n)
symbols of
x
.

Conversely, for every compact class
\mathcal{K}
, there exists
h:\mathbb{N}\to\mathbb{N}
such that
\mathcal{K}\subseteq\mathcal{K}_{h}
. All in all, a class
\mathcal{K}
is compact if and only if there exists a closed class
\mathcal{C}
and a function
h
such that
\mathcal{K}=\mathcal{K}_{h}\cap\mathcal{C}
.

Proposition 4.6
.

Let
Y
be compact,
B
be a finite alphabet and
\mathcal{K}
be a compact class of continuous functions from
Y
to
B^{\mathbb{N}}
.

If a compact set
X\subseteq B^{\mathbb{N}}
is not the image of any
f\in\mathcal{K}
, then there exists
N
such that
X
differs from the image of every
f\in\mathcal{K}
on
[0,N]
.

Proof.

For each
f\in\mathcal{K}
, there exists
n
such that
X
differs from
\mathrm{im}(f)
on
[0,n]
. The operator
f\mapsto\mathrm{im}(f)
is continuous, so for all
g\in\mathcal{K}
in a neighborhood of
f
,
X
differs from
\mathrm{im}(g)
on
[0,n]
. As
\mathcal{K}
is compact,
\mathcal{K}
is covered by finitely many such neighborhoods. Let
N
be the maximal
n
associated with these neighborhoods. For every
f\in\mathcal{K}
,
X
differs from
\mathrm{im}(f)
on
[0,N]
.
∎

When applying this result to
B^{\mathbb{Z}^{d}}
, we can replace
[0,N]
with
Q_{N}=[-N,N]^{d}\subseteq\mathbb{Z}^{d}
.

The next result shows that under certain conditions, allowing countable unions does not help when expressing a weakly mixing subshift.

Proposition 4.7

(Weak mixing and countable unions)
.

Let
\mathcal{C}=\bigcup_{i\in\mathbb{N}}\mathcal{K}_{i}
where each
\mathcal{K}_{i}
is a compact class of functions from a compact space
Y_{i}
to
B^{\mathbb{Z}^{d}}
such that for all
i\in\mathbb{N}
, all
f\in\mathcal{K}_{i}
and all
p\in\mathbb{Z}^{d}
, there exists
g\in\mathcal{K}_{i}
such that
\mathrm{im}(g)=\mathrm{im}(\sigma^{p}\circ f)
.

If
X
is a weakly mixing subshift, then
X
is a countable union of images of functions in
\mathcal{C}
if and only if
X
is the image of a single function in
\mathcal{C}
.

Proof.

Assume
X
is not the image of any function in
\mathcal{C}
. Assume for a contradiction that
X=\bigcup_{j\in\mathbb{N}}X_{j}
where each
X_{j}
is the image of a function
f_{j}\in\mathcal{C}
. By the Baire category theorem (Theorem
A.4
), there exist
j,k\in\mathbb{N}
and a finite valid pattern
\pi
on
Q_{k}
such that
X_{j}
contains all the valid extensions of
\pi
. Let
i
be such that
f_{j}\in\mathcal{K}_{i}
. By Proposition
4.6
, there exists
n
such that for every
g\in\mathcal{K}_{i}
,
X
differs from
\mathrm{im}(g)
on
Q_{n}
. As
X
is weakly mixing, there exists
p\in\mathbb{Z}^{2}
such that
Q_{k}
and
p+Q_{n}
are independent. In particular for every valid
Q_{n}
-pattern
\pi^{\prime}
,
\pi\cup\sigma^{p}(\pi^{\prime})
is valid. Any valid configuration extending
\pi\cup\sigma^{p}(\pi^{\prime})
extends
\pi
so belongs to
X_{j}
. By assumption about
\mathcal{C}
, there exists
g\in\mathcal{K}_{i}
such that
\mathrm{im}(g)=\mathrm{im}(\sigma^{-p}\circ f_{j})
. It implies that
X
coincides with
\mathrm{im}(g)
on
Q_{n}
, which contradicts the choice of
n
.
∎

4.2.2
Applications to local and narrow functions

We recall that a subshift
X
belongs to
\mathscr{L}^{0}
if there is a surjective factor map
f:K\times A^{E}\to X
, where
K
is a countable
\mathbb{Z}^{d}
-subshift and
E
a countable
\mathbb{Z}^{d}
-set. We show that if
X
is weakly mixing, then one can get rid of
K
at the price of relaxing the property of
f
being a factor map. Let first define the relevant relaxation.

Definition 4.1

(Local function)
.

A function
f:A^{\mathbb{Z}^{d}}\to B^{\mathbb{Z}^{d}}
is a
local function of radius
r
if each
p\in\mathbb{Z}^{d}
is determined by
\mathcal{N}(p,r)=\{q\in\mathbb{Z}^{d}:d(p,q)\leq r\}
.

When
A=B
, a local function is a non-uniform cellular automaton (Example
2.2
).

We then state the announced result.

Proposition 4.8

(Weak mixing vs countable unions)
.

If a weakly mixing subshift belongs to
\mathscr{L}^{0}
, then it is the image of
A^{\mathbb{Z}^{d}}\times\prod_{i=1}^{k}A^{\mathbb{Z}^{d}/H_{i}}
under a local function, where
A
is a finite alphabet and each
H_{i}
is a non-trivial subgroup of rank at most
d-1
.

Proof.

If
X\in\mathscr{L}^{0}
, then
X
is the image of
K\times Y
with
Y=A^{\mathbb{Z}^{d}}\times\prod_{i=1}^{k}A^{\mathbb{Z}^{d}/H_{i}}
under a factor map
f:K\times Y\to X
. For each
k\in K
, the function
f_{k}:Y\to X
sending
y
to
f(k,y)
is a local function of a certain radius
r
. The set
\mathcal{K}
of local functions
g:Y\to\Sigma^{\mathbb{Z}^{d}}
of radius
r
is a compact class of functions. Moreover, if
g\in\mathcal{K}
and
p\in\mathbb{Z}^{d}
, then
\sigma^{p}\circ g\circ\sigma^{-p}\in\mathcal{K}
and its image is
\mathrm{im}(\sigma^{p}\circ g)
. As
X
is weakly mixing and
X=\bigcup_{k\in K}\mathrm{im}(f_{k})
, we can apply Proposition
4.7
, implying that
X
is the image of a single
g\in\mathcal{K}
.
∎

An analogous result holds for the class
\mathscr{L}^{1}
: as far as weakly mixing subshifts are concerned, one can get rid of countable unions in the definition of
\mathscr{L}^{1}
.

Proposition 4.9

(Weak mixing vs countable unions)
.

A weakly mixing subshift belongs to
\mathscr{L}^{1}
if and only if it is the image of a narrow function.

We need the following result.

Lemma 4.1
.

Let
A,B,d
be fixed. For each
r
, there exists a compact class
\mathcal{K}
of functions whose images are exactly the images of
r
-narrow functions
f:A^{\mathbb{N}}\to B^{\mathbb{Z}^{d}}
.

Proof.

Let
(p_{n})_{n\in\mathbb{N}}
be a one-to-one enumeration of
\mathbb{Z}^{d}
. Let
\mathcal{K}
be the set of functions
f:A^{\mathbb{N}}\to B^{\mathbb{Z}^{d}}
such that for each
i
,
p_{n}
is determined by a region of size
r
contained in
[0,r(n+1))
. This class is compact and each function in
\mathcal{K}
is
r
-narrow. Moreover, every
r
-narrow function
f
has the same image as some
g\in\mathcal{K}
, obtained as follows. The idea is that we tighten the input positions as close to
0
as possible. We first let
W=\bigcup_{p\in\mathbb{Z}^{d}}\mathcal{W}_{f}(p)
and define an injective function
h:W\to\mathbb{N}
. We start defining an injective function
h:\mathcal{W}_{f}(p_{0})\to[0,r)
, which is possible as
|\mathcal{W}_{f}(p_{0})|\leq r
. Inductively assume that
h:\mathcal{W}_{f}(p_{0})\cup\ldots\cup\mathcal{W}_{f}(p_{n})\to[0,r(n+1))
has been defined. We extend
h
by sending
\mathcal{W}_{f}(p_{n+1})\setminus(\mathcal{W}_{f}(p_{0})\cup\ldots\cup\mathcal{W}_{f}(p_{n}))
to
[r(n+1),r(n+2))
in an injective way, which is possible as
|\mathcal{W}_{f}(p_{n+1})|\leq r
.

Given
x\in A^{\mathbb{N}}
, let
y\in A^{\mathbb{N}}
be defined by
y(k)=x(h(k))
and let
g(x)=f(y)
. Note that
g(x)(p_{n})
is determined by the values of
y
on
\mathcal{W}_{f}(p)
, i.e. by the values of
x
on
h(\mathcal{W}_{f}(p_{n}))
which has size at most
r
and is contained in
[0,r(n+1))
, so
g
belongs to
\mathcal{K}
. One has
\mathrm{im}(g)\subseteq\mathrm{im}(f)
because each
g(x)
is
f(y)
for some
y
. Conversely, one has
\mathrm{im}(f)\subseteq\mathrm{im}(g)
because for each
y
, define
x(k)=y(h^{-1}(k))
if
k\in\mathrm{im}(h)
and let
x(k)
be an arbitrary symbol otherwise: one has
g(x)=f(y)
.
∎

Proof of Proposition
4.9
.

By Lemma
4.1
, the narrow functions can be arranged as a countable union of compact classes
\bigcup_{A,r}\mathcal{K}_{A,r}
satisfying the assumptions of Proposition
4.7
.
∎

4.3
Separating the classes

We show that
\mathscr{L}^{1}
is strictly larger than
\mathscr{L}^{0}
(in the class of subshifts).

Proposition 4.10
.

There exists a subshift in
\mathscr{L}^{1}\setminus\mathscr{L}^{0}
.

Proof.

Let
f:\{0,1\}^{\mathbb{N}}\to\{0,1\}^{\mathbb{Z}}
send
x=x_{0}x_{1}x_{2}\ldots
to
y=\ldots x_{2}^{3}x_{1}^{2}x_{0}^{1}x_{1}^{2}x_{2}^{3}\ldots
, where
x_{0}
is placed at position
0
. Let
X\subseteq\{0,1\}^{\mathbb{Z}}
be the smallest subshift containing
\mathrm{im}(f)
.

We first show that
X\in\mathscr{L}^{1}
. The function
f
is
1
-narrow as each output position is determined by
1
input position.
X
is the union of the images of
\sigma^{k}(\mathrm{im}(f))
for
k\in\mathbb{Z}
, and of the limit sequences
\ldots 000111\ldots
and
\ldots 111000\ldots
. Therefore,
X
is a countable union of singletons and images of
1
-narrow functions. Each singleton is the image of a
0
-narrow function, so
X\in\mathscr{L}^{1}
.

Assume for a contradiction that
X
belongs to
\mathscr{L}^{0}
, i.e.
X=\bigcup_{i\in\mathbb{N}}X_{i}
where
X_{i}
is the image of a fullshift under a local function. Let
\pi
be the pattern
010
on
[-1,1]
and note that
[\pi]\cap X=[\pi]\cap\mathrm{im}(f)
. By the Baire category theorem, there exist
i\in\mathbb{N}
and a valid finite pattern
\pi^{\prime}
extending
\pi
such that
[\pi^{\prime}]\cap X\subseteq X_{i}
. Let
g:A^{\mathbb{Z}}\to X_{i}
be a surjective local function, let
W=[-k,k]
its window. Extend
\pi^{\prime}
to a valid pattern whose domain is
[1-\frac{n(n+1)}{2},\frac{n(n+1)}{2}-1]
for some
n\geq 2k+2
. Let
x=\ldots 000\pi^{\prime}000\ldots
and
y=\ldots 111\pi^{\prime}111\ldots
. One has
x,y\in[\pi^{\prime}]\cap X\subseteq\mathrm{im}(g)
, let
x_{0},y_{0}\in A^{\mathbb{Z}}
be pre-images by
g
of
x,y
respectively. Let
z_{0}\in A^{\mathbb{Z}}
coincide with
x_{0}
on
(-\infty,\frac{n(n+1)}{2}+k]
and with
y_{0}
on
[\frac{(n+1)(n+2)}{2}-k,+\infty)
, which is possible as
(\frac{(n+1)(n+2)}{2}-k)-(\frac{n(n+1)}{2}+k)=n+1-2k\geq 1
. Let
z=g(z_{0})\in[\pi^{\prime}]\cap X=[\pi^{\prime}]\cap\mathrm{im}(f)
. One has
z(-\frac{(n+1)(n+2)}{2})=0
and
z(\frac{(n+1)(n+2)}{2})=1
, which contradicts the fact that
z\in\mathrm{im}(f)
. We have reached a contradiction, so
X\notin\mathscr{L}^{0}
.
∎

5
Ramified subshifts

This section contains one of the main results of the article, which is a technique that can be used to show that a two-dimensional subshift does not belong to
\mathscr{L}^{0}
. The idea is to identify an invariant satisfied by finite products of basic subshifts and preserved under factor maps.

5.1
Definition of ramifications

We first introduce a definition which expresses the possibility of building a valid configuration from another one by inserting a pattern at a position and allowing modifications in a small neighborhood of the pattern.

If
F\subseteq\mathbb{Z}^{2}
and
r\in\mathbb{N}
, then let
\mathcal{N}(F,r)=\{p:\exists q\in F,d(p,q)\leq r\}
be the
r
-neighborhood of
F
.

Definition 5.1

(Graft)
.

Let
X
be a
\mathbb{Z}^{2}
-subshift,
F\subseteq\mathbb{Z}^{2}
,
\pi
an
F
-pattern,
x\in X
and
r\in\mathbb{N}
. We say that
\pi
can be
r
-grafted into
x
at position
p\in\mathbb{Z}^{2}
if there exists
y\in X
that coincides with
x
outside
\mathcal{N}(p+F,r)
and such that
\pi
appears at position
p
in
y
, i.e.
y(p+q)=\pi(q)
for
q\in F
.

Observe that
X
is strongly irreducible if and only if there exists
r
such that for every finite region
F
, every valid
F
-pattern can be
r
-grafted into every valid configuration (at any position, or equivalently at the origin).

The following condition about a configuration of a
\mathbb{Z}^{2}
-subshift
X
roughly expresses that it contains patterns appearing at regularly located positions, which cannot be moved at certain other positions.

Definition 5.2

(Ramification)
.

Let
X
be a
\mathbb{Z}^{2}
-subshift. A
ramification
is a configuration
x\in X
together with
r\in\mathbb{N},u,v\in\mathbb{Z}^{2}
and
F\subseteq\mathbb{Z}^{2}
such that for all
\lambda,\mu\in\mathbb{Z}
with
\mu>0
, the
F
-pattern appearing at position
\mu u+\lambda v
in
x
cannot be
r
-grafted into
x
at position
\lambda v
. We say that
x
is an
(r,v)
-ramification
.

Say that two vectors
v_{1},v_{2}\in\mathbb{Z}^{2}
are
independent
if
\lambda_{1}v_{1}+\lambda_{2}v_{2}=0
implies
\lambda_{1}=\lambda_{2}=0
, for
\lambda_{1},\lambda_{2}\in\mathbb{Z}
.

Definition 5.3

(Ramified subshift)
.

A
\mathbb{Z}^{2}
-subshift
X
is
ramified
if for every
r\in\mathbb{N}
there exist infinitely many pairwise independent vectors
v
such that
X
admits a ramification of radius
r
and support
v
.

If
r<r^{\prime}
, then an
(r^{\prime},v)
-ramification is also an
(r,v)
-ramification so, in order to show that
X
is ramified, it is sufficient to build a sequence
(v_{r})_{r\in\mathbb{N}}
of pairwise independent vectors such that
X
admits an
(r,v_{r})
-ramification for each
r
.

Remark 5.1

(Subshift of a ramified subshift)
.

Let
Y
be a ramified subshift. If the ramifications of
Y
can all be taken in a subshift
X\subsetneq Y
, then
X
is ramified as well. Indeed, if
x\in X
and a pattern cannot be
r
-grafted into
x
w.r.t.
Y
, then
a fortiori
it cannot be
r
-grafted into
x
w.r.t.
X
.

For instance, if
T
is a Wang tileset and
X_{T}
has ramifications that can all be built using a proper subset of tiles
R\subsetneq T
, then for each tileset
S
such that
R\subseteq S\subseteq T
,
X_{S}
is ramified as well.

Observe that if a subshift is ramified, then it is not strongly irreducible. Actually, showing the lack of strong irreducibility will always be the first step when building ramifications.

5.2
Examples

We illustrate the notion of ramification on a simple example.

5.2.1
The triangles

Consider the 2-dimensional SFT

5.3
An obstruction to being in

We state the main result of this section, which gives a way of showing that a subshift is not in
\mathscr{L}^{0}

Theorem 5.1

(An obstruction to being in
\mathscr{L}^{0}
)

Let

\mathbb{Z}^{2}

The rest of this section is devoted to the proof of this result.

5.3.1
Uniform case

We first show that a ramified subshift cannot be a factor of a product of fullshifts and periodic shifts. To do so, we prove that finite products of fullshifts and periodic shifts are not ramified, and that factor maps send non-ramified subshifts to non-ramified subshifts.

The “uniformity” in the title of this section refers to the fact that factor maps are uniform local functions, with the same rule in each cell. In the next section, we will consider the case of arbitrary, non-uniform local functions. Strictly speaking, the results from this section are implied by the results in the next section, but we prefer to present both because the first ones are easier to understand.

Theorem 5.2

Let

5.3.2
Non-uniform case

Our next goal is to extend Theorem
5.2
to show that a ramified subshift cannot be the image of a product of fullshifts and periodic shifts by a local function. Local functions do not necessarily play well with ramifications, so we need to refine the invariant property of being ramified. The idea is that local functions are actually uniform on arbitrarily large regular grids, by Gallai-Witt’s theorem (Theorem
A.2
). Using this observation, we show that they preserve a finite version of ramifications. We start defining this finite version, which is unfortunately rather technical and non-intuitive, but makes the argument go through.

Definition 5.4

Let

and

-pattern appearing at position

-grafted into

at position

.

A subshift

and for infinitely many pairwise independent vectors

-ramified.

Remark 5.2

(Ramified implies finitely ramified)

If

-ramified. Indeed, given

Theorem 5.3

Let

6
Transitions

We now develop a technique to prove that a subshift does not belong to
\mathscr{L}^{1}
. There are many subshifts in which typical configurations exhibit a transition between two regions that use different sets of tiles. We show that this type of subshift does not belong to
\mathscr{L}^{1}
.

6.1
An obstruction to being in
\mathscr{L}^{1}

The simplest example of a subshift witnessing a transition is the one-dimensional SFT on the alphabet
\{\raisebox{-1.42262pt}{\includegraphics[]{Tiles/tiles-7}},\raisebox{-1.42262pt}{\includegraphics[]{Tiles/tiles-8}}\}
with forbidden pattern
.

We denote by
X_{\overline{\mathbb{Z}}}
the induced
\mathbb{Z}
-subshift, because it is conjugate to
\overline{\mathbb{Z}}=\mathbb{Z}\cup\{-\infty,+\infty\}
whose topology is generated by the basis of open sets
\{n\}
,
[n,+\infty]
and
[-\infty,n]
for
n\in\mathbb{Z}
, and with the continuous
\mathbb{Z}
-action

\displaystyle p\cdot n

\displaystyle=p+n\text{ for finite $n$},

\displaystyle p\cdot(+\infty)

\displaystyle=+\infty,

\displaystyle p\cdot(-\infty)

\displaystyle=-\infty.

The conjugacy map
F:\overline{\mathbb{Z}}\to X_{\overline{\mathbb{Z}}}
sends
n\in\overline{\mathbb{Z}}
to the configuration which is white on the cells
p<-n
and black on the cells
p\geq-n
. In particular, it sends
-\infty
to the white configuration and
+\infty
to the black configuration.

The next result shows in particular that
X_{\overline{\mathbb{Z}}}
is not the image of a narrow function. It relies of the following simple observation: given a continuous function, if two output regions do not communicate, i.e. are determined by disjoint input regions, then they are independent. We recall that, once a continuous function
f:A^{\mathbb{N}}\to B^{E}
is fixed, to each output position
p\in E
is associated its input window
\mathcal{W}_{f}(p)\subseteq\mathbb{N}
. More generally, to each output region
F\subseteq E
we associate its input window
\mathcal{W}_{f}(F)=\bigcup_{p\in F}\mathcal{W}_{f}(p)
. The values of an input
x\in A^{\mathbb{N}}
on
\mathcal{W}_{f}(F)
determined the value of the output
f(x)
on
F
.

Lemma 6.1
.

Let
f:A^{\mathbb{N}}\to B^{E}
be a narrow function and
X
be the image of
f
. Let
F,G\subseteq E
. If
\mathcal{W}_{f}(F)\cap\mathcal{W}_{f}(G)=\emptyset
, then
F
and
G
are independent w.r.t.
X
.

Proof.

Let
\pi_{F},\pi_{G}
be a valid patterns on
F,G
respectively. There exist a
\mathcal{W}_{f}(F)
-pattern
\xi_{F}
and a
\mathcal{W}_{f}(G)
-pattern
\xi_{G}
such that
f([\xi_{F}])\subseteq[\pi_{F}]
and
f([\xi_{G}])\subseteq[\pi_{G}]
. As
\mathcal{W}_{f}(F)
and
\mathcal{W}_{f}(G)
are disjoint, there exists
x\in A^{\mathbb{N}}
extending
\xi_{F}\cup\xi_{G}
, so
f(x)
extends
\pi_{F}\cup\pi_{G}
which is then valid. Therefore
F
and
G
are independent.
∎

Proposition 6.1
.

Let
A
be a finite alphabet. If
f:A^{\mathbb{N}}\to X_{\overline{\mathbb{Z}}}
is a narrow function, then its image is finite. Moreover, if
f
is
r
-narrow, then

|\mathrm{im}(f)|\leq|A|^{\frac{r(r+1)}{2}}.

In particular,
X_{\overline{\mathbb{Z}}}
is not the image of a narrow function.

Proof.

We prove the result by induction on
r
. Let
b(r)=|A|^{\frac{r(r+1)}{2}}
. For
r=0
, a
0
-narrow function is contant, so
\mathrm{im}(f)=1=b(0)
.

Let
r\geq 1
and assume by induction that the result holds for
r-1
. Let
f:A^{\mathbb{N}}\to X_{\overline{\mathbb{Z}}}
and let
E=\{p\in\mathbb{Z}:\exists x,y\in\mathrm{im}(f),x(p)\neq y(p)\}
be the set of cells to which
f
assigns several values. If
E=\emptyset
, then
f
is constant so
|\mathrm{im}(f)|=1\leq b(r)
. Assume from now one that
E\neq\emptyset
.

Let us show that for every pair of distinct elements
p,q\in E
, the cells
p
and
q
are correlated in
\mathrm{im}(f)
. We can assume w.l.o.g. that
p<q
. As
p,q\in E
, there exist
x,y\in\mathrm{im}(f)
such that
x(p)=\raisebox{-1.42262pt}{\includegraphics[]{Tiles/tiles-8}}
and
y(q)=\raisebox{-1.42262pt}{\includegraphics[]{Tiles/tiles-7}}
. However, there is no
z\in\mathrm{im}(f)
such that
z(p)=x(p)
and
z(q)=y(q)
. We have shown that
p
and
q
are correlated in
\mathrm{im}(f)
. Therefore, the input windows
\mathcal{W}_{f}(p)
and
\mathcal{W}_{f}(q)
of
p
and
q
w.r.t.
f
must have non-empty intersection. Note that for
p\notin E
,
\mathcal{W}_{f}(p)=\emptyset
because
x(p)
is constant for
x\in\mathrm{im}(f)
.

Fix some
p\in E
and let
\pi
be an input
\mathcal{W}_{f}(p)
-pattern. We define
f_{\pi}:A^{\mathbb{N}}\to\overline{\mathbb{Z}}
by
f_{\pi}(x)=f(x^{\prime})
where
x^{\prime}
is obtained from
x
by replacing the content of
\mathcal{W}_{f}(p)
by
\pi
. The function
f_{\pi}
is
(r-1)
-narrow. Indeed, every output cell
q
is determined by
\mathcal{W}_{f}(q)\setminus\mathcal{W}_{f}(p)
, whose size is at most
r-1
as it is either empty, or strictly contained in
\mathcal{W}_{f}(q)
which has size at most
r
.

Therefore, by induction hypothesis,
\mathrm{im}(f_{\pi})\leq b(r-1)
. One has
\mathrm{im}(f)=\bigcup_{\pi}\mathrm{im}(f_{\pi})
, and there are
|A|^{|\mathcal{W}_{f}(p)|}\leq|A|^{r}
many
\mathcal{W}_{f}(p)
-patterns

, so
|\mathrm{im}(f)|\leq|A|^{r}b(r-1)=b(r)
.
∎

We now state the main technique that will be used to show that a subshift is not in
\mathscr{L}^{1}
, and which is a direct consequence of the previous results.

Theorem 6.1

(An obstruction to being in
\mathscr{L}^{1}
)
.

Let
X
be a
\mathbb{Z}^{d}
-subshift. If
X
is weakly mixing and
\overline{\mathbb{Z}}
is a weak factor of
X
, then
X\notin\mathscr{L}^{1}
.

Proof.

As
X
is weakly mixing we can apply Proposition
4.9
, so we only need to show that
X
is not the image of a narrow function. By assumption, there exists weak factor map
F:X\to\overline{\mathbb{Z}}
, which is in particular a narrow function. If
X
was the image of a narrow function
G:A^{\mathbb{N}}\to X
, then
\overline{\mathbb{Z}}
would be the image of the narrow function

, contradicting Proposition
6.1
.
∎

In Section

6.3.1
Stacks

Consider the SFT

with forbidden patterns
\begin{smallmatrix}1\\

and
\begin{smallmatrix}2&0\end{smallmatrix}

2

’s with a stack of
0
’s above it.

Let us first show that
\overline{\mathbb{Z}}
is not a weak factor of

, implying that Theorem

cannot be applied.

Proposition 6.3
.

Let
X,Y
be subshifts, and assume that
Y
is a weak factor of
X
. If the strongly periodic configurations of
X
are dense in
X
, then the strongly periodic configurations of
Y
are dense in

.

Proof.

Let
X
be a
\mathbb{Z}^{d}
-subshift,
Y
a
\mathbb{Z}^{e}
-subshift,

a weak factor map coming with
\varphi:\mathbb{Z}^{e}\to\mathbb{Z}^{d}
. If

is strongly periodic, i.e. its orbit
O_{x}:=\{\sigma^{p}(x):p\in\mathbb{Z}^{d}\}
is finite, then the orbit of

is finite because it is contained in

: indeed,
\sigma^{p}(f(x))=f(\sigma^{\varphi(p)}(x))\in f(O_{x})
. As

is continuous, it sends a dense set to a dense set.
∎

Our subshift
X
contains a dense set of strongly periodic configurations: given a valid

-pattern
\pi
, extend
\pi
on
[0,n-1]\times[0,n]
by adding a row filled with

’s at the top, and copy this pattern at each point of the grid

, yielding a strongly periodic configuration extending
\pi
. However in
\overline{\mathbb{Z}}
the only strongly periodic configurations are its two fixed points, which are not dense.

We now show that

, using a different but related argument.

Proposition 6.4
.

X\notin\mathscr{L}^{1}
.

Proof.

We show that

is not the image of a narrow function and that

is weakly mixing, which implies that

by Proposition

.

Let

be an

-narrow function. Let

from Proposition

. Let

be such that

, and let

be such that

. Consider the valid pattern

on the region

6.3.2
Irrational rotation

We show that the classical
\mathbb{Z}
-subshifts encoding irrational rotations on the circle do not belong to
\mathscr{L}^{1}
. It confirms the intuition that building a valid configuration cannot be achieved in local way, because all the cells need to share an infinite amount of information, namely the point of the circle that is encoded into the configuration.

We recall the definitions, more details can be found in Pytheas Fogg
[
BFMS02
, Section 6.1.2]
.

Let
\mathbb{R}/\mathbb{Z}
be the circle group. Let
\alpha\in(0,1)
be irrational and let
R_{\alpha}:\mathbb{R}/\mathbb{Z}\to\mathbb{R}/\mathbb{Z}
be the irrational rotation sending
x
to
x+\alpha\mod 1
. Consider two partitions of the circle:

\displaystyle I_{0}

\displaystyle=[0,1-\alpha)

\displaystyle I^{\prime}_{0}

\displaystyle=(0,1-\alpha]

\displaystyle I_{1}

\displaystyle=[1-\alpha,1)

\displaystyle I^{\prime}_{1}

\displaystyle=(1-\alpha,1].

To any
x\in\mathbb{R}/\mathbb{Z}
we associate the two sequences
w(x),w^{\prime}(x)\in\{0,1\}^{\mathbb{Z}}
defined by
w_{n}(x)=a
such that
R_{\alpha}^{n}(x)\in I_{a}
and
w^{\prime}_{n}(x)=a
such that
R_{\alpha}^{n}(x)\in I^{\prime}_{a}
. More directly, these sequences can be defined for
x\in[0,1]
by

\displaystyle w_{n}(x)

\displaystyle=\lfloor(n+1)\alpha+x\rfloor-\lfloor n\alpha+x\rfloor,

\displaystyle w^{\prime}_{n}(x)

\displaystyle=\lceil(n+1)\alpha+x\rceil-\lceil n\alpha+x\rceil.

We then consider the subshift containing all these sequences:

X_{\alpha}=\{w(x):x\in[0,1)\}\cup\{w^{\prime}(x):x\in[0,1)\}.

For most
x
, one has
w(x)=w^{\prime}(x)
. The two sequence are different only if some
n\alpha+x
is an integer, in which case
w_{n-1}(x)w_{n}(x)=10
and
w^{\prime}_{n-1}(x)w^{\prime}_{n}(x)=01
, and the two sequences coincide elsewhere.

It turns out that
X_{\alpha}
is not weakly mixing, so we need another argument.

Proposition 6.5
.

X_{\alpha}\notin\mathscr{L}^{1}
.

Proof.

Let
F\subseteq\mathbb{Z}
be a finite set, and
u\in\{0,1\}^{F}
a finite pattern. We show that
X\cap[u]
is not the image of a narrow function, which implies that
X\notin\mathscr{L}^{1}
by Proposition
4.2
.

We say that
x\in\mathbb{R}/\mathbb{Z}
is
generic
if no
n\alpha+x
is an integer. The generic points are dense in the circle, and their images by
w
and
w^{\prime}
are dense in
X_{\alpha}
. Let
x
be generic such that
w(x)=w^{\prime}(x)
extends
u
. For a real number
z
, let
\{z\}=z-\lfloor z\rfloor\in[0,1)
be its fractional part. Let
i_{0}\in\mathbb{N}
be such that
1-\alpha-2^{-i_{0}-1}>0
, and
\epsilon=\min\{\alpha,1-\alpha-2^{-i_{0}-1}\}
. For each
i\geq i_{0}
, there exists
n_{i}\in\mathbb{Z}
such that
\{n_{i}\alpha+x\}\in(1-\alpha-2^{-i},1-\alpha-2^{-i-1})
. Let
v
be a finite extension of
u
which is compatible with
w(x)
and such that if
w(y)
extends
v
, then
|x-y|<\epsilon
. Let
g:X\cap[v]\to\{0,1\}^{\mathbb{Z}}
send
s
to
i\mapsto s(n_{i})
. We claim that the image of
g
is an infinite set of non-decreasing binary sequences.

One has
w_{n_{i}}(x)=0
, so
\mathrm{im}(g)
contains the zero sequence.

Let
y
be such that
w(y)
extends
v
. We show that
g(w(y))
is non-decreasing. As
|x-y|<\epsilon
, one has
\{n_{i}\alpha+y\}=\{n_{i}\alpha+x\}+(y-x)
because these quantities are equal modulo
1
and both belong to
[0,1)
. If
w_{n_{i}}(y)=1
, then
\{n_{i}\alpha+y\}\geq 1-\alpha
, so
\{n_{i+1}\alpha+y\}=\{n_{i+1}\alpha+x\}+(y-x)>\{n_{i}\alpha+x\}+(y-x)=\{n_{i}\alpha+y\}\geq 1-\alpha
, so
w_{n_{i+1}}(y)=1
. Therefore,
g(w(y))
is indeed non-decreasing.

We show that
g(X\cap[v])
has infinitely many elements. As

is generic, the function
w
is continuous at
x
so there exists
\delta>0
such that if
|x-y|<\delta
, then
w(y)
extends
v
. Let

be such that

. For
i\geq i_{1}
, let
y=x+1-\alpha-2^{-i}-\{n_{i}\alpha+x\}
. One has
|x-y|<\delta
and
\{n_{i}\alpha+y\}=1-\alpha-2^{-i}
. The sequence
g(w(y))
starts with
i

0
’s, followed by
1

The function

is
1
-narrow, because its output at position

is determined by its input at position

. Therefore, if

was the image of a narrow function then by composing with

, we would obtain a narrow function whose image is an infinite set of non-decreasing sequences, i.e. of elements of

is not the image of a narrow function by Proposition

∎

7
Subshifts that can be locally generated

We now present examples of subshifts that belong to
\mathscr{L}^{0}
. We first show that
\mathscr{L}^{0}
is preserved under higher power presentations. This result will be used in the next arguments.

7.1
Higher power presentations and intertwining

A common way of building a subshift from another one is to gather the cells into rectangular blocks and interpret the content of each block as an element of a larger alphabet. It can be found in
[
LM95
, Definition 1.4.4]
in the one-dimensional case, where it is called a higher power presentation of the subshift.

This operation sometimes results in a subshift which is easier to analyze. Intuitively, this operation should not affect the possibility of local generation. Indeed, we show that a higher power presentation of a subshift belongs to
\mathscr{L}^{0}
if and only if the original subshift belongs to
\mathscr{L}^{0}
. Although intuitive, it turns out that this result is not so straightforward to prove.

Let
a=(a_{1},\ldots,a_{d})\in\mathbb{Z}^{d}
be a vector with positive coordinates and consider the hyper-rectangle
R_{a}=[0,a_{1}-1]\times\ldots\times[0,a_{d}-1]
.

Definition 7.1
.

To any
\mathbb{Z}^{d}
-subshift
X\subseteq\Sigma^{\mathbb{Z}^{d}}
we associate its
a
-higher power presentation

[X]_{a}
, which is a
\mathbb{Z}^{d}
-subshift on the alphabet
\Gamma:=\Sigma^{R_{a}}
defined as follows. Let
F_{a}:\Sigma^{\mathbb{Z}^{d}}\to\Gamma^{\mathbb{Z}^{d}}
be such that
F_{a}(x)_{p}
is the
R_{a}
-pattern appearing at position
ap=(a_{1}p_{1},\ldots,a_{d}p_{d})
in
x
. We then define
[X]_{a}=\mathrm{im}(F_{a})
.

The subshift
[X]_{a}
is always a weak factor of
X
, but not the other way round (see Example
3.3
]).

The main goal of this section is to show that higher power presentations behave well w.r.t. the class
\mathscr{L}^{0}
, as expressed by the next result.

Theorem 7.1

(
\mathscr{L}^{0}
and higher power presentations)
.

Let
a\in\mathbb{Z}^{d}
have positive coordinates and
X
be a
\mathbb{Z}^{d}
-subshift. One has

X\in\mathscr{L}^{0}\iff[X]_{a}\in\mathscr{L}^{0}.

The rest of this section is devoted to the proof of Theorem
7.1
and can be skipped at first reading.

Let us start with a result highlighting the role of the compact subshift
K
in the definition of
\mathscr{L}^{0}
when it is finite.

Proposition 7.1

(Higher power presentations and factors)
.

Let
X,Y
be subshifts. The following conditions are equivalent:

•

Y
is a factor of
K\times X
for some finite
\mathbb{Z}^{d}
-set
K
,

•

There exists
a\in\mathbb{Z}^{d}
with positive coordinates such that
[Y]_{a}
is a finite union of factors of
[X]_{a}
.

Proof.

Assume that
Y
is a factor of
K\times X
for some finite
\mathbb{Z}^{d}
-set
K
. For each
k\in K
, let
f_{k}:X\to Y
be defined by
f_{k}(x)=f(k,x)
. As
K
is finite, each vector
e_{i}
of the canonical basis of
\mathbb{Z}^{d}
has a multiple
a_{i}e_{i}
, with
a_{i}>0
, that acts as the identity on
K
. Let
a=(a_{1},\ldots,a_{d})
. For any
p\in\mathbb{Z}^{d}
,
ap
acts as the identity on
K
. It implies that
\sigma^{ap}\circ f_{k}=f_{k}\circ\sigma^{ap}
:

\displaystyle\sigma^{ap}\circ f_{k}(x)

\displaystyle=\sigma^{ap}\circ f(k,x)

\displaystyle=f(ap\cdot k,\sigma^{ap}(x))

\displaystyle=f(k,\sigma^{ap}(x))

\displaystyle=f_{k}\circ\sigma^{ap}(x).

Let
F_{X}:X\to[X]_{a}
and
F_{Y}:Y\to[Y]_{a}
be the canonical homeomorphisms, which satisfy
\sigma^{p}\circ F_{Z}=F_{Z}\circ\sigma^{ap}
(for
Z=X
or
Y
). Each function
F_{Y}\circ f_{k}\circ F_{X}^{-1}
is a factor map from
[X]_{a}
to its image, and
[Y]_{a}
is the finite union over
k\in K
of these images.

Conversely, assume that
[Y]_{a}=\bigcup_{i\in I}f_{i}([X]_{a})
where
I
is finite,
f_{i}:[X]_{a}\to[Y]_{a}
is continuous and commutes with the shift actions. Let
K=I\times\mathbb{Z}^{d}/a\mathbb{Z}^{d}
where
I
is endowed with the trivial action
p\cdot i=i
. The functions
f^{\prime}_{i}=F_{Y}^{-1}\circ f_{i}\circ F_{X}:X\to Y
satisfy
\sigma^{ap}\circ f^{\prime}_{i}\circ\sigma^{-ap}=f^{\prime}_{i}
, which implies that for any
p\in\mathbb{Z}^{d}
,
\sigma^{p}\circ f^{\prime}_{i}\circ\sigma^{-p}
only depends on the equivalence class
[p]
of
p
modulo
a\mathbb{Z}^{d}
. Therefore, the following function
g:K\times X\to Y
is well-defined:

g(i,[p],x)=\sigma^{p}\circ f^{\prime}_{i}\circ\sigma^{-p}(x).

It is continuous and surjective; moreover, it commutes with the actions:

\displaystyle\sigma^{q}\circ g(i,[p],x)

\displaystyle=\sigma^{q}\circ\sigma^{p}\circ f^{\prime}_{i}\circ\sigma^{-p}(x)

\displaystyle=\sigma^{p+q}\circ f^{\prime}_{i}\circ\sigma^{-(p+q)}(\sigma^{q}(x))

\displaystyle=g(i,[p+q],\sigma^{q}(x))

\displaystyle=g(q\cdot(i,[p],x)).

Therefore,

is a factor map from
K\times X
to
Y
.
∎

We introduce another way of building new subshifts from old ones, that will be used to prove Theorem
7.1
.

Definition 7.2

(Intertwining)
.

To a subshift

we associate the subshift
\overline{X}^{a}
whose configurations are made of
|R_{a}|
intertwined configurations of

. Precisely, let

be defined by
\psi_{a}(\overline{x})_{aq+r}=x^{r}_{q}
, where

and
\overline{x}=(x^{r})_{r\in R_{a}}
. We define

.

One easily checks that
\overline{X}^{a}
is indeed a subshift.
The restriction

is a homeomorphism but is not a conjugacy. One has

, so

is a weak factor map.

Proposition 7.2

(
\mathscr{L}^{0}
and intertwining)
.

X\in\mathscr{L}^{0}\iff\overline{X}^{a}\in\mathscr{L}^{0}
.

Proof.

As

is a factor of
X^{R_{a}}
which is a weak factor of
\overline{X}^{a}
, if

then

.

For the converse implication, it is not difficult to see that intertwining preserves basic subshifts and commutes with finite products and factor maps:

•

If

is a countable subshift, then so is

, because it is homeomorphic to

which is countable,

•

If

is the fullshift, then
\overline{X}^{a}=A^{\mathbb{Z}^{d}}
is the fullshift,

•

If

is a periodic shift, then
\overline{X}^{a}=A^{\mathbb{Z}^{d}/aH}
is a periodic shift as well,

•

\overline{X\times Y}^{a}
is conjugate to
\overline{X}^{a}\times\overline{Y}^{a}
,

•

Finally, if

is a factor of

, then

is a factor of
\overline{X}^{a}
.

As a result, if

, i.e.

is a factor of a finite product of basic subshifts

, then

is a factor of the product of basic subshifts

.
∎

Intertwining and higher power presentations are related in the following way.

Proposition 7.3
.

X
is a factor of
[\overline{X}^{a}]_{a}
.

Proof.

Let

be the projection sending

to

We now have all the ingredients to prove the main result of this section.

Proof of Theorem

.

The function

satisfies

, so

The case of

Proposition 7.4

(

.

7.2
One-dimensional SFTs

One-dimensional SFTs are known to be much simpler than higher-dimensional ones in many respects: several problems such as non-emptyness are decidable, many properties have simple characterizations that do not extend to higher-dimensions, etc. We show that they are also simpler in the sense of local generation.

Theorem 7.2
.

Every one-dimensional SFT belongs to
\mathscr{L}^{0}
.

To a finite directed graph
G=(V,E)
(possibly with loops) we associate the subshift
X_{G}
, called vertex shift in
[
LM95
, Definition 2.3.7]
, which is the set of bi-infinite walks through
G
, i.e.
X_{G}=\{x\in V^{\mathbb{Z}}:\forall n,(x_{n},x_{n+1})\in E\}
.

It is well-known that every SFT
X
is conjugate to
X_{G}
for some finite directed graph
G

[
LM95
, Proposition 2.3.9 (3)]
, obtained as follows. Let
n
be larger than the lengths of forbidden patterns, let
V
be the set of valid words of length
n
and
E
be the set of pairs
(au,ub)
where
|u|=n-1
,
a,b
are letters and
au,ub\in V
. The function
f:X\to X_{G}
such that
f(x)_{i}=x_{i}\ldots x_{i+n-1}
is then a conjugacy.

We show that for any finite directed graph
G
,
X_{G}\in\mathscr{L}^{0}
. The idea is that the walks through
G
can be described in the following way: for some
k\geq 1
and some equivalence relation between the vertices of
G
, a walk is described by giving, for each
n
which is a multiple of
k
, the equivalence class of the vertex visited at position
n
(we call this sequence a partial sequence) and then choosing a vertex in each equivalence class and filling the intermediate positions. The careful choice of
k
and the equivalence relation makes the set of partial sequences countable. The second step is local, because the choices of vertices between positions
n
and
n+k
can be made by knowing the equivalence classes at positions
n
and
n+k
only. Let us now give the details.

To a finite directed graph
G=(V,E)
we associate its powers
G^{k}=(V,E^{k})
, where
(u,v)\in E^{k}
if there exists a walk of length
k
from
u
to
v
in
G
, i.e. there exist vertices
v_{0},\ldots,v_{k}
with
v_{0}=u,v_{k}=v
and
(v_{i},v_{i+1})\in E
for all
i<k
.

Lemma 7.1
.

Let
G
be a finite directed graph (we allow loops). There exists
k\geq 1
such that
G^{k}
is transitive (i.e., if there is a walk from
u
to
v
, then there is an edge from
u
to
v
).

Proof.

We first show the result if the graph has the property that every vertex that belongs to a circuit has a loop to itself (call it the loop property).

Let
u,v
be two distinct vertices and let
L_{u,v}\subseteq\mathbb{N}
be the set of lengths of walks from
u
to
v
. We claim that
L_{u,v}
is either finite or co-finite. Indeed, if there is no walk from
u
to
v
visiting some vertex twice, then the lengths of these walks are bounded by the number of vertices; if there is a path from
u
to
v
visiting some vertex
w
twice, then by the loop property
w
has a loop to itself. The portion of the walk between the two occurrences of
w
can be replaced by that loop and one can create walks of any larger length by cycling though that loop as any times as wanted.

Let
k_{u,v}
be an upper bound on
L_{u,v}
or its complement, and let
k=\max_{u,v}k_{u,v}
. Let
u\neq v
. If there is a walk in
G^{k}
from
u
to
v
, then there is a walk in
G
whose length is a non-zero multiple of
k
, in particular this length is at least
k
. By choice of
k
, there is a walk in
G
of length exactly
k
, i.e. there is an edge in
G^{k}
from
u
to
v
. Therefore,
G^{k}
is transitive.

We now prove that for any finite directed graph
G
, there exists
k\geq 1
such that
G^{k}
has the loop property. For each vertex
u
that belongs to a circuit, let
k_{u}
be the length of such a circuit. Let
k
be a common multiple of the
k_{u}
’s. In
G^{k}
, if a vertex
u
belongs to a circuit, then
u
belongs to a circuit in
G
so it belongs to a circuit in
G
of length
k
, hence
u
has a loop to itself in
G^{k}
. Therefore,
G^{k}
has the loop property. By the first part of the proof,
G^{kl}
is transitive for some
l
.
∎

Note that
G^{k}
need not be the transitive closure of
G
: for instance if
G
is a cycle of length
2
, then
k
must be a multiple of
2
and
G^{k}
has two connected components, each one consisting of a vertex with a loop.

Lemma 7.2
.

Let
G
be a finite directed graph which is transitive. Then
X_{G}\in\mathscr{L}^{0}
.

Proof.

Let
H
be the condensation of
G
, which is the directed acyclic graph whose vertices are the strongly connected components of
G
, but in which we keep the loops of
G
. More precisely, if
C
is a strongly connected component of
G
, then either
C
is a singleton with no loop, or each vertex in
C
has a loop to itself. In
H
,
C
will have a loop to itself it and only if the vertices of
C
have loops to themselves in
G
. As
H
has no cycle other than loops, the subshift
X_{H}
is countable: a configuration is obtained by concatenating a finite number of constant blocks (either there is one bi-infinite block, or the starting and ending blocks are infinite on one side and the intermediate blocks are finite), so it can be described by the positions of the blocks and the constant symbol in each block.

We define a factor map
F:X_{H}\times V^{\mathbb{Z}}\to X_{G}
. First, for each strongly connected component
C\subseteq V
of
G
, fix a surjective function
f_{C}:V\to C
which is the identity on
C
. Given
c\in X_{H}
and

, let
y=F(c,s)
be defined by
y_{n}=f_{c_{n}}(s_{n})
for all
n\in\mathbb{Z}
.

First,

. One has
(c_{n},c_{n+1})\in E_{H}
and
y_{n}\in c_{n}
and
y_{n+1}\in c_{n+1}
so there is a walk from
y_{n}
to
y_{n+1}
in

. As

is transitive,
(y_{n},y_{n+1})
is an edge in

.

Every

belongs to

: let

be the strongly connected component of

and let

. One has

and

because

, so

.

Therefore, the function

is surjective. It is continuous and commutes with the shift action, because

is determined by

and

by a rule that does not depend on

. Therefore,

is a factor of the product of a countable subshift and a fullshift, so

.
∎

Proof of Theorem
7.2
.

Let
G
be a finite directed graph. By Lemma

, there exists

such that

is transitive. By Lemma

,

. We show that the

with a fullshift. Let

in

. For each pair of vertices

First, it is well-defined and

Future directions

The main problem that is left open is to settle whether the triangles and domino subshifts from Sections
5.4.1
and
5.4.2
belong to
\mathscr{L}^{1}
. We do not expect so.

The main techniques developed in this article, Theorems
5.1
and
6.1
apply to weakly mixing subshifts only. A natural problem is to investigate subshifts that are not weakly mixing.

The definitions of
\mathscr{L}^{0}
and
\mathscr{L}^{1}
are first attempts to capture an intuitive idea, but other definitions of local generation are probably possible. For instance, in Proposition
6.2
we considered the two-dimensional SFT
X
on the alphabet
\{\raisebox{-1.42262pt}{\includegraphics[]{Tiles/tiles-7}},\raisebox{-1.42262pt}{\includegraphics[]{Tiles/tiles-8}}\}
with forbidden pattern
, and we showed that
X\notin\mathscr{L}^{1}
. However, one can generate any configuration of
X
by the following procedure: first assign an element of
\overline{\mathbb{Z}}
to each row, and then fill each cell according to the element assigned to its row. This procedure is a function
h:\overline{\mathbb{Z}}^{\mathbb{Z}}\to X
such that each output cell is determined by
one
input cell, so it is like a
1
-narrow function, except that the input alphabet
\overline{\mathbb{Z}}
is not finite, but compact countable. In other words, each input cell is filled with a finite but unbounded amount of information.

This example naturally leads to a natural relaxation of
\mathscr{L}^{1}
, in which narrow functions are allowed to work on countable or compact countable alphabets on the input side. It would be interesting to investigate this class as well as other possible relaxations, and understand how much of the landscape is modified.

Appendix A
Background

We state classical results that are used throughout the article.

A.1
Ramsey theory

We will use two celebrated results from Ramsey theory. They can be found as Theorem 26.3 and 26.4 in
[
Juk11
]
.

Theorem A.1

((Van der Waerden))
.

Let
C
be a finite set and
L\geq 1
. There exists
N=N(C,k)
such that every coloring
c:[0,N]\to C
admits a monochromatic arithmetic progression of length
N
, i.e. there exist
a,\lambda\geq 1
such that
c
is constant on
\{a,a+\lambda,\ldots,a+(L-1)\lambda\}\subseteq[0,N]
.

The second result is a generalization in higher dimensions. A homothetic copy of a set
F\subseteq\mathbb{Z}^{m}
is
u+\lambda F=\{u+\lambda f:v\in F\}
for some
u\in\mathbb{Z}^{m},\lambda\in\mathbb{Z}
.

Theorem A.2

((Gallai-Witt))
.

Let
C
be a finite set and
c:\mathbb{Z}^{m}\to C
a coloring. Every finite subset of
\mathbb{Z}^{m}
has a homothetic copy which is monochromatic.

A.2
Group actions

Let
G
be a group (we will only use
G=(\mathbb{Z}^{d},0,+)
in this article). If
H
is a subgroup of
G
, then
G
acts on the cosets
G/H
in a natural way (note that
G/H
is not necessarily a group because
H
may not be normal, but it is always a
G
-set). The next result shows that every
G
-action can be decomposed into a disjoint union of such actions.

Theorem A.3

((Orbit-stabilizer theorem))
.

Let
G
be a group. Every
G
-set
X
can be decomposed as
X=\bigsqcup_{i\in I}G/H_{i}
where
I
is a set,
H_{i}
is a subgroup of
G
, and
G
acts on
G/H_{i}
in the natural way.

Indeed, the orbit of any
x\in S
is in bijection with
G/G_{x}
where
G_{x}=\{g\in G:g\cdot x=x\}
is the stabilizer of
x
, and the orbits are pairwise disjoint.

If
G,H
are groups,
X
is a
G
-set and
Y
is an
H
-set, then a
homomorphism
from
X
to
Y
is a pair
(f,\varphi)
where
f:X\to Y
is a surjective function and
\varphi:H\to G
is a group homomorphism satisfying
h\cdot f(x)=f(\varphi(h)\cdot x)
.

For instance, if
X
is a
G
-set and
\varphi:H\to G
is a group homomorphism, then
X
is an
H
-set with the action
h\cdot x=\varphi(h)\cdot x
.

A.3
Baire category

Theorem A.4

((Baire category theorem))
.

Let
X
be a completely metrizable topological space. If
X=\bigcup_{n\in\mathbb{N}}X_{n}
where each
X_{n}
is closed, then some
X_{n}
has non-empty interior.

We will use the following particular case. Let
A
be a finite alphabet,
Z
a countable set and
X\subseteq A^{Z}
be a closed set for the product topology. If
X=\bigcup_{n\in\mathbb{N}}X_{n}
where each
X_{n}
is a closed set, then there exists
n\in\mathbb{N}
and a finite pattern
\pi
such that
\emptyset\neq[\pi]\cap X\subseteq X_{n}
.
