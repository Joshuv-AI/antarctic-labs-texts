Abstract
Error bounds have been studied for over seventy years, beginning with Hoffman’s 1952 result [ J. Res. Natl. Bur. Standards , 49(1952), 263-65], which provided a bound on the distance from any point to the solution set of a linear system. However, little is known about the inherent intractability of error bounds. This paper focuses on the complexity of error bounds and stbaility of error bounds for systems of linear inequalities. For the complexity of error bounds for linear inequalities, we reformulate this problem as the task of solving finitely many min-max problems-defined by certain rows of the given matrix over the sphere and then prove that this problem is not in the class P , but it is in the class Co- NP -complete. Furthermore, we show that there exist pseudo-polynomial time algorithms to solve both the error bounds problem and its complement. In particular, the complement is a number problem, but not NP -complete in the strong sense (unless P = NP ). For the complexity of stability of error bounds, it is proved that this problem is not in the class P . However, such problem becomes polynomially solvable when the dimension is fixed.

Since error bounds have been shown to play a critical role in variational analysis and optimization, it is natural to expect that a system would easily satisfy such a property - that is, the error bound assumption in some practical problems can be verified with ease. A natural question arisen here is to discovery the inherent intractability of error bounds.
Motivated by this observation, we study the complexity of error bounds for systems of linear inequality. The goal is to investigate thet polynomial solvability of such problem and

Preliminaries

We present some preliminaries used in our analysis. Let us begin with the notion of a

•

For our purposes, a

is a general question to be answered, typically involving several parameters whose values are initially unspecified. A problem is described by: (1) a general definition of all its parameters, and (2) a statement of the properties that a valid answer must satisfy. An

•

A function

is said to be
polynomially bounded
by another function

if there exists a polynomial
\phi:\mathbb{R}\rightarrow\mathbb{R}
such that
f(s)\leq\phi(g(s))
for all
s\in S
.

•

An
algorithm
for solving a problem is a procedure that, given any possible instance, produces the correct answer in a finite amount of time. An algorithm is said to solve a problem in
polynomial time
if its running time — measured by the number of arithmetic operations it performs (a function
f
defined on the set
S
of instances) — is polynomially bounded by the encoding size of the input (a function
g
defined on
S
). In this case, we refer to it as a
polynomial-time algorithm
(or
polynomial algorithm
).

•

A problem is said to be in the class
P
if there exists a polynomial-time algorithm to solve it. For example, linear programming belongs to the class
P
since Karmarkar’s algorithm has been proven to solve it in polynomial time.

•

A
decision problem
is a problem whose answer is either “yes” or “no.” The class
NP
consists of all decision problems for which a “yes” answer has a
certificate
that can be verified in polynomial time. The class Co-
NP
consists of all decision problems for which a “no” answer has a certificate that can be verified in polynomial time. For example, the
mixed-integer linear programming feasibility problem
in integer programming belongs to the class

(cf.
(
CCZ2014
, Theorem 4.36)
).

•

A decision problem
Q
in

is said to be

-complete
if every problem
D
in

can be reduced to
Q
in polynomial time. It is well known that Cook

•

Analogously, a decision problem
Q
in Co-
NP
is said to be
Co-
NP
-complete
if every problem
D
in Co-
NP
can be reduced to
Q
in polynomial time.

•

A problem
Q

hard
if every problem
D
in
NP
can be reduced to
Q
in polynomial time.

Main Results

In this section, we mainly study the complexity of error bounds and their stability for systems of linear inequalities. Before this, we present several lemmas that serve as key tools in determining the complexity of error bounds. These results are of independent interests.

Lemma 1

The problem “Given a positive integer
n
and a finite set
\{d_{1},\cdots,d_{k}\}\subseteq\mathbb{R}^{n}
, verify whether
\min\limits_{\|h\|=1}\max\limits_{1\leq i\leq k}d_{i}^{T}h<0
,” is in the class
P
.

Proof.
Let
d_{1},\cdots,d_{k}\in\mathbb{R}^{n}
, and set
D:=(d_{1},\cdots,d_{k})^{T}
and
\mathbf{e}:=(1,\cdots,1)\in\mathbb{R}^{n}
. We claim that

\min\limits_{\|h\|=1}\max\limits_{1\leq i\leq k}d_{i}^{T}h<0

if and only if the following linear inequality system is infeasible:

\left\{\begin{aligned} \begin{pmatrix}D\\
\mathbf{e}\end{pmatrix}\lambda&=\begin{pmatrix}0_{n}\\
1\end{pmatrix}\\
0\leq\lambda&\leq\mathbf{e}\end{aligned}\right.

(3.1)

Assuming this equivalence, it follows from Karmarkar’s interior point algorithm that there exists a polynomial-time algorithm to verify whether
\min\limits_{\|h\|=1}\max\limits_{1\leq i\leq k}d_{i}^{T}h<0
, and thus the conclusion holds.

Suppose
\min\limits_{\|h\|=1}\max\limits_{1\leq i\leq k}d_{i}^{T}h<0
, and assume by contradiction that there exists
\bar{\lambda}=(\bar{\lambda}_{1},\cdots,\bar{\lambda}_{n})
feasible to system (
3.1
). Then

\sum_{i=1}^{n}\bar{\lambda}_{i}=1\quad\text{and}\quad\sum_{i=1}^{n}\bar{\lambda}_{i}d_{i}=0.

Since
\min\limits_{\|h\|=1}\max\limits_{1\leq i\leq k}d_{i}^{T}h<0
, there exists
\bar{h}\in\mathbb{R}^{n}
with
\|\bar{h}\|=1
such that

\max\limits_{1\leq i\leq k}d_{i}^{T}\bar{h}=\min\limits_{\|h\|=1}\max\limits_{1\leq i\leq k}d_{i}^{T}h<0.

This implies

0=\left\langle\sum_{i=1}^{n}\bar{\lambda}_{i}d_{i},\bar{h}\right\rangle=\sum_{i=1}^{n}\bar{\lambda}_{i}d_{i}^{T}\bar{h}<0,

and a contradiction. Therefore, system (
3.1
) is infeasible.

Now suppose that system (
3.1
) is infeasible. Then one can verify that
0\notin\mathrm{conv}\{d_{1},\cdots,d_{k}\}
, and it follows from the separation theorem that there exists
\hat{h}\in\mathbb{R}^{n}
such that

\|\hat{h}\|=1\quad\text{and}\quad\max_{1\leq i\leq k}d_{i}^{T}\hat{h}<0.

This implies

\min\limits_{\|h\|=1}\max\limits_{1\leq i\leq k}d_{i}^{T}h\leq\max_{1\leq i\leq k}d_{i}^{T}\hat{h}<0.

The proof is complete. ∎

Lemma 2

Let
n\in\mathbb{Z}_{+}
be fixed. Then the problem: “Given a finite set
\{d_{1},\cdots,d_{k}\}\subseteq\mathbb{R}^{n}
, verify whether
\min\limits_{\|h\|=1}\max\limits_{1\leq i\leq k}d_{i}^{T}h\neq 0
” belongs to the class
P
.

Proof.
By virtue of
Lemma

1
, it suffices to prove that there exists a polynomial-time algorithm to verify whether

\min\limits_{\|h\|=1}\max\limits_{1\leq i\leq k}d_{i}^{T}h>0

for a given set
\{d_{1},\cdots,d_{k}\}\subseteq\mathbb{R}^{n}
.

Let
\Omega:=\operatorname{co}(d_{1},\cdots,d_{k})
denote the convex hull of the given vectors. We show that:

\min\limits_{\|h\|=1}\max\limits_{1\leq i\leq k}d_{i}^{T}h>0\quad\Longleftrightarrow\quad 0\in\operatorname{int}(\Omega).

(3.2)

Indeed, define the function
g(x):=\max\limits_{1\leq i\leq k}d_{i}^{T}x
for
x\in\mathbb{R}^{n}
. One can verify that

\partial g(0)=\Omega,\quad\text{and}\quad d^{+}g(0,h)=g(h),\quad\forall h\in\mathbb{R}^{n}.

From
Lemma

1
and its proof, we know that:

\min\limits_{\|h\|=1}\max\limits_{1\leq i\leq k}d_{i}^{T}h\geq 0\quad\Longleftrightarrow\quad 0\in\Omega.

(3.3)

Moreover, it is known from
(
WTY2022
, Remark 6(b))
that:

\min\limits_{\|h\|=1}\max\limits_{1\leq i\leq k}d_{i}^{T}h=0\quad\Longleftrightarrow\quad 0\in\operatorname{bdry}(\Omega).

Since
\Omega=\operatorname{int}(\Omega)\cup\operatorname{bdry}(\Omega)
, it follows from
(
WTY2024
, Proposition 4.1)
and (
3.3
) that the equivalence in (
3.2
) holds.

Now, according to
(
Chazelle1993
, Theorem 3.5)
, given
k
points in
\mathbb{R}^{n}
, one can compute their convex hull in optimal time
O(k\log k+k^{\lfloor n/2\rfloor})
. Thus, when
n
is fixed, there exists a polynomial-time algorithm to compute the convex hull
\Omega
of
\{d_{1},\cdots,d_{k}\}
. Consequently, the convex hull can be represented as:

\Omega=\{x\in\mathbb{R}^{n}:Mx\leq\gamma\},

for some matrix
M
and vector

, both computable in polynomial time.

Then, from
(
WTY2024
, Proposition 4.1)
, we know:

\operatorname{int}(\Omega)=\{x\in\mathbb{R}^{n}:Mx<\gamma\}.

Hence,

if and only if

, i.e.,

It follows from (
3.2
) that verifying

\min\limits_{\|h\|=1}\max\limits_{1\leq i\leq k}d_{i}^{T}h>0

can be done in polynomial time. Therefore, verifying whether

\min\limits_{\|h\|=1}\max\limits_{1\leq i\leq k}d_{i}^{T}h\neq 0

Remark 1

It follows from
Lemma

2
that the problem “Given a finite set
\{d_{1},\cdots,d_{k}\}\subseteq\mathbb{R}^{n}
, verify whether
\min_{\|h\|=1}\max_{1\leq i\leq k}d_{i}^{T}h\neq 0
” is polynomially solvable when the dimension
n
is fixed.

This naturally raises the question of whether the problem also belongs to the class
P
in the general case (i.e., when
n
is not fixed). Unfortunately, we do not have an answer to this question. One possible approach might follow the line of argument in the proof of
Lemma

2
, which involves computing the convex hull of a finite set of points and analyzing the complexity of convex hull algorithms.

More precisely, the issue reduces to computing a minimal inequality description
Q=\{x\in\mathbb{R}^{n}:Mx\leq\gamma\}
of a full-dimensional convex polytope such that
Q=\operatorname{conv}(S)
, where
S
is the set of input points. The computational measure of interest is the worst-case running time of the algorithm, given an input set of
k
points in
\mathbb{R}^{n}
.

For a fixed dimension, Chazelle
Chazelle1993
established an optimal algorithm for convex hull computation in terms of the worst-case input measure, with running time
O(k^{\lfloor n/2\rfloor})
for
n\geq 4
. This bound is tight due to the Upper Bound Theorem (see
(
Fukuda2004
, Theorem 2)
), which shows that the size of the output in the worst case is also of the same order.

Although Chazelle’s result is a significant theoretical achievement, it remains far from providing a practical and efficient method for computing convex hulls in general dimensions. Under nondegeneracy assumptions, there do exist polynomial algorithms for the convex hull problem (cf.
CCH53
;
Dye83
;
CK70
;
AF96
). However, for the general (possibly degenerate) case, no polynomial-time algorithm is currently known.

It is well-recognized that stability of error bounds is more complicated than the validity of error bounds, and thus we begin with the complexity of error bounds for systems of linear inequalities.

3.1
Complexity of Error Bounds for Linear Inequalities

This subsection is devoted to the complexity of error bounds for systems of linear inequalities. As the main results, we show that there is no polynomial-time algorithm to solve the problem of error bounds (if considering the worst case) and it is proved to be in the class of Co-
NP
-complete. Further, we prove that such problem would be polynomially solvable when the dimension is fixed.
To this end, we first consider the global error bound of a given convex function and establish an equivalent criterion for the global bound in terms of the directional derivatives of the convex function.

Let
f\in\Gamma_{0}(\mathbb{R}^{n})
. We denote by

\textbf{S}_{f}:=\{x\in\mathbb{R}^{n}:f(x)\leq 0\}

(3.4)

the
lower level set
of
f
. Recall that
f
is said to have a
global error bound
if there exists
c\in(0,+\infty)
such that

c\,\mathbf{d}(x,\textbf{S}_{f})\leq f_{+}(x)\quad\forall x\in\mathbb{R}^{n},

where
f_{+}(x):=\max\{f(x),0\}
. We denote by

\mathbf{Er}(f):=\inf_{f(x)>0}\frac{f(x)}{\mathbf{d}(x,\textbf{S}_{f})}

(3.5)

the
global error bound modulus
of
f
. Thus,
f
has a global error bound if and only if
\mathbf{Er}(f)>0
.

The following theorem, established in
(
WTY2025
, Theorem 3.1)
, provides a precise estimate of the global error bound modulus for a proper lower semicontinuous convex function. The authors offered a self-contained proof based solely on the Ekeland variational principle. This result is a key tool used in this paper.

Lemma 3

Let
f\in\Gamma_{0}(\mathbb{R}^{n})
be such that
\textbf{S}_{f}
is nonempty. Then the following equality on the global error bound modulus holds:

\mathbf{Er}(f)=\inf_{f(x)>0}\left(-\inf_{\|h\|=1}d^{+}f(x,h)\right).

(3.6)

Let
A:=(a_{1}^{T},\cdots,a_{m}^{T})^{T}
be an
m\times n
matrix and
b
an
m
-vector, where
m\geq 1
and
n\geq 1
. We denote the polyhedral set by

P_{A,b}:=\left\{x\in\mathbb{R}^{n}:a_{i}^{T}x\leq b_{i},\ i=1,\cdots,m\right\}.

(3.7)

Recall from Hoffman’s work
Hoffman1952
that if
P_{A,b}
is nonempty, the quantity

\sigma(A,b):=\inf_{x\notin P_{A,b}}\frac{\max\limits_{1\leq i\leq m}(a_{i}^{T}x-b_{i})_{+}}{\mathbf{d}(x,P_{A,b})}

(3.8)

is referred to as the
Hoffman constant
for the system of linear inequalities
Ax\leq b
, where
(a_{i}^{T}x-b_{i})_{+}
denotes the positive part of the scalar
a_{i}^{T}x-b_{i}
.

Let us define a function
\varphi:\mathbb{R}^{n}\rightarrow\mathbb{R}
as follows:

\varphi(x):=\max_{1\leq i\leq m}(a_{i}^{T}x-b_{i}),\quad\forall x\in\mathbb{R}^{n}.

(3.9)

we denote

J_{A,b}(x):=\left\{i\in\{1,\cdots,m\}:a_{i}^{T}x-b_{i}=\varphi(x)\right\}.

(3.10)

It is easy to verify that
\sigma(A,b)=\mathbf{Er}(\varphi)
, and the following proposition on the global error bound of
\varphi
follows directly from
Lemma

3
.

Proposition 1

Let
\varphi
be defined as in (
3.9
). Then the system of linear inequalities
Ax\leq b
admits an error bound if and only if

\min_{\|h\|=1}\max_{i\in J}a_{i}^{T}h<0

(3.11)

holds for all
J\in\mathcal{J}:=\left\{J_{A,b}(x):\varphi(x)>0\right\}
.

Proof.
Using
Lemma

3
, the system of linear inequalities
Ax\leq b
admits an error bound if and only if

\inf_{\varphi(x)>0}\left(-\inf_{\|h\|=1}d^{+}\varphi(x,h)\right)>0.

For any

and thus the conclusion follows. The proof is complete. ∎

We are now in a position to study the complexity of error bounds for systems of linear inequalities. To this end, we formally describe the problem as follows:

ERROR BOUND FOR LINEAR INEQUALITIES

Theorem 3.1

ERROR BOUND FOR LINEAR INEQUALITIES is not in the class

Proof.
Let

and

\mathcal{J}=\{J\subseteq\{1,\cdots,m\}:J\neq\emptyset\}.

that one must equivalently verify the inequality

for all

Remark 2

Theorem

shows that the ERROR BOUND FOR LINEAR INEQUALITIES problem does not belong to the class
P
. However, it is not necessarily the case that this problem belongs to the class

\mathbf{P}\neq\mathbf{NP}
?” in complexity theory.

To the best of our knowledge, there is widespread belief that
\mathbf{P}\neq\mathbf{NP}
, even though no proof of this conjecture is currently in sight. Given the current state of knowledge, it seems more reasonable to operate under the assumption that
\mathbf{P}\neq\mathbf{NP}
, rather than to invest effort in proving the contrary. In this paper, we adopt a tentative view of the world of

is not entirely empty.

Then one can verify that

\mathcal{I}=\left\{\{1\},\{2\},\{3\},\{1,2\},\{2,3\},\{1,3\}\right\}.

We solve the following six min-max problems:

\min_{\|h\|=1}\max_{i\in I}\langle a_{i},h\rangle,\quad I\in\mathcal{I}.

It can be computed that

\min\left\{\left|\min_{\|h\|=1}\max_{i\in I}\langle a_{i},h\rangle\right|:I\in\mathcal{I}\right\}=\frac{\sqrt{2}}{2}>0.

Therefore, by (
3.24
), the Hoffman constant
\sigma(A^{\prime},b^{\prime})
for the system
Ax\leq b
is uniformly bounded under perturbations of the problem data
(A,b)
.

It is worth noting that the uniform bound on the Hoffman constant may fail if the condition (
3.23
) in
Proposition

2
is violated.

Example 2

Consider the following linear system
Ax\leq b
, where

A=\begin{pmatrix}1&1\\
-1&-1\end{pmatrix},\quad b=\begin{pmatrix}0\\
0\end{pmatrix}.

Note that

\varphi(x)=0,\quad J_{A,b}(0)=\{1,2\}\in\mathcal{I},\quad\min_{\|h\|=1}\max_{i\in J_{A,b}(0)}\langle a_{i},h\rangle=0,

and hence the condition (
3.23
) is violated.

We now show that the Hoffman constant for the system
Ax\leq b
is not uniformly bounded under perturbations of the data
(A,b)
.

Indeed, for any
\varepsilon>0
, take
u:=(0,1)^{T}
and
\bar{x}:=(0,0)^{T}
. Let
A^{\prime}:=A(\varepsilon,u,\bar{x})
,
b^{\prime}:=b(\varepsilon,u,\bar{x})
, as defined in (
3.22
), and consider the perturbed system
A^{\prime}x\leq b^{\prime}
. The solution set is then given by:

P_{A^{\prime},b^{\prime}}:=\left\{(x_{1},x_{2})\in\mathbb{R}^{2}:x_{1}+(1+\varepsilon)x_{2}\leq 0,\;x_{1}+(1-\varepsilon)x_{2}\geq 0\right\}.

Take the point
x_{\varepsilon}:=(-\varepsilon,\varepsilon)
. Then one can verify that

\frac{\max\limits_{1\leq i\leq m}(a_{i}^{\prime T}x_{\varepsilon}-b_{i}^{\prime})_{+}}{\mathbf{d}(x_{\varepsilon},P_{A^{\prime},b^{\prime}})}=\frac{\varepsilon^{2}}{\sqrt{2}\varepsilon}=\frac{\varepsilon}{\sqrt{2}},

which implies that
\sigma(A^{\prime},b^{\prime})<\varepsilon
, and hence the Hoffman constant becomes arbitrarily small under such perturbations.

We are now in a position to study the complexity of the stability of error bounds for linear inequality systems. Based on
Proposition

2
, we consider
\varepsilon
-linear perturbations of the given data and formally describe the problem as follows:

STABILITY OF ERROR BOUND FOR LINEAR INEQUALITIES –TYPE I

INSTANCE: Given positive integers
m,n
, an
m\times n
matrix
A
, and an
m
-vector
b
, determine whether there exist constants
c,\varepsilon>0
such that
\sigma(A^{\prime},b^{\prime})\geq c
for all
(A^{\prime},b^{\prime})\in\operatorname{\mathbf{LPtb}}(\varepsilon,A,b)
.

It follows from
Proposition

2
and
Example

2
that condition (
3.23
) can be used to characterize the stability of the Hoffman constant for the linear inequality system
Ax\leq b
under
\varepsilon
-linear perturbations of
(A,b)
.
Therefore, to analyze the complexity of recognizing the stability of error bounds for
Ax\leq b
, it is essential to study the complexity of the min-max problems described in (
3.23
).
Lemma

2
shows that such min-max problems can be solved by a polynomial-time algorithm. This result serves as a key tool in determining the computational complexity of the stability of error bounds for
Ax\leq b
.

The following theorem, which is one of the main results of this section, shows that there exists no polynomial-time algorithm to solve the problem of STABILITY OF ERROR BOUND FOR LINEAR INEQUALITIES–TYPE I, if one considers the worst-case scenario.

Theorem 3.5

STABILITY OF ERROR BOUND FOR LINEAR INEQUALITIES–TYPE I is not in the class
P
.

Proof.
Let
m,n\in\mathbb{Z}_{+}
, and let
A\in\mathbb{R}^{m\times n}
,
b\in\mathbb{R}^{m}
. Denote
A:=(a_{1}^{T},\cdots,a_{m}^{T})^{T}
, and define

\varphi(x):=\max\limits_{1\leq i\leq m}a_{i}^{T}x,\quad\forall x\in\mathbb{R}^{n},\quad\text{and}\quad\mathcal{I}:=\left\{J_{A,b}(x):\varphi(x)=0\right\}.

We prove that for any algorithm to recognize the stability of error bounds of
Ax\leq b
, its running time would be exponential if considering the worst case.

Consider the case where
m\leq n
and the rows
a_{1}^{T},\cdots,a_{m}^{T}
are linearly independent. We first show that

\mathcal{I}=\left\{I\subseteq\{1,\cdots,m\}:I\neq\emptyset\right\}.

(3.25)

We only need to prove the inclusion
\supseteq
. Let
I\subseteq\{1,\cdots,m\}
be nonempty. Fix
\varepsilon>0
, and define
\tilde{b}_{i}:=b_{i}-\varepsilon
for all
i\in\{1,\cdots,m\}\setminus I
. Consider the following linear system:

\left\{\begin{aligned} a_{i}^{T}x&=b_{i},\quad&&i\in I,\\
a_{i}^{T}x&=\tilde{b}_{i},\quad&&i\in\{1,\cdots,m\}\setminus I.\end{aligned}\right.

Since
\operatorname{rank}(A)\leq m\leq n
, the above system has at least one solution, say
\bar{x}
. By construction, one can verify that
\varphi(\bar{x})=0
and
J_{A,b}(\bar{x})=I
, hence
I\in\mathcal{I}
, and (
3.25
) holds.

By (
3.25
), the cardinality of
\mathcal{I}
is
2^{m}-1
. Therefore, recognizing the stability of error bounds for the system
Ax\leq b
reduces, via
Proposition

2
, to verifying that

\min\limits_{\|h\|=1}\max\limits_{i\in I}a_{i}^{T}h\neq 0

(3.26)

holds for all
I\in\mathcal{I}
. The number of such subsets
I
is exponential in
m
, so checking condition (
3.26
) over all
I\in\mathcal{I}
would require exponential time in the worst case.

This implies that any algorithm for solving the STABILITY OF ERROR BOUND FOR LINEAR INEQUALITIES–TYPE I problem must take exponential time in the worst case, and thus the problem is not in the class
P
. The proof is complete. ∎

Note that the stability of error bounds necessarily implies the existence of error bounds. Therefore, the conclusion in
Theorem

3.5
is not surprising in light of
Theorem

3.1
. However, the self-contained proof presented above leads to another important result on the complexity of stability of error bounds for the system
Ax\leq b
.

Based on
Theorem

3.5
, it is both interesting and significant to explore the complexity of stability of error bounds for linear inequalities within the
NP
framework - assuming
\mathbf{P}\neq\mathbf{NP}
. Pursuing this direction, however, first requires addressing the fundamental difficulty raised in
Remark

1
regarding the general complexity of convex hull computations.

Beyond this general direction, it is also both feasible and valuable to investigate efficient algorithms for specific cases of the problem. The following theorem shows that such problem becomes polynomially solvable when the dimension
n
is fixed.

Theorem 3.6

Let
n\in\mathbb{Z}_{+}
be fixed. Then the problem of STABILITY OF ERROR BOUND FOR LINEAR INEQUALITIES–TYPE I belongs to the class
P
.

Proof.
Let
m\in\mathbb{Z}_{+}
, and let
A\in\mathbb{R}^{m\times n}
,
b\in\mathbb{R}^{m}
. Denote
A:=(a_{1}^{T},\cdots,a_{m}^{T})^{T}
, and define

\varphi(x):=\max_{1\leq i\leq m}a_{i}^{T}x,\quad\forall x\in\mathbb{R}^{n},\quad\text{and}\quad\mathcal{I}:=\left\{J_{A,b}(x):\varphi(x)=0\right\}.

Since the dimension
n
is fixed, we consider the case
m>n
. In this setting, it can be verified that the number of distinct index sets
\mathcal{I}
is polynomially bounded by
m^{n}
. Indeed, the number of subsets of size at most
n
is bounded by
\sum_{i=1}^{n}\binom{m}{i}=\mathcal{O}(m^{n})
.

By
Lemma

2
, for each
I\in\mathcal{I}
, there exists a polynomial-time algorithm to verify whether

\min_{\|h\|=1}\max_{i\in I}a_{i}^{T}h\neq 0.

Hence, the global verification

\min_{\|h\|=1}\max_{i\in I}a_{i}^{T}h\neq 0,\quad\forall I\in\mathcal{I}

can be carried out in polynomial time.

By
Proposition

2
, this implies that the STABILITY OF ERROR BOUND FOR LINEAR INEQUALITIES–TYPE I problem is polynomially solvable when the dimension is fixed. Therefore, the problem belongs to the class
P
. The proof is complete. ∎

4
Concluding Remarks and Perspectives

It has been over 70 years since Hoffman’s pioneering work on error bounds for linear inequality systems. Unlike most of the existing works in the literature, which focuses on establishing sufficient or necessary conditions for error bounds, this paper investigates the complexity of error bounds in linear inequality systems.

From the viewpoint of practical applications, understanding the computational complexity of error bounds marks a new direction in the study of such problems. Knowing that the recognition problem is Co-
NP
-complete provides valuable insight into which approaches may be most promising. For instance, researchers might focus on identifying efficient algorithms for specific classes of linear systems, or on developing algorithms that — while not guaranteed to be fast in all cases — perform well in practice. Alternatively, one may consider relaxed formulations of the problem that are more amenable to fast computation.

In this sense, the complexity results presented in this paper are not only of theoretical interest but also serve as a guide for directing future problem-solving efforts. They help in identifying which strategies are likely to lead to useful, practically efficient algorithms for detecting error bounds and understanding their stability under data perturbations.

Ultimately, the goal of studying the complexity of error bound recognition is to help direct research efforts toward approaches with the greatest potential to yield practical and computationally feasible algorithms.

On the other hand, the approaches developed in this work for analyzing the complexity of error bounds may also be applicable to the study of other well-known notions and properties in variational analysis and optimization. A promising direction is to begin by making preliminary complexity assessments for special problems related to error bounds — some of which may be more difficult (e.g., stability-related problems), and others potentially easier — before proceeding to a deeper, more detailed complexity analysis. This line of investigation will form part of our future research.

Several open questions remain concerning the complexity of error bounds for systems of linear inequalities:

(i)

Is the ERROR BOUND FOR LINEAR INEQUALITIES problem
NP
- complete?

(ii)

Is the STABILITY OF ERROR BOUND FOR LINEAR INEQUALITIES–TYPE I problem
NP
-complete or Co-
NP
-complete?

(iii)

Does there exist a pseudo-polynomial time algorithm to solve the STABILITY OF ERROR BOUND FOR LINEAR INEQUALITIES–TYPE I problem?

(iv)

What is the complexity of other types of stability of error bounds for systems of linear inequalities?
