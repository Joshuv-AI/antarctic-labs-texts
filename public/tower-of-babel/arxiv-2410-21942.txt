Beating Bellman’s Algorithm for Subset Sum
Karl Bringmann, Nick Fischer, Vasileios Nakos

Abstract
Bellman’s algorithm for Subset Sum is one of the earliest and simplest examples of dynamic programming, dating back to 1957. For a given set of n n integers X X and a target t t , it computes the set of subset sums 𝒮 ⁡ ( X , t ) \mathcal{S}(X,t) (i.e., the set of integers s ∈ [ 0 ​ … ​ t ] s\in[0\ldots t] for which there is a subset of X X summing to s s ) in time O ⁡ ( | 𝒮 ⁡ ( X , t ) | ⋅ n ) O(|\mathcal{S}(X,t)|\cdot n) . Since then, it has been an important question whether Bellman’s seminal algorithm can be improved. This question is addressed in many recent works. And yet, while some algorithms improve upon Bellman’s algorithm in specific parameter regimes, such as Bringmann’s O ~ ​ ( t + n ) \widetilde{O}(t+n) -time algorithm [SODA ’17] and Bringmann and Nakos’ O ~ ​ ( | 𝒮 ​ ( X , t ) | 4 / 3 ) \widetilde{O}(|\mathcal{S}(X,t)|^{4/3}) -time algorithm [STOC ’20], none of the known algorithms beats Bellman’s algorithm in all regimes. In particular, it remained open whether Subset Sum is in time O ~ ​ ( | 𝒮 ⁡ ( X , t ) | ⋅ n 1 − ϵ ) \widetilde{O}(|\mathcal{S}(X,t)|\cdot n^{1-\epsilon}) (for some ϵ > 0 \epsilon>0 ). In this work we positively resolve this question and design an algorithm that outperforms Bellman’s algorithm in all regimes. Our algorithm runs in time O ~ ​ ( | 𝒮 ​ ( X , t ) | ⋅ n ) \widetilde{O}(|\mathcal{S}(X,t)|\cdot\sqrt{n}) , thus improving the time complexity by a factor of nearly n \sqrt{n} . Our key innovation is the use of a result from additive combinatorics, which has not been applied in an algorithmic context before and which we believe to be of further independent interest for algorithm design. To demonstrate the broader applicability of our approach, we extend our ideas to a variant of Subset Sum on vectors as well as to Unbounded Subset Sum.

1.2
Our Contribution

The core contribution of this paper is a positive resolution of our driving question, marking the first true improvement on Bellman’s algorithm since over 60 years. Specifically, we show the following:

1.1
.

Given a multiset
X\subseteq[0\ldots t]
, we can compute
\mathcal{S}(X,t)
in time
\widetilde{O}(|\mathcal{S}(X,t)|\cdot\sqrt{n})
(by a randomized algorithm that succeeds with high probability).

Our algorithm is based on a careful combination of three main tools: The first is Bringmann’s color coding technique
[
11
]
. The second is sparse convolution to compute sumsets in output-sensitive time. The third and most exciting ingredient is an estimate from additive combinatorics required for the key step in the analysis. Specifically, we rely on a certain
sub-multiplicativity
property of sumsets proved by Gyarmati, Matolcsi and Ruzsa
[
28
]
. It states that for all sets
A_{1},\dots,A_{K}
we can bound the size of the sumset

|A_{1}+\dots+A_{K}|\leq\left\lparen\prod_{i=1}^{K}|B_{i}|\right\rparen^{\frac{1}{K-1}},

where
B_{i}=A_{1}+\dots+A_{i-1}+A_{i+1}+\dots+A_{K}
is the same sumset where we omit one term (see
Theorem

3.3
for details). All in all, we arrive at a satisfyingly clean and even somewhat simple algorithm.

We remark that the same “three-component-recipe” has also been successfully applied in the recent algorithms due to Chen, Lian, Mao and Zhang
[
20
,
22
]
. More generally, employing tools from additive combinatorics in fine-grained algorithms for Subset Sum-type problems has evolved into a modern trend
[

We thus bring a new additive combinatorics tool to the table of algorithm design, and we are confident that there are further applications of this tool—for Subset Sum or possibly beyond—given the general prevalence of sumsets in algorithms.

Of course it is desirable to improve our result further, to time
\widetilde{O}(|\mathcal{S}(X,t)|\cdot n^{1/3})

\widetilde{O}(|\mathcal{S}(X,t)|)

1.3
Extensions

To explore the flexibility of our new approach we investigate whether we can achieve similar improvements for other Subset Sum-type problems.

Extension 1: Unbounded Subset Sum

We call an integer an
unbounded
subset sum of
X
if it can be expressed as the sum of elements from
X
that is allowed to contain each element several times (and not only once). We write
\mathcal{S}^{*}(X,t)
for the set of unbounded subset sums of
X
in the range
[0\ldots t]
. Computing the unbounded subset sums easily reduces to the bounded case by duplicating each item
x
to items
x,2x,4x,\dots\leq t
. Typically, however, Unbounded Subset Sum has significantly simpler and
deterministic
algorithms (as we can avoid color coding). We show that our technique follows this heuristic and extends to Unbounded Subset Sum with essentially the same time complexity:

1.2
Unbounded Subset Sum.

Given a multiset
X\subseteq[0\ldots t]
of size
n
we can compute
\mathcal{S}^{*}(X,t)
in time
O(|\mathcal{S}^{*}(X,t)|\cdot\sqrt{n}\cdot\polylog(t))
(by a deterministic algorithm).

Here the additional overhead
\polylog(t)
is mainly caused by the deterministic sparse convolution algorithm
[
14
]
.

Extension 2: High-Dimensional Subset Sum

We also consider the natural generalization from Subset Sum on integers to high dimensions, i.e., vectors. That is, for a set of integer vectors
X\subseteq[0\ldots t]^{d}
, the goal is to compute the set of subset sums in the cube
[0\ldots t]^{d}
, denoted as before by
\mathcal{S}(X,t)
. We assume
d
to be constant. This version of Subset Sum can still be solved in time
O(|\mathcal{S}(X,t)|\cdot n)
by Bellman’s algorithm (without changes). It turns out that our algorithm generalizes in an interesting way, with weaker bounds for higher dimensions, but nevertheless a polynomial improvement over Bellman’s algorithm:

1.3
High-Dimensional Subset Sum.

Let
d\geq 1
be a constant. Given a size-
n
multiset
X\subseteq[0\ldots t]^{d}
we can compute
\mathcal{S}(X,t)
in time
\widetilde{O}(|\mathcal{S}(X,t)|\cdot n^{1-\frac{1}{d+1}})
(by a randomized algorithm that succeeds with high probability).

For Unbounded Subset Sum the above result can be achieved deterministically with a
\polylog(t)
factor overhead, see section
5
for details. Similarly to the one-dimensional case, the bottleneck of the high-dimensional variants lies in prefix-restricted computations (in high dimensions).

For real numbers

Sumsets

For sets
A,B\subseteq\mathbb{Z}^{d}
we define the

A+B=\{a+b:a\in A,\,b\in B\}
. For a single integer

we occasionally write

2.1

Let

|A_{1}|+\dots+|A_{K}|\leq|A_{1}+\dots+A_{K}|+K-1.

Proof.

It suffices to prove the statement for

; the full statement then easily follows by induction. To show that
|A+B|\geq|A|+|B|-1
, let
a_{1}<\dots<a_{|A|}
and
b_{1}<\dots<b_{|B|}
denote the elements in
A
and
B
, respectively. Then note that
a_{1}+b_{1}<\dots<a_{1}+b_{|B|}<a_{2}+b_{|B|}<\dots<a_{|A|}+b_{|B|}
, and all of these
|A|+|B|-1
elements are clearly contained in
A+B
.
∎

Subset Sum

To define the (high-dimensional) Subset Sum problem, let
X=\{x_{1},\dots,x_{n}\}\subseteq\mathbb{Z}_{\geq 0}^{d}
be a multiset. We define the set of
subset sums

\mathcal{S}(X)=\{0,x_{1}\}+\dots+\{0,x_{n}\}
, and the (infinite) set of
unbounded subset sums

\mathcal{S}^{*}(X)=\{0,x_{1},2x_{1},\dots\}+\dots+\{0,x_{n},2x_{n},\dots\}
. For a target
t
, we set
\mathcal{S}(X,t)=\mathcal{S}(X)\cap[0\ldots t]^{d}
and
\mathcal{S}^{*}(X,t)=\mathcal{S}^{*}(X)\cap[0\ldots t]^{d}
. Then the Subset Sum problem is to compute
\mathcal{S}(X,t)
and the Unbounded Subset Sum problem is to compute
\mathcal{S}^{*}(X,t)
, or, as decision versions, to decide whether
t
is an (unbounded) subset sum.

We throughout assume that
|X|\leq|\mathcal{S}(X,t)|
. This assumption is always true for sets
X\subseteq[0\ldots t]^{d}
, and can also easily be enforced for multisets in a linear-time preprocessing to remove redundant elements.

Randomization

We say that an event happens
with high probability

3.1
Overview

Many algorithms for Subset Sum rely in one way or another on the following general idea: Consider any partition
X=X_{1}\sqcup X_{2}
(which may be random, or cleverly chosen). If we can efficiently compute the sets
\mathcal{S}(X_{1},t)
and
\mathcal{S}(X_{2},t)
, then we can also compute

\mathcal{S}(X,t)=(\mathcal{S}(X_{1},t)+\mathcal{S}(X_{2},t))\cap[0\dots t].

(1)

This approach is helpful for the design of divide-and-conquer algorithms
[
11
,
36
,
15
,
20
,
22
]
(i.e, the set
X
is repeatedly partitioned into smaller sets), or also to initially partition
X
into a small number of subsets to ensure some common properties (e.g., partition
X
into subsets
X\cap(\frac{t}{2},t],\,X\cap(\frac{t}{4},\frac{t}{2}],\,\dots
each of which only contains items of some common scale). We will design a divide-and-conquer algorithm based on the same high-level approach, but which requires significantly more care due to the following issue.

Prefix-Restricted Sumsets

Computing
\mathcal{S}(X,t)
in (
1
) is computationally quite nontrivial. To abstract from the above setup let
A=\mathcal{S}(X_{1},t)
and
B=\mathcal{S}(X_{2},t)
. Then computing
\mathcal{S}(X,t)
can be expressed as the following problem called
prefix-restricted
sumset computation: Given two sets
A,B\subseteq[0\ldots t]
, the goal is to efficiently compute
C=(A+B)\cap[0\ldots t]
. This problem can trivially be solved in time
\widetilde{O}(t)
using the Fast Fourier Transform which is sufficient for many applications
[
11
,
32
]
. However, in our “output-sensitive” setting (where the goal is a running time proportional to
\mathcal{S}(X,t)
) this would be too expensive. Conceptually, the dream solution would be to find a
(near-)linear-time
algorithm for prefix-restricted sumsets, i.e., an algorithm running in time
\widetilde{O}(|A|+|B|+|C|)
. From this it would easily follow that Subset Sum is in best-possible time
\widetilde{O}(|\mathcal{S}(X,t)|)
. However, there are barriers towards achieving such a prefix-restricted sumset algorithm
[
15
]
, and we leave this as an important open problem.

On the positive side, we are aware of three nontrivial algorithms: (i) it follows from the sparse convolution literature that we can compute
A+B
(and thereby
C
) in time
\widetilde{O}(|A+B|)
. While this appears very fast at first glance—after all,
C
is “just” the set
A+B\subseteq[0\ldots 2t]
restricted to
[0\ldots t]
—it turns out that there are sets
A
and
B
for which
|C|\ll|A+B|
.
2
2

2

For an extreme example, consider the sets
A=\frac{t}{2}+\{1,2,\dots,n\}
and
B=\frac{t}{2}+\{n,2n,\dots,n^{2}\}
for some target
t\gg n^{2}
. Then
|A|=|B|=n
and
|A+B|=\Omega(n^{2})
, whereas
|C|=0
.
Bringmann and Nakos
[
15
]
proposed two other algorithms for prefix-restricted sumset computations: (ii) a simple one running in time
\widetilde{O}(\sqrt{|A|\,|B|\,|C|})
. And (iii), a more involved algorithm based on Ruzsa’s triangle inequality that runs in time
\widetilde{O}(|A|+|B|+|C|^{4/3})
. This last algorithm can be turned into the state-of-the-art
\widetilde{O}(|\mathcal{S}(X,t)|^{4/3})
-time algorithm for Subset Sum
[
15
]
, but due to the
|C|^{4/3}
dependence we cannot use it for our goal. The other two algorithms are potentially applicable.

In summary: Suppose that we attempt to split the given instance into parts
X=X_{1}\sqcup X_{2}
, compute
\mathcal{S}(X_{1},t_{1})
and
\mathcal{S}(X_{2},t_{2})
(possibly for different targets
t_{1},t_{2}\leq t
) and recombine
\mathcal{S}(X_{1},t_{1})
and
\mathcal{S}(X_{2},t_{2})
by a prefix-restricted sumset computation. Then, for this to be efficient, we have to make sure that either

(i)

|\mathcal{S}(X_{1},t_{1})+\mathcal{S}(X_{2},t_{2})|
or

(ii)

\sqrt{|\mathcal{S}(X_{1},t_{1})|\,|\mathcal{S}(X_{2},t_{2})|\,|\mathcal{S}(X,t)|}

is upper-bounded by
O(|\mathcal{S}(X,t)|\cdot\sqrt{|X|})
.

Large Items

The previous paragraph severely restricts our freedom in partitioning
X
. Luckily, one very useful partition can nevertheless still be efficiently dealt with: the partition into
small items

X_{S}=\{x\in X:x\leq\gamma t\}
and
large items

X_{L}=X\setminus X_{S}
(for some parameter
\gamma>0
which we will determine later). The main challenge in the algorithm will be to compute the subset sums attained by small items,
\mathcal{S}(X_{S},t)
. Suppose for the moment that we have already computed
\mathcal{S}(X_{S},t)
; we prove that based on approach (ii) we can then also take the large items into account and compute
\mathcal{S}(X,t)=(\mathcal{S}(X_{S},t)+\mathcal{S}(X_{L},t))\cap[0\ldots t]
. Formally, we prove the following lemma (which should be applied with
Z=\mathcal{S}(X_{S},t)
):

3.1
Large Items.

Let
\gamma>0
, let
X_{L}\subseteq[\gamma t,t]
be a multiset and let
Z\subseteq[0\ldots t]
. We can compute
Z^{\prime}=(Z+\mathcal{S}(X_{L},t))\cap[0\ldots t]
in time
\widetilde{O}(|Z^{\prime}|\cdot\sqrt{|X_{L}|}\cdot\poly(\gamma^{-1}))
(by a Las Vegas algorithm).

Proof Sketch.

The idea is to apply the
color coding
technique as pioneered by Bringmann
[
11
]
in the context of Subset Sum. First observe that any subset sum in
\mathcal{S}(X_{L},t)
can involve at most
\gamma^{-1}
many elements. Therefore, any element
z^{\prime}\in Z^{\prime}
can be expressed as
z^{\prime}=z+x_{1}+\dots+x_{m}
where
z\in Z
(i.e., the contribution of the small elements), and
x_{1},\dots,x_{m}\in X_{L}
where
m\leq\gamma^{-1}
. Now consider a uniformly random partition
X_{L}=X_{1}\sqcup\dots\sqcup X_{K}
into
K=\Theta(\gamma^{-2})

buckets
. By a standard balls-into-bins argument it follows that
x_{1}+\dots+x_{m}\in(X_{1}\cup\{0\})+\dots+(X_{K}\cup\{0\})
with constant probability. Thus, the computation of
Z^{\prime}
essentially amounts to computing the iterated prefix-restricted sumset

(Z+(X_{1}\cup\{0\})+\dots+(X_{K}\cup\{0\}))\cap[0\ldots t].

Specifically, to compute this set start with
Z^{\prime}\leftarrow Z
. Then, for each
k\leftarrow 1,\dots,K
we use Bringmann and Nakos’ algorithm for prefix-restricted sumsets to update
Z^{\prime}\leftarrow(Z^{\prime}+(X_{k}\cup\{0\}))\cap[0\ldots t]
. Each step runs in time
\widetilde{O}(\sqrt{|Z^{\prime}|\,|Z^{\prime}|\,|X_{k}|})=\widetilde{O}(|Z^{\prime}|\cdot\sqrt{X_{L}})
, and so the claimed running time follows.

Finally, recall that this only reports any fixed element in
(Z+\mathcal{S}(X_{L},t))\cap[0\ldots t]
with constant probability. We could either repeat this process for
\Theta(\log|Z^{\prime}|)
times, or derandomize the process altogether by employing Reed-Solomon codes. We defer the details to the proof of the more general
Lemma

4.2
.
∎

Small Items

It remains to deal with the small items, i.e., to compute
\mathcal{S}(X_{S},t)
. Conceptually, the advantage of the small items is that we can expect that any subset
z\in\mathcal{S}(X_{S},t)
can be partitioned into subset sums
z=z_{1}+\dots+z_{K}
where
z_{1},\dots,z_{K}\lesssim\frac{t}{K}
. This insight inspires a divide-and-conquer algorithm along the following lines: Partition
X_{S}=X_{1}\sqcup\dots\sqcup X_{K}
into some
K
parts, compute the subset sums
\mathcal{S}(X_{1},\frac{t}{K}),\dots,\mathcal{S}(X_{K},\frac{t}{K})

recursively
, and then recover
\mathcal{S}(X_{S},t)
as the sumset
\mathcal{S}(X_{1},\frac{t}{K})+\dots+\mathcal{S}(X_{K},\frac{t}{K})
. This appears somewhat promising as this sumset can indeed be computed in time
\widetilde{O}(|\mathcal{S}(X,t)|)
(by approach (i) from before).

Unfortunately, it is unrealistic to use the exact target
\frac{t}{K}
for the recursive calls—in particular, this would require that the subset sum
t
could be perfectly partitioned into smaller sums of size at most
\frac{t}{K}
. Hence, it seems unavoidable to incur some slack and instead use the target
(1+\epsilon)\cdot\frac{t}{K}
(for some parameter
\epsilon>0
) for the recursive calls. Then, by a standard application of Hoeffding’s inequality it follows that indeed
\mathcal{S}(X_{S},t)=(\mathcal{S}(X_{1},(1+\epsilon)\cdot\frac{t}{K})+\dots+\mathcal{S}(X_{K},(1+\epsilon)\cdot\frac{t}{K}))\cap[0\ldots t]
for an appropriate choice of parameters:

3.2
Small Items.

Let
K\geq 1
and let
X_{S}\subseteq[0\ldots\frac{t}{K^{5}}]
be a multiset. Let
X_{S}=X_{1}\sqcup\dots\sqcup X_{K}
denote a uniformly random partition into
K
parts. Then with probability at least
1-\exp(-K)\cdot|\mathcal{S}(X_{S},t)|
it holds that

\mathcal{S}(X_{S},t)=\Big(\sum_{i=1}^{K}\mathcal{S}(X_{i},(1+\tfrac{1}{K})\cdot\tfrac{t}{K})\Big)\cap[0\ldots t].

The proof of
Lemma

3.2
is simple and deferred to (the generalization
Lemma

4.3
) in
Section

4.2
. Our main concern is how to make use of this lemma in the presence of the
(1+\epsilon)=(1+\frac{1}{K})
slack. In order to obtain an efficient algorithm we need to bound the cost of the prefix-restricted sumset computation (plus the cost of the recursive calls, but that is a secondary concern). As outlined before we can follow the approaches (i) or (ii). It is easy to construct instances where approach (ii) takes time
\Omega(|\mathcal{S}(X_{S},t)|^{3/2})
. Thus, to make approach (i) efficient we need to control

\left\lvert\sum_{i=1}^{K}\mathcal{S}(X_{i},(1+\tfrac{1}{K})\cdot\tfrac{t}{K})\right\rvert.

Unfortunately, it is a priori quite unclear how to bound the size of this sumset
\sum_{k}\mathcal{S}(X_{k},(1+\tfrac{1}{K})\cdot\frac{t}{K})
. It could contain numbers as large as
K\cdot(1+\frac{1}{K})\cdot\frac{t}{K}=(1+\frac{1}{K})\cdot t
, and we can thus not simply charge its size against the size of
\mathcal{S}(X_{S},t)\subseteq[0\ldots t]
. Can we nevertheless control its size with respect to
|\mathcal{S}(X_{S},t)|
?

Sub-Multiplicativity of Sumsets

This is where finally the theorem from additive combinatorics comes into play. Specifically, we rely on the following
sub-multiplicativity
property due to Gyarmati, Matolcsi and Ruzsa
[
28
]
:

3.3
Sub-Multiplicativity of Sumsets
[
28
]
.

Let
A_{1},\dots,A_{K}
be finite sets in a commutative semigroup, and define

B_{i}=\sum_{j\in[K]\setminus\{i\}}A_{j},

i.e. the sumset of all sets excluding
A_{i}
. Then, the following estimate holds:

|A_{1}+\ldots+A_{K}|\leq\left\lparen\prod_{i=1}^{K}|B_{i}|\right\rparen^{\frac{1}{K-1}}.

In the context of additive combinatorics this is not the first work which relates the size of
K
-fold sumsets
A_{1}+\dots+A_{K}
in terms of the size of
(K-1)
-fold sumsets
A_{1}+\dots+A_{i-1}+A_{i+1}+\dots+A_{K}
; see e.g. also
[
37
,
39
,
27
,
45
]
. The proof of
Theorem

3.3
is not too complicated and is built on a clever charging argument.

Coming back to our Subset Sum algorithm, it turns out that
Theorem

3.3
yields exactly the bound we were looking for. Specifically, let

A_{i}=\mathcal{S}(X_{i},(1+\tfrac{1}{K})\cdot\tfrac{t}{K})

and thus

B_{i}=\sum_{j\in[K]\setminus\{i\}}A_{j}\subseteq\mathcal{S}(X,(K-1)\cdot(1+\tfrac{1}{K})\cdot\tfrac{t}{K})\subseteq\mathcal{S}(X,t).

Then the theorem implies that

\left\lvert\sum_{i=1}^{K}\mathcal{S}(X_{i},(1+\tfrac{1}{K})\cdot\tfrac{t}{K})\right\rvert=|A_{1}+\dots+A_{K}|\leq\left\lparen\prod_{i=1}^{K}|B_{i}|\right\rparen^{\frac{1}{K-1}}\leq|\mathcal{S}(X,t)|^{\frac{K}{K-1}}=|\mathcal{S}(X,t)|^{1+\frac{1}{K-1}}.

By choosing
K\gg\log|\mathcal{S}(X,t)|
, the right-hand side becomes
O(|\mathcal{S}(X,t)|)
as planned. This completes the description of the main ideas behind our algorithm.

High-Dimensional Subset Sum

The goal of this section is to generalize

See

Recall that our approach is mainly built on three components: An efficient algorithm for prefix-restricted sumset computations for the large items, a divide-and-conquer scheme based on color coding for the small items, as well as
Theorem

3.3
from additive combinatorics for the analysis.
Theorem

3.3
immediately applies to any additive group (in fact, for any commutative semigroup). In the following two sections we generalize the first two components.

Throughout this section we treat the dimension
d
as a constant. It is however easy to check that we hide constant factors of the form
\poly(d)
and the exponents of
\polylog
is
O(d)
everywhere.

4.1
Prefix-Restricted Sumsets

4.1
High-Dimensional Prefix-Restricted Sumsets.

Let
d\geq 1
be a constant. Given sets
A,B\subseteq[0\ldots t]^{d}
we can compute
C=(A+B)\cap[0\ldots t]^{d}
in time

•

O((|A|+|B|+(|A|\,|B|)^{1-\frac{1}{d+1}}|C|^{\frac{1}{d+1}})\cdot(\log t)^{O(d)})
by a deterministic algorithm, and

•

O((|A|+|B|+(|A|\,|B|)^{1-\frac{1}{d+1}}|C|^{\frac{1}{d+1}})\cdot(\log(|A|\,|B|))^{O(d)})
by a Las Vegas algorithm.

Proof.

We inductively solve the following generalized problem: For some
0\leq k\leq d
, the task is to compute
C=(A+B)\cap[0\ldots t]^{k}\times[0\ldots\infty]^{d-k}
(i.e., we only cap the points falling outside the size
-
t
box in the first
k
coordinates). Our goal is to achieve time
\widetilde{O}(|A|+|B|+(|A|\,|B|)^{1-\frac{1}{k+1}}|C|^{\frac{1}{k+1}})
(where we comment on the log-factors later). When
k=0
, we can clearly compute
C
in time
\widetilde{O}(|C|)
by a sparse sumset computation (see
Lemma

2.2
). In the following let
k\geq 1
.

In a first preprocessing step we ensure that
|A|,|B|\leq|C|
. This can be implemented in near-linear time
\widetilde{O}(|A|+|B|+|C|)
by testing for each point
a\in A
whether there exists a point
b\in B
with
a+b\in[0\ldots t]^{k}\times[0\ldots\infty]^{d-k}
by an orthogonal range searching data structure. The more important steps follow.

For a set
X\subseteq\mathbb{Z}^{d}
, let us write
\max_{k}(X)=\max_{x\in X}x[k]
and
\min_{k}(X)=\min_{x\in X}x[k]
. Let
g
be a parameter. The first step is to partition
A=A_{1}\sqcup\dots\sqcup A_{g}
and
B=B_{1}\sqcup\dots\sqcup B_{g}
into at most
g
parts such that the following properties hold:

(1)

\max\nolimits_{k}(A_{1})\leq\min\nolimits_{k}(A_{2})\leq\max\nolimits_{k}(A_{2})\leq\dots\leq\min\nolimits_{k}(A_{g-1})\leq\max\nolimits_{k}(A_{g-1})\leq\min\nolimits_{k}(A_{g})
,

(2)

\max\nolimits_{k}(B_{1})<\min\nolimits_{k}(B_{2})\leq\max\nolimits_{k}(B_{2})<\dots<\min\nolimits_{k}(B_{g-1})\leq\max\nolimits_{k}(B_{g-1})<\min\nolimits_{k}(B_{g})
,

(3)

for all
i\in[g]
we have
|A_{i}|\leq O(|A|/g)
,

(4)

for all
j\in[g]
at least one of the following properties holds:

(i)

|B_{j}|\leq O(|B|/g)
(in which case we say that
j
is
light
), or

(ii)

\min_{k}(B_{j})=\max_{k}(B_{j})
(i.e., all vectors in
B_{j}
share the same
k
-th coordinate, in which case we say that
j
is
heavy
). In this case, it further holds that there is an index
1\leq i<g
such that
\max_{k}(A_{i})+\max_{k}(B_{j})\leq t
and
\min_{k}(A_{i+1})+\min_{k}(B_{j})>t
.

It is not complicated but somewhat tedious to obtain this partition. First, sort the sets
A
and
B
in increasing order with respect to the
k
-
th coordinate. Then take
A_{1},\dots,A_{g/2}
to be consecutive blocks of
A
in that order of length at most
\lceil 2|A|/g\rceil
each. This assignment clearly satisfies Properties (1) and (3). For the blocks in
B
we cannot apply the same construction as this does not necessarily satisfy Property (2) which requires strict inequalities
\max_{k}(B_{j})<\max_{k}(B_{j+1})
. Let us call an integer
z
a
pivot
if there are at least
2|B|/g
vectors
b\in B
with
b[k]=z
; clearly there can be at most
g/2
pivots. To assign the partition of
B
, we first identify all pivots
z
(in linear time). For each pivot
z
, we then introduce a (heavy) block
B_{j}=\{b\in B:b[k]=z\}
. Additionally, for each pivot
z
we test if there is an index
i
such that
\min(A_{i})\leq t-z<\max(A_{i})
. If it exists, this index
i
is unique; in this case we subdivide
A_{i}
at
t-z
into two sub-blocks. Since we started from
g/2
blocks and perform at most
g/2
subdivisions, we indeed end up with at most
g
blocks in
A
. Together, these two steps assert Property (4) (ii). After dealing with all the pivots, we can now partition the remaining elements in
B
into (light) blocks
B_{1}\sqcup\dots\sqcup B_{g/2}
of size
O(|B|/g)
, satisfying Property (4) (i). In this step we additionally make sure that for all integers
z
, all items
b\in B
with
b[k]=z
end up in the same block
B_{i}
; this is possible since there are at most
O(|B|/g)
such elements given that
z
is not a pivot. Thus, the strict inequalities
\max_{k}(B_{j})<\min_{k}(B_{j+1})
demanded by Property (2) apply. By inserting the heavy blocks at the appropriate places into this order, we have altogether satisfied Property (2). This completes the description of the partition.

To continue, let us call a pair
(i,j)\in[g]^{2}

partially relevant
if
\min_{k}(A_{i})+\min_{k}(B_{j})\leq t
and
totally relevant
if
\max_{k}(A_{i})+\max_{k}(B_{j})\leq t
. Note that each totally relevant pair is also partially relevant. For each partially relevant pair
(i,j)
we compute the set
C_{i,j}=(A_{i}+B_{j})\cap[0\ldots t]^{k-1}\times[0\ldots\infty]^{d-k+1}
recursively (i.e., with parameter
k-1
), and add all relevant points to the output (i.e., discarding all vectors
c\in C_{i,j}
with
c[k]>t
). The correctness of this approach is clear, as all pairs
(i,j)
that are not partially relevant cannot contribute any points to the output.

For the running time analysis, we call the set
\mathcal{C}_{\Delta}=\{(i,j)\in[g]^{2}:i-j=\Delta\}
a “chain”; note that the only non-empty chains are
\mathcal{C}_{-g+1},\dots,\mathcal{C}_{g-1}
. Let
T_{k}(|A|,|B|,|C|)
denote the running time of the algorithm (with parameter
k
). Then, up to some linear-time bookkeeping we can bound the running time by summing over all partially relevant pairs
(i,j)
as

\displaystyle\sum_{\begin{subarray}{c}(i,j)\in[g]^{2}\\
\text{part.\ relevant}\end{subarray}}T_{k-1}(|A_{i}|,|B_{j}|,|C_{i,j}|)

\displaystyle\qquad=\sum_{\Delta=-g+1}^{g-1}\sum_{\begin{subarray}{c}(i,j)\in\mathcal{C}_{\Delta}\\
\text{part.\ relevant}\end{subarray}}T_{k-1}(|A_{i}|,|B_{j}|,|C_{i,j}|)

Now observe the following two facts: First, note that in each chain there is at most one pair
(i,j)=(i,i+\Delta)
that is partially but not totally relevant, since such a pair satisfies
\min_{k}(A_{i})+\min_{k}(B_{i+\Delta})\leq t
and
\max_{k}(A_{i})+\max_{k}(B_{i+\Delta})>t
. Note further that
i+\Delta
cannot be heavy as this would contradict Property (4) (ii), and thus
i+\Delta
is light. For this one pair we will apply the trivial bound
T_{k-1}(|A_{i}|,|B_{j}|,|C_{i,j}|)\leq\widetilde{O}(|A_{i}|\,|B_{j}|)\leq\widetilde{O}(\frac{|A|\,|B|}{g^{2}})
, where the last inequality is due to Properties (3) and (4) (i). It follows that we can further bound the running time by:

\displaystyle\qquad=\sum_{\Delta=-g+1}^{g-1}\left\lparen\widetilde{O}\left\lparen\frac{|A|\,|B|}{g^{2}}\right\rparen+\sum_{\begin{subarray}{c}(i,j)\in\mathcal{C}_{\Delta}\\
\text{tot.\ relevant}\end{subarray}}T_{k-1}(|A_{i}|,|B_{j}|,|C_{i,j}|)\right\rparen

\displaystyle\qquad=\sum_{\Delta=-g+1}^{g-1}\widetilde{O}\left\lparen\frac{|A|\,|B|}{g^{2}}+\sum_{\begin{subarray}{c}(i,j)\in\mathcal{C}_{\Delta}\\
\text{tot.\ relevant}\end{subarray}}(|A_{i}|\,|B_{j}|)^{1-\frac{1}{k}}|C_{i,j}|^{\frac{1}{k}}+|A_{i}|+|B_{j}|\right\rparen

\displaystyle\qquad=\sum_{\Delta=-g+1}^{g-1}\widetilde{O}\left\lparen\frac{|A|\,|B|}{g^{2}}+\left\lparen\sum_{\begin{subarray}{c}(i,j)\in\mathcal{C}_{\Delta}\\
\text{tot.\ relevant}\end{subarray}}|A_{i}|\,|B_{j}|\right\rparen^{1-\frac{1}{k}}\cdot\left\lparen\sum_{\begin{subarray}{c}(i,j)\in\mathcal{C}_{\Delta}\\
\text{tot.\ relevant}\end{subarray}}|C_{i,j}|\right\rparen^{\frac{1}{k}}+|A|+|B|\right\rparen,

where in the last two steps we have applied the induction hypothesis and Hölder’s inequality. Next, observe that all sets
C_{i,j}
along a common chain
\mathcal{C}_{\Delta}
do not intersect. Indeed, this follows from
\max_{k}(C_{i,j})=\max_{k}(A_{i})+\max_{k}(B_{j})<\min_{k}(A_{i+1})+\min_{k}(B_{j+1})=\min_{j}(C_{i+1,j+1})
, where we have applied Properties (1) and (2) (crucially using the strict inequalities). In particular, summing over all totally relevant pairs
(i,j)
in a common chain gives
\sum_{(i,j)}|C_{i,j}|\leq|C|
. From this we can finally bound:

\displaystyle\qquad=\sum_{\Delta=-g+1}^{g-1}\widetilde{O}\left\lparen\frac{|A|\,|B|}{g^{2}}+\left\lparen\sum_{\begin{subarray}{c}(i,j)\in\mathcal{C}_{\Delta}\\
\text{tot.\ relevant}\end{subarray}}|A_{i}|\,|B_{j}|\right\rparen^{1-\frac{1}{k}}\cdot|C|^{\frac{1}{k}}+|A|+|B|\right\rparen

\displaystyle\qquad=\sum_{\Delta=-g+1}^{g-1}\widetilde{O}\left\lparen\frac{|A|\,|B|}{g^{2}}+\left\lparen\frac{|A|}{g}\cdot\sum_{\begin{subarray}{c}(i,j)\in\mathcal{C}_{\Delta}\\
\text{tot.\ relevant}\end{subarray}}|B_{j}|\right\rparen^{1-\frac{1}{k}}\cdot|C|^{\frac{1}{k}}+|A|+|B|\right\rparen,

\displaystyle\qquad=\sum_{\Delta=-g+1}^{g-1}\widetilde{O}\left\lparen\frac{|A|\,|B|}{g^{2}}+\left\lparen\frac{|A|\,|B|}{g}\right\rparen^{1-\frac{1}{k}}\cdot|C|^{\frac{1}{k}}+|A|+|B|\right\rparen

\displaystyle\qquad=\widetilde{O}\left\lparen\frac{|A|\,|B|}{g}+g^{\frac{1}{k}}\cdot(|A|\,|B|)^{1-\frac{1}{k}}\cdot|C|^{\frac{1}{k}}+g|A|+g|B|\right\rparen.

By choosing
g=(|A|\,|B|/|C|)^{\frac{1}{k+1}}
the running time becomes
\widetilde{O}(|A|+|B|+(|A|\,|B|)^{1-\frac{1}{k+1}}|C|^{\frac{1}{k+1}})
as claimed. This is easy to verify for the first terms. For the latter two terms note that

g|A|\leq g|A|^{1-\frac{2}{k+1}}\cdot|C|^{\frac{2}{k+1}}=|A|^{1-\frac{1}{k+1}}|B|^{\frac{1}{k+1}}|C|^{\frac{1}{k+1}}\leq(|A|\,|B|)^{1-\frac{1}{k+1}}|C|^{\frac{1}{k+1}}.

As a subtlety, we remark that we do not know
|C|
a priori, and thus cannot simply choose
g
. However, we can run the algorithm with exponentially increasing
guesses

s\leftarrow 2,4,8,\dots
of
|C|
. For each guess we set
g=(|A|\,|B|/s)^{\frac{1}{k+1}}
, let the algorithm run for
\widetilde{O}(|A|+|B|+(|A|\,|B|)^{1-\frac{1}{k+1}}s^{\frac{1}{k+1}})
steps, and if the time budget is exceeded we interrupt and continue with the next guess. Otherwise, we return the set
C
computed by the algorithm. The total running time is bounded by the geometric sum

\sum_{\ell\leq\log|C|+1}\widetilde{O}(|A|+|B|+(|A|\,|B|)^{1-\frac{1}{k+1}}(2^{\ell})^{\frac{1}{k+1}})=\widetilde{O}(|A|+|B|+(|A|\,|B|)^{1-\frac{1}{k+1}}|C|^{\frac{1}{k+1}}),

which only worsens the running time by a logarithmic factor.

We finally comment on the logarithmic factors. The initial use of the orthogonal range searching data structure as well as guessing
g
lead to an overhead of
(\log(|A|\,|B|))^{O(d)}
. The remaining logarithmic factors in the algorithm are due to the sparse convolutions at the base level of the recursion. By
Lemma

2.2
, this step can be implemented by a Las Vegas algorithm with a running time overhead of
\log(|A||B|)
, or by a deterministic algorithm with an overhead of
\polylog(t)
.
∎

From this theorem we can now easily derive the high-dimensional “large items” lemma:

4.2
Large Items.

Let
d\geq 1
be a constant, let
\gamma>0
, let
X_{L}\subseteq[0\ldots t]^{d}\setminus[0\ldots\gamma t]^{d}
be a multiset and let
Z\subseteq[0\ldots t]^{d}
. We can compute
Z^{\prime}=(Z+\mathcal{S}(X_{L},t))\cap[0\ldots t]^{d}
in time
\widetilde{O}(|Z^{\prime}|\cdot|X_{L}|^{1-\frac{1}{d+1}}\cdot\poly(\gamma^{-1}))
(by a Las Vegas algorithm).

Proof.

Let
m=\lceil d/\gamma\rceil
. Suppose that we have a family of hash functions
\mathcal{H}\subseteq\{h:X\to[K]\}
(for some parameter
K
) with the following property: For any distinct elements
x_{1},\dots,x_{m}\in X_{L}
, there is a hash function
h\in\mathcal{H}
such that
h(x_{1}),\dots,h(x_{m})
are pairwise distinct (we say that
x_{1},\dots,x_{m}
are
hashed perfectly
). We will first show how we can use this family to prove the lemma statement, and later show how to deterministically construct
\mathcal{H}
.

To compute
Z^{\prime}
, we enumerate all hash functions
h\in\mathcal{H}
and define
X_{h,i}=\{x\in X:h(x)=i\}
; note that this induces a partition
X_{L}=X_{h,1}\sqcup\dots\sqcup X_{h,K}
into
K
parts. For each function
h\in\mathcal{H}
we compute the set

Z^{\prime}_{h}=(Z+(X_{h,1}\cup\{0\})+\dots+(X_{h,1}\cup\{0\}))\cap[0\ldots t]^{d},

by
K
applications of
Theorem

4.1
. Then we return
\bigcup_{h\in\mathcal{H}}Z^{\prime}_{h}
.

It is easy to verify that
\bigcup_{h\in\mathcal{H}}Z^{\prime}_{h}\subseteq Z
, and it remains to verify the converse direction. Take any element
z\in Z
, which can expressed as
z^{\prime}=z+x_{1}+\dots+x_{\ell}
where
z\in Z
,
x_{1},\dots,x_{\ell}\in X_{L}
. Note that
\ell\leq d/\gamma\leq m
, as each vector
x_{i}
is at least
\gamma t
in at least one of the
d
coordinates, whereas
z^{\prime}\in[0\ldots t]^{d}
. Thus, there is a hash function
h\in\mathcal{H}
that perfectly hashes
x_{1},\dots,x_{\ell}
and it follows from the construction that
z^{\prime}\in Z^{\prime}_{h}
.

It remains to construct
\mathcal{H}
. We employ the construction behind Reed-Solomon codes. Specifically, let
p=K
be a prime. We identify
[K]
arbitrarily with the finite field
\mathbb{F}_{p}
. Let
D=\lceil\log_{p}|X_{L}|\rceil
. Then we can uniquely identify each item
x\in X_{L}
with a degree-
D
polynomial
P_{x}
over
\mathbb{F}_{p}
. Finally, take
\mathcal{H}=\{h_{0},\dots,h_{p-1}\}
, where the hash functions
h_{i}:X\to\mathbb{F}_{p}
are defined by
h_{i}(x)=P_{x}(i)
. This completes the construction of
\mathcal{H}
, and in the following we argue that this family is as desired. First consider an arbitrary pair of distinct items
x_{1},x_{2}\in X_{L}
. Since
P_{x_{1}}
and
P_{x_{2}}
are distinct degree-
D
polynomials, they can be equal on at most
D
points. Thus, there are at most
D
hash functions
h_{i}
with
h_{i}(x_{1})=h_{i}(x_{2})
. Similarly, for any distinct items
x_{1},\dots,x_{m}
there are at most
\binom{m}{2}\cdot D
hash functions that do not perfectly hash
x_{1},\dots,x_{m}
. Choosing
p\in[m^{2}\cdot\lceil\log|X_{L}|\rceil,2m^{2}\cdot\lceil\log|X_{L}|\rceil]
it holds that
\binom{m}{2}\cdot D<p=|\mathcal{H}|
, hence there is at least one good hash function and the claim follows.

It remains to analyze the running time. Operations over the finite field
\mathbb{F}_{p}
can easily be implemented in time
\poly(p)=\poly(m\log|X_{L}|)
, and therefore the construction of the hash family
\mathcal{H}
takes time
\widetilde{O}(|X_{L}|\poly(m))=\widetilde{O}(|X_{L}|\poly(\gamma^{-1}))
. The running time of the algorithm is then dominated by the
|\mathcal{H}|\cdot K=\poly(m\log|X_{L}|)=\poly(\gamma^{-1}\log|X_{L}|)
calls to
Theorem

4.1
.
Each such call is with sets
A,C\subseteq Z^{\prime}
and
B\subseteq X_{L}\cup\{0\}
, and thus runs in time
O(|Z^{\prime}|\cdot|X_{L}|^{1-\frac{1}{d+1}}\polylog(t))
, if we use the deterministic algorithm of
Theorem

4.1
. However, here we want to avoid the
\polylog(t)
factor, and thus use the Las Vegas algorithm of
Theorem

4.1
, so that each call runs in time
\widetilde{O}(|Z^{\prime}|\cdot|X_{L}|^{1-\frac{1}{d+1}})
. Since the rest of the algorithm is deterministic, in total we obtain a Las Vegas algorithm. (Note that it indeed was necessary to use a deterministic hash family
\mathcal{H}
to obtain this result, as a random hash family would only yield a Monte Carlo randomized algorithm.)
∎

4.2
Color Coding

The second step is to derive the high-dimensional analogue of the color coding lemma for small items:

4.3
Small Items.

Let
d\geq 1
be a constant, let
K\geq 1
and let
X\subseteq[0\ldots\frac{t}{K^{5}}]^{d}
be a multiset. Let
X=X_{1}\sqcup\dots\sqcup X_{K}
denote a uniformly random partition into
K
parts. Then with probability at least
1-\exp(-K)\cdot|\mathcal{S}(X,t)|\cdot d
it holds that

\mathcal{S}(X,t)=\Big(\sum_{i=1}^{K}\mathcal{S}(X_{i},(1+\tfrac{1}{K})\cdot\tfrac{t}{K})\Big)\cap[0\ldots t].

For the proof of
Lemma

4.3
we rely on Hoeffding’s inequality:

4.4
Hoeffding’s Inequality.

Let
Z_{1},\dots,Z_{n}
be independent random variables such that
Z_{i}
takes values in
[a_{i},b_{i}]
. Then for
Z=Z_{1}+\dots+Z_{n}
it holds that

\Pr\left\lparen Z-\Ex[Z]\geq\lambda\right\rparen\leq\exp\left\lparen-\frac{2\lambda^{2}}{\sum_{i=1}^{n}(b_{i}-a_{i})^{2}}\right\rparen.

Proof of
Lemma

4.3
.

Consider any subset sum
z\in\mathcal{S}(X,t)
expressed as
z=x_{1}+\dots+x_{m}
; we show that with good probability
z\in\sum_{i=1}^{K}\mathcal{S}(X_{i},(1+\tfrac{1}{K})\cdot\tfrac{t}{K})
. Fix an arbitrary part
X_{i}
and a coordinate
\ell\in[d]
. Let
Z_{1},\dots,Z_{m}
be random variables such that
Z_{j}=x_{j}[\ell]
if
x_{j}
is placed in the part
X_{i}
, and
Z_{j}=0
otherwise. Writing
Z=Z_{1}+\dots+Z_{m}
we can bound the expectation of
Z
by

\Ex[Z]=\Ex[Z_{1}]+\dots+\Ex[Z_{m}]\leq\frac{x_{1}[\ell]}{K}+\dots+\frac{x_{m}[\ell]}{K}=\frac{z[\ell]}{K}\leq\frac{t}{K}.

Using that the random variable
Z_{j}
takes values in
[0\ldots x_{j}[\ell]]
(where
x_{j}[\ell]\leq t/K^{5}
and
\sum_{j}x_{j}[\ell]\leq t
), from Hoeffding’s inequality it follows that

\displaystyle\Pr\left\lparen Z>\left\lparen 1+\frac{1}{K}\right\rparen\cdot\frac{t}{K}\right\rparen

\displaystyle\qquad\leq\Pr\left\lparen Z-\Ex[Z]>\frac{t}{K^{2}}\right\rparen

\displaystyle\qquad\leq\exp\left\lparen-\frac{2(t/K^{2})^{2}}{\sum_{j=1}^{m}x_{j}[\ell]^{2}}\right\rparen

\displaystyle\qquad\leq\exp\left\lparen-\frac{2(t/K^{2})^{2}}{t^{2}/K^{5}}\right\rparen

\displaystyle\qquad=\vphantom{\bigg(}\exp\left\lparen-2K\right\rparen.

That is, with probability at least
1-\exp(-2K)
the contribution of the subset
z
to the
i
-th bucket in the
\ell
-th coordinate does not exceed the threshold
(1+\frac{1}{K})\cdot\frac{t}{K}
. Taking a union bound over the at most
|\mathcal{S}(X,t)|
subset sums, the
K
buckets and the
d
dimensions, the total error probability indeed becomes
\exp(-2K)\cdot|\mathcal{S}(X,t)|\cdot K\cdot d\leq\exp(-K)\cdot|\mathcal{S}(X,t)|\cdot d
.
∎

satisfying that

4.5
Number of Recursive Calls.

4.7

3

Let

4.2

4.4
Approximating the Number of Subset Sums

Finally, we remove the assumption that the algorithm requires an estimate

of

as an input, and thereby complete the proof of

1.3
. Recall that we could easily set

\polylog|\mathcal{S}(X,t)|

Proof of
Theorem

1.3
.

Provided that
s\geq|\mathcal{S}(X,t)|
we have already established in

4.6
and
4.7
that

2
is correct and runs in time
|\mathcal{S}(X,t)|\cdot|X|^{1-\frac{1}{d+1}}\cdot(\log s)^{O(d)}
. We now design a recursive algorithm that computes
\mathcal{S}(X,t)
with high probability, without expecting an approximation

. For constant-sized sets

we can compute the answer trivially, say by Bellman’s algorithm. Otherwise, arbitrarily partition
X=X_{1}\sqcup X_{2}
into sets of size at most
\lceil|X|/2\rceil
and compute the subset sums
\mathcal{S}(X_{1},\frac{t}{2})
and
\mathcal{S}(X_{2},\frac{t}{2})

s_{1}=|\mathcal{S}(X_{1},\frac{t}{2})|
and
s_{2}=|\mathcal{S}(X_{2},\frac{t}{2})|

. We then call

2

and report the resulting answer.

For the correctness, we argue that
s\geq|\mathcal{S}(X,t)|
. To this end we show the existence of an injection
f:\mathcal{S}(X,t)\to X^{4d}\times\mathcal{S}(X_{1},\frac{t}{2})^{4d}\times\mathcal{S}(X_{2},\frac{t}{2})^{4d}
. Fix any subset sum
z\in\mathcal{S}(X,t)
expressed as
z=x_{1}+\dots+x_{m}
; we describe how to choose

. First, take aside all vectors
x_{i}
with an entry of size larger than
\frac{t}{4}
; note that there can be at most
4d
such terms. Afterwards, we split the remaining subset sum into
x_{1,1}+\dots+x_{1,m_{1}}+x_{2,1}+\dots+x_{2,m_{2}}
where
x_{1,1},\dots,x_{1,m_{1}}\in X_{1}\cap[0\ldots\frac{t}{4}]^{d}
and
x_{2,1},\dots,x_{2,m_{1}}\in X_{2}\cap[0\ldots\frac{t}{4}]^{d}
. Next, focus on
x_{1,1}+\dots+x_{1,m_{1}}
. We can greedily take the maximal prefix sum with value in
[0\ldots\frac{t}{2}]^{d}
; since each vector is
\frac{t}{4}
-bounded this prefix sum is at least
\frac{t}{4}
in some coordinate. Thus, by repeatedly splitting off these prefix sums we eventually end up splitting the initial subset sum

into at most

subset sums contained in
\mathcal{S}(X_{1},\frac{t}{2})
. We similarly split
x_{2,1}+\dots+x_{2,m_{2}}
. Finally, we choose

to be the
(4d+4d+4d)
-tuple obtained from the

subdivisions of the remaining subset sums. This mapping

is clearly injective as we can recover

, and thus it follows that indeed

.

For the running time observe that we always pick
s=s_{1}^{4d}\cdot s_{2}^{4d}\cdot|X|^{4d}\leq|\mathcal{S}(X,t)|^{12d}
, and therefore
\log(s)=O(\log|\mathcal{S}(X,t)|)
. It remains to bound the overhead due to the additional layer of recursion. Again, view the computation as a binary tree with depth

. Each layer

\displaystyle\sum_{i=1}^{2^{\ell}}\widetilde{O}\left\lparen|\mathcal{S}(X_{i},\tfrac{t}{2^{\ell}})|\cdot|X|^{1-\frac{1}{d+1}}\right\rparen

\displaystyle\qquad\leq\widetilde{O}\left\lparen\left\lparen 2^{\ell}+\left\lvert\sum_{i=1}^{2^{\ell}}\mathcal{S}(X_{i},\tfrac{t}{2^{\ell}})\right\rvert\right\rparen\cdot|X|^{1-\frac{1}{d+1}}\right\rparen

\displaystyle\qquad=\widetilde{O}\left\lparen|\mathcal{S}(X,t)|\cdot|X|^{1-\frac{1}{d+1}}\right\rparen,

using
Lemma

2.1

∎

Proof.

|\mathcal{S}^{*}(X,t)|\polylog(t)
