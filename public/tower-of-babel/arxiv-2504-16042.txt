Approximate matrices of systems of max-min fuzzy relational equations
Ismaïl Baaj LEMMA, Paris-Panthéon-Assas University, Paris, 75006, France ismail.baaj@assas-universite.fr

Abstract
In this article, we address the inconsistency of a system of max-min fuzzy relational equations by minimally modifying the matrix governing the system in order to achieve consistency. Our method yields consistent systems that approximate the original inconsistent system in the following sense: the right-hand side vector of each consistent system is that of the inconsistent system, and the coefficients of the matrix governing each consistent system are obtained by modifying, exactly and minimally, the entries of the original matrix that must be corrected to achieve consistency, while leaving all other entries unchanged. To obtain a consistent system that closely approximates the considered inconsistent system, we study the distance (in terms of a norm among L 1 L_{1} , L 2 L_{2} or L ∞ L_{\infty} ) between the matrix of the inconsistent system and the set formed by the matrices of consistent systems that use the same right-hand side vector as the inconsistent system. We show that our method allows us to directly compute matrices of consistent systems that use the same right-hand side vector as the inconsistent system whose distance in terms of L ∞ L_{\infty} norm to the matrix of the inconsistent system is minimal (the computational costs are higher when using L 1 L_{1} norm or L 2 L_{2} norm). We also give an explicit analytical formula for computing this minimal L ∞ L_{\infty} distance. Finally, we translate our results for systems of min-max fuzzy relational equations and present some potential applications.



Keywords
Fuzzy set theory, Systems of fuzzy relational equations

Background

In this section, we give the necessary background for studying max-min systems.
We begin by giving some notations. We then remind the solving of max-min systems and some of the results of
[

]

2.1
Notations and matrix products

We use the following notations:

Notation 1
.

[0,1]^{n\times m}
denotes the set of matrices of size
(n,m)
i.e.,
n
rows and
m
columns, whose components are in
[0,1]
. In particular:

•

[0,1]^{n\times 1}
denotes the set of column vectors of
n
components,

•

[0,1]^{1\times m}
denotes the set of row matrices of
m
components.

In the set
[0,1]^{n\times m}
, we use the order relation
\leq
defined by:

A\leq B\quad\text{iff we have}\quad a_{ij}\leq b_{ij}\quad\text{ for all }\quad 1\leq i\leq n,1\leq j\leq m,

where
A=[a_{ij}]_{1\leq i\leq n,1\leq j\leq m}
and
B=[b_{ij}]_{1\leq i\leq n,1\leq j\leq m}
.

The two matrix products
\Box_{\min}^{\max}
, and
\Box_{\rightarrow_{G}}^{\min}
used in this article are defined by modifying the usual matrix product:

•

the matrix product
\Box_{\min}^{\max}
is obtained by taking the t-norm
\min
as the product and the function
\max
as the addition.

•

the matrix product
\Box_{\rightarrow_{G}}^{\min}
is obtained by taking the Gödel implication
\rightarrow_{G}
, which is defined by:

x\rightarrow_{G}y=\begin{cases}1&\text{ if }x\leq y\\
y&\text{otherwise.}\end{cases}\text{ in }[0,1]

(1)

as the product and the function
\min
as the addition.

2.2
Systems of max-min fuzzy relational equations

Let
A=[a_{ij}]\in[0,1]^{n\times m}
be a matrix of size
(n,m)
and
b=[b_{i}]\in[0,1]^{n\times 1}
be a vector of
n
components. The system of max-min fuzzy relational equations associated with
(A,b)
is denoted by:

(S):A\Box_{\min}^{\max}x=b,

(2)

where
x=[x_{j}]_{1\leq j\leq m}\in[0,1]^{m\times 1}
is an unknown vector of
m
components. By definition of the matrix product
\Box_{\min}^{\max}
, the system
(S)
is equivalent to the following set of
n
max-min equations:

\max_{1\leq j\leq m}\min(a_{ij},x_{j})=b_{i},\,\forall i\in\{1,2,\dots,n\}.

To check if the system
(S)
, see (
2
), is consistent, we compute the following vector:

e=A^{t}\Box_{\rightarrow_{G}}^{\min}b,

(3)

where
A^{t}
is the transpose of
A
and we use the matrix product
\Box_{\rightarrow_{G}}^{\min}
(Notation
1
). The components of the vector
e=[e_{j}]_{1\leq j\leq m}
are given by:

e_{j}=\min_{1\leq i\leq n}(a_{ij}\rightarrow_{G}b_{i}),\forall j\in\{1,2,\dots,m\}.

The vector
e
is the potential greatest solution of the system
(S)
.

Thanks to Sanchez’s seminal work
[
29
]
on the solving of systems max-min fuzzy relational equations, we have the following equivalence:

\text{The system }(S)\text{ is consistent}\Longleftrightarrow A\Box_{\min}^{\max}e=b.

(4)

The set of solutions of the system
(S)
is denoted by:

{\cal S}={\cal S}(A,b)=\{v\in[0,1]^{m\times 1}\,\mid\,A\,\Box_{\min}^{\max}v=b\}.

(5)

The structure of the solution set was described by Sanchez in
[
29
]
for systems of max-min fuzzy relational equations. He proved that if
{\cal S}
is non-empty i.e., the system
(S)
is consistent, the structure of
{\cal S}
is given by the vector
e=A^{t}\Box_{\rightarrow_{G}}^{\min}b
, see (
3
), which is the greatest solution of the system
(S)
and a finite number of minimal solutions.

Example 1
.

Let a max-min system
A\Box_{\min}^{\max}x=b
be defined by
A=\begin{bmatrix}0.79&0.29&0.28\\
0.76&0.79&0.18\\
0.53&0.21&0.11\end{bmatrix}
and
b=\begin{bmatrix}0.35\\
0.6\\
0.35\end{bmatrix}
.

We compute the potential greatest solution of the system:

e=A^{t}\Box_{\rightarrow_{G}}^{\min}b=\begin{bmatrix}\min(0.79\rightarrow_{G}0.35,0.76\rightarrow_{G}0.6,0.53\rightarrow_{G}0.35)\\
\min(0.29\rightarrow_{G}0.35,0.79\rightarrow_{G}0.6,0.21\rightarrow_{G}0.35)\\
\min(0.28\rightarrow_{G}0.35,0.18\rightarrow_{G}0.6,0.11\rightarrow_{G}0.35)\\
\end{bmatrix}=\begin{bmatrix}0.35\\
0.6\\
1\end{bmatrix}.

The equation system
A\Box_{\min}^{\max}x=b
is consistent because:

A\Box_{\min}^{\max}e=\begin{bmatrix}\max(\min(0.79,0.35),\min(0.29,0.6),\min(0.28,1))\\
\max(\min(0.76,0.35),\min(0.79,0.6),\min(0.18,1))\\
\max(\min(0.53,0.35),\min(0.21,0.6),\min(0.11,1))\\
\end{bmatrix}=\begin{bmatrix}0.35\\
0.6\\
0.35\end{bmatrix}=b.

So the vector
e
is the greatest solution of the system.

2.3
Handling inconsistent systems of max-min fuzzy relational equations

Recently, the author of
[
5
]
studied how to handle inconsistent systems of max-min fuzzy relational equations. The tools introduced by
[
5
]
follow the strategy proposed by Pedrycz in
[
26
]
, which is as follows: given an inconsistent system, we perturb, as slighly as possible, the components of the right-hand side vector of the inconsistent system in order to obtain a consistent system.

To remind the tools of the author
[
5
]
we reuse some of his notations:

Notation 2
.

For
x,y,z,u,\delta\in[0,1]
, we use the following notations:

•

x^{+}=\max(x,0)
,

•

\overline{z}(\delta)=\min(z+\delta,1)
,

•

\underline{z}(\delta)=\max(z-\delta,0)=(z-\delta)^{+}
.

We rely on the following function, which was introduced in
[
5
]
:

\sigma_{G}(x,y,z)=\min(\frac{(x-z)^{+}}{2},(y-z)^{+})\quad\text{ where }\quad x,y,z\in[0,1].

(6)

Let
T=\begin{bmatrix}t_{ij}\end{bmatrix}_{1\leq i\leq n,1\leq j\leq m}\in[0,1]^{n\times m}
be a matrix. We rely on the following function defined for all
i\in\ \{1,2,\cdots,n\}
, which appears in
[
5
]
and uses the matrix
T
and the right-hand side vector
b=[b_{i}]\in[0,1]^{n\times 1}
of the system
T\Box_{\min}^{\max}x=b
:

[0,1]^{n\times m}\rightarrow[0,1]:T\mapsto\delta^{T}_{i}=\min_{1\leq j\leq m}\delta^{T}{(i,j)}

(7)

where:

\delta^{T}{(i,j)}=\max[(b_{i}-t_{ij})^{+},\max_{1\leq k\leq n}\,\sigma_{G}\,(b_{i},t_{kj},b_{k})]\quad\quad\text{(see (\ref{eq:sigmaG}) for the definition of }\sigma_{G})

(8)

Since the operations involved (minimum, maximum, and taking the positive part) are continuous on the compact set
[0,1]^{n\times m}
, we get the following result:

Lemma 1
.

For all
i\in\ \{1,2,\cdots,n\}
, the function

[0,1]^{n\times m}\rightarrow[0,1]:T\mapsto\delta^{T}_{i}
is continuous.

∎

Given the matrix
A
of an inconsistent max-min system
(S):A\Box_{\min}^{\max}x=b
, see (
2
), the author of
[
5
]
defines:

Definition 1
.

The set formed by the right-hand side vectors of the consistent systems defined with the same matrix
A
of the system
(S):A\Box_{\min}^{\max}x=b
is:

\mathcal{C}=\{c\in[0,1]^{n\times 1}\mid\text{ the system }A\Box_{\min}^{\max}x=c\text{ is consistent }\}.

(9)

Definition 2
.

The Chebyshev distance (using L-infinity norm) associated with the inconsistent max-min system
(S):A\Box_{\min}^{\max}x=b
(see (
2
)) is:

\Delta=\min_{c\in\mathcal{C}}\|b-c\|_{\infty}\text{ where }\|b-c\|=\max_{1\leq i\leq n}\mid b_{i}-c_{i}\mid.

(10)

The author of
[
5
]
introduced an analytical formula for computing the Chebyshev distance
\Delta
(Definition
2
) associated to the max-min system
(S):A\Box_{\min}^{\max}x=b
, which relies on
\delta^{A}_{i}
, see (
7
):

\Delta=\Delta(A,b)=\max_{1\leq i\leq n}\delta^{A}_{i}

(11)

The following results were proven in
[
5
]
:

\Delta=0\Longleftrightarrow\text{ the system }(S):A\Box_{\min}^{\max}x=b\text{ is consistent. }

(12)

We define a subset of
\mathcal{C}
, see (
9
):

Definition 3
.

The set of Chebyshev approximations of the right-hand side vector
b
of the system
(S):A\Box_{\min}^{\max}x=b
(see (
2
)) is defined using the Chebyshev distance
\Delta
associated with the right-hand side vector
b
of
(S)
(see Definition
2
):

\mathcal{C}_{b}=\{c\in[0,1]^{n\times 1}\mid\text{ the system }A\Box_{\min}^{\max}x=c\text{ is consistent and }\|b-c\|=\Delta\}\subseteq\mathcal{C}.

(13)

The author of
[
5
]
showed that we can directly obtain one vector in
\mathcal{C}_{b}
: the greatest Chebyshev approximation of the right-hand side vector

:

\widehat{b}=A\Box_{\min}^{\max}(A^{t}\Box_{\rightarrow_{G}}^{\min}\overline{b}(\Delta))\in\mathcal{C}_{b},

(14)

where
\overline{b}(\Delta)=\begin{bmatrix}\min(b_{i}+\Delta,1)\end{bmatrix}_{1\leq i\leq n}
. So, we have
\|b-\widehat{b}\|=\Delta
and the system

is consistent. Obtaining the minimal Chebyshev approximations of

is possible with a method developed in

]
, but minimal approximations are more expensive to obtain in terms of computational cost than the greatest Chebyshev approximation

.

The author of
[
5
]
defines:

Definition 4
.

An approximate solution of the system
(S):A\Box_{\min}^{\max}x=b
is a vector
x^{\ast}
such that the distance between the vector
c=A\Box_{\min}^{\max}x^{\ast}
and the vector

is equal to
\Delta
, i.e., we have

. Thus, the vector

is a solution of a consistent system

defined with the matrix
A
and the vector

, which is a Chebyshev approximation of

(Definition

), i.e., we have

.

In
[
5
]
, the author showed that we can directly obtain the greatest approximate solution of the system
(S)
, which is the following vector:

\eta=A^{t}\Box_{\rightarrow_{G}}^{\min}\overline{b}(\Delta).

(15)

Of course, the greatest approximate solution
\eta
of the system
(S)
is the greatest solution of the consistent system

. In
[

]
, the author describes how to obtain a set of minimal approximate solutions.

Example 2
.

Let a max-min system
A\Box_{\min}^{\max}x=b
be defined by:

A=\begin{bmatrix}0.04&0.73&0.50\\
0.33&0.35&0.94\\
0.55&0.90&0.35\end{bmatrix}\quad\text{ and }\quad b=\begin{bmatrix}0.30\\
0.42\\
0.76\end{bmatrix}

(16)

We compute the Chebyshev distance

, see (

), associated with the right-hand side vector

:

\Delta=\max_{1\leq i\leq 3}\delta^{A}_{i}

where:

\displaystyle\delta^{A}_{1}

\displaystyle=\min(\delta(1,1),\delta(1,2),\delta(1,3))=\min(0.26,0,0)=0,

\displaystyle\delta^{A}_{2}

\displaystyle=\min(\delta(2,1),\delta(2,2),\delta(2,3))=\min(0.09,0.07,0.06)=0.06,

\displaystyle\delta^{A}_{3}

\displaystyle=\min(\delta(3,1),\delta(3,2),\delta(3,3))=\min(0.21,0.23,0.41)=0.21.

Therefore, we obtain

\overline{b}(\Delta)=\begin{bmatrix}0.51\\

\widehat{b}=A\Box_{\min}^{\max}(A^{t}\Box_{\rightarrow_{G}}^{\min}\overline{b}(\Delta))=\begin{bmatrix}0.51\\

One can check that

and that the system

We compute the greatest approximate solution of the inconsistent system

, see (

\eta=A^{t}\Box_{\rightarrow_{G}}^{\min}\overline{b}(\Delta)=\begin{bmatrix}1.0\\
0.51\\

One can check that
\eta
is the greatest solution of the consistent system
A\Box_{\min}^{\max}x=\widehat{b}
.

3
On minimally modifying the matrix of an inconsistent max-min system

In this section, we present our problem formally: how to minimally modify the matrix
A
of size
(n,m)
of an inconsistent max-min system
(S):A\Box_{\min}^{\max}x=b
, see (
2
), in order to obtain a consistent system, while keeping the right-hand side vector
b
unchanged.

For this purpose, we introduce the following set, which is formed by the matrices of size
(n,m)
governing the consistent max-min systems which use the same right-hand side vector: the right-hand side vector
b
of the system
(S)
:

{\cal T}=\{T\in[0,1]^{n\times m}\mid\text{the system }T\Box_{\min}^{\max}x=b\text{ is consistent}\}.

(17)

It is easy to see that the particular matrix
T=[t_{kl}]_{1\leq k\leq n,1\leq l\leq m}

whose coefficients are
t_{kl}:=b_{k}
, belongs to the set
{\cal T}
. Therefore
{\cal T}
is a non-empty set.

For each
p\in\{1,2,\infty\}
, we define the distance from the fixed matrix
A
to the set
\mathcal{T}
as:

\mathring{\Delta}_{p}:=\inf_{T\in\mathcal{T}}\|T-A\|_{p}.

(18)

Here,
\|\cdot\|_{p}
denotes the matrix norm with exponent
p
, namely, for a matrix
X=[x_{ij}]\in\mathbb{R}^{n\times m}
:

\|X\|_{p}\;=\;\begin{cases}\displaystyle\sum_{i=1}^{n}\sum_{j=1}^{m}\bigl|x_{ij}\bigr|,&p=1,\\[10.00002pt]
\displaystyle\Bigl(\sum_{i=1}^{n}\sum_{j=1}^{m}\bigl|x_{ij}\bigr|^{2}\Bigr)^{\!1/2},&p=2,\\[10.00002pt]
\displaystyle\max_{1\leq i\leq n,\;1\leq j\leq m}\bigl|x_{ij}\bigr|,&p=\infty.\end{cases}

(19)

Our aim is to compute matrices in the set
\mathcal{T}
, i.e., matrices governing consistent max-min systems whose right-hand side vector is
b
, which are the closest to the matrix
A
of the system
(S):A\Box_{\min}^{\max}x=b
according to the distance
\mathring{\Delta}_{p}
. We also study how to compute the distance
\mathring{\Delta}_{p}
with respect to
p
according to the coefficients of
A
and
b
.

In this section, we present some preliminary results and tools that will be useful for constructing matrices in the set
\mathcal{T}
in subsequent sections.
We show that the matrices of the set
\mathcal{T}
defined in (

) dominate in a certain sense the auxiliary matrices noted
A^{(i,j)}
associated with pairs of indices
(i,j)\in\{1,2,\dots,n\}\times\{1,2,\dots,m\}
, that we introduce in Definition
5
. We establish useful properties of these auxiliary matrices
A^{(i,j)}
for our problem.

Lemma 2
.

The formula (
18
) can be rewritten as:

\mathring{\Delta}_{p}=\min\limits_{T\in{\cal T}}\,\|T-A\|_{p}.

The proof is given in Subsection
A.1
.

We deduce the following equivalence, which is analog to (
12
):

Corollary 1
.

\mathring{\Delta}_{p}=0\Longleftrightarrow\text{ the system $(S)$ is consistent.}

(20)

3.1
Constructing the auxiliary matrices
A^{(i,j)}
from the matrix
A
of the inconsistent system
(S):A\Box_{\min}^{\max}x=b

We introduce the following notations associated with the system
(S):A\Box_{\min}^{\max}x=b
, see (
2
).

Notation 3
.

Let us use the following set of indices:

I=\{1,2,\cdots,n\}\quad\text{and}\quad J=\{1,2,\dots,m\}.

(21)

For all
(i,j)\in I\times J
, a given matrix
T=\begin{bmatrix}t_{ij}\end{bmatrix}_{1\leq i\leq n,1\leq j\leq m}\in[0,1]^{n\times m}
and the right-hand side vector
b
of the system
(S)
, we define the following set using the function
\sigma_{G}
, see (
6
):

U^{T}_{ij}:=\{k\in I\mid\sigma_{G}(b_{i},t_{kj},b_{k})>0\}.

(22)

Using (
6
), we get the following equivalent definition of the set
U^{T}_{ij}
:

U^{T}_{ij}=\{k\in I\mid\theta(i,k)\cdot(t_{kj}-b_{k})^{+}>0\}\quad\text{where}\quad\theta:I\times I\mapsto\{0,1\}:\theta(i,k)=\begin{cases}1&\text{ if }b_{i}>b_{k}\\
0&\text{ otherwise}\end{cases}.

(23)

In particular, for any pair of indices
(i,j)\in I\times J
, we can compute the set
U^{A}_{ij}
using the matrix
A
of the system
(S)
.

From the formula of the Chebyshev distance
\Delta=\max_{1\leq i\leq n}\delta^{A}_{i}
, see (
11
), associated with the right-hand side vector
b
of the system
(S)
, we set:

N_{\text{cons}}:=\{i\in I\mid\delta_{i}^{A}=0\}\quad\text{ and }\quad N_{\text{inc}}:=\overline{N_{\text{cons}}}=\{i\in I\mid\delta_{i}^{A}>0\}.

(24)

The two disjoint sets
N_{\text{cons}}
and
N_{\text{inc}}
form a partition of the set
I
associated with the pair
(A,b)
. We know by (
12
) that the equality
N_{\text{cons}}=I
is equivalent to the consistency of the system
(S):A\Box_{\min}^{\max}x=b
.

Definition 5
.

For any fixed pair of indices
(i,j)\in I\times J
, we define the matrix

A^{(i,j)}:=\begin{bmatrix}a^{(i,j)}_{kl}\end{bmatrix}_{1\leq k\leq n,\,1\leq l\leq m}\in[0,1]^{n\times m}
,
whose coefficients are defined using the matrix
A
, the right-hand side vector
b
of the inconsistent system
(S):A\Box_{\min}^{\max}x=b
, and the set
U^{A}_{ij}
, see (
22
), by:

a^{(i,j)}_{ij}:=\begin{cases}b_{i}\quad&\text{if }\quad b_{i}>a_{ij}\\
a_{ij}\quad&\text{if }\quad b_{i}\leq a_{ij}\end{cases}\quad\text{and for }\quad\forall k\in I\backslash\{i\},\quad a^{(i,j)}_{kj}:=\begin{cases}b_{k}\quad&\text{if }\quad k\in U^{A}_{ij}\\
a_{kj}\quad&\text{if }\quad k\notin U^{A}_{ij}\end{cases}.

(25a)

\forall k\in I\,\forall l\in J\backslash\{j\},\quad a^{(i,j)}_{kl}:=a_{kl}.

(25b)

The matrix
A^{(i,j)}
is derived from the matrix
A
by
only modifying some entries in the column with index
j
. Specifically, we have:

\forall(k,l)\in I\times J,\quad a^{(i,j)}_{kl}\in\{b_{k},a_{kl}\}.

(26)

We begin by establishing some useful properties of the scalars
\delta^{A^{(i,j)}}(s,l)
, which is computed using (
8
) and associated with the matrix
A^{(i,j)}
and the right-hand side vector
b
:

Lemma 3
.

Let
(i,j)\in I\times J
be a fixed pair of indices. Then, we have:

1.

\delta^{A^{(i,j)}}(i,j)=0
.

2.

For all
1\leq s\leq n
, we have:

\delta^{A}(s,j)=0\Longrightarrow\delta^{A^{(i,j)}}(s,j)=0.

3.

For all
1\leq s\leq n
and

1\leq l\not=j\leq m
, we have:

\delta^{A^{(i,j)}}(s,l)=\delta^{A}(s,l).

4.

\|A^{(i,j)}-A\|_{\infty}=\max\Bigl[(b_{i}-a_{ij})^{+},\,\max_{k\in I,k\neq i}\Bigl(\theta(i,k)\cdot(a_{kj}-b_{k})^{+}\Bigr)\Bigr]

where the function
\theta
is defined in (
23
).

Any matrix
T=[t_{kl}]_{1\leq k\leq n,1\leq l\leq m}
satisfying
\delta^{T}(i,j)=0
for a given pair of indices
(i,j)\in I\times J
dominates the auxiliary matrix

A^{(i,j)}
in the following sense: the distance
|t_{kl}-a_{kl}|
between a coefficient
t_{kl}
of the matrix
T
and the corresponding coefficient
a_{kl}
of the original matrix

is always at least as large as the distance
|a^{(i,j)}_{kl}-a_{kl}|
between the coefficient
a^{(i,j)}_{kl}
of the matrix
A^{(i,j)}
and
a_{kl}

Lemma 4
.

Let

be a matrix such that
\delta^{T}(i,j)=0
.
Then, we have:

1.

\mid a^{(i,j)}_{kl}-a_{kl}\mid\leq\mid t_{kl}-a_{kl}\mid

for all pairs
(k,l)\in I\times J
,

2.

\|A^{(i,j)}-A\|_{p}\leq\|T-A\|_{p}
for
p\in\{1,2,\infty\}
.

In the following lemma, we show that if we first apply the transformation

with parameters

to the fixed matrix

Lemma 5

Let

with

and

4
Main results on constructing consistent systems by minimally modifying the matrix of an inconsistent max-min system

In this section, we establish our main results for handling the inconsistency of a max-min system

by constructing consistent systems close to the system
(S)
: for each obtained consistent system that we obtain, its right-hand side vector is the right-hand side vector

of the system
(S)
while its matrix is of the form

(Definition
6
) and is obtained by minimal modifications of the matrix

of the system
(S)
, see Theorem
1
and Theorem

.

From these results, we compute the distance
\mathring{\Delta}_{p}
, see (

\mathring{\Delta}_{\infty}
, see (

). Finally, we provide a method to construct
a non-empty and finite subset of matrices

whose distance to the matrix

of the inconsistent system is equal to the scalar

, see (

).

Constructing consistent systems close to the initial inconsistent system

.

For

The following result highlights the minimality of the modifications made to obtain the matrices

Retain the notations from Theorem

•

6
Conclusion

In this article, we handled the inconsistency of a system of max-min fuzzy relational equations by modifying the matrix governing the system. Our main results (Theorem
1
and Theorem
2
) allows us to obtain
consistent systems that closely approximate the original inconsistent system in the following sense: the right-hand side vector of each consistent system is that of the inconsistent system, and the coefficients of the matrix governing each consistent system are obtained by modifying, exactly and minimally, the entries of the original matrix that must be corrected to achieve consistency, while leaving all other entries unchanged. The solutions of the obtained consistent systems can be considered as approximate solutions of the inconsistent system. We studied the distance
\mathring{\Delta}_{p}
(in terms of a norm among
L_{1}
,
L_{2}
or
L_{\infty}
) between the matrix of the inconsistent system and the set formed by the matrices of consistent systems that use the same right-hand side vector as the inconsistent system, see (
18
). We showed in Theorem
3
that our method allows us to directly compute matrices of consistent systems that use the same right-hand side vector as the inconsistent system whose distance in terms of
L_{\infty}
norm to the matrix of the inconsistent system is minimal (the computational costs are higher when using
L_{1}
norm or
L_{2}
norm, see Corollary
3
). We also give an explicit analytical formula for computing
\mathring{\Delta}_{\infty}
