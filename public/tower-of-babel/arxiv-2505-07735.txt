Assessing the Chemical Intelligence of Large Language Models
Nicholas T. Runcie, Charlotte M. Deane, Fergus Imrie

Abstract
Large Language Models are versatile, general-purpose tools with a wide range of applications. Recently, the advent of “reasoning models” has led to substantial improvements in their abilities in advanced problem-solving domains such as mathematics and software engineering. In this work, we assessed the ability of reasoning models to directly perform chemistry tasks, without any assistance from external tools. We created a novel benchmark, called ChemIQ, which consists of 796 questions assessing core concepts in organic chemistry, focused on molecular comprehension and chemical reasoning. Unlike previous benchmarks, which primarily use multiple choice formats, our approach requires models to construct short-answer responses, more closely reflecting real-world applications. The reasoning models, exemplified by OpenAI’s o3-mini, correctly answered 28%–59% of questions depending on the reasoning level used, with higher reasoning levels significantly increasing performance on all tasks. These models substantially outperformed the non-reasoning model, GPT-4o, which achieved only 7% accuracy. We found that Large Language Models can now convert SMILES strings to IUPAC names, a task earlier models were unable to perform. Additionally, we show that the latest reasoning models can elucidate structures from 1 H and 13 C NMR data, correctly generating SMILES strings for 74% of molecules containing up to 10 heavy atoms, and in one case solving a structure comprising 21 heavy atoms. For each task, we found evidence that the reasoning process mirrors that of a human chemist. Our results demonstrate that the latest reasoning models have the ability to perform advanced chemical reasoning.

2
Construction of the ChemIQ benchmark

ChemIQ is a novel benchmark developed to assess the chemical intelligence and understanding of LLMs. We designed the questions in ChemIQ to test the understanding of molecular structures and application of chemical reasoning as opposed to assessing general chemical knowledge or superficial pattern recognition.
ChemIQ focuses on three broad competencies: (1) interpreting molecular structures, (2) translating molecular structures to chemical concepts, and (3) reasoning about molecules using chemical theory. Competencies (1) and (2) represent foundational skills necessary for molecular comprehension, while competency (3) assesses more advanced chemical reasoning capabilities.
We algorithmically generated a total of 796 questions across eight distinct categories, which are summarized in Figure

Unless otherwise stated, we used molecules from the ZINC dataset

We represented molecules using Simplified Molecular Input Line Entry System (SMILES)
[

2.1
Interpreting molecular structures

To demonstrate even a basic understanding of molecules, the model must be able to count. For example, counting the number of atoms of each element is needed to determine the molecular formula. LLMs have previously been known to struggle with counting characters in text
[
25
]
, suggesting potential challenges for interpreting SMILES strings. To test this ability, we asked the LLMs to count the number of carbon atoms and the number of rings in a molecule, properties that can be easily inferred from SMILES notation.

A core skill for molecular interpretation is the ability to extract graph-based features from SMILES strings. Certain chemical features can be identified through simple pattern recognition (e.g.
C(=O)NC
indicates an amide group). Consequently, questions asking for the identification of functional groups within a molecule can give a misleading impression of molecular comprehension. To test the general ability to extract graph-based features from SMILES strings, we created a task that requires the LLM to determine the number of bonds on the shortest path between two randomly selected positions in a molecule. This requires a greater understanding of molecular structure than subgroup identification tasks.

Finally, we also constructed an “atom mapping” task to test global understanding of molecular structures. In this question, we assess whether the model can form an internal representation of molecules and recognize graph isomorphism. While a canonical SMILES format exists, a molecule can be represented by multiple SMILES strings. Furthermore, each atom can be assigned a unique index based on its position within a SMILES string. The LLM was given two randomized SMILES strings of the same molecule and was asked to provide the mapping of atoms from one representation to the other. Successfully answering this question requires an understanding of SMILES strings and molecular graphs, signaling the potential to perform more advanced reasoning on these structures.

2.2
Translating molecular structures to chemical concepts

A key objective for LLMs is to bridge the gap between computational representations of molecules and higher-level chemical terminology. Successfully doing so is necessary for any reasoning task that requires applying chemistry theory to molecular graphs, i.e. describing electronic effects, designing molecules, and performing structure elucidation.

The International Union of Pure and Applied Chemistry (IUPAC) provides a standardized naming convention where molecules are described using common chemistry language; the ability to write the IUPAC names of molecules requires an understanding of molecular structures and their chemical features. Converting SMILES strings to IUPAC names has proven extremely challenging for LLMs, with most models achieving near-zero accuracy
[
16
,
26
,
27
,
17
]
.

Previous benchmarks have typically assessed accuracy by comparing generated names to the exact name contained in PubChem
[
28
]
, which itself uses the OpenEye tool “Lexichem”
[
29
]
to determine IUPAC names. While this approach is valid, we believe it is overly strict. Importantly, a single molecule can be identified by multiple valid IUPAC names, not only the one considered as “standard”. While these non-standard names ignore conventions related to group priority, they nonetheless reflect an equivalent understanding of molecular structure. Therefore, we propose a modification of the SMILES to IUPAC task where a name is considered correct if it can be parsed to the intended structure using the Open Parser for Systematic IUPAC nomenclature (OPSIN) tool
[
30
]
.

2.3
Chemical reasoning

For an LLM to be used for novel chemical discovery, it would have to be able to interpret chemical trends in data. We assessed the potential to conduct such analysis by algorithmically constructing a series of structure-activity relationship (SAR) questions. In each case, the LLM is provided data for seven molecules with different combinations of R-groups at three positions of a shared scaffold and is tasked with predicting the value for an unseen molecule. Further details of the scaffold and R-groups can be found in Appendix
B
.
This requires the LLM to be able to understand the differences between molecules, attribute values to these differences, and apply this knowledge to unseen examples.

We further tested chemical proficiency using a series of reaction prediction questions. These questions were constructed from nine common reaction classes, such as the copper-catalyzed click reaction and the Simmons-Smith cyclopropanation reaction. In each case the LLM was prompted to write the product as a SMILES string. While the chosen templates reflect straightforward and unambiguous chemical reactions, correctly answering the reaction prediction questions requires substantial levels of chemical understanding and reasoning.

Last, we assessed the ability of LLMs to interpret multiple sources of chemical evidence through the task of nuclear magnetic resonance (NMR) structure elucidation. While several machine learning models can provide helpful insights for this task, no current method can reliably interpret NMR spectra without expert validation
[
31
]
.
We provided the LLM with simulated
1
H and
13
C NMR data, along with a molecular formula, and then prompted the model to generate the corresponding SMILES string.
We assessed the performance both on molecules from ZINC as well as smaller molecules of up to ten heavy atoms from Huang
et al.

[
32
]
.
This task requires pattern recognition in NMR data, mapping these patterns to molecular features, and subsequently constructing a coherent and complete molecular structure consistent with all sources of information.

3
Results and Discussion

We evaluated the performance of multiple LLMs on our benchmark set of questions, ChemIQ, to assess their ability to understand molecular structures and perform chemical reasoning.
A key aim of our experiments was to assess the impact of “reasoning” on these capabilities. We, therefore, chose to use o3-mini as the primary model for our analysis, as the same base model is available in “low”, “medium”, and “high” reasoning modes. By comparing the same model across three modes we can isolate the improvement gained from additional reasoning. We additionally evaluated GPT
-
4o as a baseline for non-reasoning models. To help understand how the models arrived at their answers, we examined the “reasoning excerpts” generated by o3-mini. OpenAI does not disclose the raw CoT from its models; however, the web interface provides a filtered summary of this reasoning. We use these reasoning excerpts as an indication of the reasoning performed by o3-mini, although we note that reasoning traces are imperfect and may not describe the true method used to generate the final answers
[
33
]
. A summary of each task is provided in Figure
1
, and full prompts along with reasoning excerpts from o3-mini can be found in Table
1
and Appendix

.

3.1
Reasoning unlocks chemical intelligence

The reasoning models substantially outperformed the non-reasoning models across the 796 questions in our benchmark, with the o3-mini reasoning models correctly answering 28%-59% of questions compared to just 7% for the non-reasoning model, GPT-4o. Moreover, increased levels of reasoning enhanced performance across all tasks (Figure
2
). The reasoning models were particularly effective in numerical tasks involving counting and calculation, and showed an ability to interpret graph-based features of molecules. On the SMILES to IUPAC task, o3-mini-high achieved 29% accuracy on molecules sampled from ZINC; to our knowledge, this is the first general-purpose LLM to demonstrate meaningful success on this task. Additionally, this same model correctly solved 34 out of 46 NMR spectra of small molecules.

3.2
o3-mini understands molecular structures

A fundamental requirement for understanding organic chemistry is the ability to interpret molecular structures. In this section, we discuss assessing molecular comprehension using a series of tasks that increase in complexity. As an initial test, we examined the ability of models to count characters in the SMILES string, which is a prerequisite for any other task involving the interpretation of SMILES notation. When tasked with carbon counting, GPT-4o only answered 4% of questions correctly. The reasoning models substantially improved on this, however were still imperfect scoring between 70% and 92%. Performance on the ring counting task was higher, likely because the sampled molecules contained no more than six rings, which increased the chance of correct guesses and reduced overall task difficulty. These results are consistent with previous observations that LLMs struggle to count characters in text
[
35
]
. This may limit the usefulness of SMILES as a chemical representation for current LLMs.

We then examined the ability to understand molecular structures from SMILES strings using more complex questions beyond simple functional groups identification. The reasoning models demonstrated the ability to determine the shortest path between two atoms in a molecule (Figure
3
A), with o3-mini-high correctly answering 89% of questions when molecules were written using canonical SMILES, and successfully reasoning about paths of up to 20 bonds. The non-reasoning model only scored 11%. A challenging question is shown in Table
9
where the shortest path crossed a fused ring system. The reasoning excerpt suggests o3-mini-high constructed a graph representation and performed a graph search to solve this question, indicating the model can parse a SMILES string, build an internal graph representation, and then reason on it.

Similarly, the o3-mini model was able to answer “atom mapping” questions, where the same molecule was written as two different SMILES strings and the model was prompted to map the atoms from one to the other (Figure
3
B). The o3-mini-high model answered 52% of questions correctly and successfully mapped molecules with up to 24 atoms, whereas GPT
-
4o answered none of the questions correctly. As expected, the performance decreased as the number of atoms in the molecule increased, reflecting the greater complexity of atom mapping for larger molecules (Figure
3
B). However, the trend in success rate with increased reasoning suggests the ability to answer this question for larger molecules is not an inherent limitation of reasoning models, and may be improved further by using more reasoning tokens.

An example reasoning excerpt for atom mapping is shown in Table
10
. The excerpt suggests o3-mini-high used multiple layers of abstraction to solve this question, starting from a coarse-grained description of the molecule before focusing on individual atoms and specifically anchoring on distinctive heteroatoms to aid the search. This demonstrates that o3-mini has the capacity to interpret SMILES strings and navigate molecular graphs; however, this ability is not yet consistent or reliable. Furthermore, the low accuracy on structures larger than 20 heavy atoms implies that current models may face challenges in interpreting typical drug-sized molecules.

3.3
Randomized SMILES are more challenging than canonical SMILES

SMILES strings can be written in multiple forms depending on the atom ordering used to traverse the molecular graph
[
36
]
. If a model can reliably parse SMILES strings, the atom numbering should not impact the ability to interpret the molecular graph. We repeated the shortest path, atom mapping, SMILES to IUPAC, and reaction prediction questions using canonical and randomized SMILES, and found o3-mini generally had lower performance when prompted with randomized SMILES (Table
3
).

This effect was most prominent for the shortest path question, where the performance of all o3-mini models dropped by approximately 40% (Figure
3
A). This question, in particular, is made more challenging by considering randomized SMILES. Canonical SMILES strings are always written starting on a dummy atom, meaning the shortest path can often be inferred by the position of the second dummy atom in the string (together with consideration of branching and ring closures). In contrast, in randomized SMILES, the string-based distance between the dummy atoms typically differs significantly from the graph-based distance.

For the atom mapping questions, we explored two ways of generating multiple SMILES strings: fully randomized and semi-canonical, where SMILES were written by starting on a random atom but following canonical rules thereafter. When using semi-canonical SMILES, the performance of o3-mini-high improved to 69%, compared to 52% with fully randomized SMILES (Table
3
). This may be due to entire substructures of the molecule being traversed in the same order, yielding pairs of SMILES strings with subsequences of identical characters, thus allowing mapping of these atoms directly from the SMILES string without considering the molecular graph.

Overall, these results suggest that o3-mini may use heuristics to interpret SMILES strings, as opposed to parsing an entire molecular graph. Although the findings still demonstrate a basic understanding of SMILES notation, they show that o3-mini can not yet reliably parse SMILES strings and may struggle to interpret more complex molecular features that do not follow simple patterns.

3.4
o3-mini can write IUPAC names of molecules

We then sought to test whether LLMs can map SMILES strings to chemical concepts. The most primitive requirement of this is to identify functional groups and describe their relationship to each other, which can be captured by the task of writing IUPAC names for molecules from SMILES strings. All previously tested models have achieved near-zero performance on IUPAC naming tasks
[
16
,
26
,
27
,
17
]
.

We find that reasoning-based LLMs are able to translate SMILES strings to IUPAC names for some molecules.
The LLMs were initially tested using a sample of 100 molecules from the ZINC dataset. On these questions, GPT
-
4o failed to generate any valid solutions, whereas o3-mini-low scored 10%, o3-mini-medium 18%, and o3-mini-high 29%. The performance was similar when using randomized SMILES. There was a substantial overlap of molecules solved from both canonical and randomized SMILES, with o3-mini-high solving 16 molecules in both representations; these molecules are visualized in Figure
8
and Figure
9
.

Closer inspection suggested that the ability to name molecules depended on the substructures present, as opposed to simply the size of the molecule. To assess the main error modes on this question, we algorithmically generated two sets of molecules: one to test the ability to identify and name functional groups, and the other to test the ability to describe their positions within a molecule. The GPT
-
4o model failed to name any molecules contained in these tests, so we do not discuss it further.

Using a set of 40 common functional groups, we randomly selected six groups and attached them at different positions on a benzene scaffold (example molecules are shown in Figure

and further details are provided in Appendix
B
). o3-mini-low successfully produced IUPAC names for around 33% of these molecules, while the medium and high models both achieved
\sim
80% accuracy, demonstrating the models can accurately interpret functional groups from SMILES strings. We then tested the ability of the models to assign locant numbers by using a set of halogen-substituted scaffolds (Figure
7
). All the reasoning models could accurately number benzene and pyridine scaffolds with at least 80% success. They often failed to number the fused ring systems of naphthalene and quinoline, scoring only
\sim
20% on these questions. This could be due to fused ring systems being more challenging to parse from SMILES, and IUPAC locant numbering of fused systems being inherently more complex.

3.5
Reasoning models have the potential to interpret chemical trends

An important aspect of chemistry is the interpretation of chemical trends. We constructed a series of structure-activity relationship (SAR) type questions aiming to test the ability to explain experimental measurements in terms of molecular features. An example question is shown in Figure
5
. Both o3-mini-medium and o3-mini-high achieved perfect performance on these questions (20/20). We also repeated these questions with the addition of noise to simulate more realistic data, and again, o3-mini-high had perfect performance (20/20), and o3-mini-medium only got a single question wrong (19/20).
One common strategy used to solve these questions
was via a system of equations (Table

). These results suggest that the reasoning models are able to interpret mathematical relationships from molecular data, and indicate that they may be able to analyze more complex experimental properties.

3.6
o3-mini can write SMILES strings for simple reactions

The ability to interpret and apply chemical concepts was evaluated through a series of reaction prediction tasks spanning nine reaction classes. For each reaction, the model was prompted to write the product as a SMILES string. To do so, the models must identify the reaction and apply the appropriate transformation. Across the nine reaction classes, GPT
-
4o scored 18%, o3-mini-low 36%, o3-mini-medium 51%, and o3-mini-high 56%. All models demonstrated some degree of chemical understanding, with the reasoning models achieving significantly higher performance.

An example click reaction question is shown in Table
13
. The reasoning excerpt for this question appears to show o3-mini-high using (1) SMILES strings, (2) IUPAC names, (3) structural formulae, (4) atom numbers, and (5) chemical language interchangeably to arrive at the answer. Additionally, this excerpt highlights an instance where the model initially made a mistake by incorrectly writing the IUPAC name of a molecule, then shortly later performed an error check and corrected the issue.

3.7
Structure elucidation can be solved by reasoning models

Finally, the most challenging question we tested the models with was NMR structure elucidation. Here, the models were provided with
1
H and
13

We began by testing the LLMs on molecules containing up to 10 heavy atoms from

The reasoning excerpts for these questions show a resemblance to that of a human chemist. An example small molecule question is shown in Table

It then interprets methylene groups from the proton NMR and explains their de-shielded chemical shift by proximity to an acetamide group. At this point, the model makes a comment that the integration of the proton peaks does not correspond to the number of protons given in the molecular formula, and proposes that the remaining protons must be exchangeable. Towards the end, the model proposes the IUPAC name of the structure, performs a double check, and then provides the correct SMILES string of the molecule.

The NMR elucidation excerpt for the larger ZINC molecule gives even greater detail of chemical reasoning (Table
1
). The model initially identifies general features of the spectra, and then begins to infer their corresponding substructures. The model can be seen comparing

13

As the excerpt continues, the model generates hypotheses of substructures and then rules them out based on consistency with the data, such as by considering chemical shifts, peak counts, multiplicity, and double bond equivalents. Towards the end, the model decides the structure is a phenylalanine derivative, and then eventually provides the correct SMILES string of the molecule. This result demonstrates a clear achievement in NMR elucidation and suggests that reasoning models can now address chemistry problems that previously relied on expert human judgment, marking a paradigm shift in computational chemistry.

Conclusion

Our results show that language models that have been explicitly trained to reason now possess the capability to directly solve advanced chemistry problems without using external tools or requiring prompt engineering. Specifically, across eight distinct tasks ranging from atom counting to NMR elucidation, o3-mini demonstrated the ability to interpret SMILES strings and reason on molecular graphs. For the first time, a general-purpose LLM was able to generate IUPAC names for molecules, with o3-mini-high correctly answering almost 30% of questions. The performance of o3-mini on the chemical reasoning tasks of NMR elucidation and reaction prediction signals a fundamental shift in the capabilities of LLMs. Our results strongly suggest that reasoning models now have the capacity to “think” about the structure of molecules, as opposed to just talking about them superficially. These findings represent a step change in the ability of language models to understand and reason about molecular structures.

Current reasoning models are still far from perfect. The best-performing model, o3-mini-high, only achieved 100% accuracy on ring counting, which is a relatively simple task, and SAR analysis, which primarily involves mathematical reasoning. We expect continued advances in the general capabilities of LLMs to improve performance on domain-specific benchmarks such as ChemIQ.
In our experiments, we observed improved performance for higher levels of reasoning; it is not clear to what extent this trend would continue if current models were allowed to reason for longer.
Furthermore, we expect that domain-specific models tailored for chemical reasoning, as well as LLM-based systems augmented with external tools, will deliver significant performance gains over general-purpose LLMs.

The same methodological advances enabling LLMs to solve complex chemistry problems risk lowering the barrier for producing chemical threats. The possibility that non-experts could leverage these capabilities to produce chemical threats is a serious concern
[
37
]
, and one that has been largely overlooked in recent safety assessments that have prioritized biological risks
[
38
,
39
]
. It is essential that researchers in this field are proactive in addressing the safety and ethical implications of this technology to prevent its misuse.

The emerging capabilities of LLMs point to a new paradigm where LLMs serve as general-purpose chemical reasoning agents, combining formal theory and heuristic insights to solve a broad range of chemistry tasks.
Such frameworks allow the integration of diverse information sources – such as patents, primary literature, and domain knowledge – into a single inference process, enabling context-aware decision-making and overcoming constraints that have historically limited conventional machine learning models.
This could be transformational for data-limited chemical domains where developing task-specific models is currently often infeasible or insufficient.

Appendix A
Chemistry benchmarks for LLMs

Several benchmarks already exist to evaluate the performance of LLMs in chemistry. These benchmarks typically aggregate questions from multiple subfields and predominantly use a multiple choice format. While this approach can assess general chemical knowledge, it is less suitable for evaluating reasoning capabilities as questions can often be answered through elimination strategies rather than explicit chemical reasoning (see Table
15
for an example from ChemBench). Furthermore, combining sub-fields within a single benchmark complicates the interpretation of specific capabilities of the LLM, and none of the existing benchmarks explicitly assess whether an LLM can interpret molecular structures. Below, we provide an overview of several prominent LLM benchmarks that assess topics in chemistry.

ChemBench

[
13
]
is a chemistry-specific benchmark consisting of 2634 questions, 2441 (c. 93%) of which are multiple choice. These cover eight sub-categories: general chemistry (
n=149
), inorganic chemistry (
n=92
), materials science (
n=84
), organic chemistry (
n=429
), physical chemistry (
n=165
), technical chemistry (
n=40
), toxicity and safety (
n=675
), and medicinal chemistry preference (
n=1000
). To the best of our knowledge, the only question type in common with ChemIQ is “SMILES to IUPAC”; however, ChemBench contains only 10 such questions, and all are multiple choice. Recent studies suggest that this benchmark has limited discriminatory power between reasoning and non-reasoning models. For example, the non-reasoning GPT
-
4o model scored 61%, whereas the reasoning o1 model scored 64%
[
13
]
. Additionally, A separate study reported no difference in performance between o1, o3-mini-medium, and o3-mini-high on the ChemBench-mini subset
[
40
]
.

Google-Proof Q&A (GPQA)

[
14
]
is a benchmark of 448 multiple choice questions, manually written by experts in biology, physics, and chemistry with the aim of being “google-proof”. Each question has four options to select from, and is annotated with an estimate of difficulty level. All questions were assessed by multiple validators, and this was used to select a subset of 198 particularly challenging questions, known as “GPQA diamond”. The benchmark contains 214 chemistry questions covering organic chemistry (
n=144
), general chemistry (
n=64
), inorganic chemistry (
n=3

n=2

n=1
).

Humanity’s last exam (HLE)

[
15
]
is intended to be a challenging benchmark covering a broad range of subjects from the humanities and STEM. It contains 2,500 questions, with a mix of multi-modal questions (i.e. the prompt contains an image), multiple choice questions, and short-answer questions. Within the chemistry subset are 165 questions, 65 of which are multi-modal, and 43 are multiple choice.

Measuring Massive Multitask Language Understanding (MMLU)

[
21
]
consists of 15,908 multiple choice questions from 57 different categories in humanities, social sciences, and STEM. These questions include 203 high school-level chemistry questions and 100 college-level chemistry questions. The complexity of these questions varies from knowledge recall to problem solving; however, the difficulty of individual questions is not quantified.

ChemLLMBench

[
16

was an early assessment of the potential of LLMs in chemistry. It consists of 800 questions, with 100 questions coming from each of eight subcategories: name prediction, property prediction, yield prediction, reaction prediction, reagent selection, retrosynthesis, text-based molecule design, and molecule captioning. These were assessed by a combination of binary classification, ranking, and short-answer questions.

B.1
Cheminformatics analysis

All cheminformatics analysis was performed using the RDKit Python library (version 2022.09.5)

B.2
ZINC dataset

The ZINC dataset used in this work refers to the “molprop-250k-v2” dataset accessed using the Polaris API
[

[

B.3
Token counting questions

The number of carbon atoms in each molecule was calculated with
sum(1 for atom in mol.GetAtoms() if atom.GetSymbol() == ’C’)
. Two ZINC molecules were sampled for each unique carbon atom count, resulting
n=50
molecules ranging from three to 27 carbon atoms. The accepted answer for this question was the exact match of the integer.

The number of rings in each molecule was calculated with
mol.GetRingInfo().NumRings()
. Eight ZINC molecules were sampled for each unique ring count, resulting in
n=48
molecules ranging from one ring to six rings. The accepted answer for this question was the exact match of the integer.

B.4
Shortest path questions

Each molecule in the ZINC subset was assigned a dummy atom at two random positions. The shortest path between these two points was calculated using the RDKit function
Chem.rdmolops.GetShortestPath(mol, dummy_index_0, dummy_index_1)
, subtracting one to determine the bond distance. Each molecule was written both as a canonical SMILES and a random SMILES string.
Three molecules were sampled for every path length between three and 20 bonds, resulting in a total set of
n=54
molecules. The accepted answer for this question was the exact match of the integer.

B.5
Atom mapping questions

The atom mapping question only has a unique solution for molecules with no symmetric features, i.e. there is a single mapping of the molecule to itself. Molecules were identified as valid for this question if the substructure match of the maximum common substructure with itself resulted in a single match. By default, RDKit numbers atoms sequentially as they appear in the SMILES string; explicit hydrogens do not get numbered. The solution to this question was therefore determined by the MCS mapping of the two RDKit molecules. The pseudo-code snippet in Listing

demonstrates this procedure.

Using the subset of valid atom-mapping molecules, a maximum of five molecules were selected for each number of heavy atoms up to a maximum size of 25 heavy atoms. This resulted in
n=92

Thus, two semi-canonical SMILES strings are generally more similar than two random SMILES strings representing the same molecule.
The accepted answer in this question required all tuples to be correct, however they could be given in any order in the list.

B.7
SAR question generation

The benzofuran core was chosen since each R group position can be unambiguously identified. Three random positions on the core were chosen as R group vectors. R groups were selected from the set of fluorine, bromine, and chlorine. Each R group at each vector was assigned a random integer value in the range (50,250). Molecules were generated by sampling an R group at each position, and the score of the molecule was set as the sum of these R groups.

Questions were generated by constructing a system of equations and selecting a minimal set of R groups that yielded a full-rank matrix, guaranteeing that each variable (R group score) could be uniquely solved. The molecules selected in this step were provided in the prompt as context. An unknown molecule was randomly selected from the set of remaining molecules.

A variation of this question was generated where noise was added to the total score of each molecule. Noise was sampled from a Gaussian distribution with mean zero, variance
2
. Considering the propagation of errors, the total variance in the predicted score for the unknown molecule is given by

\operatorname{Var}(\hat{y})=\sigma^{2}\left(1+x^{T}\,(A^{T}A)^{-1}x\right),

where
\hat{y}
is the predicted score of the unknown molecule and
x
is a vector indicating the presence or absence of each R group at the corresponding positions in the unknown molecule. The acceptable answer range was then defined by the 95% confidence interval in order to account for noise in parameter estimation:

\hat{y}\pm 1.96\sqrt{\sigma^{2}\left(1+x^{T}\,(A^{T}A)^{-1}x\right)}.

B.8
Product of Reaction

Nine undergraduate-level reactions were selected such that the product could be inferred from the reactants without information of the reaction conditions: Sn2, amide coupling, lithium grignard (1,2 addition at carbonyl), Michael addition (1,4 addition at
\alpha
,
\beta
-unsaturated carbonyl), Simmons-Smith (cyclopropanation), Wittig, Suzuki-Miyaura, Mizoroki-Heck, copper catalyzed click reaction.

Each reaction was written as a reaction-template-like set of SMILES strings, with each reactant and product written with dummy atom attachment points indicating the position of R groups throughout the reaction. The set of R groups was selected such that they were unlikely to make the intended reaction in the question ambiguous. For each reaction template, R groups were randomly selected (without replacement) and attached to the template. Each reaction template was sampled five times with different R groups, yielding
n=45
total synthetic reaction questions.
The model was provided with the reactants and prompted to write the product of reaction as a SMILES string.
Answers were assessed by reading the SMILES into RDKit, removing stereochemistry, canonicalizing the product, and then comparing this to the canonical SMILES of the expected product. Answers were accepted if both canonical SMILES strings matched.

B.9
NMR questions

The set of molecules chosen for the “small molecule” NMR elucidation question were extracted from the supplementary information of Huang
et al.

[
32
]
. Their work used a neural network architecture to convert
1
H and
13
C NMR spectra to molecular structures.
n=23
molecules were selected where the model did not rank the correct molecule as the top structure, and a second set of
n=23
molecules were selected where the model was successful. This resulted in a set of
n=46
molecules where the baseline Top-1 performance of the reference model was 50%.

The ZINC dataset was split into m=10 bins by molecular weight, and three molecules were selected from each bin, resulting in a set of
n=30
molecules.

All
1
H and
13
C NMR spectra were simulated using web tools from the nmrdb website www.nmrdb.org/
[

]
. The outputted NMR text description (ie chemical shifts, peak integrals, and coupling constants) was used to construct the prompt. The LLM was prompted to generate the SMILES string of the molecule from this NMR data, along with the molecular formula. The answer was accepted as correct if the canonicalized SMILES string matched the expected answer.

B.10
Statistical tests

Models were compared to each other using the one-tailed McNemar test. The hypothesis was that models would follow the trend GPT
-
4o < o3-mini-low < o3-mini-medium < o3-mini-high. Only adjacent models in this series were tested. Horizontal staples on bar plots indicate the significance level for this test, with p values indicated with:
{}^{*}p<0.05,\quad^{**}p<0.01,\quad^{***}p<0.001
. Adjacent vertical bars without a staple do not have a statistically significant difference in performance.

The 95% confidence interval of model success rate was calculated by the binomial proportion where
\hat{p}
is the success rate, and
n
is the number of samples.

\hat{p}\pm 1.96\times\sqrt{\frac{\hat{p}(1-\hat{p})}{n}}

The use of short answer questions generally means that a random model would be unable to guess the correct answer, or would achieve poor performance. For questions with integer solutions, the performance of a random model can be estimated by the ranges sampled to generate the questions. Considering the sampling ranges, the approximate baseline for each question is: carbon counting 1/25, ring counting 1/6, shortest path 1/18. The SAR question does not have an obvious baseline, however would be close to 0%. The SMILES to IUPAC, product of reaction, and NMR questions have a baseline of 0%. The atom mapping question has a random baseline of 1/N! (where N is the number of atoms) meaning answers to this question are unlikely to be randomly guessed.

B.11
ChatGPT

All questions were run using the OpenAI batch API. GPT
-
4o was run using the 2024-11-20 snapshot. o3-mini was run using the 2025-01-31 snapshot, and by setting the reasoning effort parameter as “low”, “medium”, or “high”. Prompts were submitted without “function calling” and without the “code interpreter” meaning the model could not use external tools to help answer questions. The raw chain-of-thought reasoning trace is not shared by OpenAI, however the ChatGPT web interface provides a summary of the reasoning process. The reasoning excerpts listed in this paper were constructed by manually prompting the web interface and copying the reasoning summaries.

The prompting strategy used in this benchmark required the model generate only the exact answer in the output. However, GPT-4o is capable of generating a brief chain of thought, which can sometimes enhance accuracy. To test this, we re-ran all questions using a modified prompt that instructed the model to enclose its final answer within
<answer></answer>
tags. This did not result in a meaningful improvement in performance. These results are listed in Appendix
C
as “GPT-4o-tags”.
