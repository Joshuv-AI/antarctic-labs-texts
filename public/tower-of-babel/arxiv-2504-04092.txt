Abstract

The polarization process allows us to associate two other algebras, and this correspondence is one-one, one commutative, the other anti-commutative. Assume that μ \mu satisfies a quadratic identity ∑ σ ∈ Σ 3 a σ ​ μ ​ ( μ ⁡ ( x σ ⁡ ( i ) , x σ ⁡ ( j ) ) , x σ ⁡ ( k ) − a σ ​ μ ​ ( x σ ⁡ ( i ) , μ ⁡ ( x σ ⁡ ( j ) , x σ ⁡ ( k ) ) = 0 CLOSE CLOSE . \sum_{\sigma\in\Sigma_{3}}a_{\sigma}\mu(\mu(x_{\sigma(i)},x_{\sigma(j)}),x_{\sigma(k)}-a_{\sigma}\mu(x_{\sigma(i)},\mu(x_{\sigma(j)},x_{\sigma(k)})=0. Introduction

The notion of polarization is naturally introduced in the elementary study of functions of a real variable. To such a function we uniquely associate a pair of functions formed by an even function and an odd function whose sum gives the initial function.

We easily extend this concept to the set of bilinear applications on a vector space with values in itself (or in an another space).
If
\varphi
is such an application, the polarization process associates with it the pair
\varphi_{a},\varphi_{c}
defined by the identities

\varphi_{a}(X,Y)=\varphi(X,Y)-\varphi(Y,X),\ \ \varphi_{c}(X,Y)=\varphi(X,Y)+\varphi(Y,X).

The most classic example is to consider on the vector space
A
an algebra structure defined by a multiplication
\mu
. If we assume that
A
is an associative algebra, thet is
\mu
satisfies the relation

\mu(X,\mu(Y,Z))=\mu(\mu(X,Y),Z)

then
\mu_{c}
is a Lie bracket, that is satisfies the Jacobi identity

\mu(X,\mu(Y,Z))+\mu(Y,\mu(Z,X))+\mu(Z,\mu(X,Y))=0.

This work is motivated by the following remark. Assume that
\varphi
is an algebra law on
A
(multiplication defining the structure of the algebra
A
) that is a nonassociative bilinear map satisfying an identity of the type

(1)

\begin{array}[]{ll}a_{1}(x_{1}x_{2})x_{3}+a_{2}(x_{2}x_{1})x_{3}+a_{3}(x_{3}x_{2})x_{1}+a_{4}(x_{1}x_{3})x_{2}+a_{5}(x_{2}x_{3})x_{1}+a_{6}(x_{3}x_{1})x_{2}&\\
+b_{1}x_{1}(x_{2}x_{3})+b_{2}x_{2}(x_{1}x_{3})+b_{3}x_{3}(x_{2}x_{1})+b_{4}x_{1}(x_{3}x_{2})+b_{5}x_{2}(x_{3}x_{1})+b_{6}x_{3}(x_{1}x_{2})&=0.\end{array}

where we write
xy

\varphi(x,y)
Suppose that this identity reduces to an identity relative to
\varphi_{a}
. For example

\begin{array}[]{ll}(x_{1}x_{2})x_{3}-(x_{2}x_{1})x_{3}-(x_{3}x_{2})x_{1}-(x_{1}x_{3})x_{2}+(x_{2}x_{3})x_{1}+(x_{3}x_{1})x_{2}&\\
-x_{1}(x_{2}x_{3})+x_{2}(x_{1}x_{3})+x_{3}(x_{2}x_{1})+x_{1}(x_{3}x_{2})+x_{2}(x_{3}x_{1})+x_{3}(x_{1}x_{2})&=0.\end{array}

is equivalent to write the Jacobi identity for

(We say in this case that

(2)

\varphi_{c}(x_{1},\varphi_{c}(x_{2},x_{3}))=\varphi_{c}(x_{2},\varphi_{c}(x_{3},x_{1}))=\varphi_{c}(x_{3},\varphi_{c}(x_{1},x_{2}))

In this case we shall say that the algebra

\varphi_{c}(x_{1},\varphi_{c}(x_{2},x_{3})+\varphi_{c}(\varphi_{c}(x_{1},x_{2}),x_{3})=\varphi_{c}(x_{1},\varphi_{c}(x_{2},x_{3})-\varphi_{c}(x_{3},\varphi_{c}(x_{1},x_{2}))=0.

The goal is to study these algebras that we will call Acaa-algebras.

1.2.
A characterization of the Acaa-algebras

Assume that

3.
Representations of Acaa-algebras

3.1.
The operator
\text{\rm ad}X

Let
A
be a Acaa-algebra. Let
\text{\rm ad}X
be the linear map on
A
defined by
\text{\rm ad}X(Y)=[X,Y].
Since
A
is an Acaa-algebra, , for any
X,Y,Z\in A
, we have

[X,[Y,Z]]=[Y,[[Z,X]]=[Z,[X,Y]]

that is

[[X,Y],Z]=-[X,[Y,Z]]=[Y,[X,Z]].

This is equivalent to

\text{\rm ad}[X,Y]=-\text{\rm ad}X\circ\text{\rm ad}Y=\text{\rm ad}Y\circ\text{\rm ad}X.

We deduce

Lemma 7
.

The operators
\text{\rm ad}X
on
A
satisfy

(1)

\text{\rm ad}X\circ\text{\rm ad}Y+\text{\rm ad}Y\circ\text{\rm ad}X=0

(2)

2\text{\rm ad}[X,Y]=-\text{\rm ad}X\circ\text{\rm ad}Y+\text{\rm ad}Y\circ\text{\rm ad}X=-[\text{\rm ad}X,\text{\rm ad}Y]_{gl(n)}

where
[,]_{gl(n)}
denotes the classical bracket on the space of linear operators.

Applications
The linear map

\text{\rm ad}:A\rightarrow End(A)

is a weighted linear representation of
A
. It satisfies

\text{\rm ad}[X,Y]=-\frac{1}{2}[\text{\rm ad}X,\text{\rm ad}Y].

Since
A
is also characterized by the relation

[X,[X,Y]]=0

then
(\text{\rm ad}X)^{2}=0
for all
X\in A.
If we consider
ad
as a matricial representation of
A
, the matrices which represent the elements of
A
are square null matrices.

Along the same lines, we have

\text{\rm ad}X[Y,Z]=-[Y,\text{\rm ad}X(Z)]=-[\text{\rm ad}X(Y),Z].

So,

2\text{\rm ad}(X)[Y,Z]=-[Y,\text{\rm ad}X(Z)]-[\text{\rm ad}X(Y),Z].

In
[
3
]
, we have introduced the notion of anti-derivation : Let
A
be an algebra. A linear map

is an anti-derivation if this map satisfies

f(xy)=-xf(y)-f(x)y=0

for any

As for the representations, we are here led to put coefficients on such a relation :

Definition 8
.

Let
B
be an algebra. A linear map

is an weighted anti-derivation if there exists

such that

kf(xy)=-xf(y)-f(x)y=0

for any
x,y\in A.

In these conditions

Lemma 9
.

Let
A
be an Acaa algebra. For any

, the linear map

is a weighted anti-derivation of weight
2
.

Remark.
In
[
3

3.2.
Representations of Acaa algebras

Since an Acaa algebra is a nonassociative algebra, the notion of representation must be taken in the framework of the associative representations of non-associative algebras introduced in
[
4
]

\text{\rm ad}[X,Y]=-\text{\rm ad}X\circ\text{\rm ad}Y=\text{\rm ad}Y\circ\text{\rm ad}X.

So

is a linear mapping which gives a representation of

Definition 10

Let

be an Acaa algebra and let

be the space of linear endomorphisms of the vector space

\rho:A\rightarrow End(A)

which satisfies the identity

\rho[X,Y]=-\rho(X)\circ\rho(Y)=\rho(Y)\circ\rho(X)

for any

.

The representation
\rho
is said to be faithful if it is injective. Of course, the linear map

is an associative representation of

which is not faithful.

Let us note that, if

is a representation of

\rho(X)^{2}=0.
Then, identifying

with the space of square matrices of order

is considered as a matrix
\widetilde{X}
satisfying
\widetilde{X}^{2}=0.
