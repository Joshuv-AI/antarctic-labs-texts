APECS: Adaptive Personalized Control System Architecture
Marius F. R. Juston, Alex Gisi, William R. Norris, Dustin Nottage, Ahmet Soylemezoglu

Abstract
This paper presents the Adaptive Personalized Control System (APECS) architecture, a novel framework for human-in-the-loop control. An architecture is developed which defines appropriate constraints for the system objectives. A method for enacting Lipschitz and sector bounds on the resulting controller is derived to ensure desirable control properties. An analysis of worst-case loss functions and the optimal loss function weighting is made to implement an effective training scheme. Finally, simulations are carried out to demonstrate the effectiveness of the proposed architecture. This architecture resulted in a 4.5% performance increase compared to the human operator and 9% to an unconstrained feedforward neural network trained in the same way.

In the present work, a similar structure is used to implement a general VMS (a multiple-input, multiple-output mapping). Accordingly, we address the offline open-loop optimization of an arbitrary control system for improved operator performance by proposing the Adaptive Personalized Control System (APECS) architecture, training procedure, and application.

Informally, the objective of APECS is to modulate operator input in order to improve performance in tracking tasks without a priori knowledge of the plant. To maintain operator understanding of the system, the modulation should not be unexpected, for example, it should not change the control sign or exhibit large variations from a small input.

A function

\lVert f(x)-f(y)\rVert_{2}\leq L\lVert x-y\rVert_{2}

is the smallest such

III
Problem Formulation

A human operates an electromechanical system
\dot{y}=f(y,u)
to track a reference signal
\bar{y}
. The system control input is assumed

u=\hat{x}(x,e,\mathcal{E}),

(1)

where
x\in D=[-1,1]^{n_{x}}
is the human input,
e=y-\bar{y}
, and
\mathcal{E}\in\mathbb{R}^{n_{\mathcal{E}}}
are environment parameters observed through sensors.

The problem is to determine the mapping
\hat{x}(x,e,\mathcal{E})
between the human command and the system input which at each time satisfies:

R1)

\hat{x}\in[-1,1]^{n_{x}}

R2)

x=0\iff\hat{x}=0

R3)

\text{sign}(x)=\text{sign}(\hat{x})

R4)

\lVert\hat{x}(x_{1},\cdot,\cdot)-\hat{x}(x_{2},\cdot,\cdot)\rVert_{2}\leq L\lVert x_{1}-x_{2}\rVert_{2},\ \forall x_{1},x_{2}\in\mathcal{D}

R5)

optimal with respect to a task running cost
\mathcal{L}=J(x,\hat{x},\bar{x})

Lipschitz Constraint

A desired property for the control signal is to enforce a Lipschitz bound with respect to the human input. The Lipschitz property on a network can help with its robustness to noise
[
26
]
and provides uniqueness conditions on the generated controller output
[

]

The implementation of a neural network to be L-Lipschitz has been accomplished with various methods
[

. In
[
37
]
, the authors gave a network architecture that unifies the approaches for generating Lipchitz neural networks.

Accordingly, we assume the neural network
g_{\theta}(\cdot)
has been implemented as L-Lipschitz. However, due to the nonlinearity of
\hat{x}(\cdot)=s(\cdot)
, the Lipschitz constant of the resulting controller does not proportionally reflect the Lipschitz constant of the neural network. We now derive bounds on the relationship between them. To do so we must specify
s(\cdot),p(\cdot)
which satisfy R1-R3. Let

\displaystyle s(x)

\displaystyle=\max(-1,\min(1,x))\hskip 5.69046pt\text{(clip)},

(3)

\displaystyle p(x)

\displaystyle=\ln(1 + e^x))\hskip 5.69046pt\text{(softplus)}.

(4)

The softplus function is described in
[
39
]
. For the positive definitive function
p(\cdot)
we also enforce the constraint that it is strictly monotonically increasing and it’s first derivative is also monotically increasing. As such if
x<y
such that
p(x)<p(y)
and
0\leq\frac{d}{dx}p(x)<\frac{d}{dy}p(y)
then this will be a valid positive function
p(\cdot)
.

V-A

Lipschitz bounding

The neural network satisfies

g_{\theta}(z)\leq\hat{g}_{\theta}(z):=L_{\theta}\absolutevalue{x}+b_{\theta}

where
L_{\theta}
is the (known) Lipschitz constant of the neural network and
b_{\theta}=g_{\theta}(0)
is the bias. For convenience, let
z=\{x,\mathcal{E},e\}
. The Lipschitz constant with respect to the human input is the maximum value of the partial derivative, with
\absolutevalue{x}\leq c
and the maximum gradient
L_{\theta}
satisfies
-L_{\theta}\leq\norm{g'(z)}\leq L_{\theta}
.

\displaystyle\hat{x}(z)

\displaystyle=s(p(g_{\theta}(z))\otimes x)

\displaystyle\frac{\partial\hat{x}(z)}{\partial x}=

\displaystyle\begin{cases}p^{\prime}(g_{\theta}(z))g^{\prime}_{\theta}(z)\otimes x+p(g_{\theta}(z))&\absolutevalue{p(g_\theta(z)) \otimes x}<1\\
0&\text{Otherwise}\end{cases}

\displaystyle\leq

\displaystyle p^{\prime}(L_{\theta}\absolutevalue{x}+b_{\theta})L_{\theta}\otimes\absolutevalue{x}+p(L_{\theta}\absolutevalue{x}+b_{\theta})

\displaystyle\leq

\displaystyle p^{\prime}(L_{\theta}c+b_{\theta})L_{\theta}c+p(L_{\theta}c+b_{\theta})

As such the Lipschitz constant of the transformed network is thus,
L_{p}=p^{\prime}(L_{\theta}c+b_{\theta})L_{\theta}c+p(L_{\theta}c+b_{\theta})
. The transformed network can thus be scaled in the following way,

\displaystyle y(z)

\displaystyle=s\left(\frac{1}{L_{p}}p(g_{\theta}(z))x\right).

resulting in a 1-Lipschitz system.
To transform the function
2
into an
L_{t}
-Lipschitz function, a trainable scaling factor,
L_{t}>0
, can be utilized to train the network. To ensure the positive definiteness of the scaling factor, we can reparametrized the parameter
L_{t}
as
L_{t}=e^{\alpha}
:

\displaystyle y(z)

\displaystyle=s\left(\frac{e^{\alpha}}{L_{p}}p(g_{\theta}(z))x\right).

VI
Training

In this section, we present a training scheme for the network derived in section V. The objective is to ensure that the resulting system respects the inputs from the human operator,
y_{h}
, to reflect the personalized style while also integrating the expert operator’s reference signals
y_{e}
. To facilitate this, a variable loss function is constructed.

Recall
\text{dim}(x)=n_{x}
. Let the the dataset be a collection of
N
points
\mathcal{D}=\{z_{i}\ |\ i\in\{1,\cdots,N\}\}
. It is assumed that as
N\to\infty
, the data points are sampled uniformly and uniquely along the whole dataset dimension.

Let the losses corresponding to control signal difference from the human and expert operators be

\displaystyle\mathcal{L}_{h}

\displaystyle=\frac{1}{Nn_{x}}\sum_{\{z\}\in\mathcal{D}}\norm{\hat{x}(z) - x}_{2}^{2},

\displaystyle\mathcal{L}_{e}

\displaystyle=\frac{1}{Nn_{x}}\sum_{\{z\}\in\mathcal{D}}\norm{\hat{x}(z) - \bar{x}}_{2}^{2},

respectively. This is the generic MSE loss function implemented in e.g. PyTorch
[
40
]
. Then, the combined loss function

\mathcal{L}=\gamma\mathcal{L}_{h}+(1-\gamma)\mathcal{L}_{e},

allows us to dynamically tune
\gamma\in[0,1]
to determine the relative importance of mimicking the human or expert operator.

Given that its inputs and outputs are constrained to be
[-1,1]
, we can define the system’s maximum error.

VI-A

Maximum expert operator loss

We first examine the maximum error function of the expert operator
\mathcal{L}_{e}
. We assume the worst-case scenario where

\bar{x}=-\alpha\text{sign}(x),\hskip 5.69046pt\alpha\in[0,1].

The parameter
\alpha
can be set as an appropriate lower bound for the output of the expert controller. By the construction of
\hat{x}
from sections
IV
and
V
, we assume
y(z)
is
L_{t}
-Lipchitz, centered at
0
, and is thus bounded by
\absolutevalue{y(z)}\leq L_{t}x
.

Note the case where
L_{t}\leq 1
is distinct from
L_{t}>1
, because in the latter case, we can take
y(x)=1
for
x\geq 1/L_{t}
due to the output of
y(\cdot)
being restricted to
[-1,1]
. For the unsaturated case where
L_{t}\leq 1
:

\displaystyle\mathcal{L}_{e}

\displaystyle=\frac{1}{Nn}\sum_{\{z\}\in\mathcal{D}}\norm{y(z) - y_e}_{2}^{2}

\displaystyle\leq\frac{1}{Nn}\sum_{\{z\}\in\mathcal{D}}\norm{y(z) - (- \alpha\text{sign}(x))}_{2}^{2}

\displaystyle\leq\frac{1}{Nn}\sum_{\{x,\mathcal{E},e\}\in\mathcal{D}}\norm{L_t x + \alpha\text{sign}(x)}^{2}_{2}.

Taking limits,

\displaystyle\lim_{N\to\infty}\mathcal{L}_{e}

\displaystyle=\lim_{N\to\infty}\frac{1}{Nn}\sum_{\{x,\mathcal{E},e\}\in\mathcal{D}}\norm{L_t x + \alpha\text{sign}(x)}_{2}^{2}

\displaystyle=\int_{0}^{1}\left(L_{t}^{2}x^{2}+2L_{t}\alpha x+\alpha^{2}\right)dx

\displaystyle=\alpha^{2}+\alpha L_{t}+\frac{L_{t}^{2}}{3}.

For the saturated case where
L_{t}>1
, we use the fact that the function
y(z)
is clamped between
[0,1]
. Thus for
\frac{1}{L_{t}}\leq x\leq 1
,
\absolutevalue{y(z)}=1
. Then

\displaystyle\mathcal{L}_{e}

\displaystyle=\frac{1}{Nn}\sum_{\{z\}\in\mathcal{D}}\norm{\max(-1, \min(1, y(z))) - y_e}_{2}^{2}

It follows

\displaystyle\lim_{N\to\infty}\mathcal{L}_{e}

\displaystyle=\lim_{N\to\infty}\frac{1}{Nn}\sum_{\{x,\mathcal{E},e\}\in\mathcal{D}}\|\max(-1,\min(1,L_{t}x))

\displaystyle\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad+\alpha\text{sign}(x)\|_{2}^{2}

\displaystyle=\int_{0}^{\frac{1}{L_{t}}}\left(L_{t}^{2}x^{2}+2L_{t}\alpha x+\alpha^{2}\right)dx+\int_{\frac{1}{L_{t}}}^{1}(1+\alpha)^{2}dx

\displaystyle=\frac{3\alpha(\alpha+1)+1}{3L_{t}}+(\alpha+1)^{2}\left(1-\frac{1}{L_{t}}\right)

\displaystyle=(\alpha+1)^{2}-\frac{\alpha+\frac{2}{3}}{L_{t}}.

As such, the worst-case expert loss function becomes:

\displaystyle\hat{\mathcal{L}}_{e}

\displaystyle=\begin{cases}\alpha^{2}+\alpha L+\frac{L^{2}}{3},&0\leq L\leq 1\\
(\alpha+1)^{2}-\frac{\alpha+\frac{2}{3}}{L_{t}},&L\geq 1\end{cases}.

(5)

This loss error will be loose; a tighter bound could be achieved by assuming a Lipschitz constraint on the expert operator. However, this increases the number of cases that would need to be computed and, as such, was not derived. Future work could derive the tighter bound.

VI-B

Maximum human operator loss

The maximum human error for the system would be if the output of the neural network
g(z)
is a constant function returning
-\infty
or
\infty
, returning
y(z)=1
and
y(z)=0
respectively. Either of these scenarios would function as the worst-case output since the outputs are symmetric around
y(z)=x
.

Case
L_{t}\leq 1
:

\displaystyle\mathcal{L}_{h}

\displaystyle=\frac{1}{Nn}\sum_{\{z\}\in\mathcal{D}}\norm{y(z) - y_h}_{2}^{2}

\displaystyle\leq\frac{1}{Nn}\sum_{\{x,\mathcal{E},e\}\in\mathcal{D}}\norm{L_t x - x}_{2}^{2}.

Taking limits,

\displaystyle\lim_{N\to\infty}\mathcal{L}_{h}

\displaystyle=\lim_{N\to\infty}\frac{1}{Nn}\sum_{\{z\}\in\mathcal{D}}\norm{(L_t - 1) x}_{2}^{2}

\displaystyle=\int_{0}^{1}(L_{t}-1)^{2}\norm{x}_{2}^{2}dx

\displaystyle=\frac{(L_{t}-1)^{2}}{3}.

Case
L_{t}>1
:

\displaystyle\mathcal{L}_{h}

\displaystyle=\frac{1}{Nn}\sum_{\{z\}\in\mathcal{D}}\norm{\max(-1, \min(1,y(z))) - y_h}_{2}^{2}

\displaystyle\leq\frac{1}{Nn}\sum_{\{x,\mathcal{E},e\}\in\mathcal{D}}\norm{\max(-1, \min(1,L_t x)) - x}_{2}^{2}.

Taking the limit of,

\displaystyle\lim_{N\to\infty}\mathcal{L}_{h}

\displaystyle=\lim_{N\to\infty}\frac{1}{Nn}\sum_{\{x,\mathcal{E},e\}\in\mathcal{D}}\norm{\max(-1, \min(1,L_t x)) - x}_{2}^{2}

\displaystyle=\int_{0}^{\frac{1}{L_{t}}}(L_{t}-1)^{2}x^{2}dx+\int_{\frac{1}{L_{t}}}^{1}(1-x)^{2}dx

\displaystyle=\frac{(L_{t}-1)^{2}}{3L_{t}^{2}}.

Where, as expected the error when
\lim_{L_{t}\to 0}\frac{(L_{t}-1)^{2}}{3}=\lim_{L_{t}\to\infty}\frac{(L_{t}-1)^{2}}{3L_{t}^{2}}=\frac{1}{3}
.

As such, the constrained human loss function becomes:

\hat{\mathcal{L}}_{h}=\begin{cases}\frac{(L_{t}-1)^{2}}{3L_{t}^{2}}&0\leq L\leq 1\\
\frac{(L_{t}-1)^{2}}{3},&L\geq 1\end{cases}.

(6)

VI-C

Equal weighting

We can use the bounds derived from previous sections to weigh the linear combination of the losses. The weight factor
\gamma
ensures the system does not tend too heavily to a single objective and tries to maintain characteristics that fit both operators. Accordingly, we compute the
\gamma
in eq.
VI
which provides equal loss weights. From equations
5
and
6
, we see the loss magnitudes obtain a maximum as
\lim_{L_{t}\to\infty}
, which become
(\alpha+1)^{2}
and
\frac{1}{3}
respectively. To obtain equal weight scaling, we solve

\gamma^{*}\frac{1}{3}=(1-\gamma^{*})(\alpha+1)^{2},

obtaining

\gamma^{*}=\frac{3(\alpha+1)^{2}}{3\alpha(\alpha+2)+4}.

(7)

An initial guess of the optimal Lipschitz constant can be estimated by minimizing the total loss function
\mathcal{L}
with respect to the
L_{t}
-Lipchitz constant.
Accordingly, we compute

\displaystyle\frac{\partial\mathcal{L}}{\partial L_{t}}

\displaystyle=\begin{cases}-\alpha\gamma+\alpha-\frac{2\gamma}{3}+\frac{2L_{t}}{3},&0<L_{t}<1\\
-\frac{1}{3}(3\alpha+2)(\gamma-1),&L_{t}=1\\
\frac{(2-3\alpha(\gamma-1))L_{t}-2\gamma}{3L_{t}^{3}},&L_{t}>1\end{cases},

from which we can see that the minimum can be computed as
L_{t}=\frac{3}{2}\alpha(\gamma-1)+\gamma
as long as the following condition holds:

\displaystyle\left(\alpha<\frac{2\gamma}{3-3\gamma}\land 0<\gamma\leq\frac{3}{5}\right)\lor\left(\gamma>\frac{3}{5}\right).

(8)

If the conditions above are unmet, the
L_{t}
should be set close to zero for the initial
L_{t}
. This is because the computed
L_{t}
would otherwise result in a negative number. It should be mentioned that because the case for
\mathcal{L}_{e}
assumes the worst case, where the optimal controller performs the exact opposite of the expected output, these initializations are very loose. It is recommended never to initialize
L_{t}=0
as this would cause gradient and training issues. Instead, an initial value of
L_{t}=\frac{1}{2}
is recommended when starting the system.

VIII
Conclusion

This paper developed a novel control architecture known as the Adaptive Personalized Control System (APECS). The controller was constructed to satisfy a set of intuitively desirable properties (R1-R5). The result is a neural network based architecture which improves the control input from the human operator using an optimal controller after use of a derived training scheme. A 4.5% performance increase compared to the initial generic fuzzy logic human operator was obtained, as well as a 9.4% performance increase compared to using a standard neural network training to minimize the losses between mimicking the human and the expert operator.

Future work will demonstrate how this architecture can be trained online to demonstrate online adaptive capabilities. In addition, during development it was noticed that the SDP 1-Lipschitz networks were sensitive to the number of layers that it had available to it, which sometimes resulted in the network instability.
