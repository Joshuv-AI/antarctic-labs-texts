When is a Bottom-Up Deterministic Tree Translation Top-Down Deterministic?
Sebastian Maneth, Helmut Seidl

Abstract
We consider two natural subclasses of deterministic top-down tree-to-tree transducers, namely, linear and uniform-copying transducers. For both classes we show that it is decidable whether the translation of a transducer with look-ahead can be realized by a transducer from the same class without look-ahead. The transducers constructed in this way, may still make use of inspection , i.e., have an additional tree automaton restricting the domain. We provide a second procedure which decides whether inspection can be removed. The procedure relies on a precise abstract interpretation of inspection requirements and a dedicated earliest normal form for linear as well as uniform-copying transducers which can be constructed in polynomial time. As a consequence, equivalence of these transducers can be decided in polynomial time. Applying these results to deterministic bottom-up tree transducers, we obtain that it is decidable whether or not their translations can be realized by deterministic linear or uniform-copying top-down transducers without look-ahead (but with inspection) — or without both look-ahead and inspection. Look-ahead removal has been known to be a notoriously difficult problem. To the best of our knowledge, this paper is the first to present look-ahead removal for natural and known subclasses of top-down tree transducers.

Introduction

Even though top-down and bottom-up tree transducers are well-studied formalisms
that were introduced already in the 1970’s (by Rounds
[
1
]
and
Thatcher
[
2
]
independently,
and by Thatcher
[
3
]
, respectively), some fundamental questions
have remained open until today.
A prominent example of such a question is:
can we decide for a given deterministic bottom-up tree transducer
whether or not its translation can be realized by a top-down tree transducer?
We answer this question affirmatively, however, for a slight restriction on the
considered top-down tree transducers: they must be
uniform-copying
.
This means that all copies of the same input subtree must be processed by the same state.

It is well-known that for every deterministic bottom-up tree transducer an equivalent
deterministic top-down tree transducer can be constructed which, however, makes use of regular
look-ahead
[
4
]
.
That transducer indeed is
uniform-copying
.
The question which we ask therefore is: can regular look-ahead in
uniform-copying
transducers
be eliminated?
We prove that this is indeed the case: given a uniform-copying (or linear) top-down tree transducer
with look-ahead it is decidable whether or not it can be realized by a uniform-copying (or linear)
top-down tree transducer
without
look-ahead.
Note that is is well-known that equivalence is decidable for all of these
deterministic tree transducers
[
5
]
.
Hence, an equivalent transducer in the desired class can be found (by brute force),
once it is known to exist. We present more direct constructions for each case when we decide one
class of transducers within a larger class (but we refrain from detailed complexity analysis
of the running time of our constructions).

In order to answer the question,
we provide a canonical earliest normal form for
uniform-copying
(as well as for linear)
deterministic top-down transducers with and without look-ahead.
We prove that if an earliest such transducer
A
can be realized by such
a transducer
A^{\prime}

without
look-ahead (but with input inspection), then

A
must be
synchronizing,
twinning, and
erasing.
To understand the
synchronizing
property, consider
a transducer with look-ahead that translates an input tree of the form

a(b(f(t_{1},t_{2})))\text{ into the tree }\langle a,b\rangle(f(t_{1},t_{2})),

where

\langle a,b\rangle
is a binary output symbol.
Clearly this translation
can
be done by a transducer without look-ahead:
it outputs nothing at the root node, keeps the node label in its state,
and at its child outputs the corresponding binary symbol.
Now consider that

a(b(f(g(t_{1},t_{2}),t_{3})))\text{ is translated to }\langle a,b,g\rangle(f(g(t_{1},t_{2}),t_{3})),

where an
a
could be a
b
(or vice versa) and an
f
could be a
g
(or vice versa).
Such a translation can
not
be realized by a transducer without look-ahead.
The information about the
g
-node cannot be “synchronized” at the
f
-node
because it comes after the output must be produced
(contradicting the order of origins of output nodes
[
6
]
,
see also
[
7
,
8
]
).

The
twinning
property is similar to the string case
[
9
]

(see also
[
10
,
11
]
), but now for paths.
To understand the
erasing
property, consider a transducer
with the following rules.

{\begin{array}[]{lcllcl}q_{0}(a(x_{1}:h_{e}))&\to&a(a(e))&q_{\text{id}}(a(x_{1}:h_{f}))&\to&a(q_{\text{id}}(x_{1}))\\
q_{0}(a(x_{1}:h_{f}))&\to&a(q_{\text{id}}(x_{1}))&q_{\text{id}}(f)&\to&f\\
q_{0}(f)&\to&f\end{array}}

Here, input trees are of the form
a(\cdots a(e)\cdots)
or
a(\cdots a(f)\cdots)
.
The look-ahead automaton has two states
h_{e}
and
h_{f}
, indicating that the input tree
is of the first form (
e
-leaf) or the second form (
f
-leaf).
The transducer translates input trees of the first form to the fixed tree
a(a(e))
and
realizes the identity on trees of the second form.
This translation can
not
be realized by a transducer without look-ahead.
The
erasing
property demands that if an input path depends on two different
look-ahead states
h_{1},h_{2}
, where for
h_{1}
a constant output tree is produced
(viz. the tree
a(a(e))
), then for
h_{2}
no output may be produced in any loop.

Given a
uniform-copying

transducer
A
with look-ahead that is synchronizing, twinning, and erasing we construct
an equivalent
uniform-copying
transducer with
inspection
(if it exists), i.e., a

uniform-copying
transducer where the domain is given separately via some
top-down deterministic tree automaton.

The
third highlight
of our contribution is a procedure that removes inspection (if possible).
The idea here is quite different from what we have discussed until now.
Let us consider an example. The domain automaton accepts trees of
the form
f(t_{1},t_{2})
where
t_{2}
is an arbitrary binary tree (with internal nodes
labeled
f
and leaves labeled
a
or
b
) and
t_{1}
is a tree which has a left-most
leaf labeled
a
and a right-most leaf labeled
b
.
The transducer has this rule:

{q_{0}(f(x_{1},x_{2}))\to f(f(b,b),q_{\text{id}}(x_{2}))},

where state
q_{\text{id}}
realizes the identity.
Does there exist an equivalent top-down tree transducer
without
inspection?
As it turns out, the answer is “yes”. The idea is that the output subtree

f(b,b)
can be used to simulate inspection!
These are the rules of an equivalent transducer without inspection:

{\begin{array}[]{lll@{\quad}lll}q_{0}(f(x_{1},x_{2}))&\to&f(q(x_{1}),q_{\text{id}}(x_{2}))&q(f(x_{1},x_{2}))&\to&f(q_{a}(x_{1}),q_{b}(x_{2}))\\
q_{a}(f(x_{1},x_{2}))&\to&q_{a}(x_{1})&q_{b}(f(x_{1},x_{2}))&\to&q_{b}(x_{2})\\
q_{a}(a)&\to&b&q_{b}(b)&\to&b\end{array}}

We show that it is decidable for a given top-down deterministic tree language, whether
or not it can be simulated on a given output tree. The challenge now is that
it may be necessary to
delay
outputting certain output subtrees, until rules
are encountered which require these output trees for simulating their inspection needs.
Similar as before, such delay is only possible along input paths and must stop
when two input subtrees of an input node are processed.
Using a precise abstract interpretation of inspection needs we are able
to determine if sufficiently large output subtrees can be made available in order
to meet all required inspection needs.
The approach we have sketched here is quite different from
earlier methods for look-ahead removal
[
12
]

that rely on
difference bounds
, i.e., the
differences in the translation with respect to different look-ahead states.
In order to obtain an effective construction, however, so far a variety of technical restrictions
had to be introduced — implying that even for
linear
deterministic top-down tree transducers,
look-ahead removal remained an open problem.
To the best of our knowledge, this paper is the first to present look-ahead removal
for natural and known subclasses of top-down tree transducers.

Our result is an example of a
definability problem
, i.e., given classes
X,Y

of transductions, is it decidable for each
y\in Y
whether or not an
x\in X
exists such
that
x
is equivalent to
y
. Many such problems have been considered in the past.
Fon instance,
X
and
Y
may be classes of languages, such as the regular and
the context-free languages, respectively. In this case, it is well-known by
Greibach’s Theorem
[
13
]

that the corresponding definability problem is
undecidable
.
Interestingly, the situation changes if
Y
is diminuished to the deterministic context-free
languages (i.e., those recognized by deterministic push-down automata). Then definability
is indeed decidable
[
14
]
.
In terms of
tree languages
, such decidable definability
results are rare. One example is that for a given tree homomorphism
h
and a regular tree langauge
R

is is decidable whether or not
h(R)
can be defined by a regular tree langauge
[
15
]
.
This result was later generalized to a weighted setting
[
16
]
.

Transductions are somewhat more rigid than languages and thus better suited for decidable
definability problems. In terms of string transductions, an important decidable definability
problem was identified recently: for a given functional two-way transducer it is decidable
whether or not an equivalent one-way transducer
exists
[
17
,
18
]
.
In terms of tree transducers, this result has been extended to attributed tree transducers
with monadic output
[
19
]
.
Recently, the regular string transductions have received much attention,
see, for instance
[
20
]
.
It was shown that for a given regular string transducer, it is decidable whether its
translation has size increase
O(n^{k})
, for any given
k

[
21
]
.
In terms of tree transducers, it is known whether or not a given composition of deterministic macro tree transducers
is of linear size increase
[
22
]
;
note that in the affirmative case, the translations is indeed
definable by an MSO transducer (Monadic Second-Order logic). Recently also linear height-increase
and linear size-to-height increase was shown to be decidable for a given macro tree
transducer
[
23
]
.

This paper is an extended version of
[
24
]

which as been presented at ICALP’2020.

Basics

Let
\Sigma
denote a ranked alphabet. Then

,

, and

.
Trees in

.
Of particular importance is the set of

.
This set forms a

The tree

We thus write

We also consider the set
{\mathcal{C}}_{\Sigma}\subseteq{\mathcal{T}}_{\Sigma}(x_{1})
of
contexts
over
\Sigma

which is the subset of unary patterns which contain exactly one occurrence of
x_{1}
;
technically, this means that each such context

either is equal to

,
or is of the form

for some
f\in\Sigma_{k}
,
k\geq 1
, and

so that

is a context and

for all

.

In the following,
\Sigma
and
\Delta
denote fixed non-empty ranked alphabets of
input and output symbols, respectively.
In this paper, we consider deterministic top-down tree transducers that are
uniform-copying
,
or

-transducers for short.
Intuitively,
uniform-copying
means that each subtree of the input is processed at most once —
while the produced output may be copied arbitrarily often.
This restriction is trivially met by
linear
top-down transducers – but also by those that
arise from the top-down simulation of deterministic
bottom-up
transducers
by means of regular look-ahead.
Here, we refrain from introducing transducers with

Instead, we find it convenient to introduce yet another model, namely,
deterministic transducers with

be instantiated either with top-down deterministic inspection
(no interference with the computation of the
transducer, only restriction to relevant input) or bottom-up deterministic look-ahead
(interference with the computation as well as restriction to relevant input).

An

(h,h):x_{1}

We assume that every occurring TA

A

2.

\langle h,f,h_{1}\ldots h_{k}\rangle\in\delta

q(f(x_{1}:h_{1},\ldots,x_{k}:h_{k}))\to T

(1)

\iota
is the identity.
A classical deterministic
top-down
tree transducer with uniform-copying,
on the other hand, is obtained as a
\textsf{D\!T}^{\text{i}}_{\!\text{uc}}
transducer where
the inspection does not restrict the domain. This can be achieved, e.g., by setting

H=Q\cup\{\top\}
for a fresh symbol
\top
and
\iota(q)=q
.
Moreover, for each
f\in\Sigma_{k}
,
\langle\top,f,\top^{k}\rangle\in\delta
as well as

\langle q,f,q^{\prime}_{1}\ldots q^{\prime}_{k}\rangle\in\delta

whenever there is a rule
q(f(x_{1},\ldots,x_{k}))\to T
such that
for each
i=1,\ldots,k
,
q^{\prime}_{i}=q_{i}
if
q_{i}(x_{i})
occurs in
T
and
q^{\prime}_{i}=\top
otherwise.
Alternatively, in that case the advice automaton can be removed entirely from the definition of the transducer – thereby
obtaining the classical model of deterministic top-down transducer (as defined, e.g., in
[
1
]
),
here with the
uniform-copying
restriction.

We remark that in the same way, deterministic
linear
top-down
tree transducers with look-ahead as well as deterministic linear bottom-up transducers and
deterministic linear top-down transducers with inspection are instances of
linear

\textsf{D\!T}^{\text{a}}_{\!\text{uc}}
transducers.

3
A Dedicated Earliest Normal Form for
uc
-Transducers with Advice

In this section we present constructions of earliest normal-forms for
uc
-transducers and
linear
transducers with advice.
In the following, we fix some trim unambiguous TA
B
for advice.
A construction of
earliest
deterministic top-down transducers has already been provided
in
[
12
]
for top-down deterministic domain automata
B
and as well as
in
[
26
]
for bottom-up deterministic
B
.
Here, we are slightly more liberal by allowing
unambiguous

B
to generalize both cases.
The constructions from
[
12
,
26
]
, on the other hand,
neither preserve linearity nor uniform-copying.

Example 1

Consider a linear top-down transducer with the rules:

{\begin{array}[]{lcllcl}q_{0}(g(x_{1}))&\to&q_{1}(x_{1})&q_{0}(a)&\to&a\\
q_{1}(f(x_{1},x_{2}))&\to&f(q_{0}(x_{1}),q_{0}(x_{2}))&q_{0}(b)&\to&b\end{array}}

and the axiom
q_{0}(x_{1})
.
The (canonical) earliest transducer constructed according to the methods
in
[
12
]
has the same axiom
q_{0}(x_{1})
, but the rules:

{\begin{array}[]{lcllcl}q_{0}(g(x_{1}))&\to&f(q_{11}(x_{1}),q_{12}(x_{1}))&q_{0}(a)&\to&a\\
q_{11}(f(x_{1},x_{2}))&\to&q_{0}(x_{1})&q_{0}(b)&\to&b\\
q_{12}(f(x_{1},x_{2}))&\to&q_{0}(x_{2})\end{array}}

where no inspection automaton is required.
The non-linearity in the first rule
arises inevitably, because the output
f
-node is already determined at this point
and therefore must be output for the transducer to be
earliest
.
Since the transductions corresponding to states
q_{11}
and
q_{12}
differ,
the resulting
transducer is not only non-linear, but also not
uniform-copying
.
∎

We introduce
dedicated
constructions which
allow to construct equivalent
canonical
transducers, but retain linearity or
uniform-copying.

It turns out that these normal forms can be obtained in polynomial time.
Our key insight is that
dedicated
notions should be provided
for the notion of
maximal common prefix
of a given set
S
of trees.
In
[
12
]
, a pattern
such as
p=a(x_{1},g(x_{2}))
was used to represent the common part of trees in
S

(note that they do not use distinct variables, but one symbol

\top
to denote
any tree
and whose distinct occurrences can be substituted independently).
This meant for an element
t\in S
such as
t=a(b,g(c))
that
the variables in
p
could correspond to not necessarily isomorphic
subtrees of
t
, in the example,
b
and
c
, respectively.
In that point, we will now be more restrictive and only allow a single variable
x_{1}
and
substitutions
,
i.e., equal replacements of all occurrences of
x_{1}
in patterns.
To distinguish these patterns from those in
[
12
]
,
we call them
uniform
.
Let
\Delta
be a ranked alphabet.
Let us denote by
{\mathcal{P}}_{\Delta}

the set
{\mathcal{T}}_{\Delta}\cup{\mathcal{T}}_{\Delta}(x_{1})\cup\{\bot\}
of all ground trees
and unary patterns, extended with one specific fresh element
\bot
.
This set forms a
partial order

where for
t_{1},t_{2}\in{\mathcal{P}}_{\Delta}
,

t_{1}\sqsubseteq t_{2}
iff
t_{1}=\bot
or
t_{1}=t_{2}\{x_{1}\mapsto s\}
for
some
s\in{\mathcal{T}}_{\Delta}\cup{\mathcal{T}}_{\Delta}(x_{1})
.
In fact,
{\mathcal{P}}_{\Delta}
, partially ordered in this way,
forms a
complete lattice
with finite ascending chains.
In particular, the top-most element is
x_{1}
, and the binary least upper
bound operation
\sqcup
for incomparable elements
t_{1},t_{2}\neq\bot
, is given by
t_{1}\sqcup t_{2}=s

where
s
is the maximal tree in
{\mathcal{T}}_{\Delta}(x_{1})
such that

s\{x_{1}\mapsto t^{\prime}_{i}\}=t_{i}
for suitable trees
t^{\prime}_{i}
(
i=1,2
).

We remark that uniform patterns may contain more than one occurrence of
x_{1}
—
all representing, though, isomorphic subtrees.
Let
{\mathcal{P}}_{\Delta}^{(1)}\subseteq{\mathcal{P}}_{\Delta}
denote the subset
{\mathcal{T}}_{\Delta}\cup{\mathcal{C}}_{\Delta}\cup\{\bot\}

of all elements which either equal
\bot
or contain at most
one
occurrence of
x_{1}
.
Patterns in that set are also called
1-patterns
.
For the induced partial ordering on
{\mathcal{P}}_{\Delta}^{(1)}
,
we again obtain a complete lattice
with finite ascending chains. For a distinction, let us denote the least upper bound
operation with respect to
{\mathcal{P}}_{\Delta}^{(1)}
with
\sqcup^{(1)}
.

Example 2

The difference between the two least upper bound operations becomes
apparent when considering trees which differ in more than one subtree:

\begin{array}[]{lll}f(g(a,a),c)\sqcup f(g(b,b),c)&=&f(g(x_{1},x_{1}),c)\\
f(g(a,a),c)\sqcup^{(1)}f(g(b,b),c)&=&f(x_{1},c).\end{array}

On the other hand,

f(g(a,a),c)\sqcup f(g(b,b),d)=f(g(a,a),c)\sqcup^{(1)}f(g(b,b),d)=x_{1}
. We remark that the earliest construction in
[
12
]

would return
f(g(\bot,\bot),\bot)
for the latter example — implying
that the place holder
\bot
no longer represents
isomorphic
subtrees.
∎

3.1
Computing Maximal Common Prefixes

For the rest of this section, let
A=(B,Q,\iota,R,\alpha)
denote a fixed
uc
-transducer
with advice.
For
q\in Q
, let

\begin{array}[]{lll}\textsf{pref}\,_{A}(q)&=&\bigsqcup\{[\![t]\!]_{A,q}\mid t\in\textsf{dom}\,_{B}(\iota(q)\}\qquad\text{ and }\\
\textsf{pref}\,^{\,(1)}_{A}(q)&=&\bigsqcup^{(1)}\{[\![t]\!]_{A,q}\mid t\in\textsf{dom}\,_{B}(\iota(q))\}.\end{array}

We remark that even for a
linear
transducer, the values
\textsf{pref}\,_{A}(q)
and
\textsf{pref}\,_{A}^{\,(1)}(q)
may indeed differ.

Example 3

Let
q
be a state of a linear transducer
A
with the following two rules:

\begin{array}[]{lcl}q(f(x_{1}:h_{1}))&\to&g(a,a)\\
q(f(x_{1}:h_{2}))&\to&g(b,b).\end{array}

Then
\textsf{pref}\,_{A}(q)=g(x_{1},x_{1})
while
\textsf{pref}\,_{A}^{\,(1)}(q)=x_{1}
.
This means that a corresponding earliest
uc
-transducer outputs
a
g
-node in state
q
, while a corresponding earliest
linear
transducer
produces no output node in state
q
.
∎

In the following, we show that
\textsf{pref}\,_{A}:Q\to{\mathcal{P}}_{\Delta}

as well as
\textsf{pref}\,_{A}^{\,(1)}:Q\to{\mathcal{P}}^{(1)}_{\Delta}
(in case that
A
is in fact linear)
can be obtained
as the least solutions of the sets of constraints
{\mathcal{C}}_{A}
and
{\mathcal{C}}_{A}^{(1)}
, respectively.

The sets
{\mathcal{C}}_{A}
,
{\mathcal{C}}^{(1)}_{A}
consist of one constraint
c(\tau)
,
c^{(1)}(\tau)
for each rule
\tau

of
A
.
Assume that
\tau
is the rule

q(f(\ldots))\to T
of
A
where
T=p\{x_{j}\mapsto q_{j}(x_{j})\mid j\in J\}
for some

J\subseteq{\mathbb{N}},p\in{\mathcal{T}}_{\Delta}(X_{J})
, and suitable
q_{j}\in Q
. Then the constraint
c(\tau)
is given by

\displaystyle\sigma(q)

\displaystyle\sqsupseteq

\displaystyle[\![T]\!]\sigma\qquad

(2)

while the constraint
c^{(1)}(\tau)
is given by

\displaystyle\sigma^{(1)}(q)

\displaystyle\sqsupseteq

\displaystyle[\![T]\!]^{(1)}\sigma^{(1)}.\qquad

(3)

Here,
\sigma
(and
\sigma^{(1)}
) are mappings from states in
Q

to patterns in
{\mathcal{T}}_{\Delta}(x_{1})
.
The right-hand side
[\![T]\!]\sigma
returns
\bot
if for any state
q_{j},j\in J
,

\sigma(q_{j})=\bot
. Otherwise,
assume that
p^{\prime}
is obtained from
p
and
\sigma
by replacing
q_{j}(x_{j})

with
\sigma(q_{j})\cdot x_{j}

where
j\in J
and with
\sigma(q_{j})
whenever
\sigma(q_{j})
is ground.
If
p^{\prime}
is ground, we set
[\![T]\!]\sigma=p^{\prime}
.
If
p^{\prime}
contains occurrences of
x_{j}
for a single
j\in J
,
i.e., is of the form
p^{\prime}=p^{\prime\prime}\cdot x_{j}
for some
p^{\prime\prime}\in{\mathcal{T}}_{\Delta}(x_{1})
,
then
[\![T]\!]\sigma=p^{\prime\prime}
.
Otherwise, i.e., if
p^{\prime}
contains occurrences of more than one variable,
then
[\![T]\!]\sigma=u
where
u\in{\mathcal{T}}_{\Delta}(x_{1})
is the maximal prefix
such that
p^{\prime}=u\cdot p^{\prime\prime}
for some
p^{\prime\prime}
containing all
x_{j}
, i.e.,
u
has maximal size with
this property and thus is
least
with respect to the ordering on patterns.

Likewise for linear transducers, the right-hand side
[\![T]\!]^{(1)}\sigma^{(1)}
is evaluated
in the same way – only that now prefixes are determined w.r.t. the patterns in
{\mathcal{P}}_{\Delta}^{(1)}
.

Example 4

Let
T=f(g(q_{2}(x_{2}),a),g(q_{2}(x_{2}),q_{1}(x_{1}))
, and thus

p=f(g(x_{2},

a),g(x_{2},x_{1}))
.
Assume that we are given
\sigma=\{q_{1}\mapsto a,q_{2}\mapsto b(x_{1})\}
.
Then we have that

p^{\prime}=f(g(b(x_{2}),a),g(b(x_{2}),a))

and thus,

[\![T]\!]\sigma=f(x_{1},x_{1})\cdot g(x_{1},a)\cdot b(x_{1})=f(g(b(x_{1}),a),g(b(x_{1}),a)).

∎

Each right-hand side of a constraint in
{\mathcal{C}}_{A}
(
{\mathcal{C}}^{(1)}_{A}
)
represents a function which is
distributive
in each argument,
i.e., commutes with the binary least upper bound operator in each accessed argument
\sigma(q_{j})
(
\sigma^{(1)}(q_{j})
).
Recall that any distributive function is also monotonic.
Since the partial orderings on
{\mathcal{P}}_{\Delta}

and likewise on
{\mathcal{P}}_{\Delta}^{(1)}

are complete lattices
with finite ascending chains,
the constraint systems (
2
) and (
3
)
have a least solution.
We thus obtain:

Lemma 1

Let
\textsf{pref}\,_{A}(q),q\in Q
, and
\textsf{pref}\,_{A}^{\,(1)}(q),q\in Q)
, denote the least solutions of the set of constraints
(
2
) over the complete lattice
{\mathcal{P}}_{\Delta}
and
(
3
) over the complete lattice
{\mathcal{P}}_{\Delta}^{(1)}
(in the case that
A
is linear), respectively. Then
for every
q\in Q
with
\iota(q)=h
,

\displaystyle\textsf{pref}\,_{A}(q)

\displaystyle=

\displaystyle\bigsqcup\{[\![t]\!]_{A,q}\mid t\in\textsf{dom}\,_{B}(h)\}

(4)

\displaystyle\textsf{pref}\,_{A}^{\,(1)}(q)

\displaystyle=

\displaystyle\bigsqcup^{(1)}\{[\![t]\!]_{A,q}\mid t\in\textsf{dom}\,_{B}(h)\}

(5)

holds.
Moreover, the least solution can be computed in polynomial time.

Proof.

Recall that by our assumption, the advice automaton is trim. Therefore,

\textsf{dom}\,_{B}(\iota(q))
is non-empty, i.e.,
\textsf{pref}\,_{A}(q)\neq\bot
for each
q\in Q
.
The equality in equation (
4
) (and in equation (
5
))
then is due to the Fixpoint Transfer Lemma

[
27
]
.
More explicitly,
let
X_{q}^{(i)}
denote the
i
th iterate of the fixpoint iteration for the constraint
system (
2
) for
i\geq 0
.
By induction on
i
, it can be verified that
X_{q}^{(i)}
equals the maximal
common prefix of all
[\![t]\!]_{A,q}
for trees
t\in\textsf{dom}\,_{B}(\iota(q))
of depth less than
i
.
In case
A
is linear, we may define
X_{q}^{(i)}
analogously as the
i
th iterate of the fixpoint iteration for the constraint system
(
3
).

Thereby, the prefixes
X_{q}^{(i+1)}
can be determined from the prefixes
X_{q}^{(i)}

in polynomial time. This is obvious for
linear
transducers
A
and the constraint system
(
3
).
When
A
is
uniform-copying
, and general uniform patterns are used,
polynomial time can be obtained when
trees are represented as
dags
where isomorphic subtrees are represented only once.
Concerning the complexity of the construction.
We claim that
the number of iterations required for reaching the least fixpoint of the constraint system
is bounded by a polynomial in the size
|A|
of the transducer
A
.
A first value different from
\bot
occurs after at most
n
iterations where
n
is the number of states of
A
.
This value can be represented by some dag composed of right-hand sides where no right-hand side occurs more than once.
In each further iteration, the value for at least one state
q
shrinks (or the algorithm terminates).
In total, the least fixpoint is reached after at most
n\cdot|A|
iterations. Since the representation of each intermediate
tree is bounded by
|A|
, the overall complexity statement follows.
∎

A similar constraint system is used for the construction of maximal common prefixes in
[
5
]
for unrestricted deterministic top-down tree transducers.
Due to the more general form of patterns, however, the construction there cannot rely on compressed representations of occurring
trees – implying that no polynomial upper time bound has been provided.

3.2
Earliest Transducers

Let
A
denote some
uc
-transducer (
linear
transducer)
A
with advice.
We call
A
an earliest
uc
-transducer (
linear
transducer), if

\textsf{pref}\,_{A}(q)=x_{1}

(
\textsf{pref}\,_{A}^{(1)}(q)=x_{1}
)
for all states
q
of
A
.
If this is not yet the case,
we construct a transducer
A^{\prime}
of the same kind as
A
as follows
where we only present the construction for
uc
transducers (the linear case is analogously obtained where
each
\textsf{pref}\,_{A}
is replaced with
\textsf{pref}\,^{\,(1)}_{A}
).
The set
Q^{\prime}
of states of
A^{\prime}
consists of the
non-constant
states of
A
, i.e., of all
states of
A
with at least two distinct output trees. This set is given by

Q^{\prime}=\{q\in Q\mid\textsf{pref}\,_{A}(q)\not\in{\mathcal{T}}_{\Delta}\}
.
The mapping
\alpha^{\prime}
of axioms of
A^{\prime}
is obtained from the mapping
\alpha
of axioms of
A

as follows. Let
h
denote a final state of
B
. If
\alpha(h)
is ground, then
\alpha^{\prime}(h)=\alpha(h)
.
Otherwise,
\alpha(h)=p\cdot q(x_{1})
for some
p\in{\mathcal{T}}_{\Delta}(x_{1})
and
q\in Q
.
Assume that
\textsf{pref}\,_{A}(q)=s
. If
s\in{\mathcal{T}}_{\Delta}
, then
\alpha^{\prime}(h)=p\cdot s
; and if

s\in{\mathcal{T}}_{\Delta}(x_{1})
, then
\alpha^{\prime}(h)=p\cdot s\cdot q(x_{1})
.

Now assume that
q\in Q^{\prime}
, and
\textsf{pref}\,_{A}(q)=u
.
Then for each rule
q(f(x_{1}:h_{1},\ldots,x_{k}:h_{k}))\to p\{x_{j}\mapsto q_{j}(x_{j})\mid j\in J\}
of
A
,

A^{\prime}
has a rule
q(f(x_{1}:h_{1},\ldots,x_{k}:h_{k}))\to T^{\prime}
where
T^{\prime}
is defined as follows.
For
j\in J
, let
s_{j}=\textsf{pref}\,_{A}(q_{j})
if
\textsf{pref}\,_{A}(q_{j})\in{\mathcal{T}}_{\Delta}
,
and
s_{j}=u_{j}\cdot q_{j}(x_{j})
if
\textsf{pref}\,_{A}(q_{j})=u_{j}\in{\mathcal{T}}_{\Delta}(x_{1})
.
Then
u
must be a prefix of

p\{x_{j}\mapsto s_{j}\mid j\in J\}
, and we choose
T^{\prime}
such that

p\{x_{j}\mapsto s_{j}\mid j\in J\}=u\cdot T^{\prime}
holds.

Lemma 2

Assume that
A
is a
\textsf{D\!T}^{\text{a}}_{\!\text{uc}}
(
\textsf{D\!T}^{\text{a}}_{\!\text{lin}}
)
without constant states
and
A^{\prime}
the
\textsf{D\!T}^{\text{a}}_{\!\text{uc}}
(
\textsf{D\!T}^{\text{a}}_{\!\text{lin}}
)
as constructed above. Then,

1.

For each state
q
of
A^{\prime}
with
u=\textsf{pref}\,_{A}(q)
(
u=\textsf{pref}\,_{A}^{\,(1)}(q)
) with
\iota(q)=h
, it holds that

(a)

[\![t]\!]_{A,q}=u\cdot[\![t]\!]_{A^{\prime},q}
for all

;

(b)

\textsf{pref}\,_{A^{\prime}}(q)=x_{1}
(
\textsf{pref}\,^{\,(1)}_{A^{\prime}}(q)=x_{1}
) holds for all states
q

of
A^{\prime}
.

2.

A^{\prime}
is equivalent to
A
.

3.

A^{\prime}
can be constructed from
A
in polynomial time.

Proof.

Properties 1.a and 1.b of Lemma
2
can be proven by structural
induction on the input tree
t
.
Property 2 then follows from 1.a and 1.b by the definition of the axioms of
A^{\prime}
.
For property 3 we allow ourselves that both
A
and
A^{\prime}
use right-hand sides represented by means of

ordered dags
which represent
identical subtrees only once.
According to Lemma
1
, the maximal prefixes
\textsf{pref}\,_{A}(q)
(
\textsf{pref}\,_{A}^{\,(1)}(q)
) can be
computed in polynomial time. Since the required factorizations of right-hand sides can be computed on
compressed representations in polynomial time, also property 4 follows.
∎

The corresponding construction in
[
5
]
and its proof are
more complicated, because each state of the original transducer may be split into multiple new states
of the corresponding earliest transducer (see Example

).

The earliest transducer constructed for Lemma

.
For that, we introduce
\equiv

\iota(q)=\iota(q^{\prime})
,
and for each transition

Let

\equiv

We only prove the first statement.
Assume that we are given an equivalence relation

5
How to Inspect Top-Down Deterministic Languages

Now consider a
\textsf{D\!T}^{\text{i}}_{\!\text{uc}}

A
with underlying top-down deterministic automaton
B
which
is assumed to be canonical earliest.
For the following, we denote the unique state
h
of
B
with
\textsf{dom}\,_{B}(h)={\mathcal{T}}_{\Sigma}

(given that there is such a state), by
\top
.
The
\textsf{D\!T}^{\text{i}}_{\!\text{uc}}
(
\textsf{D\!T}^{\text{i}}_{\!\text{lin}}
)
A
is
without inspection
(denoted by
\textsf{D\!T}_{\!\text{uc}}
and
\textsf{D\!T}_{\!\text{lin}}
, respectively)
if for every rule
q(f(x_{1}:h_{1},\ldots,x_{k}:h_{k})\to T
of
A
,
h_{j}=\top
whenever

x_{j}
does not occur in
T
.
In particular, this is the case when
A
is
non-deleting
, i.e.,
the right-hand side of every rule of
A
contains all variables
x_{j}
occurring in its left-hand side.

Any
\textsf{D\!T}^{\text{i}}_{\!\text{uc}}
(
\textsf{D\!T}^{\text{i}}_{\!\text{lin}}
) that is without inspection can be changed in such a way that no advice automaton
is present at all (see the discussion of various transducer models in Section
2
).
In order to understand the idea of our approach to inspection removal,
consider the rule

q(f(x_{1}:h_{1},x_{2}:h_{2}))\to g(q_{1}(x_{1}),r(b))

of a
uc
-transducer where
\textsf{dom}\,_{B}(h_{2})=\{g(a,t)\mid t\in{\mathcal{T}}_{\Sigma}\}
.
Since
x_{2}
does not occur in the right-hand side of the rule, the transducer will not visit the corresponding
subtrees of the input. It therefore seems impossible for a transducer without inspection
to verify that the corresponding subtrees are in
\textsf{dom}\,_{B}(h_{2})
.
However, due to the simple structure of the input trees in that language,
an artificial call could be introduced which successively checks the input while producing some constant
output subtree of the given rule.
In our particular case, the given rule can be simulated by

\begin{array}[]{lll}q(f(x_{1},x_{2}))&\to&g(q_{1}(x_{1}),r(q_{2}(x_{2})))\\
q_{2}(g(x_{1},x_{2}))&\to&q^{\prime}_{2}(x_{1})\\
q^{\prime}_{2}(a)&\to&b\end{array}

For convenience, we have dropped the annotations of the
x_{i}
with advice states.

To generalize this idea, we require an effective method to decide for a given top-down deterministic tree language
L
and
a ground output tree
s\in{\mathcal{T}}_{\Delta}
whether or not
L
is
output-recognizable
by
s
, i.e.,
whether a
uc
(or, better, linear) transducer
A
without inspection with domain
L
can be constructed such that

[\![t]\!]_{A}=s
for all
t\in L
.
It turns out that a language is output-recognizable via some
\textsf{D\!T}_{\!\text{uc}}
iff
it is output-recognizable via some
\textsf{D\!T}_{\!\text{lin}}
. Hence, we drop the qualification.

Assume that the language
L
is accepted by a trim
top-down deterministic TA.
We show that for a fixed input alphabet, it can be decided in
polynomial time
whether or not
L

is output-recognizable
by a particular output tree
s
.
It turns out that output symbols in the output tree
s
with arities exceeding one, vastly extend the potential for checking
top-down deterministic languages
L
via transducers without inspection.

Example 6

Consider the rule

q(f(x_{1}:h_{1},x_{2}:h_{2}))\to g(g(c,c),q(x_{2}))

where
L=\textsf{dom}\,_{B}(h_{1})
equals the set of trees
t
over
\Sigma=\{a,b,f\}
for nullary symbols
a,b
and binary symbol
f

so that
t
has at least two leaves where the leftmost leaf of
t
equals
a
and the rightmost leaf equals
b
.
The language
L
is
not
output-recognizable by
a single leaf

alone, because both the leftmost and the rightmost leaf of the input must be visited by the transducer,
and a single output leaf only allows visiting a single path in the input tree.
On the contrary, the output tree
g(c,c)
offers the possibility to visit two paths in the input thereby allowing to recognize
L
.
A corresponding transducer is given by the following rules:

\begin{array}[]{lll}q(f(x_{1},x_{2}))&\to&g(q_{0}(x_{1}),q(x_{2}))\\
q_{0}(f(x_{1},x_{2}))&\to&g(q_{a}(x_{1}),q_{b}(x_{2}))\\
q_{a}(f(x_{1},x_{2}))&\to&q_{a}(x_{1})\\
q_{a}(a)&\to&c\\
q_{b}(f(x_{1},x_{2}))&\to&q_{b}(x_{2})\\
q_{b}(b)&\to&c\,.\\
\end{array}

∎

Consider a top-down deterministic TA
B=(H,\Sigma,\delta,\{h_{0}\})
.

Then we have:

Using the patterns

s^{\prime}
of of

of

of

For the reverse direction,

Moreover for every other reachable state

W.l.o.g., we may assume that the prefix

If this is not yet the case, we can introduce a new state

6
How to Satisfy Inspection Needs

In the following, we consider an arbitrary
\textsf{D\!T}^{\text{i}}_{\!\text{uc}}
transducer
A

with underlying top-down deterministic TA
B

as
inspection
automaton. We recall that,
since
B
has only a single accepting state,
A
only provides a single axiom.
Consider a rule
\tau
of the form
q(f(x_{1}:h_{1},\ldots,x_{k}:h_{k}))\to T
of
A
.
For every
x_{i}
not occurring in
T
, it must be verified that
the corresponding subtree of the input is contained in
\textsf{dom}\,_{B}(h_{i})
.
This verification is not needed if
h_{i}=\top
, i.e.,
\textsf{dom}\,_{B}(h_{i})={\mathcal{T}}_{\Sigma}
.
Accordingly, let
J_{\tau}
denote the set of indices
j
such that
x_{j}
does
not

occur in
T
while at the same time,
h_{j}\neq\top
.
Let us thus call the set

\eta_{\tau}=\{(j,h_{j})\mid j\in J_{\tau}\}
the
inspection need
of the rule
\tau
.

Assume that
T
has disjoint ground subtrees
s_{j},j\in J_{\tau}
,
such that
\textsf{dom}\,_{B}(h_{j})
is output-recognizable by
s_{j}
for
j\in J_{\tau}
.
Then the rule
\tau
can equivalently be replaced by rules without inspection need.
This can be seen as follows.
For each
j\in J_{\tau}
, consider the transducer
A_{j}=A_{B,h_{j},s_{j}}
from Theorem
3

with domain
\textsf{dom}\,_{B}(h_{j})
and single output
s_{j}
. By definition, each state of
A_{j}
only produces a single output.
W.l.o.g., assume that the sets of states of the
A_{j}
are all disjoint and different from the states of
A
.
Then
\tau
is replaced with the rule obtained from
\tau
by replacing each
s_{j}
in
T

with the tree obtained from the axiom of
A_{j}
by substituting
x_{1}
with
x_{j}
;
furthermore, all rules from the
A_{j}
are included.
Therefore in this case, we say that
\tau

satisfies
its inspection need.

Example 8

Consider the rule
\tau
given by

q(f(x_{1}:h_{1},x_{2}:h,x_{3}:h))\to g(q^{\prime}(x_{1}),r(b),b)

where
\textsf{dom}\,_{B}(h)
equals the set
L=\{g(a,t)\mid t\in{\mathcal{T}}_{\Sigma}\}
.
Then
J_{\tau}=\{2,3\}
, and
the inspection need of the rule
\tau
is
\eta_{\tau}=\{(2,h),(3,h)\}
because we need to verify for the
input subtrees corresponding to the variables
x_{2}
and
x_{3}
in
\tau

whether or not they are contained in
L=\text{dom}_{B}(h)
.
The language
L
is output-realizable by

as well as

.
One possible way of removing inspection therefore is by the following rules:

\begin{array}[]{lll}q(f(x_{1},x_{2},x_{3}))&\to&g(q^{\prime}(x_{1}),r(q_{1}(x_{2})),q_{1}(x_{3}))\\
q_{1}(g(x_{1},x_{2}))&\to&q_{2}(x_{1})\\
q_{2}(a)&\to&b.\end{array}

∎

Our goal is to construct for a given
\textsf{D\!T}^{\text{i}}_{\!\text{uc}}
transducer
A
an equivalent
\textsf{D\!T}^{\text{i}}_{\!\text{uc}}
transducer
A^{\prime}

such that each rule of
A^{\prime}
satisfies its inspection need.
If each rule of
A
satisfies its inspection need,
this need no longer be the case for the
earliest
transducer equivalent to
A
.
The reason is that
some ground subtrees of prefixes of right-hand sides may have been moved to the right-hand sides
of other rules.
Satisfying inspection needs of rules therefore requires to partly

revert
the
earliest
transformation.

6.1
Analyzing Inspection Needs

Let
A
denote a
\textsf{D\!T}^{\text{i}}_{\!\text{uc}}
in canonical earliest normal form, and assume that
A
is equivalent to some
\textsf{D\!T}_{\!\text{uc}}

A^{\prime}
.
Recall that each state of
A
can be considered as an equivalence class of non-constant states of
A^{\prime}
,
where for each state
q
of
A
and each state
q^{\prime}\in q
of
A^{\prime}
with

\textsf{pref}\,_{A^{\prime}}(q^{\prime})=p
, it holds that

p\cdot[\![t]\!]_{A,q}=[\![t]\!]_{A^{\prime},q^{\prime}}
.
In particular, the constant outputs for some states of
A^{\prime}
may
occur as subtrees in
p
and thus are already produced before
A

processes the input
t
.

In order to recover the (yet unknown)
\textsf{D\!T}_{\!\text{uc}}

A^{\prime}
without inspection from the canonical earliest
\textsf{D\!T}^{\text{i}}_{\!\text{uc}}

A
,
we determine the minimal suffix
p^{\prime}
of

so that all inspections possibly
encountered when
q
processes its input, can be satisfied.

Example 9

Let
h_{a}
,
h_{b}

Let the domains of
h_{a}

h_{b}
consist of all trees whose left-most leaf is labeled by

or

, respectively.
Consider the canonical earliest
\textsf{D\!T}^{\text{i}}_{\!\text{uc}}

\alpha(h_{0})=f(a,f(a,q_{0}(x_{1})))

\begin{array}[]{lll}q_{0}(f(x_{1}:h,x_{2}:h_{a}))&\to&q_{1}(x_{1})\\
q_{1}(f(x_{1}:h,x_{2}:h_{b}))&\to&q_{2}(x_{1})\\
q_{1}(g(x_{1}:h,x_{2}:h_{b},x_{3}:h_{b}))&\to&f(a,q_{2}(x_{1}))\\
q_{2}(a)&\to&a\,.\end{array}

No rule for non-leaf input symbols satisfies its inspection need.
We may, however, delay the output of the axiom in such a way that the right-hand sides of these rules receive

Example

7
Conclusion

We showed for two natural subclasses of deterministic top-down tree transducers
(namely,
linear
and
uniform-copying
ones)
how to remove
(bottom-up deterministic) look-ahead and
replace it whenever possible, with (top-down deterministic) inspection.
We then also showed for the given classes how to remove inspection (if possible).
The constructions are technically intricate, but crucially rely on canonical earliest
normal forms for the transducers in question.
As a corollary we obtain that for a given deterministic bottom-up transducer it is
decidable whether or not it can be realized by a deterministic top-down tree transducer
that is either
linear
or
uniform-copying
.
Note that, using results of this paper (or more precisely its predecessor
[
24
]
)
it was shown recently that for an arbitrary deterministic top-down tree transducer
with look-ahead it is decidable whether or not it can be realized by a

linear
transducer
[
31
]
.

One may wonder if our results imply that for a given deterministic bottom-up tree
transducer
U
it is decidable whether or not it can be realized by an

arbitrary
deterministic top-down tree transducer,
i.e., if
U
can be realized by a top-down transducer, can it also be realized by
a
uniform-copying

such transducer?
Interestingly, this is
not
necessarily the case:
let
h_{a},h_{b}
be look-ahead states that indicate that the left-most
leaf of the input tree is labeled
a
or
b
, respectively, and consider
a transducer
U
which has rules (for every
h\in\{h_{a},h_{b}\}
):

\begin{array}[]{l@{\qquad}l}q_{0}(f(x_{1}:h_{a},x_{2}:h))\to g(a,b,q_{\text{id}}(x_{2}))\\
q_{0}(f(x_{1}:h_{b},x_{2}:h))\to g(c,d,q_{\text{id}}(x_{2}))\end{array}

The corresponding translation
can
be realized by a deterministic
top-down tree transducer! However, there is no uniform-copying top-down tree transducer that
realizes the translation realized by
U
: viz.,
the output leaves
a
and
b
must be produced by different states, but
both on the input variable
x_{1}
.
It remains open
whether the methods of this paper can be generalized so that the existence of equivalent
possibly
non-uniform-copying
transducers without look-ahead can be decided.
The results reported here all refer to the question inhowfar look-ahead can be removed altogether.
As a natural extension, however, is to ask whether a smaller look-ahead automation suffices to
realize a given translation or, whether a unique
minimal
such automaton exists.
