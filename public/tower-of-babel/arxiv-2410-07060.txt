Token sliding independent set reconfiguration on block graphs
Mathew C. Francis, Veena Prabhakaran

Abstract
Let S S be an independent set of a simple undirected graph G G . Suppose that each vertex of S S has a token placed on it. The tokens are allowed to be moved, one at a time, by sliding along the edges of G G , so that after each move, the vertices having tokens always form an independent set of G G . We would like to determine whether the tokens can be eventually brought to stay on the vertices of another independent set S ′ S^{\prime} of G G in this manner. In other words, we would like to decide if we can transform S S into S ′ S^{\prime} through a sequence of steps, each of which involves substituting a vertex in the current independent set with one of its neighbours to obtain another independent set. This problem of determining if one independent set of a graph “is reachable” from another independent set of it is known to be PSPACE-hard even for split graphs, planar graphs, and graphs of bounded treewidth. Polynomial time algorithms have been obtained for certain graph classes like trees, interval graphs, claw-free graphs, and bipartite permutation graphs. We present a polynomial time algorithm for the problem on block graphs, which are the graphs in which every maximal 2-connected subgraph is a clique. Our algorithm is the first generalization of the known polynomial time algorithm for trees to a larger class of graphs (note that trees form a proper subclass of block graphs).

A

The “independent set reconfiguration” problem can defined as follows.
Suppose that
G
is a graph and
C,C^{\prime}
are two independent sets of
G

C

C^{\prime}
. Each transformation step must be in accordance with a predetermined set of rules, and at the end of the move, the vertices having tokens on them have to again form an independent set of
G
. Based on the set of rules governing the transformation steps, mainly three types of independent set reconfiguration problems have been studied in the literature — namely, the “token sliding”
[
5
,
30
]
, the “token jumping”
[

,
30
]
and the “token addition/removal”
[

]
independent set reconfiguration problems.
(Note that these three models have been studied also for reconfiguration problems other than the independent set reconfiguration problem
[
28
,
27
,
16
,

It has been shown that the token jumping and the token addition/removal models are equivalent for independent set reconfiguration
[
29
]
. In the token sliding model introduced by Hearn and Demaine
[
17

, which will be the focus of our study, the only allowed transformation step is the movement of a token from the vertex it is on to one of its neighbours (the token can be imagined to be “sliding” along the edge between them in the graph).

Formally, in the token sliding model for the independent set reconfiguration problem, given a graph
G
and two independent sets
C,C^{\prime}
of

and edge

(in this case,

The problem

Later, the problem was shown to be PSPACE-complete even for perfect graphs by Kamiński, Medvedev and Milanič

[

[

Demaine et al.
[
12

A

is an undirected graph in which each biconnected component is a clique.
Block graphs form a subclass of chordal graphs and a superclass of trees. We prove that

It is worth noting that our algorithm is the first generalization of the polynomial time algorithm of Demaine et al. for trees, since none of the other classes for which polynomial time algorithms for the problem have been obtained contains the class of trees. (It was claimed in

Our contribution

In this paper, we present a polynomial time algorithm for
TS-Ind-set reconfig
on block graphs. Our algorithm takes as input a block graph
G
and two independent sets
C_{1},C_{2}
of
G
and determines in
O(|E(G)|^{4})
time whether the independent set
C_{1}
can be transformed into the independent set
C_{2}
using token sliding.

Our algorithm is a generalization of the polynomial-time algorithm for trees given in
[
12
]
. The algorithm for trees first determines which tokens are “rigid” in both input independent sets. A token in an independent set is said to be rigid if it cannot be moved from its position by any sequence of valid token movements. Determining which tokens in an independent set are rigid is not very difficult for trees — a token on a vertex
u
is rigid if every neighbour
v
of
u
has a neighbour
x
other than
u
itself that has a token that is rigid for the tree in the forest
T-\{v\}
containing
x
. This implies that it can be determined in linear time whether a token is rigid. Clearly, two independent sets whose set of vertices containing rigid tokens are unequal cannot be reconfigured with each other. Even if the vertices having rigid tokens is the same for both independent sets, if the two independent sets have an unequal number of tokens in any connected component that is obtained by the removal of the vertices containing the rigid vertices, it can be concluded that the independent sets are not reconfigurable with each other. It is shown in
[
12
]
that any two independent sets for which the rigid tokens are on exactly the same vertices, and for whom removal of these vertices creates a graph that contains the same number of tokens from each independent set in each connected component can be reconfigured with each other. Further, their proof yields an algorithm that outputs a reconfiguration sequence of length
O(n^{2})
between the two input independent sets. Note that the result above implies that any two independent sets in a tree that have the same cardinality and contain no rigid tokens, are reconfigurable with each other.

Even though similar to trees at first sight, the problem on block graphs presents many difficulties that hinder the construction of a polynomial-time algorithm similar to the one in
[
12
]
. For example, unlike for trees, two independent sets in a block graph that have the same cardinality and have no rigid tokens may not be reconfigurable with each other; see Figure
5(a)
, or Figure 12 of
[
12
]
. This hints that instead of rigidity of tokens, one should perhaps find out which tokens are “trapped” within the blocks they are in (this is similar to the notion of “confined” tokens in
[
23
]
). However, determining which tokens are trapped in their blocks turns out to be not so straightforward.

A more important difference is perhaps the fact that in a block graph, there can be situations in which to insert one additional token into a branch of the block graph, an arbitrary number of tokens may first need to be taken out of that branch — a situation that never arises for a tree. Reachability

For two independent sets
I_{1},I_{2}
of
G
, we say that “
I_{1}\rightarrow I_{2}
” if one of the following holds:

•

I_{1}=I_{2}
, or

•

\exists v_{1},v_{2}\in V(G)
such that
I_{1}\setminus I_{2}=\{v_{1}\}
,
I_{2}\setminus I_{1}=\{v_{2}\}
and
v_{1}v_{2}\in E(G)
.

Note that the relation
\rightarrow
is symmetric and reflexive.
For independent sets

of a graph

I^{\prime}

is reachable from

if there exist independent sets

Also, since the relation

, we have that two independent sets of

that are reachable from each other are of the same cardinality.

Block graphs

A

A

A

Observation 3

If

4
Token movement: the local view around a cut-vertex

We present some lemmas that will be helpful in the movement of tokens with respect to a given cut-vertex of the graph.
For the whole of this section, we assume that
G
is a connected block graph.

Lemma 1
.

Let
p\in\{(u,B),(B,u)\}
, where
u\in V_{cut}(G)
and
B\in\mathcal{B}_{u}(G)
, and
C
be a
p
-independent set of
G
. Then the following statements are true:

(i)

cap(C)\geq 0
.

(ii)

If
ua(p)=True
and
u
is not under attack in
C
, then
cap(C)>0
.

Proof.

We prove this by induction on
d(p)
. For the base case, we consider the case when
d(p)=0
. Then we have from Observation
5
that
cap(C)=1-|\overline{C}|
. From Definition
1
, we know that
G[p]
is a complete graph. This implies that
|\overline{C}|\in\{0,1\}
, from which it follows that
cap(C)\geq 0
. If
u
is not under attack in
C
, then
|\overline{C}|=0
, and therefore
cap(C)=1-|\overline{C}|=1>0
. For the inductive step, we assume that for any
p^{\prime}\in\mathcal{P}
with
d(p^{\prime})<d(p)
, statements
(i)
and
(ii)
both hold.

Proof of
(i)
:

Suppose that
p=(u,B)
for some
u\in V_{cut}(G)
and
B\in\mathcal{B}_{u}(G)
. By Definition
1
, we know that
d(B^{\prime},u)<d(p)
for each
B^{\prime}\in\beta(p)
. Then by the induction hypothesis on statement
(i)
, we have that
cap(C[B^{\prime},u])\geq 0
for each
B^{\prime}\in\beta(p)
. If there exists
B^{\prime}\in\beta(p)
such that
cap(C[B^{\prime},u])=0
and
ua(B^{\prime},u)=True
, then we have by Definition
3
that
cap(C)=0
, and so we are done. So we can assume that for each
B^{\prime}\in\beta(p)
, either
cap(C[B^{\prime},u])>0
or
ua(B^{\prime},u)=False
. It then follows that
\sum_{B^{\prime}\in\beta(p)}(cap(C[B^{\prime},u])-ua(B^{\prime},u))\geq 0
, which implies by Definition
3
that
cap(C)\geq 0
, and we are done. Next, suppose that
p=(B,u)
. We assume for the sake of contradiction that
cap(C)<0
. Again, we have by Definition
1
that
d(v,B)<d(p)
for each
v\in\kappa(p)
. By the induction hypothesis on statement
(i)
, we then have that
cap(C[v,B])\geq 0
for each
v\in\kappa(p)
. Then from Definition
3
and the assumption that
cap(C)<0
, we have that
ua(p)=False
,
|B\cap\overline{C}|=1
and
cap(C[v,B])=0
for each
v\in\kappa(p)
. Let
B\cap\overline{C}=\{v\}
(clearly
u\neq v
since
C
is a
(B,u)
-independent set of
G
and therefore
u\notin\overline{C}
).
Since
ua(p)=False
, we have from Definition
2
that
B=\kappa(B,u)\cup\{u\}
and that
ua(v,B)=True
. The former implies that
v\in\kappa(B,u)
, and then as observed before, we have
cap(C[v,B])=0
. As we have
d(v,B)<d(B,u)
from Definition
1
, we conclude using the induction hypothesis on statement
(ii)
that
v
is under attack in
C[v,B]
. This is a contradiction to the fact that
v\in C
.

Proof of
(ii)
:

First, suppose that
p=(B,u)
for some
u\in V_{cut}(G)
and
B\in\mathcal{B}_{u}(G)
. Since
u
is not under attack in
C
, we have that
|B\cap\overline{C}|=0
. As before, we have
d(v,B)<d(B,u)
for each
v\in\kappa(p)
, and therefore we have by the induction hypothesis on statement
(i)
that
cap(C[v,B])\geq 0
for each
v\in\kappa(p)
. Then since
ua(p)=True
, we have from Definition
3
that
cap(C)>0
, and we are done.
Next, suppose that
p=(u,B)
.
Note that since
u
is not under attack in
C
,
u
is not under attack in
C[B^{\prime},u]
for any
B^{\prime}\in\beta(p)
. For each
B^{\prime}\in\beta(p)
such that
ua(B^{\prime},u)=True
, we have
d(B^{\prime},u)<d(p)
, and therefore we have by the induction hypothesis on statement
(ii)
that
cap(C[B^{\prime},u])>0
. Moreover, we have by the induction hypothesis on statement
(i)
that for each
B^{\prime}\in\beta(p)
,
cap(C[B^{\prime},u])\geq 0
. This implies that
\sum_{B^{\prime}\in\beta(p)}(cap(C[B^{\prime},u])-ua(B^{\prime},u))\geq 0
.
Now by Definition
3
and the fact that
ua(p)=True
, we have that
cap(C)>0
.
∎

Lemma 2
.

Let
u\in V_{cut}(G)
and let
C
be an independent set of
G
such that
u\notin C
.
Let
\mathcal{A}\subseteq\mathcal{B}_{u}(G)
and for each
B\in\mathcal{A}
, let
Q_{B}
be a
(B,u)
-independent set of
G
that is strongly accessible from
C[B,u]
. Then
\bigcup_{B\in\mathcal{A}}Q_{B}\cup\bigcup_{B\in\mathcal{B}_{u}(G)\setminus\mathcal{A}}C[B,u]
is an independent set of
G
that is
(\mathcal{A},u)
-reachable from
C
.

Proof.

Let
\mathcal{A}=\{B_{1},B_{2},\ldots,B_{s}\}
. For
i\in\{1,2\ldots,s\}
, we shall abbreviate
Q_{B_{i}}
to just
Q_{i}
for ease of notation.
Let
C_{0}=C
. For
i\in\{1,2,\ldots,s\}
, we inductively define
C_{i}=C_{i-1}[u,B_{i}]\cup Q_{i}
. We claim that for each
i\in\{0,1,\ldots,s\}
,
C_{i}
is an independent set of
G
that is
(\mathcal{A},u)
-reachable from
C
such that for all
j\in\{1,2,\ldots,i\}
,
C_{i}[B_{j},u]=Q
, for all
j\in\{i+1,i+2,\ldots,s\}
,
C_{i}[B_{j},u]=C[B_{j},u]
, and for all
B\in\mathcal{B}_{u}(G)\setminus\mathcal{A}
,
C_{i}[B,u]=C[B,u]
. We prove this claim by induction on
i
. Clearly, when
i=0
, we have
C_{0}=C
, and our claim is trivially true. For the inductive step, we assume that
i>0
and that
C_{i-1}
satisfies the requirements of the claim. From the induction hypothesis, we have that
C_{i-1}[B_{i},u]=C[B_{i},u]
. Since
Q_{i}
is strongly accessible from
C[B_{i},u]
, we have that
C_{i}=C_{i-1}[u,B_{i}]\cup Q_{i}
is
(B_{i},u)
-reachable from
C_{i-1}=C_{i-1}[u,B_{i}]\cup C[B_{i},u]
, and hence by Observation
6
, we have that
C_{i}
is
(\mathcal{A},u)
-reachable from
C_{i-1}
. Since
C_{i-1}
is
(\mathcal{A},u)
-reachable from
C
by the induction hypothesis, we now have that
C_{i}
is
(\mathcal{A},u)
-reachable from
C
.
It is clear from the definition of
C_{i}

that for all
j\in\{1,2,\ldots,i-1\}
, we have
C_{i}[B_{j},u]=C_{i-1}[B_{j},u]=Q_{j}
, that
C_{i}[B_{i},u]=Q_{i}
, and that for each
j\in\{i+1,i+2,\ldots,s\}
, we have
C_{i}[B_{j},u]=C_{i-1}[B_{j},u]=C[B_{j},u]
. Clearly, for any
B\in\mathcal{B}_{u}(G)\setminus\mathcal{A}
,
C_{i}[B,u]=C_{i-1}[B,u]=C[B,u]
. This proves the claim. Then
C_{s}
is an independent set of
G
that is
(\mathcal{A},u)
-reachable from
C
such that for each
i\in\{1,2,\ldots,s\}
,
C_{s}[B_{i},u]=Q_{i}
and for each
B\in\mathcal{B}_{u}(G)\setminus\mathcal{A}
,
C_{s}[B,u]=C[B,u]
. The proof is completed by noting that
C_{s}=\bigcup_{B\in\mathcal{A}}Q_{B}\cup\bigcup_{B\in\mathcal{B}_{u}(G)\setminus\mathcal{A}}C[B,u]
.
∎

Lemma 3
.

Let
u\in V_{cut}(G)
,
B\in\mathcal{B}_{u}(G)
and
p\in\{(B,u),(u,B)\}
.
Let
Q
be a
p
-independent set of
G
.
If
ua(p)=False
or
cap(Q)>0
, then there exists a
p
-independent set
Q^{\prime}
of
G
that is strongly accessible from
Q
such that
cap(Q^{\prime})\geq cap(Q)
and
u
is not under attack in
Q^{\prime}
.

Proof.

If
u
is not under attack in
Q
, then the statement of the lemma is trivially true as we can just set
Q^{\prime}=Q
.
So we assume that
u
is under attack in
Q
, which implies that
u\notin Q
.

We use induction on
d(p)
. As the base case, we consider the case when
d(p)=0
. Then by Observation
5
, we have that
cap(Q)=1-|\overline{Q}|
. As
u
is under attack in
Q
, and
G[p]
is a complete graph by Definition
1
, we have that
|\overline{Q}|=1
. Thus
cap(Q)=1-|\overline{Q}|=0
. Since
ua(p)=True
by Definition
2
, we can conclude that the statement of the lemma is vacuously true. For the inductive step, we assume that
d(p)>0
. We shall assume inductively that the statement of the lemma holds for any
p^{\prime}\in\mathcal{P}
such that
d(p^{\prime})<d(p)
.

Suppose that
p=(u,B)
. Let
\beta(u,B)=\{B_{1},B_{2},\ldots,B_{s}\}
. If there exists
i\in\{1,2,\ldots,s\}
such that
ua(B_{i},u)=True
and
cap(Q[B_{i},u])=0
, then by Definition
3
, we have that
cap(Q)=0
, and by Definition
2
, we have
ua(p)=True
. Then the statement of the lemma is vacuously true, and we are done. So using Lemma
1
(i)
, we can assume that for each
i\in\{1,2,\ldots,s\}
, we have either
ua(B_{i},u)=False
or
cap(Q[B_{i},u])>0
.
Then by the induction hypothesis, we know that for each
i\in\{1,2,\ldots,s\}
, there exists a
(B_{i},u)
-independent set

of
G
that is strongly accessible from

such that
u
is not under attack in
Q_{i}
and

.

Consider any
(B,u)
-independent set
R
of
G
that is compatible with
Q
; i.e.
u\notin R
. Let
D=Q\cup R
. Clearly, for each

, we have that

, which means that

is a
(B_{i},u)
-independent set that is strongly accessible from

such that

.
By applying Lemma

(setting

,
\mathcal{A}=\beta(u,B)=\{B_{1},B_{2},\ldots,B_{s}\}
,

for each

), we have that

is an independent set of
G
that is
(u,B)
-reachable from
D
.
Thus for any
(B,u)
-independent set
R
of

that is compatible with

, we have that

is
(u,B)
-reachable from

.
This means that
D^{\prime}[u,B]
is strongly accessible from

. Further,
D^{\prime}[u,B]=Q_{1}\cup Q_{2}\cup\cdots\cup Q_{s}
, and therefore
u
is not under attack in

. As
cap(D^{\prime}[B_{i},u])=cap(Q_{i})\geq cap(D[B_{i},u])
for each

, we have from Definition

that
cap(D^{\prime}[u,B])\geq cap(D[u,B])=cap(Q)
. Thus

is a
(u,B)
-independent set that is strongly accessible from

such that

is not under attack in
Q^{\prime}
and
cap(Q^{\prime})\geq cap(Q)
. This completes the proof for the case
p=(u,B)
.

Next, suppose
p=(B,u)
. Suppose that either
cap(Q)>0
or
ua(B,u)=False
.
Let
R
be a
(u,B)
-independent set of
G
that is compatible with
Q
(equivalently,

) and let

. Notice that since

is under attack in

, we have that

.
If
cap(Q)>0
, then we have by Definition
3
that there exists

such that

again implies that there exists

Since

is
(v,B)
-reachable from

is

-reachable from

Then

is an independent set of

that is
(B,u)
-reachable from

D_{i}[u,B]=D_{i-1}[u,B]=\cdots=D_{0}[u,B]=R
. This implies that
D_{k}=D_{k}[B,u]\cup D_{k}[u,B]=C_{k}[B,u]\cup R
. Now, it only remains to be shown that
D_{i-1}\rightarrow D_{i}
for each
i\in\{1,2,\ldots,k\}
. If
C_{i}=C_{i-1}
, then
D_{i}=D_{i-1}
, and therefore we have
D_{i-1}\rightarrow D_{i}
. So suppose that
C_{i}\neq C_{i-1}
. Then there exists
B^{\prime}\in\mathcal{B}_{u}(G)
such that
(C_{i-1}\setminus C_{i})\cup(C_{i}\setminus C_{i-1})\subseteq V(G[B^{\prime},u])\setminus\{u\}
.
If
B^{\prime}\neq B
, then we have
D_{i-1}=D_{i}
, and therefore
D_{i-1}\rightarrow D_{i}
, and we are again done.
So we can assume that
B^{\prime}=B
. Recall that we have
D_{i}[B,u]=C_{i}[B,u]
,
D_{i-1}[B,u]=C_{i-1}[B,u]
, and
D_{i}[u,B]=D_{i-1}[u,B]
. Recall that
C_{i-1}[B,u]\setminus C_{i}[B,u]=\{v_{1}\}
,
C_{i}[B,u]\setminus C_{i-1}[B,u]=\{v_{2}\}
, where
C_{i-1}\setminus C_{i}=\{v_{1}\}
,
C_{i}\setminus C_{i-1}=\{v_{2}\}
, and
v_{1}v_{2}\in E(G)
. We now have that
D_{i-1}[B,u]\setminus D_{i}[B,u]=\{v_{1}\}
,
D_{i}[B,u]\setminus D_{i-1}[B,u]=\{v_{2}\}
, and
D_{i}[u,B]=D_{i-1}[u,B]
. Thus,
D_{i-1}\setminus D_{i}=\{v_{1}\}
and
D_{i}\setminus D_{i-1}=\{v_{2}\}
. Since
v_{1}v_{2}\in E(G)
, we now have that
D_{i-1}\rightarrow D_{i}
. This implies that
D_{0}\rightarrow D_{1}\rightarrow\cdots\rightarrow D_{k}
, and we are done.
∎

Corollary 1
.

Let
C_{0},C_{1},\ldots,C_{k}
, where
k\geq 0
, be independent sets of
G
such that
C_{0}\rightarrow C_{1}\rightarrow\cdots\rightarrow C_{k}
, and
u\in V_{cut}(G)
. If
u\notin C_{0}\cup C_{1}\cup\cdots\cup C_{k}
, then:

(i)

for each
B\in\mathcal{B}_{u}(G)
, we have
|\overline{C_{0}[B,u]}|=|\overline{C_{k}[B,u]}|
and
|\overline{C_{0}[u,B]}|=|\overline{C_{k}[u,B]}|
, and

(ii)

for any
\mathcal{A}\subseteq\mathcal{B}_{u}(G)
,
\bigcup_{B\in\mathcal{A}}C_{k}[B,u]\cup\bigcup_{B\notin\mathcal{A}}C_{0}[B,u]
is
(\mathcal{A},u)
-reachable from
C_{0}
.

Proof.

We prove the two statements separately.

Proof of
(i)
:
Let
B\in\mathcal{B}_{u}(G)
. Since we have by Lemma
6
that
C_{k}[B,u]
is strongly accessible from
C_{0}[B,u]
, we have by Observation
7
that
|C_{k}[B,u]|=|C_{0}[B,u]|
. As
u\notin C_{0}\cup C_{1}\cup\cdots\cup C_{k}
, we now have
|\overline{C_{0}[B,u]}|=|C_{0}[B,u]|=|C_{k}[B,u]|=|\overline{C_{k}[B,u]}|
. Since
|C_{0}|=|C_{k}|
, it now follows that
|\overline{C_{0}[u,B]}|=|C_{0}|-|\overline{C_{0}[B,u]}|=|C_{k}|-|\overline{C_{k}[B,u]}|=|\overline{C_{k}[u,B]}|
.

Proof of
(ii)
:

Let
\mathcal{A}\subseteq\mathcal{B}_{u}(G)
. For each
B\in\mathcal{A}
, define
Q_{B}=C_{k}[B,u]
. It follows from Lemma
6
that for each
B\in\mathcal{A}
,
Q_{B}
is strongly accessible from
C_{0}[B,u]
. We now have from Lemma
2
that
\bigcup_{B\in\mathcal{A}}C_{k}[B,u]\cup\bigcup_{B\notin\mathcal{A}}C_{0}[B,u]
is
(\mathcal{A},u)
-reachable from
C_{0}
.
∎

Observation 9
.

Let

. For

, and therefore,
\mathbf{x}[p]=y^{(t)}[p]\geq y^{(1)}[p]=0

Observation 10

For every

, there exists
p^{\prime}\in\mathcal{P}
such that
y^{(i)}[p^{\prime}]>y^{(i-1)}[p^{\prime}]
and

Consider the last iteration of the
while
loop. Since this is the last iteration of the
while
loop, line
1
is not executed during this iteration. This means that the
break
statement of line
1
is never executed during this iteration, which further implies that the
for
loop of line
1
gets executed for every
p\in\mathcal{P}
.

Lemma 7
.

Let
u\in V_{cut}(G)
and
B\in\mathcal{B}_{u}(G)
. Then

\sum\limits_{\forall u^{\prime}\in\kappa(B,u)}\mathbf{x}[u^{\prime},B]+ua(B,u)-|B\cap\overline{C[B,u]}|\geq 0

Proof.

Suppose for the sake of contradiction that for some
u\in V_{cut}(G)
and
B\in\mathcal{B}_{u}(G)
, we have
\sum\limits_{\forall u^{\prime}\in\kappa(B,u)}\mathbf{x}[u^{\prime},B]+ua(B,u)-|B\cap\overline{C[B,u]}|<0
. Then

\sum\limits_{\forall u^{\prime}\in\kappa(B,u)}y^{(t)}[u^{\prime},B]+ua(B,u)-|B\cap\overline{C[B,u]}|<0
. By Observation
9
, we have that
y^{(t)}[u^{\prime},B]\geq 0
for each
u^{\prime}\in\kappa(B,u)
, which implies that
|B\cap\overline{C[B,u]}|=1
,
ua(B,u)=False
, and
y^{(t)}[u^{\prime},B]=0
for each
u^{\prime}\in\kappa(B,u)
. Let
B\cap\overline{C[B,u]}=\{v\}
. By Definition
2
, we now have that
v\in\kappa(B,u)
and
ua(v,B)=True
. Note also that
y^{(t)}[v,B]=0
. Let
\mathcal{B}_{v}^{T}=\{B^{\prime}\in\mathcal{B}_{v}(G)\colon ua(B^{\prime},v)=True\}
(note that it is possible that
B\in\mathcal{B}_{v}^{T}
). Let
B^{\prime}\in\mathcal{B}_{v}^{T}
. As
v\in C
, we have that
B^{\prime}\cap\overline{C[B^{\prime},v]}=\emptyset
.
Since the
for
loop gets executed for each
p\in\mathcal{P}
during the last iteration of the
while
loop, we have that line
1
gets executed for
p=(B^{\prime},v)
during the last iteration of the
while
loop. The value of
y^{\prime}
that gets computed at this step is greater than 0 since
ua(B^{\prime},v)=True
,
B^{\prime}\cap\overline{C[B^{\prime},v]}=\emptyset
, and
y^{(t)}[u^{\prime},B^{\prime}]\geq 0
for all
u^{\prime}\in\kappa(B^{\prime},v)
by Observation
9
. Since line
1
is not executed subsequently, this means that the value of
y[B^{\prime},v]
at this point of time, which is
y^{(t)}[B^{\prime},v]
, is greater than the value of
y^{\prime}
, and is therefore greater than 0. Thus, we have that for each
B^{\prime}\in\mathcal{B}_{v}^{T}
,
y^{(t)}[B^{\prime},v]>0
.
This means that line
1
gets executed for
p=(v,B)
during the last iteration of the
while
loop. Since
ua(v,B)=True
,
y^{(t)}[B^{\prime},v]\geq 0
for each
B^{\prime}\in\beta(v,B)
(by Observation
9
), and
y^{(t)}[B^{\prime},v]-ua(B^{\prime},v)\geq 0
for each
B^{\prime}\in\mathcal{B}_{v}^{T}
, we have that the value of the variable
y^{\prime}
computed during this execution of line
1
is positive. As
y^{(t)}[v,B]=0
, line
1
would have subsequently been executed, which contradicts the fact that this is the last iteration of the
while
loop.
∎

Lemma 8
.

For any
u\in V_{cut}(G)
and
B\in\mathcal{B}_{u}(G)
,

\mathbf{x}[B,u]=\sum\limits_{\forall u^{\prime}\in\kappa(B,u)}\mathbf{x}[u^{\prime},B]+ua(B,u)-|B\cap\overline{C[B,u]}|

Proof.

Let
u\in V_{cut}(G)
and
B\in\mathcal{B}_{u}(G)
.
Note that line
1
is not executed during the last iteration of the
while
loop, and that the
for
loop is executed for every
p\in\mathcal{P}
in the last iteration. It follows that the value of
y^{\prime}
that is computed in line
1
when
p=(B,u)
, during the last iteration of the
while
loop, is at most the value of the variable
y[B,u]
at that point, which is equal to
y^{(t)}[B,u]
. So we get
y^{(t)}[B,u]\geq\sum\limits_{\forall u^{\prime}\in\kappa(B,u)}y^{(t)}[u^{\prime},B]+ua(B,u)-|B\cap\overline{C[B,u]}|
. We thus have
\mathbf{x}[B,u]\geq\sum\limits_{\forall u^{\prime}\in\kappa(B,u)}\mathbf{x}[u^{\prime},B]+ua(B,u)-|B\cap\overline{C[B,u]}|
.
Let
i
be the smallest integer in
\{1,2,\ldots,t\}
such that
y^{(i)}[B,u]=\mathbf{x}[B,u]
. Clearly,
i
exists since
y^{(t)}[B,u]=\mathbf{x}[B,u]
. Suppose that
i>1
. By our choice of

, we have
y^{(i-1)}[B,u]<y^{(i)}[B,u]
, which implies that the variable

is assigned the value
\mathbf{x}[B,u]
during an execution of line
1
of the
(i-1)
-th iteration of the

y^{\prime}
at that point of time is equal to
\sum\limits_{\forall u^{\prime}\in\kappa(B,u)}y^{(i-1)}[u^{\prime},B]+ua(B,u)-|B\cap\overline{C[B,u]}|
, which is computed during the previous execution of line

, and it is this value that is assigned to

.
We thus get

\displaystyle\mathbf{x}[B,u]=y^{(i)}[B,u]

\displaystyle=

\displaystyle\sum\limits_{\forall u^{\prime}\in\kappa(B,u)}y^{(i-1)}[u^{\prime},B]+ua(B,u)-|B\cap\overline{C[B,u]}|

\displaystyle\sum\limits_{\forall u^{\prime}\in\kappa(B,u)}y^{(t)}[u^{\prime},B]+ua(B,u)-|B\cap\overline{C[B,u]}|\mbox{ (by Observation~\ref{obs:ymonotone})}

Lemma 9
.

For any
u\in V_{cut}(G)
and
B\in\mathcal{B}_{u}(G)
,

The argument is similar to that in the previous proof.
Let

and

.
Suppose that
\exists B^{\prime},B^{\prime\prime}\in\mathcal{B}_{u}(G)

\mathbf{x}[B^{\prime},u]=\mathbf{x}[B^{\prime\prime},u]=0

does not get executed for the pair

in any iteration of the

\nexists B^{\prime},B^{\prime\prime}\in\mathcal{B}_{u}(G)
such that
\mathbf{x}[B^{\prime},u]=\mathbf{x}[B^{\prime\prime},u]=0
and
ua(B^{\prime},u)=ua(B^{\prime\prime},u)=True
; this means that
\nexists B^{\prime},B^{\prime\prime}\in\mathcal{B}_{u}(G)

gets executed for the pair

during the last iteration of the

5.1
Time complexity of the algorithm

Lemma 10
.

For any
p\in\mathcal{P}
,
\mathbf{x}[p]\leq|\mathcal{B}(G[p])|
.

Proof.

We prove this by induction on
d(p)
. For the base case, observe that if
d(p)=0
, then
p=(B,u)
for some
u\in V_{cut}(G)
and
B\in\mathcal{B}_{u}(G)
,
ua(B,u)=True
, and
G[B,u]
is a complete graph. Then we have by Lemma
8
that
\mathbf{x}[p]=1-|B\cap\overline{C[B,u]}|\leq 1=|\mathcal{B}(G[B,u])|
. This proves the base case. For the inductive step, let us assume that for all
p^{\prime}\in\mathcal{P}
such that
d(p^{\prime})<d(p)
, the statement of the lemma is true. Suppose that
p=(B,u)
for some
u\in V_{cut}(G)
and
B\in\mathcal{B}_{u}(G)
. Then from Lemma
8
, we have that
\mathbf{x}[B,u]=\sum\limits_{\forall u^{\prime}\in\kappa(B,u)}\mathbf{x}[u^{\prime},B]+ua(B,u)-|B\cap\overline{C[B,u]}|
. Since
d(u^{\prime},B)<d(B,u)
for all
u^{\prime}\in\kappa(B,u)
, we can use the induction hypothesis to conclude that
\mathbf{x}[B,u]\leq\sum\limits_{\forall u^{\prime}\in\kappa(B,u)}|\mathcal{B}(G[u^{\prime},B])|+ua(B,u)-|B\cap\overline{C[B,u]}|
. It is easy to see that
|\mathcal{B}(G[B,u])|=1+\sum\limits_{\forall u^{\prime}\in\kappa(B,u)}|\mathcal{B}(G[u^{\prime},B])|
. We thus have that
\mathbf{x}[B,u]\leq|\mathcal{B}(G[B,u])|-1+ua(B,u)-|B\cap\overline{C[B,u]}|\leq|\mathcal{B}(G[B,u])|
.
Next, suppose that
p=(u,B)
for some
u\in V_{cut}(G)
and
B\in\mathcal{B}_{u}(G)
. Then we have by Lemma
9
that either
\mathbf{x}[u,B]=0
or
\mathbf{x}[u,B]=\sum\limits_{\forall B^{\prime}\in\beta(u,B)}\Big(\mathbf{x}[B^{\prime},u]-ua(B^{\prime},u)\Big)+ua(u,B)
. In the former case, we are done since
|\mathcal{B}(G[u,B])|\geq 0
. So we assume that
\mathbf{x}[u,B]=\sum\limits_{\forall B^{\prime}\in\beta(u,B)}\Big(\mathbf{x}[B^{\prime},u]-ua(B^{\prime},u)\Big)+ua(u,B)
. Since
d(B^{\prime},u)<d(u,B)
for all
B^{\prime}\in\beta(u,B)
, we have by the induction hypothesis that
\mathbf{x}[u,B]\leq\sum\limits_{\forall B^{\prime}\in\beta(u,B)}\Big(|\mathcal{B}(G[B^{\prime},u])|-ua(B^{\prime},u)\Big)+ua(u,B)
. It can be seen from Definition
2
that if
ua(B^{\prime},u)=True
for any
B^{\prime}\in\beta(u,B)
, then
ua(u,B)=True
. Since

Lemma 11

24

Lemma 13
.

Let
p\in\mathcal{P}
.
There exists an independent set
C^{\prime}
of
G
that is reachable from
C
such that
cap(C^{\prime}[p])\geq\mathbf{x}[p]
and
|\overline{C^{\prime}[p]}|=|\overline{C[p]}|
.

Proof.

Note that as
\mathbf{x}[p]=y^{(t)}[p]
, we will be done if we prove the following stronger statement:

Let
p\in\mathcal{P}
. For each
i\in\{1,2,\ldots,t\}
, there exists an independent set
C^{(i)}
that is reachable from
C
such that
C^{(i)}[p]
is
y^{(i)}(\overline{p})
-accessible from
C[p]
,
cap(C^{(i)}[p])\geq y^{(i)}[p]
,
C^{(i)}[\overline{p}]
is
y^{(i)}[p]
-accessible from
C[\overline{p}]
, and
cap(C^{(i)}[\overline{p}])\geq y^{(i)}[\overline{p}]
.

We prove this statement by induction on
i
. For
i=1
, we have
y^{(i)}[p]=y^{(i)}[\overline{p}]=0
, so we can simply let
C^{(1)}=C
. Suppose that
i>1
and that there is an independent set
C^{(i-1)}
that is reachable from
C
such that
C^{(i-1)}[p]
is
y^{(i-1)}[\overline{p}]
-accessible from
C[p]
,
cap(C^{(i-1)}[p])\geq y^{(i-1)}[p]
,
C^{(i-1)}[\overline{p}]
is
y^{(i-1)}[p]
-accessible from
C[\overline{p}]
, and
cap(C^{(i-1)}[\overline{p}])\geq y^{(i-1)}[\overline{p}]
. If
y^{(i)}[p]=y^{(i-1)}[p]
and
y^{(i)}[\overline{p}]=y^{(i-1)}[\overline{p}]
, then we simply let
C^{(i)}=C^{(i-1)}
and we are done. So we can assume by symmetry that
y^{(i)}[p]>y^{(i-1)}[p]
and
y^{(i)}[\overline{p}]=y^{(i-1)}[\overline{p}]
. By Lemma
12
, we have that there exists a
p
-independent set
Q
that is
y^{(i)}[\overline{p}]
-accessible from
C[p]
such that
cap(Q)\geq y^{(i)}[p]
. Since
C^{(i-1)}[p]
is also
y^{(i)}[\overline{p}]
-accessible from
C[p]
, we have that
Q
is
y^{(i)}[\overline{p}]
-accessible from
C^{(i-1)}[p]
. We define
C^{(i)}=Q\cup C^{(i-1)}[\overline{p}]
. Since
cap(C^{(i-1)}[\overline{p}])\geq y^{(i-1)}[\overline{p}]=y^{(i)}[\overline{p}]
, we can conclude that
C^{(i)}
is reachable from
C^{(i-1)}
. Clearly,
C^{(i)}[p]=Q
is
y^{(i)}[\overline{p}]
-accessible from
C[p]
,
cap(C^{(i)}[p])=cap(Q)\geq y^{(i)}[p]
,
C^{(i)}[\overline{p}]=C^{(i-1)}[\overline{p}]
is
y^{(i)}[p]
-accessible from

(since

) and
cap(C^{(i)}[\overline{p}])=cap(C^{(i-1)}[\overline{p}])\geq y^{(i-1)}[\overline{p}]=y^{(i)}[\overline{p}]

∎

Lemma 14

For any independent set
C^{\prime}
of
G

C

\displaystyle\geq

that
u\in C_{0}\cup C_{1}\cup\cdots\cup C_{k}
. Let

since

Corollary 2
.

For each

\mathbf{x}[p]=pot(C,p)

Proof.

Clearly, for each independent set

of

∎

Corollary 3

6
Rigid vertices

Let
G
be a connected block graph and
C
be any independent set of
G
.

Definition 7
.

A vertex
u\in V_{cut}(G)
is said to be
rigid for
C
, if there exist
B,B^{\prime}\in\mathcal{B}_{u}(G)
such that
pot_{G}(C,(B,u))=pot_{G}(C,(B^{\prime},u))=0
and
ua_{G}(B,u)=ua_{G}(B^{\prime},u)=True
.

With the above definition, the following observation follows directly from Corollary
3
(ii)
and Definition
2
.

Observation 11
.

If
u\in V_{cut}(G)
is rigid for
C
, then for all
B\in\mathcal{B}_{u}(G)
,
ua_{G}(u,B)=True
and
pot_{G}(C,(u,B))=0
.

Lemma 15
.

If
u\in V_{cut}(G)
is rigid for an independent set
C
of
G
, then there does not exist any independent set
C^{\prime}
of
G
that is reachable from
C
for which
u\in C^{\prime}
.

Proof.

Since
u
is rigid for
C
we know that there exist
B,B^{\prime}\in\mathcal{B}_{u}(G)
such that
pot_{G}(C,(B,u))=pot_{G}(C,(B^{\prime},u))=0
and
ua_{G}(B,u)=ua_{G}(B^{\prime},u)=True
.
Suppose that there exists an independent set
C^{\prime}
of
G
that is reachable from
C
such that
u\in C^{\prime}
. Let
C_{0},C_{1},\ldots,C_{k}
be independent sets of
G
such that
C=C_{0}\rightarrow C_{1}\rightarrow\cdots\rightarrow C_{k}=C^{\prime}
. Let
i
be the minimum integer in
\{0,1,\ldots,k\}
such that
u\in C_{i}
. If
i=0
, then we clearly have
|\overline{C_{i}[B,u]}|=|\overline{C[B,u]}|
and
|\overline{C_{i}[B^{\prime},u]}|=|\overline{C[B^{\prime},u]}|
. On the other hand, if
i>0
, then since
u\notin C_{0}\cup C_{1}\cup\cdots\cup C_{i-1}
, we know by Corollary
1
(i)
that
|\overline{C_{i-1}[B,u]}|=|\overline{C[B,u]}|
and
|\overline{C_{i-1}[B^{\prime},u]}|=|\overline{C[B^{\prime},u]}|
, and since
C_{i-1}\rightarrow C_{i}
, this implies that either
|\overline{C_{i}[B,u]}|=|\overline{C[B,u]}|
or
|\overline{C_{i}[B^{\prime},u]}|=|\overline{C[B^{\prime},u]}|
. Combining the two cases, we assume without loss of generality that
|\overline{C_{i}[B,u]}|=|\overline{C[B,u]}|
. Since
u\in C_{i}
, we know that
u
is not under attack in
C_{i}[B,u]
. Then since
C_{i}
is reachable from
C
, we have by Definition
6
that
cap(C_{i}[B,u])+|\overline{C_{i}[B,u]}|-|\overline{C[B,u]}|\leq pot_{G}(C,(B,u))=0
, which implies that
cap(C_{i}[B,u])=0
. As
u
is not under attack in
C_{i}[B,u]
, we now have a contradiction to Lemma
1
(ii)
. This completes the proof.
∎

Lemma 16
.

Let
u\in V_{cut}(G)
such that
u
is not rigid for
C
and let
B\in\mathcal{B}_{u}(G)
. If
u
is under attack in
C[u,B]
(i.e.
|N_{G}(u)\cap C[u,B]|\geq 1
), then there is an independent set
C^{\prime}
of
G
that is
(u,B)
-reachable from
C
such that
|N_{G}(u)\cap C^{\prime}[u,B]|=1
.

Proof.

Let
\beta_{G}[u,B]=\{B_{1},B_{2},\ldots,B_{m}\}
.
If there exists
B^{\prime}\in\beta_{G}[u,B]
such that
pot_{G}(C,(B^{\prime},u))=0
and
ua_{G}(B^{\prime},u)=True
, then without loss of generality, we let
B_{1}=B^{\prime}
. Note that in this case, we have from Definition
6
that
cap(C[B_{1},u])=0
. Since
ua_{G}(B_{1},u)=True
, we now have by Lemma
1
(ii)
that
u
is under attack in
C[B_{1},u]
.
On the other hand, if there does not exist
B^{\prime}\in\beta_{G}(u,B)
such that
pot_{G}(C,(B^{\prime},u))=0
and
ua_{G}(B^{\prime},u)=True
, then we assume that
B_{1}
is a block in
\beta_{G}[u,B]
such that
u
is under attack in
C[B_{1},u]
(such a block exists since
u
is under attack in
C[u,B]
). Thus we have that in any case,
u
is under attack in
C[B_{1},u]
.

For each
i\in\{2,3,\ldots,m\}
, we say that the block
B_{i}
is “good” if there exists a
(B_{i},u)
-independent set
Q_{i}
of
G
that is strongly accessible from
C[B_{i},u]
such that
u
is not under attack in
Q_{i}
.

Suppose that
B_{i}
is good for each
i\in\{2,3,\ldots,m\}
.
Then for each
i\in\{2,3,\ldots,m\}
, there exists a
(B_{i},u)
-independent set
Q_{i}
that is strongly accessible from
C[B_{i},u]
in which
u
is not under attack. Applying Lemma
2
(setting
\mathcal{A}=\{B_{2},B_{3},\ldots,B_{m}\}
and
Q_{B_{i}}=Q_{i}
for each
i\in\{2,3,\ldots,m\}
), we get that the independent set
C^{\prime}=C[B_{1},u]\cup Q_{2}\cup Q_{3}\ldots Q_{m}\cup C[B,u]
is
(\{B_{2},B_{3},\ldots,B_{m}\},u)
-reachable from
C
. Then clearly,
|N_{G}(u)\cap C^{\prime}[u,B]|=1
, and by Observation
6
, we have that
C^{\prime}
is
(u,B)
-reachable from
C
.

Next, we consider the case when there exists
i\in\{2,3,\ldots,m\}
such that
B_{i}
is not good; i.e. there does not exist a
(B_{i},u)
-independent set
Q_{i}
of
G
that is strongly accessible from
C[B_{i},u]
such that
u
is not under attack in
Q_{i}
. Without loss of generality, let
B_{2}
be one such block. Since
u
is not rigid for
C
, there exists at most one
B^{\prime}\in\beta_{G}[u,B]
such that
pot_{G}(C,(B^{\prime},u))=0
and
ua_{G}(B^{\prime},u)=True
. Then, from our choice of
B_{1}
, it is clear that
pot_{G}(C,(B_{2},u))>0
. Now, by Corollary
3
(iii)
, there exists an independent set
S
of
G
that is reachable from
C
such that
cap(S[B_{2},u])\geq pot_{G}(C,(B_{2},u))>0
.
Then there exist independent sets
C_{0},C_{1},\ldots,C_{k}
of
G
such that
C=C_{0}\rightarrow C_{1}\rightarrow\cdots\rightarrow C_{k}=S
, where
k\geq 0
, such that
cap(S[B_{2},u])\geq pot_{G}(C,(B_{2},u))>0
. If
u\notin C_{0}\cup C_{1}\cup\cdots\cup C_{k}
, then from Lemma
6
, we get a
(B_{2},u)
-independent set
S[B_{2},u]
of
G
that is strongly accessible from
C[B_{2},u]
such that
cap(S[B_{2},u])>0
. Then we have by Lemma
3
that there exists a
(B_{2},u)
-independent set
Q_{2}
that is strongly accessible from
S[B_{2},u]
, and therefore also from

, in which
u
is not under attack. This contradicts our assumption that
B_{2}
is not good. So we can assume that
u\in C_{0}\cup C_{1}\cup\cdots\cup C_{k}
. Let
j=\min\{i\in\{0,1,\ldots,k\}\colon u\in C_{i}\}
. Since
u\in C_{j}
, we have that
N_{G}(u)\cap C_{j}=\emptyset
. Moreover, since

and
C_{j-1}\rightarrow C_{j}
, we get that
C_{j}\setminus C_{j-1}=\{u\}
and there exists
v\in N_{G}(u)
such that
C_{j-1}\setminus C_{j}=\{v\}
. This implies that
N_{G}(u)\cap C_{j-1}=\{v\}
.

Suppose that
v\notin B_{2}
. Then
C=C_{0}\rightarrow C_{1}\rightarrow\cdots\rightarrow C_{j-1}
,
u\notin C_{0}\cup C_{1}\cup\cdots\cup C_{j-1}
and
u
is not under attack in
C_{j-1}[B_{2},u]
. Then by Lemma
6
, we get that
Q_{2}=C_{j-1}[B_{2},u]
is a
(B_{2},u)
-independent set of
G
that is strongly accessible from

such that
u
is not under attack in

. This again contradicts the fact that

is not good. So we can assume that

. Now, since

and

, by Corollary

(ii)
(setting
\mathcal{A}=\beta_{G}(u,B)=\{B_{1},B_{2},\ldots,B_{m}\}

C^{\prime}=C[B,u]\cup C_{j-1}[B_{1},u]\cup C_{j-1}[B_{2},u]\cup\cdots\cup C_{j-1}[B_{m},u]=C[B,u]\cup C_{j-1}[u,B]

(u,B)
-reachable from

∎

Lemma 17
.

Let
C_{1}
and
C_{2}
be two independent sets of
G
and let
W_{1}
and
W_{2}
be the set of cut-vertices of
G
that are rigid for
C_{1}
and

respectively. If
C_{2}
is reachable from

, then
W_{1}=W_{2}
.

Proof.

Suppose for the sake of contradiction that
C_{2}
is reachable from
C_{1}
and
W_{1}\neq W_{2}
. We can assume without loss of generality that there exists
u\in W_{1}\setminus W_{2}
.
Then we know that there exists
B\in\mathcal{B}_{u}(G)
such that
ua_{G}(B,u)=True
,
pot_{G}(C_{1},(B,u))=0
, and
pot_{G}(C_{2},(B,u))\geq 1
. By Corollary
3
(iii)
, we have that there is an independent set
C^{\prime}_{2}
that is reachable from
C_{2}
such that

. Since
C_{2}
is reachable from
C_{1}
, we have that
C^{\prime}_{2}
is also reachable from

. Then by Definition

, we get that
cap(C^{\prime}_{2}[B,u])-|\overline{C^{\prime}_{2}[B,u]}|+|\overline{C_{1}[B,u]}|\leq pot_{G}(C_{1},(B,u))=0
, which implies that
|\overline{C^{\prime}_{2}[B,u]}|-|\overline{C_{1}[B,u]}|\geq 1
. Let
D_{0},D_{1},\ldots,D_{k}
be independent sets of

such that
C_{1}=D_{0}\rightarrow D_{1}\rightarrow\cdots\rightarrow D_{k}=C^{\prime}_{2}
. As

, we have from Corollary

(i)
that there exists some

such that

. Then

is an independent set of

and contains the vertex

.
∎

7
Restricting to subgraphs

In this section, we show that given a connected block graph
G
and an independent set
C
of it, there are certain kinds of induced subgraphs
H
of
G
having the property that each potential of
H
has the same value as it had in
G
.

For this section, we assume that
G
is a connected block graph and
C
is an independent set of
G
.
Let
a\in V_{cut}(G)
and
A\in\mathcal{B}_{a}(G)
.
Let
H=G-V(G[a,A])
. It is easy to see that
H
is a connected block graph.
Observe that
\mathcal{B}(H)=(\mathcal{B}(G[A,a])\setminus\{A\})\cup(A\setminus\{a\})
if
|A|>2
and
\mathcal{B}(H)=\mathcal{B}(G[A,a])\setminus\{A\}
if
|A|=2
.
Observe that
V_{cut}(H)\subseteq V_{cut}(G)
.
We now define a function
f_{H,G}:\mathcal{B}(H)\rightarrow\mathcal{B}(G)
.
For each
B\in\mathcal{B}(H)
, we define
f_{H,G}(B)\in\mathcal{B}(G)
as follows.
If
|A|=2
, then we simply define
f_{H,G}(B)=B
for all
B\in\mathcal{B}(H)
. Otherwise, there exists a unique block
A^{\prime}\in\mathcal{B}(H)
such that
A^{\prime}\subseteq A
. Then we define
f_{H,G}(B)
as follows: we define
f_{H,G}(A^{\prime})=A
, and for every
B\in\mathcal{B}(H)\setminus\{A^{\prime}\}
, we define
f_{H,G}(B)=B
. It is easy to verify that for all
B\in\mathcal{B}(H)
,
f_{H,G}(B)
is well defined and
f_{H,G}(B)\in\mathcal{B}(G)
.
For
(u,B)\in\mathcal{P}_{H}
, we abuse notation and define that
f_{H,G}(u,B)=(u,f_{H,G}(B))
, and for
(B,u)\in\mathcal{P}_{H}
, we similarly define
f_{H,G}(B,u)=(f_{H,G}(B),u)
.
Let
C_{H}=C\cap V(H)
.
The following observation is easy to see.

Observation 12
.

Let
B\in\mathcal{B}(G)
. Then
0<|B\cap V(H)|<|B|
if and only if
B=A
.

Lemma 18
.

If
a\notin C
,
pot_{G}(C,(a,A))=0
and
ua_{G}(a,A)=True
, then for each
p\in\mathcal{P}_{H}
, we have
ua_{H}(p)=ua_{G}(f_{H,G}(p))
and
pot_{H}(C_{H},p)=pot_{G}(C,f_{H,G}(p))
.

Proof.

For ease of notation, we abbreviate
f_{H,G}
to just
f
,
pot_{G}(C,p)
, where
p\in\mathcal{P}_{G}
, to just
pot_{G}(p)
, and
pot_{H}(C_{H},p)
, where
p\in\mathcal{P}_{H}
, to just
pot_{H}(p)
in this proof.

We first prove a claim that will be useful.

Claim 3
.

Suppose that
A=\{a,b\}
. Then
ua_{G}(A,b)=False
and
pot_{G}(A,b)=0
.

It follows directly from Definition
2
and the fact that
ua_{G}(a,A)=True
that
ua_{G}(A,b)=False
. Then from Corollary
3
(i)
, the fact that
a\notin C
and
pot_{G}(a,A)=0
, we have that
pot_{G}(A,b)=0
. This proves the claim.

We prove the lemma by induction on
d_{H}(p)
.
For the base case, suppose that
d_{H}(p)=0
.
Then we have
p=(B,u)
for some
u\in V_{cut}(H)
and
B\in\mathcal{B}_{u}(H)
.
We have by Definition
2
that
ua_{H}(p)=ua_{H}(B,u)=True
. Also, we have by Corollary
3
(i)
that
pot_{H}(B,u)=1-|B\cap\overline{C_{H}[B,u]}|
.
Suppose first that
B\not\subseteq A
.
Then we have by our definition of
f
that
f(B,u)=(B,u)
; in particular
B\in\mathcal{B}(G)
and
(B,u)\in\mathcal{P}_{G}
.
If
d_{G}(B,u)=0
, then we have
ua_{G}(f(p))=ua_{G}(B,u)=True
and since
\kappa_{G}(B,u)=\emptyset
, we also have
V(G[B,u])=V(H[B,u])=B
. This implies that
\overline{C[B,u]}=\overline{C_{H}[B,u]}
.
Now by Corollary
3
(i)
, we have that
pot_{G}(f(p))=pot_{G}(B,u)=1-|B\cap\overline{C[B,u]}|=1-|B\cap\overline{C_{H}[B,u]}|=pot_{H}(B,u)
. Thus we are done in this case.
So assume that
d_{G}(B,u)>0
. This means that
\kappa_{G}(B,u)\neq\emptyset
. As
\kappa_{H}(B,u)=\emptyset
, we know that there exists
v\in\kappa_{G}(B,u)
such that
v\notin\kappa_{H}(B,u)
. Let
B^{\prime}\in\mathcal{B}_{v}(G)\setminus\{B\}
. Note that
B^{\prime}\notin\mathcal{B}(H)
; in fact,
B^{\prime}\cap V(H)=\{v\}
. Since
|B^{\prime}|\geq 2
, we have by Observation
12
that
B^{\prime}=A
. Note that this means that
\kappa_{G}(B,u)=\{v\}
and that
\mathcal{B}_{v}(G)=\{B,B^{\prime}\}
. If
|A|>2
, then
|B^{\prime}\cap V(H)|\geq 2
, which means that
B^{\prime}\cap V(H)
is a block of
H
in
\mathcal{B}_{v}(H)
. This contradicts the fact that
v\notin\kappa_{H}(B,u)
. So we can assume that
|A|=2
. We now have by Claim
3
that
pot_{G}(B^{\prime},v)=0
and
ua_{G}(B^{\prime},v)=False
. Now we have by Definition
2
that
ua_{G}(v,B)=False
and by Corollary
3
(ii)
that
pot_{G}(v,B)=0
. Using Definition
2
again, we get that
ua_{G}(B,u)=True
. Further, we now have from Corollary
3
(i)
that
pot_{G}(B,u)=1-|B\cap\overline{C[B,u]}|=1-|B\cap\overline{C_{H}[B,u]}|=pot_{H}(B,u)
, and we are done.
Now consider the case when
B\subseteq A
. Then
f(B)=A
. Clearly, in this case, we have
|A|>2
,
B=A\setminus\{a\}
, and
f(B,u)=(A,u)
. Since
\kappa_{H}(B,u)=\emptyset
, we have
\kappa_{G}(A,u)=\{a\}
. As
ua_{G}(a,A)=False
, we have from Definition
2
that
ua_{G}(A,u)=True
. Moreover, since
pot_{G}(a,A)=0
, we have from Corollary
3
(i)
that
pot_{G}(A,u)=1-|A\cap\overline{C[A,u]}|
. As
a\notin C
, this implies that
pot_{G}(A,u)=1-|B\cap\overline{C_{H}[B,u]}|=pot_{H}(B,u)
. This completes the proof for the base case.

For the inductive step, we assume that for all
p^{\prime}\in\mathcal{P}_{H}
such that
d_{H}(p^{\prime})<d_{H}(p)
, we have
ua_{G}(f(p^{\prime}))=ua_{H}(p^{\prime})
and
pot_{G}(f(p^{\prime}))=pot_{H}(p^{\prime})
.
Suppose first that
p=(u,B)
for some
u\in V_{cut}(H)
and
B\in\mathcal{B}_{u}(H)
. Let us first consider the case when

|\beta_{H}(u,B)|=|\beta_{G}(f(u,B))|
(i.e. it is not the case that
A\in\beta_{G}(u,B)
and
|A|=2
). Then for each
X\in\beta_{H}(u,B)
, we have by the induction hypothesis that
ua_{H}(X,u)=ua_{G}(f(X,u))
and
pot_{H}(X,u)=pot_{G}(f(X,u))
. Then it follows from Corollary
3
(ii)
that
pot_{G}(f(u,B))=pot_{H}(u,B)
. Similarly, it follows from Definition
2
that
ua_{G}(f(u,B))=ua_{H}(u,B)
.
Next, suppose that
A\in\beta_{G}(u,B)
and
|A|=2
. Then by Claim
3
, we have that
ua_{G}(A,u)=False
and
pot_{G}(A,u)=0
. Now it follows from the induction hypothesis and Definition
2
that
ua_{G}(f(p))=ua_{H}(p)
. Similarly, using the induction hypothesis and Corollary
3
(ii)
, we get
pot_{G}(f(p))=pot_{H}(p)
.

Finally, we consider the case when
p=(B,u)
for some
u\in V_{cut}(H)
and
B\in\mathcal{B}_{u}(H)
. By the induction hypothesis, we know that for each
v\in\kappa_{H}(B,u)
,
ua_{H}(v,B)=ua_{G}(f(v,B))
and
pot_{G}(f(v,B))=pot_{H}(v,B)
.
Suppose that
B\not\subseteq A
. In this case, we have
f(B,u)=(B,u)
, and also that
\kappa_{G}(B,u)=\kappa_{H}(B,u)
. It is easy to see that
B=\kappa_{H}(B,u)\cup\{u\}
if and only if
B=\kappa_{G}(B,u)\cup\{u\}
. We now have by Definition
2
and the induction hypothesis that
ua_{G}(f(B,u))=ua_{G}(B,u)=ua_{H}(B,u)
.
Since we have
B\cap\overline{C_{H}[B,u]}=B\cap\overline{C[B,u]}
,
we now have by Corollary
3
(i)
that
pot_{G}(f(B,u))=pot_{H}(B,u)
.
Finally, we consider the case when
B\subseteq A
. Then we have
\kappa_{G}(A,u)=\kappa_{H}(B,u)\cup\{a\}
. It is easy to see that
B=\kappa_{H}(B,u)\cup\{u\}
if and only if
A=\kappa_{G}(A,u)\cup\{u\}
. Since we know that
ua_{G}(a,A)=True
, we now have by Definition
2
that
ua_{G}(f(B,u))=ua_{G}(A,u)=ua_{H}(B,u)
.
Since
a\notin C
, we know that
B\cap\overline{C_{H}[B,u]}=A\cap\overline{C[A,u]}
.
Now, as
pot_{G}(a,A)=0
, we have by Corollary
3
(i)
that
pot_{G}(f(B,u))=pot_{G}(A,u)=pot_{H}(B,u)
.
∎

Putting the pieces together

Lemma 19
.

Let
G
be a connected block graph and
C
be an independent set of
G
.
Let
H
be a connected component of the graph obtained by removing all vertices of
G
that are rigid for
C
. There are no vertices in
H
that are rigid for
C\cap V(H)
.

Proof.

Let
R
denote the set of vertices in
G
that are rigid for
C
. Since
H
is a connected component of
G-R
, it must be the case that
N_{G}(H)\subseteq R
. Let
N_{G}(H)=\{r_{1},r_{2},\ldots,r_{k}\}
.
We now define connected induced subgraphs
G_{0},G_{1},G_{2},\ldots,G_{k}
of
G
, each containing
H
as a subgraph, such that for each
i\in\{0,1,\ldots,k-1\}
,
V(H)\subseteq V(G_{i})
and
\{r_{i+1},r_{i+2},\ldots,r_{k}\}\subseteq V(G_{i})
.
Let
G_{0}=G
.
For
i\in\{1,2,\ldots,k\}
, we define
G_{i}
inductively, assuming that
G_{0},G_{1},\ldots,G_{i-1}
have been defined. By the induction hypothesis, we know that
r_{i},r_{i+1},\ldots,r_{k}\in V(G_{i-1})
.
Then by Observation
4
, there exists a unique block
B_{i}\in\mathcal{B}_{r_{i}}(G_{i-1})
such that
B_{i}\cap V(H)\neq\emptyset
(since
r_{i}\in N_{G}(H)\cap V(G_{i-1})
and
V(H)\subseteq V(G_{i-1})
). We define
G_{i}=G_{i-1}-V(G_{i-1}[r_{i},B_{i}])
. It is easy to see that
G_{i}
is an induced subgraph of
G_{i-1}
, and therefore also of
G
. Moreover, since
G_{i-1}
is connected, it follows that
G_{i}
is also connected. By Observation
4
, we have that that
V(H)\subseteq V(G_{i})
, and also that no vertex in
N_{G}(H)
is in
V(G_{i-1}[r_{i},B_{i}]\setminus\{r_{i}\}
. This implies that
r_{i+1},r_{i+2},\ldots,r_{k}\in V(G_{i})
, as required.

Note that
V(H)\subseteq V(G_{k})
,
G_{k}
is a connected graph, and
N_{G}(H)\cap V(G_{k})=\emptyset
. This implies that
G_{k}=H
.
Since for each
i\in\{1,2,\ldots,k\}
, we have that
G_{i}=V(G_{i-1})-V(G_{i-1}[r_{i},B_{i}]
(recall that
B_{i}\in\mathcal{B}_{r_{i}}(G_{i-1})
), we can define the function
f_{G_{i},G_{i-1}}
as described in the beginning of Section
7
. For ease of notation, we abbreviate
f_{G_{i},G_{i-1}}
to just
f_{i}
, and
pot_{G_{i}}(C\cap V(G_{i}),p)
, where
p\in\mathcal{P}_{G_{i}}
, to just
pot_{i}(p)
for the remainder of this proof.

Claim 4
.

For each
i\in\{1,2,\ldots,k\}
and
p\in\mathcal{P}_{G_{i}}
,
pot_{i}(p)=pot_{i-1}(f_{i}(p))
and
ua_{G_{i}}(p)=ua_{G_{i-1}}(f_{i}(p))
.

We prove this by induction on
i
. As the base case, we consider the case when
i=1
. As
G_{0}=G
and
r_{1}\in R
, we have by Lemma
15
that
r_{1}\notin C
, and by Observation
11
that
pot_{0}(r_{1},B_{1})=0
and
ua_{G}(r_{1},B_{1})=True
. Now since
G_{1}=G-V(G[r_{1},B_{1}])
, we have by Lemma
18
that for any
p\in\mathcal{P}_{G_{1}}
,
ua_{G_{1}}(p)=ua_{G}(f_{1}(p))
and
pot_{1}(p)=pot_{0}(f_{1}(p))
.
For the inductive step, we assume that the claim holds for all
j\in\{1,2,\ldots,k\}
such that
j<i
. Recall that
G_{i}=G_{i-1}-V(G_{i-1}[r_{i},B_{i}])
.
Notice that
(r_{i},B_{i})\in\mathcal{P}_{G_{i-1}}
. By the induction hypothesis, we know that
pot_{i-1}(r_{i},B_{i})=pot_{i-2}(f_{i-1}(r_{i},B_{i}))=pot_{i-2}(r_{i},f_{i-1}(B_{i}))=pot_{i-3}(f_{i-2}(r_{i},f_{i-1}(B_{i})))=pot_{i-3}(r_{i},f_{i-2}\circ f_{i-1}(B_{i}))=\cdots=pot_{0}(r_{i},f_{1}\circ f_{2}\circ\cdots\circ f_{i-1}(B_{i}))
. By the same argument, we also get that
ua_{G_{i-1}}(r_{i},B_{i})=ua_{G}(r_{i},f_{1}\circ f_{2}\circ\cdots\circ f_{i-1}(B_{i}))
. It is easy to see that
f_{1}\circ f_{2}\circ\cdots\circ f_{i-1}(B_{i})\in\mathcal{B}_{r_{i}}(G)
. Since
r_{i}\in R
, we then have by Observation
11
that
pot_{0}(r_{i},f_{1}\circ f_{2}\circ\cdots\circ f_{i-1}(B_{i}))=0
and
ua_{G}(r_{i},f_{1}\circ f_{2}\circ\cdots\circ f_{i-1}(B_{i}))=True
, which implies that
pot_{i-1}(r_{i},B_{i})=0
and
ua_{G_{i-1}}(r_{i},B_{i})=True
. Observe that we have from Lemma
15
that
r_{i}\notin C
, which implies that
r_{i}\notin C\cap V(G_{i-1})
. Now it follows from Lemma
18
that for each
p\in\mathcal{P}_{G_{i}}
,
pot_{i}(p)=pot_{i-1}(f_{i}(p))
and
ua_{G_{i}}(p)=ua_{G_{i-1}}(f_{i}(p))
. This completes the proof of the claim.

From the above claim, we have that for each
p\in\mathcal{P}_{G_{k}}
,
pot_{k}(p)=pot_{0}(f_{1}\circ f_{2}\circ\cdots\circ f_{k}(p))
and
ua_{G_{k}}(p)=ua_{G}(f_{1}\circ f_{2}\circ\cdots\circ f_{k}(p))
. Suppose for the sake of contradiction that there is a vertex
u
that is rigid in
H
for
C\cap V(H)
. Then there exists
B,B^{\prime}\in\mathcal{B}_{u}(H)
such that
pot_{k}(u,B)=pot_{k}(u,B^{\prime})=0
and
ua_{G_{k}}(u,B)=ua_{G_{k}}(u,B^{\prime})=True
(recall that
H=G_{k}
). As observed above, this means that
pot_{0}(u,f_{1}\circ f_{2}\circ\cdots\circ f_{k}(B))=pot_{0}(u,f_{1}\circ f_{2}\circ\cdots\circ f_{k}(B^{\prime}))=0
and
ua_{G}(u,f_{1}\circ f_{2}\circ\cdots\circ f_{k}(B))=ua_{G}(u,f_{1}\circ f_{2}\circ\cdots\circ f_{k}(B^{\prime}))=True
. This implies that
u
is rigid in
G
for
C
, or in other words,
u\in R
. This is a contradiction since
u\in V(H)
and
V(H)\subseteq V(G)\setminus R
.
∎

Lemma 20
.

Let
G
be a connected block graph and
C_{1},C_{2}
be independent sets of
G
. If no cut-vertex of
G
is rigid for
C_{1}
or
C_{2}
, and
|C_{1}|=|C_{2}|
, then
C_{2}
is reachable from
C_{1}
.

Proof.

We prove this lemma using induction on
|C_{1}|=|C_{2}|=r
. As the base case, we assume that
r=1
. Let
C_{1}=\{u\}
and
C_{2}=\{v\}
. Suppose that
P=w_{1}w_{2}\ldots w_{k}
is a path from
u
to
v
in
G
such that
w_{1}=u
and
w_{k}=v
. Since
G
is connected,
P
is guaranteed to exist. Let
D_{1}=C_{1}
. For
i\in\{2,3,\ldots,k\}
, we define
D_{i}=(D_{i-1}\setminus\{w_{i-1}\})\cup\{w_{i}\}
. Clearly,
C_{1}=D_{1}\rightarrow D_{2}\rightarrow\cdots\rightarrow D_{k}=C_{2}
, and hence
C_{2}
is reachable from
C_{1}
. This proves the base case.

For the inductive step, we assume that if no cut-vertex of
G
is rigid for independent sets
C^{\prime}_{1}
and
C^{\prime}_{2}
of
G
, and
|C^{\prime}_{1}|=|C^{\prime}_{2}|<r
, then
C^{\prime}_{2}
is reachable from
C^{\prime}_{1}
. Now, let us prove the lemma for
C_{1}
and
C_{2}
.
We claim that there exists
l\in V_{cut}(G)
such that there exists at most one
B\in\mathcal{B}_{l}(G)
having
\kappa_{G}(B,l)\neq\emptyset
.
Indeed, we can choose as
l
an endpoint of a longest path in
G
whose both endpoints are cut-vertices of
G
. Choose as
L
a block from
\mathcal{B}_{l}(G)\setminus\{B\}
. Note that
G[L,l]
is a complete graph. Let
h\in L\setminus\{l\}
. First, we define independent sets
S_{1},S_{2}
of
G
such that
h\in S_{1}\cap S_{2}
,
S_{1}
is reachable from
C_{1}
, and
S_{2}
is reachable from
C_{2}
.

Let
i\in\{1,2\}
.

If
h\in C_{i}
, then we simply define
S_{i}=C_{i}
and we are done. So we assume that
h\notin C_{i}
. Since
N_{G}(h)\subseteq L
, we know that
|N_{G}(h)\cap C_{i}|\leq 1
. Thus, if there exists
v\in N_{G}(h)\cap C_{i}
, then
S_{i}=(C_{i}\setminus\{v\})\cup\{h\}
is an independent set of
G
such that
C_{i}\rightarrow S_{i}
, and we are done.
So we assume that
(\{h\}\cup N_{G}(h))\cap C_{i}=\emptyset
, or in other words, every vertex in
C_{i}
is at a distance of at least 2 from
h
in
G
.
Choose a vertex
v\in C_{i}
for which the distance between
v
and
h
in
G
is as small as possible. Let
P=w_{1}w_{2}\ldots w_{k}
be the shortest path from
v
to
h
in
G
such that
w_{1}=v
and
w_{k}=h
(thus the distance between
v
and
h
in
G
is
k-1
). Note that by our assumption, we have
k\geq 3
. Since
G
is a block graph, it can be easily seen that
\{w_{2},w_{3},\ldots,w_{k-1}\}\subseteq V_{cut}(G)
, and also that
w_{k-1}=l
. If for some
j\in\{3,4,\ldots,k\}
, there exists a vertex
x\in N_{G}(w_{j})\cap C_{i}
, then

xw_{j}w_{j+1}\ldots w_{k}
is a path in
G
between
x
and
h
having length
k-j+1
. Then
x
is a vertex in
C_{i}
such that the distance between it and
h
in
G
is smaller than the distance between
v
and
h
in
G
, which contradicts the choice of
v
. Therefore,

w_{j}
is not under attack in
C_{i}
, or in other words
N_{G}(w_{j})\cap C_{i}=\emptyset
, for any
j\in\{3,4,\ldots,k\}
.

Let
X\in\mathcal{B}(G)
such that
X
contains the edge
w_{2}w_{3}
. Notice that
w_{2}
is under attack in
C_{i}[w_{2},X]
(as
w_{1}\in C_{i}
). By Lemma
16
, there exists an independent set
D
that is
(w_{2},X)
-reachable from
C_{i}
such that
|N_{G}(w_{2})\cap D[w_{2},X]|=1
.
Let
N_{G}(w_{2})\cap D[w_{2},X]=\{y\}
. Observe that
yw_{2}\ldots w_{k}
is a path from
y
to
h=w_{k}
in
G
. As
D[X,w_{2}]=C_{i}[X,w_{2}]
, we have that
N_{G}(w_{j})\cap D=\emptyset
for each
j\in\{3,4,\ldots,k\}
. Let
D_{1}=D
and
D_{2}=(D_{1}\setminus\{y\})\cup\{w_{2}\}
. For
j\in\{3,4,\ldots,k\}
, we define
D_{j}=(D_{j-1}\setminus\{w_{j-1}\})\cup\{w_{j}\}
. It follows from the observations above that each of
D_{1},D_{2},\ldots,D_{k}
is an independent set of
G
, and we also clearly have
D=D_{1}\rightarrow D_{2}\rightarrow\cdots\rightarrow D_{k}
. We define
S_{i}=D_{k}
. Then
S_{i}
is reachable from
D
, and hence also from
C_{i}
. We also have
h=w_{k}\in D_{k}=S_{i}
.

Recall that
l=w_{k-1}
. Thus
l\in D_{k-1}
, and since
D_{k-1}\rightarrow D_{k}=S_{i}
, we have that
N_{G}(l)\cap S_{i}=\{h\}
. This implies that
S_{i}[l,B]=\{h\}
(recall that
B\in\mathcal{B}_{l}(G)
such that
\kappa_{G}(B,l)\neq\emptyset
). Let
H=G-V(G[l,B])
. Clearly,
H
is a connected block graph. Note that we can define a function
f_{H,G}:\mathcal{P}_{H}\rightarrow\mathcal{P}_{G}
as described in the beginning of Section
7
.
Since each
B^{\prime}\in\beta_{G}(l,B)
is a complete graph, we have by Observation
5
that
ua_{G}(B^{\prime},l)=True
, and so in particular
ua_{G}(L,l)=True
.
Since
h\in S_{i}
, this implies by Corollary
3
(i)
that
pot_{G}(S_{i},(L,l))=0
.
Moreover, since
S_{i}[l,B]=\{h\}
, we have that for each
B^{\prime}\in\beta_{G}(l,B)\setminus\{L\}
,
|\overline{S_{i}[B^{\prime},l]}\cap B^{\prime}|=0
, which implies by Corollary
3
(i)
that
pot_{G}(S_{i},(B^{\prime},l))=1
. Further, we get by Definition
2
that
ua_{G}(l,B)=True
, which implies by Corollary
3
(ii)
that
pot_{G}(S_{i},(l,B))=0
.
Therefore, since
l\notin S_{i}
, we get by Lemma
18
that for each
p\in\mathcal{P}_{H}
,
ua_{H}(p)=ua_{G}(f_{H,G}(p))
and
pot_{H}(S_{i}\cap V(H),p)=pot_{G}(S_{i},f_{H,G}(p))
.

Since
S_{i}
is reachable from
C_{i}
and no vertex is rigid for
C_{i}
, by Lemma
17
it is clear that there does not exist a vertex that is rigid for
S_{i}
. This implies that for each
u\in V_{cut}(G)
, there does not exist
B^{\prime},B^{\prime\prime}\in\mathcal{B}_{u}(G)
such that
pot_{G}(S_{i},(B^{\prime},u))=pot_{G}(S_{i},(B^{\prime\prime},u))=0
and
ua_{G}(B^{\prime},u)=ua_{G}(B^{\prime\prime},u)=True
.
From our previous observation that for each
p\in\mathcal{P}_{H}
,
ua_{H}(p)=ua_{G}(f_{H,G}(p))
and
pot_{H}(S_{i}\cap V(H),p)=pot_{G}(S_{i},f_{H,G}(p))
,
we get that for each
u\in V_{cut}(H)
, there does not exist
B^{\prime},B^{\prime\prime}\in\mathcal{B}_{u}(H)
such that
pot_{H}(S_{i}\cap V(H),(B^{\prime},u))=pot_{H}(S_{i}\cap V(H),(B^{\prime\prime},u))=0
and
ua_{H}(B^{\prime},u)=ua_{H}(B^{\prime\prime},u)=True
. This implies that in the graph
H
, no cut-vertex is rigid for the independent set
S_{i}\cap V(H)
of
H
.

We thus have that no cut-vertex of
H
is rigid for either of the independent sets
S_{1}\cap V(H)
or
S_{2}\cap V(H)
of
H
.
Further, since
|S_{1}|=|C_{1}|=|C_{2}|=|S_{2}|=r
and
S_{1}[l,B]=S_{2}[l,B]=\{h\}
, we have
|S_{1}\cap V(H)|=|S_{2}\cap V(H)|=r-1
, which implies by the induction hypothesis that in
H
,
S_{2}\cap V(H)
is reachable from
S_{1}\cap V(H)
. This implies that there exist independent sets
R_{0},R_{1},\ldots,R_{q}
of
H
, where
q\geq 0
, such that
S_{1}\cap V(H)=R_{0}\rightarrow R_{1}\rightarrow\cdots\rightarrow R_{q}=S_{2}\cap V(H)
. For each
j\in\{0,1,\ldots,q\}
, since
N_{G}(h)\cap V(H)=\emptyset
, it is clear that
R^{\prime}_{j}=R_{j}\cup\{h\}
is an independent set of
G
. It is easy to see that for each
j\in\{0,1,\ldots,q-1\}
, since
R_{j}\rightarrow R_{j+1}
, we also have
R^{\prime}_{j}\rightarrow R^{\prime}_{j+1}
. Moreover, as
S_{1}[l,B]=S_{2}[l,B]=\{h\}
, we have
R^{\prime}_{1}=S_{1}
and
R^{\prime}_{q}=S_{2}
. Hence, we get
S_{1}=R^{\prime}_{0}\rightarrow R^{\prime}_{1}\rightarrow\cdots\rightarrow R^{\prime}_{q}=S_{2}
, which shows that
S_{2}
is reachable from
S_{1}
. Since we have already showed that
S_{1}
is reachable from
C_{1}
and
S_{2}
is reachable from
C_{2}
, we get that
C_{2}
is reachable from
C_{1}
. Hence, we are done.
∎

Theorem 2
.

Let
G
be a block graph and let
C_{1},C_{2}
be independent sets of
G
. Let
W_{1},W_{2}
be the set of vertices of
G
that are rigid for
C_{1},C_{2}
respectively. Then
C_{1}
is reachable from
C_{2}
if and only if
W_{1}=W_{2}
, and for every connected component
H
of
G-W_{1}
, we have
|C_{1}\cap V(H)|=|C_{2}\cap V(H)|
.

Proof.

First, we prove the forward direction for which we consider the contrapositive statement. Suppose either
W_{1}\neq W_{2}
or there exists a connected component
H
of
G-W_{1}
such that
|C_{1}\cap V(H)|\neq|C_{2}\cap V(H)|
. If
W_{1}\neq W_{2}
, then by Lemma
17
we have that
C_{1}
is not reachable from
C_{2}
and we are done in this case. Hence,
we assume that
W_{1}=W_{2}
and that there exists a connected component
H
of
G-W_{1}
such that
|C_{1}\cap V(H)|\neq|C_{2}\cap V(H)|
. Suppose for the sake of contradiction that
C_{1}
is reachable from
C_{2}
. Then, there exists independent sets
D_{0},D_{1}\ldots,D_{k}
, where
k\geq 0
, such that
C_{1}=D_{0}\rightarrow D_{1}\rightarrow\cdots\rightarrow D_{k}=C_{2}
.
Let
j=\min\{i\in\{0,1,\ldots,k\}\colon|D_{i}\cap V(H)|\neq|C_{1}\cap V(H)|\}
.
Then clearly, we have
j>0
and
|D_{j-1}\cap V(H)|=|C_{1}\cap V(H)|
. Since
D_{j-1}\rightarrow D_{j}
, there exists
uv\in E(G)
such that
(D_{j-1}\setminus D_{j})\cup(D_{j}\setminus D_{j-1})=\{u,v\}
. As
|D_{j}\cap V(H)|\neq|D_{j-1}\cap V(H)|
, it must be the case that one of
u,v
is in
V(H)
and the other is not in
V(H)
. Without loss of generality, assume that
u\in V(H)
and
v\notin V(H)
. Since
uv\in E(G)
, it follows that
v\in N_{G}(H)
. Since
H
is a connected component of
G-W_{1}
, we now have that
v\in W_{1}
, or in other words,
v
is rigid for

Corollary 4
.

TS-Ind-set reconfig
is polynomial time solvable on block graphs.

Proof.

Consider an input instance
(G,C_{1},C_{2})
of the
TS-Ind-set reconfig
problem, where
G
is a block graph and
C_{1},C_{2}
are independent sets of
G
.
We can assume that the input block graph
G
is connected, as otherwise, we can simply solve the problem on each connected component of
G
(Observation
1
). Note that this means that
|V(G)|\leq|E(G)|
.
We first run
Compute-potentials
(G,C_{1})
and
Compute-potentials
(G,C_{2})
to compute
pot_{G}(C_{1},p)
and
pot_{G}(C_{2},p)
for all
p\in\mathcal{P}_{G}
. By Theorem
1
, this can be done in
O(|E(G)|^{4})
time. It is easy to see that once the potentials with respect to
C_{1}
and
C_{2}
have been computed, the set of vertices that are rigid for
C_{1}
and the set of vertices that are rigid for
C_{2}
can both be determined, and the equality of these sets checked, in
O(|V(G)|+|E(G)|)=O(|E(G)|)
time. If the set of vertices that are rigid is not the same for both
C_{1}
and
C_{2}
, we can return “No” since we know by Theorem
2
that
C_{2}
is not reachable from
C_{1}
. Otherwise, we remove the (common) set of rigid vertices for both
C_{1}
and
C_{2}
to obtain a graph
G^{\prime}
— this can be done in
O(|V(G)|+|E(G)|)=O(|E(G)|)
time. Clearly, in
O(|E(G)|)
time, we can determine the connected components of
G^{\prime}
and also determine if
|C_{1}\cap V(H)|=|C_{2}\cap V(H)|
for each connected component
H
of
G^{\prime}
. We return “No” if there exists some connected component
H
of
G^{\prime}
such that
|C_{1}\cap V(H)|\neq|C_{2}\cap V(H)|
, and otherwise we return “Yes”. From Theorem
2
, it follows that our algorithm returns “Yes” if and only if the independent set
C_{2}
of
G
is reachable from
C_{1}
. Clearly, this algorithm runs in time
O(|E(G)|^{4})
. This completes the proof.
∎

9
Conclusion

Although Corollary
4
tells us that there is a polynomial time algorithm that can determine whether two independent sets in a block graph are reconfigurable with each other, that algorithm does not produce a reconfiguration sequence between the two independent sets. In fact, it is not even clear whether there is a reconfiguration sequence of polynomial length between any two independent sets in a block graph that are reconfigurable with each other. It was shown in Briański et al.
[
10
]
that for any two independent sets that are reconfigurable with each other in an interval graph, there is a reconfiguration sequence of length
O(n^{3})
between them (where
n
is the number of vertices in the graph). For trees, it is shown in Demaine et al.
[
12
]
that any two independent sets that are reconfigurable with each other have a reconfiguration sequence of length
O(n^{2})
between them.
