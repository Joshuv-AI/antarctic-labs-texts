Abstract
ℒ \mathcal{L} .We define a new inner model C 2 ​ ( ω ) C^{2}(\omega) based on the fragment of second order logic in which second order variables range over countable subsets of the domain. We compare C 2 ​ ( ω ) C^{2}(\omega) to the previously studied inner model C ⁡ ( aa ) C(\hskip-1.0pt\mathop{{\mbox{\tt a\hskip-0.4pta}}}\hskip-1.0pt) . We argue that C 2 ​ ( ω ) C^{2}(\omega) appears to be a much bigger inner model than C ⁡ ( aa ) C(\hskip-1.0pt\mathop{{\mbox{\tt a\hskip-0.4pta}}}\hskip-1.0pt) , although this cannot be literally true in ZFC alone. However, we conjecture that it follows from large cardinal assumptions. For example, assuming large cardinals, C 2 ​ ( ω ) C^{2}(\omega) contains, for every n n , an inner model with n n Woodin cardinals, while C ⁡ ( aa ) C(\hskip-1.0pt\mathop{{\mbox{\tt a\hskip-0.4pta}}}\hskip-1.0pt) contains, under the same assumption, no inner model with a Woodin cardinal. As to large cardinals in C 2 ​ ( ω ) C^{2}(\omega) , we show that, assuming a Woodin limit of Woodin cardinals, the cardinal ω 1 V \omega_{1}^{V} is Mahlo in C 2 ​ ( ω ) C^{2}(\omega) . A stronger result is proved for the combination C 2 ( ω , aa ) C^{2}(\omega,\mathop{{\mbox{\tt a\hskip-0.4pta}}}) of C ⁡ ( aa ) C(\hskip-1.0pt\mathop{{\mbox{\tt a\hskip-0.4pta}}}\hskip-1.0pt) and C 2 ​ ( ω ) C^{2}(\omega) . We also show that the question whether HOD 1 \mbox{\rm HOD}_{1} , a variant of HOD , defined in [ 11 ] , is the same as HOD cannot be decided on the basis of ZFC even if we add the assumption that there are supercompact cardinals.
