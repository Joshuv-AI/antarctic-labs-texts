Time-Masked Transformers with Lightweight Test-Time Adaptation for Neural Speech Decoding
Ebrahim Feghhi, Shreyas Kaasyap, Nima Hadidi, Jonathan C. Kao, [0.6em] Neuroscience Interdepartmental Program

Abstract
Speech neuroprostheses aim to restore communication for people with severe paralysis by decoding speech directly from neural activity. To accelerate algorithmic progress, a recent benchmark released intracranial recordings from a paralyzed participant attempting to speak, along with a baseline decoding algorithm. Prior work on the benchmark showed impressive accuracy gains. However, these gains increased computational costs and were not demonstrated in a real-time decoding setting. Here, we make three contributions that pave the way towards accurate, efficient, and real-time neural speech decoding. First, we incorporate large amounts of time masking during training. On average, over 50 % 50\% of each trial is masked. Second, we replace the gated recurrent unit (GRU) architecture used in the baseline algorithm with a compact Transformer. The Transformer architecture uses 77 % 77\% fewer parameters, cuts peak GPU memory usage by 36 % 36\% relative, and is significantly faster to calibrate relative to the GRU. Third, we design a lightweight variant of an existing test-time adaptation method developed for decoding handwriting from neural activity. Our variant adapts the model using multiple time masked augmentations of a single trial and requires only one gradient step per trial. Together, these contributions reduce word error rate by 19.5 % 19.5\% and effectively mitigate performance degradations across held-out days in a real-time decoding setting while substantially lowering computational costs.



1
Introduction

Conditions including amyotrophic lateral sclerosis (ALS) and brainstem stroke can lead to severe paralysis, leaving individuals unable to speak or interact with the world. A promising path toward restoring communication for these individuals is speech neuroprostheses, which bypass the vocal apparatus and decode speech directly from neural activity
(
26
)
. Speech neuroprostheses have made significant strides in recent years, demonstrating the ability to decode speech with high accuracy over large vocabularies
(
33
;
22
;
7
;
19
)
.

To be viable in real-world clinical settings, decoding algorithms for speech neuroprostheses should ideally satisfy several key criteria beyond accuracy. First, they should operate in a real-time "streaming" fashion, decoding speech with low-latency over short windows rather than waiting for the entire utterance to finish
(
19
)
. Second, they should have low computational requirements to enable on-device inference and adaptation
(
6
)
, minimizing reliance on external connections and preserving user privacy. Finally, decoding algorithms should be easily integrated with test-time adaptation methods that mitigate performance degradation across time
(
13
)
.

To accelerate progress along these lines, the Brain-to-Text Benchmark ’24 was released, an open-source dataset containing intracortical neural recordings while a participant with ALS attempted to speak sentences across
24
days. Along the with the dataset, the organizers provided a baseline decoding algorithm which consisted of a gated recurrent unit (GRU) architecture to decode neural activity into phonemes, followed by beam search guided by an
N
-gram language model (LM)
(
33
)
.

A recent summary report outlined the findings of the top four entries submitted to the benchmark
(
34
)
. Several entries replaced the GRU architecture with Transformers, deep state space architectures, and convolutional neural networks (CNNs), and found that none of these architectures outperformed the baseline GRU. For example, the first place entry reported that the phoneme error rate (PER) for Transformers was more than double that of the baseline GRU
(
18
)
. While researchers found that using a learning rate scheduler, layer normalization
(
4
)
, and different optimization algorithms helped improve accuracy, the modification that led to the largest improvement was "using an ensemble of neural decoders to generate a diverse set of sentence hypotheses, and then using a fine-tuned large language model (LLM) to merge these hypotheses into a finalized sentence"
(
34
)
, an idea that was first implemented by
(
5
)
.

Although the accuracy gains from prior work are remarkable, there are several important caveats. First, the baseline algorithm used for the benchmark along with the top four entries all used a bidirectional GRU, which requires access to future neural activity and therefore cannot decode speech in real-time. Beyond the use of bidirectional GRUs, LLM merging was also applied after the entire text was decoded. Second, some entries used up to
10
GRUs and GPT 3.5, which makes inference and test-time adaptation challenging on resource-constrained devices challenging. Third, since the sentences used in the benchmark were from the publicly available Switchboard corpus
(
1
)
, it is possible LLMs were trained on this corpus and so their contribution is overstated relative to conversational settings. These points highlight how optimizing for a single metric on machine learning benchmarks can lead to sacrifices along other dimensions important for real-world use.

In this work, we aimed to holistically improve speech neuroprostheses by focusing on all criteria: accuracy, capability for real-time streaming, low computational costs, and robustness to distribution shifts. In order to do so, we focused on improving the neural network that translates neural activity into phonemes rather than external language modeling components. Our improvements are based on two key observations. First, the baseline GRU overfits early in training (Figure
1
a). Second, the GRU processes highly redundant inputs at each time step in order to achieve optimal performance: consecutive inputs are
87.5\%
overlapping when using the settings proposed by
Willett et al. 2023
(Figure
1
b), which we hypothesized is a source of inefficiency.

Based on these observations, we proposed two modifications to the baseline algorithm. First, in order to delay overfitting, we incorporated time masking which is a regularization strategy that masks contiguous temporal chunks of the input neural activity during training (Figure
1
c)
(
23
)
. Second, we replaced the GRU architecture with a compact, unidirectional Transformer (Figure
1
c)
(
30
)
. We hypothesized that the GRU requires overlapping inputs due to its lossy memory, which may result in increased computational costs. Since Transformers have perfect memory for a fixed context length, they are likely able to efficiently processes non-overlapping inputs. To foreshadow the results, the Transformer trained with time masking (time-masked Transformers, or masked Transformers for brevity) achieved a WER of
12.27\%
with a
3
-gram LM, which is
19.5\%
lower than the baseline unidirectional GRU. The proposed algorithm also substantially reduces parameter count, peak GPU memory usage, FLOPs, and per-epoch training times.

We next leveraged masked Transformers to improve upon the test-time adaptation method created by
Fan et al. 2023
for handwriting neuroprostheses. Their approach,
C
ontinual
O
nline
R
ecalibration with
P
seudo-labels (CORP), refines the text produced by a GRU decoder with a LM, and then adapt the GRU to output the LM-refined text. CORP utilizes multiple gradient steps per trial and maintains previous data to enable adaptation. Here, we present "DietCORP" a lightweight variant which enables test-time adaptation in a single gradient step without previous data by leveraging multiple time-masked augmentations of the same trial (Figure
1
d). When combined with the low memory requirements and fast training speeds of the Transformer, DietCORP effectively adapts the model to distribution shifts while requiring only
1.39
GiB of peak GPU memory usage and
18.38
ms to adapt per trial.

Related Work

Although we found success with using a Transformer, Transformers are typically not the architecture of choice for speech neuroprostheses or brain computer interfaces (BCIs) more broadly.
Willsey et al. 2022
used a convolutional neural network (CNN) to decode finger movements.
Costello et al. 2023
followed up on this work, and showed that recurrent neural networks (RNNs) achieve better finger movement decoding performance than either CNNs or Transformers. The majority of speech neuroprostheses have employed some combination of CNNs and RNNs
(
2
;
29
;
20
;
32
;
33
;
22
;
3
;
7
;
27
;
19
)
, although a few studies have used Transformers
(
31
;
9
;
8
)
. In the discussion of the Brain-to-Text benchmark results, the authors speculated that the relatively poor performance of Transformers may be attributed to the fact that
1)
more optimization is required or
2)
phonemes are represented over short context windows in neural activity, which suits GRUs because they naturally implement a locality bias whereas Transformers are better suited for modeling long-range dependencies
(
34
)
.

Our Transformer architecture is most similar to that of
Chen et al. 2025
in the BCI literature. Specifically, we also used relative positional embeddings and temporal patches (i.e. each patch/token consists of all channels for a short duration of time). However, this work is distinct from their work in several ways.
Chen et al. 2025
displayed their results on a closed-source dataset consisting of electrocorticographic (ECoG) and depth electrodes (sEEG), and they translated neural activity directly into speech. Our results are displayed using an open-source dataset consisting of recordings from microelectrode arrays, and we translated neural activity into text. Furthermore, we show significant reductions in memory and computational costs when using a Transformer, and replacing the GRU with a Transformer is only one out of our three core contributions.
Li et al. 2024
also used Transformers on the Brain-to-Text benchmark; however, we cannot compare our methods because to the best of our knowledge the authors did not release sufficient details to reproduce their results.

Structured input masking was initially popularized by
Park et al. 2019
for automatic speech recognition (ASR). Within speech neuroprostheses,
Littlejohn et al. 2025
masked entire channels and cropped each trial by applying a temporal window.
Metzger et al. 2023
;
Metzger et al. 2022
applied a single temporal mask to each trial. The masking augmentations used by
Littlejohn et al. 2025
;
Metzger et al. 2023
;
Metzger et al. 2022
were primarily applied on close-sourced, ECoG datasets and mask a much smaller percentage of the input than in this work. Furthermore, the contribution of masking relative to other augmentations is not emphasized in these works. Beyond speech neuroprostheses,
Saeed et al. 2021
;
Ding et al. 2024
applied structured input masking for EEG-based BCIs, and
Fu et al. 2024
applied it for intracranial monkey BCIs.

DietCORP is most directly inspired by CORP
(
13
)
. However, the idea to use multiple augmentations, rather than previous data, for test-time adaptation was inspired by
Zhang et al. 2022
and
Yao et al. 2025
.
Zhang et al. 2022
encouraged models to make consistent and confident (low entropy) predictions across several augmentations of the same image at test-time.
Yao et al. 2025
add a KL divergence loss term across two time-masked versions of the same audio sample to the CTC loss during training.

Methods

3.1
Neural Dataset

The Brain-to-Text ’24 benchmark dataset consists of microelectrode recordings from the ventral premotor cortex (area
6v
) of a single participant with ALS. Data was recorded from two microelectrode arrays with
64
channels each, a ventral
6
v array and a dorsal
6
v array. Spike band power and threshold crossings were extracted for each channel, leading to a total of
256
features. Neural activity was recorded while the patient attempted to speak
10
,
850
sentences. In each trial, the subject was shown a sentence, and attempted to speak the sentence at the onset of the “go” cue. All analyses were done on neural activity during the "go" phase while the participant attempted to speak the sentence. The neural activity was provided in
20
ms time bins (
50
Hz resolution), and z-scored within each block (
20
-
50
sentences). For additional details, refer to
(
33
)
.

4
Word error rate and phoneme error rate

We computed the
word error rate
(WER) as the Levenshtein (edit) distance between the predicted and target word sequences, normalized by the total number of words in the target. Formally, WER is defined as

WER=\frac{S+D+I}{N}

where
S
,
D
, and
I
denote the number of substitutions, deletions, and insertions, respectively, and
N
is the total number of words in the target transcription. Similarly, the
phoneme error rate
(PER) was computed in the same manner but at the level of phonemes rather than words. We applied an
N
-gram guided beam search process when computing WER (Section
F
), and computed PER using greedy decoding.

4.1
Train, validation, and test splits

The benchmark provided train, validation, and test splits. There were
8
,
770
sentences in train,
880
sentences in validation, and
1
,
200
sentences in test. Train and validation sentences were recorded on
24
days (collected over almost
4
months), and test sentences were recorded on
15
out of the
24
days. We refer to the days with testing data as "competition" days. The competition platform returns a single word-error rate (WER) for the entire test set, so day-specific WERs cannot be computed. To evaluate performance with less training data, we chronologically divided the
15
competition days into
3
non-overlapping blocks of
5
days each. We trained independent models using data from each block, and then concatenated the test set predictions across blocks to submit the decoded sentences to the benchmark. To evaluate model performance on held-out days, we trained models up until day
N
and then evaluated performance on the next
M
competition days. We used the original train and validation sentences for "testing" on held-out days since test set performance cannot be quantified for specific days.

4.2
Baseline algorithm

The dataset was accompanied by a baseline gated recurrent unit (GRU)-based algorithm. The algorithm first passed the input features through a day-specific linear layer, followed by a softsign non-linearity. At each step, the GRU received a
F\cdot T_{in}
dimensional vector corresponding to day-transformed inputs, where
F
is the number of features (typically
256
) and
T_{in}
is the number of neural time bins. The GRU hidden states were passed through a linear layer to produce logits over phonemes, the CTC blank token, and a silence token. Logits were output every
T_{out}
steps. The baseline algorithm set
T_{in}=32
and
T_{out}=4
for optimal performance, resulting in
87.5\%
overlap between consecutive inputs.

The baseline GRU was trained using the Adam optimizer and connectionist temporal classification (CTC) loss
(
15
)
. During training, white noise and baseline shift augmentations were added to the neural activity, followed by causal Gaussian smoothing. Training was performed for
10{,}000
batches (
73
epochs). The full set of hyperparameters is listed in Section
D
. All runs used a unidirectional GRU compatible with streaming. For testing on held-out days, we used the day-specific linear layer from the last available training day, following the procedure in
Willett et al. 2023
.

4.3
Transformer architecture

Inspired by
Dosovitskiy et al. 2020
and
Chen et al. 2025
, we replaced the GRU architecture with a Transformer. We segmented the input neural data into non-overlapping temporal patches, each consisting of
T_{in}
time bins and all features.
T_{in}
was set to
5
, such that each patch captured
100
ms of neural activity. Each patch was then flattened into a
F\cdot T_{in}
dimensional vector and passed through a patch embedding module, consisting of the following layers in sequence: LayerNorm, Linear, and LayerNorm. Input dropout was applied to the output of the patch embedding module, followed by
L
Transformer blocks (
L=7
). Each Transformer block comprised a self-attention layer followed by a feed-forward network. We applied LayerNorm before the self-attention layer, and the feed-forward network included the following layers in sequence: LayerNorm, Linear, GeLU activation, Dropout, Linear, and Dropout. Residual connections were added around both the self-attention layer and the feed-forward network.

We used relative positional embeddings similar to the T5 architecture
(
24
)
. Specifically, we added a learned bias to the attention scores based on the relative distance between two patches. A causal attention mask was also used to ensure that each patch could only attend to itself and previous patches. The attention operation was then defined as:

\textrm{Attention}(\mathbf{Q},\mathbf{K},\mathbf{V})=\textrm{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^{\top}}{\sqrt{d}}+\mathbf{B}+\mathbf{M}\right)\mathbf{V}

where
\mathbf{B}_{i,j}=\mathbf{b}(i-j)
, and
\mathbf{b}\in\mathbb{R}^{2L-1}
was a learnable vector containing scalar bias values for each possible relative position. The index
(i-j)
represents the relative distance between query position
i
and key position
j
, allowing attention scores to incorporate relative position information up to a maximum absolute distance of
L-1
. The matrix
\mathbf{M}
was the causal attention mask, defined as:

\mathbf{M}_{i,j}=\begin{cases}0&\text{if }j\leq i\\
-\infty&\text{otherwise}\end{cases}

The outputs of the Transformer were passed through a linear layer to obtain logits over phonemes, the CTC blank token, and silence token. Logits were output every
T_{out}
time bins, and we set
T_{out}=5
. We trained the Transformer using the AdamW optimizer and CTC loss and applied the same augmentations and Gaussian smoothing used in the baseline algorithm. All Transformer hyperparameters are listed in Section
D
, and hyperparameters in this study were selected based on validation PER as done in
Willett et al. 2023
.

Algorithm 1

TimeMask
(\mathbf{x},N,M)

We performed time masking by masking several contiguous temporal chunks of each trial. The rationale for applying contiguous masking in addition to input dropout is that input dropout does not mask contiguous chunks, and is therefore a weaker form of regularization. A description of the time masking algorithm is provided in Algorithm
1
for the Transformer. For the GRU, all details are identical except masking was applied at the time bin level, and masked bins were replaced with
0
. We do not enforce time masks to be non-overlapping.

For all analyses, we set
N=20
(number of masks) and
M=0.075
(max mask length as a fraction of trial length). Under these settings
53\%
of a trial is masked out on average (Section
I
). We report performance with other hyperparameters and when applying channel masking in Section
J
. When applying time masking, we extend model training time to
600
epochs to account for the increased regularization effects. We found that training for
600
epochs worsens WER for models without time masking (Section
E
).

4.5
DietCORP

For each trial, we generated a "pseudo-label" by applying language model guided beam search (Section
F
) to the model predictions, as done in CORP
(
13
)
. "Pseudo-label" generation is already performed for real-world use, and so it does not incur additional computational costs. In CORP, the pseudo-label is combined with labeled training data as well as previously generated pseudo-labeled data to update model weights with CTC loss until the loss decreases below a threshold or
200
gradient steps are completed. DietCORP reduces the computational costs and complexity associated with CORP by eliminating the need to store previous data and performing adaptation with one gradient step per trial. This is done by adapting the model across
Z
augmentations of the same trial. Model weights are not reset across trials (i.e., calibration is continuous), as done in CORP.

When applying DietCORP, we only updated the patch embedding module because 1) neural distribution shifts across days are likely a form of input distribution shift (as opposed to feature or output distribution shifts) and selectively fine-tuning input layers is effective when dealing with input distribution shifts
(
17
)
, and 2) test-time adaptation can rapidly degrade when adapting the entire model
(
17
)
. Augmented trials were generated by creating
Z
copies of a given trial, and applying white noise, baseline shift, and time masking to each copy. Time masking served as the main form of augmentation. We set
Z=64
since this was the batch size used for training, although DietCORP was robust to lower values of
Z
as discussed in the results. All hyperparameters were set to the values used during training.

5.2
Generalization to offline language modeling setup

We next compared the masked Transformer to the baseline GRU when using the offline language modeling setup. The offline setup is better optimized, yet also substantially increased latency and memory requirements. Across

Performance dropped sharply across held-out days, likely due to distribution shifts in neural activity. Prior work (CORP) demonstrated that calibrating with LM-refined pseudo-labels can largely avert this decline without additional labeled data. We therefore evaluated a lightweight variant, DietCORP, which adapts the decoder in a single gradient step using multiple augmentations of the current trial (Section
4.5
). We used the exact same augmentations as during training, with time masking serving as the main augmentation. All analyses focused on the masked Transformer. After training on

6
Discussion

There are three noteworthy limitations to our results. First, all results are on a single participant. To the best of our knowledge, there are no other open-source microelectrode array datasets for speech neuroprostheses available at this time, and evaluation on one participant is standard of the field. However, it is still important to evaluate the effectiveness of masked Transformers and DietCORP across multiple participants. Second, incorporating time masking increased the number of epochs for training by several-fold (
73\rightarrow 600
). Although this increase may be inconvenient for researchers aiming to rapidly iterate on model designs, it is less critical for patients, as model training is typically performed offline and only once. In contrast, the speed of test-time adaptation is more relevant in clinical settings, where adaptation occurs frequently and during real-time use. Third, our use of beam search allows previously decoded text to be revised, which complicates integration with text-to-speech systems.

In summary, this work delivers three practical advances for the Brain-to-Text Benchmark ’24 and, more broadly, for the development of speech neuroprostheses. First, we showed that large amounts of time masking is a highly effective data augmentation method for training neural networks to decode speech from neural activity. Second, we replaced the baseline GRU with a compact Transformer that is faster to train and is more suitable for test-time adaptation. Third, we introduced DietCORP, a simple, lightweight, and fast method that utilizes multiple time-masked augmentations of the same trial to effectively adapt the Transformer at test-time. Together, these innovations lower word error rate while cutting resource demands, moving us closer to building robust, on-device speech neuroprostheses that restore fluent communication for patients with severe paralysis.

There are several exciting avenues for further improving speech neuroprostheses beyond those mentioned in
Willett et al. 2024
. First, the
3
-gram LM used by
Willett et al. 2023
requires around
60
GB of CPU memory to run, making the system infeasible for on-device applications. Although we focused on advancing the phoneme decoding process here, future work should investigate ways to reduce memory costs associated with the
N
-gram LM or explore alternative strategies to integrate text-based knowledge. Second, current test-time adaptation methods require storing activations for all model layers during backpropagation, which is not ideal for adaptation on resource-limited devices. Future work should investigate cutting memory costs by incorporating memory-efficient test-time adaptation methods
(
28
)
. Third, integrating Transformers with CNNs appears to yield benefits for ASR
(
16
)
. Although we did not experiment with hybrid architectures here, adding convolutional blocks or other modules with local biases to the masked Transformer may further boost performance. Finally, future work should explore achieving similar accuracy gains with greedy decoding or other systems that are compatible with real-time audio decoding
(
19
)
.

We hope that our study encourages future speech neuroprostheses benchmarks, such as the soon-to-be released Brain-to-Text Benchmark ’25, to offer a more holistic evaluation criteria for decoding algorithms beyond only accuracy. By evaluating decoding algorithms along multiple criteria such as real-time decoding compatibility, computational costs, and integration with existing test-time adaptation methods, these benchmarks can more effectively spur innovation and assist paralyzed patients with communication impairments.

Appendix F
Language model and beam search

When reporting WER, we used beam search to obtain the most likely text sequence from the GRU/Transformer. We denote the GRU/Transformer as the "encoder" for this section. The probability of a given beam (i.e., one possible decoded transcription),
b
, was computed as a weighted sum between the phoneme probabilities emitted by the encoder and the probabilities assigned by an
N
-gram language model:

\textrm{score}(b)=\alpha\cdot\log(P_{\textrm{enc}}(b))+\log(P_{\textrm{ngram}}(b))

The beam with the lowest log probability was then selected as the final decoded transcription. Blank labels emitted by the encoder were additionally penalized by dividing their probability by a constant. When using the
online language model
, we used a
3
-gram LM with a beam size of
18
,
alpha=0.8
, and set the blank penalty to log(2), as done in the code provided by
Willett et al. 2023
.

For the
offline language model
results, the
3
-gram LM was replaced with a
5
-gram LM and two additional steps were performed. First, a second pass was applied with an unpruned
5
-gram LM. The second pass replaces the original LM beam scores with updated scores from the unpruned LM. Second, the top
K
beams are returned, and an LLM (OPT
6.7
B) was used to score these top
K
beams. The updated score for each beam was then:

\textrm{score}(b)=\alpha\cdot\log(P_{\textrm{enc}}(b))+\beta\cdot\log(P_{\textrm{ngram}}(b))+(1-\beta)\log(P_{\textrm{opt}}(b))

Following
Willett et al. 2023
we set
K=100
,
\alpha=0.8
,
\beta=0.5
, the beam size to
18
, the blank penalty to log(7), and ran OPT
6.7
B in
8
-bit precision mode.

Appendix G
Beam search decoding time

We measured the average time required for beam search decoding using the
3
-gram language model, excluding the time to generate logits. With the baseline GRU, the average decoding time across 1,200 test trials was
0.059\pm 0.044
seconds per trial. In contrast, the time-masked Transformer was over 3.5 times faster, achieving an average decoding time of
0.016\pm 0.006
seconds. One potential explanation is that the Transformer outputs logits at 20 Hz, compared to 25 Hz for the GRU, resulting in fewer decoding steps. However, the time-masked GRU, which shares the same output resolution as the baseline GRU, achieved a faster decoding speed of
0.026\pm 0.019
seconds. Understanding why time masking and Transformer-based architectures reduce beam search decoding latency remains an open question for future work.

In

Appendix I
Calculating average masking percentage

Refer to Algorithm
1
for the full variable definitions. Here we derive the expected fraction of patches that are masked. Given that each mask length is uniformly sampled between
0
and
F
, the expected mask length is
F/2
.
Ignoring boundary effects, the probability that a given patch
I
is not masked by a given mask
N_{j}
is:

P\bigl(\text{unmasked}_{I,N_{j}}\bigr)\approx 1-\frac{\frac{F}{2}}{L}=1-\frac{F}{2L}=1-\frac{\lfloor ML\rfloor}{2L}\approx 1-\frac{M}{2}

Then, the probability that a patch
I
is unmasked after all masks are applied is:

P\bigl(i\text{ unmasked}\bigr)=\prod_{k=1}^{N}P\bigl(\text{unmasked}_{i,N_{k}}\bigr)=\prod_{k=1}^{N}\Bigl(1-\tfrac{M}{2}\Bigr)=\Bigl(1-\tfrac{M}{2}\Bigr)^{N}\,.

To find the proportion of masked patches, we take the complement. Using the linearity of expectation, we find that the expected proportion of masked patches is:

\mathbb{E}\!\bigl[\text{fraction of masked patches}\bigr]\;=\;\frac{1}{L}\sum_{i=1}^{L}\Bigl[\,1-\bigl(1-\tfrac{M}{2}\bigr)^{N}\Bigr]\;=\;1-\bigl(1-\tfrac{M}{2}\bigr)^{N}\,.

For our given parameters, we approximate that
53.44\%
of patches are masked on average for each trial.
