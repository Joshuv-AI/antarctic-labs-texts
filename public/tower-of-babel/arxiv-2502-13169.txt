A common approach to singular perturbation and homogenization III: Nonlinear periodic homogenization with localized defects
Lutz Recke

Abstract
We consider periodic homogenization with localized defects for semilinear elliptic equations and systems of the type ∇ ⋅ ( ( A ( x / ε ) + B ( x / ε ) ) ∇ u ( x ) + c ( x , u ( x ) ) = d ( x , u ( x ) ) in Ω \nabla\cdot\Big(\Big(A(x/\varepsilon)+B(x/\varepsilon)\Big)\nabla u(x)+c(x,u(x)\Big)=d(x,u(x))\mbox{ in }\Omega with Dirichlet boundary conditions. For small ε > 0 \varepsilon>0 we show existence of weak solutions u = u ε u=u_{\varepsilon} as well as their local uniqueness for ‖ u − u 0 ‖ ∞ ≈ 0 \|u-u_{0}\|_{\infty}\approx 0 , where u 0 u_{0} is a given non-degenerate weak solution to the homogenized problem. Moreover, we prove that ‖ u ε − u 0 ‖ ∞ → 0 \|u_{\varepsilon}-u_{0}\|_{\infty}\to 0 for ε → 0 \varepsilon\to 0 , and we estimate the corresponding rate of convergence. Our assumptions are, roughly speaking, as follows: Ω \Omega is a bounded Lipschitz domain, A A , B B , c ⁡ ( ⋅ , u ) c(\cdot,u) and d ⁡ ( ⋅ , u ) d(\cdot,u) are bounded and measurable, c ⁡ ( x , ⋅ ) c(x,\cdot) and d ⁡ ( x , ⋅ ) d(x,\cdot) are C 1 C^{1} -smooth, A A is periodic, and B B is a localized defect. Neither global uniqueness is supposed nor growth restriction for c ⁡ ( x , ⋅ ) c(x,\cdot) or d ⁡ ( x , ⋅ ) d(x,\cdot) . The main tool of the proofs is an abstract result of implicit function theorem type which permits a common approach to nonlinear singular perturbation and homogenization.

The main goal of the present paper is to prove Theorems

\int_{\|\xi-x\|<r}w(\xi/\varepsilon)d\xi=\varepsilon^{N}\int_{\|y\|<r/\varepsilon}w(x/\varepsilon+y)dy\leq\varepsilon^{N}\int_{(-r/\varepsilon,r/\varepsilon)^{N}}w(x/\varepsilon+y)dy.

But the cube
(-r/\varepsilon,r/\varepsilon)^{N}
is covered by the cube
(-[r/\varepsilon]-1,[r/\varepsilon]+1)^{N}

of integer edge length
2([r/\varepsilon]+1)
(where
[r/\varepsilon]
is the integer part of
r/\varepsilon
),
and this cube can be covered by the union of
(2([r/\varepsilon]+1))^{N}
cubes of edge length one. Therefore the
\mathbb{Z}^{N}
-periodicity of the function
w
yields

\varepsilon^{N}\int_{(-r/\varepsilon,r/\varepsilon)^{N}}w(x/\varepsilon+y)dy\leq\varepsilon^{N}(2([r/\varepsilon]+1))^{N}\int_{(0,1)^{N}}w(y)dy\leq\mbox{const}\,(r+\varepsilon)^{N},

where the constant does not depend on
r
,

\varepsilon
and
x
.

2
An abstract result of implicit function theorem type

Let
U
and
V
be Banach spaces with norms
\|\cdot\|_{U}
and
\|\cdot\|_{V}
, respectively.
For
\varepsilon>0
let be given

\bar{u}_{\varepsilon}\in U\mbox{ and }F_{\varepsilon}\in C^{1}(U;V).

We consider the abstract equation

F_{\varepsilon}(u)=0.

(2.1)

Roughly speaking, we will show the following:
If the elements
\bar{u}_{\varepsilon}
approximately satisfy (
2.1
) for
\varepsilon\approx 0
, i.e. if
\|F_{\varepsilon}(\bar{u}_{\varepsilon})\|_{V}\to 0
for
\varepsilon\to 0
,
and if they are non-degenerate solutions
(cf. assumption (
2.2
) below), then
for all
\varepsilon\approx 0
there exists exactly one solution
u=u_{\varepsilon}
to (
2.1
) with
\|u-\bar{u}_{\varepsilon}\|_{U}\approx 0
, and
\|u_{\varepsilon}-\bar{u}_{\varepsilon}\|_{U}=O(\|F_{\varepsilon}(\bar{u}_{\varepsilon})\|_{V})
for
\varepsilon\to 0
.
For that we do not suppose
that
\bar{u}_{\varepsilon}
or
F_{\varepsilon}(u)
(with fixed
u\in U
) converge in
U
for
\varepsilon\to 0
or that

F^{\prime}_{\varepsilon}(u)
(with fixed
u\in U
) converges in
{\cal L}(U)
for
\varepsilon\to 0

(cf. also Remark
2.4
below)
or that
\|\bar{u}_{\varepsilon}\|_{U}
is bounded for
\varepsilon\approx 0
.

Theorem 2.1

Suppose that

\left.\begin{array}[]{l}\mbox{there exist $\varepsilon_{0}>0$ and $\rho>0$ such that for all $\varepsilon\in(0,\varepsilon_{0}]$ the operators $F_{\varepsilon}^{\prime}(\bar{u}_{\varepsilon})$ are}\\
\mbox{Fredholm of index zero from }$U$\mbox{ into }$V$,\mbox{and }\|F_{\varepsilon}^{\prime}(\bar{u}_{\varepsilon}))u\|_{V}\geq\rho\|u\|_{U}\mbox{ for all }u\in U\end{array}\right\}

(2.2)

and

\sup_{\|v\|_{U}\leq 1}\|(F^{\prime}_{\varepsilon}(\bar{u}_{\varepsilon}+u)-F^{\prime}_{\varepsilon}(\bar{u}_{\varepsilon}))v\|_{V}\to 0\mbox{ for }\varepsilon+\|u\|_{U}\to 0

(2.3)

and

\|F_{\varepsilon}(\bar{u}_{\varepsilon})\|_{V}\to 0\mbox{ for }\varepsilon\to 0.

(2.4)

Then there exist
\varepsilon_{1}\in(0,\varepsilon_{0}]
and
\delta>0
such that for all
\varepsilon\in(0,\varepsilon_{1}]

there exists exactly one solution
u=u_{\varepsilon}
to (
2.1
) with
\|u-\bar{u}_{\varepsilon}\|_{U}\leq\delta
. Moreover, for all
\varepsilon\in(0,\varepsilon_{1}]
we have

\|u_{\varepsilon}-\bar{u}_{\varepsilon}\|_{U}\leq\frac{2}{\rho}\|F_{\varepsilon}(\bar{u}_{\varepsilon}))\|_{V}.

(2.5)

Proof

Take
\varepsilon\in(0,\varepsilon_{0}]
.
Because of assumption (
2.2
) the linear operator
F^{\prime}_{\varepsilon}(\bar{u}_{\varepsilon})
is an isomorphism from
U
onto
V
, and, hence,
equation (
2.1
) is equivalent to the fixed point problem

u=G_{\varepsilon}(u):=u-F_{\varepsilon}^{\prime}(\bar{u}_{\varepsilon})^{-1}F_{\varepsilon}(u).

Take
u_{1},u_{2}\in U
. Then

\displaystyle\|G_{\varepsilon}(u_{1})-G_{\varepsilon}(u_{2})\|_{U}

\displaystyle=

\displaystyle\left\|F_{\varepsilon}^{\prime}(\bar{u}_{\varepsilon})^{-1}\int_{0}^{1}\left(F^{\prime}_{\varepsilon}(\bar{u}_{\varepsilon})-F^{\prime}_{\varepsilon}(su_{1}+(1-s)u_{2})\right)ds(u_{1}-u_{2})\right\|_{U}

(2.6)

\displaystyle\leq

\displaystyle\frac{1}{\rho}\,\max_{0\leq s\leq 1}\left\|\big(F^{\prime}_{\varepsilon}(\bar{u}_{\varepsilon})-F^{\prime}_{\varepsilon}(su_{1}+(1-s)u_{2})\big)(u_{1}-u_{2})\right\|_{V}.

Here we used that (
2.2
) yields that

\rho\|F_{\varepsilon}^{\prime}(\bar{u}_{\varepsilon})^{-1}v\|_{U}\leq\|v\|_{V}

for all
v\in V
.

Denote
{\cal B}^{r}_{\varepsilon}:=\{u\in U:\;\|u-\bar{u}_{\varepsilon}\|_{U}\leq r\}
.
If
u_{1},u_{2}\in{\cal B}^{r}_{\varepsilon}
,
then also
su_{1}+(1-s)u_{2}\in{\cal B}^{r}_{\varepsilon}

for all
s\in[0,1]
. Therefore it follows from (
2.3
) and (
2.6
) that there exist
r_{0}>0
and
\varepsilon_{1}\in(0,\varepsilon_{0}]
such that for all
\varepsilon\in(0,\varepsilon_{1}]

the maps
G_{\varepsilon}
are strictly contractive with contraction constant
1/2
on the closed balls
{\cal B}^{r_{0}}_{\varepsilon}
.
Moreover, for all
\varepsilon\in(0,\varepsilon_{1}]
and
u\in{\cal B}^{r_{0}}_{\varepsilon}
we have

\displaystyle\left\|G_{\varepsilon}(u)-\bar{u}_{\varepsilon}\right\|_{U}

\displaystyle\leq

\displaystyle\left\|G_{\varepsilon}(u)-G_{\varepsilon}(\bar{u}_{\varepsilon})\right\|_{U}+\left\|G_{\varepsilon}(\bar{u}_{\varepsilon})-\bar{u}_{\varepsilon}\right\|_{U}

\displaystyle\leq

\displaystyle\frac{r_{0}}{2}+\left\|F_{\varepsilon}^{\prime}(\bar{u}_{\varepsilon}))^{-1}F_{\varepsilon}(\bar{u}_{\varepsilon})\right\|_{U}\leq\frac{r_{0}}{2}+\frac{1}{\rho}\left\|F_{\varepsilon}(\bar{u}_{\varepsilon})\right\|_{V},

and (
2.4
) yields that
G_{\varepsilon}
maps
{\cal B}^{r_{0}}_{\varepsilon}
into itself if
\varepsilon_{1}
is taken sufficiently small.

Now, Banach’s fixed point principle yields the existence and uniqueness assertions of Theorem
2.1
, and the estimate (
2.5
)
follows as above:

\|u_{\varepsilon}-\bar{u}_{\varepsilon}\|_{U}\leq\|G_{\varepsilon}(u_{\varepsilon})-G_{\varepsilon}(\bar{u}_{\varepsilon})\|_{U}+\|G_{\varepsilon}(\bar{u}_{\varepsilon})-\bar{u}_{\varepsilon}\|_{U}\leq\frac{1}{2}\|u_{\varepsilon}-\bar{u}_{\varepsilon}\|_{U}+\frac{1}{\rho}\left\|F_{\varepsilon}(\bar{u}_{\varepsilon})\right\|_{V}.

Remark 2.2

In
[
9
,
10
,
11
,
30
,
31
,
34
,
38
,
41
,
43
]
) various versions of Theorem
2.1
are presented
and applied to nonlinear singularly perturbed problems.
These versions differ slightly according to which problems they are applied (ODEs or elliptic or parabolic PDEs, stationary or time-periodic solutions, semilinear or quasilinear problems, smooth or nonsmooth data,
\varepsilon
-depending norms in
U
and
V
).

For other results of the type of Theorem
2.1
and their applications to semilinear elliptic PDEs with numerically determined approximate solutions see
[
7
, Theorem 2.1]

and
[
12
]
.

If one applies Theorem
2.1
, for example to boundary value problems for elliptic PDEs, then different choices of function spaces
U
and
V
and of their norms
\|\cdot\|_{U}
and
\|\cdot\|_{V}

and of the family
\bar{u}_{\varepsilon}
of approximate solutions
are appropriate. Criteria for these choices often are the following: The family
\bar{u}_{\varepsilon}
should be ”simple” (for example,
\bar{u}_{\varepsilon}
should be
\varepsilon
-independent or given more less explicit in closed formulas, or to determine
\bar{u}_{\varepsilon}
numerically should be much cheeper than
to determine the exact solution
u_{\varepsilon}

should be high. The norm
\|\cdot\|_{V}
should be weak and the norm
\|\cdot\|_{U}
should be strong such that the error estimate
(

)
is strong. But at the same time
the norm
\|\cdot\|_{U}
should be weak such that the domain of local uniqueness, which contains all
u\in U
with
\|u-\bar{u}_{\varepsilon}\|_{U}\leq\delta
, is large.
These criteria are contradicting, of course. Hence, in any application of Theorem
2.1

the choices of
U
,
V
,
\|\cdot\|_{U}
,
\|\cdot\|_{V}
and
\bar{u}_{\varepsilon}
are compromises according to the requirements of the application.

For example, in the present paper we will work with different choices of the spaces
U
and
V
and their norms
\|\cdot\|_{U}
and
\|\cdot\|_{V}
and of
the families
\bar{u}_{\varepsilon}
:
Spaces and norms (
3.5
) with exponents (
3.4
) and families (
3.23
)
for proving Theorem
1.1
(i),
(
3.5
) with (
4.2
) and (
4.3
)
for proving Theorem
1.1
(ii)
and
(
5.8
) with (

) and (

)
for proving Theorem

.
Remark that all the families

, we will work with, do not depend on the localized defects

and

.

One rather general way to find such compromises is described in Corollary

below. It delivers existence and local uniqueness of solutions
u=u_{\varepsilon}
to the equation
F_{\varepsilon}(u)=0
with
\varepsilon\approx 0
and
\|u-u_{0}\|_{\infty}\approx 0
,
where
u_{0}\in U
is a given element
and
\|\cdot\|_{\infty}
is another norm in

.
The price for that is that the estimate (

) below of the error

is with respect to the weaker norm

, only.
In Corollary

we use the notation

for a second norm in

, because in most of the applications to ODEs or PDEs (as well as in our applications, see Sections

–

) it is an
L^{\infty}
-norm.

Remark that the space

is supposed to be complete with respect to the norm
\|\cdot\|_{U}
, but not with respect to the norm
\|\cdot\|_{\infty}
, in general, and that it is not supposed that
\|F_{\varepsilon}(u_{0})\|_{V}

converges to zero for
\varepsilon\to 0
.

Corollary 2.3

Let be given
u_{0}\in U
such that

\left.\begin{array}[]{l}\mbox{there exist $\varepsilon_{0}>0$ and $\rho>0$ such that for all $\varepsilon\in(0,\varepsilon_{0}]$ the operators $F_{\varepsilon}^{\prime}(u_{0})$ are}\\
\mbox{Fredholm of index zero from }$U$\mbox{ into }$V$,\mbox{and }\|F_{\varepsilon}^{\prime}(u_{0}))u\|_{V}\geq\rho\|u\|_{U}\mbox{ for all }u\in U,\end{array}\right\}

(2.7)

and let be given a norm
\|\cdot\|_{\infty}
in
U
such that

\displaystyle\sigma:=\sup\{\|u\|_{\infty}:\;u\in U,\,\|u\|_{U}\leq 1\}<\infty,

(2.8)

\displaystyle\sup_{\|v\|_{U}\leq 1}\|(F^{\prime}_{\varepsilon}(u_{0}+u)-F^{\prime}_{\varepsilon}(u_{0}))v\|_{V}\to 0\mbox{ for }\varepsilon+\|u\|_{\infty}\to 0.

(2.9)

Further, suppose that

\|\bar{u}_{\varepsilon}-u_{0}\|_{\infty}+\|F_{\varepsilon}(\bar{u}_{\varepsilon})\|_{V}\to 0\mbox{ for }\varepsilon\to 0.

(2.10)

Then
there exist
\varepsilon_{1}\in(0,\varepsilon_{0}]
and
\delta>0
such that for all
\varepsilon\in(0,\varepsilon_{1}]

there exists exactly one solution
u=u_{\varepsilon}
to (
2.1
) with
\|u-u_{0}\|_{\infty}\leq\delta
,
and

\|u_{\varepsilon}-u_{0}\|_{\infty}\leq\|\bar{u}_{\varepsilon}-u_{0}\|_{\infty}+\frac{4\sigma}{\rho}\|F_{\varepsilon}(\bar{u}_{\varepsilon}))\|_{V}.

(2.11)

Proof

For all
\varepsilon>0
and
u,v\in U
we have

\displaystyle\|(F_{\varepsilon}^{\prime}(\bar{u}_{\varepsilon}+u)-F_{\varepsilon}^{\prime}(\bar{u}_{\varepsilon}))v\|_{V}

\displaystyle\leq\|(F_{\varepsilon}^{\prime}(u_{0}+(\bar{u}_{\varepsilon}-u_{0}+u))-F_{\varepsilon}^{\prime}(u_{0}))v\|_{V}+\|(F_{\varepsilon}^{\prime}(u_{0})-F_{\varepsilon}^{\prime}(u_{0}+(\bar{u}_{\varepsilon}-u_{0})))v\|_{V}.

Hence, assumptions
(
2.9
) and
(
2.10
) imply that

\sup_{\|v\|_{U}\leq 1}\|(F_{\varepsilon}^{\prime}(\bar{u}_{\varepsilon}+u)-F_{\varepsilon}^{\prime}(\bar{u}_{\varepsilon}))v\|_{V}\mbox{ for }\varepsilon+\|u\|_{\infty}\to 0.

(2.12)

In particular, (
2.3
) is satisfied
(because of
(
2.8
)).
Similarly, for all
\varepsilon>0
and
u\in U
we have that

\|(F_{\varepsilon}^{\prime}(\bar{u}_{\varepsilon})u\|_{V}\geq\|(F_{\varepsilon}^{\prime}(u_{0})u\|_{V}-\|(F_{\varepsilon}^{\prime}(u_{0})-F_{\varepsilon}^{\prime}(u_{0}+(\bar{u}_{\varepsilon}-u_{0})))u\|_{V}
.
Hence, (
2.7
) and (
2.9
) yield that there exists
\varepsilon_{1}\in(0,\varepsilon_{0}]
such that

\|(F_{\varepsilon}^{\prime}(\bar{u}_{\varepsilon})u\|_{V}\geq\frac{\rho}{2}\|u\|_{U}\mbox{ for all }\varepsilon\in(0,\varepsilon_{1}]\mbox{ and }u\in U.

Therefore (
2.2
) is satisfied (with

\rho
replaced by
\rho/2
).
Hence, assumptions (
2.7
),
(
2.9
) and
(
2.10
) imply
that (
2.2
) is satisfied
(with
\varepsilon_{1}
in place of
\varepsilon_{0}
and with
\rho/2
in place of
\rho
in (
2.2
)).
Hence, Theorem
2.1
yields the existence assertion of Corollary
2.3
and the error estimate

\|u_{\varepsilon}-u_{0}\|_{\infty}\leq\|\bar{u}_{\varepsilon}-u_{0}\|_{\infty}+\sigma\|u_{\varepsilon}-\bar{u}_{\varepsilon}\|_{U}\leq\|\bar{u}_{\varepsilon}-u_{0}\|_{\infty}+\frac{4\sigma}{\rho}\|F_{\varepsilon}(\bar{u}_{\varepsilon})\|_{V}.

Now let us prove the local uniqueness assertion of Corollary
2.3
.
Take
\varepsilon\in(0,\varepsilon_{1}]
and a solution
u\in U
to (
2.1
). Then

0=F_{\varepsilon}(u)=F_{\varepsilon}(\bar{u}_{\varepsilon})+F^{\prime}_{\varepsilon}(\bar{u}_{\varepsilon})(u-\bar{u}_{\varepsilon})+\int_{0}^{1}\left(F^{\prime}_{\varepsilon}(su+(1-s)\bar{u}_{\varepsilon})-F^{\prime}_{\varepsilon}(\bar{u}_{\varepsilon})\right)(u-\bar{u}_{\varepsilon})ds,

i.e.

u-\bar{u}_{\varepsilon}=-F^{\prime}_{\varepsilon}(\bar{u}_{\varepsilon})^{-1}\left(F_{\varepsilon}(\bar{u}_{\varepsilon})+\int_{0}^{1}\left(F^{\prime}_{\varepsilon}(su+(1-s)\bar{u}_{\varepsilon})-F^{\prime}_{\varepsilon}(\bar{u}_{\varepsilon})\right)(u-\bar{u}_{\varepsilon})ds\right),

i.e.

\|u-\bar{u}_{\varepsilon}\|_{U}\leq\frac{1}{\rho}\left(\|F_{\varepsilon}(\bar{u}_{\varepsilon})\|_{V}+\max_{0\leq s\leq 1}\|\left(F^{\prime}_{\varepsilon}(su+(1-s)\bar{u}_{\varepsilon})-F^{\prime}_{\varepsilon}(\bar{u}_{\varepsilon})\right)(u-\bar{u}_{\varepsilon})\|_{V}\right).

(2.13)

But (
2.12
) yields that

\max_{0\leq s\leq 1}\|\left(F^{\prime}_{\varepsilon}(su+(1-s)\bar{u}_{\varepsilon})-F^{\prime}_{\varepsilon}(\bar{u}_{\varepsilon})\right)(u-\bar{u}_{\varepsilon})\|_{V}=o(\|u-\bar{u}_{\varepsilon}\|_{U})\mbox{ for }\varepsilon+\|u-\bar{u}_{\varepsilon}\|_{\infty}\to 0.

Therefore (
2.10
) implies that

\max_{0\leq s\leq 1}\|\left(F^{\prime}_{\varepsilon}(su+(1-s)\bar{u}_{\varepsilon})-F^{\prime}_{\varepsilon}(\bar{u}_{\varepsilon})\right)(u-\bar{u}_{\varepsilon})\|_{V}=o(\|u-\bar{u}_{\varepsilon}\|_{U})\mbox{ for }\varepsilon+\|u-u_{0}\|_{\infty}\to 0.

Hence, if
\varepsilon
and
\|u-u_{0}\|_{\infty}
are sufficiently small, then (
2.13
) yields that
\|u-\bar{u}_{\varepsilon}\|_{U}
is small also, and the local uniqueness assertion of Theorem
2.1
implies that
u=u_{\varepsilon}
.

1.7
),
the periodic correctors
v^{\beta}_{j}\in W^{1,2}_{\rm loc}(\mathbb{R}^{2};\mathbb{R}^{n})
, which are defined by the cell problems (
1.14
),
the homogenized diffusion coefficients

\hat{a}^{\alpha\beta}_{ij}\in\mathbb{R}
, which are
defined in (
1.13
), and
the
weak solution
u_{0}\in W_{0}^{1,2}(\Omega;\mathbb{R}^{n})\cap L^{\infty}(\Omega;\mathbb{R}^{n})
to the homogenized boundary value problem
(
1.12
).

3.1
Maximal Sobolev regularity for linear elliptic systems

As usual, the norm in the Sobolev space
W^{1,p}(\Omega;\mathbb{R}^{n})
(with
p\geq 2
) is denoted by

\|u\|_{1,p}:=\left(\sum_{\alpha=1}^{n}\int_{\Omega}\left(|u^{\alpha}(x)|^{p}+\sum_{i=1}^{2}|\partial_{x_{i}}u^{\alpha}(x)|^{p}\right)dx\right)^{1/p}.

The subspace
W_{0}^{1,p}(\Omega;\mathbb{R}^{n})
is the closure with respect to this norm
of the set
of all
C^{\infty}
-maps
u:\Omega\to\mathbb{R}^{n}
with compact support,
and
W^{-1,p}(\Omega;\mathbb{R}^{n}):=W_{0}^{1,p^{\prime}}(\Omega;\mathbb{R}^{n})^{*}
is the dual space to

W_{0}^{1,p^{\prime}}(\Omega;\mathbb{R}^{n})
with

1/p+1/p^{\prime}=1

and with dual space norm

\|\phi\|_{-1,p}:=\sup\{\langle\phi,\varphi\rangle_{1,p^{\prime}}:\;\varphi\in W_{0}^{1,p^{\prime}}(\Omega;\mathbb{R}^{n}),\|\varphi\|_{1,p^{\prime}}\leq 1\},

where

\langle\cdot,\cdot\rangle_{1,p^{\prime}}:W^{-1,p}(\Omega;\mathbb{R}^{n})\times W_{0}^{1,p^{\prime}}(\Omega;\mathbb{R}^{n})\to\mathbb{R}

is the dual pairing.

Further, we introduce linear bounded operators
\hat{A}:W^{1,2}(\Omega;\mathbb{R}^{n})\to W^{-1,2}(\Omega;\mathbb{R}^{n})
and, for
\varepsilon>0
,

A_{\varepsilon},B_{\varepsilon}:W^{1,2}(\Omega;\mathbb{R}^{n})\to W^{-1,2}(\Omega;\mathbb{R}^{n})

by

\left.\begin{array}[]{l}\displaystyle\langle\hat{A}u,\varphi\rangle_{1,2}:=\int_{\Omega}\hat{a}_{ij}^{\alpha\beta}\partial_{x_{j}}u^{\beta}(x)\partial_{x_{i}}\varphi^{\alpha}(x)dx,\\
\displaystyle\langle A_{\varepsilon}u,\varphi\rangle_{1,2}:=\int_{\Omega}a_{ij}^{\alpha\beta}(x/\varepsilon)\partial_{x_{j}}u^{\beta}(x)\partial_{x_{i}}\varphi^{\alpha}(x)dx,\\
\displaystyle\langle B_{\varepsilon}u,\varphi\rangle_{1,2}:=\int_{\Omega}b_{ij}^{\alpha\beta}(x/\varepsilon)\partial_{x_{j}}u^{\beta}(x)\partial_{x_{i}}\varphi^{\alpha}(x)dx,\end{array}\right\}\mbox{ for all }\varphi\in W_{0}^{1,2}(\Omega;\mathbb{R}^{n}).

(3.1)

Because of assumption (
1.4
) and the Hölder inequality we have the following:
For any
p\geq 2
the restrictions of
\hat{A}
,
A_{\varepsilon}
and
B_{\varepsilon}
to

W^{1,p}(\Omega;\mathbb{R}^{n})

map
W^{1,p}(\Omega;\mathbb{R}^{n})
into

W^{-1,p}(\Omega;\mathbb{R}^{n})
, and

\|\hat{A}u\|_{-1,p}+\|A_{\varepsilon}u\|_{-1,p}+\|B_{\varepsilon}u\|_{-1,p}\leq\mbox{const}\;\|u\|_{1,p}\mbox{ for all }u\in W^{1,p}(\Omega;\mathbb{R}^{n}),

where the constant does not depend on
\varepsilon
,
p
and
u
.
Further, because of assumption (
1.5
)
we have that

\inf\left\{\langle A_{\varepsilon}u,u\rangle_{1,2}:\;\varepsilon>0,\;u\in W_{0}^{1,2}(\Omega;\mathbb{R}^{n}),\;\|u\|_{1,2}=1\right\}>0,

and similarly for
A_{\varepsilon}+B_{\varepsilon}
and for
\hat{A}
.
Therefore K. Gröger’s maximal regularity results for elliptic systems with non-smooth data
[
23
, Theorems 1 and 2 and Remark 14]
imply the following:

Theorem 3.1

There exist
p_{1}>2
and
\rho>0
such that
for all
\varepsilon>0
and all
p\in[2,p_{1}]

the linear operators
\hat{A}
,
A_{\varepsilon}
and
A_{\varepsilon}+B_{\varepsilon}

are bijective from
W_{0}^{1,p}(\Omega;\mathbb{R}^{n})
onto
W^{-1,p}(\Omega;\mathbb{R}^{n})
and that

\|\hat{A}^{-1}\phi\|_{1,p}+\|A_{\varepsilon}^{-1}\phi\|_{1,p}+\|(A_{\varepsilon}+B_{\varepsilon})^{-1}\phi\|_{1,p}\leq\rho\,\|\phi\|_{-1,p}\mbox{ for all }\phi\in W^{-1,p}(\Omega;\mathbb{R}^{n}).

(3.2)

Remark 3.2

Estimates of the type (
3.2
) often are called Meyers’ estimates
because of the initiating paper
[
33
]

of N.G. Meyers, see also
[
17
,
32
]
. For the case of smooth boundaries
\partial\Omega
see

[
3
, Theorem 4.1]
. See also
[
13
]
for
\Omega
being a cube and for continuous diffusion coefficients as well as for certain transmission problems and applications to linear elliptic periodic homogenization.

Remark 3.3

It is easy to verify that the linear operators
A_{\varepsilon}
do not converge for
\varepsilon\to 0
with respect to the uniform operator norm in
{\cal L}(W^{1,p}(\Omega;\mathbb{R}^{n});W^{-1,p}(\Omega;\mathbb{R}^{n}))
for certain
p\geq 2
, in general (see
[
16
, Remark 8.4]
and Lemma

3.11
below). This is the reason why the classical implicit function theorem is not directly applicable to the boundary value problem (
1.1
), in general. But the linear operators
A_{\varepsilon}
converge in a certain weak sense to
the linear operator

\hat{A}
for
\varepsilon\to 0
(cf. Theorem
3.6
and Lemma
3.11

below),
and this is the reason why Theorem
2.1
is applicable to (
1.1
).

Remark 3.4

Even if the diffusion coefficients
a_{ij}^{\alpha\beta}
would be constant, i.e. if

a_{ij}^{\alpha\beta}(y)=\hat{a}_{ij}^{\alpha\beta}
for all
y\in\mathbb{R}^{2}
, i.e. if
A_{\varepsilon}=\hat{A}
for all
\varepsilon
, then the classical implicit function theorem would not be applicable to the boundary value problem (
1.1
), because the linear operators
B_{\varepsilon}
are not small in

for small

, in general. They are small only in

with

, cf. Lemma
3.5
below.

The question of
W^{1,p}
-regularity of the correctors

is much simpler than Theorem
3.1
because there do not appear problems with boundary regularity.
It is well-known (cf., e.g.
[

, Chapter 2.2, formula (2.2.22)]
) that

\mbox{there exists }p_{2}>2\mbox{ such that }v^{\beta}_{j}\in W_{\rm loc}^{1,p_{2}}(\mathbb{R}^{2};\mathbb{R}^{n}),\mbox{ in particular }v^{\beta}_{j}\in L^{\infty}(\mathbb{R}^{2};\mathbb{R}^{n}).

(3.3)

3.2
Abstract setting for the boundary value problem (
1.1

Now we introduce an abstract setting of the type of Corollary
2.3
for the boundary value problem (
1.1
). We take

p_{1}
from Theorem
3.1

and
p_{2}
from (

) and fix

and

2<p<\min\{p_{1},p_{2}\},\;p^{\prime}:=\frac{p}{p-1}.

(3.4)

The Banach spaces
U
and
V
and their norms are defined by

U:=W_{0}^{1,p}(\Omega;\mathbb{R}^{n}),\;V:=W^{-1,p}(\Omega;\mathbb{R}^{n}),\;\|\cdot\|_{U}:=\|\cdot\|_{1,p},\;\|\cdot\|_{V}:=\|\cdot\|_{-1,p}.

(3.5)

The second norm
\|\cdot\|_{\infty}
in

of Corollary
2.3
is defined by (
1.20
).
Because the space dimension is two, the assumption (
2.8
) of Corollary

is satisfied in this setting.
Further, the
C^{1}
-smooth operators
F_{\varepsilon}:U\to V
of Theorem
2.1
are defined by

F_{\varepsilon}(u):=(A_{\varepsilon}+B_{\varepsilon})u+C(u)

with a
nonlinear operator
C:L^{\infty}(\Omega;\mathbb{R}^{n})\to W^{-1,2}(\Omega;\mathbb{R}^{n})
defined by

\langle C(u),\varphi\rangle_{1,2}:=\int_{\Omega}\Big(c_{i}^{\alpha}(x,u(x))\partial_{x_{i}}\varphi^{\alpha}(x)+d^{\alpha}(x,u(x))\varphi^{\alpha}(x)\Big)dx\mbox{ for all }\varphi\in W_{0}^{1,2}(\Omega;\mathbb{R}^{n}).

(3.6)

Because of assumption (
1.7
) we have that
the nonlinear operator

is
C^{1}
-smooth from

into
W^{-1,2}(\Omega;\mathbb{R}^{n})
,

\langle C^{\prime}(u)v,\varphi\rangle_{1,2}:=\int_{\Omega}\Big(\partial_{u^{\gamma}}c_{i}^{\alpha}(x,u(x))\partial_{x_{i}}\varphi^{\alpha}(x)+\partial_{u^{\gamma}}d^{\alpha}(x,u(x))\varphi^{\alpha}(x)\Big)v^{\gamma}(x)dx.

Remark that
the linear operator

can be considered as a compact operator from

into
W^{-1,p}(\Omega;\mathbb{R}^{n})

.

With these choices a vector function

is a weak solution to the boundary value problem (
1.1
) if and only if

belongs to the function space
U
and satisfies the operator equation

F_{\varepsilon}(u)=0
.
Here we used Theorem
3.1
again.

Finally, we define the element
u_{0}\in U
of Corollary
2.3
to be the solution
u_{0}
of the homogenized boundary value problem (

), which is given in Theorem
1.1
.
Remark that

\hat{A}u_{0}+C(u_{0})=0.

(3.7)

Therefore Theorem
3.1
yields that

u_{0}\in W_{0}^{1,p_{1}}(\Omega;\mathbb{R}^{n}),\mbox{ in particular }u_{0}\in L^{\infty}(\Omega;\mathbb{R}^{n}),

(3.8)

i.e.
u_{0}\in U=W_{0}^{1,p}(\Omega;\mathbb{R}^{n})
, as needed.

In order to prove Theorem
1.1
(i) we have to verify the conditions (

) and (

)
of Corollary
2.3

in the setting introduced above, i.e. that

\inf\left\{\|(A_{\varepsilon}+B_{\varepsilon}+C^{\prime}(u_{0}))u\|_{-1,p}:\;\varepsilon\in(0,\varepsilon_{0}],u\in W_{0}^{1,p}(\Omega;\mathbb{R}^{n}),\|u\|_{1,p}=1\right\}>0

\sup_{\|v\|_{1,p}\leq 1}\|(C^{\prime}(u_{0}+u)-C^{\prime}(u_{0}))v\|_{-1,p}\to 0\mbox{ for }\|u\|_{\infty}\to 0,

and we have to construct a family

\|\bar{u}_{\varepsilon}-u_{0}\|_{\infty}+\|(A_{\varepsilon}+B_{\varepsilon})\bar{u}_{\varepsilon}+C(\bar{u}_{\varepsilon})\|_{-1,p}\to 0\mbox{ for }\varepsilon\to 0.

(3.11)

3.3
Verification of (
3.9
)

Suppose that (
3.9
) is not true. Then there exist sequences
\varepsilon_{1},\varepsilon_{2},\ldots>0
and
u_{1},u_{2},\ldots\in W_{0}^{1,p}(\Omega;\mathbb{R}^{n})
such that

\lim_{l\to\infty}\Big(\varepsilon_{l}+\|(A_{\varepsilon_{l}}+B_{\varepsilon_{l}}+C^{\prime}(u_{0}))u_{l}\|_{-1,p}\Big)=0,

(3.12)

but

\|u_{l}\|_{1,p}=1\mbox{ for all }l.

(3.13)

Because
W^{1,p}(\Omega;\mathbb{R}^{n})
is reflexive and because it is compactly embedded into
L^{\infty}(\Omega;\mathbb{R}^{n})
, without loss of generality we may assume that there exists
u_{*}\in W^{1,p}(\Omega;\mathbb{R}^{n})
such that

u_{l}\rightharpoonup u_{*}\mbox{ for $l\to\infty$
weakly in }W^{1,p}(\Omega;\mathbb{R}^{n})\mbox{ and }\lim_{l\to\infty}\|u_{l}-u_{*}\|_{\infty}=0.

(3.14)

The functions
u_{l}
are continuous and vanish on the boundary
\partial\Omega
,
and for
l\to\infty
they converge uniformly on
\overline{\Omega}
to the continous function
u_{*}
.
Therefore
u_{*}\in W_{0}^{1,p}(\Omega;\mathbb{R}^{n})
.

Moreover,
C^{\prime}(u_{0})
is a linear bounded operator from
L^{\infty}(\Omega;\mathbb{R}^{n})
into
W^{-1,p}(\Omega;\mathbb{R}^{n})
, therefore (
3.12
) and (
3.14
) imply that

\lim_{l\to\infty}\|(A_{\varepsilon_{l}}+B_{\varepsilon_{l}})u_{l}+C^{\prime}(u_{0})u_{*}\|_{-1,p}=0.

(3.15)

The next lemma is the place where we use that the coefficients
b_{ij}^{\alpha\beta}
are localized defects in the sense of assumption (
1.4
), i.e. that they belong to
L^{1}(\mathbb{R}^{2})
:

Lemma 3.5

For any
r>s\geq 2
we have

\sup\left\{\|B_{\varepsilon}u\|_{-1,s}:\;u\in W^{1,r}(\Omega;\mathbb{R}^{n}),\;\|u\|_{1,r}\leq 1\right\}=O\left(\varepsilon^{2/s-2/r}\right)\mbox{ for }\varepsilon\to 0.

Proof

Because of
b^{\alpha\beta}_{ij}\in L^{\infty}(\mathbb{R}^{2})\cap L^{1}(\mathbb{R}^{2})
(cf. assumption (
1.4
)) we have for any
t\in[1,\infty)
that

\int_{\mathbb{R}^{2}}\left|b^{\alpha\beta}_{ij}(y)\right|^{t}dy=\left\|b^{\alpha\beta}_{ij}\right\|^{t}_{L^{\infty}(\mathbb{R}^{2})}\int_{\mathbb{R}^{2}}\left(\frac{\left|b^{\alpha\beta}_{ij}(y)\right|}{\left\|b^{\alpha\beta}_{ij}\right\|_{L^{\infty}(\mathbb{R}^{2})}}\right)^{t}dy\leq\left\|b^{\alpha\beta}_{ij}\right\|^{t-1}_{L^{\infty}(\mathbb{R}^{2})}\left\|b^{\alpha\beta}_{ij}\right\|_{L^{1}(\mathbb{R}^{2})}.

(3.16)

Now, take
r>s\geq 2
and define
s^{\prime}\in[2,\infty)
and
t\in(2,\infty)
by

1/s+1/s^{\prime}=1
and
1/s-1/r=1/t
.
Then
1/r+1/s^{\prime}+1/t=1
,
and the generalized Hölder inequality implies for
u\in W^{1,r}(\Omega)
that

\displaystyle\|B_{\varepsilon}u\|_{-1,s}

\displaystyle=

\displaystyle\sup_{\|\varphi\|_{1,s^{\prime}}\leq 1}\int_{\Omega}b^{\alpha\beta}_{ij}(x/\varepsilon)\partial_{x_{j}}u^{\beta}(x)\partial_{x_{i}}\varphi^{\alpha}(x)dx

\displaystyle\leq

\displaystyle\|u\|_{1,r}\left(\sum_{i,j=1}^{2}\sum_{\alpha,\beta=1}^{n}\int_{\Omega}|b^{\alpha\beta}_{ij}(x/\varepsilon)|^{t}dx\right)^{1/t}

\displaystyle\leq

\displaystyle\varepsilon^{2/t}\;\|u\|_{1,r}\left(\sum_{i,j=1}^{2}\sum_{\alpha,\beta=1}^{n}\int_{\mathbb{R}^{2}}|b^{\alpha\beta}_{ij}(y)|^{t}dy\right)^{1/t}.

Hence,
(
3.16
)
implies the assertion of the lemma.

If we apply Lemma
3.5
with
r=p
and
s=2
(cf. (
3.4
)), then (
3.13
) implies that
\|B_{\varepsilon_{l}}u_{l}\|_{-1,2}\to 0
for
l\to\infty
. Hence, (
3.15
) yields that

\lim_{l\to\infty}\|A_{\varepsilon_{l}}u_{l}+C^{\prime}(u_{0})u_{*}\|_{-1,2}=0.

(3.17)

Now we use the following theorem, which is well-known in periodic homogenization theory for linear elliptic equations and systems with
L^{\infty}
-coefficients (see, e.g.
[
14
, Lemma 8.6]
,
[
46
, Theorem 2.3.2]
,
[
47
]
).
Its proof is based on the Div-Curl Lemma.
It claims that the sequence of diffusion tensors
a_{ij}^{\alpha\beta}(\cdot/\varepsilon_{1}),a_{ij}^{\alpha\beta}(\cdot/\varepsilon_{2}),\ldots

H-converges to the diffusion tensor
\hat{a}_{ij}^{\alpha\beta}
. We formulate this in the language of the differential operators

A_{\varepsilon_{l}}
and
\hat{A}
.

Theorem 3.6

Let be given
u\in W^{1,2}(\Omega;\mathbb{R}^{n})
and
\phi\in W^{-1,2}(\Omega;\mathbb{R}^{n})
and sequences
\varepsilon_{1},\varepsilon_{2},\ldots>0
and
u_{1},u_{2},\ldots\in W^{1,2}(\Omega;\mathbb{R}^{n})
such that

u_{l}\rightharpoonup u\mbox{ for $l\to\infty$ weakly in
$W^{1,2}(\Omega;\mathbb{R}^{n})$ and }\lim_{l\to\infty}\left(\varepsilon_{l}+\|A_{\varepsilon_{l}}u_{l}-\phi\|_{-1,2}\right)=0.

Then
\hat{A}u=\phi
.

Because of (
3.14
), (
3.17
) and Theorem
3.6
it follows that

(\hat{A}+C^{\prime}(u_{0}))u_{*}=0,

i.e. that

u_{*}
is a weak solution
to the linearized boundary value problem
(
1.18
). Hence, by assumption of Theorem
1.1
, we get that
u_{*}=0
.
Therefore
(
3.15
) implies that
\|(A_{\varepsilon_{l}}+B_{\varepsilon_{l}})u_{l}\|_{-1,p}\to 0
for

.
But this contradicts to (
3.2
) and (
3.13
).

3.4
Verification of (
3.10
)

Because of assumption (
1.7
) the functions
u\mapsto\partial_{u_{\gamma}}c^{\alpha}_{i}(\cdot,u)

and
u\mapsto\partial_{u_{\gamma}}d^{\alpha}(\cdot,u)

are continuous from
\mathbb{R}^{n}
into
L^{\infty}(\Omega)
and, hence, uniformly continuous on bounded sets. Therefore

[\phi^{\alpha\gamma}_{i}(u)](x):=\partial_{u_{\gamma}}c^{\alpha}_{i}(x,u_{0}(x)+u(x))-\partial_{u_{\gamma}}c^{\alpha}_{i}(x,u_{0}(x))

and

[\psi^{\alpha\gamma}(u)](x):=\partial_{u_{\gamma}}d^{\alpha}(x,u_{0}(x)+u(x))-\partial_{u\gamma}d^{\alpha}(x,u_{0}(x))

tend to zero for
\|u\|_{\infty}\to 0

uniformly with respect to
x\in\Omega
.
Moreover, for
u,v\in L^{\infty}(\Omega;\mathbb{R}^{n})

and
\varphi\in W_{0}^{1,p^{\prime}}(\Omega;\mathbb{R}^{n})

we have

\displaystyle\langle(C^{\prime}(u_{0}+u)-C^{\prime}(u_{0}))v,\varphi\rangle_{1,p^{\prime}}=\int_{\Omega}\Big([\phi_{i}^{\alpha\gamma}(u)](x)\partial_{x_{i}}\varphi^{\alpha}(x)+[\psi^{\alpha\gamma}(u)](x)\varphi^{\alpha}(x)\Big)v^{\gamma}(x)dx

\displaystyle\leq\mbox{const}\sum_{\alpha,\gamma=1}^{n}\left(\sum_{i=1}^{2}\|\phi^{\alpha\gamma}_{i}(u)\|_{\infty}+\|\psi^{\alpha\gamma}(u)\|_{\infty}\right)\|v\|_{\infty}\|\varphi\|_{1,p^{\prime}},

where the constant does not depend on
u
,
v
and
\varphi
.
Hence, (
3.10
) is proved.

Remark 3.7

In fact, we proved slightly more than (

), namly that
\langle(C^{\prime}(u_{0}+u)-C^{\prime}(u_{0}))v,\varphi\rangle_{1,p^{\prime}}
tends to zero for

not only uniformly with respect to

and

, but even

and

3.5
Construction of approximate solutions with (
3.11
)

In this subsection we will construct a family
\bar{u}_{\varepsilon}\in W_{0}^{1,p}(\Omega;\mathbb{R}^{n})

with
(
3.11
).
For that we will do some calulations which are well-known in periodic homogenization theory for linear elliptic problems (cf., e.g.
[
46
, Chapter 3.2]
), and some estimates which seem to be new.

We denote by
\|\cdot\|
the Euclidean norm in
\mathbb{R}^{2}
and take a mollifier function, i.e. a
C^{\infty}
-function
\rho:\mathbb{R}^{2}\to\mathbb{R}
such that

\rho(x)\geq 0\mbox{ and }\rho(x)=\rho(-x)\mbox{ for all }x\in\mathbb{R}^{2},\;\rho(x)=0\mbox{ for }\|x\|\geq 1,\int_{\mathbb{R}^{2}}\rho(x)dx=1,

and for
\delta>0
we define linear Steklov smoothing operators
S_{\delta}:L^{1}(\Omega)\to C^{\infty}(\mathbb{R}^{2})
by

[S_{\delta}u](x):=\int_{\Omega}\rho_{\delta}(x-\xi)u(\xi)d\xi\mbox{ with }\rho_{\delta}(x):=\rho(x/\delta)/\delta^{2}.

Lemma 3.8

For all
r>1
we have

\displaystyle\lim_{\delta\to 0}\int_{\Omega}|u(x)-[S_{\delta}u](x)|^{r}dx=0\mbox{ for all }u\in L^{r}(\Omega),

(3.18)

\displaystyle\sup\left\{\delta^{2}\|S_{\delta}u\|^{r}_{\infty}:\;\delta\in(0,1],\;u\in L^{r}(\Omega),\;\int_{\Omega}|u(x)|^{r}dx\leq 1\right\}<\infty,

(3.19)

\displaystyle\sup\left\{\delta^{r}\int_{\Omega}|\partial_{x_{i}}S_{\delta}u(x)|^{r}dx:\;\delta\in(0,1],\;u\in L^{r}(\Omega),\;\int_{\Omega}|u(x)|^{r}dx\leq 1,\right\}<\infty.

(3.20)

Proof

Assertion (
3.18
) is proved e.g. in

[
1
, Lemma 1.1.1]
.

In order to prove assertions (
3.19
) and (
3.20
) take
\delta>0
,
r,r^{\prime}>1
with
1/r+1/r^{\prime}=1
, and take
u\in L^{r}(\Omega)
.
Then the Hölder inequality implies that for all
x\in\Omega
we have

|[S_{\delta}u](x)|=\left|\int_{\Omega}u(\xi)\rho_{\delta}(x-\xi)^{1/r}\rho_{\delta}(x-\xi)^{1/r^{\prime}}d\xi\right|\leq\left(\int_{\Omega}|u(\xi)|^{r}\rho_{\delta}(x-\xi)d\xi\right)^{1/r}.

Here we used that

\int_{\mathbb{R}^{2}}\rho_{\delta}(x-\xi)d\xi=\int_{\mathbb{R}^{2}}\rho(\xi)d\xi=1.

It follows that

|[S_{\delta}u](x)|^{r}\leq\frac{1}{\delta^{2}}\int_{\Omega}|u(\xi)|^{r}\rho((x-\xi)/\delta)d\xi\leq\mbox{const }\frac{1}{\delta^{2}}\int_{\Omega}|u(\xi)|^{r}d\xi,

where the constant does not depend on
\delta
,
x
and
u
.
Hence, (
3.19
) is proved.

In order to prove assertion (
3.20
) we use that

\partial_{x_{i}}\rho_{\delta}(x)=-\partial_{x_{i}}\rho(x/\delta)/\delta^{3}
for all
x\in\Omega
and, therefore, that

\int_{\mathbb{R}^{2}}|\partial_{x_{i}}\rho_{\delta}(x-\xi)|d\xi=\frac{1}{\delta^{3}}\int_{\mathbb{R}^{2}}|\partial_{x_{i}}\rho((x-\xi)/\delta)|d\xi=\frac{1}{\delta}\int_{\mathbb{R}^{2}}|\partial_{x_{i}}\rho(\xi)|d\xi.

It follows that

\displaystyle|[\partial_{x_{i}}S_{\delta}u](x)|

\displaystyle\leq

\displaystyle\left(\int_{\Omega}|u(\xi)|^{r}|\partial_{x_{i}}\rho_{\delta}(x-\xi)|d\xi\right)^{1/r}\left(\int_{\Omega}|\partial_{x_{i}}\rho_{\delta}(x-\xi)|d\xi\right)^{1/r^{\prime}}

\displaystyle\leq

\displaystyle\mbox{ const }\frac{1}{\delta^{1/r^{\prime}}}\left(\int_{\Omega}|u(\xi)|^{r}|\partial_{x_{i}}\rho_{\delta}(x-\xi)|d\xi\right)^{1/r}

and, hence,

\displaystyle\int_{\Omega}\left|[\partial_{x_{i}}S_{\delta}u](x)\right|^{r}dx

\displaystyle\leq

\displaystyle\mbox{ const }\frac{1}{\delta^{r/r^{\prime}}}\int_{\Omega}|u(\xi)|^{r}\int_{\Omega}|\partial_{x_{i}}\rho_{\delta}(x-\xi)|dx\;d\xi

\displaystyle\leq

\displaystyle\mbox{ const }\frac{1}{\delta^{r}}\int_{\Omega}|u(\xi)|^{r}d\xi,

where, again, the constants do not depend on
\delta
,
x

5.1
Maximal Sobolev-Morrey regularity for linear elliptic equations

In order to introduce Morrey spaces and Sobolev-Morey spaces (cf., e.g.

(5.2)

Take

The Morrey space

is the subspace of the Lebesgue

with norm

\|u\|_{2,\omega}:=\sup_{x\in\Omega,r\in(0,1]}r^{-\omega/2}\left(\int_{\Omega_{x,r}}|u(\xi)|^{2}d\xi\right)^{1/2}

The Morrey space

W^{1,2,\omega}(\Omega):=\{u\in W^{1,2}(\Omega):\;\|u\|_{1,2,\omega}<\infty\}

It is well-known that

\left.\begin{array}[]{l}W^{1,2,\omega}(\Omega)\mbox{ is compactly embedded into }C^{0,\alpha}(\overline{\Omega})\\
