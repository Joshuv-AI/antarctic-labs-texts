Partial Feedback Online Learning
Shihao Shao 1 , Cong Fang 2 , Zhouchen Lin 2 , and Dacheng Tao 1

Abstract
We study partial-feedback online learning, where each instance admits a set of correct labels, but the learner only observes one correct label per round; any prediction within the correct set is counted as correct. This model captures settings such as language generation, where multiple responses may be valid but data provide only a single reference. We give a near-complete characterization of minimax regret for both deterministic and randomized learners in the set-realizable regime, i.e., in the regime where sublinear regret is generally attainable. For deterministic learners, we introduce the Partial-Feedback Littlestone dimension (PFLdim) and show it precisely governs learnability and minimax regret; technically, PFLdim cannot be defined via the standard version space, requiring a new collection version space viewpoint and an auxiliary dimension used only in the proof. We further develop the Partial-Feedback Measure Shattering dimension (PMSdim) to obtain tight bounds for randomized learners. We identify broad conditions ensuring inseparability between deterministic and randomized learnability (e.g., finite Helly number or nested-inclusion label structure), and extend the argument to set-valued online learning, resolving an open question of 20 . Finally, we show a sharp separation from weaker realistic and agnostic variants: outside set realizability, the problem can become information-theoretically intractable, with linear regret possible even for | ℋ | = 2 \lvert\mathcal{H}\rvert=2 . This highlights the need for fundamentally new, noise-sensitive complexity measures to meaningfully characterize learnability beyond set realizability.

Introduction

We first recall the set-valued online learning setting introduced by
20
. The learner plays a round-by-round game with an adversary over an instance space
\mathcal{X}
and a label space
\mathcal{Y}
. In each round
t\in[T]
, the adversary selects an instance
x_{t}\in\mathcal{X}
, the learner predicts a label
\hat{y}_{t}\in\mathcal{Y}
, and the adversary then reveals the set of all valid labels
S_{t}=\{y_{t}^{(1)},\ldots,y_{t}^{(k)}\}\subseteq\mathcal{Y}
, incurring the loss
\mathbbm{1}(\hat{y}_{t}\notin S_{t})
. This framework subsumes multiclass online learning
(
11
)
as the special case where
|S_{t}|=1
for all
t
. While
20
provide a detailed characterization under this
full-feedback
protocol, many practical scenarios exhibit a weaker, more realistic feedback model: instead of observing the entire set
S_{t}
, the learner only observes a single label
y_{t}\in S_{t}
(e.g., one admissible response), and does not observe whether
\hat{y}_{t}\in S_{t}
(i.e., the loss
\mathbbm{1}(\hat{y}_{t}\notin S_{t})
is not revealed). This captures, for instance, language prediction tasks where datasets typically contain only one acceptable answer per prompt despite the existence of many (potentially infinitely many) valid responses
(
16
)
. Existing combinatorial characterizations are not directly applicable in this partial-feedback regime, since the withheld set-valued structure cannot be used by the learner during the interaction; under a worst-case adversary, the unobserved sets are effectively indistinguishable from being specified only after the game ends. This partial-feedback (online learning with weak supervision) protocol strictly strengthens the adversary, and renders existing combinatorial analyses inadequate. The goal of this paper is to characterize learnability under this partial-feedback protocol.

1.1
Formal Definition

In this section, we give a rigorous definition of our learning setting, as well as fix the necessary notations. Formally, the game is associated with an instance space

\mathcal{Y}
, a subcollection

\sigma(\mathcal{Y})

\mathcal{H}

The hypothesis space
\mathcal{H}
comes into play when we define the realistic and agnostic settings. The agnostic setting does not impose any constraint to the game. The realistic setting, on the other hand, requires the real label set to obey some rules. In our paper, we discuss two different types of the realistic setting. We term them, “set realization” and “existence realization”, respectively. The set realizable setting requires that there exists a fixed subset
H^{\star}
from the power set
P(\mathcal{H})
such that
S_{t}=\{h(x_{t})\mid h\in H^{\star}\}
for all
t
. In what follows, we will let
H(x_{t}):=\{h(x_{t})\mid h\in H\}
for shorthand. On the other hand, the existence realizable setting requires that at least one label in each
S_{t}
is output by a function in
\mathcal{H}
. It is noteworthy that the realizable setting of multiclass online learning belongs to both settings above simultaneously, as there is only one correct label in each round in the multiclass online learning. In the classical online-learning literature, the agnostic setting is often viewed as a “noisy” or non-realizable regime in a broad sense: the phenomenon that the hypothesis class
\mathcal{H}
cannot fully explain the ground truth is attributed to noise or model misspecification
(
12
;
14
)
. In this sense, the set realizable setting corresponds to a fully noise-free (strong consistency) assumption, whereas the existence realizable setting can be regarded as a weaker, “mild-noise” variant—it only requires that, for each round
t
, there exists some
h\in\mathcal{H}
such that
h(x_{t})\in S_{t}
, but does not require
\mathcal{H}
to generate the entire valid label set
S_{t}
. In the same sense, the multiclass realizable setting is noise-free just as in the set-realizable case, because all the (unique) ground-truth label in each round is always output by some hypothesis in
\mathcal{H}
.

grows sublinearly in

The main goal of this work is to characterize the above learnability given some structural properties of the hypothesis space. The contributions of this paper can be summarized as follows: for the set-realizable setting: (1) we propose a novel tailored combinatorial dimension, PFLdim, to determine the minimax regret with deterministic learner, via leveraging an auxiliary dimension, PPFLdim, that will not show up in the final form; (2) we compare PFLdim with Littlestone and set Littlestone dimension to compare the learnability between different settings; (3) the PFLdim is extended to PMSdim to characterize the learnability with tight bounds with randomized learners; (4) we show that a finite Helly number, or a nested inclusion property are both sufficient condition for inseparability between deterministic and randomized learners; (5) we show that there exists a case that holds nested inclusion property, but not with a finite Helly number, which makes Helly number alone not sufficient for the inseparability, and we further extend this statement to set-valued setting to answer
20
’s open problem, namely, Helly number is not sufficient in set-valued setting as well; (6) under randomized learners, we show that there is a separation in learnability based on whether the adversary can read the label output from the predicted measure in each round; (7) we show that the learnability becomes nearly impossible under existence-realizable and agnostic setting, with an evidence that a hypothesis space with only two functions can force any learner to incur linear regret under these settings, and leave proposing tailored dimension to characterize the noise to better characterize the learnability under such scenarios as an open direction.

In this paper, we present algorithms as an information-theoretic strategy; computational efficiency is not our focus. In what follows, we present most theorems with proof sketches, and leave the detailed proof in the appendix. In Section
2
and
3
, the analysis is conducted under set-realizable setting, and we will show the hardness under existence-realizable and agnostic settings in Section
4
. For the analysis under set-realizable setting, we denote the collection of functions sets in

that can output at least one set in
\mathcal{S}(\mathcal{Y})
at every
x\in\mathcal{X}
as
\tilde{\mathcal{H}}

1.2
Related Works

Our work connects to several lines of research in online learning under adversarial sequences and limited feedback. In full-information online classification, combinatorial/sequential dimensions provide sharp characterizations of learnability and optimal rates: the Littlestone dimension was introduced by
15
in the realizable mistake-bound setting, and the agnostic minimax-regret viewpoint was developed in
3
, with broader links to sequential complexity frameworks such as sequential Rademacher complexity and related minimax analyses
(
17
;
18
)
. Multiclass online learning exhibits additional subtleties; classical structural results relate learnability and ERM-style principles
(
7
)
, and the gap between full-information and bandit feedback has been quantified via the price of bandit information
(
6
)
. Recent work has obtained sharp characterizations even for unbounded label spaces in the full-information model
(
11
)
and in the bandit-feedback model via bandit-specific sequential dimensions
(
19
)
. Closest in spirit to our setting is online learning with set-valued feedback, where the environment reveals the entire acceptable set each round and one predicts any label in the set; this model was recently characterized via tailored dimensions and exhibits separations between deterministic and randomized learnability
(
20
)
. Our partial-feedback protocol can be viewed as a further weakening of supervision: only one correct label is revealed while evaluation is still with respect to an unobserved set, placing it in the broader landscape of partial-information online learning such as adversarial bandits
(
1
)
and partial monitoring
(
2
)
, but with an observation structure that is not a direct loss-revealing signal. Another related thread studies whether minimax-optimal performance can be achieved by proper or otherwise restricted predictors; recent work provides combinatorial characterizations of minimax in
0/1
games with simple predictors
(
10
)
, and related progress studies refined rates in nonparametric online learning
(
8
)
as well as randomized Littlestone-type notions for optimal prediction
(
9
)
. Finally, in the batch setting, ambiguous/partial-label supervision has been studied theoretically, e.g., learning from candidate label sets
(
5
)
and single-positive multi-label learning where each instance is annotated with only one relevant label
(
21
)
; our problem is distinct in being adversarial and sequential with strictly weaker feedback—the learner observes only one revealed correct label while performance is evaluated against an unobserved valid-label set—which motivates new shattering notions and a minimax-regret characterization tailored to this protocol.

2
Deterministic Learners

2.1
Motivation from Finite-class Learnability

Consider
|\mathcal{H}|=n<\infty
under set-realizability and deterministic learners.
Unlike multiclass or set-valued feedback, partial feedback does not reveal which labels are wrong, so the usual
version-space elimination (and hence the halving argument) does not directly apply.
Indeed, the revealed label provides only existence information and typically does not falsify any single hypothesis
(e.g., if
\mathcal{H}=\{f_{0}\equiv 0,f_{1}\equiv 1\}
and
y_{t}^{\rm vis}=0
, then
f_{1}
need not be ruled out since
H^{\star}
could be
\{f_{0},f_{1}\}
), so the version space remains unchanged. This is problematic since many dimension-based online learning arguments rely on a monotone decrease of a combinatorial measure along the version space, which may not decrease at all under partial feedback.
A reasonable workaround is to maintain a
collection version space

\tilde{V}_{t}\subseteq\mathcal{P}(\mathcal{H})
and prune it using
y^{\rm vis}_{t}
,
eliminating those collections
H
with
y^{\rm vis}_{t}\notin H(x_{t})
. This yields an (admittedly loose) finite-class learnability guarantee.

Theorem 2

(Finite-class learnability (coarse bound))
.

Under partial feedback and set-realizability, any finite
\mathcal{H}
with
|\mathcal{H}|=n
is online learnable by a deterministic algorithm with
minimax regret at most
\sum_{i=1}^{\lfloor n/2\rfloor}\binom{n}{i}
.

Proof sketch.

We maintain a
collection version space

\tilde{V}_{t}\subseteq\mathcal{P}(\mathcal{H})
(initialized as
\tilde{V}_{0}=\mathcal{P}(\mathcal{H})
) that keeps all hypothesis-collections consistent with revealed labels. Under set-realizability, there exists
H^{\star}\subseteq\mathcal{H}
with
S_{t}=H^{\star}(x_{t})
, hence
H^{\star}\in\tilde{V}_{t}
for all
t
.
On round
t
, if there exists a label
y
such that
y\in H(x_{t})
for every
H\in\tilde{V}_{t-1}
, then predicting
y
is always correct. Otherwise, predict a label with maximum support among
\{f(x_{t}):f\in\mathcal{H}\}
(a majority vote over
\mathcal{H}
). After observing
y_{t}^{\mathrm{vis}}
, update

\tilde{V}_{t}=\{H\in\tilde{V}_{t-1}:y_{t}^{\mathrm{vis}}\in H(x_{t})\}
.
If a mistake happens in the majority-vote branch, then
V_{t}^{\mathrm{vis}}:=\{f\in\mathcal{H}:f(x_{t})=y_{t}^{\mathrm{vis}}\}
must satisfy
|V_{t}^{\mathrm{vis}}|\leq\lfloor n/2\rfloor
. Moreover, these sets cannot repeat across two mistaken rounds: if
V_{t}^{\mathrm{vis}}=V_{t^{\prime}}^{\mathrm{vis}}
for some
t<t^{\prime}
, then by monotonicity of pruning we would have
y_{t^{\prime}}^{\mathrm{vis}}\in H(x_{t^{\prime}})
for all
H\in\tilde{V}_{t^{\prime}-1}
, forcing the algorithm to predict
y_{t^{\prime}}^{\mathrm{vis}}
in the first branch and thus not err at
t^{\prime}
. Therefore each mistake corresponds to a distinct subset of
\mathcal{H}
of size at most
\lfloor n/2\rfloor
, giving at most
\sum_{i=1}^{\lfloor n/2\rfloor}\binom{n}{i}
mistakes (hence regret).

\blacksquare

Since the bound is exponential in
n
, it mainly serves as a warm-up,
highlighting that partial feedback is non-trivial even for finite classes and motivating our sharper, dimension-based characterizations.

2.2
Partial-Feedback Littlestone Dimension

To characterize the learnability of a specific setting, it is conventional to propose a tailored dimension, and prove that the minimax regret can be tightly bounded by this specific dimension. In the finite hypothesis class case, smaller number of the functions means easier learning, which are also evident in the previous finite case analysis. Likewise, we need a quantity to justify the complexity of the hypothesis class whether finite or infinite, and this is where the combinatorial dimensions come into play. Larger dimensions correspond to harder learning problems. The combinatorial dimensions for online learning (including ours) are typically defined via rooted
\mathcal{Y}
-ary trees whose nodes are labeled by instances in
\mathcal{X}
(and sometimes whose edges carry additional annotations).
We therefore fix the following notation.
A
\mathcal{X}
-labeled
\mathcal{Y}
-ary tree of depth
d
is a mapping
\mathcal{T}:\mathcal{Y}^{<d}\to\mathcal{X}
, where each node is indexed by a prefix
\mathbf{y}_{1:t-1}\in\mathcal{Y}^{t-1}
and labeled by the instance
\mathcal{T}(\mathbf{y}_{1:t-1})\in\mathcal{X}
.
Specifically, one may view a
full

\mathcal{T}
as a map
\mathcal{T}:\mathcal{Y}^{\star}\to\mathcal{X}\cup\{\varnothing\}
such that
\mathcal{T}(y)\neq\varnothing
for all
|y|<d
and
\mathcal{T}(y)=\varnothing
for all
|y|\geq d
.
When needed, we also allow edge annotations: for each
t\in[d]
, an annotation function
f_{t}:\mathcal{Y}^{t}\to\mathcal{M}
assigns an element of
\mathcal{M}
to the edge corresponding to the length-
t
path
\mathbf{y}_{1:t}
. We first recap the previous combinatorial dimension for online learning problems.

Definition 3

(Set, Multiclass, and Bandit Littlestone Dimension
(
20
)
)
.

Let
\mathcal{T}
be a depth-
d

\mathcal{X}
-valued,
\mathcal{Y}
-ary completed tree with annotation functions

be the hypothesis class we consider. If there exists a sequence,
(f_{1},\cdots,f_{d})

\mathcal{T}
is shattered by

\mathcal{S}(\mathcal{Y})=\{\{y\}:y\in\mathcal{Y}\}
holds, then it is called the Multiclass Littlestone Dimension (MLdim), and if
\mathcal{S}(\mathcal{Y})=\{A_{y}\in\mathcal{Y}\ \mid\ A_{y}=\mathcal{Y}\setminus\{y\},\ y\in\mathcal{Y}\}
holds, then it is called the Bandit Littlestone Dimension (BLdim).

Remark
.

The above definition unifies several standard online classification models by choosing different
set systems
\mathcal{S}(\mathcal{Y})

\mathcal{S}(\mathcal{Y})=\{\{y\}:y\in\mathcal{Y}\}
consists of singletons,

, i.e., Ldim

\mathcal{S}(\mathcal{Y})=\{\mathcal{Y}\setminus\{y\}:y\in\mathcal{Y}\}

)
.

These combinatorial dimensions uniquely determine the deterministic learnability of the corresponding online learning problem.

Theorem 4

(Deterministic Learnability Determined by SLdim

20

)
.

Consider a set-valued online learning problem. Let the subset collection be
\mathcal{S}(\mathcal{Y})\subseteq\sigma(\mathcal{Y})

{\rm inf}_{\rm Deterministic\ \mathcal{A}}R_{\mathcal{A}}(T,H)={\rm SL}(\mathcal{H})

Remark
.

By changing
\mathcal{S}(\mathcal{Y})

The Littlestone-like dimension treats each edge as the prediction, and the annotation as the revealed labels.
The partial-feedback protocol, however, is not directly captured by the existing Littlestone-type dimensions.
The key obstacle is that the learner never observes whether its prediction is correct, nor the full valid-label set
S_{t}
; it only observes a single witness label
y^{\rm vis}_{t}\in S_{t}
.
In the dimensions of Definition
3
, the adversary’s feedback along a root-to-leaf path is encoded by edge annotations:
for a fixed prefix
\mathbf{y}_{1:t}
, the annotation at depth
t
is determined solely by that prefix and therefore is consistent across all extensions
\mathbf{y}_{1:t}\sqcup\mathbf{y}_{t+1:d}
.
This reflects full-information models where the entire supervision signal (e.g., the set
S_{t}
) is revealed each round.
In contrast, under partial feedback, after observing only
\mathbf{y}^{\rm vis}_{1:t}
there may remain multiple valid-label sets (or equivalently, multiple ground-truth collections
H^{\star}
) consistent with the history, so the “unseen part” of
S_{t}
is not pinned down by the prefix.
This motivates a new dimension that explicitly captures such branching of the underlying ground truth under partial revelation, which we define next.

Definition 5

(Partial-Feedback Littlestone Dimension)
.

\mathcal{T}
be an
\mathcal{X}
-valued,
\mathcal{Y}

for all

2.

\Big|\big\{t\in[d]:y_{t}\notin H_{\mathbf{y}_{1:d}}\big(\mathcal{T}(\mathbf{y}_{1:t-1})\big)\big\}\Big|\geq q.

For fixed

In contrast to the previous dimensions, the annotation function

outputs the label that the adversary reveals to the learner, instead of the full label set. We show that this dimension can be used to tightly bound the minimax regret. We denote the PFLdim

Theorem 6

(Deterministic Learnability determined by PFLdim)
.

Fix a subset collection
\mathcal{S}(\mathcal{Y})\subseteq\sigma(\mathcal{Y})
, and a hypothesis space
\mathcal{H}
. It holds that
{\rm inf}_{\rm Deterministic\ \mathcal{A}}R_{\mathcal{A}}(T,\mathcal{H})={\rm PFL}_{T}(\tilde{\mathcal{H}})
for all
T\in\mathbbm{N}_{+}
.

When the previous Littlestone-type dimensions (e.g.,
{\rm SLdim}
) are infinite, deterministic learnability in the corresponding full-information models fails: for every horizon
T
, an adversary can force
\Omega(T)
mistakes even in the realizable setting.
In contrast, Theorem
6
shows that partial-feedback learnability is governed by the
growth
of
{\rm PFL}_{T}(\mathcal{H})
with
T
, rather than by a mere finiteness condition.
In particular, even if
\sup_{d\geq 1}{\rm PFL}_{d}(\tilde{\mathcal{H}})=\infty
, the problem can still be learnable provided
{\rm PFL}_{d}(\tilde{\mathcal{H}})=o(d)
.

Corollary 7

(Deterministic learnability via the growth of
{\rm PFL}_{d}
)
.

Fix
\mathcal{S}(\mathcal{Y})\subseteq\sigma(\mathcal{Y})
and
\mathcal{H}\subseteq\mathcal{Y}^{\mathcal{X}}
.
Then
\mathcal{H}
is online learnable by deterministic algorithms (i.e., admits sublinear regret) if and only if

{\rm PFL}_{d}(\tilde{\mathcal{H}})=o(d)\qquad\text{as }d\to\infty.

We now outline the proof of Theorem
6
, which is established via matching upper and lower bounds.
For the upper bound, we construct a deterministic strategy and show that its worst-case regret over
T

{\rm PFL}_{T}(\tilde{\mathcal{H}})
.
A natural first attempt is to mimic the Standard Optimal Algorithm of
20
,
which at each step predicts a label that minimizes the resulting
{\rm SLdim}
.
However, this approach crucially relies on full-information feedback: in the set-valued model, the learner can certify whether its prediction is correct and can prune the version space accordingly, and the associated potential (captured by
{\rm SLdim}
) decreases by at least one on each mistake, yielding a mistake bound equal to
{\rm SLdim}
.
In our partial-feedback protocol, by contrast, the learner observes only a single revealed label and cannot infer whether its own prediction was correct, so past mistakes are not observable and the potential-drop argument breaks. To handle this additional uncertainty, we introduce an auxiliary combinatorial quantity that tracks
prefix uncertainty
—informally, it accounts for the set of ways the unobserved parts of the valid-label sets could be consistent with the revealed labels along a history prefix.
This auxiliary dimension is used solely as a proof device to make the inductive argument go through; importantly, it does not appear in the final minimax characterization, which depends only on
{\rm PFL}_{T}(\tilde{\mathcal{H}})
.

Proof sketch of Theorem
6
.

We give matching upper and lower bounds.

Upper bound.

Consider DPFLA (Algorithm
1
) and let
\tilde{V}_{t}\subseteq\tilde{\mathcal{H}}
be the maintained collection version space.
At any time
t
, the realized number of mistakes up to horizon
T
is dominated by the prefix-aware auxiliary potential

{\rm PPFL}_{T-t}(\mathbf{x}_{1:t},\hat{\mathbf{y}}_{1:t},\tilde{V}_{t})
, since
{\rm PPFL}
counts (over the worst compatible continuation of length

\leq T-t
) how many rounds in the prefix+continuation can have
\hat{y}
outside the valid-label set generated by some
consistent collection
H\in\tilde{V}_{t}
. Hence it suffices to upper bound this potential along the algorithmic trajectory.

We show by induction on
t
that the PPFL potential never exceeds the initial PFL value:

{\rm PPFL}_{T-t}(\mathbf{x}_{1:t},\hat{\mathbf{y}}_{1:t},\tilde{V}_{t})\ \leq\ {\rm PFL}_{T}(\tilde{\mathcal{H}})\qquad\forall\,t\in\{0,\ldots,T\}.

The base case
t=0
holds since PPFLdim reduces to PFLdim on an empty prefix.
For the inductive step, suppose the inequality fails at time
t
. By the min–max prediction rule of DPFLA, this would imply
that for every candidate prediction
\hat{y}
there exists a feasible revealed label
y\in Q_{t}
such that the updated state

\tilde{V}^{(x_{t},y)}_{t-1}
yields a PPFL value larger by at least
1
than

{\rm PPFL}_{T-(t-1)}(\mathbf{x}_{1:t-1},\hat{\mathbf{y}}_{1:t-1},\tilde{V}_{t-1})
.
Using the witness continuation tree from the PPFL definition for this worst-case choice, one can prepend a new root labeled by

x_{t}
and define the first-edge visible annotation to be the revealed label
y_{t}^{\rm vis}
, thereby constructing a depth

T-(t-1)
tree witnessing prefix-
q
shattering for the shorter prefix
(\mathbf{x}_{1:t-1},\hat{\mathbf{y}}_{1:t-1})
with

q\geq{\rm PPFL}_{T-(t-1)}(\mathbf{x}_{1:t-1},\hat{\mathbf{y}}_{1:t-1},\tilde{V}_{t-1})+1
.
By definition of PPFL, this would force

{\rm PPFL}_{T-(t-1)}(\mathbf{x}_{1:t-1},\hat{\mathbf{y}}_{1:t-1},\tilde{V}_{t-1})\geq q
, a contradiction.
Thus the potential is always bounded by
{\rm PFL}_{T}(\tilde{\mathcal{H}})
, and so is the regret.

Lower bound.

Let
q={\rm PFL}_{T}(\tilde{\mathcal{H}})
, and take a depth-
T
tree
\mathcal{T}
and visible-label annotations witnessing that
\mathcal{T}
is
q
-shattered.
An adversary plays the instance
x_{t}=\mathcal{T}(\hat{\mathbf{y}}_{1:t-1})
(following the learner’s prediction path) and reveals

y_{t}^{\rm vis}=f_{t}^{\rm vis}(\hat{\mathbf{y}}_{1:t})
. By shattering, there exists a collection
H^{\star}\in\tilde{\mathcal{H}}
consistent with all
revealed labels (hence the play is set-realizable), yet along the induced path the learner’s predictions fall outside

H^{\star}(x_{t})
on at least
q
rounds. Therefore any deterministic learner incurs at least
q
mistakes.

Combining the two bounds yields
\inf_{\text{det }\mathcal{A}}R_{\mathcal{A}}(T,\mathcal{H})={\rm PFL}_{T}(\tilde{\mathcal{H}})
.

\blacksquare

We show that PFLdim can be used to improve the bound in Theorem

3.2
Relation between Randomized and Deterministic Settings

It is obvious that the learnability under randomized learners is sufficient to conclude the learnability under deterministic learners, as deterministic learners are a special case of the randomized learners. The discussion lies in when the learnability is identical in these two settings, and when it is not. A structural property—the finiteness of Helly number
(
13

Definition 14

(Helly Number)
.

The Helly number of the collection of sets,
\mathscr{H}(\mathcal{C})
is the minimum

\mathcal{S}

(2) Strict separation when

We prove the second half by the following example.

Example 2
.

Let
\mathcal{X}=[-\pi,\pi]

\mathcal{Y}=[-1,1]

\mathcal{S}_{\rm pf}(\mathcal{Y})=\sigma(\mathcal{S}_{\rm mc}(\mathcal{Y}))

is multiclass online learnable, but not partial-feedback online learnable in the deterministic set-realizable setting.

Multiclass learnability.

Fix any round and any instance

After the learner predicts, the adversary reveals the full label

.
For this fixed

\mathcal{H}
consistent with

2

A finite multiclass hypothesis class is online learnable with a constant mistake bound, therefore
\mathcal{H}
is multiclass online learnable.

Partial-feedback non-learnability.

We use the adversary in Algorithm
3

It suffices to show two properties:

(i) At most one slot increases per round.

The adversary maintains a multiset of “slots”
\hat{Q}_{t}

3

(ii) The available instance set never becomes empty.

For any fixed distinct pair

The above example is also potentially relative to the applications in signal processing. Under the set-valued setting, it is easy to construct cases which force that the hypothesis class is learnable under partial-feedback, but not under set-valued setting. This is because when instance space
\mathcal{X}
has only one element, by set-realizable setting, any reveal labels on this instance will be correct in each future round. This guarantees that the learner predicts correct in each of the following round as long as the learner outputs the revealed label shown in the first round. In contrast, this does not put much restriction under the set-valued setting. Just let
\mathcal{Y}
has infinite elements,
\mathcal{S}(\mathcal{Y}):=P(\mathcal{Y})
, and
\mathcal{H}
consist of constant function that outputs each of elements in
\mathcal{Y}
. It is not hard to see that such configuration is not learnable under set-valued setting. Conversely, there also exist cases where the learnability holds in partial-feedback, but not in set-valued setting. Although it seems that there are no obvious bound between these two settings, we manage to identify that when the ratio
\frac{{\rm PFL}_{d}(\tilde{\mathcal{H}})}{d}
approaches
1
as
d\to\infty
, and
\mathcal{S}(\mathcal{Y})
satisfies certain constraint, the two learning problems are both unlearnable. We also show that the constraint on
\mathcal{S}(\mathcal{Y})
is necessary in the sense that there exists a case where the learnability holds in partial-feedback, but not in set-valued setting, when this constraint is not satisfied.

Theorem 11

(Partial Feedback vs. Set-Value)

\mathcal{X},\mathcal{Y}

\mathcal{H}

\mathcal{S}_{\rm pf}(\mathcal{Y})\subseteq\mathcal{S}_{\rm sv}(\mathcal{Y})

\frac{{\rm PFL}_{d}(\tilde{\mathcal{H}})}{d}\longrightarrow 1\qquad\text{as }d\to\infty,

(2)

then both the partial-feedback and the set-valued online learning problems are not learnable. If
\mathcal{S}_{\rm sv}(\mathcal{Y})
is not union-closed, the above implication may fail: there exist
\mathcal{X},\mathcal{Y},\mathcal{H}
and set families with

2

Proof.

We prove the two statements separately.

Part I: if
{\rm PFL}_{d}(\tilde{\mathcal{H}})/d\to 1

(Partial-feedback.)

By Theorem
6

learnability under partial feedback holds iff
{\rm PFL}_{d}(\tilde{\mathcal{H}})=o(d)

The assumption (
2

{\rm PFL}_{d}(\tilde{\mathcal{H}})

\Omega(T)
and the partial-feedback problem is not learnable.

(Set-value.)
It suffices to show

{\rm PFL}_{d}(\tilde{\mathcal{H}})
cannot be too close to
d

{\rm PFL}_{d}(\tilde{\mathcal{H}})\;\leq\;d-\Big\lfloor\frac{d}{{\rm SL}(\mathcal{H})+1}\Big\rfloor.

(7)

Rearranging gives

{\rm SL}(\mathcal{H})\gtrsim\frac{d}{d-{\rm PFL}_{d}(\tilde{\mathcal{H}})}

Assumption (

the set-valued problem is not deterministically learnable.

It remains to justify Inequality (
7

By definition of
{\rm PFL}_{d}(\tilde{\mathcal{H}})
, there exists an
\mathcal{X}
-valued,
\mathcal{Y}
-ary full tree
\mathcal{T}
of depth

and visible-label annotation functions

Thus every root-to-leaf path has at most

We first prove the following claim.

In the top
({\rm SL}(\mathcal{H})+1)

Suppose for contradiction that

({\rm SL}(\mathcal{H})+1)

Part II: separation—partial feedback not learnable but set-valued learnable.

We give an explicit example.

\mathcal{X}:=\mathbbm{Z}_{+}

\mathcal{Y}:=\mathbbm{Z}\cup\{-\tfrac{1}{2},\tfrac{1}{2}\}

Let

\mathcal{S}_{\rm sv}(\mathcal{Y})\;:=\;\big\{\{c,\tfrac{1}{2}\}:c\in\mathbbm{Z}\setminus\{0\}\big\}\ \cup\ \big\{\{c,-\tfrac{1}{2}\}:c\in\mathbbm{Z}\setminus\{0\}\big\},\qquad\mathcal{S}_{\rm pf}(\mathcal{Y})\;:=\;\mathcal{S}_{\rm sv}(\mathcal{Y}),

\mathcal{S}_{\rm pf}(\mathcal{Y})\subseteq\mathcal{S}_{\rm sv}(\mathcal{Y})
holds, and
\mathcal{S}_{\rm sv}(\mathcal{Y})
is not closed under unions
(e.g.
\{1,\tfrac{1}{2}\}\cup\{2,\tfrac{1}{2}\}=\{1,2,\tfrac{1}{2}\}\notin\mathcal{S}_{\rm sv}(\mathcal{Y})

For

be the infinite binary expansion
of

written in least-significant-bit-first order (i.e.

infinitely many trailing zeros. Define the

p_{c}(x)\;:=\;(-1)^{\sum_{i=1}^{x}b_{i}}\in\{+1,-1\},\qquad x\in\mathbbm{Z}_{+}.

Define the hypothesis class
\mathcal{H}:=\{f_{c},g_{c}:\ c\in\mathbbm{Z}\setminus\{0\}\}

f_{c}(x)\equiv c\in\mathbbm{Z},\qquad g_{c}(x)\;:=\;\tfrac{1}{2}\cdot\mathrm{sign}(c)\cdot p_{c}(x)\in\Big\{-\tfrac{1}{2},\tfrac{1}{2}\Big\}.

For any fixed
c^{\star}\in\mathbbm{Z}\setminus\{0\}

H^{\star}:=\{f_{c^{\star}},g_{c^{\star}}\}
and define the set-valued label at time

S_{t}\;:=\;H^{\star}(x_{t})\;=\;\{f_{c^{\star}}(x_{t}),\,g_{c^{\star}}(x_{t})\}\;=\;\{c^{\star},\ \tfrac{1}{2}\,\mathrm{sign}(c^{\star})\,p_{c^{\star}}(x_{t})\}\in\mathcal{S}_{\rm sv}(\mathcal{Y}),

so the instance is set-realizable.

SV is learnable.

In the set-valued protocol, the learner observes
S_{t}
each round.
On round
1

S_{1}
and sets
\hat{c}:=c^{\star}
.
For all

\hat{y}_{t}:=g_{\hat{c}}(x_{t})
.
Then
\hat{y}_{t}\in S_{t}
for every
t\geq 2
, hence the learner makes at most one mistake,
so the deterministic minimax regret is
O(1)
.

PF is not learnable.

Fix a horizon

and let the adversary set
x_{t}:=t

Adversary strategy.

The adversary maintains a set of feasible candidates

\mathbbm{C}_{t}\;:=\;\Big\{c\in\mathbbm{Z}_{+}:\ \forall i\leq t,\ g_{c}(i)=y_{i}^{\rm vis}\Big\}.

Initially
\mathbbm{C}_{0}=\mathbbm{Z}_{+}

y_{t}^{\rm vis}\;:=\;\begin{cases}-\hat{y}_{t},&\text{if }\hat{y}_{t}\in\{\pm\tfrac{1}{2}\},\\[2.0pt]
+\tfrac{1}{2},&\text{if }\hat{y}_{t}\in\mathbbm{Z},\end{cases}

Feasibility.

We claim that
\mathbbm{C}_{t}
is infinite for every

b_{1},\dots,b_{t}
online by setting

Ground-truth label set.

By the invariant,
\mathbbm{C}_{T}

.

Every round is a mistake.

Theorem 13

(Regret of Randomized Algorithms)

For any

The proof is mainly motivated by
20

8

T

Instead of the telescope arguments in

Plug it into Inequality (

\displaystyle\sum^{T}_{t=1}\pi^{\rm pred}_{t}(S^{{\rm c}}_{t})

\displaystyle\leq\sum^{T}_{t=1}\gamma_{N}+16\sum^{N}_{i=1}\sum^{T}_{t=1}\mathbbm{1}\left\{\gamma_{i}<\pi^{i}_{t}(S^{{\rm c}}_{t})\right\}\gamma_{i}

via plugging the above condition into Inequality (
