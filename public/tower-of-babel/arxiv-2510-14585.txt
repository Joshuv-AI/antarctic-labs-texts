A Density Condition on Point Sets with Slowly-Scaling Distinct Dot Products
Anshula Gandhi

Abstract
. The distinct dot products problem, a variation on the Erdős distinct distance problem, asks “Given a set P n P_{n} of n n points in ℝ 2 \mathbb{R}^{2} , what is the minimum number | D ⁡ ( P n ) | |D(P_{n})| of distinct dot products formed between them, asymptotically?” The best proven lower-bound is | D ⁡ ( P n ) | ≳ n 2 / 3 + 7 / 1425 |D(P_{n})|\gtrsim n^{2/3+7/1425} , due to work by Hanson–Roche‐Newton–Senger, and a recent improvement by Kokkinos. However, the slowest-scaling known constructions have | D ⁡ ( P n ) | ∼ n |D(P_{n})|\sim n , leaving quite a large gap in the bound. Finding a sublinearly-scaling construction, or disproving its existence, would narrow this gap. We provide a condition that a sequence of point configurations ( P n ) n ∈ ℕ (P_{n})_{n\in\mathbb{N}} must satisfy in order for | D ⁡ ( P n ) | |D(P_{n})| to scale “slowly” i.e. | D ⁡ ( P n ) | ≪ n 3 / 4 |D(P_{n})|\ll n^{3/4} . Namely, we prove that any such configuration must contain a point-rich line that gets arbitrarily ‘dense’ as the sequence progresses.

2.
The main result

The following theorem identifies a property that must hold for any sequence of point configurations
(P_{n})_{n\in\mathbb{N}}
where
|D(P_{n})|\ll n^{3/4}
.

Theorem
6.3

(A density condition for slow scaling).

Suppose that
\mathcal{P}=(P_{n})_{n\in\mathbb{N}}
is a sequence of point configurations, where each
P_{n}
is a set of
n
distinct points in
\mathbb{R}^{2}
. And suppose
|D(P_{n})|\ll n^{3/4}
. Then, for all
b\in(0,1)
, there exists a subsequence
(P_{k_{1}},P_{k_{2}},\ldots)
of
\mathcal{P}
with the following property: in every point configuration in the subsequence, there exists a set of points
L
along a line through the origin with
\gtrsim n^{1/2}
pairs of consecutive points
p,q\in L
for which
|p|/|q|
falls within the interval
(b,1)
.

Roughly, the above theorem says that for a sequence of slowly-scaling point configurations, there must exist a subsequence along which a very populated line in the configuration gets “denser” as the subsequence progresses. That is, the arrangement of most points on a popular line “approximates” an
arithmetic progression
— in the sense that ratios between successive points in an arithmetic progression go to 1, and the ratios between many successive points on this line get arbitrarily close to 1.

This property is interesting for the dot products problem because points on a line in arithmetic progression create many dot products — in fact,
\sim n^{1/2}
points on a line in arithmetic progression would determine
\sim n
dot products. While we cannot ensure that these points will in fact be in arithmetic progression (in fact, the points could be in geometric progression with ratio
r
in each configuration, with
r\to 1
along the sequence of configurations), this density condition may still useful in bounding the scaling of distinct dot products.

3.
Line configurations

In this section, we will start by proving bounds on the number of dot products we can expect when all points in a configuration are placed on one line. We then use these results to prove that if the distinct dot product set is small, the point configuration must have a “popular line.”

Eventually, we will use the existence of this popular line to construct many dot products, leading to our main result.

3.1.
Dot products among points on a line scale at least linearly

First, we show that by spacing points in geometric progression on a line, we end up with only linearly-many dot products. This result immediately follows from some basic combinatorics, but we include the proof here for completeness.

Lemma 3.1

(Points in geometric progression along a line)
.

If we have a set
L\subset\mathbb{R}^{2}
consisting of
n
points in geometric progression on a line through the origin, then they create
\sim n
distinct dot products.

Proof.

Rotating a point set does not change the number of dot products, so without loss of generality, we can assume the points are on the
x
-axis, with
x
-coordinates
\set{ar^{0},ar^{1},\dots,ar^{n-1}}
. Thus, their dot product set is given by

D(L)=a^{2}\cdot\set{r^{0},r^{1},\dots,r^{2n-2}}.

That is, there are only
2n-1\sim n
distinct dot products.
∎

We now show the above arrangement of points on a line is optimal.

Lemma 3.2

(Bounding dot products on a line)
.

If we have a set
L\subset\mathbb{R}^{2}
consisting of
n
points
placed anywhere
on a line through the origin, then they create
\gtrsim n
distinct dot products.

Proof.

Rotating a point set does not change the number of dot products, so without loss of generality, we can assume the points are on the
x
-axis, with
x
-coordinates given by
\ell:=\set{\lvert p\rvert,p\in L}
. Note that the size of the set of dot products
|L\cdot L|
is the same as the size of the product set
|\ell\ell|
, and product sets grow linearly or superlinearly with respect to the size of their input set. ∎

\gtrsim n
dot products.

Therefore, throughout the rest of this paper, while we refer to
any
finite set of points on a line as a
line configuration
, we refer to any finite set of points
in geometric progression
on a line as an
optimal line configuration
.

3.2.
Bounding the number of supporting lines

We have just seen that if all points in a configuration lie along one line through the origin, we expect a linear number of dot products. A straightforward generalization shows that even if all points lie along a constant number of lines, we expect a linear number of dot products. So, given any sublinearly-scaling configuration (i.e.
|D(P)|\ll n
), we expect the number of
supporting lines
to grow with
n
.

Definition 3.3

(Supporting lines)
.

Given a set of points
P\subset\mathbb{R}^{2}
, let their
supporting lines
be the lines centered at the origin with slopes taken from the set
R(P):=\set{p_{y}/p_{x}}{(p_{x},p_{y})\in P}
.

Figure 3
.
A set of points and their supporting lines.

The next result shows that, indeed, in any point configuration with sublinearly-scaling dot products, the number of supporting lines in the configuration must grow with
n
.

Lemma 3.4

(Lower bound on # supporting lines)
.

Let
\mathcal{P}=(P_{n})_{n\in\mathbb{N}}
be a sequence of point configurations, where each
P_{n}
is a set of
n
distinct points in
\mathbb{R}^{2}
, with
\ll n^{\alpha}
dot products where
\alpha\in(0,1]
. Then, the number of supporting lines grows
\gg n^{1-\alpha}
.

Proof.

If the number of lines scaled
\lesssim n^{1-\alpha}
, then by an averaging argument, at least one line would have
\gtrsim n^{\alpha}
points, and therefore the points on that line alone would immediately yield
\gtrsim n^{\alpha}
dot products. ∎

Our next result shows that upper-bounding the growth of dot products produced by a point configuration also upper-bounds the growth of supporting lines in the configuration.

Lemma 3.5

(Upper bound on # supporting lines)
.

[Lemma 3.1 in
[
7
]
] Let
\mathcal{P}=(P_{n})_{n\in\mathbb{N}}
be a sequence of point configurations, with
\ll n^{\alpha}
dot products where
\alpha\in(0,1]
. Then, the number of supporting lines grows
\ll n^{2\alpha-1}
.

Proof.

This proof immediately follows from a lemma given in
[
7
]
. Fix some configuration
P_{n}
, and let
L_{n}
be its set of supporting lines. Lemma 3.1 from
[
7
]
says that there must exist some point
p\in P_{n}
that creates many dot products with the other points in the set i.e.
|\set{p\cdot q}{q\in P_{n}}|\gtrsim n^{1/2}|L_{n}|^{1/2}
.

The number of total dot products must be at least the number of dot products produced by one point:

|D(P_{n})|\gtrsim|\set{p\cdot q}{q\in P}|\gtrsim n^{1/2}|L_{n}|^{1/2}.

And so if
n^{\alpha}\gg|D(P_{n})|

n^{\alpha}\gg n^{1/2}|L_{n}|^{1/2}.

Rearranging, we have that
|L_{n}|\ll n^{2\alpha-1}
. ∎

Intuitively, we are saying that if a configuration has
not too many
dot products, then it also has
not too many
supporting lines. It should therefore follow that there exists one line which supports many points.

3.3.
Existence of a popular line

Lemma 3.6

(Existence of popular line)
.

Let
\mathcal{P}=(P_{n})_{n\in\mathbb{N}}
be a sequence of point configurations, with
\ll n^{\alpha}

\alpha\in(0,1]

\gg n^{2-2\alpha}

Proof.

By the previous lemma, the number of supporting lines must scale
\ll n^{2\alpha-1}
. Thus, by an averaging argument, at least one of these lines (what we call the “popular line”) must contain
\gg n/n^{2\alpha-1}
, that is,
\gg n^{2-2\alpha}
points. ∎

4.
Circle configurations

We now turn to proving bounds on the number of dot products we can expect when all points in a configuration are placed on one circle. Similarly to how we dealt with the case of points along a line, we will use these results to prove that if the distinct dot product set is small, the point configuration must have a “popular circle.”

Eventually, we will use the existence of this popular circle (in combination with the existence of a popular line) to construct many dot products, leading to our main result.

4.1.
Dot products among points on a circle scale at least linearly

First, we show that by spacing points equally on a circle, we end up with only linearly-many dot products.

Lemma 4.1

(Points equally spaced on a circle)
.

If we have a set
C\subset\mathbb{R}^{2}
consisting of
n
points equally spaced on a circle centered at the origin, then they create
\sim n
distinct dot products.

Proof.

Scaling a point set does not change the number of dot products, so without loss of generality, we can assume the points are on the unit circle. Label the points in
C
as
\set{c_{1},c_{2},\dots,c_{n}}
, where each
c_{j}=e^{i\theta_{j}}
. (Here, and occasionally throughout this paper, the proofs become a little bit clearer if we switch from denoting these objects as points
(x,y)\in\mathbb{R}^{2}
to instead denoting them as complex numbers
re^{i\theta}\in\mathbb{C}
.)

Thus, given a point
c_{j}=e^{i\theta_{j}}
and another point
c_{k}=e^{i\theta_{k}}
, the dot product between them is given by
\cos(\theta_{j}-\theta_{k})
. So in general, the dot product set between points on the circle is given by

D(C)=\set{\cos\theta\mid\theta=\arg(c_{j})-\arg(c_{k})\textrm{ where }c_{j},c_{k}\in C}.

That is, the number of dot products depends entirely on the number of distinct angles between points.

Any two points on the circle have a unique angle
\theta\in[0,\pi]
between them. These
n
equally spaced points determine
\frac{n}{2}+1
distinct angles between them, and in particular, any two points will be separated by one of angles in the set
T=\set{0,\frac{2\pi}{n},2\cdot\frac{2\pi}{n},3\cdot\frac{2\pi}{n},\dots,\frac{n}{2}\cdot\frac{2\pi}{n}}
. So we have:

D(C)=\set{\cos\theta\mid\theta\in T}.

Since the
\cos
function is one-to-one on the interval
[0,\pi]
,
\cos
must take on
\frac{n}{2}+1
values over the domain
T
. So
|D(C)|=\frac{n}{2}+1\sim n
.

∎

n

\sim n

We now show the above arrangement of points on a circle is optimal.

Lemma 4.2

(Bounding dot products on a circle)
.

If we have a set
C\subset\mathbb{R}^{2}
consisting of
n
points
placed anywhere
on a circle centered at the origin, then they create
\gtrsim n
distinct dot products.

Proof.

Again, scaling a point set does not change the number of dot products, so without loss of generality, we can assume the points are on the unit circle. Thus, let
C=\set{c_{1},c_{2},\dots,c_{n}}
, and suppose any
c_{j}\in C
takes the form
e^{i\theta_{j}}
.

First we show that the size of the set of dot products (
|C\cdot C|
) has the same (asymptotic) size of the ratio set of
C
with itself (
|C/C|
).

\displaystyle|C/C|

\displaystyle=\left|\left\{c_{1}/c_{2}\,\middle|\,c_{1},c_{2}\in C\right\}\right|

\displaystyle=\left|\left\{e^{i(\theta_{1}-\theta_{2})}\,\middle|\,e^{i\theta_{1}},e^{i\theta_{2}}\in C\right\}\right|

\displaystyle=\left|\left\{\cos(\theta_{1}-\theta_{2})+i\sin(\theta_{1}-\theta_{2})\,\middle|\,e^{i\theta_{1}},e^{i\theta_{2}}\in C\right\}\right|

\displaystyle\sim\left|\left\{\cos(\theta_{1}-\theta_{2})\,\middle|\,e^{i\theta_{1}},e^{i\theta_{2}}\in C\right\}\right|

\displaystyle=\left|\left\{c_{1}\cdot c_{2}\,\middle|\,c_{1},c_{2}\in C\right\}\right|

\displaystyle=|C\cdot C|.

We know that we can bound the size of a ratio set
|C/C|\geq|C|
(that is, by just fixing the denominator element to be some
c
, we get that
|C/C|\geq|C/c|=|C|
.). Therefore,
|C\cdot C|\sim|C/C|\gtrsim n
.

∎

n

\gtrsim n
dot products.

Therefore, throughout the rest of this paper, while we refer to
any
finite set of points on a circle as a
circle configuration
, we refer to any finite set of
equally spaced
points on a circle as an
optimal circle configuration
.

4.2.
Bounding the number of supporting circles

We can bound the number of supporting circles of a configuration in a manner very similar to how we bound the number of supporting lines.

Definition 4.3

(Supporting circles)
.

Given a set of points
P\subset\mathbb{R}^{2}
, let their
supporting circles
be the circles centered at the origin with radii taken from the set
R(P):=\set{\sqrt{p_{x}^{2}+p_{y}^{2}}}{(p_{x},p_{y})\in P}
.

.
A set of points and their supporting circles.

The next result shows that in any point configuration with sublinearly-scaling dot products, the number of supporting circles in the configuration must grow with
n
.

Lemma 4.4

(Lower bound on # of supporting circles)
.

Let
\mathcal{P}=(P_{n})_{n\in\mathbb{N}}
be a sequence of point configurations, with
\ll n^{\alpha}
dot products where
\alpha\in(0,1]
. Then, the number of supporting circles grows
\gg n^{2-2\alpha}
.

Proof.

We know the number of lines grow
\ll n^{2\alpha-1}
, and so by an averaging argument, there must be a popular line with
\gg n^{2-2\alpha}
points, which means we have
\gg n^{2-2\alpha}
supporting circles.
\square

∎

Our next result shows that upper-bounding the number of dot products produced by a point configuration also upper-bounds the number of supporting circles in the configuration.

Lemma 4.5

(Upper bound on # of supporting circles)
.

Let
\mathcal{P}=(P_{n})_{n\in\mathbb{N}}
be a sequence of point configurations, with
\ll n^{\alpha}
dot products where
\alpha\in(0,1]
. Then, the number of supporting circles grows
\ll n^{\alpha}
.

Proof:
Take one point
p
from each supporting circle, and note that the dot product of that point with itself
p\cdot p
must equal the squared radius of its supporting circle. Thus, the number of distinct dot products is at least equal to the number of supporting circles, and the result follows.
\square

Intuitively, we are saying that if a configuration has
not too many
dot products, then it also has
not too many
supporting circles. It should therefore follow that there exists one circle which supports many points.

5.
Line-and-circle configurations

As we have shown, a slowly-scaling point configuration’s “popular circle” and “popular line” both have many points. It turns out that counting just the dot products between this circle and this line will yield enough dot products for our bound.

As a warmup, we start by proving a more symmetric case of our main theorem. The proof of the symmetric case contains many of the central ideas of the main proof.

5.1.
Combining an optimal line and optimal circle configuration

We have proven that an optimal line configuration determines a small number of dot products, as does an optimal circle configuration.

We will now prove a bound on the number of dot products if we consider the union of both optimal configurations. When the number of points on a circle
N(n)=n^{1/2}
and number of points on a line
M(n)=n^{1/4}
, the following proposition reduces to a special case of our main theorem.

Proposition 5.1

(Optimal circle and optimal line)
.

Let
\mathcal{P}=(P_{n})_{n\in\mathbb{N}}
be a sequence of point configurations. Suppose each configuration
P_{n}
has
N(n)
points equally spaced on a circle centered at the origin, and
M(n)
points in geometric progression (with common ratio
r
) on a line through the origin. Then, the number of dot products grows
\gtrsim N(n)M(n)
.

Proof.

Scaling and rotating a configuration of points does not change the number of dot products. So, we can assume all points lie on the union of the unit circle and the
x
-axis. In fact, we can assume the points are on the positive
x
-axis, since we can only consider the points on the line that are on the more popular side of the origin, of which there must be still
\sim M
, and then rotate accordingly.

As a result, we can denote the points on the circle as

C:=\set{1,e^{i\theta},e^{2i\theta},\dots,e^{(N-1)i\theta}}\textrm{ where }\theta=\frac{2\pi}{N}.

And we can denote the points on the line as

L:=\set{a,ar^{1},ar^{2},\dots,ar^{M-1}}

for some
a\in\mathbb{R}\setminus\set{0}
.

Figure 9
.
A point configuration with points equally spaced on a circle, and points in geometric progression on a line.

For convenience, we will assume
r>1
, but an analogous argument holds for
0<r<1
.

It will suffice to ignore the dot products generated between any two points on a circle, or any two points on a line, and rather, to consider the dot products formed from a point on a circle and a point on a line. That is, we will show:

|\set{c\cdot\ell}{c\in C,\ell\in L}|\gtrsim NM.

Next, we notice these dot products can be thought of as the real projections of the
NM

r^{n}e^{i\left(m\frac{\pi}{M}\right)}
where
0\leq n\leq N
and
0\leq m\leq M
— that is, the points located on equidistantly around circles whose radii are increasing geometrically. We refer to these complex numbers as “complex dot products.”

(Complex dot product (

Given two vectors

of the complex dot product is the

Re[p\star q]=p\cdot q
. Given two sets
P,Q\subset\mathbb{R}^{2}
, we define
P\star Q:=\set{p\star q}{p\in P,q\in Q}
.

We now turn our attention to considering
C\star L
. We will prove

.

5.2.
Combining a line and optimal circle configuration

We can generalize the above theorem to

Let

5.3.
Combining a line and circle configuration

We can further adapt the above result so that points on a given circle
do not need to be evenly spaced

\mathcal{C}_{i}
fell into the bucket
B_{i}
. Instead, we only need to add the condition that all points in the set
\mathcal{C}_{i}
lie along the sector that projects into the correct bucket
B_{i}
.

While this may seem like a more stringent condition at first, we will see in the next section that we get this bunching of points along a sector “for free” in any slowly-scaling point set. That is, while not all slowly-scaling point sets will have a popular circle with equally spaced points, every slowly-scaling point set will have a popular circle with many points bunched into a small-enough sector. So, in this context, the following adaptation of the preceding Proposition

Lemma 5.6

(Circle and line)
.

Let

\mathcal{P}=(P_{n})_{n\in\mathbb{N}}

M(n)

As usual, we can fix an

If the

Then, as usual, we can consider the set of complex dot products

6.
Line-and-circle configurations in slowly-scaling sets

We know that in any slowly-scaling point configuration (i.e. a configuration of points where the number of distinct dot products is
\ll n^{3/4}
), there exists a “popular circle” and “popular line.” We will apply the preceding Lemma
5.6
to this “popular circle” and “popular line” to prove the existence of many dot products under certain conditions.

6.1.
Bounding dot products between a popular line and popular circle

In the above proofs, we have been relying on points along a line being appropriately spaced out. The following theorem finds that as long as every popular line in each configuration obeys certain spacing conditions,
|D(P)|\gtrsim n^{3/4}
. The main result of this paper, the density condition on slowly-scaling sets, is a closely related to the contrapositive of this theorem.

Theorem 6.1

(A sufficient condition for quick scaling)
.

Suppose that
\mathcal{P}=(P_{n})_{n\in\mathbb{N}}
is a sequence of point configurations, where each
P_{n}
is a set of
n
distinct points in
\mathbb{R}^{2}
. Let
b\in(0,1)
. Further suppose for any configuration
P_{n}
and every set of collinear points
L_{n}\subseteq P_{n}
with
|L_{n}|\gtrsim n^{1/2}
, we have
W_{b}(L_{n})
. Then,
|D(P_{n})|\gtrsim n^{3/4}
.

Proof.

Suppose the dot products scale
\ll n^{3/4}
(if not, we already have that
|D(P_{n})|\gtrsim n^{3/4}
). Then, by Lemma
3.6
(Existence of a Popular Line), there must exist a popular line with
\gg n^{1/2}
points. And similarly by our Lemma
4.6
(Existence of a Popular Circle), there must exist a popular circle with
\gg n^{1/4}
points.

First, a sketch of the proof: We strategically choosing a densely-populated and wedge-shaped subsection of the plane from which to select a popular circle and popular line. The angle of this “wedge” is exactly
\cos^{-1}(b)
, and as a result,
every
point from each set
\mathcal{C}_{i}
(as defined previously) will drop into the bucket
B_{i}
(as defined previously), subsequently yielding many dot products. The formal argument is as follows:

Let
P_{\theta}\subseteq P
consist of points contained in a certain wedge of the plane, i.e.

P_{\theta}:=\set{p\in P}{\theta\leq\arg p\leq\theta+\cos^{-1}b}.

.
P_{\theta}
contains points from
P
in one wedge of the plane.

Let
P_{max}
be the largest such set
P_{\theta}
, i.e.:

|P_{max}|:=\max_{\theta\in[0,2\pi)}|P_{\theta}|.

Note that
|P_{max}|\sim n
, since by an averaging argument
|P_{max}|\geq\frac{\cos^{-1}b}{2\pi}n\sim n
.

In this set of
\sim n
points, we must still have a popular circle with
\gg n^{1/4}
points and a popular line with
\gg n^{1/2}
points.

We can now scale the entire point set so the popular circle is the unit circle — call those points
C
.

We can also rotate the entire point set so the popular line is the
x
-axis. We will have either
\gtrsim n^{1/2}
points on the line
inside
the unit circle or we will have
\gtrsim n^{1/2}
points on the line
outside
the unit circle. Without loss of generality, assume the points are all outside the unit circle, and call those points

The points in
C
and the points in

satisfy the conditions in the preceding Lemma
5.6
. So by that lemma, the configuration must yield
|C||L|\gtrsim(n^{1/4})(n^{1/2})=n^{3/4}
dot products.

Note that

is the best bound this argument can yield. If we try to run the argument with a general

. Then, there must exist a supporting line with
\gg n^{2-2\alpha}
points— we call this the “popular line.” And there must exist a supporting circle with

6.2.
A density condition on point sets with slowly-scaling dot products

A modified contrapositive of the above theorem gives us our condition on point configurations with slowly-scaling dot products. We show that we can always find a point-rich and dense line in any slowly-scaling set – we formalize this particular notion of density below.

Definition 6.2

(
b
-dense)
.

Let us call a set
L
of
\ell
collinear points
b
-dense
for some
b\in(0,1)
if there are
\sim\ell
pairs of consecutive points
p,q\in L
for which
|p|/|q|
falls within the interval
(b,1)
.

Theorem 6.3

(A density condition for slow scaling)
.

Suppose that
\mathcal{P}=(P_{n})_{n\in\mathbb{N}}
is a sequence of point configurations, where each
P_{n}
is a set of
n
distinct points in
\mathbb{R}^{2}
. Further suppose
|D(P_{n})|\ll n^{3/4}
. Then, for all
b\in(0,1)
, there is a subsequence of
\mathcal{P}
such that for every point configuration in the subsequence, there exists a
b
-dense set of points
L
along a line through the origin with
|L|\gtrsim n^{1/2}
.

Proof:
By assumption, we have that
|D(P_{n})|\ll n^{3/4}
, which means that the spacing of points along a popular line cannot satisfy the conditions in the previous lemma. To help formulate the spacing conditions that should apply in this case, we introduce some new notation.

Definition 6.4

(Maximally Well-Spaced Set)
.

Let
L
be a set of points collinear along a line through the origin. Let us say that a set of points
S\subseteq L
is
maximally well spaced
with respect to some
b\in(0,1)
if (i) we have
W_{b}(S)
and (ii) for any additional point
x\in L\setminus S
, we have
\neg W_{b}(S\cup\set{x})
. We use the notation
W_{b,max}(S,L)
.

Fix some
P_{n}
. We know that if every
\gtrsim n^{1/2}
-rich line through the origin with points
L\subseteq P_{n}
satisfied the well spaced condition
W_{b}(L)
for some
b\in(0,1)
, then the point set would determine
\gtrsim n^{3/4}
dot products.

That must mean that for all
b\in(0,1)
, we will be able to find some subsequence of point configurations along which some
\gtrsim n^{1/2}
-rich line through the origin containing points
L\subseteq P_{n}
does
not
satisfy
W_{b}(L)
. Therefore, there must be some set
S\subset L\subseteq P_{n}
consisting of only
\ll n^{1/2}
points such that
W_{b,max}(S,L)
. So, there must be
\gtrsim n^{1/2}
points in
L\setminus S
— call these points
T
— all of which will break the well-spaced condition if added to
S
. Consider the set of points
T_{pairs}:=\set{(l(t),t)}{t\in T}
, where
l(t)
is the point either immediately preceding
t
or immediately after
t
in the set
L
(ordered by distance of the point to the origin) such that
\neg W_{b}(l(t),t)
. Note that
|T_{pairs}|\gtrsim n^{1/2}
. Therefore, there are
\gtrsim n^{1/2}
consecutive pairs of points
(p,q)
along a line such that
\neg W_{b}(p,q)
.
\square

The above result is saying that the sequences of points on the popular line must “approximate an arithmetic progression” in the sense that the ratios between most successive points on the line get arbitrarily close to 1 (though, there may be gaps between these “AP-mimicking” sequences of points along the same line). In the next section, we discuss why this condition may be conducive to determing bounds on the distinct dot products problem, and some possible ways to leverage this theorem in the future.

Remark:
We can actually slightly extend the above result, as follows. The above theorem says that given any set of points with
|D(P_{n})|\ll n^{3/4}
, we can find a collinear set of
\sim n^{1/2}
points that is
b
-dense for any
b\in(0,1)
. We can then “throw away” this set of points from the configuration, and still have a configuration with
\sim n
points, so we can then run the argument again, to find another line of
\sim n^{1/2}
points that is
b
-dense. We can then repeat this argument
n^{1/2}
times. That is, any point configuration with
|D(P_{n})|\ll n^{3/4}
has not only a single
b
-dense line, but actually has
n^{1/2}
different
b
-dense lines of
\sim n^{1/2}
points each.

7.
Conclusion

Here are some properties we know about point configurations with dot products that scale slowly i.e.
\ll n^{3/4}
.

(a)

(
Bounds on supporting circles
) The number of supporting circles grows
n^{1/2}\ll\textrm{\# of circles}\ll n^{3/4}
, and by the upper bound, there must be a “popular circle” with
\gg n^{1/4}
points.

(b)

(
Bounds on supporting lines
) The number of supporting lines is given by
n^{1/4}\ll\textrm{\# of lines}\ll n^{1/2}
, and by the upper bound, there must be a “popular line” with
\gg n^{1/2}
points.

(c)

(
Density along a line
) The points on a popular line get “denser” (that is, the ratio between most successive points on the line go to 1 along a subsequence of point configurations).

(d)

(
Fertility of each point
) Each point creates
\gg n^{1/2}
dot products with every other point (an immediate result of considering the dot products between any point and the points on a popular line).

Additionally, forthcoming work by the author will show that not only does such a configuration contain a dense, point-rich line, but also a dense, point-rich circle.

If we can use the above conditions to either (i) construct a point set with slowly-scaling dot products i.e.
|D(P_{n})|\ll n^{3/4}
or (ii) show that no point configuration can scale that slowly, we can narrow the estimate on the distinct dot products problem.
