LTL f Learning Meets Boolean Set Cover
Gabriel Bathie, Nathanaël Fijalkow, Théo Matricon, Baptiste Mouillon, Pierre Vandenhove

Abstract
Learning formulas in Linear Temporal Logic ( LTL f \textbf{LTL}_{f} ) from finite traces is a fundamental research problem which has found applications in artificial intelligence, software engineering, programming languages, formal methods, control of cyber-physical systems, and robotics. We implement a new CPU tool called Bolt improving over the state of the art by learning formulas more than 100 100 x faster over 70 70 % of the benchmarks, with smaller or equal formulas in 98 98 % of the cases. Our key insight is to leverage a problem called Boolean Set Cover as a subroutine to combine existing formulas using Boolean connectives. Thanks to the Boolean Set Cover component, our approach offers a novel trade-off between efficiency and formula size.

2.2
The VFB Algorithm

Our first baseline for
\textbf{LTL}_{f}
learning is an optimized enumerative algorithm from Valizadeh, Fijalkow, and Berger
[
55
]
; we call it the
VFB algorithm
. Simply put:

VFB algorithm = combinatorial search + fast evaluation + observational equivalence.

Combinatorial Search.

The core algorithm is a bottom-up enumeration of
\textbf{LTL}_{f}
formulas by size.
First, the set of formulas of size 1 contains all atomic propositions.
At step
k
, we generate all formulas of size
k+1
.
In order to do this, for each operator, we take arguments such that the sum of sizes of arguments is equal to
k
; this way, the generated formula will have size
k+1
by combining it with the selected operator.
A property of this algorithm is that it is agnostic to the operators: it can be adapted to any fragment or be augmented with other operators, as long as we can easily compute inductively whether a trace satisfies a formula.

Fast Evaluation.

The key idea is to represent the semantics of
\textbf{LTL}_{f}
formulas on input traces using so-called “characteristic tables”:

•

The
characteristic sequence (CS)
of a formula
\varphi
on a trace
w
is the bit vector
v\in\left\{0,1\right\}^{|w|}
such that
w[i\ldots]\models\varphi
if and only if
v(i)=1
;

•

The
characteristic table (CT)
of a formula
\varphi
over the positive traces
P
and the negative traces
N
is a sequence
t
such that
t(i)
is the CS of
\varphi
on the
i
th
trace of
P\cup N
.

Observational Equivalence.

A second idea to tackle the combinatorial explosion of the number of formulas is to consider only “semantically unique” formulas.

Observational equivalence
is an idea from program synthesis
[
26
]
; in our context, two formulas are
observationally equivalent
on
(P,N)
if they generate the same characteristic table.
When enumerating formulas, we may keep a single representative for each equivalence class without losing completeness.

Scaling Issues.

Despite these improvements to a simple exhaustive search, the scaling of the problem is enormous.
We identified two problems limiting the depth of algorithms.

The first issue, of course, is the exponential blow-up due to the number of increasingly large formulas.
The second issue is the memory used to store the evaluation of
\textbf{LTL}_{f}
formulas in the form of characteristic tables, which is necessary to check for observational equivalence.
The more input traces there are, the larger the characteristic tables are; the longer the traces are, the wider the tables are.
When tables have more elements, observational equivalence is also less likely to occur.

Let us start with defining Boolean Set Cover formally. We consider a finite set

X=P\cup N
. We are given a (potentially large) set of atomic formulas
\varphi_{1},\dots,\varphi_{k}
over

. The goal is to construct a formula separating
P
from
N
using conjunctions and disjunctions of the atomic formulas.

As an example, consider the following

Here,

Our idea to tackle these scaling issues is to use the VFB algorithm on the full
\textbf{LTL}_{f}

Since the exponential blow-up does not allow to go much further beyond size

3.1
Definition and Properties of Boolean Set Cover

Let
P
and
N
be two disjoint finite sets.
Let
\mathcal{F}
be a family of sets with
F\subseteq P\cup N
for all
F\in\mathcal{F}
.
We assume that a
weight

\mathsf{weight}(F)\geq 1
is associated with each set
F\in\mathcal{F}
(which is unrelated to the cardinality of
F
).

We define
positive Boolean formulas
and their weights inductively:

•

\emptyset
is a formula of weight
0
;

•

F\in\mathcal{F}
is a formula of weight
\mathsf{weight}(F)
;

•

if
\theta_{1}
and
\theta_{2}
are positive Boolean formulas, then so are
\theta_{1}\cup\theta_{2}
and
\theta_{1}\cap\theta_{2}
, both of weight
1+\mathsf{weight}(\theta_{1})+\mathsf{weight}(\theta_{2})
.

The interpretation
\llbracket\theta\rrbracket
of a positive Boolean formula
\theta
is simply the set it describes.
We adjust observational equivalence: two formulas
\theta
and
\theta^{\prime}
are observationally equivalent if
\llbracket\theta\rrbracket=\llbracket\theta^{\prime}\rrbracket
.

The Boolean Set Cover problem is as follows:

INPUT
:

two disjoint finite sets
P
,
N
and a family
\mathcal{F}
of weighted subsets of
P\cup N

OUTPUT
:

a positive Boolean formula
\theta
of minimal weight such that
\llbracket\theta\rrbracket=P
(i.e., it contains all elements of
P
but none of
N
)

The Boolean Set Cover problem can be seen as a restriction of
\textbf{LTL}_{f}
learning to a subset of the operators, namely
\land
and
\lor
.
The Boolean Set Cover problem was briefly considered in
[
49
]
(under the name
Boolean Subset Cover
).
We will compare our algorithm to theirs in Section
5
.

Polynomial Criterion for a Solution of Arbitrary Weight.

We show that we can check whether there exists a formula
\theta
(
of arbitrary weight
) such that
\llbracket\theta\rrbracket=P
in polynomial time, just by evaluating a specific formula of length
\mathcal{O}(|P|\cdot|\mathcal{F}|)
.
This allows to quickly decide the nonexistence of a solution, and when a solution exists, it gives a polynomial upper bound on the weight of formulas to consider.

Lemma 1

(Existence of a solution)
.

Let
P
,
N
,
\mathcal{F}
be an instance of Boolean Set Cover.
There exists a positive Boolean formula
\theta
such that
\llbracket\theta\rrbracket=P
if and only if for all
p\in P
,
n\in N
, there is
F\in\mathcal{F}
such that
p\in F
and
n\notin F
.
Moreover, when it exists, there is such a formula of size
\mathcal{O}(|\mathcal{F}|\cdot|P|)
.

Proof.

For the left-to-right implication, we show the contrapositive.
Assume there is
p\in P
and
n\in N
such that, for all
F\in\mathcal{F}
,
p\in F
implies
n\in F
.
One can then show by induction that any formula
\theta^{\prime}
with
p\in\llbracket\theta^{\prime}\rrbracket
also has
n\in\llbracket\theta^{\prime}\rrbracket
.

For the right-to-left implication, we build a positive Boolean formula
\theta
such that
\llbracket\theta\rrbracket=P
.
This formula happens to be of size
\mathcal{O}(|\mathcal{F}|\cdot|P|)
, thereby also settling the claim about the size.
Assume that for all
p\in P
,
n\in N
, there is
F\in\mathcal{F}
such that
p\in F
and
n\notin F
.
For
p\in P
, let
\theta_{p}=\bigcap_{F\in\mathcal{F},p\in F}F
and
\theta=\bigcup_{p\in P}\theta_{p}
.
Due to the hypothesis, for all
p\in P
, we have
p\in\llbracket\theta_{p}\rrbracket
and
N\cap\llbracket\theta_{p}\rrbracket=\emptyset
.
Hence,
\llbracket\theta\rrbracket=P
.
∎

Complexity.

Boolean Set Cover is a generalization of the NP-complete
set cover
problem
[
37
]
: an instance of the set cover problem corresponds to an instance of Boolean Set Cover with
N=\emptyset
(in which case using
\cap
is futile, and minimal formulas can be obtained only using
\cup
).
This proves NP-hardness of the decision problem for Boolean Set Cover.
Since there are short solutions by Lemma
1
, and since computing the set described by a Boolean formula is polynomial in its length, Boolean Set Cover is NP-complete.

3.2
Domination for positive Boolean Formulas

In this section, we describe
domination
, a generalization of observational equivalence that identifies even more redundant objects than observational equivalence.

Intuitively, we say that a formula
\theta_{1}

dominates
a formula
\theta_{2}
if
\theta_{2}
can be replaced with
\theta_{1}
in any formula without increasing its weight or decreasing its “quality”.
More formally, let
\mathsf{sat}(\theta)
be the subset of elements of
P\cup N
that
\theta
classifies correctly, i.e.,

\mathsf{sat}(\theta)=(\llbracket\theta\rrbracket\cap P)\cup(N\setminus\llbracket\theta\rrbracket)
.
The goal of Boolean Set Cover can then be rephrased as finding a formula
\theta
such that
\mathsf{sat}(\theta)=P\cup N
.

Definition 2
.

A formula
\theta_{2}
is
dominated
by a formula
\theta_{1}
, denoted
\theta_{2}\preceq\theta_{1}
, if
\mathsf{weight}(\theta_{1})\leq\mathsf{weight}(\theta_{2})
and
\mathsf{sat}(\theta_{2})\subseteq\mathsf{sat}(\theta_{1})
.

We claim that this notion corresponds to the above intuition.
Formally, for a positive Boolean formula
\theta
, let
\theta[\theta_{2}\leftarrow\theta_{1}]
denote the formula obtained by replacing any occurrence of
\theta_{2}
in
\theta
by
\theta_{1}
; this operation is defined inductively as follows:

\displaystyle F_{i}[\theta_{2}\leftarrow\theta_{1}]

\displaystyle=\begin{cases}\theta_{1}&\text{if }F_{i}=\theta_{2}\\
F_{i}&\text{otherwise,}\end{cases}

\displaystyle\theta_{2}[\theta_{2}\leftarrow\theta_{1}]

\displaystyle=\theta_{1},

\displaystyle(\theta\cap\theta^{\prime})[\theta_{2}\leftarrow\theta_{1}]

\displaystyle=\theta[\theta_{2}\leftarrow\theta_{1}]\cap\theta^{\prime}[\theta_{2}\leftarrow\theta_{1}],

\displaystyle\text{and }(\theta\cup\theta^{\prime})[\theta_{2}\leftarrow\theta_{1}]

\displaystyle=\theta[\theta_{2}\leftarrow\theta_{1}]\cup\theta^{\prime}[\theta_{2}\leftarrow\theta_{1}].

Any occurrence of a dominated formula can be replaced with its dominating formula:

Lemma 3
.

Let
\theta
,
\theta_{1}
, and
\theta_{2}
be positive Boolean formulas.
If
\theta_{2}\preceq\theta_{1}
, then
\theta\preceq\theta[\theta_{2}\leftarrow\theta_{1}]
.

Proof.

First, note that, as
P
and
N
are disjoint, then if
\mathsf{sat}(\theta_{2})\subseteq\mathsf{sat}(\theta_{1})
we have:

\llbracket\theta_{2}\rrbracket\cap P\subseteq\llbracket\theta_{1}\rrbracket\cap P\text{ and }N\setminus\llbracket\theta_{2}\rrbracket\subseteq N\setminus\llbracket\theta_{1}\rrbracket.

(1)

We now show that the
\mathsf{sat}(\cdot)
function is
monotone
with respect to the
\cup
and
\cap
operators:
if
\mathsf{sat}(\theta_{2})\subseteq\mathsf{sat}(\theta_{1})
, then for any formula
\theta
, we have
\mathsf{sat}(\theta_{2}\cap\theta)\subseteq\mathsf{sat}(\theta_{1}\cap\theta)
and
\mathsf{sat}(\theta_{2}\cup\theta)\subseteq\mathsf{sat}(\theta_{1}\cup\theta)
.
This can be shown through direct calculation using
\cref
eq:inclusion:

\displaystyle\mathsf{sat}(\theta_{2}\cap\theta)

\displaystyle=(\llbracket\theta_{2}\cap\theta\rrbracket\cap P)\cup(N\setminus\llbracket\theta_{2}\cap\theta\rrbracket)

\displaystyle=(\llbracket\theta_{2}\rrbracket\cap\llbracket\theta\rrbracket\cap P)\cup(N\setminus(\llbracket\theta_{2}\rrbracket\cap\llbracket\theta\rrbracket))

\displaystyle=((\llbracket\theta_{2}\rrbracket\cap P)\cap\llbracket\theta\rrbracket)\cup((N\setminus\llbracket\theta_{2}\rrbracket)\cup(N\setminus\llbracket\theta\rrbracket))

\displaystyle\subseteq((\llbracket\theta_{1}\rrbracket\cap P)\cap\llbracket\theta\rrbracket)\cup((N\setminus\llbracket\theta_{1}\rrbracket)\cup(N\setminus\llbracket\theta\rrbracket))

(2)

\displaystyle=(\llbracket\theta_{1}\rrbracket\cap\llbracket\theta\rrbracket\cap P)\cup(N\setminus(\llbracket\theta_{1}\rrbracket\cap\llbracket\theta\rrbracket))

\displaystyle=\mathsf{sat}(\theta_{1}\cap\theta).

The inclusion in eq. (
2
) follows from eq. (
1
).
A similar calculation shows the inclusion for the
\cup
operator.

Similarly, the
\mathsf{weight}(\cdot)
function is also monotone: if
\mathsf{weight}(\theta_{1})\leq\mathsf{weight}(\theta_{2})
, then

\mathsf{weight}(\theta_{1}\cap\theta)\leq\mathsf{weight}(\theta_{2}\cap\theta)
(and similarly for

\cup
) for any formula
\theta
.

We can now prove that if
\theta_{2}\preceq\theta_{1}
, then
\theta\preceq\theta[\theta_{2}\leftarrow\theta_{1}]
by structural induction over
\theta
.
The base cases follow from the definition of domination, and the cases
\theta=\theta^{\prime}\cap\theta^{\prime\prime}
or
\theta=\theta^{\prime}\cup\theta^{\prime\prime}
are handled using the monotonicity of the
\mathsf{sat}(\cdot)
and
\mathsf{weight}(\cdot)
functions.
∎

Domination can be thought of as a variation on
Property dependence
(see Theorem 6 in
[
21
]
), used to prune
\textbf{LTL}_{f}
formulas for efficient model-checking.

Further Reducing the Input Set.

\Cref

lemma:domin-works implies that we can preprocess
\mathcal{F}
to only keep maximal elements for
\preceq
(which means that we transform the input into an antichain for
\preceq
).
By encoding the characteristic vectors of formulas in bits of integers, testing whether
\theta_{1}
dominates
\theta_{2}
can be implemented efficiently using bitwise operations.
All our algorithms for Boolean Set Cover start by reducing
\mathcal{F}
in this way.

The Need for a Heuristic.

We argue that the existence of a subquadratic algorithm to completely reduce a set
\mathcal{F}
with domination is unlikely.
The obvious algorithm to find whether a given formula
\theta\in\mathcal{F}
is dominated by a formula
\theta^{\prime}\in\mathcal{F}
is to go through every formula in
\mathcal{F}
and check whether it dominates
\theta
.
This takes linear time,
and when there are
O(n)
formulas
\theta
and
\theta^{\prime}
, this approach takes quadratic time.
We do not expect a faster algorithm:
the
Orthogonal Vectors problem

[
57
]
can be reduced to whether there exists a formula
\theta_{1}\in A
that dominates a formula
\theta_{2}\in B
where
A
,
B
are sets of
n
formulas,
and a strongly subquadratic algorithm for Orthogonal Vectors would imply that the Strong Exponential Time Hypothesis is false.
The reduction between our problem and the Orthogonal Vectors problem is presented in
[
8
]
.

Fast Approximate Domination.

Yet, a quadratic running time is prohibitive in our application where we need to test domination for millions of Boolean formulas:
we therefore propose a heuristic that drastically speeds up the search of a dominating formula while allowing for some false negatives.

Instead of searching through all of
\mathcal{F}
for dominating formulas, we restrict the search to a small subset of candidates
with a high likelihood of dominating other formulas.
For a given weight value
w
and an integer
k
, let
\mathcal{T}(w,k)
denote the
k
formulas
\theta
that maximize
|\mathsf{sat}(\theta)|
among formulas of weight
w
in
\mathcal{F}
.
Our heuristic searches for a formula
\theta
that dominates
\theta^{\prime}
in the sets
\mathcal{T}(w,k)
for
w\leq\mathsf{weight}(\theta^{\prime})
.
The value chosen for
k
controls the trade-off between speed and accuracy of the technique.
We illustrate the gain in practice over a small set of tasks chosen randomly, which is substantial even for small values of
k
.
Let
\mathcal{F}^{\prime}
be as in Algorithm
1
, and
\mathcal{F}^{\prime\prime}=\textsc{FastNonDominated}(\mathcal{F}^{\prime},k)
be the result of the shrinkage of
\mathcal{F}^{\prime}
by the above approximate algorithm.
On average, over
780
tasks, the ratio
|\mathcal{F}^{\prime}|/|\mathcal{F}^{\prime\prime}|
is
3.45
for
k=3
,
4.07
for
k=5
,
4.97
for
k=10
,
5.94
for
k=25
, and
6.60
for
k=50
.

The second is related to Boolean Set Cover: the divide and conquer only combines existing formulas with operators

This means that once it is called, the other optimizations for Boolean Set Cover (reducing evaluations from tables to vectors, stronger collapse due to observational equivalence, domination reduction) can be applied.

6
Perspectives

The first contribution of this paper is a framework for combining
\textbf{LTL}_{f}
learning with Boolean Set Cover.
We proposed a new algorithm for Boolean Set Cover and, through experimental analyses, we showed that our new tool
Bolt
greatly improves over the state of the art for CPU algorithms.

These results yield evidence toward our main thesis: Boolean Set Cover is a fundamental problem of independent interest, which has a lot of potential applications beyond
\textbf{LTL}_{f}
learning. Our framework is generic; for instance, our tool (through the VFB algorithm) can be adapted to any kind of temporal operators, and Boolean Set Cover can be used for any logic or specification language with disjunctions and conjunctions. Natural candidates include regular expressions
[
54
]
, Boolean circuits
[
16
]
, and Bit-vector programs
[
20
]
.

Our paper provides a first step toward efficiently and approximately solving Boolean Set Cover. We believe there are algorithms that achieve better trade-offs between compute time and size of learned formulas.
In particular, we expect our algorithms to be highly parallelizable; we leave for future work an implementation of our framework for GPUs and a comparison with the CPU implementation.
We also contributed a large consolidated benchmark suite, which is much needed to push further the theory and practice of
\textbf{LTL}_{f}
learning and Boolean Set Cover.

As discussed in Section
2.2
, we show how to compute inductively the characteristic sequences of
\textbf{LTL}_{f}
formulas on traces with a few bitwise operations:

1.

\mathop{\textbf{X!}}\varphi
is just a (left) shift by
1
of the characteristic sequences of
\varphi
, padding it with a
0
.

2.

\lnot\varphi
is the bitwise negation of the characteristic sequences.

3.

\varphi\land\psi
is the bitwise “and” of the characteristic sequences of the two formulas; the same can be done for
\varphi\lor\psi
with “or”.

4.

\mathop{\textbf{F}}\varphi
can be seen as
\varphi\lor\mathop{\textbf{X!}}\varphi\lor\mathop{\textbf{X!}}^{2}\varphi\lor\ldots{}

Since we work with finite traces, this converges to a fixed point in finite time.
We can actually compute this efficiently with a
logarithmic
number of shifts in the trace length: simply do shifts of powers of
2
up to the length of the trace.
For example, with the sequence
0000000100000001
, first shift by
1
and do an “or”: it gives us
0000001100000011
.
Shift by
2
and do an “or”, we get:
0000111100001111
.
Now we shift by
4
and do an “or”, giving us only
1
’s.
If instead we have
0000000000000001
, we also need to shift by
8
.
The example shows that since
1
’s propagate locally, we only need to do this operation
\log\ell
times, where
\ell
is the trace length.

5.

\mathop{\textbf{G}}\varphi
is equivalent to
\lnot\mathop{\textbf{F}}\lnot\varphi
.

6.

\varphi\mathbin{\textbf{U}}\psi
can be done similarly to
\mathop{\textbf{F}}\varphi
since it is
\psi\lor(\varphi\land\mathop{\textbf{X!}}\psi)\lor(\varphi\land\mathop{\textbf{X!}}(\varphi\land\mathop{\textbf{X!}}\psi))\lor\ldots{}
Intuitively, first compute
\varphi\land\mathop{\textbf{X!}}\psi
for all positions; it suffices to do an “and” on a shifted
\psi
.
Now, following the same protocol as
\mathop{\textbf{F}}\varphi
, it suffices to do the same shifts and “or”, but with the addition that before the “or”, as
\varphi
needs to be true at all positions before, we must do an “and” with the shifted
\varphi
.
