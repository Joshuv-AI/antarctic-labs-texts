stabel: An R package for variable selection and prediction in high-dimensional cross-sectional data
Authors: Apu Chandra Das, Ran Dai, Alyssa Bouska, Javeed Iqbal, Lynette M Smith
Published: 2026

ABSTRACT
AbstractVariable selection is crucial in high-dimensional biomedical research, yet many methods are unstable and select irrelevant variables. Stability selection improves robustness but may miss important variables and does not offer prediction. To address these limitations, we developed stabel, an R package, a framework that integrates multiple stability selection procedures with diverse models and subsampling strategies, followed by ensemble-based prediction. The package supports binary and continuous outcomes, offering LASSO, sparseSVM, and random forest for variable selection, and any prediction algorithm available in the SuperLearner package. stabel provides a flexible and reliable tool for high-dimensional variable selection and prediction.Keywords: stabel, Stability selection, Ensemble learning, Variable selection, Prediction

Introduction

High-dimensional biomedical data, where the number of candidate predictors p greatly exceeds the sample size n, require methods that can simultaneously identify true signals, control false discoveries, and produce reliable predictions. Penalized regression methods such as LASSO [1], adaptive LASSO [2], SCAD [3], MCP [4], and the bridge estimator [5] are widely used for this purpose, but they can be unstable under strong predictor correlation and sensitive to variable transformations [6,7], leading to selected sets that vary across resamples and to the omission of relevant information.

Stability selection [8,9] addresses part of this problem by aggregating variable selections across multiple subsamples and providing finite-sample control of the expected number of falsely selected variables. Several R packages implement variants of this idea. The stabs package [10] provides a flexible framework for stability selection that can be combined with user-specified base learners. Similarly, the sharp package [11] offers tools for evaluating and aggregating stability-selection procedures, including ensemble constructors and prediction methods for out-of-sample evaluation, where hyperparameters are calibrated by maximizing model stability, and variable selection is typically performed using a single algorithm at a time. Unlike existing implementations that primarily focus on a single variable-selection strategy within a stability-selection framework, stabel allows users to combine variables selected by multiple algorithms and seamlessly integrate the resulting predictor set into a SuperLearner-based prediction workflow.

On the prediction side, the SuperLearner package [12] implements a cross-validated ensemble-learning framework that combines multiple candidate algorithms into a weighted predictor with strong theoretical guarantees. Thus, both stability-based variable selection and ensemble prediction are, in principle, achievable using existing software. However, constructing a complete high-dimensional analysis pipeline typically requires users to manually combine stability selection procedures from packages such as stabs or sharp with separate prediction frameworks such as SuperLearner. In addition, users must manage cross-validation, tuning parameter selection, stability thresholds, and model evaluation across multiple packages. Furthermore, although stability selection effectively controls false discoveries, reliance on a single base learner may reduce sensitivity to important predictors, particularly in the presence of multicollinearity [13]. To address these limitations, we developed a statistical method named Stability Selection with Ensemble Learning (STABEL) [14] and later the R package stabel, a unified framework that combines stability selection based on multiple variable selection algorithms with ensemble prediction, thereby leveraging the complementary strengths of different learners to improve the identification of true signals while streamlining the entire analysis workflow.

Compared with stabs [10] and sharp [11], the distinguishing features of stabel are: (i) native multi-algorithm stability selection, which aggregates empirical selection probabilities across LASSO, random forest (RF), and sparse support vector machines (sparseSVM) within a single call rather than requiring users to manually combine separate base learners; (ii) a built-in interface to the SuperLearner library, so that the variables retained by stability selection can be passed directly to a cross-validated ensemble predictor without additional glue code; and (iii) an integrated evaluation workflow that supports user-specified or Youden-index-based classification thresholds, threshold tuning at a target sensitivity or specificity, and standard performance metrics. The overall pipeline is summarized in Fig. 1: candidate predictors are repeatedly evaluated on subsamples using one or more base learners, empirical selection probabilities are aggregated across resamples and across learners, variables exceeding a user-specified threshold are retained, and the resulting feature set is used to fit a Super Learner ensemble that is then evaluated on held-out data.

Flowchart illustrating the stabel package.

We evaluate the stabel package in two complementary ways. First, in a simulation study spanning independent, AR(1), and custom correlation structures, varying predictor and sample size, we report selection accuracy and prediction performance, and compare against plain LASSO, and single-learner stability selection (LASSO only). Second, we illustrate the package on a peripheral T-cell lymphoma (PTCL-NOS) gene-expression application, where all preprocessing, screening, and tuning are performed strictly within the training set to avoid information leakage. Across these evaluations, multi-algorithm stability selection in stabel yields more stable variable sets under correlated predictors and competitive or improved prediction accuracy, while reducing the implementation burden of assembling such pipelines from existing packages.

Sections 3 and 4 present the simulation studies, the PTCL-NOS data analysis, and practical guidance for selecting tuning parameters. Section 5 provides an overview of the package’s impact and applications. Section 6 discusses the limitations of the proposed methodology and software, and Section 7 concludes the paper with a summary of the main findings and directions for future research.

Implementation

stabel is an open-source R package that can easily be installed using ‘devtools::install_github(“apustat/stabel”)’ in R. Although stabel has been written to reduce the external number of dependencies, it still depends on some existing packages. The workflow of the stabel package is depicted in Fig. 1. In this section, we will demonstrate all available R functions that belong to our package.

Data generation

The stabel.sim function generates simulated high-dimensional datasets with multivariate normal predictors and user-defined outcomes. It supports continuous or binary responses via the family argument and allows users to specify sample size n, number of predictors p, and regression coefficients β. Predictors are drawn from a multivariate normal distribution with optional correlation structures (“Independent”, “Exchangeable”, or “AR1”), or a user-supplied matrix through the argument custom.corr. A random seed can be set for reproducibility. Note that this function is not required to implement our method. Users can input their data or simulate data using alternative models.

Cross-validation

The cv.stable function performs cross-validation to determine optimal values of tuning parameters. It supports “Lasso”, “sparseSVM”, or both as the variable selection techniques and model evaluation tools. The function takes X (predictor matrix) and Y (outcome vector), with the option to specify the outcome type using the family argument (default: “binomial” for classification). The fit.fun parameter allows users to choose between “Lasso”, “sparseSVM”, or both for fitting models. Users can provide custom evaluation metrics via eval.metric.Lasso and eval.metric.sparseSVM. The function performs K-fold cross-validation (default: 10 folds, controlled by nfolds) to estimate model performance and ensure robust variable selection. A random seed can be set for reproducibility. This function is essential for optimizing variable selection and model evaluation, making the package a powerful tool for predictive modeling and high-dimensional data analysis.

Variable selection

The stabel.vs function performs variable selection using predictors X and outcome Y for both binomial and Gaussian families. Users may choose “Lasso”, “sparseSVM”, “RF”, or any combination of these three. The cutoff (default 0.6) defines the selection threshold, and B sets the number of subsamples. Tuning parameters bestlam.Lasso and bestlam.sparseSVM are obtained from cv.stable. Note that sparseSVM supports only binary outcomes. The maxRuns parameter controls the number of selection runs for RF, and pValue sets its confidence level. Results from multiple methods can be combined using “union” or “average” via comb.method. By integrating diverse selection techniques, stabel.vs provides stable and efficient feature selection in high-dimensional settings.

Prediction

The stable.pred function performs prediction using ensemble learning. It takes X (predictor matrix) and Y (outcome vector) as input and allows prediction on a new dataset (newX, newY). The method argument is used for combining models in the ensemble, with nonnegative least squares (NNLS) as the default. The function supports all models available in SuperLearner package through SL.library argument, enabling a flexible model selection. The SL.library argument specifies the set of candidate algorithms whose cross-validated predictions are combined into a single weighted ensemble. For example, setting SL.library = c(“SL.glm”, “SL.randomForest”, “SL.svm”, “SL.lda”) instructs Super Learner to fit a logistic regression, a random forest, a support vector machine, and a linear discriminant analysis on the variables retained by stabel.vs, evaluate each via k-fold cross-validation, and assign non-negative weights so that algorithms with lower cross-validated risk receive larger weights in the final predictor. Users can extend this list with any learner available in or compatible with the SuperLearner package, including custom wrappers. The family argument defines the outcome type. Cross-validation is used for model evaluation. While thr.prob is a fixed threshold for classification, users can utilize the youden index as a datadriven classification threshold. However, if use.youden is TRUE then thr.prob must be NULL. Options like target.specificity, and target.sensitivity enable threshold tuning by computing sensitivity at a specified specificity and specificity at a specified sensitivity, respectively. A seed ensures reproducibility. This function provides a robust framework for predictive modeling using ensemble methods.

These are the four main functions of our package. In addition, users can easily plot the empirical selection probability, ROC curve, and mean square error (MSE) using base R functions or with the help of other packages.

Note on default argument values:

Throughout this section, all argument values shown in the function calls are defaults provided for illustration only. They are intended as reasonable starting points, not as universally optimal choices. Users are expected to adjust them — in particular, the selection cutoff, choice of base learners, candidate Super Learner library, and classification threshold — based on their sample size, predictor correlation structure, signal sparsity, computational budget, and the desired trade-off between sensitivity and false discovery control.

Simulation: Gaussian additive regression model

We consider a high-dimensional regression problem with a combination of linear, nonlinear, and smooth predictor effects. The response is generated from an additive Gaussian model with additive predictor η=∑j=1p fjxj where η is an n-dimensional vector and y~Nη,σ2I with σ2=1. The predictor vectors X=X1,…,Xp are generated under different dependence structures. In the baseline setting, covariates are independently drawn as Xj~Unif(-2,2), for j=1,…,p.

To assess robustness under correlation, we consider two dependent designs. First, an AR(1) structure is used, where

with ρ=0.8. In this case, covariates are also generated from a uniform distribution i.e., X~Unif(-2,2) with covariance matrix induced by the AR(1) structure.

Second, we consider a data-driven correlation structure motivated by real data in Section 4. Specifically, we first apply sure independence screening (SIS) [15] to identify a subset of p informative predictors from the observed training dataset. The empirical covariance matrix of the selected predictors is then estimated and used to construct Σ^. The maximum pairwise correlation among the selected predictors is 0.98 . Synthetic covariates are subsequently generated as X~N(0,Σ^), preserving the correlation pattern observed in the real data. Note that no response variable is used to compute the correlation structure.

To evaluate the effect of different sample sizes and predictors, we set the number of observations to n∈{200,400} and the number of predictors to p∈{1000,3000}. The functional effects fj(.) are specified such that only a subset of predictors have non-zero contributions, while all remaining effects are set to zero. The impact of the active predictors is depicted in Fig. 2. Additional simulation studies regarding binomial classification problems can be obtained from our previous papers [14, 16]. For all simulation scenarios, the data are randomly divided into a training set (60%) and a testing set (40%). Variable selection and model fitting are performed exclusively on the training data, while predictive performance is evaluated using the independent testing data. This separation ensures that the test data remain completely unseen during model development, thereby eliminating the possibility of data leakage and providing an unbiased assessment of predictive performance. Each simulation setting is replicated 100 times.

Within the stabel framework, LASSO and RF are used for variable selection, as sparseSVM can handle only binary responses, and RF, linear regression (LR), and Kernel support vector regression (SVR) are used in ensemble learning for prediction. The tuning parameter (λ) for LASSO is obtained from a 5-fold cross-validation. For the stability selection procedures, a selection probability cutoff of 0.70 was used, which falls within the recommended range of ([0.6, 0.9]), with performance generally being insensitive to moderate changes within this interval [8,9]. This value was chosen because it represents a balanced compromise between variable selection sensitivity and false discovery control. Specifically, it lies near the midpoint of the recommended range, provides stronger control of false positives than the more liberal cutoff of 0.60, and is particularly well suited to the multi-algorithm aggregation strategy implemented in stabel, where a slightly higher threshold helps ensure that selected variables receive consistent support across multiple base learners. In practice, a cutoff of 0.70 offers a conservative balance between retaining truly informative predictors and excluding unstable variables. Lower thresholds generally increase the number of selected variables but at the expense of higher false discovery rates, whereas substantially higher thresholds may become overly restrictive and fail to identify biologically meaningful predictors. We note that the package default remains 0.60 to provide flexibility across a wide range of applications. Another tuning parameter B=50, total 100 subsamples, is chosen based on the recommendation of Shah & Samworth (2013) [9]. Choosing B larger than this increases the computational burden, and may lead to the r-concavity assumption being violated [9]. The remaining parameters are less important; therefore, the default values are recommended. Readers are suggested to read the R packages Boruta [17] and spareseSVM [18] for more details.

The variable selection performance, measured by the true positive rate (TPR) and false discovery rate (FDR), is summarized in Table 1. Across all three correlation settings, the proposed stabel-based procedures demonstrate a clear advantage in variable selection performance in terms of the TPR–FDR trade-off. In the independent setting, stabel-union consistently achieves competitive or higher TPR compared to competing methods while stabel-avg yields substantially more conservative selections with dramatically reduced FDR (close to zero across all scenarios). In contrast, both SS-LASSO and standard LASSO exhibit inflated false discovery rates, particularly as dimensionality increases, despite achieving moderate TPR. Under the stronger AR(1) dependence structure, stabel-union attains the highest TPR across all settings (up to 0.91), while stabel-avg maintains near-zero FDR, highlighting its strong screening property. Competing approaches show a clear degradation, with both SS-LASSO and LASSO suffering from substantially higher FDR and less stabel selection. In the most challenging custom-correlation scenario, stabel-based methods again provide the most favorable balance: while stabel-union maintains higher sensitivity (up to 0.61), stabel-avg continues to control false discoveries (maximum FDR=0.50) substantially better than all competing approaches, whereas LASSO and SS-LASSO exhibit persistently high FDR and less reliable selection behavior.

The superiority of the proposed package is further supported by prediction results, as measured by root mean squared error (RMSE) and mean absolute error (MAE), across all scenarios. As shown in Fig. 3, both stabel-avg and stabel-union consistently achieve lower prediction error compared to SS-LASSO and LASSO across different values of n,p, and correlation structures. In particular, stabel-avg provides the most stable and lowest error profile in most settings, reflecting its strong sparsity-inducing behavior, while stabel-union offers a competitive trade-off between predictive accuracy and sensitivity. In contrast, LASSO and SS-LASSO generally yield higher RMSE and MAE, especially under correlated and high-dimensional regimes, indicating reduced robustness in complex dependence structures. Overall, these results demonstrate that the proposed stabel-based approaches achieve a superior balance between accurate variable selection and predictive performance, offering consistent gains in both inference (TPR/FDR control) and prediction (RMSE/MAE) across all simulation settings.

The computational cost of the proposed framework (Table 2) depends primarily on the sample size, dimensionality, and the choice of base learners. For a moderately large dataset (n = 200, p = 1000) with independent predictors, a single iteration requires approximately 44 s on a machine equipped with an Intel Core Ultra 7 processor, 32 GB of RAM, and 8 cores. Increasing the number of predictors to p = 3000 increases the runtime to 77 s. The runtime gets doubled for a custom correlation structure. Nevertheless, the computational burden can be substantially reduced through parallel computing, as the subsampling and model-fitting steps are naturally parallelizable.

Application

Peripheral T-cell lymphoma (PTCL) is a heterogeneous disease with poor outcomes, and 30%–50% of cases remain unclassifiable as PTCL not otherwise specified (PTCL-NOS) [19]. Gene-expression profiling (GEP) of 418 PTCL cases identified major molecular subtypes, including ALK(+) and ALK(−) ALCL, and revealed two dominant PTCL-NOS groups characterized by high GATA3 (40%) or TBX21 (60%) expression. Although several recurrent genetic abnormalities have been reported [20–22], few provide subtype-specific diagnostic value beyond t(2;5)(p23;q35) in ALK(+) ALCL. As a result, GEP has become essential for improving PTCL classification and understanding disease biology [23–28].

In this study, we use the PTCL-NOS dataset to demonstrate how our stabel package performs stable gene selection and predictive modeling to classify patients into the GATA3 or TBX21 molecular subgroups. Fig. 4 illustrates the steps of data processing, screening, important gene selection, model fitting, and model validation of the GEP data.

Workflow of the data preprocessing, variable selection, model development, and validation pipeline. The training set is used for screening, variable selection, and model fitting, while the testing set is reserved for independent model validation.

Prior to analysis, the dataset was first randomly divided into a training set (60%) and an independent testing set (40%) to ensure a strictly isolated hold-out evaluation and to prevent information leakage from the test data into the model development process. All subsequent preprocessing, feature screening, variable selection, tuning, and model fitting procedures were performed exclusively within the training set. The testing set was not used at any stage of feature selection, hyperparameter tuning, or model construction and was accessed only once for final model evaluation.

To reduce dimensionality, two preprocessing steps were applied to the training data only. First, among all measured genes, the 10,000 genes exhibiting the highest variability across training subjects were retained, as highly variable genes are more likely to contain biologically relevant information. Second, SIS [15] was applied to these 10,000 genes to identify the 30 genes most strongly associated with the outcome. The selected 30 genes were subsequently used as candidate predictors for all downstream analyses. The resulting 30 genes were then subjected to three variable-selection approaches: stabel, standard LASSO, and stability selection with LASSO (SS-LASSO) as described in Shah & Samworth (2013) [9]. The primary objective was to identify genes that best distinguish the two major PTCL-NOS molecular subtypes, GATA3 and TBX21. For the stability selection procedures, a selection probability cutoff of 0.70 was used. The regularization parameters for LASSO and sparseSVM were selected using cross-validation. All remaining tuning parameters were identical to those used in the simulation studies to ensure a consistent evaluation across methods.

Our proposed stabel framework identified a parsimonious set of five genes (C1QA, C1QB, FBP1, GM2A, and HSD11B1) by combining LASSO, RF, and sparseSVM within the stability selection framework and a balanced prediction across all metrics (Accuracy = 93%, AUC = 98%, Sensitivity = 89%, Specificity = 100%). In contrast, standard LASSO selected eleven genes (C1QA, FBP1, GM2A, HSD11B1, SLAMF7, CXCL11, EPB41L3, LYZ, S100A9, FAM20A, and SUCNR1). As shown in Table 3, the LASSO-based ensemble learning model achieved the highest testing-set performance (Accuracy = 98%, AUC = 99%, Sensitivity = 100%, and Specificity = 92%). While these results are nearly perfect, they should be interpreted cautiously given the relatively small sample size and the potential for overfitting when a larger set of predictors is retained. Importantly, the train-test split was performed prior to all preprocessing, feature screening, variable selection, and hyperparameter tuning, and the testing set was completely excluded from the model-development process. Therefore, the observed performance cannot be attributed to information leakage. Furthermore, Fig. 5 demonstrates substantial biological separation between the GATA3 and TBX21 subtypes, with several genes (e.g., C1QA, C1QB, and FBP1) exhibiting distinct subtype-specific expression patterns. The unsupervised clustering analysis reveals two well-defined clusters corresponding to the molecular subtypes, suggesting that the underlying classification problem may be inherently easier than many high-dimensional prediction tasks and may partially explain the strong predictive performance observed.

To facilitate a fairer comparison with stabel, we additionally considered a modified LASSO model (LASSO-EL*) in which the regularization parameter λ was increased beyond the cross-validated value until the model retained the same number of genes (five) as stabel. This modified model was included solely as a sensitivity analysis to assess predictive performance when both approaches selected an equal number of predictors and should not be viewed as the optimal LASSO model. We also implemented SS-LASSO using the stabs package, which selected only one gene (FBP1). This model used stability selection with LASSO for variable selection and logistic regression (LR) for prediction. SS-LASSO has reduced performance across all metrics (Accuracy = 90%, AUC = 95%, Sensitivity = 89%, and Specificity = 92%), especially sensitivity at 98.5% specificity (78%), compared with stabel, an essential metric for early disease detection. During the ensemble prediction stage, RF, SVM, and LDA learners were combined through the SuperLearner framework. Overall, these findings suggest that stabel identifies a smaller and more biologically interpretable set of genes while maintaining excellent predictive performance, indicating that the selected genes capture the key discriminatory signals between the GATA3 and TBX21 molecular subtypes more efficiently than standard LASSO-EL or SS-LASSO. Note that a Youden [29] index-based threshold was used for classification across all methods.

Impact overview

The stabel package improves high-dimensional data analysis by combining stability selection with ensemble learning algorithms in a single, flexible framework. It enhances variable selection in complex settings, increases prediction accuracy, and reduces model instability. The software has been used in our research [14] to identify robust combinations of biomarkers for early cancer detection, demonstrating its effectiveness in reducing overfitting and achieving strong and reproducible predictive performance in both discovery and validation phases. As demonstrated in our application to ovarian cancer biomarker discovery using data from the PLCO Cancer Screening Trials, stabel effectively combines stability-based feature selection with ensemble prediction methods, including RF, LR, LDA, and SVM. This integrated approach yields improved sensitivity, specificity, accuracy, and area under the curve compared to existing methods. By integrating feature selection and prediction, stabel streamlines workflows and is broadly applicable to fields such as genomics, biomedical research, and machine learning.

Limitation

Despite its advantages, the stabel package has a few limitations. First, the framework can be computationally intensive, as it incorporates multiple variable selection methods, repeated subsampling, and ensemble-based prediction, which may lead to increased runtime for ultra–high-dimensional datasets. Although parallel computing and pre-screening variables can substantially reduce execution time, the computational burden may still be considerable for very large-scale applications. Second, the performance of stabel depends on user-specified tuning parameters (e.g., cutoff values, subsample size, and model choices), and suboptimal selections may affect stability and prediction accuracy, particularly in small-sample settings. While stabel is relatively robust to moderate changes in these parameters, suboptimal choices may affect variable selection stability and predictive accuracy, particularly in small-sample settings.

Conclusion

The stabel R package can be used in various settings that are useful for biomedical research. This package can be used for both linear and non-linear models as long as the distribution of outcomes belongs to the exponential family. By leveraging LASSO, RF, and sparseSVM, the package addresses key limitations of traditional methods and offers a robust, interpretable, and adaptable solution for variable selection. A wide variety of machine learning and statistical models are also used for prediction. Although the framework can be computationally intensive for ultra-high-dimensional datasets, several strategies can improve scalability, including preliminary feature-screening methods such as SIS, variance-based filtering, parallel computation of subsampling procedures, and restricting the set of candidate predictors prior to stability selection. These approaches can substantially reduce computational burden while preserving the ability to identify informative features.

Future work will focus on integrating additional functions to handle repeatedly measured data, implementing parallel computing capabilities, and developing more computationally efficient algorithms for large-scale genomic and other ultra-high-dimensional applications. The package is available at: https://github.com/apustat/stabel.
