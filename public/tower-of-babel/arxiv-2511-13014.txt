Maximal Palindromes in MPC: Simple and Optimal
Solon P. Pissis

Abstract
In the classical longest palindromic substring (LPS) problem, we are given a string S S of length n n , and the task is to output a longest palindromic substring in S S . Gilbert, Hajiaghayi, Saleh, and Seddighin [SPAA 2023] showed how to solve the LPS problem in the Massively Parallel Computation (MPC) model in 𝒪 ⁡ ( 1 ) \mathcal{O}(1) rounds using 𝒪 ~ ​ ( n ) \mathcal{\widetilde{O}}(n) total memory, with 𝒪 ~ ​ ( n 1 − ϵ ) \mathcal{\widetilde{O}}(n^{1-\epsilon}) memory per machine, for any ϵ ∈ ( 0 , 0.5 ] \epsilon\in(0,0.5] . We present a simple and optimal algorithm to solve the LPS problem in the MPC model in 𝒪 ⁡ ( 1 ) \mathcal{O}(1) rounds. The total time and memory are 𝒪 ⁡ ( n ) \mathcal{O}(n) , with 𝒪 ⁡ ( n 1 − ϵ ) \mathcal{O}(n^{1-\epsilon}) memory per machine, for any ϵ ∈ ( 0 , 0.5 ] \epsilon\in(0,0.5] . A key attribute of our algorithm is its ability to compute all maximal palindromes in the same complexities. Furthermore, our new insights allow us to bypass the constraint ϵ ∈ ( 0 , 0.5 ] \epsilon\in(0,0.5] in the Adaptive MPC model. Our algorithms and the one proposed by Gilbert et al. for the LPS problem are randomized and succeed with high probability.



1
Introduction

In the classical
longest palindromic substring
(LPS) problem, we are given a string
S
of length
n
over an alphabet
\Sigma
, and the task is to output a longest palindromic substring in
S
. The LPS problem can be solved efficiently. Several algorithms achieve
\mathcal{O}(n)
-time complexity, including Manacher’s celebrated algorithm
[
19
,
3
]
, Jeuring’s algorithm
[
16
]
, and Gusfield’s algorithm, which leverages longest common prefix queries
[
13
]
. In fact, these algorithms can output all
maximal palindromes
: the longest palindrome centered at every position within
S
. More recently, Charalampopoulos, Pissis, and Radoszewski
[
6
]
gave an algorithm that solves LPS in
\mathcal{O}(n\frac{\log\sigma}{\log n})
time, where
\Sigma=[0,\sigma)
is an integer alphabet. If, for instance,
\Sigma=\{0,1\}
and
\sigma=2
, their algorithm runs in
\mathcal{O}(n/\log n)
time.
The LPS problem has also been studied in many other settings, such as the compressed setting, where the string
S
is given as a straight-line program
[
20
]
, the streaming setting
[
10
]
, the dynamic setting, where
S
undergoes edit operations
[
1
]
, and a semi-dynamic setting
[
8
]
. In the quantum setting, Le Gall and Seddighin
[
9
]
gave a strongly sublinear-time algorithm complemented with a lower bound.

In this work, we study the LPS problem in the
Massively Parallel Computation
(MPC) model
[
17
,
12
,
2
,
4
,
15
]
. In MPC, problems with a data size of
\mathcal{O}(n)
are distributed across multiple machines, each having a strongly sublinear memory. Algorithms in MPC operate in a sequence of rounds. During each round, the machines independently perform computations on their local data. Following this, the machines communicate with each other. Given that communication often presents a significant performance bottleneck in real-world applications, the primary objective when designing MPC algorithms is to minimize the round complexity while ensuring that the total memory across all machines remains
\mathcal{O}(n)
. Specifically, each machine has
\mathcal{O}(n^{1-\epsilon})
memory, where
\epsilon\in(0,1)
. During a single communication round, machines can send and receive any number of messages, provided that the total size of these messages fits within their local memory limits. Typically, we require that each machine’s local memory is sufficient to store a message from every other machine in a single communication round. To facilitate this, we must ensure that a machine’s local memory,
\mathcal{O}(n^{1-\epsilon})
, is greater than the number of machines, which is
\mathcal{O}(n^{\epsilon})
. We thus restrict
\epsilon
to
\epsilon\in(0,0.5]
. This is justified within the MPC model because, with current computing resources, the number of machines typically does not exceed the local memory capacity of each machine.

We also consider the
Adaptive
MPC (AMPC) model
[
5
]
, which extends the MPC model by allowing machines to access a shared read-only memory
within a round
. This is modeled by writing all messages sent in round
i-1
to a distributed data storage, which all machines can read from within round
i
.

State of the Art.

Gilbert, Hajiaghayi, Saleh, and Seddighin
[
11
]
showed how to solve the LPS problem in the MPC model in
\mathcal{O}(1)
rounds using
\mathcal{\widetilde{O}}(n)
total memory, with
\mathcal{\widetilde{O}}(n^{1-\epsilon})
memory per machine, for any
\epsilon\in(0,0.5]
, with high probability (w.h.p). Their algorithm is based on periodicity arguments borrowed from
[
3
]
and a powerful oracle they introduce to answer longest common prefix queries. Unfortunately, it was difficult to assess the simplicity of their algorithm, as many proofs (and subroutines) are deferred to the full version of their work. For the same reason, we have been unable to count the polylogarithmic factors in the claimed
\mathcal{\widetilde{O}}(n)
total memory. Finally, the authors make no claim about the total running time of their algorithm.

Our Contributions and Paper Organization.

Our central contribution is a simple and optimal algorithm to solve the LPS problem in the MPC model in
\mathcal{O}(1)
rounds. The total time and memory are
\mathcal{O}(n)
, with
\mathcal{O}(n^{1-\epsilon})
memory per machine, for any
\epsilon\in(0,0.5]
, w.h.p. Our algorithm translates several of the combinatorial insights of Charalampopoulos et al.
[
6
]
into a suitable block decomposition for the MPC model, and carefully combines the latter with a modular decomposition, which was also utilized by Gilbert et al. in
[
11
]
.
A key attribute of our algorithm is its ability to compute all
maximal palindromes
in the same complexities. Furthermore, our new insights allow us to bypass the constraint
\epsilon\in(0,0.5]
in the stronger AMPC model. Our algorithms can be implemented by anyone with a basic knowledge of parallel programming using our
\tilde{3}
-page description, which also includes the arguments to fully verify the correctness of our algorithms. In
Section

2
, we present some basic concepts and in
Section

3
, we present our algorithms. We conclude the paper in
Section

4
with some final remarks.

2
Basics

Strings.

We consider an integer alphabet
\Sigma=[0,\sigma)
of size
\sigma
. A
string

S=S[0]\dots S[n-1]
is a sequence over
\Sigma
;
its
length
is denoted by
|S|=n
. For
0\leq i\leq j<n
,
a string
S[i]\dots S[j]
is called a
substring
of
S
.
By
S[i\mathinner{.\,.}j]
, we denote its occurrence at position
i
, which is called a
fragment
of
S
. A fragment with
i=0
is called a
prefix
(also denoted by
S[\mathinner{.\,.}j]
) and a fragment with
j=n-1
is called a
suffix
(also denoted by
S[i\mathinner{.\,.}]
). By
ST
or
S\cdot T
, we denote the
concatenation
of
two strings
S
and
T
. We denote the
reverse
string of
S
by
S^{R}
,
i.e.,
S^{R}=S[n-1]\dots S[0]
. The string
S
is a
palindrome
if and only if
S=S^{R}
. If
S[i\mathinner{.\,.}j]
is a palindrome, the number
\frac{i+j}{2}
is called the
center
of
S[i\mathinner{.\,.}j]
. A palindromic fragment
S[i\mathinner{.\,.}j]
of
S
is said to be a
maximal palindrome
if there is no longer palindrome in
S
with center
\frac{i+j}{2}
. Note that a longest palindromic substring in
S
must be maximal. A positive integer
p
is called a
period
of a string
S
, if
S[i]=S[i+p]
, for all
i\in[0,|S|-p)
.

Fact 2.1

(cf.
[
7
]
)
.

Let
U
be a prefix of a palindrome
V
, with
|U|<|V|
. Then
|V|-|U|

is a period of
V
if and only if
U
is a palindrome.
In particular,
|V|-|U|
is the smallest period of
V
if and
only if
U
, with
U\neq V
, is the longest palindromic prefix of
V
.

LCP Queries.

Let
S
be a string of length
n
. For any two positions
i,j
(
0\leq i,j<n
) in
S
, we define
\textsf{LCP}_{S}(i,j)
as the length of the longest common prefix (LCP) of the suffixes
S[i\mathinner{.\,.}]
and
S[j\mathinner{.\,.}]
. It is well known that computing the maximal palindrome of any center
c
in
S
reduces to asking
\textsf{LCP}_{S^{\prime}}(c,2n-c-1)
for odd-length palindromes and
\textsf{LCP}_{S^{\prime}}(\lceil c\rceil,2n-\lceil c\rceil)
for even-length palindromes, where
S^{\prime}:=S\cdot S^{R}

[
13
]
.

Karp-Rabin Fingerprints.

For a prime number
p
and an integer
x\in\mathbb{Z}^{+}
, the
Karp-Rabin
(KR)
fingerprint

[
18
]

of a string
S
of length
n
is
\phi(S)=(\sum^{n-1}_{i=0}S[i]\cdot x^{i})\mod p
. We also maintain
(x^{n-1}\mod p,x^{-(n-1)}\mod p,n)
with it for efficiency. The KR fingerprints for
S
are
collision-free
if
\phi(S[i\mathinner{.\,.}j])=\phi(S[i^{\prime}\mathinner{.\,.}j^{\prime}])
implies
S[i\mathinner{.\,.}j]=S[i^{\prime}\mathinner{.\,.}j^{\prime}]
. Using randomization, we can construct such fingerprints succeeding
with high probability
(w.h.p.).

Fact 2.2

(cf.
[
14
]
)
.

Let
S
be a string of length
n
over an alphabet
\Sigma
,
and let
p\geq\max(|\Sigma|,n^{3+c})
be a prime number. If
x
is chosen uniformly at random, then
\phi
is collision-free with probability at least
1-n^{-c}
.

Fact 2.3

(cf.
[
14
]
)
.

Let
U,V,W
be strings such that
UV=W
.
Given two of the three KR fingerprints
\phi(U),\phi(V),\phi(W)
, the third can be computed in
\mathcal{O}(1)
time.

3
The Algorithms

Let
S\in\Sigma^{n}
be the input string to the LPS problem.
In addition to
S
, we will consider the string
S^{\prime}:=S\cdot S^{R}\in\Sigma^{2n}
to be input to our algorithms. Clearly, the total input size is
\mathcal{O}(n)
, as required.

Combinatorial Insights.

Let
F=S[i\mathinner{.\,.}j]=B_{1}B_{2}B_{3}B_{4}
be a fragment of
S
of length
\ell=4\ell^{\prime}
, with
\ell^{\prime}=|B_{1}|=|B_{2}|=|B_{3}|=|B_{4}|>0
.
Let
\mathcal{P}_{F}
be the set of palindromes in
S
that are
prefixes
of
F
with centers in
[i+\ell^{\prime},i+2\ell^{\prime})
(i.e., in
B_{2}
). Further let
\mathcal{M}_{F}
be the set of
maximal
palindromes in
S
with centers in
[i+\ell^{\prime},i+2\ell^{\prime})
that either
exceed

F
or are
prefixes
of
F
. The following structural lemma shows that either
|\mathcal{M}_{F}|\leq 1
or the palindromes in
\mathcal{P}_{F}
share the same period. This lemma will inspire our
block decomposition
.

Lemma 3.1
.

Let
F=S[i\mathinner{.\,.}j]=B_{1}B_{2}B_{3}B_{4}
be a fragment of
S
of length
\ell=4\ell^{\prime}
, with
\ell^{\prime}=|B_{1}|=|B_{2}|=|B_{3}|=|B_{4}|>0
. Then the following hold: (1) If
|\mathcal{P}_{F}|=0
, then
|\mathcal{M}_{F}|=0
; (2) If
|\mathcal{P}_{F}|=1
, then
|\mathcal{M}_{F}|=1
; (3)
If
|\mathcal{P}_{F}|\geq 2
, every
P\in\mathcal{P}_{F}
has a period
p
, where
p
is the smallest period of
the longest palindrome in
\mathcal{P}_{F}
.

Proof.

By the decomposition of
F
into
B_{1}B_{2}B_{3}B_{4}
, every
M\in\mathcal{M}_{F}
has as a
substring
a palindrome
P\in\mathcal{P}_{F}
with the same center (in
B_{2}
). Thus the first two items are immediate.

For
|\mathcal{P}_{F}|\geq 2
, let us denote the longest palindrome in
\mathcal{P}_{F}
by
P_{1}
.
Let
P_{2}
denote any other palindrome in
\mathcal{P}_{F}
.
Let
n_{1}:=|P_{1}|
and
n_{2}:=|P_{2}|
.
By
2.1
,
(n_{1}-n_{2})
is a period of
P_{1}
.
By definition, the smallest period
p
of
P_{1}
must be less than or equal to any other period of
P_{1}
. Thus, we have
p\leq n_{1}-n_{2}
.

To show that
P_{2}
has a period
p
, we must prove that
P_{2}[i]=P_{2}[i+p]
, for all
0\leq i<n_{2}-p
. Since
P_{2}
is a prefix of
P_{1}
, the corresponding letters are identical for the entire length of
P_{2}
. By the definition of period, since
p
is a period of
P_{1}
, we know that
P_{1}[i]=P_{1}[i+p]
, for all
0\leq i<n_{1}-p
.

From
n_{2}<n_{1}
, we have
n_{2}-p<n_{1}-p
. If we assume that
n_{2}-p
is positive, this shows that the range of periodicity for
P_{2}
is fully contained within the range where
P_{1}
’s periodicity is guaranteed. This means that the periodic property of
P_{1}
holds over the entire length of its prefix
P_{2}
. Therefore, for any
i
in the range
0\leq i<n_{2}-p
, we have

P_{2}[i]=P_{1}[i]=P_{1}[i+p]=P_{2}[i+p]
. This proves that
P_{2}
has a period
p
.

However, we still need to prove that
n_{2}-p
is positive; i.e.,
n_{2}>p
.
Recall
p\leq n_{1}-n_{2}
.
The centers of
P_{1}
and
P_{2}
lie within
[\ell^{\prime},2\ell^{\prime})
on
F
. This implies that the difference in their lengths is at most
2\ell^{\prime}
:
n_{1}-n_{2}\leq 2\ell^{\prime}
.
The center
c_{2}
of
P_{2}
is such that
c_{2}\geq\ell^{\prime}
. This gives a lower bound for the length of
P_{2}
:
n_{2}\geq 2\ell^{\prime}+1
.

Assuming for contradiction that
n_{2}\leq p
, we combine the bounds from the steps above:
2\ell^{\prime}+1\leq n_{2}\leq p\leq n_{1}-n_{2}\leq 2\ell^{\prime}
.
This leads to the contradiction:
2\ell^{\prime}+1\leq 2\ell^{\prime}\implies 1\leq 0
.
Thus,
n_{2}>p
always holds.
∎

The crucial algorithmic implication of
Lemma

3.1

is
Lemma

3.2
: we can reduce the computation of
\mathcal{M}_{F}
to
\mathcal{O}(1)
LCP queries by accessing only
F
. Our block decomposition will be precisely based on this result.

Lemma 3.2
.

Let
S
be a string of length
n
. Given read-only access to an arbitrary fragment
F=S[i\mathinner{.\,.}j]=B_{1}B_{2}B_{3}B_{4}
of
S
of length
\ell=4\ell^{\prime}
, with
\ell^{\prime}=|B_{1}|=|B_{2}|=|B_{3}|=|B_{4}|>0
,
all palindromes in
\mathcal{M}_{F}
can be computed in
\mathcal{O}(|F|)
time and space plus the time and space to answer
3
LCP queries on string
S^{\prime}:=S\cdot S^{R}
.

Before proving
Lemma

3.2
, we prove some standard facts relating palindromes to periodicity.

Fact 3.3
.

If string
P
with a period
p
is a palindrome and string
S=cPc^{\prime}
, for two letters
c,c^{\prime}
, has
p
as a period too, then
S
is a palindrome.

Proof.

Let
n:=|P|
. Since
S=cPc^{\prime}
has a period
p
,
c=P[p-1]
and
c^{\prime}=P[n-p]
. Since
P
is a palindrome,
P[p-1]=P[n-p]
.
By combining these three results we have:
c=P[p-1]=P[n-p]=c^{\prime}
.
Since
c=c^{\prime}
, and
P
is a palindrome, the string
S=cPc^{\prime}
is also a palindrome, by the definition of a palindrome.
∎

Fact 3.4
.

If string
P
with a period
p
is a palindrome, string
cP
, for a letter
c
, has
p
as a period, and string
Pc^{\prime}
, for a letter
c^{\prime}
, does not have
p
as period, then
S=cPc^{\prime}
is not a palindrome.

Proof.

Let
n:=|P|
. By the statement, we have
c=P[p-1]
and
c^{\prime}\neq P[n-p]
.
Since
P
is a palindrome,
P[i]=P[n-1-i]
, for all valid indices
i
.
For the index
i=p-1
, this gives
P[p-1]=P[n-1-(p-1)]=P[n-p]
.
Combining these results, we get:
c=P[p-1]=P[n-p]\neq c^{\prime}
.
This shows that the first and last letters of
S=cPc^{\prime}
are not equal (
c\neq c^{\prime}
), and therefore
S
is not a palindrome, by the definition of a palindrome.
∎

Proof of
Lemma

3.2
.

We compute
\mathcal{P}_{F}
in
\mathcal{O}(|F|)
time using Manacher’s algorithm and apply
Lemma

3.1
.

If
|\mathcal{P}_{F}|=0
, then
|\mathcal{M}_{F}|=0
.
If
|\mathcal{P}_{F}|=1
, then we know that
|\mathcal{M}_{F}|=1
, and proceed as follows.
We find the center
c
of
P\in\mathcal{P}_{F}
in
B_{2}
and ask

\textsf{LCP}_{S^{\prime}}(c,2n-c-1)
, if
P
is odd-length palindrome, or
\textsf{LCP}_{S^{\prime}}(\lceil c\rceil,2n-\lceil c\rceil)
, if
P
is even-length palindrome, to find the corresponding
M\in\mathcal{M}_{F}
with center
c
.

If
|\mathcal{P}_{F}|\geq 2
, then by
Lemma

3.1
and
2.1
,
every palindrome in
\mathcal{P}_{F}
has
period
p:=|P_{1}|-|P_{2}|
,
where
P_{1}
and
P_{2}
are the longest and second longest palindromes in
\mathcal{P}_{F}
, respectively.
We check how long this period
p
extends to the left and to the right of
F

by asking two
\textsf{LCP}_{S^{\prime}}
queries.
For the left part, we ask
a:=\textsf{LCP}_{S^{\prime}}(2n-i-p,2n-i)
;
and for the right part, we ask
b:=\textsf{LCP}_{S^{\prime}}(i,i+p)
.
The periodic fragment of
S
with period
p
is thus
S[i-a\mathinner{.\,.}i+b-1]
.
For every
P\in\mathcal{P}_{F}
and
M\in\mathcal{M}_{F}
with the same center
c
,
we have two cases:

Case A
:
|P|=b-a
. The left and right endpoints of the periodic fragment are reached
simultaneously
from the center
c
of palindrome
P\in\mathcal{P}_{F}
with
|P|=b-a
. We ask
\textsf{LCP}_{S^{\prime}}(c,2n-c-1)
if
P
is odd-length palindrome, or
\textsf{LCP}_{S^{\prime}}(\lceil c\rceil,2n-\lceil c\rceil)
if
P
is even-length palindrome, to find
M\in\mathcal{M}_{F}
with center
c
. This is correct because
M
is a palindrome by
3.3
and it is maximal by the LCP query definition.

Case B
:
|M|=\min(|P|+2a,2b-|P|)
. We reach one of the two endpoints of the periodic fragment
first
coming from the center of
P
. If periodicity breaks first on the left,
|M|=|P|+2a
; otherwise,

\displaystyle|M|

\displaystyle=(\text{left extension})+|P|+(\text{right extension})

\displaystyle=(b-|P|)+|P|+(b-|P|)

\displaystyle=2b-|P|

This is correct because
M
is a palindrome by
3.3
; and it is maximal by
3.4
and symmetry.

∎

Remark 3.5
.

A lemma very similar to
Lemma

3.2
was also shown by Charalampopoulos et al.
[
6
]
, who considered the LPS problem in a very different setting: string
S\in\Sigma^{n}
is given in packed form and the task is to solve LPS sequentially in sublinear time for a small alphabet
\Sigma
. The authors showed a version of
Lemma

3.2
in a special setting; that is, for
\ell^{\prime}:=\max(1,\frac{1}{8}\log_{\sigma}n)
, with
\sigma=|\Sigma|
, and for computing only a
longest
palindrome in
\mathcal{M}_{F}
. Our proof is also considerably simpler—precisely due to the fact that we have no constraint on
\ell^{\prime}
.

The Algorithms.

Armed with the above combinatorial insights, we are now in a position to state our main algorithm. We decompose
S
into a sequence of length-
\ell^{\prime}

blocks
with
\ell^{\prime}:=n^{1-\epsilon}
. These blocks do not overlap. We also split
S
into a sequence of length-
\ell

superblocks
, with
\ell:=4\ell^{\prime}
, such that every two consecutive superblocks overlap by
3\ell^{\prime}
positions. We use
n^{\epsilon}
machines, called
block
machines. Each machine is assigned one such superblock. Thus, the memory used by every machine is
\mathcal{O}(n^{1-\epsilon})
. The goal is to compute the maximal palindromes that are centered within the
second block
of each superblock. Observe that any maximal palindrome centered at the first or last
2n^{1-\epsilon}
positions of
S
can be of length at most
4n^{1-\epsilon}=\ell
. Thus, the first and last machines can finish this assignment locally using Manacher’s algorithm
[
19
]
. See
Figure

1
that illustrates this
block decomposition
.

Figure 1
:
Illustration of the
block decomposition
. The top (black) lines show the size of the (overlapping) superblocks and
the size of the (non-overlapping) blocks. The bottom (dark red) lines show how the superblocks are assigned to the machines. Thus, we use
n^{\epsilon}
machines with local memory
\mathcal{O}(n^{1-\epsilon})
for this decomposition.

Lemma

3.2
leads to a simple and elegant algorithm because each block machine determines
\mathcal{O}(1)
LCP queries by
accessing its local superblock
. This is a key difference from the algorithm by Gilbert et al., where a more complicated method involving ranges of blocks is used to determine the set of LCP queries. For every second block, denoted by
B_{2}
, in a superblock
F
, we will compute: (i) the maximal palindromes of
F
with centers in
B_{2}
computed locally; and (ii) the maximal palindromes of
S
computed by applying
Lemma

3.2
to
F
with
\ell:=4n^{1-\epsilon}
. For (i), we use Manacher’s algorithm on
F
to compute all maximal palindromes.

Thus, what remains is to show how we can fully implement
Lemma

3.2
in our setting; i.e., how we can answer the LCP queries.
For this, we will resort to a second (folklore) decomposition of string
S^{\prime}:=S\cdot S^{R}
, called
modular decomposition
, which was also used by Gilbert et al. We make use of
n^{\epsilon}
machines.
The machine
M_{x}
with ID
x
, for all
x\in[0,n^{\epsilon})
, stores the KR fingerprint of every fragment of length
n^{\epsilon}
starting at position
i
in
S^{\prime}
so that
i\mod n^{\epsilon}=x
.
Thus, the memory used by every machine is
\mathcal{O}(n^{1-\epsilon})
and the total memory used is

\mathcal{O}(n)
by using
2.3

3.2

\epsilon\leq 0.5
. However, the total size of the messages for these requests may exceed the local memory of the machine, and so to balance these requests
we resort to
data replication

Every machine (evenly) decomposes its data into as many fragments as the number of requested messages, and sends these fragments to as many different machines, which then replicate the data in as many copies. Since a machine’s local memory is sufficient to store a message from every other machine in a single communication round, it is straightforward to arrange where to send and from where to retrieve the data. Thus each machine sends or receives data of
\mathcal{O}(n^{1-\epsilon})
size in
\mathcal{O}(1)
rounds. Moreover, the data replication takes
\mathcal{O}(n)
total time. See

In the AMPC model, we can bypass the constraint

4
Concluding Remarks

The purpose of this paper is twofold. From the results perspective, our algorithms may inspire further work on classical string matching problems in MPC or AMPC, and they may serve as a useful guide for parallel implementations. From a pedagogical standpoint, our paper may serve as material for a class on parallel and distributed algorithms showcasing a remarkably simple and optimal algorithm obtained through combinatorial insight. We propose the following two questions for future work:

•

Is there an efficient
deterministic
algorithm for the LPS problem in the MPC model?

•

Is there an efficient algorithm for the LPS problem in the MPC model
for any

\epsilon\in(0,1)
?
