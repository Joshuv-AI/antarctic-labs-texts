A multi-layer airport security framework using YOLO-based X-ray detection, video anomaly analysis, IoT sensor monitoring and blockchain logging
Authors: T. Shobha, R. Rashmi, L. R. Chaitanya, C. V. Medhini, R. J. Chandana, Sumukh P. Gowda
Published: 2026

ABSTRACT
Security screening systems require reliable and real-time detection of threats in complex X-ray imagery and surrounding environments. Manual inspection of baggage images is often a overhead due to operator fatigue, cluttered objects and overlapping items. Recent advances in deep learning and intelligent sensing technologies provide opportunities for automated threat detection in such environments. In this work, we propose a multi-layer airport security framework integrating three complementary detection modules: YOLO-based X-ray prohibited-item detection, video anomaly detection for behavioural monitoring, and IoT-based environmental anomaly sensing. In addition to this, a blockchain-secured logging mechanism is incorporated to ensure tamper-proof storage of security events. The X-ray detection module employs YOLOv11-s trained on the CLCXray dataset to identify prohibited items in baggage. Behavioural anomalies in surveillance footage are detected using a 3D-CNN autoencoder, while environmental anomalies from IoT sensors are identified using an LSTM autoencoder. Outputs from these modules are integrated using a unified multimodal risk scoring mechanism. Experimental results demonstrate that YOLOv11-s achieves mAP\documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$_{50-95}$$\end{document} of 78.91% and YOLOv8-s achieves mAP\documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$_{50-95}$$\end{document} of 78.49% with strong detection reliability across varying confidence thresholds, both the models have comparable performance and either of it could be chosen. The IoT anomaly detection produces reconstruction errors in the range of 0.019–0.03, with anomalies identified when the error exceeds a threshold of 0.041 and for video anomaly its 0.0040–0.00685. The proposed multimodal fusion module achieves ROC-AUC score of 0.864, which demonstrated an improved detection reliability compared to individual modalities. Also, the framework achieves an average detection latency of 0.014 ms per event, while the blockchain logging module records security events with an average latency of 0.179 ms and supports up to 5723.47 transactions per second. These results demonstrate that the proposed framework provides an effective, scalable, and secure solution for automated airport security monitoring systems.

Introduction

Airports are critical infrastructures.Its an area where huge passengers and high baggage throughput creates security challenges. Traditional screening systems rely heavily on human operators like analysing X-ray baggage scans and monitoring surveillance feeds, which can lead to operator fatigue, oversight, and delayed threat detection. Recent advances in artificial intelligence and computer vision have enabled automated inspection systems which are capable of identifying suspicious objects and abnormal behaviour in real time1–3.Deep learning-based object detection techniques have demonstrated strong performance in detecting prohibited items within X-ray security imagery. Datasets such as SIXray and CLCXray provide large-scale annotated benchmarks for evaluating threat detection models under complex occlusion and clutter conditions4,5. Modern object detectors such as Faster R-CNN, SSD, and YOLO variants is widely adopted for automated baggage screening due to their ability to detect multiple objects together with high accuracy6,7. Among these, YOLO-based detectors are better in terms of detection accuracy and inference speed, enabling real-time deployment in security screening systems8.In addition to object detection, surveillance video analysis plays an important role in identifying behavioural anomalies such as suspicious movement patterns, abandoned baggage, or loitering in restricted area9,10. Public datasets such as Avenue dataset provide frame-level anomaly annotations that enable evaluation of video anomaly detection models in crowded environments11and environmental sensor data from IoT networks can recognize unusual fluctuations in physical conditions such as temperature, humidity, which are of serious concern12,13.However, existing airport security solutions often operate these modalities independently. Object detection, surveillance monitoring, and IoT sensor analytics are processed in separate systems,which limits their ability to capture complex multi-modal threat patterns3,14. Furthermore, security event records must be stored securely to prevent tampering or unauthorized modifications. Blockchain-based logging frameworks provide immutable event storage and traceability for security monitoring systems15–17,37.

Motivated by these challenges, this work proposes a unified multi-layer anomaly detection framework for airport security that integrates X-ray baggage inspection, surveillance video anomaly detection, and IoT sensor monitoring with a secure blockchain-based logging architecture. The proposed framework employs a YOLOv11-based detector for prohibited item detection, combined with video anomaly scoring and IoT anomaly monitoring. Unlike conventional fusion approaches, the system performs multi-modal decision analysis where fusion-based anomaly detection is supplemented by independent prohibited item detection logic to ensure critical threats are not underestimated.The proposed system is evaluated using the CLCXray dataset for prohibited item detection and the Avenue dataset for video anomaly detection5,11. Experimental results demonstrate that the YOLOv11-s model achieves stronger detection performance while maintaining real-time inference capability. Also, the integrated framework achieves an ROC-AUC score of 0.73 for multimodal anomaly detection while maintaining low latency and efficient blockchain-based event logging (Table 1).

Related work

Recent studies have explored automated airport security systems using deep learning and multi-modal sensing1,3. Convolutional neural networks have been widely applied to detect prohibited items in X-ray baggage scans, with datasets such as SIXray and CLCXray by enabling large-scale evaluation of detection models under occlusion conditions4,5,8. Many object detection architectures including Faster R-CNN, SSD, and YOLO-based models have been investigated for security screening6,7,1836. Also, video anomaly detection techniques using convolutional autoencoders, LSTM networks, and transformer-based architectures have demonstrated good results for surveillance monitoring2,9,10.IoT-based monitoring systems have been proposed to detect abnormal sensor activity inside smart surveillance infrastructures12,13. More recently, blockchain-based logging frameworks have been explored that ensures secure and tamper-resistant event storage in distributed detection systems15–17. Research gap

Eventhough significant progress has been made in individual areas such as X-ray prohibited item detection, video anomaly detection and IoT-based monitoring2,8,12, most of the existing approaches focuses on a single modality. Real-world airport security environments require integrated monitoring frameworks that combines multiple data sources to improve detection reliability and situational awareness3,14. Many existing systems lack secure mechanisms for storing anomaly events and maintaining tamper-proof audit trails15,16. The proposed framework addresses all of these limitations by integrating X-ray prohibited item detection, video behavioural anomaly detection and IoT-based environmental monitoring within a unified multimodal architecture. In addition, a blockchain-based logging is added to ensure secure and immutable storage of anomaly events, thereby providing a comprehensive and reliable solution for intelligent airport security monitoring15,17.

Visualisation

The visualisation outputs demonstrate the effectiveness of the proposed multi-layer security system across X-ray, video and IoT modalities. For X-ray analysis, YOLOv11-s consistently identifies prohibited items such as knives, blades, scissors, bottles, cans and daggers with high-confidence bounding boxes, even in heavily cluttered bags with overlapping objects5,8. The predicted regions align closely with object boundaries, by indicating strong spatial localisation performance. YOLOv8-s produces similar detections, but with slightly less bounding-box stability in densely occluded scenes, strengthening the advantage of YOLOv11-s on complex baggage imagery6.Video anomalies further confirm the system’s ability to detect unappropriate human behaviour. The Conv3D autoencoder maintains a low reconstruction error for normal activities such as walking or standing, while shows visibly higher reconstruction error for abnormal events including running, falling and restricted-zone entry2,9.IoT anomaly visualisations show clear deviations in sensor patterns, where temperature, vibration or humidity spikes are easily distinguishable from baseline readings12,13. Together, these qualitative results supports the quantitative metrics and demonstrates that the proposed framework can accurately detect suspicious items, behaviours and environmental conditions in realistic screening environments (Figs. 2, 3, 4, 5).

Discussion

The results demonstrate that the proposed multi-layer framework effectively integrates various security modalities to improve detection reliability. The YOLOv11-s model shows a slight but consistent improvement over YOLOv8-s, that indicates an enhanced feature representation and localization stability.The IoT anomaly detection model achieved an ROC–AUC of 1.0, showing a clear separation between normal and anomalous sensor readings. This is primarily due to the controlled generation of synthetic anomalies, which introduces distinct deviations from normal behaviour. However, real-world IoT data may present more complex and overlapping patterns.The video anomaly detection module captures spatio-temporal deviations, which demonstrates its capability to detect abnormal behavioural patterns without requirement of any labelled anomaly data. A key contribution of this work is the multimodal fusion mechanism, which combines video and IoT anomaly scores to produce an unified risk assessment. The fusion model achieves an ROC–AUC of 0.73, which shows an improved robustness compared to individual modalities by making use of complementary information.Compared to any existing single-modality approaches such as X-ray detection or video-based anomaly detection2,8, the proposed framework provides a more stronger and coordinated security solution through integrated decision-level analysis.The blockchain-based logging mechanism further enhances system reliability by ensuring tamper-resistant storage of detection events while maintaining low latency.Despite these advantages, the framework is limited by the use of synthetic IoT data. Future work must focus on real-world deployment, adaptive fusion strategies, and extending detection capabilities to additional threat categories such as drugs,inorganic powders.

Methodology

The proposed airport security monitoring framework integrates multiple anomaly detection modules that analyses multiple security data sources. The system combines prohibited item detection from X-ray baggage images, behavioural anomaly detection from surveillance video streams, and anomaly monitoring from IoT sensor data2,8,12. Each module independently processes its corresponding data modality and generates anomaly scores representing the likelihood of abnormal events. These anomaly scores are integrated using a weighted fusion mechanism that estimates an overall risk score. The resulting events are recorded using a blockchain-based secure logging framework that ensures tamper-resistant storage of security monitoring data15,16.

System framework

The proposed architecture consists of four major modules: prohibited item detection using X-ray imagery,behavioural anomaly detection from surveillance videos,IoT sensor anomaly detection, andblockchain-based event logging.Figure 6 illustrates the interaction between these components. The prohibited item detection module analyses X-ray baggage images using a YOLOv11-based object detection model trained on CLCXray dataset5.The model identifies threat objects such as knives,gun,blade,cans, and other hazardous items inside baggage scans and produces detection confidence scores representing the likelihood of prohibited objects. The video anomaly detection module analyses surveillance video sequences obtained from the Avenue dataset11. Video frames are extracted from surveillance streams and analysed to compute anomaly scores that represent deviations from normal behavioural patterns.The IoT monitoring module analyses sensor readingsthat represents environmental conditions within airport infrastructure. IoT-based monitoring systems are increasingly used for infrastructure security and anomaly detection due to their ability to continuously monitor environmental conditions12,13,24. Since publicly available airport IoT datasets are limited because of security restrictions, synthetic sensor data are generated using Python-based simulation techniques28,29. These simulated datasets represent sensor measurements such as temperature readings,humidity and vibration. Each detection module generates anomaly events containing information such as anomaly type, anomaly score, timestamp, and detection source. These events are subsequently integrated and analysed by the decision module to determine the final system risk state.

Datasets

The proposed airport security monitoring framework utilizes three datasets corresponding to different security monitoring modalities: X-ray baggage imagery, surveillance video streams, and IoT sensor data. Each dataset represents a different layer of the airport security monitoring pipeline. The prohibited item detection module uses the CLCXray dataset5, which contains annotated X-ray baggage images collected for airport security screening research. For the CLCXray dataset, the original annotations were provided in COCO-style JSON format. To enable training using the YOLO detection framework, the annotations were converted into YOLO label format. In this format, each object instance is represented by a class identifier and normalized bounding box coordinates corresponding to the object center location, width, and height relative to the image dimensions. After annotation conversion, the dataset was organized into a YOLO training directory structure containing separate folders for images and label files. This dataset contains surveillance video sequences with frame-level annotations indicating whether observed behaviour corresponds to normal activity or abnormal events. Pre-processing

For the X-ray baggage dataset, all images were resized to \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$640 \times 640$$\end{document} pixels to match the input requirements of the YOLO-based object detection model6after converting to YOLO-labels. This resizing step ensures there are consistent spatial dimensions across all training and inference samples while preserving all the relevant visual information that is required for object detection. For the surveillance video dataset, video sequences from the Avenue dataset were processed using OpenCV to extract individual frames from the recorded videos11. Each extracted frame was resized to \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$224 \times 224$$\end{document} pixels at the rate of 5 fps to reduce computational complexity while preserving spatial features that are required for anomaly detection2,9. The synthetic IoT dataset contains environmental sensor readings consisting of timestamp, temperature, humidity, and vibration measurements. As the dataset contains only three sensor attributes,the sensor readings were directly used as input for anomaly detection without applying additional preprocessing operations such as feature normalization or dimensionality reduction12.

Models

The proposed airport security monitoring system employs multiple machine learning models to analyse multiple data modalities including X-ray baggage images, surveillance video streams, and IoT sensor readings2,8,12. Each model is designed to process a specific data source and generate anomaly indicators which are later used by the multimodal monitoring framework.

Prohibited item detection model

YOLOv11-S employs a multi-stage architecture having a CSP-based backbone, a BiFPN neck, and a decoupled detection head32. The backbone extracts hierarchical features using convolutional and CSP blocks with efficient gradient flow. The BiFPN aggregates multi-scale features that enhances detection of small and overlapping X-ray objects8. The anchor-free decoupled head predicts object classes and bounding boxes directly, by enabling efficient and accurate real-time detection7.

Fig. 7YOLOv11 network architecture illustrating backbone, neck, and head components used for object detection32.

YOLOv11 network architecture illustrating backbone, neck, and head components used for object detection32.

The prohibited item detection module employs a YOLOv11-based object detection model. YOLO (You Only Look Once) is a single-stage object detection framework which is capable of simultaneously performing object localization and classification within a single forward pass through a convolutional neural network18. Due to its high detection speed and accuracy (Fig. 7), YOLO-based detectors are widely used for real-time security inspection applications6,8. The model was trained using the CLCXray dataset5, which contains annotated X-ray baggage images4. Since the original annotations were provided in COCO format, they were converted into YOLO label format prior to training. Training was performed using the Ultralytics YOLO training framework with an input image resolution of \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$640 \times 640$$\end{document}33. The YOLOv8-s model was fine-tuned using transfer learning from pretrained weights and trained for a total of 160 epochs, consisting of an initial training phase of 80 epochs followed by an additional fine-tuning stage of 80 epochs whereas YOLOv11-s was trained for 50 epochs6. During training, the model learns the spatial features that allows it to detect prohibited objects such as knives, blades, scissors, and other hazardous items that are present in baggage scans8. The trained YOLO detection model predicts bounding box coordinates, object class labels, and confidence scores for each detected object.

Video anomaly detection model

The video anomaly detector is implemented using a 3D-CNN autoencoder that captures spatio-temporal patterns in surveillance data2,9,38. The encoder compresses video volumes by using a stacked 3D convolutions to learn motion and appearance features. The decoder reconstructs the input sequence, and deviations between input and reconstruction indicate abnormal behaviour. Reconstruction error is used as the anomaly score, enabling efficient real-time detection of unusual activities2. Behavioural anomaly detection in surveillance footage is performed using video data obtained from the Avenue dataset11. Video anomaly detection models analyse temporal patterns in surveillance frames to identify deviations from normal behavioural patterns that occur within monitored environments2,9. In the proposed framework, surveillance videos are first processed using OpenCV to extract individual frames from the recorded video sequences. Each frame is resized to \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$224 \times 224$$\end{document} pixels to reduce computational complexity while preserving important spatial features required for anomaly detection2. The video anomaly detection module processes the extracted frames and computes anomaly scores that represent deviations from normal motion behaviour9. Higher anomaly scores correspond to abnormal events such as irregular motion trajectories,loitering in and around restricted zones or any unusual activities occurring within the surveillance scene (Figs. 8, 9).

IoT sensor anomaly detection model

The IoT anomaly detection module employs an LSTM autoencoder to model temporal dependencies in sensor data12,13. The encoder compresses sequential sensor readings into a latent representation by capturing normal operating behaviour. The decoder reconstructs this sequence, and deviations between input and reconstruction indicate anomalies. Reconstruction error is used as the anomaly score, enabling effective detection of abnormal temporal patterns in IoT sensor streams12,35.

Fig. 9LSTM autoencoder architecture showing encoder, bottleneck, and decoder generating reconstructed sequences35.

LSTM autoencoder architecture showing encoder, bottleneck, and decoder generating reconstructed sequences35.

Environmental monitoring within airport infrastructure is performed using IoT sensor readings representing temperature, humidity, and vibration measurements12,13,24. IoT-based anomaly detection systems analyse the sensor signals to identify abnormal environmental behaviour or equipment malfunction13. Since airport IoT datasets are limited due to privacy and security constraints, a synthetic IoT dataset was generated in this work to simulate environmental monitoring conditions28,29. The dataset contains timestamped sensor readings that represents temperature, humidity, and vibration measurements collected over time. The IoT anomaly detection module analyses these sensor signals to identify deviations from normal operational behaviour12. Variations in sensor readings beyond the expected patterns indicate potential abnormal environmental conditions within the monitored infrastructure.

Fusion weight computation

To integrate anomaly indicators obtained from multiple monitoring modules, the proposed framework employs a weighted multimodal fusion mechanism3. This fusion process combines anomaly scores generated from the video anomaly detection module, IoT sensor monitoring module, and X-ray object detection module to produce a unified behavioural risk score.

Experimental setup and evaluation metrics

All experiments were conducted on a GPU-enabled system using Python and the Ultralytics framework for YOLO training33. The CLCXray dataset was used as provided by the original authors, which includes predefined training, validation, and testing splits4,5.

Two YOLO model variants were evaluated for prohibited item detection. YOLOv8-s was trained using a two-stage strategy. In the first stage, the model was trained for 80 epochs using pretrained COCO weights (Fig. 10). In the second stage, the best checkpoint from the first stage was used for further training over an additional 80 epochs to refine feature representations. YOLOv11-s was trained for 50 epochs using an input resolution of \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$640 \times 640$$\end{document} pixels and a batch size of 16. Standard YOLO data augmentation techniques were applied to improve performance of the model8.

For behavioural monitoring, the video anomaly detection module processes surveillance frames that are extracted from the Avenue dataset at 5 frames per second (FPS). The IoT anomaly detection module analyses environmental sensor readings consisting of temperature, humidity, and vibration measurements. The video analysis model uses a Conv3D autoencoder, while the IoT subsystem uses an LSTM autoencoder to model normal patterns.

For multimodal evaluation, anomaly scores generated from the video and IoT subsystems were normalized and fused using the weighted strategy defined in Eq. (1)–(3). The final fused score is used to detect anomalies

To assess detection performance, several standard evaluation metrics were employed. Computational complexity

The computational complexity of the proposed monitoring framework is given by its individual components. The prohibited item detection module, based on the YOLO architecture, is the most computationally intensive part, with complexity approximately \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$O(N^2 \cdot K^2 \cdot C)$$\end{document} for an input image of size \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$N \times N$$\end{document}, where K denotes kernel size and C denotes the number of filters6,18. The video anomaly detection module processes the frames sequentially, with a complexity proportional to the number of processed frames, i.e., O(F) per time step2. The IoT anomaly detection module operates on low-dimensional sensor data, resulting in a linear complexity O(n) for n observations12. The multimodal fusion stage involves a weighted linear combination of the anomaly scores,that yeilds a constant time complexity O(1)3. The blockchain logging component performs SHA-256 hashing with complexity O(m), where m is the size of the event record15. Overall, the framework is suitable for real-time deployment, as computational cost is dominated by the YOLO-based detection module, while the remaining components introduces a minimal overhead.

Conclusion

This work proposes a unified multi-layer airport security monitoring framework that integrates YOLOv11-s based X-ray prohibited-item detection, IoT-based environmental anomaly monitoring, video behavioural analysis, and blockchain-secured event logging within a single architecture . The proposed system demonstrates a strong performance across all the modalities, with YOLOv11-s achieving high detection accuracy on the CLCXray dataset , while the IoT LSTM-autoencoder and Conv3D-autoencoder effectively distinguishes abnormal patterns through reconstruction-error separation. A key contribution of this work is the multimodal fusion mechanism that combines behavioural and environmental anomaly indicators to generate a unified risk score,that improves detection robustness compared to individual subsystems . By integrating complementary security signals and secure blockchain-based event recording, this framework provides a more reliable and tamper-resistant monitoring solution than traditional single-modality approaches. Future work may extend the framework to additional threat categories such as concealed inorganic powders and hazardous materials, further enhancing automated airport security screening systems.
