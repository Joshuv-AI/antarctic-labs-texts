Formal Models and Convergence Analysis for Context-Aware Security Verification
Ayush Chaudhary

Abstract
We present a formal framework for context-aware security verification that establishes provable guarantees for ML-enhanced adaptive systems. We introduce context-completeness —a new security property—and prove: (1) sample complexity bounds showing when adaptive verification succeeds, (2) information-theoretic limits relating context richness to detection capability, (3) convergence guarantees for ML-based payload generators, and (4) compositional soundness bounds. We further provide a formal separation between static context-blind verifiers and context-aware adaptive verifiers: for a natural family of targets, any static verifier with finite payload budget achieves completeness at most α \alpha , while a context-aware verifier with sufficient information achieves completeness > α >\alpha . We validate our theoretical predictions through controlled experiments on 97,224 exploit samples, demonstrating: detection accuracy improving from 58% to 69.93% with dataset growth, success probability increasing from 51% to 82% with context enrichment, training loss converging at O ⁡ ( 1 / T ) O(1/\sqrt{T}) rate, and false positive rate (10.19%) within theoretical bounds (12%). Our results show that theoretically-grounded adaptive verification achieves provable improvements over static approaches under stated assumptions while maintaining soundness guarantees.

. While effective for known vulnerability patterns, static approaches face fundamental theoretical limitations

We integrate large language models (LLMs) as learned payload generators that condition on extracted context, proving convergence and soundness guarantees for this ML-enhanced verification pipeline.

III-A

Mathematical Preliminaries

Let
(\Omega,\mathcal{F},P)

\mathcal{W}=\{w_{1},\ldots,w_{k}\}

\mathcal{X}

Notation

\log

h_{b}(p)=-p\log p-(1-p)\log(1-p)
is the binary entropy function.

III-B

Verification Systems

Definition 1 (Security Verification System).
A security verification system is a tuple
\mathcal{V}=(\Sigma,\mathcal{P},V,\phi)
where:

•

\Sigma
= set of system states (e.g., web application configurations)

•

\mathcal{P}
= set of verification payloads (e.g., test inputs)

•

V:\Sigma\times\mathcal{P}\rightarrow\{0,1\}
= verification function (returns 1 if payload exposes vulnerability)

•

\phi:\Sigma\rightarrow\{0,1\}
= ground-truth security property (0 = vulnerable)

Running Example (SQL Injection).

•

\sigma\in\Sigma
: the Flask login endpoint from §

•

Definition 2 (Context-Aware Verification System).
A context-aware system extends

p_{t}\sim G\big(C(\sigma),w;\mathcal{H}_{t}\big)

III-C

Context-Completeness: A New Security Property

Traditional completeness (no false positives) is insufficient for adaptive systems. We introduce a stronger notion:

Definition 3 (Context-Completeness).
A context-aware system
\mathcal{C}
is
context-complete
for vulnerability class
w\in\mathcal{W}
if:

\forall\sigma\in\Sigma:\phi_{w}(\sigma)=0\Rightarrow\exists p\in G(C(\sigma),w):V_{w}(\sigma,p)=1

Intuition
: If a vulnerability of class
w
is present, the context-aware generator
G
will produce at least one payload
p
that successfully exposes it.

Definition 4 (
\epsilon
-Context-Completeness).
We say
\mathcal{C}
is
\epsilon
-context-complete if:

P\left(\exists p\in G(C(\sigma),w):V_{w}(\sigma,p)=1\mid\phi_{w}(\sigma)=0\right)\geq 1-\epsilon

This probabilistic version accounts for randomness in context extraction and payload generation.

Running Example.
For SQL injection, our system is
\epsilon
-context-complete if, given any SQL-injectable endpoint, it generates a successful exploit payload with probability
\geq 1-\epsilon
.

III-D

Adaptive Verification Process

Real systems improve over time through learning. We model this formally:

Definition 5 (Adaptive Process).
An adaptive verification process is a sequence
\{(\mathcal{C}_{t},\theta_{t})\}_{t=0}^{T}
where
\theta_{t}\in\Theta
are learned parameters (e.g., LLM weights).

Example
:
\theta_{t}
could be low-rank adapter weights in a fine-tuned Code Llama model, updated via gradient descent on a security-focused loss.

III-E

Relationship to Existing Security Formalisms

Our framework connects to established foundations:

Hyperproperties
[
15
]
:
Context-completeness is a hyperproperty—it quantifies over sets of execution traces. For class
w
, the property holds when sufficient context enables detection across all vulnerable states.

Noninterference
[
16
]
:
Traditional noninterference forbids information flow from high to low security levels. Our framework permits controlled flow: context information (which may include security-relevant signals)
guides
adaptive verification while maintaining soundness bounds.

Abstract Interpretation
[
2
]
:
Abstract interpretation achieves soundness via over-approximation. Our approach is dual: we achieve context-completeness via adaptive under-approximation, with provable convergence to ground truth as context information increases.

Theoretical Analysis

We establish four key results: sample complexity bounds, information-theoretic limits, convergence guarantees, and soundness preservation. Proof sketches appear here; full proofs are in Appendix
A
.

IV-A

Sample Complexity for Learning Context-Complete Verifiers

Theorem 1 (Sample Complexity Bound).

Let
\mathcal{H}
be a hypothesis class of context-aware payload generators with VC-dimension
d_{VC}
. For any
\epsilon,\delta\in(0,1)
, if training set size satisfies:

n\geq\frac{8d_{VC}+8\log(2/\delta)}{\epsilon^{2}}

then with probability
\geq 1-\delta
, the empirical risk minimizer
\hat{h}
achieves
\epsilon
-context-completeness:
R(\hat{h})\leq\epsilon
.

Intuition:
This bound tells us how many vulnerability examples we need to train a context-aware payload generator. For example, with
d_{VC}=1000
(representing generator complexity),
\epsilon=0.1
(10% error tolerance), and
\delta=0.05
(95% confidence), we need:

n\geq\frac{8(1000)+8\log(40)}{0.01}\approx 804,000\text{ samples}

Our dataset of 95,000 samples corresponds to accepting higher
\epsilon
or modeling lower effective VC-dimension through techniques like LoRA (low-rank adaptation).

Proof Sketch:
Define loss
\ell(h(x),y)=\mathbf{1}[h(x)\neq y]
where
y
indicates vulnerability presence. Let
R(h)=\mathbb{E}[\ell(h(X),Y)]
be the true risk and
\hat{R}_{n}(h)=\frac{1}{n}\sum_{i}\ell(h(x_{i}),y_{i})
be the empirical risk.

By VC theory
[
17
]
, uniform convergence holds:
\sup_{h\in\mathcal{H}}|R(h)-\hat{R}_{n}(h)|\leq\epsilon
with probability
\geq 1-\delta
when the sample size satisfies the bound. The empirical risk minimizer
\hat{h}
then satisfies
R(\hat{h})\leq\hat{R}_{n}(\hat{h})+\epsilon\leq R(h^{*})+\epsilon
where
h^{*}
is the optimal hypothesis. In the realizable case (
R(h^{*})=0
), we get
R(\hat{h})\leq\epsilon
.
\square

Worked Example (SQL Injection Generator):
Suppose we want to learn a generator for SQL injection payloads that works across different database types (MySQL, PostgreSQL, Oracle, MSSQL). Each database has
\approx 50
unique exploitation patterns. If we model the generator as a decision tree of depth
d=10
(choosing syntax based on context features), then
d_{VC}\approx 10\cdot\log_{2}(200)\approx 80
. For
\epsilon=0.2
, we need:

n\geq\frac{8(80)+8\log(40)}{0.04}\approx 17,000\text{ SQL injection examples}

Our dataset contains 16,707 SQL injection samples (Table
I
), which is close to the theoretical bound in this setup and aligns with the observed empirical performance on SQL injection.

IV-B

Information-Theoretic Limits

Theorem 2 (Fano Lower Bound for Context-Based Detection).

For
|\mathcal{W}|\geq 2
vulnerability classes, any estimator
\hat{W}
of vulnerability type
W
based on context
X
has error probability:

P_{e}\geq 1-\frac{I(W;X)+1}{\log_{2}|\mathcal{W}|}

where
I(W;X)
is the mutual information between vulnerability type and context.

Intuition:
This fundamental bound shows that detection accuracy is limited by how much information the context reveals about the vulnerability. If context is uninformative (
I(W;X)\approx 0
), error is high. If context fully determines vulnerability type (
I(W;X)=\log_{2}|\mathcal{W}|
), perfect detection is possible.

Proof Sketch:
Fano’s inequality
[
18
]
states:
H(W|\hat{W})\leq h_{b}(P_{e})+P_{e}\log_{2}(|\mathcal{W}|-1)
. Since
H(W|\hat{W})\geq H(W|X)
(data processing), and using
I(W;X)=H(W)-H(W|X)
with
h_{b}(P_{e})\leq 1
, we rearrange to get the bound. For uniform
W
,
H(W)=\log_{2}|\mathcal{W}|
, yielding the stated result.
\square

Worked Example (Multi-Class Vulnerability Detection):

Consider detecting among
|\mathcal{W}|=9
vulnerability classes (SQLi, XSS, RCE, XXE, etc.). Suppose context extraction
C
provides:

•

Rich context
: Full tech stack, framework version, error patterns
\Rightarrow I(W;X)\approx 2.5
bits

•

Poor context
: Only HTTP status codes
\Rightarrow I(W;X)\approx 0.5
bits

Theorem
IV-B
predicts:

\displaystyle P_{e}^{\text{rich}}

\displaystyle\geq 1-\frac{2.5+1}{3.17}=1-1.10\approx 0\%\text{ (perfect possible)}

\displaystyle P_{e}^{\text{poor}}

\displaystyle\geq 1-\frac{0.5+1}{3.17}=52.7\%\text{ error}

This explains why context-rich extraction is critical for multi-class detection.

IV-C

Convergence Guarantees for Adaptive Systems

Theorem 3 (Convergence Rate).

Assume the security verification loss
L(\theta)=\mathbb{E}_{(s,w)\sim\mathcal{D}}[\ell(\phi(s),\max_{p\in G_{\theta}(C(s))}V(s,p))]
is
L_{lip}
-Lipschitz continuous. Under SGD with learning rate
\eta_{t}=\eta_{0}/\sqrt{t}
, the adaptive process converges:

\mathbb{E}[L(\theta_{T})]-L(\theta^{*})\leq\frac{C}{\sqrt{T}}

for constant
C=L_{lip}\|\theta_{0}-\theta^{*}\|+\sigma^{2}
.

Intuition:
Training converges at rate
O(1/\sqrt{T})
. To halve the error, we need
4\times
more iterations.

Proof Sketch:
Standard SGD analysis
[
19
]
. Lipschitz continuity ensures gradients are bounded. With
\eta_{t}=\eta_{0}/\sqrt{t}
, we balance optimization progress against gradient noise. Optimizing
\eta_{0}
yields the
C/\sqrt{T}
rate.
\square

Worked Example (Training Our LLM):
We train for
T=9,060
steps. Theorem
IV-C
predicts:

\mathbb{E}[L(\theta_{9060})]-L(\theta^{*})\leq\frac{C}{\sqrt{9060}}\approx 0.0105\cdot C

Empirically, we observe loss decreasing from 2.847 to 0.923 (Figure
2(b)
), consistent with
O(1/\sqrt{T})
convergence when plotted on log-log axes.

IV-D

Soundness Preservation Under Composition

Definition 6 (Verification Soundness).
System
\mathcal{C}
is
\epsilon
-sound if:

P(V(s,p)=1\land\phi(s)=1\mid V(s,p)=1)\geq 1-\epsilon

(i.e., false positive rate
\leq\epsilon
).

Theorem 4 (Compositional Soundness).

Let
\mathcal{C}=(\Sigma,C,G,V,\phi)
where:

•

Context extraction
C
fails (loses security info) with probability
\delta_{C}

•

Payload generator
G
produces suboptimal payloads with probability
\delta_{G}

•

Verifier
V
has false positive rate
\epsilon_{V}

Then the composed system has false positive rate
\leq\epsilon_{V}+\delta_{C}+\delta_{G}
.

Proof Sketch:
Let
E_{C},E_{G},E_{V}
be the failure events for each component. A false positive occurs if
E_{C}\cup E_{G}\cup E_{V}
happens. By Boole’s inequality:
P(E_{C}\cup E_{G}\cup E_{V})\leq P(E_{C})+P(E_{G})+P(E_{V})=\delta_{C}+\delta_{G}+\epsilon_{V}
.
\square

Worked Example (Our System):

•

\epsilon_{V}=0.05
(verifier checks for genuine delay/error)

•

\delta_{C}=0.03
(context extraction occasionally misses framework)

•

\delta_{G}=0.07
(LLM sometimes generates invalid syntax)

Theorem
IV-D
predicts FPR
\leq 0.15
(15%). Empirically, we observe 10-15% FPR (§
VI
), confirming the bound is tight.

IV-E

Static vs Adaptive: A Formal Separation

We now formalize the advantage of context-aware verification over static, context-blind verification under a natural payload budget.

Construction (Selector Family).
For integer
n\geq 2
, define a family of targets
\{\sigma_{c}\}_{c\in[n]}
with a single vulnerable predicate
w
and payload universe
\{p_{1},\ldots,p_{n}\}
. Each target
\sigma_{c}
accepts exactly one payload:
V(\sigma_{c},p)=1
iff
p=p_{c}
. The context
C(\sigma_{c})
reveals
c
up to noise.

Theorem 6 (Separation under Budget).

Fix budget
B<n
. For any static verifier
\mathcal{V}_{s}
independent of
C
, the worst-case completeness over the selector family satisfies
\sup_{\Pi}\inf_{c\in[n]}P(\exists t\leq B:V(\sigma_{c},p_{t})=1)\leq B/n
. In contrast, any adaptive verifier
\mathcal{V}_{a}
with
I(W;C)\geq\log_{2}n-\xi
achieves completeness
\geq 1-\delta(\xi)
by selecting
p_{c}
with probability
\geq 1-\delta(\xi)
; in the noiseless case (
\xi=0
), completeness is 1 with a single query.

Proof Sketch:
Static: Without
C
, success over
\{p_{i}\}
is a uniform guessing problem; with
B
distinct trials, success probability is at most
B/n
. Adaptive: If
C
identifies
c
(noiseless), choose
p_{c}
and succeed with a single try. With noise parameterized via
I(W;C)
, a decoder
\hat{c}(C)
succeeds with error
\leq\delta(\xi)
by Fano; choose
p_{\hat{c}}
.
\square

This establishes a clean, assumption-minimal separation: context-aware verification strictly dominates static verification for families where exploitation requires
matching
payloads to latent system variants.

IV-F

Upper Bound on Achievable Completeness

Theorem 5 (Fundamental Limit).

For any adaptive verification system
\mathcal{A}
, completeness
\gamma_{\mathcal{A}}=1-P_{e}
satisfies:

\gamma_{\mathcal{A}}\leq\frac{I(W;X)+1}{\log_{2}|\mathcal{W}|}

This follows directly from Theorem
IV-B
and shows that perfect completeness requires context to fully determine vulnerability presence.

\mathcal{Q}

We instantiate

]

Let
\mathcal{F}_{L,d}
be the class of

-layer networks with width

d\geq 64|\mathcal{W}|^{2}\epsilon^{-2}\log(L|\mathcal{W}|/\epsilon)

Proof Sketch:
Follows from universal approximation for deep ReLU networks
[
20
]
. Width requirement scales as
|\mathcal{W}|^{2}\epsilon^{-2}
for multi-class classification.
\square

Verification for Our Setup:
With

(effective width),

Since

VIII
Limitations and Future Work

VIII-A

Assumptions

Our theoretical results rely on:

•

Lipschitz continuity
of loss
L(\theta)
: Holds for common losses (cross-entropy, hinge) under bounded weights; enforced via gradient clipping

•

VC-dimension bounds
: Estimated for our architecture; tighter characterization via PAC-Bayes bounds is future work

•

Context extraction fidelity
: We assume
C
preserves security-relevant information with bounded failure probability; adversarial evasion of context extraction is not addressed

VIII-B

Assumptions and Threat Model

We consider black-box verification with query access and a finite payload budget. Static verifiers select payloads independently of
C
; adaptive verifiers may condition on
C
and history. Our separation theorem (Theorem
IV-E
) applies when exploitation requires matching payloads to latent system variants. We do not assume access to source code or internal error logs;
C
is derived from observable behavior and headers.

VIII-C

Scope

Our experiments focus on web application vulnerabilities. Extension to:

•

Binary exploitation (memory safety bugs)

•

Cryptographic vulnerabilities

•

Protocol-level attacks

requires domain-specific context extractors and is left for future work.

Tighter information-theoretic bounds

Mechanized proofs

Appendix A
Complete Proofs

A-A

Proof of Theorem
IV-A
(Sample Complexity)

Define the binary loss
\ell(h(x),y)=\mathbf{1}[h(x)\neq y]
where
y\in\{0,1\}
indicates vulnerability presence. Let
\hat{R}_{n}(h)=\frac{1}{n}\sum_{i=1}^{n}\ell(h(x_{i}),y_{i})
be the empirical risk and
R(h)=\mathbb{E}_{(X,Y)\sim\mathcal{D}}[\ell(h(X),Y)]
be the true risk.

By the fundamental theorem of statistical learning theory
[
17
]
, for a hypothesis class
\mathcal{H}
with VC-dimension
d_{VC}
, we have:

P\left(\sup_{h\in\mathcal{H}}|R(h)-\hat{R}_{n}(h)|>\epsilon\right)\leq 4\mathcal{H}(2n)e^{-n\epsilon^{2}/8}

where
\mathcal{H}(m)
is the growth function. By Sauer’s lemma,
\mathcal{H}(m)\leq(em/d_{VC})^{d_{VC}}
.

For
n\geq\frac{8d_{VC}+8\log(2/\delta)}{\epsilon^{2}}
, we have:

\displaystyle 4\mathcal{H}(2n)e^{-n\epsilon^{2}/8}

\displaystyle\leq 4\left(\frac{2en}{d_{VC}}\right)^{d_{VC}}e^{-n\epsilon^{2}/8}

\displaystyle\leq 4e^{d_{VC}\log(2en/d_{VC})-n\epsilon^{2}/8}

Substituting
n\geq\frac{8d_{VC}}{\epsilon^{2}}
:

d_{VC}\log(2en/d_{VC})-n\epsilon^{2}/8\leq d_{VC}\log(16e/\epsilon^{2})-d_{VC}\leq-\log(2/\delta)

Thus:
P(\sup_{h\in\mathcal{H}}|R(h)-\hat{R}_{n}(h)|>\epsilon)\leq\delta
.

For the empirical risk minimizer
\hat{h}=\arg\min_{h\in\mathcal{H}}\hat{R}_{n}(h)
:

R(\hat{h})\leq\hat{R}_{n}(\hat{h})+\epsilon\leq\hat{R}_{n}(h^{*})+\epsilon

where
h^{*}
is the best hypothesis in
\mathcal{H}
. In the realizable case (
\exists h^{*}\in\mathcal{H}:R(h^{*})=0
), we have
\hat{R}_{n}(h^{*})\to 0
as
n\to\infty
, so:

R(\hat{h})\leq\epsilon

with probability
\geq 1-\delta
, establishing
\epsilon
-context-completeness.
\square

A-B

Proof of Theorem
IV-B
(Information-Theoretic Bound)

By Fano’s inequality
[
18
]
, for any estimator
\hat{W}
of random variable
W
based on observation
X
:

H(W|\hat{W})\leq h_{b}(P_{e})+P_{e}\log_{2}(|\mathcal{W}|-1)

where
P_{e}=P(\hat{W}\neq W)
and
h_{b}(p)=-p\log_{2}p-(1-p)\log_{2}(1-p)
is the binary entropy function.

Since
\hat{W}
is a function of
X
, the data processing inequality gives:

H(W|X)\leq H(W|\hat{W})

Combining:

H(W|X)\leq h_{b}(P_{e})+P_{e}\log_{2}(|\mathcal{W}|-1)

Using the mutual information decomposition
I(W;X)=H(W)-H(W|X)
:

H(W)-I(W;X)\leq h_{b}(P_{e})+P_{e}\log_{2}(|\mathcal{W}|-1)

Since
h_{b}(P_{e})\leq 1
for all
P_{e}\in[0,1]
and
\log_{2}(|\mathcal{W}|-1)\leq\log_{2}|\mathcal{W}|
:

H(W)-I(W;X)\leq 1+P_{e}\log_{2}|\mathcal{W}|

Rearranging:

P_{e}\geq\frac{H(W)-I(W;X)-1}{\log_{2}|\mathcal{W}|}

For the worst case (uniform distribution over
\mathcal{W}
),
H(W)=\log_{2}|\mathcal{W}|
:

P_{e}\geq\frac{\log_{2}|\mathcal{W}|-I(W;X)-1}{\log_{2}|\mathcal{W}|}=1-\frac{I(W;X)+1}{\log_{2}|\mathcal{W}|}

This establishes the fundamental lower bound on classification error based on available contextual information.
\square

A-C

Proof of Theorem
IV-C
(Convergence Rate)

Define the security verification loss:

L(\theta)=\mathbb{E}_{(s,w)\sim\mathcal{D}}\left[\ell\left(\phi(s),\max_{p\in G_{\theta}(C(s))}V(s,p)\right)\right]

Assume:

1.

L
is
L_{lip}
-Lipschitz:
|L(\theta_{1})-L(\theta_{2})|\leq L_{lip}\|\theta_{1}-\theta_{2}\|

2.

Stochastic gradients satisfy:
\mathbb{E}[\|\hat{\nabla}L(\theta_{t})-\nabla L(\theta_{t})\|^{2}]\leq\sigma^{2}

Under SGD with
\theta_{t+1}=\theta_{t}-\eta_{t}\hat{\nabla}L(\theta_{t})
and
\eta_{t}=\eta_{0}/\sqrt{t}
:

\|\theta_{t+1}-\theta^{*}\|^{2}=\|\theta_{t}-\eta_{t}\hat{\nabla}L(\theta_{t})-\theta^{*}\|^{2}

Expanding:

\displaystyle=\|\theta_{t}-\theta^{*}\|^{2}-2\eta_{t}\langle\hat{\nabla}L(\theta_{t}),\theta_{t}-\theta^{*}\rangle+\eta_{t}^{2}\|\hat{\nabla}L(\theta_{t})\|^{2}

Taking expectations and using Lipschitz continuity:

\mathbb{E}[\|\theta_{t+1}-\theta^{*}\|^{2}]\leq\|\theta_{t}-\theta^{*}\|^{2}-2\eta_{t}(L(\theta_{t})-L(\theta^{*}))+\eta_{t}^{2}(\sigma^{2}+L_{lip}^{2})

Summing from
t=0
to
T-1
and telescoping:

2\sum_{t=0}^{T-1}\eta_{t}(L(\theta_{t})-L(\theta^{*}))\leq\|\theta_{0}-\theta^{*}\|^{2}+\sum_{t=0}^{T-1}\eta_{t}^{2}(\sigma^{2}+L_{lip}^{2})

With
\eta_{t}=\eta_{0}/\sqrt{t+1}
:

\sum_{t=0}^{T-1}\eta_{t}\approx 2\eta_{0}\sqrt{T},\quad\sum_{t=0}^{T-1}\eta_{t}^{2}\approx\eta_{0}^{2}\log T

By convexity,
\frac{1}{T}\sum_{t=0}^{T-1}L(\theta_{t})\geq L(\bar{\theta})
where
\bar{\theta}
is the average. Thus:

\mathbb{E}[L(\bar{\theta})]-L(\theta^{*})\leq\frac{\|\theta_{0}-\theta^{*}\|^{2}}{2\eta_{0}\sqrt{T}}+\frac{\eta_{0}(\sigma^{2}+L_{lip}^{2})\log T}{2\sqrt{T}}

Optimizing
\eta_{0}=\|\theta_{0}-\theta^{*}\|/L_{lip}
yields:

\mathbb{E}[L(\bar{\theta})]-L(\theta^{*})\leq\frac{L_{lip}\|\theta_{0}-\theta^{*}\|+\sigma^{2}}{\sqrt{T}}=\frac{C}{\sqrt{T}}

where
C=L_{lip}\|\theta_{0}-\theta^{*}\|+\sigma^{2}
.
\square

A-D

Proof of Theorem
IV-D
(Soundness Preservation)

Define events for system state
\sigma\in\Sigma
:

•

E_{C}
: Context extraction fails to preserve security information

•

E_{G}
: Payload generation produces suboptimal payload

•

E_{V}
: Verification function produces false positive

•

E
: Overall system produces false positive

By assumption:
P(E_{C})\leq\delta_{C}
,
P(E_{G})\leq\delta_{G}
,
P(E_{V})\leq\epsilon_{V}
.

A false positive occurs when the system reports a vulnerability but none exists (
\phi(\sigma)=1
yet
V(\sigma,p)=1
for some
p\in G(C(\sigma))
).

This can happen through:

1.

Context extraction failure leading to incorrect payload selection

2.

Generator producing spurious payload despite correct context

3.

Verifier incorrectly flagging legitimate behavior

Thus:
E\subseteq E_{C}\cup E_{G}\cup E_{V}
.

By Boole’s inequality (union bound):

\displaystyle P(E)

\displaystyle\leq P(E_{C}\cup E_{G}\cup E_{V})

\displaystyle\leq P(E_{C})+P(E_{G})+P(E_{V})

\displaystyle\leq\delta_{C}+\delta_{G}+\epsilon_{V}

The soundness of the composed system is:

P(\phi(\sigma)=0\mid V(\sigma,p)=1)=1-P(E)\geq 1-(\epsilon_{V}+\delta_{C}+\delta_{G})

establishing that the system is
(\epsilon_{V}+\delta_{C}+\delta_{G})
-sound.
\square
