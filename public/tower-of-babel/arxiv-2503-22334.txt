Probabilistic analysis of optimal multi-pivot QuickSort
Cecilia Holmgren, Jasper Ischebeck, Daniel Krenn, Florian Lesny, Ralph Neininger

Abstract
We consider a multi-pivot QuickSort algorithm using K ∈ ℕ K\in{\mathbb{N}} pivot elements to partition a nonsorted list into K + 1 K+1 sublists in order to proceed recursively on these sublists. For the partitioning stage, various strategies are in use. We focus on the strategy that minimizes the expected number of key comparisons in the standard random model, where the list is given as a uniformly permuted list of distinct elements. We derive asymptotic expansions for the expectation and variance of the number of key comparisons as well as a limit law for all K ∈ ℕ K\in{\mathbb{N}} , where the convergence holds for all (exponential) moments. For K ≤ 4 K\leq 4 we also bound the rate of convergence within the Wasserstein and Kolmogorov–Smirnov distance. Our analysis of the expectation is based on classical results for random m m -ary search trees. For the remaining results, combinatorial considerations are used to make the contraction method applicable.

1
Introduction

The QuickSort algorithm, introduced by Hoare
[
12
]
, is a divide-and-conquer sorting algorithm. It solves the problem of sorting a list of distinct elements/items from a totally ordered set by selecting an element as
pivot
and partitioning the other elements into two sublists according to whether they are smaller or larger than the pivot and acting recursively on these sublists. QuickSort is commonly used, and variants of it are the standard sorting routines in many programming frameworks such as Oracle’s modern Java versions.

Java 7 switched from using the classical QuickSort to a dual-pivot QuickSort introduced by Yaroslavskiy
[
27
]
, which is still used in Java SE as of Java 23
[
13
]
. In general, multi-pivot QuickSort is a variant of QuickSort that uses
K\in{\mathbb{N}}
pivots (instead of
K=1
in the classical QuickSort) to partition into
K+1
sublists.
The advantages of multi-pivot QuickSort algorithms include that they reduce the list sizes faster and need fewer passes over the list. In addition, if designed properly, they need fewer key comparisons. The Yaroslavskiy algorithm is analyzed in
[
26
,
25
]
under the probabilistic model of uniformity of the order of the given items. In the present paper, we focus on the number of key comparisons as a cost measure to analyze the complexity of multi-pivot QuickSort.

1.1
Multi-pivot QuickSort

For
K\in{\mathbb{N}}
, a
K
-pivot QuickSort algorithm sorts a list of more than
K
elements by

1.

picking
K
elements as
pivot elements
(according to some
rule, for example picking the last
K
elements) and sorting these elements (by some elementary sorting
algorithm) as
p_{1}<\dots<p_{K}
, then

2.

partitioning the list into
K+1
sublists
S_{0}
, …,
S_{K}
, each containing only
the elements below the smallest pivot element
p_{1}
,
between two consecutive pivot elements or above the largest pivot element
p_{K}
,
and finally

3.

proceeding recursively with the
K+1
new lists.

If the list has
K
or fewer elements, it uses directly some elementary sorting algorithm. Note that the unspecified components above (how to choose and sort the pivot elements and how the lists of at most
K
elements are sorted) do not enter our analysis in this paper; our results are valid for any reasonable choice.

The core of the QuickSort algorithm is formed by the second
step dealing with the dividing (“partitioning”) of the list into
K+1
sublists, and this important aspect needs further attention. The order in which an element is compared to the different pivot elements determines how many comparisons are needed. We call these orders and how these are chosen a
partition strategy
. For example, in the case of
K=2
pivot elements, we might first compare an element with the smaller pivot,
p_{1}
. If the element is smaller than
p_{1}
, we can skip the comparison with the larger pivot.
Aumüller, Dietzfelbinger and Klaue
[
3
,
2
]
developed a partition strategy that is optimal (see
[
1
]
) with respect to the expected number of comparisons. This means
an
optimal
K
-pivot QuickSort
always chooses the partition strategy that minimizes the expected number of key comparisons. It is based on how many elements it has already sorted into the sublists
S_{0}
, …,
S_{K}
and determines the order in which the next element is compared to the different pivot elements. We will detail later, in Section
3
, how exactly optimal
K
-pivot QuickSort determines the optimal partition strategy.

1.2
Highlights of the results

In the present paper, we analyze, for a fixed
K\in{\mathbb{N}}
, the optimal
K
-pivot QuickSort when acting on
n
elements to be sorted by considering the number
X_{n}
of key comparisons. We assume that all
n
elements are distinct and all permutations of the
n
elements to be sorted are equally likely. We now highlight our results.

1.

For each
K\in{\mathbb{N}}
, we obtain the “shape” of the asymptotics for the expected number of key comparisons to be
{\mathbb{E}}\left[X_{n}\right]=\alpha_{K}n\ln n+\beta_{K}n+o(n)
as
n\to\infty
. Here,
\alpha_{K}
and
\beta_{K}
are suitable constants; in particular,

\alpha_{K}
can be determined as an expected value related to the optimal partition strategy. Theorem
1
provides more details.
The constants
\alpha_{K}
in the main term of the asymptotic formula of
{\mathbb{E}}\left[X_{n}\right]
approaches, as the parameter
K
is increased, the information-theoretic lower bound
1/{\ln 2}
, to be precise,
\lim_{K\to\infty}\alpha_{K}=1/{\ln 2}
; see Theorem
2
and the discussion above that theorem.

2.

In Theorem
3
we show that for each
K\in{\mathbb{N}}
the variance
\Var(X_{n})
is asymptotically
\sigma^{2}_{K}n^{2}
as
n\to\infty
for suitable constants
\sigma_{K}
. Insights on these constants are given and for
K\leq 6
values are provided.

3.

For each
K\in{\mathbb{N}}
, the normalization
Y_{n}:=(X_{n}-{\mathbb{E}}\left[X_{n}\right])/n
converges in distribution, as
n\to\infty
, to a
Z_{K}
which can be determined from a distributional fixed-point equation. Moreover, for every
\lambda\in\mathbb{R}
, we have
{\mathbb{E}}\left[\exp(\lambda Y_{n})\right]\longrightarrow{\mathbb{E}}\left[\exp(\lambda Z_{K})\right]<\infty
as
n\to\infty
. Details are stated in Theorem
4
.
Additionally, Theorem
6
states that the limit
Z_{K}
has a smooth Lebesgue density which, together with all its derivatives, is rapidly decreasing.
Furthermore, we provide asymptotic upper bounds for the rate of convergence of
Y_{n}
to
Z_{K}
, as
n\to\infty
, in the minimal
\ell_{p}
metric,
p\geq 1
, and in the Kolmogorov–Smirnov metric; see Theorem
7
for details.

We present the detailed results in Section
2
. The remaining paper is organized as follows: Partition strategies are discussed in Section
3
; there also related notions needed for the proofs are established. Section
4
contains the actual proofs for all the theorems and other results of Section
2
.

Classifying an element according to a classification tree is done as follows: The element starts at the root node of the tree where it is compared to the pivot in that node. If the element is bigger, it proceeds to the right, otherwise to the left. This decision process is repeated until it reaches an external node with associated sublist
S_{i}
and it is appended to this list
S_{i}
. We do this for all
n-K
elements in the list; in each step we might choose a different classification tree according to our partition strategy. A partition strategy minimizing the expected number of key-comparisons
\mathbb{E}[X_{n}]
is called
optimal
, see
[
11
]
.

We now set-up notions to analyze optimality of partition strategies. Let us fix
K
. The set of all classification trees for this
K
is called
\mathcal{T}
. The number of trees in
\mathcal{T}
is given by the Catalan number
\frac{1}{K+1}\binom{2K}{K}
.
We define the linear function

l_{t}(x_{0},\dots,x_{K}):=\sum_{i=0}^{K}x_{i}h_{t}(i)

(5)

on
\mathbb{R}^{K+1}
(
[
11
]
), where
h_{t}(i)
is the depth of external node with sublist
S_{i}
in the tree
t\in\mathcal{T}
. Note that
h_{t}(i)
is also the number of comparisons needed to classify an element by tree
t
into sublist
S_{i}
.

We now focus on the process of classifying each of the
n-K
elements in the list.
Let
C^{(k)}_{i}
be the number of elements already classified in the list
S_{i}
prior to classifying the
k
-th element; and set
C^{(k)}:=(C^{(k)}_{0},\dots,C^{(k)}_{K})
. The work
[
2
]
showed that, given
C^{(k)}
, the probability that the
k
-th element is classified in the sublist
S_{i}
is proportional to
C^{(k)}_{i}+1
(see
[
3
]
for the special case of
K=2
). Therefore, the optimal
K
-pivot QuickSort algorithm chooses the classification tree
t\in\mathcal{T}
that minimizes
l_{t}(C^{(k)}+1)
. In case of a tie, we use an arbitrary but fixed order on
\mathcal{T}
and choose the smallest of those trees.
We write
G_{t,k}
for the event that the
k
-th element is classified according to a tree
t
.

Let us now focus on the limiting behavior. Given
D
(see beginning of Section
2
), the probability for an element to go into sublist
S_{i}
is given by
D_{i}
. Therefore,
l_{t}(D)
is the expected number of comparisons for classifying an element. We define the classification tree
t_{\mathrm{opt}}
as the tree
t\in\mathcal{T}
that minimizes
l_{t}(D)
. (We denoted that quantity by
l_{\mathrm{opt}}(D)
in Section
2
). Note that there is almost surely only a single minimizer
t_{\mathrm{opt}}
. We also write
h_{\mathrm{opt}}
for
h_{t_{\mathrm{opt}}}
.
Furthermore, for a tree
t\in\mathcal{T}
, we define its
asymptotic cone
as

C_{t}:=\big\{\left(x_{0},\dots,x_{K}\right)\in\mathbb{R}_{\geq 0}^{K+1}:l_{t}\left(x_{0},\dots,x_{K}\right)\leq l_{t^{\prime}}\left(x_{0},\dots,x_{K}\right)\text{ for all }t^{\prime}\in\mathcal{T}\big\}.

Note that by definition,
D\in C_{t_{\mathrm{opt}}}
.

As for the
K
-pivot QuickSort algorithm, the true probabilities
D
are not known when classifying the
k
-th element and so the algorithm approximates these probabilities using
C^{(k)}/k
, quantities that converges to
D
. Therefore, as the algorithm classifies more elements, it updates its strategy to reflect changes in
C^{(k)}/k
.

Let us come back to the probabilistic part of the analysis.
The number of key comparisons to classify each of the
n-K
elements of a list into
K+1
sublists is denoted by
P_{n}
. We may write this quantity as

P_{n}=\sum_{k=1}^{n-K}\sum_{t\in\mathcal{T}}\sum_{i=0}^{K}\mathbf{1}_{G_{t,k}}\mathbf{1}_{\{a_{k}\in S_{i}\}}h_{t}(i)+R_{K},

(6)

where
a_{1}
, …,
a_{n}
denote the elements of the unsorted list. The term
R_{K}
is the number of comparisons required to sort the
K
pivots, and, by choosing an appropriate sorting algorithm, we can ensure
R_{K}\leq K^{2}
. In particular, for fixed
K
we have
R_{K}=\mathrm{O}(1)
as
n\to\infty
.

Writing
I_{i}^{(n)}:=\lvert S_{i}\rvert
for the sublist sizes,
X_{n}
can thus be defined by the recursion

X_{n}\overset{d}{=}\sum_{i=0}^{K}X^{(i)}_{I_{i}^{(n)}}+P_{n}

(7)

for
n≥K
,
where
X^{(i)}_{k}
for
k\in{\mathbb{N}}
are copies of
X_{k}
that are independent of each other and of the
(I_{0}^{(n)},\dots,I_{K}^{(n)},P_{n})
,
n≥K
.

4.1
Asymptotic expansion of
{\mathbb{E}}\left[X_{n}\right]

If the algorithm knew
D
beforehand, it could always use the asymptotically optimal classification tree
t_{\mathrm{opt}}
where

is minimal, see (
5

This “oracle strategy” uses only one tree and is easier to analyze. However, we show, see Lemma

between the actual strategy and the oracle strategy in the number of comparisons is minor. Furthermore, the number of comparisons when using
t_{\mathrm{opt}}
is closely related to the expected internal path length of a

-ary search tree, which shows the asymptotics of
{\mathbb{E}}\left[X_{n}\right]
in

Lemma 8

The additional cost of the algorithm compared to always using
t_{\mathrm{opt}}
is of sub-polynomial order:

\rho_{n}:=\,{\mathbb{E}}[P_{n}]-\,{\mathbb{E}}\left[\sum_{i=0}^{K}I^{(i)}_{n}h_{\mathrm{opt}}(i)\right]=\mathrm{O}\left((\log n)^{2}\right)

Proof 1

The sum
\sum_{i=0}^{K}I^{(i)}_{n}h_{\mathrm{opt}}(i)
is the number of comparisons of elements with pivots if we were always using the optimal classification tree.
Condition on
D
. Let
t_{k}
be the classification tree used for the
k
-th element and remember

being the optimal classification tree. For every classification tree
t\neq t_{\mathrm{opt}}
, consider

\psi_{t}(x_{0},\dots,x_{K}):=\sum_{i=0}^{K}x_{i}(h_{t}(i)-h_{\mathrm{opt}}(i)),

so that
\psi_{t}(D)
is
the expected number of additional comparisons sorting a single element using
t
instead of
t_{\mathrm{opt}}
conditional on
D
. By (
6

\displaystyle\rho_{n}

\displaystyle=\sum_{k=1}^{n-K}\sum_{i=0}^{K}{\mathbb{E}}\left[\sum_{t\in\mathcal{T}}\mathbf{1}_{G_{t,k}}\mathbf{1}_{\{a_{k}\in S_{i}\}}h_{t}(i)-\mathbf{1}_{\{a_{k}\in S_{i}\}}h_{\mathrm{opt}}(i)\right]+{\mathbb{E}}\left[R_{n}\right]

\displaystyle=\sum_{k=1}^{n-K}\sum_{t\in\mathcal{T}}{\mathbb{E}}\left[\mathbf{1}_{G_{t,k}}\sum_{i=0}^{K}\mathbf{1}_{\{a_{k}\in S_{i}\}}(h_{t}(i)-h_{\mathrm{opt}}(i))\right]+{\mathbb{E}}\left[R_{n}\right]

\displaystyle=\sum_{k=1}^{n-K}\sum_{t\in\mathcal{T}}\,{\mathbb{E}}\big[{\mathbb{P}}\left(G_{t,k}\nonscript\>\middle|\nonscript\>\mathopen{}D\right)\psi_{t}(D)\big]+\mathrm{O}(1).

(8)

Because the algorithm always chooses the best classification tree, the algorithm chooses
t_{\mathrm{opt}}
over a strategy
t
if and only if
l_{t}(C^{(k)}+1)
is bigger than
l_{t_{\mathrm{opt}}}(C^{(k)}+1)
or if there is a tie that is resolved in favor of
t_{\mathrm{opt}}
. We can model this tiebreaking by adding either
\frac{1}{2}
or
-\frac{1}{2}
to the inequality, so that
t_{\mathrm{opt}}
is chosen over
t
if and only if
\psi_{t}\left(C^{(k)}\right)=l_{t}(C^{(k)})-l_{t_{\mathrm{opt}}}(C^{(k)})>l_{t_{\mathrm{opt}}}(1)-l_{t}(1)\pm\frac{1}{2}=:b_{t}
. This

is some constant in
\mathbb{R}\setminus\mathbb{Z}
.
Furthermore,
t_{\mathrm{opt}}
is optimal for

, so
\psi_{t}(D)≥0
for all

, and we can bound

by

.

For fixed
t
and conditional on

, the variables
\psi_{t}(C^{(k)})
are linear combinations of independent indicator variables with
\,{\mathbb{E}}[\psi_{t}(C^{(k)})\nonscript\>|\nonscript\>\mathopen{}D]=(k-1)\psi_{t}(D)
and coefficients bound by
K
, and thus Hoeffding’s inequality can be applied to yield

\displaystyle{\mathbb{P}}\left(\psi_{t}\left(C^{(k)}\right)<b_{t}\nonscript\>\middle|\nonscript\>\mathopen{}D\right)

\displaystyle≤\exp\left(-\frac{2((k-1)\psi_{t}(D)-b_{t})^{2}}{4K\texttwosuperior(k-1)}\right)

\displaystyle=\exp\left(-\frac{k-1}{2K\texttwosuperior}\psi_{t}^{2}(D)+\mathrm{O}\left(\psi_{t}(D)+(k-1)^{-1}\right)\right).

Taking the expectation over
D
,

\,{\mathbb{E}}\big[{\mathbb{P}}\left(G_{t,k}\nonscript\>\middle|\nonscript\>\mathopen{}D\right)\psi_{t}(D)\big]≤\,{\mathbb{E}}\left[\psi_{t}(D)\exp\left(-\frac{k-1}{2K\texttwosuperior}\psi_{t}^{2}(D)+\mathrm{O}\left(\psi_{t}(D)+(k-1)^{-1}\right)\right)\right].

Now decompose the expectation on whether
\psi_{t}^{2}(D)
is smaller than
{4K\texttwosuperior\ln k}/(k-1)
into

\displaystyle\,{\mathbb{E}}\big[{\mathbb{P}}\left(G_{t,k}\nonscript\>\middle|\nonscript\>\mathopen{}D\right)\psi_{t}(D)\big]≤K\sqrt{\frac{4\ln k}{k-1}}{\mathbb{P}}\left(\psi_{t}(D)\leq K\sqrt{\frac{4\ln(k)}{k-1}}\right)+\exp\left(-2\ln k+\mathrm{O}(1)\right).

Since
\psi_{t}(D)
is a linear combination of
D
and
D
has bounded density (on a simplex),
\psi_{t}(D)
itself has bounded density (on

), so

\,{\mathbb{E}}\big[{\mathbb{P}}\left(G_{t,k}\nonscript\>\middle|\nonscript\>\mathopen{}D\right)\psi_{t}(D)\big]=\mathrm{O}\left(\frac{\log k}{k}\right)+\mathrm{O}\left(k^{-2}\right)

and, considering (

),
\rho_{n}
is of order
\mathrm{O}\left((\log n)\texttwosuperior\right)
.

Lemma 9

Define the sequence

Proof of Theorem

\displaystyle X_{n}\overset{d}{=}\sum_{i=0}^{K}A_{i}^{(n)}X_{I_{i}^{(n)}}^{(i)}+b_{n}

is the unique fixed point among all centered random variables with finite second moments of

Lemma 10

of the initial sum, while the second part is smaller than

of the initial sum.

(The case
K=1
follows from the Gaussian sum formula, while in the case
K\geq 2
the last term of the second sum is smaller than the first term of the first sum etc.).

Therefore we set
\frac{1}{\xi}:=\frac{1}{5\cdot 2^{\varepsilon}}+\frac{4}{5}<1
and with
x:=\sum_{j=0}^{\left\lfloor\frac{n}{2}\right\rfloor}\frac{(n-j-1)!}{(n-K-j)!}j
,
y:=\sum_{j=\left\lfloor\frac{n}{2}\right\rfloor+1}^{n-K}\frac{\left(n-j-1\right)!}{\left(n-K-j\right)!}j
and some
\eta\geq 0
we obtain

\begin{split}\frac{1}{2^{\varepsilon}}x+y&=\frac{1}{2^{\varepsilon}}\left(\frac{1}{5}(x+y)+\eta\right)+\frac{4}{5}(x+y)-\eta\\
&\leq\left(\frac{1}{5\cdot 2^{\varepsilon}}+\frac{4}{5}\right)(x+y)\\
&=\frac{1}{\xi}(x+y).\end{split}

The statement now follows with
\sum_{j=0}^{n-K}\frac{(n-j-1)!}{(n-K-j)!}j=\frac{n!}{K(K+1)(n-K-1)!}
.

For bounding

Therefore, for fixed

\displaystyle{}\begin{split}\Delta^{2}(n)&\leq\mathbb{E}\left[\left|\sum_{i=0}^{K}\frac{I_{i}^{(n)}}{n}Y_{I_{i}^{(n)}}^{(i)}-D_{i}Z_{K}^{(i)}+b_{n}-b\right|^{2}\right]\\

and there exists an

This yields

\displaystyle\left\|\left(\frac{c_{p-1}}{n^{\frac{1}{2}-\varepsilon}}+\tau\left|\frac{I_{i}^{(n)}}{n}-D_{i}\right|\right)^{k_{i}}\right\|_{K+2}=\mathrm{O}\left(\frac{1}{n^{k_{i}/2-k_{i}\varepsilon}}\right)

and overall we obtain

\mathbb{E}\left[\prod_{i=0}^{K}\left(\frac{c_{p-1}}{n^{\frac{1}{2}-\varepsilon}}+\tau\left|\frac{I_{i}^{(n)}}{n}-D_{i}\right|\right)^{k_{i}}\,{\mathbb{E}}_{#1}\left[\lvert b_{n}-b\rvert^{p}\right]^{\frac{k_{K+1}}{p}}\right]=\mathrm{O}\left(\frac{1}{n^{\sum k_{i}/2-\sum k_{i}\varepsilon}}\right)

and thus

\displaystyle\begin{split}\sum_{\lvert k\rvert=p}\binom{p}{k}\,{\mathbb{E}}\Bigg[\prod_{i=0}^{K}\left(\frac{c_{p-1}}{n^{\frac{1}{2}-\varepsilon}}+\tau\left|\frac{I_{i}^{(n)}}{n}-D_{i}\right|\right)^{k_{i}}\hskip-10.00002pt\,{\mathbb{E}}_{#1}\left[\lvert b_{n}-b\rvert^{p}\right]^{\frac{k_{K+1}}{p}}\Bigg]=\mathrm{O}\left({n^{-\frac{p}{2}+p\varepsilon}}\right).\end{split}

Collecting the estimates, we obtain

\displaystyle\Delta_{p}^{p}(n)\leq(K+1)\mathbb{E}\left[\left|W_{0}\right|^{p}\right]+\mathrm{O}\left(\frac{1}{n^{p\left(\frac{1}{2}-\varepsilon\right)}}\right).

For the term
\mathbb{E}\left[\left|W_{0}\right|^{p}\right]
, analogously to the case
p=2
, we have

\displaystyle\begin{split}{\mathbb{E}}\left[\left|W_{0}\right|^{p}\right]&=\mathbb{E}\left[\left|W_{0}\right|^{p}\mid\left(I_{0}^{(n)},D_{0}\right)\right]\\
&=\sum_{r=0}^{p-1}\binom{p}{r}\mathbb{E}\left[\left(\frac{I_{0}^{(n)}}{n}\right)^{r}\Delta_{p}^{r}\left(I_{0}^{(n)}\right)\tau^{p-r}\left|\frac{I_{0}^{(n)}}{n}-D_{0}\right|^{p-r}\right]\\
&\quad+\mathbb{E}\left[\left(\frac{I_{0}^{(n)}}{n}\right)^{p}\Delta_{p}^{p}\left(I_{0}^{(n)}\right)\right].\end{split}

The inductive hypothesis
\Delta_{p}(j)\leq cj^{-\frac{1}{2}+\varepsilon}
for
j<n
yields

\displaystyle\begin{split}\mathbb{E}\left[\left(\frac{I_{0}^{(n)}}{n}\right)^{r}\Delta_{p}^{r}\left(I_{0}^{(n)}\right)\tau^{p-r}\left|\frac{I_{0}^{(n)}}{n}-D_{0}\right|^{p-r}\right]&\leq\frac{\tau^{p-r}c^{r}}{n^{r/2-r\varepsilon}}\mathbb{E}\left[\left|\frac{I_{0}^{(n)}}{n}-D_{0}\right|^{p-r}\right]\\
&\leq\frac{a_{r}c^{r}}{n^{p/2-p\varepsilon}}\end{split}

for some constants
a_{r}>0
for
r=0,\dots,p-1
. The term
\mathbb{E}\left[\left(\frac{I_{0}^{(n)}}{n}\right)^{p}\Delta_{p}^{p}\left(I_{0}^{(n)}\right)\right]
is bounded explicitly through

\displaystyle\begin{split}\mathbb{E}\left[\left(\frac{I_{0}^{(n)}}{n}\right)^{p}\Delta_{p}^{p}\left(I_{0}^{(n)}\right)\right]&=\frac{1}{B(1,K)}\int_{0}^{1}\left(1-u\right)^{K-1}\sum_{j=0}^{n-K}\binom{n-K}{j}u^{j}(1-u)^{n-K-j}\\
&\quad\quad\quad\quad\quad\quad\times\mathbb{E}\left[\left(\frac{I_{0}^{(n)}}{n}\right)^{p}\Delta_{p}^{p}\left(I_{0}^{(n)}\right)\mid\left(I_{0}^{(n)}=j,D_{0}=u\right)\right]du\\
&\leq\frac{K}{n^{p}}\sum_{j=1}^{n-K}\frac{c^{p}(n-K)!}{j!(n-K-j)!}\frac{j^{p}}{j^{\frac{p}{2}-p\varepsilon}}\int_{0}^{1}u^{j}(1-u)^{n-j-1}du\\
&\leq\frac{c^{p}K(n-K)!n^{\frac{p}{2}-1}}{n^{p}}\sum_{j=1}^{n-K}\frac{1}{j!(n-K-j)!}\frac{j!(n-j-1)!}{n!}j^{1+p\varepsilon}\\
&=\frac{c^{p}K(n-K)!}{n^{\frac{p}{2}+1}n!}\sum_{j=1}^{n-K}\frac{(n-j-1)!}{(n-K-j)!}j^{1+p\varepsilon}.\end{split}

By Lemma
12
there exists a
\xi>1
(depending in
p
and being different from the
\xi
appearing above) such that

\displaystyle\sum_{j=1}^{n-K}\frac{(n-j-1)!}{(n-K-j)!}j^{1+p\varepsilon}\leq\frac{n^{p\varepsilon}}{\xi}\frac{n!}{K(K+1)(n-K-1)!}.

Plugging in, we obtain

\displaystyle\mathbb{E}\left[\left(\frac{I_{0}^{(n)}}{n}\right)^{p}\Delta^{p}\left(I_{0}^{(n)}\right)\right]

\displaystyle\leq\frac{c^{p}(n-K)n^{p\varepsilon}}{\xi(K+1)n^{\frac{p}{2}+1}}\leq\frac{c^{p}}{\xi(K+1)}\frac{1}{n^{\frac{p}{2}-p\varepsilon}}.

Overall we have

\displaystyle\Delta_{p}^{p}(n)\leq\left(\frac{1}{\xi}c^{p}+\sum_{i=0}^{p-1}\tilde{a}_{i}c^{i}\right)\frac{1}{n^{\frac{p}{2}-p\varepsilon}}\leq\frac{c^{p}}{n^{\frac{p}{2}-p\varepsilon}}

with some constants
\tilde{a}_{0},\tilde{a}_{1},\dots,\tilde{a}_{p-1}>0
and
c
sufficiently large. This finishes the proof of the bounds on the
\ell_{p}
metrics.

To bound the distance between
Y_{n}
and
Z_{K}
in the Kolmogorov-Smirnov metric, we use Lemma 5.1 in
[
9
]
, which implies

\varrho\left(Y_{n},Z_{K}\right)\leq\left(\left(1+p\right)\left\|f_{Z_{K}}\right\|^{p}_{\infty}\right)^{\frac{1}{p+1}}\left(\ell_{p}\left(Y_{n},Z_{K}\right)\right)^{\frac{p}{p+1}}

since
Z_{K}
has a bounded density function
f_{Z_{K}}
with Theorem
6
. We know that for all
p\geq 1
and
\delta>0

\ell_{p}\left(Y_{n},Z_{K}\right)\leq\frac{c_{p}}{n^{\frac{1}{2}-\delta}}

with some constant
c_{p}
. For some fixed
\varepsilon
, we can choose
p
large enough such that
p/(2(1+p))>\frac{1}{2}-\varepsilon
. It is possible to choose
\delta>0
with
(p/(1+p))\left(\frac{1}{2}-\delta\right)>\frac{1}{2}-\varepsilon
and thereby obtain

\varrho\left(Y_{n},Z_{K}\right)\leq c_{p}^{\prime}\frac{1}{n^{\frac{p}{1+p}\left(\frac{1}{2}-\delta\right)}}\leq c_{p}^{\prime}\frac{1}{n^{\frac{1}{2}-\varepsilon}}

where the constant
c_{p}^{\prime}
depends on
\varepsilon
but not on
n
. This finishes the proof of Theorem
7
.
