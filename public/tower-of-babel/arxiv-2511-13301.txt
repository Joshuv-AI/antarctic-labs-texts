A Complexity Analysis of the c-Closed Vertex Deletion Problem
Lisa Lehner, Christian Komusiewicz, Luca Pascal Staus

Abstract
A graph is c c -closed when every pair of nonadjacent vertices has at most c − 1 c-1 common neighbors. In c c -Closed Vertex Deletion , the input is a graph G G and an integer k k and we ask whether G G can be transformed into a c c -closed graph by deleting at most k k vertices. We study the classic and parameterized complexity of c c -Closed Vertex Deletion . We obtain, for example, NP-hardness for the case that G G is bipartite with bounded maximum degree. We also show upper and lower bounds on the size of problem kernels for the parameter k k and introduce a new parameter, the number x x of vertices in bad pairs , for which we show a problem kernel of size OPEN 𝒪 ⁡ ( x 3 + x 2 ⋅ c ) ) \mathcal{O}(x^{3}+x^{2}\cdot c)) . Here, a pair of nonadjacent vertices is bad if they have at least c c common neighbors. Finally, we show that c c -Closed Vertex Deletion can be solved in polynomial time on unit interval graphs with depth at most c + 1 c+1 and that it is fixed-parameter tractable with respect to the neighborhood diversity of G G .

Introduction

One of the most striking features of social networks is that they tend
to show a high degree of
triadic closure
. This is the
phenomenon that two agents which both interact with the same third
agent are likely to interact directly, too. There are different ways to
quantify this observation. For example, one can observe that
social networks have high clustering coefficients, meaning that a
large fraction of all connected vertex triples are triangles.
A further formal definition capturing triadic closure is graph
closure
, introduced by Fox et al.
[
4
]
.
Here, a network is called
c
-closed
if all pairs of vertices with at least
c
common neighbors are adjacent and the closure of a network is the smallest number
c
such that the network is
c
-closed. The hypothesis driven by the triadic closure phenomenon is now that networks should have a relatively small closure number and this is indeed the case for real-world data
[
4
,
12
]
. Apart from giving further evidence to confirm theories about the mechanisms that underly the creation of real-world networks, this observation has consequences for the development of algorithms for real-world networks: Many hard computational problems are fixed-parameter tractable when parameterized by
c
or by combinations of
c
and other parameters. Informally, this means that these problems can be solved (more) efficiently when the input networks have a small closure number.

For example, the enumeration of maximal cliques is fixed-parameter tractable with respect to the closure number
c

[
4
]
. More precisely, all maximal cliques can be enumerated in
3^{c/3}\cdot n^{\mathcal{O}(1)}
time, where
n
denotes the number of vertices in the graph. This result has been extended to the enumeration of different types of near-cliques
[
1
,
9
]
. Further algorithmic applications of
c
-closure were given for variants of
Dominating Set

[
6
,
8
,
9
]
,
Independent Set

[
8
,
9
]
, and
Vertex Cover

[
7
,
10
]
and for problems related to finding certain small subgraphs
[
11
]
.

A drawback of
c
-closure is that it is defined as the
maximum
of the sizes of common neighborhoods of nonadjacent vertices (plus one) which makes it sensitive to local changes: all it takes to drastically increase the
c
-closure of a graph is the absence of one edge between two vertices with many common neighbors. Ideally, we would like to obtain more robust positive algorithmic results that hold not only for
c
-closed graphs but also for those graphs which are
almost

c
-closed. We follow the natural way of quantifying this by counting the number
k
of vertex deletions that are necessary to obtain a
c
-closed graph. Using simple arguments, one can show that positive results for
Independent Set
and
Clique
can be extended from
c
-closed graphs to almost
c
-closed graphs.

Proposition 1

Let

be a graph and

Proof

To determine whether

S

is an independent set. If this is the case, then delete all vertices from

(as they cannot be contained in an independent set that includes

To enumerate all maximal cliques of

3.2

If

Reduction Rule 1

Remove an edge

Proof

In this section we first show that

-CVD

\mathcal{O}(k^{c-\epsilon})
unless

\subseteq

-CVD
with
\mathcal{O}(k^{c+2})

-Hitting Set
.
Finally, we show a problem kernel of size

4.1
Hitting Set Reductions

We start by defining
d
-Hitting Set
:

d
-Hitting Set

Input:

A family
\mathcal{A}
of subsets of a universe
U
such that each subset has size at most
d
, and a positive integer
k
.

Question:

Is there a set
H\subseteq U
with
|H|\leq k
such that
H
contains at least one element of each set in
\mathcal{A}
?

We now define a reduction from
d
-Hitting Set
to
c
-CVD
with
c=d
by turning the elements in each set into the connecting vertices of an FSG.

Let
(U,\mathcal{A},k)
be an instance of
d
-Hitting Set
. We first add additional elements to the sets in
\mathcal{A}
such that each set has exactly size
d
. We construct the graph
G
as follows: Each element of
U
becomes a vertex in
G
. Additionally, for each set
A\in\mathcal{A}
we add two new vertices
v_{A}
and
u_{A}
. For each vertex

we add the edges
\{v,v_{A}\}
and
\{v,u_{A}\}
such that
v_{A}
and
u_{A}
form a bad pair with the vertices in
A
as their connecting vertices. Finally, we add all edges between vertices in
U
such that
U
becomes a clique. With this we obtain the
c
-CVD
instance
(G,k)
with
c=d
.

Lemma 2

The reduction from
d
-Hitting Set
to
c
-CVD
is correct.

Proof

We need to show the following:

\displaystyle(U,\mathcal{A},k)\text{ is a yes-instance }\Leftrightarrow(G,k)\text{ is a yes-instance.}

(\Rightarrow)
Let
S\subseteq U
be a solution for
(U,\mathcal{A},k)
. Any FSG
H
in
G
must have at least one bad pair vertex
v_{A}
that is not in
U
since all vertices in
U
are pairwise connected. By construction we have
N(v_{A})=A\subseteq V(H)
. Since
S
contains at least one vertex of
A
we know that
G-S
does not contain any FSGs. This means that
S
is a solution for
(G,k)
.

(\Leftarrow)
Let
S\subseteq V(G)
be a solution for
(G,k)
. We construct the set
S^{\prime}
as follows: First we add any vertex in
S
that is also in
U
to
S^{\prime}
. Then for each vertex
v
in
S
that is not in

there are two cases. In the first case,

is a vertex that was added to a set

to increase its size to
d
. In this case we add an arbitrary vertex from

to

. In the second case,
v
is a vertex that was added to create a bad pair with

as the connecting vertices. In this case we also add an arbitrary vertex in
A
to
S^{\prime}
. Clearly we have
|S^{\prime}|\leq k
.
For each set
A\in\mathcal{A}
there is at least one FSG in

and therefore there must be at least one vertex

that is contained in that FSG. By construction, at least one vertex of
S^{\prime}
is contained in

. THence,
S^{\prime}
is a solution for
(U,\mathcal{A},k)
. ∎

From this reduction we can obtain two results. First, the constructed graph is a split graph which means that

-CVD
is NP-hard on split graphs.

Corollary 1

For every

,
c
-CVD
is NP-hard on split graphs.

Let us remark that the case

.
The second result is a lower bound for the bit size of a problem kernel for

-CVD
. For this we can use the result that

\subseteq

/poly
[

. Since

we immediately obtain the following result for

-CVD
.

Theorem 4.1

c
-Closed Vertex Deletion
with

\mathcal{O}(k^{c-\epsilon})

be an instance of

Proof

\displaystyle(G,k)\text{ is a yes-instance }\Leftrightarrow(U,\mathcal{A},k)\text{ is a yes-instance.}

. Let

. Expressive kernels are defined as follows:

(

Theorem 4.2

For

,

-Closed Vertex Deletion
admits a kernel with

Let
(G,k)
be a

-CVD

be the

-Hitting Set

. Since

by

. Our kernel is now the

that is constructed by removing any vertex in

and their incident edges from

We now need to show the following to show that

\displaystyle(G,k)\text{ is a yes-instance }\Leftrightarrow(G^{\prime},k)\text{ is a yes-instance.}

(
\Rightarrow
) Let

be a solution for
(G,k)
. Since the class of

.

(
\Leftarrow
) Let

be a minimal solution for

also exists in

is also the vertex set of some FSG in

. This means that

is a solution for

We have now shown that

is a kernel and since the vertex set

we know that

has

vertices. We now only need to show the running time of the kernelization. The kernelization consists of three main steps. First, the reduction from

to

. Finally, creating the induced subgraph

. Observe that if

For the first step, we start by looking at each pair of vertices

have less than

Kernel with parameter

To obtain a kernel with polynomial dependence on

we use a new parameter

where

that are part of at least one bad pair in

With this parameter we can obtain a kernel with
\mathcal{O}(x^{2}\cdot(k+c))

will reduce its size to the desired bound.
We may assume

since any instance with

can be trivially solved by removing all vertices of

.
We say that a bad pair is

if it has more than

Reduction Rule 2

Mark all vertices in

and all vertices that are connecting vertices of at least one weak bad pair. Then, remove an arbitrary unmarked vertex.

Lemma 5

Rule

is correct.

Proof

Let
(G,k)
be an instance of

-CVD
and let
(G^{\prime},k)
be the instance that is obtained by Rule

removing vertex

from

. We now need to show that

(G,k)\text{ is a yes-instance}\Leftrightarrow(G^{\prime},k)\text{ is a yes-instance.}

(\Rightarrow)
Let
S
be a solution for
(G,k)
which means that
G-S
is

-closed. Since the class of
c
-closed graphs is hereditary, we know that
(G-S)-\{v\}=(G^{\prime}-S)
is also

-closed. Hence,

is a solution for
(G^{\prime},k)
.

(\Leftarrow)
Let
S^{\prime}
be a solution for
(G^{\prime},k)
. Assume towards a contradiction that

is not

-closed and therefore contains some FSG

. If

, then

must also be a subgraph of

which contradicts

being a solution for
(G^{\prime},k)
. If

, then

must be a connecting vertex in

since it is not in

. Moreover, the bad pair in

is a heavy bad pair in

since

was not marked by Rule

. This means that the bad pair in

must be a bad pair in

with at least

now tells us that

contains a vertex from this bad pair. This contradicts

being an FSG in

. ∎

Exhaustively applying Rule

leads to a kernel of the desired size.

Lemma 6

c
-Closed Vertex Deletion
has a problem kernel with
\mathcal{O}(x^{2}\cdot(k+c))
vertices where

is the number of vertices that are part of at least one bad pair.

Proof

Let
(G,k)
be an instance of
c
-CVD
such that Rule

cannot be applied anymore. This means that all vertices in
G
are marked and are therefore part of a bad pair or connecting vertices of at least one weak bad pair.
Graph
G
can contain at most
\binom{x}{2}=\frac{x\cdot(x-1)}{2}\in\mathcal{O}(x^{2})
weak bad pairs. Each of those can have at most

\mathcal{O}(x^{2}\cdot(k+c))
as an upper bound for the number of vertices in
G

Since we can assume
x>k
, we can also write the bound as
\mathcal{O}(x^{3}+x^{2}\cdot c)
.

A graph

Neighborhood Diversity

The
neighborhood diversity
of a graph,
\nd(G)
, is the number of
neighborhood classes
of
G
which are the equivalence classes of the relation
\sim
with
u\sim v:\Leftrightarrow N(u)\setminus\{v\}=N(v)\setminus\{u\}
. We first show that for each neighborhood class there are essentially only
c+1
possibilities to consider.

Lemma 8

Let
S
be a minimum-size solution for a
c
-CVD
instance
(G,k)
with

. Then for each neighborhood class

we either have

or
|D\setminus S|<c
.

Proof

Assume towards a contradiction, that
D\setminus S
is a proper subset of
D
that contains at least
c
vertices and let
v
be a vertex of
D\cap S
. Since
S
is a minimal solution,
S\setminus\{v\}
is not a solution, that is,
G-(S\setminus\{v\})
contains an FSG

one of whose vertices is

. This FSG can contain at most
c
vertices of

, since the two bad pair vertices have different neighborhoods than the connecting vertices. Hence,
v
can be replaced in

by some vertex of

, giving an FSG

which is contained in

. This contradicts that

is a solution.
∎

With this we can now obtain the following via branching.

c
-CVD

Since the vertices in a neighborhood class have the same neighborhood it does not matter which vertices we specifically remove. It only matters how many of them we remove. According to Lemma

6
Conclusion

We have introduced
c
-Closed Vertex Deletion
and provided a first overview of its complexity. Several interesting questions are left open: First, it remains to settle the remaining five open cases for the complexity on bounded-degree graphs. Second, one could close the gap between the upper and lower bounds on the kernel size for the solution size parameter
k
. Third, a complexity classification for interval graphs and unit interval graphs remains open.
In addition, it is of interest to identify further problems which can be solved efficiently on almost
c
-closed graphs. Finally, we introduced the bad pairs-related parameter which could be useful for other vertex deletion problems where the forbidden subgraphs are large but contain distinguished pairs of vertices. Identifying such problems and providing a generic definition of a bad pair-related parameter could be fruitful.
