Implementation of Support Vector Machines using Reaction Networks
Amey Choudhary, Jiaxin Jin, Abhishek Deshpande

Abstract
Can machine learning algorithms be implemented using chemical reaction networks? We demonstrate that this is possible in the case of support vector machines (SVMs). SVMs are powerful tools for data classification, leveraging VC theory to handle high-dimensional data and small datasets effectively. In this work, we propose a reaction network scheme for implementing SVMs, utilizing the steady-state behavior of reaction network dynamics to model key computational aspects of SVMs. This approach introduces a novel biochemical framework for implementing machine learning algorithms in non-traditional computational environments.

Introduction

Living cells respond to external stimuli through mechanisms such as gene regulatory networks. Systems biology hopes to construct complex circuits such as oscillators/switches from simple building blocks. Recently, these designs have enabled the development of complicated biological circuits for real-world applications.
Our work aims to enable computation in living environments, where modern computers are currently unable to operate.

Reaction networks offer a robust framework for biomolecular interactions and can be realized through DNA strand displacement reactions, providing a physical basis in cellular environments. This makes them a powerful “programming language” for molecular computation, owing to DNA’s sequence specificity and high-density information storage. However, programming reaction networks for more sophisticated tasks like training and testing remains a challenge.

The idea of using reaction networks for performing computation dates back to the 1940s. McCulloch and Pitt were the first to link neural networks to cellular automata

[

. Subsequently, Winfree and Qian
[

have developed DNA strand displacement schemes to create more complex circuits. Recently, reaction networks have been used to implement various machine learning algorithms. In particular, these include the work of Stojanovic et al.
[

who construct reaction networks to automate decision tree implementations and Gopalkrishnan et al.
[

,

,

]
who have designed reaction network schemes that calculate maximum likelihood estimates and simulate Boltzmann machines
[
20
,

,

]
. More recently, reaction networks have been shown to implement neural network dynamics
[
3
,
8
,
16

.

In this paper, our focus is on Support Vector Machines (SVMs). Introduced by Vapnik and Chervonenkis in the 1960s, SVMs are supervised classification algorithms. The essential idea of SVM is to construct a hyperplane that maximally separates data points from different classes, creating the largest possible margin. For data that can be separated linearly, SVM works perfectly well, but for nonlinear cases, one needs to use the
kernel functions
for mapping data onto spaces that are high-dimensional.

In this work, we design a reaction network scheme to implement a Hard-Margin SVM, leveraging biochemical processes for machine learning tasks. Our reaction network-based model can load input data points, perform inference, back-propagate loss, and update weights via gradient descent. To ensure these operations proceed in a controlled and sequential manner, we utilize oscillating molecular species to achieve time-scale separation.
We validate our approach by simulating the reaction network on synthetic data in Python, demonstrating effective convergence with weight updates comparable to those of standard SVM library implementations. This work introduces a novel biochemical framework for executing complex machine learning algorithms beyond traditional computational systems, expanding the potential applications of reaction networks in computational and synthetic biology.

In the following, we introduce two key concepts in reaction networks: catalytic and non-catalytic species, which will be frequently used in Section

Definition 5

(
[
11
]
)
.

Let
(\mathcal{S},\mathcal{C},\mathcal{R})
be a reaction network. Suppose all reactions
R_{1},\ldots,R_{r}\in\mathcal{R}
, where each reaction is of the form

R_{j}:\sum_{i=1}^{n}\alpha_{ij}X_{i}\rightarrow\sum_{i=1}^{n}\beta_{ij}X_{i}.

(a)

A species

\alpha_{ij}\neq\beta_{ij}
.

Remark 6
.

In a reaction network, every species is either a catalytic species or a non-catalytic species. Under the mass-action system, catalytic species are those whose concentrations remain unchanged across the entire network, and therefore
\frac{dx_{i}}{dt}\equiv 0
; whereas for non-catalytic species, there exists at least one reaction that alters their concentration.

3
Support Vector Machines

Support Vector Machines (SVMs) are supervised machine learning algorithms. SVMs have attracted widespread attention in machine learning, data mining and pattern recognition tasks. In particular, they have been found to be particularly useful in binary classification problems.

SVM works on the principle of generating a surface that separates data into classes by maximizing the distance between itself and the data points. In particular, SVM assigns the data points labels by finding the
optimal hyperplane
. This hyperplane corresponds to one that is at the maximum distance from the closest point of any class. Given a new data point, it can be classified and given labels according to which side of the hyperplane it will be in feature space.

If the data cannot be separated by such a hyperplane, then the SVM finds the hyperplane as in the hard margin case with the caveat that a penalty is added each time a point crosses the margin. These SVMs are referred to as soft margin SVMs.

Figure 3
:
Hard Margin SVM Decision Boundary

3.1
Hard-Margin SVM Formulation

Given a set of data points (which are feature vectors), that belong to either of the two classes, one needs to decide to which of the two classes does a new data point belong to? More formally, given a dataset
\{(x_{i},y_{i})\}_{i=1}^{N}
, where
x_{i}\in\mathbb{R}^{d}
are the feature vectors and
y_{i}\in\{1,-1\}
are the binary class labels, the goal is to find a weight vector
\mathbf{w}\in\mathbb{R}^{d}

such that it maximizes the distance of its nearest point for each class and bias
b\in\mathbb{R}
such that:

y_{i}(\mathbf{w}\cdot x_{i}+b)\geq 1\quad\text{for all }i.

(1)

The optimization problem for a hard-margin SVM can be defined as:

\min_{\mathbf{w},b}\frac{1}{2}\|\mathbf{w}\|^{2},

(2)

subject to the constraint that all training points satisfy:

y_{i}(\mathbf{w}\cdot x_{i}+b)\geq 1.

(3)

3.2
Iterative Training with Error-Driven Update

In practice, we can use an iterative training algorithm that updates
\mathbf{w}
and
b
whenever a data point is misclassified. This approach is similar to a gradient descent method on hinge loss. Given a learning rate
\eta>0
, we update the parameters as follows:

1.
Initialize

\mathbf{w}=1
and
b=0
.

2.
For each data point

(x_{i},y_{i})
:
- Compute the decision function:
f(x_{i})=\mathbf{w}\cdot x_{i}+b
.
The hinge loss for a single training example
(x_{i},y_{i})
is defined as:

\text{Loss}(w,b)=\max(0,1-y_{i}*f(x_{i}))

To update the weights based on the hinge loss, we compute the gradients:

\frac{\partial\text{Loss}}{\partial w}=\begin{cases}-y_{i}x_{i}&\text{if }y_{i}(w\cdot x_{i}+b)<1\\
0&\text{otherwise}\end{cases}

\frac{\partial\text{Loss}}{\partial b}=\begin{cases}-y_{i}&\text{if }y_{i}(w\cdot x_{i}+b)<1\\
0&\text{otherwise}\end{cases}

The weight update rules for gradient descent with learning rate
\eta
are as follows:

1.

If there is a misclassification or margin violation
(
y_{i}(w\cdot x_{i}+b)<1
):

\displaystyle\begin{split}w&\leftarrow w-\eta\left(\lambda w-y_{i}x_{i}\right)\\
b&\leftarrow b+\eta y_{i}\end{split}

(4)

2.

If there is no misclassification
(
y_{i}(w\cdot x_{i}+b)\geq 1
):

\displaystyle\begin{split}w&\leftarrow w-\eta\lambda w\\
b&\leftarrow b\end{split}

(5)

Here
\lambda
is the regularization parameter.

3.

Repeat
this process for multiple epochs until convergence or a set number of iterations is reached.

This update rule moves
\mathbf{w}
and
b
in the direction that reduces the error for misclassified points, adjusting the hyperplane iteratively. The learning rate
\eta
controls the step size for each update, impacting the convergence rate.

3.3
Decision Rule

After training, the classification decision for a new data point
x
is given by:

f(x)=\mathbf{w}\cdot x+b.

(6)

The predicted class is then:

\hat{y}=\begin{cases}1&\text{if }f(x)\geq 0,\\
-1&\text{otherwise}.\end{cases}

This iterative approach, while not the standard quadratic programming formulation of SVM, provides a computationally efficient method for training hard-margin SVMs and is particularly useful in online or large-scale learning scenarios.

Operation modules

In this section, we flesh out the reaction network scheme for the individual sub-modules that will used for implementing the feedforward and backpropagations step. Towards this, we note that in dealing with weights and biases, we will may encounter negative values, and need a mechanism to handle this. The next subsection on

4.1
Dual rail encoding

In physical setting, concentration of species is always non-negative. As data points and weights can be negative, we use the Dual Rail Encoding
[
28
]
.

For any variable
\zeta\in\mathbb{R}
, we take two species
\zeta^{+}
and
\zeta^{-}
with non-negative concentrations
\zeta^{+}(t)\geq 0
and
\zeta^{-}(t)\geq 0
. For all
t\geq 0
, the difference between
\zeta^{+}(t)-\zeta^{-}(t)
represents the real value
\zeta
.

Here, we list some basic modules that will be used for in the implemention of the more feedforward and backpropogation modules. Some of these have also been described in
[
29
]
. In this description, we will denote by
[X(t)]
, the concentration corresponding to the species
X
at time
t
.

4.2
Addition module

In order to add two numbers, we consider the following network:

\displaystyle\begin{split}A&\overset{1}{\longrightarrow}A+C\\
B&\overset{1}{\longrightarrow}B+C\\
C&\overset{1}{\longrightarrow}\emptyset\end{split}

(7)

The concentrations of species
A
and
B
are added and the result is stored in the steady state concentration of
C
. The original input species
A
and
B
are catalysts and their concentrations are preserved. Let
[A]=[A(t)]=[A(0)]
and
[B]=[B(t)]=[B(0)]
. Then the dynamics of network
7
is given by

\displaystyle\frac{d[C(t)]}{dt}=[A]+[B]-[C(t)]

(8)

The steady-state concentration of
[C(t)]
(denoted by
[C^{ss}]
) is given by
[C^{ss}]=[A]+[B]
.

4.3
Multiplication module

In order to multiply, we consider the following network:

\displaystyle\begin{split}A+B&\overset{1}{\longrightarrow}A+B+C\\
C&\overset{1}{\longrightarrow}\emptyset\end{split}

(9)

Here, the concentrations of species
A
and
B
are multiplied and the result is stored in the steady-state concentration of
C
. Since
A
and
B
are catalysts, their concentrations are preserved. Let
[A]=[A(t)]=[A(0)]
and
[B]=[B(t)]=[B(0)]
. Then the dynamics corresponding to network
9
is given by

\displaystyle\frac{d[C(t)]}{dt}=[A]\cdot[B]-[C(t)]

(10)

The steady-state concentration of
[C(t)]
(denoted by
[C^{ss}]
) is given by
[C^{ss}]=[A]\cdot[B]
.

4.4
Comparison and Approximate majority

Our module is designed to compare the concentrations of species and set the corresponding flags. This functionality is achieved using a
comparison module
(CMP) and an
approximate majority module
(AM), triggered in consecutive clock cycles.

Comparison Module (CMP)

In the comparison (CMP) module, the inputs
X
and
Y
are assigned to flag species
X_{gtY}
and
X_{ltY}
in a normalized fashion. The network for implementing this is given by

\displaystyle\begin{split}X_{gtY}+Y&\overset{1}{\longrightarrow}X_{ltY}+Y,\\
X_{ltY}+X&\overset{1}{\longrightarrow}X_{gtY}+X.\end{split}

(11)

In this network, the species
X
and
Y
are catalysts. We let
[X]=[X(0)]
and
[Y]=[Y(0)]
. To normalize the values within the range
[0,1]
, the initial concentrations of
X_{gtY}
and
X_{ltY}
are set such that
[X_{gtY}(0)]+[X_{ltY}(0)]=1
. For example, if
[X(0)]=60
and
[Y(0)]=40
, the flag species
X_{gtY}
and
X_{ltY}
will converge to
0.6
and
0.4
, respectively.

The dynamics corresponding to network
11
is given by

\displaystyle\begin{split}\frac{d[X_{gtY}(t)]}{dt}&=-[X_{gtY}(t)]\cdot[Y]+[X_{ltY}(t)]\cdot[X]\\
\frac{d[X_{ltY}(t)]}{dt}&=[X_{gtY}(t)]\cdot[Y]-[X_{ltY}(t)]\cdot[X]\end{split}

(12)

At steady-state, we get

\displaystyle\frac{[X_{gtY}^{ss}]}{[X_{ltY}^{ss}]}=\frac{[X]}{[Y]}

(13)

Note that
[X_{ltY}^{ss}]+[X_{gtY}^{ss}]=1
. This implies that

\displaystyle\begin{split}[X_{gtY}^{ss}]&=\frac{[X]}{[X]+[Y]}\\
[X_{ltY}^{ss}]&=\frac{[Y]}{[X]+[Y]}.\end{split}

(14)

Approximate Majority module (AMP)

In the approximate Majority Module (AM) module
[
6
]
, molecules of species possessing lower population are converted into molecules of species possessing higher population through the following network:

\displaystyle\begin{split}X_{gtY}+X_{ltY}&\overset{1}{\longrightarrow}X_{ltY}+B,\\
B+X_{ltY}&\overset{1}{\longrightarrow}X_{ltY}+X_{ltY},\\
X_{ltY}+X_{gtY}&\overset{1}{\longrightarrow}X_{gtY}+B,\\
B+X_{gtY}&\overset{1}{\longrightarrow}X_{gtY}+X_{gtY}.\end{split}

(15)

The dynamical system corresponding to the module
15
is given by

\displaystyle\begin{split}\frac{d[X_{gtY}(t)]}{dt}&=-[X_{gtY}(t)]\cdot[X_{ltY}(t)]+[B(t)]\cdot[X_{gtY}(t)]\\
\frac{d[X_{ltY}(t)]}{dt}&=-[X_{gtY}(t)]\cdot[X_{ltY}(t)]+[B(t)]\cdot[X_{ltY}(t)]\\
\frac{d[B(t)]}{dt}&=-[B(t)]\cdot[X_{ltY}(t)]-[B(t)]\cdot[X_{gtY}(t)]+2[X_{gtY}(t)]\cdot[X_{ltY}(t)]\end{split}

(16)

Assuming the normalization step in the comparison module (CMP) has already been executed, the species
(X_{gtY},X_{ltY},B)
will converge to the state
(1,0,0)
if
X_{gtY}(0)>X_{ltY}(0)
, and to
(0,1,0)
if
X_{gtY}(0)<X_{ltY}(0)
. [For a proof of this fact, please refer
[
29
]
.]

As it will turn out, in Section
6

X_{gtY}
will serve as a catalyst in reactions that occur when
X>Y
, while
X_{ltY}
plays the same role for the opposite condition.

4.5
Loading module

The loading module copies the concentration of
A
into
B
using the following network:

\begin{split}A&\rightarrow A+B\\
B&\rightarrow\emptyset\end{split}

(17)

In this network, the species
A
is a catalyst. Let
[A]=[A(0)]
.
Then the dynamical system corresponding to
17
is given by

\displaystyle\frac{d[B]}{dt}=[A]-[B]

(18)

At steady state, we get

[B^{ss}]=[A]
.

4.6
Subtraction Module

The subtraction module computes
C:=\max(0,A-B)
. The reaction network corresponding to this is given by:

\begin{split}A&\rightarrow A+C\\
B&\rightarrow B+H\\
C&\rightarrow\emptyset\\
C+H&\rightarrow\emptyset\\
\end{split}

(19)

The species
A
and
B
are catalysts. Let
[A]=[A(0)]
and
[B]=[B(0)]
. Then the dynamics corresponding to network
19
is given by

\displaystyle\begin{split}\frac{d[C(t)]}{dt}&=[A]-[C(t)][H(t)]-[C(t)]\\
\frac{d[H(t)]}{dt}&=[B]-[C(t)][H(t)]\end{split}

(20)

This implies that at steady-state
[C^{ss}]=[A]-[B]
. If
[A]>[B]
, then
C=[A]-[B]
. If
[A]\leq[B]
, then
[C]=0
.

4.7
Oscillation module with doping

Oscillating molecules
[
17
,
5
,
9
]
are used for sequential execution of reactions in a network. In particular, the concentrations of these molecules oscillate such that when the concentration of a certain species is positive, the concentrations of the remaining species are zero. For example, consider the following network

\begin{aligned} O_{1}+O_{2}&\rightarrow 2O_{2}\\
\end{aligned}\qquad\begin{aligned} O_{i}+O_{i+1}&\rightarrow 2O_{i+1}\\
\end{aligned}\qquad\begin{aligned} O_{n}+O_{1}&\rightarrow 2O_{1}\\
\end{aligned}

The network contains
n
oscillating species, denoted by
O_{i}
. If a reaction contains
O_{i}
and another reaction contains
O_{j}
, such that
i<j
, then the reaction containing the oscillation molecule
O_{i}
will be executed before the reaction containing the oscillation molecule
O_{j}
.

However, these oscillations eventually die out when one of the species becomes extinct, meaning the oscillations are not perpetual. To make them perpetual, Ballarini et.al
[
5
]
. introduce the notion of a
doping reaction
for each species. A doping reaction is defined as one that generates a molecule of a species
X\in\{1,2,\dots,n\}
by consuming a molecule of a doping substance and another species.

In practical terms, the chemical equations representing the
n
-way oscillator with doping are as follows:

\begin{aligned} O_{1}+O_{2}&\rightarrow 2O_{2}\\
D_{1}+O_{n}&\rightarrow O_{1}\end{aligned}\qquad\begin{aligned} O_{i}+O_{i+1}&\rightarrow 2O_{i+1}\\
D_{i}+O_{i-1}&\rightarrow O_{i}\end{aligned}\qquad\begin{aligned} O_{n}+O_{1}&\rightarrow 2O_{1}\\
D_{n}+O_{n-1}&\rightarrow O_{n}\end{aligned}

The presence of doping species ensures that the oscillator is perpetual.

5
Encoding the feedforward module of SVM

Given an
n
-dimensional input vector
X
, and its associated label
Y
, we can use our network to determine whether it has been classified correctly or not (i.e. the associated label Y is correct or not). We can do this by computing

\displaystyle\begin{split}Y\times(W\cdot X+b)\\
\end{split}

(21)

and comparing it with 1.

We do this in a sequence of five steps:

Step 1:

We first compute the dot product of
W
and
X
. We do so by multiplying W and X pair-wise and storing the the product in
WX
(for every
i
, the product of
W_{i}
and
X_{i}
is stored in
WX_{i}
). The network below computes
WX_{i}=W_{i}\times X_{i}
.

\displaystyle\begin{split}W_{1}+X_{1}+O_{1}&\overset{1}{\longrightarrow}W_{1}+X_{1}+WX_{1}+O_{1}\\
WX_{1}+O_{1}&\overset{1}{\longrightarrow}O_{1}\\
\vdots&\\
W_{N}+X_{N}+O_{1}&\overset{1}{\longrightarrow}W_{N}+X_{N}+WX_{N}+O_{1}\\
WX_{N}+O_{1}&\overset{1}{\longrightarrow}O_{1}\end{split}

(22)

The species
W_{i},X_{i},O_{i}
are catalysts in this network. Let
[W_{i}]=[W_{i}(0)],[X_{i}]=[X_{i}(0)]
and
[O_{i}]=[O_{i}(0)]
.

The dynamical system corresponding to Equation
22
is given by

\displaystyle\frac{d[WX_{i}]}{dt}=[W_{i}][X_{i}][O_{1}]-[WX_{i}][O_{1}]

(23)

At steady state, we get
[{WX_{i}}^{ss}]=[W_{i}][X_{i}]
as required.

Step 2:

We then sum all
WX_{i}
and add the bias
b
and store the this sum in a new species, called
P
. The network below computes the following quantity:
P=(\sum_{i=1}^{N}WX_{i})+b

\displaystyle\begin{split}WX_{1}+O_{1}&\overset{1}{\longrightarrow}WX_{1}+P+O_{1}\\
\vdots&\\
WX_{N}+O_{1}&\overset{1}{\longrightarrow}WX_{N}+P+O_{1}\\
b+O_{1}&\overset{1}{\longrightarrow}b+P+O_{1}\\
P+O_{1}&\overset{1}{\longrightarrow}O_{1}\end{split}

(24)

The dynamical system corresponding to the network
24
is given by

\displaystyle\frac{d[P]}{dt}=\displaystyle\sum_{i}[W_{i}][X_{i}][O_{1}]+[b][O_{1}]-[P][O_{1}]

(25)

At steady state, we get
[P^{ss}]=\displaystyle\sum_{i}[W_{i}][X_{i}]+[b]
.

Step 3:

We first multiply
P
with
Y
and store the result in
Q
.

\displaystyle Q=Y\times P

(26)

All reactions containing
O_{1}
would be executed parallely and before other reactions. At steady state, we would have computed

\displaystyle Y\times(W\cdot X+b)

(27)

and stored the value in
Q
.

Now, we compare the value in
Q
with
1
. If the associated label is correct, then concentration of
Q
will be greater than
1
and a flag
will be set, in the form of concentration of some species converging
to
1
. We divide this comparison process into two steps, Step
4
(which
compares) and Step
5
(which sets the flag). As these steps need to
happen sequentially, we use oscillating species. Oscillation molecule
O_{2}
is used in Step
4
, whereas
O_{3}
is used in Step
5
. This ensures reactions of Step
4
finish
before Step
5
reactions begin.

\displaystyle\begin{split}P+Y+O_{1}&\overset{1}{\longrightarrow}P+Y+Q+O_{1}\\
Q+O_{1}&\overset{1}{\longrightarrow}O_{1}\end{split}

(28)

The dynamical system corresponding to network
28
is

\displaystyle\frac{d[Q]}{dt}=[P][Y][O_{1}]-[Q][O_{1}]

(29)

At steady state, we get
[Q^{ss}]=[P]\cdot[Y]
.

Step 4:

In Step
4
, we introduce the following new species:
K
,
K_{ltQ}
and
K_{gtQ}
. We will compare the concentration of
Q
with the concentration of
K
(which is set to
1
).
K_{ltQ}
and
K_{gtQ}
are flag species such that the sum of their initial concentrations is
1
.

The network that accomplishes this is given by

\displaystyle\begin{split}Q+K_{gtQ}+O_{2}&\overset{1}{\longrightarrow}K_{ltQ}+Q+O_{2}\\
K_{ltQ}+K+O_{2}&\overset{1}{\longrightarrow}K_{gtQ}+K+O_{2}\end{split}

(30)

The dynamical system corresponding to network
30
is given by

\displaystyle\begin{split}\frac{[K_{ltQ}]}{dt}&=[Q][K_{gtQ}][O_{2}]-[K_{ltQ}][K][O_{2}]\\
\frac{[K_{gtQ}]}{dt}&=-[Q][K_{gtQ}][O_{2}]+[K_{ltQ}][K][O_{2}]\end{split}

(31)

Consequently, steady-state concentrations of
K_{ltQ}
and
K_{gtQ}
will be set as follows:

\displaystyle[K_{ltQ}^{ss}]=\frac{[Q]}{[Q]+[K]}

(32)

\displaystyle[K_{gtQ}^{ss}]=\frac{[K]}{[Q]+[K]}

(33)

where
[K]=[K(0)]
and
[Q]=[Q(0)]
.

Step 5:

By end of Step
4
, we have compared
Q
and
K
, and we have set the values of
K_{ltQ}
and
K_{gtQ}
as shown above.

In Step
5
, approximate majority algorithm (see Section
4.4
) is used to detect which flag species is in majority. In particular, we try to set the flags, such that if
Q>K
, then
K_{ltQ}
converges to
1
and
K_{gtQ}
converges to
0
. If
K>Q
, then vice versa happens. The network corresponding to this is given by

\displaystyle\begin{split}K_{gtQ}+K_{ltQ}+O_{3}&\overset{1}{\longrightarrow}K_{ltQ}+B+O_{3}\\
B+K_{ltQ}+O_{3}&\overset{1}{\longrightarrow}K_{ltQ}+K_{ltQ}+O_{3}\\
K_{ltQ}+K_{gtQ}+O_{3}&\overset{1}{\longrightarrow}K_{gtQ}+B+O_{3}\\
B+K_{gtQ}+O_{3}&\overset{1}{\longrightarrow}K_{gtQ}+K_{gtQ}+O_{3}\end{split}

(34)

The dynamical system corresponding to network
34
is given by

\displaystyle\begin{split}\frac{[K_{ltQ}]}{dt}&=-[K_{gtQ}][K_{ltQ}][O_{3}]+[B][K_{ltQ}][O_{3}]\\
\frac{[dQ]}{dt}&=-[K_{gtQ}][K_{ltQ}][O_{3}]+[B][K_{gtQ}][O_{3}]\\
\frac{[dB]}{dt}&=[K_{gtQ}][K_{ltQ}][O_{3}]-[B][K_{gtQ}][O_{3}]+[K_{ltQ}][K_{gtQ}][O_{3}]-[B][K_{gtQ}][O_{3}]\end{split}

(35)

The analysis of the steady states follows from the discussion in subsection
4.4
.

After Step
5
, if
K_{ltQ}
converges to 1 and
K_{gtQ}
converges to 0, that means our associated label was correct. If the vice versa happens, that implies that associated label was wrong.

6
Learning and Gradient Descent

In this section, we flesh out the reaction network scheme for the learning (backpropagation) part of the SVM through gradient descent. In particular, this will implement Equations
4
and
5
. We describe it in the following four steps:

Step 1:

In this step, we calculate the quantity
\eta\cdot\lambda\cdot[W_{i}]
from Equation
4
and
5
. In particular, each weight
W_{i}
is multiplied by the learning parameter
\eta
and the regularization parameter
\lambda
. This update is stored in
WA_{i}
and is applied to the weight regardless of whether the outcome is correct or incorrect

\displaystyle\begin{split}O_{4}+\eta+\lambda+W_{1}&\rightarrow O_{4}+\eta+\lambda+W_{1}+WA_{1}\\
WA_{1}+O_{4}&\rightarrow O_{4}\\
O_{4}+\eta+\lambda+W_{2}&\rightarrow O_{4}+\eta+\lambda+W_{2}+WA_{2}\\
WA_{2}+O_{4}&\rightarrow O_{4}\\
\vdots&\\
O_{4}+\eta+\lambda+W_{n}&\rightarrow O_{4}+\eta+\lambda+W_{n}+WA_{n}\\
WA_{n}+O_{4}&\rightarrow O_{4}\\
\end{split}

(36)

The dynamical system corresponding to this network is

\displaystyle\frac{d[WA_{i}]}{dt}=\eta\lambda[W_{i}][O_{4}]-[WA_{i}][O_{4}]

(37)

At steady state, we get
[WA_{i}^{ss}]=\eta\cdot\lambda\cdot[W_{i}(0)]
.

Step 2:

Here, we handle conditional weight updates. In particular, we calculate the quantity
\eta\cdot[K_{gtQ}]\cdot[X_{i}]\cdot[Y]
and
\eta\cdot[K_{gtQ}]\cdot[Y]
. If the outcome is incorrect, we use
K_{gtQ}
as a catalyst with unit concentration, storing the former product in
XY_{i}
and latter in
BY
. If the outcome is correct,
K_{gtQ}
is zero, preventing any weight update.

\displaystyle\begin{split}O_{4}+\eta+Y+X_{1}+K_{gtQ}&\rightarrow O_{4}+\eta+Y+X_{1}+XY_{1}+K_{gtQ}\\
XY_{1}+O_{4}&\rightarrow O_{4}\\
\vdots&\\
O_{4}+\eta+Y+X_{n}+K_{gtQ}&\rightarrow O_{4}+\eta+Y+X_{n}+XY_{n}+K_{gtQ}\\
XY_{n}+O_{4}&\rightarrow O_{4}\\
O_{4}+\eta+Y+K_{gtQ}&\rightarrow O_{4}+\eta+Y+BY+K_{gtQ}\\
BY+O_{4}&\rightarrow O_{4}\\
\end{split}

(38)

The dynamical system corresponding to this network is

\displaystyle\frac{d[XY_{i}]}{dt}=\eta[K_{gtQ}][X_{i}][Y][O_{4}]-[XY_{i}][O_{4}]

(39)

& for bias

\displaystyle\frac{d[BY]}{dt}=\eta[K_{gtQ}][Y][O_{4}]-[BY][O_{4}]

(40)

At steady state, we get
[XY_{i}^{ss}]=\eta\cdot[K_{gtQ}]\cdot[X_{i}]\cdot[Y]
and
[BY^{ss}]=\eta\cdot[K_{gtQ}]\cdot[Y]
.

Step 3:

Note that in both equations
4
and
5
, the term
\eta\cdot\lambda\cdot[W_{i}]
is always subtracted from the weights irrespective of misclassifications. We will implement this update in the current step. In particular,
we subtract the always-updated value (
WA_{i}
) from the original weight (
W_{i}
) and store the result in
WD_{i}
.

\displaystyle\begin{split}W_{i}+O_{5}&\rightarrow O_{5}+W_{i}+WD_{i}\\
WA_{i}+O_{5}&\rightarrow O_{5}+WA_{i}+H\\
WD_{i}+O_{5}&\rightarrow O_{5}\\
WD_{i}+H+O_{5}&\rightarrow O_{5}\\
\end{split}

(41)

The dynamical system corresponding to this network is

\displaystyle\frac{d[WD_{i}]}{dt}=[W_{i}][O_{5}]-[WD_{i}][O_{5}]-[WD_{i}][H][O_{5}]

(42)

&

\displaystyle\frac{d[H]}{dt}=[WA_{i}][O_{5}]-[WD_{i}][H][O_{5}]

(43)

At steady state, we get
[H^{ss}]=[WA_{i}]/[WD_{i}]
and
[WD_{i}^{ss}]=[W_{i}]-[WA_{i}]
.

We also store the sum of the old bias
b
and the update to the bias BY in a new variable BT.

\displaystyle\begin{split}b+O_{5}&\rightarrow O_{5}+b+BT\\
BY+O_{5}&\rightarrow O_{5}+BY+BT\\
BT+O_{5}&\rightarrow O_{5}\\
\end{split}

(44)

The dynamical system corresponding to this network is

\displaystyle\frac{d[BT]}{dt}=[b][O_{5}]+[BY][O_{5}]-[BT][O_{5}]

(45)

At steady state, we get
[BT^{ss}]=[b]+[BY]
.

Step 4:

Finally, we apply the conditional weight update (
XY_{j}
) to
WD_{i}
, loading it into
W_{i}
, thus completing the final weight update.

\displaystyle\begin{split}WD_{i}+O_{6}&\rightarrow WD_{i}+O_{6}+W_{i}\\
XY_{i}+O_{6}&\rightarrow XY_{i}+O_{6}+W_{i}\\
BT+O_{6}&\rightarrow BT+O_{6}+b\\
W_{i}+O_{6}&\rightarrow O_{6}\\
b+O_{6}&\rightarrow O_{6}\\
\end{split}

(46)

The dynamical system corresponding to this network is

\displaystyle\frac{dW_{i}}{dt}=[WD_{i}][O_{6}]+[XY_{i}][O_{6}]-[W_{i}][O_{6}]

(47)

and for bias

\displaystyle\frac{db}{dt}=[BT][O_{6}]-[b][O_{6}]

(48)

At steady state, we get
[W_{i}^{ss}]=[WD_{i}]+[X][Y]
and
[b^{ss}]=[BT]
.

As a consequence, we have implemented Equations
4
and
5
and the backpropagation module is complete.

Experimental Setup

In this experiment, we aim to train a Support Vector Machine (SVM) using a computational reaction network (CRN)-based approach. Our goal is to predict the weights and bias of the SVM and compare them with the traditional machine learning implementation.

7.1
Dataset and Encoding

We generate a synthetic dataset where each sample consists of:

•

Input
(
X
): A two-dimensional vector.

•

Output
(
Y
): A binary label, either
+1
or
-1
, indicating class membership.

The dataset consists of ten data points distributed across the two classes. To represent numerical values in our computational framework, we use a dual rail encoding scheme. This encoding transforms each number into two separate values:

•

A positive component (
x_{p}
) that holds the original value if positive, or zero otherwise.

•

A negative component (
x_{n}
) that holds the approximate value of the number if it is negative, or zero otherwise.

The same encoding is applied to the output labels (
Y
) and model parameters.

7.2
Training Parameters

We train our CRN-based SVM using the following hyperparameters:

•

Regularization parameter
(
\lambda
): 0.0001

•

Number of epochs
: 500

•

Learning rate
(
\eta
): 0.002

7.3
Computational Framework

The CRN-based SVM is implemented using a system of ordinary differential equations (ODEs) that simulate biochemical reactions corresponding to arithmetic operations required for SVM optimization. The core operations include:

•

Addition and subtraction

•

Multiplication

•

Division

•

Comparison and thresholding

These operations are implemented as ODEs solved numerically using the
odeint

w_{1}
,
w_{2}
) and bias (

) are performed based on the hinge loss function, which is commonly used in SVM optimization.

9
Discussion

We have shown how to implement hard margin support vector machines using reaction networks. Our method involves implementing the feedforward and backpropagation module of the support vector machine. Towards this, we have used various sub-modules to accomplish this. In particular, these include the addition module, the subtraction module, the multiplication module, the comparison module and the approximate majority module. To handle sequential execution of reactions, we use time-scale separation, which is handled by the oscillation module coupled with doping. To handle the possibility of negative weights and biases, we make use of the dual rail encoding.

Our work intersects with several other works that have used reaction networks to implement machine learning algorithms. In particular, these include the use of reaction networks to model neural networks
[
3
]
, the use of reaction networks to implement boltzmann machines
[
20
,
21
]
and also to compute maximum likelihood estimates
[
12
]
.

Our works raises several avenues for future work and investigation.
