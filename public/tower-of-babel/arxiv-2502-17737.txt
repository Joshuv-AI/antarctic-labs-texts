Domination and multistate systems
Arne Bang Huseby

Abstract
Domination theory has been studied extensively in the context of binary monotone systems, where the structure function is a sum of products of the component state variables, and with coefficients given by the signed domination function. Using e.g., matroid theory, many useful properties of the signed domination function has been derived. In this paper we show how some of these results can be extended to multistate systems. In particular, we show how the signed domination function can be extended to such systems. Using Möbius inversion we show how the signed domination function can be expressed in terms of a multistate structure function. Moreover, using this expression we show how calculating the signed domination function of a multistate system can be reduced to calculating the signed domination function of an associated binary system. This way many results from binary theory can easily be extended to multistate theory. Keywords: Domination; Posets; Multistate systems; Matroids; Möbius functions



1
Introduction

Binary monotone systems were introduced as a model representing how the state of a system depends on the state of the components through the structure function. For an extensive introduction to binary monotone systems and reliability calculations, see
[
1
]
. A more combinatorial approach can be found in
[
7
]
. Even within the seemingly simple framework of binary monotone systems, reliability calculations are known to be computationally challenging. A standard method for calculating reliability is to identify the minimal path (or cut) sets, and then use the inclusion-exclusion method. By expanding the resulting expression, the structure function can be represented as a sum of products of the component state variables, and with coefficients given by the so-called signed domination function. For certain classes of systems, however, these coefficients follow certain patterns, and by utilising these, it is possible to compute the coefficients directly. This approach was used to analyse directed network systems where the coefficients are always either
+1
,
-1
and zero. In fact for such systems the coefficients can be derived using a simple rule based on the underlying graph. For details, see
[
32
]
and
[
30
]
. The theory of domination plays a surprising role in other calculation methods as well, such as the factoring algorithm. For undirected network systems an optimal factoring strategy can be derived based on theoretical results related to the domination invariant. See
[
31
]
. These results have later been generalised using matroid theory. See
[
18
]
,
[
19
]
,
[
20
]
and
[
21
]
.

An obvious limitation of binary monotone systems is that the system and the components are always described just as
functioning
or
failed
. In practical applications a more detailed description of the components and the system is often needed. This eventually lead to the development of the theory of multistate systems. Early attempts to this include
[
2
]
,
[
14
]
,
[
28
]
,
[
6
]
and
[
23
]
. For other early work on this, see also
[
16
]
and
[
25
]
. Currently, the theory of multistate systems is very well established as an important branch of reliability theory, and comprehensive books on this subject include
[
22
]
and
[
24
]
. With the recent development in machine learning methods, it has been shown that such methods can be used to approximate multistate structure functions. See
[
27
]
. This is indeed a very promising idea which surely will be developed further in the future.

Recently, an algebraic approach to multistate systems has emerged. In
[
17
]
a connection between multistate structure functions and monomial ideals is established. Based on this the authors show that the reliability of a multistate system can be obtained by computing the Hilbert series of the monomial ideal. An algorithm for computing this can be found in
[
4
]
. More recent papers in this area include
[
9
]
,
[
10
]
,
[
11
]
,
[
12
]
and
[
13
]
.

The present paper is very much inspired by the algebraic approach. However, the main goal is to show how the algebraic properties of multistate structure functions are connected to the signed domination function of binary monotone systems. This allows us to utilise the results from binary theory in the more general multistate framework. The results provided in the paper generalise many corresponding results for binary monotone systems. This also lays the groundwork for new efficient algorithms for multistate systems.

Basic definitions

A
multistate system
is an ordered pair
(C,\phi)
, where
C=\{1,\ldots,n\}
is the component set, and
\phi
is the structure function. Each component can be in a finite number of states. The set of possible states for component
i
is denoted by
\mathcal{S}_{i}
, where
\mathcal{S}_{i}=\{0,1,\ldots,m_{i}\}
,
i=1,\ldots,n
. The component states are ranked in the natural way such that
0
is the
worst state
where the component is completely failed, while
m_{i}
is the
best state
,
i=1,\ldots,n
. In order to simplify the notation we let
\mathfrak{C}=\mathcal{S}_{1}\times\cdots\times\mathcal{S}_{n}
denote the component state space.

We let
x_{i}
denote the state of the
i
th component,
i=1,\ldots,n
, and let
\mbox{\boldmath$x$}=(x_{1},\ldots,x_{n})
denote the
component state vector
. Thus,
x_{i}\in\mathcal{S}_{i}
,
i=1,\ldots,n
, while
\mbox{\boldmath$x$}\in\mathfrak{C}
.

Similarly, the system can be in a finite number of states, and we denote the set of possible states for the system by
\mathcal{S}=\{0,1,\ldots,M\}
. The system states are also ranked in the natural way such that
0
is the
worst state
where the system is completely failed, and
m
is the
best state
.

The structure function expresses the system state as a function of the component states:

\displaystyle\phi=\phi(\mbox{\boldmath$x$}):\mathfrak{C}\rightarrow\mathcal{S}

For a given multistate system
(C,\phi)
we also introduce the binary functions:

\displaystyle\phi_{k}=\phi_{k}(\mbox{\boldmath$x$})=\mathop{\rm\raisebox{0.1pt}{I}}(\phi(\mbox{\boldmath$x$})\geq k),\quad k=1,\ldots,M.

where
\mathop{\rm\raisebox{0.1pt}{I}}(\cdot)
denotes the indicator function. We refer to
\phi_{1},\ldots,\phi_{M}
as the
level structure functions
of the multistate system
(C,\phi)
. In particular,
\phi_{k}
is called the
k
-level structure function of
(C,\phi)
,
k=1,\ldots,M
.

A
multistate monotone system
(MMS) is a multistate system
(C,\phi)
where
\phi
is
non-decreasing
in each argument. It is easy to see that if
(C,\phi)
is a multistate monotone system, then the level structure functions are non-decreasing in each argument as well. For convenience, the ordered pairs
(C,\phi_{1}),\ldots,(C,\phi_{M})
will also be referred to as multistate monotone systems, even though the structure functions only have values in
\{0,1\}
.

3
The signed domination function

If
\mbox{\boldmath$x$}=(x_{1},\ldots,x_{n})
and
\mbox{\boldmath$y$}=(y_{1},\ldots,y_{n})
, we say that
\mbox{\boldmath$y$}\leq\mbox{\boldmath$x$}
if
y_{i}\leq x_{i}
for all
i
. Furthermore, we say that
\mbox{\boldmath$y$}<\mbox{\boldmath$x$}
if
\mbox{\boldmath$y$}\leq\mbox{\boldmath$x$}
and
y_{i}<x_{i}
for at least one
i
. If
\mbox{\boldmath$x$}\neq\mbox{\boldmath$y$}
are such that neither
\mbox{\boldmath$y$}\leq\mbox{\boldmath$x$}
nor
\mbox{\boldmath$x$}\leq\mbox{\boldmath$y$}
, we say that
x
and
y
are
incomparable
.

If
x
and
y
are two numbers we denote the maximum value of
x
and
y
by
x\vee y
. If
\mbox{\boldmath$x$}=(x_{1},\ldots,x_{n})
and
\mbox{\boldmath$y$}=(y_{1},\ldots,y_{n})
are two vectors, we let:

\displaystyle\mbox{\boldmath$x$}\vee\mbox{\boldmath$y$}=(x_{1}\vee y_{1},\ldots,x_{n}\vee y_{n})

If
\mathfrak{X}=\{\mbox{\boldmath$x$}_{1},\ldots,\mbox{\boldmath$x$}_{s}\}
is a set of incomparable vectors, we define
\mathop{\rm cl}(\mathfrak{X})
as the minimal set of vectors containing
\mbox{\boldmath$x$}_{1},\ldots,\mbox{\boldmath$x$}_{s}
which is closed under the
\vee
-operator. That is, if
\mbox{\boldmath$x$},\mbox{\boldmath$y$}\in\mathop{\rm cl}(\mathfrak{X})
, then
\mbox{\boldmath$x$}\vee\mbox{\boldmath$y$}\in\mathop{\rm cl}(\mathfrak{X})
as well. The set
\mathop{\rm cl}(\mathfrak{X})
is a
partially ordered set
(poset) with respect to the vector ordering defined above, where
\mbox{\boldmath$x$}_{1},\ldots,\mbox{\boldmath$x$}_{s}
are the minimal elements, and
\mbox{\boldmath$x$}_{1}\vee\cdots\vee\mbox{\boldmath$x$}_{s}
is the maximal element. We refer to
\mathop{\rm cl}(\mathfrak{X})
as the poset
generated
by the minimal elements
\mbox{\boldmath$x$}_{1},\ldots,\mbox{\boldmath$x$}_{s}
.

It follows that if
\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{X})
, there must exist minimal vectors
\mbox{\boldmath$x$}_{i_{1}},\ldots,\mbox{\boldmath$x$}_{i_{j}}\in\mathfrak{X}
such that
\mbox{\boldmath$x$}=\mbox{\boldmath$x$}_{i_{1}}\vee\cdots\vee\mbox{\boldmath$x$}_{i_{j}}
. The set
\{\mbox{\boldmath$x$}_{i_{1}},\ldots,\mbox{\boldmath$x$}_{i_{j}}\}
is called a
formation
of
x
. If
j
is odd, the formation is said to be
odd
, while if
j
is even, the formation is said to be
even
. Note that a vector
\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{X})
may have more than one formation. In order to keep track of these formations, the following function is useful:

\displaystyle\delta(\mbox{\boldmath$x$})

\displaystyle=\mbox{The number of odd formations of $\mbox{\boldmath$x$}$}

(1)

\displaystyle-\mbox{The number of even formations of $\mbox{\boldmath$x$}$},\quad\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{X})

The function
\delta
is called the
signed domination function
of the poset
\mathop{\rm cl}(\mathfrak{X})
, and satisfies the following:

Proposition 3.1

Let
\mathfrak{X}=\{\mbox{\boldmath$x$}_{1},\ldots,\mbox{\boldmath$x$}_{s}\}
and
\mathfrak{Y}=\{\mbox{\boldmath$y$}_{1},\ldots,\mbox{\boldmath$y$}_{s}\}
be two sets of incomparable vectors such that the posets
\mathop{\rm cl}(\mathfrak{X})
and
\mathop{\rm cl}(\mathfrak{Y})
are isomorphic, i.e., there exists a bijective mapping
\psi:\mathop{\rm cl}(\mathfrak{X})\rightarrow\mathop{\rm cl}(\mathfrak{Y})
which preserves the ordering of vectors. Moreover, let
\delta
be the signed domination function of
\mathop{\rm cl}(\mathfrak{X})
and
\gamma
be the signed domination function of
\mathop{\rm cl}(\mathfrak{Y})
. Then we have:

\displaystyle\gamma(\psi(\mbox{\boldmath$x$}))=\delta(\mbox{\boldmath$x$}),\quad\mbox{ for all }\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{X}).

Proof:
Let
\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{X})
, and assume that
\mbox{\boldmath$x$}_{i_{1}},\ldots,\mbox{\boldmath$x$}_{i_{j}}
is a formation of
x
, i.e.,
\mbox{\boldmath$x$}=\mbox{\boldmath$x$}_{i_{1}}\vee\cdots\vee\mbox{\boldmath$x$}_{i_{j}}
. This implies that:

\displaystyle\mbox{\boldmath$x$}\geq\mbox{\boldmath$x$}_{i_{r}},\quad r=1,\ldots,j.

Since the mapping
\psi
preserves the ordering of vectors, this implies that:

\displaystyle\psi(\mbox{\boldmath$x$})\geq\psi(\mbox{\boldmath$x$}_{i_{r}}),\quad r=1,\ldots,j.

Hence, it follows that:

\displaystyle\psi(\mbox{\boldmath$x$})\geq\psi(\mbox{\boldmath$x$}_{i_{1}})\vee\cdots\vee\psi(\mbox{\boldmath$x$}_{i_{j}}).

(2)

We then let
\mbox{\boldmath$y$}=\psi(\mbox{\boldmath$x$}_{i_{1}})\vee\cdots\vee\psi(\mbox{\boldmath$x$}_{i_{j}})
. This implies that:

\displaystyle\mbox{\boldmath$y$}\geq\psi(\mbox{\boldmath$x$}_{i_{r}}),\quad r=1,\ldots,j.

Since the mapping
\psi
preserves the ordering of vectors, then so does its inverse,
\psi^{-1}
, and this implies that:

\displaystyle\mbox{\boldmath$x$}^{\prime}=\psi^{-1}(\mbox{\boldmath$y$})\geq\psi^{-1}(\psi(\mbox{\boldmath$x$}_{i_{r}}))=\mbox{\boldmath$x$}_{i_{r}},\quad r=1,\ldots,j.

Hence, it follows that:

\displaystyle\mbox{\boldmath$x$}^{\prime}\geq\mbox{\boldmath$x$}_{i_{1}}\vee\cdots\vee\mbox{\boldmath$x$}_{i_{j}}=\mbox{\boldmath$x$}

Using once again that
\psi
preserves the ordering of vectors, this implies that:

\displaystyle\psi(\mbox{\boldmath$x$})\leq\psi(\mbox{\boldmath$x$}^{\prime})=\mbox{\boldmath$y$}=\psi(\mbox{\boldmath$x$}_{i_{1}})\vee\cdots\vee\psi(\mbox{\boldmath$x$}_{i_{j}})

(3)

By combining (
2
) and (
3
), we get that:

\displaystyle\psi(\mbox{\boldmath$x$})=\psi(\mbox{\boldmath$x$}_{i_{1}})\vee\cdots\vee\psi(\mbox{\boldmath$x$}_{i_{j}}).

(4)

Thus, if
\mbox{\boldmath$x$}_{i_{1}},\ldots,\mbox{\boldmath$x$}_{i_{j}}
is a formation of
x
, then
\psi(\mbox{\boldmath$x$}_{i_{1}}),\ldots,\psi(\mbox{\boldmath$x$}_{i_{j}})
is a formation of
\psi(\mbox{\boldmath$x$})
. Conversely, using the same arguments, it follows that if
\psi(\mbox{\boldmath$x$}_{i_{1}}),\ldots,\psi(\mbox{\boldmath$x$}_{i_{j}})
is a formation of
\psi(\mbox{\boldmath$x$})
, then
\mbox{\boldmath$x$}_{i_{1}},\ldots,\mbox{\boldmath$x$}_{i_{j}}
is a formation of
x
. From this it follows that the number of odd formations of
x
is equal to the number of odd formations of
\psi(\mbox{\boldmath$x$})
, and the number of even formations of
x
is equal to the number of even formations of
\psi(\mbox{\boldmath$x$})
. Hence,
\gamma(\psi(\mbox{\boldmath$x$}))=\delta(\mbox{\boldmath$x$})
as claimed
\,\blacksquare

By Proposition
1
it follows that the signed domination function is an
invariant
of posets. That is, if two posets are isomorphic, then their signed domination functions are equal.

The concepts of domination and signed domination originated in the ground-breaking papers
[
32
]
and
[
31
]
, and other related papers from the same period. The concept was studied further in the context of matroids and oriented matroids in the papers
[
18
]
,
[
19
]
,
[
20
]
and
[
21
]
.

We say that
\mbox{\boldmath$x$}\in\mathfrak{C}
is a
k
-level
path vector
of an MMS,
(C,\phi)
, if
\phi(\mbox{\boldmath$x$})\geq k
(or equivalently if
\phi_{k}(\mbox{\boldmath$x$})=1
). Moreover,
x
is a
minimal

k
-level
path vector
of
(C,\phi)
if we also have that
\phi(\mbox{\boldmath$y$})<k
(or equivalently if
\phi_{k}(\mbox{\boldmath$y$})=0
) for all vectors
\mbox{\boldmath$y$}\in\mathfrak{C}
such that
\mbox{\boldmath$y$}<\mbox{\boldmath$x$}
.

For a given MMS
(C,\phi)
we let
\mathfrak{P}_{k}=\{\mbox{\boldmath$x$}_{1},\ldots,\mbox{\boldmath$x$}_{s}\}
denote the set of minimal
k
-level path vectors. Obviously,
\phi_{k}(\mbox{\boldmath$y$})=1
if and only if
\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$}_{r}
for at least one of the minimal path vectors. Thus, the
k
-level structure function,
\phi_{k}
can be written as:

\displaystyle\phi_{k}(\mbox{\boldmath$y$})=\mathop{\rm\raisebox{0.1pt}{I}}(\bigcup_{r=1}^{s}\{\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$}_{r}\}),\quad\mbox{ for all }\mbox{\boldmath$y$}\in\mathfrak{C}.

(5)

Moreover, we note that if
\mbox{\boldmath$x$}_{i_{1}},\ldots,\mbox{\boldmath$x$}_{i_{j}}\in\mathfrak{P}_{k}
, then

\displaystyle\{\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$}_{i_{1}}\}\cap\cdots\cap\{\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$}_{i_{j}}\}=\{\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$}_{i_{1}}\vee\cdots\vee\mbox{\boldmath$x$}_{i_{j}}\}

Hence, by the inclusion-exclusion formula it follows that:

\displaystyle\phi_{k}(\mbox{\boldmath$y$})

\displaystyle=\mathop{\rm\raisebox{0.1pt}{I}}(\{\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$}_{1}\})+\cdots+\mathop{\rm\raisebox{0.1pt}{I}}(\{\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$}_{s}\})

(6)

\displaystyle-\mathop{\rm\raisebox{0.1pt}{I}}(\{\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$}_{1}\vee\mbox{\boldmath$x$}_{2}\})-\cdots-\mathop{\rm\raisebox{0.1pt}{I}}(\{\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$}_{s-1}\vee\mbox{\boldmath$x$}_{s}\})

\displaystyle+\mathop{\rm\raisebox{0.1pt}{I}}(\{\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$}_{1}\vee\mbox{\boldmath$x$}_{2}\vee\mbox{\boldmath$x$}_{3}\})+\cdots+\mathop{\rm\raisebox{0.1pt}{I}}(\{\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$}_{s-2}\vee\mbox{\boldmath$x$}_{s-1}\vee\mbox{\boldmath$x$}_{s}\})

\displaystyle-\cdots

\displaystyle+(-1)^{s-1}\mathop{\rm\raisebox{0.1pt}{I}}(\{\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$}_{1}\vee\cdots\vee\mbox{\boldmath$x$}_{s}\}),\quad\mbox{for all }\mbox{\boldmath$y$}\in\mathfrak{C}.

The following result shows how the signed domination function of a poset is connected to the
k
-level structure function of an MMS:

Teorem 3.2

Let
(C,\phi)
be an MMS, and let
\mathfrak{P}_{k}=\{\mbox{\boldmath$x$}_{1},\ldots,\mbox{\boldmath$x$}_{s}\}
denote the set of minimal
k
-level path vectors. The
k
-level structure function,
\phi_{k}
can then be written as:

\displaystyle\phi_{k}(\mbox{\boldmath$y$})=\sum_{\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{P}_{k})}\delta_{k}(\mbox{\boldmath$x$})\mathop{\rm\raisebox{0.1pt}{I}}(\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$}),\quad\mbox{ for all }\mbox{\boldmath$y$}\in\mathfrak{C}.

(7)

where
\delta_{k}
is the signed domination function of
\mathop{\rm cl}(\mathfrak{P}_{k})
, referred to as the
k
-level signed domination function of
(C,\phi)
.

Proof:
We start out by observing that all terms in (
6
) are of the form:

\displaystyle(-1)^{r-1}\mathop{\rm\raisebox{0.1pt}{I}}(\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$}_{i_{1}}\vee\cdots\vee\mbox{\boldmath$x$}_{i_{r}}),

where the odd formations have a coefficient of
(-1)^{r-1}=+1
, while the even formations have a coefficient of
(-1)^{r-1}=-1
. For each
\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{P}_{k})
we merge all terms corresponding to formations of
x
. The merged term has a coefficient which is equal to the number of odd formations minus the number of even formations, which by definition is equal to
\delta_{k}(\mbox{\boldmath$x$})
. Thus, it follows that
\phi_{k}(\mbox{\boldmath$y$})
satisfies (
7
)
\,\blacksquare

Corollary 3.3

Let
(C,\phi)
be an MMS, and let
\mathfrak{P}_{k}=\{\mbox{\boldmath$x$}_{1},\ldots,\mbox{\boldmath$x$}_{s}\}
denote the set of minimal
k
-level path vectors. Then we have:

\displaystyle\phi_{k}(\mbox{\boldmath$y$})=\sum_{\mbox{\boldmath$x$}\leq\mbox{\boldmath$y$}}\delta_{k}(\mbox{\boldmath$x$}),\quad\mbox{ for all }\mbox{\boldmath$y$}\in\mathop{\rm cl}(\mathfrak{P}_{k}),

(8)

where the sum in (
8
) is restricted to vectors
\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{P}_{k})
.

Proof:
The result follows directly from Theorem
3.2
by noting the obvious fact that
\mathop{\rm\raisebox{0.1pt}{I}}(\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$})=1
for all
\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{P}_{k})
such that
\mbox{\boldmath$x$}\leq\mbox{\boldmath$y$}
, and
\mathop{\rm\raisebox{0.1pt}{I}}(\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$})=0
for all
\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{P}_{k})
such that
\mbox{\boldmath$x$}\leq\mbox{\boldmath$y$}
does not hold
\,\blacksquare

Note that since
\phi_{k}(\mbox{\boldmath$y$})=1
for all
\mbox{\boldmath$y$}\in\mathop{\rm cl}(\mathfrak{P}_{k})
, (
8
) implies that:

\displaystyle\sum_{\mbox{\boldmath$x$}\leq\mbox{\boldmath$y$}}\delta_{k}(\mbox{\boldmath$x$})=1,\quad\mbox{ for all }\mbox{\boldmath$y$}\in\mathop{\rm cl}(\mathfrak{P}_{k}),

(9)

where again the sum in (
9
) is restricted to vectors
\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{P}_{k})
.

Before we proceed we note that if
Y_{1},\ldots,Y_{n}
are random variables with state spaces
\mathcal{S}_{1},\ldots,\mathcal{S}_{n}
respectively, and
\mbox{\boldmath$Y$}=(Y_{1},\ldots,Y_{n})
, then it follows by (
7
) that the resulting reliability of the system
(C,\phi_{k})
is given by:

\displaystyle P(\phi_{k}(\mbox{\boldmath$Y$})=1)\,=\,E[\phi_{k}(\mbox{\boldmath$Y$})]\,=\,\sum_{\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{P}_{k})}\delta_{k}(\mbox{\boldmath$x$})P(\mbox{\boldmath$Y$}\geq\mbox{\boldmath$x$})

Thus, given the signed domination function
\delta_{k}
and the joint distribution of
Y_{1},\ldots,Y_{n}
, we may calculate the system reliability.

We also note that in the binary case, i.e., where
\mathcal{S}_{1}=\cdots=\mathcal{S}_{n}=\{0,1\}
, we have:

\displaystyle\mathop{\rm\raisebox{0.1pt}{I}}(\mbox{\boldmath$y$}\geq\mbox{\boldmath$x$})\,=\,\mathop{\rm\raisebox{0.1pt}{I}}(\bigcap_{i=1}^{n}y_{i}\geq x_{i})\,=\,\prod_{i=1}^{n}y_{i}^{x_{i}},

where we define
y_{i}^{0}=1
for all values of
y_{i}
, including
y_{i}=0
,
i=1,\ldots,n
. Hence, it follows that in this case (
7
) may alternatively be written as:

\displaystyle\phi_{k}(\mbox{\boldmath$y$})=\sum_{\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{P}_{k})}\delta_{k}(\mbox{\boldmath$x$})\prod_{i=1}^{n}y_{i}^{x_{i}},\quad\mbox{ for all }\mbox{\boldmath$y$}\in\mathfrak{C}.

(10)

In the context of monomial ideals and Hilbert series, it is convenient to extend (
10
) to multistate systems. In order to avoid confusion, we use a different notation for this generalized function:

\displaystyle H_{k}(\mbox{\boldmath$y$})=\sum_{\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{P}_{k})}\delta_{k}(\mbox{\boldmath$x$})\prod_{i=1}^{n}y_{i}^{x_{i}},\quad\mbox{ for all }\mbox{\boldmath$y$}\in\mathfrak{C},

(11)

where we again define
y_{i}^{0}=1
for all values of
y_{i}
. See
[
11
]
. In the binary case we obviously have
H_{k}(\mbox{\boldmath$y$})=\phi_{k}(\mbox{\boldmath$y$})
. In the multistate case, however, this does not hold. Still there is clearly a one-to-one correspondence between
H_{k}(\mbox{\boldmath$y$})
and the structure function
\phi_{k}(\mbox{\boldmath$y$})
. In particular, both functions share the same signed domination function. Thus, reliability calculations may just as easy be based on
H_{k}(\mbox{\boldmath$y$})
as on the structure function. By using
H_{k}(\mbox{\boldmath$y$})
instead of the structure function fast algorithms for Hilbert series can be applied directly in the reliability calculations. In the present paper, however, we will focus on the connection between the structure function and the signed domination function.

Example 3.4

Consider an MMS
(C,\phi)
with the set of minimal
k
-level path vectors
\mathfrak{P}_{k}=\{\mbox{\boldmath$x$}_{1},\mbox{\boldmath$x$}_{2},\mbox{\boldmath$x$}_{3},\mbox{\boldmath$x$}_{4}\}
where:

\displaystyle\mbox{\boldmath$x$}_{1}=(2,1,1,0),\,\,\,\mbox{\boldmath$x$}_{2}=(1,2,0,1),\,\,\,\mbox{\boldmath$x$}_{3}=(1,0,2,1),\,\,\,\mbox{\boldmath$x$}_{4}=(0,1,1,2)

This implies that:

\displaystyle\mbox{\boldmath$x$}_{1}\vee\mbox{\boldmath$x$}_{2}

\displaystyle=(2,2,1,1),\,\,\,\mbox{\boldmath$x$}_{1}\vee\mbox{\boldmath$x$}_{3}=(2,1,2,1),\,\,\,\mbox{\boldmath$x$}_{1}\vee\mbox{\boldmath$x$}_{4}=(2,1,1,2),

\displaystyle\mbox{\boldmath$x$}_{2}\vee\mbox{\boldmath$x$}_{3}

\displaystyle=(1,2,2,1),\,\,\,\mbox{\boldmath$x$}_{2}\vee\mbox{\boldmath$x$}_{4}=(1,2,1,2),\,\,\,\mbox{\boldmath$x$}_{3}\vee\mbox{\boldmath$x$}_{4}=(1,1,2,2).

Furthermore, we have:

\displaystyle\mbox{\boldmath$x$}_{1}\vee\mbox{\boldmath$x$}_{2}\vee\mbox{\boldmath$x$}_{3}

\displaystyle=(2,2,2,1),\,\,\,\mbox{\boldmath$x$}_{1}\vee\mbox{\boldmath$x$}_{2}\vee\mbox{\boldmath$x$}_{4}=(2,2,1,2),

\displaystyle\mbox{\boldmath$x$}_{1}\vee\mbox{\boldmath$x$}_{3}\vee\mbox{\boldmath$x$}_{4}

\displaystyle=(2,1,2,2),\,\,\,\mbox{\boldmath$x$}_{2}\vee\mbox{\boldmath$x$}_{3}\vee\mbox{\boldmath$x$}_{4}=(1,2,2,2),

and finally, we have:

\displaystyle\mbox{\boldmath$x$}_{1}\vee\mbox{\boldmath$x$}_{2}\vee\mbox{\boldmath$x$}_{3}\vee\mbox{\boldmath$x$}_{4}=(2,2,2,2)

Since all these
15
vectors are distinct, it follows that each element in
\mathop{\rm cl}(\mathfrak{P}_{k})
has exactly
one
formation. Thus, we get:

\displaystyle\delta_{k}(\mbox{\boldmath$x$}_{i_{1}})

\displaystyle=+1,\quad 1\leq i_{1}\leq 4

\displaystyle\delta_{k}(\mbox{\boldmath$x$}_{i_{1}}\vee\mbox{\boldmath$x$}_{i_{2}})

\displaystyle=-1,\quad 1\leq i_{1}<i_{2}\leq 4

\displaystyle\delta_{k}(\mbox{\boldmath$x$}_{i_{1}}\vee\mbox{\boldmath$x$}_{i_{2}}\vee\mbox{\boldmath$x$}_{i_{3}})

\displaystyle=+1,\quad 1\leq i_{1}<i_{2}<i_{3}\leq 4

\displaystyle\delta_{k}(\mbox{\boldmath$x$}_{1}\vee\mbox{\boldmath$x$}_{2}\vee\mbox{\boldmath$x$}_{3}\vee\mbox{\boldmath$x$}_{4})

\displaystyle=-1

\,\blacksquare

So far we have defined the signed domination function,
\delta_{k}
, for all
\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{P}_{k})
. However, it is convenient to extend the definition of the function to the larger poset
\mathfrak{C}=\mathcal{S}_{1}\times\cdots\times\mathcal{S}_{n}
. If
\mbox{\boldmath$x$}\notin\mathop{\rm cl}(\mathfrak{P}_{k})
, obviously
x
does not have
any formations
. Thus, by extension, (
1
) implies that
\delta_{k}(\mbox{\boldmath$x$})=0
for all
\mbox{\boldmath$x$}\notin\mathop{\rm cl}(\mathfrak{P}_{k})
. Extending
\delta_{k}
in this way ensures that we still have:

\displaystyle\phi_{k}(\mbox{\boldmath$y$})=\sum_{\mbox{\boldmath$x$}\leq\mbox{\boldmath$y$}}\delta_{k}(\mbox{\boldmath$x$}),\quad\mbox{ for all }\mbox{\boldmath$y$}\in\mathfrak{C},

(12)

but where the sum now ranges over
all

\mbox{\boldmath$x$}\in\mathfrak{C}
such that
\mbox{\boldmath$x$}\leq\mbox{\boldmath$y$}
.

Of special interest is the signed domination of the maximal element of
\mathfrak{C}
, i.e.,
\mbox{\boldmath$m$}=(m_{1},\ldots,m_{n})
. This is referred to as the
signed domination
of the corresponding structure function
\phi_{k}
, and is denoted by
d(\phi_{k})
. Thus, we have:

\displaystyle d(\phi_{k})=\delta_{k}(\mbox{\boldmath$m$}).

(13)

Note that it may happen that
\mbox{\boldmath$m$}\notin\mathop{\rm cl}(\mathfrak{P}_{k})
in which case
d(\phi_{k})=0
. This property is related to the concepts of
relevance
and
coherence
, well-known from the theory of binary monotone systems. In the multistate case these concepts become a bit more elaborate. Let
i\in C
, and let
r\in\{1,\ldots,m_{i}\}
. We say that component
i
is
r
-relevant
with respect to
\phi_{k}
if there exists some minimal path vector vector
\mbox{\boldmath$x$}\in\mathfrak{P}_{k}
such that
x_{i}=r
. In particular, if component
i
is
m_{i}
-relevant with respect to
\phi_{k}
, component
i
is said to be
strongly relevant
with respect to
\phi_{k}
. If
i
is
not

r
-relevant for any
r\in\{1,\ldots,m_{i}\}
, component
i
is said to be
irrelevant
with respect to
\phi_{k}
.

The MMS
(C,\phi_{k})
is said to be
strongly coherent
if all the components are strongly relevant with respect to
\phi_{k}
. Based on the notion of coherency, the following result is immediate:

Proposition 3.5

If
(C,\phi_{k})
is
not
strongly coherent, then
d(\phi_{k})=0
.

We observe that component relevance, as defined above, always relates to a
specific
level
k
. A component may be irrelevant with respect to one level, but strongly relevant with respect to another. Note also that if component
i
is
r
-relevant with respect to
\phi_{k}
, it may still happen that
i
is
not

r^{\prime}
-relevant for some
r^{\prime}<r
. If we are focussing on a specific level
k
, and there are no irrelevant components, the system
(C,\phi_{k})
can be made strongly coherent simply by temporarily reducing the component state sets so that all the components become strongly relevant.

In the binary case we obviously have
\mbox{\boldmath$m$}=\mbox{\boldmath$1$}
. This implies that the components are either
1
-relevant or irrelevant. In this case we may use the simplified term
relevant
instead of
1
-relevant. Moreover, component
i
is relevant if and only if there exists a minimal path vector
x
such that
x_{i}=1
. Equivalently, a component is relevant if and only if it is contained in at least one minimal path set. A binary system is coherent if and only if all components are contained in at least one minimal path set.

Note that Proposition
3.5
implies that strong coherency is a
necessary
condition for non-zero the signed domination. As we shall see later, it is not a sufficient condition. Indeed we will present examples of strongly coherent MMS’s with zero domination.

4
Möbius inversion

The signed domination function can be analyzed using
Möbius inversion
. To explain this we again consider an MMS
(C,\phi)
and let
\mathfrak{P}_{k}
denote the set of minimal
k
-level path vectors. For the poset
\mathop{\rm cl}(\mathfrak{P}_{k})
we introduce the
Möbius function
,
\mu_{k}(\cdot,\cdot)
, defined recursively for all
\mbox{\boldmath$x$}\leq\mbox{\boldmath$y$}\in\mathop{\rm cl}(\mathfrak{P}_{k})
as follows:

\displaystyle\mu_{k}(\mbox{\boldmath$x$},\mbox{\boldmath$x$})

\displaystyle=1,\quad\mbox{ for all }\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{P}_{k}),

\displaystyle\mu_{k}(\mbox{\boldmath$x$},\mbox{\boldmath$y$})

\displaystyle=-\sum_{\mbox{\boldmath$x$}\leq\mbox{\boldmath$u$}<\mbox{\boldmath$y$}}\mu_{k}(\mbox{\boldmath$x$},\mbox{\boldmath$u$}),\quad\mbox{ for all }\mbox{\boldmath$x$}<\mbox{\boldmath$y$}\in\mathop{\rm cl}(\mathfrak{P}_{k})

Then by (
8
) and the well-known Möbius inversion formula (see
[
29
]
) we get that:

\displaystyle\delta_{k}(\mbox{\boldmath$y$})=\sum_{\mbox{\boldmath$x$}\leq\mbox{\boldmath$y$}}\phi_{k}(\mbox{\boldmath$x$})\mu_{k}(\mbox{\boldmath$x$},\mbox{\boldmath$y$}),\quad\mbox{ for all }\mbox{\boldmath$y$}\in\mathop{\rm cl}(\mathfrak{P}_{k}),

(14)

where again the sum in (
14
) is restricted to vectors
\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{P}_{k})
. Since
\phi_{k}(\mbox{\boldmath$x$})=1
for all
\mbox{\boldmath$x$}\in\mathop{\rm cl}(\mathfrak{P}_{k})
, (
14
) can be simplified to:

\displaystyle\delta_{k}(\mbox{\boldmath$y$})=\sum_{\mbox{\boldmath$x$}\leq\mbox{\boldmath$y$}}\mu_{k}(\mbox{\boldmath$x$},\mbox{\boldmath$y$}),\quad\mbox{ for all }\mbox{\boldmath$y$}\in\mathop{\rm cl}(\mathfrak{P}_{k}),

(15)

A difficulty with this approach, however, is that finding the
Möbius function
,
\mu_{k}(\cdot,\cdot)
for a given poset
\mathop{\rm cl}(\mathfrak{P}_{k})
is not straightforward in general. Many important results on signed domination functions can instead be obtained by working with the larger poset
\mathfrak{C}
instead. For this poset it is possible to derive a simple explicit expression for the Möbius function. Since this function is not limited to the chosen level
k
, we denote this simply by
\mu(\cdot,\cdot)
. In order to derive
\mu(\cdot,\cdot)
we use the following property of Möbius functions given in
[
29
]
:

Proposition 4.1

Let
\mathcal{T}_{1},\ldots,\mathcal{T}_{r}
be finite posets with Möbius functions
\mu_{1},\ldots,\mu_{r}
respectively. Then the Möbius function
\mu
of the poset
\mathcal{T}_{1}\times\cdots\times\mathcal{T}_{r}
is the product of
\mu_{1},\ldots,\mu_{r}
.

In order to apply Proposition
4.1
we note that the poset
\mathfrak{C}
is equal to the direct product
\mathcal{S}_{1}\times\cdots\times\mathcal{S}_{n}
. We denote the Möbius functions of
\mathcal{S}_{1},\ldots,\mathcal{S}_{n}
by
\mu_{1},\ldots,\mu_{n}
respectively. It is easy to verify that if
x_{i},y_{i}\in\mathcal{S}_{i}
is such that
x_{i}\leq y_{i}
,
i=1,\ldots,n
, then:

\displaystyle\mu_{i}(x_{i},y_{i})=\begin{cases}(-1)^{y_{i}-x_{i}}&\mbox{ if }x_{i}\leq y_{i}\leq x_{i}+1\\[5.69054pt]
0\quad&\mbox{ otherwise}\end{cases}

Hence, it follows immediately by Proposition
4.1
that if
\mbox{\boldmath$x$},\mbox{\boldmath$y$}\in\mathfrak{C}
is such that
\mbox{\boldmath$x$}\leq\mbox{\boldmath$y$}
, then:

\displaystyle\mu(\mbox{\boldmath$x$},\mbox{\boldmath$y$})=\begin{cases}(-1)^{\sum_{i=1}^{n}(y_{i}-x_{i})}&\mbox{ if }x_{i}\leq y_{i}\leq x_{i}+1,\,i=1,\ldots,n.\\[5.69054pt]
0&\mbox{ otherwise}\end{cases}

(16)

See
[
3
]
for further details on this.

We can now use the Möbius function (
16
) to derive an explicit expression for the signed domination function
\delta_{k}
. For this to work we must extend the definition of
\delta_{k}
from the poset
\mathop{\rm cl}(\mathfrak{P}_{k})
to the larger poset
\mathfrak{C}
. From (
12
) it follows by Möbius inversion that we have:

\displaystyle\delta_{k}(\mbox{\boldmath$y$})=\sum_{\mbox{\boldmath$x$}\leq\mbox{\boldmath$y$}}\phi_{k}(\mbox{\boldmath$x$})\mu(\mbox{\boldmath$x$},\mbox{\boldmath$y$}),\quad\mbox{ for all }\mbox{\boldmath$y$}\in\mathfrak{C},

(17)

where the Möbius function
\mu(\cdot,\cdot)
is given by (
16
). A more explicit formula is given in the following result:

Teorem 4.2

Let
(C,\phi)
be an MMS with component state space
\mathfrak{C}
and system state space
\mathcal{S}
. For any
\mbox{\boldmath$y$}\in\mathfrak{C}\setminus\{\mbox{\boldmath$0$}\}
we let
A(\mbox{\boldmath$y$})=\{i:y_{i}>0\}
. Furthermore, for any subset
B\subseteq A(\mbox{\boldmath$y$})
we define
\mbox{\boldmath$x$}(B)=(x_{1}(B),\ldots,x_{n}(B))
by:

\displaystyle x_{i}(B)=\begin{cases}y_{i}\quad&\mbox{ for all }i\in B\\[5.69054pt]
y_{i}-1\quad&\mbox{ for all }i\in A(\mbox{\boldmath$y$})\setminus B\\[5.69054pt]
0\quad&\mbox{ otherwise}\end{cases}

(18)

Then for
k\in\{1,\ldots,M\}
, the signed domination function
\delta_{k}
is given by:

\displaystyle\delta_{k}(\mbox{\boldmath$y$})=\sum_{B\subseteq A(\mbox{\boldmath$y$})}\phi_{k}(\mbox{\boldmath$x$}(B))(-1)^{|A(\mbox{\boldmath$y$})|-|B|}

(19)

Proof:
We start out by noting that the Möbius function
\mu(\mbox{\boldmath$x$},\mbox{\boldmath$y$})
given by (
16
) is non-zero if and only if
x
satisfies:

\displaystyle y_{i}-1\leq x_{i}\leq y_{i},\quad i=1,\ldots,n.

(20)

Moreover, any
x
satisfying (
20
) is of the form
\mbox{\boldmath$x$}(B)
where
B
is a subset of
A(\mbox{\boldmath$y$})
. Hence, there is a one-to-one correspondence between the vectors
\mbox{\boldmath$x$}\leq\mbox{\boldmath$y$}
such that
\mu(\mbox{\boldmath$x$},\mbox{\boldmath$y$})\neq 0
and the subsets
B
of
A(\mbox{\boldmath$y$})
. Finally, if
\mbox{\boldmath$x$}=\mbox{\boldmath$x$}(B)
where
B\subseteq A(\mbox{\boldmath$y$})
, then:

\displaystyle\sum_{i=1}^{n}(y_{i}-x_{i})=\sum_{i\in A(\mbox{\boldmath$y$})}(y_{i}-x_{i})=|A(\mbox{\boldmath$y$})\setminus B|=|A(\mbox{\boldmath$y$})|-|B|

(21)

Hence, it follows that:

\displaystyle\mu(\mbox{\boldmath$x$},\mbox{\boldmath$y$})=(-1)^{|A(\mbox{\boldmath$y$})|-|B|},\quad\mbox{ for all }B\subseteq A(\mbox{\boldmath$y$}),\mbox{ and }\mbox{\boldmath$x$}=\mbox{\boldmath$x$}(B)

(22)

By inserting (
22
) into (
17
), the expression (
19
) follows
\,\blacksquare

In the
binary case
, i.e., when
\mathcal{S}_{i}=\{0,1\}
,
i=1,\ldots,n
, there is a one-to-one correspondence between subsets
A
of the component set
C
and state vectors
\mbox{\boldmath$x$}\in\{0,1\}^{n}
:

\displaystyle A

\displaystyle=A(\mbox{\boldmath$x$})=\{i:x_{i}=1\},

x

\displaystyle=\mbox{\boldmath$x$}(A)=(\mbox{\boldmath$1$}^{A},\mbox{\boldmath$0$}^{C\setminus A})

In this case the
1
-level structure function
\phi_{1}
is equal to the structure function
\phi
, and consequently the signed domination function
\delta_{1}
is equal to the signed domination function,
\delta
, of
\phi
. Both
\phi
and
\delta
can be expressed as functions of subsets of
C
, and the formula (
19
) can be written in the following simplified form:

\displaystyle\delta(A)=\sum_{B\subseteq A}\phi(B)(-1)^{|A|-|B|},\quad\mbox{ for all }A\subseteq C.

(23)

This classical result was proved in
[
18
]
.

As a corollary to Theorem
4.2
we have the following result:

Corollary 4.3

Let
(C,\phi)
be an MMS with system state space
\mathcal{S}
, and where the set of states of component
i
is
\mathcal{S}_{i}=\{0,1,\ldots,m_{i}\}
,
i=1,\ldots,n
. For any subset
B\subseteq C
we define
\mbox{\boldmath$x$}(B)=(x_{1}(B),\ldots,x_{n}(B))
by:

\displaystyle x_{i}(B)=\begin{cases}m_{i}&\mbox{ for all }i\in B\\[5.69054pt]
m_{i}-1&\mbox{ otherwise}\end{cases}

Then for
k\in\{1,\ldots,M\}
we have:

\displaystyle d(\phi_{k})=\sum_{B\subseteq C}\phi_{k}(\mbox{\boldmath$x$}(B))(-1)^{|C|-|B|}

(24)

Proof:
The result is essentially just a special case of Theorem
4.2
where
\mbox{\boldmath$y$}=\mbox{\boldmath$m$}
, and thus
A(\mbox{\boldmath$y$})=C

\,\blacksquare

We observe that he formula for the signed domination function (
19
) given in Theorem
4.2
contains
2^{|A(\mbox{\boldmath$y$})|}
terms. Thus, for large systems this formula is not very efficient. However, the formula turns out to be very useful for theoretical purposes. We will now use this result to prove the following
recursive formula
for a signed domination function:

Teorem 4.4

Let
(C,\phi)
be an MMS with system state space
\mathcal{S}
, and where the set of states of component
i
is
\mathcal{S}_{i}=\{0,1,\ldots,m_{i}\}
,
i=1,\ldots,n
. Then for
k\in\{1,\ldots,M\}
and
e\in C
we have:

\displaystyle d(\phi_{k})=d(\phi_{k}((m_{e})_{e},\cdot))-d(\phi_{k}((m_{e}-1)_{e},\cdot)),

(25)

where
\phi_{k}((m_{e})_{e},\cdot)
denotes the structure function for the MMS obtained from
(C,\phi_{k})
by fixing the state of component
e
to
m_{e}
, while
\phi_{k}((m_{e}-1)_{e},\cdot)
denotes structure function for the MMS obtained from
(C,\phi_{k})
by fixing the state of component
e
to
m_{e}-1
.

Proof:
As in Corollary
4.3
we define:

\displaystyle x_{i}(B)=\begin{cases}m_{i}&\mbox{ for all }i\in B\\[5.69054pt]
m_{i}-1&\mbox{ otherwise}\end{cases}

We then use Corollary
4.3
and get:

\displaystyle d(\phi_{k})

\displaystyle=\sum_{B\subseteq C}\phi_{k}(\mbox{\boldmath$x$}(B))(-1)^{|C|-|B|}

\displaystyle=\sum_{B\subseteq C,\,e\in C}\phi_{k}(\mbox{\boldmath$x$}(B))(-1)^{|C|-|B|}+\sum_{B\subseteq C,\,e\notin C}\phi_{k}(\mbox{\boldmath$x$}(B))(-1)^{|C|-|B|}

\displaystyle=\sum_{B\subseteq(C\setminus e)}\phi_{k}(\mbox{\boldmath$x$}(B\cup e))(-1)^{|C|-|B\cup e|}+\sum_{B\subseteq(C\setminus e)}\phi_{k}(\mbox{\boldmath$x$}(B))(-1)^{|C|-|B|}

\displaystyle=\sum_{B\subseteq(C\setminus e)}\phi_{k}(\mbox{\boldmath$x$}(B\cup e))(-1)^{|C\setminus e|-|B|}-\sum_{B\subseteq(C\setminus e)}\phi_{k}(\mbox{\boldmath$x$}(B))(-1)^{|C\setminus e|-|B|}

\displaystyle=d(\phi_{k}((m_{e})_{e},\cdot))-d(\phi_{k}((m_{e}-1)_{e},\cdot))\quad\,\blacksquare

The formula (
25
) is also referred to as a
pivotal decomposition
formula for the signed domination, and the component
e\in C
, is referred to as the
pivotal element
.

The binary version of this theorem was proved in
[
18
]
, and can be stated as a corollary of Theorem
4.4
:

Corollary 4.5

Let
(C,\phi)
be an binary monotone system. that is, the system state space as well as the component state spaces are
\{0,1\}
. Then for
e\in C
we have:

\displaystyle d(\phi)=d(\phi(1_{e},\cdot))-d(\phi(0_{e},\cdot)),

(26)

where
\phi(0_{e},\cdot)
denotes the structure function for the binary monotone system obtained from
(C,\phi)
by fixing the state of component
e
to
1
, while
\phi(0_{e},\cdot)
denotes structure function for the binary monotone system obtained from
(C,\phi)
by fixing the state of component
e
to
0
.

Example 4.6

Consider an MMS
(C,\phi)
where
C=\{1,2,3,4\}
and where:

\displaystyle\phi(\mbox{\boldmath$x$})=\sum_{i=1}^{4}x_{i}

The component state spaces are
\mathcal{S}_{i}=\{0,1,2\}
,
i=1,2,3,4
. From this it follows that the system state space is
\mathcal{S}=\{0,1,\ldots,8\}
. We then consider the
4
-level structure function:

\displaystyle\phi_{4}(\mbox{\boldmath$x$})=\emph{I}(\sum_{i=1}^{4}x_{i}\geq 4)

Note that
(C,\phi_{4})
can be interpreted as a multistate generalization of a
k
-out-of-
n
system, where the threshold value
4
plays the role of
k
, but with multistate components.

The family of minimal
4
-level path vectors is
\mathfrak{P}_{4}=\{\mbox{\boldmath$x$}_{1},\ldots,\mbox{\boldmath$x$}_{19}\}
where:

\displaystyle\mbox{\boldmath$x$}_{1}

\displaystyle=(2,2,0,0),\quad\mbox{\boldmath$x$}_{2}=(2,0,2,0),\quad\mbox{\boldmath$x$}_{3}=(2,0,0,2),\quad\mbox{\boldmath$x$}_{4}=(0,2,2,0),

\displaystyle\mbox{\boldmath$x$}_{5}

\displaystyle=(0,2,0,2),\quad\mbox{\boldmath$x$}_{6}=(0,0,2,2),\quad\mbox{\boldmath$x$}_{7}=(2,1,1,0),\quad\mbox{\boldmath$x$}_{8}=(2,1,0,1),

\displaystyle\mbox{\boldmath$x$}_{9}

\displaystyle=(2,0,1,1),\quad\mbox{\boldmath$x$}_{10}=(1,2,1,0),\quad\mbox{\boldmath$x$}_{11}=(1,2,0,1),\quad\mbox{\boldmath$x$}_{12}=(0,2,1,1),

\displaystyle\mbox{\boldmath$x$}_{13}

\displaystyle=(1,1,2,0),\quad\mbox{\boldmath$x$}_{14}=(1,0,2,1),\quad\mbox{\boldmath$x$}_{15}=(0,1,2,1),\quad\mbox{\boldmath$x$}_{16}=(1,1,0,2),

\displaystyle\mbox{\boldmath$x$}_{17}

\displaystyle=(1,0,1,2),\quad\mbox{\boldmath$x$}_{18}=(0,1,1,2),\quad\mbox{\boldmath$x$}_{19}=(1,1,1,1)

The signed domination
d(\phi_{4})
can be calculated using (
1
). However, this means that all possible formations must be considered. With
19
minimal path vectors there are
2^{19}-1=524\,287
such formations. Fortunately, the calculations can be simplified considerably by using the results given in this section.

We start out by using the recursive formula (
25
). Due to the symmetry of this example the choice of pivotal element does not matter. Here we choose
e=4
. If we fix
x_{4}=2
, the minimal
4
-level path vectors of the resulting system are:

\displaystyle\mbox{\boldmath$x$}_{1}

\displaystyle=(2,0,0),\quad\mbox{\boldmath$x$}_{2}=(0,2,0),\quad\mbox{\boldmath$x$}_{3}=(0,0,2),\quad\mbox{\boldmath$x$}_{4}=(1,1,0),

\displaystyle\mbox{\boldmath$x$}_{5}

\displaystyle=(1,0,1),\quad\mbox{\boldmath$x$}_{6}=(0,1,1).

If we fix
x_{4}=1
, the minimal
4
-level path vectors of the resulting system are:

\displaystyle\mbox{\boldmath$x$}_{1}

\displaystyle=(2,1,0),\quad\mbox{\boldmath$x$}_{2}=(2,0,1),\quad\mbox{\boldmath$x$}_{3}=(1,2,0),\quad\mbox{\boldmath$x$}_{4}=(0,2,1),

\displaystyle\mbox{\boldmath$x$}_{5}

\displaystyle=(1,0,2),\quad\mbox{\boldmath$x$}_{6}=(0,1,2),\quad\mbox{\boldmath$x$}_{7}=(1,1,1)

The signed dominations
d(\phi_{4}(2_{4},\cdot))
and
d(\phi_{4}(1_{4},\cdot))
can then be calculated using (
1
) by considering a total number of
(2^{6}-1)+(2^{7}-1)=63+127=190
formations. Thus, we see that by using the recursive formula (
25
) we have reduced the number of formations we need to consider from
524\,287
down to just
190
which is obviously a considerable reduction. By applying the recursive formula to the systems
(C\setminus 4,\phi_{4}(2_{4},\cdot))
and
(C\setminus 4,\phi_{4}(1_{4},\cdot))
, the calculations can be further simplified.

In this case, however, there is an even simpler way of calculating
d(\phi_{4})
using (
24
). Since
C=\{1,2,3,4\}
the number of terms in this sum is just
16
. Moreover, we observe that:

\displaystyle\mbox{\boldmath$x$}(B)\geq\mbox{\boldmath$x$}(\emptyset)=(1,1,1,1),\quad\mbox{ for all }B\subseteq C.

Since
\phi_{4}(1,1,1,1)=1
, it follows that
\phi_{4}(\mbox{\boldmath$x$}(B))=1
for all
B\subseteq C
. Hence, in this case (
24
) is reduced to:

\displaystyle d(\phi_{k})=\sum_{B\subseteq C}(-1)^{|C|-|B|}=0

where the last equality is a well-known combinatorial identity. Thus, we see that we have reduced the computational complexity from considering
524\,287
formations to simply applying a well-known formula.

Finally, note that in this example
d(\phi_{4})=0
even though
(C,\phi_{4})
is strongly coherent
\,\blacksquare

5
Associated binary monotone systems

We consider the formula (
24
) again, and note that in order to calculate
d(\phi_{k})
we only need to evaluate the function
\phi_{k}(\mbox{\boldmath$x$})
for vectors
x
of the form
\mbox{\boldmath$x$}=\mbox{\boldmath$x$}(B)
, where:

\displaystyle x_{i}(B)=\begin{cases}m_{i}&\mbox{ for all }i\in B\\[5.69054pt]
m_{i}-1&\mbox{ otherwise}\end{cases}

By a change of variables, we can transform these vectors to binary vectors. That is, for all
B\subseteq C
we introduce
\mbox{\boldmath$z$}(B)=(z_{1}(B),\ldots,z_{n}(B))
, where:

\displaystyle z_{i}(B)=\begin{cases}1&\mbox{ for all }i\in B\\[5.69054pt]
0&\mbox{ otherwise}\end{cases}

This implies that we have the following relation between the binary vector
\mbox{\boldmath$z$}(B)
and the non-binary vector
\mbox{\boldmath$x$}(B)
:

\displaystyle\mbox{\boldmath$x$}(B)=\mbox{\boldmath$m$}-\mbox{\boldmath$1$}+\mbox{\boldmath$z$}(B),\quad\mbox{ for all }B\subseteq C.

We can now associate a binary monotone system
(C,\psi_{k})
to the MMS
(C,\phi_{k})
, where
\psi_{k}
is a non-decreasing function defined for all binary vectors
\mbox{\boldmath$z$}\in\{0,1\}^{n}
by:

\displaystyle\psi_{k}(\mbox{\boldmath$z$})=\phi_{k}(\mbox{\boldmath$m$}-\mbox{\boldmath$1$}+\mbox{\boldmath$z$})

(27)

We refer to
(C,\psi_{k})
as the binary monotone system
associated
with the MMS
(C,\phi_{k})
. By (
27
) we get that:

\displaystyle\psi_{k}(\mbox{\boldmath$z$}(B))=\phi_{k}(\mbox{\boldmath$m$}-\mbox{\boldmath$1$}+\mbox{\boldmath$z$}(B))=\phi_{k}(\mbox{\boldmath$x$}(B)),\quad\mbox{ for all }B\subseteq C.

(28)

Inserting
\psi_{k}(\mbox{\boldmath$z$}(B))
instead of
\phi_{k}(\mbox{\boldmath$x$}(B))
into (
24
), we get:

\displaystyle d(\phi_{k})=\sum_{B\subseteq C}\psi_{k}(\mbox{\boldmath$z$}(B))(-1)^{|C|-|B|}=d(\psi_{k})

The following result summarizes this discussion:

Teorem 5.1

The signed domination of a
k
-level MMS
(C,\phi_{k})
is equal to the signed domination of its associated binary monotone system
(C,\psi_{k})
.

More generally, similar results can be obtained for the entire signed domination function using Theorem
4.2
:

Teorem 5.2

Let
(C,\phi)
be an MMS with component state space
\mathfrak{C}
and system state space
\mathcal{S}
. For any
\mbox{\boldmath$y$}\in\mathfrak{C}\setminus\{\mbox{\boldmath$0$}\}
we let
A(\mbox{\boldmath$y$})=\{i:y_{i}>0\}
. Furthermore, for any subset
B\subseteq A(\mbox{\boldmath$y$})
we define the subvector
\mbox{\boldmath$z$}^{A(\mbox{\boldmath$y$})}(B)
with indices in the set
A(\mbox{\boldmath$y$})
by:

\displaystyle z_{i}(B)=\begin{cases}1\quad&\mbox{ for all }i\in B\\[5.69054pt]
0\quad&\mbox{ for all }i\in A(\mbox{\boldmath$y$})\setminus B\end{cases}

(29)

Moreover, for
k\in\{1,\ldots,M\}
, we let
(A(\mbox{\boldmath$y$}),\psi_{k}^{\mbox{\boldmath$y$}})
denote a binary monotone system where the structure function
\psi_{k}^{\mbox{\boldmath$y$}}
is given by:

\displaystyle\psi_{k}^{\mbox{\boldmath$y$}}(\mbox{\boldmath$z$}^{A(\mbox{\boldmath$y$})})=\phi_{k}(\mbox{\boldmath$y$}-(\mbox{\boldmath$1$}^{A(\mbox{\boldmath$y$})},\mbox{\boldmath$0$})+(\mbox{\boldmath$z$}^{A(\mbox{\boldmath$y$})},\mbox{\boldmath$0$})),\quad\mbox{\boldmath$z$}^{A(\mbox{\boldmath$y$})}\in\{0,1\}^{|A(\mbox{\boldmath$y$})|}.

Here
(\mbox{\boldmath$z$}^{A(\mbox{\boldmath$y$})},\mbox{\boldmath$0$})
denotes the binary vector where the entries with indices in the set
A(\mbox{\boldmath$y$})
are given by the subvector
\mbox{\boldmath$z$}^{A(\mbox{\boldmath$y$})}
, while the remaining entries are zero. Similarly,
(\mbox{\boldmath$1$}^{A(\mbox{\boldmath$y$})},\mbox{\boldmath$0$})
denotes the binary vector where the entries with indices in the set
A(\mbox{\boldmath$y$})
are
1
, while the remaining entries are zero.
Then we have:

\displaystyle\delta_{k}(\mbox{\boldmath$y$})=d(\psi_{k}^{\mbox{\boldmath$y$}})

Proof:
We start by noting that we have the following relation between
\mbox{\boldmath$x$}(B)
defined in (
18
) and the subvector
\mbox{\boldmath$z$}^{A(\mbox{\boldmath$y$})}(B)
defined in (
29
):

\displaystyle\mbox{\boldmath$x$}(B)=\mbox{\boldmath$y$}-(\mbox{\boldmath$1$}^{A(\mbox{\boldmath$y$})},\mbox{\boldmath$0$})+(\mbox{\boldmath$z$}^{A(\mbox{\boldmath$y$})}(B),\mbox{\boldmath$0$})),\quad\mbox{ for all }B\subseteq A(\mbox{\boldmath$y$}).

Hence, it follows by (
19
) that we have:

\displaystyle\delta_{k}(\mbox{\boldmath$y$})

\displaystyle=\sum_{B\subseteq A(\mbox{\boldmath$y$})}\phi_{k}(\mbox{\boldmath$x$}(B))(-1)^{|A(\mbox{\boldmath$y$})|-|B|}

\displaystyle=\sum_{B\subseteq A(\mbox{\boldmath$y$})}\phi_{k}(\mbox{\boldmath$y$}-(\mbox{\boldmath$1$}^{A(\mbox{\boldmath$y$})},\mbox{\boldmath$0$})+(\mbox{\boldmath$z$}^{A(\mbox{\boldmath$y$})}(B),\mbox{\boldmath$0$})))(-1)^{|A(\mbox{\boldmath$y$})|-|B|}

\displaystyle=\sum_{B\subseteq A(\mbox{\boldmath$y$})}\psi_{k}^{\mbox{\boldmath$y$}}(\mbox{\boldmath$z$}^{A(\mbox{\boldmath$y$})}(B))(-1)^{|A(\mbox{\boldmath$y$})|-|B|}=d(\psi_{k}^{\mbox{\boldmath$y$}})

which completes the proof
\,\blacksquare

Theorem
5.1
and Theorem
5.2
are important because these results reduce the problem of computing respectively the signed domination and the signed domination function of a
k
-level MMS to the problem of computing the signed domination of associated binary monotone systems. This means that all results on signed domination of binary monotone systems can be utilized. Relevant results can be found in
[
18
]
,
[
19
]
,
[
20
]
and
[
21
]
, as well as in
[
32
]
and
[
31
]
. In the remaining part of this section we will give some examples on how Theorem
5.1
can be used.

5.1
Matroid systems

In
[
19
]
and
[
20
]
a connection between binary monotone systems and
matroids
was established. A matroid is an ordered pair
(F,\mathcal{M})
, where
F
is a non-empty finite set, and
\mathcal{M}
is a family of non-empty incomparable subsets of
F
, called
circuits
, such that if
M_{1},M_{2}\in\mathcal{M}
are two distinct circuits with a common element
e\in M_{1}\cap M_{2}
, then there exists a third circuit
M_{3}\in\mathcal{M}
such that
M_{3}\subseteq(M_{1}\cup M_{2})\setminus e
. See
[
26
]
or
[
33
]
.

If
(C,\phi)
is a binary monotone system with minimal path sets
\mathcal{P}
, then
(C,\phi)
is said to be a matroid system if there exists a matroid
(C\cup x,\mathcal{M})
where
x\notin C
, such that:

\displaystyle\mathcal{P}=\{M\setminus x:M\in\mathcal{M},\,x\in M\}.

(30)

Thus, for a matroid system
(C,\phi)
the family of minimal path sets,
\mathcal{P}
can be derived from the matroid
(C\cup x,\mathcal{M})
by identifying all circuits in
\mathcal{M}
which contains the element
x
, and then delete this element from these circuits. The class of matroid systems is a large class of systems, and contains undirected network systems,
k
-out-of-
n
systems and many other types of systems.

If
(C,\phi)
is a matroid system, then the matroid
(C\cup x,\mathcal{M})
is referred to as the
corresponding matroid
, and we indicate that
(C,\phi)
can be derived from the matroid
(C\cup x,\mathcal{M})
by writing:

\displaystyle(C\cup x,\mathcal{M})\rightarrow(C,\phi)

(31)

If
(F,\mathcal{M})
is a matroid, a subset
B\subseteq F
is said to be an
independent set
if
B
does not contain any circuit. The
rank function
of the matroid, denoted by
\rho
, and defined for all subsets,
A\subseteq F
is the cardinality of the largest independent subset
B\subseteq A
. That is we have:

\displaystyle\rho(A)=\max\{|B|:B\subseteq A\mbox{ and }M\not\subseteq B\mbox{ for all }M\in\mathcal{M}\}

(32)

In
[
19
]
it was shown that
(C,\phi)
is a matroid system if and only if the structure function
\phi
, interpreted as a function defined for all subsets
A\subseteq C
, where
A=A(\mbox{\boldmath$x$})=\{i\in C:x_{i}=1\}
, can be represented as:

\displaystyle\phi(A)=1+\rho(A)-\rho(A\cup x),\mbox{ for all }A\subseteq C,

(33)

for some matroid
(C\cup x,\mathcal{M})
with rank function
\rho
.

The Crapo
\beta
-invariant of a matroid
(F,\mathcal{M})
with rank function
\rho
, introduced in
[
8
]
, is given by:

\displaystyle\beta(A)=\sum_{B\subseteq A}(-1)^{\rho(A)-|B|}\rho(B),\quad\mbox{ for all }B\subseteq A.

(34)

In particular the Crapo
\beta
-number for the matroid
(F,\mathcal{M})
, denoted
b(\mathcal{M})
is defined as:

\displaystyle b(\mathcal{M})=\beta(F)

(35)

In
[
8
]
it was shown that
\beta(A)\geq 0
for all
A\subseteq F
.

In
[
19
]
it was shown that if
(C\cup x,\mathcal{M})\rightarrow(C,\phi)
then the signed domination function of
(C,\phi)
, denoted
\delta
, is given by:

\displaystyle\delta(A)=(-1)^{|A|-\rho(A\cup x)}\beta(A\cup x),\quad\mbox{ for all }A\subseteq C.

(36)

In particular:

\displaystyle d(\phi)=(-1)^{|C|-\rho(C\cup x)}b(\mathcal{M})

(37)

In
[
31
]
the concept of domination was used in order to find an optimal strategy for pivotal decompositions for undirected network systems. In particular the
domination invariant
of a binary monotone system
(C,\phi)
, denoted by
D(\phi)
, and defined as the absolute value of the signed domination invariant
d(\phi)
. The results on optimal pivotal decomposition strategies can be generalized to matroid systems. For details see
[
19
]
and
[
20
]
. In particular, we have the following:

\displaystyle D(\phi)

\displaystyle=b(\mathcal{M}),

(38)

\displaystyle d(\phi)

\displaystyle=(-1)^{|C|-\rho(C\cup x)}D(\phi),

(39)

\displaystyle D(\phi)

\displaystyle=D(\phi(1_{e},\cdot))+D(\phi(0_{e},\cdot)),

(40)

where (
40
) is obtained using (
39
) and Corollary
4.5
.

If
(C,\phi)
is a
k
-out-of-
n
system where
n=|C|
and
0<k\leq n
, it is easy to verify that
(C,\phi)
is a matroid system. In particular, the family of minimal path sets of
(C,\phi)
is given by:

\displaystyle\mathcal{P}=\{P\subseteq C:|P|=k\},

while the family of circuits of the corresponding matroid
(C\cup x,\mathcal{M})
is given by:

\displaystyle\mathcal{M}=\{M\subseteq C\cup x:|M|=k+1\},

The matroid
(C\cup x,\mathcal{M})
is referred to as a
uniform matroid
, and it follows by (
32
) that
\rho(C\cup x)=k
.

Since
(C,\phi)
is a
k
-out-of-
n
system, it follows that
(C\setminus e,\phi(1_{e},\cdot))
is a
(k-1)
-out-of-
(n-1)
system, while
(C\setminus e,\phi(0_{e},\cdot))
is a
k
-out-of-
(n-1)
system. Utilizing this property in combination with (
39
), (
40
) and induction, it is easy to verify that:

\displaystyle d(\phi)=(-1)^{n-k}\binom{n-1}{k-1},\quad 0<k\leq n.

(41)

By using Theorem
5.1
we can extend (
41
) to mutistate systems. One such system was analyzed in Example
4.6
. In the multistate case we denote such system as a
k
-out-of-
(n,m)
-system, where
k
is a
threshold value
,
n
is the number of components in the system, and
m
denotes a common maximal component state. More specifically, we let
(C,\phi)
be an MMS where
C=\{1,\ldots,n\}
,
S_{i}=\{0,1,\ldots,m\}
and the structure function
\phi
is given by:

\displaystyle\phi(\mbox{\boldmath$x$})=\sum_{i=1}^{n}x_{i}

Then the
k
-level MMS
(C,\phi_{k})
is said to be a
k
-out-of-
(n,m)
-system, and we have:

\displaystyle\phi_{k}(\mbox{\boldmath$x$})=\mathop{\rm\raisebox{0.1pt}{I}}(\sum_{i=1}^{n}x_{i}\geq k)

We then consider the associated binary monotone system
(C,\psi_{k})
, where:

\displaystyle\psi_{k}(\mbox{\boldmath$z$})

\displaystyle=\phi_{k}(\mbox{\boldmath$m$}-\mbox{\boldmath$1$}+\mbox{\boldmath$z$})=\mathop{\rm\raisebox{0.1pt}{I}}(\sum_{i=1}^{n}(m-1+z_{i})\geq k)

\displaystyle=\mathop{\rm\raisebox{0.1pt}{I}}(\sum_{i=1}^{n}z_{i}\geq k-n(m-1))

Thus,
(C,\psi_{k})
is a binary
k-n(m-1)
-out-of-
n
system. If
k\leq n(m-1)
, it follows that
\psi_{k}\equiv 1
. Hence, by (
24
) we get:

\displaystyle d(\phi_{k})=d(\psi_{k})=\sum_{B\subseteq C}\psi_{k}(\mbox{\boldmath$x$}(B))(-1)^{|C|-|B|}=\sum_{B\subseteq C}1\cdot(-1)^{|C|-|B|}=0.

If
n(m-1)<k\leq nm
, it follows from (
41
) that:

\displaystyle d(\phi_{k})=d(\psi_{k})=(-1)^{n-(k-n(m-1))}\cdot\binom{n-1}{(k-n(m-1))-1}

Finally, if
k>nm
, then
\psi_{k}\equiv 0
. Hence, by (
24
) we get:

\displaystyle d(\phi_{k})=d(\psi_{k})=\sum_{B\subseteq C}\psi_{k}(\mbox{\boldmath$x$}(B))(-1)^{|C|-|B|}=\sum_{B\subseteq C}0\cdot(-1)^{|C|-|B|}=0.

The following theorem summarizes the above discussion:

Teorem 5.3

Let
(C,\phi)
be an MMS where
C=\{1,\ldots,n\}
,
S_{i}=\{0,1,\ldots,m\}
and the structure function
\phi
is given by:

\displaystyle\phi(\mbox{\boldmath$x$})=\sum_{i=1}^{n}x_{i}

Then the signed domination of the
k
-level MMS
(C,\phi_{k})
is given by:

\displaystyle d(\phi_{k})=\begin{cases}(-1)^{n-(k-n(m-1))}\cdot\binom{n-1}{(k-n(m-1))-1},&\mbox{for }n(m-1)<k\leq nm\\[2.84526pt]
0&\mbox{otherwise}\end{cases}

(42)

As mentioned above the MMS considered in Example
4.6
belongs to the same class as
(C,\phi)
with
n=4
and
m=2
. Moreover the
4
-level MMS
(C,\phi_{4})
considered in this example is a
4
-out-of-
(4,2)
-system. Since
4\leq 4(2-1)
, it follows by the general result proved above that
d(\phi_{4})=d(\psi_{4})=0
which is the same result we arrived at in Example
4.6
. Note also that if
m=1
, the general formula (
42
) reduces to (
41
).

Matroid systems also include
undirected network systems
. Thus, Theorem
5.1
can be applied to such systems as well:

Example 5.4

Figure 1
:
Undirected flow network

In this example we consider the undirected 2-terminal network flow system shown in Figure

. This represents the MMS
(C,\phi)
, where
C=\{1,\ldots,7\}
is the set of edges in the network, and where
\phi(\mbox{\boldmath$x$})
is defined as the maximum flow that can be transported through the network from the node
S
to the node
T
. We assume that the maximum flow capacities of the edges are given by:

\displaystyle\mbox{\boldmath$m$}=(m_{1},\ldots,m_{7})=(2,2,1,2,1,2,2)

In order to find an expression for the structure function
\phi
we start out by finding the minimal cut sets of the network:

\displaystyle K_{1}

\displaystyle=\{1,2\},\quad K_{2}=\{1,3,5,7\},\quad K_{3}=\{2,3,4\},

\displaystyle K_{4}

\displaystyle=\{2,3,5,6\},\quad K_{5}=\{4,5,7\},\quad K_{6}=\{6,7\}

By the max-flow-min-cut theorem (see
[

]
) the structure function
\phi
can be expressed as follows:

\displaystyle\phi(\mbox{\boldmath$x$})=\min_{1\leq r\leq 6}\sum_{i\in K_{r}}x_{i}

We then consider the
3

(C,\phi_{3})
where
\phi_{3}
is given by:

\displaystyle\phi_{3}(\mbox{\boldmath$x$})=\mathop{\rm\raisebox{0.1pt}{I}}(\sum_{i\in K_{1}}x_{i}\geq 3\,\cap\,\cdots\,\cap\,\sum_{i\in K_{6}}x_{i}\geq 3)

Hence, the structure function

of the associated binary monotone system is:

\displaystyle\psi_{k}(\mbox{\boldmath$z$})

\displaystyle=\phi_{k}(\mbox{\boldmath$m$}-\mbox{\boldmath$1$}+\mbox{\boldmath$z$})

\displaystyle=\mathop{\rm\raisebox{0.1pt}{I}}(\sum_{i\in K_{1}}(m_{i}-1+z_{i})\geq 3\,\cap\,\cdots\,\cap\,\sum_{i\in K_{6}}(m_{i}-1+z_{i})\geq 3)

is the structure function of the binary undirected 2-terminal network system shown in Figure

. In particular,

is a matroid system such that the rank function

of the corresponding matroid

satisfies:

\displaystyle\rho(C\cup x)=v-1,

where

) it follows that:

\displaystyle d(\phi_{3})=d(\psi_{3})=(-1)^{|C|-\rho(C\cup x)}D(\psi_{3})=(-1)^{7-(5-1)}D(\psi_{3})=-D(\psi_{3})

The domination

turns out to

5.2
Oriented matroid systems

In
[
21
]
the class of
oriented matroid systems
was introduced. Such systems can be derived from
oriented matroids
in much the same way as matroid systems are derived from matroids. For a comprehensive introduction to the theory of oriented matroids, see
[
5
]
.

Oriented matroids are based on the concept of a
signed set
. A signed set is a set
M
along with a mapping
\sigma_{M}:M\rightarrow\{+,-\}
, called the
sign mapping
of the set. With a slight abuse of notation,
M
refers both to the signed set itself as well as the underlying unsigned set of elements. The sign mapping
\sigma_{M}
of a signed set
M
defines a partition of
M
into two subsets,
M^{+}=\{e\in M:\sigma_{M}(e)=+\}
and
M^{-}=\{e\in M:\sigma_{M}(e)=-\}
.
M^{+}
and
M^{-}
are referred to as the
positive
and
negative
elements of
M
respectively. If
M
is a signed set with
M^{+}=\{e_{1},\ldots,e_{i}\}
and
M^{-}=\{f_{1},\ldots,f_{j}\}
, we indicate this by writing
M
as
\{e_{1},\ldots,e_{i},\bar{f}_{1},\ldots,\bar{f}_{j}\}
. If
M=M^{+}
,
M
is called a
positive
set, while if
M=M^{-}
,
M
is called a
negative
set. An oriented matroid can now be defined as follows:

Definition 5.5

An
oriented matroid
is an ordered pair
(F,\mathcal{M})
where
F
is a non-empty finite set, and
\mathcal{M}
is a family of signed subsets of
F
, called
signed circuits
. The signed circuits satisfy the following properties:

(O1)

\emptyset
is not a signed circuit.

(O2)

If
M
is a signed circuit, then so is
-M
.

(O3)

For all
M_{1},M_{2}\in\mathcal{M}
such that
M_{1}\subseteq M_{2}
,
we either have
M_{1}=M_{2}
or
M_{1}=-M_{2}
.

(O4)

If
M_{1}
and
M_{2}
are signed circuits such that
M_{1}\neq-M_{2}
, and

e\in M^{+}_{1}\cap M^{-}_{2}
, then there exists a third signed circuit

M_{3}
with
M^{+}_{3}\subseteq(M^{+}_{1}\cup M^{+}_{2})\setminus e
and

M^{-}_{3}\subseteq(M^{-}_{1}\cup M^{-}_{2})\setminus e
.

Similar to how we defined matroid systems in (
30
), we now define
oriented matroid systems
as follows:

Definition 5.6

Let
(C\cup x,\mathcal{M})
be an oriented matroid, and let
(C,\phi)
be a binary monotone system with minimal path set family
\mathcal{P}
given by:

\mathcal{P}=\{(M\setminus x):M\in\mathcal{M},\>x\in M^{+}\hbox{ and }(M\setminus x)^{-}=\emptyset\}

(43)

We then say that
(CE,\phi)
is the oriented matroid system derived from the oriented matroid
(C\cup x,\mathcal{M})
with respect to
x
, and write this as
(C\cup x,\mathcal{M})\rightarrow(C,\phi)
.

If
(C\cup x,\mathcal{M})\rightarrow(C,\phi)
, the system
(C,\phi)
is said to be
cyclic
if there exists a circuit
M\in\mathcal{M}
such that
M\subseteq C
and
M^{-}=\emptyset
. If no such circuit exists,
(C,\phi)
is said to be
acyclic
.

The main results on oriented matroid systems are the following two theorems:

Teorem 5.7

Let
(E,\phi)
be a coherent acyclic oriented matroid system derived from the oriented matroid
(E\cup x,\mathcal{M})
. Moreover, let
\rho
be the rank function of
(E\cup x,\mathcal{M})
. Then
d(\phi)=(-1)^{|E|-\rho(E\cup x)}
.

Teorem 5.8

Let
(E,\phi)
be a cyclic oriented matroid system. Then
d(\phi)=0
.

The above theorems were first proved for directed network systems in
[
32
]
, while simplified proofs were obtained in
[
18
]
. The generalization to oriented matroid systems was proved in
[
21
]
.

5.1
by considering the following example.

6
Conclusions and further work

We have studied the relation between
k
-level structure functions of an MMS and the corresponding
signed domination function
. Formally, the signed domination function is defined through the concept of
formations
of a poset of vectors. Computing the signed domination function directly from formations is very time consuming. By using
Möbius inversion
the signed domination function of a
k
-level structure function can be expressed in terms of this structure function. The inversion formula shows that the signed domination of a
k
-level structure function is equal to the signed domination of its associated binary structure function. This result implies that the theory of signed domination functions for binary monotone systems can be applied to MMSs as well. Future work on this topic will further explore the use of such results.
