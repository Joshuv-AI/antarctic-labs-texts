Existence Result for Difference Equations on Non-Uniform Grids via Upper and Lower Solution Method
Shalmali Bandyopadhyay, Kimsear Lor

Abstract
. This paper establishes an existence theory for discrete second-order boundary value problems on non-uniform time grids using the upper and lower solution method. We consider difference equations of the form u Δ ​ Δ ​ ( t i − 1 ) + f ⁡ ( t i , u ⁡ ( t i ) , u Δ ​ ( t i − 1 ) ) = 0 u^{\Delta\Delta}(t_{i-1})+f(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))=0 on a non-uniform time grid t 0 , t 1 , … , t n + 2 {t_{0},t_{1},\ldots,t_{n+2}} with mixed boundary conditions u Δ ​ ( t 0 ) = 0 u^{\Delta}(t_{0})=0 and u ⁡ ( t n + 2 ) = g ⁡ ( t n + 2 ) u(t_{n+2})=g(t_{n+2}) . This extends previous work on homogeneous boundary conditions to the non-homogeneous case, requiring a sophisticated functional analytic framework to handle the resulting affine function spaces. Our approach employs a decomposition strategy that separates boundary effects from the differential structure, enabling the application of Brouwer’s Fixed Point Theorem to establish existence with solutions bounded between upper and lower functions.

In this manuscript we establish existence result of a difference equation on nonuniform grid with mixed boundary condition by employing standard upper and lower solution method, extensively available in the literature together with Brouwer fixed point theory. Definition 1.1
.

Let

be fixed and
a<b
be real numbers. A
non-uniform time grid
is a strictly increasing sequence
\mathbb{T}=\{t_{0},t_{1},\ldots,t_{n+2}\}
where

.

Definition 1.2
.

Define the step sizes

for

Definition 1.3

For a function

.

The

Having introduced necessary definitions, we now consider the following boundary value problem.

\begin{cases}u^{\Delta\Delta}(t_{i-1})+{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))=0,&i\in\{1,2,\ldots,n+1\}\\
u^{\Delta}(t_{0})=0\\
u(t_{n+2})=g(t_{n+2})\end{cases}

(1.1)

where
\{t_{0},t_{1},\ldots,t_{n+2}\}
is a non-uniform partition of an interval
[a,b]
with

(A1)

is continuous on

, right continuous at

and left continuous at

in the discrete sense;

is continuous on

(A2)

(A3)

In
[

\begin{cases}u^{\Delta\Delta}(t_{i-1})+{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))=0,&i\in\{1,2,\ldots,n+1\}\\
u^{\Delta}(t_{0})=0\\
u(t_{n+2})=0.\end{cases}

Later, in
[
9
]
, authors extended the above problem for
n^{\text{th}}
order derivative. In our case, the second boundary condition allows for non-homogeneous boundary values. The main challenge we faced was defining the underlying function space to accommodate this non-homogeneous structure. This problem requires a more sophisticated functional analytic approach compared to the standard homogeneous case. While homogeneous boundary conditions naturally define linear function spaces that are well-suited for fixed point theory applications, non-homogeneous conditions create affine spaces that lack the linear structure necessary for classical fixed point arguments. To overcome this challenge, we employ a careful decomposition strategy that separates the boundary effects from the core differential structure, allowing the problem to be reformulated within an appropriate linear framework while preserving the original boundary requirements (see Section
2
).

Prior to stating our theorem, we will provide definitions of solution, upper solution and lower solution.

\begin{cases}\beta^{\Delta\Delta}(t_{i-1})+{f}(t_{i},\beta(t_{i}),\beta^{\Delta}(t_{i-1}))\leq 0,&i\in\{1,\ldots,n+1\}\\

\beta(t_{n+2})\geq g(t_{n+2})\end{cases}

(1.3)

Let

(1.4)

The remainder of this paper is organized as follows. Section
2
establishes the functional analytic framework, including the definition of appropriate function spaces, the solution decomposition theorem that separates boundary conditions from the difference equation, and Brouwer’s Fixed Point Theorem in the discrete setting. Section
3
presents the main existence result through three key steps: construction of an auxiliary problem with modified nonlinearity that handles solutions outside the upper and lower bounds, development of a solution operator whose fixed points correspond to solutions of the auxiliary problem, and application of Brouwer’s theorem to establish existence. Finally, Section

2.
Preliminaries

We begin by defining the underlying function spaces that are required for our purposes.

Definition 2.1
.

The space
E
is defined as

E=\{u:\mathbb{T}\to\mathbb{R}:u^{\Delta}(t_{0})=0,u(t_{n+2})=g(t_{n+2})\}

Definition 2.2
.

The space
E_{0}
is defined as

E_{0}=\{v:\mathbb{T}\to\mathbb{R}:v^{\Delta}(t_{0})=0,v(t_{n+2})=0\}.

Proposition 2.3
.

The space
E_{0}
equipped with the supremum norm
\|v\|_{\infty}=\max_{t\in\mathbb{T}}|v(t)|
is a normed linear space.

Proof.

We verify that
E_{0}
is a linear space and that the supremum norm satisfies the norm axioms.

Linear space properties:

Closure under addition:
Let
v_{1},v_{2}\in E_{0}
. Then

\displaystyle(v_{1}+v_{2})^{\Delta}(t_{0})

\displaystyle=v_{1}^{\Delta}(t_{0})+v_{2}^{\Delta}(t_{0})=0+0=0,

\displaystyle(v_{1}+v_{2})(t_{n+2})

\displaystyle=v_{1}(t_{n+2})+v_{2}(t_{n+2})=0+0=0.

Therefore,
v_{1}+v_{2}\in E_{0}
.

Closure under scalar multiplication:
Let
v\in E_{0}
and
\alpha\in\mathbb{R}
. Then

\displaystyle(\alpha v)^{\Delta}(t_{0})

\displaystyle=\alpha v^{\Delta}(t_{0})=\alpha\cdot 0=0,

\displaystyle(\alpha v)(t_{n+2})

\displaystyle=\alpha v(t_{n+2})=\alpha\cdot 0=0.

Therefore,
\alpha v\in E_{0}
.

Zero element:
The zero function
0:\mathbb{T}\to\mathbb{R}
defined by
0(t)=0
for all
t\in\mathbb{T}
satisfies
0^{\Delta}(t_{0})=0
and
0(t_{n+2})=0
, so
0\in E_{0}
.

Additive inverse:
For any
v\in E_{0}
, we have
-v\in E_{0}
since
(-v)^{\Delta}(t_{0})=-v^{\Delta}(t_{0})=0
and
(-v)(t_{n+2})=-v(t_{n+2})=0
.

Norm properties:

Positive definiteness:

\|v\|_{\infty}\geq 0
for all
v\in E_{0}
, and
\|v\|_{\infty}=0
if and only if
|v(t)|=0
for all
t\in\mathbb{T}
, which occurs if and only if
v
is the zero function.

Homogeneity:
For any
\alpha\in\mathbb{R}
and
v\in E_{0}
,

\|\alpha v\|_{\infty}=\max_{t\in\mathbb{T}}|\alpha v(t)|=|\alpha|\max_{t\in\mathbb{T}}|v(t)|=|\alpha|\|v\|_{\infty}.

Triangle inequality:
For any
v_{1},v_{2}\in E_{0}
,

\|v_{1}+v_{2}\|_{\infty}=\max_{t\in\mathbb{T}}|v_{1}(t)+v_{2}(t)|\leq\max_{t\in\mathbb{T}}(|v_{1}(t)|+|v_{2}(t)|)\leq\|v_{1}\|_{\infty}+\|v_{2}\|_{\infty}.

∎

Remark 2.8

Theorem 2.9

(Brouwer’s Fixed Point Theorem)
.

Let
K
be a nonempty, compact, convex subset of a finite-dimensional normed space
X
, and let
T:K\to K
be a continuous mapping. Then
T
has at least one fixed point in
K
.

Let us first understand this concept of fixed point theory for a single-variable function and how and when we can guarantee that a fixed point exists.

Claim
: Let
f:[0,1]\rightarrow[0,1]
, and it is continuous in that domain; then a fixed point of the function
f
exists in the same domain.

Proof.

Let
g(x)=f(x)-x
, where
g(x)
is continuous, since
f(x)
is continuous and
x
is an identity function. Notice that within our domain,
f(0)>0
and
f(1)<1
.

Therefore,

\displaystyle g(0)=f(0)-0=f(0)>0\Rightarrow g(0)>0

\displaystyle g(1)=f(1)-1=f(1)-1<0\Rightarrow g(1)<0

Knowing that
g(0)>0
and
g(1)<0
, we can apply the Intermediate Value Theorem and conclude that there exists a value
c
in the established domain such that
g(c)=0

\Rightarrow f(c)-c=0
, therefore
f(c)=c
, i.e.
c
is a fixed point of
f(x)
.
∎

Remark 2.10
.

Note that the range of our interval does not allow
f(x)
to go beyond 1 or below 0; in other words,
f(1)\not>1
and
f(0)\not<0
. And if
f(0)=0
or
f(1)=1
, we would already have a fixed point of
f(x)
either
0
or
1
.

Corollary 2.11

(Application to Discrete Boundary Value Problems)
.

Let
\overline{B_{r}}=\{u\in E:\|u\|_{\infty}\leq r\}
for some
r>0
. If
T:E\to E
is continuous and satisfies
T(\overline{B_{r}})\subseteq\overline{B_{r}}
, then
T
has a fixed point in
\overline{B_{r}}
.

Proof.

Since
\mathbb{T}=\{t_{0},t_{1},\ldots,t_{n+2}\}
is finite with
|\mathbb{T}|=n+3
elements, the space
E
can be identified with a subset of
\mathbb{R}^{n+3}
via the isomorphism

\Phi:E\to\mathbb{R}^{n+3},\quad\Phi(u)=(u(t_{0}),u(t_{1}),\ldots,u(t_{n+2})).

However, due to the boundary conditions
u^{\Delta}(t_{0})=0
and
u(t_{n+2})=g(t_{n+2})
, the set
E
is actually isomorphic to
\mathbb{R}^{n+1}
. Indeed, using the decomposition
u=v+w_{p}
where
v\in E_{0}
, the space
E_{0}
can be parameterized by the values
(v(t_{1}),v(t_{2}),\ldots,v(t_{n+1}))
since:

v(t_{n+2})=0
(fixed by boundary condition)

The constraint
v^{\Delta}(t_{0})=0
gives us
v(t_{1})=v(t_{0})

Therefore,
E_{0}
is isomorphic to
\mathbb{R}^{n+1}
, and consequently
E
is also
(n+1)
-dimensional.

The set
{\overline{B_{r}}}=\{u\in E:\|u\|_{\infty}\leq r\}
is:

Bounded:
By definition,
\|u\|_{\infty}\leq r
for all
u\in\overline{B_{r}}
.

Closed:
If
u_{k}\in\overline{B_{r}}
and
u_{k}\to u
in
E
, then
\|u_{k}\|_{\infty}\leq r
for all
k
. By continuity of the norm,
\|u\|_{\infty}=\lim_{k\to\infty}\|u_{k}\|_{\infty}\leq r
, so
u\in\overline{B_{r}}
.

Convex:
For any
u_{1},u_{2}\in\overline{B_{r}}
and
\lambda\in[0,1]
, we need to show
\lambda u_{1}+(1-\lambda)u_{2}\in E
and
\|\lambda u_{1}+(1-\lambda)u_{2}\|_{\infty}\leq r
.

For convexity, let
u_{1},u_{2}\in\overline{B_{r}}
and
\lambda\in[0,1]
. Set

. Using the decomposition

u_{\lambda}=\lambda(v_{1}+w_{p})+(1-\lambda)(v_{2}+w_{p})=\lambda v_{1}+(1-\lambda)v_{2}+w_{p}.

Since

is a linear space,
\lambda v_{1}+(1-\lambda)v_{2}\in E_{0}
, so

(2.2)

Since

\overline{B_{r}}

\overline{B_{r}}
is compact. The hypotheses of Brouwer’s theorem are satisfied, guaranteeing the existence of a fixed point.
∎

such that
|\widetilde{f}|\leq M
for any
t_{i}\in\mathbb{T}
.
∎

Therefore, we study the auxiliary problem below:

\begin{cases}u^{\Delta\Delta}(t_{i-1})+\widetilde{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))=0,&i\in\{1,2,\ldots,n+1\}\\
u^{\Delta}(t_{0})=0\\
u(t_{n+2})=g(t_{n+2})\end{cases}

(3.3)

Claim:
If
\alpha(t_{i})\leq u(t_{i})\leq\beta(t_{i})
for all
i\in\{0,1,\ldots,n+2\}
, then Auxiliary Problem (
3.3
) is equivalent to Main Problem (
1.1
).

Proof.

Note that, when we plug in
z=u(t_{i-1})
in the expression of
\sigma(t_{i},z)
given in (
3.2
), we get

\sigma(t_{i},u(t_{i-1}))=\begin{cases}\beta(t_{i-1})&\text{if }u(t_{i-1})>\beta(t_{i-1})\\
u(t_{i-1})&\text{if }\alpha(t_{i-1})\leq u(t_{i-1})\leq\beta(t_{i-1})\\
\alpha(t_{i-1})&\text{if }u(t_{i-1})<\alpha(t_{i-1})\end{cases}

which implies,

\sigma(t_{i},u(t_{i-1}))=u(t_{i-1})\quad\text{if }\alpha(t_{i-1})\leq u(t_{i-1})\leq\beta(t_{i-1}).

Therefore, if
\alpha(t_{i})\leq u(t_{i})\leq\beta(t_{i})
for all
i\in\{0,1,\ldots,n+2\}
, then we get

\displaystyle\widetilde{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))

\displaystyle=\widetilde{f}\left(t_{i},u(t_{i}),\frac{u(t_{i})-u(t_{i-1})}{t_{i}-t_{i-1}}\right)

\displaystyle={f}\left(t_{i},u(t_{i}),\frac{u(t_{i})-\sigma(t_{i},u(t_{i-1}))}{t_{i}-t_{i-1}}\right)

\displaystyle=f\left(t_{i},u(t_{i}),\frac{u(t_{i})-u(t_{i-1})}{t_{i}-t_{i-1}}\right)

\displaystyle={f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1})),

which establishes the claim.
∎

Consequently, if we can find a solution
u(t_{i})
of Problem (
3.3
) such that
\alpha(t_{i})\leq u(t_{i})\leq\beta(t_{i})
for all
i\in\{0,1,\ldots,n+2\}
, then we can conclude that the solution
u(t_{i})
is in fact a solution of Problem (
1.1
)

3.2.
Construction of the Operator
T

With the auxiliary problem established, we now construct the solution operator

whose fixed points are in fact solutions of Problem (

). In order to do that, we establish the following two lemmas which are essential for our purposes.

Lemma 3.2
.

If
u
satisfies (
1.1
), then

u^{\Delta}(t_{k})=-\sum_{i=1}^{k}h_{i-1}\widetilde{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))

for
k=1,2,\ldots,n+1
.

Proof.

Here we utilize proof by induction. First, let us show the base cases. We start with
k=1
:

\displaystyle u^{\Delta\Delta}(t_{0})

\displaystyle=\frac{u^{\Delta}(t_{1})-u^{\Delta}(t_{0})}{h_{0}}

\displaystyle\Rightarrow-\widetilde{f}(t_{1},u(t_{1}),u^{\Delta}(t_{0}))

\displaystyle=\frac{u^{\Delta}(t_{1})-0}{h_{0}}

\displaystyle\Rightarrow u^{\Delta}(t_{1})

\displaystyle=-h_{0}\widetilde{f}(t_{1},u(t_{1}),u^{\Delta}(t_{0}))

Next, let us check for
{u^{\Delta}(t_{2})}\colon

\displaystyle u^{\Delta\Delta}(t_{1})

\displaystyle=\frac{u^{\Delta}(t_{2})-u^{\Delta}(t_{1})}{h_{1}}

\displaystyle\Rightarrow-h_{1}\widetilde{f}(t_{2},u(t_{2}),u^{\Delta}(t_{1}))

\displaystyle=u^{\Delta}(t_{2})-u^{\Delta}(t_{1})

\displaystyle\Rightarrow u^{\Delta}(t_{2})

\displaystyle=-h_{1}\widetilde{f}(t_{2},u(t_{2}),u^{\Delta}(t_{1}))-h_{0}\widetilde{f}(t_{1},u(t_{1}),u^{\Delta}(t_{0}))

\displaystyle=-\displaystyle\sum_{i=1}^{2}h_{i-1}\widetilde{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))

Then, let us check for the the case
k=3\colon

\displaystyle u^{\Delta\Delta}(t_{2})

\displaystyle=\frac{u^{\Delta}(t_{3})-u^{\Delta}(t_{2})}{h_{2}}

\displaystyle\Rightarrow-h_{2}\widetilde{f}(t_{3},u(t_{3}),u^{\Delta}(t_{2}))

\displaystyle=u^{\Delta}(t_{3})-u^{\Delta}(t_{2})

\displaystyle\Rightarrow u^{\Delta}(t_{3})

\displaystyle=-h_{2}\widetilde{f}(t_{3},u(t_{3}),u^{\Delta}(t_{2}))-h_{1}\widetilde{f}(t_{2},u(t_{2}),u^{\Delta}(t_{1}))-

\displaystyle h_{0}\widetilde{f}(t_{1},u(t_{1}),u^{\Delta}(t_{0}))

\displaystyle=-\displaystyle\sum_{i=1}^{3}h_{i-1}\widetilde{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))

Checking the pattern, let us assume the formula holds for
k
, and

u^{\Delta}(t_{k})=-\displaystyle\sum_{i=1}^{k}{h_{i-1}\widetilde{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))}

Thereafter, we will show this formula holds for
t_{k+1}
.

\displaystyle u^{\Delta\Delta}(t_{k})

\displaystyle=\frac{u^{\Delta}(t_{k+1})-u^{\Delta}(t_{k})}{h_{k}}

\displaystyle\Rightarrow-\widetilde{f}(t_{k+1},u(t_{k+1}),u^{\Delta}(t_{k}))

\displaystyle=\frac{u^{\Delta}(t_{k+1})-u^{\Delta}(t_{k})}{h_{k}}

\displaystyle u^{\Delta}(t_{k+1})

\displaystyle=u^{\Delta}(t_{k})-h_{k}\widetilde{f}(t_{k+1},u(t_{k+1}),u^{\Delta}(t_{k}))

\displaystyle=-\displaystyle\sum_{i=1}^{k}{h_{i-1}\widetilde{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))}-h_{k}\widetilde{f}(t_{k+1},u(t_{k+1}),u^{\Delta}(t_{k}))

\displaystyle=-\displaystyle\sum_{i=1}^{k+1}{h_{i-1}\widetilde{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))}

From here, we can conclude, by mathematical induction,

u^{\Delta}(t_{k})=-\sum_{i=1}^{k}h_{i-1}\widetilde{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))

(3.4)

for
k=1,2,\ldots,n+1
. This completes the proof.
∎

Lemma 3.3
.

If
u
satisfies (

), then

(3.5)

,

,
k=n

For

\displaystyle u(t_{n+2})

Step 2:

Next step we show that

3.3.
Fixed Point of Operator
T

Having constructed the solution operator
T:E\to E
in the previous section, we now verify the properties necessary for applying Brouwer’s Fixed Point Theorem.

Lemma 3.4

(Continuity of Operator
T
)
.

The operator
T:E\to E
defined by (
3.12
) is continuous.

Proof.

For each
k\in\{0,1,\ldots,n+2\}
, the function
T(u(t_{k-1}))
is defined as

T(u(t_{k}))=g(t_{n+2})+\sum_{j=k}^{n+1}h_{j}\sum_{i=1}^{j}h_{i-1}\widetilde{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1})).

(3.17)

Since auxiliary function
\widetilde{f}
is continuous,
g
is continuous by assumption
(A3)
, the operator
T
is continuous as a finite composition of continuous functions.
∎

Proposition 3.5

(Invariance of Ball)
.

Let
\overline{B_{r}}=\{u\in E:\|u\|_{\infty}\leq r\}
where
\|u\|_{\infty}=\max_{t\in\mathbb{T}}|u(t)|
. If

r\geq g(t_{n+2})+M(t_{n+2}-t_{0})^{2},

(3.18)

where
M
is the upperbound of
\widetilde{f}
,
then
T(\overline{B_{r}})\subseteq\overline{B_{r}}
.

Proof.

Let
u\in\overline{B_{r}}
, so
\|u\|_{\infty}\leq r
. We must show that
\|Tu\|_{\infty}\leq r
.

For any
k\in\{0,1,\ldots,n+2\}
, we have

\displaystyle|T(u(t_{k}))|

\displaystyle=\left|g(t_{n+2})+\sum_{j=k}^{n+1}h_{j}\sum_{i=1}^{j}h_{i-1}\widetilde{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))\right|

\displaystyle\leq|g(t_{n+2})|+\left|\sum_{j=k}^{n+1}h_{j}\sum_{i=1}^{j}h_{i-1}\widetilde{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))\right|

\displaystyle\leq g(t_{n+2})+\sum_{j=k}^{n+1}h_{j}\sum_{i=1}^{j}h_{i-1}|\widetilde{f}(t_{i},u(t_{i}),u^{\Delta}(t_{i-1}))|

\displaystyle\leq g(t_{n+2})+M\sum_{j=k}^{n+1}h_{j}\sum_{i=1}^{j}h_{i-1},

where the last inequality follows from the boundedness of
\widetilde{f}
.
Since
j\leq n+1
,

\displaystyle\sum_{i=1}^{j}h_{i-1}

\displaystyle\leq\sum_{i=1}^{n+1}h_{i-1}

\displaystyle=\sum_{i=1}^{n+1}(t_{i}-t_{i-1})

\displaystyle=t_{1}-t_{0}+t_{2}-t_{1}+\cdots+t_{n+1}-t_{n}

\displaystyle=(t_{n+1}-t_{0})<(t_{n+2}-t_{0}),

and since
k\geq 0
,

\displaystyle\sum_{j=k}^{n+1}h_{j}

\displaystyle\leq\sum_{j=0}^{n+1}h_{j}

\displaystyle=\sum_{j=0}^{n+1}(t_{j+1}-t_{j})

\displaystyle=t_{1}-t_{0}+t_{2}-t_{1}+\cdots+t_{n+2}-t_{n+1}

\displaystyle=(t_{n+2}-t_{0}).

Therefore,

|T(u(t_{k}))|<g(t_{n+2})+M(t_{n+2}-t_{0})^{2}
.
By our choice of
r
, this gives
|T(u(t_{k}))|\leq r
for all
k\in\{0,1,\ldots,n+2\}
. Consequently,
\|Tu\|_{\infty}=\max_{k}|T(u(t_{k}))|\leq r
, which implies
Tu\in\overline{B_{r}}
.
∎

Therefore, employing Brouwer’s fixed point theorem (see Corollary
2.11
) one can conclude that
T
has a fixed point in
\overline{B(r)}
. In other words, there exists
u\in\overline{B(r)}
, such that
T(u^{*}(t_{k}))=u^{*}(t_{k})
for all
k\in\{0,1,\ldots,n+2\}
.

Remark 3.6
.

Note that in the two dimensional setting, we can think of
\overline{B(r)}
as a circle of radius
r
, whereas in three dimensional setting, as a sphere with radius
r
.

4.
Verification of Bounds

The final step shows any solution
u
satisfies
\alpha(t_{i})\leq u(t_{i})\leq\beta(t_{i})
for all
i\in\{0,1,\ldots,n+2\}
. We prove this by contradiction in two parts.

4.1.
Proof that
u(t_{i})\leq\beta(t_{i})

Suppose there exists some index
\ell\in\{0,1,\ldots,n+2\}
such that
u(t_{\ell})>\beta(t_{\ell})
. Define the maximum violation

M=\max\{u(t_{i})-\beta(t_{i}):i\in\{0,1,\ldots,n+2\}\}>0.

(4.1)

Let
\ell
be an index where this maximum is achieved, so
u(t_{\ell})-\beta(t_{\ell})=M>0
.

We consider three cases for the location of
\ell
.

Case 1:

\ell=0
. From the boundary condition
u^{\Delta}(t_{0})=0
and the upper solution condition
\beta^{\Delta}(t_{0})\leq 0
, we have

u^{\Delta}(t_{0})-\beta^{\Delta}(t_{0})=0-\beta^{\Delta}(t_{0})\geq 0.

This implies

\frac{u(t_{1})-u(t_{0})}{h_{0}}\geq\frac{\beta(t_{1})-\beta(t_{0})}{h_{0}},

which gives us
u(t_{1})-\beta(t_{1})\geq u(t_{0})-\beta(t_{0})=M
. Since
M
is the maximum violation, we must have
u(t_{1})-\beta(t_{1})=M
, meaning the maximum is also achieved at
t_{1}
. We can therefore consider
\ell=1
instead.

Case 2:

\ell=n+2
. From the boundary conditions
u(t_{n+2})=g(t_{n+2})
and
\beta(t_{n+2})\geq g(t_{n+2})
, we obtain

u(t_{n+2})-\beta(t_{n+2})=g(t_{n+2})-\beta(t_{n+2})\leq 0.

This contradicts our assumption that
u(t_{n+2})-\beta(t_{n+2})=M>0
.

Case 3:

\ell\in\{1,2,\ldots,n+1\}
. Since
\ell
achieves the maximum of
u(t_{i})-\beta(t_{i})
, we have
u(t_{i})-\beta(t_{i})\leq u(t_{\ell})-\beta(t_{\ell})=M
for all
i
. Since
\ell
is a maximum point of the function
w(t_{i})=u(t_{i})-\beta(t_{i})
, the discrete second derivative satisfies

(u-\beta)^{\Delta\Delta}(t_{\ell-1})\leq 0.

(4.2)

This follows from the discrete analogue of the second derivative test.

From the auxiliary problem (
3.3
),
u
satisfies

u^{\Delta\Delta}(t_{\ell-1})+\widetilde{f}(t_{\ell},u(t_{\ell}),u^{\Delta}(t_{\ell-1}))=0.

and from the definition of upper solution outlined in (
1.7
), we have

\beta^{\Delta\Delta}(t_{\ell-1})+f(t_{\ell},\beta(t_{\ell}),\beta^{\Delta}(t_{\ell-1}))\leq 0.

Since
u(t_{\ell})>\beta(t_{\ell})
, by plugging in
x=u(t_{\ell})
and
z=u(t_{\ell-1})
in the definition of
\widetilde{f}
outlined in equation (
3.1
), we have

\displaystyle\widetilde{f}(t_{\ell},u(t_{\ell}),u^{\Delta}(t_{\ell-1}))=

\displaystyle\widetilde{f}\left(t_{\ell},u(t_{\ell}),\frac{u(t_{\ell})-u(t_{\ell-1})}{h_{\ell-1}}\right)

\displaystyle\Rightarrow\widetilde{f}(t_{\ell},u(t_{\ell}),u^{\Delta}(t_{\ell-1}))=

\displaystyle f\left(t_{\ell},\beta(t_{\ell}),\frac{\beta(t_{\ell})-\sigma(t_{\ell},u(t_{\ell-1}))}{h_{\ell-1}}\right)-\frac{u(t_{\ell})-\beta(t_{\ell})}{u(t_{\ell})-\beta(t_{\ell})+1}

\displaystyle\Rightarrow-\widetilde{f}(t_{\ell},u(t_{\ell}),u^{\Delta}(t_{\ell-1}))=

\displaystyle-f\left(t_{\ell},\beta(t_{\ell}),\frac{\beta(t_{\ell})-\sigma(t_{\ell},u(t_{\ell-1}))}{h_{\ell-1}}\right)+\frac{u(t_{\ell})-\beta(t_{\ell})}{u(t_{\ell})-\beta(t_{\ell})+1}.

(4.3)

Now, from the definition of
\sigma
given in Eq. (
3.2
),

\sigma(t_{\ell},u(t_{\ell-1}))=\begin{cases}\beta(t_{\ell-1}),&\text{if }u(t_{\ell-1})>\beta(t_{\ell-1}),\\
u(t_{\ell-1}),&\text{if }\alpha(t_{\ell-1})\leq u(t_{\ell-1})\leq\beta(t_{\ell-1}),\\
\alpha(t_{\ell-1}),&\text{if }u(t_{\ell-1})<\alpha(t_{\ell-1}),\end{cases}

which implies
\sigma(t_{\ell},u(t_{\ell-1}))\leq\beta(t_{\ell-1})
. Therefore, using the assumption
(A2)
:
f
is non-increasing in its third variable we obtain,

-f\left(t_{\ell},\beta(t_{\ell}),\frac{\beta(t_{\ell})-\sigma(t_{\ell},u(t_{\ell-1}))}{h_{\ell-1}}\right)\geq-f(t_{\ell},\beta(t_{\ell}),\beta^{\Delta}(t_{\ell-1}))

(4.4)

Therefore, combining Eq.s (
3.3
), (
1.7
), (
4.1
) and (
4.4
), we obtain,

u^{\Delta\Delta}(t_{\ell-1})-\beta^{\Delta\Delta}(t_{\ell-1})\geq\frac{u(t_{\ell})-\beta(t_{\ell})}{u(t_{\ell})-\beta(t_{\ell})+1}>0.

(4.5)

which clearly contradicts Eq. (
4.2
). This completes the proof.
