Ratio set of a non-singular group action

Definition 1.12
.

Given an ergodic non-singular group action
G\curvearrowright(X,\mathcal{B},\mu)
on a standard measure space, a
real-valued cocycle
is a function
c:G\times X\rightarrow\mathbb{R}

c(g_{1}g_{2},x)=c(g_{1},x)c(g_{2},g_{1}^{-1}x)

G
-action is defined as the following:

D:G\times X\rightarrow\mathbb{R},\hskip 8.5359pt(g,x)\mapsto\frac{d(g\mu)}{d\mu}(x)

and we can see for any

\mu
-almost every

\frac{d(g_{2}\mu)}{d\mu}\big(g_{1}^{-1}x\big)=\frac{d(g_{1}g_{2})\mu}{dg_{1}\mu}(x)\hskip 17.07182pt\Longrightarrow\hskip 17.07182pt\frac{d(g_{1}g_{2})\mu}{d\mu}(x)=\frac{dg_{1}\mu}{d\mu}(x)\,\frac{dg_{2}\mu}{d\mu}\big(g_{1}^{-1}x\big)

If we let
R
denote the orbit equivalence of the given group action (as a subset of

), we can define the Radon-Nikodym cocycle in the following way: for any

D(x,gx)=\frac{d\big(g^{-1}\mu\big)}{d\mu}(x)

2.
Main theorems

In this section, we will show that given a Bernoulli scheme, to find its ratio set, there is no need to consider all partial isomorphisms but only those that are of the form of bijections between two elementary cylinder sets of the same length. This is inspired by the definition of an asymptotic ratio set (
Definition
1.5
). We will start by discussing the correspondence between a Bernoulli scheme and an ITPFI factor.

Given a Bernoulli scheme
G\curvearrowright(X,\mathcal{B},\mu)
, for each

, suppose

:

•

if

•

Proposition 2.16
.

Given a type-

Proof.

\displaystyle=\left(\sum_{n\in\mathcal{N}(0)}(-1)^{x_{n}-y_{n}}\big(-\epsilon_{n}-\log(1-e^{-\epsilon_{n}})\big)\right)+\left(\sum_{n\in\mathcal{N}(1)}(-1)^{x_{n}-y_{n}}\big(-\epsilon_{n}+\log\lambda\big)\right)
