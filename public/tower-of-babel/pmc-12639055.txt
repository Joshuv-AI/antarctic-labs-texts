Research on adaptive distributed optimal resource allocation consistency algorithm in WAN environment
Authors: Ling Sun
Published: 2025

ABSTRACT
AbstractIn wide-area networks (WANs), efficiently allocating distributed resources presents a significant challenge due to increasing node numbers and complex network conditions. Traditional algorithms, which heavily depend on global information, encounter scalability limitations. This study proposes an adaptive distributed optimal resource allocation consistency algorithm designed for WANs. The approach dynamically adjusts resource allocation based on real-time network conditions and user requirements, reducing dependence on global data. A time window distribution model and an information coding model are employed to optimize the resource allocation process. By integrating a Q-learning algorithm and extending the Paxos algorithm to WANs, global consistency among network nodes is ensured. The experimental results demonstrate the algorithm’s superior performance, particularly in low-bandwidth WAN scenarios (below 2 Mb/s), where it significantly enhances throughput. An average resource utilization rate exceeding 97% is achieved, along with rapid convergence and high parallelism. This research underscores the algorithm’s effectiveness and scalability, providing a robust solution to distributed resource allocation challenges in complex WAN environments.Keywords: WAN environment, Self-adaptation, Distributed, Optimal resources, Resource allocation, Consistency algorithmSubject terms: Engineering, Mathematics and computing

Introduction

With the rapid development of cloud computing, the Internet of Things (IoT), big data, and related technologies, distributed systems have emerged as the foundational infrastructure supporting these technologies. Distributed systems achieve high availability, scalability, and load balancing by distributing tasks and resources across multiple network nodes. However, they also encounter numerous challenges, including the need for optimal resource allocation in WAN environments while ensuring data consistency across nodes1,2. The resource allocation problem, also known as the economic dispatch problem, has garnered significant attention across multiple interdisciplinary fields. In distributed systems, resource allocation must consider the requirements of multiple nodes, resource availability, network conditions, and other influencing factors. Especially in wide-area network (WAN) environments, traditional centralized resource allocation methods often prove inadequate due to communication delays and bandwidth constraints between nodes. In distributed systems, resource allocation and data consistency are inherently interconnected. Distributed resource allocation seeks to optimize resource distribution across nodes to satisfy heterogeneous demands, while distributed consistency guarantees that all nodes maintain a unified perspective of the system state, including resource availability. Inconsistent data among nodes may lead to erroneous resource allocation, degraded system performance, and potential system failures. Consequently, research on distributed consistency algorithms is crucial for maintaining the stability and reliability of distributed systems.

Parween et al.3 implement conflict control and efficient resource allocation in LoRaWAN networks using TCP protocol, perform multi-hop clustering of LoRaWAN nodes and gateways with the MBKMC algorithm, utilize the IMPGBDT algorithm for collision detection, employed OOA for collision avoidance based on channel transmission signal strength, and allocate resource requests using DQN and PMMRA algorithms. However, their approach involves multiple complex algorithms, potentially increasing computational overhead and system complexity. Guo et al.4 propose a low-complexity, fairness-aware multi-source WPCN resource allocation design considering actual nonlinear energy harvesting processes. For block length allocation, they verify error probability convexity under energy harvesting constraints and obtain effective suboptimal solutions through alternating optimization of two subproblems. However, this decomposition approach may be time-consuming in large-scale systems, potentially affecting real-time allocation performance. Xu et al.5 apply 3D detection for environmental object extraction from multi-camera images, design a DNN for user identification via location distribution estimation using images and beam pairs, and propose an image-based resource allocation method to reduce time and spectrum overhead. However, 3D detection and user identification accuracy may be compromised by environmental factors like lighting conditions and object occlusion, potentially impacting allocation effectiveness. Logeshwaran et al.6 propose a load-based dynamic channel allocation (LB-DCA) model employing various control schemes, interference estimation, and channel load balancing mechanisms for effective wireless resource management. The model demonstrates good performance in CSI, MCC, delta-P, FMI, BMI, spectral efficiency, scalability, signal quality, power control, and energy efficiency. However, its performance depends heavily on control scheme and interference estimation accuracy, where inaccuracies may lead to suboptimal allocation. Li Yun et al.7 propose a WAN resource allocation algorithm based on mobile edge computing, designing a hybrid optimization model combining MARL and game theory. They establish a hierarchical resource architecture, employ MARL for distributed decision-making and learning allocation strategies, and incorporate non-cooperative game models to optimize user resource competition. However, the dynamic environment necessitates frequent model retraining, consuming substantial edge computing resources and potentially affecting allocation quality. Tan Ling et al.8 propose a WAN resource allocation algorithm using multiple drones, designing a “distributed collaborative decision-making with centralized global optimization” hybrid framework. They apply MADDPG for autonomous perception and dynamic allocation, implement conflict avoidance mechanisms, and generate global allocation benchmarks through federated learning. However, individual drones only perceive local channels and task status, with global information relying on communication that may suffer from WAN latency-induced strategy inconsistencies. Huang Jie et al.9 propose a WAN ultra-dense resource allocation algorithm using graph convolutional neural networks, modeling the network as a dynamic heterogeneous graph, designing a two-layer GCN model, and incorporating reinforcement learning for strategy construction. However, centralized GCN inference depends on feedback links vulnerable to single-point failures, while edge deployment faces hardware limitations in supporting complex model computations. Q. P D C et al.10 propose an adaptive Markov model using cache queue and channel states to represent CP-OFDM systems, developing a resource allocation scheme with a novel utility function based on Q-learning. However, in complex networks, Q-learning convergence speed may be insufficient for real-time allocation requirements. Li H et al.11 propose an adaptive allocation algorithm for 5G vehicular network mobile cloud communication resources, first identifying in-band and out-of-band communication modes, calculating transmission rates and bandwidths under different modes, and determining optimal allocation through objective function optimization. However, solving the objective function proves computationally intensive in large-scale vehicular networks, potentially compromising real-time performance.

Consequently, investigating novel adaptive distributed optimal resource allocation consistency algorithms carries substantial significance. The proposed methodology distinguishes itself through its innovative integration of a time window distribution model, information coding model, Q-learning algorithm, and an extended Paxos algorithm specifically designed for wide area networks. In contrast to conventional approaches that frequently depend extensively on global data or incorporate computationally intensive procedures, this technique dynamically adapts resource allocation in real-time, rapidly responding to fluctuating network conditions and user requirements. For cloud computing resource scheduling involving 1000GB of resources, the method achieves a response time of 2.5 s, significantly outperforming the 12.1 s reported in reference7 and 18.9 s in reference8. By streamlining the resource allocation process through inventive modeling and employing reinforcement learning for adaptive strategy development, it diminishes computational overhead while enhancing system efficiency. Moreover, the extended Paxos algorithm guarantees global node consistency even when confronted with network latency and potential failures, thereby reinforcing system robustness. This comprehensive solution effectively resolves distributed resource allocation challenges in complex wide area network environments, optimizing resource utilization and strengthening system resilience.

Implementation of resource allocation consistency based on W-Paxos algorithm

In distributed systems, asynchronous operations and inter-node communication delays may result in inconsistent resource allocation outcomes. Consequently, it is imperative to design effective consistency protocols and algorithms to guarantee that all nodes maintain coherent views and consistent decision-making results throughout the resource allocation process. This approach enhances system stability and reliability while minimizing errors and conflicts arising from inconsistencies. Compared with local area networks, wide area networks typically exhibit higher latency, are substantially constrained by bandwidth limitations, and demonstrate a relatively higher packet loss probability during communication25. These inherent WAN characteristics significantly impair the efficiency and performance of the Paxos algorithm. To overcome these limitations, the W-PaxOS algorithm is specifically designed to optimize WAN communication by employing proxy servers within each data center. In the W-PaxOS framework, the leader node transmits an identical number of messages to proxy servers across different data centers. These proxy servers subsequently assume responsibility for disseminating the messages to all servers within their local data centers. This communication strategy effectively mitigates the leader node’s workload and reduces cross-data-center communication overhead, thereby substantially improving the algorithm’s overall performance.

In W-PaxOS, nodes within a datacenter elect a proxy server through the Paxos consensus algorithm. Should the current proxy server fail, the system employs the Paxos protocol to select a new proxy server from the available operational nodes, whereupon the newly elected proxy server notifies all replica servers across the system via status update messages.

In the Paxos algorithm, consensus is achieved through majority agreement among replica servers. Consequently, the proxy server need not await responses from all replicas within its data center before forwarding messages to the leader. To minimize latency, this paper introduces an optimization strategy wherein proxy servers aggregate responses from a majority of local replicas before reporting to the leader. Under normal operation, all proxy servers in the system forward received replies to the leader. Thus, the leader ultimately accumulates responses exceeding half of the total replica servers in the system, which satisfies the requirement for consensus completion. This accelerated recovery mechanism prevents system-wide performance degradation caused by a minority of slow nodes. Figure 1 illustrates the implementation workflow of this optimized algorithm.

Conclusion

This study investigates the consistency algorithm for adaptive distributed optimal resource allocation in WAN environments. A novel consistency filter incorporating time-varying weighting coefficients is proposed to enhance flexibility and adaptability in node state iteration processes. Through dynamic adjustment of these weighting coefficients based on real-time network conditions and load variations, the consistency filter’s performance can be optimally tuned, thereby significantly improving both system consistency and convergence speed while maintaining robust operation under diverse network states.

Although the proposed algorithm shows promising performance in WAN environments, it reveals critical vulnerabilities regarding security and privacy protection. The current design lacks comprehensive defense mechanisms against sophisticated cyber attacks. Transmission data within WANs remains particularly vulnerable to interception, manipulation, and unauthorized access attempts. The implementation’s insufficient integration of advanced encryption techniques specifically designed for distributed architectures could potentially expose sensitive resource allocation information. Moreover, the existing privacy preservation framework demonstrates notable limitations. In large-scale WAN deployments involving multiple entities with diverse privacy requirements, the algorithm inadequately addresses these heterogeneous policy demands, creating possible privacy violation risks during inter-node data exchanges.

Future research directions should prioritize the development of adaptive distributed resource allocation algorithms featuring reduced computational complexity and enhanced real-time performance. Algorithm execution efficiency and response latency can be significantly improved through the integration of advanced optimization techniques and parallel computing architectures. Furthermore, comprehensive security and privacy preservation considerations must be fundamentally incorporated into the algorithmic framework. This necessitates the systematic implementation of state-of-the-art encryption schemes, robust access control frameworks, and rigorous privacy-preserving protocols to ensure secure data exchange and confidential communications throughout the resource allocation process.
