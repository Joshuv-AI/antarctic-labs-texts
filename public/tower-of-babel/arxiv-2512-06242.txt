Reasoning about concurrent loops and recursion with rely-guarantee rules
Ian J. Hayes, Larissa A. Meinicke, Cliff B. Jones

Abstract
The objective of this paper is to present general, mechanically verified, refinement rules for reasoning about recursive programs and while loops in the context of concurrency. Unlike many approaches to concurrency, we do not assume that expression evaluation is atomic. We make use of the rely-guarantee approach to concurrency that facilitates reasoning about interference from concurrent threads in a compositional manner. Recursive programs can be defined as fixed points over a lattice of commands and hence we develop laws for reasoning about fixed points. Loops can be defined in terms of fixed points and hence the laws for recursion can be applied to develop laws for loops.

Aczel trace semantics.

The semantic model for the lattice of commands consists of sets of Aczel traces

An Aczel trace consists of a possibly infinite sequence of state-to-state transitions

A trace may be either terminating, aborting or incomplete.
Sets of traces corresponding to commands are

The language includes the following three binary operators:

Our motivation above focused on boolean expressions

Fair termination

The command
\mathbf{\color[rgb]{0,0,0}fair}\mathrel{\widehat{=}}(\epsilon^{\star}\mathbin{;}\pi)^{\omega}\mathbin{;}\epsilon^{\star}
disallows an infinite contiguous sequence of environment transitions
[
18
]
.
Fair execution of a command

can be represented as
c\mathbin{\Cap}\mathbf{\color[rgb]{0,0,0}fair}
,
which rules out an infinite contiguous sequence of environment transitions when executing
c
, unless
c
aborts.
The command
\mathbf{\color[rgb]{0,0,0}term}
allows only a finite number of program transitions
but does not rule out an infinite contiguous sequence of environment transitions,
however,
\mathbf{\color[rgb]{0,0,0}term}\mathbin{\Cap}\mathbf{\color[rgb]{0,0,0}fair}=\boldsymbol{\alpha}^{\star}
and hence allows only a finite number of transitions.
Thus if a command
c
refines
\mathbf{\color[rgb]{0,0,0}term}
, then
c\mathbin{\Cap}\mathbf{\color[rgb]{0,0,0}fair}
only performs a finite number of transitions, i.e.

c\mathbin{\Cap}\mathbf{\color[rgb]{0,0,0}fair}\mathrel{\preceq}\mathbf{\color[rgb]{0,0,0}term}\mathbin{\Cap}\mathbf{\color[rgb]{0,0,0}fair}=\boldsymbol{\alpha}^{\star}
.
Hence it is sufficient to show that a command
c
refines
\mathbf{\color[rgb]{0,0,0}term}

in order to show fair execution of
c
only makes a finite number of transitions.
The reader is referred to
[
18
]
for a more thorough treatment of fairness in our theory.

Related work.

Dingel
[
12
]
handles fairness by defining the trace semantics of his parallel operator to only allow fair interleaving.
Because the semantics of Schellhorn et al.
[
35
]
explicitly alternates between a program transition and an environment transition
(corresponding to any number of our environment transitions),
it implicitly corresponds to fair execution.
Our approach allows one to decouple fair execution and allows a simpler definition of the parallel operator
[
18
]
.

7
Conclusion

The main contributions of this work are to provide
general
laws for reasoning about recursion and while loops,
including termination arguments based on a variant and a well-founded relation,
both in the context of interference from concurrent threads.
Our laws are early termination versions because these more general rules are required in the context of concurrency.
We do not assume either expressions or assignment commands are atomic
but use a fine-grained definition of expressions along with a set of inference rules
that allow compositional reasoning about expressions, including guards.
In our approach l-values can be either base variables or indexed arrays.
Importantly, evaluation of the l-value for an indexed array is done before dereferencing its value,
so that atomicity is only required for accessing individual array elements, not the whole array.
The concurrency theory used in this paper has been formalised within
the Isabelle/HOL theorem prover
[
32
]
, and the results
presented in this paper have been verified in that theory.
