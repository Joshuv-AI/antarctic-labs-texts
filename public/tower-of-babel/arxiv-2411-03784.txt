Optimal prefix-suffix queries with applications
Solon P. Pissis

Abstract
We revisit the classic border tree data structure [Gu, Farach, Beigel, SODA 1994] that answers the following prefix-suffix queries on a string T T of length n n over an integer alphabet Σ = [ 0 , σ ) \Sigma=[0,\sigma) : for any i , j ∈ [ 0 , n ) i,j\in[0,n) return all occurrences of T T in T ⁡ [ 0 ​ . . ​ i ] ​ T ​ [ j ​ . . ​ n − 1 ] T[0\mathinner{.\,.}i]T[j\mathinner{.\,.}n-1] . The border tree of T T can be constructed in 𝒪 ⁡ ( n ) \mathcal{O}(n) time and answers prefix-suffix queries in 𝒪 ⁡ ( log ⁡ n + Occ ) \mathcal{O}(\log n+\textsf{Occ}) time, where Occ is the number of occurrences of T T in T ⁡ [ 0 ​ . . ​ i ] ​ T ​ [ j ​ . . ​ n − 1 ] T[0\mathinner{.\,.}i]T[j\mathinner{.\,.}n-1] . Our contribution here is the following. We present a completely different and remarkably simple data structure that can be constructed in the optimal 𝒪 ⁡ ( n / log σ ⁡ n ) \mathcal{O}(n/\log_{\sigma}n) time and supports queries in the optimal 𝒪 ⁡ ( 1 ) \mathcal{O}(1) time. Our result is based on a new structural lemma that lets us encode the output of any query in constant time and space . We also show a new direct application of our result in pattern matching on node-labeled graphs.

Introduction

Let
T=T[0\mathinner{.\,.}n-1]=T[0\mathinner{.\,.}n)
be a string of length
n
over an integer alphabet
\Sigma=[0,\sigma)
with
\sigma=n^{\mathcal{O}(1)}
.
We would like to preprocess
T
in order to answer the following type of queries: for any
i,j\in[0,n)
, return all occurrences of
T
in
T[0\mathinner{.\,.}i]T[j\mathinner{.\,.}n-1]
. This type of query, which we denote here by
\textsf{PrefSuf}(i,j)
, is supported by the classic
border tree
data structure in
\mathcal{O}(\log n+\textsf{Occ})
time after an
\mathcal{O}(n)
-time preprocessing
[
17
]
. We show the following optimal data structure for
\textsf{PrefSuf}(i,j)
queries.

Theorem 1
.

For any string
T
of length
n
over an alphabet
\Sigma=[0,\sigma)
with
\sigma=n^{\mathcal{O}(1)}
,
we can answer
\textsf{PrefSuf}(i,j)
queries, for any
i,j\in[0,n)
, in
\mathcal{O}(1)
time after an
\mathcal{O}(n/\log_{\sigma}n)
-time preprocessing. The data structure size is
\mathcal{O}(n/\log_{\sigma}n)
and the output is given as a compact representation of
\mathcal{O}(1)
size.

In the word RAM model with
w
-bit machine words and
w=\Omega(\log n)
,

T
is represented as an array: each letter occupies one
machine word. However, a single letter can be represented using
\lceil\log\sigma\rceil
bits (i.e., packed representation), which could be (significantly) less than
w
(e.g., for a constant-sized alphabet). Thus, in the word RAM model, it takes
\mathcal{O}(n/\log_{\sigma}n)
words to store
T
and
\mathcal{O}(n/\log_{\sigma}n)
time to read it. Hence
Theorem

1
is
optimal
with respect to the construction time and the query time.

Border tree.

We start with an informal description of the border tree data structure.
The classic KMP algorithm
[
20
]
constructs an automaton over string
T=T[0\mathinner{.\,.}n-1]
. The automaton consists of an initial state and: (1) one state per prefix of
T
numbered from
0
to
n-1
;
(2) a
success
transition from state
i
to state
i+1
; and (3) a
failure
transition from state
i
to the state representing the longest string that is both a prefix and a suffix (known as
border
) of
T[0\mathinner{.\,.}i]
.
The failure transitions form the
failure tree
. Thus any path in the failure tree from the root to a state
i

specifies all the borders of
T[0\mathinner{.\,.}i]
. Since the number of distinct borders of
T[0\mathinner{.\,.}i]
can be
\Theta(n)
, we apply a grouping of the borders based on periodicity that results in the
border tree
: a compacted version of the failure tree with
\mathcal{O}(n)
states and
\mathcal{O}(\log n)
depth. The construction time is
\mathcal{O}(n)
and the size of the data structure is
\mathcal{O}(n)
. To answer a
prefix-suffix
query
\textsf{PrefSuf}(i,j)
, we use the border tree
\mathcal{T}
of
T
and the border tree
\mathcal{T}^{R}
of
T^{R}=T[n-1]\ldots T[0]
. Given that
T
is of a fixed length
n
and the border tree has
\mathcal{O}(\log n)
depth, we need to check
\mathcal{O}(\log n)
pairs of states: one from
\mathcal{T}
and one from
\mathcal{T}^{R}
. For each pair, we solve one linear equation in
\mathcal{O}(1)
time to check for the length constraints. The query time is
\mathcal{O}(\log n+\textsf{Occ})
.

Gu, Farach, and Beigel
[
17
]
used prefix-suffix queries in their dynamic text indexing algorithm to efficiently locate the occurrences of a pattern spanning an edit operation in the text by maintaining the longest prefix and the longest suffix of the pattern occurring right before and right after the edit, respectively. Since its introduction
[
17
]
, the border tree has been used for several pattern matching tasks (e.g.,
[
14
,
3
,
4
,
6
]
).

Our contribution.

We present a completely different and remarkably simple data structure that can be constructed in the optimal
\mathcal{O}(n/\log_{\sigma}n)
time in the word RAM model and answers
\textsf{PrefSuf}(i,j)
queries in the optimal
\mathcal{O}(1)
time. We remark
that it is quite standard to represent the set of occurrences of a string
X
in another string
Y
with
|Y|<2|X|
in
\mathcal{O}(1)
space due to the following folklore fact:

Fact 1

(
[
25
]
)
.

Let
X
and
Y
be strings with
|Y|<2|X|
. The set of occurrences (starting positions) of
X
in
Y
forms a single arithmetic progression.

However, to the best of our knowledge, the set of occurrences of
T
in
T[0\mathinner{.\,.}i]T[j\mathinner{.\,.}n-1]
,
for all
i,j\in[0,n)
, has not been characterized before. To arrive at
Theorem

1
, we prove a structural lemma that lets us encode the output of
\textsf{PrefSuf}(i,j)
queries for any
i,j\in[0,n)
in
constant time and space
. The border tree, and, in particular prefix-suffix queries, have been mainly used in dynamic text indexing algorithms, which however involve many other crucial primitives to arrive at their final query time. We show here instead a new direct application of our data structure in pattern matching on node-labeled graphs, a very active topic of research
[
12
,
10
,
6
,
2
]
. In particular,
we formalize
bipartite pattern matching
as a core problem that underlies any algorithm for pattern matching on node-labeled graphs.
For intuition, consider two nodes
u
and
v
in a directed graph where nodes are labeled by
strings
. Some suffixes of node
u
match some prefixes of a given pattern
P
, and some prefixes of node
v
match some suffixes of
P
.
We would like to have a data structure, constructed over
P
, that takes
\mathcal{O}(1)
time to process the directed edge
(u,v)
. Namely, in this setting, we find all occurrences of
P
spanning
at most two nodes
of the graph. (It is trivial to find the occurrences of
P
in a single node using any linear-time pattern matching algorithm
[
20
]
.)
Indeed, the bipartite pattern matching problem has been (implicitly) introduced by Ascone et al.
[
6
]
for pattern matching on
block graphs
(a restricted version of node-labeled graphs
[
22
,
13
,
26
]
), and the border tree
[
17
]
was used to solve it. If we apply
Theorem

1
on
P
, we can answer
any such query in
\mathcal{O}(1)
time
instead of
\mathcal{O}(\log|P|+\textsf{Occ})
time.

2
Optimal prefix-suffix queries

For a fixed pair
(i,j)
, we set
T^{\prime}=T[0\mathinner{.\,.}i]T[j\mathinner{.\,.}n-1]
. In particular,
T^{\prime}
is a string of length
n+(i-j+1)
.
Let us remark that the relevant cases for
\textsf{PrefSuf}(i,j)
are all
i,j\in[0,n)
such that
i\geq j
, otherwise the answer to the query is trivial: if
j=i+1
, then we have a single occurrence of
T
starting at position
0
of
T^{\prime}
. If
j>i+1
, then we have no occurrence of
T
in
T^{\prime}
because
|T^{\prime}|<n
.
Hence we assume
i\geq j
.

We start with a few standard definitions on strings from
[
11
]
. An integer
p>0
is a
period
of a string
P
if
P[i]=P[i+p]
, for all
i\in[0,|P|-p)
. The smallest period of
P
is referred to as
the period
of
P
and is denoted by
\textsf{per}(P)
. A string
P
is called
periodic
if
\textsf{per}(P)\leq|P|/2
. A
border

B
of a string
P
is a string of length
|B|<|P|
so that
B
occurs as both a prefix and a suffix of
P
.

2
, stating that the notion of border and the notion of period are dual, is well-known.

Fact 2

(
[
11
]
)
.

For every period
p
of a string
P
, there is a border of length
|P|-p
. In particular, the longest border of
P
is of length
|P|-\textsf{per}(P)
.

The periods of any string
P
also satisfy the following well-known lemma.

Lemma 1

(Periodicity lemma
[
15
]
)
.

If
p
and
q
are both periods of a string
P
and satisfy

p+q\leq|P|
, then
\gcd(p,q)
is a period of
P
.

We proceed by showing the main structural lemma of this work.

Lemma 2
.

For any string
T
of length
n
and any
i,j\in[0,n)
such that
i\geq j
,
T[0\mathinner{.\,.}i]T[j\mathinner{.\,.}n-1]
has an occurrence of
T
that is neither a prefix nor a suffix of
T[0\mathinner{.\,.}i]T[j\mathinner{.\,.}n-1]
if and only if
T
is periodic with period
p=\textsf{per}(T)<i-j+1
and
(i-j+1)\mod p=0
.

Proof.

Let us set
T^{\prime}=T[0\mathinner{.\,.}i]T[j\mathinner{.\,.}n-1]
with
|T^{\prime}|=n+(i-j+1)
. Inspect
Fig.

1
for an illustration.

(
\Rightarrow
) For the forward implication, assume
T^{\prime}[j^{\prime}\mathinner{.\,.}i^{\prime}]=T
with
j^{\prime}>0
and
i^{\prime}<|T^{\prime}|-1
; namely,
T
has an occurrence in
T^{\prime}
that it is neither a prefix nor a suffix of
T^{\prime}
. By hypothesis,
|T[0\mathinner{.\,.}i]|\leq n
and
|T[j\mathinner{.\,.}n)|\leq n
.
Since
T[0\mathinner{.\,.}i]=T^{\prime}[0\mathinner{.\,.}i]=T^{\prime}[j^{\prime}\mathinner{.\,.}i+j^{\prime}]
, by
2
,
T^{\prime}[0\mathinner{.\,.}i+j^{\prime}]
has period
j^{\prime}
(in
Fig.

1
,
T^{\prime}[0\mathinner{.\,.}i]=T^{\prime}[j^{\prime}\mathinner{.\,.}i+j^{\prime}]=\texttt{aabaabaaba}
and
j^{\prime}=3
). Symmetrically, since
T[j\mathinner{.\,.}n)=T^{\prime}[i+1\mathinner{.\,.}|T^{\prime}|)=T^{\prime}[i+1-(|T^{\prime}|-i^{\prime}-1)\mathinner{.\,.}i^{\prime}]
, by
2
,
T^{\prime}[i+1-(|T^{\prime}|-i^{\prime}-1)\mathinner{.\,.}|T^{\prime}|)
has period
|T^{\prime}|-i^{\prime}-1
(in
Fig.

1
,
T^{\prime}[i+1\mathinner{.\,.}|T^{\prime}|)=T^{\prime}[i+1-(|T^{\prime}|-i^{\prime}-1)\mathinner{.\,.}i^{\prime}]=\texttt{abaabaaba}
and
|T^{\prime}|-i^{\prime}-1=3
).

Note that because
i\geq j
, string
T^{\prime}[0\mathinner{.\,.}i]=T[0\mathinner{.\,.}i]
has a nonempty string
F
of length
i-j+1
as a suffix
and
string
T^{\prime}[i+1\mathinner{.\,.}|T^{\prime}|)=T[j\mathinner{.\,.}n)
has the same string
F
as a prefix (in
Fig.

1
,
F=\texttt{abaaba}
).

Claim 1
.

|F|=j^{\prime}+(|T^{\prime}|-i^{\prime}-1)
.

Proof.

We have
|T^{\prime}|-i^{\prime}-1+j^{\prime}=n+(i-j+1)-i^{\prime}-1+j^{\prime}
by substituting the length of
T^{\prime}
.
Then
n+(i-j+1)-i^{\prime}-1+j^{\prime}=n+(i-j+1)-n=i-j+1=|F|
because
|T^{\prime}[j^{\prime}\mathinner{.\,.}i^{\prime}]|=n
.
∎

By the above discussion and
1
, string
F
has
both
periods
j^{\prime}
and
|T^{\prime}|-i^{\prime}-1
, and so we can apply
Lemma

1
to get that

F
has period
\gcd(j^{\prime},|T^{\prime}|-i^{\prime}-1)
,
which is also a divisor of
|F|=i-j+1
,
and thus that the whole
T^{\prime}[j^{\prime}\mathinner{.\,.}i^{\prime}]=T
is periodic with period
\gcd(j^{\prime},|T^{\prime}|-i^{\prime}-1)
.
In particular,
\gcd(j^{\prime},|T^{\prime}|-i^{\prime}-1)
is either equal to the period
p=\textsf{per}(T)
or its multiple. Finally, since
j^{\prime}>0
,
i^{\prime}<|T|-1\implies|T^{\prime}|-i^{\prime}-1>0
, and
|F|=j^{\prime}+(|T^{\prime}|-i^{\prime}-1)
, it also follows that
\textsf{per}(T)<|F|
.

(
\Leftarrow
) For the reverse implication, if
T
is periodic with period
p=\textsf{per}(T)<i-j+1
and
(i-j+1)\mod p=0
, then
T^{\prime}=T[0\mathinner{.\,.}i]T[j\mathinner{.\,.}n-1]
is also periodic, and
T
occurs at positions
0,p,2p,\ldots
of
T^{\prime}
. In particular,
T
has at least three occurrences in
T^{\prime}
because
p<i-j+1
and
|T^{\prime}|=n+(i-j+1)
.
∎

Figure 1:
Illustration of
Lemma

2
for
T=\texttt{aabaabaabaaba}
(
n=13
),
i=9
, and
j=4
. We colored red an occurrence
T^{\prime}[j^{\prime}\mathinner{.\,.}i^{\prime}]=T
with
j^{\prime}=3>0
and
i^{\prime}=15<|T^{\prime}|-1
. The pair of lines with arrows on the top of
T^{\prime}
show that
T^{\prime}[0\mathinner{.\,.}i+j^{\prime}]
has period
j^{\prime}=3
. The pair of lines with arrows at the bottom of
T^{\prime}
show analogously that
T^{\prime}[i+1-(|T^{\prime}|-i^{\prime}-1)\mathinner{.\,.}|T^{\prime}|)
has period
|T^{\prime}|-i^{\prime}-1=3
. We further have that
|F|=j^{\prime}+(|T^{\prime}|-i^{\prime}-1)=3+3=6
and that
T^{\prime}[j^{\prime}\mathinner{.\,.}i^{\prime}]=T
is periodic with period
\textsf{per}(T)=3
.

The following corollary follows immediately from
Lemma

2
.

Corollary 1
.

If string
T
is periodic with period
p=\textsf{per}(T)<i-j+1
and
(i-j+1)\mod p=0
, with
i\geq j
, the set of occurrences of
T
in
T^{\prime}=T[0\mathinner{.\,.}i]T[j\mathinner{.\,.}n-1]
forms a single arithmetic progression with difference
p
.

Data structure.

Let us recall that
T
is a string of length
n
over an integer alphabet
\Sigma=[0,\sigma)
with
\sigma=n^{\mathcal{O}(1)}
.
If string
T
is periodic, the smallest period
p=\textsf{per}(T)
of string
T
can be computed in
\mathcal{O}(n/\log_{\sigma}n)
time
[
21
,
8
]
. The algorithms of
[
21
,
8
]
return
p=\perp
if
T
is not periodic within the same time complexity.
The first part of the construction algorithm is to compute this
p
.
We also construct a
longest common extension
(LCE) data structure over
T
.
The LCE data structure answers the following type of queries: for any
i,j\in[0,n)
,
return the length of the longest common prefix (
LCP
) of
T[i\mathinner{.\,.}n)
and
T[j\mathinner{.\,.}n)
. By reversing
T
, we can answer the symmetric longest common suffix (
LCS
) queries.
LCP
and
LCS
queries can be answered in
\mathcal{O}(1)
time after an
\mathcal{O}(n/\log_{\sigma}n)
-time preprocessing by constructing the LCE data structure over
T
from
[
19
]
. The total construction time and the size of our data structure are in
\mathcal{O}(n/\log_{\sigma}n)
.
Notably, this is
\mathcal{O}(n/\log n)
for any constant-sized alphabet.

Answering prefix-suffix queries.

Here comes a
\textsf{PrefSuf}(i,j)
query.
We simply apply
Lemma

2
. If
T
is periodic with period
p\neq\perp
, we also check whether
p<i-j+1
and
(i-j+1)\mod p=0
.
These checks are performed in
\mathcal{O}(1)
time.
If the answer is positive, we return all occurrences in
\mathcal{O}(1)
time by applying
Corollary

1
. If the answer is negative or
T
is aperiodic, we trigger two LCE queries. Namely, if
\textsf{LCP}(T[i+1\mathinner{.\,.}n),T[j\mathinner{.\,.}n))=n-i-1
, then
T
occurs as a prefix of
T^{\prime}=T[0\mathinner{.\,.}i]T[j\mathinner{.\,.}n-1]
;
if
\textsf{LCS}(T[0\mathinner{.\,.}j-1],T[0\mathinner{.\,.}i])=j
then
T
occurs as a suffix of
T^{\prime}
.
The total query time is thus
\mathcal{O}(1)
.

Remark 1
.

It is possible to have an aperiodic string
T
that occurs as both a prefix
and
a suffix of
T^{\prime}=T[0\mathinner{.\,.}i]T[j\mathinner{.\,.}n-1]
(we handle this with the two LCE queries). For instance, let
T=\texttt{aababaab}
,
i=5
, and
j=1
.

T
is aperiodic and it occurs as both a prefix and a suffix in

T^{\prime}=\texttt{aababaababaab}
.

The algorithm is correct by
Lemma

2
.
We have arrived at
Theorem

1
.

3
Application: Bipartite pattern matching

Pattern matching on node-labeled graphs is an old topic
[
23
,
1
,
24
,
5
]
that is regaining a lot of attention
[
12
,
10
,
6
,
2
]
due to its application in computational pangenomics
[
7
,
18
,
16
]
.
A
pangenome
is any collection of genomic sequences to be analyzed jointly or to be used as a reference
[
9
]
; e.g., a collection of highly-similar genomes of the same species. A standard pangenome representation is that of a
variation graph

[
7
]
: a directed graph
G(V,E,W)
, whose nodes are labeled by nonempty strings, equipped with a set
W
of distinguished walks corresponding to variants that we want to retain in the representation (inspect
Fig.

2
, middle). The pattern matching problem on a variation graph is then defined naturally as the problem of finding occurrences of a pattern
P
of length
m
spanning one or more nodes that lie on a walk from
W
. It should be clear that any algorithm solving this general problem
must
also solve the restricted version of it asking for occurrences spanning up to two nodes.

Figure 2:
Illustration of a variation graph and of bipartite pattern matching. The pattern
P=\texttt{ACTA}
has an occurrence (underlined) spanning two nodes lying on a valid walk for the sequence marked blue.

This restricted version is also interesting theoretically as there exists a conditional lower bound for the general problem of pattern matching on node-labeled graphs: for any constant
\epsilon>0
, an
\mathcal{O}(|E|^{1-\epsilon}m)
-time or an
\mathcal{O}(|E|m^{1-\epsilon})
-time algorithm, even when
P
is a binary string, cannot be achieved unless the Strong Exponential Time Hypothesis fails
[
12
]
. We formalize the restricted version of the problem on a bipartite graph (inspect
Fig.

2
, right) and call it the
bipartite pattern matching
problem.

Let
G(U,V,E)
be a bipartite graph such that
U
is a set
of nodes, each labeled by a string;
V
is a set
of nodes, each labeled by a string; and
E
is a set of edges.
Let
N_{U}
and
N_{V}
denote the total length of the labels in
U
and
V
, respectively.
We are also given a string
P
(the pattern) of length
m
. The
bipartite pattern matching
problem asks us to find every pair of nodes
(u,v)
, such that there exists
a node
u\in U
with a label having suffix
s
,
a node
v\in V
with a label having prefix
p
,
P=s\cdot p
, and
(u,v)\in E
.
Let
N=N_{U}+N_{V}
. Again, we make the standard assumption of an integer alphabet of size polynomial in
N
. We solve this problem in
\mathcal{O}(N+|E|)
time after preprocessing
P
in
\mathcal{O}(m)
time.

In preprocessing, we construct: the
KMP automaton

[
20
]
of
P
;
the KMP automaton of
P^{R}
, the reverse of
P
;
and the data structure of
Theorem

1
on
P
in
\mathcal{O}(m)
total time.
For each node
u
in
U
, we find the longest suffix of the label of
u
that is a prefix of
P
.
This takes
\mathcal{O}(N_{U})
time using the KMP automaton of
P
.
For each node
v
in
V
, we find the longest prefix of the label of
v
that is a suffix of
P
.
This takes
\mathcal{O}(N_{V})
time using the KMP automaton of
P^{R}
.
By
Theorem

1
, we spend
\mathcal{O}(1)
time per edge
(u,v)
: we ask a single prefix-suffix query for the prefix of
P
and the suffix of
P
found above. Our solution not only finds the relevant pair of nodes: it encodes all occurrences spanning each such pair.

Theorem 2
.

The bipartite pattern matching problem can be solved in
\mathcal{O}(N+|E|)
time after preprocessing the pattern in
\mathcal{O}(m)
time.

4
Concluding remarks

The purpose of this paper is twofold. From the results perspective,
Theorem

1
may find other applications in pattern matching, and
Theorem

2
may serve as a useful tool for developing practical algorithms for pattern matching in labeled graphs or as inspiration for future theoretical developments. From an educational perspective, our paper may serve as material for a class on advanced data structures showcasing a remarkably simple and optimal data structure obtained through combinatorial insight.
