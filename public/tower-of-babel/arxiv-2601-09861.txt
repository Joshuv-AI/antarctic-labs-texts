Barrier-crossing and energy relaxation dynamics of non-Markovian inertial systems connected via analytical Green-Fokker-Planck approach
Roland R. Netz

Abstract
From numerical simulations it is known that the barrier-crossing time of a non-Markovian one-dimensional reaction coordinate with a single exponentially decaying memory function exhibits a memory-turnover: for intermediate values of the memory decay time the barrier-crossing time is reduced compared to the Markovian limit and for long memory times increases quadratically with the memory time when keeping the total integrated friction and the mass constant. The intermediate memory acceleration regime is accurately predicted by Grote-Hynes theory, for the asymptotic long-memory slow-down behavior no systematic analytically tractable theory is available. Starting from the Green function for a general inertial (i.e. finite-mass) non-Markovian Gaussian reaction coordinate in a harmonic well, we derive by an exact mapping a generalized Fokker-Planck equation with a time-dependent effective diffusion constant. To first order in a systematic cumulant expansion we derive an analytical Arrhenius expression for the barrier-crossing time with the pre-exponential factor given by the energy relaxation time, which can be used to robustly predict barrier-crossing times from simulation or experimental trajectory data of general non-Markovian inertial systems without the need to extract memory functions. For a single exponential memory kernel we give a closed-form expression for the barrier-crossing time, which reproduces the Kramers turnover between the high-friction and high-mass limits as well as the memory turnover from the intermediate memory acceleration to the asymptotic long-memory slow-down regime. We also show that non-Markovian systems are singular in the zero-mass limit, which suggests that the long-memory barrier-crossing slow-down reflects the interplay between mass and memory effects. Thus, physically sound models for non-Markovian systems have to include a finite mass.

II
Results

II.1
Non-Markovian Green function

We consider the dynamics of a general non-Markovian stochastic process in a harmonic potential well. Neglecting possible non-linear
friction effects, the process is Gaussian and the two-point positional joint distribution for the position
to be
x
at time
t
and
x_{0}
at time zero in all generality is given by

\displaystyle{\cal P}(x,t;x_{0})

\displaystyle=\exp\left(-a(t)x^{2}/2-b(t)xx_{0}-c(t)x_{0}^{2}/2\right){\cal N}^{-1},

(1)

where
{\cal N}
is the normalization constant and
a(t)
,
b(t)
,
c(t)
are unknown time-dependent functions.
These four unknowns are determined by the following four conditions:

i) For a stationary process (assumed in this work) the joint distribution is symmetric, i.e.,

\displaystyle{\cal P}(x,t;x_{0})

\displaystyle={\cal P}(x_{0},t;x),

(2)

ii) the joint distribution is normalized,

\displaystyle\int_{-\infty}^{\infty}{\rm d}x\int_{-\infty}^{\infty}{\rm d}x_{0} {\cal P}(x,t;x_{0})

\displaystyle=1,

(3)

iii) the covariance of the distribution defines the two-point correlation function

\displaystyle\int_{-\infty}^{\infty}{\rm d}x\int_{-\infty}^{\infty}{\rm d}x_{0}xx_{0} {\cal P}(x,t;x_{0})

\displaystyle\equiv\langle xx_{0}\rangle\equiv C(t),

(4)

and iv) the variance of the distribution is denoted as
C_{0}

\displaystyle\int_{-\infty}^{\infty}{\rm d}x\int_{-\infty}^{\infty}{\rm d}x_{0}x^{2} {\cal P}(x,t;x_{0})

\displaystyle=\langle x^{2}\rangle=C(0)\equiv C_{0}

(5)

(note that due to symmetry we have
\langle x^{2}\rangle=\langle x^{2}_{0}\rangle
). With these four relations,
the joint distribution can be written in terms of the correlation function
C(t)
as

\displaystyle{\cal P}(x,t;x_{0})

\displaystyle=\frac{\exp\left(-\frac{ (x-\bar{C}(t)x_{0})^{2}}{2C_{0}\left(1-\bar{C}^{2}(t)\right)}-\frac{x_{0}^{2}}{2C_{0}}\right)}{2\pi C_{0}\left(1-\bar{C}^{2}(t)\right)},

(6)

where we introduced the normalized two-point correlation function as

\displaystyle\bar{C}(t)

\displaystyle=C(t)/C_{0},

(7)

see Appendix
A
for details.
Using the single-point distribution function, which is obtained via marginalization of Eq.(
6
) as

\displaystyle{\cal P}(x)

\displaystyle\equiv\int_{-\infty}^{\infty}{\rm d}x_{0} {\cal P}(x,t;x_{0})=\frac{\exp\left(-\frac{x^{2}}{2C_{0}}\right)}{\left[2\pi/C_{0}\right]^{1/2}},

(8)

the conditional two-point distribution is obtained as

\displaystyle{\cal P}(x,t|x_{0})

\displaystyle=\frac{{\cal P}(x,t;x_{0})}{{\cal P}(x_{0})}=\frac{\exp\left(-\frac{ (x-\bar{C}(t)x_{0})^{2}}{2C_{0}\left(1-\bar{C}^{2}(t)\right)}\right)}{\left[2\pi C_{0}\left(1-\bar{C}^{2}(t)\right)\right]^{1/2}}.

(9)

In fact, the expression Eq.(
9
) has been recently derived from the generalized Langevin equation
using stochastic path-integral formalism
52
,
which underscores the exactness of the current symmetry-based derivation.
Since the conditional two-point distribution in Eq.(
9
) corresponds to the distribution generated by the
non-Markovian process with the initial probability distribution
{\cal P}(x,t=0|x_{0})=\delta(x-x_{0})
, it
constitutes the Green function of the process.

II.2
From the non-Markovian Green function to the generalized Fokker-Planck equation

By taking a partial derivative of the Green function Eq.(
9
) with respect to time, we obtain an expression
that can be brought into the form of a partial differential equation

\displaystyle\frac{ \partial{\cal P}(x,t|x_{0})}{\partial t}

\displaystyle=-\frac{C_{0}\bar{C}^{\prime}(t)}{\bar{C}(t)} \left[\frac{ \partial}{\partial x}\frac{x}{C_{0}} +\frac{ \partial^{2}}{\partial x^{2}}\right] {\cal P}(x,t|x_{0}),

(10)

where
\bar{C}^{\prime}(t)
denotes the derivate of
\bar{C}(t)
,
see Appendix
B
for intermediate steps of the derivation.
The Green function of the Gaussian process in Eq.(
9
) is valid for a harmonic potential of the form

\displaystyle U(x)

\displaystyle=Kx^{2}/2,

(11)

for which the variance follows for a canonical system at temperature
T
from the equipartition theorem as
C_{0}=k_{B}T/K
,
where
k_{B}
is the Boltzmann constant.
With this we can rewrite Eq. (
11
) in the form

\displaystyle\frac{ \partial{\cal P}(x,t|x_{0})}{\partial t}

\displaystyle=D(t)\left[\frac{ \partial}{\partial x}\beta U^{\prime}(x)+\frac{ \partial^{2}}{\partial x^{2}}\right] {\cal P}(x,t|x_{0})

\displaystyle=D(t)\frac{ \partial}{\partial x}e^{-\beta U(x)}\frac{ \partial}{\partial x}e^{\beta U(x)} {\cal P}(x,t|x_{0}),

(12)

where we used
\beta=1/(k_{B}T)
and introduced the time-dependent diffusivity

\displaystyle D(t)

\displaystyle=-\frac{C_{0}\bar{C}^{\prime}(t)}{\bar{C}(t)}=-\frac{C_{0}C^{\prime}(t)}{C(t)}.

(13)

By writing the probability distribution as a convolution of the Green function
{\cal P}(x,t|x_{0})
with the
initial distribution
{\cal P}_{0}(x_{0})
as

\displaystyle{\cal P}(x,t)

\displaystyle=\int_{-\infty}^{\infty}{\rm d}x_{0}{\cal P}_{0}(x_{0}){\cal P}(x,t|x_{0}),

(14)

we obtain from Eq. (
II.2
) an equation for the distribution function

\displaystyle\frac{ \partial{\cal P}(x,t)}{\partial t}

\displaystyle=D(t)\frac{ \partial}{\partial x}e^{-\beta U(x)}\frac{ \partial}{\partial x}e^{\beta U(x)} {\cal P}(x,t)

(15)

with the initial condition
{\cal P}(x,0)={\cal P}_{0}(x)
.
This equation is identical to the standard Fokker-Planck equation for an overdamped Markovian reaction coordinate

72

except that the diffusivity
D(t)
is time-dependent. This time-dependency takes care of inertial and non-Markovian effects and
therefore contains the crucial physics we are interested in.

II.3
Barrier-crossing times from the generalized Fokker-Planck equation

In the following we extend the method to calculate mean-first-passage times
from the standard Fokker-Planck equation with a time-independent diffusivity
72
to the case
of a time-dependent diffusivity.
The solution of the generalized Fokker-Planck equation for the Green function Eq. (
II.2
)
can be written formally as an operator exponential as

\displaystyle{\cal P}(x,t|x_{0})

\displaystyle=e^{T(t){\cal D}(x)}{\cal P}(x,0|x_{0}),

(16)

where we defined the diffusive Fokker-Planck propagator as

\displaystyle{\cal D}(x)

\displaystyle\equiv\frac{ \partial}{\partial x}e^{-\beta U(x)}\frac{ \partial}{\partial x}e^{\beta U(x)}

(17)

and the running integral over the diffusivity as

\displaystyle T(t)

\displaystyle\equiv\int_{0}^{t}{\rm d}sD(s).

(18)

Note that Eq. (
16
), which employs
operator-exponential formalism
72
,
is the same Green function as given in
Eq. (
9
), but is more useful for imposing spatial boundary conditions as needed for
calculating the mean-first passage time.
Using that
{\cal P}(x,0|x_{0})=\delta(x-x_{0})
, we can write the Green function in
Eq. (
16
) in
symmetric form as

\displaystyle{\cal P}(x,t|x_{0})

\displaystyle=\int_{-\infty}^{\infty}{\rm d}\tilde{x}\delta(\tilde{x}-x)e^{T(t){\cal D}(\tilde{x})}\delta(\tilde{x}-x_{0})

\displaystyle=\int_{-\infty}^{\infty}{\rm d}\tilde{x}\delta(\tilde{x}-x_{0})e^{T(t){\cal D}^{\dagger}(\tilde{x})}\delta(\tilde{x}-x)

\displaystyle=e^{T(t){\cal D}^{\dagger}(x_{0})}{\cal P}(x,0|x_{0}),

(19)

where we defined the adjunct Fokker-Planck operator as

\displaystyle{\cal D}^{\dagger}(x)

\displaystyle\equiv e^{\beta U(x)}\frac{ \partial}{\partial x}e^{-\beta U(x)}\frac{ \partial}{\partial x}.

(20)

From Eqs. (
16
) and (
II.3
) it transpires that the Green function satisfies the
normal Fokker-Planck Eq. (
II.2
) as well as the
adjunct (backward) Fokker-Planck equation, i.e.

\displaystyle\frac{ \partial{\cal P}(x,t|x_{0})}{\partial t}

\displaystyle=D(t){\cal D}(x) {\cal P}(x,t|x_{0})

\displaystyle=D(t){\cal D}^{\dagger}(x_{0}) {\cal P}(x,t|x_{0}).

(21)

We define the survival probability in the domain between a reflecting boundary condition at
x_{\rm ref}

and an absorbing boundary condition at the position
x_{f}>x_{\rm ref}
as

\displaystyle S(x_{0},t)

\displaystyle=\int_{x_{\rm ref}}^{x_{f}}{\rm d}x{\cal P}(x,t|x_{0}),

(22)

which has the limits
S(x_{0},0)=1
and
S(x_{0},\infty)=0
for
x_{\rm ref}<x_{0}<x_{f}
.
The first-passage (or escape) distribution follows from the time derivative of the survival probability as

\displaystyle k(x_{0},t)

\displaystyle\equiv-\frac{\partial}{\partial t} S(x_{0},t)=-\int_{x_{\rm ref}}^{x_{f}}{\rm d}x\frac{\partial}{\partial t} {\cal P}(x,t|x_{0})

\displaystyle=-\int_{x_{\rm ref}}^{x_{f}}{\rm d}xD(t){\cal D}(x){\cal P}(x,t|x_{0})

\displaystyle=-D(t)e^{-\beta U(x_{f})}\frac{ \partial}{\partial x_{f}}e^{\beta U(x_{f})}{\cal P}(x_{f},t|x_{0}),

(23)

where we employed Eq. (
II.3
) and used
in the last step that the probability flux at
x_{\rm ref}
vanishes.
Applying the operator expression for
k(x_{0},t)
in Eq. (
II.3
)
onto the adjunct Fokker-Planck Eq. (
II.3
), we obtain

\displaystyle\frac{ \partial k(x_{0},t)}{\partial t}=D(t){\cal D}^{\dagger}(x_{0}) k(x_{0},t).

(24)

From this partial differential equation for the first-passage distribution
we can recursively determine moments of the product of the
first-passage distribution and the diffusivity defined as

\displaystyle k_{n}(x_{0})\equiv\int_{0}^{\infty}{\rm d}tt^{n}D(t)k(x_{0},t)/D_{0},

(25)

where
D_{0}
is the diffusivity in a suitably defined limit, as will be discussed further below.
For the first moment we obtain from Eq. (
24
)

\displaystyle{\cal D}^{\dagger}(x_{0})k_{1}(x_{0})

\displaystyle=\int_{0}^{\infty}{\rm d}tt\frac{\partial}{\partial t} k(x_{0},t)/D_{0}

\displaystyle=-\int_{0}^{\infty}{\rm d}tk(x_{0},t)/D_{0}=-1/D_{0},

(26)

where we used that
k(x_{0},\infty)=0
and that the time integral over
k(x_{0},t)
is normalized to unity.
This equation can be inverted and yields

\displaystyle k_{1}(x_{0})=D_{0}^{-1}\int_{x_{0}}^{x_{f}}{\rm d}xe^{\beta U(x)}\int_{x_{\rm ref}}^{x}{\rm d}x^{\prime}e^{-\beta U(x^{\prime})}.

(27)

Note that from the definition Eq. (
25
) it transpires that

k_{1}(x_{0})
only corresponds to the mean-first passage time
\tau_{\rm mfp}
,
which is the average time to
reach the final position
x_{f}
for the first time when starting from
x_{0}
,
if the diffusivity
D(t)
is time-independent and given by
D_{0}
.
If, on the other hand, the diffusivity
D(t)
is time dependent,

k_{1}(x_{0})
does not equal
\tau_{\rm mfp}
, in which case
there are different ways of how to proceed. Using that the
first-passage distribution for high barriers decays single-exponentially as

k(x_{0},t)\simeq e^{-t/\tau_{\rm mfp}}/\tau_{\rm mfp}
,

\tau_{\rm mfp}
is determined by the equation following from combining
Eq. (
25
) for
n=1
and
given
D(t)
with Eq. (
27
).
A numerical solution of the resulting equation
is possible if the two-point correlation function
C(t)
is known reliably and the diffusivity profile
D(t)

can via Eq. (
13
) be accurately calculated. In typical simulation or experimental scenarios, however, the
correlation function becomes noisy in the long-time limit and thus
D(t\rightarrow\infty)
cannot be reliably estimated.
An additional problem ist that
D(t)
for inertial and non-Markovian systems typically oscillates in the long-time limit and thus
the limit
D(t\rightarrow\infty)
is not uniquely determined, as will be seen later.
In the following section we will introduce a robust expansion method for
D(t)
, which allows us to replace

D(t)
by a constant
D_{0}
to leading order in a systematic cumulant expansion.

II.4
Cumulant expansion of the time-dependent diffusivity
D(t)

The key observation is that for a single-exponential correlation function
C(t)
, the
diffusivity
D(t)
defined in Eq. (
13
) becomes time-independent, i.e.
D(t)=D_{0}
, and thus the
mean-first passage time equals the first moment in Eq. (
27
), i.e.
\tau_{\rm mfp}=k_{1}(x_{0})
.
This is a non-trivial observation, as the correlation function of non-Markovian and inertial systems do for specific parameter combinations
indeed decay single-exponentially, as will be explicitly demonstrated below.
The idea pursued in this section is to characterize deviations of
C(t)
from a single-exponential function
by a systematic cumulant expansion.

To proceed, we rewrite Eq. (
13
) as

\displaystyle D(t)

\displaystyle=-\frac{C_{0}\bar{C}^{\prime}(t)}{\bar{C}(t)}=-\frac{C_{0}}{p}\frac{{\rm d}{\bar{C}}^{p}(t)/{\rm d}t}{{\bar{C}}^{p}(t)},

(28)

where
p
is an arbitrary positive integer number that will be discussed and chosen later.
We furthermore define the single-sided function

\displaystyle\phi(t)

\displaystyle\equiv-\theta(t)\frac{{\rm d}{\bar{C}}^{p}(t)}{{\rm d}t},

(29)

where
\theta(t)
defines the Heaviside function.
The Fourier transform of
\phi(t)
can be written as a power series in frequency according to

\displaystyle\tilde{\phi}(\omega)

\displaystyle=\int_{-\infty}^{\infty}{\rm d}te^{-\imath\omega t} \phi(t)

\displaystyle=1-\imath\omega\sum_{n=0}^{\infty}\frac{(-\imath\omega)^{n}}{n!}M_{n},

(30)

where we defined moments of the
p
-th power of the correlation function as

\displaystyle M_{n}=\int_{0}^{\infty}{\rm d}tt^{n}{\bar{C}}^{p}(t).

(31)

As the only requirement, we assume all higher moments
M_{n}
to exist, which is satisfied for exponentially
decaying correlation functions, which is the normal scenario.
Note that by virtue of the presence of the derivative in the definition of
\phi(t)
in Eq. (
29
) and the
single-sidedness of
\phi(t)
, the power series in Eq. (
II.4
) starts with unity, which is crucial.
In order to make the back-Fourier transform integrable, we define the inverse power series

\displaystyle\tilde{\phi}(\omega)

\displaystyle=\left[ 1+\imath\omega\sum_{n=0}^{\infty}\omega^{n}B_{n}\right]^{-1}

(32)

with coefficients
B_{n}
that follow uniquely from the set of moments
M_{m}
with
m\leq n
by standard
power-series inversion. To illustrate this, we write out the first two terms explicitly

\displaystyle\tilde{\phi}(\omega)

\displaystyle=1-\imath\omega M_{0}-\omega^{2}M_{1}+\cdots

\displaystyle=\left[ 1+\imath\omega M_{0}+\omega^{2}\left(M_{1}-M_{0}^{2}\right)+\cdots\right]^{-1}.

(33)

It transpires that
\tilde{\phi}(\omega)
, when written as an
inverse power series in
\omega
,
contains multiple poles that will lead upon back-Fourier-transforming to
a sum of exponentially decaying functions. To linear order in
\omega
we find

\tilde{\phi}(\omega)\simeq 1/(1+\imath\omega M_{0})
, which leads to the single exponential

\displaystyle\phi(t)

\displaystyle\simeq\theta(t)e^{-t/M_{0}}/M_{0}.

(34)

Since for a single exponential correlation function
\bar{C}(t)=e^{-t/\tau}
one has
M_{1}=M_{0}^{2}
,
one finds that in this case the second-order correction in
\omega
in Eq. (
II.4
) vanishes (and so do all higher-order corrections).
In essence, the cumulant expansion allows to write down a functional expansion in terms of deviations of the
correlation function
\bar{C}(t)
from a single-exponential form.
Note that the first-order result in Eq. (
34
) does not reproduce the long-time asymptotic decay of

\phi(t)
in case there are competing exponentially decaying contributions, this is particularly true
for correlation functions that asymptotically oscillate, as is the case for highly inertial or highly non-Markovian systems,
which will be illustrated below.

We so far have considered the numerator of Eq. (
28
). The denominator of Eq. (
28
) can for
t>0

be expressed in terms of
the function
\phi(t)
as

\displaystyle{\bar{C}}^{p}(t)

\displaystyle=-\int_{t}^{\infty}{\rm d}s\frac{{\rm d} {\bar{C}}^{p}(s)}{{\rm d}s}=\int_{t}^{\infty}{\rm d}s\phi(s)\simeq e^{-t/M_{0}},

(35)

where in the last step we used the first-order result from Eq. (
34
).
By combining the results in Eqs. (
34
) and (
35
) we obtain from Eq. (
28
) for the diffusivity
to leading order in the cumulant expansion

\displaystyle D(t)

\displaystyle\simeq D_{0}\equiv\frac{C_{0}}{\tau_{\rm rel}}=\frac{C_{0}}{pM_{0}},

(36)

where we defined the relaxation time as
\tau_{\rm rel}\equiv C_{0}/D_{0}
,
for which we obtain to leading order in the cumulant expansion
\tau_{\rm rel}=pM_{0}
.
For
p=2
, which is a natural choice as we will show below, the relaxation time follows
from Eq. (
31
) as
the integral over the squared correlation function

\displaystyle\tau_{\rm rel}

\displaystyle=2\int_{0}^{\infty}{\rm d}t{\bar{C}}^{2}(t)=\frac{2}{C_{0}^{2}}\int_{0}^{\infty}{\rm d}t{C}^{2}(t)

\displaystyle=\frac{K^{2}}{(k_{B}T)^{2}}\int_{0}^{\infty}{\rm d}t\left(\langle x^{2}(t)x^{2}(0)\rangle-\langle x^{2}\rangle^{2}\right),

(37)

where in the last line we used Wick’s theorem to show the correspondence
to the potential-energy correlation function (in the following simply called the energy correlation function).
Note that higher-order corrections can be calculated by carrying the cumulant expansion in
Eq. (
II.4
) to higher order in
\omega
, in which case the diffusivity
D(t)
becomes
time-dependent and the mean-first-passage time
\tau_{\rm mfp}

does not equal the first moment in Eq. (
27
), which is not pursued in this paper.

To show that

is a rather natural choice, we consider the average over the time-dependent

) with a weight function

, which we take to be given
by the

\displaystyle\bar{D}

\displaystyle=\frac{\int_{0}^{\infty}{\rm d}tD(t)w(t)}{\int_{0}^{\infty}{\rm d}tw(t)}=-C_{0}\frac{\int_{0}^{\infty}{\rm d}t{\bar{C}}^{\prime}(t){\bar{C}}^{p-1}(t)}{\int_{0}^{\infty}{\rm d}t{\bar{C}}^{p}(t)}=\frac{C_{0}}{pM_{0}}.

(38)

We see that we reproduce exactly the result for
D_{0}

in Eq. (

expansion corresponds to the average over
D(t
) with a weight function proportional
to
{\bar{C}}^{p}(t)
. This makes sense, since an effective time-independent diffusivity should reflect
the time-dependent diffusivity in the time range that is relevant for the escape process.
Since the idea of a weighting function implies a positive definite function and the correlation function
{\bar{C}}(t)

can be negative even in the asymptotic long-time limit,
an even exponent
p
makes sense. Furthermore, for
p=2
the relaxation time
defined in Eq. (
34
) corresponds to the energy relaxation time, which makes also intuitive
sense, as barrier-crossing involves energy relaxation. Thus, we will use
p=2
in all further calculations
and confirm the validity of this choice by comparison with previously published mean-first passage times
determined from simulations of barrier crossing dynamics in double-well potentials.

II.6
Explicit results for relaxation times

We consider the Mori GLE for the reaction coordinate (also called the position for simplicity)
x(t)

\displaystyle m\ddot{x}(t)

\displaystyle=-Kx(t)-\int_{-\infty}^{\infty} {\rm d}s\Gamma(s)\dot{x}(t-s)+F(t),

(42)

where
m
is the effective mass, defined
as
m=k_{B}T/\langle\dot{x}^{2}\rangle
,
K
is the stiffness of the harmonic potential,
the memory kernel
\Gamma(t)
is here (for simplifying the Fourier analysis)
defined to be a single-sided function, i.e.
\Gamma(t)=0
for
t<0
,
and we have moved the projection time to minus infinity, such that the integration of the non-Markovian
friction extends over the entire time domain (see Section
II.8
for a discussion of how
Eq. (
42
) follows from projection theory).
The autocorrelation function of the orthogonal force is for a time-independent Hamiltonian given by

\displaystyle\langle F(t)F(t^{\prime})\rangle

\displaystyle=k_{B}T\Gamma(|t-t^{\prime}|),

(43)

where averages in this Section are taken over the orthogonal-force distribution.
Note that the Mori GLE in Eq. (
42
) is an exact equation of motion for a general non-linear reaction coordinate, unless
one approximates the orthogonal force
F(t)
as Gaussian, as we do in this paper and as is appropriate for a Gaussian system.
Fourier-transformation of Eq. (
42
) leads to

\displaystyle-m\omega^{2}\tilde{x}(\omega)

\displaystyle=-K\tilde{x}(\omega)-\imath\omega\tilde{\Gamma}(\omega)\tilde{x}(\omega)+\tilde{F}(\omega),

(44)

from which the response of the position to the orthogonal force follows as

\displaystyle\tilde{x}(\omega)=\tilde{\chi}(\omega)\tilde{F}(\omega)

(45)

with the response function given by

\displaystyle\tilde{\chi}(\omega)=\left[ K-m\omega^{2}+\imath\omega\tilde{\Gamma}(\omega)\right]^{-1}.

(46)

From Eqs. (
43
) and (
45
) the Fourier transform of the correlation function
C(t)=\langle x(s)x(s+t)\rangle

follows as

\displaystyle\frac{\tilde{C}(\omega)}{k_{B}T}

\displaystyle=\left[\tilde{\Gamma}(\omega)+\tilde{\Gamma}(-\omega) \right]\tilde{\chi}(\omega)\tilde{\chi}(-\omega)

\displaystyle=\frac{\tilde{\Gamma}(\omega)+\tilde{\Gamma}(-\omega)}{ \left|K-m\omega^{2}+\imath\omega\tilde{\Gamma}(\omega)\right|^{2}}

\displaystyle=\frac{\tilde{\chi}(-\omega)}{\imath\omega} -\frac{\tilde{\chi}(\omega)}{\imath\omega},

(47)

where the last equation follows directly from the definition of the response function in Eqs. (
46
)
and where we used that
\chi(t)
and
\Gamma(t)
are real functions in the time domain.
We define the derivative of the correlation function as

\displaystyle C_{xv}(t)

\displaystyle\equiv\frac{{\rm d}C(t)}{{\rm d}t} =\frac{{\rm d} }{{\rm d}t}\int\frac{{\rm d}\omega}{2\pi} e^{\imath\omega t}\tilde{C}(\omega)

\displaystyle=\int\frac{{\rm d}\omega}{2\pi} e^{\imath\omega t}\imath\omega\tilde{C}(\omega),

(48)

from which transpires that
\tilde{C}_{xv}(\omega)=\imath\omega\tilde{C}(\omega)
and thus from Eqs. (
II.6
)

\displaystyle\frac{\tilde{C}_{xv}(\omega)}{k_{B}T} =\tilde{\chi}(-\omega) -\tilde{\chi}(\omega).

(49)

The time-domain response function
\chi(t)
is a single-sided function,
therefore the Fourier transform of the single-sided correlation function

C_{xv}^{+}(t)\equiv\theta(t)C_{xv}(t)
is, if the response function
\chi(t)

is regular in the limit
t\rightarrow 0
(we will come back to this important
condition when we discuss the massless non-Markovian scenario in Sec.
II.7
) given by

\displaystyle\frac{\tilde{C}^{+}_{xv}(\omega)}{k_{B}T} = -\tilde{\chi}(\omega).

(50)

This is a useful result for analytical calculations,
as the response function
\tilde{\chi}(\omega)
has the minimal
pole structure. From the time-domain function

C_{xv}^{+}(t)
the single-sided correlation function
C^{+}(t)\equiv\theta(t)C(t)

is obtained by straightforward integration as

\displaystyle C^{+}(t)

\displaystyle=-\theta(t)\int_{t}^{\infty}{\rm d}sC^{+}_{xv}(s)=k_{B}T\theta(t)\int_{t}^{\infty}{\rm d}s\chi(s),

(51)

which can then be used to calculate the relaxation time
\tau_{\rm rel}
according to Eq. (
II.4
).
Note that the time-domain result in Eq. (
51
) is equivalent to the Fourier-domain result

\displaystyle\tilde{C}^{+}(\omega)

\displaystyle=\frac{k_{B}T}{\imath\omega} \left(\tilde{\chi}(0)-\tilde{\chi}(\omega)\right).

(52)

In the following we will consider a single-exponential memory kernel

\displaystyle\Gamma(t)

\displaystyle=\theta(t)\gamma e^{-t\tau}/\tau

(53)

with a memory time
\tau
,
whose Fourier transform is given by

\displaystyle\tilde{\Gamma}(\omega)

\displaystyle=\frac{\gamma}{1+\imath\tau\omega}.

(54)

II.8
The zero-memory-time limit of the GLE is time-reversible

After having shown that the zero-mass limit of the GLE is singular,
we now discuss the zero-memory-time limit
\tau\rightarrow 0

of the GLE and show that in this limit also a singularity arises, which
in fact is crucial in order to preserve time reversibility of the resulting Langevin equation.
This resolves the puzzling finding that
in its usual formulation, the Langevin equation breaks time-reversal symmetry,
while the GLE, which is derived by exact projection from
Hamilton’s equation of motion, obeys time-reversal symmetry (as Hamilton dynamics does).

To clarify this issue, we consider the Mori GLE in the form obtained by projection formalism

50
;
72
, which reads
51

\displaystyle\ddot{B}(w,t)=-K_{M}(B(w,t)-\langle B\rangle)-\int_{0}^{t-t_{P}}{\rm d}s\,\Gamma_{M}(s)\dot{B}(w,t-s)+F_{M}(w,t).

(75)

Note that in contrast to the GLE Eq. (
42
) we have been using to derive all explicit results so far,
the Heisenberg observable
B(w,t)
and the orthogonal force
F_{M}(w,t)
in Eq. (
75
) have an explicit dependence
on the
6N
-dimensional phase-space variable
w=(\{{\bf r}_{N}\},\{{\bf p}_{N}\})
, where
N
denotes the number of particles
and
\{{\bf r}_{N}\}
are the particle positions and
\{{\bf p}_{N}\}
the particle momenta in three-dimensional space.
Time reversibility means
that the trajectory of a many-body system is invariant when time and momenta are inverted. The Hamilton equations
of motion are time-reversible for a Hamiltonian that is even in the momenta
\{{\bf p}_{N}\}
.
Note that eq. (
75
) results from an exact derivation and therefore must also be time-reversible.
The time at which the projection is taking place,
t_{P}
, appears explicitly in Eq. (
75
)
51
.
Eq. (
42
) is obtained from Eq. (
75
) by i) pushing the propagation time in Eq. (
75
)
infinitely far into the past,
t_{P}\rightarrow-\infty
,
which produces the time ordering
t>t_{P}
and makes the upper integral boundary in Eq. (
75
) equal to

+\infty
, ii) defining mass-rescaled parameters
\Gamma(t)=m\theta(t)\Gamma_{M}(t)
,
K=mK_{m}
and

F(t)=mF_{M}(w,t)
, where we defined the memory kernel
\Gamma(t)
to be single-sided so that the
integration range of the friction term can be extended to the negative time domain,
iii) introducing a shifted observable
x(t)=B(w,t)-\langle B\rangle
and skipping the phase-space
dependence of x(t) and F(t).

Setting
t_{P}=0
in the remainder, time reversibility around
t=0
manifests for the Heisenberg observable as

\displaystyle\ddot{B}(\{{\bf r}_{N}\},\{{\bf p}_{N}\},t)

\displaystyle=\ddot{B}(\{{\bf r}_{N}\},-\{{\bf p}_{N}\},-t)

\displaystyle\dot{B}(\{{\bf r}_{N}\},\{{\bf p}_{N}\},t)

\displaystyle=-\dot{B}(\{{\bf r}_{N}\},-\{{\bf p}_{N}\},-t)

\displaystyle B(\{{\bf r}_{N}\},\{{\bf p}_{N}\},t)

\displaystyle=B(\{{\bf r}_{N}\},-\{{\bf p}_{N}\},-t).

(76)

Using the time-reversal symmetry of
\Gamma_{M}(t)
, i.e.

\Gamma_{M}(t)=\Gamma_{M}(-t)
,
we obtain

\displaystyle\int_{0}^{t}{\rm d}s\,\Gamma_{M}(s)\dot{B}(\{{\bf r}_{N}\},\{{\bf p}_{N}\},t-s)

\displaystyle=\int_{0}^{-t}{\rm d}s\,\Gamma_{M}(s)\dot{B}(\{{\bf r}_{N}\},-\{{\bf p}_{N}\},-t-s),

(77)

thus the memory-friction term satisfies time-reversal symmetry as well.
Since the left side and the first two terms of the right side of Eq. (
75
)
are time-reversible, realizing that
K_{M}
is independent of time and momenta,
the orthogonal force must also be time-reversible since the entire equation
is, we therefore conclude

\displaystyle F(\{{\bf r}_{N}\},\{{\bf p}_{N}\},t)=F(\{{\bf r}_{N}\},-\{{\bf p}_{N}\},-t).

(78)

Thus not only the GLE as an equation is time-reversible, in fact each individual term of the GLE is time-reversible as well,
which is a much stronger statement.
For details and derivations see Appendix
G
,

In the Markovian limit the memory kernel becomes infinitely short-ranged and can be written as

\displaystyle\Gamma_{M}(t)=2\gamma_{M}\delta(t).

(79)

Using that

\displaystyle\int_{0}^{t}{\rm d}s\,\Gamma_{M}(s)\dot{B}(w,t-s)

\displaystyle=2\gamma_{M}\int_{0}^{t}{\rm d}s\,\delta(s)\dot{B}(w,t-s)

\displaystyle=2\gamma_{M}\dot{B}(w,t)\int_{0}^{t}{\rm d}s\,\delta(s)=\gamma_{M}\dot{B}(w,t){\rm sig}(t),

(80)

we obtain in the Markovian limit the Langevin equation as

\displaystyle\ddot{B}(w,t)=

\displaystyle-K_{M}(B(w,t)-\langle B\rangle)-\gamma_{M}{\rm sig}(t)\dot{B}(w,t)

\displaystyle+F_{M}(w,t),

(81)

where
{\rm sig}(t)
is the signum function with
{\rm sig}(t)=1
for
t>0
and
{\rm sig}(t)=-1
for
t<0
.
Obviously, the Langevin equation in Eq. (
II.8
), obeys time-reversal symmetry around
t=0

but exhibits a discontinuity
of the friction term at the time origin,
t=0
, which
reflects the fact that the friction term in the underlying GLE in Eq. (
75
) vanishes for
t-t_{P}=0
.
We note that this discontinuity of the friction term in the Langevin Eq. (
II.8
) is unproblematic
when considering time-averaged quantities. We therefore not only show in Sec.
II.7

that the zero-mass limit is ill-defined for non-Markovian friction kernels (at least for the single-exponential
kernel we consider in this paper),
we also show here that in the zero-memory-time limit the resulting Langevin equation is time-reversible
and contains a discontinuity
which, when neglected, breaks time-reversal symmetry.

Conclusions and Discussion

Using an exact mapping of the Green function of a Gaussian general non-Markovian reaction coordinate

onto a generalized Fokker Planck equation with a time-dependent diffusivity,
we derive an expression of the mean-first passage to reach

effects are fully included and enter

Appendix F
Grote-Hynes Theory

The Grote-Hynes (GH) theory predicts the mean-first passage time to reach over the barrier,
as illustrated in Fig.
1
c),
in the presence of memory friction as
28

\tau^{GH}_{{\rm mfp}}=\tau^{TST}\frac{\omega_{\text{max}}}{\lambda}=\frac{2\pi\omega_{\text{max}}}{\lambda\omega_{\text{min}}}e^{\beta U_{0}},

(131)

where
\omega_{\text{max}}=\sqrt{K_{\rm bar}/m}
and

\omega_{\text{min}}=\sqrt{K/m}
are the frequencies at the potential barrier and minimum
(with both curvatures defined as being positive)
and
\tau^{TST}
denotes the transition state theory prediction.

\lambda
is the barrier reactive frequency, which is determined by the GH equation

\lambda^{2}+\lambda\frac{\hat{\Gamma}(\lambda)}{m}=\omega^{2}_{\text{max}},

(132)

where
\hat{\Gamma}(\lambda)
is the Laplace transform of the friction memory kernel.
For a single exponential memory kernel given by Eq. (
53
) we obtain

\hat{\Gamma}(\lambda)=\int_{0}^{\infty}\Gamma(t)e^{-\lambda t}dt=\frac{\gamma}{1+\tau\lambda}.

(133)

Inserting (
133
) into the GH equation (
132
), we obtain a cubic polynomial.
In the Markov limit
\tau\rightarrow 0
we have
\hat{\Gamma}(\lambda)=\gamma
and
the solution of Eq. (
132
) reads

\lambda=-\frac{\gamma}{2m}\pm\left(\frac{\gamma^{2}}{4m^{2}}+\omega^{2}_{\text{max}}\right)^{1/2}.

(134)

Taking the positive root, we obtain

\tau^{GH}_{{\rm mfp}}=\omega_{\text{max}}\left[\left(\frac{\gamma^{2}}{4m^{2}}+\omega^{2}_{\text{max}}\right)^{1/2}-\frac{\gamma}{2m}\right]^{-1}\tau^{TST},

(135)

which is equivalent to the Kramers intermediate-to-high friction result.
In the Markovian high-friction limit
\frac{\gamma}{m}\gg 1
we obtain from Eq. (
135
)

\tau^{GH}_{{\rm mfp}}=\frac{2\pi\gamma}{K|K_{\rm bar}|}e^{\beta U_{0}},

(136)

which is identical to our result in Eq. (
41
) provided we choose for the relaxation time the result
obtained in the Markovian mass-less limit
\tau_{rel}=\gamma/K
.
In the Markovian low-friction limit
\frac{\gamma}{m}\ll 1
we obtain from Eq. (
135
)

\tau^{GH}_{{\rm mfp}}=\tau^{TST},

(137)

which means that in this limit GH theory becomes identical to transition state theory.
As explained in Sec.
II.6.1
the transition state theory prediction corresponds to the prediction
of the Kramers theory at the crossover between the high-friction and low-friction,
the Kramers turnover,
where the barrier crossing time has a minimum. Thus, the transtion-state-theory prediction
is a lower bound for the barrier-crossing time, friction and energy-diffusion effects increase the
actual barrier-crossing time.

In the zero-mass
m\rightarrow 0
limit
the solution of the GH Eq. (
132
) reads

\lambda=\frac{|K_{\rm bar}|/\gamma}{1-\tau|K_{\rm bar}|/\gamma},

(138)

so that we obtain

\tau^{GH}_{\text{mfp}}=\frac{2\pi\gamma(1-\tau K_{\rm bar}/\gamma)}{K}\left(\frac{K}{K_{\rm bar}}\right)^{1/2}e^{\beta U_{0}},

(139)

which agrees for small memory time
\tau
exactly with our result in Eq. (
71
),
except that the barrier curvature
K_{\rm bar}
(which enters the GH theory) has to be replaced
by
K
, the curvature at the potential bottom.
So the GH theory correctly recovers the speed-up regime for small
\tau

but misses the long-memory slow-down effect.

Appendix G
Derivation of time-reversal symmetry of the Mori GLE

In deriving a GLE, it is convenient (though not necessary)
to consider a general time-independent Hamiltonian for a system of
N
interacting particles or atoms in three-dimensional space of the form

\displaystyle H(\omega)

\displaystyle=\sum_{n=1}^{N}\frac{\mathbf{p}_{n}^{2}}{2m_{n}}+V(\{\mathbf{r}_{N}\}),

(140)

where a point in the 6
N
-dimensional phase space is denoted by

\omega=(\{\mathbf{r}_{N}\},\{\mathbf{p}_{N}\})
, which is a
6N
-dimensional vector consisting
of the Cartesian particle positions
\{\mathbf{r}_{N}\}

and the conjugate momenta
\{\mathbf{p}_{N}\}
and fully specifies the microstate of the system.
The Hamiltonian splits into a kinetic and a potential part and
m_{n}
is the mass of particle
n
.
The potential
V(\{\mathbf{r}_{N}\})
contains all interactions between the particles and
includes possible external potentials.
Using the Liouville operator

\displaystyle{\cal L}(\omega)

\displaystyle=\sum_{n=1}^{N}\sum_{\alpha=x,y,z}\left(\frac{\partial H(\omega)}{\partial p_{n}^{\alpha}}\frac{\partial}{\partial r_{n}^{\alpha}}-\frac{\partial H(\omega)}{\partial r_{n}^{\alpha}}\frac{\partial}{\partial p_{n}^{\alpha}}\right),

(141)

the Heisenberg observable
B(w,t)
is defined by propagation according to
51

\displaystyle B(w,t)\equiv e^{(t-t_{0}){\cal L}(w)}B_{S}(w),

(142)

where
B_{S}(w)
is the ordinary time-independent observable,
here denoted as Schrödinger observable in order to distinguish it from the Heisenberg observable.
At time
t=t_{0}
the Heisenberg observable coincides with the Schrödinger observable.
In the following we assume that the observable
B_{S}(w)
only depends on particle positions, i.e.

B_{S}(w)=B_{S}({\bf\{r\}}_{N})
.
The time derivatives appearing in Eq. (
75
) follow from the propagator expression of
B(w,t)

in Eq. (
142
) as

\dot{B}(w,t)={\cal L}(w)B(w,t)
and
\ddot{B}(w,t)={\cal L}^{2}(w)B(w,t)
.
From the symmetry
H(\{\mathbf{r}_{N}\},\{\mathbf{p}_{N}\})=H(\{\mathbf{r}_{N}\},-\{\mathbf{p}_{N}\})

of the Hamiltonian Eq. (
140
), the symmetry

{\cal L} (\{\mathbf{r}_{N}\},\{\mathbf{p}_{N}\})=-{\cal L} (\{\mathbf{r}_{N}\},-\{\mathbf{p}_{N}\})
of the
Liouville operator Eq. (
141
)
and the propagator expression Eq. (
142
), the time reversibility relations in Eq. (
II.8
)
immediately follow.

The derivation of the GLE in Eq. (
75
) follows standard procedures
72
:
One introduces a projection operator
{\cal P}
that acts on phase space functions
and its complementary projection operator
{\cal Q}
via the relation
1={\cal Q}+{\cal P}
.
Inserting this unit operator into the time propagator relation Eq. (
142
),
one obtains after a few steps the GLE in Eq. (
75
),
where
t_{P}
defines the time at which the projection is performed, which in principle can
differ from the time
t_{0}
at which the time propagation of the Heisenberg
variable in Eq. (
142
) starts
51
.

The parameter
K_{M}
in Eq. (
75
)
corresponds to the potential stiffness divided by the effective mass and
is given by

\displaystyle K_{M}

\displaystyle=\frac{\langle({\cal L}B(\omega,t_{P}))^{2}\rangle}{\langle(B(\omega,t_{P})-\langle B\rangle)^{2}\rangle}.

(143)

Here we define the expectation value of an arbitrary phase-space function
X(\omega)

with respect to a time-independent projection distribution

\rho_{\rm P}(\omega)
as

\displaystyle\langle X(\omega)\rangle=\int{\rm d}\omega X(\omega)\rho_{\rm P}(\omega),

(144)

which we here take to be the normalized equilibrium canonical distribution

\rho_{\rm P}(\omega)=e^{-H(\omega)/(k_{B}T)}/Z
, where
Z
is the canonical partition function

Z=\int{\rm d}\omega e^{-H(\omega)/(k_{B}T)}
.
Obviously, the parameter
K_{M}
is independent of time and particle momenta and therefore
not influenced by momentum or time reversal.

The complementary force in Eq. (
75
) is given by

\displaystyle F_{M}(\omega,t)

\displaystyle\equiv e^{(t-t_{P}){\cal Q}{\cal L}}{\cal Q}{\cal L}^{2}B(\omega,t_{P})

(145)

and the memory friction kernel is given by
51

\displaystyle\Gamma_{M}(t)=\frac{\langle F_{M}(\omega,0)F_{M}(\omega,t)\rangle}{\langle({\cal L}B(\omega,t_{P}))^{2}\rangle}.

(146)

From the fact that the Liouville operator is anti-self-adjoint and that the complementary projection operator
{\cal Q}

is self-adjoint and idempotent, i.e.
{\cal Q}^{2}={\cal Q}
, it follows that
the memory friction kernel is a symmetric function, i.e.
\Gamma_{M}(t)=\Gamma_{M}(-t)
,
which is used to derive the time reversibility of the friction-memory term in Eq. (
II.8
).
