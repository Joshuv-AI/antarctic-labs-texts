Kernelization for list H H -coloring for graphs with small vertex cover
Marta Piecyk, Astrid Pieterse, Paweł Rzążewski, Magnus Wahlström

Abstract
For two graphs G G and H H , a homomorphism from G G to H H is a mapping φ : V ⁡ ( G ) → V ⁡ ( H ) \varphi\colon V(G)\to V(H) such that edges of G G map to edges of H H . Additionally, given a list ℒ ⁡ ( v ) ⊆ V ⁡ ( H ) \mathcal{L}(v)\subseteq V(H) for every vertex v ∈ V ⁡ ( G ) v\in V(G) , a list homomorphism from ( G , ℒ ) (G,\mathcal{L}) to H H is a homomorphism φ \varphi from G G to H H such that for every vertex v ∈ V ⁡ ( G ) v\in V(G) , it holds that φ ⁡ ( v ) ∈ ℒ ⁡ ( v ) \varphi(v)\in\mathcal{L}(v) . List H H -Coloring is then the following problem: For a fixed graph H H , given ( G , ℒ ) (G,\mathcal{L}) as input, is there a list homomorphism from ( G , ℒ ) (G,\mathcal{L}) to H H ? Note that if H H is the complete graph on q q vertices, the problem is equivalent to List q q -Coloring . We investigate the kernelization properties of List H H -Coloring parameterized by the vertex cover number of G G . That is, given an instance ( G , ℒ ) (G,\mathcal{L}) and a vertex cover of G G of size k k , can we reduce ( G , ℒ ) (G,\mathcal{L}) to an equivalent instance ( G ′ , ℒ ′ ) (G^{\prime},\mathcal{L}^{\prime}) of List H H -Coloring where the size of G ′ G^{\prime} is bounded by a low-degree polynomial p ⁡ ( k ) p(k) in k k ? This question has been investigated previously by Jansen and Pieterse [Algorithmica 2019], who provided an upper bound, which turns out to be optimal if H H is a complete graph, i.e., for List q q -Coloring . This result was one of the first surprising applications of the method of kernelization via bounded-degree polynomials. More generally, the kernelization of List H H -Coloring parameterized by k k turns out to be equivalent to the kernelization of a related CSP (constraint satisfaction problem) on domain V ⁡ ( H ) V(H) , parameterized by the number of variables; the limits of kernelization for CSPs under this parameter is an important but poorly understood question. We define two new integral graph invariants, denoted by c ∗ ​ ( H ) c^{*}(H) and d ∗ ​ ( H ) d^{*}(H) , with d ∗ ​ ( H ) ⩽ c ∗ ​ ( H ) ⩽ d ∗ ​ ( H ) + 1 d^{*}(H)\leqslant c^{*}(H)\leqslant d^{*}(H)+1 , and show that the following hold. • For every graph H H , List H H -Coloring has a kernel with 𝒪 ⁡ ( k c ∗ ​ ( H ) ) \mathcal{O}(k^{c^{*}(H)}) vertices, hence size 𝒪 ⁡ ( k c ∗ ​ ( H ) ​ log ⁡ k ) \mathcal{O}(k^{c^{*}(H)}\log k) , via a simple marking scheme. • For every graph H H , there is no kernel of size 𝒪 ⁡ ( k d ∗ ​ ( H ) − ε ) \mathcal{O}(k^{d^{*}(H)-\varepsilon}) for any ε > 0 \varepsilon>0 , unless the polynomial hierarchy collapses. • Furthermore, if c ∗ ​ ( H ) > d ∗ ​ ( H ) c^{*}(H)>d^{*}(H) , then there is a kernel with 𝒪 ⁡ ( k c ∗ ​ ( H ) − ε ) \mathcal{O}(k^{c^{*}(H)-\varepsilon}) vertices where ε ⩾ 2 1 − c ∗ ​ ( H ) \varepsilon\geqslant 2^{1-c^{*}(H)} . Additionally, we show that for some classes of graphs, including powers of cycles and graphs H H where Δ ⁡ ( H ) ⩽ c ∗ ​ ( H ) \Delta(H)\leqslant c^{*}(H) (which in particular includes cliques), the bound d ∗ ​ ( H ) d^{*}(H) is tight, i.e., there is a kernel with 𝒪 ⁡ ( k d ∗ ​ ( H ) ) \mathcal{O}(k^{d^{*}(H)}) vertices using the polynomial method. We conjecture that this holds in general.



1
Introduction

For graphs
G
and
H
, a
homomorphism
from
G
to
H
is an edge-preserving mapping
\varphi:V(G)\to V(H)
, i.e., if
uv\in E(G)
, then
\varphi(u)\varphi(v)\in E(H)
.
If
G
is given together with lists
\mathcal{L}:V(G)\to 2^{V(H)}
– we will refer to them as
H
-lists
– then a
list homomorphism

\varphi
from
(G,\mathcal{L})
to
H
is a homomorphism from
G
to
H
, which additionally respects lists, i.e., for every
v\in V(G)
it holds that
\varphi(v)\in\mathcal{L}(v)
.
To indicate that
\varphi
is a list homomorphism from
G
to
H
respecting lists
\mathcal{L}
, we will write
\varphi:(G,\mathcal{L})\to H
, and we write
(G,\mathcal{L})\to H
, to indicate that such a list homomorphism exists. For a fixed graph
H
, in the
List
H
-Coloring
problem, we are given a pair
(G,\mathcal{L})
, and we have to determine whether
(G,\mathcal{L})\to H
. We remark that in
List
H
-Coloring
it makes sense to allow graphs
H
that have loops on vertices.

Note that if
H=K_{q}
, i.e., the complete graph on
q
vertices, then
List
H
-Coloring
is equivalent to
List
q
-Coloring
.
Thus,
List
H
-Coloring
can be seen as a far-reaching generalization of
List
q
-Coloring
. For this reason, we will typically refer to the vertices of
H
as
colors
.

The complexity dichotomy for the non-list variant of the problem was shown in 1990 by Hell and Nešetřil
[
13
]
: the problem is polynomial-time solvable if
H
is bipartite or has a vertex with a loop, and
NP
-hard otherwise.
The dichotomy for the list version was shown by Feder, Hell, and Huang
[
11
]
(see also
[
9
,
10
]
). Here, the
List
H
-Coloring
problem can be solved in polynomial time if
H
is a so-called
bi-arc graph
and otherwise it is
NP
-hard.

Kernelization of
List
H
-Coloring
.

In this paper we are interested in kernelization properties of the problem. Intuitively, we want to understand how much an instance of
List
H
-Coloring
can be compressed, in polynomial time, while preserving the answer.
Note that this problem makes sense only for graphs
H
for which the problem is
NP
-hard, i.e., for non-bi-arc-graphs.
The following result of Chen, Jansen, Okrasa, Pieterse, Rzążewski
[
5
]
shows that in general no non-trivial compression is possible,
under standard complexity assumptions (i.e., unless
\mathsf{NP\subseteq coNP/poly}
and the polynomial hierarchy collapses).

Theorem 1
(
[
5
]
).

Let
H
be a non-bi-arc graph. Then
List
H
-Coloring
parameterized by the number of vertices of the input graph admits no generalized kernel of size
\mathcal{O}(n^{2-\varepsilon})
, for any
\varepsilon>0
, unless
\mathsf{NP\subseteq coNP/poly}
.

Effectively, this results states that unless
\mathsf{NP\subseteq coNP/poly}
,
an instance of
List
H
-Coloring
with
n
vertices
cannot be compressed into
\mathcal{O}(n^{2-\varepsilon})
bits in polynomial time, regardless of encoding,
without losing track of its yes/no-status. See
section

2
for full definitions,
and
[
12
]
for more on kernelization.

However,
theorem

1
does not exclude a possibility of non-trivial compression of instances with some restricted structure.
In particular, we are interested in instances with small vertex cover. Thus, from now on we assume that the input graph is given with a set
X
of size at most
k
, such that
G-X
has no edges.

It is easy to notice that such instances can be in polynomial time transformed into equivalent ones, where the number of vertices depends on
k
only (such a compressed instance is called a
kernel
).
Indeed, every vertex from
V(G)\setminus X
can be characterized by (i) its neighborhood in
X
and (ii) its list. Thus, there are at most
2^{k}\cdot 2^{|V(H)|}=\mathcal{O}(2^{k})
possible ”types” of vertices in
V(G)\setminus X
, and it is sufficient to leave one vertex of each type (and the set
X
).
However, the number of vertices in such an instance is bounded by an exponential function of
k
. Can it be improved to a polynomial? As we discuss later, it turns out that this is indeed true. Furthermore, we are interested in bounding the degree of this polynomial. More precisely we study the the following problem.

Problem
.

For every non-bi-arc graph
H
, determine the value
\delta=\delta(H)
such that the
List
H
-Coloring
problem, parameterized by the size
k
of a vertex cover,

1.

admits a kernel with
\mathcal{O}(k^{\delta})
vertices and edges,

2.

does not have a kernel of size
\mathcal{O}(k^{\delta-\varepsilon})
, for any
\varepsilon>0
, unless
\mathsf{NP\subseteq coNP/poly}
.

This problem was previously studied by Jansen and Pieterse
[
14
]
, who showed that
\delta(H)
(using the notation from the problem above) is upper-bounded by the maximum degree of a vertex in
H
, denoted by
\Delta(H)
.
(We remark that the result of Jansen and Pieterse
[
14
]
is stated for non-list variant of the problem, but the approach easily generalizes to the list variant).

Theorem 2
(
[
14
]
).

Then
List
H
-Coloring
parameterized by the size
k
of a minimum vertex cover admits a kernel with
\mathcal{O}(k^{\Delta(H)})
vertices and edges.

Furthermore, Jansen and Pieterse
[
14
]
proved that for
List
q
-Coloring
, i.e., for the case that
H
is a complete graph, the bound given by
theorem

2
is actually tight.

Their approach uses a
polynomial method
, which can be understood in two steps.
First, instances
(G,\mathcal{L})
of
List
H
-Coloring
with a vertex cover
X
are interpreted as
CSPs, where
X
is the variable set and vertices of
V(G)\setminus X
act as

constraints
on the legal colorings of
X
; see below.
Next, these constraints are encoded into bounded-degree polynomials over
X
,
such that in order to preserve the solution space
it is enough to keep a basis of this set of polynomials.
Thus, an encoding of
List
H
-Coloring
into polynomials of degree
d
implies a kernel with
\mathcal{O}(k^{d})
constraints for the CSP,
and a kernel with
\mathcal{O}(k^{d})
vertices and edges for
List
H
-Coloring
.
In this paper we continue this line of research, aiming to provide tight bounds of other graphs
H
, with possible loops on vertices.

Our contribution.

Let
H
be a graph that is not a bi-arc graph.
We define two integer-valued quantities
c^{*}(H)
and
d^{*}(H)
(see
section

2
).
We show that these values always differ by at most one – more precisely, for every graph it holds that
d^{*}(H)\leqslant c^{*}(H)\leqslant d^{*}(H)+1
(see
lemma

12
).
Interestingly, both possibilities are attainable.
The values
c^{*}(H)
and
d^{*}(H)
upper and lower bound the kernelization bounds for the problem, respectively, as follows.

Theorem 3
.

Let
H
be a graph. Then
List
H
-Coloring
parameterized by the size
k
of a vertex cover admits a kernel with
\mathcal{O}(k^{c^{*}(H)})
vertices and edges.

Theorem 4
.

Let
H
be a fixed non-bi-arc graph.
Then
List
H
-Coloring
parameterized by the size
k
of a vertex cover does not have a kernel with
\mathcal{O}(k^{d^{*}(H)-\varepsilon})
vertices and edges, for any
\varepsilon>0
, unless
\mathsf{NP\subseteq coNP/poly}
.

Thus, for graphs
H
where
c^{*}(H)=d^{*}(H)
, the obtained bounds are tight. For graphs where
d^{*}(H)<c^{*}(H)
, we conjecture that in fact, the lower bound is correct.

Conjecture
.

For every graph
H
,
List
H
-Coloring
has a kernel with

\mathcal{O}(k^{d^{*}(H)})
vertices, where
k
is the size of a vertex cover of the input graph
G
.

We provide some evidence in support of this. As informal evidence, for
every graph
H
we have investigated via computer search, we found
that if
d^{*}(H)<c^{*}(H)
then the problem allows an encoding as above
into polynomials of degree
d^{*}(H)
(even over GF
(2)
).
More formally, we show that this holds for two classes of graphs:
powers of cycles (
section

6.2.1
), and graphs where
c^{*}(H)

is at least the max-degree of
H
(
section

6.2.2
).

Let us elaborate more on the latter class and recall that we can assume that
d^{*}(H)=c^{*}(H)-1
.
We observe that
c^{*}(H)\leqslant\Delta(H)+1
(see
lemma

14
).
If
c^{*}(H)=\Delta(H)+1
, i.e.,
d^{*}(H)=\Delta(H)
, then the tight upper bound follows already from
theorem

2
.
We also show that if
c^{*}(H)=\Delta(H)
, then
d^{*}(H)
is the optimal exponent in the problem.
Summarizing, we obtain the following result.

Theorem 5
.

Let
H
be a non-bi-arc graph such that
c^{*}(H)\geqslant\Delta(H)
.
Then
List
H
-Coloring
parameterized by the size
k
of the minimum vertex cover of the input graph admits a kernel with
\mathcal{O}(k^{d^{*}(H)})
vertices and edges, but does not admit a kernel of size
\mathcal{O}(k^{d^{*}(H)-\varepsilon})
vertices, for any
\varepsilon>0
, unless
\mathsf{NP\subseteq coNP/poly}
.

In addition, we show that for any graph
H
with
d^{*}(H)<c^{*}(H)
,
there is small but positive value
\varepsilon=2^{1-c^{*}(H)}
such that

List
H
-Coloring
has a kernel with
\mathcal{O}(k^{c^{*}(H)-\varepsilon})
vertices and edges.

Theorem 6
.

Let
H
be a non-bi-arc graph. Then for
\varepsilon=2^{1-c^{*}(H)}
, the
List
H
-Coloring
problem parameterized by the size
k
of a minimum vertex cover admits a kernel with
\mathcal{O}(k^{d^{*}(H)+1-\varepsilon})
vertices and edges.

Thus the simple bound
\mathcal{O}(k^{c^{*}(H)})
is never tight unless
c^{*}(H)=d^{*}(H)
.
This uses a connection to CSPs, which we survey next.

We note that if the degree bound of the smallest possible kernel were guaranteed to be an integer, then
the conjecture would follow. However, for CSPs, problems with tight non-integral
kernelization degrees do exist
[
1
]
(and in fact,
exist for every rational power
p/q\geqslant 1

[
2
]
).
Thus, the question is whether this occurs also for the restricted class of CSPs arising from
List
H
-Coloring
.

The CSP connection

One reason for studying
List
H
-Coloring
parameterized by the
vertex cover number is that it serves as a study case for
sparsification properties of CSPs parameterized by the number of variables.
Let us review the definitions.
A
constraint language
is a finite set of relations over some finite
domain
D
. A
constraint
over
\Gamma
is a tuple
(\mathbf{x},R)
,
where
R\in\Gamma
is a relation of some arity
r
and
\mathbf{x}=(x_{1},\ldots,x_{r})

is a tuple of variables, called the
scope
of the constraint.
This is also written simply as
R(x_{1},\ldots,x_{r})
.
The constraint is
satisfied
by an assignment
\varphi
to the variables
if
(\varphi(x_{1}),\ldots,\varphi(x_{r}))\in R
.
For a fixed constraint language
\Gamma
, the problem
\textsc{CSP}(\Gamma)

is the constraint satisfaction problem over
\Gamma
, where the input
is a set of variables
X
and a set
\mathcal{C}
of constraints over
\Gamma
, where
the scope of every constraint uses variables from
X
. The question is
whether there exists an assignment
\varphi\colon X\to D
that
satisfies all constraints in
\mathcal{C}
. The CSP framework is often used
as a setting for complexity characterizations; most famously, the

dichotomy theorem
, proven in 2017 after twenty years of study,
independently Bulatov
[
3
]
and Zhuk
[
21
,
22
]
,
says that for every language
\Gamma
,
\textsc{CSP}(\Gamma)
is either in
P
or
NP
-complete.

The
H
-Coloring
and
H
-List Coloring
problems can
be seen as special cases of this framework.
Indeed, for a fixed graph
H
, we can interpret the edge set of
H
as
a binary relation

R_{H}=\{(u,v)\in V(H)^{2}\mid uv\in E(H)\},

in which case
H
-Coloring
is equivalent to the CSP with language
\{R_{H}\}
,
where we simply enforce a constraint
R_{H}(u,v)
for every edge
uv\in E(G)
,
and
List
H
-Coloring
is the CSP with the language that
additionally contains all unary constraints
L\subseteq 2^{V(H)})
.
From this perspective, graph homomorphism problems can serve as a
“trial ground” where complex questions about the complexity of CSPs
can be studied in a more well-behaved setting. For example, the aforementioned
complexity dichotomies of
H
-Coloring

[
13
]
and
List
H
-Coloring

[
11
]

by far precede the proofs of the CSP dichotomy theorem
[
3
,
21
,
22
]
;
and the vertex/edge deletion variants of
List
H
-Coloring
, studied by
Chitnis et al.
[
7
]
, were an important milestone in
the study of FPT algorithms for CSP optimization problems such as

MinCSP

[
20
,
18
]
.

The limits of kernelization of CSPs parameterized by the number
n
of variables have seen
significant attention, and the polynomial method has been one of the
main tools employed
[
19
,
6
,
4
]
.
In fact, the first fine-grained lower bound on
kernel sizes was for
q
-SAT

[
8
]
,
and among the first applications of the polynomial method were a
non-trivial bound for
q
-NAE-SAT

[
15
]
,
which was the foundation for
theorem

2

[
14
]
.

More recently, two related notions have been studied –

non-redundancy
of CSPs, which is akin to a non-constructive kernelizability notion,
and
sparsification
, which is a stronger notion that preserves
not only the solution space of the CSP but also the approximate
portion of satisfied constraints
[
17
,
16
]
– which, remarkably, have been shown
to coincide up to a polylogarithmic factor
[
1
]
.
Still, some very basic questions remain unanswered – for example,
which Boolean languages admit kernelization to
\mathcal{O}(n)
constraints,
or have near-linear redundancy?

Studying
List
H
-Coloring
via the CSP over the relation
R_{H}
above is
not very informative, since
theorem

1
says that the
trivial kernel is optimal, but under the vertex cover parameter there
is another, richer connection to CSPs. Let
(G,\mathcal{L})
be an instance of

List
H
-Coloring
and
X
a vertex cover of
G
. Then we can view
X

as the variable set, and vertices
v\in V(G)\setminus X
as

constraints
on the coloring used on
X
.
More precisely, let
\varphi\colon X\to V(H)
be a coloring
of the vertex cover which is a list homomorphism from
(G[X],\mathcal{L})
to
H
.
Then
\varphi
can be extended to a list homomorphism
(G,\mathcal{L})\to H

if and only if, for every vertex
v\in V(G)\setminus X
,

\exists a\in L(v)\;\forall x\in N_{G}(v)\colon a\in N_{H}(\varphi(x)),

where
N_{G}(v)
denotes the set of neighbors of
v
in the graph
G
.
Since this depends only on the set of colors used for
N_{G}(v)\subseteq X

in
\varphi
, we can “project” this to a constraint directly on
X
,
specifically a constraint

R_{L,r}(x_{1},\ldots,x_{r})\text{ where }R_{L,r}=\{(x_{1},\ldots,x_{r})\in V(H)^{r}\mid\exists a\in L\;\forall i\in[r]\ :\ a\in N_{H}(x_{i})\}

where
L=\mathcal{L}(v)
and
N_{G}(v)=\{x_{1},\ldots,x_{r}\}
.
In this setting, the parameters
c^{*}(H)
and
d^{*}(H)
have natural CSP interpretations.
Namely,
c^{*}(H)
is the
decomposability
of
R_{L}
– that is,
for every value of
r=\deg_{G}(v)
and every list
L
, the relation
R_{L,r}
is equivalent to a
conjunction of constraints of arity
c^{*}(H)
. Thus,
List
H
-Coloring

is equivalent to a CSP with
k
variables over a language
\Gamma_{H}

containing relations of arity up to
c^{*}(H)
.
The parameter
d^{*}(H)
corresponds to a more technical, but established
notion:
q=d^{*}(H)+1
is the smallest
q
such that
\Gamma_{H}
is preserved
by the so-called
q
-universal partial polymorphism
(see Lagerkvist
and Wahlström
[
19
]
).
Within this framework, the
\varepsilon
-improved bound follows from the work of
Carbonnel
[
4
]
.

More strongly, for Boolean CSPs Chen, Jansen and Pieterse
[
6
]

showed that every
r
-ary relation except
r
-clauses (i.e.,
r
-ary relations with only one excluded tuple)
can be captured by a set of polynomials of degree at most
r-1
.
Unfortunately, this is not true for general CSPs, and we cannot
exclude that the “Booleanization” of
R_{L,c^{*}(H)}
yields an
r
-clause
even if
d^{*}(H)<c^{*}(H)
for some graph
H
.

Notation and preliminaries

For a positive integer
n
, by
[n]
we denote the set
\{1,\ldots,n\}
.
For a set
S
and an integer
k
, by
\binom{S}{k}
we denote the family of all
k
-element subsets of
S
.
The
shadow
of a set
S
to is

\delta S=\{S^{\prime}\subset S\mid|S^{\prime}|=|S|-1\}.

Graphs.

Let
G
be a graph with possible loops on vertices.
For a vertex
v\in V(G)
, by
N_{G}(v)
we denote the set of neighbors of
v
in
G
.
Note that
v\in N_{G}(v)
if and only if
v
has a loop.
The
degree
of
v
is
|N_{G}(v)|
and is denoted by
\deg_{G}(v)
. Note that in this convention a loop contributes 1 to the degree of the vertex.
If
G
is clear from the contex, then we will simply write
N(v)
instead of
N_{G}(v)
, and
\deg(v)
instead of
\deg_{G}(v)
.
We say that two vertices
u,v\in V(G)
are
incomparable
if
N(u)\not\subseteq N(v)
and
N(v)\not\subseteq N(u)
. A set
L\subseteq V(G)
is
incomparable
if all its vertices are pairwise incomparable.

Homomorphisms.

Fix a graph
H
and consider an instance
(G,\mathcal{L})
of
List
H
-Coloring
. Suppose there is a vertex
v\in V(G)
and two distinct vertices
x,y\in\mathcal{L}(v)
such that
N_{H}(x)\subseteq N_{H}(y)
, then the instance
(G,\mathcal{L}^{\prime})
obtained by removing
x
from
\mathcal{L}(v)
is equivalent to the instance
(G,\mathcal{L})
.
Indeed, if there is a list homomorphism
\varphi:(G,\mathcal{L})\to H
with
\varphi(v)=x
, then we can also set
\varphi(v)=y
, as all neighbors of
x
are also the neighbors of
y
.
Therefore, applying the above procedure exhaustively to an instance
(G,\mathcal{L})
, we can obtain in polynomial time an equivalent instance
(G,\mathcal{L}^{\prime})
with all lists being incomparable sets.
We will call such an instance
(G,\mathcal{L}^{\prime})

reduced
.

Sometimes we will abuse the notation and for an instance
(G,\mathcal{L})
of
List
H
-Coloring
and for a subgraph
G^{\prime}
of
G
, we will write
(G^{\prime},\mathcal{L})
instead of
(G^{\prime},\mathcal{L}|_{V(G^{\prime})})
.

Recall that
List
H
-Coloring
is polynomial-time solvable if
H
is a bi-arc-graph, and
NP
-hard otherwise
[
11
]
.
The definition of bi-arc graphs is somewhat involved and not really relevant to our work, but let us list some properties of (non) bi-arc graphs that will be useful for us.

Theorem 7
(
[
11
]
).

Let
H
be a simple graph.

1.

If
H
is non-bipartite or contains an induced cycle with at least
6
vertices, then
H
is non-bi-arc, and thus
List
H
-Coloring
is NP-hard.

2.

If
H
contains at most
2

, then
H
is a bi-arc graph, and thus
List
H
-Coloring
is polynomial-time solvable.

3.

If
H
is a non-bi-arc graph, then there are vertices (not necessarily distinct)
v_{1},v_{2},v_{3},v_{4},v_{5}
such that (i)

Kernels.

Let
\Sigma
be a finite set (alphabet).
A
parameterized problem
is a subset of
\Sigma^{*}\times\mathbb{N}
.
Let
g:\mathbb{N}\to\mathbb{N}
be a computable function.
For parameterized problems
\mathcal{P},\mathcal{P^{\prime}}\subseteq\Sigma^{*}\times\mathbb{N}
,
a generalized kernel of
\mathcal{P}
into
\mathcal{P^{\prime}}
is an algorithm
\mathcal{A}
that given an instance
(x,k)\in\Sigma^{*}\times\mathbb{N}
, outputs in time polynomial in
|x|+k
an instance
(x^{\prime},k^{\prime})
such that:

1.

(x,k)\in\mathcal{P}
if and only if
(x^{\prime},k^{\prime})\in\mathcal{P^{\prime}}
,

2.

|x^{\prime}|+k^{\prime}\leqslant g(k)
.

We say that
\mathcal{A}
is
a kernel
for
\mathcal{P}
if
\mathcal{P}=\mathcal{P^{\prime}}
.

3
Definition of
c^{*}(H)
and
d^{*}(H)

Let
H
be a graph with possible loops.
Let
L,S\subseteq V(H)
. We say that
S

has a common neighbor in

L
if there is a vertex in
L
adjacent to every vertex in
S
.
Note that it might happen that a common neighbor belongs to
S\cap L
, it is only possible if such a vertex has a loop.

Let us define two graph invariants that will be important in our paper.

Definition 8
(
c^{*}(H)
).

We define
c^{*}(H)
as follows:

c^{*}(H):=\max_{L\subseteq V(H)}\max\{|S|\ |\ S\subseteq V(H)\text{ is a minimal set that does not have a common neighbor in }L\}.

In other words,
c^{*}(H)
is the size of a largest possible set
S
, for which there is
L
, such that:

•

S
has no common neighbor in
L
,

•

every proper subset of
S
has a common neighbor in
L
.

Definition 9
(
d^{*}(H)
).

Let
H
be a graph. A
lower bound structure
of order
d
in
H
is formed by a subset
L\subseteq V(H)
, distinct vertices
(x_{1},\ldots,x_{d})
, and non-necessarily distinct vertices
(x_{1}^{\prime},\ldots,x_{d}^{\prime})
, such that
x_{i}
is incomparable with
x_{i}^{\prime}
for every
i\in[d]
, and

•

\bigcap_{i\in[d]}N(x_{i})\cap L=\emptyset
, meaning that
x_{1},\ldots,x_{d}
do not have a common neighbor in
L
, but

•

\bigcap_{i\in[d]}N(y_{i})\cap L\neq\emptyset
where
y_{i}\in\{x_{i},x_{i}^{\prime}\}
and there exists
i\in[d]
such that
y_{i}=x_{i}^{\prime}
. This means that replacing at least one
x_{i}
by its primed counterpart yields a set that does have a common neighbor in
L
.

By
d^{*}(H)
we will denote the largest
d
such that
H
admits a lower bound structure of order
d
.

Let us point out that in our setting, in both definitions, the set
L
will be a list of some vertex, and thus it would be natural to assume that
L
is an incomparable set.
However, it turns out that such an assumption does not influence the definition.

Observation 10
.

Let
H
be a graph. The following hold.

1.

c^{*}(H)=\max_{\begin{subarray}{c}L\subseteq V(H),\\
L\text{ is incomparable}\end{subarray}}\max\{|S|\ |\ S\subseteq V(H)\text{ is a minimal set that does not have a common neighbor in }L\},

2.

d^{*}(H)
is the maximum
d
such that there is an incomparable set
L\subseteq V(H)
, distinct vertices
(x_{1},\ldots,x_{d})
, and non-necessarily distinct vertices
(x_{1}^{\prime},\ldots,x_{d}^{\prime})
that form a lower bound structure of order

.

Proof.

We will prove 1. – the proof of 2. is analogous.
Let us define

c^{\prime}(H):=\max_{\begin{subarray}{c}L\subseteq V(H),\\
L\text{ is incomparable}\end{subarray}}\max\{|S|\ |\ S\subseteq V(H)\text{ is a minimal set that does not have a common neighbor in }L\}.

We aim to show that
c^{\prime}(H)=c^{*}(H)
.
Clearly, it holds that
c^{\prime}(H)\leqslant c^{*}(H)
.
So now let us show that
c^{\prime}(H)\geqslant c^{*}(H)
.
Let
L\subseteq V(H)
, and let
S\subseteq V(H)
be a minimal set that does not have a common neighbor in
L
such that
c^{*}(H)=|S|
.
By the definition, if
L
is incomparable, then
c^{\prime}(H)\geqslant c^{*}(H)
, as desired.
So suppose that
L
is not incomparable, and let
x,y\in L
be such that
N_{H}(x)\subseteq N_{H}(y)
.
We will show that
S
is also a minimal set that does not have a common neighbor in
L\setminus\{x\}
.
Indeed, since
S
does not have a common neigbor in
L
, then
S
does not have a common neighbor in
L\setminus\{x\}
.
Furthermore, for a proper subset
S^{\prime}\subseteq S
, the set
S^{\prime}
has a common neighbor in
L
.
If the common neighbor of
S^{\prime}
in
L
is
x
, then also
y
is a common neighbor of
S^{\prime}
, and thus
S^{\prime}
has a common neigbor in
L\setminus\{x\}
.

We can now exhaustively remove every vertex

such that there is
y\in L
with
N_{H}(x)\subseteq N_{H}(y)
, and obtain an incomparable set

such that
S
is minimal set that does not have a common neighbor in
L^{\prime}
.
This completes the proof.

We observe that the parameters introduced above, i.e.,

Lemma 12
.

For every graph
H
, it holds that
c^{*}(H)-1\leqslant d^{*}(H)\leqslant c^{*}(H)
.

Proof.

Let

and let

and

be as in

8
.
For all

and

Clearly, the set

.
Since

edges that are not contained in

It remains to show the equivalence of instances

and

.
Since

is a subgraph of

, if

.
So now suppose that

We define

as follows.
For every

.
Note that if we treat

6.1
Polynomial method

In this section we present how to obtain smaller kernel using low degree polynomials, similar as in
[
15
]
.
Consider an instance
(G,\mathcal{L})
of
List
H
-Coloring
with a vertex cover
X
of size
k
.
For every
v\in X
,
u\in V(H)
, we introduce a boolean variable
y_{v,u}
whose value will correspond to mapping
v
to
u
or not.

In a similar way to
[
14
, Definition 4]
, we will define a choice assignment.

Definition 21
.

Given sets
X
and
V(H)
, let
y_{v,u}\in\{0,1\}
for
v\in X
,
u\in V(H)
be a set of boolean variables and let
\mathbf{y}
be the vector containing all these variables. We say
\mathbf{y}
is given a
choice assignment
if for all
v\in X
:

\sum_{u\in V(H)}y_{v,u}=1.

Intuitively, a vector
\mathbf{y}
is given a choice assignment if and only if it directly corresponds to mapping vertices of
X
to
V(H)
so that vertex
v
is mapped to
u
whenever
y_{v,u}=1
.
By the definition of a choice assignment, this means each vertex is mapped to precisely one vertex.

For a mapping
\varphi:X\to V(H)
, we say that a choice assignment of
\mathbf{y}

corresponds to
\varphi
if for every
v\in X
, we have
y_{v,u}=1
if and only if
\varphi(v)=u
.

We now state what it means to be able to forbid a certain mapping by low degree polynomials.

Definition 22
.

Let
H
be a graph, let
L_{1},\ldots,L_{r},L\subseteq V(H)
be incomparable sets, and let
F=L_{1}\times\ldots\times L_{r}
.
Let
S=(s_{1},\ldots,s_{r})\in F
be a sequence such that
\bigcap_{i=1}^{r}N(s_{i})\cap L=\emptyset
.
We say that
S
can be forbidden (on distinct vertices
v_{1},\ldots,v_{r}\in X
) by polynomials of degree
d
with respect to pair
(F,L)
if there exists a polynomial
p_{S}
of degree at most
d
on variables
\mathbf{y}:=(y_{v,u}\mid v\in X,u\in V(H))
such that for all choice assignments to
\mathbf{y}
the following holds:

For
\ell\in[r]
, let
s_{\ell}^{\prime}\in V(H)
be such that
y_{v_{\ell},s^{\prime}_{\ell}}=1
(note that there is exactly one such
s^{\prime}_{\ell}
) and let
S^{\prime}=(s^{\prime}_{1},\ldots,s^{\prime}_{r})\in F
. Then:

•

If
S^{\prime}=S
, then
p(\mathbf{y})\neq 0
.

•

If
S^{\prime}
has a common neighbor in
L
, meaning
\bigcap_{i=1}^{r}N(s^{\prime}_{i})\neq\emptyset
, then
p(\mathbf{y})=0
.

Note that the two cases in the above definition do not cover all possibilities. There are no requirements on what the polynomial does when
\mathbf{y}
is not given a choice assignment, and there are also no requirements on what happens if
\mathbf{y}
is given an assignment that corresponds to a set with no common neighbor in
L
, not equivalent to
S
. This is on purpose.

We will use the following result of Jansen and Pieterse
[
15
]
.

Theorem 23
(
[
15
, Theorem 3.1, Claim 3.2]
).

Let
P
be a set of equalities over
m
variables
\textrm{Var}=\{x_{1},\ldots,x_{m}\}
,
where each equality is of the form
f(x_{1},\ldots,x_{m})=0
for some multivariate polynomial
f
of degree
d
over
\mathbb{Z}_{2}
.
In time polynomial in
|P|
and
m
we can find a subset
P^{\prime}\subseteq P
of size at most
m^{d}+1
, such that
an assignment of variables in
Var
satisfies all equalities in
P^{\prime}
if and only if it satisfies all equalities in
P
.

Now we are ready to show how to use low-degree polynomials to obtain smaller kernels.
The proof is similar to the one in
[
14
]
.

Theorem 24
.

Let
H
be a graph such that for every

d
with respect to
(F,L)

List
H
-Coloring

\mathcal{O}(k^{d}+k^{2})

Proof.

Let
(G,\mathcal{L})
be an instance of

H
-Coloring

.
Clearly,

-Coloring

.
The vertex set of

,
and a subset of edges joining

with

.
The set

To achieve this, we will represent the constraints on the coloring of the neighborhood of such vertices, by low-degree polynomials.

Variables and polynomials.

Let

be the vertices of

be the vertices of

.
For every

be the vector containing all variables

So now let us construct a set

Intialize

For every

.

.
Then, for each vertex

For every

that forbids

Add

to

.
This completes the costruction of

.
By

satisfying all equalities if

and list homomorphims from

that can be extended to

.

Now we apply
theorem

to

with the same set of satisfying assignments and which has at most
\mathcal{O}((h\cdot k)^{d})
polynomials.

Construction of

.

Based on

.
We start with

.
Furthermore, for every

.

.

Let us show that the instances

-Coloring

Claim 2

Since

So suppose there is a list homomorphism

\lrcorner

Using

.

Alternative proof of

In this section we consider some specific graph classes and we show that by the polynomial method we can obtain kernels of size

As building blocks of the constructed polynomials, we will use the following result of Jansen and Pieterse
[

]
– we state it in the form that is suitable for us.

Lemma 25
(
[

Let

be graphs, let

, and let
(v_{1},\ldots,v_{r})\in V(G)^{r}

There is a polynomial

6.2.1
Powers of cycles

As the first natural class of graphs, we consider cycles, and then also powers of cycles.

For an integer

\llbracket k\rrbracket:=\{0,1,\ldots,k-1\}

and

.

For integers

and

\llbracket k\rrbracket
and the edge set
\{uv\penalty\ |\penalty\ \operatorname{dist}_{k}(u,v)\leqslant p\}

with consecutive vertices

as the

of

.

As a warm-up, we first consider the case

, i.e., the case of cycles.
Let us point out that the case of
List
C_{3}
-Coloring
is equivalent to
List
3
-Coloring
, which was studied by Jansen and Pieterse
[

]
.
Furthermore, the graph

-Coloring

[

]
.
Therefore, we focus on

with

]
.
Recall that, for

Lemma 26
.

Let

-
v
-path in the frame of
C^{p}_{k}
, i.e.,
0\leqslant w\leqslant v
.
Indeed, if this is not the case, then either
\operatorname{dist}_{k}(0,w)>\operatorname{dist}_{k}(0,v)
or
\operatorname{dist}_{k}(v,w)>\operatorname{dist}_{k}(0,v)
, which contradicts our choice of
u=0
and
v
.

Now let us observe that that
S\subseteq\{0,v\}\cup(N(0)\cap N(v))
.
Indeed, suppose that there is
z\in S
such that
z\notin\{0,v\}\cup(N(0)\cap N(v))
and consider the set
S^{\prime}:=S\setminus\{z\}
.
By the minimality of
S
, the set
S^{\prime}
has a common neighbor
w\in L
.
Note that
w\neq z
as
z\notin N(0)\cap N(v)
and
w
must be in particular a common neighbor of
0
and
v
.
Furthermore, as for every common neighbor of
0
and
v
, it must hold that
\operatorname{dist}_{k}(0,w)\leqslant p
and
\operatorname{dist}_{k}(w,v)\leqslant p
.
Since we also have
0<z<v
as
z\in S
, then
\operatorname{dist}_{k}(z,w)\leqslant p
, so
z\in N(w)
.
Therefore,
w
is also a common neighbor of
S
, a contradiction.

Let us estimate the size of the set
|S|
.
Recall that
S
contains only the vertices
w
, such that
0\leqslant w\leqslant v
, and are common neighbors of
0
and
v
or are equal to
0
or
v
.
Observe that
0
has precisely
p
neighbors
w
, such that
w>0
,
and similarly
v
has precisely
p
neighbors
w
, such that
w<v
.
Thus
|S|\leqslant p+2
.

If
|S|=p+2
, then
S
consists of
0,v
and precisely
p
vertices
w
that have to satisfy
0<w\leqslant p
and
v-p\leqslant w<v
.
This is only possible for
v=p+1
and
S=\{0,1,\ldots,p+1\}
.
But then
S
contains
p+1
consecutive vertices of the frame, a contradiction.

So now assume that
|S|=p+1
, i.e.,
S
contains
0,v
and
p-1
vertices
w
that satisfy
0<w\leqslant p
and
v-p\leqslant w<v
.
As there have to be
p-1
vertices
w
satisfying
v-p\leqslant w\leqslant p
, it must hold that
v\leqslant p+2
.
On the other hand, since we consider the case that
S
does not contain
p+1
consecutive vertices of the frame, we observe that
v\geqslant p+1
, and thus
v\in\{p+1,p+2\}
.

Suppose first that
v=p+1
.
Since
|S|=p+1
, there is precisely one
0<u<p+1
such that
u\notin S
.
Note that
u\notin L
, as otherwise
S
, which contains only vertices
w
such that
0\leqslant w\leqslant p+1
, has a common neighbor
u\in L
, a contradiction.
Now consider the set
S^{\prime}=S\setminus\{0\}
.
By the minimality of
S
, the set
S^{\prime}
has a common neighbor
w\in L
.
Note that
w\neq u
and
w\notin S^{\prime}
, and thus either
w<1
or
w>v=p+1
.
We cannot have
w<1
, as then
w
is non-adjacent to
v
, so we have
w>p+1
.
Then
1\notin S^{\prime}
, as
1
cannot be adjacent to
w
, and this is only possible if
u=1
.
Now let
S^{\prime\prime}=S\setminus\{p+1\}
.
Again, by the minimality of
S
, there is a common neighbor
z\in L
of
S^{\prime\prime}
.
Since
z\notin S^{\prime\prime}
and
z\neq u
, we either have
z<0
or
z>p
.
We cannot have
z>p
, as then
z
is non-adjacent to
0\in S^{\prime\prime}
, and thus
z<0
.
But then
z
is non-adjacent to
p\geqslant 2\neq u
, which is a contradiction with the fact that
z\in S^{\prime\prime}
and
z
being the common neighbor of
S^{\prime\prime}
.

So it remains to consider the case
v=p+2
.
As every vertex
w\in S\setminus\{0,v\}
has to be adjacent to both
0
and
v
, all such vertices have to satisfy
v-p\leqslant w\leqslant p
, which for
v=p+2
is
2\leqslant w\leqslant p
.
Since
|S|=p+1
, the only possiblity is that
S=\{0,2,3,\ldots,p,p+2\}
.
This gives case (
b
) in the second statement of the lemma, which completes the proof.

Now we will show how to forbid the sets of types (
a
) and (
b
) by low-degree polynomials.

Lemma 29
.

Let
p\geqslant 2
,
k>6p
,
L_{i}\subseteq V(C_{k}^{p})
be an incomparable set for
i\in[p+1]
, and let
S\in F=L_{1}\times\ldots\times L_{p+1}
be minimal with no common neighbor in
L\subseteq V(C_{k}^{p})
. Then
S
can be forbidden by a polynomial of degree at most
p
, with respect to
(F,L)
.

Proof.

Let
S=(s_{1},\ldots,s_{p+1})
. By minimality of
S
, it holds that the set
\{s_{1},\ldots,s_{p+1}\}
has
p+1
distinct elements. We will construct a polynomial with a stronger property than required, i.e., in assignment corresponding to any coloring of vertices
v_{1},\ldots,v_{p+1}
, if the set
\{s_{1},\ldots,s_{p+1}\}
occurs, then the polynomial equals to
1
(modulo
2
), and if a set with a common neighbor in
C^{p}_{k}
occurs, then the polynomial equals to
0
(modulo
2
). Since we focus on sets rather than sequences, we will treat
S
as the set
\{s_{1},\ldots,s_{p+1}\}
.

Recall that we use variables
y_{v_{i},c}
for
i\in[p+1],c\in\llbracket k\rrbracket
representing that vertex
i
has color
c
.

For
i,j\in\llbracket k\rrbracket
, we set
A_{i,j}:=\{i,j,j+1,\ldots,j+p-2\}
.
Let us also define
I\subseteq\llbracket k\rrbracket^{2}
to be the set of of these pairs
(i,j)
such that: (i)
2\leqslant\operatorname{dist}_{k}(i,j)\leqslant 2p
, and (ii)
\operatorname{dist}_{k}(i,j)<\operatorname{dist}_{k}(i,j+1)
.
For every
(i,j)\in I
, we call
lemma

25
to construct the polynomial
p_{A_{i,j}}
, which evaluates to
1
(modulo
2
) if each of the colors in
A_{i,j}
is used exactly once by choice assignment
\mathbf{y}
(implying also that one color not from this set is used), and evaluates to
0
otherwise.

We construct the polynomial
p
as follows:

\displaystyle f(\mathbf{y})=\sum_{(i,j)\in I}p_{A_{i,j}}(\mathbf{y}).

We will prove that for a choice assignment
\mathbf{y}
corresponding to a coloring of
v_{1},\ldots,v_{p+1}
such that the set
S
occurs, we have
f(\mathbf{y})\equiv_{2}1
, and for assignment corresponding to coloring such that a set
S^{\prime}
with a common neighbor occurs, we have
f(\mathbf{y})\equiv_{2}0
.

Case 1:
p=2
.

By
lemma

28
, the set
S
is of one of the following types:
\{i,i+1,i+2\}
or
\{i,i+2,i+4\}
.
Furthermore, we have that
I=\{(i,i+2),(i,i+3),(i,i+4)\ |\ i\in\llbracket k\rrbracket\}
, and for
i\in\llbracket k\rrbracket
, we have
A_{i,i+2}=\{i,i+2\}
,
A_{i,i+3}=\{i,i+3\}
, and
A_{i,i+4}=\{i,i+4\}
.
So for an assignment
\mathbf{y}
corresponding to
S
of type
\{i,i+1,i+2\}
, the only polynomial in the sum evaluating to
1
is
p_{A_{i,i+2}}
, and for
S
of type
\{i,i+2,i+4\}
, exactly three polynomials evaluate to
1
:
p_{A_{i,i+2}}
,
p_{A_{i,i+4}}
, and
p_{A_{i+2,i+4}}
.
In both cases we obtain that
f(\mathbf{y})\equiv_{2}1
.

It remains to show that if a set
S^{\prime}
with a common neighbor occurs, then
f(\mathbf{y})\equiv_{2}0
. If
|S^{\prime}|\leqslant 2
, then no polynomial in the sum evaluates to
1
, thus
f(\mathbf{y})\equiv_{2}0
. And if
|S^{\prime}|=3
, then it can be verified that
S^{\prime}
is of one of the following types: (i)
\{i,i+1,i+4\}
, (ii)
\{i,i+3,i+4\}
, (iii)
\{i,i+1,i+3\}
, and (iv)
\{i,i+2,i+3\}
– note that since
S^{\prime}
has a common neighbor, for any vertices
uv\in S^{\prime}
it must hold
\operatorname{dist}_{k}(u,v)\leqslant 4
. In every case there are precisely two polynomials in the sum evaluating to
1
, respectively: (i)
p_{A_{i,i+4}}
and
p_{A_{i+1,i+4}}
, (ii)
p_{A_{i,i+3}}
and
p_{A_{i,i+4}}
, (iii)
p_{A_{i,i+3}}
and
p_{A_{i+1,i+3}}
, (iv)
p_{A_{i,i+2}}
and
p_{A_{i,i+3}}
. Therefore, in each case we obtain
f(\mathbf{y})\equiv_{2}0
.

Case 2:
p\geqslant 3
.

So since now assume that
p\geqslant 3
and let us prove that for choice assignment
\mathbf{y}
corresponding to a coloring of
v_{1},\ldots,v_{p+1}
such that the set
S
occurs, we have
f(\mathbf{y})\equiv_{2}1
.
As
S
is a minimal set without a common neighbor in
L
of size
p+1
, then by
lemma

28
, the set
S
is of one of the following types:
\{i,i+1,\ldots,i+p\}
or
\{i,i+2,\ldots,i+p,i+p+2\}
.
In both cases, we have
p_{A_{i,i+2}}(\mathbf{y})\equiv_{2}1
, (recall that
A_{i,i+2}=\{i,i+2,\ldots,i+p\}
) and it can be verified, that this is the only polynomial in the sum that evaluates to
1
, so
f(\mathbf{y})\equiv_{2}1
.

It remains to show that if a set
S^{\prime}
has a common neighbor in
C_{k}^{p}
, then it is not forbidden by
f
.
Let
\mathbf{y}
be a choice assignment using the colors in
S^{\prime}
.
If
|S^{\prime}|\leqslant p
, observe that all terms of
p
are always zero as some color occurs twice on a set of
p+1
vertices by the pigeon hole principle, and thus
f(\mathbf{y})\equiv_{2}0
.
Furthermore, if
S^{\prime}
does not contain
p-1
consecutive vertices, then every polynomial in the sum equals
0
, and again
f(\mathbf{y})\equiv_{2}0
as required.

So since now we assume that
|S^{\prime}|=p+1
and
S^{\prime}
contains
p-1
consecutive vertices.
By symmetry, we can assume that
S^{\prime}
contains
p+1,\ldots,2p-1
.
Since
|S^{\prime}|=p+1
, then there are two more vertices
u,v
in
S^{\prime}
.

Assume first that there are
p
consecutive vertices in
S^{\prime}
, again by symmetry we can assume that
u=2p
, i.e.,
S^{\prime}
contains the vertices
p+1,\ldots,2p
.
Note that the only common neighbors of
\{p+1,\ldots,2p\}
are
p
and
2p+1
.
Therefore
v
must be adjacent to
p
or
2p+1
, so either
0\leqslant v<p
or
2p+1<v\leqslant 3p+1
.
If the first case applies, then the only polynomials evaluating to
1
are:
p_{A_{v,p+1}}
and
p_{A_{v,p+2}}
, i.e., the polynomials for the sets
\{v,p+1,p+2,\ldots,2p-1\}
and
\{v,p+2,p+3,\ldots,2p\}
, so
f(\mathbf{y})\equiv_{2}0
as required.
If the other case applies, then no polynomial evaluates to
1
, so again
f(\mathbf{y})\equiv_{2}0
as required.

Finally, assume that there are no
p
consecutive vertices in
S^{\prime}
, so
u,v\notin\{p,2p\}
.
Now observe that the only common neighbors of
\{p+1,\ldots,2p-1\}
are
p-1
,
p
,
2p
, and
2p+1
.
Therefore
u,v
must be both adjacent either to one of
\{2p,2p+1\}
or to one of
\{p-1,p\}
.
If the first case applies, then we have that
u,v>2p
.
If
p>3
, then this means that no polynomial in the sum evaluates to
1
, so
f(\mathbf{y})\equiv_{2}0
as required.
If
p=3
, the only case when there is some polynomial that does not evaluate to
0
is when the vertices
u,v
are consecutive, say
u<v
.
In such a case there are exactly two polynomials evaluating to
1
: the ones introduced for the sets
A_{p+1,u}=\{p+1,u,v\}
and
A_{p+2,u}=\{p+2,u,v\}
, so again
f(\mathbf{y})\equiv_{2}0
.
In the other case we have
\operatorname{dist}_{k}(u,p-1)<\operatorname{dist}_{k}(u,p)\leqslant p+1
and
\operatorname{dist}_{k}(v,p-1)<\operatorname{dist}_{k}(v,p)\leqslant p+1
, and there are exactly two polynomials that evaluate to
1
: the ones introduced for the sets
A_{u,p+1}=\{u,p+1,\ldots,2p-1\}
and
A_{v,p+1}=\{v,p+1,\ldots,2p-1\}
, so again
f(\mathbf{y})\equiv_{2}0
as required.
This completes the proof.

6.2.2
Small-degree graphs
H

Recall that if
d^{*}(H)=c^{*}(H)
, tight bounds are obtained by the combination of
theorem

3
and
theorem

4
.
Thus from now on assume that
d^{*}(H)=c^{*}(H)-1
.

We now consider graphs where
c^{*}(H)
is close to or equal to the
maximum degree
\Delta(H)
.
By
lemma

14
, we have
c^{*}(H)\leqslant\Delta(H)+1
.
If
c^{*}(H)=\Delta(H)+1
, then
d^{*}(H)=\Delta(H)
, and tight bounds follow from combining
theorem

2
due to Jansen and Pieterse
[
14
]
and
theorem

4
.

So from now on we focus on the case
c^{*}(H)=\Delta(H)
and show that such graphs have a kernel with
\mathcal{O}(k^{d^{*}(H)})
vertices and edges.
By
theorem

24
,
it suffices to show the existence of appropriate polynomials of degree
d^{*}(H)
.

We begin by a useful structural property.

Lemma 31
.

Let
H
be a graph such that
d^{*}(H)+1=c^{*}(H)=\Delta(H)
.
Let
S=N(v)
for some
v\in V(H)
with
\deg(v)=\Delta(H)
.
Then there exists some
u\in S
such that
S\setminus\{u\}\subseteq N(v^{\prime})

for
v^{\prime}\in V(H)
implies
N(v^{\prime})\subseteq N(v)
.

Proof.

Assume to the contrary that for every
u\in S
there exists a vertex
v_{u}\neq v\in V(H)
such that
\deg(v_{u})=\deg(v)
and
N(v_{u})=(S\setminus\{u\})\cup u^{\prime}
for some
u^{\prime}\in V(H)
,
u^{\prime}\notin S
.
We split into two cases.
First, assume that
\{v_{u}\mid u\in S\}
has a common neighbor
z
.
Note that
z\notin S
, as then for
u=v
, we have that
N(v_{u})=S\setminus\{u\}\cup\{u^{\prime}\}=S\setminus\{z\}\cup\{u^{\prime}\}
, and thus
v_{u}
cannot be adjacent to
z
.
Moreover, for every
u\in S
, since
\deg(v_{u})\geqslant|S\setminus\{u\}\cup\{u^{\prime}\}|=\Delta(H)
, it holds that
u^{\prime}=z
.
Now consider the set
S^{\prime}=S\cup\{z\}
.
It has no common neighbors since
|S^{\prime}|>\Delta(H)
, but
S^{\prime}\setminus\{z\}=S=N(v)
has a common neighbor
v
, and for every
u\in S
, the set
S^{\prime}\setminus\{u\}=S\setminus\{u\}\cup\{z\}
has a common neighbor
v_{u}
.
Then
S^{\prime}
contradicts the claim that
c^{*}(H)=\Delta(H)
.

Otherwise, the set
X=\{v_{u}\mid u\in S\}
has no common neighbor.
Note that
|X|=|S|
, as all vertices
v_{u}
must be distinct by the degree bound on
H
.
On the other hand, let
v_{u}^{\prime}=v
for every
v_{u}\in X
.
Then
X\setminus\{v_{u}\}\cup\{v_{u}^{\prime}\}=X\setminus\{v_{u}\}\cup\{v\}
has a common neighbor
u
, and this obviously remains true if we replace more vertices
v_{i}\in X
by
v_{i}^{\prime}=v
(since the resulting set is then a strict subset of
X\setminus\{v_{u}\}\cup\{v\}
).
Finally,
v_{u}
and
v
are incomparable for every
u\in S
, since
u\in N(v)\setminus N(v_{u})
and
u^{\prime}\in N(v_{u})\setminus N(v)
.
Thus
X
is a lower bound structure of size
|X|=\Delta(H)=c^{*}(H)>d^{*}(H)
in
H
, a contradiction.

Rephrased, let
\mathcal{S}=\{S\subseteq V(H):|S|=c^{*}(H),S\text{ has a common neighbor}\}
.
Then for every
S\in\mathcal{S}
there exists a set
S^{\prime}\in\delta S

such that
S^{\prime}\subseteq S^{\prime\prime}
for
S^{\prime\prime}\in\mathcal{S}
only for
S^{\prime\prime}=S
.
We will see that this guarantees the existence of an appropriate polynomial of degree
d^{*}(H)
.
We have the following.

Lemma 32
.

Let
H
be a graph with
d^{*}(H)+1=c^{*}(H)=\Delta(H)
.
Let
L\subseteq V(H)
,
F=L_{1}\times\ldots\times L_{r}
, and a sequence
(v_{1},\ldots,v_{r})\in X^{r}
be given, where
L_{i}\subseteq V(H)
is an incomparable set for each
i\in[r]
.
Let
S_{0}\in F
be a sequence which has no common neighbor in
L
.
Then
S_{0}
can be forbidden on
(v_{1},\ldots,v_{r})
by a polynomial of degree
d^{*}(H)
with respect to
(F,L)
.

Proof.

Let
S_{0}=(s_{1},\ldots,s_{r})
.
To simplify notation in the proof, we will occasionally treat
S_{0}
and elements
S\in F

as sets rather than sequences, as the construction is largely independent of element order.
Note that if
|S_{0}|<r
, then we can forbid a subsequence of
S_{0}
.
Also, if
r<c^{*}(H)
, then we can forbid
S_{0}
trivially by the polynomial
p(\mathbf{y})=\prod_{i=1}^{r}y_{v_{i},s_{i}}
.
Hence assume
|S_{0}|=r=c^{*}(H)=d^{*}(H)+1
.

For a set
S\in\binom{V(H)}{r}
, we define
\overrightarrow{S}
to be the 0-1 vector indexed by elements of
\binom{V(H)}{d^{*}(H)}
, such that for
S^{\prime}\in\binom{V(H)}{d^{*}(H)}
, we have
\overrightarrow{S}[S^{\prime}]=1
if and only if
S^{\prime}\in\delta S
; in other words,
\overrightarrow{S}
can be seen as the indicator vector of
\delta S
.
We will use the following two facts.

(1.)

For two distinct sets
S_{1},S_{2}\in\binom{V(H)}{r}
, there is at most one
S^{\prime}\in\binom{V(H)}{d^{*}(H)}
such that
\overrightarrow{S_{1}}[S^{\prime}]=\overrightarrow{S_{2}}[S^{\prime}]=1
, as
|\delta S_{1}\cap\delta S_{2}|\leqslant 1
, otherwise the sets cannot be distinct.

(2.)

By
lemma

31
, for every
S_{1}\in\mathcal{S}
, there is
S^{\prime}\in\binom{V(H)}{d^{*}(H)}
such that
\overrightarrow{S_{1}}[S^{\prime}]=1
, and for every other
S_{2}\in\mathcal{S}
, we have
\overrightarrow{S_{2}}[S^{\prime}]=0
.

Defining the polynomial.

Let
\mathcal{S}=\{S\in F\mid|S|=r,S\text{ has a common neighbor in }L\}
.
We will construct a polynomial over GF(2) as a sum of polynomials
p_{S}(\mathbf{y})
from
lemma

25
as

p(\mathbf{y})=\sum_{S\in{\binom{V(H)}{d^{*}(H)}}}p_{S}(\mathbf{y})\cdot\mathcal{X}[S],

where
\mathcal{X}
is a 0-1 vector indexed by the elements of
\binom{V(H)}{d^{*}(H)}
.
We then want
p
to satisfy the following: (i)
p(\mathbf{y})=1
if
\mathbf{y}
is a choice assignment representing
S_{0}
,
and (ii)
p(\mathbf{y})=0
if
\mathbf{y}
is a choice assignment representing some
S\in\mathcal{S}
(or if
\mathbf{y}
uses fewer than
r
distinct colors on
v_{1},\ldots,v_{r}
).

Such a vector
{\mathcal{X}}
exists if there is a solution to the system of equations

\forall S\in\mathcal{S}\quad\sum_{S^{\prime}\in\delta S}\mathcal{X}[S^{\prime}]\equiv_{2}0,

and

\sum_{S^{\prime}\in\delta S_{0}}\mathcal{X}[S^{\prime}]\equiv_{2}1.

Indeed, if this system has a solution, then
p(\mathbf{y})\equiv_{2}1
only if
\mathbf{y}
uses on
v_{1},\ldots,v_{r}
a set of
r
distinct values, which is not included in
\mathcal{S}
, and in particular
p(\mathbf{y})\equiv_{2}1
for the values in
S_{0}
.

Existence of a solution to the system of equations.

So it remains to prove that the system has a solution.
Let us rewrite it in the following form.

\begin{cases}\overrightarrow{S}\cdot\mathcal{X}\equiv_{2}0,&\forall S\in\mathcal{S},\\
\overrightarrow{S_{0}}\cdot\mathcal{X}\equiv_{2}1,\end{cases}

where
\cdot
denotes the scalar product.

For contradiction, assume that the system has no solution.
Then there is a non-empty subset
\mathcal{S^{\prime}}\subseteq\mathcal{S}\cup\{S_{0}\}
such that the corresponding vectors form a linearly dependent set, i.e.,
\sum_{S\in\mathcal{S^{\prime}}}\overrightarrow{S}\equiv_{2}0
(here
0
states for the zero-vector).

Observe that:

(
\star
)

For every
S_{1}\in\mathcal{S^{\prime}}
, and for every
S^{\prime}\in\delta S_{1}
, there is
S_{2}\in\mathcal{S^{\prime}}\setminus\{S_{1}\}
such that
S^{\prime}\in\delta S_{2}
.

Indeed, it must hold that
\sum_{S\in\mathcal{S^{\prime}}}\overrightarrow{S}[S^{\prime}]\equiv_{2}0
, so if
