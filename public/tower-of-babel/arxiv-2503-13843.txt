WebNav: An Intelligent Agent for Voice-Controlled Web Navigation
Trisanth Srinivasan, Santosh Patapati

Abstract
The increasing reliance on web interfaces presents many challenges for visually impaired users, showcasing the need for more advanced assistive technologies. This paper introduces WebNav, a voice-controlled web navigation agent that leverages a ReAct-inspired architecture and generative AI to provide this framework. WebNav comprises of a hierarchical structure: a Digital Navigation Module (DIGNAV) for high-level strategic planning, an Assistant Module for translating abstract commands into executable actions, and an Inference Module for low-level interaction. A key component is a dynamic labeling engine, implemented as a browser extension, that generates real-time labels for interactive elements, creating mapping between voice commands and Document Object Model (DOM) components. Preliminary evaluations show that WebNav outperforms traditional screen readers in response time and task completion accuracy for the visually impaired. Future work will focus on extensive user evaluations, benchmark development, and refining the agent’s adaptive capabilities for real-world deployment.

Web accessibility has been a focus of assitive technology research for a long time. Progress has been made in developing increased accessibility for the visually impaired, but effectively navigating modern, complex web applications remains a challenge. Traditional screen readers are extremely primitive, and do not offer much benefit especially for visually impaired users seeking rapid access to information and online services.

Digital Navigation Module

The voice input and processing subsystem receives user commands via microphone and converts them into text using the Whisper speech recognition model

. This text serves as the initial input for the agent.

The DIGNAV Controller is the reasoning component, implementing a modified ReAct framework and utilizing a Google Generative AI model (‘gemini-2.0-flash-thinking-exp-01-21‘). The controller operates in an iterative ”Reason” and ”Act” cycle. In the ”Reason” phase, it analyzes the user’s goal, the current web page state (from labeled and unlabeled screenshots), and the history of previous interactions. Based on this analysis, the controller transitions to the ”Act” phase, outputting a high-level command like ”Click [5]” or ”Type [3] search query.” The ReAct framework allows the controller to adapt its reasoning and actions dynamically based on the evolving web page context and the outcomes of previous actions.

The Assistant module refines the strategic commands from the DIGNAV Controller, transforming them into concrete, executable actions. This module, also powered by a Gemini model, acts as a tactical planner. It takes the high-level intent from the Controller and generates a JSON payload specifying the function to be executed (e.g., ”Click”, ”Type”) and the necessary parameters (e.g., element number, text).

Dynamic Labeling Engine

The dynamic labeling engine is a component that provides WebNav with a representation of the web page, enabling interaction. Implemented as a browser extension, it dynamically assigns unique labels to interactive elements on the page.

When activated, the engine scans the web page to identify interactive elements. It checks their visibility and size to ensure only relevant elements are considered. Each identified element receives a visual overlay with a numerical label, making it easy to reference. These overlays adjust dynamically as the page changes, thanks to a monitoring system. A mapping system links each number to its corresponding element, allowing user interactions to be translated into actions. The extension’s core functionality is managed through its underlying Chrome architecture, ensuring seamless deployment and activation.

The Inference module executes the actions planned by the DIGNAV Controller and refined by the Assistant. Using ‘pyautogui‘, it translates JSON commands into actions, simulating keyboard and mouse inputs. For example, a JSON command to ”Click” element ”7” is translated into ‘pyautogui‘ commands that trigger a click. The Inference module also provides additional functionalities, such as text-to-speech (for auditory feedback), note-taking, summarization, and translation, all powered by the Gemini model. These functions enhance the agent’s ability to process and present web content.

III-B

Central Control and Interaction Pipeline

The ‘main.py‘ script orchestrates the WebNav system, managing the interaction between modules and ensuring execution of user commands. The process begins when a user provides input via voice or text, which is forwarded to the DIGNAV module for processing. The DIGNAV Controller first enters the ”Reason” phase, where it analyzes the current state of the web page and the user’s goal. It then transitions to the ”Act” phase, generating a high-level command that outlines the necessary actions.

This command is passed to the Assistant module, which refines it into a structured JSON payload containing precise, executable steps. The Inference module then interprets and executes these steps, interacting directly with the web interface by clicking buttons, filling forms, or navigating through the page as required.

Throughout this process, the system continuously iterates by reassessing the web page state and refining its actions based on new inputs or changes in the environment. The loop continues until the Controller emits an ”END” signal, indicating task completion, or an error threshold is reached, prompting termination. Task performance metrics are automatically logged for analysis and future improvements.

IV
Methodology

WebNav’s development follows an iterative design process aimed at refining its web navigation capabilities. The methodology includes component development and unit testing, where individual modules (DIGNAV, Assistant, Inference) are built and tested for functional correctness and adherence to specifications. Integration testing ensures seamless interaction between these modules, focusing on the ReAct cycle, Controller-Assistant handoff, and execution of actions. System-level testing evaluates WebNav’s performance across diverse web navigation tasks, measuring efficiency, adaptability, and robustness. Additionally, a benchmark testing framework is developed to quantitatively assess performance through predefined tasks categorized by complexity, with automatic logging of task metrics. Including detailed latency measurements, analyzing processing times within the DIGNAV Controller (Reason phase), Assistant (Planning phase), and Inference module (Action phase), to optimize responsiveness.

V
Experimental Results

Initial testing focused on verifying functional correctness and integrated operation. These tests confirmed the integrity of voice input processing, the DIGNAV Controller’s ReAct cycle, the Assistant module’s command refinement, the dynamic labeling engine, and the Inference module’s action execution. Preliminary results indicate that WebNav handles basic web navigation tasks effectively, demonstrating responsiveness and adaptability in simple scenarios. These findings provide a foundation for more rigorous evaluations.

VI
Discussion

Initial testing and architectural validation support WebNav’s viability as an intelligent, voice-controlled web navigation agent. The integration of the ReAct framework, dynamic labeling, and generative AI models demonstrates the potential for creating more adaptable and efficient assistive technologies. WebNav’s modular design facilitates future enhancements and targeted improvements, allowing for iterative refinement of its capabilities. This is particularly important for incorporating advancements in areas such as reasoning, natural language processing, and AI-driven interaction.

VII
Future Work

Future research on WebNav will focus on enhancing its intelligence and conducting user-centered evaluations. Extensive real-world user studies will assess WebNav’s usability and effectiveness in practical scenarios, focusing on user satisfaction and the perceived efficiency of voice-controlled interactions. The ReAct-based DIGNAV Controller will be refined to improve its planning and decision-making capabilities, incorporating user-specific preferences, learning from interactions, and handling ambiguous or complex goals. The dynamic labeling engine will be improved to provide more contextually relevant representations of web pages, exploring semantic labeling and prioritizing labels based on predicted user intent. Personalized navigation profiles will allow WebNav to adapt its interaction style to individual user preferences. Error handling will be made more robust, enabling WebNav to detect, recover from, and learn from errors with the integration of user feedback. Lastly, the quantitative evaluation framework will be developed further to include metrics measuring efficiency, adaptability, and overall performance, guiding future improvements.

VIII
Conclusion

WebNav represents a significant step towards creating voice-controlled web navigation agents that provide a more efficient and adaptable online experience for visually impaired users. By leveraging the ReAct framework, dynamic labeling, and generative AI, WebNav offers a promising approach to web accessibility. Its modular architecture and planned rigorous evaluations position it as a strong platform for further research and development in assistive technology. Future iterations, guided by user evaluations and advancements in AI, aim to further refine WebNav’s capabilities, ultimately creating a web that is more accessible and inclusive for all.
