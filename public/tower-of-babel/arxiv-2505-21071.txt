Dual Hierarchical Least-Squares Programming with Equality Constraints
Kai Pfeiffer

Abstract
Hierarchical least-squares programming (HLSP) is an important tool in optimization as it enables the stacking of any number of priority levels in order to reflect complex constraint relationships, for example in physical systems like robots. Existing solvers typically address the primal formulation of HLSP’s, which is computationally efficient due to sequential treatment of the priority levels. This way, already identified active constraints can be eliminated after each priority level, leading to smaller problems as the solver progresses through the hierarchy. However, this sequential progression makes the solvers discontinuous and therefore not differentiable. This prevents the incorporation of HLSP’s as neural network neurons, or solving HLSP’s in a distributed fashion. In this work, an efficient solver based on the dual formulation of HLSP’s with equality constraints ( D-HLSP-E ) is developed. D-HLSP-E is a convex and differentiable quadratically constrained least-squares program (QCLSP), which is solved by an Alternating Direction Method of Multipliers (ADMM). By introducing appropriate operator splitting, primal-dual variables, which link each priority level with all their respective higher priority levels, can be eliminated from the main computation step of computing a matrix factorization. The proposed solver D-HADM is about one magnitude faster than a comparable D-HLSP-E solver based on the interior-point method (D-HIPM), where the primal-dual variables enter the computational complexity in a cubic fashion.



1
Introduction

Hierarchical least-squares programming (HLSP) has seen many applications, for example in compliant control of humanoid robots
[
16
]
, in control of manipulators with obstacle avoidance in space stations
[
34
]
or for robot assisted surgeries
[
6
]
, in robot design optimization
[
13
]
, or in control of robot swarms for object transportation
[
19
]
. The ability to prioritize constraints by any number of priority levels accommodates simple formulation of complex constraint relationships, since constraints do not need to be weighted against each other, for example in complex scenarios with many constraints like in humanoid stair climbing
[
33
]
. Efficient solvers based on the primal formulation of HLSP’s have been proposed, which solve a sequence of least-squares programs (LSP) from highest to lowest priority level
[
9
]
. This is computationally advantageous since after convergence of each priority level, active constraints and occupied variables can be eliminated by nullspace projections and do not further need to be considered on lower hierarchy levels. However, the overall solution of the HLSP is not differentiable, as it is the sum of independent contributions from the sequentially solved LSP’s. The work in
[
30
]
presents a dual formulation of hierarchical linear programs (HLP), which results in a single linear program with linear constraints. However, an efficient solver has not been proposed. Critically, the dual HLP grows with each priority level in the number of primal variables, since the dual variables from previous levels need to be considered as primal ones on subsequent levels.

Given these restrictions on HLSP, this work presents several advances for HLSP’s with equality constraints (HLSP-E):

•

The dual formulation of HLSP-E’s as a quadratically constrained least-squares program (QCLSP, a sub-form of quadratically constrained quadratic programs / QCQP; see Sec.
4
) is derived, which can be solved with methods from convex optimization. This would allow to solve HLSP-E’s in a distributed fashion
[
5
]
, for example for distributed prioritized robot control.

•

The gradient of the dual formulation of the HLSP-E is formulated using techniques from matrix differential calculus (see App.
A
). This lays the foundation for future applications like inclusion of HLSP-E’s as neural network neurons for representing hierarchical relationships in the training data.

•

An efficient solver for the dual HLSP-E based on the Alternating Direction Method of Multipliers (ADMM) is developed (Sec.
5
). Appropriate operator splitting ensures that primal-dual variables do not need to be considered in demanding matrix factorizations. It is demonstrated how such an efficient formulation cannot be immediately found for an interior-point method (IPM) based solver (see App.
B
).

This article is structured as follows. First, Sec.
2
gives an overview of existing literature on hierarchical programming.
Section
3
deepens this insight by introducing the primal HLSP (
P-HLSP
). In contrast, Sec.
4
formulates the dual HLSP for equality constraints
D-HLSP-E
, which is a convex QCLSP. Such programs can be solved by methods from convex optimization, where this work introduces exemplary solvers both based on the ADMM (Sec.
5
) and the IPM (App.
B
). Section
6
categorizes these solvers with respect to existing solvers in hierarchical programming with linear constraints.
Evaluation on randomized and linear deficient test programs takes place in Sec.
7
. Section
8
concludes this article with a future outlook and reiterates on the advantages and disadvantages of dual HLSP.

2
Related work

HLSP can be broadly categorized as lexicographic multi-objective optimization (LMOO), which has its origin in
[
31
]
. This work establishes appropriate weights which transform a hierarchy of linear objectives subject to a set of linear equality constraints into an equivalently weighted optimization problem.
Inequality constraints are limited to non-negativity constraints on the variable vector.
The authors in
[
17
]
are the first to establish HLSP in its current form, which is characterized by the ability to handle feasible and infeasible inequality constraints on any priority level. This is enabled by slack variables which relax any infeasibility with respect to the
\ell_{2}
-norm. Each priority level is solved in sequence by identifying the optimal active set by the active-set method (ASM). The method is computationally unfavorable since on each priority level an increasingly larger problem needs to be solved since all active and inactive constraints from previous levels need to be considered.
The authors in
[
9
]
avoid this by projecting the constraints of the remaining priority levels into a basis of nullspace of the active constraints of previous priority levels. This effectively eliminates the active contraints, and with the right choice of nullspace basis also eliminates variables which have already been occupied in order to reach the optimal point of previous priority levels. The ASM is very efficient for problems with small changes of the active-set, or when the problem is well-conditioned, for example in parametric programs like robot control and planning where the active-set typically evolves slowly
[
21
]
. Here, the solver can be warm-started and the solver converges after a few iterations, which involve solving equality constrained problem representing the active constraints of the current priority level. However, when the problem is badly conditioned, and large changes of the active set occur, the ASM can struggle to converge, for example due to phenomenons like cycling
[
12
]
. Instead, the work in
[
27
]
proposes a HLSP solver based on the interior-point method (IPM), which is more reliable than the ASM in such situations. The solver cannot be warm-started and each iteration is more costly than those of the ASM since all inactive inequality constraints need to be considered.
In contrast, the solver in
[
28
]
is based on the ADMM, which can be warm-started and can handle ill-posed problems due to proximal regularization terms
[
24
]
. The ADMM requires fewer expensive matrix factorizations. This is more suitable for embedded applications where the system may not be equipped with enough computational power and matrix factorizations can be computed offline
[
7
]
.

The previously mentioned works consider the primal formulation of hierarchical programs, while the dual has rarely been considered. One work to do so is presented in
[
30
]
, where the authors formulate the dual of a HLP. The dual is again a constrained linear program, where all priority levels can be solved at once, unlike solvers considering the primal formulation which solve the program in sequence. However, the dual HLP increases in the number of primal variables, which now also include the dual variables of each priority level of the primal problem (from here on these variables are referred to as
primal-dual
variables, as they are dual variables in the primal problem, but primal variables in the dual problem). Furthermore, the gradient of the dual HLP has not been formulated, which is necessary if HLP’s were to be integrated as neurons in neural networks. The inclusion of convex optimization programs like quadratic programs (QP) in neural networks has been demonstrated to benefit the representation of more complex constraint relationships in the training data
[
1
]
.

Hierarchical programming is not limited to HLP’s or HLSP’s: the work in
[
25
]
addresses hierarchical sparse quadratic programs (HSQP) where the objective function is formulated with respect to the
\ell_{0}
-norm. This way, hierarchical decision-making problems can be solved, for example in goal selection for humanoid robots.

HLSP’s and HSQP’s are typically solved as sub-problems of either non-linear hierarchical least-squares or sparse quadratic programs (N-HLSP, or N-HSQP) in sequential programming type non-linear optimization methods. Examples include trust-region methods
[
26
]
with fixed trust-region radius, and hierarchical adaptations
[
29
]
of filter methods for sequential quadratic programming (SQP)
[
10
]
.
Unlike previous methods from LMOO for non-linear optimization
[
15
]
, non-linear feasible and infeasible inequality constraints are handled seamlessly by the slack formulation.
Examples of applications for such non-linear problems are robot real-time control
[
26
]
and prioritized robot optimal control
[
29
]
.

Background on Hierarchical Least-Squares Programming

This work addresses HLSP as LMOO’s (
\lexmin

\displaystyle\lexmin_{{x},{v}_{{\mathbb{C}}_{\cup p}}}

\displaystyle\qquad\frac{1}{2}\|{v}_{{\mathbb{C}}_{1}}\|^{2}_{\ell=2},\dots,\frac{1}{2}\|{v}_{{\mathbb{C}}_{p}}\|^{2}_{\ell=2},

(Lex-HLSP)

s.t.

\displaystyle\qquad A_{{\mathbb{C}}_{\cup p}}{x}-b_{{\mathbb{C}}_{\cup p}}\leqq{v}_{{\mathbb{C}}_{\cup p}}

x\in\mathbb{R}^{n_{x}}
are the primal variables. On each level
l=1,\dots,p
, the primal slack

needs to be minimized with respect to the
\ell_{2}
-norm while the optimal slacks of previous levels

needs to be maintained.
The slacks relax the linear constraints

of each level

, which are comprised of the set of equality constraints
{\mathbb{E}}_{l}
, and the set of inequality constraints
{\mathbb{I}}_{l}
. The symbol
\leqq
summarily represents both these constraint sets. The linear constraints
{\mathbb{C}}_{l}
are represented by the matrices
A_{{\mathbb{C}}_{l}}\in\mathbb{R}^{m_{{\mathbb{C}}_{l}}\times n_{x}}
and the vectors
b_{{\mathbb{C}}_{l}}\in\mathbb{R}^{m_{{\mathbb{C}}_{l}}}
. The symbol

indicates the set of integers representing the priority levels from level 1 to

is then the combined set
{\mathbb{C}}_{\cup p}\coloneqq\{{\mathbb{C}}_{1},\dots,{\mathbb{C}}_{p}\}
.

To this date, no method has been conceptualized which can solve all priority levels of
Lex-HLSP
at once. Instead, the priority levels are treated in sequence from highest to lowest priority level, resulting in the following primal (P-) HLSP

\displaystyle\mini_{x,{v}_{\mathbb{C}_{l}}}

\displaystyle\qquad\frac{1}{2}\|{v}_{\mathbb{C}_{l}}\|^{2}_{2}\qquad l=1,\dots,p

(P-HLSP)

s.t.

\displaystyle\qquad A_{\mathbb{C}_{l}}x-b_{\mathbb{C}_{l}}\leqq{v}_{\mathbb{C}_{l}}

\displaystyle\qquad A_{{\mathcal{A}}_{\cup l-1}}x-b_{{\mathcal{A}}_{\cup l-1}}={v}_{{\mathcal{A}}_{\cup l-1}}^{*}

\displaystyle\qquad A_{{\mathcal{I}}_{\cup l-1}}x-b_{{\mathcal{I}}_{\cup l-1}}\leq 0

Each level
l=1,\dots,p
is a feasible LSP. Either, the set of linear constraints
{\mathbb{C}}_{l}
are feasible and an optimal feasible point
v_{{\mathbb{C}}_{l}}^{*}\leqq 0
is identified. Otherwise, the linear constraints
{\mathbb{C}}_{l}
are infeasible, and are relaxed at an optimal infeasible point
|v_{{\mathbb{C}}_{l}}^{*}|>0
in the least-squares sense. At the same time, the optimal feasible or infeasible points
|v_{{\mathcal{A}}_{\cup l-1}}^{*}|\geq 0
of higher priority levels
1
to
l-1
need to be maintained. The active set
\mathcal{A}_{\cup l-1}
contains all equality constraints
{\mathbb{E}}_{\cup l-1}
, and violated inequality constraints in
{\mathbb{I}}_{\cup l-1}
. The remaining inequality constraints from higher priority levels, which were feasible at convergence of the LSP’s from levels 1 to
l-1
, are summarized in
\mathcal{I}_{\cup l-1}
and need to be respected.

Such a sequential treatment of the hierarchy is very efficient, since after convergence of each priority level
l
, identified active constraints from this level can be eliminated from the remaining priority levels. The approach in
[
9
]
proposed to project the remaining levels’ LSP’s into a basis of nullspace

of the active constraints of lower priority levels
\mathcal{A}_{\cup l-1}
with
A_{\mathcal{A}_{\cup l-1}}N_{l-1}=0
and

. An appropriate choice of nullspace basis

carries the additional advantage that the LSP’s become progressively smaller with a reduced number of remaining projected variables
n_{x}^{r,l}\leq n_{x}
on each level
l=2,\dots,p
. The rank of the active constraint matrix
A_{\mathcal{A}_{\cup l-1}}
is
n_{x}-n_{x}^{r,l}
. The projected primal variable on each level is
x_{l}\in\mathbb{R}^{n_{x}^{r,l}}=N_{l}x
. Furthermore, the projection eliminates the primal-dual Lagrange multipliers
\lambda_{l,\cup l-1}\in\mathbb{R}^{n_{l}^{dual}}
from each level
l
’s LSP, which relate the LSP to linear constraints
{\mathbb{C}}_{\cup l-1}
from previous levels
1
to
l-1
.

n_{l}^{dual}
is the sum of number of constraints of priority levels 1 to
l-1
:

\displaystyle n_{l}^{dual}=\sum_{k=1}^{l-1}m_{{\mathbb{C}}_{l}}=

The overall set of primal-dual variables is defined as
[
9
]

\displaystyle\Lambda_{p-1}=\begin{bmatrix}0&\lambda_{2,{\mathbb{C}}_{1}}&\dots&\lambda_{p-1,{\mathbb{C}}_{1}}\\
0&0&\dots&\lambda_{p-1,{\mathbb{C}}_{2}}\\
\vdots&\vdots&\ddots&\vdots\\
0&0&\dots&\lambda_{p-1,{\mathbb{C}}_{p-2}}\\
\end{bmatrix}\in\mathbb{R}^{n_{p-1}^{dual}\times p-1}

(primal-dual)

The non-zero entries of each column
l=2,\dots,p-1
of
\Lambda_{p-1}
correspond to
\lambda_{l,\cup l-1}
. The matrix
\Lambda_{p-1}
omits the Lagrange multipliers
\lambda_{l,l}
. They correspond to the slack variables
\lambda_{l,{\mathbb{C}}_{l}}=v_{{\mathbb{C}}_{l}}
and are simultaneously both primal and dual variables
[
9
]
.

The primal and primal-dual solutions

and

obtained from solving the primal formulation of
P-HLSP
are not differentiable with respect to the HLSP parameters

and

. This is because it is not possible to formulate a Lagrangian function of all priority levels’ LSP’s at once. This prevents the application to distributed optimization or the usage of HLSP’s as neurons in neural networks. Here, we propose a continuous and differentiable dual formulation of HLSP.

(colored in purple). Such a bilinear constraint could for example be iteratively approximated by the convex-concave procedure as a difference of convex functions. However, only local minima may be obtained. In this work, the focus is shifted to equality only constrained HLSP’s, such that both (

Another non-convexity is introduced by the duality constraint (

(in purple,

,
k=1,\dots,l-1

favors strong duality (strict equality in (

With the above simplifications,

becomes a convex QCLSP as all colored terms are ignored.
It can be confirmed that the Lagrangian given in (

Theorem 1
.

Strong duality holds for the equality constrained HLSP (

Proof.

The proof proceeds by induction by first establishing strong duality of the first priority level

\displaystyle\qquad A_{\mathbb{E}_{1}}{x}-b_{\mathbb{E}_{1}}={v}_{\mathbb{E}_{1}}

\displaystyle\qquad A_{\mathbb{E}_{1}}{x}-b_{\mathbb{E}_{1}}={v}_{\mathbb{E}_{1}}

5.4
Partial preconditioning for computational efficiency

The number of iterations
i
in first-order methods depends on the conditioning of the problem at hand. A popular since computationally reasonable approach for improving the conditioning of optimization problems is Ruiz matrix equilibration
[
18
]
. Here, matrix rows and columns are iteratively scaled until they are normalized. The authors in
[
32
]
suggest to scale the KKT system of (
26
), which is scaled as follows:

\displaystyle\begin{bmatrix}\overline{H}&\overline{B}^{T}\\
\overline{B}&0\end{bmatrix}=\begin{bmatrix}L&0\\
0&V\end{bmatrix}\begin{bmatrix}P&B^{T}\\
B&0\end{bmatrix}\begin{bmatrix}L&0\\

with

\displaystyle\overline{H}=LHL

\displaystyle\overline{B}=VBL

are scaled as follows

\displaystyle\overline{q}=L^{-1}q

(51)

\displaystyle\overline{\bullet}=V^{-1}\bullet

(52)

\displaystyle\overline{c}=Vc

(53)

\displaystyle\overline{\mathcal{C}}=\{Vs|s\in\mathcal{C}\}

(54)

Overlined matrices and variables are the equilibrated equivalents of the original quantities.

L
and
V
are subdivided into components corresponding to their respective variable or constraint sets

and
\{\mu,\eta,\phi,\nu\}
, respectively:

\displaystyle L

\displaystyle\coloneqq\begin{bmatrix}L_{x}^{T}\in\mathbb{R}^{n_{x}\times n_{x}}&L_{v}^{T}\in\mathbb{R}^{m_{\cup p}\times m_{\cup p}}&L_{\nu}^{T}\in\mathbb{R}^{\sum_{l=2}^{p-1}n_{l}^{dual}\times\sum_{l=2}^{p-1}n_{l}^{dual}}\end{bmatrix}^{T}

\displaystyle V

\displaystyle\coloneqq\begin{bmatrix}V_{\mu}^{T}\in\mathbb{R}^{m_{\cup p}\times m_{\cup p}}&V_{\eta}^{T}\in\mathbb{R}^{(p-1)n_{x}\times(p-1)n_{x}}&V_{\phi}^{T}\in\mathbb{R}^{m_{\cup p-1}\times m_{\cup p-1}}&V_{\nu}^{T}\in\mathbb{R}^{\sum_{l=2}^{p-1}n_{l}^{dual}\times\sum_{l=2}^{p-1}n_{l}^{dual}}\end{bmatrix}^{T}

Ruiz equilibraton could be applied to the full KKT system as is depicted in (

). However, this would significantly increase the computational burden of the proposed solver due to two issues.

For one, the diagonal blocks corresponding to the primal-dual variables possibly consist of differently equilibrated matrices

\displaystyle\overline{A}_{{\mathbb{E}}_{\cup p}}=V_{\mu}{A}_{{\mathbb{E}}_{\cup p}}L_{x}

The same equilibration is applied to the constraint matrices corresponding to the dual constraints by choosing

\displaystyle L_{v}

\displaystyle=I

\displaystyle L_{\nu}

\displaystyle=\begin{bmatrix}V_{\mu}(1:m_{\cup 1},1:m_{\cup 1})^{T}&\dots&V_{\mu}(1:m_{\cup p-2},1:m_{\cup p-2})^{T}\end{bmatrix}^{T}

\displaystyle V_{\eta}

\displaystyle=\begin{bmatrix}L_{x}^{T}&\dots&L_{x}\end{bmatrix}^{T}

\displaystyle V_{\phi}

\displaystyle=L_{v}^{-1}

\displaystyle V_{\nu,l}

\displaystyle=L_{\nu}

extracts a sub-matrix from row

8
Conclusion

In this work, an ADMM solver has been developed which solves the dual form of HLSP’s with equality constraints. Some computational efficiency is achieved by substitution of primal-dual variables which do not need to be considered in expensive matrix factorizations. The solver is shown to be computationally more efficient than a dual HLSP solver based on the IPM. However, the solver is significantly slower than conventional primal HLSP solvers for example based on the IPM.

Despite their computational challenges, dual HLSP solvers offer distinct advantages with respect to primal HLSP solvers. They are continuous and differentiable, which builds the foundation for a broader application of hierarchical programming with linear constraints in future work. Computation in a distributed fashion could contribute to more refined hierarchical control principles in robot swarm control. Inclusion of HLSP’s as neurons in neural networks can help learning hierarchical patterns in the training data. Here, it needs to be investigated how the gradient computation in Sec.
A
can be designed efficiently. Especially, it remains to be seen whether the linear system (
61
) can be solved efficiently, for example by re-using values from the ADMM or IPM based
D-HLSP-E
solvers.

The proposed dual HLSP solvers based on convex formulation is not able to consider inequality constraints due to the presence of non-convex complementary constraints. Future research is dedicated to identifying convex approximations to these constraints for computationally efficient handling of inequality constraints.
