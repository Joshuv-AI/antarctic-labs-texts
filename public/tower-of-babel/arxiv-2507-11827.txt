Universal Synthesis of Differentiably Tunable Numerical Abstract Transformers
Shaurya Gomber, Debangshu Banerjee, Gagandeep Singh

Abstract
. Numerical abstract interpretation is a widely used framework for the static analysis of numerical programs. However, existing numerical abstract interpreters rely on hand-crafted, instruction-specific transformers tailored to each domain, with no general algorithm for handling common operations across domains. This limits extensibility, prevents precise compositional reasoning over instruction sequences, and forces all downstream tasks to use the same fixed transformer regardless of their precision, efficiency, or task-specific requirements. To address these limitations, we propose a universal transformer synthesis algorithm that constructs a parametric family of sound abstract transformers for any given polyhedral numerical domain and a concrete operator from the class of Quadratic-Bounded Guarded Operators (QGO) , which includes both individual instructions and structured sequences. Each instantiation in this family is sound by construction, enabling downstream analyses to adapt the transformer to their particular needs. The space of transformers is differentiable but complex. To efficiently explore this space of transformers, we introduce the Adaptive Gradient Guidance (AGG) procedure, a gradient-guided search strategy that steers the search process based on downstream analysis objectives and runtime constraints. We implement these ideas in the USTAD framework and evaluate their effectiveness across three numerical abstract domains: Zones, Octagons, and Polyhedra. Our results demonstrate that the universal synthesis algorithm successfully constructs sound families of transformers across domains, and that USTAD achieves significant, tunable precision gains over baselines by leveraging compositional reasoning and efficient gradient-guided traversal of the transformer space.



1.
Introduction

Abstract interpretation
(
Cousot and Cousot 1977a
)
is a widely used framework for static program analysis, which works by soundly approximating the program’s
concrete
semantics with an alternate domain, known as the
abstract
domain. Over the years, various domains have been developed to capture different properties, including heap structure
(
Sagiv et al. 1999
;
Logozzo and Fähndrich 2008
)
, control-flow behavior
(
Beyer 2016
)
, and numeric relationships
(
Cousot and Halbwachs 1978a
;
Laviron and Logozzo 2009
)
. In this work, we focus on numerical domains, which are essential for reasoning about variable ranges
(
Singh et al. 2017b
)
, arithmetic updates
(
Laviron and Logozzo 2009
)
, and control-flow conditions
(
Beyer 2016
)
in real-world programs. These domains vary in expressiveness and efficiency, and selecting the right domain involves fundamental trade-offs between precision and scalability.

Ideally, highly expressive domains such as Polyhedra
(
Cousot and Halbwachs 1978b
)
yield the most precise program analyses. However, as programs scale, these domains become inefficient due to the exponential complexity of their operations. For better scalability, many analyzers use Template Constraint Matrix (TCM) domains
(
Sankaranarayanan et al. 2005
)
like Octagons
(
Mine 2001
)
, Zones
(
Miné 2002
)
, etc., which restrict abstract elements to fixed constraint directions. This enables efficient computation but sacrifices expressiveness. As a result, even simple and commonly occurring operations such as affine assignments
(v_{j}:=\sum c_{i}\cdot v_{i}+b)
cannot be handled exactly by such domains if these are not expressible in that domain. In practice, the imprecision is often worse: most existing libraries fail to even compute the best abstract transformer available within the domain, since this requires solving multiple linear programs, with the number of solver calls growing super-linearly with the number of variables. Moreover, while domains like Polyhedra can represent linear assignments exactly, they cannot precisely capture quadratic assignments
(v_{j}:=\sum_{i\leq k}a_{ik}v_{i}v_{k}+\sum_{i}b_{i}v_{i}+c)
, which require non-linear solvers that are slower and rely on heuristics that do not guarantee soundness
(
Gurobi Support 2024
)
. To address this, libraries like ELINA
(
Singh et al. 2017b
)
, APRON
(
Jeannet and Miné 2009
)
, and PPL
(
Bagnara et al. 2008
)
resort to carefully engineered, hand-crafted over-approximation heuristics that are provably sound and scale efficiently. But this introduces several key limitations:

(1)

No General Algorithm across Domains or Instructions:
Existing libraries implement specialized, hard-coded routines for each domain–instruction pair
\{\mathcal{D},\mathcal{I}\}
(e.g., affine assignment on Octagons). While this yields efficient implementations, it severely limits extensibility and generality. Supporting even a slightly different instruction requires designing a new algorithm for that, and then implementing it for all domains. Ideally, one would want a unified algorithm to handle common instructions, such as affine assignments, across structurally similar domains like Intervals, Zones, and Octagons, all of which represent abstract states as finite conjunctions of linear inequalities and fall within the class of Polyhedral numerical domains.

(2)

Lack of Compositional Reasoning Across Sequences:
Since there is no general algorithm for handling instructions across domains, there is also no principled way to handle sequences of instructions. As a result, existing libraries define separate transformers for each instruction in each domain, treating statements in isolation. This is limiting, as the precision of abstract interpretation is
non-compositional
: analyzing a fragment instruction-by-instruction and then composing the results is generally less precise than analyzing the entire fragment at once. Supporting such sequence-level reasoning would, in principle, be equivalent to developing and implementing a distinct transformer for every possible sequence of length
\ell
over
S
instructions and
D
domains, yielding
D\cdot S^{\ell}
combinations, which is clearly infeasible to construct or maintain. This can only be enabled by a general algorithm that handles both individual instructions and instruction sequences in a uniform way.

(3)

Fixed Imprecision and Lack of Tunability:
To ensure efficiency, current libraries resort to sound but imprecise heuristics, such as interval concretization or ad hoc, case-specific abstractions, that significantly over-approximate program behavior. This loss of precision leads to weaker invariants, limiting the utility of the analysis for downstream tasks. In practice, this results in a fixed transformer that prioritizes scalability over precision, regardless of the task at hand. However, different analysis scenarios have different needs: lightweight runtime checkers
(
Logozzo and Fähndrich 2008
)
must operate under tight time budgets, while static analyzers for safety-critical systems
(
Cousot et al. 2005
)
may tolerate longer runtimes in exchange for stronger guarantees. Between the most-efficient over-approximation and the theoretically optimal, most-precise transformer (as defined in
(
Cousot and Cousot 1977a
)
), which is often too costly to compute at scale, lies a rich spectrum of sound transformers with varying levels of precision. However, current libraries offer no mechanism to navigate this trade-off, producing the same fixed, imprecise result regardless of the task’s precision or efficiency requirements. This calls for a principled way to capture families of sound transformers that could allow analyses to span the precision-efficiency spectrum as needed.

Universal Transformer Synthesis Algorithm.

To overcome the challenges discussed above, we present a novel universal transformer synthesis algorithm that, given any polyhedral numerical abstract domain
\mathcal{D}
and a concrete operator
\mathsf{op}
, which may be a single instruction or a sequence drawn from a well-defined class, automatically constructs a parametric family of sound abstract transformers. This algorithm is domain-agnostic and applies uniformly across a broad class of operators, including affine, quadratic, and guarded updates, as well as structured sequences of such updates. In particular, we target the class of Quadratic-Bounded Guarded Operators (QGO), formalized in Section
4
. The synthesized family compactly represents the space of sound transformer outputs parameterized by tunable coefficients, and every parameter instantiation yields a sound transformer by construction. This formulation unifies the transformer generation process across domains and operator types, and allows downstream analyses to select transformers that best match their precision–efficiency requirements.

Gradient-Guided Traversal of Transformers Space.

We also propose an efficient strategy for traversing the synthesized space of transformers (which is differentiable by construction) using a novel
Adaptive Gradient Guidance (AGG)
procedure. This traversal allows downstream tasks to specify both a
search objective

\mathcal{J}
, which is a score function that evaluates the quality of a transformer for the task, and a
runtime budget

\mathcal{R}
, expressed as the number of epochs. At each epoch, AGG uses the gradient of
\mathcal{J}
to steer the search toward parameter settings that yield higher-quality, task-aligned transformers. This ensures continual progress over time, with each step improving the output according to the objective. For instance, when the score function
\mathcal{J}
is provided to reflect more precision, the search iteratively moves towards more precise transformers. This gradient-guided traversal thus enables fine-grained control over the precision-efficiency trade-off, while also supporting more general downstream goals beyond precision. By enabling systematic and scalable exploration of the parametric space, the gradient-guided traversal effectively turns our synthesized family of abstract transformers into a practical algorithm that adapts to downstream needs.

.

USTAD
takes a numerical domain and an instruction sequence, and uses our synthesis algorithm to generate a parametric family of sound transformers for that sequence. It then uses this family of transformers to compute a family of sound outputs for the input abstract element, and applies a gradient-guided search, driven by user-specified parameters, to select a suitable output during analysis.

USTAD
framework.
We implement the ideas discussed above in the
USTAD
framework (Fig.
1
), which performs abstract interpretation using parametric families of sound transformers synthesized by our universal algorithm. The framework supports general programs by applying our synthesized transformers to supported operators and falling back to baseline transformers (e.g., from
ELINA
) for the rest. Additionally, it identifies and merges sequences of instructions whose overall effect lies within the QGO class, allowing the framework to analyze such blocks jointly using a single synthesized transformer. Users can specify parameters such as the objective score
\mathcal{J}
, step size
\eta
, number of epochs
\mathcal{R}
, and others to control how the traversal algorithm selects suitable transformers from the parametric family during analysis.

Main Contributions
:

We present a universal transformer synthesis algorithm that, given a polyhedral numerical abstract domain and an operator from the defined class of Quadratic-Bounded Guarded Operators (QGO), which also covers instruction sequences, automatically constructs a parametric family of sound abstract transformers (Section

).

•

We propose the Adaptive Gradient Guidance (AGG) procedure, which takes a search objective
\mathcal{J}
and runtime budget
\mathcal{R}
as input, and efficiently navigates the transformer space using gradient signals from
\mathcal{J}
to guide the search toward task-aligned transformers (Section
4.2
).

USTAD
framework (Section
5
) and evaluate it across three numerical domains: Zones, Octagons, and Polyhedra. Our results (Section

) show that

constructs sound transformer families across domains and achieves significant, tunable precision gains over baselines through compositional reasoning and gradient-guided exploration.

Background

This section provides the necessary background and notation used in this paper.

Abstract Interpretation & Abstract Domains.

Abstract interpretation
(
Cousot and Cousot 1977a
)
works by over-approximating the behavior of a system (for e.g., a program) represented by a
Concrete Domain
, using an alternate domain known as the
Abstract Domain
. The concrete domain, denoted by
(\mathcal{C},\subseteq)
, consists of a set
\mathcal{C}
of concrete elements that are partially ordered by the relation
\subseteq
. An abstract domain, denoted by
(\mathcal{A},\sqsubseteq)
, consists of a set
\mathcal{A}
of abstract elements that are partially ordered by the relation
\sqsubseteq
, and are used to
represent
elements in the concrete domain. For example, in program analysis, a
state
is defined as a valuation over the program variables
\mathcal{V}
. The concrete domain
\mathcal{C}
is the powerset of all possible states, i.e.,
\mathcal{C}=\mathcal{P}(\mathit{States})
, and is ordered by subset inclusion
\subseteq
. Each element
\mathtt{c}\in\mathcal{C}
represents a set of possible program states. Abstract domains, such as Intervals, Zones, or Polyhedra, define a finite representation of such sets and enable efficient analysis by over-approximating elements of
\mathcal{C}
.

Abstraction and Concretization Functions.
The concrete and abstract domains are connected by two functions. The
concretization
function
\gamma:\mathcal{A}\to\mathcal{C}
is monotonic and maps each abstract element to the set of concrete elements it represents. The
abstraction
function
\alpha:\mathcal{C}\to\mathcal{A}
maps a concrete element to an abstract element. To ensure soundness of the analysis, the abstraction function
\alpha
must be
sound
, meaning it over-approximates the corresponding concrete element.

Definition 2.0 (Soundness of Abstraction Function).

The abstraction function
\alpha:\mathcal{C}\to\mathcal{A}
is sound iff for all concrete elements
\mathtt{c}\in\mathcal{C}
, the inclusion relation
\mathtt{c}\in\gamma(\alpha(\mathtt{c}))
holds.

Definition 2.0 (Precision of Abstract Elements).

An abstract element
\mathtt{a}_{1}\in\mathcal{A}
is
more precise
than another element
\mathtt{a}_{2}\in\mathcal{A}
if
\gamma(\mathtt{a}_{1})\subseteq\gamma(\mathtt{a}_{2})
.

Abstract Transformers.
The concrete domain includes operations
op:\mathcal{C}\to\mathcal{C}
that operate on concrete elements. In program analysis, these operations correspond to statements such as assignments that transform the program state. To analyze the concrete domain within the abstract domain, we require, for each concrete operator
op
, a corresponding abstract operator
\hat{op}:\mathcal{A}\to\mathcal{A}
that operates on abstract elements in a way that reflects the effect of
op
on concrete elements. This function
\hat{op}
is called the
abstract transformer
corresponding to the concrete operator
op
.

Soundness and Precision of Abstract Transformers.

We define the soundness of abstract transformers, followed by the notion of precision between transformers and the definition of the most-precise transformer.

Definition 2.0 (Soundness of Abstraction Transformer).

The abstract transformer
\hat{op}:\mathcal{A}\to\mathcal{A}
for concrete operator
op
is sound if it over-approximates the effect of
op
, i.e. for all abstract elements
\mathtt{a}\in A
, the inclusion relation
op(\gamma(\mathtt{a}))\subseteq\gamma(\hat{op}(\mathtt{a}))
holds.

Definition 2.0 (Precision of Abstract Transformers).

Given two sound abstract transformers
\hat{op}_{1},\hat{op}_{2}:\mathcal{A}\to\mathcal{A}
for the same concrete operator
op
, we say that
\hat{op}_{1}
is
more precise
than
\hat{op}_{2}
if it generates more precise outputs, i,e,
\forall\mathtt{a}\in\mathcal{A},\;\gamma(\hat{op}_{1}(\mathtt{a}))\subseteq\gamma(\hat{op}_{2}(\mathtt{a}))
.

Definition 2.0 (Most-Precise Abstract Transformer).

An abstract transformer
\hat{op}^{\#}:\mathcal{A}\to\mathcal{A}
is the
most-precise
(or
best
) transformer for a concrete operator
op:\mathcal{C}\to\mathcal{C}
in domain
\mathcal{A}
if it is sound and generates most-precise outputs, i.e, for every other sound abstract transformer
\hat{op}^{\prime}:\mathcal{A}\to\mathcal{A}
corresponding to
op
,
\forall\mathtt{a}\in\mathcal{A},\;\gamma(\hat{op}^{\#}(\mathtt{a}))\subseteq\gamma(\hat{op}^{\prime}(\mathtt{a}))
holds.

Polyhedral Domains.

The most common family of numerical abstract domains is
polyhedral domains
, which represent sets of program states using systems of linear inequalities. Given a set of program variables
\mathcal{V}=\{v_{1},\ldots,v_{n}\}
, an abstract element in a polyhedral domain is defined by a finite conjunction of constraints of the form
\mathtt{a}=\{\mathbf{A}\,\mathbf{v}\leq\mathbf{b}\}
, where
\mathbf{v}=[v_{1},\ldots,v_{n}]^{\top}
,
\mathbf{A}\in\mathbb{R}^{m\times n}
, and
\mathbf{b}\in\mathbb{R}^{m}
. This formulation subsumes a range of widely used domains: Intervals
(
Cousot and Cousot 1977b
)
capture independent bounds on variables, Zones
(
Miné 2002
)
track differences between variables, Octagons
(
Mine 2001
)
handle sums and differences, and general Polyhedra
(
Cousot and Halbwachs 1978b
)
support arbitrary linear relations.

Template Constraint Matrix (TCM) Domains.

A common subclass of polyhedral domains is the family of
template-based domains
, which restricts abstract elements to a fixed set of linear directions. These directions are encoded by a
Template Constraint Matrix (TCM)

(
Sankaranarayanan et al. 2005
)

\mathcal{T}\in\mathbb{R}^{t\times n}
, where each row
\mathcal{T}_{i}
specifies a linear constraint over program variables
\mathcal{V}=\{v_{1},\ldots,v_{n}\}
. Letting
\mathbf{v}=[v_{1},\ldots,v_{n}]^{\top}
, abstract elements take the form
\mathtt{a}=\{\mathcal{T}\mathbf{v}\geq\mathbf{c}\}
, where
\mathbf{c}\in(\mathbb{R}\cup\{-\infty\})^{t}
gives lower bounds for each constraint. Any constraint with
c_{i}=-\infty
is treated as vacuously true and omitted. TCM domains include domains like Interval, Zones, Octagons, etc.

Imprecision of Current Transformers.

Consider the program shown in Fig.

. However, the output octagon from

) but not precise. This imprecision ultimately causes the analysis to miss
x\leq 0

Elina
applies

, which discards relational constraints and reasons only over interval bounds of variables. Given
x\in[-\infty,10]

Computing Most-Precise Bounds Is Expensive.

The most-precise output in such cases can be computed by solving a set of optimization problems, one for each output bound of interest. To formalize this, we capture the effect of concrete operations (e.g.,
x:=x-y
) on the program state using an
Effective Update Map (EUM)

\sigma:\mathcal{V}\to\mathbb{E}(\mathcal{V})
, where
\mathcal{V}
is the set of program variables and
\mathbb{E}(\mathcal{V})
denotes symbolic expressions over
\mathcal{V}
. Intuitively,
\sigma
records how the value of each variable changes across an assignment or a sequence of assignments. For example, the update
x:=x-y
is represented as
\sigma(x)=x-y
and
\sigma(y)=y
, indicating that
x
is reassigned based on its previous value and
y
, while
y
remains unchanged. Given a template-based domain (see Sec.
2
) like Octagon with a fixed template matrix
\mathcal{T}
and an input abstract element
\mathtt{a}_{\mathit{in}}
, the most-precise abstract output after an operation with EUM
\sigma
can be computed by solving
c_{i}^{\#}=\min_{\mathbf{v}\in\mathtt{a}_{\mathit{in}}}\;\mathcal{T}_{i}\cdot\sigma(\mathbf{v})
for all template rows
\mathcal{T}_{i}
. Here,
\sigma(\mathbf{v})
applies the update map pointwise to the variable vector
\mathbf{v}
, yielding a symbolic expression that represents the state after update. The result
c_{i}^{\#}
is the tightest sound lower bound on the updated program state in the direction of
\mathcal{T}_{i}
.

In our example, computing the most-precise bound
c_{1}^{\#}
for the output constraint
-x\geq c_{1}^{\#}
after the assignment
x:=x-y
requires minimizing
y-x
(i.e.,
-1\cdot\sigma(x)
) subject to the input constraints:
\{x\leq 10
,
1\leq y\leq 11
,
x-y\leq-1
,
x+y\leq 21\}
. Solving this yields
c_{1}^{\#}=1
. Similar optimization problems are solved for each of the 8 octagon directions (
\pm x
,
\pm y
,
\pm x\pm y
) to compute the final output. While this solver-based transformer proves the assertion in Fig.
2(a)
, it is expensive, taking 1.82 seconds for this small program, compared to 0.19 seconds for the baseline. Since the number of solver calls grows quadratically with the number of variables, this approach does not scale. Libraries like
ELINA
thus rely on inexpensive sound heuristics, such as interval relaxation, to maintain efficiency at the cost of precision. We identify three key limitations of this choice:

(1)

No General Algorithm across Domains or Instructions:
The most-precise transformer is often too expensive, so libraries like
Elina
fall back to cheap, hand-crafted heuristics like interval relaxation and other ad hoc methods. These are tightly coupled to each domain, with separate implementations even for the same instruction across related domains like Zones and Octagons. There is no unified algorithm that generalizes across domains or instruction types.

(2)

Lack of Compositional Reasoning:
Precision in abstract interpretation is inherently
non-compositional
: analyzing instructions one at a time and composing results is often less precise than analyzing the entire block together. Consider the program in Fig.
2(b)
: the relation
x-y=20
holds initially and remains invariant across iterations, since
x
and
y
are updated using the current value of
y
(with
2y=y+y
). Thus,
x-y=20
is a valid loop invariant, and the assertion holds. However, neither existing libraries nor our optimization-based precise transformer can prove it, as the invariant can only be recovered if both assignments are analyzed jointly. Such block-level reasoning requires symbolic composition of updates, which current frameworks lack due to the absence of a general algorithm for handling instruction sequences.

(3)

Fixed Precision–Time Trade-off:
Since the most-precise transformer is often too expensive, libraries like
Elina
fall back to cheap, hand-crafted heuristics that prioritize efficiency. But this fixed design cannot adapt to the needs of different analyses, some demand high precision, others can tolerate imprecision for speed. There is no general algorithm to balance this trade-off, and current implementations always choose efficiency, even when precision is essential.

This Work.
Current frameworks lack a general algorithm for even common instructions, relying instead on fixed, hard-coded algorithms tailored to each domain. This limits extensibility and prevents adaptation to varying precision or time budgets. To address this, we propose a universal transformer synthesis algorithm that, given a polyhedral numerical abstract domain
\mathcal{D}
and a concrete operator
\mathsf{op}
, either a single instruction or a structured sequence from a defined class, automatically constructs a
parametric family of sound abstract transformers
. Our algorithm is domain- and operator-agnostic, and applies uniformly to standard domains (e.g., Intervals, Octagons, Polyhedra) and a broad class of operators including affine, quadratic, guarded assignments and even their sequences. We also introduce an efficient
gradient-guided
traversal method that explores the parametric family and selects transformers based on the specific needs of the analysis, enabling principled trade-offs between precision and efficiency.

The algorithm works by constructing a
parametric family of sound outputs
for any given input abstract element
\mathtt{a}_{\mathit{in}}
, for any supported operator
\mathsf{op}
and abstract domain
\mathcal{D}
.
We illustrate the construction of a family of sound outputs using the example above. As discussed, the most-precise lower bound for
-x
after the assignment is
1
, while
ELINA
computes a weaker bound of
-9
, which is sound but imprecise. This rigidity is limiting, as some tools may operate under relaxed time budgets and prefer more precise bounds. To support such use cases, we capture the entire space of sound bounds by constructing a
Parametric Scalar Map (PSM)

\mathcal{M}=\{\Theta,L\}
, where each
\theta\in\Theta
defines a sound lower bound
L(\theta)
. Our gradient-guided method can then be used to traverse this space, allowing downstream tasks to control the search time by specifying the number of epochs. More epochs yield more precise bounds, thus enabling a flexible trade-off between time and precision.

Computing Parametric Lower Bounds.

In our example, the most-precise lower bound
c^{\#}
for
-x
can be obtained by minimizing
y-x
subject to the input constraints:

(1)

c^{\#}=\min_{x,y}\;y-x\quad\text{subject to}\quad x\leq 10,\;1\leq y\leq 11,\;x-y\leq-1,\;x+y\leq 21

Any bound
l
less than or equal to
c^{\#}
is sound for this problem, as it over-approximates the true lower bound. To capture the entire space of such sound bounds, we construct the dual of the problem above by introducing non-negative Lagrange multipliers
\boldsymbol{\lambda}=(\lambda_{1},\lambda_{2})
for the two relational constraints,
x-y\leq-1
and
x+y\leq 21
. We do not introduce multipliers for independent variable bounds. Most numerical abstract domains maintain such variable bounds, and keeping them intact makes the bound computation easier, as we will see later. Our construction also works when some or all the variable bounds are infinite.

o_{dual}=\max_{\lambda_{1},\lambda_{2}\geq 0}\;\;\min_{x\in[-\infty,10],y\in[1,11]}\;y-x+\lambda_{1}\cdot(x-y+1)+\lambda_{2}\cdot(x+y-21)

The inner minimization problem (shown after simplification) is known as the dual function (
g
):

g(\lambda_{1},\lambda_{2})=\min_{x\in[-\infty,10],y\in[1,11]}(\lambda_{1}+\lambda_{2}-1)\cdot x+(-\lambda_{1}+\lambda_{2}+1)\cdot y+\lambda_{1}-21*\lambda_{2}

Considering the dual yields an interesting construction: by design, it produces sound lower bounds on the original objective. By the weak duality theorem
(
Boyd and Vandenberghe 2004
)
, the value of the dual function is always less than or equal to the original objective for all feasible choices of multipliers. In our case, this means that for all
\lambda_{1},\lambda_{2}\geq 0
, the dual function
g(\lambda_{1},\lambda_{2})
satisfies
g(\lambda_{1},\lambda_{2})\leq c^{\#}
. The most-precise sound bound can then be obtained by maximizing
g(\lambda_{1},\lambda_{2})
over all non-negative multipliers, i.e.,
c^{\#}=\max_{\lambda_{1},\lambda_{2}\geq 0}\;g(\lambda_{1},\lambda_{2})
.

This means that for any
\lambda_{1},\lambda_{2}\geq 0
, the value
g(\lambda_{1},\lambda_{2})
serves as a sound lower bound on
c^{\#}
and can be used to characterize the space of such bounds. Before we discuss how to compute
g(\lambda_{1},\lambda_{2})
, it is important to note that for certain choices of
\lambda_{1}
and
\lambda_{2}
, the dual function, which involves a minimization, may evaluate to
-\infty
. While this is technically a sound lower bound, it is trivial and not useful in practice. To avoid such cases, we derive additional constraints on the values of
\lambda_{1}
and
\lambda_{2}
to ensure that
g(\lambda_{1},\lambda_{2})
remains finite. This allows us to capture a family of sound, finite lower bounds that are meaningful for downstream analysis.

We simplify the dual function by introducing
a=\lambda_{1}+\lambda_{2}-1,\;b=-\lambda_{1}+\lambda_{2}+1,\&\;c=\lambda_{1}-21\cdot\lambda_{2}
so that the dual becomes:

g(\lambda_{1},\lambda_{2})=\min_{x\in[-\infty,10],\,y\in[1,11]}\;a\cdot x+b\cdot y+c

To compute the value of the dual function, we analyze it variable-wise. Specifically, for each
k\cdot v_{i}
with
v_{i}\in[l_{i},u_{i}]
, we calculate its minimum
L_{i}
and also collect constraints
\Theta_{i}
on lambdas that are required to keep this minimum finite. We consider the following four cases:

(1)

Both bounds finite
: In this case, the minimum depends on the sign of the coefficient
k
: if
k\geq 0
, the minimum is
k\cdot l_{i}
, and if
k<0
, it is
k\cdot u_{i}
. This can also be expressed using the closed-form expression
L_{i}=-\frac{|k|}{2}(u_{i}-l_{i})+\frac{k}{2}(u_{i}+l_{i})
.

(2)

Lower bound is
-\infty
, upper bound is finite
: In this case, the minimum is unbounded (i.e.,
-\infty
) when
k>0
. To ensure a finite value, we add the constraint
k\leq 0
to
\Theta_{i}
, in which case the minimum is attained at the upper bound and equals
L_{i}=k\cdot u_{i}
.

(3)

Lower bound is finite, upper bound is
+\infty
: In this case, the minimum is unbounded (i.e.,
-\infty
) when
k<0
. To ensure a finite value, we add the constraint
k\geq 0
to
\Theta_{i}
, in which case the minimum is attained at the lower bound and equals
L_{i}=k\cdot l_{i}
.

(4)

Both bounds are infinite
: In this case, this term can never yield a finite answer if
k
is not 0. So, we add the constraint
k=0
to
\Theta_{i}
and minimum equals
L_{i}=0
.

This procedure is applied to all variables, and the contributions from each term are summed to obtain the final minimized value
L=\sum_{i=1}^{V}L_{i}+c
. The individual constraint sets
\Theta_{i}
are combined to form the overall feasible region
\Theta
, along with the non-negativity constraints on all multipliers. For our example,
x
lies in case 2 above as its lower bound is
-\infty
, and
y
lies in case 1. Using the approach described above, we get
L=(10\cdot a-5\cdot|b|+6\cdot b+c)

and the parameter space
\Theta
over
\lambda_{1},\lambda_{2}
as
\Theta=\{\lambda_{1}\geq 0,\lambda_{2}\geq 0,a=\lambda_{2}+\lambda_{1}-1\leq 0\}
.

Sound Parametric Family of Abstract Outputs.

The
Parametric Scalar Map

\mathcal{M}=\{\Theta,L\}
obtained above captures a space of
finite
lower bounds on the optimal value
c^{\#}
of Eq.
1
. While the trivial bound
-\infty
is always sound,
\mathcal{M}
parameterizes a richer space of finite values
l=L(\theta)
such that the inequality
-x\geq l
is sound for every
\theta\in\Theta
, since
L(\theta)\leq c^{\#}
. By constructing such maps for all optimization problems corresponding to each template direction
\mathcal{T}_{i}
in the template, we obtain a collection of
t
maps
\mathcal{M}_{i}=\{\Theta_{i},L_{i}\}
, which together define a
parametric family of abstract outputs
. Instantiating these maps with different parameter values
\theta_{i}\in\Theta_{i}
yields different abstract outputs, each of which is sound by construction, as every selected bound corresponds to a valid lower bound on the optimum. We formalize these notions further in Sec
4.1
and Section A of the appendix.

Gradient-Guided Traversal of the Parametric Family.
The parametric family of outputs is defined by
t
maps, where each map
\mathcal{M}_{i}=\{\Theta_{i},L_{i}\}

characterizes
all sound, finite lower bounds admissible for the
i^{\text{th}}
constraint. We now describe how to traverse this space to select suitable
\theta_{i}\in\Theta_{i}
for instantiating an output. If
\Theta_{i}
is empty or infeasible, it indicates that no finite lower bound can be inferred for that direction, and the only sound bound under our construction is
-\infty
. For non-empty
\Theta_{i}
, we use a gradient-guided search procedure described in Sec.
4.2
to select a suitable
\theta_{i}\in\Theta_{i}
. This procedure allows downstream tasks to provide a differentiable score function
J_{i}
that evaluates the desirability of each bound
L_{i}(\theta)
via
J_{i}(L_{i}(\theta))
, as well as a number of epochs
R
that controls the runtime of the search. Our novel Adaptive Gradient Guidance (AGG) algorithm then uses the gradient of
J_{i}(L_{i}(\theta))
to efficiently explore the space, steering toward high-scoring bounds while ensuring that
\theta
remains within the feasible region
\Theta_{i}
, which is typically defined by complex polyhedral constraints over the parameters. The goal in most cases is to obtain more precise bounds, which corresponds to maximizing
L_{i}(\theta)
. In such cases,
one can use
L_{i}
as the score function itself, and AGG performs gradient ascent to find parameter values that yield tighter, sound bounds within the feasible region. For instance, in the example above, the lower bound for
-x
is parameterized as
L=10a-5|b|+6b+c
, with
\Theta=\{\lambda_{1}\geq 0,;\lambda_{2}\geq 0,;a=\lambda_{1}+\lambda_{2}-1\leq 0\}
, where the coefficients are given by
a=\lambda_{1}+\lambda_{2}-1
,
b=-\lambda_{1}+\lambda_{2}+1
, and
c=\lambda_{1}-21\lambda_{2}
.

Our algorithm initializes all parameters to zero:
\lambda_{1}=\lambda_{2}=0
. This always corresponds to the
interval relaxation
case. As in this case, using
\lambda_{1}=\lambda_{2}=0
, yields
L=-9
, which is the same as computed by
ELINA
. From this starting point, the algorithm performs gradient-guided updates that progressively improve the bound:

\begin{array}[]{ll}\lambda_{1}=0.3,\;\lambda_{2}=0&\Rightarrow a=-0.7,\;b=0.7,\;c=0.3,\;L=-6\\
\lambda_{1}=0.6,\;\lambda_{2}=0&\Rightarrow a=-0.4,\;b=0.4,\;c=0.6,\;L=-3\\
\lambda_{1}=1,\;\lambda_{2}=0&\Rightarrow a=0,\;b=0,\;c=1,\;L=1\;\text{(most precise)}\end{array}

Thus, our method begins at the interval baseline and follows a gradient-guided path toward progressively tighter, sound lower bounds within the feasible region
\Theta
. In the example above, it converges to the most-precise bound in just three gradient steps, demonstrating the effectiveness of our search strategy. While our approach for constructing a parametric family of transformers applies to both linear and nonlinear cases, we formally prove that in the linear setting, it captures
all
possible finite sound lower bounds, including the most-precise bound, ensuring completeness of the search space. Further details of this construction and traversal process are provided in Sec.
4
.

Quadratic Case.

While the previous discussion focused on linear assignments, the construction can be adapted to work with quadratic assignments as well. Consider
y:=x\cdot x
and the input abstract element
o=\{x\geq 0,\;0\leq y\leq 16,\;x+y\geq 0,\;x-y\geq-16\}
. To compute a lower bound on
y-x
after the assignment, we minimize
\sigma(y)-\sigma(x)=x^{2}-x
subject to the input constraints. As discussed above,
ELINA
uses interval relaxation. Since
x\in[0,\infty]
implies
x^{2}\in[0,\infty]
, the relaxation yields
x^{2}-x\in[-\infty,\infty]
, and thus provides no finite lower bound on
y-x
. However, the expression
x^{2}-x
is quadratic and attains its minimum at
x=\tfrac{1}{2}
with value
-0.25
, so
x^{2}-x\geq-0.25
for all
x\in[-\infty,\infty]
. To capture such possible lower bounds, we use our approach discussed above and introduce the non-negative lagrangian multipliers
\boldsymbol{\lambda}=(\lambda_{1},\lambda_{2})
for the two relational constraints to get the dual function:

g(\lambda_{1},\lambda_{2})=\min_{x\in[0,\infty],y\in[0,16]}x^{2}-x+\lambda_{1}\cdot(-x-y)+\lambda_{2}\cdot(-x+y-16)

Simplifying, we get:

g(\lambda_{1},\lambda_{2})=\min_{x\in[0,\infty],y\in[0,16]}x^{2}+(-\lambda_{1}-\lambda_{2}-1)\cdot x+(-\lambda_{1}+\lambda_{2})\cdot y-16\cdot\lambda_{2}

This joint minimization is still nontrivial, so we introduce a new function
\hat{g}(\lambda_{1},\lambda_{2},s)
by splitting the objective into two parts and introducing a split parameter
s
that decomposes the coefficient of
x
as
s+(-\lambda_{1}-\lambda_{2}-1-s)
. This yields:

\hat{g}(\lambda_{1},\lambda_{2},s)=\underbrace{\min_{x\in[0,\infty]}\left(x^{2}+s\cdot x\right)}_{\text{(A) convex quadratic}}+\underbrace{\min_{x\in[0,\infty],\;y\in[0,16]}\left[(-\lambda_{1}-\lambda_{2}-1-s)\cdot x+(-\lambda_{1}+\lambda_{2})\cdot y-16\cdot\lambda_{2}\right]}_{\text{(B) linear part}}.

We then minimize each part separately. By construction, this relaxation satisfies the inequality

\hat{g}(\lambda_{1},\lambda_{2},s)\leq g(\lambda_{1},\lambda_{2})\quad\text{for all }s,

since the sum of separate minima is always less than or equal to the minimum of the full expression. Therefore, it is sound to compute this relaxation as a lower bound on the original objective. We use the procedure described above to solve the linear part. Substituting
a=-\lambda_{1}-\lambda_{2}-1-s
and
b=-\lambda_{1}+\lambda_{2}
, we get
L_{lin}=(8\cdot a-8\cdot|a|)
and the parameter set as
\Theta_{lin}=\{a=-\lambda_{1}-\lambda_{2}-1-s\geq 0\}
. For the quadratic part, the minimum of
x^{2}+sx
over
x\in[0,\infty]
depends on the sign of the minimizer: if
s\leq 0
, the minimum
L_{\text{quad}}=-\tfrac{s^{2}}{4}
is attained at
x=-\tfrac{s}{2}
; if
s>0
, the minimum is
L_{\text{quad}}=0
at
x=0
. Since the minimum is always finite within the box, no additional constraints on
s
are needed. The overall parametric lower bound is given by the Parametric Scalar Map
\mathcal{M}=\{L_{\text{lin}}+L_{\text{quad}},;\Theta_{\text{lin}}\}
, which can be traversed using the gradient-guided method described above.

Support for Standard Domains and Rich Operator Sequences.

Our universal algorithm for constructing parametric families of sound abstract transformers applies to standard polyhedral domains such as Intervals, Octagons, and Polyhedra (Sec.
2
), and supports a broad class of concrete operators termed
Quadratic-Bounded Guarded Operators (QGOs)
(Sec.
4
). QGOs encompass updates defined by linear or quadratic expressions and input guards expressed as conjunctions of linear inequalities, covering affine and quadratic assignments as well as conditional statements like
assume
. A key strength of this formulation is its compositionality: it naturally extends to sequences of instructions whose overall semantics form a valid QGO. For example, the sequence
\{x:=a+b;\;y:=x+c\}
induces updates
\sigma(x)=a+b
,
\sigma(y)=a+b+c
, while
\{x:=a+b;\;y:=x\cdot c\}
yields
\sigma(y)=(a+b)\cdot c
, both sequences are QGOs since all updates are linear or quadratic.This enables our framework to reason soundly over entire blocks of code rather than isolated statements. For instance, to compute bounds for
x-y
after the sequence
\{x:=a+b;\;y:=x+c\}
, we directly derive a parametric bound for
\sigma(x)-\sigma(y)=-c
using our symbolic relaxation method. The
USTAD
framework (Sec.
5
) leverages this by merging such sequences into blocks and analyzing them jointly, yielding more precise invariants. For example, it infers
x-y=20
in the program of Fig.
2(b)
by analyzing the loop body
\{x:=x-y;\;y:=2\cdot y\}
as a unit. Fig.
3
shows how our transformer reaches this precise invariant within five epochs.

4.
Synthesizing and Traversing Family of Sound Transformers

Our universal transformer synthesis algorithm applies to standard polyhedral numerical domains such as Intervals, Octagons, and Polyhedra (Sec.
2
), and supports a wide range of concrete operators, including entire sequences of operations. The algorithm handles any operator whose overall effect can be expressed as a
Quadratic-Bounded Guarded Operator (QGO)
, defined below. For each such operator, it constructs a
parametric family of sound abstract transformers
, where each parameter instantiation yields a valid sound transformer. To effectively navigate this space, we introduce a mechanism for
gradient-guided traversal
, enabling the selection of transformers that align with specific analysis goals such as maximizing precision or minimizing runtime.

Template-Constrained Transformers.

The parametric family of transformers we construct consists of
template-constrained
transformers: each takes an input abstract element from a general polyhedral domain
\mathcal{D}
(e.g., Polyhedra) and produces an output constrained to a fixed
template
, defined by a Template Constraint Matrix (TCM)
\mathcal{T}\in\mathbb{R}^{t\times n}
(Sec
2
). Each row
\mathcal{T}_{i}
specifies a linear direction over the program variables
\mathbf{v}=[v_{1},\ldots,v_{n}]^{\top}
, and the output abstract element has the form
\mathcal{T}\mathbf{v}\geq\mathbf{c}
, where
\mathbf{c}\in(\mathbb{R}\cup\{-\infty\})^{t}
specifies the lower bounds. We say that
\mathtt{a}_{\mathit{out}}=\mathcal{T}\mathbf{v}\geq\mathbf{c}
is a
sound output
for a concrete operator
op
and input
\mathtt{a}_{\mathit{in}}
if it over-approximates the result of applying
op
to all concrete states in
\mathtt{a}_{\mathit{in}}
, i.e.,
op(\gamma(\mathtt{a}_{\mathit{in}}))\subseteq\gamma(\mathtt{a}_{\mathit{out}})
.

For polyhedral domains that are inherently template-based, such as Zones or Octagons, the output template
\mathcal{T}
can be directly derived from the domain itself, since their abstract elements already conform to a fixed constraint shape. In contrast, for expressive domains such as general Polyhedra, whose abstract elements are not tied to a built-in template, our technique can be instantiated with any user-supplied template
\mathcal{T}
. If the underlying abstract domain permits arbitrary linear combinations of variables, as is the case with Polyhedra, then the outputs produced by our parametric transformers can be directly used as valid abstract elements. Otherwise, we require that the domain supports a
sound conditional operator
, that is, an operation that soundly intersects abstract elements with arbitrary systems of linear constraints. In such cases, our output can be used in two ways: it can refine the result of a baseline analyzer by intersecting the baseline output with the generated constraints, or it can be used independently by intersecting the constraints with
\top
(top) to yield abstract elements
\mathtt{a}_{\mathcal{D}}
in the abstract domain
{\mathcal{D}}
that soundly over-approximate the transformer output
\mathtt{a}_{\mathit{out}}
, i.e.,
\gamma(\mathtt{a}_{\mathit{out}})\subseteq\gamma(\mathtt{a}_{\mathcal{D}})
.

Supported Concrete Operators.

Our algorithm applies to a broad class of concrete operators that affect program state through either or both of the following mechanisms:

•

Variable updates
, where some program variables are updated based on symbolic expressions over other variables, and

•

State restrictions
, where the set of feasible states is filtered using linear guard conditions.

These mechanisms cover the standard operators handled by numerical abstract domain libraries such as ELINA
(
Singh et al. 2015
)
. Unlike existing approaches that focus on individual statements, our algorithm naturally extends to handle entire sequences of instructions by treating the sequence as a single composite operator that summarizes the cumulative effect. To represent the behavior of such composite updates, we introduce the notion of an
Effective Update Map (EUM)
, which symbolically abstracts the overall effect of the sequence on program variables.

Definition 4.0 (Effective Update Map).

Let
\mathcal{V}
denote the set of program variables, and let
\mathcal{O}
be a concrete operator (either atomic or composite). Let
\mathcal{U}\subseteq\mathcal{V}
denote the set of
updated variables
, i.e., those whose values are modified by
\mathcal{O}
. The
Effective Update Map (EUM)
of
\mathcal{O}
is a total function
\sigma:\mathcal{V}\to\mathbb{E}(\mathcal{V})
, where
\mathbb{E}(\mathcal{V})
denotes the set of symbolic expressions over variables in
\mathcal{V}
. The map
\sigma
is defined as follows:

•

For each
v\in\mathcal{U}
,
\sigma(v)
is a symbolic expression over
\mathcal{V}
that computes the final value of
v
after applying
\mathcal{O}
.

•

For each
v\notin\mathcal{U}
,
\sigma(v)=v
, indicating that
v
remains unchanged.

The EUM is
flat
: each expression
\sigma(v)
is written directly in terms of the original variables in
\mathcal{V}
and does not reference intermediate variables or intermediate assignment steps.

Our algorithm supports all concrete operators, whether atomic instructions or instruction sequences, whose semantics can be represented by a pair
(\sigma_{\leq 2},\mathcal{G})
defined as follows:

(1)

Quadratic-Bounded Update Map (
\sigma_{\leq 2}
):
The Effective Update Map assigns each updated variable a multivariate polynomial over program variables of total degree at most two

\sigma_{\leq 2}:\mathcal{V}\to\mathcal{P}_{\leq 2}(\mathcal{V}),

where
\mathcal{P}_{\leq 2}(\mathcal{V})
denotes polynomials of the form
\sum_{i\leq j}a_{ij}v_{i}v_{j}+\sum_{k}b_{k}v_{k}+c
, with coefficients
a_{ij},b_{k},c\in\mathbb{R}
and variables
v_{i},v_{j},v_{k}\in\mathcal{V}
. This class captures a wide range of common update patterns, such as affine and quadratic assignments.

(2)

Conjunctive Linear Guard Constraints (
\mathcal{G}
):

The operator may also impose a symbolic precondition expressed as a conjunction of linear inequalities over program variables
\mathcal{G}:=\{Pv\leq d\}
,
where
v
is the vector of program variables. These constraints subsume assume statements, conditional branches, and input-domain restrictions.

We refer to the class of all such operator forms, whether individual or induced by a sequence, as
Quadratic-Bounded Guarded Operators (QGOs)
. This formulation encompasses:

•

Pure updates
, where
\sigma_{\leq 2}
performs a non-trivial quadratic-bounded update and
\mathcal{G}
is empty. These include common assignment forms such as
Affine assignments:
v_{j}:=\sum_{i}c_{i}v_{i}+b
, and
Quadratic assignments:
v_{j}:=\sum_{i\leq k}a_{ik}v_{i}v_{k}+\sum_{i}b_{i}v_{i}+c
.

•

Pure guards
, where
\sigma_{\leq 2}
is the identity and
\mathcal{G}
restricts the input space. These include conditional statements like
assume
or conjunctions of linear inequalities.

•

Guarded updates
, where both
\sigma_{\leq 2}
and
\mathcal{G}
are non-trivial.

Along with supporting common single operators listed above, a key strength of our formulation is that it also naturally subsumes many instruction sequences. If the overall effect of a sequence can be flattened into a quadratic-bounded update map, the entire sequence can be treated as a single QGO. This enables more precise, block-level reasoning. For example, the sequence
\{x:=a+b;;y:=x+c\}
induces an effective update map where
\sigma_{\leq 2}(x)=a+b
and
\sigma_{\leq 2}(y)=a+b+c
, while all other variables are mapped to themselves. Similarly, the sequence
\{x:=a+b;;y:=x\cdot c\}
yields
\sigma_{\leq 2}(x)=a+b
and
\sigma_{\leq 2}(y)=(a+b)\cdot c
. Such sequences thus lie within the QGO class, and our approach can construct a family of sound abstract transformers for them, as we discuss in the next section.

4.1.
Parametric Family of Sound Abstract Transformers

For every operator
op
in our supported class of Quadratic-Bounded Guarded Operators (QGOs), which may include arbitrary combinations of assignments and conditionals (including those induced by sequences), one can construct a potentially infinite number of sound abstract transformers that output elements within the template
\mathcal{T}
. Each operator
op
is defined by a pair
(\sigma_{\leq 2},\mathcal{G})
, where
\sigma_{\leq 2}
is a quadratic-bounded effective update map, and
\mathcal{G}:=\{P\mathbf{v}\leq d\}
is a system of linear guard constraints over the program variables. Among the sound transformers for
op
that output in
\mathcal{T}
, the
most-precise transformer
(Def.
2.5
), for any input
\mathtt{a}_{\mathit{in}}
, yields the most-precise abstract element
\mathtt{a}_{\mathit{out}}^{\#}
in
\mathcal{T}
such that
op(\gamma(\mathtt{a}_{\mathit{in}}))\subseteq\gamma(\mathtt{a}_{\mathit{out}}^{\#})
. Computing
\mathtt{a}_{\mathit{out}}^{\#}
requires minimizing each template constraint over the set of states reachable by applying
op
to any input state in
\mathtt{a}_{\mathit{in}}
. Since the operator
op
is represented by the effective update map
\sigma_{\leq 2}:\mathcal{V}\to\mathbb{P}_{\leq 2}(\mathcal{V})
, each variable after application of
op
is expressed as a polynomial over variables in
\mathcal{V}
. Thus, each row
\mathcal{T}_{i}
of the template
\mathcal{T}
, which defines a linear constraint over variables after the application of
op
, is symbolically rewritten by substituting each
v_{j}
with
\sigma_{\leq 2}(v_{j})
. We refer to the resulting polynomial as the
effective objective
for row
\mathcal{T}_{i}
. This rewriting enables us to reduce the problem of computing
\mathtt{a}_{\mathit{out}}^{\#}
to a constrained minimization problem over
\mathtt{a}_{\mathit{in}}
.

Definition 4.0 (Effective Objectives).

Let
\mathcal{T}\in\mathbb{R}^{t\times n}
be the output template, and let
\sigma_{\leq 2}:\mathcal{V}\to\mathbb{P}_{\leq 2}(\mathcal{V})
be the EUM associated with a concrete operator
op
. For each template row
\mathcal{T}_{i}\in\mathbb{R}^{n}
, the corresponding
effective objective

\hat{f}_{i}
is defined as the linear combination of update expressions:
\hat{f}_{i}:=\sum_{j=1}^{n}\mathcal{T}_{i,j}\cdot\sigma_{\leq 2}(v_{j})
, where each term multiplies the scalar coefficient
\mathcal{T}_{i,j}\in\mathbb{R}
with the symbolic expression
\sigma_{\leq 2}(v_{j})\in\mathbb{P}_{\leq 2}(\mathcal{V})
. The resulting expression
\hat{f}_{i}
is a polynomial over the variable set
\mathcal{V}
obtained by symbolically rewriting the linear output constraint
\mathcal{T}_{i}\cdot\mathbf{v}
using the update map.

To compute the most-precise abstract output, we minimize each objective
\hat{f}_{i}
over all input states satisfying both the abstract input and the guard
\mathcal{G}
. Let the abstract input be
\mathtt{a}_{\mathit{in}}=\{\,\mathbf{v}\in\mathbb{R}^{n}\mid\mathbf{A}\mathbf{v}\leq\mathbf{b}\,\}
and the guard be
\mathcal{G}=\{\,\mathbf{v}\in\mathbb{R}^{n}\mid P\mathbf{v}\leq d\,\}
. Let the combined feasible region be
\mathcal{C}_{\mathit{in}}^{op}=\{\,\mathbf{v}\in\mathbb{R}^{n}\mid\bar{\mathbf{A}}\mathbf{v}\leq\bar{\mathbf{b}}\,\}
, where
\bar{\mathbf{A}}
and
\bar{\mathbf{b}}
represent the stacked constraints from both sets. The most-precise output
\mathtt{a}_{\mathit{out}}^{\#}
is then:

(2)

\mathtt{a}_{\mathit{out}}^{\#}=\left\{\,\mathcal{T}_{i}\cdot\mathbf{v}\geq c_{i}^{\#}\;\middle|\;i=1,\ldots,t\,\right\},\quad\text{where }c_{i}^{\#}=\min_{\mathbf{v}\in\mathbb{R}^{n}}\hat{f}_{i}(\mathbf{v})\text{ s.t. }\bar{\mathbf{A}}\mathbf{v}\leq\bar{\mathbf{b}}.

Example 4.0.

Consider an operator
op
with update map
\sigma_{\leq 2}
that modifies
x
and
y
:

\sigma_{\leq 2}(x)=d^{2}
,

\sigma_{\leq 2}(y)=3d+e
,

\sigma_{\leq 2}(d)=d
, and

\sigma_{\leq 2}(e)=e
.
The guard is
\mathcal{G}:=\{\,d+e\leq 5\,\}
. Suppose a template row enforces
x+y\geq c_{i}^{\#}
. Substituting the updates gives the effective objective:
\hat{f}_{i}=d^{2}+3d+e
. Let the input abstract state be
\{0\leq d\leq 2
,
0\leq e\leq 1\}
. Then
c_{i}^{\#}
is computed by minimizing
d^{2}+3d+e
, subject to
0\leq d\leq 2
,
0\leq e\leq 1
, and
d+e\leq 5
.

Intractability of Most-Precise Transformer.

As discussed above, obtaining the most-precise output
\mathtt{a}_{\mathit{out}}^{\#}
requires solving one optimization problem per template constraint, resulting in a total of
t
problems. Each problem involves a quadratic-bounded objective and is handled using an external solver. For standard template domains such as Octagons and Zones,
t
grows on the order of
\mathcal{O}(n^{2})
in the number of variables
n
, and more generally, the number of solver calls increases super-linearly with
n
. In addition, each optimization problem becomes larger and more complex as the program size increases, leading to prohibitive runtime overhead. When the objective is linear, each optimization reduces to a linear program. In contrast, the presence of quadratic terms yields quadratic programs, which are not only significantly more expensive to solve but are often handled by nonlinear solvers that rely on heuristics and do not even guarantee soundness
(
Gurobi Support 2024
)
.

Imprecision of Current Transformers.
To address scalability and soundness concerns discussed above, existing standard implementations of numerical abstract domains in popular libraries such as ELINA
(
Singh et al. 2017b
)
, APRON
(
Jeannet and Miné 2009
)
, PPL
(
Bagnara et al. 2008
)
, etc., rely on carefully designed, hand-crafted over-approximation heuristics that are provably sound. However, these heuristics often suffer from poor precision. A common abstraction technique employed in such settings is
interval relaxation
, which simplifies reasoning by ignoring inter-variable relationships and relying solely on independent interval bounds for computing the bounds.

Example 4.0.

Consider the constraint system
\{\,v_{1}+v_{2}\geq 4,\;v_{1}-v_{2}\geq 1,\;v_{1}\geq 0,\;v_{2}\geq 0\,\}
. This represents the input abstract element over which we aim to minimize different objectives. For
O_{1}=v_{1}+2v_{2}
, the true minimum is
5.5
at
v_{1}=2.5
,
v_{2}=1.5
, but interval relaxation drops the relational constraints and considers only
v_{1},v_{2}\geq 0
, yielding a weaker bound of
0
. For
O_{2}=v_{1}-5v_{2}
, the true minimum is
-5.0
at the same point, but the relaxed system permits
v_{2}\to\infty
, resulting in a bound of
-\infty
. In both cases, interval relaxation produces sound but imprecise bounds: using a smaller constant
c
in the constraint
\mathcal{T}_{i}\cdot\mathbf{v}\geq c
yields a larger abstract set that still over-approximates all reachable states, but at the cost of precision, and in some cases fails to constrain the direction at all (like the case for
O_{2}
).

Limitations of Current Design.

These observations reveal a fundamental gap: the most-precise transformer offers maximum precision but is prohibitively expensive to compute, and so existing libraries fall back on sound, hand-crafted heuristics that scale well but often sacrifice significant precision. Moreover, these heuristics are usually designed for individual operations and lack the ability to analyze sequences of instructions as a unit, further limiting the precision achievable in practice. However, abstract interpretation supports a wide range of downstream tasks, each placing different demands on the transformer; some may require higher precision, others may prioritize different properties, all under varying time constraints. A single fixed transformer is therefore insufficient in practice. Instead, downstream analyses should be able to choose from a family of sound transformers, selecting the one best suited to their objectives and available resources.

Parametric Family of Sound Transformers.

To address the limitations of current abstract transformer design, our universal synthesis algorithm generates a
parametric family of sound transformers
. Rather than committing to a single fixed transformer, this formulation defines a space of sound abstract transformers, each corresponding to a different instantiation of the parameters and capturing a different balance between precision and efficiency. This gives downstream tasks the flexibility to choose transformers based on their needs: tools can opt to spend less time and obtain the behavior of fast, imprecise transformers, but also have the option to spend more time to recover more precise ones as resources permit.

Our algorithm generates such a
parametric family of sound abstract transformers
by constructing a corresponding parametric family of sound abstract outputs for a given operator
op
and input
\mathtt{a}_{\mathit{in}}
in the template domain
\mathcal{T}
. Each parameter instantiation yields an abstract element that serves as a sound output, effectively defining a specific sound transformer in the family. This construction works uniformly for all supported operators and standard polyhedral domains, including Intervals, Octagons, and Polyhedra. The symbolic formulation compactly captures a spectrum of transformers, allowing downstream tools to navigate the tradeoff between precision and efficiency in a principled way. We explore how this space can be traversed efficiently based on the specific needs of the downstream task in the next section. We begin by defining the notion of a
Parametric Scalar Map
, which compactly captures a space of finite scalar values indexed by parameters. We then use such maps to construct a
Parametric Family of Abstract Outputs
within a template domain
\mathcal{T}
.

Definition 4.0 (Parametric Scalar Map).

A Parametric Scalar Map (PSM) is a pair
\mathcal{M}=(\Theta,L)
where
\Theta\subseteq\mathbb{R}^{d}
is a parameter space, and
L:\Theta\to\mathbb{R}
maps each
\theta\in\Theta
to a finite scalar value.

Definition 4.0 (Parametric Family of Abstract Outputs).

Let
\mathcal{T}\in\mathbb{R}^{t\times n}
be a fixed template matrix. A parametric family of abstract outputs
\mathcal{F}_{\mathcal{T}}
is defined by a sequence of
t
Parametric Scalar Maps
\{\mathcal{M}_{i}=(\Theta_{i},L_{i})\}_{i=1}^{t}
, one for each template constraint. For each
i
, we define the extended map
L_{i}^{\prime}:\mathbb{R}^{d_{i}}\to\mathbb{R}\cup\{-\infty\}
as:

L_{i}^{\prime}(\theta_{i})=\begin{cases}L_{i}(\theta_{i})&\text{if }\theta_{i}\in\Theta_{i},\\
-\infty&\text{otherwise.}\end{cases}

\mathcal{F}_{\mathcal{T}}
consists of all abstract elements of the form

O_{\theta}=\left\{\,\mathbf{v}\in\mathbb{R}^{n}\;\middle|\;\mathcal{T}_{i}\cdot\mathbf{v}\geq L_{i}^{\prime}(\theta_{i})\text{ for }i=1,\ldots,t\,\right\}

for some tuple
\theta=(\theta_{1},\ldots,\theta_{t})
with
\theta_{i}\in\mathbb{R}^{d_{i}}
.

Intuitively, each parametric map
\mathcal{M}_{i}=(\Theta_{i},L_{i})
in the family
\mathcal{F}_{\mathcal{T}}
defines a space of possible non-trivial (finite) lower bounds that can be used for the
i^{\text{th}}
template constraint. A bound may either be selected from this space or omitted, in which case
-\infty
is used as the default. If the parameter space
\Theta_{i}
is empty or infeasible, it indicates that no finite lower bound can be instantiated for the
i^{\text{th}}
constraint; only the default value
-\infty
is valid in this case.

Example 4.0.

As a simple illustrative example, suppose the template
\mathcal{T}
includes two rows corresponding to the constraints
x+y\geq c_{1}
and
x-y\geq c_{2}
. We define a parametric family
\mathcal{F}_{\mathcal{T}}
using two Parametric Scalar Maps (one for each constraint):

\mathcal{M}_{1}=\left(\Theta_{1}=\left\{\lambda_{1}\geq 1,\;\lambda_{2}\geq 1,\;\lambda_{1}+\lambda_{2}\geq 1\right\},\;L_{1}(\lambda_{1},\lambda_{2})=2\lambda_{1}+\lambda_{2}\right),

\mathcal{M}_{2}=\left(\Theta_{2}=\left\{\lambda_{3}\geq 1,\;\lambda_{4}\geq 1,\;\lambda_{3}+\lambda_{4}\leq 1\right\},\;L_{2}(\lambda_{3},\lambda_{4})=3\lambda_{3}+2\lambda_{4}\right)

The family
\mathcal{F}_{\mathcal{T}}
is then defined as
\{\,\mathcal{M}_{1},\,\mathcal{M}_{2}\,\}
. In this example,
\mathcal{M}_{1}
is feasible: instantiating parameters yields finite lower bounds for the first template constraint. For instance, setting
(\lambda_{1},\lambda_{2})=(1,1)
yields
c_{1}=3
(corresponds to
x+y\geq 3
), and
(2,1)
yields
c_{1}=5
(corresponds to
x+y\geq 5
). In contrast,
\mathcal{M}_{2}
is infeasible due to a contradiction in its parameter constraints: both
\lambda_{3},\lambda_{4}\geq 1
and
\lambda_{3}+\lambda_{4}\leq 1
cannot simultaneously hold. Therefore, no finite lower bound can be obtained for the second constraint, and every abstract output in the family defaults to
x-y\geq-\infty
for that row, effectively omitting it.

We write
O\in\mathcal{F}_{\mathcal{T}}
to indicate that
O
belongs to the parametric family
\mathcal{F}_{\mathcal{T}}
. Formally, this means that there exists a parameter tuple
\theta=(\theta_{1},\ldots,\theta_{t})
such that
O=\left\{\,\mathcal{T}_{i}\cdot\mathbf{v}\geq L_{i}^{\prime}(\theta_{i})\;\middle|\;i=1,\ldots,t\,\right\}
, where each
L_{i}^{\prime}(\theta_{i})
denotes the lower bound computed using the extended function defined in Def
4.6
. For a given operator
op
and input abstract element
\mathtt{a}_{\mathit{in}}
, we say that a parametric family
\mathcal{F}_{\mathcal{T}}
is
sound
if every abstract element
O\in\mathcal{F}_{\mathcal{T}}
is a sound output, that is, it over-approximates all reachable states resulting from executing
op
on any state in
\mathtt{a}_{\mathit{in}}
. We formalize this notion by comparing each bound against its corresponding component in the most-precise abstract output
\mathtt{a}_{\mathit{out}}^{\#}
defined in Eq.
2
, which represents the most precise sound over-approximation expressible in
\mathcal{T}
.

Definition 4.0 (Soundness of a Parametric Family).

Let
op
be a concrete operator applied to input
\mathtt{a}_{\mathit{in}}
. Let
\mathtt{a}_{\mathit{out}}^{\#}=\{\,\mathcal{T}_{i}\cdot\mathbf{v}\geq c_{i}^{\#}\mid i=1,\ldots,t\,\}
denote the most-precise output in template
\mathcal{T}
that is sound for
op
and
\mathtt{a}_{\mathit{in}}
. A parametric family
\mathcal{F}_{\mathcal{T}}=\{\,\mathcal{M}_{i}=(\Theta_{i},L_{i})\mid i=1,\ldots,t\,\}
is
sound
if for
op
and
\mathtt{a}_{\mathit{in}}
, for each
i
and all
\theta_{i}\in\mathbb{R}^{d_{i}}
, the instantiable lower bound satisfies
L_{i}(\theta_{i})\leq c_{i}^{\#}
.

Constructing the Parametric Family.

As discussed earlier, computing the most-precise abstract output requires solving the optimization problems defined in Eq.
2
, one for each template direction
\mathcal{T}_{i}
. These problems are of the form:

(3)

c_{i}^{\#}=\min_{\mathbf{v}\in\mathbb{R}^{n}}\hat{f}_{i}(\mathbf{v})\quad\text{subject to}\quad\mathbf{A}\mathbf{v}\leq\mathbf{b},

where
\hat{f}_{i}
is the effective objective induced by the semantics of the concrete operator
op
(see Def.
4.2
). While
c_{i}^{\#}
denotes the most-precise lower bound for the
i
-th constraint, computing it exactly can be prohibitively expensive. In practice, existing libraries typically rely on heuristics to compute a sound but imprecise lower bound. This reliance on a single fixed bound is highly restrictive. Thus, instead of computing a single fixed bound, we aim to represent a richer
space of sound finite lower bounds
for
c_{i}^{\#}
using a parametric abstraction. For each optimization problem arising from the effective objectives, we construct a Parameter Scalar Map
\mathcal{M}=(\Theta,L)
that compactly captures a space of candidate lower bounds for a given optimization problem. The map
\mathcal{M}
is
sound
for the problem if every value produced by
L
lies below the optimal value. We formalize this as follows:

Definition 4.0 (Soundness of a Parametric Scalar Map).

Given an optimization problem
o^{\star}=\min\{f(\mathbf{v})\mid\mathbf{A}\mathbf{v}\leq\mathbf{b}\}
over a concrete objective
f:\mathbb{R}^{n}\to\mathbb{R}
, a Parametric Scalar Map
\mathcal{M}=(\Theta,L)
is a
sound lower bound
if
L(\theta)\leq o^{\star}
for all
\theta\in\Theta
.

We use the procedure described in Appendix
A
to compute a sound Parametric Scalar Map
\mathcal{M}_{i}=(\Theta_{i},L_{i})
for each optimization problem. The algorithm applies to problems where the objective function is a polynomial of degree
\leq 2
, which holds in our case: the template directions
\mathcal{T}_{i}
are linear, and the update map
\sigma_{\leq 2}
yields polynomial expressions over the program variables
\mathcal{V}
with degree
\leq 2
. As a result, each effective objective
\hat{f}_{i}=\sum_{j=1}^{n}\mathcal{T}_{i,j}\cdot\sigma_{\leq 2}(v_{j})
is a polynomial over the variables
\mathcal{V}
with degree
\leq 2
. The construction procedure uses symbolic optimization techniques based on duality to derive a sound map
\mathcal{M}_{i}
for each
\hat{f}_{i}
, guaranteeing valid lower bounds even for non-convex objectives. The key insights underlying this derivation are as follows:

(1)

Duality with Domain-Aware Simplification:

To obtain sound lower bounds, we formulate the dual of the original optimization problem. Since abstract domains already provide tight variable bounds, we separate these box constraints from general constraints and construct the dual only over the latter. This yields a dual problem of the form:

\max_{\boldsymbol{\lambda}\geq 0}\;\;\min_{\mathbf{v}\in[\mathbf{l},\mathbf{u}]}\Big(\hat{f}_{i}(\mathbf{v})+\boldsymbol{\lambda}^{\top}(A\mathbf{v}-\mathbf{b})\Big)\,,

where
\hat{f}_{i}
is a (possibly non-convex) quadratic function over program variables. Some components of the box bounds
[\mathbf{l},\mathbf{u}]
may be infinite; in such cases, we enforce additional parameter constraints to ensure the inner minimum remains finite (see Appendix
A.1
for details). This box-constrained structure enables symbolic simplifications that are not available in general unconstrained or inequality-constrained quadratic problems.

(2)

Symbolic Decomposition via Coefficient Splitting:

The key technical insight is that although the inner minimization remains hard due to bilinear and indefinite quadratic terms, we can introduce symbolic parameters
(\mathbf{S},\mathbf{D})
that
redistribute linear coefficients
across different parts of the objective:

\hat{f}_{i}(\mathbf{v})+\boldsymbol{\lambda}^{\top}A\mathbf{v}\;\;\rightsquigarrow\;\;\sum_{i<j}(H_{ij}v_{i}v_{j}+D_{ij}^{i}v_{i}+D_{ij}^{j}v_{j})+\sum_{i}(Q_{i}v_{i}^{2}+S_{i}v_{i})+\text{residual}\,.

Here,
H_{ij}
and
Q_{i}
are the fixed coefficients from the original quadratic objective, while
D_{ij}^{i}
,
D_{ij}^{j}
, and
S_{i}
are the split parameters we introduce to control the distribution of linear terms.
This “coefficient splitting” rewrites the total objective into a sum of independent 1D and 2D subproblems, which can then be minimized efficiently in isolation (Appendix
A.2
). The decomposition is sound: by minimizing each subproblem independently, we obtain a lower bound on the original objective, ensuring soundness.

(3)

Tractable, Modular Evaluation of Subproblems:

Each resulting subproblem is now either a linear, bilinear, or quadratic expression over a small box (1D or 2D), which can be evaluated using closed-form expressions or cheap bounded minimization routines. During this evaluation, we also accumulate constraints that ensure the boundedness of each term. These constraints define the feasible parameter region
\Theta_{i}
, and the resulting symbolic expression yields the parametric bound function
L_{i}
(Appendix
A.3
).

Now, the parametric family of abstract outputs
\mathcal{F}_{\mathcal{T}}
is constructed directly from the sound Parametric Scalar Maps computed above. For each template direction
\mathcal{T}_{i}
, the corresponding effective objective
\hat{f}_{i}
yields a sound map
\mathcal{M}_{i}=(\Theta_{i},L_{i})
via the symbolic derivation procedure. Collectively, these
t
maps define the full family
\mathcal{F}_{\mathcal{T}}=\{(\Theta_{i},L_{i})\}_{i=1}^{t}
, as formalized in Definition
4.6
. We now establish the soundness of this family.

Theorem 4.10 (Soundness of the Constructed Parametric Family).

Let
\mathcal{F}_{\mathcal{T}}
given by
\{\mathcal{M}_{i}=(\Theta_{i},L_{i})\}_{i=1}^{t}
be the parametric family of abstract outputs constructed using the sound Parametric Scalar Maps for the effective objectives
\{\hat{f}_{i}\}_{i=1}^{t}
. Then
\mathcal{F}_{\mathcal{T}}
is sound with respect to the operator
op
and input abstract element
\mathtt{a}_{\mathit{in}}
, that is, every abstract element
o\in\mathcal{F}_{\mathcal{T}}
is a sound output.

Proof Sketch.

For each
i\in\{1,\ldots,t\}
, let
\mathcal{M}_{i}=(\Theta_{i},L_{i})
be the sound Parametric Scalar Map computed for the effective objective
\hat{f}_{i}
. By construction (Theorem
C.1
in Appendix), we have
\forall\,\theta_{i}\in\Theta_{i},\;L_{i}(\theta_{i})\leq c_{i}^{\#}
, where
c_{i}^{\#}
is the most-precise sound lower bound for
\hat{f}_{i}
as defined in Eq.
3
. Thus, the extended function
L_{i}^{\prime}
(Definition
4.6
) satisfies
L_{i}^{\prime}(\theta_{i})\leq c_{i}^{\#}\;\text{for all }\theta_{i}\in\mathbb{R}^{d_{i}}
since it assigns
-\infty
to parameters outside
\Theta_{i}
and satisfies
L_{i}(\theta_{i})\leq c_{i}^{\#}
within
\Theta_{i}
. This matches the condition required for soundness in Definition
4.8
, completing the proof.
∎

The construction above defines a sound parametric family of abstract outputs for a concrete operator
op
, which in turn induces a corresponding family of sound abstract transformers. Each instantiation of the parameters yields a concrete abstract output, thereby specifying a distinct transformer within the family. Crucially, this construction is domain-agnostic: it can be instantiated for any polyhedral numerical abstract domain and output template, eliminating the need to design custom transformer synthesis procedures for each domain. While this symbolic representation compactly captures a rich spectrum of transformers, generating the family alone is not sufficient. To make the abstraction practically useful, we must support efficient traversal of this space to identify outputs aligned with the precision and efficiency requirements of the downstream tasks. In the next section, we present a gradient-guided traversal strategy to address this challenge.

4.2.
Gradient-Guided Exploration of Parametric Transformers

We now discuss how to traverse a family of abstract outputs, denoted by
\mathcal{F}_{\mathcal{T}}=\{\mathcal{M}_{i}=\,(\Theta_{i},\,L_{i})\,\}_{i=1}^{t}
. The parameter space
\Theta_{i}
defines the set of finite lower bounds
\mathcal{L}_{i}
that the family can produce for the
i^{\text{th}}
template constraint, given by
\mathcal{L}_{i}=\{L_{i}(\theta_{i})\mid\theta_{i}\in\Theta_{i}\}
. An empty or infeasible
\Theta_{i}
indicates that no finite lower bound can be inferred for that constraint. Let
\mathcal{I}
denote the set of indices
i
for which
\Theta_{i}
is non-empty; these are the constraints for which parameter search is required to instantiate a bound. This search must be guided by the goals of the downstream analysis task, which determines how the parametric family should be instantiated. Different tasks, such as invariant inference, safety checking, etc., may impose distinct preferences on the output, including thresholds on runtime or desired precision-efficiency trade-offs. Consequently, we require flexible search procedures that allow downstream tasks to specify the two key components that guide the parameter search:

(1)

Search Objective (
\mathcal{J}
):
The search procedure should allow downstream tasks to specify a score function that serves as a proxy for measuring the
quality
of candidate outputs. For each constraint
i
, the score function
\mathcal{J}_{i}
assigns a quality score
\mathcal{J}_{i}(L_{i}(\theta_{i}))
to every possible lower bound in the set
\mathcal{L}_{i}=\{L_{i}(\theta_{i})\mid\theta_{i}\in\Theta_{i}\}
. These scores can then guide the search process by steering it toward parameter values
\theta_{i}
that yield more desirable outputs. Common examples of such score functions
\mathcal{J}_{i}
include:

(a)

Precision Objective:
In general program analysis settings, the primary objective is to infer the most precise invariants. In such cases, larger lower bounds are preferred, as they correspond to more precise abstract outputs. A suitable score function to serve as a proxy for measuring precision is
\mathcal{J}_{\mathit{prec}}(\theta_{i})=L_{i}(\theta_{i})
, so that maximizing
\mathcal{J}_{\mathit{prec}}
directly promotes larger lower bounds, thereby naturally guiding the search toward more precise invariants.

(b)

Inclusion Objective:
To check whether a given abstract element
\mathcal{E}=\{\mathcal{T}_{i}\cdot\mathbf{v}\geq e_{i}\}
lies within the parametric family, one can define a score function that measures how well a candidate
\theta_{i}
satisfies the inclusion condition
L_{i}(\theta_{i})\geq e_{i}
. A natural choice is the violation-based score
\mathcal{J}_{\mathit{inc}}(\theta_{i})=-\max(0,\,e_{i}-L_{i}(\theta_{i}))
, so that higher scores correspond to smaller violations and the maximum score is attained when
L_{i}(\theta_{i})\geq e_{i}
.

(2)

Runtime Control (
\mathcal{R}
):
The search procedure should expose mechanisms that allow downstream tasks to regulate the computational effort during search. This enables tasks with different runtime constraints to choose appropriate configurations. Examples of such controls can include interpretable internal parameters, such as the number of samples, gradient steps, or epochs, or more coarse-grained options like wall-clock timeouts. These mechanisms allow tasks to traverse the trade-off between runtime and quality of outputs by tuning the associated parameters.

Limitations of Existing Search Strategies.

A naive strategy is to randomly sample parameter values
\theta_{i}
from their respective spaces
\Theta_{i}
and use them to generate abstract outputs
O
from
\mathcal{F}_{\mathcal{T}}
. Runtime can be controlled by limiting the number of samples, and the best output is selected using the score function
\mathcal{J}
. While this approach offers effective runtime control, it is not
objective-aware
, as the search is unguided and often fails to prioritize high-quality outputs under
\mathcal{J}
. Moreover, when
\Theta_{i}
is high-dimensional or defined by complex constraints, sampling uniformly or meaningfully becomes increasingly difficult. On the other hand, a highly
objective-aware
strategy is to use solver-based optimization to directly maximize
\mathcal{J}_{i}(L_{i}(\theta_{i}))
over each
\Theta_{i}
. This explicitly targets the best output under the score, but is often expensive in practice: it requires solving one optimization problem per
i\in\mathcal{I}
, leading to many solver invocations. Although solvers provide timeout mechanisms, these apply per call, whereas downstream tasks typically impose a global runtime budget
\mathcal{R}
. When
\mathcal{R}
must be split across many calls, as is common for large programs with many template constraints, each receives little time, often yielding no feasible solution or outputs that poorly reflect the objective. In effect, random sampling offers controllable runtime but lacks objective guidance, while solver-based optimization provides strong objective awareness but limited practical control over runtime. Neither approach offers the scalability, targeted search, and flexible runtime control needed in our setting.

Gradient-Guided Exploration over Parameter Space.

To balance objective-awareness with runtime controllability, an ideal search procedure should progressively move toward regions in parameter space associated with higher-scoring outputs under the objective
\mathcal{J}_{i}
. A gradient-guided search naturally fits this goal: it supports incremental improvement, avoids expensive solver calls or exhaustive enumeration, and improves output quality as more runtime becomes available. In our setting, this approach is especially well-suited. Each output
L_{i}(\theta_{i})
is differentiable (Theorem
C.5
in Appendix), and the parameter space
\Theta_{i}
is a polyhedron defined by
\{\mathbf{A}_{i}\theta_{i}\leq\mathbf{b}_{i}\}
(Theorem
C.4
in Appendix). In many practical tasks (like the ones discussed above), the score function
\mathcal{J}_{i}
can be formulated as a differentiable objective, allowing us to navigate the output space
\mathcal{L}_{i}=\{L_{i}(\theta_{i})\mid\theta_{i}\in\Theta_{i}\}
by following the gradient
\nabla\mathcal{J}_{i}(L_{i}(\theta_{i}))
at each step. This yields an iterative procedure in which the number of gradient steps (or epochs) provides a natural and fine-grained knob for controlling the runtime
\mathcal{R}
. Unlike solver-based approaches, which require separate invocations per
\theta_{i}
, gradient descent supports unified, joint optimization across all template constraints. Each update is guided by the objective rather than random, progressively improving output quality within the available budget.

While gradients offer a natural direction for search, applying descent-based methods in our setting presents several challenges. We aim to solve the constrained optimization problem:

\max_{\theta\in\Theta}\;\mathcal{J}(L(\theta))\quad\text{where}\quad\Theta=\{\theta\in\mathbb{R}^{d}\mid\mathbf{A}\theta\leq\mathbf{b}\},

with
\mathcal{J}
denoting a task-specific score and
L
a differentiable output map. A naive gradient step
\theta\leftarrow\theta+\eta\nabla\mathcal{J}(L(\theta))
(with learning rate
\eta
) may leave the feasible region
\Theta
. A standard fix is
projected gradient descent (PGD)
, which projects back onto
\Theta
after each update. However, for general polyhedral
\Theta
, this projection requires solving a quadratic (or linear) program, and repeated solves across many constraints quickly become a bottleneck. Penalty-based methods avoid projection by replacing the constrained problem with an unconstrained one:

\max_{\theta\in\mathbb{R}^{d}}\;\mathcal{J}(L(\theta))-\beta\cdot\left\|\max(\mathbf{A}\theta-\mathbf{b},0)\right\|_{p},

where
\beta
is a large penalty constant. But this requires
\mathcal{J}(L(\theta))
to be well-defined for all
\theta\in\mathbb{R}^{d}
, which is not the case in our setting: the output map
L(\theta)
is only defined over
\Theta
, making penalized objectives ill-posed once iterates leave the feasible region. Barrier methods (e.g., log-barrier or interior-point techniques) enforce feasibility by penalizing points that approach the boundary of
\Theta
, thereby keeping iterates strictly inside the feasible region. However, these methods require a strictly feasible starting point, typically obtained via a separate solver call, and involve solving large linear systems at each iteration. Both requirements make them impractical in our setting, where the search must scale across many template constraints without significant solver overhead.

To overcome these challenges, we propose a lightweight, projection-free strategy that avoids solver calls and does not require a strictly feasible starting point. Our method, which we call
Adaptive Gradient Guidance (AGG)
, adaptively chooses the update direction based on whether the current point
\theta
lies inside or outside the feasible region
\Theta=\{\theta\mid\mathbf{A}\theta\leq\mathbf{b}\}
. When
\theta
is feasible, we ascend along the gradient of the score to improve output quality. When
\theta
is infeasible, we ignore the score and instead descend along a penalty gradient that reduces constraint violation to get back to the feasible region. Formally, each update takes the form:

\theta\leftarrow\theta+\eta\cdot\begin{cases}\nabla\mathcal{J}(L(\theta))&\text{if }\theta\in\Theta,\\
-\beta\cdot\nabla\left\|\max(\mathbf{A}\theta-\mathbf{b},0)\right\|_{p}&\text{otherwise},\end{cases}

where
\eta
is the step size and
\beta
is a large penalty weight. This rule enables our procedure to make objective-aware progress whenever possible, while steering infeasible iterates back toward the feasible region without requiring projections or solver-assisted initialization. Our algorithm (
Algorithm 1
in Appendix) starts the search with all parameter values set to zero. By Theorem
C.2
(Appendix), this corresponds to the transformer obtained via interval relaxation, ensuring that our search procedure always performs at least as well as the interval relaxation baseline. We then apply the AGG update rule iteratively, tracking feasible parameter values that improve upon the current best according to the score function. After running for the specified number of epochs, the best-performing feasible parameters are returned, corresponding to the highest-scoring output found during the search. By Theorem
C.3
(Appendix), we show that for linear operators, the parametric transformer space contains all sound transformers. This ensures that the best transformer for any score function
\mathcal{J}
lies within the space; for instance, when optimizing for precision, the most-precise transformer is included in the space.
In Section
6.2
, we demonstrate that our gradient-guided traversal successfully finds this most-precise transformer as well.

5.1.
Merging Admissible Instruction Sequences into Blocks

Abstract interpretation is inherently
non-compositional
: analyzing a fragment instruction-by-instruction and composing the results is often less precise than analyzing the whole. In particular, in sequential regions like basic blocks or loop bodies, semantic dependencies between instructions can be missed, leading to imprecise abstractions. Still, existing frameworks like Clam typically analyze programs instruction-by-instruction, as implementing abstract transformers for entire instruction sequences is generally challenging. To overcome this, our framework enables analyzing certain
sequences of assignments
together as atomic blocks. Let
S
denote such a sequence, and let
\mathcal{B}(S)
represent the corresponding program block. Our framework supports the joint analysis of a specific class of blocks, which we refer to as
Quadratic-Bounded Blocks
.

Definition 5.0 (Quadratic-Bounded Block).

Let
\mathcal{B}(S)
be a block consisting of a sequence of assignments over a set of program variables
\mathcal{V}
. Let
\mathcal{A}\subseteq\mathcal{V}
denote the subset of variables that are updated by
\mathcal{B}(S)
, and let
\sigma:\mathcal{V}\to\mathbb{P}(\mathcal{V})
denote its Effective Update Map. We say that
\mathcal{B}(S)
is
quadratic-bounded
if, for every assigned variable
v\in\mathcal{A}
, the expression
\sigma(v)
lies in the set of polynomials of degree at most two over
\mathcal{V}
, denoted
\mathbb{P}_{\leq 2}(\mathcal{V})
. In other words,
\mathcal{B}(S)
is quadratic-bounded if its Effective Update Map
\sigma
is a quadratic-bounded update map.

Example 5.0.

Consider the sequence
\mathcal{S}_{1}:\{x:=a+b;\;y:=x\cdot c\}
. Its block
\mathcal{B}(\mathcal{S}_{1})
is
Quadratic-Bounded
, since flattening gives
\sigma(x)=a+b
and
\sigma(y)=(a+b)\cdot c
, both of which are degree-two polynomials. In contrast, the block for sequence
\mathcal{S}_{2}:\{x:=a+b;\;y:=x\cdot c;\;z:=y\cdot a\}
is not Quadratic-Bounded, since flattening yields
\sigma(z)=(a+b)\cdot a\cdot c
, which is a degree-three polynomial.

Quadratic-Bounded Blocks form a subclass of the broader Quadratic-Bounded Guarded Operator (QGO) class. Our framework constructs a parametric family of sound abstract transformers for such blocks using the techniques introduced earlier. This block-level reasoning generalizes instruction-wise interpretation by leveraging the compositional structure of assignment sequences and eliminating intermediate variables, leading to improved precision and performance. To enable this, the framework identifies and merges assignment sequences that form
Quadratic-Bounded Blocks
, treating them as single compositional units.

Definition 5.0 (Admissible Instruction Sequences).

A sequence of instructions
\mathcal{S}
is
admissible
if it consists only of affine and quadratic assignments, and the corresponding block
\mathcal{B}(\mathcal{S})
is quadratic-bounded (Definition
5.1
).

USTAD
(Algorithm
3

5.2.
Abstract Interpretation on the Transformed Program

After merging each admissible instruction sequence
\mathcal{S}
into a block
\mathcal{B}(\mathcal{S})
and computing its Effective Update Map (EUM)
\sigma_{\mathcal{B}(\mathcal{S})}
,
USTAD
rewrites the control-flow graph by replacing the block
\mathcal{B}(\mathcal{S})
with its corresponding EUM. This transforms the original program
\mathcal{P}
into a new program
\mathcal{P}^{\prime}
, where each admissible sequence is collapsed into a single block
\mathcal{B}
, while other instructions remain unchanged. Abstract interpretation is then performed on
\mathcal{P}^{\prime}
. Standard transfer functions are used for non-merged instructions, while for each block
\mathcal{B}(\mathcal{S})
,
USTAD
constructs a parametric family of sound transformers using the approach from Section
4.1
, and selects one of these using the gradient-guided search procedure from Section
4.2
, with search objective set to guide towards more precise invariants. This search is controlled by user-configurable parameters such as step size
\eta
, number of epochs
R
, etc., used by the traversal algorithm (
Algorithm 1
in Appendix).

Let
\llbracket\cdot\rrbracket
denote the concrete semantics of a program, i.e., the set of reachable states under standard big-step execution. The soundness of our abstract interpretation over
\mathcal{P}
follows from two components. First, for each block
\mathcal{B}(\mathcal{S})
,
USTAD
constructs a family of sound transformers using the method from Section
4.1
, ensuring that the abstract state
\mathcal{A}^{\prime}
computed for the transformed program
\mathcal{P}^{\prime}
satisfies
\llbracket\mathcal{P}^{\prime}\rrbracket\subseteq\gamma(\mathcal{A}^{\prime})
. Second, by
Theorem C.6
in Appendix, the EUM-based transformation is sound at the concrete level, i.e.,
\llbracket\mathcal{P}\rrbracket\subseteq\llbracket\mathcal{P}^{\prime}\rrbracket
. Together, these imply that
\llbracket\mathcal{P}\rrbracket\subseteq\gamma(\mathcal{A}^{\prime})
, and hence our analysis yields a sound over-approximation of the original program
\mathcal{P}
.

6.
Evaluation

Research Questions.

We evaluate our approach using the following research questions :

RQ1:
Is our universal transformer synthesis algorithm able to generate a parametric family of sound abstract transformers that offers varying trade-offs between precision and runtime efficiency across diverse numerical domains?

RQ2:
How effective is our gradient-guided search procedure at traversing the parametric family to identify transformers that optimize downstream analysis objectives, such as maximizing precision?

RQ3:
Are there precision benefits to reasoning jointly over sequences of assignments, as opposed to treating each assignment in isolation?

Benchmarks & Setup.

We conduct all experiments using our
USTAD
framework (Sec.
5
), and use the Clam analyzer along with ELINA, a state-of-the-art library for numerical abstract domains, as the baseline. All experiments were run on a machine with 48-core Intel Xeon Silver 4214R CPUs @ 2.40GHz, 187 GiB RAM, and Ubuntu 22.04.5 LTS. We use the 57 programs from the
NLA-Digbench
subset of SV-COMP as benchmarks, as they consist of numerical programs and involve polynomial numerical invariants, well aligned with the focus of our approach. These benchmarks have both isolated affine and bilinear assignments, as well as sequences of such assignments. This makes the benchmark challenging for baseline libraries, as they compute imprecise invariants due to imprecise handling of such assignments, and allows us to evaluate the benefits of our approach, which provides a way to handle such assignments,
as well as
sequences of such assignments. We use the
USTAD
framework to analyze the programs in the benchmarks for three popular numerical domains, Zones, Octagons, and Polyhedra. The framework constructs parametric families of transformers for each assignment block and uses specified parameters such as the step size
\eta
and the number of epochs
R
to traverse the family and select a suitable transformer. In our experiments, we fix the step size to
\eta=0.5
and vary the number of epochs across runs. We keep a timeout of 200s for each program. We evaluate the resulting transformers using the following two metrics:

(1)

Number of invariants strengthened:

We use our
USTAD
framework with different configurations to analyze the benchmark programs. The Clam analyzer computes invariants, which are abstract elements in the chosen numerical domain that capture possible program states at each program point. This metric counts how many of these invariants are strictly improved compared to those produced by the baseline ELINA transformers. An invariant
\mathtt{a}^{\prime}
is considered stronger than
\mathtt{a}
if
\gamma(\mathtt{a}^{\prime})\subsetneq\gamma(\mathtt{a})
. This is a standard practice in abstract interpretation
(
He et al. 2020
)
and provides a more fine-grained and continuous view of how precision evolves as we traverse the family of transformers, capturing improvements that may not be reflected in binary assertion checks.

(2)

Number of new constraints inferred:

Invariants are sets of constraints over program variables and can be strengthened either by tightening existing bounds or by inferring entirely new constraints not present in the baseline. This metric counts the number of such new constraints inferred across all invariants, relative to those produced by the baseline. It provides a finer-grained view of improvement: even if the number of strengthened invariants remains the same, more new constraints indicate increased precision. We use this instead of volume-based measures, as they are difficult to apply to unbounded elements.

Related Works

Improving the efficiency of numerical abstract domains without compromising their precision has become a prominent research direction in recent years
(
Chawdhary and King 2018
;
Chawdhary et al. 2019
;
Gange et al. 2016
;
Jourdan 2017
;
Maréchal et al. 2017
;
Singh et al. 2017a
;
Yu and Monniaux 2019
;
Zhang et al. 2014
;
Zhang et al. 2013
;
Yao et al. 2021
)
. One of the prominent approaches is online decomposition
(
Cousot et al. 2019
;
Singh et al. 2017a
)
, which offers a domain-independent strategy to enhance scalability across various abstract domains.
USTAD
is compatible with this approach.
(
Gange et al. 2021
)
designs custom sparse algorithms to optimize the runtime of Zones and Octagons domains, obtaining the same precision as ELINA. Their method does not apply to general polyhedral domains as
USTAD
. In parallel, researchers have explored machine learning-based heuristics that intentionally sacrifice some degree of precision to achieve better performance
(
Heo et al. 2016
;
Heo et al. 2019
;
Oh et al. 2015
;
Singh et al. 2018
)
. Among these approaches,
(
Heo et al. 2016
;
Oh et al. 2014
)
employ a static partitioning strategy, whereas
(
Singh et al. 2015
;
Singh et al. 2017b
)
use a dynamic partitioning approach to accelerate the analysis while aiming to preserve the precision of the original method.
(
Heo et al. 2019
;
Oh et al. 2015
)
select a subset of variables for tracking, aiming to improve the analysis speed for non-relational domains such as Intervals. Similarly, for relational domains like Octagon and Polyhedra,
(
Singh et al. 2018
;
He et al. 2020
)
applies reinforcement learning to reduce analysis runtime while minimizing loss of precision. Unlike prior approaches that trade precision for improved runtime, our method introduces a general technique for dynamically enhancing precision using gradient descent, with minimal runtime overhead.
USTAD
transforms fast but typically unreliable first-order optimization methods e.g. gradient descent (which lack guarantees of finding the optimum) into a reliable mechanism for designing sound and precise block-wise abstract transformers, while avoiding the computational blowup commonly seen in solver-based approaches
(
Jiang et al. 2017
)
.

For abstract interpretation, to the best of our knowledge, gradient descent–based approaches have previously been used only for verifying neural networks
(
Wang et al. 2021
;
Xu et al. 2021
;
Ferrari et al. 2022
)
. However, these methods focus on hand-crafted, parametric abstract transformers tailored specifically to the non-linear ReLU (Rectified Linear Unit) operation used in neural networks. Moreover, they rely on input specifications expressed as bounded intervals, whereas program analysis often involves domains that are unbounded and have relational constraints among variables. While recent GPU-based verifiers
(
Banerjee and Singh 2024
;
Suresh et al. 2024
)
support relational domains such as DiffPoly
(
Banerjee et al. 2024
)
, which tracks differences between pairs of variables, they are still limited to bounded settings. In contrast,
USTAD
provides a generalized framework that supports a wide range of unbounded relational domains, subsuming these existing methods. Beyond gradient descent, a variety of techniques have been used to improve solvers from the perspective of program analysis and verification. These include incorporating domain-specific objectives
(
Li et al. 2014
)
, learning branching heuristics for MILP solvers
(
Balcan et al. 2018
)
, and designing tactics for SMT solvers
(
Balunović et al. 2018
)
.
Alternatively,
(
Kalita et al. 2022
;
Kalita et al. 2025
)
synthesize abstract transformers based on a user-provided DSL.
(
Laurel et al. 2023
;
Paulsen and Wang 2022
)
trains neural networks to serve as abstract transformers for specific non-linear operations, although their approach is restricted to bounded abstract elements.

8.
Conclusion

We introduce
USTAD
that constructs a tunable, domain-agnostic family of sound transformers for a broad class of operators, unifying transformer generation across structurally similar domains. Combined with our Adaptive Gradient Guidance (AGG) strategy for efficient, objective-driven exploration of this space, our approach enables precise and flexible program analysis that adapts to specific block of statements and the abstract program state.
USTAD
builds on gradient descent, an approach that has demonstrated unprecedented scalability in domains such as machine learning, while preserving soundness. This potentially opens promising directions for future work on scalable program analysis methods that utilize customized hardware accelerators such as GPUs.

Appendix A
Duality-based construction of Sound Parametric Scalar Map

Our algorithm to generate a parametric family of sound transformers relies on finding a sound Parametric Scalar Map (PSM) (Def
4.5
) for the optimal value
o_{\min}
of optimization problems of the form:

(4)

o_{\min}\;=\;\min_{\mathbf{v}\in\mathbb{R}^{n}}\;f(\mathbf{v})\quad\text{s.t.}\quad A\,\mathbf{v}\leq\mathbf{b}\,

where the objective function
f(\mathbf{v})
is of the form:

(5)

f(\mathbf{v})=\sum_{1\leq i<k\leq n}H_{ik}\,v_{i}v_{k}+\sum_{i=1}^{n}Q_{i}\,v_{i}^{2}+\mathbf{c}^{\top}\mathbf{v}+d

Here,
H_{ik}\,v_{i}v_{k}
denotes the bilinear terms (products of distinct variables),
Q_{i}\,v_{i}^{2}
denotes the quadratic terms,
c_{i}\,v_{i}
denotes the linear terms, and
d\in\mathbb{R}
is a constant.

Soundness criterion.

A scalar
\ell
is a
sound lower bound
on the optimal value
o_{\min}
whenever
\ell\leq o_{\min}
.

We obtain a sound Parametric Scalar Map for Eq
4
through the following steps.

A.1.
Step 1: Efficient Dual Construction

As our goal is to obtain certified
lower bounds
on the primal optimum
o_{\min}
for the problem in Eq
4
, we turn to its Lagrangian dual, because weak duality guarantees that any feasible value of the dual function is a lower bound. Introducing non-negative multipliers
\boldsymbol{\lambda}\!\geq 0
for the constraints
A\mathbf{v}\leq\mathbf{b}
in the problem in Eq
4
yields the following re-formulation of the same problem:

o_{\min}\;=\;\min_{\mathbf{v}\in\mathbb{R}^{n}}\,\max_{\boldsymbol{\lambda}\geq 0}\bigl(f(\mathbf{v})+\boldsymbol{\lambda}^{\top}(A\mathbf{v}-\mathbf{b})\bigr)

Swapping the order of optimization produces the dual problem

o_{\text{dual}}\;=\;\max_{\boldsymbol{\lambda}\geq 0}\,\underbrace{\min_{\mathbf{v}\in\mathbb{R}^{n}}\bigl(f(\mathbf{v})+\boldsymbol{\lambda}^{\top}(A\mathbf{v}-\mathbf{b})\bigr)}_{g(\boldsymbol{\lambda})}

where
g(\boldsymbol{\lambda})
is the
dual function
. By weak duality

g(\boldsymbol{\lambda})\;\leq\;o_{\min}\quad\text{for every }\boldsymbol{\lambda}\geq 0

Consequently, if we can compute the inner minimization
g(\boldsymbol{\lambda})
for a given
\boldsymbol{\lambda}\!\geq 0
, then inserting
any
such multiplier values produces a sound lower bound, thus giving us the desired parametric family of bounds.

Inefficiency of the naive dual construction.

Before evaluating the dual function
g(\boldsymbol{\lambda})
, note that
constructing the dual from the entire constraint set
A\mathbf{v}\leq\mathbf{b}

is unnecessarily costly. The abstract input element—like most numerical
abstract domains—already contains tight
box constraints

l_{i}\leq v_{i}\leq u_{i}
. Including these bounds in the dual construction
introduces two Lagrange multipliers per variable, inflating the dual vector
and increasing the cost of every evaluation of
g
. A standard remedy is to
peel off
the box constraints first: one rewrites the feasible region as
\mathbf{v}\in[l,u]
together with the remaining
coupled inequalities, and constructs the dual only for the latter. The inner minimisation then becomes a box-constrained problem, which typically admits a closed-form solution or a very cheap projection step
(
Bertsekas 1999
, Ch. 1)
;
(
Nocedal and Wright 2006
, Ch. 17)
. This strategy keeps the dual compact, reduces the cost of computing
g(\boldsymbol{\lambda})
, and accelerates the subsequent maximisation over
\boldsymbol{\lambda}\!\geq 0
.

So, we isolate tight lower and upper bounds for each variable from the constraint system
A\mathbf{v}\leq\mathbf{b}
. This yields a bounding box
\mathbf{v}\in[\mathbf{l},\mathbf{u}]
, where
l_{i}\leq v_{i}\leq u_{i}
for each
i
. (Some bounds may be unbounded, i.e.
l_{i}=-\infty
or
u_{i}=+\infty
, depending on the original constraints.) Removing these trivial bounds from the coupled inequalities leaves a reduced system

A^{\prime}\mathbf{v}\leq\mathbf{b}^{\prime}
. The optimization problem is therefore equivalent to

(6)

o_{\min}\;=\;\min_{\mathbf{v}\in[\mathbf{l},\mathbf{u}]}\;f(\mathbf{v})\quad\text{s.t.}\quad A^{\prime}\mathbf{v}\leq\mathbf{b}^{\prime}

where the box constraint is handled explicitly and only the coupled inequalities are retained in
A^{\prime}\mathbf{v}\leq\mathbf{b}^{\prime}
. Introducing non-negative multipliers
\boldsymbol{\lambda}\!\geq 0
for the constraints
A^{\prime}\mathbf{v}\leq\mathbf{b^{\prime}}
in the problem in Eq
6
yields the following re-formulation:

(7)

o_{\min}\;=\;\min_{\mathbf{v}\in[\mathbf{l},\mathbf{u}]}\;\max_{\boldsymbol{\lambda}\geq 0}\bigl(f(\mathbf{v})+\boldsymbol{\lambda}^{\top}(A^{\prime}\mathbf{v}-\mathbf{b}^{\prime})\bigr)

Swapping the order of optimization then produces the dual problem

(8)

o_{\text{dual}}\;=\;\max_{\boldsymbol{\lambda}\geq 0}\,\underbrace{\min_{\mathbf{v}\in[\mathbf{l},\mathbf{u}]}\bigl(f(\mathbf{v})+\boldsymbol{\lambda}^{\top}(A^{\prime}\mathbf{v}-\mathbf{b}^{\prime})\bigr)}_{g(\boldsymbol{\lambda})}

where
g(\boldsymbol{\lambda})
is the
dual function
. Now, as discussed above, by weak duality, every value
g(\boldsymbol{\lambda})
with
\boldsymbol{\lambda}\geq 0
is a certified lower bound on
o_{\min}
. Henceforth, we focus on evaluating this dual function efficiently: once we can compute
g(\boldsymbol{\lambda})
for any chosen multiplier, we immediately obtain an entire parametric family of sound bounds.

Substituting
f(\mathbf{v})
from Eq. (
5
):

g(\boldsymbol{\lambda})\;=\;\min_{\mathbf{v}\in[\mathbf{l},\mathbf{u}]}\;\left(\sum_{1\leq i<k\leq n}H_{ik}\,v_{i}v_{k}\;+\;\sum_{i=1}^{n}Q_{i}\,v_{i}^{2}\;+\;(\mathbf{c}+A^{\prime T}\lambda)^{T}\mathbf{v}\;+\;d-\lambda^{T}\mathbf{b}^{\prime}\right)\

Note, however, that this inner problem is still far from trivial: even with the simple box constraint, the presence of arbitrary bilinear terms
H_{ik}v_{i}v_{k}
and potentially indefinite quadratic coefficients
Q_{i}
turns the minimisation into a general (and possibly non-convex) quadratic programme, so an exact closed-form solution for
g(\boldsymbol{\lambda})
is not available in general.

A.2.
Step 2: Sound inner minimisation via linear coefficient splitting

We now discuss how to make the inner minimisation problem
tractable
. The idea is to redistribute each linear coefficient between its associated quadratic and bilinear terms so that the objective can be broken into one– and two–variable “boxes” that can be optimised independently.

Step 1: Introduce splitting parameters.

Pick auxiliary vectors
\mathbf{S}\in\mathbb{R}^{n}
and

\mathbf{D}\in\mathbb{R}^{n\times n}
and rewrite

g(\boldsymbol{\lambda})
as

\displaystyle g(\boldsymbol{\lambda})=g(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})=\min_{\mathbf{v}\in[\mathbf{l},\mathbf{u}]}\Bigl(

\displaystyle\sum_{1\leq i<k\leq n}\bigl(H_{ik}v_{i}v_{k}+D_{ik}^{i}v_{i}+D_{ik}^{k}v_{k}\bigr)

\displaystyle+\sum_{i=1}^{n}\bigl(Q_{i}v_{i}^{2}+S_{i}v_{i}\bigr)

\displaystyle+\bigl(\mathbf{c}+A^{\top}\lambda-\mathbf{S}-\boldsymbol{\Delta}\bigr)^{\!\top}\mathbf{v}+d-\lambda^{\top}\mathbf{b}\Bigr),

where
\Delta_{i}:=\sum_{k\neq i}D_{ik}^{i}
and

\boldsymbol{\Delta}:=(\Delta_{1},\dots,\Delta_{n})^{\top}
.
For any fixed
(\mathbf{S},\mathbf{D})
this is algebraically identical to the
original
g(\boldsymbol{\lambda})
; only the grouping of the linear terms has changed.

Step 2: Minimise each box separately.

Splitting the objective term-wise yields the relaxed value

\displaystyle\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})=\;

\displaystyle\sum_{1\leq i<k\leq n}\min_{(v_{i},v_{k})\in[l_{i},u_{i}]\times[l_{k},u_{k}]}\bigl(H_{ik}v_{i}v_{k}+D_{ik}^{i}v_{i}+D_{ik}^{k}v_{k}\bigr)

\displaystyle+\sum_{i=1}^{n}\min_{v_{i}\in[l_{i},u_{i}]}\bigl(Q_{i}v_{i}^{2}+S_{i}v_{i}\bigr)

(9)

\displaystyle+\min_{\mathbf{v}\in[\mathbf{l},\mathbf{u}]}\bigl(\mathbf{c}+A^{\top}\lambda-\mathbf{S}-\boldsymbol{\Delta}\bigr)^{\!\top}\mathbf{v}+d-\lambda^{\top}\mathbf{b}.

Step 3: Soundness of the relaxation.

For any family
\{h_{j}\}
on a common domain
\mathcal{X}
,

(10)

\min_{x\in\mathcal{X}}\sum_{j}h_{j}(x)\;\geq\;\sum_{j}\min_{x\in\mathcal{X}}h_{j}(x),

so applying (
10
) to (
9
) gives

(11)

\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})\;\leq\;g(\boldsymbol{\lambda})\;\leq\;o_{\min},\qquad\text{for all }\boldsymbol{\lambda}\geq 0,\;\mathbf{S},\;\mathbf{D}.

Intuition.

The split yields
n(n\!-\!1)/2
two-variable boxes,
n
single-variable boxes, and one residual linear box.
Each box now contains only a single quadratic, bilinear, or linear term, so every sub-problem is straightforward to minimise.
Summing their minima gives the relaxed value
\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
, which remains a sound lower bound as discussed above.

A.3.
Step 3: Efficient Evaluation of Bilinear, Quadratic, and Linear Terms

We have established that
\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
is a sound lower bound for every
(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
with
\boldsymbol{\lambda}\geq 0
, regardless of the particular choices of
\mathbf{S}
and
\mathbf{D}
.
Equivalently, we can view
(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
as a parameter vector and
\Theta
as the feasible parameter space

\Theta\;=\;\{\;(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})\in\mathbb{R}^{m}\times\mathbb{R}^{n}\times\mathbb{R}^{n\times n}\;\mid\;\boldsymbol{\lambda}\geq 0\;\}\,,

so that for every parameter in
\Theta
we obtain a finite, certified bound
\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})\leq o_{\min}
.

Next, we describe how to
compute

\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
efficiently.
For fixed
(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
, the relaxed objective decomposes into independent one- and two-dimensional subproblems.
By solving each subproblem separately and summing their optimal values, we obtain the value of
\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
and, at the same time, we update the feasible parameter space
\Theta
to reflect any additional constraints discovered during this process. More concretely, the value of
\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
is obtained by solving the following one- and two-dimensional subproblems for each class of terms:

(1)

Bilinear terms:
Consider a general bilinear subproblem (assume
A\neq 0
as only such terms occur when we split the objective):

\min_{(v_{i},v_{k})\in[l_{i},u_{i}]\times[l_{k},u_{k}]}\Big(A\,v_{i}v_{k}+B\,v_{i}+C\,v_{k}\Big)\,.

If we look at
\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
in Eq (
9
), we see that
B
and
C
depend on the parameters
\mathbf{D}
introduced in our splitting (and
A
is a fixed constant), so the conditions derived below give rise to corresponding constraints that we add to the parameter set
\Theta
:

\Theta\;\leftarrow\;\Theta\;\cap\;\{\text{new sign or bound constraint}\}\,.

First, we rewrite:

A\,v_{i}v_{k}+B\,v_{i}+C\,v_{k}\;=\;\big(A\,v_{i}+C\big)\Big(v_{k}+\frac{B}{A}\Big)-\frac{BC}{A}\,,

so that the product is between two affine terms with intervals:

A\,v_{i}+C\in\begin{cases}[A\,l_{i}+C,\;A\,u_{i}+C]\,,&A\geq 0\,,\\[3.00003pt]
[A\,u_{i}+C,\;A\,l_{i}+C]\,,&A<0\,,\end{cases}\qquad v_{k}+\frac{B}{A}\in[l_{k}+B/A,\;u_{k}+B/A]\,.

Setting

l_{1}:=\min(A\,l_{i}+C,\;A\,u_{i}+C),\qquad u_{1}:=\max(A\,l_{i}+C,\;A\,u_{i}+C),

l_{2}:=l_{k}+\frac{B}{A},\qquad u_{2}:=u_{k}+\frac{B}{A}\,,

the value extreme products are
\min(\{\,l_{1}l_{2},\;l_{1}u_{2},\;u_{1}l_{2},\;u_{1}u_{2}\,\})-BC/A
.

There are four configurations in which one of these corner-products may diverge to
-\infty
:

(a)

l_{1}=-\infty
and
u_{2}>0
,

(b)

l_{2}=-\infty
and
u_{1}>0
,

(c)

u_{1}=+\infty
and
l_{2}<0
,

(d)

u_{2}=+\infty
and
l_{1}<0
.

If in any of these cases the corresponding paired bound is also unbounded (e.g.
u_{2}=+\infty
,
u_{1}=+\infty
,
l_{2}=-\infty
, or
l_{1}=-\infty
, respectively), then the objective is unbounded and cannot yield a finite lower bound. In this situation we add the contradictory constraint

\Theta\;\leftarrow\;\Theta\;\cap\;\{\,0\leq-1\,\}\,,

rendering the parameter set infeasible so that the resulting subproblem value is
-\infty
.

If, instead, the paired bound is finite, we add the appropriate sign constraint (
u_{2}\leq 0
,
u_{1}\leq 0
,
l_{2}\geq 0
, or
l_{1}\geq 0
) to
\Theta
:

\Theta\;\leftarrow\;\Theta\;\cap\;\{\text{the corresponding bound constraint}\}\,,

so that the problematic product cannot become negatively unbounded.

Once all such constraints have been added to
\Theta
, the bilinear subproblem is well-posed. Its optimal value is then

l_{\mathrm{bilin}}\;:=\;\min\{\,l_{1}l_{2},\;l_{1}u_{2},\;u_{1}l_{2},\;u_{1}u_{2}\,\}\;-\;\frac{BC}{A}\,,

which is finite if the constraints are satisfied. Otherwise, if the constraints cannot be satisfied, this subproblem value is
-\infty
.

(2)

Quadratic terms:
Consider a general quadratic subproblem (assume
A\neq 0
as only such terms occur after splitting the objective):

\min_{v_{i}\in[l_{i},u_{i}]}\;\Big(A\,v_{i}^{2}+B\,v_{i}\Big)\,,

where
B
depends on the splitting parameters
\mathbf{S}
, so the conditions derived below give rise to corresponding constraints that we add to
\Theta
:

\Theta\;\leftarrow\;\Theta\;\cap\;\{\text{new constraint}\}\,.

•

If
A>0
(convex), we first compute the unconstrained minimizer

v_{i}^{*}:=-\frac{B}{2A}\,.

v_{i}^{*}
is the global minimizer. If
v_{i}^{*}\in[l_{i},u_{i}]
, the objective value is

l_{\mathrm{quad}}:=A\,(v_{i}^{*})^{2}+B\,v_{i}^{*}\,,

which is finite. If
v_{i}^{*}\notin[l_{i},u_{i}]
, then the minimizer lies at one of the endpoints. Moreover, the unconstrained minimizer cannot lie outside the box if both bounds were truly unbounded (i.e.
l_{i}=-\infty
and
u_{i}=+\infty
), so at least one of the endpoints is finite. Thus, we can always evaluate the objective at the finite endpoint(s) and take the smaller value.

l_{\mathrm{quad}}:=\min\{\,A\,l_{i}^{2}+B\,l_{i},\;A\,u_{i}^{2}+B\,u_{i}\,\}\,,

which is finite.

•

If
A<0
(concave), then the objective can decrease without bound unless both
l_{i}
and
u_{i}
are finite.
More precisely:

–

If
l_{i}=-\infty
, then as
v_{i}\to-\infty
we have
A\,v_{i}^{2}\to-\infty
.

–

If
u_{i}=+\infty
, then as
v_{i}\to+\infty
we have
A\,v_{i}^{2}\to-\infty
.

In either of these cases the subproblem is unbounded below, so we add the contradictory constraint

\Theta\;\leftarrow\;\Theta\;\cap\;\{\,0\leq-1\,\}\,,

rendering the parameter set infeasible and the subproblem value
-\infty
.
If both
l_{i}
and
u_{i}
are finite, we evaluate at the two endpoints and take

l_{\mathrm{quad}}:=\min\{\,A\,l_{i}^{2}+B\,l_{i},\;A\,u_{i}^{2}+B\,u_{i}\,\}\,,

which is finite.

(3)

Linear terms:
Consider the subproblem

\min_{\mathbf{v}\in[\mathbf{l},\mathbf{u}]}\;\mathbf{c}^{\top}\mathbf{v}+d

We compute the value of this objective variable-wise. That is, for each term
c_{i}\cdot v_{i}
where
v_{i}\in[l_{i},u_{i}]
, we compute its minimum contribution
L_{i}
and determine a corresponding set of constraints
\Theta_{i}
on the parameters (i.e., on the coefficients
c_{i}
) that ensure this minimum is finite. We consider four exhaustive cases:

(a)

Both bounds finite:
The minimum depends on the sign of
c_{i}
: if
c_{i}\geq 0
, the minimum is
c_{i}\cdot l_{i}
; if
c_{i}<0
, it is
c_{i}\cdot u_{i}
. This can be expressed uniformly as:

L_{i}=-\frac{|c_{i}|}{2}(u_{i}-l_{i})+\frac{c_{i}}{2}(u_{i}+l_{i})

No constraint is needed on
c_{i}
in this case.

(b)

Lower bound is
-\infty
, upper bound is finite:
If
c_{i}>0
, the minimum is unbounded (
-\infty
). To ensure a finite value, we require
c_{i}\leq 0
, in which case
L_{i}=c_{i}\cdot u_{i}
.

(c)

Lower bound is finite, upper bound is
+\infty
:
If
c_{i}<0
, the minimum is unbounded. To ensure a finite value, we require
c_{i}\geq 0
, in which case
L_{i}=c_{i}\cdot l_{i}
.

(d)

Both bounds infinite:
In this case, the minimum is finite only if
c_{i}=0
, so we add this constraint and take
L_{i}=0
.

We apply this procedure to all coordinates
i=1,\dots,n
, summing the individual contributions to compute the overall minimized value:

L=\sum_{i=1}^{n}L_{i}+d

The complete constraint set
\Theta
is formed by collecting the individual
\Theta_{i}
across all variables. If the parameters
(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
satisfy
\Theta
, then the dual value is well-defined and finite. Otherwise, the objective is unbounded and evaluates to
-\infty
.

Conclusion.
In Step
A.2
, we constructed the relaxed objective
\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
by decomposing the inner minimization into independent subproblems and applying the min-split inequality. This yielded a symbolic under-approximation of
o_{\min}
. In Step
A.3
, we showed how to efficiently evaluate
\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
by solving each bilinear, quadratic, and linear subproblem separately and aggregating the resulting sign and bound constraints into a parameter set
\Theta
.

Together, these steps define a
Parametric Scalar Map

(\Theta,L)
for the optimization problem (
4
), where

L:\Theta\to\mathbb{R},\qquad L(\boldsymbol{\lambda},\mathbf{S},\mathbf{D}):=\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})\,.

By construction, each
(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})\in\Theta
yields a finite, sound lower bound on
o_{\min}
—that is,

L(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})\leq o_{\min}\quad\text{and}\quad L(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})\in\mathbb{R}\,.

If
\Theta
is empty or infeasible, then
(\Theta,L)
yields no informative bound beyond the trivial
-\infty
. This may occur if the true optimum is unbounded or if the relaxation is too coarse to derive a finite, sound lower bound. Thus, Steps
A.1
–
A.3
compute a sound PSM for the original optimization problem.

Special case: linear objectives.

Our construction also applies when the objective function
f(\mathbf{v})
is purely linear, i.e., when
H=0
and
Q=0
. In this setting, the primal optimization problem becomes a standard linear program:

f(\mathbf{v})=\mathbf{c}^{\top}\mathbf{v}+d,\qquad o_{\min}=\min_{\mathbf{v}\in[\mathbf{l},\mathbf{u}]}\;\mathbf{c}^{\top}\mathbf{v}+d\quad\text{s.t. }A^{\prime}\mathbf{v}\leq\mathbf{b}^{\prime}.

Here, Step 2 (linear coefficient splitting) is no longer needed, as there are no bilinear or quadratic terms to redistribute. The Parametric Scalar Map simplifies to the pair
(\Theta,L)
, where:

\Theta=\{\;\boldsymbol{\lambda}\in\mathbb{R}_{\geq 0}^{m}\;\mid\;\text{linear subproblem yields finite bound}\;\}\quad\text{and}\quad L(\boldsymbol{\lambda})=\hat{g}(\boldsymbol{\lambda})\,.

However,
feasibility constraints on
\boldsymbol{\lambda}
still arise
from the symbolic analysis of the linear evaluation step (see Section
A.3
). Specifically, to ensure that the inner minimum over
[\mathbf{l},\mathbf{u}]
is finite, the affine objective coefficients
\mathbf{c}+A^{\prime\top}\boldsymbol{\lambda}
must obey sign conditions based on unbounded directions of the box domain. For instance, if
l_{i}=-\infty
for some coordinate
i
, then to avoid
-\infty
in the objective, we must ensure that the
i
-th coefficient of
\mathbf{c}+A^{\prime\top}\boldsymbol{\lambda}
is non-negative; similar conditions apply for
u_{i}=+\infty
. These constraints prune the parameter space
\Theta
accordingly. Thus, even in the linear case, our construction produces a valid Parametric Scalar Map that yields sound bounds
L(\boldsymbol{\lambda})\leq o_{\min}
, with
\Theta
encoding the feasibility region induced by symbolic soundness conditions.

Theorem C.1 (Soundness of PSM Computing Procedure).

The procedure outlined in Appendix
A
computes a Parametric Scalar Map
\mathcal{M}=(\Theta,L)
for optimization problems of the form:

o_{\min}\;=\;\min_{\mathbf{v}\in\mathbb{R}^{n}}\;f(\mathbf{v})\quad\text{s.t.}\quad A\,\mathbf{v}\leq\mathbf{b},

where the objective function
f(\mathbf{v})
is a quadratic polynomial given by:

f(\mathbf{v})=\sum_{1\leq i<k\leq n}H_{ik}\,v_{i}v_{k}+\sum_{i=1}^{n}Q_{i}\,v_{i}^{2}+\mathbf{c}^{\top}\mathbf{v}+d.

The procedure is sound, meaning that for all
\theta\in\Theta
, the bound
L(\theta)
satisfies
L(\theta)\leq o_{\min}
.

Proof.

As described in Appendix
A
, the procedure constructs the PSM
\mathcal{M}=(\Theta,L)
using the following parameters:

•

Dual multipliers
\boldsymbol{\lambda}\in\mathbb{R}^{m}
for the constraints
A\,\mathbf{v}\leq\mathbf{b}
,

•

Splitting parameters
\mathbf{S}\in\mathbb{R}^{n}
and
\mathbf{D}\in\mathbb{R}^{n\times n}
used to redistribute linear coefficients during the decomposition of the inner minimization.

The parameter space
\Theta
consists of all tuples
(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
that satisfy the feasibility constraints collected during the minimization of the decomposed objective components in Section
A.3
, together with the constraint
\boldsymbol{\lambda}\geq 0
. The map
L
is defined as:

L(\boldsymbol{\lambda},\mathbf{S},\mathbf{D}):=\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D}),

where
\hat{g}
denotes the relaxed objective obtained by decomposing the dual objective
g(\boldsymbol{\lambda})
into independent subproblems using the splitting parameters
\mathbf{S}
and
\mathbf{D}
.

By the weak duality theorem, we know that:

g(\boldsymbol{\lambda})\;\leq\;o_{\min}\qquad\text{for all }\boldsymbol{\lambda}\geq 0.

Furthermore, by construction of the relaxation (Appendix
A.2
), the decomposed bound satisfies:

\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})\;\leq\;g(\boldsymbol{\lambda})\qquad\text{for all }\mathbf{S},\mathbf{D}.

Combining the two, we obtain:

L(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})=\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})\;\leq\;g(\boldsymbol{\lambda})\;\leq\;o_{\min},

for all
\boldsymbol{\lambda}\geq 0
and for all choices of
\mathbf{S},\mathbf{D}
.

Since
\Theta
is defined to include only those tuples
(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
satisfying
\boldsymbol{\lambda}\geq 0
along with the additional feasibility constraints, it follows that every
(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})\in\Theta
satisfies the above inequality. Thus,
L
yields a finite, sound lower bound on
o_{\min}
for each valid parameter, establishing that
\mathcal{M}=(\Theta,L)
is a sound Parametric Scalar Map for the given optimization problem. Note that the correctness of the proof relies on the correct computation of the relaxed bound
\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
, which relies on the correctness of the algebraic decompositions used to evaluate the independent bilinear, quadratic, and linear subproblems (Appendix
A.3
). These decompositions involve standard algebraic manipulations and closed-form expressions, whose correctness we assume.

∎

Theorem C.2 (Interval Relaxation Behavior).

The symbolic procedure described in Appendix
A
constructs a Parametric Scalar Map
\mathcal{M}=(\Theta,L)
for optimization problems of the form:

o_{\min}\;=\;\min_{\mathbf{v}\in\mathbb{R}^{n}}\;f(\mathbf{v})\quad\text{s.t.}\quad A\,\mathbf{v}\leq\mathbf{b},

where the objective
f(\mathbf{v})
is a quadratic polynomial given by:

f(\mathbf{v})=\sum_{1\leq i<k\leq n}H_{ik}\,v_{i}v_{k}+\sum_{i=1}^{n}Q_{i}\,v_{i}^{2}+\mathbf{c}^{\top}\mathbf{v}+d.

When the parameters are set to zero, i.e.,
\theta=(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})=(\vec{0},\vec{0},\vec{0})
, the behavior of the map
\mathcal{M}
coincides with that of interval relaxation. If interval relaxation yields a finite lower bound, then
\vec{0}\in\Theta
and
L(\vec{0})
matches the interval relaxation value. Otherwise, if the interval relaxation is unbounded below, then
\vec{0}\notin\Theta
.

Proof.

As described in Appendix
A
, the Parametric Scalar Map
\mathcal{M}=(\Theta,L)
is constructed using:

•

Dual multipliers
\boldsymbol{\lambda}\in\mathbb{R}^{m}
for the constraints
A\,\mathbf{v}\leq\mathbf{b}
,

•

Splitting parameters
\mathbf{S}\in\mathbb{R}^{n}
and
\mathbf{D}\in\mathbb{R}^{n\times n}
for distributing linear terms.

The lower bound is computed by the relaxed expression:

\displaystyle\hat{g}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})=\;

\displaystyle\sum_{1\leq i<k\leq n}\min_{(v_{i},v_{k})\in[l_{i},u_{i}]\times[l_{k},u_{k}]}\left(H_{ik}v_{i}v_{k}+D_{ik}^{i}v_{i}+D_{ik}^{k}v_{k}\right)

\displaystyle+\sum_{i=1}^{n}\min_{v_{i}\in[l_{i},u_{i}]}\left(Q_{i}v_{i}^{2}+S_{i}v_{i}\right)

\displaystyle+\min_{\mathbf{v}\in[\mathbf{l},\mathbf{u}]}\left(\left(\mathbf{c}+A^{\top}\boldsymbol{\lambda}-\mathbf{S}-\boldsymbol{\Delta}\right)^{\!\top}\mathbf{v}\right)+d-\boldsymbol{\lambda}^{\top}\mathbf{b}

When
(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})=(\vec{0},\vec{0},\vec{0})
, this simplifies to:

\displaystyle\hat{g}(\vec{0},\vec{0},\vec{0})=\;

\displaystyle\sum_{1\leq i<k\leq n}\min_{(v_{i},v_{k})\in[l_{i},u_{i}]\times[l_{k},u_{k}]}H_{ik}v_{i}v_{k}

\displaystyle+\sum_{i=1}^{n}\min_{v_{i}\in[l_{i},u_{i}]}Q_{i}v_{i}^{2}

\displaystyle+\min_{\mathbf{v}\in[\mathbf{l},\mathbf{u}]}\mathbf{c}^{\top}\mathbf{v}+d

This is precisely the interval relaxation of
f(\mathbf{v})
over the input box
[l_{i},u_{i}]
, ignoring the linear constraints
A\,\mathbf{v}\leq\mathbf{b}
. During evaluation, Section
A.3
adds symbolic feasibility constraints to ensure that any parameter tuple leading to a bound of
-\infty
is excluded from the parameter space
\Theta
. In particular, if the interval relaxation yields
-\infty
, then the zero-point configuration
(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})=(\vec{0},\vec{0},\vec{0})
is ruled out by these constraints, and
\vec{0}\notin\Theta
. Otherwise, if the interval relaxation yields a finite value, then
\vec{0}\in\Theta
, and the corresponding bound
L(\vec{0})
exactly matches the interval relaxation value. Thus, the Parametric Scalar Map recovers interval relaxation as the zero-parameter instantiation, when valid.

∎

Theorem C.3 (Completeness of PSM Procedure for Linear Programs).

For the linear program

\text{\emph{(P)}}\qquad o_{\min}\;=\;\min_{\mathbf{v}\in\mathbb{R}^{n}}\;\mathbf{c}^{\top}\mathbf{v}+d\quad\text{s.t.}\quad A\mathbf{v}\leq\mathbf{b},

let
\mathcal{M}=(\Theta,L)
be the Parametric Scalar Map produced by the
procedure of Appendix
A
.
Then every finite lower bound
\ell\leq o_{\min}
is realised by

\mathcal{M}
; that is,

\forall\,\ell>-\infty,\;\ell\leq o_{\min}\quad\Longrightarrow\quad\exists\,\theta\in\Theta:\;L(\theta)=\ell.

Proof.

Assume the primal LP (P) is feasible and has a finite optimum
o_{\min}
; otherwise
there are no finite bounds to realise and the claim is vacuous.

Dual form.

After separating variable bounds as in Appendix
A
,
the dual objective is

g(\boldsymbol{\lambda})=\min_{\mathbf{v}\in[\mathbf{l},\mathbf{u}]}(\mathbf{c}+A^{\prime\top}\boldsymbol{\lambda})^{\!\top}\mathbf{v}-\boldsymbol{\lambda}^{\top}\mathbf{b}^{\prime}+d,\qquad\boldsymbol{\lambda}\geq 0.

The PSM construction keeps precisely those multipliers giving finite values:

\Theta=\{\boldsymbol{\lambda}\geq 0\mid g(\boldsymbol{\lambda})>-\infty\},\quad L(\boldsymbol{\lambda})=g(\boldsymbol{\lambda}).

Strong duality.

Feasibility and boundedness of (P) imply strong duality:

o_{\min}=\max_{\boldsymbol{\lambda}\geq 0}g(\boldsymbol{\lambda})
.
Because
g
is concave and continuous on the closed convex set

\{\boldsymbol{\lambda}\geq 0\}
, its range is exactly the interval

(-\infty,o_{\min}]
.
Hence for any finite
\ell\leq o_{\min}
there exists

\boldsymbol{\lambda}\geq 0
with
g(\boldsymbol{\lambda})=\ell
. Such
\boldsymbol{\lambda}
always lies in the space
\Theta
as
g(\boldsymbol{\lambda})=\ell
is finite, and
L(\boldsymbol{\lambda})=\ell
.
Thus, every finite sound lower bound is produced by some parameter in
\Theta
, establishing completeness.

Remark.

This completeness result hinges on the strong duality property of linear
programs. For general quadratic objectives (especially non-convex ones),
strong duality need not hold, the dual may exhibit a positive gap, and

\{g(\boldsymbol{\lambda})\}
does
not
exhaust all finite
sound bounds. Hence, the analogous completeness statement fails in the
quadratic setting.
∎

Theorem C.4 (Polyhedrality of the feasible-parameter set).

Let

\theta=(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})\in\mathbb{R}^{m+n+n^{2}}

be the parameter vector constructed by the PSM computing procedure in
Appendix
A
.
The set of admissible parameters

\Theta\;=\;\bigl\{\theta\mid\text{all feasibility checks introduced
in Steps\,2\textendash 4 are satisfied}\bigr\}

is a (possibly empty)
polyhedron
; equivalently, there exist a matrix

M
and vector
\mathbf{h}
such that

\Theta=\{\theta\mid M\theta\leq\mathbf{h}\}.

Proof.

We enumerate the constraints added during the construction and show that each
is linear in
\theta
.

(i) Dual non-negativity.

Step 2 fixes
\boldsymbol{\lambda}\geq\mathbf{0}
, that is,

\lambda_{i}\geq 0
for
i=1,\dots,m
; these are linear half-spaces.

(ii) Bilinear sub-problems.

For every pair
(i,k)
the rule in
Section
A.3
may add

u_{2}\leq 0,\;u_{1}\leq 0,\;l_{2}\geq 0,\text{ or }l_{1}\geq 0\quad\text{or the contradictory }0\leq-1.

Here
l_{1},u_{1},l_{2},u_{2}
are affine expressions in
the splitting parameters
D_{ik}^{i},D_{ik}^{k}
; hence each inequality is
linear in
\theta
.

(iii) Quadratic sub-problems.

When
A<0
and a bound is missing, the procedure inserts the contradictory
half–space
0\leq-1
; otherwise no new restriction is
added. Again,
0\leq-1
is linear.

(iv) Linear sub-problem.

For every coordinate
i
the guard may require

c_{i}\leq 0,\;c_{i}\geq 0,
or
c_{i}=0
.
Because each coefficient takes the affine form

c_{i}=\hat{c}_{i}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
,
these relations are linear in
\theta
.

(v) Closure under intersection.

The parameter set
\Theta
is the finite intersection of the half-spaces
listed in (i)–(iv). A finite intersection of linear half-spaces is a
polyhedron by definition.

Hence
\Theta
is polyhedral.
∎

Theorem C.5 (Differentiability of L function in PSM).

Let

\theta=(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})\in\mathbb{R}^{m+n+n^{2}}

be the parameter vector constructed by the PSM computing procedure in Appendix
A
. This procedure outputs a parametric sound map (PSM)

\mathcal{M}=(\Theta,L)
,
where
\Theta\subseteq\mathbb{R}^{m+n+n^{2}}
is the polyhedral set of admissible parameters (as established in Theorem
C.4
) and

L:\Theta\to\mathbb{R}

is the function that maps each admissible
\theta\in\Theta
to the minimum value of the relaxed dual objective
\hat{g}(\theta)
. Then the function
L(\theta)
is piecewise-defined and differentiable on the interior of
\Theta
.

More precisely:

•

On any region of
\Theta
where the minimizing terms and endpoints in all subproblems (bilinear, quadratic, and linear) remain fixed, the expression for
L(\theta)
is a differentiable function of
\theta
.

•

The function
L(\theta)
is continuous on all of
\Theta
, and differentiable almost everywhere in
\Theta
, except possibly at boundaries where the active minimizer (e.g., which endpoint of an interval achieves the minimum) changes.

Proof.

The function
L(\theta)
is computed as described in the derivation procedure in Appendix
A
, by summing the minimum values of several subproblems, one for each bilinear, quadratic, and linear term in the relaxed objective. We analyze the differentiability of each class of subproblem:

(i) Linear terms.
The minimized value of each
c_{i}v_{i}
term is computed based on whether
c_{i}
is positive, negative, or zero. The result is a piecewise-linear function of
c_{i}
, and since
c_{i}=\hat{c}_{i}(\boldsymbol{\lambda},\mathbf{S},\mathbf{D})
is affine in
\theta
, the contribution
L_{i}
is piecewise-affine in
\theta
, hence differentiable except at switching points (where the sign of
c_{i}
changes).

(ii) Quadratic terms.
Consider subproblems of the form
\min_{v_{i}\in[l_{i},u_{i}]}Av_{i}^{2}+Bv_{i}
with fixed
A\neq 0
and parameter-dependent
B=\hat{B}(\theta)
. The analysis splits into two cases:

•

If
A>0
(convex), the objective is minimized at the unconstrained critical point
v_{i}^{*}=-B/(2A)
. If
v_{i}^{*}\in[l_{i},u_{i}]
, the minimum is attained there and equals
A(v_{i}^{*})^{2}+Bv_{i}^{*}
, which is a smooth function of
B
, hence of
\theta
. If
v_{i}^{*}\notin[l_{i},u_{i}]
, the minimum occurs at one of the endpoints. Since
B
is affine in
\theta
, both
Al_{i}^{2}+Bl_{i}
and
Au_{i}^{2}+Bu_{i}
are smooth in
\theta
, and their minimum is piecewise-smooth depending on which endpoint is active. Thus, in both cases, the quadratic contribution is differentiable on regions where the active minimizer remains fixed.

•

If
A<0
(concave), the objective can decrease without bound unless both
l_{i}
and
u_{i}
are finite. In particular, the term
Av_{i}^{2}
dominates and diverges to
-\infty
if
v_{i}\to\pm\infty
. To ensure boundedness, the feasibility check adds the constraint that both bounds must be finite. If so, the minimum is computed as
\min\{Al_{i}^{2}+Bl_{i},\;Au_{i}^{2}+Bu_{i}\}
, which is continuous and piecewise-differentiable in
\theta
.

(iii) Bilinear terms.
Consider the subproblem

\min_{(v_{i},v_{k})\in[l_{i},u_{i}]\times[l_{k},u_{k}]}\Big(A\,v_{i}v_{k}+B\,v_{i}+C\,v_{k}\Big)\,,

with
A\neq 0
fixed and
B
,
C
affine in
\theta
. Rewriting:

Av_{i}v_{k}+Bv_{i}+Cv_{k}=(Av_{i}+C)(v_{k}+B/A)-\frac{BC}{A}\,,

we reduce to minimizing a product of two affine expressions over intervals
[l_{1},u_{1}]
and
[l_{2},u_{2}]
, where:

l_{1}:=\min(Al_{i}+C,\;Au_{i}+C),\quad l_{2}:=l_{k}+B/A\,,\quad\text{etc.}

The minimal value is:

l_{\text{bilin}}:=\min\{l_{1}l_{2},\;l_{1}u_{2},\;u_{1}l_{2},\;u_{1}u_{2}\}-\frac{BC}{A}\,.

Unboundedness arises in four cases (e.g.,
l_{1}=-\infty
and
u_{2}>0
). If the paired bound is also infinite, we add the contradictory constraint
0\leq-1
to
\Theta
; otherwise, we insert the appropriate bound constraint (e.g.,
u_{2}\leq 0
). This ensures the subproblem remains well-posed and the resulting
l_{\text{bilin}}
is finite and piecewise-smooth in
\theta
.

(iv) Summation.
The total value
L(\theta)
is the sum of these subproblem contributions. Since each term is continuous and piecewise-differentiable, their sum is also continuous and piecewise-differentiable. Differentiability holds on any region where the active minimizers in all subproblems are fixed.
∎

Theorem C.6 (Soundness of EUM Block Transformation).

Let
\mathcal{P}
be a program and let
\mathcal{P}^{\prime}
be the transformed program in which each admissible instruction sequence
\mathcal{S}
is replaced by its corresponding block
\mathcal{B}(\mathcal{S})
, with semantics defined by its Effective Update Map
\sigma_{\mathcal{B}(\mathcal{S})}
. Let
\llbracket\mathcal{P}\rrbracket
denote the set of concrete reachable states of
\mathcal{P}
under standard big-step semantics, and likewise for
\llbracket\mathcal{P}^{\prime}\rrbracket
. Then,
\llbracket\mathcal{P}\rrbracket\subseteq\llbracket\mathcal{P}^{\prime}\rrbracket
holds.

Proof of Theorem
C.6
.

We prove that for any program
\mathcal{P}
and its EUM-transformed version
\mathcal{P}^{\prime}
, the set of reachable states under
\mathcal{P}
is contained in the set of reachable states under
\mathcal{P}^{\prime}
, i.e.,
\llbracket\mathcal{P}\rrbracket\subseteq\llbracket\mathcal{P}^{\prime}\rrbracket
.

The transformation from
\mathcal{P}
to
\mathcal{P}^{\prime}
proceeds by identifying admissible instruction sequences
\mathcal{S}=[\mathit{ins}_{1};\dots;\mathit{ins}_{n}]
and replacing them with their corresponding block
\mathcal{B}(\mathcal{S})
, which is a single assignment block with an Effective Update Map
\sigma_{\mathcal{B}}
.

We proceed by induction on the structure of program execution:

Base Case:
Consider an initial state
s_{0}
. Since the initial state is preserved in both
\mathcal{P}
and
\mathcal{P}^{\prime}
, we have
s_{0}\in\llbracket\mathcal{P}\rrbracket
and
s_{0}\in\llbracket\mathcal{P}^{\prime}\rrbracket
.

Inductive Step:
Suppose that a state
s
is reachable in
\mathcal{P}
via execution of a prefix of instructions, and the next instruction sequence to be executed is an admissible sequence
\mathcal{S}=[\mathit{ins}_{1};\dots;\mathit{ins}_{n}]
, which updates a set of variables
\mathcal{A}=\{x_{1},\dots,x_{m}\}
.

Let
s^{\prime}
be the state obtained by executing
\mathcal{S}
from
s
in the original program
\mathcal{P}
. That is,

s^{\prime}=s[x_{1}\leftarrow e_{1}(s),\;\dots,\;x_{m}\leftarrow e_{m}(s)],

where
e_{i}
is the final expression assigned to
x_{i}
after executing the entire sequence
\mathcal{S}
. By the definition of the Effective Update Map
\sigma_{\mathcal{B}}
, we know that for all
x_{i}\in\mathcal{A}
,

\sigma_{\mathcal{B}}(x_{i})(s)=e_{i}(s).

Thus, executing the block
\mathcal{B}(\mathcal{S})
from the same input state
s
in the transformed program
\mathcal{P}^{\prime}
yields the same output state
s^{\prime}
:

\llbracket\mathcal{B}(\mathcal{S})\rrbracket(s)=s[x_{1}\leftarrow\sigma_{\mathcal{B}}(x_{1})(s),\;\dots,\;x_{m}\leftarrow\sigma_{\mathcal{B}}(x_{m})(s)]=s^{\prime}.

Therefore, every state
s^{\prime}
that is reachable by executing
\mathcal{S}
in
\mathcal{P}
is also reachable by executing
\mathcal{B}(\mathcal{S})
in
\mathcal{P}^{\prime}
from the same prior state
s
.

Applying this argument inductively for each admissible sequence in the program, we conclude that every concrete execution trace in
\mathcal{P}
corresponds to a concrete trace in
\mathcal{P}^{\prime}
, and hence every state reachable in
\mathcal{P}
is also reachable in
\mathcal{P}^{\prime}
.

Conclusion:
We have shown that
\llbracket\mathcal{P}\rrbracket\subseteq\llbracket\mathcal{P}^{\prime}\rrbracket
as required.
∎
