Disordered Dynamics in High Dimensions: Connections to Random Matrices and Machine Learning
Blake Bordelon, Cengiz Pehlevan

Abstract
We provide an overview of high dimensional dynamical systems driven by random matrices, focusing on applications to simple models of learning and generalization in machine learning theory. Using both cavity method arguments and path integrals, we review how the behavior of a coupled infinite dimensional system can be characterized as a stochastic process for each single site of the system. We provide a pedagogical treatment of dynamical mean field theory (DMFT), a framework that can be flexibly applied to these settings. The DMFT single site stochastic process is fully characterized by a set of (two-time) correlation and response functions. For linear time-invariant systems, we illustrate connections between random matrix resolvents and the DMFT response. We demonstrate applications of these ideas to machine learning models such as gradient flow, stochastic gradient descent on random feature models and deep linear networks in the feature learning regime trained on random data. We demonstrate how bias and variance decompositions (analysis of ensembling/bagging etc) can be computed by averaging over subsets of the DMFT noise variables. From our formalism we also investigate how linear systems driven with random non-Hermitian matrices (such as random feature models) can exhibit non-monotonic loss curves with training time, while Hermitian matrices with the matching spectra do not, highlighting a different mechanism for non-monotonicity than small eigenvalues causing instability to label noise. Lastly, we provide asymptotic descriptions of the training and test loss dynamics for randomly initialized deep linear neural networks trained in the feature learning regime with high-dimensional random data. In this case, the time translation invariance structure is lost and the hidden layer weights are characterized as spiked random matrices.

Disordered Linear Dynamical Systems

In the first sections of this note, we will are focus on linear dynamical systems of the form

\displaystyle\frac{d}{dt}\bm{h}(t)=-\bm{M}\bm{h}(t)+\bm{j}(t),

(1)

where the matrix
\bm{M}\in\mathbb{R}^{N\times N}
is a fixed random matrix that depends on the specific problem details (we will show several examples in the coming sections). The two objects that we wish to track are

\displaystyle C(t,t^{\prime})=\frac{1}{N}\bm{h}(t)\cdot\bm{h}(t^{\prime})\ ,\ R(t,t^{\prime})=\frac{1}{N}\text{Tr}\frac{\delta\bm{h}(t)}{\delta\bm{j}(t^{\prime})^{\top}},

(2)

which intuitively measure the cross correlation between the state variables
\bm{h}(t)
and the response of the variables to perturbations to their dynamics. The functions
C(t,t^{\prime})
and
R(t,t^{\prime})
are central objects to describe high dimensional disordered systems. For linear systems, the response function
R(t,t^{\prime})
for matrix
\bm{M}
actually encodes its spectral density
\rho(\lambda)=\frac{1}{N}\sum_{i=1}^{N}\delta(\lambda-\lambda_{i})
, since

\displaystyle R(t,t^{\prime})=\frac{1}{N}\text{Tr}\frac{\delta\bm{h}(t)}{\delta\bm{j}(t^{\prime})^{\top}}=\frac{1}{N}\text{Tr}\exp\left(-\bm{M}(t-t^{\prime})\right)\Theta(t-t^{\prime})=\int d\lambda\rho(\lambda)e^{-\lambda(t-t^{\prime})}\Theta(t-t^{\prime})

(3)

where
\Theta(t-t^{\prime})=\mathbf{1}_{t>t^{\prime}}
is the Heaviside step function which is
1
for all
t>t^{\prime}
and zero otherwise.

For linear systems, the response function
R(t,t^{\prime})
also encodes the trace of the
resolvent
matrix for
\bm{M}
through a Fourier or Laplace transform

\displaystyle\mathcal{R}(\omega)=\int d\tau R(t+\tau,t)e^{-i\omega\tau}=\frac{1}{N}\text{Tr}\left[i\omega+\bm{M}\right]^{-1}=\int d\lambda\ \frac{\rho(\lambda)}{i\omega+\lambda}.

(4)

The trace of the resolvent,
\mathcal{R}(\omega)=\frac{1}{N}\text{Tr}\left[i\omega+\bm{M}\right]^{-1}
is often termed the Stieltjes transform, is a central object in the study of random matrices
46
. For matrices
\bm{M}
with real spectra, the eigenvalue density
\rho(\lambda)
can be obtained from the Sokhotski–Plemelj formula

\displaystyle\rho(\lambda)=\lim_{\epsilon\to 0}\frac{1}{\pi}\Im\ \mathcal{R}(\omega)|_{i\omega=-\lambda-i\epsilon}.

(5)

We will be focused on matrices with real spectra for the first sections of this paper, before moving onto matrices whose spectra extend into the complex plane in Section
8
.

3
Warmup Problem: GOE (Wigner) Matrix

To first see how the DMFT description of the high dimensional limit works, we start with the simplest example of a random matrix, the symmetric Gaussian (GOE/Wigner) matrix
\bm{M}=\frac{1}{\sqrt{N}}\bm{A}
where
\bm{A}=\bm{A}^{\top}
with
A_{ij}\sim\mathcal{N}(0,1)
. We consider the linear dynamical system

\displaystyle\frac{d}{dt}\bm{h}(t)=-\frac{1}{\sqrt{N}}\bm{A}\bm{h}(t)+\bm{j}(t).

(6)

We are interested in the behavior of this dynamical system as the system size diverges
N\to\infty
. In this limit, we will find that each of the variables effectively decouple from one another, enabling a simple description of the full dynamics in terms of a one-dimensional stochastic process.

3.1
Cavity Derivation

To characterize the dynamics in the large system size limit
N\to\infty
, we will first illustrate the cavity method. In this method, we consider adding a new site
h_{0}(t)
to the system, resulting in a
N+1
site system. We illustrate this procedure in Figure
1
.

Figure 1:
Cavity derivation of the marginal dynamics for a single site of the system as
N\to\infty
. Adding a new site to the system comes with
N
reciprocal couplings
\bm{a}_{0}\in\mathbb{R}^{N}
to the original variables which are now perturbed
\bm{h}(t)\to\tilde{\bm{h}}(t)
. In the large system size limit
N\to\infty
the system can be viewed as a single-variable stochastic process driven by a colored noise process with a delayed feedback through response function
R(t,t^{\prime})
.

Adding a New Site

Upon the addition of a new site
h_{0}
the other
N
variables will experience a
\mathcal{O}(N^{-1/2})
perturbation to their original dynamics which we denote as
\bm{h}(t)\to\tilde{\bm{h}}(t)
where

\displaystyle\tilde{\bm{h}}(t)=\bm{h}(t)-\frac{1}{\sqrt{N}}\int_{-\infty}^{t}dt^{\prime}\frac{\partial\bm{h}(t)}{\partial\bm{j}(t^{\prime})^{\top}}\bm{a}_{0}\ h_{0}(t^{\prime})+\mathcal{O}(N^{-1})

(7)

where
\bm{a}_{0}\in\mathbb{R}^{N}
are the added weights between the
N+1
st neuron and the original
N
neuron system (the red lines in Figure
1
). This expression results from considering that the added term to the right hand side can be considered a perturbation to the source
\bm{j}(t)\to\bm{j}(t)-\frac{1}{\sqrt{N}}\bm{a}_{0}\ h_{0}(t)
, allowing us to expand the dynamics by differentiating in the source at all earlier times
t^{\prime}<t
.

Computing Correction to Dynamics from Feedback

These perturbations to the original
N
variables feedback into the dynamics for the added site
h_{0}(t)
. Computing these corrections at leading order, we find

\displaystyle\frac{d}{dt}h_{0}(t)

\displaystyle\sim-\frac{1}{\sqrt{N}}\bm{a}_{0}\cdot\tilde{\bm{h}}(t)+j_{0}(t)

\displaystyle\sim-\underbrace{\frac{1}{\sqrt{N}}\bm{a}_{0}\cdot{\bm{h}}(t)}_{\text{Noise Term}}+\underbrace{\frac{1}{N}\int_{-\infty}^{t}dt^{\prime}\bm{a}_{0}^{\top}\frac{\partial\bm{h}(t)}{\partial\bm{j}(t^{\prime})^{\top}}\bm{a}_{0}h_{0}(t^{\prime})}_{\text{Response Term}}+j_{0}(t)

To proceed, we next work out the statistics of the noise term and the response term.

Statistics of The Noise Term

The noise term
u_{0}(t)\equiv-\frac{1}{\sqrt{N}}\bm{a}_{0}\cdot\bm{h}(t)
is a random variable due to the random
\bm{m}_{0}
vector. By construction, the
\bm{h}(t)
variables are statistically independent of
\bm{m}_{0}
. As a consequence,
u_{0}(t)
will behave as a Gaussian process with covariance

\displaystyle\left<u_{0}(t)u_{0}(t^{\prime})\right>=\frac{1}{N}\sum_{i=1}^{N}h_{i}(t)h_{i}(t^{\prime})\equiv C(t,t^{\prime})

(8)

which is computed as a population average over the
N
original sites.

Statistics of the Response Term

Next, we note that the response term concentrates (over random draws of the
\bm{m}_{0}
vector) as
N\to\infty
by the law of large numbers. Computing the mean and standard deviation of this term, we find that

\displaystyle\frac{1}{N}\int_{-\infty}^{t}dt^{\prime}\bm{a}_{0}^{\top}\frac{\partial\bm{h}(t)}{\partial\bm{j}(t^{\prime})^{\top}}\bm{a}_{0}\ h_{0}(t^{\prime})=\int_{-\infty}^{t}dt^{\prime}\underbrace{\left[\frac{1}{N}\sum_{i=1}^{N}\frac{\partial h_{i}(t)}{\partial j_{i}(t^{\prime})}\right]}_{\equiv R(t,t^{\prime})}h_{0}(t^{\prime})+\mathcal{O}(N^{-1/2})

(9)

where we introduced the
response function

R(t,t^{\prime})\equiv\frac{1}{N}\sum_{i=1}^{N}\frac{\partial h_{i}(t)}{\partial j_{i}(t^{\prime})}
which is another population average over the
N
original sites. This quantity asks about how a perturbation to the dynamics for the
i
-th site impacts the later value of the
i
-th site at a later time.

Decoupled Dynamics

Combining the two computations above, we find that the dynamics of the variable
h_{0}(t)
in the
N\to\infty
limit take the form

\displaystyle\frac{d}{dt}h_{0}(t)=u_{0}(t)+\int_{-\infty}^{t}dt^{\prime}R(t,t^{\prime})h_{0}(t^{\prime})+j_{0}(t),\quad u(t)\sim\mathcal{GP}(0,C(t,t^{\prime}))

(10)

which only depends
on its own dynamics
except through self-averaging functions
R(t,t^{\prime})
and
C(t,t^{\prime})
. Thus, if
C
and
R
become non-random in the
N\to\infty
limit, the variable
h_{0}
will be effectively decoupled from the other
N
variables in the model.

Each Variable Will Behave Like
h_{0}

In this model, as
N\to\infty
, all sites
h_{i}(t)
become statistically equivalent. Therefore, in the
N\to\infty
limit, they should each behave identically and independently. Averages over the population of
N
sites can be replaced with averages over the Gaussian noise
u(t)
which generates the variance.

\displaystyle\frac{\partial}{\partial t}h(t)=u(t)+\int dt^{\prime}R(t,t^{\prime})h(t^{\prime})+j(t)

(11)

Response Function Dynamics

We can differentiate with respect to the source
j(t)
to find the following equation for the linear response function

\displaystyle\frac{\partial}{\partial t}R(t,t^{\prime})=\delta(t-t^{\prime})+\int_{0}^{t}dt^{\prime\prime}R(t,t^{\prime\prime})R(t^{\prime\prime},t^{\prime})

(12)

The solution is clearly time translation invariant so that
R(t,t^{\prime})=R(\tau)
where
\tau=t-t^{\prime}
is the time-lag. Taking a Fourier transform gives

\displaystyle\mathcal{R}(\omega)

\displaystyle=\int_{-\infty}^{\infty}d\tau R(\tau)e^{-i\omega\tau}\implies i\omega\mathcal{R}(\omega)=1+\mathcal{R}(\omega)^{2}\implies\mathcal{R}(\omega)=\frac{1}{2}\left[i\omega+\sqrt{(i\omega)^{2}-4}\right]

(13)

We can compute the inverse transform
R(\tau)=\frac{1}{2\pi}\int d\omega e^{i\omega\tau}\mathcal{R}(\omega)
to obtain the

Eigenvalue Distribution (Semi-circle Law)

We note that the response function
R(\tau)
has a straightforward connection to the eigenvalue density
\rho(\lambda)=\frac{1}{N}\sum_{i=1}^{N}\delta(\lambda-\lambda_{i})
.

\displaystyle R(\tau)

\displaystyle=\frac{1}{N}\text{Tr}\exp\left(-\bm{M}\tau\right)=\int d\lambda\rho(\lambda)e^{-\lambda\tau}\implies\mathcal{R}(\omega)=\int d\lambda\ \frac{\rho(\lambda)}{i\omega+\lambda}

\displaystyle\implies\rho(\lambda)=\lim_{\epsilon\to 0}\frac{1}{\pi}\ \text{Im}\ \mathcal{R}(i\lambda-\epsilon)=\frac{1}{2\pi}\sqrt{\left[4-\lambda^{2}\right]_{+}}.

(14)

This recovers Wigner’s semicircle distribution which has support for
\lambda\in[-2,2]
.

Connection between Correlation and Response for this System

For this problem, since
\bm{M}=\bm{M}^{\top}
, the correlation function satisfies

\displaystyle C(t,t^{\prime})=\text{tr}\ \exp\left(-\bm{M}t^{\prime}\right)^{\top}\exp\left(-\bm{M}t\right)=\text{tr}\exp\left(-\bm{M}(t+t^{\prime})\right)=R(t+t^{\prime}).

(15)

Thus, the response function
R(\tau)
completely characterizes the correlation function in this setting. We stress that this correspondence between correlation and response will fail in almost all of the subsequent settings of this note, especially in cases where
\bm{M}
is asymmetric or if the correlation function involves traces against other matrices which do not commute with
\exp(\bm{M}t)
.

3.2
Path Integral Approach

In this section, we provide an additional method to compute the DMFT equations, known as the path integral approach. A reader less interested in the formal approaches used to derive the equations and more interested in applications could skip this section and proceed to Section
4
.

Moment Generating Function

An alternative approach to derive the DMFT equations in the limit of
N\to\infty
is to analyze a path integral / moment generating function for the random variables
\bm{h}(t)

\displaystyle Z[\bm{\zeta}]=\left<\exp\left(\int dt\ \bm{\zeta}(t)\cdot\bm{h}(t)\right)\right>_{\bm{h}}

(16)

where the average is taken over the distribution of the random variables
\bm{h}(t)
induced by the random couplings
\bm{M}
. While moments of the distribution for
\bm{h}
can be obtained through derivatives of
Z
with respect to
\bm{\zeta}
, it often suffices to analyze
Z
formally for
\bm{\zeta}=0
, where
Z=1

25
;
32
;
20
, which we explain in Appendix
A
.
Starting from an integral representation of the Dirac delta function
\delta(z)=\int\frac{d\hat{z}}{2\pi}\ \exp(i\hat{z}z)
, we can write a formal path integral that enforces the dynamics for
\bm{h}(t)
, yielding

\displaystyle Z

\displaystyle=\int\mathcal{D}\bm{h}\mathcal{D}\hat{\bm{h}}\left<\exp\left(i\int dt\ \hat{\bm{h}}(t)\cdot\left(\partial_{t}\bm{h}(t)+\bm{M}\bm{h}(t)-\bm{j}(t)+\delta(t)\bm{h}_{0}\right)\right)\right>_{\bm{M}}

\displaystyle=\int\mathcal{D}C\mathcal{D}\hat{C}\mathcal{D}R\mathcal{D}\hat{R}\ \exp\left(-N\mathcal{S}\left[C,\hat{C},R,\hat{R}\right]\right).

(17)

By averaging over the Gaussian random matrix
\bm{M}
we were able to re-express
Z
in terms of correlation and response variables (often referred to as
order-parameters
for the theory)

\displaystyle C(t,t^{\prime})=\frac{1}{N}\bm{h}(t)\cdot\bm{h}(t^{\prime})\ ,\ R(t,t^{\prime})=-\frac{i}{N}\bm{h}(t)\cdot\hat{\bm{h}}(t^{\prime}).

(18)

These definitions are enforced with conjugate variables
\hat{C}(t,t^{\prime}),\hat{R}(t,t^{\prime})
. The mean-field action
\mathcal{S}
has the following form

\displaystyle\mathcal{S}=-\frac{1}{2}\int dtdt^{\prime}

\displaystyle\hat{C}(t,t^{\prime})C(t,t^{\prime})+\frac{1}{2}\int dtdt^{\prime}R(t,t^{\prime})\hat{R}(t^{\prime},t)-\ln\mathcal{Z}_{h}

\displaystyle\mathcal{Z}_{h}=\int\mathcal{D}h\mathcal{D}\hat{h}\

\displaystyle\exp\left(-\frac{1}{2}\int dtdt^{\prime}\ \hat{C}(t,t^{\prime})h(t)h(t^{\prime})-\frac{1}{2}\int dtdt^{\prime}\ C(t,t^{\prime})\hat{h}(t)\hat{h}(t)\right)

\displaystyle\exp\left(i\int dt\ \hat{h}(t)\left[\partial_{t}h(t)-\frac{1}{2}\int dt^{\prime}\left(R(t,t^{\prime})+\hat{R}(t,t^{\prime})\right)h(t^{\prime})+\delta(t)\right]\right)

(19)

The object
\mathcal{Z}_{h}
is often known as the single site generating function for
h(t)
, reflecting the fact that, after averaging over
\bm{M}
, all entries in
\bm{h}(t)
are identically distributed. As
N\to\infty
the dominant contribution comes from the saddle point, where the following conditions are satsified

\displaystyle\frac{\partial\mathcal{S}}{\partial\hat{C}(t,t^{\prime})}

\displaystyle=-\frac{1}{2}C(t,t^{\prime})+\frac{1}{2}\left<h(t)h(t^{\prime})\right>=0

\displaystyle\frac{\partial\mathcal{S}}{\partial C(t,t^{\prime})}

\displaystyle=-\frac{1}{2}\hat{C}(t,t^{\prime})+\frac{1}{2}\left<\hat{h}(t)\hat{h}(t^{\prime})\right>=0

\displaystyle\frac{\partial\mathcal{S}}{\partial\hat{R}(t^{\prime},t)}

\displaystyle=\frac{1}{2}R(t,t^{\prime})+\frac{i}{2}\left<h(t)\hat{h}(t^{\prime})\right>=0

\displaystyle\frac{\partial\mathcal{S}}{\partial R(t^{\prime},t)}

\displaystyle=\frac{1}{2}\hat{R}(t,t^{\prime})+\frac{i}{2}\left<h(t)\hat{h}(t^{\prime})\right>=0

(20)

where
\left<\cdot\right>
represents an average over the stochastic process for
h(t)
defined by the single-site moment generating function
\mathcal{Z}_{h}
. The above saddle point equations imply that
\hat{C}(t,t^{\prime})=0
and
\hat{R}(t,t^{\prime})=R(t,t^{\prime})=-i\left<h(t)\hat{h}(t^{\prime})\right>
. Lastly, we can introduce a Gaussian variable
u(t)
to linearize the
\hat{h}(t)
terms

\displaystyle\exp\left(-\frac{1}{2}\int dtdt^{\prime}C(t,t^{\prime})\hat{h}(t)\hat{h}(t^{\prime})\right)=\left<\exp\left(-i\int dt\ u(t)\hat{h}(t)\right)\right>_{u(t)\sim\mathcal{GP}(0,C(t,t^{\prime}))}

(21)

After introducing this variable, it becomes possible to exchange correlation functions of
\hat{h}
with derivatives with respect to the variable
u(t)
, resulting in the following formula for the response function

\displaystyle R(t,t^{\prime})=\left<\frac{\partial h(t)}{\partial u(t^{\prime})}\right>,

(22)

which agrees with the cavity formula. Lastly, performing the integral over the
\hat{h}(t)
variables, we recover the original DMFT equations for the GOE matrix

\displaystyle\frac{\partial}{\partial t}\ h(t)=u(t)+\int dt^{\prime}R(t,t^{\prime})h(t^{\prime})+\delta(t)\ ,\ u(t)\sim\mathcal{GP}(0,C(t,t^{\prime})).

(23)

Under this dynamics, we compute the correlation
C(t,t^{\prime})=\left<h(t)h(t^{\prime})\right>
.

3.3
Anti-Symmetrized Version

The oscillatory version of this system, where
\frac{d}{dt}\bm{h}(t)=\bm{M}\bm{h}(t)
where
\bm{M}=\frac{1}{\sqrt{2N}}(\bm{A}-\bm{A}^{\top})
where
A_{ij}\sim\mathcal{N}(0,1)
was analyzed with DMFT in another recent note
9
. In this case, one arrives at very similar DMFT equations modified by flipping the sign of the term involving the response function

\displaystyle\frac{d}{dt}h(t)=u(t)-\int dt^{\prime}R(t,t^{\prime})h(t^{\prime}),

(24)

where the response function can be computed from its Fourier transform
i\omega\mathcal{R}(\omega)=1-\mathcal{R}(\omega)^{2}
. Geometrically, the eigenvalues of
\bm{M}
follow the semicircle distribution on the imaginary axis in the complex plane from
z=-2i
to
z=2i
. Consequently, the response function can also be viewed as a linear combination of oscillatory modes (rather than exponential decay timescales)

\displaystyle R(\tau)=\int d\lambda\rho(\lambda)e^{-i\lambda\tau}=\frac{1}{\pi}\int_{0}^{2}d\lambda\sqrt{4-\lambda^{2}}\cos(\lambda\tau).

(25)

In this setting, the correlation function is a function of the
time-lag

\tau=t-t^{\prime}

\displaystyle C(t,t^{\prime})=\text{tr}\exp\left(\bm{M}t^{\prime}\right)^{\top}\exp\left(\bm{M}t\right)=\int d\lambda\rho(\lambda)e^{i\lambda(t-t^{\prime})}=R(t-t^{\prime}).

(26)

While the correlation function in the symmetric case depended on
t+t^{\prime}
, we see that the anti-symmetric case depends on the value of the response function evaluated at the time-lag
t-t^{\prime}
. In this system, the correlation function does not monotonically decay with
t-t^{\prime}
, but rather exhibits oscillations.

4
Linear Regression with Isotropic Covariates

4.3
Hermiticity & Monotonicity in Noise Free Setting

We note that the response function and correlation function are linked for linear dynamical systems defined by a Hermitian matrix
\bm{M}=\bm{M}^{\top}

\displaystyle C(t,t^{\prime})=\text{tr}\left[\exp\left(-\bm{M}t\right)\right]^{\top}\left[\exp\left(-\bm{M}t^{\prime}\right)\right]=\text{tr}\exp\left(-\bm{M}(t+t^{\prime})\right)=R(t+t^{\prime})

(54)

As a consequence, the loss function
\mathcal{L}(t)=C(t,t)+\sigma^{2}
can in fact be computed from the
one-point function
/resolvent/response function
R(t)
. However, this is not always the case if
\bm{M}\neq\bm{M}^{\top}
. We will return to this point explicitly in Section
6
.

Monotonic Convergence in Noise Free Setting

The autonomous (noise-free
\sigma^{2}=0
) linear dynamics for this regression problem leads to monotonic decrease in the test loss since

\displaystyle\frac{d}{dt}\mathcal{L}(t)=-\frac{2}{N}\bm{h}(t)^{\top}\left(\frac{1}{P}\bm{\Psi}^{\top}\bm{\Psi}\right)\bm{h}(t)=-\frac{2}{NP}|\bm{\Psi}\bm{h}(t)|^{2}=-2\int_{0}^{\infty}d\lambda\rho(\lambda)\lambda e^{-2\lambda t}\leq 0

(55)

This is a consequence of the fact that the matrix
\left(\frac{1}{P}\bm{\Psi}^{\top}\bm{\Psi}\right)
is Hermitian and positive semidefinite. In the next section, however, we show how that a simple extension of this model to a random feature projection can be characterized as a linear dynamical system with
non-Hermitian
random matrix, allowing for non-monotonic training dynamics for certain values of the parameters.

Final Loss

We can access the final value of the loss by examining the low-frequency
\omega,\omega^{\prime}\to 0
limit of the correlation function (e.g. final value theorem). To start, we need the

\displaystyle\lim_{\tau\to\infty}R_{h}(\tau)=\lim_{\omega\to 0}(i\omega)\mathcal{R}_{h}(\omega)=\begin{cases}1-\alpha&\alpha<1\\
0&\alpha>1\end{cases}

(56)

From this final value for the response function, we can access the final value of the correlation function

\displaystyle\lim_{t\to\infty}\mathcal{L}(t)-\sigma^{2}=\lim_{t\to\infty}C(t,t)=\lim_{\omega,\omega^{\prime}\to 0}(i\omega)(i\omega^{\prime})\mathcal{C}(\omega,\omega^{\prime})=\begin{cases}1-\alpha+\frac{\sigma^{2}\alpha}{1-\alpha}&\alpha<1\\
\frac{\sigma^{2}}{\alpha-1}&\alpha>1\end{cases}

(57)

We note that in the presence of noise
\sigma^{2}>0
, the loss curve exhibits an overfitting peak at
\alpha=1
. The final bias and variance can be similarly deduced

\displaystyle\lim_{t\to\infty}B(t)=\begin{cases}(1-\alpha)^{2}&\alpha<1\\
0&\alpha>1\end{cases}\ ,\ \lim_{t\to\infty}V(t)=\begin{cases}\alpha(1-\alpha)+\frac{\sigma^{2}\alpha}{1-\alpha}&\alpha<1\\
\frac{\sigma^{2}}{\alpha-1}&\alpha>1\end{cases}.

(58)

While the bias monotonically decreases with
\alpha
, we see that the variance can be non-monotonic and can even diverge at
\alpha=1
.

5.2
Power Laws

We can also analyze the case of powerlaw features for which

\displaystyle\lambda_{k}\sim k^{-\nu}\ ,\ \sum_{\ell<k}\lambda_{\ell}(\beta_{\ell})^{2}\sim k^{-\nu\chi}.

(78)

where the exponents
\chi\nu
and
\nu
are known as the source and capacity exponents respectively
21
;
10
. The solution to
\mathcal{R}_{\Delta}(\omega)
can be approximated by an early time (high frequency) and late time (low frequency) expansion in
P(i\omega)^{\nu}

\displaystyle\mathcal{R}_{\Delta}(\omega)=1-\frac{1}{P}\sum_{k=1}^{\infty}\frac{\lambda_{k}\mathcal{R}_{\Delta}(\omega)}{i\omega+\lambda_{k}\mathcal{R}_{\Delta}(\omega)}\approx\begin{cases}1&\omega P^{\nu}\gg 1\\
i\omega P^{\nu}&\omega P^{\nu}\ll 1\end{cases},

(79)

which leads to the following approximations for the response functions
\mathcal{H}_{k}(\omega)

\displaystyle\mathcal{H}_{k}(\omega)\approx\begin{cases}\frac{1}{i\omega+\lambda_{k}}+\frac{1}{P(i\omega)^{\frac{1}{\nu}}}\frac{\lambda_{k}}{(i\omega+\lambda_{k})^{2}}+...&\omega P^{\nu}\gg 1\\
\frac{1}{i\omega}\frac{1}{\left(1+(P/k)^{\nu}\right)}+...&\omega P^{\nu}\ll 1\end{cases}

(80)

These equations indicate that the early stage of the dynamics, the loss dynamics along the
k
-th population eigenmode obey
\mathcal{H}_{k}(\tau)\approx e^{-\lambda_{k}\tau}+\mathcal{O}(P^{-1})
for small times
\tau
and converge to
\lim_{\tau\to\infty}\mathcal{H}_{k}(\tau)\approx\frac{1}{1+(P/k)^{\nu}}
at late time. This indicates the intuitive fact that if
P\gg k
this eigenmode will be learned effectively after sufficient training, while for
P\ll k
this eigenmode cannot be resolved at this sample size
P
. As a consequence the loss can be roughly approximated as a combination of powerlaws (motivated by
33
)

\displaystyle\mathcal{L}(t,P)\approx c_{t}\ t^{-\chi}+c_{P}\ P^{-\nu\chi}.

(81)

in the sense that this expression captures the
\lim_{t\to\infty}\mathcal{L}\sim P^{-\nu\chi}
and
\lim_{N\to\infty}\mathcal{L}\sim t^{-\chi}
. This is the same functional form explored in “Chinchilla” neural scaling laws
33
;
45
. Additional terms can be incorporated which capture the dynamical effect of variance from sampling the random dataset (which are mixed terms involving both finite
t,P
).

6
Random Feature Model

We can consider a simple random feature model of the form

\displaystyle f=\frac{1}{N_{1}}\bm{w}(t)^{\top}\bm{A}\bm{\psi}\ ,\ y=\bm{\beta}^{\star}\cdot\bm{\psi}\ ,\ \left<\psi_{k}\psi_{\ell}\right>=\lambda_{k}\delta_{k\ell}\ ,\ \left<\epsilon^{2}\right>=1

(82)

where
\bm{A}\in\mathbb{R}^{N_{1}\times N_{0}}
is a frozen random matrix and
\bm{w}(t)\in\mathbb{R}^{N_{1}}
is trained with gradient flow. The important variable to track is the discrepancy between the target weights
\bm{\beta}_{\star}
and the effective model weights
\frac{1}{N_{1}}\bm{A}^{\top}\bm{w}(t)
which gives

\displaystyle\bm{h}_{0}(t)\equiv\bm{\beta}_{\star}-\frac{1}{N_{1}}\bm{A}^{\top}\bm{w}(t)\in\mathbb{R}^{N_{0}}

(83)

The test loss is simply
\mathcal{L}(t)=\bm{h}_{0}(t)^{\top}\bm{\Lambda}\bm{h}_{0}(t)
. Gradient flow on
\bm{w}(t)
induces the following dynamics on this error variable
\bm{h}_{0}(t)

\displaystyle\frac{d}{dt}\bm{h}_{0}(t)=-\left(\frac{1}{N_{1}}\bm{A}^{\top}\bm{A}\right)\left(\frac{1}{P}\bm{\Psi}^{\top}\bm{\Psi}\right)\bm{h}_{0}(t).

(84)

Before setting out to describe the DMFT equations for this model for random
\bm{A}
matrix and random data
\bm{\Psi}
matrix, we first note that this matrix is asymmetric and non-normal.

From this above equation, we identify the matrix which drives the dynamics as

As we did in the linear regression problem, we can break up the matrix vector product

\displaystyle\bm{h}_{3}(t)=\bm{A}\bm{h}_{2}(t)\ ,\ \bm{h}_{4}(t)=\frac{1}{N_{1}}\bm{A}^{\top}\bm{h}_{3}(t)

\displaystyle\lim_{t\to\infty}\mathcal{L}(t)=\lim_{t\to\infty}C_{0}(t,t)=\lim_{\omega,\omega^{\prime}\to 0}(i\omega)(i\omega^{\prime})\mathcal{C}_{0}(\omega,\omega^{\prime})=\begin{cases}\frac{1-\nu}{1-\nu/\alpha}&\nu<\alpha\ \&\ \min\{\alpha,\nu\}<1\\
\frac{1-\alpha}{1-\alpha/\nu}&\alpha<\nu\ \&\ \min\{\alpha,\nu\}<1\\
0&\min\{\alpha,\nu\}>1\end{cases}

(93)

We see that this model displays
double descent behavior
where the test loss diverges at

if

as we illustrate in Figure

\alpha=\nu

6.0.2
Blowup Rate at the Interpolation Threshold

When
\alpha=\nu
there is an interesting asymptotic behavior as
t\to\infty
which we can access by examining the low-frequency structure of
\mathcal{C}(\omega,\omega^{\prime})
. To access the long time behavior in this case, we have to expand
\mathcal{H}
to higher order in
i\omega

\displaystyle i\omega\mathcal{H}(\omega)\sim 1-\alpha+\sqrt{\frac{\alpha^{3}}{1-\alpha}(i\omega)}\ ,\ i\omega\to 0

(94)

At low frequencies, the correlation function thus behaves like

\displaystyle\mathcal{C}(\omega,\omega^{\prime})

\displaystyle\sim\sqrt{\frac{1-\alpha}{\alpha^{3}}}\frac{(1-\alpha)^{2}}{(\sqrt{i\omega}+\sqrt{i\omega^{\prime}})i\omega i\omega^{\prime}}\ ,\ \omega,\omega^{\prime}\to\infty.

(95)

While the bias
\mathcal{B}(\omega,\omega^{\prime})\equiv\frac{1}{N}\left<\bm{h}(\omega)\right>\cdot\left<\bm{h}(\omega^{\prime})\right>=\mathcal{H}(\omega)\mathcal{H}(\omega^{\prime})\propto\frac{1}{i\omega i\omega^{\prime}}
has simple poles at
\omega,\omega^{\prime}=0
, we see that the variance induces additional inverse square-root terms. Taking an inverse Fourier transform at large
t
using a steepest descent approximation, we arrive at a
\sqrt{t}
blowup for large
t

\displaystyle C(t,t)\propto\int\frac{d\omega d\omega^{\prime}}{(2\pi)^{2}}\frac{\exp\left(i(\omega+\omega^{\prime})t\right)}{(i\omega)(i\omega^{\prime})\left[\sqrt{i\omega}+\sqrt{i\omega^{\prime}}\right]}\sim\sqrt{t}

(96)

This prediction matches experiments as we show in Figure

6.0.3
Comparison of Ensembling and Bagging

Similar to the analysis provided in section
4.2.1
, we can analyze the dynamics of the loss for the
averaged predictor
over a model ensemble of size
E
(meaning
E
indepedent copies of
\bm{A}
) and a bagging over
B
datasets (
B
independently sampled data matrices
\bm{\Psi}
). We let
e\in\{1,...,E\}
represent each ensemble member and
b\in\{1,...,B\}
represent each dataset

\displaystyle\frac{d}{dt}\bm{h}_{e,b}(t)=-\left(\frac{1}{N_{1}}\bm{A}_{e}^{\top}\bm{A}_{e}\right)\left(\frac{1}{P}\bm{\Psi}_{b}^{\top}\bm{\Psi}_{b}\right)\bm{h}_{e,b}(t)

(97)

and specifically are interested in the correlation and response functions for

\displaystyle\bar{\bm{h}}(t)=\frac{1}{EB}\sum_{e=1}^{E}\sum_{b=1}^{B}\bm{h}_{e,b}(t)

(98)

The exact DMFT equations can be averaged over different instances of
(e,b)

are uncorrelated across separate ensemble members
(e,e^{\prime})
and
u_{2,e,b}(t)
are uncorrelated across separate datasets
(b,b^{\prime})

\displaystyle\mathcal{C}(\omega,\omega^{\prime})=\frac{1}{1-\underbrace{\Gamma(\omega,\omega^{\prime},E,B)}_{\text{Variance Reduction}}}\ \underbrace{\mathcal{H}(\omega)\mathcal{H}(\omega^{\prime})}_{\text{Original Bias}}.

(99)

As

\lim_{E,B\to\infty}\Gamma(\omega,\omega^{\prime},E,B)=0
. Thus, the bias is indeed controlled only by
\mathcal{H}(\omega)
and is unaffected by bagging or ensembling, while the quantity
\Gamma
which controls the variance is reduced by ensembling and bagging.

6.1
Online Stochastic Gradient Descent on Structured Random Features

The same type of technology can also be used to analyze stochastic gradient descent in discrete time, which evolves the error vector
\bm{h}(t)

\displaystyle\bm{h}(t+1)=\bm{h}(t)-\eta\left(\frac{1}{N_{1}}\bm{A}^{\top}\bm{A}\right)\left(\frac{1}{B}\bm{\Psi}(t)^{\top}\bm{\Psi}(t)\right)\bm{h}(t)

where the matrix

1.

2.

that is decorrelated across steps. For the case where the dataset is repeated across steps of training, there is a limiting loss set by
P

Symmetric and Asymmetric Free Products

In this section, we move beyond Gaussian random matrices and consider general free products
46
;
5
;
4
;
12
. Consider two
N\times N
matrices
\bm{A}
and
\bm{B}
and define the two types of free products

\displaystyle\bm{M}=\begin{cases}\bm{O}\bm{B}\bm{O}^{\top}\bm{A}&\text{Asymmetric Free Product}\\
\bm{A}^{1/2}\bm{O}\bm{B}\bm{O}^{\top}\bm{A}^{1/2}&\text{Symmetrized Free Product}\end{cases}.

(105)

where
\bm{O}
is a randomly sampled orthogonal matrix
N\times N
matrix, drawn from the Haar measure. We would like to obtain correlation and response functions for the dynamical system

\displaystyle\frac{d}{dt}\bm{h}(t)=-\bm{M}\bm{h}(t)+\delta(t)\bm{h}_{0},

(106)

and compare the dynamics of the asymmetric and symmetrized free product. We are interested in the limiting dynamics in an appropriate
N\to\infty
limit under assumed knowledge of the spectra of
\bm{A},\bm{B}
. We will see that due to the fact that symmetric and asymmetric versions of the free-product
\bm{M}
have identical spectra, the response function of the above dynamical system will be identical in either case. However, the correlation function dynamics will be distinct. To characterize this with DMFT, we write down the path integral for this system (defining
i\hat{\bm{h}}(t)\equiv\bm{\chi}(t)
)

\displaystyle Z=\int\mathcal{D}\bm{h}\mathcal{D}\bm{\chi}\left<\exp\left(-\int dt\ \bm{\chi}(t)\cdot\left(\partial_{t}\bm{h}(t)-\bm{M}\bm{h}(t)\right)\right)\right>_{\bm{O}}=1.

(107)

As we outline in Appendix
E
, after integrating out the dependence of the random orthogonal matrix
\bm{O}
for large
N
, we can express
Z
as an integral over a pair of
2\times 2
matrix valued functions
\bm{\Sigma}(\omega,\omega^{\prime})\in\mathbb{R}^{2\times 2}
and
\bm{\Psi}(\omega,\omega^{\prime})\in\mathbb{R}^{2\times 2}

\displaystyle Z=\int\mathcal{D}\bm{\Sigma}\ \mathcal{D}\bm{\Psi}\ \exp\left(-\frac{N}{2}\mathcal{S}[\bm{\Sigma},\bm{\Psi}]\right),

(108)

where the DMFT action
\mathcal{S}
takes the form

\displaystyle\mathcal{S}[\bm{\Sigma},\bm{\Psi}]

\displaystyle=-\textbf{Tr}\ \bm{\Psi}\bm{\Sigma}-\frac{2}{N}\ln\mathcal{Z}_{A}(\bm{\Psi})-\textbf{Tr}\ \hat{\bm{\Sigma}}_{\star}\bm{\Sigma}-\frac{1}{N}\textbf{Tr}\ \log\left(\hat{\bm{\Sigma}}_{\star}\otimes\bm{I}+\bm{P}\otimes\bm{B}\right)+\textbf{Tr}\ \log\bm{\Sigma},

where we introduced the super-trace notation
\textbf{{Tr}}\ \bm{\Sigma}\bm{\Psi}=\int d\omega d\omega^{\prime}\ \text{Tr}\bm{\Sigma}(\omega,\omega^{\prime})\bm{\Psi}(\omega,\omega^{\prime})
represents both trace over the dimension of the matrix and integration over the frequency and the matrix
\bm{P}=\begin{bmatrix}0&1\\
1&0\end{bmatrix}
. The single site MGF
\mathcal{Z}_{A}(\bm{\Psi})
has the form

\displaystyle\mathcal{Z}_{A}(\bm{\Psi})

\displaystyle=\int\exp\left(-\frac{1}{2}\int d\omega d\omega^{\prime}\left[\Psi_{\chi\chi}(\omega,\omega^{\prime})\bm{\chi}(\omega)\cdot\bm{\chi}(\omega^{\prime})+\Psi_{hh}(\omega,\omega^{\prime})\bm{h}(\omega)^{\top}\bm{A}^{2}\bm{h}(\omega^{\prime})\right]\right)

\displaystyle\times\exp\left(-\int d\omega d\omega^{\prime}\ \bm{\chi}(\omega)\cdot\left(i\omega\delta(\omega-\omega^{\prime})\bm{I}+\Psi_{h\chi}(\omega,\omega^{\prime})\bm{A}\right)\bm{h}(\omega^{\prime})\right)

(109)

The order parameter
\hat{\bm{\Sigma}}_{\star}
is an implicit function of
\bm{\Sigma}
that satisfies the equation

\displaystyle\bm{\Sigma}=\frac{1}{N}\textbf{Tr}\left(\hat{\bm{\Sigma}}_{\star}\otimes\bm{I}+\bm{P}\otimes\bm{B}\right)^{-1}.

(110)

As
N\to\infty
, the dominant contribution from the integral over
\{\bm{\Sigma},\bm{\Psi}\}
is the saddle point

\displaystyle\frac{\partial\mathcal{S}}{\partial\bm{\Sigma}}=0\ ,\ \frac{\partial\mathcal{S}}{\partial\bm{\Psi}}=0

(111)

At the saddle point (which dominates as
N\to\infty
), the structure of the
\bm{\Psi}
and
\bm{\Sigma}

\displaystyle\bm{\Sigma}(\omega,\omega^{\prime})=\begin{bmatrix}\Sigma_{hh}(\omega,\omega^{\prime})&\Sigma_{h\chi}(\omega,\omega^{\prime})\\
\Sigma_{h\chi}(\omega,\omega^{\prime})&0\end{bmatrix}\ ,\ \bm{\Psi}(\omega,\omega^{\prime})=\begin{bmatrix}0&\Psi_{h\chi}(\omega,\omega^{\prime})\\
\Psi_{\chi h}(\omega,\omega^{\prime})&\Psi_{\chi\chi}(\omega,\omega^{\prime})\end{bmatrix}

(112)

We will see that the diagonal and off-diagonal components of
\bm{\Sigma}(\omega,\omega^{\prime})
and
\bm{\Psi}(\omega,\omega^{\prime})
provide the correlation and response functions respectively.

7.1
Response Functions

Under the saddle point equations, the off-diagonal entries of the order parameters decouple over frequencies and encode the response function

\displaystyle\Sigma_{h\chi}(\omega,\omega^{\prime})=\Sigma_{\chi h}(\omega,\omega^{\prime})=\delta(\omega-\omega^{\prime})\ \mathcal{H}(\omega),

(113)

where
\mathcal{H}(\omega)
is the usual single-frequency response function. Similarly, we have
\Psi_{h\chi}(\omega,\omega^{\prime})=\Psi(\omega)\delta(\omega-\omega^{\prime})
and
\hat{\Sigma}_{h\chi}(\omega,\omega^{\prime})=\delta(\omega-\omega^{\prime})\hat{\Sigma}(\omega)
where these single frequency functions satisfy the following

\displaystyle\Psi(\omega)=\mathcal{H}(\omega)^{-1}-\hat{\Sigma}(\omega)\ ,\ \mathcal{H}(\omega)=\text{tr}\left(\hat{\Sigma}(\omega)+\bm{B}\right)^{-1}

(114)

\displaystyle\Psi(\omega)\mathcal{H}(\omega)=\text{tr}\bm{A}\left(i\omega\Psi(\omega)^{-1}+\bm{A}\right)^{-1}=\text{tr}\bm{B}\left(\hat{\Sigma}(\omega)+\bm{B}\right)^{-1}.

(115)

We see that it would be convenient to define the
\mathcal{T}_{\bm{A}}(\omega)
transform of a matrix
\bm{A}
and its inverse function
i\omega_{\bm{A}}(\mathcal{T})

\displaystyle\mathcal{T}_{\bm{A}}(i\omega)\equiv\text{tr}\bm{A}\left(i\omega+\bm{A}\right)^{-1}\ ,\ i\omega_{\bm{A}}(\mathcal{T})=\mathcal{T}^{-1}_{\bm{A}}(\mathcal{T})

(116)

Using this definition, we find the simple relationship between the matrices
\bm{A},\bm{B},\bm{M}

\displaystyle\mathcal{T}_{\bm{M}}(i\omega)=\text{tr}\bm{A}\left(i\omega/\Psi(\omega)+\bm{A}\right)^{-1}=\mathcal{T}_{\bm{A}}(i\omega_{\bm{A}})=\mathcal{T}_{\bm{B}}(i\omega_{\bm{B}})

(117)

\displaystyle i\omega_{\bm{A}}=i\omega/\Psi(\omega)\ ,\ i\omega_{\bm{B}}=\hat{\Sigma}(\omega)

(118)

We can reformulate the subordination relation as an equivalence in the
\mathcal{T}
transforms computed across these matrices

\displaystyle\mathcal{T}_{\bm{A}}(i\omega_{\bm{A}})=\mathcal{T}_{\bm{B}}(i\omega_{\bm{B}})=\mathcal{T}_{\bm{M}}(i\omega)=\mathcal{T}

(119)

where from the saddle point equations, the variables
\{i\omega_{\bm{A}},i\omega_{\bm{B}},i\omega,\mathcal{T}\}
satisfy

\displaystyle i\omega_{A}(\mathcal{T})\ i\omega_{B}(\mathcal{T})=\frac{1-\mathcal{T}}{\mathcal{T}}\ i\omega.

(120)

This determines
\mathcal{T}(i\omega)
from which we can infer the response function function
\mathcal{H}(\omega)=\frac{1}{i\omega}\left[1-\mathcal{T}(i\omega)\right]
. The eigenvalue density can, as before, be obtained from
\rho(\lambda)=\frac{1}{\pi}\lim_{\epsilon\to 0}\Im\ \mathcal{H}(i\lambda-\epsilon)
.

\displaystyle\bm{h}(\omega)\bm{h}(\omega^{\prime})^{\top}

\displaystyle\simeq\left(i\omega+\Psi(\omega)\bm{A}\right)^{-1}\bm{h}_{0}\bm{h}_{0}^{\top}\left(i\omega^{\prime}+\Psi(\omega^{\prime})\bm{A}\right)^{-1}

\displaystyle+\begin{cases}\frac{\Gamma(\omega,\omega^{\prime})}{1-\Gamma(\omega,\omega^{\prime})}\left(i\omega+\Psi(\omega)\bm{A}\right)^{-1}\left(i\omega^{\prime}+\Psi(\omega^{\prime})\bm{A}\right)^{-1}&\text{Asymmetric}\\
\frac{\Gamma(\omega,\omega^{\prime})}{1-\Gamma(\omega,\omega^{\prime})}\ \bm{A}\ \left(i\omega+\Psi(\omega)\bm{A}\right)^{-1}\left(i\omega^{\prime}+\Psi(\omega^{\prime})\bm{A}\right)^{-1}&\text{Symmetrized}\end{cases}.

(134)

We see that the bias term (the first term) is identical across both cases, but that the variance term differs by a factor of
\bm{A}
in the symmetrized and asymmetric cases. The function
\Gamma(\omega,\omega^{\prime})
which controls the variance has the following form

\displaystyle\Gamma(\omega,\omega^{\prime})

\displaystyle=\frac{1}{\alpha}-\frac{\alpha}{(i\omega+\Psi(\omega))(i\omega^{\prime}+\Psi(\omega^{\prime}))}\times\left[\frac{\beta}{(i\omega_{\bm{B}}+1)(i\omega_{\bm{B}}^{\prime}+1)}+\frac{1-\beta}{i\omega_{\bm{B}}i\omega_{\bm{B}}^{\prime}}\right]^{-1}.

(135)

For isotropic and random initial conditions
\left<\bm{h}_{0}\bm{h}_{0}^{\top}\right>=\bm{I}
, the correlation functions have the form

\displaystyle\mathcal{C}(\omega,\omega^{\prime})=\begin{cases}\frac{1}{1-\Gamma(\omega,\omega^{\prime})}\left[\frac{\alpha}{(i\omega+\Psi(\omega))(i\omega^{\prime}+\Psi(\omega^{\prime}))}+\frac{1-\alpha}{i\omega i\omega^{\prime}}\right]&\text{Asymmetric}\\
\frac{1}{1-\Gamma(\omega,\omega^{\prime})}\left[\frac{\alpha}{(i\omega+\Psi(\omega))(i\omega^{\prime}+\Psi(\omega^{\prime}))}\right]+\frac{1-\alpha}{i\omega i\omega^{\prime}}&\text{Symmetrized}\end{cases}

(136)

In the symmetrized case, the null-space of the matrix
\bm{A}
(which has dimension
(1-\alpha)N
) does not interact with the variance term that appears in
\mathcal{C}(\omega,\omega^{\prime})
, while in the asymmetric case, it is amplified by a factor
\frac{1}{1-\Gamma(\omega,\omega^{\prime})}
, indicating interaction with the variance of the dynamics. In the next section we will show that this implies the final value of
\lim_{t\to\infty}C(t,t)
cannot diverge for the symmetrized matrix but the final value can diverge when
\alpha=\beta
for the asymmetric case, similar to the random feature model at
\nu=\alpha
.

Final Correlation Values: Asymmetric vs Symmetrized

To illustrate the impact of the the non-normality on the final value of the correlation function, we can now evaluate the
\omega\to 0
limit. The
\Psi
function has the following behavior

\displaystyle\Psi(\omega)=\frac{i\omega}{i\omega_{A}}\sim\begin{cases}\frac{i\omega\beta}{\alpha-\beta}&\alpha>\beta\\
\frac{\beta-\alpha}{1-\alpha}&\alpha<\beta\end{cases}\ ,\ i\omega\to 0.

(137)

The final values of the correlation function have the following form

\displaystyle\lim_{t\to\infty}C(t,t)=\begin{cases}|\alpha-\beta|+\frac{\max(\alpha,\beta)(1-\max(\alpha,\beta))}{|\alpha-\beta|}&\text{Asymmetric}\\
[1-\min(\alpha,\beta)]_{+}&\text{Symmetrized}\end{cases}

(138)

We note that this loss curve exhibits a divergence at
\alpha=\beta
, reminiscent of the isotropic random feature model where the matrices had independent entries where a divergence occurred at
\alpha=\nu
. While the structure of the loss curve is distinct from the random feature model due to distinct spectra, the
\sqrt{t}
blowup at the interpolation threshold is universal.

8
Non-Hermitian Systems with Complex Spectra

Unfortunately, the response function for a DMFT does not always capture the full spectrum of a random matrix. In fact this can lead to problems for matrices whose spectral densities are not confined to the real line in the complex plane.

Standard DMFT Response and Spectra in Complex Plane

To see an example of the failure of the standard response function to capture a spectrum that is extended in the complex plane, consider the case of an asymmetric random Gaussian matrix
M_{ij}\sim\mathcal{N}(0,1/N)
. The behavior of this system as
N\to\infty
is governed by the following DMFT equation

\displaystyle\text{DMFT Equation:}\quad\frac{d}{dt}h(t)=u(t)\ ,\ u(t)\sim\mathcal{GP}(0,C(t,t^{\prime}))

(139)

\displaystyle\implies\text{Trivial Response Function:}\quad\mathcal{R}(\omega)=\frac{1}{i\omega},

(140)

which is indistinguishable from the response function for
\bm{M}=\bm{0}
. Thus the spectral density of
\bm{M}
cannot be obtained by studying the simple dynamical system driven by the matrix
\bm{M}

6
6

6

This failure is closely connected to the failure of moment methods and standard expansions of the resolvent that use
\text{tr}\left<\bm{M}^{k}\right>
to compute resolvents for generic asymmetric matrices.
.

Hermitianization

To counteract this problem, we can consider a dynamical system driven by a
hermitian matrix
which relaxes to a fixed point that depends on the resolvent of the matrix
31
;
26
;
6
;
24
. We consider the following flows

\displaystyle\frac{d}{dt}\bm{h}(t)=-\left(\bm{M}-z\right)^{\dagger}\left[\left(\bm{M}-z\right)\bm{h}(t,z)+\bm{b}\right],

(141)

where
z\in\mathbb{C}
is an arbitrary complex argument. Since the matrix
\left(\bm{M}-z\right)^{\dagger}\left(\bm{M}-z\right)
is Hermitian and positive semidefinite, the dynamics will relax to the following long time limit

\displaystyle\lim_{t\to\infty}\bm{h}(t)=\left(z-\bm{M}\right)^{-1}\bm{b}

(142)

The resolvent of the matrix for complex
z=x+iy\in\mathbb{C}
and the density
\rho(z)
can be obtained from the long time limit

\displaystyle\mathcal{G}(z)=\lim_{t\to\infty}\text{tr}\left(\frac{\partial\bm{h}(t)}{\partial\bm{b}^{\top}}\right)=\text{tr}\left(z-\bm{M}\right)^{-1}\quad\rho(z)=\frac{1}{\pi}\partial_{z^{\star}}\mathcal{G}(z)

(143)

from which the spectral density in the complex plane at point
z\in\mathbb{C}
can be obtained
7
7

7

We use the definition
\partial_{z^{\star}}=\frac{1}{2}(\partial_{x}+i\partial_{y})
for
z=x+iy
so that
\partial_{z^{\star}}z^{\star}=1
and
\partial_{z^{\star}}\ \frac{1}{z}=\delta(z)
.
. Fortunately, this
Hermitianized
dynamical system does generate response functions in its associated DMFT equations that enable computation of the complex spectrum from the long time limit
8
8

8

For readers familiar with Hermitianization, often a regulator is introduced when computing the resolvent of the Hermitianized matrix
48
. In our setup, the finite time plays the role of the regulator, with the long-time limit
t\to\infty
(
i\omega\to 0
) giving the final result.
.

8.1
Ginibre Matrices and the Circular Law

The simplest such example is a completely asymmetric random matrix
\bm{M}=\frac{1}{\sqrt{N}}\bm{A}
where
A_{ij}\sim\mathcal{N}(0,1)
have real entries with no symmetry requirement. As before, we break up the dynamics into two separate processes whose defining equations are each linear in
\bm{M}

\displaystyle\frac{d}{dt}\bm{h}_{0}(t)=-\left(\bm{M}-z\right)^{\dagger}\bm{h}_{1}(t)\ ,\ \bm{h}_{1}(t)=\left(\bm{M}-z\right)\bm{h}_{0}(t)+\bm{b}.

(144)

The long time limit of
\bm{h}_{0}
is a function of the matrix resolvent

\displaystyle\lim_{t\to\infty}\bm{h}_{0}(t)=\left(z-\bm{M}\right)^{-1}\bm{b}

(145)

We can therefore investigate the limit of the dynamical system we started with. These dynamics in the
N\to\infty
limit, can be described by the following DMFT equations

\displaystyle\frac{d}{dt}h_{0}(t)=-h^{2}(t)\ ,\ h^{2}(t)=\xi_{2}(t)+\int dt^{\prime}\ R_{1}(t,t^{\prime})h_{0}(t^{\prime})-z^{\star}h_{1}(t)

(146)

\displaystyle h_{1}(t)=\xi_{1}(t)+\int dt^{\prime}\ R_{0,2}(t,t^{\prime})h_{1}(t^{\prime})-zh_{0}(t)+b

(147)

where
R_{1}(t,t^{\prime})=\frac{\partial h_{1}(t)}{\partial\xi_{1}(t^{\prime})}
and
R_{0,2}(t,t^{\prime})=\frac{\partial h_{0}(t)}{\partial\xi_{2}(t^{\prime})}
are the response functions that arise from the DMFT equations. Defining
\mathcal{H}(t,t^{\prime})=-R_{0,2}(t,t^{\prime})
and taking a Fourier transform, we find

\displaystyle i\omega=\frac{1}{\mathcal{H}(\omega)(1+\mathcal{H}(\omega))^{2}}\left[1-(|z|^{2}-1)\mathcal{H}(\omega)\right].

(148)

We are interested in the solutions to this equation as
i\omega\to 0
. One solution is
\mathcal{H}(\omega)=\frac{1}{|z|^{2}-1}
, but there are two other solutions
\mathcal{H}(\omega)\sim\pm(i\omega)^{-1/2}\left[1-|z|^{2}\right]^{1/2}
. For a given value of
|z|^{2}
, we select the branch which gives an analytic function of
z
and decays like
\mathcal{G}(z)\sim\frac{1}{z}
for large
|z|
. Thus for
|z|>1
, we choose
\mathcal{H}(\omega)=\left[|z|^{2}-1\right]^{-1}
, while for
|z|<1
we choose the diverging solutions. This results in the following expression for the resolvent and eigenvalue density,

\displaystyle\mathcal{G}(z)=\lim_{\omega\to 0}\frac{z^{\star}}{1+\mathcal{H}(\omega)^{-1}}=\begin{cases}z^{\star}&|z|^{2}\leq 1\\
\frac{1}{z}&|z|^{2}>1\end{cases}\implies\rho(z)=\begin{cases}\frac{1}{\pi}&|z|^{2}<1\\
0&|z|^{2}>1\end{cases}.

(149)

This recovers the circular law, where the eigenvalue density is uniform in a unit disk in the complex plane
30
;
48
.

8.2
Diagonally Modulated Gaussian

To see how this method can be used for slightly more interesting ensembles, consider a Gaussian asymmetric matrix
\bm{A}
which is multiplied by a diagonal matrix with entries
\sigma_{i}
, each of which are iid draws from some distribution
\mu(\sigma)

\displaystyle\bm{M}=\frac{1}{\sqrt{N}}\ \bm{A}\ \text{diag}(\bm{\sigma})\quad,\quad\sigma_{i}\sim\mu(\sigma).

(150)

This ensemble is of interest in theoretical neuroscience since it describes the eigenvalues of the Jacobian for a randomly connected recurrent neural network
49
;
32
. The DMFT equations for the Hermitianized dynamical system take the form

\displaystyle\frac{d}{dt}h_{0}(t)=-h_{2}(t)\ ,\ h_{2}(t)=\xi_{2}(t)+\sigma^{2}\int dt^{\prime}R_{1}(t,t^{\prime})h_{0}(t^{\prime})-z^{\star}h_{1}(t)

\displaystyle h_{1}(t)=\xi_{1}(t)+\int dt^{\prime}R_{0,2}(t,t^{\prime})h_{1}(t^{\prime})-zh_{0}(t^{\prime})+b.

(151)

In the above expressions, the dynamics for
h_{0}
are modulated by the random variable
\sigma\sim\mu(\sigma)
. The response functions
R_{1}(t,t^{\prime})
and
R_{0,2}(t,t^{\prime})
are computed as

\displaystyle R_{1}(t,t^{\prime})=\left<\frac{\partial h_{1}(t)}{\partial\xi_{1}(t^{\prime})}\right>_{\sigma}\ ,\ R_{0,2}(t,t^{\prime})=\left<\sigma^{2}\frac{\partial h_{0}(t)}{\partial\xi_{2}(t^{\prime})}\right>_{\sigma}

(152)

where the average
\left<\cdot\right>
is over the measure
\mu(\sigma)
. To close the equations for the response functions, it will be advantagous to introduce a function
\mathcal{H}_{\sigma}(\omega)\equiv-\int d\tau e^{-i\omega\tau}\frac{\partial h_{0}(t+\tau)}{\partial\xi_{2}(t)}
which is the response function
conditional on a particular value of
\sigma
.

\displaystyle\mathcal{H}_{\sigma}(\omega)\equiv\frac{1}{i\omega+\sigma^{2}\mathcal{R}_{1}(\omega)+\frac{|z|^{2}}{1-\mathcal{R}_{0,2}(\omega)}}

(153)

From this function, we can compute the averaged Fourier-transformed response functions
\mathcal{R}_{1}(\omega)
and
\mathcal{R}_{0,2}(\omega)
as

\displaystyle\mathcal{R}_{0,2}(\omega)=-\left<\sigma^{2}\mathcal{H}_{\sigma}(\omega)\right>\ ,\ \mathcal{R}_{1}(\omega)=\frac{1}{1+\left<\sigma^{2}\mathcal{H}_{\sigma}(\omega)\right>}\left[1-\frac{|z|^{2}\left<\mathcal{H}_{\sigma}(\omega)\right>}{1+\left<\sigma^{2}\mathcal{H}_{\sigma}(\omega)\right>}\right]

(154)

where
\left<\cdot\right>
represents an average over
\rho(\sigma)
. Lastly we can recover the limiting resolvent and spectral density from

\displaystyle\mathcal{G}(z)=\lim_{\omega\to 0}\frac{\left<\mathcal{H}_{\sigma}(\omega)\right>z^{\star}}{1+\left<\sigma^{2}\mathcal{H}_{\sigma}(\omega)\right>}\ ,\ \rho(z)=\frac{1}{\pi}\partial_{z^{\star}}\mathcal{G}(z)

(155)

The defining equation for
\mathcal{H}_{\sigma}(\omega)
depends on the random variable
\sigma
two moments
\left<\mathcal{H}(\omega)\right>
and
\left<\mathcal{H}(\omega)\sigma^{2}\right>

\displaystyle\mathcal{H}_{\sigma}(\omega)=\frac{(1+\left<\sigma^{2}\mathcal{H}_{\sigma}(\omega)\right>)^{2}}{i\omega(1+\left<\sigma^{2}\mathcal{H}_{\sigma}(\omega)\right>)^{2}+\sigma^{2}\left(1+\left<\sigma^{2}\mathcal{H}_{\sigma}(\omega)\right>-|z|^{2}\left<\mathcal{H}_{\sigma}(\omega)\right>\right)+|z|^{2}(1+\left<\sigma^{2}\mathcal{H}_{\sigma}(\omega)\right>)}

(156)

For the first solution, we will investigate when
\left<\sigma^{2}\mathcal{H}_{\sigma}(\omega)\right>=\mathcal{O}(1)
as
i\omega\to 0
. In this case,

\displaystyle\mathcal{G}(z)=\lim_{\omega\to 0}\frac{z^{\star}\left<\mathcal{H}_{\sigma}(\omega)\right>}{1+\left<\sigma^{2}\mathcal{H}_{\sigma}(\omega)\right>}=\frac{1}{z}

(157)

In the other case, we investigate
\left<\sigma^{2}\mathcal{H}(\omega)\right>
which diverges as
i\omega\to 0
. This leads to the condition

\displaystyle 1=\left<\frac{\sigma^{2}}{|z|^{2}+\sigma^{2}\left(1-z\mathcal{G}(z)\right)}\right>.

(158)

The boundary separating these two solutions occurs when this solution approaches
\mathcal{G}(z)=\frac{1}{z}
, which occurs for
|z|=\sqrt{\left<\sigma^{2}\right>}
. The eigenvalue density in the bulk region can be obtained by differentiating the above equation, resulting in the density

\displaystyle\rho(z)=\frac{1}{\pi}\left<\frac{\sigma^{2}}{\left[|z|^{2}+\sigma^{2}\left(1-z\mathcal{G}(z)\right)\right]^{2}}\right>\left<\frac{\sigma^{4}}{\left[|z|^{2}+\sigma^{2}\left(1-z\mathcal{G}(z)\right)\right]^{2}}\right>^{-1}\Theta\left(\left<\sigma^{2}\right>-|z|^{2}\right)

(159)

If the density of diagonal values is Bernoulli over
\{\pm\sigma_{\star}\}
with probability
1/2
, (i.e.
\mu(\sigma)=\frac{1}{2}\delta(\sigma-\sigma_{\star})+\frac{1}{2}\delta(\sigma+\sigma_{\star})
) then we recover the previous result (the circular law) where
\rho(z)=\frac{1}{\pi\sigma^{2}_{\star}}\Theta(\sigma^{2}_{\star}-|z|^{2})
as we show in Figure
12
(a). However, for other distributions
\mu(\sigma)
variables, the density in the bulk is generally non-uniform as we show in Figure

(b).

9
Beyond Linear TTI Structure, Evolving Matrices

In the previous examples, the random matrices appearing in the dynamics were frozen. Since the dynamics for
\bm{h}
were linear, the response functions were time-translation invariant (TTI) and could be obtained directly from a Fourier transform. Subsequently, the correlation functions could be computed in closed form as a two-variable Fourier transform. However, DMFT is arguably most useful in settings beyond linear dynamics. In this section, we illustrate a few simple examples where the resulting DMFT equations remain Gaussian, which enables exact analytical computations of the correlations. A number of interesting high dimensional systems with this Gaussian property have been recently shown to capture similar phenomena such as transitions to chaos, aging dynamics, and potential separations from mean field statics
28
;
27
.

9.1
Toy Example: Simple (Anti)-Hebbian Linear Dynamics

Consider a linear dynamical system with dynamical connectivity
\bm{M}(t)
. While this model was studied in a nonlinear RNN with asymmetric initial connectivity
18
, we will take
\bm{M}(0)
to be a GOE matrix and study a linear RNN with adaptive weights

\displaystyle\frac{d}{dt}\bm{h}(t)=-\bm{M}(t)\bm{h}(t)\ ,\ \frac{d}{dt}\bm{M}(t)=\frac{\gamma}{N}\bm{h}(t)\bm{h}(t)^{\top}.

(160)

In the above system, the matrix
\bm{M}
has two random components, a random initial matrix
\bm{M}(0)
and a dynamical spike
\gamma N^{-1}\int_{0}^{t}dt^{\prime}\ \bm{h}(t^{\prime})\bm{h}(t^{\prime})^{\top}
which depends on the random variables
\bm{h}(t)
that themselves depend on
\bm{M}(0)
. Fortunately, one can still easily compute the DMFT system to characterize the
N\to\infty
limit. As before, the single-site stochastic process for
h(t)
depends only on the correlation and response

\displaystyle\frac{d}{dt}h(t)=u(t)+\int_{0}^{t}dt^{\prime}R(t,t^{\prime})h(t^{\prime})-\gamma\int_{0}^{t}dt^{\prime}\ C(t,t^{\prime})h(t^{\prime})\ ,\ u(t)\sim\mathcal{GP}(0,C(t,t^{\prime})).

(161)

In the above, the only two order parameters that arise are the correlation
C(t,t^{\prime})
and response
R(t,t^{\prime})
. We note that this system, unlike the linear dynamics (
\gamma=0
), is non-TTI and the response functions cannot be solved for directly through Fourier transform. Rather, we are left with a coupled set of integro-differential equations for our two-time order parameters

\displaystyle\frac{\partial}{\partial t}C(t,t^{\prime})=\int_{0}^{t}dt^{\prime\prime}\left[R(t^{\prime},t^{\prime\prime})C(t^{\prime\prime},t)+R(t,t^{\prime\prime})C(t^{\prime\prime},t^{\prime})-\gamma C(t,t^{\prime\prime})C(t^{\prime\prime},t^{\prime})\right]

\displaystyle\frac{\partial}{\partial t}R(t,t^{\prime})=\delta(t-t^{\prime})+\int_{0}^{t}dt^{\prime\prime}\left[R(t,t^{\prime\prime})R(t^{\prime\prime},t^{\prime})-\gamma C(t,t^{\prime\prime})R(t^{\prime\prime},t^{\prime})\right].

(162)

These integro-differential equations capture the interesting transient and late time dynamics of this model as we show in Figure
13
. Despite no longer being exactly solveable in frequency space, the DMFT equations can be integrated in real time to capture the asymptotic
N\to\infty
limit of the dynamics.

9.2
Deep Linear ResNets under Random Initialization

Another setting where DMFT equations still provide an exact description of the asymptotic dynamics, without having a TTI description is the training dynamics of randomly initialized infinite width neural networks
14
;
13
. In this model, all weights of the network start off as random matrices, but experience structured updates from training. In this setting, we will briefly describe a special case of deep linear networks trained on random data in a proportional scaling regime for input dimension
N_{0}
, hidden width
N_{1}
and dataset size
P

15

\displaystyle N_{0},N_{1},P\to\infty\ ,\ \frac{P}{N_{0}}=\alpha\ ,\ \frac{N_{1}}{N_{0}}=\nu.

(163)

We consider a
L
hidden layer linear network
f(\bm{x})
and a noisy linear target function
y(\bm{x})

\displaystyle f(\bm{x})=\frac{\sqrt{N_{0}}}{\gamma_{0}N_{1}}\ \bm{w}^{L}\cdot\prod_{\ell=1}^{L-1}\left(\bm{I}+\frac{\beta}{\sqrt{N_{1}}}\bm{W}^{\ell}\right)\left(\frac{1}{\sqrt{N_{0}}}\bm{W}^{0}\right)\bm{x}\quad,\quad y(\bm{x})=\frac{1}{\sqrt{N_{0}}}\bm{\beta}_{\star}\cdot\bm{x}+\sigma\epsilon

(164)

We train all parameters
\bm{\theta}\in\{\bm{w}^{L},\bm{W}^{L-1},...,\bm{W}^{0}\}
with gradient flow with learning rate
\eta=N_{1}\gamma_{0}^{2}
on a training loss
\mathcal{\hat{L}}=\frac{1}{P}\sum_{\mu=1}^{P}\left(f(\bm{x}_{\mu},t)-y_{\mu}\right)^{2}
defined over dataset
\mathcal{D}=\{(\bm{x}_{\mu},y_{\mu})\}_{\mu=1}^{P}

\displaystyle\frac{d}{dt}\bm{\theta}(t)=-\eta\frac{\partial}{\partial\bm{\theta}}\ \hat{\mathcal{L}}(t).

(165)

We aim to characterize not only the training loss but also the test loss, which is an average over the population distribution for
\bm{x}
and
\epsilon
.

\displaystyle\mathcal{L}(t)=\left<\left(f(\bm{x},t)-y(\bm{x})\right)^{2}\right>_{\bm{x},\epsilon}

(166)

The vector
\bm{v}(t)
which controls the test loss
\mathcal{L}(t)=\frac{1}{N_{0}}\bm{v}(t)\cdot\bm{v}(t)+\sigma^{2}
is defined as

\displaystyle\bm{v}(t)\equiv\bm{\beta}_{\star}-\frac{\sqrt{N_{0}}}{\gamma_{0}N_{1}}\bm{W}^{0}(t)^{\top}\left[\prod_{\ell=1}^{L-1}\left(\bm{I}+\frac{\beta}{\sqrt{N_{1}}}\bm{W}^{\ell}(t)\right)\right]^{\top}\bm{w}^{L}(t).

(167)

We note that the gradient flow dynamics on the weights
\bm{W}^{\ell}(t)
can be expressed in terms of its initial condition
\bm{W}^{\ell}(t)
and a low rank update expressed in terms of vectors
\bm{h}^{\ell}(t)
and
\bm{g}^{\ell}(t)

\displaystyle\bm{w}^{L}(t)=\bm{w}^{L}(0)+\gamma_{0}\int_{0}^{t}dt^{\prime}\ \bm{h}^{L}(t^{\prime})

\displaystyle\bm{W}^{\ell}(t)=\bm{W}^{\ell}(0)+\frac{\gamma_{0}\beta}{\sqrt{N_{1}}}\int_{0}^{t}dt^{\prime}\ \bm{g}^{\ell+1}(t^{\prime})\bm{h}^{\ell}(t^{\prime})^{\top}

\displaystyle\bm{W}^{0}(t)=\bm{W}^{0}(0)+\frac{\gamma_{0}}{\sqrt{N_{0}}}\int_{0}^{t}dt^{\prime}\ \bm{g}^{1}(t^{\prime})\bm{h}^{0}(t^{\prime})^{\top}

(168)

where the vectors
\bm{h}^{\ell}(t)
and
\bm{g}^{\ell}(t)
are defined as forward pass and backward pass variables

\displaystyle\bm{h}^{0}(t)=\frac{\sqrt{N_{0}}}{P}\bm{X}^{\top}\bm{\Delta}(t)\ ,\ \bm{\Delta}(t)=\frac{1}{\sqrt{N_{0}}}\bm{X}\bm{v}(t)+\sigma\epsilon

\displaystyle\bm{h}^{1}(t)=\frac{1}{\sqrt{N_{0}}}\bm{W}^{0}(t)\bm{h}^{0}(t)\ ,\ \bm{h}^{\ell+1}(t)=\bm{h}^{\ell}(t)+\frac{\beta}{\sqrt{N_{1}}}\bm{W}^{\ell}(t)\bm{h}^{\ell}(t)\ ,\ \ell\in\{1,...,L-1\}

\displaystyle\bm{g}^{L}(t)=\bm{w}^{L}(t)\quad,\quad\bm{g}^{\ell}(t)=\bm{g}^{\ell+1}(t)+\frac{\beta}{\sqrt{N_{1}}}\bm{W}^{\ell}(t)^{\top}\bm{g}^{\ell+1}(t)\ ,\ \ell\in\{1,...,L-1\}.

(169)

To isolate the dependence of these variables on the initial random matrices, we introduce variables
\bm{\chi}^{\ell}(t)
and
\bm{\xi}^{\ell}(t)
which depend explicitly on the initial conditions for the weights
\bm{W}^{\ell}(0)

\displaystyle\bm{\chi}^{1}(t)=\frac{1}{\sqrt{N_{0}}}\bm{W}^{0}(0)\bm{h}^{0}(t)\ ,\ \bm{\chi}^{\ell+1}(t)=\frac{1}{\sqrt{N_{1}}}\bm{W}^{\ell}(0)\bm{h}^{\ell}(t)

\displaystyle\bm{\xi}^{0}(t)=\frac{\sqrt{N_{0}}}{N_{1}}\bm{W}^{0}(0)^{\top}\bm{g}^{1}(t)\ ,\ \bm{\xi}^{\ell}(t)=\frac{1}{\sqrt{N_{1}}}\bm{W}^{\ell}(0)^{\top}\bm{g}^{\ell+1}(t)

(170)

The full DMFT equations in the proportional scaling limit
P/N_{0}=\alpha
and
N_{1}/N_{0}=\nu
are thus

\displaystyle v(t)=\beta_{\star}-\frac{1}{\gamma_{0}}r^{0}(t)-\int_{0}^{t}dt^{\prime}\left[\gamma_{0}^{-1}R_{gu}^{1}(t,t^{\prime})+C_{g}^{1}(t,t^{\prime})\right]h^{0}(t^{\prime})\ ,\ r^{0}(t)\sim\mathcal{N}\left(0,\frac{1}{\nu}C_{g}^{1}(t,t^{\prime})\right)

\displaystyle h^{0}(t)=u^{0}(t)+\int_{0}^{t}dt^{\prime}R_{\Delta}(t,t^{\prime})v(t^{\prime})\ ,\ u^{0}(t)\sim\mathcal{GP}\left(0,\frac{1}{\alpha}C_{\Delta}(t,t^{\prime})\right)

\displaystyle\Delta(t)=u_{\Delta}(t)+\frac{1}{\alpha}\int_{0}^{t}R_{vu}^{0}(t,t^{\prime})\Delta(t^{\prime})+\sigma\epsilon\ ,\ u_{\Delta}(t)\sim\mathcal{GP}\left(0,C_{v}(t,t^{\prime})\right)\ ,\ \epsilon\sim\mathcal{N}(0,1)

\displaystyle h^{1}(t)=u^{1}(t)+\int_{0}^{t}dt^{\prime}\left[\frac{1}{\nu}R_{hr}^{0}(t,t^{\prime})+\gamma_{0}C_{h}^{0}(t,t^{\prime})\right]g^{1}(t^{\prime})\ ,\ u^{1}(t)\sim\mathcal{GP}\left(0,C_{h}^{0}(t,t^{\prime})\right)

\displaystyle h^{\ell+1}(t)=h^{\ell}(t)+\beta u^{\ell+1}(t)+\beta\int_{0}^{t}dt^{\prime}\left[R_{hr}^{\ell}(t,t^{\prime})+\gamma_{0}\beta C_{h}^{\ell}(t,t^{\prime})\right]g^{\ell+1}(t^{\prime})\ ,\ u^{\ell+1}(t)\sim\mathcal{GP}\left(0,C_{h}^{\ell}(t,t^{\prime})\right)

\displaystyle g^{L}(t)=r^{L}+\gamma_{0}\int_{0}^{t}dt^{\prime}h^{L}(t^{\prime})\ ,\ r^{L}\sim\mathcal{N}(0,1)

\displaystyle g^{\ell}(t)=g^{\ell+1}(t)+\beta r^{\ell}(t)+\beta\int_{0}^{t}dt^{\prime}\left[R_{gu}^{\ell+1}(t,t^{\prime})+\gamma_{0}\beta C_{g}^{\ell+1}(t,t^{\prime})\right]h^{\ell}(t^{\prime})\ ,\ r^{\ell}(t)\sim\mathcal{GP}\left(0,C_{g}^{\ell+1}(t,t^{\prime})\right).

(171)

Despite the original loss function being non-convex in the original trainable parameters
\bm{\theta}
, this system retains Gaussianity of all hidden fields in the proportional limit. The correlation functions
C
in the above dynamics are defined as

\displaystyle C_{\Delta}(t,t^{\prime})=\left<\Delta(t)\Delta(t^{\prime})\right>\ ,\ C_{v}(t,t^{\prime})=\left<v(t)v(t^{\prime})\right>

\displaystyle C_{h}^{\ell}(t,t^{\prime})=\left<h^{\ell}(t)h^{\ell}(t^{\prime})\right>\ ,\ C_{g}^{\ell}(t,t^{\prime})=\left<g^{\ell}(t)g^{\ell}(t^{\prime})\right>

(172)

We note that the test loss and train loss can be computed from htese correlations

\displaystyle\mathcal{L}(t)=C_{v}(t,t)+\sigma^{2}\ ,\ \hat{\mathcal{L}}(t)=C_{\Delta}(t,t).

(173)

The response functions, likewise can be computed as

\displaystyle R_{vu}^{0}(t,t^{\prime})=\frac{\partial v(t)}{\partial u^{0}(t^{\prime})}\ ,\ R_{\Delta}(t,t^{\prime})=\frac{\partial\Delta(t)}{\partial u_{\Delta}(t^{\prime})}

\displaystyle R_{hr}^{\ell}(t,t^{\prime})=\frac{\partial h^{\ell}(t)}{\partial r^{\ell}(t^{\prime})}\ ,\ R_{gu}^{\ell}(t,t^{\prime})=\frac{\partial g^{\ell}(t)}{\partial u^{\ell}(t^{\prime})}

(174)

These equations close directly at the level of correlation and response, however the systems dynamics are no longer time-translation invariant so both correlation and response must be solved for simultaneously (unlike the previous examples where response functions could be solved for independently of the correlations). We plot examples of these equations compared to wide but finite networks in Figure

. Finite
\nu
and finite
\alpha

\beta
is scaled as
\beta=\frac{\beta_{0}}{\sqrt{L}}
, the above dynamics converge to a well defined infinite depth limit as
L\to\infty
. A discrete time version of these equations was explored in

\nu
and
L
in different parameterizations, providing a simple tractable example where the hyperparameter transfer effect can be characterized theoretically

Discussion

In this work, we provided a pedagogical overview of DMFT ideas to analyze the evolution of dynamical systems in high dimensions. Our focus was on dynamical systems that admit single site Gaussian processes in the high dimensional limit. However, the potential application areas of DMFT are far more diverse. While we examined the use of DMFT methods for simple models that yield Gaussian processes, many problems generate asymptotic descriptions that are non-Gaussian including descriptions of training dynamics of nonlinear models with random data
29
;
41
;
42
, training deep nonlinear networks from random initialization
14
;
13
, and Hebbian learning in nonlinear RNNs
18
. In such cases, the single site equations can still be solved with Monte-Carlo sampling to estimate the non-Gaussian single site equations
47
. Approximations which make the limiting equations as tractable as the examples provided in this work are an active area of research
43
;
28
. In general, DMFT is a powerful tool which enables insights into a large variety of complex dynamical systems, including those arising in machine learning theory. We hope that this note inspires future research in this direction.

Appendix A
Path Integral Approach to DMFT

In this section, we describe the basic machinery of the path integral. As a starting point, we take a discretization of the equations of motion with timestep
\delta t

\displaystyle\bm{h}_{n+1}=\bm{h}_{n}-(\delta t)\ \bm{M}\bm{h}_{n}+(\delta t)\ \bm{j}_{n}

(175)

where
\bm{h}_{n}\equiv\bm{h}(t)|_{t=n(\delta t)}
as
\delta t\to 0
. We will first express the path integral in discrete time for finitely many steps before describing its continuous limit
9
9

9

While we will express a formal path integral in continuous time, one could also properly take the saddle point in discrete time over finitely many steps (compared to the number of dimensions
N
) and then subsequently take a continuum limit of the resulting DMFT equations. This procedure generates the same final result.

\displaystyle Z[\bm{\zeta}]=\int\left(\prod_{n=1}^{\infty}d\bm{h}_{n}\right)\ \left<\prod_{n=0}^{\infty}\delta\left(\bm{h}_{n+1}-\bm{h}_{n}+(\delta t)\bm{M}\bm{h}_{n}-\bm{j}_{n}\right)\right>_{\bm{M}}\exp\left((\delta t)\sum_{n=0}^{\infty}\bm{\zeta}_{n}\cdot\bm{h}_{n}\right)

(176)

where
\delta(\cdot)
is a Dirac delta function and the average
\left<\right>
is computed over the random matrix
\bm{M}
. From this convention (known as the Ito convention
[
20
]
), the moment generating function trivially satisfies
Z[\bm{0}]=1
. A key identity which we will utilize repeatedly is the Fourier integral representation of the dirac delta function

\displaystyle\delta(z)=\int_{-\infty}^{\infty}\frac{d\hat{z}}{2\pi}\exp(i\hat{z}z).

(177)

where the
\hat{z}
integral runs over the real axis. Applying this to each timestep for
\bm{h}_{n}
we have

\displaystyle Z=\int\left(\prod_{n=1}^{\infty}\frac{d\bm{h}_{n}d\hat{\bm{h}}_{n}}{(2\pi)^{N}}\right)

\displaystyle\left<\exp\left(i(\delta t)\sum_{n=0}^{\infty}\hat{\bm{h}}_{n+1}\cdot\left[(\bm{h}_{n+1}-\bm{h}_{n})/(\delta t)+\bm{M}\bm{h}_{n}-\bm{j}_{n}\right]\right)\right>_{\bm{M}}

\displaystyle\exp\left((\delta t)\sum_{n=0}^{\infty}\bm{\zeta}_{n}\cdot\bm{h}_{n}\right)

(178)

Now, taking the
dt\to 0
limit, we define the following formal measure over the functions
\bm{h}(t),\hat{\bm{h}}(t)

\displaystyle\mathcal{D}\bm{h}\mathcal{D}\hat{\bm{h}}\equiv\lim_{\delta t\to 0}\left(\prod_{n=0}^{\infty}\frac{d\bm{h}_{n}d\hat{\bm{h}}_{n}}{(2\pi)^{N}}\right).

(179)

Using this notation, we arrive at our formal path integral

\displaystyle Z=\int\mathcal{D}\bm{h}\mathcal{D}\hat{\bm{h}}\left<\exp\left(i\int dt\ \hat{\bm{h}}(t)\cdot\left[\partial_{t}\bm{h}(t)+\bm{M}\bm{h}(t)-\bm{j}(t)\right]+\int dt\ \bm{\zeta}(t)\cdot\bm{h}(t)\right)\right>_{\bm{M}}.

(180)

This is the starting point for the various path integral computations we utilize in this work. Depending on the matrix
\bm{M}
, one arrives at different effective descriptions of the limiting dynamics in terms of a low dimensional set of dynamical order parameters
\bm{Q}
(which are usually a collection of correlation and response functions, see examples in coming sections). The general form for
\bm{Z}
takes the form

\displaystyle Z=\int\mathcal{D}\bm{Q}\exp\left(-N\mathcal{S}[\bm{Q}]\right)

(181)

where
\mathcal{S}
is a
\mathcal{O}(1)
action. The
N\to\infty
limit is dominated by the saddle point

\displaystyle\frac{\partial\mathcal{S}[\bm{Q}]}{\partial\bm{Q}}=0.

(182)

These equations will provide us the DMFT equations for correlation and response functions in each of our examples as we outline in the coming sections for the main examples in the main text.
In this setting, one can characterize higher order moments of
\bm{Q}
over the distribution induced by the DMFT action
\mathcal{S}
. Schematically, leading order corrections to the mean and variance of
\bm{Q}
can be obtained from higher order derivatives of the mean field action (disregarding matrix indices)

\displaystyle\left<\bm{Q}\right>\sim\bm{Q}_{\star}-\frac{1}{2N}\left(\frac{\partial^{3}\mathcal{S}}{\partial\bm{Q}^{3}}\right)\cdot\left(\frac{\partial^{2}\mathcal{S}}{\partial\bm{Q}^{2}}\right)^{-2}+\mathcal{O}(N^{-2})

\displaystyle\left<(\bm{Q}-\bm{Q}_{\star})^{2}\right>\sim\frac{1}{N}\left(\frac{\partial^{2}\mathcal{S}}{\partial\bm{Q}^{2}}\right)^{-1}+\mathcal{O}(N^{-2})

(183)

Thus, at large but finite
N
the order parameters
\bm{Q}
deviate from the saddle point
\bm{Q}_{\star}
through a
\mathcal{O}(N^{-1/2})
zero mean fluctuation and a
\mathcal{O}(N^{-1})
mean shift.

Appendix B
GOE Path Integral Derivation

For the GOE matrix, the average over the matrix
\bm{M}
gives the following

\displaystyle\ln\left<\exp\left(i\int dt\hat{\bm{h}}(t)^{\top}\bm{M}\bm{h}(t)\right)\right>=-\frac{1}{2}\int dtdt^{\prime}\ \hat{\bm{h}}(t)\cdot\hat{\bm{h}}(t^{\prime})\ \underbrace{\frac{1}{N}\bm{h}(t)\cdot\bm{h}(t^{\prime})}_{C(t,t^{\prime})}

\displaystyle-\frac{1}{2}\int dtdt^{\prime}\ \hat{\bm{h}}(t)\cdot\bm{h}(t^{\prime})\ \underbrace{\frac{1}{N}\bm{h}(t)\cdot\hat{\bm{h}}(t^{\prime})}_{iR(t,t^{\prime})}

(184)

We introduced the following correlation and response function

\displaystyle C(t,t^{\prime})=\frac{1}{N}\bm{h}(t)\cdot\bm{h}(t^{\prime})\ ,\ R(t,t^{\prime})=-\frac{i}{N}\bm{h}(t)\cdot\hat{\bm{h}}(t^{\prime}).

(185)

To enforce the definition of these new variables, we need introduce the following resolution of the identity. We start in discrete time, with
C(t,t^{\prime})=C_{n,n^{\prime}}
where
n(\delta t)=t
and
n^{\prime}(\delta t)=t^{\prime}

\displaystyle 1

\displaystyle=N\int dC_{n,n^{\prime}}\delta(NC_{n,n^{\prime}}-\bm{h}_{n}\cdot\bm{h}_{n^{\prime}})

\displaystyle=\int\frac{dC_{n,n^{\prime}}d\hat{C}_{n,n^{\prime}}}{4\pi iN^{-1}(\delta t)^{-2}}\exp\left(\frac{1}{2}(\delta t)^{2}\ \hat{C}_{n,n^{\prime}}\left[NC_{n,n^{\prime}}-\bm{h}_{n}\cdot\bm{h}_{n^{\prime}}\right]\right)

\displaystyle 1

\displaystyle=N\int dR_{n,n^{\prime}}\delta(NR_{n,n^{\prime}}+i\bm{h}_{n}\cdot\hat{\bm{h}}_{n^{\prime}})

\displaystyle=\int\frac{dR_{n,n^{\prime}}d\hat{R}_{n,n^{\prime}}}{4\pi iN^{-1}(\delta t)^{-2}}\exp\left(-\frac{1}{2}(\delta t)^{2}\hat{R}_{n^{\prime},n}\left[NR_{n,n^{\prime}}+i\bm{h}_{n}\cdot\hat{\bm{h}}_{n^{\prime}}\right]\right)

(186)

We multiply the path integral
Z
by these integral expression for each pair of
(n,n^{\prime})
, corresponding to pairs of time. We define the limiting measure over the functions
C(t,t^{\prime}),\hat{C}(t,t^{\prime}),R(t,t^{\prime}),\hat{R}(t,t^{\prime})
has the expression

\displaystyle\mathcal{D}C\mathcal{D}\hat{C}=\lim_{(\delta t)\to 0}\left(\prod_{n=0}^{\infty}\prod_{n^{\prime}=0}^{\infty}\frac{dC_{n,n^{\prime}}d\hat{C}_{n,n^{\prime}}}{4\pi iN^{-1}(\delta t)^{-2}}\right)

(187)

\displaystyle\mathcal{D}R\mathcal{D}\hat{R}=\lim_{(\delta t)\to 0}\left(\prod_{n=0}^{\infty}\prod_{n^{\prime}=0}^{\infty}\frac{dR_{n,n^{\prime}}d\hat{R}_{n,n^{\prime}}}{4\pi iN^{-1}(\delta t)^{-2}}\right)

(188)

Using this notation, we can now notice that all expressions involving
\bm{h}(t)
or
\hat{\bm{h}}(t)
decouple as a sum over each of the
N
sites. This allows us to

\displaystyle Z

\displaystyle=\int\mathcal{D}C\mathcal{D}\hat{C}\mathcal{D}R\mathcal{D}\hat{R}\exp\left(-N\mathcal{S}[C,\hat{C},R,\hat{R}]\right)

(189)

\displaystyle\mathcal{S}

\displaystyle=-\frac{1}{2}\int dtdt^{\prime}\left[\hat{C}(t,t^{\prime})C(t,t^{\prime})-\hat{R}(t,t^{\prime})R(t^{\prime},t)\right]-\ln\mathcal{Z}

(190)

where
\mathcal{Z}
is a single-site moment generating function

\displaystyle\mathcal{Z}=\int\mathcal{D}h\mathcal{D}\hat{h}

\displaystyle\exp\left(-\frac{1}{2}\int dtdt^{\prime}\left[\hat{C}(t,t^{\prime})h(t)h(t^{\prime})+C(t,t^{\prime})\hat{h}(t)\hat{h}(t^{\prime})\right]\right)

\displaystyle\exp\left(i\int dt\ \hat{h}(t)\left[\partial_{t}h(t)-\frac{1}{2}\left(\hat{R}(t,t^{\prime})+R(t,t^{\prime})\right)h(t^{\prime})\right]\right)

(191)

The
N\to\infty
limit is governed by the saddle point equations

\displaystyle\frac{\partial\mathcal{S}}{\partial C(t,t^{\prime})}

\displaystyle=-\frac{1}{2}\hat{C}(t,t^{\prime})+\frac{1}{2}\left<\hat{h}(t)\hat{h}(t^{\prime})\right>=0

(192)

\displaystyle\frac{\partial\mathcal{S}}{\partial\hat{C}(t,t^{\prime})}

\displaystyle=-\frac{1}{2}\hat{C}(t,t^{\prime})+\frac{1}{2}\left<\hat{h}(t)\hat{h}(t^{\prime})\right>=0

(193)

\displaystyle\frac{\partial\mathcal{S}}{\partial R(t^{\prime},t)}

\displaystyle=\frac{1}{2}\hat{R}(t,t^{\prime})+\frac{i}{2}\left<h(t)\hat{h}(t^{\prime})\right>=0

(194)

\displaystyle\frac{\partial\mathcal{S}}{\partial\hat{R}(t^{\prime},t)}

\displaystyle=\frac{1}{2}R(t,t^{\prime})+\frac{i}{2}\left<h(t)\hat{h}(t^{\prime})\right>=0

(195)

where by
\left<\right>
we mean an average over the single-site distribution. Let
G\left[h,\hat{h}\right]
be an arbitrary functional of
h(t)
and
\hat{h}(t)
, then the single site average
\left<G\left[h,\hat{h}\right]\right>
is

\displaystyle\left<G\left[h,\hat{h}\right]\right>=\frac{1}{\mathcal{Z}}\int\mathcal{D}h\mathcal{D}\hat{h}

\displaystyle\exp\left(-\frac{1}{2}\int dtdt^{\prime}\left[\hat{C}(t,t^{\prime})h(t)h(t^{\prime})+C(t,t^{\prime})\hat{h}(t)\hat{h}(t^{\prime})\right]\right)

\displaystyle\exp\left(i\int dt\ \hat{h}(t)\left[\partial_{t}h(t)-\frac{1}{2}\left(\hat{R}(t,t^{\prime})+R(t,t^{\prime})\right)h(t^{\prime})\right]\right)\times G\left[h,\hat{h}\right]

(196)

These expressions imply that
\{C,\hat{C},R,\hat{R}\}
all take on deterministic values in the
N\to\infty
limit. Further, we learned that
R(t,t^{\prime})=\hat{R}(t,t^{\prime})
at the saddle point. To simplify the expressions, we will linearize the quadratic term in
\hat{h}(t)
at the expense of introducing a new Gaussian field
u(t)

\displaystyle\exp\left(-\frac{1}{2}\int dtdt^{\prime}C(t,t^{\prime})\hat{h}(t)\hat{h}(t^{\prime})\right)=\left<\exp\left(-i\int dt\ u(t)\ \hat{h}(t)\right)\right>_{u\sim\mathcal{GP}(0,C)}

(197)

After introducing this new variable, we note that the response functions can be expressed as derivatives with respect to
u(t)

\displaystyle R(t,t^{\prime})

\displaystyle=\left<h(t)i\hat{h}(t)\right>

\displaystyle=-\frac{1}{\mathcal{Z}}\int\mathcal{D}h\mathcal{D}\hat{h}\ h(t)\left<\frac{\partial}{\partial u(t^{\prime})}\exp\left(i\int dt\hat{h}(t)\left[\partial_{t}h(t)-u(t)-\int dt^{\prime}R(t,t^{\prime})h(t^{\prime})\right]\right)\right>

\displaystyle=\frac{1}{\mathcal{Z}}\int\mathcal{D}h\frac{\partial}{\partial u(t^{\prime})}h(\{u(\cdot)\},t)

(198)

where we integrated by parts after utilizing the fact that the integral over
\hat{h}(t)
collapses to a Dirac mass after introduction of the
u(t)
variable

\displaystyle\int\mathcal{D}\hat{h}(t)\exp\left(i\int dt\hat{h}(t)\left[\partial_{t}h(t)-u(t)-\int dt^{\prime}R(t,t^{\prime})h(t^{\prime})\right]\right)

\displaystyle\propto\prod_{t}\delta\left(\partial_{t}h(t)-u(t)-\int dt^{\prime}R(t,t^{\prime})h(t^{\prime})\right).

(199)

In the above expression, we let
h(\{u(\cdot)\},t)
represent
h
at time
t
as a functional of
u(t)
that is the solution to the ODE

\displaystyle\partial_{t}h(t)=u(t)+\int dt^{\prime}R(t,t^{\prime})h(t^{\prime})\ ,\ u(t)\sim\mathcal{GP}(0,C(t,t^{\prime}))

(200)

This expression coupled with the formulas
C(t,t^{\prime})=\left<h(t)h(t^{\prime})\right>
and
R(t,t^{\prime})=\left<\frac{\partial h(t)}{\partial u(t^{\prime})}\right>
recover our DMFT equations from the main text.

Appendix C
Linear Regression Path Integral Derivation

In the linear regression example, we introduced two variables
\{\bm{h}(t),\bm{\Delta}(t)\}
which satisfy

\displaystyle\bm{\Delta}(t)=\frac{1}{\sqrt{N}}\bm{\Psi}\bm{h}_{0}(t)\ ,\ \partial_{t}\bm{h}(t)=-\frac{1}{\alpha\sqrt{N}}\bm{\Psi}^{\top}\bm{\Delta}(t)

(201)

We introduce both of these variables into the path integral using conjugate variables
\hat{\bm{\Delta}}(t)
and
\hat{\bm{h}}_{1}(t)
. The resulting average over a random Gaussian
\bm{\Psi}
matrix gives

\displaystyle\ln\left<\exp\left(-\frac{i}{\sqrt{N}}\text{Tr}\bm{\Psi}\int dt\left[\bm{h}_{0}(t)\hat{\bm{\Delta}}(t)^{\top}-\frac{1}{\alpha}\hat{\bm{h}}(t)\bm{\Delta}(t)^{\top}\right]\right)\right>

\displaystyle=-\frac{1}{2}\int dtdt^{\prime}\left[\hat{\bm{\Delta}}(t)\cdot\hat{\bm{\Delta}}(t)\underbrace{\left(\frac{1}{N}\bm{h}(t)\cdot\bm{h}(t^{\prime})\right)}_{C(t,t^{\prime})}+\frac{1}{\alpha}\hat{\bm{h}}(t)\cdot\hat{\bm{h}}(t^{\prime})\underbrace{\left(\frac{1}{P}\bm{\Delta}(t)\cdot\bm{\Delta}(t^{\prime})\right)}_{C_{\Delta}(t,t^{\prime})}\right]

\displaystyle+\frac{1}{P}\int dtdt^{\prime}\ \underbrace{(\hat{\bm{h}}(t)\cdot\bm{h}(t^{\prime}))}_{iNR_{h}(t^{\prime},t)}\underbrace{(\bm{\Delta}(t)\cdot\hat{\bm{\Delta}}(t^{\prime}))}_{iPR_{\Delta}(t,t^{\prime})}

(202)

Introducing the correlation and response functions, we find

\displaystyle Z=\int\mathcal{D}C_{h}\mathcal{D}\hat{C}_{h}\mathcal{D}C_{\Delta}\mathcal{D}\hat{C}_{\Delta}\mathcal{D}R_{h}\mathcal{D}R_{\Delta}\exp\left(-N\mathcal{S}[C_{h},\hat{C}_{h},C_{\Delta},\hat{C}_{\Delta},R_{h},R_{\Delta}]\right)

(203)

where the action
\mathcal{S}
has the form (recall that
\alpha=P/N
)

\displaystyle\mathcal{S}=

\displaystyle-\frac{1}{2}\int dtdt^{\prime}\left[\hat{C}_{h}(t,t^{\prime})C_{h}(t,t^{\prime})+\alpha\hat{C}_{\Delta}(t,t^{\prime})C_{\Delta}(t,t^{\prime})\right]

(204)

\displaystyle-\int dtdt^{\prime}R_{\Delta}(t^{\prime},t)R_{h}(t,t^{\prime})-\ln\mathcal{Z}_{h}-\alpha\ln\mathcal{Z}_{\Delta}

(205)

where the single site stochastic moment generating functions

\displaystyle\mathcal{Z}_{h}=\int\mathcal{D}h\mathcal{D}\hat{h}\

\displaystyle\exp\left(i\int dt\hat{h}(t)\left[\partial_{t}h(t)+\int dt^{\prime}R_{\Delta}(t,t^{\prime})h(t^{\prime})\right]\right)

\displaystyle\exp\left(-\frac{1}{2}\int dtdt^{\prime}\left[\frac{1}{\alpha}C_{\Delta}(t,t^{\prime})\hat{h}(t)\hat{h}(t^{\prime})+\hat{C}_{h}(t,t^{\prime})h(t)h(t^{\prime})\right]\right)

(206)

\displaystyle\mathcal{Z}_{\Delta}=\int\mathcal{D}\Delta\mathcal{D}\hat{\Delta}\

\displaystyle\exp\left(i\int dt\hat{\Delta}(t)\left[\Delta(t)+\frac{1}{\alpha}\int dt^{\prime}R_{h}(t,t^{\prime})h(t^{\prime})\right]\right)

\displaystyle\exp\left(-\frac{1}{2}\int dtdt^{\prime}\left[C_{h}(t,t^{\prime})\hat{\Delta}(t)\hat{\Delta}(t^{\prime})+\hat{C}_{\Delta}(t,t^{\prime})\Delta(t)\Delta(t^{\prime})\right]\right)

(207)

The relevant saddle point equations give the defining equations for the correlation and response

\displaystyle\frac{\partial\mathcal{S}}{\partial\hat{C}_{h}(t,t^{\prime})}=-\frac{1}{2}C_{h}(t,t^{\prime})+\frac{1}{2}\left<h(t)h(t^{\prime})\right>=0

\displaystyle\frac{\partial\mathcal{S}}{\partial\hat{C}_{\Delta}(t,t^{\prime})}=-\frac{1}{2}C_{\Delta}(t,t^{\prime})+\frac{1}{2}\left<\Delta(t)\Delta(t^{\prime})\right>=0

\displaystyle\frac{\partial\mathcal{S}}{\partial R_{\Delta}(t^{\prime},t)}=-R_{h}(t,t^{\prime})-i\left<h(t)\hat{h}(t^{\prime})\right>=0

\displaystyle\frac{\partial\mathcal{S}}{\partial R_{h}(t^{\prime},t)}=-R_{\Delta}(t,t^{\prime})-i\left<\Delta(t)\hat{\Delta}(t^{\prime})\right>=0

(208)

Following the same manipulations of the last sections, we now introduce Gaussian variables
u_{h}(t),u_{\Delta}(t)
to linearize the terms involving
\hat{h}(t),\hat{\Delta}(t)
which enables us to characterize the single site stochastic processes for
h(t)
and
\Delta(t)

\displaystyle\frac{\partial}{\partial t}h(t)=u_{h}(t)-\int dt^{\prime}R_{\Delta}(t,t^{\prime})h(t^{\prime})\ ,\ u_{h}(t)\sim\mathcal{GP}\left(0,\frac{1}{\alpha}C_{\Delta}\right)

\displaystyle\Delta(t)=u_{\Delta}(t)-\frac{1}{\alpha}\int dt^{\prime}R_{h}(t,t^{\prime})\Delta(t^{\prime})\ ,\ u_{\Delta}(t)\sim\mathcal{GP}(0,C_{h}).

(209)

The correlation and response functions can then be obtained from the above equations.

Appendix D
Structured Random Features

In the structured random feature model, we decompose the dynamics into a collection of variables
\{\bm{h}_{0},\bm{h}_{1},\bm{h}_{2},\bm{h}_{3},\bm{h}_{4}\}
defined as

\displaystyle\bm{h}_{1}(t)=\bm{\Psi}\bm{h}_{0}(t)\ ,\ \bm{h}_{2}(t)=\frac{1}{P}\bm{\Psi}^{\top}\bm{h}_{1}(t)

\displaystyle\bm{h}_{3}(t)=\bm{A}\bm{h}_{2}(t)\ ,\ \bm{h}_{4}(t)=\frac{1}{N}\bm{A}^{\top}\bm{h}_{3}(t)

\displaystyle\frac{\partial}{\partial t}\bm{h}_{0}(t)=-\bm{h}_{4}(t)

(210)

where the matrices
\bm{A}
and
\bm{\Psi}
are zero mean with covariance structure

\displaystyle\left<A_{ij}A_{k\ell}\right>=\delta_{ik}\delta_{j\ell}\ ,\ \left<\Psi_{\mu k}\Psi_{\nu\ell}\right>=\delta_{\mu\nu}\lambda_{k}\delta_{k\ell}

(211)

The averages over the

\displaystyle\ln

\displaystyle\left<\exp\left(-i\ \text{Tr}\bm{\Psi}\int dt\left[\bm{h}_{0}(t)\hat{\bm{h}}_{1}(t)^{\top}+\frac{1}{P}\hat{\bm{h}}_{2}(t)\bm{h}_{1}(t)^{\top}\right]\right)\right>

\displaystyle=

\displaystyle-\frac{1}{2}\int dtdt^{\prime}\left[\hat{\bm{h}}_{1}(t)\cdot\hat{\bm{h}}_{1}(t^{\prime})\underbrace{\bm{h}_{0}(t)^{\top}\bm{\Lambda}\bm{h}_{0}(t^{\prime})}_{C_{0}(t,t^{\prime})}+\frac{1}{P}\hat{\bm{h}}_{2}(t)^{\top}\bm{\Lambda}\hat{\bm{h}}_{2}(t^{\prime})\underbrace{\left(\frac{1}{P}\bm{h}_{1}(t)\cdot\bm{h}_{1}(t^{\prime})\right)}_{C_{1}(t,t^{\prime})}\right]

\displaystyle-\int dtdt^{\prime}\ \underbrace{\bm{h}_{0}(t)\bm{\Lambda}\hat{\bm{h}}_{2}(t^{\prime})}_{iR_{0,2}(t,t^{\prime})}\ \ \underbrace{\left(\frac{1}{P}\bm{h}_{1}(t^{\prime})\cdot\hat{\bm{h}}_{1}(t)\right)}_{iR_{1}(t,t^{\prime})}

(212)

We thus need to introduce the correlation functions and response function order parameters highlighted above. Next, we perform the average over
\bm{A}

\displaystyle\ln

\displaystyle\left<\exp\left(-i\text{Tr}\bm{A}\int dt\left[\bm{h}_{2}(t)\hat{\bm{h}}_{3}(t)^{\top}+\frac{1}{N}\hat{\bm{h}}_{4}(t)\bm{h}_{3}(t)^{\top}\right]\right)\right>

\displaystyle=-\frac{1}{2}\int dtdt^{\prime}\left[\hat{\bm{h}}_{3}(t)\cdot\hat{\bm{h}}_{3}(t^{\prime})\underbrace{\left(\bm{h}_{2}(t)\cdot\bm{h}_{2}(t^{\prime})\right)}_{C_{2}(t,t^{\prime})}+\frac{1}{N}\hat{\bm{h}}_{4}(t)\cdot\hat{\bm{h}}_{4}(t^{\prime})\underbrace{\left(\frac{1}{N}\bm{h}_{3}(t)\cdot\bm{h}_{3}(t^{\prime})\right)}_{C_{3}(t,t^{\prime})}\right]

\displaystyle-\int dtdt^{\prime}\underbrace{\bm{h}_{2}(t)\cdot\hat{\bm{h}}_{4}(t^{\prime})}_{iR_{2,4}(t,t^{\prime})}\underbrace{\left(\frac{1}{N}\bm{h}_{3}(t^{\prime})\cdot\hat{\bm{h}}_{3}(t)\right)}_{iR_{3}(t^{\prime},t)}

(213)

The path integral now has the following form after introducing these order parameters

\displaystyle Z=\int\left(\prod_{\ell=0}^{3}\mathcal{D}C_{\ell}\mathcal{D}\hat{C}_{\ell}\right)\prod_{(j,\ell)\in\Pi}\mathcal{D}R_{j,\ell}\ \exp\left(-\mathcal{S}[\{C_{\ell}\}_{\ell\in[3]},\{R_{j,\ell}\}_{(j,\ell)\in\Pi}]\right)

(214)

where
\Pi=\{(0,2),(2,4),(1,1),(3,3)\}
are the pairings of variables involved in response functions and the action
\mathcal{S}
is defined as

\displaystyle\mathcal{S}

\displaystyle=-\frac{1}{2}\int dtdt^{\prime}\left[C_{0}(t,t^{\prime})\hat{C}_{0}(t,t^{\prime})+PC_{1}(t,t^{\prime})\hat{C}_{1}(t,t^{\prime})+C_{2}(t,t^{\prime})\hat{C}_{2}(t,t^{\prime})+NC_{3}(t,t^{\prime})\hat{C}_{3}(t,t^{\prime})\right]

\displaystyle+\int dtdt^{\prime}\left[R_{1}(t,t^{\prime})R_{0,2}(t^{\prime},t)+R_{3}(t,t^{\prime})R_{2,4}(t^{\prime},t)\right]-P\ln\mathcal{Z}_{1}-N\ln\mathcal{Z}_{3}-\sum_{k}\mathcal{\ln}\mathcal{Z}_{(0,2,4),k}

(215)

where the single site processes have the form

\displaystyle\mathcal{Z}_{1}=\int\mathcal{D}h_{1}\mathcal{D}\hat{h}_{1}

\displaystyle\exp\left(-\frac{1}{2}\int dtdt^{\prime}\left[\hat{h}_{1}(t)\hat{h}_{1}(t^{\prime})C_{0}(t,t^{\prime})+h_{1}(t)h_{1}(t^{\prime})\hat{C}_{1}(t,t^{\prime})\right]\right)

\displaystyle\exp\left(i\int dt\hat{h}_{1}(t)\left[h_{1}(t)+\frac{1}{P}\int dt^{\prime}R_{0,2}(t,t^{\prime})h_{1}(t^{\prime})\right]\right)

\displaystyle\mathcal{Z}_{3}=\int\mathcal{D}h_{3}\mathcal{D}\hat{h}_{3}

\displaystyle\exp\left(-\frac{1}{2}\int dtdt^{\prime}\left[\hat{h}_{3}(t)\hat{h}_{3}(t^{\prime})C_{2}(t,t^{\prime})+h_{3}(t)h_{3}(t^{\prime})\hat{C}_{3}(t,t^{\prime})\right]\right)

\displaystyle\exp\left(i\int dt\hat{h}_{3}(t)\left[h_{3}(t)+\frac{1}{N}\int dt^{\prime}R_{2,4}(t,t^{\prime})h_{3}(t^{\prime})\right]\right)

\displaystyle\mathcal{Z}_{(0,2,4),k}=\int\prod_{j\in\{0,2,4\}}\mathcal{D}h_{\ell}\mathcal{D}\hat{h}_{\ell}\

\displaystyle\exp\left(-\frac{1}{2}\int dtdt^{\prime}\left[\frac{\lambda_{k}}{P}C_{1}(t,t^{\prime})\hat{h}_{2}(t)\hat{h}_{2}(t^{\prime})+\frac{1}{N}C_{3}(t,t^{\prime})\hat{h}_{4}(t)\hat{h}_{4}(t^{\prime})\right]\right)

\displaystyle\exp\left(-\frac{1}{2}\int dtdt^{\prime}\left[\lambda_{k}\hat{C}_{0}(t,t^{\prime})h_{0}(t)h_{0}(t^{\prime})+\hat{C}_{2}(t,t^{\prime})h_{2}(t)h_{2}(t^{\prime})\right]\right)

\displaystyle\exp\left(i\int dt\hat{h}_{2}(t)\left[h_{2}(t)+\int dt^{\prime}R_{1}(t,t^{\prime})h_{0}(t^{\prime})\right]\right)

\displaystyle\exp\left(i\int dt\hat{h}_{4}(t)\left[h_{4}(t)+\int dt^{\prime}R_{3}(t,t^{\prime})h_{0}(t^{\prime})\right]\right)

\displaystyle\exp\left(i\int dt\hat{h}_{0}(t)\left[\partial_{t}h_{0}(t)+h_{4}(t)\right]\right)

(216)

At finite
N,P
the above path integral is not perfectly dominated by the saddle point. However, the mean field approximation to the test loss is obtained by taking a saddle point over these variables. This incurs an approximation error, but that approximation error decays gracefully as
N,P
increase
[
11
]
. The saddle point equations recover the DMFT equations provided in the main text.

Appendix E
Free Product Dynamics

In this section, we work out the mean field action for the free product dynamics for both the asymmetric and symmetrized cases.

E.1
Asymmetric

The path integral for the asymmetric free product ensemble has the frequency space expression

\displaystyle Z=\int\mathcal{D}\bm{\chi}\mathcal{D}\bm{h}\ \left<\exp\left(-\int d\omega\ \bm{\chi}(\omega)\cdot\left[i\omega\bm{h}(\omega)+\bm{O}\bm{B}\bm{O}^{\top}\bm{A}\bm{h}(\omega)-\bm{h}_{0}\right]\right)\right>

(217)

where
\bm{h}_{0}
is the initial condition at
t=0
. To compute the average over
\bm{O}
, we introduce two vectors

\displaystyle\bm{v}(\omega)=\bm{O}^{\top}\bm{A}\bm{h}(\omega)\ ,\ \bm{u}(\omega)=\bm{O}^{\top}\bm{\chi}(\omega)

(218)

As
N\to\infty
, the measure of finitely many vectors
\bm{v}(\omega)
and
\bm{u}(\omega)
is uniform up to constraints on the inner products, which is the main insight of low-rank HCIZ integrals
[
46
]
. The inner product constraints on
\bm{v}(\omega)
and
\bm{u}(\omega)
are

\displaystyle\frac{1}{N}\bm{v}(\omega)^{\top}\bm{v}(\omega^{\prime})=\frac{1}{N}\bm{h}(\omega)^{\top}\bm{A}^{2}\bm{h}(\omega^{\prime})\equiv\Sigma_{hh}(\omega,\omega^{\prime})

\displaystyle\frac{1}{N}\bm{v}(\omega)^{\top}\bm{u}(\omega^{\prime})=\frac{1}{N}\bm{h}(\omega)^{\top}\bm{A}\bm{\chi}(\omega^{\prime})\equiv\Sigma_{h\chi}(\omega,\omega^{\prime})

\displaystyle\frac{1}{N}\bm{u}(\omega)^{\top}\bm{u}(\omega^{\prime})=\frac{1}{N}\bm{\chi}(\omega)\cdot\bm{\chi}(\omega^{\prime})\equiv\Sigma_{\chi\chi}(\omega,\omega^{\prime})

(219)

We introduce a two-by-two matrix
\bm{\Sigma}(\omega,\omega^{\prime})
which has the structure

\displaystyle\bm{\Sigma}(\omega,\omega^{\prime})=\begin{bmatrix}\Sigma_{hh}(\omega,\omega^{\prime})&\Sigma_{h\chi}(\omega,\omega^{\prime})\\
\Sigma_{\chi h}(\omega,\omega^{\prime})&\Sigma_{\chi\chi}(\omega,\omega^{\prime})\end{bmatrix}

(220)

For a given
\bm{\Sigma}
, we let
\mu(\bm{v},\bm{u},\bm{\Sigma})
represent the normalized probability distribution for
\bm{u},\bm{v}
induced by the random
\bm{O}
. We desire to compute the following integral

\displaystyle\int\mathcal{D}\bm{v}\mathcal{D}\bm{u}\ \mu(\bm{v},\bm{u},\bm{\Sigma})\exp\left(-\int d\omega\ \bm{u}(\omega)^{\top}\bm{B}\bm{v}(\omega)\right)

(221)

As
N\to\infty
the formula for
\mu
is

\displaystyle\mu(\bm{v},\bm{u},\bm{\Sigma})\propto\prod_{\omega,\omega^{\prime}}

\displaystyle\delta\left(\bm{v}(\omega)\cdot\bm{v}(\omega^{\prime})-N\Sigma_{hh}(\omega,\omega^{\prime})\right)\delta\left(\bm{v}(\omega)\cdot\bm{u}(\omega^{\prime})-N\Sigma_{h\chi}(\omega,\omega^{\prime})\right)

\displaystyle\times\delta\left(\bm{u}(\omega)\cdot\bm{v}(\omega^{\prime})-N\Sigma_{\chi h}(\omega,\omega^{\prime})\right)\delta\left(\bm{u}(\omega)\cdot\bm{u}(\omega^{\prime})-N\Sigma_{\chi\chi}(\omega,\omega^{\prime})\right)

(222)

where the
\propto
represents the distribution up to normalization. To enforce the inner product constraints between
\bm{v}
and
\bm{u}
, we introduce Lagrange multipliers
\hat{\bm{\Sigma}}
(Fourier variables for a Dirac delta function integral representation), giving the following integral

\displaystyle\frac{\int\mathcal{D}\bm{v}\mathcal{D}\bm{u}\ \mathcal{D}\hat{\bm{\Sigma}}\exp\left(\frac{1}{2}\int d\omega d\omega^{\prime}\text{Tr}\hat{\bm{\Sigma}}(\omega,\omega^{\prime})^{\top}\left(N\bm{\Sigma}(\omega,\omega^{\prime})-\begin{bmatrix}\bm{v}(\omega)\cdot\bm{v}(\omega^{\prime})&\bm{v}(\omega)\cdot\bm{u}(\omega^{\prime})\\
\bm{v}(\omega^{\prime})\cdot\bm{u}(\omega)&\bm{u}(\omega)\cdot\bm{u}(\omega^{\prime})\end{bmatrix}\right)-\int d\omega\ \bm{u}(\omega)^{\top}\bm{B}\bm{v}(\omega)\right)}{\int\mathcal{D}\bm{v}\mathcal{D}\bm{u}\ \mathcal{D}\hat{\bm{\Sigma}}\exp\left(\frac{1}{2}\int d\omega d\omega^{\prime}\text{Tr}\hat{\bm{\Sigma}}(\omega,\omega^{\prime})^{\top}\left(N\bm{\Sigma}(\omega,\omega^{\prime})-\begin{bmatrix}\bm{v}(\omega)\cdot\bm{v}(\omega^{\prime})&\bm{v}(\omega)\cdot\bm{u}(\omega^{\prime})\\
\bm{v}(\omega^{\prime})\cdot\bm{u}(\omega)&\bm{u}(\omega)\cdot\bm{u}(\omega^{\prime})\end{bmatrix}\right)\right)}

(223)

We introduce a matrix notation for the integrals over
(\omega,\omega^{\prime})
and also introduce a tensor product representation of the above Gaussian integral. We use the notation
Tr
to represent a super-trace over both frequency and matrix dimensions. The integral in the numerator thus becomes

\displaystyle\int\mathcal{D}\hat{\bm{\Sigma}}\exp\left(\frac{N}{2}\textbf{Tr}\hat{\bm{\Sigma}}\bm{\Sigma}-\frac{1}{2}\textbf{Tr}\log\left(\hat{\bm{\Sigma}}\otimes\bm{I}+\bm{I}\otimes\bm{B}\right)\right)=\int\mathcal{D}\hat{\bm{\Sigma}}\exp\left(-\frac{N}{2}\mathcal{S}_{B}(\hat{\bm{\Sigma}})\right)

(224)

As
N\to\infty
, we are justified utilizing a saddle point to compute the numerator integral.

\displaystyle\frac{\partial\mathcal{S}_{B}}{\partial\hat{\bm{\Sigma}}}=-\bm{\Sigma}+\frac{1}{N}\textbf{Tr}\left(\hat{\bm{\Sigma}}\otimes\bm{I}+\bm{I}\otimes\bm{B}\right)^{-1}=0

(225)

This equation defines
\hat{\bm{\Sigma}}_{\star}
which is a function of
\bm{\Sigma}
. The numerator integral is thus

\displaystyle\int\mathcal{D}\hat{\bm{\Sigma}}\exp\left(\frac{N}{2}\textbf{Tr}\hat{\bm{\Sigma}}\bm{\Sigma}-\frac{1}{2}\textbf{Tr}\log\left(\hat{\bm{\Sigma}}\otimes\bm{I}+\bm{I}\otimes\bm{B}\right)\right)

\displaystyle\sim\exp\left(\frac{N}{2}\textbf{Tr}\hat{\bm{\Sigma}}_{\star}\bm{\Sigma}-\frac{1}{2}\textbf{Tr}\log\left(\hat{\bm{\Sigma}}_{\star}\otimes\bm{I}+\bm{I}\otimes\bm{B}\right)\right)

(226)

Performing the same analysis for the integral arising in the denominator. For the denominator integral, the dominant contribution comes from
\hat{\bm{\Sigma}}=\bm{\Sigma}^{-1}
. Therefore our original average over the
\bm{v}
and
\bm{u}
fields reduces to (up to irrelevant constants)

\displaystyle\int\mathcal{D}\bm{v}\mathcal{D}\bm{u}\ \mu(\bm{v},\bm{u},\bm{\Sigma})\exp\left(-\int d\omega\ \bm{u}(\omega)^{\top}\bm{B}\bm{v}(\omega)\right)

(227)

\displaystyle\sim\exp\left(\frac{N}{2}\textbf{Tr}\hat{\bm{\Sigma}}_{\star}\bm{\Sigma}-\frac{1}{2}\textbf{Tr}\log\left(\hat{\bm{\Sigma}}_{\star}\otimes\bm{I}+\bm{I}\otimes\bm{B}\right)-\frac{N}{2}\textbf{Tr}\log\bm{\Sigma}\right)

(228)

Next, we must introduce a Lagrange multiplier variable to enforce the relationship between
\{\bm{h},\bm{\chi}\}
and
\bm{\Sigma}
. We let this set of Lagrange multipliers be
\bm{\Psi}
.

\displaystyle Z=\int\mathcal{D}\bm{\Psi}\mathcal{D}\bm{\Sigma}\exp\left(-\frac{N}{2}\mathcal{S}[\bm{\Sigma},\bm{\Psi}]\right)

(229)

\displaystyle\mathcal{S}[\bm{\Sigma},\bm{\Psi}]=-\textbf{Tr}\bm{\Psi}\bm{\Sigma}-\frac{2}{N}\ln\mathcal{Z}_{A}(\bm{\Psi})-\textbf{Tr}\hat{\bm{\Sigma}}_{\star}\bm{\Sigma}+\frac{1}{N}\textbf{Tr}\log\left(\hat{\bm{\Sigma}}_{\star}\otimes\bm{I}+\bm{I}\otimes\bm{B}\right)+\textbf{Tr}\log\bm{\Sigma}

(230)

where in the above expression
\hat{\bm{\Sigma}}_{\star}
is implicitly a function of
\bm{\Sigma}
and the function
\mathcal{Z}_{A}
is defined as

\displaystyle\mathcal{Z}_{A}=\int\mathcal{D}\bm{h}\mathcal{D}\bm{\chi}

\displaystyle\exp\left(-\int d\omega\bm{\chi}(\omega)\left[i\omega\bm{h}(\omega)+\bm{h}_{0}\right]\right)

(231)

\displaystyle\exp\left(-\frac{1}{2}\int d\omega d\omega^{\prime}\text{Tr }\bm{\Psi}(\omega,\omega^{\prime})\begin{bmatrix}\bm{h}(\omega)^{\top}\bm{A}^{2}\bm{h}(\omega^{\prime})&\bm{h}(\omega)^{\top}\bm{A}\bm{\chi}(\omega^{\prime})\\
\bm{\chi}(\omega)^{\top}\bm{A}\bm{h}(\omega^{\prime})&\bm{\chi}(\omega)^{\top}\bm{\chi}(\omega^{\prime})\end{bmatrix}\right)

The saddle point equations over
\bm{\Psi}
and
\bm{\Sigma}
are

\displaystyle\frac{\partial\mathcal{S}}{\partial\bm{\Sigma}}=-\bm{\Psi}-\hat{\bm{\Sigma}}_{\star}+\bm{\Sigma}^{-1}=\bm{0}

(232)

\displaystyle\frac{\partial\mathcal{S}}{\partial\bm{\Psi}}=-\bm{\Sigma}+\begin{bmatrix}\frac{1}{N}\left<\bm{h}(\omega)^{\top}\bm{A}^{2}\bm{h}(\omega^{\prime})\right>&\frac{1}{N}\left<\bm{h}(\omega)^{\top}\bm{A}\bm{\chi}(\omega^{\prime})\right>\\
\frac{1}{N}\left<\bm{h}(\omega^{\prime})^{\top}\bm{A}\bm{\chi}(\omega)\right>&\frac{1}{N}\left<\bm{\chi}(\omega)\cdot\bm{\chi}(\omega^{\prime})\right>\end{bmatrix}=\bm{0}

(233)

where the average
\left<\cdot\right>
is over the distribution induced by
\mathcal{Z}_{A}
. We thus need to compute the mean and variance of
\bm{h}
and
\bm{\chi}
. We note that
\bm{h}(\omega)
will have nonzero mean and variance due to the term involving
\bm{\chi}(\omega)(i\omega\bm{h}-\bm{h}_{0})
, even if
\bm{\Psi}
is zero. However, we note that there is a physically meaningful solution where
\bm{\chi}
has vanishing self-correlation, giving a
\bm{\Sigma}(\omega,\omega^{\prime})
matrix with vanishing lower block

\displaystyle\bm{\Sigma}(\omega,\omega^{\prime})=\begin{bmatrix}\Sigma_{hh}(\omega,\omega^{\prime})&\Sigma_{h\chi}(\omega,\omega^{\prime})\\
\Sigma_{\chi h}(\omega,\omega^{\prime})&0\end{bmatrix}.

(234)

Off diagonal blocks

As a consequence the matrices
\hat{\bm{\Sigma}}_{\star}(\omega,\omega^{\prime})
and
\bm{\Psi}(\omega,\omega^{\prime})
have vanishing lower block. Further, we note that the off-diagonal blocks decouple over frequencies
\Sigma_{h\chi}(\omega,\omega^{\prime})=\delta(\omega-\omega^{\prime})\Sigma_{h\chi}(\omega)

\displaystyle\Sigma_{h\chi}(\omega)=\text{tr}\bm{A}\left(i\omega+\Psi_{h\chi}(\omega)\bm{A}\right)^{-1}

\displaystyle\Psi_{h\chi}(\omega)=\Sigma_{h\chi}(\omega)^{-1}-\hat{\Sigma}_{h\chi}(\omega)

\displaystyle\Sigma_{h\chi}(\omega)=\text{tr}\left(\hat{\Sigma}_{h\chi}(\omega)+\bm{B}\right)^{-1}

(235)

We define
\mathcal{T}_{A}=\text{tr}\bm{A}\left(i\omega+\bm{A}\right)^{-1}
. Thus, the first equation gives

\displaystyle\Sigma_{h\chi}(\omega)\Psi_{h\chi}(\omega)=\mathcal{T}_{A}(i\omega_{A})\ ,\ i\omega_{A}=i\omega/\Psi_{h\chi}(\omega).

(236)

The second and third equations imply

\displaystyle\mathcal{T}_{A}(i\omega_{A})

\displaystyle=\Sigma_{h\chi}(\omega)\Psi_{h\chi}(\omega)=1-\Sigma_{h\chi}(\omega)\hat{\Sigma}_{h\chi}(\omega)

\displaystyle=\text{tr}\bm{B}\left(\hat{\Sigma}_{h\chi}(\omega)+\bm{B}\right)^{-1}=\mathcal{T}_{B}(i\omega_{B})\ ,\ i\omega_{B}=\hat{\Sigma}_{h\chi}(\omega)

(237)

Lastly, we note that the
\mathcal{T}
transform is also identical

\displaystyle\mathcal{T}_{M}(i\omega)=\text{tr}\bm{A}\left(i\omega+\Psi_{h\chi}(\omega)\bm{A}\right)^{-1}=\mathcal{T}_{A}(i\omega_{A})=\mathcal{T}_{B}(i\omega_{B})

(238)

Since each of these
\mathcal{T}
variables are identical when evaluated at their respective frequencies, we can simply use
\mathcal{T}
without a subscript. Lastly, we can deduce a relationship between the three frequencies
\{i\omega_{A},i\omega_{B},i\omega\}

\displaystyle i\omega=i\omega_{A}\Psi_{h\chi}(\omega)=i\omega_{A}\left[\Sigma_{h\chi}(\omega)^{-1}-i\omega_{B}\right]=i\omega_{A}i\omega_{B}\left[\frac{\mathcal{T}}{1-\mathcal{T}}\right]

(239)

Rearranging this equation gives the stated result in the main text

\displaystyle i\omega_{A}i\omega_{B}=\frac{1-\mathcal{T}}{\mathcal{T}}i\omega

(240)

Diagonal Blocks

The diagonal blocks satisfy the following equations

\displaystyle\Sigma_{hh}(\omega,\omega^{\prime})=\text{tr}\bm{A}^{2}\left(i\omega+\Psi_{h\chi}(\omega)\bm{A}\right)^{-1}\left[\bm{h}_{0}\bm{h}_{0}^{\top}-\Psi_{\chi\chi}(\omega,\omega^{\prime})\right]\left(i\omega^{\prime}+\Psi_{h\chi}(\omega^{\prime})\bm{A}\right)^{-1}

\displaystyle\Psi_{\chi\chi}(\omega,\omega^{\prime})=-\Sigma_{hh}(\omega,\omega^{\prime})\Sigma_{h\chi}(\omega)^{-1}\Sigma_{h\chi}(\omega^{\prime})^{-1}-\hat{\Sigma}_{\chi\chi}(\omega,\omega^{\prime})

\displaystyle\Sigma_{hh}(\omega,\omega^{\prime})=-\hat{\Sigma}_{\chi\chi}(\omega,\omega^{\prime})\ \text{tr}\left(\hat{\Sigma}_{h\chi}(\omega)+\bm{B}\right)^{-1}\left(\hat{\Sigma}_{h\chi}(\omega^{\prime})+\bm{B}\right)^{-1}.

(241)

When combined these equations yield our full equations for the two point functions.

E.2
Symmetrized Case

For the symmetrized case, we instead have the following dynamics

\displaystyle Z=\int\mathcal{D}\bm{\chi}\mathcal{D}\bm{h}\ \left<\exp\left(-\int d\omega\ \bm{\chi}(\omega)\cdot\left[i\omega\bm{h}(\omega)+\bm{A}^{1/2}\bm{O}\bm{B}\bm{O}^{\top}\bm{A}^{1/2}\bm{h}(\omega)-\bm{h}_{0}\right]\right)\right>

(242)

In this case, the relevant correlations are

\displaystyle\bm{\Sigma}(\omega,\omega^{\prime})=\begin{bmatrix}\frac{1}{N}\bm{h}(\omega)^{\top}\bm{A}\bm{h}(\omega^{\prime})&\frac{1}{N}\bm{h}(\omega)^{\top}\bm{A}\bm{\chi}(\omega^{\prime})\\
\frac{1}{N}\bm{\chi}(\omega)^{\top}\bm{A}\bm{h}(\omega^{\prime})&\frac{1}{N}\bm{\chi}(\omega)^{\top}\bm{A}\bm{\chi}(\omega^{\prime})\end{bmatrix}

(243)

The calculation proceeds as in the previous section. However, the difference comes in the computation of the diagonal blocks which now have the following structure

\displaystyle\Sigma_{hh}(\omega,\omega^{\prime})=\text{tr}\bm{A}\left(i\omega+\Psi_{h\chi}(\omega)\bm{A}\right)^{-1}\left[\bm{h}_{0}\bm{h}_{0}^{\top}-\bm{A}\Psi_{\chi\chi}(\omega,\omega^{\prime})\right]\left(i\omega^{\prime}+\Psi_{h\chi}(\omega^{\prime})\bm{A}\right)^{-1}

\displaystyle\Psi_{\chi\chi}(\omega,\omega^{\prime})=-\Sigma_{hh}(\omega,\omega^{\prime})\Sigma_{h\chi}(\omega)^{-1}\Sigma_{h\chi}(\omega^{\prime})^{-1}-\hat{\Sigma}_{\chi\chi}(\omega,\omega^{\prime})

\displaystyle\Sigma_{hh}(\omega,\omega^{\prime})=-\hat{\Sigma}_{\chi\chi}(\omega,\omega^{\prime})\ \text{tr}\left(\hat{\Sigma}_{h\chi}(\omega)+\bm{B}\right)^{-1}\left(\hat{\Sigma}_{h\chi}(\omega^{\prime})+\bm{B}\right)^{-1}.

(244)

This subtle change in the two point functions can generate vastly different dynamics as we demonstrate in Figure
11
.
