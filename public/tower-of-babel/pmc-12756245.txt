Image super-resolution method using a generative adversarial network incorporating attention and residual density
Authors: Qiong Zhang, Yiliu Hang, Hui Zhang, Xi Lu, Jianlin Qiu
Published: 2025

ABSTRACT
AbstractImage super-resolution reconstruction is currently gaining huge attention because of its very promising applications. However, there are still problems such as loss of detailed features and low signal-to-noise ratio. To address this problem, we propose a generative adversarial network that incorporates attention and residual density. Firstly, the network makes full use of the different layers of features for fusion and prevents gradient decay through the residual dense module. Then through the attention gate structure, the noisy information is suppressed and the signal-to-noise ratio value is improved. The experimental results show that the method proposed is improved in peak signal-to-noise ratio and structural similarity index measure compared to other comparative methods, which proves the advancement of the method proposed.Keywords: Attention gate, Residual density module, Generative adversarial network, Image super-resolutionSubject terms: Computational science, Computer science

Introduction

Image super-resolution reconstruction technology, which has important application scenarios in the fields of security and surveillance images1, medical images2, remote sensing images3, etc., has gained tremendous attention. As low-resolution images or small-size images are enlarged in the process, it causes the image to become blurred, which affects people’s recognition of image features. To address this problem, Dong C et al.4 applies deep learning to image super-resolution applications for the first time, using a three-layer shallow convolutional neural network to achieve image super-resolution. The low-resolution images are up-scaled to high-resolution image size, and the high-resolution images are obtained through feature extraction, non-linear feature mapping and reconstruction by neural networks. Compared with the traditional methods5, the SRCNN has a great improvement in the reconstructed super-resolution image, which opens the precedent of deep learning method in image super-resolution method. Since the SRCNN method requires the low-resolution image to be up-sampled and interpolated to get the same size as the high-resolution image before feeding it into the network. This means that the convolution operation has to be performed at a higher resolution, which increases the computational complexity. Shi W et al.6 proposed a more efficient network, ESPCN, which extracts features directly on a small low-resolution image and then obtains a high-resolution image by rearranging each pixel of the feature image, which greatly reduces the training time. Kim J et al.7 proposed the VDSR network. This network deepens the overall network with full convolutional layers, and uses residual networks8 to drive the entire network to learn the differences between low-resolution and high-resolution images. Park S W et al.9 proposed the NeXtSRGAN, which integrates a ConvNeXt-based discriminator to overcome these limitations and achieve more realistic and high-quality super-resolution images. But with CNN-based super-resolution methods10,11, the recovered image usually loses high-frequency information, which reduces the visual perception. Ledig C et al.12 proposed SRGAN method, which for the first time used generative adversarial network (GAN13) to solve the super-resolution problem. The SRGAN method use perceptual loss and adversarial loss to enhance the realism of the recovered images and achieve better visual results. Wang X et al.14 proposed an enhanced adversarial generative super-resolution reconstruction method, which improves the multi-layer feature fusion capability by incorporating residual dense network (RDN15) into the generator structure of GAN, and improves the feature generation effect of the generator from low-resolution to super-resolution. Meng F et al.16 proposed a layered dense sampling and chain training to generate adversarial network, which enhances the fusion of internal features and improves the clarity of super-resolution images through dense sampling of features in each layer, but also brings noise interference. Based on the shortcomings of the above methods, we propose image super-resolution method using a generative adversarial network incorporating attention and residual density. Propose a novel and effective image super-resolution method that overcomes the shortcomings of existing methods and improves image super-resolution quality.

Related work

In the subsection, we give a brief introduction to generative adversarial network and attention gate. Image super-resolution method generates images that are structurally similar to real images, while achieving high fidelity and low loss of detail features. For high fidelity, we use a generative adversarial network structure to generate high-fidelity images. For low feature loss, we use residual dense connections and attention gates to enhance the fusion of features and prevent feature loss.

Generative adversarial network

Generative Adversarial Network (GAN12) is a deep generative model based on adversarial learning17 which consists of a generative network and a discriminative network. The generative network is responsible for generating the fake super resolution image based on the input noisy data; the discriminative network discriminates the authenticity based on the real high-resolution and generated fake super-resolution image. The generative network evades the judgement of the discriminator by continuously optimizing the generated image, and the discriminator makes its judgement more accurate by optimizing the network structure, thus forming an adversarial relationship between the two. Attention gate

Attention mechanism18 as a feature weight allocation mechanism can effectively highlight important feature information and suppress background feature information, and its core idea is to assign different weights according to the importance of features. For the attention gate(AG19), shown in Fig. 2, based on input features G and P, after convolution by 1 × 1 × 1, the corresponding position features are added, then negative features are suppressed by ReLU function, and the features are normalized by Sigmoid function. The processed results are multiplied with the initial feature P by channel to obtain the new feature Pl after the assigned weight. Methodologies

Multi-level feature fusion adopts the method of residual in residual density network. Because residual connections can prevent gradient disappearance when the number of network layers increases, and dense connections can better concatenate features of different scales from different layers. Therefore, the way of residual in residual density network contains both the shallow features of the low layer and the high-level features of the high layer, so the features are more abundant. At the same time, an attention gate structure is used to highlight important features and suppress noise.

Residual dense network

Residual Density Network (RDN14) is a deep learning network based on residual connectivity for image super-resolution reconstruction. The core of RDN is dense residual, which uses the structure of dense block to transfer information between each block and improve the utilization of information. To avoid gradient vanishing, the RDN uses the strategy of residual connectivity, which allows the inputs and outputs of each dense block to be added to each other to ensure the flow of information. Experiment

Experimental environment

The experiment was run on the Linux server and the configuration environment is Ubuntu20.04 Python 3.10, Stable Diffusion v1-5, CUDA 11.7, cuDNN 8, Pytorch 2, JupyterLab. Computing power is NVIDIA Tesla T4 GPU—16 GB +| 8 + TFlops SP CPU—8 cores| Memory—32 GB. The experimental details include batch size = 16, learning rate = 1 × e−4, and the optimization function is Adam. The loss function adopts a hybrid loss function of perceptual loss, content loss and adversarial loss in SRGAN12.

Datasets

The training set adopted in this experiment is DIV2K_train_HR in DIV2K22, the verification set is DIV2K_valid_HR, and the test set is Set523, Set1424, T9125, Urban10026. The training set DIV2K_train_HR contains 800 high-resolution images with 2 K resolution and the verification set DIV2K_valid_HR contains 100 high-resolution images, each with rich texture information. At the same time, to evaluate the generalization ability of the model, we used the images from the test sets Set5, Set14, T91 and Urban100 data sets for a single image super-resolution.

Discussion

Through the research in this paper, it can be fully proved that the method proposed can effectively improve the resolution of the image in the reconstruction of the super-resolution. However, this method also has some defects. When it is integrated into the residual-dense network and the network parameters are increased, the computing resource consumption is also increased. Such as, the FLOP is 734,219 for SRGAN and 867,149 for SRARDGAN. Meanwhile, we adopt the loss function in SRGAN, which uses perceptual loss and adversarial loss to enhance the realism of the recovered images, but this loss function has the potential to bring about gradient explosion and make the training unstable. Therefore, in the future, we will focus on how to reduce the network parameters while guaranteeing the image effect, and at the same time, we will study the new loss function and train the model to be more stable.

Conclusions

We propose image super-resolution method using a generative adversarial network incorporating attention and residual density. Increase feature fusion in multi-layer networks by incorporating residual-dense modules to prevent gradient decay. Attention gates are also incorporated into the GAN structure to suppress low-resolution image background noise. This method can effectively improve the image super-resolution and provide the basis for the later research of image segmentation28, target detection29, attitude tracking30 and so on.
