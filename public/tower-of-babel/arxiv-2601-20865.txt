The Noncomputability of Immune Reaction Complexity: Algorithmic Information Gaps under Effective Constraints
Emmanuel Pio Pastore, Francesco De Rango

Abstract
We introduce a validity-filtered, certificate-based view of reactions grounded in Algorithmic Information Theory. A fixed, total, input-blind executor maps a self-delimiting advice string to a candidate response, accepted only if a decidable or semi-decidable validity predicate V ⁡ ( x , r ) V(x,r) holds. The minimum feasible realizer complexity M ( x ) = min r : , V ⁡ ( x , r ) = 1 K ( r ) M(x)=\min_{r:,V(x,r)=1}K(r) , with K K denoting prefix Kolmogorov complexity, measures the minimal information required for a valid outcome. We define the Normalized Advice Quantile (NAQ) as the percentile of M ⁡ ( x ) M(x) across a reference pool, yielding a scale-free hardness index on [ 0 , 1 ] [0,1] robust to the choice of universal machine and comparable across task families. An Exact Realizer Identity shows that the minimal advice for any input-blind executor equals M ⁡ ( x ) M(x) up to O ⁡ ( 1 ) O(1) , while a description+selection upper bound refines it via computable feature maps, separating description cost K ⁡ ( y ) K(y) from selection cost ⌈ log ⁡ i y ​ ( x ) ⌉ \lceil\log i_{y}(x)\rceil . In finite-ambiguity regimes M ⁡ ( x ) ≈ min y ⁡ K ⁡ ( y ) M(x)\approx\min_{y}K(y) ; in generic-fiber regimes the bound is tight. NAQ is quasi-invariant under bounded enumeration changes. An operational converse links NAQ to rate–distortion: communicating advice with error ε \varepsilon requires average length near the entropy of target features. Extensions include a resource-bounded variant NAQ t \mathrm{NAQ}_{t} incorporating time-penalized complexity (Levin’s K ​ t Kt ) and an NP-style setting showing linear worst-case advice n − O ⁡ ( 1 ) n-O(1) . Finally, a DKW bound guarantees convergence of empirical NAQ estimates, enabling data-driven calibration via compressor-based proxies.

Framework and notation

A computable bijection
\varphi:\Sigma^{\ast}\to\{0,1\}^{\ast}
aligns alphabets so that
K(x)
abbreviates
K(\varphi(x))
, and the validity predicate
V:\Sigma^{\ast}\times\Gamma^{\ast}\to\{0,1\}
has c.e. acceptance unless stated otherwise. The domain of instances that admit at least one valid response is

D_{V}\ :=\ \bigl\{\,x\in\Sigma^{\ast}:\ \exists r\in\Gamma^{\ast}\ \ V(x,r)=1\,\bigr\}.

(2)

An
executor
is a fixed total computable map
E:\{0,1\}^{\ast}\to\Gamma^{\ast}
that does not read
x
, and advice strings form a prefix-free domain
\mathcal{A}
. Given

C_{\mathrm{rxn},E}^{\mathrm{adv}}(x)\ :=\ \min\bigl\{\,|w|:\ \exists r\ \bigl(E(w)=r\ \wedge\ V(x,r)=1\bigr)\,\bigr\},

(3)

which is upper-semicomputable by finite search in increasing advice length. To relate different executors we use a universal executor
E_{\mathrm{univ}}
that parses a self-delimiting header

E_{\mathrm{univ}}(\langle h_{F},w\rangle)=F(w)

|\langle h_{F},w\rangle|\leq|w|+|h_{F}|+O(1)

C^{\mathrm{adv}}_{\mathrm{rxn},E_{\mathrm{univ}}}(x)\ \leq\ C^{\mathrm{adv}}_{\mathrm{rxn},F}(x)\ +\ |h_{F}|\ +\ O(1),

(4)

and any executor that simulates
E_{\mathrm{univ}}
has the same burden up to an additive constant. When a discrete computable loss
L:\Sigma^{\ast}\times\Gamma^{\ast}\to\Lambda

\Lambda

\prec

\Gamma^{\ast}
, the selected response is the
\prec

r^{\ast}(x)\ \in\ \arg\min\nolimits_{\prec}\ \bigl\{\,L(x,r):\ V(x,r)=1\,\bigr\}.

(5)

3
NAQ: a Kolmogorov-relative hardness quantile

The basic quantity is the minimum realizer complexity already introduced, which we take to be
+\infty
if no valid
r
exists. For a finite multiset
\mathcal{T}\subseteq D_{V}
define the empirical cdf

\widehat{F}_{\mathcal{T}}(z)\ :=\ \frac{1}{|\mathcal{T}|}\,\#\bigl\{\,x^{\prime}\in\mathcal{T}:\ M(x^{\prime})\leq z\,\bigr\}.

(6)

Tie convention.

In discrete pools we use the
mid-rank
convention

\mathrm{NAQ}(x;\mathcal{T})\ :=\ \frac{\#\{x^{\prime}\in\mathcal{T}:\ M(x^{\prime})<M(x)\}\ +\ \tfrac{1}{2}\,\#\{x^{\prime}\in\mathcal{T}:\ M(x^{\prime})=M(x)\}}{|\mathcal{T}|},

(7)

which differs from the right-continuous cdf value
\widehat{F}_{\mathcal{T}}(M(x))
by at most
1/(2|\mathcal{T}|)
and is stable under pooling.

The constant-gap invariance of prefix complexity implies that, after coarse bucketing, NAQ is machine-stable in the following sense.

Theorem 1

(Coarse machine invariance)
.

Let
U,U^{\prime}
be universal machines with invariance constant
c
, i.e.,
|K_{U}(z)-K_{U^{\prime}}(z)|\leq c
for all
z
. If NAQ is computed on bucketed complexities
\lfloor K(\cdot)/b\rfloor
with
b>c
, then for any finite
\mathcal{T}
the empirical NAQ ranks of all
x\in\mathcal{T}
coincide across
U
and
U^{\prime}
.

Proof.

Changing from
K_{U}
to
K_{U^{\prime}}
perturbs each complexity by at most
c
, hence cannot cross a bucket boundary of width
b>c
. The bucket-induced weak order is therefore identical, and so are the ranks.
∎

Pool enlargement perturbs quantiles continuously; writing the bounds directly on empirical cdf’s avoids denominator confusion.

Lemma 1

(Pool-stability)
.

If
\mathcal{T}\subseteq\mathcal{T}^{\prime}
are finite pools, then for all
z\in\mathbb{R}
,

\frac{|\mathcal{T}|}{|\mathcal{T}^{\prime}|}\,\widehat{F}_{\mathcal{T}}(z)\ \leq\ \widehat{F}_{\mathcal{T}^{\prime}}(z)\ \leq\ \widehat{F}_{\mathcal{T}}(z)+\frac{|\mathcal{T}^{\prime}|-|\mathcal{T}|}{|\mathcal{T}^{\prime}|}.

(8)

In particular, at
z=M(x)
, the midpoint-tie NAQ in (
7
) obeys the same bounds up to
\pm 1/(2|\mathcal{T}^{\prime}|)
.

Finally, NAQ is distinct in spirit from randomness deficiency, structure functions, and normalized information distance: the first two depend on explicit model classes or two-part descriptions of
x
(algorithmic statistics and MDL
[
19
,
20
,
21
]
), while the third is pairwise and symmetric (information distance and its practical proxy NCD
[
22
,
23
]
); in contrast, NAQ is a univariate hardness order parameter governed entirely by the feasibility relation through

4
Exact Realizer Identity

Setting.

Fix a universal prefix machine
U
for
K(\cdot)
and a fixed
input-blind
executor model
E
that is total on the relevant prefix-free advice domain. All complexities are with respect to
U
, and feasibility is filtered solely by
V
.

Lemma 2

(Executor/program translation)
.

There exist constants
a,b
depending only on the choice of
U
and of the fixed header for
E_{\mathrm{univ}}
such that for every string
r
:

(i)

\displaystyle\exists w\ \ \text{with}\ \ E_{\mathrm{univ}}(w)=r\ \text{and}\ |w|\leq K_{U}(r)+a,

(ii)

\displaystyle\forall w\ \ \text{letting }r=E_{\mathrm{univ}}(w),\ \ K_{U}(r)\leq|w|+b.

Proof.

(i) Prefix a fixed self-delimiting header telling
E_{\mathrm{univ}}
to simulate
U
on a shortest
U
-program for
r
; the header contributes
a
. (ii) Hard-wire a prefix machine that simulates
E_{\mathrm{univ}}
on
w
and outputs
r
; the wrapper contributes
b
.
∎

Theorem 2

(Exact Realizer Identity)
.

For any computable
V
and universal executor
E_{\mathrm{univ}}
one has

C^{\mathrm{adv}}_{\mathrm{rxn},E_{\mathrm{univ}}}(x)\ =\ \min_{r:\,V(x,r)=1}K(r)\ \pm O(1)\ =\ M(x)\ \pm O(1).

(9)

Proof.

Upper bound: given a feasible
r_{x}
of complexity
K(r_{x})=M(x)\pm O(1)
, Lemma
2
(i) provides
w
with
|w|\leq K(r_{x})+a
, whence
C^{\mathrm{adv}}_{\mathrm{rxn},E_{\mathrm{univ}}}(x)\leq M(x)+O(1)
. Lower bound: for any
w
with feasible
r=E_{\mathrm{univ}}(w)
, Lemma
2
(ii) gives
K(r)\leq|w|+b
, hence
|w|\geq K(r)-b
; minimize over feasible
r
.
∎

6
Features: description and selection, tightness, and quasi-invariance

A computable feature map
\Phi:\Sigma^{\ast}\times\Gamma^{\ast}\to\{0,1\}^{m}
together with a computable circuit
C
determines feasibility by
V(x,r)=C(\Phi(x,r))
, and a computable bijection
\pi:\mathbb{N}_{\geq 1}\to\Gamma^{\ast}
orders realizers. For any feasible feature vector
y
at
x
we write

i_{y}^{\pi}(x)\ :=\ \min\bigl\{\,i\geq 1:\ \Phi\bigl(x,\pi(i)\bigr)=y\,\bigr\}.

(11)

This index quantifies how deep one must search, under
\pi
, to materialize
y
. The minimum realizer complexity obeys a simple and robust two-part upper bound.

\underbrace{K(\text{realizer})}_{\text{target}}\ \leq\ \underbrace{K(\text{desc})}_{:=\,K(y)}\ +\ \underbrace{K(\text{sel})}_{:=\,\lceil\log i_{y}^{\pi}(x)\rceil}\ +\ O(1).

Theorem 7

(Description plus selection)
.

For a universal executor
E
and every
x\in D_{V}
,

M(x)\ \leq\ \min_{y:\,C(y)=1}\ \Bigl(K(y)\ +\ \bigl\lceil\log i_{y}^{\pi}(x)\bigr\rceil\Bigr)\ \pm O(1).

(12)

Moreover, for each fixed feasible
y
one has the conditional lower bound

\min_{r:\,\Phi(x,r)=y}K(r)\ \geq\ K(y\mid x)\ \pm O(1),

(13)

and the upper bound

\min_{r:\,\Phi(x,r)=y}K(r)\ \leq\ K(y)+\bigl\lceil\log i_{y}^{\pi}(x)\bigr\rceil\ \pm O(1).

(14)

Remark 1

(Unconditional lower bound under decoding)
.

If there exists a total computable
\Psi
(independent of
x
) and a total computable
G
such that for all feasible
(x,r)
,
G(\Psi(r))
equals the part of
y
used in the bound, then
K(r)\geq K(y)-O(1)
along the fiber, so (
13
) strengthens to
\min_{r:\Phi(x,r)=y}K(r)\geq K(y)\pm O(1)
.

Fibers may contain accidentally simple realizers with
K(r)\ll K(y)+\log i_{y}^{\pi}(x)
, so equality requires structure; when such shortcuts are absent, the bound is tight in a precise sense. A first tightness regime arises under finite ambiguity: if for every feasible
y
there exists a finite computable prototype set
R_{y}
such that whenever
y
is feasible at
x
some
r\in R_{y}
realizes it, then
M(x)=\min_{y:\,C(y)=1}K(y)\pm O(1)
and NAQ reduces to the percentile of
K(y^{\ast}(x))
across the pool. A second regime can be captured by an explicit genericity assumption.

Assumption 1

(Fiber genericity)
.

There exist constants
c,\alpha>0
such that for all
x
and all feasible
y
, the number of
r
in the fiber
\{r:\Phi(x,r)=y\}
with
K(r)\leq K(y)+\lceil\log i_{y}^{\pi}(x)\rceil-c
is at most
i_{y}^{\pi}(x)^{-\alpha}
.

Remark 2

(Natural sufficient condition)
.

Assumption
1
holds if the universal semimeasure has no heavy concentration on compressed outliers within each fiber, e.g.

\sum_{\begin{subarray}{c}r:\ \Phi(x,r)=y\\
K(r)\leq K(y)+\lceil\log i_{y}^{\pi}(x)\rceil-c\end{subarray}}2^{-K(r)}\ \leq\ i_{y}^{\pi}(x)^{-\alpha}\,2^{-K(y)-\lceil\log i_{y}^{\pi}(x)\rceil},

which is implied by
K(r)\gtrsim K(y)+\lceil\log\mathrm{rank}_{\pi}(r)\rceil
up to
O(1)
on the fiber (no exponentially many compressed outliers).

Proposition 1

(Tightness under genericity)
.

If Assumption
1
holds, then

M(x)\ =\ \min_{y}\ \Bigl(K(y)+\bigl\lceil\log i_{y}^{\pi}(x)\bigr\rceil\Bigr)\ \pm O(1).

(15)

A final piece of robustness concerns the choice of enumeration. If two computable bijections
\pi
and
\pi^{\prime}
distort indices by at most a multiplicative factor
D
on the pairs
(x,y)
that attain the minimum, namely

\frac{1}{D}\ \leq\ \frac{i_{y}^{\pi^{\prime}}(x)}{i_{y}^{\pi}(x)}\ \leq\ D,

(16)

then

\min_{y}\Bigl[K(y)+\bigl\lceil\log i_{y}^{\pi^{\prime}}(x)\bigr\rceil\Bigr]\ =\ \min_{y}\Bigl[K(y)+\bigl\lceil\log i_{y}^{\pi}(x)\bigr\rceil\Bigr]\ \pm\bigl\lceil\log D\bigr\rceil\ \pm O(1),

(17)

so, after coarse binning, NAQ ranks are unchanged across enumerations.

An NP-style regime with a linear worst-case bound

Fix
n\geq 2
and let
\mathcal{X}_{n}=\{x_{s}:\ s\in\{0,1\}^{n}\}
where
x_{s}
self-delimits
s
; responses are pairs
r=\langle s^{\prime},y\rangle
, and
V_{\mathrm{P}}(x_{s},r)=1
if and only if
s^{\prime}=s
and

, so the feasible sets
F_{s}
are pairwise disjoint and the input-blindness of the executor forces the following linear lower bound.

Proposition 2

(Linear worst-case advice under input blindness)
.

For any total input-blind
E
and any
n\geq 2
,

\sup_{x\in\mathcal{X}_{n}}C^{\mathrm{adv}}_{\mathrm{rxn},E}(x)\ \geq\ n-O(1).

(18)

Proof.

If every
x\in\mathcal{X}_{n}
admitted advice shorter than
n-c
, then the number of distinct advice strings would be
<2^{n-c}
, hence two distinct identifiers would be served by the same advice, contradicting the disjointness of feasible sets.
∎

(NAQ view)
.

Against the pool
\mathcal{T}=\mathcal{X}_{n}
, the top NAQ quantiles near 1 must be occupied since some instances necessarily incur
\Omega(n)
advice; cf. instance and advice complexity

Resource-bounded variants and
\mathrm{NAQ}_{t}

Notation dictionary.

For an executor
E
and advice
w
, let
\tau_{E}(w)
denote the halting time of
E
on
w
. For an output string
r
, let

\tau^{\star}(r)\ :=\ \min\bigl\{\,\tau_{U}(p):\ U(p)=r,\ |p|=K(r)\,\bigr\}

be the running time of a shortest
U
-program for
r
.

In the spirit of Levin’s time-penalized description length
Kt

[
2
]
and universal search
[
3
]
, for a time-constructible budget
T
define the truncated advice
+
time objective

C_{\mathrm{rxn},E}^{(T)}(x)\ =\ \min\Bigl\{|w|+\log\bigl(1+\tau_{E}(w)\bigr):\ \exists r\ \bigl(E(w)=r\bigr)\ \wedge\ V_{T}(x,r)=1\Bigr\},

(19)

where
V_{T}
is verified within time
T(|x|)
.

Lemma 3

(Exact truncation)
.

Assume a computable bound
B
with the property that for all
x\in D_{V}
there exists
w
such that
E(w)=r
,
V_{T}(x,r)=1
, and
|w|+\log(1+\tau_{E}(w))\leq B(|x|)
. Then
C^{(T)}_{\mathrm{rxn},E}(x)
is uniformly computable by simulating each
w
with
|w|\leq B(|x|)
for

\Theta(x,w)\ :=\ 2^{\,B(|x|)-|w|}-1

(20)

steps, and the cutoff is tight in the following bidirectional sense:

(discard)

\displaystyle\tau_{E}(w)>\Theta(x,w)\ \Longrightarrow\ |w|+\log(1+\tau_{E}(w))>B(|x|),

(keep)

\displaystyle\tau_{E}(w)\leq\Theta(x,w)\ \Longrightarrow\ |w|+\log(1+\tau_{E}(w))\leq B(|x|).

Additive distortion under truncation.

When advice length is a priori bounded by
B(|x|)
, the additive distortion incurred by truncation in the objective
|w|+\log(1+\tau_{E}(w))
is
O(1)
(in fact zero under the stated cutoff), i.e., the computed value coincides with the true minimum up to a constant independent of
x
.

Definition 1

(Resource-bounded quantile
\mathrm{NAQ}_{t}
)
.

Let
M_{T}(x):=\min_{r:\,V_{T}(x,r)=1}\bigl(K(r)+\log(1+\tau^{\star}(r))\bigr)
. For a pool
\mathcal{T}
, define
\mathrm{NAQ}_{t}(x;\mathcal{T})
as the percentile of
M_{T}(x)
over
\mathcal{T}
; the coarse invariance and pool-stability statements for NAQ transfer
mutatis mutandis
.

Operational converse: calibrating NAQ mass

Consider any (possibly randomized) mechanism that, on
x\sim P
, emits prefix-free advice
W
for an input-blind executor producing
\hat{r}
and
\hat{y}=\Phi(x,\hat{r})

y^{*}(x)
(for example, the
\prec

) and require
\Pr[\hat{y}\neq y^{*}(x)]\leq\varepsilon
. Writing
L=\mathbb{E}[|W|]

Y^{*}=y^{*}(X)
, a Fano/Rate–Distortion converse (e.g.,
[
1
]
) yields

Probability space.

Let
(\Omega,\mathcal{F},\mathbb{P})
be a probability space,
X\sim P
the random input,

W
the (random) prefix-free advice emitted by the encoder,
\hat{r}=\hat{r}(W)
the executor’s output,

\hat{Y}=\Phi(X,\hat{r})
, and
Y^{*}=y^{*}(X)

\mathbb{P}
.

Theorem 8

(Fano/Rate–Distortion converse)
.

Assume
\mathcal{Y}
is finite (equivalently
H(Y^{*})<\infty
). Then

L\geq H(Y^{*})-h(\varepsilon)-\varepsilon\log(|\mathcal{Y}|-1)-O(1),

(21)

where the

H(W)\leq\mathbb{E}[|W|]+1

Remark 4

(NAQ interpretation)
.

Under finite ambiguity,
M(x)=K\bigl(Y^{*}(x)\bigr)\pm O(1)

Empirical estimation of NAQ (DKW)

Let
F
be the cdf of
M(X)
under a computable source
P
, and let
\widehat{F}_{n}
be the empirical cdf over
n

X_{1},\dots,X_{n}\sim P
(or over a computable pool). The Dvoretzky–Kiefer–Wolfowitz inequality
[

]
gives a sharp uniform guarantee:

Theorem 9

(Dvoretzky–Kiefer–Wolfowitz)

\Pr\Bigl(\ \sup_{z}\,|\widehat{F}_{n}(z)-F(z)|>\epsilon\ \Bigr)\ \leq\ 2e^{-2n\epsilon^{2}}\qquad\text{for all }\epsilon>0,

(22)

so the empirical NAQ converges uniformly to the true quantile, and coarse binning further stabilizes ranks across universal machines (Theorem

In practice one approximates

Biological application: a formal theory for adaptive immunity

We state the formal results with concise effective hypotheses; expanded modeling details are in Appendix
D
.

Effective search universe (concise).

Blueprints live in a computably enumerable domain over finite alphabets with computable length bounds; surrogate binding/presentation maps
(\widehat{A}_{\mathrm{B}},\widehat{A}_{\mathrm{MHC}},\widehat{A}_{\mathrm{T}})
and thresholds are total computable; proteasomal/endosomal digestions and MHC-binding filters are total computable transductions; the within-host dynamics
\mathcal{D}
is a finite-horizon computable system with rational coefficients.

Proposition 3

(Computable presentation and semi-decidable recognition)
.

Under the effective search universe above, the presentation map

\mathcal{P}_{H}:\ (\mathrm{Seq},\mathrm{PTM},\mathrm{Comp})\ \longmapsto\ \bigl\{\,p:\ \widehat{A}_{\mathrm{MHC}}(p,H)\geq\theta_{\mathrm{MHC}}\,\bigr\}

(23)

is total and computable. Consequently
\mathrm{Recog}(x,r)
is c.e. and
\mathrm{Exec}(x,r)
is decidable. If safety is enforced by typed blueprints, then
V
is c.e.; if safety is checked by explicit universal quantification over a computable self set
\mathcal{S}
, then
V\in\Delta^{0}_{2}
.

Lemma 4

(Tolerance barrier
\Rightarrow
finite ambiguity)
.

Let
d
be a computable metric on epitope/pMHC descriptors and suppose: (i) for each feasible
y
there is a computable length bound
L(y)
for descriptor strings; (ii) a tolerance margin

\min_{s\in\mathcal{S}}d(e,s)\geq\delta

; (iii) typed blueprint guards forbid recognition above threshold whenever

These results show how NAQ, and its timed variant

, arise from concrete mechanisms: clonal exploration materializes the selection term; processing/presentation keep feasibility effective; tolerance margins yield finite ambiguity so descriptive cost dominates; variant panels force worst-case hardness; kinetic deadlines push difficulty upward; and memory imposes an information budget.

13
Consequences

In computably enumerable regimes, the advice functional
C^{\mathrm{adv}}
aligns with Kolmogorov complexity and therefore inherits its noncomputability. When validity is decidable and the loss is computable, the optimization problem collapses in the sense that
r^{\ast}
is uniformly computable and
K(r^{\ast}\!\mid x)
remains bounded. If validity is decidable but the loss is only upper-semicomputable,
r^{\ast}
may fail to be computable; if validity is merely c.e. while the loss is computable, noncomputability already enters through feasibility. Under resource bounds, however, one can recover exact truncation provided an effective
a priori
budget is available, and NAQ encapsulates all of these separations into a universal hardness scale whose calibration is supplied directly by the operational converse. See also the computable analysis perspective on
\arg\min
and selection
[
29
,
30
]
.

Appendix A
Proof of Theorem
4
(decidable
V
and computable
L
)

Proof.

Fix a recursive, strictly increasing enumeration
\Lambda=\{\lambda_{0}<\lambda_{1}<\cdots\}\subset\mathbb{Q}_{\geq 0}
containing the range of
L
, and a computable
\prec
-enumeration
(e_{k})_{k\geq 0}
of
\Gamma^{\ast}
. For
x\in D_{V}
define the (nonempty) index set

J(x):=\{\,j\in\mathbb{N}:\ \exists r\in\Gamma^{\ast}\ \text{s.t. }V(x,r)=1\ \wedge\ L(x,r)\leq\lambda_{j}\,\}.

Since
J(x)\subseteq\mathbb{N}
is nonempty, it has a
least
element
j_{0}=\min J(x)
. Define

K(x):=\{\,k\in\mathbb{N}:\ V(x,e_{k})=1\ \wedge\ L(x,e_{k})\leq\lambda_{j_{0}}\,\}.

By definition of
j_{0}
,
K(x)
is nonempty. Because
\prec
is a computable total order with enumeration
(e_{k})
, the
\prec
-least
r
with loss
\leq\lambda_{j_{0}}
is exactly
e_{k^{\ast}}
where
k^{\ast}=\min K(x)
.

We now give a
terminating
procedure that, on input
x
, returns
e_{k^{\ast}}
.

Algorithm (dovetail on
(j,k)
):
For stages
s=0,1,2,\dots
, scan all pairs
(j,k)
with
j\leq s
and
k\leq s
in lexicographic order on
(j,k)
; for each pair, compute (i)
V(x,e_{k})
(decidable by assumption) and (ii)
L(x,e_{k})
(computable by assumption); if
V(x,e_{k})=1
and
L(x,e_{k})\leq\lambda_{j}
, halt and
output

e_{k}
.

Termination.
Since
j_{0}\in J(x)
and
k^{\ast}\in K(x)
, the pair
(j_{0},k^{\ast})
will be examined at stage
s\geq\max\{j_{0},k^{\ast}\}
. When it is examined, both predicates are true and the algorithm halts. Hence the algorithm terminates on every
x\in D_{V}
.

Correctness.
Suppose the algorithm halts on
(j,k)
. By construction,
L(x,e_{k})\leq\lambda_{j}
. If
j>j_{0}
, then, because pairs are scanned in increasing
(j,k)
, the pair
(j_{0},k^{\ast})
would have been scanned earlier and would have caused termination; contradiction. Thus
j=j_{0}
. Among those with
j=j_{0}
, pairs are scanned in increasing
k
, so
k
must be the
least
index with
V(x,e_{k})=1
and
L(x,e_{k})\leq\lambda_{j_{0}}
, i.e.
k=k^{\ast}
. Therefore the output is exactly

r^{\ast}(x)=e_{k^{\ast}}\in\arg\min\nolimits_{\prec}\{\,L(x,r):V(x,r)=1\,\}.

Uniform computability and bounded conditional complexity.
The procedure above is a single Turing machine that, on input
x
, halts with
r^{\ast}(x)
. Hence
x\mapsto r^{\ast}(x)
is total computable on
D_{V}
. Let
A
denote a fixed description (program) of this machine. For all
x
, the conditional Kolmogorov complexity satisfies

K\bigl(r^{\ast}(x)\mid x\bigr)\ \leq\ |A|\ +\ O(1)\ =:C,

because a shortest program can consist of a fixed code for
A
plus a constant-size wrapper that forwards its conditional input
x
to
A
and prints the result. The constant
C
is global (independent of
x
). This proves the theorem.
∎

Appendix B
Proof of Theorem
5
(decidable
V
and upper-semicomputable
L
)

Proof.

We work under the stated promise that inputs are of the form
x=0^{n}1u
, from which
n
is computably parsed. Fix a computable, prefix-free encoding
\mathrm{enc}(n,b)
for
(n,b)\in\mathbb{N}\times\{0,1\}
, and define

r_{n,0}:=\mathrm{enc}(n,0),\qquad r_{n,1}:=\mathrm{enc}(n,1).

Let the acceptance predicate be decidable and
trivial
:
V(x,r)\equiv 1
for all
(x,r)
.

Define the loss
L:\Sigma^{\ast}\times\Gamma^{\ast}\to\mathbb{Q}_{\geq 0}
by

L(x,r)=\begin{cases}2n+1-\mathbf{1}\{\text{$p_{n}$ halts}\},&\text{if }r=r_{n,1},\\
2n,&\text{if }r=r_{n,0},\\
2n+2+|r|,&\text{otherwise,}\end{cases}

where
(p_{n})_{n\geq 1}
is any fixed prefix-free enumeration of programs for a universal machine. Then:

•

The
codomain
of
L
is a recursive discrete subset of
\mathbb{Q}
(namely
\{2n,2n+1\}\cup\{2n+2+|r|:r\in\Gamma^{\ast}\}
).

•

L
is
upper-semicomputable
: for
r=r_{n,1}
output the rational sequence
q_{s}(x,r)\equiv 2n+1
for all
s
until a halting witness for
p_{n}
is enumerated, at which point switch forever to
q_{s}(x,r)\equiv 2n
; for
r=r_{n,0}
and all other
r
output the constant sequences
2n
and
2n+2+|r|
, respectively. In all cases
q_{s}(x,r)\searrow L(x,r)
.

•

For every
x=0^{n}1u
and every
r\notin\{r_{n,0},r_{n,1}\}
one has
L(x,r)=2n+2+|r|\geq 2n+2>2n+1\geq L(x,r_{n,1})
, so
no
such
r
can be a minimizer.

Consequently the set of minimizers at
x
is contained in
\{r_{n,0},r_{n,1}\}
. We distinguish two cases.

Case 1:
p_{n}
does not halt.
Then
L(x,r_{n,1})=2n+1>L(x,r_{n,0})=2n
, so the unique minimizer is
r^{\ast}(x)=r_{n,0}
.

Case 2:
p_{n}
halts.
Then
L(x,r_{n,1})=L(x,r_{n,0})=2n
. By hypothesis, the global tie-breaking order
\prec
is fixed so that, at equal loss,
r_{n,1}\prec r_{n,0}
. Therefore
r^{\ast}(x)=r_{n,1}
.

Noncomputability of the optimizer.
Consider the map
f:\mathbb{N}\to\{0,1\}
defined by

f(n)\ :=\ \begin{cases}1,&\text{if }r^{\ast}(0^{n}1u)=r_{n,1},\\
0,&\text{if }r^{\ast}(0^{n}1u)=r_{n,0}.\end{cases}

By the case analysis above,
f(n)=\mathbf{1}\{\text{$p_{n}$ halts}\}
. Thus if
x\mapsto r^{\ast}(x)
were computable, then the halting problem would be decidable—a contradiction. Hence
x\mapsto r^{\ast}(x)
is
not
computable.

Remark on conditional complexity.
For each fixed
x=0^{n}1u
, a constant-size program can, given
x
as conditional input, parse
n
and print either
r_{n,0}
or
r_{n,1}
with the choice hard-coded; therefore
K(r^{\ast}(x)\mid x)=O(1)
pointwise (this does not contradict noncomputability of the
function

x\mapsto r^{\ast}(x)
).
∎

Appendix D
Expanded biological modeling details (moved from Sec.
12
)

Within this encoding, an antigenic context is a finite record
x=(\mathrm{Seq};\mathrm{PTM};\mathrm{Comp};\mathrm{Kinetics};\mathrm{Host})
, where
\mathrm{Seq}
is a finite multiset of protein or peptide strings representing pathogen proteome fragments,
\mathrm{PTM}
records post-translational modifications and conformational motifs such as disulphides and glycan masks that govern BCR epitope visibility,
\mathrm{Comp}
gives the compartmental footprint (extracellular, endosomal, cytosolic) that determines MHC class routing (II versus I),
\mathrm{Kinetics}
specifies a simple growth/clearance model with parameters
(\beta,\delta)
and an initial inoculum
n_{0}
, and
\mathrm{Host}
lists MHC alleles
H=(H^{\mathrm{I}},H^{\mathrm{II}})
together with a tolerance profile
\mathcal{S}
that abstracts the self peptidome; all fields admit computable encodings once finite alphabets and rational parameters are fixed. A response is a self-delimiting code
r=(\mathsf{Rec},\mathsf{Eff},\mathsf{Mem},\mathsf{Sched})
decoded by a total input-blind interpreter:
\mathsf{Rec}
is a finite set of clonotype blueprints for BCR and/or TCR detailing V(D)J usage, junctional constraints (regex-style), and an affinity target band;
\mathsf{Eff}
is a finite vector over a small alphabet of effector modes such as
\mathrm{CD8\text{-}CTL}
,
\mathrm{Th1}
,
\mathrm{Th2}
,
\mathrm{Th17}
,
\mathrm{Tfh}
,
\mathrm{Treg}
, and
\mathrm{PlasmaB}
with cytokine knobs;
\mathsf{Mem}
prescribes memory allocations for B, CD4, and CD8 lineages with half-life parameters; and
\mathsf{Sched}
is a coarse schedule
\{(t_{i},\mathrm{module}_{i})\}
with discrete days
t_{i}\in\{0,\dots,T_{\max}\}
.

Validity is the conjunction of recognition, safety, and execution: we set
V(x,r)=1
if and only if
\mathrm{Recog}(x,r)\wedge\mathrm{Safe}(x,r)\wedge\mathrm{Exec}(x,r)
, and we display this compactly as

V(x,r)\ =\ \underbrace{\mathrm{Recog}(x,r)}_{\text{binding \& presentation}}\ \wedge\ \underbrace{\mathrm{Safe}(x,r)}_{\text{tolerance}}\ \wedge\ \underbrace{\mathrm{Exec}(x,r)}_{\text{operational success}}.

(30)

Recognition holds if either there exists an epitope
e
formed by
(\mathrm{Seq},\mathrm{PTM})
for which some blueprint in
\mathsf{Rec}
admits a BCR conformer whose coarse-grained binding functional
A_{\mathrm{B}}(e)
exceeds a threshold
\theta_{\mathrm{B}}
, or there exists a peptide
p
in the proteasomal or endosomal digest of
\mathrm{Seq}
that binds an allele in
H
with
A_{\mathrm{MHC}}(p,H)\geq\theta_{\mathrm{MHC}}
and for which some blueprint in
\mathsf{Rec}
admits a TCR conformer with
A_{\mathrm{T}}(p{:}H)\geq\theta_{\mathrm{T}}
; the binding maps
A_{\mathrm{B}},A_{\mathrm{MHC}},A_{\mathrm{T}}
are taken as computable surrogates, so the existential nature of the check makes
\mathrm{Recog}
c.e. Safety requires that no self peptide
s\in\mathcal{S}
with sufficiently strong presentation is recognized above a tolerance band, which we write as

\neg\exists s\in\mathcal{S}:\ A_{\mathrm{MHC}}(s,H)\geq\theta_{\mathrm{MHC}}^{\mathrm{self}}\ \wedge\ A_{\mathrm{T}}(s{:}H)\geq\theta_{\mathrm{T}}^{\mathrm{self}},

(31)

with an analogous guard for BCR via a library of self-like conformational motifs; being universal over an effectively enumerable
\mathcal{S}
, this is typically co-c.e. (violations are c.e.). Execution requires that when the computable within-host dynamical system
\mathcal{D}
, a rational-coefficient ODE/agent hybrid on an integer time grid, is driven by
\mathsf{Eff}
and
\mathsf{Sched}
instantiated by the recognized module(s), the pathogen burden remains below a harm threshold throughout the horizon:

\forall t\leq T_{\max}:\ \mathrm{Burden}_{\mathcal{D}}(t)\ \leq\ B_{\mathrm{safe}}.

(32)

Because
\mathcal{D}
is computable and

is finite,
\mathrm{Exec}
is decidable once recognition anchors the inputs; overall,

is c.e. if safety is enforced by typed blueprints that exclude self motifs by construction, while insisting on explicit safety checking over

makes

Case families and design heuristics (details)
