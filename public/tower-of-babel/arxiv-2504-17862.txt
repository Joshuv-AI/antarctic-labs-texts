Geodetic Set on Graphs of Constant Pathwidth and Feedback Vertex Set Number
Prafullkumar Tale

Abstract
In the Geodetic Set problem, the input consists of a graph G G and a positive integer k k . The goal is to determine whether there exists a subset S S of vertices of size k k such that every vertex in the graph is included in a shortest path between two vertices in S S . Kellerhals and Koana [IPEC 2020; J. Graph Algorithms Appl 2022] proved that the problem is 𝖶 ⁡ [ 1 ] {\mathsf{W}}[1] -hard when parameterized by the pathwidth and the feedback vertex set number of the input graph. They posed the question of whether the problem admits an 𝖷𝖯 {\mathsf{XP}} algorithm when parameterized by the combination of these two parameters. We answer this in negative by proving that the problem remains 𝖭𝖯 \mathsf{NP} -hard on graphs of constant pathwidth and feedback vertex set number.

Introduction

Consider a simple undirected graph
G
with vertex set
V(G)
and edge set
E(G)
.
For two vertices
u,v\in V(G)
, let
I(u,v)
be the set of all vertices in
G
that are part of some shortest path between
u
and
v
. For a subset
S
of vertices, we generalize this definition to
I(S)
by taking the union of
I(u,v)
for all pairs of vertices
u,v
in
S
. A subset of vertices
T
is said to be
covered
by
S
if
T\subseteq I(S)
. A set of vertices
S
is a
geodetic set
if
V(G)
is covered by
S
. In the
Geodetic Set
problem, the input is a graph
G
and a positive integer
k
, and the objective is to determine whether there is a geodetic set of size
k
.
This problem was introduced in
1993
by Harary, Loukakis, and Tsouros
[
28
]
.
We refer readers to
[
9
,
22
]
for the application
of the problem.
See
[
23
,
38
]
for a broader
discussion on geodesic convexity in graphs.

The
Geodetic Set
problem falls under the broad category of
metric graph problems
. These problems are defined using a metric on the graph, with the shortest distance between two vertices being the most commonly used metric. Metric graph problems include many important

{\mathsf{NP}}
-complete graph problems such as
Distance
d
-Dominating Set
(also called
(k,d)
-Center
),
Distance
d
-Independent Set
(also called
d
-Scattered Set
), and
Metric Dimension
. These problems have been central to the development of classical as well as parameterized algorithms and complexity theory
[
33
,
34
,
3
,
36
,
4
,
10
,
24
,
30
,
12
]
, as they behave quite differently from their more ‘local’ (neighborhood-based) counterparts such as
Dominating Set
or
Independent Set
.

Due to the non-local nature of metric graph problems, most algorithmic techniques fail to yield positive results.
Consider the case of the
Metric Dimension
problem
in which an input is a graph
G
and an integer
k
,
and the objective is to determine whether there is
a set
S
of at most
k
vertices such that for any pair of vertices

u
and
v
, there is a vertex in
S
which has distinct distances
to
u
and
v
.
In a seminal paper, Hartung and Nichterlein
[
29
]
proved that the problem is
\mathsf{W}
[2]-hard when parameterized by the solution size
k
. This motivated the structural parameterization of the problem
[
24
, Section 2.1]
.
The complexity of
Metric Dimension
parameterized by treewidth
remained an open problem for a long time, until Bonnet and Purohit
[
5
]

made the first breakthrough by proving that the problem is
\mathsf{W}
[1]-hard when
parameterized by pathwidth.
This result was strengthened in two directions: Li and Pilipczuk
[
36
]

proved that it is
para
-
\mathsf{NP}
-hard when parameterized by pathwidth,
whereas Galby et al.
[
26
]
showed that the problem is

\mathsf{W}
[1]-hard when parameterized by pathwidth
plus feedback vertex set number of the graph.

Continuing the ‘hardness saga’, we mention some results that hold
for both
Metric Dimension
and
Geodetic Set
.
Foucaud et al.
[
24
]
demonstrated that
these two problems on graphs of bounded diameter admit
double exponential conditional lower bounds when parameterized by treewidth, along with a matching algorithm.
This was a
first-of-its-kind
result for a natural
\mathsf{NP}
-complete problem.
The same set of authors also proved that both problems admit ‘exotic’
conditional lower bounds when parameterized by the vertex cover
number
[
25
]
.
Bergougnoux et al.
[
4
]
showed that
enumerating minimal solution sets for both problems in
split graphs is equivalent to enumerating minimal transversals of
hypergraphs, arguably the most important open problem
in algorithmic enumeration.

As illustrated in the examples above,
Metric Dimension
and

Geodetic Set
behave similarly concerning hardness results.
Kellerhals and Koana
[
35
]

proved that
Geodetic Set
is
\mathsf{W}
[1]-hard when parameterized by
the pathwidth and feedback vertex set number (and the solution size)
combined, a result similar to that of
Galby et al.
[
26
]
regarding
Metric Dimension
.
However, a result similar to that of Li and Pilipczuk’s work
[
36
]

on
Metric Dimension
for
Geodetic Set
is not known.
More formally, we do not know the complexity of the

Geodetic Set
problem on graphs of constant treewidth.
Kellerhals and Koana
[
35
]
posed an even stronger question: Does
Geodetic Set
admit an
{\mathsf{XP}}
algorithm when parameterized by the pathwidth
and feedback vertex set number?
We answer this question in the negative.

Theorem 1
.

Geodetic Set
is
\mathsf{NP}
-complete even on graphs of
pathwidth
17
and feedback vertex set number
13
.

Note that this result is surprising in the context of the closely
related problem
Geodetic Hull
.
In
Geodetic Hull
, the input is a graph
G
and an integer
k
, and the objective is to determine whether there is a vertex set
S
of size
k
such that
I|V^{j}(G)|[S]=V(G)
, where
I^{0}[S]=S
and
I^{j}[S]=I[I^{j-1}[S]]
for
j>0
.
It is easy to see that both these problems are trivial on trees as it is
necessary and sufficient to take all the leaves into the solution.
Kante et al.
[
32
]
proved, among other things, that the problem admits
an
\mathsf{XP}
-algorithm parameterized by treewidth.
Hence, while
Geodetic Hull
is polynomial-time solvable on
graphs of constant treewidth,
Geodetic Set
remains
\mathsf{NP}
-hard.

Preliminaries

For an integer
n
, we let
[n]=\{1,\ldots,n\}
.
We use standard graph-theoretic notation and refer the reader
to
[
17
]
for any undefined notation.
For an undirected graph
G
, the sets
V(G)
and
E(G)
denote its
set of vertices and edges, respectively.
Two vertices
u,v\in V(G)
are
adjacent
or
neighbors
if

(u,v)\in E(G)
.
We say a vertex
v
is a
pendant vertex
if its degree is one.
A vertex
v
is a
branching vertex
if its degree is at least three.
A path is a collection of vertices
\{v_{1},v_{2},\dots,v_{\ell}\}

such that
(v_{i},v_{i+1})
for every
i
in
[\ell-1]
.
In this case,
v_{1}
and
v_{\ell}
are two endpoints, whereas all the other vertices are called
internal vertices
.
We say a path is simple if all its internal vertices have degree
precisely two.
The length of a path is the number of edges in it.
The
distance
between two vertices
u,v
in
G
, denoted by

\dist(u,v)
, is the length of a shortest path connecting

u
to
v
.
For a subset
S
of
V(G)
, we denote the graph obtained by deleting
S
from
G
by
G-S
.
Recall that a subset
S\subseteq V(G)
is a
geodetic set
if for
every
u\in V(G)
, the following holds: there exist
s_{1},s_{2}\in S

such that
u
lies on a shortest path from
s_{1}
to
s_{2}
.
Consider a pendant vertex
v
in
G
.
Note that
v
does not belong to any shortest path between
any pair
x,y
of vertices which are distinct from
v
.
Hence,
v
belongs to every geodetic set of
G
.
This was also observed in
[
14
]
.

Parameterized Complexity.

In parameterized analysis, we associate each instance

I
with a parameter
\ell
, and are interested in an algorithm
with running time
f(\ell)\cdot|I|^{\mathcal{O}(1)}

for some computable function
f
.
Parameterized problems that admit such an algorithm are called

fixed parameter tractable
(
\mathsf{FPT}
) parameterized by
\ell
.
On the other hand,
{\mathsf{W}}[1]
-hardness categorizes problems that
are unlikely to have
\mathsf{FPT}
algorithms.
A parameterized problem is in
\mathsf{XP}
if it admits an algorithm running in time

|I|^{f(\ell)}
for some computable function
f
.
We say a parameterized problem in
para
-
\mathsf{NP}
-hard if it is

\mathsf{NP}
-hard even when the parameter is a constant.
For more on parameterized complexity and related terminologies, we refer the reader to the recent book by Cygan et al.
[
15
]
.

We define some of the parameters mentioned in this article.
For a graph
G
, a set
X\subseteq V(G)
is a

feedback vertex set
of
G
if
G-X
is an acyclic graph.
The
feedback vertex set number
of graph
G
, denoted by

\mathtt{fvs}(G)
, is the size of minimum feedback vertex set of
G
.
A tree decomposition of a graph
G
is a pair
(\mathcal{X},T)
where

T
is a tree and
\mathcal{X}=\{X_{i}\mid i\in V(T)\}
is a collection of subsets of

V(G)
such that:

(i)

\bigcup_{i\in V(T)}X_{i}=V(G)
,

(ii)
for each edge
(x,y)
in
E(G)
,
\{x,y\}\subseteq X_{i}

for some
i\in V(T)
, and

(iii)
for each
x
in
V(G)
the set
\{i\mid x\in X_{i}\}
induces a
connected subtree of
T
.
The width of the tree decomposition is
\textsf{max}_{i\in V(T)}\{|X_{i}|-1\}
.
The treewidth of a graph
G
is the minimum width over all tree
decompositions of
G
.
We denote by
\mathtt{tw}(G)
the treewidth of graph
G
.
If, in the definition of treewidth, we restrict the tree
T
to be a path, then we get the notion of pathwidth and denote it by
\mathtt{pw}(G)
.
It is easy to verify that
\mathtt{tw}(G)\leq\mathtt{fvs}(G)+1
and
\mathtt{tw}(G)\leq\mathtt{pw}(G)

whereas
\mathtt{pw}(G)
and
\mathtt{fvs}(G)
are incomparable.

We define an equivalent definition of pathwidth via mixed search games.
In a mixed search game, a graph
G
is considered a system of tunnels.
Initially, all edges are contaminated by a gas.
An edge is cleared by placing searchers at both its endpoints simultaneously
or by sliding a searcher along the edge.
A cleared edge is re-contaminated if there is a path from
an uncleared edge to the cleared edge without any searchers on its vertices or edges.
A search is a sequence of operations that can be of the following types:

(i)
placement of a new searcher on a vertex;

(ii)
removal of a searcher from a vertex;

(iii)
sliding a searcher on a vertex along an incident edge and
placing the searcher on the other end.
A search strategy is winning if, after its termination, all edges are
cleared.
The mixed search number of a graph
G
, denoted by
\texttt{ms}(G)
, is
the minimum number of searchers required for a winning strategy of mixed searching on
G
.
Takahashi et al.
[
39
]

proved that
\mathtt{pw}(G)\leq\texttt{ms}(G)\leq\mathtt{pw}(G)+1
,
which we use to bound the pathwidth of the graphs obtained in reduction.

NP-Hardness

In this section, we prove that the problem is
para
-
\mathsf{NP}
-hard when parameterized
by pathwidth and feedback vertex set number of the input graph.
We present a polynomial-time reduction from the

\mathsf{NP}
-hard
[

Input consists of a universe

Lemma 5
.

Pathwidth and feedback vertex set the number of

and

, respectively.

We present

Place

These searchers will never move from their places.
(This is equivalent to deleting common branching vertices and presenting

We search the graph in

Consider an element-encoding gadget encoding

We can place three searchers on

,

,
and

the path connecting these vertices and with common branching vertices

\mathcal{S}^{i}

in

4
Conclusion

In this article, we proved that
Geodetic Set

is
\mathsf{NP}
-complete even on graphs with constant pathwidth and feedback
vertex set number answering the open question by Kellerhals and Koana
[
35
]
.
In the same paper, the authors provided an
\mathsf{FPT}
algorithm
(with impractical running time) when parameterized by
treedepth (denoted by
\mathtt{td}
) of the input graph.
Recent work by Foucaud et al.
[
24
]

showed that
Geodetic Set
admits an algorithm running in time

2^{\mathtt{diam}^{\mathcal{O}(\mathtt{tw})}}\cdot poly(|V(G)|)
,
where
\mathtt{diam}
denotes the diameter of the graph.
This result, along with the fact that
\mathtt{diam}
and
\mathtt{tw}
are upper bounded
by
2^{\mathtt{td}}
and
\mathtt{td}+1
, respectively,
imply that
Geodetic Set

admits an algorithm running in time
2^{2^{\mathcal{O}(\mathtt{td}^{2})}}\cdot poly(|V(G)|)
.
It would be interesting to obtain an
\mathsf{FPT}
algorithm
parameterized by treedepth with improved running time.
We remark that
Foucaud et al.
[
24
]
proved
that the problem does not admit an algorithm running in time

2^{2^{o(\mathtt{td})}}\cdot poly(|V(G)|)
, unless the
ETH
fails.

As highlighted in the introduction of this article and
also in
[
8
,
35
]
,

Metric Dimension
and
Geodetic Set
share many hardness properties.
We mention one notable exception:

Metric Dimension
is
\mathsf{FPT}
when
parameterized by the solution size plus the treelength
[
3
]
,
however,
Geodetic Set
is
\mathsf{W}
[2]-hard when parameterized by
the solution size even when treelength is a constant.
See
[
20
, Theorem 2]
.
Regarding the parameterized complexity
of
Metric Dimension
when parameterized by pathwidth
and feedback vertex set number of the graph,
Galby et al.
[
26
]
showed that the problem is

\mathsf{W}
[1]-hard.
Can we improve this result to obtain a result for
Metric Dimension
as we did for
Geodetic Set
in this article?
