Combining Local Symmetry Exploitation and Reinforcement Learning for Optimised Probabilistic Inference – A Work In Progress
Sagad Hamid, Tanya Braun

Abstract
Efficient probabilistic inference by variable elimination in graphical models requires an optimal elimination order. However, finding an optimal order is a challenging combinatorial optimisation problem for models with a large number of random variables. Most recently, a reinforcement learning approach has been proposed to find efficient contraction orders in tensor networks. Due to the duality between graphical models and tensor networks, we adapt this approach to probabilistic inference in graphical models. Furthermore, we incorporate structure exploitation into the process of finding an optimal order. Currently, the agent’s cost function is formulated in terms of intermediate result sizes which are exponential in the number of indices (i.e., random variables). We show that leveraging specific structures during inference allows for introducing compact encodings of intermediate results which can be significantly smaller. By considering the compact encoding sizes for the cost function instead, we enable the agent to explore more efficient contraction orders. The structure we consider in this work is the presence of local symmetries (i.e., symmetries within a model’s factors).

4
MDP Formulation & RL Setting

For brevity, we refer to
Van Otterlo and Wiering (2012)
for background on
MDP
and
RL
. Analogous to the problem of finding an optimal contraction order in
TN
, we consider the problem of finding an optimal elimination order in
FG
and formulate it as an MDP.
For an
FG

G=(\boldsymbol{X}\cup\boldsymbol{F},\boldsymbol{E})
with
n

RV

\boldsymbol{X}=\{X_{1},\dots,X_{n}\}
, an elimination order
\rho=(X_{i_{1}},\dots,X_{i_{n}})
defines in which order we sum out
RV
to calculate the partition function. Summing out an
RV

X\in\boldsymbol{X}
creates an intermediate factor
\phi^{*}(\boldsymbol{X}^{*}\backslash\{X\})=\prod_{\phi(\boldsymbol{X}_{i})\in\boldsymbol{F}_{X}}\phi(\boldsymbol{X}_{i})
with
\boldsymbol{F}_{X}=\{\phi(\boldsymbol{X}_{i})\in\boldsymbol{F}\mid X\in\boldsymbol{X}_{i}\}
and
\boldsymbol{X}^{*}=\bigcup\boldsymbol{X}_{i}
. Since a factor over
RV

\boldsymbol{X}^{*}
needs to be created to obtain
\phi^{*}(\boldsymbol{X}^{*}\backslash\{X\})
, we generally define the sum-out cost as

c(X)=|\text{Dom}(\boldsymbol{X}^{*})|

and the total elimination order cost as

c(\rho)=\sum_{j=1}^{n-1}c(X_{j})
.
Please note that we obtain different sets of
RV

\boldsymbol{X}^{*}
for different orders.
Similarly, we aim for an order
\rho^{\text{min}}
of minimal cost, i.e.,

\displaystyle\mathcal{\rho}^{\text{min}}(G)=\text{argmin}_{\rho}~c(\rho).

(1)

Having defined the problem of finding an optimal elimination order, we analogously formulate the corresponding
MDP

(\mathsf{S},\mathsf{A},\mathsf{F},\mathsf{R})
: The state space
\mathsf{S}=\{G=(\boldsymbol{X}\cup\boldsymbol{F},\boldsymbol{E})\}
is the space of all
FG
, the actions
\mathsf{A}=\boldsymbol{X}
is the set of
RV
to sum out, the transition function
\mathsf{F}(G,X)=G^{\prime}(\boldsymbol{X}^{\prime}\cup\boldsymbol{F}^{\prime},\boldsymbol{E}^{\prime})
takes the current
FG
and the
RV
to sum out as input and outputs the resulting
FG

G^{\prime}
with
\boldsymbol{X}^{\prime}=\boldsymbol{X}^{*}\backslash\{X\},\boldsymbol{F}^{\prime}=\boldsymbol{F}\backslash\boldsymbol{F}_{X}\cup\phi^{*}(\boldsymbol{X}^{*}\backslash\{X\})
, and the (immediate) cost function
\mathsf{R}(G,X)=c(X)
is set to be the cost of summing out
X
in
G
. With the MDP formulation at hand, the goal is now to learn a policy that chooses actions, i.e., an
RV
to sum out next, s.t. the cumulative sum-out cost is kept minimal. To do so, we can analogously introduce a graph neural network for
RV
selection. Specifically, we use the graph neural network to determine the next
RV
to sum out for a given
FG
to sequentially eliminate all
RV
. After each elimination, we remove the node of the eliminated
RV
and the nodes of the corresponding factors and include a new factor, defined over the
RV
involved, that represents the intermediate result. To calculate the partition function, we continue until all
RV
are eliminated, though it can be adapted to any type of query. After each elimination step, we update the total cost according to the cost function. For space reasons, the detailed description of the
RL
procedure is left for future work.

We observe that in the current formalism the sum-out cost is defined w.r.t. the domain size of
\boldsymbol{X}^{*}
as we calculate an intermediate result factor
\phi^{*}(\boldsymbol{X}^{*})
. Unfortunately, this size is exponential in the number of
RV

|\boldsymbol{X}^{*}|
. However, if we know beforehand that the intermediate factor has some structure that allows for introducing a compact encoding, we do not have to calculate all potentials, but only those required for the compact encoding. As a consequence, we can reformulate the cost function to not depend exponentially on
|\boldsymbol{X}^{*}|
anymore, but rather on the size of the compact encoding. With costs that scale with specific structures, we enable the agent to explore new elimination orders. In the following, we show how local symmetries can be compactly encoded and how probabilistic inference can benefit from these compact encodings to create smaller intermediate factors.

\displaystyle|\text{Dom}(S_{\boldsymbol{\bar{X}}})|=\binom{n^{\prime}+d^{\prime}-1}{d^{\prime}-1},

(3)

Next, we show how to perform the common factor operations, namely multiplication of factors and sum-out of
RV
, with the compact encoding. This allows us to take advantage of local symmetries to introduce compact encodings of intermediate result factors during inference. We start with the sum-out operation which preserves symmetries:

Theorem 5.1

(
Sum-Out with Symmetries
)
.

Let
\phi(\boldsymbol{X})
be a factor and let
X\in\boldsymbol{X},\boldsymbol{X}^{\prime}=\boldsymbol{X}\backslash\{X\}
, and
\phi^{\prime}(\boldsymbol{X}^{\prime})=\sum_{X}\phi(\boldsymbol{X})
. Let further
\text{Sym}^{\prime}_{\phi}(\boldsymbol{X})=\text{Sym}_{\phi}(\boldsymbol{X})\backslash\{\boldsymbol{\bar{X}}\}\cup\{\boldsymbol{\bar{X}}\backslash\{X\}\}
if there exists
\boldsymbol{\bar{X}}\in\text{Sym}_{\phi}(\boldsymbol{X})
with
X\in\boldsymbol{\bar{X}}
. Then, the following holds:

\text{Sym}_{\phi^{\prime}}(\boldsymbol{X}^{\prime})=\begin{cases}\text{Sym}_{\phi}(\boldsymbol{X})&\text{if }\nexists\boldsymbol{\bar{X}}\in\text{Sym}_{\phi}(\boldsymbol{X}):X\in\boldsymbol{\bar{X}}\\
\text{Sym}^{\prime}_{\phi}(\boldsymbol{X})&\text{else }\end{cases}

Proof.

Summing out
RV

X
with
d=|\text{Dom}(X)|
yields for any
\boldsymbol{x}^{\prime}\in\text{Dom}(\boldsymbol{X}^{\prime})
:

\displaystyle\phi^{\prime}(\boldsymbol{x}^{\prime})=\sum_{i=0}^{d-1}\phi(\boldsymbol{x}^{\prime},i).

For the first case, i.e., where
X
is not included in any interchangeable subset in
\text{Sym}_{\phi}(\boldsymbol{X})
, we obtain
\forall\boldsymbol{\bar{X}}\in\text{Sym}_{\phi}(\boldsymbol{X})
:

\displaystyle\phi^{\prime}(\boldsymbol{x}^{\prime})=\sum_{i=0}^{d-1}\phi(\boldsymbol{x}^{\prime},i)=\sum_{i=0}^{d-1}\phi(\sigma_{\boldsymbol{\bar{x}}}(\boldsymbol{x}^{\prime}),i)=\phi^{\prime}(\sigma_{\boldsymbol{\bar{x}}}(\boldsymbol{x}^{\prime}))

for any permutation
\sigma_{\boldsymbol{\bar{X}}}(\boldsymbol{x}^{\prime})
, meaning that symmetries hold in
\phi^{\prime}(\boldsymbol{X}^{\prime})
as well. It is clear that the same argument holds for the latter case with interchangeable
RV
in
\text{Sym}^{\prime}_{\phi}(\boldsymbol{X})
.
∎

An immediate consequence of
Theorem

5.1
is that in the presence of symmetries the sum-out operation can be performed with the compact encoding. Most importantly, since the resulting factor preserves symmetries, we only have to calculate as many potentials as required for the resulting compact encoding. We continue with the multiplication of factors with symmetries:

Theorem 5.2

(
Multiplication with Symmetries
)
.

Let
\phi_{1}(\boldsymbol{X}_{1}),\phi_{2}(\boldsymbol{X}_{2}),\phi_{3}(\boldsymbol{X}_{3})
be factors with
\phi_{3}(\boldsymbol{X}_{3})=\phi_{1}(\boldsymbol{X}_{1})\cdot\phi_{2}(\boldsymbol{X}_{2})
. Then, the following holds for
i,j\in\{1,2\}
with
i\neq j
:

(i)

\boldsymbol{\bar{X}}_{i}\in\text{Sym}_{\phi_{i}}(\boldsymbol{X}_{i})\Rightarrow

\boldsymbol{\bar{X}}_{i}\backslash(\boldsymbol{\bar{X}}_{i}\cap\boldsymbol{X}_{j})\in\text{Sym}_{\phi_{3}}(\boldsymbol{X}_{3})

(ii)

\boldsymbol{\bar{X}}_{i}\in\text{Sym}_{\phi_{i}}(\boldsymbol{X}_{i})\land\exists\boldsymbol{\bar{X}}_{j}\in\text{Sym}_{\phi_{j}}(\boldsymbol{X}_{j}):\boldsymbol{\bar{X}}_{i}\cap\boldsymbol{\bar{X}}_{j}\neq\emptyset\\
\Rightarrow\boldsymbol{\bar{X}}_{i}\cap\boldsymbol{\bar{X}}_{j}\in\text{Sym}_{\phi_{3}}(\boldsymbol{X}_{3})

Proof.

For assignments
\boldsymbol{x}_{3}\in\boldsymbol{X}_{3}
we have

\displaystyle\phi_{3}(\boldsymbol{x}_{3})=\phi_{i}(\boldsymbol{x}_{3i})\cdot\phi_{j}(\boldsymbol{x}_{3j}),

with
\boldsymbol{x}_{3i}=\pi_{\boldsymbol{X}_{i}}(\boldsymbol{x}_{3}),\boldsymbol{x}_{3j}=\pi_{\boldsymbol{X}_{j}}(\boldsymbol{x}_{3})
. For case (i), let
\boldsymbol{\bar{X}}_{i}^{\prime}=\boldsymbol{\bar{X}}_{i}\backslash(\boldsymbol{\bar{X}}_{i}\cap\boldsymbol{X}_{j})
for any
\boldsymbol{\bar{X}}_{i}\in\text{Sym}_{\phi_{i}}(\boldsymbol{X}_{i})
. Since
\boldsymbol{\bar{X}}^{\prime}_{i}
does not contain any
RV
in
\boldsymbol{X}_{j}
, we obtain

\displaystyle\phi_{3}(\boldsymbol{x}_{3})

\displaystyle=\phi_{i}(\boldsymbol{x}_{3i})\cdot\phi_{j}(\boldsymbol{x}_{3j})

\displaystyle=\phi_{i}(\sigma_{\boldsymbol{\bar{x}}^{\prime}_{i}}(\boldsymbol{x}_{3i}))\cdot\phi_{j}(\boldsymbol{x}_{3j})

\displaystyle=\phi_{3}(\sigma_{\boldsymbol{\bar{x}}^{\prime}_{i}}(\boldsymbol{x}_{3})),

for any permutation
\sigma_{\boldsymbol{\bar{x}}_{i}^{\prime}}(\boldsymbol{x}_{3})
. For case (ii), let
\boldsymbol{\bar{X}}_{ij}=\boldsymbol{\bar{X}}_{i}\cap\boldsymbol{\bar{X}}_{j}
with
\boldsymbol{\bar{X}}_{i}\cap\boldsymbol{\bar{X}}_{j}\neq\emptyset
for any two sets
\boldsymbol{\bar{X}}_{i}\in\text{Sym}_{\phi_{i}}(\boldsymbol{X}_{i}),\boldsymbol{\bar{X}}_{j}\in\text{Sym}_{\phi_{j}}(\boldsymbol{X}_{j})
. Then, we obtain

\displaystyle\phi_{3}(\boldsymbol{x}_{3})

\displaystyle=\phi_{i}(\boldsymbol{x}_{3i})\cdot\phi_{j}(\boldsymbol{x}_{3j})

\displaystyle=\phi_{i}(\sigma_{\boldsymbol{\bar{x}}_{ij}}(\boldsymbol{x}_{3i}))\cdot\phi_{j}(\sigma_{\boldsymbol{\bar{x}}_{ij}}(\boldsymbol{x}_{3j}))

\displaystyle=\phi_{3}(\sigma_{\boldsymbol{\bar{x}}_{ij}}(\boldsymbol{x}_{3})),

for any permutation
\sigma_{\boldsymbol{\bar{x}}_{ij}}(\boldsymbol{x}_{3})
.
∎

Theorem

5.2
provides information on which symmetries remain after multiplication, allowing us to determine the compact encoding of the resulting factor.

6
Conclusion

We have adapted a recently introduced
RL
approach for finding optimal contraction orders in
TN
to the problem of finding optimal elimination orders for probabilistic inference in
PGM
. We further incorporated the exploitation of local symmetries which allows for introducing compact encodings for intermediate result factors, enabling the agent to explore new elimination orders.
There exist many other interesting compact encodings such as low-rank tensor decompositions that can be taken into account for the cost function. Further, one can reformulate the
RL
setting to consider evidence as well as other types of queries.
