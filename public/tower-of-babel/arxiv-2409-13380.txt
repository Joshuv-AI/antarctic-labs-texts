Parameterized Local Search for Max c c -Cut
Jaroslav Garvardt, Niels Grüttemeier, Christian Komusiewicz, Nils Morawietz

Abstract
In the NP-hard Max c c -Cut problem, one is given an undirected edge-weighted graph G G and aims to color the vertices of G G with c c colors such that the total weight of edges with distinctly colored endpoints is maximal. The case with c = 2 c=2 is the famous Max Cut problem. To deal with the NP-hardness of this problem, we study parameterized local search algorithms. More precisely, we study LS Max c c -Cut where we are also given a vertex coloring and an integer k k and the task is to find a better coloring that changes the color of at most k k vertices, if such a coloring exists; otherwise, the given coloring is k k -optimal. We show that, for all c ≥ 2 c\geq 2 , LS Max c c -Cut presumably cannot be solved in f ⁡ ( k ) ⋅ n 𝒪 ⁡ ( 1 ) f(k)\cdot n^{\mathcal{O}(1)} time even on bipartite graphs. We then present an algorithm for LS Max c c -Cut with running time 𝒪 ⁡ ( ( 3 ​ e ​ Δ ) k ⋅ c ⋅ k 3 ⋅ Δ ⋅ n ) \mathcal{O}((3e\Delta)^{k}\cdot c\cdot k^{3}\cdot\Delta\cdot n) , where Δ \Delta is the maximum degree of the input graph. Finally, we evaluate the practical performance of this algorithm in a hill-climbing approach as a post-processing for a state-of-the-art heuristic for Max c c -Cut . We show that using parameterized local search, the results of this state-of-the-art heuristic can be further improved on a set of standard benchmark instances.

Introduction

Graph coloring and its generalizations are among the most famous NP-hard optimization problems with numerous practical applications
[
22
]
.
In one prominent problem variant, we want to color the vertices of an edge-weighted graph with
c
colors so that the sum of the weights of all edges that have endpoints with different colors is maximized.
This problem is known as

Max
c
-Cut

[
12
,
23
]
or

[

Applications of

-Cut

[

[

]

[

]
, sampling of public opinions in social networks

In addition,

An equivalent formulation of the problem is to ask for a coloring that minimizes the weight sum of the edges whose endpoints receive the same color; this formulation is known as

[

The main difference is that for instances of

From an algorithmic viewpoint, even restricted cases of

-Cut

The special case

Moreover, for all

As a consequence,

-Cut

While

[

Due to

A popular heuristic approach for

c
-Cut

is hill-climbing local search
[
11
,
32
]
with the 1-flip neighborhood.
Here, an
initial solution (usually computed by a greedy algorithm) is replaced by a better one in
the 1-flip neighborhood as long as such a better solution exists.
Herein, the 1-flip
neighborhood of a coloring is the set of all colorings that can be obtained by
changing the color of one vertex.
A coloring that has no improving 1-flip is called
1-optimal and the problem of computing 1-optimal solutions has also received interest from
a theoretical standpoint: Finding 1-optimal solutions for
Max Cut
is PLS-complete
on edge-weighted graphs
[

and thus presumably not efficiently solvable in
the worst case.
This PLS-completeness result for the 1-flip neighborhood was later
extended to
Generalized Graph Coloring
, and thus to
Max
c
-Cut
, for all
c

[
41
]
.
For graphs where the absolute values of all edge weights are constant, however, a simple hill climbing algorithm terminates after
\mathcal{O}(m)
improvements, where
m
is the number of edges in the input graph.
Here, a different question arises: Can we replace the 1-flip neighborhood with a larger efficiently searchable neighborhood, to avoid being stuck in a bad local optimum?
A natural candidate is the
k
-flip neighborhood where we are allowed to change the color of at most
k

As noted by Kleinberg and Tardos
[
26

, a standard algorithm for searching the
k
-flip neighborhood takes
\Theta(n^{k}\cdot m)

This led Kleinberg and Tardos to conclude that the

In this work, we ask whether we can do better than the brute-force
\Theta(n^{k}\cdot m)
-time algorithm or, in other words, whether the dismissal of
k
-flip neighborhood may have been premature.

The ideal framework to answer this question is parameterized local search, where the
main goal would be to design an algorithm that in

finds a better solution in the
k
-flip neighborhood or correctly answers that the current

k

Such a running time is preferable to

The framework also provides a toolkit for negative results that allows to

In fact, most parameterized local search problems turn out to be

Our Results.

We study
LS Max
c
-Cut
, where we want to decide whether a given coloring has a better one in its
k
-flip neighborhood.
We first show that
LS Max
c
-Cut
is presumably not solvable in
f(k)\cdot n^{o(k)}
time and transfer this lower-bound also to local search versions of related partition problems like
Min Bisection
and
Max Sat
.
We then present an algorithm to solve
LS Max
c
-Cut
in time
\mathcal{O}((3e\Delta)^{k}\cdot c\cdot k^{3}\cdot\Delta\cdot n)
, where
\Delta
is the maximum degree of the input graph.
To put this running time bound into context, two aspects should be discussed:
First, the NP-hardness of the special case of
Max
c
-Cut
with
\Delta=3
implies that a running time of
f(\Delta)\cdot n^{\mathcal{O}(1)}
is impossible unless
\mathrm{P}=\mathrm{NP}
.
Second, only the parameter
k
occurs in the exponent; we say that the running time grows mildly with respect to
\Delta
and strongly with respect to
k
.
This is desirable as
k
is a user-determined parameter whereas
\Delta
depends on the input; a broader discussion of this type of running times is given by Komusiewicz and Morawietz
[
29
]
.

The algorithm is based on two main observations:
First, we show that minimal improving flips are connected in the input graph.
This allows to enumerate candidate flips in
\mathcal{O}((e\Delta)^{k}\cdot k\cdot n)
time.
Second, we show that, given a set of
k
vertices to flip, we can determine an optimal way to flip their colors in
\mathcal{O}(3^{k}\cdot c\cdot k^{2}+k\cdot\Delta)
time.
We then discuss several ways to speed up the algorithm, for example by computing upper bounds for the improvement of partial flips.
We finally evaluate our algorithm experimentally when it is applied as post-processing for a state-of-the-art
Max
c
-Cut
heuristic
[
33
]
.
In this application, we take the solutions computed by the heuristic and improve them by hill-climbing with the
k
-flip neighborhood for increasing values of
k
.
We show that, for a standard benchmark data set, a large fraction of the previously best solutions can be improved by our algorithm, leading to new record solutions for these instances.
The post-processing is particularly successful for the instances of the data set with
c>2
and both positive and negative edge weights.

Afterwards, extend the intractability results even to the permissive version of

4
Algorithms

In this section, we complement the running time lower bound of
Theorem

2
by presenting an algorithm for
LS Max
c
-Cut
that runs in
\Delta^{\mathcal{O}(k)}\cdot c\cdot n
time, where
\Delta
denotes the maximum degree of the input-graph.
Our algorithm for
LS Max
c
-Cut
follows a simple framework: Generate a collection of candidate sets
S
that may improve the coloring if the vertices in
S
flip their colors.
For each such candidate set
S
, we only know that the colors of the vertices of
S
change, but we do not yet know which new color the vertices receive.
To answer this question, that is, to find whether there is any coloring of
S
that leads to an improving coloring, we present an algorithm based on dynamic programming.

We first describe the subroutine that we use to find a best coloring for a given candidate set
S
of vertices to flip.

Theorem 4
.

Let
G=(V,E)
be a graph, let
\omega:E\to\mathds{Q}
be an edge-weight function, let
\chi
be a
c
-coloring of
G
, and let
S\subseteq V
be a set of size at most
k
.
One can compute in
\mathcal{O}(3^{k}\cdot c\cdot k^{2}+k\cdot\Delta(G))
time a
c
-coloring
\chi^{\prime}
of
G
such that
D_{\mathrm{flip}}(\chi,\chi^{\prime})\subseteq S
and
\omega(E(\chi^{\prime}))
is maximal among all such colorings.

Proof.

We use dynamic programming.
Initially, we compute for each vertex
v\in S
and each color
i\in[1,c]
the weight
\theta_{v}^{i}
of edges between
v
and vertices of
V\setminus S
that do not receive color
i
under
\chi
, that is,
\theta_{v}^{i}:=\omega(\{\{v,w\}\in E\mid w\in N(v)\setminus S,\chi(w)\neq i\})
.
Moreover, we compute the weight
\omega_{S}
of all properly colored edges of
E(S,N[S])
as
\omega_{S}:=\omega(\{\{u,v\}\in E(S,N[S])\mid\chi(u)\neq\chi(v)\})
.
This can be done in
\mathcal{O}(c\cdot k+k\cdot\Delta(G))
time.

The table
T
has entries of type
T[S^{\prime},c^{\prime}]
for each vertex set
S^{\prime}\subseteq S
and each color
c^{\prime}\in[1,c]
.
Each entry
T[S^{\prime},c^{\prime}]
stores the maximum total weights of properly colored edges with at least one endpoint in
S^{\prime}
and no endpoint in
S\setminus S^{\prime}
such that the following holds:

1.

the vertices in
S^{\prime}
have some color in
[1,c^{\prime}]
, and

2.

every vertex
v\in V\setminus S
has color
\chi(v)
.

We start to fill the dynamic programming table by setting

T[S^{\prime},1]:=\sum_{v\in S^{\prime}}\theta_{v}^{1}
for each vertex set
S^{\prime}\subseteq S
.

For each vertex set
S^{\prime}\subseteq S
and each color
c^{\prime}\in[2,c]
, we set

\displaystyle T[S^{\prime},c^{\prime}]:=

\displaystyle\max_{S^{\prime\prime}\subseteq S^{\prime}}T[S^{\prime}\setminus S^{\prime\prime},c^{\prime}-1]+\omega(E(S^{\prime\prime},S^{\prime}\setminus S^{\prime\prime}))+\sum_{v\in S^{\prime\prime}}\theta_{v}^{c^{\prime}}.

Intuitively, to find the best way to assign colors of
[1,c^{\prime}]
to the vertices of
S^{\prime}
, we search for the best vertex set
S^{\prime\prime}\subseteq S^{\prime}
, assign color
c^{\prime}
to all vertices of
S^{\prime\prime}
, and find the best way to assign the colors of
[1,c^{\prime}-1]
to the vertices of
S^{\prime}\setminus S^{\prime\prime}
.
The maximal improvement
\omega(E(\chi^{\prime}))-\omega(E(\chi))
for any
c
-coloring
\chi^{\prime}
with
D_{\mathrm{flip}}(\chi,\chi^{\prime})\subseteq S
can then be found by evaluating
T[S,c]-\omega_{S}
: this term corresponds to the maximum total weight of properly colored edges we get when distributing the vertices of
S
among all color classes minus the original weights when every vertex of
S
sticks with its color under
\chi
.
The corresponding
c
-coloring can be found via traceback.

The formal correctness proof is straightforward and thus omitted.
Hence, it remains to show the running time.
The dynamic programming table
T
has
2^{k}\cdot c
entries.
Each of these entries can be computed in
\mathcal{O}(2^{|S^{\prime}|}\cdot k^{2})
time.
Consequently, all entries can be computed in
\mathcal{O}(\sum_{i=0}^{k}\binom{k}{i}\cdot 2^{i}\cdot c\cdot k^{2})=\mathcal{O}(3^{k}\cdot c\cdot k^{2})
time in total.
Hence, the total running time is
\mathcal{O}(3^{k}\cdot c\cdot k^{2}+k\cdot\Delta(G))
.
∎

For
LS Max Cut
, if we enforce that each vertex of
S
changes its color, the situation is even simpler:
When given a set
S\subseteq V
of
k
vertices that must flip their colors, the best possible improvement can be computed in
\mathcal{O}(k\cdot\Delta(G))
time, since every vertex of
S
must replace its color with the unique other color.

Recall that the idea of our algorithms for
LS Max Cut
and
LS Max
c
-Cut
is to iterate over possible candidate sets of vertices that may flip their colors.
With the next lemma we show that it suffices to consider those vertex sets that are connected in the input graph.

Lemma 3
.

Let
I:=(G=(V,E),c,\omega,\chi,k)
be an instance of
LS Max
c
-Cut
.
Then, for every inclusion-minimal improving
k
-flip
\chi^{\prime}
for
\chi
, the vertex set
D_{\mathrm{flip}}(\chi,\chi^{\prime})
is connected in
G
.

Proof.

Let
\chi^{\prime}
be an inclusion-minimal improving
k
-flip for
\chi
.
Let
S^{\prime}:=D_{\mathrm{flip}}(\chi,\chi^{\prime})
be the vertices
\chi
and
\chi^{\prime}
do not agree on and let
\mathcal{C}
denote the connected components in
G[S^{\prime}]
.
We show that if there are at least two connected components in
\mathcal{C}
, then there is an improving
k
-neighbor
\widetilde{\chi}
of
\chi
with
D_{\mathrm{flip}}(\chi,\widetilde{\chi})\subsetneq D_{\mathrm{flip}}(\chi,\chi^{\prime})
.
For each connected component
C\in\mathcal{C}
, let
E^{+}_{C}:=(E(C,V)\cap E(\chi^{\prime}))\setminus E(\chi)
denote the set of properly colored edges in
E(\chi^{\prime})\setminus E(\chi)
that have at least one endpoint in
C
and let
E^{-}_{C}:=(E(C,V)\cap E(\chi))\setminus E(\chi^{\prime})
denote the set of properly colored edges in
E(\chi)\setminus E(\chi^{\prime})
that have at least one endpoint in
C
.
Note that
E(\chi^{\prime})\setminus E(\chi)=\sum_{C\in\mathcal{C}}E^{+}_{C}
and that
E(\chi)\setminus E(\chi^{\prime})=\sum_{C\in\mathcal{C}}E^{-}_{C}
.
Hence, the improvement of
\chi^{\prime}
over
\chi
is

\omega(E(\chi^{\prime}))-\omega(E(\chi))=\sum_{C\in\mathcal{C}}\omega(E^{+}_{C})-\sum_{C\in\mathcal{C}}\omega(E^{-}_{C})=\sum_{C\in\mathcal{C}}(\omega(E^{+}_{C})-\omega(E^{-}_{C}))

Since
\chi^{\prime}
improves over
\chi
, this implies that there is at least one connected component

with
\omega(E^{+}_{S})-\omega(E^{-}_{S})>0
.
Let
\widetilde{\chi}
be the
c
-coloring of
G
that agrees with
\chi
on all vertices of
V\setminus S
and agrees with
\chi^{\prime}
on all vertices of
S
.
Hence,
\widetilde{\chi}
is an improving
k
-neighbor of
\chi
with
D_{\mathrm{flip}}(\chi,\widetilde{\chi})\subsetneq D_{\mathrm{flip}}(\chi,\chi^{\prime})
.
∎

.
By

Since we can enumerate all connected vertex sets

Hill-Climbing Algorithm

To obtain not only a single improvement of a given coloring but a
c
-coloring with a total weight of properly colored edges as high as possible, we introduce the following hill-climbing algorithm.

Given an initial coloring
\chi
, we set the initial value of
k
to 1. In each step, we use the above-mentioned algorithm for
LS Max
c
-Cut
to search for an improving coloring in the
k
-flip neighborhood of the current coloring.
Whenever the algorithm finds an improving
k
-neighbor
\chi^{\prime}
for the current coloring
\chi
, the current coloring gets replaced by
\chi^{\prime}
and
k
gets set back to one.
If the current coloring is
k
-optimal, the value of
k
is incremented and the algorithm continues to search for an improvement in the new
k
-flip neighborhood.
This is done until a given time limit is reached.

In our experiments, we also use the following ILP formulation for

.
For each vertex

.

.

x_{u,i}+x_{v,i}+y_{\{u,v\}}
.

maximize

for each vertex

(2)

5
Speedup Strategies

We now introduce several speedup strategies that we use in our implementation to avoid enumerating all candidate sets. First we describe how to speed up the algorithm for
LS Max
c
-Cut
.

5.1
Upper Bounds

To prevent the algorithm from enumerating all possible connected subsets of size at most
k
, we use upper bounds to determine for any given connected subset
S^{\prime}
of size smaller than
k
, if
S^{\prime}
can possibly be extended to a set
S
of size
k
such that there is an improving
c
-coloring
\chi^{\prime}
for
G
where
S
is exactly the set of vertices
\chi
and
\chi^{\prime}
do not agree on.
If there is no such possibility, we prevent our algorithm from enumerating supersets of
S^{\prime}
.
With the next definition we formalize this concept.

Definition 2
.

Let
I:=(G,c,\omega,\chi,k)
be an instance of
LS Max
c
-Cut
and let
S^{\prime}
with
|S^{\prime}|<k
be a subset of vertices of
G
.
A value
b(I,S^{\prime})
is an
upper bound
if for each
c
-coloring
\chi^{\prime}
of
G
, with
S^{\prime}\subsetneq D_{\mathrm{flip}}(\chi,\chi^{\prime})
and
d_{\mathrm{flip}}(\chi,\chi^{\prime})=k
,

\displaystyle b(I,S^{\prime})\geq\omega(E(\chi^{\prime})).

In our implementation, we use upper bounds as follows: Given a set
S^{\prime}
we compute the value
b(I,S^{\prime})
and check if it is not larger than
\omega(E(\chi))
for the current coloring
\chi
. If this is the case, we abort the enumeration of supersets of
S^{\prime}
, otherwise, we continue.

We introduce two upper bounds; one for
c=2
and one for
c\geq 3
.
To describe these upper bounds, we introduce the following notation: Given a vertex
v
and a color
i
, we let
\omega_{v}^{i}:=\omega(\{\{v,w\}\mid w\in N(v),\chi(w)\neq i\})
denote the total weight of properly colored edges incident with
v
if we change the color of
v
to
i
in in the
c
-coloring
\chi
.
Thus, the term
\omega^{i}_{v}-\omega^{\chi(v)}_{v}
describes the improvement obtained by changing only the color of
v
to
i
.
Furthermore, let
\omega_{\max}:=\max_{e\in E}|\omega(e)|
denote the maximum absolute edge weight.

Upper Bound for
c=2
.

Let
I
be an instance of
LS Max
c
-Cut
with
c=2
and let
S^{\prime}
be a vertex set of size less than
k
.
Since
c=2
, we let
\overline{\chi(v)}
denote the unique color distinct from
\chi(v)
for each vertex
v
.
For a vertex set
A\subseteq V
, let
\chi_{A}
denote the coloring where
\chi_{A}(v):=\chi(v)
for all
v\notin A
and
\chi_{A}(v)=\overline{\chi(v)}
, otherwise.
Intuitively,
\chi_{A}
is the coloring resulting from
\chi
when exactly the vertices in
A
change their colors.
For each vertex
v\in V\setminus S^{\prime}
, we define
\alpha_{v}:=\omega^{\overline{\chi(v)}}_{v}-\omega^{\chi(v)}_{v}+\beta_{v}
, where

\displaystyle\beta_{v}:=\sum_{e\in E(v,S^{\prime})\cap E(\chi)}2\cdot\omega(e)-\sum_{e\in E(v,S^{\prime})\setminus E(\chi)}2\cdot\omega(e).

Intuitively,
\alpha_{v}-\beta_{v}
is an upper bound for the improvement obtained when we choose to change only the color of
v
to
\overline{\chi(v)}
.
The term
\beta_{v}
corresponds to the contribution of the edges between
v
and the vertices of
S^{\prime}
.
In the definition of
\beta_{v}
, we take into account the edges between
v
and
S^{\prime}
that are falsely counted twice, once when extending
\chi_{S^{\prime}}
with
v
and a second time in the
term
\omega^{\overline{\chi(v)}}_{v}-\omega^{\chi(v)}_{v}
.
Hence,
\alpha_{v}
is the improvement over the coloring
\chi_{S^{\prime}}
obtained by changing only the color of
v
.
Let
Y\subseteq V\setminus S^{\prime}
be the
k-|S^{\prime}|
vertices from
V\setminus S^{\prime}
with largest
\alpha_{v}
-values.
We define the upper bound by

\displaystyle b_{c=2}(I,S^{\prime}):=\omega(E(\chi_{S^{\prime}}))+\underbrace{\sum_{v\in Y}\alpha_{v}}_{\text{(1)}}+\underbrace{2\binom{k-|S^{\prime}|}{2}\omega_{\max}}_{\text{(2)}}.

Recall that the overall goal is to find a set
X
such that changing the colors of
S^{\prime}\cup X
results in a better coloring.
The summand (1) corresponds to an overestimation of all weights of edges incident with exactly one vertex of
X
by fixing the falsely counted edges between
X
and
S^{\prime}
due to the included
\beta_{v}
summands.
The summand (2) corresponds to an overestimation of the weight of properly colored edges with both endpoints in
X
.
We next show that
b_{c=2}
is in fact an upper bound.

Proposition 1
.

If
c=2
, then
b_{c=2}(I,S^{\prime})
is an upper bound.

Proof.

Let
\chi^{\prime}
be a coloring with
S^{\prime}\subsetneq D_{\mathrm{flip}}(\chi,\chi^{\prime})
and
d_{\mathrm{flip}}(\chi,\chi^{\prime})=k
, and let
X:=D_{\mathrm{flip}}(\chi,\chi^{\prime})\setminus S^{\prime}
.
We show that
\omega(E(\chi^{\prime}))\leq b_{c=2}(I,S^{\prime})
.
To this end, we consider the coloring
\chi_{S^{\prime}}
that results from
\chi
when exactly the vertices in
S^{\prime}
change their colors and analyze how
\omega(E(\chi^{\prime}))
differs from
\omega(E(\chi_{S^{\prime}}))
.

\displaystyle\omega(E(\chi^{\prime}))=~

\displaystyle\omega(E(\chi_{S^{\prime}}))+\underbrace{\sum_{v\in X}(\omega^{\overline{\chi(v)}}_{v}-\omega^{\chi(v)}_{v})}_{\text{(1)}}

\displaystyle+\underbrace{\sum_{\begin{subarray}{c}e\in E(X,S^{\prime})\\
e\in E(\chi)\end{subarray}}2\cdot\omega(e)-\sum_{\begin{subarray}{c}e\in E(X,S^{\prime})\\
e\not\in E(\chi)\end{subarray}}2\cdot\omega(e)}_{\text{(2)}}

\displaystyle+\underbrace{\sum_{\begin{subarray}{c}e\in E(X)\\
e\in E(\chi)\end{subarray}}2\cdot\omega(e)-\sum_{\begin{subarray}{c}e\in E(X)\\
e\not\in E(\chi)\end{subarray}}2\cdot\omega(e)}_{\text{(3)}}

By adding (1) to
\omega(E(\chi_{S^{\prime}}))
, we added the weight of all properly colored edges if only
v
changes its color for every vertex
v\in X
.
The difference between
\omega(E(\chi^{\prime}))
and
\omega(E(\chi_{S^{\prime}}))+\text{(1)}
then consists of all edge-weights that were falsely counted in (1) since both endpoints were moved.
To compensate this, the summand (2) and (3) need to be added.
Summand (2) corresponds to falsely counted edges with one endpoint in
X
and one endpoint in
S^{\prime}
, while (3) corresponds to falsely counted edges with both endpoints in
X
.
Observe that every falsely counted edge weight was counted for both of its endpoints within
\omega(E(\chi_{S^{\prime}}))+\text{(1)}
. Thus, each edge weight in (2) and (3) needs to be multiplied by
2
.

Note that (3) is upper bounded by
2\cdot\binom{k-|S^{\prime}|}{2}\cdot\omega_{\max}
.
Furthermore, note that
\text{(1)}+\text{(2)}=\sum_{v\in X}\alpha_{v}
.
Recall that
Y
consists of the
k-|S^{\prime}|
vertices from
V\setminus S^{\prime}
with largest
\alpha_{v}
-values.
Hence,
\text{(1)}+\text{(2)}\leq\sum_{v\in Y}\alpha_{v}
.
This implies that
\omega(E(\chi^{\prime}))\leq b_{c=2}(I,S^{\prime})
.
Consequently,
b_{c=2}(I,S^{\prime})
is an upper bound.
∎

Upper Bound for
c\geq 3
.

We next present an upper bound
b_{c\geq 3}
that works for the case where
c\geq 3
. Recall that the upper bound
b_{c=2}
relies on computing
\omega(E(\chi_{S^{\prime}}))
, where
\chi_{S^{\prime}}
is the coloring resulting from
\chi
when exactly the vertices in
S^{\prime}
change their colors.
This was possible since for
c=2
, there is only one coloring for which the flip with
\chi
is exactly
S^{\prime}
.
In case of
c\geq 3
, each vertex in
S^{\prime}
has
c-1\geq 2
options to change its color.
Our upper bound
b_{c\geq 3}
consequently contains a summand
b(S^{\prime})
that overestimates the edge weights when only the vertices in
S^{\prime}
change their colors.

To specify
b(S^{\prime})
, we introduce the following notation:
Given a vertex
v\in S^{\prime}
and a color
i
, we let

\theta^{i}_{v}:=\omega(\{\{v,w\}\mid w\in N(v)\setminus S^{\prime},\chi(w)\neq i\}).

Analogously to
\omega^{i}_{v}
, the value
\theta^{i}_{v}
describes the weight of properly colored edges when changing the color of
v
to
i
, but excludes all edges inside
S^{\prime}
.
We define the term

\displaystyle b(S^{\prime}):=

\displaystyle~\omega(E(\chi))+\binom{|S^{\prime}|}{2}\cdot\omega_{\max}-\sum_{\begin{subarray}{c}e\in E(S^{\prime})\\
e\in E(\chi)\end{subarray}}\omega(e)

\displaystyle+\sum_{v\in S^{\prime}}\left(\max_{i\neq\chi(v)}\theta^{i}_{v}-\theta^{\chi(v)}_{v}\right).

As mentioned above, for
b_{c\geq 3}
the summand
b(S^{\prime})
replaces the summand
\omega(E(\chi_{S^{\prime}}))
which was used for
b_{c=2}
. Intuitively, the sum
\sum_{v\in S^{\prime}}(\max_{i\neq\chi(v)}\theta^{i}_{v}-\theta^{\chi(v)}_{v})
is an overestimation of the improvement for properly colored edges with exactly one endpoint in
S^{\prime}
, the term
\binom{|S^{\prime}|}{2}\cdot\omega_{\max}
overestimates the properly colored edges inside
S^{\prime}
, and the remaining terms overestimate the properly colored edges outside
S^{\prime}
.

Analogously to
b_{c=2}
, for each vertex
v\in V\setminus S^{\prime}
, we define a value
\alpha_{v}:=\max_{i\neq\chi(v)}(\omega^{i}_{v}-\omega^{\chi(v)}_{v})+\beta_{v}
with

\beta_{v}:=\sum_{e\in E(v,S^{\prime})}2\cdot|\omega(e)|.

Again, let
Y\subseteq V\setminus S^{\prime}
be the
k-|S^{\prime}|
vertices with biggest
\alpha_{v}
-values of
V\setminus S^{\prime}
.
We define the upper bound by

\displaystyle b_{c\geq 3}(I,S^{\prime}):=b(S^{\prime})+\sum_{v\in Y}\alpha_{v}+2\binom{k-|S^{\prime}|}{2}\cdot\omega_{\max}

and show that it is in fact an upper bound.

Proposition 2
.

If
c\geq 3
, then
b_{c\geq 3}(I,S^{\prime})
is an upper bound.

Proof.

Let
\chi^{\prime}
be a coloring with
S^{\prime}\subsetneq D_{\mathrm{flip}}(\chi,\chi^{\prime})
and
d_{\mathrm{flip}}(\chi,\chi^{\prime})=k
, and let
X:=D_{\mathrm{flip}}(\chi,\chi^{\prime})\setminus S^{\prime}
.
We show that
\omega(E(\chi^{\prime}))\leq b_{c\geq 3}(I,S^{\prime})
.
To this end, let
\chi_{S^{\prime}}
denote the coloring that agrees with
\chi
on all vertices of
V\setminus S^{\prime}
and that agrees with
\chi^{\prime}
on all vertices of
S^{\prime}
.
To show
\omega(E(\chi^{\prime}))\leq b_{c\geq 3}(I,S^{\prime})
we analyze how
\omega(E(\chi^{\prime}))
differs from
\omega(E(\chi_{S^{\prime}}))
.

\displaystyle\omega(E(\chi^{\prime}))\leq~

\displaystyle\omega(E(\chi_{S^{\prime}}))+\underbrace{\sum_{v\in X}(\omega^{\chi^{\prime}(v)}_{v}-\omega^{\chi(v)}_{v})}_{\text{(1)}}

\displaystyle+\underbrace{\sum_{\begin{subarray}{c}e\in E(S^{\prime},~X)\end{subarray}}2\cdot|\omega(e)|}_{\text{(2)}}+\underbrace{\sum_{\begin{subarray}{c}e\in E(X)\end{subarray}}2\cdot|\omega(e)|}_{\text{(3)}}

By adding (1) to
\omega(E(\chi_{S^{\prime}}))
, we added the weight of all properly colored edges if only
v
changes its color for every vertex
v\in X
. The difference between
\omega(E(\chi^{\prime}))
and
\omega(E(\chi_{S^{\prime}}))+\text{(1)}
then consists of all edge-weights that were falsely counted in (1) since both endpoints were moved.
To compensate this, the summand (2) and (3) were added.
Summand (2) overestimates the weight of falsely counted edges with one endpoint in
X
and one endpoint in
S^{\prime}
, while (3) overestimates the weight of falsely counted edges with both endpoints in
X
. Observe that every falsely counted edge weight may be counted for both of its endpoints within
\omega(E(\chi|_{S^{\prime}}))+\text{(1)}
.
Thus, each edge weight in (2) and (3) needs to be multiplied by
2
.

Note that
\text{(1)}+\text{(2)}\leq\sum_{v\in X}\alpha_{v}\leq\sum_{v\in Y}\alpha_{v}
and that
\text{(3)}\leq 2\binom{k-|S^{\prime}|}{2}\cdot\omega_{\max}
. Therefore, it remains to show that
\omega(E(\chi_{S^{\prime}}))\leq b(S^{\prime})
.
To this end, note that
\omega(E(\chi_{S^{\prime}}))
can be expressed by the sum of
\omega(E(\chi))
, improvement of the weight of properly colored edges inside
S^{\prime}
between
\chi
and
\chi_{S^{\prime}}
, and
\sum_{v\in S^{\prime}}(\theta^{\chi^{\prime}(v)}_{v}-\theta^{\chi(v)}_{v})
:

\displaystyle\omega(E(\chi_{S^{\prime}}))=~

\displaystyle\omega(E(\chi))+\sum_{\begin{subarray}{c}e\in E(S^{\prime})\\
e\in E(\chi_{S^{\prime}})\end{subarray}}\omega(e)-\sum_{\begin{subarray}{c}e\in E(S^{\prime})\\
e\in E(\chi)\end{subarray}}\omega(e)

\displaystyle+\sum_{v\in S^{\prime}}(\theta^{\chi^{\prime}(v)}_{v}-\theta^{\chi(v)}_{v}).

Since
\binom{|S^{\prime}|}{2}\cdot\omega_{\max}
is at least as big as the sum of the weights of properly edges inside
S^{\prime}
under
\chi_{S^{\prime}}
, we conclude
\omega(E(\chi_{S^{\prime}}))\leq b(S^{\prime})
.
Hence,
b_{c\geq 3}
is an upper bound.
∎

5.2
Prevention of Redundant Flips

We introduce further speed-up techniques that we used in our implementation of the hill-climbing algorithm. Roughly speaking, the idea behind these speed-up techniques is to exclude vertices that are not contained in an improving flip
D_{\mathrm{flip}}(\chi,\chi^{\prime})
of any
k
-neighbor
\chi^{\prime}
of
\chi
. To this end, we introduce for each considered value of
k
an
auxiliary vertex set

V_{k}
containing all remaining vertices that are potentially part of an improving flip of a
k
-neighbor of
\chi
.
For each value of
k
, the set
V_{k}
is initialized once with
V
, when we search for the first time for an improving
k
-neighbor.

It is easy to see that all vertices
x
that are
(i,k)
-blocked for all
i\neq\chi(x)
can be removed from
V_{k}
if each edge of
G
has weight 1.
This also holds for general instances when considering an extension of the definition of
(i,k)
-blocked vertices for arbitrary weight functions.
Moreover, whenever our algorithm has verified that a vertex
v
is in no improving
k
-flip
D_{\mathrm{flip}}(\chi,\chi^{\prime})
, then we may remove
v
from
V_{k}
.

Recall that we set the initial value of
k
to one and increment
k
if the current coloring
\chi
is
k
-optimal.
If at any time our algorithm replaces the current coloring
\chi
by a better coloring
\chi^{\prime}
, we set
k
back to one and continue by searching for an improving
k
-neighbor of the new coloring
\chi^{\prime}
, where
k
again is incremented if necessary.
Now, for each value of
k^{\prime}
that was already considered for a previous coloring, we only consider the remaining vertices of
V_{k^{\prime}}
together with vertices that have a small distance to the flip between
\chi^{\prime}
and the last previously encountered
(k^{\prime}-1)
-optimal coloring.
This idea is formalized by the next lemma.

Lemma 4
.

Let
G=(V,E)
be a graph, let
\omega:E\to\mathds{Q}
be an edge-weight function, and let
k
be an integer.
Moreover, let
\chi
and
\chi^{\prime}
be
(k-1)
-optimal
c
-colorings of
G
and let
v
be a vertex within distance at least
k+1
to each vertex of
D_{\mathrm{flip}}(\chi,\chi^{\prime})
.
If there is no improving
k
-neighbor
\widehat{\chi}
of
\chi
with
v\in D_{\mathrm{flip}}(\chi,\widehat{\chi})
, then there is no improving
k
-neighbor
\widetilde{\chi}
of
\chi^{\prime}
with
v\in D_{\mathrm{flip}}(\chi^{\prime},\widetilde{\chi})
.

Proof.

We prove the lemma by contraposition. Let
\widetilde{\chi}
be an improving
k
-neighbor of
\chi^{\prime}
with
v\in D_{\mathrm{flip}}(\chi^{\prime},\widetilde{\chi})
. We show that there is an improving
k
-neighbor
\widehat{\chi}
of
\chi
with
v\in D_{\mathrm{flip}}(\chi,\widehat{\chi})
.

The
c
-coloring
\widehat{\chi}
agrees with
\widetilde{\chi}
on all vertices of
D_{\mathrm{flip}}(\chi^{\prime},\widetilde{\chi})
and agrees with
\chi
on all other vertices of
V
.
Hence,
D_{\mathrm{flip}}(\chi,\widehat{\chi})
contains the vertex
v
.
Moreover,
\widehat{\chi}
and
\chi
disagree on at most
d_{\mathrm{flip}}(\chi^{\prime},\widetilde{\chi})\leq k
positions which implies that
\widehat{\chi}
is a
k
-neighbor of
\chi
.
It remains to show that
\widehat{\chi}
improves over
\chi
.
To this end, we analyze the edge set
X\subseteq E
of all edges with at least one endpoint in
D_{\mathrm{flip}}(\chi^{\prime},\widetilde{\chi})
.
Consider the following claim about properly colored edges.

Claim 3
.

It holds that

a)

E(\widetilde{\chi})\setminus X=E(\chi^{\prime})\setminus X
and
E(\widehat{\chi})\setminus X=E(\chi)\setminus X
,

b)

E(\widetilde{\chi})\cap X=E(\widehat{\chi})\cap X
and
E(\chi)\cap X=E(\chi^{\prime})\cap X
.

Proof.

a)

Let
e
be an edge of
E\setminus X
.
Note that both endpoints of
e
are elements of
V\setminus D_{\mathrm{flip}}(\chi^{\prime},\widetilde{\chi})
.
Thus, the endpoints of
e
have distinct colors under
\widetilde{\chi}
if and only if they have distinct colors under
\chi^{\prime}
.
Consequently,
E(\widetilde{\chi})\setminus X=E(\chi^{\prime})\setminus X
.
Furthermore, by definition of
\widehat{\chi}
,
D_{\mathrm{flip}}(\chi,\widehat{\chi})=D_{\mathrm{flip}}(\chi^{\prime},\widetilde{\chi})
, which implies that
E(\widehat{\chi})\setminus X=E(\chi)\setminus X
.

b)

Since
\chi^{\prime}
is
(k-1)
-optimal and
\widetilde{\chi}
is an improving
k
-neighbor of
\chi^{\prime}
, the set
D_{\mathrm{flip}}(\chi^{\prime},\widetilde{\chi})
contains exactly
k
vertices.
Thus, we may assume by Lemma
3
that
D_{\mathrm{flip}}(\chi^{\prime},\widetilde{\chi})
is connected.
Consequently, each vertex of
D_{\mathrm{flip}}(\chi^{\prime},\widetilde{\chi})
has distance at most
k-1
from
v
, since
v
is contained in
D_{\mathrm{flip}}(\chi^{\prime},\widetilde{\chi})
.

Let
e
be an edge of
X
.
Since each vertex of
D_{\mathrm{flip}}(\chi^{\prime},\widetilde{\chi})
has distance at most
k-1
from
v
, both endpoints of
e
have distance at most
k
from
v
.
Together with the fact that
v
has distance at least
k+1
from
D_{\mathrm{flip}}(\chi,\chi^{\prime})
, this implies that no endpoint of
e
is contained in
D_{\mathrm{flip}}(\chi,\chi^{\prime})
.
Hence,
\chi
and
\chi^{\prime}
agree on both endpoints of
e
.
Consequently, the edge
e
is properly colored under
\chi
if and only if
e
is properly colored under
\chi^{\prime}
.
This then implies that
E(\chi)\cap X=E(\chi^{\prime})\cap X
.

By the definition of
\widehat{\chi}
and the fact that
\chi
and
\chi^{\prime}
agree on the endpoints of each edge of
X
,
\widehat{\chi}
and
\widetilde{\chi}
agree on the endpoints of each edge of
X
.
This then implies that
E(\widetilde{\chi})\cap X=E(\widehat{\chi})\cap X
.
\hfill\diamond

\blacksquare

We next use
Claim

3
to show that
\widehat{\chi}
is an improving neighbor of
\chi
.
Since
\widetilde{\chi}
is an improving neighbor of
\chi^{\prime}
we have
\omega(E(\widetilde{\chi}))>\omega(E(\chi^{\prime}))
, which implies

\displaystyle\omega(E(\widetilde{\chi})\cap X)+\omega(E(\widetilde{\chi})\setminus X)>\omega(E(\chi^{\prime})\cap X)+\omega(E(\chi^{\prime})\setminus X).

Together with
Claim

3

a)
, we then have

\displaystyle\omega(E(\widetilde{\chi})\cap X)>\omega(E(\chi^{\prime})\cap X).

Moreover, due to
Claim

3

b)
, we have

\displaystyle\omega(E(\widehat{\chi})\cap X)>\omega(E(\chi)\cap X).

Finally, since
E(\widehat{\chi})\setminus X=E(\chi)\setminus X
by
Claim

3

a)
, we may add the weights of all edges in
E(\widehat{\chi})\setminus X
to the left side of the inequality and the weight of all edges in
E(\chi)\setminus X
to the right side.
We end up with the inequality
\omega(E(\widehat{\chi}))>\omega(E(\chi))
which implies that
\widehat{\chi}
is an improving
k
-neighbor of
\chi
.
∎

We next describe how we exploit
Lemma

4
in our implementation:
We start with a coloring
\chi
and search for improving
k
-neighbors of
\chi
for increasing values of
k
starting with
k=1
.
Whenever we find an improving neighbor
\chi^{\prime}
of
\chi
we continue by searching for an improving neighbor
\chi^{\prime\prime}
of
\chi^{\prime}
starting with
k=1
again.
We use
Lemma

4
as follows: if we want to find an improving
k
-neighbor for a
(k-1)
-optimal coloring
\chi^{\prime}
, we take the last previously encountered
(k-1)
-optimal coloring
\chi
and add only the vertices to
V_{k}
that have distance at most
k
from
D_{\mathrm{flip}}(\chi,\chi^{\prime})
, instead of setting
V_{k}
back to
V
.
This is correct since every vertex which is not in
V_{k}
, is not part of any improving
k
-flip of
\chi
and therefore according to
Lemma

4
, the only vertices outside of
V_{k}
that can possibly be in an improving
k
-flip of
\chi^{\prime}
are those with distance at most
k
from
D_{\mathrm{flip}}(\chi,\chi^{\prime})
.

Next, we provide a further technique to identify vertices that can be removed from
V_{k}
. The idea behind this technique can be explained as follows: if a vertex can be excluded from
V_{k}
, then all equivalent vertices can also be excluded, where equivalence is defined as follows.

Definition 3
.

Let
G=(V,E)
be a graph, let
\omega:E\to\mathds{Q}
be an edge-weight function.
Two vertices
v
and
w
of
G
are
weighted twins
if
N(v)\setminus\{w\}=N(w)\setminus\{v\}
and
\omega(\{v,x\})=\omega(\{w,x\})
for each
x\in N(v)\setminus\{w\}
.

Lemma 5
.

Let
G=(V,E)
be a graph, let
\omega:E\to\mathds{Q}
be an edge-weight function, and let
k
be an integer.
Moreover, let
\chi
be a
c
-coloring of
G
and let
v
and
w
be weighted twins in
G
with
\chi(v)=\chi(w)
.
If there is no improving
k
-neighbor
\chi^{\prime}
of
\chi
with
v\in D_{\mathrm{flip}}(\chi,\chi^{\prime})
, then there is no improving
k
-neighbor
\widetilde{\chi}
of
\chi
with
w\in D_{\mathrm{flip}}(\chi,\widetilde{\chi})
.

Proof.

Assume towards a contradiction that there is an improving
k
-neighbor
\widetilde{\chi}
of
\chi
with
w\in D_{\mathrm{flip}}(\chi,\widetilde{\chi})
.
By assumption,
v\notin D_{\mathrm{flip}}(\chi,\widetilde{\chi})
.
Let
\chi^{\prime}
be the
c
-coloring that agrees with
\widetilde{\chi}
on
V\setminus\{v,w\}
and where
\chi^{\prime}(v):=\widetilde{\chi}(w)
and
\chi^{\prime}(w):=\widetilde{\chi}(v)=\chi(v)
.
Recall that
\omega(\{v,x\})=\omega(\{w,x\})
for each
x\in N(v)\cap N(w)
and that
N(v)\setminus\{w\}=N(w)\setminus\{v\}
.
For each
x\in N(v)\cap N(w)
, let
E_{x}:=\{\{v,x\},\{w,x\}\}
.
Note that since
\widetilde{\chi}(v)\neq\widetilde{\chi}(w)
, at least one edge of
E_{x}
is contained in
E(\widetilde{\chi})
.
If both edges of
E_{x}
are contained in
E(\widetilde{\chi})
, then
\chi^{\prime}(x)=\widetilde{\chi}(x)\not\in\{\chi^{\prime}(v),\chi^{\prime}(w)\}
and thus both edges of
E_{x}
are contained in
E(\chi^{\prime})
.
If only one edge of
E_{x}
is contained in
E(\widetilde{\chi})
, then
E(\chi^{\prime})
contains exactly the other edge of
E_{x}
since
\chi^{\prime}(v)=\widetilde{\chi}(w)
,
\chi^{\prime}(w)=\widetilde{\chi}(v)
, and
\chi^{\prime}(x)=\widetilde{\chi}(x)
.
Since the weight of both edges of
E_{x}
are the same for each
x\in N(v)\cap N(w)
, we have
\omega(E(\chi^{\prime}))=\omega(E(\widetilde{\chi}))
.
Hence,
\chi^{\prime}
is an improving
k
-neighbor of
\chi
with
v\in D_{\mathrm{flip}}(\chi,\chi^{\prime})
, a contradiction.
∎

Consequently, when our algorithm removes a vertex
v
from
V_{k}
for some
k
because no improving
k
-neighbor
\chi^{\prime}
of
\chi
contains
v
, then it also removes all weighted twins of
v
with the same color as
v
from
V_{k}
.

For one graph (g23) and each

, there is a large gap between the value of the published coloring and the stated value of the corresponding coloring (for example, for

To not exploit this gap in our evaluation, we only considered the remaining 70 graphs. These 70 graphs are of two types: 34 graphs are unit graphs (where each edge has weight 1) and 36 graphs are signed graphs (where each edge has either weight 1 or -1). For each of these graphs, we ran experiments for each
c\in\{2,3,4\}
with a time limit of 30 minutes and the published MOH solution as initial solution.
In addition to LS, for each instance we ran standard ILP-formulations for
Max
c
-Cut
(again for 30 minutes) using the Gurobi solver version 9.5, once without starting solution and once with the MOH solution as starting solution. Each run of an ILP provides both a best found solution and an upper bound on the maximum value of any
c
-coloring for the given instance.
Each experiment was performed on a single thread of an Intel(R) Xeon(R) Silver 4116 CPU with 2.1 GHz, 24 CPUs and 128 GB RAM.

The ILP upper bounds verified the optimality of 22 MOH solutions. Thus, of the 210 instances, only 188 instances are interesting in the sense that LS or the ILP can find an improved solution. The upper bounds also verified the optimality of 8 further improved solutions found by LS or ILP.

In total, the ILP found better colorings than the MOH coloring for 43 of the 188 instances.
In comparison, our hill-climbing algorithm was able to improve on the MOH solutions for 69 instances of the 188 instances.

The MOH solutions were obtained within a time limit of 30, 120, and 240 minutes for small, medium, and large instances, respectively.

We summarize our main experimental findings as follows.
First, parameterized local search can be used successfully as a post-processing for state-of-the-art heuristics for
Max

, in many cases leading to new record solutions for

k

Conclusion

In this work we analyzed
LS Max
c
-Cut
from both a theoretical and practical point of view.
Form a negative point of view, we showed that both the strict and the permissive version of
LS Max
c
-Cut
cannot be solved in
f(k)\cdot n^{o(k)}
time for any computable function
f
, unless the ETH fails.
From a positive point of view, we presented an algorithm that solves these problems in
\Delta^{\mathcal{O}(k)}\cdot n^{\mathcal{O}(1)}
time.
Moreover, we implemented this algorithm and evaluated its performance as a post-processing for a state-of-the-art heuristic for
Max
c
-Cut
.
Our experimental findings indicate that parameterized local search might be a promising technique in the design of local search algorithms and that its usefulness should be explored for further hard problems, in particular as post-processing for state-of-the-art heuristics to improve already good solutions.

Open questions.

Our results in this work leave several questions open and give raise to new research directions.
From a practical point of view, it would be interesting to consider a combined implementation of the MoH algorithm with our hill-climbing algorithm based on the
k
-flip neighborhood.
In such a combined implementation, one could for example consider two different time limits
t_{1}
and
t_{2}
:
First, until time limit
t_{1}
is reached, we let the MoH-algorithm run.
Afterwards, we take the best found solution by MoH as starting solution for our hill-climbing algorithm which we then run until time limit
t_{2}
is reached.
It would be interesting to analyze the final solution quality with respect to these two time limits.
In other words, it would be interesting to analyze when switching from MoH to our hill-climbing algorithm is promising.
Such an approach could also be considered with respect to combinations of other state-of-the-art heuristics for
Max
c
-Cut
.
For example for
c=2
, that is, for
Max Cut
, one could consider analyzing the usefulness of our hill-climbing algorithm as a post-processing algorithm for algorithms like TS-UBQP
[
27
]
or TSHEA
[
45
]
.

Regarding the practical evaluation of parameterized local search algorithms, we believe that some of the techniques introduced in this chapter might find successful applications also for other problems.
In particular, the technique we introduced to prevent redundantly checking candidates (see
Lemma

4
) seems promising:
We can ignore candidates that contain a vertex
v
for which no vertex of distance
\mathcal{O}(k)
has changed since the last time we verified that
v
is not contained in any improving candidate.
This technique was already successfully adapted in a local search solver for
Weighted Vertex Cover

[
40
]
and we believe that it might find successful application for local search versions of problems like
Max SAT

[
39
]
or
Hitting Set
.

From a theoretical point of view, one could ask for a smaller parameter in the basis of the worst-case running time.
For example, one may ask whether we can replace the maximum degree in the basis by the
h
-index of the input graph, that is, if we can solve
Max
c
-Cut
in
h^{\mathcal{O}(k)}\cdot n^{\mathcal{O}(1)}
time.
In the aim of developing an algorithm with such a running time, one could for example branch into all possible ways to flip up to
k
high-degree vertices.
For each such branch, one then needs to find a coloring that improves over the initial coloring that only flips low-degree vertices.
This would then necessitate solving a gap-version of
Max
c
-Cut
similar to the one introduced by Komusiewicz and Morawietz
[
29
]
for the local search version of
Vertex Cover
.

Based on the
\mathrm{W}[1]
-hardness results for
LS Min Bisection
and
LS Max Bisection
with respect to the search radius
k
, one might also consider revisiting the parameterized complexity of these problems with respect to
k
plus some additional parameter
\ell
.
So far, the only known algorithm for
LS Min Bisection
and
LS Max Bisection
run in FPT-time with respect to
k
on graphs on bounded local treewidth
[
9
]
.
These algorithms imply that
LS Min Bisection
and
LS Max Bisection
can be solved in
2^{\Delta^{\mathcal{O}(k)}}\cdot n^{\mathcal{O}(1)}
time, but the existence of algorithms for these problems that run in
\Delta^{\mathcal{O}(k)}\cdot n^{\mathcal{O}(1)}
time are open.
Based on the restriction that each part of the partition is equally-sized in any solution of these problems, one might need to consider candidates to flip that are not connected in the input graph to achieve a better solution.
