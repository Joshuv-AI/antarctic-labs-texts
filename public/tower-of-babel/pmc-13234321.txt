TAGNN: topology-aware graph neural network framework for link prediction
Authors: Minsi Liang, Honggang Zhang
Published: 2026

ABSTRACT
Link prediction is a fundamental task in graph machine learning. While Graph Neural Network (GNN)-based methods are mainstream, they exhibit limitations: restricted receptive fields hinder their ability to capture long-range structural information between target node pairs; the node-centric paradigm may lead to information loss as it mismatches the nature of link-centric tasks; and neighborhood node features may introduce task-irrelevant noise in link prediction scenarios, which has been less addressed by existing improvements built on the inherent GNN message-passing paradigm. We propose a Topology-Aware Graph Neural Network (TAGNN) framework for link prediction, achieving breakthroughs from two key perspectives. First, during the GNN neighborhood structure encoding stage, we innovatively propose to discard neighborhood node attributes that may introduce interference in the link-centric task, retaining only topological information encoded via Double-Radius Node Labeling (DRNL) for neighborhood structure encoding. DRNL transforms topological relationships into learnable structural features by computing distances between nodes within the subgraph and the target nodes, enabling the model to focus more precisely on fitting neighborhood topology and avoiding interference from irrelevant features. Second, we design a Reinforced Structural Transformer (RST) module, with its core being the Reinforced Structural Attention (RSA) mechanism. RSA first extracts structural correlation features of target node pairs using topological heuristics like shortest path distance, Adamic-Adar index, and Jaccard coefficient. These features are then fused with node features to form a structural encoding that directly models pairwise relationships, compensating for GNN’s deficiency in long-range structural perception. Crucially, RST confines attention computation strictly to the target node pair rather than all nodes, simultaneously avoiding noise from non-target nodes and reducing the computational complexity from quadratic (as in a standard Transformer) to linear, significantly boosting efficiency. Experiments on six datasets (three from OGB and three classic attributed graphs) demonstrate the outstanding performance of TAGNN, achieving top rankings on ogbl-ppa, ogbl-citation2, and Pubmed. The variant without neighborhood features performs even better. Ablation studies confirm the contribution of RST, and TAGNN shows a 10–16 × computational efficiency gain over a fully-connected Transformer baseline.

Introduction

Link prediction is a fundamental and core task in the field of graph machine learning, whose primary goal is to accurately infer missing or potential edges based on the existing node and edge information in a graph. This task plays a crucial role in numerous practical scenarios, covering multiple domains such as knowledge graph completion1, intelligent recommendation systems2, and social network relationship mining3. For instance, in knowledge graphs, it can complete key attribute information such as missing colleague relationships and places of birth for individuals; in e-commerce recommendation systems, it can predict users’ interest preferences for specific commodities based on the historical interaction graphs between users and commodities, thereby achieving personalized recommendations.

Among the numerous solutions for link prediction, methods based on Graph Neural Networks (GNNs)4 have gradually become the mainstream technical route due to their excellent performance and efficient processing capabilities. GNN series models5–7 take nodes as the core and aggregate the node and edge features within the neighborhood of the central node to the central node through the message-passing mechanism, thus efficiently learning node representations. In link prediction tasks, such methods usually adopt the Graph Autoencoder (GAE) framework8: (i) first, encode individual nodes via GNNs to obtain node representations, (ii) then aggregate and decode the representations of target node pairs, (iii) and finally obtain the probability of the existence of a link.

However, this node-centered encoding approach has significant limitations in link prediction tasks, as it is highly prone to missing key structural features required for link prediction. We take the simple scenario in Fig. 1a as an example: nodes h1 and h2 are isomorphic nodes. If node features are removed, GNNs will learn identical node representations, which in turn leads to identical link representations for the node pairs (h1, t) and (h2, t). In reality, node h2 and t share a common neighbor, so theoretically the probability of a link between them should be significantly higher than that between h1 and t. This contradiction clearly shows that the GAE framework overfocuses on the neighborhood information of individual nodes during the encoding phase, while ignoring the structural correlations between target node pairs. As a result, it fails to meet the core requirements of link prediction.

To address this issue, recent studies have attempted to optimize models using node labeling strategies. For example, ID-GNN9 assigns a unique label to the target node to distinguish it from ordinary neighborhood nodes. SEAL (Subgraphs, Embeddings, and Attributes for Link prediction)10 employs a node positional encoding strategy (Double-Radius Node Labeling, DRNL) that computes the shortest path distances from nodes to the target node pair, assigning unique labels to nodes within the subgraph to distinguish their structural roles. However, these methods only enable the model to perceive the depth information of paths, and lack the ability to effectively capture features related to path “width” (such as node degree, number of paths, etc.). More critically, these approaches still rely on the message-passing paradigm of GNNs, leading to two core flaws in information perception and transmission for link prediction: (i) the information aggregation process requires first converging label information to the target node and then converting it into relationship representations. This process is obscure and cumbersome, making it highly prone to information loss; (ii) GNNs have a limited receptive field, so they struggle to effectively capture long-range structural information between distant target node pairs, which are common in link prediction tasks.

As shown in the examples on the right side of Fig. 1, even ID-GNN9 or SEAL10 models using 3-layer GNNs cannot distinguish between the two different link structures in Fig. 1b and c. The numbers above the nodes are represented by DRNL, and the coloring of the target node t indicates the labels assigned by ID-GNN. When computing the representation of the head node h, the computation graphs (including node DRNL labels) for both structures are identical (as shown in Fig. 1d), and the label information of the tail node t cannot be effectively aggregated; similarly, the same issue arises when computing the representation of the tail node t. Thus, even with the introduction of labeling strategies, 3-layer GNNs still fail to distinguish these two link structures. If we attempt to expand the receptive field by increasing the number of GNN layers, new model degradation problems such as over-smoothing and over-fitting will occur, leaving us in a dilemma.

From the perspective of the information aggregation mechanism of GNNs, their core advantage lies in extracting rich information from node neighborhoods, which mainly consists of two parts: the topological structure information of the graph and the attribute features of neighboring nodes. However, in graph learning, the necessity of neighborhood information is limited. In link prediction tasks, the attribute features of neighboring nodes are often weakly correlated with the core task of inferring the existence of an edge between a target node pair, and may act as interfering factors in the tested benchmark scenarios, especially when the link formation is mainly driven by topological connectivity rather than node attribute similarity. For example, when predicting whether two people are paper collaborators, the key basis is the topological structure information of "the two having co-authored papers", while attribute features such as the journals or conferences where the papers are published and DOI numbers are not only unhelpful for the judgment but also may increase the risk of the model learning irrelevant patterns.

Based on the above analysis and experimental verification of the limitations of GNNs, we propose a Topology-aware Graph Neural Network (TAGNN) framework for link prediction. The core design of this framework revolves around two key dimensions: (i) first, in the neighborhood information processing stage, GNNs are still adopted as the base model to collect the neighborhood structural information of target nodes, but by removing the attribute features of neighboring nodes, the model is forced to focus its learning on topological structures, thereby avoiding interference from irrelevant features; (ii) second, to address the flaw that GNNs cannot capture long-range structural information, a Reinforced Structural Attention (RSA) mechanism is introduced, which is specifically designed to encode the features of target node pairs (especially the structural correlations between long-distance nodes), forming an effective supplement to the capabilities of GNNs. In particular, RSA addresses the limitations of traditional self-attention in adapting to graph learning tasks. The traditional self-attention is capable of modeling node-pair correlations, it suffers from a lack of topological awareness, high computational complexity, and a tendency to cause the "data-hungry" problem. RSA converts heuristic structural information of node pairs into feature vectors via topological encoding and integrates such structural information into the attention calculation process. Meanwhile, it strictly constrains the scope of computation to only target nodes, thereby avoiding the high overhead of full-graph computation, isolating noise introduced by non-target nodes, and accurately capturing the key local structures for link prediction that are overlooked by GNNs during neighborhood aggregation.

Related work

Existing research on link prediction can be primarily categorized into four major technical paradigms, namely random walk-based methods, shallow knowledge graph embedding methods, path-based methods, and Graph Neural Network (GNN)-based methods. Each paradigm has its own focus in terms of underlying principles and applicable scenarios.Walk-based methods: Such methods take the random walk sequence of a node as its representation carrier and learn node features by mining topological correlations in the walk sequence. Jeyaraj et al.11 propose a DeepWalk algorithm integrated with reinforcement learning (DWRL). By identifying common nodes between each pair of nodes in the original graph, DWRL can reduce the number of dot product operations in the latent space, thereby ensuring second-order structural similarity. DWIM (DeepWalk-based influence maximization)12 integrates users’ topical and topological features via collaborative filtering and constructing a unified graph, and DWIM can identify k influential nodes in social networks within computable time. However, the representational capability of these methods is limited by the walk strategy, and they are difficult to handle link prediction tasks on dynamic graphs.Shallow knowledge graph embedding methods: This category of methods focuses on the triple relationships of head node-edge-tail node. By mapping entities and relationships to a low-dimensional vector space, they use vector operations to characterize the association logic of triples. Yang et al.13 proposed a community-aware information seeking based content recommender (CISCRec). This model enhances user preference modeling and recommendation interpretability through a two-level TransE prediction framework and an interaction-aware embedding enhancement module. To address the core demand for learning representations of entities and relations in knowledge graph link prediction tasks, RotatE14 defines each relation as a rotation operation from the source entity to the target entity in the complex vector space. It can model various relation patterns such as symmetry/anti-symmetry, inversion, and composition, and achieves efficient training by combining the self-developed self-adversarial negative sampling technique. However, such methods lack inductiveness and parameter sharing mechanisms, which limits their applicability in large-scale and scalable graph data scenarios.Path-based methods: This category of methods takes the connected paths between target node pairs as the core and realizes link prediction by mining the association patterns in the paths. It can be further subdivided into three categories: (i) the first is heuristic methods, which are simple in principle, strong in interpretability and inductive, and are often used as structural features to be integrated into other models. For example, Coskun et al.15 proposed the LRC-Katz algorithm, which accelerates Katz index queries through indexing and low-rank correction techniques, and outperforms the mainstream Conjugate Gradient method in various large-scale real-world networks; (ii) the second is rule-based methods, which can automatically learn logical reasoning rules in knowledge graphs. For example, Duan et al.16 proposed a novel multigranularity three-way decision model that integrates multigranularity (from coarse to fine granularity) and three-way decision (i.e., acceptance, rejection, and deferred decision), designed a corresponding algorithm for mining multigranularity decision rules, and accelerated rule mining by leveraging the monotonicity of positive or negative granule spaces; (iii) the third is path representation methods, which encode path sequences to achieve in-depth mining of path features. For example, Kong et al.17 proposed an efficient GNN framework called GDGNN, which requires only a single GNN run. By treating the shortest paths between nodes as spatial graph contexts to generate geodesic representations, and conditioning on these geodesic representations, GDGNN can produce richer node, link, and graph representations. Owing to the characteristics of simple and efficient computational performance of heuristic methods, they have become an important source of structural features in the proposed Reinforced Structural Attention (RSA) module in our TAGNN.GNN-based methods: Benefiting from their excellent performance and efficiency, GNN-based methods have become the mainstream technology for link prediction. Mainstream solutions can be divided into two frameworks: (i) The first is the graph autoencoder framework, where GNNs act as encoders to learn node representations, and then convert node pair representations into link probabilities through decoding functions. For example, Wu et al.18 proposed a model called Transferable Graph Auto-Encoders (TGAE), which generates node latent representations via an attentional mechanism, achieves feature transfer between source and target networks using distribution alignment, preserves graph structures through pairwise and reconstruction constraints; (ii) the second is the subgraph encoding framework, where the model extracts closed subgraphs around target node pairs and directly encodes the subgraphs to complete link prediction. For example, Zhang et al.19 proposed the IGMC (Inductive Graph-based Matrix Completion) model, which only trains a GNN based on the 1-hop subgraphs of (user-item) pairs generated from the rating matrix and maps these subgraphs to their corresponding ratings. However, excellent node-level representations are not equivalent to excellent link-level representations. Therefore, methods such as ID-GNN9 and SEAL10 introduce node labeling strategies to attempt to bridge the gap between node-level and link-level representations. But, these methods are still limited by the message-passing paradigm of GNNs and cannot directly and comprehensively capture the long-range structural information between target node pairs.Graph Transformer: The Transformer architecture20 has achieved groundbreaking success in the fields of natural language processing and computer vision, and its application to graph data has also become a research hotspot. However, adapting the Transformer to graph data faces two core challenges: (i) Structural/positional encoding challenge: The self-attention mechanism does not inherently possess graph structure awareness and cannot distinguish the topological positions of nodes in the graph. To address this problem, the academic community has proposed various encoding schemes. Galron et al.21 established the connection between supra-Laplacian encodings and per-time-slice encodings, and clarified the adaptability of such encodings to different models, tasks and datasets, confirming that they can significantly improve performance in specific scenarios. Ying et al.22 proposed the Graphormer model based on the standard Transformer architecture. By designing efficient graph structural encoding methods to integrate graph structural information into the model, Graphormer achieved excellent performance on a wide range of graph representation learning tasks including the OGB Large-Scale Challenge. For our TAGNN model, in the RSA module, we extend topological encoding by encoding pairwise heuristic features such as shortest path distance and Adamic-Adar index and integrating them into the attention mechanism, thus achieving accurate capture of structural features of target node pairs; (ii) Computational Complexity Challenge: The self-attention mechanism needs to calculate the similarity between all pairs of nodes, with a time complexity of O(N2D) (where N is the number of nodes and D is the feature dimension), making it difficult to implement on large-scale graph data. Existing solutions mostly limit the number of nodes involved in computation through sampling strategies, but such strategies are still node-centric rather than link-centric for link prediction. For example, Dwivedi et al.23 proposed a generalized Transformer architecture for arbitrary graphs, which incorporates four core improvements: neighborhood connectivity-aware attention, positional encoding based on Laplacian eigenvectors, replacement of layer normalization with batch normalization, and extension of edge feature representation. Given the architecture’s simplicity and generality, the research team believes it can serve as a universal black-box tool for future applications that integrate Transformers with graph data. The RSA module in our TAGNN specifically limits the scope of attention computation to target node pairs, which not only avoids the high overhead of global computation but also eliminates noise introduced by irrelevant nodes, achieving a balance between efficiency and effectiveness.Doubts about Neighborhood Nodes: In recent years, some studies have begun to question the effectiveness of neighborhood nodes in GNNs. For instance, Feng et al.24 pointed out that Graph Convolutional Networks (GCNs) assume that graphs are homophilous by default, but graphs in real-world scenarios are never perfect. The local structure of nodes may have discrepancies (e.g., inconsistent labels of neighboring nodes), so it is necessary to take the discrepancy of local structure into account in GCN modeling. Park et al.25 addressed the problem that graph neural networks (GNNs) tend to overfit the neighbor sets of minority classes due to message passing in class-imbalanced node classification tasks, and proposed the GraphENS augmentation method, which synthesizes complete neighborhoods by fusing different minority-class ego networks based on similarity and incorporates a saliency-based node mixing method (which leverages class-generic attributes while blocking the injection of class-specific features). However, few studies have focused on the necessity of neighborhood nodes in link prediction, which is where the contribution of our TAGNN lies.

The RSA module in our TAGNN specifically limits the scope of attention computation to target node pairs, which not only avoids the high overhead of global computation but also eliminates noise introduced by irrelevant nodes, achieving a balance between efficiency and effectiveness.

Doubts about Neighborhood Nodes: In recent years, some studies have begun to question the effectiveness of neighborhood nodes in GNNs. For instance, Feng et al.24 pointed out that Graph Convolutional Networks (GCNs) assume that graphs are homophilous by default, but graphs in real-world scenarios are never perfect. The local structure of nodes may have discrepancies (e.g., inconsistent labels of neighboring nodes), so it is necessary to take the discrepancy of local structure into account in GCN modeling. Park et al.25 addressed the problem that graph neural networks (GNNs) tend to overfit the neighbor sets of minority classes due to message passing in class-imbalanced node classification tasks, and proposed the GraphENS augmentation method, which synthesizes complete neighborhoods by fusing different minority-class ego networks based on similarity and incorporates a saliency-based node mixing method (which leverages class-generic attributes while blocking the injection of class-specific features). However, few studies have focused on the necessity of neighborhood nodes in link prediction, which is where the contribution of our TAGNN lies.

Methodology

Problem definition

In the research scope of graph machine learning, link prediction is a core fundamental task. Its goal is to infer whether there is a missing or potential connection between any two nodes in the graph, based on the existing nodes, edges, and node feature information in the graph.

Definition 1

We formally define the graph under study as G = (V, A, E), where V represents the set of all nodes in the graph, E represents the set of existing edges between nodes, and A is the adjacency matrix of the graph, which characterizes the connection relationships between nodes (if there is an edge between node vi and vj, Aij = 1; otherwise, Aij = 0). Meanwhile, we define the node feature matrix X∈ℝ|V|×D, where |V| is the total number of nodes and D is the dimension of the feature of a single node. This matrix stores the attribute information of each node.

Definition 2

The mathematical objective of the link prediction task can be described as: given graph G and any two nodes vi and vj, learn a prediction function f: V×V →[0, 1], such that the output of f(vi, vj) can accurately reflect the probability of the existence of edge eij between the node pair (vi, vj). The closer the output value is to 1, the higher the possibility that the two nodes have a connection.

Definition 3

We define the standard message passing (MP) mechanism of GNNs, taking the classic Graph Convolutional Network (GCN) as an example. The core formula of GCN’s layer-wise propagation is Eq. (1):

Limitations of the Standard Paradigm for Link Prediction. The receptive field of GCN is limited to the l-hop neighborhood of the node. For target node pairs with long-range structural correlations (e.g., two nodes connected through a 4-hop path), a 3-layer GCN cannot capture their cross-neighborhood structural association. The input H(0) of the first layer of GCN is usually the original node feature matrix X. The fusion of node features and structural information in the propagation process makes it impossible for the model to distinguish which part of the representation comes from topology and which comes from attributes, leading to the model being prone to overfitting to irrelevant attributes.

Overall architecture

To address issues such as insufficient long-range structural information perception and noise introduced by node features in traditional Graph Neural Networks (GNNs) for link prediction tasks, we propose a Topology-Aware Graph Neural Network framework for link prediction (TAGNN). This framework is divided into four closely connected core modules: subgraph sampling, neighborhood structure encoding based on a structure information-enhanced GNN, pairwise structure encoding based on a Reinforced Structure Transformer (RSA), and link decoding. The functions and collaboration logic of each module are shown in Fig. 2: (i) The subgraph sampling module provides accurate local graph structure inputs for subsequent encoding; (ii) the neighborhood structure encoding module uses an improved GNN model to focus on the neighborhood topological structure of target nodes rather than redundant neighbor node features; (iii) the pairwise structure encoding module leverages RSA to compensate for GNNs’ deficiency in long-range structure perception, directly modeling the structural correlation between target node pairs; (iv) finally, the link decoding module fuses the outputs of the previous two encoding modules to complete the final link probability prediction.

Subgraph sampling

In link prediction tasks, subgraph sampling is a critical step for constructing local context for target node pairs. Its core objective is to extract topological and structural information that characterizes the connectivity likelihood of node pairs, providing high-quality input for subsequent encoding modules. To address the limitation that traditional subgraph sampling (e.g., single-node k-hop neighborhood sampling) cannot effectively capture associations between target node pairs, we adopt the k-hop enclosing subgraph sampling strategy26. Given a target node pair (vi, vj), the sampling of a k-hop enclosing subgraph does not simply take the union of the k-hop neighborhood subgraphs of vi and vj. Instead, on the basis of the union, it additionally incorporates cross-domain edges between the two single-node neighborhoods to form a complete local subgraph with stronger connectivity. Specific implementation steps are as follows:Single-node neighborhood initialization: Taking vi and vj as centers respectively, sample their respective k-hop neighborhood subgraphs Gi and Gj. Among them, the 1-hop neighborhood includes the directly adjacent nodes of the central node and corresponding edges, the 2-hop neighborhood includes the directly adjacent nodes of 1-hop neighborhood nodes and corresponding edges, and so on up to k-hop.Cross-domain edge integration: Traverse all edges in the graph. If one endpoint of an edge belongs to Gi and the other belongs to Gj (and the edge is not included in Gi or Gj), it will be incorporated into the final enclosing subgraph. For example, in a 1-hop enclosing subgraph, even if the 1-hop neighborhoods of the target node pair (h, t) originally have no direct intersection, if there is an edge e1,5 connecting node 1 (in h's 1-hop neighborhood) and node 5 (in t's 1-hop neighborhood), this edge will also be added to the subgraph (as shown in Fig. 2).Subgraph structure regularization: Deduplicate and reconstruct the index of the integrated nodes and edges to generate a local enclosing subgraph Genclose(vi, vj, k) centered on the target node pair. The setting of the k value (number of hops) needs to balance information completeness and computational complexity: (i) When k is too small (e.g., k=1), the subgraph cannot capture the multi-order neighborhood associations of the target node pair, resulting in the loss of key long-range structural information; (ii) When k is too large (e.g., k>3), the subgraph will introduce a large number of redundant nodes and edges, which not only increases computational costs but may also introduce irrelevant noise, reducing the efficiency of subsequent encoding modules; (iii) In the experiments of this paper, after comprehensive verification on multiple datasets, k=2 is finally selected as the default number of hops. This parameter can not only cover the core associated structures of the target node pair but also control the subgraph scale within a reasonable range.

Neighborhood structure encoding

Neighborhood structure encoding is a core component of the TAGNN, which aims to extract and model the local topological structures around target node pairs through a modified Graph Neural Network (GNN). Unlike traditional GNNs that fuse both neighbor node features and structural information, this module discards task-irrelevant neighbor node features and focuses solely on structural cues, ensuring that the learned node representations are more aligned with the demands of link prediction tasks. This section elaborates on the encoding paradigm, core formulas, and optimization strategies in detail.

Link prediction is essentially a link-centric task, which requires capturing the relational patterns between target nodes rather than the attribute characteristics of individual nodes or their neighbors. Traditional GNNs aggregate both structural topology and neighbor node features during message passing, which introduces two critical issues: (i) neighbor node features are often irrelevant to the link relationship between target nodes, and may even introduce redundant information that misleads the model; (ii) the aggregation mechanism of standard GNNs is designed for node-level tasks (e.g., node classification), and cannot directly model the structural correlation between target node pairs.

To address these issues, the neighborhood structure encoding module of TAGNN makes two key adjustments: (i) we remove neighbor node features, and only retain structural information (encoded by node topological labels) as the input of GNN; (ii) we supplement the target node’s own features through a dedicated feed-forward network (FFN), and fuse them with the structural representation learned by GNN to preserve the unique attribute information of the target node while focusing on structural patterns.

Pairwise structure encoding

As we analyzed in the above sections, even with labeling tricks, the GNN framework has two limitations for link prediction: the absence of long-range structural information due to restricted receptive fields and the conflict between node-centric models and link-centric tasks. To address these shortcomings, we propose the RST to capture pairwise structures and feature similarities between target nodes exclusively, representing relations directly and supplementing the limitations of GNNs.

The core of RST is Reinforced Structural Attention (RSA), whose calculation process is illustrated on the right side of Fig. 3. This module takes two key inputs: the feature representations of the target nodes and the structural heuristic features of the target node pair. The former is derived from the output of the neighborhood structure encoding module, which has undergone GNN processing and FFN enhancement for target node features. The latter is computed through a series of classic structural heuristic methods that can effectively characterize the connectivity and correlation between node pairs.

By integrating these heuristics, we can comprehensively capture the structural relationships between target nodes, including both local and long-range information.

Structural Encoding Fusion. To effectively integrate the above structural heuristics into the attention mechanism, we adopt a structural lookup embedding strategy. Specifically, we construct two parameterized lookup tables Pquery and Pkey, each containing a set of learnable vectors corresponding to different heuristic values. For each heuristic (e.g., SPD, Jaccard, AA), we first map its calculated value to an index in the lookup table, then retrieve the corresponding structural vectors from Pquery and Pkey, and finally sum the structural vectors from all heuristics to obtain the integrated structural encoding for the target node pair (i, j).

The core design adheres to simplicity and efficiency, fully leveraging the complementary information of local neighborhood structures and long-range pairwise structures.

Theoretical analysis for neighbor feature noise

Our empirical observation that neighbor node features introduce task-irrelevant noise in link prediction can be theoretically justified by three classic machine learning frameworks: bias-variance decomposition, mutual information (MI) theory, and the information bottleneck (IB) principle.From the perspective of bias-variance decomposition, the generalization error of a model is the sum of bias squared, variance, and irreducible noise. Link prediction is a link-centric task whose core signal is topological structural correlation, and neighbor features (Xnbr) provide no incremental discriminative information for this core signal, thus failing to reduce model bias. In contrast, Xnbr contains abundant task-irrelevant random fluctuations, which force the model to overfit training data and drastically increase variance—this imbalance is the key reason for performance degradation when retaining neighbor features.MI theory further quantifies the irrelevance of Xnbr: the mutual information between Xnbr and link labels I(Y;Xnbr) is much smaller than that between topological structure Xtopo and Y (I(Y;Xtopo)). Moreover, the conditional mutual information I(Y;Xnbr∣Xtopo)≈0, meaning Xnbr provides no additional information after capturing topological signals, while I(Xnbr;N) > 0 indicates Xnbr carries significant noise. The introduction of Xnbr thus dilutes the core topological signal in the input space.The IB principle defines the optimal feature learning as balancing I(Y;Z) (retaining task-relevant information) and I(X;Z) (compressing redundant information). For link prediction, Xnbr is a task-redundant input with I(Y;Xnbr)≈0, so the optimal strategy is to completely eliminate Xnbr from the input—this operation does not reduce I(Y;Z) but significantly compresses redundant noise, which is exactly the core design of our neighborhood structure encoding module. Notably, we retain target node features Xtarget instead of all node features, as I(Y;Xtarget∣Xtopo) > 0, which flexibly balances the IB tradeoff and avoids blind feature elimination.

Computational efficiency is critical for link prediction models, especially on large-scale graphs. Complexity of SPD and attention in FCA and RSA.

For SPD computation, traditional Transformers’ FCA module calculates shortest paths between all node pairs in the subgraph, resulting in a time complexity of O(N(N + E) logN) that becomes a bottleneck for large subgraphs. In contrast, RSA abandons global pairwise SPD calculation and focuses solely on the target node pair and their local neighborhood-related structures, reducing SPD complexity to O((N + E) logN) by eliminating the multiplicative factor of N.

The self-attention mechanism in FCA has an overall complexity of O(N2D + ND2) due to linear transformations of node features and pairwise similarity calculations for all nodes, with the O(N2D) term dominating for large N. RSA restricts attention calculation to the target node pair and their key structural-related nodes (a constant number independent of N), reducing attention complexity to O(D2) and solving the scalability issue of traditional Transformer-based methods.

The total computational complexity of FCT (using FCA) is O(N(N + E) logN + N2D + ND2), showing quadratic growth with N and making it impractical for medium-to-large-scale subgraphs. In contrast, RSA-based RST has a total complexity of O((N + E) logN + D2), which is linear with N and E. The acceleration ratio of RST over FCT ranges from O(N) (for small subgraphs with high-dimensional features) to O(N2) (for large subgraphs with low-dimensional features).

Implementation details

To fully elaborate the experimental setup of the TAGNN model, the model architecture parameters, training settings, experimental environment, code implementation details, and special processing strategies are summarized as follows: For model architecture, subgraph sampling adopts a 2-hop enclosing subgraph strategy (empirically optimal across all datasets) by merging the k-hop subgraphs of target node pairs and retaining inter-subgraph edges, with the maximum number of nodes per subgraph limited to 200 (topological importance sampling is used for over-sized subgraphs to retain core nodes); the GNN encoder uses a 2-layer GCN as the default (replaceable with GraphSAGE, GAT, etc.) with 128-dimensional hidden layers and ReLU activation, taking DRNL node labels (10-dimensional, covering all possible distance combinations) as input features instead of raw node attributes, while the raw attributes of target nodes are encoded via a 2-layer FFN (128-dimensional hidden layer) and concatenated with GNN output structural representations; the RST module employs 4 multi-head attention heads, integrates 5 structural heuristic features (SPD, Jaccard Index, Adamic-Adar Index, CN, SPN) with 32-dimensional query and key embeddings for each feature, and consists of 2 stacked blocks each including Layer Normalization, residual connection, and FFN (256-dimensional hidden layer); link decoding concatenates the GNN output node-pair similarity representation (processed by SortPooling, 256-dimensional) with the RST output pairwise structural representation (256-dimensional) to form a 512-dimensional joint representation, which is then fed into a 2-layer MLP (256-dimensional hidden layer with ReLU activation, 1-dimensional output layer) to output link existence probability via sigmoid activation. For training settings, the Adam optimizer is used with learning rates of 0.001 (ogbl-ppa, ogbl-citation2) and 0.0005 (other datasets), weight decay of 1e-5 to prevent overfitting, batch sizes of 64 (small-scale datasets: Cora, Citeseer), 128 (medium-scale datasets: Pubmed, ogbl-vessel), and 256 (large-scale datasets: ogbl-ppa, ogbl-citation2), maximum training epochs of 100 with an early stopping strategy (patience=20); the loss function is binary cross-entropy loss, and regularization strategies include Dropout (rate 0.5 for GNN and RST modules) and Layer Normalization after all fully connected and attention layers. The experimental hardware environment includes an Intel Xeon Gold 6248 CPU, an NVIDIA A100 GPU (for large-scale dataset training), and 128 GB memory; the software environment is based on Ubuntu 20.04 LTS, with PyTorch 1.12.1, PyTorch Geometric 2.1.0, and other dependencies (NumPy 1.21.6, Scikit-learn 1.0.2, NetworkX 2.8.4); the code is open-sourced on GitHub, with fixed random seed (seed=42) for reproducibility and grid search for hyperparameter tuning (search ranges: learning rate, hidden layer dimension, number of attention heads) to select optimal parameters based on validation performance. Special processing includes adding normalized spatial distance features (scaled to [0,1]) for the ogbl-vessel dataset, using mean imputation for missing attributes in the Citeseer dataset, adopting mini-batch subgraph sampling for large-scale datasets to reduce memory consumption, and conducting FCT module comparative experiments only on small-scale datasets (due to its O(N2) computational complexity) to verify the efficiency advantage of RST.

Specially, the five structural heuristics (CN, JI, AA, SPD, SPN) in the RSA module are all calculated based on the 2-hop enclosing subgraphs of target node pairs (instead of the entire graph), with the core implementation details as follows:The core logic is implemented based on NetworkX 2.8.4, and all calculations are performed on the sampled 2-hop enclosing subgraphs. Uniform processing is applied to boundary cases (e.g., SPD is set to the maximum number of nodes in the subgraph plus 1 when there is no connected path, and the contribution value of nodes with a degree of 1 in AA is set to 0).CN and JI are rapidly calculated via the dot product of sparse adjacency matrices instead of node-wise traversal; SPD and SPN are implemented based on Breadth-First Search (BFS) to avoid redundant overhead from full path enumeration. The node degree for all heuristics refers to the local degree within the subgraph rather than the degree in the entire graph.(3) 32-dimensional learnable parameter lookup tables (Pquery and Pkey) are constructed, and discrete heuristic values are mapped to indices (e.g., continuous values of JI and AA are discretized into 10 bins). The embeddings of each heuristic are extracted and summed to obtain the integrated structural encoding. For all the baseline models involved in the experiments, their hyperparameter settings follow a unified and rigorous principle: we first adopt the optimal hyperparameter configurations reported in the original papers of each baseline model (including hidden layer dimension, learning rate, batch size, regularization strength, etc.) that are validated on the corresponding link prediction datasets; for baselines that lack explicit optimal parameter settings for the tested datasets in their original papers, we perform grid search for hyperparameter tuning under the experimental environment of this paper (the search ranges are consistent with those used for TAGNN’s hyperparameter optimization, including learning rate: 1e-4~1e-2, hidden layer dimension: 64~256, dropout rate: 0.3~0.7) and select the optimal parameter combination based on the performance on the validation set. All baseline models use the same random seed (seed=42) for parameter initialization and training to eliminate the impact of randomness on experimental results. To ensure the absolute fairness of the experiments, all baseline models and the proposed TAGNN framework (including all its variants) are trained, validated and tested in a completely consistent hardware and software experimental environment. No model is deployed on a higher-performance computing device or optimized with exclusive acceleration strategies; all models use the same deep learning framework interfaces and graph processing toolkits (PyTorch 1.12.1, PyTorch Geometric 2.1.0) to avoid experimental biases caused by differences in implementation frameworks or toolkits. In addition to the above unified hyperparameter principles and consistent experimental environment, all models also adopt the same dataset partitioning strategy (official OGB standards/classic 8:1:1 partitioning), negative sampling method (global non-overlapping negative sampling with 1:1 positive/negative ratio), and evaluation metric calculation method (consistent with the official evaluation protocols of each dataset), to ensure that the performance comparison between TAGNN and all baselines is based on a fully fair and comparable experimental setup.

Experimental results

Comparison with baselines

The TAGNN framework (especially the TAGNN w/o NF variant) demonstrates significant advantages across six mainstream datasets: it ranks first on the ogbl-ppa, ogbl-citation2 and Pubmed datasets, and achieves performance second only to task-specific optimized models on the ogbl-vessel, Cora and Citeseer datasets. These results fully validate its effectiveness in structural information capture and noise suppression.

In the large-scale OGB dataset scenario (Table 2), TAGNN w/o NF delivers exceptional performance: On ogbl-ppa (protein association network, Hits@100 metric), it ranks first with 63.22±1.74 (95% CI: [61.54, 64.90]), outperforming the second-place Neural CN by 2.03 percentage points and traditional GNN method GCN by over 44 percentage points. As this attribute-free dataset relies solely on structural information, TAGNN’s neighbor feature removal and RST module enable focused topological learning and effective capture of long-range protein associations, outperforming heuristic methods like CN and AA. On ogbl-citation2 (paper citation network, MRR metric), it achieves 89.87±0.18 (95% CI: [89.69, 90.05]) to rank first—0.96 and 1.04 percentage points higher than NGNN and SUREL respectively. Its RST module accurately encodes citation path features via SPD and Jaccard heuristics, overcoming GNNs’ limited receptive fields in capturing long-distance directed citations, while TAGNN w/ NF (89.57±0.10) underperforms, confirming attribute interference. On ogbl-vessel (vascular network, AUC metric), TAGNN w/o NF reaches 96.87±0.01 (95% CI: [96.86, 96.88]), second only to task-specific GAV and superior to SUREL/SEAL. By combining DRNL local encoding and RST global association modeling, it balances spatial proximity and structural connectivity, avoiding the pitfalls of ignoring long-range structures or introducing spatial noise seen in other methods.

On the Cora dataset, TAGNN w/o NF achieves 93.92±0.05 (95% CI: [93.87, 93.97]), placing it among top performers, and it is 0.22 percentage points higher than sGraphite and only 0.18 percentage points lower than S-VGAE. It achieves the most notable performance improvements on attribute-free/low-attribute datasets (e.g., ogbl-ppa), showcasing the universality of its structural encoding capability. TAGNN w/o NF outperforms the two baselines on all datasets. On OGB datasets, it surpasses Graphormer by 1.52–4.58 percentage points and NBFNet by 0.85–2.95 percentage points; on classic attributed graph datasets, it outperforms Graphormer by 0.23–0.92 percentage points and NBFNet by 1.07–1.49 percentage points. Graphormer’s node-centric full-graph self-attention is prone to introducing noise from non-target nodes and diluting core topological signals in attribute-rich scenarios. NBFNet’s iterative path-based message passing suffers from insufficient capture of high-order and fine-grained local topology, with poor robustness in attribute-missing scenarios. In contrast, TAGNN’s GNN + RST dual-module architecture accurately captures both local topology and global long-range structural information, and its design of removing neighborhood features further focuses on core topological signals.

The proposed TAGNN addresses the core limitations of tow existing types of structural link prediction methods (subgraph-based methods, topology-aware GNN methods) with targeted innovations in tow aspects: encoding paradigm and structure capture mode. The core differences are highly summarized as follows:Versus subgraph-based methods: Though these methods extract enclosing subgraphs and introduce node labeling (e.g., DRNL), they still fuse neighbor features with structural information and capture only path depth information via local GNN aggregation, suffering from neighbor noise interference, limited receptive fields, and a single dimension of structural perception. In contrast, TAGNN abandons noisy neighbor features and retains only DRNL topological encoding; it also designs the RST module to enable direct pairwise encoding of target node pairs and fuse multi-dimensional structural heuristic features, resolving all the three aforementioned issues simultaneously.Versus topology-aware GNN methods: These methods enhance topological perception via diffusion, high-order aggregation and other strategies but still follow a node-centric modeling paradigm and fail to decouple topological learning from attribute aggregation. Moreover, they capture long-range structural information by increasing GNN layers or diffusion steps, which is prone to over-smoothing. TAGNN adopts a topology-first encoding strategy to eliminate noisy neighbor features, designs a GNN-independent RST module to directly model long-range structural correlations, and customizes the RSA mechanism for link prediction to avoid noise from non-target nodes.

Performance of TAGNN and its variants.

The performance gaps on ogbl-ppa, Pubmed, Citeseer, and Cora are 1.34, 0.24, 1.25, and 0.88 percentage points, respectively, demonstrating that structural information plays a dominant role in link prediction. The RST module is crucial for compensating for GNNs’ deficiency in capturing long-range structures and for link-centric encoding. After its removal, the performance on ogbl-vessel, Pubmed, and ogbl-citation2 drops by 12.17, 0.8, and 0.69 percentage points, respectively, with more significant contributions observed on datasets that rely on global connectivity. Its design of “focusing on the target node pair” also avoids irrelevant node noise and reduces computational complexity. In contrast, TAGNN (FCT) w/o NF shows performance decreases of 1.39, 0.7, and 5.16 percentage points on Pubmed, Cora, and Citeseer, respectively. Moreover, FCT cannot scale to medium and large datasets due to the quadratic complexity of global computation. The GNN module serves as the foundation for local structural encoding, providing core structural representations through DRNL encoding. Its removal leads to substantial performance drops of 29.76, 2.66, and 2.42 percentage points on ogbl-ppa, Cora, and Pubmed, respectively, with particularly strong support on datasets with tightly connected local structures. No single module can achieve optimal performance, confirming the rationality of the dual-module architecture of “local structural encoding + long-range structural supplementation.”

Topological heuristic-based encoding significantly outperforms Laplacian PE on all datasets, with the performance gap exceeding 2 percentage points on both large-scale OGB datasets and classic attributed graph datasets, and only a slight performance improvement is observed after fusing the two encodings. The reason is that Laplacian PE is a node-level positional representation that only captures the global position of nodes in the subgraph and fails to depict the direct structural correlation between target node pairs, which is mismatched with the link-centric link prediction task. In contrast, heuristic-based encoding is custom-designed for link prediction and can accurately characterize the structural correlation of node pairs from multiple dimensions, serving as the core encoding method adapted to the task. Laplacian PE only provides a small amount of position-related complementary information and cannot replace the core role of heuristic-based encoding. These results further verify the rationality and pertinence of the selection of topological heuristic-based encoding.

The purpose of the adaptability experiments (Fig. 4) for different GNN encoders is to verify the compatibility of the TAGNN framework’s dual-module architecture (i.e., “GNN+RSA”) with diverse types of GNN encoders, and test the performance stability of the framework when the local structural encoding methods are altered. The core objectives are to confirm whether the framework’s structure-oriented design relies on specific GNN encoders, screen out the optimally adapted GNN type, and provide a basis for users to make flexible choices. In terms of experimental setup: the core parameters of the RST module were fixed (including 4 attention heads, 2 layers of RST blocks, and a heuristic feature combination for specific structures (SPD+CN+Jaccard+AA+SPN)), and neighbor features were removed (w/o NF). Four mainstream GNN encoders (GCN, GraphSAGE, GAT, and GIN) were selected, with their parameters (e.g., hidden layer dimension and activation function) unified. The experiments were conducted on three representative datasets: ogbl-citation2 (a large-scale directed graph), Pubmed (a medium-to-small-scale attributed graph), and Citeseer (an attribute-deficient graph). For each encoder-dataset combination, independent training was performed 5 times; the mean ± standard deviation and 95% confidence interval were then calculated. Experimental analysis demonstrates that all tested encoders maintained high-level performance after adaptation, with the maximum performance gap relative to the original GCN version not exceeding 1.69 percentage points, which proves the strong compatibility of the framework. Among them, GAT achieved the optimal adaptation effect (showing the closest performance to the original GCN, as its attention mechanism aligns with the design philosophy of the framework). GraphSAGE exhibited stable adaptation performance, making it suitable for dynamically scalable graph scenarios. In contrast, GIN delivered relatively poor adaptation results, because its advantages in attribute aggregation could not be leveraged due to the removal of neighbor features in the framework.

For the TAGNN(FCT) variant, its results on large-scale OGB datasets (ogbl-ppa, ogbl-citation2, ogbl-vessel) are not reported (marked as "-" in Table 4) because the fully connected attention (FCA) module in FCT has an inherent quadratic computational complexity (O(N2D)) in attention calculation. In contrast, the RSA module in our proposed RST avoids this problem by confining attention computation strictly to target node pairs, reducing the complexity to linear (O(D2)) and enabling efficient training on large-scale datasets.

The purpose of the structure-heuristic feature ablation experiments (Fig. 5) is to verify the contribution degree of different structure-heuristic features in the RST module, and identify the core feature combinations to provide a basis for model lightweighting. In terms of experimental setup: the TAGNN w/o NF (with GCN encoder) was adopted as the baseline model, and the original feature combination of the RST module was set as “SPD + CN + Jaccard + AA + SPN”. Six groups of variants were constructed by removing a single feature one by one or eliminating feature combinations. The experiments were conducted on two datasets, namely ogbl-vessel (a spatial network) and Cora (a graph with dense local structures), with AUC selected as the evaluation metric. Each variant was independently trained 5 times, and the mean ± standard deviation as well as the 95% confidence interval were calculated accordingly. Experimental analysis shows that SPD (Shortest Path Distance) is the core feature: after its removal, the model performance on the ogbl-vessel and Cora datasets decreased by 2.75 percentage points and 1.06 percentage points, respectively. CN (Common Neighbors) contributes the second most. The combination of Jaccard and AA is also crucial due to their normalization effect. The performance of the feature combination with only SPD + CN failed to reach the level of the full-feature set, while the combination of SPD + CN + Jaccard + AA achieved over 98% of the full-feature performance. These results indicate that a rational feature combination can achieve model lightweighting while ensuring performance, thus providing a clear direction for subsequent model optimization.

The purpose of the noise robustness tests (Fig. 6) is to verify the robustness of the TAGNN framework in realistic and complex scenarios where node features contain noise and graph structures include anomalous edges, as well as to simulate the impact of noise interference on model performance. In terms of experimental setup: the models under test were TAGNN w/o NF and TAGNN w/ NF, with SEAL and GAT serving as the baseline models for comparison. Specifically, Gaussian noise with variances of 0.1/0.3/0.5 was added to the node features of the Cora and Pubmed datasets, respectively; meanwhile, anomalous edges accounting for 5%/10%/15% of the original edge count were randomly inserted into the ogbl-ppa and ogbl-citation2 datasets. AUC and MRR were used as the evaluation metrics to record the performance and performance decay rate under different noise intensities. Each model was independently trained 5 times, and the mean ± standard deviation as well as the 95% confidence interval were calculated. Experimental analysis shows that TAGNN w/o NF achieved the optimal robustness: when the feature noise variance reached 0.5, its performance only decreased by 1.37%; when the structural noise level hit 15%, the performance decay rate was merely 2.20%. These values were far lower than those of TAGNN w/ NF (with a 4.80% decay under feature noise and 3.41% under structural noise) and the baseline models SEAL and GAT (with a maximum performance decay of 8.07%). This result confirms that removing neighbor features effectively reduces noise sources, and the structure-focused design of TAGNN enables it to stably capture core structural information even in noisy environments. Compared with baseline models that rely on node feature or local structure aggregation, TAGNN is more suitable for realistic and complex data scenarios.

All models show declining link prediction performance with increasing shortest path distance (SPD) between node pairs, with traditional GCN performing poorly for long-range pairs (SPD≥5). TAGNN w/o NF outperforms baselines (GCN, SEAL, NGNN) across all SPD intervals on both ogbl-ppa and ogbl-citation2, with its advantages expanding drastically for long-range pairs, even achieving slightly higher performance on long-range vs short-range pairs in the citation network (ogbl-citation2). The RST module’s performance contribution has a strong positive correlation with SPD: it yields negligible gains for short-range node pairs (SPD=2) but drives dramatic performance boosts for long-range ones (22.35 percentage points for Hits@100 on ogbl-ppa and 4.89 for MRR on ogbl-citation2 at SPD≥5), serving as the core to address traditional GNNs’ limited receptive field. Together, the GNN module underpins short-range local structural encoding while the RST module compensates for long-range structural perception deficiencies, and their synergy makes TAGNN highly adaptive to link prediction across distance scales, especially excelling on large-scale attribute-free graphs with abundant long-range node pairs (e.g., ogbl-ppa).

Computational efficiency

To comprehensively verify the engineering practicality of the TAGNN framework, we supplemented computational efficiency comparison experiments focusing on two core metrics: training/inference speed (Tables 8 and 9). Quantitative comparisons were conducted against mainstream baseline models, including heuristic methods (CN, AA), GNN-based methods (GCN, GAT, GraphSAGE, SEAL), and Transformer-based methods (GraphBert, TAGNN (FCT)), and other methods across four representative datasets of varying scales (Cora, Pubmed, ogbl-citation2, ogbl-ppa). The experiments were standardized with unified hardware environments, software configurations and model parameters. Key evaluation metrics included single-epoch latency, single-link prediction latency and batch inference throughput. The results demonstrate that, through the structure-focused design of the RST module (which performs attention calculations exclusively on target node pairs, avoiding global quadratic complexity) and the neighbor feature removal strategy, the TAGNN framework resolves the out-of-memory (OOM) issue on large-scale datasets compared to fully connected Transformer-based models. In comparison with mainstream GNN methods such as SEAL, TAGNN achieves over 40% improvement in training efficiency, over 80% enhancement in inference throughput, and over 30% reduction in memory footprint. Specifically, TAGNN w/o NF attains a throughput of 40,322 pairs/s on ogbl-ppa, while reducing memory usage by 8.5% compared to GAT. Moreover, while maintaining state-of-the-art performance, TAGNN controls inference latency within the acceptable range for industrial applications (only 2.48 seconds for 100,000 link predictions).

Discussion

The experimental results across six benchmark datasets validate the effectiveness of the TAGNN framework in addressing the inherent limitations of GNN-based link prediction methods. A key empirical insight from our experiments is that, for the link-centric link prediction task and the six tested benchmark datasets, neighbor node attributes (which are widely used and considered valuable in node-centric graph learning tasks such as node classification) tend to introduce task-irrelevant interference, rather than providing incremental discriminative information. The consistent outperformance of the TAGNN w/o NF variant over TAGNN w/ NF across all tested datasets, especially in attribute-rich but noisy scenarios like Pubmed and Citeseer, indicates that topological structural information plays a dominant role in the link prediction tasks we tested, while unfiltered neighbor node features may dilute the critical topological signals that determine link formation. This aligns with our initial hypothesis and highlights the importance of decoupling structural learning from attribute aggregation in link prediction. The RST module emerges as a core contributor to TAGNN’s success, effectively compensating for GNNs’ restricted receptive fields. Its focus on target node pairs, rather than global node interactions, not only captures long-range structural correlations (e.g., citation chains in ogbl-citation2 and vascular connectivity in ogbl-vessel) but also reduces computational complexity from quadratic to linear. This efficiency gain is pivotal for scaling to large-scale datasets like ogbl-ppa, where fully connected Transformer-based models (e.g., TAGNN (FCT)) fail to run due to memory constraints. The ablation study further demonstrates that removing the RST module leads to significant performance drops, especially on datasets relying on global connectivity, underscoring its role in bridging the gap between node-centric GNN encodings and link-centric task requirements. TAGNN’s dual-module architecture proves synergistic, which combines GNN-based local structural encoding (via DRNL) and RST-based long-range pairwise encoding. The GNN module excels at capturing local neighborhood topology, as evidenced by the sharp performance decline when it is removed (e.g., a 29.76 percentage point drop on ogbl-ppa), while the RST module supplements critical long-range information that GNNs cannot reach. This complementarity enables TAGNN to adapt to diverse graph types: from attribute-free large-scale graphs (ogbl-ppa) to small-scale attributed graphs with missing features (Citeseer). Additionally, the framework’s compatibility with various GNN encoders (GCN, GraphSAGE, GAT, GIN) showcases its flexibility, allowing users to tailor the model to specific data characteristics without sacrificing performance.

Robustness tests confirm that TAGNN w/o NF maintains stable performance under feature and structural noise, outperforming baselines like SEAL and GAT. This resilience stems from its structure-focused design: by discarding noisy neighbor features and leveraging heuristic structural cues (e.g., SPD, CN), TAGNN prioritizes core topological patterns that are less susceptible to interference. The structural heuristic ablation experiments further identify SPD as the most critical feature, with its removal causing the largest performance drops, while combinations like SPD+CN+Jaccard+AA retain over 98% of the full-feature performance, offering a path toward model lightweighting without compromising effectiveness.

Despite these strengths, TAGNN has limitations: First, the DRNL-based structural encoding relies on shortest path calculations, which can be costly for extremely large graphs. Second, the framework uses a fixed set of structural heuristics, lacking adaptive selection for diverse data scenarios. Third, TAGNN currently focuses on static link prediction and has not been tested on dynamic graphs. Future work will explore approximate distance metrics to enhance scalability, integrate adaptive heuristic feature selection mechanisms, and extend the RST module to capture temporal structural changes for dynamic link prediction tasks.

For the shortest path calculation overhead of DRNL in extremely large graphs, preliminary engineering optimization can be implemented from two practical directions: first, adopting approximate shortest path algorithms (e.g., bidirectional BFS with early termination or landmark-based approximate distance calculation) to replace the exact shortest path computation in the whole graph, which can significantly reduce time complexity while ensuring the structural discrimination of DRNL labels for link prediction; second, performing subgraph-level precomputation and caching of shortest path distances for the k-hop enclosing subgraphs sampled for target node pairs, since the subgraph scale is controlled within a reasonable range (k=2 in our experiments), precomputing and caching the pairwise shortest path distances of nodes in the sampled subgraphs can avoid repeated calculation for the same subgraph and further reduce the actual computational overhead in model training and inference.

Furthermore, recent relevant studies have validated the effectiveness and cross-domain adaptability of GNN-based models in the fine-grained modeling of topological structures across different fields. Alaygut et al.58 applied hypergraph neural networks to stock trend prediction and improved prediction performance by mining high-order topological relationships in financial scenarios, verifying the significant value of non-local structural information for graph learning tasks. The residual graph attention network GAT HiC proposed by Kaya et al.59 achieves efficient modeling in 3D chromosome structure reconstruction, a structural prediction task in bioinformatics, and provides practical references for encoder design and topological modeling of GNNs in biological network link prediction tasks. The topology-aware and structure-focused design philosophy of the TAGNN framework proposed in this paper is consistent with the core research directions of the above studies, and also provides an alternative lightweight structural modeling solution for such cross-domain graph learning tasks. Meanwhile, these two studies offer new perspectives for the further development of TAGNN. For example, high-order relational modeling with hypergraphs and the customized design of GNN encoders dedicated to biological domains represent promising directions for future exploration.

It is necessary to clarify the applicable scope of our finding that removing neighbor node features improves link prediction performance, to avoid overgeneralization: (1) This conclusion only applies to the link prediction task. It does not extend to node-centric or graph-centric tasks (e.g., node classification, graph classification), where neighbor node features remain highly informative; (2) Our finding is validated on six benchmark datasets, with more significant performance gains on large-scale sparse graphs and topology-driven link formation graphs. For scenarios where links strongly depend on node attribute similarity (e.g., social networks, recommendation systems), neighbor features may still provide positive benefits; (3) We only remove neighbor node attributes while keeping the features of target node pairs. We do not deny the value of node attributes in general, but show that decoupling neighborhood topology learning from neighbor attribute aggregation yields better performance in link prediction.

Conclusion

This work addresses three key limitations of mainstream GNN-based link prediction methods: restricted receptive fields that hinder long-range structural perception, the mismatch between node-centric encoding paradigm and link-centric task objectives, and the potential task-irrelevant interference introduced by neighbor node attributes in link prediction scenarios. To tackle these issues, we propose the Topology-Aware Graph Neural Network (TAGNN) framework. Genuine novel contributions of TAGNN are as follow:We identify three core GNN limitations for link prediction and theoretically prove (via bias-variance decomposition, MI, IB principle) the rationality of discarding noisy neighbor features.We propose to decouple GNN’s topology learning from attribute aggregation by discarding neighbor features, breaking the conventional fusion of features and topology in all prior methods.We design the first link-specific Transformer module for link prediction, which realizes linear-complexity attention via target node pair-focused computation and fuses domain structural heuristics to make up for GNN’s long-range perception deficiency.We integrate GNN-based local topological encoding and RST-based long-range pairwise encoding, unifying the modeling of local and global node-pair structure—an innovation beyond the single encoding architecture of all prior methods.

Extensive experiments on six benchmark datasets demonstrate that TAGNN achieves state-of-the-art performance, ranking first on ogbl-ppa, ogbl-citation2, and Pubmed. The TAGNN w/o NF variant consistently outperforms its counterpart with full neighbor features across all six tested benchmark datasets, which provides solid empirical evidence for our observation that neighbor node attributes tend to introduce interference in the tested link prediction scenarios. Future work will focus on optimizing structural encoding efficiency for dynamic graphs, integrating adaptive heuristic feature selection, and extending the framework to temporal link prediction tasks.
