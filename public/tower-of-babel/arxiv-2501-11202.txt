Online Hybrid-Belief POMDP with Coupled Semantic-Geometric Models
Tuvy Lemberg, Vadim Indelman

Abstract
Robots operating in complex and unknown environments frequently require geometric-semantic representations of the environment to safely perform their tasks. Since the environment is unknown, robots must infer it and account for many possible scenarios when planning future actions. Because object class types are discrete, and the robot’s self-pose and the objects’ poses are continuous, the environment can be represented by a hybrid discrete-continuous belief, which has to be updated according to models and incoming data. Prior probabilities and observation models representing the environment can be learned from data using deep learning algorithms. Such models often couple environmental semantic and geometric properties. As a result, all semantic variables are interconnected, causing the dimensionality of the semantic state space to increase exponentially. In this paper, we consider the framework of planning under uncertainty using partially observable Markov decision processes (POMDPs) with hybrid semantic-geometric beliefs. The models and priors considered in this work assume coupling between semantic and geometric variables. We show that obtaining representative samples of the theoretical hybrid belief, required for estimating the value function, is very challenging. As a key contribution, we develop a novel form of the hybrid belief and leverage it to generate representative samples. Furthermore, we show that under certain conditions, the value function and constraints, such as the probability of safety, can be calculated efficiently with an explicit expectation over all possible semantic mappings. Our simulations show that our estimators of the objective function achieve similar levels of accuracy compared to estimators that run exhaustively on the entire semantic state-space using samples from the theoretical hybrid belief. Nevertheless, the complexity of our estimators is polynomial rather than exponential.

Therefore, the robot must infer its environment and account for different possible scenarios when planning future actions.

POMDPs

Since the robot’s state and environment are unknown, they can be represented by the belief’s state. The belief, which is a posterior probability of the state, represents the probability of different scenarios. It can be derived using prior probabilities, a motion model, an observation model, and previous history such as previous actions and observations.

I-A

Coupled Semantic-Geometric Models

Prior probabilities and models can be learned using machine learning and deep learning algorithms. The learned priors can account for the dependencies between geometric and semantic variables. For instance, in
[
12
]
, a semantic 3D reconstruction methodology is proposed, where the model learns priors that capture the dependencies between semantic labels and the geometric properties of the environment. By doing so, they achieve improved accuracy in 3D reconstruction tasks, while reducing the number of parameter of the neural network. Likewise, learned prior probabilities can link an object’s class and its location, since certain objects are more likely to be found in certain locations
[

.

In general, semantic observations often depend on both the class of the observed object and its relative position to the robot

6

. For example, an image-based classifier may produce different results for the same object when the images are taken from different viewpoints.

Manhardt et al.
[
16

study the ambiguity of object detection and 6D pose estimation from visual data. They highlight that objects often appear similar from different viewpoints due to shape symmetry, occlusion and repetitive textures.
A bowl and a mug can appear similar from certain poses, leading to potential misclassification and incorrect pose estimation errors. A robot tasked with locating the mug should account for this ambiguity in its planning.

I-B

Hybrid Semantic-Geometric Belief in SLAM and POMDPs

The coupling between the object’s pose and its class causes statistical dependency between all random variables of the state. Therefore, the classes of all objects are mutually dependent. Since all classes are dependent, the number of semantic mapping hypotheses is exponential in the number of objects. This makes many required computations, such as finding the most probable hypothesis and computing the value function, computationally prohibitive.

Many POMDP solvers approximate the value function using sample-based estimators
[
17
,
18
,
19
,
20
]
. This is a common approach in POMDPs, since computing expectations over continuous state space is often intractable, the state space dimensionality can be substantial and the horizon the robot must plan for can be far, making numerical approximation difficult.
However, this approximation introduces estimation error, which can be substantial in the case of hybrid semantic-geometric beliefs since the state space increases exponentially with the number of objects.

Only a few studies considered a semantic-geometric belief with dependency between classes and poses, and most of them are in the context of semantic simultaneous localization and mapping (SLAM). Most of these studies use only the maximum likelihood of a classifier output, without considering the coupling between the semantic observation and the relative viewpoint
[
21
,
15
,
22
]
. These approaches do not consider a belief over the semantic mappings and therefore cannot assess uncertainty.

The approach proposed in
[
23
]
, maintains a belief on classes of objects. However, semantic observations are considered independent of the relative position of the object to the robot. Even though this observation model simplifies the problem computationally, it neglects the effect of viewpoint on classification and vice versa, losing important information. The works
[
24
,
25
]
use separate beliefs for the robot state and the object’s object property.

Recent studies have used viewpoint dependent semantic observation models in SLAM and considered the coupling between object’s class and pose, showing improved data association (DA), localization, and semantic mapping
[
26
,
27
,
4
,
5
,
14
]
. However, these works manage the computational burden by pruning most semantic hypotheses. Aside from the performance loss, pruning hypotheses will make it impossible to assess the system’s risk if one of the pruned hypotheses turns out to be true.
Moreover, after pruning and renormalization, the resulting belief is overconfident relative to the original belief
[
28
]
. This may lead to actions that pose a higher risk.

In
[
28
]
, a method was developed
for estimating the normalization factor and the probability of a single semantic mapping hypothesis considering all possible semantic mappings. Computation of the theoretical normalization factor requires summation over all possible semantic mappings and integration over the continuous state which may be intractable. Although the number of possible semantic mappings is exponential, it was shown that an explicit summation over these mappings for the normalization factor can be calculated very efficiently, without explicitly running through all possible semantic mappings explicitly. The estimation of the normalization factor allows to estimate the probability of a single semantic mapping hypothesis, without running through all possible semantic mappings.

I-C

Contributions and Paper Organization

In this work, we consider a semantic-geometric hybrid belief POMDP. Observation models and prior probabilities that link between an object’s class and its pose, cause all classes to be mutually dependent. This makes the state space increase exponentially with the number of objects. Large space spaces, also known as the curse of dimensionality, is one of the most discussed topics in POMDPs
[
10
]
.

Because the number of semantic mapping hypotheses is exponential, explicitly marginalizing the unnormalized belief over the semantic mapping hypotheses is computationally prohibitive. Yet, we show that this can be accomplished efficiently using novel formulations of the belief, allowing us to calculate the marginal unnormalized belief of the continuous state while accounting for
all
the semantic mapping hypotheses.

Using the marginal unnormalized belief of the continuous state, we show that sampling the belief at planning time can be done efficiently. This is possible by first drawing representative samples of the continuous state and then sampling objects classes given the continuous state samples. Since the models considered coupling between an object’s class and its pose, classes of different objects are independent given objects’ poses. This allows us to sample semantic mapping hypotheses efficiently.

Continuous state samples can be obtained using MCMC methods such as the Metropolis-Hastings (MH) algorithm
[
29
]
or proposal distribution for self-normalized importance sampling (SNIS)
[
30
]
. Both require evaluating the marginal unnormalized belief for sampled continuous state realization. This calculation can be performed efficiently using our formulation. In contrast, without it, this evaluation is computationally intractable due to the exponential number of semantic mapping hypotheses.

Moreover, we demonstrate that using importance sampling to estimate the value function in hybrid POMDP settings can lead to an exponential increase in the mean squared error (MSE) with the number of objects, due to semantic samples. We show that in many cases, the MSE caused by semantic samples has a lower bound that increases exponentially with the number of objects. However, by utilizing our sampling methods, this lower bound is zero in these cases. Furthermore, our empirical simulations demonstrate that the error does not increase with the number of objects.

To improve estimation error even further, we prove that the objective function can be estimated with an
explicit
expectation over all possible semantic mapping hypotheses efficiently. This can be applied in an open loop setting, where policies are reduced to a pre-defined action sequence, and for a specific structure of reward functions. Since we run through all semantic hypotheses, the true hypothesis will be considered. In contrast, using pruning or sampling hypotheses we may miss the true semantic hypothesis. Furthermore, the Rao-Blackwell theorem
[
31
]
guarantees a reduced estimation error.

The probability of safety
[
32
,
33
,
34
,
35
]
in the context of hybrid semantic POMDP is used as an illustrative example for the structured reward throughout this study.
Often, robots operating in complex environments should satisfy constraints dependent on both geometric and semantic properties. For instance, autonomous vehicles should assess traffic sign type and location.
In a POMDP, computing the probability of fulfilling such constraints in the future is often called the probability of safety.

Since each object creates a constraint on the robot’s state, and each semantic mapping hypothesis implies a set of constraints, to estimate the probability of safety, one must run through all possible semantic mappings and compute the probability of fulfilling the constraints under each hypothesis. Nevertheless, we show that the probability of safety falls under the special reward function type and therefore explicit expectation of semantic hypotheses can be applied effectively.

To summarize, our main contributions are as follows:

•

We present a novel formulation for the hybrid semantic-geometric belief. This formulation allows us to calculate the unnormalized marginal belief of the continuous state efficiently, marginalizing over all semantic mapping hypotheses.

•

Sampling from a belief at planning time is generally intractable. We provide sampling methods that utilize the unnormalized marginal belief of the continues state.

•

Under simplified assumptions we show that the objective function and the probability of safety considering hybrid semantic-geometric beliefs can be estimated efficiently, while running through all possible semantic mappings, thus reducing estimation error.

Related Work

II-A

Semantic SLAM and Viewpoint-Dependent Models

Only a few semantic SLAM works have considered a viewpoint dependent semantic observation model. In such models, observations depend on the object’s class, the object’s pose, and the robot’s pose. There are many works outside of SLAM framework that estimate the pose of an object depending on its class from a single image, such as
[
36
,
37
,
38
]
, thereby modeling the coupling. However, in a SLAM framework, this coupling causes all classes to be dependent, therefore it is very common to neglect this coupling and consider classes and poses separately.

Segal and Reid
[
39
]
implemented a hybrid continuous-discrete belief optimization method for robot localization and mapping. They approximated inference on a factor graph with junction nodes.
Velez et al.
[
1
]
and Teacy et al.
[
40
]
utilized an online planning algorithm that considers a viewpoint-dependent semantic observation model and learns the spatial correlations between observations. However, they simplified the belief by assuming known localization and no prior information is given. Therefore, classes of different objects are independent.

Bowman et al.
[
41
]
formulated the full joint belief over the environment’s semantic and geometric properties. They used the expectation maximization (EM) method to infer the belief. They showed results in scenarios with a small number of objects and possible classes. Because the number of semantic hypotheses increases exponentially, it is not feasible to evaluate all hypotheses in EM.

Feldman and Indelman
[
5
]
developed a method to extend a single image classifier into a viewpoint-dependent observation model that also captures the model’s epistemic uncertainty
[
42
]
, which occurs when the classifier receives raw data at deployment that is far from the data the classifier was trained on. They model the output as a Gaussian process. They show empirically that their method improves robustness and classification accuracy compared to other methods that do not use a viewpoint-dependent semantic model. Tchuiev and Indelman
[
14
]
fused the viewpoint-dependent semantic model with epistemic uncertainty in belief space planning.

Morilla-Cabello et al.
[
6
]
proposed a generalization of the viewpoint-dependent observation model. Their observation model additionally accounts for environmental effects, such as appearance, occlusions, and backlighting. They showed improvements in state estimation quality.

Tchuiev et al.
[
27
]
showed that a semantic viewpoint-dependent observation model can be used to enhance localization, DA, and semantic mapping in ambiguous scenarios. To reduce the computational burden, they considered only a few semantic mapping hypotheses and pruned the rest. Kopitkov and Indelman
[
4
]
used a neural network to learn a viewpoint-dependent measurement model of CNN classifier output features.

II-B

Hybrid Discrete-Continuous POMDPs

General state-of-the-art POMDP algorithms such as POMCPOW, PFT-DPW, and DESPOT
[
17
,
18
,
19
]
are not explicitly formulated for hybrid discrete-continuous beliefs but can be modified to support them. However, these methods assume that the state can be sampled from the belief at planning time. This is not possible in our setting since it requires full knowledge of the probability of semantic hypotheses. Because the number of semantic hypotheses is exponential, it is not feasible to calculate the probabilities of all hypotheses.

Recently, POMDPs with hybrid continuous and discrete states have been investigated in the context of DA
[
43
,
44
,
45
]
.
Several works have incorporated discrete DA variables into the state, creating a hybrid continuous-discrete belief in POMDP. Although the formulations of beliefs with DA are similar to the hybrid belief with semantic-geometric coupling, there are several fundamental differences.
In DA POMDP, the discrete state space grows exponentially with history. In our case, the discrete state space grows exponentially with the number of objects; thus, it is exponentially large at planning time, but it does not increase within future time instances within planning, assuming one does not model observations of new objects that are unknown at planning time.

Barenboim et al.
[
45
]
utilized the Monte Carlo Tree Search (MCTS) algorithm to support a hybrid discrete-continuous state POMDP. They propose a sequential importance sampling method with resampling to estimate the value function. They define the proposal distribution for the discrete state to be uniform. In our case, this proposal will result in an exponential MSE. Additionally, we provide several methods for obtaining representative samples that result in significantly lower MSEs.

II-C

Rao-Blackwellization in Hybrid Models

Several works used the Rao-Blackwell theorem
[
31
]
to reduce the estimation error.
Doucet et al.
[
46
]
introduced the Rao-Blackwellised Particle Filtering (RBPF). They show that for some cases, it is possible to exploit the structure of a Bayesian network by sampling only the state variables that cannot be marginalized analytically, and marginalize analytically the rest. Using this approach, they improve the particle filter algorithm in two ways: they improve state estimation according to the Rao-Blackwell theorem, and they avoid the curse of dimensionality by reducing sample state dimensionality.

In a recent paper
[
47
]
, the RBPF was integrated with the POMCPOW algorithm
[
17
]
combined with quadrature-based integration, showing fewer samples were required, and planning quality superiority compared to other methods.

In our work, we utilize the Rao-Blackwell theorem by calculating the expectation over the semantic mapping hypotheses explicitly. This allows us to reduce the MSE of the estimated objective function. We show that this is possible for specific reward structures and open-loop policies. It can be applied to a variety of objectives, such as object search and probability of safety.
We provide a complementary proof of the Rao-Blackwell theorem for our setting, where part of the expectation is estimated using samples and the other part is computed explicitly (see Theorem
V.6
).

III
Preliminaries and Problem Formulation

In this section, we formulate the agent’s posterior probability distribution, also known as belief, where a semantic, viewpoint-dependent observation model is considered. This belief is hybrid, containing both continuous-geometric variables, such as agent’s and objects’ poses, and discrete-semantic variables, such as objects’ classes. Next, we formulate the hybrid semantic-geometric POMDP. Lastly, we introduce semantic risk awareness under a semantic-geometric POMDP with semantic-geometric constraints.

III-C

Semantic Risk Awareness

There are many studies that focus on chance constraints and risk awareness within POMDP settings, such as
[
32
,
33
,
34
]
.
In our work, we formulate the probability of safety in an object-semantic-geometric POMDP setting, where both the semantic and geometric properties of the environment affect the constraints that the agent must satisfy. This scenario is very common. For example, self-driving cars that encounter traffic signs will have different constraints for each traffic sign; a robot that navigates a cluttered household may have to avoid fragile objects of a certain type while engaging with other types. In both cases, the object type affects the constraints.

To our knowledge, this work is the first to formulate the probability of safety in object-semantic-geometric POMDP settings. We consider the safety constraints to be class dependent. Further, we show in this section that computing the probability of safety is computationally intractable if done naively in a brute-force manner, whereas in Section
V-B
we show that using our methods, the probability of safety can be computed with great efficiency, reaching real-time performance.

Consider scenarios where the agent poses a risk to the environment or vice versa. This event is defined by the agent’s state, the objects’ states, and the objects’ classes, creating constraints on the robot.
Because a POMDP setting is considered, it is not always possible to guarantee the fulfilment of the conditions. Instead, the probability of fulfilling the constraints should be considered. In particular, each semantic mapping defines a different constraint on the agent’s state, and to compute the probability of safety, it is necessary to run over all possible semantic mappings. Generally, calculating this probability is prohibitively expensive.

Specifically, suppose each object defines an unsafe subspace for the agent,

\mathcal{X}_{\text{unsafe}}\left(c_{n},x^{o}_{n}\right)\subseteq\mathcal{X},\;\;n=1,\ldots,N^{o}
.
Given a semantic map
(C,X^{o})
, the unsafe subspace is the union of all objects’ unsafe subspaces,

\mathcal{X}_{\text{unsafe}}\left(C,X^{o}\right)=\cup_{n=1}^{N^{o}}\mathcal{X}_{\text{unsafe}}\left(c_{n},x_{n}^{o}\right)
.

Definition III.2
.

The probability of safety
\mathbb{P}_{\text{safe}}
is defined as the probability that the agent will only pass through the safe subspace. This is equal to the probability that it will never pass through the unsafe subspace,

\mathbb{P}_{\text{safe}}=\mathbb{P}\left(\left\{\wedge_{\tau=k+1}^{L}x_{\tau}\notin\mathcal{X}_{\text{unsafe}}\left(C,X^{o}\right)\right\}\mid b_{k},\pi_{k:L-1}\right).

(13)

In Section
V-C
, equation (
44
), we show that the probability of safety,
\mathbb{P}_{\text{safe}}
, can be formulated as an expectation of a state-dependent reward, similar to the value function in (
50
).

Therefore,
\mathbb{P}_{\text{safe}}
can be computed using the same methods we developed for the value function.
Ultimately, we will show that
\mathbb{P}_{\text{safe}}
has a special structure, as given in (
36

allowing us to compute it efficiently while considering all possible combinations of semantic mappings, assuming open-loop settings.

IV-A
1
Sampling Directly from the Belief

Sampling from the hybrid belief
b_{k}\left[C,X_{k}\right]
is challenging. Commonly, the belief is decomposed using chain rule into
b_{k}\left[C\right]b_{k}\left[X_{k}\mid C\right]
(
17
), where
b_{k}\left[C\right]
are the weights and
b_{k}\left[X_{k}\mid C\right]
are the components.
Once the weights are calculated, we can sample hypothesis
C^{(i)}
using the weights and sample
X_{k}^{(i)}
using the component
b_{k}\left[X_{k}\mid C^{(i)}\right]
.
However, calculating all the weights is computationally prohibitive since the number of hypotheses is
|\mathcal{C}|=(N^{c})^{N^{o}}
,
which is exponential complexity in the number of objects
N^{o}
.
Additionally, it may be impossible to sample from the components
b_{k}\left[X_{k}\mid C\right]
directly since not all probabilities can be sampled directly, and if the expectation of
X_{k}
is intractable, the weights are also approximated

b_{k}\left[C\right]=\intop b_{k}\left[C,X_{k}\right]dX_{k}\approx\sum_{i}b_{k}\left[C,X_{k}^{(i)}\right]
,
resulting in an additional layer of error.

Alternatively, the belief can be reformulated as
b_{k}\left[X_{k}\right]b_{k}\left[C\mid X_{k}\right]
(
16
), allowing sampling
X_{k}^{(i)}
from
b_{k}\left[X_{k}\right]
and
C^{(i)}
from
b_{k}\left[C\mid X_{k}^{(i)}\right]
.
Similarly to the previous case, samples of
b_{k}\left[X_{k}\right]
cannot be obtained directly since it requires computing an exponential number of weights,

b_{k}\left[X_{k}\right]=\eta_{1:k}\sum_{C\in\mathcal{C}}b_{k}\left[C\right]\tilde{b}_{k}\left[X_{k}\mid C\right],

(20)

and is not always possible to sample from the components
b_{k}\left[X_{k}\mid C\right]
.

However, there are MCMC methods to sample from a general multivariate distribution like MH
[
29
]
. Yet, this requires querying the unnormalized marginal
\tilde{b}_{k}\left[X_{k}\right]
, given by

\tilde{b}_{k}\left[X_{k}\right]=\sum_{C\in\mathcal{C}}\tilde{b}_{k}\left[C,X_{k}\right],

(21)

which involves an
exponential
number of components and is computationally prohibitively expensive.
Querying belief means calculating the belief for a specific state value. Similarly, the unnormalized belief, the marginals, and the conditional beliefs can be queried.

Other MCMC methods like Gibbs sampling, require repeated sampling from
b_{k}\left[C\mid X_{k}\right]
and
b_{k}\left[X_{k}\mid C\right]
, are viable but computationally expensive due to the large number of components involved. Despite its practicality, Gibbs sampling remains a costly alternative.

IV-A
2
Pruning Hypotheses

Pruning hypotheses and keeping only a limited set is common practice, but it has severe drawbacks. Following pruning and renormalization, the belief is overconfident and the agent may assume that it knows the true hypothesis with very high probability while in fact the probability that the true hypothesis was pruned can be significant because most of the hypotheses were pruned.

Moreover, it is unclear how to keep the most probable hypotheses. To know which hypotheses are the most probable, it is necessary to calculate them. This requires calculating all hypotheses, which is intractable.

Additionally, the agent maintains a set of hypotheses at the beginning of the session. During operation, the agent received observations that may indicate that the true hypothesis was pruned. The agent cannot know whether the true hypothesis was pruned with a high probability since the probabilities of the pruned hypotheses are not calculated.

The un-normalized marginal belief
\tilde{b}_{k}\left[X_{k}\right]
(
21
), can be approximated by marginalizing over a subset of hypotheses
\bar{\mathcal{C}}\subset\mathcal{C}
, which reduces complexity but introduces large estimation errors.
Our approach allows us to avoid such an estimation and query it explicitly.

IV-A
3
Importance Sampling

Important sampling (IS) is another common practice for estimating expectations. IS has two main problems in this setting.
First, finding a suitable proposal distribution is challenging.
Secondly, to calculate the importance ratio, we must compute the normalized belief and therefore the normalization factor
\eta_{1:k}
.

Since, in general the expectation of
X_{k}
is intractable, the normalization factor is also intractable. In this case the normalization factor can be approximate. One popular approximation is self-normalized importance sampling (SNIS), where samples obtained from the proposal distribution are used both for estimating the expectation and the normalization factor. The estimation mean square error (MSE) of SNIS is slightly larger than IS since the normalization factor is approximated
[
49
]
.

Identifying an appropriate proposal distribution
q(X_{k},C)
that is easy to sample and provides accurate estimation is very challenging
[
50
]
. The mean square error (MSE) of the IS and SNIS estimators are dependent on the proposal distribution, hybrid belief, and rewards. Generally the MSE calculation is intractable.
Yet, Theorem
V.5
will show that under certain assumptions, the MSE of IS can be bound from below by a bound that is exponential in the number of objects.

In comparison, if we could draw samples directly from the hybrid belief, the MSE would be exponentially smaller. Our approach empirically achieves accuracy similar to sampling from the original belief (see section
VI
).

Additionally, utilizing RBPF
[
51
]
requires marginalizing over
C
, which is computationally impractical.

IV-B

Explicit Expectation over
C

In an ambiguous environment, to ensure the agent operates safely and accurately, it is necessary to consider many states and possible hypotheses. In the case of sparse semantic probability
b_{k}[C]
, it is possible that the agent will be required to consider many hypotheses and will not be able to prune a significant number of hypotheses while maintaining the required level of accuracy and safety.

This motivates us to consider computing the value function (
18
) with an explicit expectation of
C
, i.e. considering
all
the hypotheses explicitly. There are, however, two principal difficulties associated with this challenge.
First, going through all the hypotheses is computationally prohibitive.
Secondly, samples of
X_{k}
are still required, which is computationally very costly if possible (see Section
IV-A1
).

In section

\text{MSE}\left(\hat{\mathbb{E}}_{IS}^{\left(X,C\right)}\right)\geq\frac{1}{N^{s}}\left|\mathcal{C}\right|\underset{w}{\text{Var}}\left(\bar{g}\right).

(27)

The proof is provided in appendix
A-C
.

Since
\left|\mathcal{C}\right|
is exponential in
N^{o}
,
the MSE (
27
) is exponential.

For example, if the proposed distribution of
C
is uniform, as
k
increases and more observations are collected, the semantic belief
b_{k}[C]
is expected to be increasingly concentrated around specific hypotheses. Consequently the MSE will increase with the time-step
k
.

As a consequence of Theorem
V.5
, any proposal distribution should be evaluated in terms of estimation MSE, since scenarios with proposal distribution that fulfill Assumptions
V.2
-
V.4
, will result in exponential MSE.
Estimators with exponential MSEs will be highly inaccurate and unreliable. In such a scenario, reducing the MSE to a reasonable level will require an exponential number of samples.

In contrast, by using a proposal distribution of the form

q(X_{k},C)=q(X_{k})\tilde{b}_{k}\left[C\mid X_{k}\right]
estimation accuracy can be improved.
According to
[
50
]
, the MSE of SNIS is proportional to the variance of the importance weights.
The importance weights for the above proposal distribution are given by

\omega_{\text{IS}}(X_{k},C)=\frac{\tilde{b}_{k}\left[X_{k},C\right]}{q(X_{k},C)}=\frac{\tilde{b}_{k}\left[X_{k}\right]}{q(X_{k})}.

(28)

Since
\tilde{b}_{k}\left[C\mid X_{k}\right]
does not affect importance weights, they do not increase the MSE.
Furthermore, following Theorem
V.5
and bounding the MSE from below using inequality (
57
), then the bound on the MSE using our proposal distribution

q(X_{k},C)=q(X_{k})\tilde{b}_{k}\left[C\mid X_{k}\right]

will be

\text{MSE}\left(\hat{\mathbb{E}}_{IS}^{\left(X,C\right)}\right)\geq\frac{1}{N^{s}}\underset{b_{k}\left[C\right]}{\text{Var}}\left[\bar{g}\right].

(29)

In this case the MSE is not exponential and therefore exponentially smaller than in Theorem
V.5
.

Computing
\omega_{\text{IS}}
for our proposal distribution involves querying
\tilde{b}_{k}\left[X_{k}\right]
, which is only possible using Theorem
V.1
, otherwise, the computational cost is exponential.
A reasonable proposal distribution candidate for
q(X_{k})
would be
b^{g}_{k}\left[X_{k}\right]
, since it already incorporates geometric history. This resulted in
\omega_{\text{IS}}=\Phi\left(X_{k}\right)
.

V-B

Structured State Dependent Reward

To increase estimation accuracy, instead of taking samples of
C
, we can compute the expectation over
C
explicitly. The Rao-Blackwell theorem
[
31
]
states that this will improve the estimation accuracy. Furthermore, because all semantic mappings are taken into account in the expectation, the true semantic mapping is considered.

Methods developed in this section are applicable to open-loop planning and policy evaluation, i.e. for any given policy. Extending these results to closed-loop planning is left for future work.

Theorem V.6

(Rao-Blackwellization for Sampled Based Estimations)
.

Let
X
and
C
be random vectors, with the joint probability density function
b\left[X,C\right]
, domain
\mathcal{X}\times\mathcal{C}
, marginal density
b[X]
and conditional
b\left[C\mid X\right]
.
Let
\left\{X^{(i)},C^{(i)}\right\}_{i=1}^{N^{s}}
be a set of
N^{s}
independent and identically distributed (iid) samples drawn from
b\left[X,C\right]
.
Let
g:\mathcal{X}\times\mathcal{C}\to\mathbb{R}
be a function from
\mathcal{X}\times\mathcal{C}
to the real numbers
\mathbb{R}
.
Define an estimator of
\mathbb{E}\left[g(X,C)\right]
using samples

\left\{X^{(i)},C^{(i)}\right\}_{i=1}^{N^{s}}

as follows

\hat{E}^{(X,C)}\left[g\right]=\frac{1}{N^{s}}\sum_{i=1}^{N^{s}}g(X^{(i)},C^{(i)}).

(30)

Define another estimator using only samples

\left\{X^{(i)}\right\}_{i=1}^{N^{s}}

and explicitly calculated expectation over
C\mid X^{(i)}
by

\hat{E}^{(X)}\left[g\right]=\frac{1}{N^{s}}\sum_{i=1}^{N^{s}}\sum_{C\in\mathcal{C}}g(X^{(i)},C)b\left[C\mid X^{(i)}\right].

(31)

Then

\text{MSE}(\hat{E}^{(X)})\leq\text{MSE}(\hat{E}^{(X,C)})
,
with the relation between the MSEs given by

\text{MSE}(\hat{E}^{(X)})=\text{MSE}(\hat{E}^{(X,C)})-\frac{\underset{b[X]}{\mathbb{E}}\left[\underset{b\left[C\mid X\right]}{\text{Var}}\left\{g\left(X,C\right)\mid X\right\}\right]}{N^{s}}.

(32)

Since the variance

\underset{b\left[C\mid X\right]}{\text{Var}}\left(g\left(X,C\right)\mid X\right)

is non-negative, equality holds if and only if the variance is zero for all non-negligible subsets of
\mathcal{X}
.

The proof is provided in Appendix
A-D
.
This is a special case of the Rao-Blackwell theorem for sample based estimators which was added here for the completeness of the mathematical presentation. In this special case, it is possible to calculate a theoretical term for the MSE reduction as shown in (
32
).
In certain special cases that will be discussed later, the Rao-Blackwell theorem can be applied to improve the estimation accuracy of the value function (
14
) or the objective function (
15
). Since all hypotheses are considered in such cases, the true hypothesis is always taken into account. However, when pruning or sampling hypotheses this cannot be guaranteed.

Lemma V.7
.

Let
X_{t},H_{k}
, and
\pi_{k:t-1}
denote the state at time-step
t
, the history at time-step
k
, and future policy sequence, respectively.
Assume that the inner reward function is state-dependent and it is not directly dependent on the policy
r_{t}=r_{t}(X_{t},C)
, or, it is dependent on the action in an open-loop setting. Then the value function can be formulated as follows

V_{k}\left(b_{k},\pi_{k:L}\right)=\underset{\mathbb{P}\left(X_{L}\mid H_{k},\pi_{k:L-1}\right)}{\mathbb{E}}\left[\underset{b_{k}\left[C\mid X_{k}\right]}{\mathbb{E}}\left[\sum_{t=k}^{L}r_{t}\left(\cdot\right)\right]\right].

(33)

The proof of Lemma
V.7
is provided in Appendix
A-E
.

Following Lemma
V.7
, the expected reward of one reward element
\rho_{t}
is given by

\underset{z_{k+1:t}}{\mathbb{E}}\left[\rho_{t}\left(b_{t}\right)\right]=\underset{\mathbb{P}\left(X_{t}\mid H_{k},\pi_{k:t-1}\right)}{\mathbb{E}}\left[\underset{b_{k}\left[C\mid X_{k}\right]}{\mathbb{E}}\left[r_{t}\left(\cdot\right)\right]\right].

(34)

Accordingly, the estimation of (
34
) using samples
\left\{X_{t}^{(i)}\right\}_{i=1}^{N^{s}}\sim\mathbb{P}\left(X_{t}\mid H_{k},\pi_{k:t-1}\right)
and explicit expectation over
C
is given by

\hat{\mathbb{E}}^{(X)}[\rho_{t}(b_{t})]=\frac{1}{N^{s}}\sum_{i=1}^{N^{s}}\sum_{C\in\mathcal{C}}b_{k}\left[C\mid X_{k}^{(i)}\right]r_{t}\left(\cdot\right).

(35)

Since the number of semantic hypotheses is
(N^{c})^{N^{o}}
the computation complexity of (
35
)
is
O\left(N^{s}\cdot(N^{c})^{N^{o}}O_{r}\right)
, where
O_{r}
is the computational complexity of calculating
r
.

The computation of Equations (
33
)–(
35
) is possible only in open-loop or policy evaluation settings, since the expectation applied assumes that the policy sequence
\pi_{k:t-1}
is given. Applying explicit expectation over
C
in a closed-loop setting for policy optimization necessitates generating future observations for all hypotheses, which is computationally infeasible.
Nevertheless, sampling observations without hypothesis pruning (Section
V-A
) remains feasible in a closed-loop setting.

As another major contribution of this study, we show that it is possible to calculate the objective function (
12
) with an explicit expectation over
C
very efficiently, for a special structured reward function. This improves estimation error.

Define
\theta\triangleq\{1,\ldots,N^{o}\}
as the set of all objects’ indexes, and define the following structure of inner reward functions

r_{t}\left(C,X_{t}\right)=\sum_{j=1}^{|\Theta|}\prod_{n\in\theta_{j}}r_{t,j,n}\left(c_{n},X_{t}\right),

(36)

where
{\theta_{j}}
is a subset of the objects’ indexes,

\theta_{j}\subseteq\theta
, and
\Theta
is a set of such subsets.

\Theta
is a subset of the power set of
\theta
,
\Theta\subseteq\mathcal{P}(\theta)
. It is assumed that
|\Theta|
is small,
|\Theta|\ll|\mathcal{P}(\theta)|
.
For simplicity, the number of inner reward elements
r_{t,j,n}
participating in the inner reward function
r_{t}
(
36
) denoted by
N^{\Theta}=\sum_{j=1}^{|\Theta|}|\theta_{j}|
.
The computation complexity of a structured inner reward function is
O_{r}=O(N^{\Theta})
.

Following are special cases of the structured state-dependent reward (
36

\displaystyle r_{t}\left(C,X_{t}\right)

\displaystyle=\sum_{n\in\theta}r_{t,n}\left(c_{n},X_{t}\right),

(37)

\displaystyle r_{t}\left(C,X_{t}\right)

\displaystyle=\prod_{n\in\theta}r_{t,n}\left(c_{n},X_{t}\right),

(38)

) is referred as an additive reward and (

)
as a multiplicative reward.
The additive reward is a special case where

\Theta=\{\theta_{j}\}_{j\in\theta},\;\;\theta_{j}=\{j\}
,
and the multiplicative reward (

)

has only one element:

An example of an additive reward is object search.
Object search refers to a problem in which the robot attempts to find any object of a particular class type.
This can be formulated using the additive reward, where the distance to a specific class type is minimized.
It will be shown that
\mathbb{P}_{\text{safe}}

Theorem V.8
.

Let the reward be of a structured reward function (

The expected reward (

\underset{z_{k+1:t}}{\mathbb{E}}\left[\rho_{t}\left(b_{t}\right)\right]=\\

\hat{\mathbb{E}}^{(X)}[\rho_{t}(b_{t})]=\\

VI
Experiments

Our methods were evaluated using a Python simulation in a synthetic 2D environment. The primary claim is that our method can estimate the objective function, for instance, the probability of safety accurately and efficiently. In contrast, other methods cannot achieve both. To verify this claim, we designed an experiment in which the belief can be calculated analytically without approximations or estimations. Despite this, the expected reward and the probability of safety do not have analytical solutions and are therefore approximated using samples.

To obtain an analytical solution for belief propagation, we assume that all prior probabilities of the continuous variables are Gaussian mixture model (GMM) and that the observation and transition models are linear and Gaussian . For each class type, a different observation model is assumed. The result is a hybrid belief that contains semantic discrete variables
C
and continuous state variables
X_{k}
, all of which are interconnected. In this case, the analytical solution for the propagated belief of
X_{k}
is a GMM, and the GMM weights are the marginal belief of
C
. An analytical solution to belief propagation can be found in
[
53
]
. Due to computational limitations, this solution can be applied only in scenarios with small numbers of objects and classes, since the number of hypotheses is combinatorial.

We considered an open-loop setting in which only predefined action sequences are considered. This setting enables evaluation of objective function estimators in a controlled scenario.

VI-A

Simulation Setting

Our simulated scenario consists of a robot traveling in a 2D environment with scattered objects. The
n
th object is represented by a location
x_{n}^{o}
and a class
c_{n}
. In each simulation, the class and location of each object are chosen randomly according to their respective prior probabilities. Each object also has an unsafe area, defined by its class and centered at the object’s location.

Starting at the origin, the robot either moves according to a predefined sequence of actions (Section
VI-B
),
or it performs planning and chooses the best action sequence from a given set of candidate action sequences (Section
VI-C
).
At each time-step, the robot receives a geometric and a semantic observation from each object.
The geometric observation model is given by

z_{k,n}^{g}=x_{n}^{o}-x_{k}+v_{k,n}^{g}
,
where
v_{k,n}^{g}\sim\mathcal{N}(0,\mathbf{I}\sigma^{2})
and
\sigma^{2}=5
. The semantic observation model is given by

z_{k,n}^{s}=\alpha_{c_{n}}\left(x_{n}^{o}-x_{k}\right)+v_{k,n}^{s}
,
where
v_{k,n}^{s}\sim\mathcal{N}(0,\mathbf{I}\sigma^{2})

and

\alpha_{c_{n}}
is equally spaced between

\alpha_{c_{n}}=0.95
for
c_{n}=1

and

\alpha_{c_{n}}=1.05
for
c_{n}=N^{c}
.
The transition model is given by
x_{k+1}=x_{k}+a_{k}+w_{k}
, where

w_{k}\sim\mathcal{N}(0,\mathbf{I}\sigma^{2}_{x})
,

\sigma^{2}_{x}=0.3
.
The observation noises and the process noise
v_{k,n}^{g},v_{k,n}^{s}
and
w_{k}
, are independent on each other and on noises of different time-steps.

Since the robot has only partial knowledge of the environment represented by the prior probability
\mathbb{P}_{0}(X_{k},C)
, it infers the environment using the observations it receives. Following inference, the robot estimates the probability of safety
\mathbb{P}_{\text{safe}}
and the expected reward.

We compare our estimation methods to the following estimation methods. Samples of
X_{k}
are drawn from the theoretical belief, followed by an explicit expectation over the semantic hypotheses
C
. This estimation method will be referred to as the
theoretical-all-hyp
. This method is the most accurate and we do not claim our method is more accurate. However, this method requires an analytical solution to belief propagation, which is not available in the general case, and it runs explicitly over all hypotheses which is computationally very expensive.

Another method is using a particle filter. For each hypothesis we can consider representing conditional beliefs
b_{k}\left[X_{k}\mid C\right]
, by a particle filter followed by estimation of
b_{k}\left[C\right]
using (
4
) and an explicit expectation over hypotheses
C
. This method does not require an analytical solution for belief propagation. However, the computational complexity of running over all hypotheses remains. Since all hypotheses are explicitly considered, we will refer to this method as
PF-all-hyp
.

To deal with the exponential number of hypotheses, we will modify these two methods by pruning all hypotheses except three. These methods are referred to as
theoretical-pruned
and
PF-pruned
, respectively. These methods will be given an advantage in our experiments by keeping the hypotheses with the highest probability, which is typically not provided.

For our methods, we will consider the MCMC method, where samples from the belief are approximated using the MH algorithm, and SNIS method, in which samples from the geometric belief are drawn from
b_{k}^{g}(X_{k})
and weighted according to (
28
).
These methods will be referred to as
MCMC-Ours
and
SNIS-Ours
, respectively.

Lastly, the geometric and semantic components are considered separately by taking the MAP estimator ,
X_{k}^{MAP}=\underset{X_{k}}{\text{argmax}}\left\{b^{g}_{k}\left[X_{k}\right]\right\}
, followed by the MAP estimator of
C\mid X
,
C^{MAP}=\underset{C}{\text{argmax}}\left\{b_{k}\left[C\mid X_{k}^{MAP}\right]\right\}
. We will refer to this method as
GS-MAP
- geometric semantic MAP.

VII
Conclusions

We present a novel approach for estimating the value and objective functions in hybrid semantic-geometric POMDPs, where observation models and prior probabilities couple the geometric and semantic variables. This coupling causes all semantic variables to be dependent, resulting in a combinatorial number of semantic hypotheses. In this setting, obtaining representative samples of the belief required for estimating the value function and safety probability is highly challenging. Under certain assumptions, the MSE of sample-based estimators will grows exponentially with time. As a key contribution, we develop a novel factorization of the hybrid belief and leverage it to provide two methods for obtaining representative samples that avoid exponential MSE: (1) approximating samples from the theoretical belief using MCMC, and (2) utilizing importance sampling with a proposal leveraging the belief factorization. As another key contribution, we show that under certain assumptions and for specific structured rewards, the expected reward can be computed efficiently with an explicit expectation over
all
possible semantic mappings, further reducing estimation error. We prove that the probability of safety falls under this structured reward class. Our empirical simulations show that our approaches achieve accuracy comparable to exhaustive enumeration of all semantic hypotheses, but with linear rather than exponential complexity. We believe this work paves the way for more reliable and safer autonomous robots that operate in complex semantic-geometric environments.

\intop_{z_{k}^{+}}\intop_{X_{t}}\sum_{C}\mathbb{P}\left(z_{k}^{+}\mid X_{t},C\right)\mathbb{P}\left(X_{t},C\mid H_{k},\pi_{k}^{+}\right)r_{t},

(64)

where the future beliefs
b_{t}\left[X_{t},C\right]
and actions
a_{t}
are defined uniquely by
H_{k}
, the future observations
z_{k}^{+}
, and the policies
\pi_{k}^{+}
. The future beliefs and action can be calculated as by defining the update operator
b_{\tau+1}\triangleq\varphi(b_{\tau},a_{\tau},z_{\tau+1})
. The they are obtained recursively by
a_{\tau}=\pi_{\tau}\left(b_{\tau}\right)
and
b_{\tau+1}=\varphi\left(b_{\tau},a_{\tau},z_{\tau+1}\right)
.
Using chain rule we can refactor the following probability

\mathbb{P}\left(X_{t},C\mid H_{k},\pi_{k}^{+}\right)=\mathbb{P}\left(X_{t}\mid H_{k},\pi_{k}^{+}\right)\mathbb{P}\left(C\mid X_{t},H_{k},\pi_{k}^{+}\right)

(65)

The semantic hypothesis
C
is dependent on
X_{t}
only through the prior probability and the observations that connect between them, therefore,

\mathbb{P}\left(C\mid X_{t},H_{k},\pi_{k}^{+}\right)=\mathbb{P}\left(C\mid X_{k},H_{k}\right).

(66)

By substituting (
66
) into (
64
), we obtain

\underset{z_{k}^{+}}{\mathbb{E}}\left[\rho_{t}\left(b_{t}\right)\right]=\\
\intop_{z_{k}^{+}}\intop_{X_{t}}\sum_{C}\mathbb{P}\left(z_{k}^{+}\mid X_{t},C\right)\mathbb{P}\left(X_{t}\mid H_{k},\pi_{k}^{+}\right)\mathbb{P}\left(C\mid X_{k},H_{k}\right)r_{t}.

(67)

This can be reformulated as follows

\underset{z_{k}^{+}}{\mathbb{E}}\left[\rho_{t}\left(b_{t},a_{t}\right)\right]=\underset{\mathbb{P}\left(X_{t}\mid H_{k},\pi_{k}^{+}\right)}{\mathbb{E}}\left[\underset{b_{k}\left[C\mid X_{k}\right]}{\mathbb{E}}\prod_{\tau=k+1}^{t}\underset{\mathbb{P}_{Z}\left(z_{\tau}\mid X_{\tau},C\right)}{\mathbb{E}}\left[r_{t}(\cdot)\right]\right].

(68)

Using the assumption that
r_{t}
is state dependent, and it is not dependent on the action, or it is dependent on the action but the actions are predetermined in an open loop settings, then it is possible to marginalize the observations.

\underset{z_{k}^{+}}{\mathbb{E}}\left[\rho_{t}\left(b_{t},a_{t}\right)\right]=\underset{\mathbb{P}\left(X_{t}\mid H_{k},\pi_{k}^{+}\right)}{\mathbb{E}}\left[\underset{b_{k}\left[C\mid X_{k}\right]}{\mathbb{E}}\left[r_{t}(\cdot)\right]\right].

(69)

Finally, the value function is the sum of the expected rewards, therefore it can be written as follows

V_{k}\left(b_{k},\pi_{k:L}\right)=\underset{\mathbb{P}\left(X_{L}\mid H_{k},\pi_{k:L-1}\right)}{\mathbb{E}}\left[\underset{b_{k}\left[C\mid X_{k}\right]}{\mathbb{E}}\left[\sum_{t=k}^{L}r_{t}\left(\cdot\right)\right]\right].

(70)

∎

Proof.

).

Using the augmented element (

(72)

Since expectation is a linear operation, we can take the sum in (
72
) out of the expectation and return it latter.
For now, consider that the reward above (
72
) consists of only one element of the sum,

r_{t}\left(C,X_{t}\right)=\prod_{n=1}^{N^{o}}\tilde{r}_{t,j,n}(c_{n},X_{t}).

(73)

Consider the expected reward (
34
)
and using the above inner reward function (
73
), the expected reward can be formulated as follows

\underset{z_{k+1:t}}{\mathbb{E}}\left[\rho\left(b_{t}\right)\right]=\\

\underset{\mathbb{P}\left(X_{t}\mid H_{k},\pi_{k:t-1}\right)}{\mathbb{E}}\sum_{C}\left[\prod_{n=1}^{N^{o}}b_{k}\left[c_{n}\mid X_{k}\right]\tilde{r}_{t,j,n}(c_{n},X_{t})\right].

To simplify notations we will use

Since both

\tilde{r}_{t,j,n}(c_{n},X_{t})

, the expected reward (

) can be reorganized as follows

\underset{z_{k+1:t}}{\mathbb{E}}\left[\rho\left(b_{t}\right)\right]=\underset{\mathbb{P}^{+}(X_{t})}{\mathbb{E}}\left[\prod_{n=1}^{N^{o}}\sum_{c_{n}=1}^{N^{c}}b_{k}\left[c_{n}\mid X_{k}\right]\tilde{r}_{t,j,n}\left(c_{n},X_{t}\right)\right].

If
n\notin\theta_{j}
the augmented element is equal to 1 and the sum in (
75
) result in

\sum_{c_{n}=1}^{N^{c}}b_{k}\left[c_{n}\mid X_{k}\right]\cdot 1
.
Therefore we can simplify (
75
) to

\underset{z_{k+1:t}}{\mathbb{E}}\left[\rho\left(b_{t}\right)\right]=\underset{\mathbb{P}^{+}(X_{t})}{\mathbb{E}}\left[\prod_{n\in\theta_{j}}\underset{b_{k}\left[c_{n}\mid X_{k}\right]}{\mathbb{E}}\left[r_{t,j,n}\left(c_{n},X_{t}\right)\right]\right].

36
)

\underset{z_{k+1:t}}{\mathbb{E}}\left[\rho\left(b_{t}\right)\right]=\underset{\mathbb{P}^{+}(X_{t})}{\mathbb{E}}\left[\sum_{j=1}^{|\Theta|}\prod_{n\in\theta_{j}}\underset{b_{k}\left[c_{n}\mid X_{k}\right]}{\mathbb{E}}\left[r_{t,j,n}\left(c_{n},X_{t}\right)\right]\right].

(77)

\hat{\mathbb{E}}[\rho_{t}(b_{t})]=\\
