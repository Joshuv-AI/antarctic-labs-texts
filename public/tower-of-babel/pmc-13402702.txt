FC-FTCP: a lightweight fault-tolerant clustering protocol for secure IoT data transmission
Authors: M Jalasri, Mageshkumar Nagappan, Mamoon Rashid, Sultan S Alshamrani, Kaled M Alshmrany, Neha Singh
Published: 2026

ABSTRACT
AbstractInternet of Things (IoT) plays a vital role in various applications, enabling device-level communication. However, challenges such as unauthorized access, latency, and data breaches require efficient and secure solutions. This paper proposes a Fog Computing-based Fault - Tolerance Clustering Protocol (FC-FTCP) integrated with lightweight cryptography and Off-the-Record (OTR) authentication to enhance data security and transmission reliability in IoT environments. The FC-FTCP protocol supports decentralized data processing and fault-tolerant routing to reduce delays and improve energy efficiency. Simulation results demonstrate that FC-FTCP achieves an efficiency ratio of 98.45%, accurate data authentication at 95.12%, reduced network overhead (21.19%), lower latency (15.13%), computational overhead of 9.5 ms, and reduced computational cost (23.12%). Compared with existing protocols such as FEA-SDTS, HLSF, DIoTA, and CMANET-IoTIF, FC-FTCP shows consistent improvements in secure data handling and resource optimization, making it suitable for low-power IoT deployments.Keywords: Internet of things, Fog computing, Lightweight cryptography, Off-the-record-message, Fault tolerance, Clustering protocolSubject terms: Engineering, Mathematics and computing

Experimental setup and simulation environment

The Contiki operating system and Cooja simulator were used for the performance analysis of FC-FTCP in this work which is widely used for IoT and wireless sensor network simulations. The experiment includes 50 IoT nodes designed as resource-constrained devices similar to low-power MSP430-based hardware. Within the simulation area, nodes are deployed randomly and clustered in groups due to closeness and residual energy. The low-power MAC protocol implemented is in accordance with IEEE 802.15.4 communication model. A uniform configuration of radio parameters, including transmission range, data rate, and size of the packet, is done at all nodes. The traffic model has a periodic manner of data generation where the sensor nodes will transmit the data to the cluster heads that will send the summarized data further down to the fog nodes. The network under evaluation is examined for its scalability and performance under varied nodes.

The fault tolerance of nodes is evaluated by forcing nodes to run out of energy and communication interruption. Nodes that are abnormal in behavior are detected and handled using re-clustering. In order to conduct a fair comparison, the existing schemes of FEA-SDTS, HLSF, DIoTA, and the CMANET-IoTIF are carried out in identical simulation conditions in terms of network size, traffic pattern and energy configurations presented in Tables 3, 4 and 5. For each simulation, we run multiple independent executions with different random seeds. We take the average and standard deviation of all results. The evaluation considers the performance metrics which include latency, energy consumption, computation overhead, and network lifetime. Each experiment was performed several times with different random seeds from which we report the averages along with the observed variance.

Conclusions

This paper presented FC-FTCP, a lightweight and fault-tolerant clustering protocol designed to enhance secure data transmission in IoT-enabled networks through the integration of fog computing and Off-the-Record (OTR) authentication. The proposed approach improves network efficiency, reduces latency and overhead, and strengthens data security using resource-efficient cryptographic techniques. Simulation results demonstrated that FC-FTCP demonstrates improved performance compared to existing models under the evaluated conditions in several key performance metrics, making it a viable solution for real-world IoT applications. In FC-FTCP, the decentralized computer framework is used in data management at various logical sites. FC-FTCP offers different cloud-based applications for the open network and solutions to security issues. Small fingerprint encryption and restricted computational complexity encryption function. Fog Computing intends to apply encryption systems to limited net-works and obtain their international standards. The encryption strategy employs a user authentication method based on OTR. OTR authenticates users and prevents unwanted access, and ensures confidentiality and fairness of data. In addition, the protocol transmits the data using a fault-tolerant clustering mechanism lifetime maximization. The protocol essentially starts the journey from source to destination by reducing the overhead network and making the lifespan maximal. Thus, the experimental results show the FC-FTCP to high efficiency 98.45%, accurate data authentication 95.12%, less network overhead 21.19%, low latency 15.13%, computational overhead 9.5ms reduced total computational cost 23.12%, and secure data transmission 96.19% when compared to other methods. These enhancements aim to further improve the protocol’s robustness and applicability across diverse IoT environments. However, the evaluation discussed so far takes place in simulation environments and, when deployed in the real world, can experience complications like hardware diversity, dynamic network conditions, and long-term key management. We will deal with these issues in the future.
