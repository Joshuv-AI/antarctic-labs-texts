Real-time measurement error mitigation for one-way quantum computation
Tobias Hartung, Stephan Schuster, Joachim von Zanthier, Karl Jansen

Abstract
We propose a quantum error mitigation scheme for single-qubit measurement errors, particularly suited for one-way quantum computation. Contrary to well established error mitigation methods for circuit-based quantum computation, that require to run the circuits several times, our method is capable of mitigating measurement errors in real-time, during the processing measurements of the one-way computation. For that, an ancillary qubit register is entangled with the to-be-measured qubit and additionally measured afterwards. By using a voting protocol on all measurement outcomes, occurring measurement errors can be mitigated in real-time while the one-way computation continues. We provide an analytical expression for the probability to detect a measurement error in dependency of the error rate and the number of ancilla qubits. From this, we derive an estimate of the ancilla register size for a given measurement error rate and a required success probability to detect a measurement error. Additionally, we also consider the CNOT gate error in our mitigation method and investigate how this influences the probability to detect a measurement error. Finally, we show in proof-of-principle simulations, also considering a hardware noise model, that our method is capable of reducing the measurement errors significantly in a one-way quantum computation with only a small number of ancilla qubits.

IV
Mitigating projection errors in a OWQC with error-free CNOT operations

On the lowest level of a one-way quantum computation (OWQC), we are working with graph states of two qubits which are in the state

\ket{\psi}_{TC}=\ket{\alpha}\otimes HR_{Z}(\alpha)\ket{+}+\ket{-\alpha}\otimes XHR_{Z}(\alpha)\ket{+}.

(5)

The qubit in the state
\ket{\pm\alpha}
is the target
T
for the projective measurement in the
\ket{\pm\alpha}
-basis and the second qubit is used further in the quantum computation. This continuation qubit
C
needs to be in the state
HR_{Z}(\alpha)\ket{+}
which implies that a measurement of
T
in
\ket{-\alpha}
requires an additional
X
-gate operation. Hence, we need to reliably identify the state
C
was projected into. Without projection errors,
T
would be in the state
\ket{b}
after measurement, and the
X
-gate needs to be inserted if and only if
b=1
. However, with projection errors, there are probabilities of projecting into the false states
\ket{0}\otimes XHR_{Z}(\alpha)\ket{+}
which needs an application of
X
even though
T
is in the
\ket{0}
state, and
\ket{1}\otimes HR_{Z}(\alpha)\ket{+}
which does not need an application of
X
even though
T
is in the
\ket{1}
state. Hence, we cannot identify the state of
C
by only looking at
T
after the measurement has taken place.

Instead, we introduce a verification register
V
, which is initialized in the state
\ket{0\ldots 0}
. Before the measurement of target
T
, we have to initialize the graph state and the verification register
V
in the state:

\begin{split}\ket{\tilde{\psi}}_{TCV}=&\ket{\alpha}\otimes HR_{Z}(\alpha)\ket{+}\otimes\ket{\alpha}^{\otimes\#V}\\
&+\ket{-\alpha}\otimes XHR_{Z}(\alpha)\ket{+}\otimes\ket{-\alpha}^{\otimes\#V}.\end{split}

(6)

Therefore, we have to first rotate
T
back into the computational basis
\{\ket{0},\ket{1}\}
. This is achieved by the unitary
HR^{z}(\alpha)
. Next, we will entangle
T
with the whole verification register
V
by applying
\mathrm{CNOT}
s between
T
and all qubits in
V
. Finally, we rotate all qubits (
T
and
V
) back to the measurement basis
\{\ket{\pm\alpha}\}
, this is achieved by applying
R^{z}(-\alpha)H
to all qubits. The whole unitary to initialize
T+V
in the desired state is thus given by

(R^{z}(-\alpha)H)_{T}(R^{z}(-\alpha)H)_{V}\mathrm{CNOT}(T,V)(HR^{z}(\alpha))_{T},

(7)

from which we obtain the desired state in Eq. (
6
). After the projective measurement of
T
, the verification register is in the state
\ket{\alpha}^{\otimes\#V}
or
\ket{-\alpha}^{\otimes\#V}
and we need to apply an
X
gate if and only if the verification state is
\ket{-\alpha}^{\otimes\#V}
. We may now proceed with measuring each verification qubit in the
\ket{\pm\alpha}
-basis. Note, that if the measurement in the rotated basis is implemented via rotating the qubit into the computational basis and then performing a computational basis measurement, we can simplify the unitary of Eq. (
7
) and integrate it into the measurement process. For this case we simply need to apply
\mathrm{CNOT}(T,V)
before the computational basis measurement of
T
, the register
V
needs then also to be measured in the computational basis. For the measurements in
V
there may again be projection and readout errors. If the readout can be performed separately from the projection, then the readout protocol above means we can exactly identify the state the verification qubit is in after the projective measurement. In this case, the error is purely given by the projection error. If readout cannot be separated, then we only project and measure once and receive a possibly erroneous output that combines readout and projection errors. In either case, there is an effective error rate
r_{\neg b,b}
for incorrectly identifying the state of each verification qubit, and therefore the number of readout shots
N
in the readout-only protocol translates to the size of the verification register
\#V+1=N
in the projection error setup discussed here.

V
Considering CNOT errors in the verification scheme

For simplicity, we will consider pure-state preserving errors. If the
\mathrm{CNOT}
-gate were error-free, then
\mathrm{CNOT}\ket{+}\otimes\ket{0}=\frac{1}{\sqrt{2}}(\ket{0}\otimes\ket{0}+\ket{1}\otimes\ket{1})=\ket{\Phi^{+}}
and
\mathrm{CNOT}\ket{-}\otimes\ket{0}=\frac{1}{\sqrt{2}}(\ket{0}\otimes\ket{0}-\ket{1}\otimes\ket{1})=\ket{\Phi^{-}}
should hold. However, if the
\mathrm{CNOT}
has an error rate
\gamma_{\Phi^{\mp},\Phi^{\pm}}
, then the final state of the verification qubit is

\sqrt{1-\gamma_{\Phi^{-},\Phi^{+}}}\ket{\Phi}^{+}+\sqrt{\gamma_{\Phi^{-},\Phi^{+}}}\ket{\Phi^{-}}

or

\sqrt{1-\gamma_{\Phi^{+},\Phi^{-}}}\ket{\Phi^{-}}+\sqrt{\gamma_{\Phi^{+},\Phi^{-}}}\ket{\Phi^{+}}.

Either way, there is a probability
\gamma
that the verification qubit is in the wrong state. If we add the combined error
r_{\neg b,b}
for projection and readout, then there is a probability of
(1-r_{\neg b,b})(1-\gamma)+r_{\neg b,b}\gamma=1-r_{\neg b,b}-\gamma+2r_{\neg b,b}\gamma
that the state is verified correctly and a probability of
(1-r_{\neg b,b})\gamma+r_{\neg b,b}(1-\gamma)=r_{\neg b,b}+\gamma-2r_{\neg b,b}\gamma
that the state is incorrectly identified.

Hence, if we use a linear
\mathrm{CNOT}
setup, that is, if we
\mathrm{CNOT}
each verification qubit directly with the target qubit, then we are again in the same protocol as the projection-free readout, but we have the larger effective error rate
r_{\neg b,b}+\gamma-2r_{\neg b,b}\gamma
.

If we use a
\log\#V
-deep verification setup, that is, populating the verification register according to the following
S=\log\#V
steps

1:

\mathrm{CNOT}(T,V_{1})

2:

\mathrm{CNOT}(T,V_{2})\mathrm{CNOT}(V_{1},V_{3})

\vdots

S
:

\mathrm{CNOT}(T,V_{2^{S-1}})\prod_{j=1}^{2^{S-1}-1}\mathrm{CNOT}(V_{j},V_{2^{S-1}+j})

then we have accumulating effects of the error
\gamma
to a maximum depth of
\log\#V
.

If we model our erroneous
\mathrm{CNOT}
as via the action of

\displaystyle\mathcal{CNOT}=\begin{pmatrix}1-\gamma_{\Phi^{-},\Phi^{+}}&\gamma_{\Phi^{+},\Phi^{-}}\\
\gamma_{\Phi^{-},\Phi^{+}}&1-\gamma_{\Phi^{+},\Phi^{-}}\\
\end{pmatrix}=1+\Gamma

in propagating the error, then we have depth errors of

\displaystyle\mathcal{CNOT}^{k}=

\displaystyle\sum_{j=0}^{k}{\binom{k}{j}}\Gamma^{j}.

If
\Gamma
is reasonably small, say in the
1\%

\Gamma^{2}
is in the
0.1
‰ range, and so realistically, the propagated error to depth

\displaystyle\mathcal{CNOT}^{\log\#V}\approx 1+\log\#V\ \Gamma.

In other words, a starting error of about

VII
Conclusion

We first introduced a measurement error model that, in contrast to most previous works, makes a clear distinction between errors that occur through the readout apparatus after projecting the qubit during the measurement (readout error) and the actual projection error that occurs during the projection. Note, that for cases were those two error sources are not clearly separable, we can still apply our mitigation method simply by viewing the measurement error as part of the projection error in our model. We then discussed the compensation of the readout error through a voting protocol in great detail and gave theoretical predictions on the number of consecutive readouts for given error rates and its resulting probability to misidentify the post-measurement state, which vanishes quickly with small effort in terms of the readout number. Next, we discussed the compensation of projection errors, by using a register of verification qubits that are entangled with the next to-be-measured qubit in the OWQC. Measuring the to-be-measured qubit as well as all verification qubits, allows then to apply a similar voting protocol as for the readout errors on the measurement outcomes, simply replacing the readout error with the projection error and the number of readouts with the number of measured qubits. Note that, by re-using the verification qubits after each measurement, we require only a constant number of verification qubits depending on the measurement error rates. Finally we showed in proof-of-principle simulations, including a noisy simulation representing the noise of the real ibm quantum hardware ibm_nazca, that our method works and can be used to mitigate measurement errors in real-time during a OWQC.

Derivation of
N(\varepsilon)
in the polynomial approximation

The dependence of
N
on
\varepsilon
is shown in Eq. (
4
) in the main text. In the following, a detailed derivation of this equation is presented.

The regularized incomplete beta function from Eq. (
2
), modelling the misidentification probability, can be written in the polynomial approximation shown in Eq. (
3
) as:

\displaystyle\varepsilon

\displaystyle=I_{r_{\neg b,b}}\left(N-\left\lfloor\frac{N}{2}\right\rfloor,1+\left\lfloor\frac{N}{2}\right\rfloor\right)

(11)

\displaystyle\approx\frac{\Gamma(N+1)}{(N-\left\lfloor\frac{N}{2}\right\rfloor)\Gamma(N-\left\lfloor\frac{N}{2}\right\rfloor)\Gamma(1+\left\lfloor\frac{N}{2}\right\rfloor)}r_{\neg b,b}^{N-\left\lfloor\frac{N}{2}\right\rfloor}

\displaystyle=\frac{N!}{(N-\left\lfloor\frac{N}{2}\right\rfloor)!(\left\lfloor\frac{N}{2}\right\rfloor)!}r_{\neg b,b}^{N-\left\lfloor\frac{N}{2}\right\rfloor}

\displaystyle={\binom{N}{\left\lfloor\frac{N}{2}\right\rfloor}}r_{\neg b,b}^{N-\left\lfloor\frac{N}{2}\right\rfloor}

Assuming that
N
is an odd number, since the voting protocol would be indefinite otherwise, we can write the floor function
\lfloor N/2\rfloor
as:

\left\lfloor\frac{N}{2}\right\rfloor\underset{N\text{ is odd}}{=}\frac{N-1}{2}

The binomial coefficient in Eq. (
11
) can thus be simplified as follows, using Stirling’s approximation for factorials
n!\approx\sqrt{2\pi n}(n/e)^{n}
:

\displaystyle\binom{N}{\frac{(N-1)}{2}}

\displaystyle=\frac{N!}{\frac{N-1}{2}!\frac{N+1}{2}!}=\frac{N!}{\left(\frac{N+1}{2}!\right)^{2}\frac{2}{N+1}}

\displaystyle=\frac{N!(N+1)}{\left(\frac{N+1}{2}!\right)^{2}\cdot 2}\approx\frac{4^{\frac{(N+1)}{2}}}{\sqrt{2\pi(N+1)}}

This yields a compact approximation for the misidentification probability:

\varepsilon\approx\frac{(4r_{\neg b,b})^{\frac{N+1}{2}}}{\sqrt{2\pi(N+1)}}

(12)

In order to invert this function
\varepsilon(N)
for a given fixed
r_{\neg b,b}
and thus find
N(\varepsilon)
we can use the Lambert
W
-function. This function is defined as the inverse of
ye^{y}
,

ye^{y}=z\,\Leftrightarrow\,W(z)=y\quad\forall y,z\in\mathbb{R},\,z\geq-\frac{1}{e}.

First, we will rewrite Eq. (
12
) in the form

(2\pi)^{-1}\varepsilon^{-2}=(N+1)R^{-(N+1)},

with
R=4r_{\neg b,b}
. Next, we apply
R^{x}=e^{x\ln(R)}
and find the required form to use the Lambert
W
-function

\displaystyle-\frac{\ln(R)}{2\pi\varepsilon^{2}}

\displaystyle=-(N+1)\ln(R)e^{-(N+1)\ln(R)}

\displaystyle\Rightarrow N(\varepsilon)

\displaystyle=\frac{-W(-\frac{\ln(R)}{2\pi\varepsilon^{2}})}{\ln(R)}-1

(13)

Note that, the argument of the Lambert
W(z)
has to fulfill
z\geq-1/e
. Since
z=-1/e
is the global minimum of
z=ye^{y}
. This is fulfilled for any
\varepsilon
if
r_{\neg b,b}\leq 0.25
,

\ln(R)=\ln(4r_{\neg b,b})\leq 0\,\Leftrightarrow\,r_{\neg b,b}\leq 0.25.

For higher measurement errors, the polynomial approximation of the incomplete, regularized beta function deviates significantly from the exact function. In this case, other methods to extract the required
N
for a given
\varepsilon
can be employed, e.g., iteratively calculating
\varepsilon
from
