ProtoSAM for automated one shot medical image segmentation using foundational models
Authors: Lev Ayzenberg, Raja Giryes, Hayit Greenspan
Published: 2025

ABSTRACT
AbstractThis work presents an advance in one-shot medical image segmentation, where a single image-label sample from a new site is used for finetuning the solution - particularly valuable in scenarios where labeled data is scarce or rapid adaptation to new classes and sites is required. We introduce ProtoSAM, a novel, fully automated framework, for one-shot medical image segmentation that combines Prototypical networks, known for few-shot segmentation, with the Segment Anything Model (SAM), a natural image foundation model for segmentation. The proposed method creates an initial coarse segmentation mask using the ALPnet prototypical network, augmented with a DINOv2 encoder. Following the extraction of an initial mask, prompts are extracted, such as points and bounding boxes, which are then input into SAM. We present extensive validation on multiple datasets including CT, MRI, and endoscopy images, demonstrating state-of-the-art results in many scenarios. Our results show that an untrained ProtoSAM can match or exceed the performance of existing one-shot trained methods, with further improvements possible through self-supervised finetuning of the encoder. Our code is available at: https://github.com/levayz/ProtoSAM/.Keywords: Foundational Models, One Shot, SegmentationSubject terms: Anatomy, Health care, Engineering

Introduction

Deep learning models are now the go-to method for segmenting medical images. However, using these models usually requires a large set of manually labeled data, which is expensive and time-consuming. Additionally, these models struggle with new categories they have not seen before, requiring more training and adjustments. In the supervised setting of medical image segmentation, deep learning models are trained to predict labels for each pixel in the input images. This process typically starts from scratch for each new task, requiring extensive annotated datasets. Few-shot segmentation (FSS) has been introduced as a solution to these problems. FSS trains the model to learn from just a few labeled examples, reducing the need for large, manually labeled datasets. Thus it offers a more practical solution in this context, enabling models to perform well with limited annotated data, typically referred to as the support set. Prototypical Networks (PN)1 are widely used for FSS. These networks use prototypes, which represent the key features of different classes, to make predictions based on similarity. They focus on exploiting representation prototypes of semantic classes extracted from the support set.

Another important approach to segmenting medical images involves the use of Foundational models. Foundational models are large-scale, pre-trained models that serve as a base for various downstream tasks, have shown impressive performance on natural images, making their adaptation to medical domains an important research direction. DINOv22 is a foundational model in self-supervised learning (SSL) that is based on a vision transformer architecture (ViT3) and provides improved representation compared to prior models. The Segment Anything Model (SAM)4 is another foundational vision model, that demonstrated strong segmentation capabilities on natural images. This model was trained on a curated dataset of 1B masks and 11M natural images and supports fully automatic and prompt-based segmentation.

In this work, we introduce ProtoSAM, a framework that combines the strengths of both approaches. ProtoSAM integrates Prototypical Networks with DINOv2 and SAM to enable one shot medical image segmentation. Our approach uses DINOv2 as a feature extractor for the prototypical network to generate an initial segmentation mask, from which we extract prompts to guide SAM toward a more precise segmentation. A novel approach that combines Prototypical Networks with the Segment Anything Model (SAM) for one shot medical image segmentation in an automatic manner (requiring no user interaction).

Related works

Recent advances in medical image segmentation have explored several techniques that aim to reduce reliance on extensive labeled datasets. Semi-supervised learning with contrastive techniques has emerged as a promising direction. SimCVD5 presents a contrastive distillation framework that predicts object boundaries in medical images using two views created with dropout masks - a simple but effective approach that achieves performance comparable to fully supervised methods with much less labeled data. The ACTION6 framework and its improved version ACTION++7 introduce anatomical contrastive learning approaches that effectively handle medical images with unbalanced class distributions, using specialized sampling techniques and adaptive learning strategies to improve segmentation performance with limited labeled data. CVRL8 introduces voxel-wise and dimensional contrastive learning strategies that capture rich spatial representation.

FSS approaches using Prototypical Networks have shown promising results in medical imaging. One notable approach is ALPNet9,10 which introduces two key innovations. First, its Adaptive Local Prototypes Pooling (ALP) module, captures fine details in medical images. Second, they utilize superpixels as pseudo-labels for training without annotations. Several works have adopted this superpixel-based training approach, including11–13.

In parallel to these developments, foundation models have emerged as a powerful approach. Extending the foundation model concept mentioned earlier, researchers have begun adapting SAM to address challenges specific to medical imaging. Several works have adapted SAM for the medical domain. Recently, MedSAM14 was introduced, which finetuned the SAM model for medical images on over 1 million image-mask pairs across 15 different modalities. Yet, unlike our work, MedSAM requires user specified bounding box prompts per image. In Zhang et. al.15 they comprehensively review SAM’s applications in medical image segmentation, noting that while SAM’s zero-shot performance varies significantly across different medical datasets, it generally struggles with irregular shapes, weak boundaries, and small structures common in medical images. To address the need for manual prompts, several auto-prompting strategies have been proposed, including localization-based approaches using detection models (e.g., YOLOv816), learning-based methods that train auxiliary prompt encoders such as AutoSAM17, and uncertainty-based techniques (EviPrompt18, UR-SAM19). However, these approaches either require supervised finetuning or still face challenges in generalization across different medical modalities or show a significant performance gap to SAM with manual prompts.

More recently, Segment Anything Model 2 (SAM 2)20 has been introduced to extend SAM’s capabilities to video domains, offering prompt-based segmentation for both images and videos. Ma. J. et al.21 conducted comprehensive experiments evaluating SAM 2 across 11 medical image modalities, including various 2D and 3D images and videos. Their evaluation protocol requires bounding box prompts for each 2D image. For 3D volumes, a bounding box is needed on the middle slice to initialize segmentation before propagating to the remaining slices. It was demonstrated that SAM 2 improves 3D medical image segmentation compared to slice-by-slice approaches, yet it still lags behind domain-specific models like MedSAM in most 2D medical image tasks. Overall, this approach, while effective, still necessitates subject-specific prompts for each new scan or volume. Building on SAM 2, Zhu et al.22 introduced Medical SAM 2 (MedSAM-2), a generalized auto-tracking model for universal 2D and 3D medical image segmentation. MedSAM-2 relies on initial prompts in at least one image or slice to propagate segmentation to subsequent frames. While MedSAM-2 represents an important advance in medical image segmentation using foundation models, it addresses a different use case than our few-shot learning approach. In contrast to these recent approaches, our presented method requires only a single support image and mask pair, which can then be applied to segment multiple different subjects and scans without additional manual prompting.

Methods

Given that ProtoSAM leverages foundational models like SAM and DINOv2 which are inherently designed for 2D images, we adopt a 2D slice-by-slice segmentation approach even for volumetric data (CT, MRI). Extending these large models to 3D would require substantial architectural changes and computationally prohibitive retraining. Consequently, our comparisons, including those with nnU-Net, are also conducted using their 2D configurations (e.g., nnU-Net 2D) to ensure a fair comparison basis focused on the contribution of the foundational models and the prototype mechanism in the one-shot setting. Final segmentation

The prompts of the previous stage are fed into the Segment Anything Model (SAM) which produces the final finer segmentation map.

Encoder finetuning (EFT)

To enhance performance, it is possible to finetune the DINOv2 encoder on the target modality. For that, we employ the ALPNet framework9. We emulate test-time scenarios by constructing episodes, comprised of a support set and a query set. We explore two approaches for encoder finetuning (EFT): In one approach, we utilize the method proposed in Ouyang, C. et. al9 that uses Felzenszwalb superpixels (EFT-SP)24. In a second approach, we propose to leverage SAM’s automatic segmentation capabilities to generate masks (EFT-SAM). For EFT-SP, a preprocessing step is taken, where we generate superpixels using Felzenszwalb24 for all the available slices. For EFT-SAM, we utilize SAM’s automatic mask generation for each slice to create segmentation masks that serve as pseudo-labels. Implementation details

For MRI scans, we first mitigated off-resonance effects by truncating the top 0.5% of the intensity histogram. The CT and MRI images were then resampled to a unified voxel spacing, and center cropped to 256 × 256 pixels. Each slice was tripled in the channel dimension. During inference, slices were bilinearly interpolated to 672 × 672 during prototype generation, then resized to 1024 × 1024 for the SAM model. For (optionally) finetuning the encoder, we employ the ALPNet9 framework as described in Section "Initial segmentation stage", together with Low Rank Adaptation (LoRA)26. We train for 100k steps with a learning rate of and resize the images to using bilinear interpolation. For EFT on MRI and CT datasets, we divide the organs into two groups: (Spleen, Liver), (RK, LK), where RK and LK represent Right-Kidney and Left-Kidney respectively. When testing on the kidney group, we remove all slices containing kidneys from the training data, even if they contain liver or spleen. Conversely, when testing on the liver/spleen group, we exclude all slices containing either of these organs from training. For EFT on the polyp dataset, we generate a foreground mask to restrict superpixels to meaningful image regions, preventing their formation in the black background areas. For the DINOv2 encoder we use the ‘large’ architecture. We use the SAM ‘huge’ architecture for ProtoSAM, AutoSAM, and SAM models, and the ‘base’ architecture for ProtoSAM-base and ProtoMedSAM.

Results

In this section we describe our experimental setup and results.

Experimental setup

Datasets

We employ two datasets for abdominal organ segmentation, each associated with a different modality (CT and MRI), and four polyp datasets. The first two datasets include (i) Abd-CT: Derived from the MICCAI 2015 Multi-Atlas Abdomen Labeling challenge27, containing 30 3D abdominal CT scans and (ii) Abd-MRI: Sourced from the ISBI 2019 Combined Healthy Abdominal Organ Segmentation Challenge (Task 5)23, comprising 20 3D T2-SPIR MRI scans. The organs used for segmentation are Liver, Spleen, Right Kidney (RK) and Left Kidney (LK). The polyp datasets are: Kvasir-SEG28, ClinicDB29, ColonDB30, and ETIS31. The test splits of each dataset are as follows: 100 images from ClinicDB, 64 from Kvasir-SEG, 380 from ColonDB, 196 from ETIS, following Shaharabany et al.17. SOTA few-shot comparison

Our method was benchmarked against leading methods across different datasets. For the polyp dataset, we compared our model to the SOTA supervised segmentation model, AutoSAM17. This work proposed adding a learnable prompt encoder which generates a prompt for SAM. For fair comparison, we trained AutoSAM with support sets of 1, 5, and 100 images and their masks, before evaluating it. Additionally, we compare our method with PerSAM33, a training-free one-shot segmentation method for personalized object segmentation, which uses cosine similarity between the support set and the query image to extract confidence maps which are utilized for prompt extraction, similar to our method. We note that the out-of-the-box version of PerSAM scores low in the following tasks, demonstrating its limitations when applied directly to medical images. We introduced a modified version of PerSAM, which we refer to as PerSAM-modified in Tables 2 and 4. This adaptation includes dropping the mask and bounding box prompts used in the original version and using only point-based prompts, selecting the first generated mask by SAM (index 0) instead of its automatic mask selection, and replacing its built-in z-score normalization with our medical image processing pipeline. These changes significantly improved its performance compared to the original implementation. We also assessed SAM, using its automatic segmentation mode, and manually selecting its best-performing mask. Additionally, we compared ProtoSAM with both the default DINOv2 encoder and a finetuned version as described in Section "Encoder finetuning (EFT)". Finally, we evaluated the performance of ProtoMedSAM, where we replace SAM with MedSAM in ProtoSAM and use only bounding boxes as prompts, as MedSAM was finetuned on bounding boxes. Table 2 presents results on LK, RK, Spleen and Liver for the CT and MRI dataset, and Table 4 presents results on the polyp datasets.

For completeness we added comparisons to leading fully-supervised methods. For CT we compare to SWIN-UNETR34, a method combining UNET35 with SWIN36 transformers, as well as to nnUNet-2D37, a self-configuring segmentation method that has become a widely used benchmark for medical imaging segmentation tasks. For MRI we compare to MS-dual-guided38, a method that utilizes multi scale features extracted by a ResNet39 network with guided attention, and similarly include comparison to nnUNet-2D37. CT dataset

As shown in Table 2, for CT images, ProtoSAM achieves a mean Dice score of 74.55. When comparing with SSL-based methods, ProtoSAM outperforms SSL-ALPNET+BP (67.62), CRAP-Net (69.72), and CRTPNet (67.31) with notable improvements across most organ regions. In particular, ProtoSAM demonstrates strong performance in the liver region with a Dice score of 86.21, surpassing previous SSL-based methods which achieve scores between 71.44 and 73.16. When compared to foundational models, SAM (best mask) provides better masks than ProtoSAM, indicating that there may be room for improvement in prompt generation. This suggests that while ProtoSAM is promising, further training and refinement could enhance its performance in specific areas. Note though that in SAM, we manually select the best mask out of several candidates produced by SAM, with respect to GT, which is not done in ProtoSAM. Among the foundational adapted methods, ProtoSAM outperforms PerSAM (24.51) and PerSAM-modified (56.61). SSL-DINOv2 (71.44) and SSL-DINOv2+CCA (73.16) demonstrate competitive performance, but its important to note that ProtoSAM didn’t undergo any SSL finetuning. When comparing our model variants, ProtoMedSAM and ProtoSAM-base achieve comparable performance on CT (68.10 and 66.90 respectively), with ProtoMedSAM showing a slight advantage. However, our default ProtoSAM model outperforms both with a mean Dice score of 74.55, which can be attributed to its utilization of the SAM ’huge’ architecture, while ProtoMedSAM uses a finetuned version of SAM with ’base’ architecture. The EFT variants of ProtoSAM, which did undergo SSL finetuning, consistently surpass the SSL-DINOv2 models, and achieve comparable performance overall to SAM (best mask). Compared to fully supervised methods like SWIN-UNETR34, and nnUNET37, there still remains a performance gap.

MRI dataset

When comparing with SSL-based methods, ProtoSAM (80.80) outperforms SSL-ALPNET+BP (76.81), CRAP-Net (73.82), and CRTPNet (75.08) across most organ regions. ProtoSAM shows strong performance in the right kidney and liver regions with scores of 86.27 and 81.36, respectively. These scores are higher than the DINOv2 SSL-based methods which achieve mean scores between 75.16 and 78.43. Compared to foundational models, ProtoSAM substantially outperforms SAM (best mask) (63.01). Among the foundational adapted methods, ProtoSAM outperforms PerSAM (33.12) and PerSAM-modified (62.27), as well as SSL-DINOv2 and SSL-DINOv2+CCA. Similar to CT results, ProtoMedSAM and ProtoSAM-base achieve comparable performance on MRI. By applying the EFT described in Section "Encoder finetuning (EFT)", ProtoSAM+EFT-SP achieves a mean score of 83.94, with particularly strong performance in the left kidney (87.16) and right kidney (89.23) regions. ProtoSAM+EFT-SAM further improves performance to a mean score of 84.11. When comparing to the supervised methods, ProtoSAM and its EFT variants achieve comparable or better performance than MS-Dual-Guided for specific organs like spleen and right kidney, but MS-Dual-Guided (86.75) performs better overall. A more substantial performance gap remains when compared to nnUNET (90.31).

Polyp datasets

Table 4 presents the results of the polyp segmentation benchmarks to compare the performance of ProtoSAM (1-shot) with SAM and AutoSAM (under different shot settings, including training on the full training dataset). The evaluation metrics used are the Dice coefficient and Intersection over Union (IoU). ProtoSAM (1-shot) achieves a mean Dice score of 68.06 and a mean IoU of 60.49 across all datasets. This performance surpasses that of SAM when choosing its best mask with respect to GT. This indicates that our prompt generation process is effective. Observe that ProtoSAM consistently outperforms ProtoMedSAM across all our test cases. Note that the ProtoSAM with SAM-base model provided comparable performance to ProtoMedSAM for MRI and CT but better results for the polyps. We believe the gap stems from the fact that MedSAM was finetuned using bounding boxes derived from ground-truth masks, ensuring high accuracy in the targeted regions. Since the ProtoSAM framework relies on an initial coarse segmentation, the bounding boxes are not as accurate. In contrast, SAM in ProtoSAM employs both bounding boxes and points. Since it was not finetuned with precise bounding boxes, it is more resilient to Bbox noise. When comparing encoder finetuning strategies, Table 4 shows that using EFT-SP led to modest improvements over ProtoSAM, increasing the Dice score to 69.13 and IoU to 61.44. More significantly, our proposed EFT-SAM approach resulted in a 3-point Dice score improvement (71.21) and 3.28-point IoU improvement (63.77) over the baseline ProtoSAM without EFT. This improvement is further supported by the HD95 results in Table 3, where EFT-SAM achieved the best score of 90.61, demonstrating improved boundary accuracy compared to EFT-SP (87.07) and ProtoSAM (92.21). When comparing ProtoSAM (1-shot) to AutoSAM under different shot settings, it is evident that our untrained method achieves better performance using fewer images. Specifically, ProtoSAM (1-shot) outperforms AutoSAM (1-shot) (15.57 Dice, 10.23 IoU), AutoSAM (5-shot) (36.72 Dice, 33.33 IoU), and even AutoSAM (100-shot) (52.87 Dice, 43.08 IoU) in terms of mean Dice and IoU scores, despite using only one image. This highlights the efficiency of ProtoSAM in leveraging pre-trained foundational models to achieve superior segmentation results under few-shot settings, compared to the best supervised framework on these datasets, namely AutoSAM. However, there remains a performance gap between the fully-supervised model and the 1-shot performance of ProtoSAM.

Statistical significance

We compare ProtoSAM, which did not undergo any finetuning or SSL against ALPNet, an SSL model. The p-values were for CT and for MRI. Ablation study

We examined the effects of using different prompt extraction methods. We tested the effects of the prompts on all polyp segmentation datasets and performed five fold cross validation on both the CT and MRI datasets using the ProtoSAM model. Table 6 presents the results of this study. In this table, we compare various combinations of prompts, including centroid (Cent), confidence (Conf), negative (Neg) point, and bounding box (Bbox). Negative points are generated in the same way as Conf points, only for the background class instead of the foreground class. Our findings indicate that the combination of bounding box, confidence, and centroid prompts (Bbox+Conf+Cent) yielded the best performance for the polyp dataset, while bounding box plus confidence (Bbox+Conf) produced optimal results for both CT and MRI datasets and highest overall performance. Notably, we observed that the bounding box (Bbox) is the most crucial component, providing significantly better performance compared to point prompts and their combinations. The addition of other prompts to the bounding box only marginally improved Dice score.

Discussion

In this work we introduce ProtoSAM, a novel automatic framework for one-shot image segmentation. The experimental results demonstrate that the untrained ProtoSAM achieves competitive performance across various organs and modalities, often surpassing previous SSL pre-trained methods. Encoder finetuning further boosts its performance, enabling it to outperform all previous one-shot methods. A key distinction of our approach when compared to SAM, is that ProtoSAM generates segmentation masks for new images using only a single annotated support image. In contrast, SAM requires manual prompts for each new image or generates multiple candidate masks from which users must select. In our comparisons, we report SAM results using manually selected best masks from multiple candidates—an advantage not available in practical applications. ProtoSAM still outperforms SAM in specific anatomical regions, particularly on MRI data where SAM shows a notable performance drop. While SAM’s best mask selection performs well on CT images, our approach demonstrates more consistent performance across both modalities.

The encoder finetuning techniques showed varied effectiveness across different datasets. EFT-SP (using superpixels) substantially improved results for CT and MRI datasets but provided only minor benefits for polyp segmentation. In contrast, EFT-SAM, which utilizes masks automatically generated by SAM, delivered more significant improvements for polyp segmentation while maintaining comparable performance gains to EFT-SP on CT and MRI datasets. This highlights SAM’s potential as a SSL tool, generating high-quality pseudo-labels that can enhance segmentation performance without requiring manual annotations.

Several limitations of the current approach warrant discussion. The method currently selects prompts based on the most confident component of the initial segmentation phase, limiting it to single object segmentation and making it unsuitable for tasks requiring multiple object segmentation without modifications. While ProtoSAM outperforms many existing methods, there are still cases where SAM provides better masks, indicating room for improvement in the prompt generation process. Furthermore, there remains a performance gap between fully-supervised models and ProtoSAM’s one-shot performance, particularly evident in the polyp segmentation results. Furthermore, our evaluation adheres to established protocols in one-shot segmentation literature, which often involve using predefined, representative slices as support images. While this ensures fair comparison with state-of-the-art methods, it represents a limitation for true ’plug-and-play’ practical application where an arbitrary slice might be provided. Future work could explore strategies robust to variations in the support slice selection.

In future work we aim to enhance prompt generation by exploring learning based approaches for prompt extraction, potentially extending ProtoSAM capabilities to multi object segmentation. Further, contrastive learning or meta-learning can be employed to further enhance EFT. We also plan to explore using SAM 2 as our foundation model, which could potentially improve performance. Additionally, exploring methods to automatically select the optimal mask from multiple SAM proposals based on prototype similarity, as suggested during review, presents an interesting avenue for future work to potentially improve performance and reduce reliance on specific prompting strategies. To conclude, ProtoSAM presents a promising novel and generalizable approach to one-shot image segmentation in medical imaging, with potential applications in scenarios where labeled data is scarce or where rapid adaptation to new classes is required.
