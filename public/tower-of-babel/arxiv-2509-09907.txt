Further constructions of square integer relative Heffter arrays
Diane Donovan, Sarah Lawson, James Lefevre

Abstract
A square integer relative Heffter array is an n × n n\times n array whose rows and columns sum to zero, each row and each column has exactly k k entries and either x x or − x -x appears in the array for every x ∈ ℤ 2 ​ n ​ k + t ∖ J x\in\mathbb{Z}_{2nk+t}\setminus J , where J J is a subgroup of size t t . There are many open problems regarding the existence of these arrays. In this paper we construct two new infinite families of these arrays with the additional property that they are strippable. These constructions complete the existence theory for square integer relative Heffter arrays in the case where k = 3 k=3 and n n is prime.

Lemma 2.1
.

If an

\frac{2nk}{n-1}>t

Proof.

Lemma 2.2

If an
