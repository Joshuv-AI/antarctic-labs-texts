GoDe: Gaussians on Demand for Backbone-Agnostic Progressive Compression
Francesco Di Sario, Riccardo Renzulli, Marco Grangetto, Akihiro Sugimoto, Enzo Tartaglione

Abstract
Splat-based radiance fields have rapidly diversified in primitive type, kernel support, and appearance parameterization. This diversity makes compression difficult: most codecs are single-rate, requiring a separately optimized model for each target bitrate, while progressive codecs remain tied to representation-specific assumptions that do not transfer across backbones. We introduce GoDe (Gaussians on Demand), a progressive compression framework whose central contribution is backbone agnosticism : it reorganizes any trained differentiable splat representation into a single scalable bitstream without modifying the backbone or re-deriving the compression structure for each new primitive type. GoDe builds a nested level-of-detail hierarchy via masked-gradient importance ranking, refines all levels with one quantization-aware fine-tuning stage, and stores the base layer and enhancement layers as progressive chunks compressed with shared entropy dictionaries. Any decoded prefix is directly renderable, so one training pipeline provides multiple rate–distortion operating points without per-rate retraining. Across five heterogeneous backbones and three standard benchmarks, GoDe achieves competitive rate–distortion performance while enabling faster rendering and substantially faster progressive decoding than existing methods. Project page: https://gaussians-on-demand.github.io/

Introduction

Novel view synthesis has been transformed by Neural Radiance
Fields
[
28
]
and, more recently, by 3D Gaussian
Splatting
[
20
]
.
Splat-based radiance fields have since diversified rapidly beyond the
original Gaussian formulation, with methods differing in primitive type
[
19
,
16
,
27
]
,
kernel support
[
25
]
, and view-dependent appearance model
[
11
]
.
This diversity improves reconstruction and rendering quality, but it also fragments compression: a codec designed around one set of internal parameters is difficult to transfer to another backbone.
Compression is necessary for deployment, since uncompressed scenes can
occupy hundreds of megabytes.
Most codecs are single-rate
[
3
]
: each memory budget
requires its own optimized model.
This differs from progressive rendering and level-of-detail
methods
[
32
,
9
]
, which reduce the number of
rendered primitives at runtime but do not define a progressively
decodable compressed representation.
For streaming and adaptive storage, the useful object is a bitstream
whose prefixes are valid renderable models.
Progressive compression provides exactly this structure: a base layer can
be decoded first, and enhancement layers refine the same scene
incrementally.
Existing progressive codecs
[
34
,
6
]
achieve strong
rate–distortion results within the Scaffold-GS family, but their entropy context is conditioned on internal anchor feature vectors that have no analog in other primitive types.
As new splat representations continue to appear, tying progressive compression to one specific backbone reintroduces the same fragmentation that motivated compression in the first place. The missing ingredient is a progressive compression structure that operates on primitives as atomic units, without requiring access to their internal parameterization. In this work, we introduce GoDe (Gaussians on Demand), a progressive
compression framework for differentiable splat representations
(Fig.
1
).
The key insight is that three operations are available for any
backbone that supports differentiable rendering: gradient-based
importance ranking, quantization-aware optimization, and serialization
of primitive parameters.
GoDe composes these into a single pipeline that produces a progressive
bitstream from any trained model.
Decoding a level requires only decompressing and concatenating the chunks up to that level: no optimization is performed at decode time.
To apply GoDe to a new backbone, one specifies the primitive grouping
and the quantization rule for each parameter group. GoDe composes gradient-based importance ranking, quantization-aware
fine-tuning, and entropy coding into the first progressive compression
framework that transfers across heterogeneous splat backbones.
The critical design choice is operating at the level of primitives as
atomic units: by requiring only differentiable rendering, parameter serialization, and a lightweight
per-backbone specification of parameter groups, GoDe avoids the representation-specific assumptions that
limit existing progressive codecs to a single backbone family.
One training pipeline produces a full rate–distortion curve; one
compressed file exposes multiple operating points at deployment time. Across five backbones, GoDe provides competitive rate–distortion curves,
fast rendering on explicit representations, and fast progressive decoding.
To summarize, our contributions are:

•

A backbone-agnostic progressive compression framework

for differentiable splat representations, producing multiple decoded
prefixes from a single training pipeline without modifying the
underlying backbone or re-deriving the compression structure per
primitive type.

•

A simple, transferable pipeline
composed of
gradient-informed importance ranking, stochastic quantization-aware
fine-tuning over nested levels, and chunk-based entropy coding with
shared dictionaries.

•

Evaluation across five heterogeneous backbones
,
demonstrating competitive rate–distortion, high rendering speed, and decoding times one to two
orders of magnitude faster than existing methods.

Related Work

Splat-based radiance fields.

3D Gaussian Splatting
[
20
]
achieves real-time novel view
synthesis via differentiable rasterization of anisotropic Gaussian
primitives.
Its success has led to a diverse family of splat representations.
Scaffold-GS
[
27
]
generates Gaussians from neural
anchors, Octree-GS
[
31
]
adds a hierarchical anchor
organization, and Triangle Splatting
[
19
]
replaces
ellipsoidal kernels with flat triangle primitives.
Other works change the local support or the optimization process:
Deformable Beta Splatting
[
25
]
uses bounded
shape-adaptive Beta kernels, while MCMC-based
training
[
22
]
replaces the standard densification
heuristics with a Markov chain sampling strategy for primitive
placement.
Appearance is also representation dependent: classical 3DGS stores
spherical harmonics per primitive
[
14
]
, but alternative representations have
been explored, ranging from neural feature codes decoded by a small
MLP
[
27
]
, to Spherical Voronoi
tessellations
[
11
]
.
These choices are not interchangeable at the parameter level, which is
why compression methods that depend on a particular internal structure
are difficult to reuse across backbones.

Progressive rendering and level of detail.

PRoGS
[
39
]
prioritizes splats by contribution for progressive
streaming.
LapisGS
[
32
]
constructs a layered representation for adaptive
bandwidth rendering.
CLoD-GS
[
9
]
learns distance-dependent opacity decay for smooth
quality scaling from a single model.
Octree-GS
[
31
]
and
Hierarchical-GS
[
21
]
dynamically select the
level of detail at render time based on viewing distance.
These methods adapt which primitives are rendered or at which resolution
a scene is accessed, but they do not define a compressed bitstream in
which each prefix is a valid stored representation.
The distinction matters for deployment: progressive rendering controls
computation at render time, whereas progressive compression controls
storage and transmission before rendering starts.
GoDe is complementary to these approaches and uses Octree-GS as one of
its evaluated backbones (Sec.
4
).

Compression of 3DGS.
Compression of neural scene representations gained prominence already
in the NeRF era, where hybrid explicit-implicit models
[
29
,
33
,
5
]
traded memory efficiency for rendering speed, motivating early compression work targeting their explicit components
[
10
,
12
]
.
The shift to splat-based representations renewed these concerns at larger scale.
A large body of work addresses single-rate compression of splat-based representations, including pruning-based methods
[
17
,
13
]
,
entropy coding approaches
[
7
,
8
,
36
,
38
,
24
,
2

serve as per-rate reference points in our evaluation. They all share the
same assumption: the optimized output corresponds to one point on the
rate–distortion curve, and supporting multiple budgets requires training
and storing multiple models independently.

Progressive 3DGS compression.

PCGS
[
6
]
builds on HAC++
[
8
]
and Scaffold-GS to
achieve scalable compression via an anchor hierarchy, progressive
quantization, and a cross-level entropy context conditioned on anchor
feature codes.
CSGaussian
[
34
]
pursues scalable progression with an
additional semantic segmentation objective and is therefore not directly
comparable to our radiance field compression setting.
Both methods achieve strong rate–distortion results within the
Scaffold-GS family.
Their strongest component (the entropy context conditioned on anchor
feature vectors) is also the least transferable: explicit Gaussians,
Beta kernels, Spherical Voronoi appearance, and triangle primitives do
not expose the same feature structure, so the context model has no
direct analog outside the anchor family.
GoDe takes the complementary approach: by relying only on gradient
magnitudes, simulated quantization, and dictionary-based entropy coding, it only requires differentiable rendering of primitive subsets, serializable
per-primitive parameters, and a per-backbone specification of parameter groups
and quantization rules.

3
Method

Figure 2
:
GoDe pipeline.
From a trained representation:
(1) primitives are organized into a nested LoD hierarchy via
iterative gradient-informed ranking; (2) all LoDs are jointly
fine-tuned under simulated quantization, sampling one LoD per
iteration; (3) the base layer and each enhancement layer are
entropy-coded as independent chunks.

GoDe takes a trained splat-based representation and produces a single
progressive bitstream from which any prefix can be decoded and rendered
directly, without retraining or re-optimization.
The pipeline has three stages (Fig.
2
).
First, primitives are ranked by gradient-informed importance and
organized into a nested level-of-detail hierarchy, so that each coarser
level is a strict subset of every finer one
(Sec.
3.1
).
Second, all levels are jointly fine-tuned under simulated quantization
in a single training stage, adapting the shared parameters to every
decoded prefix at once (Sec.
3.2
).
Third, the base layer and each enhancement layer are entropy coded as
independent chunks; decoding a level requires only concatenating the
chunks up to that level (Sec.
3.3
).
The pipeline treats primitives as atomic units and requires only a
differentiable renderer that supports rendering subsets of primitives,
a serializable per-primitive parameterization, and a per-backbone
specification of parameter groups and their quantization rules.
These requirements are met by all splat backbones we consider, which
allows the same procedure to transfer across them.

3.1
Progressive Hierarchy Construction

Let
\mathcal{S}=\{p_{i}\}_{i=1}^{N}
denote the set of
N
primitives
of the trained model, each with parameters
\theta_{i}
.
GoDe constructs a sequence of
L
nested subsets

\mathcal{G}_{0}\subset\cdots\subset\mathcal{G}_{L-1}\subseteq\mathcal{S}
,
where
\mathcal{G}_{0}
is the base layer and each finer level

\mathcal{G}_{l}
extends the previous one by a disjoint enhancement
layer
\mathcal{E}_{l}=\mathcal{G}_{l}\setminus\mathcal{G}_{l-1}
:

\mathcal{G}_{l}=\mathcal{G}_{0}\cup\bigcup_{j=1}^{l}\mathcal{E}_{j},\quad l=1,\dots,L-1.

(1)

This decomposition guarantees that decoding level
l
requires only
the first
l{+}1
chunks, each carrying primitives not present in any
coarser level, with no primitive transmitted twice.
Level sizes follow a geometric progression,

n_{l}=\left\lfloor n_{\min}\left(n_{\max}/n_{\min}\right)^{l/(L-1)}\right\rfloor,\quad l=0,\dots,L-1,

(2)

with
n_{\min}=|\mathcal{G}_{0}|
and
n_{\max}=|\mathcal{G}_{L-1}|\leq N
.
A geometric schedule yields smaller absolute increments at low rates,
where additional primitives typically provide larger marginal quality
gains, and larger increments at high rates, where the rate–distortion
curve typically flattens. The hierarchy is built top-down, starting from the full model.
At each step, parameters are frozen and the gradient of the
photometric loss with respect to each primitive’s parameters is
accumulated over all training views. Let

g_{i}^{(m)}=\|\partial\mathcal{L}/\partial\theta_{i}^{(m)}\|_{2}
denote
the gradient norm for parameter group
m
of primitive
p_{i}
. Since
different groups have different dimensionalities and numerical
scales, directly summing
g_{i}^{(m)}
can make one group dominate the
ranking. We therefore normalize each group by its root-mean-square
gradient over the current active set
\mathcal{A}
:

r_{m}=\max\!\left(\epsilon,\sqrt{\frac{1}{|\mathcal{A}|}\sum_{p_{j}\in\mathcal{A}}\left(g_{j}^{(m)}\right)^{2}}\right),\qquad s_{i}=\sum_{m}\frac{g_{i}^{(m)}}{r_{m}},

(3)

where
\epsilon>0
is a small numerical constant.
The sum runs over all parameter groups of
p_{i}
. Including all groups is
important because a primitive can be critical through geometry, opacity,
kernel shape, or appearance; restricting the score to a single group
risks discarding primitives that are negligible in one attribute but
essential in another. The normalization places the group-wise scores on
comparable empirical scales before aggregation.
We first evaluate Eq. (
3
) on the full model and set

\mathcal{G}_{L-1}=\{p_{i}\in\mathcal{S}:s_{i}\geq\tau\}
with

\tau=10^{-12}
, used as a numerical cutoff for near-zero importance.
Thus,
n_{\max}=|\mathcal{G}_{L-1}|
is scene-adaptive by removing only
primitives with numerically zero importance. Starting from

\mathcal{G}_{L-1}
, we then iteratively remove the least important
primitives to obtain each coarser level.
At level
l
, we remove the
n_{l}-n_{l-1}
primitives with the lowest

s_{i}
and assign them to the enhancement layer
\mathcal{E}_{l}
, yielding

\mathcal{G}_{l-1}=\mathcal{G}_{l}\setminus\mathcal{E}_{l}
.
After each masking step, gradients are recomputed on the updated
active set before proceeding to the next coarser level.
Each step requires one gradient-accumulation sweep with no optimizer
update, so building the full
L
-level hierarchy takes approximately

1
–
2
minutes.

3.2
Quantization-Aware Multi-Level Fine-Tuning

Once the hierarchy is fixed, GoDe maintains a single global set of
primitive parameters
\Theta=\{\theta_{i}:p_{i}\in\mathcal{G}_{L-1}\}
.
Each level
\mathcal{G}_{l}
renders the corresponding subset of

\Theta
; whenever a primitive appears in multiple levels, its
attributes are shared rather than stored or optimized separately for
each LoD. Fine-tuning must therefore adapt these shared parameters to
perform well across all decoded prefixes and under the quantization
applied at coding time. A straightforward approach would accumulate the loss over all
L

levels at each iteration, but this requires
L
forward–backward
passes per step and makes training cost grow linearly with
L
.
Instead, GoDe samples one level

l\sim\mathrm{Uniform}\{0,\dots,L-1\}
and one training view
(c,I_{c})

per iteration, where
c
denotes the camera and
I_{c}
its reference
image. It renders only
\mathcal{G}_{l}
with quantized parameters and takes one stochastic gradient step toward the objective

\min_{\Theta}\;\mathbb{E}_{l,c}\big[\mathcal{L}\big(\mathcal{R}(c,Q(\Theta_{l})),I_{c}\big)+\lambda\|\Theta_{l}^{(a)}\|_{1}\big],

(4)

where
\Theta_{l}=\{\theta_{i}:p_{i}\in\mathcal{G}_{l}\}
denotes the parameters of
level
l
,
\|\Theta_{l}^{(a)}\|_{1}=\sum_{p_{i}\in\mathcal{G}_{l}}\|\theta_{i}^{(a)}\|_{1}
,

Q(\cdot)
simulates deployment quantization via a straight-through estimator
(
\partial Q/\partial\theta\approx I
), and
\lambda
controls the appearance
sparsity penalty. Uniform sampling makes Eq. (
4
) the equally weighted mean of
the
L
level-specific objectives. Thus, all levels are optimized jointly, while each iteration uses only one
LoD forward–backward pass, regardless of the number of levels
L
.
Full pseudocode is provided in Supp. Sec.
S1
.

Quantization.

We use two storage classes: geometric attributes are quantized to

float16
, while appearance attributes are quantized to
int8
. The exact
attribute partition is detailed in
Supp. Sec.
S4
.

Sparsity regularization.

Appearance attributes are typically among the most expensive
components to store in 3DGS-style representations.
We therefore apply the
\ell_{1}
penalty in
Eq. (
4
) to encourage sparsity in the appearance attributes
of the active primitives.

3.3
Progressive Coding

The disjoint structure of Eq. (
1
) means that

\mathcal{G}_{0}
and each
\mathcal{E}_{l}
can be quantized and
serialized independently.
We compress each chunk with Zstandard using two shared dictionaries,
one for geometry and one for appearance, trained once on the
fine-tuned model and reused across all chunks.
Decoding level
l
is then simply

\mathrm{Dec}(l)=\bigcup_{j=0}^{l}\mathrm{Dec}(z_{j})
, where
z_{j}
denotes
the compressed chunk for
\mathcal{G}_{0}
(
j{=}0
) or
\mathcal{E}_{j}

(
j{\geq}1
).
Receiving an enhancement layer at runtime triggers only decompression
and concatenation.

3.4
Adaptive Deployment and Smooth Transitions

At deployment time, the active level is selected according to the
available budget: for a memory constraint
B
, one picks

l^{\star}=\max\{l:\mathrm{Size}(z_{0},\dots,z_{l})\leq B\}
; the same
prefix selection mechanism can use a measured rendering cost budget,
such as a target FPS. Since each decoded prefix is a complete,
renderable model, switching levels requires only decoding the next
chunk and appending its primitives to the active representation.
For interactive applications, switching levels abruptly activates a
full enhancement layer at once, which can produce a visible pop.
To mitigate this, we ramp the opacities of newly introduced
primitives when activating
\mathcal{E}_{l+1}
:

o_{i}(\alpha)=\alpha\,o_{i},\quad\alpha\in[0,1],\;p_{i}\in\mathcal{E}_{l+1},

(5)

so that rendering
\mathcal{G}_{l}\cup\alpha\mathcal{E}_{l+1}
produces
a smooth transition without altering the stored bitstream.

5
Conclusion

We presented GoDe, a progressive compression framework for splat-based
radiance fields: starting from a trained model, it ranks primitives by
gradient-informed importance, applies quantization-aware fine-tuning
across all levels, and entropy-codes the resulting layers for progressive decoding.
Across five heterogeneous backbones, the same pipeline produces monotonic rate–distortion curves and competitive quality while enabling
fast rendering on explicit representations; most importantly for
deployment, cumulative decoding takes
0.2
–
1.3
s, one to two
orders of magnitude faster than existing methods.
These results indicate that progressive delivery can be added to
existing splat-based pipelines without sacrificing their interactive
rendering advantages, making GoDe suitable for bandwidth-adaptive
streaming and scalable storage of radiance fields.

Limitations.

The proposed hierarchy introduces a minor coding overhead, though this cost is small relative to the
benefit of progressive access; moreover, since GoDe is deliberately model-agnostic, architecture-specific designs could still improve individual backbones further.

S2.4
Adaptive Upper Bound

Unlike the lower bound, which specifies a deployment-dependent
quality–complexity trade-off, the upper bound can be selected adaptively
by removing inactive capacity without measurable quality degradation.
A fixed upper endpoint can conservatively discard a predetermined
fraction of the pretrained model; in our initial setting, retaining

75\%
of the primitives preserved essentially full-model quality.
However, the normalized importance scores reveal that the amount of
inactive capacity varies substantially across scenes. We therefore use
a scene-adaptive upper bound that removes primitives with score below

10^{-12}
before constructing the hierarchy. Across the nine Mip-NeRF360 scenes, this rule retains on average

62.86\%
of the pretrained Gaussians, corresponding to
37.14\%

pruning, while preserving PSNR, SSIM, and LPIPS at the reported
precision. Compared with the conservative
75\%
retain setting, the
adaptive rule therefore removes more inactive capacity
while preserving full-model reconstruction quality.

S4
Quantization-Aware Fine-Tuning Details

General setup.

QAT adapts the shared parameter vector
\Theta
to perform well at
every decoded prefix simultaneously and under the quantization applied
at coding time.
Unless otherwise stated, we use
L{=}8
output levels selected via
the geometric schedule of Eq.
2
. We set

n_{\max}
per scene by retaining primitives whose normalized
importance is at least
10^{-12}
. The lower hierarchy bound

n_{\min}
is fixed per dataset and representation family, without
scene-specific tuning, as detailed in
Sec.
S2.3
. All backbones are fine-tuned for

30
k iterations.
Geometric attributes are frozen for the final
3
k iterations to
stabilize quantization ranges before calibration.

Quantization scheme.

We use two storage classes across all backbones.
Geometric attributes are stored in float16, while appearance attributes
are uniformly quantized to int8 using affine quantization:

s=\frac{x_{\max}-x_{\min}}{q_{\max}-q_{\min}},\qquad z=\mathrm{round}\!\left(q_{\min}-\frac{x_{\min}}{s}\right),

(6)

x_{q}=\mathrm{clip}\!\left(\mathrm{round}\!\left(\tfrac{x}{s}+z\right),q_{\min},q_{\max}\right),\qquad\hat{x}=s(x_{q}-z).

(7)

The forward pass uses
\hat{x}
in place of
x
; the backward pass
uses the straight-through estimator
\partial Q/\partial x\approx I
.

Per-backbone attribute mapping.

For GoDe (3DGS) and GoDe (Triangle Splatting), appearance attributes
are the spherical harmonics coefficients.
For GoDe (BS+SV), they are the Spherical Voronoi site directions,
lobe colors, and temperatures.
For GoDe (Scaffold-GS) and GoDe (Octree-GS), they are the anchor
feature codes.
In all cases, opacity is treated as an appearance attribute and
quantized to int8; the remaining geometric attributes are stored in
float16.

Fine-tuning objective.

At each iteration, one level
l
is sampled uniformly and the
fine-tuning objective is:

\min_{\Theta}\;\mathcal{L}\!\left(\mathcal{R}\!\left(c,\{Q(\theta_{i}):p_{i}\in\mathcal{G}_{l}\}\right),I_{c}\right)+\lambda\sum_{p_{i}\in\mathcal{G}_{l}}\|\theta_{i}^{(a)}\|_{1},

(8)

where
\mathcal{L}
is the backbone’s standard photometric loss
(L1 + D-SSIM) and the
\ell_{1}
term encourages sparse appearance
parameters before coding.
We use
\lambda{=}0.05
for all backbones and scenes.

Optimizer and schedule.

We follow each backbone’s original optimizer settings (Adam with
backbone-specific learning rates), resetting the optimizer state at the
start of QAT. No learning-rate warmup is applied, and the backbone’s
default decay schedule is reused for the QAT duration. Apart from the
attribute mapping and the fixed per-backbone settings reported above,
the same GoDe optimization procedure is used across all representations.
