Analysis of ( 3 + 1 ) ​ D (3+1)D and ( 2 + 1 ) ​ D (2+1)D nonlinear ultrasonic waves using conformal invariance
Sadataka Furui, Serge Dos Santos

Abstract
Localization and classification of scattered nonlinear ultrasonic signatures in 2 dimensional complex damaged media using Time Reversal based Nonlinear Elastic Wave Spectroscopy (TR-NEWS) approach is extended to 3 dimensional complex damaged media. In (2+1)D, i.e. space 2 dimensional time 1 dimensional spacetime, we used quaternion bases for analyses, while in (3+1)D, we use biquaternion bases. The optimal weight function of the path of ultrasonic wave in (3+1)D lattice is obtained by using the Echo State Network (ESN) which is a Machine Learning technique. The hysteresis effect is incorporated by using the Preisach-Mayergoyz model. We analyze the spectrum data of Wire Arc Additive Manufacturing (WAAM) sample obtained by Quaternion Excitation Symmetry Analysis Method (QESAM) using the conformally invariant quantum mechanical variables of de Alfaro-Fubini-Furlan and their supersymmetrically extended variables of Fubini-Rabinovici.

Hysteresis effects and Feynman’s path integral

Feynman showed the probability amplitude for a space-time path in the region
R
as
|\varphi(R)|^{2}
[
12
]
, where

\varphi(R)=\lim_{\epsilon\to 0}\int_{R}exp[\frac{\sqrt{-1}}{\hbar}\sum_{i}S(x_{i+1},x_{i})]\cdots\frac{dx_{i+1}}{A}\frac{dx_{i}}{A}\cdots.

(9)

Here
\frac{1}{A}
is a normalization factor to make the wave function satisfies the Schrödinger equation. The probability that the path is in
R^{\prime}
and later in
R^{\prime\prime}
is
|\varphi(R^{\prime},R^{\prime\prime})|^{2}
, where

\displaystyle\varphi(R^{\prime},R^{\prime\prime})

\displaystyle=

\displaystyle\int\chi^{*}(x,t)\psi(x,t)dx,

(10)

\displaystyle\psi(x_{k},t)

\displaystyle=

\displaystyle\lim_{\epsilon\to 0}\int_{R^{\prime}}exp[\frac{\sqrt{-1}}{\hbar}\sum_{t=-\infty}^{k-1}S(x_{i+1},x_{i})]

(11)

\displaystyle\times\frac{dx_{k-1}}{A}\frac{dx_{k-2}}{A}\cdots,

\displaystyle\chi^{*}(x_{k},t)

\displaystyle=

\displaystyle\lim_{\epsilon\to 0}\int_{R^{\prime\prime}}exp[\frac{\sqrt{-1}}{\hbar}\sum_{i=k}^{\infty}S(x_{i+1},x_{i})]

(12)

\displaystyle\times\frac{dx_{k+1}}{A}\frac{dx_{k+2}}{A}\cdots.

The wave function at
t=t+\epsilon
is approximated as

\psi(x_{k+1},t+\epsilon)=\int exp[\frac{\sqrt{-1}}{\hbar}S(x_{k+1},x_{k})]\psi(x_{k},t)\frac{dx_{k}}{A}.

(13)

The PM model
[
13
]
contains many building blocks of
\varphi(R^{\prime},R^{\prime\prime})
with time delay. It is formulated by the input

and output

[

(14)

where

\hat{\gamma}_{\alpha\beta}u(t)=\left\{\begin{array}[]{cc}1,&u(t)\geq\alpha,\\
0,&u(t)\leq\beta,\\
k,&u(t)\in(\beta,\alpha),\end{array}\right.

(15)

k=\left\{\begin{array}[]{cc}1&\exists t^{*}:u(t^{*})>\alpha\quad{\rm and}\quad\forall\tau\in(t^{*},t),u(\tau)\in(\beta,\alpha),\\
0&\exists t^{*}:u(t^{*})<\beta\quad{\rm and}\quad\forall\tau\in(t^{*},t),u(\tau)\in(\beta,\alpha).\end{array}\right.

(16)

The PM model is constructed as a superposition of

multipied by the weight function
\mu(\alpha,\beta)
.

In magnetism, input
