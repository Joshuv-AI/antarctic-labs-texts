Abstract
Federated learning(FL) is used for distributed scenarios to train artificial intelligence(AI) models while ensuring users’ privacy. In federated learning scenario, the server generally never knows about users’ data. This type of concept makes the AI training process efficient in terms of data privacy. However, regarding model performance, federated AI models may not sufficiently satisfy AI users’ expectations. Furthermore, AI users have a wide range of different needs. It is not easy to satisfy the whole users needs. These types of issues can be addressed through AI model optimization, fine-tuning, or personalization to achieve optimal model performance. To address model optimization challenges, we propose reference model-based federated learning for optimal fine-tuning, which overcomes catastrophic forgetting in each round. This method is derived from Bayesian parameter-efficient transfer learning, which includes an optimal proximal term and enables overcoming the catastrophic forgetting issue in each round by utilizing a reference model that incorporates previous model parameters. As a result, this method achieves both high model performance and low computing cost.



I
Introduction

Recently, in the AI industry, federated learning (FL) has been proposed as a prominent solution to protect users’ data privacy while allowing collaborative model training between independent affiliations. Users’ data are fundamentally protected because clients share only updated local model parameters (resulting from local training using their local data) and other non-private values with the server or other clients. The server then computes the global model by aggregating the local models received by the clients. However, as highlighted in
[
1
]
, FL solutions face numerous challenges. Our focus is on optimizing model performance and decreasing computing costs on client devices.

In existing work, the MAP problem was applied as an objective function for optimizing model transfer learning between a target model with pre-trained parameters and a source model. On the other hand, traditional model optimization in FL scenarios used a proximal term to minimize deviation from the global model. However, the proximal term can be denoted as a MAP problem. In this paper, we define the MAP problem as an objective function that is updated with aggregated models from previous rounds only on the server-side, thereby minimizing clients’ computing cost.

In our experiments, we applied FedRef on MNIST, CIFAR10, FeTs2022 data partitioning from distributed condition for non-IID(Independent and Identically Distributed) setting. We defined each baseline and then analyzed model performances, as baseline models differ for each dataset. V
Challenge

FedRef still faces many challenges, including the selection of hyperparameters (client-server side learning rate, a constant value representing the total number of selected previous round models) and protection against malicious users and model inference attacks. Regarding assumptions about the FIM matrix, there are various equations. For future work, we should analyze various FIM matrices and define a more proper proximal term.

VI
Conclusion

For optimizing model training in FL scenarios, existing works have proposed various proximal terms that act as regularization terms in the objective function, preventing the local model from drifting too far from the global model. However, they did not solve the catastrophic forgetting issue in each round, and the proximal term had to be computed on the client side, which increased the client’s computing cost. Our FedRef, a communication-efficient Bayesian fine-tuning approach with a reference model, solves these issues by applying server-side only optimization, including a proximal term that infers previous global features. This concept leads to low client-side computing cost and high model optimization performance. As a result, FedRef contributes to model training optimization in federated learning conditions.
