1. OVERVIEW
The Full-Field Irradiance Analysis Model (FFIAM) evaluates reflected-sunlight irradiance
throughout the airspace of a concentrating solar power (CSP) field during standby. Unlike a receiver-
only calculation, FFIAM resolves where high-irradiance regions form, how intense they are, and
how they move as the sun position and heliostat aim strategy change.
FFIAM partitions the modeled airspace into a three-dimensional grid of voxels and computes the
total irradiance at each voxel. The contribution from each heliostat is evaluated using a facet-level
representation with configurable facet geometry and focal point [1]. Field layouts and heliostat
designs can be defined with input parameters or imported from comma-separated-value and JSON
files.
This full-field view supports airspace-safety and operational-planning questions that cannot be
answered by receiver flux alone: where hazardous irradiance concentrates during standby, how much
radiant exposure an object accumulates along a path through the field, and which standby strategies
preserve more navigable airspace. FFIAM was developed by Sims Industries, LLC for Sandia
National Laboratories.

 Figure 1. FFIAM assessment of standby irradiance at the Sandia National Laboratories National
 Solar Thermal Test Facility (NSTTF). Colored voxels indicate reflected-sunlight irradiance above
 the reporting threshold; the highest flux forms a plume above the receiver tower.

2. ANALYSIS AND OUTPUTS
FFIAM provides complementary Data and Visualization workflows. The Data workflow runs an
analysis from the command line or through the pyffiam Python interface. It produces voxel-scatter
heatmaps in the east–north, north–up, and east–up planes; time-resolved animations; flight-path
irradiance and radiant-exposure plots; and a tabulated spreadsheet summary.
The Visualization workflow renders the CSP field and its high-irradiance voxels in an interactive
Unreal Engine scene. A user can navigate the field in real time and adjust site, date and time, standby
aim strategy, and the reporting threshold. Together, the two workflows support quantitative
comparison and spatial interpretation of the same modeled conditions.

Figure 2. Example Data-workflow outputs for the NSTTF field. Left: a north–up irradiance heatmap
 that reports the maximum irradiance along the viewing axis for each cell. Right: irradiance
 evaluated along a flight path through the airspace for radiant-exposure analysis.

3. STANDBY AIM STRATEGIES
A central use of FFIAM is comparing standby aim strategies, which strongly influence the location
and extent of elevated irradiance. Under a single-point strategy, every heliostat aims at one location
and reflected flux converges into a concentrated high-irradiance column. Under a ring strategy, aim
points are distributed around an annulus above the tower, spreading the same reflected flux into a
broader and generally lower-intensity region. A constant-vector strategy provides a third
configurable reference case.
Evaluating these strategies volumetrically enables an operator or analyst to compare the amount,
location, and continuity of hazardous airspace rather than relying on a receiver-plane result. The
comparison can identify standby configurations that reduce concentrated exposure and preserve
larger navigable regions.

 Figure 3. Standby aim strategy reshapes hazardous airspace. Left: a single-point strategy
 concentrates reflected flux into one high-irradiance column. Right: a ring strategy over a larger
 field distributes flux through a broader, lower-intensity elevated region.

4. SITES AND SCALE
FFIAM includes preset sites for immediate use: the Sandia NSTTF field, synthetic generic fields, and
parametric radial fields with radii of approximately 1 km and 1.6 km. Custom sites are defined with
imported heliostat and facet positions or a JSON configuration.
At full scale, FFIAM Version 3.0 evaluates a field radius of up to 1.6 km, an airspace height of
300 m, more than 11,000 heliostats, and approximately 300 million voxels per analysis at 2 m
resolution. Smaller fields with radii near 1 km can be assessed at 1 m resolution. These scales allow
the model to retain field-wide context while resolving localized regions of elevated irradiance.

 irradiance at that point in the airspace, with color indicating intensity.

5. GETTING STARTED
The easiest way to run FFIAM is the containerized quickstart:
 ./quickstart.sh # run the default NSTTF demonstration
 ./quickstart.sh radial_small # run another preset

The command builds a Docker image on first use and runs a demonstration analysis, writing plots
and the spreadsheet summary to the ./output/ directory. FFIAM uses an NVIDIA GPU when one
is available and otherwise uses a feature-equivalent CPU backend, so the same workflow can run on
any machine with Docker.
The accompanying OpenCSP repository documentation provides the remaining installation and
analysis details:
 • README — installation, containerized quickstart, site and aim-strategy reference, worked
 examples, and configuration schema [2].
 • pyffiam guide — Python wrapper architecture and analysis application programming
 interface [3].
 • Portfolio — representative results from the Data and Visualization workflows [4].

FFIAM is released as open-source software through Sandia’s OpenCSP ecosystem [5]. The project
was developed by Sims Industries, LLC for Sandia National Laboratories, operated by National
Technology & Engineering Solutions of Sandia, LLC.
