Some dynamical properties of constrained Modified Swift-Hohenberg Equation
Saeed Ahmed, Javed Hussain

Abstract
. In this paper, we have studied the long-term behavior for the projected deterministic constrained modified Swift-Hohenberg equation with constraints and Dirichlet boundary conditions. Specifically, using Lojasiewicz-Simon inequality, we have shown that the global solution approaches an equilibrium state. Also, we have analyzed the rate at which the solution approaches equilibrium. Finally, we have proven the existence of a global attractor.

For the proof of first estimate, we begin by same expression used in theorem (
3.4
). We know that
\mathcal{Y}
is constant on
\Omega(u_{0})
and
u^{\infty}\in\Omega(u_{0})
so
\frac{d}{dt}\mathcal{Y}(u^{\infty})=0
and there exists a sequence
t_{n}\rightarrow\infty
such that
u(t_{n})\rightarrow u^{\infty}
in
\mathcal{H}
as
n
tends to
\infty
.

(4.1)

\displaystyle-\frac{d}{dt}\left(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty})\right)^{\theta}

\displaystyle=

\displaystyle-\frac{\theta}{(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{1-\theta}}\frac{d}{dt}\left(\mathcal{Y}(u(t))\right)=\frac{\theta\left|u_{t}\left(t\right)\right|_{\mathcal{H}}^{2}}{(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{1-\theta}}

\displaystyle=

\displaystyle\frac{\theta\left|-\Delta^{2}u+2\Delta u+\|u\|^{2}_{\mathcal{V}}u-\|u\|^{2}_{L^{2}}u+\|u\|^{2n}_{L^{2n}}u-u^{2n-1}\right|_{\mathcal{H}}^{2}}{(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{1-\theta}}

\displaystyle\geq

\displaystyle\frac{\theta\left((\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{1-\theta}\right)^{2}}{(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{1-\theta}}\geq K\left|u_{t}\left(t\right)\right|_{\mathcal{H}}.

The above inequality (
4.1
) takes the form of

(4.2)

\displaystyle\frac{d}{dt}\left(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty})\right)^{\theta}+K\left|u_{t}\left(t\right)\right|_{\mathcal{H}}\leq 0

Taking integration on (
3.6
) and using fact that
u(t)\rightarrow u^{\infty}
in
\mathcal{H}
as
t\rightarrow\infty
, for each
t\geq 0
, we have

(4.3)

\left|u\left(t\right)-u^{\infty}\right|_{\mathcal{H}}\leq\int_{t}^{+\infty}\left|u_{t}\left(p\right)\right|_{\mathcal{H}}dp\leq\frac{1}{K}(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{\theta}.

Using Lojasiewicz–Simon Inequality (
3.6
) along with inequality (
4.2
), we have

\frac{d}{dt}(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{\theta}+K\left((\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{\theta}\right)^{\frac{1-\theta}{\theta}}\leq\frac{d}{dt}(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{\theta}+K\left|u_{t}\left(t\right)\right|_{\mathcal{H}}\leq 0.

That is,

(4.4)

\frac{d}{dt}(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{\theta}+K\left((\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{\theta}\right)^{\frac{1-\theta}{\theta}}\leq 0.

If we substitute
\theta=\frac{1}{2}
, and solve differential inequality (
4.4
) for
(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{\theta}
, then we can conclude that there are two positive constants
c_{1},c_{2}
, such that

(4.5)

\displaystyle(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{\theta}\leq c_{1}e^{-c_{2}t}.

Using inequalities (
4.3
) and (
4.5
), it follows that

(4.6)

\left|u\left(t\right)-u^{\infty}\right|_{\mathcal{H}}\leq\kappa_{1}e^{-\kappa_{2}t},

where
\kappa_{1}:=\frac{a}{K}
and
\kappa_{2}:=b
, are positive constants.

ii) We will use a comparison principle for nonlinear ODEs for the proof decay estimate in the case of
0<\theta<\frac{1}{2}
. Consider the following initial value problem,

\displaystyle\frac{d\Lambda}{dt}+K\Lambda^{\frac{1-\theta}{\theta}}=0,

(4.7)

\displaystyle\Lambda(0)=(\mathcal{Y}(u_{0})-\mathcal{Y}(u^{\infty}))^{\theta}>0.

The solution of above initial value problem is

\Lambda(t)=\left((\mathcal{Y}(u_{0})-\mathcal{Y}(u^{\infty}))^{(2\theta-1)}+\frac{K(1-2\theta)}{\theta}t\right)^{-\frac{\theta}{1-2\theta}}.

Set

\chi(t):=\Lambda(t)-(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{\theta}.

Now, one can easily verify that
\chi
satisfy the following initial value problem.

\left\{\begin{array}[]{l}\frac{d\chi}{dt}+K\left(\frac{1-\theta}{\theta}\eta^{{1-2\theta}}\right)\chi\geq 0\\
\chi(0)=0\end{array}\right.

Where each
\eta
satisfying
(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{\theta}<\eta<\Lambda
. Multiplying differential inequality with integrating factor
\exp{\int_{0}^{t}K\left(\frac{1-\theta}{\theta}\eta(p)^{{1-2\theta}}\right)dp}
and simplifying, we get

\chi(t)\exp{\int_{0}^{t}K\left(\frac{1-\theta}{\theta}\eta(p)^{{1-2\theta}}\right)dp}\geq 0.

Which gives,

\chi(t)\geq 0,\quad\forall t\geq 0.

That is,

(4.8)

\left((\mathcal{Y}(u_{0})-\mathcal{Y}(u^{\infty}))^{(2\theta-1)}+\frac{K(1-2\theta)}{\theta}t\right)^{-\frac{\theta}{1-2\theta}}\geq(\mathcal{Y}(u(t))-\mathcal{Y}(u^{\infty}))^{\theta}

Using the inequality (
4.3
), we have

(4.9)

\displaystyle\left|u\left(t\right)-u^{\infty}\right|_{\mathcal{H}}\leq\left((\mathcal{Y}(u_{0})-\mathcal{Y}(u^{\infty}))^{(2\theta-1)}+\frac{K(1-2\theta)}{\theta}t\right)^{-\frac{\theta}{1-2\theta}}.

As from (
4.7
) we have
(\mathcal{Y}(u_{0})-\mathcal{Y}(u^{\infty}))>0
. Moreover, as
\theta\in\left(0,\frac{1}{2}\right)
so
-1<2\theta-1<0
, which implies that

(4.10)

(\mathcal{Y}(u_{0})-\mathcal{Y}(u^{\infty}))^{2\theta-1}<1.

Using last estimate, we can rewrite (
4.9
) as

(4.11)

\left|u\left(t\right)-u^{\infty}\right|_{\mathcal{H}}\leq\left(1+\frac{K(1-2\theta)}{\theta}t\right)^{-\frac{\theta}{1-2\theta}}\leq\left(\frac{K(1-2\theta)}{\theta}\right)^{-\frac{\theta}{1-2\theta}}\left(\frac{K(1-2\theta)}{\theta}+t\right)^{-\frac{\theta}{1-2\theta}}

Now, take
K
such that
\frac{K(1-2\theta)}{\theta}\leq 1
. Thus, (
4.11
) becomes

(4.12)

\displaystyle\left|u\left(\tau\right)-u^{\infty}\right|_{\mathcal{H}}\leq\kappa(1+t)^{-\frac{\theta}{1-2\theta}}

where
\kappa:=\left(\frac{K(1-2\theta)}{\theta}\right)^{-\frac{\theta}{1-2\theta}}>0
. This is the end of the proof.

5.
Existence of Global Attractor

In this section, we present the existence of global attractor to our main problem (
2.2
).

Theorem 5.1
.

The problem (
2.2
) admits global attractor
\mathcal{A}=\Omega(u_{0})
in manifold
\mathcal{V}\cap\mathcal{M}
.

Proof.

To prove the existence of global attractor, we will use the definition from Theorem
2.10
. From the Corollary (
3.2
), we know that
\{u(t):t\geq 0\}
is compact in
\mathcal{V}
so from Corollary
2.6
we can infer that
\mathcal{A}=\Omega(u_{0})
compact, connected invariant set under semigroup. Hence condition (ii) of Theorem
2.10
is fulfilled.

From Theorem
2.5
, we have already the existence of global solution with
\left\|u(t)\right\|\leq 2\mathcal{Y}(u_{0})
. We , now, start by showing the existence of absorbing set in
\mathcal{V}.
Using the trace Lemma
2.11
, consider the following chain of equations

\displaystyle\frac{d}{dt}\left|u(t)\right|_{\mathcal{H}}^{2}

\displaystyle=

\displaystyle\left\langle u^{\prime}(t),u(t)\right\rangle_{\mathcal{H}}=\left\langle-\Delta^{2}u+2\Delta u+\|u\|^{2}_{\mathcal{V}}u-\|u\|^{2}_{L^{2}}u+\|u\|^{2n}_{{L}^{2n}}u-u^{2n-1},u(t)\right\rangle_{\mathcal{H}},

\displaystyle=

\displaystyle{\left(\|u\|^{2}_{H^{2}_{0}}+2\|u\|^{2}_{H^{1}_{0}}+\|u\|^{2n}_{L^{2n}}\right)\left(|u(t)|^{2}_{\mathcal{H}}-1\right)}\leq\left(\|u\|^{2}_{H^{2}_{0}}+2\|u\|^{2}_{H^{1}_{0}}+\|u\|^{2n}_{L^{2n}}\right)\left|u(t)\right|_{\mathcal{H}}^{2}.

Using the continuos embeddings
\mathcal{V}\hookrightarrow H^{2}_{0}
,
\mathcal{V}\hookrightarrow\mathcal{L}^{2n}
, and
\mathcal{V}\hookrightarrow H^{1}_{0}
and the inequality
\left\|u(t)\right\|_{\mathcal{V}}\leq 2\mathcal{Y}(u_{0})
, we have

\displaystyle\frac{d}{dt}\left|u(t)\right|_{\mathcal{H}}^{2}

\displaystyle\leq

\displaystyle\left(a^{2}\|u\|^{2}_{\mathcal{V}}+2b^{2}\|u\|^{2}_{\mathcal{V}}+c^{2n}\|u\|^{2n}_{\mathcal{V}}\right)\left|u(t)\right|_{\mathcal{H}}^{2}

\displaystyle\leq

\displaystyle\left(4a^{2}(\mathcal{Y}(u_{0}))^{2}+8b^{2}(\mathcal{Y}(u_{0}))^{2}+c^{2n}(2c)^{2n}(\mathcal{Y}(u_{0}))^{2n}\right)\left|u(t)\right|_{\mathcal{H}}^{2}.

Using Grownwall’s lemma,

\left|u(t)\right|_{\mathcal{H}}^{2}\leq\left|u_{0}\right|_{\mathcal{H}}^{2}\exp\left(4a^{2}(\mathcal{Y}(u_{0}))^{2}+8b^{2}(\mathcal{Y}(u_{0}))^{2}+c^{2n}(2c)^{2n}(\mathcal{Y}(u_{0}))^{2n}\right):=K

More precisely, there is
t_{0}\left(\left|u_{0}\right|_{\mathcal{H}}^{2}\right)
such that

\left|u(t)\right|_{\mathcal{H}}^{2}\leq K,\text{ for all }t\geq t_{0}.

In addition, from Theorem
2.5

\frac{d}{dt}\mathcal{Y}(u)=-\left|\frac{du}{dt}\right|_{\mathcal{H}}^{2}\leq 0

So again using Gronwall’s inequality, we can deduce that

\mathcal{Y}(u(t))\leq\mathcal{Y}(u_{0}).

If the initial data varies within a bounded set in
V
( Sobolev imbedding theorem). That is, for a given
\mathcal{R}>0

\mathcal{B}=\{u_{0}\in\mathcal{V}:\left\|u_{0}\right\|\leq\mathcal{R}\}.

then there is a constant
\kappa(\mathcal{R})>0
(not on
\|u_{0}\|
) (which depends on the bounded set) such that for all
t\geq t_{\kappa}
,

\mathcal{Y}(u(t))\leq\mathcal{Y}(u_{0})\leq\kappa.

This implies that for
t\geq t_{\kappa}
the orbits starting from
\mathcal{B}
uniformly enter an absorbing ball of radius
\kappa
.

In addition, it is trivial that there exists a absorbing set in
\mathcal{V}
norm because we already know that
\left\|u(t)\right\|\leq 2\mathcal{Y}(u_{0}),
so also for
t\geq t\kappa
,

\left\|u(t)\right\|\leq 2\mathcal{Y}(u_{0})\leq\frac{\kappa}{2}.

This implies that orbit starting from
\mathcal{B}
enter in ball in
\mathcal{V}
with radius
\frac{\kappa}{2}
. Thus, condition (i) of Theorem
2.10
is fulfilled. and global attractor exists.

6.
Conclusion

This paper presents the dynamical properties and long-term behavior of solution of particular gradient flow with the solution in Hilbert manifold. Firstly, the convergence of global solution of the main problem (
2.2
) to equilibrium by means of Lojasiewicz–Simon Inequality has been proven. Secondly, the decay rate of convergence of solution to equilibrium have been analyzed. In this case, we have shown that the decay rate is either polynomial or exponential, depending on the values of
\theta
. Finally, the existence of a global attractor has been established.
