Maximal Achievable Service Rates of Codes and Connections to Combinatorial Designs
Hoang Ly and Emina Soljanin

Abstract
We investigate the service-rate region (SRR) of distributed storage systems that employ linear codes. We focus on systems where each server stores one code symbol, and a user recovers a data symbol by accessing any of its recovery groups, subject to per-server capacity limits. The SRR–the convex polytope of simultaneously achievable request rates–captures system throughput and scalability. We first derive upper and lower bounds on the maximum request rate of each data object. These bounds hold for all linear codes and depend only on the number of parity checks orthogonal to a particular set of codeword coordinates associated with that object, i.e., the equations used in majority-logic decoding, and on code parameters. We then check the bound saturation for 1) all non-systematic codes whose SRRs are already known and 2) systematic codes. For the former, we prove the bounds are tight. For systematic codes, we show that the upper bound is achieved whenever the supports of minimum-weight dual codewords form a 2-design. As an application, we determine the exact per-object demand limits for binary Hamming codes. Our framework provides a new lens to address the SRR problem through combinatorial design theory.

I
Introduction

Reliable and scalable data access is a key requirement in modern computing systems, particularly under dynamic and uneven demands. Traditional systems have relied mainly on basic replication strategies
[
1
]
. The increasing disparity in data popularity has motivated hybrid redundancy schemes that combine erasure coding with replication. In this context,
Service Rate Region
(SRR) has emerged as a foundational metric, quantifying the set of achievable request rates supported by a given redundancy configuration
[
1
,
2
]
. The concept of SRR is closely related to load-balancing
[
3
]
, and it generalizes the problem of batch codes
[
4
]
. It is also connected to the problem of access balancing; see, e.g.,
[
5
]
and the follow-up work.

Previous work has largely characterized the SRRs of several important code families, including MDS, Simplex, first- and higher-order Reed-Muller codes, and locally recoverable codes; see
[
1
]
, and more recently
[
6
,
7
]
. At the same time, other studies investigated code parameters, such as the field size and block length required for a target SRR
[
8
]
. Despite these developments, many fundamental questions about the behavior and structure of the SRR remain open.

In distributed storage systems and SRR problems, each data object is retrieved through
recovery sets
(or repair groups), which are collections of stored symbols that together enable the reconstruction of the desired object. This notion closely parallels that of
majority-logic decoding
(MLD) in linear codes, where each message (or information) symbol is recovered using multiple (not necessarily disjoint) sets of codeword symbols. Each such set contributes a "vote" toward the true value of the message symbol, and decoding succeeds if the majority of these votes remain uncorrupted in the presence of noise in the communication channel. Since errors in received codeword symbols affect all recovery sets that contain them, the effectiveness of MLD depends critically on the overlap structure among these sets.

The codes that can be decoded using this scheme are known as
majority-logic decodable codes
. These codes are attractive in practice due to their inexpensive decoding circuitry and their potential to correct beyond their worst-case error bounds
[
9
]
. The structure of the recovery sets–and thus the correction capability of MLD–is intimately tied to the combinatorics of the dual code, specifically to how codeword symbols appear in the supports of dual codewords. A fundamental result of Rudolph
[
10
]
characterizes the error correction capability of MLD in a code when the supports of its dual codewords exhibit certain combinatorial regularities. For some extensions of these results, see, for instance,
[
11
,
12
]
.

This paper explicitly connects SRR analysis with MLD decoding and combinatorial design theory. We thus reveal how a linear code’s combinatorial structure and error-correcting properties fundamentally influence its data access performance in storage systems.

The rest of the paper is organized as follows. Section II formally presents the problem setting, defines the SRR problem and maximal achievable demand for each data object, and summarizes our main contributions. Section III introduces majority-logic decoding and establishes bounds on the maximal achievable demand using orthogonal parity checks. In Section IV, we specialize these results into systematic codes and identify the conditions under which the upper bound is achieved, drawing connections to combinatorial designs. Section V concludes the paper.

Service Rate of Codes

Consider a storage system in which

\displaystyle\sum_{j=1}^{t_{i}}\lambda_{i,j}

\displaystyle\;=\;\lambda_{i},\quad\forall\,i\in[k],

(1)

\displaystyle\sum_{i=1}^{k}\sum_{\begin{subarray}{c}j=1\\

(

II-C

Maximal achievable demands of data objects

For each
\ell\in[k]
define the
coordinate-wise maximum

\lambda_{\ell}^{\max}\;:=\;\max\bigl\{\lambda_{\ell}\mid\boldsymbol{\lambda}\in\mathcal{S}(\boldsymbol{G},\boldsymbol{1})\bigr\},

i.e., the largest request rate for object
o_{\ell}
achievable while other objects may also receive traffic. Next, define the
axis intercept

\lambda_{\ell}^{\mathrm{int}}\;:=\;\max\bigl\{\gamma\in\mathbb{R}_{\geq 0}\mid\gamma\,\boldsymbol{e}_{\ell}\in\mathcal{S}(\boldsymbol{G},\boldsymbol{1})\bigr\},

i.e., the maximum rate for
o_{\ell}
achievable when all other demands are zero. It was proved in
[
6
]
that

\lambda_{\ell}^{\mathrm{int}}=\lambda_{\ell}^{\max}
. Consequently, dedicating the entire system to object
o_{\ell}
permits to serve at most
\lambda_{\ell}^{\max}
requests. We refer to this quantity as the
maximal achievable demand
(or maximal achievable rate) for object
\ell
. Practically,
\lambda_{\ell}^{\max}
represents the highest individual request rate for object
o_{\ell}
that the system can support in isolation. Characterizing these values is particularly relevant in distributed storage systems, where object demands or popularities are commonly skewed
[
1
]
.

Form the simplex

\Delta_{\max}\;:=\;\operatorname{conv}\bigl\{\boldsymbol{0}_{k},\;\lambda_{1}^{\max}\boldsymbol{e}_{1},\dots,\lambda_{k}^{\max}\boldsymbol{e}_{k}\bigr\},

which is the convex hull of the origin and the
k
axis-intercept vertices. Because
\mathcal{S}(\boldsymbol{G},\boldsymbol{1})
is convex (Lemma
2
),
\Delta_{\max}\subseteq\mathcal{S}(\boldsymbol{G},\boldsymbol{1})
. No larger axis-aligned simplex lies inside the SRR, so we call
\Delta_{\max}
the
maximal achievable simplex
, in which every point is achievable.

II-D

Summary of Contributions

This paper focuses on the maximal achievable rate for each individual object, denoted
\lambda_{j}^{\max}
, and establishes a connection between the SRR problem, MLD, and combinatorial design theory. Concretely, the main contributions of this work are as follows:

1.

We establish upper and lower bounds on the maximal achievable demand for each data object in a system encoded by a generator matrix
\boldsymbol{G}
, expressed in terms of the number of parity checks orthogonal to its minimal recovery set and the parameters of the underlying code. Unlike previously established bounds that apply only to specific codes (e.g., Reed–Muller codes) or code families (e.g., systematic codes), our result holds for all binary linear codes (Theorem
1
).

2.

We specialize these bounds to the case where
\boldsymbol{G}
is systematic and show that the upper bound is achieved when the minimum-weight dual codewords satisfy a specific structural condition. This reveals a direct connection between the maximal achievable demand in the SRR problem and the error-correction capability of MLD applied to the underlying code (Theorem
2
and Corollary
1
).

3.

We verify that the bounds are tight for all codes whose SRR has previously been characterized in the literature (Remark
3
and Section
V
.B).

4.

We extend the analysis to Hamming codes, providing the first characterization of their service rate region (Theorem
3
).

IV
MLD and Axis Intercept Points of SRR

We show how the MLD orthogonal checks correspond to recovery sets for data objects in the SRR problem, enabling tight bounds on the maximum achievable demand for each object. We state the concept for binary codes; generalization to linear codes over any finite field is straightforward.

Now consider
\mathcal{O}
, a smallest recovery set for object
{\ell}\in[k]
. In other words,
\mathcal{O}
is a set of minimal cardinality such that:

\sum\limits_{j\in\mathcal{O}}\,\boldsymbol{c}^{j}\,=\,\boldsymbol{e}_{\ell}.

Let
a=|\mathcal{O}|
denote the size of this smallest recovery set. Let
\mathcal{I}_{1},\dots,\mathcal{I}_{J_{\mathcal{O}}}
be the index sets of
J_{\mathcal{O}}
parity-check sums such that these checks are orthogonal on the set
\mathcal{O}
. (Here,
J_{\mathcal{O}}
denotes the maximum number of such checks orthogonal on this specific set
\mathcal{O}
.) Recall that for any
\mathcal{I}_{i}
, the definition of the parity check implies

\sum_{j\in\mathcal{I}_{i}}\,\boldsymbol{c}^{j}\,=\,\boldsymbol{G}\cdot\boldsymbol{\chi}(\mathcal{I}_{i})^{\top}\,=\,\boldsymbol{0}_{k}.

Then, we have for each
i\in[J_{\mathcal{O}}]
:

\sum\limits_{j\in\mathcal{I}_{i}\setminus\mathcal{O}}\boldsymbol{c}^{j}\,=\,\sum\limits_{j\in\mathcal{I}_{i}}\boldsymbol{c}^{j}-\sum\limits_{j\in\mathcal{O}}\boldsymbol{c}^{j}\,=\,\boldsymbol{0}_{k}-\boldsymbol{e}_{\ell}\,=\,\boldsymbol{e}_{\ell}\ \ \ (\text{over }\mathbb{F}_{2}).

In other words, the sets
\mathcal{R}_{i}=\mathcal{I}_{i}\setminus\mathcal{O}
for
i=1,\dots,J_{\mathcal{O}}
form recovery sets for object
o_{\ell}
. Including
\mathcal{O}
itself—which is also a recovery set for
o_{\ell}
—we obtain
J_{\mathcal{O}}+1
recovery sets in total. Moreover, by the orthogonality condition
\mathcal{I}_{i}\cap\mathcal{I}_{k}=\mathcal{O}
for
i\neq k
, the sets
\mathcal{R}_{i}
are pairwise disjoint by construction.

Thus, we have constructed
J_{\mathcal{O}}+1
pairwise disjoint recovery sets for
o_{\ell}
: the original set
\mathcal{O}
and the
J_{\mathcal{O}}
sets
\mathcal{R}_{1},\dots,\mathcal{R}_{J_{\mathcal{O}}}
. This leads to the following theorem.

Theorem 1
.

Consider a storage system encoded by a generator matrix
\boldsymbol{G}
. Let
\mathcal{O}
be a smallest recovery set for object
o_{\ell}
, with
\ell\in[k]
, and let
a=|\mathcal{O}|
denote its size. Let
J_{\mathcal{O}}
be the maximum number of parity-check sums orthogonal on
\mathcal{O}
. Then the maximal achievable demand
\lambda_{\ell}^{\max}
for object
o_{\ell}
satisfies:

1+J_{\mathcal{O}}\,\leq\,\lambda_{\ell}^{\max}\,\leq\,1+\frac{n-a}{\max\{d^{\perp}-a,\ a\}}\,\leq\,1+\frac{n-a}{d^{\perp}-a},

where
d^{\perp}
is the minimum distance of the dual code
\mathcal{C}^{\perp}
.

Proof.

The lower follows from the above argument. We now prove the upper bound.

Step 1: Every recovery set other than
\mathcal{O}
has size at least
d^{\perp}-a
.

Let
\mathcal{O}
be a minimal recovery set for
o_{\ell}
, with size
a=|\mathcal{O}|
, and let
\mathcal{O}^{\prime}\neq\mathcal{O}
be any other recovery set for
o_{\ell}
. Since both
\mathcal{O}
and
\mathcal{O}^{\prime}
recover
o_{\ell}
, we have:

\sum_{j\in\mathcal{O}}\boldsymbol{c}^{j}\,=\,\boldsymbol{e}_{\ell}\,=\,\sum_{j\in\mathcal{O}^{\prime}}\boldsymbol{c}^{j}.

Adding these equations over
\mathbb{F}_{2}
yields:

\sum_{j\in\mathcal{O}}\boldsymbol{c}^{j}+\sum_{j\in\mathcal{O}^{\prime}}\boldsymbol{c}^{j}\,=\,\boldsymbol{0}_{k}.

Let
\mathcal{O}_{1}:=(\mathcal{O}\cup\mathcal{O}^{\prime})\setminus(\mathcal{O}\cap\mathcal{O}^{\prime})
be the symmetric difference of
\mathcal{O}
and
\mathcal{O}^{\prime}
. Then:

\sum_{j\in\mathcal{O}_{1}}\boldsymbol{c}^{j}\,=\,\boldsymbol{0}_{k}.

This implies that the incidence vector
\boldsymbol{\chi}(\mathcal{O}_{1})\in\mathbb{F}_{2}^{n}
satisfies:

\boldsymbol{G}\cdot\boldsymbol{\chi}(\mathcal{O}_{1})^{\top}\,=\,\boldsymbol{0}_{k},

so
\boldsymbol{\chi}(\mathcal{O}_{1})\in\mathcal{C}^{\perp}
. Since
\mathcal{O}\neq\mathcal{O}^{\prime}
, the set
\mathcal{O}_{1}
is nonempty, and thus
\boldsymbol{\chi}(\mathcal{O}_{1})
is a nonzero codeword in
\mathcal{C}^{\perp}
, with weight at least
d^{\perp}
:

|\mathcal{O}_{1}|\,=\,\textsf{w}(\boldsymbol{\chi}(\mathcal{O}_{1}))\,\geq\,d^{\perp}.

By the identity:

|\mathcal{O}_{1}|\,=\,|\mathcal{O}|+|\mathcal{O}^{\prime}|-2|\mathcal{O}\cap\mathcal{O}^{\prime}|,

we obtain:

|\mathcal{O}^{\prime}|\,\geq\,|\mathcal{O}_{1}|-|\mathcal{O}|\,\geq\,d^{\perp}-a.

Therefore, every recovery set distinct from
\mathcal{O}
must have size at least
d^{\perp}-a
. Since
\mathcal{O}
has size
a
and is by definition the smallest recovery set, it follows that the size of any other recovery set is at least
\max\{d^{\perp}-a,\,a\}
.

Step 2: Upper bound via capacity constraint.

To support a demand rate
\lambda_{\ell}=\lambda_{\ell}^{\max}
, the system must allocate server capacity across recovery sets for object
o_{\ell}
. As shown in Step 1, the object can be recovered from:

•

one recovery set
\mathcal{O}
of size
a
, and

•

other recovery sets, each of size at least
\max\{d^{\perp}-a,\,a\}\geq a
.

To minimize total server usage, we consider the following assignment: allocate one unit of request to the smallest recovery set
\mathcal{O}
, which consumes
a
servers; assign the remaining
\lambda_{\ell}-1
units of request to other recovery sets, each of size at least
\max\{d^{\perp}-a,\,a\}
. Therefore, the total number of servers involved is at least:

1\times a+(\lambda_{\ell}-1)\times\max\{d^{\perp}-a,\ a\}.

Since this request is achievable, the total required server capacity must not exceed the total available capacity
n
. Thus,

a+(\lambda_{\ell}-1)\max\{d^{\perp}-a,\ a\}\,\leq\,n.

Solving for
\lambda_{\ell}
yields:

\lambda_{\ell}\,\leq\,1+\frac{n-a}{\max\{d^{\perp}-a,\,a\}}\,\leq\,1+\frac{n-a}{d^{\perp}-a}.

Since this holds for all achievable
\lambda_{\ell}
, it applies in particular to
\lambda_{\ell}^{\max}
. Together with the lower bound
\lambda_{\ell}^{\max}\geq 1+J_{\mathcal{O}}
, this completes the proof.
∎

Remark 2
.

Theorem
1
immediately yields an upper bound on
J_{\mathcal{O}}
, the number of parity-check sums orthogonal on a given set of codeword coordinates
\mathcal{O}
of size
a
:

J_{\mathcal{O}}\;\leq\;\frac{n-a}{\max\{a,\,d^{\perp}-a\}}.

Remark 3
.

We show that the upper bound in Theorem
2
is achieved for non-systematic codes whose SRR is known up to now, that are Reed–Muller codes and non-systematic MDS codes.

•

Reed–Muller codes.
Consider the
\mathrm{RM}(r,m)
code of length
n=2^{m}
and order
r
. Its dual is the
\mathrm{RM}(m-r-1,m)
code, which has minimum distance
d^{\perp}=2^{r+1}

[
15
]
. Substituting into the bound, we obtain:

\lambda_{\ell}^{\max}\,\leq\,1+\frac{2^{m}-a}{2^{r+1}-a},

where
a
is the size of the smallest recovery set for object
o_{\ell}
. It was shown in
[
7
]
that this bound is achieved with equality, establishing the tightness of the bound for Reed–Muller codes.

•

Non-systematic MDS codes.
Consider a non-systematic
[n,\,k,\,n-k+1]
MDS code (
n\geq k+1
), whose dual is an
[n,\,n-k,\,k+1]
MDS code. In such codes, each recovery set has size
k
. Applying the general bound yields:

\lambda_{j}^{\max}\,\leq\,1+\frac{n-k}{k+1-k}\,=\,1+(n-k),\quad\forall\,j\in[k],

which significantly overestimates the true value.

A tighter bound is obtained by refining the denominator to account for the actual recovery set size:

\lambda_{j}^{\max}\,\leq\,1+\frac{n-k}{\max\{k+1-k,\,k\}}\,=\,1+\frac{n-k}{k}\,=\,\frac{n}{k}.

This bound is known to be tight and achievable for non-systematic MDS codes, as established in
[
6
,
1
]
.

We also observe that our result offers an alternative estimate, where the maximal achievable requests for individual objects are bounded in terms of the dual distance
d^{\perp}
rather than the minimum distance
d_{\min}
of the original code. In contrast, the bound from
[
2
, Corollary 2]
states that for any linear code,

\left\lceil\min_{j}\{\lambda_{j}^{\max}\}\right\rceil\,\leq\,d_{\min}.

For instance, in the case of
[n,\,k,\,n-k+1]
MDS codes, this yields the bound
\lambda_{j}^{\max}\leq n-k+1
, which is strictly weaker than the bound
\lambda_{j}^{\max}\leq n/k
whenever
n\geq k
.

V
Application to Systematic codes and Connection to Combinatorial Designs

In this section, we apply the results from the previous section to systems where the generator matrix
\boldsymbol{G}
is systematic, so that each object has a recovery set of size 1. We then propose a sufficient condition under which the upper bound on the maximal achievable demand is attained, and demonstrate that this condition holds for several classes of systematic codes—recovering known results and establishing new ones.

V-A

Bounds for Maximal Achievable Demands in Systematic Codes

We apply the results from Section
IV
to cases when
\boldsymbol{G}
is systematic, which is of the form

\displaystyle\boldsymbol{G}_{k\times n}\,=\,\left[\boldsymbol{I}_{k}\ |\ \boldsymbol{P}_{k\times(n-k)}\right],

(14)

where the first
k
columns form the identity matrix
\boldsymbol{I}_{k}
, and the remaining
n-k
columns provide redundancy. In this setting, each column
\boldsymbol{c}^{\ell}=\boldsymbol{e}_{\ell}
for
\ell\in[k]
, so the smallest recovery set for object
o_{\ell}
is simply
\mathcal{O}=\{\ell\}
, consisting of the systematic column
\boldsymbol{c}^{\ell}
itself, and has size 1. In this case,
J_{\mathcal{O}}
denotes the maximum number of parity-check sums that are orthogonal on coordinate
\ell
–that is, each parity check includes
x_{\ell}
and intersects the others only at
x_{\ell}
. In this case, we will call this quantity instead by
J_{\ell}:=J_{\mathcal{O}}
. We assume that the dual distance satisfies
d^{\perp}\geq 2
, so that
\max\{d^{\perp}-a,\ a\}=\max\{d^{\perp}-1,\ 1\}=d^{\perp}-1
.

Consider the systematic
[15,11,3]
Hamming code
\mathcal{C}
, generated by a systematic matrix
\boldsymbol{G}_{H}
of the form (
14
), and a storage system encoded using
\boldsymbol{G}_{H}
. The dual code
\mathcal{C}^{\perp}
is the
[15,4,8]
Simplex code, generated by
\boldsymbol{G}_{S}
as introduced in the previous section. In this setting, the upper bound from Theorem
1
becomes:

\lambda_{1}^{\max}\,\leq\,1+\frac{15-1}{8-1}=1+\frac{14}{7}=3.

We now show that this bound is indeed achievable. Consider the set of all minimum-weight dual codewords
\boldsymbol{h}\in\mathcal{C}^{\perp}
(in this case, those of weight 8) with
h_{1}=1
. Their supports are listed below:

\displaystyle\mathrm{Supp}(\boldsymbol{h}^{1})=\{1,3,5,7,9,11,13,15\}

\displaystyle\mathrm{Supp}(\boldsymbol{h}^{2})=\{1,2,5,6,9,10,13,14\}

\displaystyle\mathrm{Supp}(\boldsymbol{h}^{3})=\{1,3,4,6,9,11,12,14\}

\displaystyle\mathrm{Supp}(\boldsymbol{h}^{4})=\{1,2,4,7,9,10,12,15\}

\displaystyle\mathrm{Supp}(\boldsymbol{h}^{5})=\{1,3,5,7,8,10,12,14\}

\displaystyle\mathrm{Supp}(\boldsymbol{h}^{6})=\{1,2,5,6,8,11,12,15\}

\displaystyle\mathrm{Supp}(\boldsymbol{h}^{7})=\{1,3,4,6,8,10,13,15\}

\displaystyle\mathrm{Supp}(\boldsymbol{h}^{8})=\{1,2,4,7,8,11,13,14\}

Each of these satisfies
\boldsymbol{G}_{H}\cdot(\boldsymbol{h}^{i})^{\top}=\boldsymbol{0}_{11}
, and since
\boldsymbol{G}_{H}
is systematic, the first column of
\boldsymbol{G}_{H}
is
\boldsymbol{c}^{1}(\boldsymbol{G}_{H})=\boldsymbol{e}_{1}
, we obtain

\displaystyle\sum_{j\,\in\,\mathrm{Supp}(\boldsymbol{h}^{i})\setminus\{1\}}\boldsymbol{c}^{j}(\boldsymbol{G}_{H})\,

\displaystyle=\,\sum_{j\,\in\,\mathrm{Supp}(\boldsymbol{h}^{i})}\boldsymbol{c}^{j}(\boldsymbol{G}_{H})-\boldsymbol{c}^{1}(\boldsymbol{G}_{H})

\displaystyle=\,\boldsymbol{0}-\boldsymbol{e}_{1}\,=\,\boldsymbol{e}_{1},\quad\forall\,i=1,\dots,8.

(15)

This implies that each set
\mathrm{Supp}(\boldsymbol{h}^{i})\setminus\{1\}
is a recovery set for object
o_{1}
. Notably, each coordinate
j\in\{2,3,\dots,15\}
appears in precisely 4 of these 8 sets, forming a
1
-
(14,7,4)
design.

Therefore, we can assign demand for object
o_{1}
to its recovery sets as follows:

\begin{cases}\text{Assign }\lambda_{1}=1\text{ to the singleton set }\boldsymbol{c}^{1}=\boldsymbol{e}_{1},\\
\text{Assign }\lambda_{-1}=\frac{1}{4}\text{ to each of 8 sets }\mathrm{Supp}(\boldsymbol{h}^{i})\setminus\{1\},\ i\in[8].\end{cases}

This assignment ensures that the total request served by each server is exactly
\frac{1}{4}\cdot 4=1
, and the total demand for
o_{1}
is

1+\frac{8}{4}=3,

which achieves the theoretical upper bound.

As seen above, when the supports of minimum-weight codewords form a specific combinatorial structure, the upper bound on
\lambda_{1}^{\max}
becomes achievable. This observation is formalized in the following theorem.

Theorem 2
.

Consider a system encoded by a systematic generator matrix
\boldsymbol{G}
(over
\mathbb{F}_{2}
). Then, for any object
o_{\ell}
corresponding to the systematic column
\boldsymbol{c}^{\ell}=\boldsymbol{e}_{\ell}
(with
\ell\in[k]
), the maximal achievable demand
\lambda_{\ell}^{\max}
satisfies:

1+J_{\ell}\,\leq\,\lambda_{\ell}^{\max}\,\leq\,1+\frac{n-1}{d^{\perp}-1},

where
d^{\perp}
is the minimum distance of
\mathcal{C}^{\perp}
, which is the dual code of the code generated by
\boldsymbol{G}
, assuming
d^{\perp}>1
.

The upper bound is achieved if the collection

\mathcal{N}_{\ell}=\left\{\mathrm{Supp}(\boldsymbol{h})\setminus\{\ell\}\,\middle|\,\boldsymbol{h}\in\mathcal{C}^{\perp},\;\textsf{w}(\boldsymbol{h})=d^{\perp},\;h_{\ell}=1\right\}

forms a
1
-design on the point set
[n]\setminus\{\ell\}
; that is, the supports (excluding position
\ell
) of all minimum-weight dual codewords with a 1 in position
\ell
form a
1
-design.

Proof.

The lower and upper bounds follow from Theorem
1
, noting that when
\boldsymbol{G}
is systematic, the smallest recovery set for each object consists of a single systematic coordinate, i.e.,
a=1
. The upper bound can also be proved using Theorem IV.6 in
[
17
]
by setting all other requests
\lambda_{j},j\neq\ell
to 0.

To prove achievability of the upper bound, assume the sets in
\mathcal{N}_{\ell}
form a
1
-
(n-1,\,d^{\perp}-1,\,d_{c})
design. Let
\gamma=|\mathcal{N}_{\ell}|
be the number of blocks. Since each block contains
d^{\perp}-1
points, double-counting the total number of point-block incidences in this 1-design yields the identity:

(n-1)\cdot d_{c}=\gamma\cdot(d^{\perp}-1).

(16)

For every
\boldsymbol{h}\in\mathcal{C}^{\perp}
such that
\boldsymbol{h}\setminus\{l\}\in\mathcal{N}_{\ell}
, we have

\boldsymbol{G}\cdot\boldsymbol{h}^{\top}=\boldsymbol{0}_{k}
. Since
\boldsymbol{c}^{\ell}=\boldsymbol{e}_{\ell}
and
h_{\ell}=1
, it follows that:

\sum_{j\,\in\,\mathrm{Supp}(\boldsymbol{h})\setminus\{\ell\}}\boldsymbol{c}^{j}(\boldsymbol{G})=\boldsymbol{0}_{k}-\boldsymbol{e}_{\ell}=\boldsymbol{e}_{\ell}.

(This generalized eq. (
V-A
).) Thus, each set
\mathrm{Supp}(\boldsymbol{h})\setminus\{\ell\}
is a recovery set of size
d^{\perp}-1
for object
o_{\ell}
. Because these recovery sets by assumption form a
1
-design, each server
j\in[n]\setminus\{\ell\}
appears in exactly
d_{c}
of the
\gamma
recovery sets. We now construct a fractional allocation:

\begin{cases}\text{Assign }\lambda_{\ell}=1\text{ to the singleton set }\{\ell\},\\
\text{Assign }\lambda_{\ell}=\dfrac{1}{d_{c}}\text{ to each of $\gamma$ recovery sets in }\mathcal{N}_{\ell}.\end{cases}

This allocation ensures that each server handles at most unit total demand (
d_{c}\cdot\frac{1}{d_{c}}=1
). The total demand served for object
o_{\ell}
is:

\lambda_{\ell}^{\max}=1+\frac{\gamma}{d_{c}}=1+\frac{n-1}{d^{\perp}-1},

where the final equality uses (
16
). This matches the claimed upper bound.
∎

We now observe that the achievability condition in Theorem
2
is satisfied if the supports of the minimum-weight codewords of the dual code
\mathcal{C^{\perp}}
form a
2
-design, yielding a more elegant and broadly applicable condition for achievability. This follows from the result below.

Lemma 3
.

(Design Reduction, see, e.g.,
[
13
, Theorem 9.2]
)
Let
\mathcal{D}=(V,\mathcal{A})
be a
t
-design and let
Z\subseteq V
with
|Z|=i<t
. Then the incidence structure
(V\setminus Z,\,\{A\setminus Z:A\in\mathcal{A},\,Z\subset A\})
is a
(t-i)
-design.

That is, by fixing any subset
Z
of size
i<t
, the substructures formed by removing
Z
from every block containing it yield a
(t-i)
-design on the remaining points.

Applying this Design Reduction result with
t=2
and
Z=\{\ell\}
, we conclude that the subcollection of supports of minimum-weight dual codewords containing coordinate
\ell
, punctured at position
\ell
, forms a
1
-design on
[n]\setminus\{\ell\}
. This confirms the achievability condition in Theorem
2
. We thus have the following corollary.

Corollary 1
.

Let
\boldsymbol{G}
be a systematic generator matrix of a binary linear code
\mathcal{C}
with dual distance
d^{\perp}>1
. If the supports of the minimum-weight codewords in the dual code
\mathcal{C}^{\perp}
form a
2
-design, then:

\lambda_{\ell}^{\max}\;=\;1+\frac{n-1}{d^{\perp}-1},\quad\forall\,\ell\in[k].

Conditions under which dual codewords of certain weights form block designs have been extensively studied, although much remains to be understood. Interested readers are referred to the Assmus–Mattson theorem
[
18
]
, its related results
[
19
]
, and references therein.

Remark 4
.

For a code with a systematic generator matrix,
Theorem
2
relates each symbol’s

maximal achievable demand
to its
error-correction capability
.
Combined with Proposition
1
, it follows that, for each coordinate
\ell\in[k]
, the largest number of errors a code can tolerate while still correctly recovering the message symbol
a_{\ell}
using one-step MLD, denoted
t_{\ell}
, satisfies

t_{\ell}\;=\;\left\lfloor\frac{J_{\ell}}{2}\right\rfloor\;\leq\;\left\lfloor\frac{\lambda_{\ell}^{\max}-1}{2}\right\rfloor,

where
J_{\ell}
denotes the number of parity-check sums orthogonal to
coordinate
\ell
. Moreover, Theorem
2
directly implies the bound on
J_{\ell}

J_{\ell}\;\leq\;\frac{n-1}{d^{\perp}-1},

which is a classical bound that appears, for example, as Theorem 17 in

[
15
, Ch. 13]
.

V-B

Applications to certain classes of systematic codes

We now demonstrate that the upper bound in Theorem
2
is matched for all systematic codes whose SRR is explicitly known–namely, Simplex codes, Maximum Distance Separable (MDS) codes, and Repetition codes.

V-B
1
Simplex codes.

Consider a systematic
[2^{k}-1,\,k,\,2^{k-1}]
Simplex code. Its dual is a
[2^{k}-1,\,2^{k}-k-1,\,3]
Hamming code. The upper bound in Theorem
2
becomes

\lambda_{\ell}^{\max}\,\leq\,1+\frac{2^{k}-2}{3-1}=2^{k-1}.

This bound is achieved by Corollary
1
, as the minimum-weight codewords in the dual Hamming code (i.e., weight-3 codewords) form a 2-design—specifically, a
Steiner system

[
13
, Theorem 10.25]
. This confirms the tightness of the bound for Simplex codes. An alternative proof using graph-theoretic arguments appears in
[
4
,
1
]
.

V-B
2
Systematic MDS codes.

Consider a systematic
[n,k,n-k+1]
MDS code with
n\geq k+1
.
Its dual is an
[n,n-k,k+1]
MDS code, so the general upper bound reads

\lambda_{\ell}^{\max}\;\leq\;1+\frac{n-1}{k}.

The bound is achieved by Corollary
1
. Indeed, it is known that the minimum–weight codewords of an
[n,k,d_{\min}]
MDS code form a
d_{\min}
-design
[
18
]
. Since here
d_{\min}=n-k+1\geq 2
, Lemma
1
guarantees that the supports of the minimum-weight dual codewords always constitute a
2
-design. Hence the bound is tight for all systematic MDS codes. A purely graph–theoretic derivation appears in

[
1
,
6
]
.

V-B
3
Repetition and single parity-check codes.

For the (systematic) repetition code with parameters
[n,\,1,\,n]
, the maximal achievable demand for the sole object
o_{1}
is

\lambda_{1}^{\max}\,=\,n.

Its dual is a systematic single parity-check (SPC) code with parameters
[n,\,n-1,\,2]
. For any object
o_{\ell}
,
\ell\in[n-1]
, the maximal achievable demand is

\lambda_{\ell}^{\max}\,=\,2.

These results follow directly from the fact that both codes are systematic MDS codes, and thus the general tightness and achievability results for MDS codes apply.

V-C

Application to Hamming codes

We present and prove the following result.

Theorem 3
.

For any systematic Hamming code with parameters
[2^{k}-1,\,2^{k}-k-1,\,3]
, the maximal achievable demand for any object
o_{\ell}
,
\ell\in[k]
, is

\lambda_{\ell}^{\max}\,=\,3.

This implies that increasing the number of server nodes does not improve the maximal achievable request rates for data objects in such systems.

Proof.

Let
\mathcal{C}
denote the Hamming code. Its dual,
\mathcal{C}^{\perp}
, is the
[2^{k}-1,\,k,\,2^{k-1}]
Simplex code, with minimum distance
d^{\perp}=2^{k-1}
. Substituting into the bound, we obtain:

\displaystyle\lambda_{\ell}^{\max}

\displaystyle\,\leq\,1+\frac{n-1}{d^{\perp}-1}=1+\frac{2^{k}-2}{2^{k-1}-1}

\displaystyle=1+\frac{2(2^{k-1}-1)}{2^{k-1}-1}=3.

To show that the bound is tight for all
\ell\in[k]
, note that:

•

All nonzero codewords in the Simplex code
\mathcal{C}^{\perp}
have weight
2^{k-1}
, and hence are minimum-weight codewords.

•

The supports of these codewords form a
2
-design
[
20
]
.

Thus, the achievability condition in Corollary
1
is satisfied, and the upper bound is attained.
∎

VI
Conclusion

We presented a unified framework for analyzing the service-rate region (SRR) of linear codes through the lens of orthogonal parity checks and combinatorial design theory. By establishing upper and lower bounds on the maximal achievable demand for each data object, we linked SRR analysis with the error-correction capability of one-step MLD. Our results recover known SRR characterizations for a variety of codes, and provide the first SRR description for Hamming codes. Furthermore, we showed that the achievability of the upper bound is guaranteed when minimum-weight dual codewords form a 2-design. This connection between SRR structure and classical design theory opens new directions for understanding and optimizing coded storage systems.
