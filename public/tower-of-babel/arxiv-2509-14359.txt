On the extension of a class of Hermite bivariate interpolation problems
Hakop Hakopian, Anush Khachatryan

Abstract
We characterize the sets of solvability for Hermite bivariate interpolation problems when the sum of multiplicities is at most 2 ​ n + 2 2n+2 , with n n the degree of the polynomial space. This result extends an earlier theorem (2000) by one of the authors concerning the case 2 ​ n + 1 2n+1 . The latter theorem, in turn, can be regarded as a natural generalization of a classical theorem of Severi (1921).

Introduction

In this paper, we characterize the sets of solvability for Hermite bivariate interpolation problems when the sum of multiplicities is at most
2n+2
, where
n
denotes the degree of the polynomial space (see Theorem
2.1
). This extends a previous result (Theorem
1.20
) that addresses the case of
2n+1
. The latter theorem can, in turn, be regarded as a natural generalization of a classical theorem of Severi (Theorem
1.21
).

One should mention that the correctness of Hermite problems was
considered first in algebraic geometry by M. Nagata
[
6
]
. In approximation
theory the investigation was initiated by G. G. Lorentz and R. A. Lorentz
[
4
]
.

It should be noted also that a similar study in the case of Lagrange bivariate interpolation is more advanced (see
[
1
]
).

1.1
Lagrange bivariate interpolation

Denote the space of bivariate polynomials of total degree

\leq n
with real or complex coefficients:

\Pi_{n}=\left\{\sum_{i+j\leq n}a_{ij}x^{i}y^{j}\right\},

N:=N_{n}:=\dim\Pi_{n}={n+2\choose 2}.

Let us fix a set of distinct nodes in the plane:

\mathcal{X}:=\mathcal{X}_{s}=\{A_{1},\ldots,A_{s}\},\ \hbox{where}\ A_{i}=(x_{i},y_{i}).

(1.1)

The problem of finding a polynomial
p\in\Pi_{n}
satisfying the conditions

p(x_{i},y_{i})=c_{i},\ \ \quad i=1,2,\dots s,

(1.2)

for a given data
{\bf\hat{c}}:=\{c_{1},\dots,c_{s}\},
is called
Lagrange interpolation problem.

Definition 1.1
.

A set of nodes
\mathcal{X}_{s}
is called

n
-
solvable
if for any data
{\bf\hat{c}}
there exists a
polynomial (not necessarily unique)
p\in\Pi_{n}
, satisfying the conditions
(
1.2
).

Denote by
p|_{\mathcal{X}}
the restriction of
p
on the set
\mathcal{X}.

A polynomial
p\in\Pi_{n}
is called an
n
-
fundamental polynomial

for
A=(x_{k},y_{k})\in\mathcal{X}
if

p|_{\mathcal{X}\setminus\{A\}}=0\ \hbox{and}\ p(A)=1.

We denote this

n
-fundamental polynomial by

p_{k}^{\star}=p_{A}^{\star}=p_{A,\mathcal{X}}^{\star}.

Let us mention that sometimes we call
n
-fundamental a polynomial
p\in\Pi_{n}
satisfying the conditions

p|_{\mathcal{X}\setminus\{A\}}=0\ \hbox{and}\ p(A)\neq 0,

since it equals a non-zero constant times
p_{A}^{\star}.

Definition 1.2
.

A set of nodes
\mathcal{X}
is called
n
-
independent
if each node
has an
n
-fundamental polynomial. Otherwise, it is called
n
-
dependent.

If a set
\mathcal{X}_{s}
is
n
-independent then the following Lagrange formula gives a solution to the problem (
1.2
):

p=\sum_{i=1}^{s}c_{i}p^{\star}_{i}.

Thus we obtain:

Proposition 1.3
.

A node set
\mathcal{X}_{s}

is
n
-independent if and only if it is
n
-solvable.

Fundamental polynomials are linearly independent. Therefore a
necessary condition of
n
-independence, or
n
-solvability, is

\#\mathcal{X}_{s}=s\leq N.

Definition 1.4
.

A set of nodes
\mathcal{X}_{s}
is called

n
-
correct
if for any data
{\bf\hat{c}}
there exists a
unique polynomial
p\in\Pi_{n}
, satisfying the conditions
(
1.2
).

A necessary condition of

n
-correctness is:

\#\mathcal{X}_{s}=s=N.

For the sets of nodes
\mathcal{X}
satisfying the above condition we have

Proposition 1.5
.

Assume that
\#\mathcal{X}=N.
Then the following conditions are equivalent:

(i)

The set
\mathcal{X}
is
n
-correct.

(ii)

The set
\mathcal{X}
is
n
-solvable.

(iii)

p\in\Pi_{n},\ p|_{\mathcal{X}}=0\implies p=0.

A
plane algebraic curve
is the zero set of some bivariate polynomial of degree
\geq 1.
To simplify notation, we shall use the same letter, say
p
,
to denote the polynomial
p
and the curve given by the equation
p(x,y)=0
.
In particular, by
\alpha
we denote a linear
polynomial from
\Pi_{1}
and the line defined by the equation

\alpha(x,y)=0.
Similarly by
\beta
we denote a quadratic
polynomial from
\Pi_{2}
and the conic defined by the equation

\beta(x,y)=0.

1.2
Hermite bivariate interpolation

Hermite interpolation problem
is determined by a pair
(\mathcal{N},\mathcal{X}),
where
\mathcal{X}:=\mathcal{X}_{s}
is a set of nodes given by (
1.1
) and

\mathcal{N}:=\{n_{1},\ldots,n_{s};n\}

is a
scheme
, i.e., a sequence of multiplicities of the nodes associated with the degree
n.

As a rule we assume that the multiplicities in the scheme
\mathcal{N}
are non-increasing:

n_{1}\geq n_{2}\geq\cdots\geq n_{s}.

(1.3)

Denote

D^{ij}p={\partial^{i+j}{p}\over{\partial{x}^{i}\partial{y}^{j}}}.

In the problem
(\mathcal{N},\mathcal{X})
the
interpolation parameters
at a given node
A_{k}=(x_{k},y_{k}),\ 1\leq k\leq s,
are the value of a polynomial and its partial
derivatives up to the order
n_{k}-1:

D^{ij}p(x_{k},y_{k})=c_{k}^{ij}\quad\forall i,j;\ i+j\leq n_{k}-1,\ \ k=1,2,\ldots,s.

(1.4)

The problem of finding a polynomial
p\in\Pi_{n}
satisfying the above conditions,
for a data

{\bf\tilde{c}}:=\{c_{k}^{ij}\ |\ i+j\leq n_{k}-1,\ 1\leq k\leq s\},

is called Hermite interpolation problem.

We express briefly the conditions (
1.4
) as follows

D^{\mathcal{N}}p|_{\mathcal{X}}={\bf\tilde{c}}.

Nodes whose multiplicity is equal to one are called
simple
. At these nodes only the value of a polynomial is interpolated in the conditions (
1.4
).

It is sometimes convenient to allow nodes of multiplicity
0
in the problem
(\mathcal{N},\mathcal{X}).
In fact, such a node can be ignored because there is no interpolation condition.

Definition 1.6
.

A problem
(\mathcal{N},\mathcal{X})
is called

n
-
solvable
if for any data
{\bf\tilde{c}}
there exists a
polynomial (not necessarily unique)
p\in\Pi_{n}
, satisfying
(
1.4
).

A polynomial
p\in\Pi_{n}
is called an
n
-
fundamental polynomial

for a parameter
D^{i^{\prime}j^{\prime}}p(x_{k^{\prime}},y_{k^{\prime}}),\ i^{\prime}+j^{\prime}\leq n_{k^{\prime}}-1,\ 1\leq k^{\prime}\leq s.
if it is a solution to the problem
(
1.4
) where
c_{k}^{ij}=0\ \ \forall(i,j,k)\neq(i^{\prime},j^{\prime},k^{\prime})\ \hbox{and}\ c_{k^{\prime}}^{i^{\prime}j^{\prime}}=1.

The above fundamental polynomial we denote by

p_{k^{\prime}}^{\star i^{\prime}j^{\prime}}=p_{k^{\prime}\mathcal{N}\mathcal{X}}^{\star i^{\prime}j^{\prime}}.

Definition 1.7
.

A problem

(\mathcal{N},\mathcal{X})
is called

n
-
independent
if for each parameter in (
1.4
) there is an
n
-fundamental polynomial.

The Lagrange formula for the above problem
(\mathcal{N},\mathcal{X}),
giving a solution to the problem (
1.4
), takes the form:

p=\sum_{k=1}^{s}\sum_{i+j\leq n_{k}-1}c_{k}^{ij}p_{k}^{\star{ij}}.

From here we get:

Proposition 1.8
.

A problem
(\mathcal{N},\mathcal{X})
is
n
-
independent

if and only if it is
n
-solvable.

Denote

\overline{k}=1+2+\cdots+k={k+1\choose 2}.

We have that the number of interpolation conditions at a node
A_{k}=(x_{k},y_{k})
in (
1.4
) equals to
\overline{n}_{k}.
Hence the total number of the conditions equals to

\mathcal{N}_{\#}:=\sum_{k=1}^{s}\overline{n}_{k}.

(1.5)

It is easily seen that fundamental polynomials are linearly independent. Also we have that
N=\overline{n+1}.
Therefore a
necessary condition of
n
-independence, or
n
-solvability, of the problem
(\mathcal{N},\mathcal{X})
is

\mathcal{N}_{\#}\leq\overline{n+1}.

A scheme
\mathcal{N}
satisfying the above condition we call
(\leq)
-scheme
.

A scheme
\mathcal{N}
satisfying the condition

\mathcal{N}_{\#}<\overline{n+1}.

we call
(<)
-scheme
.

Definition 1.9
.

A problem
(\mathcal{N},\mathcal{X})
is called

n
-
correct
if for any data
{\bf\tilde{c}}
there exists a

unique
polynomial
p\in\Pi_{n}
, satisfying the conditions
(
1.4
).

A necessary condition of

n
-correctness is:

\mathcal{N}_{\#}=\overline{n+1}.

A scheme satisfying the above condition we call an
exact scheme.

Below we have the analog of Proposition
1.5
for the Hermite interpolation.

Proposition 1.10
.

Assume that a scheme
\mathcal{N}
is exact. Then the following conditions are equivalent:

(i)

The problem
(\mathcal{N},\mathcal{X})
is
n
-correct.

(ii)

The problem
(\mathcal{N},\mathcal{X})
is
n
-solvable.

(iii)

p\in\Pi_{n},\ D^{\mathcal{N}}p|_{\mathcal{X}}=0\implies p=0.

Proposition 1.11
.

Assume that in the problem
(\mathcal{N},\mathcal{X}),
the scheme
\mathcal{N}
is
(<)
-scheme. Then
there exists

p\in\Pi_{n},\ p\neq 0,\ \hbox{and}\ D^{\mathcal{N}}p|_{\mathcal{X}}=0.

Indeed, note that
\mathcal{N}_{\#}
is the number of interpolation conditions in (
1.4
) and each condition can be considered as a linear equation with respect to
N
unknown coefficients of
p\in\Pi_{n}.

Thus we get a linear homogeneous system, where the number of equations is less than the number of unknowns. As we know such systems have non-trivial solutions.

In the simplest case
\mathcal{N}=\{1,1,1,1,1;2\}
the above proposition implies

Lemma 1.12
.

For any five points, there exists a conic that passes through all of them.

For a
(<)
-scheme
\mathcal{N}:=\{n_{1},\ldots,n_{s};n\}
we define the exact
scheme

\widehat{\mathcal{N}}:=\{n_{1},\ldots,n_{s},\underbrace{1,\ldots,1}_{\text{$r$}};n\},\ \hbox{where}\ r=N-\#\mathcal{N}.

Accordingly, for a set

\mathcal{X}=\{A_{1},\ldots,A_{s}\},
we define

\widehat{\mathcal{X}}:=\mathcal{X}\cup\mathcal{S}=\{A_{1},\ldots,A_{s+r}\},

where
\mathcal{S}=\{A_{s+1},\ldots,A_{s+r}\}
is a set of
r
simple points.

Proposition 1.13

(
[
5
]
, lemma 2.1)
.

The problem
(\widehat{\mathcal{N}},\widehat{\mathcal{X}})
is
n
-correct, for some
\widehat{\mathcal{X}},
if and only if the
problem
(\mathcal{N},\mathcal{X})
is
n
-solvable.

For the sake of completeness we present:

Proof.

The direction “only if” is evident. For the direction “if”, in view of Proposition
1.10
, it is enough to prove that there exists a (simple) node
A_{s+1}
such that
the problem
(\mathcal{N}^{\prime},\mathcal{X}^{\prime}),
where
\mathcal{X}^{\prime}=\mathcal{X}\cup\{A_{s+1}\}

and
\mathcal{N}:=\{n_{1},\ldots,n_{s},1;n\}
is
n
-solvable. For this, in view of
n
-solvability of
(\mathcal{N},\mathcal{X}),
we need just an
n
-fundamental polynomial of the simple node
A_{s+1}.

Now, according to Proposition
1.11
, there exists

p\in\Pi_{n},\ p\neq 0,\ \hbox{and}\ D^{\mathcal{N}}p|_{\mathcal{X}}=0.

Since
p\neq 0
there is a point:
A_{s+1}
such that
p(A_{s+1})\neq 0.

It is easily seen that the polynomial
p
is the desired
n
-fundamental polynomial
of
A_{s+1}.

∎

Let
\mathcal{N}:=\{n_{1},\ldots,n_{s};n\},

\mathcal{X}_{s}=\{A_{i}\}_{i=1}^{s}
and
\mathcal{X}_{s}^{\prime}=\{A_{i}^{\prime}\}_{i=1}^{s}.

Remark 1.14

(
[
3
]
, rem.1.14)
.

If the problem
(\mathcal{N},\mathcal{X})
is
n
-solvable, then so is the problem
(\mathcal{N},\mathcal{X}^{\prime})
with

sufficiently close to
A_{i},\ i=1,\ldots,s.

Definition 1.15
.

Let
(\mathcal{N},\mathcal{X})
be a problem, where
\mathcal{X}
is given by (
1.1
), and
f
be a curve of degree
m.
Then we define the scheme
\Delta^{f}_{\mathcal{X}}
as follows

\Delta^{f}_{\mathcal{X}}:=\{\delta(1),\ldots,\delta(s);m\},

(1.6)

where
\delta(k)=1
if
{A_{k}}\in f,
and
\delta(k)=0
otherwise.

Denote by
\#f_{\mathcal{N},\mathcal{X}}
the number of nodes from
\mathcal{X}
on the curve
f,
counted with the multiplicities from
\mathcal{N}:

\#f_{\mathcal{N},\mathcal{X}}=\sum_{i=1}^{s}\delta(i)n_{i}=\sum_{i=1}^{s}\overline{n}_{i}-\sum_{i=1}^{s}\overline{n_{i}-\delta(i)}.

(1.7)

Note that in what follows, this notation, as well as the previous definition, mainly will be used in cases where the curve
f
is a line or a conic.

We will need the following well-known proposition (see e.g.
[
2
]
, lemma 4):

Proposition 1.16
.

Let
\mathcal{N}:=\{n_{1},\ldots,n_{s};n\}
be a scheme with

n_{1}+\cdots+n_{s}=n+1
and
\mathcal{X}
be a set of nodes with
\mathcal{X}\subset\ell^{0},
where
\ell^{0}
is a line. Then

p\in\Pi_{n},\ D^{\mathcal{N}}p|_{\mathcal{X}}=0\implies p=\ell^{0}q,\ \hbox{where}\ q\in\Pi_{n-1}.

Set

d(n,k):=N_{n}-N_{n-k}=(n-k+2)+(n-k+3)+\cdots+(n+1)=(1/2)k(2n+3-k).

The following proposition we will use for lines and (irreducible) conics.

Proposition 1.17
.

Let
\mathcal{N}:=\{n_{1},\ldots,n_{s};n\}
be a scheme with non-increasing sequence of
multiplicities. If the problem
(\mathcal{N},\mathcal{X})
is
n
-solvable for a set of nodes
\mathcal{X},
then for any curve
f
of degree
k\leq n
we have that

\#f_{\mathcal{N},\mathcal{X}}\leq d(n,k).

Proof.

Let the problem
(\mathcal{N},\mathcal{X})
be
n
-solvable for a set of nodes
\mathcal{X}.

Assume, by way of contradiction, that for a curve
f^{0}
of degree
k\leq n,
we have that

\#f_{\mathcal{N},\mathcal{X}}^{0}>d(n,k).

Then,
Proposition
1.13
implies that

(\widehat{\mathcal{N}},\widehat{\mathcal{X}})\ \hbox{is $n$-correct,}

(1.8)

for some
\widehat{\mathcal{X}}=\mathcal{X}\cup\mathcal{S},

where
\mathcal{S}
is a set of
r
simple points with
r=N-\mathcal{N}_{\#}
and

\widehat{\mathcal{N}}:=\{n_{1},\ldots,n_{s},\underbrace{1,\ldots,1}_{\text{$r$}};n\}.

Moreover, by making use of
Remark
1.14
we may assume that
the set
\mathcal{S}
contains no point from the curve
f^{0}.

Consider the following scheme

\widehat{\mathcal{N}}^{0}:=\widehat{\mathcal{N}}-\Delta^{f^{0}}_{\widehat{\mathcal{X}}}=\{n_{1}^{0},\ldots,n_{s}^{0},\underbrace{1,\ldots,1}_{\text{$r$}};n-k\}

:=\{n_{1}-\delta(1),\ldots,n_{s}-\delta(s),\underbrace{1,\ldots,1}_{\text{$r$}};n-k\}.

The above condition on the curve
f^{0},
in view of (
1.7
), means that

\sum_{i=1}^{s}\delta(i)n_{i}>d(n,k).

(1.9)

Then let us check that
\widehat{\mathcal{N}}^{0}
is
(<)
-scheme. Indeed, by using (
1.7
) and (
1.9
), we get

\widehat{\mathcal{N}}^{0}_{\#}=\sum_{i=1}^{s}\overline{n_{i}-\delta(i)}+r<\sum_{i=1}^{s}\overline{n}_{i}+r-d(n,k)=\overline{n+1}-d(n,k)=\overline{n-k}.

(1.10)

Therefore, in view of Proposition
1.11
, there exists a polynomial
p^{0}\in\Pi_{n-k}
such that

D^{\widehat{\mathcal{N}}^{0}}p^{0}|_{\widehat{\mathcal{X}}}=0.

Now one readily obtains for the polynomial
p:=f^{0}p^{0}\in\Pi_{n}

that

D^{\widehat{\mathcal{N}}}p|_{\widehat{\mathcal{X}}}^{0}=0.

This, in view of Proposition
1.10
, contradicts the
n
-correctness of the problem
(\widehat{\mathcal{N}},\widehat{\mathcal{X}}).

Corollary 1.19

Let
\mathcal{N}:=\{n_{1},\ldots,n_{s};n\}

Now we are in a position to present the result (slightly reformulated), which we will extend.

Theorem 1.20

(
[
2
]
, th. 9)
.

Let
\mathcal{N}:=\{n_{1},\ldots,n_{s};n\}
be a scheme, satisfying the condition

\sum_{i=1}^{s}n_{i}\leq 2n+1.

(1.11)

Then the problem
(\mathcal{N},\mathcal{X})
is

n
-solvable if and only if there is no line passing through more than
n+1

\mathcal{X}.

This theorem can be regarded as a natural generalization of the following classical theorem of Severi (1921).

Theorem 1.21

(Severi
[
7
]
, th. 9)
.

Let
\mathcal{N}:=\{n_{1},\ldots,n_{s};n\}
be a scheme. The problem
(\mathcal{N},\mathcal{X})
is solvable for any node set
\mathcal{X}
if and only if

\sum_{i=1}^{s}n_{i}\leq n+1.

From Theorem
1.20
we get

Corollary 1.22
.

For any scheme
\{n_{1},\ldots,n_{s};n\},
with non-increasing sequence of multiplicities, we have that

n_{1}+n_{2}\leq n+1,\ \ \sum_{i=1}^{s}n_{i}\leq 2n+1\implies\sum_{i=1}^{s}\overline{n}_{i}\leq\overline{n+1}.

(1.12)

Indeed, consider the problem
(\mathcal{N},\mathcal{X}),
where in
\mathcal{X}
no three nodes are collinear. Then according to Theorem
1.20
the problem
(\mathcal{N},\mathcal{X})
is
n
-solvable. Hence
\mathcal{N}
is
(\leq)
-scheme.

Proposition 1.23
.

Let
\mathcal{N}:=\{n_{1},\ldots,n_{s};n\}
be a scheme with non-increasing sequence of
multiplicities such that

n_{1}+n_{2}\leq n+1,\quad n_{1}+\cdots+n_{s}=2n+1,\ s\geq 5,\ n_{s}\geq 1.

Suppose
\mathcal{X}
is a set of
s

\mathcal{X}\subset\beta^{0}
where
\beta^{0}
is an irreducible conic. Then we have that

p\in\Pi_{n},\ D^{\mathcal{N}}p|_{\mathcal{X}}=0\implies p=\beta^{0}q,\ \hbox{where}\ q\in\Pi_{n-2}.

Proof.

Consider the following scheme:

\mathcal{N}^{0}:=\{n_{1}^{0},\ldots,n_{s}^{0};n-2\}:=\{n_{1}-1,\ldots,n_{s}-1;n-2\}.

We have that

\sum_{i=1}^{s}n^{0}_{i}=\sum_{i=1}^{s}n_{i}-s\leq 2n+1-5=2(n-2).

Note that

n_{1}^{0}+n_{2}^{0}:=n_{1}+n_{2}-2\leq(n-2)+1.

The above inequality, in view of irreducibility of
\beta_{0},
implies that the
l/(n-1)
-condition is satisfied.
Thus, in view of Theorem (
1.20
), we obtain that the problem
(\mathcal{N}^{0},\mathcal{X})
is
(n-2)
-solvable. Similarly we obtain that the problem
(\mathcal{N},\mathcal{X})
is
n
-solvable.

Now consider the following linear spaces:

V:=\{p\in\Pi_{n}\ |\ D^{\mathcal{N}}p|_{\mathcal{X}}=0\},

V_{0}:=\{\beta^{0}q\ |\ q\in\Pi_{n-2},\ D^{\mathcal{N}^{0}}q|_{\mathcal{X}}=0\}.

Note that
V_{0}\subset V.

In view of … we have that

\dim V=\overline{n+1}-\sum_{i=1}^{s}\overline{n}_{i}=\overline{n-1}+2n+1-(\sum_{i=1}^{s}\overline{n_{i}-1}+2n+1)

=\overline{n-1}-\sum_{i=1}^{s}\overline{n_{i}-1}=\dim V_{0}.

Thus we obtain that
V=V_{0}.

∎

Remark 1.24
.

Let
\mathcal{N}:=\{n_{1},\ldots,n_{4};n\}

Therefore Proposition

, we have the condition:
\mathcal{N}
is
(\leq)
-scheme.

2
The result

In this section we will prove the following

Theorem 2.1
.

Let
\mathcal{N}:=\{n_{1},\ldots,n_{s};n\}
be a
(\leq)
-scheme satisfying the condition

\sum_{i=1}^{s}n_{i}\leq 2n+2.

(2.1)

Then the problem
(\mathcal{N},\mathcal{X})
is

n
-solvable if and only if

(i)

there is no line passing through more than
n+1
nodes
of
(\mathcal{N},\mathcal{X})
,

(ii)

there is no conic passing through more than
2n+1
nodes of
(\mathcal{N},\mathcal{X}).

Proof.

The direction “only if” follows from Corollary
1.18
. Let us prove the direction “if”.

Note that the above condition (ii) means that
there is no conic passing through all the nodes of
\mathcal{X}.

In view of Theorem
1.20
we can assume, in what
follows, that

\sum_{i=1}^{s}n_{i}=2n+2.

(2.2)

From now on suppose also that
\mathcal{N}:=\{n_{1},\ldots,n_{s};n\}
is a scheme with non-increasing sequence of multiplicities:

n_{1}\geq n_{2}\geq\cdots\geq n_{s}.

(2.3)

In view of Corollary
1.19
we have that

n_{1}+n_{2}\leq n+1.

(2.4)

We can assume also that

n_{1}\leq n-1.

(2.5)

Indeed, the only
(\leq)
- scheme, in the case
n_{1}=n+1
is the Taylor scheme
\{n+1;n\},
which does not satisfy (
2.2
).
While if
n_{1}=n
then the conditions (
2.2
) and (
2.4
) imply that

\mathcal{N}=\{n,\underbrace{1,\ldots,1}_{\text{$n+2$}};n\},

which is not
(\leq)
- scheme.

We will apply induction
on the degree of the scheme
\mathcal{N}.

Step 1.

It is easily seen that if
n=1,
then there is no
(\leq)
-scheme satisfying the condition (
2.2
).

In the case
n=2,
there is only one
(\leq)
- scheme

\mathcal{N}=\{1,1,1,1,1,1;2\}
satisfying the conditions (
2.2
) and (
2.5
). According to the condition (ii) of Theorem, the six simple nodes of the set
\mathcal{X}
do not belong to a conic. Since
\mathcal{N}
is exact scheme, by Proposition
1.5
(iii), we get that
\mathcal{X}
is
2
-correct.

Now, assuming the statement holds for all degrees
\leq n-1,
we will prove it for
n,
where
n\geq 3.

Step 2.
Assume that there is a line
\ell^{0}
which passes through
n+1
nodes of
(\mathcal{N},\mathcal{X}),
i.e., the following condition is satisfied:

\#\ell^{0}_{\mathcal{N},\mathcal{X}}=n+1.

(2.6)

Consider the scheme (see (
1.6
))

\mathcal{N}^{0}:=\mathcal{N}-\Delta^{\ell^{0}}_{\mathcal{X}}=\{n_{1}^{0},\ldots,n_{s}^{0};n-1\}:=\{n_{1}-\delta(1),\ldots,n_{s}-\delta(s);n-1\}.

From (
1.7
), in view of the condition (
2.6
), we have that

\sum_{k=1}^{s}\overline{n}_{k}=\sum_{k=1}^{s}\overline{n_{k}-\delta(k)}+n+1.

(2.7)

Now let us check that
\mathcal{N}^{0}
is
(\leq)
- scheme. Indeed, by using (
2.7
), we get

\sum_{k=1}^{s}\overline{n}_{k}^{0}=\sum_{k=1}^{s}\overline{n_{k}-\delta(k)}=\sum_{k=1}^{s}\overline{n}_{k}-(n+1)\leq\overline{n+1}-(n+1)=\overline{n}.

(2.8)

The condition (
2.1
) for
\mathcal{N}^{0},
readily follows from the fact that
\ell^{0}
passes through at least two nodes of
\mathcal{X}:

\sum_{i=1}^{s}n_{i}^{0}=\sum_{i=1}^{s}\ n_{i}-\sum_{i=1}^{s}\delta(i)\leq 2n+2-2=2n.

(2.9)

Then let us verify that the
l/n
-condition is satisfied with respect to the problem
(\mathcal{N}^{0},\mathcal{X}),
i.e., there is no
line
\ell
containing
\geq(n+1)
nodes of
(\mathcal{N}^{0},\mathcal{X}).
Assume conversely that there is such a
line
\ell.
Then evidently
\ell\neq\ell^{0}
and, in view of the relation

\#\ell_{\mathcal{N}^{0},\mathcal{X}}\leq\#\ell_{\mathcal{N},\mathcal{X}},

we obtain that
\ell
contains
n+1
nodes from
(\mathcal{N},\mathcal{X}).

Since
\ell
contains
n+1
nodes both from
(\mathcal{N},\mathcal{X})
and
(\mathcal{N}^{0},\mathcal{X}),
we conclude that the line
\ell
does not intersect
\ell_{0}
at a node of
\mathcal{X}.

Therefore, the (reducible) conic
\beta=\ell^{0}\ell
passes through
2n+2
nodes of
\mathcal{X},
which contradicts the condition (ii) of Theorem.

Finally let us verify the
c/(2n-1)
-condition for the problem
(\mathcal{N}^{0},\mathcal{X}).
Assume, by way of contradiction, that there is a
conic
\beta
containing
2n
nodes of
(\mathcal{N}^{0},\mathcal{X}).

In view of (
2.9
) this means that
\beta
passes through all the nodes
A_{i}\in\mathcal{X}
with
n^{0}_{i}\geq 1.

Note that if
\ell^{0}
passes through at least three nodes of
\mathcal{X}
then
in (
2.9
) we would obtain
\sum_{i=1}^{s}n_{i}^{0}\leq 2n-1
and hence the

c/(2n-1)
-condition is satisfied. It remains to consider the case where

\ell^{0}
passes through exactly two nodes, say,
A_{r},A_{s}\in\mathcal{X}.
In this case, in view of (
2.6
), we have that
n_{r}+n_{s}=n+1.
According to (
2.5
) we get that
n_{r},n_{s}\geq 2.
Hence we have that
n_{i}^{0}\geq 1\ \forall 1\leq i\leq s.
Thus
\beta
passes through all the nodes of
\mathcal{X},
which is contradiction.

Therefore, the problem
(\mathcal{N}^{0},\mathcal{X})
is
(n-1)
-solvable by virtue of the induction hypothesis.

Now, Proposition
1.13
implies that there is a set
\mathcal{S}_{0},
consisting of
r:=\overline{n}-\mathcal{N}^{0}_{\#}
simple nodes, such that the problem

(\widehat{\mathcal{N}}^{0},\widehat{\mathcal{X}})\ \hbox{is $(n-1)$-correct,}

(2.10)

where

\widehat{\mathcal{N}}^{0}=\{n_{1}^{0},\ldots,n_{s}^{0},\underbrace{1,\ldots,1}_{\text{$r$}};n-1\},\quad\widehat{\mathcal{X}}=\mathcal{X}\cup\mathcal{S}_{0},

and the
r
nodes of
\mathcal{S}_{0}
correspond to the last
r
ones in
\widehat{\mathcal{N}}^{0}.

Here, by making use of
Remark
1.14
, we can also assume that
the set
\mathcal{S}_{0}
contains no node belonging to the line
\ell_{0}.

Now consider the problem
(\widehat{\mathcal{N}},\widehat{\mathcal{X}}),

where

\widehat{\mathcal{N}}=\{n_{1},\ldots,n_{s},\underbrace{1,\ldots,1}_{\text{$r$}};n\}.

Let us check first that
\widehat{\mathcal{N}}
is exact scheme. Indeed, in view of (
2.7
), we have that

\widehat{\mathcal{N}}_{\#}=\mathcal{N}_{\#}+\#\mathcal{S}_{0}=\mathcal{N}_{\#}^{0}+(n+1)+\#\mathcal{S}_{0}=\overline{n}+(n+1)=\overline{n+1}.

(2.11)

Next, let us prove that the problem
(\widehat{\mathcal{N}},\widehat{\mathcal{X}})
is
n
-correct. For this, let us assume, in view of Proposition
1.10
, (iii), that

D^{\widehat{\mathcal{N}}}p|_{\widehat{\mathcal{X}}}=0,
where
p\in\Pi_{n}

and prove that
p=0.

By the choice of the set
\mathcal{S}_{0}
and the condition (
2.6
) we have that

\#\ell^{0}_{\widehat{\mathcal{N}},\widehat{\mathcal{X}}}=n+1.

Now, Proposition
1.16
implies that
p=\ell_{0}q,
where

q\in\Pi_{n-1}\ \hbox{and}\ D^{\widehat{\mathcal{N}}^{0}}q|_{\widehat{\mathcal{X}}}=0.

Now, in view of (
2.10
) and Proposition
1.10
, we get
q=0,
and hence
p=0.

Thus, the problem
(\widehat{\mathcal{N}},\widehat{\mathcal{X}})
is
n
-correct, which implies evidently that
(\mathcal{N},\mathcal{X})
is
n
-solvable. ∎

From now on, in view of Step 2, we can assume that the
l/n
-condition is satisfied for the scheme
\mathcal{N},
which implies that

n_{1}+n_{2}\leq n.

(2.12)

Step 3.

Assume that there is a line
\ell^{0}
passing through at least
3
nodes of
\mathcal{X}.

Consider the following scheme (see (
1.6
))

\mathcal{N}^{0}:=\mathcal{N}-\Delta^{\ell^{0}}_{\mathcal{X}}=\{n_{1}^{0},\ldots,n_{s}^{0};n-1\}:=\{n_{1}-\delta(1),\ldots,n_{s}-\delta(s);n-1\}.

We have that

\sum_{i=1}^{s}n_{i}^{0}=\sum_{i=1}^{s}\ n_{i}-\sum_{i=1}^{s}\delta(i)\leq 2n+2-3=2(n-1)+1,

On the other hand, in view of Step 2, the
l/n
-condition holds.
Thus according to Theorem
1.20
we obtain that the problem
(\mathcal{N}^{0},\mathcal{X})
is
(n-1)
-solvable.

Now, Proposition
1.13
implies that there is a set
\mathcal{S}_{0},
consisting of
r_{0}:=\overline{n}-\mathcal{N}^{0}_{\#}
simple nodes, such that the problem

(\widehat{\mathcal{N}}^{0},\widehat{\mathcal{X}})\ \hbox{is $(n-1)$-correct,}

(2.13)

where

\widehat{\mathcal{N}}^{0}=\{n_{1}^{0},\ldots,n_{s}^{0},\underbrace{1,\ldots,1}_{\text{$r_{0}$}};n-1\},\quad\widehat{\mathcal{X}}=\mathcal{X}\cup\mathcal{S}_{0}.

Again, by making use of
Rremark
1.14
, we can assume also that
the set
\mathcal{S}_{0}
contains no node belonging to the line
\ell_{0}.

Then denote by
\mathcal{S}_{1}
a set of
r_{1}:=n+1-\#\ell^{0}_{\mathcal{N},\mathcal{X}}

simple nodes in
\ell^{0}\setminus\mathcal{X}.

Consider
the problem
(\widetilde{\mathcal{N}},\widetilde{\mathcal{X}}),
where

\widetilde{\mathcal{X}}:=\mathcal{X}\cup\mathcal{S}_{0}\cup\mathcal{S}_{1},
and

\widetilde{\mathcal{N}}=\{n_{1},\ldots,n_{s},\underbrace{1,\ldots,1}_{\text{$r_{0}+r_{1}$}};n\}.

Let us check first that
\widetilde{\mathcal{N}}
is exact scheme. Indeed, we have that

r_{0}+r_{1}=\overline{n}-\mathcal{N}_{\#}^{0}+(n+1)-\#\ell^{0}_{\mathcal{N},\mathcal{X}}=\overline{n+1}-\mathcal{N}_{\#}.

(2.14)

Next, let us prove that the problem
(\widetilde{\mathcal{N}},\widetilde{\mathcal{X}})
is
n
-correct. For this let us assume, in view of Proposition
1.10
, (iii), that

D^{\widetilde{\mathcal{N}}}p|_{\widetilde{\mathcal{X}}}=0,
where
p\in\Pi_{n},

and prove that
p=0.

In view of the choice of the sets
\mathcal{S}_{0}
and
\mathcal{S}_{1}
we have that

\#\ell^{0}_{\widetilde{\mathcal{N}},\widetilde{\mathcal{X}}}=n+1.

Therefore, Proposition
1.16
implies that
p=\ell_{0}q,
where

q\in\Pi_{n-1}\ \hbox{and}\ D^{\widehat{\mathcal{N}}^{0}}q|_{\widehat{\mathcal{X}}}=0.

Now, in view of (
2.13
) and Proposition
1.10
, we get
q=0,
and hence
p=0.

Thus, the problem
(\widetilde{\mathcal{N}},\widetilde{\mathcal{X}})
is
n
-correct, which implies that
(\mathcal{N},\mathcal{X})
is
n
-solvable. ∎

From now on, in view of Step 3, we may assume that there are no three collinear nodes in the set
\mathcal{X}.

Step 4.
First note that the condition (ii) of Theorem, in view of Lemma
1.12
, implies that
s\geq 6.

Consider a conic
\beta_{0}
passing through the nodes
A_{1},\ldots,A_{5}.
Since no three nodes are collinear the conic
\beta_{0}
is irreducible.

Consider the following scheme (see (
1.6
))

\mathcal{N}^{0}:=\mathcal{N}-\Delta^{\beta^{0}}_{\mathcal{X}}=\{n_{1}^{0},\ldots,n_{s}^{0};n-2\}:=\{n_{1}-\delta(1),\ldots,n_{s}-\delta(s);n-2\}.

We have that

\sum_{i=1}^{s}n^{0}_{i}=\sum_{i=1}^{s}n_{i}-\sum_{i=1}^{s}\delta(i)\leq 2n+2-5=2(n-2)+1.

Note that
\mathcal{N}^{0}
may not satisfy the condition (
2.3
).
Thus, to apply Theorem
1.20
, let us verify that

n_{i}^{0}+n_{j}^{0}:=n_{i}-\delta(i)+n_{j}-\delta(j)\leq n-1\ \forall 1\leq i<j\leq s.

Indeed, if
i\leq 5
then
\delta(i)=1
and, in view of (
2.12
), this is evident.

Now, assume conversely, that the inequality
n_{i}+n_{j}\geq n_{i}^{0}+n_{j}^{0}\geq n
holds for some
6\leq i<j\leq s.

Then, in view of (
2.3
), we have that
n_{5}+n_{6}\geq n_{i}+n_{j}\geq n,
and therefore
n_{1}+\cdots+n_{6}\geq 3(n_{5}+n_{6})\geq 3n.

On the other hand we have that
3n\geq 2n+3,
if
n\geq 3.

Hence we have that
n_{1}+\cdots+n_{6}\geq 2n+3,

which contradicts the condition (
2.1
).

Thus, according to Theorem
1.20
, the problem
(\mathcal{N}^{0},\mathcal{X})
is
(n-2)
-solvable.

Now, Proposition
1.13
implies that there is a set
\mathcal{S}_{0},
consisting of
r_{0}:=\overline{n-1}-\mathcal{N}^{0}_{\#}
simple nodes, such that the problem

(\widehat{\mathcal{N}}^{0},\widehat{\mathcal{X}})\ \hbox{is $(n-2)$-correct,}

(2.15)

where

\widehat{\mathcal{N}}^{0}=\{n_{1}^{0},\ldots,n_{s}^{0},\underbrace{1,\ldots,1}_{\text{$r_{0}$}};n-2\},\quad\widehat{\mathcal{X}}=\mathcal{X}\cup\mathcal{S}_{0}.

By making use of
Remark
1.14
we can assume that
the set
\mathcal{S}_{0}
contains no node belonging to the conic
\beta^{0}.

Next, denote by
\mathcal{S}_{1}
a set of
r_{1}:=2n+1-\#\beta^{0}_{\mathcal{N},\mathcal{X}}

simple nodes in
\beta^{0}\setminus\mathcal{X}.

Consider
the problem
(\widetilde{\mathcal{N}},\widetilde{\mathcal{X}}),
where

\widetilde{\mathcal{X}}:=\mathcal{X}\cup\mathcal{S}_{0}\cup\mathcal{S}_{1},
and

\widetilde{\mathcal{N}}=\{n_{1},\ldots,n_{s},\underbrace{1,\ldots,1}_{\text{$r_{0}+r_{1}$}};n\}.

Let us check first that
\widetilde{\mathcal{N}}
is exact scheme. Indeed, we have that

r_{0}+r_{1}=\overline{n}-\mathcal{N}_{\#}^{0}+(n+1)-\#\ell^{0}_{\mathcal{N},\mathcal{X}}=\overline{n+1}-\mathcal{N}_{\#}.

(2.16)

Next, let us prove that the problem
(\widetilde{\mathcal{N}},\widetilde{\mathcal{X}})
is
n
-correct. For this let us assume, in view of Proposition
1.10
, (iii), that

D^{\widetilde{\mathcal{N}}}p|_{\widetilde{\mathcal{X}}}=0,
where
p\in\Pi_{n}

and prove that
p=0.

By taking into account the choice of the sets
\mathcal{S}_{0}
and
\mathcal{S}_{1}
we have that

\#\beta^{0}_{\widetilde{\mathcal{N}},\widetilde{\mathcal{X}}}=2n+1.

Therefore, Proposition
1.23
implies that
p=\beta^{0}q,
where

q\in\Pi_{n-2}\ \hbox{and}\ D^{\widehat{\mathcal{N}}^{0}}q|_{\widehat{\mathcal{X}}}=0.

Now, in view of (
2.15
) and Proposition
1.10
, we get
q=0,
and hence
p=0.

Thus, the problem
(\widetilde{\mathcal{N}},\widetilde{\mathcal{X}})
is
n
-correct, which implies that
(\mathcal{N},\mathcal{X})
is
n
-solvable.
∎
