Residual Growth Control for General Maps and an Approximate Inverse Function Result
Mario Amrein

Abstract
. The need to control the residual of a potentially nonlinear function ℱ \mathcal{F} arises in several situations in mathematics. For example, computing the zeros of a given map, or the reduction of some cost function during an optimization process are such situations. In this note, we discuss the existence of a curve t ↦ x ⁡ ( t ) t\mapsto x(t) in the domain of the nonlinear map ℱ \mathcal{F} leading from some initial value x 0 x_{0} to a value u u such that we are able to control the residual ℱ ⁡ ( x ⁡ ( t ) ) \mathcal{F}(x(t)) based on the value ℱ ⁡ ( x 0 ) \mathcal{F}(x_{0}) . More precisely, we slightly extend an existing result from J.W. Neuberger by proving the existence of such a curve, assuming that the directional derivative of ℱ \mathcal{F} can be represented by x ↦ 𝒜 ⁡ ( x ) ​ ℱ ​ ( x 0 ) x\mapsto\mathcal{A}(x)\mathcal{F}(x_{0}) , where 𝒜 \mathcal{A} is a suitable defined operator. The presented approach covers, in case of 𝒜 ⁡ ( x ) = − 𝖨𝖽 \mathcal{A}(x)=-\mathsf{Id} , some well known results from the theory of so-called continuous Newton methods . Moreover, based on the presented results, we discover an approximate inverse function result.

1.
Introduction

The object of this work is a (possibly) nonlinear map
\mathcal{F}:X\rightarrow\mathbb{R}^{m}
with
X\subset\mathbb{R}^{n}
. Based on some initial guess
x_{0}\in X
and the curve
t\mapsto x(t)\in X
with
x|_{t=0}=x_{0}
, we want to control the residual

t\mapsto\mathcal{F}(x(t)),

(1.1)

using the initial residual
\mathcal{F}(x_{0})
.
In many situations, we are interested in zeros of
\mathcal{F}
. Apart of finding zeros for
\mathcal{F}
, e.g., in machine learning tasks, one often seeks to minimize some cost function
\mathcal{F}
using an initial condition
x_{0}
, i.e., for some
t_{1}>0
, we would like to have

\left\|\mathcal{F}(x(t_{1}))\right\|\leq c\cdot\left\|\mathcal{F}(x_{0})\right\|

for a constant
c<1
.
However, in case of
X
being a subset of
\mathbb{R}^{m}
with initial value
x_{0}\in X
, and assuming that the derivative of
\mathcal{F}
is invertible, the well-known ODE, also called Davidenko’s method
[
3
]
, given by

\begin{cases}\dot{x}&=-[\mathcal{F}^{\prime}(x)]^{-1}\mathcal{F}(x_{0})\\
x|_{t=0}&=x_{0}\end{cases}

(1.2)

may serve as a possible scheme to find a zero for
\mathcal{F}
starting from the initial value
x_{0}\in X
. Indeed, under suitable
assumptions on
\mathcal{F}
, there exists a solution
t\mapsto x(t)
on the interval
[0,1]
solving (
1.2
) and leading to a zero of
\mathcal{F}
. Notice that this solution is implicitly given by

\mathcal{F}(x(t))=(1-t)\mathcal{F}(x_{0}),

i.e.,
\mathcal{F}(x(1))=0
. Let us briefly outline the connection between the well-known continuous Newton method given by the initial value problem

\begin{cases}\dot{z}&=-[\mathcal{F}^{\prime}(z)]^{-1}\mathcal{F}(z)\\
z|_{t=0}&=x_{0}\end{cases}

(1.3)

and the initial value problem from (
1.2
). First of all, notice that a solution
t\mapsto z(t)
of (
1.3
) satisfies
\mathcal{F}(z(t))=\mathcal{F}(x_{0})\mathrm{e}^{-t}
. Thus, given a solution
t\mapsto x(t)
of (
1.2
), we obtain the solution
z(t)
based on

z(t)=x(w(t)),\qquad\text{with}\qquad t\mapsto w(t)=1-\mathrm{e}^{-t}.

On the other hand, given a solution of (
1.3
), we obtain a solution
x(t)
of (
1.2
) using

x(t)=z(w^{-1}(t)),\qquad\text{with}\qquad t\mapsto w^{-1}(t)=\ln\left(\frac{1}{1-t}\right).

Regarding the initial value problem (
1.2
), a somewhat natural approach is to replace the ODE (
1.2
) by the more general ODE

\begin{cases}\dot{x}&=\mathcal{M}(x)\mathcal{F}(x_{0})\\
x|_{t=0}&=x_{0},\end{cases}

(1.4)

where
X\ni x\mapsto\mathcal{M}(x)\in\mathbb{R}^{n\times m}
. In case of
n=m
and assuming that
\mathcal{M}(x)
is approximately
-[\mathcal{F}^{\prime}(x)]^{-1}
, we still may expect that the residual
\mathcal{F}
decreases on a trajectory
t\mapsto x(t)
solving (
1.4
).

Let us take a closer look at this situation.
Assume for the moment that on the set
X\subset\mathbb{R}^{n}
the map
X\ni x\mapsto\mathcal{F}^{\prime}(x)\in\mathbb{R}^{m\times n}
exists. In addition, let
t\mapsto x(t)
be a solution of (
1.4
). Formally we now use the derivative of
\mathcal{F}
, multiply (
1.4
) from the left with
\mathcal{F}^{\prime}(x)
, and obtain:

\frac{\mathsf{d}}{\mathsf{d}t}\mathcal{F}(x(t))=\mathcal{A}(x(t))\mathcal{F}(x_{0}),\quad\mathcal{A}(x):=\mathcal{F}^{\prime}(x)\mathcal{M}(x)\in\mathbb{R}^{m\times m}.

(1.5)

Integrating (
1.5
) on
[0,T]
, we end up with

\mathcal{F}(x(t))=\mathcal{F}(x_{0})+\int_{0}^{t}{\mathcal{A}(x(s))\mathcal{F}(x_{0})\mathsf{d}s},\quad t\in[0,T].

(1.6)

We can rewrite (
1.6
) as follows:

\mathcal{F}(x(t))=\mathcal{F}(x_{0})(1-t)+\int_{0}^{t}{(\mathcal{A}(x(s))+\mathsf{Id}_{\mathbb{R}^{m}})\mathcal{F}(x_{0})\mathsf{d}s},\quad t\in[0,T],

(1.7)

where
\mathsf{Id}_{\mathbb{R}^{m}}
denotes the identity
\mathbb{R}^{m}\ni x\mapsto\mathsf{Id}_{\mathbb{R}^{m}}(x)=x
.
Henceforth, if
\mathcal{A}(x)+\mathsf{Id}_{\mathbb{R}^{m}}
is bounded on a set
U\subset\mathbb{R}^{m}
containing the trajectory of
t\mapsto x(t)
, say

\kappa:=\sup_{x\in U}{\left\|\mathcal{A}(x)+\mathsf{Id}_{\mathbb{R}^{m}}\right\|}=\sup_{x\in U}{\left(\sup_{w\in\mathbb{R}^{m},\left\|w\right\|\neq 0}{\frac{\left\|(\mathcal{A}(x)+\mathsf{Id}_{\mathbb{R}^{m}})(w)\right\|}{\left\|w\right\|}}\right)},

(1.8)

we get

\left\|\mathcal{F}(x(1))\right\|\leq\kappa\left\|\mathcal{F}(x_{0})\right\|.

(1.9)

Here
\left\|\cdot\right\|
stands for the standard Euclidean norm, i.e.,
\left\|x\right\|=\left(\sum_{i=1}^{n}{x_{i}^{2}}\right)^{\nicefrac{{1}}{{2}}}
for
x\in\mathbb{R}^{n}
. As a conclusion, we see that we are able to control the residual
\mathcal{F}(x)
by the two components
\kappa
and
\left\|\mathcal{F}(x_{0})\right\|
.
Remember that in case of
\mathcal{M}(x)=-[\mathcal{F}^{\prime}(x)]^{-1}
in (
1.4
) and (
1.5
), i.e., for problem (
1.2
), we readily infer

\mathcal{A}(x)=-\mathsf{Id}_{\mathbb{R}^{m}},

i.e., we get
\kappa=0
and therefore
x(1)
is a zero for
\mathcal{F}
.
Based on the results given in
[
1
,
2
]
, we see in this work that the residual bound from (
1.9
) can be obtained using only some notion of directional derivative for
\mathcal{F}
:

\mathcal{F}^{\prime}(x)h:=\lim_{t\searrow 0}{\frac{\mathcal{F}(x+th)-\mathcal{F}(x)}{t}},\quad x,h\in\mathbb{R}^{n}.

(1.10)

In
[
1
]
, the author shows the existence of a zero
u
for
\mathcal{F}
under the assumption that
x
and
h
are taken from some suitable subsets of
\mathbb{R}^{n}
such that the directional derivative of
\mathcal{F}
from (
1.10
) exists and satisfies

\mathcal{F}^{\prime}(x)h=-\mathcal{F}(x_{0}).

We see that the proof given in
[
1
]
can be extended in such a way that we obtain the residual bound from (
1.9
), assuming that the directional derivative satisfies

\mathcal{F}^{\prime}(x)h=\mathcal{A}(x)\mathcal{F}(x_{0}).

Therefore, the result from
[
1
]
can be seen as a special case of the residual bound (
1.9
) for
\kappa=0
. Based on the same assumption on the directional derivative as in the work
[
1
]
, where the author proves the existence of a zero
u
for
\mathcal{F}
, in
[
2
]
, the forgoing result has been extended by showing the existence of a continuous function
x:[0,1]\to\mathbb{R}^{n}
with

\mathcal{F}(x(t))=(1-t)\mathcal{F}(x_{0}).

As shown in
[
1
]
and
[
2
]
, using some suitable notion of compactness, these results are also valid in the infinite dimensional case. In this work, we see that the existence of a function
t\mapsto x(t)
can be extended such that there holds

\left\|\mathcal{F}(x(t))-(1-t)\mathcal{F}(x_{0})\right\|\leq\kappa t\left\|\mathcal{F}(x_{0})\right\|,

(1.11)

i.e., the result given in
[
2
]
is simply the case with
\kappa=0
in (
1.11
).

Outline

In Section

, we first show the existence of an element
u\in\mathbb{R}^{n}
satisfying the residual bound (
1.9
). In addition, we discuss some implications and applications based on this residual bound. In a second part, we address the existence of a path
t\mapsto x(t)
that satisfies
(
1.11
).
We again discuss this result and some implications thereof.
We finally discuss these results in the infinite dimensional case and give some concluding remarks in Section
3
.
The presented results rely on ideas from
[
1
,
2
]
.

2.
Main results

For
r>0
, we denote by
b_{r}(x)
the open, and by
B_{r}(x)
the closed ball in
X\subset{\mathbb{R}^{n}}
with
x\in X
. We start with the following result:

Theorem 2.1
.

Given
r>0,x_{0}\in\mathbb{R}^{n}
and let
\mathcal{F}:B_{r}(x_{0})\to\mathbb{R}^{m}

be a continuous function on the ball
B_{r}(x_{0})
. In addition, assume that the map
B_{r}(x_{0})\ni x\mapsto\mathcal{A}(x)\in\mathbb{R}^{m\times m}
is continuous.
If for all
x\in b_{r}(x_{0})
, there exists a direction
h\in B_{r}(0)
such that

\lim_{t\searrow 0}{\frac{\mathcal{F}(x+th)-\mathcal{F}(x)}{t}}=\mathcal{A}(x)\mathcal{F}(x_{0}),

(2.1)

then there exists an element
u\in B_{r}(x_{0})
with

\left\|\mathcal{F}(u)\right\|\leq\kappa\left\|\mathcal{F}(x_{0})\right\|,

where the constant
\kappa
is given by

\kappa=\max_{x\in B_{r}(x_{0})}{\left\|\mathcal{A}(x)+\mathsf{Id}_{\mathbb{R}^{m}}\right\|}.

Proof.

First of all we note that by continuity of
x\mapsto\left\|\mathcal{A}(x)+\mathsf{Id}_{\mathbb{R}^{m}}\right\|
the constant
\kappa
is finite.
For the proof, we follow the ideas of
[
2
]
and define for given
\varepsilon>0
the set:

S_{\varepsilon}=\{s\in[0,1]|\exists y\in B_{rs}(x_{0})\ \text{s.t.}\ \left\|\mathcal{F}(y)-(1-s)\mathcal{F}(x_{0})\right\|\leq\varepsilon s+\kappa s\left\|\mathcal{F}(x_{0})\right\|\}.

Note that
S_{\varepsilon}
is a closed set. Indeed, for a given sequence
(s_{k})\subset S_{\varepsilon}
with
s_{k}\to s
, there is a sequence
(y_{k})
with
y_{k}\in B_{rs_{k}}(x_{0})
and

\left\|\mathcal{F}(y_{k})-(1-s_{k})\mathcal{F}(x_{0})\right\|\leq\varepsilon s_{k}+\kappa s_{k}\left\|\mathcal{F}(x_{0})\right\|.

(2.2)

Note that
(y_{k})\subset B_{r}(x_{0})
. Thus by compactness of
B_{r}(x_{0})
, we can choose a subsequence
(y_{k_{j}})
with
y_{k_{j}}\to y\in B_{r}(x_{0})
. In addition we have

\left\|y-x_{0}\right\|\leq\left\|y-y_{k_{j}}\right\|+\left\|y_{k_{j}}-x_{0}\right\|\leq\left\|y-y_{k_{j}}\right\|+rs_{k_{j}}\to rs,

i.e.,
y\in B_{rs}(x_{0})
. Together with (
2.2
), using the continuity of
\mathcal{F}
, we conclude that
s_{k}\to s
in
S_{\varepsilon}
, i.e.,
S_{\varepsilon}
is a closed subset of [0, 1], and therefore
\sup{S_{\varepsilon}}\in S_{\varepsilon}
. We see that
\sup{S_{\varepsilon}}=1
.
Let us assume by contradiction that
\sup{S_{\varepsilon}}=m<1
.
For
m\in S_{\varepsilon}
we can choose
y\in B_{rm}(x_{0})
with

\left\|\mathcal{F}(y)-(1-m)\mathcal{F}(x_{0})\right\|\leq\varepsilon m+\kappa m\left\|\mathcal{F}(x_{0})\right\|.

(2.3)

Since
y\in B_{rm}(x_{0})\subset b_{r}(x_{0})
, there exists
h\in B_{r}(0)
such that assumption (
2.1
) holds. Therefore we can choose
\delta\in(0,1-m]
so small such that

\left\|\mathcal{F}(y+\delta h)-\mathcal{F}(y)-\delta\mathcal{A}(y)\mathcal{F}(x_{0})\right\|\leq\varepsilon\delta.

(2.4)

Using (
2.3
) and (
2.4
) we observe:

\displaystyle\left\|\mathcal{F}(y+\delta h)-(1-(\delta+m))\mathcal{F}(x_{0})\right\|

\displaystyle\leq

\displaystyle\left\|\mathcal{F}(y+\delta h)-\mathcal{F}(y)-\delta\mathcal{A}(y)\mathcal{F}(x_{0})\right\|

\displaystyle+

\displaystyle\left\|\mathcal{F}(y)-(1-m)\mathcal{F}(x_{0})\right\|+\delta\left\|(\mathcal{A}(y)+\mathsf{Id}_{\mathbb{R}^{m}})\mathcal{F}(x_{0})\right\|

\displaystyle\leq

\displaystyle\varepsilon\delta+\varepsilon m+\kappa m\left\|\mathcal{F}(x_{0})\right\|+\delta\kappa\left\|\mathcal{F}(x_{0})\right\|

\displaystyle=

\displaystyle\varepsilon(\delta+m)+\kappa(m+\delta)\left\|\mathcal{F}(x_{0})\right\|.

Since
\left\|(y+\delta h)-x_{0}\right\|\leq\left\|y-x_{0}\right\|+\delta\left\|h\right\|\leq r(m+\delta)
, we see that

(y+\delta h)\in B_{r(\delta+m)}(x)
and
we deduce
\delta+m\in S_{\varepsilon}
contradicting the assumption
\sup{S_{\varepsilon}}=m
. Hence
\sup{S_{\varepsilon}}=1
and therefore for all
\varepsilon>0
, we find
y_{\varepsilon}\in B_{r}(x_{0})
with

\left\|\mathcal{F}(y_{\varepsilon})\right\|\leq\varepsilon+\kappa\left\|\mathcal{F}(x_{0})\right\|.

Again by compactness of
B_{r}(x_{0})
, we obtain the existence of
u\in B_{r}(x_{0})
with

\left\|\mathcal{F}(u)\right\|\leq\kappa\left\|\mathcal{F}(x_{0})\right\|.

∎

We now consider some immediate consequences of Theorem
2.1
:

Corollary 2.2
.

Suppose the assumptions of Theorem
2.1
hold for any
x=x_{0}\in\mathbb{R}^{n}
.
Then, for any
i\in\mathbb{N}
, there exists
u_{i}\in\mathbb{R}^{n}
with

\left\|\mathcal{F}(u_{i})\right\|\leq\kappa^{i}\left\|\mathcal{F}(u_{0})\right\|.

Proof.

This follows by induction. For
i=1
this holds true by Theorem
2.1
with
x_{0}=u_{0}
. Thus, assume that
\left\|\mathcal{F}(u_{i-1})\right\|\leq\kappa^{i-1}\left\|\mathcal{F}(u_{0})\right\|
. We set
x_{0}=u_{i-1}
in Theorem
2.1
and obtain
u_{i}
with
\left\|\mathcal{F}(u_{i})\right\|\leq\kappa\left\|\mathcal{F}(u_{i-1})\right\|
from where we deduce the desired result.
∎

Corollary 2.3
.

Suppose the assumptions of Theorem
2.1
hold for any
x=x_{0}\in\mathbb{R}^{n}
. In addition, suppose that the sequence
(u_{i})_{i\in\mathbb{N}}
from Corollary
2.2
remains bounded and that
\kappa<1
. Then there exists at least one zero
u
for
\mathcal{F}
.

Proof.

This simply follows from Corollary
2.2
together with the boundedness of the sequence
(u_{i})_{i\in\mathbb{N}}
.
∎

Next, we consider an approximate inverse function result:

Theorem 2.4
.

Given
r>0
,
B_{r}(0)\subset\mathbb{R}^{n}
, a continuous map
\Psi:\mathbb{R}^{n}\to\mathbb{R}^{m}
with
\Psi(0)=0
, and the continuous matrix-valued map
\mathcal{A}:B_{r}(0)\rightarrow\mathbb{R}^{m\times m}
, let
g\in\mathbb{R}^{m}
be such that for all
x\in b_{r}(0)
, there is
h\in B_{r}(0)
with

\lim_{t\searrow 0}{\frac{\Psi(x+th)-\Psi(x)}{t}}=\mathcal{A}(x)g.

Then, there exists
u\in B_{r}(0)
with

\left\|\Psi(u)-g\right\|\leq\kappa\left\|g\right\|,

where the constant
\kappa
is now given by

\kappa=\max_{x\in B_{r}(0)}{\left\|\mathcal{A}(x)+\mathsf{Id}_{\mathbb{R}^{m}}\right\|}.

Proof.

Set
\mathcal{F}(x):=\Psi(x)-g
and note that for any
y\in b_{r}(0)
there is
h\in B_{r}(0)
such that

\lim_{t\searrow 0}{\frac{\Psi(y+th)-\Psi(y)}{t}}=\lim_{t\searrow 0}{\frac{\mathcal{F}(y+th)-\mathcal{F}(y)}{t}}=\mathcal{A}(y)g.

Invoking Theorem
2.1
, we obtain
u\in B_{r}(0)
with

\left\|\Psi(u)-g\right\|=\left\|\mathcal{F}(u)\right\|\leq\kappa\left\|\mathcal{F}(0)\right\|=\kappa\left\|g\right\|.

∎

Let us now discuss the existence of a continuous curve
x:[0,T]\to\mathbb{R}^{n}
satisfying the bound (
1.11
).

Theorem 2.5
.

Under the assumptions given in Theorem
2.1
, there exists a continuous function
x:[0,1]\rightarrow\mathbb{R}^{n}
such that

\left\|\mathcal{F}(x(t))-(1-t)\mathcal{F}(x_{0})\right\|\leq\kappa t\left\|\mathcal{F}(x_{0})\right\|.

In addition,
x([0,1])\subset B_{r}(x_{0})
.

Note that from this result, we immediately obtain Theorem
2.1
if we set
t=1
. Again, we follow the ideas given in
[
2
]
. In doing so, we use the following result:

Lemma 2.6
.

Given
t\in(0,1)
,
y\in b_{tr}(x_{0})
,
s\in(0,1-t]
and suppose the assumptions from Theorem
2.1
hold. Then for all
\varepsilon>0
, there exists
w\in B_{rs}(y)
such that

\left\|\mathcal{F}(w)-\mathcal{F}(y)+s\mathcal{F}(x_{0})\right\|\leq s\varepsilon+s\kappa\left\|\mathcal{F}(x_{0})\right\|.

(2.5)

Proof.

Let
t\in(0,1)
. Choose
(y,h)\in b_{tr}(x_{0})\times B_{r}(0)
such that

\lim_{s\searrow 0}{\frac{\mathcal{F}(y+sh)-\mathcal{F}(y)}{s}}=\mathcal{A}(y)\mathcal{F}(x_{0}).

Next, we fix a positive number
\varepsilon>0
and set
\delta>0
such that whenever
s\in(0,\delta]
,

\left\|\mathcal{F}(y+sh)-\mathcal{F}(y)-s\mathcal{A}(y)\mathcal{F}(x_{0})\right\|\leq\varepsilon s.

Again, we define the set

\displaystyle S_{y,\varepsilon}=

\displaystyle\{\delta\in(0,1-t]|\forall s\in(0,\delta]\ \exists w\in B_{sr}(y):

\displaystyle\left\|\mathcal{F}(w)-\mathcal{F}(y)+s\mathcal{F}(x_{0})\right\|\leq s\varepsilon+s\kappa\left\|\mathcal{F}(x_{0})\right\|\}.

As before, we see that
\sup{S_{y,\varepsilon}}\in S_{y,\varepsilon}
and equals
1-t
. Let therefore
\delta_{k}>0
such that
\delta_{k}\nearrow m=\sup{S_{y,\varepsilon}}
. For each
\delta_{k}
, we can find
w_{k}\in B_{r\delta_{k}}(y)\subset B_{rm}(y)
such that

\left\|\mathcal{F}(w_{k})-\mathcal{F}(y)+\delta_{k}\mathcal{F}(x_{0})\right\|\leq\varepsilon\delta_{k}+\delta_{k}\kappa\left\|\mathcal{F}(x_{0})\right\|.

By compactness of
B_{rm}(y)
, we can find
w\in B_{rm}(y)
such that
w_{k_{j}}\to w
as
j\to\infty
, and the continuity of
\mathcal{F}
implies

\left\|\mathcal{F}(w)-\mathcal{F}(y)+m\mathcal{F}(x_{0})\right\|\leq m\varepsilon+m\kappa\left\|\mathcal{F}(x_{0})\right\|,

(2.6)

i.e.,
m\in S_{y,\varepsilon}
.
It remains to show that
m=1-t
. By contradiction, we assume that
0<m<1-t
which is equivalent to
0<1-(t+m)
.
Note that

\left\|w-x_{0}\right\|\leq\left\|w-y\right\|+\left\|y-x_{0}\right\|\leq r(m+t)<r.

Thus, by assumption, we can find
\widetilde{h}
such that

\lim_{s\searrow 0}{\frac{\mathcal{F}(w+s\widetilde{h})-\mathcal{F}(w)}{s}}=\mathcal{A}(w)\mathcal{F}(x_{0}).

Choose again a positive number
0<d<1-(t+m)
such that for
0<s\leq d
,

\left\|\mathcal{F}(w+s\widetilde{h})-\mathcal{F}(w)-s\mathcal{A}(w)\mathcal{F}(x_{0})\right\|\leq\varepsilon s.

(2.7)

We set
\widetilde{w}=w+s\widetilde{h}
. Invoking (
2.6
) and (
2.7
), we arrive at

\displaystyle\left\|\mathcal{F}(\widetilde{w})-\mathcal{F}(y)+(s+m)\mathcal{F}(x_{0})\right\|

\displaystyle\leq

\displaystyle\left\|\mathcal{F}(\widetilde{w})-\mathcal{F}(w)-s\mathcal{A}(w)\mathcal{F}(x_{0})\right\|

\displaystyle+\left\|\mathcal{F}(w)-\mathcal{F}(y)+m\mathcal{F}(x_{0})\right\|+s\left\|(\mathcal{A}(w)+\mathsf{Id})\mathcal{F}(x_{0})\right\|

\displaystyle\leq

\displaystyle\varepsilon s+m\varepsilon+m\kappa\left\|\mathcal{F}(x_{0})\right\|+s\kappa\left\|\mathcal{F}(x_{0})\right\|

\displaystyle=

\displaystyle(s+m)\varepsilon+(s+m)\kappa\left\|\mathcal{F}(x_{0})\right\|.

Moreover, since
\left\|\tilde{w}-y\right\|\leq sr+\left\|w-y\right\|
, we have

\widetilde{w}\in B_{{r}(m+s)}(y)
, i.e., we get the contradiction
\sup{S_{y,\varepsilon}}=m<m+d=\sup{S_{y,\varepsilon}}
.
∎

Proof of Theorem
2.5
.

We use the ideas from Neuberger
[
2
]
. Indeed, for
k\in\mathbb{N}
, let
p_{k}
be a partition of the interval
[0,1]
such that
p_{k+1}
is a refinement of
p_{k}
. The
n_{k}+1
nodes of
p_{k}
will be denoted by

0=t_{k,0}<t_{k,1}<t_{k,2}<\ldots<t_{k,n_{k}}=1.

E.g., we can choose the sequence of partitions

p_{k}=\left\{\frac{i}{2^{k}}\right\}_{\{i=0,\ldots,2^{k}\}},\quad k\in\{1,2,3,\ldots\},\quad\text{with}\quad t_{k,i}=\frac{i}{2^{k}}.

Next we define the family of functions
x_{k}:[0,1]\rightarrow\mathbb{R}^{n}
as the piecewise linear interpolant with nodal values

x_{k}(t_{k,i})=w_{k,i}\quad\text{for}\quad i\in\{0,1,\ldots,n_{k}\}.

Here,
x_{k}(t_{k,0})=w_{k,0}
.
For
w_{k,0}=x_{0}
and
t_{1}>0
, we choose
w_{k,1}\in b_{t_{1}r}(x_{0})
, such that there holds

\displaystyle\left\|\mathcal{F}(w_{k,1})-\mathcal{F}(x_{0})+t_{1}\mathcal{F}(x_{0})\right\|

\displaystyle\leq\left\|\mathcal{F}(w_{k,1})-\mathcal{F}(x_{0})-t_{1}\mathcal{A}(x_{0})\mathcal{F}(x_{0})\right\|

\displaystyle+t_{1}\left\|\mathcal{A}(x_{0})\mathcal{F}(x_{0})+\mathcal{F}(x_{0})\right\|

\displaystyle\leq\frac{t_{1}}{k}+t_{1}\kappa\left\|\mathcal{F}(x_{0})\right\|.

Since
w_{k,1}\in b_{t_{1}r}(x_{0})
, by Lemma
2.6
, there exists
w_{k,2}\in B_{s_{2}r}(w_{k,1})
with
s_{2}=t_{2}-t_{1}\in(0,1-t_{1}]
such that

\left\|\mathcal{F}(w_{k,2})-\mathcal{F}(w_{k,1})+s_{k,2}\mathcal{F}(x_{0})\right\|\leq\frac{s_{k,2}}{k}+\kappa s_{k,2}\left\|\mathcal{F}(x_{0})\right\|.

Notice that

\left\|w_{k,2}-x_{0}\right\|\leq\left\|w_{k,2}-w_{k,1}\right\|+\left\|w_{k,1}-x_{0}\right\|<(s_{2}+t_{1})r=t_{2}r,

i.e.,
w_{k,2}\in b_{t_{2}r}(x_{0})
.
Thus, again by Lemma
2.6
, we obtain
w_{k,3}\in B_{s_{3}r}(w_{k,2})
with
s_{3}=t_{3}-t_{2}
such that

\left\|\mathcal{F}(w_{k,3})-\mathcal{F}(w_{k,2})+s_{k,3}\mathcal{F}(x_{0})\right\|\leq\frac{s_{k,3}}{k}+\kappa s_{k,3}\left\|\mathcal{F}(x_{0})\right\|.

Hence, for
i\in\{1,2,3,\ldots,n_{k}\}
, we inductively get

\left\|\mathcal{F}(x_{k}(t_{k,i}))-\mathcal{F}(x_{k}(t_{k,i-1}))+s_{k,i}\mathcal{F}(x_{0})\right\|\leq\frac{s_{k,i}}{k}+\kappa s_{k,i}\left\|\mathcal{F}(x_{0})\right\|.

Summing this inequality from
i=1
up to
i=j_{k}\leq n_{k}
and using the triangle inequality, we obtain

\left\|\mathcal{F}(x_{k}(t_{k,j_{k}}))-\mathcal{F}(x_{0})+t_{k,j_{k}}\mathcal{F}(x_{0})\right\|\leq\frac{t_{k,j_{k}}}{k}+\kappa\left\|\mathcal{F}(x_{0})\right\|t_{k,j_{k}}.

(2.8)

Remember that
x_{k}(t_{k,0})=x_{0}
.
We need to check that

i)

for each
t\in[0,1]
, the sequence
\{x_{k}(t)\}_{k\in\mathbb{N}}
remains within
B_{r}(x_{0})
and

ii)

in addition, for all
k
and
s,t\in[0,1]
, the functions are Lipschitz with

\left\|x_{k}(t)-x_{k}(s)\right\|\leq r\left|t-s\right|.

We first address
\mathrm{i})
: For
t\in[t_{k,0},t_{k,1}]
we observe:

\left\|x_{k}(t)-x_{0}\right\|=\frac{\left\|w_{k,1}-x_{0}\right\|}{\left|t_{k,1}-t_{k,0}\right|}\left|t-t_{k,0}\right|\leq rs_{k,1}<r.

Let
t\in[t_{k,1},t_{k,2}]
:

\left\|x_{k}(t)-x_{0}\right\|\leq\left\|w_{k,2}-w_{k,1}\right\|+\left\|w_{k,1}-x_{0}\right\|\leq r(s_{k,2}+s_{k,1})\leq rt_{k,2}<r.

Clearly we can repeat this process until we reach the interval
[t_{k,n_{k}-1},t_{k,n_{k}}]
.
Let us now consider
\mathrm{ii})
:
Choose
t,s\in[0,1]
with
0\leq s<t
and assume that for
j\in\mathbb{N}
, we have

s,t\in[t_{k,j},t_{k,j+1}]
. We observe:

\left\|x_{k}(t)-x_{k}(s)\right\|=\frac{\left\|w_{k,j}-w_{k,j-1}\right\|}{t_{k,j}-t_{k,j-1}}\left|t-s\right|\leq\frac{rs_{k,j}}{t_{k,j}-t_{k,j-1}}\left|t-s\right|=r\left|t-s\right|.

Next assume
0\leq s<t
with
t_{k,j}\leq t<t_{k,j+1},t_{k,l}\leq s<t_{k,l+1}
for
l<j
. We observe:

\displaystyle\left\|x_{k}(t)-x_{k}(s)\right\|

\displaystyle\leq

\displaystyle\left\|x_{k}(t)-x_{k}(t_{k,j})\right\|+\left\|x_{k}(t_{k,j})-x_{k}(t_{k,j-1})\right\|+\ldots

\displaystyle\ldots+\left\|x_{k}(t_{k,l+2})-x_{k}(t_{k,l+1})\right\|+\left\|x_{k}(t_{k,l+1})-x_{k}(s)\right\|

\displaystyle\leq

\displaystyle r\left|t-t_{k,j}\right|+r\left|t_{k,j}-t_{k,j-1}\right|+\ldots r\left|t_{k,l+2}-t_{k,l+1}\right|+r\left|t_{k,l+1}-s\right|

\displaystyle\leq

\displaystyle r\left|t-s\right|.

Hence, by Arzela-Ascoli we can choose a sequence
\{k_{p}\}_{p=1,2,3,\ldots}\subset\mathbb{N}
such that

x_{k_{p}}\to x\in C([0,1];\mathbb{R}^{n})\quad\text{for}\quad p\to\infty.

Let
t\in[0,1]
. Then, for all
k\in\mathbb{N}
, there exists
j_{k}

t_{k,j_{k}}\leq t\leq t_{k,j_{k}+1}.

Thus
\lim_{k\to\infty}{t_{k,j_{k}}}=t

and by continuity of
\mathcal{F}
, we have

\lim_{p\to\infty}{\mathcal{F}(x_{k_{p}}(t_{k_{p},j_{k_{p}}}))}=\mathcal{F}(x(t))

with

\left\|\mathcal{F}(x(t))-(1-t)\mathcal{F}(x_{0})\right\|\leq\kappa t\left\|\mathcal{F}(x_{0})\right\|.

∎

3.
Conclusions

In this work, we discussed the control of the residual for a given possibly nonlinear map
\mathcal{F}
starting from the quantity
\left\|\mathcal{F}(x_{0})\right\|
. More precisely: Using some notion of directional derivative, we have seen that we can easily extend the results given in
[
1
,
2
]
to establish the bound:

\left\|\mathcal{F}(u)\right\|\leq\kappa\left\|\mathcal{F}(x_{0})\right\|

where
\kappa
is an upper bound for the quantity
\left\|\mathcal{A}(x)+\mathsf{Id}\right\|
and
\mathcal{A}
satisfies
\mathcal{F}^{\prime}(x)h=\mathcal{A}(x)\mathcal{F}(x_{0})
. Based on this observation, we further extended the path existing result from
[
1
,
2
]
in the case that given
x
, the system
\mathcal{F}^{\prime}(x)h=\mathcal{A}(x)\mathcal{F}(x_{0})
has a solution
h
, to get the bound:

\left\|\mathcal{F}(x(t))-(1-t)\mathcal{F}(x_{0})\right\|\leq\kappa t\left\|\mathcal{F}(x_{0})\right\|.

As a result, we therefore are able to control the norm of the homotopy

H(x,t)\equiv\mathcal{F}(x)-(1-t)\mathcal{F}(x_{0})

along the derived path
t\mapsto x(t)
with
H(x_{0},0)=0
. Based on this result, we further proved an approximate version of an inverse function type Theorem
2.10
.
Possible future investigations based on the results of this work are the study of approximate equation solving procedures in the finite dimensional as well as within the context of infinite dimensional problems.
