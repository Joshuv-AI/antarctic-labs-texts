Some Remarks on Marginal Code Languages
Stavros Konstantinidis

Abstract
A prefix code L satisfies the condition that no word of L is a proper prefix of another word of L. Recently, Ko, Han and Salomaa relaxed this condition by allowing a word of L to be a proper prefix of at most k words of L, for some ‘margin’ k, introducing thus the class of k-prefix-free languages, as well as the similar classes of k-suffix-free and k-infix-free languages. Here we unify the definitions of these three classes of languages into one uniform definition in two ways: via the method of partial orders and via the method of transducers. Thus, for any known class of code-related languages definable via the transducer method, one gets a marginal version of that class. Building on the techniques of Ko, Han and Salomaa, we discuss the uniform satisfaction and maximality problems for marginal classes of languages.

3
Jürgensen Independence and Marginal Code Languages

An important direction in the research on independent languages is the investigation of systematic methods that allow one to define and study different classes of these languages.
Next we review some of these methods.

Independent languages via partial orders.

To our knowledge, the first method for defining code properties is the method of

[
17
]
via certain binary relations on words. A binary relation
\omega
is a set of pairs of words, that is,
\omega\subseteq\Sigma^{*}\times\Sigma^{*}
.
In
[
18
]
, the author presents the method via binary relations that are partial orders (in the standard definition). Let
\leq
be a partial order on
\Sigma^{*}
.
A language
L
is called
\leq
-independent
, if

u,v\in L\>\text{ and }\>u\leq v\>\text{ imply }\>u=v.

(1)

The same class of languages is defined via the strict version ‘
<
’ of ‘
\leq
’:

<\>\cap\>[L]^{2}=\emptyset.

(2)

Above,
<\,=\,\leq-\{(u,u)\mid u\in\Sigma^{*}\}
, which is the irreflexive and asymmetric version of ‘
\leq
’.
The classic examples of prefix and suffix codes are defined via the partial orders
\leq_{\mathrm{px}},\leq_{\mathrm{sx}}\subseteq[\Sigma^{*}]^{2}
, respectively:

\leq_{\mathrm{px}}=\{(w,z)\mid z\text{ is a prefix of }w\}\quad\text{ and }\quad\leq_{\mathrm{sx}}=\{(w,z)\mid z\text{ is a suffix of }w\};

or via the strict versions of these orders

<_{\mathrm{px}}=\{(w,z)\mid z\text{ is a proper prefix of }w\}
and

<_{\mathrm{sx}}=\{(w,z)\mid z\text{ is a proper suffix of }w\}.

Thus,
L
is a prefix code iff no two
different
words
u,v\in L
are related via
\leq_{\mathrm{px}}
; equivalently, iff no two words
u,v\in L
are related via
<_{\mathrm{px}}
.

Jürgensen Independence.

Let
n
be a positive integer or
\aleph_{0}
. An
n
-independent property
is a class of languages
\mathbb{P}
such that

L\in\mathbb{P}\quad\text{iff}\quad\text{for all $L^{\prime}\subseteq L$ with $|L^{\prime}|<n$: $L^{\prime}\in\mathbb{P}$}.

(3)

A
Jürgensen property
is simply an
n
-independent property for some
n\in\mathbb{N}\cup\{\aleph_{0}\}
.
Thus, to tell whether a language
L
is independent w.r.t. some
\mathbb{P}
, it is sufficient (and necessary) to ensure that every subset of
L
with
<n
elements is independent w.r.t.
\mathbb{P}
.
For example, the class of prefix codes is a
3
-independent property because a language
L
is a prefix code iff every subset of
L
with at most
2
words is a prefix code.
Why is the Jürgensen definition interesting?
One reason is that it can be used to model the independent properties defined by all previous methods.
Another reason is that the Jürgensen method guarantees that every independent language is included in a maximal one
[
6
]
.
A third reason is that the class of UD-codes cannot be modelled by the previous methods, as it is an
\aleph_{0}
-independence
(a language
L
is a UD-code iff every finite subset of
L
is a UD-code), but the class of UD-codes is
not
an
n
independent property, for any
n<\aleph_{0}
,
[
6
]
.

3.1
Marginal properties.

The
\leq
-independent properties defined in (
2
) require that no pair of
L
-words are related via the order ‘
<
’.
For example, when
L
is a prefix code, no
L
-word is a proper prefix of an
L
-word.
In
[
8
]
, Ko, Han and Salomaa, relax this condition by allowing an
L
-word to be a proper prefix of at most
k
words, for some ‘error’ margin
k\in\mathbb{N}_{0}
.
They define the class of
k
-prefix-free languages
, which is here denoted by
\mathbb{P}_{k\text{-}\mathrm{px}}
, as follows

L\in\mathbb{P}_{k\text{-}\mathrm{px}},\quad\text{if every word of $L$ is a proper prefix of at most $k$ words of $L$.}

(4)

It follows that
\mathbb{P}_{0\text{-}\mathrm{px}}
is exactly the class of prefix codes.
The class
\mathbb{P}_{\mathrm{fin}\text{-}\mathrm{px}}
of
finitely prefix-free languages
is defined as follows

L\in\mathbb{P}_{\mathrm{fin}\text{-}\mathrm{px}},\quad\text{if $\forall w\in L$, $w$ is a proper prefix of at most finitely many $L$-words.}

(5)

Unlike the case of prefix codes (0-prefix languages) which are UD-codes, it is important to note that, for
k>0
, these languages are not necessarily UD-codes. For example,
\{0,00\}
is a 1-prefix-free language but it is not a UD-code.

The classes
\mathbb{P}_{k\text{-}\mathrm{sx}}
and
\mathbb{P}_{k\text{-}\mathrm{ix}}
of
k
-suffix-free languages
and
k
-infix-free languages
are defined analogously, as well as the classes
\mathbb{P}_{\mathrm{fin}\text{-}\mathrm{sx}}
and
\mathbb{P}_{\mathrm{fin}\text{-}\mathrm{ix}}
,
[
8
]
.

We extend the above concepts via the mechanism of partial orders.

Definition 1

Let
\leq_{\alpha}
be a partial order on
\Sigma^{*}
, where
\alpha
is used as the name of the partial order. The class
\mathbb{P}_{k\text{-}\alpha}
of
k
-
\alpha
languages is defined as follows:

L\in\mathbb{P}_{k\text{-}\alpha},\quad\text{if every word of $L$ is smaller w.r.t. `$<_{\alpha}$' by at most $k$ words of $L$.}

The class
\mathbb{P}_{\mathrm{fin}\text{-}\alpha}
of finitely-
\alpha
languages is defined as above by using the condition “every word of
L
is smaller w.r.t. ‘
<_{\alpha}
’ by at most finitely many words of
L
”.

Thus, we can talk about the classes of
k
-hypercode and
k
-outfix-free languages, based on appropriate partial orders.
Note that every singleton language
\{w\}
is a
k
-
\alpha
language, for every partial order
\leq_{\alpha}
and every
k\in\mathbb{N}_{0}
.
While for all
k\in\mathbb{N}_{0}
, the classes
\mathbb{P}_{k\text{-}\alpha}
are independent properties, this is not the case for the classes
\mathbb{P}_{\mathrm{fin}\text{-}\alpha}
.
This is shown in the next theorem, in which the term
right-infinite order

\leq_{\alpha}
means that, for every word
u
, there is a word
v
such that
u<_{\alpha}v
.

Theorem 3.1

Let
\leq_{\alpha}
be any partial order on words and let
k\in\mathbb{N}_{0}
.
The following statements hold true.

1.

The class
\mathbb{P}_{k\text{-}\alpha}
is a (k+3)-independent property; hence, every
k
-
\alpha
language is included in a maximal one.

2.

If
\leq_{\alpha}
is a right-infinite order then, for every finitely-
\alpha
language
L
, there is a word
z\notin L
such that
L\cup\{z\}
is a finitely-
\alpha
language. Hence, the class
\mathbb{P}_{\mathrm{fin}\text{-}\alpha}
is not a Jürgensen property.

Proof

The first statement follows from the definitions of Jürgensen property and
k
-
\alpha
language, using standard logical arguments.
For the second statement, consider any finitely-
\alpha
language
L
. We show that there is a word
z\notin L
such that
L\cup\{z\}
is a finitely-
\alpha
language.
If
L
is empty then
z
can be any word:
L\cup\{z\}=\{z\}
, which is finitely-
\alpha
. If
L
is not empty, consider any word
u\in L
.
We use the notation
V(x)=\{v\mid x<_{\alpha}v\}
, for any word
x
.
As
L
is finitely-
\alpha
, the set
L\cap V(u)
is finite; so it is of the form

L\cap V(u)\>=\>\{v_{1},\ldots,v_{n}\}.

Consider any element
v_{r}
which is maximal in
\{v_{1},\ldots,v_{n}\}
; that is,
v_{r}\not<_{\alpha}v_{j}
for all
j=1,\ldots,n
.
As
\leq_{\alpha}
is right-infinite, there is a word
z
such that
v_{r}<_{\alpha}z
. Moreover, we have that
u<_{\alpha}v_{r}<_{\alpha}z
and
z\notin\{v_{1},\ldots,v_{n}\}
.
We show next that
z\notin L
and
L\cup\{z\}
is a finitely-
\alpha
language.

As
z\in V(u)
and
z\notin L\cap V(u)
, we have that
z\notin L
.

Let
w
be any word in
L\cup\{z\}
. We need to show that
w
is smaller w.r.t. ‘
<
’ by at most finitely many words of
L\cup\{z\}
; that is, the set
\big(L\cup\{z\}\big)\cap V(w)
is finite. First note that

\big(L\cup\{z\}\big)\cap V(w)\>=\>\big(L\cap V(w)\big)\cup\big(\{z\}\cap V(w)\big).

If
w\not=z
then
w\in L
and
L\cap V(w)
is finite and, therefore
\big(L\cup\{z\}\big)\cap V(w)
is finite as well.
If
w=z
then it is sufficient to show that
L\cap V(z)
is empty.
If there were
z_{1}\in L\cap V(z)
then
u<_{\alpha}z<_{\alpha}z_{1}
, implying that
z_{1}\in V(u)
and also
z_{1}\in\{v_{1},\ldots,v_{n}\}
, which is impossible.

All partial orders corresponding to the classes of codes in Example
1
, other than the class of UD-codes, are right-infinite orders.

It is interesting to note that, if a language
L
is regular and finitely prefix-free then
L
is
k
-prefix-free for some

; but this is not the case, in general, if

is context-free
[

]
.

Decidability of Satisfaction

The
satisfaction problem
for a
fixed
independent property
\mathbb{P}
is to decide whether a given language
L
satisfies
\mathbb{P}
; that is whether
L\in\mathbb{P}
.
The language is given as input via a well-defined description method.
Usually, the input is a finite automaton describing a regular language.
This is a reasonable assumption in coding theory, as the languages of interest are usually finite, or regular.
Of course it is perfectly fine to assume that the input describing the language is a context-free grammar or a pushdown automaton; however in this case, the satisfaction problem is usually undecidable
[
6
]
.

In Section
5
, we discuss the
uniform
versions of the above decision problems, where in addition to the description of the language
L
, the desired algorithm also takes as input a description of the independent property
\mathbb{P}
.

Decidability of satisfaction of marginal properties.

These properties are from
[
8
]
and are defined in the statements (

) and (
5
) of Section

. As shown in
[
8
]
, the
k
-marginal properties are hard to decide—see further below for the finitely-marginal properties:

•

Deciding whether the language

is
k
-prefix-free, for given automaton
\bm{a}
and integer

, is PSPACE-complete.

•

Deciding whether the language
L(\bm{a})
is
k
-suffix-free, for given automaton
\bm{a}
and integer
k\geq 0
, is PSPACE-complete.

•

Deciding whether the language
L(\bm{a})
is
k
-infix-free, for given automaton
\bm{a}
and integer
k\geq 0
, is PSPACE-hard.

It was left as an open question in
[
8
]
whether the satisfaction of the

-infix-free property is in the class PSPACE.
Then, the question was answered in the affirmative in
[

]
—in fact, even for the larger machine class where

is a finite-crossing 2-way machine with a number of reversal-bounded counters.

For the case of the finitely marginal properties—see definition in statement (

•

Assuming a fixed (but arbitrary) alphabet, there is an

algorithm to decide whether a given automaton

accepts a finitely-prefix-free language (also, finitely-suffix-free, finitely-infix-free).
