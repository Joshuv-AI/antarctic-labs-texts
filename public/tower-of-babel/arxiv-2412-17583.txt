By Dimitrios Charamaras and Florian K. Richter

Abstract
Let Ω ⁡ ( n ) \Omega(n) denote the number of prime factors of a positive integer n n counted with multiplicities. We show that for any bounded functions a , b : ℕ → ℂ a,b\colon\mathbb{N}\to\mathbb{C} , 1 log ⁡ N ​ ∑ n = 1 N a ⁡ ( Ω ⁡ ( n ) ) ​ b ​ ( Ω ⁡ ( n + 1 ) ) n = ( 1 N ​ ∑ n = 1 N a ⁡ ( Ω ⁡ ( n ) ) ) ​ ( 1 N ​ ∑ n = 1 N b ⁡ ( Ω ⁡ ( n ) ) ) + o N → ∞ ​ ( 1 ) . \frac{1}{\log{N}}\sum_{n=1}^{N}\frac{a(\Omega(n))b(\Omega(n+1))}{n}=\Bigg(\frac{1}{N}\sum_{n=1}^{N}a(\Omega(n))\Bigg)\Bigg(\frac{1}{N}\sum_{n=1}^{N}b(\Omega(n))\Bigg)+{\mathrm{o}}_{N\to\infty}(1). 1.1.  Main results

The aim of this paper is to validate the logarithmically averaged two-point correlation case of

Theorem A

For any bounded functions

{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}a(\Omega(n))b(\Omega(n+1))=\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}a(\Omega(n))\Big)\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}b(\Omega(n))\Big)+{\mathrm{O}}\bigg(\frac{(\log\log\log N)^{2}}{\sqrt{\log\log N}}\bigg).

Moreover, the error term only depends on
\max\{\|a\|_{\infty},\|b\|_{\infty}\}

We can provide a clearer, more intuitive, understanding of this behavior by recasting our result in the language of probability theory, in the spirit of the Erdős-Kac theorem.
Recall that if

\mu=\mathbb{E}[X]
and standard deviation

f(x;\mu,\sigma)=\frac{1}{\sigma\sqrt{2\pi}}\,e^{-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^{2}}.

(1.4)

This means that for any bounded and continuous

\mathbb{E}[g(X)]=\int_{-\infty}^{\infty}g(x)f(x;\mu,\sigma)\penalty\ \mathrm{d}x.

(1.5)

In analogy, the “mean” and “standard deviation” of
\Omega(n)

\mu_{N}=\log\log{N}\sim\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\Omega(n)\hskip 10.00002pt\text{and}\hskip 10.00002pt\sigma_{N}=\sqrt{\log\log{N}}\sim\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\big|\Omega(n)-\mu_{N}\big|^{2}\Big)^{\frac{1}{2}}.

(1.7)

Based on the uniform asymptotic estimates of

k\in\mathbb{N}

\sum_{\ell_{1},\ldots,\ell_{k}=1}^{\infty}\Big|\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\mathbbm{1}_{\mathbb{P}_{\ell_{1}}}(n)\mathbbm{1}_{\mathbb{P}_{\ell_{2}}}(n+1)\cdots\mathbbm{1}_{\mathbb{P}_{\ell_{k}}}(n+k-1)-\overline{\pi}_{\ell_{1}}(N)\cdots\overline{\pi}_{\ell_{k}}(N)\Big|={\mathrm{o}}_{N\to\infty}(1).

Conjecture

1.9
implies
Conjecture

1.4
, although the relationship between the two is not immediately apparent. To clarify the connection, we offer below an equivalent formulation of
Conjecture

1.9
.

Conjecture 1.10
.

For any
k\in\mathbb{N}
and any bounded
a\colon\mathbb{N}^{k}\to\mathbb{C}
, we have

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}a\big(\Omega(n),\Omega(n+1),\ldots,\Omega(n+k-1)\big)=\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle(n_{1},\ldots,n_{k})\in[N]^{k}}$}a\big(\Omega(n_{1}),\ldots,\Omega(n_{k})\big)+{\mathrm{o}}_{N\to\infty}(1).

Conjectures
1.9
and
1.10
are equivalent. The proof of this equivalence is analogous to the proof that Theorems
A
and
C
are equivalent given in
Section

6
, so it is omitted.

2.1.  Passing from Cesàro to logarithmic averages

The following lemma gives a well-known identity relating Cesàro averages to logarithmic ones.

Lemma 2.1
.

Let
f\colon\mathbb{N}\to\mathbb{C}
be
1
-bounded. Then for any
N\in\mathbb{N}
and
\varepsilon\in\left(0,\frac{1}{2}\right)
, we have

{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}f(n)={\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{M\in(N^{\varepsilon},N)}\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[M]}$}f(n)+{\mathrm{O}}\bigg(\frac{1}{\log{N}}+\varepsilon\bigg).

Proof.

By partial summation, we have

\displaystyle\sum_{n\leqslant N}\frac{f(n)}{n}

\displaystyle=\sum_{M<N}\frac{1}{M(M+1)}\sum_{n\leqslant M}f(n)+\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}f(n)

\displaystyle=\sum_{M<N}\frac{1}{M}\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[M]}$}f(n)+\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}f(n)+{\mathrm{O}}(1),

hence,

{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}f(n)={\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{M\in[1,N)}\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[M]}$}f(n)+{\mathrm{O}}\bigg(\frac{1}{\log{N}}\bigg).

Moreover, we have

\displaystyle\Big|{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{M\in(N^{\varepsilon},N)}\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[M]}$}f(n)-{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{M\in[1,N)}\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[M]}$}f(n)\Big|

\displaystyle\hskip 85.35826pt\leqslant\bigg|\frac{1}{\log{N}}\sum_{M\in(N^{\varepsilon},N)}\frac{1}{M}\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[M]}$}f(n)-\frac{1}{\log{N}}\sum_{M<N}\frac{1}{M}\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[M]}$}f(n)\bigg|+{\mathrm{O}}(\varepsilon)

\displaystyle\hskip 85.35826pt\leqslant\frac{1}{\log{N}}\sum_{M\leqslant N^{\varepsilon}}\frac{1}{M}+{\mathrm{O}}(\varepsilon)={\mathrm{O}}(\varepsilon).

Combining the last two estimates, the lemma follows.
∎

Recall that given
\ell,N\in\mathbb{N}
we have defined
\overline{\pi}_{\ell}(N)=\frac{|\mathbb{P}_{\ell}\cap[N]|}{N}
. We also define

\overline{\pi}^{\log}_{\ell}(N)={\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\mathbb{P}_{\ell}}(n).

We note the following immediate identities that will be invoked several times throughout
Section

6
: For any function
a\colon\mathbb{N}\to\mathbb{C}
and any
N\in\mathbb{N}
,

a(\Omega(n))=\sum_{\ell=1}^{\infty}a(\ell)\mathbbm{1}_{\mathbb{P}_{\ell}}(n),

(2.2)

and consequently,

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}a(\Omega(n))=\sum_{\ell=1}^{\infty}a(\ell)\overline{\pi}_{\ell}(N)\hskip 10.00002pt\text{and}\hskip 10.00002pt{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}a(\Omega(n))=\sum_{\ell=1}^{\infty}a(\ell)\overline{\pi}^{\log}_{\ell}(N).

(2.3)

Lemma 2.2
.

For any
A>1
and
N\in\mathbb{N}
sufficiently large, we have

\overline{\pi}_{\ell}(N)=f(\ell;\mu_{N},\sigma_{N})\bigg(1+{\mathrm{O}}\bigg(\frac{1}{\sqrt{\log\log{N}}}\bigg)\bigg)\\
=\frac{\exp\Big(-\frac{1}{2}\Big(\frac{\ell-\log\log{N}}{\sqrt{\log\log{N}}}\Big)^{2}\Big)}{\sqrt{2\pi\log\log{N}}}\bigg(1+{\mathrm{O}}\bigg(\frac{1}{\sqrt{\log\log{N}}}\bigg)\bigg),

uniformly for all
\ell\in T_{A,N}
, where
T_{A,N}
is the typical range defined in (
1.7
), and
f(\ell;\mu_{N},\sigma_{N})
is the Gaussian probability density function defined in (
1.4
) with mean
\mu_{N}
and standard deviation
\sigma_{N}
defined in (
1.6
).

Proof.

This follows immediately from the estimate

\overline{\pi}_{\ell}(N)=\frac{\exp\Big(-\frac{1}{2}\Big(\frac{\ell-\log\log{N}}{\sqrt{\log\log{N}}}\Big)^{2}\Big)}{\sqrt{2\pi\log\log{N}}}\bigg(1+{\mathrm{O}}\bigg(\frac{1}{\sqrt{\log\log{N}}}+\frac{|\ell-\log\log{N}|^{3}}{(\log\log{N})^{2}}\bigg)\bigg),

which holds uniformly for all positive integers
\ell\leqslant\frac{3}{2}\log\log{N}
. For this estimate we refer the reader to
[
26
, p. 236]
.
∎

Lemma 2.3
.

For
N\in\mathbb{N}
sufficiently large, we have

\sum_{\ell=1}^{\infty}\big|\overline{\pi}_{\ell}(N)-\overline{\pi}^{\log}_{\ell}(N)\big|\ll\frac{1}{\sqrt{\log\log{N}}}.

Proof.

By (
2.1
)
we have

\frac{1}{\sqrt{2\pi}}\int_{-A}^{A}e^{-\frac{u^{2}}{2}}\penalty\ \mathrm{d}u=1+{\mathrm{O}}\bigg(\frac{1}{\sqrt{\log\log{N}}}\bigg).

We define
T_{N}=(\log\log{N}-A\sqrt{\log\log{N}},\log\log{N}+A\sqrt{\log\log{N}}]\cap\mathbb{Z}
and we denote its complement in
\mathbb{Z}
by
T_{N}^{\text{c}}
. Then, by the quantitative Erdős-Kac theorem
[
30
, Theorem 2]
, we have

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\mathbbm{1}_{T_{N}^{\text{c}}}(\Omega(n))=1-\frac{1}{\sqrt{2\pi}}\int_{-A}^{A}e^{-\frac{u^{2}}{2}}\penalty\ \mathrm{d}u+{\mathrm{O}}\bigg(\frac{1}{\sqrt{\log\log{N}}}\bigg)\ll\frac{1}{\sqrt{\log\log{N}}}.

In view of
Lemma

2.1
, we also have

{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{T_{N}^{\text{c}}}(\Omega(n))\ll\frac{1}{\sqrt{\log\log{N}}}.

By the two last bounds, it follows that

\sum_{\ell\in T_{N}^{\text{c}}}\overline{\pi}_{\ell}(N)=\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\sum_{\ell\in T_{N}^{\text{c}}}\mathbbm{1}_{\mathbb{P}_{\ell}}(n)=\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\mathbbm{1}_{T_{N}^{\text{c}}}(\Omega(n))\ll\frac{1}{\sqrt{\log\log{N}}}

and respectively,

\sum_{\ell\in T_{N}^{\text{c}}}\overline{\pi}^{\log}_{\ell}(N)\ll\frac{1}{\sqrt{\log\log{N}}}.

Therefore, using triangle inequality, we see that it is enough to prove

\sum_{\ell\in T_{N}}\big|\overline{\pi}_{\ell}(N)-\overline{\pi}^{\log}_{\ell}(N)\big|\ll\frac{1}{\sqrt{\log\log{N}}}.

Applying
Lemma

2.1
with
\varepsilon=(\log\log{N})^{-\frac{1}{2}}
and the triangle inequality, we have

\sum_{\ell\in T_{N}}\big|\overline{\pi}_{\ell}(N)-\overline{\pi}^{\log}_{\ell}(N)\big|\leqslant{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{M\in(N^{\varepsilon},N)}\sum_{\ell\in T_{N}}\big|\overline{\pi}_{\ell}(N)-\overline{\pi}_{\ell}(M)\big|+{\mathrm{O}}\bigg(\frac{1}{\sqrt{\log\log N}}\bigg),

hence, in view of
Lemma

2.2
, it suffices to show that

{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{M\in(N^{\varepsilon},N)}\sum_{\ell\in T_{N}}|f(\ell;\mu_{N},\sigma_{N})-f(\ell;\mu_{M},\sigma_{M})|\ll\frac{1}{\sqrt{\log\log{N}}}.

(2.4)

Given
t\in\mathbb{R}
, we define the function
f_{t}(u)=f(t;u,u)
and we set
x=\log\log M
,
y=\log\log N
. Then, the left-hand side of (
2.4
) becomes

{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{M\in(N^{\varepsilon},N)}\sum_{\ell\in T_{N}}|f_{\ell}(x)-f_{\ell}(y)|.

By the Fundamental Theorem of Calculus and the triangle inequality, this is

\leqslant{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{M\in(N^{\varepsilon},N)}\int_{x}^{y}\sum_{\ell\in T_{N}}|f_{\ell}^{\prime}(u)|\penalty\ \mathrm{d}u,

where
f_{\ell}^{\prime}
is the derivative of
f_{\ell}
.
Now we bound the sum by

\int_{T_{N}}|f_{t}^{\prime}(u)|\penalty\ \mathrm{d}t+|f^{\prime}_{t_{1}}(u)|+|f^{\prime}_{t_{2}}(u)|,

where the
t_{1},t_{2}
are the points in
T_{N}
in which the two local maxima of the function
t\mapsto|f^{\prime}_{t}(u)|
are attained, and both maxima are
{\mathrm{O}}(u^{-1})
. The details are left as an exercise to the interested reader. Then, the left hand side of (
2.4
) is

\leqslant{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{M\in(N^{\varepsilon},N)}\int_{x}^{y}\int_{T_{N}}|f_{t}^{\prime}(u)|\penalty\ \mathrm{d}t\penalty\ \mathrm{d}u+{\mathrm{O}}\bigg(\log x-{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{M\in(N^{\varepsilon},N)}\log y\bigg).

To calculate the error term, first we have

\sum_{N^{\varepsilon}<M<N}\frac{1}{M}=(1-\varepsilon)\log N+{\mathrm{O}}(1),

and

\sum_{N^{\varepsilon}<M<N}\frac{\log\log\log M}{M}=\int_{N^{\varepsilon}}^{N}\frac{\log\log\log t}{t}\penalty\ \mathrm{d}t+{\mathrm{O}}(1)=\Big[(\log t)\log\log\log t-\mathrm{li}(\log t)\Big]_{N^{\varepsilon}}^{N}\\
=(\log N)\log\log\log N-\mathrm{li}(\log N)-\varepsilon(\log N)\log\log\log(N^{\varepsilon})+\mathrm{li}(\varepsilon\log N).

Using
\mathrm{li}(x)\sim\frac{x}{\log x}
, a simple calculation gives that the error term is

\frac{\mathrm{li}(\log N)}{(1-\varepsilon)\log N}+\frac{\varepsilon}{1-\varepsilon}\log\left(1+\frac{\log\varepsilon}{\log\log N}\right)-\frac{\mathrm{li}(\varepsilon\log N)}{(1-\varepsilon)\log N}+{\mathrm{O}}\bigg(\frac{1}{\log N}\bigg)\ll\frac{1}{\log\log N}.

In addition, we can also extend the inner integral to
\mathbb{R}
, thus, in view of (
2.4
), it is enough to show

{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{M\in(N^{\varepsilon},N)}\int_{x}^{y}\int_{-\infty}^{\infty}|f_{t}^{\prime}(u)|\penalty\ \mathrm{d}t\penalty\ \mathrm{d}u\ll\frac{1}{\sqrt{\log\log N}}.

(2.5)

To show this, we first estimate the inner integral.
Calculating

|f_{t}^{\prime}(u)|=\frac{|t^{2}-u^{2}-u|}{2u^{2}}f_{t}(u),

we have

\int_{-\infty}^{\infty}|f_{t}^{\prime}(u)\penalty\ \mathrm{d}t=\frac{1}{2\sqrt{2\pi}}\int_{-\infty}^{\infty}\frac{|t^{2}-u^{2}-u|}{u^{2}\sqrt{u}}e^{-\frac{(t-u)^{2}}{2u}}\penalty\ \mathrm{d}t.

Applying the change of variables
t=u+s\sqrt{u}
and using the triangle inequality, the above is

\leqslant\frac{1}{\sqrt{2\pi u}}\int_{-\infty}^{\infty}|s|e^{-\frac{s^{2}}{2}}\penalty\ \mathrm{d}s+\frac{1}{2u\sqrt{2\pi}}\int_{-\infty}^{\infty}|s^{2}-1|e^{-\frac{s^{2}}{2}}\penalty\ \mathrm{d}s=\frac{\mathbb{E}|Z|}{\sqrt{u}}+\frac{\mathbb{E}|Z^{2}-1|}{2u},

for
Z\sim\mathcal{N}(0,1)
. Using the well-known estimate
\mathbb{E}|Z|=\sqrt{\frac{2}{\pi}}
along with the elementary computation
\mathbb{E}|Z^{2}-1|=\frac{4}{\sqrt{2\pi e}}
, it follows that the inner integral in (
2.5
) is
\ll u^{-\frac{1}{2}}
. Then,

\int_{x}^{y}\int_{-\infty}^{\infty}|f_{t}^{\prime}(u)|\penalty\ \mathrm{d}t\penalty\ \mathrm{d}u\ll\sqrt{y}-\sqrt{x}=\frac{y-x}{\sqrt{y}+\sqrt{x}}\asymp\sqrt{\log\log N}-\frac{\log\log M}{\sqrt{\log\log N}},

so, the left-hand side of (
2.5
) is

\ll\sqrt{\log\log N}-\frac{1}{\sqrt{\log\log N}}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{M\in(N^{\varepsilon},N)}\log\log M.

Now we have

\displaystyle\sum_{N^{\varepsilon}<M<N}\frac{\log\log M}{M}

\displaystyle=\int_{N^{\varepsilon}}^{N}\frac{\log\log t}{t}\penalty\ \mathrm{d}t+{\mathrm{O}}(1)=\Big[(\log t)(\log\log t-1)\Big]_{N^{\varepsilon}}^{N}+{\mathrm{O}}(1)

\displaystyle=(1-\varepsilon)(\log N)(\log\log N-1)+\frac{(\log N)\log\log\log N}{2\sqrt{\log\log N}},

thus,

{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{M\in(N^{\varepsilon},N)}\log\log M=\log\log N-1+{\mathrm{O}}\Bigg(\frac{\log\log\log N}{\sqrt{\log\log N}}\Bigg),

and then (
2.5
) follows, concluding the proof.
∎

Lemma 2.4
.

For any bounded function
a\colon\mathbb{N}\to\mathbb{C}
and
N\in\mathbb{N}
sufficiently large, we have

\Big|\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}a(\Omega(n))-{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}a(\Omega(n))\Big|\ll_{\|a\|_{\infty}}\frac{1}{\sqrt{\log\log{N}}}.

Proof.

Invoking (
2.3
), we have

\Big|\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}a(\Omega(n))-{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}a(\Omega(n))\Big|=\Bigg|\sum_{\ell=1}^{\infty}a(\ell)\big(\overline{\pi}_{\ell}(N)-\overline{\pi}^{\log}_{\ell}(N)\big)\Bigg|\ll\sum_{\ell=1}^{\infty}\big|\overline{\pi}_{\ell}(N)-\overline{\pi}^{\log}_{\ell}(N)\big|.

The claim now follows from
Lemma

2.3
.
∎

2.2.  Independence of periodic functions

We say that a function
f\colon\mathbb{N}\to\mathbb{C}
can be written as a
linear combination of
k
indicator functions of infinite arithmetic progressions
if there exist
v_{1},\ldots,v_{k}\in\{z\in\mathbb{C}:|z|\leqslant 1\}
,
a_{1},\ldots,a_{k}\in\mathbb{N}
and
b_{1},\ldots,b_{k}\in\mathbb{N}\cup\{0\}
such that

f(n)=v_{1}\mathbbm{1}_{a_{1}\mathbb{N}+b_{1}}(n)+\ldots+v_{k}\mathbbm{1}_{a_{k}\mathbb{N}+b_{k}}(n),\hskip 20.00003pt\forall n\in\mathbb{N}.

Note that the modulus of the coefficients
v_{1},\ldots,v_{k}
in the above description is not allowed to exceed
1
.

Lemma 2.5
.

Let
k,\ell,r,s\in\mathbb{N}
. Let
f\colon\mathbb{N}\to\mathbb{C}
be an
r
-periodic function that can be written as a linear combination of
k
indicator functions of infinite arithmetic progressions and
g\colon\mathbb{N}\to\mathbb{C}
an
s
-periodic function that can be written as a linear combination of
\ell
indicator functions of infinite arithmetic progressions. If
r
and
s
are coprime, then for any
N\in\mathbb{N}
,

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}f(n)g(n)=\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}f(n)\Big)\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}g(n)\Big)+{\mathrm{O}}\bigg(\frac{k\ell}{N}\bigg),

(2.6)

where the implicit constant in
{\mathrm{O}}(k\ell/N)
is universal (i.e., does not depend on
k
,
\ell
,
r
,
s
,
f
,
g
, or
N
).

Proof.

Let

f(n)=v_{1}\mathbbm{1}_{a_{1}\mathbb{N}+b_{1}}(n)+\ldots+v_{k}\mathbbm{1}_{a_{k}\mathbb{N}+b_{k}}(n)
and
g(n)=w_{1}\mathbbm{1}_{c_{1}\mathbb{N}+d_{1}}(n)+\ldots+w_{\ell}\mathbbm{1}_{c_{\ell}\mathbb{N}+d_{\ell}}(n)
.
Then

\displaystyle\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}f(n)g(n)=\sum_{\begin{subarray}{c}1\leqslant i\leqslant k\\
1\leqslant j\leqslant\ell\end{subarray}}v_{i}w_{j}\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\mathbbm{1}_{a_{i}\mathbb{N}+b_{i}}(n)\mathbbm{1}_{c_{j}\mathbb{N}+d_{j}}(n)\Big).

(2.7)

Since
a_{i}
divides
r
and
c_{j}
divides
s
, we get
\gcd(a_{i},c_{j})=1
. So

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\mathbbm{1}_{a_{i}\mathbb{N}+b_{i}}(n)\mathbbm{1}_{c_{j}\mathbb{N}+d_{j}}(n)=\frac{1}{a_{i}c_{j}}+{\mathrm{O}}\left(\frac{1}{N}\right).

On the other hand, we have

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\mathbbm{1}_{a_{i}\mathbb{N}+b_{i}}(n)=\frac{1}{a_{i}}+{\mathrm{O}}\left(\frac{1}{N}\right)\hskip 10.00002pt\text{and}\hskip 10.00002pt\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\mathbbm{1}_{c_{j}\mathbb{N}+d_{j}}(n)=\frac{1}{c_{j}}+{\mathrm{O}}\left(\frac{1}{N}\right).

This implies that

\displaystyle\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\mathbbm{1}_{a_{i}\mathbb{N}+b_{i}}(n)\mathbbm{1}_{c_{j}\mathbb{N}+d_{j}}(n)=\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\mathbbm{1}_{a_{i}\mathbb{N}+b_{i}}(n)\Big)\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\mathbbm{1}_{c_{j}\mathbb{N}+d_{j}}(n)\Big)+{\mathrm{O}}\left(\frac{1}{N}\right).

(2.8)

Combining (
2.7
) and (
2.8
) gives

\displaystyle\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}f(n)g(n)

\displaystyle=\sum_{\begin{subarray}{c}1\leqslant i\leqslant k\\
1\leqslant j\leqslant\ell\end{subarray}}v_{i}w_{j}\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\mathbbm{1}_{a_{i}\mathbb{N}+b_{i}}(n)\Big)\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\mathbbm{1}_{c_{j}\mathbb{N}+d_{j}}(n)\Big)+{\mathrm{O}}\left(\frac{k\ell}{N}\right)

\displaystyle=\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}f(n)\Big)\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}g(n)\Big)+{\mathrm{O}}\left(\frac{k\ell}{N}\right),

as was to be shown.
∎

2.3.  Turán-Kubilius inequality and applications

The following is a special case of the Turán-Kubilius inequality, which we will use to derive rough upper bounds on the distribution of
\Omega(n)
outside the typical range. Let
n\mapsto\mathbbm{1}_{p\mid n}
denote the indicator function of the set of numbers divisible by a fixed prime
p
.

Theorem 2.6

(Turán-Kubilius inequality; see
[
6
]
)
.

For any
N\in\mathbb{N}
and
P\subseteq\mathbb{P}\cap[1,N]
, we have

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\Bigg|\sum_{p\in P}\mathbbm{1}_{p\mid n}-\sum_{p\in P}\frac{1}{p}\Bigg|\leqslant 2\Bigg(\sum_{p\in P}\frac{1}{p}\Bigg)^{\frac{1}{2}}.

(2.9)

Corollary 2.7
.

For
N\in\mathbb{N}
and
D\geqslant 1
, let

\Gamma_{N,D}=\Bigg\{n\leqslant N:\sum_{p\leqslant N}\mathbbm{1}_{p\mid n}\geqslant\log\log N+D\sqrt{\log\log{N}}\Bigg\}

and

\Delta_{N,D}=\Bigg\{n\leqslant N\colon\sum_{p\leqslant N}\mathbbm{1}_{p\mid n}\leqslant\log\log N-D\sqrt{\log\log{N}}\Bigg\}.

Then for
N
sufficiently large, we have

\frac{|\Gamma_{N,D}|}{N}={\mathrm{O}}\bigg(\frac{1}{D}\bigg)\hskip 10.00002pt\text{and}\hskip 10.00002pt\frac{|\Delta_{N,D}|}{N}={\mathrm{O}}\bigg(\frac{1}{D}\bigg).

Proof.

We prove the result only for
\Gamma_{N,D}
, since the proof for
\Delta_{N,D}
is analogous.
By
Theorem

2.6
and Markov’s inequality, we have for all
t>0
and all but finitely many
N
that

\frac{1}{N}\Bigg|\Bigg\{n\leqslant N:\Bigg|\sum_{p\leqslant N}\mathbbm{1}_{p\mid n}-\sum_{p\leqslant N}\frac{1}{p}\Bigg|>t\Bigg\}\Bigg|\leqslant\frac{2}{t}\Bigg(\sum_{p\leqslant N}\frac{1}{p}\Bigg)^{\frac{1}{2}}\leqslant\frac{4\sqrt{\log\log{N}}}{t}.

It follows that

\frac{1}{N}\Bigg|\Bigg\{n\leqslant N:\sum_{p\leqslant N}\mathbbm{1}_{p\mid n}\geqslant\sum_{p\leqslant N}\frac{1}{p}+t\Bigg\}\Bigg|\leqslant\frac{4\sqrt{\log\log{N}}}{t}.

Since, by Mertens’ theorem, for all but finitely many
N
we have

\sum_{p\leqslant N}\frac{1}{p}+\frac{D}{2}\sqrt{\log\log{N}}\leqslant\log\log N+D\sqrt{\log\log{N}},

we can take
t=\frac{D}{2}\sqrt{\log\log{N}}
and get

\frac{|\Gamma_{N,D}|}{N}={\mathrm{O}}\bigg(\frac{1}{D}\bigg)

as desired.
∎

Lemma 2.8
.

Let
N\in\mathbb{N}
and

such that

, and

If

, then for

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}e\bigg(\frac{t\left(\sum_{r\in P}\mathbbm{1}_{r\mid(n+p)}-\mathbbm{1}_{r\mid(n+q)}\right)}{\sqrt{\log\log{N}}}\bigg)\\

(2.10)

and

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle\begin{subarray}{c}m\in[M]\\
n\in[N]\end{subarray}}$}e\bigg(\frac{t\left(\sum_{r\in P}\mathbbm{1}_{r\mid m}-\mathbbm{1}_{r\mid n}\right)}{\sqrt{\log\log{N}}}\bigg)\\
=\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle\begin{subarray}{c}m\in[M]\\
n\in[N]\end{subarray}}$}e_{K}\bigg(\frac{t\left(\sum_{r\in P}\mathbbm{1}_{r\mid m}-\mathbbm{1}_{r\mid n}\right)}{\sqrt{\log\log{N}}}\bigg)+{\mathrm{O}}\bigg(e^{-K}+\frac{1}{(\log\log N)^{\sigma}}\bigg).

(2.11)

Proof.

We only provide a proof of (
2.10
). The proof of (
2.11
) is analogous. Note that

\displaystyle|e(x)-e_{K}(x)|=\bigg|\sum_{k=K+1}^{\infty}\frac{(2\pi ix)^{k}}{k!}\bigg|

\displaystyle=\bigg|(2\pi ix)^{K+1}\sum_{k=0}^{\infty}\frac{(2\pi ix)^{k}}{(k+K+1)!}\bigg|

\displaystyle\leqslant\bigg|\frac{(2\pi ix)^{K+1}}{(K+1)!}\bigg|\bigg|\underbrace{\sum_{k=0}^{\infty}\frac{(2\pi ix)^{k}}{k!}}_{=1}\bigg|.

Let
D=(\log\log N)^{\sigma}
, and let
\Gamma_{N,D}
be as in
Corollary

2.7
. Then, by the conclusion of
Corollary

2.7
, we have

\displaystyle\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}e\bigg(\frac{t\left(\sum_{r\in P}\mathbbm{1}_{r\mid(n+p)}-\mathbbm{1}_{r\mid(n+q)}\right)}{\sqrt{\log\log{N}}}\bigg)

\displaystyle\hskip 14.22636pt=\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\mathbbm{1}_{\Gamma_{N,D}}(n+p)\mathbbm{1}_{\Gamma_{N,D}}(n+q)e\bigg(\frac{t\left(\sum_{r\in P}\mathbbm{1}_{r\mid(n+p)}-\mathbbm{1}_{r\mid(n+q)}\right)}{\sqrt{\log\log{N}}}\bigg)

\displaystyle\hskip 113.81102pt+{\mathrm{O}}\bigg(\frac{1}{(\log\log N)^{\sigma}}+\frac{H}{N}\bigg)

\displaystyle\hskip 14.22636pt=\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\mathbbm{1}_{\Gamma_{N,D}}(n+p)\mathbbm{1}_{\Gamma_{N,D}}(n+q)e_{K}\bigg(\frac{t\left(\sum_{r\in P}\mathbbm{1}_{r\mid(n+p)}-\mathbbm{1}_{r\mid(n+q)}\right)}{\sqrt{\log\log{N}}}\bigg)

\displaystyle\hskip 113.81102pt+{\mathrm{O}}\bigg(\sup_{n\in\Gamma_{N,D}}\frac{20^{K+1}t^{K+1}\left(\sum_{r\in P}\mathbbm{1}_{r\mid n}\right)^{K+1}}{(K+1)!(\log\log N)^{\frac{K+1}{2}}}+\frac{1}{(\log\log N)^{\sigma}}+\frac{H}{N}\bigg)

\displaystyle\hskip 14.22636pt=\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}e_{K}\bigg(\frac{t\left(\sum_{r\in P}\mathbbm{1}_{r\mid(n+p)}-\mathbbm{1}_{r\mid(n+q)}\right)}{\sqrt{\log\log{N}}}\bigg)

\displaystyle\hskip 113.81102pt+{\mathrm{O}}\bigg(\sup_{n\in\Gamma_{N,D}}\frac{20^{K+1}t^{K+1}\left(\sum_{r\in P}\mathbbm{1}_{r\mid n}\right)^{K+1}}{(K+1)!(\log\log N)^{\frac{K+1}{2}}}+\frac{1}{(\log\log N)^{\sigma}}+\frac{H}{N}\bigg).

We now have

\displaystyle\sup_{n\in\Gamma_{N,D}}\frac{20^{K+1}t^{K+1}\left(\sum_{r\in P}\mathbbm{1}_{r\mid n}\right)^{K+1}}{(K+1)!(\log\log N)^{\frac{K+1}{2}}}

\displaystyle\leqslant\frac{40^{K+1}t^{K+1}(\log\log N)^{(K+1)\sigma}}{(K+1)!}.

Note, by Stirling’s formula, we have

for all but finitely many

, and hence for all but finitely many

we have that

\displaystyle\log\bigg(\frac{40^{K+1}t^{K+1}(\log\log N)^{(K+1)\sigma}}{(K+1)!}\bigg)

\displaystyle\hskip 20.00003pt\hskip 20.00003pt\leqslant(K+1)\log(40t)+(K+1)\sigma(\log\log\log N)-(K+1)\log(K)+2(K+1)

\displaystyle\hskip 20.00003pt\hskip 20.00003pt\leqslant(K+1)\left(\log(40t)+\sigma(\log\log\log N)-\log(K)+2\right)

\displaystyle\hskip 20.00003pt\hskip 20.00003pt=(K+1)\bigg(\log\bigg(\frac{40t(\log\log N)^{\sigma}}{K}\bigg)+2\bigg).

Invoking the assumption

, it now follows that

\log\bigg(\frac{40^{K+1}t^{K+1}(\log\log N)^{\sigma(K+1)}}{(K+1)!}\bigg)\leqslant-(K+1)

and hence

\displaystyle\sup_{n\in\Gamma_{N,D}}\frac{20^{K+1}t^{K+1}\left(\sum_{r\in P}\mathbbm{1}_{r\mid n}\right)^{K+1}}{(K+1)!(\log\log N)^{\frac{K+1}{2}}}

\displaystyle\leqslant e^{-(K+1)}.

The conclusion now follows by combining the above estimates.
∎

2.4.  Approximations of
\Omega(n)

For technical reasons, it will be convenient to replace
\Omega(n)
with an approximation
\omega_{N}(n)
that ignores the contribution of large primes.
We define

t_{N}=N^{\frac{1}{(\log\log N)^{8}}}\hskip 10.00002pt\text{and}\hskip 10.00002pt\omega_{N}(n)=\sum_{\begin{subarray}{c}p\in\mathbb{P}\\
p\leqslant t_{N}\end{subarray}}\mathbbm{1}_{p\mid n}.

(2.12)

The following lemma estimates the error that occurs when replacing
\Omega(n)
with
\omega_{N}(n)
in the expressions appearing in the proof of our main theorem.

Lemma 2.9
.

Let
N,H\geqslant 1
and
p\leqslant H
be positive integers.
For any
t\in\mathbb{R}
, we have

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}e\bigg(\frac{t\Omega(n+p)}{\sqrt{\log\log{N}}}\bigg)\\
=\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}e\bigg(\frac{t\omega_{N}(n+p)}{\sqrt{\log\log{N}}}\bigg)+{\mathrm{O}}\left(\frac{t(\log\log\log N)}{\sqrt{\log\log{N}}}+\frac{tH}{N}\right),

and

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}e\bigg(\frac{t\Omega(n)}{\sqrt{\log\log{N}}}\bigg)=\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}e\bigg(\frac{t\omega_{N}(n)}{\sqrt{\log\log{N}}}\bigg)+{\mathrm{O}}\left(\frac{t(\log\log\log N)}{\sqrt{\log\log{N}}}\right).

Proof.

We only prove the first estimate, as the proof of the second is analogous.
Using that
|e(x)-1|^{2}=2-2\cos{x}\leqslant x^{2}
for all
x\in\mathbb{R}
, we get

\displaystyle\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\left|e\bigg(\frac{t\Omega(n+p)}{\sqrt{\log\log{N}}}\bigg)-e\bigg(\frac{t\omega_{N}(n+p)}{\sqrt{\log\log{N}}}\bigg)\right|=\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\left|e\bigg(\frac{t\left|\Omega(n+p)-\omega_{N}(n+p)\right|}{\sqrt{\log\log{N}}}\bigg)-1\right|

\displaystyle\leqslant\frac{t}{\sqrt{\log\log{N}}}\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\left|\Omega(n+p)-\omega_{N}(n+p)\right|\ll\frac{t}{\sqrt{\log\log{N}}}\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\left|\Omega(n)-\omega_{N}(n)\right|+\frac{tH}{N}.

Now, we have

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\left|\Omega(n)-\omega_{N}(n)\right|=\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\sum_{t_{N}<p\leqslant N}\mathbbm{1}_{p\mid n}+{\mathrm{O}}(1)=\sum_{t_{N}<p\leqslant N}\frac{1}{N}\left\lfloor\frac{N}{p}\right\rfloor+{\mathrm{O}}(1)\\
\leqslant\sum_{t_{N}<p\leqslant N}\frac{1}{p}+{\mathrm{O}}(1)\ll\log\bigg(\frac{\log{N}}{\log{t_{N}}}\bigg)=8\log\log\log{N},

concluding the proof.
∎

3.  Reduction to multiplicative functions

), which follows from
[

, Corollary 1.4]
and a Fourier analytic argument, we reduce the statement in Theorem

to an assertion concerning averages that involve a sequence of multiplicative functions

First, note that in light of

.

Expanding the square in

|\xi|>B\end{subarray}}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\Big|{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{p\in\mathcal{P}_{N}}f_{\xi,N}(n+p)-{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{m\in[N]}f_{\xi,N}(m)\Big|^{2}

we see that
Theorem

3.5
follows from the next two propositions.

Proposition 5.1
.

We have

\sum_{\begin{subarray}{c}\xi\in I_{N}\\
|\xi|>B\end{subarray}}\Big|\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}f_{\xi,N}(n)\Big|\ll\frac{1}{(\log\log N)^{50}}.

Proposition 5.2
.

We have

\sum_{\begin{subarray}{c}\xi\in I_{N}\\
|\xi|>B\end{subarray}}\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}\Big|{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{p\in\mathcal{P}_{N}}f_{\xi,N}(n+p)\Big|^{2}\ll\frac{1}{\log\log{N}}.

We use these propositions for logarithmic averages over
n
, but we can prove them for Cesàro averages, which, in view of
Lemma

2.1
, makes the results stronger.

To prove
Proposition

5.1
we use Halász’s mean value theorem, while the proof of
Proposition

5.2
requires using a deeper result of Matomäki-Radziwiłł-Tao
[
24
]
. For both cases we need to introduce the notion of distance between two multiplicative functions.

Definition 5.3
.

Let
f,g\colon\mathbb{N}\to\mathbb{C}
be two bounded multiplicative functions. The
distance (up to
N
)
between
f
and
g
is defined as

\mathbb{D}(f,g;N)=\Bigg(\sum_{p\leqslant N}\frac{1-\mathrm{Re}(f(p)\overline{g(p)})}{p}\Bigg)^{\frac{1}{2}}.

5.1.  Distance from twisted characters

To prove Propositions
5.1
and
5.2
, we need to have appropriate lower bounds on the distance of the functions
f_{\xi,N}
from twisted characters, i.e., functions of the form
\chi(n)n^{it}
, where
\chi
is a Dirichlet character and
t\in\mathbb{R}
.

Lemma 5.4
.

Let
\xi\in I_{N}
and
t\in\mathbb{R}
.

(i)

If
|t|\ll 1
, then

\mathbb{D}(f_{\xi,N},n\mapsto n^{it};N)^{2}=\bigg(1-\cos\bigg(\frac{2\pi\xi}{|I_{N}|}\bigg)\bigg)\log\log{N}+\cos\bigg(\frac{2\pi\xi}{|I_{N}|}\bigg)\log(1+|t|\log{N})+{\mathrm{O}}(1).

(5.1)

In particular, for
N
sufficiently large and for
\xi\in I_{N}
, we have

\inf_{|t|\ll 1}\mathbb{D}(f_{\xi,N},n\mapsto n^{it};N)^{2}\geqslant\begin{cases}\frac{\pi^{2}\xi^{2}}{2A^{2}}+{\mathrm{O}}(1),&|\xi|\leqslant\sqrt{|I_{N}|},\\
\frac{\pi^{2}\log\log N}{A}+{\mathrm{O}}(1),&\sqrt{|I_{N}|}<|\xi|\leqslant\frac{|I_{N}|}{4},\\
\log\log N+{\mathrm{O}}(1),&\text{otherwise}.\end{cases}

(5.2)

(ii)

If
2\leqslant|t|\leqslant N^{B}
, for
B>0
, then for any
\varepsilon>0
, we have

\mathbb{D}(f_{\xi,N},n\mapsto n^{it};N)^{2}\geqslant\bigg(\frac{1}{3}-\varepsilon\bigg)\log\log{N}+{\mathrm{O}}_{B,\varepsilon}(1).

(5.3)

Lemma 5.5
.

Let
\xi\in I_{N}
,
H^{\prime}\geqslant 2
,
\chi
be a non-principal Dirichlet character modulo
q
, and
t\in\mathbb{R}
.

(i)

If
q\leqslant(\log{H^{\prime}})^{5}
and
|t|\ll 1
, then

\mathbb{D}(f_{\xi,N},n\mapsto\chi(n)n^{it};N)^{2}\gg\log\log{N}.

(ii)

If
q\leqslant(\log{N})^{\frac{1}{125}}
and
10\leqslant|t|\leqslant N^{B}
, for
B>0
, then for any
\varepsilon>0
, we have

\mathbb{D}(f_{\xi,N},n\mapsto\chi(n)n^{it};N)^{2}\geqslant\bigg(\frac{1}{3}-\varepsilon\bigg)\log\log{N}+{\mathrm{O}}_{B,\varepsilon}(1).

Proof of
Lemma

5.4
.

(i) Let
s=1+\frac{1}{\log{N}}+it
,
|t|\ll 1
, and for
\mathrm{Re}(s)>1
, define

F(s)=\sum_{n\geqslant 1}\frac{f_{\xi,N}(n)}{n^{s}}.

Then we have

\log{F(s)}=\sum_{p}\frac{f_{\xi,N}(p)}{p^{s}}+{\mathrm{O}}(1)=e\bigg(\frac{\xi}{|I_{N}|}\bigg)\log{\zeta(s)}+{\mathrm{O}}(1).

(5.4)

Now, using the following classic estimate for the Riemann zeta function

\zeta(s)=\frac{s}{s-1}+O\bigg(\frac{|s|}{\sigma}\bigg)=\frac{1}{s-1}+{\mathrm{O}}(1),\hskip 10.00002pt\sigma=\mathrm{Re}(s)>0,

we get that

\displaystyle\log{\zeta(s)}

\displaystyle=-\log\bigg(\frac{1}{\log{N}}+it\bigg)+{\mathrm{O}}(1)

(5.5)

\displaystyle=-\log\bigg|\frac{1}{\log{N}}+it\bigg|-i\arg\bigg(\frac{1}{\log{N}}+it\bigg)+{\mathrm{O}}(1)

\displaystyle=\log\log{N}-\log(1+|t|\log{N})+{\mathrm{O}}(1).

Combining (
5.4
) and (
5.5
), we obtain that

\mathrm{Re}(\log{F(s)})=\cos\bigg(\frac{2\pi\xi}{|I_{N}|}\bigg)(\log\log{N}-\log(1+|t|\log{N}))+{\mathrm{O}}(1)

(5.6)

Now, using the asymptotic (see
[
13
, Eq. (2.2)]
)

\exp(-\mathbb{D}(f_{\xi,N},n\mapsto n^{it};N)^{2})=\frac{|F(s)|}{\log{N}}+{\mathrm{O}}(1),

we see that

\mathbb{D}(f_{\xi,N},n\mapsto n^{it};N)^{2}=\log\log{N}-\log|F(s)|=\log\log{N}-\mathrm{Re}(\log{F(s)})

and then, by substituting (
5.6
) to the right-hand side of the above we obtain (
5.1
).

We now prove the second part. We distinguish two cases depending on the size of
|\xi|
:

•

If
|\xi|\leqslant|I_{N}|/4
, then
\cos(2\pi\xi/|I_{N}|)\geqslant 0
, hence (
5.1
) gives

\mathbb{D}(f_{\xi,N},n\mapsto n^{it};N)^{2}\geqslant\bigg(1-\cos\bigg(\frac{2\pi\xi}{|I_{N}|}\bigg)\bigg)\log\log{N}+O(1).

1-\cos(2\pi\xi/|I_{N}|)
is increasing as a function of
|\xi|
and it is also positive. Moreover, by the Laurent expansion of
1-\cos(1/x)
at
x=\infty
, we have

1-\cos\bigg(\frac{1}{x}\bigg)=\frac{1}{2x^{2}}+{\mathrm{O}}\bigg(\frac{1}{x^{4}}\bigg).

(5.7)

–

If
|\xi|\leqslant\sqrt{|I_{N}|}
, then (
5.7
) gives that
for
N
sufficiently large,

1-\cos\bigg(\frac{2\pi\xi}{|I_{N}|}\bigg)=\frac{2\pi^{2}\xi^{2}}{|I_{N}|^{2}}+{\mathrm{O}}\bigg(\frac{1}{|I_{N}|^{2}}\bigg),

hence

\mathbb{D}(f_{\xi,N},n\mapsto n^{it};N)^{2}\geqslant\frac{\pi^{2}\xi^{2}}{2A^{2}}+{\mathrm{O}}(1).

–

If
\sqrt{|I_{N}|}<|\xi|\leqslant|I_{N}|/4
, then by monotonicity and (
5.7
), we have

1-\cos\bigg(\frac{2\pi\xi}{|I_{N}|}\bigg)>1-\cos\bigg(\frac{2\pi}{\sqrt{|I_{N}|}}\bigg)=\frac{2\pi^{2}}{|I_{N}|}+{\mathrm{O}}\bigg(\frac{1}{|I_{N}|^{2}}\bigg),

thus,

\mathbb{D}(f_{\xi,N},n\mapsto n^{it};N)^{2}\geqslant\frac{\pi^{2}(\log\log{N})}{A}+{\mathrm{O}}(1).

•

If
|I_{N}|/4\leqslant|\xi|\leqslant|I_{N}|/2
, then
\cos(2\pi\xi/|I_{N}|)\leqslant 0
. Rewriting (
5.1
), we have

\mathbb{D}(f_{\xi,N},n\mapsto n^{it};N)^{2}=\log\log{N}+\cos\bigg(\frac{2\pi\xi}{|I_{N}|}\bigg)\log\bigg(\frac{1+|t|\log{N}}{\log{N}}\bigg)+{\mathrm{O}}(1)

and now we distinguish cases on the size of
|t|
:
If
|t|\leqslant 1/2
, then the second term above is non-negative for
N
sufficiently large. On the other hand if
1/2<|t|\ll 1
, then the second term is
{\mathrm{O}}(1)
. Hence, in both cases we have

\mathbb{D}(f_{\xi,N},n\mapsto n^{it};N)^{2}\geqslant\log\log{N}+{\mathrm{O}}(1).

Putting everything together, we get that (
5.2
) holds for
N
sufficiently large.

(ii) We have that

\displaystyle\mathbb{D}(f_{\xi,N},n\mapsto n^{it};N)^{2}

\displaystyle=\sum_{p\leqslant N}\frac{1-\mathrm{Re}\big(e(\xi/|I_{N}|)p^{-it}\big)}{p}

\displaystyle\geqslant\sum_{\exp((\log{N})^{\frac{2}{3}+\varepsilon})\leqslant p\leqslant N}\frac{1-\mathrm{Re}\big(e(\xi/|I_{N}|))p^{-it}\big)}{p}

\displaystyle\geqslant\sum_{\exp((\log{N})^{\frac{2}{3}+\varepsilon})\leqslant p\leqslant N}\frac{1}{p}-\Bigg|\sum_{\exp((\log{N})^{\frac{2}{3}+\varepsilon})\leqslant p\leqslant N}\frac{e(\xi/|I_{N}|)p^{-it}}{p}\Bigg|

\displaystyle=\bigg(\frac{1}{3}-\varepsilon\bigg)\log\log{N}-\Bigg|\sum_{\exp((\log{N})^{\frac{2}{3}+\varepsilon})\leqslant p\leqslant N}\frac{1}{p^{1+it}}\Bigg|+{\mathrm{O}}(1),

and so, it suffices to show that

\Bigg|\sum_{\exp((\log{N})^{\frac{2}{3}+\varepsilon})\leqslant p\leqslant N}\frac{1}{p^{1+it}}\Bigg|\ll 1.

The left-hand side above is equal to

\bigg|\log\bigg(\zeta\bigg(1+\frac{1}{\log{N}}+it\bigg)\bigg)-\log\bigg(\zeta\bigg(1+\frac{1}{(\log{N})^{\frac{2}{3}+\varepsilon}}+it\bigg)\bigg)\bigg|+{\mathrm{O}}(1).

(5.8)

By the Vinogradov-Korobov zero-free region
[
19
,
39
]
, there exists some absolute constant
C>0
, such that
\zeta(\sigma+it)\neq 0
in the region

\sigma\geqslant 1-\frac{C}{(\log|t|)^{\frac{2}{3}}(\log\log|t|)^{\frac{1}{3}}},\hskip 10.00002pt|t|\geqslant 10,

and then
it follows using standard analytic methods
(as in
[
31
]
) that (
5.8
) is
{\mathrm{O}}(1)
.
∎

Proof of
Lemma

.

(i) For

\displaystyle\mathbb{D}(f_{\xi,N},

Plugging this in (

(ii) We omit this proof since it is identical to that of

5.2.  Proof of
Proposition

5.1

We will use a version of Halász’s mean value theorem
[
14
]
due to Tenenbaum
[
38
]
.
Given a
X,T\geqslant 1
, and
f
a
1
-bounded multiplicative function, we define

M_{0}(f;X,T):=\inf_{|t|\leqslant T}\mathbb{D}(f,n\mapsto n^{it};X)^{2}.

Theorem 5.6

(
[
38
, Theorem 4.5]
)
.

For
X\geqslant 3
,
1\leqslant T\leqslant(\log X)^{3}
, and
f

1
-bounded multiplicative function, we have

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[X]}$}f(n)\ll(1+M_{0}(f;X,T))e^{-M_{0}(f,X,T)}+\frac{1}{T}+\frac{1}{\sqrt{\log X}}.

Proof of
Proposition

5.1
.

By
Theorem

5.6
for
X=N
and
T=\log N
, we have

\sum_{\begin{subarray}{c}\xi\in I_{N}\\
|\xi|>B\end{subarray}}\Big|\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}f_{\xi,N}(n)\Big|\ll\sum_{\begin{subarray}{c}\xi\in I_{N}\\
|\xi|>B\end{subarray}}\exp\bigg(-\frac{M_{0}(f_{\xi,N};N,\log N)}{2}\bigg)+\frac{|I_{N}|}{\sqrt{\log N}}.

By
Lemma

5.4
, we have for
N
sufficiently large,

M_{0}(f_{\xi,N};N,\log N)\geqslant\min\bigg\{\frac{\pi^{2}\xi^{2}}{2A^{2}},\frac{\pi^{2}(\log\log{N})}{A}\bigg\}+{\mathrm{O}}(1).

Then we have

\displaystyle\sum_{\begin{subarray}{c}\xi\in I_{N}\\
|\xi|>B\end{subarray}}\Big|\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}f_{\xi,N}(n)\Big|\ll\max\Bigg\{\sum_{\xi>B}e^{-\frac{\pi^{2}\xi^{2}}{A^{2}}},\frac{|I_{N}|}{(\log{N})^{\frac{\pi^{2}}{16A}}}\Bigg\}.

For
N
sufficiently large,

\sum_{\xi>B}e^{-\frac{\pi^{2}\xi^{2}}{4A^{2}}}\leqslant\int_{B-1}^{\infty}e^{-\frac{\pi^{2}x^{2}}{4A^{2}}}\penalty\ \mathrm{d}x=\frac{\sqrt{2}A}{\pi}\int_{{\frac{\pi(B-1)}{\sqrt{2}A}}}^{\infty}e^{-\frac{y^{2}}{2}}\penalty\ \mathrm{d}y\leqslant\frac{2A^{2}}{\pi^{2}(B-1)}\int_{{\frac{\pi(B-1)}{\sqrt{2}A}}}^{\infty}ye^{-\frac{y^{2}}{2}}\penalty\ \mathrm{d}y\\
=\frac{2A^{2}}{\pi^{2}(B-1)}\exp\bigg(-\frac{\pi^{2}(B-1)^{2}}{4A^{2}}\bigg)\ll\exp\bigg(-\frac{\pi^{2}B^{2}}{4A^{2}}\bigg)=(\log\log N)^{-50}.

We can readily check that the second term in the maximum is smaller than the above bound, and that the contribution of
\frac{|I_{N}|}{\sqrt{\log N}}
in the first equation is negligible, hence the result follows.

|\xi|>B\end{subarray}}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{p\in\mathcal{P}_{N}}h_{\xi,N}(n)f_{\xi,N}(n+p)\\
=\sum_{\begin{subarray}{c}\xi\in I_{N}\\
|\xi|>B\end{subarray}}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{p\in\mathcal{P}_{N}}f_{\xi,N}(n)\overline{h_{\xi,N}(n-p)}+{\mathrm{O}}\bigg(\frac{|I_{N}|\log{H}}{\log{N}}\bigg),

(5.11)

where we set

.
For the main term, we first decompose the set
\mathcal{P}_{N}
into pairwise disjoint dyadic intervals
\mathcal{P}_{k}=[\frac{H_{k}}{2},H_{k})\cap\mathbb{P}
, where

, for

, where

.

\sum_{\begin{subarray}{c}\xi\in I_{N}\\
|\xi|>B\end{subarray}}\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}^{\ast}_{k\in[K]}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{p\in\mathcal{P}_{k}}f_{\xi,N}(n)\overline{h_{\xi,N}(n-p)},

(5.12)

where
\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}^{\ast}:=\frac{1}{\mathscr{L}}\sum_{k=1}^{K}\mathscr{L}_{k}
and
\mathscr{L}_{k}=\sum_{p\in\mathcal{P}_{k}}\frac{1}{p}\sim\log 2
.
We define for

,
|\xi|>B
,

\varepsilon_{\xi}=\begin{cases}\exp\Big(-\frac{\pi^{2}\xi^{2}}{200A^{2}}\Big),&|\xi|\leqslant\sqrt{|I_{N}|},\\
\Big(\frac{\log\log N}{\log\log\log N}\Big)^{\frac{1}{5}}\exp\Big(-\frac{3\log\log N}{20\log\log\log N}\Big),&\text{otherwise}.\end{cases}

For simplicity, we denote the second value of

by
\varepsilon_{N}
.
For each
\xi,k

for

,

,
\xi\in I_{N}
,
\mathcal{P}=\mathcal{P}_{k}
and
\varepsilon=\varepsilon_{\xi}>0
, it follows that (

) is

\ll\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}^{\ast}_{k\in[K]}\sum_{\begin{subarray}{c}\xi\in I_{N}\\
|\xi|>B\end{subarray}}\Bigg(\varepsilon_{\xi}^{-4}\bigg(\sup_{\alpha\in[0,1]}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\Big|\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}_{j\in[H_{k}]}f_{\xi,N}(n+j)e(j\alpha)\Big|+\frac{\log{H_{k}}}{\log N}\bigg)+\varepsilon_{\xi}\Bigg)\\
\ll\sum_{\begin{subarray}{c}\xi\in I_{N}\\
|\xi|>B\end{subarray}}\varepsilon_{\xi}^{-4}\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}^{\ast}_{k\in[K]}\sup_{\alpha\in[0,1]}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\Big|\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle j\in[H_{k}]}$}f_{\xi,N}(n+j)e(j\alpha)\Big|+\frac{\log H}{\log N}\sum_{\begin{subarray}{c}\xi\in I_{N}\\
|\xi|>B\end{subarray}}\varepsilon_{\xi}^{-4}+\sum_{\begin{subarray}{c}\xi\in I_{N}\\
|\xi|>B\end{subarray}}\varepsilon_{\xi}.

Now, by

5.10
,

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}^{\ast}_{k\in[K]}\sup_{\alpha\in[0,1]}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\Big|\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle j\in[H_{k}]}$}f_{\xi,N}(n+j)e(j\alpha)\Big|\\
\ll\sup_{k\in[K]}\exp\bigg(-\frac{M(f_{\xi,N};N,Q_{N,H_{k}})}{20}\bigg)+\frac{\log\log H}{\log H_{0}}+\frac{1}{(\log N)^{\frac{1}{700}}}.

Combining Lemmas
5.4
and
5.5
, summing over
\xi
, and noting that
\frac{\log\log H}{\log H_{0}}
dominates over
\frac{\log H}{\log N}
and
(\log N)^{-\frac{1}{700}}
, we obtain that (

) is

\displaystyle\ll\sum_{B<\xi\leqslant\sqrt{|I_{N}|}}\varepsilon_{\xi}^{-4}\exp\bigg(-\frac{\pi^{2}\xi^{2}}{40A^{2}}\bigg)+(\log N)^{-\frac{\pi^{2}}{A}}\sum_{\sqrt{|I_{N}|}<\xi\leqslant\frac{|I_{N}|}{2}}\varepsilon_{\xi}^{-4}+\frac{\log\log H}{\log H_{0}}\sum_{B<\xi\leqslant\frac{|I_{N}|}{2}}\varepsilon_{\xi}^{-4}

\displaystyle+\sum_{B<\xi\leqslant\frac{|I_{N}|}{2}}\varepsilon_{\xi}

\displaystyle\ll\sum_{\xi>B}\exp\bigg(-\frac{\pi^{2}\xi^{2}}{200A^{2}}\bigg)+(\log N)^{-\frac{\pi^{2}}{A}}|I_{N}|\varepsilon_{N}^{-4}+\frac{\log\log H}{\log H_{0}}\sum_{\xi\leqslant\sqrt{|I_{N}|}}\exp\bigg(\frac{\pi^{2}\xi^{2}}{50A^{2}}\bigg)

\displaystyle+\frac{\log\log H}{\log H_{0}}|I_{N}|\varepsilon_{N}^{-4}+|I_{N}|\varepsilon_{N}.

Since
\frac{\log\log H}{\log H_{0}}\gg(\log N)^{-\frac{\pi^{2}}{A}}
, the second term is negligible. The last two terms are balanced by the choice of
\varepsilon_{N}
and they much smaller than
(\log\log N)^{-{\mathrm{O}}(1)}
, so they are also negligible. The first term, as in the proof of
Proposition

5.1
, is

\exp\bigg(-\frac{\pi^{2}B^{2}}{200A^{2}}\bigg)=\frac{1}{\log\log N}.

Finally, by a similar argument, we have the asymptotic

\sum_{\xi\leqslant\sqrt{|I_{N}|}}\exp\bigg(\frac{\pi^{2}\xi^{2}}{50A^{2}}\bigg)\sim\frac{25A^{2}}{\pi^{2}\sqrt{|I_{N}|}}\exp\bigg(\frac{\pi^{2}|I_{N}|}{50A^{2}}\bigg)\ll\exp\bigg(\frac{|I_{N}|}{2A^{2}}\bigg)=\exp\bigg(\sqrt{\frac{\log\log N}{\log\log\log N}}\bigg),

hence the third term is

\ll\frac{\log\log N}{\log\log\log N}\exp\bigg(-\frac{3\log\log N}{4\log\log\log N}+\sqrt{\frac{\log\log N}{\log\log\log N}}\bigg)\ll(\log\log N)^{-{\mathrm{O}}(1)}.

Putting everything together and since the error term in (
5.11
) is dominated by the main term, we conclude the proof.
∎

and

In this section we prove Theorem

. In fact, we show that Theorems

For our purposes in this section, we reformulate (

as follows: Given a bounded function

, in light of (

), the left-hand side of (

\displaystyle\hskip 5.69046pt=\sum_{\ell=1}^{\infty}\Big|\Big({\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]\cap\mathbb{P}_{\ell}}a(\Omega(n+1))\Big)\overline{\pi}^{\log}_{\ell}(N)-\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[N]}$}a(\Omega(n))\Big)\overline{\pi}_{\ell}(N)\Big|+{\mathrm{O}}\Bigg(\frac{(\log\log\log{N})^{2}}{\sqrt{\log\log{N}}}\Bigg).

Now observe that

(6.1)

We first show the easy direction that Theorem
C
implies Theorem

.

Proof of Theorem

\implies

.

Let

be bounded and suppose that Theorem

Appendix A

with optimal error term

We sketch an alternative proof of Theorem

with optimal error term that was communicated to us by Harald A. Helfgott after the first version of the article appeared. The three main ingredients of this proof is the main theorem of
[

]
(in particular,
[

, Corollary 1.4]
), the quantitative Erdős-Kac theorem
[

, Theorem 2]
, and
[

, Proposition 8.12]
. The use of the latter as a black-box is crucial to obtain the optimal error term.

Let
a,b\colon\mathbb{N}\to\mathbb{C}
be bounded functions. We want to show

\Big|{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}a(\Omega(n))b(\Omega(n+1))-\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}_{n\in[N]}a(\Omega(n))\Big)\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}_{n\in[N]}b(\Omega(n))\Big)\Big|\ll\frac{1}{\sqrt{\log\log N}}.

In view of
Lemma

2.4
, it is enough to show

\Big|{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}a(\Omega(n))b(\Omega(n+1))-\Big({\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}a(\Omega(n))\Big)\Big({\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}b(\Omega(n))\Big)\Big|\ll\frac{1}{\sqrt{\log\log N}}.

We let
H=\exp\big(\sqrt{\log N}\big)
,

,
\mathcal{P}=[H_{0},H]\cap\mathbb{P}
,

, and

as in (

We start by noting that

{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}a(\Omega(n))b(\Omega(n+1))={\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{p\in\mathcal{P}}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\widetilde{a}(\Omega(n))\widetilde{b}(\Omega(n+p))+{\mathrm{O}}\bigg(\frac{1}{\sqrt{\log\log N}}\bigg),

where
\widetilde{a},\widetilde{b}
are defined as in the proof of
Theorem

3.3
.
The proof of this is identical to that of
Proposition

3.2
, and is a consequence of
[
15
, Corollary 1.4]
.
Then it suffices to show

\Big|{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{p\in\mathcal{P}}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\widetilde{a}(\Omega(n))\widetilde{b}(\Omega(n+p))-\Big({\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\widetilde{a}(\Omega(n))\Big)\Big({\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\widetilde{b}(\Omega(n))\Big)\Big|\ll\frac{1}{\sqrt{\log\log N}}.

We can write the left-hand side of the last equation as

\Bigg|\sum_{\ell,k=1}^{\infty}\widetilde{a}(\ell)\widetilde{b}(k){\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{p\in\mathcal{P}}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\mathbb{P}_{\ell}}(n)\mathbbm{1}_{\mathbb{P}_{k}}(n+p)\\
-\Bigg(\sum_{\ell=1}^{\infty}\widetilde{a}(\ell){\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\mathbb{P}_{\ell}}(n)\Bigg)\Bigg(\sum_{k=1}^{\infty}\widetilde{b}(k){\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\mathbb{P}_{k}}(n)\Bigg)\Bigg|,

hence it suffices to show

\sum_{\ell,k=1}^{\infty}\Big|{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{p\in\mathcal{P}}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\mathbb{P}_{\ell}}(n)\mathbbm{1}_{\mathbb{P}_{k}}(n+p)-\Big({\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\mathbb{P}_{\ell}}(n)\Big)\Big({\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\mathbb{P}_{k}}(n)\Big)\Big|\ll\frac{1}{\sqrt{\log\log N}}.

Now we restrict both summations to
\ell,k\in T_{N}
and the contribution of the complementary range is at most

2{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\Omega(n)\not\in T_{N}}+{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{p\in\mathcal{P}}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\Omega(n+p)\not\in T_{N}}\ll\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}_{n\in[N]}\mathbbm{1}_{\Omega(n)\not\in T_{N}}+\sup_{p\in\mathcal{P}}\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}_{n\in[N]}\mathbbm{1}_{\Omega(n+p)\not\in T_{N}}.

By
Lemma

3.1
, which is a corollary of the quantitative Erdős-Kac theorem
[
30
, Theorem 2]
, the error is

\ll\frac{1}{\sqrt{\log\log N}},

thus, it is enough to show

\sum_{\ell,k\in T_{N}}\Big|{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{p\in\mathcal{P}}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\mathbb{P}_{\ell}}(n)\mathbbm{1}_{\mathbb{P}_{k}}(n+p)-\Big({\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\mathbb{P}_{\ell}}(n)\Big)\Big({\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\mathbb{P}_{k}}(n)\Big)\Big|\ll\frac{1}{\sqrt{\log\log N}}.

(A.1)

By
[
15
, Proposition 8.12]
, we have for any
M\in[N^{\frac{1}{\log\log N}},N^{2\log\log N}]
and uniformly for all
k,\ell\geqslant 1
,

{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in\mathcal{P}}\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[M]}$}\mathbbm{1}_{\mathbb{P}_{\ell}}(n)\mathbbm{1}_{\mathbb{P}_{k}}(n+p)\\
=\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[M]}$}\mathbbm{1}_{\mathbb{P}_{\ell}}(n)\Big)\Big(\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}\raisebox{-1.50696pt}{${}_{\scriptstyle n\in[M]}$}\mathbbm{1}_{\mathbb{P}_{k}}(n)\Big)+{\mathrm{O}}\Bigg(\frac{|\ell-\log\log N|^{2}+|k-\log\log N|^{2}+1}{(\log\log N)^{2}}\Bigg).

Using
Lemma

2.1
as we did in
Section

4
to derive
Theorem

3.4
from
Theorem

4.1
, it follows that

{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in\mathcal{P}}{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\mathbb{P}_{\ell}}(n)\mathbbm{1}_{\mathbb{P}_{k}}(n+p)\\
=\Big({\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\mathbb{P}_{\ell}}(n)\Big)\Big({\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{\mathbb{P}_{k}}(n)\Big)+{\mathrm{O}}\Bigg(\frac{|\ell-\log\log N|^{2}+|k-\log\log N|^{2}+1}{(\log\log N)^{2}}\Bigg).

Summing over all
\ell,k\in T_{N}
, we obtain that the left-hand side of (
A.1
) is

\ll\frac{\log\log\log N}{\log\log N},

so the result follows.

While an optimal error term for the Erdős-Kac theorem was obtained by Rényi and Turán in
[
30
]
, it has remained an open problem to do the same for the bivariate Erdős-Kac theorem.
Currently, the best known result, established in
[
21
]
, asserts that

\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}_{n\in[N]}\mathbbm{1}_{(-\infty,y)}\bigg(\frac{\Omega(n)-\log\log N}{\sqrt{\log\log N}}\bigg)\mathbbm{1}_{(-\infty,z)}\bigg(\frac{\Omega(n+1)-\log\log N}{\sqrt{\log\log N}}\bigg)\\
=\Bigg(\frac{1}{\sqrt{2\pi}}\int_{-\infty}^{y}e^{-\frac{t^{2}}{2}}\penalty\ \mathrm{d}t\Bigg)\Bigg(\frac{1}{\sqrt{2\pi}}\int_{-\infty}^{z}e^{-\frac{t^{2}}{2}}\penalty\ \mathrm{d}t\Bigg)+{\mathrm{O}}\Bigg(\frac{\log\log\log N}{(\log\log N)^{\frac{1}{4}}}\Bigg).

As a consequence of the above argument, we can now establish an optimal error in the bivariate setting, but with the caveat that Cesàro averages are replaced by logarithmic averages.

Corollary A.1
.

Uniformly for all
y,z\in\mathbb{R}
and for
N
sufficiently large, we have

{\raisebox{-1.72218pt}{\scalebox{1.4}[1.3]{$\mathbb{E}$}}}^{\log}_{n\in[N]}\mathbbm{1}_{(-\infty,y)}\bigg(\frac{\Omega(n)-\log\log N}{\sqrt{\log\log N}}\bigg)\mathbbm{1}_{(-\infty,z)}\bigg(\frac{\Omega(n+1)-\log\log N}{\sqrt{\log\log N}}\bigg)\\
=\Bigg(\frac{1}{\sqrt{2\pi}}\int_{-\infty}^{y}e^{-\frac{t^{2}}{2}}\penalty\ \mathrm{d}t\Bigg)\Bigg(\frac{1}{\sqrt{2\pi}}\int_{-\infty}^{z}e^{-\frac{t^{2}}{2}}\penalty\ \mathrm{d}t\Bigg)+{\mathrm{O}}\bigg(\frac{1}{\sqrt{\log\log N}}\bigg).
