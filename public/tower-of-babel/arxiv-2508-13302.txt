A First Order Algorithm on an Optimization Problem with Improved Convergence when Problem is Convex
Chee-Khian Sim

Abstract
We propose a first order algorithm, a modified version of FISTA, to solve an optimization problem with an objective function that is the sum of a possibly nonconvex function, with Lipschitz continuous gradient, and a convex function which can be nonsmooth. The algorithm is shown to have an iteration complexity of 𝒪 ⁡ ( ϵ − 2 ) \mathcal{O}(\epsilon^{-2}) to find an ϵ \epsilon -approximate solution to the problem, and this complexity improves to 𝒪 ( ϵ − 2 / 3 ) \mathcal{O}(\epsilon^{-2/3}) when the objective function turns out to be convex. We further provide asymptotic convergence rate for the algorithm of worst case o ⁡ ( ϵ − 2 ) o(\epsilon^{-2}) iterations to find an ϵ \epsilon -approximate solution to the problem, with worst case o ( ϵ − 2 / 3 ) o(\epsilon^{-2/3}) iterations when its objective function is convex. Keywords. Fast iterative shrinkage thresholding algorithm (FISTA); nonconvex optimization problem; convex optimization problem; iteration complexity; asymptotic convergence rate.

\displaystyle 2La_{k-1}[(a_{k-1}-1)[\|y_{k-1}-{x}_{k}\|^{2}-\|y_{k-1}-y_{k}\|^{2}]+[\|y^{\ast}-{x}_{k}\|^{2}-\|y^{\ast}-y_{k}\|^{2}]]+

\displaystyle\frac{\underline{m}-L_{k}}{2}a_{k-1}\|y^{\ast}-x_{k}\|^{2}.

Applying (
21
) in Proposition
3.3
on the right hand side of the inequality in (
26
), we have

\displaystyle a_{k-1}^{2}[f_{k}(y_{k})+h(y_{k})-f_{k}(y^{\ast})-h(y^{\ast})]-a_{k-2}^{2}[f_{k}(y_{k-1})+h(y_{k-1})-f_{k}(y^{\ast})-h(y^{\ast})]+

(27)

\displaystyle La_{k-1}^{2}\|y_{k}-{x}_{k}\|^{2}

\displaystyle\leq

\displaystyle 2L[\|a_{k-2}[y_{k-1}-y_{k-2}]+y_{k-2}-y^{\ast}\|^{2}-\|a_{k-1}[y_{k}-y_{k-1}]+y_{k-1}-y^{\ast}\|^{2}]+

\displaystyle\frac{\underline{m}-L_{k}}{2}a_{k-1}\|y^{\ast}-y_{k}\|^{2}.

Now,

\displaystyle a_{k-1}^{2}[f_{k}(y_{k})+h(y_{k})-f_{k}(y^{\ast})-h(y^{\ast})]-a_{k-2}^{2}[f_{k}(y_{k-1})+h(y_{k-1})-f_{k}(y^{\ast})-h(y^{\ast})]

\displaystyle=

\displaystyle a_{k-1}^{2}[\phi(y_{k})-\phi(y^{\ast})]+\frac{L_{k}}{2}a_{k-1}^{2}[\|y_{k}-y_{k-1}\|^{2}-\|y^{\ast}-y_{k-1}\|^{2}]-a_{k-2}^{2}[\phi(y_{k-1})-\phi(y^{\ast})]+

\displaystyle\frac{L_{k}}{2}a_{k-2}^{2}\|y^{\ast}-y_{k-1}\|^{2}

\displaystyle=

\displaystyle a_{k-1}^{2}[\phi(y_{k})-\phi(y^{\ast})]-a_{k-2}^{2}[\phi(y_{k-1})-\phi(y^{\ast})]+\frac{L_{k}}{2}a_{k-1}^{2}\|y_{k}-y_{k-1}\|^{2}-

\displaystyle\frac{L_{k}}{2}(a_{k-2}^{2}-a_{k-1}^{2})\|y^{\ast}-y_{k-1}\|^{2}

\displaystyle=

\displaystyle a_{k-1}^{2}[\phi(y_{k}-\phi(y^{\ast})]-a_{k-2}^{2}[\phi(y_{k-1})-\phi(y^{\ast})]+\frac{L_{k}}{2}a_{k-1}^{2}\|y_{k}-y_{k-1}\|^{2}-\frac{L_{k}}{2}a_{k-1}\|y_{k-1}-y^{\ast}\|^{2},

where the last equality follows from (
11
). From the above and (
27
), upon algebraic manipulations, we have

\displaystyle a_{k-1}^{2}[\phi(y_{k}-\phi(y^{\ast})]-a_{k-2}^{2}[\phi(y_{k-1})-\phi(y^{\ast})]+\frac{L_{k}}{2}a_{k-1}^{2}\|y_{k}-y_{k-1}\|^{2}+La_{k-1}^{2}\|y_{k}-{x}_{k}\|^{2}

\displaystyle\leq

\displaystyle 2L[\|a_{k-2}[y_{k-1}-y_{k-2}]+y_{k-2}-y^{\ast}\|^{2}-\|a_{k-1}[y_{k}-y_{k-1}]+y_{k-1}-y^{\ast}\|^{2}]+

\displaystyle\frac{\underline{m}-L_{k}}{2}a_{k-1}\|y^{\ast}-y_{k}\|^{2}+\frac{L_{k}}{2}a_{k-1}\|y_{k-1}-y^{\ast}\|^{2},

and the lemma is proved.

\Box

Summing the inequality in Lemma
4.1
from
k=2
to
n
leads to

\displaystyle a_{n-1}^{2}[\phi(y_{n})-\phi(y^{\ast})]-a_{0}^{2}[\phi(y_{1})-\phi(y^{\ast})]+\frac{1}{2}\sum_{k=2}^{n}L_{k}a_{k-1}^{2}\|y_{k}-y_{k-1}\|^{2}+L\sum_{k=2}^{n}a_{k-1}^{2}\|y_{k}-{x}_{k}\|^{2}

(28)

\displaystyle\leq

\displaystyle 2L[\|a_{0}[y_{1}-y_{0}]+y_{0}-y^{\ast}\|^{2}-\|a_{n-1}[y_{n}-y_{n-1}]+y_{n-1}-y^{\ast}\|^{2}]+

\displaystyle\frac{1}{2}\sum_{k=2}^{n}(\underline{m}-L_{k})a_{k-1}\|y^{\ast}-y_{k}\|^{2}+\frac{1}{2}\sum_{k=2}^{n}L_{k}a_{k-1}\|y_{k-1}-y^{\ast}\|^{2}.

We are now ready for the main theorem in this paper:

Theorem 4.2

Given tolerance
\epsilon>0
. Algorithm mFISTA outputs an
\epsilon
-approximate solution to Problem (
3
) in at most
\mathcal{O}(\epsilon^{-2})
iterations. In the case when
f
in Problem (
3
) is convex, the iteration complexity becomes
\mathcal{O}(\epsilon^{-2/3})
.

Proof
: From (
12
), we have

\displaystyle\|v_{k}\|

\displaystyle=

\displaystyle\|\nabla f(y_{k})-\nabla f(x_{k})+L_{k}[y_{k-1}-x_{k}]+4L[{x}_{k}-y_{k}]\|

\displaystyle\leq

\displaystyle(5L+L_{k})\|x_{k}-y_{k}\|+L_{k}\|y_{k}-y_{k-1}\|

\displaystyle\leq

\displaystyle 6L\|x_{k}-y_{k}\|+L_{k}\|y_{k}-y_{k-1}\|.

Hence,

\displaystyle\min_{1\leq k\leq n}\|v_{k}\|\leq 2\sqrt{L}\left(\min_{2\leq k\leq n}\left(36L\|x_{k}-y_{k}\|^{2}+L_{k}\|y_{k}-y_{k-1}\|^{2}\right)\right)^{1/2}.

(29)

On the other hand, from (
28
), the following holds:

\displaystyle\frac{1}{36}\left(\min_{2\leq k\leq n}\left(36L\|x_{k}-y_{k}\|^{2}+L_{k}\|y_{k}-y_{k-1}\|^{2}\right)\right)\sum_{k=2}^{n}a_{k-1}^{2}

(30)

\displaystyle\leq

\displaystyle 2L\|a_{0}[y_{1}-y_{0}]+y_{0}-y^{\ast}\|^{2}+\frac{\underline{m}}{2}\sum_{k=2}^{n}a_{k-1}\|y^{\ast}-y_{k}\|^{2}+\frac{1}{2}\sum_{k=2}^{n}L_{k}a_{k-1}\|y_{k-1}-y^{\ast}\|^{2}

\displaystyle\leq

\displaystyle 2L\|a_{0}[y_{1}-y_{0}]+y_{0}-y^{\ast}\|^{2}+2C^{2}\left(\underline{m}+\max_{2\leq k\leq n}L_{k}\right)\sum_{k=2}^{n}a_{k-1},

where the last inequality follows from
\|y\|\leq C
for
y\in{\rm{dom}}\ h
. Note that by (
15
) and (
16
),

\displaystyle\frac{1}{16}\sum_{k=2}^{n}k^{2}\leq\sum_{k=2}^{n}a_{k-1}^{2},\quad\sum_{k=2}^{n}a_{k-1}\leq\sum_{k=2}^{n}k.

Using the above two inequalities, (
30
) implies that

\displaystyle\frac{1}{576}\left(\min_{2\leq k\leq n}\left(36L\|x_{k}-y_{k}\|^{2}+L_{k}\|y_{k}-y_{k-1}\|^{2}\right)\right)\sum_{k=2}^{n}k^{2}

(31)

\displaystyle\leq

\displaystyle 2L\|a_{0}[y_{1}-y_{0}]+y_{0}-y^{\ast}\|^{2}+2C^{2}\left(\underline{m}+\max_{2\leq k\leq n}L_{k}\right)\sum_{k=2}^{n}k.

When
f
is convex,
\underline{m}=0
and
\max_{2\leq k\leq n}L_{k}=0
, hence (
31
) becomes

\displaystyle\frac{1}{576}\left(\min_{2\leq k\leq n}\left(36L\|x_{k}-y_{k}\|^{2}+L_{k}\|y_{k}-y_{k-1}\|^{2}\right)\right)\sum_{k=2}^{n}k^{2}\leq 2L\|a_{0}[y_{1}-y_{0}]+y_{0}-y^{\ast}\|^{2}.

(32)

From (
29
) and (
31
), we deduce that

\displaystyle\min_{1\leq k\leq n}\|v_{k}\|=\mathcal{O}(n^{-1/2}),

and when
f
is convex, from (
29
) and (
32
), we deduce that

\displaystyle\min_{1\leq k\leq n}\|v_{k}\|=\mathcal{O}(n^{-3/2}).

The theorem is hence proved.

\Box

Remark 4.3

It is easy to see from (

), where we have
\underline{m}=L_{k}=0
when

4.1
Further Discussions

In this subsection, we analyze the convergence behavior of Algorithm mFISTA further.

We first consider the case when
f
is convex. It turns out that we can get from the iteration complexity of Algorithm mFISTA of
O(\epsilon^{-2/3})
to an asymptotic
o(\epsilon^{-2/3})
iterations to find an
\epsilon
-approximate solution to Problem (
3
) in this case.

When
f
is convex, it holds that
\underline{m}=L_{k}=0
for all
k
. Hence, (
22
) becomes

\displaystyle a_{k-1}^{2}[\phi(y_{k})-\phi(y^{\ast})]-a_{k-2}^{2}[\phi(y_{k-1})-\phi(y^{\ast})]+La_{k-1}^{2}\|y_{k}-{x}_{k}\|^{2}

(33)

\displaystyle\leq

\displaystyle 2L[\|a_{k-2}[y_{k-1}-y_{k-2}]+y_{k-2}-y^{\ast}\|^{2}-\|a_{k-1}[y_{k}-y_{k-1}]+y_{k-1}-y^{\ast}\|^{2}].

We see from (
33
) that
\{a_{k-1}^{2}[\phi(y_{k})-\phi(y^{\ast})]+2L\|a_{k-1}[y_{k}-y_{k-1}]+y_{k-1}-y^{\ast}\|^{2}\}
is a nonincreasing sequence, and furthemore each term in the sequence nonnegative. Hence, the sequence is convergent.

By summing (
33
) from
k=n+1
to
2n
, we have

\displaystyle L\left(\min_{n+1\leq k\leq 2n}\|y_{k}-x_{k}\|^{2}\right)\sum_{k=n+1}^{2n}a_{k-1}^{2}\leq L\sum_{k=n+1}^{2n}a_{k-1}^{2}\|y_{k}-x_{k}\|^{2}

(34)

\displaystyle\leq

\displaystyle(a_{n-1}^{2}[\phi(y_{n})-\phi(y^{\ast})]+2L\|a_{n-1}[y_{n}-y_{n-1}]+y_{n-1}-y^{\ast}\|^{2})-

\displaystyle(a_{2n-1}^{2}[\phi(y_{2n})-\phi(y^{\ast})]+2L\|a_{2n-1}[y_{2n}-y_{2n-1}]+y_{2n-1}-y^{\ast}\|^{2}).

We are then led to the following theorem:

Theorem 4.4

When
f
in Problem (
3
) is convex, Algorithm mFISTA finds an
\epsilon
-approximate solution to the problem in at most
o(\epsilon^{-2/3})
iterations.

Proof
: When
f
is convex,
v_{k}
in (
12
) is given by

\displaystyle v_{k}=\nabla f(y_{k})-\nabla f(x_{k})+4L[x_{k}-y_{k}].

Hence,

\displaystyle\|v_{k}\|\leq 5L\|y_{k}-x_{k}\|.

(35)

On the other hand, from (
34
) and (
15
), we have

\displaystyle\frac{1}{16}L\left(\min_{n+1\leq k\leq 2n}\|y_{k}-x_{k}\|^{2}\right)\sum_{k=n+1}^{2n}k^{2}\leq L\left(\min_{n+1\leq k\leq 2n}\|y_{k}-x_{k}\|^{2}\right)\sum_{k=n+1}^{2n}a_{k-1}^{2}

\displaystyle\leq

\displaystyle(a_{n-1}^{2}[\phi(y_{n})-\phi(y^{\ast})]+2L\|a_{n-1}[y_{n}-y_{n-1}]+y_{n-1}-y^{\ast}\|^{2})-

\displaystyle(a_{2n-1}^{2}[\phi(y_{2n})-\phi(y^{\ast})]+2L\|a_{2n-1}[y_{2n}-y_{2n-1}]+y_{2n-1}-y^{\ast}\|^{2}),

where the right hand side in the above inequality tends to zero as

tends to infinity since
\{a_{k-1}^{2}[\phi(y_{k})-\phi(y^{\ast})]+2L\|a_{k-1}[y_{k}-y_{k-1}]+y_{k-1}-y^{\ast}\|^{2}\}
is a convergent sequence. Hence, we have

\displaystyle\min_{n+1\leq k\leq 2n}\|y_{k}-x_{k}\|^{2}=o(n^{-3}).

The above equality together with (

\displaystyle\min_{n+1\leq k\leq 2n}\|v_{k}\|=o(n^{-3/2}).

5
Conclusion

In this paper, we propose a first order algorithm, Algorithm mFISTA, to solve an optimization problem whose objective function is the sum of a possibly nonconvex function, with Lipschitz continuous gradient, and a convex function which can be nonsmooth. A feature of the algorithm is its ability to “detect” when the objective function is convex to obtain an improved iteration complexity. We analyze the algorithm to provide iteration complexity results for the algorithm in the nonconvex and convex case. We further provide asymptotic convergence rate results for the algorithm also in the nonconvex and convex case that take the iteration complexity results for these cases a step forward.
