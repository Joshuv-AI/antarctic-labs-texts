Robust Adaptive Discrete-Time Control Barrier Certificate footnoteinfo
Changrui Liu, Anil Alan, Shengling Shi, Bart De Schutter

Abstract
This work develops a robust adaptive control strategy for discrete-time systems using Control Barrier Functions (CBFs) to ensure safety under parametric model uncertainty and disturbances. A key contribution of this work is establishing a barrier function certificate in discrete time for general online parameter estimation algorithms. This barrier function certificate guarantees positive invariance of the safe set despite disturbances and parametric uncertainty without access to the true system parameters. In addition, real-time implementation and inherent robustness guarantees are provided. Our approach demonstrates that, using the proposed robust adaptive CBF framework, the parameter estimation module can be designed separately from the CBF-based safety filter, simplifying the development of safe adaptive controllers for discrete-time systems. The resulting safety filter guarantees that the system remains within the safe set while adapting to model uncertainties, making it a promising strategy for real-world applications involving discrete-time safety-critical systems.

Remark 2.1
.

Contrary to the existing results on robust DT-CBFs with (unbounded) stochastic disturbances
[

]
,
[

Since knowing

However, controllers designed based on such worst-case safety condition may not respond to dangerous system behaviors as fast as its counterpart that knows the true model, and more conservative inputs are then needed to guarantee safety. Considering that parametric uncertainty is epistemic in nature

3
Robust adaptive safety

In this section, we introduce robust adaptive safety guarantees with general online parameter adaptation laws. More specifically, a robust adaptive CBC is formulated that only relies on an instantaneous parameter estimate and the associated adaptation law. This proposed certificate ensures robust safety against both parametric model mismatch and disturbances with reduced conservatism due to the adaptation mechanism.

3.1
Online parameter estimation

At each time step
t
, consider a parameter estimation module
\mathtt{EST}
that can provide a
polytopic
set estimate
\Theta_{t}\subseteq\Theta
such that
\theta^{\ast}\in\Theta_{t}

\displaystyle e_{\theta,t}:=\hat{\theta}_{t}-\theta^{\ast},

(11a)

\displaystyle\varepsilon_{\theta,t}(p):=\max_{\theta\in\Theta_{t}}\|\theta-\hat{\theta}_{t}\|_{p}.\vskip-5.69046pt

(11b)

The module

Inherent robustness

Inspired by
[
46
]
, we discuss the inherent robustness property of the CBC in (
16
). Specifically, when
x_{t_{0}}
is only safe but not robustly safe (i.e.,
x_{t_{0}}\in\mathcal{S}\setminus\mathcal{S}_{\mathrm{ra},t_{0}}

x_{t_{0}}\notin\mathcal{S}
) for some

due to unexpected perturbations
[
46
]
or poor parameter estimates, inherent robustness ensures that the safe inputs derived from the safety filter (
19
) based on the CBC (
16

Definition 5.1
.

Assume that
\{\mathcal{X}_{t}\}^{\infty}_{t=0}
with
\mathcal{X}_{t}\subseteq\overline{\mathcal{X}}
is sequentially positively invariant (cf. Definition
3.1
) for a general time-varying system
x_{t+1}=h_{t}(x_{t})+w_{t}
for all
w_{t}\in\mathcal{W}

converges to
\{\mathcal{X}_{t}\}^{\infty}_{t=0}
asymptotically on
\overline{\mathcal{X}}
if
\lim_{t\to\infty}\mathrm{dist}_{\mathcal{X}_{t}}(x_{t})=0
for all
x_{0}\in\overline{\mathcal{X}}
.

Following (
15
), we define the corresponding
time-varying
energy functions on
\mathcal{X}
as follows:

V_{t}(x)=\begin{cases}0&\text{if }x\in\mathcal{S}_{\mathrm{ra},t}\\

(25)

It is obvious that

for
x\in\mathcal{X}\setminus\mathcal{S}_{\mathrm{ra},t}

\mathcal{S}_{\mathrm{ra},t}
is sequentially positively invariant (see Appendix

Let Assumption
1

B:\mathcal{X}\to\mathbb{R}

\mathtt{EST}
for

7
Conclusions

In this paper, we have developed a safe control method for discrete-time systems using robust adaptive discrete-time control barrier functions (CBFs), considering both parametric model uncertainty and disturbances. Unlike traditional approaches in continuous-time adaptive safe control design that tightly couple adaptation and control, our framework supports a modular architecture where the parameter learning algorithm operates independently of the safety filter. This separation simplifies safe control design and supports greater flexibility in implementation. In addition, the proposed method provides rigorous guarantees of safety without requiring exact model knowledge, which is particularly valuable for safety-critical applications where online adaptation is necessary. Future research directions include suboptimality analysis of safe control using CBFs and extension to distributed safe control of multi-agent systems.
