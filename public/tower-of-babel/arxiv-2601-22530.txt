Enhancing TableQA through Verifiable Reasoning Trace Reward
Tung Sum Thomas Kwok, Xinyu Wang, Hengzhi He, Xiaofeng Lin, Peng Lu, Liheng Ma, Chunhe Wang, Ying Nian Wu, Lei Ding, Guang Cheng

Abstract
A major challenge in training TableQA agents, compared to standard text- and image-based agents, is that answers cannot be inferred from a static input but must be reasoned through stepwise transformations of the table state, introducing multi-step reasoning complexity and environmental interaction. This leads to a research question: Can explicit feedback on table transformation action improve model reasoning capability? In this work, we introduce RE-Tab , a plug-and-play framework that architecturally enhances trajectory search via lightweight, training-free reward modeling by formulating the problem as a Partially Observable Markov Decision Process. We demonstrate that providing explicit verifiable rewards during State Transition (“What is the best action?”) and Simulative Reasoning (“Am I sure about the output?”) is crucial to steer the agent’s navigation in table states. By enforcing stepwise reasoning with reward feedback in table transformations, RE-Tab achieves state-of-the-art performance in TableQA with almost 25% drop in inference cost. Furthermore, a direct plug-and-play implementation of RE-Tab brings up to 41.77% improvement in QA accuracy and 33.33% drop in test-time inference samples for consistent answer. Consistent improvement pattern across various LLMs and state-of-the-art benchmarks further confirms RE-Tab ’s generalisability. 1 1 1 The repository is available at https://github.com/ThomasK1018/RE_Tab .

Introduction

Tabular data is a prevalent modality for storing and acting on structured information, widely used in healthcare, finance, and marketing
(
44
;
21
)
. Table Question Answering (‘TableQA’) therefore serves as a practical interface between raw records and decision making. Recent Large Language Models (‘LLM’s) have achieved strong TableQA performance by integrating in-context learning
(
5
;
46
;
40
)
, Chain-of-Thought prompting
(
7
;
64
)
, and agentic frameworks
(
62
;
63
)
to support multi-turn table reasoning. A common execution pattern is a state-transition loop

\texttt{Table}\rightarrow\texttt{Action}\rightarrow\texttt{New Table},

which resonates with state transition in world-model reasoning
(
58
;
55
)
, with each intermediate table functioning as an explicit state.

However, under this paradigm, actions are often executed without explicit step-level feedback about their quality. Without such feedback, table agents struggle to reflect on intermediate decisions. They may fail to identify suboptimal actions early, and errors can compound across turns. In the worst case, missing an optimal intermediate state (Figure
1
) leads to continual state exploration and ultimately incorrect answers. Although post-hoc correction methods such as graph-based refinement
(
62
)
and test-time scaling
(
63
)
have been explored, they rely heavily on LLM internal signals and remain fragile in multi-hop TableQA, hence highlighting the importance of explicit reward feedback in tabular reasoning.

Reward modeling is a standard ingredient for guiding world-model reasoning in other modalities
(
1
;
31
;
43
)
, but it does not transfer naturally to tables. Human-feedback rewards
(
35
)
are difficult to scale in tabular settings due to weak preference signals and costly, inconsistent annotations
(
61
)
. While verifiable rewards appear promising, existing formulations remain inadequate for TableQA. First, many require substantial manual engineering which limits scalability. Second, stepwise rewards from other modalities often rely on semantic similarity (e.g., CLIPScore
(
12
)
or cosine similarity
(
45
)
), which fails to respect heterogeneous schemas and structural constraints. In tables, even a single cell error can disrupt row or column distributions and break schema fidelity, leading to unreliable reasoning (Figure
1
). Third, embedding-based similarity require length truncation if input exceeds embedding model limitations
(
69
;
66
)
, which directly destroys tabular structure and causes both semantic and structural information loss. These limitations motivate rewards tailored to tabular structure rather than generic semantic proximity.

Since generic similarity rewards fail to reflect tabular structure, a suitable stepwise reward for TableQA should evaluate intermediate table states with respect to the query itself. This leads to our core question:
“Is the current table sufficient to address the query?”

We argue that sufficiency hinges on two complementary criteria: (1)
Lexical Coverage
: Does the current table contain the crucial information required by the query?, (2)
Precision
: Does the table state remain minimal, retaining only information necessary for computing the answer? and (3)
Structural Integrity
: Does evaluation preserve the full table structure? Motivated by these criteria, we extend
ROUGE

(
23
)
to tabular data, using the Longest Common Subsequence (‘LCS’) component to capture coverage, and unigram-length behavior to quantify precision, thereby formulating
TabROUGE
.

TabROUGE
constitutes the backbone of
RE-Tab
, a lightweight, training-free framework that introduces world-model-style reasoning into tabular agents. First, during
State Transition
,
TabROUGE
provides turn-by-turn feedback for evaluating the quality of each action through its effect on the intermediate table state. Second, through
Simulative Reasoning
, the agent generates multiple candidate trajectories, and
TabROUGE
supports trajectory evaluation and selection before final answer inference. By introducing an explicit, structure-aware reward that is query-grounded and training-free,
RE-Tab
aims to make multi-turn TableQA both more reliable and more efficient. All in all, we make three key contributions:

1.

A novel table-to-query relevance metric.
We introduce
TabROUGE
, a tabular reward for evaluating intermediate table states with respect to the query, together with theoretical analysis of metric robustness (Section
3
);

2.

A plug-and-play, training-free framework for TableQA.
Built on
TabROUGE
,
RE-Tab
augments existing TableQA paradigms with explicit feedback and trajectory selection, improving performance while reducing token generation costs (Section
4
); and

3.

Generalizable empirical validation.
Incorporating
RE-Tab
yields consistent improvements across both open- and closed-source LLMs on multiple state-of-the-art TableQA datasets (Section
4
).

Build Internal Reward Models in Multi-Turn Table Reasoning

3.1
Problem Formulation

Tool-based Table Reasoning State Transitions

We formalize the tool-based table reasoning
(
54
;
15
)
as follows: Each entry consists of a tabular dataset
T
, a natural language query
Q
, and ground truth
\alpha
. Our objective is to produce
\hat{\alpha}
that maximizes
G(\hat{\alpha},\alpha)
where
G
is an evaluation function. In practice, both LLMs and VLMs struggle to reliably attend to entire tables token by token
(
53
)
, making full-table prompting infeasible and cost-intensive. Consequently, agents need to reason over partial snapshots of the full table. This information bottleneck motivates us to model the task as a Partially Observable Markov Decision Process (‘POMDP’)
(
2
)
. The agent observes partial table snapshot
o\in O
from true table state
T
and selects action
a\in A
from a set of predefined atomic table operations
(
54
)
, parameterized by arguments
\theta_{a}
. At each step
t
, the agent executes
a_{t}
by generating
\theta_{a_{t}}
based on observation
o_{t}
, so the environment is transited from
T_{t}
to
T_{t+1}
via transition function
P(T_{t+1}\mid T_{t},a_{t})
, emitting a scalar reward
r_{t}=r(a_{t},T_{t+1},Q)
. The agent then observes a partial snapshot of new state
T_{t+1}
:
o_{t+1}\sim\Omega(\cdot\mid T_{t+1})
, eventually forming a trajectory and respective trajectory reward
R(\tau)
as the
aggregated discounted reward
over all reward
r_{t}

\tau=(T_{0},o_{0},a_{0},r_{0},\ldots,T_{S},o_{S},a_{S}=\hat{\alpha}_{\tau},r_{S}).

Optimal Trajectory Search in Simulative Reasoning

After generating multiple trajectories, the agent chooses and outputs the trajectory that returns highest trajectory reward. We formulate this as a two-phase search process which explores the action space
A
for optimal move in each turn and the possible trajectory space
\mathcal{T}
for optimal trajectory. We express the search problem as:

\displaystyle R(\tau)

\displaystyle=\sum_{l=0}^{S}\gamma_{l}(\underset{a_{l}\in A}{\arg\max}(r(a_{l},T_{l+1},Q)))

\displaystyle\tau^{*}

\displaystyle=\underset{\tau\in\mathcal{T}}{\arg\max}(R(\tau)),\qquad\hat{\alpha}_{\tau^{*}}=a_{S}\in\tau^{*}

where
\gamma_{k}\in[0,1]
is a discount factor.
RE-Tab
(‘Reward-Enhanced Tabular Agent’) proposes two reward models for stepwise reward
\{r_{l}\}_{l=0}^{S}
and the subsequent trajectory reward
R(\tau)
, parameterized by the agent that takes in observation tokens
o_{t}
, and outputs the reward
r_{t}
.

Figure 2

Action-token confidence can be high even when the reasoning trajectory drifts, whereas the state-based, verifiable reward measured by

better reflects whether an intermediate table state contains the right information to answer the query by rewarding query-relevant lexical coverage and penalizing excessive low-relevance table content (low precision). Specifically,
TabROUGE
facilitates evaluation in both the step (action) and trajectory levels, enabling
RE-Tab
’s two-phase trajectory search.

RE-Tab
Reward Modeling

Reward model serves as a feedback mechanism to stabilize the stochastic reasoning trajectory
\tau
. Without an explicit feedback, LLM agent generates brittle reasoning and suffers from degraded accuracy in reasoning drifts (Figure
6
,
7
).

Proposition 3.1

(Reward Model Significance in Multi-turn LLM Interactions)
.

From Section
3.1
, let the tabular reasoning task be defined as a POMDP where
T_{t}\in\mathcal{T}
represents the high-dimensional underlying table state and
o_{t}=\phi(T_{t})
represents the observation via a projection function
\phi:\mathcal{T}\to\mathcal{O}
. This projection induces an information bottleneck
(
49
)
such that the mutual information between the observation and the state is constrained:

I(T_{t};o_{t})\ll H(T_{t})

(1)

The agent’s decision policy
\pi(a_{t}\mid o_{1:t})
must consequently infer task progress under uncertainty. The introduction of turn-wise scalar reward
r_{t}=\mathcal{R}(a_{t},T_{t+1},Q)
as a
compressed table distillation signal
that collapses the high-dimensional and not fully observable table state into a one-dimensional progress metric. This grounding signal compensates for the partially observable
o_{t}
which satisfies:

H(T_{t+1}\mid o_{t+1},r_{t})<H(T_{t+1}\mid o_{t+1})

(2)

We identify a lightweight, training-free method for
RE-Tab
: a
state-based reward
which estimates quality of action result, i.e. the table state after each action.

3.2.1
State-Based Reward Modeling

Action confidence does not guarantee that an agent is making meaningful progress toward answering the query. Therefore, we introduce a state-based reward model that evaluates the semantic quality of intermediate table states. This approach is inspired by verifiable reward signals developed in other modalities
(
52
;
55
)
. However, in structured table reasoning, conventional correctness or cell-level accuracy is insufficient because the key question is not merely “Is this table correct?”, but rather:

1.

Lexical Coverage
: Does the table contain all information necessary to answer the query?

2.

Precision
: Does the table restrict itself to only query-relevant and directly usable information?

3.

Structural Integrity
: Does the evaluation operate on the full table without truncation or structural distortion?

To address these criteria, we propose a reward metric that measures the semantic alignment between the query and each intermediate table state.

Verifiable Query2Table Precision Reward:
TabROUGE

We extend ROUGE-L
(
23
)
to define
TabROUGE
for tabular reasoning (see Section
A.3
for details). After each step
l
, the updated table state
T_{l+1}
is deterministically converted into a textual sequence using an encoding function
Enc(\cdot)
(Appendix
B
). This deterministic encoding ensures reproducibility and incurs negligible computational overhead. The reward is then computed by comparing the encoded table against the query
Q
:

\displaystyle r_{{\textsc{TabROUGE}{}}}(a_{l},T_{l+1},Q)

\displaystyle=\frac{LCS(Q,Enc(T_{l+1}))}{|Enc(T_{l+1})|}.

(3)

The numerator
LCS(Q,Enc(T_{l+1}))
measures the amount of query-relevant content preserved in the current table state, while the denominator
|Enc(T_{l+1})|
reflects the total information contained in the table. This formulation encourages
lexical coverage
(retaining necessary evidence) while penalizing unnecessary content, thereby promoting
precision
. Moreover, because this reward operates without embedding transformation, it avoids size truncation on the full serialized table, hence preserving
structural integrity
.

Importantly, because
TabROUGE
relies on the single longest common subsequence, it is robust to repetition and prevents reward hacking through duplicated rows or columns. The reward therefore favors concise, sufficient table representations rather than inflated states. Finally,
TabROUGE
is conditioned on both the query and the current table state and is not intended for cross-table comparison. Instead, it serves as a trajectory-local progress signal, where relative improvements indicate that a transformation moves the table toward a more sufficient and minimal representation for answering the query.

Proposition 3.2

(Metric Optimality of Table States)
.

Given a query
Q
, a candidate set of intermediate table states
\mathcal{T}
and
TabROUGE
(Equation
3
), then any maximizer

T^{\star}\in\arg\max_{T\in\mathcal{T}}s(T;Q)

corresponds to a “just-right” table state which contains all available query-relevant information while excluding removable redundancy. A maximizer of this score cannot contain removable redundancy: if
\exists T^{\prime}\subset T^{\star}
such that
\Omega(T^{\prime},Q)=\Omega(T^{\star},Q)
(i.e., the sub-state preserves all query-relevant numerator overlap), then:

\mathcal{L}(T^{\prime})<\mathcal{L}(T^{\star})\implies\frac{\Omega(T^{\prime},Q)}{\mathcal{L}(T^{\prime})}>\frac{\Omega(T^{\star},Q)}{\mathcal{L}(T^{\star})}

yields a higher score
s(T^{\prime};Q)>s(T^{\star};Q)
, contradicting the maximality of
T^{\star}
. At the same time, it cannot omit available query-relevant information. If additional content
\Delta T
can be added to form
T^{+}=T^{\star}\cup\Delta T
with overlap gain
\Delta\Omega
and encoding increase
\Delta\mathcal{L}
, the ratio improves as marginal information density exceeds current state’s density:

\frac{\Delta\Omega}{\Delta\mathcal{L}}>s(T^{\star};Q)\implies s(T^{+};Q)>s(T^{\star};Q)

Detailed theoretical support is provided in Appendix
A.3
. Additional sensitivity analysis of using different delimiters for
Enc(T)
is attached in Appendix
D.3
. The overall state-level trajectory reward is

R_{\text{state}}(\tau)=\sum_{l=0}^{S}\gamma_{l}r_{{\textsc{TabROUGE}{}}}(a_{l},T_{l+1},Q),

where
\gamma_{l}
is the stepwise discount factor. This mechanism verifies whether each action meaningfully transforms the table to better facilitate answering the query.

3.3
Two-Phase Implementation of Reward Models

Two-Phase Search

This two-phase, training-free design provides dense and interpretable supervision for strucutured reasoning and complements confidence-based and terminal reward signals in a unified optimization framework. Operationally, the process unfolds as follows:

1.

State Transition
: At each step, the agent explores the action space
A
and selects action using the step-level reward
r(a_{l},T_{l+1},Q)
.

2.

Simulative Reasoning
: Given the trajectory set
\mathcal{T}
, the agent outputs highest-reward trajectory
\tau^{*}
and the corresponding final answer
\hat{\alpha}_{\tau^{*}}
.

\tau^{*}=\arg\max_{\tau\in\mathcal{T}}R(\tau),\qquad\hat{\alpha}_{\tau^{*}}=a_{S}\in\tau^{*}.

Optimization Objective

For a set of sampled trajectories
\mathcal{T}
, the agent aims to maximize the expected reward

J(\mathcal{T})=\mathbf{E}_{\tau\sim\mathcal{T}}\big[R_{\text{state}}(\tau)\big],

(4)

This objective biases the agent toward trajectories that achieve high semantic alignment with the query throughout multi-turn execution.

5
Limitations

Despite improved reasoning depth, several challenges remain:
Global Reward Calibration:
Our metric provides a trajectory-level signal for specific tables but lacks calibration for direct inter-table comparison; while multi-table inputs can be merged, globally unified rewards remain an open challenge.
OOD Generalization:
While
RE-Tab
shows strong zero-shot capabilities, its robustness under extreme distribution shifts requires further validation across diverse industrial schemas.
Semantic Noise Sensitivity:
Current rewards may be influenced by semantically meaningless stop words or formatting artifacts, necessitating future work in denoising and keyword extraction to ensure signals are grounded strictly in reasoning quality.

6
Discussion

In this work, we pioneer reward modeling as a practical mechanism for incorporating world-model reasoning into the tabular domain. By positioning
RE-Tab
as a tabular agent reasoning paradigm, we move beyond static table parsing toward dynamic, robust table understanding. Our findings demonstrate that process-level supervision alone yields substantial gains for proprietary models, even without the immediate integration of reinforcement fine-tuning.

Looking ahead, we position the evolution of
RE-Tab
to develop unified foundation world models that support a seamless pipeline from supervised pre-training to reinforcement fine-tuning, mirroring successful paradigms in language and vision modalities. There is significant potential in extending tabular reward mechanisms to broader tabular challenges, such as prediction, missing value imputation, and complex causal inference
(
40
;
13
)
. To enhance reward precision, we seek to extend our work by decomposing key words and critical reasoning steps from trajectories, allowing neural agents to eventually and consistently surpass the performance of traditional gradient-boosted trees
(
10
)
. By integrating reinforcement learning as a natural extension, future iterations can transition from guided process-supervision to independent policy optimization, enabling agents to navigate complex data environments and distribution shifts with minimal human intervention.

Impact Statement

This paper presents work aimed at advancing the field of Machine Learning by improving the reliability and efficiency of reasoning over structured data. Tabular data is a cornerstone of information storage in critical sectors such as healthcare, finance, and marketing; by enhancing the accuracy and grounding of TableQA agents, this research provides a more robust and dependable interface for data-driven decision-making.

The proposed
RE-Tab
framework contributes to the development of sustainable AI by significantly reducing inference costs and token generation through more efficient state exploration. Furthermore, by introducing verifiable, query-grounded rewards, the framework addresses the “black-box” nature of multi-step reasoning, fostering greater transparency and reducing the risk of compounding errors or hallucinations in automated data analysis. These advancements are essential for deploying trustworthy AI agents in real-world environments where precision and interpretability are paramount.

A.1
How unoptimized LLM agent drifts harm performance?

Proposition A.1

(Variance growth with interaction length)
.

Let

Y_{S}:=\ell(\hat{a}(\tau_{S}),A)

denote a nonnegative loss after
S
interaction steps, where

Y_{S}=0
if and only if
\hat{a}(\tau_{S})=A
.
Assume that each additional step introduces stochastic variability without
systematic corrective bias, i.e.,

\mathbb{E}[Y_{S}\mid Y_{S-1}]=Y_{S-1}.

Then the variance of the loss is non-decreasing:

\mathrm{Var}(Y_{S})\geq\mathrm{Var}(Y_{S-1}).

Proof.

By the law of total variance,

\displaystyle\mathrm{Var}(Y_{S})

\displaystyle=\mathrm{Var}\!\big(\mathbb{E}[Y_{S}\mid Y_{S-1}]\big)+\mathbb{E}\!\big[\mathrm{Var}(Y_{S}\mid Y_{S-1})\big]

\displaystyle=\mathrm{Var}(Y_{S-1})+\mathbb{E}\!\big[\mathrm{Var}(Y_{S}\mid Y_{S-1})\big].

Since conditional variances are nonnegative,

\mathbb{E}[\mathrm{Var}(Y_{S}\mid Y_{S-1})]\geq 0,

which implies

\mathrm{Var}(Y_{S})\geq\mathrm{Var}(Y_{S-1}).

∎

A.2
How does Explicit Reward improve multi-turn LLM conversation performance

1. Global State Distillation and Information Compression

In tool-based TableQA, the observation
o_{t}
is spatially limited to a small window of rows and columns, creating a significant information gap where the agent lacks visibility into the “Global Table State”
T_{t}
. Formally, the state entropy remains high given only the observation,
H(T_{t}\mid o_{t})\gg 0
.
The scalar reward
r_{t}
functions as a
compressed representation
of the entire hidden state. It maps the high-dimensional, unobserved data in
T_{t}\setminus o_{t}
into a single-dimensional metric relative to the query
Q
. By providing
r_{t}
, the environment effectively “telegraphs” the global utility of an operation to the agent. This allows the LLM to make informed decisions about the next action
a_{t+1}
based on global progress rather than being misled by the local, potentially unrepresentative samples found in the snapshot
o_{t}
.

2. Mitigation of Stochastic Drift (
\epsilon
-Accumulation)

The tool-based transition is modeled as
T_{t+1}=\mathcal{P}(T_{t},a_{t},\theta_{a_{t}})+\epsilon_{t}
, where
\epsilon_{t}
represents the “imagination gap” between the LLM’s predicted outcome and the actual tabular transformation. In code-based generation or unsupervised tool-calling, these discrepancies are unobserved, leading to a compounding error
\sum_{l=0}^{S}\epsilon_{l}
.
Without the turn-wise scalar
r_{t}
to ground the agent, the reasoning trajectory
\tau
becomes
brittle
, eventually decoupling from the ground truth. The reward signal acts as a corrective feedback loop, ensuring that the generated parameters
\theta_{a_{t}}
are grounded in the physical state of the dataset.

3. Convergence via Density of Search Signals

Code-based generation often suffers from sparse terminal rewards, whereas our framework utilizes
r_{t}
to create a
dense reward environment
. The trajectory reward
R(\tau)=\sum\gamma_{l}r_{l}
transforms the search into a directed optimization problem.
The scalar
r_{t}
provides a “gradient” for the agent; if an action
a_{t}
fails to maximize the reward, it provides an immediate signal to prune that reasoning path. This significantly reduces the variance in the terminal prediction
\hat{\alpha}
by constraining the trajectory space
\mathcal{T}
to paths with measurable progress, shifting the process from a stochastic linguistic walk to a directed heuristic search.

4. Grounding of Latent State Utility

As noted in
(
53
)
, LLMs fail to attend to all tokens, and many atomic operations (e.g., casting types or re-indexing) result in latent changes to
T_{t+1}
that are invisible in the snapshot
o_{t+1}
.
In an unsupervised setting, the agent suffers from
perceptual aliasing
, where it cannot distinguish between a productive transformation and a redundant one. The scalar reward
r_{t}
resolves this by capturing the latent utility of the operation—validating that the table is “closer” to the goal state even when the visual observation remains static. This calibration ensures that the reasoning tokens
z_{t}
stay aligned with the underlying data structure.

A.3
Detailed theoretical support for
TabROUGE
Optimality

If there exists a substring
\Delta\subset\mathrm{Enc}(T^{\star})
such that

\mathrm{LCS}(Q,\mathrm{Enc}(T^{\star}))=\mathrm{LCS}\!\bigl(Q,\mathrm{Enc}(T^{\star})\setminus\Delta\bigr),

then removing
\Delta
yields a new table
\tilde{T}
satisfying

\displaystyle r_{{\textsc{TabROUGE}{}}{}}(\tilde{T};Q)

\displaystyle=\frac{\mathrm{LCS}(Q,\mathrm{Enc}(T^{\star}))}{|\mathrm{Enc}(T^{\star})|-|\Delta|}

\displaystyle>r_{{\textsc{TabROUGE}{}}{}}(T^{\star};Q),

contradicting the optimality of
T^{\star}
. Hence
T^{\star}
cannot contain removable redundancy. Conversely, if there exists additional content
\Gamma
such that appending it to
T^{\star}
yields a table
T^{+}
with

\mathrm{LCS}(Q,\mathrm{Enc}(T^{+}))=\mathrm{LCS}(Q,\mathrm{Enc}(T^{\star}))+\delta,\quad\delta\geq|\Gamma|,

then

\displaystyle r_{{\textsc{TabROUGE}{}}{}}(T^{+};Q)

\displaystyle=\frac{\mathrm{LCS}(Q,\mathrm{Enc}(T^{\star}))+\delta}{|\mathrm{Enc}(T^{\star})|+|\Gamma|}

\displaystyle\geq r_{{\textsc{TabROUGE}{}}{}}(T^{\star};Q),

with strict inequality when
\delta>|\Gamma|
, again contradicting the optimality of
T^{\star}
. Therefore,
TabROUGE

r_{{\textsc{TabROUGE}{}}{}}(T;Q)
favors intermediate table states that preserve all useful information for answering the query while excluding unnecessary content.

A.4
Proof of monotonically increasing ROUGE score

Proof.

Let
S_{k}=Emb(D_{k})
denote the textual encoding of the table at step
k
, and let
Q
denote the token sequence of the query. We model each tool step as an operator that may (i) remove query-irrelevant content or (ii) derive new query-relevant information under correct and successful execution:

S_{k+1}=\Pi_{k}(S_{k}),

where
\Pi_{k}
either removes tokens independent of
Q
or appends derived tokens that are functionally determined by existing table entries and relevant to
Q
. Now consider the representation length
L_{k}:=|S_{k}|
and overlap
c_{k}:=\mathrm{LCS}(Q,S_{k})
. Define the stepwise increments

\Delta L_{k}:=L_{k+1}-L_{k},\qquad\Delta c_{k}:=c_{k+1}-c_{k}.

Under pruning steps,
\Delta L_{k}<0
and typically
\Delta c_{k}=0
since query-relevant tokens are preserved.
Under derivation steps, both
\Delta L_{k},\Delta c_{k}>0
due to appended tokens and overlapping content with query tokens.

To formalize the likelihood that length increase is accompanied by sufficient overlap gain, let
U_{k}=\{u_{1},\dots,u_{\Delta L_{k}}\}
denote the multiset of tokens newly appended by
\Pi_{k}
when
\Delta L_{k}>0
. Define indicator variables

Z_{i}:=I\{u_{i}\text{ contributes to an LCS match with }Q\},

so that the overlap gain satisfies the lower bound

\Delta c_{k}\;\geq\;\sum_{i=1}^{\Delta L_{k}}Z_{i}

(5)

Since derivation is query-conditioned under correct execution, we assume each appended token is query-relevant with probability at least
p
:

\mathbb{E}[Z_{i}\mid\Delta L_{k},\mathcal{F}_{k}]\geq p,

where
\mathcal{F}_{k}
denotes the interaction history up to step
k
(including the current table state and query) and
\Delta L_{k}
is
\mathcal{F}_{k}
-measurable. Now consider Eq.
5
, by taking conditional expectations on
\Delta L_{k}
and
\mathcal{F}_{k}
, we have

\displaystyle\mathbb{E}[\Delta c_{k}|\Delta L_{k},\mathcal{F}_{k}]

\displaystyle\geq\mathbb{E}\left(\sum_{i=1}^{\Delta L_{k}}Z_{i}\middle|\Delta L_{k},\mathcal{F}_{k}\right)

By linearity of expectation,

\displaystyle\mathbb{E}\left(\sum_{i=1}^{\Delta L_{k}}Z_{i}\middle|\Delta L_{k},\mathcal{F}_{k}\right)

\displaystyle=\sum_{i=1}^{\Delta L_{k}}\mathbb{E}(Z_{i}|\Delta L_{k},\mathcal{F}_{k})

\displaystyle\geq\sum_{i=1}^{\Delta L_{k}}p=p\Delta L_{k}

\displaystyle\mathbb{E}[\Delta c_{k}|\Delta L_{k},\mathcal{F}_{k}]

\displaystyle\geq p\Delta L_{k}

By law of total expectation,

\displaystyle\mathbb{E}[\Delta c_{k}|\Delta L_{k}]

\displaystyle=\mathbb{E}[\mathbb{E}[\Delta c_{k}|\Delta L_{k},\mathcal{F}_{k}]]\geq p\Delta L_{k}

Now, under the assumption of conditional independence between
\{Z_{i}\}
given
\mathcal{F}_{k}
, we have the Hoeffding’s inequality such that for any
\epsilon\in(0,p)
,

\displaystyle\mathbb{E}(\Delta c_{k}|\Delta L_{k})

\displaystyle\geq p\Delta L_{k}

\displaystyle\Pr\left[\sum_{i=1}^{n}Z_{i}-E\left(\sum_{i=1}^{n}Z_{i}\right)\leq-t\right]

\displaystyle\leq\exp\left(-\frac{2t^{2}}{\sum_{i=1}^{n}(1)^{2}}\right)

\displaystyle\text{By choosing }t=\epsilon n,

\displaystyle\Pr\left[\sum_{i=1}^{n}Z_{i}\leq(p-\epsilon)n\right]

\displaystyle\leq\exp\left(-2\epsilon^{2}n\right)

\displaystyle\Pr\left[\sum_{i=1}^{n}Z_{i}\leq(p-\epsilon)\Delta L_{k}\middle|\Delta L_{k}\right]

\displaystyle\leq\exp\left(-2\epsilon^{2}\Delta L_{k}\right)

Consider the extreme events between
\{S_{n}\leq(p-\epsilon)n\}
and
\{\Delta c_{k}\leq(p-\epsilon)n\}
, for
S_{n}\leq\Delta c_{k}
,
\{\Delta c_{k}\leq(p-\epsilon)n\}\subseteq\{S_{n}\leq(p-\epsilon)n\}
given a fixed
(p-\epsilon)n
. Therefore, we have

\displaystyle\Pr\left[\Delta c_{k}\leq(p-\epsilon)\Delta L_{k}\middle|\Delta L_{k}\right]

\displaystyle\leq\Pr\left[\sum_{i=1}^{n}Z_{i}\leq(p-\epsilon)\Delta L_{k}\middle|\Delta L_{k}\right]

\displaystyle\Pr\left[\Delta c_{k}\leq(p-\epsilon)\Delta L_{k}\middle|\Delta L_{k}\right]

\displaystyle\leq\exp\left(-2\epsilon^{2}\Delta L_{k}\right)

Therefore, as long as
p
is not too small, the probability that a derivation step substantially increases length without adding commensurate query-overlap decays exponentially in the number of appended tokens. Combining this with the condition for monotone improvement of the precision-style surrogate

\Delta c_{k}\geq\widetilde{\mathrm{ROUGE\text{-}L}}(Q,S_{k})\cdot\Delta L_{k}\Longleftrightarrow\widetilde{\mathrm{ROUGE\text{-}L}}(Q,S_{k+1})\geq\widetilde{\mathrm{ROUGE\text{-}L}}(Q,S_{k}),

we conclude that, under query-conditioned derivation and typical navigation pruning, the expectation of
\widetilde{\mathrm{ROUGE\text{-}L}}
is a monotonically increasing function as
k
increases.
∎

LLM Drifting

Figure 6
:
Unoptimized tabular LLM agent shows tendency to drift despite having already discovered the correct answer within the intermediate steps, and such drift would lead to the generation of an incorrect answer at final step.

We measure LLM drift via the drifting on the
TabROUGE
, as we align all trajectories to the ending point to measure how each step performs before reaching conclusion. For
x=0
representing the moment the model stops generating, while both lines show an upward trend as they approach termination, we observe that incorporating early stopping leads to correct selection of higher ROUGE stopping points. Moreover, in the second plot, we can see that the model is actually approaching the conclusion in a fair early stage with about 4 steps to achieve over 80% of the work needed to be done, while the rest is less meaningful drifting which does not contribute to the answer accuracy. By eliminating these drifting rounds, we can both improve accuracy and remove the noisy extra tokens that cost additional computational burden.

:
The first plot depicts LLM’s drifting before reaching final conclusion, while the second plot illustrates the LLM is capable of reaching most of the work in the first four steps, while the subsequent drifting does not contribute to the performance significantly.

Further analysis on dataset-wise performance (Table
8
) shows that Tree-of-Tables performs best on WikiTQ and MMQA, which require semantic inference to align latent attributes with the query. These datasets consist largely of small to medium tables, where hierarchical decomposition enables independent resolution of conceptual components. Such decomposition is particularly beneficial for MMQA, where relevant signals are less explicit. In contrast, MMTU contains large tables focused on exact lookups over long and irregular expressions. For Tree-of-Tables, early semantic decomposition conversely introduces biases, such as normalizing intentionally irregular values by misinterpreting the term as a typographical error, hence degrading exact retrieval. This is further supported by Figure
9

RE-Tab
mitigates these complementary weaknesses, producing more consistent performance across datasets and task types.

(
