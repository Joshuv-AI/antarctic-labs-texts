Resilience for Regular Path Queries: Towards a Complexity Classification
Antoine Amarilli, Wolfgang Gatterbauer, Neha Makhija, Mikaël Monet, Martín Muñoz

Abstract
. The resilience problem for a query and an input set or bag database is to compute the minimum number of facts to remove from the database to make the query false. In this paper, we study how to compute the resilience of Regular Path Queries (RPQs) over graph databases. Our goal is to characterize the regular languages L L for which it is tractable to compute the resilience of the existentially-quantified RPQ built from L L . We show that computing the resilience in this sense is tractable (even in combined complexity) for all RPQs defined from so-called local languages . By contrast, we show hardness in data complexity for RPQs defined from the following language classes (after reducing the languages to eliminate redundant words): all finite languages featuring a word containing a repeated letter, and all languages featuring a specific kind of counterexample to being local (which we call four-legged languages). The latter include in particular all languages that are not star-free . Our results also imply a dichotomy on all languages with a so-called neutral letter . We last show tractability for some classes of non-local languages, namely the so-called bipartite chain languages and one-dangling languages , and highlight some remaining obstacles towards a full dichotomy.

1.
Introduction

This paper studies the
resilience problem
, which asks, for a
Boolean query
Q
and a given database
D
(in set or bag semantics),
for a minimum-size set of facts to remove from
D
so
that
Q
is not satisfied. In bag semantics, facts additionally
carry multiplicities, which we view as deletion costs.
1
1

1

If
Q
does not hold on
D
, then resilience is zero. If
Q
holds
on
D
and on all subinstances of
D
, then resilience is infinite.

The notion of resilience is motivated by the need to identify how
“robust” a query answer is, especially when the facts of the input
database may be incorrect. Specifically, resilience quantifies how many
facts of
D
must be removed before
Q
no longer holds, so that higher
resilience values mean that
Q
is less sensitive to facts of
D
being
removed.
Resilience is also closely connected to database causality and
responsibility measures
(
Meliou et al., 2010a
;
Freire et al., 2015
;
Meliou et al., 2010b
)
,
and more generally to reverse data-management tasks
(
Meliou et al., 2011
)
, including
view-update and deletion-propagation problems
(
Buneman et al., 2002
)
with controlled
source side effects
(
Dayal and Bernstein, 1982
)
or view side effects
(
Kimelfeld, 2012
)
.
It is also related to finding smallest witnesses or
small database examples for explaining wrong queries
(
Hu and Sintos, 2024
;
Miao et al., 2019
)
.
See
(
Makhija and Gatterbauer, 2025
)
for a recent unified perspective on several such
explanation tasks as minimum contrastive or abductive explanations.

The resilience problem was introduced for Boolean conjunctive queries (CQs)
and has mostly been studied for such queries

(
Freire et al., 2015
;
Freire et al., 2020b
;
Bodirsky et al., 2024
;
Makhija and Gatterbauer, 2023
)
.
The key challenge in this line of work is to understand its
data complexity
,
i.e., its complexity for a fixed query
Q
as a function of the input database
D
.
Whenever query evaluation for
Q
is in polynomial data complexity, the associated
resilience decision problem is in NP.
2
2

2

Here and throughout,
NP-hardness and NP-completeness statements refer to the threshold decision problem: given
D
and an integer
k
, decide whether the resilience is at most
k
.
Our tractability results compute the resilience value itself along with a
witness.
The relation between the decision, value, and witness variants is discussed formally in
Section

2
.

However, the exact complexity landscape is subtle:
resilience is NP-hard for some simple queries, yet tractable for other nontrivial ones

(
Freire et al., 2020b
;
Makhija and Gatterbauer, 2023
)
.
This motivates the goal of

characterizing the queries for which resilience can be tractably computed
,
ideally via a dichotomy that separates the PTIME cases from the NP-complete ones.
For self-join-free CQs, this boundary is well-understood

(
Freire et al., 2015
)
. For general CQs with self-joins,
it remains elusive.
For self-join-free CQs, dichotomies are known under set semantics
(
Freire et al., 2015
)
and bag semantics
(
Makhija and Gatterbauer, 2023
)
,
with different tractability boundaries.
Makhija and Gatterbauer
(
Makhija and Gatterbauer, 2023
)
give a unified ILP formulation, establish cases where its LP relaxation is exact, and develop automated IJP-based hardness certificates.
A complete classification for arbitrary CQs with self-joins remains open.
We note, however, that for bag semantics,
recent work
(
Bodirsky and Semanišinová, 2026
)

establishes
a PTIME/NP-complete dichotomy for UCQs over a single binary relation.
This does not establish the corresponding dichotomy under set semantics.

In this paper, we study resilience from a different perspective: we focus
on graph databases (i.e., databases on an arity-two signature), and on
queries defined by regular languages, namely Boolean Regular Path Queries
(Boolean RPQs), with no constants and with existentially quantified
endpoints. In other words, the query asks whether the database contains a
walk whose edge labels form a word of the regular language, and
resilience asks how many database facts must be removed so that no such
walk remains.

The relationship between RPQs and CQs is subtle.
On finite languages, Boolean RPQs correspond to unions of path-shaped CQs, i.e., to a restricted class of UCQs over binary relations.
Hence, our results for finite languages can be read as results about path-like UCQs.
RPQs and UCQs over binary relations are incomparable in expressive power: RPQs can express unbounded reachability (via the Kleene star),
whereas UCQs can impose branching and cyclic join patterns not expressible by a single RPQ.
Finite-language RPQs correspond to unions of directed-path CQs.

To our knowledge, the only other work which studies resilience for RPQs
is the recent paper of Bodirsky et al.
(
Bodirsky et al., 2024
;
Bodirsky et al., 2025
)
, in
which the authors use CSP techniques. In particular, they obtain
a dichotomy on the
resilience problem for Boolean RPQs (and also for the broader class of
so-called
two-way RPQs
, aka 2RPQs). However, their lower bounds
do not apply to databases in set semantics. In addition, their dichotomy
criterion, while decidable, does not give an intuitive
language-theoretic characterization of the tractable cases. We discuss
this in more detail at the end of
Section

2
.

Our study of resilience for RPQs is motivated by the above stated database applications,
but it is also motivated by connections to classical network flow
problems. Consider for instance the classical MinCut problem of finding
the minimum-cost cut in a flow network,
which can be solved in polynomial time,
and where we can allow
multiple sources and sinks without loss of generality.
It is easily seen
that MinCut is
equivalent to the resilience problem in bag semantics for the RPQ

ax^{*}b
on the alphabet
\{a,b,x\}
, with
a
-facts of the database
corresponding to sources,
b
-facts to sinks, and
x
-facts to edges of
the network. Hence, the resilience problem for RPQs corresponds to a
generalization of MinCut, where the edges of the flow network are labeled
and we must cut edges to ensure that no walk in a specific language
remains. In the other direction, for many RPQs, we can devise tractable
algorithms for resilience by reducing to a MinCut problem on a suitably
constructed flow network. However, resilience is NP-hard for some RPQs,
e.g., the finite RPQ
aa

(
Freire et al., 2020b
)
, so these
methods do not always apply. Our results aim at determining which RPQs
have tractable resilience (in particular via such flow-based methods),
and which RPQs have intractable resilience.

Contributions and outline.

After giving preliminary definitions and stating the problem in

Section

2
, we start in
Section

3
by giving our main tractability
result (
Theorem

3.15
): resilience is tractable for RPQs defined from so-called
local
languages

(
Pin, 2025
;
Sakarovitch, 2009
)
. Those languages are intuitively
those that are defined by specifying the possible initial labels of a path,
the possible final
labels of a path, and the consecutive pairs of labels that are allowed.
Examples of local languages are
ax^{*}c
or
ab|ad|cd
.
We then show that, for RPQs defined with a local language
L
, we can compute
resilience by reducing to the MinCut problem via a
natural product construction. The argument applies to queries both in set and bag semantics,
and it yields an algorithm which is also tractable in combined
complexity.
Using the recent almost-linear-time deterministic algorithm for minimum-cost
flow
(
van den Brand et al., 2023
, Theorem 1.1)
, our algorithm
runs in time

(|A|\times|\Sigma|\times|D|)^{1+o(1)}
where
A
is an automaton
representing
L
, where
\Sigma
is the signature,
and where
D
is the input
database;
in other words, the algorithm runs in time

O((|A|\times|\Sigma|\times|D|)^{1+\epsilon})

for all
\epsilon>0
.

We then turn to intractability results in

Sections

4
,
5
and
6
.
In all these results, we assume that we focus on the
infix-free

sublanguage where redundant words have been eliminated, e.g., resilience for
abbc|bb
and
bb
is the same
because the corresponding (existentially-quantified) Boolean RPQs are
equivalent.
Note that the infix-free sublanguage of a regular language is easily
seen to also be a regular language.

We define in
Section

4
the
notion of a
hardness gadget
for a language
L
, namely, a specific
database to be used as a building block in a reduction.
Our gadgets adapt to RPQs the independent-join-path approach introduced in
(
Freire et al., 2020b
)

and developed into a semantic hardness criterion in
(
Makhija and Gatterbauer, 2023
)
.
Our endpoint restriction ensures non-leaking composition, while condensation to an odd path supports the reduction from vertex cover.
When an RPQ
Q
has a hardness gadget
\Gamma
,
we can reduce the minimum vertex cover problem on
an undirected graph
G
to a resilience computation (in set semantics)
for
Q
on a
database built using
\Gamma
, by replacing the edges of
G
by a copy
of
\Gamma
. We illustrate in
Section

4
how our
gadgets
can be used to show hardness for two specific RPQs:
axb|cxd

(
Proposition

4.13
), and
aa
(
Proposition

4.1
).

We then generalize
these two hardness results in turn to apply to a
broader class of languages. First, in
Section

5
, we introduce the notion of
a
four-legged language
, as a language featuring a specific kind of
counterexample to being local. More precisely,
the local languages of
Section

3
have the following
known equivalent characterization
(
Sakarovitch, 2009
)
: for
any letter
x
and words
\alpha,\beta,\gamma,\delta
, if a language
L

contains the words

\alpha x\beta
and
\gamma x\delta
but does not contain the
“cross-product” word
\alpha x\delta
, then
L
is not local. A four-legged
language is a non-local language that features a counterexample of this form in
which all the words
\alpha,\beta,\gamma,\delta
are required to be non-empty.
This covers, for instance,
axb|cxd
,
but not
ab|bc
.
We show (
Theorem

5.3
) that resilience is intractable for any
four-legged language. This result implies hardness for many languages: it
covers all
non-star-free
languages (
Lemma

5.6
), a well-known class of infinite
regular languages; and, along with the tractability of local languages, it implies
a dichotomy for languages having a

neutral letter
(
Proposition

5.8
).

Second, in
Section

6
, we show that resilience is hard for any finite
infix-free
language containing a word with a repeated letter (
Theorem

6.1
).
This generalizes the case of
aa
, and shows that self-joins always imply hardness
in
the following sense: finite RPQs (those equivalent to UCQs), once made
infix-free, have intractable
resilience as soon as one of their constituent CQs features a self-join.
This contrasts with the setting of CQs, where characterizing the tractable
queries with self-joins is still open
(
Freire et al., 2020a
)
.

Note that our two hardness results (
Theorem

5.3
and

Theorem

6.1
) are incomparable:
languages with a repeated letter are non-local, but they are not all
four-legged (e.g.,
aa
); conversely, some four-legged
languages have no words with a repeated letter (e.g.,
axb|cxd
). Assuming finiteness
in
Theorem

6.1
is also crucial, as
ax^{*}b
features
words with repeated letters and still enjoys tractable resilience. The proof of

Theorem

6.1
is our main technical achievement: it
relies on
Theorem

5.3
and uses different
gadgets
depending on which additional words the language contains.

Section

7
then explores how our results do not classify all RPQs. We
mostly focus
on finite RPQs: the remaining open cases are then the RPQs which have no words with
repeated letters, are not local, but are not four-legged. We introduce the class
of chain languages (e.g.,
axb|byc
) to cover some of these RPQs,
and show tractability (and reducibility to MinCut) assuming
a bipartiteness condition. We then introduce the class of one-dangling languages
(e.g.,
abc|be
), for which we show tractability (via a more elaborate
reducibility to MinCut).
We finish the section by showing that some other unclassified RPQs are intractable.
We conclude the paper in
Section

8
.

.

Regular Path Queries.

From a language
L
over
\Sigma
we now define a query over graph
databases that tests the existence of walks labeled by words of
L
.
Given a database
D
, a
walk

in
D
is a (possibly empty) sequence of consecutive
edges

v_{1}\xrightarrow{a_{1}}v_{2}
,

v_{2}\xrightarrow{a_{2}}v_{3}
,
\ldots
,
v_{k}\xrightarrow{a_{k}}v_{k+1}

in
D
. Note that the
a_{i}
and
v_{i}
are not
necessarily pairwise distinct.
We say that the walk is
labeled
by the word
\alpha=a_{1}\cdots a_{k}
, and call it an
\alpha
-walk
. We also say that the walk

contains
a word
\beta\in\Sigma^{*}
if
\beta

is an infix of
\alpha
.
An
L
-walk
in

is then an

\alpha
-walk for some
\alpha\in L
.
We define the
Boolean query
Q_{L}
as:
Q_{L}(D)=1

L
-walk in
D
. In particular, if
\epsilon\in L

then
Q_{L}(D)=1
on every
database
D
(including
D=\emptyset
).
A
regular path query
(RPQ)
is then a Boolean query of the form

Q_{L}
for
L
a regular language.
Note that, in all of the present paper, we evaluate RPQs with walk semantics
(i.e., arbitrary paths with repetitions), as opposed to other works such
as
(
Martens and Trautner, 2019
)
which evaluate them with simple path or trail
semantics: we leave open the question of studying resilience for RPQs in simple
path or trail semantics.

Observe that
Q_{L}
does not change if we remove from
L
all
words
\beta
such that some strict infix
\alpha
of
\beta
is
also in
L
: indeed if

contains a
\beta
-walk then it also contains
an
\alpha
-walk.
Formally, the
infix-free sublanguage
of

is
\mathtt{IF}(L)\coloneq\{\alpha\in L\mid\text{no strict infix
of }\alpha\text{ is in }L\}
. We then have that
Q_{L}

and

denote the same
query. The infix-free sublanguage
of
L
can also
be called the
factor-free sublanguage of
L
in

(
Barceló et al., 2019
)
, and is called the
reduced sublanguage
in
our earlier conference
paper
(
Amarilli et al., 2025a
)
. It is easy to show that if
L
is regular then so is
\mathtt{IF}(L)
. We say that
L

is

if

L=\mathtt{IF}(L)
; this is also called being an

(
Ito et al., 1991
)
.

Bag semantics.

We also consider the resilience problems on
bag graph databases
,
as opposed to
set graph databases
which are the databases
defined so far. A
bag (graph) database

consists of a
database
D
together with a
multiplicity function

\mathtt{mult}:D\to\mathbb{N}_{>0}
; it can equivalently be seen as a multiset of
facts.
In the input, the multiplicities are expressed as integers written in binary.
A Boolean query
Q
is satisfied by a bag database
(D,\mathtt{mult})
iff
D

satisfies
Q
, i.e., the multiplicities of facts are not seen by queries.
A contingency set of
D
for
Q
is
then again a subset
D^{\prime}\subseteq D
such that
D\setminus D^{\prime}\not\models Q
, and
the
resilience of
Q
on
D
is:

\mathtt{RES}_{\mathrm{bag}}(Q,D)\coloneq\min_{\begin{subarray}{c}D^{\prime}\subseteq D\\
\text{s.t. }D\setminus D^{\prime}\not\models Q\end{subarray}}\sum_{e\in D^{\prime}}\mathtt{mult}(e)
, i.e.,
fact multiplicities represent costs.

Networks and cuts.

Our resilience algorithms work by reducing to the problem of finding a

minimum cut of a flow network

(
Cormen et al., 2009
)
.
Recall that
a
flow network

consists of a directed graph
\mathcal{N}=(V,t_{\text{source}},t_{\text{target}},E,c)

with

V
being the vertices,
t_{\text{source}},t_{\text{target}}\in V
being special vertices
called the
source
and the
target
respectively,

E\subseteq V\times V
, and
c:E\to\mathbb{R}_{+}\cup\{+\infty\}
giving the
capacity
of each
edge. For
E^{\prime}\subseteq E
, we define the
cost
of
E^{\prime}
as
c(E^{\prime})\coloneq\sum_{e\in E^{\prime}}c(e)
,
and denote
\mathcal{N}\setminus E^{\prime}
as the network in which all edges from
E^{\prime}
are removed.
A
cut
is a set of edges

E^{\prime}\subseteq E
such that there is no directed path from
t_{\text{source}}
to

t_{\text{target}}

in
\mathcal{N}\setminus E^{\prime}
. The
min-cut problem
, written MinCut, takes as input a
flow network and returns the minimum cost of a cut.
From the
max-flow min-cut theorem

(
Ford and Fulkerson, 1956
)
and Menger’s
theorem
(
Menger, 1927
)
, we know that the min-cut problem
can be solved in PTIME.
More precisely,
practical algorithms can run in

O(|V|^{2}\sqrt{|E|})

(
Ahuja et al., 1997
)
,
and recent theoretical algorithms
run in

|\mathcal{N}|^{1+o(1)}

(
van den Brand et al., 2023
)
, (i.e., in
O(|\mathcal{N}|^{1+\epsilon})
for all
\epsilon>0
) where
|\mathcal{N}|\coloneq|V|+|E|
.

For all our upper bounds, we work in the RAM
model on words of logarithmic size and where arithmetic operations take
constant time
(
Aho et al., 1974
)
. In particular, memory cells can only represent integers of
value polynomial in the input length; this implies that the fact
multiplicities for bag databases are assumed to be bounded by a polynomial and that
capacities in all flow networks that we will construct will be polynomial as
well.

Problem statement.

In this paper, we study the
resilience problem
for
queries
Q_{L}
defined by languages
L
; most of our results are for
regular languages.
The
resilience problem
for
L
, written

\textsc{Res}_{\mathrm{set}}(L)
, is
the following:
given as input a
database
D
and
k\in\mathbb{N}
, decide if
\mathtt{RES}_{\mathrm{set}}(Q_{L},D)\leq k
.
The problem
\textsc{Res}_{\mathrm{bag}}(L)
in bag semantics is defined analogously.
Note that
\textsc{Res}_{\mathrm{set}}(L)

easily reduces to

\textsc{Res}_{\mathrm{bag}}(L)
by giving multiplicity of 1 to each fact;
however, in the setting of CQs, some conjunctive queries
Q_{0}
are known for which

\textsc{Res}_{\mathrm{set}}(Q_{0})
is in PTIME, but
\textsc{Res}_{\mathrm{bag}}(Q_{0})
is NP-complete

(
Makhija and Gatterbauer, 2023
, Table 1)
(even when the multiplicities of the input
bag database are written in unary).

We also note that the definition given here corresponds to a
decision
problem
of determining whether the resilience is no greater than the value
k
.
However, thanks to self-reducibility
(
Goldreich, 2010
, Section 3.3)
, the
function
problem
of computing a witness contingency set reduces in polynomial time to
this decision problem: see also
(
Bodirsky et al., 2025
, Remark 8.4)
for a
self-contained argument. The same holds for the problem of computing the
value of resilience, i.e., the cardinality of such a witness; this can be
performed via self-reducibility, or simply by a binary search over the possible
values. Conversely, the decision problem immediately reduces to any of these two problems.

Our definitions correspond to the
data complexity

perspective, where we have one computational problem per
language
L

and where the complexity is measured as a function
of
|D|
only. We mostly focus on data complexity, but most of our upper bounds also
apply in
combined complexity
, i.e., when both the database
D
and an
automaton
A
representing
L

are given as input.

It is easy to see that, for any regular language
L
, the problem

\textsc{Res}_{\mathrm{bag}}(L)
, hence
\textsc{Res}_{\mathrm{set}}(L)
, is in NP. Indeed, given a bag
database
D
, it suffices to guess a subdatabase
D^{\prime}\subseteq D
,
and verify in PTIME that
\sum_{f\in D^{\prime}}\mathtt{mult}(f)
is small enough
and that
D^{\prime}
is a contingency set, i.e.,
D\setminus D^{\prime}\not\models Q
. The latter point, i.e., the nonexistence of an

L
-walk in
D\setminus D^{\prime}
, can easily be checked in PTIME by a
product construction followed by a reachability test (see, e.g.,

(
Mendelzon and Wood, 1995
, Lemma 3.1)
).

However, the NP upper bound is not always tight:
there are languages
L
(e.g.,

L=a|b
)
such that
\textsc{Res}_{\mathrm{bag}}(L)
is in PTIME. The goal of our
paper is to characterize the languages
L
for which

\textsc{Res}_{\mathrm{set}}(L)
and
\textsc{Res}_{\mathrm{bag}}(L)
are in PTIME, and give efficient
algorithms for them.

Connection to VCSPs.

The recent work
of Bodirsky et al.
(
Bodirsky et al., 2024
)
uses earlier results on Valued
Constraint Satisfaction Problems (VCSP) to obtain the following dichotomy on
\textsc{Res}_{\mathrm{bag}}
:

Theorem 2.2

(
(
Bodirsky et al., 2024
)
, see also

(
Bodirsky et al., 2025
, Theorem 8.15)
)
.

Let
L
be a regular language. The problem
\textsc{Res}_{\mathrm{bag}}(L)
is either in PTIME or
it is NP-complete.

We point out that this result can be extended to so-called
two-way RPQs
, and to the case where some relations are declared
exogenous
(i.e., they cannot be part of a contingency set).
Hence, as discussed in the introduction,
Theorem

2.2
gives a complete dichotomy across all regular languages. However, it also has four important
shortcomings:

1

The
VCSP approach gives no explicit characterization of the class
L
of tractable languages,
or efficient bounds on the complexity of testing whether a given
L
is PTIME or
not: the criterion in
(
Bodirsky et al., 2024
)
, using
(
Kolmogorov, 2019
)
,
can be computationally checked but takes time exponential in a representation of the so-called

dual
of
L
.

2

In
tractable cases, the VCSP approach does not give good bounds on the
degree of the polynomial (unlike, e.g., explicit reductions
to MinCut).
We remark that the first two difficulties
also occur in works studying other problems where VCSP
implies a general dichotomy but without explicit characterizations or tight
bounds, for instance in
(
Hirai and Mizutani, 2021
)
.

3

The
VCSP approach does not shed light on the

combined complexity
, i.e., it does not identify cases that are
tractable when both the query and
the database are given as input.

4

The
VCSP approach inherently only applies
to bag semantics and not to set semantics, so there is no known analogous
dichotomy for
\textsc{Res}_{\mathrm{set}}
.
Our results improve on some of these shortcomings.
Specifically, all our intractability results already apply to the
\textsc{Res}_{\mathrm{set}}

problem,
most of our upper bound results apply to combined
complexity (when the query is given as an automaton along with the database), and
our tractability results
feature a polynomial complexity with a low degree
(and in fact up to
n^{o(1)}
factors the data complexity is always linear, except
for one result,
Proposition

7.7
, where it is quadratic).
However, unlike

(
Bodirsky et al., 2024
)
, our results do not establish a full dichotomy.

We now start the presentation of our results on the resilience

3.1.
Local Languages

We define here local languages and show some useful properties. Intuitively, a

Definition 3.1

A language

and every infix of

Definition 3.2

A DFA is

(

A language

if and only if there exists a local DFA that

Next we give a second known equivalent language-theoretic characterization of local

Definition 3.5

(Letter-Cartesian)
.

A language
L
is
letter-Cartesian

if the following implication holds: for every letter
x\in\Sigma

and words
\alpha,\beta,\gamma,\delta\in\Sigma^{*}

\alpha x\beta\in L
and
\gamma x\delta\in L

\alpha x\delta\in L

Note that, by exchanging the roles of
\alpha,\beta
and
\gamma,\delta

\alpha x\beta\in L
and
\gamma x\delta\in L
then also
\gamma x\beta\in L

x\in\Sigma

the words of

containing an

between what can appear left of an

and what can appear right of an

Formally, for a letter
x\in\Sigma

L_{x}=\{\alpha\in\Sigma^{*}\mid\exists\beta\in\Sigma^{*}\text{ s.t. }\alpha x\beta\in L\}
and
R_{x}=\{\beta\in\Sigma^{*}\mid\exists\alpha\in\Sigma^{*}\text{ s.t. }\alpha x\beta\in L\}
. Then, if
L
is letter-Cartesian, we have that
L\setminus\{\epsilon\}=\bigcup_{x\in\Sigma}L_{x}xR_{x}
.

It is known that letter-Cartesian languages are precisely the local languages:

Proposition 3.7
.

A language is local if, and only if,
it is letter-Cartesian.

This result has been claimed in
(
Sakarovitch, 2009
, Chp. II, Ex. 1.8,
(d))
without proof (as an exercise). For completeness, and
to provide more intuition on local languages to the reader,
we provide a proof here. One direction is easy to show: local languages are
always letter-Cartesian.

Claim 3.8
.

If
L
is local then it is letter-Cartesian.

Proof.

Let
A
be a local DFA recognizing
L
. Let
x\in\Sigma
, and let

\alpha,\beta,\gamma,\delta\in\Sigma^{*}
such that
\alpha x\beta\in L
and

\gamma x\delta\in L
, and let us show that
\alpha x\delta
is in
L
as
well. Because
L
is local, the state
q
that is reached in
A
after reading

\alpha x
in the accepting run of
\alpha x\beta
is the same state that is
reached after reading
\gamma x
in the accepting run of
\gamma x\delta
.
We can thus compose a run from the initial state to
q
reading
\alpha x
,
with the run from
q
to some final state reading
\delta
, to form an
accepting run for
\alpha x\delta
. This concludes the proof.
∎

We now prove the converse, thus establishing
Proposition

3.7

Claim 3.9
.

If
L
is letter-Cartesian then it is local.

To establish this claim,
we use a construction from
(

We define the
local overapproximation
of a

Definition 3.10
.

Let

We start by defining the following:

•

The set

of letters that can start words of

i.e., the letters

•

The set
\Sigma_{\mathrm{end}}
of letters that can end words of

\alpha\in\Sigma^{*}

•

The set

of pairs of letters that can occur

such
that there exist
\alpha,\beta\in\Sigma^{*}
such that
\alpha ab\beta\in L

The

is the DFA

defined in the following way. We have an initial state

, which is final iff
\epsilon\in L
. For every
a\in\Sigma

have a state

. Then,
for every

we add an

to

and
for every

b

q_{a}
to
q_{b}
.

The local overapproximation

is local by definition, and the following is
immediate:

Claim 3.11
.

We have
\mathcal{L}(A)\supseteq L
.

We now claim that, for letter-Cartesian languages, the local overapproximation
is in fact equal to the original language, namely:

Claim 3.12
.

If
L
is letter-Cartesian, then
\mathcal{L}(A)=L
.

This immediately implies
Claim

3.9
: if
L
is letter-Cartesian,
then it is local, because

is equal to
\mathcal{L}(A)
for

3.12

Proof of
Claim

3.12
.

We must show that if
L
is letter-Cartesian then
\mathcal{L}(A)=L
.
By

3.11
, it suffices to
show that
\mathcal{L}(A)\subseteq L
.

Take
\alpha

in
\mathcal{L}(A)
, and let us show that it is in

. If
\alpha
is the empty word then
it is clear by construction that
\alpha
is also in
L

So assume
\alpha=a_{1}\cdots a_{m}
with

By construction of

is accepted witnesses that:

•

\alpha^{\prime\prime}\in\Sigma^{*}
such

•

a_{m}\in\Sigma_{\mathrm{end}}

\alpha^{\prime\prime\prime}\in\Sigma^{*}

For each

If

Hence, in the sequel, we assume that

Testing if a language is local.

We can use the local overapproximation
(

)
to show that it is PTIME to determine whether a language is local.
Indeed, the previous results imply:

Claim 3.13
.

Let
L
be a language, and
A
its local overapproximation. Then we have
\mathcal{L}(A)=L
if and only if
L
is local.

Proof.

If
L
is local, then
L
is letter-Cartesian by
Proposition

3.7

so by

Claim

3.12
we have

\mathcal{L}(A)=L
. Conversely, if
\mathcal{L}(A)=L
then
L
is recognized by a local
DFA, so it is local.
∎

This result gives us a way to check whether the language recognized by an
automaton is local. First, in the case of DFA, we can check this tractably:

Proposition 3.14

(Locality testing for DFAs)
.

Given a DFA
A
, it is in PTIME to determine if
\mathcal{L}(A)
is local.

Proof.

Let
L\coloneq\mathcal{L}(A)
. Build the local overapproximation
A^{\prime}
of

using

Definition

, which is clearly in PTIME.
By
Claim

3.13
,
it suffices to check whether
L=\mathcal{L}(A^{\prime})
.
It is well-known that testing equivalence of two DFAs is PTIME, so this concludes the proof.
∎

Note that
Proposition

3.14
is about testing if the language
L=\mathcal{L}(A)

recognized by

is local (i.e., some local DFA for
L
exists); it is not
about testing if the specific DFA

is a local DFA (which is easy to do in linear
time simply by following the definition). It is also not about the complexity of
testing whether the

of
\mathcal{L}(A)
is local, which can
be the case even if
\mathcal{L}(A)
is not local. We can do this by building an automaton

representing

from a DFA

representing

, but the
straightforward construction for

entails an exponential blowup
(
(

). We leave the precise complexity
of this task open.

By contrast, if the input language

is given as
an NFA instead of a DFA, then testing if
L
is local is
PSPACE-complete
(
Amarilli et al., 2025c
)
. This holds even under the assumption that
L
is infix-free, so that the same lower bound
applies to the problem of testing whether the infix-free
sublanguage of an input
NFA is local.

Proof.

We first prove the first sentence of the claim.

\epsilon

\epsilon

We let

4.
Hardness Techniques and First Results

In this section, we move on to cases where computing resilience is intractable.
From now on we only study languages
that are infix-free, because showing hardness for an infix-free language
L
is
sufficient to imply the same for any language
L^{\prime}
such that
\mathtt{IF}(L^{\prime})=L
.

We start the section by showing the NP-hardness of
\textsc{Res}_{\mathrm{set}}(aa)
, by an explicit
reduction from the minimum vertex cover problem.
We then generalize this reduction and
define the notion of
(hardness) gadgets
as databases that can be used
to encode graphs and reduce from minimum vertex cover.
We show that whenever a language
L
admits a gadget
then
\textsc{Res}_{\mathrm{set}}(L)
is
NP-hard.
We finally illustrate these techniques to show the
hardness of resilience for the specific language

axb|cxd
.

The notion of gadgets introduced in this section will be used in the next two
sections to show the hardness of entire language families. Specifically, we will
generalize in
Section

5
the hardness of
\textsc{Res}_{\mathrm{set}}(axb|cxd)
to that
of the so-called
four-legged languages
; and generalize in
Section

6
the hardness
of
\textsc{Res}_{\mathrm{set}}(aa)
to that of all finite languages featuring a word with a
repeated letter.

4.1.
Hardness of
aa

We first present the hardness proof for the language
aa
.
This result is already known from the setting of CQs
(
Freire et al., 2020b
, Prop. 10)
,
by a direct reduction from 3-SAT.
We give a self-contained proof by reduction from the minimum vertex cover (VC) problem,
inspired by the edge-gadget framework of
(
Makhija and Gatterbauer, 2023
)
.
This proof serves as a first illustration of the reductions used throughout the section:
we encode a graph given as input to VC by replacing each edge with a fixed database gadget,
so that hitting
all query matches (i.e., selecting a set
H
of edges such that every match of the query contains an edge of
H
) corresponds to choosing a vertex cover of the original graph.

The query
Q_{aa}
asks whether the input database contains a directed walk of length two whose
two facts are labeled by
a
. Thus, a contingency set for
Q_{aa}
is a set of
a
-facts that hits all
directed
aa
-walks. At a high level, the reduction starts from an undirected VC instance, chooses
an arbitrary orientation of its edges, and replaces each directed edge by a copy of a fixed

(oriented) database gadget
.
The gadget has
two distinguished endpoint facts
, one for each
endpoint of the encoded VC edge.
All gadget copies incident to the same VC vertex share the
corresponding endpoint fact.

The gadget need not be symmetric, since any orientation of the VC instance suffices. What matters
is composability: identifying copies at shared endpoint facts must not create unintended directed

aa
-walks across different copies, which would be spurious matches. In the terminology
of
(
Makhija and Gatterbauer, 2023
)
, the
composition of gadgets
must be
non-leaking
. In our setting,
this is enforced syntactically by the choice of endpoints: endpoint elements never occur as heads of
internal facts, so a directed walk cannot leave the internal part of one gadget copy and enter another.

Inside one completed copy of the gadget, the graph whose vertices are facts and whose edges are

aa
-matches is an
odd path
between the two endpoint facts. After identifying copies according
to the VC instance, the graph of
aa
-matches is an odd subdivision of the original undirected graph.
Hitting
all
aa
-matches is therefore the same as finding a vertex cover of this odd
subdivision; and, as we will recall in

Proposition

4.2
,
the minimum vertex cover of an odd
subdivision determines the minimum vertex cover of the original graph.

To summarize, in the language of
independent join
paths

(
Makhija and Gatterbauer, 2023
)
,
the endpoint facts provide the two alternatives for covering
edges (the semantic
OR-property
), while the syntactic endpoint condition guarantees non-leaking
composition (the
composability
property). Thus, the gadgets below can be seen as directed-walk analogues of independent join
paths. Let us now turn to the concrete case of the query
aa

before
we present more general hardness gadgets in the next subsection.

Proposition 4.1
.

\textsc{Res}_{\mathrm{set}}(aa)
is NP-hard.

In other words, given a
directed graph
G
and integer
k\in\mathbb{N}
, it is NP-hard to decide if we can remove
k

edges of
G
such that
G
no longer contains any walk of length 2.
We show
Proposition

4.1
by reducing from the
minimum vertex cover problem
.
Recall that a
vertex cover
of an undirected graph
G=(V,E)
is a
subset of vertices
V^{\prime}\subseteq V
such that every edge of
E
is incident to a
vertex of
V^{\prime}
, i.e., for each
e\in E
, we have
e\cap V^{\prime}\neq\emptyset
.
The
vertex cover number

of
G
is the minimum cardinality of a vertex
cover of
G
.
Given an undirected graph
G
and
an integer
k\in\mathbb{N}
,
the
minimum vertex cover problem
asks if the vertex cover number of
G
is at most
k
.
It is an NP-complete problem
(
Karp, 1972
, Main Theorem)
.

Before showing the reduction, we show that the vertex cover number
of an undirected graph
G
can be computed from the vertex
cover number of any odd-length subdivision of
G
.
Formally, for
\ell\in\mathbb{N}
,
\ell\geq 1
, the
\ell
-subdivision
of
G

is the undirected graph
G^{\prime}

(unique up to isomorphism) that we obtain
by replacing each edge of
G
by a path of length
\ell
(i.e., with

\ell-1

fresh internal vertices, that are disjoint across edges).
We claim:

Proposition 4.2

(Hardness of vertex cover on subdivisions)
.

Let
\ell\in\mathbb{N}
be an odd integer. Then for any undirected graph
G=(V,E)
, letting
G^{\prime}
be the

\ell
-subdivision of
G
, then the vertex cover number of
G^{\prime}
is

k+m(\ell-1)/2
,
where
k
is the vertex cover number of
G
and
m
is the
number of edges of
G
.

Proof.

It suffices to show that
G
has a vertex cover of cardinality at most
k

if and only if
G^{\prime}
has a vertex cover of cardinality at most
k+m(\ell-1)/2
.

We first show the “only if” direction. Let
G=(V,E)
and let
C
be a vertex
cover of
V
of cardinality at most
k
. We pick a subset
C^{\prime}
of the vertices of
G^{\prime}

by taking the vertices of
C
and picking vertices of the subdivisions in the
following way. For each edge
\{u,v\}
of
G
, letting
u-v_{1}-\cdots v_{\ell-1}-v
be the corresponding path in
G^{\prime}
,
we distinguish three cases:

•

If
u\in C
and
v\notin C
then we add to
C^{\prime}
the vertices
v_{2},v_{4},\ldots,v_{\ell-1}

•

If
v\in C
and
u\notin C
then we add to
C^{\prime}
the vertices
v_{1},v_{3},\ldots,v_{\ell-2}
.

•

If
u\in C
and
v\in C
we do one of the above (it does not matter

The case where
u\notin C
and
v\notin C
is impossible because
C
is a
vertex cover of
G
.

Now, for each edge of
G
we select
(\ell-1)/2
vertices in
C^{\prime}
, so in total
C^{\prime}

has the prescribed cardinality. To see that it is a vertex cover, note that
all edges of
G^{\prime}
occur in a path of the form

, and the vertices of
C^{\prime}

selected above form a vertex cover of the edges of such paths. Hence,
C^{\prime}
is
a vertex cover of
G^{\prime}
.

We next show the second direction, which is somewhat more challenging. Given a
vertex cover
C^{\prime}
of
G^{\prime}
of cardinality at most
k+m(\ell-1)/2
, we will
first modify
C^{\prime}
without increasing its cardinality to guarantee the
following property (*): for each edge
(u,v)\in E
, considering the
corresponding path

of

, then there are
precisely
(\ell-1)/2
of the intermediate vertices of the path that are
in
C^{\prime}
, formally
|C^{\prime}\cap\{v_{1},\ldots,v_{\ell-1}\}|=(\ell-1)/2
.

For this, we process each path

, and consider each vertex
v_{1},\ldots,v_{\ell-1}
in order. If for

we have that
v_{i}\in C^{\prime}
and the
previous vertex
v_{i-1}
was already in
C^{\prime}
, then we remove
v_{i}
from
C^{\prime}

and add instead
v_{i+1}
to
C^{\prime}
. Note that the cardinality of
C^{\prime}
does not
increase, and may strictly decrease if
v_{i+1}
was already in
C^{\prime}
. At the
end of this process, given that we start with a vertex cover
C^{\prime}
of
G^{\prime}
, we see
that
C^{\prime}
contains precisely
(\ell-1)/2
vertices of the path: if

then we keep the
v_{i}
’s for which

is odd, and otherwise the
v_{i}
’s
for which

We have processed

to still be a vertex cover, and have cardinality

m(\ell-1)/2+k^{\prime}
for some

, with

. Let us define

. It has cardinality at most

, and we claim that

is a
vertex cover. Indeed, assuming by contradiction that some edge
(u,v)
of
G

is not covered by

, so that

and
v\notin C
,
and considering the path
u=v_{0}-v_{1}-\cdots v_{\ell-1}-v_{\ell}=v
, we know that
C^{\prime}

(after the processing of the previous paragraph) was a vertex cover of

,
but if

and

then it cannot be the case that precisely

(\ell-1)/2
of the

’s are in

and cover all the edges of the path, a

We have thus shown both directions of the claimed equivalence, which concludes
the proof.
∎

To show the hardness of resilience for other languages than

Gadgets are used as building blocks to reduce from

We first define

as databases with two domain elements to

as pre-gadgets
whose hypergraph of matches

and

Definition 4.5

(1)

•

Let us observe the following property about the encoding, which is the reason why
we require that in-elements and out-elements never occur as the head of

Claim 4.6

(Walks in encodings)
.

Let
G
be a directed graph, let
\Gamma=(D,t_{\textup{in}},t_{\textup{out}},a)
be a pre-gadget, and let
\Xi
be the encoding of

with
\Gamma
.
Then
no walk of
\Xi
passes through two internal elements
belonging to different copies of
D
.

Proof.

Consider a walk in
\Xi
and consider the first element used in the walk which
is an internal element of a copy
D_{e}
of

. The only elements shared
between
D_{e}
and the rest of
\Xi
are the images of the elements
t_{\textup{in}}
and

t_{\textup{out}}
, i.e., elements of the form

for

a vertex of

. However,
by our requirement on

,
there is no fact in

having

or

as head. Hence, the

and

can never reach an internal element of another copy.
∎

For now, our definition of pre-gadgets is independent of the query. Let us now
formalize what we require from query matches in gadgets, in order to reduce
from the vertex cover problem. We do this by introducing the
hypergraph of

,
generalizing the graph of matches from the proof of

along with a

4.3.
Condensed Hypergraph of Matches

Let
L
be a language and
D
a database.
A
match

(or witness)
of
L
on
D
is a set of edges
corresponding to an

L
-walk (as defined in
Section

2
): formally, each
L
-walk
e_{1},\ldots,e_{m}
defines a match which is the set

\{e_{1},\ldots,e_{m}\}
, noting that several
L
-walks may define the same
match. Then:

Definition 4.7

(Hypergraph of matches)
.

The
hypergraph of matches
of
D
and
L
, denoted
\mathcal{H}_{L,D}
,
is the hypergraph whose nodes are the
facts of
D
and whose hyperedges are the matches of
L
on
D
.

Recall that a
hitting set
(also called
hypergraph
transversal

(
Gottlob, 2004
)
)
of a hypergraph
\mathcal{H}=(V,E)
is
a subset
V^{\prime}\subseteq V
such that
V^{\prime}\cap e\neq\emptyset
for
every
e\in E
.
Thus, hitting sets are a generalization of vertex covers to hypergraphs.
It is clear from the definition of resilience that
\mathtt{RES}_{\mathrm{set}}(Q_{L},D)

is equal to the minimum size of a hitting set of
the hypergraph of matches
\mathcal{H}_{L,D}
. We now introduce two
rewriting rules, called the
condensation rules
, that can be applied to any hypergraph
\mathcal{H}=(V,E)
to simplify it
without affecting the minimum size of hitting sets.
For
v\in V
, write
E(v)=\{e\in E\mid v\in e\}
.
The condensation rules are:

Edge-domination.:

If there are
e,e^{\prime}\in E
with
e\neq e^{\prime}
and
e\subseteq e^{\prime}
,
we can remove
e^{\prime}
to obtain
\mathcal{H}^{\prime}=(V,E\setminus\{e^{\prime}\})
. Intuitively, hitting sets must intersect
e
so they
automatically intersect
e^{\prime}
.

Node-domination.:

If there are
v,v^{\prime}\in V
with
v\neq v^{\prime}
such that

E(v)\subseteq E(v^{\prime})
,
we can remove
v
to obtain
\mathcal{H}^{\prime}=(V\setminus\{v\},\{e\setminus\{v\}\mid e\in E\})
. Intuitively, we can
always replace
v
by
v^{\prime}

in hitting sets.

We say that
\mathcal{H}^{\prime}
is a
condensed hypergraph
of

\mathcal{H}
if
\mathcal{H}^{\prime}
can be obtained from
\mathcal{H}
by
applying some sequence of condensation rules
(note that we do
not
require that
\mathcal{H}^{\prime}
cannot be further simplified
using the rules).
It can be remarked that the condensation rules are
confluent
in the sense
that we always get isomorphic hypergraphs if we apply them to an input
hypergraph until it is
no longer possible, no matter the order in which we apply them:
see
(
Amarilli et al., 2025b
)
. However, we will not need confluence for our purposes in the present paper.
One can easily see that the rules preserve the minimum size of a hitting set:

Claim 4.8

(Condensation preserves minimum size of hitting sets)
.

Let
\mathcal{H}^{\prime}
be
a condensed hypergraph of
\mathcal{H}
.
Then the minimum size of a hitting set of
\mathcal{H}
and
\mathcal{H}^{\prime}
are the same.

Proof.

We show the claim by induction on the length of the sequence of applications
of the condensation rules: the
base case, corresponding to the empty sequence, is trivial.

For the induction
case, let us first assume that
\mathcal{H}^{\prime}
is obtained from
\mathcal{H}=(V,E)
by applying
the edge-domination rule. We then immediately see
that any
V^{\prime}\subseteq V
is a hitting set of

\mathcal{H}
iff it is a hitting set of
\mathcal{H}^{\prime}
, so the minimal size of a
hitting set in
\mathcal{H}
and
\mathcal{H}^{\prime}
is the same.

Second, let us assume that
\mathcal{H}^{\prime}=(V^{\prime},E^{\prime})
is obtained from
\mathcal{H}=(V,E)
by
applying the node-domination rule on two vertices
v
and
v^{\prime}
with
E(v)\subseteq E(v^{\prime})
.
Write
V^{\prime}=V\setminus\{v\}
and
E^{\prime}=\{e\setminus\{v\}\mid e\in E\}
.
We show both directions of the claim. First,
any hitting set of
\mathcal{H}^{\prime}
is also a hitting set of

\mathcal{H}
, so the minimum size of a hitting set of
\mathcal{H}
is at most the
minimum
size of a hitting set of
\mathcal{H}^{\prime}
. Second, let us consider
a hitting set
S^{\prime}
of
\mathcal{H}
. If

v\notin S^{\prime}
then
S^{\prime}
is a hitting set of
\mathcal{H}^{\prime}
. Otherwise, if
v\in S^{\prime}
, then
(S^{\prime}\setminus\{v\})\cup\{v^{\prime}\}
is a
hitting set of
\mathcal{H}^{\prime}
of cardinality at most
|S^{\prime}|
. In both cases

\mathcal{H}^{\prime}
has a hitting set of cardinality at most
|S^{\prime}|
, so that the
minimum size of a hitting set of
\mathcal{H}^{\prime}
is at most the minimum size of a
hitting set of of
\mathcal{H}
. Hence, the equality is proven, which concludes
the induction step and finishes the proof.
∎

By
Claim

4.8
, we know that
\mathtt{RES}_{\mathrm{set}}(Q_{L},D)
is equal to
the minimum size of a hitting set of any condensed hypergraph of
\mathcal{H}_{L,D}
, so we can always apply condensation rules in hardness proofs.

We prove

5.
Hardness of Four-Legged Languages

In the previous section, we have presented
hardness gadgets,
and
shown the hardness of resilience
for the two specific languages
aa

and

axb|cxd
.
In this section we generalize the latter result
to a subclass of the
infix-free non-local languages, called the
four-legged languages
:
these
languages intuitively feature a specific kind of counterexample to locality.
We show that every four-legged language admits a gadget, so that resilience for such
languages is always NP-hard by
Proposition

4.11
.
We give two consequences of this result: it implies that resilience is hard for all
infix-free regular languages that are
non-star-free
; and it also
implies a dichotomy on resilience for languages featuring a

neutral letter
.

5.1.
Four-Legged Languages

Recall the notion of local languages (
Definition

3.1
) from
Section

3
,
which hinges on recognizability
by certain automata
(namely, local DFAs, see
Definition

3.2
), and which was equivalent to the notion of being
letter-Cartesian (
Proposition

3.7
).

If a language
L
is not letter-Cartesian, by definition there are

x\in\Sigma
and
\alpha,\beta,\gamma,\delta\in\Sigma^{*}
such that

\alpha x\beta\in L
and
\gamma x\delta\in L
but
\alpha x\delta\notin L
.
We then define the
four-legged languages
as those infix-free languages that
feature such a violation
in which none of the words
\alpha
,
\beta
,
\gamma
, and
\delta
is empty.
Formally:

Definition 5.1

(Four-legged)
.

A language
L
is
four-legged
if it is infix-free and
has a letter

x\in\Sigma
(the
body
) and four non-empty words

\alpha,\beta,\gamma,\delta\in\Sigma^{+}
(the
legs
) with

\alpha x\beta\in L
and
\gamma x\delta\in L
but
\alpha x\delta\notin L
.

Example 5.2
.

The languages
axb|cxd
(from
Proposition

4.13
) and
axb|cxd|cxb
are non-local and
four-legged. The languages
aa
(from
Proposition

4.1
) and

ab|bc

are non-local but
not four-legged.

Note that four-legged languages are never local, because they are
not letter-Cartesian. The main result of this section is that
\textsc{Res}_{\mathrm{set}}(L)
is always NP-hard when
L
is four-legged;
formally:

Theorem 5.3

(Hardness of four-legged languages)
.

If
L
is four-legged then

\textsc{Res}_{\mathrm{set}}(L)
is NP-hard.

We prove
Theorem

5.3
in the remainder of
Section

5.1
.
To this end, we first show an intermediate lemma: for
languages that are four-legged, we can assume without loss of
generality that the legs are
stable
, i.e., no infix of
\alpha x\delta

is in
L
:

Definition 5.4
.

Let
L
be a four-legged language, and let
x\in\Sigma
be a body and let

\alpha,\beta,\gamma,\delta\in\Sigma^{+}
be legs that witness that
L
is four-legged, i.e.,
\alpha x\beta\in L

and
\gamma x\delta\in L
but
\alpha x\delta\notin L
. We say that the
legs
\alpha,\beta,\gamma,\delta
are
stable
if, in addition, there is
no infix of
\alpha x\delta
which is in
L
.

Lemma 5.5
.

Any infix-free language which is four-legged with body
x\in\Sigma
also has
stable legs with body
x
.

Proof.

Let
L
be an infix-free language which is four-legged, and let
x\in\Sigma

be a body and
\alpha^{\prime},\beta^{\prime},\gamma^{\prime},\delta^{\prime}\in\Sigma^{+}
be legs that
witness it, i.e.,
\alpha^{\prime}x\beta^{\prime}\in L
and
\gamma^{\prime}x\delta^{\prime}\in L
but

\eta^{\prime}\coloneq\alpha^{\prime}x\delta^{\prime}\notin L
.

If
\alpha^{\prime},\beta^{\prime},\gamma^{\prime},\delta^{\prime}
are already stable (i.e., no
infix of
\eta^{\prime}
is in
L
) then we are done.
Otherwise, as
\eta^{\prime}\notin L
, it means that there is a strict
infix
\eta
of
\eta^{\prime}
that is in
L
. We know that
\eta
must have a non-trivial
intersection with
\alpha^{\prime}
, as otherwise
\eta\in L
would be a strict infix of

\gamma^{\prime}x\delta^{\prime}\in L
, contradicting the fact that
L
is infix-free.
Similarly,
\eta
has a non-trivial intersection with
\delta^{\prime}
, as otherwise

\eta\in L
would be a strict infix of
\alpha^{\prime}x\beta^{\prime}\in L
.
So let us write
\alpha^{\prime}=\alpha_{2}\alpha_{1}
and
\delta^{\prime}=\delta_{1}\delta_{2}
, with
\alpha_{1}
and

\delta_{1}
being non-empty, so that
\eta=\alpha_{1}x\delta_{1}
is a strict infix of

\alpha^{\prime}x\delta^{\prime}
that is in
L
. Note that
\alpha_{2}
and
\delta_{2}
cannot
both be empty, as otherwise we have
\eta=\eta^{\prime}
but we assumed that
\eta
is a
strict infix of
\eta^{\prime}
.

We distinguish two cases:

•

We have
\delta_{2}\neq\epsilon
. Then we claim that

\alpha\coloneq\gamma^{\prime}
,
\beta\coloneq\delta^{\prime}
,
\gamma\coloneq\alpha_{1}

and
\delta\coloneq\delta_{1}
are stable legs. Indeed, observe
first that none of
\alpha,\beta,\gamma,\delta
is empty.
Moreover we have
\alpha x\beta=\gamma^{\prime}x\delta^{\prime}\in L

and
\gamma x\delta=\alpha_{1}x\delta_{1}\in L
. Last, no
infix of
\alpha x\delta=\gamma^{\prime}x\delta_{1}
can be in
L

because
\gamma^{\prime}x\delta_{1}\delta_{2}=\gamma^{\prime}x\delta^{\prime}
is
in
L
and
\delta_{2}\neq\epsilon
so any infix of
\alpha x\delta
is a strict infix of a word of
L
; but
L
is
infix-free so no strict infix of a word of
L
is a word of
L
,
hence no infix of
\alpha x\delta
is a word of
L
.

•

We have
\alpha_{2}\neq\epsilon
. Then we do the
symmetric choice of taking
\alpha\coloneq\alpha_{1},\beta\coloneq\delta_{1}
,
\gamma\coloneq\alpha^{\prime}
, and
\delta\coloneq\beta^{\prime}
and
claim that they are stable legs. Instead, none of
\alpha,\beta,\gamma,\delta
is empty. Further,
\alpha x\beta=\alpha_{1}x\delta_{1}
and
\gamma x\delta=\alpha^{\prime}x\beta^{\prime}

are in

Hence, in either case, we can define stable legs for

5.2.
Implications of Hardness for Four-Legged Languages

Next, we spell out two consequences of
Theorem

5.3
. The first one
concerns
non-star-free languages
, the second concerns languages with a

neutral letter
.

Hardness for non-star-free languages.

We say that a regular language
L
is

star-free
if there exists a
k>0
such that, for every
\rho,\sigma,\tau\in\Sigma^{*}
, for every
m\geq k
, we have
\rho\sigma^{k}\tau\in L

iff
\rho\sigma^{m}\tau\in L
. Star-free languages
have many equivalent characterizations (see, e.g.,
(
Pin, 2025
, Chapter VI)
).
Further, if a
language
L
is star-free then so is
\mathtt{IF}(L)
(see
). We can show
that star-freeness of the infix-free sublanguage is a necessary condition
to enjoy tractable resilience, because non-star-free infix-free regular languages are four-legged:

Lemma 5.6

(Four-leggedness of non-star-free languages)
.

Let
L
be a regular language which is infix-free and non-star-free.
Then
L
is four-legged.

Proof.

Let
A
be a DFA which recognizes
L
, and
let
k>0
be greater than the number of states of
A
.
From the fact that
L
is not star-free, applying the definition to this
choice of
k
, we obtain

\rho,\sigma,\tau\in\Sigma^{*}
and
m\geq k
such that exactly one of
\rho\sigma^{k}\tau

and
\rho\sigma^{m}\tau

is in the language.
In particular this implies that
\sigma\neq\epsilon
; let us
write
\sigma=x\sigma^{\prime}
.

As
k
is greater than the number of states
of
A
, by the pigeonhole principle, there must be
0\leq i<j\leq k
such that the partial runs of
\rho\sigma^{i}
and
\rho\sigma^{j}
finish at
the same state when read by
A
. Let

\omega\coloneq j-i
. We know that we have
\rho\sigma^{k}\tau\in L
iff
\rho\sigma^{k+\omega}\tau\in L
, because
exchanging the prefixes
\rho\sigma^{i}
and
\rho\sigma^{j}
does not change the state that we reach.
Iterating the argument, we get the following fact, dubbed (*): for any
p\geq 0
we have
\rho\sigma^{k}\tau\in L
iff
\rho\sigma^{k+p\omega}\tau\in L
. For similar
reasons, we get the fact dubbed (**): for any
p\geq 0
we have

\rho\sigma^{m}\tau\in L
iff
\rho\sigma^{m+p\omega}\tau\in L
.

Let
(\phi,\psi)=(k,m)
if
\rho\sigma^{k}\tau\in L
and
\rho\sigma^{m}\tau\notin L
, and

(\phi,\psi)=(m,k)
if it is the opposite.
Recall that
m,k>0
so

\phi>0
and
\psi>0
.
Further, by (*) and (**) we know the
following fact, dubbed (
\dagger
): we have
\rho\sigma^{\phi+p\omega}\tau\in L
for all
p\geq 0
, and
\rho\sigma^{\psi+p\omega}\tau\notin L
for all
p\geq 0
.
Let
p
be large
enough so that
\phi+p\omega-1>\psi
. Now let us take:

•

\alpha=\rho\sigma^{2\omega-1}
,

•

\beta=\sigma^{\prime}\sigma^{\phi}\tau
,

•

\gamma=\rho\sigma^{\phi+p\omega-1-\psi}
and

•

\delta=\sigma^{\prime}\sigma^{\psi}\tau
.

Note that all of
\alpha,\beta,\gamma,\delta
are
non-empty because they all contain
\sigma\neq\epsilon
at a power which is greater than
0. We claim that they witness that
L
is four-legged with body
x
. Indeed:

•

\alpha x\beta=\rho\sigma^{2\omega-1}x\sigma^{\prime}\sigma^{\phi}\tau=\rho\sigma^{2\omega+\phi}\tau

•

\gamma x\delta=\rho\sigma^{\phi+p\omega-1-\psi}x\sigma^{\prime}\sigma^{\psi}\tau=\rho\sigma^{\phi+p\omega}\tau

•

\alpha x\delta=\rho\sigma^{2\omega-1}x\sigma^{\prime}\sigma^{\psi}\tau=\rho\sigma^{2\omega+\psi}\tau
.

So by (
\dagger
) we have that:

•

\alpha x\beta\in L
because
\rho\sigma^{\phi}\tau\in L

•

\gamma x\delta\in L
because
\rho\sigma^{\phi}\tau\in L

•

\alpha x\delta\notin L
because
\rho\sigma^{\psi}\tau\notin L

This establishes that
L
is four-legged. As it is infix-free, we can conclude by

Theorem

5.3
.
∎

Using
Theorem

5.3
, we deduce:

Corollary 5.7

(Hardness of non-star-free languages)
.

Let
L
be a regular language. If
\mathtt{IF}(L)
is non-star-free, then
\textsc{Res}_{\mathrm{set}}(L)
is NP-hard.

Dichotomy for languages with a neutral letter.

A second consequence of
Theorem

5.3
concerns languages
L
with a

neutral
letter, i.e.,
a letter
e\in\Sigma
such that inserting or deleting
e
anywhere
does not change the membership of words
to
L
.
Formally,
e
is neutral for
L
if for every
\alpha,\beta\in\Sigma^{*}
we have

\alpha\beta\in L
iff
\alpha e\beta\in L
.
(Note that the existence of a neutral letter for
L
does not mean that the
infix-free sublanguage
\mathtt{IF}(L)
also has a neutral letter, and in fact it is easy to
observe that non-empty
infix-free languages can never have a neutral letter.)
In formal language theory, one often
assumes the existence of a neutral letter as a technical assumption on
languages
(
Kouckỳ et al., 2005
;
Barrington et al., 2005
)
.
Under this assumption, we can show:

Proposition 5.8

(Dichotomy for languages with neutral letters)
.

Let
L
be a language with a neutral letter.
If the language
\mathtt{IF}(L)
is local then
\textsc{Res}_{\mathrm{bag}}(L)
is PTIME,
otherwise
\textsc{Res}_{\mathrm{set}}(L)

is NP-hard.

Note that we can read this result as implying that, in the presence of a neutral letter, there
are not many tractable cases left. Indeed, intuitively, when considering a language

L
with neutral letter whose infix-free sublanguage is local, then membership
to
L
must be guided only by the first and last non-neutral letters and the set
of non-neutral letters that occur in the word.

We prove
Proposition

5.8
in the remainder of
Section

5.2
.
To prove this result, we first show that, for languages featuring a neutral letter, whenever the
infix-free language is non-local then it must either be four-legged or contain a
word with a repeated letter, specifically a word of the form
aa
for
a\in\Sigma
:

Lemma 5.9
.

Let
L
be a language with a neutral letter such that
\mathtt{IF}(L)
is not
local. Then one of the following two cases holds (possibly both):

•

the language
\mathtt{IF}(L)
is four-legged;

•

there is
x\in\Sigma
such that
xx\in\mathtt{IF}(L)
.

To prove this lemma, let us prove the following intermediate result:

Claim 5.10
.

Let
L
be a language with a neutral letter
e
and let

L^{\prime}=\mathtt{IF}(L)
. Then for any non-empty words
\theta,\eta\in\Sigma^{+}
, if
\theta\eta\in L^{\prime}
then
\theta e\eta\in L^{\prime}
.

Proof.

We have
\theta\eta\in L^{\prime}
so
\theta\eta\in L
, and
e
is
neutral for
L
so we have
\theta e\eta\in L
. Let us
proceed by contradiction and assume that
\theta e\eta\notin L^{\prime}
. This means that there is a strict infix
\tau
of
\theta e\eta
which is in
L
.
We first claim that
\tau
must include the
e
. Indeed, if it
does not, then there are two cases:

•

\tau
is an infix of
\theta
. Then it is a strict
infix of
\theta\eta\in L^{\prime}
, which contradicts the fact
that
L^{\prime}
is infix-free, so this case is impossible.

•

\tau
is an infix of
\eta
. This is impossible
for the same reason as the previous case.

Now, we know that
\tau
is a strict infix of
\theta e\eta

which includes the
e
. Let
\tau^{\prime}
be obtained from
\tau
by
removing
e
. We have
\tau^{\prime}\in L
because
\tau\in L

and
e
is neutral for
L
. What is more, it is easily seen
that
\tau^{\prime}
is an infix of
\theta\eta
, and it is a strict
infix because
\tau
includes the
e
so from
|\tau|<|\theta e\eta|
(because
\tau
is a strict infix) we deduce
|\tau^{\prime}|=|\tau|-1<|\theta e\eta|-1=|\theta\eta|
. So
\tau^{\prime}\in L
is a strict infix of
\theta\eta\in L^{\prime}
, which
contradicts the assumption that
L^{\prime}
is infix-free.
∎

We can now prove
Lemma

5.9
:

Proof of
Lemma

5.9
.

Let
L^{\prime}=\mathtt{IF}(L)
and
e\in\Sigma
a neutral letter of
L
. By

Proposition

3.7
,
L^{\prime}
is not letter-Cartesian, so there is
x\in\Sigma
and

\alpha^{\prime},\beta^{\prime},\gamma^{\prime},\delta^{\prime}\in\Sigma^{*}
such that
\alpha^{\prime}x\beta^{\prime}\in L^{\prime}
and
\gamma^{\prime}x\delta^{\prime}\in L^{\prime}
and
\alpha^{\prime}x\delta^{\prime}\notin L^{\prime}
.

Now, because
L^{\prime}
is infix-free, it is easy to check
that the following
claim, dubbed (
\star
), must hold:

(
\star
)

\text{we have~}\alpha^{\prime}\beta^{\prime}\neq\epsilon\text{~and~}\gamma^{\prime}\delta^{\prime}\neq\epsilon\text{~and~}\alpha^{\prime}\gamma^{\prime}\neq\epsilon\text{~and~}\beta^{\prime}\delta^{\prime}\neq\epsilon.

Indeed:

•

If
\alpha^{\prime}\beta^{\prime}=\epsilon
then
\alpha^{\prime}x\beta^{\prime}\in L^{\prime}

is equal to
x
which is an infix of
\gamma^{\prime}x\delta^{\prime}\in L^{\prime}
, so by infix-freeness it must be the case that
\gamma^{\prime}\delta^{\prime}=\epsilon
, but now
x=\alpha^{\prime}x\delta^{\prime}=x
and we
assumed
x=\alpha^{\prime}x\delta^{\prime}\notin L^{\prime}
,
which is a contradiction.

•

If
\gamma^{\prime}\delta^{\prime}=\epsilon
, the reasoning is similar:
in this case
\gamma^{\prime}x\delta^{\prime}
is equal to
x
, which is an
infix of
\alpha^{\prime}x\beta^{\prime}
, so by infix-freeness we must have

\alpha^{\prime}\beta^{\prime}=\epsilon
, but then
x=\alpha^{\prime}x\beta^{\prime}\in L^{\prime}
and
x=\alpha^{\prime}x\delta^{\prime}\notin L^{\prime}
is a contradiction.

Thus, we have established (
\star
).

We now start proving the statement of the lemma, namely, that either
L^{\prime}

is four-legged or that
L^{\prime}
contains
xx
.
Let us first show
that (call this
\dagger
) if both
\alpha^{\prime}
and
\delta^{\prime}
are empty then
the
statement of the lemma holds.
Indeed, in that case we have
x\beta^{\prime}\in L^{\prime}
and
\gamma^{\prime}x\in L^{\prime}
. By (
\star
) (first two points) we have that
\beta^{\prime}
and
\gamma^{\prime}
are
both non-empty.
By
Claim

5.10
we deduce from
x\beta^{\prime}\in L^{\prime}
that
xe\beta^{\prime}\in L^{\prime}
,
and
we deduce from
\gamma^{\prime}x\in L^{\prime}
that
\gamma^{\prime}ex\in L^{\prime}
.
Now, take
e
as a candidate choice of body, and
\alpha=x
,
\beta=\beta^{\prime}
,
\gamma=\gamma^{\prime}
and
\delta=x
, as a candidate choice of legs: all of these are non-empty.
We have
\alpha e\beta\in L^{\prime}
and
\gamma e\delta\in L^{\prime}
. So,
considering the word
\alpha e\delta=xex
, there are two
possibilities:
either
xex\notin L^{\prime}
or
xex\in L^{\prime}
. In the first case,
we conclude with our choice of body and legs that
L^{\prime}
is four-legged.
In the second case,
we have
xx\in L
because
e
is neutral for
L
. Further, we have
xx\in L^{\prime}

because the strict infixes of
xx
are the empty word and
x
which are both
strict infixes of the word
x\beta^{\prime}\in L^{\prime}
:
as
L^{\prime}
is
infix-free we conclude that
xx\in L^{\prime}
.

The same reasoning shows that (call this
\dagger^{\prime}
) if both
\beta^{\prime}
and
\gamma^{\prime}
are empty then
the statement of the lemma holds.
Indeed, in this case we have
\alpha^{\prime}x\in L^{\prime}
and
x\delta^{\prime}\in L^{\prime}
, and we
have
\alpha^{\prime}
and
\delta^{\prime}
both non-empty by (
\star
) (first two points). Applying

Claim

5.10
to each gives us that
\alpha^{\prime}ex\in L^{\prime}
and
xe\delta^{\prime}\in L^{\prime}
, and again we conclude that
L^{\prime}
is four-legged or that
xex\in L^{\prime}

from which we show
xx\in L^{\prime}
in the same way.

We have ruled out the case of
\alpha^{\prime}
and
\delta^{\prime}
being both empty, and of

\beta^{\prime}
and
\gamma^{\prime}
being both empty.
Combining with
(\star)
, one gets that either
\alpha^{\prime}
and

\gamma^{\prime}
are both non-empty, or
\beta^{\prime}
and
\delta^{\prime}
are both non-empty.
Indeed, assume that the first term in the disjunction is false, i.e., that it
is not the case that
\alpha^{\prime}
and
\gamma^{\prime}
are both non-empty.
If we have
\alpha^{\prime}=\epsilon
, then
\delta^{\prime}
is non-empty from (
\dagger
), and
\beta^{\prime}
is non-empty by
(\star)
(first point).
If we have
\gamma^{\prime}=\epsilon
, then
\beta^{\prime}
is non-empty by (
\dagger^{\prime}
), and
\delta^{\prime}
is non-empty by
(\star)
(second

We finish the proof by distinguishing these two cases:

•

Assume that
\alpha^{\prime}\neq\epsilon
and
\gamma^{\prime}\neq\epsilon
.
We have
\alpha^{\prime}x\beta^{\prime}\in L^{\prime}
so by
Claim

5.10
we have

\alpha^{\prime}ex\beta^{\prime}\in L^{\prime}
, and we have

\gamma^{\prime}x\delta^{\prime}\in L^{\prime}
so by
Claim

5.10
we have

\gamma^{\prime}ex\delta^{\prime}\in L^{\prime}
.
We then claim that
\alpha^{\prime}ex\delta^{\prime}\notin L^{\prime}
, implying that
L^{\prime}

is four-legged (taking
e
as the body,
\alpha=\alpha^{\prime}
,
\beta=x\beta^{\prime}
,
\gamma=\gamma^{\prime}
and
\delta=x\delta^{\prime}
, which are all not empty). Indeed, assume by
way of contradiction that
\alpha^{\prime}ex\delta^{\prime}\in L^{\prime}
. We would then have

\alpha^{\prime}ex\delta^{\prime}\in L
, so
\alpha^{\prime}x\delta^{\prime}\in L
(as
e
is neutral).
As
\alpha^{\prime}x\delta^{\prime}\notin L^{\prime}
by assumption, there
exists a strict infix
\tau
of
\alpha^{\prime}x\delta^{\prime}
that is in
L^{\prime}
. Now,
adding
e
to
\tau
would give a strict infix
\tau^{\prime}
of
\alpha^{\prime}ex\delta^{\prime}
, with
\tau^{\prime}\in L
because
\tau\in L
and
e
is neutral
for
L
,
a contradiction because
L^{\prime}
is infix-free.

•

Assume that
\beta^{\prime}\neq\epsilon
and
\delta^{\prime}\neq\epsilon
. The
reasoning is similar: using
Claim

5.10
we have
\alpha^{\prime}xe\beta^{\prime}\in L^{\prime}
and
\gamma^{\prime}xe\delta^{\prime}\in L^{\prime}

and we obtain that
L^{\prime}
is four-legged by taking
e
as the body,
\alpha=\alpha^{\prime}x
,
\beta=\beta^{\prime}
,
\gamma=\gamma^{\prime}x
and
\delta=\delta^{\prime}
.

This concludes the proof.
∎

,

,

,

,

. Now take

,

,

, but

We can then use

to prove our complexity characterization
of resilience for languages featuring a neutral letter (

Proposition

5.8
.

If
\mathtt{IF}(L)
is local then
\textsc{Res}_{\mathrm{bag}}(L)
is PTIME by

.
Otherwise, by

is four-legged, in which case

is NP-hard by

,
or

for

.
In this case one can easily adapt the proof of

The dichotomy above relies on the presence of a neutral letter, so it does
not apply to all languages. In particular, it does not apply at all to finite
languages. This motivates further study of finite languages, and in fact all the
languages studied in the remainder of the paper will be finite languages.

6.
Hardness of Finite Languages Having Repeated Letters

We now conclude the presentation of our main hardness results by showing that
resilience is hard for a class of languages that generalizes
aa

(
Proposition

4.1
). We say that a
word
\alpha
has a
repeated letter
if we have
\alpha=\beta a\gamma a\delta
for some
a\in\Sigma
and
\beta,\gamma,\delta\in\Sigma^{*}
.
We show that, for infix-free finite languages,
resilience is NP-hard whenever the language contains a word with a repeated letter:

Theorem 6.1

(Hardness with repeated letters)
.

Let
L
be an infix-free finite language that contains a word with a repeated
letter. Then
\textsc{Res}_{\mathrm{set}}(L)
is NP-complete.

Before proving
Theorem

6.1
, we discuss its relation
with existing work and with the other results we have obtained so far.

Connections to UCQs and self-joins.

Observe that
finite languages
L
correspond to the case of RPQs that are in fact unions of
conjunctive queries (UCQs). The UCQs obtained from RPQs have a specific form:
they are posed on an arity-two signature corresponding to the
alphabet
\Sigma
, and their constituent conjunctive queries (CQs) are directed
paths corresponding to words of the language
L
.
The language being infix-free corresponds then to the UCQ being
irredundant
.
In this sense, repeated
letters in words correspond to self-joins in CQs. Thus,

Theorem

6.1
implies that, for those (irredundant) UCQs that correspond to finite (infix-free) RPQs,
the resilience problem is NP-hard unless every CQ is self-join-free.
8
8

8

This
contrasts with the setting of general UCQs, where resilience is sometimes
tractable even in the presence of
self-joins.
Specifically, in that setting,
the following Boolean CQ
over a signature of arity at most two has tractable resilience under set semantics
(
Freire et al., 2020b
, Proposition 12)
:

Q{\,:\!\!-\,}A(x),R(x,y),R(z,y),C(z)
. See also
(
Freire et al., 2020a
, Appendix C.1, Example 61)
.

Note that the converse does not hold, e.g.,
the UCQ corresponding to the language
axb|cxd
is hard, yet each of its
constituent CQs is self-join-free. Thus our results do not imply a dichotomy on
UCQs with directed-path constituent CQs, with some such queries being left unclassified by our work (e.g., the query corresponding to language
abc|bcd
). Our results however imply a dichotomy for

single directed-path CQs
, because a singleton word without repeated
letters is local and hence tractable, while a singleton word with a repeated
letter is hard by Theorem
6.1
. Last, we discuss
the recent work
(
Bodirsky and Semanišinová, 2026
)

that establishes a dichotomy for UCQs that use a single binary relation: on the one
hand, these queries are more general than the unions of directed path CQs
(since CQs are not restricted to be directed paths), but on the other hand they
do not allow multiple binary relations.

Connections to other language classes.

We now explain how

Theorem

6.1

relates to the languages discussed so far. We first perform
a sanity check: such languages are never local.

Lemma 6.2
.

Let
L
be a
finite language containing a word with a
repeated letter. Then
L
is not local.

Proof.

As
L
is finite and contains a word with a repeated letter, we can take a word with a repeated letter whose length is
maximum among words of
L
with a repeated letter.
Let
\alpha=\beta a\gamma a\delta\in L
be such a word.
Assume by
contradiction that
L
is local.
Then, by
Proposition

3.7
,
L
is letter-Cartesian.
Applying the definition to
\alpha
and
\alpha
, we must have that the
following word is also in
L
:

\beta a\gamma a\gamma a\delta\in L.

This word is a word of
L
which contains a repeated letter and is strictly
longer than
\alpha
.
This contradicts the maximality of
\alpha
, and
concludes the proof.
∎

Equivalently, every local language containing a word with a repeated letter must be infinite.
Note that the finiteness hypothesis is essential for
Lemma

6.2
, e.g.,

L=ax^{*}b

contains words with repeated letters but it is local (see

Example

3.4
).
Further notice that there is no converse to
Lemma

6.2
:
there are finite infix-free non-local
languages that feature no words with repeated letters and for which resilience
is hard. This is for instance the
case of the four-legged language
axb|cxd
of
Proposition

4.13
.
Thus,
the languages covered by

Theorem

6.1
and

Theorem

5.3

are incomparable: they each generalize
Proposition

4.1
and

Proposition

4.13
, respectively, without implying the other result. (However, the proof of

Theorem

6.1
relies on
Theorem

5.3
.)
These two results also do not cover all intractable cases, as we will
see in the next sections.

We prove
Theorem

6.1
in the remainder of this section.
Because the proof is technical, we sketch it here
before giving the details.
We first make a preliminary observation: the tractability of resilience is
preserved under the

reversal operation

on regular languages. We then
start from a word featuring a repeated letter, and pick it to optimize certain
criteria (maximizing the gap between the repeated letters, and then maximizing
the total length of the word): we call this a
maximal-gap
word.
Note that the
existence of such words is
the only place where we use the fact that
L
is finite; indeed, our auxiliary hardness
results in the sequel will be stated in full generality without the assumption
that
L
is finite.

We then consider such a maximal-gap word
\beta a\gamma a\delta
, and consider
various cases.
We first deal separately with the case where
\beta
and
\delta
are both
non-empty, as we can then show rather easily that
L
is four-legged. Once this
case is dealt with,
we use the
reversal operation
to assume without loss of
generality that it is
\beta
which is empty.
We then consider the word
\gamma a\gamma

and study whether it has infixes in
L
. If it does not, we easily build a
gadget. If it does, we can now show that
\delta
must be empty or otherwise the
language is four-legged. We then study the choice of infix
\alpha^{\prime}
of
\gamma a\gamma

and distinguish two cases by considering the suffix of the left
\gamma
and the
prefix of the right
\gamma
: either they overlap or they do not
overlap. We build
suitable gadgets for each case.

The reversal operation.

We first make a straightforward observation on the

reversal
of
languages. The
reversal

of a word
\alpha=a_{1}\cdots a_{n}\in\Sigma^{*}
is

\alpha^{\mathrm{R}}=a_{n}\cdots a_{1}\in\Sigma^{*}
(in particular

\epsilon^{\mathrm{R}}=\epsilon
).
The
reversal

of a language
L\subseteq\Sigma^{*}
is
L^{\mathrm{R}}\coloneq\{\alpha^{\mathrm{R}}\mid\alpha\in L\}
.
Observe that
(L^{\mathrm{R}})^{\mathrm{R}}=L
.
It is immediate by symmetry that a language
L
is infix-free iff

L^{\mathrm{R}}
is
infix-free. Further, it is also immediate that a language and its
reversal
have the same
complexity for resilience:

Proposition 6.3
.

Let
L
be any language. There are PTIME reductions between

\textsc{Res}_{\mathrm{set}}(L^{\mathrm{R}})
and
\textsc{Res}_{\mathrm{set}}(L)
, and between

\textsc{Res}_{\mathrm{bag}}(L^{\mathrm{R}})
and
\textsc{Res}_{\mathrm{bag}}(L)
.

The point of this claim will be to eliminate symmetric cases, up to replacing the
language by its
reversal.
We only use the claim about set semantics in the sequel (given that we will show
hardness of resilience in set semantics, from which hardness for bag
semantics follows): the claim for bag semantics in
Proposition

6.3
is given just for
completeness.

Proof of
Proposition

6.3
.

We give the proof for set semantics, the proof for bag semantics is the
same mutatis mutandis.
Given a database instance
D
for
\textsc{Res}_{\mathrm{set}}(L^{\mathrm{R}})
,
simply create a database instance
D^{\mathrm{R}}
by reversing the direction of
all arrows of
D
. It is then obvious that a subset
D^{\prime}\subseteq D

satisfies
Q_{L^{\mathrm{R}}}
iff the corresponding subset

(D^{\prime})^{\mathrm{R}}

of
D^{\mathrm{R}}
, which has the same cardinality, satisfies
Q_{L}
.
Hence, the answer to
\textsc{Res}_{\mathrm{set}}(L^{\mathrm{R}})
on
D
and to
\textsc{Res}_{\mathrm{set}}(L)
on

D^{\mathrm{R}}
are identical, giving the forward PTIME reduction. The
converse reduction is obtained by applying the previous argument to
reduce

(L^{\mathrm{R}})^{\mathrm{R}}=L
to
L^{\mathrm{R}}
.
∎

Maximal-gap words

Let

We will pick a word with a repeated letter for the rest of the proof, but we

Definition 6.4

For

\alpha=\beta a\gamma a\delta

•

The gap between the repeated letters is maximal, i.e., there is no word

Among such words, the length of

\alpha^{\prime}=\beta^{\prime}a^{\prime}\gamma^{\prime}a^{\prime}\delta^{\prime}

in

|\gamma^{\prime}|=|\gamma|
and
|\alpha^{\prime}|>|\alpha|

It is clear that any finite language that contains a word with a repeated

7.
Additional Complexity Results

We have shown tractability for local languages (
Theorem

3.15
),
and hardness for
four-legged languages
(
Theorem

5.3
)
and for finite infix-free languages containing
a word with a repeated letter
(
Theorem

6.1
).
These results do not give a full
classification. The purpose of this section is to illustrate two phenomena that any
full classification must account for: non-locality alone does not imply hardness,
and our hardness criteria do not cover all intractable cases.

We first give two tractable classes of languages that are not necessarily local.
First,
bipartite chain languages
,
such as
ab|bc
, are finite languages obtained from a bipartite graph on letter
endpoints; their resilience can be computed by a MinCut reduction that reverses some
matches. Second,
one-dangling languages
, such as
abc|be
, extend a local language
with one word that consists of two distinct letters such that at least one letter is fresh (i.e., does not
occur in the rest of the language); such languages are tractable by a more
involved flow encoding. We then show additional NP-hard cases not covered by
our
previous hardness criteria.

7.1.
Tractability of Bipartite Chain Languages

Let us define the

chain languages
:

Definition 7.1

(Chain languages)
.

A language
L
is a
chain language
if:

(1)

No word in
L
contains a repeated letter.

(2)

Each word of
L
of length at least 2 may only share its first or last
letter with other words in
L
:
formally,
for each word
\alpha=a\gamma b
in
L
, no letter of
\gamma

occurs in another word of
L
.

Note that chain languages are always finite, because they contain at most

|\Sigma|
words of length
>2
: indeed, each word of length 3 or more contains
intermediate letters which cannot occur in another word. We will focus on chain
languages satisfying an extra condition, called being
bipartite
:

Definition 7.2

(Endpoint graph, BCL)
.

The
endpoint graph
of a language
L
is the undirected graph

(\Sigma,E)
having as vertices the letters of
\Sigma
, and
having an edge
\{a,b\}
for
a\neq b
in
\Sigma
iff
a
and
b
are
the endpoints of some word of
L
of length at least
2
(i.e.,
L
contains a
word of the form
a\alpha b
or
b\alpha a
).

A chain language is a
bipartite chain language
(BCL) if its endpoint
graph is bipartite.

Example 7.3

(
Figure

14
)
.

The languages

(from

5.2
) and

are BCLs; the language

is a chain language but not a BCL. None of
these languages are local.

Thus, there are two kinds of chain languages: those that are bipartite, and
those which are not. We conjecture that
non-bipartite ones are intractable:

Let

be an infix-free chain language. If

is not bipartite, then
\textsc{Res}_{\mathrm{set}}(L)

\epsilon

We present the proof in the rest of this subsection. At a high level, we proceed by partitioning the letters of
\Sigma
based on the bipartition of the
endpoint graph. We then build a flow network like for
Theorem

3.15
, but
we reverse some words depending on the sides of the partition in which their
endpoints fall. Before doing all this, however, in order to establish our precise runtime
bounds we must show a preliminary claim (
Lemma

7.8

the input
\epsilon
NFA recognizing the BCL language can be tractably

Lemma

.

Given an
\epsilon
NFA
A
such that the language
\mathcal{L}(A)

in time

the explicit list of words of the finite
language
L
.

We can then prove
Proposition

7.7
from

:

Proof of
Proposition

7.7
.

Thanks to
Lemma

7.8
, we compute in time
O(|A|\times|\Sigma|^{2})

the language
L\coloneq\mathcal{L}(A)
as an explicit list of words.

We first process

in linear time to eliminate the words of length

0
or
1
. Namely, if
L
contains
\epsilon
, then resilience is
+\infty
; so in
the sequel we assume that
L
does not contain
\epsilon
. For words
of length
1
, for every letter

such that

contains the single-letter word

know that in the input database

we must remove every

to remove all such facts
(accounting for their multiplicities in the resilience value that we are

and

. Hence, at the end of
this preprocessing, in time

consists of

We now point out that

is infix-free. This is by
definition of a chain language and from the assumption that the words have
length at least 2. Indeed, if
\alpha\in L
is a strict infix of
\beta\in L
then

\beta
must have length at least 3, so there are letters in
\beta
that are neither
the first nor the last letter, by definition of

being a chain language these letters
cannot occur in a word of

\alpha

\alpha
being an infix
of
\beta
implies that
\alpha
has length

, contradicting the assumption that the

have length 2 or more.

We then build the endpoint graph
G
of
L
, simply by going over the explicit
list and noting which letters occur as the first or last letter of some word.
We now know by assumption that
G
is bipartite: we compute a witnessing
bipartition in linear time by the obvious greedy algorithm.
Let us assign each letter that occurs in
L
as an endpoint (i.e., as the
first or last letter of a word of length at least

) to either the source or
target partition.
Now, the words of
L
can be partitioned between the
forward words
, in
which the first letter is assigned to the source partition and the
last letter to the target partition;
and the
backward words
, where the opposite occurs.

Then we construct a flow network as follows:

•

We add two fresh vertices
t_{\text{source}}
and
t_{\text{target}}
which are the source and the target respectively of the network.

•

For every fact

we define two vertices
\mathrm{start}_{a,v,v^{\prime}}
and
\mathrm{end}_{a,v,v^{\prime}}
.

•

For every letter
a
, there is an edge with capacity

\mathtt{mult}(a(v,v^{\prime}))
from
\mathrm{start}_{a,v,v^{\prime}}
to

\mathrm{end}_{a,v,v^{\prime}}
for every
v,v^{\prime}
such that
we have
a(v,v^{\prime})\in D
.

•

For every forward word containing an infix
ab
, where
a,b
are letters in
\Sigma
,
and
a(v,v^{\prime})
and
b(v^{\prime},v^{\prime\prime})\in D
, there is an edge with capacity

+\infty
from
\mathrm{end}_{a,v,v^{\prime}}
to
\mathrm{start}_{b,v^{\prime},v^{\prime\prime}}

•

For every backward word containing an infix
ab
, where
a,b
are
letters in
\Sigma
, and
a(v,v^{\prime})
and
b(v^{\prime},v^{\prime\prime})\in D
, there is an edge with capacity
+\infty

from
\mathrm{end}_{b,v^{\prime},v^{\prime\prime}}
to

\mathrm{start}_{a,v,v^{\prime}}
.

•

There is an edge with capacity
+\infty
from
t_{\text{source}}
to
every vertex of the form
\mathrm{start}_{a,v,v^{\prime}}
where
a
is an endpoint
assigned to the source partition, and from every vertex of the form

\mathrm{end}_{a,v,v^{\prime}}
to
t_{\text{target}}
where
a
is an endpoint in the target partition.

The explicit list of words has size
O(|A|\times|\Sigma|^{2})
, and the
construction runs in time
O(|D|^{2}\times|A|\times|\Sigma|^{2})
.

We can see that this construction contains a single edge for every fact,
whose capacity is the multiplicity of said fact.
Every witness of the instance corresponds to a source-to-target walk by
construction.
Indeed, for each forward word, we have a path from
t_{source}

to the edge corresponding to its first letter, then following each letter in
succession until we reach the last letter and then
t_{target}
.
Further, for each backward word, we have a path from
t_{source}

to the edge corresponding to its last letter, then following each letter in
succession in reverse order, until we reach the first letter and
t_{target}
.

We must also show that there is no path from source to target in the network that does not correspond to a witness.
Any path from
t_{source}
to
t_{target}
must start with a vertex of the
form
\mathrm{start}_{a,v,v^{\prime}}
where
a
is assigned to the source partition (in
particular it is not a letter that occurs in the middle of any word). We
then move to a vertex
\mathrm{start}_{b,v^{\prime},v^{\prime\prime}}
and there are two cases: either

a
was the first letter of a forward word
\alpha
and
ab
occurs as an infix in that word,
necessarily at the beginning because no middle letters are repeated, or
a
was the
last letter of a backward word
\alpha
and
ba
occurs in that word, again necessarily at
the end because no middle letters are repeated. We describe the first case
(corresponding to forward words), the second (corresponding to backward words)
is symmetric. From the condition that intermediate letters of words do not
occur in other words, whenever we reach a vertex, then
the next vertex must correspond to the next letter of
\alpha
. Eventually we
reach the last letter of
\alpha
and the corresponding node has no outgoing
edge in the flow network except the edge to
t_{\text{target}}
, so we
terminate.
Thus, all paths in this network correspond to witnesses.

Thus, this construction maintains the one-to-one
correspondence between the contingency sets of
D

for
Q_{L}
and the cuts of the network that
have finite cost: selecting facts to remove in the
contingency set corresponds to cutting edges in the
network, and ensuring that the contingency set does
not satisfy the query corresponds to ensuring that
no source to target paths remain. Furthermore,
the sum of multiplicities of the facts in a
contingency set is equal to the cost of the
corresponding cut, so that minimum cuts correspond
to minimum contingency sets. We can then, as in
the case of local languages, simply solve the
MinCut problem for this network in

(|A|\times|D|^{2}\times|\Sigma|^{2})^{1+o(1)}
,
concluding the proof.
∎

Definition 7.9

A

is a language that can be written as
L\cup\{xy\}
where
L
is a local language over some alphabet
\Sigma

and where
x
and
y
are distinct letters
such that at least one of them is not in
\Sigma

Note that one-dangling languages cover in particular the more restricted class of languages for which tractability had been shown in
the conference version of this paper

(
Amarilli et al., 2025a

. They also cover the two languages
abcd|be
and

for which the
complexity of resilience had been left open
in
(
Amarilli et al., 2025a
)
. So we can subsume that result by
showing the following:

Proposition 7.10

Let
L\cup\{xy\}
be a one-dangling language where
L

is recognized by an RO-
\epsilon
NFA
A
.
The problem
\textsc{Res}_{\mathrm{bag}}(L\cup\{xy\})
is solvable in

(|A|\times|D|\times|\Sigma|)^{1+o(1)}

In addition to covering more languages, this result is a combined
tractability result instead of a data complexity result, and it
gives a better polynomial exponent than

(
Amarilli et al., 2025a
, Proposition 7.7)
. This is because our proof will
proceed via a reduction to a
flow problem,
instead of the submodular-function-minimization argument used in
(
Amarilli et al., 2025a
, Proposition 7.7)
,
which relies on the general techniques surveyed in
(
McCormick, 2005
)
.

We prove
Proposition

7.10
in the rest of this
subsection, before finally turning to other NP-hard cases in the rest of the
section.
If
\epsilon
is in
L
, then resilience is
+\infty
; so in
the sequel we assume that
L
does not contain
\epsilon
.
We do a slight abuse of notation throughout the proof for convenience: for
D^{\prime\prime}
a bag database and
L^{\prime\prime}
a
language, we will talk of a
contingency set of
D^{\prime\prime}
for
L^{\prime\prime}
simply to mean a
contingency set of
D^{\prime\prime}
for
Q_{L^{\prime\prime}}
.

Due to Proposition
6.3
, if there is a PTIME solution for
\textsc{Res}_{\mathrm{bag}}(L\cup\{xy\})
,
then there is a PTIME solution for
\textsc{Res}_{\mathrm{bag}}(L^{R}\cup\{yx\})
, and the reversal of
a local language is local (as can easily be seen from
Proposition

3.7
). Hence, we can assume without loss of generality that

y\not\in\Sigma
. Furthermore, we can also assume without loss of generality that
x
occurs in some word of
L
, as otherwise
L\cup\{xy\}
is local and we can conclude by
Theorem

3.15
. In particular,
x\in\Sigma
.

Let
z
be a fresh letter which is not in
\Sigma\cup\{y\}
.
Our strategy will be to rewrite the input bag database
D
over
\Sigma\cup\{y\}

to a modified bag database
D^{\prime}
over
\Sigma\cup\{z\}
,
and create a local language
L^{\prime}
over
\Sigma\cup\{z\}

such that
\mathtt{RES}_{\mathrm{bag}}(L\cup\{xy\},D)=\mathtt{RES}_{\mathrm{bag}}(L^{\prime},D^{\prime})+\kappa
,
where
\kappa
is a value that we can tractably compute from
D
.
We first define the language
L^{\prime}
, which is intuitively obtained by
replacing every appearance of the letter
x
in
L
by the word
xz
.
Formally, let
A=(S,I,F,\Delta)
be an RO-
\epsilon
NFA for
L
.
Let
A^{\prime}
be the automaton that results from adding one fresh state
s^{\prime}
to
S
,
and replacing the one transition
(s,x,t)
labeled by
x
(which exists as
x
occurs in some word of
L
) by two transitions
(s,x,s^{\prime})
and
(s^{\prime},z,t)
.
Note that the new state
s^{\prime}
is not final, so there are no
words in
\mathcal{L}(A^{\prime})
that end in
x
.
Clearly, the automaton
A^{\prime}
is also an RO-
\epsilon
NFA, so that
L^{\prime}\coloneq\mathcal{L}(A^{\prime})
is also a local language. As
L
is a language over
\Sigma
, the
language
L^{\prime}
is defined over
\Sigma\cup\{z\}
, and further for any

m\in\mathbb{N}
and
\alpha_{1},\ldots,\alpha_{m}\in\Sigma^{*}
we have

\alpha_{1}x\alpha_{2}x\cdots\alpha_{m-1}x\alpha_{m}\in L
iff

\alpha_{1}xz\alpha_{2}xz\cdots\alpha_{m-1}xz\alpha_{m}\in L^{\prime}
.

Let us now define how the input bag database
D
over
\Sigma\cup\{y\}
is rewritten to a
bag database
D^{\prime}
over
\Sigma\cup\{z\}
.
To do this, we will extend the semantics of bag graph databases to what we
call the
extended bag semantics
, where we allow
the function
\mathtt{mult}
to give negative multiplicities, or multiplicity zero,
to edges of the database.
The rest of the semantics
remains unchanged, and the definition of resilience is unchanged as well –
noting that, when computing resilience over database in extended bag semantics,
one can always assume that facts with a non-positive multiplicity are removed.
For this reason, it is easy to see that

\textsc{Res}_{\mathrm{bag}}(L)
under the extended semantics
reduces in linear time to
\textsc{Res}_{\mathrm{bag}}(L)

under the normal bag semantics.
Let us use the notation
\textsc{Res}_{\mathrm{bag}}^{\sf ex}(L)
for a fixed language
L

to denote the resilience
problem when posed over databases in
extended bag semantics.

We can now describe the transformation. Given a bag database
D
, let
V
be the domain of
D
. For every node
v\in V
, let
D^{-}_{x}(v)
be the set of
edges of the form
u\xrightarrow{x}v
for some
u\in V
, and
let
D^{+}_{y}(v)
be the set of edges of the form
v\xrightarrow{y}u
for some
u\in V
.
We rewrite
D
by doing the following for each
v\in V
:

(1)

add a fresh node
(v,{\sf in})
into
V
;

(2)

replace all edges of the form
u\xrightarrow{x}v\in D^{-}_{x}(v)
by
the edge
u\xrightarrow{x}(v,{\sf in})
, keeping the same multiplicity;

(3)

add an edge
(v,{\sf in})\xrightarrow{z}v
into
D
and define

\mathtt{mult}((v,{\sf in})\xrightarrow{z}v)\coloneq\sum_{e\in D^{-}_{x}(v)}\mathtt{mult}(e)-\sum_{e\in D^{+}_{y}(v)}\mathtt{mult}(e)
(which may be negative);
and

(4)

erase any edges in
D^{+}_{y}(v)
from
D
.

Let us call
D^{\prime}
the resulting bag database: it is a bag database in extended
semantics, and it is over the alphabet
\Sigma\cup\{z\}
because applying
the last point of the list above over all
v\in V
will remove all
y
-facts.
Let us define
the value
\kappa\coloneq\sum_{v\in V}\sum_{e\in D^{+}_{y}(v)}\mathtt{mult}(e)

(evaluating this expression in
D
). Note that
\kappa
can be computed in
linear time from
D
as it is simply the sum of multiplicities of all edges
labeled
y
in
D
.

We now claim the following:

(
\dagger
)

\mathtt{RES}_{\mathrm{bag}}(L\cup\{xy\},D)=\mathtt{RES}_{\mathrm{bag}}^{\sf ex}(L^{\prime},D^{\prime})+\kappa\addcontentsline{lla}{section}{\numberline q:res}

which suffices to conclude, because we have computed
\kappa
and we can compute
the resilience expression in the right-hand side using

Theorem

3.15
: the language
L^{\prime}
is local, and as we explained the
complexity of computing resilience is unchanged when working over
extended bag semantics databases. To show Equation (

†

7.2
), we will show the
following claim, and explain after its proof how the lemma implies

7.2

.

(i) For any minimum-cost contingency set
C
of
D
for
L\cup\{xy\}
, there
exists a contingency set
C^{\prime}
of

for

such that
\sum_{e\in C}\mathtt{mult}(e)=\kappa+\sum_{e\in C^{\prime}}\mathtt{mult}(e)
; and
(ii) for any minimum-cost contingency set
C^{\prime}
of
D^{\prime}
for
L^{\prime}
, there exists
a contingency set
C
of
D
for
L\cup\{xy\}
such that
\sum_{e\in C}\mathtt{mult}(e)=\kappa+\sum_{e\in C^{\prime}}\mathtt{mult}(e)
.

We end
the proof of
Proposition

7.10

by explaining why Equation (

†

7.2
)
follows from

7.11
. First, suppose that
\mathtt{RES}_{\mathrm{bag}}(L\cup\{xy\},D)<\mathtt{RES}_{\mathrm{bag}}^{\sf ex}(L^{\prime},D^{\prime})+\kappa

C^{*}
be a minimum-cost contingency set of
D
for

L\cup\{xy\}

C^{\prime*}
be a minimum-cost contingency set of

for

. We have that
\sum_{e\in C^{*}}\mathtt{mult}(e)<\kappa+\sum_{e\in C^{\prime*}}\mathtt{mult}(e)

Already in the case of finite infix-free languages, there are gaps remaining

Proposition

7.7
) and the hard cases (languages containing a word with a repeated letter, and four-legged
languages) that we have identified so far. We show below that an unclassified
language is NP-hard by building a specific gadget:

.

\textsc{Res}_{\mathrm{set}}(abcd|be|ef)

\textsc{Res}_{\mathrm{set}}(abcd|bef)

8.
Conclusion and Future Work

We have studied the complexity of resilience for RPQs, towards the goal of
characterizing the languages for which the problem is tractable. We study
bag and set semantics, but
our results so far show no difference between the two settings,
unlike for
CQs
(
Makhija and Gatterbauer, 2023
)
.
Refer back to
Figure

1
on page
1
for a summary of
our results and of some remaining open cases.
We leave open the general question of whether there are
languages
L
, regular or not, for which
\textsc{Res}_{\mathrm{set}}(L)
is PTIME but
\textsc{Res}_{\mathrm{bag}}(L)

is NP-hard.
We also leave open the question of classifying the complexity of resilience
in intermediate settings, e.g., bag semantics where only weights
1
and

\infty
are allowed; or the setting where some relations are indicated as

exogenous
in the signature, which amounts to giving a weight of
\infty

to all their facts. Other settings left open by our work are those where we
delete vertices (or just vertex labels) instead of edges, or where vertices and/or
edges can be labeled by words or by non-empty words instead of single letters.

At the level of conjectures,
two directions seem particularly natural. First, for finite
chain languages, we conjecture that the bipartiteness condition of

Proposition

7.7

is
also necessary for tractability: non-bipartite chain languages should have NP-hard
resilience in set semantics (this is
Conjecture

7.4
, with

Proposition

7.5
proving one
representative case).
More generally, at a high level, we still do not fully understand the non-local languages that are not
four-legged, i.e., non-letter-Cartesian languages featuring counterexamples
where some of the “legs” are empty.
Second, all tractable classes identified in this paper admit reductions to MinCut or
closely related flow problems (subsuming in particular the
techniques based on submodular optimization used in the earlier
version of this work
(
Amarilli et al., 2025a
)
), and we currently know no tractable example requiring
fundamentally different techniques. It remains open whether flow-based
techniques always suffice whenever the resilience problem is tractable.

Another open question concerns
non-Boolean RPQs
, i.e., where
endpoints are fixed (or given as input).
For instance, the RPQ
aa
then seems
tractable as possible contingency sets have a simple structure; but
longer RPQs may stay hard. This problem may relate to

length-bounded cuts

(
Itai et al., 1982
;
Baier et al., 2010
)
,
or
multicuts
(
Garg et al., 1994
)
and skew multicuts
(
Kratsch et al., 2015
)
.
Note that this non-Boolean setting corresponds to the problem of
deletion
propagation with source side effects

(
Buneman et al., 2002
)
, which was studied before
resilience: this problem asks about finding a minimum contingency set to remove
a specific query answer. The case of removing multiple tuples has also been
investigated
(
Kimelfeld et al., 2013
)
. We do not know whether a dichotomy
in one of these settings implies a dichotomy for our problem, or vice-versa.
We also do not understand how our results relate to
VCSPs
(
Bodirsky et al., 2024
)
, e.g., whether classes of VCSPs with better
algorithms (in combined complexity, or in terms of the polynomial degree) can
imply tractable algorithms for some RPQ classes; or whether VCSP dichotomies
hold in set semantics (or in bag semantics
with weights restricted to
1
and
\infty
).

Last, resilience can be studied for
recursive queries beyond RPQs, in particular two-way RPQs or Datalog, though
this would require new techniques (unlike RPQs, these queries are not
“directional”).
We note that for two-way RPQs, and more generally for Boolean connected simple
monadic Datalog queries over signatures of arity at most two,
the existence of finite duals
(
Bienvenu et al., 2014
, Theorem 4.6(4))

yields a PTIME/NP-complete dichotomy for resilience under bag semantics
via the VCSP approach (see
(
Bodirsky et al., 2025
, Lemma 8.14 and Theorem 8.15)
).
