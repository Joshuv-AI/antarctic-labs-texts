Abstract
We introduce the class of L L -functions to certify the attractivity of sets for uncertain nonlinear switched systems in discrete time. The existence of an L L -function associated with a set guarantees the robust local attractivity of that set under the system dynamics. We propose a constructive method for obtaining piecewise-continuous L L -functions based on contractive sets for the system, and show that the existence of a robust control contractive set for the dynamics implies the existence of an appropriate L L -function, and hence the robust local attractivity of the set itself. We illustrate the proposed framework through examples that elucidate the theoretical concepts, and through the case study of a nonlinear switched system modelling antimicrobial resistance, which highlights the relevance of the approach to the analysis of biological systems.

Introduction

Switched systems model complex systems where discrete factors influence the continuous evolution of the states
(
14
)
. A powerful tool for the stability analysis of switched systems is offered by common Lyapunov functions, which enable the derivation of explicit formulas for the stabilising controller
(
15
)
. Yet, finding a common Lyapunov function that ensures stability is a nontrivial task
(
16
)
.
An alternative approach to Lyapunov stability analysis relies on invariant sets
(
4
)
, which provide geometric certificates of asymptotic stability and constraint satisfaction. The concept of control invariance has been extensively studied for linear switched systems (
6
;
17
;
10
;
18
)
offering constructive tools for analysing asymptotic behaviour
(
7
;
9
)
. However, attractivity analysis based on invariant sets remains a challenging open problem for nonlinear switched systems subject to uncertainties.

Here, we address the problem of certifying set attractivity for uncertain nonlinear switched systems with state constraints in discrete time.
We introduce the class of
L
-functions — a relaxation of the concept of Lyapunov function, with weaker requirements — and show that the existence of an
L
-function associated with a set guarantees robust local attractivity of that set for the dynamics.
We also propose a specific construction of
L
-functions based on contractive invariant sets for the system, and we prove that the existence of a contractive set implies the existence of an
L
-function, and hence robust local attractivity.
We demonstrate our theoretical results on a switched system that models bacterial population dynamics in a host, affected by the immune response and antibiotic action, in the presence of antimicrobial resistance (AMR); numerical simulations reveal the presence of invariant contractive sets, and hence of attractive sets for the system dynamics.

We provide preliminary definitions from the set-theoretic control literature (see, e.g.,

We wish to analyse whether a given

Definition 1

(Robust control invariant set, RCIS.)

Set
\Omega\subset\mathbb{X}
is a robust control invariant set for system (
1
) if, for every state
x\in\Omega

\sigma\in\mathbb{N}_{q}
such that
\boldsymbol{\Phi}(x,\sigma)\subseteq\Omega

The existence of
\sigma\in\mathbb{N}_{q}

\boldsymbol{\Phi}(x,\sigma)\subseteq\Omega

\sigma^{k}\in\mathbb{N}_{q}^{k}
such that
\boldsymbol{\Phi}(x,\sigma^{k})\subseteq\Omega
for all
k\geq 1

In the following, whenever we mention a RCIS, we implicitly assume that it is nonempty and compact.
A RCIS for the system is attractive if it has a nontrivial
domain of attraction
.

Definition 2

(Domain of attraction.)

The domain of attraction
\mathbb{D}(\Omega)
of a RCIS
\Omega\subset\mathbb{X}
for system (
1
) is given by all states in
\mathbb{X}
that can be driven to
\Omega
by the dynamics (
1
) with a feasible switching law
\sigma^{k}
and for all feasible uncertainties
w^{k}
, with any
k\geq 1
. Formally,

\mathbb{D}(\Omega)=\{x\in\mathbb{X}:~\exists~k\geq 1,\ \sigma^{k}\in\mathbb{N}_{q}^{k}\text{ s.t. }\boldsymbol{\Phi}(x,\sigma^{k})\subseteq\Omega\}.

We consider the
controllable set
of states from which we can drive the dynamics of system (
1
) into a given RCIS.

Definition 3

(Robust controllable set for mode
\sigma
.)

Given a RCIS
\Omega\subset\mathbb{X}
for system (
1
), the robust controllable set to
\Omega
for mode
\sigma\in\mathbb{N}_{q}
is

\mathbb{C}(\sigma,\Omega)=\{x\in\mathbb{X}\colon\boldsymbol{\Phi}(x,\sigma)\subseteq\Omega\}.

(2)

Definition 4

(Robust controllable set.)

Given a RCIS
\Omega\subset\mathbb{X}
for system (
1
), the robust controllable set to
\Omega
is

\mathbb{C}(\Omega)=\bigcup_{\sigma\in\mathbb{N}_{q}}\mathbb{C}(\sigma,\Omega),

(3)

Remark 1

To verify that a set
\Omega
is a RCIS, it is sufficient to check that
\Omega\subseteq\mathbb{C}(\Omega)
.

Definition 5

(Robust
k
-step controllable set.)

Given a RCIS
\Omega\subset\mathbb{X}
for system (
1
), the robust
k
-step controllable set to
\Omega
for system (
1
) can be defined iteratively by

\mathbb{C}^{k}(\Omega):=\mathbb{C}(\mathbb{C}^{k-1}(\Omega)),

for
k\geq 1
, with
\mathbb{C}^{1}(\Omega):=\mathbb{C}(\Omega)
and
\mathbb{C}^{0}(\Omega):=\Omega
.

Proposition 1

Given a RCIS
\Omega\subset\mathbb{X}
for system (
1
), its domain of attraction
\mathbb{D}(\Omega)
can be expressed as

\mathbb{D}(\Omega)=\bigcup_{k=1}^{\infty}\mathbb{C}^{k}(\Omega).

(4)

As a standing assumption throughout the work, we let
\Omega\subset\mathbb{X}
be a closed (and hence compact) set.

Remark 2

Since
\Omega
is closed, for each
k\geq 1
, the set
\mathbb{C}^{k}(\Omega)
is a finite union of controllable sets, each associated with a mode. Since each of these sets is closed
(
5
)
, their finite union is also closed. In contrast, the domain of attraction
\mathbb{D}(\Omega)
is defined as an infinite union of closed sets, which does not necessarily preserve closedness. Hence, while every
\mathbb{C}^{k}(\Omega)
is closed,
\mathbb{D}(\Omega)
may fail to be closed.

Robust controllable sets to a RCIS have a nested structure.

Proposition 2

Given a RCIS
\Omega\subset\mathbb{X}
for system (
1
),

\mathbb{C}^{k-1}(\Omega)\subseteq\mathbb{C}^{k}(\Omega)\,\,\mbox{ for all }k\geq 1.

Proof.

We prove that
\mathbb{C}(\Omega)\subseteq\mathbb{C}^{2}(\Omega)
; then, the result follows by induction.
For
x\in\mathbb{C}(\Omega)
, by definition, there is
\sigma_{1}\in\mathbb{N}_{q}
such that
\boldsymbol{\Phi}(x,\sigma_{1})\subseteq\Omega
. Since
\Omega
is a RCIS, then there is
\sigma_{2}\in\mathbb{N}_{q}
such that
\boldsymbol{\Phi}(x,\sigma^{2})\subseteq\Omega
for
\sigma^{2}:=\{\sigma_{1},\sigma_{2}\}
. Therefore
x\in\mathbb{C}^{2}(\Omega)
, which proves the result.
∎

3
L
-functions for set attractivity

We can associate an
L
-function with a RCIS
\Omega
for system (
1
), as per the following definition.

Definition 6

(
L
-function)

Given a RCIS
\Omega\subset\mathbb{X}
for system (
1
), function
L\colon\mathbb{X}\to\mathbb{R}_{\geq 0}
is an
L
-function for system (
1
) and set
\Omega
if it satisfies the following properties:

(i)

L(x)=0
for all
x\in\Omega
and
L(x)>0
for all
x\in\mathbb{X}\setminus\Omega
.

(ii)
There exists
R>0
such that
\{x\in\mathbb{X}\colon d(x,\Omega)=R\}
is nonempty and, given
L_{R}^{\ast}:=\inf_{d(x,\Omega)=R}L(x)
and defined the level set
\mathcal{L}_{R}(\Omega):=\{x\in\mathbb{X}\colon L(x)\leq L_{R}^{\ast}\}
, there exists a non-decreasing function
\eta_{R}\colon[0,R]\to\mathbb{R}_{\geq 0}
, with
\eta_{R}(0)=0
and
\eta_{R}(r)>0
for all
r\in(0,R]
, such that

\min_{\sigma\in\mathbb{N}_{q}}\;\sup_{z\in\boldsymbol{\Phi}(x,\sigma)}L(z)-L(x)\;\leq\;-\eta_{R}\!\left(d(x,\Omega)\right)

for all
x\in\mathcal{L}_{R}(\Omega)
.

Remark 3

The control-Lyapunov-like
L
-function in Definition
6
may be non-continuous; discontinuities may arise, e.g., due to switching between distinct modes of system (
1
). Still, function
L
is monotonically non-increasing along the system trajectories emanating from
\mathcal{L}_{R}(\Omega)
, and monotonically decreasing when
x\in\mathcal{L}_{R}(\Omega)\setminus\Omega
, as we show next.

Proposition 3

Given a RCIS
\Omega\subset\mathbb{X}
for system (
1
), if there exists an
L
-function for system (
1
) and set
\Omega
, as per Definition
6
, then
\Omega
is robustly locally attractive in
\mathcal{L}_{R}(\Omega)
.

Proof.

Consider a suitable
R>0
and functions
\eta_{R}
and
L
as in Definition
6
.
The switching law can be always chosen so that
L
is monotonically non-increasing along the system trajectories.
In fact, given a generic
k\geq 0
, for every admissible uncertainty sequence
w^{k+1}\in\mathbb{W}^{k+1}
, there exists an admissible switching law
\sigma^{k+1}\in\mathbb{N}_{q}^{k+1}
such that, for the resulting trajectory of system (
1
),
with
\phi(x,\sigma^{k},w^{k})\in\mathcal{L}_{R}(\Omega)
,
property
(ii)
in Definition
6
yields

\displaystyle L(\phi(x,\sigma^{k+1},w^{k+1}))-L(\phi(x,\sigma^{k},w^{k}))

\displaystyle\leq\ -\eta_{R}\!\bigl(d(\phi(x,\sigma^{k},w^{k}),\Omega)\bigr),

(5)

where
\phi(x,\sigma^{0},w^{0}):=x
.

Property
(ii)
in Definition
6
involves the supremum of
L(z)-L(x)
over all
z\in\boldsymbol{\Phi}(x,\sigma)
.
Therefore, possible discontinuities of
L
do not invalidate the decrease condition (
5
).
For any
x\in\mathcal{L}_{R}(\Omega)
, property
(ii)
implies that,
\forall w\in\mathbb{W}
, there exists
\sigma\in\mathbb{N}_{q}

such that
L(\phi(x,\sigma,w))\leq L(x)\leq L_{R}^{\ast}
,
and thus
\phi(x,\sigma,w)\in\mathcal{L}_{R}(\Omega)
. Hence,
\mathcal{L}_{R}(\Omega)
is a RCIS.
Consequently, given
x\in\mathcal{L}_{R}(\Omega)
, the decrease inequality (
5
) is valid for all
k\geq 0
.
Hence, the sequence
\{L(\phi(x,\sigma^{k},w^{k}))\}_{k\geq 0}
is non-increasing within
\mathcal{L}_{R}(\Omega)
, and strictly decreasing within
\mathcal{L}_{R}(\Omega)\setminus\Omega
, and it is bounded below by
0
.

Summing (
5
) from
k=0
to
N-1
,
and using the fact that
L
takes non-negative values, yields

\displaystyle\sum_{k=0}^{N-1}\eta_{R}\!\big(d(\phi(x,\sigma^{k},w^{k}),\Omega)\big)\

\displaystyle\leq\ L(x)-L(\phi(x,\sigma^{N},w^{N}))

\displaystyle\leq\ L(x),

which implies that
\sum_{k=0}^{\infty}\eta_{R}(d(x_{k},\Omega))<\infty
, and hence
\eta_{R}\!\big(d(\phi(x,\sigma^{k},w^{k}),\Omega)\big)\to 0
as
k\to\infty
.
Since
\eta_{R}
is non-decreasing and
\eta_{R}(r)>0
for all
R\geq r>0
, while
\eta_{R}(0)=0
, we have
d(\phi(x,\sigma^{k},w^{k}),\Omega)\to 0
as
k\to\infty
.
The above reasoning holds for all admissible uncertainty sequences and for all initial conditions
x
in a neighbourhood of
\Omega
.
Therefore,
\Omega
is
robustly locally attractive
, for all initial conditions in
\mathcal{L}_{R}(\Omega)
.
∎

3.1
Construction of an
L
-function

Here, we provide a constructive method to generate
L
-functions based on
contractive sets
for the system. Henceforth, the interior of any set will be interpreted as its interior relative to
\mathbb{X}
.

Definition 7

(Robust control contractive set, RCCS.)

Set
\Omega\subset\mathbb{X}
is a robust control contractive set for system (
1
) if, for every state
x\in\Omega
, there is
\sigma\in\mathbb{N}_{q}
such that
\boldsymbol{\Phi}(x,\sigma)\subseteq\text{int}\left(\Omega\right)
.

Remark 4

The inclusion
\boldsymbol{\Phi}(x,\sigma)\subseteq\operatorname{int}(\Omega)
in Definition
7
differs from the classical condition
\boldsymbol{\Phi}(x,\sigma)\subseteq\lambda\Omega
, for some
\lambda\in(0,1)
, which requires the origin to lie in
\Omega
(see, e.g.,
4
). This interior-based formulation was used by
2
;
8
.

Of course, every RCCS is also a RCIS. Whenever we mention a RCCS, we implicitly assume that it is nonempty and compact.

Remark 5

Given any set
\Omega
such that
\Omega\subseteq\text{int}\big(\mathbb{C}(\Omega)\big)
, the set
\mathbb{C}(\Omega)
is a RCCS. In fact, if
x\in\mathbb{C}(\Omega)
, by the definition of robust controllable set, there exists
\sigma\in\mathbb{N}_{q}
such that
\boldsymbol{\Phi}(x,\sigma)\subseteq\Omega\subseteq\text{int}\big(\mathbb{C}(\Omega)\big)
, which corresponds to Definition
7
.

Robust controllable sets to a RCCS have a stronger nested structure that extends Proposition
2
(see Fig.
1
-B).

Proposition 4

If
\Omega
is a RCCS of system (
1
), then

\mathbb{C}^{k-1}(\Omega)\subset\text{int}\left(\mathbb{C}^{k}(\Omega)\right)\,\,\mbox{ for all }k\geq 1.

Proof.

We prove that
\Omega\subset\text{int}\left(\mathbb{C}(\Omega)\right)
, which means that
\mathbb{C}(\Omega)
is a RCCS; then, the result follows by induction.
Given
x\in\Omega
, by definition of RCCS there is
\sigma\in\mathbb{N}_{q}
such that
\boldsymbol{\Phi}(x,\sigma)\subseteq\text{int}\left(\Omega\right)
.
Since
\mathbb{W}
is compact and
f_{\sigma}(x,\cdot)
is continuous, then
\boldsymbol{\Phi}(x,\sigma)
is compact, and hence there is
\varepsilon>0
such that

\bigcup_{z\in\boldsymbol{\Phi}(x,\sigma)}\mathcal{B}_{\varepsilon}(z)\subseteq\Omega,

where
\mathcal{B}_{\varepsilon}(z)
is the closed ball with center in
z\in\mathbb{X}
and radius
\varepsilon
relative to
\mathbb{X}
.
By joint continuity of
f_{\sigma}
and compactness of
\mathbb{W}
,
f_{\sigma}
is uniformly continuous on the compact set
\mathcal{B}_{r}(x)\times\mathbb{W}
for some small
r>0
, in view of Heine-Cantor theorem. Hence, for the considered
\varepsilon
, there exists
\delta\in(0,r)
such that, for all
w\in\mathbb{W}
,

\|y-x\|<\delta~\Rightarrow\|f_{\sigma}(y,w)-f_{\sigma}(x,w)\|<\varepsilon,

and therefore, for all
y\in\mathcal{B}_{\delta}(x)
, it holds that

\boldsymbol{\Phi}(y,\sigma)\subseteq\bigcup_{z\in\boldsymbol{\Phi}(x,\sigma)}\mathcal{B}_{\varepsilon}(z)\subseteq\Omega,

which implies that
\mathcal{B}_{\delta}(x)\subset\mathbb{C}(\Omega)
. Hence,
x\in\text{int}\left(\mathbb{C}(\Omega)\right)
, which concludes the proof.
∎

We define the following function, illustrated in Fig.
1
-B.

Definition 8

(
h-
function.)

Given a RCIS
\Omega\subset\mathbb{X}
for system (
1
), the associated
h-
function
h\colon\mathbb{N}\to\mathbb{R}_{\geq 0}
is
h(0):=0
and, for
k\geq 1
,

h(k):=\min\{d(y,z)\colon y\in\partial\mathbb{C}^{k-1}(\Omega),z\in\partial\mathbb{C}^{k}(\Omega)\}.

(6)

If
\Omega
is a RCCS, then
h(k)>0
for all
k\geq 1
, since the robust controllable sets are strictly nested as per Proposition
4
. We can thus prove the following.

Proposition 5

If
\Omega
is a closed RCCS and
h
is the associated
h
-function as per Definition
8
, then, for all
k\geq 1
,

\min_{y\in\partial\mathbb{C}^{k}(\Omega)}d(y,\Omega)\leq\min_{y\in\partial\mathbb{C}^{k+1}(\Omega)}d(y,\Omega)-h(k+1).

(7)

Proof.

We prove the statement for
k=1
; the result then follows by induction. Since
\Omega
and
\mathbb{C}^{2}(\Omega)
are compact sets, there exist
\bar{x}\in\Omega
and
\bar{z}\in\partial\mathbb{C}^{2}(\Omega)
such that
d(\bar{x},\bar{z})=\min_{y\in\partial\mathbb{C}^{2}(\Omega)}d(y,\Omega)
. Since
\Omega\subset\text{int}\left(\mathbb{C}^{1}(\Omega)\right)\subset\text{int}\left(\mathbb{C}^{2}(\Omega)\right)
and
\mathbb{C}^{1}(\Omega)
are compact sets, there exists
\bar{y}\in\partial\mathbb{C}^{1}(\Omega)
such that

. Then,

\displaystyle\min_{y\in\partial\mathbb{C}^{1}(\Omega)}d(y,\Omega)

\displaystyle\leq d(\bar{x},\bar{y})=\min_{y\in\partial\mathbb{C}^{2}(\Omega)}d(y,\Omega)-d(\bar{y},\bar{z})

\displaystyle\leq\min_{y\in\partial\mathbb{C}^{2}(\Omega)}d(y,\Omega)-h(2),

with
h(2)=\min\{d(y,z):y\in\partial\mathbb{C}^{1}(\Omega),z\in\partial\mathbb{C}^{2}(\Omega)\}
, for the

-function given in (
6
).

Considering the characterisation of the domain of attraction in Proposition
1
, we define the following function.

Definition 9

(
\kappa-

Given a RCIS
\Omega\subset\mathbb{X}
for system (
1
), the associated
\kappa
-function
\kappa\colon\mathbb{D}(\Omega)\to\mathbb{N}
is

\kappa(x)=\min\{k\in\mathbb{N}:x\in\mathbb{C}^{k}(\Omega)\},

with
\kappa(x)=0
for

.

Next, we propose a constructive method to obtain an
L
-function associated with a compact RCCS.
Note that an
L
-function is defined in the whole domain
\mathbb{X}
, but is guaranteed to be decreasing along the system trajectories only in (a subset of)
\mathbb{D}(\Omega)\setminus\Omega
, associated with some
R>0
,
which is guaranteed to exist if
\Omega
is a RCCS, since
\Omega\subset\text{int}\big(\mathbb{C}(\Omega)\big)
, and hence
\mathbb{D}(\Omega)\setminus\Omega\not=\emptyset
.

Proposition 6

Let
\Omega\subset\mathbb{X}
be a RCCS for system (
1
). The set-based map
L\colon\mathbb{X}\to\mathbb{R}_{\geq 0}
defined for
x\in\mathbb{D}(\Omega)
as

L(x)=\min_{y\in\partial\mathbb{C}^{\kappa(x)}(\Omega)}d(y,\Omega),

(8)

where
\kappa(x)
is the
\kappa
-function associated with
\Omega
as per Definition
9
, and for
x\in\mathbb{X}\setminus\mathbb{D}(\Omega)
as
L(x)=\bar{L}\geq\sup_{y\in\mathbb{D}(\Omega)}L(y)
, is an
L
-function for system (
1
) and set
\Omega
according to Definition
6
.

Proof.

We prove that the function
L
defined in (
8
) satisfies both properties in Definition
6
.

Property
(i)
. For
x\in\Omega
, we have
\kappa(x)=0
. Since
\Omega
is closed,
\partial\Omega\subseteq\Omega
, which implies that
d(z,\Omega)=0
for all
z\in\partial\mathbb{C}^{0}(\Omega)=\partial\Omega
, and hence
L(x)=0
.
Conversely,
\kappa(x)\geq 1
for all
x\in\mathbb{X}\setminus\mathbb{D}(\Omega)
, and hence

\min_{y\in\partial\mathbb{C}^{\kappa(x)}(\Omega)}d(y,\Omega)>0.

since
\Omega\subset\text{int}(\mathbb{C}^{\kappa(x)}(\Omega))
for all
\kappa(x)\geq 1
(see Proposition
4
).
Then, also for all
x\in\mathbb{X}\setminus\mathbb{D}(\Omega)
,
L(x)=\bar{L}>0
.

Property
(ii)
. Consider
x\in\mathbb{D}(\Omega)
. Given the
\kappa
-function
\kappa(x)
associated with
\Omega
as per Definition
9
, we have that
x\in\mathbb{C}^{\kappa(x)}(\Omega)
. By the definition of controllable set and the nested structure, there is
\sigma_{x}\in\mathbb{N}_{q}
such that

\boldsymbol{\Phi}(x,\sigma_{x})\subset\mathbb{C}^{\kappa(x)-1}(\Omega).

Then, for all
z\in\boldsymbol{\Phi}(x,\sigma_{x})
, we have that
\kappa(z)\leq\kappa(x)-1
, and hence

\min_{y\in\partial\mathbb{C}^{\kappa(z)}(\Omega)}d(y,\Omega)\leq\min_{y\in\partial\mathbb{C}^{\kappa(x)-1}(\Omega)}d(y,\Omega)

Since the last inequality holds pointwise in
z
, then

\sup_{z\in\boldsymbol{\Phi}(x,\sigma_{x})}\min_{y\in\partial\mathbb{C}^{\kappa(z)}(\Omega)}d(y,\Omega)\leq\min_{y\in\partial\mathbb{C}^{\kappa(x)-1}(\Omega)}d(y,\Omega).

(9)

Now consider that:

\displaystyle\min_{\sigma\in\mathbb{N}_{q}}\sup_{z\in\boldsymbol{\Phi}(x,\sigma)}L(z)

\displaystyle\leq\sup_{z\in\boldsymbol{\Phi}(x,\sigma_{x})}L(z)

(10)

\displaystyle=\sup_{z\in\boldsymbol{\Phi}(x,\sigma_{x})}\left(\min_{y\in\partial\mathbb{C}^{\kappa(z)}(\Omega)}d(y,\Omega)\right)

(11)

\displaystyle\leq\min_{y\in\partial\mathbb{C}^{\kappa(x)-1}(\Omega)}d(y,\Omega)

(12)

\displaystyle\leq\min_{y\in\partial\mathbb{C}^{\kappa(x)}(\Omega)}d(y,\Omega)-h(\kappa(x))

(13)

\displaystyle=L(x)-\mathbf{h}(x),

(14)

where
\mathbf{h}(x):=h(\kappa(x))
, and
h(\kappa(x))
is given by (
6
). Note that inequality (
12
) follows from (
9
), while inequality (
13
) follows from Proposition
5
.

Since
\Omega
is a RCCS, the set
\mathbb{D}(\Omega)\setminus\Omega\not=\emptyset
, and there exists
R>0
such that
N_{R}(\Omega):=\{x\in\mathbb{X}\colon d(x,\Omega)\leq R\}\subseteq\mathbb{D}(\Omega)
. Now, for any
r
with
0\leq r\leq R
, we define the “ring” set
N_{r,R}(\Omega):=\{x\in\mathbb{X}\colon r\leq d(x,\Omega)\leq R\}
. The family
\{\text{int}\left(\mathbb{C}^{i}(\Omega)\right)\}_{i\geq 1}
is an open cover of
N_{r,R}(\Omega)
. Since
N_{r,R}(\Omega)
is compact, there is a finite subcover

N_{r,R}(\Omega)\subset\bigcup_{j=1}^{m}\text{int}\left(\mathbb{C}^{i_{j}}(\Omega)\right).

and

\min_{x\in N_{r,R}(\Omega)}\mathbf{h}(x)=\min_{i\in S_{m}}h(i)>0,

for the index set
S_{m}=\{i_{1},\dots,i_{m}\}
.

Define
\eta_{R}(0)=0
and, for each
r\in(0,R]
,

\eta_{R}(r)\;:=\;\min_{x\in N_{r,R}(\Omega)}\mathbf{h}(x).

Since
N_{r_{2},R}(\Omega)\subseteq N_{r_{1},R}(\Omega)
whenever
0\leq r_{1}\leq r_{2}\leq R
, function
\eta_{R}(r)
is non-decreasing. Moreover, any
x\in N_{R}(\Omega)
also satisfies
x\in N_{d(x,\Omega),R}(\Omega)
, and hence

\mathbf{h}(x)\ \geq\ \eta_{R}\big(d(x,\Omega)\big).

Combining the above inequality with (
10
)–(
14
) yields

\min_{\sigma\in\mathbb{N}_{q}}\ \sup_{z\in\boldsymbol{\Phi}(x,\sigma)}L(z)-L(x)\leq-\eta_{R}\!\big(d(x,\Omega)\big).

The inequality also holds for all
x\in\mathcal{L}_{\hat{R}}
, where
\mathcal{L}_{\hat{R}}
is the largest level set of
L
such that
\mathcal{L}_{\hat{R}}\subseteq N_{R}(\Omega)
, which concludes the proof.
∎

The
L
-function proposed in Proposition
6
is piecewise constant, as it is constant over each set
\mathbb{C}^{k}(\Omega)\setminus\mathbb{C}^{k-1}(\Omega)
.

Theorem 7

If
\Omega
is a RCCS for system (
1
), then
\Omega
is robustly locally attractive under the system dynamics.
Moreover, an explicit stabilizing switching law is

\sigma(x)\ =\min\Big\{\,\sigma\in\mathbb{N}_{q}\;:\;x\in\mathbb{C}\big(\sigma,\mathbb{C}^{\kappa(x)-1}(\Omega)\big)\,\Big\},

(15)

where
\mathbb{C}\big(\sigma,\mathbb{C}^{\kappa(x)-1}(\Omega)\big)
is the robust controllable set to set
\mathbb{C}^{\kappa(x)-1}(\Omega)
for mode
\sigma
, as per Definition
3
.

Proof.

Robust local attractivity of
\Omega
follows from combining Proposition
6
, by which the existence of a RCCS guarantees that a suitable
L
-function exists, and Proposition
3
, by which the existence of a suitable
L
-function guarantees robust local attractivity.

We now show that
\sigma(x)
in (
15
) is a stabilizing switching law. By Definition
9
, of
\kappa
, and for a state
x\in\mathcal{L}_{R}(\Omega)\not=\emptyset
we have

x\in\mathbb{C}^{\kappa(x)}(\Omega)=\mathbb{C}\big(\mathbb{C}^{\kappa(x)-1}(\Omega)\big)=\bigcup_{\sigma\in\mathbb{N}_{q}}\mathbb{C}\big(\sigma,\mathbb{C}^{\kappa(x)-1}(\Omega)\big),

hence the set in (
15
) is non-empty for
x\in\mathcal{L}_{R}(\Omega)
; taking the minimum makes
\sigma(x)
single-valued.
By Definition
3
, it is
\boldsymbol{\Phi}(x,\sigma(x))\subseteq\mathbb{C}^{\kappa(x)-1}(\Omega)
; thus, for every
z\in\boldsymbol{\Phi}(x,\sigma(x))
,
\kappa(z)\leq\kappa(x)-1
. Consider
\bar{\kappa}:=\kappa(x)-\kappa(z)\geq 1
. Then, considering the

-function defined in (

) and relying on the inequality in Proposition

\displaystyle L(z)

\displaystyle=\min_{y\in\partial\mathbb{C}^{\kappa(z)}(\Omega)}d(y,\Omega)

\displaystyle\leq\min_{y\in\partial\mathbb{C}^{\kappa(x)}(\Omega)}d(y,\Omega)-\sum_{i=1}^{\bar{\kappa}}h(\kappa(z)+i)

\displaystyle\leq L(x)-h(\kappa(x)),

for all

)–(

Our result applies broadly to generic nonlinear switched systems with bounded uncertainties. However, it is affected by inherent conservatism, which depends on the specific nonlinearities, the uncertainty structure, and the chosen RCCS. In general, given a RCIS
\Omega
, the identification of the whole domain of attraction
\mathbb{D}(\Omega)
in (
4
) cannot be guaranteed a priori.

Also, the proposed scheme does not establish global attractivity for nonlinear switched systems. For uncertainty-free
linear
switched systems, the existence of a RCCS can imply global attractivity under suitable homogeneity assumptions; see
9
.

Next, we briefly examine the specificities of the linear case in Section
3.2
and then, in Section
4
, we consider the case study of control of nonlinear switching dynamics in the context of antimicrobial resistance, illustrating that the region of local attractivity,
\mathcal{L}_{R}(\Omega)
, can be considerably larger than the obtained RCCS
\Omega
.

3.2
Linear case

The case of a linear switched system with additive uncertainty,

x^{+}=A_{\sigma}x+w,

(16)

where
x\in\mathbb{X}
,
\sigma\in\mathbb{N}_{q}
, and
w\in\mathbb{W}
, sets
\mathbb{X}
and
\mathbb{W}
are compact and contain the origin in their interior, and matrix
A_{\sigma}
is nonsingular for all
\sigma\in\mathbb{N}_{q}
,
can be treated using a specific characterization of the controllable sets.

Consider the Minkowski (Pontryagin) difference of two sets
\mathcal{A}\subset\mathbb{X}
and
\mathcal{B}\subset\mathbb{X}
,

\mathcal{A}\ominus\mathcal{B}=\{a\colon a+b\in\mathcal{A},\text{ for all }b\in\mathcal{B}\}.

Given a set
\Omega\subseteq\mathbb{X}
, with
\Omega\ominus\mathbb{W}\neq\emptyset
, the robust controllable set to
\Omega
(as per Definition
4
) can be expressed as

\mathbb{C}(\Omega)=\bigcup\limits_{\sigma\in\mathbb{N}_{q}}A^{-1}_{\sigma}\left(\Omega\ominus\mathbb{W}\right).

(17)

Indeed, if
x\in\bigcup_{\sigma}A^{-1}_{\sigma}\left(\Omega\ominus\mathbb{W}\right)
, there exists
\sigma\in\mathbb{N}_{q}
such that
x\in A^{-1}_{\sigma}\left(\Omega\ominus\mathbb{W}\right)
, which implies
A_{\sigma}x\in\Omega\ominus\mathbb{W}
. Hence,
A_{\sigma}x+w\in\Omega
for all
w\in\mathbb{W}
, meaning that
\boldsymbol{\Phi}(x,\sigma)\subseteq\Omega
. Therefore,
x\in\mathbb{C}(\Omega)
. Conversely, if
x\in\mathbb{C}(\Omega)
, there must exist
\sigma\in\mathbb{N}_{q}
such that
A_{\sigma}x+w\in\Omega
for all
w\in\mathbb{W}
, or equivalently
A_{\sigma}x\in\Omega\ominus\mathbb{W}
, and thus

x\in A^{-1}_{\sigma}(\Omega\ominus\mathbb{W})\subseteq\bigcup\limits_{\sigma\in\mathbb{N}_{q}}A^{-1}_{\sigma}\left(\Omega\ominus\mathbb{W}\right).

Remark 6

For compact and convex sets
\Omega
and
\mathbb{W}
, both containing the origin in their interiors,

\mathbb{C}(\Omega)
is a
C^{*}
-set (a compact, convex set that contains the origin in its interior and is star-convex with respect to the origin). Such sets can be treated using standard geometric tools from linear and convex analysis
(
12
)
.

Building upon (
17
), we can extend Algorithm 1 by
9
, computing contractive sets for system (
16
) in the uncertainty-free case with
w=0
, by accounting for uncertainty
w\in\mathbb{W}
.

Algorithm 1. Computing RCCS for linear switched systems (
16
).

i.

Set
k=1
. Select
k_{stop}\in\mathbb{N}
and a RCIS
\Omega_{0}\subset\mathbb{X}
.

ii.

For
k\geq 1
,
\Omega_{k}=\bigcup_{\sigma\in\mathbb{N}_{q}}A^{-1}_{\sigma}\left(\Omega_{k-1}\ominus\mathbb{W}\right)\cap\mathbb{X}

iii.

If
\Omega_{0}\subseteq\text{int}\Big(\bigcup_{j=1}^{k}\Omega_{j}\Big)
, stop successfully.

iv.

Otherwise, if
k=k_{stop}
, stop unsuccessfully.

This algorithm does not generally guarantee obtaining a RCCS (unless it stops successfully at the first iteration). However, if it stops successfully at step
k=N
, then the set
\tilde{\mathbb{D}}(\Omega_{0}):=\bigcup_{j=1}^{N}\Omega_{j}
is an inner approximation of the domain of attraction
\mathbb{D}(\Omega_{0})
by construction.
In this way, the algorithm determines that set
\Omega_{0}
is robustly locally attractive, and it allows us to compute offline the switching law
\sigma(x)
in Eq. (
15
), which is well defined for all

.

The outcome of Algorithm
3.2
critically depends on the choice of an initial RCIS
\Omega_{0}
. However, the same algorithm can also be used to find a RCIS: if an arbitrary convex set
\Omega_{0}
is selected at step i. of Algorithm
3.2
and the algorithm stops successfully at step

, then
\hat{\Omega}_{0}:=\bigcup_{j=1}^{\hat{N}}\Omega_{j}
is a RCIS
(
1
)
.
The algorithm can then be subsequently applied to such a set so as to assess its contractivity.

Nonlinear Case Study: AMR Dynamics

Consider the nonlinear continuous-time dynamic model proposed by
3
to capture the time evolution of antibiotic-susceptible and antibiotic-resistant bacterial populations in the host, in the presence of immune-system response and antibiotics:

\begin{cases}\dot{b}=\alpha\,b\!\left(1-\tfrac{b}{N}\right)-I(b)\,b-D(u)\,s\\
\dot{s}=\alpha\,s\!\left(1-\tfrac{b}{N}\right)-I(b)\,s-D(u)\,s-M(u)\,s,\end{cases}

(18)

where
s
is the drug–susceptible subpopulation and
b
denotes the total bacterial load given by susceptible and resistant subpopulations. The states are constrained to the feasible domain
\mathbb{X}:=\{(b,s)\in\mathbb{R}^{2}:\ 0\leq s\leq b\leq N\}
.
All subpopulations have net growth rate
\alpha>0
, affected by a logistic term with carrying capacity
N>0
. The killing rate due to the host immune response is
I(b)=\beta\,\tfrac{K}{K+b}
, where
\beta>\alpha
is the maximum killing rate and
K<N
is the total bacterial load yielding half-maximal rate. The antibiotic killing rate is the Hill-type function
D(u)
, where
u
is the antibiotic concentration, and the antibiotic-induced resistance rate is the threshold function
M(u)
; see
3
for details.

We consider here two modes with different constant antibiotic levels: immune response alone, with
u\equiv 0
; immune response plus antibiotic dosing, with
u\equiv u_{M}
, where
u_{M}
is the Minimum Inhibitory Concentration (MIC) of the antibiotic
(
13
)
.
Denoting the state by
z=(b,s)\in\mathbb{X}
, we consider the continuous-time nonlinear switched system

\dot{z}=s_{\sigma}(z),\quad\sigma\in\{1,2\},

with

\displaystyle s_{1}(z)

\displaystyle=\begin{bmatrix}\alpha b(1-b/N)-I(b)\,b\\
\alpha s(1-b/N)-I(b)\,s\end{bmatrix},

\displaystyle s_{2}(z)

\displaystyle=\begin{bmatrix}\alpha b(1-b/N)-I(b)\,b-D_{M}\,s\\
\alpha s(1-b/N)-I(b)\,s-D_{M}\,s-\mu\,s\end{bmatrix},

where
D(u_{M})=D_{M}>\alpha
is the constant death rate of susceptible bacteria exposed to antibiotic concentration
u_{M}
, while
M(u_{M})=\mu>0
is the corresponding antibiotic-induced resistance rate.

We consider the discretisation of the continuous-time switched system obtained by applying the forward Euler method with sampling period
\Delta
:

x^{+}\;=\;x+\Delta\,s_{\sigma}(x)+w\;=:\;f_{\sigma}(x,w),\quad\sigma\in\{1,2\},

(19)

where
s_{\sigma}(x)
is the active subsystem vector field at time
k\Delta
, and
w=(w_{b},w_{s})
represents the discretisation error at time
k
, which lies in a bounded set
\mathbb{W}
provided that the sampling step
\Delta
is sufficiently small
(
11
)
.
To the discrete-time nonlinear switched system in (
19
), we can then apply the proposed methodology.

Following the criterion in Remark
5
, we design a numerical procedure to identify a RCCS for system (
19
).
Generate a dense grid of initial conditions in the domain

D_{0}=\{(b,s)\in\mathbb{X}:b\leq b_{\max}\}

with
b_{max}\leq N
and, for
b_{0}<b_{max}
, define a candidate set

\Omega_{0}=\{(b,s)\in\mathbb{X}:b\leq b_{0}\}.

For each grid point
x_{i}=(b_{i},s_{i})\in D_{0}
, we compute the one-step evolution of the system under both modes
\sigma\in\{1,2\}
and three uncertainty realisations:

w_{1}=(\bar{w}_{b},0)
,
w_{2}=(0,\bar{w}_{s})
,
w_{3}=(\bar{w}_{b},\bar{w}_{s})
,
where
\bar{w}_{b}
and
\bar{w}_{s}
are the maximum values of
w_{b}
and
w_{s}
, respectively.

For each mode, we define the set of next states

X^{+}_{i,\sigma}:=\{\,f_{\sigma}(x_{i},w_{1}),\;f_{\sigma}(x_{i},w_{2}),\;f_{\sigma}(x_{i},w_{3})\,\}\subseteq\boldsymbol{\Phi}(x_{i},\sigma).

An initial condition
x_{i}
is labelled as
inside
the robust controllable set
\mathbb{C}(\Omega_{0})
if

X^{+}_{i,\sigma}\subseteq\Omega_{0}\text{ for some }\sigma\in\{1,2\}.

(20)

The convex hull of all points
x_{i}
fulfilling condition (
20
) provides an inner approximation of
\mathbb{C}(\Omega_{0})
. If
\Omega_{0}
is in the interior of this convex hull, then the set
\mathbb{C}(\Omega_{0})
is a RCCS.

Remark 7

Considering only
w_{1}
,
w_{2}
, and
w_{3}
is sufficient since they represent the worst-case uncertainties at the positive upper corners of
\mathbb{W}
, and the uncertainty appears linearly (additively) in the dynamics.
Negative values of
w_{b}
or
w_{s}
yield smaller state increments, which in this case favor contractivity.

For all our numerical experiments, we fix step size
\Delta=0.1h
and uncertainty bounds
\bar{w}_{b}=\bar{w}_{s}=5
, while the model parameters are the same as in
3
.

5
Conclusion

We proposed the new class of
L
-functions and a method to certify attractivity of sets for uncertain nonlinear switched systems with state constraints. The approach relies on the construction of an
L
-function derived from controllability analysis, showing that the existence of a robust control contractive set ensures robust local attractivity of the set itself.
The applicability of the methodology across different system classes was demonstrated by linear examples and a nonlinear case study on antimicrobial resistance dynamics.
