Abstract
This paper develops a generalization of the line-search sequential quadratic programming (SQP) algorithm with ℓ 1 \ell_{1} -merit function that uses objective and constraint function approximations with tunable accuracy to solve smooth equality-constrained optimization problems. The evaluation of objective and constraint functions and their gradients is potentially computationally expensive, but it is assumed that one can construct effective, computationally inexpensive models of these functions. This paper specifies how these models can be used to generate new iterates. At each iteration, the models have to satisfy function error and relative gradient error tolerances determined by the algorithm based on its progress. Moreover, bounds for the model errors are used to explore regions where the combined objective function and constraint models are sufficiently accurate. The algorithm has the same first-order global convergence properties as a line-search SQP algorithm with ℓ 1 \ell_{1} -merit function, but only uses objective and constraint function models and the model error bounds. The algorithm is applied to a discretized boundary control problem in which the evaluation of the objective and constraint functions requires the solution of the Boussinesq partial differential equation (PDE). The models are constructed from projection-based reduced-order models of the Boussinesq PDE.



Keywords.
Constrained optimization, sequential quadratic programming, line-search, inexact functions, inexact gradients, reduced order model.

2.1
Step Computation

Let
c^{\prime}(x)\in\mathbb{R}^{m\times n}
denote the Jacobian of the constraints.
The first-order necessary conditions for (
1.1
) are

\nabla f(x)-c^{\prime}(x)^{T}\lambda=0\quad\mbox{ and }\quad c(x)=0.

(2.1)

Given the iterate
x_{k}
, the search direction
s_{k}
in the SQP method is chosen as the (approximate) solution of

\displaystyle\min\quad

\displaystyle\frac{1}{2}s^{T}H_{k}s+\nabla f(x_{k})^{T}s,

(2.2a)

s.t.

\displaystyle c(x_{k})+c^{\prime}(x_{k})s=0,

(2.2b)

where
H_{k}\in\mathbb{R}^{n\times n}
is a symmetric matrix that replaces the Hessian
\nabla^{2}_{xx}\mathcal{L}(x_{k},\lambda_{k})
.
The problem of finding the search direction can be seen as a quadratic approximation of the Lagrangian (
2.2a
)
subject to a linearization of the equality constraint (
2.2b
).

Assume that
c^{\prime}(x_{k})\in\mathbb{R}^{m\times n}
has rank
m
.
If
H_{k}
is symmetric positive semidefinite on the nullspace
{\cal N}(c^{\prime}(x_{k}))
, then
s_{k}\in\mathbb{R}^{n}
solves (
2.2
) if and only if

s_{k}\in\mathbb{R}^{n}
,
\lambda_{k+1}\in\mathbb{R}^{m}
solve the following KKT system (see
[
21
, Sec. 18.2]
)

\begin{bmatrix}H_{k}&-c^{\prime}(x_{k})^{T}\\
c^{\prime}(x_{k})&0\end{bmatrix}\begin{bmatrix}s_{k}\\
\lambda_{k+1}\end{bmatrix}=-\begin{bmatrix}\nabla f(x_{k})\\
c(x_{k})\end{bmatrix}.

(2.3)

Moreover, if
H_{k}
is symmetric positive definite on the nullspace
{\cal N}(c^{\prime}(x_{k}))
, then the KKT system (
2.3
)
has a unique solution and therefore, (
2.2
) has a unique solution.

One can also convert (
2.2
) to an unconstrained problem.
Again, assume that
c^{\prime}(x_{k})\in\mathbb{R}^{m\times n}
has rank
m
.
Let
s_{k}^{c}\in\mathbb{R}^{n}
be a particular solution of (
2.2b
).
For example,

could be set to the minimum norm solution of (
2.2b
) given by

s_{k}^{c}=-c^{\prime}(x_{k})^{T}(c^{\prime}(x_{k})c^{\prime}(x_{k})^{T})^{-1}c(x_{k}).

(2.4)

Let

P_{k}=I-c^{\prime}(x_{k})^{T}(c^{\prime}(x_{k})c^{\prime}(x_{k})^{T})^{-1}c^{\prime}(x_{k})\in\mathbb{R}^{n\times n}

(2.5)

be the projection onto
{\cal N}(c^{\prime}(x_{k}))
. If

is small, (
2.4
)
and (

Often the projection matrix (

) is not needed explicitly, but only
its application to vectors is required.

Because

satisfies the linearized constraints (
2.2b
) if and only if

s_{k}=s_{k}^{c}+P_{k}s_{k}^{0},

(2.6)

the equality constrained quadratic program (QP) (

) is equivalent to the unconstrained problem

\min_{s^{0}\in\mathbb{R}^{n}}\quad\frac{1}{2}(s^{0})^{T}\big(P_{k}H_{k}P_{k}\big)s^{0}+\Big(P_{k}\big(\nabla f(x_{k})+H_{k}s_{k}^{c}\big)\Big)^{T}s^{0}.

(2.7)

A vector
s_{k}\in\mathbb{R}^{n}
solves the equality constrained QP (
2.2
) if and only
if there exists a solution
s_{k}^{0}\in\mathbb{R}^{n}
of (
2.7
) such that
(
2.6
) holds.
The matrix
P_{k}H_{k}P_{k}
is singular with nullspace
{\cal N}(P_{k}H_{k}P_{k})={\cal N}(c^{\prime}(x_{k}))^{\perp}={\cal R}(c^{\prime}(x_{k})^{T})
, but
if
P_{k}H_{k}P_{k}
is positive definite on
{\cal N}(c^{\prime}(x_{k}))
, which is equivalent to
H_{k}
being positive definite on
{\cal N}(c^{\prime}(x_{k}))
,
then (
2.7
) has a solution
s_{k}^{0}\in\mathbb{R}^{n}
.
Because
P_{k}H_{k}P_{k}
is singular with nullspace
{\cal N}(P_{k}H_{k}P_{k})={\cal N}(c^{\prime}(x_{k}))^{\perp}={\cal R}(c^{\prime}(x_{k})^{T})

The unconstrained problem can be solved approximately, e.g., using the conjugate gradient method, which only uses

If an approximate solution (

This gives

From (

Numerical Results

This section considers a boundary control problem governed by the Boussinesq equations.
The unconstrained version of this boundary control problem was studied in

,
with emphasis on finite element discretization of the optimal control problem.
This section uses a change in notation.
The optimization variables are the control

4.1
Boundary Control of the Boussinesq PDE

Let
\Omega=(0,8)\times(0.5,1)\cup(1,8)\times(0,0.5)
be the domain given in Figure
4.1
.
Let
\Gamma_{\text{in}}=\{0\}\times(0.5,1)
be the inflow boundary,
\Gamma_{\text{out}}=\{8\}\times(0,1)
the outflow boundary,

\Gamma_{c}=((0,1)\times\{0.5\})\cup(\{1\}\times(0,0.5))
the channel boundary, and
\Gamma_{d}=\partial\Omega\setminus(\Gamma_{\text{in}}\cup\Gamma_{\text{out}}\cup\Gamma_{c})
the control boundary.
See Figure
4.1
for an illustration.

Figure 4.1:
Geometry of the backstep region with corresponding (coarse) finite element grid.

Given a temperature control
u
on
\Gamma_{d}
, the velocity
v
, temperature
T
, and pressure

are solutions to the nondimensional Boussinesq equations

\displaystyle-\frac{1}{Re}\Delta v(x)+(v(x)\cdot\nabla)v(x)+\nabla p(x)+\frac{Gr}{Re^{2}}T(x)\mathbf{g}

\displaystyle=0

\displaystyle x\in\Omega,

(4.1a)

\displaystyle\nabla\cdot v(x)

\displaystyle=0

\displaystyle x\in\Omega,

(4.1b)

\displaystyle-\frac{1}{RePr}\Delta T(x)+v(x)\cdot\nabla T(x)

\displaystyle=0

\displaystyle x\in\Omega,

(4.1c)

\displaystyle v(x)=0,\quad\frac{\partial T}{\partial n}(x)+T(x)

\displaystyle=u(x)

\displaystyle x\in\Gamma_{d},

(4.1d)

\displaystyle v(x)=0,\quad T(x)

\displaystyle=1

\displaystyle x\in\Gamma_{c},

(4.1e)

\displaystyle v(x)=d_{\text{in}}(x),\quad T(x)

\displaystyle=0

\displaystyle x\in\Gamma_{\text{in}},

(4.1f)

\displaystyle v(x)=d_{\text{out}}(x),\quad\frac{\partial T}{\partial n}(x)

\displaystyle=0

\displaystyle x\in\Gamma_{\text{out}}.

(4.1g)

In (
4.1
)

is the Reynolds number,
Gr
the Grashof number,
Pr
the Prandtl number,
n
is the outward unit normal,

,

are given Dirichlet velocity boundary data, set to

d_{\text{in}}(x)=\big(8(x_{2}-0.5)(1-x_{2}),\;0\big)^{T},\quad\mbox{ and }\quad d_{\text{out}}(x)=\big((1-x_{2})x_{2},\;0\big)^{T},

and
\mathbf{g}=(0,-1)^{T}
is the nondimensionalized gravitational acceleration.

We want to find a control

that minimizes recirculation in the subdomain

behind the step.
Recirculation is quantified using the integral of the vorticity squared. Moreover, we add a penalty term for the control.
Thus, the unconstrained optimal control problem is

\min_{u\in L^{2}(\Gamma_{d})}\quad\frac{1}{2}\int_{D}\big(\partial_{x_{1}}v_{2}(x;u)-\partial_{x_{2}}v_{1}(x;u)\big)^{2}dx+\frac{\omega}{2}\int_{\Gamma_{d}}u^{2}(x)dx,

(4.2)

where the velocity

, the pressure

, and the temperature

solve (
4.1
).
For the constrained version, we include a constraint on the temperature. Specifically, given the subdomain
\Omega_{T}=[1,8]\times[0,0.5]
behind the step,

\min_{u\in L^{2}(\Gamma_{d})}\;\frac{1}{2}\int_{D}\big(\partial_{x_{1}}v_{2}(x;u)-\partial_{x_{2}}v_{1}(x;u)\big)^{2}dx+\frac{\omega}{2}\int_{\Gamma_{d}}u^{2}(x)dx,\qquad\text{s.t.}\;\;\int_{\Omega_{T}}T^{2}(x;u)dx=T_{d},

where again the velocity

, the pressure
p(\cdot;u)
, and the temperature

solve (
4.1
).
Given Reynolds number

, Grashof number

, and
Pr

is

,

is computed using optimal temperature for the unconstrained problem (

The control penalty parameter is

\omega=10^{-2}.

4.2

The optimal control problem is discretized using a Taylor-Hood finite element approximation. See, e.g.,
[
11
]
.
Specifically, the finite element mesh is a uniform refinement of the mesh shown in Figure
4.1
.
The mesh used has either 3,168 (
Re=
10) or 8,800 (
Re=
100 and 200) triangles.
Piecewise quadratic elements are used for the velocity and the temperature, piecewise linear elements are used for the pressure.

The boundary control is approximated by

u_{h}(x)=\sum_{j=1}^{n_{u}}\mathbf{u}^{(j)}\varphi_{j}(x),

(4.4)

where
n_{u}=34
and
\varphi_{j}
are the control basis functions.
The basis functions are shifted versions of the following two functions

H_{1}(x_{1}):=\begin{cases}(x_{1}+1)^{2}(1-2x_{1})&-1<x_{1}\leq 0,\\
(1-x_{1})^{2}(1+2x_{1})&0<x_{1}\leq 1,\end{cases}\qquad H_{2}(x_{1}):=\begin{cases}x_{1}(x_{1}+1)^{2}&-1<x_{1}\leq 0,\\

The first 18 basis functions correspond to the top boundary
[0,8]\times\{1\}
, with one each of
H_{1}
and
H_{2}
centered at the grid points

,

\varphi_{2j+1}(x)=H_{1}(x_{1}-j),\quad\varphi_{2j+2}(x)=H_{2}(x_{1}-j)\qquad x\in[0,8]\times\{1\},\quad j=0,\ldots,8.

The remaining 16 basis functions correspond to the bottom boundary
[1,8]\times\{0\}

\varphi_{2j+17}(x)=H_{1}(x_{1}-j),\quad\varphi_{2j+18}(x)=H_{2}(x_{1}-j)\qquad x\in[1,8]\times\{0\},\quad j=1,\ldots,8.

where

The discretization of the unconstrained problem (

4.3

We use a Galerkin ROM. In the
k
-th outer iteration, the FOM (
4.5
) is approximated by the ROM

\mathbf{V}_{k}^{T}\mathbf{R}(\mathbf{V}_{k}\mathbf{y};\mathbf{u})=\mathbf{V}_{k}^{T}\mathbf{R}\big(\mathbf{V}_{k}(\mathbf{v},\mathbf{p},\mathbf{T})^{T};\mathbf{u}\big)=\mathbf{0}.

(4.8)

The ROM matrix
\mathbf{V}_{k}
has block diagonal structure with diagonal blocks

\mathbf{V}^{y}\in\mathbb{R}^{|\mathcal{F}_{y}|\times r_{y}}
,
\mathbf{V}^{p}\in\mathbb{R}^{n_{p}\times r_{p}}
,
\mathbf{V}^{t}\in\mathbb{R}^{|\mathcal{F}_{T}|\times r_{T}}
corresponding
to velocity, pressure, and temperature components of the state.

To construct a new model at step
k
of the ROM based optimization algorithm (see line
5
in Algorithm
4
),
information from the FOM at the current iterate
\mathbf{u}_{k}
is used.
The FOM state equation (
4.5
) is solved for
\mathbf{y}(\mathbf{u}_{k}),\mathbf{p}(\mathbf{u}_{k}),\mathbf{T}(\mathbf{u}_{k})
.
In addition, the FOM adjoint equation is solved for
\mbox{\boldmath$\lambda$}_{\mathbf{y}}(\mathbf{u}_{k}),\mbox{\boldmath$\lambda$}_{\mathbf{p}}(\mathbf{u}_{k}),\mbox{\boldmath$\lambda$}_{\mathbf{T}}(\mathbf{u}_{k})

and the FOM sensitivities
\mathbf{y}_{\mathbf{u}}(\mathbf{u}_{k}),\mathbf{p}_{\mathbf{u}}(\mathbf{u}_{k}),\mathbf{T}_{\mathbf{u}}(\mathbf{u}_{k})
are computed.
Since different solutions have different scales, they are orthonormalized individually and then orthonormalized again to
compute

\displaystyle\widetilde{}\mathbf{V}^{y}

\displaystyle=\text{orth}\Big(\big[\text{orth}([\mathbf{y}(\mathbf{u}_{1}),\ldots,\mathbf{y}(\mathbf{u}_{k})]),\,\text{orth}([\mbox{\boldmath$\lambda$}_{\mathbf{y}}(\mathbf{u}_{1}),\ldots,\mbox{\boldmath$\lambda$}_{\mathbf{y}}(\mathbf{u}_{k})]),\,\text{orth}(\mathbf{y}_{\mathbf{u}}(\mathbf{u}_{k}))\big]\Big),

\displaystyle\mathbf{V}^{p}

\displaystyle=\text{orth}\Big(\big[\text{orth}([\mathbf{p}(\mathbf{u}_{1}),\ldots,\mathbf{p}(\mathbf{u}_{k})]),\,\text{orth}([\mbox{\boldmath$\lambda$}_{\mathbf{p}}(\mathbf{u}_{1}),\ldots,\mbox{\boldmath$\lambda$}_{\mathbf{p}}(\mathbf{u}_{k})]),\,\text{orth}(\mathbf{p}_{\mathbf{u}}(\mathbf{u}_{k}))\big]\Big),

\displaystyle\mathbf{V}^{t}

\displaystyle=\text{orth}\Big(\big[\text{orth}([\mathbf{T}(\mathbf{u}_{1}),\ldots,\mathbf{T}(\mathbf{u}_{k})]),\,\text{orth}([\mbox{\boldmath$\lambda$}_{\mathbf{T}}(\mathbf{u}_{1}),\ldots,\mbox{\boldmath$\lambda$}_{\mathbf{T}}(\mathbf{u}_{k})]),\,\text{orth}(\mathbf{T}_{\mathbf{u}}(\mathbf{u}_{k}))\big]\Big).

To ensure stability of the ROM, the velocity ROM is enriched following
[
24
]
.
See
[

for implementation details. The velocity ROM is

\mathbf{V}^{y}=\text{orth}\Big(\big[\widetilde{}\mathbf{V}^{y},\mathbf{V}^{y}_{\text{enr}}\big]\Big)
.

5
Conclusions

We have introduced a generalized line-search SQP algorithm with
\ell_{1}
-merit function
that uses objective function and constraint function models with tunable accuracy for the solution of smooth equality-constrained optimization problems.
The algorithm was motivated by an algorithm developed in
[
14
]
for unconstrained problems.
Our algorithm leverages efficient approximate models with error bounds and tunable accuracy to reduce the number of expensive objective and constraint function evaluations.
We presented a general convergence result for our generalized line-search SQP algorithm and provided the details of an implementable algorithm.
Specifically, we proved that our algorithm has the same first-order global convergence properties as the traditional line-search SQP algorithm with
\ell_{1}
-merit function,
provided the objective and constraint function models meet the required accuracy requirements. Our algorithm only uses these models and
corresponding error functions, but never directly accesses the original objective function. The accuracy requirement of the model are adjusted
to the progress of the optimization algorithm.
In addition, we proved that for a large class of commonly used model functions based on ROMs, the constructed models meet the
accuracy requirements specified by our algorithm.

Our algorithm was applied to a boundary control problem governed by the Boussinesq PDE, and models were computed using ROMs.
We demonstrated that with appropriately chosen models, the algorithm demonstrates significant reductions both in the number of outer iterations
and in the number of expensive full-order PDE solves required to reach an optimal solution, when compared to optimization strategies
using solely exact objective and constraint function information.

There are several avenues for future research.
Currently, no hyperreduction is used in the Boussinesq PDE ROMs. However, it seems possible to adapt the
techniques from
[
26
]
to introduce hyperreduction in a systematic way to arrive at truly
efficient algorithms. This would combine the hyperreduction of
[
26
]
with the comprehensive
convergence analysis of our optimization algorithm.

As reported in
[
14
]
for unconstrained problems, the construction of the ROM
has a big impact on the overall performance. We include sensitivity information to construct ROMs, which has shown
to be beneficial, e.g., in
[
14
]
,
[
25
]
,
However, when sensitivity information is added, the ROM size depends on the number of optimization variables.
The shape optimization examples in
[
14
]
,
[
25
]

have a relatively small number of shape parameters and ROM sizes stay small, whereas in our example, the number of
discrete controls was relatively large (
n_{u}=34
), resulting in larger ROMs. Exploration of other ROM constructions will be
beneficial.

Finally, numerical exploration using different asymptotic error estimates on the overall performance are useful.
For unconstrained problems, results in this direction are contained in
[
13
, Ch. 3]
.
