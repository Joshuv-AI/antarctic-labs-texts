GENCAT: Generative Computerized Adaptive Testing
Wanyong Feng, Andrew Lan

Abstract
Existing computerized Adaptive Testing (CAT) frameworks are typically built on predicting the correctness of a student response to a question. Although effective, this approach fails to leverage textual information in questions and responses, especially for open-ended questions. In this work, we propose GENCAT ( GEN erative CAT ), a novel CAT framework that leverages Large Language Models for knowledge estimate and question selection. First, we develop a Generative Item Response Theory (GIRT) model that enables us to estimate student knowledge from their open-ended responses and predict responses to unseen questions. We train the model in a two-step process, first via Supervised Fine-Tuning and then via preference optimization for knowledge-response alignment. Second, we introduce three question selection algorithms that leverage the generative capabilities of the GIRT model, based on the uncertainty, linguistic diversity, and information of sampled student responses. Third, we conduct experiments on two real-world programming datasets and demonstrate that GENCAT outperforms existing CAT baselines, achieving an AUC improvement of up to 4.32% in the key early testing stages.



1
Introduction and Background

Computerized Adaptive Testing (CAT) adaptively selects questions (or items) for students (or test takers) based on their prior responses in a psychometric or educational assessment. This approach creates a personalized testing pathway: students who struggle receive easier questions, while high-performers receive more challenging ones. As a result, CAT effectively reduces the number of questions required to accurately estimate the ability (or knowledge) of each student
[
30
,
18
]
. A standard CAT framework consists of three components (see
[
14
]
for an overview):

The first component is the response model, which specifies how the probability of answering a question correctly depends on the student knowledge and the question difficulty. After receiving responses from students, CAT updates the current student knowledge estimate under the response model, typically using maximum-likelihood or Bayesian estimate
[
32
]
. Most response models are based on Item Response Theory (IRT); the simplest form, the one-parameter logistic (1PL) model, defines the probability that student
i
answers question
j
correctly as:

\Pr(Y_{i,j}=1)=\sigma(\theta_{i}-b_{j}),

where
Y_{i,j}\in\{0,1\}
indicates correctness,
\sigma(\cdot)
is the sigmoid function,
\theta_{i}\in\mathbf{R}
is the student knowledge, and
b_{j}\in\mathbf{R}
is the question difficulty
[
17
,
22
]
.
The 1PL model is typically extended in two ways. First, by introducing additional parameters related to the question, such as discrimination (2PL), representing question sensitivity to differences in student knowledge, and guessing (3PL), representing the probability of answering the question correctly by chance. Second, by modeling student knowledge as a vector (MIRT), which allows for a granular representation across multiple knowledge components rather than a single scalar.
[
7
,
23
]
.

The second component is the question bank, which contains a set of candidate questions, each associated with parameters characterizing its difficulty (for 1PL IRT) and other properties. These properties are typically estimated from historical student response data
[
27
]
and remain fixed during the testing process.

The third component is the question-selection algorithm, which selects the next
most informative
question over a sequence of time steps. At time step
t
, we observe the student responses to the previous
t-1
questions, leading to a knowledge estimate
\hat{\theta}_{i}^{(t-1)}
. The question selection algorithm evaluates the remaining questions in the question bank and selects the one expected to be most informative, given
\hat{\theta}_{i}^{(t-1)}

[
31
]
. Under the 1PL IRT model, informativeness is often measured through the Fisher information
[
5
]
of question
j
, given by:

I_{j}(\theta)=\sigma(\theta-b_{j})\bigl(1-\sigma(\theta-b_{j})\bigr).

The fisher information is maximized when the predicted probability of student answering the question correctly is closest to 0.5, meaning the question is neither too easy nor too difficult for the current student knowledge estimate. This criteria mirrors the principle of uncertainty sampling in active learning
[
15
]
, a strategy widely adopted in the NLP community to minimize human annotation costs. By only selecting the data samples where the model is most uncertain for human labeling, Active Learning drastically reduces the cost to train high-performing models
[
34
,
2
]
.

Recent research works have sought to improve the CAT framework by developing more advanced response models and data-driven question-selection algorithms. BECAT
[
36
]
minimizes student knowledge estimate error by treating question selection problem as a data summarization problem, selecting the subset of questions that best approximates the information in the full test bank. GMOCAT
[
33
]
improves the question selection algorithm by utilizing a graph-enhanced multi-objective. NCAT
[
35
]
treats the question selection problem as a reinforcement learning problem, training a policy network to optimize prediction accuracy on held-out test questions. BOBCAT
[
13
]
frames the task as a bilevel optimization problem that jointly learns a response model and question selection algorithm to optimize prediction accuracy on held-out test questions. More recently, LACAT
[
6
]
enhances question selection interpretability by utilizing a multi-agent LLM framework that contains a Summarizer, Reasoner, and Critic to generate human-interpretable explanations for question selection.

Despite these advances, a critical limitation in CAT remains in how it utilizes question and response data. With the exception of LACAT, which utilizes question text for reasoning, most existing CAT frameworks simply represent questions as scalar-valued parameters (difficulty, etc.), discarding the rich textual information contained in the question. Moreover, even LACAT still rely on a key simplifying assumption regarding the student response: reducing the student response to binary-valued (1 for correct, 0 for incorrect). This binary abstraction is fine for closed-form questions such as multiple-choice, but ignores critical diagnostic information embedded in open-ended questions such as programming, mathematical reasoning, and essay-type questions; student open-ended responses often contains rich information on their knowledge, such as whether they exhibit specific errors and misconceptions. Therefore, it remains to be seen whether there can be a CAT regime that exploits open-ended student responses to further reduce test length.

To address this limitation, we propose the

). GENCAT leverage large language models (LLMs) in two components of CAT, both response model and question-selection algorithm.

Our code is publicly available at
https://github.com/umass-ml4ed/GENCAT

Our contributions are summarized as follows:

First, we develop a novel Generative Item Response Theory (GIRT) model that predicts/generates student open-ended responses, not just their correctness. We use a two-step training process to build this model: first supervised fine-tuning (SFT), followed by further aligning predicted responses with student knowledge using Direct Preference Optimization
[
21
]
(DPO). We found that this alignment step is necessary to training an informative GIRT model.

Second, we experiment with three novel question-selection algorithms that leverage the LLM-based generative capabilities of GIRT model, going beyond existing algorithms based on binary-valued response correctness prediction.
We explore three different criteria, including the amount of uncertainty of the generated student response correctness, linguistic diversity in the generated student responses, and information contained in the generated student responses.

Third, we conduct extensive quantitative and qualitative experiments on two real-world datasets that enable us to validate GENCAT. Both datasets track each student responses to multiple open-ended programming questions in computer science education. Results demonstrate that GENCAT leads to significantly more accurate knowledge estimate than traditional CAT baselines, particularly in the early stages of testing. Notably, our diversity-based question selection algorithm achieves an AUC improvement of up to 4.32% over the traditional CAT baseline at the initial stages of CAT, while our information-based question selection algorithm consistently outperforms numerous baselines across all test stages.

We acknowledge that our work represents a first exploration into this new CAT regime, with many limitations. In particular, our experiments are limited to a single domain, but we have no choice: open-ended datasets in other domains, such as short-answer math
[
19
]
, science
[
10
]
, and essay writing
[
28
]
that contain open-ended student responses but do not contain the same student responses to multiple questions. Therefore, we cannot use them to validate GENCAT. We will release our code and call on other researchers who may have access to open-ended response data in other domains to continue the work.

Methodology

In this section, we formally define the data format, detail the components of our GENCAT framework.

2.1
Data Format

Let
\mathcal{U}=\{u_{1},u_{2},\dots,u_{I}\}
denote the set of
I
students and
\mathcal{Q}=\{q_{1},q_{2},\dots,q_{J}\}
denote the set of
J
programming questions. We define the set of distinct knowledge components (KCs)
as
\mathcal{K}=\{k_{1},k_{2},\dots,k_{M}\}
. A KC represents a fundamental knowledge/skill required to answer a programming question (e.g., loops, arrays, and arithmetic operations). Thus, each programming question
q_{j}\in\mathcal{Q}
is denoted as a tuple
(p_{j},\mathcal{K}_{j})
, where
p_{j}
is the question text sequence and
\mathcal{K}_{j}\subseteq\mathcal{K}
is the subset of KCs associated with the question. We define the dataset of student responses as
\mathcal{R}=\{x_{i,j}\mid(i,j)\in\Omega\}
, where
\Omega\subseteq\{1\dots I\}\times\{1\dots J\}
represents the set of observed student responses, which covers the case when not every student responds to every question. Each data point
x_{i,j}
corresponds to the response from student
u_{i}
for programming question
q_{j}
and is defined as:

x_{i,j}=(c_{i,j},a_{i,j},q_{j})
,
where
c_{i,j}
is the student
i
’s response, which is a sequence of code tokens, and
a_{i,j}\in[0,1]
is the response correctness, usually given by the portion of the unit test cases being passed.

2.2
Generative Item Response Theory Model

Inspired by
[
8
]
, we represent the explicit knowledge of student
u_{i}
as a vector of mastery levels across all
M
distinct KCs, denoted as
\mathbf{\theta}_{i}=(\theta_{i,1},\theta_{i,2},\dots,\theta_{i,M})
, where each scalar
\theta_{i,m}\in[0,1]
reflects the student mastery of the
m
-th KC. Directly learning
\mathbf{\theta}_{i}
assumes independence among KCs, which is unrealistic in educational domains like programming where skills are highly correlated (e.g., mastery of arrays often implies mastery of loops). Ignoring these interdependencies can lead to inaccurate knowledge representation and estimate, especially when we only observe a small number of responses per student. Therefore, we introduce a low-dimensional latent knowledge representation
\mathbf{z}_{i}\in\mathbf{R}^{D}
(
D\ll M
).
We project this latent knowledge into the explicit knowledge space using a multilayer perceptron (MLP) parameterized by
\epsilon
, followed by a sigmoid activation to constrain the mastery levels to the unit interval:
\mathbf{\theta}_{i}=\sigma(\mathrm{MLP}_{\epsilon}(\mathbf{z}_{i})).

Given a question
q_{j}
with text
p_{j}
and associated KCs
\mathcal{K}_{j}
, our goal is to predict the student open-ended response, i.e., code
c_{i,j}
, using an LLM parameterized by
\phi
to characterize
P_{\phi}(c_{i,j}\mid q_{j},\mathbf{\theta}_{i})
.
To jointly learn the student latent knowledge
\mathbf{z}_{i}
, the projection parameters
\epsilon
, and the LLM parameters
\phi
, we must make the scalar-valued KC mastery levels adaptable to the LLM’s input space. Therefore, we use a differentiable transformation
g:[0,1]\to\mathbf{R}^{H}
, which maps a scalar mastery level to a continuous embedding vector compatible with the LLM’s hidden dimension
H
. Specifically, for each KC
k\in\mathcal{K}_{j}
, we compute a mastery embedding
\mathbf{e}_{i,k}=g(\theta_{i,k})
. In our implementation,
g(\cdot)
is a linear interpolation between the pre-trained embeddings of the semantic tokens “TRUE” and “FALSE”:

\mathbf{e}_{i,k}=\theta_{i,k}\cdot\mathbf{e}^{\text{TRUE}}+(1-\theta_{i,k})\cdot\mathbf{e}^{\text{FALSE}}.

This soft prompting approach enables the LLM to leverage its pre-trained semantic understanding to represent KC mastery. A higher mastery value
\theta_{i,k}
shifts the representation closer to “TRUE”, signaling higher master level of KC
k
to LLM. These embeddings are injected into the input prompt using a structured template:
“KC 1: <
k
>. The student has knowledge of <
k
>: <
\mathbf{e}_{i,k}
>…”
. The LLM then generates the predicted code response conditioned on this knowledge-augmented prompt. See one specific example in Figure
1
. See Appendix
8
for the exact prompt we used.

2.3
Model Training

For a single observed data sample
x_{i,j}\in\mathcal{R}
, we define the generative loss as the negative log-likelihood of the student response
c_{i,j}
given the question text and the student latent knowledge:

\mathcal{L}_{i,j}^{\text{SFT}}=-\sum_{t=1}^{|c_{i,j}|}\log P_{\phi,\epsilon}(c^{(t)}_{i,j}\mid c^{(<t)}_{i,j},q_{j},z_{i}).

Although the LLM’s generation is conditioned on student knowledge, optimizing the generative objective alone does not guarantee that the explicit knowledge
\mathbf{\theta}_{i}
are aligned with the actual student performance. In student modeling, we need to enforce model monotonicity, i.e., higher KC mastery leads to higher probability of a correct response. Without this constraint, the estimated student explicit knowledge levels may not be interpretable. Therefore, we introduce an auxiliary alignment loss to align student explicit knowledge with correctness of the open-ended response,
a_{i,j}
. We first take the average knowledge of the student on the associated KCs,
\mathcal{K}_{j}
, and use it as the predicted correctness, i.e.,
\hat{a}_{i,j}=\frac{1}{|\mathcal{K}_{j}|}\sum_{k\in\mathcal{K}_{j}}\theta_{i,k}.

We then apply a binary cross-entropy loss between this predicted success probability and the ground-truth correctness score, i.e.,

\mathcal{L}_{i,j}^{\text{KC}}=-\bigl[a_{i,j}\log\hat{a}_{i,j}+(1-a_{i,j})\log(1-\hat{a}_{i,j})\bigr],

for a single data point
x_{i,j}
. We note that
a_{i,j}
can either be continuous or binary-valued, i.e.,
a_{i,j}=1
if the student code passes all test cases and
a_{i,j}=0
otherwise. Although this choice does not affect the binary cross-entropy loss, we follow standard IRT literature and use
a_{i,j}\in\{0,1\}
in what follows.
Finally, we combine the two losses using a hyperparameter
\lambda\in[0,1]
. The total loss for a single data sample is:
\mathcal{L}_{i,j}=(1-\lambda)\mathcal{L}_{i,j}^{\text{SFT}}+\lambda\mathcal{L}_{i,j}^{\text{KC}}.

Finally, the global training objective is the average loss over the entire set of observed data samples
\mathcal{R}
:

\mathcal{L}_{\text{Total}}(z,\epsilon,\phi)=\frac{1}{|\mathcal{R}|}\sum_{x_{i,j}\in\mathcal{R}}\mathcal{L}_{i,j}.

We train the stduent lantent knowledge (
z
), MLP (
\epsilon
), and LLM (
\phi
) end-to-end by optimizing these parameters together to minimize
\mathcal{L}_{\text{Total}}
.

2.4
Knowledge-Response Alignment

While GIRT model is designed to generate the student response conditioned on the student knowledge, we observe that SFT alone fails to reliably enforce this dependency. Specifically, the post-SFT GIRT model suffers from mode collapse, generating semantically identical responses for some questions regardless of the input student knowledge. In other words, the GIRT model ignores the input student knowledge and fails to mimic errors made by struggling students or capture the diversity among correct responses. Therefore, we employ DPO to perform another alignment stage between student knowledge and the model’s generated response.

Inspired by the preference pair construction method in
[
26
]
, we construct them by evaluating the likelihood of a response given the student latent knowledge, which is given under the continuous Bernoulli distribution
[
16
]
as

P(a_{i,j}\mid z_{i})=\hat{a}_{i,j}^{a_{i,j}}\cdot(1-\hat{a}_{i,j})^{1-a_{i,j}}.

For a specific data sample
x_{i,j}
, we pair student
u_{i}
’s actual response
c_{i,j}
(preferred) with a response
c_{i^{\prime},j}
from another student
u_{i^{\prime}}
(dispreferred). We select
c_{i^{\prime},j}
only if it is significantly less likely to be responded by student
u_{i}
, i.e., the two having a response correctness likelihood difference that exceeds a threshold
\tau
:

P(a_{i,j}\mid z_{i})-P(a_{i^{\prime},j}\mid z_{i})>\tau.

We pair the preferred response with
M
dispreferred responses with the highest likelihood differences to form
M
preference pairs for DPO training. To ensure a stable alignment target, i.e., student explicit knowledge, we keep them frozen to their learned values after SFT during DPO training.

2.5
CAT Cycles

CAT represents an iterative process that alternates between selecting the most informative question and updating the student knowledge estimate. Next, we detail our iterative process while focusing on a single student
u_{i}
. Let
\mathcal{Q}_{i}\subseteq\mathcal{Q}
denote the set of candidate questions available to the student. Each CAT time step consists of three phases:

•

Initialization
To warm-start the CAT iterations before observing any responses for a new student, we initialize their latent knowledge
\mathbf{z}_{i}^{(0)}
using the population average. Specifically, we compute the average of latent knowledge vectors across all students in GIRT model training and use it as the prior knowledge for student
u_{i}
.

•

Response Sampling
At each time step
t
, we evaluate the set of remaining candidate questions
\mathcal{Q}_{i,t}
. For every candidate question
q_{j}\in\mathcal{Q}_{i,t}
, we use the GIRT model to sample
N
responses based on student latent knowledge estimate
z_{i}^{(t-1)}
from previous time step:

\hat{c}_{i,j}^{(n)}\sim P_{\phi,\epsilon}(\cdot\mid q_{j},z_{i}^{(t-1)}),\quad n=1,\dots,N.

We then apply one of the question-selection algorithms (detailed below in Sections
2.6
) to these sampled responses and select the next question,
q_{j^{*}}
, for the student.

•

Knowledge Update
After observing their actual response
c_{i,j^{*}}
to
q_{j^{*}}
, we update the student latent knowledge while keeping the GIRT model parameters (
\phi,\epsilon
) fixed. We update the latent knowledge
\mathbf{z}_{i}
via gradient descent to minimize the total loss across the student responses to all observed questions.

We visualize the iterative process in Figure
1
.

2.6
Question Selection Algorithms

Given the sampled responses of question
q_{j}
, we explore three algorithms to select the next question among all candidates, each using a different way to evaluate question informativeness:

•

Uncertainty-Based
This algorithm selects the question with the maximum response correctness prediction uncertainty. Inspired by the informativeness used in traditional 1PL CAT selection algorithm, we assume that the question with a predicted correctness closest to 0.5 contains the most information on student knowledge. For a candidate question
q_{j}
, we first evaluate the
N
sampled responses using a trained scoring model, which takes the question and response as input and outputs a continuous correctness score
\hat{a}_{i,j}^{(n)}\in[0,1]
. We then compute the uncertainty metric
U_{j}
as 1 minus the absolute distance between the average correctness score and 0.5:

U_{j}=1-\left|\left(\frac{1}{N}\sum_{n=1}^{N}\hat{a}_{i,j}^{(n)}\right)-0.5\right|.

We select the question with the maximum
U_{j}
. The training detail of the scoring model can be found in Appendix
A
. We denote this question selection algorithm as
Uncertainty
.

•

Diversity-Based
This algorithm selects the question with the most semantically diverse set of generated responses. The sampled responses having high diversity indicates that the GIRT model is unsure of the student possible response to the question, reflecting a high degree of uncertainty. For a candidate question
q_{j}
, we first use a pre-trained
CodeBERT
model
[
12
]
to obtain code semantic embedding vectors
\{\mathbf{h}_{j_{n}}\}_{n=1}^{N}
for the
N
sampled responses. We then compute 1 minus the average pairwise cosine similarity
S_{j}
between these embeddings:

S_{j}=1-\left[\frac{2}{N(N-1)}\sum_{n=1}^{N}\sum_{m=n+1}^{N}\frac{\mathbf{h}_{j_{n}}\cdot\mathbf{h}_{j_{m}}}{\lvert\mathbf{h}_{j_{n}}\rvert\,\lvert\mathbf{h}_{j_{m}}\rvert}\right].

We select the question with the maximum
S_{j}
. We denote this question selection algorithm as
Diversity
.

•

Information-Based
This algorithm selects the question with the maximum Fisher Information (specifically, utilizing the T-optimality criteria
[
20
]
), which measures the expected amount of reduction in uncertainty in the student knowledge after observing their response. For a candidate question
q_{j}
, we compute the Fisher Information as the trace of the Fisher information matrix w.r.t. the latent knowledge vector
\mathbf{z}_{i}
:

\mathcal{I}(q_{j})\!=\!\mathbf{E}_{\hat{c}_{i,j}}\!\left[\!\left\|\!\nabla_{\mathbf{z}_{i}}\!\!\log P_{\phi,\epsilon}\!\left(\!\hat{c}_{i,j}\!\mid\!q_{j},\mathbf{z}_{i}^{(t-1)}\!\right)\!\right\|_{2}^{2}\!\right]\!.

We select the question with the maximum
\mathcal{I}(q_{j})
. We denote this question selection algorithm as
Information
.

3
Experimental Evaluation

We now detail experiments that we conduct to validate GENCAT on a real-world dataset.

3.1
Datasets Details

We evaluate GENCAT on two datasets: the first one is the
CodeWorkout
dataset
[
11
]
, which was originally released as part of the Second CSEDM Data Challenge
[
4
]
. This dataset consists of real-world open-ended Java code submissions collected from students in an introductory computer science course. Each question in the dataset is associated with a set of human-written KCs, with 18 distinct KCs in total. The dataset comprises 246 students and 50 programming questions. Following prior work
[
29
,
8
]
, we only analyze student first submission to each problem. After this filtering process, the final dataset contains 10,834 distinct student submissions in total.

The second one is the
ProgFeed
dataset, which is a new dataset created by us. This dataset consists of real-world open-ended Python code submissions collected from students in an introductory computer science course. Each question in the dataset is associated with a set of human-written KCs, with 10 distinct KCs in total. The dataset comprises 374 students, 42 programming questions, and 8724 distinct student submissions in total for the first submission. We emphasize that ProgFeed is private at the moment, and we are in the process of IRB review. We cannot guarantee that we will make it publicly available.

For data splitting, we use 5-fold cross-validation to ensure robust results. In each fold, we randomly partition students into a GIRT model training group (80%) and a CAT evaluation group (20%). For students in the GIRT model training group, we further split their question responses into training, validation, and testing sets with a ratio of 8:1:1 for CodeWorkout, and into training and testing with a ratio of 7:3 for ProgFeed. For students in the CAT evaluation group, we hold out a test set of 10 questions for CodeWorkout, and 5 questions for ProgFeed to evaluate whether the estimated student knowledge can accurately predict their response on the test set, following
[
13
]
. The remaining questions form the candidate question set for the question selection algorithm to select from. The size of the candidate question set is at least 30 for CodeWorkout and 20 for ProgFeed. We provide further details on the data splitting in Appendix
E
.

3.2
Baselines

We compare GENCAT against four representative CAT baselines:

1PL_IRT
: The standard baseline in the CAT literature. It models the probability of a correct response under the 1PL IRT model and selects the next question with maximum Fisher Information.

BOBCAT
: A data-driven framework that jointly learns both the response model and the question selection algorithm, using bilevel optimization to minimize prediction error on test set.

NCAT
: A follow-up to BOBCAT that use reinforcement learning to learn a policy that maximizes prediction accuracy on test set.

LACAT
: An LLM agent-based framework that uses multiple agents to decide which question to select next. However, unlike GENCAT, it still relies on binary-valued response correctness rather than open-ended responses.

3.3
Experimental Setup and Metrics

The GIRT model uses
Llama-3.2-1B-Instruct

[
9
]
as the backbone LLM. The student latent knowledge is projected into explicit knowledge (KC mastery levels) space using a 3-layer MLP with ReLU activations. More training details can be found in the Appendix
D
.

The primary goal of CAT is to accurately estimate student knowledge using fewer questions. However, in a real-world student response dataset, student true knowledge are not directly given. Therefore, we use the estimated student knowledge to predict their responses on test set, which acts as a proxy for knowledge estimate accuracy. We use
Accuracy
and
AUC
as metrics for this binary prediction task.

Unlike standard CAT frameworks like 1PL_IRT, BOBCAT, and NCAT, GENCAT and LACAT lack a probabilistic item response model for binary classification. To evaluate the informativeness of their selected questions, we use the pre-trained 1PL IRT model as a proxy item respones model to update student knowledge estimates and predict correctness, thereby enabling fair performance comparison. We leave studying the performance of GENCAT under different item response models to future work.

We also test the knowledge estimate accuracy by checking the similarity of the generated student responses based on knowledge estimate to the ground truth responses on the test set on CodeWorkOut dataset. The details are in the Appendix
C
.

Quantitative Results

GENCAT excels in early-stage knowledge estimate.
We report the 5-fold averaged knowledge estimate performance (Accuracy and AUC) of GENCAT and four baselines across test lengths ranging from

outperforming strong baselines like 1PL_IRT (0.7299) and NCAT (0.7343) on the Codeworkout dataset. This performance improvement stems from GENCAT’s ability to leverage both the question text and the student open-ended responses to select questions, shifting the focus from predicting whether a student will fail to how they might fail. By evaluating these sampled responses, GENCAT captures valuable information about student knowledge, such as specific errors or misconceptions the student might have.
As the test progresses and the knowledge estimate stabilizes in the later time steps, GENCAT still maintains the best accuracy on both datasets. The performance gap naturally narrows, though, since all CAT methods converge to the same performance when a student responds to every question.

Performance varies with selection algorithm across test lengths.
Comparing our three question selection algorithms on the CodeWorkout dataset, we observe that depending on the stage of the test, the best-performing algorithm differs. Diversity performs when
t
is small; when
t=1
, Diversity reaches an AUC of 0.7073, compared to 0.6854 for Information. This difference suggests that maximizing response diversity is effective when the student knowledge estimate does not diverge much from its initialized, prior value (
\mathbf{z}_{i}^{(0)}
). Conversely, Information achieves the best performance when
t
increases. For instance, when
t=15
, Information reaches an AUC of 0.7842, compared to 0.7801 for Diversity. This difference suggests that when the student knowledge estimate becomes more accurate, gradient-based Information is better suited for refining the knowledge estimate in the later phase of the test. Finally, Uncertainty generally yields lower AUC values than the other two question selection algorithms at each stage. This result suggests that relying solely on the correctness of simulated code might be insufficient for optimal question selection, which further emphasizes the need to explicitly model the open-ended student responses. However, on the ProgFeed dataset, Information is always the best-performing algorithm. The potential reason Information is better than Diversity is that the GIRT model has limited ability to generate diversified code given the student submissions are only 4-5 lines for most of the questions.

Baselines are limited by data sparsity and knowledge representation abstraction.

BOBCAT achieves the lowest performance among all baselines, likely because its bilevel optimization objective is data-hungry and may not work well when the number of question is small (for example, 50 in CodeWorkout compared to at least 1000 in datasets it was evaluated on). While LACAT uses strong LLM agents (
GPT-3.5-turbo-16k
) for question selection, it underperforms GENCAT on most time steps (e.g., AUC of 0.7104 vs 0.7529 at
t=5

\theta
from 1PL to guide its agents to select questions. The agents are forced to reason over a highly compressed scalar representation of knowledge, which is a naturally hard task. In contrast, GENCAT represents student knowledge as mastery of granular KCs, which is more specific and interpretable to LLMs.

5
Conclusions and Future Work

In this paper, we proposed GENCAT, a novel Generative CAT framework that leverages LLMs to exploit the rich information embedded in question text and open-ended student responses to estimate student knowledge. We showed that our GIRT model can effectively associate student knowledge and their responses to open-ended questions. We also showed that our three novel question-selection algorithms that utilize the generative capabilities of the GIRT model outperforms existing CAT baselines, particularly in the key early stages of testing.

For future work, we will focus on addressing the limitations of GENCAT. First, we plan to investigate into other domains and subjects, such as mathematical reasoning, essay writing, and language learning, depending on the data availability. Open-ended questions are common in these domains, which enable us to validate the generalizability of our framework. Second, we need to reduce the computational cost associated with response sampling during question selection, to facilitate real-time deployment because minimizing waiting time is essential to
maintain student engagement. Finally, we intend to explore automated KC discovery to reduce the reliance on human annotation and improve adaptation in new scenarios.

Appendix A
Scoring Model for Student Response

For the scoring model used in Uncertainty question selection algorithm, we use
Llama-3.2-1B-Instruct
as the backbone LLM. Given a data point
x_{i,j}
with question text
p_{j}
and a student response
c_{i,j}
, our goal is to predict the continuous correctness score
\hat{a}_{i,j}\in[0,1]
that approximates the ground-truth unit-test outcome
a_{i,j}
.

We formulate the input by concatenating the problem text
p_{j}
and student response
c_{i,j}
into a single prompt sequence. The detailed prompt is in Appendix
9
. To generate a continuous score from the LLM, we adopt the logit-interpolation method described in
[
25
]
. Specifically, we extract the logits corresponding to the tokens for “Correct” (1) and “Incorrect” (0) from LLM’s output at the last token position of the input sequence, denoting them as
l_{1}
and
l_{0}
respectively. We then compute the predicted correctness score
\bar{a}_{i,j}
by normalizing these two extracted logits using softmax function:

\bar{a}_{i,j}=\frac{e^{l_{1}}}{e^{l_{0}}+e^{l_{1}}}.

For a single data point
x_{i,j}\in\mathcal{R}
, we define the loss as the binary cross-entropy between the predicted score
\bar{a}_{i,j}
and the ground-truth score
a_{i,j}
:

\mathcal{L}_{i,j}^{\text{Score}}=-\bigl[a_{i,j}\log\bar{a}_{i,j}+(1-a_{i,j})\log(1-\bar{a}_{i,j})\bigr],

Finally, the global training objective for the scoring model is the average loss over all data points:

\mathcal{L}_{\text{Total\_Score}}=\frac{1}{|\mathcal{R}|}\sum_{x_{i,j}\in\mathcal{R}}\mathcal{L}_{i,j}^{\text{Score}}.

Our trained scoring model achieves a Pearson’s correlation coefficient of 0.845 on the test set, indicating high agreement with ground-truth scores.

D.1
GIRT model Training Details

D.1.1
SFT

The GIRT model is fine-tuned for 15 epochs with a batch size of 4 and 16 gradient accumulation steps. The Llama backbone LLM is trained with a learning rate of
1\times 10^{-5}
, while the latent knowledge parameters and MLP are trained with a learning rate of
0.01
. we utilize the AdamW optimizer for all parameters. A linear warmup is applied for the first 3% of training steps. We set the dimension of latent knowledge
\mathbf{z}_{i}\in\mathbf{R}^{D}
where
D=2
, and we set
\lambda=0.2
to balance the two training losses. Training requires approximately 1 hour and 23 minutes on one NVIDIA L40 GPU.

D.1.2
DPO

The GIRT model is trained with DPO objective for 1 epoch with a batch size of 2 and 16 gradient accumulation steps. We utilize the AdamW optimizer with learning rate =
1\times 10^{-6}
. We set the KL-divergence penalty parameter
\beta=0.5
. For constructing preference pairs, we set
M=3
and
\tau=0.1
to select rejected samples. Training requires approximately 25 minutes on one NVIDIA L40 GPU.

D.2
Adaptive Testing Cycle Details

During the adaptive testing cycle, we set the number of sampled responses
N=10
for each candidate question. The responses are generated using nucleus sampling with a temperature of 0.8, top-
p
of 0.9, and top-
k
of 50. To update the student knowledge estimate
\mathbf{z}_{i}
, we utilize the AdamW optimizer with a learning rate of
0.01
. We utilize an incremental knowledge update strategy where the number of optimization epochs scales with the test sequence length (2 epochs per step), capped at a maximum of 10 epochs. Consistent with the SFT objective, we maintain the loss balancing coefficient
\lambda=0.2
during the knowledge update phase. Adaptive testing time varies based on the test sequence length on one NVIDIA L40 GPU.

Appendix E
Data Splitting Details

For both GIRT model training and CAT evaluation group, we implement a specific data splitting that ensures KC coverage. We employ a greedy set cover algorithm to partition each student responses. This algorithm first identifies the minimal set of questions required to cover all KCs associated with the student responses and assigns them to the training set (for the GIRT model training group) or the candidate question set (for the CAT evaluation group). This constraint guarantees that every KC appearing in the evaluation or hold-out test set is also present in the training or candidate sets. This constraint can prevent the cold-start problem for specific KCs, ensuring the student mastery level on a KC is estimated before being tested.
We then apply group-specific splitting rules. For the GIRT model training group, after the greedy set cover assigns the necessary questions to the training set, the remaining questions are shuffled and allocated to reach a target distribution of 10% for validation and 10% for testing, with the rest added back to training to form an approximate 80:10:10 split. For the CAT evaluation group, we determine the size of the test set by calculating 20% of the average number responses across all students, which yields a set of 10 questions. We also enforce the students must have a candidate question set of at least 30. Otherwise, they are reassigned to the GIRT model Training Group.

Appendix F
GIRT model Qualitative Analysis

In this section, we qualitatively analyze the sensitivity of our GIRT model. For GENCAT to function effectively, the GIRT model must be sensitive regarding student estimated KC mastery levels: it should generate incorrect responses when conditioned on low KC mastery levels (
\theta\approx 0
) and correct responses when conditioned on high mastery levels (
\theta\approx 1
). If the model generates the same responses regardless of the KC mastery levels, the question-selection algorithms cannot differentiate between candidate questions. We analyze the model’s response for a problem under three mastery levels (
\theta\in\{0,0.5,1\}
), comparing the SFT baseline against our DPO-refined model.
Table
7
in the Appendix demonstrates that the SFT model fails to condition generation on student KC mastery levels. Even when the input KC mastery levels are set to 0, the model generates the correct code. While the code structure differs slightly across KC mastery levels, the model consistently outputs correct code.
In contrast, Table
6
demonstrates that the DPO-refined model can conditions generation on student KC mastery levels. When the input KC mastery levels are set to 0, the model generates code with a logic error: it incorrectly returns 0 for number 15 and 16. When conditioned on higher KC mastery levels, the model generates correct code, while the coding style differs between mastery levels 0.5 and 1. This difference shows that DPO is necessary to enforce the GIRT model to conditions generation on student KC mastery levels, which is a fundamental requirement for the GENCAT question-selection algorithms to work.
