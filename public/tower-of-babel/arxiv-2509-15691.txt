Fast subdivision of Bézier curves
Paweł Woźny, Filip Chudy

Abstract
It is well-known that a d d -dimensional polynomial Bézier curve of degree n n can be subdivided into two segments using the famous de Casteljau algorithm in O ⁡ ( d ​ n 2 ) O(dn^{2}) time. Can this problem be solved more efficiently? In this paper, we show that it is possible to do this in O ⁡ ( d ​ n ​ log ⁡ n ) O(dn\log{n}) time using the fast Fourier transform and its inverse. Experiments show that the direct application of the new method performs well only for small values of n n , as the algorithm is numerically unstable. However, a slightly modified version—which still has O ⁡ ( d ​ n ​ log ⁡ n ) O(dn\log{n}) computational complexity—offers good numerical quality, which is confirmed by numerical experiments conducted in Python . Moreover, the new method has a nice property: if a Bézier curve is extended by an additional control point, the subdivision can be updated in O ⁡ ( d ) O(d) time. A similar idea can be applied to speed up the subdivision of rational Bézier curves and rectangular Bézier surfaces, as well as to compute the derivatives of Bézier curves more efficiently.

Introduction

Let
\mbox{{P}}_{n}:[0,1]\rightarrow{\mathbb{E}}^{d}

(d\in\mathbb{N})
be a
(polynomial)
Bézier curve of degree
n\in\mathbb{N}
with the

control points

\mbox{{W}}_{0},\mbox{{W}}_{1},\ldots,\mbox{{W}}_{n}\in{\mathbb{E}}^{d}
,

\mbox{{P}}_{n}(t):=\sum_{i=0}^{n}B^{n}_{i}(t)\mbox{{W}}_{i}\qquad(0\leq t\leq 1).

(1.1)

Here
B^{n}_{i}
denotes the
i
th Bernstein (basis) polynomial of degree

n
,

B^{n}_{i}(t):=\binom{n}{i}t^{i}(1-t)^{n-i}\qquad(0\leq i\leq n;\;n\in\mathbb{N}).

(1.2)

The parametric Bézier curves have many well-known advantages and are
therefore among the most popular tools used in computer graphics and CAD/CAGD.
The standard way to evaluate
\mbox{{P}}_{n}(c)
for a given
c\in[0,1]
is to use
the
de Casteljau algorithm
:

\left\{\begin{array}[]{l}\mbox{{W}}_{i}^{(0)}:=\mbox{{W}}_{i}\qquad(0\leq i\leq n),\\[4.30554pt]
\mbox{{W}}^{(k)}_{i}:=(1-c)\mbox{{W}}^{(k-1)}_{i}+c\,\mbox{{W}}^{(k-1)}_{i+1}\qquad(1\leq k\leq n;\;0\leq i\leq n-k).\end{array}\right.

(1.3)

Then,
\mbox{{P}}_{n}(c)=\mbox{{W}}^{(n)}_{0}
. The algorithm follows from the identity

B^{n}_{k}(t)=tB^{n-1}_{k-1}(t)+(1-t)B^{n-1}_{k}(t)\qquad(0\leq k\leq n;\ \mbox{$B^{p}_{q}\equiv 0$ if $q<0$ or $q>p$}).

The de Casteljau method is very simple. Moreover, it has an elegant geometric
interpretation, good numerical properties, and involves only convex
combinations of points in
{\mathbb{E}}^{d}
. However, its drawback is the
quadratic computational complexity, i.e.,
O(dn^{2})
.

2
The problem

The de Casteljau algorithm can also be used to
subdivide
a Bézier
curve (
1.1
) into two segments. This is particularly significant
for designers working with CAD systems.

For example, if we fix
c\in(0,1)
, then the
left part
of the curve

\mbox{{P}}_{n}
(cf. (
1.1
)), i.e., the Bézier curve

\mbox{{P}}^{L}_{n}([0,1]):=\mbox{{P}}_{n}([0,c])

is given by

\mbox{{P}}^{L}_{n}(t)=\sum_{i=0}^{n}B^{n}_{i}(t)\mbox{{V}}_{i}\qquad(0\leq t\leq 1),

(2.1)

where the control points
\mbox{{V}}_{0},\mbox{{V}}_{1},\ldots,\mbox{{V}}_{n}\in{\mathbb{E}}^{d}

are defined as

\mbox{{V}}_{k}\equiv\mbox{{V}}_{k}(c):=\sum_{i=0}^{k}B^{k}_{i}(c)\mbox{{W}}_{i}\qquad(0\leq k\leq n).

(2.2)

See, e.g.,
[
4
, Eqs. (5.29), (6.22)]
.

The points in the de Casteljau table (cf. Table
1.1
) satisfy the
following relation:

\mbox{{W}}^{(k)}_{i}\equiv\mbox{{W}}^{(k)}_{i}(c)=\sum_{j=0}^{k}B^{k}_{j}(c)\mbox{{W}}_{i+j},

where
0\leq k\leq n
and
0\leq i\leq n-k
(cf. (
1.3
)). For
details, see, e.g.,
[
4
, Eq. (5.7)]
.

Note that for
k=0,1,\ldots,n
,
\mbox{{V}}_{k}=\mbox{{W}}^{(k)}_{0}

(cf. (
2.2
)), i.e., the control points of the left part of
\mbox{{P}}_{n}

lie along the diagonal of the de Casteljau table. Similarly, the control points
of the
right part
of
\mbox{{P}}_{n}
comprise the bottom row of
Table
1.1
. This means that the problems of finding the left and
the right segments can be easily reduced to each other.

In summary, by executing the de Casteljau algorithm once, we subdivide
a
d
-dimensional polynomial Bézier curve of degree
n
into two segments
in
O(dn^{2})
time.

Note that, using the new geometric linear-time method mentioned in
Section
1
, one can also subdivide a polynomial Bézier
curve into two parts. The computational complexity, however, remains
O(dn^{2})
.
See
[
8
, p. 3]
.

Now, both for theoretical and practical reasons, an important and interesting
question arises:
can one subdivide a polynomial Bézier curve
faster?

Accordingly, this paper addresses the following main problem.

Problem 2.1
.

Given
c\in(0,1)
, a natural number
n
and the points

\mbox{{W}}_{0},\mbox{{W}}_{1},\ldots,\mbox{{W}}_{n}\in{\mathbb{E}}^{d}
, compute all points

\mbox{{V}}_{0},\mbox{{V}}_{1},\ldots,\mbox{{V}}_{n}\in{\mathbb{E}}^{d}
,
(cf. (
2.1
) and (
2.2
)), significantly faster than in

O(dn^{2})
time.

The article is organized as follows. In Section
3
, we show
that Problem
2.1
can be solved in
O(dn\log{n})
time using
the
fast Fourier transform
(the FFT in short) and its
inverse

(the IFFT).

Note that the new method has an important property. Suppose that, for a given

c\in(0,1)
, the left segment of a
d
-dimensional Bézier curve of degree

n
, with control points
\mbox{{W}}_{0},\mbox{{W}}_{1},\ldots,\mbox{{W}}_{n}

(cf. Problem
2.1
), has already been computed using the new
approach. Then, the solution to the analogous problem for
n+1
—that is,
for the Bézier curve of degree
n+1
in
{\mathbb{E}}^{d}
with control points

\mbox{{W}}_{0},\mbox{{W}}_{1},\ldots,\mbox{{W}}_{n}
and
\mbox{{W}}_{n+1}
—can be obtained using
only
O(d)
additional arithmetic operations.

Unfortunately, the solution proposed in Section
3
appears to
be mainly theoretical, as its direct implementation performs well only for
small values of
n
due to numerical instability. Therefore, in
Section
4
, we propose a slightly modified algorithm having
the same computational complexity but considerably improved numerical
robustness, making it effective even for fairly large values of
n
.

In Section
5
, we apply a similar idea to accelerate the
subdivision of rational Bézier curves and rectangular Bézier surfaces.
Additionally, we introduce a method for computing the derivatives of polynomial
Bézier curves more efficiently than with the traditional de Casteljau
algorithm.

The results of numerical experiments are given in Section
6
.

3
The theoretical solution

Recall that our goal is to compute all the points (
2.2
) more
efficiently than by using the de Casteljau algorithm. We now state the main
theoretical result of the paper.

Theorem 3.1
.

Problem
2.1
can be solved in
O(dn\log{n})
time.

Proof.

Let us consider the case of
d=1
. If
d>1
, we can proceed in
a component-wise manner.

For a fixed
n\in\mathbb{N}
, we have
v_{k}
as the one-dimensional version of

\mbox{{V}}_{k}
:

v_{k}\equiv v_{k}(c)=k!\sum_{i=0}^{k}\frac{w_{i}c^{i}}{i!}\cdot\frac{(1-c)^{k-i}}{(k-i)!}\qquad(k=0,1,\ldots,n)

(3.1)

(cf. (
2.2
), (
1.2
)), where
c\in(0,1)
, and

w_{i}\in\mathbb{R}

(0\leq i\leq n)
are the
scalar
control points.

Let us define the following two polynomials of degree
n
in the variable
x
:

a_{n}(x):=\sum_{i=0}^{n}\alpha_{i}\cdot x^{i},\qquad b_{n}(x):=\sum_{j=0}^{n}\beta_{j}\cdot x^{j},

(3.2)

where

\alpha_{i}:=\frac{w_{i}}{i!}c^{i},\qquad\beta_{j}:=\frac{1}{j!}(1-c)^{j}\qquad(0\leq i,j\leq n).

(3.3)

Define
g_{n}(x):=a_{n}(x)\cdot b_{n}(x)
. Certainly, the power form of the
polynomial
g_{n}
is

g_{n}(x)=\sum_{k=0}^{2n}\gamma_{k}\cdot x^{k}

(3.4)

with

\gamma_{k}:=\sum_{i=0}^{k}\alpha_{i}\cdot\beta_{k-i}\qquad(0\leq k\leq 2n),

(3.5)

where we set
\alpha_{\ell}:=0
,
\beta_{\ell}:=0
if
\ell>n
.

Now, observe that

v_{k}=k!\cdot\gamma_{k}\qquad\mbox{for}\qquad k=0,1,\ldots,n.

(3.6)

It is well-known that all the coefficients
\gamma_{k}

(0\leq k\leq 2n)
can be
computed using fast polynomial multiplication—via the fast Fourier
transform and its inverse—which has computational complexity
O(n\log{n})
.
See, e.g.,
[
3
, §30]
. This completes the proof.
∎

Corollary 3.2
.

Theorem
3.1
implies that the asymptotic complexity of the
Bézier curve subdivision problem does not exceed the asymptotic lower bound
of polynomial multiplication.

Let us point out interesting properties of the approach used to prove
Theorem
3.1
.

Remark 3.3
.

Observe that in the general case of
d>1
, it suffices to perform the FFT once
for the input related to the polynomial
b_{n}
(see (
3.2
)) as
it does not depend on the control points. The result can then be used for all
dimensions.

Remark 3.4
.

Again, without loss of generality, we assume that
d=1
. For a fixed natural

n
, suppose we have just computed all the coefficients
\gamma_{k}
for

k=0,1,\ldots,2n
(cf. (
3.4
), (
3.5
)) using
the FFT, the IFFT and the method described in the proof of
Theorem
3.1
. If we increase
n
by
1
then the values

v_{0},v_{1},\ldots,v_{n}
(see Eq. (
3.1
)) remain unchanged, and we only
need to compute
v_{n+1}
. Note that this can be done in
O(1)
time
because

v_{n+1}=w_{0}(1-c)^{n+1}+(n+1)!\gamma_{n+1}+w_{n+1}c^{n+1}.

Thus, in the general case, one can update the result in
O(d)
time.

Analogously, note that we also have

v_{n+2}=w_{0}(1-c)^{n+2}+(n+2)w_{1}c(1-c)^{n+1}+(n+2)!\gamma_{n+2}+(n+2)w_{n+1}c^{n+1}(1-c)+w_{n+2}c^{n+2},

which may be useful if we want to increase
n
by
2
, and so on.

Corollary 3.5
.

When increasing
n
by
m

(1\leq m\leq n)
, using the method described in
Remark
3.4
, one gets the subdivision in
O(dm^{2})
additional time,
i.e.,
O(d(n\log{n}+m^{2}))
in total. This may be of interest in practical
applications if
m^{2}
is small enough compared to
n
or if the FFT
implementation of choice is tailored to certain values of
n
.

4
The practical solution

Regrettably, experiments have shown that the new approach proposed in the
previous section is of rather theoretical interest, as it is numerically
unstable. Hence, in practical applications, it is effective only for small
values of
n
.

There are probably two main reasons for such behavior of the method:

(i)
the
input signals
for the FFT, i.e., the
coefficients (
3.3
), vanish quite rapidly for higher
i
,

j
;
(ii)
the
output signals
of the IFFT, i.e., the
coefficients (
3.5
) (cf. (
3.4
)), are quite
small and have to be multiplied by a factorial in the final stage
(cf. (
3.6
)).

Fortunately, it is possible to slightly modify the new method and mitigate
this drawback. To do this, we introduce the
scaling factor
, which
allows us to amplify the input signals for the FFT and to overcome the
numerical limitations listed above. However, let us stress that, in practice,
its numerical efficiency may depend on the chosen implementation of the FFT and
the IFFT.

As in the proof of Theorem
3.1
, we consider
Problem
2.1
in the case of
d=1
. If
d>1
, one simply applies
the component-wise strategy.

Now, given the scaling factor
s\neq 0
, and
c\in(0,1)
,
n\in\mathbb{N}
,

w_{i}\in\mathbb{R}

(0\leq i\leq n)
, we rewrite (
3.1
)
as

v_{k}\equiv v_{k}(c)=\frac{k!}{s^{k}}\sum_{i=0}^{k}\frac{s^{i}w_{i}c^{i}}{i!}\cdot\frac{s^{k-i}(1-c)^{k-i}}{(k-i)!},

(4.1)

where
k=0,1,\ldots,n
.

Consequently, we define

\displaystyle a^{s}_{n}(x):=\sum_{i=0}^{n}\alpha^{s}_{i}\cdot x^{i},\qquad\alpha^{s}_{i}:=s^{i}\alpha_{i}\qquad(0\leq i\leq n),

\displaystyle b^{s}_{n}(x):=\sum_{j=0}^{n}\beta^{s}_{j}\cdot x^{j},\qquad\beta^{s}_{j}:=s^{j}\beta_{j}\qquad(0\leq j\leq n)

(4.2)

(cf. (
3.3
)), and
g^{s}_{n}(x):=a^{s}_{n}(x)\cdot b^{s}_{n}(x)
.

So, we have

g^{s}_{n}(x)=\sum_{k=0}^{2n}\gamma^{s}_{k}\cdot x^{k},

where

\gamma^{s}_{k}:=\sum_{i=0}^{k}\alpha^{s}_{i}\cdot\beta^{s}_{k-i}\qquad(0\leq k\leq 2n),

(4.3)

and we set
\alpha^{s}_{\ell}:=0
,
\beta^{s}_{\ell}:=0
if
\ell>n
.

Finally, for
k=0,1,\ldots,n
, we obtain

v_{k}=s^{-k}k!\cdot\gamma^{s}_{k}.

Certainly, if
s=1
, nothing has changed compared to
Section
3
.

As previously recalled, using the FFT and the IFFT, all the coefficients

\gamma^{s}_{0},\gamma^{s}_{1},\ldots,\gamma^{s}_{2n}
can be computed in
O(n\log{n})

time. This implies that the required quantities
v_{0},v_{1},\ldots,v_{n}
can also
be found with the same computational complexity.

It is worth noting that similar observations to those given in
Remark
3.3
and Remark
3.4
also apply in the

scaling case
.

The new scaling factor-based approach for solving Problem
2.1

in its general form (i.e., for
d\in\mathbb{N}
) in
O(dn\log{n})
time, using
Remark
3.3
, is summarized in Algorithm
4.1
.

5
Other applications

In this section, we briefly outline the possible applications of the new method
for subdividing polynomial Bézier curves. More precisely, we consider:

(i)
computing the derivatives of polynomial Bézier curves;

(ii)
subdividing rational Bézier curves; and
(iii)

subdividing rectangular Bézier surfaces — all in a fast and efficient
manner.

5.1
Derivatives of polynomial Bézier curves

In many applications, it is necessary to compute the derivatives of Bézier
curves. For example, to find the vectors

P^{(1)}_{n}(t),P^{(2)}_{n}(t),\ldots,P_{n}^{(r)}(t)\in\mathbb{R}^{d}

(5.1)

(cf. (
1.1
)) for a given
t\in[0,1]
and
1\leq r\leq n
, we can
also use the de Casteljau algorithm (
1.3
). In that case, the
computational complexity is
O(d(n^{2}+r^{2}))
. New, faster methods achieving

O(drn)
time complexity have recently been proposed by the authors.
For details, see
[
2
]
, where the problem of computing the derivatives
of rational Bézier curves is considered as well.

It seems that the use of the FFT and the IFFT allows to accelerate the new
methods proposed in the mentioned article. In particular, Algorithm 2.2
from
[
2
]
, which computes all the vectors (
5.1
)
in
O(drn)
time, may be optimized. However, the modification is rather
complex, and we leave it for future research.

For this reason, we restrict ourselves to the problem of
computing all the vectors (
5.1
) at the ends of a curve
(i.e., for
t\in\{0,1\}
) which is of great importance, for example, when
joining a sequence of polynomial Bézier curves smoothly.

It is simple to check that

\displaystyle P_{n}^{(k)}(0)=\dfrac{n!}{(n-k)!}\sum_{i=0}^{k}\binom{k}{i}(-1)^{k-i}\mbox{{W}}_{i},

(5.2)

\displaystyle P_{n}^{(k)}(1)=\dfrac{n!}{(n-k)!}\sum_{i=n-k}^{n}\binom{k}{n-i}(-1)^{n-i}\mbox{{W}}_{i},

(5.3)

where
k=0,1,\ldots,n
. See, e.g.,
[
4
, Eq. (5.25) and (5.26)]
.
Let us focus on (
5.2
), as the method for (
5.3
)
can be derived similarly.

Certainly, the vectors
P_{n}^{(k)}(0)\in\mathbb{R}^{d}

(1\leq k\leq n)
can be
derived component-wise. So, let us assume
d=1
. Observe that to evaluate all
the sums

\sum_{i=0}^{k}\binom{k}{i}z_{i}\qquad(z_{i}\in\mathbb{R})

for all
k=0,1,\ldots,n
, where
n\in\mathbb{N}
is fixed, it is possible to
apply the approach from Section
4
(cf. (
4.1
);
see also Section
3
and (
3.1
)). Indeed, it is
enough to set
c:=\tfrac{1}{2}
there, because

B^{k}_{i}(\tfrac{1}{2})=2^{-k}\cdot\binom{k}{i}

(0\leq i\leq k)
.

To sum up, one can compute all the vectors

P_{n}^{(k)}(0),P_{n}^{(k)}(1)\in\mathbb{R}^{d}
for all
1\leq k\leq n
with
computational complexity
O(dn\log{n})
. This approach is faster than the use
of the de Casteljau algorithm or the methods from
[
2
]
, all of which
run in
O(dn^{2})
time.

5.2
Rational Bézier curves

Let us consider a
rational Bézier curve

\mbox{{R}}_{n}:[0,1]\rightarrow{\mathbb{E}}^{d}

(d\in\mathbb{N})
of degree

n\in\mathbb{N}
with the
control points

\mbox{{W}}_{0},\mbox{{W}}_{1},\ldots,\mbox{{W}}_{n}\in{\mathbb{E}}^{d}
, and the corresponding

weights

\omega_{0},\omega_{1},\ldots,\omega_{n}>0
,

\mbox{{R}}_{n}(t):=\frac{\displaystyle\sum_{i=0}^{n}\omega_{i}B^{n}_{i}(t)\mbox{{W}}_{i}}{\displaystyle\sum_{i=0}^{n}\omega_{i}B^{n}_{i}(t)}\qquad(0\leq t\leq 1).

A point on the parametric curve
\mbox{{R}}_{n}
can be evaluated using the

rational de Casteljau algorithm
, which has a computational complexity

O(dn^{2})
. Note that the rational de Casteljau algorithm is significantly more
expensive compared to its polynomial version, as it requires
O(n^{2})

divisions. Similarly to the polynomial case, this method also subdivides a
rational Bézier curve into two segments in
O(dn^{2})
time.

For example, for a given
c\in(0,1)
, the
left part
of the curve

\mbox{{R}}_{n}
, i.e., the rational Bézier curve

\mbox{{R}}^{L}_{n}([0,1]):=\mbox{{R}}_{n}([0,c])
, has the following form:

\mbox{{R}}^{L}_{n}(t)=\dfrac{\displaystyle\sum_{i=0}^{n}\nu_{i}B^{n}_{i}(t)\mbox{{V}}_{i}}{\displaystyle\sum_{i=0}^{n}\nu_{i}B^{n}_{i}(t)}\qquad(0\leq t\leq 1),

where

\nu_{k}\equiv\nu_{k}(c):=\sum_{i=0}^{k}\omega_{i}B^{k}_{i}(c),\qquad\mbox{{V}}_{k}\equiv\mbox{{V}}_{k}(c):=\frac{1}{\nu_{k}}\sum_{i=0}^{k}\omega_{i}B^{k}_{i}(c)\mbox{{W}}_{i}\qquad(0\leq k\leq n).

(5.4)

As already mentioned, all these weights and points can be found via the
rational de Casteljau algorithm in
O(dn^{2})
time.

For a justification of the given facts, further information on rational
Bézier curves and the rational de Casteljau algorithm, see, e.g.,

[
4
, §13]
.

It should be noted that the new geometric linear-time method
[
8
]
,
derived by the authors, allows for faster computation of a point on a rational
Bézier curve, namely in
O(dn)
time. However, subdividing a rational
Bézier curve into two parts using this new method still requires
O(dn^{2})

arithmetic operations. See
[
1
, p. 59]
.

It is not difficult to see that all the weights and the control
points (
5.4
) can be computed with computational complexity

O(dn\log{n})
. Indeed, we first need to determine
\nu_{0},\nu_{1},\ldots,\nu_{n}

using the new method proposed in Section
4

(cf. (
4.1
); see also Section
3

and (
3.1
)). Next, we can compute
\mbox{{V}}_{0},\mbox{{V}}_{1},\ldots,\mbox{{V}}_{n}

in a component-wise manner using the new approach again.

5.3
Rectangular Bézier surfaces

The
rectangular Bézier surface

\mbox{{S}}_{nm}:[0,1]^{2}\rightarrow\mathbb{E}^{d}

(d\in\mathbb{N})

of degree

(n,m)\in\mathbb{N}^{2}
with the
control points

\mbox{{W}}_{ij}\in{\mathbb{E}}^{d}

(0\leq i\leq n,\;0\leq j\leq m)
is defined by

\mbox{{S}}_{nm}(t,u):=\sum_{i=0}^{n}\sum_{j=0}^{m}B^{n}_{i}(t)B^{m}_{j}(u)\mbox{{W}}_{ij}\qquad(0\leq t,u\leq 1).

To evaluate a point on a rectangular Bézier surface, one can use the de
Casteljau algorithm multiple times. The computational complexity in this case
is
O(d\overline{M}(\underline{M}^{2}+\overline{M}))
, where

\underline{M}:=\min(n,m)
,
\overline{M}:=\max(n,m)
. See, e.g.,

[
4
, §14]
.

Recently, the authors have proposed faster methods of computing a point on
the surface
\mbox{{S}}_{nm}
, which work in
O(dnm)
time. See
[
8
]
and

[
1
, §2.4]
.

The problem of subdividing rectangular Bézier surfaces is important in
practical applications, and for this reason, it has been considered in the
literature. Note that the de Casteljau algorithm is also helpful in solving
this task. For details, see, e.g.,
[
4
, §14.7 and §16.1]
.

Let us restrict ourselves only to the following case of rectangular Bézier
surface subdivision. Consider the rectangular Bézier surface

\mbox{{S}}^{L}_{nm}
representing the
left part
of the patch
\mbox{{S}}_{nm}
,
i.e.,
\mbox{{S}}^{L}_{nm}([0,1],[0,1]):=\mbox{{S}}_{nm}([0,c],[0,1])
, where
c\in(0,1)

is fixed.

It can be checked that

\mbox{{S}}^{L}_{nm}(t,u)=\sum_{i=0}^{n}\sum_{j=0}^{m}B^{n}_{i}(t)B^{m}_{j}(u)\mbox{{V}}_{ij}\qquad(0\leq t,u\leq 1),

where the points
\mbox{{V}}_{ij}\in\mathbb{E}^{d}
are given by

\mbox{{V}}_{ij}\equiv\mbox{{V}}_{ij}(c):=\sum_{k=0}^{i}B^{i}_{k}(c)\mbox{{W}}_{kj}\qquad(0\leq i\leq n,\;0\leq j\leq m).

(5.5)

These quantities can be computed using the de Casteljau algorithm
m+1

times in
O(dmn^{2})
time (cf. Section
2
).

However, it is now clear that the new method from Section
4

(cf. (
4.1
); see also Section
3

and (
3.1
)) allows us to derive all the points (
5.5
)
with the computational complexity
O(dmn\log{n})
.

Remark 5.1
.

Using the new approach, one can take advantage of the fact that we need to
compute
m+1
sums of the form (
5.5
) for different sets of control
points which all correspond to the same value of
c
. This suggests that a
notable improvement can be achieved. Indeed, it suffices to run the FFT once
for the input related to the polynomial
b^{s}_{n}
(see (
4.2
); or
to the polynomial
b_{n}
, cf. (
3.2
)), and the result can then be
applied to all dimensions (cf. Remark
3.3
) and for all

\ell=0,1,\ldots,m
.

By combining the approaches given in this and the previous paragraph, a similar
method for fast subdivision of
rational rectangular Bézier
surfaces
(see, e.g.,
[
4
, §16.6]
; cf. also §
5.2
) can
be formulated as well.

7
Conclusions

We have proposed a new fast method for subdividing a Bézier curve of degree

n
in
{\mathbb{E}}^{d}
, with a computational complexity of
O(dn\log n)
. The
algorithm is based on the fast Fourier transform and its inverse. A scaled
variant of the method, implemented in
Python
, has good numerical
quality even for Bézier curves of relatively high degree. Furthermore, the
method facilitates more efficient evaluation of Bézier curve derivatives,
as well as faster subdivision of rational Bézier curves and rectangular
polynomial or rational Bézier patches.

The conducted numerical experiments indicate that, in future research, one
should investigate in greater detail the possibility of an
optimal

choice of the scaling factor. This involves taking into account not only the
degree of the considered curve, but also the subdivision point, as well as
exploring various other popular and efficient implementations of the FFT and
the IFFT. Such an approach is expected to make the new method more numerically
efficient, even for Bézier curves of very high degree.
