1.
Introduction

Given graphs
G
and
H,
as usual we say that
G
is
H
-free
if
G
contains no induced subgraph isomorphic to
H.
What can be said about the structure of such graphs
G?
The most famous open problem in this regard is a conjecture of Erdős and Hajnal
[
2
]
from 1977.

Conjecture 1.1
.

For every graph
H,
there exists a constant
c_{H}>0
such that any
H
-free graph
G
contains either a clique or a stable set of size at least
|G|^{c_{H}}.

We say that any graph
H
satisfying Conjecture
1.1
has the
Erdős-Hajnal property
. We remark that Erdős and Szekeres
[
4
]
showed that all graphs
G
contain either a clique or a stable set of size at least
\frac{1}{2}\log|G|,
and Erdős
[
3
]
further showed that almost all graphs
G
contain neither a clique nor a stable set of size greater than
(2+o(1))\log|G|
(all logarithms in this paper are to the base 2). In light of this, Conjecture
1.1
would indicate that
H
-free graphs have a highly atypical structure.

Conjecture
1.1
has received a lot of attention over the years, having now been verified in a good number of nontrivial cases. A natural variation of this problem asks the following: to what degree do
H
-free graphs contain large regions which are either very ‘sparse’ or very ‘dense’? Given a graph
G
and any
\epsilon>0,
say that a set
S\subseteq V(G)
is
weakly
\epsilon
-restricted
if one of
G[S],\overline{G}[S]
contains at most
\epsilon|S|^{2}
edges. Rödl
[
7
]
showed that
H
-free graphs contain linear-sized such sets.

Theorem 1.2

(Rödl)
.

For every graph
H
and any
\epsilon>0,
there exists
\delta>0
with the following property: if
G
is an
H
-free graph, then there is some subset
S\subseteq V(G)
with
|S|\geq\delta|G|,
such that
S
is weakly
\epsilon
-restricted.

For a fixed graph
H,
how large can we take
\delta
as a function of
\epsilon?
Fox and Sudakov
[
6
]
conjectured the following polynomial bound.

Conjecture 1.3
.

For every graph
H,
there exists a constant
C_{H}>0
with the following property: for all
0<\epsilon\leq 1/2
and any
H
-free graph
G,
there is some weakly
\varepsilon
-restricted set
S\subseteq V(G)
with
|S|\geq\epsilon^{C_{H}}|G|.

We say that any graph
H
satisfying Conjecture
1.3
has the
polynomial Rödl property
. An easy application of Turán’s Theorem shows that any graph with the polynomial Rödl property also has the Erdős-Hajnal property. It was recently shown in a beautiful paper of Bucić, Fox and Pham that the converse is also true.

Theorem 1.4
.

Let
H
be a graph. Then
H
has the Erdős-Hajnal property if and only if
H
has the polynomial Rödl property.

An interesting variation of the above problem asks to what degree we may partition
H
-free graphs into a ‘small’ number of sets, all of which are either sparse or dense. Indeed, this has a straightforward answer in the context of what we have defined so far.

Theorem 1.5
.

For every graph
H
and for all
\epsilon>0,
there exists
N\geq 1
such that any
H
-free graph
G
partitions into at most
N
sets, all of which are weakly
\epsilon
-restricted. Moreover,
H
satisfies the polynomial Rödl property if and only if we may take
N=(1/\varepsilon)^{C_{H}}
for some constant
C_{H}>0.

This can be seen by partitioning all but a very small number of vertices into weakly
(\varepsilon/2)
-restricted sets (by repeatedly applying Theorem
1.2
, along with the relevant quantitative bounds for the ‘moreover’ statement), and then placing the leftover vertices into a largest such one of these sets.

What if we demand a little more restriction on the sets making up such a partition? Given a graph
G
and any
\epsilon>0,
say now that a set
S\subseteq V(G)
is
strongly
\epsilon
-restricted
if one of
G[S],\overline{G}[S]
has maximum degree at most
\epsilon|S|.
It is easily seen that any strongly
\epsilon
-restricted set is weakly
(\epsilon/2)
-restricted, and that any weakly
(\epsilon/2)
-restricted set contains a set of at least half its size which is strongly
\epsilon
-restricted. It follows that Theorem
1.2
and Conjecture
1.3
are equivalent to their ‘strong’ analogies (the statement given by replacing the word ‘weakly’ with ‘strongly’). However, it is not hard to see why the above argument for Theorem
1.5
fails to adapt to the case of strongly restricted sets. Indeed, it was shown only recently in a paper of Chudnovsky, Scott, Seymour and Spirkl
[
1
]
that
H
-free graphs can be partitioned into a bounded number of strongly
\varepsilon
-restricted sets.

Theorem 1.6
.

For every graph
H
and for all
\epsilon>0,
there exists
N\geq 1
such that any
H
-free graph
G
partitions into at most
N
sets, all of which are strongly
\epsilon
-restricted.

A corresponding strengthening of Conjecture
1.3
was raised by Fox, Nguyen, Scott and Seymour
[
5
]
: given a graph
H,
is there some constant
C_{H}>0
such that we may take
N=(1/\varepsilon)^{C_{H}}
in Theorem
1.6
? Say that any graph
H
for which this holds has the
strong polynomial Rödl property
. It was shown in
[
5
]
that
H=P_{4}
has this property, and it was remarked that the same was not known when
H
is a triangle. We address this case and, more generally, the case where
H
is any complete graph.

Theorem 1.7
.

Every complete graph has the strong polynomial Rödl property.

Given
\varepsilon>0
and a graph

Theorem 2.1

For each integer

there exists a constant
C_{r}>0

0<\varepsilon\leq 1/2,
every
K_{r+1}
-free graph

We will use the following standard Chernoff bound.

Lemma 2.2

Let

be a binomially distributed random variable with mean

Then for all
0<\delta<1,
the following holds.

\mathbb{P}\mathopen{}\mathclose{{\left(|X-\mu|\geq\delta\mu}}\right)\leq 2e^{-\delta^{2}\mu/3}.

We begin with the following easy lemma.

Lemma 2.3
.

Let

be an integer. Then for all
0<\alpha\leq 1,
if
G
is any
K_{r+1}
-free graph, there exists an
\alpha
-sparse set
S\subseteq V(G)

\alpha^{r-1}|G|.

Proof.

Proceed by induction on
r\geq 1.
For
r=1
this is trivial, so suppose that
r\geq 2.
If
V(G)
is
\alpha
-sparse, then we are done; otherwise, there is some vertex
v\in V(G)
with at least
\alpha|G|
neighbours. Since

must be

-free, applying the inductive hypothesis gives the result.
∎

We will use Lemma
2.3
both in its own right, and also in the following application.

Lemma 2.4
.

Let

be an integer and let

Then for all
0<\alpha\leq 1/2,
if

is any

is
\alpha

•

|L|\leq\alpha^{(r-1)(1/\alpha)^{m}}|G|.

We will need the following approximation, the proof of which we omit.

Lemma 2.5
.

Let
0<x<1.
Then for all

we have that

(1-x)^{(1/x)^{s}}\leq x^{(1/x)^{s-2}}.

We now deduce Lemma
2.4
as follows.

Proof of Lemma
2.4
.

Produce
\mathcal{A}
by greedly applying Lemma
2.3

\lfloor(1/\alpha)^{m+2r-1}\rfloor

Then

|L|\leq(1-\alpha^{r-1})^{\lfloor(1/\alpha)^{m+2r-1}\rfloor}|G|\leq(1-\alpha^{r-1})^{(1/\alpha)^{m+2r-2}}|G|.

Now write
(1/\alpha)^{m+2r-2}=(1/\alpha^{r-1})^{\frac{m}{r-1}+2}.
Then by applying Lemma

We now introduce some terminology to describe the distribution of edges between two sets of vertices. Given

a graph

and disjoint sets

•

•

More generally, we will say that a sequence of disjoint sets

is

-full if the pair

-full for each

The following says that an appropriately full sequence of

Lemma 2.6
.

Let

be an integer, let

Fix

as such and proceed by induction on

For

this is trivial, so suppose that

and that
S_{1},\dots,S_{r}
are subsets of some graph

of the vertices in

are
\gamma

Therefore, at least

Let

The following lemma is key in the proof of Theorem

Lemma 2.7

Let

We must have that

-sparse, because
T_{i}
is
\varepsilon
-sparse,
B_{i}
is
\varepsilon
-sparse to
T_{i}
and
|B_{i}|\leq\varepsilon|T_{i}|.

Lastly, let
\tilde{S}_{i}=T_{i}^{\prime}
for each
1\leq i\leq k+1.

Observe now that the collection of sets
\tilde{\mathcal{A}}\cup\{\tilde{S}_{1},\dots,\tilde{S}_{k+1},\tilde{R}\}
is a partition of
V(G),
and that each set in
\tilde{\mathcal{A}}
is
\varepsilon
-sparse.

Claim 4:

|\tilde{\mathcal{A}}|\leq(k+1)(1/\varepsilon)^{a_{0}+2r}+(k+1)^{2}.

Proof:
This is immediate by noting that
|\tilde{\mathcal{A}}|\leq|\mathcal{A}|+(1/\varepsilon)^{a_{0}+2r}+(2k+1).

Claim 5:
The sequence
\tilde{S}_{1},\dots,\tilde{S}_{k+1}
is
(\varepsilon^{13r-8(k+1)-1},\varepsilon^{13r-8(k+1)-1},\varepsilon^{5})
-full.

Proof:
Firstly, the sequence
\tilde{S}_{1},\dots,\tilde{S}_{k}
is
(\varepsilon^{13r-8(k+1)-1},\varepsilon^{13r-8(k+1)-1},\varepsilon^{5})
-full, since
|\tilde{S_{i}}|\geq(\varepsilon/108)|S_{i}|\geq\varepsilon^{8}|S_{i}|
for each
1\leq i\leq k.
Secondly, note that for each
1\leq i\leq k,
the pair
(\tilde{S}_{i},\tilde{S}_{k+1})
is
(9(\varepsilon/6)^{13r},3\varepsilon^{g(\varepsilon)},\varepsilon/12)
-full, where

g(\varepsilon)=(1/\varepsilon)^{a_{i}}-\sum_{j=i+1}^{k}(1/\varepsilon)^{a_{j}}(6/\varepsilon)^{26r}\geq 13r.

Noting that
9(\varepsilon/6)^{13r}\leq\varepsilon^{13r-4}\leq\varepsilon^{13r-8(k+1)-1},
that
3\varepsilon^{13r}\leq\varepsilon^{13r-2}\leq\varepsilon^{13r-8(k+1)-1}
and that
\varepsilon/12\geq\varepsilon^{5},
it follows that the pair
(\tilde{S}_{i},\tilde{S}_{k+1})
is
(\varepsilon^{13r-8(k+1)-1},\varepsilon^{13r-8(k+1)-1},\varepsilon^{5})
-full for each
1\leq i\leq k.

Claim 6:
The set
\tilde{S}_{i}
is
\epsilon^{8(r-k-1)+1}
-sparse for each
1\leq i\leq k+1.

Proof:
Indeed, for
1\leq i\leq k,
this follows since
|\tilde{S}_{i}|\geq\varepsilon^{8}|S_{i}|.
For
i=k+1,
we see that, by construction, the set
\tilde{S}_{k+1}
is
3\varepsilon^{h(\varepsilon)}
-sparse, where

h(\varepsilon)=(1/\varepsilon)^{a_{0}}-\sum_{j=1}^{k}(1/\varepsilon)^{a_{j}}(6/\varepsilon)^{26r}\geq 13r\geq 8r-5.

The claim follows since
3\varepsilon^{g(\varepsilon)}\leq\varepsilon^{g(\varepsilon)-2}\leq\varepsilon^{8r-7}\leq\varepsilon^{8(r-k+1)+1}.

Claim 7:

|\tilde{R}|\leq(\varepsilon/100)|\tilde{S}_{i}|
for each
1\leq i\leq k+1.

Proof:
This is immediate, since
|\tilde{R}|\leq|R^{\prime}|\leq(\varepsilon/300)|Y_{i}|
and
|S_{i}^{k}|\geq|Y_{i}|/3
for each
1\leq i\leq k+1.

But then we have shown that
k
was not maximal, and so we are done.

∎

3.
Concluding remarks

We have shown that for each integer
r\geq 2,
there is a constant
C_{r}>0
such that, for any
0<\varepsilon\leq 1/2,
every
K_{r+1}
-free graph can be partitioned into at most
(1/\varepsilon)^{C_{r}}
sets, all of which are
\varepsilon
-sparse.

It is now known that the Erdős-Hajnal and polynomial Rödl properties are equivalent. Fox, Nguyen, Scott and Seymour
[
5
]
raised the question as to whether every graph has the strong polynomial Rödl property. We conjecture that the strong polynomial Rödl is equivalent to the Erdős-Hajnal property.

Conjecture 3.1
.

Any graph
H
which satisfies the Erdős-Hajnal property also satisfies the strong polynomial Rödl property.
