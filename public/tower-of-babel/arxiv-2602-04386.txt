Improved Sparse Recovery for Approximate Matrix Multiplication
Yahel Uffenheimer, Omri Weinstein

Abstract
We present a simple randomized algorithm for approximate matrix multiplication (AMM) whose error scales with the output norm ‖ A ​ B ‖ F \|AB\|_{F} . Given any n × n n\times n matrices A , B A,B and a runtime parameter r ≤ n r\leq n , the algorithm produces in O ⁡ ( n 2 ​ ( r + log ⁡ n ) ) O(n^{2}(r+\log n)) time, a matrix C C with total squared error 𝔼 ⁡ [ ‖ C − A ​ B ‖ F 2 ] ≤ ( 1 − r n ) ​ ‖ A ​ B ‖ F 2 \mathbb{E}[\|C-AB\|_{F}^{2}]\leq(1-\frac{r}{n})\|AB\|_{F}^{2} , per-entry variance ‖ A ​ B ‖ F 2 / n 2 \|AB\|_{F}^{2}/n^{2} and bias 𝔼 ⁡ [ C ] = r n ​ A ​ B \mathbb{E}[C]=\frac{r}{n}AB . Alternatively, the algorithm can compute an unbiased estimation with expected total squared error n r ​ ‖ A ​ B ‖ F 2 \frac{n}{r}\left\lVert AB\right\rVert_{F}^{2} , recovering the state-of-art AMM error obtained by Pagh’s TensorSketch algorithm [ 14 ] . Our algorithm is a log-factor faster. The key insight in the algorithm is a new variation of pseudo-random rotation of the input matrices (a Fast Hadamard Transform with asymmetric diagonal scaling), which redistributes the Frobenius norm of the output A ​ B AB uniformly across its entries.

The idea of using a fast orthogonal rotation matrix like the Walsh-Hadamard transformed, with randomized signs, was first proposed by

Instead of sketching both matrices and computing the product of sketches, we transform them to a more convenient form and then sketch their product directly. Our transformation acts on the matrix space and not on the vector space. This difference allows a fast runtime without compressing the matrices (and also escapes the low-rank constraint of common sketching algorithms).

2
Fast Walsh-Hadamard Sketch

2.1
Preliminaries

Denote
[n]=\left\{0,\ldots,n-1\right\}
. The Frobenius norm of a square
n\times n
matrix
A
is defined as
\left\lVert A\right\rVert_{F}^{2}=\sum_{i,j\in[n]}\left|A_{i,j}\right|^{2}
. The
2^{k}
-th Walsh-Hadamard transform (WHT), denoted by
H_{2^{k}}
, is defined recursively:

H_{2}=\frac{1}{\sqrt{2}}\cdot\begin{pmatrix}1&1\\
1&-1\end{pmatrix}\quad,\quad H_{2^{k+1}}=H_{2^{k}}\otimes H_{2^{k}}.

More explicitly, for
i,j\in[2^{k}]
it holds

(H_{2^{k}})_{i,j}=\frac{1}{\sqrt{2^{k}}}(-1)^{\left\langle{i,j}\right\rangle_{b}}\quad\text{where}\quad\left\langle{i,j}\right\rangle_{b}=\bigoplus_{t=0}^{k-1}b(i)_{t}\oplus b(j)_{t},

letting
b(i)
denote the binary representation of
i
and
\oplus
denote binary addition (i.e., addition in
\mathbb{F}_{2}
). When
k
is clear from context, we drop the subscript and write
H
.
We note that
H
has the following important properties – it is a unitary symmetric involution, that is:

H=H^{\top}\quad,\quad H^{-1}=H\quad,\quad\left\lVert Hx\right\rVert_{2}=\left\lVert x\right\rVert_{2}.

We also note that
H_{2^{k}}
is the Discrete Fourier transform of the group
\mathbb{Z}_{2}^{k}
. For a vector
a
of size
n
, let
D_{a}=\mathsf{Diag}(a)
. Note that for every couple of vectors
a,b
of size
n
and a matrix
X
of size
n\times n
it holds

(ab^{\top})\odot X=D_{a}XD_{b},

using the vec-trick, where
\odot
denotes the element-wise product of matrices.

2.2
Sketch Idea

Note that for random Rademacher matrices
A,B
, since they are highly “balanced” in the sense that mass (i.e., the magnitude of the entries) is uniformly distributed, one can approximate
AB
by computing any fixed set of
rn
output entries, and fill the rest with zeros. This is a biased estimator achieving
\frac{n-r}{n}\cdot\left\lVert AB\right\rVert_{F}^{2}
squared Frobenius error in expectation (over the randomness of
A,B
).

For arbitrary fixed
A,B
, the matrices may be unbalanced (have most of the mass concentrated on a small number of entries), and thus following the same strategy may lead to a very large and uncontrolled error, as the choice of wrong entries may have dire effects. Our idea, inspired by the Fast-JL Transform
[
2
]
, is to precondition the matrices in order to obtain new “
pseudo-random
” matrices, for which the above naïve algorithm should work well. Intuitively, the uncertainty principle (for the Fourier transform, see
[
20
]
) mitigates severe imbalances in the original matrices. For this to work, we design the preconditioning to be invertible.

We note that by the vec-trick, for a matrix
X
of size
2^{k}\times 2^{k}
it holds

\mathrm{vec}(H_{2^{k}}XH_{2^{k}})=H_{2^{k+1}}\mathrm{vec}({X}).

Therefore we can view the preconditioning done in the algorithm (presented next), as a transformation in the matrix space, compared with standard sketching algorithms, where the sketch is applied on each column / row of the matrices separately (at least conceptually).

2.3
The Algorithm

Let
A,B
be given
n\times n
matrices where we assume
n=2^{k}
for some
k
. Let
H=H_{2^{k}}
denote the WHT. Let
r\leq n
be a given parameter.

Definition 2.1
.

For
\boldsymbol{\alpha},\boldsymbol{\beta}\in\left\{\pm 1\right\}^{n}
define
\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\beta}}
to be an operator on
n\times n
matrices defined by
\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\beta}}(A)=HD_{\boldsymbol{\alpha}}AD_{\boldsymbol{\beta}}H
. It is an invertible unitary linear operator with inverse given by
\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\beta}}^{-1}(B)=D_{\boldsymbol{\alpha}}HBHD_{\boldsymbol{\beta}}
.

Lemma 2.2
.

For any
\boldsymbol{\alpha},\boldsymbol{\beta},\boldsymbol{\gamma}\in\left\{\pm 1\right\}^{n}
and matrices
A,B
, it holds
\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\beta}}(AB)=\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\gamma}}(A)\cdot\mathcal{W}_{\boldsymbol{\gamma},\boldsymbol{\beta}}(B)
and
\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\beta}}^{-1}(AB)=\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\gamma}}^{-1}(A)\cdot\mathcal{W}_{\boldsymbol{\gamma},\boldsymbol{\beta}}^{-1}(B)
.

Proof.

Indeed,
\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\beta}}(AB)=HD_{\boldsymbol{\alpha}}ABD_{\boldsymbol{\beta}}H=HD_{\boldsymbol{\alpha}}AD_{\boldsymbol{\gamma}}HHD_{\boldsymbol{\gamma}}BD_{\boldsymbol{\beta}}H=\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\gamma}}(A)\cdot\mathcal{W}_{\boldsymbol{\gamma},\boldsymbol{\beta}}(B)
using the fact
D_{\boldsymbol{\gamma}}^{2}=I
and
H^{2}=I
. Similarly for the inverse.
∎

Algorithm 1

Approximate Matrix Multiplication

1:

n\times n
matrices
A,B
.

2:

an approximation
C
for
AB
.

3:

Draw random sign vectors
\boldsymbol{\alpha},\boldsymbol{\beta},\boldsymbol{\gamma}\in\left\{\pm 1\right\}^{n}
.

4:

Compute
A^{\prime}=\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\gamma}}(A),B^{\prime}=\mathcal{W}_{\boldsymbol{\gamma},\boldsymbol{\beta}}(B)
.

5:

Choose any set of
n\cdot r
indices
(i,j)\in[n]^{2}
and compute
A_{i,:}^{\prime}\cdot B_{:,j}^{\prime}
. Store the results in a matrix
C^{\prime}
initialized to zero.

6:

return

\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\beta}}^{-1}(C^{\prime})
.

Runtime.
Drawing random sign vectors requires
O(n)
time. To compute
A^{\prime},B^{\prime}
, note that
\mathrm{vec}(HXH)=(H\otimes H)\mathrm{vec}(X)
can be computed using the fast WHT algorithm in time
O(n^{2}\log n)
, while a product with a diagonal matrix can be computed in time
O(n^{2})
. Hence step
4
takes
O(n^{2}\log n)
time. For step
5
, a trivial calculation takes
O(rn\cdot n)
time. At last, step
6
is the same as step
4
. We conclude that
C
can be computed in time
O(n^{2}(r+\log n))
.

Remark 2.3
.

A few remarks are in place:

•

Compared to previously known algorithms, like that of
[
14
]
, the runtime is a logarithmic factor faster.

•

The specifics of step
5
are left unspecified on purpose. In the analysis to follow we will assume a
random
subset of size
rn
is chosen, but different methods are possible, maybe with some improvements to the analysis. Since the error analysis (shown next) is only concerned with the marginal distributions, it is blind to other effects of the implementation of step
5
.

•

The vector
\boldsymbol{\gamma}
is canceled out and so has no algorithmic effect (and can be removed). However, when analyzing the properties of
A^{\prime},B^{\prime}
on their own, the presence of
\boldsymbol{\gamma}
does have significance.

•

Setting
r=n
we have
C^{\prime}=A^{\prime}B^{\prime}
, and so by definition of
C
and
2.2
,
C=AB
. This is unusual in sketching algorithms, which usually cannot recover the result exactly due to likely hashing collisions.

•

If the
n\cdot r
positions are chosen to be specific rows or columns of
A^{\prime}B^{\prime}
(say the first
r
rows), then the rank of
C^{\prime}
is at most
r
. Since
\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\beta}}
is linear and invertible, the resulting rank of
C
is
r
too. However, if the positions are chosen in an unstructured way (say, a random set of size
rn
), we don’t have such a guarantee. This doesn’t change the analysis, but it does mean the error isn’t inherently lower bounded by the sum of the lower
n-r
singular values of
AB
.

2.4
Error Analysis

Proposition 2.4
.

Assuming the calculated positions are randomly chosen (uniformly), it holds
\mathbb{E}[C]=\frac{r}{n}AB
.

Proof.

By assumption,
\mathbb{E}[C^{\prime}_{i,j}]=\frac{r}{n}\cdot(A^{\prime}B^{\prime})_{i,j}
where the probability is taken over the choice of indices. Therefore, taking the expectation over both indices and signs,

\displaystyle\mathbb{E}[C_{i,j}]

\displaystyle=\mathbb{E}[(D_{\boldsymbol{\alpha}}HC^{\prime}HD_{\boldsymbol{\beta}})_{i,j}]=\mathbb{E}\left[\boldsymbol{\alpha}_{i}\boldsymbol{\beta}_{j}\cdot\sum_{k,\ell}H_{i,k}C^{\prime}_{k,\ell}H_{\ell,j}\right]=\sum_{k,\ell}H_{i,k}H_{\ell,j}\cdot\mathbb{E}[\boldsymbol{\alpha}_{i}\boldsymbol{\beta}_{j}\cdot C^{\prime}_{k,\ell}].

Using conditioned expectation and
2.2
,

\mathbb{E}[\boldsymbol{\alpha}_{i}\boldsymbol{\beta}_{j}C^{\prime}_{k,\ell}]=\frac{r}{n}\cdot\mathbb{E}[\boldsymbol{\alpha}_{i}\boldsymbol{\beta}_{j}(A^{\prime}B^{\prime})_{k,\ell}]=\frac{r}{n}\sum_{p,q}H_{k,p}H_{q,\ell}\cdot(AB)_{p,q}\cdot\mathbb{E}[\boldsymbol{\alpha}_{i}\boldsymbol{\beta}_{j}\cdot\boldsymbol{\alpha}_{p}\boldsymbol{\beta}_{q}].

Note that
\mathbb{E}[\boldsymbol{\alpha}_{i}\boldsymbol{\beta}_{j}\cdot\boldsymbol{\alpha}_{p}\boldsymbol{\beta}_{q}]=0
unless
i=p,j=q
in which case it is equal to
1
. Therefore
\mathbb{E}[\boldsymbol{\alpha}_{i}\boldsymbol{\beta}_{j}C^{\prime}_{k,\ell}]=\frac{r}{n}H_{k,i}H_{j,\ell}(AB)_{i,j}
, implying that

\mathbb{E}[C_{i,j}]=\sum_{k,\ell}H_{i,k}H_{\ell,j}H_{k,i}H_{j,\ell}\cdot\frac{r}{n}\cdot(AB)_{i,j}.

We finish by recalling that
H
is symmetric with elements of magnitude
1/n
, thus

\mathbb{E}[C_{i,j}]=\frac{n^{2}}{n^{2}}\cdot\frac{r}{n}\cdot(AB)_{i,j}=\frac{r}{n}(AB)_{i,j}.

∎

Proposition 2.5
.

It holds
\mathsf{Var}(\left\lVert C-AB\right\rVert_{F})\leq\mathbb{E}[\left\lVert C-AB\right\rVert_{F}^{2}]=\frac{n-r}{n}\cdot\left\lVert AB\right\rVert_{F}^{2}.

Proof.

Since
\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\beta}}
is unitary, we have

\displaystyle\left\lVert C-AB\right\rVert_{F}^{2}=\left\lVert\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\beta}}^{-1}(C^{\prime}-A^{\prime}B^{\prime})\right\rVert_{F}^{2}=\left\lVert C^{\prime}-A^{\prime}B^{\prime}\right\rVert_{F}^{2}.

(2.1)

For any
i,j\in[n]
, by
2.2
we have

(A^{\prime}B^{\prime})_{i,j}=\sum_{k,\ell}H_{i,k}H_{\ell,j}\cdot\boldsymbol{\alpha}_{k}\boldsymbol{\beta}_{\ell}\cdot(AB)_{k,\ell}.

Therefore, denoting
R_{k,\ell}=H_{i,k}H_{\ell,j}\cdot(AB)_{k,\ell}
we have:

\mathbb{E}[(A^{\prime}B^{\prime})_{i,j}^{2}]=\sum_{k,l,p,q}R_{k,l}R_{p,q}\cdot\mathbb{E}\left[\boldsymbol{\alpha}_{k}\boldsymbol{\alpha}_{p}\cdot\boldsymbol{\beta}_{\ell}\boldsymbol{\beta}_{q}\right].

The expectation over the signs is
0
unless
k=p
and
\ell=q
, in which case it is
1
. Thus the sum collapses,

\mathbb{E}[(A^{\prime}B^{\prime})_{i,j}^{2}]=\sum_{k,\ell}R_{k,\ell}^{2}=\frac{1}{n^{2}}\sum_{k,\ell}(AB)_{k,\ell}^{2}=\frac{\left\lVert AB\right\rVert_{F}^{2}}{n^{2}}.

Conditioned on any fixed set of indices
F\subset[n]^{2}
of size
rn
,

\displaystyle\mathbb{E}[\left\lVert C^{\prime}-A^{\prime}B^{\prime}\right\rVert_{F}^{2}\mid F\text{ was chosen}]=\sum_{(i,j)\notin F}\mathbb{E}[(A^{\prime}B^{\prime})_{i,j}^{2}]=(n^{2}-rn)\cdot\frac{\left\lVert AB\right\rVert_{F}^{2}}{n^{2}}.

(2.2)

Returning to
Equation 2.1
, we conclude

\mathbb{E}[\left\lVert C-AB\right\rVert_{F}^{2}]=\mathbb{E}[\left\lVert C^{\prime}-A^{\prime}B^{\prime}\right\rVert_{F}^{2}]=\frac{n-r}{n}\cdot\left\lVert AB\right\rVert_{F}^{2}.

∎

Remark 2.6
.

We can output an unbiased estimator by scaling step
6
to be
C=\frac{n}{r}\cdot\mathcal{W}_{\boldsymbol{\alpha},\boldsymbol{\beta}}^{-1}(C^{\prime})
. In this case, if the index
(i,j)
was chosen to be computed in step
5
, then
C_{i,j}^{\prime}=\frac{n}{r}\cdot(A^{\prime}B^{\prime})_{i,j}
, which implies

\left|C_{i,j}^{\prime}-(A^{\prime}B^{\prime})_{i,j}\right|^{2}=\left|\left(\frac{n}{r}-1\right)\cdot(A^{\prime}B^{\prime})_{i,j}\right|^{2}.

Noting that
(n/r-1)^{2}=\frac{n^{2}}{r^{2}}-2\frac{n}{r}+1
,
Equation 2.2
becomes

\displaystyle\mathbb{E}[\left\lVert C^{\prime}-A^{\prime}B^{\prime}\right\rVert_{F}^{2}]

\displaystyle=\sum_{i=0}^{n-r-1}\sum_{j=0}^{n-1}\mathbb{E}[(A^{\prime}B^{\prime})_{i,j}^{2}]+\sum_{i=n-r}^{n-1}\sum_{j=0}^{n-1}\left(\frac{n}{r}-1\right)^{2}\cdot\mathbb{E}\left[(A^{\prime}B^{\prime})_{i,j}^{2}\right]

\displaystyle=\frac{1}{n^{2}}\left(n(n-r)+nr\cdot\left(\frac{n^{2}}{r^{2}}-2\frac{n}{r}+1\right)\right)\cdot\left\lVert AB\right\rVert_{F}^{2}

\displaystyle=\left(1-\frac{r}{n}+\frac{n}{r}-2+\frac{r}{n}\right)\cdot\left\lVert AB\right\rVert_{F}^{2}\leq\frac{n}{r}\cdot\left\lVert AB\right\rVert_{F}^{2}.

This is exactly the variance bound achieved by
[
14
]
, which is the state-of-the-art for unbiased estimators. Thus we recover the same result, with different tools.

Remark 2.7
.

Note that the trivial algorithm of randomly choosing
rn
coordinates and computing their values, while setting all other values to null, achieves the same global guarantee, meaning
\mathbb{E}[C]=\frac{r}{n}AB
and
\mathbb{E}[\left\lVert C-AB\right\rVert_{F}^{2}]=\frac{n-r}{n}\cdot\left\lVert AB\right\rVert_{F}^{2}
. However, the main difference from our approach, or Pagh’s approach
[
14
]
, is the per-entry variance. In this naïve algorithm, we have

\mathbb{E}[(C_{ij}-(AB)_{ij})^{2}]=\frac{n-r}{n}\cdot(AB)_{ij}^{2},

so the variance is related to the magnitude of the
i,j
-th output value. In our algorithm, the per-entry variance is
\frac{n-r}{n}\cdot\frac{\left\lVert AB\right\rVert_{F}^{2}}{n^{2}}
, i.e., the average squared value of the output matrix. If we multiply by
\frac{n}{r}
to obtain unbiased estimators, the per-entry variance becomes
\leq\frac{n}{r}\cdot(AB)_{ij}^{2}
for the naïve algorithm and
\leq\frac{n}{r}\cdot\frac{\left\lVert AB\right\rVert_{F}^{2}}{n^{2}}=\frac{\left\lVert AB\right\rVert_{F}^{2}}{nr}
for our algorithm. This is the same as the per-entry variance of Pagh’s algorithm. This is useful for sparse applications, as demonstrated in Pagh’s original paper.

3
Discussion

This simplification for a known result was recovered when trying to formalize and prove that random Gaussian matrices (or Rademacher matrices), are the hardest case for approximate matrix multiplication algorithms. We hoped to reduce the worst-case to the average case, thus allowing one to obtain algorithms for any (real) matrices from an algorithm that works well (on average) for random matrices (Gaussians or Rademacher).

In the finite field case, a recent work of
[
18
]
shows such a reduction, using cryptographic assumptions. However, these do not extend to the real case. The main failure is the fact real distributions cannot be shift invariant. Unfortunately, the random rotations we present here are not sufficient for such a reduction. First, it is unclear how to define in-distinguishability from a matrix distribution in this context. Second, the rotation doesn’t change the spectral properties of the matrices (since it is unitary), which is in our view a prerequisite for any meaningful reduction (and a distinguishing feature).

Another feature of our algorithm is that it can be amplified to an exact algorithm. In other words, given black box access to the algorithm, running
O(\frac{n}{r}\ln(1/\varepsilon))
independent iterations suffice to obtain a matrix
C
which satisfies
\left\lVert C-AB\right\rVert_{F}^{2}\leq\varepsilon
assuming
\left\lVert AB\right\rVert_{F}=1
. While it has no practical use, since one can just compute the exact product in time
O(n^{3})
, it is a unique feature of this algorithm. As mentioned above, most sketching algorithms inherently corrupt the data, while our algorithm intuitively “peels off” a uniform layer. It is not even clear if any algorithm achieving the same guarantees can be amplified to an exact algorithm. It is interesting to understand what type of constraints do these guarantees impose on a (randomized) bilinear algorithm.

We finish the discussion by pointing out that more improvements might be made to this algorithm. In particular, switching out step
5
with a smarter algorithm might give better results. Any algorithm that works well for Gaussian or Rademacher matrices and relies only on first and second moment properties might extend this result.
