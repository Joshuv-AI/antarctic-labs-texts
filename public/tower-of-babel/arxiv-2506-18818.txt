How Hard is it to be a Star? Convex Geometry and the Real Hierarchy
Marcus Schaefer, Daniel Štefankovič

Abstract
A set is star-shaped if there is a point in the set that can see every other point in the set in the sense that the line-segment connecting the points lies within the set. We show that testing whether a non-empty compact smooth region is star-shaped is ∀ ℝ \mathbf{\bm{\forall\mathbb{R}}} -complete. Since the obvious definition of star-shapedness has logical form ∃ ∀ \exists\forall , this is a somewhat surprising result, based on Krasnosel'skiĭ’s theorem from convex geometry; we study several related complexity classifications in the real hierarchy based on other results from convex geometry.



Keywords.
existential theory of the real numbers, Krasnosel'skiĭ theorem, Helly theorem, Kirchberger theorem, Steinitz theorem, Carathéodory theorem, real hierarchy, computational complexity, semialgebraic sets

Introduction

In an earlier paper
[
22
,
23
]
we studied the computational complexity of properties of semialgebraic sets that can be classified at various levels of the real polynomial hierarchy, such as
\mathbf{\bm{\exists\mathbb{R}}}
,
\mathbf{\bm{\forall\mathbb{R}}}
,
\mathbf{\bm{\exists\forall\mathbb{R}}}
, and
\mathbf{\bm{\forall\exists\mathbb{R}}}
(for background on the existential theory of the reals and the real polynomial hierarchy, see
[
18
,
21
,
23
]
). One of the examples we encountered behaved unexpectedly: the radius problem.

A semialgebraic set
S
has
radius at most
r
if there is a (center) point
c
such that all points in
S
have distance at most
r
from
c
. More formally,

(\exists c\in\mathbb{R}^{d})(\forall x\in\mathbb{R}^{d})\ x\in S\rightarrow\sum_{i=1}^{d}(x_{i}-c_{i})^{2}\leq r^{2}.

So the straightforward definition of radius gives us an
\mathbf{\bm{\exists\forall\mathbb{R}}}
-characterization of deciding whether
S
has radius at most
r
. Using Helly’s theorem, we were able to obtain a
\mathbf{\bm{\forall\exists\mathbb{R}}}
-characterization saying that any
d+1
balls of radius
r
with centers in
S
have a common point, placing the radius problem in
\mathbf{\bm{\exists\forall\mathbb{R}}}\cap\mathbf{\bm{\forall\exists\mathbb{R}}}
. Using duality, the non-emptiness of the intersection of the
d+1
balls can be expressed in
\mathbf{\bm{\forall\mathbb{R}}}
, leading to a
\mathbf{\bm{\forall\mathbb{R}}}
-characterization of the radius problem (for details, see
[
22
, Theorem 3.3]
). Since the problem is easily seen to be
\mathbf{\bm{\forall\mathbb{R}}}
-hard, this settles the complexity of the radius problem for semialgebraic sets.

The radius example inspired us to look for further instances of this effect, in which the combination of a result from convex geometry with duality leads to a surprisingly lower complexity classification than what one would have expected based on the definition of the problem.

Our main result in the current paper is on star-shapedness. A set is
star-shaped
if it contains a point
c
that
sees
all points in the set in the sense that the line segments connecting
c
to any point in the set must belong to the set. We determine the complexity of testing star-shapedness for semialgebraic sets whose boundary is sufficiently smooth; we call these sets smooth regions (for the formal definition see Section
4.2
).

Theorem 1.1
.

Deciding whether a non-empty compact smooth region is star-shaped is
\mathbf{\bm{\forall\mathbb{R}}}
-complete.

The result from convex geometry that makes Theorem
1.1
possible is Krasnosel'skiĭ’s characterization of star-shapedness.

Remark 1.2

(Assumptions)
.

Krasnosel'skiĭ’s characterization needs compactness, which is why we require compactness in Theorem
1.1
. We also require the set to be non-empty, since testing non-emptiness is
\mathbf{\bm{\exists\mathbb{R}}}
-complete, and non-empty sets are not star-shaped by definition; so Theorem
1.1
would not hold without the non-emptiness assumption (unless
\mathbf{\bm{\exists\mathbb{R}}}=\mathbf{\bm{\forall\mathbb{R}}}
), or we redefine empty sets to be star-shaped (which is not done traditionally).

On the other hand, being bounded is
\mathbf{\bm{\forall\mathbb{R}}}
-complete
[
4
, Proposition 6.4,Corollary 9.4]
. The complexity of being closed for a semialgebraic set is unknown; for a basic semialgebraic set, it is known to be
\mathbf{\bm{\forall\mathbb{R}}}
-complete
[
4
, Theorem 6.15]
; since our smooth regions are basic semialgebraic sets it follows that testing compactness for smooth regions lies in
\mathbf{\bm{\forall\mathbb{R}}}
. So we could modify Theorem
1.1
to state that testing whether a non-empty smooth region is star-shaped and compact is
\mathbf{\bm{\forall\mathbb{R}}}
-complete.

Context and Overview

There are quite a number of results already for which the usual definition of a problem does not agree with its eventual complexity classification. Many of these examples involve properties of semialgebraic sets, and go back to papers by Cucker, Rosselló
[

Unboundedness.

A semialgebraic set
S

unbounded

r>0

\lVert x\rVert>r

\mathbf{\bm{\forall\exists\mathbb{R}}}

\mathbf{\bm{\exists\mathbb{R}}}

[

[

[

Dimension.

A semialgebraic set

-complete. Other examples that can be captured using

4
]

There are also examples not based on exotic quantifiers:

Art Gallery Problem.

An art gallery (a polygon) can be guarded by
k
guards if there is a placement of the

guards in the art gallery so that every point in the art gallery can be seen by at least one of the guards. This definition gives an
\mathbf{\bm{\exists\forall\mathbb{R}}}
-characterization of the art gallery problem, but the inner two universal quantifiers can be removed by using the linear structure of the polygon
[

The examples in this paper are different in that they rely on duality and characterizations from convex geometry by Carathéodory, Steinitz, Kirchberger, and Krasnosel'skiĭ to flip quantifiers. The only previous result of this nature we are aware of is the radius problem we discussed above.

Carathéodory, Steinitz and the Convex Hull

We say a point
p
is the
convex combination
of a set of points
p_{1},\ldots,p_{n}
if
p=\sum_{i\in[n]}\lambda_{i}p_{i}

with
\sum_{i\in[n]}\lambda_{i}=1
and
\lambda_{i}\geq 0
for all
i\in[n]
. We also say that
p
lies in the
convex hull

\conv(p_{1},\ldots,p_{n})
of
p_{1},\ldots,p_{n}
.
Carathéodory proved the following theorem
[
28
, Theorem 1.21]
.

Theorem 2.1

(Carathéodory)
.

A point belongs to the convex hull of a set in
\mathbb{R}^{d}
if and only if it is the convex combination of at most
d+1

points of the set.

With this we can settle the complexity of membership in the convex hull of a semialgebraic set.

Theorem 2.2
.

Testing whether a point
q\in\mathbb{Q}^{d}
lies in the convex hull of a semialgebraic set is
\mathbf{\bm{\exists\mathbb{R}}}
-complete.

Proof.

To see
\mathbf{\bm{\exists\mathbb{R}}}
-hardness we reduce from bounded feasibility which is
\mathbf{\bm{\exists\mathbb{R}}}
-complete
[
19
, Lemma 3.9]
; we are given
f:[0,1]^{d}\rightarrow\mathbb{R}
.
Define
S=\{-x,x\in\mathbb{R}^{d}:f(x)=0\}
. If
f
is feasible, then
0
belongs to the convex hull of
S
, otherwise
S
is empty.

Let
S=\{x\in\mathbb{R}^{d}:\varphi(x)\}
. Using Theorem
2.1
we can express that
q
lies in the convex hull of
S
as

\displaystyle(\exists x_{1},

\displaystyle\ldots,x_{d+1}\in\mathbb{R}^{d})(\exists\lambda_{1},\ldots,\lambda_{d+1}\in\mathbb{R}_{\geq 0})

\displaystyle\sum_{i\in[d+1]}\lambda_{i}a_{i}=q\wedge\sum_{i\in[d+1]}\lambda_{i}=1.

This establishes membership in
\mathbf{\bm{\exists\mathbb{R}}}
.
∎

Steinitz proved an extension of Carathéodory’s result that captures the interior of the convex hull
[
9
, Theorem 10.3]
.

Theorem 2.3

(Steinitz)
.

A point lies in the interior of the convex hull of a set in
\mathbb{R}^{d}
if and only if it lies in the interior of the convex hull of at most
2d
points in the set.

The bound of
2d
is known to be optimal, as can be seen by looking at the
2d
points
\{\pm e_{1},\ldots,\pm e_{d}\}
, where
e_{1},\ldots,e_{d}
is the standard basis of
\mathbb{R}^{d}
. With Steinitz’s version of Carathéodory’s theorem, we can show how to recognize the interior of a convex hull in
\mathbf{\bm{\exists\mathbb{R}}}
.

Corollary 2.4
.

Testing whether a point
q\in\mathbb{Q}^{d}
lies in the interior of the convex hull of a semialgebraic set is
\mathbf{\bm{\exists\mathbb{R}}}
-complete.

Call a convex combination
strict
if all the
\lambda_{i}
are positive. Then a point
q
lies in the interior of the convex hull of
2d
points
a_{1},\ldots a_{2d}
if it is a strict convex combination of these points, and the affine space spanned by the points has full dimension, that is, they do not lie in a common hyperplane. Formally, we can write this as

\displaystyle(\exists\lambda_{1},

\displaystyle\ldots,\lambda_{2d}\in\mathbb{R}_{>0})

(1)

\displaystyle\sum_{i\in[2d]}\lambda_{i}a_{i}=q\wedge\sum_{i\in[2d]}\lambda_{i}=1\ \wedge

\displaystyle\neg(\exists u\in\mathbb{R}^{d})\ u\neq 0\wedge\bigwedge_{i\in[2d-1]}(a_{i}-a_{2d})\cdot u=0.

The final condition verifies that the
a_{i}
do not lie on a common hyperplane by expressing that there is no non-trivial normal vector
u
. This gives us a universal characterization. Using duality, we can exchange universal with existential quantification. Consider the existential condition we are using for lying on a common hyperplane:

(\exists u\in\mathbb{R}^{d})\ u\neq 0\wedge\bigwedge_{i\in[2d-1]}(a_{i}-a_{2d})\cdot u=0.

(2)

We can rewrite
u\neq 0
as
\bigvee_{j\in[d]}u_{j}\neq 0
, and, since we can scale
u
, as
\bigvee_{j\in[d]}u_{j}=1
; exchanging the order of the quantifiers and the disjunction we get that (
2
) is equivalent to

\bigvee_{j\in[d]}(\exists u\in\mathbb{R}^{d})\ u_{j}=1\wedge\bigwedge_{i\in[2d-1]}(a_{i}-a_{2d})\cdot u=0.

(3)

Let
A=((a_{1}-a_{2d})^{T}|\cdots|(a_{2d-1}-a_{2d})^{T}|e^{T}_{j})
, where
e_{j}
is the
j
-th vector in the standard basis of
\mathbb{R}^{d}
. Then the inner part of (
3
) can be written as
(\exists u\in\mathbb{R}^{d})\ Au=(0^{d}|1)^{T}
. By Farkas’ lemma, this fails if and only if

(\exists v\in\mathbb{R}^{d+1})\ A^{T}v=0\wedge(0^{d}|1)\cdot v\neq 0
, which simplifies to
(\exists v\in\mathbb{R}^{d+1})\ A^{T}v=0\wedge v_{d+1}\neq 0
.
This allows us to rewrite (
1
) as

\displaystyle(\exists\lambda_{1},

\displaystyle\ldots,\lambda_{2d}\in\mathbb{R}_{>0})

(4)

\displaystyle\sum_{i\in[2d]}\lambda_{i}a_{i}=q\wedge\sum_{i\in[2d]}\lambda_{i}=1\ \wedge

\displaystyle\bigwedge_{j\in[d]}(\exists v\in\mathbb{R}^{d+1})\ A^{T}v=0\wedge v_{d+1}\neq 0,

which is purely existential.

The proof of Corollary
2.4
then follows the proof of Theorem
2.2
, replacing Carathéodory’s Theorem
2.1
with Steinitz’s Theorem
2.3
, and testing whether a point lies in the interior of a set of
2d
points in
\mathbb{R}^{d}
using (
4
).

Steinitz’s theorem also extends to relative interiors, see
[
9
, Theorem 10.4]
, so testing membership in relative interiors is likely
\mathbf{\bm{\exists\mathbb{R}}}
-complete as well.

We can also extend the argument in Theorem
2.2
to apply to the positive (or conic) hull of a set. The
positive hull
of a set
S\subseteq\mathbb{R}^{d}
is defined as
\operatorname{pos}(S)=\{\sum_{i\in[n]}\lambda_{i}a_{i}:a_{i}\in S,n\in\mathbb{N}\}
, the set of all non-negative linear combinations of elements in
S
. Caratheodory’s theorem for cones implies that any element of
\operatorname{pos}(S)
is a non-negative linear combination of at most
d
elements of
S
, using
S\subseteq\mathbb{R}^{d}
.

Corollary 2.5
.

Testing whether a point
q\in\mathbb{Q}^{d}
lies in the positive hull of a semialgebraic set is
\mathbf{\bm{\exists\mathbb{R}}}
-complete.

Kirchberger and Hyperplane Separations

We say two sets
A,B\in\mathbb{R}^{d}
are
(strictly) separated by a hyperplane

H
if there is a
v\in\mathbb{R}^{d}\setminus\{0\}
and
c\in\mathbb{R}
such that

v\cdot a\leq c
and
v\cdot b\geq c
(
v\cdot a<c
and
v\cdot b>c
) for all
a\in A,b\in B
, where
\cdot
is the dot-product of two vectors. We will treat strict separability first and then point out the necessary modifications for separability.

For semialgebraic sets
A=\{x\in\mathbb{R}^{d}:\alpha(x)\}
and
B=\{x\in\mathbb{R}^{d}:\beta(x)\}
we can express being strictly separable by a hyperplane as

(\exists v\in\mathbb{R}^{d})(\exists c\in\mathbb{R})(\forall a\in A)(\forall b\in B)\ v\neq 0\wedge v\cdot a<c\wedge v\cdot b>c,

in other words, the problem lies in
\mathbf{\bm{\exists\forall\mathbb{R}}}
. Enter a theorem proved by Paul Kirchberger, a student of David Hilbert.

Theorem 3.1

(Kirchberger
[
12
]
)
.

If
A
and
B
are compact sets in
\mathbb{R}^{d}
then
A
and
B
can be strictly separated by a hyperplane if and only if
A\cap P
and
B\cap P
can be separated by a hyperplane for every set

of
d+2
points in
A\cup B
.

A proof of this theorem can be found in Valentine’s book
[

.

Theorem 3.2
.

Testing whether two compact semialgebraic sets

and

\mathbb{R}^{d}

\mathbf{\bm{\forall\mathbb{R}}}
-complete.

Proof.

To see
\mathbf{\bm{\forall\mathbb{R}}}
-hardness we reduce from bounded polynomial feasibility, which is
\mathbf{\bm{\exists\mathbb{R}}}
-complete
[
19

A=[-1,1]^{d}

.

To see membership in

A=\{x\in\mathbb{R}^{d}:\alpha(x)\}

Using Kirchberger’s theorem

\displaystyle(\forall a_{1},

\displaystyle\ldots,a_{d+2})(\forall b_{1},\ldots b_{d+2})\

\displaystyle\bigwedge_{i\in[d+2]}\alpha(a_{i})\wedge\beta(b_{i})\rightarrow\conv(a_{1},\ldots,a_{d+2})\cap\conv(b_{1},\ldots,b_{d+2})=\emptyset,

\displaystyle(\forall\lambda_{1},

\displaystyle\ldots,\lambda_{d+2})(\forall\mu_{1},\ldots,\mu_{d+2}\in\mathbb{R}_{\geq 0})

\mathbf{\bm{\forall\mathbb{R}}}

Krasnosel'skiĭ and Star-Shapedness

A set
S
in
\mathbb{R}^{d}
is
star-shaped
if there is a point
q\in S
which sees every point of
S
; here, two points
see
each other if the line segment connecting them belongs to
S
. By definition, star-shapedness of a semilalgebraic set lies in
\mathbf{\bm{\exists\forall\mathbb{R}}}
, since it can be expressed as

(\exists q\in\mathbb{R}^{d})(\forall p\in\mathbb{R}^{d})(\forall\lambda\in[0,1]\ p\in S\rightarrow\lambda p+(1-\lambda)q\in S.

The alternative characterization of star-shapedness we will work with was published by Krasnosel'skiĭ in 1946 in Russian
[
16
]
.

Theorem 4.1

(Krasnosel'skiĭ
[
16
]
)
.

A non-empty compact set
S\subseteq\mathbb{R}^{d}
is star-shaped if and only if every
d+1
points in
S
can see a common point in
S
.

Breen
[
2
]
includes two examples justifying the compactness assumption in Krasnosel'skiĭ’s theorem: an open disk with the center removed shows that the set has to be closed, and—an example from Hare and Kenelly
[
11
]
—the set
S=\cup_{n}T_{n}
, where
T_{n}=\{(x,y):n-1\leq y\leq n,x+y\geq n\}
;
S
is not star-shaped even though for every finite subset of
S
there is a point (even a disk) inside
T_{1}
that can see all points in the set. As Hare and Kenelly observe,
S
does not contain a maximal star-shaped subset.

Using Krasnosel'skiĭ’s theorem we can express the star-shapedness of a non-empty compact set as

(\forall p_{1},\ldots,p_{d+1})(\exists q)\ \bigwedge_{i\in[d+1]}p_{i}\in S\rightarrow\bigwedge_{i\in[d+1]}p_{i}q\subseteq S.

This only gives us a
\mathbf{\bm{\forall\exists\forall\mathbb{R}}}
-characterization of star-shapedness, since the conditions
p_{i}q\subseteq S
hide a universal quantifier. Indeed, we do not know how to improve on this for general semialgebraic sets
S
, instead we will work with a more restricted type of semialgebraic set which we will introduce in Section
4.2
; before that, in Section
4.1
we prove the version of Krasnosel'skiĭ’s theorem we need for our result.

4.1
Krasnosel'skiĭ’s Theorem

The material in this section closely follows the proof of Krasnosel'skiĭ’s theorem as presented in Valentine’s book on convex sets
[
28
, Section 6]
.

Let
S_{x}=\{y:xy\subseteq S\}
, the set of points in
S
visible from
x
, known as the
x
-star of
S
. We call a point
x\in S

spherical
if there is an open ball
B
disjoint from
S
and such that
x
lies on the boundary of
B
(we take this terminology from Cel
[
5
]
; Valentine’s presentation works with a different type of points called regular). Note that a spherical point has to lie on
\partial S
. For a spherical point
x
and such an open ball
B
, let
H
be the closed halfspace disjoint from
B
which is tangential to
B
at
x
; we call
H
a
supporting halfspace
at
x
. We have
S_{x}\subseteq H
; the reason is that any line-segment ending in
x
must intersect
B
or
H
. Let
{\cal H}
be the set of all supporting halfspaces of
S
.

Lemma 4.2

(Krasnosel'skiĭ)
.

Suppose
S\subseteq\mathbb{R}^{d}
is a closed set with
y\in S
, and
x\in\mathbb{R}^{d}
such that
xy\nsubseteq S
. Then there is a spherical point
z\in S
such that
x\notin H
, where
H
is a supporting halfspace at
z
. In particular,
x\notin S_{z}
.

Valentine’s argument
[
28
, Lemma 6.2]
establishes our version of the lemma, but we include a sketch of the proof.

Proof.

Since
xy\nsubseteq S
, there must be a point on
xy
which does not belong to
S
; since
S
is compact, there even is a ball, with center on
xy
such that the closure of the ball is disjoint from
S
. We move the center of that ball along
xy
towards
y
until the closure of the ball intersects
S
; this must happen, eventually, since
y\in S
. For the first such ball
B
(a meaningful definition, since
S
is compact), pick
z
in the intersection of
S
and
B
. Then
B
witnesses that
z
is a spherical point. Let
H
be the supporting halfspace at
z
. Since the center of
B
lies on
xy
and we were moving the ball towards
y
, the point
z
must belong to the half of
B
(as viewed along
xy
) that is closer to
y
; hence
x\notin H
, which completes the proof.
∎

Theorem 4.3

(Krasnosel'skiĭ)
.

Suppose
S\subseteq\mathbb{R}^{d}
is a non-empty compact set and
{\cal H}
is the set of all supporting halfspaces of
S
. Then
S
is star-shaped if and only if the intersection of every
d+1
halfspaces (not necessarily distinct) in
{\cal H}
is non-empty.

The following argument is based on the proof of
[
28
, Theorem 6.17]
; that proof assumes connectivity, which is unnecessary.

Proof.

If
S
is star-shaped, let
c\in S
be a point that sees all points of
S
. It follows that
c
belongs to
S_{x}
for every
x\in S
. If
H\in{\cal H}
, then there is a spherical point
z\in S
for which
S_{z}\subseteq H
, so in particular,
c\in S_{z}\subseteq H
and
c
belongs to the intersection of all halfspaces in
{\cal H}
.

For the other direction, let
T
be a minimal axis-aligned bounding-box for
S
(such a box exists, since
S
is compact). Then
T
is the intersection of
2d
halfspaces in
{\cal H}
, since each of the bounding half-planes must contain a point on the boundary of
S
. We are assuming that the intersection of every
d+1
halfspaces in
{\cal H}
is non-empty, so by the finite version of Helly’s theorem, the intersection of every
2d+(d+1)
halfspaces in
{\cal H}
is non-empty. Since we can always include the
2d
halfspaces whose intersection is
T
, we can conclude that every
d+1
halfspaces in
{\cal H}
contain a point in
T
.

It follows that the intersection of
every
d+1
sets in
\{H\cap T:H\in{\cal H}\}
is non-empty. Since the sets
H\cap T
are convex and compact, we can apply Helly’s theorem to conclude that there is a point
x
that belongs to all halfspaces in

{\cal H}
(this argument works even if
\lvert{\cal H}\rvert\leq d
since we do not require the halfspaces to be distinct). We claim that
x
belongs to
S
and sees all of
S
: Pick an arbitrary point
y\in S
(this is possible since
S\neq\emptyset
). If
xy\nsubseteq S
, then, by
Lemma
4.2
, there is a spherical point
z\in S
such that
x\notin H
, where
H
is a supporting halfspace at
z
. Since
z
is spherical,
H
belongs to
{\cal H}
, contradicting the definition of
x
. It follows that
xy\subseteq S
, so
x\in S
and
x
sees
y
. As
y
was chosen arbitrarily in
S
this implies that
x
sees all of
S
, so
S
is star-shaped.
∎

4.2
Complexity of Star-Shapedness

We call a set
S\subseteq\mathbb{R}^{d}
a
region
if there is an integer polynomial
f\in\mathbb{Z}[x]
such that
S=\{x\in\mathbb{R}^{d}:f(x)\geq 0\}

and the boundary of the set
\partial S
is
\{x\in\mathbb{R}^{d}:f(x)=0\}
, in general one only has
\partial S\subseteq\{x\in\mathbb{R}^{d}:f(x)=0\}
. We call the region
smooth
if the gradient
\nabla f
does not vanish on
\partial S
, that is
(\nabla f)(x)\neq 0
for all
x\in\mathbb{R}^{d}
.

Proof of Theorem
1.1
.

Hardness can be shown using the reduction from
[
22
, Theorem 3.1]
for convexity.

To show membership in
\mathbf{\bm{\exists\mathbb{R}}}
we will use Theorem
4.3
to express star-shapedness of
S
as follows: the intersection of any
d+1
halfspaces in
{\cal H}
contains a point in
T
, where
{\cal H}
is the set of supporting halfspaces for
S
. A supporting half-space can be described by the center
c
of the ball
B
through which it is defined, and the spherical point
z
in which
B
intersects
S
. Since we assumed that
\partial S
is smooth and the gradient does not vanish on
\partial S
, vector
cz
must be a multiple of
(\nabla f)(z)
.

We can therefore express star-shapedness as

\displaystyle(\forall

\displaystyle z_{1},\ldots,z_{d+1}\in\mathbb{R}^{d})\biggl(\bigwedge_{i=1}^{d+1}f(z_{i})=0\biggr)\rightarrow\bigcap_{i=1}^{d+1}H_{i}\neq\emptyset,

where
H_{i}=\{y:(y-z_{i})\cdot(\nabla f)(z_{i})\geq 0\}
, the halfspace through
z_{i}
that is tangent to
S
at
z_{i}
.
Rewriting the main implication
p\rightarrow q
as
\overline{p}\vee q
,

\displaystyle(\forall

\displaystyle z_{1},\ldots,z_{d+1}\in\mathbb{R}^{d})\biggl(\bigvee_{i=1}^{d+1}f(z_{i})\neq 0\biggr)\vee\biggl(\bigcap_{i=1}^{d+1}H_{i}\neq\emptyset\biggr).

We can write the second condition as

(\exists x\in\mathbb{R}^{d})\ \bigwedge_{i=1}^{d+1}(x-z_{i})\cdot(\nabla f)(z_{i})\geq 0.

Using linear programming duality, we can rewrite the second condition

(\forall y\in\mathbb{R}^{d+1}_{\geq 0})\ \biggl(\bigvee_{i=1}^{d}\sum_{j=1}^{d+1}y_{j}(z_{i})_{j}\neq 0\biggr)\vee\biggl(\sum_{j=1}^{d+1}y_{j}(z_{j}\cdot(\nabla f)(z_{i}))\leq 0\biggr).

At this point, we can move all universal quantifiers to the leading block of quantifiers, giving us the required universal characterization, thereby showing that star-shapedness lies in
\mathbf{\bm{\forall\mathbb{R}}}
.
∎

5
Open Questions

We have shown that results from convex geometry, sometimes together with duality, can be used to settle the computational complexity of various properties of semialgebraic sets—at lower levels than might have been expected. Are there more examples like this? E.g. Helly’s theorem can be used to show that testing whether the intersection of a parameterized family of convex sets is nonempty lies in
\mathbf{\bm{\forall\exists\mathbb{R}}}
, is the problem complete for this level? And Kirchberger’s theorem extends to separations by surfaces other than hyperplanes, such as hyperspheres, see
[
9
]
; do these results leads to new complexity results?

Our main result, Theorem
1.1
on star-shapedness, is restricted to what we called smooth regions; this leaves unanswered the question of how hard it is to test star-shapedness of semialgebraic sets in general; while there does not seem to be an intrinsic reason to believe that star-shapedness becomes truly harder in this case, proving so would require much more sophisticated tools than the ones we used here. (Also: does testing star-shapedness remain in
\mathbf{\bm{\forall\mathbb{R}}}
if we drop the compactness assumption?)

Resolving this issue is relevant to determine the complexity of testing cone-shapedness. A set
S
is
cone-shaped
if there is a point
a
such that
(0,\infty)\cdot(S-a)\subseteq S-a
, see
[
10
, Section 3]
. By definition, cone-shapedness lies in
\mathbf{\bm{\exists\forall\mathbb{R}}}
. Smooth regions are not cone-shaped though, so one needs to extend the methods for star-shapedness to work for non-smooth regions as well. Otherwise, cone-shapedness seems a promising candidate for our approach; since there is a Krasnosel'skiĭ-style characterization due to Cel
[
5
]
. He showed that a set
S
in
\mathbb{R}^{d}
is cone-shaped if and only if any
d+1
spherical points (in our definition) are
S
-visible from a common point, where being
S
-visible
means that a ray starting at the common point through the spherical point lies in
S
.

A similar issues arises for other properties; e.g. closedness and compactness are known to be
\mathbf{\bm{\forall\mathbb{R}}}
-complete for
basic
semialgebraic sets
[
4
, Lemma 6.20, Corollary 9]
, but the complexity for semialgebraic sets remains open. Another example we mentioned earlier: the art gallery problem; membership of the art gallery problem in
\mathbf{\bm{\exists\mathbb{R}}}
is based on the underlying set being a polygon; without this restriction, the current best upper bound on the problem is
\mathbf{\bm{\forall\exists\mathbb{R}}}
, and it is not clear whether the universal quantifier can be eliminated in this case.

One could attack the art gallery problem by looking at the case in which only a constant number
k
of guards are allowed; this notion is known as
k
-star-shapedness and has been investigated in the literature, e.g. Koch and Marr
[
13
]
and Larman
[
17
]
proved Krasnosel'skiĭ-style characterization of
2
-star-shaped sets; there seem to be no Krasnosel'skiĭ-style characterizations for larger
k
(though there is a related result for
k=3
in the plane
[
3
]
).

The polygonal vs semialgebraic issue in the art gallery problem also suggests the question of how hard it is to test whether a semialgebraic set is polygonal or polytopal in general. Dumortier, Gyssens, and Vandeurze
[
8
,
7
]
call a semialgebraic set
semilinear
if all the defining equalities and inequalities are linear. They show that recognizing semilinearity lies in
\mathbf{\bm{\forall\exists\forall\mathbb{R}}}
; is this best possible? Is the problem hard for
\mathbf{\bm{\exists\mathbb{R}}}
or
\mathbf{\bm{\forall\mathbb{R}}}
or higher levels? And how about testing whether a semialgebraic set is a simplex?

Finally, star-shapedness itself deserves a closer look; it exists in many variants, see
[
10
]
for a recent survey, some with Krasnosel'skiĭ-style characterizations and these may make good candidates for further examples of unexpected complexity classifications. We’d like to explicitly mention a result by Valentine
[
27
]
on
shoreline visibility
: if every five points in a plane set
S
, the
swimmers
, see a common boundary point of a compact convex set
C
in
\mathbb{R}^{2}
, the
coast
, then all points in
S
can see a common boundary point of
C
(and this remains true with
d+1
points in
\mathbb{R}^{d}
if the boundary is smooth and
C
is strictly convex). Can this result be used to determine the computational complexity of shoreline visibility for
S
and
C
? By definition, shorelines visibility for semialgebraic sets
S
and
C
belongs to
\mathbf{\bm{\exists\forall\mathbb{R}}}
, and Valentine’s result immediately implies a
\mathbf{\bm{\forall\exists\mathbb{R}}}
-characterization (assuming
C
is a smooth region and strictly convex), so that the problem belongs to
\mathbf{\bm{\exists\forall\mathbb{R}}}\cap\mathbf{\bm{\forall\exists\mathbb{R}}}
; can this upper bound be improved?
