Scalable and Optimal Security Allocation in Networks against Stealthy Injection Attacks
Anh Tung Nguyen, Sribalaji C. Anand, André M. H. Teixeira

Abstract
This paper addresses the security allocation problem in a networked control system under stealthy injection attacks. The networked system is comprised of interconnected subsystems which are represented by nodes in a digraph. An adversary compromises the system by injecting false data into several nodes with the aim of maximally disrupting the performance of the network while remaining stealthy to a defender. To minimize the impact of such stealthy attacks, the defender, with limited knowledge about attack policies and attack resources, allocates several sensors on nodes to impose the stealthiness constraint governing the attack policy. We provide an optimal security allocation algorithm to minimize the expected attack impact on the entire network. Furthermore, under a suitable local control design, the proposed security allocation algorithm can be executed in a scalable way. Finally, the obtained results are validated through several numerical examples.

These systems commonly operate

In an attempt to handle cyber attacks, various studies find defense mechanisms by solving optimization problems that formulate the objectives of the malicious adversary and the defender simultaneously. By casting the security allocation problem in the Stackelberg game framework, the authors in
[
7
]
aim to find the game equilibrium by formulating a single optimization problem that accounts for all admissible adversarial actions with a simplified linear mapping from action spaces to game payoffs.
Similarly, Yuan et al. also seek the Stackelberg equilibrium by considering all admissible adversarial actions in the context of industrial control systems in
[
8
]
.
It is worth noting that such a linear mapping may not cover advanced attack policies such as stealthy attacks
[
9
]
, which will be addressed in this paper.
The work in
[
10
]
adopts a slightly different game setup, where both the defender and the adversary have discrete action spaces. The setup allows for the use of the traditional backward induction to determine the Stackelberg equilibrium. However, this requires evaluating all admissible players’ actions, leading to very high computational complexity, as noted in
[
10
, Section V]
. Instead of using the Stackelberg game framework, the authors in
[
9
,
11
]
allow the malicious adversary and the defender make their decisions simultaneously. It is worth noting that a pure equilibrium in such a scenario does not necessarily exist. Alternatively, a mixed-strategy equilibrium notation was employed to outline the defense strategy,
which is also known as moving target defense. As presented in
[
9
]
, the mixed-strategy equilibrium requires an explicit game matrix that accommodates all the possible pairs of players’ actions, probably resulting in a high computational complexity.

One interesting observation among the existing studies
[
7
,
8
,
10
,
9
,
11
]
is that no analysis and computation of the performance loss caused by stealthy attacks (also henceforth referred to as attack impact) on the network has been made.
This issue has been addressed in our previous study
[
12
]
by adopting the output-to-output gain security metric
[
13
]
. Our previous work
[
12
]
mainly studies the graph-theoretical condition under which the security metric is well-posed while this paper studies how to efficiently exploit the security metric given its well-posedness. Moreover, this paper extends a single attack node in
[
12
]
to multiple attack nodes.
Another observation is that explicitly computing the game payoff for all the admissible players’ actions results in an enormous computational complexity.
These two issues are studied in this paper.

In this paper, we consider a continuous-time networked control system, associated with a strongly connected digraph, under stealthy attacks.
The system consists of several interconnected one-dimensional subsystems, known as nodes in the digraph. The adversary aims to maximally degrade the global network performance
by selecting several nodes to execute stealthy data injection attacks on their inputs.
Concurrently, the defender chooses a set of nodes and monitors their outputs with the goal of detecting and mitigating the impact of attacks. The goal of this paper is to find the optimal set of nodes for the defender in an efficient way. We study this security allocation problem and provide the following contributions:

•

The worst-case impact of stealthy attacks on the global network performance is evaluated via a novel Attack-Energy-Constrained Output-to-Output gain security metric.

•

The well-posedness of the proposed security metric is guaranteed and the metric is shown to be equivalent to a semidefinite program (SDP) problem.

•

Without explicitly computing a large matrix game as in
[
7
,
8
,
10
,
9
]
, we propose a novel optimization-based method to find the optimal monitor nodes that minimize the security metric.

•

Further, we show that the optimal monitor nodes can be exactly found in a more scalable optimization problem under a suitable design of local controllers.

II
Problem Formulation

In this section, we first describe a networked control system, with a global performance metric, under stealthy attacks.
Secondly, the adversary and the defender are modeled with opposing objectives.
Finally, we formulate the two main research problems that will be studied in this paper.

II-A

Networked control systems under attacks

In this subsection, we introduce a networked control system in a normal operation without attacks and describe the resources of the adversary and the defender. Subsequently, the system modeling under attacks is formulated.

II-A
1
Networked control systems without attacks

Consider a strongly connected digraph
{\mathcal{G}}\triangleq({\mathcal{V}},\,{\mathcal{E}},\,A,\,\Theta)
with
N
nodes, the state-space model of a one-dimensional node

is described:

\displaystyle\dot{x}_{i}(t)

\displaystyle=A_{ii}x_{i}(t)+u_{i}(t),~i\in{\mathcal{V}}=\bigl\{1,\,2,\ldots,\,N\bigr\},

(1)

where
x_{i}(t)\in{\mathbb{R}}
and
u_{i}(t)\in{\mathbb{R}}
are the state and the local control input, respectively. The local parameter
A_{ii}
is given to the operator.
Each node

\displaystyle u_{i}(t)=-(\theta_{i}+A_{ii})x_{i}(t)+\sum_{j\,\in\,{\mathcal{N}}_{i}}A_{ij}\big(x_{j}(t)-x_{i}(t)\big),

(2)

where
\theta_{i}\in{\mathbb{R}}_{>0}

For convenience, let us denote

x(t)\triangleq\big[x_{1}(t),~x_{2}(t),\ldots,~x_{N}(t)\big]^{\top}
. Therefore, the closed-loop network control system (
1
)-(
2

\displaystyle\dot{x}(t)=-Lx(t),

(3)

where

.

Similar to robust control, the global performance of the entire network for a given, possibly infinite, time horizon

is formulated as follows:

\displaystyle J\triangleq\left\lVert p\right\rVert_{{\mathcal{L}}_{2}[0,H]}^{2}.

(4)

Here, the performance output vector
p(t)\in{\mathbb{R}}^{N}
is defined as follows:

\displaystyle p(t)=Wx(t),

(5)

where
W=\textbf{diag}([w_{i}])

II-A
2
Defense resources

To get prepared for facing malicious activities, the defender selects a subset of the node set
{\mathcal{V}}
as a set of monitor nodes, denoted as
{\mathcal{M}}=\{m_{1},m_{2},\ldots,m_{|{\mathcal{M}}|}\}\subset{\mathcal{V}}
. A sensor is placed on each monitor node to monitor its output, where the number of utilized sensors should be constrained for practical reasons.
Let us denote
\beta\in{\mathbb{R}}_{>0}
as the sensor budget that is the maximum number of utilized sensors, i.e.,

\displaystyle|{\mathcal{M}}|\leq\beta.

(6)

More specifically, the defender monitors the following output measurements:

\displaystyle y_{m}(t)=e^{\top}_{m}x(t),~~\forall\,m\in{\mathcal{M}}.

(7)

At each monitor node
m\in{\mathcal{M}}
, a corresponding alarm threshold
\delta_{m}\in{\mathbb{R}}_{>0}
is assigned. The defender notifies the presence of the adversary if the output energy for a given time horizon
[0,H]
of at least one monitor node crosses its corresponding alarm threshold, i.e.,

\displaystyle\left\lVert y_{m}\right\rVert^{2}_{{\mathcal{L}}_{2}[0,H]}>\delta_{m}.

(8)

For later uses, let us denote the vector of all the alarm thresholds as
\delta\triangleq[\delta_{1},\,\delta_{2},\ldots,\,\delta_{N}]^{\top}
.
Further, each node
i
has a cost
\kappa_{i}\in{\mathbb{R}}_{>0}
, resulting in the following sensor cost of the monitor set
{\mathcal{M}}
:

\displaystyle c_{s}({\mathcal{M}})=\sum_{m\,\in\,{\mathcal{M}}}\kappa^{\top}e_{m},

(9)

where
\kappa=\left[\kappa_{1},\kappa_{2},\ldots,\kappa_{N}\right]
is the given vector of all sensor costs.

II-A
3
Adversary resources

In critical conditions, the adversary gains access to the network and acquires enough information about the system parameters and defense strategies. Then, the adversary conducts the following attack strategies.

The adversary selects exactly
\alpha~(\alpha\leq N)
attack nodes on which to conduct stealthy data injection attacks on their inputs.
Let us denote the set of attack nodes as
{\mathcal{A}}\,(|{\mathcal{A}}|=\alpha)
.
For each attack node
a\in{\mathcal{A}}
, the adversary constructs an additive attack signal
\zeta_{a}(t)
, which is assumed to have bounded energy:

\displaystyle\left\lVert\zeta_{a}\right\rVert^{2}_{{\mathcal{L}}_{2}[0,\infty]}\leq E<\infty,~\forall\,a\in{\mathcal{A}},

(10)

where the maximum attack energy

is given.
Then, the control input in (
2
) under false data injection attacks can be represented as follows:

\displaystyle\tilde{u}_{a}(t)=u_{a}(t)+\begin{cases}\zeta_{a}(t),~~\text{if}~~a\in{\mathcal{A}},\\
0,~~\text{otherwise}.\end{cases}

(11)

Given a set of attack nodes
{\mathcal{A}}\triangleq\{a_{1},a_{2},\ldots,a_{\alpha}\}
, let us denote the corresponding attack input matrix as
B_{\mathcal{A}}\triangleq[e_{a_{1}},e_{a_{2}},\ldots,e_{a_{\alpha}}]
and the attack signal vector as
\zeta(t)\triangleq[\zeta_{a_{1}}(t),\zeta_{a_{2}}(t),\ldots,\zeta_{a_{\alpha}}(t)]^{\top}
.

II-A
4
Networked control systems under attacks

Given the above descriptions of the healthy network (

\displaystyle\dot{x}^{a}(t)

\displaystyle=-Lx^{a}(t)+B_{\mathcal{A}}\zeta(t),

\displaystyle p^{a}(t)

\displaystyle=Wx^{a}(t),

(13)

\displaystyle y^{a}_{m}(t)

\displaystyle=e_{m}^{\top}x^{a}(t),~\forall m\in{\mathcal{M}},

(14)

As a consequence, the impact of attacks on the global performance is formulated as follows:

\displaystyle J^{a}\triangleq\left\lVert p^{a}\right\rVert_{{\mathcal{L}}_{2}[0,H]}^{2}.

\triangleleft

It is worth noting that the bounded energy assumption (

Lemma 1
(Limited end-point attacks)

Consider the system (
12

it holds

\zeta_{a}(\infty)=0,~\forall a\in{\mathcal{A}}
.
\triangleleft

Proof:

(If) based on the discussion right before Lemma

, one considers that
\zeta(t)=0,\forall t\in(T_{a},\,\infty)
. Since

in (
12
) is Hurwitz, the system (

. (Only if) the condition

\lim_{t\rightarrow\infty}x^{a}(t)=0

\lim_{t\rightarrow\infty}\dot{x}^{a}(t)=0
, leading to
\lim_{t\rightarrow\infty}B_{\mathcal{A}}\zeta(t)=0

is full column rank by construction, one has

∎

Assumption 1 and Lemma

allow us to analyze the impact of the stealthy attacks subjected to the two constraints

x^{a}(\infty)=0

In the following, we conduct a deeper investigation into the impact of stealthy attacks, resulting in a novel security metric.

II-B

Adversary model

The purpose of the adversary is to maximally disrupt the global performance of the network (
15
) subject to the network model (
12
)-(
14
) while remaining stealthy to the defender (see the discussion on the importance of the stealthiness in
[
9
, Sec. II.E]
).
The above adversarial purpose allows us to mainly focus on stealthy attacks which will be defined in the following.

Definition 1
(Stealthy injection attacks)

Consider the structure of the continuous LTI system
(
12
)-(
14
) with monitor outputs
y_{m}^{a}(t)=e_{m}^{\top}x^{a}(t)
for every
m\in{\mathcal{M}}
, which is a set of monitor nodes. The attack
\zeta(t)
on the system (
12
)-(
14
) is defined as a stealthy attack if the following condition
\left\lVert y_{m}^{a}\right\rVert^{2}_{{\mathcal{L}}_{2}}\leq\delta_{m}
holds for all
m\in{\mathcal{M}}
.
\triangleleft

The stealthy attack policy in Definition
1
enables the adversary to evaluate the maximum disruption on the network given a set of attack nodes
{\mathcal{A}}
and a set of monitor nodes
{\mathcal{M}}
. Inspired by game theory
[
14
]
, the set of attack nodes
{\mathcal{A}}
can be varied to gain the maximum disruption on the network. As a result, given a set of monitor nodes
{\mathcal{M}}
and the number of attack nodes
\alpha
, the adversary solves the following optimization problem to find the optimal attack set
{\mathcal{A}}
that yields the highest maximum disruption on the network:

\displaystyle Q({\mathcal{M}}\,|\,\alpha)\triangleq\max_{{\mathcal{A}}\,\subset\,{\mathcal{V}},\,|{\mathcal{A}}|=\alpha}

\displaystyle~V({\mathcal{M}},{\mathcal{A}}),

(16)

where
V({\mathcal{M}},{\mathcal{A}})
is the worst-case disruption on the global performance of the network (
15
) and is formulated as follows:

\displaystyle V({\mathcal{M}},{\mathcal{A}})\triangleq~\sup_{\zeta}

\displaystyle~\left\lVert p^{a}\right\rVert_{{\mathcal{L}}_{2}}^{2}

(17)

s.t.

\displaystyle~\eqref{sys:xa}-\eqref{sys:yma},\,x^{a}(0)=0,\,x^{a}(\infty)=0,

\displaystyle\left\lVert y_{m}^{a}\right\rVert^{2}_{{\mathcal{L}}_{2}}\leq\delta_{m},~\forall\,m\in{\mathcal{M}},

\displaystyle\left\lVert e_{j}^{\top}\zeta\right\rVert^{2}_{{\mathcal{L}}_{2}}\leq E,~\forall\,j\in\{1,2,\ldots,|{\mathcal{A}}|\}.

The worst-case disruption (
17
) is an extended version of the Output-to-Output gain security metric proposed in
[
13
]
. This security metric (
17
) is
called an Attack-Energy-Constrained Output-to-Output gain security metric for a given set of attack nodes
{\mathcal{A}}
and a given set of monitor nodes
{\mathcal{M}}
, which plays a crucial role in evaluating the impact of stealthy attacks and finding the optimal monitor set for the defender in the remainder of this paper.
Next, we model the defender who does not have full knowledge of the adversary.

Remark 1

In (
17
), the first constraint is the system modeling of the network while the second and the third constraints are based on the assumption of the attack resources (Assumption

and Lemma

). The last two constraints are the stealthiness condition (

II-C

Defender model

In practice, the defender seldom foresees the number of attack nodes, which is refereed to as attack type,
they need to deal with. In line with
[
9
]
, the defender can know several possible attack types with some probabilities. Let us assume that the defender considers a set of
n_{a}~(n_{a}\leq N)
attack types, which is defined as follows:

\displaystyle{\mathcal{T}}\triangleq\{\alpha_{1},\,\alpha_{2},\ldots,\,\alpha_{n_{a}}\},

(18)

where an attack type
\alpha_{k}~(0<\alpha_{k}\leq N)
has exactly
\alpha_{k}
attack nodes. Here, the attack types in
{\mathcal{T}}
are modeled as random variables, where the probability of each type
\alpha_{k}
is known
a priori
and denoted as
\phi_{k}~(0\leq\phi_{k}\leq 1)
and
\sum_{k=1}^{n_{a}}~\phi_{k}=1
.
The information about these probabilities can be provided by conducting a risk assessment
[
15
]
, which is in line with the Bayesian and the stochastic game settings
[
9
,
16
,
17
]
.
For each attack type
\alpha_{k}
, let us denote
{\mathcal{S}}_{\alpha_{k}}
as a collection of all the admissible attack sets, i.e.,

\displaystyle{\mathcal{S}}_{\alpha_{k}}\triangleq\{{\mathcal{A}}\subseteq{\mathcal{V}}\,|\,|{\mathcal{A}}|=\alpha_{k}\}.

(19)

In risk management, the fewer attack resources adversaries need to mount an attack, the more likely such attacks are to occur, leading to the following reasonable assumption.

Assumption 2

For any pair of attack types
\alpha_{k}
and
\alpha_{l}
, if
\alpha_{k}>\alpha_{l}
, then we assume that
\phi_{k}<\phi_{l}
.
\triangleleft

To deal with all the attack types of
{\mathcal{T}}
defined in (
18
), the defender evaluates all the possible disruptions on the network for every attack type. This evaluation enables the defender to optimally allocate sensors such that the expected disruption is minimized. As a result, given a set of attack types
{\mathcal{T}}
, the defender
solves the following optimization problem:

\displaystyle R({\mathcal{T}}\,|\,\beta)

\displaystyle\triangleq\min_{{\mathcal{M}}\,\subset\,{\mathcal{V}},\,|{\mathcal{M}}|\leq\beta}~\sum_{\alpha_{k}\,\in\,{\mathcal{T}}}~\phi_{k}~U({\mathcal{M}}\,|\,\alpha_{k}),

(20)

where
U({\mathcal{M}}\,|\,\alpha_{k})
is the defense worst-case cost corresponding to
\alpha_{k}
-type adversary who solves (
16
). This cost is defined as follows:

\displaystyle U({\mathcal{M}}\,|\,\alpha_{k})\triangleq c_{s}({\mathcal{M}})+Q({\mathcal{M}}\,|\,\alpha_{k}),

(21)

where the cost of utilized sensors
c_{s}({\mathcal{M}})
is given in (
9
) and
Q({\mathcal{M}}\,|\,\alpha_{k})
is given in (
16
). In the following, we formulate the research problems that will be addressed in this paper.

Remark 2
(Game theory perspective)

The adversary and defender models described in this section are adapted from game theory with incomplete information, which Harsanyi introduced in 1967
[
18
]
. In this paper, the adversary finds the best response by solving (
16
) while the defender, who is uncertain of the adversary’s objective, minimizes the expected value of all the possible adversary’s payoffs (
20
). This information assumption is also considered in Bayesian games, applied in security problems
[
9
,
19
]
. It is worth noting that this game may not yield a pure equilibrium if the two players make decisions simultaneously. To deal with such an issue, the concept of Stackelberg games
[
14
]
is adopted in this paper, in line with
[
7
,
8
,
10
]
, where the adversary is allowed to move after fully observing the defender’s decision.
\triangleleft

VI
Conclusion

We investigated the security allocation problem in a networked control system under stealthy attacks. The uncertainty of the adversary’s resources allowed us to formulate the objective of the defender as an expected defense cost based on the defender’s rational information. Then, we proposed a method that supports the defender in optimally allocating the defense resources based on the expected defense cost. Moreover, by deeply investigating the worst-case disruption, an algorithm is presented
to analyze the impact of stealthy attacks and to find the optimal monitor set in a scalable manner.

, the variables

\displaystyle\omega_{{\mathcal{A}}}\,\leq\,\hat{V}_{\infty}z,\,\forall\,{{\mathcal{A}}}\in{\mathcal{S}}_{\alpha_{k}},\,\forall\,\alpha_{k}\in{\mathcal{T}}.

(49)

Finally, by substituting (

\blacksquare

A.2
Proof of Theorem

We next provide a result that aids the proof of Theorem
2
.

Proposition 1

Let us consider a continuous LTI system
\Sigma
with a state-space model:
\dot{x}(t)=Ax(t)+Bu(t),~y_{1}(t)=C_{1}x(t),~y_{2}(t)=C_{2}x(t)

where
A
is a Metzler matrix,

{B}\in{\mathbb{R}}^{n\times m}_{\geq 0},{C_{1}}\in{\mathbb{R}}^{p_{1}\times n}_{\geq 0},
and
{C_{2}}\in{\mathbb{R}}^{p_{2}\times m}_{\geq 0}

Let us consider a quadratic supply rate
s(\cdot,\cdot)=||\Gamma^{\frac{1}{2}}u||^{2}+\left\lVert y_{1}\right\rVert^{2}-\left\lVert y_{2}\right\rVert^{2}
where
\Gamma
is a positive diagonal matrix and let
C_{2}^{\top}C_{2}\geq C_{1}^{\top}C_{1}
where the inequality applies element-wise. Then the following statements are equivalent.

1.

For all trajectories of the system with
x(0)=0,
we have
\int_{0}^{T}s(\cdot,\cdot)\geq 0
;

2.

There exists a diagonal matrix
P\in{\mathbb{S}}^{n}_{>0}
such that

\begin{bmatrix}A^{\top}P+PA&PB\\
B^{\top}P&0\end{bmatrix}+M\leq 0,

(50)

where

.
\triangleleft

A.3
Proof of Lemma
6

Let us assume that (
43
) does not hold. In the following, we show that an increase of all the local self-loop gains in
\Theta
strictly reduces the value of
V_{\infty}({\mathcal{A}})
, resulting in the fulfillment of (
43
).

Let us add a positive diagonal matrix
\Delta\Theta\succ 0
to the self-loop gain matrix
\Theta
, resulting in the changed Laplacian matrix, which can be denoted as
\tilde{L}\triangleq L+\Delta\Theta
. The problem (
36
) corresponding to the changed Laplacian matrix
\tilde{L}
can be computed by the following SDP, which is adapted from (
30
):

\displaystyle\tilde{V}_{\infty}({\mathcal{A}})=\min_{\psi_{{\mathcal{A}}}\,\in\,{\mathbb{R}}^{|{\mathcal{A}}|}_{>0},\,P^{\mathcal{A}}\,\in\,{\mathbb{S}}^{N}_{\succeq 0}}~E~\textbf{1}^{\top}\psi_{{\mathcal{A}}}

(54)

s.t.

\displaystyle~\left[\begin{array}[]{cc}-\tilde{L}^{\top}P_{{\mathcal{A}}}-P_{{\mathcal{A}}}\tilde{L}+W^{2}&P_{{\mathcal{A}}}B_{\mathcal{A}}\\
B_{\mathcal{A}}^{\top}P_{{\mathcal{A}}}&-\,\textbf{diag}(\psi_{{\mathcal{A}}})\\
\end{array}\right]\preceq 0.

Since
\tilde{L}
is Hurwitz and
W
is a positive diagonal matrix, the necessary condition
for (
54
) is
P_{\mathcal{A}}\succ 0
(top left block).
Thus, the constraint in (
54
) can be rewritten as follows:

\displaystyle\left[\begin{array}[]{cc}-L^{\top}P_{{\mathcal{A}}}-P_{{\mathcal{A}}}L+\tilde{W}^{\top}\tilde{W}&P_{{\mathcal{A}}}B_{\mathcal{A}}\\
B_{\mathcal{A}}^{\top}P_{{\mathcal{A}}}&-\,\textbf{diag}(\psi_{{\mathcal{A}}})\\
\end{array}\right]\preceq 0,

where
\tilde{W}^{\top}\tilde{W}=W^{2}-\Delta\Theta P^{\mathcal{A}}-P^{\mathcal{A}}\Delta\Theta\prec W^{2}
by the symmetric property.
Then, the optimization problem (
54
) is the dual form of the following optimization problem, which is adapted from (
17
):

\displaystyle\tilde{V}_{\infty}({\mathcal{A}})\triangleq

\displaystyle\sup_{\zeta}~\left\lVert\tilde{W}W^{-1}p^{a}\right\rVert_{{\mathcal{L}}_{2}}^{2}

(57)

s.t.

\displaystyle\eqref{sys:xa}-\eqref{sys:yma},\,x^{a}(0)=0,\,x^{a}(\infty)=0,

\displaystyle\left\lVert e_{j}^{\top}\zeta\right\rVert^{2}_{{\mathcal{L}}_{2}}\leq E,~\forall\,j\in\{1,2,\ldots,|{\mathcal{A}}|\}.

From
\tilde{W}^{\top}\tilde{W}\prec W^{2}
, (
36
), and (
57
), one has
\tilde{V}_{\infty}({\mathcal{A}})<V_{\infty}({\mathcal{A}})
by construction, which completes the proof.
\blacksquare
