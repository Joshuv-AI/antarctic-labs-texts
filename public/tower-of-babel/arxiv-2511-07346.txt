On Subexponential Parameterized Algorithms for Steiner Tree on Intersection Graphs of Geometric Objects
Sujoy Bhore, Barış Can Esmer, Dániel Marx, Karol Węgrzycki

Abstract
We study the Steiner Tree problem on the intersection graph of most natural families of geometric objects, e.g., disks, squares, polygons, etc. Given a set of n n objects in the plane and a subset T T of t t terminal objects, the task is to find a subset S S of k k objects such that the intersection graph of S ∪ T S\cup T is connected. Given how typical parameterized problems behave on planar graphs and geometric intersection graphs, we would expect that exact algorithms with some form of subexponential dependence on the solution size or the number of terminals exist. Contrary to this expectation, we show that, assuming the Exponential-Time Hypothesis (ETH), there is no 2 o ⁡ ( k + t ) ⋅ n O ⁡ ( 1 ) 2^{o(k+t)}\cdot n^{O(1)} time algorithm even for unit disks or unit squares, that is, there is no FPT algorithm subexponential in the size of the Steiner tree. However, subexponential dependence can appear in a different form: we show that Steiner Tree can be solved in time n O ⁡ ( t ) n^{O(\sqrt{t})} for many natural classes of objects, including: • Disks of arbitrary size. • Axis-parallel squares of arbitrary size. • Similarly-sized fat polygons. This in particular significantly improves and generalizes two recent results: (1) Steiner Tree on unit disks can be solved in time n O ⁡ ( k + t ) n^{O(\sqrt{k+t})} (Bhore, Carmi, Kolay, and Zehavi, Algorithmica 2023) and (2) Steiner Tree on planar graphs can be solved in time n O ⁡ ( t ) n^{O(\sqrt{t})} (Marx, Pilipczuk, and Pilipczuk, FOCS 2018). We complement our algorithms with lower bounds that demonstrate that the class of objects cannot be significantly extended, even if we allow the running time to be n o ⁡ ( k + t ) / log ⁡ ( k + t ) n^{o(k+t)/\log(k+t)} .

The

Lower bounds for other classes of objects.

Finally, we show that the restrictions on the set of objects cannot be
significantly relaxed. The main lower bound applies for the case when terminals are points and the other objects are “almost-squares” of roughly the same size (in the proof, we are reusing a construction of Chan and Grant
[
7
]
).

Theorem 1.8.

Assuming ETH, for any
\varepsilon>0
, there is no
n^{o((k+t)/\log(k+t))}
time algorithm
for Steiner Tree on the intersection graph of a given set of objects, where
every terminal is a point and every other object is an axis-parallel rectangle with side length in
[1,1+\varepsilon]
.

This lower bound limits the set of objects that can be considered in
two ways. First, by replacing each point with a sufficiently small
square, we obtain a lower bound for the case where every object is an
almost square (of arbitrary size). Thus, our result for squares of
arbitrary sizes cannot be further generalized, even by a small relaxation
of the aspect ratio.

Corollary 1.9.

Assuming ETH, for any
\varepsilon>0
, there is no
n^{o((k+t)/\log(k+t))}
time algorithm for Steiner Tree for the intersection graph of a given set of axis-parallel rectangles, even if every rectangle has aspect ratio in
[1-\varepsilon,1+\varepsilon]
.

Corollary
1.9
highlights the significance of disks and
squares in our algorithmic results: it is not only the fatness of the
objects that matters, but also the metric properties of disks and
squares. Therefore, it is unavoidable that our algorithms need to consider two different
classes of objects: similarly sized fat objects and disks/squares. It is in fact
surprising that these two classes can be handled by the same algorithm.

A different way to look at Theorem
1.8
is to consider each
terminal point to be a disk of appropriately small size and to consider the
almost squares as similarly sized fat objects. This shows that when combining
similarly sized fat objects and disks, it is essential to require that the size
of disks is at least comparable to the size of the fat objects.

Corollary 1.10.

Assuming ETH, for any
\varepsilon>0
, there is no
n^{o((k+t)/\log(k+t))}
time algorithm for Steiner Tree for the intersection graph of a given set of objects, even where each object is a disk or an axis-parallel rectangle with side length in
[1,1+\varepsilon]
.

Technical Overview

In this section, we formally present our main results, along with all
assumptions, outline the main stages of our algorithms, and discuss key proof ideas.

2.1
Geometric problems

Let us formally define the Steiner Tree problem on geometric objects. To ensure generality, we define a weighted version of the problem (and in later steps of the proof, it will be essential that we can create weighted instances).

Geometric Steiner Tree

Input:

Set
\mathtt{OBJ}
of connected objects in the plane with a positive weight function
w
, and a subset
T\subseteq\mathtt{OBJ}
.

Find:

A set
S\subseteq\mathtt{OBJ}
such that the intersection graph of
S\cup T
is connected

Goal:
Minimize the total weight of
S

To make this problem definition precise, we need to specify how the set

\mathtt{OBJ}
is represented in the input. We restrict our attention to simple polygons and disks. We consider the input size
|I|
of the instance
(\mathtt{OBJ},w,T)
to be the total complexity of these objects, that is, the total number of vertices of the polygons plus the number of disks. To avoid dealing with degeneracies and numerical issues, we assume that an arrangement of
\mathtt{OBJ}
is given in the input: a description of all intersection points, intersecting sides, and how they are connected. Note that the total size of the arrangement is polynomial in the total complexity of the objects; such differences do not matter in our running times.

As mentioned above, we need the requirement that the disks cannot be smaller than the similarly sized fat objects. For every
\alpha\geqslant 4
, we formalize this assumption as follows:

Assumption (A
\alpha
)
.

As set
\mathtt{OBJ}
of geometric objects in the plane satisfies (A
\alpha
) if every object in
\mathtt{OBJ}
is either:

•

(fat)
a simple polygon of diameter at most
\alpha/4
and that contains a unit-diameter disk, or

•

(disk)
a disk of radius at least 1.

Our main geometric result is the following:

Theorem 2.1 (Main Result).

For every
\alpha\geqslant 4
,
Geometric Steiner Tree
with Assumption (A
\alpha
) can be solved in time
|I|^{O_{\alpha}(\sqrt{|T|})}
.

In particular, Theorem
2.1
implies
|I|^{O(\sqrt{|T|})}
time algorithms for
unit squares, unit disks, and disks of arbitrary radii.

We remark that squares are in some sense very similar to disks: an axis-parallel square rotated 45 degrees can be described as a set of points at
L_{1}
-distance at most
r
from a center. This can be used to show that the reduction from geometric problems to planar graph problems described in the next section also works for axis-parallel squares. Therefore, all our algorithmic results work if disks are replaced by axis-parallel squares.

2.2
Translation to planar graphs

The main technical tool we rely on is the Voronoi separator technique of Marx
and Pilipczuk
[
35
]
, which is formulated for planar
graphs. Therefore, at some point, we need to create a planar graph
representation of our geometric problem. To this end, we define the Steiner Tree
problem on objects that are connected subgraphs of a planar graph. There is one
important technicality: we consider two objects connected not only if they
intersect, but also if they are adjacent by an edge. The reason for this is that the
Voronoi separator technique applies to a pairwise nonintersecting collection of
connected objects. Therefore, we need to allow that pairwise disjoint objects
form a connected solution, which would be clearly impossible if connectivity
required direct intersection.

An
object

is a connected subset of vertices in
G
.
Two objects
O_{1}
and
O_{2}
in
G

if they share a vertex or there
is an edge of
G
between a vertex of
O_{1}
and a vertex of
O_{2}

touching graph
of a set
\mathtt{OBJ}
of objects in
G
, denoted by

\textup{Touch}(\mathtt{OBJ})
, has

\mathtt{OBJ}
as vertex sets and two objects are adjacent if and only if the two objects
touch in
G
. We refer to the set of objects in
\mathtt{OBJ}
and the corresponding
vertices in their touching graph interchangeably.
A set
S
of objects in
G
is
connected
if
\textup{Touch}(S)
is a connected graph.

We formulate our planar problem, to include a cardinality constraint in addition
to the optimization goal (if we want to ignore the cardinality constraint, we
may set

Minimize the total weight of

.

Given an instance

of
Planar Object Steiner Tree
, the size
|I|
of the instance is the number
of vertices of the graph plus the total number of vertices of the objects in

\mathtt{OBJ}

|I|
is polynomial in
|V(G)|
and
|\mathtt{OBJ}|
. Formally,
the set
S\subseteq\mathtt{OBJ}
(excluding the terminals) is the solution to the optimization problem
Planar Object Steiner Tree
, but sometimes we informally refer to
S\cup T

We would like to reduce an instance of
Geometric Steiner Tree
satisfying (A
\alpha
) to an
instance of
Planar Object Steiner Tree

Planar Object Steiner Tree
efficiently for

Geometric Steiner Tree
satisfies (A
\alpha

\alpha
) in the planar graph setting. Being a disk has a natural analog in planar graphs a
disk
(or

)
B(v,r)
in an edge-weighted graph

is the set of vertices at distance at most
r
from
v
. The diameter of a connected subgraph
S
of a planar graph
G
also has a natural interpretation: it is the largest distance between any two vertices of
S
(note that here we allow that the shortest path between two vertices of
S
goes outside

, i.e., we mean weak diameter).

However, formalizing fatness by saying that some disk
B(v,\alpha)
is fully contained in the object does not have the intended effect. Suppose that every object has a radius at most
\alpha
. Let some object
S
be contained in the disk
B(v,\alpha)
. Let us attach a new pendant vertex
v^{\prime}
to
v
and let
\alpha
be the length of the edge
vv^{\prime}
. Let us extend
S
with this extra vertex
v^{\prime}
; the new object
S^{\prime}=S\cup\{v^{\prime}\}
intersects the same objects as
S
does. Moreover,
S^{\prime}
is still in
B(v,\alpha)
(hence has radius at most
\alpha
) and
S^{\prime}
contains the disk
B(v^{\prime},\alpha)
. Repeating this for every vertex, we obtain an equivalent instance where every object has radius at most
\alpha
and every object contains a disk of radius
\alpha
. This shows that the property of containing a disk of radius
\alpha
does not bring any extra algorithmic advantage in the context of planar graphs.

A key insight in our algorithmic framework is to formalize fatness in planar graphs in a different, more abstract way. We want to capture an important property of similarly sized fat
objects: while the input may contain a large clique of such objects, it is
unlikely that a solution will contain a large clique. Intuitively, if we remove the clique, the neighborhood cannot break into too many components (as there is no space for many independent objects in the neighborhood). As a result, a few objects of the clique are already sufficient to reconnect them.

Theorem 2.3.

For every

The natural approach to prove Lemma

of vertices that is contained in

•

The set

is not necessarily connected if an object
O^{*}
is fully contained in
O

•

Let

be a disk of radius
r

O^{\prime}=B(v,r)
be the corresponding object in

. It is not clear at all whether some vertex
v^{\prime}
of the arrangement is in

, then

is in

is at most

and

•

Even if a fat object

The second part of the proof of Lemma

\alpha

However, here is the first point where it is essential that the disk objects are not very small: otherwise, a large clique may be needed to cover many small disk terminals. Furthermore, we need to preprocess the instance such that the terminals are independent.

When proving Lemma

in Section

2.3
Reducing the number of objects in the solution

The size of the solution
S
can be, of course, much larger than the number
t=|T|
of terminals: if the terminals are far from each other, then they may be connected by long chains of intersecting objects. These chains may meet and overlap each other, but our next crucial insight is that such interactions are somewhat rare: there are only
O(t)
objects that participate in such interactions, and the remaining objects are inside chains of objects (see Figure
1
). Therefore, the solution can be described by
O(t)
objects and
O(t)
independent chains connecting these objects. The following combinatorial lemma shows that this is indeed possible:

Theorem 2.4.

Let

be a connected graph and

be a subset of vertices with

.
Suppose that, for any

, the graph

Notice that

vertices of degree at least three.

We enrich the set
\mathtt{OBJ}
by new objects in a way that allows us to represent each long chain with a single object. For every
x,y\in V(G)
, let us compute the cheapest connected set

of objects covering both

and

(this can be computed by an appropriate shortest path computation in the touching graph of

). Let us introduce an object

that is an arbitrary

. Let us set the cost of

to be the total cost of

. Observe that adding such objects does not change the cost of the optimum solution: if

appears in the solution, then it can always be replaced by the set

of objects without increasing the cost. Thus, if such objects are available, then we can replace each of the
O(|T|)

O(|T|)

The introduction of these objects may ruin the property (B
\alpha
) of the solution: in particular, it may no longer be true that every non-disk object has diameter
\alpha
. However, if we perform the replacement of chains with such “long” objects in a careful way, then we can ensure that these new objects are completely disjoint from every other object in the solution. To take into account this third type of object, we define the following assumption.

Assumption (C
\alpha
)
.

A set
S\cup T
of objects in an edge-weighted graph

\alpha
) there is an

and an injective function
\tau:S\cup T\to V(G)
with
\tau(O)\in O
for every

such that the objects in
S\cup T
can be partitioned into

•

(fat)
has diameter at most
\alpha

•

(disk)
is

for some

with
\tau(B(v,r))=v
, and

•

(long)
is an arbitrary connected subset.

Moreover, this partition satisfies:

•

Every long object in

is disjoint from every other object in
S\cup T
.

•

For every

, the ball
B(v,4\alpha)
intersects at most

.

•

For every long or fat object

1000\alpha^{2}

The last point is an additional technical requirement, which can be satisfied by making sure that if a fat object

is close to one of the endpoints of

\alpha

Lemma 2.5.

For every fixed
\alpha>0
, there is a polynomial-time algorithm that transforms

(G,\infty,\mathtt{OBJ},T)
of
Planar Object Steiner Tree
that has an optimum solution with assumption (B
\alpha
) into an equivalent instance
(G^{\prime},k^{\prime},\mathtt{OBJ}^{\prime},T^{\prime})
of
Planar Object Steiner Tree
that has an optimum solution with assumption (C
\alpha
) such that
|T^{\prime}|=|T|
and

hold.

In the following, our goal is to solve an instance of

where some optimum solution satisfies
(C
\alpha
). Importantly, now the exponent of the running time can depend on the cardinality of the solution: we have created instances where this can be assumed to be linear in the number of terminals. We formalize this goal in the following theorem.

Theorem 2.6.

For every
\alpha\geqslant 1
, if there is an optimum solution of an instance of

.

2.4
Voronoi separators

Marx and Pilipczuk
[
35
]
present two versions of their main result on enumerating Voronoi separators: a simpler version (Lemma 2.1 in
[
35
]
) that considers disjoint sets of objects, and a more powerful version (Theorem 4.22 in
[
35
]
) that can handle, in particular, disks of arbitrary radii that may intersect other objects and each other. It may seem that the more powerful version is precisely the right tool for our application, as
overlapping disks are also possible in a solution for the Steiner Tree problem. However, even this more powerful version does not handle overlapping fat objects; hence, we need to obtain a disjoint representation of the solution anyway. This is a technical detail that we will discuss shortly in
Section

2.6
(see Lemma
2.13
). As we can obtain this disjoint representation even for overlapping disks, there is no real gain in using the more powerful version. Therefore, we use the simpler Lemma 2.1 from
[
35
]
, which requires considerably simpler definitions and involves much fewer technical details.

Let
G
be an edge-weighted graph and
{\mathcal{D}}
be a set of
d
objects (connected subsets of vertices). A
guarded
separator
is a pair
(Q,\Gamma)
consisting of a set

Q\subseteq{\mathcal{D}}
of objects and a subset

\Gamma\subseteq V(G)
of vertices. We assume that distances are unique in
G
, that is,
\mathrm{dist}_{G}(a,b)\neq\mathrm{dist}_{G}(c,d)
if
\{a,b\}\neq\{c,d\}
. This can be achieved by slightly perturbing the weights of the edges.

Theorem 2.7 (Lemma 2.1 in
[
35
]
).

Let
G
be an edge-weighted
n
-vertex planar graph,
{\mathcal{D}}
a set of

d
connected subsets of
V(G)
, and
k
an integer. We can
enumerate (in time polynomial in the size of the output) a set

\mathcal{N}
of
d^{O(\sqrt{k})}
pairs
(Q,\Gamma)
with

Q\subseteq{\mathcal{D}}
,
|Q|=O(\sqrt{k})
,
\Gamma\subseteq V(G)
such
that the following holds. If
{\mathcal{F}}\subseteq{\mathcal{D}}
is a set of
k

pairwise disjoint objects, then there is a pair
(Q,\Gamma)\in\mathcal{N}
such that

(a)

Q\subseteq{\mathcal{F}}
,

(b)

for every
v\in\Gamma
and
p\in{\mathcal{F}}\setminus Q

\mathrm{dist}_{G}(p,v)>\min_{p^{\prime}\in Q}\mathrm{dist}_{G}(p^{\prime},v)
.

(c)

for every connected component
C
of
G-\Gamma
, there are at most

\frac{2}{3}k
objects of
{\mathcal{F}}
that are fully contained in
C
.

Theorem
2.7
is typically used in the following way. The set
{\mathcal{F}}
of disjoint objects is an unknown solution to a problem. We enumerate the collection
\mathcal{N}
of pairs described in the Theorem, guess one of these pairs
(Q,\Gamma)
, and assume that it satisfies items (a)–(c). In particular, by item (a), we guessed that
Q
is part of the solution. Item (b) implies that no object of
{\mathcal{F}}\setminus Q
intersects
\Gamma
: otherwise, the distance of that object would be zero to a vertex
v
of
\Gamma
, strictly larger than the distance of any object in
Q
to
v
. Therefore, depending on the problem, it could be possible to recursively solve subproblems, where each subproblem consists of
Q
and the objects in a component of
G-\Gamma
. Item (c) shows that the number of objects in the solution for these subproblems is a constant factor lower than in the original problem.

An algorithm using Theorem
2.7
can be imagined as a branching algorithm that branches into
n^{O(\sqrt{k})}
directions in each step of the recursion, where
k
is the solution size of the current subproblem. The size of the branching tree can be bounded by the product of the number of directions in each level. Since the size
k
of the solution decreases by a constant factor in each level of the recursion, the exponent of the running time can be bounded by a geometric series starting with
O(\sqrt{k})
. That is, the running time is
n^{O(\sqrt{k})}
.

We need a version of Theorem
2.7
that is stronger in two ways:

•

Instead of a balance condition on the components of
G-\Gamma
, we want to have a balanced bipartition of
V(G)\setminus\Gamma
. A
guarded separation
is a tuple
(Q,\Gamma,A,B)
where
(\Gamma,A,B)
is a partition of
V(G)
such that there is no edge between
A
and
B
. In item (c), we want to bound the number of objects fully contained in
A
and the number of objects fully contained in
B
.

•

Instead of giving a balance condition on the number of objects from
{\mathcal{F}}
, we need to satisfy the balance condition with respect to an unknown subset
{\mathcal{F}}_{0}\subseteq{\mathcal{F}}
.

We can prove these strengthening of Theorem
2.7
, with a
slight loss in the balance condition. To achieve the first property, we
observe that given the components of
G-\Gamma
, we can enumerate a bounded
number of bipartitions
(A,B)
of these components such that one of them
results in a balanced separator. For the second property, we slightly modify
the graph
G
and the set
{\mathcal{D}}
of objects, and then whenever we want to have
a separation of
{\mathcal{F}}
that is balanced with respect to the objects in

{\mathcal{F}}_{0}
, we invoke the result for the set
{\mathcal{F}}^{\prime}\supseteq{\mathcal{F}}
that contains
some number
c
additional objects close to each object in
{\mathcal{F}}_{0}
. Thus
whether a separation is balanced with respect to
{\mathcal{F}}^{\prime}
mainly depends on
whether it is balanced with respect to these additional objects, hence in the
end depends on whether it is balanced with respect to the objects in
{\mathcal{F}}_{0}
.

Theorem 2.8.

Let

2.5
Recursion

To facilitate recursions, we need to consider a slightly more general problem. In the recursion step, we guess a set
Q
of objects in the solution that breaks the solution into two parts, one part containing terminals
T_{1}
, and the other part containing terminals
T_{2}
. It is now tempting to try to solve the problem recursively, with the first subproblem finding a tree connecting
Q\cup T_{1}
, and the second subproblem finding a tree connecting
Q\cup T_{2}
. While the union of these two solutions would certainly connect
Q\cup T_{1}\cup T_{2}
, it is not necessarily true that an optimum solution arises this way. It is possible that in the optimum solution, the first part does not provide a full connection of
Q\cup T_{1}
, the second part does not provide a full connection of
Q\cup T_{2}
, but the solution still fully connects
Q\cup T_{1}\cup T_{2}
(see Figure
2
).

Figure 2
:
A solution with a separator
Q
that breaks the solution into two disconnected parts.

Intuitively, when solving a subproblem, we should assume that there is already some kind of connection on
Q
(provided by another subproblem), and we want to achieve full connection of
Q
and the terminals. Therefore, we define the following extension of
Planar Object Steiner Tree
, where the input contains a distinguished set
X
of terminals and a “provided connectivity” on
X
, described by a graph
F
.

Extended Planar Object Steiner Tree

Input:

An edge-weighted planar graph
G
, integer
k
,
set
\mathtt{OBJ}
of connected objects in
G
with a positive weight function, subsets
X\subseteq T\subseteq\mathtt{OBJ}
, and a forest
F
with vertex set
X
.

Find:

A set
S\subseteq\mathtt{OBJ}
of cardinality
at most
k
such that the union of
\textup{Touch}(S\cup T)
and
F
is connected in
G
.

Goal:
Minimize the total weight of
S
.

To prove
Theorem

2.9
, we will focus on establishing the following
theorem.

Theorem 2.9.

For every
\alpha\geqslant 1
, if there is an optimum solution of an instance of
Extended Planar Object Steiner Tree
satisfying Assumption (C
\alpha
), then an optimum solution can be found in time
|X|^{|X|}|I|^{O_{\alpha}(\sqrt{k+|T|})}
.

We formalize now the properties of a triple
(T_{1},T_{2},Q)
that allows us to execute the recursion.

Definition 2.10
.

Consider an instance
(G,k,\mathtt{OBJ},T,X,F)
of
Extended Planar Object Steiner Tree
and let
(T_{1},T_{2},Q)
be a triple where
Q\subseteq\mathtt{OBJ}
and
(T_{1},T_{2})
is a partition of
T\setminus Q
. We say that
(T_{1},T_{2},Q)
is a
\beta
-balanced triple
of a solution

if
Q\subseteq S\cup T
and there is a bipartition
(A,B)
of
(S\cup T)\setminus Q
such that

•

A\cap T=T_{1}
and
B\cap T=T_{2}
,

•

|A|,|B|\leqslant\beta|S\cup T|
, and

•

every object in
T
is in the same component of the graph
H
defined by removing every
A-B
edge from
\textup{Touch}(S\cup T)
and then adding the edges of
F
.

We show that, given access to a balanced triple, we can reduce the problem to
“smaller” subproblems. However, there is a technicality related to Assumption
(C
\alpha
) that needs to be addressed. Ideally, we would like to say that if every optimum solution of the original instance satisfies (C
\alpha
), then every optimum solution of every subproblem also satisfies (C
\alpha
) as well. However, it is both cumbersome and unnecessary to prove this. In light of the way Theorem
2.9
is stated, it is sufficient to say that if there is a “nice” solution, then we return an arbitrary solution that is at least as good. Formally, we say that an algorithm
weakly solves instance
I
of
Extended Planar Object Steiner Tree
under Assumption (C
\alpha
)
if it returns a solution that is not worse than any solution of
I
satisfying Assumption (C
\alpha
). The main recursion step can be formulated in the following way:

Lemma 2.11.

Let
I=(G,k,\mathtt{OBJ},T,X,F)
be an instance of
Extended Planar Object Steiner Tree
. If a
\beta
-balanced triple
(T_{1},T_{2},Q)
is given for a solution
S
that has minimum cost among those satisfying Assumption (C
\alpha
), then in time
2^{O(|Q\cup X|\log|Q\cup X|)}\textup{poly}(|I|)
we can reduce weakly solving
I
under Assumption (C
\alpha
) to weakly solving
k\cdot 2^{O(|Q\cup X|\log|Q\cup X|)}
instances under Assumption (C
\alpha
), where each such instance
(G,k^{\prime},\mathtt{OBJ},T^{\prime},X^{\prime},F^{\prime})
satisfies
|T^{\prime}|\leqslant|T\cup Q|
,
|X^{\prime}|\leqslant|X\cup Q|
,
k^{\prime}\leqslant\beta k
.

The proof of Lemma
2.11
uses the definition of a

\beta
-balanced triple in a fairly straightforward way. However, we have to be
careful not to follow a natural approach that does not work: Suppose that
splitting the optimum solution at the separator creates two forests,
W_{A}
and

W_{B}
. Let
F_{A}
(resp.,
F_{B}
) be a forest representing how the components of

W_{A}
(resp.,
W_{B}
) connect the vertices of
Q
. The natural approach would be
to guess these forests
F_{A}
and
F_{B}
, move
Q
into the set
X^{\prime}
of
distinguished terminals, and solve two subproblems: in the first, we need to
connect
T_{1}\cup Q
assuming connectivity
F_{B}
on
Q
is present, and in the
second, we need to connect
T_{2}\cup Q
, assuming connectivity
F_{A}
on
Q
is
present. However, somewhat counterintuitively, if
W^{\prime}_{A}
and
W^{\prime}_{B}
are
solutions of these two instances, respectively, then it is not necessarily true that
W^{\prime}_{A}\cup W^{\prime}_{B}
really connects

: see Figure
3
for an example.

:
Replacing two parts of the solution by alternative solutions that are compatible with the original other part may not result in a solution connecting all three red terminals.

Therefore, the proof of Lemma
2.11
proceeds in a slightly different way. First, we guess the connectivity
F_{B}
provided by
W_{B}
. Then we solve a subproblem where
we need to connect
T_{1}\cup Q
assuming connectivity
F_{B}
on

is present; let
W^{\prime}_{A}
be the solution obtained this way. Let
F_{A}
be a forest representing how the components of
W^{\prime}_{A}
connect the vertices of

, and let us solve the subproblem where we need to connect

assuming connectivity
F_{A}
on

is present; let
W^{\prime}_{B}
be the resulting solution. Now
W^{\prime}_{A}\cup W^{\prime}_{B}
is indeed a solution and we can argue that

and

The last ingredient in our algorithmic framework is showing that we can list
|I|^{O_{\alpha}(\sqrt{k+|T|})}
candidates for the balanced triple

.
For technical reasons, the following lemma has two very mild conditions. We say that a set

of objects is

if for every

, the vertex set
O\setminus\bigcup_{O^{\prime}\in T,O\neq O^{\prime}}O^{\prime}
is nonempty. Note that if
O\subseteq\bigcup_{O^{\prime}\in T,O\neq O^{\prime}}O^{\prime}
for some

, then removing
O
from

does not change the problem at all (besides decreasing the cost by the cost of
O
). Indeed, removing

cannot disconnect the solution of the original instance, and adding

to the solution of the new instance maintains connectivity. We say that a solution

is

if no proper subset of

is a solution; clearly, it is sufficient to restrict our attention to inclusionwise minimal solutions.

Lemma 2.12.

Given an instance
(G,k,\mathtt{OBJ},T,X,F)
where

is irredundant, in time

|I|^{O_{\alpha}(\sqrt{k+|T|})}
we can list a set of

|I|^{O_{\alpha}(\sqrt{k+|T|})}

(T_{1},T_{2},Q)
such that
|Q|=O_{\alpha}(\sqrt{k+|T|})
and for every inclusionwise minimal solution

satisfying Assumption (C
\alpha
) at least
one of them is a
\frac{3}{4}
-balanced triple.

In the proof of Lemma
2.12
, we first invoke Lemma
2.13
to argue that there is a disjoint representation
W
of the objects in the hypothetical solution
S\cup T
. Theorem
2.8
lists a set of guarded separations
(Q,\Gamma)
, one of them being balanced for this disjoint representation

. We need to turn guarded separations
(Q,\Gamma)
for the objects in
W
into balanced triples
(T_{1},T_{2},Q^{\prime})
. There is an intuitive way of doing this:
let
Q^{\prime}
contain an object of
S\cup T
if a corresponding object of
W
is in
Q
, and let us define
T_{1}
and
T_{2}
somehow based on the partition
(A,B)
. However, there are some technical challenges. Recall that in the disjoint representation

, multiple objects could correspond to a single object
S\cup T
. Therefore, being balanced with respect to the objects in
W
does not necessarily mean being balanced with respect to the objects in
S\cup T
. To solve this issue, we use that Theorem
2.8
can guarantee balance with respect to a subset of the objects: we define a subset
W^{*}
containing one object of

corresponding to each object of
S\cup T
, and require balance with respect to
W^{*}
.

An additional fundamental issue is that two objects of
W
could be in different components of
G-\Gamma
, even if they both correspond to the same object of
S\cup T
. For disk objects in
S\cup T
, Lemma
2.13
guarantees that the corresponding objects form a connected set. This means that if these objects are in two different components of
G-\Gamma
, then one of them intersects
\Gamma
. This means that the object intersecting
\Gamma
is in
Q
, and hence the disk object was selected into the separator
Q^{\prime}
. However, for a fat object
O
of
S\cup T
we have no such guarantee: the corresponding set
W_{O}
of objects in
W
is potentially not connected. This is the point where the properties of Assumption (C
\alpha
) come into play. If
W_{0}
contains objects from two different components of
G-\Gamma
, then the diameter property of
O
implies that one object of
W_{0}
is close to a vertex
v
of
\Gamma
. Now item (b) of Theorem
2.8
implies that there is an object in
Q
that is even closer to
v
. This means that
O
has to be an object close to some object in
Q^{\prime}
. Therefore, we can avoid the issue if we extend
Q^{\prime}
with every object that is close to some object in
Q^{\prime}
. The conditions of Assumption (C
\alpha
) imply that for each object in
Q^{\prime}
, we introduce only
O_{\alpha}(1)
additional objects into
Q^{\prime}
.

2.6
Disjoint representation of the solution

The Voronoi separator tools that we would like to use from the work of Marx and Pilipczuk
[
35
]
are applicable to disjoint subsets of connected objects in graphs. However, in general, the objects of the solution in the Steiner Tree problem are not disjoint; thus, it seems that those tools, as stated, are not applicable in our case. Nevertheless, we show that, by introducing new objects (shortest paths inside objects), we can create a representation of the solution that consists of disjoint objects. This representation is then used to argue that certain balanced separators exist.
To ensure disjointness of the objects, each original object is potentially represented by multiple new objects (see Figure
4
).

:
Representing a solution (red terminals and black non-terminals) with disjoint objects (green).

Lemma 2.13.

Let
\mathtt{OBJ}^{\prime}
contain

•

every object in
\mathtt{OBJ}
,

•

for every object
O\in\mathtt{OBJ}
and every

a
shortest path between
x
and

in
G[O]
.

Let
S\cup T
be a solution of
Extended Planar Object Steiner Tree
satisfying (C
\alpha
) and let
\tau:S\cup T\to V(G)
be the injective function defined in this assumption. Then there is a subset
W\subseteq\mathtt{OBJ}^{\prime}

of size
O(|S|+|T|)
and a mapping
\pi:W\to S\cup T
such that

1.

if
t_{1},t_{2}\in T
are in the same component
of
\textup{Touch}(S\cup T)
, then
\tau(t_{1})
and
\tau(t_{2})
are covered by one component of
\textup{Touch}(W)
.

2.

objects in
W
are pairwise disjoint.

3.

if
\pi(R^{\prime})
is long, then
R^{\prime}=\pi(R^{\prime})
.

4.

if
\pi(R^{\prime})
is fat, then
R^{\prime}
is a shortest
path in
G[\pi(R^{\prime})]
.

5.

if
\pi(R^{\prime})
is a disk

, then
R^{\prime}
is
either a shortest path in
G[B(v,r)\setminus B(v,r-3\alpha)]
, or
a shortest path of length

in
G[B(v,r-3\alpha)]
.

6.

for every
R\in S\cup T
that is a disk, the
set
\pi^{-1}(R)
is connected and
\{\tau(R)\}\in\pi^{-1}(R)
.

7.

\{\tau(R)\}\in W
for every fat object
R\in S\cup T
(but it is not necessarily true that
\pi(\{\tau(R)\})=R
).

8.

if

is a fat object that is a subset of a disk object in

, then
\pi^{-1}(O)=\emptyset
.

Note that for each disk object, we require that its representatives form a
connected set, but we do not require this for fat objects. In fact, it would be
impossible to require that two crossing objects are represented in a way that
the representatives of each object are connected. The proof of
Lemma
2.13
is an iterative process. We first identify the vertices
that need to be connected together to ensure global connectivity. Then we
iteratively add new objects from
\mathtt{OBJ}^{\prime}
to

, independent from those already in

, to ensure connectivity of these vertices. To ensure the connectivity of the objects representing disks (item

2.7
Lower bounds

A standard technique for proving lower bounds for planar and geometric problems is to reduce from the so-called
Grid Tiling
problem (see, e.g.,
[
12
]
).

Grid Tiling

Input:
integers
k
and
N
, a collection
\mathcal{S}=\{S_{i,j}\}_{1\leqslant i,j\leqslant k}
of
k^{2}
non-empty sets where
S_{i,j}\subseteq[N]\times[N]
for
1\leqslant i,j\leqslant k

Question:
Is there
s_{i,j}\in S_{i,j}
for each
1\leqslant i,j\leqslant k
such that

•

If
s_{i,j}=(a,b)
and
s_{i+1,j}=(a^{\prime},b^{\prime})
, then
a=a^{\prime}

•

If
s_{i,j}=(a,b)
and
s_{i,j+1}=(a^{\prime},b^{\prime})
, then
b=b^{\prime}
.

Intuitively, we can imagine the problem instance as
k\times k
grid, where
k
pieces of information are propagated horizontally, another
k
pieces of information are propagated vertically, and whenever a horizontal and a vertical piece meet, there is a restriction on what combination of values they can take. Note that each piece of information is a choice of an element from
[N]
.
In the proof of Theorem
1.1
(showing that there is no
subexponential FPT algorithms for Steiner Tree in planar graphs), Marx,
Pilipczuk, and Pilipczuk
[
34
]
implicitly proved a
hardness result for a variant of
Grid Tiling
, where each piece of information
that propagates horizontally is a choice from
[N]
, but each piece of information
that propagates vertically is a single bit. We formally introduce this problem and state lower bounds for it, which will be used as the starting point of our lower bounds for Steiner Tree on geometric objects.

Narrow Grid Tiling

Input:
integers
x,y
, integer
N
, a collection
\mathcal{S}=\{S_{i,j}\}_{(i,j)\in[x]\times[y]}
of
x\cdot y
non-empty sets where
S_{i,j}\subseteq\{0,1\}\times[N]
for
(i,j)\in[x]\times[y]
.

Question:
Is there
s_{i,j}\in S_{i,j}
for each
(i,j)\in[x]\times[y]
such that

•

If
s_{i,j}=(a,b)
and
s_{i+1,j}=(a^{\prime},b^{\prime})
, then
a=a^{\prime}

•

If
s_{i,j}=(a,b)
and
s_{i,j+1}=(a^{\prime},b^{\prime})
, then
b=b^{\prime}
.

Observe that there is a simple brute-force
2^{O(y)}N^{O(1)}
time algorithm,
which guesses each of the
y
bits of information propagated vertically. We show
that this is essentially optimal: assuming ETH, we cannot improve
2^{O(y)}
to

2^{o(y)}
. In fact, we prove the stronger statement that there is no algorithm
subexponential in the number
xy
of cells:

Theorem 2.14.

Assuming ETH, there is no
2^{o(xy)}N^{O(1)}
time algorithm for
Narrow Grid Tiling
.

The actual precise statement is even stronger, to allow some leeway for further reductions (see Theorem
5.1
).

In reductions involving geometric objects, it is often much easier to express
\leqslant
constraints than
=
constraints: for example, the horizontal position of an object has to be at least/at most some value in order for the object to intersect/not intersect some other object. This motivated the introduction of a version of
Grid Tiling
where
a\leqslant a^{\prime}
and
b\leqslant b^{\prime}
appear as requirements in the problem definition. We introduce a similar variant of
Narrow Grid Tiling
, where the horizontally propagated information can increase monotonically, but the vertically propagated information remains the same.

Monotone Narrow Grid Tiling

Input:
integers
x,y
, integer
N
, a collection
\mathcal{S}=\{S_{i,j}\}_{(i,j)\in[x]\times[y]}
of
x\cdot y
non-empty sets where
S_{i,j}\subseteq\{0,1\}\times[N]
for
(i,j)\in[x]\times[y]

Question:
Is there
s_{i,j}\in S_{i,j}
for each
(i,j)\in[x]\times[y]
such that

•

If
s_{i,j}=(a,b)
and
s_{i+1,j}=(a^{\prime},b^{\prime})
, then
a=a^{\prime}

•

If
s_{i,j}=(a,b)
and
s_{i,j+1}=(a^{\prime},b^{\prime})
, then
b\leqslant b^{\prime}
.

We prove a lower bound similar to Theorem
2.14
for
Monotone Narrow Grid Tiling
as well. Here, it becomes important that we show a slightly stronger bound in
Theorem
5.1
, as this additional power allows us to implement extra checks to enforce that the horizontally propagated information does not change.

Theorem 2.15.

Assuming ETH, there is no
2^{o(s)}N^{O(1)}
time algorithm for
Monotone Narrow Grid Tiling
, where
s=xy
.

To prove Theorem
1.4
(ruling out
2^{o(s)}n^{O(1)}
algorithms for Steiner Tree on unit squares), we present a reduction from
Monotone Narrow Grid Tiling
. The reduction uses a crossing gadget (see Figure
9
) that allows to transfer a single bit of information vertically, in a way that the solution Steiner Tree is not connected vertically. The gadget occupies an area of height roughly
h
and width roughly
\omega
. The gadget has four interface objects
u_{NW}
,
u_{NW}
,
u_{SW}
,
u_{SE}
, one in each corner, which are the only objects that can intersect other objects outside the gadget. The gadget contains four terminal objects, and obviously, the solution needs to connect each of them to at least one of the interface objects. The construction of the gadget ensures that there are only two optimal ways of doing this: (1) every terminal is connected to either
u_{NW}
or
u_{SE}
, or (2) every terminal is connected to either
u_{NE}
and
u_{SW}
, and in both cases, the north and south interfaces vertices are not connected inside the gadget. Moreover, every other subset that violates these properties has a higher cost.

We reduce from
Monotone Narrow Grid Tiling
using copies of this gadget. The reduction is using very crucially that we are working with intersection graphs and hence the input can contain large cliques. Each of the
x
rows of the
Monotone Narrow Grid Tiling
instance is expressed by about
\omega\cdot y
cliques of unit squares. In each clique, the top left corner of each square is close to the point
(p,q)
for some integers
p,q
; more precisely, it is of the form
(p+b\varepsilon,q+a\varepsilon)
for some
b\in[N]
and
a\in\{0,1\}
. That is, each square has
N
possible horizontal offsets and two possible vertical offsets. Each cell is represented by a block of
\omega
such cliques next to each other, and
y
such blocks form a line representing one row of the input
Monotone Narrow Grid Tiling
instance (see Figure
11
). In a solution, we are supposed to select exactly one square from each clique, and the squares selected from the cliques of a line are supposed to be connected. In particular, this means that the horizontal offsets of the squares should be nonincreasing, otherwise two adjacent squares would not intersect. Therefore, we can interpret the horizontal offset in block
(i,j)
as the second component of
s_{i,j}
in the solution to
Monotone Narrow Grid Tiling
and we interpret the vertical offset as the first component. Then we add a
y
copies of the crossing gadget between two rows to ensure that the vertical offset is consistent in two vertically adjacent blocks, hence the first component of
s_{i,j}
and
s_{i+1,j}
agrees. We need careful global arguments to ensure that every cheap solution is of the required form; in particular, no such solution creates a connection between two rows through a crossing gadget. The reduction shows that a
Monotone Narrow Grid Tiling
instance can be reduced to Steiner Tree on unit disk graphs with
O(xy)
terminals, thus we can establish the lower bound using Theorem
2.15
.

Preliminaries and Notation

In this section, we give an overview of the standard notation and definitions used throughout the paper and remind the reader of the definitions of concepts from the previous section.
Usually,
n\coloneqq|V(G)|
,
t\coloneqq|T|
is the number of terminals, and
k\coloneqq|S|
is the cardinality of the solution.
Unless stated otherwise, costs and running times are polynomial in the size of the input, denoted
|I|
.
We use the notations
\widetilde{O}(\cdot)
to hide polylogarithmic factors and
O_{\alpha}(\cdot)
hides constants depending only on
\alpha
. For any
N\in\mathbb{N}
we write
[N]\coloneqq\{1,\dots,N\}
. All logarithms are taken to base 2.

Graphs and distances.

We work with finite, undirected graphs whose edges carry non-negative real
lengths (sometimes also called weights). For a graph
G
, the shortest-path
distance between vertices
u,v\in V(G)
is denoted by
\mathrm{dist}_{G}(u,v)
. For a
vertex set
X\subseteq V(G)
we write
\mathrm{dist}_{G}(u,X)\coloneqq\min_{x\in X}\mathrm{dist}_{G}(u,x)
. The (closed) ball of radius
r\geqslant 0
around
v\in V(G)
is

B_{G}(v,r)\coloneqq\{\,x\in V(G)\mid\mathrm{dist}_{G}(v,x)\leqslant r\}
, and we abbreviate

B_{G}(v,r)
as
B(v,r)
when the graph is clear from the context. The weak
diameter of a connected vertex set
S\subseteq V(G)
is
\max_{x,y\in S}\mathrm{dist}_{G}(x,y)
, that is, distances are measured in the ambient graph
G
and
paths may leave
S
. When convenient, we assume distances are made unique by an
infinitesimal perturbation of edge lengths; this yields unique shortest paths
and unique nearest objects without affecting any combinatorial argument.

Objects and the touching graph.

Throughout this paper, we use
\mathtt{OBJ}
to denote a set of objects and typically use
O
to denote an individual object. An object is a connected subset
O\subseteq V(G)
. Two objects
O_{1},O_{2}

touch
if either
O_{1}\cap O_{2}\neq\emptyset
or there exists an edge of
G
with one endpoint in
O_{1}
and the other in
O_{2}
. For a family
\mathtt{OBJ}
of objects, the
touching graph

\textup{Touch}(\mathtt{OBJ})
is the graph with vertex set
\mathtt{OBJ}
in which two vertices are adjacent exactly when the corresponding objects touch. A subfamily
\mathcal{A}\subseteq\mathtt{OBJ}
is
connected
if
\textup{Touch}(\mathcal{A})
is connected. We say that objects are
disjoint
(or
independent
) if the sets of their vertices are disjoint. For a subfamily
\mathcal{A}
we use
\bigcup\mathcal{A}\subseteq V(G)
to denote the set of vertices covered by the objects of
\mathcal{A}
, and we freely identify an object
O
with the induced subgraph
G[O]
when discussing paths inside
O
. We recall that in the context of Assumptions (A
\alpha
) and (C
\alpha
), objects are classified into the following types:

•

(fat)
A simple polygon (in the geometric setting) or a connected subgraph (in the planar setting) of diameter at most
O(\alpha)
, which also contains a unit-diameter disk (geometrically) or disk of radius at least 1 (in planar graphs).

•

(disk)
A disk of radius at least 1 (in the geometric setting) or a ball
B(v,r)
in an edge-weighted graph
G
for some vertex
v
and radius
r\geqslant 4\alpha
(in the planar setting).

•

(long)
(in Assumption (C
\alpha
) only) An arbitrary connected subset that is disjoint from every other object in the solution.

A set
T
of objects is
irredundant
if for every
O\in T
, the vertex set
O\setminus\bigcup_{O^{\prime}\in T,O^{\prime}\neq O}O^{\prime}
is nonempty. A solution
S
is
inclusionwise minimal
if no proper subset of
S
is a solution.
For a solution
S\cup T
satisfying Assumption (C
\alpha
), a set
W\subseteq\mathtt{OBJ}^{\prime}
together with a mapping
\pi:W\to S\cup T
is called a
disjoint representation
if the objects in
W
are pairwise disjoint and satisfy the properties stated in Lemma
2.13
.

Hardness assumption.

The Exponential Time Hypothesis (ETH), is a widely used assumption in fine-grained complexity. It can be formally stated as follows: There exists
\delta>0
such that 3-SAT with
n
variables cannot be solved in time
O(2^{\delta\cdot n})
.
See
[
27
,
12
]
for more details on ETH and its implications.

Proofs of the algorithmic results

In this section, we go over the proofs of the statements presented in the overview (Section
2
). The proofs are presented in the same order as the statements appeared.

4.1
Lemma
2.2
(reduction to the planar problem)

As described in Section
2.2
, our first step is translating the geometric problem into a planar problem. We prove here Lemma
2.2
, restated for reference.

See
2.2

As a first preprocessing step, we construct an instance where the terminal objects are pairwise disjoint.

Lemma 4.1.

For every fixed
\alpha>0
, there is a polynomial-time algorithm that transforms an instance
(\mathtt{OBJ},T)
of
Geometric Steiner Tree
with assumption (A
\alpha
) to an instance
(\mathtt{OBJ}^{\prime},T^{\prime})
of
Geometric Steiner Tree
also satisfying assumption (A
\alpha
) such that
|T^{\prime}|\leqslant|T|
, the optimum value of the two instances differ by less than
1/2
, and the objects in
T^{\prime}
are pairwise disjoint.

Proof.

Let
T^{\prime}
be an arbitrary maximal independent set of
T
and let us pick an arbitrary
t\in T^{\prime}
. The set
\mathtt{OBJ}^{\prime}
is the same as
\mathtt{OBJ}
, but with a weight function
w^{\prime}
that is slightly different from the original weight function
w
: we set

•

w^{\prime}(O)=1/(3|T\setminus T^{\prime}|)
for every
O\in T\setminus T^{\prime}
,

•

w^{\prime}(t)=w(t)+w(T\setminus T^{\prime})
, and

•

w^{\prime}(O)=w(O)
for every
O\in\mathtt{OBJ}\setminus(T\setminus(T^{\prime}\cup\{t\}))
.

It is clear that (A
\alpha
) holds, as the set of objects is the same. Let us observe that a solution
S\cup T
of the original instance is also a solution of the new instance, as it is connected and includes
T^{\prime}
. However, the weight of the solution increases by exactly
1/3
: the original weight of the objects in
T\setminus T^{\prime}
is accounted for in
w^{\prime}(t)
, and furthermore each object in
T^{\prime}\setminus T
incurs an extra weight of
1/(3|T\setminus T^{\prime}|)
. Thus, the optimum of the new instance is at most
1/3
larger than the original optimum.

Consider now an optimum solution
S^{\prime}\cup T^{\prime}
of the new instance and let
S=S^{\prime}\setminus(T\setminus T)
. We claim that
S\cup T=S^{\prime}\cup T^{\prime}\cup(T\setminus T^{\prime})
is a feasible solution of the original instance. Indeed, the intersection graph of
S^{\prime}\cup T^{\prime}
is connected and, by the maximal choice of
T^{\prime}
, every object in
T\setminus T^{\prime}
intersects an object in
T^{\prime}
, hence the intersection graph of
S^{\prime}\cup T^{\prime}\cup(T\setminus T^{\prime})
is also connected. Let us show that
w(S\cup T)\leqslant w^{\prime}(S^{\prime}\cup T^{\prime})
. Indeed, the only difference appears on
T\setminus T^{\prime}
and on
t
: the weight of
t
is lower by
w(T\setminus T^{\prime})
on the left-hand side, compensating any potential increase from members of
T\setminus T^{\prime}
appearing on the left-hand side. Thus, we can conclude that the optimum of the new instance cannot be lower than the original optimum.
∎

Next, we show a basic consequence of (A
\alpha
): an optimum solution cannot be very dense.

Lemma 4.2.

Let
(\mathtt{OBJ},T)
be an instance of
Geometric Steiner Tree
with assumption (A
\alpha
) where
T
is a set of pairwise disjoint objects and let
S\cup T
be an optimum solution. Then every ball of radius
4\alpha
in the plane intersects at most
1000\alpha^{2}
objects in
S\cup T
.

Proof.

Let
B
be a ball of radius
4\alpha
centered around some point
p
.
Let
S^{\prime}\subseteq S
be obtained in the following way: we start with
S^{\prime}\subseteq S
containing those objects that do not intersect
B
and then we repeatedly add objects from
S
to
S^{\prime}
if they do not intersect any object already in
S^{\prime}\cup T
. Observe that when this process stops, the objects in
S^{\prime}\cup T
intersecting the ball

are pairwise independent, as no two objects in
T
intersect by assumption.

Let us bound the number of objects in
S^{\prime}\cup T
intersecting
B
. Let
B^{\prime}
be the ball of radius
4\alpha+1
centered at
p
. If
O
is a fat object intersecting
B
, then its diameter is at most
\alpha/4\geqslant 1
, hence
O
is contained in
B^{\prime}
, implying that the unit-diameter disk in

is in ball
B^{\prime}
. If
O
is a disk intersecting
B
, then it has radius at least 1. In particular, this means that it contains a unit-diameter disk that intersects
B
and hence this disk is contained in
B^{\prime}
. It follows that the objects in
S^{\prime}\cup T
intersecting
B
are pairwise disjoint and each of them contains a unit-diameter disk contained in the ball
B^{\prime}
or radius
4\alpha+1
. Now, a simple area bound shows that there are at most
100\alpha^{2}
such objects.

Unlike
S\cup T
, which had a connected intersection graph, the intersection graph of
S^{\prime}\cup T
may have some number

of connected components. Each such component has to have an object that intersects the ball

(otherwise,

would not be able to reconnect

). Let us select one such object from each component; this gives us a set

of

. By the previous paragraph, we have

.

Next, we reconnect

by reintroducing some objects from

of the intersection graph of

and let us select a minimal subset

of

that connects this component to some other component. Let us observe that

can intersect

can intersect some other component, and if an object of

does not intersect any object of

, then this would contradict the initial maximal choice of

. Thus, by adding two objects to

The optimality of the solution

implies that this reconnection process reintroduces all objects in

, and

can have at most

has at most

objects intersecting

∎

4.7
Analyzing the recursion

Here we conclude the proof of
Theorem

2.9
: weakly solving an instance of
Extended Planar Object Steiner Tree
under assumption (C
\alpha
).
The algorithm is a branching procedure described as follows. Assume we are given an instance

(G,k,\mathtt{OBJ},T,X,F)
of
Extended Planar Object Steiner Tree
.

In each step, we need to first handle a technicality. If the set
T
of terminals is not irredundant, then we can replace it with a subset
T_{0}\subseteq T
of irredundant terminals that has the same union as
T
. This decreases the cost of the optimum solution exactly by the cost of
T\setminus T_{0}
: removing
T\setminus T_{0}
does not disconnect any solution of the original instance, and adding
T\setminus T_{0}
to any solution of the instance maintains connectivity. Moreover, if a solution of the original instance satisfies Assumption (C
\alpha
), then this is true even after removing
T\setminus T_{0}
(the conditions about the bound on the number of certain objects still hold). Therefore, weakly solving the original instance under Assumption (C
\alpha
) can be reduced to weakly solving the modified instance under Assumption (C
\alpha
).

In the following, we assume that
T
is irredundant.
Therefore, we can use
Lemma

2.12
to list

|I|^{O_{\alpha}(\sqrt{k+|T|})}
triples and guess a
\frac{3}{4}
-balanced
triple
(T_{1},T_{2},Q)
for the instance
(G,k,\mathtt{OBJ},T,X,F)
. Then
we invoke
Lemma

2.11
and branch into
instances
(G,k^{\prime},\mathtt{OBJ},T^{\prime},X^{\prime},F^{\prime})
that
satisfy
|X^{\prime}|\leqslant|X|+|Q|\leqslant|T|+|Q|
,
|E(F^{\prime})|\geqslant|E(F)|
. Moreover, as stated by Lemma
2.11
, for every integer
c
, we branch into

O(k|X\cup Q|^{2c})=|I|^{2c}
instances with
|E(F^{\prime})|\leqslant|E(F)|+c
.
Because
(T_{1},T_{2},Q)
is a

\frac{3}{4}
-balanced triple we have that
k^{\prime}+|T^{\prime}|\leqslant\frac{3}{4}(k+|T|)+|Q|
.
As
|Q|=O_{\alpha}(\sqrt{k+|T|})
, we can assume that
k+|T|
decreases by a constant factor in each step. The base case of the algorithm occurs when
k^{\prime}=O(1)
, which can be solved naively in

|I|^{O(1)}
time. Note that
|X^{\prime}|\leqslant|X|+|Q|
and since
|Q|=O_{\alpha}(\sqrt{k+|T|})
decreases by a constant factor in each step, the size of
|X|
is always
O_{\alpha}(\sqrt{k+|T|})
for the original
k
and
|T|
.

The correctness of the algorithm follows from the correctness of

Lemmas

2.12
and
2.11
(here we implicitly use that a solution has the minimum cost among those satisfying Assumption (C
\alpha
) can be assumed to be an inclusionwise minimal solution). For the running time,
observe that the degree of the branching procedure is

\sum_{c=|F|}^{|X|}|I|^{2c}\cdot|I|^{O_{\alpha}(\sqrt{k+|T|})}
.
More precisely, in each step, each new constructed instance can be described by a triple
(i,c,j)
: we selected the
i
-th triple
(T_{1},T_{2},Q)
for the list returned by
Lemma

2.12
, the constructed instance satisfies
|E(F^{\prime})|=|E(F)|+c
for some
c
, and this is the
j
-th such instance. Each leaf of the recursion tree can be described by a sequence of such triples. To bound the number of leaves of the recursion tree, we bound the number of possible such sequences.

First, in each step, there are
|I|^{O_{\alpha}(\sqrt{k+|T|})}
possibilities for

i
. Since
k+|T|
decreases by a constant factor in each step, the product of
these possibilities has a decreasing geometric series in the exponent, hence the
total number of possibilities for the values of
i
in this sequence is also

|I|^{O_{\alpha}(\sqrt{k+|T|})}
. The sequence of
c
’s is a sequence of
non-negative integers that add up at most to the final size of
|X|
, which is

O_{\alpha}(\sqrt{k+|T|})
. It is known that there are

2^{O_{\alpha}(\sqrt{k+|T|})}
such sequences. Finally, in each triple
(i,c,j)
,
after fixing
i
and
c
, the value of
j
can take
|I|^{O(c)}
possibilities.
Thus, if the
c
’s are fixed in a sequence, then the number of possibilities for
the
j
’s can be bounded by
|I|
to a power that is the sum of the
c
’s, that
is,
|I|^{O_{\alpha}(\sqrt{k+|T|})}
. Therefore, we can conclude that there are

|I|^{O_{\alpha}(\sqrt{k+|T|})}
such possible sequences and hence the branching
tree has at most that many leaves. As the total work to be done at all nodes of the branching tree is polynomial in
|I|^{O_{\alpha}(\sqrt{k+|T|})}
, this bounds the total running time.

Using sparsification lemma

Assume now that there exists

such that for all

Lemma 5.3.

Let

be a power of two and define

.
For each
1\leqslant i\leqslant\ell
, define the sets

as

\displaystyle A_{i}

\displaystyle\coloneqq\Big\{(s[i],s)\mid 1\leqslant s\leqslant N\Big\}

\displaystyle B_{i}

\displaystyle\coloneqq\Big\{\Bigl(\overline{s[i]},s\Bigr)\mid 1\leqslant s\leqslant N\Big\}.

Suppose that for each
1\leqslant i\leqslant\ell
there exists
x_{i}\in\{0,1\}
,

1\leqslant a_{i},b_{i}\leqslant N
such that
(x_{i},a_{i})\in A_{i}
,
(x_{i},b_{i})\in B_{i}
and

\displaystyle a\coloneqq a_{1}

\displaystyle\geqslant a_{2}\geqslant\ldots\geqslant a_{\ell},

\displaystyle b\coloneqq b_{1}

\displaystyle\geqslant b_{2}\geqslant\ldots\geqslant b_{\ell}.

Then,
a
is bitwise complement of
b
.

Proof.

For each
1\leqslant i\leqslant\ell
,
(x_{i},a_{i})\in A_{i}
implies that
x_{i}=a_{i}[i]
.
Similarly,
(x_{i},b_{i})\in B_{i}
implies that
x_{i}=\overline{b_{i}[i]}
.
Therefore, the
i
’th bits of
a_{i}
and
b_{i}
are complements of each other.

In the following, we will prove by reverse induction that for each
1\leqslant i\leqslant\ell
,
the first
\ell-i+1
most significant bits of
a_{i}
and
b_{i}
are complements of each other.
For
i=\ell
, this holds by the argument above. Therefore, let
i\leqslant\ell-1

and suppose that the claim holds for
i+1
. We can write the
binary representation of
a_{i+1}
and
b_{i+1}
as

\displaystyle\mathrm{bin}\left(a_{i+1}\right)

\displaystyle=\mathbf{s}\circ\alpha

\displaystyle\mathrm{bin}\left(b_{i+1}\right)

\displaystyle=\overline{\mathbf{s}}\circ\beta

where
\mathbf{s}
is a binary string of length
\ell-i
and
\alpha,\beta
are
binary strings of length
i
.

Similarly, we can write

\displaystyle\mathrm{bin}\left(a_{i}\right)

\displaystyle=\mathbf{m}_{1}\cdot t\cdot\alpha^{\prime}

\displaystyle\mathrm{bin}\left(b_{i}\right)

\displaystyle=\mathbf{m}_{2}\cdot\overline{t}\cdot\beta^{\prime}

where
\mathbf{m}_{1},\mathbf{m}_{2}
are bitstrings of length
\ell-i
,
t\in\{0,1\}
and

\alpha^{\prime},\beta^{\prime}
are bitstrings of length
i-1
.
Observe that the
i
’th bit of
a_{i}
and
b_{i}
, i.e.
t
and
\overline{t}
,
are complements as discussed above.

Since
a_{i}\geqslant a_{i+1}
and
b_{i}\geqslant b_{i+1}
, we have

\mathbf{m}_{1}\geqslant\mathbf{s},\quad\mathbf{m}_{2}\geqslant\overline{\mathbf{s}}.

Since
\mathbf{s}
is a bitstring of length

, we also have

\mathbf{m}_{1}+\mathbf{m}_{2}\geqslant\mathbf{s}+\overline{\mathbf{s}}=2^{i}-1.

(9)

Note that (

) holds only if

and

are bitwise complements
as both of them are bitstrings of length

Finally, by setting

Theorem 5.4.

For every

i\in[x]
, by definition it holds that

S^{\prime}_{q(i),z(j)}=S_{i,j}.

Therefore,
s^{\prime}_{i,j}\in S^{\prime}_{q(i),z(j)}=S_{i,j}
.

Let us now show that

is consistent with
I
.
Let
i\in[x]
and
j_{1},j_{2}\in[y]
. The second coordinates of
s_{i,j_{1}}
and
s_{i,j_{2}}
are
a_{q(i),z(j_{1})}
and
a_{q(i),z(j_{2})}
respectively, which are equal by (

) since
l(i)\leqslant z(j_{1}),z(j_{2})\leqslant r(i)
.

Similarly, for
j\in[y]
and
i_{1},i_{2}\in[x]
, the first coordinates of
s_{i_{1},j}
and
s_{i_{2},j}
are equal to
c_{q(i_{1}),z(j)}
and
c_{q(i_{2}),z(j)}
respectively.
By (
11
), it holds that
c_{q(i_{1}),z(j)}
and
c_{q(i_{2}),z(j)}

are also equal to each other since

.
Hence
Z
is consistent with
\mathcal{I}
and therefore
\mathcal{I}
is a yes instance.

Running Time.

The construction of the instance
\mathcal{I}^{\prime}
takes
time

\displaystyle C\cdot x^{\prime}\cdot y^{\prime}\cdot N

\displaystyle=C\cdot 2\cdot x\cdot(y+2\cdot x\cdot\log(N))\cdot N

\displaystyle\leqslant C\cdot 2^{\frac{\varepsilon}{2}\cdot(x\cdot y+x^{2}\cdot\log(N))}\cdot N^{b}

(18)

for large enough
x,y
and
N
. Running the hypothetical algorithm takes time

\displaystyle C\cdot 2^{\varepsilon^{\prime}\cdot x^{\prime}\cdot y^{\prime}}\cdot N^{b}

\displaystyle=C\cdot 2^{\varepsilon^{\prime}\cdot 2\cdot x\cdot(y+2\cdot x\cdot\log(N))}\cdot N^{b}

\displaystyle\leqslant C\cdot 2^{\frac{\varepsilon}{2}\cdot\left(x\cdot y+x^{2}\cdot\log(N)\right)}\cdot N^{b}

(19)

Finally, by (
18
) and (
19
), the whole algorithm runs in time

\displaystyle C\cdot 2^{\frac{\varepsilon}{2}\cdot(x\cdot y+x^{2}\cdot\log(N))}\cdot N^{b}+C\cdot 2^{\frac{\varepsilon}{2}\cdot(x\cdot y+x^{2}\cdot\log(N))}\cdot N^{b}

\displaystyle=C\cdot 2\cdot 2^{\frac{\varepsilon}{2}\cdot(x\cdot y+x^{2}\cdot\log(N))}\cdot N^{b}

\displaystyle=C\cdot 2^{1+\frac{\varepsilon}{2}\cdot(x\cdot y+x^{2}\cdot\log(N))}\cdot N^{b}

\displaystyle=C\cdot 2^{\varepsilon\cdot(x\cdot y+x^{2}\cdot\log(N))}\cdot N^{b}

for large enough
x,y
and
N
, which contradicts ETH by
Theorem

5.1
.
∎

6.1

A unit square

Before we present the reduction, we introduce several gadgets.
A gadget is a pair

1.

A set of squares

\mathcal{D}

separates
\mathcal{Z}\setminus\mathcal{G}
from
\mathcal{G}\setminus\mathcal{D}

in the touching graph. Our construction assembles several gadgets to produce
an
Steiner Tree of Unit Squares
instance

which is

connects all terminals
of
\mathcal{Z}
, then
A\cap\mathcal{G}
must connect each
terminal inside
\mathcal{G}
to an interface square in
\mathcal{D}
.

Lemma 6.4 (Wire Gadget).

Let
