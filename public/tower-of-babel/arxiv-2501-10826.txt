2.
Angular Momenta

2.1.
Phase variations and Angular Momentum of the
\xi
function

Derivative of the phase of
\xi(s)
for constant
\epsilon
with respect to
t
:

(2.1)

\displaystyle\frac{\partial}{\partial t}\arctan\left(\frac{\Im\xi(s)}{\Re\xi(s)}\right)

\displaystyle=

\displaystyle\frac{1}{1+\left(\frac{\Im\xi(s)}{\Re[\xi(s)]}\right)^{2}}\frac{\frac{\partial\Im\xi(s)}{\partial t}\Re\xi(s)-\frac{\partial\Re\xi(s)}{\partial t}\Im\xi(s)}{\left(\Re\xi(s)\right)^{2}}

\displaystyle=

\displaystyle\frac{\frac{\partial\Im\xi(s)}{\partial t}\Re\xi(s)-\frac{\partial\Re\xi(s)}{\partial t}\Im\xi(s)}{\left(\Re\xi(s)\right)^{2}+\left(\Im\xi(s)\right)^{2}}=\frac{\partial\angle[\xi(s)]}{\partial t}

Where
\angle[\psi]
means phase of
\psi
. The numerator, that determines the sign of (
2.1
), can be seen as the angular momentum with respect to the origin of an unitary mass positioned in
(\Re\xi(s),\Im\xi(s))
at time
t
for constant
\epsilon
. We will name it
\mathcal{L}[\xi(s)]
, so that:

(2.2)

\mathcal{L}[\xi(s)]=\det\left(\begin{matrix}\Re\xi(s)&\Im\xi(s)\\
\frac{\partial}{\partial t}\Re\xi(s)&\frac{\partial}{\partial t}\Im\xi(s)\end{matrix}\right)

Since
\Im\xi=0
for
\epsilon=0
, we have
\mathcal{L}[\xi(s)]=0
on the critical line.

If

(2.3)

\mathcal{L}[FA(s)]=|F|^{2}\mathcal{L}[A(s)]

PROOF:
\angle[F\ A]=\angle[F]+\angle[A]
so
\frac{\partial\angle[F\ A]}{\partial t}=\frac{\partial\angle[A]}{\partial t}

2.1

3.1.
Third lemma on angular momentum

If all the zeros of the
\xi
function are on the critical line then the sign of the angular momentum equals the sign of
\epsilon
.
That is:

(3.1)

\forall t:\text{sign}(\mathcal{L}[\xi(t,\epsilon)])=\text{sign}(\epsilon)\quad and\ \forall t:\text{sign}(\mathcal{L}[\xi(t,\epsilon,\chi_{primitive)}])=\text{sign}(\epsilon)

PROOF: to compute (
2.4
) we can write :

(3.2)

\frac{\partial\xi(s)}{\partial t}=E^{T}(s)\frac{\partial Z^{T}(s)}{\partial t}=\xi(s)\sum_{\rho}\frac{-i}{\rho-\frac{1}{2}-\epsilon-it}=\xi(s)\sum_{\rho}\frac{(t-\Im[\rho)]+i(\frac{1}{2}+\epsilon-\Re[\rho])}{|\rho-s|^{2}}

For
\xi(s)
because
E^{T}(s)
is constant, but, only in order to compute (
2.4
), also for
\xi(s,\chi)
, even if
E^{T}(s,\chi)
is not constant (Lemma 2).
Taking now the real and imaginary parts to compute the angular momentum:

(3.3)

\mathcal{L}[\xi(s)]=\det\left(\begin{matrix}\Re[\xi]&\Im[\xi]\\
\sum_{\rho}\frac{\Re[\xi](t-\Im\rho)-\Im[\xi](\frac{1}{2}+\epsilon-\Re\rho)}{|\rho-s|^{2}}&\sum_{\rho}\frac{\Re[\xi](\frac{1}{2}+\epsilon-\Re\rho)+\Im[\xi](t-\Im\rho)}{|\rho-s|^{2}}\end{matrix}\right)

so that, after cancellations:

(3.4)

\mathcal{L}[\xi(s)]=|\xi(s)|^{2}\sum_{\rho}\frac{\frac{1}{2}+\epsilon-\Re[\rho]}{|\rho-s|^{2}}

Notice that the multiplication by
|\xi(s)|^{2}
avoids divergence on each zero.
From eq. (
3.4
) we see that, if
\Re\rho=\frac{1}{2}
for each zero, then the sign of the angular momentum
\mathcal{L}[\xi(s)]
equals the sign of
\epsilon
everywhere.
For Lemma 2 the same applies to
\xi(s,\chi_{primitive})
.

3.2.
Fourth lemma on angular momentum

If the angular momentum of the
\xi
function has always the same sign as
\epsilon
, then all the zeros of
\xi(s)
are on the critical line.

PROOF:
suppose that there is a zero
\rho^{*}
with
\Re\rho^{*}=\frac{1}{2}+\epsilon^{*}
with
\epsilon^{*}>0
(by symmetry it is enough to consider this case). Eq. (
3.4
) becomes:

(3.5)

\mathcal{L}[\xi(s)]=|\xi(s)|^{2}\left(\frac{\epsilon-\epsilon^{*}}{|\rho^{*}-s|^{2}}+\sum_{\rho\neq\rho^{*}}\frac{\frac{1}{2}+\epsilon-\Re[\rho]}{|\rho-s|^{2}}\right)

Since the first term in parenthesis is the only divergent one for
s\rightarrow\rho^{*}
, it dominates over the rest of the sum in a neighborhood of
\rho^{*}
. It is then possible to choose a
\epsilon
value such that
0<\epsilon<\epsilon^{*}
where
\mathcal{L}[\xi]<0
, against the hypothesis.
It follows that if
\text{sign}(\mathcal{L}[\xi(s)])=\text{sign}(\epsilon)
then all the zeros must be on the critical line.
For (
2.1
) the phase variation is :

(3.6)

\frac{\partial\angle[\xi(t,\epsilon)]}{\partial t}=\frac{\mathcal{L}[\xi(s)]}{|\xi(s)|^{2}}=\left(\frac{\epsilon-\epsilon^{*}}{|\rho^{*}-s|^{2}}+\sum_{\rho\neq\rho^{*}}\frac{\frac{1}{2}+\epsilon-\Re[\rho]}{|\rho-s|^{2}}\right)

For Lemma 2 the same applies to
\xi(s,\chi_{primitive})
.By Lemma 3+4, statement (
