Dominating Set Knapsack: Profit Optimization on Dominating Sets
Sipra Singh

Abstract
In a large-scale network, we want to choose some influential nodes to make a profit by paying some cost within a limited budget so that we do not have to spend more budget on some nodes adjacent to the chosen nodes; our problem is the graph-theoretic representation of it. We define our problem Dominating Set Knapsack by attaching Knapsack Problem with Dominating Set on graphs. Each vertex is associated with a cost factor and a profit amount. We aim to choose some vertices within a fixed budget that gives maximum profit so that we do not need to choose their 1-hop neighbors. We show that the Dominating Set Knapsack problem is strongly 𝖭𝖯 \mathsf{NP} -complete even when restricted to Bipartite graphs but weakly 𝖭𝖯 \mathsf{NP} -complete complete for Star graphs. We present a pseudo-polynomial time algorithm for Trees in time 𝒪 ⁡ ( n ⋅ m ​ i ​ n ​ { s 2 , ( α ⁡ ( 𝒱 ) ) 2 } ) \mathcal{O}(n\cdot min\{s^{2},(\alpha(\mathcal{V}))^{2}\}) . We show that Dominating Set Knapsack is very unlikely to be fixed parameter tractable by proving that it is in W ⁡ [ 2 ] W[2] -hard parameterized by the solution size. We developed FPT algorithms with running time 𝒪 ⁡ ( 4 t ​ w ⋅ n 𝒪 ⁡ ( 1 ) ​ min ⁡ { s 2 , α ​ ( 𝒱 ) 2 } ) \mathcal{O}(4^{tw}\cdot n^{\mathcal{O}(1)}\min\{s^{2},{\alpha(\mathcal{V})}^{2}\}) and 𝒪 ⁡ ( 2 v ​ c ​ k − 1 ⋅ n 𝒪 ⁡ ( 1 ) ​ min ⁡ { s 2 , α ​ ( 𝒱 ) 2 } ) \mathcal{O}(2^{vck-1}\cdot n^{\mathcal{O}(1)}\min\{s^{2},{\alpha(\mathcal{V})}^{2}\}) , where t ​ w tw represents the Treewidth of the given graph, v ​ c ​ k vck is the solution size of the Vertex Cover Knapsack , s s is the size of the knapsack and α ⁡ ( 𝒱 ) = ∑ v ∈ 𝒱 α ⁡ ( v ) \alpha(\mathcal{V})=\sum_{v\in\mathcal{V}}\alpha(v) .

Introduction

The
Knapsack Problem
is a fundamental problem widely studied in Computer Science. In this problem, there are
n
items and a knapsack with fixed capacity. Each of these items has a weight and a profit value. The goal of this problem is to put some items in the knapsack that give maximum profit so that the total weight of the items do not exceed the knapsack capacity. This problem was first introduced by R Bellman in 1954
[
4
]
. The problem was
\mathsf{NP}
-complete
proved by R.M.Karp in 1972
[
25
]
. Later on, much more work has been done on the generalization version of this problem.
[
31
,
26
,
6
,
7
]
.

In our problem, we include a graph constraint on
Knapsack Problem
, where we represent each item as the vertex of a graph, and each vertex has weight and profit values. Based on a graph constraint, we choose some vertices that give the maximum profit within the fixed capacity of the knapsack. There are some existing variants of the
Knapsack Problem
with graph constraints. Pferschy and Schauer showed
\mathsf{NP}
-hardness and approximation results for some special graph classes for the
Knapsack Problem
with the independent set as graph property
[
35
]
. Dey et al. studied
Knapsack Problem
with graph connectivity, path, shortest path
[
14
]
, and
Vertex Cover

[
13
]
.

In this paper, we consider another graph property as a constraint, the
Dominating Set

[
21
]
, with the
Knapsack Problem
. A
Dominating Set
of an undirected graph is a set of vertices such that all other vertices are adjacent to at least one element of that set. We use the name
Dominating Set Knapsack
for our problem, which is formally defined in Section
5
. As a brief introduction, suppose
\mathcal{G}(\mathcal{V},\mathcal{E})
is a graph with each vertex
v\in\mathcal{V}
having weight
w(v)
and profit
\alpha(v)
. The positive integers
s,d
are knapsack capacity and target profit, respectively. We want to find
\mathcal{W}\subseteq\mathcal{V}
such that (I)
\mathcal{W}
is a
Dominating Set
(II)
\sum_{v\in\mathcal{W}}w(v)\leqslant s
and (III)
\sum_{v\in\mathcal{W}}\alpha(v)\geqslant d
.

Towards the motivation: One can argue on the natural question that if, for a graph instance, both
Dominating Set
and
Knapsack Problem
are
yes
instances, then obviously
Dominating Set Knapsack
is
yes
instance. But, it is not true, in general. Consider the following instances of graph classes in Figure
1
and Figure
2
:

Figure 1
:
The instance of a star graph
\mathcal{G}(\mathcal{V},\mathcal{E})
with
\mathcal{V}=\{v_{0},\ldots,v_{5}\}
.
w(v_{i})=\alpha(v_{i})=1~\forall i=1,\ldots 5
and
w(v_{0})=\alpha(v_{0})=5
and
s=d=4
.

Figure 2
:
The instance of a split graph
\mathcal{G}^{\prime}(\mathcal{V}^{\prime},\mathcal{E}^{\prime})
with
\mathcal{V}^{\prime}=\{u_{i}:1\leqslant i\leqslant 4\}\cup\{v_{j}:1\leqslant j\leqslant 3\}
.
w(u_{i})=4,\alpha(u_{i})=0~\forall i=1,\ldots 4
and
w(v_{j})=\alpha(v_{j})=1~\forall j=1,\ldots 3
and
s=d=3
.

For both of these graph instances,
Dominating Set
as well as
Knapsack Problem
are
yes
instances, but
Dominating Set Knapsack
is not.

Now, consider a real-world scenario as a representation of our problem. Suppose the government wants to optimally build power stations in different localities of a city so that each consumer of every locality can get electric supply. Here, we consider each locality as the vertex. The power station of each locality has a finite range within which it can distribute electricity. If two such regions overlap, we draw an edge between those localities. Building a power station with different capacities, availability of places in a locality, etc., are the cost factors for this problem. The revenue generated by the total unit of power distributed to a locality to provide electricity in different houses and factories is the profit of this problem. Our problem
Dominating Set Knapsack
represents such a real-world example in the graph theoretic approach. Here, we want to find a subset of vertices to distribute power supply to the entire city and make optimal profit. Our problem can widely be applicable in different network problems like wireless ad-hoc networks
[
30
]
, railway transportation networks
[
39
]
, where stations are represented as the vertices, the connection between two stations through the railway tracks is denoted as edges, and we want to find a subset of stations to pass express trains, etc.

In Section
2
, we summarize our main contributions. We discussed the literature related to our works in Section
3
. Some preliminary definitions that are used in other sections are given in Section
4
. Our problem statement is defined in Section
5
. The results we proved on
\mathsf{NP}
-hardness are discussed in Section
6
. In Section
7
, we show the parameterized complexity results for our problem
Dominating Set Knapsack
. Finally we conclude in Section
8
.

2
Our Contributions

The main contributions of this paper are on Classical
\mathsf{NP}
-Hardness and Parameterized Complexity.

◗

Classical
\mathsf{NP}
-Hardness.

We proved
Dominating Set Knapsack
is strongly
\mathsf{NP}
-complete
for general graph (Theorem
14
), even for general bipartite graph (Theorem
15
). We showed that though the star graph is a special case of a bipartite graph,
Dominating Set Knapsack
is weakly
\mathsf{NP}
-complete
for the star graph (Theorem
16
). We provided a dynamic programming-based algorithm that solves
Dominating Set Knapsack
for Trees in Pseudo-polynomial time (Theorem
17
). The running time of this algorithm is
\mathcal{O}(n\cdot min\{s^{2},(\alpha(V))^{2}\})
, where
s
is the size of the knapsack and
\alpha(V)=\sum_{v\in\mathcal{V}}\alpha(v)
.

◗

Parameterized Complexity.

\bullet

Solution size:

Dominating Set Knapsack

W[2]
-hard (Theorem
21
). The reduction is made from the parameterized version of
Dominating Set
in Theorem
20
. By reducing
Dominating Set Knapsack
to
Weighted Circuit Satisfiability
(WCS), we proved that
Dominating Set Knapsack
belongs to
W[2]
(Theorem
22
). Thus, it is
W[2]
-complete (Theorem
23
). We showed that unless
Exponential Time Hypothesis
(ETH) fails, there is a no
f(k)n^{o(k)}
-time algorithm parameterized by the solution size
k
(Theorem
26
).

\bullet

Solution size of
Vertex Cover Knapsack
:

Dominating Set Knapsack
is Fixed-Parameter Tractable (FPT) parameterized by the size of
Vertex Cover Knapsack
solution (Theorem
29
). We proved this theorem by using the dynamic programming algorithm described in Theorem
17
. The running time of the algorithm is
\mathcal{O}(2^{vck-1}\cdot n^{\mathcal{O}(1)}\min\{s^{2},{\alpha(\mathcal{V})}^{2}\})
, where
vck
is the solution size of the
Vertex Cover Knapsack
,
s
is the size of the knapsack and
\alpha(\mathcal{V})=\sum_{v\in\mathcal{V}}\alpha(v)
.

\bullet

Treewidth:
By considering
Treewidth
as the parameter, we proved
Dominating Set Knapsack
is FPT (Theorem
32
). We developed an algorithm that is a modified version of the approach discussed in
[
1
]
. The running time of the algorithm is
\mathcal{O}(4^{tw}\cdot n^{\mathcal{O}(1)}\min\{s^{2},{\alpha(\mathcal{V})}^{2}\})
, where
tw
represents the
Treewidth
of the given graph.

Preliminaries

This section is the recap of some definitions and few notations that we used throughout in this paper. We define
\mathcal{G}(\mathcal{V},\mathcal{E})
as the graph with the set of vertices
\mathcal{V}
and the set of edges
\mathcal{E}
, where
|\mathcal{V}|=n
and
|\mathcal{E}|=m
. The size of the knapsack and the target value are represented as
s
and
d
respectively. The weight and profit of a vertex
u\in\mathcal{V}
are denoted as
w(u)
and
\alpha(u)
respectively. We denote the closed interval
[1,n]=\{x\in\mathbb{Z}:1\leqslant x\leqslant n\}
.

Definition 1

(
Dominating Set
)
.

Given a graph
\mathcal{G}=(\mathcal{V},\mathcal{E})
and a positive integer
k
, compute if there exists a subset
\mathcal{V}^{\prime}\subseteq\mathcal{V}
such that every vertex of
\mathcal{V}^{\prime}
is adjacent with all the vertices of
\mathcal{V}
and
|\mathcal{V}^{\prime}|\leqslant k
. We denote an arbitrary instance of
Dominating Set
by
(\mathcal{G},k)
.

Definition 2

(
Vertex Cover
)
.

Given a graph
\mathcal{G}=(\mathcal{V},\mathcal{E})
and a positive integer
k
, compute if there exists a subset
\mathcal{V}^{\prime}\subseteq\mathcal{V}
such that at least one end point of every edge belongs to
\mathcal{V}^{\prime}
and
|\mathcal{V}^{\prime}|\leqslant k
. We denote an arbitrary instance of
Vertex Cover
by
(\mathcal{G},k)
.

Definition 3

(
Knapsack Problem
)
.

Given a set
\mathcal{X}=[1,n]
of
n
items with sizes
\theta_{1},\ldots,\theta_{n},
values
p_{1},\ldots,p_{n}
, capacity
b
and target value
q
, compute if there exists a subset
\mathcal{I}\subseteq\mathcal{X}
such that
\sum_{i\in\mathcal{I}}\theta_{i}\leqslant b
and
\sum_{i\in\mathcal{I}}p_{i}\geqslant q
. We denote an arbitrary instance of
Knapsack Problem
by
(\mathcal{X},(\theta_{i})_{i\in\mathcal{X}},(p_{i})_{i\in\mathcal{X}},b,q)
.

Definition 4

(
Vertex Cover Knapsack
)
.

Given an undirected graph
\mathcal{G}=(\mathcal{V},\mathcal{E})
, weight and profit of vertices are defined as the functions
w:\mathcal{V}\rightarrow\mathbb{Z}_{\geqslant 0}
and
\alpha:\mathcal{V}\rightarrow\mathbb{R}_{\geqslant 0}
respectively, size
s(\in\mathbb{Z^{+}})
of the knapsack and target value
d(\in\mathbb{R^{+}})
, compute if there exists a subset
\mathcal{U}\subseteq\mathcal{V}
of vertices such that (I)
\mathcal{U}
is a
Vertex Cover
, (II)
\sum_{u\in\mathcal{U}}w(u)\leqslant s
, (III)
\sum_{u\in\mathcal{U}}\alpha(u)\geqslant d
.
We denote an arbitrary instance of
Dominating Set Knapsack
by
(\mathcal{G},(w(u))_{u\in\mathcal{V}},(\alpha(u))_{u\in\mathcal{V}},s,d)
.

Definition 5

(
Upper Dominating Set
)
.

Given a graph
\mathcal{G}=(\mathcal{V},\mathcal{E})
and a positive integer
k
, compute if there exists a subset
\mathcal{V}^{\prime}\subseteq\mathcal{V}
such that
\mathcal{V}^{\prime}
is a
Dominating Set
of size at least
k
i.e.,
|\mathcal{V}^{\prime}|\geqslant k
. We denote an arbitrary instance of
Upper Dominating Set
by
(\mathcal{G},k)
.

Maximum cardinality among all Minimal
Dominating Set
problem or Upper Domination (UD) (denoted as
\Gamma(\mathcal{G})
) problem is
\mathsf{NP}
-complete
(Th 4.4)
[
9
]
. UD is polynomial time solvable for Bipartite graphs (Th 5)
[
10
]
,(Th 7)
[
24
]
and Chordal graphs (Th 9)
[
24
]
. Thus it indicates that some times finding max-min problem is more ’easy’ than the finding of minimization problem.

Definition 6

(
Tree decomposition
)
.

Given a graph
\mathcal{G}=(\mathcal{V},\mathcal{E})
. The set of vertices
\chi=\{X_{i}\}_{i\in V}
, where each
X_{i}\subseteq\mathcal{V}
is called a bag such that
T=(V,E)
is a tree structure for the graph
\mathcal{G}
with
i
as the nodes of
~T
. We define a
Tree decomposition

T^{\chi}
of
~\mathcal{G}
having the following properties:

\bullet

\bigcup\limits_{i\in V}X_{i}=\mathcal{V}
.

\bullet

For each edge
e=\{v_{1},v_{2}\}\in\mathcal{E}
there must be a bag
X_{k}
such that
\{v_{1},v_{2}\}\subseteq X_{k}
, where
k=|V|
.

\bullet

If a node
j
lies on the path between the nodes
i
and
k
, then
X_{i}\cap X_{k}\subseteq X_{j}
, which means that the set
\{i,j,k\}
induces a connected subtree of
~T
,
\forall~i,j,k\in V
.

We denote an arbitrary instance of
Tree decomposition

T^{\chi}
of
~\mathcal{G}
by the pair
\langle\chi,T\rangle
. The
width
of
T^{\chi}
is equal to
\max_{i\in V}|X_{i}|-1
and the
treewidth
(tw)
holds the minimum width value among all
T^{\chi}
of
\mathcal{G}
.

From later on, we use the term ’vertices’ for the vertices of the graph
\mathcal{G}
and ’nodes’ for the vertices of
~T
.

Definition 7

(
Nice tree decomposition
)
.

A
Tree decomposition

T^{\chi}_{r}
rooted at a node
r
is called a

if the following properties holds:

\bullet

Every node of
~T
has at most two children.

\bullet

A node with no children is called

.

\bullet

A node

j
is either called

(i)

if
X_{i}=X_{j}\setminus\{v\}
and
|X_{i}|=|X_{j}|+1
or

(ii)

X_{j}=X_{i}\setminus\{v\}
and
|X_{j}|=|X_{i}|+1
, where
v\in\mathcal{V}
.

\bullet

A node
i

j
and
k

if
X_{i}=X_{j}=X_{k}
.

Definition 8

(
Exponential Time Hypothesis
)
.

\mathcal{O}^{*}(2^{cn})
, where
\delta_{3}(>0)

Definition 9

(
Weighted Circuit Satisfiability
)
.

Given a circuit
\mathcal{C}
and a positive integer
k
, compute if there exists a satisfying assignment with weight exactly
k
. We denote an arbitrary instance of

.

Definition 10

(

)
.

A parameterized problem

if there is a parameterized reduction form

6
Results on Classical NP-hardness

This section shows the classical NP-hardness results for our problem for some graph classes.
Dominating Set
problem (see, definition
1
) is strongly
\mathsf{NP}
-complete
as the reduction is done from
Vertex Cover

[
21
]
. For proving
\mathsf{NP}
-completeness of
Dominating Set Knapsack
, we reduce
Dominating Set
to
Dominating Set Knapsack
. The theorem for strong
\mathsf{NP}
-completeness of
Dominating Set Knapsack
is shown below.

Theorem 14
.

Dominating Set Knapsack
is strongly
\mathsf{NP}
-complete
.

Proof.

Clearly,
Dominating Set Knapsack

\in

\mathsf{NP}
. Let us construct the following instance
(\mathcal{G}^{\prime}(\mathcal{V}^{\prime}=\{u_{i}:i\in[1,n]\},\mathcal{E}^{\prime}),(w(u))_{u\in\mathcal{V}^{\prime}},(\alpha(u))_{u\in\mathcal{V}^{\prime}},s,d)
of
Dominating Set Knapsack
from a given arbitrary instance
(\mathcal{G}(\mathcal{V}=\{v_{i}:i\in[1,n]\},\mathcal{E}),k)
of
Dominating Set
of size
k
.

\displaystyle\qquad\qquad\qquad\qquad\qquad\mathcal{V}^{\prime}=\{u_{i}:v_{i}\in\mathcal{V},\forall i\in[1,n]\}

\displaystyle\qquad\qquad\qquad\qquad\qquad\mathcal{E}^{\prime}=\{\{u_{i},u_{j}\}:\{v_{i},v_{j}\}\in\mathcal{E},i\neq j,\forall i,j\in[1,n]\}

This theorem is essential to prove the following theorem, where we show that

Theorem 15
.

Dominating Set Knapsack
is strongly
\mathsf{NP}
-complete
even when the instances are restricted to a bipartite graph.

Proof.

We already proved that
Dominating Set Knapsack
is
\mathsf{NP}
-complete
for general graph. Now we reduce an arbitrary instance of general graph
(\mathcal{G}(\mathcal{V},\mathcal{E}),(w(u))_{u\in\mathcal{V}},(\alpha(u))_{u\in\mathcal{V}},s,d)
for

to the instance of a bipartite graph
(\mathcal{B}(\hat{\mathcal{V}},\hat{\mathcal{E}}),(w(v))_{v\in\hat{\mathcal{V}}},(\alpha(v))_{v\in\hat{\mathcal{V}}},\hat{s},\hat{d})
for
Dominating Set Knapsack
. The reduction is as follows:

\displaystyle\hat{\mathcal{V}}=X\cup Y\cup\{z\}

\displaystyle X=\{v_{i}:u_{i}\in\mathcal{V},\forall i\in[1,n]\}

\displaystyle Y=\{v_{i}^{\prime}:u_{i}\in\mathcal{V},\forall i\in[1,n]\}

\displaystyle\hat{\mathcal{E}}=\{\{v_{i},v_{i}^{\prime}\}\cup\{\{v_{i},v_{j}^{\prime}\}\cup\{v_{i}^{\prime},v_{j}\}:\{u_{i},u_{j}\}\in\mathcal{E}\}\cup\{z,v_{i}^{\prime}\}:i\neq j,\forall i,j\in[1,n]\}

\displaystyle w(v_{i})=0,\alpha(v_{i})=0\quad\forall i\in[1,n]

\displaystyle w(v_{i}^{\prime})=w(u_{i}),\alpha(v_{i}^{\prime})=\alpha(u_{i})\quad\forall i\in[1,n]

\displaystyle w(z)=0,\alpha(z)=0

\displaystyle\hat{s}=s,\hat{d}=d

Now, we can proof that the arbitrary graph
\mathcal{G}
has a solution for

iff the corresponding bipartite graph

has a solution for
Dominating Set Knapsack

Suppose,

is

\mathcal{G}
. That means

has a

\sum_{v\in\hat{\mathcal{W}}}\alpha(v)=\alpha(z)+\sum_{u\in\mathcal{W}}\alpha(u)\geqslant d=\hat{d},\quad\text{since}\quad\alpha(z)=0

Dominating Set Knapsack
is
yes
instance for bipartite graph
B
.

Conversely, let
Dominating Set Knapsack
has
yes
instance for the bipartite graph

and
\hat{\mathcal{W}}

Case 1
: Let

.

Without loss of generality, let

and/or

from
\mathcal{V}
of

\displaystyle\sum_{u_{i}\in\mathcal{W}}w(u_{i})

\displaystyle=\sum_{v_{i}\in(X\cap\hat{\mathcal{W}})}w(v_{i})+\sum_{v_{i}^{\prime}\in(Y\cap\hat{\mathcal{W}})}w(v_{i}^{\prime}),\qquad\text{since}~w(v_{i})=0,w(v_{i}^{\prime})=w(u_{i})

\displaystyle=\sum_{v_{i}\in(X\cap\hat{\mathcal{W}})}w(v_{i})+\sum_{v_{i}^{\prime}\in(Y\cap\hat{\mathcal{W}})}w(v_{i}^{\prime})+w(z),\qquad\text{as}~w(z)=0

The following theorem is for the Star graph, a special case of the Bipartite graph. Though the Star graph is a Bipartite graph, the following theorem proves that our problem is weakly
\mathsf{NP}
-complete
for it.

Theorem 16
.

Dominating Set Knapsack
is
\mathsf{NP}
-complete

Proof.

Dominating Set Knapsack
clearly belongs to
\mathsf{NP}
. We reduce
Knapsack Problem
to

. Let

\displaystyle\qquad\qquad\qquad\qquad\qquad\mathcal{E}=\{\{v_{0},v_{i}\}:1\leqslant i\leqslant n\}

8
Conclusion

In this paper, we proposed the problem
Dominating Set Knapsack
, which is a variation of the
Knapsack Problem
problem with the association of
Dominating Set
. We proved that
Dominating Set Knapsack
is strongly
\mathsf{NP}
-complete
for the general graph and even for the special graph class Bipartite graph, which is very popular for its simple structure and properties. We showed that
Dominating Set Knapsack
is weakly
\mathsf{NP}
-complete
for the star graph and provided a Pseudo-polynomial time algorithm for Trees. Also, we proved some parameterized results on
Dominating Set Knapsack
that it is
W[2]
-complete parameterized by the solution size, and it is very unlikely that
Dominating Set
has a sub-exponential time algorithm that has running time
f(k)n^{o(k)}
parameterized by the solution size
k
. For two parameters
Treewidth
and
Vertex Cover Knapsack
, we showed that
Dominating Set Knapsack
is Fixed Parameter Tractable. We end here with the statement that, though in general this problem is intractable, it has enormous practical importance.
