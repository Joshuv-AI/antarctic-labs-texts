On exponential stability of linear and nonlinear delay differential equations: a review and new results
Leonid Berezansky, Elena Braverman, Alexander Domoshnitsky

Abstract
An extensive overview of existing criteria, as well as some new uniform exponential stability tests are included for a scalar delay equation x ˙ ​ ( t ) + ∑ j = 1 n a j ​ ( t ) ​ x ​ ( h j ​ ( t ) ) = 0 . \dot{x}(t)+\sum_{j=1}^{n}a_{j}(t)x(h_{j}(t))=0. Both cases of continuous and measurable parameters h j h_{j} , a j a_{j} are explored. We apply the global linearisation approach and employ linear results to explore global exponential stability for nonlinear models of the form x ˙ ​ ( t ) + ∑ j = 1 n f j ​ ( t , x ⁡ ( h j ​ ( t ) ) ) = 0 . \dot{x}(t)+\sum_{j=1}^{n}f_{j}\left(t,x(h_{j}(t))\right)=0. The proofs are based on solution estimations. Further, the Bohl-Perron theorem on exponential dichotomy is instrumental for establishing global exponential stability for nonlinear models. Conclusions are illustrated with numerical examples.



1
Introduction

The dynamics of applied models in physics, engineering, and population dynamics can frequently be defined by the behaviour of solutions to a scalar differential equation

\dot{x}(t)+\sum_{j=1}^{n}f_{j}\left(t,x(h_{j}(t))\right)=0,\quad t\geq t_{0}

(1.1)

with multiple delays (here we assume
h_{j}(t)\leq t
for any
j
).

If
f_{j}(t,0)\equiv 0
, while the limits
\displaystyle a_{j}(t)=\lim_{x\to 0}\frac{f_{j}(t,x)}{x}
exist and are finite,
the linearised equation about the zero equilibrium for (
1.1
) has the form

\dot{x}(t)+\sum_{j=1}^{n}a_{j}(t)x(h_{j}(t))=0,\quad t\geq t_{0}.

(1.2)

Equations (
1.1
) and (
1.2
) are usually considered with a prescribed initial function

x(t)=\psi(t)\mbox{~~ for ~~}t\leq t_{0}.

(1.3)

Linearised equations for known mathematical models have different forms: equations with one, two or several delays,
equations in which all the terms are delayed and those containing a non-delay term, dominating or not, equations with only nonnegative coefficients or equations
with oscillatory coefficients, equations with coefficients of prescribed signs, not all of them positive, and equations with bounded, as well as with
with unbounded delays, inherited from their nonlinear counterparts.

To obtain efficient local stability conditions for a specific form of nonlinear equation (
1.1
), a set of explicit, convenient to use
stability tests is required for all the types of linear models listed above.

The first part of the present paper outlines a review of several known asymptotic and exponential stability tests
for (
1.2
) and its special cases.
We start with a better investigated case of continuous parameters in Section
2
.
However, in many cases it is still unknown whether the results for the continuous case can be extended to measurable
parameters without changing critical constants.
Then, in Section
3
we present tests for measurable parameters.
We also consider two important classes of equations: with two delays and when there is a term without delay.

The second part, in particular, Section
4
, presents new stability conditions for (
1.2
)
in a form quite convenient in applications.
In Section
5
, we formulate and apply global linearised stability theorem
to analyze stability properties of nonlinear models in the form of (
1.1
).
In Section
6
, we discuss the reviewed and new results.
We also contemplate on unsolved problems and discuss relevant further research.

We review here equations with one delay term (
m=1
) only with connection to stability tests for equations with several delays.
Such partial cases as autonomous equations with constant coefficients and constant delays,
equations with periodic parameters, and some other classes of scalar functional differential equations are not considered.
Also, in the present paper, we don’t deal with equations of higher order, vector equations and systems of linear equations.

Before we start with the review, let us present basic definitions. Relevant notations are introduced later, in Section
3
.

Definition 1
.

We will say that (
1.2
) is

1.

asymptotically stable (AS) if, in addition to its (local) stability, any solution
x(t)
satisfies
\lim\limits_{t\rightarrow\infty}x(t)=0
;

2.

uniformly exponentially stable (UES) if there are constants
{\mathcal{M}}>0
and
\nu>0
such that any solution
of problem (
1.2
), (
1.3
) has the estimate

|x(t)|\leq{\mathcal{M}}e^{-\nu(t-t_{0})}\sup_{t\leq t_{0}}|\psi(t)|\mbox{ ~ for ~~}t\geq t_{0},

while the numbers
{\mathcal{M}}
and
\nu
are independent of both the initial point
t_{0}
and the initial function
\psi(t)
.

Definition 2
.

The equilibrium of equation (
1.1
) (assumed to be zero) is

1.

locally asymptotically stable (LAS) if for every
\varepsilon>0
there is a constant
\delta>0
for which
|\psi(t)|\leq\delta
implies
|x(t)|<\varepsilon
,
t\geq t_{0}
and
\lim\limits_{t\rightarrow\infty}x(t)=0

for a solution
x
to (
1.1
), (
1.3
);

2.

locally exponentially stable (LES) if there are
\delta>0
,
{\mathcal{M}}>0
and
\nu>0
such that the estimate

|x(t)|\leq{\mathcal{M}}e^{-\nu(t-t_{0})}\sup_{t\leq t_{0}}|\psi(t)|

(1.4)

holds for all solutions
x
to (
1.1
), (
1.3
) such that
|\psi(t)|\leq\delta
;

3.

globally asymptotically stable (GAS) if, in addition to (local) stability, all solution to (
1.1
), (
1.3
) tend to the equilibrium
\lim\limits_{t\rightarrow\infty}x(t)=0
;

4.

globally exponentially stable (GES) if (
1.4
) is satisfied for any solution to (
1.1
), (
1.3
).

Recall that the fundamental function
X(t,s)
of equation (
1.2
)
solves equation (
1.2
) with the variable initial point
t_{0}=s
, the zero
initial function
x(t)=0
,
t<s
, and the initial value equal to one:
x(s)=1
.
All the stability definitions for linear equations can be formulated in an equivalent form, using the fundamental function.
For some equations, such form is more convenient.

Definition 3
.

Linear equation (
1.2
) is called

1.

uniformly stable if the exists
{\mathcal{M}}>0
which is an upper bound for
X(t,s)
:
|X(t,s)|\leq M
;

2.

uniformly asymptotically stable, once the limit
\lim\limits_{t\rightarrow\infty}X(t,s)=0
is uniform in
s
on
[t_{0},\infty)
;

3.

uniformly exponentially stable if some positive constants
{\mathcal{M}}>0
and
\nu>0
define a uniform exponential estimate

|X(t,s)|\leq{\mathcal{M}}e^{-\nu(t-s)}
.

2
Equations with continuous parameters

In this section, we assume that all the functions
a_{j}(t)
,
h_{j}(t),k=1,\dots,m
are continuous on
[t_{0},\infty)
,

\lim\limits_{t\rightarrow\infty}h_{j}(t)=\infty
,
and the initial function
\psi(t)
is continuous on
(-\infty,t_{0}]
.

Equation (
1.2
) with one delay

\dot{x}(t)+a(t)x(h(t))=0

(2.1)

is very well studied, see
[
74
]
for a review of stability results for (
2.1
). In particular, the
following famous stability test
[
85
]
holds for equation (
2.1
), see also
[
86
]
for unbounded delays.

Theorem 2.1
.

[
85
]

Assume that the coefficient
a(t)
is nonnegative,

0<\liminf_{t\rightarrow\infty}\int_{h(t)}^{t}a(s)ds\leq\limsup_{t\rightarrow\infty}\int_{h(t)}^{t}a(s)ds<\frac{3}{2}.

Then equation (
2.1
) is AS. The constant
\frac{3}{2}
is sharp.

A fundamental result for equations with continuous parameters and several delays was obtained by Krisztin
[
52
]
.

Theorem 2.2
.

[
52
]

1) Let
0\leq a_{j}(t)\leq a_{j}
,
0\leq t-h_{j}(t)\leq\tau_{j}
,
j=1,\dots,n
, the integral of the sum of the coefficients diverge

\displaystyle\int_{\cdot}^{\infty}\sum_{j=1}^{n}a_{j}(s)ds=+\infty
, and

\sum_{j=1}^{n}a_{j}\tau_{j}<1.

(2.2)

Then, (
1.2
) is AS, and one in the right-hand side of (
2.2
)
is a sharp constant which cannot be replaced with any
c>1
.

2) If
a_{j}(t)\equiv\alpha_{j}
are positive constants then one in (
2.2
) is no longer optimal, a larger constant
\frac{3}{2}
in the right-hand side is the best possible
for the case.

Theorem
2.2
gives explicit stability conditions for equation (
1.2
).
However, the important message of this theorem is that, when moving from one to several delay terms, the constant
\frac{3}{2}
is not preserved and
should be replaced by a smaller best possible constant of
1
.
Note that for constant coefficients and one term, the best constant is
\pi/2
exceeding
\frac{3}{2}
.

The statement in
[
74
, Corollary 2.4]
adds the following stability test to Theorem
2.2
.

Theorem 2.3
.

[
74
]

Let
a_{j}(t)\geq 0
,
h_{n}(t)\geq\cdots\geq h_{1}(t)
. If

\limsup_{t\rightarrow\infty}\int_{h_{1}(t)}^{t}\sum_{j=1}^{n}a_{j}(s)ds<\frac{3}{2}\,,

for each solution to (
1.2
) there is a constant
c
such that
\displaystyle\lim_{t\to\infty}x(t)=c
.
An additional conditions of divergence

\displaystyle\int_{t_{0}}^{\infty}\sum_{j=1}^{n}a_{j}(s)ds=\infty
implies that (
1.2
) is AS.

Faria in the paper
[
35
]
investigated a very general linear equation with a non-delay term
which includes equations (
1.2
) with a non-delay term and several delay terms, and equations with a non-delay term and distributed delays.

Equations (
1.2
) with two terms (
m=2
) often appear as linearised equations of population dynamics.
Therefore, such equations require a more detailed study.

Consider an equation with a non-delay term

\dot{x}(t)=-a(t)x(t)+b(t)x(h(t))

(2.3)

with
a(t)>0
.

The following stability result was obtained in
[
47
]
and also follows from
[
35
, Corollary 3.2]
.

Theorem 2.4
.

[
35
,
47
]

Assume that there are a constant
T\geq 0
and a function
e(t)\geq 0
which is locally integrable, but

\int_{T}^{\infty}e(t)dt=\infty
. If either

(i)
\displaystyle a(t)-|b(t)|\sup_{t\geq T}\int_{h(t)}^{t}e(u)du\geq e(t)

or

(ii)
\displaystyle a(t)\geq\alpha|b(t)|
for some
\alpha>1

or

(iii)

\displaystyle e(t)\leq a(t)-|b(t)|,~\sup_{t\geq T}\int_{h(t)}^{t}e(u)du<\infty

then (
2.3
) is AS.

Condition (ii) implies AS in the case of measurable parameters,
which is a scalar case of the result, obtained in
[
25
]
.
Note also that the coefficients in equation (
2.3
) are not assumed to be bounded for
t\geq T
.

Consider a scalar differential equation including a term with a constant positive coefficient without delay

\dot{x}(t)+\alpha x(t)+\beta(t)x(h(t))=0.

(2.4)

The following result is a corollary of a global asymptotic stability test obtained in
[
34
]
for a nonlinear equation.

Theorem 2.5
.

[
34
]

Assume that
\alpha>0
, the delay and the variable coefficients are bounded
0\leq\beta(t)\leq b
,
0\leq t-h(t)\leq h
, where
b>0
,
h\geq 0
, and

\frac{\alpha}{b}e^{-\alpha h}>\ln\frac{b^{2}+\alpha b}{b^{2}+\alpha^{2}}\,.

Then equation (
2.4
) is AS.

In
[
34
]
and several other papers by Ivanov, Liz, Trofimchuk, Theorem
2.5
was applied to obtain new asymptotic properties for many mathematical models of population dynamics.
In
[
18
]
, Theorem
2.5
was generalized to an equation with several delay terms and measurable parameters.
This result will be formulated in the next section.

Next, proceed to the study of a model containing a non-delay term and one delay term

\dot{x}(t)+\alpha(t)x(t)+\beta(t)x(h(t))=0

(2.5)

with
\beta(t)\geq 0
.

The test of
[
88
, Theorem 2.1]
gives sharp AS conditions.

Theorem 2.6
.

[
88
]

Let

\liminf_{t\rightarrow\infty}\int_{0}^{t}a(s)ds>-\infty,~\int_{0}^{\infty}e^{-\int_{s}^{t}a(u)du}b(s)ds\leq\alpha<1.

Then the condition
\displaystyle\lim_{t\rightarrow\infty}\int_{0}^{t}a(s)ds=\infty
is necessary and sufficient for (
2.5
) to be AS.

Sometimes, linearised equations for mathematical models have three terms, for example,
there is a production term, a mortality term, and a harvesting term, where all three can be delayed. The following result
is designed for this kind of linear equations.

Consider an equation with three bounded delays

\dot{x}(t)+a(t)x(h_{1}(t))-b(t)x(h_{2}(t))-c(t)x(h_{3}(t))=0,

(2.6)

in particular,
0\leq t-h_{j}(t)\leq\tau
,
\displaystyle\int_{0}^{\infty}a(s)ds=\infty
, the first term
has a positive coefficient
a(t)>0
and in some sense dominates over the other two.

Theorem 2.7
.

[
78
, Theorem 7]

Let
for some
\theta\in(0,1)
,

|b(t)|+|c(t)|<\theta a(t),~\limsup_{t\rightarrow\infty}\int_{h_{1}(t)}^{t}(a(s)+|b(s)|+|c(s)|)ds<1-\theta.

Then equation (
2.6
) is AS.

In
[
46
]
, the authors considered equation (
1.2
)
with constant coefficients
a_{j}(t)\equiv a_{i}
and piecewise continuous delays
h_{j}(t)
.
Denote

a=\sum_{j=1}^{n}a_{j},~\Phi(\tau)=\int_{0}^{\infty}X(t,\tau)dt,

where

is the fundamental function of the
equation
\dot{x}(t)+x(t-\tau)=0,~0<\tau<\frac{\pi}{2}
. If
\tau\leq\frac{1}{e}
then
\Phi(\tau)=1
.
For
\tau\in(\frac{1}{e},\frac{\pi}{2})
, numerical estimations for
\Phi(\tau)
are presented
in
[
46
, Table 1]
.

Theorem 2.8
.

[
46
, Theorem 3.2]

Suppose
a_{i}>0
are constants, and there exists a number
\tau\in[0,\frac{\pi}{2a}]
such that

\tau a-\frac{1}{\Phi(\tau a)}<\sum_{j=1}^{n}a_{j}\liminf_{s\rightarrow\infty}(s-h_{j}(s))\leq\sum_{j=1}^{n}a_{j}\limsup_{s\rightarrow\infty}(s-h_{j}(s))<\tau a+\frac{1}{\Phi(\tau a)}\,.

Then equation (
1.2
) with constant coefficients is AS.

In
[
79
]
, the equation with a non-delay term

\dot{x}(t)=-ax(t)+b(t)x(t-\tau)

(2.7)

(together with more general nonlinear equations) was considered.
As a corollary of
[
79
, Theorem 2.5]
, we outline a test for (
2.7
).

Theorem 2.9
.

[
79
]

Let
a>0
,
0\leq b(t)\leq\beta
and for some
D>0

\int_{t-\tau}^{t}e^{-a(t-s)}b(s)ds\leq D<1+\frac{1}{2}\left(1+\frac{a^{2}}{\beta^{2}}\right)e^{-a\tau}.

Then equation (
2.7

3
Stability tests for equations with measurable parameters

Next, we consider more general models, where both coefficients and delays are not necessarily continuous.

Up to the end of the paper, we assume that all the parameters of equation (
1.2
) (the coefficients and the delays
t-h_{j}(t)\geq 0
) are Lebesgue measurable
and essentially bounded on
[t_{0},\infty)
, apart from the initial function
\psi(t)
which is Borel measurable and bounded.
The same hypotheses are implied on all the special forms of (
1.2
).

We consider measurable functions (coefficients, delayed arguments, solution derivatives) in the space
{\mathbf{L}}_{\infty}[t_{0},\infty)
of Lebesgue measurable functions
y:[t_{0},\infty)\to{\mathbb{R}}
with the essential supremum norm
\|y\|={\rm ess}\sup_{s\geq t_{0}}|y(s)|
. We will also consider the space
{\mathbf{L}}_{\infty}[a,b]
of
y:[a,b]\to{\mathbb{R}}
with
\|y\|_{[a,b]}={\rm ess}\sup_{s\in[a,b]}|x(s)|
.

Note that initial value problem (
1.2
), (
1.3
) has a unique solution,
see
[
3
,
8
,
39
,
49
]
.

Together with homogeneous equation (
1.2
), we consider its non-homogeneous counterpart with the zero initial function

\dot{x}(t)+\sum_{j=1}^{n}a_{j}(t)x(h_{j}(t))=f(t),\quad t\geq t_{0},\quad x(t)=0,\quad t\leq t_{0},

(3.1)

where
\|f\|<\infty
, and the norm is defined above.

For the proofs of all the theorems in this section, the Bohl-Perron result (Lemma
3.1
) is the main tool.

Lemma 3.1
.

[
3
,
39
]

If for any bounded
f
, a solution to (
3.1
) is also a bounded function on
[t_{0},\infty)
.
then (
1.2
) is UES.

There is a close connection between the nonoscillatory behaviour and UES for functional differential equations.
For equation (
1.2
) with nonnegative coefficients, nonoscillation which is interpreted as existence of an eventually positive solution,
is equivalent to positivity of the fundamental function to (
1.2
).
Denote the sum of the coefficients as

A(t)=\sum_{j=1}^{n}a_{j}(t).

(3.2)

Lemma 3.2
.

[
4
, P. 52]

If
a_{j}(t)\geq 0
and the sum of the coefficients defined in (
3.2
) is separated from zero
A(t)\geq a_{0}>0
then positivity of the fundamental function to
(
1.2
) implies that equation (
1.2
) is UES.

Condition
A(t)\geq a_{0}>0
can be replaced by a more general condition:

there is
{\mathcal{R}}>0
such that
\displaystyle\liminf\limits_{t\rightarrow\infty}\int_{t}^{t+{\mathcal{R}}}A(\zeta)d\zeta>0
,

which is equivalent to UES of the
ordinary differential equation

\dot{x}(t)+A(t)x(t)=0.

Let us outline some explicit conditions under which the fundamental function of (
1.2
) is positive.
Many other results can be found in the monograph
[
4
]
.

Lemma 3.3
.

[
9
,
10
]

Suppose
0\leq a_{j}(t)\leq\alpha_{j}
,
t-h_{j}(t)\leq\tau_{j}
,
A
is defined in (
3.2
), and either

1)
\displaystyle\int_{\min_{j}\{h_{j}(t)\}}^{t}A(s)ds\leq\frac{1}{e}

or

2) there exists
\lambda>0
for which the inequality
\displaystyle\lambda\geq\sum_{j=1}^{n}\alpha_{j}e^{\lambda\tau_{j}}
holds.

Then, (
1.2
) possesses a positive solution; moreover, it has a positive fundamental function.

All the stability tests in this section are divided into three groups:

1.

equations like (
1.2
) where the number of delays is not prescribed,

2.

models with two terms, both delayed,

3.

equations with at least two terms, where one of the terms is not delayed.

3.1
Equations with multiple delays

We start with several explicit sufficient conditions when (
1.2
) is AS or UES.

Theorem 3.1
.

[
13
, Theorem 3.1]

Let
a_{j}(t)\geq 0
and

\displaystyle\limsup_{s\rightarrow\infty}\sum_{j=1}^{n}\frac{a_{j}(s)}{A(s)}\int_{h_{j}(s)}^{s}A(\zeta)d\zeta<1+\frac{1}{e}\,
.

If
\displaystyle\int_{t_{0}}^{\infty}A(\zeta)d\zeta=\infty
then equation (
1.2
) is AS.

If there is
{\mathcal{R}}>0
for which
\displaystyle\liminf_{t\rightarrow\infty}\int_{t}^{t+{\mathcal{R}}}A(\zeta)d\zeta>0
then (
1.2
) is UES.

Corollary 1
.

Assume that
a_{j}(t)\geq 0
,
A(t)\equiv\alpha>0
and

\limsup_{t\rightarrow\infty}\sum_{j=1}^{n}a_{j}(t)(t-h_{j}(t))<1+\frac{1}{e}\,.

(3.3)

Then equation (
1.2
) is UES.

Corollary 2
.

Assume that
a_{j}(t)\geq 0
, while
\displaystyle 0<a_{0}\leq A(t)\leq A
and
either

\limsup_{s\rightarrow\infty}\int_{\min_{j}\{h_{j}(s)\}}^{s}A(\zeta)d\zeta<1+\frac{1}{e}

(3.4)

or

\limsup_{s\rightarrow\infty}\sum_{j=1}^{n}a_{j}(s)(s-h_{j}(s))<\frac{a_{0}}{A}\left(1+\frac{1}{e}\right).

(3.5)

Then equation (
1.2
) is UES.

Let us compare Corollaries
1
and
2
with Theorem
2.2
. For constant coefficients in the statement of
Theorem
2.2
, the constant
\frac{3}{2}
is better than
1+\frac{1}{e}\approx 1.368<1.5
in (
3.3
), but the condition
\displaystyle\sum_{j=1}^{n}a_{j}(t)\equiv\alpha>0
is more general than the assumption that each
coefficient is constant.

Consider the general case of the coefficients in equation (
1.2
).
If
\frac{a_{0}}{A}\left(1+\frac{1}{e}\right)>1
for the case of variable delays then inequality (
3.5
) in Corollary
2
is
better than the corresponding inequality in Theorem
2.2
with the constant 1.
Otherwise, Theorem
2.2
is sharper.

In the following theorem
[

, Theorem 6]
and some other stability tests,
we do not assume that

.

[

Let

.

Let

\limsup_{s\rightarrow\infty}\sum_{j=1}^{n}\frac{|a_{j}(s)|}{A(s)}\left|\int_{h_{j}(s)}^{s}\sum_{j=1}^{n}|a_{j}(\zeta)|d\zeta\right|<1.

Next, proceed to the autonomous case

\dot{x}(t)+\sum_{j=1}^{n}a_{j}x(t-\sigma_{j})=0,t\geq t_{0},~\sigma_{j}\geq 0.

(3.6)

Corollary 4
.

Assume that
\displaystyle\sum_{j=1}^{n}a_{j}>0

\sum_{j=1}^{n}|a_{j}|\sigma_{j}\leq\frac{\sum_{j=1}^{n}a_{j}}{\sum_{j=1}^{n}|a_{i}|}\,.

Theorem 3.3
.

[
11
]

Let
A
as in (

) be separated from zero
A(t)\geq\alpha>0
. Once there exists a positive solution to

\dot{x}(t)+\sum_{j=1}^{n}a_{j}^{+}(t)x(h_{j}(t))=0,~\mbox{ where ~~}u^{+}=\max\{u,0\},

(equivalently, its fundamental function is positive),

For the next two theorems, in (
1.2
) the sum of the coefficients
is not necessarily positive: the inequality

can be violated. It means that the sum of the coefficients may be oscillatory.

Theorem 3.4
.

[
20
]

Denote by

the sum of the norms
A_{0}=\sum_{j=1}^{n}\|a_{j}\|
.
Let

\dot{x}(t)+A(t)x(t)=0

(3.7)

be UES, we recall that the delays are bounded
0\leq t-h_{j}(t)\leq\tau_{j}
. If

A_{0}\int_{t_{0}}^{t}e^{-\int_{s}^{t}A(\xi)d\xi}\sum_{j=1}^{n}\tau_{j}|a_{j}(s)|ds\leq\beta<1,\quad t\geq t_{0}

) is UES.

Let us note that equation (
3.7

{\mathcal{R}}>0
we have

In this section, we obtain UES tests by the use of a priori estimation for solutions to linear equation (
1.2
) and their
derivatives.

We assume, as previously, measurability and boundedness of the coefficients and the delays and also that
t-h_{j}(t)\leq\tau_{j}
,
j=1,\dots,n
.

Denote

A(t)=\sum_{j=1}^{n}a_{j}(t),\quad J=[t_{0},t_{1}],\quad\Omega\subset N_{n}=\{1,\dots,n\},\quad A_{\Omega}(t)=\sum_{j\in\Omega}a_{j}(t),

and the norms
\|f\|
,
\|f\|_{J}
on the halfline and a segment are defined as above; as usual,
by

we denote an identity matrix.

We recall
[
24
]
that a matrix
B=(b_{ij})_{i,j=1}^{m}
is an
M
-matrix (here we reduce consideration to non-singular matrices) if its off-diagonal entries are non-positive, and either
B
is invertible with
B^{-1}\geq 0
(meaning that all the entries of
B^{-1}
are nonnegative)
or (which is equivalent) its leading principal minors are positive.
In particular,
2\times 2
matrix
B
is an
M
-matrix and is not singular if
b_{12}\leq 0
,
b_{21}\leq 0
,
b_{11}>0
,
b_{22}>0
and in addition,
\det B>0
.

Theorem 4.1
.

Let there be a non-empty set
\Omega\subset N_{n}
and a constant
\alpha>0
such that
A_{\Omega}(t)\geq\alpha>0

and either

\sum_{j=1}^{n}\tau_{j}\|a_{j}\|<1,~\sum_{j=1}^{n}\|a_{j}\|\sum_{j\in\Omega}\tau_{j}\left\|\frac{a_{j}}{A_{\Omega}}\right\|+\sum_{j\in N_{n}/\Omega}\left\|\frac{a_{j}}{A_{\Omega}}\right\|<1

(4.1)

or

\|A\|\sum_{j\in\Omega}\tau_{j}\left\|\frac{a_{j}}{A_{\Omega}}\right\|<\left(1-\sum_{j=1}^{n}\tau_{j}\|a_{j}\|\right)\left(1-\sum_{j\in N_{n}/\Omega}\left\|\frac{a_{j}}{A_{\Omega}}\right\|\right).

(4.2)

Then equation (
1.2
) is UES.

Proof.

1) Assume that
x(t)
is a solution of (
3.1
) and obtain two estimates for its derivative
\dot{x}(t)
.
From equation (
3.1
) we have

\|\dot{x}\|_{J}\leq\sum_{j=1}^{n}\|a_{j}\|\|x\|_{J}+\|f\|.

(4.3)

By the addition and subtraction of the term
A(t)x(t)
, (
3.1
) can be presented as

\dot{x}(t)+A(t)x(t)=\sum_{j=1}^{n}a_{j}(t)\int_{h_{j}(t)}^{t}\dot{x}(\xi)d\xi+f(t).

(4.4)

Equality (
4.4
) implies

\|\dot{x}\|_{J}\leq\|A\|\|x\|_{J}+\sum_{j=1}^{n}\tau_{j}\|a_{j}\|\|\dot{x}\|_{J}+\|f\|.

(4.5)

2) Next, let us estimate
x(t)
, first on
J
, then on the halfline.
To this end, rewrite (
3.1
) as

\dot{x}(t)+A_{\Omega}(t)x(t)=\sum_{j\in\Omega}a_{j}(t)\int_{h_{j}(t)}^{t}\dot{x}(\xi)d\xi+\sum_{j\in N_{n}/\Omega}a_{j}(t)x(h_{j}(t))+f(t).

(4.6)

From (
4.6
) and the assumption
x(t_{0})=0
, we obtain

x(t)=\int_{t_{0}}^{t}e^{-\int_{\zeta}^{t}A_{\Omega}(s)ds}A_{\Omega}(\zeta)\left(\sum_{j\in\Omega}\frac{a_{j}(\zeta)}{A_{\Omega}(\zeta)}\int_{h_{j}(\zeta)}^{\zeta}\dot{x}(\xi)d\xi+\sum_{j\in N_{n}/\Omega}\frac{a_{j}(\zeta)}{A_{\Omega}(\zeta)}x(h_{j}(\zeta))\right)d\zeta+\tilde{f}(t),

where
\tilde{f}(t)=\int_{t_{0}}^{t}e^{-\int_{s}^{t}A_{\Omega}(\zeta)d\zeta}f(s)ds
.

If
A_{\Omega}(t)\geq 0
, then
\left|\int_{t_{0}}^{t}e^{-\int_{s}^{t}A_{\Omega}(\tau)d\tau}A_{\Omega}(s)u(s)~ds\right|\leq\|u\|
.
Hence
\|\tilde{f}\|<\infty
and

\|x\|_{J}\leq\sum_{j\in\Omega}\tau_{j}\left\|\frac{a_{j}}{A_{\Omega}}\right\|\|\dot{x}\|_{J}+\sum_{j\in N_{n}/\Omega}\left\|\frac{a_{j}}{A_{\Omega}}\right\|\|x\|_{J}+\|\tilde{f}\|.

(4.7)

3) Let us introduce the notation

X=\{\|x\|_{J},\|\dot{x}\|_{J}\}^{T},~F=\{\|f\|,\|\tilde{f}\|\}^{T},~A_{1}=\left(\begin{array}[]{cc}\sum_{j\in N_{n}/\Omega}\left\|\frac{a_{j}}{A_{\Omega}}\right\|&\sum_{j\in\Omega}\tau_{j}\left\|\frac{a_{j}}{A_{\Omega}}\right\|\\
\sum_{j=1}^{n}\|a_{j}\|&0\end{array}\right),

B_{1}=I-A_{1}=\left(\begin{array}[]{cc}1-\sum_{j\in N_{n}/\Omega}\left\|\frac{a_{j}}{A_{\Omega}}\right\|&-\sum_{j\in\Omega}\tau_{j}\left\|\frac{a_{j}}{A_{\Omega}}\right\|\\

Inequalities (

) and (
4.3

.

f_{1}(t,u)=\alpha(t)u\left(1+\frac{1}{1+u^{2}}\right),\quad f_{2}(t,u)=\beta(t)\frac{u}{1+u^{2}}

and

a(t)=\lim_{u\rightarrow 0}\frac{f_{1}(t,u)}{u}=\alpha(t),\quad b(t)=\lim_{u\rightarrow 0}\frac{f_{2}(t,u)}{u}=\beta(t).

Then the linearised equation to (
5.1
) is

\dot{y}(t)+\alpha(t)y(h_{1}(t))+\beta(t)y(h_{2}(t))=0.

(5.2)

From Corollaries
1
and
2
, respectively, the following results are obtained.

Statement 1
.

Let the sum of the coefficients
\alpha(t)+\beta(t)\equiv a_{0}>0
be constant, while

\displaystyle\tau_{1}\|\alpha\|+\tau_{2}\|\beta\|<1+\frac{1}{e}\,.

Then, equation (
5.1
) is LAS.

Statement 2
.

Let
0<a_{0}\leq\alpha(t)+\beta(t)\leq A_{0}
and
either

a)
\displaystyle\tau_{1}\|\alpha\|+\tau_{2}\|\beta\|<\frac{a_{0}}{A_{0}}\left(1+\frac{1}{e}\right)

or

b)
\displaystyle\limsup_{s\rightarrow\infty}\left(\int_{h_{1}(s)}^{s}\left[\alpha(\zeta)+\beta(\zeta)\right]\,d\zeta+\int_{h_{2}(s)}^{s}\left[\alpha(\zeta)+\beta(\zeta)\right]\,d\zeta\right)<1+\frac{1}{e}\,.

Then, equation (
5.1
) is LAS.

Next, we will apply Corollary
8
.

Statement 3
.

Assume that anyone of the four hypotheses is valid:

a)
\displaystyle\alpha(t)\geq\alpha_{0}>0,~\tau_{1}(\|\alpha\|+\|\beta\|)+\left\|\frac{\beta}{\alpha}\right\|<1
;

b)
\displaystyle\beta(t)\geq\beta_{0}>0,~\tau_{2}(\|\alpha\|+\|\beta\|)+\left\|\frac{\alpha}{\beta}\right\|<1;

c)
\displaystyle\alpha(t)+\beta(t)\geq a_{0}>0,(\|\alpha\|+\|\beta\|)\left(\tau_{1}\left\|\frac{\alpha}{\alpha+\beta}\right\|+\tau_{2}\left\|\frac{\beta}{\alpha+\beta}\right\|\right)<1
;

d)
\displaystyle\alpha(t)+\beta(t)\geq a_{0}>0,\|\alpha+\beta\|\left(\tau_{1}\left\|\frac{\alpha}{\alpha+\beta}\right\|+\tau_{2}\left\|\frac{\beta}{\alpha+\beta}\right\|\right)<1-\tau_{1}\|\alpha\|-\tau_{2}\|\beta\|
.

Then equation (
5.1
) is LES.

Sometimes for equation (
1.1
), we are interested only in solutions in a certain interval
A\leq x(t)\leq B
. In this
case, for GES we will consider only such solutions. This in particular is true for population dynamics equations, where only positive solutions are biologically senseful,
and there is also a some natural upper bound.

If linearised equation (
1.2
) is UES, we can conclude that the zero equilibrium (or any other constant equilibrium, we can make a shift to zero) of equation (
1.1
) is LES.
The situation with global exponential stability (GES) is more complicated.
One of the methods named global linearised stability
[
12
]
, can be applied by construction another linear equation,
associated with nonlinear equation (
1.1
).
Let
x(t)
be an arbitrary fixed solution of equation (
1.1
).
Denote

c_{j}(t)=\left\{\begin{array}[]{cc}\frac{f_{j}(t,x(h_{j}(t)))}{x(h_{j}(t))},&x(h_{j}(t))\neq 0,\\
0,&x(h_{j}(t))=0,\end{array}\right.

and consider the associated linear equation

\dot{y}(t)+\sum_{j=1}^{n}c_{j}(t)y(h_{j}(t))=0.

(5.3)

If equation (
5.3
) is UES, then
x(t)
has an exponential estimate, as it solves (
5.3
). Hence every solution
of (
1.1
) has an exponential estimate. It means that equation (
1.1
) is GES.

More precisely, the global linearised stability method
[
12
]
is formulated below.

Theorem 5.1
.

[
12
]

Assume that there exist numbers

-\infty\leq A\leq B\leq+\infty,~-\infty\leq d_{j}\leq D_{j}\leq+\infty,~j=1,\dots,n,

such that any solution
x(t)
of equation (
1.1
) has a priori estimates

A\leq\liminf_{s\rightarrow\infty}x(s)\leq\limsup_{s\rightarrow\infty}x(s)\leq B

and

d_{j}\leq\frac{f_{j}(t,u)}{u}\leq D_{j},~u\in[A,B],\quad j=1,\dots,n.

(5.4)

If equation (
5.3
) is UES for any
c_{j}(t)
satisfying the inequalities

d_{j}\leq c_{j}(t)\leq D_{j},

then (
1.1
) is GES.

Example 4
.

Let us return to model (
5.1
).
To obtain global stability result for (
5.1
), we will apply Theorem
5.1
.
Take
x(t)
which solves (
5.1

denote

c(t):=\frac{f_{1}(t,x(h_{1}(t)))}{x(h_{1}(t))}=\alpha(t)\left(1+\frac{1}{1+x^{2}(h_{1}(t))}\right),~~d(t):=\frac{f_{2}(t,x(h_{2}(t)))}{x(h_{2}(t))}=\frac{\beta(t)}{1+x^{2}(h_{2}(t))}.

(5.5)

Next, consider a linear counterpart of (
5.1
)

\dot{z}(t)+c(t)z(h_{1}(t))+d(t)z(h_{2}(t))=0

(5.6)

with the above notation.

Since the inequality
d(t)\geq d_{0}>0
fails, both Corollary
1
and Part b) of Corollary
8

fail for equation (

(Parts 3 and 4 can be considered in a similar way) and also Corollary

Statement 4
.

Assume that there exists a positive lower bound
\alpha_{0}>0
such that either

a)
\displaystyle\alpha(t)\geq\alpha_{0},\quad\tau_{1}(2\|\alpha\|+\|\beta\|)+\left\|\frac{\beta}{\alpha}\right\|<1

or

b)
\displaystyle\alpha(t)+\beta(t)\geq a_{0},\quad(\tau_{1}+\tau_{2})(2\|\alpha\|+\|\beta\|)<1+\frac{1}{e}

Then, (
5.1
) is GES.

Proof.

a)
We have for (
5.6
), taking into account (
5.5
),

c(t)\geq\alpha(t)\geq\alpha_{0}>0,~~\|c\|=2\|\alpha\|,\|d\|=\|\beta\|,~~\left\|\frac{d}{c}\right\|=\left\|\frac{\beta}{\alpha}\right\|.

Part 1) of Corollary
8
implies that equation (

) is UES. By Theorem
4.1
,
equation (
5.1

b) We have

0<\alpha_{0}\leq\alpha(t)\leq c(t)+d(t)\leq 2\|\alpha\|+\|\beta\|.

Hence

\limsup_{t\rightarrow\infty}\left(\int_{h_{1}(t)}^{t}(c(s)+d(s))ds+\int_{h_{2}(t)}^{t}(c(s)+d(s))ds\right)\leq(2\|\alpha\|+\|\beta\|)(\tau_{1}+\tau_{2})<1+\frac{1}{e}\,.

Inequality (

Hence equation (

∎

In this paper we partially fill the gap for scalar differential equations with several delays.
Together with a review, we also obtain several new exponential stability conditions.
These new UES tests are quite simple and convenient in applications.

To apply global linearised stability method for a given nonlinear differential equation,
we have to estimate coefficients of a corresponding linear delay differential equation dependent, generally,
on an unknown solution of the given nonlinear equation. In Section

the coefficients of (

However, for many known mathematical models, in order
to estimate the coefficients of linear equation, we need first to construct a priori estimates for solutions
of a given nonlinear equation:

A\leq\liminf_{t\rightarrow\infty}x(t)\leq\limsup_{t\rightarrow\infty}x(t)\leq B.

In this paper we separate stability tests for equations with measurable and continuous parameters.
Actually, any stability test for equations with measurable parameters is also valid,
once we reduce ourselves to continuous delays and coefficients, but the converse, generally, is not true.
We investigate here equations, where both coefficients and delays are bounded, which is appropriate to study GES and LES, but is not the general case.
New results on stability for equations with unbounded coefficients and/or delays with
a review on known results can be found in the recent paper
[

In line with the review, we list some open problems arising from it.

1.

3.

All the applications of global linearised stability method so far have been obtained for scalar equations.
How can this method be extended to vector equations and systems of scalar equations, as well as
