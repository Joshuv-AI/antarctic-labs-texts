ArcMark : Multi-bit LLM Watermark via Optimal Transport
Atefeh Gilani 1 Carol Xuan Long 2 Sajani Vithana 2 Oliver Kosut 1† Lalitha Sankar 1† Flavio P. Calmon 2† 1 Arizona State University 2 Harvard University † Equal senior author contribution

Abstract
Watermarking is an important tool for promoting the responsible use of language models (LMs). Existing watermarks insert a signal into generated tokens that either flags LM-generated text (zero-bit watermarking) or encodes more complex messages (multi-bit watermarking). Though a number of recent multi-bit watermarks insert several bits into text without perturbing average next-token predictions, they largely extend design principles from the zero-bit setting, such as encoding a single bit per token. Notably, the information-theoretic capacity of multi-bit watermarking – the maximum number of bits per token that can be inserted and detected without changing average next-token predictions – has remained unknown. We address this gap by deriving the first capacity characterization of multi-bit watermarks. Our results inform the design of ArcMark : a new watermark construction based on coding-theoretic principles that, under certain assumptions, achieves the capacity of the multi-bit watermark channel. In practice, ArcMark outperforms competing multi-bit watermarks in terms of bit rate per token and detection accuracy. Our work demonstrates that LM watermarking is fundamentally a channel coding problem, paving the way for principled coding-theoretic approaches to watermark design.

Introduction

The process of embedding several bits of information into tokens generated by a large language model (LLM) is commonly referred to as
multi-bit watermarking
. Multi-bit watermarks can encode, for example, which model and user generated a given piece of text or code. Multi-bit watermarks can also help AI providers respond to emerging policy and regulatory efforts that call for marking their outputs as AI-generated and curbing LLM misuse
[
1
,
2
,
3
]
.

Ideally, a multi-bit watermark should maximize
rate
—the number of bits encoded per token—and minimize the
error probability
of decoding the watermarked message. Recent constructions balance these two objectives while preserving text quality by enforcing a
distortion-free
constraint: averaged over side information shared between a watermark encoder and decoder, watermarking does not change the LLM’s average next-token predictions. Side information is usually generated by hashing previously-generated tokens and shared secret keys
[
4
,
5
]
.

Multi-bit watermarking is a more complex counterpart of
zero-bit watermarking
, which aims only to decide whether a text is LLM-generated or not
[
4
,
6
,
7
,
8
,
5
]
. Despite being a fundamentally different problem (statistical detection vs. communication), existing multi-bit methods often extend design principles from the zero-bit setting. For example, constructions such as
[
9
]
and
[
10
]
encode information on a token-by-token basis, rather than treating message recovery over long sequences of tokens as a channel coding problem. Consequently, while prior works provide evidence that distortion-free multi-bit watermarking is feasible, they leave open its information-theoretic
capacity
: How many bits can we reliably embed into LLM-generated text while preserving average next-token predictions?

We present the
first information-theoretic abstraction of the multi-bit LLM watermarking problem and a formal definition of watermarking capacity
of the resulting channel. We do so by modeling multi-bit watermarking as communication over a noisy channel with side information available at both the encoder (the watermarker) and decoder. Under this model, we derive an expression for the Shannon capacity of distortion-free multi-bit watermarking as: the maximum number of watermarked bits per token that can be embedded while achieving asymptotically vanishing decoding error probability over long sequences of tokens, without changing the token distributions.

Our information-theoretic perspective directly informs the design of a new watermarking scheme called
ArcMark
.
ArcMark
employs a random linear channel code to exploit the full length of the token sequence, producing a codeword (vector of codeword symbols) for each message. This linear code is defined on the integers with modulo operations. Such coding mechanisms can be naturally mapped to points on a circle, which is the intuition behind
ArcMark
. Concretely, for each token,
ArcMark
(i) represents each message codeword symbol
C
, generated token
X
, and side information
V
as points on the unit circle, and (ii) solves an optimal transport problem that minimizes the arc length between
C+V
and
X
while assuring the correct token distribution from the LLM. This message-secret coupling alongside the LLM itself induce a noisy channel from coded symbols to observed tokens and side information.

The key strength of
ArcMark
is that its encoding mechanism ensures that each token contains some information about the message to be encoded, which is information-theoretically optimal. This is in contrast to competing mutli-bit watermark methods that encode only one message bit in each token and achieve accuracy via repetition. Moreover,
ArcMark
can achieve capacity in certain settings. We show that
ArcMark
achieves the watermarking capacity for a specific, simple class of i.i.d. token distributions. We first evaluate the general capacity expression in this setting, and then show that, with the correct parameters,
ArcMark
achieves arbitrarily small probability of error for any rate below capacity. This result highlights that
ArcMark
is designed based on information-theoretic principles.

We evaluate the accuracy of decoded multi-bit messages from
ArcMark
on multiple LLMs. We find that the message accuracy, the probability that the decoded message exactly matches the true message
i.e., all embedded bits are recovered correctly, significantly exceeds that of state-of-the-art methods across different watermark embedding lengths, generation lengths, and language models (Llama2-7B and Llama3-8B). This advantage is clearly highlighted in
Figure

1
which shows the message accuracy as a function of the number of tokens for 3-bit, 8-bit, and 16-bit messages for Llama3-8B. By design,
ArcMark
is distortion-free. We empirically validate this property by evaluating the perplexity of text generated with
ArcMark
and comparing it to unwatermarked generation.

In summary, our main contributions include:

•

We introduce an information-theoretic model for multi-bit LLM watermarking, and derive an expression for the Shannon capacity of distortion-free watermarking.

•

We introduce
ArcMark
, a new distortion-free multi-bit watermark based on random linear channel codes. Notably,
ArcMark
ensures that each token contains some information about the entire message, rather than only encoding one message bit per token.

•

We prove that, under simplifying assumptions,
ArcMark
is capacity achieving.

•

Our experiments demonstrate that
ArcMark
Pareto-dominates competing multi-bit watermarks in terms of rate (i.e., number of bits per token) and decoding error probability.

1.1
Related Work

We discuss the related works on zero-bit and multi-bit watermarks most closely related to ours.

Zero-bit Watermarks.
Zero-bit watermarking schemes aim to determine whether a given sequence of outputs was generated by a specific model. Many multi-bit watermarking methods build directly on ideas developed in the zero-bit setting, with the Red-Green watermark playing a central role. We therefore begin by reviewing several notable zero-bit watermarking approaches.

The first watermark for LLMs was proposed by
[
4
]
, commonly referred to as the Red-Green watermark. This method partitions the token vocabulary into two disjoint lists and biases generation by exponentially tilting the model’s next-token distribution toward one of the lists. In practice, the Red-Green watermark is implemented by adding a bias term to the logits of green-list tokens. Subsequent work extended this framework by introducing alternative schemes for generating the random side information used in the partitioning
[
11
]
. Since then, watermarking for LLMs has been studied extensively.
Most notably, SynthID
[
5
]
produces watermarked tokens via a strategy called tournament sampling.
This watermark has been adopted in industry and covers various modalities, including text, images, and video generation.

Information-Theoretic Analysis of Watermarking

Watermarking has a long history in information theory
[
12
,
13
,
14
]
, particularly through formulations based on the Gelfand–Pinsker (GP) channel
[
15
,
16
,
17
]
. These classical approaches typically study watermarking of sequences via joint typicality arguments and assume perfect knowledge of the underlying source distribution at the decoder. In contrast, in LLM watermarking the next-token distribution is unknown to the detector.

[
18
]
analyzes text watermarking through the lens of hypothesis testing with side information, formalizing the fundamental trade-off between detection power and distortion in generated text. Their analysis yields the Correlated Channel Watermark, which constructs an optimal coupling between the side information shared with the detector and a random partition of the LLM vocabulary.
Complementarily,
[
19
]
characterize the universal Type-II error under worst-case control of the Type-I error by jointly optimizing the watermarking scheme and detector. In this paper, we cast multi-bit LLM watermarking as a channel coding problem, and use information-theoretic insights to design optimal coding schemes. To our knowledge, this is the first formal capacity characterization for multi-bit LLM watermarking.

Distortion-free Watermarking via Optimal Transport.

[
6
]
formulates LLM watermarking as an optimal transport problem between the original next-token distribution and a watermarked distribution conditioned on random side information, a perspective that is especially effective in the low-entropy regime where next-token predictions are near-deterministic. This formulation leads to distortion-free watermarking schemes such as HeavyWater and SimplexWater. In this paper, we extend the optimal-transport construction of
[
6
]
to a circular (modulo) setting, enabling channel-coding ideas to be integrated with optimal transport. In addition, we also introduce an explicit message encoding/decoding scheme for efficient multi-bit watermarking, rather than applying
[
6
]
repeatedly for each message symbol.

Multi-bit Watermarks.
BiMark
[
9
]
builds on unbiased green–red list watermarking but strengthens the signal by applying
k
sequential, weak reweighting layers per token. Each layer uses an independent pseudorandom green/red partition and a fair coin flip to slightly bias the distribution, and the token is sampled from the final reweighted distribution. For detection, the verifier reconstructs the same
k
partitions and flips and checks how often each generated token falls on the expected “green” side; these
k
weak votes are then aggregated via majority voting to recover the embedded bit. In contrast to
ArcMark
, which decodes messages jointly from a series of tokens, BiMark performs per-token voting and aggregates these local decisions. Our joint decoding enables global, sequence-level strategies that can outperform token-by-token decoding.

Multi-bit Watermark via Position Allocation (MPAC)
[
10
]
extends red–green watermarking to embed multiple bits by assigning each generated token to a pseudorandom message position and using the corresponding bit to choose which vocabulary subset (“colorlist”) to bias during sampling. At detection, the verifier computes a histogram over the colorlist for each message position, and determines the embedded message by determining which color sequence appears the most. The primary distinction between
ArcMark
and MPAC is that MPAC is not distortion-free. In contrast,
ArcMark
supports multi-bit watermarking without compromising text quality.

Other multibit watermarks include
[
20
]
, which is based on pseudo-random segment assignment,
[
21
]
, which randomly categorizes the LLM vocabulary into different message symbols and apply red-green on top, and
[
22
]
, which uses a finetuned LLM to parapharse the input text given a user-chosen key and extract the message via a paired decoder. We benchmark our method against Bimark
[
9
]
and MPAC
[
10
]
because of comparability and code availability:
[
21
]
does not provide publicly available code, and
[
22
]
operates post hoc on generated token sequences rather than at the LLM generation level.

Notation.

Throughout, random variables are denoted by uppercase letters (e.g.,
X
and
S
), with their realizations represented by lowercase letters (e.g.,
x
and
s
), and their distributions by subscripted symbols
P
or
Q
(e.g.,
P_{X}
and
P_{S}
). For any positive integer
m
, we define
[1\!:\!m]\triangleq\{1,\ldots,m\}
. The set
\{0,1\}^{k}
denotes all binary strings of length
k
. The set of positive integers is denoted by
\mathbb{Z}^{+}
. For integers
a
and
p
,
a\bmod p
denotes the remainder of
a
upon division by
p
. We write
V\sim\text{uniform}(\mathcal{R})
to denote that
V
is uniformly distributed over
\mathcal{R}
. We use
\mathbf{1}_{A}
for the indicator function on set
A
. We use the following notation for information-theoretic quantities:
H(X)
for entropy,
H(X|Y)
for conditional entropy,
I(X;Y)
for mutual information, and
I(X;Y|Z)
for conditional mutual information.

We consider a large language model (LLM) with token vocabulary
\mathcal{X}=[1\!:\!N]
that generates text autoregressively. At time
t
, a token
X_{t}\in\mathcal{X}
is drawn according to the conditional distribution
P_{X_{t}|X_{1:t-1}}
, where
X_{1:t-1}
denotes the tokens generated at previous time instances. For notational simplicity, we write
Q_{X_{t}}=P_{X_{t}|X_{1:t-1}}\in\Delta_{\mathcal{X}}
where
\Delta_{\mathcal{X}}
denotes the probability simplex over
\mathcal{X}
.

In multi-bit watermarking for LLM-generated text, there exists two parties: a watermarker (the LLM) and a decoder. At each generation step
t
, the two parties share a common secret key
S_{t}\in\mathcal{S}
. The watermarker has access to the model’s next-token distribution
Q_{X_{t}}
, whereas the decoder observes only the generated tokens and the corresponding secret keys, i.e.,
(X_{t},S_{t})
. The watermarker embeds a
k
-bit message
M\in\mathcal{M}=\{0,1\}^{k}
into a sequence of
n
generated tokens
\{X_{t}\}_{t=1}^{n}
by sampling each
X_{t}
from a watermarked distribution
Q_{X_{t}|S_{t},M}
that depends on the message to be embedded, the shared random key, and the original LLM token distribution
Q_{X_{t}}
. The watermark embedding process must preserve the quality of the generated text. We formalize this requirement via a distortion-free constraint, requiring the marginal token distribution to remain unchanged:

\displaystyle\mathbb{E}_{S_{t}}[Q_{X_{t}|S_{t},M=m}]=Q_{X_{t}},\quad\forall m\in\mathcal{M},\ t\in[1:n]

(1)

This condition ensures that, on average over the secret key, watermarking does not alter the LLM’s output distribution.

The decoder reconstructs the message from the observed sequence via a decoding function
g:\mathcal{X}^{n}\times\mathcal{S}^{n}\mapsto\mathcal{M}
as
\hat{M}=g(X_{1:n},S_{1:n})
. We characterize the system by the following quantities: the error probability
P_{e}=\mathrm{Pr}(M\neq\hat{M})
, number of message bits
k
, and the token length
n
.

Capacity of Multi-bit Watermarking

In this section, we derive the capacity of multi-bit watermarking. In this capacity definition, we assume that the token distributions
Q_{X_{t}}
are independent and identically distributed (i.i.d.) across time, where
Q
is a random variable in the simplex
\Delta_{\mathcal{X}}
with the same distribution. We emphasize that this assumption that the token distributions are i.i.d. is necessary for the theoretical characterization of the capacity, and is not required for the performance of our practical scheme
ArcMark

n

.

The capacity
R_{\text{cap}}
of multi-bit watermarking is defined as the supremum over all achievable rates
R=\frac{k}{n}
measured in bits/token, for which reliable decoding (
P_{e}\to 0
) is possible under the distortion-free constraint.

The following theorem, proved in Appendix
A

X
denote the output of the watermarked LLM and
W
represents an encoding of the message
M
and the secret
S
. One can view this as a channel where the uncertainty is a result of the LLM’s output distribution
Q_{X_{t}}
at any time
t
. The capacity is the maximum information about
M
that can be transmitted error-free and is captured by the maximal mutual information between
W
and
X
over all choices of the distribution of
W
and a function

which determines the token based on the encoding of the message
w
and the LLM distribution
q

The watermarking capacity is given by

\displaystyle R_{\textup{cap}}=\max_{P_{W},x(w,q)}I(W;X),

\displaystyle\textup{s.t. }\Pr(X=x|Q=q)=q(x),\forall x\in\mathcal{X},\forall q\in\Delta_{\mathcal{X}}

where

is a distribution on an arbitrary alphabet

Next, we derive the capacity for a specific class of token distributions. Consider the class of distributions
\mathcal{P}_{2}(\mathcal{X})\subset\Delta_{\mathcal{X}}

can be written as,

\displaystyle q(x)

\displaystyle=\begin{cases}1/2,&x=i,j\\
0,&x\neq i,j\end{cases}

(3)

for any pair of tokens

Assuming token distributions are uniformly distributed on

\displaystyle R_{\textup{cap}}=\log N+\sum_{t=1}^{N-1}\frac{t}{\binom{N}{2}}\log\frac{t}{\binom{N}{2}}.

4
ArcMark
: Distortion-Free Multi-Bit Watermark

ArcMark
consists of three stages:

1.

Message encoding:
The message to be embedded is mapped to a length-
n
codeword, with redundancy introduced to enable reliable recovery at the detector.

2.

Message embedding:
At each time step
t
, the watermarker embeds the corresponding codeword symbol by sampling token
X_{t}
from a watermarked distribution
Q_{X_{t}|Z_{t}}
, where
Z_{t}
is derived from both the codeword symbol and the shared secret key
S_{t}
.

3.

Message decoding:
The detector observes the generated token-key sequence
\{(X_{t},S_{t})\}_{t=1}^{n}
and decodes the message
\hat{M}
.

We detail each of these stages as follows. The method is also illustrated in Fig.
2
.

Message encoding:

The watermarker maps the
k
-bit message
m\in\{0,1\}^{k}
to a length-
n
codeword
C_{m}=[C_{m}(1),\dotsc,C_{m}(n)]
using a random linear code over
\mathcal{F}=\{0,\dotsc,p-1\}
for some
p\in\mathbb{Z}^{+}
. The
t^{\text{th}}
codeword symbol
C_{m}(t)
will be embedded in the
t^{\text{th}}
generated token.

Addition in
\mathcal{F}
is defined as modular arithmetic:
a\oplus b=(a+b)\bmod p
. Then, the codeword for message
m
is

\displaystyle C_{m}=m\cdot G

(6)

where
G\in\mathcal{F}^{k\times n}
is a random generator matrix with entries
G_{i,j}
sampled uniformly from
\mathcal{F}
. The generator matrix
G

is known to both the watermarker and the detector.

The shared secret at time
t
consists of two components:
S_{t}=(V_{t},\Pi_{t})
, where
V_{t}\sim\text{uniform}(\mathcal{R})
with
\mathcal{R}=\{0,\dotsc,r-1\}
for some
r\in\mathbb{Z}^{+}
, and
\Pi_{t}
is a random permutation of token indices. We represent tokens
\mathcal{X}
, message symbols
\mathcal{F}
, and random keys
\mathcal{R}
as angles on the unit circle. Specifically, the
i
th token is mapped to angle
\frac{i}{N}2\pi
, the
i
th message symbol to
\frac{i}{p}2\pi
, and the
i
th random key to
\frac{i}{r}2\pi
.

To embed message
m
at time
t
, the watermarker combines the codeword symbol
C_{m}(t)\in\mathcal{F}
with the shared key
V_{t}=v_{t}\in\mathcal{R}
to produce the
channel input
:

\displaystyle z_{t}=\left(\frac{2\pi C_{m}(t)}{p}+\frac{2\pi v_{t}}{r}+\phi\right)\bmod 2\pi

(7)

where
\phi
is a fixed angle offset. In the next stage, optimal transport is used to select a token
X_{t}
close to
z_{t}
.

Message embedding:

At time
t
, the encoder transmits
z_{t}
by biasing the LLM’s token distribution such that, after observing
n
token-key pairs
\{(x_{t},s_{t})\}_{t=1}^{n}
, the decoder can reliably recover the embedded message
m
. Our key insight is to design a watermarked distribution
Q_{X_{t}|Z_{t}}
(channel) that is biased toward tokens that are closer to
z_{t}
in angular distance, while maintaining the distortion-free constraint in (
1
). In other words, the watermarker’s objective is to sample a token
x_{t}
that is as close as possible to
z_{t}
in angular distance while satisfying (
1
).

We define the angular distance between angles
\theta_{1},\theta_{2}
as:

\displaystyle d(\theta_{1},\theta_{2})=\min\{|\theta_{1}-\theta_{2}|,2\pi-|\theta_{1}-\theta_{2}|\}

(8)

The watermarked distribution
Q^{*}_{X_{t}|Z_{t}}
is obtained by solving the following optimization problem at each time
t
:

\displaystyle Q_{X_{t}|Z_{t}}^{*}

\displaystyle=\arg\min_{Q_{X_{t}|Z_{t}}}\mathbb{E}_{X_{t},Z_{t}}\left[d\left(\frac{2\pi\cdot\Pi_{t}(X_{t})}{N},Z_{t}\right)\right]

\displaystyle\qquad\text{s.t. }\mathbb{E}_{Z_{t}}[Q_{X_{t}|Z_{t}}]=Q_{X_{t}}

(9)

where
\Pi_{t}
is a random permutation of token indices shared between the watermarker and the detector. This is an optimal transport (OT) problem, which we solve efficiently using the Sinkhorn algorithm. The cost matrix
\texttt{C}\in\mathbb{R}^{N\times r}
for the OT problem is defined as:

\displaystyle\texttt{C}_{i,j}=d\left(\frac{2\pi\cdot\Pi_{t}(i)}{N},\left(\frac{2\pi C_{m}(t)}{p}+\frac{2\pi j}{r}+\phi\right)\bmod 2\pi\right)

(10)

for
(i,j)\in[0:N-1]\times[0:r-1]
where
\Pi_{t}(i)
denotes the permuted index of token
i
. The Sinkhorn algorithm returns the optimal joint distribution
Q^{*}_{X_{t},Z_{t}}
, from which we extract the conditional:

\displaystyle Q^{*}_{X_{t}|Z_{t}=z_{t}}=\frac{Q^{*}_{X_{t},Z_{t}}(X_{t},z_{t})}{P_{Z_{t}}(z_{t})}=r\cdot Q^{*}_{X_{t},Z_{t}}(X_{t},z_{t})

(11)

where the second equality uses
P(Z_{t}=z_{t})=\frac{1}{r}
since
V_{t}\sim\text{uniform}[0:r-1]
. Finally, the watermarker then samples token
X_{t}\sim Q^{*}_{X_{t}|Z_{t}=z_{t}}
for the angle
z_{t}
computed in the encoding stage (
7
). This is the token received by the detector at token instance
t
.

Message decoding:

Upon receiving the token-key sequence
\{(x_{t},s_{t})\}_{t=1}^{n}
, the decoder estimates the embedded message
\hat{M}
via minimum distance decoding over all possible codewords.

Since the encoder transmits tokens as close as possible to the channel input
z_{t}
(subject to the distortion-free constraint), the decoder first recovers the transmitted angles. At time
t
, using the received token
x_{t}
, shared key
v_{t}
, and permutation
\Pi_{t}
, the decoder estimates the encoder’s channel input as:

\displaystyle\hat{z}_{t}=\frac{2\pi\cdot\Pi_{t}(x_{t})}{N}

(12)

It then removes the shared randomness to recover the codeword symbol angle:

\displaystyle\hat{C}(t)=\left(\frac{2\pi\cdot\Pi_{t}(x_{t})}{N}-\frac{2\pi v_{t}}{r}\right)\bmod 2\pi

(13)

which inverts the encoding operation in (
7
).

For each candidate message
m\in\{0,1\}^{k}
, the decoder computes its angular codeword representation:

\displaystyle C_{m}^{\text{ang}}=\left[\frac{2\pi C_{m}(1)}{p}+\phi,\dotsc,\frac{2\pi C_{m}(n)}{p}+\phi\right]

(14)

and calculates the total distance to the received sequence:

\displaystyle D_{m}=\sum_{t=1}^{n}f\left(d\left(\hat{C}(t),C_{m}^{\text{ang}}(t)\right)\right)

(15)

where
f
is a non-decreasing function. The decoded message is then
\hat{M}=\arg\min_{m}D_{m}
.

5.1
Extraction Accuracy

Message accuracy.

ArcMark
is designed to prioritize message-level recovery, rather than optimizing exclusively for bit-level accuracy. As the watermark embedding length increases, translating high bit accuracy into correct message recovery becomes increasingly difficult, since recovering longer messages is inherently more challenging: even a single bit error results in an incorrect decoded message. As a consequence, the gap in message accuracy between
ArcMark
and prior methods becomes more pronounced as the number of embedded bits grows.

Figure
3
illustrates this behavior on Llama2-7B, showing message accuracy for 3-bit (top), 8-bit (middle), and 16-bit (bottom) watermarks. As the embedding length increases,
ArcMark
maintains substantially higher message accuracy than prior methods, reflecting its emphasis on message-level recovery. A similar trend is observed on Llama3-8B, as shown in Figure
1
in the introduction for 3-bit, 8-bit, and 16-bit watermarks.

Bit accuracy.

ArcMark
is optimized for message-level recovery, but it also achieves strong bit-level performance. High message accuracy directly implies high bit accuracy—for example, correct recovery of an 8-bit message results in all 8 bits being decoded correctly. When message recovery fails, each embedded bit is still recovered with approximately 50% probability on average, due to the randomized symbol assignments and codebook structure. As a result, optimizing for message accuracy yields competitive bit accuracy as a natural consequence.

This behavior is supported empirically. As shown in Figure
4
,
ArcMark
achieves bit accuracy comparable to or higher than existing methods across a range of generation lengths and watermark embedding sizes, indicating that prioritizing message-level recovery does not come at the expense of bit-level performance.

5.2
Perplexity

We use perplexity as a text quality metric to evaluate whether
ArcMark
preserves the model’s output distribution. We compute perplexity on text generated with and without watermarking, evaluated under the same language model used for generation. Perplexity is a standard metric for assessing the likelihood assigned by a model to generated text. Evaluating perplexity using the generation model controls for model mismatch, allowing observed differences to be attributed directly to
ArcMark
rather than discrepancies between generation and evaluation models.

Figures
5
report the perplexity results. Across all embedding lengths (3, 8, and 16 bits),
ArcMark
achieves perplexity comparable to unwatermarked generation on both Llama2-7B and Llama3-8B. This suggests that watermarking does not appreciably alter the probabilities the model assigns to generated tokens, and therefore has minimal effect on token frequency statistics and overall text fluency, consistent with the distortion-free property of
ArcMark
described in (
1
).

5.3
Ablation Study on Side Information Resolution

Recall that
r
denotes the number of discrete side information values used in the optimal transport formulation (see eqn.
10
), which determines the size of the OT cost matrix and, consequently, the computational cost of the Sinkhorn solver. We study the effect of varying
r\in\{64,512,1024\}
on message and bit accuracy. As shown in Figure
6
, performance is comparable across different values of
r
, indicating that increasing the side information resolution provides limited benefit for extraction accuracy. Since larger
r
incurs higher computational overhead, these results suggest that a small value (e.g.,
r=64
) is sufficient in practice.

6
Conclusion

Our results suggest a principled path forward for multi-bit watermark design: once watermarking is cast as channel coding with side information, novel schemes inspired by time-tested error-correcting codes can be used to watermark LLMs. This approach led to
ArcMark
, which significantly outperforms existing benchmarks. Future work includes developing watermarking schemes that achieve capacity in a wider class of settings. Evaluating the capacity characterization in Theorem
3.1
for more realistic settings than in Corollary
3.2
is a challenge; but doing so can yield insights leading to better watermarkers. Finally, an unexploited resource with our method is that the watermarker has
feedback
, in that it knows the tokens that are sent to the decoder, which can be viewed as the output of the channel. While feedback typically does not increase capacity, it likely will improve probability of error or encoding complexity.

Impact Statement

Multi-bit watermarking of LLMs can curb AI misuse and add a layer of accountability, even beyond existing zero-bit watermarkers. Multi-bit watermarkers such as the one introduced in this paper can include information about the model version, user ID, or even the prompt, all of which are valuable for tracking and verifying LLM output. High-capacity low error-probability distortion-free watermarkers will enable these societally-beneficial capabilities, all without impacting LLM performance, which means they are more likely to be used in practice.

\displaystyle=\frac{N}{\pi\binom{N}{2}}\left(\pi-\frac{\pi}{2N}-d(z_{t},A_{y_{a}})\right)

(67)

\displaystyle=\frac{N}{\pi\binom{N}{2}}\left(d_{\max}-d(z_{t},A_{y_{a}})\right).

(68)

Since this holds for all
a
, and
y_{a}
runs over all tokens in the alphabet for all
a
, this means that for any token
x
, we can rewrite the likelihood function in terms of the distance function:

P(X_{t}=x|z_{t})=\frac{N}{\pi\binom{N}{2}}\left(d_{\max}-d(z_{t},A_{x})\right).

(69)

Recalling that
A_{x}=\frac{2\pi\Pi_{t}(x)}{N}
, we have

\displaystyle d(z_{t},A_{x_{t}})

\displaystyle=d\left(C_{m}^{\text{ang}}+\frac{2\pi v_{t}}{N}\text{ mod }2\pi,\frac{2\pi\Pi_{t}(x_{t})}{N}\right)

(70)

\displaystyle=d\left(C_{m}^{\text{ang}},\frac{2\pi}{N}\left(\Pi_{t}(x_{t})-v_{t}\right)\text{ mod }2\pi\right)

(71)

\displaystyle=d(C_{m}^{\text{ang}},\hat{C}(t))

(72)

where we have used the fact that

\hat{C}(t)=\frac{2\pi}{N}\left(\Pi_{t}(x_{t})-v_{t}\right)\text{ mod }2\pi.

(73)

Thus,

P(X_{t}=x_{t}|z_{t})=\frac{N}{\pi\binom{N}{2}}\left(d_{\max}-d(C_{m}^{\text{ang}},\hat{C}(t))\right).

(74)

Considering this likelihood function for all time instances
t
, we have

P(X^{n}=x^{n}|z^{n})=\prod_{t=1}^{n}\frac{N}{\pi\binom{N}{2}}\left(d_{\max}-d(C_{m}^{\text{ang}},\hat{C}(t))\right).

(75)

Therefore, the maximum likelihood decoder is identical to the decoding rule given in (
60
).

By classical results in information theory (see
[
25
]
, Theorem 18.13), random linear coding as in (
6
) with maximum likelihood decoding can achieve arbitrarily small probability of error for any rate below the mutual information of the channel, assuming the input distribution is uniform. In this case, the channel has input given by the code sequence
C_{m}(t)
, the output is the token
X_{t}
, and we have side information
W_{t}
, known to both encoder and decoder (so we can condition on
W_{t}
in the mutual information). Based on the calculation of the likelihood function in (
64
),

I(C(t);X_{t}|W_{t})=H(X_{t}|W_{t})-H(X_{t}|C(t),W_{t})=H(X_{t})-H(X_{t}|Z_{t})=\log N+\sum_{i=1}^{N-1}\frac{i}{\binom{N}{2}}\log\frac{i}{\binom{N}{2}}.

(76)

Since this quantity matches the capacity found in Corollary
3.2
, this proves that
ArcMark
achieves capacity for this setting.
