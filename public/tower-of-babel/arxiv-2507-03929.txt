An ASP-Based Framework for MUSes
Mohimenul Kabir, Kuldeep S Meel

Abstract
Given an unsatisfiable formula, understanding the core reason for unsatisfiability is crucial in several applications. One effective way to capture this is through the minimal unsatisfiable subset (MUS), the subset-minimal set of clauses that remains unsatisfiable. Current research broadly focuses on two directions: (i) enumerating as many MUSes as possible within a given time limit, and (ii) counting the total number of MUSes for a given unsatisfiable formula. In this paper, we introduce an answer set programming-based framework, named 𝖬 ​ 𝖴 ​ 𝖲 \mathsf{\mathchar 29005\mathchar 29013\mathchar 29011} - 𝖠 ​ 𝖲 ​ 𝖯 \mathsf{\mathchar 28993\mathchar 29011\mathchar 29008} , designed for online enumeration of MUSes. ASP is a powerful tool for its strengths in knowledge representation and is particularly suitable for specifying complex combinatorial problems. By translating MUS enumeration into answer set solving, 𝖬 ​ 𝖴 ​ 𝖲 \mathsf{\mathchar 29005\mathchar 29013\mathchar 29011} - 𝖠 ​ 𝖲 ​ 𝖯 \mathsf{\mathchar 28993\mathchar 29011\mathchar 29008} leverages the computational efficiency of state-of-the-art ASP systems. Our extensive experimental evaluation demonstrates the effectiveness of 𝖬 ​ 𝖴 ​ 𝖲 \mathsf{\mathchar 29005\mathchar 29013\mathchar 29011} - 𝖠 ​ 𝖲 ​ 𝖯 \mathsf{\mathchar 28993\mathchar 29011\mathchar 29008} and highlights the acceleration in both MUS enumeration and counting tasks, particularly when integrated within hybrid solvers, including the framework proposed in this paper.

Introduction

When dealing with an unsatisfiable formula — one that has no solution — it is often crucial to identify the reasons for its unsatisfiability.
A common concept in the literature is the
minimal unsatisfiable subset
(MUS), which provides a concise explanation for the formula’s unsatisfiability
(
Liffiton et al., 2016
)
.
For instance, in
requirement analysis

(
Bendík, 2017
)
, a set of constraints represents the requirements that need to be fulfilled.
If these constraints are unsatisfiable, a MUS highlights the minimal set of requirements that cannot be satisfied simultaneously.

Given an unsatisfiable Boolean formula
\mathchar 28998
, expressed as a conjunction of clauses
\{\mathchar 28995_{\mathchar 28721}\mathchar 24891\ldots\mathchar 24891\mathchar 28995_{\mathsf{\mathchar 29038\mathchar 29027\mathchar 29036}}\}
,
a minimal unsatisfiable subset (MUS) of
\mathchar 28998
is a subset
\mathchar 28998\raise 3.44444pt\hbox{\sevensy\char 48\relax}\mathchar 12818\mathchar 28998
such that
\mathchar 28998\raise 3.44444pt\hbox{\sevensy\char 48\relax}
is unsatisfiable
and for every
\mathchar 28995_{\mathchar 29033}\mathchar 12850\mathchar 28998\raise 3.44444pt\hbox{\sevensy\char 48\relax}
, the set
\mathchar 28998\raise 3.44444pt\hbox{\sevensy\char 48\relax}\mathchar 8814\{\mathchar 28995_{\mathchar 29033}\}
is satisfiable.
Finding MUSes is an active research area due to their wide range of applications, including
formal equivalence checking
(
Cohen et al., 2010
)
,
Boolean function bi-decomposition
(
Chen and Marques-Silva, 2012
)
,
counter-example guided abstraction refinement
(
Andraus et al., 2007
)
, circuit error diagnosis
(
Han and Lee, 1999
)
,
and others
(
Hunter and Konieczny, 2008
;
Ivrii et al., 2016
;
Jannach and Schmitz, 2016
)
.

Since the MUS of an unsatisfiable formula is not necessarily unique, it is important to enumerate multiple MUSes.
Enumerating more MUSes of
\mathchar 28998
provides a clearer explanation of the underlying unsatisfiability
(
Bendík and Černá, 2020b
)
.
Thus, existing research focuses on enumerating MUSes in an
online fashion

(
Bacchus and Katsirelos, 2015
;
Katsirelos and Bacchus, 2016
;
Bendík and Černá, 2020b
;
Bendík et al., 2018
;
Narodytska et al., 2018
;
Liffiton and Malik, 2013
)
, aiming to identify as many MUSes as possible within a given time limit.
Moreover, the number of MUSes is frequently used as a metric to quantify inconsistency in diagnostic tasks
(
Mu et al., 2011
;
Hunter and Konieczny, 2008
)
.

Existing MUS enumeration algorithms can be broadly divided into two categories: algorithms based on the well-known
seed-shrink
scheme
(
Bendík and Černá, 2020a
)
and those employing the
hitting set duality

(
Reiter, 1987
)
.
The seed-shrink scheme systematically explores subsets of
\mathchar 28998
and identifies an unsatisfiable subset called a
u-seed
, which is then shrunk into a MUS through a single MUS
extractor

(
Belov and Marques-Silva, 2012
)
.
Conversely, the hitting set duality leverages the well-known relationship between MUSes and MCSes, where a
minimal correction subset
(MCS) is the minimal subset
\mathchar 28998\raise 3.44444pt\hbox{\sevensy\char 48\relax}\mathchar 12826\mathchar 28998
such that the formula
\mathchar 28998\mathchar 8814\mathchar 28998\raise 3.44444pt\hbox{\sevensy\char 48\relax}
is satisfiable.
This approach involves computing and exploiting the MCSes of
\mathchar 28998
to enumerate MUSes
(
Liffiton and Sakallah, 2008
)
.
Traditional MUS enumeration techniques often rely on SAT-based methods.
In contrast, we explore an alternative perspective by formulating MUS enumeration as an
answer set solving
problem, leveraging the expressiveness of ASP for modeling combinatorial structures.

Answer set programming (ASP)
(
Marek and Truszczyński, 1999
)
is a well-known declarative problem-solving paradigm in knowledge representation and reasoning, valued for its ability to model complex combinatorial problems
(
Erdem et al., 2016
)
.
An ASP
program
consists of
logical rules
defined over
propositional atoms

An assignment of values to propositional atoms that satisfies the ASP semantics of the program is referred to as an
answer set
.
ASP programs can be classified into two categories based on their expressiveness:
disjunctive
and
normal
ASP programs
(
Lierler, 2005
)
.
However, the expressiveness comes at the cost of computational complexity.
Specifically, determining whether a disjunctive program has an answer set is
\textstyle\mathchar 4944\displaylimits_{\mathchar 28722}^{\mathchar 29008}
-complete
(
Eiter and Gottlob, 1995
)
,
while the complexity reduces to NP-complete for normal programs
(
Marek and Truszczyński, 1991
)
.

The main contribution of the paper is the proposal of an ASP solving-based MUS enumeration framework called
\mathsf{\mathchar 29005\mathchar 29013\mathchar 29011}
-
\mathsf{\mathchar 28993\mathchar 29011\mathchar 29008}

To compute MUSes, we focus on

Computing the subset minimal answer sets is not a new research problem

It is worth noting that reducing one problem to a harder one is not uncommon in combinatorial problem-solving

Building on prior work in ASP-based counting

, we provide an extensive experimental evaluation demonstrating that
\mathsf{\mathchar 29005\mathchar 29013\mathchar 29011}
-
\mathsf{\mathchar 28993\mathchar 29011\mathchar 29008}
outperforms existing MUS enumerators and counters across multiple benchmarks, where counting is performed via enumeration.
Although
\mathsf{\mathchar 29005\mathchar 29013\mathchar 29011}
-

While the

)

\mathsf{\mathchar 29005\mathchar 29013\mathchar 29011}
-
\mathsf{\mathchar 28993\mathchar 29011\mathchar 29008}

3
Related Works

Previous research on MUSes primarily focused on the extraction of a single MUS or computing one single MUS
(
Belov and Marques-Silva, 2011
;
Belov and Marques-Silva, 2012
;
Nadel et al., 2014
;
Nadel, 2010

However, with the increasing demand for computing multiple MUSes, the area of MUS enumeration has emerged as a significant focus of recent research
(
Bendík and Černá, 2020b
)
.
Very recently, there has been growing interest in MUS counting.

MUS Enumeration.

FLINT
(
Narodytska et al., 2018

utilizes a framework similar to those in
(
Marques-Silva and Planes, 2008
)
for MUS enumeration,
iteratively computing MUSes and MCSes of an unsatisfiable formula across multiple

an unsatisfiable formula and

a satisfiable one.

(

)

To find a MUS of a Boolean formula
\mathchar 28998

This u-seed is then shrunk to a MUS through a single MUS extraction subroutine.
The main difference between these algorithms lies in how they identify the u-seed
\mathchar 29011
.
MARCO iteratively identifies maximal unexplored subsets of
\mathchar 28998
and checks their satisfiability until a u-seed is found.
TOME computes a chain of unexplored subsets of
\mathchar 28998
— namely,
\mathchar 28998_{\mathchar 28721}\mathchar 12826\ldots\mathchar 28998_{\mathchar 29040}

binary search
over the chain to identify MUSes.
ReMUS employs a different technique to identify smaller u-seeds, which are easier to shrink.
In particular, ReMUS finds the initial u-seed
\mathchar 29011
among the maximal unexplored subsets of
\mathchar 28998
and shrinks it into a MUS
\mathchar 29011\raise 3.44444pt\hbox{\sevensy\char 48\relax}

To find subsequent MUSes, ReMUS selects a set
\mathchar 29010
such that
\mathchar 29011\raise 3.44444pt\hbox{\sevensy\char 48\relax}\mathchar 12826\mathchar 29010\mathchar 12826\mathchar 29011

decreasing the size of the u-seed with each recursive call.

The hitting set duality is specifically used in MUS enumerators such as CAMUS
(
Liffiton and Sakallah, 2008
)
and DAA
(
Bailey and Stuckey, 2005
)
.
CAMUS operates in two phases: in the first phase, it computes MCSes of a formula using an
incremental
SAT solver; in the second phase, it enumerates MUSes by finding minimal hitting sets of the computed MCSes through a

.
DAA is based on the

(

A major drawback of these techniques is that the number of MCSes can grow exponentially.

The hitting set duality is also leveraged in the MUS enumerator MCS-MUS

Bacchus and Katsirelos, 2015

This approach incorporates several optimization techniques, such as

(
Nadel et al., 2014

In a follow-up work,
Katsirelos and Bacchus, 2016

MUS Counting.

MUS counting without explicit enumeration was first introduced by
Bendík and Meel, 2020
. They developed a
hashing-based
model counting framework, AMUSIC, which provides an
\delimiter 67273472\mathchar 28962\mathchar 24891\mathchar 28942\delimiter 84054785
-approximation
(

)

The counting framework AMUSIC does not scale due to its reliance on
\mathchar 4944\displaylimits_{\mathchar 28723}^{\mathchar 29008}

Later,
Bendík and Meel, 2021

Subset-minimal Answer Sets.

A variety of techniques exist for computing subset-minimal answer sets.
The tool asprin
(
Brewka et al., 2015
)
supports subset minimality as a special case of user-defined
preferences

Clingo computes the subset-minimal answer sets using an approach similar to the OPTSAT algorithm
(
Di Rosa et al., 2010

More recently,
Alviano et al., 2023

\mathsf{\mathbf{\mathchar 29000}}_{\mathchar 28721}
Union of MUSes.

If we compute a union of MUSes or an over-approximation of them,
then we can focus only on those clauses for MUS computation

Lymperopoulos and Liu, 2024

Computing the union of MUSes is computationally harder

Building on the work in
(

(
Kleine Büning and Kullmann, 2009

(
Marques-Silva et al., 2014
)

Bendík and Meel, 2021
)
to compute a lower bound on the minimum MUS cardinality using the well-known minimal hitting set duality.
Additionally, we compute an upper bound on the maximum MUS cardinality by solving a MaxSAT problem.
