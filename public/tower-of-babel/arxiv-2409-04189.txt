Optimal Fidelity Estimation from Binary Measurements for Discrete and Continuous Variable Systems
Omar Fawzi, Aadil Oufkir, Robert Salzmann

Abstract
Estimating the fidelity between a desired target quantum state and an actual prepared state is essential for assessing the success of experiments. For pure target states, we use functional representations that can be measured directly and determine the number of copies of the prepared state needed for fidelity estimation. In continuous variable (CV) systems, we utilise the Wigner function, which can be measured via displaced parity measurements. We provide upper and lower bounds on the sample complexity required for fidelity estimation, considering the worst-case scenario across all possible prepared states. For target states of particular interest, such as Fock and Gaussian states, we find that this sample complexity is characterised by the L 1 L^{1} -norm of the Wigner function, a measure of Wigner negativity widely studied in the literature, in particular in resource theories of quantum computation. For discrete variable systems consisting of n n qubits, we explore fidelity estimation protocols using Pauli string measurements. Similarly to the CV approach, the sample complexity is shown to be characterised by the L 1 L^{1} -norm of the characteristic function of the target state for both Haar random states and stabiliser states. Furthermore, in a general black box model, we prove that, for any target state, the optimal sample complexity for fidelity estimation is characterised by the smoothed L 1 L^{1} -norm of the target state. To the best of our knowledge, this is the first time the L 1 L^{1} -norm of the Wigner function provides a lower bound on the cost of some information processing task.

Introduction

With the possibility to produce a variety of complex and highly entangled quantum states in experiments, it is essential to develop reliable methods certifying that a desired target state has been prepared successfully. For a pure target state
\rho=|\psi\rangle\!\langle\psi|
and an actually prepared state
\sigma
, an operationally meaningful way to achieve such certification is by estimating the fidelity
F(\rho,\sigma)
through measurements on the state
\sigma.
For example, performing the projective measurement
\{|\psi\rangle\!\langle\psi|,\mathbbm{1}-|\psi\rangle\!\langle\psi|\}
, allows fidelity estimation using a number of copies of
\sigma
that depends only on the desired accuracy and success probability, and is independent of the target state or system size. However, for most states
|\psi\rangle\!\langle\psi|
of interest, performing this measurement is not possible in practice in an efficient and reliable manner. Therefore, it is sensible to express the fidelity as the overlap of certain functions representing the quantum states, which can be directly measured with current experimental techniques
[
FL11
,
dSLCP11
]
:

For continuous variable (CV) quantum systems with
m\in\mathbb{N}
degrees of freedom, e.g. an
m
-mode photonic system, we use the phase space representation of the fidelity between
\rho
and
\sigma
in terms of their
Wigner functions

W_{\rho}
and
W_{\sigma}
given by

\displaystyle F(\rho,\sigma)=\pi^{m}\int_{\mathbb{C}^{m}}W_{\rho}(\alpha)W_{\sigma}(\alpha)d\alpha.

(1.1)

Assuming full knowledge of the pure target state
\rho
, the fidelity can hence be estimated by directly measuring the Wigner function
W_{\sigma}(\alpha)
at different points in phase space
\alpha\in\mathbb{C}^{m}
through
Wigner tomography.
This can be achieved by utilising
that the Wigner function of
\sigma
is given by the expectation value of the
displaced parity operator

[
Roy77
]
, i.e.

\displaystyle W_{\sigma}(\alpha)=\left(\frac{2}{\pi}\right)^{m}\mathrm{Tr}\Big(D(\alpha)\Pi D^{*}(\alpha)\ \sigma\Big),

(1.2)

with
D(\alpha)
denoting the
displacement operator
and
\Pi=(-1)^{N}
the
parity operator
with
N
being the
m
-mode number operator
(c.f. Section
2.4
for definition). The observable
\left(2/\pi\right)^{m}D(\alpha)\Pi D^{*}(\alpha)
has measurement outcomes
\{\left(2/\pi\right)^{m},-\left(2/\pi\right)^{m}\},
showing that we can estimate
W_{\sigma}(\alpha)
by some binary measurement on the state
\sigma.
A practical scheme for performing these displaced parity measurements relying on Ramsey interferometry has been proposed in
[
LD97
]
and experimentally first implemented in
[
NRO+00
,
BAM+02
,
VKL+13a
]
. Directly measuring the Wigner function in this way and performing fidelity estimation using (

) has become conventional in practice, see
[
VKL+13b
,
WGR+16
,
RBG+24
,
MEC+24
,
MDR+24
]
and references therein. In the following, we refer to the above-described paradigm as the
Wigner model of fidelity estimation
.

On the other hand, for discrete variable (DV) quantum systems consisting of
n
qubits, we consider the representation of the fidelity given by

\displaystyle F(\rho,\sigma)=\frac{1}{d}\sum_{P\in\mathcal{P}_{n}}\chi_{\rho}(P)\chi_{\sigma}(P),

(1.3)

with dimension of the overall system
d=2^{n}
,
\mathcal{P}_{n}=\{\mathbbm{1},X,Y,Z\}^{\otimes n}
denoting the set of Pauli strings of length
n
and

\displaystyle\chi_{\sigma}(P)=\mathrm{Tr}(P\sigma)

(1.4)

the
characteristic function
of the state
\sigma.
Again, assuming full knowledge of the pure target state
\rho,
we can estimate the fidelity by measuring Pauli strings with binary outcome in
\{1,-1\}
on the state
\sigma.

We refer to this paradigm as the
Pauli model of fidelity estimation
in the following.

For both of these settings, efficient fidelity estimation algorithms are know for some special families of states, e.g., well-conditioned states including stabiliser states
[
FL11
]
. However, as far as we are aware, no lower bound for fidelity estimation is known. This raises the following natural question:

Are there states for which fidelity estimation is hard?

More specifically, in the Wigner model of fidelity estimation, are there states for which the sample complexity is arbitrarily large? In the Pauli model, are there states for which the number of samples required is exponential in
n
? Our results give an affirmative answer to both of these questions using Fock states (Eq. (
1.10
)) and Haar-random
n
-qubit states (Eq. (
1.17
)). Going beyond such hard states, we can ask:

Which property of
\rho
quantifies the sample complexity of fidelity estimation?

We identify the smoothed
L^{1}
-norm as quantifying the optimal sample complexity for fidelity estimation in a general black box model (Eq. (
1.7
)).

\displaystyle=N_{\varepsilon,\delta}(W_{\rho},\mathcal{S}_{W}),

\displaystyle\text{DV systems: }\ \quad N^{\scalebox{0.65}{$P$}}_{\varepsilon,\delta}(\rho)

\displaystyle=N_{\varepsilon,\delta}(\chi_{\sigma},\mathcal{S}_{P}).

(1.6)

We provide upper and lower bounds on the sample complexity of black box overlap estimation

for a large class of sets of functions

Black box overlap estimation:

For general measurable spaces
\Omega
with measure
\mu
we prove upper and lower bounds on the sample complexity
N_{\varepsilon,\delta}(f,\mathcal{S})
for

and all sets of functions

where for some fixed number

consists of all functions

\mathcal{S}
and

are motivated by the Wigner- and Pauli model as for all quantum states
\rho

\|W_{\rho}\|_{L^{2}(\mathbb{C}^{m},\mu_{W})}\leq 1
and
\|W_{\rho}\|_{L^{\infty}(\mathbb{C}^{m},\mu_{W})}\leq(2/\pi)^{m}
(or
\|\chi_{\rho}\|_{L^{2}(\mathcal{P}_{n},\mu_{P})}\leq 1
and
\|\chi_{\rho}\|_{L^{\infty}(\mathcal{P}_{n},\mu_{P})}\leq 1
). Hence, under the appropriate choice of
\Omega
and
\mu
as above, the sets of Wigner- and characteristic functions for continuous and discrete variable quantum systems respectively provide examples of such sets
\mathcal{S},
i.e.
\mathcal{S}_{W}\subset\mathcal{S}_{\max}
and
\mathcal{S}_{P}\subset\mathcal{S}_{\max}.

For all such sets

we provide an explicit algorithm for estimating the overlap (

) yielding an upper bound on

(c.f. Theorem

) and furthermore, through some information theoretic argument, the corresponding lower bound (c.f. Theorem

). For the particular choice of

since they are given as

\displaystyle\left(\frac{\|f\|^{(2\varepsilon)}_{1}}{2\varepsilon}\right)^{2}\log\left(\frac{1}{3\delta}\right)\ \lesssim\,N_{\varepsilon,\delta}(f,\mathcal{S}_{\max})\,\lesssim\inf_{\varepsilon^{\prime}\in[0,\varepsilon)}\left(\frac{\|f\|^{(\varepsilon^{\prime})}_{1}}{\varepsilon-\varepsilon^{\prime}}\right)^{2}\log\left(\frac{1}{\delta}\right).

(1.7)

Here, we have denoted the
smoothed
L^{1}
-norm
of the function

by

\displaystyle\|f\|^{(\varepsilon)}_{1}=\inf_{\begin{subarray}{c}\tilde{f}\in L^{1}(\Omega)\cap L^{2}(\Omega),\\
\|f-\tilde{f}\|_{2}\leq\varepsilon\end{subarray}}\|\tilde{f}\|_{1}.

(1.8)

Note that (

characterisation for the task of black box overlap estimation, i.e., it identifies precisely the property of

that governs the sample complexity as the smoothed
L^{1}
-norm. The study of instance-optimal bounds is well-developed in the learning literature, for example for the problem of identity testing, one of the flagship results is that classical identity testing is characterised by a smoothed version of the

-quasinorm of the distribution to be tested
[

]
; see also
[

]
for results about quantum identity testing in this direction.

For functions

with rapidly decaying tail as defined in Section
3
and discussed in detail in Appendix

, which include for example exponentially decaying functions on Euclidean space, we find that the sample complexity is characterised by the usual

-norm as

\displaystyle N_{\varepsilon,\delta}(f,\mathcal{S}_{\max})=\Theta\left(\left(\frac{\|f\|_{1}}{\varepsilon}\right)^{2}\log\left(\frac{1}{\delta}\right)\right),

(1.9)

with precise statement given in Corollary

Fidelity estimation in Wigner model:

In Theorem
4.1
and
4.2

we give upper and lower bounds on the sample complexity of fidelity estimation in the Wigner model,

from the ones established for the abstract framework of black box overlap estimation. In particular, the upper bound involves the smoothed

-norm of

giving that for every fixed pure state

can be estimated by performing displaced parity measurements on a finite number of copies of

Showing for general pure states

For

9

9

The integral expression (

We consider some measurable space
\Omega
with measure
\mu
and employ the notation of Section
2.2
. Let
r>0
be some number, which is fixed throughout the whole section. We say one has
black box access to some function

g\in B^{\infty}_{r}(0)
if for every
\lambda\in\Omega
one can obtain samples from the unique
11
11

11

Note that the condition on
Y_{\lambda}
uniquely determines its distribution to be
\mathbb{P}(Y_{\lambda}=r)=\frac{1+g(\lambda)/r}{2}
and
\mathbb{P}(Y_{\lambda}=-r)=\frac{1-g(\lambda)/r}{2}
random variable
Y_{\lambda}\equiv Y_{\lambda}(g)
with outcome space
\{r,-r\}
and

\displaystyle\mathbb{E}[Y_{\lambda}]=g(\lambda).

(3.1)

In the following we consider subsets
\mathcal{S}\subseteq B^{\infty}_{r}(0)
and assume to have black box access to the functions
g\in\mathcal{S}.

With that terminology the task of
black box overlap estimation
is defined to be the following:
Let
f\in L^{2}(\Omega,\mathbbm{R})
and
\mathcal{S}\subseteq L^{2}(\Omega,\mathbbm{R})\cap B^{\infty}_{r}(0).
Then,
provided full access to the function
f
and black box access to a function

the goal is to estimate

\displaystyle\int_{\Omega}f(\lambda)g(\lambda)d\mu(\lambda)=\int_{\Omega}f(\lambda)\,\mathbbm{E}[Y_{\lambda}]d\mu(\lambda)

(3.2)

using as few samples as possible of the random variable
Y_{\lambda}\equiv Y_{\lambda}(g)
for different points
\lambda\in\Omega
. More precisely, for
N\in\mathbb{N},
a
N
-query algorithm

\mathcal{\mathcal{A}}
for the task of black box overlap estimation takes points
\lambda_{1},\cdots,\lambda_{N}\in\Omega
and for each
\lambda_{t}
a sample
y_{\lambda_{t}}\in\{r,-r\}
from
Y_{\lambda_{t}}.
Here, we allow for adaptive algorithms meaning that the points
\lambda_{t},
or their distributions when chosen at random, can depend on
f
and the previous points
\lambda_{1},\cdots,\lambda_{t-1}
and corresponding samples, i.e.

\displaystyle\lambda_{1}\equiv

\displaystyle\,\lambda_{1}(f)

\displaystyle\longrightarrow\quad

\displaystyle y_{\lambda_{1}}\ \text{ sample from }Y_{\lambda_{1}}

\displaystyle\lambda_{2}\equiv

\displaystyle\,\lambda_{2}(f,\lambda_{1},y_{\lambda_{1}})

\displaystyle\longrightarrow\quad

\displaystyle y_{\lambda_{2}}\ \text{ sample from }Y_{\lambda_{2}}

\displaystyle\lambda_{N}\equiv

\displaystyle\,\lambda_{N}(f,\lambda_{1},y_{\lambda_{1}},\cdots,\lambda_{N-1},y_{\lambda_{N-1}})

\displaystyle\longrightarrow\quad

\displaystyle y_{\lambda_{N}}\ \text{ sample from }Y_{\lambda_{N}}.

(3.3)

The algorithm then outputs a value
\phi_{\mathcal{A}}(f,\lambda_{1},y_{\lambda_{1}},\cdots,\lambda_{N},y_{\lambda_{N}})\in\mathbbm{R}.
We demand that
\mathcal{A}
works for any function

We say the algorithm

\displaystyle\mathbb{P}\left(\,\left|\phi_{\mathcal{A}}(f,\lambda_{1},y_{\lambda_{1}},\cdots,\lambda_{N},y_{\lambda_{N}})-\int_{\Omega}f(\lambda)g(\lambda)d\mu(\lambda)\right|>\varepsilon\right)\leq\delta.

The optimal sample complexity of black box overlap estimation for the function

is hence defined as

\displaystyle N_{\varepsilon,\delta}(f,\mathcal{S})=\inf\left\{N\in\mathbb{N}\Big|\,\exists N\text{-query algorithm with accuracy $\varepsilon$ and failure probability bounded by $\delta$}\right\}.

\displaystyle\left(\frac{r\|f\|^{(2\varepsilon)}_{1}}{2\varepsilon}\right)^{2}\log\left(\frac{1}{3\delta}\right)\ \leq\,N_{\varepsilon,\delta}(f,\mathcal{S}_{\max})\,\leq\ 2\inf_{\varepsilon^{\prime}\in[0,\varepsilon)}\left(\frac{r\|f\|^{(\varepsilon^{\prime})}_{1}}{\varepsilon-\varepsilon^{\prime}}\right)^{2}\log\left(\frac{1}{\delta}\right).

(3.4)

c\geq 0.
Then we have

\displaystyle N_{\varepsilon,\delta}(f,\mathcal{S}_{\max})=\Theta\left(\left(\frac{r\|f\|_{1}}{\varepsilon}\right)^{2}\log\left(\frac{1}{\delta}\right)\right)

(3.11)

for
\varepsilon,\delta>0
small enough, i.e. for all
\varepsilon,\delta\in(0,c^{\prime}]
where
c^{\prime}
depends on
c
but not on
f.

Proof.
We get from Theorem
3.1
and the definition of the smoothed
L^{1}
-norm in (
2.2
) the upper bound

\displaystyle N_{\varepsilon,\delta}(f,\mathcal{S}_{\max})\leq 2\left(\frac{r\|f\|_{1}}{\varepsilon}\right)^{2}\log\left(\frac{1}{\delta}\right).

On the other hand from Lemma
A.2
and the fact that
\kappa,\sqrt{\mu(\Omega_{0})}\leq\mathcal{O}(\|f\|_{1}),
we have

\displaystyle\|f\|^{(2\varepsilon)}_{1}\geq\|f\|_{1}\left(1-C\varepsilon^{\beta}\right)

for some
C\geq 0
independent of
f
and
\varepsilon.

Hence, by the
lower bound (
3.8
) in Theorem
3.3
we find for all
\varepsilon,\delta>0
small enough

\displaystyle N_{\varepsilon,\delta}(f,\mathcal{S}_{\max})

\displaystyle\geq\left(\frac{r\|f\|^{(2\varepsilon)}_{1}}{2\varepsilon}\right)^{2}\log\left(\frac{1}{3\delta}\right)\gtrsim\left(\frac{r\|f\|_{1}}{2\varepsilon}\right)^{2}\log\left(\frac{1}{3\delta}\right).

3.1
Proof of the upper bound on the sample complexity
N_{\varepsilon,\delta}(f,\mathcal{S})

In this section we prove the upper bound on the sample complexity of black box overlap estimation given in Theorem
3.1
. The proof works by providing a specific algorithm for the estimation task: Here, the tester chooses random points
\lambda\in\Omega
by sampling from the distribution

\displaystyle p(\lambda)=\frac{|\widetilde{f}(\lambda)|}{\|\widetilde{f}\|_{1}},

(3.12)

where
\widetilde{f}
is essentially the minimiser in the optimisation of the smoothed
L^{1}
-norm in (
2.2
). For every chosen
\lambda,
a sample of the bounded random variable
Y_{\lambda}\,\|\widetilde{f}\|_{1}\operatorname{sgn}(f(\lambda))
is obtained. Using these samples, an empirical estimator is calculated which, provided the number of samples is high enough, is close to the overlap

\displaystyle\int_{\Omega}\widetilde{f}(\lambda)g(\lambda)d\mu(\lambda)

by Hoeffding’s inequality
[
Hoe63
]
. This overlap approximates the desired one in (
3.2
) since
\widetilde{f}
and the target function
f
are close in
L^{2}
-norm.

In
[
FL11
,
dSLCP11
]
a similar algorithm has been considered for the concrete case of fidelity estimation in the Pauli model. Formulating their approach in terms in the abstract black box overlap estimation framework, the authors consider the distribution

\displaystyle p_{2}(\lambda)=\frac{f^{2}(\lambda)}{\|f\|^{2}_{2}},

(3.13)

instead the distribution
p(\lambda)
above, for sampling
\lambda\in\Omega.
For every chosen
\lambda
they then take samples from the random variable
\|f\|^{2}_{2}Y_{\lambda}/f(\lambda)
to construct an empirical estimator for the overlap (
3.2
). This random variable is no longer bounded, leading to a worse upper bound on the corresponding sample complexity for many functions
f.
Recently,
[
GPR23
]
use
the same sampling distribution as ours for the problem of estimation the expectation values of observables in the Pauli model. However, their analysis is different than ours.

Proof of Theorem
3.1
.

Let
\varepsilon>0
,
\varepsilon^{\prime}\in[0,\varepsilon)
and
\widetilde{f}\in L^{2}(\Omega,\mathbbm{R})\cap L^{1}(\Omega,\mathbbm{R})
such that
\|f-\widetilde{f}\|_{2}\leq\varepsilon^{\prime}.
Note that such a function always exists since
L^{2}(\Omega,\mathbbm{R})\cap L^{1}(\Omega,\mathbbm{R})
is dense in
L^{2}(\Omega,\mathbbm{R})
as remarked in Section
2.2
.
Consider the random variable
\Lambda
with outcome space
\Omega
and distributed according to the probability density

\displaystyle p(\lambda)=\frac{|\widetilde{f}(\lambda)|}{\|\widetilde{f}\|_{1}}.

Let
g\in\mathcal{S}\subseteq B^{2}_{1}(0)\cap B^{\infty}_{r}(0)
for which we assume to have black box access and
Y_{\lambda}\equiv Y_{\lambda}(g)
the corresponding random variable with outcome space
\{r,-r\}
satisfying (
3.1
).
Consider the random variable

\displaystyle X=Y_{\Lambda}\ \|\widetilde{f}\|_{1}\,\operatorname{sgn}(\widetilde{f}(\Lambda)).

Note that by definition we have

\displaystyle\mathbbm{E}[X]=\mathbbm{E}\big[Y_{\Lambda}\ \|\widetilde{f}\|_{1}\,\operatorname{sgn}(\widetilde{f}(\Lambda))\big]=\int_{\Omega}\frac{|\widetilde{f}(\lambda)|}{\|\widetilde{f}\|_{1}}g(\lambda)\|\widetilde{f}\|_{1}\,\operatorname{sgn}(\widetilde{f}(\Lambda))d\mu(\lambda)=\int_{\Omega}\widetilde{f}(\lambda)g(\lambda)d\mu(\lambda).

For
N\in\mathbb{N}
to be determined later we take samples
\lambda_{1},\cdots,\lambda_{N}
of
\Lambda
and then for each
\lambda_{i}
a sample
y_{\lambda_{i}}
of
Y_{\lambda_{i}}.
Furthermore, we define the empirical average

\displaystyle\overline{X}=\frac{1}{N}\sum_{i=1}^{N}\ y_{\lambda_{i}}\ \|\widetilde{f}\|_{1}\,\operatorname{sgn}(\widetilde{f}(\lambda_{i})).

Noting that by definition and assumption (
3.1
) the random variable
X
is bounded as

\left|X\right|\leq r\|\widetilde{f}\|_{1},

we can employ Hoeffding’s inequality
[
Hoe63
]
which gives

\displaystyle\mathbb{P}\left(\,\left|\,\overline{X}-\int_{\Omega}\widetilde{f}(\lambda)g(\lambda)d\mu(\lambda)\right|\geq\varepsilon-\varepsilon^{\prime}\right)\leq\exp\left(-\frac{N(\varepsilon-\varepsilon^{\prime})^{2}}{2r^{2}\|\widetilde{f}\|^{2}_{1}}\right).

(3.14)

Furthermore note that by Cauchy Schwarz inequality and the assumption that
\|g\|_{2}\leq 1
we have

\displaystyle\left|\int_{\Omega}f(\lambda)g(\lambda)d\mu(\lambda)-\int_{\Omega}\widetilde{f}(\lambda)g(\lambda)d\mu(\lambda)\right|\leq\|f-\widetilde{f}\|_{2}\leq\varepsilon^{\prime}.

Hence, we see that for
\delta>0
a total number of

\displaystyle N=2\left(\frac{r\|\widetilde{f}\|_{1}}{\varepsilon-\varepsilon^{\prime}}\right)^{2}\log\left(\frac{1}{\delta}\right)

samples suffices to have with probability greater than
1-\delta
:

\displaystyle\left|\,\overline{X}-\int_{\Omega}\widetilde{f}(\lambda)g(\lambda)d\mu(\lambda)\right|

\displaystyle\leq\varepsilon-\varepsilon^{\prime}\;\;\text{and}\;\;\left|\int_{\Omega}f(\lambda)g(\lambda)d\mu(\lambda)-\int_{\Omega}\widetilde{f}(\lambda)g(\lambda)d\mu(\lambda)\right|\leq\varepsilon^{\prime}

and thus, by the triangle inequality,
give a good approximation of the desired overlap as

\displaystyle\left|\int_{\Omega}f(\lambda)g(\lambda)d\mu(\lambda)-\overline{X}\right|

\displaystyle\leq\left|\int_{\Omega}f(\lambda)g(\lambda)d\mu(\lambda)-\int_{\Omega}\widetilde{f}(\lambda)g(\lambda)d\mu(\lambda)\right|+\left|\,\overline{X}-\int_{\Omega}\widetilde{f}(\lambda)g(\lambda)d\mu(\lambda)\right|

\displaystyle\leq\varepsilon^{\prime}+\varepsilon-\varepsilon^{\prime}=\varepsilon.

Since
\varepsilon^{\prime}\in[0,\varepsilon)
and
\widetilde{f}
under the constraint above were arbitrary, this shows (
3.5
).

3.2
Proof of the lower bound on the sample complexity
N_{\varepsilon,\delta}(f,\mathcal{S})

Here, we prove the lower bound on the sample complexity of black box overlap estimation given in Theorem
3.3
. The first part given in (
3.7
) follows by some information theoretic argument in which we show hardness of the estimation task by embedding the problem of distinguishing two hypotheses. For the second part in (
3.8
) showing the lower bound for the choice
\mathcal{S}\equiv\mathcal{S}_{\max}=B^{2}_{1}(0)\cap B^{\infty}_{r}(0),
we use the established (
3.7
) together with a specific test function
g\in\mathcal{S}_{\max},
whose existence is provided in Lemma
3.5
below.
We first state and prove this lemma and then continue to give the proof of Theorem
3.3
.

Lemma 3.5

Let
f\in L^{2}(\Omega,\mathbbm{R})
and
\varepsilon\in(0,\|f\|_{2}).
Then there exists
g\in L^{2}(\Omega,\mathbbm{R})\cap L^{\infty}(\Omega,\mathbbm{R})
such that the following three points hold:

1.

\int_{\Omega}f(\lambda)g(\lambda)d\mu(\lambda)\geq\varepsilon,

2.

\|g\|_{2}\leq 1,

3.

\|g\|_{\infty}\leq\frac{\varepsilon}{\|f\|^{(\varepsilon)}_{1}}.

Remark 3.6

In the context of Sections
4
and
5
below we consider the specific choices of
\mathcal{S}
being either the set of Wigner functions or characteristic functions for valid quantum states on
L^{2}(\mathbbm{R}^{m})
or
(\mathbb{C})^{\otimes n}
respectively. There, the considered
f
is a Wigner or characteristic function of some pure state
\rho.
However, the function
g
constructed in Lemma
3.5
does in general not correspond the Wigner or characteristic function of some state
\sigma.
Hence, in the context of fidelity estimation for continuous or discrete variable systems of Sections
4
and
5
, we cannot use the lemma above to establish the corresponding the lower bound (
3.8
) when
\sigma
is assumed to be a valid state.

Proof of Lemma
3.5
.

In the following we explicitly construct a function
\widetilde{f}\in L^{1}(\Omega,\mathbbm{R})\cap L^{2}(\Omega,\mathbbm{R})
with

\|f-\widetilde{f}\|_{2}\leq\varepsilon

(3.15)

and furthermore
g\in L^{2}(\Omega,\mathbbm{R})\cap L^{\infty}(\Omega,\mathbbm{R})
satisfying points
1
and
2
and furthermore

\displaystyle\|g\|_{\infty}\leq\frac{\varepsilon}{\|\widetilde{f}\|_{1}}\leq\frac{\varepsilon}{\|f\|^{(\varepsilon)}_{1}}\,,

where the last inequality followed by the definition of the smoothed
L^{1}
-norm in (
2.2
).

For that, note first of all that by the dominated convergence theorem we have

\lim_{c\to 0}\int_{\{|f|<c\}}|f(\lambda)|^{2}d\mu(\lambda)=0
and hence we can define

\displaystyle c_{\star}=\sup\left\{c\in[0,\infty]\,\Big|\,\int_{\{|f|<c\}}|f(\lambda)|^{2}d\mu(\lambda)\leq\varepsilon^{2}\right\}>0.

Note that since
\varepsilon<\|f\|_{2}
we have
c_{\star}<\infty.

Furthermore, since for all
\lambda\in\Omega
we have
\lim_{c\uparrow c_{\star}}|f(\lambda)|^{2}\mathbf{1}_{\{|f|<c\}}(\lambda)=|f(\lambda)|^{2}\mathbf{1}_{\{|f|<c_{\star}\}}(\lambda),
we have again by the dominated convergence theorem

\displaystyle\int_{\{|f|<\,c_{\star}\}}|f(\lambda)|^{2}d\mu(\lambda)=\lim_{c\uparrow c_{\star}}\int_{\{|f|<\,c\}}|f(\lambda)|^{2}d\mu(\lambda)\leq\varepsilon^{2}.

(3.16)

Therefore, we can define

\displaystyle\widetilde{f}=f\,\mathbf{1}_{\{|f|\geq c_{\star}\}}\neq 0

(3.17)

which by (
3.16
) approximates
f
in
L^{2}
-norm, i.e. satisfies (
3.15
). Note that by definition we have that
\widetilde{f}\in L^{1}(\Omega,\mathbbm{R})
as

\displaystyle\|\widetilde{f}\|_{1}=\int_{\{|f|\geq c_{\star}\}}|f(\lambda)|d\mu(\lambda)\leq\frac{1}{c_{\star}}\int_{\{|f|\geq c_{\star}\}}|f(\lambda)|^{2}d\mu(\lambda)\leq\frac{\|f\|^{2}_{2}}{c_{\star}}.

We define the function
g
differently depending on whether
c_{\star}<\frac{\varepsilon^{2}}{\|\widetilde{f}\|_{1}}
and
c_{\star}\geq\frac{\varepsilon^{2}}{\|\widetilde{f}\|_{1}}.
In the first case
c_{\star}<\frac{\varepsilon^{2}}{\|\widetilde{f}\|_{1}},
we define

\displaystyle h=f\,\mathbf{1}_{\left\{|f|\,<\,\frac{\varepsilon^{2}}{\|\widetilde{f}\|_{1}}\right\}}

and the normalised function
g=h/\|h\|_{2}.
By definition of
c_{\star}
and using
\frac{\varepsilon^{2}}{\|\widetilde{f}\|_{1}}>c_{\star}
we have

\displaystyle\|h\|_{2}=\sqrt{\int_{\left\{|f|\,<\,\frac{\varepsilon^{2}}{\|\widetilde{f}\|_{1}}\right\}}|f(\lambda)|^{2}\,d\mu(\lambda)}>\varepsilon

(3.18)

and hence

\displaystyle\|g\|_{\infty}=\frac{1}{\|h\|_{2}}\left\||f|\,\mathbf{1}_{\left\{|f|\,<\,\frac{\varepsilon^{2}}{\|\widetilde{f}\|_{1}}\right\}}\right\|_{\infty}\leq\frac{\varepsilon}{\|\widetilde{f}\|_{1}}.

Furthermore, using (
3.18
) again we see

\displaystyle\int_{\Omega}f(\lambda)g(\lambda)d\mu(\lambda)=\sqrt{\int_{\left\{|f|\,<\,\frac{\varepsilon^{2}}{\|\widetilde{f}\|_{1}}\right\}}|f(\lambda)|^{2}d\mu(\lambda)}\geq\varepsilon.

Therefore, the function
g
satisfies the points
1
-
3
.

On the other hand, in the case
c_{\star}\geq\frac{\varepsilon^{2}}{\|\widetilde{f}\|_{1}}
define

\displaystyle g=\frac{\varepsilon}{\|\widetilde{f}\|_{1}}\,\operatorname{sgn}(f)\,\mathbf{1}_{\{|f|\geq c_{\star}\}}.

Clearly, we have
\|g\|_{\infty}\leq\frac{\varepsilon}{\|\widetilde{f}\|_{1}}
and furthermore by definition of
\widetilde{f}
in (
3.17
)

\displaystyle\int_{\Omega}f(\lambda)g(\lambda)d\mu(\lambda)=\frac{\varepsilon}{\|\widetilde{f}\|_{1}}\int_{\{|f|\geq c_{\star}\}}|f(\lambda)|d\mu(\lambda)=\varepsilon.

Lastly, we have using
c_{\star}\geq\frac{\varepsilon^{2}}{\|\widetilde{f}\|_{1}}
that also

\displaystyle\|g\|^{2}_{2}=\frac{\varepsilon^{2}}{\|\widetilde{f}\|^{2}_{1}}\,\mu\left(\left\{|f|\geq c_{\star}\right\}\right)\leq\frac{\varepsilon^{2}}{\|\widetilde{f}\|^{2}_{1}\,c_{\star}}\int_{\{|f|\geq c_{\star}\}}|f(\lambda)|d\mu(\lambda)=\frac{\varepsilon^{2}}{\|\widetilde{f}\|_{1}\,c_{\star}}\leq 1

and hence, also in this case, the defined function
g
satisfies the points
1
-
3
.

Proof of Theorem
3.3
.

Let
g_{1},g_{2}\in\mathcal{S}
such that

\displaystyle\left|\int_{\Omega}f(\lambda)\left(g_{1}(\lambda)-g_{2}(\lambda)\right)d\mu(\lambda)\right|>2\varepsilon.

(3.19)

If such functions do not exist, (
3.7
) is trivially satisfied.
Consider for
i=1,2
and
\lambda\in\Omega
the random variable
Y^{(i)}_{\lambda}
with outcome space
\{r,-r\},
with
r>0
being the number which was fixed at the beginning of Section
3
, and distributed according to

\displaystyle\mathbb{P}\left(Y^{(i)}_{\lambda}=r\right)=\frac{1+g_{i}(\lambda)/r}{2},\quad\quad\mathbb{P}\left(Y^{(i)}_{\lambda}=-r\right)=\frac{1-g_{i}(\lambda)/r}{2}.

(3.20)

Note, both pairs
(g_{1},(Y^{(1)}_{\lambda})_{\lambda\in\Omega})
and
(g_{2},(Y^{(2)}_{\lambda})_{\lambda\in\Omega})
satisfy the assumption (
3.1
).
We consider two situations:

\mathcal{H}_{1}:

The tester has black box access to
g_{1}
through the random variable
Y^{(1)}_{\lambda},

\mathcal{H}_{2}:

The tester has black box access to
g_{2}
through the random variable
Y^{(2)}_{\lambda}.

Hence, if

\displaystyle\Big(g,\left(Y_{\lambda}\right)_{\lambda\in\Omega}\Big)\in\left\{\left(g_{1},\left(Y^{(1)}_{\lambda}\right)_{\lambda\in\Omega}\right)\,,\,\left(g_{2},\left(Y^{(2)}_{\lambda}\right)_{\lambda\in\Omega}\right)\right\},

and using (
3.19
) a black box overlap estimation algorithm with success probability
1-\delta
can find which pair is present only by estimating the overlap
\int_{\Omega}f(\lambda)g(\lambda)d\mu(\lambda)
up to additive error
\varepsilon
. Let
N
be a sufficient number of steps for this test and let
\lambda_{1},\dots,\lambda_{N}\in\Omega
be the points the tester chooses to sample the random variable
Y_{\lambda}
. Let
y_{\lambda_{1}},\dots,y_{\lambda_{N}}\in\{r,-r\}
be the corresponding obtained samples. As explained around (
3.3
), we allow for the algorithm to be adaptive, i.e. at each step
t
the variable
\lambda_{t}
can depend on the previous points
\lambda_{1},\dots,\lambda_{t-1},
outcomes
y_{\lambda_{1}},\dots,y_{\lambda_{t-1}}
as well as on the function
f,
i.e.

\displaystyle\lambda_{t}\equiv\lambda_{t}(f,\lambda_{1},y_{\lambda_{1}},\dots,\lambda_{t-1},y_{\lambda_{t-1}}).

We denote
Z_{t}=(\lambda_{t},Y_{\lambda_{t}})
and let
\mathbb{P}_{\mathcal{H}_{1}}^{Z_{1},\dots,Z_{N}}
be the distribution of
Z_{1},\dots,Z_{N}
under
\mathcal{H}_{1}
and
\mathbb{P}_{\mathcal{H}_{2}}^{Z_{1},\dots,Z_{N}}
the law of
Z_{1},\dots,Z_{N}
under
\mathcal{H}_{2}
. Let
\mathcal{E}
be the event that the tester returns the first hypothesis. We have by the data processing inequality of the KL divergence:

\displaystyle\KL\left(\mathbb{P}_{\mathcal{H}_{1}}^{Z_{1},\dots,Z_{N}}\Big\|\mathbb{P}_{\mathcal{H}_{2}}^{Z_{1},\dots,Z_{N}}\right)

\displaystyle\geq\KL\left(\mathbb{P}_{\mathcal{H}_{1}}(\mathcal{E})\big\|\mathbb{P}_{\mathcal{H}_{2}}(\mathcal{E})\right)

\displaystyle\geq\KL\left(1-\delta\big\|\delta\right)

\displaystyle\geq\log\left(\frac{1}{3\delta}\right).

(3.21)

On the other hand, we have using the notation
\bm{Z}_{<t}=(Z_{1},\dots,Z_{t-1})
for
t\in[N]
that

\displaystyle\KL\left(\mathbb{P}_{\mathcal{H}_{1}}^{Z_{1},\dots,Z_{N}}\Big\|\mathbb{P}_{\mathcal{H}_{2}}^{Z_{1},\dots,Z_{N}}\right)

\displaystyle\overset{(a)}{=}\sum_{t=1}^{N}\mathbb{E}_{\bm{Z}_{<t}\sim\mathbb{P}_{\mathcal{H}_{1}}}\left[\KL\left(\mathbb{P}_{\mathcal{H}_{1}}^{Z_{t}|\bm{Z}_{<t}}\Big\|\mathbb{P}_{\mathcal{H}_{2}}^{Z_{t}|\bm{Z}_{<t}}\right)\right]

\displaystyle\overset{(b)}{=}\sum_{t=1}^{N}\mathbb{E}_{(\lambda_{t},\bm{Z}_{<t})\sim\mathbb{P}_{\mathcal{H}_{1}}}\left[\KL\left(\mathbb{P}_{\mathcal{H}_{1}}^{Y_{\lambda_{t}}|(\lambda_{t},\bm{Z}_{<t})}\Big\|\mathbb{P}_{\mathcal{H}_{2}}^{Y_{\lambda_{t}}|(\lambda_{t},\bm{Z}_{<t})}\right)\right]

\displaystyle\overset{(c)}{\leq}\sum_{t=1}^{N}\mathbb{E}_{(\lambda_{t},\bm{Z}_{<t})\sim\mathbb{P}_{\mathcal{H}_{1}}}\left[\chi^{2}\left(\mathbb{P}_{\mathcal{H}_{1}}^{Y_{\lambda_{t}}|(\lambda_{t},\bm{Z}_{<t})}\Big\|\mathbb{P}_{\mathcal{H}_{2}}^{Y_{\lambda_{t}}|(\lambda_{t},\bm{Z}_{<t})}\right)\right]

\displaystyle\overset{(d)}{=}\sum_{t=1}^{N}\mathbb{E}_{(\lambda_{t},\bm{Z}_{<t})\sim\mathbb{P}_{\mathcal{H}_{1}}}\left[\frac{1}{2}\left(\frac{\left(1+g_{1}(\lambda_{t})/r\right)^{2}}{1+g_{2}(\lambda_{t})/r}+\frac{\left(1-g_{1}(\lambda_{t})/r\right)^{2}}{1-g_{2}(\lambda_{t})/r}\right)-1\right]

\displaystyle=\sum_{t=1}^{N}\mathbb{E}_{(\lambda_{t},\bm{Z}_{<t})\sim\mathbb{P}_{\mathcal{H}_{1}}}\left[\frac{\left(g_{1}(\lambda_{t})-g_{2}(\lambda_{t})\right)^{2}}{r^{2}-g^{2}_{2}(\lambda_{t})}\right]

\displaystyle\leq N\,\left\|\frac{\left(g_{1}-g_{2}\right)^{2}}{r^{2}-g^{2}_{2}}\right\|_{\infty},

(3.22)

where in
(a)
, we have used the chain rule of the KL divergence; in
(b)
, we have used that the distribution of
\lambda_{t}
conditioned on
\mathbf{Z}_{<t}
does not depend on
\mathcal{H}_{1}
or
\mathcal{H}_{2}
combined again with the chain rule; in
(c)
, we have used the well known inequality
\KL\leq\chi^{2}
(c.f. (
2.4
)); in
(d)
we have used the definition of
Y_{\lambda}
(c.f. (
3.20
)) and the definition of the
\chi^{2}
-divergence (c.f. (
2.3
)).

Therefore, combining both inequalities (
3.21
) and (
3.22
), we obtain

\displaystyle\log\left(\frac{1}{3\delta}\right)\leq\KL\left(\mathbb{P}_{\mathcal{H}_{1}}^{Z_{1},\dots,Z_{N}}\Big\|\mathbb{P}_{\mathcal{H}_{2}}^{Z_{1},\dots,Z_{N}}\right)\leq N\,\left\|\frac{\left(g_{1}-g_{2}\right)^{2}}{r^{2}-g^{2}_{2}}\right\|_{\infty}

hence

\displaystyle N\geq\left\|\frac{\left(g_{1}-g_{2}\right)^{2}}{r^{2}-g^{2}_{2}}\right\|^{-1}_{\infty}\log\left(\frac{1}{3\delta}\right).

Since
g_{1},g_{2}\in\mathcal{S}
under the constraint (
3.19
) were arbitrary this shows (
3.7
).

To prove (
3.8
) in the case of
\mathcal{S}=\mathcal{S}_{\max}=B^{2}_{1}(0)\cap B^{\infty}_{r}(0)
and
f\in\mathcal{S}_{\max}
with
\|f\|_{2}=1,
we first use that since
g_{2}=0\in\mathcal{S}_{\max}
we can conclude from (
3.7
) that

\displaystyle N_{\varepsilon,\delta}(f,\mathcal{S}_{\max})\geq\sup_{\begin{subarray}{c}g\in\mathcal{S}_{\max},\\
\left|\int\!fg\right|\,>\,2\varepsilon\end{subarray}}\,\frac{r^{2}}{\|g\|^{2}_{\infty}}\log\left(\frac{1}{3\delta}\right).

Furthermore, we can, without loss of generality, restrict to
2\varepsilon<\|f\|_{2}=1
as otherwise
\|f\|^{(2\varepsilon)}_{1}=0
and hence (
3.8
) is trivially satisfied.

Under this constraint, we want to show

\displaystyle\sup_{\begin{subarray}{c}\,g\in\mathcal{S}_{\max},\\
\left|\int\!fg\right|\,>\,2\varepsilon\end{subarray}}\,\frac{1}{\|g\|^{2}_{\infty}}=\sup_{\begin{subarray}{c}g\in\mathcal{S}_{\max},\\
\left|\int\!fg\right|\,\geq\,2\varepsilon\end{subarray}}\,\frac{1}{\|g\|^{2}_{\infty}}.

(3.23)

Note that the left hand side of (
3.23
) is clearly less or equal than the right hand side, so we only need to show the opposite inequality.
Let
(\varepsilon_{n})_{n\in\mathbb{N}}\subseteq(0,\infty)
be a sequence such that
\varepsilon_{n}>\varepsilon
and
\lim_{n\to\infty}\varepsilon_{n}=\varepsilon.
Define furthermore

\displaystyle\kappa_{n}=\frac{2(\varepsilon_{n}-\varepsilon)}{1-2\varepsilon}

(3.24)

which for
n\in\mathbb{N}
large enough satisfies
\kappa_{n}\in(0,1]
and to which we shall restrict in the following. Let
g\in\mathcal{S}_{\max}
such that
\left|\int_{\Omega}f(\lambda)g(\lambda)d\mu(\lambda)\right|\geq 2\varepsilon
and define

\displaystyle g_{n}=(1-\kappa_{n})g+\kappa_{n}\operatorname{sgn}\left(\int_{\Omega}f(\lambda)g(\lambda)d\mu(\lambda)\right)f

(3.25)

Note first of all that since
f,g\in\mathcal{S}_{\max}=B^{2}_{1}(0)\cap B^{\infty}_{r}(0)
we also have by triangle inequality that
g_{n}\in\mathcal{S}_{\max}.
Moreover, we have

\displaystyle\left|\int_{\Omega}f(\lambda)g_{n}(\lambda)d\mu(\lambda)\right|=(1-\kappa_{n})\left|\int_{\Omega}f(\lambda)g(\lambda)d\mu(\lambda)\right|+\kappa_{n}\geq 2\varepsilon_{n}>2\varepsilon.

Since, we also have

\displaystyle\|g_{n}\|_{\infty}\leq(1-\kappa_{n})\|g\|_{\infty}+\kappa_{n}\|f\|_{\infty}\xrightarrow[n\to\infty]{}\|g\|_{\infty},

this shows (
3.23
).

To conclude (
3.8
) note that we can restrict to
\delta\leq 1/3
as otherwise (
3.8
) is trivially satisfied. For the case
\frac{2\varepsilon}{\|f\|^{(2\varepsilon)}_{1}}>r
the statement follows by simply lower bounding the supremum in (
3.23
) by choosing the feasible function
g=f
. On the other hand, for the case
\frac{2\varepsilon}{\|f\|^{(2\varepsilon)}_{1}}\leq r
, we can employ Lemma
3.5
and use the function
g
(with
parameter
2\varepsilon
) from there as a feasible function which gives

\displaystyle N_{\varepsilon,\delta}(f,\mathcal{S}_{\max})\geq\sup_{\begin{subarray}{c}g\in\mathcal{S}_{\max},\\
\left|\int\!fg\right|\,\geq\,2\varepsilon\end{subarray}}\,\frac{r^{2}}{\|g\|^{2}_{\infty}}\log\left(\frac{1}{3\delta}\right)\geq\left(\frac{r\|f\|^{(2\varepsilon)}_{1}}{2\varepsilon}\right)^{2}\log\left(\frac{1}{3\delta}\right)

and finishes the proof.

4
Fidelity estimation of continuous variable systems

In this section we consider for
m\in\mathbb{N}
an
m
-mode harmonic oscilator on the Hilbert space
\mathcal{H}=L^{2}(\mathbbm{R}^{m}).
We study the task of estimating the fidelity between a desired pure state
\rho
on
L^{2}(\mathbbm{R}^{m}),
of which we have a theoretical description, and a general state
\sigma,
which is prepared experimentally, by performing measurements on
\sigma.

Since
\rho
is a pure state, we can write the fidelity by (
2.10
) as

\displaystyle F(\rho,\sigma)=\pi^{m}\int_{\mathbb{C}^{m}}W_{\rho}(\alpha)W_{\sigma}(\alpha)d\alpha

(4.1)

Assume that we are able to perform measurements of the displaced parity operator

\left(2/\pi\right)^{m}D(\alpha)\Pi D(\alpha)
with outcomes in
\{(2/\pi)^{m},-(2/\pi)^{m}\}
on the state
\sigma
for chosen values of
\alpha\in\mathbb{C}^{m}
. Here, the values of
\alpha
can be chosen adaptively and hence depend on the previous values and corresponding measurement outcomes. In the following we refer to this model as the
Wigner model of fidelity estimation.

For this model,

4.1
Matching upper and lower bounds for
N^{\scalebox{0.65}{$W$}}_{\varepsilon,\delta}(\rho)
for examples of states

In this section we discuss two examples of families of states
for which the upper and lower bounds on

provided in Theorem

and Theorem

match. In particular we give a full characterisation of the sample complexity of fidelity estimation in the Wigner model for

1.

the Fock states
\left(|n\rangle\!\langle n|\right)_{n\in\mathbb{N}}
corresponding to the eigenstates of the (1-mode) harmonic oscilator,

2.

which we define in Section

3.

in terms of the

-norms of the corresponding Wigner functions.

In the case of the Fock states the key insight is that the corresponding Wigner functions can explicitly be expressed in terms of Laguerre polynomials, c.f. (
4.16
) below.
Combining this with the results on the asymptotic behaviour of the Laguerre polynomials in
[

,
Sze75
,
Mar82
,

]
, we show in Proposition

that the upper bound in Theorem

and the first lower bound in Theorem

match, giving that

\displaystyle N^{\scalebox{0.65}{$W$}}_{\varepsilon,\delta}(|n\rangle\!\langle n|)=\Theta\left(\Bigg(\frac{\left\|W_{|n\rangle\!\langle n|}\right\|_{1}}{\varepsilon}\Bigg)^{2}\log\left(\frac{1}{\delta}\right)\right)=\Theta\left(\frac{n}{\varepsilon^{2}}\log\left(\frac{1}{\delta}\right)\right).

The spike states on the other hand are a sequence of pure states
\left(\rho_{n}\right)_{n\in\mathbb{N}}
on
L^{2}(\mathbbm{R}^{m})
constructed in such a way, that their Wigner functions uniformly vanish as

\displaystyle\|W_{\rho_{n}}\|_{\infty}\xrightarrow[n\to\infty]{}0.

-norms, i.e.

\displaystyle\|W_{\rho_{n}}\|_{1}\sim\|W_{\rho_{n}}\|^{-1}_{\infty}.

and the second lower bound in Theorem

\displaystyle N^{\scalebox{0.65}{$W$}}_{\varepsilon,\delta}(\rho_{n})=\Theta\left(\Bigg(\frac{\left\|W_{\rho_{n}}\right\|_{1}}{\varepsilon}\Bigg)^{2}\log\left(\frac{1}{\delta}\right)\right).

(4.11)

We believe the existence of such a sequence of pure states satisfying (

) and (

) to be potentially of independent interest.

Lastly, for Gaussian states

the

-norm of the corresponding Wigner function is by the normalisation (

Combining this with the lower bound provided in Theorem

As a consequence of these results we find the following worst case characterisation of the sample complexity of fidelity estimation in the Wigner model:

Theorem 4.4
(Sample complexity of fidelity estimation in Wigner model in worst case)

Let
0<\varepsilon<1/2
and
0<\delta<1/4
. Then we have for all

\displaystyle\sup_{\begin{subarray}{c}\rho\text{ pure state,}\\
\|W_{\rho}\|_{1}\leq t\end{subarray}}N^{\scalebox{0.65}{$W$}}_{\varepsilon,\delta}(\rho)=\Theta\left(\left(\frac{t}{\varepsilon}\right)^{2}\log\left(\frac{1}{\delta}\right)\right),

In particular, this shows that in worst case over all pure states

\displaystyle\sup_{\rho\text{ pure state}}N^{\scalebox{0.65}{$W$}}_{\varepsilon,\delta}(\rho)=\infty.

(4.14)

which gives for
|\alpha|>1,

\displaystyle e^{-|\alpha|^{2}/2}L_{n}(|\alpha|^{2})=\mathcal{O}\left(n^{-1/4}\right)

and hence using again (
4.18
)

\displaystyle 1-r^{-2}W^{2}_{|n\rangle\!\langle n|}(\alpha/2)\geq c

for
n
large enough and some
c>0.

Hence, combining this again with (
4.26
) we see

\displaystyle\sup_{|\alpha|>1}\frac{\left(W_{|n+2\rangle\!\langle n+2|}(\alpha/2)-W_{|n\rangle\!\langle n|}(\alpha/2)\right)^{2}}{r^{2}-W^{2}_{|n\rangle\!\langle n|}(\alpha/2)}\lesssim\frac{1}{n}

(4.29)

Therefore, combining (
4.25
),
(
4.28
) and (
4.29
) we see

\displaystyle\left\|\frac{\left(W_{|n+2\rangle\!\langle n+2|}-W_{|n\rangle\!\langle n|}\right)^{2}}{r^{2}-W^{2}_{|n\rangle\!\langle n|}}\right\|_{\infty}\lesssim\frac{1}{n}

and therefore, from (
4.21
)

\displaystyle N^{\scalebox{0.65}{$W$}}_{\varepsilon,\delta}(|n\rangle\!\langle n|)\gtrsim\frac{n}{\varepsilon^{2}}\log\left(\frac{1}{3\delta}\right).

which together with the established (
4.20
) finishes the proof.

4.1.2
Sample complexity for spike states

In this section we define the
spike states
and analyse the scaling behaviour of the
L^{1}
-  and
L^{\infty}
-norms of their Wigner functions.
In particular for every number of modes
m\in\mathbb{N}
the spike states are a sequence of pure states
\left(\rho_{n}\right)_{n\in\mathbb{N}}=\left(|\psi_{n}\rangle\!\langle\psi_{n}|\right)_{n\in\mathbb{N}}
on
L^{2}(\mathbbm{R}^{m})
whose Wigner functions satisfy

\displaystyle\|W_{\rho_{n}}\|_{\infty}\xrightarrow[n\to\infty]{}0

(4.30)

Here, the idea of the construction is to pick wave functions
\psi_{n}
with increasing uncertainty in both position and momentum which then leads to a further and further spreaded out Wigner function. We pick such wave functions by super positioning ‘spikes’ in position space, which each have a high momentum uncertainty. In the particular construction of Lemma
4.7
these ‘spikes’ are simply given by Gaussian functions. Super-positioning now sufficiently many at increasing distance also leads to high position uncertainty and to a point wise uniformly vanishing Wigner function.

More precisely, the spike states are defined as follows: Let
\phi\in L^{2}(\mathbbm{R}^{m})
be the normalised (within
L^{2}(\mathbbm{R}^{m})
, i.e.
\|\phi\|_{2}=1
) Gaussian function centered at the origin, i.e. for
x\in\mathbbm{R}^{m}

\displaystyle\phi(x)=\left(\frac{2}{\pi}\right)^{m/4}\,e^{-x^{2}}.

(4.31)

Consider for
n\in\mathbb{N}
the wave function defined for
x\in\mathbbm{R}^{m}
by

\displaystyle\psi_{n}(x)=\frac{1}{\sqrt{c_{n}}}\sum_{k=1}^{n}\phi(x-\mu_{k}),

(4.32)

with

\displaystyle\mu_{k}=n\,3^{k}e_{1},

(4.33)

and
e_{1}=(1,0,\cdots,0)\in\mathbbm{R}^{m}
and where we drop the
n
dependence for brevity. Furthermore,
c_{n}
being the normalisation constant such that
\|\psi_{n}\|_{2}=1
which in particular satisfies

\displaystyle c_{n}=\sum_{k,l=1}^{n}\int_{\mathbbm{R}^{m}}\phi(x-\mu_{k})\phi(x-\mu_{l})dx\geq\sum_{k=1}^{n}\int_{\mathbbm{R}^{m}}|\phi(x-\mu_{k})|^{2}dx=n.

(4.34)

The
n^{th}

spike state
is defined to be the corresponding pure state
\rho_{n}=|\psi_{n}\rangle\!\langle\psi_{n}|.

The particular spreading of the spikes parameterised by the
\mu_{k}
in (
4.33
) is chosen in such a way that for every fixed point in phase space essentially at most only two spikes contribute to the Wigner function in the formula (
2.8
) (see the proof of Lemma
4.7
for more details).

Notably, we provide control of the speed of convergence for the limit (
4.30
) and also on the blow up of the corresponding
L^{1}
-norms. In particular, we see that the the sequence of pure states satisfies

\displaystyle\|W_{\rho_{n}}\|^{-1}_{\infty}\sim\|W_{\rho_{n}}\|_{1}

(c.f. Remark
4.8
). This is then used as key insight for proving the worst case characterisation (
4.13
) of the sample complexity in Theorem
4.2
.

In the following lemma we provide the precise scaling behaviour of the
L^{1}
- and
L^{\infty}
-norms of the spike states.

Lemma 4.7
(Asymptotic behaviour of spike states)

The pure states
\left(\rho_{n}\right)_{n\in\mathbb{N}}=\left(|\psi_{n}\rangle\!\langle\psi_{n}|\right)_{n\in\mathbb{N}}
on
L^{2}(\mathbbm{R}^{m})
defined by (
4.32
) have Wigner functions satisfying
W_{\rho_{n}}\in L^{1}(\mathbb{C}^{m})
and

\displaystyle\|W_{\rho_{n}}\|_{\infty}\leq 4\left(\frac{2}{\pi}\right)^{m}\frac{1}{n}\quad\text{ and }\quad\|W_{\rho_{n}}\|_{1}\leq\,n.

(4.35)

Moreover, the corresponding sequence
\left(\psi_{n}\right)_{n\in\mathbb{N}}
converges weakly to
0
in
L^{2}(\mathbbm{R}^{m}),
i.e. for all
\varphi\in L^{2}(\mathbbm{R}^{m})
we have

\displaystyle\lim_{n\to\infty}\langle\varphi,\psi_{n}\rangle=0.

(4.36)

Remark 4.8

Note that the
n
-dependence in of the bounds (
4.35
) is tight. This can be seen by using that since
\rho_{n}
is pure we have
\|W_{\rho_{n}}\|^{2}_{2}=\pi^{-m}
by (
2.11
) and hence

\displaystyle\|W_{\rho_{n}}\|^{-1}_{\infty}\leq\pi^{m}\|W_{\rho_{n}}\|_{1}.

Using this and the established bounds in (
4.35
) shows

\displaystyle\|W_{\rho_{n}}\|_{\infty}\sim\frac{1}{n}\quad\text{ and }\quad\|W_{\rho_{n}}\|_{1}\sim n

(4.37)

Before giving the proof of Lemma
4.7
, we show how we can use it to obtain a characterisation of the sample complexity
N^{\scalebox{0.65}{$W$}}_{\varepsilon,\delta}(\rho_{n})
from the upper bound and lower bounds in Theorems
4.1
and
4.2
:

Proposition 4.9
(Sample complexity for spike states)

Let
0<\varepsilon<1/2,

0<\delta<1/4
and
\left(\rho_{n}\right)_{n\in\mathbb{N}}=\left(|\psi_{n}\rangle\!\langle\psi_{n}|\right)_{n\in\mathbb{N}}
be the spike states defined in (
4.32
). Then we have the following characterisation of the corresponding sample complexity of fidelity estimation in the Wigner model:

\displaystyle N^{\scalebox{0.65}{$W$}}_{\varepsilon,\delta}\left(\rho_{n}\right)=\Theta\left(\Bigg(\frac{\left\|W_{\rho_{n}}\right\|_{1}}{\varepsilon}\Bigg)^{2}\log\left(\frac{1}{\delta}\right)\right),

where the constants in the
\Theta(\,\cdot\,)
can be
m
-dependent.

Proof.
By the upper bound provided in Theorem
4.1
we immediately see

\displaystyle N^{\scalebox{0.65}{$W$}}_{\varepsilon,\delta}(\rho_{n})\leq 2^{2m+1}\left(\frac{\|W_{\rho_{n}}\|_{1}}{\varepsilon}\right)^{2}\log\left(\frac{1}{\delta}\right)\leq 2^{2m+1}\left(\frac{n}{\varepsilon}\right)^{2}\log\left(\frac{1}{\delta}\right),

where for the second inequality we have used Lemma
4.7
.

To prove the corresponding lower bound we take
n^{\prime}=\left\lceil{n/\varepsilon}\right\rceil
and state
\sigma_{n}=2\varepsilon\rho_{n}+(1-2\varepsilon)\rho_{n^{\prime}},
which satisfies
F(\rho_{n},\sigma_{n})\geq 2\varepsilon.

Furthermore, we have by Lemma
4.7
that

\displaystyle\|W_{\sigma_{n}}\|_{\infty}\leq 2\varepsilon\|W_{\rho_{n}}\|_{\infty}+(1-2\varepsilon)\|W_{\rho_{n^{\prime}}}\|_{\infty}\leq 16\left(\frac{2}{\pi}\right)^{m}\frac{\varepsilon}{n}.

Therefore, using the second lower bound in Theorem
4.2
we see that

\displaystyle N^{\scalebox{0.65}{$W$}}_{\varepsilon,\delta}(\rho_{n})\geq\left(\frac{2}{\pi}\right)^{2m}\,\frac{1}{\|W_{\sigma_{n}}\|^{2}_{\infty}}\log\left(\frac{1}{3\delta}\right)\geq\frac{1}{16}\left(\frac{n}{\varepsilon}\right)^{2}\log\left(\frac{1}{3\delta}\right)

which finishes the proof.

Proof of Lemma
4.7
.

We proof the result with phase space being parametrised with position and momentum variables
(x,p)\in\mathbbm{R}^{2m}
which corresponds to the change of coordinates given by
\alpha=\frac{1}{\sqrt{2}}\left(x+ip\right).

Using (
2.8
) and the explicit form of the wave functions in (
4.32
), we can calculate the Wigner function of
\rho_{n}
at phase space point
(x,p)\in\mathbbm{R}^{2m}
by

\displaystyle W_{\rho_{n}}(x,p)=\frac{1}{c_{n}}\left(\frac{2}{\pi}\right)^{3m/2}\sum_{k,l=1}^{n}\int_{\mathbbm{R}^{m}}e^{-(x-\mu_{k}+y)^{2}-(x-\mu_{l}-y)^{2}}\,e^{i2p\cdot y}\,dy

\displaystyle=\frac{1}{c_{n}}\left(\frac{2}{\pi}\right)^{3m/2}\sum_{k,l=1}^{n}e^{-(x-\mu_{k})^{2}-(x-\mu_{l})^{2}+\frac{(\mu_{k}-\mu_{l})^{2}}{2}}\int_{\mathbbm{R}^{m}}e^{-2(y-(\mu_{k}-\mu_{l})/2)^{2}}e^{i2p\cdot y}dy

\displaystyle=\frac{1}{c_{n}}\left(\frac{2}{\pi}\right)^{m}\sum_{k,l=1}^{n}e^{-2\big(x-(\mu_{k}+\mu_{l})/2\big)^{2}}\ e^{ip\cdot(\mu_{k}-\mu_{l})-p^{2}/2},

(4.38)

where for the last line the standard relation for Fourier transforming a Gaussian function (see e.g.
[
Tes14
, Lemma 7.3]
).

Note that because of the specific choice of
\mu_{k}
in (
4.33
), we have for
x\in\mathbbm{R}^{m}
fixed that there exists at most one
(k_{x},l_{x})\in\mathbb{N}^{2}
with
k_{x}\geq l_{x}
such that for the euclidean norm we have

\displaystyle\left\|x-\frac{\mu_{k_{x}}+\mu_{l_{x}}}{2}\right\|\leq\frac{n}{2},

(4.39)

which can be seen by the following argument: Assume for contradiction that there exists
(k,l)\neq(i,j)
with
k\geq l
and
i\geq j
and such that
\|x-(\mu_{k}+\mu_{l})/2\|\leq n/2
and
\|x-(\mu_{i}+\mu_{j})/2\|\leq n/2.
This hence gives

\displaystyle\big\|\mu_{k}+\mu_{l}-\mu_{i}-\mu_{j}\big\|=n\left|3^{k}+3^{l}-3^{i}-3^{j}\right|\leq 2n

(4.40)

Without loss of generality we can assume that
i>k
as for
k=i
we immediately also have
l=j
from (
4.40
).
Using
k\geq l
this gives

\displaystyle 3^{i}+3^{j}\geq 3^{i}\geq 3^{k+1}\geq 3^{k}+3^{l}+3,

which contradicts (
4.40
) and hence proves the desired claim.

Using hence for
(x,p)\in\mathbbm{R}^{2m}
the uniqueness of
(k_{x},l_{x})\in\mathbb{N}^{2}
with
k_{x}\geq l_{x}
and satisfying (
4.39
) and plugging this into (
4.38
) gives together with (
4.34
)

\displaystyle|W_{\rho_{n}}(x,p)|

\displaystyle\leq\frac{1}{n}\left(\frac{2}{\pi}\right)^{m}\sum_{k,l=1}^{n}e^{-2\big(x-(\mu_{k}+\mu_{l})/2\big)^{2}}

\displaystyle\leq\frac{2}{n}\left(\frac{2}{\pi}\right)^{m}\left(e^{-2\big(x-(\mu_{k_{x}}+\mu_{l_{x}})/2\big)^{2}}+\sum_{\begin{subarray}{c}k,l=1\\
k\geq l,(k,l)\neq(k_{x},l_{x})\end{subarray}}^{n}e^{-2\big(x-(\mu_{k}+\mu_{l})/2\big)^{2}}\right)

\displaystyle\leq\frac{2}{n}\left(\frac{2}{\pi}\right)^{m}\left(1+n^{2}e^{-n^{2}/2}\right)\leq\frac{4}{n}\left(\frac{2}{\pi}\right)^{m},

where we used
t^{2}e^{-t^{2}/2}\leq 1
for all
t\in\mathbbm{R}
and which hence shows the
L^{\infty}
-bound in (
4.35
).

On the other hand, using again the explicit form of the Wigner function of
\rho_{n}
in (
4.38
), we see

\displaystyle\|W_{\rho_{n}}\|_{1}

\displaystyle=\int_{\mathbb{C}^{m}}|W_{\rho}(\alpha)|d\alpha=2^{-m}\int_{\mathbbm{R}^{2m}}|W_{\rho}(x,p)|dxdp

\displaystyle\leq\frac{1}{n\pi^{m}}\sum_{k,l=1}^{n}\int_{\mathbbm{R}^{2m}}e^{-2\big(x-(\mu_{k}+\mu_{l})/2\big)^{2}}\ e^{-p^{2}/2}dxdp

\displaystyle=\frac{n}{\pi^{m}}\int_{\mathbbm{R}^{2m}}e^{-x^{2}}e^{-p^{2}}dxdp=n.

Lastly we want to show the weak convergence of the sequence
\left(\psi_{n}\right)_{n\in\mathbb{N}}
to
0,
i.e. (
4.36
). For that let
\varphi\in L^{2}(\mathbbm{R})
and
\varepsilon>0
and pick
R\geq 0
such that

\displaystyle\int_{\|x\|>R}|\varphi(x)|^{2}dx<\varepsilon,

which is possible due to the dominated convergence theorem. Furthermore, note that we have for the Gaussian function
\phi
defined in (
4.31
),
k\in[n]
and
n3^{k}\geq R

\displaystyle\int_{\|x\|\leq R}|\phi(x-\mu_{k})|^{2}dx\leq\sqrt{\frac{2}{\pi}}\int_{-R}^{R}e^{-2(x_{1}-n3^{k})^{2}}dx_{1}\leq\sqrt{\frac{2}{\pi}}\int_{-R+n3^{k}}^{\infty}e^{-2x_{1}^{2}}dx_{1}\leq e^{-2(n3^{k}-R)^{2}}

where the first inequality follows by definition of
\mu_{k}
in (
4.33
) and second inequality follows by standard Gaussian tail bounds.
Hence, using the Cauchy Schwarz inequality and the fact that
\psi_{n}
is normalised in
L^{2}
, we see for
n
large enough

\displaystyle\left|\langle\varphi,\psi_{n}\rangle\right|

\displaystyle\leq\sqrt{\int_{\|x\|>R}|\varphi(x)|^{2}dx}\ +\ \frac{\|\varphi\|_{2}}{\sqrt{c_{n}}}\sum_{k=1}^{n}\sqrt{\int_{\|x\|\leq R}|\phi(x-\mu_{k})|^{2}dx}

\displaystyle\leq\sqrt{\varepsilon}\ +\ \frac{\|\varphi\|_{2}}{\sqrt{c_{n}}}\sum_{k=1}^{n}e^{-(n3^{k}-R)^{2}}\xrightarrow[n\to\infty]{}\sqrt{\varepsilon}.

Since,
\varepsilon>0
was arbitrary, this shows (
4.36
).

5
Fidelity estimation for discrete variable systems

We consider for
n\in\mathbb{N}
an
n
-qubit quantum system on the Hilbert space
\mathcal{H}=\left(\mathbb{C}^{2}\right)^{\otimes n}
with dimension
d=2^{n}.
The corresponding set of Pauli strings is denoted by
\mathcal{P}_{n}=\{\mathbbm{1},X,Y,Z\}^{\otimes n}.

Note that
\mathcal{P}_{n}
forms an orthogonal basis on the space of operators on
\left(\mathbb{C}^{2}\right)^{\otimes n}
and we have for all
P,Q\in\mathcal{P}_{n}

\displaystyle\frac{1}{d}\mathrm{Tr}(PQ)=\delta_{PQ}.

(5.1)

For
\rho
a state on
\left(\mathbb{C}^{2}\right)^{\otimes n}
we can define its
characteristic function
as

\displaystyle\chi_{\rho}:\mathcal{P}_{n}

\displaystyle\to[-1,1]

\displaystyle P

\displaystyle\mapsto\mathrm{Tr}(P\rho).

In the following we consider the task of estimating the fidelity between a desired
n
-qubit pure state
\rho,
of which we have a theoretical description, and a general state
\sigma,
which we prepared experimentally, by performing measurements on
\sigma.
Since
\rho
is a pure state, we can write the fidelity by using (
5.1
) as

\displaystyle F(\rho,\sigma)=\frac{1}{d}\sum_{P\in\mathcal{P}_{n}}\chi_{\rho}(P)\chi_{\sigma}(P)=\frac{1}{d}+\sum_{P\in\mathcal{P}_{n}\setminus\{\mathbbm{1}\}}\chi_{\rho}(P)\chi_{\sigma}(P)

(5.2)

Assume that we are able to measure any observable
P\in\mathcal{P}_{n}
with outcome in
\{1,-1\}
on the state
\sigma
. Here, the observables
P
can be chosen adaptively and hence depend on the previous ones and their corresponding measurement outcomes.
Since
\chi_{\sigma}(\mathbbm{1})=1
we can restrict to Pauli measurements with
P\in\mathcal{P}_{n}\setminus\{\mathbbm{1}\}
as for
P=\mathbbm{1}
a tester does not gain any information.
In the following we refer to this model as the
Pauli-parity model of fidelity estimation.

For this model,
\varepsilon>0
and
\delta>0
being the allowed additive error and probability of failure respectively and pure state
\rho
fixed, which we call the
instanced based setup,
we denote the
sample complexity of fidelity estimation in the Pauli-parity model
by
N^{\scalebox{0.65}{$P$}}_{\varepsilon,\delta}(\rho)
: That is
N^{\scalebox{0.65}{$P$}}_{\varepsilon,\delta}(\rho)
is the optimal number of measurements on different copies of the unknown state
\sigma
needed to estimate
F(\rho,\sigma)
in the worst case over all states
\sigma.

Due to the definition of the characteristic function
\chi_{\sigma}
, the assumption that we are able to perform measurements of the observables
P\in\mathcal{P}_{n}
on
\sigma
exactly means that we have black box access to the
\chi_{\sigma}.
Hence, estimating the fidelity (
5.2
) in this setup becomes special instance of black box overlap estimation as discussed in Section
3
: In particular we can make the identifications

\displaystyle\Omega

\displaystyle\mapsto\mathcal{P}_{n}\setminus\{\mathbbm{1}\}

\displaystyle\text{and }\quad d\mu(\lambda)\mapsto\frac{1}{d}d\mu_{\text{count}}(P)\text{ with $\mu_{\text{count}}$ being the counting measure on $\mathcal{P}_{n}\setminus\{\mathbbm{1}\}$}

\displaystyle r

\displaystyle\mapsto 1

\displaystyle f(\lambda)

\displaystyle\mapsto\chi_{\rho}(P)

to which we have full access

\displaystyle g(\lambda)

\displaystyle\mapsto\chi_{\sigma}(P)

to which we have black box access

\displaystyle Y_{\lambda}

\displaystyle\mapsto Y_{P}

measurement outcome of observable
P\in\mathcal{P}_{n}\setminus\{\mathbbm{1}\}
on state
\sigma.

(5.3)

In particular this leads to the following convention of
L^{q}
-norms for
q\in[1,\infty)

\displaystyle\|\chi_{\sigma}\|_{q}:=\left(\frac{1}{d}\sum_{P\in\mathcal{P}_{n}\setminus\{\mathbbm{1}\}}|\chi_{\rho}(P)|^{q}\right)^{1/q}.

(5.4)

and

\displaystyle\|\chi_{\sigma}\|_{\infty}:=\max_{P\in\mathcal{P}_{n}\setminus\{\mathbbm{1}\}}|\chi_{\rho}(P)|.

(5.5)

With these definition we have
\|\chi_{\sigma}\|_{2}=\sqrt{\mathrm{Tr}(\sigma^{2})-1/d}\leq 1
and hence by the Cauchy-Schwarz inequality

\displaystyle\|\chi_{\rho}\|_{1}=\frac{1}{d}\sum_{P\in\mathcal{P}_{n}\setminus\{\mathbbm{1}\}}|\chi_{\rho}(P)|\leq\sqrt{d}\|\chi_{\rho}\|_{2}\leq\sqrt{d}.

(5.6)

For the subset
\mathcal{S}
employed in Section
3
, we are interested here in the particular choice
\mathcal{S}_{P}
consisting of all characteristic functions
\chi_{\sigma}
for valid states
\sigma.
We see that
\mathcal{S}_{P}\subseteq B^{2}_{1}(0)\cap B^{\infty}_{1}(0).

With the notation above, the sample complexity of fidelity estimation can be written as

\displaystyle N^{\scalebox{0.65}{$P$}}_{\varepsilon,\delta}(\rho)\equiv N_{\varepsilon,\delta}(\chi_{\rho},\mathcal{S}_{P})

(5.7)

with
N_{\varepsilon,\delta}(\chi_{\rho},\mathcal{S}_{P})
being defined in Section
3
.

Formulating the achievability result Theorem
3.1
for this special case leads to the following theorem:

Theorem 5.1
(Upper bound on fidelity estimation with Pauli measurements)

Let
\rho
be a pure state on
\left(\mathbb{C}^{2}\right)^{\otimes n}
to which we have a theoretical description. Then, for any state
\sigma,
we can estimate the fidelity
F(\rho,\sigma)
with precision
\varepsilon>0
and failure probability at most

by performing Pauli measurements on a number of

N^{\scalebox{0.65}{$P$}}_{\varepsilon,\delta}(\rho)\leq 2\inf_{\varepsilon^{\prime}\in[0,\varepsilon)}\left(\frac{\|\chi_{\rho}\|^{(\varepsilon^{\prime})}_{1}}{\varepsilon-\varepsilon^{\prime}}\right)^{2}\log\left(\frac{1}{\delta}\right)

(5.8)

copies of the state
\sigma.
Furthermore, the upper bound holds true even when restricting to non-adaptive algorithms.

Remark 5.2
(Worst case bound)

Using (
5.6
), we see that the sample complexity in the Pauli model satisfies for all pure states
\rho

\displaystyle N^{\scalebox{0.65}{$P$}}_{\varepsilon,\delta}(\rho)=\mathcal{O}\left(\frac{d}{\varepsilon^{2}}\log\left(\frac{1}{\delta}\right)\right).

(5.9)

As we see below, this worst case bound is essentially tight as Theorems

and

show a lower bound on the sample complexity for random Haar states which matches with high probability (

) up to factors logarithmic in the dimension

. Furthermore, we believe that this tightness result can be strengthened by not relying on a randomised argument but, possibly inspired by the construction of the spike states in Section

, finding explicit examples of states for which the lower bound in Theorem

below can be shown to match (
5.9
) up to constants which are independent of the system size. We, however, leave this as an open problem.

Furthermore, from the lower bound on the sample complexity of black box estimation in Theorem
3.3
, we find the corresponding lower bound on

Theorem 5.3
(Lower bound on fidelity estimation with Pauli measurements)

Let
\rho
be a pure state on
\left(\mathbb{C}^{2}\right)^{\otimes n}
to which we have a theoretical description. Then for
0<\varepsilon<1/2
and
0<\delta\leq 1/3
we have the that the sample complexity of fidelity estimation in the Wigner model is lower bounded as

\displaystyle N^{\scalebox{0.65}{$P$}}_{\varepsilon,\delta}(\rho)

\displaystyle\geq\sup_{\begin{subarray}{c}\sigma_{1},\sigma_{2}\text{ state,}\\
|F(\rho,\sigma_{1})-F(\rho,\sigma_{2})|\,>\,2\varepsilon\end{subarray}}\left\|\frac{\left(\chi_{\sigma_{1}}-\chi_{\sigma_{2}}\right)^{2}}{1-\chi^{2}_{\sigma_{2}}}\right\|^{-1}_{\infty}\log\left(\frac{1}{3\delta}\right)

\displaystyle\geq\sup_{\begin{subarray}{c}\sigma\text{ state,}\\
|F(\rho,\sigma)-1/d|\,>\,2\varepsilon\end{subarray}}\,\frac{1}{\|\chi_{\sigma}\|^{2}_{\infty}}\log\left(\frac{1}{3\delta}\right).

(5.10)

Proof.
The first inequality immediately follows from Theorem
3.3
. For the second we use the first with the choice
\sigma_{2}=\mathbbm{1}/d
which satisfies
\chi_{\sigma_{2}}=0
on
\mathcal{P}_{n}\setminus\{\mathbbm{1}\}
and
F(\rho,\sigma_{2})=1/d.

Remark 5.4
(Matching upper and lower bound for small
\varepsilon
)

Inspired from the construction in Lemma
3.5
consider for some pure state
\rho
and
\varepsilon>0
the operator

\omega=\frac{1}{d}\left(\mathbbm{1}+\frac{3\varepsilon}{\|\chi_{\rho}\|_{1}}\sum_{P\in\mathbf{P}_{n}\setminus\{\mathbbm{1}\}}\operatorname{sgn}(\chi_{\rho}(P))P\right)

which has characteristic function
\chi_{\omega}(P)=\mathrm{Tr}(P\omega)=\frac{3\varepsilon}{\|\chi_{\rho}\|_{1}}\operatorname{sgn}(\chi_{\rho}(P))

for all
P\in\mathcal{P}_{n}\setminus\{\mathbbm{1}\}.
This operator
\omega
has normalised trace but is in general not positive semi-definite and hence not a state (c.f. Remark
3.6
) unless
\varepsilon>0
is small enough. In particular, a naive operator norm bound shows that
\omega
is in fact positive semi-definite if

Whenever
\omega
is a state we can combine (

) with the argument in Lemma

to show the instanced based lower bound on the sample complexity of fidelity estimation in the Pauli model

N^{\scalebox{0.65}{$P$}}_{\varepsilon,\delta}(\rho)\geq\left(\frac{\|\chi_{\rho}\|_{1}}{3\varepsilon}\right)^{2}\log\left(\frac{1}{3\delta}\right).

(5.11)

In fact note that

\displaystyle F(\rho,\omega)=\frac{1}{d}\sum_{P\in\mathcal{P}_{n}}\chi_{\rho}(P)\chi_{\omega}(P)=\frac{1}{d}\left(1+\sum_{P\in\mathcal{P}_{n}\setminus\{\mathbbm{1}\}}\frac{3\varepsilon|\chi_{\rho}(P)|}{\|\chi_{\rho}\|_{1}}\right)=\frac{1}{d}+3\varepsilon

from which we see that

is a feasible state in the second line of (

we can conclude (

Proposition 5.5

Let

be a Haar random pure state on

,
0<\varepsilon,\delta\leq 1/5

\displaystyle N^{\scalebox{0.65}{$P$}}_{\varepsilon,\delta}(\rho)=\widetilde{\Theta}\left(\left(\frac{\|\chi_{\rho}\|_{1}}{\varepsilon}\right)^{2}\log\left(\frac{1}{\delta}\right)\right)=\widetilde{\Theta}\left(\frac{d}{\varepsilon^{2}}\log\left(\frac{1}{\delta}\right)\right).

(5.14)

Here, we used

Proof.
For the upper bound we use Theorem

To prove the lower bound, we show in the following that with high probability a Haar random pure state

\displaystyle\|\chi_{\rho}\|_{\infty}\lesssim\sqrt{\frac{\log d}{d}}.

(5.15)

Let
U\in\mathbb{U}(d)
be a Haar unitary such that
|\Psi\rangle=U^{\dagger}|0\rangle
. For a fixed

\displaystyle f(U)=|\langle\Psi|P|\Psi\rangle|=|\langle 0|UPU^{\dagger}|0\rangle|.

The function

2
-Lipschitz with respect to the Frobenius norm denoted

be two unitary matrices, we have

\displaystyle|f(U)-f(V)|

\displaystyle=\left||\langle 0|UPU^{\dagger}|0\rangle|-|\langle 0|VPV^{\dagger}|0\rangle|\right|

\displaystyle\overset{(a)}{\leq}|\langle 0|(U-V)PU^{\dagger}|0\rangle|+|\langle 0|VP(U-V)^{\dagger}|0\rangle|

\displaystyle\overset{(b)}{\leq}\|P(U-V)^{\dagger}|0\rangle\|_{2}\|U^{\dagger}|0\rangle\|_{2}+\|V^{\dagger}|0\rangle\|_{2}\|P(U-V)^{\dagger}|0\rangle\|_{2}

\displaystyle\overset{(c)}{\leq}2\|P(U-V)^{\dagger}\|_{\rm{F}}=2\|U-V\|_{\rm{F}}

where

follows from the triangle inequality,
(b)
follows from the Cauchy Schwarz inequality and
(c)
uses the fact

for a pure

as well as the Frobenius norm is unitarily invariant.
So by the concentration inequality of Lipschitz functions of Haar unitaries

]

\displaystyle\mathbb{P}\left(|f(U)-\mathbb{E}(f)|\geq s\right)\leq\exp\left(-\frac{ds^{2}}{48}\right).

Moreover we have by the Cauchy Schwarz inequality

\displaystyle\mathbb{E}\left(f\right)\leq\sqrt{\mathbb{E}\left(f^{2}\right)}=\sqrt{\mathbb{E}\left(\langle\Psi|P|\Psi\rangle^{2}\right)}=\sqrt{\frac{{\rm Tr}(PP^{\dagger})+|{\rm Tr}(P)|^{2}}{d(d+1)}}=\sqrt{\frac{1}{d+1}}.

\displaystyle\mathbb{P}\left(\exists P\in\mathcal{P}_{n}\setminus\{I\}:|\langle\Psi|P|\Psi\rangle|>2\sqrt{\frac{48\log d^{3}}{d}}\right)

\displaystyle\leq\sum_{P\in\mathcal{P}_{n}\setminus\{I\}}\mathbb{P}\left(|\langle\Psi|P|\Psi\rangle|>2\sqrt{\frac{48\log d^{3}}{d}}\right)

\displaystyle\leq d^{2}\mathbb{P}\left(f(U)-\mathbb{E}(f)>2\sqrt{\frac{48\log d^{3}}{d}}-\sqrt{\frac{1}{d+1}}\right)

\displaystyle\leq d^{2}\mathbb{P}\left(f(U)-\mathbb{E}(f)>\sqrt{\frac{48\log d^{3}}{d}}\right)

\displaystyle\leq d^{2}\exp\left(-\frac{d\cdot\frac{48\log d^{3}}{d}}{48}\right)=\frac{1}{d}.

Hence, when sampling from the Haar measure, with probability at least

such that for all

\displaystyle|\langle\Psi|P|\Psi\rangle|\leq 2\sqrt{\frac{48\log d^{3}}{d}}

and therefore the corresponding pure state

satisfies (

and has characteristic function

on

Hence, this state is feasible in the optimisation in the second lower bound provided in Theorem
5.3
which gives using (

\displaystyle N^{\scalebox{0.65}{$P$}}_{\varepsilon,\delta}(\rho)\gtrsim\frac{1}{\varepsilon^{2}\|\chi_{\rho}\|^{2}_{\infty}}\log\left(\frac{1}{3\delta}\right)\gtrsim\frac{d}{\varepsilon^{2}\log d}\log\left(\frac{1}{3\delta}\right)\geq\left(\log d\right)^{-1}\left(\frac{\|\chi_{\rho}\|_{1}}{\varepsilon}\right)^{2}\log\left(\frac{1}{3\delta}\right).

(5.16)

Appendix A
Some facts about the smoothed
L^{1}
-norm

For
\Omega
a measure space with measure
\mu,
we have defined in the Section
2.2
the smoothed
L^{1}
-norm of a function
f\in L^{2}(\Omega)
as

\displaystyle\|f\|^{(\varepsilon)}_{1}=\inf_{\begin{subarray}{c}\widetilde{f}\in L^{1}(\Omega)\\
\|f-\widetilde{f}\|_{2}\leq\varepsilon\end{subarray}}\|\widetilde{f}\|_{1}.

(A.1)

Different from the scope of the rest of the paper, in which we restricted to real valued functions, we allow in this section for real or complex valued functions. Hence, for simplicity, we write as
L^{q}(\Omega)
as the corresponding
L^{q}
-spaces without denoting the field over which the considered functions are taking values.

The following lemma establishes that in the limit
\varepsilon\to 0
the smoothed
L^{1}
-norm converges to the usual (non-smoothed)
L^{1}
-norm.

Lemma A.1

For all
f\in L^{2}(\Omega)
we have

\displaystyle\lim_{\varepsilon\downarrow 0}\|f\|^{(\varepsilon)}_{1}=\|f\|_{1},

(A.2)

where the right hand side is understood as infinity if
f\notin L^{1}(\Omega).

Proof.
We use the relation for a measurable function
f

\displaystyle\int_{\Omega}|f(\lambda)|d\mu(\lambda)=\sup_{\begin{subarray}{c}\Omega_{0}\subseteq\Omega\\
\mu(\Omega_{0})<\infty\end{subarray}}\int_{\Omega_{0}}|f(\lambda)|d\mu(\lambda),

(A.3)

which follows directly from the definition of the Lebesgue integral.

First we consider the case
f\in L^{1}(\Omega)
: Let
\delta>0.
Using (
A.3
) we can pick a set of finite measure
\Omega_{0}\subseteq\Omega
such that

\displaystyle\int_{\Omega^{c}_{0}}|f(\lambda)|d\mu(\lambda)\leq\frac{\delta}{2}.

Let
\varepsilon\in(0,\frac{\delta}{2\sqrt{\mu(\Omega_{0}})})
and
\tilde{f}\in L^{1}(\Omega)\cap L^{2}(\Omega)
be such that
\|f-\tilde{f}\|_{2}\leq\varepsilon.
Then

\displaystyle\|f\|_{1}

\displaystyle\leq\int_{\Omega_{0}}|f(\lambda)-\tilde{f}(\lambda)|d\mu(\lambda)+\int_{\Omega_{0}}|\tilde{f}(\lambda)|d\mu(\lambda)+\int_{\Omega^{c}_{0}}|f(\lambda)|d\mu(\lambda)

\displaystyle\leq\int_{\Omega_{0}}|f(\lambda)-\tilde{f}(\lambda)|d\mu(\lambda)+\|\tilde{f}\|_{1}+\frac{\delta}{2}.

For the first term we use the Cauchy-Schwarz ineqality which gives

\displaystyle\int_{\Omega_{0}}|f(\lambda)-\tilde{f}(\lambda)|d\mu(\lambda)\leq\|f-\tilde{f}\|_{2}\sqrt{\mu(\Omega_{0})}\leq\frac{\delta}{2}.

Plugging this into the above and using that
\tilde{f}
was arbitrary under the constraints above gives

\displaystyle\|f\|^{\varepsilon}_{1}\geq\|f\|_{1}-\delta.

Noting that the opposite inequality
\|f\|^{(\varepsilon)}_{1}\leq\|f\|_{1}
is trivially true and using that
\delta>0
was arbitrary, shows
\lim_{\varepsilon\downarrow 0}\|f\|^{(\varepsilon)}_{1}=\|f\|_{1}
.

To finish the proof we consider the case
f\notin L^{1}(\Omega).
We have to show
\liminf_{\varepsilon\downarrow 0}\|f\|^{(\varepsilon)}_{1}=\infty.
Assume for contradiction that there exists
C>0
such that for all
\varepsilon>0
we have the uniform bound

\displaystyle\|f\|^{(\varepsilon)}_{1}\leq C.

Let
\Omega_{0}\subseteq\Omega
be a set of finite measure. Note by similar arguments as above, it holds true that
\|f\mathbf{1}_{\Omega_{0}}\|^{(\varepsilon)}_{1}\leq\|f\|^{(\varepsilon)}_{1}\leq C
for all
\varepsilon>0.
Hence, using the established (
A.2
) for the function
f\mathbf{1}_{\Omega_{0}}\in L^{1}(\Omega),
we see

\displaystyle\int_{\Omega_{0}}|f|d\mu(\lambda)=\lim_{\varepsilon\downarrow 0}\|f\mathbf{1}_{\Omega_{0}}\|^{(\varepsilon)}_{1}\leq C.

But using that
\Omega_{0}
was an arbitrary set of finite measure together with (
A.3
) shows that
f\in L^{1}(\Omega),
which gives a contradiction and finishes the proof.

in terms of the Laguerre polynomials as

\displaystyle W_{|n\rangle\!\langle n|}(\alpha)=(-1)^{n}\left(\frac{2}{\pi}\right)e^{-2|\alpha|^{2}}L_{n}(4|\alpha|^{2}).

Using the asymptotic expressions for the Laguerre polynomials in
[
AW65
]
, we see that

\displaystyle W_{|n\rangle\!\langle n|}(\alpha)\leq c\,e^{-t|\alpha|^{2}}

for all
|\alpha|\geq s\sqrt{n}
for some
s,c,t>0
independent of
n.
Therefore, by the discussion around (
A.9
) we see that
W_{|n\rangle\!\langle n|}
has a rapidly decaying tail of order
(\gamma,\kappa_{c,\gamma,t})
outside of
\Omega_{0}=B_{s\sqrt{n}}(0)\subset\mathbb{C}
for all
\gamma\in(0,1).
Here,
\kappa_{c,\gamma,s}>0
depends linearly on
c
and is independent of
n.
Noting that the volume of
\Omega_{0}
is of order
n,
we see from Lemma
A.2

that

\displaystyle\left\|W_{|n\rangle\!\langle n|}\right\|_{1}-\left\|W_{|n\rangle\!\langle n|}\right\|^{(\varepsilon)}_{1}\lesssim\varepsilon^{\beta}+\sqrt{n}\varepsilon\lesssim\sqrt{n}\,\varepsilon^{\beta},

where
\beta=\tfrac{\gamma}{\gamma+1}\in(0,1/2)
and we are hiding all constants which are independent of
n
and
\varepsilon
in the
\lesssim
-notation.
Using the fact that
\|W_{|n\rangle\!\langle n|}\|_{1}\sim\sqrt{n}
as noted in (
4.19
) as a consequence of
[
Mar82
, Lemma 1]
, finishes the proof.
