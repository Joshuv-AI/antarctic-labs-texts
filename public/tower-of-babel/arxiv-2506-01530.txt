Solutions of Problem

\Adj(A):=\{\alpha\in\Pi_{+}\ |\ \exists\beta\in\Pi_{+}:\ \alpha\leq\beta\}.

(2.1)

Definition 2.1
.

The
\nu
-sequence
of an element

\{\nu^{k}(u)\}_{k\geq 0}
of subsets of
\Pi_{+}
defined as

\nu^{0}(u):=u(\Pi_{+})\cap\Pi_{+},\ \ \nu^{k}(u):=u(\Adj\nu^{k-1}(u))\cap\Pi_{+},\ \ k\geq 1.

(2.2)

In Proposition
3.2
, we show that the sequence
\{\nu^{k}(u)\}_{k\geq 0}
is descending and stabilizes after a finite number of terms. Thus we can make sense of the limit

\nu(u):=\lim_{k\rightarrow\infty}\nu^{k}(u);

(2.3)

that is, if
\nu^{m}(u)=\nu^{m+1}(u)=\cdots
for some
m\geq 1
, then
\nu(u)=\nu^{m}(u)
.

Definition 2.2
.

The
rationality graph

\Gamma(u)
of an element
u\in W
is an oriented graph constructed as follows:

•

The vertex set of
\Gamma(u)
is given by the set
\nu^{0}(u)

•

Two roots
\alpha,\beta\in\nu^{0}(u)
are connected by an edge
\alpha\rightarrow\beta
if and only if
u^{-1}(\alpha)\leq\beta
.

Definition 2.3
.

An element

is called

if one of the following equivalent conditions is satisfied:

i)

The set
\nu(u)
is empty;

ii)

The graph
\Gamma(u)
has no cycles.

We prove the equivalence of the above conditions in Proposition
3.3
. In Proposition
3.5
we show that
\Gamma(u)
contains a loop if and only if
\alpha\leq u(\alpha)
for some
\alpha\in\Pi_{+}
. As a consequence, a rational element does not fix any root. Another consequence is that if the highest root is a vertex of
\Gamma(u)
, then
u
is not rational (see Proposition
3.4
).

Theorem 2.4
.

For any rational element
u\in W
and its representative
\overline{u}\in N_{G}(\mathcal{H})
, there exist rational maps
B:G\dashrightarrow\mathcal{B}_{+}
and
N:G\dashrightarrow\mathcal{N}_{-}
such that for a generic
g\in G

g=N(g)B(g)\overline{u}N(g)^{-1}.

(2.4)

Conversely, if
u\in W
is any element with
\ell(u)\geq\ell(w_{0})-2
and the decomposition (
2.4
) exists for a generic

and some rational maps

and

, then
u
is rational.

In other words, any rational element
u\in W
is a solution of Problem
1.1
, and conversely, any solution
u
of Problem
1.1
with

is rational. We conjecture that the solutions of Problem

are precisely the rational Weyl group elements.

\nu

3.1

In this subsection, for a given

Lemma 3.1
.

For any
k\geq 0
, a root
\alpha\in\nu^{0}(u)
belongs to
\nu^{k}(u)
if and only if there is a path in
\Gamma(u)
of length
k
that starts at
\alpha
.

Note that we allow loops in
\Gamma(u)
, so a path can traverse the same vertex multiple times.

Proof.

Let us prove the statement by induction. For
k=0
, the vertex set of
\Gamma(u)
is the same as the set of paths of length
0
, and it is equal to
\nu^{0}(u)
. Assume that the statement holds for
k-1
,
k\geq 1
. By equation (
2.2
), a root
\alpha\in\nu^{0}(u)
belongs to
\nu^{k}(u)
if and only if there is a root
\beta\in\nu^{k-1}(u)
such that
u^{-1}(\alpha)\leq\beta
; that is, there is an arrow
\alpha\rightarrow\beta
in the graph
\Gamma(u)
. But then, there is a path of length
k-1
that starts at
\beta
; thus, there is a path of length
k
that starts at
\alpha
.
∎

Proposition 3.2
.

The sequence
\{\nu^{k}(u)\}_{k\geq 0}
is descending and stabilizes after a finite number of terms.

Proof.

By Lemma
3.1
, a root
\alpha\in\nu^{0}(u)
belongs to
\nu^{k}(u)
if and only if there is a path of length
k
that starts at
\alpha
; hence, if
k\geq 1
and
\alpha\in\nu^{k}(u)
, there is also a path of length
k-1
that starts at
\alpha
, and thus
\alpha\in\nu^{k-1}(u)
. Since the elements of the sequence are subsets of a finite set, and since the sequence is descending, it stabilizes after a finite number of terms.
∎

The result of Proposition

allows us to define

\nu(u):=\lim_{k\rightarrow\infty}\nu^{k}(u).

(3.1)

As a consequence, the set
\nu(u)
satisfies the following equation:

\nu(u)=u(\Adj\nu(u))\cap\Pi_{+}.

(3.2)

The following result shows that the two definitions of rationality of an element

).

Proposition 3.3
.

A positive root
\alpha
belongs to
\nu(u)
if and only if there is a cycle in
\Gamma(u)
that passes through
\alpha
. In particular, the graph
\Gamma(u)
contains a cycle if and only if

is nonempty.

Proof.

If
\nu(u)
is nonempty, we can find paths in

has a finite number of vertices and is oriented, it contains a cycle. Conversely, if

∎

Proposition 3.4
.

Let

be the highest root. If

is not rational.

Proof.

Indeed, if

\Gamma(u)
at

∎

Proposition 3.5
.

The graph

For the next subsections, we set up notation and review some background on Lie theory.

Gaussian decomposition.

For a generic
g\in G
, we denote by
g_{-}\in\mathcal{N}_{-}
and

the unique elements such that

. For any

,
n_{-}\in\mathcal{N}_{-}
and
n_{+}\in\mathcal{N}_{+}
, the Gaussian decomposition has the following properties:

\displaystyle(n_{-}g)_{-}=n_{-}g_{-},

\displaystyle(gan_{+})_{-}=g_{-},

\displaystyle(ag)_{-}=ag_{-}a^{-1};

(3.17)

\displaystyle(n_{-}g)_{\oplus}=g_{\oplus},

\displaystyle(gan_{+})_{\oplus}=g_{\oplus}an_{+},

\displaystyle(ag)_{\oplus}=ag_{\oplus}.

(3.18)

We use these properties routinely in Section
3.4
.

Cartan integers.

We use the following convention on Cartan integers
a_{ij}
:

a_{ij}:=\langle\alpha_{j},\alpha_{i}^{\vee}\rangle=2\frac{\langle\alpha_{j},\alpha_{i}\rangle}{\langle\alpha_{i},\alpha_{i}\rangle}.

(3.19)

In this convention, the simple reflections act on simple roots as

s_{i}(\alpha_{j})=\alpha_{j}-a_{ij}\alpha_{i}.

(3.20)

Chevalley generators.

Let
\{(e_{i},h_{i},f_{i})\}_{i=1}^{r}

and

,

. We complement the Chevalley generators to a basis of

. Define the following

:

\displaystyle x_{\beta}:=\exp(te_{\beta}),\ \ t\in\mathbb{C};

(3.21)

\displaystyle x_{i}:=x_{\alpha_{i}},\ \ y_{i}:=x_{-\alpha_{i}},\ \ i\in\{1,\ldots,r\}.

(3.22)

For each
i\in\{1,\ldots,r\}
, define a group homomorphism
\phi_{i}:\SL_{2}(\mathbb{C})\rightarrow G
via

\phi_{i}\begin{bmatrix}1&t\\
0&1\end{bmatrix}:=x_{i}(t),\ \ \phi_{i}\begin{bmatrix}1&0\\
t&1\end{bmatrix}:=y_{i}(t).

(3.23)

Define the element

via

t^{h_{i}}:=\phi_{i}\begin{bmatrix}t&0\\
0&t^{-1}\end{bmatrix}

(3.24)

The group versions

and

if

\displaystyle x_{i}(t_{1})x_{j}(t_{2})=x_{j}(t_{2})x_{i}(t_{1});

\displaystyle y_{i}(t_{1})y_{j}(t_{2})=y_{j}(t_{2})y_{i}(t_{1});

\displaystyle y_{i}(t_{1})y_{j}(t_{2})y_{i}(t_{3})=y_{j}\left(\frac{t_{2}t_{3}}{t_{1}+t_{3}}\right)y_{i}(t_{1}+t_{3})y_{j}\left(\frac{t_{1}t_{2}}{t_{1}+t_{3}}\right).

(3.30)

For any
\alpha_{i}\in\Delta

\displaystyle ax_{i}(t)=x_{i}(a^{\alpha_{i}}t)a;

\displaystyle ay_{i}(t)=y_{i}(a^{-\alpha_{i}}t)a.

For a simple reflection
