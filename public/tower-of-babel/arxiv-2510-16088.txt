Differentiable, Bit-shifting, and Scalable Quantization without training neural network from scratch
zia badar

Abstract
Quantization of neural networks provides benefits of inference in less compute and memory requirements. Previous work in quantization lack two important aspects which this work provides. First almost all previous work in quantization used a non-differentiable approach and for learning; the derivative is usually set manually in backpropogation which make the learning ability of algorithm questionable, our approach is not just differentiable, we also provide proof of convergence of our approach to the optimal neural network. Second previous work in shift/logrithmic quantization either have avoided activation quantization along with weight quantization or achieved less accuracy. Learning logrithmic quantize values of form 2 n 2^{n} requires the quantization function can scale to more than 1 bit quantization which is another benifit of our quantization that it provides n n bits quantization as well. Our approach when tested with image classification task using imagenet dataset, resnet18 and weight quantization only achieves less than 1 percent accuracy compared to full precision accuracy while taking only 15 epochs to train using shift bit quantization and achieves comparable to SOTA approaches accuracy in both weight and activation quantization using shift bit quantization in 15 training epochs with slightly higher(only higher cpu instructions) inference cost compared to 1 bit quantization(without logrithmic quantization) and not requiring any higher precision multiplication. code: https://github.com/zia-badar/DBSSQ

Introduction

Quantization of neural network is the process of learning weight which can be represented in small no of bits and also converting activations into small no. of bits, So layer computation involves both quantize inputs and quantize weights, through which higher precision layer operations can be avoided. Quantization provided two main advantages during inference. First the adders and multipliers used to evaluate the network can be of lower precision since there input is of lower precision and lower precision adder and multiplier are composed of smaller no of steps compared to their full precision counter part. Second benefit of quantization is the small memory required during inference for keeping the model loaded in hardware accelerator(gpu etc) memory for faster computation otherwise the weight which are required for computation have to be loaded when needed which slows down the inference.

Quantization has already been much explored, still we found two missing element in quantization which can limit it adoption and this work contributes in these two areas. First almost all works in quantization trains neural network from scratch without attempting to convert an already trained full precision network into a quantize one, because of this the compute cost spend to trained a large neural network has to be spend again to get a quantize equivalent. In this work, quantization is refered as the normal
q
bit quantization and shift quantization is refered as
s
bit quantization where
q
quantization bits takes quantize values in
\{-2^{q-1},...,-2^{0}+1,-2^{0},2^{0},2^{0}+1,...,2^{q-1}\}
and
s
shift bits takes quantize values in
\{-2^{2^{s-1}},...,-2^{1},-2^{0},2^{0},2^{1},...,2^{2^{s-1}}\}
. Quantization function’s task is to maps its input of full precision on a quantize value. Also this work will refer to the image of quantization function on any one of its intervals of continuity union with its supremum as quantize level, quantize level is of form
(a,b]
, the union is for consistency with its implementation.

This works contributions are:

•

Provides a differentiable quantization function capable of learning quantize network with both weight and activation quantization of competative accuracy utilizing shift bits and costing only slightly higher cpu instructions compared to 1 bit quantization in approximately 15 training epochs.

•

Provides proof of convergence of our approach to the optimal neural network using assumption verified experimentally.

Problem statement

w*a\approx\alpha_{1}q(w)*\alpha_{2}q(a)=\alpha(q(w)*q(a))

(1)

Quantization of neural network refers to representing weights and/or activations in small no. of bits which leads to requirement of low precision multipliers and adders for inference, which cost less no. of steps compared to their full precision counter part. To quantize a neural network a quantization function is used which maps its full precision input to quantized output which is represented in small no. of bits. A full precision scaling factor
\alpha
is used which can be factor out of convolution and multiplication only needed to be preformed with it one time on convolution output, this scaling factor is learned exclusively for each convolution in network. After training, the quantization function only need to evaluted on weights once but as activations are only known at inference time the quantization function on activations have to be evaluted during inference which requires the quantization function cost should be less then the cost saving by avoiding full precision operations. Other requirements of quantization function are it should be differentiable or its derivation can be manually set in backpropogation.

Related Work

Binary neural network
(
Courbariaux & Bengio 2016
)
trains convolution neural network with sign function as the quantization function for both weight and activation. They set the derivative of loss w.r.t to sign function’s input as the same derivative of loss w.r.t to sign function’s output and set it zero when input is large. XNOR
(
Rastegari et al. 2016
)
introduced two networks; binary weight network with only weights quantization and XNOR network with both weight and activation quantization. For weight only, weight and activation quantization they solved a weight reconstruction problem between full precision weights and binary weight scaled by another optimization parameter. They used the same sign function differentiation approach as binary neural networks
(
Courbariaux & Bengio 2016
)
. Ternary weight network
(
Li & Liu 2016
)
uses a weight reconstruction optimization problem to quantize weights only. Although their approach is differentiable, the derivative is computed from optimization problem solution which solves for a distribution composed of 3d filter weights and not for individual weights. ABC-net
(
Lin et al. 2017
)
uses sign function as quantization function, multiple binary basis and multiple activations to increase accuracy, although they achieve higher accuracy but it is at the cost of much higher no. of parameters compared to resnet18 which they modified.
(
Miyashita et al. 2016
)
perform both weight and activation quantization but achieved less imagenet accuracy, this accuracy was improved by
(
Li et al. 2019
)
but at the cost of using higher no. of addition operation over quantized values represented as power of 2, which is equivalent to low precision multiplication. Our approach is close to IR-Net
(
DBL 2019
)
, in the sense they also use a quantization differentiable function with normalized distribution of weights and activations as input, to quantize full precision weight and activations, and differ from our approach as our quantization function supports logrithmic and scalable quantize values, donot trains network from scratch and only requires 15 epochs. Our apporach is also close to
(
Miyashita et al. 2016
)
as they also used both weight and activation quantization, but there apporach simulates multiplication through shift and addition operations.

to represent complete quantization the accuracy should drop to large margin but this does not occur implying neural network learns without exploiting
\lambda
. We provide three reason for not seeing such behaviour. First scaling factor of weights quantization is fixed which is the standard deviation of full precision which reduces distance between weights on the same quantize level with decrease in
\lambda
although still network can remain dependent on
\lambda
through representing information as small difference of values on the same quantize level. Second learning objective forces the network to learn utilizing quantize levels which contradicts with utilizing the
\lambda
slope to learn. Third the optimizer parameters like learning rate, momentum forces the optimal minima which involves exploiting
\lambda
to be never reached. One hypothetical way to exploit
\lambda
is that neural network maps for each gaussian two points at high positive and negative value which maintains the variance of gaussian, the remaining points to very small positive and negative values then using a high scaling factor
\alpha
the distance between quantized values remains maintained on the same quantize level no matter how much value of
\lambda
is reduced, although this hypothetical case causes quantize levels to also get scaled from each other.

4.8
Convergence Proof

We provide proof of convergence of our approach, during training as
\lambda
reaches value of
0
, the network function being optimized reaches the completely(
\lambda=0
) quantized optimal network function. Quantization functions previously mentioned were on unbounded domain, for the purpose of applying limit on the quantization function, this proof will assumes quantization function have bounded domain, this bounded assumption donot have any negative effect since the gaussian which is quantized using the quantization function is of finite variance.

Lemma 4.1
.

If
N_{\lambda}
be a neural network function which uses a quantization function with
\lambda
as its slope, then
\lim_{\lambda\to 0^{+}}N_{\lambda}=N_{0}
. where
N_{0}
is completely quantize network function which may or may not be optimal.

Proof.

Since
\lim_{\lambda^{{}^{\prime}}\to 0^{+}}q(\cdot;\lambda=\lambda^{{}^{\prime}})=q(\cdot;\lambda=0)
then
\lim_{\lambda\to 0^{+}}N_{\lambda}=N_{0}
.
∎

Proposition 1
.

Let
C
defines an operator, which takes nerual network function as input and output the measure of optimiality of neural network function w.r.t to some task and
N^{*}_{\lambda}
defines the optimal neural network function which implies
C[N_{a}^{*}]\leq C[N_{b}^{*}]
, when
a<b
, as
N_{b}^{*}
is more complex function than
N_{a}^{*}
due to larger parameter space, then
\lim_{\lambda\to 0^{+}}N^{*}_{\lambda}=N^{*}_{0}
. Assuming operator
C
allows limit to
0
from above to pass under it,
C[\lim_{\lambda\to 0^{+}}N^{*}_{\lambda}]=\lim_{\lambda\to 0^{+}}C[N^{*}_{\lambda}]
and
N^{*}_{0}
is unique.

Proof.

From
Lemma

4.1
it is know
\lim_{\lambda\to 0^{+}}N^{*}_{\lambda}=N_{0}
. We will proof by contradiction
N_{0}=N^{*}_{0}
. Let
N_{0}
be not optimal then
C[N^{*}_{0}]>C[N_{0}]
which implies for
\epsilon=\frac{C[N^{*}_{0}]-C[N_{0}]}{2}
their exist a
\lambda^{{}^{\prime}}
satisfying
C[N^{*}_{0}]>C[N^{*}_{\lambda}]
where
\lambda\in(0,\lambda^{{}^{\prime}})
since
C[N_{0}]=\lim_{\lambda\to 0^{+}}C[N^{*}_{\lambda}]
but
C[N^{*}_{0}]>C[N^{*}_{\lambda}]
is a contradiction as
\lambda>0
which makes
N^{*}_{\lambda}

, hence

and
N^{*}_{0}=N_{0}
by uniqueness.
∎
