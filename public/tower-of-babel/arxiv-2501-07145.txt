A User’s Guide to KSig : GPU-Accelerated Computation of the Signature Kernel
Csaba Tóth 1, Danilo Jr Dela Cruz 2, Harald Oberhauser 3

Abstract
The signature kernel is a positive definite kernel for sequential and temporal data that has become increasingly popular in machine learning applications due to powerful theoretical guarantees, strong empirical performance, and recently introduced various scalable variations. In this chapter, we give a short introduction to KSig , a Scikit-Learn compatible Python package that implements various GPU-accelerated algorithms for computing signature kernels, and performing downstream learning tasks. We also introduce a new algorithm based on tensor sketches which gives strong performance compared to existing algorithms. The package is available at https://github.com/tgcsaba/ksig .

Introduction

This paper introduces
KSig
, a
Scikit-Learn
compatible Python library that implements various GPU-accelerated signature kernel algorithms; this includes exact algorithms as well as recent scalable variations such as Random Fourier Signature Features (RFSF)
[
35
]
, to enable practical applications on modern machine learning problems involving large-scale time series datasets.

The Signature Kernel.

Let
\mathcal{X}
be the input data domain, which can be a topological space or a set, and

\displaystyle\mathrm{k}\mathrel{\mathop{\mathchar 58\relax}}\mathcal{X}\times\mathcal{X}\to\mathbb{R},

(1)

be a positive definite, symmetric kernel on
\mathcal{X}
. Throughout we refer to
\mathrm{k}
as the
static kernel
.
The kernel
\mathrm{k}
is parametrized by some hyperparameters
\theta_{\mathrm{k}}\in\Theta_{\mathrm{k}}
on
\mathcal{X}
; e.g.
\mathcal{X}=\mathbb{R}^{d}
with
\mathrm{k}
being the RBF kernel and
\theta
denoting the bandwidth, i.e.

\displaystyle\mathrm{k}(\mathbf{x},\mathbf{y})=\exp\left(\frac{\mathinner{\!\left\lVert\mathbf{x}-\mathbf{y}\right\rVert}^{2}}{2\sigma^{2}}\right)\quad\text{for }\mathbf{x},\mathbf{y}\in\mathbb{R}^{d}

(2)

where
\theta_{\mathrm{k}}=\sigma\in\Theta_{\mathrm{k}}=\mathbb{R}_{+}
is the bandwidth of the RBF kernel.

The signature kernel construction
[
14
]
turns the kernel
\mathrm{k}
on
\mathcal{X}
into a positive definite kernel
\mathrm{k}_{\mathrm{\mathsf{Sig}}}
on the set of sequences of arbitrary length in the set
\mathcal{X}
,

\displaystyle\mathcal{X}_{\text{seq}}\coloneqq\{\mathbf{x}=(\mathbf{x}_{0},\ldots,\mathbf{x}_{L})\mathrel{\mathop{\mathchar 58\relax}}L\geq 0,\,\mathbf{x}_{i}\in\mathcal{X}\},

(3)

where we use
0
-based indexing for sequences, and we denote the “effective” length of a sequence
\mathbf{x}=(\mathbf{x}_{0},\dots,\mathbf{x}_{L})\in\mathcal{X}_{\text{seq}}
by
\mathsf{L}_{\mathbf{x}}=L
.
The resulting kernel

\displaystyle\mathrm{k}_{\mathrm{\mathsf{Sig}}}\mathrel{\mathop{\mathchar 58\relax}}\mathcal{X}_{\text{seq}}\times\mathcal{X}_{\text{seq}}\to\mathbb{R},

(4)

is called the
signature kernel
and is again a positive definite kernel on
\mathcal{X}_{\text{seq}}
that has strong theoretical guarantees from stochastic analysis and scalable algorithms.
It has become increasingly popular in machine learning tasks and statistics for sequential and temporal data.
We refer to
[
16
]
for a recent survey and theoretical background.

Hyperparameters.

The signature kernel
\mathrm{k}_{\mathrm{\mathsf{Sig}}}
inherits the hyperparameter set
\Theta_{\mathrm{k}}
of the original kernel
\mathrm{k}
, but has additional hyperparameters.
The full set of hyperparameters consists of:

•

Static hyperparameters
\Theta_{\mathrm{k}}
.
These are simply the hyperparameter of static kernel
\mathrm{k}
, e.g. the bandwidth in case of the RBF kernel.

•

Truncation level

\mathbb{N}_{\infty}\coloneqq\mathbb{N}\cup\{\infty\}
. The number of iterated integrals to use. Informally, this is somewhat analogous to the degree in polynomial regression.

•

Preprocessing options

\Theta_{\text{Preprocess}}
. Time series preprocessing techniques, such as resampling, adding lagged channels, adding a time coordinate, etc.

•

Algebraic structure

\Theta_{\text{Algebra}}
. The signature kernel is an inner product of iterated integrals.
There is a classic “geometric” choice motivated from stochastic analysis how these integrals are approximated, but an insight from the machine learning application is that non-geometric approximations can often improve the complexity with no deterioration in performance or even improvements.

•

Normalization

\Theta_{\text{Normalization}}
. Normalization makes the signature kernel statistically robust and there are various possibilities.

We denote the resulting hyperparameter set of
\mathrm{k}_{\mathrm{\mathsf{Sig}}}
with

\Theta_{\mathrm{k}_{\mathrm{\mathsf{Sig}}}}\coloneqq\Theta_{\mathrm{k}}\times\mathbb{N}_{\infty}\times\Theta_{\text{Preprocess}}\times\Theta_{\text{Algebra}}\times\Theta_{\text{Normalization}}.

We emphasize that this is the full hyperparameter set and advise readers who are new or less familiar to just focus on the first two, namely
\Theta_{\mathrm{k}}
and truncation level
\mathbb{N}_{\infty}\coloneqq\mathbb{N}\bigcup\{\infty\}
.
Optimizing only these two sets of hyperparameters often already leads to good performance. We note that although doing a full grid-search for the bandwidth hyperparameter
\sigma=\theta_{\mathrm{k}}\in\Theta_{\mathrm{k}}
is recommended when using e.g. the RBF kernel (
42
), we find that sometimes the median heuristic
[
12
]
can give a reasonable baseline value when the optimization budget is limited, although there is no theory to support this in case of the signature kernel. Additionally, we find that the median heuristic can be useful for defining the grid for the bandwidth
\sigma
by parameterizing
\sigma
in terms of multiples of the value given by the median heuristic on a logarithmic grid as done in in
(
35
, Sec. 4)
.
For a hashed out example of complete hyperparameter optimization, we refer to the experimental work
[
19
]
, while we refer to
[
35
]
for a discussion of the most relevant choices that are used to achieve state-of-the-art performance on popular time series classification tasks.

Dual Signature Algorithms

In this section, we detail variations of the signature kernel based on the dual approach – that is, approaches which employ the kernel trick for computing Gram matrices.

2.1
Signature Kernels

First, we establish some terminology.
Define the collection of all (non-strictly) ordered
m
-tuples

\displaystyle\Delta_{m}(L)=\{1\leq i_{1}\leq\cdots i_{m}\leq L\,\mathrel{\mathop{\mathchar 58\relax}}\,i_{1},\dots,i_{m}\in\mathbb{Z}_{+}\},

(5)

where
m,L\in\mathbb{Z}_{+}
. Then, recall from
[
14
]
that the order-
p
and level-
m
signature kernel for
p,m\in\mathbb{Z}_{+}
between sequences
\mathbf{x},\mathbf{y}\in\mathcal{X}_{\text{seq}}
can be written as

\displaystyle\mathrm{k}_{{\mathrm{\mathsf{Sig}}_{m}}}(\mathbf{x},\mathbf{y})=\sum_{\begin{subarray}{c}\mathbf{i}\in\Delta_{m}(\mathsf{L}_{\mathbf{x}})\\
\mathbf{j}\in\Delta_{m}(\mathsf{L}_{\mathbf{y}})\end{subarray}}\frac{1}{\mathbf{i}!^{(p)}}\nabla_{i_{1},j_{1}}\mathrm{k}(\mathbf{x}_{i_{1}},\mathbf{y}_{j_{1}})\cdots\nabla_{i_{m},j_{m}}\mathrm{k}(\mathbf{x}_{i_{m}},\mathbf{y}_{j_{m}}),

(6)

where
\nabla_{i,j}\mathrm{k}(\mathbf{x}_{i},\mathbf{y}_{j})=\mathrm{k}(\mathbf{x}_{i},\mathbf{y}_{j})-\mathrm{k}(\mathbf{x}_{i-1},\mathbf{y}_{j})-\mathrm{k}(\mathbf{x}_{i},\mathbf{y}_{j-1},\mathbf{x}_{i})+\mathrm{k}(\mathbf{x}_{i-1},\mathbf{y}_{j-1})
is a double difference operator, and
\mathbf{i}!^{(p)}
is such that if there are
k\in\mathbb{Z}_{+}
distinct entries in the multi-index
\mathbf{i}
, and respectively each is repeated
p_{1},\dots,p_{k}
times, then it is

\displaystyle\mathbf{i}!^{(p)}=\begin{cases}p_{1}!\cdots p_{k}!\quad&\text{if }p_{1},\dots,p_{k}\leq p\\
0&\text{otherwise}.\end{cases}

(7)

2.2
Truncated Signature Kernels

Here, we discuss the dynamic programming based recursive algorithm proposed in
[
14
]
. This approach computes exactly the signature kernel for finite truncation-
M

\displaystyle\mathrm{k}_{\mathrm{\mathsf{Sig}}}(\mathbf{x},\mathbf{y})=\sum_{m=0}^{M}\mathrm{k}_{{\mathrm{\mathsf{Sig}}_{m}}}(\mathbf{x},\mathbf{y}).

(8)

This is performed by an efficient recursion relation across levels. For a sequence
\mathbf{x}\in\mathcal{X}_{\text{seq}}
, let
\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}k}=(\mathbf{x}_{0},\dots,\mathbf{x}_{k})
denote a slicing operation, where
k\leq\mathsf{L}_{\mathbf{x}}
. Let
\mathrm{k}_{\mathbf{x}_{i}}=\mathrm{k}(\mathbf{x}_{i},\cdot)\in\mathcal{H}_{\mathrm{k}}
denote the reproducing kernel lift of
\mathbf{x}_{i}\in\mathcal{X}
. Then, a consequence of the Chen identity for signatures
[
18
]
is that the following recursion holds for the order-
p
level-
m
(reproducing) signature kernel (
6
) across time steps for
\mathbf{x}\in\mathcal{X}_{\text{seq}}

\displaystyle\mathrm{k}_{{\mathrm{\mathsf{Sig}}_{m}}}(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}k},\cdot)=\mathrm{k}_{{\mathrm{\mathsf{Sig}}_{m}}}(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}k-1},\cdot)+\sum_{q=1}^{p}\mathrm{k}_{{\mathrm{\mathsf{Sig}}_{m-q}}}(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}k-1},\cdot)\otimes\frac{(\nabla_{k}\mathrm{k}_{x_{k}})^{\otimes q}}{q!},

(9)

and unrolling this along the sequence with respect to the first term, we get

\displaystyle\mathrm{k}_{{\mathrm{\mathsf{Sig}}_{m}}}(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}k},\cdot)=\sum_{\kappa=1}^{k}\sum_{q=1}^{p}\mathrm{k}_{{\mathrm{\mathsf{Sig}}_{m-q}}}(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}\kappa-1},\cdot)\otimes\frac{(\nabla_{\kappa}\mathrm{k}_{\mathbf{x}_{\kappa}})^{\otimes q}}{q!}.

(10)

Then, taking inner products and employing the reproducing property, we get that the order-
p
level-
m
signature kernel can be computed for
\mathbf{x},\mathbf{y}\in\mathcal{X}_{\text{seq}}

\displaystyle\mathrm{k}_{{\mathrm{\mathsf{Sig}}_{m}}}

\displaystyle(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}k},\mathbf{y}_{0\mathrel{\mathop{\mathchar 58\relax}}l})

(11)

\displaystyle=

\displaystyle\sum_{\kappa=1}^{k}\sum_{\lambda=1}^{l}\sum_{q=1}^{p}\sum_{r=1}^{p}\frac{1}{q!r!}\langle\mathrm{k}_{{\mathrm{\mathsf{Sig}}_{m-q}}}(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}\kappa-1},\cdot)\otimes(\nabla_{\kappa}\mathrm{k}_{\mathbf{x}_{\kappa}})^{\otimes q},\mathrm{k}_{{\mathrm{\mathsf{Sig}}_{m-r}}}(\mathbf{y}_{0\mathrel{\mathop{\mathchar 58\relax}}\lambda-1},\cdot)\otimes(\nabla_{\lambda}\mathrm{k}_{\mathbf{x}_{\lambda}})^{\otimes r}\rangle_{\mathcal{H}_{\mathrm{k}}^{\otimes m}}.

(12)

Although the computation of (
11
) is rather involved, note that it only depends on the signature kernel levels lower than
m
, establishing a recursion across levels that allows to iteratively compute the signature kernel up to truncation level-
M
. The algorithm derived in
(
14
, App. B)
is based on dynamic programming, and we refer to Algorithm 6 for the computation, which is also implemented in
KSig
. It has a complexity of
\mathcal{O}((Mp^{2}+d)\mathsf{L}_{\mathbf{x}}\mathsf{L}_{\mathbf{y}})
, where
M
is the truncation level,
d
is the complexity of evaluating
\mathrm{k}
, and
\mathsf{L}_{\mathbf{x}},\mathsf{L}_{\mathbf{y}}
are respectively the effective length of the input sequences
\mathbf{x},\mathbf{y}
. We note this algorithm solely uses cumulative sum operations for the recursion step, which is completely parallelizable and using a work-efficient scan algorithm can be computed in logarithmic time given enough computing cores. Hence, the best achievable time complexity on GPUs actually scales in length as
\mathcal{O}(\log\mathsf{L}_{\mathbf{x}}\log\mathsf{L}_{\mathbf{y}})
, but the quadratic complexity remains in terms of memory, which can become a bottleneck.
Further, note this algorithm is exact, that is it computes (
8
) without any approximation (which is not the case for many of the following algorithms).

Next, we discuss the role of the order parameter
p
. It allows to change the algebraic embedding employed by the signature kernel. We do not discuss the theory behind different choices of algebraic embeddings in detail, and instead refer to
[
33
,
8
,
9
]
.
for discussion. However, we note that lowering
p
leads to computational savings, while often retaining or even improving performance on downstream tasks. This can also be theoretically explained for the
p=1
case by a universality result proved in
[
33
]
.
Hence, it is often beneficial to start with
p=1
for efficiency.

2.3
Signature-PDE Kernels

An alternative approach for computing signature kernels proposed by
[
27
]
is involved with approximating the untrucated signature kernel by a PDE-based approach – that is, we set
M=\infty
, and we have

\displaystyle\mathrm{k}_{\mathrm{\mathsf{SigPDE}}}(\mathbf{x},\mathbf{y})=\sum_{m=0}^{\infty}\mathrm{k}_{{\mathrm{\mathsf{Sig}}_{m}}}(\mathbf{x},\mathbf{y}),

(13)

where
\mathbf{x},\mathbf{y}\in\mathcal{X}_{\text{seq}}
.
Since the method is based on PDE discretization, we briefly consider the continuous-time formulation. Let
\mathbf{x},\mathbf{y}\in\mathcal{X}_{\text{paths}}
be such that
(\mathrm{k}_{\mathbf{x}_{s}})_{s\in[0,S]}
and
(\mathrm{k}_{\mathbf{y}_{t}})_{t\in[0,T]}
are bounded variation in
\mathcal{H}_{\mathrm{k}}
. Let us define the function
\mathrm{K}\mathrel{\mathop{\mathchar 58\relax}}[0,S]\times[0,T]\to\mathbb{R}
as the signature kernel restricted to a given timeframe for
s\in[0,S]
and
t\in[0,T]

\displaystyle\mathrm{K}(s,t)=\mathrm{k}_{\mathrm{\mathsf{SigPDE}}}(\mathbf{x}|_{[0,s]},\mathbf{y}|_{[0,t]}).

(14)

Then, they show in Section 2.2 that
\mathrm{K}
solves the following PDE

\displaystyle\frac{\partial^{2}\mathrm{K}(s,t)}{\partial s\partial t}=\langle\dot{\mathrm{k}_{\mathbf{x}_{s}}},\dot{\mathrm{k}_{\mathbf{x}_{t}}}\rangle_{\mathcal{H}_{k}}\mathrm{K}(s,t),

(15)

where
(\,\dot{}\,)
denotes a time derivative. This is a Goursat problem, and by Taylor expansion they derive a 2
nd
-order finite-difference scheme. Hence, we return to the discrete-time setting. Let
\mathbf{x},\mathbf{y}\in\mathcal{X}_{\text{seq}}
be sequences corresponding to discretizations of underlying paths along the grid where the PDE is solved. Define

\displaystyle\hat{\mathrm{K}}(k,l)\approx\mathrm{K}(k,l)\equiv\mathrm{k}_{\mathrm{\mathsf{SigPDE}}}(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}k},\mathbf{y}_{0\mathrel{\mathop{\mathchar 58\relax}}l})

(16)

as the discretized signature-PDE kernel over the restricted time frame up to steps
k
and
l
. Then, by
(
27
, Def. 3.3)
, we can compute
\hat{\mathrm{K}}
recursively by

\displaystyle\hat{\mathrm{K}}(k,l)

\displaystyle=\hat{\mathrm{K}}(k,l-1)+\hat{\mathrm{K}}(k-1,l)-\hat{\mathrm{K}}(k-1,l-1)

(17)

\displaystyle-\frac{1}{2}\nabla_{k,l}\mathrm{k}(\mathbf{x}_{k},\mathbf{y}_{l})(\hat{\mathrm{K}}(k,l-1)+\hat{\mathrm{K}}(k-1,l)),

(18)

with the initial condition
\hat{\mathrm{K}}(\cdot,0)=\hat{\mathrm{K}}(0,\cdot)=1
, where
\nabla_{k,l}
is the double difference operator as defined previously. Then,
\mathrm{k}_{\mathrm{\mathsf{SigPDE}}}(\mathbf{x},\mathbf{y})=\hat{\mathrm{K}}(\mathsf{L}_{\mathbf{x}},\mathsf{L}_{\mathbf{y}})
.
Note that unlike algorithm for the truncated signature kernel from
Section
2.2
, this gives an approximation due to PDE discretization.
In practice, when starting from discrete-time data, the authors propose to apply dyadic refinement with linear interpolation in order to increase the accuracy of the PDE solver. We omit this here and leave it up to the user as a data preprocessing step to upsample the data.

In this algorithm, the recursion step requires computing the full matrix
(\hat{\mathrm{K}}(k,l))_{k,l}
, which has a similar quadratic sequence length complexity as the dynamic programming algorithm above. In theory, complexity of computations is
\mathcal{O}(d\mathsf{L}_{\mathbf{x}}\mathsf{L}_{\mathbf{y}})
, where
d
is the static kernel evaluation cost, and
\mathsf{L}_{\mathbf{x}},\mathsf{L}_{\mathbf{y}}
are the lengths of the input time series. To speed up computations,
[
27
]
proposes a parallelized recursion scheme, which opens the avenue for GPU based parallelization, by iterating over each antidiagonal of this matrix, and computing each entry of it in parallel. This potentially reduces the time complexity in
\mathsf{L}_{\mathbf{x}}
and
\mathsf{L}_{\mathbf{y}}
to the number of antidiagonals, i.e.
\mathcal{O}(\mathsf{L}_{\mathbf{x}}+\mathsf{L}_{\mathbf{y}})
, but it still retains the quadratic memory complexity as before.

In
KSig
, we provide an implementation using
Numba

[
15
]
with a
CUDA

JIT
kernel. We optimized the implementation compared to the original version

2
2

2

The original implementation in
torch
is available at
https://github.com/crispitagorico/sigkernel
.

released by the authors of
[
27
]
. The main difference is that in there the whole
(\hat{\mathrm{K}}(k,l))_{k,l}
matrix is kept in memory during the computation, leading to a significant memory footprint, while our implementation only keeps the current and the previous two antidiagonals in memory saving considerable amounts of GPU memory. This allows for potential scalability to slightly longer time series, although other time series operations performed during the computation (i.e. the static kernel evaluation) retain quadratic memory, hence, scalability to long time series is still a bottleneck.

3
Primal Signature Algorithms

Next, we discuss primal approaches – that is, approaches which employ low-rank approximations to the Gram matrix of signature kernels allowing to construct finite-dimensional features such that their inner product approximate the signature kernel in probability. We focus on approximating the truncated signature kernel built from a continuous, bounded, and stationary static kernel on the sequence state space
\mathcal{X}=\mathbb{R}^{d}
, such as the the RBF kernel.

3.1
Random Fourier Features

Our main tool will be the classic Random Fourier Features.
KSig
also provides other feature maps such as the Nyström method
[
10
]
, but in practice there is not much difference in performance between the two, hence we restrict our attention to the former.

Recall that Random Fourier Features (RFF)
[
23
]
are defined for a continuous, bounded, stationary kernel
\mathrm{k}\mathrel{\mathop{\mathchar 58\relax}}\mathbb{R}^{d}\times\mathbb{R}^{d}\to\mathbb{R}
with spectral measure
\Lambda
as

\displaystyle\varphi(\mathbf{x})=\frac{1}{\sqrt{D}}\left(\cos(W^{\top}\mathbf{x}),\sin(W^{\top}\mathbf{y})\right)\quad\text{for }\mathbf{x}\in\mathbb{R}^{d},

(19)

where
\mathbb{R}^{d\times D}\ni W\sim\Lambda^{D}
. Another formulation of RFF is given by using

\displaystyle\varphi^{\mathsf{1D}}(\mathbf{x})=\frac{1}{\sqrt{D}}\cos(W^{\top}\mathbf{x}+\mathbf{b}),

(20)

where
\mathbb{R}^{d\times D}\ni W\sim\Lambda^{D}
and
\mathbb{R}^{D}\ni\mathbf{b}\sim\mathcal{U}^{D}(0,2\pi)
, where
\mathcal{U}
refers to the uniform distribution. Then, both approaches offer an unbiased approximation of the kernel

\displaystyle\mathrm{k}(\mathbf{x},\mathbf{y})=\mathbb{E}[\langle\varphi(\mathbf{x}),\varphi(\mathbf{y})\rangle_{\mathbb{R}^{2D}}]=\mathbb{E}[\langle\varphi^{\mathsf{1D}}(\mathbf{x}),\varphi^{\mathsf{1D}}(\mathbf{y})\rangle_{\mathbb{R}^{D}}]

(21)

with strong probabilistic concentration guarantees
[
28
,
31
,
3
]
. Note that both approaches use
D
Monte Carlo samples for approximating the stationary static kernel
\mathrm{k}
, however, for RFF (
19
) each sample is
2
-dimensional leading to a
2D
-dimensional feature map, while for RFF-1D (
20
) each sample is
1
-dimensional, leading to a
D
-dimensional feature map. This will be an important distinction later on, when discussing the diagonal projection approach in Section
3.3
.

3.2
Random Fourier Signature Features

First, we provide an overview of Random Fourier Signature Features (RFSF) from
[
35
]
.
Let
\varphi_{1},\dots,\varphi_{m}\mathrel{\mathop{\mathchar 58\relax}}\mathbb{R}^{d}\to\mathbb{R}^{D}
be independent RFF maps as in (
19
).
Then, the order-
p
level-
m
Random Fourier Signature Feature map is defined as

\displaystyle\Phi_{m}(\mathbf{x})\coloneqq\sum_{\mathbf{i}\in\Delta_{m}(\mathsf{L}_{\mathbf{x}})}\frac{1}{\mathbf{i}!^{(p)}}\nabla_{i_{1}}\varphi_{1}(\mathbf{x}_{i_{1}})\otimes\cdots\otimes\nabla_{i_{m}}\varphi_{m}(\mathbf{x}_{i_{m}}).

(22)

We leave it a straightforward exercise for the reader to check that this indeed provides an unbiased approximation to the level-
m
order-
p
signature kernel (
6
).
Alternatively, we could have used in place of
\varphi
the lower-dimensional
\varphi^{\mathsf{1D}}
, but for didactic purposes we shall focus on the former and later discuss the differences. The recursion to compute (
22
) can be written for
\mathbf{x}\in\mathcal{X}_{\text{seq}}
as

\displaystyle\Phi_{m}(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}k})=\sum_{\kappa=1}^{k}\sum_{q=1}^{p}\frac{1}{q!}\Phi_{m-q}(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}\kappa-1})\otimes\nabla_{\kappa}\varphi_{m-q+1}(\mathbf{x}_{\kappa})\otimes\cdots\otimes\nabla_{\kappa}\varphi_{m}(\mathbf{x}_{\kappa})

(23)

This feature map represents the order-
p
level-
m
signature kernel in feature space using
(2D)^{m}
coordinates.
Alternatively, if we used
\varphi^{\mathsf{1D}}
in place of
\varphi
we would end up with a feature map that is
D^{m}
dimensional, and we denote this variation by

\displaystyle\Phi_{m}^{\mathsf{1D}}\mathrel{\mathop{\mathchar 58\relax}}\mathcal{X}_{\text{seq}}\to\mathbb{R}^{D^{m}}.

(24)

An algorithm to compute (
23
) was proposed by
(
35
, Alg. D.1)
, which computes (
22
) with a complexity of
\mathcal{O}(L(MdD+pD^{m}))
, the algorithm and complexity of
\varphi_{m}^{\mathsf{1D}}
is analogous since the dimension of the static feature map is only different by a factor of
2
. Although this allows to approximate the signature kernel using a finite-dimensional space, it still suffers from the combinatorial explosion of signature coordinates incurred by high-degree tensors. This motivates the use of (randomized) dimensionality reduction techniques to aid in further scalability. We consider three projection techniques:

(1)

the diagonal projection and

(2)

tensor random projection approaches proposed by
[
35
,
36
]
;

(3)

a novel approach based on the tensor sketch
[
22
]
not discussed in previous work yet

.

3.3
Diagonal Projection Approach

The first approach we consider is the diagonal projection approach of
[
35
]
. Here, the core idea is that since RFSF in (
22
) is an unbiased estimator for the truncated signature kernel (
6
), we can sample multiple independent copies of it and average them to get an estimator for the signature kernel. Then, by the law of large numbers and probabilistic concentration arguments, this estimator converges to the signature kernel
(1/m)
-subexponentially fast (see
(
35
, Thm. 3.5)
as we increase the number of samples. In order to make the computation of each RFSF sample fast, for each of them we decrease the internal RFF size to
1
-sample. Thus, let
\Phi^{(1)},\dots,\Phi^{(D)}\mathrel{\mathop{\mathchar 58\relax}}\mathcal{X}_{\text{seq}}\to\mathbb{R}^{2^{m}}
be independent RFSF maps as in (
22
) with internal RFF sample size-
1
. Then, the diagonally projected RFSF map (RFSF-DP) is defined for
\mathbf{x}\in\mathcal{X}_{\text{seq}}
as

\displaystyle\Phi^{\mathsf{DP}}_{m}(\mathbf{x})=\frac{1}{\sqrt{D}}\left(\Phi_{m}^{(1)}(\mathbf{x}),\dots,\Phi_{m}^{(D)}(\mathbf{x})\right)\in\mathbb{R}^{2^{m}D},

(25)

where the computation of each
\Phi_{m}^{(i)}
is completely analogous to (
23
), except that now each of these have internal RFF sample size-
1
, resulting in
2
-dimensional RFFs as per (
19
), which leads to each
\Phi_{m}^{(i)}
being
2^{m}
dimensional, leading to an overall dimensionality of
2^{m}D
. See
(
35
, Alg. D.2)
for the vectorized computation of this approach. The complexity of computing all features up to truncation-
M
is then governed by computing (
22
)
D
-times in parallel with RFF size-
1
, which is
\mathcal{O}(L(MdD+pD2^{M+1}))
, which has an exponential factor in
M
, although with a base of
2
, which is mild for moderate truncation.

Next, we discuss the diagonal projection approach applied to the RFSF-1D variation (
24
)
[
36
]
, that uses
1
-dimensional RFF samples from (
20
). We denote this approach by
\Phi^{\mathsf{DP\text{-}1D}}_{m}\mathrel{\mathop{\mathchar 58\relax}}\mathcal{X}_{\text{seq}}\to\mathbb{R}^{D}
, and similarly to (
25
), it is given by concatenating
D
independent copies
\Phi_{m}^{\mathsf{1D},(1)},\dots,\Phi_{m}^{\mathsf{1D},(D)}\mathrel{\mathop{\mathchar 58\relax}}\mathcal{X}_{\text{seq}}\to\mathbb{R}
, so we have

\displaystyle\Phi^{\mathsf{DP\text{-}1D}}_{m}=\frac{1}{\sqrt{D}}\left(\Phi^{\mathsf{1D},(1)}_{m},\dots,\Phi^{\mathsf{1D},(D)}_{m}\right)\in\mathbb{R}^{D}.

(26)

The algorithm to compute (
26
) is analogous to the computation of (
25
), i.e. computing the
D
independent copies of
\Phi^{\mathsf{1D},(i)}
in parallel, and returning their concatenation as the resulting feature map. We call this variation RFSF-DP-1D that has a complexity of
\mathcal{O}(LMD(d+p))
, hence avoiding the exponential factor
2^{M}
, resulting in better scalability in
M
. In practice, for given of
D
and
M
it is lower dimensional, but has higher variance due to the static feature map (
20
) having higher variance than (
19
).

3.4
Tensor Random Projection Approach

This approach was also introduced by
[
35
]
, and it uses tensor random projections (TRP)
[
24
,
30
]
to reduce the dimensionality of the base RFSF map (
22
) by constructing factorized projection tensors using the tensor product of Gaussian vectors.

Let
X\in(\mathbb{R}^{D})^{\otimes m}
. The rank-
1
TRP of
X
is constructed via the random functional
\ell\in L((\mathbb{R}^{D})^{\otimes m},\mathbb{R})
,
\ell(X)=\langle\mathbf{u}_{1}\otimes\cdots\otimes\mathbf{u}_{m},X\rangle_{(\mathbb{R}^{D})^{\otimes m}}
,
where
\mathbf{u}_{1},\dots,\mathbf{u}_{m}\in\mathbb{R}^{D}
have i.i.d.
\mathcal{N}(0,1)
entries. Then, stacking
Q
independent functionals
\ell_{1}=\langle\mathbf{u}_{1}^{(1)}\otimes\cdots\otimes\mathbf{u}_{m}^{(1)},\cdot\rangle,\dots,\ell_{Q}=\langle\mathbf{u}_{1}^{(Q)}\otimes\cdots\otimes\mathbf{u}_{m}^{(Q)},\cdot\rangle
gives the TRP map

\displaystyle\mathsf{TRP}(X)=\frac{1}{\sqrt{Q}}(\ell_{1}(X),\dots,\ell_{Q}(X))^{\top}\in\mathbb{R}^{Q},\quad\mathsf{TRP}\mathrel{\mathop{\mathchar 58\relax}}(\mathbb{R}^{D})^{\otimes m}\to\mathbb{R}^{Q}.

(27)

We can apply this idea to RFSF by composing it with the TRP map in order to reduce its dimensionality, such that
\Phi^{\mathsf{TRP}}_{m}(\mathbf{x})=\mathsf{TRP}\left(\Phi_{m}(\mathbf{x})\right)
for
\mathbf{x}\in\mathcal{X}_{\text{seq}}
. By exploiting linearity and that the inner product with the projection tensors factorizes across the components in the tensor product, we get the explicit formulation

\displaystyle\Phi^{\mathsf{TRP}}_{m}(\mathbf{x})=\frac{1}{\sqrt{Q}}\sum_{\mathbf{i}\in\Delta_{m}(\mathsf{L}_{\mathbf{x}})}\frac{1}{\mathbf{i}!^{(p)}}P_{1}(\nabla_{i_{1}}\varphi_{1}(\mathbf{x}_{i_{1}}))\odot\cdots\odot P_{m}(\nabla_{i_{m}}\varphi_{m}(\mathbf{x}_{i_{m}})),

(28)

where
P_{j}(\mathbf{x})=\left(\langle\mathbf{u}_{j}^{(1)},\mathbf{x}\rangle,\dots,\langle\mathbf{u}_{j}^{(Q)},\mathbf{x}\rangle\right)^{\top}\in\mathbb{R}^{Q}
for
\mathbf{x}\in\mathbb{R}^{D}
. The recursive formulation in this case is written similarly to (
23
) for a
\mathbf{x}\in\mathcal{X}_{\text{seq}}
as

\displaystyle\Phi^{\mathsf{TRP}}_{m}

\displaystyle(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}k})

(29)

\displaystyle=

\displaystyle\sum_{\kappa=1}^{k}\sum_{q=1}^{p}\frac{1}{q!}\Phi^{\mathsf{TRP}}_{m-q}(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}k-1})\odot P_{m-q+1}(\nabla_{k}\varphi_{m-q+1}(\mathbf{x}_{k}))\odot\cdots\odot P_{m}(\nabla_{k}\varphi_{m}(\mathbf{x}_{k})).

(30)

An algorithm to compute (
29
) is given under
(
35
, Alg. D.3)
. It has a complexity of
\mathcal{O}(MLD(d+pQ))
. Typically
Q=D
, for which it is more expensive than RFSF-DP-1D by a factor of
D
due to performing multiplications with the
Q\times D
projection matrices in (
29
).

3.5
Tensor Sketch Approach

Finally, the last approach we consider is similar to the tensor random projection approach, where individual random projections are combined to build a projection of the tensor product. It is termed the tensor sketch introduced in
[
22
]
, and it starts with the count sketches
[
4
]
of the component vector across the tensor product, and then combines the count sketches of these components to build a count sketch for the tensor product. The core idea is to use that the circular convolution of count sketches is again a count sketch corresponding to their tensor product. Further, it admits efficient computations by realizing convolutions in the frequency domain as element-wise products. Using this property, we can build the count sketch of RFSFs by replacing each tensor product in (
22
) with the convolution of count sketches.

We introduce the count sketch, and show how given count sketches of vectors we can build a count sketch for their tensor product, called the tensor sketch. Let
h\mathrel{\mathop{\mathchar 58\relax}}[d]\to[Q]
and
s\mathrel{\mathop{\mathchar 58\relax}}[d]\to\{\pm 1\}
be
2
-wise independent hash functions. Then, the count sketch
\mathsf{CS}\mathrel{\mathop{\mathchar 58\relax}}\mathbb{R}^{d}\to\mathbb{R}^{Q}
of a
\mathbf{x}=(x_{1},\dots,x_{d})\in\mathbb{R}^{d}
is

\displaystyle\mathsf{CS}(\mathbf{x})=\left(\mathsf{CS}(\mathbf{x})_{1},\dots\mathsf{CS}(\mathbf{x})_{Q}\right)^{\top}\in\mathbb{R}^{Q},\quad\mathsf{CS}(\mathbf{x})_{j}=\sum_{h(i)=j}s(i)x_{i}.

(31)

Then an unbiasedness approximation result holds for
\mathbf{x},\mathbf{y}\in\mathbb{R}^{d}
such that

\displaystyle\langle\mathbf{x},\mathbf{y}\rangle_{\mathbb{R}^{d}}=\mathbb{E}\left[\langle\mathsf{CS}(\mathbf{x}),\mathsf{CS}(\mathbf{y})\rangle_{\mathbb{R}^{Q}}\right]\approx\langle\mathsf{CS}(\mathbf{x}),\mathsf{CS}(\mathbf{y})\rangle_{\mathbb{R}^{Q}},

(32)

with the variance of the estimator on the RHS is bounded by the
2
-norm of the inputs
(
22
, Lem. 3)
.
Now, let
\mathbf{x}_{1},\dots,\mathbf{x}_{m}\in\mathbb{R}^{D}
, and
\mathsf{CS}_{1},\dots,\mathsf{CS}_{m}\mathrel{\mathop{\mathchar 58\relax}}\mathbb{R}^{D}\to\mathbb{R}^{Q}
independent CS operators. Then, the tensor sketch operator
\mathsf{TS}\mathrel{\mathop{\mathchar 58\relax}}(\mathbb{R}^{D})^{\otimes m}\to\mathbb{R}^{Q}
is

\displaystyle\mathsf{TS}(\mathbf{x}_{1}\otimes\cdots\otimes\mathbf{x}_{m})=\mathsf{CS}_{1}(\mathbf{x}_{1})\star\cdots\star\mathsf{CS}_{m}(\mathbf{x}_{m})\in\mathbb{R}^{Q},

(33)

where
\star
denotes circular convolution, and can be computed efficiently using the Fast Fourier Transform (FFT) in
\mathcal{O}(Q\log Q)
time. Note that TS is again a count sketch of
\mathbf{x}_{1}\otimes\cdots\otimes\mathbf{x}_{m}\in(\mathbb{R}^{D})^{\otimes m}

[
22
]
. Hence, we can build the TS of (
22
) for
\mathbf{x}\in\mathcal{X}_{\text{seq}}
by

\displaystyle\Phi^{\mathsf{TS}}_{m}(\mathbf{x})=\sum_{\mathbf{i}\in\Delta_{m}(\mathsf{L}_{\mathbf{x}})}\frac{1}{\mathbf{i}!^{(p)}}\mathsf{CS}_{1}(\nabla_{i_{1}}\varphi_{1}(\mathbf{x}_{i_{1}}))\star\cdots\star\mathsf{CS}_{m}(\nabla_{i_{m}}\varphi_{m}(\mathbf{x}_{i_{m}})).

(34)

Then, we establish a recursion analogous to (
23
) for
\mathbf{x}\in\mathcal{X}_{\text{seq}}
given by

\displaystyle\Phi^{\mathsf{TS}}_{m}

\displaystyle(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}k})

(35)

\displaystyle=

\displaystyle\sum_{\kappa=1}^{k}\sum_{q=1}^{p}\frac{1}{q!}\Phi^{\mathsf{TS}}_{m-q}(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}\kappa-1})\star\mathsf{CS}_{m-q+1}(\nabla_{\kappa}\varphi_{m-q+1}(\mathbf{x}_{\kappa}))\star\cdots\star\mathsf{CS}_{m}(\nabla_{\kappa}\varphi_{m}(\mathbf{x}_{\kappa}))

(36)

\displaystyle=

\displaystyle\sum_{\kappa=1}^{k}\sum_{q=1}^{p}\frac{1}{q!}\mathsf{FFT}^{-1}\left(\mathsf{FFT}(\Phi^{\mathsf{TS}}_{m-q}(\mathbf{x}_{0\mathrel{\mathop{\mathchar 58\relax}}\kappa-1}))\odot\mathsf{FFT}(\mathsf{CS}_{m-q+1}(\nabla_{\kappa}\varphi_{m-q+1}(\mathbf{x}_{\kappa})))\odot\cdots\odot\mathsf{FFT}(\mathsf{CS}_{m}(\nabla_{\kappa}\varphi_{m}(\mathbf{x}_{\kappa})))\right),

(37)

where the second line follows from being able to realize circular convolutions
\star
as element-wise products
\odot
in the frequency domain. The algorithm to compute (
35
) is similar to the one for TRP with appropriate changes, that is implemented in
KSig
under the same API. It has a time complexity of
\mathcal{O}(ML(Dd+pQ\log Q)
. Setting
Q=D
, it is more expensive than RFSF-DP-1D by a factor of
\log D
due to the FFT computation, but cheaper than RFSF-TRP since it replaces the
D^{2}
factor by a factor of
D\log D
.

4
Scalability Analysis

We study the memory footprint, runtime and accuracy of the algorithms in computing the Gram matrix of a synthetic dataset and observe the following:

•

Primal methods are necessary for long sequences.
Running each algorithm until the memory limit, dual methods can process sequence lengths
L\sim 10^{3}
whereas primal methods can process
L\geq 10^{5}
(Fig.
1
). This is due to their linear dependence on the sequence length
L
(Table
1
).

•

Diagonal Projection methods achieve the highest accuracy.
For given memory constraint, we can increase the parameters of diagonal projection methods further yielding higher accuracy (Fig.
3
).

•

RFSF-TRP and RFSF-TS generate better features.
For a given feature map size, the resulting feature maps yield higher accuracy (Fig.
3
). For downstream applications, where the feature map size have a larger effect on the overall complexity, these methods may be more desirable.

•

Projection size is the accuracy bottleneck for RFSF-TRP and RFSF-TS.
A large static feature size
D
is redundant if the projection size
Q
is not sufficiently large (Fig.
4
).

•

All algorithms are effectively linear in truncation level for fixed order.
With the feature map size equal across algorithms, we observe that each one scales linearly in memory and runtime (Fig.
5
).

Experiments were conducted on a NVIDIA A100 GPU with a memory capacity of 40GB. The synthetic dataset consists of
d
-dimensional Brownian Motion over
[0,1]
. Across all experiments we fix dimension
d=5
and order
p=1
. Other parameter choices vary and will be specified in the associated caption.

5
Conclusion and Outlook

KSig
provides a GPU-accelerated library for efficient computation of various flavours of the signature kernel, bridging theoretical robustness and practical scalability.
We emphasize the following points

•

Modularity and Integration.

Following
Scikit-Learn
’s design,
KSig
enables seamless integration into diverse kernel learning applications and packages (e.g., supervised learning using SVM, hypothesis testing with MMDs
[
13
,
5
]
, or unsupervised algorithms such as kernel k-means
[
7
]
).

•

Choice of Algorithm.
While optimization across possible variations (together with hyperparameter optimization) is recommended for optimal results, the RFSF-DP-1D approach (Section
3.3
) offers the most economic computational footprint for given feature size, hence we recommend it as a starting point.
Its primal formulation (Remark
1
) avoids Gram matrix computations.
This allows for linear complexity in the number of sequences and in sequence length without data subsampling!

•

Future Directions.
Future work includes implementing recent advances, such as the forgetting mechanism for time-localized sequence analysis proposed in
[
36
]
addressing the need to emphasize recent events over distant history in signature kernels, or extending the hypo-elliptic diffusion approach for graphs
[
34
]
to the kernel learning regime potentially combined with random features for scalability.

We encourage community contributions and feedback to further enhance
KSig
.
The package is available at
https://github.com/tgcsaba/ksig
.

Type 2 - Structured Tensor Projections

Projections in this class compute the projection of the tensor product of multiple vectors in a way that respects the tensorial nature of the input, and correspond to the variations discussed in Section
3
.
In particular, for a tensor
\mathbf{x}_{1}\otimes\cdots\otimes\mathbf{x}_{m}\in(\mathbb{R}^{d})^{\otimes m}
, they implement a tensor projection operator
P\in L((\mathbb{R}^{d})^{\otimes m},\mathbb{R}^{Q})
, where
Q=\texttt{n\_components}
, such that the algorithm computes
\mathbf{x}_{1}\otimes\cdots\otimes\mathbf{x}_{m}\mapsto P(\mathbf{x}_{1}\otimes\cdots\otimes\mathbf{x}_{m})
without building the input tensor itself. This type also has
_project

\psi
and
_project_outer_prod

\widehat{\psi}
methods such that the projection of
\mathbf{x}_{1}\otimes\cdots\otimes\mathbf{x}_{m}
is computed recursively as

\displaystyle P(\mathbf{x}_{1}\otimes\dots\otimes\mathbf{x}_{m})=\widehat{\psi_{m}}(\cdots\widehat{\psi_{2}}(\psi_{1}(\mathbf{x}_{1}),\mathbf{x}_{2}),\cdots,\mathbf{x}_{m}).

(53)

The interpolation procedure is as follows. Given a sequence
\mathinner{\left\{\mathbf{x}_{0},\dots,\mathbf{x}_{L-1}\right\}}
of length
L
, we define a function
f
on
[0,1]
. Set
f(i/{L-1})=\mathbf{x}_{i}
and interpolate each dimension separately and linearly.

f(t)=\mathbf{x}_{i}+(L-1)\left(t-\frac{i}{L-1}\right)(\mathbf{x}_{i+1}-\mathbf{x}_{i}),\quad t\in\left[\frac{i}{L-1},\frac{i+1}{L-1}\right],\quad i\in\mathinner{\left\{0,1,\dots,L-2\right\}}

(63)

To obtain the output sequence
\mathinner{\left\{\widetilde{\mathbf{x}}_{0},\dots,\widetilde{\mathbf{x}}_{\widetilde{L}-1}\right\}}
of length
\widetilde{L}
we set
\widetilde{\mathbf{x}}_{i}=f(i/{\widetilde{L}-1})
.

SequenceAugmentor
.
This class assumes
X_seq
is an array of shape
(N,L,d)
. We have a parameter to indicate whether to perform each type of augmentation and auxiliary ones (
max_time
,
max_len
). The augmentations can be chained and are performed in the following order.

•

normalize
.
Ensure all values of
X_seq
are in
[-1,1]
by dividing by the maximum absolute value found in
X_seq
. The output shape is unchanged.

•

lead_lag
.
Map
\mathbf{x}_{i}=(\mathbf{x}_{i}^{(1)},\dots,\mathbf{x}_{i}^{(d)})\to(\mathbf{x}_{i+1}^{(1)},\dots,\mathbf{x}_{i+1}^{(d)},\mathbf{x}_{i}^{(1)},\dots,\mathbf{x}_{i}^{(d)})=(\mathbf{x}_{i+1},\mathbf{x}_{i})
. The output shape is
(N,L-1,2d)
.

•

add_time
.
Obtain a regular grid
t_{i}
on
[0,\texttt{max\_time}]
of size
L
(i.e.
t_{i}=\texttt{max\_time}\cdot i/({L-1})
), by default
max_time
= 1. Map
\mathbf{x}_{i}\to(t_{i},\mathbf{x}_{i})
. The output shape is
(N,L,d+1)
.

•

.
Append
\mathbf{0}\in\mathbb{R}^{d}
to the sequence
\mathinner{\left\{\mathbf{0},\mathbf{x}_{0},\dots,\mathbf{x}_{L-1}\right\}}
. The output shape is
(N,L+1,d)
.

If
max_len
is specified and the length is greater than

, we downsample by interpolation.

This folder contains classes to generate Support Vector Classifiers (handling multiclass via a one-vs-one scheme) which have built-in hyperparameter tuning (via stratified cross validation and grid search).
