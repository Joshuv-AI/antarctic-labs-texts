Bias-Class Discrimination of Universal QRAM Boolean Memories
Leonardo Bohac

Abstract
We study the discrimination of Boolean memory configurations via a fixed Universal QRAM (U-QRAM) interface. Given query access to a quantum memory storing an unknown Boolean function f : [ N ] → { 0 , 1 } f:[N]\to\{0,1\} , we ask: what can be inferred about the bias class of f f (its imbalance from 1 / 2 1/2 , up to complement symmetry) using coherent, addressable queries? We show that for exact-weight bias classes, the induced single-query ensemble state on the address register has a two-eigenspace structure that yields closed-form expressions for the single-copy Helstrom-optimal measurement and success probability. Because complementing f f changes | ψ f ⟩ \ket{\psi_{f}} only by a global phase, hypotheses p p and 1 − p 1-p are information-theoretically identical in this model; thus the natural discriminand is the phase-bias magnitude | μ | |\mu| (equivalently μ 2 \mu^{2} ). This goes beyond the perfect-discrimination case of Deutsch–Jozsa [ 6 ] and complements exact-identification settings such as Bernstein–Vazirani [ 7 ] .



1
Introduction

Quantum random-access memory (QRAM) has been proposed as a key primitive for quantum algorithms
that process classical data in superposition
[
3
]
. However, the primary value of QRAM
is not as a “fast data loader” but as a
structured query interface
to quantum memory.

In this work, we study U-QRAM from the perspective of
state discrimination
:
given query access to an unknown memory configuration via a fixed U-QRAM interface,
what properties of the memory can be inferred?

This paper continues a program that treats U-QRAM as a
fixed, data-independent interface
whose inputs are different
memory states
(rather than different unitaries), following the construction in
[
1
]
.
It is also complementary to single-query
identification
results for Boolean families (where the goal is to output
f
itself) developed in
[
2
]
.

Why this is not “just Deutsch–Jozsa.”

While the optimal single-copy measurement turns out to be as simple as a
\ket{+}
-vs-
\perp
test, the point of this paper is that this simplicity is
forced by symmetry
of the
U-QRAM induced ensemble
for exact-weight classes.
We isolate this maximally symmetric base case (uniform prior over exact-weight truth tables), obtain the induced mixed states in closed form, and thereby pin down the
information accessible through the fixed interface
as a function of the bias parameter.
This establishes a baseline for follow-ups where the symmetry is broken (approximate weights, noise, non-uniform priors, or genuinely quantum memories), for which Helstrom tests need not remain trivial.

Related work and scope.

There is prior literature on discriminating
sets
of Boolean functions using quantum-state filtering/discrimination methods (e.g., the Bergou–Hillery line of work), which studies different promise structures and objectives and shares the same core move of mapping a Boolean function to a phase-kickback “function state” and then applying quantum-state discrimination/filtering tools
[
4
]
.
Separately, the Deutsch–Jozsa setting has also been framed as discrimination among transformations/oracles in the unitary-discrimination literature
[
5
]
.
Our focus here is the
U-QRAM induced ensemble
for exact-weight bias classes and the resulting
closed-form single-copy
Helstrom test.
For repeated queries we analyze an explicit
separable
strategy under the physically natural “memory fixed” model; we do not claim global optimality over all collective or fully coherent oracle algorithms.
In particular, in the standard controlled-oracle query model one can obtain different
\varepsilon
-scalings via amplitude estimation
[
12
]
(see Remark
5.4
).
We view the exact-weight setting as the canonical “maximal symmetry” starting point: it is precisely this symmetry that makes the induced states commuting and the Helstrom test explicit.

Our main contributions are:

(i)

A reduction from Universal QRAM queries to phase-oracle address states (Lemma
2.4
);

(ii)

A closed form for the induced ensemble state
\rho_{p}
over exact-weight bias classes (Theorem
3.5
);

(iii)

Optimal measurements and success probabilities for binary bias discrimination in the ensemble model (Theorem
4.1
);

(iv)

An achievable multi-query strategy under persistent-memory sampling, with explicit error exponent (Theorem
5.1
).

Ensemble hypothesis-testing viewpoint.

Throughout, we adopt an
ensemble (Bayesian) model
of restricted-access discrimination.
Under a hypothesis
H_{p}
(or
H_{m}
with
p=m/N
), Nature draws a Boolean function
f

once
from a known distribution on the corresponding class (here: uniform on exact-weight truth tables), prepares the preserved memory register in
\ket{M_{f}}
, and keeps it fixed for the duration of the experiment.
The experimenter cannot access
\ket{M_{f}}
directly; they may only query it through the fixed unitary
U_{\mathrm{UQRAM}}
, producing address states
\ket{\psi_{f}}
.
As a result, the discrimination task is between the
induced mixed states

\rho_{p}
(averaged over
f
under the hypothesis), and our single-copy optimality results characterize optimal
average-case
performance rather than worst-case guarantees for every
f
in a class.
For background on minimum-error quantum hypothesis testing, see
[
8
,
9
]
.
Moreover, complement symmetry is built in: since
\ket{\psi_{1-f}}=-\ket{\psi_{f}}
, any procedure in this model can depend on
p
only through
|\mu|
(equivalently
\mu^{2}
).

2
The Universal QRAM Model

2.1
Registers and Memory Encoding

We consider a U-QRAM system with three quantum registers:

•

Address register

A
:
n
qubits,
N=2^{n}
addresses.

•

Data/output register

D
: 1 qubit (for
K=1
bit per address).

•

Memory register

M
:
N
qubits storing the truth table.

A Boolean function
f:[N]\to\{0,1\}
is encoded in the memory register as the basis state

\ket{M_{f}}:=\bigotimes_{a=0}^{N-1}\ket{f(a)}_{M},

(1)

which we call the
truth-table encoding
.

2.2
The U-QRAM Unitary

We model U-QRAM access as a fixed unitary
U_{\mathrm{UQRAM}}
acting on
A\otimes D\otimes M
.
This idealized query semantics is consistent with the data-independent U-QRAM interface viewpoint developed in
[
1
]
.

Definition 2.1

(U-QRAM query on basis memories)
.

For any computational-basis memory state

\ket{m}_{M}:=\bigotimes_{j=0}^{N-1}\ket{m_{j}}_{M},\qquad m_{j}\in\{0,1\},

the U-QRAM unitary is specified by

U_{\mathrm{UQRAM}}\ket{a}_{A}\ket{y}_{D}\ket{m}_{M}=\ket{a}_{A}\ket{y\oplus m_{a}}_{D}\ket{m}_{M},

(2)

and extended by linearity to arbitrary memory states.

Remark 2.2

(Unitarity)
.

The map in Eq. (
2
) permutes computational-basis states and satisfies
U_{\mathrm{UQRAM}}^{2}=\mathbb{I}_{A\otimes D\otimes M}
; hence it extends uniquely to a unitary on
A\otimes D\otimes M
.

We emphasize that Eq. (
2
) defines an idealized U-QRAM query for computational-basis memory contents; when
M
is in superposition over basis memories, the same linear extension generally entangles
A
and
M
(cf. Remark
2.7
).

For a Boolean function
f:[N]\to\{0,1\}
we use the truth-table basis encoding
\ket{M_{f}}_{M}
defined above,
so that Eq. (
2
) specializes to

U_{\mathrm{UQRAM}}\ket{a}_{A}\ket{y}_{D}\ket{M_{f}}_{M}=\ket{a}_{A}\ket{y\oplus f(a)}_{D}\ket{M_{f}}_{M}.

(3)

Remark 2.3

(Key properties)
.

The unitary
U_{\mathrm{UQRAM}}
satisfies:

(a)

Fixed architecture:

U_{\mathrm{UQRAM}}
is data-independent; different memories correspond to different input states on
M
, not different unitaries.

(b)

Memory preservation:
the memory register is unchanged by a query.

(c)

Address locality:
the data/output depends only on the addressed location.

2.3
Reduction to Phase Oracle and Address States

Lemma 2.4

(U-QRAM–Phase-Oracle Reduction)
.

Let
\ket{+}=\frac{1}{\sqrt{N}}\sum_{a=0}^{N-1}\ket{a}
and
\ket{-}=\frac{1}{\sqrt{2}}(\ket{0}-\ket{1})
.
Then:

U_{\mathrm{UQRAM}}\big(\ket{+}_{A}\ket{-}_{D}\ket{M_{f}}_{M}\big)=\ket{\psi_{f}}_{A}\otimes\ket{-}_{D}\otimes\ket{M_{f}}_{M},

(4)

where the
address state
is

\ket{\psi_{f}}:=P_{f}\ket{+}=\frac{1}{\sqrt{N}}\sum_{a=0}^{N-1}(-1)^{f(a)}\ket{a},

(5)

and
P_{f}=\sum_{a}(-1)^{f(a)}\ket{a}\bra{a}
is the phase oracle.

Proof.

Apply
U_{\mathrm{UQRAM}}
to the probe state:

\displaystyle U_{\mathrm{UQRAM}}\big(\ket{+}_{A}\ket{-}_{D}\ket{M_{f}}_{M}\big)

\displaystyle=\frac{1}{\sqrt{N}}\sum_{a}U_{\mathrm{UQRAM}}\ket{a}\ket{-}\ket{M_{f}}

(6)

\displaystyle=\frac{1}{\sqrt{N}}\sum_{a}\ket{a}\cdot\frac{1}{\sqrt{2}}\big(\ket{0\oplus f(a)}-\ket{1\oplus f(a)}\big)\cdot\ket{M_{f}}.

(7)

For each
a
:

\ket{0\oplus f(a)}-\ket{1\oplus f(a)}=\begin{cases}\ket{0}-\ket{1}=\sqrt{2}\ket{-}&\text{if }f(a)=0,\\
\ket{1}-\ket{0}=-\sqrt{2}\ket{-}&\text{if }f(a)=1.\end{cases}

Thus
\ket{-}\mapsto(-1)^{f(a)}\ket{-}
, and

U_{\mathrm{UQRAM}}\big(\ket{+}\ket{-}\ket{M_{f}}\big)=\bigg(\frac{1}{\sqrt{N}}\sum_{a}(-1)^{f(a)}\ket{a}\bigg)\otimes\ket{-}\otimes\ket{M_{f}}=\ket{\psi_{f}}\otimes\ket{-}\otimes\ket{M_{f}}.

∎

Corollary 2.5

(Conditionally i.i.d. repeated queries)
.

Conditioned on a fixed (but unknown)
f
and the truth-table basis encoding
\ket{M_{f}}_{M}
, each query with probe
\ket{+}_{A}\ket{-}_{D}
produces the product output

\ket{\psi_{f}}_{A}\otimes\ket{-}_{D}\otimes\ket{M_{f}}_{M}.

Hence, by reinitializing
A,D
and reapplying
U_{\mathrm{UQRAM}}
, the experimenter can generate

\ket{\psi_{f}}^{\otimes t}
on
t
fresh address registers (conditioned on
f
).

Remark 2.6

(Gram-matrix viewpoint)
.

Conditioned on a fixed but unknown
f
, the experimenter receives pure states
\ket{\psi_{f}}
whose pairwise overlaps are captured by the Gram matrix
G_{f,g}=\braket{\psi_{f}}{\psi_{g}}
.
Gram-matrix methods and related “square-root”/pretty-good measurements are a standard toolbox for analyzing (near-)symmetric state ensembles
[
10
]
.
For a complementary single-query
identification
perspective (recovering
f
within structured families), see
[
2
]
.
In this paper we take the complementary
ensemble-state
route: for a bias class we study the induced mixture
\rho_{p}=\mathbb{E}_{f}[\ket{\psi_{f}}\!\bra{\psi_{f}}]
, whose symmetry forces a two-eigenspace form and makes the Helstrom test explicit.

Remark 2.7

(Superposed memories)
.

If the memory register is prepared in a superposition over truth tables, e.g.
\sum_{f}c_{f}\ket{M_{f}}_{M}
, then a U-QRAM query generally entangles
A
and
M
and the conditional i.i.d. picture is no longer automatic.
Analyzing such genuinely quantum-memory effects is a natural direction beyond the present paper.

3
Bias Classes and Ensemble States

3.1
Bias as a Function Property

Definition 3.1

(Bias and phase-bias)
.

For
f:[N]\to\{0,1\}
, define:

•

The
bias
:
p(f):=\frac{1}{N}\sum_{a}f(a)=\frac{|f^{-1}(1)|}{N}
.

•

The
phase-bias
:
\mu(f):=\frac{1}{N}\sum_{a}(-1)^{f(a)}=1-2p(f)
.

Remark 3.2

(Complement symmetry forces
\mu^{2}
)
.

Let
(1-f)(a)=1-f(a)
. Then
\ket{\psi_{1-f}}=-\ket{\psi_{f}}
, so the induced ensembles for weights
m
and
N-m
are identical.
Consequently, any discrimination task between exact-weight classes in this ensemble model can depend on
p
only through
|\mu|
(equivalently
\mu^{2}
).

Definition 3.3

(Exact-weight bias class)
.

For
m\in\{0,1,\ldots,N\}
, define

\mathcal{F}(m):=\big\{f:[N]\to\{0,1\}:|f^{-1}(1)|=m\big\}.

This is the set of all Boolean functions with exactly
m
ones (Hamming weight
m
),
with
|\mathcal{F}(m)|=\binom{N}{m}
.

3.2
Induced ensemble state

Under the hypothesis
H_{m}
we assume
f\sim\mathrm{Unif}(\mathcal{F}(m))
is sampled once, the memory is prepared in the corresponding basis state
\ket{M_{f}}
, and then held fixed.
A single query produces (conditioned on
f
) the address pure state
\ket{\psi_{f}}
; averaging over the unknown
f
within the class yields the induced single-copy ensemble state

\rho_{p}:=\mathbb{E}_{f\sim\mathcal{F}(m)}\big[\ket{\psi_{f}}\bra{\psi_{f}}\big],

(8)

where
p=m/N
.

Remark 3.4

(Ensemble/Bayesian setting)
.

Throughout, our discrimination results are for the Bayesian/ensemble model induced by the uniform prior over
\mathcal{F}(m)
.
Worst-case discrimination over all
f\in\mathcal{F}(m)
is a distinct problem.

Theorem 3.5

(Ensemble state structure)
.

For the exact-weight bias class
\mathcal{F}(m)
with uniform prior, the induced ensemble state is

\rho_{p}=\mu^{2}\ket{+}\bra{+}+\frac{1-\mu^{2}}{N-1}\Pi_{\perp},

(9)

where
\mu=1-2p
,
p=m/N
, and
\Pi_{\perp}=\mathbb{I}-\ket{+}\bra{+}
(with
\mathbb{I}
the identity on the address space).

Proof.

Let
\mathsf{S}_{N}
act on the address basis by permuting labels: for
\pi\in\mathsf{S}_{N}
, let
U_{\pi}\ket{a}=\ket{\pi(a)}
.
Because the prior over
\mathcal{F}(m)
is uniform and invariant under relabeling of addresses, we have

\rho_{p}=U_{\pi}\rho_{p}U_{\pi}^{\dagger}
for all
\pi
.
Therefore
\rho_{p}
commutes with the full permutation representation on
\mathbb{C}^{N}
.

The representation decomposes as
\mathbb{C}^{N}=\mathrm{span}\{\ket{+}\}\oplus\ker(\bra{+})
, and any operator commuting with all
U_{\pi}
must act as a scalar on each irreducible component.
This is an instance of Schur’s lemma for the permutation representation (see, e.g.,
[
13
]
).
Hence there exist scalars
\alpha,\beta
such that

\rho_{p}=\alpha\mathbb{I}+\beta\ket{+}\bra{+}.

(10)

We determine
\alpha,\beta
from two constraints.
First,
\Tr(\rho_{p})=1
gives
\alpha N+\beta=1
.
Second,

\bra{+}\rho_{p}\ket{+}=\mathbb{E}_{f}\big[|\braket{+}{\psi_{f}}|^{2}\big].

But by (
5
),

\braket{+}{\psi_{f}}=\frac{1}{N}\sum_{a=0}^{N-1}(-1)^{f(a)}=\mu,

so
\bra{+}\rho_{p}\ket{+}=\mu^{2}
.
On the other hand, (
10
) implies
\bra{+}\rho_{p}\ket{+}=\alpha+\beta
.
Thus
\alpha+\beta=\mu^{2}
.

Solving yields

\alpha=\frac{1-\mu^{2}}{N-1},\qquad\beta=\frac{N\mu^{2}-1}{N-1}.

Rewriting in terms of
\Pi_{\perp}=\mathbb{I}-\ket{+}\bra{+}
gives (
9
).
∎

Corollary 3.6

(Two-eigenspace structure)
.

The induced ensemble state
\rho_{p}
has:

•

eigenvalue
\lambda_{+}=\mu^{2}
with multiplicity 1 (eigenvector
\ket{+}
);

•

eigenvalue
\lambda_{\perp}=\frac{1-\mu^{2}}{N-1}
with multiplicity
N-1
(eigenspace
\ker(\bra{+})
).

In particular,
\rho_{p}
and
\rho_{p^{\prime}}
commute for all
p,p^{\prime}
.

4
Binary Discrimination Between Bias Classes

Consider two bias classes with parameters
p_{0}=m_{0}/N
and
p_{1}=m_{1}/N
, with equal prior probability
1/2
each.

Theorem 4.1

(Optimal single-copy discrimination)
.

For binary discrimination between
\rho_{p_{0}}
and
\rho_{p_{1}}
with equal priors:

(a)

The
trace distance
is
D(\rho_{p_{0}},\rho_{p_{1}})=\Delta
, where

D(\rho,\sigma)=\tfrac{1}{2}\|\rho-\sigma\|_{1}
and

\Delta:=|\mu_{0}^{2}-\mu_{1}^{2}|=|(1-2p_{0})^{2}-(1-2p_{1})^{2}|.

(11)

(b)

An optimal Helstrom measurement is the two-outcome POVM
\{\ket{+}\bra{+},\Pi_{\perp}\}
:
output the hypothesis with larger
\mu^{2}
upon outcome
\ket{+}
, and the other upon outcome
\perp
.
Equivalently: apply
H^{\otimes n}
, measure in the computational basis, and decide based on whether the outcome is
\ket{0^{n}}
.

(c)

The
Helstrom success probability
is

P_{\mathrm{succ}}=\frac{1+\Delta}{2}.

(12)

Proof.

By Corollary
3.6
,
\rho_{p_{0}}
and
\rho_{p_{1}}
commute and share the eigenbasis
\{\ket{+}\}\cup\ker(\bra{+})
.
For commuting states, the Helstrom optimal measurement is diagonal in the shared eigenbasis, with each projector assigned to the hypothesis with larger eigenvalue.

Moreover,

\rho_{p_{0}}-\rho_{p_{1}}=(\mu_{0}^{2}-\mu_{1}^{2})\ket{+}\bra{+}-\frac{\mu_{0}^{2}-\mu_{1}^{2}}{N-1}\Pi_{\perp},

so the trace norm is

\|\rho_{p_{0}}-\rho_{p_{1}}\|_{1}=|\mu_{0}^{2}-\mu_{1}^{2}|\Big(1+(N-1)\cdot\frac{1}{N-1}\Big)=2\Delta.

Thus
D=\Delta
and
P_{\mathrm{succ}}=\tfrac{1}{2}(1+D)=\tfrac{1}{2}(1+\Delta)
.
∎

Operational recipe (single query).

Input:
one U-QRAM query access to
\ket{M_{f}}
(held fixed), and a fresh address register
A
.

1.

Prepare
A
in
\ket{+}
and
D
in
\ket{-}
.

2.

Apply
U_{\mathrm{UQRAM}}
once to obtain
\ket{\psi_{f}}
on
A
(Lemma
2.4
).

3.

Apply
H^{\otimes n}
to
A
and measure in the computational basis.

4.

If the outcome is
0^{n}
(projecting onto
\ket{+}
), decide for the hypothesis with larger
\mu^{2}
; otherwise decide for the other.

Remark 4.2

(Special cases)
.

1.

Deutsch–Jozsa

[
6
]
:
p_{0}=0
(constant) vs.
p_{1}=1/2
(balanced).
Then
\mu_{0}=1
,
\mu_{1}=0
,
\Delta=1
,
P_{\mathrm{succ}}=1
(perfect discrimination).

2.

Symmetric biases
:
p_{0}=p
vs.
p_{1}=1-p
.
Then
\mu_{0}^{2}=\mu_{1}^{2}
,
\Delta=0
, and
P_{\mathrm{succ}}=1/2
(no discrimination in the ensemble model).

5
Multi-Query Performance Under Persistent Memory

After
t
queries with the memory held fixed, the experimenter receives (conditioned on
f
) the pure product state
\ket{\psi_{f}}^{\otimes t}
on
t
fresh address registers.
Averaging over
f
under the hypothesis yields the
t
-copy induced state

\rho_{p}^{(t)}:=\mathbb{E}_{f\sim\mathcal{F}(m)}\Big[\big(\ket{\psi_{f}}\bra{\psi_{f}}\big)^{\otimes t}\Big],

(13)

which need not factor as
\rho_{p}^{\otimes t}
in general.

Theorem 5.1

(Achievable separable multi-query strategy)
.

Fix two hypotheses
p_{0},p_{1}
with
\mu_{i}=1-2p_{i}
and let
t\geq 1
.
Consider the separable measurement that applies the two-outcome POVM
\{\ket{+}\bra{+},\Pi_{\perp}\}
independently to each of the
t
address registers, and then performs a likelihood-ratio test on the resulting count.
Then:

(a)

For any
f\in\mathcal{F}(m)
, one has
\braket{+}{\psi_{f}}=\mu
, hence the single-shot outcome probability

\Pr(+\mid f)=|\braket{+}{\psi_{f}}|^{2}=\mu^{2}

is constant across the class.

(b)

Consequently, under hypothesis
p
the number
k
of “
+
” outcomes is exactly

k\sim\mathrm{Binomial}(t,\mu^{2}),

even though
\rho_{p}^{(t)}
may be correlated.

(c)

For equal priors on
p_{0},p_{1}
, the likelihood-ratio test achieves an error probability bounded by

P_{\mathrm{err}}(t)\leq\tfrac{1}{2}e^{-t\,\xi_{\mathrm{cl}}},

(14)

where
\xi_{\mathrm{cl}}
is the classical Chernoff information for distinguishing

\mathrm{Bernoulli}(\mu_{0}^{2})
from
\mathrm{Bernoulli}(\mu_{1}^{2})
:

\xi_{\mathrm{cl}}=-\log\min_{s\in[0,1]}\Big[(\mu_{0}^{2})^{s}(\mu_{1}^{2})^{1-s}+(1-\mu_{0}^{2})^{s}(1-\mu_{1}^{2})^{1-s}\Big],

(15)

interpreted by continuity when a parameter equals
0
or
1
.

Proof.

Item (a) follows from (
5
):

\braket{+}{\psi_{f}}=\frac{1}{N}\sum_{a=0}^{N-1}(-1)^{f(a)}=\mu,

which depends only on the weight
m
(equivalently
p
), not on the specific
f\in\mathcal{F}(m)
.

Conditioned on
f
, the
t
measured outcomes are independent (Corollary
2.5
) and each has success probability
\mu^{2}
, so
k\mid f\sim\mathrm{Binomial}(t,\mu^{2})
.
Since this conditional law does not depend on
f
within the class, the unconditional law under hypothesis
p
is also
\mathrm{Binomial}(t,\mu^{2})
, proving (b).

Finally, the likelihood-ratio test between two i.i.d. Bernoulli models achieves an exponentially decaying error bounded in terms of the Chernoff information
[
11
]
, yielding (c).
∎

Corollary 5.2

(Scaling for small bias gap (separable strategy))
.

To distinguish
p_{0}=1/2
from
p_{1}=1/2+\varepsilon
with constant success probability using the separable strategy of Theorem
5.1
, it suffices to take

t=\Theta(1/\varepsilon^{2}).

In the special case
p_{0}=1/2
(so
\mu_{0}^{2}=0
), the likelihood-ratio test reduces to “decide
p_{1}
iff
k\geq 1
,” and the error probability is

P_{\mathrm{err}}(t)=\tfrac{1}{2}(1-\mu_{1}^{2})^{t}
.

Remark 5.3

(Open question: do collective measurements help?)
.

The
t
-copy induced state
\rho_{p}^{(t)}
generally does not factor as
\rho_{p}^{\otimes t}
, so in principle a collective Helstrom measurement on
\rho_{p_{0}}^{(t)}
vs.
\rho_{p_{1}}^{(t)}
could outperform any separable strategy.
An interesting open problem is to characterize the optimal error exponent for distinguishing these
exchangeable
but potentially correlated mixtures, and to determine whether the “
\ket{+}
-count” statistic is sufficient for optimal discrimination in the exact-weight prior model.

Remark 5.4

(Comparison with coherent amplitude estimation)
.

If one allows fully coherent algorithms with repeated controlled uses of the phase oracle
P_{f}
(implemented via
U_{\mathrm{UQRAM}}
and phase kickback), amplitude estimation can estimate
\mu=\mathbb{E}_{a}[(-1)^{f(a)}]
with query complexity scaling as
O(1/\varepsilon)
in relevant regimes
[
12
]
.
This comparison assumes the standard query-model capability of
controlled
uses of
P_{f}
(or an equivalent controlled-
U_{\mathrm{UQRAM}}
construction), as required by amplitude estimation.
Thus the
\Theta(1/\varepsilon^{2})
scaling above should be interpreted as the complexity of the
separable copy-measurement strategy
, not as a general quantum query lower bound.

6
Discussion

6.1
What U-QRAM Contributes

The discrimination results above could be stated in terms of abstract phase oracles. However, the U-QRAM framing provides:

1.

Operational semantics
: queries are interactions with a fixed, known device, not black-box access to an unknown unitary.

2.

Memory persistence
: the hypothesis is “which memory state?” and the memory register is preserved by
U_{\mathrm{UQRAM}}
.

3.

Restricted-access viewpoint
: the experimenter never accesses
\ket{M_{f}}
directly; the accessible information is mediated by the fixed interface.

6.2
Relation to Deutsch–Jozsa and Bernstein–Vazirani

Deutsch–Jozsa
[
6
]
is the special case
p_{0}=0
vs.
p_{1}=1/2
with
\Delta=1
(perfect discrimination in the ensemble model).
Bernstein–Vazirani
[
7
]
concerns
identifying
a specific function within a structured family, not discriminating between bias classes; our results are complementary.

6.3
Limitations and Future Work

The exact-weight bias class has maximal permutation symmetry, yielding commuting ensemble states and a two-eigenspace form.
Relaxing to approximate-bias classes, noisy QRAM calls, or non-uniform priors breaks this structure and requires more general analyses.
Additionally, for multi-query discrimination under persistent memory, it remains open whether collective measurements across queries can improve the achievable error exponent beyond the explicit separable strategy analyzed here.

6.4
Scientific Contribution

This work makes explicit a clean “restricted-access discrimination” viewpoint for Universal QRAM: the unknown is not an oracle but a

Within this model, we introduce bias classes as a first nontrivial hypothesis family and derive the induced single-query ensemble state
\rho_{p}
in closed form for exact-weight truth tables, using permutation symmetry to show it has only two eigenspaces.
This yields an immediately implementable Helstrom-optimal single-copy test (and an explicit success probability) that quantitatively characterizes how much class-level information about a Boolean memory is accessible through U-QRAM queries.
More broadly, the paper provides a bridge between Universal QRAM constructions and the quantum state-discrimination toolbox, setting up a systematic path to study less symmetric families, non-uniform priors, noise, and genuinely quantum-memory effects beyond basis-encoded tables.
