A Program Logic for Abstract (Hyper)Properties
Paolo Baldan, Roberto Bruni, Francesco Ranzato, Diletta Rigo

Abstract
. We introduce APPL (Abstract Program Property Logic), a unifying Hoare-style logic that subsumes standard Hoare logic, incorrectness logic, and several variants of Hyper Hoare logic. APPL provides a principled foundation for abstract program logics parameterised by an abstract domain, encompassing both existing and novel abstractions of properties and hyperproperties. The logic is grounded in a semantic framework where the meaning of commands is first defined on a lattice basis and then extended to the full lattice via additivity. Crucially, nondeterministic choice is interpreted by a monoidal operator that need not be idempotent nor coincide with the lattice join. This flexibility allows the framework to capture collecting semantics, various classes of abstract semantics, and hypersemantics. The APPL proof system is sound, and it is relatively complete whenever the property language is sufficiently expressive. When the property language is restricted to an abstract domain, the result is a sound abstract deduction system based on best correct approximations. Relative completeness with respect to a corresponding abstract semantics is recovered provided the abstract domain is complete, in the sense of abstract interpretation, for the monoidal operator.

1.
Introduction

Since the seminal work of Hoare
(
Hoare69
)
, program logics have constituted a cornerstone of formal reasoning about program properties. The underlying idea is simple yet effective: Hoare’s logical system for partial correctness formalizes assertions of the form

\langle\mathit{pre}\rangle\,\mathsf{code}\,\langle\mathit{post}\rangle,

meaning that, starting from any state satisfying the precondition
\mathit{pre}
, if the program execution terminates, it will reach a state satisfying the postcondition
\mathit{post}
. The properties of the elementary operations invoked by a program provide the axioms of the logic, while syntax-directed rules enable the compositional derivation of properties for compound programs. A crucial component of the framework is the ability to reason via approximation by strengthening preconditions and weakening postconditions.
Consequently, classical Hoare logic reasons about
over-approximations
of program behaviour and is designed to establish program
correctness
, that is, to prove the absence of undesirable
behaviours.

In recent years, logics based on
under-approximation
have garnered significant attention, following the work of O’Hearn on incorrectness logic
(
OHearn20
)
. These logics aim to prove program
incorrectness
by witnessing the presence of actual bugs rather than certifying their absence. This shift in perspective has spurred the development of various new systems, focusing either exclusively on incorrectness reasoning
(
RDB:LRAPB
;
RaadVO24
)
or on combining correctness and incorrectness within unified frameworks
(
ZDS:OL
;
BGGR21
;
BruniGGR23
;
AscariBG25
)
.

The landscape of program logics has expanded further with the growing interest in
hyperproperties
, as they relate multiple execution traces of the same program. Hyperproperties arise naturally in the analysis of determinism, non-interference, and other security-related concerns. This domain has given rise to dedicated logics and semantic frameworks, including
(
MP:HSFF
;
MP:VBSCH
;
DM:HHL
;
CousotW25
;
ZhangZK024
;
MastroeniP19
)
.

The Problem.

Given the proliferation of program logics, several authors have sought to bring order to this “zoo,” by developing either systematic taxonomies
(
VerschtK25
;
AscariBGL25
;
Cousot24
;
MP:HSFF
)
or unifying frameworks that recover multiple logics as instances
(
ZDS:OL
;
Zil:toplas
;
CousotW25
)
. However, most approaches either neglect abstraction (of properties or hyperproperties) or address it only marginally. Notable exceptions include
(
Cousot24
;
CousotW25
)
, which promote a calculational approach to logic design from semantic definitions, and
(
MP:HSFF
;
DM:HHL
)
, which focus on the definition and abstraction of hypersemantics.
In this work, we address the challenge of devising a single program logic that simultaneously captures many reasoning modalities—correctness, incorrectness, and hyperproperty reasoning—while systematically integrating abstraction in the sense of abstract interpretation
(
CC77
;
cousot21
)
.

Main Contributions.

Our core programming language is a Kleene Algebra with Tests (KAT)
(
KozenKAT
)
, parametric in the choice of elementary commands. The semantics is defined over an
interpretation monoid

(D,\sqsubseteq,\oplus,\operatorname{B})
, comprising a complete lattice
(D,\sqsubseteq)
equipped with a distinguished basis
\operatorname{B}
that generates
D
via joins, and an infinitary monoidal operator
\oplus
satisfying specific distributivity properties with respect to lattice joins. Crucially, non-deterministic choice is interpreted via this monoidal operator
\oplus
, which is notably not required to coincide with the lattice join and need not be idempotent. Command semantics are first defined on the lattice basis
\operatorname{B}
and then extended to the full lattice
D
by additivity. This structure subsumes collecting semantics, a wide range of abstract semantics, and several forms of hypersemantics.

Within this framework, we introduce a Hoare-style logic, denoted
APPL
(Abstract Program Property Logic). Its assertions range over a chosen subset of the semantic lattice, which serves as the property
language. The proof system supports the derivation of judgments of the form

\vdash\langle h\rangle\ \mathsf{r}\ \langle k\rangle
,
where
\mathsf{r}
is a program and
h,k
are behavioural properties. As in standard Hoare logic, such a judgment expresses that whenever execution starts in a configuration satisfying the precondition
h
, the postcondition
k
is an admissible approximation (according to the lattice order) of the configurations reachable after executing
\mathsf{r}
.
The logic is sound by construction and is relatively complete whenever the property language is sufficiently expressive, in particular, when it is
extensional
, namely, it contains all elements of the interpretation monoid.

By suitably instantiating the parameters of the framework—the complete lattice
D
, the monoidal operator
\oplus
, and the basis
\operatorname{B}
—we recover several well-known logics. Classical Hoare logic is obtained by taking
D=\wp({\mathit{States}})
ordered by subset inclusion, with
\oplus=\cup
and an arbitrary basis. Hyper Hoare logics in the style of Dardinier and Müller
(
DM:HHL
)
arise by setting
D=\wp({\wp({\mathit{States}})})
ordered by inclusion, with a suitable hyperproperty operation
\oplus
, and a basis of irreducible hypersets
\{X\}
, for
X\in\wp({\mathit{States}})
.
As a further instance, incorrectness logic in the style of O’Hearn
(
OHearn20
)
is recovered
by adopting the standard powerset lattice but reversing the order,
that is, taking
(\wp({\mathit{States}}),\supseteq)
, and using the entire
\wp({\mathit{States}})
as the basis.
Furthermore, our framework accommodates various
abstract domains, yielding Hoare-style logics for abstract semantics, a problem highlighted by Cousot et al.
(
CCLB:AIFR
)
for its
inherent difficulty. In our setting, the choice of the join basis (which is irrelevant for standard Hoare logic) plays a pivotal role in controlling the degree of approximation in the abstract domain.

A key insight of our approach is that restricting the logical language
\mathcal{L}
constitutes a form of abstraction.
If the strongest postcondition for a given precondition
h
and program

\mathsf{r}
is not expressible in
\mathcal{L}
, soundness ensures that only an over-approximation (a sound abstraction) is derived.
When
\mathcal{L}
corresponds to an abstract domain
A
, this yields a deduction system grounded in best correct approximations as defined in abstract interpretation
(
CC77
)
. While such a system is always sound, we show that if
A
is
complete
with respect to
\oplus
(in the sense of
(
GRS00
)
), the induced program logic is also relatively complete with respect to a suitable abstract semantics.

Finally, since our framework naturally encompasses hyperproperties and provides a principled notion of abstraction, it offers new tools for the challenging task of abstracting hyperproperties, supporting
both existing and novel abstractions in this setting.

Illustrative Examples.

We show the versatility of
APPL
over three distinct settings: hyperproperties, abstraction,
and incorrectness.

The first example mirrors the motivating case for Hyper Hoare Logic
(
DM:HHL
)
.
When reasoning about hyperproperties, i.e., sets of state properties,
we can derive triples such as:

\displaystyle\langle\{\{x/0\},\{x/2\}\}\rangle\,\textbf{if~}\mathit{rnd}\textbf{~then~}x:=x+1\,\langle\{\{x/0,x/1\},\{x/2,x/3\}\}\rangle

where
\mathit{rnd}
is a random expression.
Notably, the derivation is precise: the hyper postcondition
captures the exact correlation and
is not over-approximated
by spurious cross-products such as
\{x/0,x/3\}
and
\{x/1,x/2\}
that mix outcomes from separate initial cases.

In
abstract interpretation,
APPL

can achieve better precision by supporting
disjunctive reasoning on suitable basis, akin to trace partitioning abstraction
(
RivalM07
)
.
For example,
APPL
can express unreachability properties that standard interval analysis misses:

\displaystyle\langle x\in[\text{-}1,1]\rangle\big(\textbf{if}~x<0~\textbf{then}~x:=\text{-}1~\textbf{else}~x:=1\big);\textbf{assert}(x=0)\langle\varnothing\rangle

Deriving the postcondition
\varnothing
proves
that the exit point is unreachable given the precondition
x\in[-1,1]
.
Standard interval analysis would merge the branches to
[-1,1]
, failing to prove that
x\neq 0
.

For under-approximated reasoning, we reverse the order of the interpretation monoid from subset inclusion to superset inclusion.

This allows us to derive triples such as:

\displaystyle\langle x<0\rangle\ \textbf{if}~y<0~\textbf{then}~x:=0\ \langle y<0\wedge x=0\rangle

This asserts that starting from a state where
x<0
, it is impossible for the execution to terminate with
x=0
unless the branch condition
y<0
also holds.
Here, path conditions (i.e.,
y<0
) are accumulated in the postcondition to guarantee reachability.

2.
Semantic Model

2.1.
Background

We let
\mathcal{K}
denote the class of cardinal numbers.
Posets are denoted as
(D,\sqsubseteq)
, with join and meet of a subset
X\subseteq D
denoted by
\sqcup X
and
\sqcap X
, resp., when they exist.
The down closure of a subset
X\subseteq D
is defined as
\mathord{\downarrow}X\triangleq\{d\in D\mid\exists x\in X.\,d\sqsubseteq x\}
.
If join and meet exist for any subset
X\subseteq D
, then
D
is a complete lattice and

\bot
and
\top
denote its bottom and top elements, resp.

Let
(D,\sqsubseteq)
be a complete lattice. A (
join
)

basis
for
D
is a subset
\operatorname{B}\subseteq D
such
that each
d\in D
is the join of the
basis elements below
d
, i.e.,
d=\sqcup\operatorname{B}{\!(d)}
, where

\operatorname{B}{\!(d)}\triangleq\left\{b\in\operatorname{B}\mid b\sqsubseteq d\right\}
.
The basis
\operatorname{B}
is called
pointed
if
\bot\in\operatorname{B}
.
Clearly,
\operatorname{B}
is a basis if and only if
\operatorname{B}\cup\left\{\bot\right\}
is a basis.
Any complete lattice
D
admits a trivial basis consisting of
D
itself.
It is interesting to consider minimal bases including elements that cannot be further
decomposed through joins. Thus, recall that
d\in D
is completely join-irreducible if, for any subset
X\subseteq D
,
d=\sqcup X
implies
d\in X
. The subset of these irreducible
elements is denoted by
\operatorname{Irr}({D})
and we write
\operatorname{Irr}_{\!\scriptscriptstyle\bot\!}({D})
for
\operatorname{Irr}({D})\cup\left\{\bot\right\}
.
Since any basis must contain
\operatorname{Irr}({D})
, if
\operatorname{Irr}({D})
forms a basis itself, it is the unique minimal basis for
D
, called the
irreducible basis
of
D
.
We will rely on the following notions of density and cardinal weight.

Definition 2.1 (Dense subset).

Let
D
be a complete lattice with a basis
\operatorname{B}
. A
subset
X\subseteq D
is
dense
(wrt
\operatorname{B}
) if
for every
b\in\operatorname{B}
such that

b\sqsubseteq\sqcup X
, there exists
x\in X
with

b\sqsubseteq x
.
\lozenge

Definition 2.2 (Weight wrt a Basis).

Let
D
be a complete lattice with a basis
\operatorname{B}
.
The

weight
of an element
d\in D
wrt the basis

\operatorname{B}
is defined as
w(d)\triangleq\min\{|Y|\mid Y\subseteq\operatorname{B}{\!(x)},\,\mathord{\downarrow}{Y}=\mathord{\downarrow}{\operatorname{B}{\!(d)}\}}
.
The notation extends to sets
X\subseteq D
by letting
w(X)\triangleq\sup\left\{w(d)\mid d\in X\right\}
.

\lozenge

A
complete monoid

(
Krob87
;
Kar04
)
is a structure

(M,\oplus)
where
\oplus
is an
infinitary sum operation that maps each indexed family
\{m_{i}\}_{i\in I}
of elements of
M
,
with
I
arbitrary index set, to

\bigoplus_{i\in I}m_{i}\in M
so that:

(i)

\bigoplus_{i\in\left\{j\right\}}m_{i}=m_{j}
,

(ii)

for any partition

(I_{j})_{j\in J}
of the index set
I
,

\textstyle\bigoplus_{i\in I}m_{i}=\bigoplus_{j\in J}(\bigoplus_{i\in I_{j}}m_{i})\,.

Property (
ii
) is an infinitary form of associativity,
that entails infinitary commutativity and the existence of a neutral element for
\oplus
,
namely
0_{\oplus}\triangleq\bigoplus_{i\in\varnothing}m_{i}\in M
.
We will write
m_{1}\oplus\cdots\oplus m_{n}
instead of
\bigoplus_{j\in[1,n]}m_{j}
and
\bigoplus_{\mathbb{N}}m
for the sum of countably many
m
.

Given
S\subseteq M
, we denote by
S^{\oplus}
the least complete
submonoid including
S
, which is
the complete submonoid generated by
S
.

An
ordered complete monoid
is a structure
(M,\sqsubseteq,\oplus)
such that
(M,\oplus)
is a complete monoid and
(M,\sqsubseteq)
is a poset such that
\oplus
is monotone, i.e.,
given indexed families
\{m_{i}\}_{i\in I}
and
\{n_{i}\}_{i\in I}
of elements of
M
, if
m_{i}\sqsubseteq n_{i}
for all
i\in I
, then
\bigoplus_{i\in I}m_{i}\sqsubseteq\bigoplus_{i\in I}n_{i}
.

Definition 2.3 (
\kappa
-Quantale).

Given a cardinal number
\kappa\in\mathcal{K}
, an (
infinitary non-strict
)
\kappa
-quantale
is an ordered complete monoid
(M,\sqsubseteq,\oplus)
such that
the poset

(M,\sqsubseteq)
has

\kappa
-joins, i.e., each subset

X\subseteq M
with
|X|\leq\kappa
has the join
\sqcup X
in
(M,\sqsubseteq)
, and for
all
\{x_{i,j}\mid i\in I,j\in J(i)\}
, for
index sets
I
,

(J_{i})_{i\in I}
such that, for all
i\in I
,
0<|J_{i}|\leq\kappa
,
the following
\oplus
-
\sqcup
distributivity law holds:

(1)

\bigoplus_{i\in I}\bigsqcup_{j\in J_{i}}x_{i,j}=\bigsqcup_{\overset{\beta:I\to\bigcup_{i\in I}J_{i}}{\beta(i)\in J_{i}}}\bigoplus_{i\in I}x_{i,\beta(i)}

where
the join in the right-hand side of (
1
) is required to exist, while
joins
\bigsqcup_{j\in J_{i}}x_{i,j}
in the left-hand side exist because

|J_{i}|\leq\kappa
.

\lozenge

Note that a
\kappa
-quantale always includes a bottom element

\bot=\sqcup\varnothing
. Since
\oplus
-
\sqcup
distributivity (
1
) is restricted to
non-empty joins (as
|J_{i}|>0
),
\bot
is not required to act as annihilator for

\oplus
. Note that every ordered complete monoid is trivially a
1
-quantale.

2.2.
Command Syntax

We consider a core programming language of
regular commands
,
parameterised by a set of elementary commands.

Definition 2.4 (Commands).

The syntax of elementary commands
\mathsf{e}\in\mathsf{Elc}
and regular commands
\mathsf{r}\in\mathsf{Reg}
is defined as follows:

\lozenge

\displaystyle\mathsf{Elc}\ni\mathsf{e}

\displaystyle:=\mathsf{0}\mid\mathsf{1}\mid\cdots

\displaystyle\mathsf{Reg}\ni\mathsf{r}

\displaystyle:=\mathsf{e}\mid\mathsf{r};\mathsf{r}\mid\mathsf{r}+\mathsf{r}\mid\mathsf{r}^{*}

We assume that the set of elementary commands includes the
skip
command,
denoted
\mathsf{1}
, and the
diverge
command, denoted
\mathsf{0}
.
In examples, we will utilise assignments
x:=\mathit{exp}

and Boolean filters
b?
, where
\mathit{exp}
represents an arithmetic expression and
b
a Boolean expression.
We write

;
for sequential composition,
+
for nondeterministic choice, and
(\cdot)^{*}
for Kleene star iteration.
We also inductively define
\mathsf{r}^{0}\triangleq\mathsf{1}
and
\mathsf{r}^{i+1}\triangleq\mathsf{r};\mathsf{r}^{i}
, as a shorthand for the sequential composition of a fixed number of copies of
\mathsf{r}
.

Other standard control flow constructs are derived as usual:

\displaystyle\textbf{assert}(b)

\displaystyle\triangleq b?

\displaystyle\textbf{if}~b~\textbf{then}~\mathsf{r}_{1}~\textbf{else}~\mathsf{r}_{2}

\displaystyle\triangleq(b?;\mathsf{r}_{1})+(\neg b?;\mathsf{r}_{2})

\displaystyle\textbf{while}~b~\textbf{do}~\mathsf{r}

\displaystyle\triangleq(b?;\mathsf{r})^{*};\neg b?

2.3.
Command Semantics

Our command semantics is designed to subsume collecting semantics, as well as a broad class of abstract and hyperproperty semantics found in the literature. While interpretation lattices in most applications are lattices of sets, we treat the lattice elements abstractly to accommodate both subset and superset inclusion.
We work with semantic structures that form both ordered complete monoids and complete lattices. The monoidal structure captures nondeterministic choice and models computation, while the lattice structure aggregates results additively through joins. This approach generalises the derivation of collecting and abstract semantics from a basic semantics, since we define the semantics on a suitable join basis and extend it to the entire lattice via joins.

Definition 2.5 (Interpretation monoid).

An
interpretation monoid
is a tuple

(D,\sqsubseteq,\oplus,\operatorname{B})
such that: (i)
(D,\sqsubseteq,\oplus)
is an ordered complete monoid,
(ii)
(D,\sqsubseteq)
is a complete lattice, (iii)
\operatorname{B}
is a pointed basis of
D
, and (iv)
\operatorname{B}^{\oplus}
is a

\kappa_{D}
-quantale where

\kappa_{D}\triangleq w(\operatorname{B}^{\oplus})
.

\lozenge

The weight
\kappa_{D}
is relevant
only in the instantiation of Definition
2.5
to hyperproperties;
in all other cases
\kappa_{D}
is inessential.

Some key examples of interpretation domains are defined below.

Example 2.6 (Irreducible powerset monoid).

Let
X
be any set and consider the complete Boolean lattice

(\wp({X}),\subseteq)
with
\sqcup=\cup
and
\sqcap=\cap
.
The irreducibles are
\operatorname{Irr}({\wp({X})})=\left\{\left\{x\right\}\mid x\in X\right\}
. Then,
\wp({X})
with the pointed basis
\operatorname{Irr}_{\!\scriptscriptstyle\bot\!}({\wp({X})})

and sum
\oplus=\cup
forms an interpretation monoid, referred
to as the
irreducible powerset monoid

(\wp({X}),\subseteq,\cup,\operatorname{Irr}_{\!\scriptscriptstyle\bot\!}({\wp({X})}))
.
In fact,
\operatorname{Irr}_{\!\scriptscriptstyle\bot\!}({\wp({X})})^{\oplus}=\wp({X})
and

(\wp({X}),\subseteq,\cup)
is a
\kappa
-quantale for any

\kappa\in\mathcal{K}
since it has all joins and the
distributivity law (
1
) holds without restrictions.
Hence, in
particular, it is a
\kappa
-quantale for

\kappa=w(\wp({X}))
.

\lozenge

Example 2.7 (Irreducible lattice monoid, Intervals).

By generalising Example
2.6
, if
(D,\leq)

is a complete lattice with the irreducible basis then we
can consider the
irreducible lattice monoid
over
D
by
fixing
\operatorname{B}=\operatorname{Irr}_{\!\scriptscriptstyle\bot\!}({D})
and defining
\oplus\triangleq\vee
,
namely the interpretation monoid
(D,\leq,\vee,\operatorname{Irr}_{\!\scriptscriptstyle\bot\!}({D}))
.
As in Example
2.6
,
\operatorname{Irr}_{\!\scriptscriptstyle\bot\!}({\mathsf{Int}})^{\oplus}=\mathsf{Int}
is a

\kappa
quantale for any
\kappa\in\mathcal{K}
.

As an example, this interpretation monoid can be instantiated to the complete lattice of
integer intervals:

\mathsf{Int}\triangleq\{\left[{l},{u}\right]\mid l\in\mathbb{Z}\cup\{-\infty\},\,u\in\mathbb{Z}\cup\{+\infty\}\ \land\ l\leq u\}\cup\left\{\varnothing\right\}

endowed with the inclusion order, which is a complete lattice with irreducible basis

\operatorname{Irr}({\mathsf{Int}})=\left\{\left[{z},{z}\right]\mid z\in\mathbb{Z}\right\}
.

\lozenge

Example 2.8 (Simple monoid).

Let
(C,\leq,\oplus)
be an ordered complete monoid with

(C,\leq)
a complete lattice. Then, taking the trivial basis, we
always obtain an interpretation monoid
(C,\leq,\oplus,C)
.
In fact, for all
c\in C
, we have
\operatorname{B}{\!(c)}=\mathord{\downarrow}{c}
. Consequently,
w(c)\leq 1
(
w(c)=1
for
c\neq\bot
and
w(\bot)=0
), thus
implying
\kappa_{C}=1
. Hence, Definition
2.5

requires the underlying structure to be a
1
-quantale.

In particular,
(C,\leq,\vee,C)
, where
\oplus=\vee
, is an
interpretation monoid that we refer as the
simple monoid
over

D
.

Similarly, reversing the order one still gets an interpretation monoid

(C,\geq,\vee,C)
, called the
dual simple monoid
.

\lozenge

Example 2.9 (Hyper monoid).

Let
(C,\leq)
be a complete lattice with join
\vee
. The powerset lattice
(\wp({C}),\subseteq)
can be seen as an ordered complete monoid by taking the set of singletons as the basis, i.e.,
\operatorname{Irr}_{\!\scriptscriptstyle\bot\!}({\wp({C})})=\left\{\{c\}\mid c\in C\right\}\cup\left\{\varnothing\right\}
, and letting the sum be:

\textstyle\bigoplus_{i\in I}X_{i}\triangleq\left\{\bigvee_{i\in I}x_{i}\ \middle|\ \forall i\in I.\,x_{i}\in X_{i}\right\}\,.

This is the analogous of the
\otimes
operation on hyper-assertions in
(
DM:HHL
)
.
Observe that the monoid operation is closed over the basis, i.e.,

Instances

We present several instantiations of the interpretation monoid, each giving rise to a corresponding semantics.

2.4.1.
Inductive Semantics

Given a generic complete lattice
(C,\leq)
, the standard inductive semantics of regular commands over

(as seen in, e.g.,
(

;

;

;

)
) can be recovered as a direct instance of Definition
2.11
using the simple monoid

(see Example

In this setting, the join extension is redundant because the basis decomposition is simply
\operatorname{B}{\!(c)}=\mathord{\downarrow}{c}

\llparenthesis\mathsf{r}\rrparenthesis
(Lemma

(

\llbracket{\mathsf{e}}\rrbracket c=\llparenthesis\mathsf{e}\rrparenthesis c

\llbracket{\mathsf{r}_{1};\mathsf{r}_{2}}\rrbracket c=\llbracket{\mathsf{r}_{2}}\rrbracket(\llbracket{\mathsf{r}_{1}}\rrbracket c)

\llbracket{\mathsf{r}_{1}+\mathsf{r}_{2}}\rrbracket c=(\llbracket{\mathsf{r}_{1}}\rrbracket c)\vee(\llbracket{\mathsf{r}_{2}}\rrbracket c)

\llbracket{\mathsf{r}^{*}}\rrbracket c=\bigvee_{i\geq 0}\llbracket{\mathsf{r}^{i}}\rrbracket c

We consider an imperative language with integer variables

2.4.3.
Semantics for Incorrectness Logic

To obtain an incorrectness logic in the style of
(

)

Note that

In this setting, Definition

It is worth noting that this semantics is non-strict,

Finally, we remark that while incorrectness logic

2.4.5.
Collecting Hypersemantics

The
collecting hypersemantics
is defined by applying the hyper monoid construction (Example
2.9
) over the concrete domain
(\wp({\Sigma}),\subseteq)
.
The resulting interpretation monoid is

(\wp({\wp({\Sigma})}),\subseteq,\oplus,\operatorname{Irr}_{\!\scriptscriptstyle\bot\!}({\wp({\wp({\Sigma})})}))
,
whose basis is the set of hyper singletons:

\operatorname{Irr}_{\!\scriptscriptstyle\bot\!}({\wp({\wp({\Sigma})})})=\{\{X\}\mid X\in\wp({\Sigma})\}\cup\{\varnothing\}\,.

Observe that the elements
\varnothing
and
\{\varnothing\}
in

\operatorname{Irr}_{\!\scriptscriptstyle\bot\!}({\wp({\wp({\Sigma})})})
play distinct roles:
\varnothing

is the bottom element of the lattice, whereas
\{\varnothing\}
is the
neutral element for
\oplus
.

For
\mathsf{e}\in\mathsf{Elc}
and a basis element
\{X\}\in\operatorname{Irr}_{\!\scriptscriptstyle\bot\!}({\wp({\wp({\Sigma})})})
, the semantics is defined via the strongest postcondition:

\llparenthesis\mathsf{e}\rrparenthesis(\{X\})\triangleq\{\mathrm{post}({\mathsf{e}})(X)\}\,.

Since the underlying lattice is completely meet-distributive and the basis consists of irreducibles, the full semantics
\llbracket{\mathsf{r}}\rrbracket
, defined as additive extension, acts pointwise on the set of properties.
By Lemma
2.13
(
3
), for any
\mathsf{r}\in\mathsf{Reg}
and hyperproperty
H\in\wp({\wp({\Sigma})})
:

\llbracket{\mathsf{r}}\rrbracket H=\{\mathrm{post}({\mathsf{r}})(X)\mid X\in H\}\,.

This construction extends to any complete lattice
(C,\leq)
equipped with an inductive semantics
\llbracket{\cdot}\rrbracket_{\imath\scriptscriptstyle(C)}
(as defined in §
2.4.1
).
By replacing
(\wp({\Sigma}),\subseteq)
with
(C,\leq)
, and defining the elementary semantics on basis elements as
\llparenthesis\mathsf{e}\rrparenthesis(\{c\})\triangleq\{\llbracket{\mathsf{e}}\rrbracket_{\imath\scriptscriptstyle(C)}c\}
, we obtain a generalized hypersemantics where, for
H\in\wp(C)
:
\llbracket{\mathsf{r}}\rrbracket H=\{\llbracket{\mathsf{r}}\rrbracket_{\imath\scriptscriptstyle(C)}c\mid c\in H\}
.

3.
The Program Logic
APPL

We introduce an Abstract Program Property Logic, called
APPL
, which serves as a general unifying framework for reasoning about regular commands in terms of pre- and postconditions.
Abstract program properties range over a fixed language
\mathcal{L}
and logical judgements take the form of triples
\langle h\rangle\ \mathsf{r}\ \langle k\rangle
, where
h,k\in\mathcal{L}
.
The intended validity condition
of such a judgment is that
\llbracket{\mathsf{r}}\rrbracket h\sqsubseteq k
.
The resulting logical system is always sound and, whenever the assertion language
\mathcal{L}
is sufficiently expressive, also relatively complete.
The framework subsumes basic Hoare logic for state properties
and Hoare-style logics for hyperproperties.
Although the logic is designed in terms of over-approximation,
via the order
\sqsubseteq
, it is flexible enough to support under-approximate reasoning as well.
In fact, we show that incorrectness logic is a suitable instance of
APPL
.

We assume that the full semantics (Definition

(D,\sqsubseteq,\oplus,\operatorname{B})

\mathcal{L}\subseteq D

An
APPL

triple

,
where
h,k\in\mathcal{L}
and
\mathsf{r}\in\mathsf{Reg}
.
Such a triple is
valid
if

\llbracket{\mathsf{r}}\rrbracket{h}\sqsubseteq k
.
