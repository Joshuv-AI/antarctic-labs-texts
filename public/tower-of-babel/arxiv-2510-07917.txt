Abstract
. We consider several variants of Baumgartner’s axiom for ℵ 1 \aleph_{1} -dense sets defined on the Baire and Cantor spaces in terms of Lipschitz functions with respect to the usual metric. A variation of Baumgartner’s original argument shows that these variants are consistent. However, unlike in the case of the classical 𝖡𝖠 \mathsf{BA} , we are able to give many applications for which the corresponding fact for linear orders is open. In particular we show that there are provable implications from the ω ω \omega^{\omega} variants to the 2 ω 2^{\omega} variants and that some of these principles imply all the cardinals in the Cichoń’s diagram are large. We also show, similar to (but not the same as) 𝖡𝖠 \mathsf{BA} , that none of the Lipschitz variants follow from a large fragment of 𝖬𝖠 \mathsf{MA} .

Some Basics on Lipschitz and Isometries of Baire and Cantor Spaces

Here we collect some facts about isometries and Lipschitz functions on Baire and Cantor space that we will use throughout the text. Most of these are presumably known though we struggled to find citations so we include (sketches of) proofs for completeness. No attempt has been made to work in further generality than
\omega^{\omega}
and
2^{\omega}
as we aim to not distract. To be clear, the metric on
\omega^{\omega}
is defined by
d(x,y)=\frac{1}{2^{k}}
where
k
is least with
x(k)\neq y(k)
. As
2^{\omega}
can be viewed as a subspace of
\omega^{\omega}

we simply define the metric on
2^{\omega}
as the same
3
3

3

It is also common in the literature to have the metric be
d(x,y)=\frac{1}{k+1}
where
k
is as above. The choice here makes no difference in what we will do. The only point is that the longer sequences agree, the closer they are together.
. In practice this means a function
f:\omega^{\omega}\to\omega^{\omega}
(or
f:2^{\omega}\to 2^{\omega}
) is
Lipschitz
(with Lipschitz constant
1
) if for all
k<\omega
we have that if
x\upharpoonright k=y\upharpoonright k
then
f(x)\upharpoonright k=f(y)\upharpoonright k
. It is an
isometry
if the above is an if and only if i.e. for all
k<\omega
we have that
x\upharpoonright k=y\upharpoonright k
if and only if
f(x)\upharpoonright k=f(y)\upharpoonright k
.

As we will be working with both
\omega^{\omega}
and
2^{\omega}
and many of the basic lemmas hold mutandis mutatis for either of them we will state them for arbitrary spaces of the form
X^{\omega}
where
|X|\leq\aleph_{0}
and the topology is generated by the basic opens of the form
[s]:=\{x\in X^{\omega}\;|\;s
is an initial segment of

for

. For the rest of this section fix a countable set

as above. Given
s,y\in X^{<\omega}
denote by

if and only if
s
is an initial segment of
t
. Note that this means that
[s]\supseteq[t]
. Finally recall that a

T\subseteq X^{<\omega}
is a set which is downwards
\lhd

. The set of

through a tree

Definition 2.1
.

Let
T
and
S
be trees. A function
g:T\to S
is a
homomorphism
if the following two conditions hold.

(1)

g
is
level preserving
i.e.
|s|=|g(s)|
for all
s\in T
.

(2)

g
is

i.e. if
s\lhd t
then
g(s)\lhd g(t)
.

Note that if
T
is a tree and

is a homomorphism then the image of

must be again a tree (of cofinal height). The first observation we need is that homomorphisms of
X^{<\omega}
(treated as a tree itself) are effectively the same as Lipschitz functions on
X^{\omega}
.

Lemma 2.2
.

(1)

If
f:X^{\omega}\to X^{\omega}
is a Lipschitz, then the function
\tilde{f}:X^{<\omega}\to X^{<\omega}
defined by
\tilde{f}(s)=t
if and only if there is an
x\in[s]
so that
f(x)\in[t]
with
|s|=|t|
is well defined and is a homomorphism of
X^{<\omega}
.

(2)

If
\tilde{f}:X^{<\omega}\to X^{<\omega}
is a homomorphism then it induces a unique Lipschitz function
f:X^{\omega}\to X^{\omega}
so that for all
k<\omega
and all
x\in X^{\omega}
we have that
f(x)\upharpoonright k=\tilde{f}(x\upharpoonright k)
.

Proof.

Suppose
f
is Lipschitz. Then for each
x,y\in X^{\omega}
and
k<\omega
we have that
f(x)\upharpoonright k=f(y)\upharpoonright k
if
x\upharpoonright k=y\upharpoonright k
hence the map
\tilde{f}:X^{<\omega}\to X^{<\omega}
defined by
\tilde{f}(t)=s
if and only if there is an
x\in X^{\omega}
with
t\supset x
and
s=f(x)\upharpoonright|t|
is well defined. Moreover it is easily verified that it has the properties claimed.

Conversely if we have a function
\tilde{f}
which is order and level preserving then define

to be
\bigcup_{k<\omega}\tilde{f}(x\upharpoonright k)
. Again it’s easy to see that it has the advertised properties.
∎

Next we need to know how to lift Lipschitz functions from from small domains to larger ones.

Lemma 2.3
.

Suppose
A\subseteq X^{\omega}
and let
f:A\to X^{\omega}
be Lipschitz. Then
f
uniquely lifts to a (Lipschitz) function
\hat{f}:\bar{A}\to X^{\omega}
where
\bar{A}
denotes the closure of
A
. In particular a Lipschitz function on a dense subset of
X^{\omega}
lifts uniquely to a Lipschitz function on the entire
X^{\omega}
.

Proof.

The point is that the homomorphism determined by
f
is in fact defined on the tree of finite sequences extending to elements of
A
, whose set of branches is simply the closure of
A
. More concretely, let
f:A\to X^{\omega}
be Lipschitz. If
a\in\bar{A}
then there is a sequence
\{a_{n}\}_{n<\omega}\subseteq A
so that for all
n<\omega
we have that
a\upharpoonright n=a_{n}\upharpoonright n
. Fix one and define
\hat{f}(a)
to be the unique
b
so that
b\upharpoonright n=f(a_{n})\upharpoonright n
. Note that the Lipschitz property implies that this is well defined since
a_{m}\upharpoonright n=a_{n}\upharpoonright n
for
m>n
and is moreover independent of the choice of
\{a_{n}\}_{n<\omega}
since by Lemma
2.2
we only need the first
n
bits of
a_{n}
to define the map. The last thing to check is that this is indeed a Lipschitz function on
\bar{A}
. To see this, suppose
a,b\in\bar{A}
and
k<\omega
is such that
a\upharpoonright k=b\upharpoonright k
. There are in
A
elements
a^{\prime},b^{\prime}\in A
so that
a^{\prime}\upharpoonright k=a\upharpoonright k
and
b^{\prime}\upharpoonright k=b\upharpoonright k
. We have that
\hat{f}(a)\upharpoonright k=f(a^{\prime})\upharpoonright k=f(b^{\prime})\upharpoonright k=\hat{f}(b)\upharpoonright k
as needed.

∎

Lemma 2.4
.

Suppose
A,B\subseteq X^{\omega}
and let
f:A\to B
be a surjective isometry (and therefore a bijection from
A
to
B
). Then there is a unique isometry
\hat{f}:\bar{A}\to\bar{B}
. In particular isometric bijections between dense sets lift to isometric (and hence homeomorphic) maps from
X^{\omega}\to X^{\omega}
.

Proof.

The map
\hat{f}
is exactly as defined in the previous paragraph. Let us check that it is a bijection and both it and its inverse are also isometries. We start by checking that it is injective. Suppose that
a,b\in\bar{A}
are distinct. Let
k<\omega
be such that
a\upharpoonright k\neq b\upharpoonright k
. By the way that
\hat{f}
was defined this means that there are
a_{k},b_{k}\in A
so that
a_{k}\upharpoonright k=a\upharpoonright k
and
b_{k}\upharpoonright k=b\upharpoonright k
. Since
f
is an isometry we have that
\hat{f}(a)\upharpoonright k=f(a_{k})\upharpoonright k\neq f(b_{k})\upharpoonright k=\hat{f}(b)\upharpoonright k
and hence
\hat{f}(a)\neq\hat{f}(b)
.

For surjectivity suppose that
b\in\bar{B}
and let
\{b_{k}\}_{k<\omega}\subseteq B
be a sequence converging to
b
with
b\upharpoonright k=b_{k}\upharpoonright k
. Since
f
is surjective there are
\{a_{k}\}_{k<\omega}\subseteq A
so that
f(a_{k})=b_{k}
for all
k<\omega
. Now if
j>k
we have that
b_{j}\upharpoonright k=b_{k}\upharpoonright k
and, since
f
is an isometry therefore
a_{j}\upharpoonright k=a_{k}\upharpoonright k
and consequently
\{a_{k}\}_{k<\omega}
is a Cauchy sequence. Thus there is an
a=\lim_{k\to\infty}a_{k}
. Now observe though that
\hat{f}(a)=b
by the way the lift was defined.

Proving that both
\hat{f}
and its inverse are isometries is a straightforward generalization of the observation that
\hat{f}
is Lipschitz in the case of Lemma
2.3
. Indeed fix
a,a^{\prime}\in\bar{A}
with sequences
\{a_{k}\}_{k<\omega}
and
\{a_{k}^{\prime}\}_{k<\omega}
in

so that for all

we have
a\upharpoonright j=a_{j}\upharpoonright j
and
a^{\prime}\upharpoonright j=a_{j}^{\prime}\upharpoonright j
. Then for all
k<\omega
we have
a\upharpoonright k=a^{\prime}\upharpoonright k
if and only if
a_{k}^{\prime}\upharpoonright k=a^{\prime}\upharpoonright k
if and only if
f(a_{k})\upharpoonright k=f(a_{k}^{\prime})\upharpoonright k
if and only if
\hat{f}(a)\upharpoonright k=\hat{f}(a^{\prime})\upharpoonright k
. The case of the inverse is identical.
∎

Remark 1
.

A subtle though important point here is that we do not in general assume isometries to be surjective. For instance the map

Claim 2.6

There is a
