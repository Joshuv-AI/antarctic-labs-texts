A new lower bound for multi-color discrepancy with applications to fair division
Ioannis Caragiannis, Kasper Green Larsen, Sudarshan Shyam

Abstract
. A classical problem in combinatorics seeks colorings of low discrepancy. More concretely, the goal is to color the elements of a set system so that the number of appearances of any color among the elements in each set is as balanced as possible. We present a new lower bound for multi-color discrepancy, showing that there is a set system with n n subsets over a set of elements in which any k k -coloring of the elements has discrepancy at least OPEN Ω ​ ( n ln ⁡ k CLOSE ) \Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{n}{\ln{k}}}}}\right) . This result improves the previously best-known lower bound of OPEN Ω ​ ( n k CLOSE ) \Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{n}{k}}}}\right) of Doerr and Srivastav (2003) and may have several applications. Here, we explore its implications on the feasibility of fair division concepts for instances with n n agents having valuations for a set of indivisible items. The first such concept is known as consensus 1 / k 1/k -division up to d d items ( CD d d ) and aims to allocate the items into k k bundles so that no matter which bundle each agent is assigned to, the allocation is envy-free up to d d items. The above lower bound implies that CD d d can be infeasible for OPEN d ∈ Ω ​ ( n ln ⁡ k CLOSE ) d\in\Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{n}{\ln{k}}}}}\right) . We furthermore extend our proof technique to show that there exist instances of the problem of allocating indivisible items to k k groups of n n agents in total so that envy-freeness and proportionality up to d d items are infeasible for OPEN d ∈ Ω ​ ( n k ​ ln ⁡ k CLOSE ) d\in\Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{n}{k\ln{k}}}}}\right) and OPEN d ∈ Ω ​ ( n k 3 ​ ln ⁡ k CLOSE ) d\in\Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{n}{k^{3}\ln{k}}}}}\right) , respectively. The lower bounds for fair division improve the currently best-known ones by Manurangsi and Suksompong (2022) .

1.
Introduction

Allocating indivisible items to agents with valuations for them has been a key problem in
fair division
. The notion of envy-freeness up to one item (EF1), introduced by
Budish (2011)
is a well-established fairness notion today. An allocation of items to agents is EF1 if every agent (weakly) prefers the bundle of items allocated to her to the bundle of items allocated to any other agent after removing one item from the latter. In contrast to the notion of envy-freeness, which is very demanding for indivisible items, EF1 can always be achieved in a number of different ways: via the envy-cycle elimination algorithm of
Lipton et al. (2004)
, the folklore round-robin algorithm, while it is compatible with Pareto-optimality
(
Caragiannis et al., 2019
)
.

A natural generalization of the standard fair division setting with indivisible items assumes that agents with different valuations for a set of items are partitioned into groups. In this setting, an allocation has one bundle per group, and the agent gets value for the items in the bundle allocated to her group. Unfortunately, EF1 allocations may not exist in this setting
(
Kyropoulou et al., 2020
)
. Actually, even the further relaxed notion of envy-freeness up to
d
items (EF
d
) may be infeasible even when
d
is a function of the number of agents and the number of groups.
Manurangsi and Suksompong (2022)
show that even envy-freeness up to
\Omega\mathopen{}\mathclose{{\left(\sqrt{n}/{k^{2}}}}\right)
items can be infeasible for instances with
n
agents partitioned into
k
groups. Non-trivial positive results are also known; EF
d
allocations do exist for
d\in O\mathopen{}\mathclose{{\left(\sqrt{n}}}\right)
in all instances with
n
agents. Notice that this bound does not depend on the number of groups.

Other fairness properties that have been considered for groups of agents include relaxations of proportionality. An allocation of items to agents partitioned into
k
groups is proportional up to
d
items (PROP
d
) if the value that each agent has for the bundle of items allocated to her group together with the
d
most valuable items not allocated to her group is at least
1/k
times her total value for all items. The simplest version of PROP
1
was introduced by
Conitzer et al. (2017)
and is considered for groups of agents by
Manurangsi and Suksompong (2022)
, who prove similar bounds on
d
for the feasibility of PROP
d
allocations with those for EF
d
mentioned above. Another relevant fairness notion is known as consensus
1/k
-division up to
d
items (CD
d
). Here, a partition of the items to
k
bundles is CD
d
for a set of
n
agents with valuations for the items if the values an agent has for any pair of items differ by at most
d
.
Manurangsi and Suksompong (2022)
prove that CD
d
partitions always exist for
d\in O\mathopen{}\mathclose{{\left(\sqrt{n}}}\right)
and may not exist for
d\in\Omega\mathopen{}\mathclose{{\left(\sqrt{n/k}}}\right)
.

In their proofs,
Manurangsi and Suksompong (2022)
exploit several problems and statements from
discrepancy theory
. For example, their lower bound for
CD
d
follows after establishing a connection between
k
-allocations and
k
-colorings of set systems. Given a set system consisting of a universe of elements and a collection of
n
element subsets, a
k
-coloring of the elements has a discrepancy
d
if the number of elements colored with any color in each subset
S
is between
|S|/k-d
and
|S|/k+d
. Intuitively, we may think of the elements of a set system as the items of a corresponding fair division instance. Each set corresponds to a distinct agent with valuation
1
for each item corresponding to an element in her set and valuation
0
for any other item. A
k
-coloring of the elements directly defines an allocation of the items into
k
bundles. Now, the relation between the minimum discrepancy among all
k
-colorings of the set system and the minimum value of
d
for which a
CD
d
allocation exists in the corresponding fair division instance should be clear. The lower bound of
Manurangsi and Suksompong (2022)
on
CD
d
exploits such a relation and follows directly by a lower bound on multi-color discrepancy due to
Doerr and Srivastav (2003)
. Other notions, such as the weighted discrepancy of
2
-colorings, are used by
Manurangsi and Suksompong (2022)
to get upper and lower bounds on
EF
d
and
PROP
d
.

1.1.
Our contribution

In this paper, we improve the bounds on
d
for which CD
d
partitions and EF
d
and PROP
d
allocations may not exist. Our new bounds are
\Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{n}{\ln{k}}}}}\right)
,
\Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{n}{k\ln{k}}}}}\right)
, and
\Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{n}{k^{3}\ln{k}}}}}\right)
and apply even to instances with binary agent valuations. For instances with
n_{h}
agents in group
h\in[k]
, we also have another lower bound of
d\in\Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{\min\{n_{1},n_{2},...,n_{k}\}}{\ln k}}}}\right)
for
PROP
d
. For CD
d
, we exploit the relation of CD
d
partitions on instances with binary valuations with
k
-colorings in set systems that have discrepancy
d
. So, our new lower bound for CD
d
follows directly by a new lower bound of
\Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{n}{\ln{k}}}}}\right)
on multi-color discrepancy. This improves the twenty-year-old bound of
\Omega\mathopen{}\mathclose{{\left(\sqrt{n/k}}}\right)
by
Doerr and Srivastav (2003)
and may have applications to other areas as well. In our proof, we define a probability distribution over set systems with
n
subsets over an appropriately defined collection of elements and show that the probability that no
k
-coloring has discrepancy at most
d
in all sets of the set system returned by the distribution is less than
1
. This probabilistic argument implies that there exists a set system (one of those in the support of the distribution) for which any
k
-coloring has discrepancy more than
d
.

In contrast to the approach of
Manurangsi and Suksompong (2022)
, our lower bounds for EF
d
and PROP
d
do not follow by applying bounds from discrepancy theory as black boxes. Instead, adapting our construction and proof for our multi-color discrepancy lower bound, we prove that there exist instances with
n
agents partitioned into
k
groups and having binary valuations for a set of items, so that any allocation of the items to the
k
groups is not EF
d
or PROP
d
for the values of
d
claimed above.

1.2.
Further related work

Existing work on fair division concepts for groups of agents has focused on relaxations of envy-freeness. The results of
Manurangsi and Suksompong (2022)
on EF
d
improve considerably previous ones by
Kyropoulou et al. (2020)
and
Segal-Halevi and Suksompong (2019)
.
Manurangsi and Suksompong (2017)
study EF
d
for groups of agents, assuming that the values are drawn independently from a common probability distribution. Consensus
1/k
-division up to
d
items generalizes and relaxes the consensus halving problem (e.g., see
Alon (1987)
;
Simmons and Su (2003)
) from two groups and divisible items to multiple groups and indivisible items. Different fairness notions that involve groups of agents in their definitions are studied by
Conitzer et al. (2019)
and
Aziz and Rey (2020)
.

The rich literature on discrepancy theory is the topic of several books, e.g., see
(
Chazelle, 2000
;
Matousek, 1999
;
Chen et al., 2014
)
. Classical bounds on the discrepancy of
2
-colorings of set systems follow by the seminal work of
Alon and Spencer (2000)
and
Spencer (1985)
. Extensions to multi-colorings are considered by
Doerr and Srivastav (2003)
. The problem is equivalent to coloring the nodes of a hypergraph so that all colors are used approximately the same number of times in each hyperedge. In the discrepancy theory literature, bounds on
2
- or multi-color discrepancy are expressed in terms of the number of nodes, the number of hyperedges, and the number of colors. Here, we aim to bound the minimum multi-color discrepancy using only the number of sets (i.e., hyperedges) and colors as parameters.
Manurangsi and Suksompong (2022)
explain how existing discrepancy theory results can be expressed under this terminology, yielding the currently best upper and lower bounds of
O(\sqrt{n})
and
\Omega\mathopen{}\mathclose{{\left(\sqrt{n/k}}}\right)
, respectively.

1.3.
Roadmap

The rest of the paper is structured as follows. We present formal definitions of the notions we study in Section
2
. The lower bound for multi-color discrepancy and its implication to consensus
1/k
-division up to
d
items is presented in Section
3
. The lower bounds for EF
d
and PROP
d
are presented in Section
4
. We conclude in Section
5
.

A lower bound for multi-color discrepancy

\frac{|S_{i}|}{k}\leq\frac{m}{2k}
, we have

\displaystyle\mathopen{}\mathclose{{\left|\mathopen{}\mathclose{{\left|\chi^{-1}(h_{2})}}\right|-\frac{|S_{i}|}{k}}}\right|=\mathopen{}\mathclose{{\left|\chi^{-1}(h_{2})}}\right|-\frac{|S_{i}|}{k}>d.

Both cases imply a discrepancy higher than
d
for coloring
\chi
.
∎

We now bound the probabilities of the events defined above. Specifically, we prove the following lemma.

Lemma 0.

For every
i\in[n-1]
,
h\in[k]
it holds

\displaystyle\Pr\mathopen{}\mathclose{{\left[\overline{\mathcal{E}_{i,h_{1}}}}}\right]<\exp(-\exp(-48)).

Proof.

Notice that the random variable
\mathopen{}\mathclose{{\left|\chi^{-1}(h)\cup S_{i}}}\right|
follows the binomial probability distribution
\mathcal{B}(|\chi^{-1}(h)|,1/2)
with
|\chi^{-1}(h)|
trials and success probability
1/2
per trial.
For
i\in[n-1]
and
h\in\{1,2,...,\lfloor k/2\rfloor\}
, we have

\displaystyle\Pr[\mathcal{E}_{i,h}]

\displaystyle=\Pr\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left|\chi^{-1}(h)\cup S_{i}}}\right|<\frac{m}{2k}-d}}\right]

\displaystyle\geq\Pr\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left|\chi^{-1}(h)\cup S_{i}}}\right|<\frac{\mathopen{}\mathclose{{\left|\chi^{-1}(h)}}\right|}{2}-\frac{3d}{2}}}\right]

(2)

\displaystyle\geq\exp\mathopen{}\mathclose{{\left(-\frac{81}{2}\cdot\frac{d^{2}}{\mathopen{}\mathclose{{\left|\chi^{-1}(h)}}\right|}}}\right).

For
i\in[n-1]
and
h\in\{\lfloor k/2\rfloor+1,...,k\}
, we have

\displaystyle\Pr[\mathcal{E}_{i,h}]

\displaystyle=\Pr\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left|\chi^{-1}(h)\cup S_{i}}}\right|>\frac{m}{2k}+d}}\right]

\displaystyle\geq\Pr\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left|\chi^{-1}(h)\cup S_{i}}}\right|>\frac{\mathopen{}\mathclose{{\left|\chi^{-1}(h)}}\right|}{2}-\frac{3d}{2}}}\right]

(3)

\displaystyle\geq\exp\mathopen{}\mathclose{{\left(-\frac{81}{2}\cdot\frac{d^{2}}{\mathopen{}\mathclose{{\left|\chi^{-1}(h)}}\right|}}}\right).

The first inequality in the derivations of (
2
) and (
3
) follow by the right and left inequality in (
1
) respectively. The second inequality follows by applying the reverse Chernoff bound (Lemma
8
) with
t=|\chi^{-1}(h)|
and
\varepsilon=\frac{3d}{|\chi^{-1}(h)|}
. The next claim justifies that we can indeed do so.

Claim 1.

For
\varepsilon=\frac{3d}{|\chi^{-1}(h)|}
and
t=|\chi^{-1}(h)|
, it holds that
\varepsilon\leq 1/2
and
\varepsilon^{2}\cdot|\chi^{-1}(h)|\geq 6
.

Proof.

By the fact that
d\leq\frac{m}{7k}
and the left inequality in (
1
), we have
6d\leq\frac{m}{k}-d\leq|\chi^{-1}(h)|
, which implies that
\varepsilon=\frac{3d}{|\chi^{-1}(h)|}\leq\frac{1}{2}
. Now, notice that the facts
d=\sqrt{\frac{m}{k}}
and
d\leq\frac{m}{7k}
imply that
d\leq\frac{d^{2}}{7}\leq\frac{d^{2}}{2}
. Using this observation and the right inequality in (
1
), we get
|\chi^{-1}(h)|\leq\frac{m}{k}-d=d^{2}+d\leq\frac{3d^{2}}{2}
. Hence,
\varepsilon^{2}t=\frac{9d^{2}}{|\chi^{-1}(h)|}\geq 6
. The claim follows.
∎

Now, using the left inequality in (
1
), equations (
2
) and (
3
) yield

\displaystyle\Pr[\mathcal{E}_{i,h}]

\displaystyle\geq\exp\mathopen{}\mathclose{{\left(-\frac{81}{2}\cdot\frac{d^{2}}{\frac{m}{k}-d}}}\right)\geq\exp\mathopen{}\mathclose{{\left(-\frac{81}{2}\cdot\frac{7d^{2}k}{6m}}}\right)>\exp\mathopen{}\mathclose{{\left(-48}}\right).

Finally, by the inequality
1-z\leq e^{-z}
for every real
z
, we get

\displaystyle\Pr\mathopen{}\mathclose{{\left[\overline{\mathcal{E}_{i,h}}}}\right]

\displaystyle=1-\Pr\mathopen{}\mathclose{{\left[\mathcal{E}_{i,h}}}\right]<1-\exp(-48)\leq\exp(-\exp(-48)),

as desired.
∎

We are now ready to complete the proof of Theorem
1
. Denote by
\mathcal{D}
the event that coloring
\chi\in X
has discrepancy at most
d
for the random set system. By Lemma
2
, we have

\displaystyle\mathcal{D}

\displaystyle\subseteq\overline{\bigvee_{i\in[n-1]}\mathopen{}\mathclose{{\left(\mathopen{}\mathclose{{\left(\bigvee_{h_{1}\in\{1,...,\lfloor k/2\rfloor\}}\mathcal{E}_{i,h_{1}}}}\right)\wedge\mathopen{}\mathclose{{\left(\bigvee_{h_{2}\in\{\lfloor k/2\rfloor+1,...,k\}}\mathcal{E}_{i,h_{2}}}}\right)}}\right)}

\displaystyle=\bigwedge_{i\in[n-1]}\mathopen{}\mathclose{{\left(\overline{\mathopen{}\mathclose{{\left(\bigvee_{h_{1}\in\{1,...,\lfloor k/2\rfloor\}}\mathcal{E}_{i,h_{1}}}}\right)\wedge\mathopen{}\mathclose{{\left(\bigvee_{h_{2}\in\{\lfloor k/2\rfloor+1,...,k\}}\mathcal{E}_{i,h_{2}}}}\right)}}}\right)

\displaystyle=\bigwedge_{i\in[n-1]}\mathopen{}\mathclose{{\left(\mathopen{}\mathclose{{\left(\overline{\bigvee_{h_{1}\in\{1,...,\lfloor k/2\rfloor\}}\mathcal{E}_{i,h_{1}}}}}\right)\vee\mathopen{}\mathclose{{\left(\overline{\bigvee_{h_{2}\in\{\lfloor k/2\rfloor+1,...,k\}}\mathcal{E}_{i,h_{2}}}}}\right)}}\right)

(4)

\displaystyle=\bigwedge_{i\in[n-1]}\mathopen{}\mathclose{{\left(\mathopen{}\mathclose{{\left(\bigwedge_{h_{1}\in\{1,...,\lfloor k/2\rfloor\}}\overline{\mathcal{E}_{i,h_{1}}}}}\right)\vee\mathopen{}\mathclose{{\left(\bigwedge_{h_{2}\in\{\lfloor k/2\rfloor+1,...,k\}}\overline{\mathcal{E}_{i,h_{2}}}}}\right)}}\right)

Using equation (
4
) and Lemma
2
, we obtain

\displaystyle\Pr[\mathcal{D}]

\displaystyle\leq\Pr\mathopen{}\mathclose{{\left[\bigwedge_{i\in[n-1]}\mathopen{}\mathclose{{\left(\mathopen{}\mathclose{{\left(\bigwedge_{h_{1}\in\{1,...,\lfloor k/2\rfloor\}}\overline{\mathcal{E}_{i,h_{1}}}}}\right)\vee\mathopen{}\mathclose{{\left(\bigwedge_{h_{2}\in\{\lfloor k/2\rfloor+1,...,k\}}\overline{\mathcal{E}_{i,h_{2}}}}}\right)}}\right)}}\right]

\displaystyle=\prod_{i\in[n-1]}\Pr\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left(\mathopen{}\mathclose{{\left(\bigwedge_{h_{1}\in\{1,...,\lfloor k/2\rfloor\}}\overline{\mathcal{E}_{i,h_{1}}}}}\right)\vee\mathopen{}\mathclose{{\left(\bigwedge_{h_{2}\in\{\lfloor k/2\rfloor+1,...,k\}}\overline{\mathcal{E}_{i,h_{2}}}}}\right)}}\right)}}\right]

\displaystyle\leq\prod_{i\in[n-1]}\mathopen{}\mathclose{{\left(\Pr\mathopen{}\mathclose{{\left[\bigwedge_{h_{1}\in\{1,...,\lfloor k/2\rfloor\}}\overline{\mathcal{E}_{i,h_{1}}}}}\right]+\Pr\mathopen{}\mathclose{{\left[\bigwedge_{h_{2}\in\{\lfloor k/2\rfloor+1,...,k\}}\overline{\mathcal{E}_{i,h_{2}}}}}\right]}}\right)

(5)

\displaystyle=\prod_{i\in[n-1]}\mathopen{}\mathclose{{\left(\prod_{h_{1}\in\{1,...,\lfloor k/2\rfloor\}}\Pr\mathopen{}\mathclose{{\left[\overline{\mathcal{E}_{i,h_{1}}}}}\right]+\prod_{h_{2}\in\{\lfloor k/2\rfloor+1,...,k\}}\Pr\mathopen{}\mathclose{{\left[\overline{\mathcal{E}_{i,h_{2}}}}}\right]}}\right).

The second inequality follows by applying the union bound. The last equality follows since for a given
i\in[n-1]
, the events in
\mathopen{}\mathclose{{\left\{\mathcal{E}_{i,h}:h\in\{1,...,\lfloor k/2\rfloor\}}}\right\}
(and, respectively, the events
\mathopen{}\mathclose{{\left\{\mathcal{E}_{i,h}:h\in\mathopen{}\mathclose{{\left\{\lfloor k/2\rfloor+1,...,k}}\right\}}}\right\}
) are mutually independent.
Using the upper bound for
\Pr\mathopen{}\mathclose{{\left[\overline{\mathcal{E}_{i,h}}}}\right]
from Lemma
3
, we finally get

\displaystyle\Pr[\mathcal{D}]

\displaystyle<\mathopen{}\mathclose{{\left(2\cdot\exp\mathopen{}\mathclose{{\left(-\frac{k-1}{2}\cdot\exp(-48)}}\right)}}\right)^{n-1}

\displaystyle\leq\exp\mathopen{}\mathclose{{\left((n-1)\cdot\mathopen{}\mathclose{{\left(-\frac{k-1}{2}\cdot\exp(-48)+1}}\right)}}\right)

\displaystyle\leq\exp\mathopen{}\mathclose{{\left(-(n-1)\cdot\frac{k}{3}\cdot\exp(-48)}}\right)

\displaystyle\leq\exp(-m\ln{k})=k^{-m},

as desired. The first inequality follows by equation (
5
) after observing that each of the sets
\mathopen{}\mathclose{{\left\{1,...,\lfloor k/2\rfloor}}\right\}
and
\mathopen{}\mathclose{{\left\{\lfloor k/2\rfloor+1,...,k}}\right\}
have at least
\frac{k-1}{2}
elements. The second inequality is obvious, the third one follows by the condition
k\geq 3+6e^{48}
, and the fourth one by the definition of
m
.
∎

Using a result of
Manurangsi and Suksompong (2022, Theorem 3.1)
which lower-bounds
CD
(n,k)
by
DISC
(n,k)
, we obtain the following corollary.

Theorem 4.

Let
k\geq 3+6e^{48}
and
n\geq 1+147\cdot e^{48}\ln{k}
be integers. Then, there is a set of
n
agents with valuations for a set of items so that no
k
-allocation of the items is
CD
d
for some
d\in\Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{n}{\ln{k}}}}}\right)
.

4.
Lower bounds for envy-freeness and proportionality

In this section, we prove our lower bounds for
\text{EF}(n_{1},...,n_{k})
(Theorem
1
) and
\text{PROP}(n_{1},...,n_{k})
(Theorem
2
and Theorem
3
).

Theorem 1.

Let
k\geq 2
be an integer and
n\geq k+242\cdot e^{124}k\ln{k}
. Then, for every set of
n
agents, partitioned into
k
non-empty groups, there is a set of items and valuations of the agents for these items so that no allocation is
EF
d
for some
d\in\Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{n}{k\ln{k}}}}}\right)
.

Theorem 2.

Let
k\geq 2
be an integer and
n\geq k+162\cdot e^{77}k\ln{k}
. Then, for every set of
n
agents, partitioned into
k
non-empty groups, there is a set of items and valuations of the agents for these items so that no allocation is
PROP
d
for some
d\in\Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{n}{k^{3}\ln{k}}}}}\right)
.

Theorem 3.

For every set of agents partitioned into
k\geq 4
groups so that the number of agents in each group is at least
1+32e^{96}k^{2}\ln{k}
, there is a set of items and valuations of the agents for these items so that no allocation is
PROP
d
for some
d\in\Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{\min(n_{1},n_{2},\dots,n_{k})}{\ln{k}}}}}\right)
.

We prove Theorems
1
,
2
and
3
using a probabilistic argument that adapts the one we used for multi-color discrepancy in Section
3
. For appropriate parameters
m
and
d
, we will define a valuation profile in which the agent valuations for
m
items are random and will show that the probability that there exists an allocation that is envy-free/proportional up to
d
items is strictly smaller than
1
. This implies that there exists an instance that does not admit an allocation that is envy-free/proportional up to
d
items.

For each group
h\in[k]
, we select a specific agent to be the
leader
of the group. We denote by
L
the set of agents who are group leaders and by
F
the remaining agents. The instance has a set
M
of
m
items. For each item
j\in M
, the group leader
i\in L
has valuation
v_{i}(j)=1
for the item. The valuation
v_{i}(j)
of an agent
i\in F
for item
j\in M
is decided by tossing a fair coin; it is equal to
1
on heads (this happens with probability
1/2
) and equal to
0
on tails. All coin tosses are independent.

4.1.
Proof of Theorem
1

We prove Theorem
1
using the above construction with
m=\mathopen{}\mathclose{{\left\lfloor\frac{n-k}{2e^{124}\ln{k}}}}\right\rfloor
and set
d=\sqrt{\frac{m}{k}}
. Together with the restriction
n\geq k+242\cdot e^{124}k\ln{k}
, these definitions imply that
d\in\Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{n}{k\ln{k}}}}}\right)
. Furthermore, notice that
\sqrt{m/k}\geq 11
and
m\geq 11kd
; these observations will be useful later.

Denote by
\mathcal{A}
the set of allocations
A=(A_{1},A_{2},...,A_{k})
of the items in
M
to
k
bundles so that

(6)

\displaystyle\frac{m}{k}-d

\displaystyle\leq|A_{h}|\leq\frac{m}{k}+d

for every
h\in[k]
. Clearly, an allocation that does not belong to
\mathcal{A}
is not envy-free up to
d
; the condition for
EF
d
would be violated for some agent in
L
. We will show that the random valuation profile is envy-free up to
d
for an allocation
A\in\mathcal{A}
is less than
k^{-m}
. Since there are at most
k^{m}
allocations in
\mathcal{A}
, the probability that some of them is envy-free up to
d
will be strictly less than
1
, completing the proof of Theorem
1
.

For an agent
i\in F
and allocation
A\in\mathcal{A}
, we denote by
\mathcal{E}_{i}(A)
the event defined as

(7)

\displaystyle v_{i}(A_{g(i)})

\displaystyle\geq v_{i}(A_{h})-d

for every
h\in[k]
. The following lemma provides the main argument in our proof.

Lemma 1.

Consider an allocation
A\in\mathcal{A}
and agent
i\in F
. Then,

\displaystyle\Pr[\mathcal{E}_{i}(A)]

\displaystyle<\exp\mathopen{}\mathclose{{\left(-\frac{1}{2}\cdot\exp\mathopen{}\mathclose{{\left(-124}}\right)}}\right).

Proof.

We will focus on two additional events
\mathcal{E}_{i}^{1}(A)
and
\mathcal{E}_{i}^{2}(A)
. Let
h^{*}
be an arbitrary group in
[k]\setminus\{g(i)\}
. Event
\mathcal{E}_{i}^{1}(A)
is true if and only if

(8)

\displaystyle v_{i}(A_{g(i)})

\displaystyle\leq\frac{|A_{h^{*}}|}{2}-\frac{3d}{2}.

Event
\mathcal{E}_{i}^{2}(A)
is true if and only if

(9)

\displaystyle v_{i}(A_{h^{*}})

\displaystyle\geq\frac{|A_{h^{*}}|}{2}.

Set
\varepsilon=\frac{5d}{|A_{g(i)}|}
and notice that

\displaystyle\Pr\mathopen{}\mathclose{{\left[\mathcal{E}_{i}^{1}(A)}}\right]

\displaystyle=\Pr\mathopen{}\mathclose{{\left[v_{i}(A_{g(i)})\leq\frac{|A_{h^{*}}|}{2}-\frac{3d}{2}}}\right]\geq\Pr\mathopen{}\mathclose{{\left[v_{i}(A_{g(i)})\leq\frac{|A_{g(i)}|}{2}-\frac{5d}{2}}}\right]

(10)

\displaystyle=\Pr\mathopen{}\mathclose{{\left[v_{i}(A_{g(i)})\leq\frac{|A_{g(i)}|}{2}(1-\varepsilon)}}\right].

The inequality follows by equations (
6
), which imply that
|A_{h^{*}}|\geq|A_{g(i)}|-2d
.

Now, notice that the random variable
v_{i}(A_{g(i)})
follows the binomial probability distribution
\mathcal{B}(|A_{g(i)}|,1/2)
with
|A_{g(i)}|
trials (one for each item in bundle
A_{g(i)}
) and success probability
1/2
per trial. We will bound the RHS of inequality (
10
) by applying the reverse Chernoff bound (Lemma
8
) with
\varepsilon=\frac{5d}{|A_{g(i)}|}
and
t=|A_{g(i)}|
. The next claim justifies that we can indeed do so.

Claim 2.

For
\varepsilon=\frac{5d}{|A_{g(i)}|}
, it holds
\varepsilon\leq 1/2
and
\varepsilon^{2}\cdot|A_{g(i)}|\geq 6
.

Proof.

Recall that
m\geq 11dk
and
d=\sqrt{m/k}
. Thus, by the left part of equation (
6
), we have
|A_{g(i)}|\geq\frac{m}{k}-d\geq 10d
and
\varepsilon=\frac{5d}{|A_{g(i)}|}\leq 1/2
. Furthermore, by the right part of equation (
6
), we have
|A_{g(i)}|\leq\frac{m}{k}+d\leq\frac{12m/k}{11}
and
\varepsilon^{2}|A_{g(i)}|=\frac{25m}{k|A_{g(i)}|}\geq 275/12>6
.
∎

Thus, by applying Lemma
8
, inequality (
10
) yields

\displaystyle\Pr\mathopen{}\mathclose{{\left[\mathcal{E}_{i}^{1}(A)}}\right]

\displaystyle\geq\exp\mathopen{}\mathclose{{\left(-\frac{9\varepsilon^{2}|A_{g(i)}|}{2}}}\right)=\exp\mathopen{}\mathclose{{\left(-\frac{225d^{2}}{2|A_{g(i)}|}}}\right)\geq\exp\mathopen{}\mathclose{{\left(-\frac{225d^{2}}{2(m/k-d)}}}\right)

(11)

\displaystyle=\exp\mathopen{}\mathclose{{\left(-\frac{225\sqrt{m/k}}{2(\sqrt{m/k}-1)}}}\right)\geq\exp\mathopen{}\mathclose{{\left(-\frac{2375}{20}}}\right)>\exp(-124).

The first inequality follows by the left part of equation (
6
) and the second one follows by the fact
\sqrt{m/k}\geq 11
.

The random variable
v_{i}(A_{h^{*}})
follows the binomial probability distribution
\mathcal{B}(|A_{h^{*}}|,1/2)
with
|A_{h^{*}}|
trials and success probability
1/2
per trial. Thus,

(12)

\displaystyle\Pr\mathopen{}\mathclose{{\left[\mathcal{E}_{i}^{2}(A)}}\right]

\displaystyle\geq 1/2.

Clearly, since the bundles
A_{g(i)}
and
A_{h^{*}}
are disjoint, the valuations of agent
i
for the two bundles are independent. Thus, by inequalities (
11
) and (
12
), we get

(13)

\displaystyle\Pr\mathopen{}\mathclose{{\left[\mathcal{E}_{i}^{1}(A)\wedge\mathcal{E}_{i}^{2}(A)}}\right]

\displaystyle>\frac{1}{2}\cdot\exp\mathopen{}\mathclose{{\left(-124}}\right).

Now, observe that event
\mathcal{E}_{i}(A)
is true only if some of events
\mathcal{E}_{i}^{1}(A)
and
\mathcal{E}_{i}^{2}(A)
is false. Hence,

\displaystyle\Pr[\mathcal{E}_{i}(A)]

\displaystyle\leq 1-\Pr\mathopen{}\mathclose{{\left[\mathcal{E}_{i}^{1}(A)\wedge\mathcal{E}_{i}^{2}(A)}}\right]<1-\frac{1}{2}\cdot\exp\mathopen{}\mathclose{{\left(-124}}\right)\leq\exp\mathopen{}\mathclose{{\left(-\frac{1}{2}\cdot\exp\mathopen{}\mathclose{{\left(-124}}\right)}}\right)

using inequality (
13
) and the property
1-x\leq e^{-x}
for every real
x
.
∎

Now, allocation
A\in\mathcal{A}
is envy-free up to

if the event
\mathcal{E}_{i}(A)
is true for every agent
i\in F
. These events are independent as each of them depends on the random valuations of a different agent in
F
. Thus, by Lemma
4
and since
|F|=n-k
, we have

\displaystyle\Pr\mathopen{}\mathclose{{\left[\bigwedge_{i\in F}{\mathcal{E}_{i}(A)}}}\right]

\displaystyle<\exp\mathopen{}\mathclose{{\left(-\frac{n-k}{2}\cdot\exp\mathopen{}\mathclose{{\left(-124}}\right)}}\right)\leq\exp\mathopen{}\mathclose{{\left(-m\ln{k}}}\right)=k^{-m},

as desired. The second inequality follows by the definition of
m
.

4.2.
Proof of Theorem
2

To prove Theorem
2
, we use our construction above with
m=\mathopen{}\mathclose{{\left\lfloor\frac{n-k}{2e^{77}\ln{k}}}}\right\rfloor
and set
d=\sqrt{\frac{m}{k^{3}}}
. Together with the restriction
n\geq k+162e^{77}k\ln{k}
, these definitions imply that

and, furthermore,

(this fact will be useful later).

Denote by
\mathcal{A}
the set of allocations
A=(A_{1},A_{2},...,A_{k})
of the items in
M
to
k
bundles so that

(14)

\displaystyle|A_{h}|

\displaystyle\geq\frac{m}{k}-d

for every
h\in[k]
. Clearly, an allocation that does not belong to
\mathcal{A}
is not proportional up to
d
items, as the condition for

would be violated for some agent in

. We will show that the probability that the random valuation profile is proportional up to
d
items for an allocation
A\in\mathcal{A}
is at most

. Since there are fewer than
k^{m}
allocations in
\mathcal{A}
, the probability that some of them is proportional up to
d
items will be strictly less than

, completing the proof.

Let
A\in\mathcal{A}
. For an agent
i\in F
, we denote by
\mathcal{E}_{i}(A)
the event defined as

(15)

\displaystyle v_{i}(A_{g(i)})

\displaystyle\geq\frac{1}{k}\cdot\sum_{h\in[k]}{v_{i}(A_{h})}-d.

The following lemma provides the main argument in our proof.

Lemma 2.

Consider the allocation
A\in\mathcal{A}
and agent
i\in F
. Then,

\displaystyle\Pr[\mathcal{E}_{i}(A)]

\displaystyle\leq\exp\mathopen{}\mathclose{{\left(-\frac{1}{2}\cdot\exp\mathopen{}\mathclose{{\left(-77}}\right)}}\right).

Proof.

Since the allocation
A
belongs to
\mathcal{A}
, inequality (

) implies

(16)

\displaystyle|A_{g(i)}|

\displaystyle=m-\sum_{h\in[k]\setminus\{g(i)\}}{|A_{h}|}\leq\frac{m}{k}+(k-1)d.

We will argue about two additional events
\mathcal{E}_{i}^{1}(A)
and
\mathcal{E}_{i}^{2}(A)
. Event
\mathcal{E}_{i}^{1}(A)
is true if and only if

(17)

\displaystyle v_{i}(A_{g(i)})

\displaystyle\leq\frac{|A_{g(i)}|}{2}-2kd.

Event
\mathcal{E}_{i}^{2}(A)
is true if and only if

(18)

\displaystyle\sum_{h\in[k]\setminus\{g(i)\}}{v_{i}(A_{h})}

\displaystyle\geq\frac{m-|A_{g(i)}|}{2},

Set
\varepsilon=\frac{4kd}{|A_{g(i)}|}
and observe that

(19)

\displaystyle\Pr[\mathcal{E}_{i}^{1}(A)]

\displaystyle=\Pr\mathopen{}\mathclose{{\left[v_{i}(A_{g(i)})\leq\frac{|A_{g(i)}|}{2}-2kd}}\right]=\Pr\mathopen{}\mathclose{{\left[v_{i}(A_{g(i)})\leq\frac{|A_{g(i)}|}{2}\cdot(1-\varepsilon)}}\right].

Now, notice that, for agent
i\in F
, the random variable
v_{i}(A_{g(i)})
follows the binomial probability distribution
\mathcal{B}(|A_{g(i)}|,1/2)
with
|A_{g(i)}|
trials (one for each item of bundle
A_{g(i)}
) and success probability

per trial. We will bound the RHS of equation (

) by applying the reverse Chernoff bound (Lemma

) with
\varepsilon=\frac{4kd}{|A_{g(i)}|}
and
t=|A_{g(i)}|
. The next claim justifies that we can indeed do so.

Claim 3.

For
\varepsilon=\frac{4kd}{|A_{g(i)}|}
and
t=|A_{g(i)}|
, it holds that
\varepsilon\leq 1/2
and
\varepsilon^{2}|A_{g(i)}|\geq 6
.

Proof.

Recall that
m\geq 9k^{2}d
and
d=\sqrt{m/k^{3}}
. Thus, by inequality (
14
), we have
|A_{g(i)}|\geq\frac{m}{k}-d\geq 8kd
and
\varepsilon=\frac{4kd}{|A_{g(i)}|}\leq 1/2
. Furthermore, by inequality (
16
), we have
|A_{g(i)}|\leq\frac{m}{k}+(k-1)d\leq\frac{m}{k}+kd\leq\frac{10m}{9k}
and
\varepsilon^{2}t=\frac{16k^{2}d^{2}}{|A_{g(i)}|}\geq\frac{72k^{3}d^{2}}{5m}\geq 6
.
∎

Using inequality (
14
) and the facts
m\geq 9k^{2}d
and

, we have

(20)

\displaystyle|A_{g(i)}|

\displaystyle\geq\frac{m}{k}-d\geq\frac{m}{k}-\frac{m}{9k^{2}}\geq\frac{17m}{18k}.

Now, by applying Lemma
8
and using inequality (
20
), we have

(21)

\displaystyle\Pr[\mathcal{E}_{i}^{1}(A)]

\displaystyle\geq\exp\mathopen{}\mathclose{{\left(-\frac{9\varepsilon^{2}|A_{g(i)}|}{2}}}\right)=\exp\mathopen{}\mathclose{{\left(-\frac{72k^{2}d^{2}}{|A_{g(i)}|}}}\right)\geq\exp\mathopen{}\mathclose{{\left(-\frac{1296k^{3}d^{2}}{17m}}}\right)>\exp(-77).

Also, the random variable
\sum_{h\in[k]\setminus\{g(i)\}}{v_{i}(A_{h})}
follows the binomial probability distribution
\mathcal{B}(m-|A_{g(i)}|,1/2)
with
m-|A_{g(i)}|
trials (one for each item not belonging to bundle
A_{g(i)}
) and success probability
1/2
per trial. Thus,

(22)

\displaystyle\Pr[\mathcal{E}_{i}^{2}(A)]

\displaystyle\geq\frac{1}{2}.

Notice that the valuations of agent
i
for the items in
A_{g(i)}
and
\cup_{h\in[k]\setminus\{g(i)\}}{A_{h}}
are selected independently and, hence, the events
\mathcal{E}_{i}^{1}(A)
and
\mathcal{E}_{i}^{2}(A)
are independent. Thus,

(23)

\displaystyle\Pr[\mathcal{E}_{i}^{1}(A)\wedge\mathcal{E}_{i}^{2}(A)]

\displaystyle\geq\frac{1}{2}\exp\mathopen{}\mathclose{{\left(-77}}\right).

We now claim that if the events
\mathcal{E}_{i}^{1}(A)
and
\mathcal{E}_{i}^{2}(A)
are true, then the event
\mathcal{E}_{i}(A)
is false. Indeed, using the inequalities (
17
) and (
18
), we obtain that

\displaystyle\sum_{h\in[k]\setminus\{g(i)\}}{v_{i}(A_{h})}-(k-1)\cdot v_{i}(A_{g(i)})

\displaystyle\geq\frac{m-|A_{g(i)}|}{2}-(k-1)\cdot\mathopen{}\mathclose{{\left(\frac{|A_{g(i)}|}{2}-2kd}}\right)

\displaystyle=\frac{m}{2}-\frac{k\cdot|A_{g(i)}|}{2}+2k(k-1)d

\displaystyle\geq\frac{m}{2}-\frac{k}{2}\cdot\mathopen{}\mathclose{{\left(\frac{m}{k}+(k-1)d}}\right)+2k(k-1)d

(24)

\displaystyle=\frac{3k(k-1)}{2}d>kd.

The second inequality follows by inequality (
16
) and the third one by the facts
k\geq 2
and
d>0
. Equivalently, equation (
24
) yields

\displaystyle v_{i}(A_{g(i)})

\displaystyle<\frac{1}{k}\cdot\sum_{h\in[k]\setminus\{g(i)\}}{v_{i}(A_{h})}-d,

contradicting the definition of event
\mathcal{E}_{i}(A)
in Equation (
15
). Thus, event
\mathcal{E}_{i}(A)
is true only if some of
\mathcal{E}_{i}^{1}(A)
and
\mathcal{E}_{i}^{2}(A)
is not true, i.e.,

\displaystyle\Pr[\mathcal{E}_{i}(A)]

\displaystyle\leq 1-\Pr[\mathcal{E}_{i}^{1}(A)\wedge\mathcal{E}_{i}^{2}(A)]

\displaystyle\leq 1-\frac{1}{2}\exp\mathopen{}\mathclose{{\left(-77}}\right)

\displaystyle\leq\exp\mathopen{}\mathclose{{\left(-\frac{1}{2}\exp\mathopen{}\mathclose{{\left(-77}}\right)}}\right).

The last inequality follows by the property
1-x\leq e^{x}
for every real
x
. The proof of the lemma is complete.
∎

Now, allocation
A\in\mathcal{A}
is proportional up to
d
items if the event
\mathcal{E}_{i}(A)
is true for every agent
i\in F
. These events are independent as each of them depends on the random valuations of a different agent. Thus, by Lemma
5
and since
|F|=n-k
, we have

\displaystyle\Pr\mathopen{}\mathclose{{\left[\bigwedge_{i\in F}{\mathcal{E}_{i}(A)}}}\right]

\displaystyle<\exp\mathopen{}\mathclose{{\left(-\frac{n-k}{2}\exp\mathopen{}\mathclose{{\left(-77}}\right)}}\right)\leq\exp\mathopen{}\mathclose{{\left(-m\ln{k}}}\right)=k^{-m},

as desired. The second inequality follows by the definition of
m
.

4.3.
Proof of Theorem
3

We prove Theorem
3
using our construction with
m=\mathopen{}\mathclose{{\left\lfloor\frac{(\min\{n_{1},n_{2},...,n_{k}\}-1)k}{2e^{96}\ln{k}}}}\right\rfloor
and set
d=\sqrt{m/k}
. Together with the assumption
\min\{n_{1},n_{2},...,n_{k}\}\geq 1+32e^{96}k^{2}\ln{k}
, this implies
d\leq\frac{m}{4k^{2}}
(and, obviously,
d\leq\frac{m}{4k}
); these facts will be useful later in the proof.

Again, denote by
\mathcal{A}
the set of allocations
A=(A_{1},A_{2},...,A_{k})
of the items in
M
to
k
bundles so that
|A_{h}|\geq m/k-d
for every
h\in[k]
. As argued in the proof of Theorem
2
, no other allocation can be proportional up to
d
items.

Let
A\in\mathcal{A}
. For an agent
i\in F
, we denote by
\mathcal{E}_{i}(A)
the event defined as

(25)

\displaystyle v_{i}(A_{g(i)})

\displaystyle\geq\frac{1}{k}\cdot\sum_{h\in[k]}{v_{i}(A_{h})}-d.

For
h\in[k]
, let
\zeta_{h}\geq 0
be such that

(26)

\displaystyle|A_{h}|

\displaystyle=\frac{m}{k}+\mathopen{}\mathclose{{\left(\zeta_{h}-1}}\right)d.

Clearly, since
\sum_{h\in[k]}{|A_{h}|}=m
, it holds

(27)

\displaystyle\sum_{h\in[k]}{\zeta_{h}}

\displaystyle=k.

Hence,
\zeta_{h}\leq k
for every
h\in[k]
.

The next lemma is crucial for our proof.

Lemma 3.

Consider the allocation
A\in\mathcal{A}
and agent
i\in F
. Then,

\displaystyle\Pr[\mathcal{E}_{i}(A)]

\displaystyle<\exp\mathopen{}\mathclose{{\left(-\frac{1}{2}\exp\mathopen{}\mathclose{{\left(-\frac{6\mathopen{}\mathclose{{\left(3+\zeta_{g(i)}}}\right)^{2}d^{2}k}{m}}}\right)}}\right)

Proof.

We will argue about two additional events
\mathcal{E}_{i}^{1}(A)
and
\mathcal{E}_{i}^{2}(A)
. Event
\mathcal{E}_{i}^{1}(A)
is true if and only if

(28)

\displaystyle v_{i}(A_{g(i)})

\displaystyle\leq\frac{m}{2k}-2d,

while event
\mathcal{E}_{i}^{2}(A)
is true if and only if

(29)

\displaystyle\sum_{h\in[k]\setminus\{g(i)\}}{v_{i}(A_{h})}

\displaystyle\geq\frac{m(k-1)}{2k}-\frac{(k-1)d}{2}.

Using the definition of
\zeta_{g(i)}
and setting
\varepsilon=\frac{(3+\zeta_{g(i)})d}{|A_{g(i)}|}
, we have

\displaystyle\Pr\mathopen{}\mathclose{{\left[\mathcal{E}_{i}^{1}(A)}}\right]

\displaystyle=\Pr\mathopen{}\mathclose{{\left[v_{i(A_{g(i)})}\leq\frac{m}{2k}-2d}}\right]

\displaystyle=\Pr\mathopen{}\mathclose{{\left[v_{i}(A_{g(i)})\leq\frac{|A_{g(i)}|}{2}-\frac{3+\zeta_{g(i)}}{2}d}}\right]

(30)

\displaystyle=\Pr\mathopen{}\mathclose{{\left[v_{i}(A_{g(i)})\leq\frac{|A_{g(i)}|}{2}(1-\varepsilon)}}\right].

Now, notice that, for agent
i\in F
, the random variable
v_{i}(A_{g(i)})
follows the binomial probability distribution
\mathcal{B}(|A_{g(i)}|,1/2)
with
|A_{g(i)}|
trials (one for each item of bundle
A_{g(i)}
) and success probability
1/2
per trial. We will bound the RHS of equation (
30
) by applying the reverse Chernoff bound (Lemma
8
) with
\varepsilon=\frac{(3+\zeta_{g(i)})d}{|A_{g(i)}|}
and
t=|A_{g(i)}|
. The next claim justifies that we can indeed do so.

Claim 4.

For
\varepsilon=\frac{(3+\zeta_{g(i)})d}{|A_{g(i)}|}
and
t=|A_{g(i)}|
, it holds that
\varepsilon\leq 1/2
and
\varepsilon^{2}t\geq 6
.

Proof.

By the definition of
\zeta_{g(i)}
, we have
\varepsilon=\frac{(3+\zeta_{g(i)})d}{|A_{g(i)}|}=\frac{(3+\zeta_{g(i)})d}{m/k+(\zeta_{g(i)}-1)d}
, which is non-decreasing for
\zeta_{g(i)}\in[0,k]
since
d\leq\frac{m}{4k}
. Thus, since
k\geq 4
and
d\leq\frac{m}{4k^{2}}
, we get
\varepsilon\leq\frac{(3+k)d}{m/k+(k-1)d}\leq\frac{2k^{2}d}{m}\leq\frac{1}{2}
.

Also, by the definition of
\zeta_{g(i)}
, we have
\varepsilon^{2}t=\frac{(3+\zeta_{g(i)})^{2}d^{2}}{\frac{m}{k}+(\zeta_{g(i)}-1)d}
. The derivative of this expression w.r.t
\zeta_{g(i)}
has the same sign as the
quantity

\displaystyle 2(3+\zeta_{g(i)})\mathopen{}\mathclose{{\left(\frac{m}{k}+(\zeta_{g(i)}-1)d}}\right)-(3+\zeta_{g(i)})^{2}d

\displaystyle=(3+\zeta_{g(i)})\mathopen{}\mathclose{{\left(\frac{2m}{k}+d(\zeta_{g(i)}-5}}\right)\geq\mathopen{}\mathclose{{\left(3+\zeta_{g(i)}}}\right)\mathopen{}\mathclose{{\left(\frac{2m}{k}-5d}}\right)\geq 0.

Thus, it is minimized for
\zeta_{g(i)}=0
and, hence,
\varepsilon^{2}t\geq\frac{9d^{2}}{m/k-d}\geq\frac{12d^{2}k}{m}\geq 6
,
as desired. The second last inequality follows by the fact
d\leq\frac{m}{4k}
and the last inequality follows since
d=\sqrt{m/k}
, by definition.
∎

We get

\displaystyle\Pr\mathopen{}\mathclose{{\left[\mathcal{E}_{i}^{1}(A)}}\right]

\displaystyle\geq\exp\mathopen{}\mathclose{{\left(-\frac{9(3+\zeta_{g(i)})^{2}d^{2}}{2|A_{g(i)}|}}}\right)=\exp\mathopen{}\mathclose{{\left(-\frac{9(3+\zeta_{g(i)})^{2}d^{2}}{2(m/k+(\zeta_{g(i)}-1)d}}}\right)

(31)

\displaystyle\geq\exp\mathopen{}\mathclose{{\left(-\frac{6(3+\zeta_{g(i)})^{2}d^{2}k}{m}}}\right).

Furthermore,

\displaystyle\Pr\mathopen{}\mathclose{{\left[\mathcal{E}_{i}^{2}(A)}}\right]

\displaystyle=\Pr\mathopen{}\mathclose{{\left[\sum_{h\in[k]\setminus\{g(i)\}}{v_{i}(A_{h})}\geq\frac{m(k-1)}{2k}-\frac{(k-1)d}{2}}}\right]

\displaystyle=\Pr\mathopen{}\mathclose{{\left[\sum_{h\in[k]\setminus\{g(i)\}}{v_{i}(A_{h})}\geq\sum_{h\in[k]\setminus\{g(i)\}}{\frac{|A_{h}|-(\zeta_{h}-1)d}{2}}-\frac{k-1}{2}d}}\right]

(32)

\displaystyle\geq\Pr\mathopen{}\mathclose{{\left[\sum_{h\in[k]\setminus\{g(i)\}}{v_{i}(A_{h})}\geq\frac{1}{2}\sum_{h\in[k]\setminus\{g(i)\}}{|A_{h}|}}}\right]\geq\frac{1}{2}.

The second last inequality follows since
\zeta_{g(i)}\leq k
. The last inequality follows since the random variable
\sum_{h\in[k]\setminus\{g(i)\}}{v_{i}(A_{h})}
follows the binomial probability distribution
\mathcal{B}\mathopen{}\mathclose{{\left(\sum_{h\in[k]\setminus\{g(i)\}}{|A_{h}|},1/2}}\right)
and the LHS is just the probability that this random variable is at least its mean.

We now claim that event
\mathcal{E}_{i}(A)
is false when events
\mathcal{E}_{i}^{1}(A)
and
\mathcal{E}_{i}^{2}(A)
are true. Indeed, assuming that inequalities (
28
) and (
29
) are true, we obtain

\displaystyle\frac{1}{k}\sum_{h\in[k]}{v_{i}(A_{h})}-v_{i}(A_{g(i)})

\displaystyle=\frac{1}{k}\sum_{h\in[k]\setminus\{g(i)\}}{v_{i}(A_{h})}-\frac{k-1}{k}v_{i}(A_{g(i)})

\displaystyle\geq\frac{m(k-1)}{2k^{2}}-\frac{(k-1)d}{2k}-\frac{m(k-1)}{2k^{2}}+\frac{2(k-1)}{k}d

\displaystyle\geq\frac{3(k-1)}{2k}d>d.

The last inequality follows since
k\geq 4
.

Now, observe that the events
\mathcal{E}_{i}^{1}(A)
and
\mathcal{E}_{i}^{2}(A)
are independent as they refer to the valuation of agent
i\in F
for disjoint sets of items. Hence, using equations (
31
) and (
32
), we get

\displaystyle\Pr\mathopen{}\mathclose{{\left[\mathcal{E}_{i}(A)}}\right]

\displaystyle\leq 1-\Pr\mathopen{}\mathclose{{\left[\mathcal{E}_{i}^{1}(A)}}\right]\cdot\Pr\mathopen{}\mathclose{{\left[\mathcal{E}_{i}^{2}(A)}}\right]

\displaystyle\leq\exp\mathopen{}\mathclose{{\left(-\Pr\mathopen{}\mathclose{{\left[\mathcal{E}_{i}^{1}(A)}}\right]\cdot\Pr\mathopen{}\mathclose{{\left[\mathcal{E}_{i}^{2}(A)}}\right]}}\right)

\displaystyle\leq\exp\mathopen{}\mathclose{{\left(-\frac{1}{2}\exp\mathopen{}\mathclose{{\left(-\frac{6(3+\zeta_{g(i)})^{2}d^{2}k}{m}}}\right)}}\right).

This completes the proof of the lemma.∎

Let
\ell=\min\{n_{1},n_{2},...,n_{k}\}-1
. For
h\in[k]
, denote by
F_{h}
a set of
\ell
non-leader agents from group
h
. Let
\widetilde{F}=\cup_{h\in[k]}{F_{h}}
.

Now, observe that allocation
A\in\mathcal{A}
is proportional up to
d
items only if the event
\mathcal{E}_{i}(A)
is true for every agent
i\in\widetilde{F}
. These events are independent as each of them depends on the random valuations of a different agent. Thus, by Lemma
6
, we have

\displaystyle\Pr\mathopen{}\mathclose{{\left[\bigwedge_{i\in\widetilde{F}}{\mathcal{E}_{i}(A)}}}\right]

\displaystyle<\prod_{i\in\widetilde{F}}{\exp\mathopen{}\mathclose{{\left(-\frac{1}{2}\exp\mathopen{}\mathclose{{\left(-\frac{6\mathopen{}\mathclose{{\left(3+\zeta_{g(i)}}}\right)^{2}d^{2}k}{m}}}\right)}}\right)}

\displaystyle=\prod_{h\in[k]}{\prod_{i\in F_{h}}{\exp\mathopen{}\mathclose{{\left(-\frac{1}{2}\exp\mathopen{}\mathclose{{\left(-\frac{6\mathopen{}\mathclose{{\left(3+\zeta_{g(i)}}}\right)^{2}d^{2}k}{m}}}\right)}}\right)}}

\displaystyle=\prod_{h\in[k]}{\exp\mathopen{}\mathclose{{\left(-\frac{\ell}{2}\exp\mathopen{}\mathclose{{\left(-\frac{6\mathopen{}\mathclose{{\left(3+\zeta_{h}}}\right)^{2}d^{2}k}{m}}}\right)}}\right)}

(33)

\displaystyle=\exp\mathopen{}\mathclose{{\left(-\frac{\ell}{2}\sum_{h\in[k]}{\exp\mathopen{}\mathclose{{\left(-\frac{6\mathopen{}\mathclose{{\left(3+\zeta_{h}}}\right)^{2}d^{2}k}{m}}}\right)}}}\right)

We can easily verify that the function
\exp(-c\cdot(3+z)^{2})
is convex in
[0,+\infty)
for
c\geq 1/18
. Then, using Jensen’s inequality and equation (
27
), we have

(34)

\displaystyle\sum_{h\in[k]}{\exp\mathopen{}\mathclose{{\left(-c\cdot(3+\zeta_{h})^{2}}}\right)}

\displaystyle\geq\exp\mathopen{}\mathclose{{\left(-c\cdot\mathopen{}\mathclose{{\left(3+\frac{1}{k}\sum_{h\in[k]}{\zeta_{h}}}}\right)^{2}}}\right)=\exp\mathopen{}\mathclose{{\left(-16c}}\right).

Using equation (
34
) for
c=\frac{6d^{2}k}{m}=6
, equation (
33
) yields

\displaystyle\Pr\mathopen{}\mathclose{{\left[\bigwedge_{i\in\widetilde{F}}{\mathcal{E}_{i}(A)}}}\right]

\displaystyle<\exp\mathopen{}\mathclose{{\left(-\frac{k\ell}{2}\exp\mathopen{}\mathclose{{\left(-\frac{96d^{2}k}{m}}}\right)}}\right)=\exp\mathopen{}\mathclose{{\left(-\frac{k\mathopen{}\mathclose{{\left(\min\{n_{1},n_{2},...,n_{k}\}-1}}\right)}{2e^{96}}}}\right)

\displaystyle\leq\exp\mathopen{}\mathclose{{\left(-m\ln{k}}}\right)=k^{-m},

as desired. The first equality follows by the definition of
d
and
\ell
and the second inequality follows by the definition of
m
.

5.
Conclusion

We have presented an improved lower bound on multi-color discrepancy and improved lower bounds on how much we should relax the fairness notions of consensus division, envy-freeness, and proportionality when sets of indivisible items have to be allocated in
k
groups of
n
agents in total. There is still a small gap of
\Theta\mathopen{}\mathclose{{\left(\sqrt{\ln{k}}}}\right)
from the currently known upper bounds for multi-color discrepancy and consensus division, and larger gaps for the other two fair division properties. Closing these gaps are the obvious open problems that stem from our work. Exploring additional implications of our multi-color discrepancy lower bound is an interesting task as well. We suspect that it will find applications to areas completely different than fair division, which has been our focus here.
