An alternative explicit circuit diagram for the quantum search algorithm by implementing a non-unitary gate
Ammar Daskin

Abstract
Since the final quantum state in the Grover search algorithm is the normalized marked quantum state from the Gram-Schmidt process, Abrams and Lloyd [ abrams1998nonlinear ] has shown that we can generate this vector by using a non-unitary gate. Following their ideas, in this paper, we present multiple explicit unitary implementations by using the square root of the non-unitary matrix and by a unitary matrix that mimics the Gram-Schmidt process. We also discuss the implementation through a linear combination of unitary matrices or similar methods and how these approximations may change the complexity. The reading of the marked element from the given circuits with high probability still requires multiple repetitions similar to the original algorithm. However, it gives an alternative implementations which may be useful in certain platforms.



Keywords—
alternative quantum search, quantum algorithms, quantum search with ancilla

1
Introduction

The Grover search algorithm
[
grover1996fast
,
grover1997quantum
]
is an iterative algorithm consisting of two operators
[
nielsen2010quantum
]
:
\displaystyle U_{mark}
that marks (changes the sign of) the solution. The marking, for instance, can be done by controlling this operator by a register that represents the superposition state of the output of a function.
The second operator is
\displaystyle U_{amplify}
which increases the magnitude of the amplitude that is marked by the previous operator.
After applying these two operators
\displaystyle O(\sqrt{N})
times for a state of dimension
\displaystyle N
, the marked solution can be measured with probability
\displaystyle\approx 1
. The algorithm is generalized for searching multiple elements
[
biron1999generalized
]
and through the years its many variants and implementations are presented
[
giri2017review
]
.
We can also understand the algorithm through the Gram-Schmidt orthogonalization process
[
golub2013matrix
]
used in linear algebra. In our case, the process start with assuming the initial state vector as
\displaystyle\mathbf{v_{0}}
, generally a superposition state, and the marked state as
\displaystyle\mathbf{v_{1}}
. Here, these two vectors differ only on the sign of one element and they are not orthogonal to each other: in the case when
\displaystyle\mathbf{v_{0}}
is a superposition state
\displaystyle\mathbf{v_{0}^{T}v_{1}}=\frac{N-2}{N}
.

Abrams and Lloyd
[
abrams1998nonlinear
]
has shown that
by allowing non-linearities, e.g. using a non-unitary gate on an ancilla register, one can generate this solution state directly on quantum computers. The circuit for this model is investigated in
[
terashima2005nonunitary
]
.
This model is also used to study different problems: e.g. studies related to general non-unitary computing
[
gingrich2004non
,
williams2004probabilistic
]
, simulation of non-unitary matrices
[
daskin2017ancilla
,
mazzola2019nonunitary
]
, exploring the divergence of fisher information
[
waghela2024simulation
]
.

In the following sections, we first review the key steps in the Gram-Schmidt process, then follow mainly Ref.
[
abrams1998nonlinear
]
to discuss and formalize how to construct this process on quantum states which requires a non-unitary gate. We then implement this non-unitary gate by using additional ancillary qubits. We also discuss how this non-unitary gate can be implemented through the linear combination of unitaries.
We then show how using the amplitude amplification on the ancillar register to mark the desired state and amplify the success probability of the desired part. After discussing how the approach can be used for multiple database search, we discuss its complexity and conclude the paper with this discussion.

The Gram-Schmidt orthogonalization process

Gram-Schmidt process is used to orthogonalize given vectors.
It is used to construct QR decomposition of a matrix.
An alternative quantum version
[
zhang2021quantum
]
is also proposed which is used to construct orthonormal basis vectors of a quantum state from a given arbitrary vectors.

In the Gram-Schmidt process
[
golub2013matrix
]
the first vector does not change if it is normalized.

\mathbf{u_{0}}=\mathbf{v_{0}}.

(1)

The second vector is found by removing the residual in their inner product:

\mathbf{u_{1}}=\mathbf{v_{1}}-\alpha\mathbf{u_{0}},\mathbf{\tilde{u}_{1}}=\frac{\mathbf{u_{1}}}{\lVert\mathbf{u_{1}}\rVert},

(2)

where
\displaystyle\mathbf{\tilde{u}_{1}}
represents the normalized version of the vector
\displaystyle\mathbf{u_{1}}
.
For the normalized vectors;

\alpha=\frac{\left\langle\mathbf{v_{1}}|\mathbf{u_{0}}\right\rangle}{\left\langle\mathbf{u_{0}}|\mathbf{u_{0}}\right\rangle}=\left\langle\mathbf{v_{1}}|\mathbf{v_{0}}\right\rangle=\frac{N-2}{N}.

(3)

As an example consider the following two vectors:

\mathbf{v_{0}}=\frac{1}{2}\left(\begin{matrix}1\\
1\\
1\\
1\end{matrix}\right),\mathbf{v_{1}}=\frac{1}{2}\left(\begin{matrix}1\\
1\\
-1\\
1\end{matrix}\right).

(4)

The solution is chosen as the third element and marked by negative sign.
Then we can define the orthogonal vectors:

\displaystyle\mathbf{u_{0}}=\mathbf{v_{0}}
and
\displaystyle\mathbf{u_{1}}
as:

\begin{split}\mathbf{u_{1}}=&\mathbf{v_{1}}-\frac{\left\langle\mathbf{v_{1}}|\mathbf{u_{0}}\right\rangle}{\|\mathbf{u_{0}}\|}\mathbf{u_{0}}\\
=&\frac{1}{2}\left(\begin{matrix}1\\
1\\
-1\\
1\end{matrix}\right)-\frac{1}{4}\left(\begin{matrix}1\\
1\\
1\\
1\end{matrix}\right)=\left(\begin{matrix}1/4\\
1/4\\
-3/4\\
1/4\end{matrix}\right).\end{split}

(5)

Therefore, the amplitude of the marked state after the orthogonalization becomes 3 times of the others. And the probability becomes three times of the sum of other probabilities.
Note that normalization of
\displaystyle\mathbf{v_{0}}
and
\displaystyle\mathbf{v_{1}}
does not change this fact since it scales all the elements.
In generic case with all elements one in
\displaystyle\mathbf{u_{0}}
, we can define the terms as:

\begin{split}&\left\langle\mathbf{v_{1}}|\mathbf{u_{0}}\right\rangle=N-2\text{ if normalized }\left\langle\mathbf{v_{1}}|\mathbf{u_{0}}\right\rangle=\frac{N-2}{N}\\
&\|\mathbf{u_{0}}\|=\sqrt{N},\text{ if normalized }\|\mathbf{u_{0}}\|=1\end{split}

(6)

Therefore, we can define the vector elements of
\displaystyle\mathbf{u_{1}}
as:

\displaystyle\displaystyle\mathbf{u_{1}}_{unmarked}=\frac{1}{\sqrt{N}}-\frac{N-2}{N\sqrt{N}}=\frac{2}{N\sqrt{N}},

(7)

\displaystyle\displaystyle\mathbf{u_{1}}_{marked}=-\frac{1}{\sqrt{N}}-\frac{N-2}{N\sqrt{N}}=\frac{2-2N}{N\sqrt{N}}

(8)

If we take the ratio of the amplitudes for the marked and unmarked elements given above, we see that overall the marked element is
\displaystyle(N-1)
times greater than the other elements.
This orthogonalization mirrors Grover’s amplitude amplification.
Therefore, we can consider this as the final state in the Grover search algorithm.

Note that in the Grover search algorithm, the final orthogonal vector is found through small changes by applying the
\displaystyle U_{mark}
and
\displaystyle U_{amplify}
operators successively.
