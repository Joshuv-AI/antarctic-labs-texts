Adversarial Robustness on Insertion-Deletion Streams
Elena Gribelyuk, Honghao Lin, David P. Woodruff, Huacheng Yu, Samson Zhou

Abstract
We study adversarially robust algorithms for insertion-deletion (turnstile) streams, where future updates may depend on past algorithm outputs. While robust algorithms exist for insertion-only streams with only a polylogarithmic overhead in memory over non-robust algorithms, it was widely conjectured that turnstile streams of length polynomial in the universe size n n require space linear in n n . We refute this conjecture, showing that robustness can be achieved using space which is significantly sublinear in n n . Our framework combines multiple linear sketches in a novel estimator-corrector-learner framework, yielding the first insertion-deletion algorithms that approximate: (1) the second moment F 2 F_{2} up to a ( 1 + ε ) (1+\varepsilon) -factor in polylogarithmic space, (2) any symmetric function ℱ \cal{F} with an 𝒪 ⁡ ( 1 ) \mathcal{O}(1) -approximate triangle inequality up to a 2 𝒪 ⁡ ( C ) 2^{\mathcal{O}(C)} factor in 𝒪 ~ ​ ( n 1 / C ) ⋅ S ​ ( n ) \tilde{\mathcal{O}}(n^{1/C})\cdot S(n) bits of space, where S S is the space required to approximate ℱ \cal{F} non-robustly; this includes a broad class of functions such as the L 1 L_{1} -norm, the support size F 0 F_{0} , and non-normed losses such as the M M -estimators, and (3) L 2 L_{2} heavy hitters. For the F 2 F_{2} moment, our algorithm is optimal up to poly ​ ( ( log ⁡ n ) / ε ) \textrm{poly}((\log n)/\varepsilon) factors. Given the recent results of Gribelyuk et al. (STOC, 2025), this shows an exponential separation between linear sketches and non-linear sketches for achieving adversarial robustness in turnstile streams.



1
Introduction

In the classical streaming model, updates arrive sequentially and define an implicit dataset, and the goal is to approximate or compute a specific statistic using space sublinear in both the stream length
m
and the dataset dimension
n
.
Typically, the algorithm is expected to process the data in a single pass, maintaining a compact summary that enables efficient estimation despite stringent memory constraints.
This model effectively captures the computational limitations encountered in many large-scale applications, where the data size far exceeds available storage.
As a result, the streaming model has attracted significant attention in both theoretical and applied research, leading to a rich body of work exploring algorithmic techniques, lower bounds, and practical implementations of streaming algorithms.
Such applications include processing logs from network and traffic monitoring, analyzing financial market transactions, handling sensor data from Internet of Things (IoT) devices, and managing scientific measurement streams.

While classical streaming algorithms typically assume that the input stream is fixed and independent of the internal parameters of the algorithm, many practical settings require a more flexible model, where previous algorithmic outputs may influence future inputs.
For example, database queries often depend on prior responses, iterative methods like stochastic gradient descent update their internal state based on earlier results, recommendation systems create feedback loops through user interactions, and financial markets respond to aggregated statistics, which in turn shape future input data.
This juxtaposition between the assumption of an oblivious, fixed input dataset and the adaptive nature of many real-world applications undermines the foundations of classical streaming analysis, which often crucially leverages the independence between the internal randomness of the algorithm and the underlying dataset.

Adversarial robustness.

Motivated by this gap,
[
BJWY22
]
introduced the
adversarially robust streaming model
to capture settings in which the sequence of updates may be adaptive or even adversarial.
This model and its variants has received significant attention, with a growing body of work developing robust algorithms for various tasks

,

.
Formally, at each time step
t\in[m]
, the streaming algorithm
{\mathcal{A}}
receives an update
u_{t}=(a_{t},\Delta_{t})
, where
a_{t}\in[n]
is an index and
\Delta_{t}\in\mathbb{Z}
denotes an increment or decrement to coordinate
a_{t}
of an implicit frequency vector
{\mathbf{x}}
, defined by
x_{i}=\sum_{t:a_{t}=i}\Delta_{t}
.
In this manner, we also define the prefix vector
{\mathbf{x}}^{(t)}
as the frequency vector after the first
t
updates, i.e.,
x^{(t)}_{i}=\sum_{s\leq t:a_{s}=i}\Delta_{s}
.
Throughout, we assume that
m=\poly(n)
and that
|\Delta_{t}|\leq\poly(n)
for all
t\in[m]
; by scaling, one could equivalently assume that each
\Delta_{t}
is a multiple of
\frac{1}{\poly(n)}
.
We say the algorithm
{\mathcal{A}}
is
adversarially robust
for a specified function
f:\mathbb{Z}^{n}\to\mathbb{R}
if
{\mathcal{A}}
provides accurate estimates of
f({\mathbf{x}}^{(t)})
at each time step
t\in[m]
, even when the updates are chosen adaptively and may depend on the entire transcript of previous updates and algorithm responses.

Definition 1.1
.

[
BJWY22
]

Let
f:\mathbb{Z}^{n}\to\mathbb{R}
be a fixed function.
A streaming algorithm
{\mathcal{A}}
is adversarially robust if, for any
\varepsilon,\delta\in(0,1)
and
m=\poly(n)
, at each time step
t\in[m]
, the algorithm outputs an estimate
Z_{t}
such that

\mathbf{Pr}\left[|Z_{t}-f({\mathbf{x}}^{(t)})|\leq\varepsilon\cdot f({\mathbf{x}}^{(t)})\right]\geq 1-\delta.

Conceptually, the model can be viewed as a sequential two-player game between the randomized streaming algorithm
{\mathcal{A}}
and an adaptive adversary, which constructs a sequence of updates
\{u_{1},\ldots,u_{m}\}
, where each
u_{t}
may depend on the entire history of past updates and algorithm outputs.
Then, the game unfolds as follows:

(1)

In each round
t
, the adversary selects an update
u_{t}
based on the previous updates
u_{1},\ldots,u_{t-1}
and the corresponding outputs
Z_{1},\ldots,Z_{t-1}
of the algorithm.

(2)

The algorithm
{\mathcal{A}}
processes
u_{t}
and updates its internal state.

(3)

The algorithm
{\mathcal{A}}
then returns an estimate
Z_{t}
of
f({\mathbf{x}}^{(t)})
before proceeding to the next round.

By nature of the game, the algorithm is only permitted a single pass over the data stream.

Insertion-only streams.

In the insertion-only streaming model, each update
\Delta_{t}>0
increases some coordinate of the underlying frequency vector.
This setting has received significant attention recently, and it is now known that many fundamental streaming problems admit adversarially robust algorithms using sublinear space
[
HKM+20
,
BHM+21
,
KMNS21
,
WZ21b
,
ABJ+22
,
BJWY22
,
ACSS23
,
JPW23
]
.
The techniques range from importance sampling and merge-and-reduce
[
BHM+21
,
JPW23
]
, to switching between various sketches or bounding the total number of computation paths
[
BJWY22
]
, to differential privacy
[
HKM+20
,
ACSS23
]
, to new algorithmic paradigms for estimating the difference of the function values at different times
[
WZ21b
]
.
Notably, for many problems such as heavy hitters, entropy estimation, clustering, linear regression, subspace embeddings, and graph sparsification, there exist adversarially robust solutions, which compared to the space complexity of classical insertion-only algorithms, only incur a small overhead polylogarithmic in the universe size
n
.

A particularly well-studied family of problems is that of estimating the frequency moments
F_{p}({\mathbf{x}})=\sum_{i\in[n]}|x_{i}|^{p}
for
p>0
and
F_{0}({\mathbf{x}})=|\{i\in[n]\,\mid\,x_{i}\neq 0\}|
.
These moments capture various important statistics of the data stream.
For example,
F_{1}
corresponds to the total number of inserted items,
F_{2}
relates to the repeat rate or collision probability, and
F_{0}
is the number of distinct elements, i.e., the support size of the stream.
Moreover, the
L_{p}
norms satisfy
\|{\mathbf{x}}\|_{p}=(F_{p}({\mathbf{x}}))^{1/p}
, so that algorithms for estimating the
F_{p}
moments directly yield algorithms for estimating
L_{p}
norms, and vice versa.
Since the seminal work of
[
AMS99
]
which formalized the classical streaming model and introduced the frequency moment estimation problem, this family of problems has been studied extensively
[
Ind06
,
IW05
,
Li08
,
KNW10a
,
KNW10b
,
AKO11
,
Gan11
,
Gan12
,
BKSV14
,
BVWY18
,
BGL+18
,
GW18
,
WZ21a
,
JWZ24
,
BZ25
,
FSW25
]
. More recently, there has been significant work on designing robust algorithms for frequency moments
[

,
WZ21b
,
BEO22
,
BJWY22
,
WZ24
]
, and indeed it has been shown
[
WZ21b
]
that achieving a
(1+\varepsilon)
-multiplicative approximation for any input accuracy parameter
\varepsilon\in(0,1)
incurs at most
\polylog\left(\frac{1}{\varepsilon}\right)
space overhead in an insertion-only stream.
This makes the
F_{p}
moment estimation problem a compelling case study for understanding the limits of robustness in the streaming model.

Insertion-deletion streams.

Compared to insertion-only streams, significantly less is understood about the space complexity of adversarially robust algorithms in turnstile streams, where updates
\Delta_{t}
may increase or decrease coordinates.

[
BJWY22
]
showed that when deletions can only decrease the underlying statistic by at most some bounded factor, there exists an adversarially robust algorithm with space sublinear in the stream length
m
; however, this assumption may not hold in general.
By utilizing techniques in differential privacy,
[
HKM+20
,
BEO22
,
WZ24
]
designed adversarially robust algorithms with space sublinear in the stream length
m
; however, when
m
grows polynomially in the dimension
n
, the resulting space complexity is no longer sublinear in
n
.

On the negative side, a recent line of work
[
HW13
,
CNS+24
,
GLW+24
,
GLW+25
]
has developed adaptive attacks against linear sketches, which represent a popular algorithmic tool for designing low-space streaming algorithms.
Given a stream of updates to a vector
{\mathbf{x}}\in\mathbb{R}^{n}
, a linear sketch compresses the data into a much smaller vector
{\mathbf{A}}{\mathbf{x}}\in\mathbb{R}^{r}
, where
r\ll n
, using a carefully chosen matrix
{\mathbf{A}}\in\mathbb{R}^{r\times n}
that is efficient to store and apply.
The matrix should be designed so that there exists a post-processing function
g
, so that
g({\mathbf{A}}{\mathbf{x}})
can be used to estimate the desired quantity about
{\mathbf{x}}
, e.g.,
g({\mathbf{A}}{\mathbf{x}})\approx\|{\mathbf{x}}\|_{p}
.
Since
{\mathbf{A}}{\mathbf{x}}
only has
r
entries, the algorithm often only needs to store
\mathcal{O}\left(r\log n\right)
bits throughout the stream, and for many interesting problems, it is possible to achieve
r\ll n
.
In fact, all known algorithms for turnstile streams of sufficiently large length are based on linear sketches.
Moreover, under certain conditions, it has been shown that optimal algorithms for turnstile streaming can be characterized entirely by linear sketching methods
[
LNW14
,
AHLW16
,
KMSY18
,
KP20
]
.
Unfortunately, results by
[
HW13
,
GLW+24
,
GLW+25
]
prove that any adversarially robust insertion-deletion streaming algorithm that uses a linear sketch to achieve any constant multiplicative approximation to the
F_{p}
moments requires sketching dimension
r=\Omega(n)
.
Although it is not clear whether
adversarially robust
turnstile streaming algorithms can be completely characterized by linear sketching methods, a long-standing open conjecture
[
Wor21
,
Wor23
,
Wor25
]
has been:

Conjecture 1.2
.

Any adversarially robust constant-factor approximation algorithm for
F_{p}
moments on insertion-deletion streams of sufficient length
m=\poly(n)
requires
\Omega(n)
space.

1.1
Our Contributions

In this work, we show that
1.2
is false.
Namely, we circumvent the above
\Omega(n)
lower bound for linear sketches and design sublinear-space streaming algorithms that output a
(1+\varepsilon)
-approximations to a wide variety of functions in an adversarial insertion-deletion stream.
Crucially, our algorithms are
non-linear
, which is necessary to bypass the linear sketch lower bounds for achieving adversarial robustness in insertion-deletion streams in
[
GLW+25
]
.

We first present our result for arguably one of the most fundamental problems for streaming algorithms, estimating the
F_{2}
moment
\|{\mathbf{x}}\|_{2}^{2}=x_{1}^{2}+\ldots+x_{n}^{2}
.
The
F_{2}
moment estimation problem was first studied in the seminal work of
[
AMS99
]
, which formally defined the streaming model and gave a
\mathcal{O}\left(\frac{1}{\varepsilon^{2}}\log n\log\frac{1}{\delta}\right)
space algorithm for
F_{2}
estimation, which was later shown to be optimal
[
KNW10a
,
BZ25
]
.

Theorem 1.3
.

Given any
\varepsilon\in(0,1)
, there exists an adversarially robust insertion-deletion streaming algorithm on a stream of length
m
that with high probability, outputs a
(1+\varepsilon)
-approximation to the
F_{2}
moment at all times, for the underlying frequency vector of universe size
n
.
For
m=\poly(n)
, the algorithm uses
\poly\left(\frac{1}{\varepsilon},\log n\right)
bits of space.

As the lower bound by
[
BZ25
]
implies that even in the non-adaptive setting,
F_{2}
moment estimation requires
\poly\left(\frac{1}{\varepsilon},\log n\right)
bits of space, our results in
Theorem

1.3
are optimal up to
\poly\left(\frac{1}{\varepsilon},\log n\right)
factors.
Interestingly, while our overall framework is not a linear sketch, it combines multiple linear sketches in careful way to only require each of them to be robust to a small number of adaptive queries.
Thus, while prior work
[
LNW14
,
AHLW16
,
KMSY18
,
KP20
]
showed that optimal turnstile streaming algorithms are necessarily linear sketches, our results imply that this characterization breaks down in the adversarially robust setting: robustness can be achieved through non-linear frameworks that fundamentally go beyond linear sketching.

We next show that our robust frequency moment algorithms can be used to robustly identify the heavy-hitters at each step in an adaptive insertion-deletion stream.
Recall that for a frequency vector
{\mathbf{x}}\in\mathbb{R}^{n}
and a heavy-hitter threshold
\varepsilon\in(0,1)
, the goal of the heavy-hitter problem is to recover a “small” list containing all coordinates
i\in[n]
such that
|x_{i}|\geq\varepsilon\cdot\|{\mathbf{x}}\|_{2}
.

Theorem 1.4
.

Given any
\varepsilon\in(0,1)
, there exists an adversarially robust insertion-deletion streaming algorithm on a stream of length
m
that with high probability, outputs the set of
L_{2}
heavy hitters at all times, for the underlying frequency vector of universe size
n
.
For
m=\poly(n)
, the algorithm uses
\poly\left(\frac{1}{\varepsilon},\log n\right)
bits of space.

Since an algorithm for
L_{2}
heavy hitters can be used to recover
L_{p}
heavy hitters for
p\leq 2
, we obtain an adversarially robust algorithm for
L_{p}
heavy hitters for all
p\leq 2
.
Again, we remark that the best-known
L_{2}
heavy-hitter algorithms use
\poly\left(\frac{1}{\varepsilon},\log n\right)
space for
p=2
and such dependencies are known to be necessary
[
Gan12
,
WZ21a
]
.
Thus, our result essentially matches the optimal space bounds of classical non-adaptive
L_{2}
heavy-hitter algorithms, up to polynomial factors in
\frac{1}{\varepsilon}
and logarithmic factors in
n
.

More generally, we show that our approach applies broadly to any function that satisfies an approximate triangle inequality and admits a non-adaptive sketching algorithm.
Formally, we say that for a constant
\beta>0
, a symmetric function
{\mathcal{F}}
satisfies a
\beta
-approximate triangle inequality if
{\mathcal{F}}({\mathbf{x}}-{\mathbf{z}})\leq\beta\cdot({\mathcal{F}}({\mathbf{x}}-{\mathbf{y}})+{\mathcal{F}}({\mathbf{y}}-{\mathbf{z}}))
for all vectors
{\mathbf{x}},{\mathbf{y}},{\mathbf{z}}\in\mathbb{R}^{n}
.

Theorem 1.5
.

Suppose
{\mathcal{F}}
is a symmetric function on a stream of length
m=\poly(n)
, has value
\left[\frac{1}{\poly(m)},\poly(m)\right]
and satisfies the
\beta
-approximate triangle inequality.
Let
\kappa>2\beta+1
be a fixed constant and suppose there exists a non-adaptive turnstile streaming algorithm that uses
S(n)\cdot\log\frac{1}{\delta}
bits of space and with probability at least
1-\delta
, outputs a
\kappa
-approximation to
{\mathcal{F}}
.
Then for any constant
C>1
, there exists an adversarially robust insertion-deletion streaming algorithm on a stream of length
m
that uses
\tilde{\mathcal{O}}\left(n^{1/C}\right)\cdot S(n)
bits of space and with high probability, outputs a
\kappa^{\mathcal{O}\left(c\right)}
-approximation to
{\mathcal{F}}
at all times.

We apply
Theorem

1.5
to the
L_{1}
norm, the support size
L_{0}
, the
L_{p}
norms for
p\in(0,1)
, and many other loss functions such as the Huber loss functions, M-estimators, and so on.

1.2
Technical Overview

Recall that from the previous discussion, given a data stream that induces a frequency vector
{\mathbf{x}}\in\mathbb{R}^{n}
, a common algorithmic approach is to generate a random sketch matrix
{\mathbf{A}}\in\mathbb{R}^{r\times n}
and maintain
{\mathbf{A}}{\mathbf{x}}
throughout the stream.
The matrix should be designed so that there exists a post-processing function
g
, so that
g({\mathbf{A}}{\mathbf{x}})
can be used to estimate the desired quantity for
{\mathbf{x}}
, e.g.,
g({\mathbf{A}}{\mathbf{x}})\approx\|{\mathbf{x}}\|_{p}
.
Since
{\mathbf{A}}{\mathbf{x}}
only has
r
entries, the algorithm often only needs to store
\mathcal{O}\left(r\log n\right)
bits throughout the stream, and for many interesting problems, it is possible to achieve
r\ll n
.
For example, constant-factor approximations to the
L_{p}
norm are possible with
r=\polylog(n)
for
p\leq 2
and
r=\mathcal{O}\left(n^{1-2/p}\right)
for
p>2
.
Unfortunately, recent results by
[
GLW+24
,
GLW+25
]
prove that any such linear sketch for adversarially robust insertion-deletion streams requires dimension
\Omega(n)
.
One inherent reason is that linear sketches only use randomness at the start to generate the sketching matrices, thereafter, the algorithm is deterministic.
In order for the adversary to break such algorithms, it suffices to take
\poly(n)
queries to gradually figure out these initial random bits, and then construct a hard query for the corresponding sketching matrix.
This is how the recent lower bounds were proved.
Thus, to circumvent the lower bounds, it informally seems like new random bits need to be introduced during the execution of the streaming algorithm, rather than all at the beginning.
Our solution achieves small space by initializing new independent sketches in the “middle” of the data stream.

To that end, suppose that the underlying frequency vector
{\mathbf{x}}
satisfies
{\mathbf{x}}={\mathbf{z}}+{\mathbf{q}}
, where
{\mathbf{z}}
is the frequency vector defined by all of the updates of the stream, up to some time
t
and
{\mathbf{q}}
is the frequency vector defined by the remaining updates after
t
, i.e.,
{\mathbf{z}}
corresponds to some prefix of the stream and
{\mathbf{q}}
corresponds to the remaining suffix of the stream.
Consider a sketch matrix
{\mathbf{B}}
that was initialized at time
t+1
, so that the algorithm tracks
{\mathbf{B}}{\mathbf{q}}
.
For a random sketch matrix
{\mathbf{B}}
designed for
F_{2}
moment estimation, if we knew
{\mathbf{B}}{\mathbf{z}}
(which we actually do not, since
{\mathbf{B}}
is only initialized after
{\mathbf{z}}
appears), then since
{\mathbf{B}}{\mathbf{x}}={\mathbf{B}}{\mathbf{z}}+{\mathbf{B}}{\mathbf{q}}
, we could approximate
\|{\mathbf{x}}\|_{2}^{2}
from
{\mathbf{B}}{\mathbf{x}}
.
Below, we will show that either we can approximate
\|{\mathbf{x}}\|_{2}^{2}
without knowing
{\mathbf{B}}{\mathbf{z}}
, or we will gradually learn
{\mathbf{B}}{\mathbf{z}}
.

1.2.1
Technical Overview for
F_{2}
Moment Estimation

Now suppose there exists another random sketch matrix
{\mathbf{A}}
designed for
F_{2}
moment estimation, but initialized at the beginning of the stream, so that the algorithm is able to store
{\mathbf{A}}{\mathbf{z}}
as well as to track
{\mathbf{A}}{\mathbf{x}}
after time
t
.
In this case, the information we have about
{\mathbf{z}}
is the sketch
{\mathbf{A}}{\mathbf{z}}
.
Suppose
{\mathbf{q}}
has a random direction independent of
{\mathbf{z}}
, then we cannot hope to learn anything about
{\mathbf{B}}{\mathbf{z}}
from it.
However, this is exactly a case where we do not need to know
{\mathbf{B}}{\mathbf{z}}
to approximate
\|{\mathbf{x}}\|_{2}^{2}
.
Since random directions are nearly orthogonal in large dimensions, we have
\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}\approx\|{\mathbf{z}}\|_{2}^{2}+\|{\mathbf{q}}\|_{2}^{2}
, which in turn, can be estimated from
{\mathbf{A}}{\mathbf{z}}
and
{\mathbf{B}}{\mathbf{q}}
respectively.
On the other hand, if
\|{\mathbf{z}}\|_{2}^{2}+\|{\mathbf{q}}\|_{2}^{2}
is a bad approximation to
\|{\mathbf{x}}\|_{2}^{2}
, then because

\|{\mathbf{x}}\|_{2}^{2}=\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}=\|{\mathbf{z}}\|_{2}^{2}+2\langle{\mathbf{z}},{\mathbf{q}}\rangle+\|{\mathbf{q}}\|_{2}^{2},

|\langle{\mathbf{z}},{\mathbf{q}}\rangle|
must be large in magnitude, relative to both
\|{\mathbf{z}}\|_{2}^{2}
and
\|{\mathbf{q}}\|_{2}^{2}
.
However, it can only happen when
{\mathbf{z}}
has a non-trivial alignment with
{\mathbf{q}}
, in which case we can hope to learn something about
{\mathbf{z}}
from
{\mathbf{q}}
.
We can use
{\mathbf{A}}{\mathbf{x}}
to check whether
\|{\mathbf{z}}\|_{2}^{2}+\|{\mathbf{q}}\|_{2}^{2}
is a bad approximation, and either return an accurate estimate to
\|{\mathbf{x}}\|_{2}^{2}
, or learn some extra information about
{\mathbf{z}}
in each step.

Consider the following setting:

(1)

{\mathbf{A}}{\mathbf{q}}

{\mathbf{B}}

{\mathbf{B}}

{\mathbf{q}}

\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}
while using
{\mathbf{A}}

Our simplified
F_{2}

(1)

An estimator, whose role is to output estimates of
\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}
.

(2)

A learner, whose role is to learn
{\mathbf{z}}
to facilitate the estimation.
When the estimator is incorrect, the learner will gain information about
{\mathbf{z}}
from
{\mathbf{q}}
.

(3)

A corrector, whose role is to inform the learner/estimator when the estimate is incorrect.

The corrector uses
{\mathbf{A}}{\mathbf{x}}
to detect when an estimate is incorrect.
The learner will maintain a vector
{\mathbf{z}}^{\prime}
, which is a linear combination of the queries
{\mathbf{q}}
on which the algorithm was incorrect, though algorithmically, only
{\mathbf{A}}{\mathbf{z}}^{\prime}
and
{\mathbf{B}}{\mathbf{z}}^{\prime}
are explicitly maintained.
The estimator will output
\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}^{2}+\|{\mathbf{z}}^{\prime}+{\mathbf{q}}\|_{2}^{2}
as an estimate for
\|{\mathbf{x}}\|_{2}^{2}=\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}
, where the first term is estimated using
{\mathbf{A}}{\mathbf{z}}-{\mathbf{A}}{\mathbf{z}}^{\prime}
, and the second term is estimated using
{\mathbf{B}}{\mathbf{z}}^{\prime}+{\mathbf{B}}{\mathbf{q}}
.
As sanity checks, note that if
{\mathbf{z}}^{\prime}=\mathbf{0}^{n}
, i.e., we have no information about
{\mathbf{z}}
, the estimator corresponds to the previous estimator

Robustness and progress.

By standard minimax arguments, it suffices for us to consider a deterministic adversary.
In the algorithm framework above, one vulnerability is that the corrector must use
{\mathbf{A}}{\mathbf{x}}
to flag incorrect estimates. Each such interaction potentially leaks information about
{\mathbf{A}}
, so after a large number of interactions, the corrector itself might be broken by adversarial inputs.
To this end, suppose that the estimator is only incorrect at most
L
times.
Then, we use the key insight from the bounded computation paths technique of
[
BJWY22
]
: note that there are at most
\binom{m}{L}
possible sets of times where the corrector can flag incorrect estimates over a stream of length
m
.
Thus, there are only at most
\binom{m}{L}
adaptive input streams that a deterministic adversary can generate, based on the information which is outputted by the corrector.
Now, by setting the failure probability of the corrector to be
\delta=\frac{1}{\poly(n)}\cdot\binom{m}{L}^{-1}
, by a union bound, the corrector will be robust to all possible adversarial streams generated by the deterministic adversary.
Since the space complexity of streaming algorithms often scales with
\log\frac{1}{\delta}
, the resulting space complexity will roughly have a linear dependence on
L
.
Note that we also use the estimate of the
corrector

L
times as the output and further use
{\mathbf{A}}
at most
L
times to estimate
\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}^{2}
after each update to
{\mathbf{z}}^{\prime}
, but a sketch of size linear in
L
can also be used
\mathcal{O}\left(L\right)
times against an adaptive adversary (e.g., use a different block of rows for each query).
Thus, it remains to upper bound the total number
L
of incorrect outputs made by the estimator.

To do so, consider each time the estimate is inaccurate (see
Figure

2
).
In this case,
{\mathbf{z}}-{\mathbf{z}}^{\prime}
must be far from being orthogonal with
{\mathbf{z}}^{\prime}+{\mathbf{q}}
.
Thus, by moving
{\mathbf{z}}^{\prime}
towards
-{\mathbf{q}}
(or away from
-{\mathbf{q}}
), the distance to
{\mathbf{z}}
will decrease non-trivially, i.e.,
{\mathbf{z}}^{\prime}
approximates
{\mathbf{z}}
better.
Formally, we use
\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}^{2}
as the “progress measure”.
Then, an incorrect estimate for
\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}
implies

\left\lvert\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}^{2}+\|{\mathbf{z}}^{\prime}+{\mathbf{q}}\|_{2}^{2}-\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}\right\rvert\geq\varepsilon\cdot\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}.

By expanding the both sides, we must have

|\langle{\mathbf{z}}-{\mathbf{z}}^{\prime},{\mathbf{z}}^{\prime}+{\mathbf{q}}\rangle|\geq\frac{\varepsilon}{2}\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}=\frac{\varepsilon}{2}\left(\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}^{2}+\|{\mathbf{q}}+{\mathbf{z}}^{\prime}\|_{2}^{2}+2\langle{\mathbf{z}}-{\mathbf{z}}^{\prime},{\mathbf{q}}+{\mathbf{z}}^{\prime}\rangle\right).

Suppose that
\langle{\mathbf{z}}-{\mathbf{z}}^{\prime},{\mathbf{z}}^{\prime}+{\mathbf{q}}\rangle\geq\frac{\varepsilon}{2}\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}
, as the other case is very similar. In particular, this can be used to see that
\langle{\mathbf{z}}-{\mathbf{z}}^{\prime},{\mathbf{z}}^{\prime}+{\mathbf{q}}\rangle\geq\varepsilon\cdot\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}\cdot\|{\mathbf{q}}+{\mathbf{z}}^{\prime}\|_{2}
.
Now, when the algorithm was incorrect on query
{\mathbf{q}}
, the vector
{\mathbf{z}}^{\prime}
will be updated to
{\mathbf{z}}^{\prime\prime}={\mathbf{z}}^{\prime}+\alpha({\mathbf{q}}+{\mathbf{z}}^{\prime})
for some carefully chosen
\alpha
. We have

\displaystyle\|{\mathbf{z}}-{\mathbf{z}}^{\prime\prime}\|_{2}^{2}

\displaystyle=\|{\mathbf{z}}-{\mathbf{z}}^{\prime}-\alpha({\mathbf{q}}+{\mathbf{z}}^{\prime})\|_{2}^{2}

\displaystyle=\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}^{2}+\alpha^{2}\|{\mathbf{q}}+{\mathbf{z}}^{\prime}\|_{2}^{2}-2\alpha\langle{\mathbf{z}}-{\mathbf{z}}^{\prime},{\mathbf{q}}+{\mathbf{z}}^{\prime}\rangle

\displaystyle\leq\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}^{2}+\alpha^{2}\|{\mathbf{q}}+{\mathbf{z}}^{\prime}\|_{2}^{2}-2\alpha\cdot\varepsilon\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}\cdot\|{\mathbf{q}}+{\mathbf{z}}^{\prime}\|_{2}.

Then, by setting the step-size
\alpha=\frac{\varepsilon\cdot\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}}{\|{\mathbf{q}}+{\mathbf{z}}^{\prime}\|_{2}}
, we get

\|{\mathbf{z}}-{\mathbf{z}}^{\prime\prime}\|_{2}^{2}\leq(1-\varepsilon^{2})\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}^{2}.

Importantly, this step-size
\alpha
can also be estimated up to a
(1\pm\varepsilon)
multiplicative factor with high probability using robust
L_{2}
sketches and a bounded computation bounds argument. Since
\|{\mathbf{z}}\|_{2}^{2}\leq\poly(n)
for a stream of length
m=\poly(n)
, it follows that
{\mathbf{z}}^{\prime}
will be updated at most
\mathcal{O}\left(\frac{1}{\varepsilon^{2}}\log n\right)
times, which gives our upper bound on
L
.
Thus, the algorithm solves the problem in the simplified setting with only
\poly\left(\frac{1}{\varepsilon},\log n\right)
rows in
{\mathbf{A}}
.

Recursive estimator.

To extend the above approach to a full streaming algorithm, the main shortcoming is that while the algorithm with sketching matrix
{\mathbf{B}}
has access to
{\mathbf{B}}{\mathbf{q}}
and can gradually learn
{\mathbf{B}}{\mathbf{z}}
, it must correctly answer a large number of queries based on
{\mathbf{B}}{\mathbf{q}}
throughout the stream.
For example, if
{\mathbf{x}}={\mathbf{z}}+{\mathbf{q}}
is the frequency vector for the full stream of length
m
and
{\mathbf{z}}
and
{\mathbf{q}}
each correspond to frequency vectors for substreams of length
\frac{m}{2}
, then
{\mathbf{B}}
must itself be robust to
\frac{m}{2}
adaptive queries en route to
{\mathbf{q}}
, and similarly
{\mathbf{A}}
must be robust to
\frac{m}{2}
adaptive queries that ultimately form
{\mathbf{z}}
.
To address this, the natural approach is to recurse on both halves of the stream, corresponding to
{\mathbf{z}}
and
{\mathbf{q}}
respectively.

Recall that our estimator is
\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}^{2}+\|{\mathbf{z}}^{\prime}+{\mathbf{q}}\|_{2}^{2}
, and we will maintain both
{\mathbf{A}}{\mathbf{z}}^{\prime}
and
{\mathbf{B}}{\mathbf{z}}^{\prime}
as we update
{\mathbf{z}}^{\prime}
.
The first term
\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}^{2}
is estimated from
{\mathbf{A}}{\mathbf{z}}-{\mathbf{A}}{\mathbf{z}}^{\prime}
.
The key observation is that estimating the second term
\|{\mathbf{z}}^{\prime}+{\mathbf{q}}\|_{2}^{2}
is a task of the same form as the full problem, but on a shorter stream: given a (rounded) sketch
{\mathbf{B}}{\mathbf{z}}^{\prime}
for an unknown
{\mathbf{z}}^{\prime}
, estimate
\|{\mathbf{z}}^{\prime}+{\mathbf{q}}\|_{2}^{2}
for
{\mathbf{q}}
that arrives in a stream.
This allows us to recursively estimate the second term.

Two levels and beyond.

For example, consider a two-level scheme where we can write
{\mathbf{q}}={\mathbf{q}}_{1}+{\mathbf{q}}_{2}
, so that
\|{\mathbf{z}}^{\prime}+{\mathbf{q}}\|_{2}^{2}=\|{\mathbf{z}}^{\prime}+{\mathbf{q}}_{1}+{\mathbf{q}}_{2}\|_{2}^{2}
.
We can use a sketch matrix
{\mathbf{B}}_{1}
to track
{\mathbf{B}}_{1}({\mathbf{z}}^{\prime}+{\mathbf{q}}_{1})
and a sketch matrix
{\mathbf{B}}_{2}
to track
{\mathbf{B}}_{2}{\mathbf{q}}_{2}
.
Similarly, we implement a learner at this second level, whose role is to learn
{\mathbf{z}}^{\prime}+{\mathbf{q}}_{1}
over the course of the stream updates of
{\mathbf{q}}_{2}
.
In particular, the learner maintains a vector
{\mathbf{u}}
, which is a linear combination of queries for which an estimator at the second level is inaccurate, when using
\|{\mathbf{z}}^{\prime}+{\mathbf{q}}_{1}-{\mathbf{u}}\|_{2}^{2}+\|{\mathbf{u}}+{\mathbf{q}}_{2}\|_{2}^{2}
as an estimate for
\|{\mathbf{z}}^{\prime}+{\mathbf{q}}_{1}+{\mathbf{q}}_{2}\|_{2}^{2}
. By the above intuition, this estimate is incorrect if
\langle{\mathbf{z}}^{\prime}+{\mathbf{q}}_{1},{\mathbf{q}}_{2}\rangle
is large, meaning the algorithm for
{\mathbf{q}}_{2}
learns information about
{\mathbf{z}}^{\prime}+{\mathbf{q}}_{1}
from
{\mathbf{q}}_{2}
.

To check if the estimate is inaccurate, we can again interface the learner and estimator at the second level with a corrector for
\|{\mathbf{z}}^{\prime}+{\mathbf{q}}_{1}+{\mathbf{q}}_{2}\|_{2}^{2}
.
One caveat is that the iterate
{\mathbf{z}}^{\prime}
might change over the course of the stream for
{\mathbf{q}}_{2}
because the estimator at the first level may be incorrect for some queries
{\mathbf{q}}
.
To address this, we simply start another block at the second level whenever
{\mathbf{z}}^{\prime}
is updated.
That is, instead of having two blocks each corresponding to streams of length
\frac{m}{2}
, we dynamically form blocks when either the stream length has reached a multiple of
\frac{m}{2}
or when
{\mathbf{z}}^{\prime}
is updated to
{\mathbf{z}}^{\prime}+\alpha({\mathbf{q}}+{\mathbf{z}}^{\prime})
for some incorrect query
{\mathbf{q}}
.
Because we previously upper bounded the total number of updates to iterate
{\mathbf{z}}^{\prime}
by
L=\mathcal{O}\left(\frac{1}{\varepsilon^{2}}\log n\right)
, then the number of blocks at the second level is at most
\mathcal{O}\left(\frac{1}{\varepsilon^{2}}\log n\right)
.

More generally, we can split the stream into
B+\mathcal{O}\left(\frac{1}{\varepsilon^{2}}\log n\right)
blocks of size at most
\frac{m}{B}
for the two-level scheme.
To avoid the accumulation of errors over blocks, we can again query a corrector that maintains
{\mathbf{A}}({\mathbf{q}}_{1}+{\mathbf{q}}_{2}+\ldots+{\mathbf{q}}_{k})
after
k
blocks.
Then the corrector at the first level must interact with
B+\mathcal{O}\left(\frac{1}{\varepsilon^{2}}\log n\right)
adaptive queries both in response to incorrect estimates over the entire stream and to correct the estimates at the end of each block.
The corrector at the second level must interact with
\frac{m}{B}
adaptive queries within its block of
\frac{m}{B}
updates.
Hence, the space is dominated by roughly
B+\frac{m}{B}
, which can be optimized at
B=\sqrt{m}
.
While this is unimpressive for
m=\poly(n)
, one can observe this corresponds to a two-level tree and recursively split each block into
B
blocks toward a full
B
-ary tree with height
H
.
Since we require
B^{H}\geq m
and each corrector must handle
\mathcal{O}\left(\frac{1}{\varepsilon^{2}}\log n\right)
queries corresponding to incorrect estimates, it suffices to set
B=\mathcal{O}\left(\frac{1}{\varepsilon^{2}}\log n\right)
and
H=\log m=\mathcal{O}\left(\log n\right)
for
m=\poly(n)
.
As each sketch must now only be robust to
B
queries, the corresponding space complexity is
\poly\left(\frac{1}{\varepsilon},\log n\right)
per sketch.
Since at most
\poly(B,H)=\poly\left(\frac{1}{\varepsilon},\log n\right)
sketches are maintained at any given time, our algorithm has the desired space complexity.

1.2.2
Approximate triangle inequality

As a natural extension of our
F_{2}
algorithm, we show an algorithm to robustly estimate functions
{\mathcal{F}}
that satisfy an approximate triangle inequality and have non-robust turnstile sketches.
Indeed, observe that for a function
{\mathcal{F}}
that satisfies triangle inequality and
{\mathcal{F}}({\mathbf{v}})={\mathcal{F}}(-{\mathbf{v}})
for all
{\mathbf{v}}\in\mathbb{R}^{n}
, if we seek an
\alpha
-approximation for a sufficiently large constant
\alpha>3
, then we will use
{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})+{\mathcal{F}}({\mathbf{z}}^{\prime}+{\mathbf{q}})
as the estimator for
{\mathcal{F}}({\mathbf{z}}+{\mathbf{q}})
.
By triangle inequality, this is always an overestimate.
The estimator will only be incorrect when

{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})+{\mathcal{F}}({\mathbf{z}}^{\prime}+{\mathbf{q}})\geq\alpha\cdot{\mathcal{F}}({\mathbf{z}}+{\mathbf{q}}).

In this case, by triangle inequality,
{\mathcal{F}}({\mathbf{z}}+{\mathbf{q}})+{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})\geq{\mathcal{F}}({\mathbf{z}}^{\prime}+{\mathbf{q}})
, and so
{\mathcal{F}}({\mathbf{z}}+{\mathbf{q}})+2{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})\geq\alpha\cdot{\mathcal{F}}({\mathbf{z}}+{\mathbf{q}})
, we must have

{\mathcal{F}}({\mathbf{z}}+{\mathbf{q}})\leq\frac{2}{\alpha-1}\cdot{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime}).

Now if we take
{\mathbf{z}}^{\prime\prime}
to be the closest vector to
{\mathbf{z}}
in the span of
{\mathbf{q}}
and
{\mathbf{z}}^{\prime}
under the function
\cal{F}
, we have

{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime\prime})\leq{\mathcal{F}}({\mathbf{z}}+{\mathbf{q}})\leq\frac{2}{\alpha-1}\cdot{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime}),

which shows progress.
Thus, the learner can apply this iterative procedure of updating
{\mathbf{z}}^{\prime}
will converge to
{\mathbf{z}}
within
\mathcal{O}\left(\log n\right)
steps, after which the learner will have recovered
{\mathbf{z}}
.
A similar analysis can be applied for
{\mathcal{F}}
that only satisfies approximate triangle inequality.
We can then apply the same framework with a corrector, an estimator, and a learner and in fact, we can use recursion and design a robust algorithm that outputs a
\Theta(1)
-approximation to
{\mathcal{F}}
using
n^{1/C}
levels for some constant
C>1
.

, as follows.
Let
{\mathbf{z}}^{\prime}
be the value of the iterate
{\mathbf{v}}
prior to an update.
We observe that whenever the estimator outputs an inaccurate value for
\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}
, there must be correlation between the residual
{\mathbf{z}}-{\mathbf{z}}^{\prime}
and the current query
{\mathbf{q}}+{\mathbf{z}}^{\prime}
, since an incorrect estimate implies

|\langle{\mathbf{z}}-{\mathbf{z}}^{\prime},{\mathbf{q}}+{\mathbf{z}}^{\prime}\rangle|\geq\varepsilon\cdot\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}\cdot\|{\mathbf{q}}+{\mathbf{z}}^{\prime}\|_{2}.

Then by updating
{\mathbf{z}}^{\prime}
to
{\mathbf{z}}^{\prime\prime}={\mathbf{z}}^{\prime}+\alpha({\mathbf{q}}+{\mathbf{z}}^{\prime})
, where the step-size
\alpha
is chosen proportional to the residual magnitude, possibly flipped in sign according to

and using

as a progress measure, one can verify that

\|{\mathbf{z}}-{\mathbf{z}}^{\prime\prime}\|_{2}^{2}\leq(1-\varepsilon^{2})\|{\mathbf{z}}-{\mathbf{z}}^{\prime}\|_{2}^{2},

so each iteration makes nontrivial progress toward learning

.
We remark the step-size

can be approximated within a
(1\pm\varepsilon)
factor using the estimate
P_{i}
and

with high probability.
Now since

Lemma 2.3

For each

We now upper bound the number of times
L_{i}
that the iterate
v
in block
C_{i,j}
at any level

is updated, across all times in the stream.

Lemma 2.5

(Bounded iterations)
.

Let
L_{i}
be the number of times that the iterate
{\mathbf{v}}
in a particular block at level
i\in[H]
is updated and let
\eta=\Theta\left(\frac{\varepsilon}{H}\right)
.
With high probability,
L_{i}\leq\mathcal{O}\left(\frac{1}{\eta^{2}}\log n\right)
for all
i\in[H]
and for all times in the stream, for
m\leq\poly(n)
.

Proof.

For any fixed level
i\in[H]
and for any fixed time in the stream, let
{\mathcal{P}}_{i}
and
{\mathcal{P}}_{i+1}
be the active blocks at levels
i
and
i+1
respectively.
Let
{\mathbf{z}}
be the frequency vector corresponding to all the updates prior to
{\mathcal{P}}_{i+1}
.
Conditioned on the correctness guarantees of
{\mathsf{EstLevel}}
in
Lemma

2.3
, we have that

\displaystyle\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}+\|{\mathbf{v}}+{\mathbf{q}}\|_{2}^{2}\leq{\mathsf{EstLevel}}(i,{\mathbf{B}}_{i+1}{\mathbf{z}})\leq(1+\eta)\cdot\left(\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}+\|{\mathbf{v}}+{\mathbf{q}}\|_{2}^{2}\right).

If the iterate
{\mathbf{v}}
is updated, then it must be that the estimate is inaccurate, so that

\left\lvert\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}+\|{\mathbf{v}}+{\mathbf{q}}\|_{2}^{2}-\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}\right\rvert\geq\eta\cdot\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}.

By expanding the left hand side, we get

\displaystyle|\langle{\mathbf{z}}-{\mathbf{v}},{\mathbf{v}}+{\mathbf{q}}\rangle|

\displaystyle\geq\frac{\eta}{2}\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}

\displaystyle=\frac{\eta}{2}\left(\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}+2\langle{\mathbf{z}}-{\mathbf{v}},{\mathbf{v}}+{\mathbf{q}}\rangle+\|{\mathbf{v}}+{\mathbf{q}}\|_{2}^{2}\right).

Suppose
\langle{\mathbf{z}}-{\mathbf{v}},{\mathbf{v}}+{\mathbf{q}}\rangle\geq\frac{\eta}{2}\cdot\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}
. By rearranging the inequality above, we get

\displaystyle(1-\eta)\cdot\langle{\mathbf{z}}-{\mathbf{v}},{\mathbf{v}}+{\mathbf{q}}\rangle

\displaystyle\geq\frac{\eta}{2}\left(\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}+\|{\mathbf{v}}+{\mathbf{q}}\|_{2}^{2}\right)

\displaystyle\geq\eta\cdot\|{\mathbf{z}}-{\mathbf{v}}\|_{2}\cdot\|{\mathbf{v}}+{\mathbf{q}}\|_{2}

Therefore, it follows that
\langle{\mathbf{z}}-{\mathbf{v}},{\mathbf{v}}+{\mathbf{q}}\rangle\geq\eta\cdot\|{\mathbf{z}}-{\mathbf{v}}\|_{2}\cdot\|{\mathbf{v}}+{\mathbf{q}}\|_{2}
.
Then,
{\mathsf{MaintainIter}}
will update
{\mathbf{v}}
to
{\mathbf{v}}^{\prime}={\mathbf{v}}+\alpha({\mathbf{v}}+{\mathbf{q}})
for some step-size parameter
\alpha\in[-1,1]
.
To upper bound the total number of times this occurs, we will consider the progress measure
\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}-\|{\mathbf{z}}-{\mathbf{v}}^{\prime}\|_{2}^{2}
.
First, we have that

\displaystyle\|{\mathbf{z}}-{\mathbf{v}}^{\prime}\|_{2}^{2}=\|{\mathbf{z}}-{\mathbf{v}}-\alpha({\mathbf{v}}+{\mathbf{q}})\|_{2}^{2}=\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}-2\alpha\langle{\mathbf{z}}-{\mathbf{v}},{\mathbf{v}}+{\mathbf{q}}\rangle+\alpha^{2}\cdot\|{\mathbf{v}}+{\mathbf{q}}\|_{2}^{2}.

So, it follows that

\displaystyle\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}-\|{\mathbf{z}}-{\mathbf{v}}^{\prime}\|_{2}^{2}

\displaystyle\geq 2\alpha\langle{\mathbf{z}}-{\mathbf{v}},{\mathbf{v}}+{\mathbf{q}}\rangle-\alpha^{2}\cdot\|{\mathbf{v}}+{\mathbf{q}}\|_{2}^{2}

\displaystyle\geq 2\alpha\cdot\eta\|{\mathbf{z}}-{\mathbf{v}}\|_{2}\cdot\|{\mathbf{v}}+{\mathbf{q}}\|_{2}-\alpha^{2}\cdot\|{\mathbf{v}}+{\mathbf{q}}\|_{2}^{2}.

For any
\alpha=\Theta(\eta)\cdot\frac{\|{\mathbf{z}}-{\mathbf{v}}\|_{2}}{\|{\mathbf{v}}+{\mathbf{q}}\|_{2}}
where the constant ranges in
\left[\frac{1}{10},\frac{1}{2}\right)
, we get that

\displaystyle\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}-\|{\mathbf{z}}-{\mathbf{v}}^{\prime}\|_{2}^{2}\geq\frac{\eta^{2}}{100}\cdot\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}.

Similarly, suppose that
\langle{\mathbf{z}}-{\mathbf{v}},{\mathbf{v}}+{\mathbf{q}}\rangle\leq-\frac{\eta}{2}\cdot\|{\mathbf{z}}+{\mathbf{q}}\|_{2}^{2}
.
Then, we see that

\displaystyle\langle{\mathbf{z}}-{\mathbf{v}},{\mathbf{v}}+{\mathbf{q}}\rangle

\displaystyle\leq-\frac{\eta}{2}\left(\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}+2\langle{\mathbf{z}}-{\mathbf{v}},{\mathbf{v}}+{\mathbf{q}}\rangle+\|{\mathbf{v}}+{\mathbf{q}}\|_{2}^{2}\right).

So, it follows that
(1+\eta)\cdot\langle{\mathbf{z}}-{\mathbf{v}},{\mathbf{v}}+{\mathbf{q}}\rangle\leq-\eta\cdot\|{\mathbf{z}}-{\mathbf{v}}\|_{2}\cdot\|{\mathbf{q}}+{\mathbf{v}}\|_{2}
, e.g.

-\langle{\mathbf{z}}-{\mathbf{v}},{\mathbf{v}}+{\mathbf{q}}\rangle\geq\frac{\eta}{2}\cdot\|{\mathbf{z}}-{\mathbf{v}}\|_{2}\cdot\|{\mathbf{q}}+{\mathbf{v}}\|_{2}.

As before, we consider the progress measure
\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}-\|{\mathbf{z}}-{\mathbf{v}}^{\prime}\|_{2}^{2}
:

\displaystyle\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}-\|{\mathbf{z}}-{\mathbf{v}}^{\prime}\|_{2}^{2}

\displaystyle\geq 2\alpha\langle{\mathbf{z}}-{\mathbf{v}},{\mathbf{v}}+{\mathbf{q}}\rangle-\alpha^{2}\cdot\|{\mathbf{q}}+{\mathbf{v}}\|_{2}^{2}.

For
\alpha=-\Theta(\eta)\cdot\frac{\|{\mathbf{z}}-{\mathbf{v}}\|_{2}}{\|{\mathbf{q}}+{\mathbf{v}}\|_{2}}
with any constant in the range
\left[\frac{1}{10},\frac{1}{2}\right)
, we have

\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}-\|{\mathbf{z}}-{\mathbf{v}}^{\prime}\|_{2}^{2}\geq\frac{\eta^{2}}{100}\cdot\|{\mathbf{z}}-{\mathbf{v}}\|_{2}^{2}.

Thus, we have shown that
\|{\mathbf{z}}-{\mathbf{v}}^{\prime}\|_{2}^{2}
decreases by a factor of
(1-\mathcal{O}\left(\eta^{2}\right))
in both cases.
Observe that since
\|{\mathbf{z}}\|_{2}^{2}\leq\poly(n)
, then this holds even when the image of
{\mathbf{v}}^{\prime}
is truncated to a sufficiently fine precision
\frac{1}{\poly(n)}
.
Moreover, since
{\mathbf{v}}=\mathbf{0}^{n}
originally and
\|{\mathbf{z}}\|_{2}^{2}\leq\poly(n)
, we get that
{\mathbf{v}}
will be updated at most
\mathcal{O}\left(\frac{1}{\eta^{2}}\log n\right)
times.
∎

Proof.

First, observe that a randomized adversary is a distribution over sequences of possible inputs and the probability that the attack succeeds is at most the maximum of the probabilities that any particular input sequence succeeds.
Thus, without loss of generality, it suffices to consider a deterministic adversary.

We first track the adaptive interactions with the linear sketches for the corrector.
Note that at each time,
{\mathsf{MaintainIter}}
asks each
F_{2}
linear sketch
{\mathbf{B}}_{i}
whether to update the iterate
{\mathbf{v}}
with the query
{\mathbf{q}}
.
Therefore, the transcript from
{\mathbf{B}}_{i}
can be viewed as a sequence of symbols, either
\bot
or
\top
, so that an output of
\bot
from the sketching matrix indicates that no action should be taken, while an output of
\top
indicates that the iterate should be updated.
Suppose
\top
occurs at most
L
times throughout the stream.

This latter action also triggers a linear sketch at level
i-1
to maintain
{\mathbf{B}}_{i-1}{\mathbf{v}}^{\prime}
, where
{\mathbf{v}}^{\prime}
is the updated iterate
{\mathbf{v}}^{\prime}={\mathbf{v}}+\varepsilon({\mathbf{q}}+{\mathbf{v}})
, releases the estimate produced by
{\mathbf{B}}_{i}
, but no other information about
{\mathbf{B}}_{i}
is revealed.
Moreover, the linear sketch outputs an estimate for
F_{2}
moment at the beginning of each of the
B
blocks, encoded in
C_{1}\log n
bits, for some fixed constant
C_{1}>0
.
We remark that the entries of the truncated image of
{\mathbf{v}}
must be multiples of the precision
\frac{1}{\poly(n)}
with magnitude at most
\poly(n)

{\mathbf{v}}
could not be a good approximation to

Hence, the total number of possible output streams induced by

is at most
\binom{m}{L}\cdot\left(2^{(C_{1}\log n)}\right)^{B+L}

Since the adversary is deterministic, then any possible input stream must be induced by one of these possible output streams.
By setting the total failure probability

\delta\leq\frac{1}{(nm)^{3}}\cdot\left(\binom{m}{L}\cdot\left(2^{(C_{1}\log n)}\right)^{B+L}\right)^{-1},

then by a union bound over all possible input streams from the adversary, the sketching matrix

is correct with probability
1-\frac{1}{(nm)^{3}}

For

\log\frac{1}{\delta}=\mathcal{O}\left((L+B)\cdot\log n\right)

2.4

We next track the number of adaptive interactions to the estimator, which consists of two components
P_{i}
and

While the correctness of

It thus remains to analyze the space complexity.

B

B

3
L_{2}
Heavy-Hitters

Next, we show a natural extension of our robust
F_{2}
estimation algorithms to robustly compute the
L_{2}
heavy hitters of the frequency vector at all times in the stream.
Recall that an algorithm solves the
L_{2}
heavy hitters problem if it returns coordinate
i
whenever
|x_{i}|\geq\varepsilon\|{\mathbf{x}}\|_{2}
, and any coordinate
i
with
|x_{i}|\leq\frac{\varepsilon}{2}\|{\mathbf{x}}\|_{2}
is not returned.
Note that as a direct corollary of our robust
L_{2}
heavy hitters algorithm, we also obtain an adversarially robust algorithm that recovers the
L_{p}
heavy hitters for all
p\leq 2
.

Suppose without loss of generality that
x_{i}>0
; the algorithm is symmetric for
x_{i}<0
.
Intuitively, the main idea is to robustly approximate the
L_{2}
norm
\|{\mathbf{x}}\|_{2}\leq X\leq\left(1+\frac{\varepsilon}{100}\right)\|{\mathbf{x}}\|_{2}
; then, to identify heavy hitters, we
deterministically
iterate through each coordinate
i\in[n]
of the frequency vector, add mass
\frac{1}{2}\varepsilon\cdot X\cdot{\mathbf{e}}_{i}
to coordinate
i
, and recompute the new
L_{2}
norm
S_{i}
.
If the approximate
F_{2}
moment
S_{i}^{2}
increases by at least
1.15\cdot\varepsilon^{2}\cdot\|{\mathbf{x}}\|_{p}^{2}
, we report
i
as a heavy hitter, and move on to the next index.
This algorithm is formalized in
Figure

5
.

:

Let
{\mathcal{A}}
be a robust
L_{2}
norm estimation algorithm with accuracy
(1+\mathcal{O}\left(\varepsilon^{2}\right))

(2)

Let
{\mathbf{x}}^{(t)}
denote the frequency vector for the stream at time

, and let

Initialize
H_{t}\leftarrow\emptyset

(4)

For

for the elementary vector

Lemma 3.1
.

Let

In particular, these two cases can be distinguished by the threshold

∎

4
Approximate Triangle Inequality

In this section, we extend our robust framework for
F_{2}
estimation to a broader class of functions
{\mathcal{F}}
that satisfy an approximate triangle inequality.
Recall that for a constant
\beta>0
, a function
{\mathcal{F}}
satisfies a
\beta
-approximate triangle inequality if

{\mathcal{F}}({\mathbf{x}}-{\mathbf{z}})\leq\beta\cdot({\mathcal{F}}({\mathbf{x}}-{\mathbf{y}})+{\mathcal{F}}({\mathbf{y}}-{\mathbf{z}})),

for all vectors
{\mathbf{x}},{\mathbf{y}},{\mathbf{z}}\in\mathbb{R}^{n}
.

As before, we use the framework consisting of an estimator, a corrector, and a learner, and the algorithm maintains an iterate
{\mathbf{z}}^{\prime}
that approximates the previous stream vector
{\mathbf{z}}
.
Each incoming query
{\mathbf{q}}
is handled by estimating
P_{i}\approx{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})
and
Q_{i}\approx{\mathcal{F}}({\mathbf{z}}^{\prime}+{\mathbf{q}})
, the former using a non-adaptive sketch, and the latter using a recursive procedure.
The estimator then outputs sum of these estimates
P_{i}+Q_{i}
, which by triangle inequality is at least
{\mathcal{F}}({\mathbf{z}}+{\mathbf{q}})
.
Now, if
P_{i}+Q_{i}
is significantly larger than
{\mathcal{F}}({\mathbf{z}}+{\mathbf{q}})
, then by the approximate triangle inequality, the iterate can be updated to a new vector
{\mathbf{z}}^{\prime\prime}=-{\mathbf{q}}
in a way that provably reduces the distance to the true vector under
{\mathcal{F}}
.
Specifically,
Lemma

4.1
formalizes how such an update guarantees that
{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime\prime})
is a constant factor smaller than
{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})
, which measures progress toward learning
{\mathbf{z}}
.
As a result,
Lemma

4.2
shows that the algorithm only performs
\mathcal{O}\left(\log n\right)
updates per node
C_{i,j}
level in level
i
of the recursion.
Finally, we again use a recursive structure to upper bound the number of adaptive interactions in each level.
The important subroutine
{\mathsf{EstLevel}}
appears in
Algorithm

; it is then encapsulated within the same tree structure as
Figure

.

We begin by examining the precise condition under which the algorithm’s output
{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})+{\mathcal{F}}({\mathbf{z}}^{\prime}+{\mathbf{q}})
is not an accurate estimate of
{\mathcal{F}}({\mathbf{z}}+{\mathbf{q}})
.

Lemma 4.1

(Precondition triggering)
.

Let
{\mathcal{A}}
be an algorithm that outputs a
\kappa
-approximation to a function
{\mathcal{F}}
that satisfies
\beta
-triangle inequality and let
Z={\mathcal{A}}({\mathbf{z}}-{\mathbf{z}}^{\prime})+{\mathcal{A}}({\mathbf{z}}^{\prime}+{\mathbf{q}})
.
Suppose
Z>\kappa^{2}\cdot{\mathcal{A}}({\mathbf{z}}+{\mathbf{q}})
.
Then with high probability, for
{\mathbf{z}}^{\prime\prime}=-{\mathbf{q}}
, we have

{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime\prime})\leq\frac{\beta+1}{\kappa-\beta}\cdot{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime}).

Proof.

Conditioned on the correctness of the subroutines, we have with high probability:

(1)

Z\in\left[{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})+{\mathcal{F}}({\mathbf{z}}^{\prime}+{\mathbf{q}}),\kappa\cdot({\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})+{\mathcal{F}}({\mathbf{z}}^{\prime}+{\mathbf{q}}))\right]

(2)

{\mathcal{A}}({\mathbf{z}}+{\mathbf{q}})\in\left({\mathcal{F}}({\mathbf{z}}+{\mathbf{q}}),\kappa\cdot{\mathcal{F}}({\mathbf{z}}+{\mathbf{q}})\right]
.

Thus if
Z>\kappa^{2}\cdot{\mathcal{A}}({\mathbf{z}}+{\mathbf{q}})
, then

\kappa\cdot({\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})+{\mathcal{F}}({\mathbf{z}}^{\prime}+{\mathbf{q}}))\geq Z>\kappa^{2}\cdot{\mathcal{A}}({\mathbf{z}}+{\mathbf{q}})\geq\kappa^{2}\cdot{\mathcal{F}}({\mathbf{z}}+{\mathbf{q}}),

so that

{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})+{\mathcal{F}}({\mathbf{z}}^{\prime}+{\mathbf{q}})\geq\kappa\cdot{\mathcal{F}}({\mathbf{z}}+{\mathbf{q}}).

By the
\beta
-approximate triangle inequality property of
{\mathcal{F}}
, we have
\beta\cdot({\mathcal{F}}({\mathbf{z}}+{\mathbf{q}})+{\mathcal{F}}({\mathbf{z}}^{\prime}-{\mathbf{z}}))\geq{\mathcal{F}}({\mathbf{z}}^{\prime}+{\mathbf{q}})
.
Since
{\mathcal{F}}
is symmetric, then
\cal({\mathbf{z}}^{\prime}-{\mathbf{z}})={\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})
, so that

(\beta+1)\cdot{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})\geq(\kappa-\beta)\cdot{\mathcal{F}}({\mathbf{z}}+{\mathbf{q}}).

Therefore, we have
{\mathcal{F}}({\mathbf{z}}-(-{\mathbf{q}}))\leq\frac{\beta+1}{\kappa-\beta}\cdot{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})
, which gives our notion of progress by updating the iterate from
{\mathbf{z}}^{\prime}
to
{\mathbf{z}}^{\prime\prime}=-{\mathbf{q}}
.
∎

Next, we show that when the estimator is inaccurate on a query, we have a notion of progress, in the sense that
{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime\prime})
is a constant factor smaller than
{\mathcal{F}}({\mathbf{z}}-{\mathbf{z}}^{\prime})
, where
{\mathbf{z}}^{\prime}
and
{\mathbf{z}}^{\prime\prime}
are the iterates maintained before and after the query. Note that since
\mathcal{F}
satisfies a
\beta
-approximate triangle inequality, we have
\mathcal{F}({\mathbf{z}}-{\mathbf{z}}^{\prime})+\mathcal{F}({\mathbf{z}}^{\prime}+{\mathbf{q}})\geq\frac{1}{\beta}\cdot\mathcal{F}({\mathbf{z}}+{\mathbf{q}})
. As a result, we conclude that the number of iterations that the estimate
{\mathbf{v}}
to
{\mathbf{z}}
can change is at most
\mathcal{O}\left(\log n\right)
times.

We now justify the guarantees of our algorithm, which again uses
{\mathsf{EstLevel}}
as a building block within the tree structure from
Figure

3
.
See
1.5

Proof.

We first reduce to a deterministic adversary.
A randomized adversary is simply a distribution over input streams, and the probability that it succeeds is at most the maximum over deterministic sequences.
Hence, it suffices to consider a deterministic adversary.

We now track the interactions with the sketches maintained by
Algorithm

3
.
At each time,
{\mathsf{EstLevel}}
queries the sketch at level
i
to determine whether to update the iterate
{\mathbf{v}}
.
The output of a sketch can be viewed as a symbol:
\bot
if no update occurs,
\top
if the iterate is updated.
By
Lemma

4.2
, the number of times
\top
occurs at level
i
is at most
L_{i}=\mathcal{O}\left(\log n\right)
with high probability.

Each update at level
i
triggers a query to level
i-1
but does not reveal additional information about level
i
.
Moreover, at the beginning of each block, the sketch outputs a
\kappa^{i}
-approximation encoded in
\mathcal{O}\left(1\right)
words.
Hence, the total number of possible output transcripts at level
i
is at most
\binom{m}{L_{i}}\cdot\mathcal{O}\left(1\right)^{B+L_{i}}
, where
B
is the number of blocks per level.

Now, to achieve constant-factor approximation, we require
\kappa^{\mathcal{O}\left(H\right)}=\mathcal{O}\left(1\right)
, and thus we require
H=\mathcal{O}\left(1\right)
.
In particular, for any constant
C>1
, there exists
H=\mathcal{O}\left(1\right)
such that the sizes of all blocks at the bottom level are at most
n^{1/C}
.
Moreover, we remark that each output by the estimator and by the estimate of
P_{i}
is at most
\mathcal{O}\left(\log n\right)
bits.
Thus the number of possible output transcripts at the bottom level is at most
\left(2^{(C_{1}\log n)}\right)^{n^{1/C}+L}
for a fixed constant
C_{1}>0
, while at the other levels, the number of possible transcripts is at most
\binom{m}{L}\cdot\left(2^{(C_{1}\log n)}\right)^{B+L}
.
Thus if we set
B=\mathcal{O}\left(n^{1/C}\right)
, then it suffices to set the failure probability of each sketch so that
\log\frac{1}{\delta}\leq\mathcal{O}\left(n^{1/C}\right)\cdot\log m
for some constant
C>1
.
Conditioned on the correctness of the sketches, the iterate updates always make progress by
Lemma

4.1
.
Specifically, each update reduces the function
{\mathcal{F}}({\mathbf{z}}-{\mathbf{v}})
by a constant factor.
Since
{\mathcal{F}}
takes values in
\left[\frac{1}{\poly(m)},\poly(m)\right]
, this guarantees that each level performs at most
\mathcal{O}\left(\log n\right)
updates, which matches the bound
L_{i}
.

For space complexity, observe that each sketch requires failure probability
\log\frac{1}{\delta}\leq\mathcal{O}\left(n^{1/C}\right)\cdot\log m
.
Since each sketch uses space
S(n)\cdot\log\frac{1}{\delta}
, then each sketch uses space
\tilde{\mathcal{O}}\left(n^{1/C}\right)\cdot S(n)
.
In fact, despite setting
B=\mathcal{O}\left(n^{1/C}\right)
, the total space at a particular level is
\tilde{\mathcal{O}}\left(n^{1/C}\right)\cdot S(n)
because it suffices to maintain a single active sketch per level at any given time.
Since there are
H=\mathcal{O}\left(1\right)
levels, the resulting space bound follows.

Finally, correctness follows from the triangle inequality argument: the iterate updates always ensure that the output is a
\kappa^{\mathcal{O}\left(C\right)}
-approximation to
{\mathcal{F}}
at all times.
Hence, the algorithm is adversarially robust and achieves the claimed space and approximation guarantees.
∎

Applications.

We now present several detailed examples of functions that satisfy the approximate triangle inequality.
The first example is
\mathcal{F}({\mathbf{x}})=\left\lVert{\mathbf{x}}\right\rVert_{p}^{p}
for
p\geq 0
.

Lemma 4.3
.

For any
{\mathbf{x}},{\mathbf{y}}\in\mathbb{R}^{n}
and
p\in[0,1]
, we have
\left\lVert{\mathbf{x}}+{\mathbf{y}}\right\rVert_{p}^{p}\leq\left\lVert{\mathbf{x}}\right\rVert_{p}^{p}+\left\lVert{\mathbf{y}}\right\rVert_{p}^{p}
.

Proof.

Recall that for
0\leq p\leq 1
, for any
x,y\in\mathbb{R}
, we have
|x+y|^{p}\leq|x|^{p}+|y|^{p}
. Then, we observe that

\left\lVert{\mathbf{x}}+{\mathbf{y}}\right\rVert_{p}^{p}=\sum_{i=1}^{n}|x_{i}+y_{i}|^{p}\leq\sum_{i=1}^{n}(|x_{i}|^{p}+|y_{i}|^{p})\leq\left\lVert{\mathbf{x}}\right\rVert_{p}^{p}+\left\lVert{\mathbf{y}}\right\rVert_{p}^{p}\;.\qed

Lemma 4.4
.

For any
{\mathbf{x}},{\mathbf{y}}\in\mathbb{R}^{n}
and
p\geq 1
, we have
\left\lVert{\mathbf{x}}+{\mathbf{y}}\right\rVert_{p}^{p}\leq 2^{p-1}\left(\left\lVert{\mathbf{x}}\right\rVert_{p}^{p}+\left\lVert{\mathbf{y}}\right\rVert_{p}^{p}\right)
.

Proof.

Recall that for
p\geq 1
, for any
x,y\in\mathbb{R}
, we have
|x+y|^{p}\leq 2^{p-1}(|x|^{p}+|y|^{p})
. Then, we observe that

\left\lVert{\mathbf{x}}+{\mathbf{y}}\right\rVert_{p}^{p}=\sum_{i=1}^{n}|x_{i}+y_{i}|^{p}\leq\sum_{i=1}^{n}2^{p-1}(|x_{i}|^{p}+|y_{i}|^{p})\leq 2^{p-1}(\left\lVert{\mathbf{x}}\right\rVert_{p}^{p}+\left\lVert{\mathbf{y}}\right\rVert_{p}^{p})\;.\qed

We next consider the function
\mathcal{F}
that has the form
\mathcal{F}({\mathbf{x}})=\sum_{i=1}^{n}g(x_{i})
for some function
g
such that
g(t)=f(t^{2})
for some Bernstein function
f
.
Specifically, the following are several examples of such a function

, which are common in robust statistics.

•

(Pseudo–Huber Loss):
g_{\tau}(x)=\tau(\sqrt{1+(x/\tau)^{2}}-1)

•

(Cauchy/Lorentzian Loss):
g_{\tau}(x)=\log(1+x^{2}/\tau)

•

(Generalized Charbonnier):
g_{\tau}=(1+x^{2}/\tau)^{\beta}-1
for
0<\beta\leq 1
.

•

(Welsch/Leclerc Loss):
g_{\tau}(x)=1-e^{x^{2}/\tau}

•

(Geman–McClure loss):
\displaystyle g_{\tau}=\frac{x^{2}}{x^{2}+\tau}

Definition 4.5

(Bernstein function, e.g.,
[
SSV12
]
)
.

A function
f:(0,\infty)\to[0,\infty)
is called a
Bernstein function
if
f\in C^{\infty}(0,\infty)
and its derivative
f^{\prime}
is completely monotone; that is, for all
n\in\mathbb{N}_{0}
and all
x>0
,

(-1)^{n}f^{(n+1)}(x)\geq 0.

Let
f
be any Bernstein function with
f(0)=0
. We now show that any function
g
defined by
g(t)=f(t^{2})
satisfies the approximate triangle inequality with
\beta=2
.
As in the proof of
Lemma
4.3
, it suffices for us to consider the one-dimensional case.

Lemma 4.6
.

Suppose that the function
g(t)=f(t^{2})
for some Bernstein function
f
and
g(0)=0
.
Then for any
a,b\in\mathbb{R}
, we have
g(a+b)\leq 2((g(a)+g(b))
.

Proof.

Since
f
is a Bernstein function, we have
f^{\prime}(x)\geq 0
and
f^{\prime\prime}(x)\leq 0
for all
x>0
, so
f
is increasing and concave.
Also,
g(0)=0
implies
f(0)=0
.

Concavity and
f(0)=0
imply that
f
is subadditive on
[0,\infty)
, i.e.,
f(x+y)\leq f(x)+f(y)
for all
x,y\geq 0
, and that
f(2x)\leq 2f(x)
for all
x\geq 0
.

Now, for any
a,b\in\mathbb{R}
, we have
(a+b)^{2}\leq 2a^{2}+2b^{2}
, so

g(a+b)=f((a+b)^{2})\leq f(2a^{2}+2b^{2})\leq f(2a^{2})+f(2b^{2})\leq 2(f(a^{2})+f(b^{2}))=2(g(a)+g(b)).

∎

Next, we recall several classical results from the streaming literature.
Note that in order to apply our framework, we require a non-robust sketch for the chosen function

.

describes a sufficient condition under which the function

Lemma 4.7

(Zero-one law for normal functions,
[

]
)
.

Let

There exists a one-pass turnstile streaming algorithm that provides a

A function

is

and
x<y

g(x)\leq g(y)h(y)
.

(2)

A function
g\in\mathcal{G}
is slow-jumping if and only if there exists a sub-polynomial function
h
such that for any
x<y

g(y)\leq\lfloor y/x\rfloor^{2}\,h(\lfloor y/x\rfloor\,x)\,g(x)

(3)

g\in\mathcal{G}

or

.

In particular, if the function

Lemma 4.8
.

Suppose that the function
f:(0,\infty)\to[0,\infty)
is a Bernstein function and
g(x)=f(x^{2})
.
Then

(1)

g
is slow-dropping with
h(x)=1
.

(2)

g
is slow-jumping with
h(x)=4
.

(3)

g
is predictable with
h(x)=\lceil 3/\varepsilon(x)\rceil
.

Proof.

(1) Since
f
is a Bernstein function, we have
f^{\prime}\geq 0
, which implies that
f
is non-decreasing.
Therefore
g(x)=f(x^{2})
is also non-decreasing on positive input, and for
x<y
we have
g(x)\leq g(y)
, showing that
g
is slow-dropping with
h(x)=1
.

(2) Since
f
is a Bernstein function, its derivative
f^{\prime}
exists and is non-increasing.
Define

s(t):=\frac{f(t)-f(0)}{t}=\frac{1}{t}\int_{0}^{t}f^{\prime}(u)\,du,\qquad t>0.

Because
f^{\prime}
is non-increasing,
s(t)
is non-increasing, so for
0<x<y
we have
s(y)\leq s(x)
.
Therefore,

\frac{f(y)}{y}=\frac{f(0)}{y}+s(y)\leq\frac{f(0)}{y}+s(x)\leq\frac{f(0)}{x}+s(x)=\frac{f(x)}{x}.

This shows that
f(y)\leq\frac{y}{x}f(x)
for
y\geq x>0
, and hence

g(y)=f(y^{2})\leq\frac{y^{2}}{x^{2}}f(x^{2})=\frac{y^{2}}{x^{2}}g(x).

Thus for the relevant input range, we can upper bound
(y/x)^{2}\leq 4
, showing that
g
slow-jumping with
h(x)=4
.

(3) Since
f
is concave and increasing with
f(0)\geq 0
, we have

f^{\prime}(t)\leq\frac{f(t)}{t}\qquad(t>0).

Let
g(x)=f(x^{2})
and write
\Delta:=(x+y)^{2}-x^{2}=2xy+y^{2}
.
Then

\frac{|g(x+y)-g(x)|}{g(x)}=\frac{f(x^{2}+\Delta)-f(x^{2})}{f(x^{2})}\leq\frac{f^{\prime}(x^{2})}{f(x^{2})}\Delta\leq\frac{\Delta}{x^{2}}=2\frac{y}{x}+\left(\frac{y}{x}\right)^{2}.

With
y\leq x/h(x)\leq(\varepsilon(x)/3)\,x
, we have
y/x\leq\varepsilon(x)/3
, hence

2\frac{y}{x}+\left(\frac{y}{x}\right)^{2}\leq\frac{2}{3}\varepsilon(x)+\frac{1}{9}\varepsilon(x)^{2}\leq\frac{7}{9}\varepsilon(x)<\varepsilon(x),

where we used
\varepsilon(x)\leq 1
. Therefore

\frac{|g(x+y)-g(x)|}{g(x)}\leq\varepsilon(x),

which shows that
g
is predictable with
h(x)=\lceil 3/\varepsilon(x)\rceil
.
∎

Finally, we combine
Lemma
4.7
and
Lemma
4.8
to conclude that there exists a non-robust turnstile streaming algorithm for functions
g
satisfying
Lemma
4.8
.

Lemma 4.9
.

Given a function
g:\mathbb{Z}_{n\geq 0}\to\mathbb{R}
, where
g(x)=f(x^{2})
for some Bernstein function
f
, there exists a one-pass (non-robust) turnstile streaming algorithm that with high probability, outputs a
(1\pm\varepsilon)
-approximation to
\|{\mathbf{x}}\|_{g}=\sum_{i=1}^{n}g(x_{i})
using space
\poly\left(\frac{1}{\varepsilon},\log n\right)
.
