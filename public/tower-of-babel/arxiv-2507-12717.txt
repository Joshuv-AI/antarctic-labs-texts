On the Properties of Optimal-Decay Control Barrier Functions
Pio Ong, Max H. Cohen, Tamas G. Molnar, Aaron D. Ames

Abstract
Control barrier functions provide a powerful means for synthesizing safety filters that ensure safety framed as forward set invariance. Key to CBFs’ effectiveness is the simple inequality on the system dynamics: h ˙ ≥ − α ⁡ ( h ) \dot{h}\geq-\alpha(h) . Yet determining the class 𝒦 e \mathcal{K}^{e} function α \alpha is a user defined choice that can have a dramatic effect on the resulting system behavior. This paper formalizes the process of choosing α \alpha using optimal-decay control barrier functions (OD-CBFs). These modify the traditional CBF inequality to: h ˙ ≥ − ω ​ α ​ ( h ) \dot{h}\geq-\omega\alpha(h) , where ω ≥ 0 \omega\geq 0 is automatically determined by the safety filter. A comprehensive characterization of this framework is elaborated, including tractable conditions on OD-CBF validity, control invariance of the underlying sets in the state space, forward invariance conditions for safe sets, and discussion on optimization-based safe controllers in terms of their feasibility, Lipschitz continuity, and closed-form expressions. The framework also extends existing higher-order CBF techniques, addressing safety constraints with vanishing relative degrees. The proposed method is demonstrated on a satellite control problem in simulation.



I
Introduction

Control barrier functions (CBFs), first conceptualized in
[
1
]
and later refined in

[
2
]
, provide a framework for safety-critical control of nonlinear systems through the concept of set invariance
[
3
]
. A core contribution of the modern version of CBFs introduced in
[
2
]
over previous versions
[
1
]
, and other instantiations of barrier functions (BFs)
[
4
]
, is the addition of an extended class
\mathcal{K}
function, denoted by
\mathcal{K}^{e}
, to the Lyapunov-like inequality characterizing safety. This modification has important practical ramifications: rather than every superlevel set, only the zero superlevel set of the BF
is rendered forward invariant; this set is also, under certain assumptions, asymptotically stable
[
5
,
6
]
; and the set of safe controllers meeting the corresponding CBF requirement is greatly expanded, facilitating the use of optimization-based control approaches, typically via quadratic programs (QPs). This modern notion of a BF also closes the gap between the necessary and sufficient conditions for set invariance originally stated by Nagumo
[
7
]
(see
[
3
, Ch. 4.2]
and
[
8
, Ch. 4.1]
for a modern account) in that compact forward invariant sets necessarily admit a BF satisfying the Lyapunov-like conditions in
[
2
]
.

Although the modern version of CBFs
[
2
]
has expanded the practical applications of safety-critical control techniques, this class
\mathcal{K}^{e}
function characterization of set invariance also brings certain drawbacks. Namely, one must now not only search for a control invariant set – the zero superlevel set of the corresponding CBF – contained within a desirable set of system states (that is a challenging problem on its own), but also for a class
\mathcal{K}^{e}
function compatible with the dynamics and invariant set. When the CBF has a uniform relative degree and the set of admissible inputs is unbounded, any class
\mathcal{K}^{e}
function will be compatible with the dynamics and CBF. However, if there exist states where the (candidate) CBF’s relative degree vanishes or the set of admissible inputs is bounded, the choice of class
\mathcal{K}^{e}
function significantly impacts the validity of this candidate CBF.

The challenges associated with searching for a compatible class
\mathcal{K}^{e}
function in the modern CBF framework are further amplified when using higher-order CBF techniques, such as exponential CBFs (ECBFs)
[
9
]
and high-order CBFs (HOCBFs)
[
10
,
11
]
. Such techniques dynamically extend a given safety constraint that does not meet the criteria of a CBF to a new function that, under certain conditions, is a valid certificate for set invariance and satisfies a Lyapunov-like inequality characterized by a class
\mathcal{K}^{e}
function. Yet, as illustrated in, e.g.,
[
12
, Example 1]
and
[
13
, Example 5]
, there often exists no class
\mathcal{K}^{e}
function compatible with the dynamics and corresponding ECBF/HOCBF if there exist points within the safe set where the relative degree of such an ECBF/HOCBF vanishes, even if the admissible set of inputs is unbounded. That is, even for seemingly benign dynamics and safety constraints, ECBFs and HOCBFs, as defined in
[
9
,
10
,
11
]
, may not exist. Alternative higher-order CBF techniques, such as rectified CBFs (ReCBFs)
[
12
]
and backstepping CBFs
[
14
,
15
]
, maintain compatibility of the class
\mathcal{K}^{e}
function under vanishing relative degree by construction, but this phenomenon can often degrade performance by producing controllers with large Lipschitz constants. Indeed, as studied in
[
16
]
, sampled-data implementations of CBF-based controllers with vanishing relative degree can produce chattering despite the fact that, under certain assumptions
[
17
]
, such inputs are guaranteed to be locally Lipschitz when implemented in continuous-time.

One technique that has the potential to address some of these aforementioned limitations is to scale the class
\mathcal{K}^{e}
function by a tunable coefficient whose value is optimized, in real-time, alongside the control input. Specifically, CBF-based control inputs are typically computed as the solution to a QP, and by adding a tunable coefficient as a decision variable to this QP, one effectively gains an additional control input that provides more flexibility to satisfy the Lyapunov-like conditions for set invariance. This approach is used often among practitioners, but there is relatively little information in the formal CBF literature concerning the properties of this approach, with exceptions being
[
18
]
and
[
19
]
. In particular,
[
18
]
is, to our knowledge, the first to explicitly acknowledge that one may optimize such a coefficient within the CBF-QP, but does not establish any properties of the resulting controller. The most in-depth study of this technique is presented in
[
19
]
in the context of ensuring feasibility for CBF-QPs in the presence of bounded inputs, where the corresponding controller is referred to as an
optimal decay
CBF-QP (OD-CBF-QP). Importantly,
[
19
]
establishes that this OD-CBF-QP is feasible for any point on the interior of the safe set, but does not make any statements regarding feasibility on the boundary (a necessary condition for safety), feasibility outside the safe set (useful for ensuring stability of the safe set), or Lipschitz continuity of the resulting controller (needed to guarantee existence and uniqueness of solutions to the closed-loop system).

In this paper, we build upon the insights of
[
18
,
19
]
to provide a rigorous characterization of OD-CBFs and their properties. We begin with motivating our developments by introducing a generalized notion of a BF, an optimal decay BF (OD-BF). The main advantage of OD-BFs over those in
[
2
]
is that OD-BFs provide tighter connections to Nagumo’s conditions for set invariance: OD-BFs are necessary and sufficient for set invariance without any compactness assumptions. With this as motivation, we then revisit OD-CBFs as introduced in
[
18
,
19
]
. Here, we provide tractable conditions to verify that a given function is an OD-CBF, establish the feasibility of the corresponding OD-CBF-QP at all points in the safe set, illustrate that the resulting controller is locally Lipschitz continuous, and that it renders the safe set forward invariant. Under further assumptions, we show that the OD-CBF-QP is also feasible outside the safe set and renders the safe set asymptotically stable if it is compact. We then extend these developments to higher-order CBF techniques to address the aforementioned issues with a vanishing relative degree, and highlight via numerical examples the advantage of the OD-CBF framework over traditional CBF approaches. Finally, we showcase the developed framework on a more complicated satellite control problem.

Optimal-Decay CBFs

Verifying (
12

Building on the CBF-QP control formulation, the optimal-decay CBF-QP simultaneously solves for a scaling factor multiplying

\displaystyle\begin{bmatrix}\mathbf{k}(\mathbf{x})\\
\theta(\mathbf{x})\end{bmatrix}

\displaystyle=\argmin_{\begin{subarray}{c}\mathbf{u}\in\real^{m}\\
\omega\in\mathbb{R}_{\geq 0}\end{subarray}}\tfrac{1}{2}\|\mathbf{u}-\mathbf{k}_{\operatorname{d}}(\mathbf{x})\|_{\boldsymbol{\Gamma}}^{2}+\tfrac{1}{2}p(\omega-\theta_{\operatorname{d}})^{2}

\displaystyle=\mathbf{k}_{\operatorname{d}}(\mathbf{x})+\phi\big(a(\mathbf{x}),\|\mathbf{b}(\mathbf{x})\|_{\boldsymbol{\Gamma}},c(\mathbf{x})\big)\mathbf{b}(\mathbf{x}),

(17)

\displaystyle a(\mathbf{x})

\displaystyle=L_{\mathbf{f}}h(\mathbf{x})+L_{\mathbf{g}}h(\mathbf{x})\mathbf{k}_{\operatorname{d}}(\mathbf{x})+\theta_{\operatorname{d}}\alpha(h(\mathbf{x})),

\displaystyle\mathbf{b}(\mathbf{x})

\displaystyle=\boldsymbol{\Gamma}^{-1}L_{\mathbf{g}}h(\mathbf{x})^{\top},\quad c(\mathbf{x})=p^{-1}\alpha(h(\mathbf{x})),

\displaystyle\phi(a,

\displaystyle b,c)=\begin{cases}0&\mathrm{if}\ b=0\ \wedge\ c\leq 0,\\
\frac{{\operatorname{ReLU}}(-a)}{b^{2}+p{\operatorname{ReLU}}(c)^{2}}&\mathrm{otherwise},\end{cases}

whereas the corresponding optimal decay rate is:

\displaystyle\theta(\mathbf{x})

\displaystyle=\theta_{\operatorname{d}}+\psi\big(a(\mathbf{x}),\|\mathbf{b}(\mathbf{x})\|_{\boldsymbol{\Gamma}},c(\mathbf{x})\big),

(18)

\displaystyle\chi(a,

\displaystyle b,c)=\begin{cases}0&\mathrm{if}\ b=0\ \wedge\ c\leq 0,\\
\frac{{\operatorname{ReLU}}(-a){\operatorname{ReLU}}(c)}{b^{2}+pc^{2}}&\mathrm{otherwise}.\end{cases}

Proof.

First, we notice that the first constraint in (
13
) can be represented using
a
,
\mathbf{b}
, and
c
in (
17
) as:

\displaystyle L_{\mathbf{f}}h(\mathbf{x})+L_{\mathbf{g}}h(\mathbf{x})\mathbf{u}+\omega\alpha(h(\mathbf{x}))

\displaystyle=a(\mathbf{x})+\mathbf{b}(\mathbf{x})^{\top}\boldsymbol{\Gamma}\big(\mathbf{u}-\mathbf{k}_{\operatorname{d}}(\mathbf{x})\big)+c(\mathbf{x})p(\omega-\theta_{\operatorname{d}}).

The QP (
13
) is feasible if and only if:

\mathbf{b}(\mathbf{x})=\mathbf{0}\;\wedge\;c(\mathbf{x})\leq 0\implies a(\mathbf{x})\geq 0.

(19)

Because the OD-CBF property (
16
) is equivalent to
{\mathbf{b}(\mathbf{x})=\mathbf{0}\;\wedge\;c(\mathbf{x})=0\implies a(\mathbf{x})>0}
, feasibility holds for all
{\mathbf{x}\in\mathcal{C}}
, i.e., when
{c(\mathbf{x})\geq 0}
.

We solve the QP (
13
) using the Karush-Kuhn-Tucker (KKT) conditions from
[
22
]
:

\displaystyle a(\mathbf{x})+\mathbf{b}(\mathbf{x})^{\top}\hat{\mathbf{k}}(\mathbf{x})+c(\mathbf{x})\hat{\theta}(\mathbf{x})

\displaystyle\geq 0,

(20)

\displaystyle p^{-1}\hat{\theta}(\mathbf{x})\geq 0,~\lambda_{\mathbf{u}}(\mathbf{x})\geq 0,~\lambda_{\omega}(\mathbf{x})

\displaystyle\geq 0,

\displaystyle\lambda_{\mathbf{u}}(\mathbf{x})\big(a(\mathbf{x})+\mathbf{b}(\mathbf{x})^{\top}\hat{\mathbf{k}}(\mathbf{x})+c(\mathbf{x})\hat{\theta}(\mathbf{x})\big)

\displaystyle=0,

\displaystyle\lambda_{\omega}(\mathbf{x})p^{-1}\hat{\theta}(\mathbf{x})

\displaystyle=0,

\displaystyle\hat{\mathbf{k}}(\mathbf{x})-\lambda_{\mathbf{u}}(\mathbf{x})\boldsymbol{\Gamma}\mathbf{b}(\mathbf{x})

\displaystyle=\mathbf{0},

\displaystyle\hat{\theta}(\mathbf{x})-\lambda_{\mathbf{u}}(\mathbf{x})pc(\mathbf{x})-\lambda_{\omega}(\mathbf{x})

\displaystyle=0,

where:

\hat{\mathbf{k}}(\mathbf{x})=\boldsymbol{\Gamma}\big(\mathbf{k}(\mathbf{x})-\mathbf{k}_{\operatorname{d}}(\mathbf{x})\big),\quad\hat{\theta}(\mathbf{x})=p(\theta(\mathbf{x})-\theta_{\operatorname{d}}).

(21)

Here
{\lambda_{\mathbf{u}}:\real^{n}\rightarrow\real}
and
{\lambda_{\omega}:\real^{n}\rightarrow\real}
are Lagrange multipliers.
Based on their values, we distinguish four cases.
Case 1: if
{\lambda_{\mathbf{u}}(\mathbf{x})=0}
,
{\lambda_{\omega}(\mathbf{x})=0}
, the KKT conditions (
20
) give:

\hat{\mathbf{k}}(\mathbf{x})=\mathbf{0},\quad\hat{\theta}(\mathbf{x})=0,\quad a(\mathbf{x})\geq 0.

Case 2: if
{\lambda_{\mathbf{u}}(\mathbf{x})>0}
,
{\lambda_{\omega}(\mathbf{x})=0}
, we obtain:

\displaystyle\hat{\mathbf{k}}(\mathbf{x})

\displaystyle=\frac{-a(\mathbf{x})}{\|\mathbf{b}(\mathbf{x})\|_{\boldsymbol{\Gamma}}^{2}+pc(\mathbf{x})^{2}}\boldsymbol{\Gamma}\mathbf{b}(\mathbf{x}),\quad

\displaystyle a(\mathbf{x})<0,

\displaystyle\hat{\theta}(\mathbf{x})

\displaystyle=\frac{-a(\mathbf{x})}{\|\mathbf{b}(\mathbf{x})\|_{\boldsymbol{\Gamma}}^{2}+pc(\mathbf{x})^{2}}pc(\mathbf{x}),\quad

\displaystyle c(\mathbf{x})\geq 0.

Case 3: if
{\lambda_{\mathbf{u}}(\mathbf{x})=0}
,
{\lambda_{\omega}(\mathbf{x})>0}
, the sixth and eighth lines of the KKT conditions (
20
) contradict, and this case cannot hold.
Case 4: if
{\lambda_{\mathbf{u}}(\mathbf{x})>0}
,
{\lambda_{\omega}(\mathbf{x})>0}
, then we get:

\displaystyle\hat{\mathbf{k}}(\mathbf{x})

\displaystyle=\frac{-a(\mathbf{x})}{\|\mathbf{b}(\mathbf{x})\|_{\boldsymbol{\Gamma}}^{2}}\boldsymbol{\Gamma}\mathbf{b}(\mathbf{x}),\quad

\displaystyle a(\mathbf{x})<0,

\displaystyle\hat{\theta}(\mathbf{x})

\displaystyle=0,\quad

\displaystyle c(\mathbf{x})<0.

Overall, these cases can be combined into:

\hat{\mathbf{k}}(\mathbf{x})=\begin{cases}\mathbf{0}&\mathrm{if}\ a(\mathbf{x})\geq 0,\\
\frac{-a(\mathbf{x})}{\|\mathbf{b}(\mathbf{x})\|_{\boldsymbol{\Gamma}}^{2}+pc(\mathbf{x})^{2}}\boldsymbol{\Gamma}\mathbf{b}(\mathbf{x})&\mathrm{if}\ a(\mathbf{x})<0\;\wedge\;c(\mathbf{x})\geq 0,\\
\frac{-a(\mathbf{x})}{\|\mathbf{b}(\mathbf{x})\|_{\boldsymbol{\Gamma}}^{2}}\boldsymbol{\Gamma}\mathbf{b}(\mathbf{x})&\mathrm{if}\ a(\mathbf{x})<0\;\wedge\;c(\mathbf{x})<0,\end{cases}

\hat{\theta}(\mathbf{x})=\begin{cases}0&\mathrm{if}\ a(\mathbf{x})\geq 0,\\
\frac{-a(\mathbf{x})}{\|\mathbf{b}(\mathbf{x})\|_{\boldsymbol{\Gamma}}^{2}+pc(\mathbf{x})^{2}}pc(\mathbf{x})&\mathrm{if}\ a(\mathbf{x})<0\;\wedge\;c(\mathbf{x})\geq 0,\\
0&\mathrm{if}\ a(\mathbf{x})<0\;\wedge\;c(\mathbf{x})<0.\end{cases}

Given the feasibility property (
19
), these can be written equivalently using
\phi
in (
17
) and
\chi
in (
18
) as:

\displaystyle\hat{\mathbf{k}}(\mathbf{x})

\displaystyle=\phi\big(a(\mathbf{x}),\|\mathbf{b}(\mathbf{x})\|_{\boldsymbol{\Gamma}},c(\mathbf{x})\big)\boldsymbol{\Gamma}\mathbf{b}(\mathbf{x}),

(22)

\displaystyle\hat{\theta}(\mathbf{x})

\displaystyle=\chi\big(a(\mathbf{x}),\|\mathbf{b}(\mathbf{x})\|_{\boldsymbol{\Gamma}},c(\mathbf{x})\big)p.

Substituting this into (
21
) yields (
17
)-(
18
).
∎

Remark 1
.

Note the difference between the OD-CBF-QP controller (
17
) and the standard CBF-QP (
11
).
The denominator
{\|\mathbf{b}(\mathbf{x})\|_{\boldsymbol{\Gamma}}^{2}}
in (
11
) is zero if and only if
{L_{\mathbf{g}}h(\mathbf{x})=\mathbf{0}}
, whereas the denominator
{\|\mathbf{b}(\mathbf{x})\|_{\boldsymbol{\Gamma}}^{2}+p{\operatorname{ReLU}}(c(\mathbf{x}))^{2}}
in (

) is zero for some
{\mathbf{x}\in\mathcal{C}}
if and only if
{L_{\mathbf{g}}h(\mathbf{x})=\mathbf{0}}
and
{h(\mathbf{x})=0}
, which occurs for a smaller set of states.
Practically speaking, this leads to better numerical conditioning of the OD-CBF-QP, as demonstrated later in our numerical results.

Proposition 2
.

If
h
is an OD-CBF for (
6
) on
\mathcal{C}
,
and if
\alpha
,
\frac{\partial h}{\partial\mathbf{x}}
and
\mathbf{k}_{\operatorname{d}}
are locally Lipschitz, then the controller in (
17
) is locally Lipschitz at each
\mathbf{x}\in\mathcal{C}
.

Proof.

First, we show that the optimal-decay CBF-QP is defined locally for each
\mathbf{x}
on the boundary of the set
\mathcal{C}
where
{h(\mathbf{x})=0}
.
If
{L_{\mathbf{g}}h(\mathbf{x})\neq\mathbf{0}}
, then there exists an open ball centered at
\mathbf{x}
where
{L_{\mathbf{g}}h(\mathbf{x})\neq\mathbf{0}}
due to the continuity of
L_{\mathbf{g}}h
.
Therefore, condition (
15
) holds locally.
If
{L_{\mathbf{g}}h(\mathbf{x})=\mathbf{0}}
, then condition (
16
) suggests that
{L_{\mathbf{f}}h(\mathbf{x})>0}
is satisfied, which also holds locally in an open ball around
\mathbf{x}
due to the continuity of
L_{\mathbf{f}}h
.
Thus, again, condition (
15
) holds locally.
Hence, the optimal-decay CBF-QP is defined locally in an open ball around any
{\mathbf{x}\in\mathcal{C}}
.

Considering the controller (
17
), all the functions involved in its definition (i.e.,
a
,
\mathbf{b}
,
c
, and
{\operatorname{ReLU}}
) are locally Lipschitz.
Thus,
\mathbf{k}
is locally Lipschitz where its denominator is nonzero, i.e., for all
\mathbf{x}
where

D(\mathbf{x})\triangleq\|\mathbf{b}(\mathbf{x})\|_{\boldsymbol{\Gamma}}^{2}+p{\operatorname{ReLU}}(c(\mathbf{x}))^{2}\neq 0.

On the other hand,
{D(\mathbf{x})=0}
if and only if
L_{\mathbf{g}}h(\mathbf{x})=\mathbf{0}
and
h(\mathbf{x})\leq 0
. For
\mathbf{x}\in\mathcal{C}
, this is true only when
L_{\mathbf{g}}h(\mathbf{x})=\mathbf{0}
and
{h(\mathbf{x})=0}
, implying
L_{\mathbf{f}}h(\mathbf{x})>0
based on (
16
). Therefore,

-a(\mathbf{x})=-L_{\mathbf{f}}h(\mathbf{x})<0,

for any
{\mathbf{x}\in\mathcal{C}}
satisfying
{D(\mathbf{x})=0}
.
Due to the continuity of
a
,
{-a(\mathbf{x})<0}
also holds locally in an open ball around such state
\mathbf{x}
.
Thus,
{{\operatorname{ReLU}}(-a(\mathbf{x}))=0}
in (
17
), making the function
\mathbf{k}
locally Lipschitz and concluding the proof.
∎

.

If

Combining the previous results allows for establishing that

Corollary 2

If

Proposition 3
.

Let
h
be an OD-CBF for (
6
) on
\mathcal{C}
and suppose there exists a set
\mathcal{E}\supset\mathcal{C}
such that
L_{\mathbf{g}}h(\mathbf{x})\neq\mathbf{0}
for all
\mathbf{x}\in\mathcal{E}\setminus\mathcal{C}

) is feasible for all
\mathbf{x}\in\mathcal{E}
with any
\alpha\in\mathcal{K}^{\rm e}
and, if
\mathcal{C}
is compact and
\theta_{\rm{d}}>0
, the resulting controller renders
\mathcal{C}
asymptotically stable for (
8
).

Proof.

Since
h
is an OD-CBF, (
13
) is feasible for all
\mathbf{x}\in\mathcal{C}
. Further, since
L_{\mathbf{g}}h(\mathbf{x})\neq\mathbf{0}
for all
\mathbf{x}\in\mathcal{E}\setminus\mathcal{C}
, the OD-CBF condition (
15
) holds on
\mathbf{x}\in\mathcal{E}\setminus\mathcal{C}
, implying feasibility of (
13
) for all
\mathbf{x}\in\mathcal{E}\setminus\mathcal{C}
. Together, this implies that (
13
) is feasible for all
\mathbf{x}\in\mathcal{E}
, guarantees that the resulting controller
\mathbf{k}\,:\,\mathcal{E}\rightarrow\mathbb{R}^{m}
satisfies (
14
) for all
\mathbf{x}\in\mathcal{E}
, and renders
\mathcal{C}
is forward invariant (Theorem
3
). To show asymptotic stability, consider the Lyapunov function candidate:

V(\mathbf{x})\coloneqq\begin{cases}0&\text{if }\mathbf{x}\in\mathcal{C}\\
h(\mathbf{x})^{2}&\text{if }\mathbf{x}\in\mathcal{E}\setminus\mathcal{C},\end{cases}

which is continuously differentiable and satisfies
{V(\mathbf{x})=0\iff\mathbf{x}\in\mathcal{C}}

{V(\mathbf{x})>0}
for
{\mathbf{x}\in\mathcal{E}\setminus\mathcal{C}}

\dot{V}(\mathbf{x})=\begin{cases}0&\text{if }\mathbf{x}\in\mathcal{C}\\

\underbrace{2h(\mathbf{x})}_{<0}\underbrace{\big(L_{\mathbf{f}}h(\mathbf{x})+L_{\mathbf{g}}h(\mathbf{x})\mathbf{k}(\mathbf{x})\big)}_{>0}<0.

∎

IV
Optimal-Decay CBF Variants

Different variants of CBFs can also benefit from the proposed OD-CBF framework. Particularly, we will investigate how these results apply to high-order CBFs (HOCBFs)
[
9
,
10
,
11
]
and rectified CBFs (ReCBFs)
[
12
]
. These methods are constructive approaches for generating CBF candidates that address safety constraints with higher relative degrees.

Given a safety constraint
\mathcal{S}
in (
2
), the construction of CBFs typically involve the safety constraint function
\psi
. For example, the first natural CBF candidate is the safety constraint function
\psi
itself. Under the new OD-CBF framework, we only need to check if (
16
) holds. If
\psi
is an OD-CBF, then
\mathcal{S}
itself is a safe set for (
6
).

Nevertheless, an arbitrary constraint function
\psi
may not be an OD-CBF, particularly when
\psi
has higher relative degrees.

Definition 7
.

(Relative Degree):

A smooth function
{\psi:\real^{n}\rightarrow\real}
has relative degree
r\in\mathbb{N}
for (
6
) if:

1.

L_{\mathbf{g}}L_{\mathbf{f}}^{i}\psi(\mathbf{x})=\mathbf{0}
for all
i\in\{1,\dots,r-2\}
and
{\mathbf{x}\in\real^{n}}
;

2.

L_{\mathbf{g}}L_{\mathbf{f}}^{r-1}\psi(\mathbf{x})\neq\mathbf{0}
for some
\mathbf{x}\in\real^{n}
.

If
\psi
has relative degree
{r\geq 2}
, then
{L_{\mathbf{g}}\psi(\mathbf{x})\equiv\mathbf{0}}
, and the OD-CBF condition (
16
) for
\psi
reduces to

{\psi(\mathbf{x})=0\implies L_{\mathbf{f}}\psi(\mathbf{x})>0}
,
implying that
\mathcal{S}
must already be forward invariant without any control. When
\psi
has higher relative degrees, we cannot rely on
\psi
being an OD-CBF, but we may use other methods to construct an OD-CBF based on
\psi
. For simplicity, we will limit ourselves to relative degree
r=2
safety constraints in this paper.

IV-A

Optimal-Decay HOCBF

First, we demonstrate the power of the optimal-decay CBF framework in the context of HOCBFs
[
9
,
10
,
11
]
.
For relative degree
{r=2}
, instead of directly using
\psi
, the HOCBF framework defines the following candidate CBF:

h(\mathbf{x})=L_{\mathbf{f}}\psi(\mathbf{x})+\alpha_{1}(\psi(\mathbf{x})),

(23)

with some continuously differentiable class-
\mathcal{K}^{\rm e}
function
\alpha_{1}
.

Definition 8
.

(Optimal-Decay HOCBF):

The function
\psi
from (
2
) is an optimal-decay high-order control barrier function (OD-HOCBF) of degree
{r=2}
for (
6
) on
\mathcal{S}\cap\mathcal{C}
if it has relative degree
r=2
and there exist
\alpha_{1},\alpha\in\mathcal{K}^{\rm e}

such that
h
in (
23
) satisfies for all
\mathbf{x}\in\mathcal{S}\cap\mathcal{C}
that:

\sup_{\begin{subarray}{c}\mathbf{u}\in\real^{m},~\omega\in\mathbb{R}_{\geq 0}\end{subarray}}L_{\mathbf{f}}h(\mathbf{x})+L_{\mathbf{g}}h(\mathbf{x})\mathbf{u}+\omega\alpha(h(\mathbf{x}))>0.

(24)

The OD-HOCBF condition (
24
) for
\psi
is similar to the OD-CBF condition (
15
) for
h
. The key difference is that it only needs to hold on
\mathcal{S}\cap\mathcal{C}
, rather than the entire
\mathcal{C}
.
Next, we state a sufficient condition for
\psi
to be an OD-HOCBF.

Corollary 3
.

Consider a constraint function
\psi
from (
2
) with relative degree
{r=2}
for (
6
). If
{L_{\mathbf{g}}L_{\mathbf{f}}\psi(\mathbf{x})\neq\mathbf{0}}
for each
{\mathbf{x}\in\mathcal{S}\cap\mathcal{C}}
satisfying
{h(\mathbf{x})=0}
, then
\psi
is an OD-HOCBF of degree
{r=2}
for (
6
) on
\mathcal{S}\cap\mathcal{C}
.

Proof.

Because
{L_{\mathbf{g}}h(\mathbf{x})=L_{\mathbf{g}}L_{\mathbf{f}}\psi(\mathbf{x})}
,
(
24
) holds for any
{\alpha\in\mathcal{K}^{\rm e}}
under the assumption of the corollary, and thus,
\psi
is an OD-HOCBF.
∎

With an OD-HOCBF, we establish that
{\mathcal{S}\cap\mathcal{C}}
is a safe set.

Proposition 4
.

If
\psi
is an OD-HOCBF of degree
{r=2}
for (
6
) on
\mathcal{S}\cap\mathcal{C}
and
\frac{\partial\psi}{\partial\mathbf{x}}(\mathbf{x})\neq\mathbf{0}
when
\psi(\mathbf{x})=h(\mathbf{x})=0
, then
\mathcal{S}\cap\mathcal{C}
is a safe set.

Proof.

Let the QP-based controller
\mathbf{k}
in
(
13
) define the closed-loop vector field (
8
). Since
h
is an OD-CBF, Proposition
2
guarantees that
\mathbf{k}
is locally Lipschitz at each
{\mathbf{x}\in\mathcal{S}\cap\mathcal{C}}
, and so is the closed-loop vector field
\mathbf{F}
. We first note that in the interior of the set
{\mathcal{S}\cap\mathcal{C}}
,
the vector field is trivially in the set’s tangent cone
[
3
, Def. 4.9]
.

Now, consider the points on the boundary of the set

{\mathcal{S}\cap\mathcal{C}}
.
If
{\psi(\mathbf{x})=0}
and
{h(\mathbf{x})>0}
, then by definition (
23
) of
h
and noting that
{L_{\mathbf{g}}\psi(\mathbf{x})=0}
, we have

\frac{\partial\psi}{\partial\mathbf{x}}(\mathbf{x})\mathbf{F}(\mathbf{x})=\frac{\partial\psi}{\partial\mathbf{x}}(\mathbf{x})\mathbf{f}(\mathbf{x})>0

and

{\frac{\partial\psi}{\partial\mathbf{x}}(\mathbf{x})\neq\mathbf{0}}
.
Therefore, the closed-loop vector field
\mathbf{F}(\mathbf{x})
belongs to the tangent cone at
\mathbf{x}
, given by:

\mathcal{T}(\mathbf{x})=\Big\{\mathbf{v}\in\real^{n}\;|\;\frac{\partial\psi}{\partial\mathbf{x}}(\mathbf{x})\mathbf{v}\geq 0\Big\}.

If
{\psi(\mathbf{x})>0}
and
{h(\mathbf{x})=0}
, then

{\frac{\partial h}{\partial\mathbf{x}}(\mathbf{x})\mathbf{F}(\mathbf{x})\geq 0}

because the resulting closed-loop system enforces (
14
). Since
h
is an OD-CBF, we have
\frac{\partial h}{\partial\mathbf{x}}(\mathbf{x})\neq\mathbf{0}
when
h(\mathbf{x})=0
because the left hand side of (
15
) would evaluate to zero otherwise. Thus, the closed-loop vector field
\mathbf{F}(\mathbf{x})
belongs to the tangent cone:

\mathcal{T}(\mathbf{x})=\Big\{\mathbf{v}\in\real^{n}\;|\;\frac{\partial h}{\partial\mathbf{x}}(\mathbf{x})\mathbf{v}\geq 0\Big\}.

Finally, if
{\psi(\mathbf{x})=h(\mathbf{x})=0}
, the constraint (
14
) enforces that

{\frac{\partial h}{\partial\mathbf{x}}(\mathbf{x})\mathbf{F}(\mathbf{x})\geq 0}
,
whereas the definition (
23
) of
h
gives

{\frac{\partial\psi}{\partial\mathbf{x}}(\mathbf{x})\mathbf{F}(\mathbf{x})=\frac{\partial\psi}{\partial\mathbf{x}}(\mathbf{x})\mathbf{f}(\mathbf{x})=0}
.
The assumption that
\frac{\partial\psi}{\partial\mathbf{x}}(\mathbf{x})\neq\mathbf{0}
ensures that the tangent cone is given by:

\mathcal{T}(\mathbf{x})=\Big\{\mathbf{v}\in\real^{n}\;|\;\frac{\partial\psi}{\partial\mathbf{x}}(\mathbf{x})\mathbf{v}\geq 0~\wedge~\frac{\partial h}{\partial\mathbf{x}}(\mathbf{x})\mathbf{v}\geq 0\Big\},

and the vector field
\mathbf{F}(\mathbf{x})
belongs to it.

As a result of Nagumo’s theorem
[
7
]
, the set
\mathcal{S}\cap\mathcal{C}
is forward invariant under the controller
{\mathbf{u}=\mathbf{k}(\mathbf{x})}
in (
13
), because the locally Lipschitz vector field
\mathbf{F}(\mathbf{x})
is in the tangent cone of the set
{\mathcal{S}\cap\mathcal{C}}
for all
{\mathbf{x}\in\mathcal{S}\cap\mathcal{C}}
.
Thus, this set is control invariant, and it is also a safe set as
{\mathcal{S}\cap\mathcal{C}\subseteq\mathcal{S}}

VI
Conclusion

We established a rigorous formalization of optimal-decay control barrier functions (OD-CBFs).
We derived conditions to verify the validity of OD-CBFs, established the feasibility and closed-form solution of quadratic program-based controllers, and proved the forward invariance and stability of the resulting safe set.
We highlighted the advantages of this framework in the context of higher-order CBF constructions, and showed that it provides beneficial properties for cases with vanishing relative degrees.
We demonstrated the applicability of this framework on a satellite control problem.

The main limitation of our results is that they rely on the assumption of an unbounded admissible input set, which is somewhat in contrast to the original motivation of OD-CBFs in
[
18
]

[
19
]
. Yet, as argued earlier, bounded inputs are not the only factor that make the search for a compatible class
\mathcal{K}^{e}
function challenging, and the results presented herein provide a comprehensive understanding of how OD-CBFs address the pitfalls of CBFs with a vanishing relative degree, especially for higher order safety constraints. Future efforts will focus on extending our results to the bounded input case.
