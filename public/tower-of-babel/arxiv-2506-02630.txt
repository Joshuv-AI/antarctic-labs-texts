HAM: A Hyperbolic Step to Regulate Implicit Bias
Tom Jacobs, Advait Gadhikar, Celia Rubio-Madrigal, Rebekka Burkholz

Abstract
Understanding the implicit bias of optimization algorithms has become central to explaining the generalization behavior of deep learning models. For instance, the hyperbolic implicit bias induced by the overparameterization m ⊙ w m\odot w —though effective in promoting sparsity—can result in a small effective learning rate, which slows down convergence. To overcome this obstacle, we propose HAM (Hyperbolic Aware Minimization), which alternates between an optimizer step and a new hyperbolic mirror step. We derive the Riemannian gradient flow for its combination with gradient descent, leading to improved convergence and a similar beneficial hyperbolic geometry as m ⊙ w m\odot w for feature learning. We provide an interpretation of the the algorithm by relating it to natural gradient descent, and an exact characterization of its implicit bias for underdetermined linear regression. HAM’s implicit bias consistently boosts performance —even of dense training, as we demonstrate in experiments across diverse tasks, including vision, graph and node classification, and large language model fine-tuning. HAM is especially effective in combination with different sparsification methods, improving upon the state of the art. The hyperbolic step requires minimal computational and memory overhead, it succeeds even with small batch sizes, and its implementation integrates smoothly with existing optimizers.

Introduction

The success of modern deep learning approaches relies on the highly overparameterized regime, which has led to a computationally demanding trend to increase the size of models, and thus the amount of trainable parameters by orders of magnitude

Training sparse models instead leads to suboptimal performance

This fact has limited

(

;

In contrast, state-of-the-art sparsification methods utilize overparameterization in some capacity, as they either iteratively prune parameters in Dense-to-Sparse (DtS) training

;

;

or dynamically explore multiple sparse masks to find high-performing sparse networks with Dynamic Sparse Training (DST)

;

;

)

Key observations regarding these algorithms are that a) mild amounts of sparsity and b) longer training with standard optimizers can improve generalization performance significantly. The latter indicates that sparse models are difficult to train and take longer to converge

)
.
Accordingly, standard optimization stands to benefit from overparameterization not only with respect to its generalization performance, but also its convergence speed.

In this work, we propose to capture the essential structure of these two methods, the implicit bias of pointwise overparameterization, which provably aids in finding generalizable sparse solutions. At the same time, we are able to avoid their drawbacks: their slower convergence and their need for explicit overparameterization that negatively impacts memory and compute. Related work

Sparsification

Sparse training methods can be categorized into three broad classes: Pruning at Initialization (PaI), Dense-to-Sparse training (DtS), and Dynamic Sparse Training (DTS).
PaI methods identify a sparse mask at initialization and train the remaining parameters to convergence.
They include methods like SNIP

)

)

Their primary limitation is that standard optimizers do not find generalizable solutions on these fixed masks, as they struggle to effectively learn parameter signs

;

In contrast, DtS methods learn the mask via a dense or denser phase of training, followed by any kind of pruning step and possibly more training.
This includes iterative pruning methods like IMP

frankle2019lottery
)
, LRR
(

;
han-efficient-nns
)
, Ac/Dc
(
peste2021acdc
)
, CAP
(
kuznedelev2024cap
)
, and WoodFisher
(
singh2020woodfisher
)
.
Continuous sparsification methods, which start from a dense network and gradually sparsify it with a learnable mask, also fall under this category.
They include PILoT
(
jacobs2024maskmirrorimplicitsparsification
)
, STR
(
kusupati20
)
, CS
(
savarese2021winning
)
and spred
(
Ziyin2022spredSL
)

The third class of methods, Dynamic Sparse Training, start from an already sparse mask but dynamically update it during training, and in this sense utilize a form of (dynamic) overparameterization
(
dynamicoverparam
)

Examples include RiGL
(
evci-rigl
)
, MEST
(
yuan2021mest
)
, and SET
(
mocanu-adaptive-sparse-train
)

While PaI methods cannot compete with the generalization performance of DtS and DST methods, Sign-In
(
gadhikar2025signinlotteryreparameterizingsparse
)
improves on PaI by using the pointwise overparameterization
m\odot w
, which leverages a hyperbolic mirror map to facilitate sign flips.
In this work, we propose instead a simpler, more powerful hyperbolic optimization step to leverage a similar mirror map without doubling the number of parameters. Our method HAM can improve the optimization process of both dense and sparse training phases and, in contrast to PILoT and Sign-In, also DtS and DST methods like Ac/Dc and RiGL.

Implicit bias and mirror flow

The implicit bias of neural networks is a well studied topic that aims to explain the regularization benefits resulting from overparameterization
(
woodworth2020kernel
;
gunasekar2017implicit
;
gunasekar2020characterizing
;
Li2022ImplicitBO
)
.
It is primarily characterized within the mirror flow framework, a well-established concept in convex optimization
(
Alvarez_2004
;
BECK2003167
;
Rockafellar1970ConvexA
;
Boyd2009ConvexO
)
.
A mirror flow can be interpreted as a gradient flow on a Riemannian manifold
(
Li2022ImplicitBO
;
Alvarez_2004
)
, which has also been extended to cover stochastic gradient descent (SGD)
(
pesme2021implicit
;
Even2023SGDOD
;
lyu2023implicit
)
and more recently to explicit regularization
(
jacobs2025mirrormirrorflowdoes
)
.
This framework allows us to characterize the implicit bias.
The main observation is that large learning rates, stochastic noise from SGD, and regularization can benefit generalization by implicitly inducing sparsity.
However, overparameterization can also lead to small artificial learning rates, slowing down convergence and potentially hampering generalization
(
jacobs2024maskmirrorimplicitsparsification
)
, which we can successfully avoid in HAM.

Natural gradient descent and Bayesian learning rules

The mirror flow framework also enables us to view our algorithm HAM through the lens of natural gradient descent.
Natural gradient descent uses the Fisher information matrix —or an approximation of it— to capture second order information and adapt the artificial learning rate accordingly
(
Martens2014NewIA
;
10.7551/mitpress/7011.003.0010
)
.
A more general Bayesian framework
(
Khan2021TheBL
)
is used to gain insight into invariant distributions by using Lie groups

(
Kral2023TheLB
)
and for the development of a new optimizer IVON

(
shen2024variational
)
.
In this work, we provide an interpretation of our alternating scheme HAM with gradient descent by mapping the Fisher information to a known posterior distribution.
Notably, our proposed hyperbolic update is reminiscent of exponentiated gradient descent

(
10.5555/902667
)
.
A key distinction is that exponential gradient descent normalizes such that it stays on a probability simplex, as seen for example in Chapter 7 of
(
Vishnoi_2021
)
.
HAM, on the other hand, does not normalize, as the algorithmic step acts directly in the weight space.
Recently, exponential gradient descent has been applied to reweighting batches
(
Majidi2021ExponentiatedGR
)
.

Two-step and alternating schemes

Various previous works have explored alternating training schemes.
Examples include birth-death dynamics at a neuron level in two layer neural network training
(
Rotskoff2019GlobalCO
)
or variational inference
(
Mielke2025HellingerKantorovichGF
;
Gladin2024InteractionForceTG
;
Yan2024LearningGM
)
.
An important difference is that we work on a weight level while other approaches work on a neuron or distribution level and serve an entirely different purpose.
Another well-known two-step approach, although not alternating, is sharpness aware minimization (SAM)
(
foret2021sharpnessaware
)
, which promotes the search for flat solutions at the expense of almost doubling the compute of one optimization step.
In contrast, HAM encourages mild sparsity and acceleration around
0
, which are complementary mechanisms.
Our experiments (Table
2
) demonstrate that our proposed hyperbolic step can be effectively combined with SAM to further boost generalization.

We derive our novel optimization step by building on insights from the implicit bias of recently developed sparsification methods.

Alternating the new hyperbolic update in Eq. (

\displaystyle x_{k+1}

\displaystyle=x_{k+\frac{1}{2}}\odot\exp\left(-\eta\left(\alpha\ \sign(x_{k})\nabla f(x_{k})+\beta\right)\right)

Natural gradient descent interpretation

Our algorithm can be interpreted through the lens of natural gradient descent
(
10.7551/mitpress/7011.003.0010
;
Martens2014NewIA
)
.
Each optimizer step corresponds to a natural gradient update

x_{k+1}=x_{k}-\eta\mathcal{I}(x_{k})^{-1}\nabla f(x_{k})
, with
\mathcal{I}
the Fisher information.
The key insight is that parameters follow a known parameterized distribution that is learned by the optimizer.
For gradient descent,
\mathcal{I}_{\text{GD}}(x)=1
, which corresponds to a normally distributed random variable
X
with unit variance and learnable mean; i.e.,
x=\mathbb{E}[X]
.
Thus we can interpret
x
as the mean of a normal distribution whose
position
is learned.

In contrast, the exponential update (
2
) corresponds to
\mathcal{I}_{\text{HYP}}(x)=1/|x|
, which directly follows from the first order approximation of the exponential function.
Its Fisher information may correspond to a random variable
X
parameterized as a normal distribution with unit variance:
\mathcal{N}({2\sqrt{|x|},1})
.
In this view, weights are recovered via
x=\frac{1}{4}\sign(x)\mathbb{E}[X]^{2}
, meaning we learn the
magnitude
of the expected position. Furthermore, if the sign is not correct, the hyperbolic step (
HYP
) will move the parameter exponentially fast towards zero, facilitating its sign flip.
We provide derivations for both discussed cases in Appendix
B
.
To summarize, our combined update can be interpreted as follows:

Learn the position (
GD
), and then the magnitude if the sign is correct; else move fast to zero (
HYP
).

This mechanism is crucial to facilitate sparse training
(
gadhikar2024masks
;
gadhikar2025signinlotteryreparameterizingsparse
)
, as portrayed in our experiments (§
6
), where HAM considerably boosts its performance.

Algorithm: Hyperbolic Aware Minimization (HAM)

We propose HAM (Algorithm
1
) which alternates between any standard optimizer step and a hyperbolic (signed) mirror map to improve general trainability of neural networks.
The proposed method is inspired by recent sparsification methods, as developed in §
3
, and theoretically justified in §
4
.
We next state the main algorithmic innovations.

Hyperbolic step

Let
\eta>0
denote the learning rate, and
\alpha,\beta\geq 0
be positive constants. The deployed hyperbolic step for parameters
x_{k}\in\mathbb{R}^{n}
is given by

x_{k}=x_{k+\frac{1}{2}}\odot\exp{\left(-\eta\left(\alpha\ \sign(x_{k+\frac{1}{2}})\nabla f(x_{k})+\beta\right)\right)},

(HYP*)

where
\odot
is the Hadamard product, and
x_{k+\frac{1}{2}}
is the step of any other optimizer over
x_{k}
.

\alpha
controls the convergence speed and hyperbolic awareness of the method, and
\beta
induces an explicit regularization similar to that of PILoT
(
jacobs2024maskmirrorimplicitsparsification
)
.
Note that we have replaced
\sign(x_{k})
with
\sign(x_{k+\frac{1}{2}})
, as mentioned in Remark
3.2
. Our analysis §
4
still remains valid at the end of training, as we show in Appendix
A
.

Memory and compute overhead

HAM does not incur any memory overhead, as it reuses the known gradient and current signs of the weights.
In contrast, the pointwise overparameterization
m\odot w
doubles the number of parameters, which would only be negligible in case of large batch sizes (where activations dominate the memory requirements).
HAM is viable on large scale LLM tasks, where batches are small and the memory is largely consumed by model parameters.
Moreover, the amount of extra flops during training is negligible, as they are on the order of the level of parameters.

Conclusion

We have proposed a new hyperbolic update step that can be combined with any first-order optimizer and that improves generalization of dense and sparse training.
Our algorithm HAM (Hyperbolic Aware Minimization) mitigates the vanishing artificial learning rate of the pointwise overparameterization
m\odot w
used in recent sparsification methods, while inducing a similar implicit bias.
Due to discretization, it is more suitable to control the strength and shape of the bias—and with this improve generalization, especially for dense-to-sparse training.
The main mechanisms how HAM achieves this are a mild implicit bias towards sparsity and an acceleration of learning that promotes parameter sign flips.
It remains an interesting open question if different mirror maps could create better task and optimizer-specific awareness.
For example, for some tasks one might want to take into account the data structure; for the optimizer, it might be the momentum or normalization.
This could lead to more algorithmic advances to improve generalization via implicit bias control, and to new theory for understanding the success of deep learning algorithms.
In particular, optimizers with implicit biases that emulate the positive effects of overparameterization, without explicitly requiring huge models, may represent an important leap in reducing the high computational costs associated with deep learning.

Appendix B
Fisher information derivations

We provide here the Fisher information
\mathcal{I}
calculations for random variables
\mathcal{N}(x,1)
and
\mathcal{N}(\sqrt{x},1)
.
The Fisher information is defined as see for example Definition 1.1 in
[
49
]
:

\mathcal{I}(x)=\mathbb{E}\left[\log f(X)\right]

(7)

where
f
is the probability density function of the random variable
X
and
\mathbb{E}
is the expectation with respect to the random variable.

Let
X\sim\mathcal{N}(x,1)
, where
x\in\mathbb{R}
is the mean parameter. The likelihood function is:

f(X;x)=\frac{1}{\sqrt{2\pi}}\exp\left(-\frac{1}{2}(X-x)^{2}\right)

Taking the natural logarithm:

\ell(x)=\log f(X;x)=-\frac{1}{2}\log(2\pi)-\frac{1}{2}(X-x)^{2}

The score function is:

\frac{d\ell}{dx}=(X-x)

Then the Fisher Information is given by:

\mathcal{I}_{\text{GD}}(x)=\mathbb{E}\left[\left(\frac{d\ell}{dx}\right)^{2}\right]=\mathbb{E}[(X-x)^{2}]=\operatorname{Var}(X)=1

Let
X\sim\mathcal{N}(2\sqrt{|x|},1)
. The likelihood function is:

f(X;x)=\frac{1}{\sqrt{2\pi}}\exp\left(-\frac{1}{2}(X-2\sqrt{|x|})^{2}\right)

The log-likelihood function is:

\ell(x)=-\frac{1}{2}\log(2\pi)-\frac{1}{2}(X-2\sqrt{|x|})^{2}

Differentiate to get the score function:

\frac{d\ell}{dx}=(X-2\sqrt{|x|})\cdot\left(-\frac{\text{sign}(x)}{\sqrt{|x|}}\right)=-\text{sign}(x)\frac{X-2\sqrt{x}}{\sqrt{x}}

Now square the score and take the expectation:

\mathcal{I}_{\text{HYP}}(x)=\mathbb{E}\left[\left(\frac{d\ell}{dx}\right)^{2}\right]=\mathbb{E}\left[\left(\frac{X-2\sqrt{|x|}}{\sqrt{|x|}}\right)^{2}\right]=\frac{1}{|x|}\mathbb{E}[(X-2\sqrt{|x|})^{2}]=\frac{1}{|x|}Var(X)=\frac{1}{|x|}

Note that instead of being part of the exponential family of distributions this distribution is part of the curved exponential family distributions.

Appendix C
Optimization definitions and results

In this section we recall some basic definitions from convex and non-convex optimization.

Definition C.1

(
L-
smooth)
A differentiable function
f:\mathbb{R}^{n}\to\mathbb{R}
is said to be
L-smooth
if its gradient is Lipschitz continuous with constant
L>0
. That is, for all
x,y\in\mathbb{R}^{n}
,

\|\nabla f(x)-\nabla f(y)\|\leq L\|x-y\|,

or equivalently,

f(y)\leq f(x)+\langle\nabla f(x),y-x\rangle+\frac{L}{2}\|y-x\|^{2}.

or equivalently,

\frac{1}{2}\|\nabla f(x)\|^{2}\leq L\left(f(x)-f^{*}\right),

where
f^{*}=\min_{x\in\mathbb{R}^{n}}f(x)
.

Definition C.2

(PL-inequality)
A differentiable function
f:\mathbb{R}^{n}\to\mathbb{R}
satisfies the
PL inequality
with parameter
\Lambda>0
if for all
x\in\mathbb{R}^{n}
,

\frac{1}{2}\|\nabla f(x)\|^{2}\geq\Lambda\left(f(x)-f^{*}\right),

where
f^{*}=\min_{x\in\mathbb{R}^{n}}f(x)
.

Definition C.3

(Legendre function Definition 3.8 (
[
43
]
))
Let
R:\mathbb{R}^{d}\rightarrow\mathbb{R}\cup\{\infty\}
be a differentiable
convex function. We say
R
is a Legendre function when the following holds:

•

R
is strictly convex on
\interior(\dom R)
.

•

For any sequence
\{x_{i}\}^{\infty}_{i=1}
going to the boundary of
\dom R
,
\lim_{i\rightarrow\infty}||\nabla R(x_{i})||_{L_{2}}^{2}=\infty
.

In order to recover the convergence result in Theorem 4.14 in
[
43
]
the function
R
also needs to be a Bregman function, which we define in Definition
C.4
.

Definition C.4

(Bregman function Definition 4.1
[
1
]
)
A function
R
is called a
Bregman function if it satisfies the following properties:

•

\dom R
is closed.
R
is strictly convex and continuous on
\dom R
.
R
is
C^{1}
on
\interior(\dom R))
.

•

For any
x\in\dom R
and
\gamma\in\mathbb{R}
,
\{y\in\dom R|D_{R}(x,y)\leq\gamma\}
is bounded.

•

For any
x\in\dom R
and sequence
\{x_{i}\}^{\infty}_{i=1}\subset\interior(\dom R)
such that
\lim_{i\rightarrow\infty}x_{i}=x
, it holds that
\lim_{i\rightarrow\infty}D_{R}(x,x_{i})\rightarrow 0
.

Theorem C.5

(Theorem 4.7
[
1
]
)
If
R
is a Legendre function with
\dom R=\mathbb{R}^{n}
,
then if the domain of the convex conjugate
\dom R^{*}=\mathbb{R}^{n}
implies that
R
is a Bregman function
