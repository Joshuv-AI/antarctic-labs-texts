Weighted k k - Path and Other Problems in Almost O ∗ ​ ( 2 k ) O^{*}(2^{k}) Deterministic Time via Dynamic Representative Sets
Jesper Nederlof

Abstract
We present a data structure that we call a Dynamic Representative Set . In its most basic form, it is given two parameters 0 < k < n 0<k<n and allows us to maintain a representation of a family ℱ \mathcal{F} of subsets of { 1 , … , n } \{1,\ldots,n\} . It supports basic update operations (unioning of two families, element convolution) and a query operation that determines for a set B ⊆ { 1 , … , n } B\subseteq\{1,\ldots,n\} whether there is a set A ∈ ℱ A\in\mathcal{F} of size at most k − | B | k-|B| such that A A and B B are disjoint. After 2 k + O ⁡ ( k ​ log 2 ​ k ) ​ n ​ log ⁡ n 2^{k+O(\sqrt{k}\log^{2}k)}n\log n preprocessing time, all operations use 2 k + O ⁡ ( k ​ log 2 ​ k ) ​ log ⁡ n 2^{k+O(\sqrt{k}\log^{2}k)}\log n time. Our data structure has many algorithmic consequences that improve over previous works. One application is a deterministic algorithm for the Weighted Directed k k - Path problem, one of the central problems in parameterized complexity. Our algorithm takes as input an n n -vertex directed graph G = ( V , E ) G=(V,E) with edge lengths and an integer k k , and it outputs the minimum edge length of a path on k k vertices in 2 k + O ⁡ ( k ​ log 2 ​ k ) ​ ( n + m ) ​ log ⁡ n 2^{k+O(\sqrt{k}\log^{2}k)}(n+m)\log n time (in the word RAM model where weights fit into a single word). Modulo the lower order term 2 O ⁡ ( k ​ log 2 ​ k ) 2^{O(\sqrt{k}\log^{2}k)} , this answers a question that has been repeatedly posed as a major open problem in the field.

1.2
Representative Sets.

Representative sets play a main role in this paper and hence we introduce them in detail now.

Conceptually, the dynamic programming paradigm partitions at any stage a solution into two sets of
partial
solutions
: A set
\mathcal{A}
of partial solutions represented in the current table entries, and a set
\mathcal{B}
of (yet unexplored) partial solutions that could potentially complete a partial solution in
\mathcal{A}
to a global solution. The definition of
\mathcal{A}
and
\mathcal{B}
does not depend on the actual input, but only on its parameters (like number of vertices, solution size, or treewidth).

A crucial object of study in the context of representative sets is the
compatibility matrix
, which is a Boolean matrix
\mathbf{M}\in\{0,1\}^{\mathcal{A}\times\mathcal{B}}
indicating whether two (fingerprints of) partial solutions combine into a solution.
Suppose that
\mathbb{S}
is a semiring and a dynamic programming table is a vector
\mathbf{a}\in\mathbb{S}^{\mathcal{A}}
. That is, the table
\mathbf{a}
assigns to each fingerprint/partial solution
A\in\mathcal{A}
a number
\mathbf{a}[A]
that indicates whether there is a partial solution with fingerprint
A
(if
\mathbb{S}
is the Boolean semiring with
\vee
and
\wedge
as operations) for decision problems, the number of partial solutions with fingerprint
A
(if
\mathbb{S}
is the ring of integers with integer addition and multiplication) for counting problems, or the minimum weight of a partial solution with fingerprint
A
(if
\mathbb{S}
is the min-sum semiring with
\min
as addition and integer addition as multiplication) for minimization problems.

The general idea of representative sets is the following observation: If
\mathbf{a},\mathbf{a^{\prime}}\in\mathbb{S}^{\mathcal{A}}
are two different dynamic programming tables such that
\mathbf{a}\cdot\mathbf{M}=\mathbf{a^{\prime}}\cdot\mathbf{M}
, we call
\mathbf{a^{\prime}}
a
representative set
of
\mathbf{a}
. Since the solution of the problem at hand equals
\mathbf{a}\cdot\mathbf{M}\cdot\mathbf{b}^{\intercal}=\mathbf{a^{\prime}}\cdot\mathbf{M}\cdot\mathbf{b}^{\intercal}
, for some (unknown) vector
\mathbf{b}
, we can as well replace the dynamic programming table
\mathbf{a}
with its representative set
\mathbf{a^{\prime}}
and retain the solution. The use of this observation is due to that for many matrices
\mathbf{M}
one can show that any
\mathbf{a}
has a representative set
\mathbf{a^{\prime}}
with small support (i.e., for minimization problems, only few values of
\mathbf{a^{\prime}}
are finite). For example, if
\mathbb{S}
is the min-plus semiring, a vector
\mathbf{a}
with support
\mathrm{supp}(\mathbf{a})
is given and
\mathbf{M}
has rank
r
over a finite field, one can find a representative set
\mathbf{a^{\prime}}
with
|\mathrm{supp}(\mathbf{a^{\prime}})|\leq r
in time
|\mathrm{supp}(\mathbf{a})|\cdot r^{\omega-1}
, where
\omega
is the matrix multiplication constant
[
BCKN15
]
.
When the compatibility matrix
\mathbf{M}
commutes with the matrices that compute new table entries from old table entries, one can use this observation to compute the outcome of the dynamic programming while only working with representative sets of small support and have faster algorithms.

As mentioned before, unfortunately this approach often does not lead to the fastest known algorithms. The computation of small representative sets is the only bottleneck here, and it is an important and beautiful open question to remove this bottleneck:

Question 1:

For which
\mathbf{M}
are there deterministic
\tilde{O}(|\mathrm{supp}(\mathbf{a})|+r)
time algorithms to compute a representative set of support size at most
r
of
\mathbf{a}
?

See also
[
Ned20a
]
.
We stress that this is an important question. For example:
If Question
1.2
is positively resolved with the compatibility matrix
\mathbf{M}
indicating whether the union of

•

two forests of a graph is a spanning tree, then the Cut&Count method
[
CNP+22
]
can be derandomized and extended to weighted problems without overhead in the runtime,

•

two independent sets of a matroid form another independent set, then many kernelization algorithms based on
[
KW20
]
can be derandomized,

•

two perfect matchings forms a Hamiltonian cycle, then the approach from
[
Ned20b
]
is a promising direction towards a
O^{*}(1.9999^{n})
time algorithm for the
Traveling Salesperson Problem
.

We will now make this application to

Fix the semiring
\mathbb{S}=(S,+,\cdot,\bar{0},\bar{1})

Let

\mathbf{C}_{n,e}[A,B]:=\llbracket e\notin A\text{ and }A\cup\{e\}=B\rrbracket\hskip 20.00003pt\text{and}\hskip 20.00003pt\mathbf{D}_{n,k}[A,B]:=\llbracket A\cap B=\emptyset\text{ and }|A\cup B|\leq k\rrbracket.

Here the Iverson bracket notation
\llbracket b\rrbracket

\bar{0}
if

\bar{1}
if

A crucial property which we show in Lemma

\mathbf{C}_{n,e}\cdot\mathbf{D}=\mathbf{D}\cdot\mathbf{C}^{\intercal}_{n,e}

Suppose

1.4
Intuition behind our proof for Theorem
1.1
.

Our main innovation allowing us to prove Theorem
1.1
is to compute an (implicit) representation of
\mathbf{a}\cdot\mathbf{C}_{n,e}\cdot\mathbf{D}_{n,k}
from a given a (similarly implicit) representation of
\mathbf{a}\cdot\mathbf{C}_{n,e}\cdot\mathbf{D}_{n,k}
. See Theorem
3.2
for precise statements. From this, Theorem
1.1
follows in a relatively standard way and hence we only focus on the mentioned key step. By using the splitting trick as mentioned in the previous paragraph, it can be shown that it suffices to quickly compute an (implicit) representation of
\mathbf{a}\cdot(\mathbf{I}^{\otimes i-1}\otimes\mathbf{C}_{u,e}\otimes\mathbf{I}^{\otimes s-i})\cdot\mathbf{D}^{\otimes s}_{u,s}
from a (similarly implicitly) given representation of
\mathbf{a}\cdot\mathbf{D}^{\otimes s}_{u,s}
(i.e., when we want to insert a vertex of the path that is in the
i
-th block). Here
\mathbf{I}
denotes the identity matrix of appropriate dimension.

Our starting point is a simple linear algebraic idea that works under the following (invalid!) assumption: Suppose that
\mathbf{D}_{u,s}
has a rank-
\ell
factorization
\mathbf{D}_{u,s}=\mathbf{X}\cdot\mathbf{Y}
over the reals for some
\ell\leq 2^{s}
. Then we can assume
\mathbf{Y}
has rank
\ell
and hence there exists a right inverse
\mathbf{Y}^{-1}_{\mathsf{right}}
such that
\mathbf{Y}\cdot\mathbf{Y}^{-1}_{\mathsf{right}}=\mathbf{I}
. Suppose that we have a representation
\mathbf{b}=\mathbf{a}\cdot\mathbf{X}^{\otimes s}
of
\mathbf{a}\cdot\mathbf{D}^{\otimes s}_{u,s}
, then given
\mathbf{b}
we can compute a representation of
\mathbf{a}\cdot(\mathbf{I}^{\otimes i-1}\otimes\mathbf{C}_{u,e}\otimes\mathbf{I}^{\otimes s-i})
of the same type as follows:

\displaystyle\mathbf{b}\cdot(\mathbf{I}^{\otimes i-1}\otimes\mathbf{Y}\cdot\mathbf{C}^{\intercal}_{u,e}\cdot\mathbf{Y}^{-1}_{\mathsf{right}}\otimes\mathbf{I}^{\otimes s-i})

\displaystyle=\mathbf{a}\cdot(\mathbf{X}^{\otimes i-1}\otimes\mathbf{D}_{u,s}\cdot\mathbf{C}^{\intercal}_{u,e}\cdot\mathbf{Y}^{-1}_{\mathsf{right}}\otimes\mathbf{X}^{\otimes s-i})

\displaystyle=\mathbf{a}\cdot(\mathbf{X}^{\otimes i-1}\otimes\mathbf{C}_{u,e}\cdot\mathbf{D}_{u,s}\cdot\mathbf{Y}^{-1}_{\mathsf{right}}\otimes\mathbf{X}^{\otimes s-i})

\displaystyle=\mathbf{a}\cdot(\mathbf{I}^{\otimes i-1}\otimes\mathbf{C}_{u,e}\otimes\mathbf{I}^{\otimes s-i-1})\cdot\mathbf{X}^{\otimes s}.

Since the vector
\mathbf{b}\cdot(\mathbf{I}^{\otimes i-1}\otimes\mathbf{Y}\cdot\mathbf{C}^{\intercal}_{u,e}\cdot\mathbf{Y}^{-1}_{\mathsf{right}}\otimes\mathbf{I}^{\otimes s-i})
can be computed from the vector
\mathbf{b}
in a direct way in
2^{s(s+1)}=2^{k+\sqrt{k}}
time this gives a simple way to prove Theorem
3.2
(but, under an invalid assumption).

To make this idea work without the invalid assumption that
\mathbf{D}_{u,s}
has small rank over the reals, we use the fact that
\mathbf{D}_{u,s}
has small Boolean rank in combination with another type of “inversion” (Lemma
4.1
) which heavily relies on a partial order induced by
\mathbb{S}
and is applied to
\mathbf{X}
instead of
\mathbf{Y}
. In the above setting, our actual approach can be thought of as follows:

1.

Compute the
unique minimal
vector
\mathbf{a}^{*}_{\mathsf{ext}}
such that
\mathbf{b}\preceq_{\mathbb{S}}\mathbf{a}^{*}_{\mathsf{ext}}(\mathbf{I}^{\otimes i-1}\otimes\mathbf{X}\otimes\mathbf{I}^{\otimes s-i})
.

2.

Output
\mathbf{a}^{*}_{\mathsf{ext}}\cdot(\mathbf{I}^{\otimes i-1}\otimes\mathbf{C}_{u,e}\cdot\mathbf{X}\otimes\mathbf{I}^{\otimes s-i})

Since we do not have additive inverses in the min-plus semiring, the inversion from Lemma
4.1
is lossy and could lead to inconsistent data: If we first insert an element in the first block and apply “inversion” here to get a vector
\mathbf{b^{\prime}}
we cannot guarantee that
\mathbf{b}=\mathbf{a}^{*}_{\mathsf{ext}}(\mathbf{I}\otimes\mathbf{X}\otimes\mathbf{I}^{\otimes s-3})
for some
\mathbf{a}^{*}_{\mathsf{ext}}
and hence inversion may fail when we try to insert an element in the second block.
Also, the matrices
\mathbf{X}
and
\mathbf{C}_{u,e}
do not commute and hence it seems hard to recover e.g.
\mathbf{a}\cdot(\mathbf{C}_{u,e}\otimes\mathbf{I})
from
\mathbf{a}\cdot\mathbf{X}^{\otimes 2}
by only consider the “slices” induced by the second block separately.

However, the inversion is only lossy in one direction since in Step 1. there is always a unique
minimal
solution, implying that the actual original solution is above
\mathbf{a}^{*}_{\mathsf{ext}}
.
Moreover,
\mathbf{C}_{u,e}
and
\mathbf{D}_{u,s}

do
commute. This allows us to define an upper bound (based on the minimality property of inversion) and a lower bound (that actually compares images of
\mathbf{D}_{u,s}
, which
does
commute with
\mathbf{C}_{u,e}
) invariant that can be simultaneously maintained. See Definition
3.3
for these invariant statements.

(for which representative sets of support size

exist). However, the above method allows us to obtain the arguably ”next best” thing: A data structure that supports all relevant operations and maintains some sort of representative set with small overhead in runtime.
We formalize this (in Theorem
3.2
) in what we call a
dynamic representative set
.
In its most basic form (i.e.,
\mathbb{S}
being the Boolean semiring
(\{0,1\},\vee,\wedge,0,1)
), it is given two parameters
0<k<n
and allows us to maintain a representation of a family
\mathcal{F}
of subsets of
\{1,\ldots,n\}
. It supports basic update operations (unioning of two families, element convolution) and a query operation that determines for a set
B\subseteq\{1,\ldots,n\}
whether there is a set
A\in\mathcal{F}
of size at most
k-|B|
such that
A
and
B
are disjoint. After
2^{k+O(\sqrt{k}\log^{2}k)}n\log n
preprocessing time, all operations use
2^{k+O(\sqrt{k}\log^{2}k)}\log n
time.

We believe this formalism is easy to use as black box for speeding up relevant dynamic programming algorithms of which the compatibility matrices are disjointness matrices.
We leave it as a challenging open question whether such dynamic representative sets can also be maintained for other matrices
\mathbf{M}
to improve e.g. the three applications mentioned below Question
1.2
.

To relate this more directly to the existing literature, we show how to use dynamic representative sets to get a fast deterministic algorithm for the following problem (see Subsection
3.2
for definitions):

Skewed Multilinear Monomial Summation over
\mathbb{S}

Input:
A

-skewed arithmetic circuit
C
over an additively idempotent semiring
\mathbb{S}
in commutative indeterminates

Question:
The value
\sum_{A\in\binom{[n]}{k}}c_{A}
.

Theorem 1.2
.

There is a deterministic algorithm for
Skewed Multilinear Monomial Summation Over
\mathbb{S}
that uses
2^{k+O(\sqrt{k}\log^{2}k)}(n+d\cdot|C|)\log n
time and arithmetic (i.e., additions, multiplications and
\mathsf{lcu}
operations) operations in
\mathbb{S}
.

This result improves over a plethora of previous results via known reductions.
For example, Theorem

Idempotent Semirings.

To state our general results we need to recall some basic algebra:

Definition 2.1
.

A
semiring
is a quintuple
\mathbb{S}=(S,+,*,\bar{0},\bar{1})
such that

1.

(S,+,\bar{0})
is a commutative monoid:
(a+b)+c=a+(b+c)
and
a+b=b+a
for all
a,b,c\in S
, and
a+\bar{0}=a
for all
a\in A
,

2.

(S,*,\bar{1})
is a monoid:
(a*b)*c=a*(b*c)
for all
a,b,c\in S
and
a*\bar{1}=\bar{1}*a=a
for all
a\in A
,

3.

The multiplication operator
*
distributes over the addition operator
+
: for every
a,b,c\in S
:

(a+b)*c=a*c+b*c\hskip 20.00003pt\text{ and }\hskip 20.00003pta*(b+c)=a*b+a*c.

4.

The additive identity
\bar{0}
is an annihilator for multiplication:
a*\bar{0}=\bar{0}*a=\bar{0}
for every
a\in S
.

The two semirings that are most relevant for this paper are the Boolean semiring
(\{0,1\},\vee,\wedge,0,1)
(useful for solving decision problems), and the min-plus semiring
(\mathbb{Z}_{\geq 0}\cup\infty,\min,+,\infty,0)
(useful for optimization problems.). Since the min-plus semiring is infinite, we emulate it with the
M
-capped min-plus semiring
, which is defined as the semiring
(\{0,\ldots,M\}\cup\infty,\min,+,\infty,0)
with all integers larger than
M
being mapped to
\infty
. It is easily verified that this is still a semiring. All these semirings have the following property:

Definition 2.2
.

A semiring
(S,+,*,\bar{0},\bar{1})
is
additively idempotent
if
a+a=a
for every
a\in A
.

Assuming
\mathbb{S}=(S,+,*,\bar{0},\bar{1})
is additively idempotent, we define a relation
\preceq_{\mathbb{S}}
on
S
as follows:
a\preceq_{\mathbb{S}}b
if and only if
a+b=a
.
It is well known that
(S,\preceq_{\mathbb{S}})
is a lower semilattice: It is easily seen to be a partial ordered set,
7
7

7

Recall, an ordering
\preceq
is a partial ordered set if for every
x,y,z
it holds that
x\preceq x
(
reflexivity
),
x\leq y
and
y\leq x
implies
x=y
(
antisymmetry
), and
x\leq y
together with
y\leq z
implies
x\leq z
(
transitivity
).
and the unique greatest lower bound of
a,b
is
a+b
. To see this, suppose
c\leq a
and
c\leq b
. Then
c+a=c+b=c
, and therefore
c+(a+b)=c
which means that
c\preceq_{\mathbb{S}}a+b
.
Moreover,
a\preceq_{\mathbb{S}}\bar{0}
for every
a\in S
. This implies that, if
S
is finite, then
\preceq_{\mathbb{S}}
is in fact a lattice: Given elements
x_{1},\ldots,x_{\ell}
we can define a
least common upper bound

\mathrm{lcu}(x_{1},\ldots,x_{\ell}):=\sum_{y\text{ s.t. }\forall i\in[\ell]:x_{i}\preceq_{\mathbb{S}}y}y.

We assume that this
\mathrm{lcu}
is efficiently computable and call the addition, multiplication and
\mathsf{lcu}
operation
arithmetic operations in
\mathbb{S}
. Note that in the (
M
-capped) min-plus semi-ring,
\mathsf{lcu}(x_{1},\ldots,x_{\ell})
equals
\max\{x_{1},\ldots,x_{\ell}\}
.

Linear Algebra.

Vectors and matrices are denoted in boldface. They will be interchangeably be indexed both with integers and sets (assuming a fixed ordering of the set).

Definition 2.3
.

If
\mathbf{A}\in\mathbb{S}^{n\times m}
and
\mathbf{B}\in\mathbb{S}^{n^{\prime}\times m^{\prime}}
, their
Kronecker product

\mathbf{A}\otimes\mathbf{B}\in\mathbb{S}^{([n]\times[n^{\prime}])\times([m]\times[m^{\prime}])}
is defined as follows:

(\mathbf{A}\otimes\mathbf{B})[(i,j),(i^{\prime},j^{\prime})]:=\mathbf{A}[i,i^{\prime}]\cdot\mathbf{B}[j,j^{\prime}].

If
s\in\mathbb{N}_{>0}
, we denote
\mathbf{A}^{\otimes s}
for the

\mathbf{A}\otimes\cdots\otimes\mathbf{A}
.

A basic property of this product used frequently and implicitly throughout this paper is the
Mixed Product Property

(\mathbf{A}\cdot\mathbf{B})\otimes(\mathbf{C}\cdot\mathbf{D})=(\mathbf{A}\otimes\mathbf{C})\cdot(\mathbf{B}\otimes\mathbf{D}).

Matrices and vectors are denoted in boldface throughout this paper. By default, vectors denote row vectors (i.e.
(1\times n)
-matrices). We use
\mathbf{A}^{\intercal}
to denote the transpose of matrix
\mathbf{A}
.

Throughout this paper, the semiring
\mathbb{S}
will be implicitly extended to a matrix semiring: If
\mathbf{A}\in\mathbb{S}^{n\times m}
and
\mathbf{B}\in\mathbb{S}^{m\times n}

(\mathbf{A}\cdot\mathbf{B})[i,k]=\sum_{j=1}^{m}\mathbf{A}[i,j]\cdot\mathbf{B}[j,k]
, where the summation and multiplication are in
\mathbb{S}
. Likewise, the ordering
\preceq_{\mathbb{S}}
is extended to vectors and matrices in the natural way: If
\mathbf{a},\mathbf{b}\in\mathbb{S}^{n}
, then
\mathbf{a}\preceq_{\mathbb{S}}\mathbf{b}
denotes that
\mathbf{a}[i]\preceq_{\mathbb{S}}\mathbf{b}[i]
for every
i
.

3
Dynamic Representative Sets: Statement and Applications

We will now formally state our dynamic representative set tool. Following the discussion of Sections
1.2
and
1.3
we aim to efficiently represent
\mathbf{a}\cdot\mathbf{D}_{n,k}
in such a way that a representation of
\mathbf{a}\cdot\mathbf{C}_{n,e}\cdot\mathbf{D}_{n,k}
can be quickly computed from a representation of
\mathbf{a}\cdot\mathbf{D}_{n,k}
.
We will show this in Theorem
3.2
(and Lemma
3.5
) for a notion of “represents” (outlined in Definition
3.3
) that is slightly stronger than just being able to recover
\mathbf{a}\cdot\mathbf{D}_{n,k}
(as shown in Observation
3.4
).

Fix an additively idempotent semiring
\mathbb{S}=(S,+,\cdot,\bar{0},\bar{1})
.
We encourage reader to assume
\mathbb{S}
is the min-sum semi-ring
(\mathbb{Z}_{\geq},\min,+,\infty,0)
during their first read. In this case the order
\preceq_{\mathbb{S}}
(defined in Section
2
) reduces to the natural order on integers and
\mathsf{lcu}
reduces to
\max
. In this section,
+,\cdot
refers to the operations of
\mathbb{S}
. Likewise, the Iverson bracket notation
\llbracket b\rrbracket
, for a boolean
b
, indicates
\bar{0}
if
b
is false, and
\bar{1}
if
b
is true.

Throughout this section, we fix two integers
k,n
with
k\leq n
. Recall from Subsection
1.3
that

\mathbf{C}_{n,e}[A,B]:=\llbracket e\notin A\text{ and }A\cup\{e\}=B\rrbracket\hskip 20.00003pt\text{and}\hskip 20.00003pt\mathbf{D}_{n,k}[A,B]:=\llbracket A\cap B=\emptyset\text{ and }|A\cup B|\leq k\rrbracket.

A crucial property is that these matrices commute in the following sense:

Lemma 3.1
.

If
e\in U
, then
\mathbf{C}_{n,e}\cdot\mathbf{D}_{n,k}=\mathbf{D}_{n,k}\cdot\mathbf{C}_{n,e}^{\intercal}
.

Proof.

By expanding the matrix multiplications, we have

\displaystyle(\mathbf{C}_{n,e}\cdot\mathbf{D}_{n,k})[A,B]

\displaystyle=\begin{cases}\mathrlap{\mathbf{D}_{n,k}[A\cup\{e\},B],}\hphantom{\mathbf{D}_{n,k}[A,B\cup\{e\}],}&\text{if $e\notin A$},\\
\bar{0},&\text{otherwise},\end{cases}

\displaystyle(\mathbf{D}_{n,k}\cdot\mathbf{C}^{\intercal}_{n,e})[A,B]

\displaystyle=\begin{cases}\mathbf{D}_{n,k}[A,B\cup\{e\}],&\text{if $e\notin B$},\\
\bar{0},&\text{otherwise}.\end{cases}

Hence, both terms are equal to
\bar{1}
if
e\not\in A\cup B
,
A\cap B=\emptyset
and
|A\cup B|\leq k-1
, and otherwise both terms are equal to
\bar{0}
.
∎

We now state our main tool, discuss its utility in this section and postpone its proof to Section
4
.

Theorem 3.2

(Dynamic Representative set)
.

Let
\mathbb{S}=(S,+,*,\bar{0},\bar{1})
be an additively idempotent semiring and let
n,k
be integers satisfying
k\leq n
. There exists a factorization
\mathbf{D}_{n,k}=\mathbf{L}\cdot\mathbf{R}
of rank
r\leq 2^{k+O(\sqrt{k}\cdot\log^{2}k)}\log n
such that, after
2^{O(\sqrt{k}\cdot\log^{2}k)}n\log n
preprocessing time:

(P1)

Any entry of
\mathbf{L}
and
\mathbf{R}
can be computed in
k^{O(1)}
time, assuming the subset of
[n]
that indexes the row of
\mathbf{L}
(or the column of
\mathbf{R}
) is given as sequence of its elements,
8
8

8

Entries of
\mathbf{L}
and
\mathbf{R}
indexed by subsets of more than
k
elements actually always are equal to
\bar{0}
.

(P2)

there is an algorithm
\mathsf{convolve}(\mathbf{b},e)
that takes as input a vector
\mathbf{b}\in\mathbb{S}^{r}
and an element
e\in[n]
, and it computes in
2^{k+O(\sqrt{k}\cdot\log^{2}k)}\log n
time and arithmetic operations in
\mathbb{S}
(i.e. addition, multiplication,
\mathsf{lcu}
) a vector
\mathbf{b^{\prime}}\in\mathbb{S}^{r}
such that
\mathbf{b}\cdot\mathbf{R}\cdot\mathbf{C}^{\intercal}_{n,e}\preceq_{\mathbb{S}}\mathbf{b^{\prime}}\cdot\mathbf{R}
and

\text{for all $\mathbf{a}\in\mathbb{S}^{2^{[n]}}$ such that }\mathbf{b}\preceq_{\mathbb{S}}\mathbf{a}\cdot\mathbf{L},\text{ it holds that }\mathbf{b^{\prime}}\preceq_{\mathbb{S}}\mathbf{a}\cdot\mathbf{C}_{n,e}\cdot\mathbf{L}.

Here all time bounds are with respect to the Word RAM model with word size
\log n
.

While the statement of Theorem
3.2
is convenient for its proof, we provide some simple definitions and observations to facilitate its use.
In their statements, we let integers
n,k,r
and matrices
\mathbf{L},\mathbf{R}
be as in Theorem
3.2
.
We first connect Theorem
3.2
to its name “dynamic representative set”:

Definition 3.3
.

A vector
\mathbf{b}\in\mathbb{S}^{r}

represents
a vector
\mathbf{a}\in\mathbb{S}^{2^{[n]}}
if
\mathbf{a}\cdot\mathbf{D}_{n,k}\preceq_{\mathbb{S}}\mathbf{b}\cdot\mathbf{R}
and
\mathbf{b}\preceq_{\mathbb{S}}\mathbf{a}\cdot\mathbf{L}
.

Note
\mathbf{b}\preceq_{\mathbb{S}}\mathbf{a}\cdot\mathbf{L}
implies
\mathbf{b}\cdot\mathbf{R}\preceq_{\mathbb{S}}\mathbf{a}\cdot\mathbf{L}\cdot\mathbf{R}=\mathbf{a}\cdot\mathbf{D}_{n,k}
. Thus, by anti-symmetry of
\preceq_{\mathbb{S}}
we have:

Observation 3.4
.

If
\mathbf{b}
represents
\mathbf{a}
then
\mathbf{a}\cdot\mathbf{D}_{n,k}=\mathbf{b}\cdot\mathbf{R}
.

The utility of Theorem
3.2
lies in that it preserves representation:

Lemma 3.5
.

If
\mathbf{b}
represents
\mathbf{a}
, then
\mathsf{convolve}(\mathbf{b},e)
represents
\mathbf{a}\cdot\mathbf{C}_{n,e}
.

Proof.

Let
\mathbf{b^{\prime}}=\mathsf{convolve}(\mathbf{b},e)
.
For the first condition of Definition
3.3
, note that by Lemma
3.1
we have that

\mathbf{a}\cdot\mathbf{C}_{n,e}\cdot\mathbf{D}_{n,k}=\mathbf{a}\cdot\mathbf{D}_{n,k}\cdot\mathbf{C}^{\intercal}_{n,e}\preceq_{\mathbb{S}}\mathbf{b}\cdot\mathbf{R}\cdot\mathbf{C}^{\intercal}_{n,e}\preceq_{\mathbb{S}}\mathbf{b^{\prime}}\cdot\mathbf{R},

where the two inequalities follow from respectively
\mathbf{b}
representing
\mathbf{a}
, and
(P2)
of Theorem
3.2
.

For the second condition of Definition
3.3
, note that since
\mathbf{b}\preceq\mathbf{a}\cdot\mathbf{L}
,
(P2)
of Theorem
3.2
implies
\mathbf{b^{\prime}}\preceq_{\mathbb{S}}\mathbf{a}\cdot\mathbf{C}_{n,e}\cdot\mathbf{L}
.
∎

The next two observations follow directly from Definition
3.3
and the axioms of linear algebra:

Observation 3.6
.

If
\mathbf{b}
represents
\mathbf{a}
and
\mathbf{b^{\prime}}
represents
\mathbf{a^{\prime}}
, then
\mathbf{b}+\mathbf{b^{\prime}}
represents
\mathbf{a}+\mathbf{a^{\prime}}
.

Observation 3.7
.

If
\lambda\in\mathbb{S}
and
\mathbf{b}
represents
\mathbf{a}
then
\lambda\cdot\mathbf{b}
represents
\lambda\cdot\mathbf{a}
and
\mathbf{b}\cdot\lambda
represents
\mathbf{a}\cdot\lambda
.

The final observation computes a representation of an initial vector:

Observation 3.8
.

We can compute in
2^{k+O(\sqrt{k}\cdot\log^{2}k)}n\log n
time the vector
\mathbf{b}_{\mathsf{init}}:=\mathbf{a}_{\mathsf{init}}\cdot\mathbf{L}
, where
\mathbf{a}_{\mathsf{init}}
denotes the vector that satisfies
\mathbf{a}_{\mathsf{init}}[A]=\llbracket A=\emptyset\rrbracket
, and
\mathbf{b}_{\mathsf{init}}
represents
\mathbf{a}_{\mathsf{init}}
.

It follows from
(P1)
of Theorem
3.2
, which implies that indeed
\mathbf{b}_{\mathsf{init}}[r]=\mathbf{L}[\emptyset,r]
can be computed in the claimed time, and
\mathbf{b}_{\mathsf{init}}
represents
\mathbf{a}_{\mathsf{init}}
because
\mathbf{L}\cdot\mathbf{R}=\mathbf{D}_{n,k}
.

Step 4: Justification of the assumption that
k
is a square

We now prove Theorem
3.2
, assuming it holds whenever
k
is a square number.
Define
s:=\left\lceil\sqrt{k}\right\rceil
,
d:=s^{2}-k
,
n^{\prime}:=n+d
and
k^{\prime}:=s^{2}
. Apply the theorem with
n^{\prime}
and
k^{\prime}
to obtain a factorization
\mathbf{D}_{n^{\prime},k^{\prime}}=\mathbf{L^{\prime}}\cdot\mathbf{R^{\prime}}
of rank
r=2^{k^{\prime}+O(\sqrt{k^{\prime}}\cdot\log^{2}k^{\prime})}\log n^{\prime}=2^{k+O(\sqrt{k}\cdot\log^{2}k)}\log n
.
Define a matrix
\mathbf{P}\in\mathbb{S}^{2^{n}\times 2^{n^{\prime}}}
as follows: For every
A\subseteq[n]
and
A^{\prime}\subseteq[n^{\prime}]
we set

\mathbf{P}[A,A^{\prime}]=\llbracket A\cup\{n+1,\ldots,n+d\}=A^{\prime}\rrbracket.

Observe that
\mathbf{P}\cdot\mathbf{C}_{n,e}=\mathbf{C}_{n,e}\cdot\mathbf{P}
, if

.
Define
\mathbf{L}
and
\mathbf{R}
as follows:

\mathbf{L}:=\mathbf{P}\cdot\mathbf{L^{\prime}}
and
\mathbf{R}
is equal to
\mathbf{R^{\prime}}
restricted to subsets of

. Note that, for any

.
Hence,
\mathbf{L}\cdot\mathbf{R}=\mathbf{D}_{n,k}
.
Moreover, any entry of
\mathbf{L}
and
\mathbf{R}
can be computed in

time since this also holds for
\mathbf{L^{\prime}}
and
\mathbf{R^{\prime}}
. Hence
(P1)
follows.

We now show
(P2)
. Let

be the algorithm that is given by Theorem
3.2
with

.
Let

.
