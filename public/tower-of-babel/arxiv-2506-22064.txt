Disentangling the growth rate of perturbations from the HI bias using only clustering data from galaxy surveys
Pankaj Chavan, Tapomoy Guha Sarkar, Anjan A Sen

Abstract
This work serves two-fold purpose. Firstly, we provide an alternative to the traditional method of determining the growth rate of density perturbations f ⁡ ( z ) f(z) . In usual practice, f ⁡ ( z ) f(z) can not be directly measured from tracer clustering at some redshift without knowledge of the bias. While the bayron acoustic oscillation (BAO) imprint allows the determination of ( D A ​ ( z ) , H ​ ( z ) ) (D_{A}(z),H(z)) , redshift space anisotropy (RSD) allows the measurement of a quantity f 8 ​ ( z ) = f ⁡ ( z ) ​ σ 8 , 0 ​ D + ​ ( z ) f_{8}(z)=f(z)\sigma_{8,0}D_{+}(z) . To extract f ⁡ ( z ) f(z) from f 8 ​ ( z ) f_{8}(z) , one usually requires some other data set. We show that precise BAO and RSD measurements in and around some key redshifts themselves can solely reconstruct f ⁡ ( z ) f(z) without requiring any other data sets. Secondly, we extend this approach to another tracer, namely the post-reionization 21-cm brightness temperature intensity maps. We demonstrate that the measured f ⁡ ( z ) f(z) from purely redshift space clustering allows us to measure the 21-cm bias, which is a largely unknown quantity. This may help interpret the observed intensity mapping signal in the future.
