A new maximal regularity for parabolic equations and an application
Jinlong Wei, Wei Wang, Guangying Lv, Jinqiao Duan

Abstract




Abstract
We introduce the Lebesgue–Hölder–Dini and Lebesgue–Hölder spaces
L^{p}(\mathbb{R};{\mathcal{C}}_{\vartheta,\varsigma}^{\alpha,\rho}({\mathbb{R}}^{n}))
(
\vartheta\in\{l,b\},\,\varsigma\in\{d,s,c,w\}
,
p\in(1,+\infty]
and
\alpha\in[0,1)
), and then use a vector-valued Calderón–Zygmund theorem to establish the maximal Lebesgue–Hölder–Dini and Lebesgue–Hölder regularity for a class of parabolic equations. As an application, we obtain the unique strong solvability of the following stochastic differential equation

\displaystyle X_{s,t}(x)=x+\int\limits_{s}^{t}b(r,X_{s,r}(x))dr+W_{t}-W_{s},\ \ t\in[s,T],\ x\in\mathbb{R}^{n},\ s\in[0,T],

for the low regularity growing drift in critical Lebesgue–Hölder–Dini spaces
L^{p}([0,T];{\mathcal{C}}^{\frac{2}{p}-1,\rho}_{l,d}({\mathbb{R}}^{n};{\mathbb{R}}^{n}))
(
p\in(1,2]
), where

\{W_{t}\}_{0\leqslant t\leqslant T}
is a
n
-dimensional standard Wiener process. In particular, when
p=2
we give a partially affirmative answer to a longstanding open problem, which was proposed by Krylov and Röckner for
b\in L^{2}([0,T];L^{\infty}({\mathbb{R}}^{n};{\mathbb{R}}^{n}))
based upon their work (
Probab. Theory Relat. Fields 131(2): 154–196, 2005
).

MSC:
35K10; 60H10

Keywords:
Calderón–Zygmund kernel, Maximal Lebesgue–Hölder–Dini regularity, Maximal Lebesgue–Hölder regularity, Stochastic differential equation, Low regularity growing drift.

\displaystyle b\in L^{p}([0,T];{\mathcal{C}}^{\alpha}({\mathbb{R}}^{n};{\mathbb{R}}^{n})),\ \ p\in(1,2),\ \ \alpha\in(0,1),\ \ \frac{2}{p}-\alpha=1.

Definition 2.5

An increasing continuous function
\rho:\mathbb{R}_{+}\rightarrow\mathbb{R}_{+}
is called a Dini function if

\displaystyle\int\limits_{0}^{1}\frac{\rho(r)}{r}dr<+\infty.

A measurable function
\rho:\mathbb{R}_{+}\rightarrow\mathbb{R}_{+}
is called a slowly varying function at zero (in Karamata’s sense
[
2

) if for

\upsilon>0

\displaystyle\lim_{r\rightarrow 0}\frac{\rho(\upsilon r)}{\rho(r)}=1.

A measurable function

is said to be locally Dini continuous if there is a Dini function
\rho
such that

\displaystyle|h(x)-h(y)|\leqslant\rho(|x-y|),\ \ x,y\in{\mathbb{R}}^{n},\ |x-y|\leqslant 1.

Example 2.6

Let
\beta<-1
and

\displaystyle\rho(r)=\left\{\begin{array}[]{ll}|\log(r)|^{\beta},&{\rm when}\ \ 0<r<\frac{1}{2},\\
\quad\psi(r),&{\rm when}\ \ r\geqslant\frac{1}{2},\end{array}\right.

where

\displaystyle\psi\left(\frac{1}{2}\right)=|\log(2)|^{\beta},\quad\psi^{\prime}\left(\frac{1}{2}\right)=-2\beta|\log(2)|^{\beta-1}.

Then we have

\displaystyle\int\limits_{0}^{1}\frac{\rho(r)}{r}dr=\int\limits_{0}^{\frac{1}{2}}\frac{|\log(r)|^{\beta}}{r}dr+\int\limits_{\frac{1}{2}}^{1}\psi(r)dr\leqslant-\frac{|\log(2)|^{\beta+1}}{\beta+1}+\frac{1}{2}\psi(1)<+\infty.

Moreover, for all

\displaystyle\lim_{r\rightarrow 0}\frac{\rho(\upsilon r)}{\rho(r)}=\lim_{r\rightarrow 0}\frac{|\log(\upsilon r)|^{\beta}}{|\log(r)|^{\beta}}=\lim_{r\rightarrow 0}\frac{|\log(\upsilon)+\log(r)|^{\beta}}{|\log(r)|^{\beta}}=1.

Therefore,

is a Dini and slowly varying (at zero) function. Similarly, let

\displaystyle\rho(r)=\left\{\begin{array}[]{ll}|\log(r)|^{\beta}e^{-\frac{1}{r}},&{\rm when}\ \ 0<r<\frac{1}{2},\\
\quad\psi_{1}(r),&{\rm when}\ \ r\geqslant\frac{1}{2},\end{array}\right.

is a Dini function. However, for all

\displaystyle\lim_{r\rightarrow 0}\frac{\rho(\upsilon r)}{\rho(r)}=\lim_{r\rightarrow 0}\frac{|\log(\upsilon r)|^{\beta}e^{-\frac{1}{\upsilon r}}}{|\log(r)|^{\beta}e^{-\frac{1}{r}}}=\lim_{r\rightarrow 0}\Big[\frac{|\log(\upsilon)+\log(r)|^{\beta}}{|\log(r)|^{\beta}}e^{\frac{(\upsilon-1)}{r\upsilon}}\Big]=+\infty.

The function

\displaystyle 0\leqslant\tilde{\varrho}\in{\mathcal{C}}^{\infty}_{0}({\mathbb{R}}^{n}),\ \ \,{\rm supp}(\tilde{\varrho})\subset B_{1},\ \int\limits_{{\mathbb{R}}^{n}}\tilde{\varrho}(x)dx=1.

For
k\in{\mathbb{N}}
, we set
\tilde{\varrho}_{k}(x)=k\tilde{\varrho}(kx)
, and then smooth
b
in space variable by
\tilde{\varrho}_{k}

b^{k}(t,x)=(b(t,\cdot)\ast\tilde{\varrho}_{k})(x)=\int\limits_{{\mathbb{R}}^{n}}b(t,x-y)\tilde{\varrho}_{k}(y)dy\,.

Let
\chi_{R}
be given by (
7
). We set
b^{k}_{R}(t,x)=b^{k}(t,x\chi_{R}(x))
, then
b^{k}_{R}\in L^{2}([0,T];{\mathcal{C}}_{b,d}^{\beta,\rho}({\mathbb{R}}^{n};{\mathbb{R}}^{n}))
for every

and

\displaystyle\lim_{k\rightarrow+\infty}\lim_{R\rightarrow+\infty}|b^{k}_{R}(t,x)-b(t,x)|=0,\ \ \ {\rm for\;all}\ (t,x)\in[0,T]\times{\mathbb{R}}^{n}.

(7.29)

Moreover, we get analogues of (
7.9
) and (
7.10
) that

\displaystyle\int\limits_{0}^{T}\|(1+|\cdot|)^{-1}b^{k}_{R}(t,\cdot)\|_{0}^{2}dt\leqslant 4\int\limits_{0}^{T}\|(1+|\cdot|)^{-1}b(t,\cdot)\|_{0}^{2}dt

(7.30)

and

\displaystyle[b^{k}_{R}]_{2,0,\rho}\leqslant[b]_{2,0,\rho}\sup_{0<|x-y|\leqslant 1}\frac{\rho(3|x-y|)}{\rho(|x-y|)}\leqslant C[b]_{2,0,\rho},

(7.31)

where

\displaystyle[b^{k}_{R}]_{2,0,\rho}^{2}=\int\limits_{0}^{T}[b^{k}_{R}(r,\cdot)]_{0,\rho}^{2}dr\ \ {\rm and}\ \ [b]_{2,0,\rho}^{2}=\int\limits_{0}^{T}[b(r,\cdot)]_{0,\rho}^{2}dr.

Consider the following Kolmogorov equation

\displaystyle\left\{\begin{array}[]{ll}\partial_{t}U^{k}_{R}(t,x)=\frac{1}{2}\Delta U^{k}_{R}(t,x)+b^{k}_{R}(t,x)\cdot\nabla U^{k}_{R}(t,x)\\
\qquad\qquad\qquad-\lambda U^{k}_{R}(t,x)+b^{k}_{R}(t,x),\ \ (t,x)\in(0,T]\times{\mathbb{R}}^{n},\\
U^{k}_{R}(0,x)=0,\ \ x\in{\mathbb{R}}^{n}\,.\end{array}\right.

By Theorem
3.6
(i), there exists a unique
U^{k}_{R}\in L^{2}([0,T];{\mathcal{C}}_{l,d}^{1+\beta,\rho}({\mathbb{R}}^{n};{\mathbb{R}}^{n}))\cap W^{1,2}([0,T];{\mathcal{C}}_{l,d}^{\beta,\rho}({\mathbb{R}}^{n};{\mathbb{R}}^{n}))\cap L^{\infty}([0,T];{\mathcal{C}}^{1+\beta,\rho}_{l,d}({\mathbb{R}}^{n};{\mathbb{R}}^{n}))
solving the Cauchy problem (
7
). Moreover,
U^{k}_{R}
satisfies integral equation (
7.15
) if one uses
b^{k}_{R}
instead of
b_{m,R}
.
Similar to (
7.16
)–(
7.21
), if one chooses
p=2
, then we get an analogue of (
7.22
) that

\displaystyle\sup_{0\leqslant t\leqslant T}\|\nabla U^{k}_{R}(t,\cdot)\|_{0}\leqslant C[b]_{2,0,\rho}\Big[1+\sup_{0\leqslant\tau\leqslant T}\|\nabla U^{k}_{R}(r,\cdot)\|_{0}\Big]\Bigg\{\int\limits_{0}^{\sqrt{T}}e^{-2\lambda r^{2}}\Big[r+\frac{\rho(r)}{r}\Big]dr\Bigg\}^{\frac{1}{2}},

which also suggests that

\displaystyle\sup_{0\leqslant t\leqslant T}\|\nabla U^{k}_{R}(t,\cdot)\|_{0}\leqslant\frac{3}{2}C[b]_{2,0,\rho}\Bigg\{\int\limits_{0}^{\sqrt{T}}e^{-2\lambda r^{2}}\Big[r+\frac{\rho(r)}{r}\Big]dr\Bigg\}^{\frac{1}{2}}\leqslant\frac{1}{2},

(7.36)

by choosing
\lambda
large enough such that

\displaystyle C[b]_{2,0,\rho}\Bigg\{\int\limits_{0}^{\sqrt{T}}e^{-2\lambda r^{2}}\Big[r+\frac{\rho(r)}{r}\Big]dr\Bigg\}^{\frac{1}{2}}\leqslant\frac{1}{3}.

By similar arguments as (
7.24
)–(
7.26
), we also get

\displaystyle\left\{\begin{array}[]{ll}\sup\limits_{0\leqslant t\leqslant T}\sup\limits_{x\in{\mathbb{R}}^{n}}\frac{|U^{k}_{R}(t,x)|}{1+|x|}\leqslant C\|b\|_{L^{2}([0,T];{\mathcal{C}}_{l,d}^{0,\rho}({\mathbb{R}}^{n};{\mathbb{R}}^{n}))},\\[5.69046pt]
\|\nabla^{2}U^{k}_{R}\|_{L^{2}([0,T];L^{\infty}({\mathbb{R}}^{n};{\mathbb{R}}^{n}))}\leqslant C[b]_{2,0,\rho}\Big[1+\int\limits_{0}^{\sqrt{T}}e^{-\lambda r^{2}}\frac{\rho^{\frac{1}{2}}(r)}{r}dr\Big]\leqslant C[b]_{2,0,\rho},\\[5.69046pt]
\|(1+|\cdot|)^{-1}\partial_{t}U^{k}_{R}(t,\cdot)\|_{L^{2}([0,T];L^{\infty}({\mathbb{R}}^{n};{\mathbb{R}}^{n}))}\leqslant C\|b\|_{L^{2}([0,T];{\mathcal{C}}_{l,d}^{0,\rho}({\mathbb{R}}^{n};{\mathbb{R}}^{n}))}.\end{array}\right.

In view of (
7.36
)–(
7
) and (
7.29
) there exists a (unlabelled) subsequence
U^{k}_{R}
and a measurable function
U\in{\mathcal{H}}_{T}
such that
U^{k}_{R}(t,x)\rightarrow U(t,x)\in{\mathcal{H}}_{T}
for a.e.
(t,x)\in[0,T]\times{\mathbb{R}}^{n}
as

and

tend to infinity in turn. In particular

satisfies (
7
) and the estimate (
7.27
) holds true.

For the uniqueness, the argument is the same for the case of

. So we complete the proof of the unique solvability for the Kolmogorov equation (

) in
{\mathcal{H}}_{T}
.

Part II:
the well-posedness of solutions for SDE (
1.18
) with low regularity growing drift.

Let
U
be the unique strong solution of (
7
). We set
V(t,x)=U(T-t,x)
, then
V\in{\mathcal{H}}_{T}
and satisfies

\displaystyle\left\{\begin{array}[]{ll}\partial_{t}V(t,x)+\frac{1}{2}\Delta V(t,x)+b(t,x)\cdot\nabla V(t,x)\\
\qquad=\lambda V(t,x)-b(t,x),\ \ (t,x)\in[0,T)\times{\mathbb{R}}^{n},\\
V(T,x)=0,\ x\in{\mathbb{R}}^{n}\,.\end{array}\right.

Moreover, (
7.27
) holds true for
V
. Now set
\Phi(t,x)=x+V(t,x)
, then
\Phi
forms a nonsingular homeomorphism uniformly in
t\in[0,T]
and

\displaystyle\frac{1}{2}\leqslant\sup_{0\leqslant t\leqslant T}\|\nabla\Phi(t,\cdot)\|_{0}\leqslant\frac{3}{2},\quad\frac{2}{3}\leqslant\sup_{0\leqslant t\leqslant T}\|\nabla\Psi(t,\cdot)\|_{0}\leqslant 2,

(7.45)

where
\Psi(t,\cdot)=\Phi^{-1}(t,\cdot)
.

For
0<\epsilon<1
and
t\in[0,T]
, define

\displaystyle V_{\epsilon}(t,x)=\frac{1}{\epsilon}\int\limits_{t}^{t+\epsilon}V(r,x)dr=\int\limits_{0}^{1}V(t+r\epsilon,x)dr

and
\Phi_{\epsilon}(t,x)=x+V_{\epsilon}(t,x)
, where
V(t,x):=V(T,x)=0
when
t>T
. Notice that
\Phi_{\epsilon}\in W^{1,2}([0,T];W^{2,\infty}_{loc}({\mathbb{R}}^{n};{\mathbb{R}}^{n}))
, if
X_{s,t}(x)
is a strong solution of SDE (
1.18
), in light of Itô’s formula (
[
25
, Theorem 3.7]
), we derive

\displaystyle\Phi_{\epsilon}(t,X_{s,t}(x))=\Phi_{\epsilon}(s,x)+\int\limits_{s}^{t}\partial_{r}V_{\epsilon}(r,X_{s,r}(x))dr+\int\limits_{s}^{t}b(r,X_{s,r}(x))\cdot\nabla V_{\epsilon}(r,X_{s,r}(x))dr

\displaystyle\quad+\frac{1}{2}\int\limits_{s}^{t}\Delta V_{\epsilon}(r,X_{s,r}(x))dr+\int\limits_{s}^{t}b(r,X_{s,r}(x))dr+\int\limits_{s}^{t}[I+\nabla V_{\epsilon}(r,X_{s,r}(x))]dW_{r}.

(7.46)

Since
V\in{\mathcal{H}}_{T}
, if one lets
\epsilon
tend to
0
in (
7.46
), we obtain

\displaystyle\Phi(t,X_{s,t}(x))=\Phi(s,x)+\int\limits_{s}^{t}\partial_{r}V(r,X_{s,r}(x))dr+\int\limits_{s}^{t}b(r,X_{s,r}(x))\cdot\nabla V(r,X_{s,r}(x))dr

\displaystyle\quad+\frac{1}{2}\int\limits_{s}^{t}\Delta V(r,X_{s,r}(x))dr+\int\limits_{s}^{t}b(r,X_{s,r}(x))dr+\int\limits_{s}^{t}[I+\nabla V(r,X_{s,r}(x))]dW_{r}

\displaystyle=\Phi(s,x)+\lambda\int\limits_{s}^{t}V(r,X_{s,r}(x))dr+\int\limits_{s}^{t}(I+\nabla V(r,X_{s,r}(x)))dW_{r},

(7.47)

where in the last line we have used the fact that
V
satisfies the Cauchy problem (
7
).

Denote
Y_{s,t}(y)=\Phi(t,X_{s,t}(x))
, it follows from (
7.47
) that

\displaystyle\left\{\begin{array}[]{ll}dY_{s,t}(y)=\lambda V(t,\Psi(t,Y_{s,t}(y)))dt+(I+\nabla V(t,\Psi(t,Y_{s,t}(y))))dW_{t}\\
\quad\quad\ =:\tilde{b}(t,Y_{s,t}(y))dt+\tilde{\sigma}(t,Y_{s,t}(y))dW_{t},\ t\in(s,T],\\
Y_{s,s}=y=\Phi(s,x).\end{array}\right.

Conversely, if
Y_{s,t}(y)
is a strong solution of SDE (
7
), with the help of (
7.45
) and Itô’s formula,
X_{s,t}(x)=\Psi(t,Y_{s,t}(y))
satisfies SDE (
1.18
). Therefore, SDEs (
1.18
) and (
7
) are equivalent. By the regularity of
V
, we have
\tilde{b}\in L^{\infty}([0,T];Lip({\mathbb{R}}^{n};{\mathbb{R}}^{n}))
and
\tilde{\sigma}\in L^{2}([0,T];W^{1,\infty}({\mathbb{R}}^{n};{\mathbb{R}}^{n\times n}))
. Owing to Cauchy–Lipschitz’s theorem, there exists a unique strong solution
Y_{s,t}(y)
to (
7
), which also satisfies that
Y_{s,t}(y)=Y_{r,t}(Y_{s,r}(y))
for all
0\leqslant s\leqslant r\leqslant t\leqslant T
and
y\in{\mathbb{R}}^{n}
, and
Y_{s,s}(y)=y
. Moreover, an application of Itô’s formula to
|Y_{s,t}|^{q}
yields that

\displaystyle d|Y_{s,t}(y)|^{q}\leqslant C[1+|Y_{s,t}(y)|^{q}]dt+q|Y_{s,t}(y)|^{q-2}\langle Y_{s,t}(y),\tilde{\sigma}(t,Y_{s,t}(y))dW_{t}\rangle,\quad{\rm for\;}\ q\geqslant 2.

Observe that for every
t>s
,
\int\limits_{s}^{t}|Y_{s,r}(y)|^{q-2}\langle Y_{s,r}(y),\tilde{\sigma}(r,Y_{s,r}(y))dW_{r}\rangle
is a martingale. Then

\displaystyle\sup_{s\leqslant t\leqslant T}{\mathbb{E}}|Y_{s,t}(y)|^{q}\leqslant C(1+|y|^{q}).

(7.52)

Now let us check the homeomorphisms. Due to
[
26
, Lemmas II.2.4, II.4.1 and II.4.2]

and the estimate

\displaystyle\sup_{s\leqslant t\leqslant T}{\mathbb{E}}(1+|Y_{s,t}(y)|)^{\xi}\leqslant C(1+|y|)^{\xi},\quad{\rm for}\ \xi<0,

which is direct by using the Itô formula, it is sufficient to prove that for every
y,y^{\prime}\in{\mathbb{R}}^{n}
(
y\neq y^{\prime}
) and every
s,t,s^{\prime},t^{\prime}\in[0,T]
(
s<t,\,s^{\prime}<t^{\prime}
),

\displaystyle\sup_{s\leqslant t\leqslant T}{\mathbb{E}}|Y_{s,t}(y)-Y_{s,t}(y^{\prime})|^{2\xi}\leqslant C|y-y^{\prime}|^{2\xi},\quad{\rm for}\ \xi<0,

(7.53)

and

\displaystyle{\mathbb{E}}|Y_{s,t}(y)-Y_{s^{\prime},t^{\prime}}(y^{\prime})|^{q}\leqslant C\Big\{|y-y^{\prime}|^{q}+(1+|y|^{q}+|y^{\prime}|^{q})[|s-s^{\prime}|^{\frac{q}{2}}+|t-t^{\prime}|^{\frac{q}{2}}]\Big\},\;{\rm for}\ q\geqslant 2.

(7.54)

We first treat (
7.53
). For
\epsilon>0
, we
choose
f_{\epsilon}(x)=(\epsilon+|x|^{2})
and
set
Y_{s,t}(y,y^{\prime}):=Y_{s,t}(y)-Y_{s,t}(y^{\prime})
. In view of Itô’s formula

\displaystyle f^{\xi}_{\epsilon}(Y_{s,t}(y,y^{\prime}))

\displaystyle\leqslant

\displaystyle f^{\xi}_{\epsilon}(y-y^{\prime})+C|\xi|\int\limits_{s}^{t}f^{\xi}_{\epsilon}(Y_{s,r}(y,y^{\prime}))dr+C|\xi(\xi-1)|\int\limits_{s}^{t}\kappa^{2}(r)f^{\xi}_{\epsilon}(Y_{s,r}(y,y^{\prime}))dr

(7.55)

\displaystyle+2\xi\int\limits_{s}^{t}f^{\xi-1}_{\epsilon}(Y_{s,r}(y,y^{\prime})))\langle Y_{s,r}(y,y^{\prime}),(\tilde{\sigma}(r,Y_{s,r}(y))-\tilde{\sigma}(r,Y_{s,r}(y^{\prime})))dW_{r}\rangle,

where
\kappa(r)=\|\nabla^{2}V(r,\cdot)\|_{0}\in L^{2}([0,T])
for
\nabla V\in L^{2}([0,T];W^{1,\infty}({\mathbb{R}}^{n};{\color[rgb]{1,0,0}{\mathbb{R}}^{d\times d}}))
.
Due to the Grönwall inequality, we obtain from (
7.55
) that

\displaystyle\sup_{s\leqslant t\leqslant T}{\mathbb{E}}[\epsilon+|Y_{s,t}(y)-Y_{s,t}(y^{\prime})|^{2}]^{\xi}\leqslant C[\epsilon+|y-y^{\prime}|^{2}]^{\xi}.

Then (
7.53
) follows by letting
\epsilon\downarrow 0
.

To prove (
7.54
), we assume without loss of generality that
s<s^{\prime}<t<t^{\prime}
, then

\displaystyle|Y_{s,t}(y)-Y_{s^{\prime},t^{\prime}}(y^{\prime})|^{q}

(7.56)

\displaystyle\leqslant

\displaystyle 3^{q-1}[|Y_{s,t}(y)-Y_{s,t}(y^{\prime})|^{q}+|Y_{s,t}(y^{\prime})-Y_{s^{\prime},t}(y^{\prime})|^{q}+|Y_{s^{\prime},t}(y)-Y_{s^{\prime},t^{\prime}}(y^{\prime})|^{q}].

Applying the Itô formula to
|Y_{s,t}(y)-Y_{s,t}(y^{\prime})|^{q}
yields

\displaystyle{\mathbb{E}}|Y_{s,t}(y)-Y_{s,t}(y^{\prime})|^{q}\leqslant|y-y^{\prime}|^{q}+C\int\limits_{s}^{t}[1+\kappa^{2}(r)]{\mathbb{E}}|Y_{s,r}(y)-Y_{s,r}(y^{\prime})|^{q}dr,

then by the Grönwall inequality

\displaystyle\sup_{s\leqslant t\leqslant T}{\mathbb{E}}|Y_{s,t}(y)-Y_{s,t}(y^{\prime})|^{q}\leqslant C|y-y^{\prime}|^{q}.

(7.57)

For
|Y_{s,t}(y^{\prime})-Y_{s^{\prime},t}(y^{\prime})|^{q}
, by employing Itô’s formula again, one ascertains

\displaystyle{\mathbb{E}}|Y_{s,t}(y^{\prime})-Y_{s^{\prime},t}(y^{\prime})|^{q}\leqslant{\mathbb{E}}|Y_{s,s^{\prime}}(y^{\prime})-y^{\prime}|^{q}+C{\mathbb{E}}\int\limits_{s^{\prime}}^{t}[1+\kappa^{2}(r)]|Y_{s,r}(y^{\prime})-Y_{s^{\prime},r}(y^{\prime})|^{q}dr.

This, together with the Grönwall and Minkowski inequalities, leads to

\displaystyle{\mathbb{E}}|Y_{s,t}(y^{\prime})-Y_{s^{\prime},t}(y^{\prime})|^{q}

\displaystyle\leqslant

\displaystyle C{\mathbb{E}}|Y_{s,s^{\prime}}(y^{\prime})-y^{\prime}|^{q}

(7.58)

\displaystyle\leqslant

\displaystyle C\Big|\int\limits_{s}^{s^{\prime}}[{\mathbb{E}}|\tilde{b}(r,Y_{s,r}(y^{\prime}))|^{q}]^{\frac{1}{q}}dr\Big|^{q}+C{\mathbb{E}}\Big[\int\limits_{s}^{s^{\prime}}\|\tilde{\sigma}(r,Y_{s,r}(y^{\prime}))\|^{2}dr\Big]^{\frac{q}{2}}

\displaystyle\leqslant

\displaystyle C[1+\sup_{s\leqslant r\leqslant T}{\mathbb{E}}|Y_{s,r}(y^{\prime}))|^{q}]|s-s^{\prime}|^{q}+C|s-s^{\prime}|^{\frac{q}{2}}

\displaystyle\leqslant

\displaystyle C[(1+|y^{\prime}|^{q})|s-s^{\prime}|^{q}+|s-s^{\prime}|^{\frac{q}{2}}]\leqslant C(1+|y^{\prime}|^{q})|s-s^{\prime}|^{\frac{q}{2}},

where in the third line we have used the fact
\tilde{b}
is Lipschitz continuous uniformly in time variable and
\tilde{\sigma}
is bounded.

For the term
|Y_{s^{\prime},t}(y^{\prime})-Y_{s^{\prime},t^{\prime}}(y^{\prime})|^{q}
we have

\displaystyle{\mathbb{E}}|Y_{s^{\prime},t}(y^{\prime})-Y_{s^{\prime},t^{\prime}}(y^{\prime})|^{q}

\displaystyle=

\displaystyle{\mathbb{E}}\Bigg|\int\limits_{t}^{t^{\prime}}\tilde{b}(r,Y_{s^{\prime},r}(y^{\prime}))dr+\int\limits_{t}^{t^{\prime}}\tilde{\sigma}(r,Y_{s^{\prime},r}(y^{\prime}))dW_{r}\Bigg|^{q}

(7.59)

\displaystyle\leqslant

\displaystyle C(1+|y^{\prime}|^{q})|t-t^{\prime}|^{\frac{q}{2}}.

Summing over (
7.56
)–(
7.59
), we obtain (
7.54
). Thus
Y_{s,t}(\cdot)
forms a homeomorphism. Observing that
Y_{s,t}
satisfies equation (
7
), then

\displaystyle Y_{s,t}(Y^{-1}_{s,t}(y))=Y^{-1}_{s,t}(y)+\int\limits_{s}^{t}\tilde{b}(r,Y_{s,r}(Y^{-1}_{s,t}(y)))dr+\int\limits_{s}^{t}\tilde{\sigma}(r,Y_{s,r}(Y^{-1}_{s,t}(y)))dW_{r}.

Noting that
Y_{s,r}(Y^{-1}_{s,t}(y))=Y^{-1}_{r,t}(y)
, thus

\displaystyle Y^{-1}_{s,t}(y)=y-\int\limits_{s}^{t}\tilde{b}(r,Y^{-1}_{r,t}(y))dr-\int\limits_{s}^{t}\tilde{\sigma}(r,Y^{-1}_{r,t}(y))dW_{r}.

(7.60)

We then get an analogue of (

once taken into account the backward character of the equation (

is continuous in
(s,t,y)
almost surely in

, and

forms a stochastic flow of homeomorphisms to SDE
(

).
