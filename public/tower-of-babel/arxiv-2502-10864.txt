Recursions for quadratic rotation symmetric functions weights
Thomas W. Cusick

Abstract
A Boolean function in n n variables is rotation symmetric (RS) if it is invariant under powers of ρ ⁡ ( x 1 , … , x n ) = ( x 2 , … , x n , x 1 ) \rho(x_{1},\ldots,x_{n})=(x_{2},\ldots,x_{n},x_{1}) . An RS function is called monomial rotation symmetric (MRS) if it is generated by applying powers of ρ \rho to a single monomial. The author showed in 2017 2017 that for any RS function f n f_{n} in n n variables, the sequence of Hamming weights w ​ t ​ ( f n ) wt(f_{n}) for all values of n n satisfies a linear recurrence with associated recursion polynomial given by the minimal polynomial of a rules matrix . Examples showed that the usual formula for the weights w ​ t ​ ( f n ) wt(f_{n}) in terms of powers of the roots of the minimal polynomial always has simple coefficients. The conjecture that this is always true is the Easy Coefficients Conjecture (ECC). The present paper proves the ECC if the rules matrix satisfies a certain condition. Major applications include an enormous decrease in the amount of computation that is needed to determine the values of w ​ t ​ ( f n ) wt(f_{n}) for a quadratic RS function f n f_{n} if either n n or the order of the recursion for the weights is large, and a simpler way to determine the Dickson form of f n . f_{n}. The ECC also enables rapid computation of generating functions which give the values of w ​ t ​ ( f n ) wt(f_{n}) as coefficients in a power series.

An important tool in Boolean function theory (see

In this paper we shall mainly need the case

A Boolean function of degree

Lemma 1

Two quadratic Boolean functions

There is also a well-known

Lemma 2

For any Boolean function

N(f)=2^{n-1}-\frac{1}{2}\max_{x\in V_{n}}|W_{f}(x)|.

After earlier work on special cases, the following general theorem was proved in

Theorem 1
.

Let

denote any rotation symmetric function in

r
ules matrix (which depends on the choice of the function
f_{k}
), with any powers of
x
in the minimal polynomial removed.

An algorithm for computing the rules matrix was explained in
[
11
]
. A Mathematica program for computing the rules matrix was given in
[
12
]

[

[

]

[
3
]

The quadratic case was not explicitly considered in

We begin with a set

Q_{m}=\{(1,t_{1}),(1,t_{2}),\ldots,(1,t_{m})\}

(4)

Remark 1

The rules matrix is square with

rows (we say it has size

Every row and column in the Rules matrix has exactly two nonzero elements, and these nonzero elements are always either

or
-1.
No row or column contains two elements
-1.
The last column of the rules matrix is always
[0,0,\ldots,0,2]

and the last row has
1
in every column which contains

Theorem
2
below gives every statement in Remark

, and more.
Here we briefly describe the program which computes the rules matrix (for details see the Appendix). The program first computes a much larger (size

with

{\emph{e}xpanded~rules~matrix}.
Once the expanded matrix has been computed, the next step in the program is to delete the
i
-th row if it is all zeros and to also delete the
i
-th column. If the resulting matrix still has any zero rows, the process of deleting zero rows and the corresponding columns is repeated until a matrix with no zero rows is reached.

The next lemma gives some important facts about the expanded rules matrix.

Lemma 3

The expanded rules matrix

The final rules matrix with no zero rows has nonzero determinant and size

Also the last column is always

Corollary 1

If

The quadratic Easy Coefficients Conjecture

We begin with some results that are easily derived from Theorem
2
and the details in the Appendix.
First, we can extend Example
1
to any MRS function
(1,t)_{n}.

Lemma 4
.

The minimal polynomial
m_{t}(x)
for the rules matrix (which is square of size
2^{t-1}+1
) of
(1,t)_{n}
is

m_{t}(x)=x^{2t-1}-2x^{2t-2}-2^{t-1}x+2^{t}=(x-2)(x^{2t-2}-2^{t-1}).

The characteristic polynomial
c_{t}(x)
for the rules matrix has degree
2^{t-1}+1,
has no
0

2
is never a multiple root.

Proof.

A direct proof of this is given in
[
6

. Note that the rules matrix defined in this paper has an extra final row and column (corresponding to the root
2
which the minimal polynomial of the rules matrix always has) compared to the ”rules matrix” (called the Rules matrix in this paper) defined in
[
6
]
.
This lemma can also be deduced from the work in the Appendix.
∎

We see from Lemma
4
that the minimal polynomial for the rules matrix of
(1,t)_{n}
in general has much smaller degree (
2t-1
) than the characteristic polynomial (degree
2^{t-1}+1
). A similar result is true for the general quadratic RS function
f(Q_{m})=f^{(m)}
defined by (

) when (

) holds. The next lemma shows that changing the order of the functions in

simply replaces the rules matrix by a similar matrix, and in fact the two rules matrices are permutation equivalent.

Lemma 5

Let
R(f^{(m)})
denote the Rules matrix for
f^{(m)}=f(Q_{m})
when

and (

) holds. If
R^{\prime}(f^{(m)})
denotes the Rules matrix for
f^{(m)}
with some different ordering of the integers

then
R^{\prime}(f^{(m)})=PR(f^{(m)})P^{-1}
for some permutation matrix

(which is the identity matrix

with permuted rows). Obviously this also holds for the rules matrix.

Proof.

It follows from Theorem

and (

), (
14
) and (

) that the number of zero rows in the expanded rules matrix for

does not depend on the ordering of the functions in (

). It also follows that there is a one-to-one correspondence between the columns in
R(f^{(m)})
with two entries
1
and the columns of
R^{\prime}(f^{(m)})
with two entries
1,
and a similar correspondence between the columns with entries
1
and
-1.
Therefore, whatever the ordering of the functions in

the Rules matrix which is produced by the process of deleting all the zero rows from

is permutation equivalent to

The final sentence in the lemma is trivially true because of the special form (see Lemma

Theorem 3
.

For any quadratic RS Boolean function
f^{(m)}=f(Q_{m})
, where

is given by (

and let

denote the rules matrix for

The method in the Appendix gives the nonsingular square rules matrix of size

Let

denote the minimal polynomial of

and let

denote the characteristic polynomial of

Then the weights of
f_{n}
satisfy a linear recursion with integer coefficients of order
\deg m_{f}(x).
The weights also satisfy a linear recursion with integer coefficients of order
\deg c_{f}(x)=2^{T}+1.

Proof.

Everything but the last sentence is simply the quadratic case of Theorem
1
. Note that by Lemma
5
we can assume without loss of generality that (
5
) holds. By Corollary
1
the minimal polynomial has distinct roots. It is well-known that the sets of roots of
m_{f}(x)
and
c_{f}(x)
are the same, but roots (except for
2
) can occur with multiplicity
>1
in
c_{f}(x).
Thus by adjusting the coefficients in the weight recursion of order
\deg m_{f}(x)
we can get a recursion of order
\deg c_{f}(x).

∎

Given
f^{(m)}=f(Q_{m}),
let the roots of the minimal polynomial
m_{f}(x)
of

of degree

be
2
and
\mu_{i},1\leq i\leq D-1.
We know from Corollary
1
that these roots are distinct. Then
from Theorem
3
and the theory of linear recurrences (see
[

) it is possible to represent

as a linear combination of the

-th powers
of the roots of
m_{f}(x)
with complex number coefficients and it is also possible to represent

as a linear combination of the
n
-th powers of the roots of

with some other coefficients. The Easy Coefficients Conjecture (ECC) stated below says that if we choose the representation in terms of the roots of

(this just means repeating each root of

as many times as it occurs as a root of

), then the coefficients are very simple (all are

except for the coefficient of the root

which is

).

\mu_{i},
each repeated as often as its multiplicity in the characteristic polynomial of
r(f^{(m)}).
Then

wt(f_{n})=2^{n-1}-\sum_{j=1}^{2^{T}}\frac{1}{2}\eta_{j}^{n},~n=1,2,\ldots

(6)

The ECC implies an enormous decrease in the amount of computation that is need to determine the values of
wt(f_{n})
for a quadratic RS function
f_{n}
if either
n
or the order of the recursion for the weights is large. Without the ECC, even if we know the coefficients in a recursion polynomial of degree
d
for the weights
wt(f_{n}),
we need to determine the initial
2d+1
values of
wt(f_{n})
in order to compute any weight values for
n
large. This is an exponential computation, bounded in size by
O(n2^{n}),
and so not feasible for large
n.
A detailed discussion of such computations is given in
[
10
, Section 6]
and
[
13
, Section 3]
. See also
[
15
, p. 222]
. With the ECC, we need only compute the decimals for the roots
\mu_{i}
with very high accuracy,
and this computation is
linear
in
n,
apart from logarithmic factors (see
[
10
, Section 6]
for details). Thus the ECC allows us to reduce an exponential computation in
n
to one that is essentially linear in
n.

Another way to very efficiently determine the values of
wt(f_{n})
is to find a
generating function

\text{gen}(f_{n})(x)
such that

\text{gen}(f_{n})(x)=\sum_{i=1}^{\infty}wt(f_{i})x^{i-1}

(7)

Here the values of
wt(f_{i})
for
i<n
can be obtained by extending the recursion for the weights
wt(f_{i})
backwards from
i=n,
as in Theorem
4
below.

It turns out that the generating functions
\text{gen}(f_{n})(x)
for quadratic RS functions
f_{n}=f(Q_{m})
are rational functions with integer coefficients, and these rational functions can be easily computed by using the ECC. Full explanations and examples are given in
[

]
. We give the generating function for the Example
3
function

here.

Example 4
.

For

\text{gen}(f_{n})(x)=\frac{56x^{6}-32x^{5}+8x^{4}-4x^{3}+4x^{2}-2x+1}{16x^{7}-8x^{6}-2x+1}

and the expansion of this rational function is

\text{gen}((1,4)_{n})(x)=1+4x^{2}+4x^{3}+16x^{4}+64x^{6}+112x^{7}+256x^{8}+480x^{9}\ldots

Computing the weights in Examples
2
and
3
confirms Conjecture
1
for those cases.
The idea goes back to
[
10
]
where a weaker version for degree
3
MRS functions only was proved. The special case of MRS quadratics was done in
[

.

Theorem 4
.

Let
w_{n}=wt((1,t)_{n})
for
n\geq 2t-1.
The recursion for the weights is

w_{n}=2w_{n-1}+2^{t-1}w_{n-2t+2}-2^{t}w_{n-2t+1},~n\geq 2t-1.

(8)

If we extend the recursion backwards from
n=2t-1
to
n=1
to define
w_{n}
for
n\leq 2t-1,
then

w_{n}=2^{n-1}-\frac{1}{2}(\alpha_{1}^{n}+\ldots+\alpha_{2^{t}}^{n}),~n=1,2,\ldots.

(9)

Here
\alpha_{1},\ldots,\alpha_{2^{t}}
is the list of the

irrational roots, counted with multiplicity, of the characteristic polynomial
c_{t}(x)
for the rules matrix
r((1,t)),
with the distinct roots

\alpha_{1},\ldots,\alpha_{2t}
of the polynomial
m_{t}(x)/(x-2)=x^{2t}-2^{t}
for

listed first. The remaining roots are various duplicates of the first
2t
roots.

Proof.

We already saw the minimal polynomial for this case in Lemma
4
; this gives (

). The full details of the proof of the theorem are in

[

, Theorems 4.4 and 4.5]
.
The condition

in (

n\geq 2t-1.
This is true because extending the recursion backwards gives
w_{2t-2}=0.
However, if we adopt the convention that the short functions
(1,t)_{2t-2}
are identically
0
(see Example

then (

w_{n}=wt(1,t)_{n}
for all

∎

Theorem

for the case

4
Special case of Easy Coefficients Conjecture

We shall prove the quadratic ECC in the special case where
m_{f}(x)=c_{f}(x)
in Theorem
3
. This case frequently occurs and is clearly equivalent to saying that
c_{f}(x)
has no multiple roots. The proof depends on a deep connection between the weights of
f(Q_{m})
and certain zeta functions,
as explained in
[
7
]
. We summarize the results from
[
7
]
that we need. These results are in fact true for
rotation symmetric functions of any degree, but in this paper we only need the degree
2
case.

Before proceeding with our work, we need some results from
[
4
,
6
,
7
]
. First, it is well known that quadratic Boolean functions are
plateaued

[
5
, p. 263]
: The weight of a quadratic Boolean function
f_{n}
is either
2^{n-1}
(balanced function) or is of the form
2^{n-1}\pm 2^{\frac{n+v(n)}{2}-1}
for some integer
v(n)
of the same parity as
n
. We use the notation
v_{f}(n)
if it is necessary to emphasize the dependence of
v(n)
on the function
f_{n}.

Using the results in
[
7
, Sections 3 and 4]
and the fact that the values of
v_{f}(n)
are periodic (how to compute the period length,
P(v_{f})
say,
is explained in
[
6
, Theorem 5.2]
and
[
8
, Proof, p. 95]
, but we do not need that information here), we can get even more complete results below.

Theorem 5
.

Given a quadratic function
f_{n}=f(Q_{m})
, there is a Galois-invariant multiset of algebraic
integers
\alpha_{i}
such that

|\alpha_{i}|=\sqrt{2},\ 1\leq i,~j\leq\max_{n}~2^{v(n)/2},

and

wt(f_{n})=2^{n-1}-\frac{\sum\alpha_{i}^{n}}{2}.

(10)

Furthermore, the order of the group generated by the roots of unity
\alpha_{i}/\sqrt{2}
is either the period
P(v_{f})
or
2P(v_{f})
.

Proof.

This is a version of
[
7
, Theorem 5.2]
.
∎

We find the size of the multiset in Theorem
5
in the next theorem, which gives the maximum value for
v_{f}(n).

Theorem 6
.

Given a quadratic function
f_{n}=f(Q_{m}),
let

Then
\max_{n}v_{f}(n)=2T,
so the multiset in Theorem

has size

Proof.

The proof of
\max_{n}v_{f}(n)=2T
(and more), in a different notation, is given in
[

, Theorem 5.2]
.
∎

We can now prove the special case of the quadratic ECC mentioned in the first paragraph of Section
4
. We call this
result the Easier Easy Coefficients Theorem (EECT).

Theorem 7
.

The Easier Easy Coefficients Theorem

For any quadratic RS Boolean function
f_{n}=\sum_{i=1}^{m}(1,t_{i})_{n}
let
T=\max~(t_{i}-1).
Then the method of
[
11
,
12
]
gives a rules matrix
r(f_{n})
of size
2^{T}+1
and a Rules matrix
R(f_{n})
of size
2^{T}
such that
(1/\sqrt{2})R(f_{n})
is orthogonal. Let the roots (which are distinct and nonzero) of the minimal polynomial
m_{f}(x)
of
r(f_{n})
be
2
and

\{\mu_{i}:1\leq i\leq 2^{T}\}.
Then the characteristic polynomial
c_{f}(x)
of
r(f_{n})
has the same roots and

wt(f_{n})=2^{n-1}-\sum_{i=1}^{2^{T}}\frac{1}{2}\mu_{i}^{n},~n=1,2,\ldots

(11)

The weights
wt(f_{n})
satisfy a linear recursion with integer coefficients of order
\deg m_{f}(x)=2^{T}+1.

Proof.

Theorem
3
guarantees that the weight recursion in the last sentence of the theorem exists. We know from Corollary
1
that

(1/\sqrt{2})R(f_{n})
is orthogonal, so the roots
\mu_{i}
of
m_{f}(x)/(x-2)
are distinct and nonzero, and all have absolute value
\sqrt{2}.
Now
Theorem
5
, (
10
) and Theorem
6
tell us that there is a Galois invariant multiset of algebraic integers
\alpha_{i}
with

|\alpha_{i}|=\sqrt{2},~1\leq i\leq 2^{T},
such that
wt(f_{n})
satisfies (
11
) with
\mu_{i}
replaced by
\alpha_{i}.

The theory of recursions says that the set of distinct algebraic integers
\mu_{i},~1\leq i\leq 2T
that gives the linear recursion of order
2^{T}+1
for

wt(f_{n})
is uniquely determined by the weights. Since the multiset of the
\alpha_{i}
has the same size
2^{T},
it must in fact be a set (
2^{T}
distinct elements).
Therefore the Galois invariant set of algebraic integers
\alpha_{i}
must be the same as the set of the
\mu_{i}
in (
11
).
This means there is a one-to-one correspondence between the sets made up of the
\alpha_{i}
and the
\mu_{i},
so the theorem is proved.
∎

The situation where the characteristic polynomial
c_{f}(x)
has multiple roots is more difficult, because then it is not true that the recursion polynomial
for the

recursion of order equal to the degree of the characteristic polynomial is unique. Here the roots
\mu_{i}
of

are a multiset
and new ideas are needed to connect that multiset with the

in Theorem

5
Topics for further research

Many computations confirm that the Easy Coefficients Conjecture (as stated in
[
13
, Conjecture 1]
) is true for RS functions of any degree. The
computation of the weights via generating functions (
7
) can be done just as in the quadratic case, but for degrees
>2
there is no nice formula
for the generating functions like the one in
[
13
, Theorem 2]
.

The proof of the Easy Coefficients Conjecture for degrees larger than
2
will require new ideas, since the higher degree cases are more complicated. For example, we know from Lemma
3
that for a quadratic function
f_{n}=f(Q_{m})
the rules matrix has size
2^{T}+1
and (although the minimal polynomial can have degree
<2^{T}+1
) the characteristic polynomial always has degree
2^{T}+1,
and has no zero roots. The rules matrix is always nonsingular (that is, has nonzero determinant).

The situation for higher degrees is very different. Using notation

(1,c(1),c(2),\ldots,c(d-1))

for the MRS function generated by the monomial
x_{1}x_{c(1)}\ldots x_{c(d-1)},
the RS function
(1,2,5)+(1,5)
has rules matrix of size
17,
minimal polynomial of degree
12
with
8
nonzero roots and characteristic polynomial of degree
17
with
8
nonzero roots. Thus the rules matrix has determinant zero and its characteristic polynomial has
9
zero roots. Also, the absolute values of the nonzero roots
\neq 2
in the minimal polynomial are not the same. Despite these differences, the ECC is always true for the many examples we have done. It is also the case that rapid computation of generating functions for the weights, as in Example
4
, is possible for all of the many cases we checked.

At least for degree
3,
it is possible for different sequences of functions to have the same weight recursion and the same sequence of weights, tho the functions are sometimes not affine equivalent. This happens for the functions
(1,2,4)_{n}
and
(1,2,5)_{n},
for example. It turns out that the minimal polynomial for
(1,2,5)_{n}
is
x^{4}
times the minimal polynomial for
(1,2,4)_{n}.
The functions
(1,2,4)_{7}
and
(1,2,5)_{7}
are not affine equivalent since they have different distributions of the Walsh transforms (
2
).

Appendix–Computing a quadratic rules matrix

We start with a quadratic RS function
f(Q_{m})=f(x),
say. We need some preliminary definitions. Though all of our definitions apply for any ordering of the functions in
Q_{m}
(see (
4
)), it is convenient to assume

t_{1}>t_{2}>\ldots>t_{m}

(12)

because this gives the rules matrix in a desirable form. More details about this are in Theorem
2
above.

We first compute the expanded rules matrix described in Lemma
3
. Define a sequence
y_{k},~0\leq k\leq m
by

y_{0}=0,y_{k}=\sum_{i=1}^{k}(t_{m-i+1}-1).

Define

X=\{2^{y_{k}-1}:~1\leq k\leq m\}=\{x_{i}:~1\leq i\leq m\}.

Define a function
F:\{subsets~of~X\}\rightarrow\mathbb{R},
which maps a subset
u
of
X
to the sum of its elements, by

F(u)=\sum x_{i}~\text{for all}~x_{i}\in u.

Given a positive integer
b=\sum_{i=0}^{B}g_{b}(k)2^{k}
in base
2,
define its
k
-th bit, using
k=0,1,...,B,
counting from the right, by

g_{b}(k)=\left[{\frac{b}{2^{k}}}\right]-2\left[{\frac{b}{2^{k+1}}}\right].

Define

S=\{F(u):~u\in P(X)\}=F[P(X)],

where
P(X)
is the power set of all subsets of
X.

Example 5
.

Take
m=3
and
Q_{3}=\{(1,4),(1,3),(1,2)\}.
Then
t_{1}=4,t_{2}=3,t_{3}=2
and the sequence

\{y_{0},y_{1},y_{2},y_{3}\}
is
\{0,t_{3}-1,t_{3}+t_{2}-2,t_{3}+t_{2}+t_{1}-3\}=\{0,1,3,6\}.
Set
X
is

\{1,4,32\}
and set
S
is
\{0,1,4,5,32,33,36,37\}.

Next we build the expanded rules matrix. Let the entries in the expanded matrix of size
2^{y_{m}}+1
be denoted by
e_{i,j}
where

0\leq i,~j\leq 2^{y_{m}}.
Then the matrix entries are defined as follows for
i,j<2^{y_{m}}:

e_{i,j}=1~\text{if}~g_{i}(y_{0})=\ldots=g_{i}(y_{m-1})=0~\text{and}~j=\left[{\frac{i}{2}}\right]+s~\text{for~some}~s\in S

(13)

e_{i,j}=1~\text{if~all}~g_{i}(y_{k})=1~\text{and}~j=\left[{\frac{i}{2}}\right]-f(x)~\text{for~some}~f(x)\in S,~|x|~\text{even}

(14)

e_{i,j}=-1~\text{if~all}~g_{i}(y_{k})=1~\text{and}~j=\left[{\frac{i}{2}}\right]-f(x)~\text{for~some}~f(x)\in S~|x|~\text{odd}

(15)

For the last row,
e_{2^{y_{m}},j}=1
if (
15
) holds and otherwise
e_{2^{y_{m}},j}=0.
For the last column, all entries are
0
except
e_{2^{y_{m}},2^{y_{m}}}=2.
This is the result of the fact that the minimal and characteristic polynomials of the expanded matrix have one
integer root
2
(see Example
1
).

The expanded rules matrix is then reduced in size by repeatedly deleting row
i
and column
i,
where row
i
is a zero row, so that the output matrix and expanded rules matrix have the same characteristic and minimal polynomials. This process is continued until all zero rows are removed, and that final matrix is the rules matrix. The Rules matrix is the rules matrix with the last row and last column removed.

It is important to keep in mind (as stated in Remark
1
) that the program places exactly two numbers (each is either
1
or
-1
)
in every row and column of the Rules matrix, and all other entries in the Rules matrix are zero, so the rules matrix is very sparse.
