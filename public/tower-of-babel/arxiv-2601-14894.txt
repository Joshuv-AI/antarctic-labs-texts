To Neuro-Symbolic Classification and Beyond by Compiling Description Logic Ontologies to Probabilistic Circuits
Nicolas Lazzari, Valentina Presutti, Antonio Vergari

Abstract
Background: Neuro-symbolic methods enhance the reliability of neural network classifiers through logical constraints, but they lack native support for ontologies. Objectives: We aim to develop a neuro-symbolic method that reliably outputs predictions consistent with a Description Logic ontology that formalizes domain-specific knowledge. Methods: We encode a Description Logic ontology as a circuit, a feed-forward differentiable computational graph that supports tractable execution of queries and transformations. We show that the circuit can be used to (i) generate synthetic datasets that capture the semantics of the ontology; (ii) efficiently perform deductive reasoning on a GPU; (iii) implement neuro-symbolic models whose predictions are approximately or provably consistent with the knowledge defined in the ontology. Results: We show that the synthetic dataset generated using the circuit qualitatively captures the semantics of the ontology while being challenging for Machine Learning classifiers, including neural networks. Moreover, we show that compiling the ontology into a circuit is a promising approach for scalable deductive reasoning, with runtimes up to three orders of magnitude faster than available reasoners. Finally, we show that our neuro-symbolic classifiers reliably produce consistent predictions when compared to neural network baselines, maintaining competitive performances or even outperforming them. Conclusions: By compiling Description Logic ontologies into circuits, we obtain a tighter integration between the Deep Learning and Knowledge Representation fields. We show that a single circuit representation can be used to tackle different challenging tasks closely related to real-world applications.

Suppose that we want to design a model for automated information extraction in a domain-specific setting. For instance, we are interested in automatically detecting the creative influence between different artists from a biographical document containing the sentence

2
Tractable DL circuits

We aim at designing a reliable NeSy model that combines a neural network model with an ontology encoding domain-specific knowledge. To do so, we need a practical computational approach to detect whether the predictions of the neural network are consistent with the ontology. Moreover, to achieve a seamless integration between the model and the ontology during the training phase, we need this approach to be fully differentiable with respect to the neural network’s inputs.

In this section, we show that compiling an ontology into a circuit achieves all our computational desiderata and, in addition, enables other useful applications beyond NeSy models, thanks to the circuit’s properties.

Throughout the rest of the paper, we will refer to the same example scenario of automatically extracting the artistic influences of an artist.

For the sake of concreteness, we assume we have access to a corpus of artists’ biographies extracted from Wikipedia. For each entity mentioned in the corpus, we have some background knowledge available extracted from Wikidata, a humanly curated Knowledge Graph based on Wikipedia. We frame the problem as a link prediction task where we want to design a neural network model that predicts whether one artist has been influential to another artist, such as between
Fugazi
and
The Smiths
in the sentence Example
1

For simplicity, we assume we can only observe two types of mutually disjoint entities in the corpus: artists (e.g.,
Fugazi
and

) and music labels (e.g.,
Dischord Records
). Artists can be signed to music labels, but can only be influenced by other artists. This simple set of constraints represents our background knowledge and acts as an

definition of the domain, represented in the form of an ontology
\mathcal{O}

[

Definition 2.1
(Circuit
[
24
,
132
]
)

A circuit
c
is a parameterized directed acyclic computational graph over variables
\mathbf{X}
encoding a function
c(\mathbf{X})
, and comprising three kinds of
computational units: input, product, and sum units. Each product or sum unit
n
receives the outputs
of other units as inputs, denoted with the set
\mathsf{in}(n)
. Each unit
n
encodes a function
c_{n}
defined as: (i)
f_{n}(\mathsf{sc}(n))
if
n
is an input unit, where
f_{n}
is a function over variables
\mathsf{sc}(n)\subseteq\mathbf{X}
, called its scope, (ii)
\prod_{j\in\mathsf{in}(n)}c_{j}(\mathsf{sc}(j))
if
n
is a product unit, and (iii)
\sum_{j\in\mathsf{in}(n)}w_{j}c_{j}(\mathsf{sc}(j))
if
n
is a sum unit, with
w\in\mathbb{R}
denoting the weighted sum parameters.

Figure
2
shows a graphical representation of the circuit
\mathcal{C}_{\mathcal{O}}
compiled using the method described in Section
5
, where inputs are ordered before outputs from left to right. Informally, each input to the circuit refers to a part of the ontology
\mathcal{O}
, such as the different concepts and roles defined and the relationships between them. A detailed description is provided in Section
5
.
By imposing different properties on the structure of a circuit, it is possible to guarantee tractable execution of complex queries and transformations
[
24
,
132
,
28
]
. In this paper, we rely on three main properties: smoothness, decomposability, and determinism.

Definition 2.2
(Smoothness, decomposability, determinsm
[
24
,
132
,
27
]
)

A circuit
c
is smooth if for every sum unit
n
, its input units depend all on the same variables, i.e.,
\forall i,j\in\mathsf{in}(n):\mathsf{sc}(i)=\mathsf{sc}(j)
. A circuit
c
is decomposable if the inputs of every product unit
n
depend on disjoint sets of variables, i.e.,
\forall i,j\in\mathsf{in}(n),i\neq j:\mathsf{sc}(i)\cap\mathsf{sc}(j)=\emptyset
. A circuit
c
is deterministic if for every sum unit
n
, its inputs have disjoint supports, i.e.,
\forall i,j\in\mathsf{in}(n),i\neq j:\mathsf{supp}(i)\cap\mathsf{supp}(j)=\emptyset
. The support of a sum unit
n
is the set of assignments to its scope such that the output of
n
is non-zero, i.e.,
\mathsf{supp}(n)=\{x\in\mathsf{val}(\mathbf{X})\ |\ n(x)\neq 0\}
.

Smooth and decomposable circuits support tractable marginalization i.e., , it is possible to
ignore
some variables when evaluating the encoded function, which is a fundamental requirement for modeling complex probability distributions
[
108
,
106
]
that is generally hard
[
15
]
. Similarly, they support complex information-theoretical queries, such as the similarity between two probability distributions through their KL-divergence
[
132
]
. Similarly, decomposable and deterministic circuits support boolean
[
27
]
and probabilistic
[
21
,
29
]
reasoning as well as complex queries that are traditionally intractable, such as Maximum A Posteriori (MAP)
[
24
,
29
]
.
These structural properties are usually enforced by carefully designing the circuit construction phase
[
108
,
32
,
46
,
107
,
82
]
or by using knowledge compilation techniques
[
27
,
72
,
25
]
. The circuit of Figure
2
, obtained through knowledge compilation, is smooth, decomposable, and deterministic.

Alongside their properties, one key aspect of circuits is their computational graph nature, which benefits from a clear feed-forward semantics. This can be seen from the circuit in Figure

3.1
Description Logic

Description Logics (DL) are formal languages used to define, manipulate, and reason about domain-specific knowledge. A DL knowledge base
\mathcal{KB}
is defined as the combination of
terminological
and
assertional
knowledge. The terminological knowledge establishes the domain-specific vocabulary by defining a set of concepts
\mathbf{C}
, a set of roles (binary relations)
\mathbf{R}
between the concepts
\mathbf{C}
, and complex descriptions obtained by combining concepts and roles through different constructs. Assertional knowledge instantiates named individuals and their relations using the concepts
\mathbf{C}
, relations
\mathbf{R}
, and complex combinations of them
[
4
]
. In literature, terminological knowledge is notated as
TBox
and assertional knowledge as
ABox
. In this paper, we refer to them as, respectively, ontology
\mathcal{O}
and Knowledge Graph
\mathcal{KG}
.

For example,
\mathsf{Artist}\in\mathbf{C}
and
\mathsf{influence}\in\mathbf{R}
are
statements
(or
axioms
) in
\mathcal{O}
, while
\mathsf{Artist}(\textit{Fugazi})
and
\mathsf{signedTo}(\textit{Fugazi},\textit{Dischord Records})
are
assertions
contained in
\mathcal{KG}
. Assertions can be created manually or automatically, such as by using the link prediction model hypothesized in Section
2
with
\mathsf{influence}(\textit{Fugazi},\textit{The Smiths})
represented in green in Figure
2
.
Complex concept descriptions are obtained by combining concepts
\mathbf{C}
and roles
\mathbf{R}
using
concept constructors
, e.g., boolean connectives, such as defining the set of individuals that is
not
an artist, but does not have to be a music label.

Different choices of concept constructors identify different DL
fragments
. Each fragment exhibits a different tradeoff between expressivity and computational complexity in automated reasoning tasks. For example, the
\mathcal{SROIQ}
fragment, underpinning OWL ontologies
5
5

5

https://www.w3.org/TR/owl2-profiles/
, is a decidable subset of First Order Logic with
NExpTime-hard
complexity. Less expressive but more tractable fragments have been proposed in literature by carefully selecting and analyzing concept constructors
6
6

6

See
http://www.cs.man.ac.uk/~ezolin/dl/
for an extensive review of DL fragments and their complexity.
such as
\mathcal{ALC}

[
114
]
,
\mathcal{EL}

[
5
]
, or DL-lite
[
20
]
.
The
\mathcal{ALC}{}
fragment is often considered the

3.1.3
Reasoning

Formally, an interpretation
\mathcal{I}
is consistent with a
\mathcal{KB}
if
\mathcal{I}

satisfies
the concept
C
, written
\mathcal{I}\models C
, for all
C\in\mathbf{C}
. We say that
\mathcal{I}\models C
if
C^{\mathcal{I}}
is not empty. A
\mathcal{KB}
is consistent if all of its concepts are consistent for any interpretation
\mathcal{I}
.
Consistency is central to automated reasoning since most of the interesting queries on
\mathcal{KB}
(e.g., classification, subsumption test) can be reduced to consistency checking
[
4
]
. In other words, an efficient algorithm for consistency checking enables a multitude of efficient automated reasoning tasks. Moreover, the complexity of DL fragments is measured as the complexity of the algorithm used to perform consistency checking.

Depending on the fragment at hand, different algorithms have been proposed in literature. The most common approaches are based on the tableau algorithm or its variations, which frame the consistency decision problem as a search algorithm. Statements and assertions of
\mathcal{KB}
are iteratively processed until an inconsistency is generated. If the procedure ends without conflicts,
\mathcal{KB}
is satisfiable. Popular DL reasoners such as Pellet
[
118
]
, HermiT
[
49
]
, and Konclude
[
123
]
rely on carefully designed heuristics to efficiently explore the huge search space. Other approaches include leveraging the structural properties of specific fragments
[
70
,
3
]
or reducing DL reasoning to other logic languages
[
39
,
67
,
84
,
53
,
42
]
.

Related works

Different approaches have been proposed in recent years to combine DL ontologies with neural networks. These mainly follow two lines of research: deep deductive reasoners

]
and ontology embeddings

Deep Deductive Reasoners

Deep deductive reasoners approximate deductive reasoning using neural networks by learning a representation of an ontology and its elements to derive sound and meaningful conclusions
[

[

,
10
]

Ontology Embeddings

Ontology embeddings, on the other hand, compute vectorial representations of the elements of
\mathcal{O}
that can be specialized for additional tasks beyond deductive reasoning, such as classification or ontology alignment
[

]

[

]

is used to synthesize sentences from the ontology that are then embedded as vectors

[

or to influence the training process of general KG embedding methods

Knowledge compilation and circuits in the DL landscape

While our approach might seem similar to the ones described here, it fundamentally differs in its spirit. Deep deductive reasoners and ontology embeddings learn and/or apply (possibly latent) inference rules to derive conclusions using vectorial representations instead of symbolic ones. The circuit

and
\mathcal{B}

Given an interpretation

of
\mathcal{I}

\mathcal{C}
is the set that contains the triple
\langle\mathcal{A},\mathcal{R},\mathcal{B}\rangle
such that

\mathcal{A}=\{C\in\mathcal{C}\mid\delta_{1}\in C^{\mathcal{I}}\}\quad\mathcal{R}=\{R\in\mathbf{R}\mid(\delta_{1},\delta_{2})\in R^{\mathcal{I}}\}\quad\mathcal{B}=\{C\in\mathcal{C}\mid\delta_{2}\in C^{\mathcal{I}}\}

for all
\delta_{1},\delta_{2}\in\Delta^{\mathcal{I}}
,
\mathcal{A},\mathcal{B}\subseteq\mathcal{C}
and
\mathcal{R}\subseteq\mathbf{R}

In other words, the domino projection of
\mathcal{I}
w.r.t.
\mathcal{C}
encodes which roles between two individuals
\delta_{1}
and
\delta_{2}
are consistent w.r.t.
\mathcal{O}
if
\delta_{1}
and
\delta_{2}
are classified by the elements of
\mathcal{A}
and
\mathcal{B}

\mathcal{I}

\mathcal{I}

\mathcal{C}
is chosen to be the set of

\mathcal{O}

\mathcal{O}
is either an atomic concept or a role restriction on an atomic concept.
112

\mathcal{ALCI}

For example, the parts of the
\mathcal{KB}
of Figure

\displaystyle\mathsf{parts}(\mathcal{KB})=\{\mathsf{Artist},\mathsf{Label},\forall\mathsf{influence}.\mathsf{Artist},\forall\mathsf{influence}^{-}.\mathsf{Artist},\forall\mathsf{signedTo}.\mathsf{Label},\forall\mathsf{signedTo}^{-}.\mathsf{Artist}\}

1.

Normalize
\mathcal{O}
to Negative Normal Form (NNF);

2.

Compile a boolean formula encoding normalized
\mathcal{O}
into a tractable circuit.

The NNF normalization phase leverages syntactic and semantic equivalences to rewrite
\mathcal{O}
so that negation only appears before an atomic concept. Suppose for example, that we have a statement describing Punk artists as artists that can not be influenced by neither Pop nor Classical artists. The statement and its equivalent NNF translation is

\mathsf{Punk}\sqsubseteq\forall\mathsf{influence}^{-1}.\lnot(\mathsf{Pop}\sqcup\mathsf{Classical})\quad\underset{\textit{NNF}}{\longrightarrow}\quad\mathsf{Punk}\sqsubseteq\forall\mathsf{influence}^{-1}.(\lnot\mathsf{Pop}\sqcap\lnot\mathsf{Classical})

Additionally,
\mathcal{O}
is
flattened
by rewriting existential and universal restrictions so that they are only asserted on atomic concepts. For example, the previous NNF axiom is replaced by

\displaystyle\mathsf{Punk}\sqsubseteq\forall\mathsf{influence}^{-1}.X\quad\top\sqsubseteq\lnot X\sqcup(\lnot\mathsf{Pop}\sqcap\lnot\mathsf{Classical})

where
X
is a fresh concept name. From here on, we assume that
\mathcal{O}
has been normalized to NNF and flattened if not explicitly stated.

The boolean formula that is compiled to
\mathcal{C}_{\mathcal{O}}
is defined on the set of variables
\mathbf{Vars}=\{v_{X}:X\in\mathbf{R}\cup(\mathsf{parts}(\mathcal{O})\times\{1,2\})
where

is a fresh variable that refers to
X
. Intuitively,
\mathbf{Vars}
contains one variable for each element that could be in the sets
\mathcal{A}
,
\mathcal{B}
(e.g.,
(\mathsf{Artist},1)
and
(\mathsf{Artist},2)

\mathcal{R}
of a domino
\langle\mathcal{A},\mathcal{R},\mathcal{B}\rangle

This can also be seen in Figure

Experiments

In this section, we experiment with the different applications offered by
\mathcal{C}_{\mathcal{O}}
as introduced in Section
2
. In Section

, we experiment with synthetic data generation using the circuit
\mathcal{C}_{\mathcal{O}}
(

can be harnessed to generate structured synthetic data that encapsulates the knowledge defined in
\mathcal{O}

\mathcal{ALCI}

by sampling from

\mathcal{D}

and quantitatively evaluate the complexity of the synthesized data. In Section

as a deductive reasoner and compare its results with other search-based DL reasoners (

(

Training and testing models using synthetic data is a widespread technique in Machine Learning

6.1.2
Knowledge Graph generation

In this section, we show that the circuit
\mathcal{C}_{\mathcal{O}}
can be used to generate a Knowledge Graph
\mathcal{KG}
based on the knowledge defined in the ontology
\mathcal{O}
.

Consider a sample
\mathbf{s}
drawn from
\mathcal{C}_{\mathcal{O}}
i.e.,
\mathbf{s}\sim\mathcal{C}_{\mathcal{O}}
, where the input units of
\mathcal{C}_{\mathcal{O}}
are parameterized using indicator functions and the weights of sum units are initialized to one. Since the circuit encodes the canonical domino set
\mathbb{D}_{\mathcal{O}}
,
\mathbf{s}
corresponds to the encoding of some domino
\langle\mathcal{A},\mathcal{R},\mathcal{B}\rangle\in\mathbb{D}_{\mathcal{O}}
such that
\llbracket\langle\mathcal{A},\mathcal{R},\mathcal{B}\rangle\rrbracket=\mathbf{s}
, where
\mathcal{A}
and
\mathcal{B}
refer to some individuals
a,b
by definition of domino. Moreover, due to the characteristic boolean function
\llbracket\cdot\rrbracket
defined in Equation (
16
), the vector
\mathbf{s}
can be seen as the concatenation operation
\mathbf{s}=[\mathbf{a};\mathbf{r};\mathbf{b}]
where
\mathbf{a}
(resp.
\mathbf{b}
) is a boolean vector representing the knowledge encoded in
\mathcal{A}
about
a
(resp.
\mathcal{B}
and
b
) and
\mathbf{r}
encodes the roles asserted between
a
and
b
as specified in
\mathcal{R}
.

In other words, sampling from
\mathcal{C}_{\mathcal{O}}
means sampling two random individuals and some relationships that hold between them in some interpretation of
\mathcal{O}
. Clearly, the knowledge about both individuals (how they are classified) and their relations must be consistent with
\mathcal{O}
by definition.

By naively sampling from
\mathcal{C}_{\mathcal{O}}
we assume that all the sampled individuals are different, due to the unique name assumption of DL. This produces a sparse
\mathcal{KG}
where we only have pairwise relationships between entities. For example, in
\mathcal{KG}
from Figure
2
, we would have that at most one artist is signed to each label. While this might be a desirable outcome in some settings, it defies the main purpose of Knowledge Graphs: to represent if and how different entities are related together
[
62
]
.

To overcome this limitation, we first sample a set of individuals
\mathcal{E}
from the circuit
\mathcal{C}_{\mathcal{O}}
and then sample the relation holding between all their pairwise combinations.
The set of individuals
\mathcal{E}
can be sampled from
\mathcal{C}_{\mathcal{O}}
by sampling one boolean vector
\mathbf{e}_{i}
for each
\varepsilon_{i}\in\mathcal{E}
, where
\mathbf{e}_{i}
represents the knowledge encoded in some
\mathcal{A}
of some domino
\langle\mathcal{A},\mathcal{R},\mathcal{B}\rangle\in\mathbb{D}_{\mathcal{O}}
.

Since we are only interested in the encoding of
\mathcal{A}
, we can avoid sampling the vectors related to
\mathcal{R}
and
\mathcal{B}
. This corresponds to drawing samples from the circuit obtained by marginalizing the variables related to
\mathcal{R}
and
\mathcal{B}
, which can be performed tractably in
\mathcal{C}_{\mathcal{O}}
since it is decomposable
[
24
,
132
]
.
Formally, we obtain
\mathbf{e}_{i}
as

\mathbf{e}_{i}\sim\sum_{R\in\mathbf{R}}\sum_{C\in\mathbf{C}}\mathcal{C}_{\mathcal{O}}([\llbracket R\rrbracket;\llbracket C,2\rrbracket])

where the two sums over
\mathbf{R}
and
\mathbf{C}
are effectively marginalizing some variables of
\mathcal{C}_{\mathcal{O}}
.

Similarly, we identify the relations between each combination of individuals
\mathbf{e}_{1},\mathbf{e}_{2}\in\mathcal{E}
by using them as evidence when sampling from
\mathcal{C}_{\mathcal{O}}
. Sampling with evidence is also tractable on smooth and decomposable circuits such as SDDs
[
24
]
. The collection of all samples drawn using all combinations of individuals produces the final
\mathcal{KG}
. Formally, we have that
\mathcal{KG}
is the set of vectors
\mathbf{a}_{ij}
such that
\mathbf{a}_{ij}\sim\mathcal{C}_{\mathcal{O}}([\mathbf{e_{i}};\mathbf{e_{j}}])
for all
\mathbf{e}_{i},\mathbf{e}_{j}\in\mathcal{E}
with
i\leq j
. Notice that we also sample roles between an individual and itself in case
\mathcal{O}
models reflexive relations.

6.1.3
Synthesizing a dataset

Given the generated
\mathcal{O}
and
\mathcal{KG}
as proposed before, we can construct a synthetic dataset
\mathcal{D}
as initially described in Section
2
. Informally,
\mathcal{D}
contains
observations
of the knowledge defined in a Knowledge Base
\mathcal{KB}
i.e., its samples are shaped as information that could be observed in the real world, such as images or text.

For instance, the sentence of example
1
is an observation of (some) of the knowledge of
\mathcal{KB}
in Figure
2
. Observations contain latent information that is embedded in the semantics of their modality. For example, there is no direct mention of
The Smiths
and
Fugazi
being artists. This information is implied by common-sense knowledge instead. In this case, the ontology
\mathcal{O}
acts as an explicit formalization of this latent common-sense knowledge. Clearly, an observation is a very general concept that spans any arbitrary modality, from images to embeddings produced by a pre-trained language model.

In this section, we propose a method that leverages the boolean vectors sampled from the circuit to synthesize the dataset of observations
\mathcal{D}
from a
\mathcal{KB}
generated in Section
6.1
.

Recall that
\mathcal{E}
refers to the individuals of
\mathcal{KG}
and for each
\varepsilon_{i}\in\mathcal{E}
we have a corresponding boolean vector representation
\mathbf{e}_{i}
that we sampled from (marginalized)
\mathcal{C}_{\mathcal{O}}
.

We define the generative model
\mathcal{G}^{\mathcal{E}}_{i}
which takes as input the vector
\mathbf{e}_{i}
and outputs an observation of
\varepsilon_{i}
in the form of an n-dimensional vector
\mathbf{o}_{i}\in\mathbb{R}^{n}
. In this work, we choose
\mathcal{G}^{\mathcal{E}}_{i}
to be a multivariate normal distribution and use the vector
\mathbf{e}_{i}
as its mean and a covariance
\Sigma_{i}
i.e.,
\mathcal{G}^{\mathcal{E}}_{i}=\mathcal{N}(\mathbf{e}_{i},\Sigma_{i})
. In other words, for each individual, we define a normal distribution whose mean is its intensional description encoded as defined in Section
5
. Different individuals with the same intensional description will have different generative models through the use of different covariance matrices. It follows that each observation from the same individual will be generated from the same distribution, but will still display some superficial variability due to the covariance matrix. Moreover, samples that have a similar intensional description will have a more similar generating distribution. This allows observations with similar intensional descriptions to be represented with vectors that can be clustered together in principle.

Similarly, we define one generative model
\mathcal{G}^{\mathbf{R}}
for each possible combination of roles. In other words, we have a generative model
\mathcal{G}^{\mathbf{R}}_{K}
for each
K\in 2^{\mathbf{R}}
. As done for individuals, we define
\mathcal{G}^{\mathbf{R}}_{K}
as a multivariate normal distribution, i.e.,
\mathcal{G}^{\mathbf{R}}_{K}=\mathcal{N}(\mathbf{v}_{K},\Sigma_{K})
where
\mathbf{v}_{K}
is a
|\mathbf{R}|
-dimensional boolean vector representing a multi-hot encoding of the combination
K
.

We can now synthesize the sample
\mathcal{D}^{(i)}\in\mathcal{D}
as

\mathcal{D}^{(i)}=[\mathbf{s}\sim\mathcal{G}^{\mathcal{E}}_{i};\ \mathbf{r}_{ij}\sim\mathcal{G}^{\mathbf{R}}_{ij};\ \mathbf{o}\sim\mathcal{G}^{\mathcal{E}}_{j}]

(17)

for some individuals
\varepsilon_{i},\varepsilon_{j}\in\mathcal{E}
where
\mathbf{r}_{ij}
is the multi-hot encoding of the relations between them.

The dataset
\mathcal{D}
is a collection of
n

n=|\mathbf{C}|+|\mathbf{R}|+|\mathbf{C}|
.

Both choices, however, still partition the space into different distinguishable sections, making geometrical distance a reliable predictor of similarity between observations.

On the other hand, sampling the covariance matrix from a Wishart distribution produces observations where the distance is not a strong predictor of the similarity between observations, while sampling from the inverse Wishart distribution produces observations where clusters are highly separated.

All of those aspects influence the complexity of the dataset when used for training Machine Learning models. In Table
2
, we test different popular ML models and report their accuracy in predicting the observations’ concept. For each individual, we train on
80\%
of its observations and test on the remaining
20\%
. The classification task is a regular multiclass classification problem, since all concepts are mutually disjoint. Table
2
confirms the qualitative findings of Figure
5
. Observations generated using the inverse Wishart distribution, for example, are easier to classify when compared to observations generated using the identity matrix due to being more highly clustered.

6.2
Deductive reasoning

The driving motivation of the different Description Logic fragments is to reduce the expressivity of First Order Logic languages so that decidable automated reasoning algorithms can be defined while maintaining a language expressive enough to model domain-specific knowledge
[
4
,
128
]
.
The time complexity of reasoning in most Description Logic fragments, however, is often exponential in the size of the ontology. This is a strong limit on the applicability of
textbook
algorithms, particularly in real-world scenarios where one is interested in working with a large amount of data. In practice, this has been addressed by proposing search algorithms for which clever heuristics and optimizations can be used to obtain efficient implementations
[
7
]
. A compilation-based approach aims at addressing this issue from a different angle. The exponential blow-up of the search space is encoded in a succinct representation using expensive knowledge compilation techniques. This is then amortized by the ability to execute different complex queries efficiently in the circuit.

Of course, the efficiency of compilation-based approaches is also dependent on the implementation of the circuit. The computational nature of circuits, however, allows the use of modern GPU-based parallel computations
[
88
,
105
,
82
,
79
]
that benefit from recent software and hardware advancements in the field. Informally, it is possible to evaluate multiple assignments at the same time by representing a state assignment as a vector and relying on parallelized implementations of sums and products on GPUs to evaluate multiple assignments at the same time.

6.3
Reliable NeSy classification

In this Section, we show that the circuit
\mathcal{C}_{\mathcal{O}}
can be used for effective and reliable multilabel NeSy classification by experimenting with Semantic Losses (SL)
[
136
]
and Semantic Probabilistic Layers (SPL)
[
2
]
.
Both approaches compile user-defined constraints as circuits using knowledge compilation techniques and integrate them within a neural network, leveraging the differentiability of circuits. We will first describe those methods and later report on the results of our experiments.

SL and SPL background

To describe both the SL and SPL approaches, we consider a multilabel classification problem where we have an input
\mathbf{x}
that has been labeled by an
L
-dimensional boolean vector
\mathbf{\hat{y}}\in\{0,1\}^{L}
, with
L
the number of classes.

Similarly to
2
, we observe that any neural network classifier can be abstracted as the combination of a feature extraction function
\mathsf{nn}
that produces an
n
-dimensional feature vector
\mathbf{z}=\mathsf{nn}(\mathbf{x})
from
\mathbf{x}
and a classification function that predicts the probability distribution
p(\mathbf{y}|\mathbf{z})
.

In a general setting,
\mathsf{nn}
is trained to optimize a discriminative loss, such as minimizing the cross-entropy loss
\mathcal{L}_{CE}(\mathbf{\hat{y}},\mathbf{z)}
, where the different
L
classes are assumed to be independent. In practice, we have that
p(\mathbf{y}|\mathbf{z})
is implemented as

p(\mathbf{y}|\mathbf{z})=\prod_{i=0}^{L}p(\mathbf{y}_{i}=1|\mathbf{z})\quad\quad p(\mathbf{y}_{i}=1|\mathbf{z})=\sigma(\mathbf{w}^{T}\mathbf{z)}

(18)

with
\mathbf{w}\in\mathbb{R}^{L}
a parameter vector of the classification function and
\sigma(x)=1/(1+e^{-x})
the logistic sigmoid activation function.

The SL approach integrates the user constraints by updating the loss function
\mathcal{L}
to

\mathcal{L}=\mathcal{L}_{CE}(\mathbf{\hat{y}},\mathbf{z)}+\lambda\mathcal{L}_{SL}(\mathbf{z})\quad\quad\mathcal{L}_{SL}(\mathbf{z})=\sum_{\mathbf{y}^{*}\in\{0,1\}^{L}}p(\mathbf{y}^{*}|\mathbf{z})\mathcal{C}_{\mathcal{O}}(\mathbf{y}^{*})

(19)

where
\mathcal{L}_{SL}(\mathbf{z})
is the Semantic Loss term and
\lambda
is a parameter used to regulate its importance.
The SL terms relies on the circuit
\mathcal{C}_{\mathcal{O}}
parameterized as done in Section
3.1.3
(indicator function for input units and unitary weights for sum units) and computes the Weighted Model Count (WMC) with respect to the models of
\mathcal{O}
, which is tractable for smooth, decomposable and deterministic circuits
[
21
]
.

In a nutshell, the SL enumerates all the consistent assignments of
\mathcal{C}_{\mathcal{O}}
and weights them according to the belief predicted by the neural network. Since the support
\mathsf{supp}(\mathcal{C}_{\mathcal{O}})
matches the models of
\mathcal{O}
, the probability mass that
\mathsf{nn}
places on inconsistent assignments is discarded. By maximizing
\mathcal{L}_{SL}
, one seeks to instruct
\mathsf{nn}
to place more probability mass on consistent assignments. This interpretation suggests that higher values of
\lambda
lead to an optimization procedure that focuses more on predicting consistent assignments, which might disadvantage the optimization of
\mathcal{L}_{CE}
. The SL is hence treated as a regularization term, where the parameter
\lambda
is a hyper-parameter to optimize based on the downstream performances
[
136
]
. Note that this can be useful in settings where the knowledge represented in
\mathcal{O}
is noisy and therefore one wishes to enforce
soft-constraints
on the model, by relying on small values of
\lambda
.

Different from SL, a Semantic Probabilistic Layer
[
2
]
directly relies on the circuit
\mathcal{C}_{\mathcal{O}}
to implement the probability distribution
p(\mathbf{y}|\mathbf{z})
. Intuitively, since the support of
\mathcal{C}_{\mathcal{O}}
encodes the set of dominoes that are consistent with
\mathcal{O}
by definition,
2
proposes to optimize
\mathsf{nn}
so that it outputs a parameterization of
\mathcal{C}_{\mathcal{O}}
such that its most probable state is
\mathbf{\hat{y}}
.

Formally, an SPL computes
p(\mathbf{y}|\mathbf{z})
as

p(\mathbf{y}|\mathbf{z})=\mathcal{C}_{\mathcal{O}}(\mathbf{y};\mathbf{\Omega}=g(\mathbf{z}))

(20)

where
\mathbf{\Omega}
is the set of parameters of the sum units of
\mathcal{C}_{\mathcal{O}}
and
g
is called a gating function
[
115
]
, which takes as input the feature vector
\mathbf{z}
and outputs a set of parameters
\mathbf{\Omega}
. The gating function can be implemented using any arbitrary function, including the identity function or training a specific neural network model. Note that for
\mathcal{C}_{\mathcal{O}}(\mathbf{y};\mathbf{\Omega}=g(\mathbf{z}))
to represent a valid probability distribution, the parameters of each sum unit must be non-negative and sum up to one
[
106
]
, which can be done by relying on a softmax activation for each sum units.

Rather than optimizing a discriminative loss, one minimizes the negative log-likelihood

\mathcal{L}=-\log(p(\mathbf{\hat{y}}|\mathbf{z}))=-\log(\mathcal{C}_{\mathcal{O}}(\mathbf{\hat{y}};\mathbf{\Omega}=g(\mathbf{z})))

(21)

Informally, one trains
\mathsf{nn}
to output parameters for
\mathcal{C}_{\mathcal{O}}
that maximize the belief over the assignment
\mathbf{\hat{y}}
when
\mathbf{z}
is observed.

At inference time, it is possible to output predictions by extracting the most probable assignment
\mathbf{y}
i.e., query
\mathcal{C}_{\mathcal{O}}
for its MAP (Maximum A Posteriori) assignment, as

\mathbf{y}=\mathop{\mathrm{argmax}}\limits_{\mathbf{y}^{*}\in\{0,1\}^{L}}\mathcal{C}_{\mathcal{O}}(\mathbf{y}^{*};\mathbf{\Omega}=g(\mathbf{z}))

(22)

which is tractable for smooth, decomposable, and deterministic circuits
[
24
,
29
]
.
Different from the SL approach, an SPL is guaranteed to produce a prediction
\mathbf{y}
that is consistent with the ontology
\mathcal{O}
since
\mathbf{y}\in\mathsf{supp}(\mathcal{C}_{\mathcal{O}})
by definition and can only implement
hard-constraints
.

Note that given their definitions in Equations
19
and
20
, both SL and SPL output predictions
\mathbf{y}
that can be interpreted as vectors encoded using the characteristic boolean function of Equation
16
and can be interpreted accordingly, i.e., each element of the vector refers to the and element of a domino.

Alongside the differences highlighted so far, SL and SPL also differ in their expressiveness. Informally, the independence assumption required by the SL approach results in models that are harder to train and produce over-confident predictions only over a small set of possible consistent assignments, possibly suffering from reasoning shortcuts
[
130
,
92
]
. On the other hand, an SPL models an expressive probability over the
L
labels and is hence able to capture conditional dependencies between them.

Integrate background knowledge

The experiments described above jointly perform the classification of the subject and object of the input and detect the relationships between them. While this approach is consistent with recent advancements in automated information extraction methods
[
98
,
83
]
, there are situations in which one has some background knowledge at hand that can be used, as also argued in Section
2
. In this section, we demonstrate that background knowledge can be easily integrated into models based on SL or SPL. In particular, we update our experimental setting and assume that the classification of subjects and objects can be performed using background knowledge, while the detection of the relations is performed by the neural network, similarly to the link prediction setting described in Section
2
.

We first consider the SL approach by recalling that
p(\mathbf{y}|\mathbf{z})
is implemented as formalized in Equation
18
.
We can inject background knowledge in
p(\mathbf{y}|\mathbf{z})
by updating it to

p(\mathbf{y}|\mathbf{z})=\prod_{i\in\mathbf{L}_{S}}\llbracket\mathbf{e}^{S}_{i}=1\rrbracket\prod_{i\in\mathbf{L}_{R}}p(\mathbf{y}_{i}=1|\mathbf{z})\prod_{i\in\mathbf{L}_{O}}\llbracket\mathbf{e}^{O}_{i}=1\rrbracket

(23)

where
\mathbf{L}_{S},\mathbf{L}_{R},\mathbf{L}_{O}
are, respectively, the indices that refer to subject, role, and object variables and
\mathbf{e}^{S}\in\{0,1\}^{|\mathbf{L}_{S}|},\mathbf{e}^{O}\in\{0,1\}^{|\mathbf{L}_{O}|}
are the evidence vectors encoding background knowledge according to the characteristic boolean function of Equation
16
. Intuitively, one constructs the classification function such that it contributes only to a subset of the probability distribution
p(\mathbf{y}|\mathbf{z})
, while background knowledge is used for the rest.

Integrating background knowledge in the SPL approach is even simpler. It is sufficient to update Equation
22
to

\mathbf{y}=\mathop{\mathrm{argmax}}\limits_{\mathbf{y}^{*}\in\{0,1\}^{L}}\mathcal{C}_{\mathcal{O}}(\mathbf{y}^{*}|\mathbf{e};\mathbf{\Omega}=g(\mathbf{z}))

(24)

where
\mathbf{e}
refers to the evidence vector encoding background knowledge according to the characteristic boolean function of Equation
16
. This is possible since querying for the MAP state using evidence is tractable in smooth, decomposable, and deterministic circuits
[
24
,
29
]
.

7
Conclusion

In this paper, we propose to compile an
\mathcal{ALCI}{}
Description Logic ontology into a circuit representation to obtain deep learning models that can reliably output predictions consistent with the domain knowledge formalized in the ontology. We experiment with different NeSy methods and show that they obtain reliable performances and even outperform fully neural baselines, including cases when background knowledge is available.

Moreover, we show that challenging tasks can be addressed efficiently as a byproduct of compiling the ontology to a circuit, such as generating semantically defined datasets or performing highly scalable deductive reasoning.

Our proposal paves the way for a tight integration between advancements in the Knowledge Representation field and advancements in the NeSy field through the use of circuits as a unifying framework.

As described in Section
2
, the attractive properties of circuits can be used to implement methods beyond NeSy approaches, tackling real-world problems where domain knowledge can be formalized as an ontology. In this work, we preliminarily explored some applications (data generation and deductive reasoning) to showcase the advantages of compiling a circuit
\mathcal{C}_{\mathcal{O}}
. Future works include experimenting with
\mathcal{C}_{\mathcal{O}}
on real-world use cases, using datasets and benchmarks that closely resemble real environments.

Nonetheless, this approach entails facing the main limitations of our proposal: the scalability of the compilation algorithm with respect to the size of the ontology. Future works include identifying other methods to encode DL fragments to more succinct circuit representations and exploring the limits of knowledge compilers with respect to the dimension of an ontology.
