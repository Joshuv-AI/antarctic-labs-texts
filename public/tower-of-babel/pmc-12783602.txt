An epilepsy prediction and management system based on federated learning combined with hybrid harmony search and mutual information (HSA-MI)-based feature selection approach
Authors: Mohd Abdul Rahim Khan, Khaled Mahmoud Heba, Abbass Hassan Abbass, Mujeeb Ahmed Shaikh, Ghanshyam G. Tejani, Sunil Kumar Sharma, Mohammad Khaleel Sallam Ma’aitah
Published: 2025

ABSTRACT
Epilepsy represents a widespread neurological disorder that causes unexpected seizure occurrences which produce significant obstacles for daily life activities in people worldwide. Real-time seizure detection accuracy stands vital for safeguarding patients while ensuring timely interventions and bettering their quality of life. The present seizure detection methods suffer from multiple limitations including poor applicability across different cases and excessive incorrect alerts and inefficient feature selection procedures. Traditional deep learning algorithms generally fail to detect EEG patterns with both temporal and spatial characteristics thereby producing subpar results in practical settings. This study proposes EpilepNet-LD integrated with federated learning (FL), a novel framework for decentralized EEG analysis that preserves patient privacy while enabling collaborative model training. The framework employs a hybrid harmony search and mutual information (HSA-MI) feature selection technique to identify optimal temporal, spectral, and spatial EEG features, reducing computational overhead. The EpilepNet-LD architecture combines long short-term memory (LSTM) networks to capture temporal dependencies with DenseNet-121 to extract hierarchical spatial features, improving seizure detection performance. Extensive experimental evaluations confirmed the proposed method achieves 99.41% extensive experiments demonstrate that the proposed method achieves 99.41% accuracy and 99.50% sensitivity, outperforming existing state-of-the-art approaches. The integrated FL and HSA-MI approach, coupled with the EpilepNet-LD classifier, enables robust, real-time, and high-precision seizure detection, offering a reliable solution for advanced epilepsy monitoring and management.

Despite improvements in therapeutic techniques and technology, most of the patients are still plagued by unpredictable seizures, no doubt indicating the requirement for developing accurate prediction systems so that timely intervention could be ensured2–5. This class of traditional EEG-based seizure detection techniques, though widely practiced, is usually characterized by errors in real-life applications, owing to factors such as noise, artifacts, and inter-patient variability6,7.

Over the past few years, machine learning (ML)8–17 and deep learning (DL) have been highly promising in improving seizure prediction by automating feature extraction and improving accuracy18–22. However, EEG data is high-dimensional, complex, and non-stationary, and seizures are very rare, which leads to imbalanced datasets that are difficult for prediction models23. One of the solutions is the application of hybrid deep learning architectures, which include the combination of several neural networks to learn both the temporal and spatial patterns of EEG signals24. The accuracy and computational load of these models heavily rely on selecting appropriate features because extraneous or duplicate data will decrease performance25.

To meet these challenges, this research develops an epilepsy prediction and management system which integrates hybrid DL with an innovative feature selection framework26,27. The system implements Hybrid Harmony Search and Mutual Information (HAS-MI) methodology which selects important features for creating an efficient yet understandable model28. The hybrid DL system benefits from selected features obtained through the Harmony Search (HS) with MI process which leads to enhanced EEG pattern analysis leading up to the seizure29,30.

The system aims at improving the prediction accuracy, decreasing false alarms, and enabling real-time applications by integrating feature selections generated from HAS-MI with hybrid deep learning. Also, it contains a management module that provides personal therapeutic recommendations so that the prediction does not aim to be only a technical achievement but also a practical tool for enhancing patient care. This research is beyond novel epilepsy research. It empowers patients, enhances their independence, and reduces the societal effect of uncontrolled seizures.

Related work

In 2023, Jaishankar et al.31 presented a new DL-based seizure prediction model for epilepsy using EEG recordings from the CHB-MIT dataset with 23 cases (17 females and 5 males). To improve efficiency, raw EEG signals are input directly into a feature extractor to lower computational complexity and execution time. The model leverages an Adaptive Grey Wolf Optimizer (AGWO) to learn and enhance discriminative features, thus enhancing prediction accuracy. Also, an auto-encoder combined with a Genetic Algorithm (GA) is utilized to optimize features adaptively. The developed approach delivers 99% accuracy results alongside minimal False Alarm Rate (FAR). The MATLAB simulation validates the model functionality by demonstrating better trade-offs than traditional approaches.

In 2023, Pandey et al.32. introduced a seizure prediction model which combines sequential DL prediction with a new hybrid Forensic-based-Search-and-Rescue Optimization (FB-SARO). The model resolves seizure variability through multiple feature enhancement techniques which build a combined feature domain able to detect epileptic seizure non-linear behavior. The classifier learning process determines a best seizure prediction horizon (SPH) which allows for early prediction with high accuracy and low FPR. The proposed methodology undergoes testing using public databases while comparing results with best techniques.

In 2023, Palanisamy et al.33 proposed the combination of Arnold transform algorithms and chaotic mapping with convolutional neural networks (CNNs) to forms an efficient approach for epileptic seizure prediction and classification of encrypted EEG data. Each EEG time series channel generates 2D spectrogram images that undergo encryption through chaotic algorithms. The encrypted data receives processing through CNNs that use transfer learning (TL) frameworks for operation. A hybridized spoofing optimization method uses corvid and gregarious-seeking agent characteristics to develop ensemble learning classifiers’ fusion parameters. Secure EEG data analysis occurs within the proposed system while achieving better seizure prediction performance.

In 2023, Pratap and Krishan34 suggested a hybrid DL model of ResNet50 and LSTM for predicting epileptic seizures based on EEG data. EEG signals are converted into the time-frequency domain through Short-Time Fourier Transform (STFT) and then transformed into spectrogram images for feature extraction and classification. The model is tested on the CHB-MIT scalp EEG dataset for preictal lengths of 5, 15, and 30 min, with best performance at a 5-minute preictal length, outperforming current seizure prediction methods.

In 2023, Hu et al.35 suggested a hybrid Transformer-based model for epilepsy prediction using transfer learning (TL) methods and multiple EEG rhythms for better performance. The model is developed to assess benefits over pure CNN-based models. Two traditional feature engineering techniques and a new method with multiple EEG rhythms are also investigated. The model is evaluated on the CHB-MIT scalp EEG dataset, which shows increased robustness with fine-tuning methods and underscores the significance of gamma rhythm information for seizure prediction.

In 2021, Ryu and Joe36 developed a hybrid DL model expelled by dense convolutional networks (DenseNet) and LSTM models for the prediction of epileptic seizures from EEG data. The method follows converting the EEG data into the time-frequency domain using Discrete Wavelet Transform (DWT) before training the proposed hybrid DenseNet-LSTM model. The model is evaluated on the different preictal lengths based on the CHB-MIT scalp EEG database, with improved performance in seizure prediction compared to previously published work.

In 2024, Ahmad et al.37 proposed a patient-specific seizure prediction framework, integrated with CIoT (Consumer Internet of Things) for real-time monitoring and early treatment pertaining to smart healthcare. Multiple handcrafted and deep features are extracted, fused, and passed through a Bidirectional Long Short-Term Memory (BiLSTM) network to capture temporal dependencies in EEG signals. The Attention Mechanism works to reduce the dimensionality of the features, while the CioT module provides support for real-time seizure prediction and alert notifications to the concerned medical experts through the cloud platform.

In 2022, Kapoor et al.38 presented a hybrid optimization-controlled ensemble classifier for predicting epileptic seizures based on EEG data. The approach employs classifier strategies based on a combination of AdaBoost, Random Forest (RF), and Decision Tree (DT). The EEG signals go through the process of preprocessing and feature selection through a hybrid seek optimization algorithm that extracts statistical, wavelet-based, and entropy-based features. A proposed hybrid optimization technique based on corvid and gregarious search agent behavior optimizes ensemble classifier fusion parameters and demonstrates high accuracy in early seizure prediction on both CHB-MIT and Siena Scalp databases.

In 2024, Yuan et al.39 suggested a approach for the prediction of epileptic seizures, a hybrid DL architecture that combines DenseNet and Vision Transformer (ViT) with an attention fusion layer. DenseNet learns representative features hierarchically while ViT implements self-attention mechanisms and global feature representation. The attention fusion layer better predicts by fusing features from both networks. The EEG signals that are ultimately fed into the DenseNet-ViT model were preprocessed using the STFT and converted into time-frequency matrices. The approach is further validated in the CHB-MIT dataset via a leave-one-out cross-validation scheme, yielding far superior prediction results for seizure activities.

In 2025, Saadoon et al.40 presented a new framework for seizure prediction, which can be fundamentally regarded as an efficient CNN like EfficientNet-b0 and consists of an ensemble of six support vector machines (SVMs) along with a voting mechanism. The framework extracts both spectral and spatial features from EEG signals through normalized STFT and channel correlation features. Computation efficiency has been increased using EfficientNet-b0 as a backbone with accuracy, and prediction reliability has been improved by reducing noise and variability by the SVM ensemble. Comparison of the existing techniques in epilepsy prediction.

Extensive studies have been conducted in the domain of mental health prediction and EEG-based neurological disorder detection, leveraging both conventional and deep learning approaches. Traditional methods primarily rely on statistical and handcrafted feature extraction techniques, which often suffer from high dimensionality, feature redundancy, and limited ability to capture complex temporal and spatial dependencies in EEG, speech, and behavioral signals. More recent deep learning frameworks, such as CNN, RNN, and GNN, have improved feature representation and classification performance; however, they still face significant limitations in handling multi-modal data, maintaining scalability, and reducing computational complexity.

Moreover, existing approaches rarely incorporate adaptive feature selection methods that can dynamically prioritize the most discriminative features across multiple modalities, leading to suboptimal predictive performance. In addition, the integration of personalized intervention strategies with prediction frameworks remains underexplored, limiting the practical utility of these models in real-world clinical settings.

The present study addresses these critical gaps by proposing MQAD-Net, which combines Graph Attention Networks (GAT) for EEG feature extraction, Quantum Greylag Multi-Criteria Decision-Making Feature Selection (QGMFS) for adaptive and optimal feature selection, and a hybrid Dense-DualLSTMNet (DDL-Net) classifier for multi-modal learning. This approach not only enhances prediction accuracy but also enables personalized therapy recommendations, thereby advancing the field beyond the limitations of prior works.

Proposed methodology

In this work, a FL-based seizure detection system is presented to enhance the accuracy and reliability of epilepsy prediction. The method starts with EEG data acquisition from the Epilepsy Dataset, then EEG preprocessing, where EMD is employed to extract Intrinsic Mode Functions (IMFs) for the analysis of non-stationary EEG components, and Adaptive Noise Filtering (ANF) is utilized to eliminate artifacts and unwanted noise. Following that, feature extraction is done to obtain temporal, spectral, and spatial features from EEG signals. A Hybrid Feature Selection (HFS) approach is utilized to improve model performance by combining Harmony Search Algorithm (HAS) for selecting the best subsets of features and Mutual Information (MI) for making features relevant depending on seizure event interdependencies. Lastly, a FL-based seizure detection model, EpilepNet-LD, is proposed that integrates LSTM for temporal pattern capture and DenseNet-121 for hierarchical spatial feature extraction. FL setup provides decentralized training while maintaining data privacy, but enhancing classification performance. The overview of the suggested approach is presented in Fig. 1.

Data collection

Here in this research, raw data is obtained from Epilepsy Dataset (https://www.kaggle.com/datasets/datasetengineer/epilepsy-dataset) and processed further to develop federated deep learning models in epilepsy detection while maintaining data privacy. The dataset contains 289,010 EEG-derived feature records, which include features from time-domain, frequency-domain, wavelet transform, nonlinear, seizure-specific, and demographic features. It offers multi-class labels (Normal, Pre-Seizure, Seizure, Post-Seizure) and seizure type classifications (Normal, Generalized Seizure, Focal Seizure). Gathered in real-time from several hospitals with standardized preprocessing, the dataset spans a wide age range (1–90 years). It is useful for seizure detection, prediction, and individualized epilepsy management, making it worth considering for real-time AI applications. Pre-processing

The non-stationary non-linear properties of EEG signals create high susceptibility to noise and artifacts that make seizure prediction extremely challenging. The model performance suffers from unwanted interferences found in raw EEG recordings including baseline drift together with muscle movements, eye blinks, and environmental noise. A strong signal preprocessing approach serves as an essential requirement to improve signal clarity before performing feature extraction and subsequent phases.

This study employs a two-step EEG preprocessing approach:

Empirical mode decomposition (EMD)

EEG signals are very non-stationary in nature, i.e., their frequency content changes over time. Conventional spectral analysis techniques like Fourier Transform (FT) or Wavelet Transform (WT) make stationarity assumptions and are unable to handle transient changes of seizure patterns. EMD handles this issue by the adaptive decomposition of EEG signals into Intrinsic Mode Functions (IMFs), each describing a different frequency component of the signal.

In seizure detection, IMFs are important to capture specific frequency components of the EEG signal. Lower-order IMFs mainly involve high-frequency variations, which typically relate to epileptic discharges and are good for seizure-onset detection. Higher-order IMFs preserve slowly varying trends describing seizure development, offering important knowledge on the time evolution of epilepsy. By choosing the most important IMFs only, the process of feature extraction becomes more effective, allowing deep learning models to learn seizure-relevant patterns and minimize computational complexity. EMD demonstrates its key strength through its adaptive data-driven operation which requires no pre-defined basis functions. EMD properly separates seizure-relevant frequency bands from noise while preserving essential neural oscillations. EMD processing enhances DL model discrimination ability while improving both the accuracy and reliability of seizure classification.

Adaptive noise filtering (ANF)

The EEG systems generate three types of artifacts which contaminate their recordings: Electromyographic (EMG) noise from muscle contractions, Electrooculographic (EOG) noise from eye blinks and Power-line interference (50/60 Hz noise). The artifacts distort signals so classification accuracy decreases. Traditional bandpass filters used for noise reduction have the potential to remove essential seizure-related features along with the noise. The Adaptive Noise Filtering (ANF) system resolves this issue through real-time adjustments of its filter parameters which match current noise variations.

Feature selection: hybrid harmony search and mutual information (HSA-MI) approach

The selection of an optimal relevant and discriminative subset from the extracted comprehensive feature set \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\:{x}_{fe}\left(t\right)$$\end{document} becomes essential for effective seizure classification of EEG signals. The high-dimensional nature of EEG data generates feature spaces containing redundant information along with noise and unimportant attributes that diminish model outcomes and increases processing requirements and creates overfitting problems. The hybrid feature selection (HFS) approach HSA-MI combines Mutual Information (MI) with Harmony Search Algorithm (HSA) to execute systematic optimization of feature selection processes. The feature selection subset generated by this method combination achieves both improved classification precision and faster computations and stronger model generalization for seizure detection.

Rationale for HSA-MI in feature selection

The failure of traditional feature selection techniques exists because EEG signals exhibit non-linear dynamics together with temporal variability and inter-channel correlations. Traditional methods show ineffective results when removing redundant features and detecting complex dependencies during their analysis of conventional techniques. The combination of two powerful methods within the HSA-MI approach addresses these issues effectively:

FL-based detection via EpilepNet-LD

EpilepNet-LD utilizes Federated Learning (FL) to boost data privacy and scalability for epilepsy detection purposes. The model utilizes FL to enable multiple edge devices to improve a global model by collaborative learning without exchanging raw EEG data. The method protects patient privacy by securing data in addition to minimizing transmission requirements which enables efficient secure seizure prediction and management through the proposed framework.

The standard centralized training approaches for epilepsy detection face three major problems when working with EEG data from different sources: network bandwidth limitations and high computational requirements and privacy risks. A Federated Hybrid Deep Learning (FHDL) framework includes two essential components namely a global model and a local model to resolve identified limitations.

The local model is then trained on individual edge device or hospital-based EEG sensor employing the best feature subset \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\:x{f}_{s}\left(t\right)$$\end{document} identified from the Hybrid Harmony Search and Mutual Information (HSA-MI) feature selection process. These optimized features improve the efficiency of training with minimization of redundancy and consideration of only the most promising seizure-related EEG patterns. Local training employs EpilepNet-LD, a hybrid deep learning model fusing DenseNet121 for learning feature representation and LSTM for learning temporal seizure patterns.

Following local training on local datasets, the global model combines the learned parameters from all the local models at the end of each federated learning round. This combination shares the knowledge across distributed nodes without compromising data privacy since raw EEG signals do not leave local devices but remain there without sharing. In addition, the last latent feature representations are further refined by a fully connected (FC) layer with output being processed using Softmax for seizure classification. LSTM

The advanced version of Recurrent Neural Networks (RNNs) known as LSTM networks exists to solve the vanishing gradient problem that affects standard RNNs. The ability to handle extended dependencies in sequential EEG data makes LSTMs effective for accurate seizure prediction. The gating mechanism built into LSTMs controls information retention and forgetting to ensure relevant EEG patterns contribute to seizure classification while standard RNNs lack this capability.

The LSTM architecture includes three main gates which are input gate, forget gate and output gate together with a cell state that functions as a memory unit for essential temporal patterns.

DenseNet 121

The proposed FL-based EpilepNet-LD model uses DenseNet-121 as its deep CNN model for EEG signal classification. The distinctive connectivity pattern of DenseNet-121 allows efficient spatial-temporal correlation identification in EEG signals which makes it ideal for EEG-based seizure detection tasks.

The model contains four densely connected convolutional blocks which extract hierarchical representations of EEG feature data. A sequential pattern extraction process starts with EEG feature maps as input while using convolutional layers for information retrieval. Performance evaluation based on key metrics

The proposed system achieves better results than AGWO-AE31, FB-SARO32, CNN-TL33, and ResNet50 + LSTM34 on multiple evaluation metrics. The integration of Federated Learning (FL) for decentralized training together with Hybrid Harmony Search and Mutual Information (HSA-MI) for feature selection and EpilepNet-LD, a novel deep learning-based seizure detection model resulted in exceptional improvements across accuracy, precision, F1-score and other key metrics, which is represented in Table 3.

The experimental results presented in Table 3 demonstrate the superior performance of the proposed seizure detection model across multiple evaluation metrics compared to several state-of-the-art baseline methods, including AGWO-AE31, FB-SARO32, CNN-TL33, and ResNet50 + LSTM34. The proposed model achieves an accuracy of 0.99419, indicating near-perfect classification of seizure and non-seizure EEG signals, which represents a substantial improvement over the closest competitor, ResNet50 + LSTM, which records an accuracy of 0.96439. This improvement reflects the effectiveness of integrating EpilepNet-LD with Federated Learning and the HSA-MI feature selection technique, which ensures optimal selection of discriminative EEG features while preserving temporal and spatial characteristics.

The precision of 0.98829 illustrates the model’s ability to correctly identify true seizure events, reducing false positives, which is critical in real-time clinical applications where unnecessary alerts can disrupt patient care. In comparison, the baseline models report lower precision values ranging from 0.94649 to 0.95669, indicating higher rates of misclassification in their predictions.

Similarly, the F1-score of 0.99799 underscores the balance between precision and recall, showing that the proposed model effectively minimizes both false positives and false negatives. This is particularly important for seizure detection, where missing a seizure (false negative) or incorrectly signaling one (false positive) can have serious consequences for patient safety. In contrast, baseline models achieve F1-scores between 0.94419 and 0.96239, demonstrating comparatively weaker performance in harmonizing sensitivity and specificity.

The sensitivity of 0.99509 further confirms the model’s proficiency in detecting true seizure events, outperforming all baselines. High sensitivity is vital for early and accurate seizure detection, which facilitates timely interventions and improved patient outcomes. The specificity of 0.99209 indicates that the model can effectively identify non-seizure events, reducing the likelihood of false alarms, which is a common challenge in existing approaches.

Other metrics, including Matthews Correlation Coefficient (MCC = 0.98869) and Negative Predictive Value (NPV = 0.98919), validate the robustness of the proposed model in maintaining balanced classification performance across imbalanced datasets. The False Positive Rate (FPR = 0.04488) and False Negative Rate (FNR = 0.03908) are significantly lower than those of the baselines, demonstrating improved reliability and real-world applicability in clinical scenarios.

Overall, the quantitative outcomes substantiate the superiority of the proposed approach. The integration of temporal feature extraction via LSTM, hierarchical feature representation through DenseNet-121, and optimized feature selection using HSA-MI synergistically enhances seizure detection. This explains why the proposed model consistently outperforms baseline methods across all metrics, providing both high precision and recall, which are essential for trustworthy and real-time epilepsy monitoring.

Conclusion

This work suggested a FL-based seizure detection system to improve the reliability and accuracy of epilepsy prediction. The steps involved EEG data acquisition, EMD-based preprocessing for the analysis of the non-stationary components and ANF for removing artifacts. Feature extraction was then employed to obtain temporal, spectral, and spatial features of EEG signals. A Hybrid Feature Selection (HFS) strategy, which was a blend of Harmony Search Algorithm (HSA) and Mutual Information (MI), was employed to achieve the maximum relevance of the features. Lastly, the EpilepNet-LD model, which utilized LSTM for learning in time and DenseNet-121 for spatial feature learning, was implemented using a Federated Learning (FL) setting for decentralized training while maintaining data privacy and enhancing seizure detection accuracy. The Python-based implementation of the approach yielded successful experimental results which showed its effectiveness. The model reached 99.41% accuracy while showing 99.20% specificity which surpassed all existing state-of-the-art seizure detection methods. This work establishes an essential epilepsy prediction system because it delivers precise real-time privacy-protected monitoring which makes it suitable for medical use in clinical settings and real-world applications. This rigorous empirical validation highlights the superior detection capability and stability of the proposed framework under varying operational conditions, thereby demonstrating its practical reliability. However, despite these promising results, certain limitations must be acknowledged. First, while the model demonstrates strong performance across the selected datasets, its generalizability to heterogeneous real-world EEG environments requires further validation. Second, the computational complexity associated with the feature selection and deep learning components may present scalability challenges when deployed in resource-constrained clinical or mobile environments. Third, the dependence on high-quality pre-processed EEG signals may affect robustness when dealing with signals containing severe noise or missing data. Additionally, the current study focuses primarily on detection accuracy; future work should explore real-time deployment strategies, adaptive learning mechanisms, and model interpretability enhancements to improve clinical applicability and trustworthiness. For future research, this approach can be extended to incorporate multi-modal EEG data for improved robustness, investigate edge computing frameworks to further minimize computational expenses, and include personalized seizure prediction functions to improve patient-specific adaptability in real-time surveillance systems.
