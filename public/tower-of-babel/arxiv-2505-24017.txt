On the number of exceptional intervals to the prime number theorem in short intervals
Ayla Gafni, Terence Tao

Abstract
. For a fixed exponent 0 < θ ≤ 1 0<\theta\leq 1 , it is expected that we have the prime number theorem in short intervals ∑ x ≤ n < x + x θ Λ ⁡ ( n ) ∼ x θ \sum_{x\leq n<x+x^{\theta}}\Lambda(n)\sim x^{\theta} as x → ∞ x\to\infty . From the recent zero density estimates of Guth and Maynard, this result is known for all x x for θ > 17 30 \theta>\frac{17}{30} and for almost all x x for θ > 2 15 \theta>\frac{2}{15} . Prior to this work, Bazzanella and Perelli obtained some upper bounds on the size of the exceptional set where the prime number theorem in short intervals fails. We give an explicit relation between zero density estimates and exceptional set bounds, allowing for the most recent zero density estimates to be directly applied to give upper bounds on the exceptional set via a small amount of computer assistance.

We begin with some simple reductions.
Fix

Fix

\delta,\theta,\varepsilon
), that one has the upper bound

|{\mathcal{E}}_{\delta}(X,\theta)|\ll_{\delta,\theta,J}X^{\mu+4/J+o(1)}

as

(holding the other parameters
J,\delta,\theta,\varepsilon

X
is larger than any specified absolute constant.

By subdividing
[X,2X]
into
O_{\delta}(1)
intervals of the form
[X,(1+\delta/J)X]
and using the triangle inequality, it suffices to show that

\left|\left\{X\leq x<(1+\delta/J)X:\left|\sum_{x<n\leq x+x^{\theta}}\Lambda(n)-x^{\theta}\right|\geq\delta x^{\theta}\right\}\right|\ll_{\delta,\theta,J}X^{\mu+4/J+o(1)}.

From the Brun–Titchmarsh inequality we see that for
X\leq x<(1+\delta/J)X

\sum_{x<n\leq x+x^{\theta}}\Lambda(n)=\sum_{x<n\leq x+x/\tau}\Lambda(n)+O\left(\frac{\delta}{J}x^{\theta}\right)

where

J
large enough) to show that

\left|\left\{X\leq x<(1+\delta/J)X:\left|\sum_{x<n\leq x+x/\tau}\Lambda(n)-\frac{x}{\tau}\right|\geq\frac{\delta}{2}\frac{X}{\tau}\right\}\right|\ll_{\delta,\theta,J,\varepsilon}X^{\mu+4/J+o(1)}.

\sum_{x<n\leq x+x/\tau}\Lambda(n)-\frac{x}{\tau}=\sum_{\rho\in{\mathcal{Z}}(0,T)}\frac{(x+x/\tau)^{\rho}-x^{\rho}}{\rho}+O\left(\frac{x(\log x)^{2}}{T}\right).

By choice of

, the error term here is

\left|\left\{X\leq x<(1+\delta/J)X:|S_{[0,1]}(x)|\geq\frac{\delta}{3}\frac{X}{\tau}\right\}\right|\ll_{\delta,\theta,J,\varepsilon}X^{\mu+4/J+o(1)}

S_{I}(x)\coloneqq\sum_{\rho\in{\mathcal{Z}}(0,T):\Re\rho\in I}\frac{(x+x/\tau)^{\rho}-x^{\rho}}{\rho}.

If

From the fundamental theorem of calculus and the triangle inequality, we have

\displaystyle\ll\sum_{\sigma+it\in{\mathcal{Z}}(1-\eta_{0},T)}\frac{X}{\tau}X^{\sigma-1}

\displaystyle\ll\frac{X}{\tau}\sum_{\sigma+it\in{\mathcal{Z}}(1-\eta_{0},T)}X^{-\eta_{0}}+\int_{1-\sigma}^{\eta_{0}}(\log X)X^{-\eta}\ d\eta

A similar argument controls intervals

Lemma 2.2

(

If

for some fixed

We also have a second moment bound:

Lemma 2.3

(
L^{2}
bound)
.

If
I\subset[\sigma_{-},\sigma_{+}]
for some fixed
0\leq\sigma_{-}\leq\sigma_{+}\leq 1
, then

\frac{1}{X}\int_{X}^{2X}|S_{I}(x)|^{2}\ dx\ll_{\theta}X^{(1-\theta)(1-\sigma_{-})A(\sigma_{-})+2\theta+2\sigma_{+}-2+o(1)}

Proof.

This estimate is essentially in
[
16
, §2]
, but for the convenience of the reader we give a proof here. We can bound the left-hand side by

\ll\int_{0}^{\infty}|S_{I}(x)|^{2}\psi(\log x-\log X)\ \frac{dx}{x}

where
\psi
is fixed non-negative bump function that is bounded away from zero on
[0,\log 2]
. Using (
2.4
), we may expand this as

\sum_{\sigma+it,\sigma^{\prime}+it^{\prime}\in{\mathcal{Z}}(0,T):\sigma,\sigma^{\prime}\in I}c_{\sigma+it}\overline{c}_{\sigma^{\prime}+it^{\prime}}X^{\sigma+\sigma^{\prime}+i(t-t^{\prime})}\hat{\psi}(t-t^{\prime}-i(\sigma+\sigma^{\prime}))

where

\hat{\psi}(\xi)\coloneqq\int_{\mathbb{R}}\psi(u)e^{iu\xi}\ du

is the (complexified) Fourier transform of
\psi
, and
c_{\sigma+it}
are the coefficients

c_{\sigma+it}\coloneqq\frac{(1+1/\tau)^{\sigma+it}-1}{\sigma+it}.

By standard integration by parts estimates, we have

\hat{\psi}(t-t^{\prime}-i(\sigma+\sigma^{\prime}))\ll\frac{1}{(1+|t-t^{\prime}|)^{10}}

(say), while from the fundamental theorem of calculus one has

c_{\sigma+it},c_{\sigma^{\prime}+it^{\prime}}\ll\frac{1}{\tau}=X^{\theta-1+o(1)}.

By the triangle inequality, we conclude that

\frac{1}{X}\int_{X}^{2X}|S_{I}(x)|^{2}\ dx\ll X^{2\theta+2\sigma_{+}-2+o(1)}\sum_{\sigma+it,\sigma^{\prime}+it^{\prime}\in{\mathcal{Z}}(\sigma_{-},T)}\frac{1}{(1+|t-t^{\prime}|)^{10}}.

From the Riemann-von Mangoldt formula, there are there are at most
O(\log T)
zeroes
\sigma+it\in{\mathcal{Z}}(\sigma_{-},T)
(counting multiplicity) with
t
in any given unit interval in
[-T,T]
, so we can bound the above expression by

\ll X^{2\theta+2\sigma_{+}-2+o(1)}(\log T)N(\sigma_{-},T),

and the claim now follows from (
1.3
) and the definitions of
T,\tau
.
∎

In a similar spirit, we have a fourth moment bound:

Lemma 2.4

(

If

for some fixed

\frac{1}{X}\int_{X}^{2X}|S_{I}(x)|^{4}\ dx\ll_{\theta}X^{(1-\theta)(1-\sigma_{-})A^{*}(\sigma_{-})+4\theta+4\sigma_{+}-4+o(1)}

Proof.

Again, this estimate is essentially in
[
16
, §2]
, but we reproduce the argument here. With
\psi
as before, we can bound the left-hand side by

\displaystyle\ll\sum_{\sigma_{1}+it_{1},\dots,\sigma_{4}+it_{4}\in{\mathcal{Z}}(0,T):\sigma_{1},\dots,\sigma_{4}\in I}c_{\sigma_{1}+it_{1}}c_{\sigma_{2}+it_{2}}\overline{c}_{\sigma_{3}+it_{3}}

\displaystyle\quad X^{\sigma_{1}+\sigma_{2}+\sigma_{3}+\sigma_{4}+i(t_{1}+t_{2}-t_{3}-t_{4})}\hat{\psi}(t_{1}+t_{2}-t_{3}-t_{4}-i(\sigma_{1}+\sigma_{2}+\sigma_{3}+\sigma_{4}))

and so by using the estimates used to bound

2.3

\ll X^{4\theta+4\sigma_{+}-4+o(1)}\sum_{\sigma_{1}+it_{1},\dots,\sigma_{4}+it_{4}\in{\mathcal{Z}}(\sigma_{-},T)}\frac{1}{(1+|t_{1}+t_{2}-t_{3}-t_{4}|)^{10}}.

By a routine double counting, we can bound this expression by

\ll X^{4\theta+4\sigma_{+}-4+o(1)}\int_{\mathbb{R}}\int_{\mathbb{R}}F(t)F(t^{\prime})\frac{dtdt^{\prime}}{(1+|t-t^{\prime}|)^{10}}

where

F(t)\coloneqq\#\left\{\sigma_{1}+it_{1},\sigma_{2}+it_{2}\in{\mathcal{Z}}(\sigma_{-},T):|t_{1}+t_{2}-t|\leq\frac{1}{2}\right\}.

By Schur’s test, this is bounded by

\ll X^{4\theta+4\sigma_{+}-4+o(1)}\int_{\mathbb{R}}F(t)^{2}\ dt

\ll X^{4\theta+4\sigma_{+}-4+o(1)}N^{*}(\sigma_{-},T)

1.3
) and the definitions of

By definition of

Remark

By a routine modification of the above arguments one can replace

As mentioned in the introduction, on the Riemann hypothesis (RH) we have that

for

for
