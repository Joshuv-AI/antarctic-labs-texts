The role of counting quantifiers in laminar set systems
Rutger Campbell, Noleen Köhler

Abstract
Laminar set systems consist of non-crossing subsets of a universe with set inclusion essentially corresponding to the descendant relationship of a tree, the so-called laminar tree. Laminar set systems lie at the core of many graph decompositions such as modular decompositions, split decompositions, and bi-join decompositions. We show that from a laminar set system we can obtain the corresponding laminar tree by means of a monadic second order logic ( MSO \operatorname{MSO} ) transduction. This resolves an open question originally asked by Courcelle and is a satisfying resolution as MSO \operatorname{MSO} is the natural logic for set systems and is sufficient to define the property “laminar”. Using results from Campbell et al. [STACS 2025], we can now obtain transductions for obtaining modular decompositions, co-trees, split decompositions and bi-join decompositions using MSO \operatorname{MSO} instead of CMSO \operatorname{CMSO} . We further gain some insight into the expressive power of counting quantifiers and provide some results towards determining when counting quantifiers can be simulated in MSO \operatorname{MSO} in laminar set systems and when they cannot.

Introduction

A transduction transforms relational structures over an input vocabulary
\Sigma_{1}
into
relation structures over an output vocabulary
\Sigma_{2}
in such a way that each
\Sigma_{2}
-definable property can be “translated” back to a
\Sigma_{1}
-definable preimage.

Theorem 1

(Backwards Translation Theorem
[
7
, Theorem 1.40]
)
.

Let
\tau
be a
\operatorname{MSO}
-transduction with input vocabulary
\Sigma_{1}
and output vocabulary
\Sigma_{2}
.
If
\phi_{2}
is an
\operatorname{MSO}
-sentence over
\Sigma_{2}
, then there is a
\operatorname{MSO}
-sentence
\phi_{1}
over
\Sigma_{1}
so that,
the sentence
\phi_{1}
holds for precisely the structures
\mathbb{A}
over
\Sigma_{1}
for which
\tau(\mathbb{A})
contains a structure satisfying
\phi_{2}
.

This is incredibly useful as it means derived structure can be used to define properties.
Of particular significance is derived tree-structure,
due to connections to tree-automata.
Thatcher and Wright showed that a property of labelled rooted trees of bounded degree is
\operatorname{MSO}
-definable if and only if it is recognizable by a tree-automaton.
So if we have a class of objects from which we can transduce a bounded tree description, from whence we can, in turn, transduce the original object,
then
\operatorname{MSO}
-definability of the original object corresponds to recognizability with a tree-automaton. There are also generalizations of the Theorem of Thatcher and Wright which rely on the same principles of obtaining a tree-structured decomposition and then using backwards translation to simulate a run of the tree-automaton on the decomposition.
Most prominently, for graphs of bounded treewidth,
\operatorname{MSO}
-definability is equivalent to tree-automaton recognizability, where the forwards implication is Courcelle’s Theorem
[
9
]
and the backward direction was finally shown by Bojańczyk and Pilipczuk in 2016
[
2
]
. Using the powerful method of Simon’s factorization
[
19
]
, results of Bojańczyk et al.
[
1
]
show that definability equal recognizability in graphs of bounded linear clique-width.
This was recently generalized to show definability equal recognizability in classes of
represented matroids
[
3
]
and more generally representable matroids
[
5
]
over finite fields of bounded linear branch-width.
In pursuit of understanding when definability equals recognizability, Courcelle studied how to transduce tree-structured decompositions such as modular decompositions and split decompositions
[
10
,
11
,
12
,
14
]
. In this series of work, Courcelle uses order invariant
\operatorname{MSO}
, which allows the use of a global linear order of the vertices of the graph. This logic is strictly more expressive than
\operatorname{MSO}
with counting quantifiers, denoted
\operatorname{CMSO}
, which in turn is more expressive than
\operatorname{MSO}

[
16
]
.
These transductions were recently improved to avoid the use of linear order, but still relied on counting quantifiers for the key step
[
4
]
.
This key step involves transducing a tree from a collection of sets and was independently described by Bojańczyk
[
3
]
, also using counting quantifiers.
It was asked as an open question in
[
3
,
4
,
13
]
whether this transduction can be obtained using just
\operatorname{MSO}
.

We focus on transducing a tree from the setting of set systems as it provides a general form of structure itself, to which many other settings have a transduction to.
A
set system
is a pair
(U,\mathcal{F})
consisting of a set
U
and a family
\mathcal{F}
of subsets of
U
. We model this over the vocabulary
\{\mathsf{SET}\}
, consisting of the unary set-predicate
\mathsf{SET}
, by taking
\{\mathsf{SET}\}
-structure
\mathbb{F}
with universe
U_{\mathbb{F}}
and taking
\mathsf{SET}_{\mathbb{F}}(X)
to be true precisely when
X\in\mathcal{F}
.
We say a set system is
laminar
when:
U\in\mathcal{F}
, for each
u\in U
the singleton
\{u\}\in\mathcal{F}
, and for any
F_{1},F_{2}\in\mathcal{F}
the intersection
F_{1}\cap F_{2}
is one of
\emptyset,F_{1},F_{2}
.
For the last condition, we say that
F_{1}
and
F_{2}
do not cross.

Any laminar set system
(U,\mathcal{F})
naturally corresponds to a tree
T
, called the
laminar tree
of
(U,\mathcal{F})
, in which each node of
T
corresponds to a set in
\mathcal{F}
and the descendant relation coincides with the subset relation.
In particular,
U\in\mathcal{F}
corresponds to the root of
T
while
the leaves of
T
correspond to the singletons
\{u\}\in\mathcal{F}
. For ease of notation, we identify
u\in U
with the leaf that corresponds to the singleton
\{u\}
.
Doing this, a set
F\in\mathcal{F}
corresponds to the node
v_{F}
of
T
where the leaves that are descendants of
v_{F}
are precisely the elements of
F
.
For an example of a laminar set system and its laminar tree see
\cref
fig:laminarTree.

In this paper, we introduce a new technique for choosing a representative leaf for every node of a tree in such a way that each leaf is used only a bounded number of times, we give an
\operatorname{MSO}
-transduction that, given any laminar set system
(U,\mathcal{F})
, outputs its laminar tree. We believe that our new technique is of independent interest to the community and has other applications. Formally, our main theorem is the following:

Theorem 2
.

There is an
\operatorname{MSO}
-transduction
\tau
from structures over the vocabulary
\{\mathsf{SET}\}
of set systems, to structures over the vocabulary
\{\mathsf{desc}\}
of rooted trees, such that if
(U,\mathcal{F})
is a laminar set system, then its image is the laminar tree of
(U,\mathcal{F})
.

Figure 1:
An example of a laminar set system and its laminar tree.

We present two consequences of this theorem.
Firstly,
we gain some insights into when
\operatorname{CMSO}
for laminar set systems is strictly more expressive than
\operatorname{MSO}
and when they are equivalent.

Theorem 3
.

Let
k
be a positive integer.
Let
\mathcal{L}_{k}
be the collection of laminar set systems whose laminar trees have down-degree at most
k
.
Then there is a unary set-predicate
\operatorname{EVEN}_{k}
, that is
\{\mathsf{SET}\}
-definable over
\operatorname{MSO}
, where for any set system
(U,\mathcal{F})\in\mathcal{L}_{k}
and any
X\subseteq U
, we have
\operatorname{EVEN}_{k}(X)
as true if
|X|
is even.

By adapting a known result of non-definability in
\operatorname{MSO}
,
we give the following partial converse to Theorem
3
.

Theorem 4
.

If
\mathcal{L}
contains laminar set systems whose laminar trees are stars of unbounded degree, then we cannot
\{\mathsf{SET}\}
-define
\operatorname{EVEN}
for
\mathcal{L}
over
\operatorname{MSO}
.

Secondly,
\cref
thm:main has numerous corollaries in various graph theory decompositions. This work is a strengthening of Theorem 2 from
[
4
]
, as we show that we can achieve the same transduction without the use of a parity predicate.
So by combining Theorem
2
with the other transductions given in
[
4
]
(see
[
4
, Theorem 1]
), we obtain similar corollaries, but now without the use of counting predicates.

Weakly-partitive set systems are less restrictive than laminar set systems. In a weakly-partitive set system, two sets
F_{1}
and
F_{2}
in the family can cross but only if
F_{1}\cap F_{2},F_{1}\setminus F_{2},F_{2}\setminus F_{1}
and
F_{1}\cup F_{2}
are also in the family. For example, in graph theory the set of modules of a directed graph is weakly-partitive. The “weakly-partitive tree” of a weakly-partitive set system is obtained from the laminar tree
T
of a particular laminar sub-set-system (the sets that do not cross any other),
by adding a node labelling
\lambda
and a partial ordering
<
in a way that fully capture the structure of the weakly-partitive set system (see
[
6
]
). We obtain the following transduction.

Corollary 5
.

There is an
\operatorname{MSO}
-transductions
\tau
such that given any weakly-partitive set system
(U,\mathcal{S})
modelled by the
\{\mathsf{SET}\}
-structure
\mathbb{S}
,
\tau
outputs the weakly-partitive tree
(T,\lambda,<)
of
(U,\mathcal{S})
.

Instead of considering set systems, we can also consider systems of bi-partitions. Systems of bi-partitions naturally model concepts in graph theory such as splits and bi-joins. The concept analogous to weak-partitiveness in the world of systems of bipartitions is weakly-bipartitiveness. We obtain a similar corollary which allows one to
\operatorname{MSO}
-transduce a tree and additional structure that captures the bipartitions of a weakly-bipartitive system.

Corollary 6
.

There is an
\operatorname{MSO}
-transductions
\tau
such that, given any weakly-bipartitive system of bipartitions
(U,\mathcal{B})
modelled by the
\{\mathsf{BIPART}\}
-structure
\mathbb{B}
,
\tau
outputs the weakly-bipartitive tree
(T,\lambda,<)
of
(U,\mathcal{B})
.

Finally, we can apply
\cref
thm:main and the machinery from
[
4
]
to obtain transductions for the graph decompositions mentioned above whose underlying set system or system of bipartitions are weakly-partitive or weakly-bipartitive, repectively.

Corollary 7
.

There are non-deterministic
\operatorname{MSO}
-transductions
\tau_{1},\ldots,\tau_{4}
such that:

1.

Given any (directed) graph
G
as input,
\tau_{1}
outputs the modular decomposition
(T,F)
of
G
.

2.

Given any (directed) cograph
G
,
\tau_{2}
outputs the cotree
(T,\lambda)
of
G
.

3.

Given any (directed) graph
G
,
\tau_{3}
outputs a split decomposition
(T,F)
of
G
.

4.

Given any graph
G
,
\tau_{4}
outputs a bi-join decomposition
(T,F)
of
G
.

We believe that this line of research of considering transductions for simple, but dense tree-structured decompositions is important in the context of definability-equals-recognizability results. Notably, there are such results for trees
[
21
]
and graphs of bounded treewidth
[
2
]
which we can think of as sparse tree-structured decompositions. Additionally, there are definability-equals-recognizability results for dense graph classes in the case the decomposition used has a linear structure
[
1
,
5
]
. It is open, however, whether in graphs of bounded clique-width, for which
[
8
]
yields one direction, whether definability equals recognizability. In some sense, our results solve a restricted version of this major open problem.

Preliminaries

We denote by
[n]
for
n\in\mathbb{N}
the set
[n]=\{1,\dots,n\}
. A
partition

(P^{1},\dots,P^{\ell})
of a set
U
has to satisfy that the parts
P_{i}
are pairwise disjoint and their union is
U
but we do not require parts to be non-empty. For a partition
(P^{1},\dots,P^{\ell})
a
refinement
of
(P^{1},\dots,P^{\ell})
is a partition
(S^{1},\dots,S^{k})
such that each
S^{i}\subseteq P^{j}
for some
j\in[\ell]
.

We consider trees to be rooted and are therefore equipped with an ancestor-descendant relationship. We use the usual terminology regarding
parent, child
and
sibling
. We distinguish between
ancestors/descendants
of a node
t
that include
t
itself, and
proper ancestors/proper descendants
of
t
that are all ancestors/descendants except
t
.
In addition, for a tree
T
we denote the set of nodes by
V(T)
and the set of edges of
T
by
E(T)
.
For a tree
T
nodes of degree
1
are called
leaves
of
T
.
Each node in
T
that is not a leaf, we call an
inner node
.
For a tree
T
and a node
t\in V(T)
, we denote by
T_{t}
the subtree of
T
induced by all descendants of
t
.

2.1
Logic and transductions

In order to model set systems we consider extended relational structures which extend the usual notion of relational structures to allow the use of set predicates. An
extended relational vocabulary
is a set
\Sigma
of symbols each having an associated arity, denoted
\operatorname{ar}(Q)
for
Q\in\Sigma
, where each symbol is either a relational name or a set predicate name. An
extended relational structure
over
\Sigma
, or short
\Sigma
-structure
, is a tuple
\mathbb{A}=(U_{\mathbb{A}},(Q_{\mathbb{A}})_{Q\in\Sigma})
consisting of a finite set of elements
U_{\mathcal{A}}
, called the
universe
of
\mathbb{A}
, and an interpretation
Q_{\mathbb{A}}
of every
Q\in\Sigma
where
Q_{\mathbb{A}}
is a relation over
U_{\mathbb{A}}
if
Q
is a relational name and a relation over subsets of
Q_{\mathbb{A}}
if
Q
is a set predicate name. For two vocabularies
\Sigma
and
\Gamma
, and a
\Sigma
-structure
\mathbb{A}
and a
\Gamma
-structure
\mathbb{B}
we let the
union
, denoted
\mathbb{A}\sqcup\mathbb{B}
, be the
\Sigma\cup\Gamma
-structure with universe
U_{\mathbb{A}}\cup U_{\mathbb{B}}
and the interpretation
Q_{\mathbb{A}\sqcup\mathbb{B}}
of some symbol
Q\in\Sigma\cup\Gamma
being either
Q_{\mathbb{A}}
,
Q_{\mathbb{B}}
or
Q_{\mathbb{A}}\cup Q_{\mathbb{B}}

depending on whether
Q
belongs to
\Sigma\setminus\Gamma
, to
\Gamma\setminus\Sigma
, or to
\Sigma\cap\Gamma
.

We define syntax and semantic of
monadic second order logic
, short
\operatorname{MSO}
, in the usual way and refer, for example, to

[
7
,
15
,
17
,
20
]
for the definition of
\operatorname{MSO}
on extended relational structures.
\operatorname{MSO}
extends first-order logic introducing set variables and allowing quantification over set variables. To clearly identify the type of variables, we distinguish between
element variables
and
set variables
and use
lowercase letters, such as
r,x,y,z,\dots
, for element variables and uppercase letters, such as
R,X,Y,Z,\dots
, for set variables.
For a formula
\phi
, we write
\phi(x_{1},\dots,x_{\ell},X_{1},\dots,X_{k})
to indicate that the free element variables of
\phi
are
x_{1},\dots,x_{\ell}
and the free set variables of
\phi
are
X_{1},\dots,X_{k}
,
namely, the set of variables occurring in
\phi
that are not bound to a quantifier within
\phi
.
A
sentence
is a formula without any free variables. Where possible, we follow the convention that relational names and formulas with only free element variables are lowercase while set predicate names as well as formulas that have only free set variables receive uppercase names.

We use the following extended relational structures to model the structures used in this paper. We use vocabulary
\{\mathsf{SET}\}
where set is a set predicate name of arity
1
to model set systems. Naturally a set system
(U,\mathcal{F})
is modelled by the
\{\mathsf{SET}\}
-structure
\mathbb{F}
with universe
U_{\mathcal{F}}=U
and for which
\mathcal{F}
is the interpretation
\mathsf{SET}_{\mathbb{F}}
. Additionally, we use vocabulary
\{\mathsf{DESC}\}
to model trees. Here a tree
T
is modelled by the
\{\mathsf{DESC}\}
-structure
\mathbb{T}
with universe
U_{\mathbb{T}}=V(T)
and the interpretation
\mathsf{DESC}_{\mathbb{T}}
being the descendant relationship of
T
. Note that choosing the descendant relationship is arbitrary and the relations
\mathsf{ANC},\mathsf{CHILD}
and
\mathsf{PARENT}
can easily be defined in
\operatorname{MSO}
.

We note that
\operatorname{MSO}
is sufficient to define laminar sets systems.
Indeed, laminar set systems are exactly those that satisfy the
\{\mathsf{SET}\}
-formula

\displaystyle\exists U\forall x(x\in U\vee\mathsf{SET}(U))\bigvee\forall x\exists S\forall y(\mathsf{SET}(S)\vee\left[y\in S\leftrightarrow y=x\right])

\displaystyle\qquad\bigvee\forall F_{1}\forall F_{2}(\mathsf{SET}(F_{1})\wedge\mathsf{SET}(F_{2})\rightarrow\left[F_{1}\cap F_{2}=\emptyset\vee F_{1}\cap F_{2}=F_{1}\vee F_{1}\cap F_{2}=F_{2}\right]).

Transductions

Let
\Sigma
and
\Gamma
be two extended relational vocabularies.
A
\Sigma
-to-
\Gamma
transduction

is a set
\tau
of pairs formed by
a
\Sigma
-structure, call the
input
,
and a
\Gamma
-structure, called the
output
.
We write
\mathbb{B}\in\tau(\mathbb{A})
when
(\mathbb{A},\mathbb{B})\in\tau
.
When for every pair
(\mathbb{A},\mathbb{B})\in\tau

we have
\mathbb{A}\sqsubseteq\mathbb{B}
,
we call
\tau
an

overlay transduction
.
Transductions
are defined over some logic
\mathcal{L}
, such as
\operatorname{FO}
,
\operatorname{MSO}
or
\operatorname{CMSO}
. In this paper the ambient logic is
\operatorname{MSO}
and we therefore restrict the following definitions to this case.
We define an
\operatorname{MSO}
-transduction

to be a transduction obtained
by composing a finite number of
atomic
\operatorname{MSO}
-transductions

of the following kinds.

Colouring

A
k
-colouring tansduction
adds
k
new unary predicates
\mathsf{colour}_{i}
for every
i\in[k]
to the signature
\Sigma
while adding
k
new unary relations to the original
\Sigma
-structure
\mathcal{A}
interpreting the
k
additional predicates.
Any possible interpretation yields an output of the transduction.
Hence, it defines a total (non-functional) relation
from
\Sigma
-structures to
\Gamma
-structures
where
\Gamma=\Sigma\cup\{\mathsf{colour}_{i}\mid i\in[k]\}
.

Copying

A
k
-copying transduction
adds
k
copies of the universe of the original
\Sigma
-structure
\mathbb{A}
to
\mathbb{A}
while introducing new binary predicates
\mathsf{copy}_{i}(x,y)
for every
i\in[k]
which expresses that element
x
is the
i
-th copy of the original element
y
. Hence, this defines a function from
\Sigma
-structures to
\Gamma
-structures,
where
\Gamma=\Sigma\cup\{\mathsf{copy}_{i}\mid i\in[k]\}
. For sake of easier notation, we assume that a binary predicate
\mathsf{copy}_{0}(x,y)
is added which is satisfied for elements
x,y
if
x
is an original element and
y=x
(
y
is the original copy of
x
).

Filtering

A
filtering transduction
is specified by a sentence
\chi
and outputs the original
\Sigma
-structure
\mathbb{A}
if
\mathbb{A}
satisfies
\chi
.
Hence, a filtering transduction defines a partial function from
\Sigma
-structures to
\Sigma
-structures.

Interpretation

An
interpretation
is a transduction from
\Sigma
to
\Gamma
-structure for any signature
\Sigma
and
\Gamma
. An interpretation is specified by a tuple
(\phi,(\psi_{Q})_{Q\in\Gamma})
where
\phi
has one free variable and
\psi_{Q}
for any
Q\in\Gamma
has
\operatorname{ar}(Q)
free variables (which may be set variables if
Q
is a set predicate). For input
\Sigma
-structure
\mathbb{A}
the interpretation returns the
\Gamma
-structure whose universe consists of all elements of the universe of
\mathbb{A}
satisfying
\phi
and for which
Q
is interpreted by the set of all tuples satisfying
\psi_{Q}
for each
Q\in\Gamma
.
This defines a function from
\Sigma
-structures to
\Gamma
-structures.

We often refer to unary predicates as colours and therefore we describe
k
-colouring transductions as a colouring of the universe with
k
colours. Note that in such a colouring any element might receive multiple colours or even no colour at all.

In the following we show that we can easily obtain laminar set systems from their laminar trees by means of a transduction.

Lemma 8
.

For any laminar set system
(U,\mathcal{F})
with laminar tree
T
modelled by the
\{\mathsf{DESC}\}
-structure
\mathbb{T}
there is an
\operatorname{MSO}
-transduction
\tau
which on input
\mathbb{T}
produces the
\{\mathsf{SET}\}
-structure
\mathbb{F}
that models
(U,\mathcal{F})
.

Proof.

We can transduce the set system from the laminar tree using a single
\operatorname{MSO}
-interpretation.
We obtain the
\{\mathsf{SET}\}
-structure
\mathbb{F}
modelling
(U,\mathcal{F})
from
\mathbb{T}
by restricting the universe consisting of all nodes of
T
to just the leaves of
T
. Additionally, we can define the predicate
\mathsf{SET}
by a formula
\psi_{\mathsf{SET}}(X)
expressing that
X
is the set of leaves of the subtree
T_{t}
of
T
rooted at
t
for some node
t\in V(T)
. Specifically, we can implement this interpretation as follows:

\displaystyle\phi(x)

\displaystyle:=\forall y\big(\mathsf{DESC}(y,x)\rightarrow y=x\big),\text{ and }

\displaystyle\psi_{\mathsf{SET}}(X)

\displaystyle:=\exists y\forall x\big(\mathsf{DESC}(x,y)\leftrightarrow x\in X\big).

∎

Note by the Backwards Translation Theorem (
\cref
thm:backwards_translation), this means that any property of laminar set system that can be defined in the language of sets corresponds to a property of rooted trees definable in the language of rooted trees.

3
Transducing laminar trees

In this section we prove our main result, which consists in constructing a transduction that, given a laminar set system
(U,\mathcal{F})
outputs its laminar tree
T
.

Observe that the tree structure of the laminar tree is implicitly already given by the subset relationship.
But in the set system language we do not have any means of talking about the nodes of the laminar tree, and can only specify sets of leaves.
Indeed, the tricky part is to identify elements that can play the role of each node of the laminar tree
T
.
In order to achieve this, we partition the nodes of
T
into
17
sets.
For each of these parts, we will use a copy of the universe
U
to contain elements to play the roles of the nodes in this part.
We will call the element (in a copy of
U
) that plays the role of some node
t
of
T
the “realization” of the set
F\in\mathbb{F}
corresponding to the node
t
.
Any copy of an element can be the realization of at most one set.
One of the
17
parts will contain exactly the leaves of the tree
T
for which it is trivial to identify realizations. All other parts of the partition consist of a carefully chosen set of inner nodes. From now on, assume that
S
is one of the parts containing only inner nodes of
T
. To find realizations for all nodes in
S
, we first choose a subtree of
T
for each element
s\in S
, denoted
H_{s}
. We show that we can choose such trees to be pairwise disjoint if we choose
S
to be thin.
Thinness roughly enforces that we can always grow the representative tree of a node
t\in S
downwards in such a way that avoids
S
itself, which is crucial for guaranteeing disjointness of representative trees.

Besides choosing the representative trees disjoint, we also enforce them to have a particular structure. This structure allows us, given all the leaves of representative trees in
S
to pinpoint (by means of an
\operatorname{MSO}
-formula) exactly which leaves belong to the same representative tree. Hence, we can use a colouring-transduction to identify all possible choices of the leaves of the representative trees of nodes in
S
. We then filter which colourings correctly correspond to the set of leaves of representative trees. We chose an arbitrary leaf in the set of leaves of the representative tree of
s
to be the realization of the set
F
corresponding to
S
. Distinctness trivially follows from the disjointness of the representative trees. We then interpret, restricting the universe to only contain realizations of sets and introducing the descendant relationship through the subset relationship.

3.1
Representative sets

Let
(U,\mathcal{F}
be a laminar set system,
T
be the laminar tree of
(U,\mathcal{F})
and
L
the set of leaves of
T
. We equip
T
with a labelling
\delta_{T}:V(T)\rightarrow\{0,1,2,3\}
where a node of depth
d
in
T
is assigned label
d\mod 4
.

Let
s
be a node of
T
.
A
representative tree
of
s
is a subtree
H
of
T
with the following properties.

(RT1)

s
is the root of
H
.

(RT2)

If
\delta_{T}(s)\equiv\delta_{T}(t)\mod 2
for some
t\in V(H)
, then either
t
is a leaf of
T
or
H
contains exactly one child of
t
.

(RT3)

If
\delta_{T}(s)\not\equiv\delta_{T}(t)\mod 2
for some
t\in V(H)
, then either
t
is a leaf of
T
or
H
contains every child of
t
.

For a set
B\subseteq L
we call the parent of the least common ancestor of the leaves in
B
the
tip
of
B
. We call the minimum subtree of
T
which contains both
B
and the tip of
B
the
up-tree
of
B
, denoted
H_{B}^{\uparrow}
.
A
representative set
of a node
s
of
T
is a set
A_{s}
of leaves of
T
for which
s
is the tip and the up-tree
H_{A_{s}}^{\uparrow}
of
A_{s}
is a representative tree.

A set
S\subseteq V(T)\setminus L
of inner nodes of

is called

if there is
i\in\{0,1,2,3\}
such that the following properties hold.

(TS1)

\delta_{T}(s)=i
for every
s\in S
.

(TS2)

Every
s\in S
has a sibling which is not in
S
with the exception of the root of
T
.

(TS3)

The parent
t_{s}
of every
s\in S
has a sibling such that no child of
t_{s}
is in
S
with the exception of nodes
s\in S
that are children of the root of
T
.

We first prove that thinness is enough to choose disjoint representative trees for all nodes of the thin set. For this, the following observation is an important ingredient.

Observation 9
.

In the laminar tree
T
of any laminar set system
(U,\mathcal{F})
every inner node has at least two children.

Note that for the following lemma property (TS2) is not needed. We, however, require this property later.

consisting of the larger orange nodes and pairwise disjoint representative trees of the nodes in

Lemma 10
.

If
S\subseteq V(T)\setminus L
is thin, then we can choose representative sets
(A_{s})_{s\in S}
such that the representative trees
H_{A_{s}}^{\uparrow}
,
s\in S
are pairwise disjoint.

Proof.

Let
S\subseteq V(T)\setminus L
be a thin set and let
i\in\{0,1,2,3\}
be the index such that
\delta_{T}(s)=i
for every
s\in S
which exists by (TS1). Let
P
be the set of all nodes which are parents of a node in
S
. Note that every
p\in P
satisfies
\delta_{T}(p)\equiv i-1\mod 4
. We show that for every
s\in S
we can choose a representative tree
H_{s}
, which avoids all nodes in
P
(i.e. does not contain any node in
P
). This statement implies that the representative trees
H_{s}
are pairwise disjoint. Clearly, since
H_{s}
is a subtree of
T_{s}
for every
s\in S
by (RT1),
H_{s}
and
H_{s^{\prime}}
must be disjoint whenever
s,s^{\prime}\in S
are not in any ancestor-descendant relationship. If, on the other hand,
s\in S
is a proper ancestor of
s^{\prime}\in S
then
H_{s}
cannot intersect
T_{s^{\prime}}
(and hence cannot intersect
H_{s^{\prime}}
) since
H_{s}
avoids the parent of
s^{\prime}
.

We now describe how to construct
H_{s}
which avoids
P
for some fixed
s\in S
. We construct the tree
H_{s}
recursively, level by level. The
0
-th level of
H_{s}
consists of just

, which clearly avoids
P
. Assume that we have constructed
j
levels of
H_{s}
that avoid

and aim to construct the
(j+1)
-th level. We distinguish the following cases. First, assume
j\equiv i\mod 4
. In this case, for every node
t
on level
j
of
H_{s}
, which is not a leaf, we choose an arbitrary child
t^{\prime}
of
t
and add it to
H_{s}
. Note that the updated tree
H_{s}
clearly still avoids
P
as
\delta_{T}(t^{\prime})\equiv i+1\mod 4
for every newly added node
t^{\prime}
while nodes
p\in P
satisfy
\delta_{T}(p)\equiv i-1\mod 4
. Next, assume that
j\equiv i+1\mod 4
. In this case, for every
t
on level
j
of
H_{s}
, which is not a leaf of
T
, we add all children of
t
to
H_{s}
. Again, each newly added vertex
t^{\prime}
cannot be contained in
P
as they satisfy
\delta(t^{\prime})\equiv i+2\mod 4
. Next, we assume that
j\equiv i+2\mod 4
. In this case, for every node
t
on level
j
of
H_{s}
, which is not a leaf, we choose a child
t^{\prime}
of
t
which is not in
P
and add it to
H_{s}
. This choice is always possible, as
S
is thin and, therefore, every node
p\in P
must have a sibling that does not have children in

by (TS3) which implies that this child is not contained in

. Clearly, the updated tree

avoids
P
. Finally, assume

. For every node
t
on level
j
of
H_{s}
, which is not a leaf, we add all its children to
H_{s}
. The resulting tree
H_{s}
still must avoid
P
as each newly added node
t^{\prime}
satisfies
\delta_{T}(t^{\prime})=i
while nodes
p\in P
satisfy
\delta_{T}(p)\equiv i-1\mod 4
. Note that the tree
H_{s}
is a representative tree of

by construction because

is the root of
H_{s}
implying (RT1), for every node
t
on level
j
except leaves with
j\equiv i\mod 2
we added exactly one child of

to
H_{s}
implying (RT2) and for every node

on level
j
except leaves with

we added all children of
t
to
H_{s}
implying (RT3). For an illustration of the construction of representative trees of a thin set
S
we refer the reader to
\cref
fig:representativeSets.

We can now set

to be the leaves of
H_{s}
for every

. We argue that

. First note that because
s
is the root of
H_{s}
the least common ancestor of the leaves in
A_{s}
is some descendant of
s
. By construction, there is exactly one child
t
of
s
which is contained in
H_{s}
and therefore the least common ancestor of the leaves in

is indeed a descendant of

. Let

be the children of

and note that

by
\cref
obs:atLeastTwoChildren. By construction

are contained in
H_{s}
(as
\delta(t)\equiv i+1\mod 4
). Since both the subtree of
H_{s}
rooted at
t_{1}
and the subtree of
H_{s}
rooted at
t_{2}
must have a leaf and therefore an element of
A_{s}
, the least common ancestor of the leaves in
A_{s}
is

. Therefore the tip of
A_{s}
is
s
. Hence, by definition of up-tree, we know that

is a subtree of

as

contains all nodes in
A_{s}
and the tip of
A_{s}
. Furthermore, every node

contained in

must be in

because the subtree of

rooted at

must contain a leaf

which, by construction, is in

. Then the path from

to

implying that

. Since

is a representative tree,

is a representative set. Hence, we have chosen representative sets

with pairwise disjoint representative trees

proving the statement.
∎

We now aim to prove that given the union
A:=\bigcup_{s\in S}A_{s}
or representative sets of a thin set, the representative sets are uniquely defined. We further aim to characterize representative sets in such a way that we can later define them in

. For this we use the following terminology.

of leaves of

we say that an inner-node

is

(by

) if for every child

of

the set of leaves in the subtree of

with root

contains a leaf from

is

(by

) if there is exactly one child

of

for which the subtree of

contains a leaf from

. We say that

is

(by

contains no leaves from

.

Lemma 11
.

Let
S
be a thin set,
(A_{s})_{s\in S}
representative sets with pairwise disjoint up-trees

and

. For any

and any node
s
of

,

if and only if the following hold:

{romanenumerate}

,

is the tip of

if a descendant

of

or a leaf in

of

Proof.

We start by proving parts of the forwards direction of the statement.

Claim 12
.

For every
s\in S
the representative set
A_{s}
and node

satisfy conditions (i)-(iv).

{claimproof}

First, note that condition (i) is trivially satisfied. Additionally, (ii) is satisfied by the definition of representative sets.
By definition

is a representative tree.
Observe that for any node

of

there is some leaf

of

that is contained in

by the definition of representative trees. In particular, this implies that every node

and every node

Since every inner node

The essential property we use to prove the equivalence in the statement of the lemma is that the up-tree

is an induced subgraph of

{claimproof}

Let

Towards a contradiction assume the claim is not true and let

, but the edge

. Additionally,

3.2
The colouring

In this subsection, we describe the colouring we use for our transduction and introduce the predicate we obtain that identifies representative sets for all inner nodes. For this, we first show that we can partition the nodes of every laminar tree into a finite number of thin sets.

Let

be the laminar tree of a set system

and

Lemma 16

Proof.

Our goal is to define the conditions of

\operatorname{MSO}

To implement

. Hence, fix any unary predicate

representing a subset of

. For any

and the node corresponding to

\displaystyle\mathsf{fully}_{A}(X):=

\displaystyle\mathsf{SET}(X)\land\lnot\mathsf{LEAF}(X)\land\forall Y\Big(\mathsf{CHILD}(Y,X)\rightarrow\exists y\big(y\in Y\land A(y)\big)\Big),

\displaystyle\mathsf{single}_{A}(X):=

\displaystyle\mathsf{SET}(X)\land\lnot\mathsf{LEAF}(X)\land\exists Y\Big(\mathsf{CHILD}(Y,X)\land\exists y\big(y\in Y\land A(y)\big)\land

\displaystyle\phantom{aaaaaaaa}\forall Z\Big[\big(\mathsf{CHILD}(Z,X)\land\exists z\big(z\in Z\land A(z)\big)\big)\rightarrow Z=Y\Big]\Big),

\displaystyle\mathsf{missed}_{A}(X):=

\displaystyle\mathsf{SET}(X)\land\lnot\mathsf{LEAF}(X)\land\forall x\big(x\in X\rightarrow\lnot A(x)\big).

Since

is an identifying colouring for

each

is the union of representative sets
(A^{i}_{s})_{s\in S^{i}}
with pairwise disjoint up-trees

. Hence, by
\cref
lem:uniqueRepSets any set
R\subseteq U
and set

corresponding to inner node
s
of the laminar tree satisfy
R=A_{s}^{i}
if and only if they satisfy predicate
\mathsf{REP}_{A}^{\ast}(R,X)
defined below. Note that we first define the following auxiliary predicate
\mathsf{REP}_{A}(R,X)
which implements precisely conditions (i)-(iv) of
\cref
lem:uniqueRepSets and then
\mathsf{REP}_{A}^{\ast}(R,X)
extends
\mathsf{REP}_{A}(R,X)
to also include property (v). This is needed because property (v) states that set

is maximal among all sets for which there is a node and they satisfy (i)-(iv). We define
\mathsf{REP}_{A}(R,X)
as follows:

\displaystyle\mathsf{REP}_{A}(R

\displaystyle,X):=\mathsf{SET}(X)\land

\displaystyle\forall x(x\in R\rightarrow A(x))\land

(i)

\displaystyle\exists Y\Big(\mathsf{CHILD}(Y,X)\land R\subseteq Y\land\forall Y^{\prime}\big[\big(\mathsf{DESC}(Y^{\prime},X)\land R\subseteq Y^{\prime}\big)\rightarrow Y^{\prime}=Y\big]\Big)\land

(ii)

\displaystyle\forall Y\Big(\big(\mathsf{DESC}(Y,X)\land\mathsf{fully}_{A}(Y)\big)\rightarrow\forall Z\Big[\mathsf{CHILD}(Z,Y)\rightarrow\big(\mathsf{LEAF}_{A}(Z)\lor\mathsf{single}_{A}(Z)\big)\Big]\Big)\land

(iii)

\displaystyle\forall Y\Big(\big(\mathsf{DESC}(Y,X)\land\mathsf{single}_{A}(Y)\big)\rightarrow\exists Z\Big[\mathsf{CHILD}(Z,Y)\land\big(\mathsf{LEAF}_{A}(Z)\lor\mathsf{fully}_{A}(Z)\big)\land

\displaystyle\phantom{aaaaaaaaaaaaaaaaaaaaaaa}\forall Z^{\prime}\big((\mathsf{CHILD}(Z^{\prime},Y)\land Z^{\prime}\not=Z)\rightarrow\mathsf{missed}_{A}(Z^{\prime})\big)\Big]\Big).

(iv)

Note that each line of the formula above expresses precisely one condition from
\cref
lem:uniqueRepSets (excluding (v)) and we additionally have to ensure that

corresponds to a node and therefore is in
\mathcal{F}
. We define

as follow:

\displaystyle\mathsf{REP}_{A}^{\ast}(R,X):=\mathsf{REP}_{A}(R,X)\land\forall X^{\prime}\forall R^{\prime}\Big(\big(\mathsf{ANC}(X^{\prime},X)\land

\displaystyle\mathsf{REP}_{A}(R^{\prime},X^{\prime})\big)\rightarrow

\displaystyle\big(R^{\prime}=R\land X^{\prime}=X\big)\Big).

(v)

For a fixed

\displaystyle\mathsf{leader}_{i}(r,X):=B^{i}(r)\land\exists R\big(r\in R\land\mathsf{REP}_{A_{i}}^{\ast}(R,X)\big).

Note that since for fixed

3.3
The transduction

We have introduced all the tools to provide our transduction. We recall
\cref
thm:main here in a slighly different version. We note however that by a simple interpretation which forgets the
\mathsf{SET}
predicate, we can obtain the original version.

Theorem
2
.

There is an overlay
\operatorname{MSO}
-transduction
\tau
from
\{\mathsf{SET}\}
-structure to
\{\mathsf{desc},\mathsf{SET}\}
-structures such that for any laminar set system
(U,\mathcal{F})
represented by the
\{SET\}
-structure

the image of

is the
\{\mathsf{desc},\mathsf{SET}\}
-structure

where
\mathbb{T}
is the
\{\mathsf{desc}\}
-structure which represents the laminar tree

of
(U,\mathcal{F})
.

Proof of
\cref
thm:main.

Let
(U,\mathcal{F})
be a laminar set system and
\mathbb{F}
be the
\{\mathsf{SET}\}
-structure representing
(U,\mathcal{F})
.
Our
\operatorname{MSO}
-transduction is obtained by composing the following atomic
\operatorname{MSO}
-transductions.
To define the transduction, we use the formula constructed in
\cref
lem:leaderFormula.

1.

We first apply a
32
-colouring transduction to structure
\mathbb{F}
and obtain unary predicates
\mathsf{colour}_{1},\dots,\mathsf{colour}_{32}
.

2.

We use filtering to ensure that the colouring
\mathsf{colour}_{1},\dots,\mathsf{colour}_{32}
is essentially identifying leaders correctly. To achieve this, we need to check that for every set
X\in\mathcal{F}
there is precisely one
i\in\{0,\dots,16\}
and one

for which the predicate
\mathsf{leader}_{i}(r,X)
is satisfied. Furthermore, we need to ensure that for every
i\in\{0,\dots,16\}
and any two distinct sets

for which there are elements

such that
\mathsf{leader}_{i}(r,X)
and
\mathsf{leader}_{i}(r^{\prime},X^{\prime})
are satisfied, it holds that

. Note that we can express both these properties through an
\operatorname{MSO}
sentence

. By
\cref
lem:partitionThinSets and
\cref
lem:disjointRepSets there must always exist an identifying colouring while
\cref
lem:leaderFormula guarantees that if
\mathsf{colour}_{1},\dots,\mathsf{colour}_{32}
is an identifying colouring then the properties we filter by must be satisfied. Hence, for any laminar set system
\mathbb{F}
we must receive at least one output.

3.

Copy the resulting structure
16
times (resulting in
17
instances of each element of
U
),
thus introducing
16
additional binary relations
(\mathsf{copy}_{i})_{i\in\{0,\dots,16\}}

where
\mathsf{copy}_{i}(x,y)
for
i>0
indicates that
x
is the
i
-th copy
of the original element
y
and
\mathsf{copy}_{0}(x,y)
indicates that
x
is the original element
y
. Note that the original elements will represent the leaves of the laminar tree while the
i
-th copy of the leader of a set

will play the role of the node
t
corresponding to
X
in case the appropriate thin set

contains
t
.

4.

Finally, we interpret using a pair of formulas
(\phi,\psi_{\mathsf{DESC}})
to obtain a
\{\mathsf{DESC}\}
structure
\mathbb{T}
. For this we define the
realization
of a set

to be the
i
-th copy of the element

for which
\mathsf{leader}_{i}(r,X)
is satisfied. We define predicate
\mathsf{real}(x,X)
expressing that
x
is the relization of

as follows:

\displaystyle\mathsf{real}(x,X):=\exists r\Big(\bigvee_{i\in\{0,\dots,16\}}\big(\mathsf{leader}_{i}(r,X)\land\mathsf{copy}_{i}(x,r)\big)\Big).

Now
\phi
restrict the universe to elements which are the realization of some set in
\mathcal{F}
. We define the descendant relationship of
\mathbb{T}
as follows. For two elements

of the restricted universe,
\psi_{\mathsf{DESC}}
defines that

is a descendant of

if they are the realization of two sets

and

. Formally, let

\displaystyle\psi_{\mathsf{desc}}(x,x^{\prime}):=\exists X\exists X^{\prime}\Big(\mathsf{real}(x,X)\land\mathsf{real}(x^{\prime},X^{\prime})\land X\subseteq X^{\prime}\Big).

We are left to argue that the resulting structure
\mathbb{T}
represents the laminar tree

of
(U,\mathcal{S})
. For this we use the properties we ensured through filtering. First, we define a partition
(P^{0},\dots,P^{16})
of
\mathcal{F}
as follows. Set

to be contained in part

if and only if there is

there is precisely one

and one

.

3.4
Beyond laminar set systems

In this section we shortly outline how to adjust the proofs of
[
4
]
to obtain
\cref
cor:partitive,
\cref
cor:biPartitive and
\cref
cor:graphDecompositions.

We first note that the transductions used to obtain
[
4
, Theorem 1]
uses the
\operatorname{CMSO}
-transduction
\tau
which given a laminar set system outputs its laminar tree
[
4
, Theorem 2]
as a black box.
As stated in
[
4
]
, the other steps of the transductions in
[
4
, Theorem 1]
are
\operatorname{MSO}
-transductions. Roughly these transductions are of the form:

1.

An
\operatorname{MSO}
-interpretation that adds a predicate
\mathsf{SET}
to recognize sets corresponding to a side of a separations (for bipartitions we take the side not containing a fixed element).

2.

An
\operatorname{MSO}
-interpretation that adds a predicate
\mathsf{SET}!
that recognizes the sets that do not cross any other.

3.

As these sets are laminar, we can apply
\tau
to transduce tree-structure.

4.

An
\operatorname{MSO}
-interpretation that adds the information to the tree-structure that is necessary to recover the original object.

Thus, by using our new
\operatorname{MSO}
-transduction (
\cref
thm:main) within the transductions given in
[
4
]
directly yields
\cref
cor:partitive,
\cref
cor:biPartitive and
\cref
cor:graphDecompositions with the exception of the transduction outputting the bi-join decomposition of a graph.
Although this transduction does not rely on counting aside from obtaining the laminar tree, it uses the representative predicate
\mathsf{rep}_{A}(x,X)
which is defined within the transduction producing the laminar tree in a different way to the predicate given in this paper. The predicate is required for the following reason.

A bi-join of a graph
G
is a bipartition
\{X,Y\}
of
G
for which there exists subsets
X^{\prime}\subseteq X
and
Y^{\prime}\subseteq Y
such that
X^{\prime}
is complete to
Y^{\prime}
,
X\setminus X^{\prime}
is complete to
Y\setminus Y^{\prime}
and there are no further edges between
X
and
Y
. In the bi-join decomposition, an auxiliary vertex is introduced for each of the sets
X^{\prime},X\setminus X^{\prime},Y^{\prime}
and
Y\setminus Y^{\prime}
. However, structurally the bi-join is completely symmetric and therefore the representative of the node representing a particular bi-join in the decomposition is used to identify which of the sets
X^{\prime},X\setminus X^{\prime},Y^{\prime},Y\setminus Y^{\prime}
is associated with which of the auxiliary vertices. To conclude, we can easily use our predicate
\mathsf{leader}_{i}(r,X)
instead for this purpose.

4
Simulating counting quantifiers in laminar set system

In this section, we consider for which classes of laminar set systems the parity of a set is expressible over
\operatorname{MSO}
.
By Theorem
2
and Lemma
8
, we have transductions between laminar set systems and laminar trees, so by the Backwards Translation Theorem (Theorem
1
), it is equivalent to ask when we can
\operatorname{MSO}
-express the parity of a set of leaves.
Using the technique of Thatcher and Wright
[
21
]
, we show that if we have a rooted tree with bounded down-degree, then counting is definable over
\operatorname{MSO}
.

Theorem 17
.

Let
k
be a positive integer.
Let
\mathcal{T}_{k}
be the collection of rooted trees with down-degree at most
k
.
Then there is a unary set-predicate
\operatorname{EVEN-LEAF}_{k}
, that is
\{\mathsf{desc}\}
-definable over
\operatorname{MSO}
, where for any rooted tree
T\in\mathcal{T}_{k}
and any subset of the leaves
X
, we have
\operatorname{EVEN-LEAF}_{k}(X)
as true if
|X|
is even.

We first define some useful predicates in the vocabulary of rooted trees, which encode when a node is the root, when a node is a leaf, and when a node is a child of another. Let

\mathsf{root}(x):=\forall y\left(\mathsf{desc}(x,y)\rightarrow y=x\right),

\mathsf{leaf}(x):=\forall y\left(\mathsf{desc}(y,x)\rightarrow y=x\right),\text{ and}

\mathsf{child}(x,y):=\mathsf{desc}(x,y)\wedge\forall z\left(\mathsf{desc}(x,z)\wedge\mathsf{desc}(z,y)\rightarrow z=x\vee z=y\right).

Proof.

We capture the parity of
|X|
by considering it as a sum modulo two where we group terms according to
T
and have a set
S
keeping track of which partial sums are one mod two. We first require a way to express the sum of a bounded number of children.

Given a fixed positive integer
\ell
, there is an
\operatorname{MSO}
-expression for a node
v
having exactly
\ell
children in a set
S
, namely:

\operatorname{countkids}_{\ell}(v,S):=\exists s_{1}\dots\exists s_{\ell}\left(\bigwedge_{i\neq j}s_{i}\neq s_{j}\right)\wedge\forall x\left(x\in S\wedge\operatorname{child}(x,v)\longleftrightarrow\bigvee x=s_{i}\right).

So given a fixed positive integer
k
, in a rooted tree with degree at most
k
we have an
\operatorname{MSO}
-formula for a node
v
having an odd number of children in a set
S
by using the previous formula for all positive odd numbers less than
k
, namely:

\operatorname{oddkids}(v,S):=\bigvee_{\begin{subarray}{c}\ell\text{ odd}\\
\ell\leq k\end{subarray}}\operatorname{countkids}_{\ell}(v,S).

Now we express
|X|
being even by saying
there is a set of nodes
S
where: a leaf of the tree is in
S
if and only if it is in
X
, an internal node is in
S
if and only if an odd number of its children are in
S
, and the root is not in
S
.
Namely:

\displaystyle\operatorname{EVEN-LEAF}_{k}(X):=

\displaystyle\exists S\big(\forall\ell\left[\operatorname{leaf}(\ell)\rightarrow\left(\ell\in S\leftrightarrow\ell\in X\right)\right]\wedge

\displaystyle\qquad\forall v\left[\neg\operatorname{leaf}(\ell)\rightarrow\left(v\in S\leftrightarrow\operatorname{oddkids}(v,S)\right)\right]\wedge

\displaystyle\qquad\forall r\left[\operatorname{root}(r)\rightarrow r\notin S\right]\big).

The first two conditions certifies that
S
is exactly the nodes of the tree with an odd number of descendants in
X
;
