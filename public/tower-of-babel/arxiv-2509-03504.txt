Recognizing flag varieties and reductive groups
N. I. Shepherd-Barron

Abstract
Fix a flat and projective morphism X → Σ X\to\Sigma of schemes. We show, first, that any set of ℙ 1 {\mathbb{P}}^{1} -fibrations on X X defines a set of simple roots, a set of simple coroots and a Cartan matrix C C . Second, X X is an étale ℱ {{\mathcal{F}}} -bundle over some projective Σ \Sigma -scheme, where ℱ {{\mathcal{F}}} is the flag variety of the adjoint Chevalley group over 𝐒𝐩𝐞𝐜 ℤ {\mathop{\bf Spec\hskip 1.5pt}\nolimits}{\mathbb{Z}} defined by C C . In particular, if the simple roots generate NS ⁡ ( X / Σ ) ℚ \operatorname{NS}(X/\Sigma)_{\mathbb{Q}} and X X is cohomologically flat in degree zero over Σ \Sigma then X X is a form of ℱ {{\mathcal{F}}} . When X X is a smooth Fano variety over 𝐒𝐩𝐞𝐜 ℂ {\mathop{\bf Spec\hskip 1.5pt}\nolimits}{\mathbb{C}} all of whose extremal rays are accounted for by these fibrations this is due to Occhetta, Solá Conde, Watanabe and Wiśniewski. Third, we recover, in a uniform way, the isomorphism and isogeny theorems of Chevalley and Demazure: over any base a pinned reductive group is determined by its pinned root datum, and a p p -morphism of pinned root data determines a unique homomorphism of the corresponding groups.

\textstyle{{\cdots}\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\textstyle{{F^{i+1}}\ignorespaces\ignorespaces\ignorespaces\ignorespaces}

page is given by

of
