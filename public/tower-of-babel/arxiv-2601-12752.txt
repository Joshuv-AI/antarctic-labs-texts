SoundPlot: An Open-Source Framework for Birdsong Acoustic Analysis and Neural Synthesis with Interactive 3D Visualization
Naqcho Ali Mehdi, Mohammad Adeel, Aizaz Ali Larik

Abstract
We present SoundPlot, an open-source framework for analyzing avian vocalizations through acoustic feature extraction, dimensionality reduction, and neural audio synthesis. The system transforms audio signals into a multi-dimensional acoustic feature space, enabling real-time visualization of temporal dynamics in 3D using web-based interactive graphics. Our framework implements a complete analysis-synthesis pipeline that extracts spectral features (centroid, bandwidth, contrast), pitch contours via probabilistic YIN (pYIN), and mel-frequency cepstral coefficients (MFCCs), mapping them to a unified timbre space for visualization. Audio reconstruction employs the Griffin-Lim phase estimation algorithm applied to mel spectrograms. The accompanying Three.js-based interface provides dual-viewport visualization comparing original and synthesized audio trajectories with independent playback controls. We demonstrate the framework’s capabilities through comprehensive waveform analysis, spectrogram comparisons, and feature space evaluation using Principal Component Analysis (PCA). Quantitative evaluation shows mel spectrogram correlation scores exceeding 0.92, indicating high-fidelity preservation of perceptual acoustic structure. SoundPlot is released under the MIT License to facilitate research in bioacoustics, audio signal processing, and computational ethology. The complete source code, documentation, and demonstration data are publicly available at: https://github.com/naqchoalimehdi/SoundPlot-An-Open-Source-Framework-for-Birdsong-Acoustic-Analysis-and-Neural-Synthesis- .

II
Related Work

II-A

Birdsong Analysis Systems

Early computational approaches to birdsong analysis focused on spectrographic visualization and manual feature measurement
[
1
]
. Systems like Canary
[
13
]
and later Raven
[
14
]
provided graphical interfaces for spectrogram analysis but limited automated feature extraction capabilities. Sound Analysis Pro (SAP)
[
15
]
introduced automated measurements of acoustic similarity but remains Windows-only and proprietary.

More recent work has explored machine learning approaches. BirdNET
[
16
]
applies deep convolutional neural networks for species classification, achieving high accuracy but functioning as a black-box classifier rather than an analysis tool. Warblr
[
17
]
similarly focuses on detection and classification. In contrast, SoundPlot emphasizes transparent feature extraction and interactive exploration, making the analysis process interpretable and customizable.

II-B

Audio Feature Extraction

Mel-frequency cepstral coefficients (MFCCs)
[
18
]
have been the dominant feature representation in audio analysis for decades, originally developed for speech recognition and later adapted for music information retrieval
[
19
]
and animal vocalization analysis
[
20
]
. The key insight of MFCCs is their approximation of the human auditory system’s non-linear frequency perception.

Spectral features such as centroid, bandwidth, and rolloff provide complementary information about the timbral quality of sounds
[
21
]
. For birdsong specifically, pitch tracking is crucial due to the tonal nature of many vocalizations. The pYIN algorithm
[
10
]
improves upon the classic YIN algorithm
[
22
]
by adding probabilistic modeling, resulting in more robust pitch estimates for polyphonic and noisy signals.

II-C

Audio Synthesis and Phase Reconstruction

The Griffin-Lim algorithm
[
12
]
addresses the phase reconstruction problem in short-time Fourier transform (STFT) inversion. Given only the magnitude spectrogram, Griffin-Lim iteratively estimates the phase through consistency constraints, enabling audio reconstruction without explicit phase information. While neural vocoders like WaveNet
[
23
]
, WaveGlow
[
24
]
, and HiFi-GAN
[
25
]
achieve higher perceptual quality, they require substantial training data and computational resources. For analysis applications where deterministic, fast synthesis is preferred, Griffin-Lim remains widely used
[
26
]
.

II-D

Dimensionality Reduction and Visualization

Principal Component Analysis (PCA)
[
27
]
provides a linear projection for visualizing high-dimensional feature spaces. Non-linear methods like t-SNE
[
28
]
and UMAP
[
29
]
better preserve local structure but are more computationally intensive. For real-time visualization of acoustic trajectories, PCA offers a good balance of computational efficiency and interpretability.

Audio Processing Pipeline

The complete processing pipeline consists of five sequential stages:

Stage 1: Audio Loading.
The

Stage 2: Preprocessing.
The
AudioPreprocessor
applies:

•

Min-max normalization to [-1, 1] range

•

Optional trimming to 5-minute maximum duration for computational efficiency

•

Optional silence removal using energy-based thresholding

Stage 3: Feature Extraction.
The
FeatureExtractor
computes frame-level features with configurable window and hop sizes:

•

Spectral Centroid

\mu_{c}
: weighted mean of frequencies

•

Spectral Bandwidth

\sigma_{b}
: weighted standard deviation of frequencies

•

Pitch

f_{0}
: fundamental frequency via pYIN
[
10
]

•

MFCCs
: 13 coefficients capturing timbral characteristics

•

Additional features: spectral contrast, rolloff, zero-crossing rate

Stage 4: Neural Synthesis.
The
AudioSynthesizer
implements the analysis-synthesis loop:

1.

Compute mel spectrogram with 128 bands

2.

Apply pseudo-inverse of mel filterbank for linear spectrogram estimation

3.

Reconstruct audio via Griffin-Lim with 32 iterations

4.

Apply post-normalization

Stage 5: Visualization Mapping.
Time-series features are normalized to [0, 10] range and mapped to 3D Cartesian coordinates:

•

X-axis: Spectral Centroid (brightness)

•

Y-axis: Spectral Bandwidth (richness)

•

Z-axis: Pitch (fundamental frequency)

IV
Methodology

IV-A

Feature Extraction Mathematics

For an audio signal
x[n]
of length
N
sampled at rate
f_{s}=22050
Hz, we apply STFT with window size
W=2048
and hop size
H=512
samples:

X[k,m]=\sum_{n=0}^{W-1}x[mH+n]w[n]e^{-j2\pi kn/W}

(1)

where
w[n]
is a Hann window and
m
indexes frames.

The magnitude spectrum is:

S[k,m]=|X[k,m]|

(2)

Spectral Centroid:

\mu_{c}[m]=\frac{\sum_{k=0}^{K-1}f_{k}S[k,m]}{\sum_{k=0}^{K-1}S[k,m]}

(3)

where
f_{k}=k\cdot f_{s}/W
is the frequency of bin
k
.

Spectral Bandwidth:

\sigma_{b}[m]=\sqrt{\frac{\sum_{k=0}^{K-1}(f_{k}-\mu_{c}[m])^{2}S[k,m]}{\sum_{k=0}^{K-1}S[k,m]}}

(4)

Pitch Estimation:
We employ the pYIN algorithm
[
10
]
, which computes:

f_{0}[m]=\arg\max_{f}P(f|x[mH:mH+W])

(5)

where
P(f|x)
is the posterior probability distribution over pitch candidates.

IV-B

Mel Spectrogram Synthesis

The mel spectrogram is computed by applying a mel-scale filterbank
M\in\mathbb{R}^{B\times K}
with
B=128
bands:

S_{\text{mel}}[b,m]=\sum_{k=0}^{K-1}M[b,k]S[k,m]^{2}

(6)

Synthesis inverts this process. Given
S_{\text{mel}}
, we estimate the linear spectrogram via pseudo-inverse:

\hat{S}[k,m]=\sqrt{\sum_{b=0}^{B-1}M^{\dagger}[k,b]S_{\text{mel}}[b,m]}

(7)

where
M^{\dagger}=(M^{T}M)^{-1}M^{T}
is the Moore-Penrose pseudo-inverse.

The Griffin-Lim algorithm
[
12
]
iteratively refines phase estimates:

Initialize:
\hat{X}^{(0)}[k,m]=\hat{S}[k,m]

for

i=1
to
N_{\text{iter}}

do

\hat{x}^{(i)}[n]=\text{ISTFT}(\hat{X}^{(i-1)}[k,m])

\tilde{X}^{(i)}[k,m]=\text{STFT}(\hat{x}^{(i)}[n])

\hat{X}^{(i)}[k,m]=\hat{S}[k,m]\cdot\frac{\tilde{X}^{(i)}[k,m]}{|\tilde{X}^{(i)}[k,m]|}

end

for

return

\hat{x}^{(N_{\text{iter}})}[n]

We use
N_{\text{iter}}=32
iterations, which provides a good balance between quality and computational cost.

IV-C

Quality Metrics

We evaluate synthesis fidelity using four metrics:

Signal-to-Noise Ratio (SNR):

\text{SNR}=10\log_{10}\frac{\sum_{n}x[n]^{2}}{\sum_{n}(x[n]-\hat{x}[n])^{2}}

(8)

Waveform Correlation:

\rho_{\text{wave}}=\frac{\text{Cov}(x,\hat{x})}{\sigma_{x}\sigma_{\hat{x}}}

(9)

Spectral Correlation:

\rho_{\text{spec}}=\text{corr}(\text{vec}(S),\text{vec}(\hat{S}))

(10)

Mel Correlation:

\rho_{\text{mel}}=\text{corr}(\text{vec}(S_{\text{mel}}),\text{vec}(\hat{S}_{\text{mel}}))

(11)

The mel correlation is particularly important as it reflects perceptual similarity better than raw spectrogram correlation
[
19
]
.

VI
Web-Based Visualization Interface

The SoundPlot framework includes a modern web interface built with Three.js
[
30
]
for real-time 3D visualization. The interface design prioritizes accessibility and interactivity.

VI-A

User Interface Components

The interface consists of:

•

Dual-Viewport Display
: Split-screen showing original (left, cyan) and synthesized (right, magenta) acoustic trajectories simultaneously

•

Independent Playback Controls
: Separate play/pause buttons for each audio stream with visual pulse animation

•

3D Point Cloud
: Acoustic features rendered as connected spheres with color-coded pitch (blue = low, red = high)

•

Real-time Synchronization
: Points animate and glow to indicate current playback position

•

Orbital Controls
: Mouse-based camera manipulation for exploring trajectories from multiple angles

•

Download Section
: One-click access to all generated assets (audio files, figures, metadata)

VI-B

Implementation Details

The visualization uses WebGL through Three.js for hardware-accelerated rendering. Each acoustic frame is represented as a sphere with radius proportional to spectral energy. Points are connected by lines to show temporal continuity, and a glow effect highlights points within 300ms of the current playback time.

The implementation achieves 60 FPS rendering for trajectories with up to 5000 points on modern hardware, enabling smooth visualization of several minutes of audio.

VI-C

Session Management

Each analysis creates an organized session folder:

data/sessions/{audio_name}_{session_id}/

containing:

•

original.wav
: Processed input audio

•

synthesized.wav
: Griffin-Lim reconstruction

•

comparison.png
: Spectrogram comparison figure

•

analysis.png
: PCA feature space visualization

•

metadata.json
: Metrics, parameters, timestamps

This structure facilitates reproducibility and batch processing experiments.

VII
Discussion

VII-A

Strengths and Limitations

The primary strength of SoundPlot is its combination of transparency, modularity, and accessibility. Unlike black-box deep learning approaches, every processing step is interpretable and customizable. The web-based interface lowers the barrier to entry for non-experts.

Limitations include:

•

Synthesis Quality
: Griffin-Lim produces artifacts compared to neural vocoders, though it is deterministic and fast

•

Mono Processing
: Stereo information is discarded during preprocessing

•

Fixed Feature Set
: Current 3D mapping uses only three features; richer representations require dimensionality reduction

VII-B

Future Directions

Planned enhancements include:

1.

Integration of neural vocoders (MelGAN
[
31
]
, HiFi-GAN
[
25
]
) for higher-quality synthesis

2.

Automatic clustering and segmentation using HDBSCAN
[
32
]
for call-type classification

3.

Multi-species comparison interface for comparative bioacoustics

4.

Real-time streaming mode for live field recording analysis

5.

Export to standardized formats (e.g., Raven selection tables)

VIII
Conclusion

We have presented SoundPlot, an open-source framework for birdsong acoustic analysis combining classic signal processing with modern web-based visualization. The system demonstrates that effective analysis tools can be built using established techniques without requiring deep learning training, while maintaining interpretability and computational efficiency. By releasing the complete implementation under an open-source license, we aim to accelerate research in bioacoustics and lower barriers to computational analysis of animal vocalizations.
