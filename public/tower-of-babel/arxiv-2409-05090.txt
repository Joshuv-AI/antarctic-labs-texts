Cofiniteness and finiteness of associated prime ideals of generalized local cohomology modules
Alireza Vahidi, Ahmad Khaksari, Mohammad Shirazipour

Abstract
Let n n be a non-negative integer, R R a commutative Noetherian ring, 𝔞 \mathfrak{a} an ideal of R R , M M and N N two finitely generated R R -modules, and X X an arbitrary R R -module. In this paper, we study cofiniteness and finiteness of associated prime ideals of generalized local cohomology modules. In some cases, we show that H 𝔞 i ⁡ ( M , X ) \operatorname{H}^{i}_{\mathfrak{a}}(M,X) is an ( FD < n , 𝔞 ) (\operatorname{FD}_{<n},\mathfrak{a}) -cofinite R R -module and { 𝔭 ∈ Ass R ⁡ ( H 𝔞 i ⁡ ( M , X ) ) : dim ( R / 𝔭 ) ≥ n } \{\mathfrak{p}\in\operatorname{Ass}_{R}(\operatorname{H}^{i}_{\mathfrak{a}}(M,X)):\dim(R/\mathfrak{p})\geq{n}\} is a finite set for all i i . If R R is semi-local, we observe that Ass R ⁡ ( H 𝔞 i ⁡ ( M , N ) ) \operatorname{Ass}_{R}(\operatorname{H}^{i}_{\mathfrak{a}}(M,N)) is finite for all i i when dim R ( M ) ≤ 3 \dim_{R}(M)\leq{3} or dim R ( N ) ≤ 3 \dim_{R}(N)\leq{3} . Also, in some situations, we prove that H 𝔞 i ⁡ ( M , X ) \operatorname{H}^{i}_{\mathfrak{a}}(M,X) is an 𝔞 \mathfrak{a} -cofinite R R -module for all i i .

Theorem 2.1

Let

\operatorname{Ass}_{R}(\operatorname{H}^{i}_{\mathfrak{a}}(M,N))_{\geq n}

Proof.

(i). We first assume that
\dim_{R}(M)\leq n+2
. Set
\overline{M}=M/\Gamma_{\mathfrak{a}}(M)

\Gamma_{\mathfrak{a}}(\overline{M})=0

0\longrightarrow\overline{M}\overset{a}{\longrightarrow}\overline{M}\longrightarrow\overline{M}/a\overline{M}\longrightarrow 0

\operatorname{H}^{t}_{\mathfrak{a}}(\overline{M}/a\overline{M},N)\longrightarrow\operatorname{H}^{t}_{\mathfrak{a}}(\overline{M},N)\overset{a}{\longrightarrow}\operatorname{H}^{t}_{\mathfrak{a}}(\overline{M},N).

Thus
\dim_{R}(\operatorname{Hom}_{R}(R/Ra,\operatorname{H}^{t}_{\mathfrak{a}}(\overline{M},N)))\leq n+1
and so
\dim_{R}(\operatorname{H}^{t}_{\mathfrak{a}}(\overline{M},N))\leq n+1

[
8
, Exercise 1.2.28]

\operatorname{H}^{t}_{\mathfrak{a}}(\overline{M},N)
is an
\operatorname{FD}_{<n+2}

R
-module. From the short exact sequence

0\longrightarrow\Gamma_{\mathfrak{a}}(M)\longrightarrow M\longrightarrow\overline{M}\longrightarrow 0

and
[
22
, Lemma 2.5(c)]
, we have the exact sequence

\operatorname{H}^{t}_{\mathfrak{a}}(\overline{M},N)\longrightarrow\operatorname{H}^{t}_{\mathfrak{a}}(M,N)\longrightarrow\operatorname{Ext}^{t}_{R}(\Gamma_{\mathfrak{a}}(M),N)

which shows that
\operatorname{H}^{t}_{\mathfrak{a}}(M,N)
is an
\operatorname{FD}_{<n+2}

R
-module. Therefore
\operatorname{H}^{i}_{\mathfrak{a}}(M,N)
is an
(\operatorname{FD}_{<n},\mathfrak{a})
-cofinite
R
-module for all
i
from
[
26

.
