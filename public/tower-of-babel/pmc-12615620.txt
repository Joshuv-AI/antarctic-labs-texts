Combining K-fold cross validation with bayesian hyperparameter optimization for accuracy enhancement of land cover and land use classification
Authors: Pooya Heidari, Asghar Milan
Published: 2025

ABSTRACT
Land cover and land use (LCLU) information is crucial in different earth observation applications, such as environmental management, infrastructure planning, and urban development. Recently, deep learning has emerged as an effective technique for image processing and spatial analysis, with excellent accuracies in image classification. However, training deep learning models for LCLU classification using remote sensing data continues to be challenging. One of the main challenges when using deep learning techniques for remote sensing classification is determining the optimized hyperparameters. Bayesian hyperparameter optimization is considered to be one of the most effective methods for determining optimized hyperparameters. Therefore, this method was applied to find the optimal learning rate, gradient clipping threshold and dropout rate for ResNet18 model. Using these optimized hyperparameters to classify EuroSat dataset, the model’s overall accuracy was 94.19%. To improve the exploration of the search space for better learning rate, gradient clipping threshold, and dropout rate hyperparameters, Bayesian hyperparameter optimization was combined with K-fold cross validation. The ResNet18 model achieved 96.33% overall accuracy for classifying EuroSat dataset when using the hyperparameters obtained by this process. This improvement in overall accuracy demonstrates the effectiveness of combining Bayesian hyperparameter optimization with K-fold cross validation as an enhanced technique for finding optimized hyperparameters in remote sensing LCLU classification.

Introduction

LCLU information is an essential tool for studying various earth observation applications, such as land change patterns1, regional planning2, urban expansion3, infrastructure planning4, and environmental management5. This information describes the changes to the Earth’s surface and its effects on society and ecology6. Additionally, timely and accurate acquisition of this information at the national scale can be applied to both short-term land management and long-term economic planning7.

Recently, deep learning has become a powerful method for image processing and spatial analysis, which has shown high accuracies for image classification8. These methods achieved significant results in the fields of image analysis and image classification from remotely sensing data9. Deep learning techniques can model hierarchical feature representations, and LCLU information is described with such features. Consequently, deep learning models offer an effective approach for LCLU classification10. These models are able to learn distinctive and high-level semantic image features11. Providing such advantages, deep learning approaches can be employed for LCLU classification.

However, training deep learning models for LCLU classification using remote sensing images continues to be challenging task12. Determining the optimized hyperparameters is one of the major challenges when using deep learning methods for remote sensing applications13. The accuracy of the deep learning model can be improved by using the optimum hyperparameters; however, determining the optimized values is still difficult55.

Several studies demonstrated that K-fold cross validation can be an effective tool for different remote sensing applications. Gholinejad et al.15 determined the optimal Rational function coefficient for geometrical correction of high-resolution satellite images using particle swarm optimization with K-fold cross validation. Roy and Saha16 used K-fold cross validation (4-fold) to map the gully erosion susceptibility of the Hinglo River in India with ALOS and Landsat 8 datasets. Arabameri et al.17 used K-fold cross validation for mapping and predicting the susceptibility of land subsidence in the Semnan Plain of Iran. They used 3 folds for training and 1-fold for validating their proposed machine learning model. Ghorbanzadeh et al.18 used K-fold (4-fold) cross validation for mapping the subsidence susceptibility of the Marand plain in Iran. Chen et al.19 combined MODIS data with daily ground monitoring data of particulate matter smaller than 1 micron (PM1) to calculate PM1 concentrations throughout China from 2005 to 2014. The prediction ability was evaluated using a 10-fold cross-validation. Leggesse et al.20 used Landsat 8 images for predicting water quality of Lake Tana in Ethiopia with machine learning algorithms such as Support Vector Machine regression, Random Forest regression, XGBoost regression, AdaBoost regression, and Gradient Boosting regression. They also utilized K-fold (5-fold) cross validation to overcome data limitation and enhance the model’s accuracy.

Other researchers used K-fold cross validation with optimization methods to address the challenge of finding optimized hyperparameters. Soper21 presented a greedy K-fold cross validation for hyperparameter optimization. The proposed method reduced the time for searching for the optimized hyperparameters. Shebl et al.22 used Landsat 9 and PRISMA images for lithological mapping of the region near the Red Sea hills in Egypt. They used Random Forest machine learning algorithm for their image classification. They also used grid search hyperparameter tuning and K-fold evaluation technique for enhancing the model performance. Alonso-Sarría et al.14 evaluated machine learning methods for LULC classification of the Mar Menor Basin, which is located in Spain. They used multi-source data for this classification, which consisted of Sentinel-1, Sentinel-2, and LiDAR data from the study area. The machine learning models in this study consisted of Random Forest, Support Vector Machine, Multilayer Perceptron, and Convolutional Neural Networks. They also utilized K-fold cross validation (10-fold) to evaluate the impact of hyperparameter optimization on the 4 mentioned machine learning models accuracy.

According to some other research, the model’s architectural hyperparameters can be found through optimization. Azedou et al.23 employed three hyperparameter optimization to determine the best deep learning architecture for LCLU classification in Talassemtane National Park in northern Morocco. Random Search, Hyperband, and Bayesian Optimization were used as optimization techniques. The hyperparameters they optimized included the number of neurons, hidden layers, dropout rate, activation function, and optimizer. The classification was done using Sentinel-2 images, and the classes were forest, matorral, agricultural lands, built-up areas, limestone soil surfaces, and bare lands. The overall accuracy for these optimized models were 82.76%, 94.5%, and 89.42%, respectively. In another study, Azedou et al.24 used genetic algorithm to determine the optimum hyperparameters of a Random Forest model. The hyperparameters were the number of trees, maximum tree depth, features considered per split, minimum samples per node, and maximum leaf nodes. They applied this optimized model to classify Sentinel-2 images from Talassemtane National Park and it achieved 96.2% in overall accuracy.

These studies indicated that K-fold cross validation is a powerful method in remote sensing applications, and it can be used with greedy and grid search to obtain optimized hyperparameters. Compared to grid or greedy search, Bayesian optimization allows for more efficient and probabilistic exploration of the hyperparameter space, as a result, we optimized hyperparameters using Bayesian method. In this study, we utilized K-fold cross validation combined with Bayesian optimization to optimize hyperparameters for LCLU classification. In this method, the training data were split into four folds, and the hyperparameters of dropout rate, gradient clipping threshold, and learning rate were determined in each fold. In this method, the optimization process will be carried out using different folds of training and validation sets, allowing the optimization’s search space to be explored more efficiently. Finally, the fold’s hyperparameters with the best validation accuracy will be used to train the model for LCLU classification, resulting in higher accuracies.

To assess whether the proposed strategy provided better hyperparameters for LCLU classification, the model that used the hyperparameters obtained by combining K-fold cross validation with Bayesian optimization was compared to the model that used the hyperparameters acquired by Bayesian optimization without K-fold cross validation. The results show that the proposed approach to hyperparameter optimization yields better hyperparameters than the model without K-fold cross validation. In comparison to the technique without K-fold cross validation, the hyperparameters of the proposed method improved classification accuracy by 2.14%.

Materials and methods

Eurosat dataset

The final accuracy of a deep learning model is substantially impacted by the selection of a suitable dataset, as deep learning models require a proper dataset for training25. Recently, several datasets for LCLU classification have been generated26. The EuroSat dataset is among the datasets used for LCLU classification. This dataset’s images were collected from Sentinel-2 A satellite imagery. There are 13 bands on this satellite, and the red, green, and blue bands have a spatial resolution of 10 m. There are 27,000 images in this dataset, divided into 10 classes, with two to three thousand images in each class. This dataset’s classes include annual crop, forest, herbaceous vegetation, highway, industrial areas, pasture, permanent crops, residential, river and sea/lake. Each image has a 64 × 64 pixel size27. ResNet architecture

The accuracy of a classification task can be significantly affected by selecting a suitable model for LCLU classification. One convolutional neural network model which demonstrated good classification accuracy for remote sensing images is the ResNet architecture. The ResNet18 model was chosen in this study to classify the EuroSat dataset due to its excellent accuracy in remote sensing applications, primarily remote sensing image classification.

ResNet architecture includes several convolutional layers with a shortcut connection. To skip some of the convolutional layers, a shortcut connection was added28. ResNet architecture has proven to be an effective model for various computer vision tasks, including the classification of remote sensing images29.

Model performance enhancement methods

Data augmentation

To achieve high accuracies, deep learning models need a substantial amount of labeled training data30. However, it’s not always possible to gather a large amount of data, and training the network with insufficient data results in a model with poor accuracy and generalization31. Typically used for training data during the network training stage, the data augmentation technique is the primary answer for this issue of data scarcity in deep learning models32. Data augmentation techniques used in this study included rotation, zooming, and flipping both horizontally and vertically.

Gradient clipping

The model’s training process may be interrupted by problems including vanishing and exploding gradients33. One helpful method for avoiding vanishing and exploding gradients is the gradient clipping technique. By employing a threshold value to control the gradient values, this method avoids the gradient values from increasing over the threshold value34. If a gradient value goes up above a certain threshold during the training stage, it will be clipped. As a result, the threshold value is the greatest value that a gradient may have, and any value that exceeds this value, it will be clipped35. But there are still challenges to use the gradient clipping approach as well. The training process can be considerably impacted by the threshold value37. If the gradient clipping threshold is set too high, gradient clipping won’t be applied since the gradient value will always be less than the threshold. On the other hand, if the threshold is set too low, the network training step size might get extremely small, which would make the model training process take too long38.

The model’s fitting abilities can be enhanced by using a higher threshold, but noisy gradients are not minimized. Furthermore, choosing a low threshold restricts noisy gradients while reducing the model’s fitting abilities39. Consequently, it is necessary to optimize the gradient clipping threshold40, and it needs to be selected automatically in order to prevent unnecessary computing expenses.

Early stopping

Early stopping is a method that stops training when the model reaches its maximum level of generalization41. When the validation loss does not improve over a specific number of epochs, early stopping stops model training.

Dropout

Regularization techniques are one of the most efficient ways to prevent deep learning models from overfitting42. Dropout is a popular, widely used, and successful regularization technique43. The typical range for the dropout rate is 0.2 to 0.5. Finding the optimum dropout rate remains a challenge. While evaluating values between 0.2 and 0.5 in the deep learning model can yield the optimal dropout rate, this method is computationally costly and takes a long time to find the optimal and appropriate number. Therefore, it is essential to discover this hyperparameter using an automated technique.

Learning rate optimization

The learning rate is an important hyperparameter in deep learning models. Determining an effective learning rate is challenging since choosing a value that is too low will result in a long learning process with a large learning error, while selecting a high value will lead to rapid learning without achieving model generalization44. As a result, determining the optimized learning rate for deep learning models is critical for achieving higher accuracies.

Bayesian hyperparameter optimization

One of the most powerful techniques for deep neural network hyperparameter optimization is Bayesian optimization. Finding the model’s parameters that work best on validation data is the primary objective of hyperparameter optimization, which also increases the model’s accuracy on test data. Tuning the hyperparameters manually is computationally inefficient and time-consuming. When the search space is discontinuous, the data is noisy, the functions are non-convex, and the derivatives are challenging to get, Bayesian optimization works effectively45,46. The acquisition function and the Gaussian process are the two main components of Bayesian optimization.

The Gaussian process is a generalization of the Gaussian probability distribution that originated from the Gaussian random process and Bayesian learning theory. Every finite set of random variables has a multivariate Gaussian distribution, making the Gaussian process a stochastic process. The basic assumption of this procedure is that similar inputs yield similar outputs, and it considers a statistical model of the function47.

By determining the location of the next sample, acquisition functions in Bayesian optimization direct the search for the objective function’s optimal value. The acquisition function’s purpose is to achieve a balance between exploration and exploitation in optimization48.

One of the best acquisition functions for achieving a balance between exploration and exploitation throughout the optimization process is the upper confidence bound acquisition function. Equation 2 describes this function:2\documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\:UCB=\mu\:\left(x\right)+\:\beta\:\sigma\:\left(x\right)$$\end{document}

where β is a parameter that, when increased, causes the algorithm to explore more, and when lowered, causes it to exploit more. The variables µ(x) and σ(x) represent the predicted output’s mean and standard deviation, respectively.

In this study, Bayesian hyperparameter optimization was used in two ways to obtain the optimal values for learning rate, dropout rate, and gradient clipping threshold. The first technique employed Bayesian hyperparameter optimization without K-fold cross validation, while the second used Bayesian hyperparameter optimization with K-fold cross validation to enhance search space exploration for the optimized hyperparameters. The upper confidence bound acquisition function was employed in each of these optimizations, and β was set at 2.6 to provide a balance between exploration and exploitation.

K-fold cross validation

In the K-fold cross validation procedure divides the data into k folds, with each fold repeatedly serving as a validation set for a candidate model trained on the data from the remaining folds. The model is then put through an iterative evaluation process once the data has been divided into k folds. The candidate model is trained using k-1 of the folds during each evaluation iteration, and the remaining fold is used to assess the model’s performance. This procedure is done until every fold is used as a validation set exactly once, giving each candidate model a total of k training and validation iterations49.

In this work, we employed K-fold cross validation with folds set to 4, as well as Bayesian hyperparameter optimization, to determine the optimized values for learning rate, dropout rate, and gradient clipping threshold. In this way, better hyperparameters were determined and the search space of hyperparameter optimization was explored more effectively.

The optimization and loss function

The loss function calculates the difference between the value predicted by the model and the actual value50. The sparse categorical cross-entropy loss function can be applied to the classification of remote sensing images. Additionally, it is the optimizer’s duty to minimize the loss function’s value during training. One of the most popular optimizers in the deep learning field is the Adam optimizer. This optimizer facilitates model convergence, reduces fluctuations during training, and is resistant to noisy gradients51. In this study, sparse categorical cross-entropy was applied to calculate the loss of the classification process, and the Adam optimizer was used to minimize this loss.

Image preprocessing and data prepration

Images from the Eurosat collection were resized into 224 by 224 pixels, then these images were normalized, and allocated grayscale values ranging from 0 to 1. Following that, this dataset was divided into test, validation, and training sets. The training data, which made up 70% of the dataset, was used to train the ResNet18 network. During training, the model was evaluated using the validation data, which included 20% of the total data. The accuracy of the model was assessed using the test data, which makes up 10% of the total data. The batch size was also set at 64 images.

Optimizing the model without K-fold cross validation

For Bayesian hyperparameter optimization without K-fold cross validation, the training and validation datasets were split up, which comprises 75% and 25% of the training data, respectively. This procedure included 100 trials, each involving 200 epochs. Early stopping was employed during these 200 training epochs. If the validation loss did not improve after 10 epochs, the hyperparameter search procedure stopped and the optimization process continued with the next trial. Figure 5 displays the entire process carried out at this stage.

After the hyperparameter optimization procedure was done, the two training and validation datasets for hyperparameter optimization were concatenated and transformed back into training data before being split up. The ResNet18 model was trained using this training data for to classify the EuroSat dataset. Optimized learning rate, dropout rate, and gradient clipping threshold hyperparameters were utilized in the ResNet18 model for classifying EuroSat dataset. This model also used augmentation and early stopping methods in the training stage to prevent overfitting. If the validation data loss did not decrease after 10 epochs, the training would be stopped.

Optimizing the model with K-fold cross validation

In this model, the training data were split into four folds, and the hyperparameters of dropout rate, gradient clipping threshold, and learning rate were determined in each fold using Bayesian hyperparameter optimization. The hyperparameters in the fold with the best validation accuracy throughout the optimization process were selected for the training procedure. Figure 6 shows the process of combining K-fold cross validation with Bayesian hyperparameter optimization.

Fig. 6Combining K-fold cross validation with Bayesian hyperparameter optimization.

Combining K-fold cross validation with Bayesian hyperparameter optimization.

Using K-fold cross-validation during optimization improves search space exploration because, unlike the traditional approach, which validates on a fixed split of the training data, K-fold cross validation ensures that the model has been evaluated on multiple, distinctive subsets. This variation in validation data among folds enables the optimization to generalize more effectively by going through a broader range of data scenarios. As a consequence, the search space is explored more efficiently.

Similar to the previous model, this process comprised 100 trials, each with 200 epochs, but these 100 trials were divided into 25 trials in each fold, meaning that each fold had 25 trials for hyperparameter optimization. During these 200 training epochs, early stopping was used. Like to the earlier model, the hyperparameter search process stopped and the optimization process proceeded with the next trial if the validation loss did not improve after 10 epochs. The whole procedure followed at this stage is shown in Fig. 7.

The training data which was used in the optimization process was converted back into the original training dataset after the hyperparameter optimization process was ended. This original training dataset was used to train the ResNet18 model, which was employed for classifying the EuroSat dataset. To improve the ResNet18 classification accuracy, optimized learning rate, dropout rate, and gradient clipping threshold hyperparameters—obtained by combining hyperparameter optimization with K-fold cross validation—were utilized. This model utilized data augmentation and early stopping methods in the training stage. Training would be stopped after 10 epochs if the validation data loss did not decrease.

Discussion

In this study, we developed an improved method for determining hyperparameters such as learning rate, gradient clipping threshold, and dropout rate. Better hyperparameters for LCLU classification were found and the search space of the optimization was more effectively explored by combining Bayesian hyperparameter optimization with K-fold cross validation. We compared the suggested approach with the model that did not employ K-fold cross validation with Bayesian optimization to see if the proposed method had better hyperparameters for LCLU classification. The overall accuracy of the proposed method was 96.33%, while the model without K-fold cross validation achieved 94.19%. Various K-fold cross-validation procedures, such as 4-fold, 5-fold, and 10-fold approaches, were frequently used in previous studies. Our study used 4-fold cross-validation as a practical compromise between accuracy and efficiency due to computational limitations. We suggest evaluating 5-fold and 10-fold cross-validation techniques in the context of hyperparameter optimization for further study. Investigating the effects of various K-fold configurations could provide useful information about model stability and generalization performance.

As it can be seen in Fig. 9, the model without K-fold cross validation exhibited misclassification in the vegetation classes. Specifically, this model predicted 8 images of annual crop as permanent crop, and 21 instances of herbaceous vegetation were classified as permanent crop. Furthermore, 16 images of the pasture class were misclassified as forest, and 10 images of permanent crop were predicted as herbaceous vegetation. These misclassifications represent the most frequent sources of error, primarily due to their high visual similarity in the EuroSat dataset. In the proposed method, the model classified 7 images of herbaceous vegetation as permanent crop and 13 images of permanent crop as herbaceous vegetation. These represent the most frequent misclassifications, which can be attributed to the high visual similarity between these two land cover classes in the EuroSat dataset. As we used the RGB version of EuroSat data set, the visual similarity between vegetation classes were the main sources of error and misclassification in both models. The issue of misclassification in vegetation classes can be resolved by using the 13-band dataset from EuroSat. By using stratified K-fold cross validation, the difference between the accuracy of vegetation classes and other classes, such as sea and lake, can be addressed. For hyperparameter optimization, this approach can assist in balancing the representation of various class types across each fold. In this study we used RGB version of EuroSat dataset and the proposed method has some difficulty in classifying vegetation classes. The 13-band version of EuroSat can be utilized to improve findings and stratified K-fold cross validation can be applied to Bayesian optimization to address the problem of higher accuracies for vegetation classes.

Some previous works, such as Azedou et al.23, used Hyperband and Bayesian optimization to optimize the model’s architectural hyperparameters. The optimized models achieved 94.5% and 89.42% overall accuracy for LCLU classification by employing these optimization techniques. This exhibits the efficacy of Hyperband and Bayesian optimization for optimization. Azedou et al.24 employed a Genetic algorithm in a different study to determine the Random Forest model’s hyperparameters for LCLU classification. They obtained an overall accuracy of 96.2%. In our study we used K-fold cross validation with Bayesian optimization to obtain optimized hyperparameters of learning rate, gradient clipping threshold and dropout rate for enhancing classification of EuroSat dataset and achieved 96.33% in overall accuracy. This showed the effectiveness of the proposed method for hyperparameter optimization. Further hyperparameter optimization, including the ResNet18 architecture hyperparameters, was not feasible due to computing resources. The model can be further improved to achieve higher LCLU classification accuracies by using architectural hyperparameters in addition to learning rate, dropout rate, and gradient clipping threshold. By incrementally adding additional architectural hyperparameters into the search space, we allow a more comprehensive study of the model’s design space. This search space expansion provides the chance to see how different hyperparameter settings affect classification accuracy, which could result in better performance and a better understanding of the behavior of the model. Consequently, using K-fold cross validation when combined with other hyperparameter optimizations such as Genetic algorithms and Hyperband optimization, as well as adding architectural hyperparameters, may lead to better results.

The balance between higher classification accuracy and higher computing cost during hyperparameter optimization is one of the key trade-offs observed in this study. The proposed method increased the optimization time to 9 h and 54 min, while the baseline model took 8 h and 57 min to be completed. The processing time has increased by 57 min as a consequence. The suggested method improved classification accuracy by 2.14% in spite of the extra optimization time. This shows that the extra computational resources and time spent on hyperparameter tuning were justified by a measurable improvement in performance. Furthermore, the baseline model was trained using a T4 GPU, which took 42 min and 31 s for 37 training epochs, while the proposed approach utilized an A100 GPU, which took 32 min and 21s for 62 epochs. This demonstrates how training time can be impacted by the use of various GPUs.

The broader applicability of combining Bayesian optimization and K-fold cross validation can be examined using the high-resolution remote sensing datasets like AID and UC Merced. High-resolution remote sensing datasets such as AID and UC Merced need a robust model for LCLU classification. Therefore, more hyperparameters need to be optimized for the model so as to obtain robust models. In order to get high accuracies from more robust models and broaden the applicability of the proposed approach, we suggest classifying high-resolution datasets using the proposed approach and adding other hyperparameters, like architectural hyperparameters. This increases the search space and allows us to obtain a robust model for LCLU classification.

Conclusion

LCLU information is an important tool for evaluating a variety of earth observation applications. Deep learning approaches have shown to be highly effective in this field of study, with excellent outcomes. However, it is still challenging to train deep learning models for LCLU classification using remote sensing images. Finding the optimized hyperparameters is a significant challenge when using deep learning techniques to remote sensing applications. Using optimum hyperparameters can improve the deep learning model’s accuracy, but determining the optimal hyperparameters is still challenging. An enhanced approach to determine the optimal hyperparameters—learning rate, gradient clipping threshold, and dropout rate—was used in this work to classify the EuroSat dataset. This approach uses Bayesian hyperparameter optimization with K-fold cross-validation to find the optimal hyperparameters. This approach will enhance the search space exploration for appropriate hyperparameters. To determine if the proposed method found better hyperparameters, the model with K-fold cross validation was compared to the model without K-fold cross validation for hyperparameter optimization. Both models used early stopping and data augmentation techniques to improve training stage performance and avoid overfitting. The model that employed K-fold cross validation in the hyperparameter optimization stages performed better than the other model, with an overall accuracy and kappa coefficient of 96.33% and 0.9592, respectively. The model that combined Bayesian optimization with K-fold cross validation could not be tested on other datasets due to computational resource limitations. For wider applicability, we recommend testing this approach using other remote sensing datasets like UC Merced and AID datasets. Additionally, we were unable to optimize architectural hyperparameters due to this constraint. In order to improve LCLU accuracies, we recommend employing other advanced models for future research, such as using Vision Transformer model with architectural hyperparameter optimization with K-fold cross validation.
