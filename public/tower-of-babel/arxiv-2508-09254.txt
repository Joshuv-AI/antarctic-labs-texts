Quantifying non-invertible chiral symmetry breaking
Finn Gagliano

Abstract
It has recently been suggested that the chiral symmetry of the Standard Model is not explicitly broken by its ABJ anomaly, but is instead made non-invertible. In this work, I quantify the breaking of non-invertible symmetries of this type by calculating the symmetry breaking scales and effective charges q ⁡ ( r ) q(r) originally studied for continuous invertible higher-form symmetries. As an example I consider the explicit breaking of the chiral symmetry of massless QED by introducing Yukawa couplings between the electron and a massive real scalar in the UV. I briefly comment on how one might quantify the breaking of general non-invertible symmetries.

For (non-invertible) higher-form symmetries, the standard way for the symmetry to be broken is to consider adding additional matter to the theory that screens the charged extended operators to the identity. II
Non-invertible symmetry breaking scales

A prominent class of non-invertible symmetries are given by so-called ABJ-like symmetries, where a would-be conserved current for a continuous
p
-form symmetry is violated:

d*j_{p+1}=V_{k+1}\wedge W_{d-p-k-1}

(1)

where
V_{k+1},W_{d-p-k-1}
are closed forms that obstruct us from obtaining an invertible symmetry. The operator we would define for the
p
-form symmetry,

\mathcal{U}_{\alpha}(\Sigma_{d-p-1})=e^{i\alpha\int_{\Sigma}*j},

(2)

is then non-topological - if we consider a smooth deformation of
\Sigma
to some other
\tilde{\Sigma}
then we get

\mathcal{U}_{\alpha}(\tilde{\Sigma})-\mathcal{U}_{\alpha}(\Sigma)=e^{i\alpha\int_{(\Delta\Sigma)_{d-p}}d*j_{p+1}}\neq 1

(3)

so that correlation functions depend dynamically on
\Sigma
. Thus, this operator does not define a symmetry of our system.

However, suppose we can locally write

V_{k+1}=dv_{k},

(4)

or similar for
W
, so that we can rewrite (
1
) as

d(*j_{p+1}-v\wedge W)=0

(5)

to obtain a modified conserved current. Then, we can define a
topological
operator

\tilde{\mathcal{U}}_{\alpha}(\Sigma_{d-p-1})=e^{i\alpha\int_{\Sigma}*j-v\wedge W}.

(6)

On general
\Sigma_{d-p-1}
,
v_{k}
might be subject to large gauge transformations

v_{k}\rightarrow v_{k}+\lambda_{k},\ \int\lambda_{k}\neq 0,

(7)

so that (
6
) is not gauge invariant if
\int W\neq 0
. A way to circumnavigate this is to ‘stack’ a
(d-p-1)
-dimensional TQFT
\mathcal{A}_{\alpha}(\Sigma)
onto the operator, with
\mathcal{A}_{\alpha}
transforming in the opposite way under gauge transformations
Cordova and Ohmori 2023
;
Choi et al. 2022b
:

\widehat{\mathcal{U}}_{\alpha}(\Sigma)=\mathcal{A}_{\alpha}\otimes\tilde{\mathcal{U}}_{\alpha}(\Sigma)

(8)

so that this is then a topological gauge-invariant operator, and therefore defines a valid symmetry of our theory. However, the minimal choice of
\mathcal{A}_{\alpha}
can in general be a
non-invertible
TQFT, i.e. there is no other TQFT that we can multiply this by to obtain the identity. Thus, symmetries of this type become non-invertible due to the stacking with non-invertible TQFTs.

III
QED chiral symmetry

I now wish to consider the example of the
U(1)_{\chi}
symmetry in massless QED. Consider the 4d Lagrangian

\mathcal{L}=\frac{1}{2e^{2}}F\wedge*F+i\bar{\psi}\not{D}\psi

(17)

where
\psi
is the unit charge electron, represented as a Dirac fermion. The Lagrangian is invariant under an invertible chiral
U(1)_{\chi}
transformation:

\psi\xrightarrow{U(1)_{\chi}}e^{i\alpha\gamma_{5}}\psi,\ \bar{\psi}\xrightarrow{U(1)_{\chi}}\bar{\psi}e^{-i\alpha\gamma_{5}},

(18)

which acts on left and right-handed fermions with opposite sign. The current for this symmetry is

j_{\mu}=\bar{\psi}\gamma_{\mu}\gamma_{5}\psi

(19)

and it is conserved classically. However, when we quantise the theory, the path integral measure is
not
invariant under the symmetry due to instanton effects, and so the current conservation is violated in the quantum theory:

d*j_{1}=F\wedge F.

(20)

The would-be symmetry operator for the original current is given as

\mathcal{U}_{\alpha}(\Sigma_{3})=e^{2\pi i\alpha\int_{\Sigma}*j}

(21)

which is not topological due to the current violation. However, locally we can write the above current violation as

d(*j-A\wedge dA)=0

(22)

such that we can instead define a topological operator

\tilde{\mathcal{U}}_{\alpha}=e^{2\pi i\alpha\int*j-A\wedge dA}.

(23)

However, this is not invariant under large gauge transformations:
A\rightarrow A+\lambda
where
\int\lambda=N\in\mathbb{Z}
gives a variation

\mathcal{U}_{\alpha}\rightarrow e^{2\pi i\alpha N}\mathcal{U}_{\alpha}

(24)

so that this is not gauge invariant unless
\alpha=\frac{p}{N}
for
p\in\mathbb{Z}
. This is precisely the issue regarding the
\mathbb{Q}/\mathbb{Z}
symmetry that we discussed qualitatively in the previous section. To retain the whole
U(1)_{\chi}
, we can stack
Karasik 2023
;
García-Etxebarria and Iqbal 2023

\mathcal{A}_{\alpha}=\int[\mathcal{D}\theta]e^{2\pi i\alpha\int d\theta\wedge dA}

(25)

where
\theta
is a compact boson with
d\theta
transforming in the same way as
A
under large gauge transformations, thus cancelling the gauge variance of
\tilde{\mathcal{U}}_{\alpha}
. As discussed above, it was shown in
Karasik 2023
;
García-Etxebarria and Iqbal 2023
that this vanishes unless
\alpha\int dA=0
. If we have
H^{1}(\Sigma_{3};\mathbb{Z})=0
then there is no need to stack this TQFT, as discussed in the previous section. Further analysis of this continuous non-invertible symmetry can be found in
Arbalestrier et al. 2024
.

III.1
Coupling to massive particles

I now wish to discuss a specific way to explicitly break the non-invertible chiral symmetry. A first point to make is that there is a very easy way to break the chiral symmetry - add magnetic monopoles
Cordova et al. 2022b
. Doing so also means the magnetic 1-form symmetry is broken. This gives

dF\neq 0

(26)

which means we cannot go from (
20
) to (
22
). Thus, we cannot define a topological operator for our
U(1)_{\chi}
symmetry, so breaking the magnetic 1-form symmetry
automatically
breaks the chiral symmetry. This sort of method gives us the inequality

E_{\chi}\lesssim E_{m}

(27)

where these are the energy scales above which the chiral and magnetic symmetries are broken, respectively. One could rephrase this as the energy scales at which these symmetries emerge under an RG flow from some UV completion of the theory, assuming these symmetries are spontaneously broken in the IR such that this notion of emergent symmetry is valid
Cherman and Jacobson 2024
.

Adding monopoles is a breaking mechanism that gives us
E_{\chi}\approx E_{m}
. But what if we want

E_{\chi}\lnsim E_{m}\ ?

(28)

It was pointed out in
Cordova et al. 2024a
that one can simply add an operator to the theory that classically breaks the symmetry at the level of the Lagrangian. I will study one such way to break the chiral symmetry at general
E_{\chi}
by adding a Yukawa coupling between the electron and a massive real scalar in the UV that is neutral under the chiral symmetry:

\mathcal{L}^{\prime}\supset g\bar{\psi}\psi\phi+m^{2}\phi^{2}+g^{\prime}\phi^{3}

(29)

where
\phi
has mass
m
so that at energy scales
\Lambda\ll E_{\chi}(m)
we can integrate it out to obtain the Lagrangian of massless QED. The
\phi^{3}
term guarantees that
\phi
cannot be charged under the
U(1)_{\chi}
symmetry, nor any finite subgroup

IV
Future work

In this work, I have focused on non-invertible
U(1)
symmetries like the chiral symmetry of massless QED, and quantified their breaking scales by extending existing methods for continuous invertible higher-form symmetries. The symmetries we considered in this work have charges labelled by integers, but the possible charges under more general non-invertible symmetries are described by some appropriate representation category, see
Lin et al. 2023
;
Bhardwaj and Schafer-Nameki 2024
;
Bartsch et al. 2023a

Bhardwaj and Schafer-Nameki 2023
;
Bartsch et al. 2023b
;
Copetti 2024
;
Cordova et al. 2024c
;
Copetti et al. 2024
;
García Etxebarria et al. 2025

;
Das et al. 2024

;

;

. These representation categories often account for how the non-invertible topological operators exchange charged particles from one ‘twisted sector’ to another, or how they act on deep IR degrees of freedom, both of which we have not considered in this work. A categorical description of the effective charges under
general

that depends on the length scale
r
, compared to the fixed IR representations
\mathsf{Rep}_{\mathrm{IR}}

\mathsf{Rep}(r_{\infty})=\mathsf{Rep}_{\mathrm{IR}}

\mathsf{Rep}(r_{0})=(d-1)\mathsf{Vec},

(41)

where the UV representation category being trivial indicates that the symmetry is badly broken at length scales
r_{0}
. Such a description is most naturally defined in terms of a stack of tensor categories, and it would be interesting to explore this more general setup in future work.

B=k^{2}
. This gives the integral

\int_{0}^{1}dx\int d^{4}k\frac{\not{k}}{\left[k^{2}-2xp\cdot k+xp^{2}-xm^{2}\right]^{2}}

(47)

which, after changing coordinates to
\tilde{k}=k-xp
, we get

\int_{0}^{1}dx\int d^{4}\tilde{k}\frac{\not{\tilde{k}}+x\not{p}}{\left[\tilde{k}^{2}-\Delta\right]^{2}}

(48)

where
\Delta=x(1-x)p^{2}+xm^{2}
. Then, splitting this into two fractions, the one with numerator
\not{\tilde{k}}
vanishes by asymmetry by sending
\tilde{k}\rightarrow-\tilde{k}
. Then, we have

\Sigma(p)\approx g^{2}\not{p}\int_{0}^{1}dx\int d^{4}k\frac{x}{\left[k^{2}-\Delta\right]^{2}}.

(49)

We can write the integral over
k
as a standard dimensional regularisation result:

\int d^{4}k\frac{1}{{\left[k^{2}-\Delta\right]^{2}}}\approx\frac{1}{\epsilon}+\log\Delta+\dots,

(50)

which, ignoring the diverging term and assuming
p^{2}\ll m^{2}
, gives

\log\Delta\approx\log\left[1+(1-x)\frac{p^{2}}{m^{2}}\right]+\log(xm^{2}).

(51)

Ignoring the second term, which gives something scaling as
g^{2}\log m^{2}\cdot\not{p}
after the
x
integral and can therefore be ignored compared to (
34
), we make a Taylor expansion

\log\Delta\approx(1-x)\frac{p^{2}}{m^{2}}

(52)

so that performing the integral over
x
in
\Sigma(p)
gives

\boxed{\Sigma(p)\approx\frac{g^{2}}{m^{2}}\cdot p^{2}\cdot\not{p}}

(53)

as in (
34
).

Then, we can write the correction to the propagator,
G(p)=G_{0}(p)+G_{1}(p)
, as

G(p)=\frac{i}{\not{p}-\Sigma(\not{p})}=\frac{i\not{p}}{p^{2}(1-\frac{g^{2}}{m^{2}}p^{2})}.

(54)

We can write this as the sum of two partial fractions

G(p)=\frac{i\not{p}}{p^{2}}+\frac{i\frac{g^{2}}{m^{2}}\cdot\not{p}}{1-\frac{g^{2}}{m^{2}}p^{2}}

(55)

so that we can clearly read off
G_{1}(p)
as this second term.

The last step is to Fourier transform
G_{1}(p)
into position space, as required:

G_{1}(r)\approx\int d^{4}pe^{ir\cdot p}G_{1}(p).

(56)

If we let
M^{2}=\frac{m^{2}}{g^{2}}
, then we can write this as

G_{1}(r)\approx\frac{1}{M^{2}}\int d^{4}pe^{ir\cdot p}\frac{i\not{p}}{1-\frac{1}{M^{2}}p^{2}}=\int d^{4}pe^{ir\cdot p}\frac{i\not{p}}{M^{2}-p^{2}}.

(57)

Then, consider the form of the propagator for a scalar of mass
M
:

G^{\mathrm{scalar}}(p)=\frac{i}{p^{2}-M^{2}}.

(58)

In position space,

G^{\mathrm{scalar}}(r)\approx\int d^{4}pe^{ir\cdot p}\frac{i}{p^{2}-M^{2}}\approx\frac{M}{r}K_{1}(Mr)

(59)

where
K_{1}(s)
is a modified Bessel function of the second kind. What we can see is that we can rewrite
G_{1}(r)
as

G_{1}(r)\approx\not{\partial}G^{\mathrm{scalar}}(r)

(60)

to produce the
\not{p}
in the numerator of (
57
), but then we can use the known form of
G^{\mathrm{scalar}}(r)
in terms of the Bessel function to find
G_{1}(r)
. We then have that

G_{1}(r)\approx\frac{M\not{r}}{r^{3}}K_{1}(Mr)+\frac{M^{2}\not{r}}{r^{2}}K_{2}(Mr)

(61)

where we have used the property that

\frac{d}{ds}K_{n}(s)=\frac{n}{s}K_{n}(s)+K_{n+1}(s).

(62)

Rewriting
G_{1}(r)\approx\delta q(r)G_{0}(r)
where
G_{0}(r)\approx\frac{\not{r}}{r^{4}}
then gives

\delta q(r)\approx MrK_{1}(Mr)+M^{2}r^{2}K_{2}(Mr)

(63)

and as both terms scale similarly for small and large
r
we write for simplicity in the main text

\boxed{\delta q(r)\approx\frac{m^{2}r^{2}}{g^{2}}K_{2}\left(\frac{mr}{g}\right)}

(64)

after substituting
M=\frac{m}{g}
back in.
