Protocol for making forecasts exogenous in the International Futures model
Authors: José Solórzano, Barry B. Hughes, Mohammod T. Irfan, Yutang Xiong, Stellah Kwasi, Abdelrahman Ibrahim, Solikhakhon Makhmatova, Taylor Hanna, Jonathan D. Moyer
Published: 2024

ABSTRACT
SummaryUnderstanding future dynamics and trends in human and natural development is foundational for creating appropriate policy strategies to address planetary and development challenges. Here, we present a protocol for adding exogenous series for key variables, such as the shared socioeconomic pathways, to the database of the International Futures (IFs) integrated model. We describe steps for installing IFs and the SQLiteStudio software, understanding the IFs database, importing series, running the model, and extracting results.For complete details on the use and execution of this protocol, please refer to Moyer.1

Before you begin

International Futures (IFs) is a large-scale, long-term integrated model that forecasts over 800 variables from 2019–2100 for 188 countries. IFs integrates forecasts across different domains, including: agriculture, demographics, economics, education, energy, environment, governance, health, infrastructure, international politics, and technology. These sub-models are dynamically connected, so the model simulates how changes in one system can lead to changes across other systems, endogenizing many relationships from global systems.2 The model is open-source and available for free at https://korbel.du.edu/pardee (Table 1).Table 1Issue area publicationsIssue AreaPublicationsAgricultureHedden et al.,3 Verhagen et al.4Climate and theEnvironmentMoyer,5 Moyer et al.,6ConflictMoyer et al.7Economic DevelopmentHughes and Narayan,8 Milante et al.,9 Moyer,5EducationDickson et al.10 Hughes et al.,11GovernanceHughes et al.,12 Joshi et al.,13HealthJoshi et al.,13 Hughes et al.,14 Hughes et al.,15 Kuhn et al.,16 Moyer et al.17,18InfrastructureMoyer et al.,18 Rothman et al.19International RelationsMoyer et al.,20 Moyer21,22SDGsHanna et al.,23 Hughes,24 Moyer and Bohl,25 Moyer and Hedden26TechnologyMoyer and Hughes27

There are three main avenues for analysis in IFs: historical data analysis (cross-sectional and longitudinal), Current Path analysis (also referred to as Business-as-usual scenario showing how systems are likely to develop based on prevailing conditions), and alternative scenario development (exploring if-then statements about the future). The Current Path assumes no major paradigm shifts, seismic policy changes, or transformative ‘black swan’ events. However, adjustments can be made to these initial conditions by adding or amending data or altering parameters to change forecast assumptions.

IFs forecasts are not intended to be point predictions about the future; the platform is a tool designed to help people think systematically about how development systems work and how the future is likely to unfold given various assumptions.

This article describes how to make 23 variables exogenous within IFs, allowing researchers to explore how forecasts created by others may interact with a broader set of outcome indicators via the existing model structure.

We provide step by step information to researchers who seek to explore how existing projections for key indicators (like the ones associated with the Shared Socioeconomic Pathways (SSPs)) impact other variables in IFs. Here, we outline how to add an exogenous projection series in IFs, run the model with these inputs, and extract results. The instructions provided encompass four main steps: 1) installing the IFs platform and any SQLite reader; 2) importing exogenous forecasts into the IFs database; 3) preparing IFs to run with exogenous series, including the SSP projections; and 4) exporting results via the model interface.

If readers are interested in analyzing the effect of an alternative pre-loaded SSP series on outcome variables within the IFs model, they need to follow Step 1 and Step 4. Quantification and statistical analysis

The IFs model is large and contains many structured relationships between variables that drive model results. Opening the “black box” and making the underlying assumptions more accessible is important for understanding and analyzing results. There are various resources that can help improve users understanding of the relationships within the IFs model.

First, the site https://pardeewiki.du.edu is a useful source of information for both the user interface as well as core model structures. Choosing Use IFs (Download Version) will provide users with help system material on the user interface. Choosing Understand IFs will provide more information on the underlying model structures organized by key submodule.

There are also many publications that can provide resources to users about the overall structure of the model. Foundational model texts describe the overall purpose of the modeling project, its history, and what key systems are covered.1,46

Limitations

IFs can only run on Windows. Users require Internet Information Services (IIS) to run IFs. This is a Windows only web server released by Microsoft. Therefore, IFs cannot run on the operating system for Apple’s mac computers (macOS). A workaround is installing a virtual window application like Citrix or VMware Horizon on macOS and launch IFs within it. Alternatively, users can use Remote Desktop (or any other similar Windows desktop sharing like VNC). All these solutions require additional processing, setup, and maintenance.

Additionally, the only supported browsers are Google Chrome, Firefox, and Edge. JavaScript and Cookies must also be enabled to use IFs.

Troubleshooting

Problem 1

When installing IFs, an error message can sometimes appear during the running of the model. Insufficient computational resources can cause slow model execution or memory errors.

This can be expected during the first step of installing IFs into the users’ local drive as described in the step-by-step method details section.

Potential solution 1

To resolve this problem, allocate more computational resources, such as CPU, memory, or disk space, if available. Consider parallel processing techniques or cloud computing services for faster execution.

Users can also delete and reinstall IFs from the provided link if issues persist because they could have accidentally deleted a file during the set-up process. If issues persist, reach out to the contact people listed in this manuscript for technical help.

Problem 2

When importing data/projections into IFs using an excel spreadsheet, users could get an error message. This problem can be expected in the second step that involves data import into IFs.

Potential solution 2

Users should make sure that they are using the correct data format in their spreadsheet and in IFs.

Users can also consider going to the Extended features tab on the main menu and from the list of options, Click “Clear Session” and redo the process.

If issues persist, reach out to the contact person listed in this manuscript for technical help.

Problem 3

When viewing results in the IFs Flexible display, users could get an error message when they try to show results of any given variable, for example, poverty at US$2.15. This could occur because of incomplete updates or coding mishaps of the variable on the back-end side of things. This problem can be expected in the fourth step of the step-by-step method details section of this manuscript.

Potential solution 3

The solution to this kind of problem is often technical and users should reach out to the contact people listed in this manuscript.

Problem 4

After navigation for an extended period in the Flexible display, multiple geography columns and dimensions can sometimes appear repeatedly when users try pick a new result variable after navigating out of a line graph interface, for example, from a previous result visualization. This problem could be experienced in fourth step of the step-by-step method details section.

Potential solution 4

Users should go to the Extended features tab on the main menu and from the list of options, Click “Clear Session.” Additionally, users can search for “Internet Information Services (IIS) Manager” from their devices’ program menu and then click on “Restart” on the right side of the window. This will often resolve the problem, and users can keep navigating in IFs.

However, if this does not work, users should just exit the IFs program and reopen it to start over.

Problem 5

When IFs has been dormant for a while, it will sometimes time out and give an error message when you click on a variable in the Flexible Display, for example. This problem can occur at any stage from the second step if IFs has been dormant.

Potential solution 5

Users can search for “Internet Information Services (IIS) Manager” from their devices’ program menu and then click on “Restart” on the right side of the window. This will often resolve the problem and users can keep navigating in IFs.

Users can also just exit the IFs program and reopen it to start over.
