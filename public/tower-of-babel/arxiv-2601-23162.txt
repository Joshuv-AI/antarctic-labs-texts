Causal spinfoam vertex for 4d Lorentzian quantum gravity
Eugenio Bianchi, Chaosong Chen, Mauricio Gamonal

Abstract
We introduce a new causal spinfoam vertex for 4 4 d Lorentzian quantum gravity. The causal data are encoded in Toller T T -matrices, which add to Wigner D D -matrices T ( + ) + T ( − ) = D T^{(+)}+T^{(-)}=D , and for which we provide a Feynman i ​ ε \mathrm{i}\varepsilon representation. We discuss how the Toller poles cancel in the EPRL vertex, how the Livine-Oriti model is obtained in the Barrett-Crane limit, and how spinfoam causal data are distinct from Regge causal data. In the large-spin limit, we show that only Lorentzian Regge geometries with causal data compatible with the spinfoam data are selected, resulting in a single exponential exp ( + i S Regge / ℏ ) \exp(+\mathrm{i}\, S_{\mathrm{Regge}}/\hbar) and a new form of causal rigidity.

III
Relation to the EPRL model

The Feynman
\mathrm{i}\varepsilon

The first property is the additive relation:

T^{(+,\rho,k)}_{jm\,ln}(g)+T^{(-,\rho,k)}_{jm\,ln}(g)=D^{(\rho,k)}_{jm\,ln}(g)\,.

(5)

\langle A_{v}^{\mathrm{EPRL}}|\,=\sum_{\kappa_{ab}=\pm 1}\langle A_{v}^{({\kappa_{ab}})}|\,,

(6)

\displaystyle\langle

V
Discussion

In this paper, we introduced a causal vertex amplitude for
4
d Lorentzian spinfoams, defined by the expression (
4
), as briefly summarized here:

–

We introduced the new expression (
3
) for Toller
T
-matrices
Toller:1968gr
;
Toller:1968pole
;
Sciarrino:1967

\mathrm{i}\varepsilon
prescription applied to the Wigner
D
-matrices. In the literature on harmonic analysis on the Lorentz group
Ruhl:1970lor

T
-matrices are described in terms of their analytic properties (Toller poles). The new formula (
3

2

–

The causal vertex amplitude proposed here replaces the Wigner
D
-matrices, which are associated with wedges in the EPRL model
Engle:2007wy
, with Toller
T
-matrices (
3
). In this way, the spinfoam vertex amplitude defined in (
4

\sigma_{a}
of the edges (Fig.
1a
). This construction of the causal vertex for the EPRL model follows the same logic as the construction of the Livine-Oriti causal vertex
Livine:2002rh
;
Oriti:2004mu
for the Barrett-Crane model
Barrett:1999qw
; there, one replaces the function
d^{(\rho,0)}_{000}(\beta)
with the functions

with fixed area
\rho=\gamma j
, the Livine-Oriti model is reproduced in the same limit from (
4
).

–

We studied the large-spin asymptotics of the causal vertex amplitude for a semiclassical boundary state peaked on a non-degenerate Lorentzian Regge geometry. The integral formula (
17
) for the Toller
T
-matrices allows us to employ the same saddle-point techniques developed for the EPRL model

;

where one inserts in the integral a step function

times the Regge action (

The Wigner
d
-matrices can be expressed as a sum over hypergeometric functions. Following Rühl’s phase conventions

, we have

\displaystyle d^{(\rho,k)}_{jlm}(\beta)

\displaystyle=\sqrt{(1+2j)(1+2l)}\,\sqrt{\frac{(j-k)!\,(j+k)!\,(-k+l)!\,(k+l)!}{(j-m)!\,(l-m)!\,(j+m)!\,(l+m)!}}\;\frac{1}{(1+j+l)!}

\displaystyle\quad\times\sum_{n_{1},n_{2}}(-1)^{n_{1}+n_{2}}\binom{j-m}{k-m+n_{1}}\binom{l-m}{k-m+n_{2}}\binom{j+m}{n_{1}}\binom{l+m}{n_{2}}

\displaystyle\quad\times(j-k+l+m-n_{1}-n_{2})!\,(k-m+n_{1}+n_{2})!\,\mathrm{e}^{\,\beta(-1-k+m-2n_{1}-\mathrm{i}\rho)}

\displaystyle\quad\times{}_{2}F_{1}\Big(1+k-m+n_{1}+n_{2},\;1+j+\mathrm{i}\rho;\;2+j+l;\;1-\mathrm{e}^{-2\beta}\Big)\,,

(19)

where the sums over
n_{1},n_{2}
run over

and
n_{2}=\max(0,m-k),\ldots,\min(l+m,l-k)
. With this phase convention, the Wigner
d
-matrices are entire in the complex
\rho

\rho
