Steiner Forest: A Simplified Better-Than-2 Approximation
Anupam Gupta, Vera Traub

Abstract
In the Steiner Forest problem, we are given a graph with edge lengths, and a collection of demand pairs; the goal is to find a subgraph of least total length such that each demand pair is connected in this subgraph. For over twenty years, the best approximation ratio known for the problem was a 2 2 -approximation due to Agrawal, Klein, and Ravi (STOC 1991), despite many attempts to surpass this bound. Finally, in a recent breakthrough, Ahmadi, Gholami, Hajiaghayi, Jabbarzade, and Mahdavi (FOCS 2025) gave a 2 − ε 2-\varepsilon -approximation, where ε ≈ 10 − 11 \varepsilon\approx 10^{-11} . In this work, we show how to simplify and extend the work of Ahmadi et al. to obtain an improved 1.994 1.994 -approximation. We combine some ideas from their work (e.g., an extended run of the moat-growing primal-dual algorithm, and identifying autarkic pairs) with other ideas—submodular maximization to find components to contract, as in the relative greedy algorithms for Steiner tree , and the use of autarkic triples . We hope that our cleaner abstraction will open the way for further improvements.



1
Introduction

We study the Steiner Forest problem, where we are given an undirected
graph
G=(V,E)
with non-negative edge costs
\{c_{e}\}_{e\in E}
,
and a collection of demand pairs
\mathcal{D}\subseteq\binom{V}{2}
; a solution
is a subset of edges
F\subseteq E
such that for each demand pair, both of its vertices lie in the
same connected component of the subgraph
(V,F)
. The goal
of the optimization algorithm is to minimize the total cost
c(F)\coloneqq\sum_{e\in F}c_{e}
.

The problem is APX-hard
[
CC08
]
, and the first constant-factor
approximation ratio given for this problem was the
2
-approximation
due to Agrawal, Klein, and Ravi
[
AKR95
]
, based on the (by-now standard)
moat-growing primal-dual framework. Remarkably, this approximation
ratio proved extremely difficult to improve upon: Goemans and
Williamson extended the primal-dual framework to a wide class of
constrained forest problems
[
GW95
]
, but the approximation ratio
for Steiner forest remained the same. (See
Section

1.2
for
a discussion of several other algorithms for the problem.)

Finally, in a remarkable result earlier this year, Ahmadi, Gholami,
Hajiaghayi, Jabbarzade, and Mahdavi
[
AGH+25b
]
gave a

(2-\varepsilon)
-approximation for
\varepsilon\approx 10^{-11}
, breaking the
three-decades old logjam. Their work combines the primal-dual scheme with a local-search approach and a new
technique of “autarkic pairs”, which builds on ideas from earlier
work of the same authors on the prize-collecting version of Steiner
Forest
[
AGH+25a
]
.

Building on this breakthrough, we show how to simplify and
abstract these powerful new ideas and integrate them with classical
approaches to get a more intuitive algorithm, a simpler analysis,
and a stronger approximation guarantee.
Our main result is the
following:

Theorem 1.1
.

There is an
1.994
-approximation algorithm for the Steiner Forest
problem.

While building upon key ideas from
[
AGH+25b
]
, we achieve this
result by an arguably simpler algorithm and analysis. This
simplification, which unifies classical techniques with recent
breakthroughs, is a primary contribution of our work. We show how to
adapt well-established tools from approximation algorithms for the
Steiner Tree problem (which is the special case of Steiner Forest
where all demand pairs share a common endpoint) to the setting of
Steiner Forest. This leads not only to a significant simplification
and a better approximation ratio, but it also provides a more unified
perspective, revealing connections between the different algorithms we
have for these two problems.

1.1
Our Techniques

The first step of our new algorithm for Steiner Forest is to run the

\varepsilon
-extended moat growing algorithm introduced
in
[
AGH+25b
]
, which is a variant of the classical primal-dual
algorithm. In this variant sets stay active and grow for a bit longer
than they would in the classical primal-dual algorithm. For a precise
description, we refer to
Section

2
.

Next, we apply two different algorithms that each start with the solution resulting from the
\varepsilon
-extended moat growing algorithm and aim at improving upon it.

Improving Components:
The first of these two
algorithms aims at finding “improving components”, which is a key
concept present in almost all known approximation algorithms for
Steiner Tree that have an approximation ratio below
2
, including
those algorithms achieving the currently best approximation guarantee

[
BGRS13
,
TZ25
]
. Our algorithm builds on Zelikovsky’s
relative greedy algorithm for Steiner Tree

[
Zel96
]
, but with some key differences,
described next.

For the Steiner tree problem, there is a simple
2
-approximation
algorithm, which returns a spanning tree (in the metric closure) on
the set of
terminals
(the set of vertices to be connected).
Zelikovsky’s algorithm selects a set of “components”—a set of
trees each connecting only a subset of the terminals—then contracts
each of the terminal sets connected by these components. It finally
builds a minimum spanning tree on the terminals in the contracted
instance to get a Steiner tree.

For the Steiner Forest problem, we do not have a simple

2
-approximation via minimum spanning trees. Thus, we instead complete the selected components via the primal-dual technique. This
however creates a new challenge: In contrast to the cost of a minimum
spanning tree on the terminals, the cost of the Steiner forest
returned by the (classical or
\varepsilon
-extended) primal-dual
algorithm might change in very non-intuitive ways when contracting
vertices. In fact, this cost is not even monotone and might
increase when contracting some vertices. This makes it difficult to
analyze such an algorithm and also difficult to select a good set of
components.

For this reason, we work with a “time-based” version of the
primal-algorithm. To the best of our knowledge, such a timed version was first studied in
[
GKPR03
,
KLS05
]
, and was rediscovered in

[
AGH+25b
]
. Using this “time-based” version, the cost of a
solution returned by the primal-dual algorithm can only decrease when
contracting a component. Moreover, we show that the decrease can be
quantified by a submodular function. (See
Definition

3.4
and

Lemma

3.5
.) This allows us to apply techniques from
submodular optimization, much like the relative greedy algorithm used
by Zelikovsky
[
Zel96
]
, to select a good set of
components.

In order to be able to restrict ourselves to components connecting
only a constant-size set of vertices, which we need to obtain an
efficient algorithm, we use classical results by Borchers and Du on

k
-restricted Steiner trees
[
BD97
]
. However, it turns
out that this restriction to constant-size sets is only possible when
our components are “actively connected” (a concept introduced in

[
AGH+25b
]
). While this property is trivially satisfied for
Steiner Tree instances, this is not the case for Steiner Forest. This
difficulty is the reason why we need the
\varepsilon
-extended moat
growing algorithm, and cannot simply work with the classical
primal-dual algorithm. We expand on this component-based algorithm in

Section

3
.

Autarkic Pairs:
The second algorithm again starts
with the solution resulting from the
\varepsilon
-extended moat-growing
algorithm. It then aims at improvements of this solution via the idea
of “autarkic pairs” introduced in
[
AGH+25b
]
, building on
similar ideas from
[
AGH+25a
]
. The idea is to carefully
select a set of demand pairs to contract and then run any

2
-approximation algorithm on the resulting instance. If the cost of
an optimum solution decreases by more than half of the cost needed to
connect the contracted demand pairs (by a shortest path each), then
this leads to a cheaper solution than applying a
2
-approximation
directly to the original instance.

We provide a new abstraction of the concept of autarkic pairs and show
how we can quantify the improvement in the solution cost for a given
collection of autarkic pairs (
Lemma

4.7
). Then we
prove that an optimal collection of autarkic pairs can be computed in
polynomial time (
Theorem

4.6
). Moreover, our new abstraction
allows us to generalize our results to autarkic triples, which leads
to further improvements of the approximation guarantee. For details
we refer to
Section

4
.

In the end, we return the best of all the solutions we obtained from
these different algorithms. For a description of our overall
algorithm and the key technical statement that implies the
approximation ratio of
1.994
, we refer to
Section

5
.

Plan for the Paper:
We discuss the
\varepsilon
-extended
moat-growing algorithm in
Section

2
, and explore
the ideas of improving components in
Section

3
, and
autarkic pairs in
Section

4
. We then give the
algorithm in
Section

5
. The proof that one of these two
ideas gives an improvement appears
in
Section

6
, which we use to
complete the analysis in
Section

7
. We close with
some deferred proofs in the Appendices.

1.2
Related Work

Apart from the recent work of Ahmadi, Gholami, Hajiaghayi, Jabbarzade,
and Mahdavi
[
AGH+25b
]
mentioned above, there is a large body of
work on Steiner network problems. The first approximation algorithms
for the Steiner forest problem was due to Agrawal, Klein, and
Ravi
[
AKR95
]
. The primal-dual approach they developed was
extended to a wide class of network design problems by Goemans and
Williamson
[
GW95
]
, who gave a network-formation plus
reverse-delete perspective for Steiner forest (as opposed to the

[
AKR95
]
algorithm which built edges irrevocably, and did not have
a reverse-delete step). Another
2
-approximation algorithm for the
Steiner Forest problem is Jain’s seminal iterative rounding
algorithm
[
Jai01
]
, which applies far beyond Steiner Forest to a
wide class of network design problems.

“Timed” versions of the primal-dual algorithm had been proposed by

[
GKPR03
]
in order to give an algorithm for a rent-or-buy
variant of the Steiner forest problem. Könemann, Leonardi, and
Schäfer proposed a timed algorithm to give another
2
-approximation
algorithm for Steiner forest which also admits a cross-monotonic
cost-sharing scheme
[
KLS05
]
. Their algorithm gave a new LP
relaxation, but this was shown to have an integrality gap no better
than a factor of two
[
KLSvZ08
]
. Such a timed version of the
algorithm was rediscovered by Ahmadi et al.
[
AGH+25b
]
; one
component of their improvement was to perform a local search on the
time vectors. Other approaches for Steiner forest were explored,
including a greedy “gluttonous” algorithm
[
GK15
]
and a
local-search algorithm
[
GGK+18
]
. While these approaches gave
constant-factor approximations, none of them were successful in
breaking past the factor of
2
.

In contrast, the Steiner
Tree
problem, where all the demand
pairs share a common endpoint, has a simple
2
-approximation by just
outputting an MST on the terminals. Much better approximation
algorithms are known: a line of work culminating in the work of Robins
and Zelikovsky
[
RZ05
]
gave
relative greedy
algorithms
(based on finding small sets of terminals to contract, thereby
reducing the cost of the MST on the remaining instance); the last of
these algorithms gave an approximation ratio of
1.55
.
Byrka, Grandoni,
Rothvoß, and Sanitá
[
BGRS13
]
gave a randomized version of
the relative greedy algorithm achieving an approximation of

\ln 4+\varepsilon
, for any constant
\varepsilon>0
. (Goemans, Olver,
Rothvoß, and Zenklusen
[
GORZ12
]
gave an LP-based analysis
of the same algorithm.) Recently, Traub and Zenklusen
[
TZ25
]

gave a non-oblivious local-search algorithm with the same
approximation bound of
\ln 4+\varepsilon
.

The autarkic pairs technique from
[
AGH+25b
]
, which we generalize
in
Section

4
, builds on an idea introduced by the same
authors in their exploration of the prize-collecting generalization of
Steiner Forest (where we pay a penalty for every demand pair not
connected in the solution); they give the currently best-known
approximation ratio of
2
for the problem
[
AGH+25a
]
. This
algorithm recursively applies the classical the primal-dual algorithm,
which has been extended to the prize-collecting version of Steiner
Forest in
[
HJ06
]
. A key step of the
2
-approximation
algorithm for prize-collecting Steiner Forest is the contraction of a
carefully selected set of demand pairs. The set of demand pairs to
contract is chosen such that the cost of an optimum solution decreases
a lot, unless the optimum solution is so expensive that the solution
returned by the primal-dual algorithm is already a
2
-approximation.
Similar techniques have been applied to the prize-collecting Steiner
tree problem, leading to an approximation factor of
1.79

[
AGH+24
]
.

The standard linear programming relaxation for Steiner Forest (see

Section

1.3
), which is used by the primal-dual algorithm, has
an integrality gap of exactly
2
even for the MST/Steiner Tree
instances on the cycle. A stronger linear programming relaxation
based on the Bidirected Cut Relaxation for Steiner Tree has been
investigated in
[
BGT25
]
, but it is not known if this
relaxation has an integrality gap strictly smaller than
2
. For the
special case of Steiner tree, Byrka, Grandoni and Traub recently
showed that the Bidirected Cut relaxation has an integrality gap below

2

[
BGT24
]
. This proof is also based on an extension of the
primal-dual algorithm where sets grow longer than in the classical
primal-dual algorithm, but it is nevertheless very different from the

\varepsilon
-extended moat-growing algorithm we use. For Steiner Tree,
also other relaxations have been studied and it has been shown that
Hypergraphic Relaxation has an integrality gap of at most
\ln 4

[
GORZ12
]
(see also
[
TZ25
]
).

1.3
Notation and Basic Definitions

In the
Steiner Forest problem
, we are given a graph
G=(V,E)

with non-negative edge costs
\{c_{e}\}_{e\in E}
, and a collection

\mathcal{D}=\{a_{i},b_{i}\}_{i=1}^{h}
of demand pairs, where each

a_{i},b_{i}\in V
.
We say that
a_{i}
and
b_{i}
are partners for each
other.
A vertex might have several partners.
The vertices belonging to pairs in
\mathcal{D}
are called
terminals. (We can assume without loss of generality that all vertices
in
V
are terminals; indeed, any Steiner nodes can be replaced by a
demand pair at distance zero from each other.)
A solution to the Steiner Forest problem is a collection
F\subseteq E
of edges such that for each demand pair, both of its vertices lie
in the same connected component of the edge-induced graph
(V,F)
;
the goal is to find a solution of minimum total cost

c(F)\coloneqq\sum_{e\in F}c_{e}
.

We use
\operatorname{OPT}
to denote a fixed optimum solution.
If there are several optimum solutions, we choose an inclusionwise minimal one,
that is an optimum solution that contains no edges of cost
0
that could also be omitted.

A set
U\subseteq V

separates
a demand
d=\{a,b\}\in\mathcal{D}
if

d\cap U\neq\varnothing
and
d\setminus U\neq\varnothing
. We
generalize this from demand pairs
d
to a general set
S
.

Definition 1.2

(Separation)
.

A set
U\subseteq V

separates
a set
S\subseteq V
if

S\cap U\neq\varnothing
and
S\setminus U\neq\varnothing
.

Note that this definition is asymmetric: e.g., if
S=U\cup\{x\}

for some
x\not\in U
, then
S
is separated by
U
(since there are
parts of
S
both inside and outside
U
), but
U
is not separated by

S
. Define a
separating cut
as a set
U\subseteq V
such that
there exists some demand
d\in\mathcal{D}
separated by
U
.

The standard linear programming relaxation for Steiner forest has a
variable
x_{e}
for each edge
e\in E
, with the following constraints:

\displaystyle\min\sum_{e\in E}c_{e}

\displaystyle x_{e}

\displaystyle\sum_{e\in\delta(U)}x_{e}

\displaystyle\geq 1\qquad\qquad\forall\text{ separating
cuts }U

\displaystyle x_{e}

\displaystyle\geq 0.

Its LP dual has variables
y_{U}
for each subset
U\subseteq V
of
vertices:

\displaystyle\max\sum_{\text{separating cuts }U}y_{U}

\displaystyle\sum_{U:e\in\delta(U)}y_{U}

\displaystyle\leq c_{e}\qquad\qquad\forall e\in E

\displaystyle y_{U}

\displaystyle\geq 0.

Note that we allow variables for all subsets
U
, while the objective
function only sums over the contribution for separating cuts; hence an
optimal solution has no incentive to have non-zero values for
y_{U}
’s
with non-separating sets
U
. However, the dual solutions constructed by
the algorithm in
Section

2
have non-separating cuts in
their support.

2
The
\varepsilon
-Extended Moat-Growing Algorithm

The following variant of the standard moat-growing algorithm of

[
AKR95
,
GW95
]
was considered by
[
AGH+25b
]
. At each time
t
,
we have a collection of tight edges
F\subseteq E
, and let
\mathcal{C}^{t}
be the
connected components of the graph
(V,F)
. Moreover, we have
non-negative variables
\{y_{S}(t)\}_{S\subseteq V}
, such that tight edges
satisfy
\sum_{S\subseteq V:e\in\delta(S)}y_{S}(t)=c_{e}
and all other edges satisfy
\sum_{S\subseteq V:e\in\delta(S)}y_{S}(t)<c_{e}
.

Each component of
\mathcal{C}^{t}
has a budget
b_{S}(t)\geq 0
. Initially

y_{S}(t)=0
for all
S
and
F=\varnothing
, which means the
components of
\mathcal{C}^{0}
are the individual vertices of the
graph. The budget of each terminal is initialized to zero.

A component
S\in\mathcal{C}^{t}
is called
demand-active
if
S

contains a terminal that has a partner to which it is not connected in
(V,F)
, and
S
is called

budget-active
if it is not demand-active but it has a strictly
positive budget. Component
S\in\mathcal{C}^{t}
is called
active
if it
is either demand-active or budget-active, and is called

inactive
if it is neither. Let
\mathscr{A}^{t}\subseteq\mathcal{C}^{t}
be the
active components at time
t
.

Now we raise time
t
continuously at unit rate and raise the dual
variables
y_{S}(t)
of all active components
S\in\mathscr{A}^{t}
at the same
rate; the
y_{S}(t)
values of all other sets
S
remain unchanged. (In
other words, the derivative satisfies
\dot{y}_{S}(t)=\mathbf{1}(S\in\mathscr{A}^{t})
.) If the
component is demand-active, we increase the budget
b_{S}(t)
at rate

\varepsilon
, else if it is budget-active, we decrease the budget
b_{S}(t)

at unit rate. This process continues until some edge
e
becomes
tight: i.e.,
\sum_{S\in\mathscr{A}^{t}:e\in\delta(S)}y_{S}(t)=c_{e}
. At
this moment, all newly-tight edges are added to
F
, which changes the
component structure. If components
S_{1},\ldots,S_{k}
are merged into
one component
S
, we merge their budgets, and hence define

b_{S}(t):=\sum_{j=1}^{k}b_{S_{j}}(t)
. This process can continue
indefinitely, but observe that the variables
y_{S}(t)
stop growing
when there are no more active components.

Henceforth, we refer to this algorithm as the
\varepsilon
-extended
moat-growing algorithm
, or simply the
extended algorithm
for
brevity. To avoid superfluous notation, we let
\{y_{S}\}_{S\subseteq V}

denote the solution it generates when it terminates; i.e.,

y_{S}=y_{S}(\infty)
. Note that

\displaystyle\sum_{S\subseteq V}y_{S}=\int_{t=0}^{\infty}|\mathscr{A}^{t}|\,dt.

(2.1)

2.1
Properties of the
\varepsilon
-Extended Algorithm

Since we grow duals based on either the demands or the budgets, we
partition the support of
y
(denoted by
\mathcal{U}
or
\operatorname{supp}(y)
) into

\displaystyle\mathcal{U}_{\rm{sep}}\

\displaystyle\coloneqq\ \{U\subseteq V:U\in\operatorname{supp}(y)\text{ and separates some
demand pair}\}

\displaystyle\mathcal{U}_{\rm unsep}\

\displaystyle\coloneqq\ \{U\subseteq V:U\in\operatorname{supp}(y)\text{ and separates no demand pair}\}.

Note that the sets in
\mathcal{U}_{\rm{sep}}
contribute to the dual objective
function, whereas the others do not. By construction, the sets in the
support have a laminar structure.

Letting
y(\mathcal{U}^{\prime})=\sum_{U\in\mathcal{U}^{\prime}}y_{U}
for any
\mathcal{U}^{\prime}\subseteq\mathcal{U}
, we have

\displaystyle y(\mathcal{U}_{\rm{unsep}})=\varepsilon\cdot y(\mathcal{U}_{\rm{sep}})=\frac{\varepsilon}{1+\varepsilon}\cdot y(\mathcal{U}).

(2.2)

Looking at which duals pack into
\operatorname{OPT}
, we get

c(\operatorname{OPT})\ \geq\ \sum_{U\subseteq V}y_{U}\,|\operatorname{OPT}\cap\ \delta U|\geq\ y(\mathcal{U}_{\rm{sep}})+\underbrace{\sum_{\begin{subarray}{c}U\subseteq V:\\
|\operatorname{OPT}\cap\delta(U)|\geq 2\end{subarray}}y_{U}}_{=:\Lambda}.

(2.3)

Definition 2.1
.

Let
F\subseteq E
be a solution to our Steiner forest instance.
We define its
excess
(with respect to the dual solution

y
) to be

\operatorname{excess}(F)\ \coloneqq\ c(F)-y(\mathcal{U}_{\rm{sep}}).

Now (
2.3
) says that
\operatorname{excess}(\operatorname{OPT})\geq\Lambda
.
Moreover, the algorithm of
[
AKR95
,
GW95
]
gives a
solution to Steiner forest with the following guarantee:

Theorem 2.2
.

There is an efficient algorithm to find a Steiner forest of cost at most

2\cdot\sum_{S\subseteq V}y_{S}\ \leq\ 2(1+\varepsilon)\cdot y(\mathcal{U}_{\rm{sep}})\leq 2(1+\varepsilon)\cdot\big(c(\operatorname{OPT})-\operatorname{excess}(\operatorname{OPT})\big).

If the optimal solution has a large excess, then the solution of the

\varepsilon
-extended algorithm itself is a good approximation. If not, we
give ways to improve it in the following sections.

3
Actively Connected Components

For a vertex
v\in V
, we define its
deactivation time

\mathbf{d}_{v}
in the extended algorithm to be the largest time
t
such
that the vertex
v
belongs to an active component at time
s
for all

s<t
. In other words,
v\in S
for some
S\in\mathscr{A}^{s}
for all
times
s<t
, but not at time
t
itself. Observe that for a vertex

v
, the deactivation time is
at least
the first time at which
it lies in the same component as all its partners. (The component
containing
v
may remain active when
v
is connected to its
partner—either demand-active, or budget-active if
\varepsilon>0
—and
hence typically the deactivation time will be larger.)

Definition 3.1

(Actively Connected Vertices)
.

Vertices
u,v\in V
are
actively connected
if there is a
time
t
during the run of the extended algorithm such that

1.

\{u,v\}\subseteq S
for some
S\in\mathcal{C}^{t}
, and

2.

the deactivation time for both
u
and
v
is at least
t
.

In other words, actively connected vertices belong to the same
connected component (which may or may not be active) at some time
t
,
and both elements have always been part of some active component
before time
t
. By definition, the vertices
a_{i},b_{i}
of each demand pair are always
actively connected. A key property of actively connected vertices is
that they have the same deactivation time.

Observation 3.2
.

If
u,v
are actively connected, then
\mathbf{d}_{u}=\mathbf{d}_{v}
.

Proof.

If
u
and
v
are actively connected, they belong to the same
connected component
S
at some time

t\leq\min(\mathbf{d}_{u},\mathbf{d}_{v})
. Either this component is inactive,
in which case
\mathbf{d}_{u}=\mathbf{d}_{v}=t
, else they will always remain
part of the same connected component henceforth. Thus, their
deactivation time is the same.
∎

Being actively connected is an equivalence relation: indeed, it is a
symmetric relation; moreover, if
\{u,v\}
and
\{v,w\}
are actively
connected, all three of
\{u,v,w\}
have the same deactivation time,
and lie in the same connected component at this time. We can now
extend
Definition

3.1
to sets:

Definition 3.3

(Actively Connected Sets)
.

A
set

A\subseteq V
is
actively connected
if
A

is a subset of some equivalence class of the relation.

The maximal actively connected sets form a partition of
the vertex set
V
.

3.1
Contracting Actively Connected Components

The next idea is a natural
one: if we can find an actively connected set
S
, which intersects
many moats during the moat-growing process, and shrink it down to a
single point, we can reduce the cost of the resulting solution. (Of course, we
need to pay the cost to shrink the set!) The idea extends to
collections of actively connected sets—and since the “gain” we
achieve is submodular, we can use the machinery of submodular
maximization to find a good collection of such sets to contract.

Definition 3.4

(Gain)
.

Let
\mathscr{S}
be a collection of vertex sets, each being
actively connected. Define

\displaystyle\operatorname{gain}(\mathscr{S})\ \coloneqq\ 2\cdot\int_{t=0}^{\infty}\big(|\mathscr{A}^{t}|-|\mathscr{A}^{t}/\mathscr{S}|\big)\,dt,

(3.1)

where
\mathscr{A}^{t}/\mathscr{S}
arises from
\mathscr{A}^{t}
by
merging sets in
\mathscr{A}^{t}
into a single set whenever they are
intersected by the same set
S\in\mathscr{S}
.

Lemma 3.5

(Submodularity)
.

The function

\operatorname{gain}\colon 2^{\{S\subseteq V\colon S\text{ actively
connected}\}}\to\mathbb{R}_{\geq 0}
is submodular.

Proof.

To prove that the
\operatorname{gain}
function is submodular, we show that for
each time
t\geq 0
the function
g^{t}
given by

g(\mathscr{S})\coloneqq|\mathscr{A}^{t}|-|\mathscr{A}^{t}/\mathscr{S}|
is submodular. This
implies that the function
\operatorname{gain}
given by

\operatorname{gain}(\mathscr{S})=\int_{t=0}^{\infty}g^{t}(\mathscr{S})\ dt
is submodular. To
prove that the function
g^{t}
is submodular it suffices to prove
that it satisfies the diminishing return property: for any two
collections
\mathscr{S}_{1}
and
\mathscr{S}_{2}
of actively connected sets with

\mathscr{S}_{1}\subseteq\mathscr{S}_{2}
and any actively connected set
S
, we have

g^{t}(\mathscr{S}_{1}\cup\{S\})-g^{t}(\mathscr{S}_{1})\geq g^{t}(\mathscr{S}_{2}\cup\{S\})-g^{t}(\mathscr{S}_{2}).

(3.2)

For
i\in\{1,2\}
, let
m_{i}
be the number of sets from

\mathscr{A}^{t}/\mathscr{S}_{i}
intersected by
S
. Then the marginal increase

g^{t}(\mathscr{S}_{i}\cup\{S\})-g^{t}(\mathscr{S}_{i})
is
m_{i}-1
unless
m_{i}=0
,
in which case the marginal increase is
0
. Because

\mathscr{S}_{1}\subseteq\mathscr{S}_{2}
, every set in
\mathscr{A}^{t}/\mathscr{S}_{2}
is a union of
sets in
\mathscr{A}^{t}/\mathscr{S}_{1}
, implying
m_{2}\leq m_{1}
. This shows
(
3.2
).
∎

Lemma 3.6
.

Let
\mathscr{S}
be a collection of vertex sets, each being actively
connected. Let
\mathcal{I}/\mathscr{S}
be the instance arising from the
original instance
\mathcal{I}
by contracting each set
S\in\mathscr{S}
.
Then we can efficiently compute a solution for the instance

\mathcal{I}/\mathscr{S}
of cost at most

\displaystyle 2\cdot y(\mathcal{U})-\operatorname{gain}(\mathscr{S}),

(3.3)

where
y
is solution from the extended algorithm.

Proof.

Consider a time-based moat-growing algorithm that receives the
vector
\mathbf{d}\in\mathbb{R}^{V}
of deactivation times of the vertices
as input, and increases a variable
y_{S}
corresponding to a
connected component whenever the current time
t
satisfies

t<\mathbf{d}_{v}
for at least one vertex
v\in S
. More precisely,
we again start with the vector
y(t)=0
and let
\mathcal{C}^{t}
be the
vertex sets of the connected components of the subgraph
(V,F)
,
where
F
is the set of tight edges at time
t
. A component

S\in\mathcal{C}^{t}
is active if
t<\mathbf{d}_{v}
for at least one vertex

v\in S
. Now we raise time
t
continuously at unit rate and
raise the dual variables
y_{S}(t)
of all active components

S\in\mathscr{A}^{t}
at the same rate; the
y_{S}(t)
values of all other
sets
S
remains unchanged. Once
t\geq\max_{v\in V}\mathbf{d}_{v}
,
the vector
y(t)
does not change anymore and this is what the
algorithm returns. This time-based moat-growing algorithm produces
exactly the same vector
\{y_{S}\}_{S\subseteq V}
as the extended
algorithm.

By
3.2
, all vertices contained in the
same set
S\in\mathscr{S}
have the same deactivation time. Thus all
vertices
v
in the instance
\mathcal{I}
that are contracted into the same
vertex of the instance
\mathcal{I}/\mathscr{S}
have the same deactivation time.
We define the deactivation time
\mathbf{d}^{\prime}_{w}
for a vertex
w
in the
contracted instance as the deactivation time
\mathbf{d}_{v}
of the
original vertices
v
contracted into
w
. We now run the
time-based moat-growing algorithm on the instance.

Let
y(t)
and
y^{\prime}(t)
denote the dual variables at time
t
in this
time-based run on the original instance
\mathcal{I}
and the contracted
instance
\mathcal{I}/\mathscr{S}
, respectively, and
\mathscr{A}^{t}
denote the active sets
at time
t
in the time-based run on
\mathcal{I}
. We show the following
invariants for any time
t\geq 0
:

(i)

The active sets in the time-based run
on
\mathcal{I}/\mathscr{S}
at time
t
are exactly the sets in
\mathscr{A}^{t}/\mathscr{S}
.

(ii)

For every edge
e
that does not have both endpoints in the same set from
\mathscr{A}^{t}/\mathscr{S}
, we have

\sum_{S\subseteq V:e\in\delta(S)}y^{\prime}_{S}(t)\ =\sum_{S\subseteq V:e\in\delta(S)}y_{S}(t).

These invariants are trivially satisfied for
t=0
. Note that the
active sets only change a finite number of times. If the invariants
hold at some time
t
, then growing the dual variables corresponding
to the active sets until some new edge becomes tight (in one of the
runs of the algorithms) maintains property
(ii)
,
because of property
(i)
. Then the active sets
might change; however, by property
(ii)
, every edge
that does not have both endpoints in the same set from
\mathscr{A}^{t}/\mathscr{S}

is tight in one of the two runs of the algorithm if and only if it
is tight in the other. Finally,
3.2

implies that all vertices contained in the same set
S\in\mathscr{S}
have
the same deactivation time, hence
(i)

is maintained.

Invariant
(i)
implies that every vertex that is not yet connected
to all of its partners at some time

is part of an active set at time

when running
the time-based algorithm on the contracted instance
\mathcal{I}/\mathscr{S}
.
Thus, the primal-dual algorithm from
[
AKR95
,
GW95
]
yields a feasible solution
H

of cost at most

c(H)\ \leq\ 2\cdot\int_{t=0}^{\infty}|\mathscr{A}^{t}/\mathscr{S}|\ dt\ =\ 2\cdot\int_{t=0}^{\infty}|\mathscr{A}^{t}|\ dt-\operatorname{gain}(\mathscr{S})\ =\ 2\cdot y(\mathcal{U})-\operatorname{gain}(\mathscr{S}).\qed

Definition 3.7

(Cost of a vertex set)
.

For a set
S\subseteq V
, let
\operatorname{cost}(S)
be the cost of a cheapest
Steiner tree for
S
, that is the minimum cost of an edge set

F\subseteq E
such that all vertices of
S
belong to the same
connected component of
(V,F)
. For a collection
\mathscr{S}
of vertex
sets, we define
\operatorname{cost}(\mathscr{S})\coloneqq\sum_{S\in\mathscr{S}}\operatorname{cost}(S)
.

3.2
An Efficient Algorithm

These results suggest the following algorithm: find a collection
\mathscr{S}

of actively connected sets for which
\operatorname{gain}(\mathscr{S})-\operatorname{cost}(\mathscr{S})
is
large, build Steiner trees on each of them, and then use

Lemma

3.6
to find a solution on the contracted instance.
In order to make the search over actively connected sets tractable, we
can use known results on
k
-restricted Steiner trees to restrict
ourselves to collections
\mathscr{S}
of actively connected sets that contain
only a constant number of vertices, as follows:

Lemma 3.8
.

Let
k\in\mathbb{N}_{\geq 2}
. For every actively connected set

S
, then there exists a collection
\mathscr{S}_{k}
of subsets of
S
, each
containing at most
k
elements, such that

•

\operatorname{cost}(\mathscr{S}_{k})\leq\big(1+\frac{1}{\lfloor\log_{2}k\rfloor}\big)\cdot\operatorname{cost}(S)
, and

•

{\rm gain}(\mathscr{S}_{k})={\rm gain}(\{S\})
.

Proof.

Let
T
be a cheapest Steiner tree for the set
S
. Then

\operatorname{cost}(S)=c(T)
. By a result due to Borchers and
Du
[
BD97
]
, there exists a
k
-restricted Steiner tree

T_{k}
for
S
satisfying

c(T_{k})\leq\big(1+\frac{1}{\lfloor\log_{2}k\rfloor}\big)\cdot\operatorname{cost}(S)
. In other words, there exists a collection
\mathscr{S}_{k}
of
subsets of
S
, each containing at most
k
elements, such that

(i)

the hypergraph with vertex set
S
and hyperedges being the sets in
\mathscr{S}_{k}
is connected, and

(ii)

\operatorname{cost}(\mathscr{S}_{k})\leq\big(1+\frac{1}{\lfloor\log_{2}k\rfloor}\big)\cdot\operatorname{cost}(S)
.

In order to prove
\operatorname{gain}(\mathscr{S}_{k})=\operatorname{gain}(\{S\})
, it suffices to show
that for every time
t\geq 0
, we have

|\mathscr{A}^{t}|-|\mathscr{A}^{t}/\mathscr{S}_{k}|\ =\ |\mathscr{A}^{t}|-|\mathscr{A}^{t}/\{S\}|
. We recall
that
\mathscr{A}^{t}/\{S\}
arises from
\mathscr{A}^{t}
by merging sets in
\mathscr{A}^{t}

into a single set whenever they are intersected by the same set
S
.

By the definition of
S
being actively connected, there exists a
time
t^{*}
such that
S\subseteq C
for some
C\in\mathcal{C}^{t^{*}}
, and
moreover, all vertices in
S
must be in active components at each
time
t<t^{*}
. The former fact means that
S
is contained in the
same connected component from
\mathcal{C}^{t}
at all times
t\geq t^{*}
,
implying
|\mathscr{A}^{t}|-|\mathscr{A}^{t}/\mathscr{S}_{k}|=0=|\mathscr{A}^{t}|-|\mathscr{A}^{t}/\{S\}|
.
For times
t<t^{*}
, each vertex in
S
is contained in some set
from
\mathscr{A}^{t}
. Thus, by
(i)
, we have

\mathscr{A}^{t}/\mathscr{S}_{k}=\mathscr{A}^{t}/\{S\}
, completing the proof. (See

Appendix

A
for an example where this last
equality fails if
S
is not actively connected.)
∎

This means that modulo an arbitrarily small loss, it suffices to
consider actively connected sets connecting at most
k
actively
connected vertices. Now, to approximately maximize the “profit”
(i.e.,
\operatorname{gain}(\mathscr{S})-\operatorname{cost}(\mathscr{S})
), we can use the submodularity of the

\operatorname{gain}
function to obtain the following theorem, which allows us to
improve upon the cost
2\cdot y(\mathcal{U})
of the solution obtained from
the extended moat-growing algorithm whenever there exists a collection

\mathscr{S}
of actively connected sets with
\operatorname{gain}(\mathscr{S})>\operatorname{cost}(\mathscr{S})
.

Theorem 3.9
.

Let
\mathcal{I}
be a given of the Steiner Forest problem and
\mathscr{S}
an (unknown) collection of vertex sets actively connected by
the extended algorithm.
Then, for any
\alpha\geq 0
and any
\delta>0
, we can find a Steiner forest
for
\mathcal{I}
, having cost at most

\displaystyle 2\cdot y(\mathcal{U})+(\alpha+\delta)\cdot\operatorname{cost}(\mathscr{S})-(1-e^{-\alpha})\cdot\operatorname{gain}(\mathscr{S})

in polynomial time.

Proof.

Let
k\in\mathbb{N}
be large enough such that

(\alpha+\nicefrac{{\delta}}{{2}})\cdot\big(1+\frac{1}{\lfloor\log_{2}k\rfloor}\big)\leq\alpha+\delta
. We say that a collection of actively
connected vertex sets is
k
-restricted if each of its sets has
cardinality at most
k
, i.e., it contains only sets from

\mathscr{A}_{k}\coloneqq\big\{S\subseteq V\colon S\text{ actively connected and }|S|\leq k\big\}.

By
Lemma

3.8
, there exists a

k
-restricted collection
\mathscr{S}_{k}\subseteq\mathscr{A}_{k}
of actively
connected sets such that
\operatorname{gain}(\mathscr{S}_{k})=\operatorname{gain}(\mathscr{S})
and

\operatorname{cost}(\mathscr{S}_{k})\leq\big(1+\frac{1}{\lfloor\log_{2}k\rfloor}\big)\cdot\operatorname{cost}(\mathscr{S})
. Because
|\mathscr{A}_{k}|=O(n^{k})
and
k
is a
constant, this set has polynomial size. Using that every set

A\in\mathscr{A}_{k}
has constant size, we can compute
\operatorname{cost}(A)
, that is
the cost of a cheapest Steiner tree for
A
, for all
A\in\mathscr{A}_{k}
in
polynomial time by
[
DW71
]
. The function

\operatorname{cost}:2^{\mathscr{A}_{k}}\to\mathbb{R}_{\geq 0}
is modular (by
definition) and by
Lemma

3.5
, the function

\operatorname{gain}:2^{\mathscr{A}_{k}}\to\mathbb{R}_{\geq 0}
is submodular. Thus,
using ideas from submodular optimization subject to knapsack
constraints (see
Appendix

B
) we can compute a collection

\widetilde{\mathscr{S}}\subseteq\mathscr{A}_{k}
satisfying

\displaystyle\operatorname{gain}(\widetilde{\mathscr{S}})-\operatorname{cost}(\widetilde{\mathscr{S}})\ \geq\ (1-e^{-\alpha})\cdot\operatorname{gain}(\mathscr{S}_{k})-(\alpha+\nicefrac{{\delta}}{{2}})\cdot\operatorname{cost}(\mathscr{S}_{k})

in time
O(n^{O(1/\delta)})
. By
Lemma

3.6
, we obtain a
solution to the contracted instance
\mathcal{I}/\mathscr{S}
of cost at most

2\cdot y(\mathcal{U})-{\rm gain}(\widetilde{\mathscr{S}})
. The union of this
solution and cheapest Steiner trees for all sets

S\in\widetilde{\mathscr{S}}
is a feasible solution to the instance
\mathcal{I}

of cost

\displaystyle 2\cdot y(\mathcal{U})-{\rm gain}(\widetilde{\mathscr{S}})+\operatorname{cost}(\widetilde{\mathscr{S}})\ \leq

\displaystyle\ 2\cdot y(\mathcal{U})-(1-e^{-\alpha})\cdot\operatorname{gain}(\mathscr{S}_{k})+(\alpha+\nicefrac{{\delta}}{{2}})\cdot\operatorname{cost}(\mathscr{S}_{k})

\displaystyle\leq

\displaystyle\ 2\cdot y(\mathcal{U})+(\alpha+\delta)\cdot\operatorname{cost}(\mathscr{S})-(1-e^{-\alpha})\cdot\operatorname{gain}(\mathscr{S}),

where we used
\operatorname{gain}(\mathscr{S}_{k})=\operatorname{gain}(\mathscr{S})
and

(\alpha+\nicefrac{{\delta}}{{2}})\cdot\operatorname{cost}(\mathscr{S}_{k})\leq(\alpha+\nicefrac{{\delta}}{{2}})\cdot\big(1+\frac{1}{\lfloor\log_{2}k\rfloor}\big)\cdot\operatorname{cost}(\mathscr{S})\leq(\alpha+\delta)\cdot\operatorname{cost}(\mathscr{S})
.
∎

3.3
The Path Forward

To get a good approximation for Steiner forest, the natural next step

This is easy for the special case of Steiner

(up to one set at a time, which is the slack we already have in the

4
Autarkic Collections

We start off with defining the notion of autarkic pairs from
[
AGH+25b
]
,
which we then extend to triples to obtain our improved bounds. The
concept of an autarkic pair is motivated by the example in

Figure

1
. To handle such instances, we would like to
identify a suitable subset of the demand pairs—in this case the
demand pairs
\{a_{1},b_{1}\},\dots,\{a_{k},b_{k}\}
—contract them, and
apply a
2
-approximation algorithm to the resulting instance. Then
we obtain a solution to the original instance by adding a shortest
path between any two contracted vertices.

Now consider a variant of the same example containing multiple copies
of each demand pair
\{a_{i},b_{i}\}
, where all copies of
a_{i}
are at
distance
\delta\approx 0
from each other, and the same for copies
of
b_{i}
. We cannot afford paying for a separate shortest path for
each copy, so we would want to contract a single one of these copies.
Thus, autarkic pairs are defined not as demand pairs, but as pairs of
sets (e.g., the pairs
\{A_{i},B_{i}\}
in the right figure); and we
later choose one demand pair as the designated representative for the
autarkic pair. Only these designated representatives are contracted
to obtain the residual instance.

We now formalize this, and generalize it to triples. Given a set

S\in\operatorname{supp}(y)
, define
\operatorname{sep}(S)
to be the set of demand pairs
separated by
S
—i.e.,

\operatorname{sep}(S):=\{\{a_{i},b_{i}\}\in\mathcal{D}\mid|\{a_{i},b_{i}\}\cap S|=1\}.

Definition 4.1

(Autarkic Pairs)
.

For sets
A,B\in\operatorname{supp}(y)
, define
P=\{A,B\}
to be an

autarkic pair
if
A\cap B=\varnothing
, both
A,B\in\mathscr{A}^{t}

for some time
t
, and
\operatorname{sep}(A)=\operatorname{sep}(B)\neq\varnothing
. We overload notation
and define
\operatorname{sep}(P):=\operatorname{sep}(A)\cup\operatorname{sep}(B)=\operatorname{sep}(A)
.

For our work, we generalize this notion to triples:

Definition 4.2

(Autarkic Triples)
.

Define
P=\{A_{1},A_{2},A_{3}\}
to be an
autarkic triple
if

1.

the sets
A_{i}
are disjoint,

2.

there exists a time
t
such that
A_{i}\in\mathscr{A}^{t}
for all
i

(and hence each
A_{i}\in\operatorname{supp}(y)
),

3.

\operatorname{sep}(A_{i})\neq\varnothing
, but

4.

\operatorname{sep}(A_{1}\cup A_{2}\cup A_{3})=\varnothing
.

Define the separated pairs for
P
to be

\operatorname{sep}(P):=\cup_{i}\operatorname{sep}(A_{i})
.

In words, the demands individually separated by these sets
A_{i}
cross
between these sets, but there are no demands going outside their
union. We use the term
autarkic tuples
to denote both pairs and
triples, and the term
autarkic collection
for a collection of
such tuples.

Definition 4.3

(Crossing-Free Collection)
.

An autarkic collection
\mathscr{P}
is

crossing-free
if
\operatorname{sep}(P)\cap\operatorname{sep}(Q)=\varnothing
for all
P\neq Q
with
P,Q\in\mathcal{P}
.

Definition 4.4

(Coverage of
\mathscr{P}
)
.

We say that a set
U\in\operatorname{supp}(y)
is

a

\mathscr{P}
if there exists a

P\in\mathscr{P}
and some set
A_{i}\in P
such that

\operatorname{sep}(A_{i})=\operatorname{sep}(U)
. Given

, define the coverage of
\mathscr{P}
as

\displaystyle\operatorname{coverage}(\mathscr{P}):=\sum_{U\subseteq V:\mathscr{P}\text{ covers }U}y_{U}.

(4.1)

4.1
Connecting Autarkic Tuples and Residual Instances

For each autarkic tuple
P
, we define the
connector
of
P
as follows:

1.

For each pair
P\in\mathscr{P}
, pick a demand pair

\{a,b\}\in\operatorname{sep}(P)
as its
designated representative
.
Define the connector for
P
as the direct edge
\{a,b\}
.

2.

For each triple
P=(A_{1},A_{2},A_{3})\in\mathscr{P}
, for each

i\neq j\in\{1,2,3\}
such that

\operatorname{sep}(A_{i})\cap\operatorname{sep}(A_{j})\neq\varnothing
, choose a demand pair

\{a_{ij},b_{ij}\}
from
\operatorname{sep}(A_{i})\cap\operatorname{sep}(A_{j})
as the

designated representative
. Define the connector for
P
as
the minimum Steiner tree on these (at least three and at most six)
vertices which are designated representatives.

Definition 4.5

(Cost and Profit for
\mathscr{P}
)
.

For an autarkic tuple
P
, let
\operatorname{cost}(P)
be the total length of the
connector for
P
; for a collection
\mathscr{P}
, define

\operatorname{cost}(\mathscr{P})=\sum_{P\in\mathscr{P}}\operatorname{cost}(P)
. Define

\displaystyle\operatorname{profit}(\mathscr{P})=2\cdot\operatorname{coverage}(\mathscr{P})-\operatorname{cost}(\mathscr{P}).

(4.2)

Theorem 4.6

(Efficient Algorithm)
.

There is an efficient algorithm to find a crossing-free autarkic collection

\mathscr{P}
that maximizes
\operatorname{profit}(\mathscr{P})
.

The main idea of this algorithm is to show a “laminar” structure on
the autarkic tuples, which allows us to then find the best
crossing-free collection using dynamic programming; we defer the proof
to
Section

4.2
. Given a crossing-free autarkic collection

\mathscr{P}
, we define the contracted instance
\mathcal{I}/\mathscr{P}
as the instance
obtained by contracting the connectors for each
P\in\mathscr{P}
, and the
cost
\operatorname{cost}(\mathscr{P}):=\sum_{P\in\mathscr{P}}\operatorname{cost}(P)
as the sum of costs of
the connectors. The following key lemma quantifies the gain
from
\mathscr{P}
:

Lemma 4.7
.

Let
\mathscr{P}
be a crossing-free autarkic collection. Then
there exists a solution for the contracted instance
\mathcal{I}/\mathscr{P}
of
cost at most

\displaystyle c(\operatorname{OPT}(\mathcal{I}))-{\rm coverage}(\mathscr{P})+\sum_{\begin{subarray}{c}S\subseteq V:\\
|\operatorname{OPT}\cap\delta(S)|\geq 2\end{subarray}}y_{S}.

(4.3)

Proof.

Consider any set
U\subseteq V
covered by
\mathscr{P}
. Then OPT contains
at least one edge in

We can now give the algorithm to find the profit-maximizing autarkic

See
4.6

Proof of
Theorem

4.6
.

If

\operatorname{profit}(\mathscr{P})=\sum_{P\in\mathscr{P}}\operatorname{profit}(\{P\})

maximizing the sum of the profits
\operatorname{profit}(\{P\})
with
P\in\mathscr{P}
.

Because there is only a polynomial number of autarkic tuples, we can

for each autarkic tuple. Let

be the set of
all autarkic tuples. We show how to use the laminarity to

with maximum profit using a dynamic program. In our dynamic

in an

before

are given the collections
\mathscr{P}(P)
for all
P\in\mathcal{Q}
with

P\subset Q
.

To compute

or not) and take a solution with maximum
profit among these two. If

be the autarkic tuples with

that
are maximal with respect to the partial order
\subseteq

for all

are disjoint and their union

is crossing-free.
Therefore, by the profit-maximality of the sets
\mathscr{P}(P_{i})
, this
union is a maximum-profit subset of

\{P\in\mathcal{Q}:P\subseteq Q\}\setminus\{Q\}
.

Now it remains to consider the case

. Among all
autarkic tuples
P
that are not crossing

(i.e., tuples

such
that
\operatorname{sep}(P)\cap\operatorname{sep}(Q)=\varnothing
) and satisfy

P_{1},\dots,P_{k}
be those autarkic tuples that are maximal with

\subseteq
. We claim that

\mathscr{P}\coloneqq\{Q\}\cup\mathscr{P}(P_{1})\cup\mathscr{P}(P_{2})\cup\dots\cup\mathscr{P}(P_{k})

\mathscr{P}(P_{i})

Suppose for the sake of a contradiction that

5
The Algorithm for Steiner Forest

Given the machinery developed in the preceding sections, the algorithm
for Steiner forest can be compactly described:

(1)

\varepsilon
-extended moat-growing algorithm to
define the active components
\mathscr{A}^{t}

.

(2)

Start with the duals from Step

3.9
get a

.

(3)

Again, start with the duals from Step

to find a maximum-profit autarkic collection

-approximation algorithm on the contracted instance

. This gives the solution

.

(4)

Among these three solutions, return the solution with least cost.

We show that, given the dual solution
y
:

Theorem 5.1
.

There exists a collection
\mathscr{S}
of actively connected vertex sets,
and a crossing-free autarkic collection
\mathscr{P}
such that

\frac{10}{3}\cdot(\operatorname{gain}(\mathscr{S})-\operatorname{cost}(\mathscr{S}))+(2\operatorname{coverage}(\mathscr{P})-\operatorname{cost}(\mathscr{P}))+\Big(\frac{1}{2\varepsilon}+17\Big)\cdot\operatorname{excess}(\operatorname{OPT})\ \geq\ y(\mathcal{U}_{\rm{sep}}).

In other words, (i) either the
\operatorname{excess}(\operatorname{OPT})
is large, or (ii) there
exists a collection
\mathscr{S}^{*}
of actively connected vertex sets with
large gain, or (iii) there exists an autarkic collection
\mathscr{P}^{*}
with

that the best of

,

, and

is a

-approximation to

Two asides: to get the best approximation guarantee, we don’t just use

involved in its proof. Moreover, we can show that just taking the

and

suffices (since the forest

is essentially what we get as

We prove

a,a^{\prime}\in U
). Observe that the optimal
trees connecting

must belong to the same forest

of
\mathcal{F}
,
by construction. Moreover, the set
\{a,b,a^{\prime},b^{\prime}\}
belongs to the
same equivalence class of actively connected vertices:
\{a,a^{\prime}\}

because they both lie in

while both are still active,

\{a,b\},\{a^{\prime},b^{\prime}\}
because any demand pair must be actively

belongs to the same equivalence class, then

, else neither will be,

.
∎

Lemma 6.4

(Cheap Trees)
.

The collection
\mathscr{S}
satisfies:

\sum_{S\in\mathscr{S}}c(T_{S})\ \leq\ \operatorname{value}(\mathscr{S})+2\cdot\operatorname{excess}(\operatorname{OPT}).

(6.1)

Proof.

For a connected component
T
of OPT, define its excess as

\displaystyle\operatorname{excess}(T)\coloneqq c(T)-\operatorname{value}(\{V(T)\})\ \geq\ c(T)-\sum_{U:T\cap\delta(U)\neq\varnothing}y_{U}\ \geq\ 0,

(6.2)

where the last inequality holds because
y
satisfies the dual LP
constraints. Using that every demand pair is satisfied by exactly
one connected component of OPT, and that the value function assigns
each set
U\in\mathcal{U}_{\rm{sep}}
to exactly one demand pair, we get

\displaystyle\operatorname{excess}(\operatorname{OPT})\ =

\displaystyle\ c(\operatorname{OPT})-\sum_{U\in\mathcal{U}_{\rm{sep}}}y_{U}

\displaystyle=

\displaystyle\ c(\operatorname{OPT})-\operatorname{value}\big(\{V(T):T\text{ connected comp. of OPT}\}\big)

\displaystyle=

\displaystyle\ \sum_{\begin{subarray}{c}T:\text{ conn. comp.}\\
\text{of OPT}\end{subarray}}\Big(c(T)-\operatorname{value}(\{V(T)\})\Big)

\displaystyle=

\displaystyle\ \sum_{\begin{subarray}{c}T:\text{ conn. comp.}\\
\text{of OPT}\end{subarray}}\operatorname{excess}(T).

Because the sets in
\mathscr{S}
are disjoint, we have

\operatorname{value}(\mathscr{S})=\sum_{S\in\mathscr{S}}\operatorname{value}(\{S\})
. Thus, it suffices to
show that for any single connected component
T
of
\operatorname{OPT}
and the
unique set
S\in\mathscr{S}
corresponding to
T
(if such a set
S

exists), we have

c(T_{S})\ \leq\ \operatorname{value}(\{S\})+2\cdot\operatorname{excess}(T).

(6.3)

To prove (
6.3
), we relate the
difference
c(T)-c(T_{S})
with
\operatorname{value}(\{V(T)\})-\operatorname{value}(\{S\})
. Indeed, let
\mathcal{U}_{\rm loss}\subseteq\mathcal{U}_{\rm{sep}}

be the set of all
U\in\mathcal{U}_{\rm{sep}}
for which the demand pair

\varphi(U)
is satisfied by
V(T)
but not by
S
. Then we have

y(\mathcal{U}_{\rm loss})=\operatorname{value}(\{V(T)\})-\operatorname{value}(\{S\}).

(6.4)

Next, we establish a lower bound on
c(T)-c(T_{S})
. Consider a set

U\in\mathcal{U}_{\rm loss}
. We show that
S\cap U=\varnothing
. Say
\varphi(U)=\{a,b\}
with
a\in U
. By definition
of
\mathcal{U}_{\rm loss}
, the demand pair
\varphi(U)
is not
satisfied by
S
. Because the two vertices of a demand pair are
always actively connected to each other, by construction of
S
,
neither of
\{a,b\}
is actively connected to the vertex
r_{F}
(for
the forest
F\in\mathcal{F}
that has
T
as a connected
component). Because
U\in\operatorname{supp}(y)
, every vertex
w\in U
is
either actively connected to
a
or has an deactivation time
strictly smaller than
a
’s. In the former case,
w
lies in the
same equivalence class of actively connected components as
a
, and
hence cannot be actively connected to
r_{F}
. In the latter case,
w

has strictly smaller deactivation time than
a
, and thus strictly
than
r_{F}
(since
r_{F}
was chosen to have the largest deactivation
time among all vertices in
F
). In both cases, we conclude that

w\in U
is not actively connected to
r_{F}
and hence not contained
in
S
. This shows
S\cap U=\varnothing
.

This claim means that if
T\cap\delta(U)=1
, then the unique edge
in
T\cap\delta(U)
cannot be connecting two vertices in
S
, and
is not part of the tree
T_{S}
. Using that
y
satisfies the dual LP
constraints, we get

\sum_{\begin{subarray}{c}U\in\mathcal{U}_{\rm loss}:\\
|T\cap\delta(U)|=1\end{subarray}}y_{U}\ \leq\ \sum_{U:(T\setminus T_{S})\cap\delta(U)\neq\varnothing}y_{U}\ \leq\ c(T\setminus T_{S})=c(T)-c(T_{S}).

(6.5)

Combining
(
6.4
) and (
6.5
), we obtain

\displaystyle c(T_{S})-\operatorname{value}(\{S\})\ \leq

\displaystyle\ c(T)-\sum_{\begin{subarray}{c}U\in\mathcal{U}_{\rm loss}:\\
|T\cap\delta(U)|=1\end{subarray}}y_{U}-\operatorname{value}(\{V(T)\})+y(\mathcal{U}_{\rm loss})

\displaystyle=

\displaystyle\ \operatorname{excess}(T)+\sum_{\begin{subarray}{c}U\in\mathcal{U}_{\rm loss}:\\
|T\cap\delta(U)|>1\end{subarray}}y_{U}

(6.6)

\displaystyle\leq

\displaystyle\ 2\cdot\operatorname{excess}(T);

in equality (
6.6
) we used that
|T\cap\delta(U)|\geq 1
for all

U\in\mathcal{U}_{\rm loss}
, because
T
satisfies the demand
pair
\varphi(U)
separated by
U
. This allowed to partition

y(\mathcal{U}_{\rm loss})
into sums over those
U
’s which are crossed by

T
exactly once, and more than once. This shows
(
6.3
) and completes the proof of

Lemma

6.4
.
∎

Lemma 6.5

(Non-Trivial Excess)
.

The collection
\mathscr{S}
satisfies:

\operatorname{excess}(\operatorname{OPT})\ \geq\ 2\varepsilon\cdot\Big(y(\mathcal{U}_{\rm{sep}})-\operatorname{value}(\mathscr{S})\Big).

(6.7)

Proof.

It suffices to show that

\sum_{\begin{subarray}{c}W\in\mathcal{U}_{\rm unsep}:\\
\operatorname{OPT}\cap\delta(W)\neq\varnothing\end{subarray}}y_{W}\ \geq\ \varepsilon\cdot\big(y(\mathcal{U}_{\rm{sep}})-\operatorname{value}(\mathscr{S})\big).

(6.8)

Indeed, if
\operatorname{OPT}\cap\delta(W)
contains only a single edge, then
because
W
does not separate any demand pair, we could remove this
edge and maintain a feasible solution, contradicting the minimality
of OPT. Therefore, for every
W\in\mathcal{U}_{\rm unsep}
, we
have
\operatorname{OPT}\cap\delta(W)=\varnothing
or

|\operatorname{OPT}\cap\delta(W)|\geq 2
. The definition of excess combined
with (
6.8
) implies

\operatorname{excess}(\operatorname{OPT})\geq\sum_{W\in\mathcal{U}_{\rm unsep}}|\operatorname{OPT}\cap\delta(W)|\cdot y_{W}\ \geq\ 2\cdot\sum_{\begin{subarray}{c}W\in\mathcal{U}_{\rm unsep}:\\
\operatorname{OPT}\cap\delta(W)\neq\varnothing\end{subarray}}y_{W}\ \geq\ 2\varepsilon\cdot\big(y(\mathcal{U}_{\rm{sep}})-\operatorname{value}(\mathscr{S})\big).

In the rest of the proof, we show (
6.8
).

We consider a set
U
from
\mathcal{U}_{\rm{sep}}
. Because
U\in\mathcal{U}_{\rm{sep}}
, the
moat-growing process generates
\varepsilon\cdot y_{U}
money when
growing
U
. Consider some set
W\in\mathcal{U}_{\rm unsep}
whose
growth was (partially) paid by some money collected by
U
. We show
that either
\varphi(U)
is satisfied by
\mathscr{S}
, i.e.,
U

contributes to
\operatorname{value}(\mathscr{S})
, or
\operatorname{OPT}\cap\delta(W)\neq\varnothing
.
Note that this implies (
6.8
).

Let
F\in\mathcal{F}
be the forest satisfying the demand pair

\varphi(U)
; such a forest exists because
\mathcal{F}
partitions

\operatorname{OPT}
. If
\operatorname{OPT}\cap\delta(W)=\varnothing
, every connected
component of
F
is either completely inside
W
, or completely
outside of
W
. Because
U
pays for
W
, we have
U\subseteq W
,
and hence at least one connected component of
F
is inside
W
. We
now distinguish two cases.

The first case is where some connected component of
F
is outside

W
. Then, by construction of
\mathcal{F}
, there must be some set

\widehat{U}\in\mathcal{U}_{\rm{sep}}
and two connected components
T_{1}
and
T_{2}

of
F
such that

•

T_{1}
is inside
W
and
T_{2}
is outside
W
, and

•

each of the trees
T_{1}
and
T_{2}
satisfies some demand pair separated by
\widehat{U}
.

This implies
\widehat{U}\cap W\neq\varnothing
and

\widehat{U}\cap(V\setminus W)\neq\varnothing
. Now since both
W

and
\widehat{U}
belong to the support of
y
, this contradicts the
laminarity of the support of
y
.

The second case is where the forest
F
is completely inside
W
.
We now show that
\varphi(U)
is satisfied by
\mathscr{S}
, i.e.,
U

contributes to
\operatorname{value}(\mathscr{S})
. Let
u\in U
be the vertex of the
demand pair
\varphi(U)
that is contained in
U
. Because
U

separates
\varphi(U)
, the vertex
u
was still active at any time
when
y_{U}
was growing. Because
U
paid for
W
, the vertex
u

remained active at least until the time when
y_{W}
was growing,
using money generated by
U
. Thus, by the choice of the vertex

r_{F}
, also
r_{F}
was still active when
y_{W}
was growing using
money generated by
U
. Using
u\in U\subseteq W
and

r_{F}\in W
, we conclude that
r_{F}
and
u
are actively connected,
i.e.,
u\in S
for the set
S
corresponding to the connected
component
T
of
F
that contains
u
. Because the elements of
every demand pair are actively connected, this implies that

\varphi(U)
is satisfied by
S
.
∎

6.2
Constructing the autarkic collection
\mathscr{P}
from
\operatorname{OPT}

Having constructed the canonical collection
\mathscr{S}
of actively
connected sets in the preceding section, we now show that if
\mathscr{S}
has
small gain relative to its cost, and the excess is small, there is an
autarkic collection
\mathscr{P}
with large profit.

Lemma 6.6
.

Let
\mathscr{S}
be the agreeable collection of actively connected vertex
sets constructed in
Section

6.1
. Then there exists
a crossing-free autarkic collection
\mathscr{P}
such that

\frac{10}{3}\cdot(\operatorname{gain}(\mathscr{S})-\operatorname{cost}(\mathscr{S}))+\operatorname{profit}(\mathscr{P})+17\cdot\operatorname{excess}(\operatorname{OPT})\geq\operatorname{value}(\mathscr{S}).

(6.9)

Let
\mathcal{U}_{\mathscr{S}}
be the collection of sets contributing to
\operatorname{value}(\mathscr{S})
,
that is

\mathcal{U}_{\mathscr{S}}\ \coloneqq\ \{U\in\operatorname{supp}(y)\cap\mathcal{U}_{\rm{sep}}:\mathscr{S}\text{ satisfies }\varphi(U)\}.

and for
S\in\mathscr{S}
, let
\mathcal{U}_{S}\coloneqq\mathcal{U}_{\{S\}}
be the
collection of sets contributing to
\operatorname{value}(\{S\})
. For any time
t
,
let
\mathcal{U}_{\mathscr{S}}^{t}:=\mathcal{U}_{\mathscr{S}}\cap\mathscr{A}^{t}
and
\mathcal{U}_{S}^{t}:=\mathcal{U}_{S}\cap\mathscr{A}^{t}
be the corresponding sets that are active at time
t
.
Then

\operatorname{value}(\mathscr{S})\ =\ \int_{t=0}^{\infty}|\mathcal{U}_{\mathscr{S}}^{t}|\ dt\ =\ \sum_{S\in\mathscr{S}}\int_{t=0}^{\infty}|\mathcal{U}_{S}^{t}|\ dt.

(6.10)

For a time
t
and a set
U\in\mathcal{U}_{\mathscr{S}}^{t}
, let

m(U,t)\geq 0
be the number of sets from
\mathcal{U}_{\mathscr{S}}^{t}

which with the set
U
is merged when going from
\mathscr{A}^{t}
to

\mathscr{A}^{t}/\mathscr{S}
. Because the demand pair
\varphi(U)
is separated by

U
, there is some set in
\mathscr{A}^{t}\setminus\{U\}
that is also
separated by
\varphi(U)
. Since
\mathscr{S}
satisfies the demand pair

\varphi(U)
, the set
U
is merged with at least one other set when
going from
\mathscr{A}^{t}
to
\mathscr{A}^{t}/\mathscr{S}
, and so
m(U,t)\geq 1
. We observe
that

{\rm gain}(\mathscr{S})\ =\ 2\cdot\int_{t=0}^{\infty}\big(|\mathscr{A}^{t}|-|\mathscr{A}^{t}/\mathscr{S}|\big)\ dt\ \geq\ 2\cdot\int_{t=0}^{\infty}\sum_{U\in\mathcal{U}_{\mathscr{S}}^{t}}\frac{m(U,t)}{m(U,t)+1}\ dt.

(6.11)

Recall from
Lemma

6.4
that the
cost term is approximately equal to
\operatorname{value}(\mathscr{S})
. Consequently, if

m(U,t)\geq 2
—i.e., when each set is being merged with at least
two others—most of the time, we get a contribution from
\operatorname{gain}(\mathscr{S})

that is much more than
\operatorname{cost}(\mathscr{S})
. In fact, the larger the value of

m(U,t)
, the easier the proof. The tricky cases are when

m(U,t)=1
, but then it seems natural to extract out autarkic pairs,
which is exactly what the rest of the construction does.

Definition 6.7

(
S
-Good/Bad Times)
.

For a set
S\in\mathscr{S}
, a time
t\geq 0
is called
S
-bad
if
some set
U\in\mathscr{A}^{t}
that separates
S
also separates some other
set
S^{\prime}\in\mathscr{S}\setminus\{S\}
; otherwise, the time
t
is

S
-good
.

The following lemma formalizes the intuition that a small excess means
that bad times are rare; in fact, for the first read, one could
imagine all times being good. (Their presence just adds complexity to
the proof, and increases the constant in front of the
\operatorname{excess}(\operatorname{OPT})

term.)

Lemma 6.8

(Few Bad Times)
.

We have

B(\mathscr{S})\ \coloneqq\ \int_{t=0}^{\infty}|\{S\in\mathscr{S}:t\text{ is $S$-bad}\}|\ dt\ \leq\ 2\cdot\operatorname{excess}(\operatorname{OPT}).

Proof.

Using the dual feasibility of
y
and
|\operatorname{OPT}\cap U|\geq 1
for all

U\in\mathcal{U}_{\rm{sep}}
, we have

\displaystyle\operatorname{excess}(\operatorname{OPT})\ =

\displaystyle\ c(\operatorname{OPT})-\sum_{U\in\mathcal{U}_{\rm{sep}}}y_{U}\ \geq\ \sum_{U\in\operatorname{supp}(y)}y_{U}\cdot|\operatorname{OPT}\cap\delta(U)|-\sum_{U\in\mathcal{U}_{\rm{sep}}}y_{U}

\displaystyle\geq

\displaystyle\ \sum_{U\in\operatorname{supp}(y)}y_{U}\cdot\max\big\{|\operatorname{OPT}\cap\delta(U)|-1,0\big\}

\displaystyle=

\displaystyle\ \int_{t=0}^{\infty}\sum_{U\in\mathscr{A}^{t}}\max\big\{|\operatorname{OPT}\cap\delta(U)|-1,0\big\}.

Thus, it suffices to show that for every time
t\geq 0
, we have

|\{S\in\mathscr{S}:t\text{ is $S$-bad}\}|\ \leq\ 2\cdot\sum_{U\in\mathscr{A}^{t}}\max\big\{|\operatorname{OPT}\cap\delta(U)|-1,0\big\}.

(6.12)

Call a set
U\in\mathscr{A}^{t}

double-crossing
if

|\operatorname{OPT}\cap\delta(U)|>1
. The collection
\mathscr{S}
is agreeable, so
property
(A1)
means that each

S\in\mathscr{S}
is a subset of some tree in
\operatorname{OPT}
. Thus, if some set

U\in\operatorname{supp}(y)
separates some
k
sets from
\mathscr{S}
, then we have

|\operatorname{OPT}\cap\delta(U)|\geq k
. If
U
is double-crossing, it can
give out
k\geq 2
tokens, and each set
S\in\mathscr{S}
separated by it
can collect one such token. By the definition of
S
-bad times,
every set
S
for which the time
t
is
S
-bad then receives at
least one token. Moreover, since
k\geq 2
,

k\leq 2\,\max(k-1,0)
, which implies (
6.12
), and
completes the proof.
∎

6.2.1
Lower-Bounding the Benefit from
\mathscr{S}

In order to prove

, we separate out

(whether the number is

, or higher)—since these

We prove bounds on

) and the fact that the sets

with

, we then get

.

{\rm gain}(\mathscr{S})-\operatorname{cost}(\mathscr{S})\ \geq\ \tfrac{1}{3}\cdot(x_{2}+\overline{x}_{2})+\tfrac{1}{2}\cdot x_{3}-2\cdot\operatorname{excess}(\operatorname{OPT}).

Proof.

Using (

) and the definition of

, we have

\displaystyle{\rm gain}(\mathscr{S})\ \geq

Moreover, combining

and

), we get

6.2.2
Extracting the Autarkic Collection
\mathscr{P}

Definition 6.10

(

-relevant)
.

For a set
S\in\mathscr{S}
, we say that a set

is

-relevant
if
\operatorname{sep}(U)
contains some demand pair satisfied
by

.

Observe that every
S
-relevant set

separates the set

.

Definition 6.11

(Connection Time)
.

For a demand pair, let the

of the pair be the

sets in
\mathscr{A}^{t}
.

Note that the connection time of the pair is never more than the

Lemma 6.12
.

There is a crossing-free autarkic collection
\mathscr{P}
such that

\displaystyle\operatorname{coverage}(\mathscr{P})\ \geq

\displaystyle\ x_{1}

\displaystyle\operatorname{cost}(\mathscr{P})\ \leq

\displaystyle\ x_{1}+\overline{x}_{1}+x_{2}+\overline{x}_{2}+x_{3}+2\cdot\operatorname{excess}(\operatorname{OPT}).

To construct
\mathscr{P}
, we proceed as follows, starting with

\mathscr{P}=\varnothing
. For each set

, we consider the smallest

S
-good time

, where

contains at most two

S
-relevant sets. If
\mathscr{A}^{t^{\prime}}
contains some

-relevant set,
then there are exactly two

-relevant sets

.
Because the sets

. In order to show that

. Since

\mathscr{S}
is agreeable and

satisfies some demand pair in

\operatorname{sep}(A_{i})
, every demand pair in
\operatorname{sep}(A_{1})
is satisfied by the

\mathscr{S}
. The time

being

\operatorname{sep}(A_{1})
is satisfied by the set

. Any demand

has a connection time strictly larger than

because

and thus both vertices of such a demand

\mathscr{A}^{t^{\prime}}
. But

and
A_{2}

are the only

-relevant sets in
\mathscr{A}^{t^{\prime}}
, so one vertex of the

and the other in

. This shows
that any demand pair in
\operatorname{sep}(A_{1})
is also contained in

\operatorname{sep}(A_{2})
. By symmetry, we also have

Next, we show that the autarkic collection

We now bound the coverage and cost of the collection
\mathscr{P}

Appendix B
Submodular Optimization with Knapsacks

We are given a submodular function
f:2^{X}\to\mathbb{R}_{\geq 0}
, where

f(\varnothing)=0
, and each element
x\in X
has a cost
c(x)
. For
simplicity, assume that the costs are distinct. Let

S^{*}=\arg\max_{S\subseteq X}[f(S)-c(S)]
. We claim the following:

Theorem B.1
.

There exists an algorithm that given
\alpha\in[0,1]
and

\gamma>0
, finds a set
S\subseteq X
such that

\displaystyle f(S)-c(S)\geq\big(1-e^{-\alpha}\big)\cdot f(S^{*})-(\alpha+\gamma)\cdot c(S^{*}).

(B.1)

Moreover, the algorithm runs in time
n^{O(1/\gamma)}
.

Proof.

To prove this, let us first consider the case where each element has
cost
c(e)\leq C_{\max}
for some value
C_{\max}
. In this case,
consider the algorithm that starts with the empty set and picks
elements greedily, setting

e_{i+1}=\arg\max_{e\in X}\frac{f_{S_{i}}(e)}{c(e)}
, where

S_{i}=\{e_{1},\ldots,e_{i}\}
is the set of the first
i
elements to
be picked and
f_{S_{i}}(e)\coloneqq f(S_{i}\cup\{e\})-f(S_{i})
.
Return the set
S_{i}
that maximizes
f(S_{i})-c(S_{i})
. It
suffices to show that there exists a good set.

Indeed, consider the first index
k
such that

c(S_{k})\geq\alpha c(S^{*})
; a
standard submodularity-based analysis shows that:

f(S_{k})\geq\big(1-e^{-c(S_{k})/c(S^{*})}\big)\cdot f(S^{*})\geq(1-e^{-\alpha})\cdot f(S^{*}).

(See, e.g.,

[
CV25
, Proposition 2.2]
; for completeness we present their proof
in
Proposition

B.2
.) Since the elements have cost at most
C_{\max}
, we know
that
c(S_{k})\leq\alpha\,c(S^{*})+C_{\max}
, we get that

f(S_{k})-c(S_{k})\geq(1-e^{-\alpha})\cdot f(S^{*})-(\alpha\,c(S^{*})+C_{\max}).

If
C_{\max}\leq\gamma c(S^{*})
, we would
get the bound claimed in (
B.1
).

To handle the general case where the costs may be larger than

\gamma\,c(S^{*})
, we need a partial enumeration strategy. We guess
the (at most)
1/\gamma
elements in
S^{*}
that have cost more than

\gamma\,c(S^{*})
. Moreover, since we do not know the cost

c(S^{*})
, we also guess the maximum-cost element in
X
that is at
most
\gamma\,c(S^{*})
, so that we can define the set of
“low-cost” elements on which to run the above algorithm. Indeed,
the algorithm for the general case is the following:

1.

Enumerate over sets
S^{\prime}
of at most
1/\gamma
elements, and
one extra element
e_{0}
.

2.

Define
X^{\prime}:=\{e\in X\mid c(e)\leq c(e_{0})\}
, and define
submodular function
g(S):=f_{S^{\prime}}(S)
over the ground set

X^{\prime}
. Use the above procedure on submodular function
g
over
ground set
X^{\prime}
to find a solution
S^{\prime\prime}
.

3.

Among all these solutions, return the solution with largest

f(S)-c(S)
, where
S=S^{\prime}\cup S^{\prime\prime}
.

To prove the approximation guarantee, consider the run where we
correctly guess the elements
S^{\prime}
to be those in
S^{*}
having cost
strictly more than
\gamma\,c(S^{*})
, and also correctly guess
e_{0}

so that
X^{\prime}=\{e\in X\mid c(e)\leq\gamma\,c(S^{*})\}
. Define

H^{*}=S^{*}\setminus X^{\prime}
and
L^{*}=S^{*}\cap X^{\prime}
; by assumption, we
are focusing on the guess where
H^{*}=S^{\prime}
, and also
L^{*}\subseteq X^{\prime}

with
C_{\max}\leq\gamma\,c(S^{*})
. Now the algorithm’s
solution
S=S^{\prime}\cup S^{\prime\prime}
for this run satisfies

\displaystyle f(S)-c(S)

\displaystyle=f(S^{\prime})-c(S^{\prime})+f_{S^{\prime}}(S^{\prime\prime})-c(S^{\prime\prime})

\displaystyle\geq f(H^{*})-c(H^{*})+(1-e^{-\alpha})\cdot f_{H^{*}}(L^{*})-(\alpha\cdot c(L^{*})+\gamma\cdot c(S^{*})).

We will soon show the claim that
f(H^{*})-c(H^{*})\geq 0
, but first we use it to complete the proof. Multiplying the
first two terms by
\alpha\in[0,1]
gives

\displaystyle\geq\alpha(f(H^{*})-c(H^{*}))+(1-e^{-\alpha})\cdot f_{H^{*}}(L^{*})-(\alpha\cdot c(L^{*})+\gamma\cdot c(S^{*})).

Moreover, using that
\alpha\geq 1-e^{-\alpha}
, we get

\displaystyle\geq(1-e^{-\alpha})\cdot\big[f(H^{*})+f_{H^{*}}(L^{*})\big]-\alpha\cdot\big[c(H^{*})+c(L^{*})\big]-\gamma\cdot c(S^{*}),

which proves the claimed bound using submodularity. Finally, to prove the claim, note that if

f(H^{*})<c(H^{*})
, we get that
f(L^{*})-c(L^{*})>f(S^{*})-c(S^{*})
,
which contradicts the optimality of the set
S^{*}
.
∎

Proposition B.2
.

For the sets
S_{i}
defined by the greedy process,

Proof.

By submodularity and the greedy choice of element
