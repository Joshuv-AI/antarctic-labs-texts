Abstract
Quantum state preparation, also known as encoding or embedding, is a crucial initial step in many quantum algorithms and often constrains theoretical quantum speedup in fields such as quantum machine learning and linear equation solvers. One common strategy is amplitude encoding, which embeds a classical input vector of size N=2 n in the amplitudes of an n-qubit register. For arbitrary vectors, the circuit depth typically scales linearly with the input size N, rapidly becoming unfeasible on near-term hardware. We propose a general-purpose procedure with sublinear average depth in N, increasing the window of utility. Our amplitude encoding method encodes arbitrary complex vectors of size N=2 n at any desired binary precision using a register with n qubits plus 2 ancillas and a sublinear number of multi-controlled NOT (MCX) gates, at the cost of a probabilistic success rate proportional to the sparsity of the encoded data. The core idea of our procedure is to construct an isomorphism between target states and hypercube graphs, in which specific reflections correspond to MCX gates. This reformulates the state preparation problem in terms of permutations and binary addition . The use of MCX gates as fundamental operations makes this approach particularly suitable for quantum platforms such as ion traps and neutral atom devices . This geometrical perspective paves the way for more gate-efficient algorithms suitable for near-term hardware applications.

III-B

Encoding an entire vector in parallel

Now that we know how to exploit
R_{y}
rotations in order to encode a single entry
v_{i}
of the input vector, corresponding to a single row of
\mathbf{B}
, into the amplitude of the
{|{1}\rangle}
state, we can parallelize this procedure over the whole vector using quantum superposition. The central idea is to consider the columns
\bm{B}_{:,l},l\in\{0,\dots,L-1\}
sequentially and
at each step encode all entries of the column in parallel.
The strategy we present here involves three registers:

•

a SYSTEM (S) register with
n
qubits,

•

a TARGET (T) register with one qubit,

•

a FLAG (F) register with one qubit.

The algorithm begins with applying a layer of Hadamard gates to the SYSTEM register, creating the uniform superposition

{|{\Psi_{\bm{0}}}\rangle}_{S,T}:=\frac{1}{\sqrt{N}}\sum_{i=0}^{N-1}{|{i}\rangle}_{S}{|{0}\rangle}_{T}.

(9)

Looking at this state, we can consider the basis state
{|{i}\rangle}
on the SYSTEM register, ranging from
0
to
N-1
, as an index for the state of the TARGET qubit. This allows us to see (
9
) as encoding a specific binary vector of length
N
, which contains only zeros.
We now consider acting on this state with a unitary operator
\mathcal{W}_{\bm{b}}
as a function of an arbitrary vector
\bm{b}\in\mathbb{F}_{2}^{N}
such that it acts as

\mathcal{W}_{\bm{b}}{|{\Psi_{\bm{0}}}\rangle}={|{\Psi_{\bm{0}\oplus\bm{b}}}\rangle}={|{\Psi_{\bm{b}}}\rangle}\,,

(10)

where
{|{\Psi_{\bm{b}}}\rangle}
is the uniform superposition

{|{\Psi_{\bm{b}}}\rangle}_{S,T}:=\frac{1}{\sqrt{N}}\sum_{i=0}^{N-1}{|{i}\rangle}_{S}{|{b_{i}}\rangle}_{T},

(11)

in which the TARGET qubit is entangled with the SYSTEM register.
More generally given a state as in (
11
) and a binary vector
\bm{b}^{\prime}\in\mathbb{F}_{2}^{N}
we want

\mathcal{W}_{\bm{b^{\prime}}}{|{\Psi_{\bm{b}}}\rangle}={|{\Psi_{\bm{b}\oplus\bm{b}^{\prime}}}\rangle}.

(12)

For now we assume that such an operator
\mathcal{W}_{\bm{b^{\prime}}}
is given as a black box.
We later describe how to implement the
\mathcal{W}
operators in terms of
MCX

IV

V

When we act with a controlled
R_{y}(\phi)
rotation that uses the qubit TARGET as control and the FLAG as target on the state in (
11

\displaystyle CR_{y}(\phi_{j},T\rightarrow F){|{\Psi_{\bm{b}}}\rangle}_{S,T}{|{0}\rangle}_{F}

\displaystyle=\frac{1}{\sqrt{N}}\sum_{i=0}^{N-1}{|{i}\rangle}_{S}{|{b_{i}}\rangle}_{T}(\cos(b_{i}\phi_{j}){|{0}\rangle}_{F}+\sin(b_{i}\phi_{j}){|{1}\rangle}_{F})

\displaystyle=\frac{1}{\sqrt{N}}\sum_{i=0}^{N-1}{|{i}\rangle}_{S}{|{b_{i}}\rangle}_{T}\bigg(R_{y}(b_{i}\phi_{j}){|{0}\rangle}_{F}\bigg).

(13)

From this equation we see how the binary values
b_{i}
tell us which indices
i
and therefore which amplitudes are affected by the given rotation
R_{y}(\phi_{j})
.

The final state we want to prepare is

\displaystyle{|{\zeta}\rangle}=

\displaystyle\frac{1}{\sqrt{N}}\sum_{i=0}^{N-1}{|{i}\rangle}_{S}{|{0}\rangle}_{T}\bigg(R_{y}\bigg(\sum_{j=0}^{L-1}\phi_{j}B_{i,j}\bigg){|{0}\rangle}_{F}\bigg)

\displaystyle=

\displaystyle\sqrt{\rho}{|{\Psi_{\text{good}}}\rangle}{|{0}\rangle}_{T}{|{1}\rangle}_{F}+\sqrt{1-\rho}{|{\Psi_{\text{bad}}}\rangle}{|{0}\rangle}_{T}{|{0}\rangle}_{F}

(14)

where

{|{\Psi_{\text{good}}}\rangle}=\sum_{i=0}^{N-1}w_{i}{|{i}\rangle}_{S}.

(15)

{|{\zeta}\rangle}
is a weighted superposition of the desired state that encodes the approximating vector
\bm{w}
,
{|{\Psi_{\text{good}}}\rangle}
, entangled with the state
{|{1}\rangle}
on the FLAG register and of an undesired state
{|{\Psi_{\text{bad}}}\rangle}
, associated to the state
{|{0}\rangle}
on the FLAG. By measuring the FLAG qubit, we know if the procedure succeeded, which happens with a probability given by the data density parameter
[
46
]

\rho=\frac{1}{N}\sum_{i=0}^{N-1}\left(\frac{v_{i}}{\|\bm{v}\|_{\infty}}\right)^{2}\in\left[\frac{1}{N},1\right]\,.

(16)

If we measure zero on the FLAG qubit, we need to discard the state and repeat the encoding step.
The success probability can be increased through amplitude amplification, but for near-term devices, where circuit depth is a bottleneck, it can be beneficial to instead use the shallow ‘core’ encoding circuit with non-amplified success probability.

We then introduce two equivalent, but useful ways to view the problem:

We aim to construct a

These pictures will aid us in formulating the optimization Subroutine

IV-A

Properties of
\mathcal{W}_{\bm{b}}

It turns out that each of the encoding circuits

\bm{b}

The most naive implementation of (

\bm{b}
as binary control strings

\displaystyle\text{MCX}(\dots 0\dots)\text{MCX}(\dots 1\dots)

\displaystyle=\text{MCX}(\dots\text{I}\dots)~,

(30a)

\displaystyle\text{MCX}(\dots 0\dots)\text{MCX}(\dots\text{I}\dots)

\displaystyle=\text{MCX}(\dots 1\dots)~,

(30b)

\displaystyle\text{MCX}(\dots 1\dots)\text{MCX}(\dots\text{I}\dots)

\displaystyle=\text{MCX}(\dots 0\dots)~.

(30c)

In the same way, any

Using the relations (

IV-C

Kronecker decomposition representation

As a third option, we can reformulate the problem of finding an
MCX
-decomposition (
25
) with minimal number
M
of
MCX

into the problem of finding a minimal Kronecker decomposition, which allows for an efficient numerical implementation with bit-wise operations.
First, we associate each control string
\bm{c}\in\{0,1,\text{I}\}^{n}
with a binary vector
\bm{b}_{\bm{c}}\in\mathbbm{F}_{2}^{2^{n}}
via the following mapping

\bm{b}_{\bm{c}}:=\bigotimes_{i=0}^{n-1}\bm{t}(c_{i}),\quad\bm{t}(c_{i})=\left\{\begin{aligned} (1,0)&\qquad\text{if }c_{i}=0\\
(0,1)&\qquad\text{if }c_{i}=1\\
(1,1)&\qquad\text{if }c_{i}=\text{I}\end{aligned}\right.

(32)

expresses the binary vector
\bm{b}_{\bm{c}}
as a tensor product of 2-dimensional binary vectors in
\{(1,0),(0,1),(1,1)\}
.
Every tensor product corresponds to a single
MCX
as

\mathcal{W}_{\bm{b}_{\bm{c}}}=\text{MCX}(\bm{c})~.

(33)

A general binary vector
\bm{b}\in\mathbb{F}_{2}^{N}
can be decomposed into Kronecker products

\bm{b}=\bigoplus_{j=0}^{M-1}\bm{b}_{\bm{c}_{j}}~,

(34)

which is equivalent to the
MCX
decomposition (
25
).
Thus, finding a minimal
MCX
decomposition of
\mathcal{W}_{\bm{b}}
is equivalent to finding the shortest Kronecker decomposition,
which is known to be NP-hard
[
47
,
48
]
.
The advantage of this formulation is that the joining and splitting operations (
30
) can be expressed as binary additions (XOR operations) on the tensor products
\bm{b}_{\bm{c}}
.
Thus, in Sec.
V
we will formulate our algorithm in terms of Kronecker decompositions.

VII
Conclusion & Outlook

In this work, we introduced an algorithm to embed an
L
-bit binary approximation of
N
classical real values
into a quantum register of
n=\log_{2}(N)
qubits via amplitude encoding, using
L
rotations and a series of
MCX
operations and 2 ancilla qubits.
Our algorithm first builds a binary matrix
\mathbf{B}\in\mathbb{F}_{2}^{N,L}
which contains the binary expansions of the input values,
with each one of the columns corresponding to a power of two in the expansion.
It then solves a
TSP
to find the optimal path in which to encode the
L
columns.
The cost of the path depends on the required number of
MCX
to build the difference vector between consecutively visited columns.
To find an efficient
MCX
decomposition, we use a tree algorithm, which reformulates the problem as finding the minimal Kronecker decomposition.
This allows us to use binary operations in the numerical implementation.
In addition, we introduced an isomorphism to a hypercube graph,
which enables useful visualizations of our algorithm and helps in building an intuitive understanding of good solutions.

We analyzed the performance of our algorithm on several examples of structured input data from the literature, and compared the circuit depth with that of equivalent Qiskit encoding circuits transpiled to the gate set {
Rx
,
Ry
,
Rz
,
CNOT
} at the highest available optimization level (level 3).
For each encoding circuit, we analyzed a shallower version (core), with a success probability that depends on the input density
\rho
in (
16
), and a longer version (full), which incorporates amplitude amplification to boost the success probability.
For both versions, we present numerical evidence for a scaling of the circuit depth that is
\mathcal{O}(n^{\alpha}L)
,
\alpha\approx 1.4
for common structured inputs such as Gaussian or Ricker wavelet distributions, and
\mathcal{O}(L)
for functions like
\cos(x)
and
\sin(x)
, providing an exponential improvement over Qiskit. The success probability is constant in
N
and exceeds
20\%
in all cases.
For unstructured data, while the full
MCX
circuit has depth
\approx 2^{n}L
, which is worse than Qiskit, the
core

MCX
circuit shows improved scaling of
\approx\frac{2^{n-1}L}{\sqrt{n}}
, significantly outperforming Qiskit for any fixed
L
, with success probability scaling as
\frac{1}{n}
.

Even if not fully deterministic, we consider the core version of each encoding circuit to be of interest for NISQ devices, where a shorter circuit reduces noise and errors at the cost of rejecting some trials. This is particularly relevant given that the average number of required attempts is independent of
N
for structured inputs and scales only slowly, as
\log N
, for unstructured input.

In the future, the algorithm can be further improved.
The current low-level implementation is highly optimized using binary operations, but algorithmic improvements are possible.
For instance, one can adapt Subroutines
1
and
2
to be more discriminating between semi-full nodes by using the precise fullness values to determine an optimal selection of nodes from the maximum independent sets. Additionally, on a more fundamental level, one can choose a different basis than the binary one given by
\mathbf{B}
, such as the Hadamard–Walsh basis, which we explore in ongoing work.
Finally,
one can include
MCX
which target the SYSTEM register,
which in the hypercube picture corresponds to reflections.
Such operations sacrifice the commutativity of the
MCX
, but vastly increase the search space of solutions.
