The Unification Type of an Equational Theory May Depend on the Instantiation Preorder: From Results for Single Theories to Results for Classes of Theories \lsuper * Thanks: Both authors were partially supported by DFG grant 389792660 as part of TRR 248 – CPEC, and by the German Federal Ministry of Education and Research (BMBF, SCADS22B) and the Saxon State Ministry for Science, Culture and Tourism (SMWK) by funding the competence center for Big Data and AI “ScaDS.AI Dresden/Leipzig”.
Franz Baader ORCID:0000-0002-4049-221X, Oliver Fernández Gil ORCID:0000-0002-9458-1701

Abstract
. The unification type of an equational theory is defined using a preorder on substitutions, called the instantiation preorder, whose scope is either restricted to the variables occurring in the unification problem, or unrestricted such that all variables are considered. It has been known for more than three decades that the unification type of an equational theory may vary, depending on which instantiation preorder is used. More precisely, it was shown in 1991 that the theory 𝖠𝖢𝖴𝖨 \mathsf{ACUI} of an associative, commutative, and idempotent binary function symbol with a unit is unitary w.r.t. the restricted instantiation preorder, but not unitary w.r.t. the unrestricted one. In 2016 this result was strengthened by showing that the unrestricted type of this theory also cannot be finitary. In the conference version of this article, we considerably improved on this result by proving that 𝖠𝖢𝖴𝖨 \mathsf{ACUI} is infinitary w.r.t. the unrestricted instantiation preorder, thus precluding type zero. We also showed that, w.r.t. this preorder, the unification type of 𝖠𝖢𝖴 \mathsf{ACU} (where idempotency is removed from the axioms) and of 𝖠𝖢 \mathsf{AC} (where additionally the unit is removed) is infinitary, though it is respectively unitary and finitary in the restricted case. In the other direction, we proved (using the example of unification in the description logic ℰ ​ ℒ \mathcal{E\mkern-1.618muL} ) that the unification type may actually improve from type zero to infinitary when switching from the restricted instantiation preorder to the unrestricted one. In the present article, we not only determine the unrestricted unification type of considerably more equational theories, but we also prove general results for whole classes of theories. In particular, we show that theories that are regular and finite, regular and locally finite, or regular, monoidal, and satisfy an additional condition are Noetherian, and thus cannot have unrestricted unification type zero.

Syntactic unification of terms was independently introduced by Robinson

Both showed the important result that any solvable unification problem has a most general unifier (mgu), i.e., a unifier that has all other unifiers as
instances. In these papers, a substitution

In addition to many papers on how to compute the mgu efficiently

In his seminal paper

2.
Equational theories

Given a
signature

\Sigma
consisting of a finite set of function symbols (with associated arities) and a countably infinite set
of
variables

V
, the set
T(\Sigma,V)
of
terms
over
\Sigma
with variables in
V
is defined in the usual way: every variable is a
term, and if
f
is an
n
-ary function symbol and
t_{1},\ldots,t_{n}
are terms, then
f(t_{1},\ldots,t_{n})
is also a term.
Function symbols of arity
0
are called
constants
, and we write
c
rather than
c()
for the term built using a constant
c
.
For a term
t
, we denote with
\Var(t)
the set of variables (i.e., elements of
V
) occurring in
t
. The
size
of
t

is the number of occurrences of function symbols and variables in
t
.

An equational theory
E
is given by a set of identities
s\approx t
between terms, which are (implicitly) assumed to be universally quantified.
Such a set of identities
E
induces the congruence relation
\approx_{E}
on terms, which can either be defined syntactically through
rewriting or semantically through first-order interpretations of
\Sigma
, with
\approx
as identity relation
[
13
]
.
We will assume in this paper that all equational theories under consideration are non-trivial in the sense that
x\approx_{E}y
does not hold for distinct
variables
x,y
. While a trivial equational theory is not inconsistent in the logical sense since it has models of cardinality
1
, it is
similarly degraded since
\approx_{E}
has a single equivalence class consisting of all terms. Making this general non-triviality assumption
simplifies the formulation of some of our results.

In this section, we introduce several specific equational theories as well as some classes of equational theories that have been
investigated in the context of unification, and which will play an important rôle in this article.

2.1.
Some common equational theories

We start with presenting some identities that axiomatize frequently occurring properties of mathematical functions.
Let
f
be a binary function symbol, and
x,y,z\in V
. Then the following identities respectively state associativity (
\mathsf{A}
), commutativity (
\mathsf{C}
),
idempotency (
\mathsf{I}
) of
f
, as well as the fact that
f
has the constant
0
as a unit (
\mathsf{U}
):

\begin{array}[]{l@{\ \ \ \ \ }l}\mathsf{A}:=\{f(x,f(y,z))\approx f(f(x,y),z)\},&\mathsf{C}:=\{f(x,y)\approx f(y,x)\},\\[3.00003pt]
\mathsf{I}:=\{f(x,x)\approx x\},&\mathsf{U}:=\{f(x,0)\approx x\}.\end{array}

For function symbols satisfying several of these properties, we denote the theory obtained as the union of some of these theories by concatenating
the corresponding letters. For example,
\mathsf{AC}=\mathsf{A}\cup\mathsf{C}
and
\mathsf{ACUI}
denotes the union of all four theories. By a slight abuse of notation, we
will use the respective letters also for binary function symbols different from
f
and constants different from
0
, but in the union we assume
that the same binary symbol is used. For example, we may use
\mathsf{AU}
also for
\{g(x,g(y,z))\approx g(g(x,y),z),g(x,1)\approx x\}
, but

\mathsf{AC}
not for
\{f(x,f(y,z))\approx f(f(x,y),z),g(x,y)\approx g(y,x)\}
.

2.2.
Regular and finite theories

The equational theory
E
is called

•

regular
if
\Var(s)=\Var(t)
holds for all identities
s\approx t
in
E
.

•

finite
if every equivalence class of the induced congruence relation
\approx_{E}
is finite. That is, for all terms
t\in T(\Sigma,V)
, the set
\{s\in T(\Sigma,V)\mid s\approx_{E}t\}
is finite.

The following two properties of these classes of theories will turn out to be useful later on.
First, it is well-known that regularity of the defining set of identities of an equational theory implies regularity of the whole theory
(see, e.g.,
[
71
]
for a proof):

Lemma 1
.

If
E
is regular, then
\Var(s)=\Var(t)
holds for all terms
s,t
satisfying
s\approx_{E}t
.

Second, as shown in Lemma 3.3.1 of
[
27
]
, finite theories are always regular:

Lemma 2
.

Every finite equational theory is regular.

Obviously, the identities in
\mathsf{A}
,
\mathsf{C}
,
\mathsf{I}
, and
\mathsf{U}
satisfy the regularity condition, and thus any equational theory obtained as a union
of these theories is also regular. However, the identities in
\mathsf{I}
and
\mathsf{U}
destroy finiteness. In fact, the chain of equivalences

x\approx_{\mathsf{I}}f(x,x)\approx_{\mathsf{I}}f(x,f(x,x))\approx_{\mathsf{I}}f(x,f(x,f(x,x)))\approx_{\mathsf{I}}\cdots

shows that the
\approx_{\mathsf{I}}
-equivalence class of the variable
x
is infinite, and so does the following chain for its
\approx_{\mathsf{U}}
-equivalence class:

x\approx_{\mathsf{U}}f(x,0)\approx_{\mathsf{U}}f(x,f(0,0))\approx_{\mathsf{U}}f(x,f(0,f(0,0)))\approx_{\mathsf{U}}\cdots.

Let us continue by presenting examples of finite theories. First, note that the empty theory
\emptyset
as well as the theories
\mathsf{A}
,
\mathsf{C}
, and
\mathsf{AC}

are obviously finite since they preserve the size and the symbols of terms, i.e., every term in the equivalence class of the term
t
has the same size as
t

and contains the same function symbols and variables as
t
.
Second, we consider distributivity of a binary function symbol
m
(for multiplication) over a binary function symbol
p
(for plus):

\mathsf{D}:=\{m(z,p(x,y))\approx p(m(z,x),m(z,y)),\ m(p(x,y),z)\approx p(m(x,z),m(y,z))\}.

Finiteness of
\mathsf{D}
was first observed in Szabo’s PhD thesis
[
70
]
, though Szabo calls these theories permutative.
Since the thesis is written in German and very hard to access, we give a new proof of this fact here.
We associate with
m
the polynomial
P_{m}(X,Y):=XY
, with
p
the polynomial
P_{p}(X,Y):=X+Y
, and with every constant
c
the polynomial
P_{c}:=2
. This basically means that we interpret
m
as multiplication and
p
as addition. Let
\pi_{2}(t)
be the natural number obtained by evaluating
P_{t}
with
2
substituted for all indeterminates of
P_{t}
. It is shown in the proof of Lemma 5.1 of
[
4
]
that the size of a given term
t
is strictly smaller than
\pi_{2}(t)
.
3
3

3

Strictly speaking, this result is formulated in
[
4
]
for the nu-size, where unary function symbols are not counted, but since in our setting there are no unary function symbols, the nu-size coincides with the size of the term.

When computing
\pi_{2}(t)
, the function symbol
m
is interpreted as multiplication of natural numbers and
p
is interpreted as addition of natural numbers. Since multiplication distributes over addition from both sides, this means that
s\approx_{\mathsf{D}}t
implies that
\pi_{2}(s)=\pi_{2}(t)
. Consequently, all elements
s
of the
\approx_{\mathsf{D}}
equivalence class of
t
satisfy
|s|<\pi_{2}(t)
. Since
\pi_{2}(t)
is a finite natural number and
\mathsf{D}
preserves the symbols of
t
, this implies that the
\approx_{\mathsf{D}}
equivalence class of
t
is finite.

Summing up, we have shown the following result.

Proposition 3
.

The equational theories
\emptyset
,
\mathsf{C}
,
\mathsf{A}
,
\mathsf{AC}
, and
\mathsf{D}
are finite.

2.3.
Monoidal theories

The equational theories
\mathsf{ACU}
and
\mathsf{ACUI}
belong to the class of monoidal theories. This class of theories was independently introduced by Nutt
[
52
]
and Baader (as
commutative theories
)
[
20
]
, and the correspondence between the two formulations was established in
[
14
]
.
For simplicity, we use the definition of monoidal theories given in
[
52
]
, since it requires less auxiliary definitions

Let
E
be an equational theory. The signature of
E
, denoted as
\Sig(E)
, is the set of function symbols occurring in the identities of
E
.
An equational theory
E
is called
monoidal
if it satisfies the following properties:

•

The signature
\Sig(E)
contains a constant symbol
0
and a binary function symbol
f
, and all other function symbols in
\Sig(E)
are unary.

•

The symbol
f
is (modulo
E
) associative and commutative with unit
0
. That is,

f(x,y)\approx_{E}f(y,x),\ \ f(x,(f(y,z))\approx_{E}f(f(x,y),z),\ \ f(x,0)\approx_{E}x.

•

Every unary function symbol
h
in
\Sig(E)
is a homomorphism for
f
and
0
, i.e.,

h(f(x,y))\approx_{E}f(h(x),h(y)),\ \ h(0)\approx_{E}0.

The equational theory
\mathsf{ACU}
is the least monoidal theory in the sense that its signature contains no unary function symbol and
f
is not required to satisfy any additional property.
Another example of a monoidal theory is
\mathsf{ACUI}
, as is its extension with a homomorphism:

\mathsf{ACUIh}:=\mathsf{ACUI}\cup\{h(f(x,y))\approx f(h(x),h(y)),\ h(0)\approx 0\}.

The same is true for the extension
\mathsf{ACUh}
of
\mathsf{ACU}
with a homomorphism.
By a slight abuse of notation, we use
\mathsf{ACUIh}
and
\mathsf{ACUh}
also to denote the extension of
\mathsf{ACUI}
and
\mathsf{ACU}
with more than one homomorphism.
Finally, note that the theory
\mathsf{AG}
of
Abelian groups
is also a monoidal theory. It is obtained by adding to
\mathsf{ACU}
a unary function symbol
\mathsf{inv}
that expresses the existence of an inverse. That is,

\mathsf{AG}:=\mathsf{ACU}\cup\{f(x,\mathsf{inv}(x))\approx 0\}.

Note that, although not explicitly stated in
\mathsf{AG}
, the unary function symbol
\mathsf{inv}
is also a homomorphism. It is not hard to show that the following holds:

\mathsf{inv}(f(x,y))\approx_{\mathsf{AG}}f(\mathsf{inv}(x),\mathsf{inv}(y))\ \ \ \mbox{and}\ \ \ \mathsf{inv}(0)\approx_{\mathsf{AG}}0.

Hence,
\mathsf{AG}
is indeed a monoidal theory.
In contrast to
\mathsf{ACU}
,
\mathsf{ACUI}
and
\mathsf{ACUIh}
, the theory
\mathsf{AG}
is an example of a monoidal theory that is not regular. None of these theories is finite due to
the fact that
\mathsf{U}
is contained in them.

Given disjoint sets of concept names (unary predicates) and role names (binary predicates),

\top

C::=\top\mid\>\bot\>\mid\>A\>\mid\>C\sqcap C\>\mid\>C\sqcup C\>\mid\>\neg C\>\mid\forall r.C\>\mid\exists r.C,

where

for
\mathcal{ALC}

\mathcal{E\mkern-1.618muL}
is the sublogic of

that uses only the constructors top, conjunction, and existential restriction,
whereas

In the model-theoretic semantics of

\mathcal{I}

\mathcal{I}=(\Delta^{\mathcal{I}},\cdot^{\mathcal{I}})

\begin{array}[]{rcl}\top^{\mathcal{I}}&:=&\Delta^{\mathcal{I}},\ \ \bot^{\mathcal{I}}\ \,:=\ \,\emptyset,\ \ (C\sqcap D)^{\mathcal{I}}\ \,:=\ \,C^{\mathcal{I}}\cap D^{\mathcal{I}},\ \ (\neg C)^{\mathcal{I}}\ \,:=\ \,\Delta^{\mathcal{I}}\setminus C^{\mathcal{I}},\\[3.00003pt]

3.
Unification and unification types

In unification, the goal is to make pairs of terms equivalent w.r.t.
\approx_{E}
for an equational theory
E
by replacing variables with terms.
Formally, this replacement is achieved by applying a substitution.

A
substitution

\sigma
is a mapping from
V
to
T(\Sigma,V)
that has a finite
domain

\Dom(\sigma):=\{x\in V\mid\sigma(x)\neq x\}
.
It can be homomorphically extended to a mapping from
T(\Sigma,V)
to
T(\Sigma,V)
by defining

\sigma(f(t_{1},\ldots,t_{n})):=f(\sigma(t_{1}),\ldots,\sigma(t_{n}))
.
The
variable range

\VRan(\sigma)
of
\sigma
consists of the set of variables occurring in the terms
\sigma(x)
for
x\in\Dom(\sigma)
.
Substitutions can be compared using the instantiation preorder:
given an equational theory
E
, a set of variables
X\subseteq V
, and two substitutions
\sigma,\tau
, we say that

\sigma
is
more general
than
\tau
(or
\tau
is an
instance
of
\sigma
) w.r.t.
E
and
X

(written
\sigma\leq_{E}^{X}\tau
)
if there is a substitution
\lambda
such that
\lambda\sigma\approx_{E}^{X}\tau
, i.e.,
\lambda(\sigma(x))\approx_{E}\tau(x)
holds for all
x\in X
.
In case
X=V
we also write
\lambda\sigma\approx_{E}\tau
in place of
\lambda\sigma\approx_{E}^{V}\tau
.
It is easy to see that
\leq_{E}^{X}
is indeed a preorder, i.e., reflexive and transitive, but in general not antisymmetric.
We write
\sim_{E}^{X}
for the equivalence relation induced by
\leq_{E}^{X}
, i.e.,
\sigma\sim_{E}^{X}\tau
iff

\sigma\leq^{X}_{E}\tau
and
\tau\leq^{X}_{E}\sigma
.
We say that
\sigma
is
strictly more general
than
\tau
(or
\tau
is a
strict instance
of
\sigma
) w.r.t.
E
and
X

(written
\sigma<_{E}^{X}\tau
) if
\sigma\leq_{E}^{X}\tau
and
\sigma\not\sim_{E}^{X}\tau
.

An
E
-unification problem
is a finite set of equations of the form

\Gamma=\{s_{1}\approx_{E}^{?}t_{1},\ldots,s_{n}\approx_{E}^{?}t_{n}\}

where
s_{1},t_{1},\ldots,s_{n},t_{n}
are terms in
T(\Sigma,V)
.
An
E
-unifier
of
\Gamma
is a substitution
\sigma
that solves all the equations in
\Gamma
, i.e.,
satisfies
\sigma(s_{i})\approx_{E}\sigma(t_{i})
for all
i,1\leq i\leq n
.
The unification problem
\Gamma
is
solvable
if it has an
E
-unifier.
The set of all
E
-unifiers of
\Gamma
is denoted as
\mathcal{U}_{E}(\Gamma)
.
For
elementary
E
-unification
it is assumed that
\Sigma
(and thus also
\Gamma
) contains only function symbols
occurring in

E
-unification with constants

and for
general
E
-unification

\Sigma

In this paper, we restrict our attention to elementary

-unification.

Unification types for non-empty sets of identities

are usually defined w.r.t. the
restricted instantiation preorder

In this paper, we will additionally consider settings where

4.
When the employed instantiation preorder does not matter

The purpose of the first result shown in this section is to clarify the reason why the unification type can change when going from
the restricted to the unrestricted instantiation preorder. It is not that the unrestricted preorder also takes variables into account that do not
occur in the unification problem and not even that it considers infinitely many such variables. The reason is that it does not leave infinitely many
variables unobserved.

Proposition 7
.

Let
E
be an equational theory,
\Gamma
an
E
-unification problem,
X_{0}:=\Var(\Gamma)
, and
X\subseteq V
a set of variables such that

X_{0}\subseteq X
and
V\setminus X
is infinite. If
\Gamma
has a minimal complete set of
E
-unifiers w.r.t.
\leq_{E}^{X}
, then it has a
minimal complete set of
E
-unifiers w.r.t.
\leq_{E}^{X_{0}}
of the same cardinality, and vice versa.

Proof 4.1
.

Let
\mathcal{S}
be a minimal complete set of
E
-unifiers of
\Gamma
w.r.t.
\leq_{E}^{X}
. For every unifier
\theta
in
\mathcal{S}

we can rename the variables in
\VRan(\theta)
such that they do not belong to
X
by applying an appropriate permutation
\pi
that
maps the variables of
\VRan(\theta)
bijectively to a set of variables
Y
with
|Y|=|\VRan(\theta)|
and
Y\cap(X\cup\VRan(\theta))=\emptyset
.
Such a finite set
Y
of variables exists since
\VRan(\theta)
is finite and
V\setminus X
is infinite.
For a given bijection
p:\VRan(\theta)\rightarrow Y
, we can define
\pi
as follows:

\pi(z):=p(z)
for all
z\in\VRan(\theta)
,
\pi(y):=p^{-1}(y)
for all
y\in Y
, and
\pi(x)=x
for all other variables.
Note that
\pi
is a substitution since its domain is
\VRan(\theta)\cup Y
, which is finite.
To show that
\pi
really is a permutation, i.e., a bijective mapping from
V
to
V
, it is sufficient to show that it is an injective mapping
from
V
to
V
(see Lemma 2.6 in
[
34
]
). This is an immediate consequence of the facts that

p
and
p^{-1}
are bijections and
Y
and
\VRan(\theta)
are disjoint.

The substitution
\pi\theta
is equivalent to
\theta
w.r.t. the equivalence relation
\sim_{\emptyset}^{V}
induced by

\leq_{\emptyset}^{V}
, and thus also w.r.t.
\sim_{E}^{X}
. In fact,
\pi^{-1}\pi\theta=\theta
.
If we restrict the domain of this substitution to
X
, then the resulting substitution
\pi\theta|_{X}
is still equivalent to

\theta
w.r.t.
\sim_{E}^{X}
and also satisfies
\VRan(\pi\theta|_{X})\cap X=\emptyset
.
To see the latter, consider a variable
x\in\Dom(\pi\theta|_{X})
.
First assume that
x\in\Dom(\theta)\cap X
. Then all the variables in
\theta(x)
belong to
\VRan(\theta)
, and thus all the variables in

\pi\theta|_{X}(x)
belong to
Y
, which is disjoint with
X
. If
x\in X\setminus\Dom(\theta)
, then
\pi\theta|_{X}(x)=\pi(x)\neq x
.
Since
\Dom(\pi)=\VRan(\theta)\cup Y
and
Y
is disjoint with
X
, this implies
x\in\VRan(\theta)
, and thus
\pi(x)\in Y
.

be the set of substitutions obtained from
\mathcal{S}
by applying this renaming and domain restriction process to every element of
\mathcal{S}
.
Due to the
\sim_{E}^{X}

\mathcal{S}

\Gamma

\mathcal{S}^{\prime}
is also a minimal complete set of

E

\Gamma

\leq_{E}^{X}
. In a second step, we restrict the domains of the elements of
\mathcal{S}^{\prime}
to

.
Given an element
\theta
of

to be the substitution that coincides

\theta

and maps each variable

to

. Since
\theta
is an
E
-unifier of
\Gamma
and this unification problem

\Gamma
.
We claim that

.

coincides with

on the variables in

.

is a minimal complete set w.r.t.

,

of

w.r.t.

Conversely, let
\mathcal{S}

By applying the same construction as in the proof of the other direction, we can assume without loss of generality

of

, and thus also
\sim_{E}^{X_{0}}
-equivalent. Consequently, this new set
\mathcal{S}
is also
a minimal complete set of
E
-unifiers of
\Gamma
w.r.t.
\leq_{E}^{X_{0}}
.

We claim that
\mathcal{S}
is also minimal and complete w.r.t. the larger set of variables
X
.
Minimality trivially follows from the fact that
{\leq_{E}^{X}}\subseteq{\leq_{E}^{X_{0}}}
.
To prove completeness, assumed that
\tau
is an
E
-unifier of
\Gamma
. Completeness of
\mathcal{S}
w.r.t.
\leq_{E}^{X_{0}}

yields an element
\theta
of
\mathcal{S}
such that
\theta\leq_{E}^{X_{0}}\tau
, i.e., there is a substitution
\lambda
such that

\lambda\theta(x)\approx_{E}\tau(x)
holds for all
x\in X_{0}
.
Let
x
be a variable in
X\setminus X_{0}
. Then
\lambda\theta(x)=\lambda(x)
.
Thus, if we modify
\lambda
to
\lambda^{\prime}
such that
\lambda^{\prime}(x)=\tau(x)
holds for all
x\in X\setminus X_{0}
, then

\lambda^{\prime}(\theta(x))=\tau(x)
holds for all
x\in X\setminus X_{0}
.
The claim that this modification has no effect for the variables
x\in X_{0}
can be shown as in the proof of minimality of

\mathcal{S}^{\prime}|_{X_{0}}
w.r.t.
\leq_{E}^{X_{0}}
above. This proves that
\lambda^{\prime}\theta(x)\approx_{E}\tau(x)
holds for all
x\in X
,
and thus
\mathcal{S}
is also complete w.r.t.
\leq_{E}^{X}
.

The following theorem is an immediate consequence of this lemma.

Theorem 8
.

Let
E
be an equational theory,
\Gamma
an
E
-unification problem, and
X\subseteq V
a set of variables such that

\Var(\Gamma)\subseteq X
and
V\setminus X
is infinite. Then the restricted unification type of
\Gamma
coincides
with the unification type of
\Gamma
w.r.t.
\leq_{E}^{X}
.

Note that the condition of the theorem is in particular satisfied if
X
is a finite superset of
\Var(\Gamma)
.
However, it is clearly not satisfied for
X=V
, which corresponds to the unrestricted instantiation preorder setting.
We will see in the next two sections that in this case the unification type can indeed depend on whether the restricted or the unrestricted
instantiation preorder is used. However, there is a special case where this cannot happen.

Lemma 9
.

Let
E
be an equational theory,
\Gamma
an
E
-unification problem, and
\mathcal{S}
a set of
E
-unifiers of
\Gamma
such that

\VRan(\sigma)\cup\Dom(\sigma)\subseteq\Var(\Gamma)
holds for all
\sigma\in\mathcal{S}
.
Then
\mathcal{S}
is a minimal complete set of
E
-unifiers of
\Gamma
w.r.t.
\leq_{E}^{V}

iff it is a minimal complete set of
E
-unifiers of
\Gamma
w.r.t.
\leq_{E}^{\Var(\Gamma)}
.

Proof 4.2
.

Let
\mathcal{S}
be a minimal complete set of
E
-unifiers of
\Gamma
w.r.t.
\leq_{E}^{V}
.
Since
{\leq_{E}^{V}}\subseteq{\leq_{E}^{\Var(\Gamma)}}
, this set is also complete w.r.t.
\leq_{E}^{\Var(\Gamma)}
.
To show minimality w.r.t.
\leq_{E}^{\Var(\Gamma)}
,
assume to the contrary that
\sigma,\theta
are two distinct elements of
\mathcal{S}
such that
\sigma\leq_{E}^{\Var(\Gamma)}\theta
,
i.e., there is a substitution
\lambda
such that
\lambda\sigma(x)\approx_{E}\theta(x)
holds for all
x\in\Var(\Gamma)
.
We modify
\lambda
to
\lambda^{\prime}
by setting
\lambda^{\prime}(x)=x
for all variables
x\in V\setminus\Var(\Gamma)
.
For
x\in\Var(\Gamma)
, we know that
\sigma(x)
contains only variables from
\VRan(\sigma)\subseteq\Var(\Gamma)
if
x\in\Dom(\sigma)
or

\sigma(x)=x\in\Var(\Gamma)
. Since
\lambda
and
\lambda^{\prime}
coincide on
\Var(\Gamma)
, this yields

\lambda^{\prime}\sigma(x)=\lambda\sigma(x)\approx_{E}\theta(x)
.
For
x\in V\setminus\Var(\Gamma)
, this variable does not belong to any of the sets
\Dom(\sigma)
,
\Dom(\theta)
, and
\Dom(\lambda^{\prime})
,
and thus
\lambda^{\prime}\sigma(x)=\lambda^{\prime}(x)=x=\theta(x)
. Summing up, we have shown that
\sigma\leq_{E}^{V}\theta
, which contradicts
our assumption that
\mathcal{S}
is minimal w.r.t.
\leq_{E}^{V}
.

Conversely, assume that
\mathcal{S}
is a minimal complete set of
E
-unifiers of
\Gamma
w.r.t.
\leq_{E}^{\Var(\Gamma)}
.
Since
{\leq_{E}^{V}}\subseteq{\leq_{E}^{\Var(\Gamma)}}
, minimality also holds w.r.t.
\leq_{E}^{V}
.
To show completeness w.r.t.
\leq_{E}^{V}
, assume that
\theta
is an
E
-unifier of
\Gamma
. Completeness of
\mathcal{S}
w.r.t.
\leq_{E}^{\Var(\Gamma)}

yields a substitution
\sigma\in\mathcal{S}
such that
\sigma\leq_{E}^{\Var(\Gamma)}\theta
. Similarly to the first part of the proof, we can show that
this also implies
\sigma\leq_{E}^{V}\theta
. The difference is that now
\theta
is an arbitrary unifier, and thus

\VRan(\theta)\cup\Dom(\theta)\subseteq\Var(\Gamma)
need not hold.
Let
\lambda
be such that
\lambda\sigma(x)\approx_{E}\theta(x)
holds for all
x\in\Var(\Gamma)
.
We modify
\lambda
to
\lambda^{\prime}
by setting
\lambda^{\prime}(x)=\theta(x)
for all variables
x\in V\setminus\Var(\Gamma)
.
For
x\in\Var(\Gamma)
, we obtain
\lambda^{\prime}\sigma(x)=\lambda\sigma(x)\approx_{E}\theta(x)
as in the first part of the proof.
For
x\in V\setminus\Var(\Gamma)
, this variable does not belong to
\Dom(\sigma)
, and thus

\lambda^{\prime}\sigma(x)=\lambda^{\prime}(x)=\theta(x)
.

Note that the proof of completeness in each direction did not make use of the minimality assumption. Thus, it also shows the following lemma.

Lemma 10
.

Let
E
be an equational theory,
\Gamma
an
E
-unification problem, and
\mathcal{S}
a set of
E
-unifiers of
\Gamma
such that

\VRan(\sigma)\cup\Dom(\sigma)\subseteq\Var(\Gamma)
holds for all
\sigma\in\mathcal{S}
.
Then
\mathcal{S}
is a complete set of
E
-unifiers of
\Gamma
w.r.t.
\leq_{E}^{V}

iff it is a complete set of
E
-unifiers of
\Gamma
w.r.t.
\leq_{E}^{\Var(\Gamma)}
.

The following theorem is an easy consequence of these two lemmas.

Theorem 11
.

Let
E
be an equational theory,
\Gamma
an
E
-unification problem, and
\mathcal{S}
a set of
E
-unifiers of
\Gamma
such that

\VRan(\sigma)\cup\Dom(\sigma)\subseteq\Var(\Gamma)
holds for all
\sigma\in\mathcal{S}
and
\mathcal{S}
is complete w.r.t. the restricted or
the unrestricted instantiation preorder. Then the restricted and the unrestricted
E
-unification types of
\Gamma
coincide.

Proof 4.3
.

By
10
, the assumption that
\mathcal{S}
is complete w.r.t. one of the two instantiation preorders implies that it is
also complete w.r.t. the other.

If
\Gamma
has a minimal complete set of
E
-unifiers w.r.t.
\leq_{E}^{\Var(\Gamma)}
,
then it also has such a minimal complete set that is contained in
\mathcal{S}
. In fact, for
\mathcal{S}
to be complete, it must contain a representative of
each minimal
\sim_{E}^{\Var(\Gamma)}
-equivalence class, and thus we obtain a minimal complete set contained in
\mathcal{S}
by taking one representative in
\mathcal{S}
for each class. By
9
, this minimal complete set w.r.t.
\leq_{E}^{\Var(\Gamma)}
is also minimal complete w.r.t.
\leq_{E}^{V}
.
Thus, types unitary, finitary, and infinitary transfer from the restricted instantiation preorder to the unrestricted one. In the same way, we can also show that
types unitary, finitary, and infinitary transfer from the unrestricted instantiation preorder to the restricted one.

Since type zero is the only other type, it thus follows immediately that it also transfers between the two types.

Examples of equational theories where the conditions of this theorem are always satisfied are the empty theory (unitary),
the theory
\mathsf{C}
(finitary), the theory
\mathsf{A}
(infinitary), and the theory
\mathsf{I}
axiomatizing
idempotency of a binary function symbol (finitary).

Corollary 12
.

For the theories
\emptyset
,
\mathsf{C}
,
\mathsf{A}
, and
\mathsf{I}

Proof 4.4
.

For the first three theories
\emptyset
,
\mathsf{C}
, and
\mathsf{A}

[
50
,
61

55

computing (or enumerating, in the case of
\mathsf{A}
) minimal complete sets of unifiers for these theories w.r.t. the restricted instantiation preorder.

For idempotency
\mathsf{I}
, dedicated algorithms are described in
[
46
,
37
]
. However, the fact that
\mathsf{I}

is finitary already follows from the fact that the rewrite system consisting of the single rule

is clearly canonical (i.e.,
confluent and terminating) and that this system satisfies Hullot’s termination criterion for basic narrowing. Thus, basic narrowing enumerates a finite, complete
set of

-unifiers w.r.t. the restricted instantiation preorder (see Theorem 4, Proposition 1, and Example 1 in

This set satisfies the conditions formulated for the set

In fact, both the narrowing steps and the final unification step employ syntactic unification (i.e., unification modulo the theory

the same holds for their compositions, which are the elements of the complete set.

Another equational theory for which

\mathsf{K}

has unification type zero w.r.t. the

However, for the unification problem he considers (unify

with

is a variable), he exhibits a complete set of unifiers (w.r.t. the unrestricted instantiation preorder) consisting of infinitely many unifiers whose domains and variable

He shows that this unification problem has type zero w.r.t. the unrestricted instantiation preorder.

yields that this problem then also has type zero w.r.t. the restricted instantiation preorder. Thus, the theory is of type zero in both cases.

Corollary 13
.

For the equational theory axiomatizing equivalence in the modal logic
\mathsf{K}
, the restricted and the unrestricted unification types coincide,
and is thus zero in both cases.

Lemma 16
.

Let
E
be a regular theory and
\Gamma=\{s\approx_{E}^{?}t\}
an
E
-unification problem s.t.
\Var(s)\cap\Var(t)=\emptyset
.
If
\Gamma
has a minimal complete set of
E
-unifiers w.r.t.
\leq_{E}^{V}
, then it has one that is contained in
\mathcal{C}_{E}(\Gamma)
.

Proof 5.1
.

Since
\Gamma
has a minimal complete set of

-unifiers, the set

of minimal elements of
[\mathcal{U}_{E}(\Gamma)]_{E}^{V}
is complete.
For

to be complete, it must contain for every equivalence class in

by selecting for each class in

\mathcal{C}_{E}(\Gamma)

\mathcal{C}_{E}(\Gamma)

We are now ready to formulate the “additional restrictions” mentioned above.

{defi}

Given a regular equational theory
E
, we say that the
E
-unification problem
\Gamma
is

if the following conditions are satisfied:

•

\Gamma=\{s\approx_{E}^{?}t\}
for terms

satisfying
\Var(s)\cap\Var(t)=\emptyset
,

•

there is a
\leq_{E}^{V}
-minimal unifier
\sigma
of
\Gamma
that uses fresh variables, i.e.,

\VRan(\sigma)\setminus X\neq\emptyset
where
X=\Var(s)\cup\Var(t)
, and

•

this unifier
\sigma
belongs to the set
\mathcal{C}_{E}(\Gamma)
defined in the formulation of Lemma
15
.

Intuitively, NUOF stands for “not unitary or finitary,” but we still need to show that this name is justified.
Given a NUOF
E
-unification problem
\Gamma
,
let
x_{0}\in\VR(\sigma)\setminus X
and consider the following construction of substitutions:

\sigma_{z}:=\sigma\tau_{x_{0},z}\ \ \mbox{where $z\in{V}$ and $\tau_{x_{0},z}:=\{x_{0}\mapsto z,z\mapsto x_{0}\}$}.

One can show that, under certain conditions on

such substitutions
\sigma_{z}
are
\leq_{E}^{V}
-minimal unifiers that are incomparable to each other w.r.t.
\leq_{E}^{V}
.
By
5
, this implies that
\Gamma
cannot have a finite minimal complete set of unifiers w.r.t.
\leq_{E}^{V}

since there are infinitely many variables

satisfying these conditions.

Lemma 17

(
[
8
]
)
.

Let
E
be a regular equational theory
E

\Gamma
a NUOF

(
[

]
)
.

The unrestricted unification type of
\mathsf{ACUI}

.

Since
\mathsf{ACUI}

According to Corollary 3.6 in
[

must use a fresh variable.
Let
\theta
be such an mgu.

If
\Gamma
does not have a minimal complete set of
\mathsf{ACUI}
-unifiers w.r.t. unrestricted instantiation,

Thus, assume that
\Gamma
has a minimal complete set

\mathsf{ACI}

.

The unrestricted unification type of

.

\Gamma

.

The unrestricted unification type of

.
In contrast to
\mathsf{ACU}
, the theory
\mathsf{AC}
is finitary rather than unitary in the restricted setting. A minimal complete set of unifiers
is obtained by taking appropriate subsets of the Hilbert base and turning them into unifiers that have a variable in the range for
each element of the subset (see, e.g.,
[
13
,
36
]
).
Since the full Hilbert base is an appropriate subset, the minimal complete set of
\mathsf{AC}
-unifiers for the unification problem
\Gamma_{n}

corresponding to the linear diophantine equation
ny=x_{1}+2x_{2}+\ldots nx_{n}
for a large enough natural number
n

must contain a unifier
\theta
that introduces a fresh variable. As in the case of
\mathsf{ACUI}
we can now show that, under the assumption that
\Gamma
has
a minimal complete set
\mathcal{S}
of
\mathsf{AC}
-unifiers w.r.t. the unrestricted instantiation preorder, this set
\mathcal{S}
contains a
\leq_{\mathsf{AC}}^{V}
-minimal

\mathsf{AC}
-unifier
\sigma
satisfying
\sigma\leq_{\mathsf{AC}}^{V}\theta
, and thus also
\sigma\leq_{\mathsf{AC}}^{\Var(\Gamma_{n})}\theta
.
Since
\theta
contains a variable in the range for each element of the Hilbert base and elements of the Hilbert base cannot be generated
by a sum of other vectors, this implies that
\sigma
must also contain at least as many variables in its range as
\theta
.
Consequently, we have shown that
\Gamma_{n}
is NUOF, and thus
18
is applicable.

Corollary 22
.

The unrestricted unification type of
\mathsf{AC}
for elementary unification is at least infinitary.

6.
Upper bounds

This section is devoted to obtaining matching “at most infinitary” upper bounds for the “at least infinitary” lower bounds established in the previous section,
by proving that none of these theories can have type zero. In this way, we determine the exact unrestricted unification type (infinitary) of these equational theories.

To demonstrate that the theories in question cannot have unrestricted unification type zero, we prove that all these theories are Noetherian.

{defi}

We call an equational theory
E

Noetherian
w.r.t. the unrestricted instantiation preorder if

•

every strictly descending chain of substitutions
\sigma_{1}>_{E}^{V}\sigma_{2}>_{E}^{V}\sigma_{3}>_{E}^{V}\cdots
is finite.

The notion of a Noetherian equational theory was introduced in
[

]
for the restricted instantiation preorder where non-existence
of an infinite strictly descending chain of substitutions was required for

for all finite subsets

of

.
The authors of
[
27
]
show that Noetherian in their sense precludes restricted unification type zero.
We will see that there are theories that are not Noetherian in the sense of
[
27
]
, but are Noetherian w.r.t. the unrestricted instantiation preorder.
In fact, the theories of restricted type zero considered in this section (
\mathcal{E\mkern-1.618muL}
,
\mathcal{FL}_{0}
,
\mathsf{ACUh}
,
\mathsf{AI}
) cannot be
Noetherian in the restricted setting, but we will show that these theories are Noetherian in the unrestricted setting.

In the following, when we say Noetherian we will mean Noetherian w.r.t. the unrestricted instantiation preorder.

Proposition 23
.

If
E
is a Noetherian theory, then it cannot have unrestricted unification type zero.

Proof 6.1
.

By
5
it is sufficient to show that the set of
\preceq_{E}^{V}
-minimal elements in the set of all unifiers is complete, i.e.,
that every unifier
\theta
is above a minimal unifier. If
\theta
itself is minimal, then we are done. Otherwise, there is a unifier

\sigma_{1}

\theta>_{E}^{V}\sigma_{1}

\sigma_{1}

\sigma_{2}

\theta>_{E}^{V}\sigma_{1}>_{E}^{V}\sigma_{2}>_{E}^{V}\sigma_{3}>_{E}^{V}\cdots

\theta>_{E}^{V}\sigma_{1}>_{E}^{V}\sigma_{2}>_{E}^{V}\sigma_{3}>_{E}^{V}\cdots>_{E}^{V}\sigma_{n}

Our proof that the equational theories under consideration here are Noetherian proceeds in two steps.
First, we show in

the search for a minimal unifier
\sigma
below a given unifier

\theta

Then, we prove that finite theories are Noetherian w.r.t. the unrestricted instantiation preorder. This allows us to establish the

and
\mathsf{D}

Next, we consider regular, locally finite theories, such as

is regular,
but not locally finite. However, a proof similar to the one employed for locally finite theories can be used to establish that

\mathcal{E\mkern-1.618muL}
is Noetherian.
Finally we turn our attention to the class of monoidal theories. We define the subclass of “restrictive” monoidal theories and prove that the regular theories of this subclass are also Noetherian. Since
\mathsf{ACU}

\mathsf{ACUh}
, and
\mathcal{FL}_{0}

\sigma\sim^{V}_{E}\sigma^{\prime}\ \ \mbox{ and }\ \ \Dom(\sigma^{\prime})\subseteq\Dom(\theta).

Consider a signature

Obviously,

or

Now, let
\sigma
and
\theta
be the following substitutions:

\sigma:=\{x\mapsto y,\ y\mapsto f(y)\}\ \ \ \mbox{and}\ \ \theta:=\{x\mapsto g(y)\},

\Dom(\sigma)\not\subseteq\Dom(\theta)

\{y\mapsto g(y)\}\sigma\approx_{E}\theta

\sigma\leq_{E}^{V}\theta

Let us then assume that there is a substitution
\sigma^{\prime}
satisfying (

\sigma^{\prime}
must satisfy the following:

•

•

there are substitutions
\lambda

\lambda\sigma\approx_{E}\sigma^{\prime}
and
\tau\sigma^{\prime}\approx_{E}\sigma

From this, we obtain that

\lambda(\sigma(x))=\lambda(y)\approx_{E}\sigma^{\prime}(x)\ \ \mbox{and}\ \ \lambda(\sigma(y))=\lambda(f(y))\approx_{E}\sigma^{\prime}(y)=y.

Since

Now, by using

\tau(\sigma^{\prime}(x))\approx_{E}\tau(\lambda(y))=\tau(\Xi(\cdots(g(y))\cdots))\approx_{E}\sigma(x)=y\ \ \mbox{and}\ \ \tau(\sigma^{\prime}(y))=\tau(y)\approx_{E}f(y).

Let us continue with the proof of

Lemma 25
.

Let
E
be a regular theory an let

\sigma^{\prime}

\sigma\sim_{E}^{V}\sigma^{\prime}\ \ \mbox{ and }\ \ \Var(\sigma^{\prime}(x))=\{x\}\mbox{ for all }x\in\Dom(\sigma^{\prime})\setminus\Dom(\theta).

Proof 6.2
.

First, note that we can assume without loss of generality that
\VRan(\sigma)\cap\Dom(\theta)=\emptyset

to
\sigma

\sim_{E}^{V}

\sigma

and satisfies the required disjointness condition

Since
\sigma\leq_{E}^{V}\theta

\lambda

\lambda\sigma\approx_{E}\theta
.
Consider the set
\mathcal{X}

Hence, an application of
1

\Var(\lambda(\sigma(x)))=\{x\}

\Var(\sigma(x))=\{z_{1}^{x},\ldots,z_{n_{x}}^{x}\}\ \ \mbox{and}\ \ \Var(\lambda(z_{1}^{x}))\cup\cdots\cup\Var(\lambda(z_{n_{x}}^{x}))=\{x\}.

Let us assume without loss of generality that
\Var(\lambda(z_{1}^{x}))=\{x\}
. This implies that
z_{1}^{x}\neq z_{1}^{y}
for different elements

of
\mathcal{X}
.

Since
\VRan(\sigma)\cap\Dom(\theta)=\emptyset

z_{i}^{x}\not\in\Dom(\theta)
for all

and

.

\lambda(\sigma(z_{i}^{x}))=\lambda(z_{i}^{x})

. However, since

\lambda(\sigma(z_{i}^{x}))\approx_{E}\theta(z_{i}^{x})=z_{i}^{x}

1
yields that
\Var(\lambda(\sigma(z_{i}^{x})))=\{z_{i}^{x}\}
.
For this not to yield a contradiction,

must hold. But then we also have

since
x\in\Dom(\sigma)
.
We have thus shown that all the variables
z_{i}^{x}
for

also belong to
\mathcal{X}=\Dom(\sigma)\setminus\Dom(\theta)
.
Since
z_{1}^{x}\neq z_{1}^{y}
for different elements
x,y
of
\mathcal{X}
, this implies that the
z
-variables with index
1
already “use up”

\mathcal{X}

\tau(x):=\begin{cases}z_{1}^{x}&\mbox{if }x\in\Dom(\sigma)\setminus\Dom(\theta),\\[3.00003pt]
x&\mbox{otherwise}.\end{cases}

According to what we have shown above, this substitution

is an

-renaming for

,

a substitution

Since

and

\tau
is also a

By Lemma 2.12 in

Let

Lemma 26
.

Let
E
be a regular theory and let

be substitutions such that

\sigma\leq^{V}_{E}\theta\ \ \mbox{and}\ \ \Var(\sigma(x))=\{x\}\mbox{ for all }x\in\Dom(\sigma)\setminus\Dom(\theta).

\sigma^{\prime}
such that
\sigma\sim_{E}^{V}\sigma^{\prime}
and

.

Let
\lambda
be such that
\lambda\sigma\approx_{E}\theta
. Consider the set
\mathcal{X}
of all variables
x
such that
x\in\Dom(\sigma)\setminus(\Dom(\theta)\cup\VRan(\theta))
. Then,
\lambda(\sigma(x))\approx_{E}\theta(x)=x
holds for all
x\in\mathcal{X}
. Hence, an application of
1
yields that
\Var(\lambda(\sigma(x)))=\{x\}
. Due to
\Var(\sigma(x))=\{x\}
we have that
\Var(\lambda(\sigma(x)))=\Var(\lambda(x))
. It follows that
\Var(\lambda(x))=\{x\}
for all
x\in\mathcal{X}
. From this, we can conclude that the following holds (for all
x\in\mathcal{X}

x\not\in\Var(\sigma(y))\ \ \mbox{for all variables }y\neq x.

(2)

In fact, if
x\in\Var(\sigma(y))
, then
\Var(\lambda(x))=\{x\}
implies that
x\in\Var(\lambda(\sigma(y)))
. Hence, since
\lambda(\sigma(y))\approx_{E}\theta(y)
and

is regular,
1
tells us that
x\in\Var(\theta(y))
. If
y\in\Dom(\theta)
, then this contradicts the fact that
x\not\in\VRan(\theta)
; otherwise, it contradicts the fact that
y\neq x
.

Let us define
\sigma^{\prime}
as the following substitution:

\sigma^{\prime}(x):=\begin{cases}x&\mbox{if }x\in\mathcal{X},\\[3.00003pt]
\sigma(x)&\mbox{otherwise}.\end{cases}

First, we show that
\sigma\sim_{E}^{V}\sigma^{\prime}
. It suffices to find two substitutions
\tau_{1}
and

such that
\tau_{1}\sigma\approx_{E}\sigma^{\prime}
and
\tau_{2}\sigma^{\prime}\approx_{E}\sigma

and

as

\displaystyle\tau_{1}(x):=\begin{cases}\lambda(x)&\mbox{if }x\in\mathcal{X}\\[3.00003pt]

\displaystyle\tau_{2}(x):=\begin{cases}\sigma(x)&\mbox{if }x\in\mathcal{X}\\[3.00003pt]
x&\mbox{otherwise}.\end{cases}

To show that these substitutions satisfy the required properties, we make the following case distinction:

•

x\in\mathcal{X}
.
We know that
\Var(\sigma(x))=\{x\}
and
\tau_{1}(x)=\lambda(x)
, and thus
\tau_{1}(\sigma(x))=\lambda(\sigma(x))
. By the definition of
\sigma^{\prime}
, we consequently obtain

\tau_{1}(\sigma(x))=\lambda(\sigma(x))\approx_{E}\theta(x)=x=\sigma^{\prime}(x).

In addition, the definitions of
\tau_{2}
and
\sigma^{\prime}
yield
\tau_{2}(\sigma^{\prime}(x))=\tau_{2}(x)=\sigma(x)
.

•

y\not\in\mathcal{X}
. Then (
2

x\not\in\Var(\sigma(y))
for all
x\in\mathcal{X}

and

and
\tau_{2}
behave as the identity on

\tau_{2}(\sigma^{\prime}(x))\approx_{E}\sigma(x)

\tau_{1}\sigma\approx_{E}\sigma^{\prime}

\tau_{2}\sigma^{\prime}\approx_{E}\sigma

In

Our proof that the same holds for the unrestricted case

for the restricted case, but it requires several adjustments to deal with the unrestricted

Remark 27
.

Let

and
X\subseteq V
be a finite set of variables. Then, there are only finitely many terms

such that

The following lemma shows that finite equational theories are Noetherian w.r.t.

Lemma 28
.

If a theory is finite, then it is Noetherian w.r.t. the unrestricted instantiation preorder.

Proof 6.4
.

Let
E
be a finite equational theory. By
2
, we know that
E
is also a regular theory.
Suppose that
E
is not Noetherian, i.e., there exists a strictly decreasing chain
\theta_{1}>_{E}^{V}\theta_{2}>_{E}^{V}\theta_{3}>_{E}^{V}\cdots
of substitutions. Since
\leq_{E}^{V}
is a transitive relation, we have that
\theta_{i}\leq^{V}_{E}\theta_{1}
for all
i\geq 2
. Hence, since
E
is regular, we can apply
24
to obtain substitutions
\sigma_{2},\sigma_{3},\ldots
such that the following holds for all

\theta_{i}\sim_{E}^{V}\sigma_{i}\ \ \mbox{and}\ \ \Dom(\sigma_{i})\cup\VRan(\sigma_{i})\subseteq\Dom(\theta_{1})\cup\VRan(\theta_{1}).

Based on this, we prove that there are indices
i,j
such that
i\neq j
and
\sigma_{i}(x)=\sigma_{j}(x)
for all

. Note that this implies that
\theta_{i}\sim_{E}^{V}\theta_{j}
. Hence, since

, this would contradict the assumption that the above chain of
\theta_{i}

From
\Dom(\sigma_{i})\subseteq\Dom(\theta_{1})\cup\VRan(\theta_{1})
, we obtain that all substitutions
\sigma_{i}
coincide on

Now, let

•

From
\theta_{i}\leq^{V}_{E}\theta_{1}
and
\theta_{i}\sim_{E}^{V}\sigma_{i}
, it follows that there is a substitution
\lambda_{i}
such that
\lambda_{i}\sigma_{i}\approx_{E}^{V}\theta_{1}
. This means that, for all

\lambda_{i}(\sigma_{i}(x))\approx_{E}\theta_{1}(x).

•

Consider the following set of terms:

Since

is a finite equational theory, the

-equivalence class of

•

Since
\VRan(\sigma_{i})\subseteq\Dom(\theta_{1})\cup\VRan(\theta_{1})
for all

for all

, where

is a finite set of variables. Hence, since
\lambda_{i}(\sigma_{i}(x))\in S
and
S
is a finite set, it follows from
27
that
\{\sigma_{i}(x)\mid i\geq 2\}
is a finite set.

Thus, since all substitutions
\sigma_{i}
coincide on
V\setminus(\Dom(\theta_{1})\cup\VRan(\theta_{1}))
and
\Dom(\theta_{1})\cup\VRan(\theta_{1})
is a finite set, the third observation implies that
\sigma_{i}=\sigma_{j}
for some
i\neq j
. This, as argued above, contradicts the existence of an infinite strictly decreasing chain.
Thus, we have proved our claim.

By
23
, this lemma implies that the unrestricted unification type of a finite equational theory cannot be zero. This was already established for the finite theories
\emptyset
,
\mathsf{C}
, and
\mathsf{A}
in Section
4
, where
12
also yields their exact unrestricted unification type.
In
3
, we also identified
\mathsf{AC}
and
\mathsf{D}
as finite theories. We have shown, in
22
for
\mathsf{AC}
and in
14
for
\mathsf{D}
, that the unrestricted unification type of these two theories for elementary unification is at least infinitary.

Theorem 29
.

The unrestricted unification type of
\mathsf{AC}
and
\mathsf{D}
for elementary unification is infinitary.

6.3.
The unrestricted unification types of locally finite theories and of
\mathcal{E\mkern-1.618muL}

In universal algebra
[
28
]
, an equational theory
E
is called locally finite if all finitely generated algebras that are models of
E
are finite. In terms of
\approx_{E}
-equivalence classes, this condition can be formulated as follows.

{defi}

Let
E
be an equational theory over the signature
\Sigma
, and let
[t]_{\approx_{E}}
denote the
\approx_{E}
-equivalence class of the term
t\in T(\Sigma,V)
.
Then
E
is called
locally finite
if the set
\{[t]_{\approx_{E}}\mid t\in T(\Sigma,X)\}
is finite for all finite subsets
X
of
V
.

Note that, in a certain sense, finite and locally finite theories are opposites of each other. Finite means that each equivalence class
[t]_{\approx_{E}}
consists of finitely many terms, and
thus there must be many of them. Locally finite means that there are only finitely many classes, and thus the classes must be large. In particular,
if
\Sigma
contains a function symbol of arity
>0
, then
T(\Sigma,X)
is infinite for all finite sets
\emptyset\neq X\subseteq V
. Thus, if
E
is locally finite,
then at least one equivalence class of terms in
T(\Sigma,X)
must be infinite. Conversely, if
E
is finite, then there must be infinitely many
equivalence classes. Thus, finite and locally finite are mutually exclusive.

Nevertheless, like regular finite theories, the locally finite theories that are regular are Noetherian.

Proposition 30
.

If
E
is a regular, locally finite theory over the signature
\Sigma
, then
E
is Noetherian.

Proof 6.5
.

Consider the set
\{\sigma\mid\sigma\leq^{V}_{E}\theta\}
for a given substitution
\theta
. Since
E
is regular, an application of
24
shows that, up to
\sim_{E}
-equivalence, one can restrict the attention to substitutions
\sigma
such that
\Dom(\sigma)\cup\VRan(\sigma)\subseteq\Dom(\theta)\cup\VRan(\theta)
.
Let
S
be the subset of such substitutions and
X=\Dom(\theta)\cup\VRan(\theta)
. Then
\sigma(x)\in T(\Sigma,X)
for all
\sigma\in S
and
x\in\Dom(\sigma)
. Therefore, since
X
is a finite set and
\Dom(\sigma)
is contained in the finite set
\Dom(\theta)\cup\VRan(\theta)
, the fact that
E
is locally finite implies that
S
is finite up to
\approx_{E}
-equivalence. Overall, we thus can conclude that
\{\sigma\mid\sigma\leq^{V}_{\mathsf{AI}}\theta\}
must be finite up to
\sim_{E}
-equivalence.
Thus, there cannot be an infinite, strictly decreasing chain w.r.t.
\leq^{V}_{E}
issuing from
\theta
. Since
\theta
was an arbitrary substitution, this
proves that
E
is Noetherian.

Among the theories introduced in Section
2
, the following theories are locally finite.

Proposition 31
.

The theories
\mathsf{AI}
,
\mathsf{ACI}
, and
\mathsf{ACUI}
are locally finite.

Proof 6.6
.

For
\mathsf{ACI}
and
\mathsf{ACUI}
, this is an easy consequence of the fact that equivalence modulo these theories can be characterized by the set of variables the terms contain,
i.e.,
s
and
t
are equivalent modulo
\mathsf{ACI}
or
\mathsf{ACUI}
iff
\Var(s)=\Var(t)

[
2
]
.
For
\mathsf{AI}
, local finiteness was show by McLean
[
51
]
(see also
[
65
]
).

Together with
23
, the previous two propositions show that the unrestricted unification types of
\mathsf{AI}
,
\mathsf{ACI}
, and
\mathsf{ACUI}
cannot be zero.
Since we already know that the unrestricted unification types of these theories are at least infinitary
(see
14
,
20
, and
19
),
this yields the following theorem.

Theorem 32
.

The unrestricted unification type of
\mathsf{AI}
,
\mathsf{ACI}
, and
\mathsf{ACUI}
for elementary unification is infinitary.

The theory
\mathcal{E\mkern-1.618muL}
is regular, but not locally finite since the terms in the sequence

x,\ \ \exists r.x,\ \ \exists r.(\exists r.x),\ \ \exists r.(\exists r.(\exists r.x)),\ldots

are pairwise not
\approx_{\mathcal{E\mkern-1.618muL}}
-equivalent. Thus,
30
cannot be applied to
\mathcal{E\mkern-1.618muL}
. However, a proof very similar
to the one of
30
can be used to show that
\mathcal{E\mkern-1.618muL}
is Noetherian.
The reason is that one can actually bound the role depth of the terms relevant in the proof.

The
role depth
\rd(C)
of an
\mathcal{E\mkern-1.618muL}
concept (viewed as a term with variables from
V
) is the the maximal nesting of existential restrictions,
i.e.,

•

\rd(x):=\rd(\top):=0
for
x\in V
,

•

\rd(C\sqcap D):=\max\{\rd(C),\rd(D)\}
and
\rd(\exists r.C):=1+\rd(C)
.

The following lemma is an easy consequence of the fact that
\approx_{\mathcal{E\mkern-1.618muL}}
preserves the role depth as well as the set of role names occurring in a concept description, and applying a substitution to a concept description can only increase the role depth and add role names, but not decrease the role depth or remove role names.

Lemma 33
.

Let
\sigma,\theta
be substitutions such that
\sigma\leq_{\mathcal{E\mkern-1.618muL}}^{V}\theta
.
Then the following holds for all
x\in V
: the role depth of
\sigma(x)
is bounded by the role depth of
\theta(x)
, and the role names occurring in
\sigma(x)
also occur in
\theta(x)
.

As a consequence of
24
and
33
we know that, for a given substitution
\theta
, the set of more general
substitutions is finite up to the equivalence relation
\sim_{\mathcal{E\mkern-1.618muL}}^{V}
. In fact,
24
shows that one can restrict the attention
to substitutions
\sigma
satisfying
\Dom(\sigma)\cup\VRan(\sigma)\subseteq\Dom(\theta)\cup\VRan(\theta)
.
In addition, for all
x\in\Dom(\sigma)
, the concept descriptions
\sigma(x)
are built using role names occurring in
\theta(x)
as well
as variables from
\Dom(\theta)\cup\VRan(\theta)
, and have a role depth that is bounded by the one of
\theta(x)
.
It is well-known
[
10
]
that there are up to
\approx_{\mathcal{E\mkern-1.618muL}}
-equivalence only finitely many
\mathcal{E\mkern-1.618muL}
concept descriptions
satisfying these properties.

Lemma 34
.

For a given substitution
\theta
, the set
\{\sigma\mid\sigma\leq_{\mathcal{E\mkern-1.618muL}}^{V}\theta\}
is finite up to
\sim_{\mathcal{E\mkern-1.618muL}}^{V}
-equivalence.

This lemma obviously implies that
\mathcal{E\mkern-1.618muL}
is Noetherian (see the proof of
30
). Hence, an application of
23
yields that the unrestricted unification type of
\mathcal{E\mkern-1.618muL}
cannot be zero. Since we already know that the unrestricted unification type of
\mathcal{E\mkern-1.618muL}
is at least infinitary (see
14
), we obtain the following result.

Theorem 35
.

The unrestricted unification type of
\mathcal{E\mkern-1.618muL}
for elementary unification is infinitary.

6.4.
Monoidal theories

The theory
\mathsf{ACU}
is an example of a regular theory that belongs to the class of monoidal theories. For this theory, we proved in
[
5
]
directly that its unrestricted unification type cannot be zero. In this section, we generalize this result to a whole class of regular monoidal theories, which also contains
\mathcal{FL}_{0}
and
\mathsf{ACUh}
. To this purpose, we proceed as follows:

(1)

We recall some relevant aspects of the relation between monoidal theories and semirings.

(2)

We define the subclass of restrictive monoidal theories, and then show that the regular theories in this subclass are Noetherian. Thus, they cannot have unrestricted unification type zero.

(3)

Finally, we establish that
\mathsf{ACU}
,
\mathcal{FL}_{0}
, and
\mathsf{ACUh}
are restrictive monoidal theories, and thus, their unrestricted unification type is infinitary.

Let us start by introducing the notion of a semiring. A
semiring

\mathcal{S}
is a tuple
(S,\oplus,\mathsf{0},\otimes,\mathsf{1})
, where
\oplus
and
\otimes
are two binary operations over the set
S
, and
\mathsf{0}
and
\mathsf{1}
are two constant elements, such that:

•

(S,\oplus,\mathsf{0})
is a commutative monoid.

•

(S,\otimes,\mathsf{1})
is a monoid.

•

the operator
\otimes
distributes over
\oplus
from left and right, i.e., for all
a,b,c\in S
:

a\otimes(b\oplus c)=(a\otimes b)\oplus(a\otimes c)\ \ \ \mbox{and}\ \ \ (a\oplus b)\otimes c=(a\otimes c)\oplus(b\otimes c).

•

a\otimes\mathsf{0}=\mathsf{0}\otimes a=\mathsf{0}
for all
a\in S
.

The operators
\oplus
and
\otimes
are usually called the
addition
and
multiplication
of the semiring, respectively.

Nutt showed in
[
52
]
that solving unification problems in a monoidal theory
E
can be reduced to solving linear equations over an associated semiring
\mathcal{S}_{E}=(S_{E},\oplus,\mathsf{0},\otimes,\mathsf{1})
. The precise details of how to define
\mathcal{S}_{E}
from
E
can be found in
[
52
,
14
]
.
A key component of showing the results in
[
52
]
is that, given a finite set of variables
X_{n}=\{x_{1},\ldots,x_{n}\}
, the
\approx_{E}
-equivalence class of a term
t\in T(\Sigma,X_{n})
can be uniquely represented by a vector
\vec{v}_{n}(t)=(a^{t}_{1},\ldots,a^{t}_{n})
, where
a^{t}_{1},\ldots,a^{t}_{n}
are elements of
\mathcal{S}_{E}
(this is a consequence of Corollary 5.11 in
[
52
]
).
Based on this representation, a substitution
\sigma
with
\Dom(\sigma)\subseteq X_{n}
and
\VRan(\sigma)\subseteq\{y_{1},\ldots,y_{m}\}
(
n,m\geq 1
) can be represented as an
n\times m
matrix with rows
\vec{v}_{m}(\sigma(x_{1})),\ldots,\vec{v}_{m}(\sigma(x_{n}))
.
Moreover, applying a substitution
\sigma
to a term
t
corresponds to multiplying the vector for
t
with the matrix for
\sigma
,
i.e., the representation
\vec{v}_{m}(\sigma(t))
of
\sigma(t)
can be obtained by computing the following sums over
\mathcal{S}_{E}
(for all
j,1\leq j\leq m
):

a^{\sigma(t)}_{j}\ =\ \bigoplus\limits_{k=1}^{n}a^{t}_{k}\otimes a^{\sigma(x_{k})}_{j}.

For simplicity, given a substitution
\sigma
, we will from now on write
(a^{\sigma}_{i1},\ldots,a^{\sigma}_{im})
instead of
(a^{\sigma(x_{i})}_{1},\ldots,a^{\sigma(x_{i})}_{m})
to refer to the vector
\vec{v}_{m}(\sigma(x_{i}))
.

{exa}

The semiring
\mathcal{S}_{\mathsf{ACU}}
associated to
\mathsf{ACU}
corresponds to the semiring of natural numbers
(\mathbb{N},+,0,\cdot,1)

[
20
,
52
]
.
The
\approx_{\mathsf{ACU}}
-equivalence class of a term
t\in T(\Sigma,X_{n})
can be uniquely represented by the vector
\vec{v}_{n}(t)=(a^{t}_{1},\ldots,a^{t}_{n})
, where
a^{t}_{i}
is the number of occurrences of the variable
x_{i}
in
t
(Lemma 10.3.1 of
[
13
]
).

For example, if
t=f(x_{1},f(x_{2},x_{2}))
and
\sigma=\{x_{1}\mapsto x_{2},x_{2}\mapsto f(x_{1},x_{1})\}
, then

\vec{v}_{2}(t)=(1,2)
and the matrix representing
\sigma
has the rows
(0,1)
and
(2,0)
.
The vector representing
\sigma(t)=f(x_{2},f(f(x_{1},x_{1}),f(x_{1},x_{1})))
is
(4,1)
. Note that
4=1\cdot 0+2\cdot 2
and
1=1\cdot 1+2\cdot 0
.

Let us continue by defining the subclass of restrictive monoidal theories. A
total preorder
on a set
S
is a reflexive and transitive binary relation
\leq
on
S
such that any two elements
a,b
of
S
are comparable, i.e.,
a\leq b
or
b\leq a
. As usual, we denote the strict part of
\leq
as
<
, i.e.,
a<b
if

a\leq b
, but
b\not\leq a
.

{defi}

Given a monoidal equational theory
E
, we say that
E
is
restrictive
if there is a
total preorder

\leq_{\mathcal{S}_{E}}
on
S_{E}
such that

(1)

For all
a,b,c\in S_{E}
with
c\neq\mathsf{0}
:
a<_{\mathcal{S}_{E}}b
implies that
a<_{\mathcal{S}_{E}}b\otimes c
.

(2)

For all
a,b,c\in S_{E}
:
a<_{\mathcal{S}_{E}}b
implies that
a<_{\mathcal{S}_{E}}b\oplus c
.

(3)

For all
a\in S_{E}
: the set
\{b\mid b\leq_{\mathcal{S}_{E}}a\}
is finite.

It is easy to see that the standard total order
\leq_{\mathbb{N}}
on
\mathbb{N}
satisfies these properties, and thus,
\mathsf{ACU}
is a restrictive monoidal theory. We will later show that
\mathsf{ACUI}
and
\mathcal{FL}_{0}
are also restrictive theories.
It is worth asking whether there are natural examples of monoidal theories that are not restrictive. The answer to this question is positive,
as shown by the following example.

{exa}

The semiring
\mathcal{S}_{\mathsf{AG}}
associated to the theory
\mathsf{AG}
of Abelian groups corresponds to the semiring of integers
(\mathbb{Z},+,0,\cdot,1)

[
20
,
52
]
.
To show that the equational theory
\mathsf{AG}
is not a restrictive theory, we must demonstrate that
(\mathbb{Z},+,0,\cdot,1)
does not admit a total preorder satisfying the conditions required in
subsection 6.4
.

Suppose there exists a total preorder
\leq_{\mathbb{Z}}
on
\mathbb{Z}
satisfying these conditions. Note that this preorder need not be identical to the usual total order
\leq
on
\mathbb{Z}
.
Let
a\in\mathbb{Z}
. By Condition
3
, the set
\{c\mid c\leq_{\mathbb{Z}}a\}
is finite. Hence, since
\leq_{\mathbb{Z}}
is a total preorder and
\mathbb{Z}
is infinite, there must exist an element
b\in\mathbb{Z}
such that
a\neq b
and
a<_{\mathbb{Z}}b
.
It then follows by Condition
2
that

a<_{\mathbb{Z}}b+c\ \mbox{for all }c\in\mathbb{Z}.

(3)

However, if we set
c:=a-b
, then
a=b+c
. This means that
b+c\leq_{\mathbb{Z}}a
since
\leq_{\mathbb{Z}}
is reflexive, which contradicts (
3
).
Hence, such a preorder
\leq_{\mathbb{Z}}
cannot exist, which shows that the monoidal theory
\mathsf{AG}
is not restrictive.

We now turn our attention to showing that regular and restrictive monoidal theories are Noetherian w.r.t. the unrestricted instantiation preorder. To this end, it is convenient to first make some general assumptions for the rest of the section:

•

We assume that
E
is a monoidal theory that is also restrictive.

•

We will use
\leq_{\mathcal{S}_{E}}
to refer to a fixed total preorder on
S_{E}
satisfying the conditions in
subsection 6.4
.

•

Given
n\geq 0
, we use
X_{n}
to denote an indexed set of
n
variables
\{x_{1},\ldots,x_{n}\}
. In addition, we denote by
P_{n}
the set of pairs
\{1,\ldots,n\}\times\{1,\ldots,n\}
.

Next, we introduce some notions and show a property about
\leq_{E}^{V}
(in
38
), which will be useful later on.

{defi}

Let
n\geq 0
and
P\subseteq P_{n}
. Additionally, let
\sigma_{1}
and
\sigma_{2}
be substitutions whose domains and variable ranges are contained in
X_{n}
. We say that
\sigma_{1}
is greater than
\sigma_{2}
w.r.t.
P
(denoted as
\sigma_{1}>_{P}\sigma_{2}
)
if

•

for all
(i,j)\in P
and
k\in\{1,\ldots,n\}
:
a^{\sigma_{1}}_{ij}\ >_{\mathcal{S}_{E}}\ a^{\sigma_{2}}_{ik}
,

and that
\sigma_{1}
and
\sigma_{2}
coincide on
P
if

•

for all
(i,j)\in P
:
a^{\sigma_{1}}_{ij}\ =a^{\sigma_{2}}_{ij}
.

It is not hard to show that
>_{P}
is a transitive relation.

Lemma 36
.

Let
n\geq 0
and
P\subseteq P_{n}
. The relation
>_{P}
is transitive.

Proof 6.7
.

Let
\sigma_{1},\sigma_{2}
and
\sigma_{3}
be substitutions such that
\sigma_{1}>_{P}\sigma_{2}
and
\sigma_{2}>_{P}\sigma_{3}
. To prove transitivity of
>_{P}
, we need to show that
\sigma_{1}>_{P}\sigma_{3}
.

Let us take any pair
(i,j)\in P
. Since
\sigma_{1}>_{P}\sigma_{2}
, we have that
a^{\sigma_{1}}_{ij}\ >_{\mathcal{S}_{E}}\ a^{\sigma_{2}}_{ik}
for all
k\in\{1,\ldots,n\})
. In particular, this yields
a^{\sigma_{1}}_{ij}\ >_{\mathcal{S}_{E}}\ a^{\sigma_{2}}_{ij}
. Furthermore,
\sigma_{2}>_{P}\sigma_{3}
means that
a^{\sigma_{2}}_{ij}\ >_{\mathcal{S}_{E}}\ a^{\sigma_{3}}_{ik}
for all
k\in\{1,\ldots,n\}
.
Consequently, transitivity of
>_{\mathcal{S}_{E}}
implies that

a^{\sigma_{1}}_{ij}\ >_{\mathcal{S}_{E}}\ a^{\sigma_{3}}_{ik}\ \ \mbox{for all }k\in\{1,\ldots,n\}.

Thus, since
(i,j)\in P
was arbitrarily chosen, we can conclude that
\sigma_{1}>_{P}\sigma_{3}
.

The following property of
\leq_{E}^{V}
is needed to prove
38
.

Lemma 37
.

Let
\sigma_{1}
and
\sigma_{2}
be substitutions such that
\sigma_{1}\leq_{E}^{V}\sigma_{2}
and

\Dom(\sigma_{1})\cup\Dom(\sigma_{2})\cup\VRan(\sigma_{1})\cup\VRan(\sigma_{2})\subseteq X_{n}.

Then, there is a substitution
\lambda
such that
\lambda\sigma_{1}\approx_{E}\sigma_{2}
and
\Dom(\lambda)\cup\VRan(\lambda)\subseteq X_{n}
.

Proof 6.8
.

Since
\sigma_{1}\leq_{E}^{V}\sigma_{2}
, there is a substitution
\lambda
such that
\lambda\sigma_{1}\approx_{E}\sigma_{2}
.
Let
\VRan(\lambda)\setminus X_{n}=\{z_{1},\ldots,z_{k}\}
. Consider the substitution
\theta:=\{z_{1}\mapsto x_{1},\ldots,z_{k}\mapsto x_{1}\}
, an define the substitution
\lambda^{\prime}
as follows:

•

\lambda^{\prime}(x_{i}):=\theta(\lambda(x_{i}))
for all
i\in\{1,\ldots,n\}
, and

•

\lambda^{\prime}(y):=y
for all
y\not\in X_{n}
.

The definition of
\lambda^{\prime}
ensures that
\Dom(\lambda^{\prime})\cup\VRan(\lambda^{\prime})\subseteq X_{n}
, and
\Dom(\sigma_{1})\cup\Dom(\sigma_{2})\subseteq X_{n}
implies that
\lambda^{\prime}\sigma_{1}(y)=y=\sigma_{2}(y)
for all
y\not\in X_{n}
.
Finally, since
\lambda^{\prime}
and
\theta\lambda
coincide on
X_{n}
,
\approx_{E}
is closed under substitutions, and
\{z_{1},\ldots,z_{k}\}\cap\VRan(\sigma_{2})=\emptyset
, we obtain

\lambda^{\prime}\sigma_{1}(x_{i})=\theta(\lambda\sigma_{1}(x_{i}))\approx_{E}\theta(\sigma_{2}(x_{i}))=\sigma_{2}(x_{i})\ \ \mbox{for all }i\in\{1,\ldots,n\}.

Hence, we have shown that
\lambda^{\prime}\sigma_{1}\approx_{E}\sigma_{2}
. This concludes our proof.

We are now ready to prove
38
.

Lemma 38
.

Let
n\geq 0
and
P\subseteq P_{n}
. In addition, let
\sigma_{1}
,
\sigma_{2},\sigma_{3}
be substitutions such that:

•

\Dom(\sigma_{\ell})\cup\VRan(\sigma_{\ell})\subseteq X_{n}
for
\ell\in\{1,2,3\}
,

•

\sigma_{1}\leq_{E}^{V}\sigma_{2}
,

•

\sigma_{1}
is greater than
\sigma_{2}
w.r.t.
P
, and

•

\sigma_{1}
and
\sigma_{3}
coincide on
P_{n}\setminus P
.

Then,
\sigma_{3}\leq_{E}^{V}\sigma_{2}
.

Proof 6.9
.

Since
\sigma_{1}\leq_{E}^{V}\sigma_{2}
, there is a substitution
\lambda
such that
\lambda\sigma_{1}\approx_{E}\sigma_{2}
. By
37
, we can assume that
\Dom(\lambda)\cup\VRan(\lambda)\subseteq X_{n}
.
Hence, since
\Dom(\sigma_{1})\cup\Dom(\sigma_{3})\cup\Dom(\lambda)\subseteq X_{n}
, we know that
\Dom(\lambda\sigma_{1})\subseteq X_{n}
and
\Dom(\lambda\sigma_{3})\subseteq X_{n}
. To prove that
\sigma_{3}\leq_{E}^{V}\sigma_{2}
, it thus suffices to show that

\lambda\sigma_{1}(x_{i})\ \approx_{E}\ \lambda\sigma_{3}(x_{i})\ \ \mbox{for all }i\in\{1,\ldots,n\}.

(4)

Let
i\in\{1,\ldots,n\}
. Since
\VRan(\sigma_{1})\cup\VRan(\lambda)\subseteq X_{n}
, the
\approx_{E}
-equivalence class of
\lambda\sigma_{1}(x_{i})
can be uniquely represented with a vector of the form
(a^{\lambda\sigma_{1}}_{i1},\ldots,a^{\lambda\sigma_{1}}_{in})
, where each value
a^{\lambda\sigma_{1}}_{ij}
(
1\leq j\leq n
) is determined by the following expression:

a^{\lambda\sigma_{1}}_{ij}\ =\ \bigoplus_{k=1}^{n}a^{\sigma_{1}}_{ik}\otimes a^{\lambda}_{kj}.

Since
\lambda\sigma_{1}(x_{i})\approx_{E}\sigma_{2}(x_{i})
, we thus obtain

a^{\lambda\sigma_{1}}_{ij}\ =\ \bigoplus_{k=1}^{n}a^{\sigma_{1}}_{ik}\otimes a^{\lambda}_{kj}\ =\ a^{\sigma_{2}}_{ij}\ \ \mbox{for all }j\in\{1,\ldots,n\}.

(5)

Consider any pair
(i,k)\in P
. Since
\sigma_{1}>_{P}\sigma_{2}
, this means that
a^{\sigma_{1}}_{ik}>_{\mathcal{S}_{E}}a^{\sigma_{2}}_{ij}
for all
j\in\{1,\ldots,n\}
.
Hence, it must be the case that
a^{\lambda}_{kj}=\mathsf{0}
for all
j\in\{1,\ldots,n\}
. Otherwise, there would be an index
j\in\{1,\ldots,n\}
such that

•

a^{\sigma_{1}}_{ik}\otimes a^{\lambda}_{kj}>_{\mathcal{S}_{E}}a^{\sigma_{2}}_{ij}
(by (
1
) in
subsection 6.4
), and hence,

•

the whole sum in (
5
) yields a value
a>_{\mathcal{S}_{E}}a^{\sigma_{2}}_{ij}
(by (

7.
Conclusion

In this paper, we have investigated the effect that the employed instantiation preorder has on the unification type of an equational theory.
As a rule of thumb, one can extract from this investigation that nothing changes if unifiers in a minimal complete set w.r.t. the restricted
instantiation preorder do not need fresh variables (
11
), whereas the unification type switches from unitary or finitary
to at least infinitary otherwise (
18
), though the latter result was only shown for regular theories. We have employed
18

in Section
5
to prove that the unification type of the frequently used theories
\mathsf{ACUI}
,
\mathsf{ACI}
,
\mathsf{ACU}
, and
\mathsf{AC}
is at least infinitary
w.r.t. the unrestricted instantiation preorder (
19
,
20
,
21
, and
22
).
For theories whose restricted unification type is infinitary or zero, one can use
6
to show the lower bound “at least infinitary”
for the unrestricted unification type. In Section
5
we have employed this argument for the theories
\mathsf{AI}
,
\mathsf{D}
,
\mathcal{E\mkern-1.618muL}
,
\mathcal{FL}_{0}
, and
\mathsf{ACUh}
.
Our main tool for proving “at most infinitary” upper bounds for regular theories in Section
6
was
24
,
which basically states that, up to equivalence, substitutions that have a given substitution
\theta
as instance do not “use” more variables than
\theta
.
We have employed this result to prove “at most infinitary” upper bounds for several classes of regular theories:
regular finite theories, regular locally finite theories, and regular monoidal theories that satisfy an additional restriction on the associated semiring,
called restrictiveness.

We have clarified by
8
,
that the reason for changes in the unification type when going from the restricted to the unrestricted setting
is not that the unrestricted instantiation preorder considers infinitely many variables, but that it does
not leave infinitely many variables unobserved. In particular, this shows that nothing changes compared to the
restricted setting if one compares unifiers on finite supersets of the set of variables occurring in the unification problem instead.

Rather surprisingly, with unification in the description logic
\mathcal{E\mkern-1.618muL}
, we have found (already in the conference version
[
5
]
) an example
where the unification type improves from type zero to infinitary when going from the restricted to the unrestricted instantiation preorder (
35
).
In the present paper we were able to show that this is not an extraordinary property of
\mathcal{E\mkern-1.618muL}
, but this also happens for the theories
\mathsf{AI}
,
\mathcal{FL}_{0}
, and
\mathsf{ACUh}
(
32
and
42
). However, we were also able to find a case (unification in the modal logic
\mathsf{K}
) where the
unification type stays zero when going from the restricted to the unrestricted setting (
13
).

The reason for restricting the presentation of our results to elementary unification was mainly for simplicity. For most of our results,
it is easy to see that they hold accordingly for unification with constants. Lower bounds transfer from elementary unification to unification
with constants since every elementary unification problem is also a problem with constants.
8
8

8

Unification with constants only means that one is allowed to use free constants in the unification problem. One is not forced to do so.

For our upper bounds in Section
6
, it is easy to see that the results for finite and locally finite theories also hold
in the presence of free constants. For monoidal theories, adapting our proofs would, however, be more work since, e.g., the characterization of composition
substitution in (
5
) would need to take free constants into account.
For general unification, results on the combination of unification algorithms
[
60
,
15
]

imply that restricted unification type unitary or finitary for unification with linear constant restrictions, a generalization of unification with constants,
yields restricted unification type unitary or finitary for general unification. Whether such combination results can be adapted to the unrestricted setting
or to unification type infinitary is not clear.

While the contributions of this work are primarily foundational, one can nevertheless ask whether the obtained results also have a practical impact.
The answer to the question which instantiation preorder should be used in practice mainly depends on the application that employs unification,
i.e., which variables are relevant in the overall procedure and for which of them need the instantiation relation between the unifiers hold.
In case the restricted unification type is unitary/finitary, the restricted instantiation preorder should be used unless the application enforces comparison on all variables.
For example, in Knuth-Bendix completion modulo equational theories
[
54
,
43
,
23
]
,
where unification is employed to test confluence by computing critical pairs, the restricted instantiation preorder is clearly sufficient, and thus should be used for theories that are unitary or finitary w.r.t. it.
In case the restricted unification type is zero and the unrestricted one is infinitary, it may be useful to employ unrestricted unification
if one can find a unification algorithm that enumerates a minimal complete set of unifiers w.r.t. the unrestricted preorder.
From the restricted preorder point of view, such an algorithm would enumerate a complete set of unifiers that is non-minimal,
but usually still much smaller than the set of all unifiers.
With few exceptions, where the restricted and the unrestricted types coincide according to our
11

(e.g., the empty theory, commutativity
\mathsf{C}
, or associativity
\mathsf{A}
)
there are no unification algorithms known for the unrestricted case since research on equational unification concentrated on the restricted case.
For settings where the unrestricted type is better (i.e., infinitary), it is thus a new challenge to find an algorithm enumerating a minimal
complete set of unifiers. Our proof of type infinitary for
\mathcal{E\mkern-1.618muL}
,
\mathsf{AI}
,
\mathcal{FL}_{0}
, and
\mathsf{ACUh}
does not directly yield a practical algorithm.
