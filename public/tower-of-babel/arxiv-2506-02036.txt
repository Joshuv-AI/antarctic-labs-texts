Multi-Operator Quantum Uncertainty Relations from New Cauchy-Schwarz Inequalities
Samuel R.​ Hedemann

Abstract
We present new generalizations of Cauchy-Schwarz (CS) inequalities to multiple vectors and use them to derive multi-operator quantum uncertainty relations and propose multi-operator squeezing.

II.1
Multiple-Vector Cauchy-Schwarz Inequalities for Complex Vectors

A
balanced multiple-vector CS inequality
involving all vector magnitudes exactly once on the left is

\framebox{$\prod\limits_{j=1}^{M}{|{{\bf{a}}_{j}}|}\geqslant{\left({\prod\limits_{j=1}^{M-1}{\prod\limits_{k=j+1}^{M}{|{{\bf{a}}_{j}}\cdot{{\bf{a}}_{k}}|}}}\right)^{\frac{1}{{M-1}}}}$}\;,

(2)

valid for
M\geqslant 2
complex vectors, see
Sec.
III.1.2
for proof. For example, for
M=3
vectors
{\bf{a}},{\bf{b}},{\bf{c}}
,
(
2
)
yields

|{\bf{a}}||{\bf{b}}||{\bf{c}}|\geqslant\sqrt{|{\bf{a}}\cdot{\bf{b}}||{\bf{a}}\cdot{\bf{c}}||{\bf{b}}\cdot{\bf{c}}|}.

(3)

For
M=4

{\bf{a}},{\bf{b}},{\bf{c}},{\bf{d}}
,
(
2
)

|{\bf{a}}||{\bf{b}}||{\bf{c}}||{\bf{d}}|\geqslant\sqrt[3]{{|{\bf{a}}\cdot{\bf{b}}||{\bf{a}}\cdot{\bf{c}}||{\bf{a}}\cdot{\bf{d}}||{\bf{b}}\cdot{\bf{c}}||{\bf{b}}\cdot{\bf{d}}||{\bf{c}}\cdot{\bf{d}}|}}.

(4)

A more general
unbalanced multiple-vector CS inequality
for any monomial combination of powers of vector magnitudes of any
K\geqslant 1

\framebox{$\prod\limits_{q=1}^{K}{|{{\bf{a}}_{{j_{q}}}}||{{\bf{a}}_{{k_{q}}}}|}\geqslant\prod\limits_{q=1}^{K}{|{{\bf{a}}_{{j_{q}}}}\cdot{{\bf{a}}_{{k_{q}}}}|}$}\;,

(5)

where each

can have vectors in common with other pairs; see

for proof. For example, for

with various vector definitions,

5

yields

\begin{array}[]{rcl}{|{\bf{a}}{|^{2}}|{\bf{b}}{|^{2}}|{\bf{c}}{|^{2}}}&\!\!\geqslant&\!\!{|{\bf{a}}\cdot{\bf{b}}||{\bf{a}}\cdot{\bf{c}}||{\bf{b}}\cdot{\bf{c}}|,}\\
{|{\bf{a}}{|^{2}}|{\bf{b}}||{\bf{c}}|}&\!\!\geqslant&\!\!{|{\bf{a}}\cdot{\bf{b}}||{\bf{a}}\cdot{\bf{c}}|,}\\
{|{\bf{a}}||{\bf{b}}{|^{2}}|{\bf{c}}|}&\!\!\geqslant&\!\!{|{\bf{a}}\cdot{\bf{b}}||{\bf{b}}\cdot{\bf{c}}|,}\\
{|{\bf{a}}||{\bf{b}}||{\bf{c}}{|^{2}}}&\!\!\geqslant&\!\!{|{\bf{a}}\cdot{\bf{c}}||{\bf{b}}\cdot{\bf{c}}|,}\\
{|{\bf{a}}||{\bf{b}}|\geqslant|{\bf{a}}\cdot{\bf{b}}|,\quad|{\bf{a}}||{\bf{c}}|}&\!\!\geqslant&\!\!{|{\bf{a}}\cdot{\bf{c}}|,\quad|{\bf{b}}||{\bf{c}}|\geqslant|{\bf{b}}\cdot{\bf{c}}|,}\end{array}

Multi-Operator Quantum Uncertainty Relations for Hermitian Operators and Normalized States

For a system in normalized state
\rho
, mixed or pure,
(

\framebox{$\prod\limits_{j=1}^{M}{{\sigma_{{A_{j}}}}}\geqslant{\left({\prod\limits_{j=1}^{M-1}{\prod\limits_{k=j+1}^{M}{|\sigma_{{A_{j}},{A_{k}}}^{2}|}}}\right)^{\frac{1}{{M-1}}}}$}\;,

For a system in a generally unnormalized state
\rho

\framebox{$\prod\limits_{j=1}^{M}{{{\widetilde{\sigma}}_{{A_{j}}}}}\geqslant{\left({\prod\limits_{j=1}^{M-1}{\prod\limits_{k=j+1}^{M}{|\widetilde{\sigma}_{{A_{j}},{A_{k}}}^{2}|}}}\right)^{\frac{1}{{M-1}}}}$}\;,\\
~\\

(23)

\widetilde{\sigma}_{A,B}^{2}\equiv\widetilde{\text{cov}}(A,B)\equiv\langle{A^{\dagger}}B\rangle-[2-{\rm tr}(\rho)]\langle{A^{\dagger}}\rangle\langle B\rangle,

so that the

\widetilde{\sigma}_{A}^{2}\equiv\widetilde{\sigma}_{A,A}^{2}\equiv\widetilde{\text{cov}}(A,A)\equiv\langle{A^{\dagger}}A\rangle-[2-{\rm tr}(\rho)]\langle{A^{\dagger}}\rangle\langle A\rangle,

(25)

and we define the
generalized standard deviation
as

{\widetilde{\sigma}_{A}}\equiv\sqrt{\widetilde{\sigma}_{A}^{2}}\equiv\sqrt{\widetilde{\sigma}_{A,A}^{2}}\geqslant 0.

where examples of

II.6
Multi-Operator Squeezing Definition

In
Sec.
, we propose to define
q/M

operator squeezing
(or just
q/M

squeezing
) for
q\in 1,\ldots,M-1
, such that if the lower limit of its generalized variance product (with respect to a particular
M
-operator uncertainty relation) is
\beta
, then using the balanced any-operator uncertainty relation from
(
23
)
for a set of
M

q/M

if any particular subset
\{A_{j_{1}},\ldots,A_{j_{q}}\}
of those operators obeys

\framebox{$\begin{array}[]{*{20}{l}}{{{\widetilde{\sigma}}_{{A_{{j_{1}}}}}^{2}}\!\!<{\beta^{1/M}}\ldots\,\,\text{and}\,\,\ldots\;{{\widetilde{\sigma}}_{{A_{{j_{q}}}}}^{2}}\!\!<{\beta^{1/M}}}\\
{\text{s.t. all uncertainty relations are still obeyed}}\end{array}$}\;,

(33)

where, using the square of the right side of
(
23
)
,

\beta\equiv{\left({\prod\limits_{j=1}^{M-1}{\prod\limits_{k=j+1}^{M}{|\widetilde{\sigma}_{{A_{j}},{A_{k}}}^{2}|}}}\right)^{\!\!\frac{2}{{M-1}}}},

(34)

and the “uncertainty relations still obeyed” are all balanced any-operator uncertainty relations from
(
23
)
for this
M
or smaller
M
, where the simplification should be the same (i.e., if using the Robertson version for
M
operators, use that for all relations of smaller
M
as well).

For example, for
M=3
operators
A,B,C
, a state is
2/3
squeezed if, for constants
a,b,c>1
, and if
\beta\geqslant 1
,

\begin{array}[]{*{20}{l}}{{\widetilde{\sigma}_{A}^{2}}\!=\!\frac{{{\beta^{1/3}}}}{a}\!<\!\beta^{1/3}\,\,\text{and}\,\,\widetilde{\sigma}_{C}^{2}\!=\!\frac{{{\beta^{1/3}}}}{c}\!<\!\beta^{1/3}\;\;\text{s.t.}\,\,\widetilde{\sigma}_{B}^{2}\!=\!ac{\beta^{1/3}},}\\
{\textnormal{\scalebox{0.75}{$\widetilde{\sigma}_{A}^{2}\widetilde{\sigma}_{B}^{2}=c\beta^{2/3}\geqslant|\widetilde{\sigma}_{A,B}^{2}|,\,\,\widetilde{\sigma}_{A}^{2}\widetilde{\sigma}_{C}^{2}=\frac{{{\beta^{2/3}}}}{{ac}}\geqslant|\widetilde{\sigma}_{A,C}^{2}|,\,\,\widetilde{\sigma}_{B}^{2}\widetilde{\sigma}_{C}^{2}=a\beta^{2/3}\geqslant|\widetilde{\sigma}_{B,C}^{2}|$}}.}\end{array}

(35)

See

for a more detailed look at this example.

III.1
Proof of The Multiple-Vector Cauchy-Schwarz Inequalities for Complex Vectors

Since the
unbalanced
inequalities of
(
5
)
actually contain the
balanced
inequalities of
(
2
)
as a special case, the unbalanced kind are more general so we start with those.

III.1.1
Proof of the Generally Unbalanced CS Inequality

Given any set of
M

n
-dimensional complex vectors
\{{\mathbf{a}_{1}},\ldots,{\mathbf{a}_{M}}\}
, where
{\mathbf{a}_{k}}\equiv({a_{k,1}},\ldots,{a_{k,n}})
for
k\in 1,\ldots,M
, and the
Hermitian inner product

\mathbf{u}\cdot\mathbf{v}\equiv{\mathbf{u}^{\dagger}}\mathbf{v}
with Hermitian conjugate
{\mathbf{u}^{\dagger}}\equiv{\mathbf{u}^{*T}}={\mathbf{u}^{T*}}
, it is already well-known that the two-vector CS inequality is

|{\mathbf{a}_{1}}||{\mathbf{a}_{2}}|\geqslant|{\mathbf{a}_{1}}\cdot{\mathbf{a}_{2}}|,

(36)

which trivially holds if either vector is the zero vector
\mathbf{0}
as well (we write the product of magnitudes on the left to prepare for the quantum results which are typically written with uncertainty products on the left).

Next, noting that since the overlap magnitude on the right in
(
36
)
involves up to
two
distinct vectors, then there are
\binom{M}{2}\equiv

\frac{{M!}}{{2!(M-2)!}}
distinct overlap magnitudes. However, since we can pick any subset of those pairs, suppose we make a product of distinct overlap magnitudes between
K\in 1,\ldots,\binom{M}{2}
pairs of vectors as

\Omega\equiv\prod\limits_{q=1}^{K}{|{\mathbf{a}_{{j_{q}}}}\cdot{\mathbf{a}_{{k_{q}}}}|},

(37)

where
\{{\mathbf{a}_{{j_{q}}}},{\mathbf{a}_{{k_{q}}}}\}\equiv{P_{q}}
is the
q
th pair of vectors in the chosen set (where curly braces denote a
set
here, not the anticommutator) with vector labels
\{{j_{q}},{k_{q}}\}\equiv L_{q}
.

For example, for
M=4
vectors
\{{\mathbf{a}_{1}},{\mathbf{a}_{2}},{\mathbf{a}_{3}},{\mathbf{a}_{4}}\}
, there are
\binom{4}{2}=6
distinct pairs of vectors
\{\{{{\bf{a}}_{1}},{{\bf{a}}_{2}}\},

\{{{\bf{a}}_{1}},{{\bf{a}}_{3}}\},\{{{\bf{a}}_{1}},{{\bf{a}}_{4}}\},\{{{\bf{a}}_{2}},{{\bf{a}}_{3}}\},\{{{\bf{a}}_{2}},{{\bf{a}}_{4}}\},\{{{\bf{a}}_{3}},{{\bf{a}}_{4}}\}\}
, and if we choose a particular set of
K
of these as
\{{P_{1}},{P_{2}},{P_{3}}\}\equiv\{\{{{\bf{a}}_{1}},{{\bf{a}}_{3}}\},\{{{\bf{a}}_{2}},{{\bf{a}}_{3}}\},\{{{\bf{a}}_{2}},{{\bf{a}}_{4}}\}\}
(letting
q
label the
new
set’s elements), so the chosen label pairs are
\{{L_{1}},{L_{2}},{L_{3}}\}\equiv\{\{{j_{1}},{k_{1}}\},\{{j_{2}},{k_{2}}\},\{{j_{3}},{k_{3}}\}\}\!\equiv\!\{\{1,3\},\{2,3\},\{2,4\}\}
, then
(
37
)
would be
\Omega\equiv|{{\bf{a}}_{1}}\cdot{{\bf{a}}_{3}}||{{\bf{a}}_{2}}\cdot{{\bf{a}}_{3}}||{{\bf{a}}_{2}}\cdot{{\bf{a}}_{4}}|
for this subset.

Next, since
(
36
)
also holds in
(
37
)
as

|{{\bf{a}}_{{j_{q}}}}||{{\bf{a}}_{{k_{q}}}}|\geqslant|{{\bf{a}}_{{j_{q}}}}\cdot{{\bf{a}}_{{k_{q}}}}|;\quad\forall{j_{q}},{k_{q}}\in 1,\ldots,M;\,\,\,q\in 1,\ldots,K,

(38)

then putting
(
38
)
into
(
37
)
yields an inequality with
K
products of magnitudes on the left as

\prod\limits_{q=1}^{K}{|{{\bf{a}}_{{j_{q}}}}||{{\bf{a}}_{{k_{q}}}}|}\geqslant\prod\limits_{q=1}^{K}{|{{\bf{a}}_{{j_{q}}}}\cdot{{\bf{a}}_{{k_{q}}}}|},

(39)

which proves
(
5
)
, while
(
6
)
shows examples of all nontrivial sets of pairs that can be used. Notice that the product on the left in
(
39
)
can have repeated vector magnitudes from the same vector because multiple different overlap magnitudes on the right could contain the same vector. In all cases, the powers of each vector magnitude on the left will equal the number of overlap magnitudes that involve that vector on the right, but since not all the powers of all the factors on the left are generally the same, it does not make as much sense to take any radicals except in the special cases where they are all the same.

III.1.2
Proof of the Balanced CS Inequality

In the case of the generally unbalanced inequality of
Sec.
III.1.1
, if we choose the maximum number of distinct overlap magnitudes of
M
vectors which is
K=\binom{M}{2}
, then
(
39
)
becomes

\prod\limits_{q=1}^{\binom{M}{2}}{|{{\bf{a}}_{{j_{q}}}}||{{\bf{a}}_{{k_{q}}}}|}\geqslant\prod\limits_{j=1}^{M-1}{\prod\limits_{k=j+1}^{M}{|{{\bf{a}}_{j}}\cdot{{\bf{a}}_{k}}|}},

(40)

where we cannot just use the same nested product on the left as on the right because the magnitude product would factor and give the wrong number of contributions; this is because on the right, the dot product is generally a nonfactorizable binary product so
k
cannot increment without requiring a repeat of the input in the first argument for
j
, and so the same thing must happen on the left of
(
40
)
but a nested product would not achieve that. However, we can determine the result for the left by looking at the enumerations in the general case as

\begin{array}[]{*{20}{l}}{\prod\limits_{q=1}^{\binom{M}{2}}{|{{\bf{a}}_{{j_{q}}}}||{{\bf{a}}_{{k_{q}}}}|}}&\!\!=&\!\!{{{\left[{\left({|{{\bf{a}}_{1}}||{{\bf{a}}_{2}}|}\right)\cdots\left({|{{\bf{a}}_{1}}||{{\bf{a}}_{M}}|}\right)}\right]}_{1}}}\\[-8.0pt]
&&\!\!{\times{{\left[{\left({|{{\bf{a}}_{2}}||{{\bf{a}}_{3}}|}\right)\cdots\left({|{{\bf{a}}_{2}}||{{\bf{a}}_{M}}|}\right)}\right]}_{2}}\cdots{{\left[{\left({|{{\bf{a}}_{M-1}}||{{\bf{a}}_{M}}|}\right)}\right]}_{M-1}}}\\[1.0pt]
&\!\!=&\!\!{\!{{\left[{\,\underline{|{{\bf{a}}_{1}}{|^{M-1}}}\left({\underline{\underline{|{{\bf{a}}_{2}}|}}\cdots\underline{\underline{\underline{|{{\bf{a}}_{M}}|}}}\,}\right)}\right]}_{1}}}\\[8.0pt]
&&\!\!{{\times\!{\left[{\,\underline{\underline{|{{\bf{a}}_{2}}{|^{M-2}}}}\left({|{{\bf{a}}_{3}}|\cdots\underline{\underline{\underline{|{{\bf{a}}_{M}}|}}}\,}\right)}\right]}_{2}}\!\!\!\cdots{{\left[{\left({|{{\bf{a}}_{M-1}}|\underline{\underline{\underline{|{{\bf{a}}_{M}}|}}}\,}\right)}\right]}_{M-1}}}\\[8.0pt]
&\!\!=&\!\!{\underline{|{{\bf{a}}_{1}}{|^{(M-1)+0}}}\,\,\underline{\underline{|{{\bf{a}}_{2}}{|^{(M-2)+1}}}}\cdots\underline{\underline{\underline{|{{\bf{a}}_{M}}{|^{(M-M)+M-1}}}}}}\\[8.0pt]
&\!\!=&\!\!{|{{\bf{a}}_{1}}{|^{M-1}}|{{\bf{a}}_{2}}{|^{M-1}}\cdots|{{\bf{a}}_{M}}{|^{M-1}}=(|\mathbf{a}_{1}||\mathbf{a}_{2}|\cdots|\mathbf{a}_{M}|)^{M-1}}\\[2.0pt]
&\!\!=&\!\!{{{\left({\,\smash{\prod\limits_{j=1}^{M}{|{{\bf{a}}_{j}}|}}\rule{0.0pt}{15.0pt}}\right)}^{\!\!M-1}},}\end{array}

(41)

where subscripts on square brackets count groups of magnitude pairs that share the same index in the left factor. The pattern can be seen by looking at the second equality of
(
41
)
and counting all occurrences of each magnitude, indicated by underline types. The exponent grouping in the third equality shows in the parenthetical exponent on the left the number of common factors appearing on the left in a given square bracket term, while the nonparenthetical exponent on the right shows shows the number of that same factor that are distributed among the other square-bracket factors. Thus, putting
(
41
)
into
(
40
)
gives

{\left({\,\smash{\prod\limits_{j=1}^{M}{|{{\bf{a}}_{j}}|}}\rule{0.0pt}{17.0pt}}\right)^{M-1}}\geqslant\prod\limits_{j=1}^{\!M-1}{\prod\limits_{k=j+1}^{M}{|{{\bf{a}}_{j}}\cdot{{\bf{a}}_{k}}|}},

(42)

and then the
(M-1)
th root of both sides of
(
42
)
yields

\prod\limits_{j=1}^{M}{|{{\bf{a}}_{j}}|}\geqslant{\left({\prod\limits_{j=1}^{M-1}{\prod\limits_{k=j+1}^{M}{|{{\bf{a}}_{j}}\cdot{{\bf{a}}_{k}}|}}}\right)^{\frac{1}{{M-1}}}},

(43)

which proves
(
2
)
, examples of which can be seen in
(
3
)
and
(
4
)
, valid for
M\geqslant 2
.

)

which proves

)

(

)

(

)
in

\begin{array}[]{*{20}{c}}{\prod\limits_{q=1}^{K}{|{{\bf{a}}_{{j_{q}}}}||{{\bf{a}}_{{k_{q}}}}|}}&\!\!\geqslant&\!\!{\prod\limits_{q=1}^{K}{|{{\bf{a}}_{{j_{q}}}}\cdot{{\bf{a}}_{{k_{q}}}}|}}\\

III.3.1
Proof of Multi-Operator Quantum Uncertainty Relations for NonHermitian Operators and Unnormalized States

First, we define not-necessarily-normalized states

|{\psi_{k}}\rangle\equiv({A_{k}}-\langle{A_{k}}\rangle)|\psi\rangle,

(49)

where
\langle{A_{k}}\rangle\equiv\langle\psi|{A_{k}}|\psi\rangle
which can be generalized for mixed states
\rho
as
\langle{A_{k}}\rangle\equiv{\rm tr}(\rho{A_{k}})
, and operator
A_{k}
is not necessarily Hermitian. Then, overlaps of
\{|{\psi_{k}}\rangle\}
are

\begin{array}[]{*{20}{l}}{\langle{\psi_{j}}|{\psi_{k}}\rangle}&\!\!{=\langle\psi|(A_{j}^{\dagger}-{{\langle{A_{j}}\rangle}^{*}})({A_{k}}-\langle{A_{k}}\rangle)|\psi\rangle}\\[1.0pt]
&\!\!{=\langle\psi|(A_{j}^{\dagger}{A_{k}}-{{\langle{A_{j}}\rangle}^{*}}{A_{k}}-{A_{j}}^{\dagger}\langle{A_{k}}\rangle+{{\langle{A_{j}}\rangle}^{*}}\langle{A_{k}}\rangle)|\psi\rangle}\\[1.0pt]
&\!\!{=\langle A_{j}^{\dagger}{A_{k}}\rangle\!-\!{{\langle{A_{j}}\rangle}^{*}}\langle{A_{k}}\rangle\!-\!\langle A_{j}^{\dagger}\rangle\langle{A_{k}}\rangle\!+\!{{\langle{A_{j}}\rangle}^{*}}\langle{A_{k}}\rangle\langle\psi|\psi\rangle.}\end{array}

(50)

Then, using the fact that
{\langle{A}\rangle^{*}}=\langle A^{\dagger}\rangle
,
(
50
)
becomes
