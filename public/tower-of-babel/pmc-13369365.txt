Class-incremental few-shot underwater object detection framework
Authors: Xue Zhao, Bin Zhou, Yanjiang Wang
Published: 2026

ABSTRACT
Underwater object detection is vital for marine exploration and ecological monitoring. However, due to the low-quality original characteristics of underwater images, the diversity changes of underwater species, and the scarcity of samples, existing underwater object detection technologies struggle to address these challenges simultaneously. To this end, this paper proposes a class-incremental few-shot underwater object detection framework(CIFS-UD). First, we design an end-to-end multi-task architecture by integrating the existing underwater image enhancement module based on the deep inception and channel-wise attention (DICAM) and object detection, enhancing underwater visual quality and enabling more discriminative feature representations. Second, we develop a prototype-based multi-scale dual attention module (ProMSDA) that strengthens cross-scale feature correlations and key object regions to optimize class prototype representations. Finally, we propose a dynamic boundary-aware prototype collaboration optimization strategy (DB-PCO) that jointly constrains intra-class compactness and inter-class separability to alleviate catastrophic forgetting. Experiments on Brackish, Trashcan, and RUOD datasets verify that CIFS-UD can effectively adapt to novel classes and improve the class-incremental few-shot underwater object detection performance.The code and implementation are publicly available at https://github.com/snow102/Class-Incremental-Few-Shot-Underwater-Object-Detection-Framework.

Introduction

With the increasing demand for marine resource exploration, ecological environment monitoring, and underwater security, underwater object detection has become a key technology for underwater environment perception, the performance of which directly determines the accuracy of object recognition, condition assessment, and decision-making response in practical applications1. Compared with general object detection, underwater object detection faces the following three difficulties: (1)Degradation of the underwater image quality. The scattering effect of water on light leads to blurred edges and loss of details in images, while selective absorption causes color distortion. In addition, suspended particles exacerbate image noise, reducing the grayscale contrast between the object and the background2,3. (2) Scarcity of annotated samples. Underwater data collection relies on specialized equipment (such as underwater robots and high-pressure-resistant cameras) and domain-specific annotators4, resulting in high costs, long cycles, and limited sample coverage. (3) Difficulty in dynamic class expansion. The emergence of novel objects in practical scenarios requires detection models to continuously learn novel object classes without retraining from scratch, whereas traditional fixed-class object detection models cannot adapt to the need for dynamic class expansion5. Therefore, in complex underwater environments, how to effectively learn novel classes with a limited number of labeled samples while maintaining the detection performance of learned classes has become a critical issue that urgently needs to be addressed.

In response to the scarcity of annotated underwater samples, the existing few-shot underwater object detection method6 employed transfer learning and the feature rectification strategy to compensate for degraded features by transferring knowledge from the source domain, thereby mitigating the performance degradation caused by cross-domain feature distribution differences. However, this method pays insufficient attention to feature representations of few-shot categories. Currently, general few-shot object detection methods7 mainly include two categories: meta-learning-based and transfer-learning-based. Prototype-learning-based few-shot object detection methods8–10 represent an important branch of meta-learning11,12. These methods extract key features from the support set data and aggregate them to form class prototypes. By calculating the feature distance between the query data and existing class prototypes, the category of the query data is determined, and localization is completed. Such methods enhance the stability of the query data detection by aggregating features from the support set data into stable prototypes, which helps reduce interference from underwater noise and blur in feature discrimination. However, when there is a large cross-domain distribution gap, their discriminative capability tends to be limited. Recent research13 has combined prototype learning with transfer learning for few-shot object detection, effectively enhancing the model’s focus on class-discriminative features.

Underwater object detection faces the challenge of dynamically expanding categories. Some studies have applied knowledge distillation strategies to underwater incremental classification tasks5, but the performance is limited for newly added categories with scarce samples. In real-world underwater scenarios, the introduction of novel classes is typically accompanied by very few labeled samples, which exacerbates the conflict between few-shot learning and class-incremental learning: the former relies on a limited number of labeled samples for generalization, while the latter requires continuous data input to update the model. The two approaches conflict in terms of data dependency and learning mechanisms, making it difficult for them to work in tandem. Consequently, models struggle to simultaneously maintain learning capabilities for novel classes and preserve performance on existing classes in practical applications, severely limiting their effectiveness in dynamic underwater scenarios. Class incremental learning models typically rely on a sufficient number of novel class samples, and few-shot learning lacks the ability to continuously expand. Therefore, a single technical approach (either class incremental learning or few-shot learning alone) is difficult to meet the needs of practical applications. Class-incremental few-shot object detection achieves synergistic integration of few-shot learning and class-incremental learning within the context of object detection. By leveraging a small number of annotated samples from novel classes, it enables the detection and localization of novel classes while maintaining identification ability on previously learned classes, without relying on the full set of base class data14. Compared to general scenarios, class incremental few-shot underwater object detection tasks are often affected by multiple factors, such as underwater imaging degradation, multi-scale transformation, and imbalance in incremental data distribution. Currently, general class-incremental few-shot object detection methods primarily combine prototype learning with memory replay. Specifically, key features of base class samples are extracted and aggregated into class prototypes to retain knowledge of base classes, while a limited number of base class samples are stored for class-incremental training to mitigate forgetting caused by prototype drift. For example, InfRS15 integrates transfer learning, prototype learning, and memory replay, which first extracts object features from the base class dataset and aggregates them along the channel dimension to construct class prototypes. Then, during incremental learning of novel classes, a small number of representative base class samples are stored and mixed with novel class samples for joint training. At the same time, the method optimizes the discriminability between novel class features and base class prototypes through a prototype distance constraint.

Applying the aforementioned general few-shot object detection methods and class-incremental few-shot object detection methods to real-world underwater scenarios still has the following limitations: (1) It cannot adapt to the feature requirements of low-quality underwater images; (2) Single-scale prototypes are insufficient to cover multi-scale underwater objects; (3) During the class-incremental phase, it is challenging to adaptively balance the feature updates between novel classes and base classes.

To address these limitations, this paper proposes a novel class-incremental few-shot detection framework designed across three dimensions: feature enhancement, prototype modeling, and incremental optimization. First, an end-to-end integrated multi-task architecture is constructed, embedding the image enhancement module as a pre-enhancement unit into the object detection network. A collaborative optimization mechanism is designed to achieve synergistic optimization, using the object region localization loss of the detection task to guide the parameter updates of the enhancement module. Then the enhancement module improves the clarity of underwater images by integrating multi-scale feature extraction with the channel attention mechanism and enhances the discrimination of details–such as edges and textures–in key regions, as well as color authenticity, thereby providing highly discriminative feature inputs to the object detection module. Secondly, in the prototype feature extraction stage, we design a multi-scale dual-attention prototype learning module (ProMSDA). Specifically, by strengthening cross-scale feature correlations and focusing on key object regions, this module optimizes the representational ability of class prototype features, improving the discriminative ability of multi-scale features, and enhancing the model’s detection performance for underwater objects of varying scales. Finally, in the class-incremental learning stage, we propose a dynamic boundary-aware prototype collaborative optimization strategy(DB-PCO). This strategy achieves joint modeling of feature discriminability and class boundary constraints through the synergistic optimization of feature contrast loss and boundary adjustment loss. The boundary modeling branch designs an adaptive boundary perturbation mechanism based on prediction confidence, applying varying degrees of suppression to high-confidence predictions for non-target classes. This allows boundary constraints to adapt dynamically based on prediction confidence, thereby adjusting class intervals during the optimization process; Concurrently, the prototype contrast branch enhances intra-class compactness and mitigates inter-class confusion. These two types of losses work in concert under fixed weights, driven by data distribution and model prediction confidence, to form an implicit adaptive optimization path. This effectively enhances the overall discriminative capability between the base classes and novel classes while mitigating catastrophic forgetting. Compared with existing general class incremental few-shot object detection methods, this paper systematically designs a unified solution for complex underwater scenarios by focusing on three aspects: enhancement-detection collaborative modeling, multi-scale prototype representation, and class incremental stage dynamic optimization.

Related work

Underwater image enhancement

Underwater images are often affected by factors such as light scattering in water, selective absorption, and interference from suspended particles. As a result, raw underwater images commonly suffer from issues such as non-uniform color shifts, loss of object edges and textures, and redundant background noise16. Therefore, to improve the imaging quality of underwater images for practical applications, researchers have proposed various image enhancement methods, such as non-physical model-based methods, physical model-based methods, and deep learning-based methods.

Non-physical model-based methods rely on traditional image processing theories and enhance images by directly adjusting the spatial distribution of pixels. The core idea is to optimize visual perception without explicitly modeling the degradation process. Key techniques include histogram equalization, Retinex theory, and contrast stretching, among other conventional image processing approaches17,18. These methods offer advantages such as low computational complexity and strong real-time performance. However, due to the lack of targeted modeling of the underwater degradation mechanism and reliance solely on pixel statistical characteristics for adjustment, they are prone to issues such as local overexposure and artifact generation. Therefore, the enhancement effects tend to be subjective and scene-dependent.

Physical model-based methods seek to enhance images by establishing mathematical models that quantify the attenuation and scattering effects of water on light, and then obtain clear images by the inversion of raw images based on prior assumptions19,20. Key techniques include classical models such as the dark channel prior, underwater light transmission models, and semi-blind deconvolution models. Compared to non-physical model-based methods, those based on physical models yield enhancement results that are more physically plausible and can effectively address issues like underwater color shifts. However, the solution process often involves complex iterative optimization, leading to high computational costs. Moreover, these methods heavily rely on prior knowledge of water parameters (such as attenuation and scattering coefficients). Since these parameters dynamically change in real underwater environments, the generalization ability of such models is often limited.

Deep learning-based underwater image enhancement methods are capable of adaptive degradation modeling and multi-scale feature extraction, therefore demonstrating stronger robustness against non-uniform underwater degradation. Current approaches primarily focus on the integration of attention mechanisms and multi-modal feature fusion. For example, the UIEC\documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$^2$$\end{document}-Net method21 proposes a dual-color-space feature fusion strategy using RGB and HSV spaces. The RGB space preserves structural information of objects, while the HSV space retains color saturation and brightness information. By leveraging cross-space features, it generates a more accurate enhancement model. Another example is WaveNet22, which introduces a convolutional attention module to enhance the red channel and suppress redundant blue-green channels. It also employs spatial attention to focus on object regions and combines multi-stage feature fusion to achieve collaboration optimization of noise suppression, detail enhancement, and color correction in underwater images. However, the aforementioned methods still have limitations in addressing the proportional degradation in underwater images. In other fields, drawing on the ideas of multi-scale attention and feature fusion can solve the problem of image degradation. For example, PISENEt23 achieves cross-layer fusion of multi-scale features and global semantic modeling through a progressive interaction encoder and global context enhancement module. This article cites the DICAM method2, which integrates multi-scale feature extraction with the channel attention mechanism to address non-uniform color shifts and proportional degradation in underwater images. Therefore, the enhanced images preserve key object features more effectively.

Underwater object detection

Underwater object detection methods primarily focus on adapting general detection frameworks to complex underwater environments while balancing detection accuracy and real-time performance. In recent years, the main approaches for underwater object detection include R-CNN-based methods and YOLO-based methods24. R-CNN-based methods25,26 employ a two-stage detection process suitable for large and irregularly shaped objects, and achieve high detection accuracy. However, they suffer from high computational costs and limited real-time performance. YOLO-based methods27,28 achieve high real-time performance through single-stage end-to-end detection. But, due to the degradation of underwater images, they often exhibit higher miss rates for small-scale objects.

Apart from improving detection methods themselves, few-shot learning has also been introduced to address the issue of class scarcity. Researchers have attempted to combine domain adaptation with few-shot learning to enhance model generalization under limited samples6. However, this approach still suffers from insufficient adaptability when facing scenarios with dynamically expanding categories.

Underwater class-incremental learning can alleviate the pressure of category expansion. The previous study has combined deep convolutional neural networks (CNN) with a knowledge distillation strategy for the underwater incremental classification task5. This approach first focuses on learning challenging species and then incrementally learns novel species while training the CNN with distillation loss, thereby maintaining the classification performance of previously learned categories. However, this method is not suitable for few-shot object detection.

Although recent computational architectural improvements have increased detection performance, underwater image degradation remains a core challenge, and the integration of image enhancement and object detection has become a key research direction29,30. For example, the LUIEO method31 combines physical priors to enable joint training of both tasks, but it relies heavily on water parameters and exhibits weak generalization. The UICE-MIRNet32 optimizes small object detection in low-light scenarios but fails to adapt to multiple types of degradation. The EnYOLO33 emphasizes real-time performance with a lightweight enhancement design, yet its effectiveness is limited for severely degraded images. The UnitModule34 offers a plug-and-play design compatible with various detection models, but its self-supervised signals lack reliability in few-shot scenarios. These methods generally suffer from insufficient collaborative depth, poor scene adaptability, and weak compatibility with few-shot learning.

The above-mentioned underwater object detection methods perform poorly in dynamic scenarios where samples of novel species are limited.

Class-incremental few-shot object detection

Few-shot object detection aims to achieve detection using only a very limited number of annotated samples, thereby reducing the reliance of traditional deep models on large-scale annotated data35. Research on few-shot object detection in natural scenes has developed well, which can be broadly categorized into meta-learning-based and transfer-learning-based approaches. Meta-learning-based methods enable models to quickly adapt to novel tasks by simulating few-shot scenarios where the distribution of “training-test” tasks remains consistent. For example, Meta R-CNN36 introduces meta-learning into a region-based detection framework, training object detectors through a scenario-learning paradigm to acquire prior knowledge and achieve rapid adaptation to few-shot classes, but it is limited by low-quality proposals and the neglect of inter-class relationships, resulting in missed and misdetected objects. Meta-DETR37 removes the reliance on region proposals, performing image-level detection and leveraging inter-class correlation for meta-learning; IPNe38 proposes an instance-level prototype learning network that simultaneously addresses domain adaptation in few-shot scenarios, improving cross-scene feature compatibility. FPD39 introduces an additional support branch that encodes novel class samples into prototypes and fuses them with the query branch to optimize class feature representations. Transfer learning-based methods, on the other hand, first pre-train models on source data and then fine-tune them with a small number of object data to achieve rapid generalization to object tasks. For instance, WFS-DETR40 learns object integrity and localization capability using image-level labels, followed by simple fine-tuning to transfer source knowledge to object classes, ensuring detection accuracy. Additionally, some research13 combines transfer learning with prototype learning, using prototype learning to enhance feature extraction and discriminative ability for scarce samples, thus addressing the insufficiency of feature learning under extremely limited samples in transfer learning, achieving efficient learning from limited labeled data and significantly improving intrusion detection performance. In addition to few-shot object detection methods based on meta-learning and transfer learning, non-parametric learning methods based on prototype representations have also been extensively studied in the field of visual recognition. For example, DNC41 proposes a representation method based on category centroids in the deep feature space, which classifies objects by calculating the distance between test samples and the prototypes of each category. This method is characterized by its simple structure, high interpretability, and good robustness. Such methods provide an important theoretical foundation for prototype learning. However, the above few-shot object detection methods designed for natural scenes inadequately account for the multi-scale characteristics of underwater objects, and they both suffer from insufficient discriminative capability for multi-scale objects. To address this issue, both multi-scale feature fusion and cross-branch feature fusion are considered effective approaches. Multi-scale feature fusion42–44 integrates features from different levels to balance high-level semantic information with low-level details, while cross-branch feature fusion4546 enhances the model’s ability to perceive targets and scale-varying targets by aligning and integrating representations from different feature branches.

However, simply improving the model’s ability to represent features in scenarios involving small datasets and multiple scales is still insufficient to meet the demands of practical applications. In real-world scenarios, object detection tasks often face the challenge of dynamically changing classes, which traditional few-shot detection methods struggle to handle. Class-incremental object detection refers to the ability to incrementally learn novel classes without retraining on the complete set of original data, while maintaining detection performance for previously learned classes47. Unlike traditional fixed-class detection models, class-incremental object detection models better satisfy the need for dynamic class expansion in practical applications. Existing class-incremental object detection techniques, aimed at mitigating catastrophic forgetting, can be broadly categorized into three types according to the strategies behind them. (1)Parameter Isolation Strategies. These strategies identify and fix model parameters critical to base class tasks, updating only parameters relevant to novel classes to prevent overwriting the knowledge of the base classes48. Therefore, this technology has high computational efficiency and eliminates the need to store the raw data of the base classes. However, it relies heavily on accurate quantification of parameter importance, and incorrect identification of key parameters can easily lead to forgetting of base classes or insufficient learning of novel classes. (2)Knowledge Distillation Strategies. By constructing a dual-model architecture of teacher-student, these strategies use a pre-trained teacher model to supervise the training of the student model, thereby transferring knowledge of base classes to the student model49,50. This technology enables the direct transfer of knowledge from the base classes to the novel model. However, over-reliance on the teacher model may result in limited generalization ability of the student model. (3)Memory Replay Strategies. These strategies store a small number of base class samples and train them together with novel class samples during incremental learning to mitigate forgetting caused by data distribution shift51,52. This technology provides stable retention of base class knowledge but requires the storage of base class samples. However, improper sample selection may lead to feature drift in base classes.

In practical scenarios, the novel object classes have extremely limited annotated samples, making it difficult for a single technical approach to meet the demand of accurate identification. Class-incremental few-shot object detection represents the integration of few-shot learning and class-incremental learning within the context of object detection tasks. It aims to enable models to continuously learn novel classes from limited samples while retaining the ability to locate and classify objects from previously learned classes, thereby achieving accurate location of corresponding objects in images53–57.

Existing class-incremental few-shot object detection methods primarily focus on mitigating catastrophic forgetting and improving the efficiency of learning novel classes. For example, ONCE55 introduces a class-specific parameterized object locator via meta-learning to enable rapid recognition of novel classes. However, its meta-learning strategy does not account for localization deviations caused by blurred edges in underwater images, which can lead to localization drift for objects of base classes. Sylph56 proposes an architecture that decouples classification and localization tasks to reduce interference between tasks during incremental learning. Nevertheless, this decoupled design disrupts feature relevance, and in underwater multi-scale object scenarios, it often results in “correct classification but mislocalization of novel class objects.” SHRDet-N57 generates class-enhanced features through a cross-attention mechanism and combines elastic weight consolidation with feature distance constraints to alleviate forgetting. However, its cross-attention module is sensitive to noise from suspended particles in underwater environments, potentially encoding noise features as valid information and reducing the discriminability between base and novel class features. Recent studies have further integrated transformers and meta-learning mechanisms into this task. Meta-Incremental DETR58 proposes an end-to-end meta-learning incremental detection framework that achieves rapid task-level adaptation and cross-task knowledge transfer by collaboratively designing task learners and meta-learners, thereby enhancing the model’s ability to retain knowledge of baseline classes and generalize to new classes. However, this method primarily relies on global attention modeling and still falls short in capturing fine-grained local features in scenes with a high density of small objects. IF-DETR59 proposes an incremental few-shot detection Transformer framework tailored for industrial defect scenarios. Employing an instance-aware distillation loss at the feature level and a hierarchical alignment loss at the logit level, it mitigates knowledge conflicts between novel and existing classes, achieving superior performance under few-shot conditions. However, its optimization objectives rely heavily on regular textures and structured backgrounds, limiting its adaptability to complex natural scenes, particularly for low-contrast targets in underwater environments. Furthermore, HDCPAA60 proposes a class-incremental learning framework for remote sensing images. It expands the inter-class margin by constructing a quasi-orthogonal prototype space and dynamically updates class prototypes using a prototype adaptive attention module, thereby enhancing incremental recognition performance. However, this method is primarily designed for image classification tasks and lacks the ability to model object localization and multi-instance detection problems, making it difficult to directly transfer to class-incremental few-shot object detection tasks. InfRS15 combines transfer learning with channel-level prototype-based contrastive encoding. By utilizing prototype distance constraints during the incremental learning process to optimize the distinction between the base class and the novel class, it effectively mitigates the forgetting phenomenon. However, the prototype comparison strategy adopted by this method cannot adapt to the dynamic demands of incremental learning in underwater scenarios. Consequently, during the initial stages of learning new categories, stronger boundary separation is required to avoid confusion with the base category, whereas in later stages, consolidating knowledge of the base category is crucial for preventing forgetting. This strategy cannot dynamically adjust category boundaries based on the feature differences between the base category and the new category.

Method overview

Fig. 1CIFS-UD framework.

CIFS-UD framework.

Figure 1 illustrates the architecture of the proposed class-incremental few-shot underwater object detection framework (CIFS-UD), which incorporates both a pre-training phase and a class-incremental few-shot fine-tuning phase. Among them, we use solid lines to represent the forward data stream and mark the backward gradient propagation path of the detection loss to the enhancement module with red dashed arrows. Building upon the class-incremental few-shot object detection method for remote sensing images (InfRS)15 and underwater image processing techniques (deep inception and channel-wise attention modules for underwater image enhancement, DICAM)2, our framework achieves a good balance between preserving knowledge from existing classes and efficient learning of novel classes through three combined modules: an underwater image enhancement module, an attention prototype learning module, and a dynamic boundary-aware prototype collaboration optimization module.

In the pre-training phase, first, the base class training dataset \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$D_{base}$$\end{document} is input into the underwater image enhancement module based on DICAM. Then, through a multi-scale feature extraction and channel attention mechanism, color bias is corrected, and object details are enhanced, resulting in highly discriminative enhanced images \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$D'_{base}$$\end{document} being output. Subsequently, these enhanced images are input into the object detector module for training, with the combination of a prototype-based multi-scale dual attention module (ProMSDA), which performs cross-scale correlation and key region focusing on the region-of-interest features that are output by the detector for each class, and then generates class prototype representations for the base classes through mean vector aggregation. Therefore, the prototype representations not only retain multi-scale feature information of the base class objects but also effectively suppresses underwater noise interference, providing explicit semantic supervision for the transfer of base class knowledge in the subsequent incremental phase.

In the incremental fine-tuning phase, to avoid forgetting base class knowledge caused by full-parameter updates, the framework first freezes the class-irrelevant parameters of the backbone networks and feature pyramid networks, and then fine-tunes only the classification head, regression head, and prototype-related modules of the detector. Since \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$D'_{base}$$\end{document} is inaccessible at this stage, we utilize prototype knowledge to provide explicit supervision information. As shown in Fig. 1, the dynamic boundary-aware prototype collaboration optimization module (DB-PCO) dynamically balances the association between the novel class feature embeddings and base class prototypes by decoupling feature contrast loss and boundary adjustment loss, which not only improves the efficiency of few-shot learning for novel classes but also significantly reduces catastrophic forgetting, ensuring the model’s comprehensive detection performance for both novel and old classes.

Specifically, the innovation of this article can be understood from three levels: (1) Reusable modules: This article references the incremental few-shot object detection in remote sensing images (InfRS)15 and the deep inception and channel-wise attention module (DICAM)2 to form the basic framework of our method. (2) Modified part: Integrate the underwater image enhancement method DICAM from the original independent image enhancement task into the class incremental few-shot object detection task, and achieve image-level enhancement for detection perception through end-to-end joint training. It should be noted that the DICAM module is initialized using pre-trained weights from the general underwater image enhancement task, and its output enhanced image is used as the input for the detection network (Faster R-CNN). The backbone feature extractor (ResNet FPN) of the detection network is only used for object detection tasks and does not share convolutional layer parameters with DICAM. DICAM itself does not have an independent loss function, but updates it in reverse through the classification and localization losses of the detector, so that the enhancement process is directly driven by the detection object, thereby achieving adaptive image optimization for detection tasks. (3) Truly innovative algorithmic contributions: The main algorithmic innovations of this article are reflected in two key modules: firstly, proposing a prototype guided multi-scale dual attention module (ProMSDA) to enhance the discriminative ability of prototype representation; Secondly, a dynamic boundary aware prototype collaborative optimization strategy (DB-PCO) is proposed to adaptively adjust the decision boundaries between novel and old categories during the incremental phase. These two modules together constitute the core method contribution of this article.

Prototype-based multi-scale dual attention module

Fig. 2prototype-based multi-scale dual attention module.

Dynamic boundary-aware prototype collaboration optimization module

In this subsection, we propose a dynamic boundary-aware prototype collaboration optimization module that realizes strong discrimination of novel and base class features and dynamic adaptation of class boundaries through the collaboration loss optimization between the prototype comparison branch and boundary modeling branch.

First, through a \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$1\times 128$$\end{document} fully connected layer, the ROI features and class prototypes generated during pre-training are mapped into the same latent space, yielding encoded vectors \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$h_i$$\end{document} and the k-th class prototype encoding \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$p_k$$\end{document}. The prototype contrast branch takes the class prototype \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$p_k$$\end{document} as the class center to measure the similarity among encoded vectors and optimize the contrastive objective. It aims to enhance the difference between the novel class samples \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$D'_{novel}$$\end{document} and the base class prototypes, as well as samples from other classes, while maximizing the consistency within the same class. The boundary modeling branch addresses class boundary blurring caused by underwater image degradation by applying boundary perturbation modeling to non-target class original classification scores. Specifically, the encoding vector and the class prototype encoding are first concatenated and then mapped through a normalization layer to obtain the classification score \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$z_{i,k}$$\end{document} of the i-th sample in the k-th class. \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$z_{i,k}$$\end{document} is computed as shown in Equation 6:6\documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\begin{aligned} z_{i,k} = \Vert {\textrm{MLP}(\textrm{concat}(h_i,p_k))}\Vert _2, \end{aligned}$$\end{document}where \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\operatorname {concat}(\cdot )$$\end{document} denotes the feature concatenation operation; \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\operatorname {MLP}(\cdot )$$\end{document} denotes a two-layer multilayer perceptron with nonlinear activation functions; \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\Vert \mathbf {\cdot }\Vert _2$$\end{document} represents the \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\operatorname {L2}$$\end{document} normalization.

Then \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$z_{i,k}$$\end{document} is passed through sigmoid mapping, which generates adaptive boundary intervals and defines the boundary perturbation function \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\Phi \left( z_{i,k}\right)$$\end{document} as shown in Equation 7:7\documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\begin{aligned} \begin{aligned} \Phi \left( z_{i, k}\right) =\sigma \left( \beta \left( \frac{1}{K-1}+z_{i, k}-0.5\right) \right) + \sigma \left( \beta \left( -\frac{1}{K-1}-z_{i, k}-0.5\right) \right) , k \ne y_i \end{aligned} \end{aligned}$$\end{document}where K is the total number of classes, \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\sigma (\cdot )$$\end{document} is the sigmoid function, and \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\beta$$\end{document} is the parameter controlling the steepness of the boundary.

By using a boundary perturbation function, high-confidence predictions of non-target classes can be suppressed63, thereby enhancing inter-class separability. At the same time, the total number of categories K automatically adjusts the boundary strictness to adapt to classification tasks of different scales. Based on this, the boundary-aware classification loss \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$L_{db}$$\end{document} is calculated as shown in Equation 8:8\documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\begin{aligned} L_{db}=-\frac{1}{N} \sum _{i=1}^N\left[ \alpha \cdot z_{i, y_i}-\log \left( \exp \left( \alpha \cdot z_{i, y_i}\right) + \sum _{k \ne y_i} \exp \left( \alpha \cdot \Phi \left( z_{i, k}\right) \right) \right) \right] \end{aligned}$$\end{document}where N is the batch size, i.e., the total number of samples in the current batch; \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\alpha$$\end{document} is the temperature scaling factor; \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$z_{i, y_i}$$\end{document} denotes the original classification scores of the i-th sample. This loss function focuses on the most easily confused sample regions and applies greater optimization force, thereby actively widening the decision boundary and increasing the inter-class margin. This loss function is equivalent to introducing an adjustable “safety margin” between class prototypes. The “dynamic” nature of the mechanism proposed in this paper stems from \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\Phi (z_{i, k})$$\end{document} real-time response to the confidence of sample predictions: when the model’s classification boundaries are still ambiguous (with prediction scores close to 0.5), \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\Phi (z_{i, k})$$\end{document} generates stronger perturbation gradients, forcing the model to actively widen the margins; When the feature distribution stabilizes and the prediction score approaches 0 or 1, the constraints generated by \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\Phi (z_{i, k})$$\end{document} weaken naturally, and the model’s optimization focus shifts to the intra-class compactness emphasized by the feature contrast loss. This adjustment behavior is an implicit adaptive mechanism driven by the sample distribution and prediction confidence, rather than relying on an explicit time-scheduling function. This avoids the need for manually designed scheduling strategies while achieving adaptive optimization of class intervals.

By combining the boundary occupancy classification loss \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$L_{db}$$\end{document} with the loss function \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$L_p$$\end{document}15 in the ancestor comparison branch, the class center aggregation and boundary distinction of the structural distribution are considered, as well as the forgetting of some base classes and the sparsity of novel classes. The prototype dynamic boundary-aware collaboration optimization loss function \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$L_{d b-p c o}$$\end{document} is calculated in Equation 9:9\documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\begin{aligned} L_{d b-p c o}=L_p+\lambda \cdot L_{d b} \end{aligned}$$\end{document}where \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\lambda$$\end{document} is the weight parameter of the boundary-aware classification loss \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$L_{db}$$\end{document}.

Experiments

Datasets

In this paper, experiments are carried out on three underwater object detection datasets: Brackish65, RUOD66, and Trashcan67 to verify the performance of the proposed method.

Specifically, Brackish65 is a dataset of underwater imagery collected in temperate brackish waters, contains 14,518 images with 960\documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\times$$\end{document}540 pixel resolution. And it covers six typical underwater classes: large fish, crabs, jellyfish, shrimp, small fish, and starfish, featuring 25,613 annotated bounding boxes for each class.

RUOD66 is a high-quality image dataset collected from diverse real-world underwater environments, features rich background variations, complex underwater lighting interference, and varied object scale distributions. The dataset contains 14,000 high-resolution images across 10 representative underwater classes: sea cucumbers (holothurian), sea urchins (echinus), scallops (scallop), starfish (starfish), fish (fish), corals (corals), divers (diver), cuttlefish (cuttlefish), sea turtles (turtle), and jellyfish (jellyfish), comprising 74,903 annotated instances in total.

Trashcan67 is a dedicated open dataset for underwater debris detection and instance segmentation, contains 7,212 images with pixel-level instance annotations. Covering 22 classes including common marine debris types (plastic bags, cans, ropes), underwater robots, and various marine species, this dataset is an outstanding dataset of real-world underwater cleanup scenarios.

Implementation details

In this experiment, we use ResNet-101 with FPN as the backbone network. The stochastic gradient descent optimizer is employed, with a momentum parameter of 0.9 and a weight decay rate of 0.0001. We also conduct a warm-up phase consisting of 100 iterations before model training.

On the Brackish dataset, the pre-training phase employs a batch size of 1 for 20 training cycles, followed by fine-tuning until full convergence. The initial learning rate is set to 0.001, which is reduced tenfold during the 10th and 15th pre-training cycles. In the incremental learning phase, the learning rate is maintained at 0.00015 but decreases tenfold after 4,000 iterations.

On the RUOD dataset, the batch size is set to 1 during the pre-training phase with 24 training cycles. The initial learning rate is 0.002, which is reduced tenfold at the 12th and 18th cycles. In the incremental learning phase, the learning rate is maintained at 0.0001 but decreases after 6,000 iterations.

On the TrashCan dataset, we set the batch size to 1 and implement 18 pre-training cycles followed by fine-tuning until convergence. The initial learning rate is 0.001, with decay applied at the 9th and 14th cycles. As this dataset contains pixel-level instance segmentation labels, we retain boundary box information during detection and standardize it into the object detection task format.

In the hyperparameter configuration, \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\beta$$\end{document} in Equation 7 is set to 10; \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\alpha$$\end{document} in Equation 8 is set to 10; \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\lambda$$\end{document} in Equation 9 is set to 0.05; while balance coefficient \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\lambda _1$$\end{document} and \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\lambda _2$$\end{document} in Equation 10 are both set to 0.1. All model training and testing are conducted on NVIDIA vGPU computing nodes equipped with 48GB video memory (processor is Intel Xeon Platinum 8481 C, featuring 25 virtual CPUs).

These results validate the effectiveness of our incremental learning framework in balancing “knowledge retention of base class” and “knowledge acquisition of novel classes”.

Conclusion and future work

The accurate and robust underwater object detection technique faces challenges such as image degradation, scarce sample annotations, and dynamic class expansion. To address these challenges, this paper proposes a class-incremental few-shot underwater object detection framework. First, to overcome feature discriminability deficiencies caused by underwater image quality degradation, CIFS-UD constructs an end-to-end integrated multi-task framework that integrates underwater image enhancement with object detection while sharing a feature extractor. By back-propagating detection task localization losses to guide parameter updates in the image enhancement module, the enhanced images can retain object edges, texture details, and chromatic authenticity, and therefore, the image enhancement module can provide high-visibility input for detection. Second, to improve the adaptability of prototype representations for underwater multi-scale objects, we propose a dual attention prototype learning module that enhances cross-scale feature correlation and focuses on key object regions, significantly boosting feature discriminability and robustness under few-shot learning. Finally, to resolve the imbalance between novel class learning and existing class memory in fixed-loss weighting during class-incremental learning, we design a dynamically boundary-aware prototype collaboration optimization strategy that decouples feature comparison and boundary adjustment losses while dynamically adjusting weights. Experimental validation on the Brackish, RUOD, and Trashcan datasets demonstrates the effectiveness of our proposed framework.

However, there are still some limitations to the current method: firstly, there is still room for improvement in the adaptability and discriminative ability of the model for novel categories at extremely low sample increments (such as 1-shot), and the current dataset is relatively controlled and cannot fully cover scenarios under extreme degradation conditions. Future work will further explore the robustness of the method under extremely low visibility, motion blur, highly similar visual features, or high turbidity water conditions to enhance the model’s generalization ability. Secondly, this study mainly uses single-modal image data, which limits the information utilization efficiency of the model in complex underwater scenes. Future research could be extended to video-level underwater object detection or motion-based dynamic object detection tasks, introducing online spatiotemporal modeling mechanisms to enhance the model’s adaptability to dynamic and non-stationary environments70. At the same time, multi-branch feature fusion strategies could be designed by drawing on the idea of multi-kernel learning to model complex degradation characteristics from different feature subspaces71, thereby improving detection performance and robustness. Thirdly, this article adopts a random sampling strategy, mainly based on its advantages of simple implementation and good stability. We believe that in the future, we can further explore the optimal sample selection strategy or the strategy of prioritizing difficult cases. Finally, although our current work strikes a good balance between performance and stability, we can still explore lightweight designs in the future to balance efficient inference with detection performance, thereby providing more practical solutions for resource-constrained scenarios.
