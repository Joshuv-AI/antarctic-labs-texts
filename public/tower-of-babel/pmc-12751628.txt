Machine learning-based discovery of informative SNPs for population assignment through whole genome sequencing
Authors: Hui Liang, Yugang He, Jingfang Si, Xin Su, Xue Wang, Huaming Mao, Yi Zhang
Published: 2025

ABSTRACT
AbstractBackgroundWhole-genome sequencing (WGS) data contain a large proportion of genetic information for farm animals, while machine learning algorithms offer a powerful approach for discovering population-informative genetic markers for population assignment. These methods can enhance population classification, supporting genetic resource conservation and optimizing breeding strategies.MethodsWGS data from 187 individuals representing eight water buffalo breeds (four river type breeds, i.e., Mediterranean, Murrah, Nili Ravi, and Binglangjiang, and four swamp type breeds, i.e., Diandongnan, Dehong, Guizhoubai, and Shanghai) were analyzed. Multiple single nucleotide polymorphism (SNP) selection methods including the population genetic differentiation index (FST), the machine learning-based Minimum Redundancy Maximum Relevance (mRMR) and Relief-F algorithm were investigated to pinpoint the highly informative SNPs for population assignment. Four machine learning classifiers-Support Vector Machine (SVM), K-Nearest Neighbor (KNN), Naive Bayes (NB), and Random Forest (RF)-were applied for population assignment of the eight water buffalo breeds. Nine different SNP set sizes (100, 250, 500, 800, 1000, 2000, 3000, 5000, 10000) were examined. The impact of SNP selection methods, classifiers and SNP set size on assignment accuracy was evaluated.ResultsPopulation genetic analysis revealed hierarchical structures among the eight water buffalo breeds, with two divergent groups (swamp type buffaloes and river type buffaloes) and relatively closely related breeds within each group. Among the classifiers, SVM and NB outperformed RF and KNN in terms of assignment accuracy. Accuracy improved with an increasing number of SNPs, reaching over 85% for all classifiers with 10,000 SNPs. The mRMR method provided the highest accuracy, achieving 97.6% with 2000 SNPs when paired with the SVM classifier, followed by Relief-F (94%) and FST (90.4%). A panel of 768 mRMR-selected SNPs achieved 98.8% assignment accuracy using SVM classifiers, indicating it is a robust tool for reliable population assignment.ConclusionBy integrating machine learning-based feature selection with machine learning classifier, this study provides an effective framework for mining highly informative genetic markers for population assignment from whole-genome sequencing data.Supplementary InformationThe online version contains supplementary material available at 10.1186/s12864-025-12322-1.

Introduction

Population assignment plays a crucial role in managing animal genetic resources, ensuring breed conservation and guiding breeding strategies [1]. Livestock breeds typically exhibit a complex hierarchical genetic structure, often consisting of major groups with further subgroups [2, 3]. Within a subgroup, breeds may show low level of genetic differentiation and share similar morphological traits. For example, domestic water buffaloes are classified into swamp type and river type with a genetic divergence of subspecies level. However, the genetic differentiation between geographically proximate water buffalo breeds is often low and lack distinctive phenotypic characteristics [3], making morphological classification particularly challenging. As a result, genetic markers are essential for accurate breed classification, especially in livestock species with such hierarchical genetic structures.

Common genetic markers like microsatellites [4] and single nucleotide polymorphisms (SNPs) [5–7] have been employed for population assignment. Although microsatellites are highly polymorphic, their use in population assignment was limited due to the labor-intensive and time-consuming process of genotyping multiple loci [8]. On the other hand, SNP arrays offer a more efficient tool for population assignment. However, most commercially available SNP arrays were designed for genomic selection in a small number of dominant breeds [9, 10], which may limit their effectiveness in other breeds. Whole-genome sequencing (WGS) offers a comprehensive approach by capturing the entire genetic makeup of an individual, enabling the identification of breed-informative molecular markers that can effectively address breed assignment challenges [11–14].

In recent years, machine learning has become an increasingly powerful tool for classification tasks. A variety of algorithms, such as Support Vector Machine (SVM), K-Nearest Neighbors (KNN), Naive Bayes (NB), Random Forest (RF), Gradient Boosting Machines (GBM), and Artificial Neural Networks (ANN) have demonstrated significant potential in enhancing both the accuracy and efficiency of population assignment [15, 16]. These studies have shown that when combined with SNP array data, machine learning algorithms can achieve accurate population assignment. However, previous researches focused primarily on well-defined breeds exhibiting substantial genetic differentiation [6, 14, 17–19] and used mostly the genomic data derived from SNP arrays [6, 14, 17–21]. Given the level of genetic differentiation between populations is a crucial factor affecting the classification accuracy [22–24], the performance of machine learning to classify breeds with lower genetic differentiation using whole genome sequencing (WGS) data remains inconclusive and warrants further investigation.

The success of population assignment not only relies on the choice of machine learning classifiers but also on the selection of informative SNPs. The population differentiation index (FST), a widely used metric for assessing genetic divergence between populations [22, 25], was frequently employed in SNP selection [7, 26]. Recent advancements have introduced machine learning-based feature selection methods, such as minimum Redundancy Maximum Relevance (mRMR) and Relief-F, which offer promising results in identifying highly informative features for classification tasks [27]. However, the relative performance of the machine learning-based feature selection methods over the common genetic feature selection methods has yet to be established.

In this study, we aim to develop an informative SNP panel for population assignment using WGS data, by evaluating three SNP selection methods (FST, mRMR, and Relief-F) combined with four popular machine learning classifiers (KNN, RF, SVM, and NB) (Fig. 1). The goal is to determine the most effective approach for population assignment, particularly in cases of low genetic differentiation among populations.

Results

Population genetic differentiation

After quality control on the WGS dataset, a total of 1,453,445 SNPs were retained for the downstream analyses. Principal component analysis (PCA) of 187 individuals (Table 1; Table S1) revealed that the first three principal components explained 57.12%, 7.15%, and 4.2% of the total genetic variance, respectively. The first component primarily differentiated swamp buffaloes from river-type buffaloes, while the second component distinguished Mediterranean buffalo from other river-type breeds. The third component captured variations within the swamp-type breeds. These PCA results, together with phylogenetic tree and admixture analysis (Figure S1), indicated clear geographical differentiation, with Mediterranean buffalo standing out as the most genetically distinct among the river-type breeds. Among the swamp type buffaloes, three major geographical clusters were observed: the Yangtze River basin (including Guizhoubai and Shanghai), southwestern China (Dehong), and southeastern Yunnan (Diandongnan), a pattern consistent with the previous studies [3, 28, 29]. However, some genetically similar breeds showed overlap on the PCA plots (Fig. 2), such as the Guizhoubai and Shanghai buffaloes, and the Binglangjiang and Nili Ravi buffaloes.

Pairwise FST values further supported the observed genetic differentiation between populations (Fig. 2). Significant differences were found between river-type and swamp-type buffaloes, with FST values ranging from 0.26 to 0.42. Among the four river-type buffalo breeds, Mediterranean buffalo exhibited the greatest genetic distinctness (FST >0.1), while the remaining river-type breeds showed relatively low differentiation (FST = 0.02–0.03). Within swamp-type buffaloes, genetic differentiation was also low (FST = 0.02–0.06). Notably, the breed pairs, such as Diandongnan and Guizhoubai, Binglangjiang and Murrah, and Murrah and Nili Ravi, showed very low FST values (FST = 0.02), which could complicate population assignment.

Given the differing chromosome number between swamp buffalo and river buffalo, it is insightful to examine whether specific chromosomes contribute to the inflation of genome-wide FST between the two buffalo types. However, the results indicated that the FST estimates across individual chromosomes were largely consistent (Figure S2).

Assignment accuracy of different machine learning classifiers

The assignment accuracy of the four machine learning algorithms (SVM, KNN, NB, and RF) was compared under the same SNP selection method (Fig. 3). Overall, assignment accuracy improved as the number of SNPs increased. Among the classification algorithms, KNN consistently underperformed (P < 0.01; adapted paired Student’s T-test [30]), with accuracy lower than the other three for all SNP selection methods. Notably, KNN was highly sensitive to SNP number, achieving accuracy above 90% only when the SNP number exceeded 10,000. In contrast, RF, SVM, and NB showed comparable performance, with accuracy surpassing 90% when the SNP number exceeded 2,000.

Impact of different SNP selection methods on assignment accuracy

The assignment accuracy for SNPs selected using the FST method increased rapidly as the number of SNPs rose from 100 to 2000, after which it plateaued (Fig. 3). All classifiers, except for KNN, achieved over 90% accuracy when more than 2000 SNPs were selected. Among these, the FST-selected SNPs performed best when combined with the Naive Bayes (NB) classifier, especially when fewer than 5000 SNPs were used. Once the SNP number reached ≥ 5000, all classifiers achieved high assignment accuracy.

In contrast, the Relief-F feature selection algorithm showed a steady increase in assignment accuracy as the number of SNPs grew, stabilizing once more than 2000 SNPs were included (Fig. 3). The NB, Support Vector Machine (SVM), and Random Forest (RF) classifiers all achieved greater than 95% accuracy with more than 2000 SNPs.

The Minimum Redundancy Maximum Relevance (mRMR) feature selection algorithm outperformed all other methods in combination with NB, SVM, and RF, achieving near 95% accuracy even with as few as 250 SNPs (Fig. 3).

Overall, while all three SNP selection methods provided assignment accuracy greater than 90%, machine learning-based methods (mRMR and Relief-F) consistently outperformed the genetic FST method (P < 0.01; adapted paired Student’s T-test [30]), particularly when fewer SNPs were selected. Among them, mRMR demonstrated the best performance with accuracy of 0.936 ~ 0.940 (SVM, RF, NB) even using only 250 SNPs, followed by Relief-F with accuracies of 0.652 ~ 0.708 (Fig. 3; Table S2). FST, on the other hand, required a larger dataset (more than 2000 SNPs) to achieve the comparable accuracy levels.

Development of a SNP panel for accurate population assignment

To develop a highly informative SNP panel for accurate population assignment, we compared the SNP sets identified by three selection methods (FST, Relief-F, mRMR) with the SNP sets obtained from the mRMR alone across five training sets (Table 2). Our analysis showed that the SNP set selected by mRMR, when applied in SVM classifier, yielded the highest assignment accuracy. Specifically, the 768 SNPs identified by mRMR across the five training sets resulted in perfect classification, achieving 100% accuracy and an AUC of 1, indicating no misclassifications (Table 2). To validate this panel’s performance, we tested the same 768 SNPs using the SVM classifier on five newly generated datasets. The panel maintained high accuracy, achieving 100% assignment accuracy on two datasets (no misassignments) and 98.0% accuracy on the remaining three datasets (with one misassigned animal per dataset). Overall, the average assignment accuracy across all validation datasets was 98.8%.

These 768 SNPs were distributed across all autosomal chromosomes of the buffalo genome (Fig. 4). To explore the possible biological relevance of the 768 SNPs in water buffalo, we performed functional annotation using SnpEff (https://pcingola.github.io/SnpEff/). The majority of SNPs were located in non-coding regions, including intergenic (409; 46.69%) and intronic (333; 38.01%) regions. Smaller proportions were found in upstream (45; 5.14%) and downstream (38; 4.34%) regulatory regions, transcript (31; 3.54%), exon (15; 1.71%), 5’UTR (3; 0.34%) and 3’UTR (2; 0.23%) (Fig. 5c; Table S3). Despite the non-coding predominance, annotation associated the 768 SNPs with 350 genes (291 protein-coding; Table S3). Gene ontology (GO) enrichment analysis using the clusterProfiler R package (https://bioconductor.org/packages/clusterProfiler/) revealed significant enrichment for key biological processes, including ventricular cardiac muscle cell action potential, neuron migration regulation, axonogenesis, mammary gland morphogenesis, and mesenchymal cell differentiation (Fig. 5d; Table S4). This indicates that the breed-informative SNPs are likely associated with genes governing fundamental physiological and developmental functions.

Discussion

In this study, we assessed the performance of multiple SNP selection methods and machine learning classifiers for population assignment using whole-genome sequencing (WGS) data. The results demonstrated that the choice of SNP selection method, classifier, and the number of SNPs significantly impacted the accuracy of population assignment.

SNP selection plays a critical role in population assignment as it directly affects the performance of downstream classifiers. We used the FST method, a classical approach based on genetic differentiation between populations, as a benchmark. FST is effective at capturing overall genetic differentiation through allele frequency differences and is widely used in population genetics [25]. However, our results showed that FST-selected SNPs failed to accurately distinguish breeds when only a small number of SNPs were used. This limitation likely arises because FST averages genetic differences across populations, potentially overlooking finer-scale genetic variation between specific breed pairs. In contrast, the mRMR and Relief-F methods, designed to prioritize informative features while minimizing redundancy, outperformed FST when fewer SNPs were used. The mRMR method selects SNPs most relevant to the target breed while reducing redundancy, making it particularly effective in handling high-dimensional genomic data [31]. Relief-F, an unsupervised feature selection algorithm, evaluates feature interactions based on nearest neighbors, improving classification performance in high-dimensional datasets and making it robust to noise and feature interactions [32, 33]. In this study, the phylogenetic tree and admixture analysis results based on the 768 selected SNPs showed a more distinct differentiation among the breeds compared to the original dataset (Figure S1), indicating the remarkable discriminative ability of the machine learning-selected SNP. These results are consistent with Schiavo et al.‘s findings, where the RF algorithm outperformed Delta, FST, and PCA methods in SNP selection for population discrimination [26]. These findings underscore the advantages of machine learning algorithm for identifying a small panel of SNPs for accurate population assignment.

The choice of machine learning classifier also significantly impacts the accuracy of population assignment. In this study, we assessed the performance of four widely used classifiers: SVM, RF, NB, and KNN. Among these, SVM and NB demonstrated the higher assignment accuracy, followed by RF, while KNN consistently yielded the lowest performance. Both SVM and NB achieved an impressive 98% accuracy using 2000 SNPs, showcasing their ability to detect weak genetic differentiation between breeds. These results align with previous studies that have highlighted the effectiveness of SVM and RF in handling high-dimensional genomic data [14, 17, 34]. The strength of SVM lies in its capacity to model non-linear relationships between features and class labels, making it particularly suitable for genomic datasets where complex interactions among SNPs are present [14]. Random Forest, a tree-based ensemble method, also performed well in our analysis, providing robust classification results. Its advantage stems from its ability to handle large, noisy datasets with many irrelevant features, as it constructs multiple decision trees and aggregates their predictions. This makes RF especially valuable in high-dimensional genomic data analysis. KNN, a simpler distance-based algorithm, performed poorly for population assignment, particularly where population genetic structures were complex. This poor performance is consistent with KNN’s susceptibility to the curse of dimensionality in high-dimensional settings, a known factor reducing its accuracy [35].

The combination of mRMR and SVM classifiers yielded the most promising results in terms of assignment accuracy and robustness. mRMR efficiently selected a small subset of SNPs, which simplified the problem and enabled the SVM to more effectively distinguish between populations. In this study, a panel of 768 SNPs, selected by mRMR from five training sets and distributed across the water buffalo genome, achieved 98.8% assignment accuracy. This panel represents a highly effective tool for population assignment in Asian water buffalo with practical applications in verifying breed purity for both live animals and cryobank-preserved genetic materials such as embryos, sperm and somatic cells.

It is noteworthy, however, that misassignments occurred between genetically similar populations (Binglangjiang vs. Murrah; Murrah vs. Nili-Ravi; Fig. 5a and b), underscoring the critical influence of population structure on assignment accuracy [36, 37]. Additionally, given the higher cost of WGS compared to SNP arrays, future work should focus on developing a custom low-density SNP array for population assignment or integrating breed-informative variants into existing commercial arrays to facilitate broader adoption of this approach.

Despite these promising findings, several limitations warrant consideration. First, the relatively small sample size increases the risk of overfitting, potentially inflating assignment accuracy [38]. Larger and more diverse samples are needed to enhance the generalizability and reliability of these results. Furthermore, future research should explore a broader array of SNP selection algorithms, classification methods, and their combinations to further improve the accuracy of population assignment.

Conclusion

This study highlights the effectiveness of combining feature selection methods like mRMR and Relief-F with machine learning classifiers such as SVM, RF and NB to achieve optimal population assignment based on whole genome sequence data. The combination of mRMR with SVM offers a robust tool for population assignment, yielding high accuracy even with small SNP panels. These findings provide valuable insights for future genomic studies on population assignment, particularly in livestock species with complex hierarchical population structures. The breed-informative SNPs provide a useful panel for verifying breed purity in water buffalo, applicable to both live animals and cryobank-preserved genetic materials such as embryos, sperm and somatic cells.

Materials and methods

Breeds and whole genome sequencing data

Whole-genome short-read sequencing data from 187 individuals representing eight water buffalo breeds were analyzed. These included four river type breeds (Mediterranean, Murrah, Nili Ravi, and Binglangjiang) and four swamp type breeds (Diandongnan, Dehong, Guizhoubai, and Shanghai) (Table 1; Table S1). These well-defined breeds were chosen to represent different levels of genetic differentiations between populations (Fig. 2), consistent with the observed stratification among water buffalo breeds [29]. The sequencing depths ranged from 7.12 to 37.39 (Table S2). The number of individuals per breed varied between 20 and 26. The experiment was designed to collect the samples randomly from each population to minimize close genetic relationships following the ARRIVE guidelines (Animal Research: Reporting of In Vivo Experiments) [39].

To evaluate the classification accuracy, five replicates of random sampling were performed to partition the dataset into a training set and a testing set at a 3:1 ratio (Table 1; Fig. 1).

Whole genome sequencing data processing

Raw sequencing reads were processed for quality control using Trimmomatic software (http://www.usadellab.org/cms/index.php?page=trimmomatichttp://www.usadellab.org/cms/index.php?page=trimmomatic), with the following parameters for adapter trimming and base quality filtering: ILLUMINACLIP:2:30:3:1:true SLIDINGWINDOW:3:15 LEADING:20 TRAILING:20 AVGQUAL:20 MINLEN:50. The processed reads were then aligned to the water buffalo reference genome (UOA_WB_1) [40] using Sentieon software (https://www.sentieon.com/). SNP calling was performed using the Genome Analysis Toolkit (GATK v4.2.2.0) after duplicate removal. Genotypes were filtered with bcftools to retain variants with a minor allele frequency (MAF) >0.05 and genotype missingness < 0.05, resulting in 24,898,545 SNPs. Linkage disequilibrium (LD) pruning was performed using Plink [41] with the parameters “--indep-pairwise 50 10 0.2”. The final dataset included 1,453,445 SNPs. Missing genotypes were imputed using Beagle software with the parameters “iterations = 50” and “window = 50”.

Despite substantial genetic differentiation at the subspecies level between swamp buffalo (2n = 48) and river buffalo (2n = 50) (Zhang et al. 2020), whole-genome sequencing reads were mapped to the river buffalo reference genome, with average mapping rates exceeding 99% (99.19% for swamp buffalo and 99.36% for river buffalo). These comparable high mapping rates demonstrate the absence of significant mapping bias between the two buffalo types (Table S2).

Population genetics analysis

Principal component analysis (PCA) and pairwise FST value calculation were performed using Plink. PCA plots and FST heatmaps were generated and visualized in R. ADMIXTURE v1.3 software [42] was used to infer the proportion of ancestry in the tested population with K values ranging from 2 to 6. For phylogenetic analysis, the NJ tree was constructed based on IBD distance and visualized using the online iTOL tool [43].

SNP selection methods

To identify the most effective SNP selection methods and the highly breed-informative markers, we employed both a genetic approach (the population differentiation index FST) and two machine learning algorithms (Minimum Redundancy Maximum Relevance (mRMR) and Relief-F). These methods were assessed using SNP sets across different levels of SNP number (100, 250, 500, 800, 1000, 2000, 3000, 5000, 10000) based on the previous studies [6, 14, 22].

FST quantifies genetic differentiation by measuring allele frequency differences between populations. Given the significant genetic divergence between river-type and swamp-type water buffaloes, we first categorized the populations into two groups and calculated FST for SNPs within each group. The top 20,000 SNPs with the highest FST values from each group were selected, yielding a pool of 40,000 pre-selected SNPs for subsequent analysis.

mRMR evaluates feature importance by balancing the relevance (mutual information) between each SNP and the target variable, and redundancy (mutual information) between the SNPs. The mRMRe R package [44] was used to compute mRMR scores.

Relief-F assesses the importance of each SNP by evaluating how well it distinguishes between the nearest same-class and different-class neighbors. The CoreLearn R package [45] was used with the attrEval function, where the estimator parameter was set to ReliefFbestK.

Machine learning classifiers for population assignment

This study evaluates four widely used machine learning classifiers - Random Forest (RF), Support Vector Machine (SVM), K-Nearest Neighbor (KNN), and Naive Bayes (NB) - selected for their distinct learning paradigms and strengths [14–17, 46].

Random Forest (RF) is an ensemble learning method based on decision trees. The key parameters include the number of trees (ntree), the number of features selected for each split (mtry), and tree depth [40]. Hyperparameters mtry and ntree were optimized using the tuneRF function from the randomForest package [47]. The randomForest function was used for model training, and predict for classification.

Support Vector Machine (SVM) is a linear classifier used in supervised learning tasks. The key parameters for SVM include regularization (cost), kernel type, and kernel coefficient (gamma). The tune.svm function in the e1071 package [48] was used to perform a grid search for optimal values of cost and gamma. The svm function was employed for model fitting, and predict was used for classification.

K-Nearest Neighbor (KNN) is a non-parametric method for supervised learning, where the key parameter is the number of nearest neighbors (K). The class package (https://CRAN.R-project.org/package=class) was used to calculate distances between samples using the Euclidean distance metric.

Naive Bayes (NB) classifiers are probabilistic models based on Bayes’ theorem, assuming feature independence. NB calculates the posterior probability of each class given the observed features and assigns the class with the highest probability. The train function in the caret package (https://CRAN.R-project.org/package=caret) was used to optimize the Laplace smoothing parameter, while the naiveBayes function from the e1071 package was used for model training and prediction.

Evaluation metrics

We used a random sampling approach to partition the training and testing datasets. Specifically, we performed five rounds of random sampling, generating five distinct dataset pairs for model training and classification testing at a 3:1 ratio (Table 1; Fig. 1). In addition, the same random sampling procedure was repeated to generate five new datasets for validating the performance of the 768 breed-informative SNP panel for population assignment. The assignment accuracy (ACC) was used to evaluate the performance of the models, calculated as the proportion of correctly classified instances. Additionally, the area under the receiver operating characteristic curve (AUC) was employed to assess the model’s robustness. ROC curves were generated using the pROC package (https://CRAN.R-project.org/package= pROC).
