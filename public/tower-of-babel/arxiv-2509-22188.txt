Abstract
. We introduce a systematic method for constructing new presentations of free products that give rise to previously unknown geodetic Cayley graphs. Our approach adapts subdivision techniques of Parthasarathy and Srinivasan [J. Combin. Theory Ser. B, 1982], which preserve geodecity at the graph level, to the setting of group presentations and rewriting systems. Specifically, given a group G G with geodetic Cayley graph with respect to generating set Σ \Sigma and an integer n n , our construction produces a rewriting system presenting G ∗ F n ​ | Σ | G\ast F_{n|\Sigma|} with geodetic Cayley graph with respect to the new generating set. This framework provides new infinite families of geodetic Cayley graphs and extends the toolkit for investigating long-standing conjectures on geodetic groups.

1.
Introduction

A connected graph is called
geodetic
if there is a unique shortest path between each pair of vertices.
The study of geodetic graphs is motivated by applications in network design and parallel computing, where uniqueness of shortest paths in a graph provides efficiency in routing algorithms (see for example
[
12
,
22
]
) and non-trivial 2-blocks allow for localised fault-tolerance. Algebraically, a finitely generated group is called
geodetic
if it admits a finite inverse-closed generating set
\Sigma
for which the associated Cayley graph is geodetic, in which case we call
\Sigma
a
geodetic generating set
.

If a group has a geodetic generating set, then it admits a confluent length-reducing rewriting system with respect to that generating set.
Madlener and Otto
[
14
]
conjectured that a group admits a finite confluent length-reducing rewriting system if and only if it is plain (that is, a free product of finitely many finite groups and a finitely generated free group). Ten years later Shapiro
[
19
]
conjectured that a finitely generated group is geodetic if and only if it is plain. Recent progress by several authors

[
5
,
6
,
7
,
8
,
16
]
has attempted to clarify the
connection between rewriting systems and geodetic Cayley graphs, with a goal to advance both conjectures.

Federici
[
10
]
conjectured that the only finite geodetic Cayley graphs are complete graphs and, in the special case of cyclic groups of odd order, an odd cycle.
This conjecture has been confirmed in some special infinite families, and checked by computer for all groups up to order
1024
in
[
8
, Theorems B and C]
.

In this paper we investigate systematic methods for constructing new geodetic Cayley graphs from existing ones. At the graph-theoretic level, it is known that if
\Gamma
is a geodetic graph then replacing every edge of
\Gamma
by a path of fixed odd length yields another geodetic graph
[
15
]
.
Inspired by this, we introduce a construction that takes as input a group
G
with finite generating inverse-closed set
\Sigma
and outputs a rewriting system
\nabla_{n}(G,\Sigma)
corresponding to a subdivision of the Cayley graph. We show that
\nabla_{n}(G,\Sigma)
presents the free product
G\ast F_{n|\Sigma|}
, and that geodeticity of the generating set is preserved under this transformation.

Our main results are the following. First, we prove that the construction
\nabla_{n}(G,\Sigma)
yields a confluent, inverse-closed rewriting system that presents
G\ast F_{n|\Sigma|}
(
A
). Second, we establish that
\Sigma
is a geodetic generating set for
G
if and only if the expanded generating set
\Sigma(n)
is geodetic for the constructed free product (
B
). This provides a general framework for building new families of geodetic Cayley graphs
from known ones.

2.3.
Cayley graphs and geodetic groups

Let
G
be a group. We write
1_{G}
for the identity element in
G
, and we adopt the convention that the empty product is equal to
1_{G}
. A subset
\Sigma\subset G
is a
finite inverse-closed generating set for
G
if
\Sigma
is finite,
\Sigma
does not contain the identity element
1_{G}
, for every
g\in\Sigma
we have that
g^{-1}\in\Sigma
, and every element of
G
is a product of elements in
\Sigma
. Given such a set
\Sigma
, the
Cayley graph of
G
with respect to
\Sigma
is the
\Sigma
-labelled graph
\Gamma=\text{Cay}(G,\Sigma)
with
V(\Gamma)=G
,
E(\Gamma)=\{\{g,h\}\subset G\mid g^{-1}h\in\Sigma\}
, together with
\Sigma
-labelling function
L

defined by
L((g,h))=g^{-1}h\in\Sigma
for each
(g,h)\in V(\Gamma)\times V(\Gamma)
with
\{g,h\}\in E(\Gamma)
.
It follows immediately that for any pair of adjacent vertices
g
and
h
,
L(g,h)
and
L(h,g)
are inverses in
G
, and
L(h,g)=L(g,h)=x
if and only if
x
has order two.

As noted in the introduction, we call a group
G

geodetic
if it admits a finite inverse-closed generating set
\Sigma
such that

\text{Cay}(G,\Sigma)
is geodetic; in which case we say that
\Sigma
is a
geodetic generating set for
G
.

2.4.
Rewriting systems

An
alphabet
is a finite set.
If
\Sigma
is an alphabet,
\Sigma^{\ast}
denotes the set of all sequences
(x_{1},\dots,x_{n})
of length
n
with
x_{i}\in\Sigma
, which we write as words
x_{1}\cdots x_{n}
.
If
w\in\Sigma^{\ast}
we write
|w|
for the length of
w
. The word of length
0
is denoted
\lambda
. If
u,v\in\Sigma^{\ast}
we say
v
is a
factor
of
u
if there exist
\alpha,\beta\in\Sigma^{\ast}
so that
u=\alpha v\beta
, and a
proper factor
if
u\neq v
.

A
rewriting system
is a pair
(\Sigma,T)
where
\Sigma
is an alphabet, and
T
is a subset of
\Sigma^{\ast}\times\Sigma^{\ast}
called the set of
rewriting rules
.
Then
T
determines a relation
\rightarrow
on
\Sigma^{\ast}
given by
u\ell v\rightarrow urv
if
(\ell,r)\in T

and
u,v\in\Sigma^{\ast}
.
We write
\xrightarrow{\ast}
for the reflexive and transitive closure of
\rightarrow
, and
\overset{\ast}{\leftrightarrow}
for the symmetric closure of
\xrightarrow{\ast}
. A word
u\in\Sigma^{\ast}
is
irreducible
if no factor is the left-hand side of any rewriting rule.

A rewriting system
(\Sigma,T)
is called:

(i)

finite
if
T
is a finite set,

(ii)

length-reducing
if for each
(\ell,r)\in T
we have
|\ell|>|r|
,

(iii)

confluent
if for all
u,v,w\in\Sigma^{\ast}
,
u\overset{\ast}{\leftarrow}w\overset{\ast}{\rightarrow}v
implies that there exists
t\in\Sigma^{\ast}
such that
u\overset{\ast}{\rightarrow}t\overset{\ast}{\leftarrow}v
,

(iv)

Church-Rosser
if for all
u,v\in\Sigma^{\ast}
,
u\overset{\ast}{\leftrightarrow}v
implies there exists
w\in\Sigma^{\ast}
such that
u\overset{\ast}{\rightarrow}w\overset{\ast}{\leftarrow}v
.

The operation of concatenation is well defined on
\overset{\ast}{\leftrightarrow}
-classes, and so
\Sigma^{\ast}
with concatenation forms a monoid. We denote this monoid by
M(\Sigma,T)
and call it the monoid presented by
(\Sigma,T)
.
If for every
x\in\Sigma^{\ast}
there exists
y\in\Sigma^{\ast}
such that
xy\overset{\ast}{\rightarrow}\lambda
and
yx\overset{\ast}{\rightarrow}\lambda
, then we call
y
the
inverse
of
x
in
M(\Sigma,T)
. We say
(\Sigma,T)
is
inverse-closed
if there is no
x\in\Sigma
with
x\overset{\ast}{\leftrightarrow}\lambda
and
for all
x\in\Sigma
there exists an inverse
y\in\Sigma
.
Note that if
(\Sigma,T)
is inverse-closed, then
M(\Sigma,T)
is a group with inverse-closed generating set
\Sigma
.
Given a word
w=x_{1}x_{2}\cdots x_{n}\in\Sigma^{\ast}
in an inverse-closed rewriting system
(\Sigma,T)
, let
w^{-1}=x_{n}^{-1}\cdots x_{2}^{-1}x_{1}^{-1}
be the
inverse word
.

We have the following connection between inverse-closed confluent length-reducing rewriting systems and geodetic groups.

Lemma 2.5
.

Let
(\Sigma,T)
be an inverse-closed length-reducing rewriting system. Then
(\Sigma,T)
is confluent if and only if
M(\Sigma,T)
is a group with geodetic generating set
\Sigma
.

Proof.

Since
\Sigma
is an inverse-closed,
M(\Sigma,T)
is a group. Note that
(\Sigma,T)
is confluent if and only if it is Church-Rosser (see
[
4
, Theorem 8.1 (d)]
or
[
1
, Lemma 1.17]
,). That is, any word
v\in\Sigma^{\ast}
rewrites to a unique form
w\in\Sigma^{\ast}
, which
is of minimal length since rules are length-reducing.
Now
v
is the unique label of a geodesic path in the Cayley graph of the group
M(\Sigma,T)
with finite inverse-closed generating set
\Sigma
. Hence, the result follows.

2.5.
Group presentations

A
group presentation
is a pair
(X,R)
, usually written
\langle X\mid R\rangle
, comprising an alphabet
X
and a set
R\subset(X\cup X^{-1})^{\ast}
of words; the elements of
X
are called
(group) generators
, and the elements of
R
are called
relators
. The group
G
presented by
\langle X\mid R\rangle
is the quotient of
F(X)
, the free group on
X
, by
\left<\left<\mathinner{R}\right>\right>
, the smallest normal subgroup that contains
R
. We note that, since
G
is a quotient of
F(X)
, the words
xx^{-1}
and
x^{-1}x
spell the identity in
G
for each generator
x
, and so these words need not appear in
R
.

Lemma 2.6
.

Let
(\Sigma,T)
be
an inverse-closed rewriting system and
R=\{\ell r^{-1}\mid(\ell,r)\in T\}
.
Then
the groups
M(\Sigma,T)
and
G=\langle\Sigma\mid R\rangle
isomorphic.

Proof.

Recall that each element of
M(\Sigma,T)
is an

\overset{\ast}{\leftrightarrow}
-equivalence class. Define
\phi\colon M(\Sigma,T)\to G

to be a map which takes
any word
w\in\Sigma^{*}
in a
\overset{\ast}{\leftrightarrow}
-class and, considering
w
as an element of
F(\Sigma)
, computes its image under the quotient map to
G
. We now explain why the map is a well-defined group homomorphism. Suppose
w_{1}\overset{\ast}{\leftrightarrow}w_{2}
. Then there exists a finite sequence

w_{1}=w_{1,0}\leftrightarrow w_{1,1}\leftrightarrow w_{1,2}\leftrightarrow\cdots\leftrightarrow w_{1,k}=w_{2},

where each step is the application (or reverse) of a rule in
T
, that is, for each
i,j
with
|i-j|=1
,
w_{1,i}=u\ell v
,
w_{1,j}=urv
for some
u,v\in\Sigma^{\ast}
and
(\ell,r)\in T
.
Since
u\ell v,u\ell r^{-1}rv,urv
each represent the same element of
G
, each

w_{1,i}
represents the same element of
G
as
w_{1}
and
w_{2}
.

It is clear that
\phi
is
surjective, since
G
is generated by
\Sigma
. For injectivity, let
w\in\Sigma^{\ast}
represent the identity of
G
. Hence,
w=\prod_{i=1}^{n}u_{i}\gamma_{i}u_{i}^{-1}
for some
n\in\mathbb{N}
,
u_{i}\in\Sigma^{\ast}
and
\gamma_{i}\in R
(see
[
2
, Prop. 4.1.2]
). We wish to show that
w
represents the identity in
M(\Sigma,T)
, that is,
w\overset{\ast}{\leftrightarrow}\lambda
.
Using the rewriting we
find that

\displaystyle w

\displaystyle=u_{1}\gamma_{1}u_{1}^{-1}u_{2}\gamma_{2}u_{2}^{-1}\cdots u_{n}\gamma_{n}u_{n}^{-1}

\displaystyle=u_{1}\ell_{1}r_{1}^{-1}u_{1}^{-1}u_{2}\ell_{2}r_{2}^{-1}u_{2}^{-1}\cdots u_{n}\ell_{n}r_{n}^{-1}u_{n}^{-1}

\displaystyle\overset{\ast}{\to}u_{1}r_{1}r_{1}^{-1}u_{1}^{-1}u_{2}r_{2}r_{2}^{-1}u_{2}^{-1}\cdots u_{n}r_{n}r_{n}^{-1}u_{n}^{-1}

\displaystyle\overset{\ast}{\to}u_{1}u_{1}^{-1}u_{2}u_{2}^{-1}\cdots u_{n}u_{n}^{-1}

\displaystyle\overset{\ast}{\to}\lambda.

Hence,
w
represents the identity in
M(\Sigma,T)
and so
\phi
is injective.
∎

It is a standard fact in combinatorial group theory that
the following transformations of group presentations preserve the groups they present up to isomorphism
[
13
, Pg. 89]
.

Definition 2.7
.

Given a presentation
\langle X\mid R\rangle
, the following transformations of presentations are called
Tietze transformations
:

(T1):

Replace
\langle X\mid R\rangle
by
\langle X\mid R\cup S\rangle
, where
S\subset\left<\left<\mathinner{R}\right>\right>
.

(T1
-1
):

Replace
\langle X\mid R\rangle
by
\langle X\mid R\setminus S\rangle
, where
S\subset\left<\left<\mathinner{R\setminus S}\right>\right>
.

(T2):

Replace
\langle X\mid R\rangle
by
\langle X\cup Y\mid R\cup S\rangle
, where
Y\cap F(X)=\emptyset
is a set of new symbols,
and
S=\{y^{-1}u_{y}\colon y\in Y,u_{y}\in(X\cup X^{-1})^{\ast}\}
.

(T2
-1
):

Replace
\langle X\mid R\rangle
by
\langle X\setminus Y\mid R\setminus S\rangle
, where
Y\subseteq X
such that
S=\{yu_{y}\colon y\in Y,u_{y}\in((X\setminus Y)\cup(X\setminus Y)^{-1})^{\ast}\}\subseteq R
.

Example 2.8
.

The cyclic group of order four has presentation
\langle x\mid x^{4}\rangle
. Applying
(T2)
with
Y=\{y,z\}
and
S=\{y^{-1}x^{2},z^{-1}x^{3}\}

yields a presentation

(2.1)

\langle x,y,z\mid x^{4},y^{-1}x^{2},z^{-1}x^{3}\rangle

for the same group (up to isomorphism).
Similarly, in
Example

1.1
, applying
(T2)
with
Y=\{z\}
and
S=\{z^{-1}xy\}
to
\langle x,y\mid-\rangle
gives the presentation whose corresponding Cayley graph is shown in
Fig.

.

The following well-known lemma (see
[

Lemma 2.9

If
\langle X_{1}\mid R_{1}\rangle

3.
The construction

In this section we describe the key construction for the paper.

Definition 3.1
.

Let
G
be a group with a finite inverse-closed generating set
\Sigma
, let
(\Gamma,L)=\text{Cay}(G,\Sigma)
, and let
n
be a natural number.

First, we introduce convenient notation for the elements of
\Sigma
. Let
\Sigma_{1}
be the subset of
\Sigma
comprising the elements of order two. If
\Sigma_{1}=\Sigma
, then define
\Sigma_{2}=\Sigma_{3}=\emptyset
; otherwise, let
\{\Sigma_{2},\Sigma_{3}\}
be a partition of
\Sigma\setminus\Sigma_{1}
such that for each
x\in\Sigma_{2}
, we have
x^{-1}\in\Sigma_{3}
. Let
m_{1}=|\Sigma_{1}|
,
m_{2}=|\Sigma_{2}|
, and introduce symbols for the elements of
\Sigma
such that
\Sigma_{1}=\{a_{1},\dots,a_{m_{1}}\}
,
\Sigma_{2}=\{b_{1},\dots,b_{m_{2}}\}
,
\Sigma_{3}=\{c_{1},\dots,c_{m_{2}}\}
, and
c_{i}
is the inverse of
b_{i}
in
G
for all
i\in[1,m_{2}]
.

We now introduce a larger set of symbols which will become the labelling set for a subdivision of
\Gamma
.
Let
\Sigma_{1}(n)=\{a_{i,j}\mid i\in[1,m_{1}],j\in[1,2n+1]\}
,
\Sigma_{2}(n)=\{b_{i,j}\mid i\in[1,m_{2}],j\in[1,2n+1]\}
,
\Sigma_{3}(n)=\{c_{i,j}\mid i\in[1,m_{2}],j\in[1,2n+1]\}

and let
\Sigma(n)=\Sigma_{1}(n)\cup\Sigma_{2}(n)\cup\Sigma_{3}(n)
.

Let
\Gamma_{n}
denote the graph obtained from
\Gamma
by subdividing each edge into
2n+1
sub-edges (as discussed in
Section

2.2
). Let
L(n)
be the
\Sigma(n)
-labelling of
\Gamma_{n}
constructed such that the following holds: for every edge
\{g,h\}\in E(\Gamma)
with label
L((g,h))=x_{i}\in\Sigma_{1}\cup\Sigma_{2}
, the path in
\Gamma_{n}
from
g
to
h
of length
2n+1
is labelled
x_{i,1},x_{i,2},\dots,x_{i,2n+1}
; for every edge
\{g,h\}\in E(\Gamma)
with label
L((g,h))=c_{i}\in\Sigma_{3}
, the path in
\Gamma_{n}
from
g
to
h
of length
2n+1
is labelled
c_{i,2n+1},c_{i,2n},\dots,c_{i,1}
.
Assume a total order on
\Sigma(n)
has been fixed so that
\Gamma_{n}
-slex is well defined as in

Definition

2.3
.

We define a set of rewriting rules
T(n)\subset\Sigma(n)^{\ast}\times\Sigma(n)^{\ast}
as follows: a pair
(\ell,r)\in\Sigma(n)^{\ast}\times\Sigma(n)^{\ast}
is a rule in
T(n)
if and only if one of the following is true:

(\mathcal{R}_{1})

\ell
is the label on a path
(u,v,u)
for some pair of adjacent vertices
u
and
v
, and
r=\lambda
;

(\mathcal{R}_{2})

\ell
is the label on a path
\alpha
,
r
is the label on a path
\beta
,
\alpha\beta^{-1}
is
an embedded circuit of odd length,
|\alpha|=|\beta|+1
, and
\beta
is
\Gamma_{n}
-slex

(\mathcal{R}_{3})

\ell
is the label on a path
\alpha
,
r
is the label on a path
\beta
,
\alpha\beta^{-1}
is
an embedded circuit of length at least
4
,
|\alpha|=|\beta|
, and
\beta
is
\Gamma_{n}
-slex.

Finally, we write
\nabla_{n}(G,\Sigma)
for the rewriting system
(\Sigma(n),T(n))
.

Remark 3.2
.

Note that rules of type
(\mathcal{R}_{1})
and
(\mathcal{R}_{2})
never label circuits made up of two distinct geodesics with the same initial and terminal vertices. Hence,
\Gamma_{n}
is geodetic if and only if there are no rules of type
(\mathcal{R}_{3})
in
\nabla_{n}(G,\Sigma)
.

Lemma 3.4
.

Let
w
be the label of a geodesic path in
\Gamma_{n}
. Let
w^{\prime}
be the label of a

\Gamma_{n}
-slex
path that shares the same initial and terminal vertices as
w
. Then
w\overset{\ast}{\to}w^{\prime}
.

Proof.

If
w
is a label of a
\Gamma_{n}
-slex path, we are done.
If not, scan
w
from left to right until the prefix labels a path that
is not
\Gamma_{n}
-slex. Take this prefix and scan right to left until the suffix labels a path
\gamma
that is not
\Gamma_{n}
-slex. Let
p
be the label of
\gamma
. There exists a path
\gamma_{0}
with the same endpoints as
\gamma
, that is
\Gamma_{n}
-slex, such that
\gamma\gamma_{0}^{-1}
labels an embedded circuit of even length at least
4
. Let
p_{0}
be the label of
\gamma_{0}
. Hence
(p,p_{0})\in T(n)
is of type (
\mathcal{R}_{3}
). Let
w_{1}
be the word
w
with the
p
factor replaced by
p_{0}
. If
w_{1}
is a label of a
\Gamma_{n}
-slex path we are done, otherwise repeat. The procedure will terminate as
\leqslant
is a total order on
\Sigma(n)^{\ast}
, at each step there is a reduction with respect to
\leqslant
, and the length of words is bounded below by
0
.
∎

Lemma 3.5
.

Let
w
be the label of a path in
\Gamma_{n}
. Let
w^{\prime\prime}
be the label of a
\Gamma_{n}
-slex path with the same initial and terminal vertices as
w
. Then
w\overset{\ast}{\to}w^{\prime\prime}
.

Proof.

If
w
is a label of a
\Gamma_{n}
-slex path, we are done. If
w
is a label of a geodesic path, apply
Lemma

3.4
and we are done. Otherwise, scan
w
from left to right, until a prefix is not a geodesic. Now scan the prefix from right to left until a suffix is not a geodesic. Let
p
be this suffix. Either
p
is a label on a path
(u,v,u)
for some pair of adjacent vertices
u
and
v
, and so we replace the path labelled by
p
by the empty path using the rule
(p,\lambda)
, or there exists a path labelled by
p_{0}
that is
\Gamma_{n}
-slex and
pp_{0}^{-1}
labels an embedded circuit in
\Gamma_{n}
, so
(p,p_{0})\in T(n)
, and replace the path labelled by
p
by the path labelled by
p_{0}
. Let
w_{1}
be the label of the word obtained. If
w_{1}
is a label of a
\Gamma_{n}
-slex path, we are done. If
w_{1}
is a label of a geodesic path, apply
Lemma

3.4
and we are done. Otherwise we repeat the process. The procedure will terminate as
\leqslant
is a total order on
\Sigma(n)^{\ast}
, at each step there is a reduction with respect to
\leqslant
, and word length is bounded below by
0
.
∎

Lemma 3.6
.

Let
G
be a group with finite inverse-closed generating set
\Sigma
. For each
n\in\mathbb{N}
,
\nabla_{n}(G,\Sigma)
is an inverse-closed confluent rewriting system.

Proof.

The inverse of each
a_{i,j}\in\Sigma_{1}(n)
is
a_{i,2n+2-j}\in\Sigma_{1}(n)
. The inverse of each
b_{i,j}\in\Sigma_{2}(n)
is
c_{i,2n+2-j}\in\Sigma_{3}(n)
. Hence, each element of
\Sigma(n)
has an inverse, so the rewriting system is inverse-closed.

Suppose
u,v,w\in\Sigma^{\ast}
with
u\overset{\ast}{\leftarrow}w\overset{\ast}{\rightarrow}v
and
u\neq v
. By the construction,
u
and
v
are labels of paths in
\Gamma_{n}
with the same initial and terminal vertices of
w
. By
Lemma

3.5
, there are
\Gamma_{n}
-slex geodesics with labels
u_{1}
and
v_{1}
and the same initial and terminal vertices of
w
so that
u\overset{\ast}{\to}u_{1}
and
v\overset{\ast}{\to}v_{1}
. Since
\leqslant
is a total order, we have
u_{1}=v_{1}
. Hence,
\nabla_{n}(G,\Sigma)
is confluent.
∎

Now that we know that
\nabla_{n}(G,\Sigma)
is an inverse-closed rewriting system, we can conclude that the monoid presented by
\nabla_{n}(G,\Sigma)
is a group with finite inverse-closed generating set
\Sigma(n)
. Let

(3.1)

\mathcal{G}_{n}(G,\Sigma)=M(\nabla_{n}(G,\Sigma))

(3.2)

\mathcal{G}^{\text{gen}}_{n}(G,\Sigma)=(\mathcal{G}_{n}(G,\Sigma),\Sigma(n))

In
Section

4
, we will identify the isomorphism class of
\mathcal{G}_{n}(G,\Sigma)
, while in
Section

5
, we will prove some properties of Cayley graphs associated to
\mathcal{G}^{\text{gen}}_{n}(G,\Sigma)
. A notational advantage of
\mathcal{G}_{n}^{\text{gen}}
is that the input and output are both a group and its generating set, so can be applied repeatedly.

Proposition 3.7
.

Let
G
be a group with finite inverse-closed generating set
\Sigma
. Then for each
n\in\mathbb{N}
,
\text{Cay}(G,\Sigma)
is geodetic if and only if
\nabla_{n}(G,\Sigma)
is length-reducing.

Proof.

As noted in
Remark

3.2
,
\Gamma_{n}
is geodetic if and only if there are no rules of type
(\mathcal{R}_{3})
.

Suppose
\Gamma=\text{Cay}(G,\Sigma)
is geodetic. By
Lemma

2.4
,
\Gamma_{n}
is geodetic. Since
\Gamma_{n}
is geodetic, there are no rules of type
(\mathcal{R}_{3})
and we conclude
\nabla_{n}(G,\Sigma)
is length-reducing.

Suppose
\Gamma=\text{Cay}(G,\Sigma)
is not geodetic. By
Lemma

2.4
,
\Gamma_{n}
is not geodetic, so
\mathcal{R}_{3}
is non-empty. Hence,
\nabla_{n}(G,\Sigma)
is not length-reducing.
∎

We have now proved the following.

Theorem B
.

Let
G
be a group with finite inverse-closed generating set
\Sigma
. For each
n\in\mathbb{N}
,
\text{Cay}(G,\Sigma)
is geodetic if and only if
\text{Cay}(\mathcal{G}_{n}^{\text{gen}}(G,\Sigma))
is geodetic.

Proof.

Follows from
Lemma

2.5
,
Lemma

3.6
and
Proposition

3.7
.
∎

4.
Identifying the group constructed

We will use Tietze transformations to transform
\langle\Sigma\mid\{\ell^{-1}r\mid(\ell,r)\in T\}\rangle
into a presentation from which the the isomorphism class of
\mathcal{G}_{n}(G,\Sigma)
is easily understood (that is, as in
Lemma

2.9
).

Proposition 4.1
.

Let
n\in\mathbb{N}
and let
G
be a group with finite inverse-closed generating set
\Sigma
. Then
\mathcal{G}_{n}(G,\Sigma)\cong G\ast F_{n|\Sigma|}
.

Proof.

By
Lemma

2.6
, the group
\nabla_{n}(G,\Sigma)
associated to the rewriting system
(\Sigma(n),T(n))
is the group presented by
\langle\Sigma(n)\mid R_{0}\rangle
where
R_{0}=\{\ell r^{-1}\mid(\ell,r)\in T(n)\}
. We adopt the notation of
Definition

3.1
. We note that rewriting rules of type
(\mathcal{R}_{1})
express inverse relations between generators, while all other rewriting rules label embedded circuits in
\Gamma(n)
.

In this paragraph we describe a sequence of Tietze transformation that removes generators which are inverses of other generators. Let
X_{0}=\Sigma(n)
and
X_{1}=\{a_{i,j}\mid 1\leqslant i\leqslant m_{1},1\leqslant j\leqslant n+1\}\cup\Sigma_{2}
; we note that
X_{1}
is a minimal set with the property that the inverse-closure of
X_{1}
is
X_{0}
. Let
R_{0}^{\prime}=\{yx\mid x\in X_{1},y\in X_{0}\setminus X_{1}\}
and
R_{0}^{\prime\prime}=\{xy\mid x\in X_{1},y\in X_{0}\setminus X_{1}\}
; we note that
R_{0}^{\prime}\cup R_{0}^{\prime\prime}
is the set of relators that express inverse-relations between elements of
X_{1}
and elements of
X_{0}\setminus X_{1}
. Let
R_{1}
be the set of words obtained from
R_{0}\setminus(R_{0}^{\prime}\cup R_{0}^{\prime\prime})
by replacing each occurrence of each element
y\in X_{0}\setminus X_{1}
by
x^{-1}
such that
x\in X_{1}
and
yx\in R_{0}
. The following is a sequence of Tietze transformations, with the types indicated, that transforms our starting presentation into one in with a smaller set of generators:

\langle X_{0}\mid R_{0}\rangle\overset{(T_{1})}{\mapsto}\langle X_{0}\mid R_{0}\cup R_{1}\rangle\overset{(T_{1}^{-1})}{\mapsto}\langle X_{0}\mid R_{0}^{\prime}\cup R_{1}\rangle\overset{(T_{2}^{-1})}{\mapsto}\langle X_{1}\mid R_{1}\rangle

Let
X_{2}=X_{1}
, and let
R_{2}
be the subset of
R_{1}
comprising those relators that declare certain generators to have order two and those that label embedded circuits in
\Gamma(n)
and which begin with one of the letters
a_{i,1},a_{i,1}^{-1},b_{i,1}
or
b_{i,1}^{-1}
; the relators omitted are those that correspond to paths that begin at vertices that were added in the subdivision of the original graph. Since each word in
R_{1}\setminus R_{2}
is a cyclic conjugate of a word in
R_{2}
, the following is a Tietze transformation

\langle X_{1}\mid R_{1}\rangle\overset{(T_{1}^{-1})}{\mapsto}\langle X_{2}\mid R_{2}\rangle.

We introduce more new generators which correspond to labels on edges of
\Gamma
. Let
X_{3}=X_{2}\cup\Sigma
, and let

R_{3}=R_{2}\cup\{a_{i,n+1}^{-1}a_{i,n}^{-1}\dots a_{i,1}^{-1}a_{i}a_{i,1}\dots a_{i,n}:1\leqslant i\leqslant m_{1}\}\\
\cup\{b_{i,n+1}^{-1}b_{i,n}^{-1}\dots b_{i,1}^{-1}b_{i}b_{i,2n+1}^{-1}\dots b_{i,n+2}^{-1}:1\leqslant i\leqslant m_{2}\}.

The following is a Tietze transformation

\langle X_{2}\mid R_{2}\rangle\overset{(T_{2})}{\mapsto}\langle X_{3}\mid R_{3}\rangle.

Let
X_{4}=X_{3}
. Let
R_{3}^{\prime}
be the set of relators in
R_{2}
that express that certain generators have order two, let
R_{3}^{\prime\prime}
be the set of relators in
R_{3}
that label embedded circuits in
\Gamma(n)
and begin with one of the letters
a_{i,1},a_{i,1}^{-1},b_{i_{1}}
or
b_{i,1}^{-1}
, and let
R_{3}^{\prime\prime\prime}
be the set of relators in
R_{3}
that were introduced in the previous paragraph. Let
R_{4}^{\prime\prime}
be the set of words obtained from
R_{3}^{\prime\prime}
by replacing every occurrence of the factor

a_{i,1}\cdots a_{i,n}a_{i,n+1}a_{i,n}^{-1}\cdots a_{i,1}^{-1}
by
a_{i}
, every occurrence of the factor
b_{i,1}b_{i,2}\cdots b_{i,2n+1}
by
b_{i}
, and every occurrence of the factor
b_{i,2n+1}^{-1}\cdots b_{i,2}^{-1}\dots b_{i,1}^{-1}
by
b_{i}^{-1}
. Let
R_{4}=R_{3}^{\prime}\cup R_{4}^{\prime\prime}\cup R_{4}^{\prime\prime\prime}
. The following is a sequence of Tietze transformations:

\langle X_{3}\mid R_{3}\rangle\overset{(T_{1})}{\mapsto}\langle X_{4}\mid R_{3}\cup R_{4}^{\prime\prime}\rangle\overset{(T_{1}^{-1})}{\mapsto}\langle X_{4}\mid R_{4}\rangle.

Finally, we remove the middle edge from each subdivided edge. Let
X_{5}=X_{4}\setminus(\{a_{i,n+1}:1\leqslant i\leqslant m_{1}\}\cup\{b_{i,n+1}:1\leqslant i\leqslant m_{2}\})
and let
R_{5}=R_{4}\setminus R_{3}^{\prime\prime\prime}
. We note that in
R_{4}
, the letter
a_{i,n+1}
appears only in the relator
a_{i}^{-1}a_{i,1}\dots a_{i,n}a_{i,n+1}a_{i,n}^{-1}\dots a_{i,1}^{-1}
, the letter
b_{i,n+1}
appears only in the relator
b_{i}^{-1}b_{i,1}b_{i,2}\dots b_{i,2n+1}
, the letter
b_{i,n+1}^{-1}
does not appear at all. It follows that the following is a Tietze transformation:

\langle X_{4}\mid R_{4}\rangle\overset{(T_{2}^{-1})}{\mapsto}\langle X_{5}\mid R_{5}\rangle.

In summary,

X_{5}=\Sigma_{1}\cup\Sigma_{2}\cup\{a_{i,j}:1\leqslant i\leqslant m_{1},1\leqslant j\leqslant n\}\cup\{b_{i,j}:1\leqslant i\leqslant m_{2},1\leqslant j\leqslant 2n+1\text{ and }j\neq n+1\},

and
R_{5}
contains only words from
(\Sigma_{1}\cup\Sigma_{2}\cup\Sigma_{2}^{-1})^{\ast}
. By
Lemma

2.9
,
\langle X_{5}\mid R_{5}\rangle
presents a group isomorphic to
\langle\Sigma_{1}\cup\Sigma_{2}\mid R_{5}\rangle\ast F(\{a_{i,j}:1\leqslant i\leqslant m_{1},1\leqslant j\leqslant n\}\cup\{b_{i,j}:1\leqslant i\leqslant m_{2},1\leqslant j\leqslant 2n+1\text{ and }j\neq n+1\})
. Finally, we note that
\langle X_{5}\mid R_{5}\rangle
presents
G
.
∎

We have now proved the following.

Theorem A
.

Let
G
be a group with finite inverse-closed generating set
\Sigma
and
n\in\mathbb{N}
. Then the rewriting system
\nabla_{n}(G,\Sigma)=(\Sigma(n),T(n))

is inverse-closed confluent and presents a finitely-generated group that is isomorphic to

G\ast F_{n|\Sigma|}
.

Proof.

Follows from
Lemmas

3.6
and
4.1
.
∎

Proposition

4.1

shows that we have not produced any new geodetic groups. On input of a plain group with geodetic generating set into
\mathcal{G}_{n}^{\text{gen}}

5.
Further properties of the construction

In this section we observe some simple facts about the construction, namely: that iterating the construction (applying subdivision again after an initial subdivision) has the same effect as subdividing with a larger number of subintervals; and applying the construction to a free product with a standard geodetic generating set is equivalent to applying the construction to each factor separately then forming the free product.

We start with a straightforward observation.

Lemma 5.1
.

Let
G
be a group with finite inverse-closed generating set
\Sigma
. Then
\text{Cay}(G,\Sigma)\cong\text{Cay}(\mathcal{G}^{\text{gen}}_{0}(G,\Sigma))

Proof.

The bijection
\phi:\Sigma\to\Sigma(0)
given by
\phi(x_{i})\mapsto x_{i,1}
induces a labelled graph isomorphism between the two Cayley graphs.
∎

Proposition 5.3
.

Let

\text{Cay}(\mathcal{G}^{\text{gen}}_{n}(G,\Sigma_{G}))\cong\text{Cay}(\mathcal{G}_{n}(H,\Sigma_{H})\ast\mathcal{G}_{n}(K,\Sigma_{K})),\Sigma_{H}(n)\sqcup\Sigma_{K}(n)).

The construction in

individually to construct the new alphabet, so
\Sigma_{G}(n)=\Sigma_{H}(n)\sqcup\Sigma_{K}(n)
. Furthermore, by inspection of the types of rules in the new rewriting system, we observe
T_{G}(n)=\Sigma_{H}(n)\sqcup\Sigma_{K}(n)
. The labelled graph isomorphism between the two Cayley graphs follows.
∎

6.
Conclusion and outlook

We have presented a way to construct new presentations for free products which yields new geodetic generating sets with interesting properties. While the construction does not furnish examples which can resolve
the conjectures of Madlener and Otto, Shapiro, and Federici respectively,
they give further insight into these difficult open problems.
Since the Cayley graphs we construct are a simple generalisation of trees, they might also find application in parallel computing in place of (or combined with) trees and hypercubes.

The construction is based on subdivision of edges in an existing geodetic graph to construct a new geodetic graphs due to Parathasarathy and Srinvivasan
[
15
]
. There are several other ways to construct new geodetic graphs from existing ones, as in for example

[
11
,
17
,
18
,
21
]
. However these methods only apply to particular types of graphs such as complete graphs and Moore graphs, and they create vertices of different degrees, so cannot be vertex transitive, so will not yield Cayley graphs.

We conclude with two further remarks.
When
n\neq 0
,
\mathcal{G}_{n}(G,\Sigma)
is a group with generating set
\Sigma(n)
whose elements are either order
2
or infinity. If we were to begin with a finite group
G
of odd order with geodetic generating set
\Sigma
, then
\mathcal{G}_{n}(G,\Sigma)\cong G\ast F_{n|\Sigma|}
would be a group with geodetic generating set
\Sigma(n)
that contains no finite order elements, but still contains finite subgroups. Following this idea of removing finite order generators, it is worth noting that by
[
8
, Lemma 3.11]
, any order
2
element of a geodetic group
G
must have a conjugate contained in any geodetic generating set for
G
, and so if the group has order
2
elements a geodetic generating set must contain order
2
elements.

Finally, several authors have considered
the following generalisation of geodetic where
k\in\mathbb{N}_{+}

[
9
,
20
]
. If a graph has at most
k
geodesics between each pair of vertices, then we call a graph
k
-geodetic
. A group is called
k
-geodetic if there exists an inverse-closed generating set such that Cayley graph is
k
-geodetic. See
[
9
]
for some results on this topic. Suppose
k>1
and that
G
is group with
k
-geodetic generating set
\Sigma
that is not a geodetic generating set. It is not hard to see that for all
n>1
this
\text{Cay}(\mathcal{G}_{n}^{\text{gen}}(G,\Sigma))
is not
k
-geodetic for any
k\in\mathbb{N}_{+}
. Note that, to date, the only known examples of
k
-geodetic groups that are not geodetic are finite.
