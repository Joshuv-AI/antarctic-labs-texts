Amortized Linear-time Exact Shapley Value for Product-Kernel Methods
Majid Mohammadi, Siu Lun Chau, Krikamol Muandet

Abstract
Kernel methods are widely used in machine learning and statistics for their flexibility and expressive power, yet their black-box nature limits adoption in high-stakes applications. Shapley value–based attribution methods such as SHAP, and kernel-specific adaptations including RKHS-SHAP, provide a principled framework for explainability—but exact computation of Shapley values is generally intractable, forcing existing approaches to rely on approximations that incur unavoidable estimation error. We introduce PKeX-Shapley, an algorithm that exploits the multiplicative structure of product kernels to compute exact Shapley values for all d d features in quadratic time in d d . The method rests on a distribution-free removal operator intrinsic to the product-kernel structure: removing a feature replaces its kernel factor with the multiplicative identity. This yields a parameter-free value function—requiring no sampling and no density estimation—and uniquely determines a functional decomposition of the model. Building on this value function, we develop shared recursive formulations that evaluate all feature attributions jointly, achieving amortized linear time per feature with numerical stability. Beyond predictive modeling, the framework extends to widely used kernel-based discrepancies such as the Maximum Mean Discrepancy (MMD) and the Hilbert–Schmidt Independence Criterion (HSIC), providing new tools for interpretable statistical analysis.



Keywords: Efficient Shapley value, Kernel methods, Feature attributions

Introduction

Shapley values
(
Shapley, 1953
)
, a solution concept from cooperative game theory, provide a principled axiomatic framework for feature attribution in machine learning (ML)
(
Lundberg and Lee, 2017
;
Covert et al., 2020
)
. Their rigorous foundation has driven widespread adoption in the explainable AI community
(
Sundararajan and Najmi, 2020
)
: a model’s output—predictions, losses, or other quantities of interest—can be

(

)
to model-specific methods that leverage structural properties for statistical or computational gains: TreeSHAP for tree-based models
(
Lundberg et al., 2020
)
, GPSHAP for Gaussian processes
(
Chau et al., 2023
)
, Deep SHAP for deep neural networks
(
Lundberg and Lee, 2017
)
, and, most relevant to our work, RKHS-SHAP for kernel methods
(
Chau et al., 2022
)
. Kernel methods are notable well beyond prediction: they underpin a broad range of statistical inference tasks, including measuring distributional closeness
(
Gretton et al., 2006
;
Naslidnyk et al., 2025
)
, two-sample testing
(
Schrab, 2025
;
Chau et al., 2025
)
, goodness-of-fit testing
(
Chwialkowski et al., 2016
;
Liu et al., 2016
)
, independence testing
(
Albert et al., 2022
)
, and causal inference and discovery
(

;
Zhang et al., 2026
)
. As kernel methods see growing use in high-stakes applications for their flexibility and expressive power, interpretability has become essential.

Despite their rigorous game-theoretic foundation, Shapley values face two major challenges when applied to ML. The first is to define and estimate a value function that quantifies the contribution of a feature coalition. Ideally, this function should capture the model’s behavior when the complementary features are absent. A natural approach retrains the model on each subset and uses the resulting prediction as the value
(
Lipovetsky and Conklin, 2001
)
, but the exponential number of retrainings makes this infeasible. A more practical alternative simulates feature absence via marginal or conditional expectations of the model’s output given the retained subset; see
Sundararajan and Najmi (2020)
for further options.
Chau et al. (2022)
pursue this route in the context of kernel methods, exploiting the structure of reproducing kernel Hilbert spaces (RKHS) and using kernel distributional embeddings
(
Muandet et al., 2017
)
to estimate value functions nonparametrically, thereby avoiding density estimation. An increasingly popular alternative defines the value function through functional decomposition
(
Gevaert and Saeys, 2024
;
Fumagalli et al., 2025
;
Mohammadi et al., 2026
)
, identifying the contribution of a feature subset with the component of the model that depends on those features.

Once a value function is chosen, the second challenge is computing the Shapley values themselves. Exact evaluation requires the value function on all
2^{d}
feature subsets, which quickly becomes prohibitive. Approximation methods—Monte Carlo sampling, regression-based estimators—sidestep the exponential cost by evaluating only a subset of coalitions, but introduce estimation errors that grow with dimensionality

)
. Model-specific structure can sometimes be exploited to recover exactness: TreeSHAP, for instance, leverages tree decompositions for exact polynomial-time computation. RKHS-SHAP improves the statistical estimation of the value function but still relies on regression-based approximation for the Shapley values, inheriting the same computational limitations.

To design an efficient Shapley value–based attribution algorithm for kernel methods, we focus on the subclass employing product kernels—which we call
product-kernel methods
—and introduce
PKeX-Shapley
(
P

K

act

)
. This narrows the scope relative to
Chau et al. (2022)
, which considers generic kernels, but the additional structure lets us address both challenges raised above directly. We first identify the

intrinsic to product-kernel models: removing a feature
j
amounts to replacing its kernel factor by the multiplicative identity,
k_{j}\mapsto 1
. This choice preserves the product structure, requires no background distribution, and induces a parameter-free value function—no sampling, no density estimation. By

Building on this value function, we derive a recursive formulation that computes the Shapley value of a single feature in quadratic time. Organizing these recursions across features via a prefix–suffix construction of elementary symmetric polynomials, we then show that all

As an additional, independent contribution, we demonstrate that our framework extends beyond kernel-based predictive models. In particular, we show how our method applies to popular kernel-based statistical discrepancies, including the Maximum Mean Discrepancy (MMD) and Hilbert–Schmidt Independence Criterion (HSIC), thereby enabling interpretable statistical inference. Background

Notation.

Let
\mathcal{D}
denote the set of
d
features, and
2^{\mathcal{D}}
its power set. The training set
\{(\boldsymbol{x}^{(i)},y^{(i)})\}_{i=1}^{n}
consists of
n

\boldsymbol{x}^{(i)}\in\mathbb{R}^{d}
and
y^{(i)}\in\mathbb{R}
(or a discrete label set for classification). Let
\mathbf{X}\in\mathbb{R}^{n\times d}
be the feature matrix, and
\mathbf{X}_{\mathcal{S}}\in\mathbb{R}^{n\times s}
the submatrix restricted to features in subset
\mathcal{S}\subseteq\mathcal{D}
, and we write
\mathbf{X}_{j}:=\mathbf{X}_{\{j\}}
. We use capital letters for random variables, bold capital letters for matrices, calligraphic letters for sets, and bold lowercase letters for vectors. The restriction of a vector
\boldsymbol{x}
to features in
\mathcal{S}
is denoted by
\boldsymbol{x}_{\mathcal{S}}
. The element-wise product and division are respectively denoted by
\odot
and
\oslash
, and expectation by
\mathbb{E}
. A symmetric positive (semi-)definite kernel function over
\mathcal{D}
is denoted by
k
, and its restriction to a subset
\mathcal{S}
by
k_{\mathcal{S}}
. The corresponding kernel matrices are denoted by
\mathbf{K}
and
\mathbf{K}_{\mathcal{S}}
, respectively. All proofs are provided in Appendix
C
.

Shapley value.

The Shapley value
(
Shapley, 1953
)
is a widely used game-theoretic solution concept for feature attribution in predictive models. It assigns importance to each input feature by averaging its marginal contribution across all feature subsets, weighted by coalition size. Given a value function
v:2^{\mathcal{D}}\to\mathbb{R}
that quantifies the contribution of a feature subset, the Shapley value for feature
j
is

\phi_{j}=\sum_{\mathcal{S}\subseteq\mathcal{D}\setminus\{j\}}\mu(|\mathcal{S}|)\big(v(\mathcal{S}\cup\{j\})-v(\mathcal{S})\big),

(1)

where
\mu(s)=\nicefrac{{s!\,(d-s-1)!}}{{d!}}
and
v(\mathcal{S}\cup\{j\})-v(\mathcal{S})
is the marginal contribution of
j
to
\mathcal{S}
. For any fixed value function, the Shapley value is the unique attribution satisfying efficiency, null player, symmetry, and linearity
(
Shapley, 1953
)
. In explainability, however, the choice of
v
is itself a non-trivial design decision. Several formulations have been proposed
(
Sundararajan and Najmi, 2020
)
; two are dominant. The
interventional
value function
(
Janzing et al., 2020
)
,

v_{\boldsymbol{x}}(\mathcal{S})=\mathbb{E}_{X_{\mathcal{D}\setminus\mathcal{S}}}\!\left[f(\boldsymbol{x}_{\mathcal{S}},X_{\mathcal{D}\setminus\mathcal{S}})\right],

replaces missing features with samples from their marginal distributions, while the
observational
value function
(
Chen et al., 2020
)
,

v_{\boldsymbol{x}}(\mathcal{S})=\mathbb{E}\!\left[f(X)\,\middle|\,X_{\mathcal{S}}=\boldsymbol{x}_{\mathcal{S}}\right],

conditions on the observed features. Both require sampling from marginal or conditional distributions, incurring repeated model evaluations and a dependence on background samples that can substantially shape the resulting explanations
(
Molnar, 2025
, Chapter 21)
.

Functional decomposition.

An increasingly popular alternative defines the value function through a functional decomposition of the learned model
(
Gevaert and Saeys, 2024
;
Fumagalli et al., 2025
;
Mohammadi et al., 2026
)
, expressing
f
as a sum of components indexed by feature subsets,

f(\boldsymbol{x})=\sum_{\mathcal{S}\subseteq\mathcal{D}}f_{\mathcal{S}}(\boldsymbol{x}_{\mathcal{S}}),

where each
f_{\mathcal{S}}
depends only on the variables in
\mathcal{S}
. The value function can then be defined as the Möbius transform of the functional components
\{f_{S}\}
and thus

\nu_{\boldsymbol{x}}(S)=\sum_{\mathcal{T}\subseteq S}f_{\mathcal{T}}(\boldsymbol{x}_{\mathcal{T}}),

aggregating all sub-coalition effects of
S
.

This framing connects Shapley-based attribution to a century of statistical theory: ANOVA
(
St et al., 1989
)
, Sobol indices
(
Owen, 2013
;
Owen, 2014
)
, partial dependence
(
Berzal et al., 2002
)
, and generalized additive models
(
Hastie, 2017
)
are all functional decomposition methods that long predate modern XAI. The advantage is not merely historical. Writing
f
as
\sum_{\mathcal{S}}f_{\mathcal{S}}
makes a
structural
claim about the model that can be inspected componentwise, and many desirable properties of attribution methods, analogues of Shapley’s axioms stated directly in terms of
f
rather than an induced cooperative game, admit clean characterizations at the decomposition level
(
Gevaert and Saeys, 2024
, Section 6.3)
.

Furthermore,
Gevaert and Saeys (2024)
sharpen this picture by establishing a correspondence between functional decompositions and
removal operators
—mappings that render the model independent of a given feature subset. Every removal operator induces a unique decomposition, and every decomposition arises this way. Designing a value function therefore reduces to a single modelling choice: pick a sensible removal operator and read off the decomposition. We adopt the removal-operator perspective. In the next section, we show that the natural removal operator for product-kernel models—replacing each absent kernel factor with the multiplicative identity—yields a parameter-free value function and induces a functional decomposition with a simple closed form.

Exact Shapley Value for Product-Kernel Learning Methods

This section develops an algorithm that computes all
d
Shapley values for product-kernel methods—including support vector machines and kernel ridge regression—in quadratic time in
d
overall, or amortized linear time per feature. The value function is induced by a natural, distribution-free removal operator and admits a closed form, requiring neither sampling nor density estimation.

3.1
Value Function for Product-Kernel Methods

Product-kernel methods rely on kernel functions to capture complex relationships between input features and output. A kernel-based decision function is generally expressed as

f(\boldsymbol{x})=\sum_{i=1}^{n}\alpha_{i}k(\boldsymbol{x},\boldsymbol{x}^{(i)})=\boldsymbol{\alpha}^{\top}k(\mathbf{X},\boldsymbol{x})

where
k
is a kernel function and
\alpha_{i}
are the model-specific coefficients.
When
k
is a product kernel, it can be expressed as:

k(\boldsymbol{x},\boldsymbol{x}^{(i)})=\prod_{j\in\mathcal{D}}k_{j}(x_{j},x^{(i)}_{j}).

Product-kernel methods are widely used in ML for their simplicity and effectiveness in modelling similarities in high-dimensional data
(
Gardner et al., 2018
)
. They also come with strong theoretical guarantees: if the base kernels are universal—capable of approximating any continuous function on the marginal input—then the product kernel inherits this property
(
Szabó and Sriperumbudur, 2018
)
. Several widely used kernels are of product form, including the radial basis function (RBF) with isotropic or anisotropic bandwidth,

k(\boldsymbol{x},\boldsymbol{x}^{\prime})=\exp\!\left(-\|\boldsymbol{x}-\boldsymbol{x}^{\prime}\|^{2}/2\sigma^{2}\right)=\prod_{j=1}^{d}\exp\!\left(-(x_{j}-x^{\prime}_{j})^{2}/2\sigma^{2}\right);

further examples are given in Appendix
A
. For product-kernel methods, we utilize the canonical neutral-factor removal: removing a feature subset
\mathcal{T}
corresponds to replacing each kernel factor
k_{j}
,
j\in\mathcal{T}
, with the multiplicative identity
1
, giving

P_{\mathcal{T}}(f)(\boldsymbol{x})=\boldsymbol{\alpha}^{\top}k_{\mathcal{D}\setminus\mathcal{T}}(\mathbf{X}_{\mathcal{D}\setminus\mathcal{T}},\boldsymbol{x}_{\mathcal{D}\setminus\mathcal{T}}).

This removal preserves the product-kernel structure and requires no background distribution, sampling, or density estimation—absent features contribute a neutral factor. By the canonical additive decomposition framework of
Gevaert and Saeys (2024)
, once this removal family is chosen, it uniquely determines the corresponding functional decomposition via Möbius inversion on the subset lattice. The resulting components are given in Proposition
1
.

Proposition 1
.

The removal operator above induces the functional decomposition
f=\sum_{\mathcal{S}\subseteq\mathcal{D}}f_{\mathcal{S}}
with components

f_{\mathcal{S}}(\boldsymbol{x}_{\mathcal{S}})=\sum_{i=1}^{n}\alpha_{i}\prod_{j\in\mathcal{S}}\bigl(k_{j}(x_{j},x^{(i)}_{j})-1\bigr),

where
f_{\emptyset}=\sum_{i=1}^{n}\alpha_{i}
.

The value function for coalition
\mathcal{S}
is obtained by applying the removal operator to the absent features.

Proposition 2
.

The value function induced by the canonical neutral-factor removal is

v_{\boldsymbol{x}}(\mathcal{S})\;=\;\boldsymbol{\alpha}^{\top}k_{\mathcal{S}}(\mathbf{X}_{\mathcal{S}},\boldsymbol{x}_{\mathcal{S}})-f_{\emptyset},

(2)

where
f_{\emptyset}=\sum_{i=1}^{n}\alpha_{i}
, satisfying
v_{\boldsymbol{x}}(\emptyset)=0
and
v_{\boldsymbol{x}}(\mathcal{D})=f(\boldsymbol{x})-f_{\emptyset}
.

Since
f_{\emptyset}
is constant, it cancels in every marginal contribution
v_{\boldsymbol{x}}(\mathcal{S}\cup\{j\})-v_{\boldsymbol{x}}(\mathcal{S})
and has no effect on the Shapley values. We therefore drop it henceforth and work with
v_{\boldsymbol{x}}(\mathcal{S})=\boldsymbol{\alpha}^{\top}k_{\mathcal{S}}(\mathbf{X}_{\mathcal{S}},\boldsymbol{x}_{\mathcal{S}})
, which is exact and parameter-free: it requires no sampling and no density estimation, and can be evaluated in
O(|\mathcal{S}|\cdot n)
time. Given this value function, we next derive an efficient algorithm to compute exact Shapley values.

3.2
Exact Shapley Values Computation

Building on the value function above, we now show that the Shapley value of any feature admits a recursive form. This recursion underlies the computational gains of our approach and provides the pathway to exact computation.

Theorem 3
.

Let
\mathcal{Z}:=\{\boldsymbol{z}_{1},\ldots,\boldsymbol{z}_{d}\}
with

\boldsymbol{z}_{i}:=k_{i}(\mathbf{X}_{i},x_{i})
,
\mathcal{Z}_{-j}=\mathcal{Z}\setminus\{\boldsymbol{z}_{j}\}
,
and
e_{q}(\mathcal{Z})
the elementary symmetric polynomials (ESPs) of order
q
over
\mathcal{Z}
,
defined as

e_{q}(\mathcal{Z}_{-j})=\frac{1}{q}\sum_{r=1}^{q}(-1)^{r-1}e_{q-r}(\mathcal{Z}_{-j})\odot p_{r}(\mathcal{Z}_{-j}),

where
p_{r}(\mathcal{Z})=\sum_{\boldsymbol{z}_{i}\in\mathcal{Z}}\boldsymbol{z}_{i}^{r}
is the element-wise degree-
r
power sum.
For product-kernel learning methods with coefficients
\boldsymbol{\alpha}
, the Shapley value
\phi_{j}^{\boldsymbol{x}}

for feature
j
of instance
\boldsymbol{x}
under the functional decomposition value function can then be expressed as

\displaystyle\phi_{j}^{\boldsymbol{x}}=\boldsymbol{\alpha}^{\top}\big(\big(\boldsymbol{z}_{j}-\boldsymbol{1}\big)\bigodot\sum_{q=0}^{d-1}\mu(q)\,e_{q}\big(\mathcal{Z}_{-j}\big)\big).

(3)

The recursion follows from Newton’s identities for ESPs
(
Egge, 2019
)
; we defer the details to Appendix
B
. Intuitively, under the functional decomposition value function, the multiplicative structure of the product kernel allows us to factorize the marginal contribution
v_{\boldsymbol{x}}(\mathcal{S}\cup\{j\})-v_{\boldsymbol{x}}(\mathcal{S})
as
\boldsymbol{\alpha}^{\top}\!\big((k_{j}(\mathbf{X}_{j},x_{j})-\boldsymbol{1})\odot k_{\mathcal{S}}(\mathbf{X}_{\mathcal{S}},\boldsymbol{x}_{\mathcal{S}})\big)
. This factorization lets us pull the sum over
\mathcal{S}\subseteq\mathcal{D}\setminus\{j\}
inside the inner product with
\boldsymbol{\alpha}
and express it directly in terms of weighted ESPs
e_{q}(\mathcal{Z}_{-j})
, where
\boldsymbol{z}_{i}=k_{i}(\mathbf{X}_{i},x_{i})
.

From one to all Shapley values.

The recursion in Theorem
3
shows that a
single
Shapley value
\phi_{j}^{\boldsymbol{x}}
can be computed in
O(d^{2})
time, since each
e_{q}
follows from the power sums
p_{r}(\mathcal{Z}_{-j})
via Newton’s identities. Applying this procedure independently to every
j\in\mathcal{D}
, however, ignores substantial overlap between the sets
\mathcal{Z}_{-j}
: the ESPs
e_{q}(\mathcal{Z}_{-j})
across different
j
share many intermediate quantities, which can be reused.

To this end, we develop a numerically stable method that exploits structural properties of ESPs to compute the sum
\sum_{q}\mu(q)e_{q}(\mathcal{Z}_{-j})
from equation (
3
). The key tool is the generating-polynomial representation of ESPs, which organizes interaction terms by degree and makes intermediate quantities reusable across features. For any ordered index set
\mathcal{A}\subseteq\mathcal{D}
, define

p_{\mathcal{A}}(s):=\bigodot_{i\in\mathcal{A}}\big(\boldsymbol{1}+\boldsymbol{z}_{i}\,s\big),

where
s
is a univariate variable. Expanding the product gives

p_{\mathcal{A}}(s)=\sum_{q=0}^{|\mathcal{A}|}e_{q}(\mathcal{A})\,s^{q},

so the coefficient of
s^{q}
is the degree-
q
ESP over the vectors indexed by
\mathcal{A}
. For a fixed index
j\in\mathcal{D}
, we construct the ESPs over
\mathcal{Z}_{-j}
in (
3
) by splitting the remaining vectors into a
prefix
(indices before
j
) and a
suffix
(indices after
j
):

\displaystyle p^{\mathrm{pref}}_{j-1}(s):=\bigodot_{i=1}^{j-1}\big(\boldsymbol{1}+\boldsymbol{z}_{i}\,s\big)=\sum_{t=0}^{j-1}\mathbf{\Gamma}_{j-1,t}\,s^{t},\qquad p^{\mathrm{suf}}_{j+1}(s):=\bigodot_{i=j+1}^{d}\big(\boldsymbol{1}+\boldsymbol{z}_{i}\,s\big)=\sum_{u=0}^{d-j}\mathbf{R}_{j+1,u}\,s^{u},

where
\mathbf{\Gamma}_{j-1,t}
and
\mathbf{R}_{j+1,u}
are the element-wise ESPs of degrees
t
and
u
over the vectors preceding and following index
j
, respectively. The leave-one-out polynomial then factorizes as

p_{-j}(s)=p^{\mathrm{pref}}_{j-1}(s)\odot p^{\mathrm{suf}}_{j+1}(s),

involving only vectors in
\mathcal{Z}_{-j}
by construction.

Shapley value computation thus reduces to evaluating the inner sum of weighted degree-
q
ESPs. The following proposition shows that prefix–suffix polynomial constructions enable the reuse of intermediate ESP quantities across features, yielding efficient computation of all Shapley values.

Proposition 4
.

Let
\mathbf{\Gamma}_{j-1,t}
and
\mathbf{R}_{j+1,u}
be as above, and
\mathbf{G}_{j+1,t}:=\sum_{u=0}^{d-j}\mu(t+u)\,\mathbf{R}_{j+1,u}
. Then

\sum_{q=0}^{d-1}\mu(q)\,e_{q}(\mathcal{Z}_{-j})=\sum_{t=0}^{j-1}\mathbf{\Gamma}_{j-1,t}\odot\mathbf{G}_{j+1,t}.

Time and memory complexity.
Proposition
4
reduces the computation of all Shapley values to constructing the prefix coefficients
\mathbf{\Gamma}_{j,t}
and the aggregated suffix quantities
\mathbf{G}_{j,u}
for
j\in\mathcal{D}
,
t<j
,
u\leq d-j
: given these, each Shapley value can be obtained in linear time. We now show that both quantities admit simple recursive constructions and can themselves be computed in
O(d^{2})
time.

Proposition 5
.

The prefix coefficients
\mathbf{\Gamma}=\{\mathbf{\Gamma}_{j,t}\}
and aggregated suffix quantities
\mathbf{G}=\{\mathbf{G}_{j,t}\}
can be computed and stored in
O(d^{2}n)
time and
O(d^{2}n)
memory.

Proposition
5
shows that the prefix and suffix ESP coefficients can be computed in
O(d^{2}n)
time, after which each Shapley value
\phi_{j}^{\boldsymbol{x}}
is obtained in
O(dn)
time.
Computing all
d
Shapley values therefore costs
O(d^{2}n)
in total, or
O(dn)
per feature on average.

Comparison to TreeSHAP.

A value function with similar multiplicative structure arises in TreeSHAP, where interpolation-based algorithms recover leave-one-out ESPs via polynomial division
(
Bifet et al., 2022
;
Jiang et al., 2025
)
. These methods work well when the polynomial degree is bounded by the tree depth
D\ll d
, giving Linear TreeSHAP an
\mathcal{O}(DL)
per-tree complexity. For product-kernel methods, however, the polynomial degree is
d-1
, and interpolation becomes numerically unstable already at moderate dimensions (e.g.,
d\approx 50
); see Appendix
D
. PKeX-Shapley avoids this by relying only on element-wise additions and multiplications, remaining stable at large
d
with
\mathcal{O}(d^{2}n)
total cost. Notably, applying Linear TreeSHAP to kernel methods would view the model as an ensemble of
n
trees—one per training point, each with depth and leaf count
d
—also yielding
\mathcal{O}(d^{2}n)
overall, but at the cost of the numerical instability above.

Explaining kernel-based statistical discrepancies

We extend the removal-operator framework to two widely used kernel-based statistical discrepancies: the
Maximum Mean Discrepancy
(MMD) and the
Hilbert–Schmidt Independence Criterion
(HSIC). The same principle applies in both cases: removing a feature replaces its kernel factor with the multiplicative identity, yielding a parameter-free value function in closed form. We give the corresponding recursive Shapley formulations based on Newton’s identities; the prefix–suffix construction transfers directly and is omitted for brevity.

4.1
Distributing the discrepancy: Explaining MMD

The MMD quantifies the difference between two probability distributions in terms of their kernel mean embeddings:

\text{MMD}^{2}(\mathbb{P},\mathbb{Q}):=\|\mu_{\mathbb{P}}-\mu_{\mathbb{Q}}\|_{\mathcal{H}_{k}}^{2}

where
\mathcal{H}_{k}
is the RKHS associated with the kernel
k
and
\mu_{\mathbb{P}}:=\int k(\boldsymbol{x},\cdot)\,d\mathbb{P}(\boldsymbol{x})\in\mathcal{H}_{k}
is the kernel mean embedding of
\mathbb{P}

(
Muandet et al., 2017
, Sec. 3.5)
. The embedding
\mu_{\mathbb{Q}}
is defined analogously.
Based on the samples
\{\boldsymbol{x}^{(i)}\}_{i=1}^{n}\sim\mathbb{P}
and
\{\boldsymbol{z}^{(i)}\}_{i=1}^{m}\sim\mathbb{Q}
, the empirical estimate of MMD, expressed entirely in terms of
k
, is given by

\widehat{\text{MMD}}^{2}(\mathbb{P},\mathbb{Q})=\frac{1}{n(n-1)}\sum_{i\neq j}k(\boldsymbol{x}^{(i)},\boldsymbol{x}^{(j)})+\frac{1}{m(m-1)}\sum_{i\neq j}k(\boldsymbol{z}^{(i)},\boldsymbol{z}^{(j)})-\frac{2}{nm}\sum_{i,j}k(\boldsymbol{x}^{(i)},\boldsymbol{z}^{(j)}).

In this section, we propose an attribution method that allocates the overall discrepancy measured by MMD among the variables involved. Such attributions are useful in many settings, including explaining MMD-based test statistics in hypothesis testing
(
Gretton et al., 2012
)
and identifying the variables driving covariate shift
(
Zhang et al., 2020
)
. For a product kernel
k
, removing a feature subset
\mathcal{T}
replaces each factor
k_{q}
,
q\in\mathcal{T}
, with
1
, leaving only the sub-kernel
k_{\mathcal{D}\setminus\mathcal{T}}
. Applied to MMD, this removal induces a natural, parameter-free value function, and the corresponding functional decomposition is uniquely determined.

Theorem 6
.

For product kernel MMD, the removal operator
k_{q}\mapsto 1
for
q\in\mathcal{T}
induces the following:

(i)

The value function representing the contribution of the variables in
\mathcal{S}
is

v_{\text{MMD}}(\mathcal{S})=\frac{1}{n(n-1)}\sum_{i\neq j}k_{\mathcal{S}}(\boldsymbol{x}^{(i)}_{\mathcal{S}},\boldsymbol{x}^{(j)}_{\mathcal{S}})+\frac{1}{m(m-1)}\sum_{i\neq j}k_{\mathcal{S}}(\boldsymbol{z}^{(i)}_{\mathcal{S}},\boldsymbol{z}^{(j)}_{\mathcal{S}})-\frac{2}{nm}\sum_{i,j}k_{\mathcal{S}}(\boldsymbol{x}^{(i)}_{\mathcal{S}},\boldsymbol{z}^{(j)}_{\mathcal{S}}).

(ii)

The MMD function admits the unique functional decomposition into subset contributions induced by this removal operator:

\displaystyle\widehat{\text{MMD}}^{2}(\mathbb{P},\mathbb{Q})=\sum_{\mathcal{S}\subseteq\mathcal{D}}\bigg[\frac{1}{n(n-1)}\sum_{i\neq j}\prod_{q\in\mathcal{S}}\big(k_{q}(x^{(i)}_{q},x^{(j)}_{q})-1\big)

\displaystyle\hskip 18.49988pt+\frac{1}{m(m-1)}\sum_{i\neq j}\prod_{q\in\mathcal{S}}\big(k_{q}(z^{(i)}_{q},z^{(j)}_{q})-1\big)-\frac{2}{nm}\sum_{i,j}\prod_{q\in\mathcal{S}}\big(k_{q}(x^{(i)}_{q},z^{(j)}_{q})-1\big)\bigg].

Applying the same construction as in Theorem
3
to
v_{\mathrm{MMD}}
yields an analogous recursive formulation. For the first term in
v_{\mathrm{MMD}}
, the multiplicative structure of the product kernel gives

v_{\mathrm{MMD}}(\mathcal{S}\cup\{q\})-v_{\mathrm{MMD}}(\mathcal{S})=k_{\mathcal{S}\cup\{q\}}(\boldsymbol{x}^{(i)}_{\mathcal{S}\cup\{q\}},\boldsymbol{x}^{(j)}_{\mathcal{S}\cup\{q\}})-k_{\mathcal{S}}(\boldsymbol{x}^{(i)}_{\mathcal{S}},\boldsymbol{x}^{(j)}_{\mathcal{S}})\\
=\big(k_{q}(x^{(i)}_{q},x^{(j)}_{q})-1\big)\,k_{\mathcal{S}}(\boldsymbol{x}^{(i)}_{\mathcal{S}},\boldsymbol{x}^{(j)}_{\mathcal{S}}).

Pulling
k_{q}(x^{(i)}_{q},x^{(j)}_{q})-1
outside the summation in the Shapley value lets us express the total sum over
\mathcal{S}\subseteq\mathcal{D}\setminus\{q\}
as a weighted ESP. The following proposition formalizes this.

Proposition 7
.

Let
\mathcal{Z}^{(\boldsymbol{x},\boldsymbol{x}^{\prime})}=\{k_{1}(x_{1},x^{\prime}_{1}),\ldots,k_{d}(x_{d},x^{\prime}_{d})\}
, and
e_{r}(\mathcal{Z}_{-q}^{(\boldsymbol{x},\boldsymbol{x}^{\prime})})
determined as

e_{r}(\mathcal{Z}_{-q}^{(\boldsymbol{x},\boldsymbol{x}^{\prime})})=\frac{1}{r}\sum_{s=1}^{r}(-1)^{s-1}e_{r-s}(\mathcal{Z}_{-q}^{(\boldsymbol{x},\boldsymbol{x}^{\prime})})\,p_{s}(\mathcal{Z}_{-q}^{(\boldsymbol{x},\boldsymbol{x}^{\prime})}),

where
p_{s}(\mathcal{Z})=\sum_{z\in\mathcal{Z}}z^{s}
represents the degree-
s
power sum.
Further, let
\gamma_{q}(\boldsymbol{x},\boldsymbol{x}^{\prime})
be defined as

\gamma_{q}(\boldsymbol{x},\boldsymbol{x}^{\prime}):=(k_{q}(x_{q},x^{\prime}_{q})-1)\sum_{r=0}^{d-1}\mu(r)e_{r}(\mathcal{Z}_{-q}^{(\boldsymbol{x},\boldsymbol{x}^{\prime})}).

Then, for product kernels, the Shapley value for the MMD can be recursively computed as

\phi_{q}^{\text{MMD}}=\tfrac{1}{n(n-1)}\sum_{i\neq j}\gamma_{q}(\boldsymbol{x}^{(i)},\boldsymbol{x}^{(j)})+\tfrac{1}{m(m-1)}\sum_{i\neq j}\gamma_{q}(\boldsymbol{z}^{(i)},\boldsymbol{z}^{(j)})-\tfrac{2}{nm}\sum_{i,j}\gamma_{q}(\boldsymbol{x}^{(i)},\boldsymbol{z}^{(j)}).

The Shapley values
\phi_{q}^{\text{MMD}}
allow us to allocate the overall distributional discrepancy between
\mathbb{P}
and
\mathbb{Q}
across the variables, identifying the most influential ones in distinguishing the two distributions.

4.2
Distributing the dependence: Explaining HSIC

The HSIC is a kernel-based dependence measure between two random variables. Let
X
and
Y
be random variables equipped with reproducing product kernels
k(\cdot,\cdot)
and
l(\cdot,\cdot)
, respectively. Then

\mathrm{HSIC}(X,Y):=\|\mathcal{C}_{XY}\|^{2}_{\mathrm{HS}},

where
\mathcal{C}_{XY}
is the cross-covariance operator and
\|\cdot\|_{\mathrm{HS}}
is the Hilbert–Schmidt (HS) norm; see
Muandet et al. (2017, Sec. 3.6)
for technical details. Given a sample
\{(\boldsymbol{x}^{(i)},\boldsymbol{y}^{(i)})\}_{i=1}^{n}\sim\mathbb{P}(X,Y)
, HSIC admits the empirical estimator

\widehat{\mathrm{HSIC}}(X,Y)=\frac{1}{(n-1)^{2}}\,\mathrm{tr}(\mathbf{K}\mathbf{H}\mathbf{L}\mathbf{H}),

where
\mathbf{K},\mathbf{L}\in\mathbb{R}^{n\times n}
are the kernel matrices with
\mathbf{K}_{ij}=k(\boldsymbol{x}^{(i)},\boldsymbol{x}^{(j)})
and
\mathbf{L}_{ij}=l(\boldsymbol{y}^{(i)},\boldsymbol{y}^{(j)})
, and
\mathbf{H}=I-\tfrac{1}{n}\boldsymbol{1}\boldsymbol{1}^{\top}
is the centreing matrix.

Computing
\mathrm{HSIC}(X,Y)
gives the overall dependence between
X
and
Y
. We now consider the setting where
X
is a feature vector
\boldsymbol{x}
and
Y
is a scalar outcome
y
, and ask how the overall dependence can be distributed across the features of
\boldsymbol{x}
. This is particularly useful for feature selection and global sensitivity analysis, where the target is typically univariate.

For a product kernel
k
on
X
, the kernel matrix factorizes element-wise as
\mathbf{K}=\bigodot_{j\in\mathcal{D}}\mathbf{K}_{j}
, where
(\mathbf{K}_{j})_{ab}=k_{j}(x^{(a)}_{j},x^{(b)}_{j})
. Removing feature
j
corresponds to replacing
\mathbf{K}_{j}
with
\boldsymbol{1}\boldsymbol{1}^{\top}
, the all-ones matrix, which is the element-wise multiplicative identity (
\mathbf{A}\odot\boldsymbol{1}\boldsymbol{1}^{\top}=\mathbf{A}
) and the kernel matrix for the constant kernel
k_{j}\equiv 1
. Applied to HSIC, this yields a natural, parameter-free value function, and the corresponding functional decomposition is uniquely determined by this removal operator.

Theorem 8
.

For the HSIC with the product kernel on
X
, the removal operator
\mathbf{K}_{j}\mapsto\boldsymbol{1}\boldsymbol{1}^{\top}
for
j\notin\mathcal{S}
induces the following:

(i)

The value function that quantifies the contribution of the variable set
\mathcal{S}
to the overall dependence is

v_{\text{HSIC}}(\mathcal{S})={(n-1)^{-2}}\mathrm{tr}\big(\mathbf{H}\mathbf{L}\mathbf{H}\mathbf{K}_{\mathcal{S}}\big).

(ii)

The HSIC function admits the unique functional decomposition into subset contributions induced by this removal operator:

\widehat{\text{HSIC}}(X,Y)=\frac{1}{(n-1)^{2}}\sum_{\mathcal{S}\subseteq\mathcal{D}}\mathrm{tr}\bigg(\mathbf{H}\mathbf{L}\mathbf{H}\bigodot_{j\in\mathcal{S}}(\mathbf{K}_{j}-\boldsymbol{1}\boldsymbol{1}^{\top})\bigg).

Applying the same trick as in Proposition
7
to the value function
v_{\text{HSIC}}

yields a similar recursive formulation of Shapley values for HSIC.

Proposition 9
.

For the product kernel, the Shapley value for HSIC can be recursively computed as:

\phi_{j}^{\text{HSIC}}=\frac{1}{(n-1)^{2}}\mathrm{tr}\left(\mathbf{H}\mathbf{L}\mathbf{H}\bigg((\mathbf{K}_{j}-\boldsymbol{1}\boldsymbol{1}^{\top})\bigodot\sum_{q=0}^{d-1}\mu(q)E_{q}(\mathcal{K}_{-j})\bigg)\right).

where
\mathcal{K}=\{\mathbf{K}_{1},\dots,\mathbf{K}_{d}\}
with
\mathbf{K}_{i}
being the kernel matrix for feature
i
only, and

E_{q}(\mathcal{K}_{-j})=\frac{1}{q}\sum_{r=1}^{q}(-1)^{r-1}E_{q-r}(\mathcal{K}_{-j})\bigodot P_{r}(\mathcal{K}_{-j}),

is the ESPs with
P_{r}(\mathcal{K})=\sum_{\mathbf{K}_{i}\in\mathcal{K}}\mathbf{K}_{i}^{r}
being the element-wise degree-
r
power sum.

The Shapley values
\phi_{j}^{\text{HSIC}}
allow us to allocate the overall dependence between
X
and
Y
across individual features fairly, identifying the most influential ones for prediction. Our results can be generalized to scenarios when both
X
and
Y
are multivariate. The attribution of overall dependence to the involved multivariate variables has other applications in statistical inference as well, e.g., kernel-based (conditional) independence testing
(
Albert et al., 2022
;
Gretton et al., 2007
)
.

Conclusion, Limitation, and Discussion

This work introduces PKeX-Shapley, an algorithm that computes exact Shapley values for all
d
features of product-kernel methods in
O(d^{2}n)
time—amortised linear time per feature. The method rests on a distribution-free removal operator intrinsic to the product-kernel structure: replacing each absent feature’s kernel factor with the multiplicative identity. This yields a parameter-free value function requiring no sampling, and uniquely determines the corresponding functional decomposition of the model. Recursive algorithms then compute all attributions jointly. The framework extends to kernel-based statistical discrepancies—MMD and HSIC—enabling exact and efficient interpretability of distributional differences and dependence.

The main limitation is that the algorithm applies only to product kernels. This trade-off is largely unavoidable: tractable computation requires structural constraints. We see several directions for future work. The first is to explore whether the product-kernel assumption can be relaxed without sacrificing tractability. A second is to extend the approach to higher-order attribution methods such as Shapley interaction indices
(
Sundararajan et al., 2020
;
Muschalik et al., 2024
)
. A third is to investigate whether our computational techniques can accelerate other explanation methods, including partial dependence plots and integrated gradients.

Appendix A
Product Kernels in Kernel Methods

Product kernels provide a powerful mechanism for constructing high-dimensional similarity measures by combining kernels defined on individual dimensions or feature subsets. This section discusses key examples of product kernels.

Radial Basis Function (RBF) Kernels as Product Kernels

The RBF kernel is a canonical example of product kernels. The RBF kernel is defined based on a distance metric between two instances, with the two well-known metrics being Euclidean (L2 norm) and Manhattan distances (L1 norm). We refer to the former as RBF, and the latter as Laplacian RBF to distinguish these two kernel functions. In addition, when we have only one kernel bandwidth parameter
\sigma
, the RBF kernel is referred to as
isotropic
. The RBF kernel with both distance metrics inherently decomposes into products of univariate kernels across dimensions:

•

RBF Kernel
:

\displaystyle K_{\text{RBF}}(\boldsymbol{x},\boldsymbol{z})=\exp\left(-\frac{\|\boldsymbol{x}-\boldsymbol{z}\|^{2}}{2\sigma^{2}}\right)=\prod_{i=1}^{d}\exp\left(-\frac{(x_{i}-z_{i})^{2}}{2\sigma^{2}}\right).

•

Laplacian RBF Kernel
:

K_{\text{Laplacian RBF}}(\boldsymbol{x},\boldsymbol{z})=\exp\left(-\frac{\|\boldsymbol{x}-\boldsymbol{z}\|_{1}}{\sigma}\right)=\prod_{i=1}^{d}\exp\left(-\frac{|x_{i}-z_{i}|}{\sigma}\right).

When alternative distance metrics are incorporated into the RBF kernel, such as the Mahalanobis distance, which involves a covariance matrix, the resulting kernel might lose its product decomposition.

Automatic Relevance Determination (ARD) in Gaussian Processes

ARD extends RBF kernels by assigning independent length-scale parameters
\sigma_{i}
to each dimension:

K_{\text{ARD}}(\boldsymbol{x},\boldsymbol{z})=\exp\left(-\sum_{i=1}^{d}\frac{(x_{i}-z_{i})^{2}}{2\sigma_{i}^{2}}\right)=\prod_{i=1}^{d}\exp\left(-\frac{(x_{i}-z_{i})^{2}}{2\sigma_{i}^{2}}\right).

The ARD is extensively used in Gaussian processes for feature selection via learned
\sigma_{i}
, and to enhance interpretability and adaptability. ARD is also referred to as
anisotropic
.

Cauchy Kernel

The Cauchy kernel, inspired by the Cauchy distribution, is another example of a product kernel:

K_{\text{Cauchy}}(\boldsymbol{x},\boldsymbol{z})=\prod_{i=1}^{d}\frac{1}{1+\frac{(x_{i}-z_{i})^{2}}{\sigma^{2}}}.

Product of Base Kernels

A popular way for constructing product kernels is by first defining a base kernel for each individual feature and then computing the overall kernel function by multiplying the base kernels over individual features. The product of PSD kernels remains PSD by the Schur product theorem:

K(\boldsymbol{x},\boldsymbol{z})=\prod_{i=1}^{d}K_{i}(x_{i},z_{i}).

This type of kernel introduces flexibility in combining base kernels while maintaining validity as a (product) kernel function.

Appendix B
Newton’s Identities

To explain Newton’s identities, we begin with a specific set of variables
\mathcal{Z}_{4}=\{z_{1},z_{2},z_{3},z_{4}\}
before generalizing it to sets of arbitrary size
\mathcal{Z}_{d}=\{z_{1},z_{2},\ldots,z_{d}\}
.
The
elementary symmetric polynomials
(ESPs) of degree
q
is defined as

e_{q}(\mathcal{Z}_{4})=\sum_{1\leq i_{1}<i_{2}<\cdots<i_{q}\leq 4}z_{i_{1}}z_{i_{2}}\cdots z_{i_{q}},

with the conventions
e_{0}(\mathcal{Z}_{4})=1
and
e_{q}(\mathcal{Z}_{4})=0
for
q>4
. For example:

\displaystyle e_{1}(\mathcal{Z}_{4})=z_{1}+z_{2}+z_{3}+z_{4},

\displaystyle e_{2}(\mathcal{Z}_{4})=z_{1}z_{2}+z_{1}z_{3}+z_{1}z_{4}+z_{2}z_{3}+z_{2}z_{4}+z_{3}z_{4},

\displaystyle e_{4}(\mathcal{Z}_{4})=z_{1}z_{2}z_{3}z_{4}.

The
power sum
of degree
r
is given by

p_{r}(\mathcal{Z}_{4})=z_{1}^{r}+z_{2}^{r}+z_{3}^{r}+z_{4}^{r}.

In particular,
p_{1}(\mathcal{Z}_{4})=e_{1}(\mathcal{Z}_{4})
and, for example,
p_{2}(\mathcal{Z}_{4})=z_{1}^{2}+z_{2}^{2}+z_{3}^{2}+z_{4}^{2}
.
Then, Newton’s identities relate the ESPs to the power sum recursively. For
q\geq 1
,

e_{q}(\mathcal{Z}_{4})=\frac{1}{q}\sum_{r=1}^{q}(-1)^{r-1}e_{q-r}(\mathcal{Z}_{4})\,p_{r}(\mathcal{Z}_{4}).

For the set
\mathcal{Z}_{4}=\{z_{1},z_{2},z_{3},z_{4}\}
, the identities yield:

\displaystyle e_{1}(\mathcal{Z}_{4})

\displaystyle=\frac{1}{1}[e_{0}(\mathcal{Z}_{4})\,p_{1}(\mathcal{Z}_{4})]=p_{1}(\mathcal{Z}_{4})=z_{1}+z_{2}+z_{3}+z_{4},

\displaystyle e_{2}(\mathcal{Z}_{4})

\displaystyle=\frac{1}{2}\Big[e_{1}(\mathcal{Z}_{4})\,p_{1}(\mathcal{Z}_{4})-e_{0}(\mathcal{Z}_{4})\,p_{2}(\mathcal{Z}_{4})\Big]

\displaystyle\hskip 9.24994pt=\frac{(z_{1}+z_{2}+z_{3}+z_{4})^{2}-(z_{1}^{2}+z_{2}^{2}+z_{3}^{2}+z_{4}^{2})}{2},

\displaystyle e_{3}(\mathcal{Z}_{4})

\displaystyle=\frac{1}{3}\Big[e_{2}(\mathcal{Z}_{4})\,p_{1}(\mathcal{Z}_{4})-e_{1}(\mathcal{Z}_{4})\,p_{2}(\mathcal{Z}_{4})+e_{0}(\mathcal{Z}_{4})\,p_{3}(\mathcal{Z}_{4})\Big],

\displaystyle e_{4}(\mathcal{Z}_{4})

\displaystyle=\frac{1}{4}\Big[e_{3}(\mathcal{Z}_{4})\,p_{1}(\mathcal{Z}_{4})-e_{2}(\mathcal{Z}_{4})\,p_{2}(\mathcal{Z}_{4})

\displaystyle\hskip 18.49988pt+e_{1}(\mathcal{Z}_{4})\,p_{3}(\mathcal{Z}_{4})-e_{0}(\mathcal{Z}_{4})\,p_{4}(\mathcal{Z}_{4})\Big].

The identities presented above can be extended to sets of arbitrary size
\mathcal{Z}_{d}=\{z_{1},z_{2},\dots,z_{d}\}
as

e_{q}(\mathcal{Z}_{d})=\frac{1}{q}\sum_{r=1}^{q}(-1)^{r-1}e_{q-r}(\mathcal{Z}_{d})\,p_{r}(\mathcal{Z}_{d}),\quad\text{for }q\geq 1,

with
e_{0}(\mathcal{Z}_{d})=1
and
e_{q}(\mathcal{Z}_{d})=0
if
q>d
or
q<0
.

Appendix C
Proofs

This section provides the detailed proofs of the theoretical results presented in the main paper. First of all, we present a theorem that plays a key role in the other proofs.

Proposition 10
.

Let the kernel function for feature
j
be denoted by
k_{j}(x_{j},x^{\prime}_{j})
, and
\prod_{j\in\emptyset}(k_{j}(x_{j},x^{\prime}_{j})-1)=1
by convention. Then, the following equation holds for product kernel functions:

\prod_{j\in\mathcal{D}}k_{j}(x_{j},x^{\prime}_{j})=\sum_{\mathcal{S}\subseteq\mathcal{D}}\prod_{j\in\mathcal{S}}(k_{j}(x_{j},x^{\prime}_{j})-1).

Proof.

We prove the statement by induction on
|\mathcal{D}|
.

Base case
(|\mathcal{D}|=1)
:
Let
\mathcal{D}=\{j\}
. Then

k_{j}(x_{j},x^{\prime}_{j})=1+(k_{j}(x_{j},x^{\prime}_{j})-1),

as desired.

Inductive step:
Assume the equation holds for any set of size
n
. Consider a set
\mathcal{D}
with size
n+1
, and let
a\in\mathcal{D}
. We write:

\prod_{j\in\mathcal{D}}k_{j}(x_{j},x^{\prime}_{j})=k_{a}(x_{a},x^{\prime}_{a})\prod_{j\in\mathcal{D}\setminus\{a\}}k_{j}(x_{j},x^{\prime}_{j}).

Using the induction hypothesis for
\mathcal{D}\setminus\{a\}
, we have

\prod_{j\in\mathcal{D}}k_{j}(x_{j},x^{\prime}_{j})=k_{a}(x_{a},x^{\prime}_{a})\sum_{\mathcal{T}\subseteq\mathcal{D}\setminus\{a\}}\prod_{j\in\mathcal{T}}(k_{j}(x_{j},x^{\prime}_{j})-1).

Since
k_{a}(x_{a},x^{\prime}_{a})=(k_{a}(x_{a},x^{\prime}_{a})-1)+1
, expanding gives:

\prod_{j\in\mathcal{D}}k_{j}(x_{j},x^{\prime}_{j})=\left[(k_{a}(x_{a},x^{\prime}_{a})-1)+1\right]\sum_{\mathcal{T}\subseteq\mathcal{D}\setminus\{a\}}\prod_{j\in\mathcal{T}}(k_{j}(x_{j},x^{\prime}_{j})-1).

Expanding this product, we obtain:

\prod_{j\in\mathcal{D}}k_{j}(x_{j},x^{\prime}_{j})=\sum_{\mathcal{T}\subseteq\mathcal{D}\setminus\{a\}}(k_{a}(x_{a},x^{\prime}_{a})-1)\prod_{j\in\mathcal{T}}(k_{j}(x_{j},x^{\prime}_{j})-1)\>+\sum_{\mathcal{T}\subseteq\mathcal{D}\setminus\{a\}}\prod_{j\in\mathcal{T}}(k_{j}(x_{j},x^{\prime}_{j})-1).

The first sum on the right-hand side of the equation covers all subsets that contain
a
, and the second sum covers all subsets that do not contain
a
. Thus, together they sum over all subsets
\mathcal{\mathcal{S}}\subseteq\mathcal{\mathcal{D}}
:

\prod_{j\in\mathcal{D}}k_{j}(x_{j},x^{\prime}_{j})=\sum_{\mathcal{S}\subseteq\mathcal{D}}\prod_{j\in\mathcal{S}}(k_{j}(x_{j},x^{\prime}_{j})-1).

Thus, by induction, the theorem is proved. ∎

We now provide the proofs for all the theorems and lemmas in the manuscript.

Proof of Proposition
1

Using the product kernel, the decision function can be rewritten as:

f(\boldsymbol{x})=\sum_{i=1}^{n}\alpha_{i}\prod_{j\in\mathcal{D}}k_{j}(x_{j},x^{(i)}_{j}).

Expanding the product using Proposition
10
:

\prod_{j\in\mathcal{D}}k_{j}(x_{j},x^{(i)}_{j})=\sum_{\mathcal{S}\subseteq\mathcal{D}}\prod_{j\in\mathcal{S}}\big(k_{j}(x_{j},x^{(i)}_{j})-1\big).

Substituting this expansion into the decision function:

f(\boldsymbol{x})=\sum_{i=1}^{n}\alpha_{i}\sum_{\mathcal{S}\subseteq\mathcal{D}}\prod_{j\in\mathcal{S}}\big(k_{j}(x_{j},x^{(i)}_{j})-1\big).

Rearranging the summations:

f(\boldsymbol{x})=\sum_{\mathcal{S}\subseteq\mathcal{D}}\sum_{i=1}^{n}\alpha_{i}\prod_{j\in\mathcal{S}}\big(k_{j}(x_{j},x^{(i)}_{j})-1\big).

This establishes the functional decomposition:

f(\boldsymbol{x})=\sum_{\mathcal{S}\subseteq\mathcal{D}}f_{\mathcal{S}}(\boldsymbol{x}_{\mathcal{S}}),

where each term is defined as:

f_{\mathcal{S}}(\boldsymbol{x}_{\mathcal{S}})=\sum_{i=1}^{n}\alpha_{i}\prod_{j\in\mathcal{S}}\big(k_{j}(x_{j},x^{(i)}_{j})-1\big).

This establishes the existence of the decomposition. To see uniqueness relative to the chosen removal family, let
R_{\mathcal{S}}f:=P_{\mathcal{D}\setminus\mathcal{S}}f
. By the canonical additive decomposition (CAD) construction of
Gevaert and Saeys (2024)
, the induced components satisfy

R_{\mathcal{S}}f(\boldsymbol{x})=\sum_{\mathcal{T}\subseteq\mathcal{S}}f_{\mathcal{T}}(\boldsymbol{x}_{\mathcal{T}}),\qquad\mathcal{S}\subseteq\mathcal{D}.

By Möbius inversion on the subset lattice,

f_{\mathcal{S}}(\boldsymbol{x}_{\mathcal{S}})=\sum_{\mathcal{T}\subseteq\mathcal{S}}(-1)^{|\mathcal{S}|-|\mathcal{T}|}R_{\mathcal{T}}f(\boldsymbol{x}).

For the product-kernel removal,
R_{\mathcal{T}}f(\boldsymbol{x})=\boldsymbol{\alpha}^{\top}k_{\mathcal{T}}(\mathbf{X}_{\mathcal{T}},\boldsymbol{x}_{\mathcal{T}})
, so

f_{\mathcal{S}}(\boldsymbol{x}_{\mathcal{S}})=\boldsymbol{\alpha}^{\top}\sum_{\mathcal{T}\subseteq\mathcal{S}}(-1)^{|\mathcal{S}|-|\mathcal{T}|}\bigodot_{j\in\mathcal{T}}\boldsymbol{z}_{j}=\sum_{i=1}^{n}\alpha_{i}\prod_{j\in\mathcal{S}}\bigl(k_{j}(x_{j},x_{j}^{(i)})-1\bigr),

where the last equality is the standard inclusion-exclusion identity
\sum_{\mathcal{T}\subseteq\mathcal{S}}(-1)^{|\mathcal{S}|-|\mathcal{T}|}\prod_{j\in\mathcal{T}}z_{j}=\prod_{j\in\mathcal{S}}(z_{j}-1)
. Thus these are the unique CAD components induced by the chosen removal family. ∎

Proof of Proposition
2

By Proposition
1
, the product-kernel predictor admits the functional decomposition

f(\boldsymbol{x})=\sum_{\mathcal{T}\subseteq\mathcal{D}}f_{\mathcal{T}}(\boldsymbol{x}_{\mathcal{T}}),\qquad f_{\mathcal{T}}(\boldsymbol{x}_{\mathcal{T}})=\sum_{i=1}^{n}\alpha_{i}\prod_{j\in\mathcal{T}}\big(k_{j}(x_{j},x_{j}^{(i)})-1\big).

Following the decomposition-based removal view of
Gevaert and Saeys (2024)
, removing the variables in

\mathcal{D}\setminus\mathcal{S}
retains only those decomposition components whose support is contained in
\mathcal{S}
. Hence,

P_{\mathcal{D}\setminus\mathcal{S}}(f)(\boldsymbol{x}):=\sum_{\mathcal{T}\subseteq\mathcal{S}}f_{\mathcal{T}}(\boldsymbol{x}_{\mathcal{T}}).

Substituting the product-kernel components gives

\displaystyle P_{\mathcal{D}\setminus\mathcal{S}}(f)(\boldsymbol{x})

\displaystyle=\sum_{\mathcal{T}\subseteq\mathcal{S}}\sum_{i=1}^{n}\alpha_{i}\prod_{j\in\mathcal{T}}\big(k_{j}(x_{j},x_{j}^{(i)})-1\big)

\displaystyle=\sum_{i=1}^{n}\alpha_{i}\sum_{\mathcal{T}\subseteq\mathcal{S}}\prod_{j\in\mathcal{T}}\big(k_{j}(x_{j},x_{j}^{(i)})-1\big).

For each fixed
i
, the inner sum expands as

\sum_{\mathcal{T}\subseteq\mathcal{S}}\prod_{j\in\mathcal{T}}\big(k_{j}(x_{j},x_{j}^{(i)})-1\big)=\prod_{j\in\mathcal{S}}\left(1+\big(k_{j}(x_{j},x_{j}^{(i)})-1\big)\right)=\prod_{j\in\mathcal{S}}k_{j}(x_{j},x_{j}^{(i)}).

Therefore,

P_{\mathcal{D}\setminus\mathcal{S}}(f)(\boldsymbol{x})=\sum_{i=1}^{n}\alpha_{i}\prod_{j\in\mathcal{S}}k_{j}(x_{j},x_{j}^{(i)})=\boldsymbol{\alpha}^{\top}k_{\mathcal{S}}(\mathbf{X}_{\mathcal{S}},\boldsymbol{x}_{\mathcal{S}}).

Thus, for product-kernel models, decomposition-based removal is algebraically equivalent to replacing all absent kernel factors by the multiplicative identity
1
. This is natural since
k_{j}=1
is the neutral element for the multiplicative structure.

Following the pointwise cooperative-game construction induced by the removal operator
(
Gevaert and Saeys, 2024
, Definition 40)
, we define

v_{\boldsymbol{x}}(\mathcal{S})=P_{\mathcal{D}\setminus\mathcal{S}}(f)(\boldsymbol{x})-P_{\mathcal{D}}(f)(\boldsymbol{x}).

Since

P_{\mathcal{D}}(f)(\boldsymbol{x})=f_{\emptyset}=\sum_{i=1}^{n}\alpha_{i},

we obtain

v_{\boldsymbol{x}}(\mathcal{S})=\boldsymbol{\alpha}^{\top}k_{\mathcal{S}}(\mathbf{X}_{\mathcal{S}},\boldsymbol{x}_{\mathcal{S}})-f_{\emptyset}.

In particular,

v_{\boldsymbol{x}}(\emptyset)=f_{\emptyset}-f_{\emptyset}=0,\qquad v_{\boldsymbol{x}}(\mathcal{D})=f(\boldsymbol{x})-f_{\emptyset}.

This proves the claimed value function.

Proof of Proposition
4

To justify the decomposition of
e_{q}(\mathcal{Z}_{-j})
into prefix and suffix contributions, we start from the polynomial representation introduced in the main body. Consider the leave-one-out polynomial

p_{-j}(s):=\bigodot_{i\in\mathcal{D}\setminus\{j\}}\big(\boldsymbol{1}+\boldsymbol{z}_{i}\,s\big),

whose coefficient of
s^{q}
is, by definition, the degree-
q
ESP
e_{q}(\mathcal{Z}_{-j})
.
Since
\mathcal{D}\setminus\{j\}=\{1,\dots,j-1\}\cup\{j+1,\dots,d\}
is a disjoint union, the polynomial
p_{-j}(s)
factorizes as the product of a prefix and a suffix polynomial,

p_{-j}(s)=\left(\bigodot_{i=1}^{j-1}\big(\boldsymbol{1}+\boldsymbol{z}_{i}\,s\big)\right)\bigodot\left(\bigodot_{i=j+1}^{d}\big(\boldsymbol{1}+\boldsymbol{z}_{i}\,s\big)\right).

Using the definitions of the prefix and suffix polynomials, this can be written as

p_{-j}(s)=\left(\sum_{t=0}^{j-1}\mathbf{\Gamma}_{j-1,t}\,s^{t}\right)\odot\left(\sum_{u=0}^{d-j}\mathbf{R}_{j+1,u}\,s^{u}\right).

Expanding the product yields

p_{-j}(s)=\sum_{t=0}^{j-1}\sum_{u=0}^{d-j}\big(\mathbf{\Gamma}_{j-1,t}\odot\mathbf{R}_{j+1,u}\big)\,s^{t+u}.

Collecting terms with the same total degree
q=t+u
, the coefficient of
s^{q}
is therefore given by

e_{q}(\mathcal{Z}_{-j})=\sum_{\begin{subarray}{c}t,u\geq 0\\
t+u=q\end{subarray}}\mathbf{\Gamma}_{j-1,t}\odot\mathbf{R}_{j+1,u},

where only indices
t\in\{0,\dots,j-1\}
and
u\in\{0,\dots,d-j\}
contribute nonzero terms. This establishes the claimed prefix–suffix decomposition of the ESPs over
\mathcal{Z}_{-j}
.

Substituting this expression into
\sum_{q=0}^{d-1}\mu(q)\,e_{q}(\mathcal{Z}_{-j})
yields

\displaystyle\sum_{q=0}^{d-1}\mu(q)\,e_{q}(\mathcal{Z}_{-j})

\displaystyle=\sum_{q=0}^{d-1}\mu(q)\sum_{\begin{subarray}{c}t,u\geq 0\\
t+u=q\end{subarray}}\mathbf{\Gamma}_{j-1,t}\odot\mathbf{R}_{j+1,u}

\displaystyle=\sum_{t=0}^{j-1}\sum_{u=0}^{d-j}\mu(t+u)\,\big(\mathbf{\Gamma}_{j-1,t}\odot\mathbf{R}_{j+1,u}\big).

For fixed
t
, the factor
\mathbf{\Gamma}_{j-1,t}
does not depend on
u
and can be factored out of the inner sum, giving

\sum_{q=0}^{d-1}\mu(q)\,e_{q}(\mathcal{Z}_{-j})=\sum_{t=0}^{j-1}\mathbf{\Gamma}_{j-1,t}\odot\left(\sum_{u=0}^{d-j}\mu(t+u)\,\mathbf{R}_{j+1,u}\right).

Recognizing the inner term as
\mathbf{G}_{j+1,t}
completes the proof.

Proof of Proposition
5

The prefix coefficients
\mathbf{\Gamma}_{j,t}
arise as the polynomial coefficients of the prefix polynomial

p^{\mathrm{pref}}_{j}(s)=\bigodot_{i=1}^{j}(\boldsymbol{1}+\boldsymbol{z}_{i}s)=\sum_{t=0}^{j}\mathbf{\Gamma}_{j,t}s^{t}.

Multiplying
p^{\mathrm{pref}}_{j-1}(s)
by
(\boldsymbol{1}+\boldsymbol{z}_{j}s)
and matching coefficients of equal powers of
s
yields the recurrence

\mathbf{\Gamma}_{j,t}=\mathbf{\Gamma}_{j-1,t}+\boldsymbol{z}_{j}\odot\mathbf{\Gamma}_{j-1,t-1},\qquad j=1,\dots,d,

with the convention
\mathbf{\Gamma}_{j,-1}=\mathbf{0}
. This allows all prefix coefficients to be computed in a single forward pass. The aggregated suffix quantities are defined from the suffix ESPs by

\mathbf{G}_{j,t}:=\sum_{u=0}^{d-j+1}\mu(t+u)\,\mathbf{R}_{j,u}.

The suffix ESP
\mathbf{R}
has a similar recurrence to
\mathbf{\Gamma}
. Substituting the suffix recurrence

\mathbf{R}_{j,u}=\mathbf{R}_{j+1,u}+\boldsymbol{z}_{j}\odot\mathbf{R}_{j+1,u-1}

into this definition gives

\displaystyle\mathbf{G}_{j,t}

\displaystyle=\sum_{u}\mu(t+u)\Big(\mathbf{R}_{j+1,u}+\boldsymbol{z}_{j}\odot\mathbf{R}_{j+1,u-1}\Big)

\displaystyle=\underbrace{\sum_{u}\mu(t+u)\mathbf{R}_{j+1,u}}_{=\,\mathbf{G}_{j+1,t}}+\boldsymbol{z}_{j}\odot\underbrace{\sum_{u\geq 1}\mu(t+u)\mathbf{R}_{j+1,u-1}}_{=\,\mathbf{G}_{j+1,t+1}},

where the second identity follows from the index shift
u\mapsto u-1
. Consequently,
\mathbf{G}
satisfies the backward recursion

\mathbf{G}_{j,t}=\mathbf{G}_{j+1,t}+\boldsymbol{z}_{j}\odot\mathbf{G}_{j+1,t+1},\qquad j=d,\dots,1,

with boundary condition
\mathbf{G}_{d+1,t}=\mu(t)\boldsymbol{1}
induced by the empty-suffix polynomial.

We set
\mu(q)=0
for
q\notin\{0,\ldots,d-1\}
so the boundary terms in the backward recurrence vanish automatically. Using these recursive formulations, computing and storing the triangular tables
\mathbf{\Gamma}
and
\mathbf{G}
requires
O(d^{2}n)
time and
O(d^{2}n)
memory, since each table entry
\mathbf{\Gamma}_{j,t}
or
\mathbf{G}_{j,t}
is a vector in
\mathbb{R}^{n}
. Given
\mathbf{\Gamma}
and
\mathbf{G}
, each Shapley value
\phi_{j}^{\boldsymbol{x}}
can be computed on the fly in
O(dn)
time and
O(n)
additional memory. Therefore, the overall time complexity for computing all
d
Shapley values is
O(d^{2}n)
.

\mathcal{K}=\{\mathbf{K}_{1},...,\mathbf{K}_{d}\}
, we express:

\sum_{\begin{subarray}{c}\mathcal{S}\subseteq\mathcal{D}\setminus\{j\}\\
|\mathcal{S}|=q\end{subarray}}\mathbf{K}_{\mathcal{S}}=E_{q}(\mathcal{K}_{-j}),

which is computed recursively via Newton’s identities, with base case
E_{0}(\mathcal{K}_{-j})=\boldsymbol{1}\boldsymbol{1}^{\top}
and for
q\geq 1
:

E_{q}(\mathcal{K}_{-j})=\frac{1}{q}\sum_{r=1}^{q}(-1)^{r-1}E_{q-r}(\mathcal{K}_{-j})\odot P_{r}(\mathcal{K}_{-j}),

where
P_{r}(\mathcal{K})=\sum_{\mathbf{K}_{i}\in\mathcal{K}}\mathbf{K}_{i}^{\odot r}
is the element-wise power sum (with
\mathbf{K}_{i}^{\odot r}
denoting the element-wise
r
-th power of
\mathbf{K}_{i}
). Substituting this back, we obtain:

\phi_{j}^{\text{HSIC}}=\frac{1}{(n-1)^{2}}\mathrm{tr}\left(\mathbf{H}\mathbf{L}\mathbf{H}\bigg((\mathbf{K}_{j}-\boldsymbol{1}\boldsymbol{1}^{\top})\bigodot\sum_{q=0}^{d-1}\mu(q)E_{q}(\mathcal{K}_{-j})\bigg)\right),

which completes the proof. ∎

Appendix D
Interpolation-Based ESP Recovery Methods

This appendix describes the polynomial interpolation approaches used to recover the elementary symmetric polynomials (ESPs) appearing in the recursive Shapley formulation of Theorem
3
. Both the Chebyshev and Fourier constructions encode the ESPs

\{e_{q}(\mathcal{Z}_{-j})\}_{q=0}^{d-1},\qquad j\in\{1,\dots,d\},

as the coefficients of a univariate polynomial and attempt to reconstruct these coefficients from evaluations of the polynomial at a fixed set of interpolation nodes. Although highly effective for tree-based models—where the relevant polynomial degree is the depth of the tree—these methods become numerically unstable for product kernels, where the polynomial degree equals
d-1
, the total number of features. We describe each method in detail and analyze its numerical behavior.

D.1
Chebyshev Interpolation

Polynomial Representation.

Theorem
3
shows that the Shapley value for feature
j
involves the weighted sum

\sum_{q=0}^{d-1}\mu(q)\,e_{q}(\mathcal{Z}_{-j}),

where
e_{q}(\mathcal{Z}_{-j})
is the degree-
q
ESP over the leave-one-out set
\mathcal{Z}_{-j}=\mathcal{Z}\setminus\{\boldsymbol{z}_{j}\}
. Define the polynomial

H_{j}(y)\;:=\;\sum_{q=0}^{D}e_{q}(\mathcal{Z}_{-j})\,y^{q},\qquad D:=d-1.

Recovering the ESPs
\{e_{q}(\mathcal{Z}_{-j})\}
is therefore equivalent to recovering the coefficient vector of
H_{j}
.

Interpolation at Chebyshev Nodes.

Let

y_{\ell}=\cos\!\left(\frac{\pi\ell}{D}\right),\qquad\ell=0,\dots,D,

be the
(D+1)
Chebyshev points of the second kind on
[-1,1]
. Evaluating the polynomial at these nodes yields

g_{j,\ell}=H_{j}(y_{\ell})=\sum_{q=0}^{D}e_{q}(\mathcal{Z}_{-j})\,y_{\ell}^{q}.

Define the vector
e^{(-j)}=(e_{0}(\mathcal{Z}_{-j}),\dots,e_{D}(\mathcal{Z}_{-j}))^{\top}
and the Chebyshev–Vandermonde matrix
V\in\mathbb{R}^{(D+1)\times(D+1)}
with entries

V_{\ell q}=y_{\ell}^{q}.

Then

g_{j}=V\,e^{(-j)}.

Inverting this system recovers
e^{(-j)}=V^{-1}g_{j}
. In practice, instead of repeatedly solving this system, it is convenient to precompute a weight vector
N\in\mathbb{R}^{D+1}
satisfying

\mu^{\top}e^{(-j)}=N^{\top}g_{j},

so that the Shapley contribution can be evaluated without explicitly materializing
e^{(-j)}
.

Numerical Instability.

Although optimal in an approximation-theoretic sense, Chebyshev nodes do not prevent numerical ill-conditioning when the polynomial degree
D
is moderate or large. Even with Chebyshev spacing, the condition number of
V
grows exponentially with
D
: for
D\approx 40
, one typically obtains
\mathrm{cond}(V)\gtrsim 10^{12}
in double precision, and for
D\approx 60
the matrix becomes nearly singular. In decision trees, the polynomial degree equals the depth, often
<15
. For product kernels, the degree is
D=d-1
, which can be up to hundreds, making instability intrinsic. These issues make the inversion
V^{-1}g_{j}
highly unreliable beyond
d\approx 40
, even if the Chebyshev grid is used.

D.2
Fourier / Roots-of-Unity Interpolation

The Fourier approach mirrors the Chebyshev strategy but replaces Chebyshev nodes with equally spaced complex roots of unity. The algebraic structure becomes particularly simple due to the unitary nature of the discrete Fourier transform (DFT).

Roots-of-Unity Evaluation.

Let
n=D+1
and

\omega_{\ell}=\exp\!\left(\tfrac{2\pi i\ell}{n}\right),\qquad\ell=0,\dots,n-1.

Evaluating
H_{j}
at these points gives

g_{j,\ell}=H_{j}(\omega_{\ell})=\sum_{q=0}^{D}e_{q}(\mathcal{Z}_{-j})\,\omega_{\ell}^{q}.

Define the DFT matrix
F\in\mathbb{C}^{n\times n}
by
F_{\ell q}=\omega_{\ell}^{q}
. Then

g_{j}=F\,e^{(-j)},\qquad e^{(-j)}=F^{-1}g_{j}=\frac{1}{n}F^{\ast}g_{j}.

Relation to the Chebyshev Construction.

The Fourier method uses the same polynomial representation as the Chebyshev method, but replaces the real Vandermonde matrix
V
with the complex DFT matrix
F
. The main steps differ only in the choice of nodes and the linear system that is solved:

\text{Chebyshev:}\quad g_{j}=Ve^{(-j)},\qquad\text{Fourier:}\quad g_{j}=Fe^{(-j)}.

Both methods require evaluating
H_{j}
at
D+1
distinct interpolation points and both require recovering the coefficients of a degree-
D
polynomial from these evaluations.

Numerical Instability.

Although the DFT matrix
F
is perfectly conditioned in exact arithmetic, numerical instability arises for product kernels due to various reasons. First and foremost, the values
H_{j}(\omega_{\ell})
involve complex products
\prod_{i\neq j}(1+\omega_{\ell}\boldsymbol{z}_{i})
whose magnitudes grow roughly exponentially in
d
. Thus
g_{j}
spans an enormous dynamic range. In addition, the inverse DFT involves alternating complex phases. When some entries of
g_{j}
are extremely large and others small, cancellation magnifies floating-point error. Moreover, as with the Chebyshev method, the instability is structural: the degree
D=d-1
is simply too large for stable recovery of polynomial coefficients by interpolation.

Even though the Fourier transform itself is numerically stable, the interpolation problem it is solving is not. In our experiments, instability appears as early as
d\approx 50
for product kernels.

D.3

We empirically evaluate the numerical stability and computational efficiency of different elementary symmetric polynomial (ESP) aggregation strategies used to compute exact Shapley values in product-kernel models.

Experimental setup.

,
as well as the average wall-clock time per explanation call.

Discussion.

These results highlight a clear trade-off between computational speed and numerical robustness.
While FFT- and Chebyshev-based ESP aggregation can be attractive for low-dimensional problems, their current formulations amplify rounding and conditioning errors as the polynomial degree grows, leading to numerical instability at moderate to large
d
.
The quadratic dynamic-programming approach, although asymptotically slower, is the only method that remains numerically reliable across all tested dimensions, making it the appropriate default for exact Shapley computation in high-dimensional product-kernel models.

Experimental Setup

SVM Optimization Using Optuna

When using SVM in our experiments, we optimized the Support Vector Machine (SVM) with a Radial Basis Function (RBF) kernel using Optuna

After conducting the specified number of trials (n=100), the best hyperparameters were used to train a final SVM model on the entire dataset, yielding both the optimal model configuration and the best cross-validation score achieved during the optimization process.

Training Gaussian Process (GP) Using K-Fold Cross-Validation

Performance metrics were chosen based on the problem type: accuracy for classification models and mean absolute percentage error (MAPE) for regression models. The scores from each fold were aggregated to compute the average and standard deviation of the scores.

Appendix F
FAQ

How Does PKeX-Shapley Differ from
Mohammadi et al. (2026)
?

In
Mohammadi et al. (2026)
, the authors propose an exact Shapley computation method for stochastic attribution in FANOVA GP models. Similar to PKeX-Shapley, their approach leverages Newton’s identities and symmetric polynomial representations to obtain closed-form attributions. However, the two methods differ in both scope and capability.

PKeX-Shapley is designed specifically for kernel methods with product kernels. It employs the functional decomposition value function to compute exact Shapley values. While this formulation enables exact computation of the mean Shapley values, it does not extend naturally to higher-order moments. In particular, when applied to Gaussian processes, computing the variance or covariance structure of Shapley values is nontrivial, since orthogonality does not generally hold for product kernels. As a result, our method cannot be directly extended to explain GP models in a stochastic way. In addition, PKeX-Shapley computes all d Shapley values in
O(d^{2}n)
, while the one proposed by
Mohammadi et al. (2026)
has the same complexity for compute one Shapley value only.

In addition,
Mohammadi et al. (2026)
focus on FANOVA GPs, whose kernels admit a functional ANOVA decomposition. Compared to product kernels, this class of kernels is more restrictive and often harder to train in practice. Nonetheless, the additional structure provides a key advantage: it enables exact polynomial-time computation not only of the mean but also of the variance and covariance of stochastic Shapley values—something that product kernels cannot achieve. This distinction highlights the central difference between their method and ours.

How Does PKeX-Shapley Differ from RKHS-SHAP
(
Chau et al., 2022
)
?

RKHS-SHAP is the first kernel method-specific SHAP-based algorithm. While the author still employs the conditional expectation value function
{\tilde{\nu}_{\boldsymbol{x}}}(S)=\mathbb{E}[f(X)\mid X_{S}=\boldsymbol{x}_{S}]
, they used the fact that for function
f
in the RKHS
\mathcal{H}_{k}
, it is possible to estimate
{\tilde{\nu}_{\boldsymbol{x}}}(S)
non-parametrically utilizing a tool known as conditional kernel mean embedding. Specifically, this leads to the following expression:

\displaystyle{\tilde{\nu}_{\boldsymbol{x}}}(\mathcal{S})=\boldsymbol{\alpha}^{\top}\mathbf{K}(\mathbf{K}_{\mathcal{S}}+n\lambda I)^{-1}k_{\mathcal{S}}(\mathbf{X}_{\mathcal{S}},\boldsymbol{x}_{\mathcal{S}})

which of course, is different from our functional decomposition value function.

Another crucial difference between PkeX-Shapley and
Chau et al. (2022)
is that the former uses two recurrences to compute all Shapley values in quadratic time, while the latter uses a subset of coalition samples and computes the Shapley value using a regressor, similar to Kernel SHAP.
