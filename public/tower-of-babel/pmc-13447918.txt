Class prototype rectification and multi-scale feature measurement for few-shot classification of bearing surface defects
Authors: Yan Cang, Chunguang Li, Xuanshang Zhang, Jun Ma, Ziwei Zhou
Published: 2026

ABSTRACT
AbstractIndustrial defect detection often exhibits limited generalization and reduced accuracy when labeled data are scarce. To address this challenge, we propose a meta-learning framework for few-shot industrial defect detection that learns task-adaptive embeddings, rectified class prototype representations, and multi-scale metric inference, leading to improved classification performance under scarce annotations. Adaptive weighted pooling generates normalized spatial weights for channel-wise weighted summation, and a local sliding operation enables fast cross-task adaptation while preserving micro-crack and low-contrast details. Class Prototype Rectification (PR) uses a Sum-of-Absolute-Differences (SAD)-based weighting in embedding space to down-weight outlier support samples and form robust class prototypes. A Multi-Scale Feature Measurement (MSFM) module extracts features from each convolutional/residual block via parallel branches with local–global fusion and similarity attention; per-scale predictions are ensembled for layer-wise supervision and improved detection of small/low-contrast defects. Focal Loss is adopted during meta-training. Experiments on mini-ImageNet and a bearing-surface defect dataset show consistent gains over strong baselines; ablations verify each module’s contribution, and production-line tests confirm feasibility. The framework improves accuracy and robustness under limited data, offering a practical solution for few-shot industrial defect classification.Keywords: Few-shot learning, Industrial defect inspection, Class prototype rectification, Multi-scale feature measurement, Metric-based meta-learningSubject terms: Engineering, Mathematics and computing

Introduction

Automated visual inspection using deep neural networks plays a vital role in modern manufacturing by ensuring product quality, and it has seen significant success in various defect-detection tasks1–3. However, its widespread adoption is fundamentally limited by data scarcity. While common practices such as data augmentation, transfer learning, and weakly supervised learning offer partial solutions4–6, their performance often plateaus when generalizing to novel defect categories under extreme few-shot conditions.

Inspired by the human capacity for learning from limited examples, few-shot learning (FSL) offers a principled framework for addressing data scarcity. Existing FSL methods for image classification generally follow two paradigms. Optimization-based approaches (e.g., MAML) aim to learn a favorable initialization for rapid task adaptation; however, they are susceptible to gradient noise induced by small support sets, which can amplify class prototype drift and obscure subtle defect characteristics7–9. Metric-based approaches (e.g., ProtoNets), by contrast, learn a transferable embedding space wherein classification is performed via distance to class prototypes10. Recent advances have further investigated the use of frozen pretrained features augmented through learned transformations11 as well as progressive feature refinement with continuous relational modeling for fine-grained recognition12. Nonetheless, the prevailing reliance on fixed embedding networks, simplistic mean-based prototypes, and single-scale feature representations renders these methods vulnerable to the high intra-class variance, outliers, and scale variations commonly encountered in industrial defect data.

To overcome these limitations, researchers have explored adaptive pooling strategies to enhance the adaptability of fixed embeddings. While traditional operations like Max and Average Pooling utilize fixed rules that may discard valuable feature information, learnable strategies such as Stochastic Pooling13 and Mixed Pooling14 aim to preserve fine-grained details. Specifically, Zeiler et al.13 proposed Stochastic Pooling, which selects activations based on a multinomial distribution derived from feature values. Although effective for regularization, the inherent randomness can introduce instability when detecting subtle, deterministic defect patterns. Alternatively, Yu et al.14 introduced Mixed Pooling, which combines max and average pooling via a fixed or learnable ratio. However, this approach typically applies a global strategy to the entire feature map, ignoring the fact that defect features are often spatially sparse and require location-specific handling.

Second, the fragility of simple mean-based class prototypes is acute in industrial settings, where variance in lighting and perspective leads to significant intra-class spread and outlier sensitivity10. Correction strategies, including attention-based reweighting, transductive refinement, and clustering15–17, often improve accuracy at the cost of high computational overhead or strong query-distribution assumptions. More fundamentally, most operate as post-hoc processing18 rather than embedding robustness directly into the class prototype construction during meta-training. Hence, an intrinsic, efficient robustness mechanism for class prototype formation is still lacking.

Finally, the underutilization of multi-scale information limits representational capacity. Although FPN-based architectures and early-fusion methods15,19,20 have been applied in FSL, merging features into a single vector before measurement tends to blur the distinct strengths of shallow (detail) and deep (semantic) features21–24.

Motivated by these interconnected gaps, we propose a unified meta-learning framework with three core innovations designed to operate synergistically: (1) An Adaptive Weighted Pooling (AWP) module that dynamically generates input-conditioned spatial weights, transforming pooling into a task-aware feature enhancer; (2) A class Prototype Rectification mechanism that down-weights divergent support samples based on feature-space consistency, yielding robust class prototypes intrinsically; (3) A late-stage multi-scale metric strategy that maintains independent similarity streams per scale and fusions decisions collaboratively, adaptively leveraging the most discriminative scale per query.

Together, these components form an efficient, robust, and discriminative FSL framework tailored to the demands of industrial defect inspection.

Training protocol and hyperparameters

We adopt the standard episodic training paradigm for few-shot learning. Models are trained and evaluated under 5-way 1-shot and 5-way 5-shot configurations. Each training episode samples 5 random classes, providing K support images and 15 query images per class (). For the 1-shot setting, the Prototype Representation (PR) module remains active and computes the class prototype directly from the single support feature, maintaining architectural consistency across different shot settings.

The meta-training process consists of 100 epochs, with 3000 randomly constructed episodes per epoch. Crucially, the model is trained exclusively on the base classes from Mini-ImageNet and never accesses any sample from the target bearing defect dataset during this phase. This ensures the learning of a generalizable, task-agnostic representation, directly addressing the core challenge of target-domain data scarcity.

All models are optimized using stochastic gradient descent (SGD) with momentum. The detailed hyperparameters are listed in Table 2.

Discussion

The proposed integrated meta-learning framework attains the highest classification accuracy of 83.94% on Mini-ImageNet and 91.34% on the bearing surface defect dataset. The improvements arise from a synergistic design that addresses key challenges jointly. This conclusion is supported by systematic visualisation and ablation studies.

Each core module contributes in a distinct manner. The adaptive weighted pooling module produces dynamic spatial weights, which enable the model to attend more precisely to critical defect regions. It also preserves fine-grained details that are often weakened by standard pooling. The class prototype rectification mechanism reweights support samples according to consistency in feature space, thereby suppressing the influence of outliers. The t-SNE results show that the corrected class prototypes move closer to their class centres while inter-class separation increases. This helps to explain the reduced confusion between visually similar defects, including scratching and incising marks. The multi-scale metric strategy improves robustness to variation in defect size through parallel processing and collaborative decision making.

The proposed framework demonstrates strong suitability for practical industrial deployment on bearing production lines. Although it incurs marginally higher parameter counts and computational overhead compared to conventional few-shot detection methods, the substantial gains in defect detection accuracy fully justify this trade-off; moreover, the increased complexity remains well within acceptable limits for industrial applications.

Raw bearing images are captured by industrial cameras at varying resolutions, subsequently cropped to 200 × 200 pixels, and fed into the model with a batch size of 1. Deployed on a Jetson Xavier NX edge device, the algorithm attains a processing speed of 200–400 FPS under FP16 precision. Consequently, processing the full set of six images (two end faces and one shaft surface captured from four rotational views) requires only 0.015–0.03 seconds, a duration far below the 4-second real-time inspection threshold mandated for each bearing. Additional optimizations–including precomputation of class prototype centers and TensorRT-based FP16 quantization–further reduce inference latency and memory footprint, thereby establishing a viable pathway toward formal production deployment.

Nevertheless, several limitations of the proposed method warrant further discussion. In practical deployment, a lens hood and supplementary lighting were employed to mitigate ambient light interference. Under these controlled conditions, the algorithm achieves application-grade performance for the five common defect types addressed in this study. However, its recognition accuracy for zero-shot defects—i.e., defect categories not encountered during training—remains insufficient for practical deployment, indicating that the method is inherently constrained in terms of detectable defect category coverage. Moreover, the model continues to exhibit degraded performance when distinguishing among highly similar bearing defects characterized by overlapping feature distributions, such as light rust, mill scale, and shallow surface scratches on outer and side surfaces. Furthermore, the current cross-domain pre-training strategy lacks an explicit mechanism for modeling domain discrepancies arising from diverse industrial operating conditions. Future investigations will incorporate margin-based loss constraints to strengthen inter-class feature separation and will adopt domain adaptation modules to harmonize feature distributions across varying production environments.

In summary, the coordinated integration of adaptive feature preservation, rectification class prototype construction, and multi-scale metric learning addresses key bottlenecks in few-shot defect classification while offering practical industrial value. Methods

We propose a novel meta-learning framework that integrates three key innovations, as shown in Fig. 8.

Overall network architecture based on class prototype rectification and multi-scale feature measurement.

The feature embedding network employs ResNet-12 as the backbone, and its core contribution is the integration of a set of adaptive weighting layers. The class Prototype Rectification module proposes a class Prototype Rectification algorithm designed to identifying feature vectors within the same class that exhibit high discrepancy, thereby avoiding the class prototype shift caused by uniform weighting in the averaging process.

The multi-scale feature measurement strategy uses the output features of each convolutional block in the feature embedding network to represent image features, thereby increasing the effective number of feature samples. In the similarity measurement stage, it separately utilises class prototype-like features and query set similar features at different scales for classification. Adaptive weighted pooling

Unlike traditional adaptive pooling methods that rely on fixed rules or global statistics, the Adaptive Weighted Pooling (AWP) layer utilizes a lightweight convolutional subnet to dynamically generate spatially-adaptive weights tailored to the unique defect textures in the input. Inspired by meta-learning principles, AWP incorporates a dedicated weight generation module implemented via convolutional layers. This design enables efficient adaptation across tasks by leveraging the local sliding operations of convolutions to effectively capture spatial information shared across different defect patterns. Crucially, the module computes weights by considering feature information from all channels at each spatial location, enabling it to dynamically produce task-specific pooling weights during multi-task training. The AWP architecture comprises two core components: (i) adaptive pooling weight generation, which learns spatially-varying weights, and (ii) weighted pooling, which integrates these weights into the pooling operation. To enhance defect representation, we replace the original max pooling layers in the feature embedding network with the proposed AWP layer. Class prototype rectification algorithm

Standard prototypical networks compute class prototypes as simple means of support embeddings. Although widely adopted, this approach is particularly sensitive to intra-class variance in industrial defect data. Defects may appear with small foreground regions, dominant backgrounds, or partial occlusion, causing their feature embeddings to deviate from the class’s main distribution. Direct averaging under such conditions shifts the class prototype away from the representative class center, impairing its discriminative power and increasing misclassification risk, as illustrated in Fig. 10.

Illustration of class prototype shift caused by an outlier sample under uniform averaging.

To address this, we propose a class Prototype Rectification (PR) mechanism that re-weights support samples based on their feature-space consistency, thereby suppressing the influence of divergent samples and producing a more robust class prototype.

Our method adapts the Sum of Absolute Differences (SAD) principle from image matching to measure pairwise discrepancy in the feature space. Multi-scale feature measurement strategy

The multi-scale feature measurement (MSFM) strategy has three parallel branches. Figure 11 shows its structure.The baseline model only uses features from the last layer of the feature embedding network. MSFM uses features from every layer. For a CNN encoder with four convolutional blocks, MSFM takes feature maps from all four blocks. For a ResNet encoder, it takes feature maps from every residual block—including those in early layers. This gives the model more information across different scales. It improves similarity measurement between support and query samples.

First, the feature embedding network processes input data. It produces support and query features at multiple scales. At each scale, we extract support features and query features separately. Support features go through a global-local fusion module and a similar-feature attention module. Query features pass through their own global-local fusion module and similar-feature attention module. These modules run in parallel. They generate two outputs per scale: class prototypes and a similarity-aware query feature map.

Using features at multiple scales to jointly determine the final category prediction enhances the constraint ability of the feature extraction network on each layer of the feature embedding network, making the model focus not only on high-level semantic information but also on low-level detail contour information. Additionally, using multi-scale cosine similarity scores instead of just relying on the output features of the feature embedding network can better avoid misjudgement.
