Example 1.1.

Consider an economist who wants to understand the various reasons behind high crime in Brooklyn, NY (more generally, in any specific neighborhood in the US). To ensure statistical significance of the analysis, the economist searches for data that contain a substantial fraction of the data points (say at least 10%) from Brooklyn.
More generally, such support requirement would hold even if they want to analyze crime (or other factors affecting development) across different cities across the United States. Several prior works
(

,

,

on data discovery have considered such queries for data analysis on open data repositories which contain roughly 100K datasets.

Additionally, the economist may want to identify cities which have at least k neighborhoods with high or low quality of life, modeled as a linear function of crime, pollution, healthcare and other factors that they are interested to consider.

In summary, the economist often faces two types of distributional requirements for data search: (i) The fraction of data points within a specific range (geographical region) must meet or exceed a specified threshold, such as x%. We refer to this query as a percentile-query.
(ii) The value (or score) of a specific combination of attributes from at least
k
data points must exceed a threshold, such as
\tau

The prior work on distribution aware search suffer from two main challenges:
First, these techniques cannot handle preference requirements and only support one-sided percentile queries. For example, a query to identify datasets that contain at least
10\%
points in a rectangular area (that includes Brooklyn) can not be answered with these tools.
Second, all these techniques employ heuristics to identify the best datasets. More generally, prior work on data discovery employs heuristics (for example in keyword based data discovery techniques
(
13
,
45
)
), which do not guarantee the effectiveness of the search algorithm.
This means that the search result may miss certain datasets, even though it satisfies user’s query. Missing any dataset that satisfies user query can percolate biases into the system.
Missing datasets is generally unacceptable in data marketplaces, where it is extremely crucial to ensure that all datasets that satisfy the query are available to the user. Therefore, it is important to develop a theoretically rigorous framework for data discovery, which guarantees to return all relevant datasets for the user’s query.

In this work, we address these limitations and present the first theoretical framework for data discovery which helps users to identify datasets that satisfy distributional requirements.
Next, we describe a new general theoretical framework that is used to formally define various practical problems from distribution-aware dataset search. Later, we show two of the most common subclasses of problems that we focus in this paper, derived from our new framework.

1.1.
Theoretical Framework

In this section, we present a new theoretical framework for data discovery.

Dataset

A
schema

\mathcal{A}=(A_{1},A_{2},\ldots,A_{d})
is an ordered tuple of attributes. A
dataset

P
with schema
\mathcal{A}
is a finite set of data entries, where each entry
p\in P
is a
d
-tuple
p=(p_{1},p_{2},\ldots,p_{d})
such that
p_{i}\in{\texttt{dom}}(A_{i})
for
i=1,2,\ldots,d
. Thus,
P\subseteq{\texttt{dom}}(A_{1})\times{\texttt{dom}}(A_{2})\times\cdots\times{\texttt{dom}}(A_{d})
. In this paper, we focus on datasets where all attributes are numerical, i.e.,
{\texttt{dom}}(A_{i})=\mathbb{R}
for all
i
. Hence,
P\subset\mathbb{R}^{d}
. We denote the schema of a dataset
P
as
\textsc{Schema}(P)
. In all cases, we assume that
d=O(1)
.

Repository

A
repository

\mathcal{P}
is a collection of datasets
\mathcal{P}=\{P_{1},P_{2},\ldots,P_{N}\}
, all of which share the same schema, i.e.,
\textsc{Schema}(P_{i})=\textsc{Schema}(P_{j})
for all
i,j
.
1
1

1

The assumption that all datasets contain only numerical attributes and share the same schema is not strictly required. These assumptions are adopted to simplify the presentation. For our framework to be applicable, it suffices for datasets in
\mathcal{P}
to share at least some numerical attributes.

For each
i\in[N]
, let
n_{i}=|P_{i}|
be the size of dataset
P_{i}
, and
\mathcal{N}=\sum_{i\in[N]}n_{i}
.

Measure Function

A
measure function

\mathcal{M}(\cdot)
, is a function that, when applied to a dataset
P
, assigns a numerical value
\mathcal{M}(P)\in\mathbb{R}
to quantify a specific property or characteristic of the dataset. We assume that
\mathcal{M}(\cdot)
is applied to a dataset
P
only if
\mathcal{M}(P)
is well-defined. For example, a commonly used measure function is the percentile measure function
\mathcal{M}_{R}
over a rectangle
R
, which is defined as
\mathcal{M}_{R}(P)=\frac{|R\cap P|}{|P|}
.

A set of measure functions that quantify similar properties is called a
class
, which we typically denote by
\mathcal{F}
. For example, a the class of percentile measure functions consists of all measure functions
\mathcal{M}_{R}
such as
R
is any axis-parallel rectangle in
\mathbb{R}^{d}
.

Predicates

A
predicate

\textsc{Pred}(\cdot)
is a function that, given a dataset
P
, evaluates to
\textsc{Pred}(P)\in\{\textsf{True},\textsf{False}\}
. For a measure function
\mathcal{M}
and an interval
\theta=[a_{\theta},b_{\theta}]
, where
a_{\theta},b_{\theta}\in\mathbb{R}
and
a_{\theta}\leq b_{\theta}
, a
range-predicate

\textsc{Pred}_{\mathcal{M},\theta}(P)
returns
True
if
\mathcal{M}(P)\in\theta
. If
\theta
is a one-sided interval (for instance,
\theta=[a_{\theta},\infty)
), we call
\textsc{Pred}_{\mathcal{M},\theta}(\cdot)
a
threshold-predicate
.
Complex predicates can be formed by combining individual predicates using conjunction and, disjunctions.
For example, consider the complex predicate
\Pi=\textsc{Pred}_{\mathcal{M},\theta}\land\textsc{Pred}_{\mathcal{M}^{\prime},\theta^{\prime}}
, over two measure functions
\mathcal{M}
and
\mathcal{M}^{\prime}
of the same class. The expression
\Pi(P)
evaluates to
True
if both
\textsc{Pred}_{\mathcal{M},\theta}(P)
and
\textsc{Pred}_{\mathcal{M}^{\prime},\theta^{\prime}}(P)
are
True
.

Synopsis

Let
\mathcal{F}
be a class of measure functions. For a dataset
P
, a
synopsis
(or
sketch
) with respect to the class
\mathcal{F}
, denoted by
\mathcal{S}_{P}^{\mathcal{F}}
, is a compressed representation of
P
that captures the structure of
P
with regards to the class
\mathcal{F}
.
For example, the class of percentile measure functions is defined as the collection of functions
\mathcal{M}_{R}
over every rectangle
R
.
Ideally, for any function
\mathcal{M}\in\mathcal{F}
,
\mathcal{M}(P)\approx\mathcal{M}(\mathcal{S}_{P}^{\mathcal{F}}),
where
\mathcal{M}(\mathcal{S}_{P}^{\mathcal{F}})
is the result of evaluating the measure function
\mathcal{M}
on
\mathcal{S}_{P}^{\mathcal{F}}
.
2
2

2

We assume
\mathcal{M}(\mathcal{S}_{P}^{\mathcal{F}})
is well-defined.

We ignore the superscript and only write
\mathcal{S}_{P}
, when the class
\mathcal{F}
is clear from context.
For a function
\mathcal{M}\in\mathcal{F}
, we denote the error of
\mathcal{S}_{P}
on
\mathcal{M}
as
\textsc{Err}_{\mathcal{S}_{P}}(\mathcal{M})
, where the specific definition of
\textsc{Err}_{\mathcal{S}_{P}}(\cdot)
depends on the class
\mathcal{F}
and the dataset
P
. We define
\textsc{Err}_{\mathcal{S}_{P}}(\mathcal{F}):=\max_{\mathcal{M}\in\mathcal{F}}\textsc{Err}_{\mathcal{S}_{P}}(\mathcal{M})
.

Distribution-Aware Indexing

Let
\mathcal{P}=\{P_{1},P_{2},\ldots,P_{N}\}
be a repository, where each dataset
P_{i}\subset\mathbb{R}^{d}
, and let
\mathcal{F}
be a class of measure functions. The general
distribution-aware indexing problem
for
(\mathcal{P},\mathcal{F})
aims to design an index
\mathcal{I}
that, given a logical expression
\Pi
(of constant size) involving predicates of the form
\textsc{Pred}_{\mathcal{M},\theta}
, where
\mathcal{M}\in\mathcal{F}
and
\theta
is an interval in
\mathbb{R}
, efficiently computes the subset of datasets in
\mathcal{P}
that satisfy
\Pi
. Formally, the index
\mathcal{I}
should answer a
distribution-aware dataset query

\bm{q}_{\Pi}
:

\bm{q}_{\Pi}(\mathcal{P}):=\{i\in[N]\mid\Pi(P_{i})=\textsc{True}\}.

There are two natural variants of the problem.
In the
centralized
setting,
we have direct and full access to all the datasets in
\mathcal{P}
for building
\mathcal{I}
.
In the
federated
setting,
we do not have direct access to
\mathcal{P}
. Instead, we have access to a collection of synopses
\mathcal{P}_{\mathcal{S}}=\{\mathcal{S}_{P_{1}},\mathcal{S}_{P_{2}},\ldots,\mathcal{S}_{P_{N}}\}
, where
\mathcal{S}_{P_{i}}
is a synopsis of
P_{i}
with respect to
\mathcal{F}
. We note that if
\mathcal{S}_{P_{i}}=P_{i}
, for every
i\in[N]
, then this is equivalent to the centralized setting.

It is evident that,
\bm{q}_{\Pi}(\mathcal{P})
can be answered exactly in the centralized setting, where direct access to all datasets in
\mathcal{P}
is available. In the federated setting, however, the ability to evaluate
\Pi(P_{i})
, for any
i
, critically depends on the quality of the synopsis
\mathcal{S}_{P_{i}}
provided for each dataset
P_{i}
. Specifically, the ability to correctly decide any predicate
\textsc{Pred}_{\mathcal{M}_{j},\theta_{j}}(P_{i})
is influenced by the error
\textsc{Err}_{\mathcal{S}_{P_{i}}}(\mathcal{M})
, which is a measure of deviation between
\mathcal{M}(\mathcal{S}_{P_{i}})
and
\mathcal{M}(P_{i})
.

1.2.
Problem definition

In order to define a problem based on the proposed framework in Section
1.1
, someone needs to specify the class of measure functions.
In this paper, we propose efficient data structures for two of the most common classes of measure functions in the distribution-aware indexing problem.

Percentile-aware indexing

Let
P\subset\mathbb{R}^{d}
be a dataset and let
R
be an axis-parallel rectangle in
\mathbb{R}^{d}
. A
percentile measure function

\mathcal{M}_{R}
is defined as:

\mathcal{M}_{R}(P):=\frac{|R\cap P|}{|P|}
.
Interpreting
P
as a uniform discrete probability distribution with support defined by the points in
P
,
\mathcal{M}_{R}(P)
measures the mass of the distribution in the region
R
. A percentile measure function is relevant when the user is interested in the proportion of tuples within a specific region of a dataset, e.g., the proportion of tuples from Brooklyn.
We denote the class of axis-parallel percentile measure functions in
\mathbb{R}^{d}
by:

\mathcal{F}^{d}_{\Box}=\{\mathcal{M}_{R}(\cdot)\mid R\text{ is an axis-aligned rectangle in }\mathbb{R}^{d}\}.

For the class
\mathcal{F}^{d}_{\Box}
, the commonly used synopses in practice include probability distributions over
\mathbb{R}^{d}
, such as histograms, mixture models, and
\varepsilon
-samples
(a formal definition of an
\varepsilon
-sample is given in the next section).
Such synopses support random sampling over the compressed representation of their datasets. The error in this context is defined as

\textsc{Err}_{\mathcal{S}_{P_{i}}}(\mathcal{M}_{R}):=|\mathcal{M}_{R}(P_{i})-\mathcal{M}_{R}(\mathcal{S}_{P_{i}})|,

where
\mathcal{M}_{R}(\mathcal{S}_{P_{i}}):=\Pr_{p\sim\mathcal{S}_{P_{i}}}[p\in R]
.
For simplicity, we assume that for every
i\in[N]
,

\textsc{Err}_{\mathcal{S}_{P_{i}}}(\mathcal{F}^{d}_{\Box})\leq\delta_{i}\leq\delta
, where
\delta\in[0,1)
is a known arbitrarily small constant.
For the class of measure functions
\mathcal{F}^{d}_{\Box}
, the problem derived by our new framework is better known in the literature as
percentile-aware indexing

(
Ptile
)

(
8
,
6
)
.

Problem 1 (
Ptile
).

Let
\mathcal{P}
be a repository over a set of (possibly) unknown datasets
\{P_{1},\ldots,P_{N}\}
, where
P_{i}\subset\mathbb{R}^{d}
for every
i\in[N]
and
d=O(1)
.
We are given a family of
N
synopses
\{\mathcal{S}_{P_{1}},\ldots,\mathcal{S}_{P_{N}}\}
, with regards to the class of measure functions
\mathcal{F}^{d}_{\Box}
, such that
\textsc{Err}_{\mathcal{S}_{P_{i}}}(\mathcal{F}^{d}_{\Box})\leq\delta
for every
i\in[N]
, for
\delta\in[0,1)
. The goal is to construct a data structure such that, given a logical expression
\Pi
over a constant number of range-predicates of the form
\textsc{Pred}_{\mathcal{M}_{R},\theta}
, where
\mathcal{M}_{R}\in\mathcal{F}^{d}_{\Box}
, it returns
\bm{q}_{\Pi}(\mathcal{P})
.

In the centralized setting (
\delta=0
), we call the problem the
centralized percentile-aware indexing

(
CPtile
)
, and in the federated setting (
\delta>0
),
federated percentile-aware indexing

(
FPtile
)
.

Preference-aware Indexing

Let
P\subset\mathbb{R}^{d}
be a dataset. For a unit vector
\vec{v}\in\mathbb{R}^{d}
and a point
p\in P
, define the score of point
p
with respect to vector
\vec{v}
as
\omega(p,\vec{v})=\langle p,\vec{v}\rangle
, i.e., the inner product of
p
with
\vec{v}
. For an integer
k>0
, let
\omega_{k}(P,\vec{v})
denote the score of the point in
P
with the
k
-th largest inner-product with respect to
\vec{v}
. A
top-k preference measure function
is defined as:

\mathcal{M}_{\vec{v},k}(P):=\omega_{k}(P,\vec{v})
.
A top-
k
preference measure function is relevant when the user is interested in the top-
k
scores of a dataset with respect to some linear function over the attributes, e.g., cities with
k
neighborhoods with high/low quality of life, modeled as a linear function.
We denote the class of top-k preference measure functions in
\mathbb{R}^{d}
by

\vec{\mathcal{F}}^{d}_{k}=\{\mathcal{M}_{\vec{v},k}(\cdot)\mid\vec{v}\text{ is a unit-vector in }\mathbb{R}^{d}\}.\vskip-3.99994pt

For the class
\vec{\mathcal{F}}^{d}_{k}
, then a commonly used synopsis in practice include a kernel
(
5
,
37
,
55
)
or a histogram.
Such synopses have a mechanism to return

\mathcal{M}_{\vec{v},k}(\mathcal{S}_{P})
, i.e., an estimation of the
k
-th largest score in dataset
P
with respect to unit vector
\vec{v}
.
The error in this context is also defined as

\textsc{Err}_{\mathcal{S}_{P}}(\mathcal{M}_{\vec{v},k}):=|\mathcal{M}_{\vec{v},k}(P)-\mathcal{M}_{\vec{v},k}(\mathcal{S}_{P})|
.
For simplicity, we assume that for every
i\in[N]
,

\textsc{Err}_{\mathcal{S}_{P_{i}}}(\vec{\mathcal{F}}^{d}_{k})\leq\delta_{i}\leq\delta
, where
\delta\in[0,1)
is a known arbitrarily small constant.
For the class of measure functions
\vec{\mathcal{F}}^{d}_{k}
, the problem derived by our new framework is called
preference-aware indexing

(
Pref
)
.

Problem 2 (
Pref
).

Let
\mathcal{P}
be a repository over a set of (possibly) unknown datasets
\{P_{1},\ldots,P_{N}\}
, where
P_{i}\subset\mathbb{R}^{d}
for every
i\in[N]
and
d=O(1)
. Let
k
be a positive integer number.
We are given a family of
N
synopses
\{\mathcal{S}_{P_{1}},\ldots,\mathcal{S}_{P_{N}}\}
, with regards to the class of measure functions
\vec{\mathcal{F}}^{d}_{k}
, such that
\textsc{Err}_{\mathcal{S}_{P_{i}}}(\vec{\mathcal{F}}^{d}_{k})\leq\delta
for every
i\in[N]
, for
\delta\in[0,1)
. The goal is to construct a data structure such that, given a logical expression
\Pi
over a constant number of threshold-predicates of the form
\textsc{Pred}_{\mathcal{M}_{\vec{v},k},\theta}
, where
\mathcal{M}_{\vec{v},k}\in\vec{\mathcal{F}}^{d}_{k}
, it returns
\bm{q}_{\Pi}(\mathcal{P})
.

In the centralized setting (
\delta=0
), we call the problem
centralized preference-aware indexing

(
CPref
)
, and in the federated setting (
\delta>0
)
federated preference-aware indexing

(
FPref
)
.

1.3.
Our Results

We use
\tilde{O}(\cdot)
notation to suppress exact dependencies on
\log N
and
\log\mathcal{N}
. Detailed dependencies are fully specified in subsequent sections.
In all cases, we denote the set of reported indexes (corresponding to datasets in
\mathcal{P}
) as
J
, and sometimes refer to
\mathsf{OUT}=|J|
as the output size.

\bullet
(
Section
3
: Lower Bounds
)
In Subsection
3.1
, we focus on
CPtile
and rely on the conjectured hardness of the
strong set intersection problem
to show that no data structure with
\tilde{O}(\mathcal{N})
size and
\tilde{O}(1+\mathsf{OUT})
query time exists in
\mathbb{R}^{2}
, even with a single threshold-predicate (conditional lower bound). In Subsection
3.2
, using the hardness of the
halfspace reporting problem
, we show that no data structure of
\tilde{O}(\mathcal{N})
size and
\tilde{O}(1+\mathsf{OUT})
query time exists for the
CPref
problem in
\mathbb{R}^{5}
, even with one predicate (unconditional lower bound).

\bullet
(
Section
4
: Approximate Data structures for
Ptile
)

We first, design an approximate data structure for the
Ptile
problem in
\mathbb{R}^{d}
, supporting a single range-predicate.
It has
\tilde{O}(N)
space,
\tilde{O}(N)
preprocessing time, and
\tilde{O}(1+\mathsf{OUT})
query time.
For a query
\Pi=\textsc{Pred}_{\mathcal{M}_{R},\theta}
, with
R
as a query rectangle and
\theta=[a_{\theta},1]
, the data structure returns
J
such that
\bm{q}_{\Pi}(\mathcal{P})\subseteq J
, and if
j\in J
, then
a_{\theta}-\varepsilon-2\delta\leq\mathcal{M}_{R}(P_{j})\leq b_{\theta}+\varepsilon+2\delta
, with high probability, where
\varepsilon\in(0,1)
is a small constant.
Next, we extend the data structure to work for general intervals
\theta=[a_{\theta},b_{\theta}]
(range-predicate), having the same error and the same theoretical guarantees.
In Appendix
C.4
, we extend the structure further to handle logical expressions (supporting disjunctions and conjunctions) of
m
range-predicates, where
m=O(1)
, while retaining the same error bounds and same asymptotic complexities.

\bullet
(
Section
5
: Approximate Data structures for
Pref
)
We design an approximate data structure that works for the
Pref
problem assuming one threshold-predicate. It has
\tilde{O}(N)
space,
\tilde{O}(N)
preprocessing time, and
\tilde{O}(1+\mathsf{OUT})
query time. For a query
\Pi=\textsc{Pred}_{\mathcal{M}_{\vec{v},k},\theta}
, where
\vec{v}
is a query unit vector and
\theta
is a one-sided query interval, it returns a set
J
such that
\bm{q}_{\Pi}(\mathcal{P})\subseteq J
, and if
j\in J
, then
\mathcal{M}_{\vec{v},k}(P_{j})\geq a_{\theta}-\varepsilon-2\delta
. In Appendix
D.1
, we extend this data structure to handle logical expressions of
m
threshold-predicates, where
m=O(1)
, while retaining the same error bounds and same asymptotic complexities.

\bullet
(
Additional Results
)
All of our data structures satisfy the following properties: i) They extend to settings where
\delta_{i}
’s are unknown, with no global upper bound
\delta
, while maintaining the same guarantees.
ii) They are dynamic, supporting
\tilde{O}(1)
update time for the insertion or deletion of a synopsis. iii) They provide
\tilde{O}(1)
delay guarantees, ensuring the time between reporting two consecutive indexes is
\tilde{O}(1)
.

In traditional database systems, there are two settings for query-driven dataset search: data lakes and metadata-based search.
Data lakes usually assume full data access and their proposed solutions do not have theoretical guarantees
(

,

,

,

,

,

,

,
42
,

,

)
.
Existing metadata-based dataset search engines, such as
(
12
,
13
)
, are great engineering solutions but they do not provide theoretical guarantees or/and are limited to keyword search.

Asudeh and Nargesian
(
6
)
developed a system vision for distribution-aware data discovery. While their vision targets the data lake setting, it highlights the importance of distributional queries over dataset collections. Similarly, Nargesian et al.
(
41
)
proposed distribution tailoring to meet fairness requirements in the same setting.
These methods require raw data access and they do not provide theoretical error guarantees for our studied problems.

The definition of
Ptile
problem was first given in
(
8
)
, which built a federated search technique assuming that histograms represent the synopsis of each dataset
P_{i}
.
While their method detects all datasets whose percentile measure function is in
\theta
, its query time is super linear with respect to the number of datasets.
Furthermore, they only studied one-sided query predicates
\theta
and their method does not extend to range predicates.

Our problems for the centralized setting can be modeled as range color reporting queries. Indeed, if every dataset has a different color, then the
CPtile
problem asks to report all colors in a query rectangle
R
that contain a fraction (at least
a_{\theta}
and at most
b_{\theta}
) of their points in
R
. Similarly, the
CPref
problem asks to report all colors such that the score of their
k
-th larger point on a vector
\vec{v}
is at least
a_{\theta}
. The paper closest to our work is
(
2
)
, where the authors study range summary queries on colored points. Given a set of
n
colored points

. It is not clear how the data structures in

ii) They design data structures only for

.
iii) They do not consider the

or the

Furthermore, there are more works on range queries in colored points such as, color reporting
(

,

, color counting
(

However, the techniques of these papers do not apply to our problem.

2.
Preliminaries

Hyper-rectangles

A hyper-rectangle
R
in
\mathbb{R}^{d}
is usually defined in two ways. Either
R
is defined by its two opposite corners
R^{-},R^{+}\in\mathbb{R}^{d}
, or
R
is defined as the product of
d
intervals
R=[R^{-}_{1},R^{+}_{1}]\times\ldots\times[R^{-}_{d},R^{+}_{d}]
, where
R^{-}_{j},R^{+}_{j}
are the
j
-th coordinates of the points
R^{-},R^{+}
, respectively. For
d=2
,
R
is a rectangle, and for
d=1
,
R
is an interval. For simplicity, for every
d\geq 1
we call
R
a rectangle.
An open rectangle
R
that is only defined by one of its corners is called an
orthant
.

\varepsilon
-sample

Let
\mathcal{S}=(\mathbf{X},\mathcal{R})
be a range space, where
\mathbf{X}
is a set of points in
\mathbb{R}^{d}
and
\mathcal{R}
is a set of ranges in
\mathbb{R}^{d}
.
For
\varepsilon\in[0,1]
, a subset
C\subseteq\mathbf{X}
is an
\varepsilon
-sample for
\mathbf{X}
, if for any range
R\in\mathcal{R}
, we have

\bigg|\frac{|\mathbf{X}\cap R|}{|\mathbf{X}|}-\frac{|C\cap R|}{|C|}\bigg|\leq\varepsilon
.
It is known by the
\varepsilon
-sample theorem
(
53
)
, that if
(\mathbf{X},\mathcal{R})
is a range space with constant VC dimension, then a random subset
\mathsf{S}\subseteq\mathbf{X}
of cardinality
O(\varepsilon^{-2}(\log(\varepsilon^{-1})+\log(\varphi^{-1})))
, is an
\varepsilon
-sample for
\mathbf{X}
with probability at least
1-\varphi
.
If
\mathcal{R}
is a set of rectangles then the random subset
C
has cardinality
O(\varepsilon^{-2}\log\varphi^{-1})
,
(
17
,
32
)
.
The next lemma follows straightforwardly by our definitions and properties of
\varepsilon
-samples. Its proof is shown in Appendix
A
.

Lemma 2.1.

Let
\mathcal{S}_{X}
be the synopsis of
X
with respect to the class
\mathcal{F}^{d}_{\square}
. Assume that
\textsc{Err}_{\mathcal{S}_{X}}(\mathcal{F}_{\square}^{d})=\delta
for a parameter
\delta\in[0,1)
.
If
\mathsf{S}
is a set of
O(\varepsilon^{-2}\log\varphi^{-1})
random samples from
\mathcal{S}_{X}
, then
\mathsf{S}
is an
(\varepsilon+\delta)
-sample for
X

with probability at least
1-\varphi^{-1}
.

\varepsilon
-net

Let
\mathbb{S}^{d-1}
be the unit sphere in
\mathbb{R}^{d}
. A centrally symmetric set
\mathcal{C}\subseteq\mathbb{S}^{d-1}
(i.e., if
u\in\mathcal{C}
, then
-u\in\mathcal{C}
) of
O\left(\varepsilon^{-d+1}\right)
unit vectors is an
\varepsilon
-net
if for every point
v\in\mathbb{S}^{d-1}
, there exists a point
u\in\mathcal{C}
with angle at most
\mathsf{cos}^{-1}\left(\frac{1}{1+\varepsilon^{2}}\right)=O\left(\varepsilon\right)
.
An
\varepsilon
-net in
\mathbb{R}^{d}
can be constructed in
O(\varepsilon^{-d+1})
time
(
3
)
.

Range tree

Let
X
be a set of finite weighted points in
\mathbb{R}^{d}
. For a point
x\in X
, let
w_{x}\in\mathbb{R}
be its weight, and let
W=\{w_{x}\mid x\in X\}
be the list of weights.
The goal is to construct a data structure such that given a query rectangle
R
, and an interval
I
the set
X_{R,I}=\{x\in X\mid x\in X\cap R,w_{x}\in I\}
is reported efficiently.
A range tree
\mathcal{T}
constructed on
X,W
, is a near-linear space tree-based data structure that constructs a hierarchical decomposition of the space such that, for any rectangle
R
and interval
I
, all points in
X_{R,I}

are reported in
O(\text{\,}\mathrm{polylog}\,(|X|+\mathsf{OUT})
, where
\mathsf{OUT}
is the output size
|X_{R,I}|
.
It is known that range trees over weighted points have
O(|X|\log^{d}|X|)
space,
O(|X|\log^{d}|X|)
preprocessing time, and can answer range reporting queries in
O(\log^{d}(|X|)+\mathsf{OUT})
time. See
(
21
)
for details.
It is also known how to design dynamic range trees that handle insertions and deletions of points, efficiently. More specifically, a dynamic range tree over weighted points has
O(|X|\log^{d}|X|)
space,
O(|X|\log^{d}|X|)
preprocessing time,
O(\log^{d+1}|X|)
update time and can answer range reporting queries in
O(\log^{d+1}(|X|)+\mathsf{OUT})
time. See
(
47
,
16
)
for details.
Let
\mathcal{T}=\mathsf{DRangeTreeConstruct}(X,W)
be a method that takes the set of points
X
along with their weights
W
and constructs a dynamic range tree, denoted by
\mathcal{T}
. If we construct a static range tree we use
\mathsf{RangeTreeConstruct}(X,W)
.
Given a query rectangle
R
and interval
I
, let
\mathcal{T}.\mathsf{Report}(R,I)
be the query procedure that returns
X_{R,I}
.
We also define the procedure
\mathcal{T}.\mathsf{ReportFirst}(R,I)
that reports one (arbitrary) point from
X_{R,I}
, if
X_{R,I}\neq\emptyset
, and then terminate the query procedure. On the other hand, if
X_{R,I}=\emptyset
then it returns
\mathsf{NULL}
.
By slightly modifying the standard query procedures, it is executed in
O(\log^{d+1}(|X|))
time and
O(\log^{d}(|X|))
time for dynamic and static range trees, respectively.

Delay guarantees

A data structure for a reporting (or enumeration) problem over a set
X
of
n
points, satisfies
f(n)
delay (for a real function
f
) if the time between the start of the reporting procedure to the first result, the time between two consecutive pair of results, and the time between the last result and the termination of the reporting procedure are all bounded by
f(n)
time
(
7
)
.

3.
Lower Bounds

In this section we show some lower bounds for the
Ptile
and
Pref
problems.
We first show a conditional lower bound for the
CPtile
problem using the strong set intersection conjecture. Next, we show a lower bound for the
Pref
using a known hardness result for halfspace reporting queries. The missing proofs can be found in Appendix
B
.

3.1.
CPtile
problem

In this section, we show a conditional lower bound suggesting that no efficient data structure exists for the exact
CPtile
problem. More precisely, assuming the strong set intersection conjecture, we show that for the
CPtile
problem even with one threshold-predicate, there is no data structure that uses near linear (
\tilde{O}(\mathcal{N})
) space and answers the queries in near constant (
\tilde{O}(1)
) time even for
d=2
. The strong set intersection conjecture is a commonly used tool for showing tradeoffs between the space and the query time of the data structures
(
36
,
54
,
58
)
, introduced in
(
27
)
, and can be stated as follows.

Definition 3.1.

[Set intersection] Given a universe of integers
\mathcal{U}
, and
g
subsets
\{S_{1},S_{2},\cdots,S_{g}\}
, set intersection query asks for reporting
S_{i}\cap S_{j}
for two arbitrary indices
i,j\in[g]
.

Conjecture 3.2.

[Strong set intersection conjecture]
Given
g
sets
S_{1},\ldots,S_{g}
with
M=\sum_{i\in[g]}|S_{i}|
, any index that answers a set intersection query in time
\tilde{O}(\mathbb{T}+\mathsf{OUT})
, needs at least
\tilde{\Omega}(M+\frac{M^{2}}{\mathbb{T}^{2}})
space, where
\mathbb{T}
is any user defined positive integer parameter and
\mathsf{OUT}
is the size of the output of the query.

We note that a stronger version of Conjecture
3.2
, is stated in
(
27
)
, however, this weaker conjecture suffices for us to show the desired lower bounds.

To show a reduction from the set intersection problem to our
CPtile
problem, we first prove a conditional hardness result for a more restricted version of the set intersection problem, which is of independent interest and could be used to show lower bounds for other restrictive problems. We call a collection of sets
uniform
if any element belongs to the same number of different sets. More formally, a collection of sets
T=\{T_{1},\ldots,T_{g}\}
over the universe
\mathcal{U}
is
uniform
if for any pair of elements
u_{1},u_{2}\in\mathcal{U}
, we have
|\{T_{i}\in T:u_{1}\in T_{i}\}|=|\{T_{i}\in T:u_{2}\in T_{i}\}|
. Furthermore, we define the
uniform set intersection
problem similar to
3.1
, but with an additional constraint that the input collection of sets is uniform. The proof of the next lemma can be found in Appendix
B
.

Lemma 3.3.

For the uniform set intersection problem with total input size
M
, there is no data structure of size
\tilde{O}(M)
that answers queries in time
\tilde{O}(1+\mathsf{OUT})
, unless the strong set intersection conjecture is false, where
\mathsf{OUT}
is the size of the output of the query.

In Appendix
B.1
, we reduce the uniform set intersection problem to the
CPtile
problem.

Theorem 3.4.

Given a repository
\mathcal{P}=\{P_{1},\ldots,P_{N}\}
such that
\mathcal{N}=\sum_{P_{i}\in\mathcal{P}}|P_{i}|
and
P_{i}\subset\mathbb{R}^{2}
for every
i\in[N]
, there is no data structure for the
CPtile
problem of size
\tilde{O}(\mathcal{N})
and
\tilde{O}(1+\mathsf{OUT})
query time, unless the strong set intersection conjecture is false.

3.2.
CPref
problem

In this subsection, we show an unconditional lower bound for the
CPref
problem. In the halfspace reporting problem, we are given a set
U\subset\mathbb{R}^{d}
of
n
points and the goal is to construct a data structure such that given a query halfspace
H
, report all points in
|U\cap H|
.
The next lower bound for halfspace reporting queries is known from
(
1
)
. Any data structure that answers
d(d+3)/2
-dimensional halfspace reporting queries in
\bar{\mathcal{Q}}(n)+O(K)
time, where
K
is the number of reported points, requires
\Omega\left(\left(\frac{n}{\bar{\mathcal{Q}}(n)}\right)^{d}2^{-O\left(\sqrt{\log\bar{\mathcal{Q}}(n)}\right)}\right)
space.
Hence, there is no hope to get an
\tilde{O}(n)
space data structure with
\tilde{O}(1)
query time for the halfspace reporting problem in
\mathbb{R}^{d}
for
d>4
.
Due to space limit, we show a reduction from the halfspace reporting problem to
CPref
problem in Appendix
B.2
and we conclude with the next theorem.

Theorem 3.5.

Given a repository
\mathcal{P}=\{P_{1},\ldots,P_{n}\}
such that
\mathcal{N}=\sum_{P_{i}\in\mathcal{P}}|P_{i}|
and
P_{i}\subset\mathbb{R}^{5}
, for every
i\in[N]
, there is no data structure for the
CPref
problem of size
\tilde{O}(\mathcal{N})
and
\tilde{O}(1+\mathsf{OUT})
query time.

4.
Data structures for the
Ptile
Problem

In this section we describe our data structures for the
Ptile
problem. In the previous section, we showed that we cannot hope for an efficient exact data structure for the
CPtile
problem when
d\geq 2
, even if the logical expression contains only one threshold-predicate. In Appendix
C.1
, we show an efficient exact data structure for the
CPtile
in
\mathbb{R}^{1}
assuming one range-predicate in the logical expression
\Pi
. In this section we focus on approximate data structures for the
Ptile
for any
d\geq 1
.
In Subsection
4.1
, we show the high level ideas and a technical overview of our new data structures.
Then, as a warm-up, in Subsection
4.2
, we consider
Ptile
queries with one threshold predicate. In Subsection
4.3
, we extend the approximate data structure for
Ptile
queries with a general range-predicate. Finally, in Appendix
C.4
, we further extend to any logical expression (of disjunctions and conjunctions)
\Pi
over a constant number of range predicates.
Recall that each synopsis
\mathcal{S}_{P}
supports random sampling (with replacement) over
P
. Let
\mathcal{S}_{P}.\mathsf{Sample}(\kappa)
be the synopsis’ procedure that returns
\kappa
random samples from
P
, for any positive integer
\kappa
.

4.1.
Overview

Before we start describing the technical details, we show an overview of our approach. For simplicity we assume that the query logical expression
\Pi
consists of only one predicate
\textsc{Pred}_{\mathcal{M}_{R},\theta}
.

Current methods cannot solve
Ptile
efficiently with theoretical guarantees, even in the centralized setting where every dataset is known.
For example, consider the following baseline. For every dataset
P_{i}
construct a range tree to answer range counting queries.
Given a query predicate
\textsc{Pred}_{\mathcal{M}_{R},\theta}
, the naive solution goes through each dataset
P_{i}
and using the range tree it computes
\frac{|R\cap P_{i}|}{|P_{i}|}
. If this value belongs in
\theta
then we report
i
, otherwise we continue with the next dataset.
While this algorithm solves the
CPtile
problem exactly, it has
\Omega(N)
query time. Another baseline, that works in both centralized and federated settings, is proposed by
(
8
)
that first defined the
Ptile
problem. While their data structure returns a solution for the
Ptile
problem with bounded error, the query time is
\Omega(N)
in the worst case.

We design a new data structure with bounded error having query time with polylogarithmic dependency on
N
.
Our new method consists of two core ideas: First, we construct a small summary for each dataset using only the input synopses.
Second we construct a data structure over the summaries in a higher dimensional space that allows us to answer percentile queries in sublinear time with respect to
N
.

One of the main components of our data structure is the notion of
coreset
.
Coresets are used in computational geometry, theory and databases, as small summaries that maintain key properties of the original data
(
3
,
33
)
.
More specifically, for every dataset
i\in[N]
we get a set
\mathsf{S}_{i}
of roughly
O(\varepsilon^{-2})
random samples from
\mathcal{S}_{P_{i}}
. Assuming that all synopses have error at most
\delta
, from Lemma
2.1
, we know that
\mathsf{S}_{i}
is an
(\varepsilon+\delta)
-sample. By its definition, an
\varepsilon^{\prime}
-sample acts like a coreset for percentile queries.
Notice that every set
\mathsf{S}_{i}
can be computed in both settings: In the centralized setting we sample directly from the dataset
P_{i}
and
\delta=0
, so
\mathsf{S}_{i}
is an
\varepsilon
-sample. In the federated setting we sample from the synopsis
\mathcal{S}_{P_{i}}
and
\mathsf{S}_{i}
is an
(\varepsilon+\delta)
-sample.

While we reduce the size of each dataset
P_{i}
from
n_{i}
to
O(\varepsilon^{-2})
our problem is far from being solved. Given a query rectangle
R
and predicate
\theta
, we still need to go through each set
\mathsf{S}_{i}
to answer the query.
Our main idea is to construct, all possible combinatorially different rectangles with respect to the coreset
\mathsf{S}_{i}
, for each
i\in[N]
. Interestingly, for each
i\in[N]
, this number is small, because each coreset is small. For each precomputed rectangle
\rho
, we store the weight
\frac{|\rho\cap\mathsf{S}_{i}|}{|\mathsf{S}_{i}|}
, i.e., the fraction of points from the coreset that lies in this rectangle. Intuitively, given a query rectangle
R
, we should find for every dataset, among all precomputed rectangles, the one which is the “most similar” to
R
in order to estimate the fraction of points it contains in
R
. If the interval
\theta
has the form
[a_{\theta},1]
(threshold-predicate in Section
4.2
) then it turns out that each dataset
i
that has at least one precomputed rectangle
\rho
completely inside
R
with weight at least
a_{\theta}-\varepsilon-\delta
, should be reported.
If the interval
\theta
has the form
[a_{\theta},b_{\theta}]
(range-predicate in Section
4.3
), then it turns out that each dataset, whose largest precomputed rectangle inside
R
has weight between
a_{\theta}-\varepsilon-\delta
and
b_{\theta}+\varepsilon+\delta
, should be reported.

In order to guarantee sublinear query time, we construct a geometric data structure among all precomputed rectangles over all datasets. For threshold-predicate (Section
4.2
), we search among all precomputed rectangles and find any of them that lies completely inside
R
with weight at least
a_{\theta}\!-\!\varepsilon\!-\!\delta
(property
\textbf{P}1
). Similarly, for range-predicate (Section
4.3
) we search among all precomputed rectangles to find any of them that is maximal inside
R
(no other larger precomputed rectangle generated from the same coreset lies completely inside
R
) with weight between
a_{\theta}\!-\!\varepsilon\!-\!\delta
and
b_{\theta}\!+\!\varepsilon\!+\!\delta
(property
\textbf{P}2
).
Once we find such a rectangle (that was generated from coreset, say,
\mathsf{S}_{i}
), we report
i
, we remove all precomputed rectangles generated from
\mathsf{S}_{i}
and continue with the same query until we cannot find a rectangle that satisfies property
\textbf{P}1
(threshold-predicate), or property
\textbf{P}2
(range-predicate).
In order to efficiently find precomputed rectangles with these properties and to efficiently remove precomputed rectangles, we use a dynamic range tree.

Recall that the range tree is constructed on a set of points, such that given a query rectangle it reports the points inside the query rectangle efficiently. In order to use it for our purpose, in Section
4.2
, we map the precomputed rectangles in
\mathbb{R}^{d}
(along with their weights) to weighted points in
\mathbb{R}^{2d}
.
The new set of (weighted) points in
\mathbb{R}^{2d}
is stored in the range tree. Given a query rectangle
R
in
\mathbb{R}^{d}
, we map it to a new rectangle (orthant)
R^{\prime}
in
\mathbb{R}^{2d}
, such that a precomputed rectangle
\rho
in
\mathbb{R}^{d}
lies completely inside
R
, if and only if,
\rho
’s mapped point in
\mathbb{R}^{2d}
lies inside the orthant
R^{\prime}
.
In Section
4.3
the geometric data structure is more involved and we need to map the precomputed rectangles to points in
\mathbb{R}^{4d}
.

\mathcal{S}_{P_{i}}
.

\mathsf{S}_{i}

(\varepsilon+\delta)

For every
i\in[N]

\mathcal{R}_{i}
that contains all combinatorially different hyper-rectangles defined by
\mathsf{S}_{i}
. Every hyper-rectangle
\rho\in\mathcal{R}_{i}

.

and

. Finally, we define

and

6.
Future work

There are multiple interesting open problems arising from our data structures and the proposed framework in general.

\bullet
Our new framework can be used to define multiple types of distribution-aware queries such as nearest neighbor or diversity queries
both in the centralized and federated setting. We are given a repository
P_{1},...,P_{N}
.
For nearest neighbor queries: given a query point
q
and a threshold
\tau
, return all datasets
P_{j}
such that
\mathsf{dist}(q,P_{j})\leq\tau
, where
\mathsf{dist}(q,P_{j})
is the closest distance between q and a point in
P_{j}
. For diversity queries: given a query rectangle
R
and a threshold
\tau
, return all datasets
P_{j}
such that
\mathsf{div}(P_{j}\cap R)\geq\tau
, where
\mathsf{div}()
is a diversity function
(
33
)
.
While the goal of the paper is not to provide a data structure with theoretical guarantees for every problem arising from our proposed framework, our techniques are useful to handle additional queries such as nearest neighbor and diversity queries.
The main obstacle for these queries is that, to the best of our knowledge, there are no high-quality and small-size coresets we can use for the construction of our data structures.
Recall that for the
Ptile
problem we used the notion of
\varepsilon
-sample, while for the
Pref
problem we used the notion of
\varepsilon
-net to construct coresets that are sufficient to answer any percentile or preference query, respectively.
On the other hand, for the approximate nearest neighbor problem (similar arguments can be made for other types of queries), given a set of points
P
, there is no method to derive a subset
S
, where
|S|\ll|P|
, such that for any query point
q\in\mathbb{R}^{d}
,
\mathsf{dist}(q,S)\leq(1+\varepsilon)\cdot\mathsf{dist}(q,P)
. There are some recent results constructing coresets for approximate nearest neighbor queries with additive approximation
(
26
)
. While our current data structures only handle percentile and preference queries (percentile measure and top-k preference measure functions), our work is a first step toward efficiently solving general problems arising from our proposed framework.

\bullet
For the
CPtile
problem in
\mathbb{R}
we proposed an exact data structure of near linear space and polylogarithmic query, assuming that
\theta
is fixed. A natural question to ask is whether this data structure can be extended to allow
\theta
to be part of the query.
Our current data structure (in Appendix
B.1
) heavily uses the fact that
\theta=[a_{\theta},b_{\theta}]
is known in the preprocessing phase.
One idea to overcome this obstacle is to construct the data structure for different dyadic ranges in
[0,1]
. Such an idea has been used in
(
18
)
for range queries. Given
R
and
\theta
, we could combine the different results from the precomputed dyadic ranges to have a valid solution for our problem. Currently, it is not clear how the precomputed dyadic ranges can be combined to get an exact solution.

C.4.
Approximate data structure for the
Ptile
problem with a logical expression

So far, we assumed that the (query) logical expression
\Pi
contains only one predicate,
\textsc{Pred}_{\mathcal{M}_{R},\theta}
. In this subsection, we extend our data structure to work for any constant number
m
of predicates. Handling disjunction of predicates is straightforward using the designed data structure. For example, if the query consists of rectangles
R^{(1)},\ldots,R^{(m)}
with intervals
\theta^{(1)},\ldots,\theta^{(m)}
then by keeping track of the indexes we report (so that we do not report duplicates), we can handle every rectangle independently. We might encounter an index
i
at most
O(m)=O(1)
times so all our guarantees from the previous section hold. On the other hand, it is not clear how to handle conjunction of predicates.

Main idea

In this section, we describe a data structure that handles
m
conjunctions of predicates. The main difference from the previous section is that we map all possible
m
pairs of rectangles
(\rho,\hat{\rho})
in
4md
dimensions instead of
4d
dimensions that we had in the previous section. Given a query rectangle
R
and
m
predicates we define an orthant
R^{\prime}
in
4md
dimensions. The construction of the data structure is similar as in Subsection
4.3
.

We only describe the data structure for general range-predicates. If we consider threshold-predicates the exponential complexities on
d
are improved.

Data structure

The first steps of constructing the data structure are identical with the data structure in the previous subsection.
Without loss of generality assume that all datasets and query rectangles lie in a bounded box
\mathcal{B}
.
For every
i\in[N]
, we get an
(\varepsilon+\delta)
-sample
\mathsf{S}_{i}\subset\mathbb{R}^{d}
by sampling
O(\varepsilon^{-2}\log(N\varphi^{-1}))
points from
\mathcal{S}_{P_{i}}
uniformly at random.
Let
\bar{\mathsf{S}}_{i}
be the projection of
\mathsf{S}_{i}
onto the
2\cdot d
boundaries of
\mathcal{R}
.
For every
i\in[N]
, we construct the set
\mathcal{R}_{i}
that contains all combinatorially different hyper-rectangles defined by
\mathsf{S}_{i}\cup\bar{\mathsf{S}}_{i}
. Every hyper-rectangle
\rho\in\mathcal{R}_{i}
is defined by their two opposite corners
\rho^{-},\rho^{+}\in\mathbb{R}^{d}
such that
\rho^{-}_{h}\leq\rho^{+}_{h}
, for every
h\in[d]
, where
\rho^{-}_{h},\rho^{+}_{h}
are the
h
-coordinates of
\rho^{-}
and
\rho^{+}
, respectively.
We construct all pairs of rectangles
\hat{\mathcal{R}}_{i}=\{(\rho,\hat{\rho})\mid\rho\in\mathcal{R}_{i},\hat{\rho}\in\mathcal{R}_{i},\rho\subseteq\hat{\rho},\nexists\rho^{\prime}\in\mathcal{R}_{i}:\rho\subset\rho^{\prime}\subset\!\!\subset\hat{\rho}\}
.
Let
\tilde{\mathcal{R}}_{i}
contain all subsets of
m
pairs of rectangles in
\hat{\mathcal{R}}_{i}
. For every
\sigma=\{(\rho^{(1)},\hat{\rho}^{(1)}),\ldots(\rho^{(m)},\hat{\rho}^{(m)})\}\in\tilde{\mathcal{R}}_{i}
, let

q_{\sigma}=(\rho_{1}^{(1)-},\ldots,\rho^{(1)-}_{d},\hat{\rho}^{(1)-}_{1},\ldots,\hat{\rho}^{(1)-}_{d},\rho^{(1)+}_{1},\ldots,\rho^{(1)+}_{d},\hat{\rho}^{(1)+}_{1},\ldots,\hat{\rho}^{(1)+}_{d},\ldots,\rho_{1}^{(m)-},\ldots,\rho^{(m)-}_{d},

\hat{\rho}^{(m)-}_{1},\ldots,\hat{\rho}^{(m)-}_{d},\rho^{(m)+}_{1},\ldots,\rho^{(m)+}_{d},\hat{\rho}^{(m)+}_{1},\ldots,\hat{\rho}^{(m)+}_{d})

be the point in
\mathbb{R}^{4md}
defined by merging the opposite corners of
(\rho^{(r)},\hat{\rho}^{(r)})\in\sigma
, for
r\in[m]
.
For every point
q_{\sigma}
, we assign
m
weights,
w_{q_{\sigma}}=(\mathcal{M}_{\rho^{(1)}}(\mathsf{S}_{i}),\ldots,\mathcal{M}_{\rho^{(m)}}(\mathsf{S}_{i}))=(\frac{|\rho^{(1)}\cap\mathsf{S}_{i}|}{|\mathsf{S}_{i}|},\ldots,\frac{|\rho^{(m)}\cap\mathsf{S}_{i}|}{|\mathsf{S}_{i}|})
.
Let
Q_{i}=\{q_{\sigma}\mid\sigma\in\tilde{\mathcal{R}}_{i}\}
and
W_{i}=\{w_{q_{\sigma}}\mid q_{\sigma}\in Q_{i}\}
. Finally, we define
Q=\bigcup_{i\in[N]}Q_{i}
and
W=\bigcup_{i\in[N]}W_{i}
. We construct a dynamic range tree
\mathcal{T}
over the (weighted) points
Q
with their corresponding
m
-dimensional weights in
W
.

Query procedure

We are given
m
query rectangles
\{R^{(1)},\ldots,R^{(m)}\}
in
\mathbb{R}^{d}
and
m

\theta^{(1)}=[a_{\theta^{(1)}},b_{\theta^{(1)}}],\ldots\theta^{(m)}=[a_{\theta^{(m)}},b_{\theta^{(m)}}]

R^{-},R^{+}
be the two opposite corners of a rectangle
R
. We define the orthant
R^{\prime}=[R^{(1)-}_{1},\infty)\times\ldots\times[R^{(1)-}_{d},\infty)\times(-\infty,R^{(1)-}_{1})\times\ldots\times(-\infty,R^{(1)-}_{d})\times(-\infty,R^{(1)+}_{1}]\times\ldots\times(-\infty,R^{(1)+}_{d}]\times(R^{(1)+}_{1},\infty)\times\ldots\times(R^{(1)+}_{d},\infty)\times\ldots\times R^{(m)-}_{1},\infty)\times\ldots\times[R^{(m)-}_{d},\infty)\times(-\infty,R^{(m)-}_{1})\times\ldots\times(-\infty,R^{(m)-}_{d})\times(-\infty,R^{(m)+}_{1})\times\ldots\times(-\infty,R^{(m)+}_{d}]\times(R^{(m)+}_{1},\infty)\times\ldots\times(R^{(m)+}_{d},\infty)

in
\mathbb{R}^{4md}
and the weight query rectangle
I^{\prime}=[a_{\theta^{(1)}}-\varepsilon-\delta,b_{\theta^{(1)}}+\varepsilon+\delta]\times\ldots\times[a_{\theta^{(m)}}-\varepsilon-\delta,b_{\theta^{(m)}}+\varepsilon+\delta]
.
We repeat the following until no index is returned:
Using,
R^{\prime}\times I^{\prime}
we query the range tree
\mathcal{T}
. Let
u
be the first (non-empty) canonical node it returns and let
q_{\sigma}
be any arbitrary point stored in this node. Let
j
be the index of the point set
P_{j}
that

was constructed for. We report
j
, and we delete from
\mathcal{T}

\{q_{\sigma}\mid\rho^{(1)}\in\mathcal{R}_{j}\}

If there is no such canonical node or we do not find any
q_{\sigma}
we stop the execution.
Let
J
be the indexes we reported.
In the end of the process, we re-insert in
\mathcal{T}

for every index

Correctness

4.6

4.8

predicates.
If we assume that
\varepsilon
is an arbitrarily small constant and
m
is a constant then the data structure has size
O(N\log^{m-1}N)=\tilde{O}(N)
, can be constructed in

O(\sum_{i\in[N]}\Lambda_{\mathcal{S}_{P_{i}}}+N\log^{m-1}N)=\tilde{O}(\sum_{i\in[N]}\Lambda_{\mathcal{S}_{P_{i}}}+N)
time, and it has
O(\log^{m-1}(N)+|J|)=\tilde{O}(1+|J|)
query time.

Remark 1

The data structure can be made dynamic under insertion or deletion of synopses. If a synopsis
\mathcal{S}_{P}
is inserted/deleted
we can update our data structure in
O(\varepsilon^{-d+1}\Lambda_{\mathcal{S}_{P}}+\varepsilon^{-md+m}\log^{m}N)
time.

Remark 2

If we do not know an upper bound
\delta
on
\textsc{Err}_{\mathcal{S}_{P_{i}}}(\vec{\mathcal{F}}^{d}_{k})
, then by slightly modifying the data structure above we can get the following result. Let
\textsc{Err}_{\mathcal{S}_{P_{i}}}(\vec{\mathcal{F}}^{d}_{k})\leq\delta_{i}
for unknown parameters
\delta_{i}\in[0,1)
.
Having the same complexities as in
Theorem
C.8
, we report a set of indexes
J
such that, if
\mathcal{M}_{\vec{u}^{(\ell)},k}(P_{i})\geq a_{\theta^{(\ell)}}+\varepsilon+\delta_{i}
for every
\ell\in[m]
, then
i\in J
, and if
j\in J
, then
\mathcal{M}_{\vec{u}^{(\ell)},k}(P_{j})\geq a_{\theta^{(\ell)}}-\varepsilon-\delta_{j}
, for every
\ell\in[m]
.
