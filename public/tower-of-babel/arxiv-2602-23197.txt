Fine-Tuning Without Forgetting In-Context Learning: A Theoretical Analysis of Linear Attention Models
Chungpa Lee, Jy-yong Sohn, Kangwook Lee

Abstract
Transformer-based large language models exhibit in-context learning, enabling adaptation to downstream tasks via few-shot prompting with demonstrations. In practice, such models are often fine-tuned to improve zero-shot performance on downstream tasks, allowing them to solve tasks without examples and thereby reducing inference costs. However, fine-tuning can degrade in-context learning, limiting the performance of fine-tuned models on tasks not seen during fine-tuning. Using linear attention models, we provide a theoretical analysis that characterizes how fine-tuning objectives modify attention parameters and identifies conditions under which this leads to degraded few-shot performance. We show that fine-tuning all attention parameters can harm in-context learning, whereas restricting updates to the value matrix improves zero-shot performance while preserving in-context learning. We further show that incorporating an auxiliary few-shot loss enhances in-context learning primarily on the target task, at the expense of degraded in-context learning ability on tasks not seen during fine-tuning. We empirically validate our theoretical results.

In-context learning is the ability of a pretrained model to adapt to a target task through

By contrast, fine-tuning is a process of adapting a pretrained model to a target task by updating its parameters through additional training

Although both in-context learning and fine-tuning have been independently studied, their interaction is not fully understood

Recent empirical studies report a trade-off between these two paradigms: improving zero-shot performance through fine-tuning on a target task can degrade in-context learning

Related Work

Understanding In-context Learning of Transformers.

There are studies that explain why Transformer models exhibit in-context learning
(
10
;
29
;
5
;
8
;
6
;
24
;
34
;
28
;
47
;
26
)
. One prominent line of work interprets in-context learning as implicit Bayesian inference over latent task variables
(
44
)
. Complementary work provides explanations by showing that simplified Transformer architectures can implement learning algorithms from the prompt:
39
prove that a linear self-attention layer is equivalent to a step of gradient descent, and
3
further show that linear Transformers trained on regression tasks learn to implement preconditioned gradient descent for in-context learning. Motivated by this line of work, we adopt a theoretical formulation of Transformer models that assumes the pretrained model exhibits in-context learning capability.

Fine-Tuning Each Projection Matrix in Transformers.

Recent work has studied matrix-wise fine-tuning of attention by updating the query, key, and value matrices separately, and finds that fine-tuning the value matrix often yields better performance than tuning the key or query matrices
(
46
)
. For example, Table 5 of
16
shows that low-rank adaptation on the value matrix achieves stronger performance on WikiSQL
(
51
)
than adapting the query or key matrices, while attaining performance comparable to that of fine-tuning all matrices under the two-standard-error criterion. However, these studies primarily evaluate performance on the target-task objective and do not assess whether fine-tuning degrades a pretrained model’s intrinsic capabilities, such as in-context learning. In our work, we show that value-matrix fine-tuning can achieve competitive target-task performance while preserving in-context learning capability, thereby maintaining general-purpose few-shot performance.

Regression Tasks and Data Distribution.

We consider linear regression tasks specified by a task vector
{\mathbf{\theta}}\in\mathbb{R}^{d}
, where a
d
-dimensional input
{\mathbf{x}}\in\mathbb{R}^{d}
is mapped to a response
y\in\mathbb{R}
. Given a task
{\mathbf{\theta}}
, data points
({\mathbf{x}},y)
are generated independently as
{\mathbf{x}}\sim\mathcal{N}({\mathbf{0}}_{d},{\mathbf{\Sigma}})
and
y={\mathbf{\theta}}^{\top}{\mathbf{x}}+e
, where

with
\sigma^{2}>0
. The covariance matrix
{\mathbf{\Sigma}}:={\mathbf{U}}{\mathbf{\Lambda}}{\mathbf{U}}^{\top}\in\mathbb{S}_{++}^{d}
is positive definite, where
{\mathbf{U}}
is orthogonal and
{\mathbf{\Lambda}}=\diag(\lambda_{i})_{i\in[d]}
with
\lambda_{1}\geq\cdots\geq\lambda_{d}>0
.

For a given task

, we sample a dataset
\{({\mathbf{x}}_{i},y_{i})\}_{i\in[n+1]}
. We define
{\mathbf{z}}_{i}:=\begin{bmatrix}1&{\mathbf{x}}_{i}^{\top}&y_{i}\end{bmatrix}^{\top}\in\mathbb{R}^{d+2}
for
i\in[n]
, and
{\mathbf{z}}_{n+1}:=\begin{bmatrix}1&{\mathbf{x}}_{n+1}^{\top}&0\end{bmatrix}^{\top}\in\mathbb{R}^{d+2}
, whose response entry is masked to zero. We then define the prompt matrix as

\begin{bmatrix}{\mathbf{Z}}_{[n]}&{\mathbf{z}}_{n+1}\end{bmatrix}=\begin{bmatrix}\begin{bmatrix}1&\cdots&1\\
{\mathbf{x}}_{1}&\cdots&{\mathbf{x}}_{n}\\
y_{1}&\cdots&y_{n}\end{bmatrix}&\begin{bmatrix}1\\
{\mathbf{x}}_{n+1}\\
0\end{bmatrix}\end{bmatrix},

(1)

where
{\mathbf{Z}}_{[n]}:=[{\mathbf{z}}_{1}\cdots{\mathbf{z}}_{n}]\in\mathbb{R}^{(d+2)\times n}
stacks the
n
context examples.
Hereafter, we omit the subscript
n+1
on
{\mathbf{x}}_{n+1}
,
y_{n+1}
, and
{\mathbf{z}}_{n+1}
for notational simplicity.

Transformer Architecture.

To model the regression task, we consider a linear self-attention layer that replaces the softmax function in standard self-attention with a linear function. For a prompt
{\mathbf{Z}}
with
\mathrm{ncol}({\mathbf{Z}})
columns, the linear attention model
f(\cdot)
is defined as

\displaystyle f({\mathbf{Z}};{\mathbf{V}},{\mathbf{Q}}):={\mathbf{Z}}+\tfrac{1}{\mathrm{ncol}({\mathbf{Z}})}\cdot{\mathbf{V}}{\mathbf{Z}}{\mathbf{Z}}^{\top}{\mathbf{Q}}{\mathbf{Z}},

(2)

\displaystyle{\mathbf{V}}:={\begin{bmatrix}0&{\mathbf{0}}_{d}^{\top}&0\\
{\mathbf{0}}_{d}&{\mathbf{V}}_{11}&{\mathbf{v}}_{12}\\
0&{\mathbf{v}}_{21}^{\top}&v_{22}\end{bmatrix}}\!,\quad{\mathbf{Q}}:={\begin{bmatrix}q&{\mathbf{0}}_{d}^{\top}&0\\
{\mathbf{0}}_{d}&{\mathbf{Q}}_{11}&{\mathbf{q}}_{12}\\
0&{\mathbf{q}}_{21}^{\top}&q_{22}\end{bmatrix}}\!,

(3)

where
{\mathbf{V}},{\mathbf{Q}}\in\mathbb{R}^{(d+2)\times(d+2)}
denote the value projection matrix and the merged query–key projection matrix, respectively. Here
{\mathbf{V}}_{11},{\mathbf{Q}}_{11}\in\mathbb{R}^{d\times d}
are matrices,
{\mathbf{v}}_{12},{\mathbf{v}}_{21},{\mathbf{q}}_{12},{\mathbf{q}}_{21}\in\mathbb{R}^{d}
are vectors, and
v_{22},q,q_{22}
are scalars. Our formulation generalizes existing linear attention models
(
3
;
47
;
48
)
; in particular, setting
q=0
in (
2
) recovers their model. Moreover,
4

Based on the model
f(\cdot)
in (
2
), we take the last entry of its output as the prediction of
y_{n+1}
from
{\mathbf{x}}_{n+1}
. Specifically,

\displaystyle\!\!\!\hat{y}_{\mathrm{FS}}({\mathbf{Z}}_{[n]},{\mathbf{x}};{\mathbf{V}},{\mathbf{Q}})

\displaystyle:=\left[f\!\left(\begin{bmatrix}{\mathbf{Z}}_{[n]}\!\!&\!\!{\mathbf{z}}\end{bmatrix}\!\!;{\mathbf{V}},{\mathbf{Q}}\right)\right]_{d+2,n+1}\!,

(4)

\displaystyle\hat{y}_{\mathrm{ZS}}({\mathbf{x}};{\mathbf{V}},{\mathbf{Q}})

\displaystyle:=\left[f\left({\mathbf{z}};{\mathbf{V}},{\mathbf{Q}}\right)\right]_{d+2},

(5)

where
\hat{y}_{\mathrm{FS}}
in (
4
) denotes the few-shot prediction from a prompt containing
n
examples, whereas
\hat{y}_{\mathrm{ZS}}
in (
5
) denotes the zero-shot prediction from a prompt containing no examples, i.e., using only
{\mathbf{x}}_{n+1}
.

Evaluation Metric and Training Objective.

We evaluate model performance under zero-shot and few-shot settings using the following test error.

Definition 3.1

(Test Error)
.

For
n\in{\mathbb{N}}
and a task
{\mathbf{\theta}}\in{\mathbb{R}}^{d}
, the
n
-shot test error on the task
{\mathbf{\theta}}
is defined as

\displaystyle\mathcal{E}({\mathbf{V}},{\mathbf{Q}};n,{\mathbf{\theta}}):=\displaystyle\mathbb{E}_{{\mathbf{Z}}_{[n]},\,{\mathbf{x}},\,y\mid{\mathbf{\theta}}}\!\left[\big(\hat{y}_{\mathrm{FS}}({\mathbf{Z}}_{[n]},{\mathbf{x}};{\mathbf{V}},{\mathbf{Q}})\!-\!y\big)^{2}\right]\!,

(6)

and the zero-shot test error on the task
{\mathbf{\theta}}
is defined as

\displaystyle\mathcal{E}({\mathbf{V}},{\mathbf{Q}};0,{\mathbf{\theta}}):=\displaystyle\mathbb{E}_{{\mathbf{x}},\,y\mid{\mathbf{\theta}}}\left[\big(\hat{y}_{\mathrm{ZS}}({\mathbf{x}};{\mathbf{V}},{\mathbf{Q}})-y\big)^{2}\right].

(7)

Motivated by prior work demonstrating that Transformers exhibit in-context learning behavior on linear regression tasks
(
47
;
3
;
25
;
12
)
, we model pretraining by minimizing the expected
m
-shot test error averaged over tasks. Concretely, let
m\in{\mathbb{N}}
denote the number of context examples used during pretraining, which may differ from the test-time number of examples
n
. Although pretraining may involve various context lengths

, we fix

for analytical purposes. We define the pretraining loss as

\mathcal{L}({\mathbf{V}},{\mathbf{Q}}):=\displaystyle\mathbb{E}_{{\mathbf{\theta}}}\big[\mathcal{E}({\mathbf{V}},{\mathbf{Q}};m,{\mathbf{\theta}})\big].

(8)

Starting from the model pretrained via (
8
), we consider fine-tuning to improve zero-shot performance on the target task vector
{\mathbf{\theta}}_{0}\in{\mathbb{R}}^{d}
, by minimizing the zero-shot prompt loss

\mathcal{L}_{\mathrm{ZS}}({\mathbf{V}},{\mathbf{Q}};{\mathbf{\theta}}_{0}):=\mathcal{E}({\mathbf{V}},{\mathbf{Q}};0,{\mathbf{\theta}}_{0}).

(9)

We characterize the resulting models under these training objectives and analyze the zero-shot and few-shot test errors defined in Definition
3.1
.

Optimal Parameters and Test Error of Learned Linear Attention Models

In this section, we theoretically analyze the linear attention model
f(\cdot)
in (
2
) under different training regimes.
Starting from a pretrained model, we consider fine-tuning variants that improve zero-shot performance on a target task
{\mathbf{\theta}}_{0}
by minimizing the zero-shot prompt loss in (
9
).
These variants differ in which attention parameters are updated and whether an auxiliary few-shot prompt loss is included.

4.1
Pretraining

First, we consider a linear attention model pretrained using the loss
\mathcal{L}({\mathbf{V}},{\mathbf{Q}})
in (
8
). During pretraining, the training data are generated from task vectors
{\mathbf{\theta}}
sampled from
\mathcal{N}({\mathbf{0}}_{d},{\mathbf{I}}_{d})
. In the zero-shot setting, where

is predicted directly from
{\mathbf{x}}
without observing any additional examples, a single input

does not provide information about the underlying task vector
{\mathbf{\theta}}
. Consequently, the Bayesian optimal predictor under squared loss relies on the prior mean
\displaystyle\mathbb{E}[{\mathbf{\theta}}]={\mathbf{0}}_{d}
, yielding zero prediction for all
{\mathbf{x}}\in{\mathbb{R}}^{d}
. By contrast, when few-shot examples are provided, the model can implicitly infer the shared task vector and adapt its predictions accordingly.

A linear attention model pretrained by minimizing the loss
\mathcal{L}({\mathbf{V}},{\mathbf{Q}})
in (
8

A.3
and

4.3
Fine-Tuning Value Matrix with Zero-Shot Loss

To improve zero-shot performance on the target task
{\mathbf{\theta}}_{0}
while preserving few-shot performance, we revisit the structure of the optimal parameters derived in the previous subsections. A key insight from Theorem
4.3
is that, under full fine-tuning, the target task vector
{\mathbf{\theta}}_{0}
may be encoded in the value matrix through the parameter
{\mathbf{v}}_{21}
. In this sense, the value component of the attention mechanism provides a pathway to improved zero-shot performance.

We formalize this by characterizing when zero-shot performance outperforms few-shot performance, and show that this comparison is governed by the value parameter
{\mathbf{v}}_{21}
.

Theorem 4.5
.

Suppose
{\mathbf{V}}
and
{\mathbf{Q}}
in (
2
) satisfy
v_{22}=1
,
{\mathbf{q}}_{21}={\mathbf{0}}_{d}
, and
{\mathbf{Q}}_{11}
is positive definite. For any
{\mathbf{\theta}}\in{\mathbb{R}}^{d}
, the following inequality holds:

\displaystyle\mathcal{E}({\mathbf{V}},{\mathbf{Q}};0,{\mathbf{\theta}})\leq\mathcal{E}({\mathbf{V}},{\mathbf{Q}};n,{\mathbf{\theta}}),

(19)

if and only if

\displaystyle\left({\mathbf{v}}_{21}-{\mathbf{A}}^{-1}{\mathbf{B}}{\mathbf{\theta}}\right)^{\top}{\mathbf{A}}\left({\mathbf{v}}_{21}-{\mathbf{A}}^{-1}{\mathbf{B}}{\mathbf{\theta}}\right)\leq c,

(20)

where
c:={\mathbf{\theta}}^{\top}({\mathbf{B}}{\mathbf{A}}^{-1}{\mathbf{B}}+{\mathbf{C}}){\mathbf{\theta}}+(\tr({\mathbf{Q}}_{11}{\mathbf{\Sigma}}{\mathbf{Q}}_{11}{\mathbf{\Sigma}})+q^{2})\sigma^{2}
, and
{\mathbf{A}},{\mathbf{B}},{\mathbf{C}}
are matrices determined by
{\mathbf{Q}},{\mathbf{\Sigma}}
, and
n
.

Theorem
4.5
makes the role of the value parameter explicit. While
{\mathbf{A}}
,
{\mathbf{B}}
, and

depend on
{\mathbf{Q}}
,
{\mathbf{\Sigma}}
,
\sigma^{2}
,

{\mathbf{\theta}}
at which the test error is evaluated, they are independent of
{\mathbf{v}}_{21}

{\mathbf{v}}_{21}
. In particular, moving
{\mathbf{v}}_{21}
toward
{\mathbf{A}}^{-1}{\mathbf{B}}{\mathbf{\theta}}
makes the condition hold, which corresponds to a regime where zero-shot performance outperforms few-shot performance.

At the same time, recall that few-shot performance in the pretrained model relies on the query-key matrix
{\mathbf{Q}}
, and in particular on the condition
{\mathbf{Q}}_{11}={\mathbf{\Sigma}}^{-1}
in Corollary
4.1
. This observation suggests a fine-tuning strategy: rather than updating both
{\mathbf{V}}
and

{\mathbf{Q}}

to improve zero-shot performance. We refer to this strategy as

The following theorem characterizes the models obtained by value-matrix fine-tuning under the zero-shot prompt loss.

Theorem 4.6

(Optimal Parameters and Test Error of Value-Matrix Fine-Tuned Models)
.

Given a target task
{\mathbf{\theta}}_{0}\in{\mathbb{R}}^{d}

\mathcal{L}_{\mathrm{ZS}}({\mathbf{V}},{\mathbf{Q}};{\mathbf{\theta}}_{0})
in (

For any

\hat{{\mathbf{V}}}(w)=\begin{bmatrix}\cdot&\cdot&\cdot\\
\cdot&\cdot&\cdot\\
\cdot&\frac{1}{d+4}{\mathbf{\theta}}_{0}^{\top}&w\end{bmatrix}\!,\quad\hat{{\mathbf{Q}}}=\begin{bmatrix}\cdot&\cdot&\cdot\\
\cdot&{\mathbf{\Sigma}}^{-1}&\cdot\\
\cdot&\cdot&\cdot\end{bmatrix}\!.

(21)

Then,
\hat{{\mathbf{V}}}(w)

\hat{{\mathbf{Q}}}

\hat{{\mathbf{V}}}(w)\in\argmin_{{\mathbf{V}}}\mathcal{L}_{\mathrm{ZS}}({\mathbf{V}},\hat{{\mathbf{Q}}};{\mathbf{\theta}}_{0}),

(22)

Under this choice of parameters, for any

\displaystyle\lim_{n\to\infty}\mathcal{E}\big(\hat{{\mathbf{V}}}(w),\hat{{\mathbf{Q}}};n,{\mathbf{\theta}}\big)

(23)

\displaystyle=\sigma^{2}+\big(\tfrac{1}{d+4}{\mathbf{\theta}}_{0}+(w-1){\mathbf{\theta}}\big)^{\top}{\mathbf{\Sigma}}\big(\tfrac{1}{d+4}{\mathbf{\theta}}_{0}+(w-1){\mathbf{\theta}}\big).

The parameter

in (

\displaystyle\hat{{\mathbf{V}}}\left(\tfrac{m}{m+1+d}\right)

4.4

Fine-Tuning with an Auxiliary Few-Shot Loss Improves Few-Shot Performance at the Expense of Generalization.

The task-wise optimal value
w^{\star}(n;{\mathbf{\theta}})
in (

{\mathbf{\theta}}

As a result, choosing

to optimize few-shot performance on the target task

{\mathbf{\theta}}(\neq{\mathbf{\theta}}_{0})

w^{\star}(n;{\mathbf{\theta}}_{0})
instead of the task-wise optimal choice
w^{\star}(n;{\mathbf{\theta}})

Proposition 4.10
.

Given a target task
{\mathbf{\theta}}_{0}\in{\mathbb{R}}^{d}
, consider the family of parameters
\big(\hat{{\mathbf{V}}}(w),\hat{{\mathbf{Q}}}\big)
in (
21
). Fix
n\in\mathbb{N}
.
For simplicity, define
\mathcal{E}(w;\theta):=\mathcal{E}\big(\hat{{\mathbf{V}}}(w),\hat{{\mathbf{Q}}};n,{\mathbf{\theta}}\big)
and
w^{\star}(\theta):=w^{\star}(n;\theta)

For any

\displaystyle\mathcal{E}(w^{\star}(\theta_{0});\theta)-\mathcal{E}\big(w^{\star}(\theta);\theta\big)

\displaystyle=\frac{n\big((n\!+\!1\!+\!d)\theta^{\top}\Sigma\theta+d\sigma^{2}\big)}{(n\!+\!1)^{2}}\cdot\big(w^{\star}(\theta_{0})-w^{\star}(\theta)\big)^{2}\geq 0,

(35)

with equality if and only if
w^{\star}(\theta)=w^{\star}(\theta_{0})

Moreover, if

\displaystyle\mathcal{E}(w^{\star}(\theta_{0});\theta)-\mathcal{E}\big(w^{\star}(\theta);\theta\big)

{\mathbf{\theta}}_{0}

under the

6
Conclusion

We investigate the effect of task-specific fine-tuning on the in-context learning capability of Transformers with linear attention.
Specifically, we derive closed-form expressions for the parameters that minimize the pretraining and fine-tuning objectives, which reveal how different fine-tuning regimes induce a distinct trade-off between zero-shot and few-shot performances.
Our analysis shows that fine-tuning all parameters to optimize the zero-shot performance can degrade the few-shot performance. In contrast, restricting updates to the value matrix preserves the few-shot performance while improving the zero-shot performance.
Furthermore, although incorporating an auxiliary few-shot loss enhances the performance on the target task, it may lead to degradation on out-of-distribution tasks.

Limitations and Future Work.

Our theoretical analysis relies on linear attention models, which offer analytical tractability and enable closed-form characterization of optimal parameters and test errors, but do not capture all architectural and optimization features of Transformer models. While experiments on the MMLU benchmark indicate that qualitatively similar phenomena may arise in large-scale models, these results should be interpreted as illustrative rather than conclusive. Extending the theory to more expressive attention mechanisms, such as softmax attention and multi-head architectures, and understanding how these insights generalize to broader parameter-efficient fine-tuning settings remain directions for future work.

Proposition A.17

Theorem A.20
.

Under Assumption
A.18
, suppose the parameters are close to the optimal zero-shot solution in Theorem
A.8
. If one additional gradient descent step is performed on the asymptotic few-shot prompt loss in (
33
) with a sufficiently small learning rate
\eta
and
n\to\infty
, then the zero-shot error increases.

Proof.

From (
321
) in Lemma
A.19
, define the zero-shot error as

\displaystyle\mathcal{E}(\alpha,\beta,\gamma)

\displaystyle:=\big((\beta+(d+2)\gamma)\alpha-1\big)^{2}\left\lVert{\mathbf{\theta}}_{0}\right\rVert_{2}^{2}+2(d+2)\alpha^{2}\gamma^{2}\left\lVert{\mathbf{\theta}}_{0}\right\rVert_{2}^{2}+\sigma^{2}.

(326)

From Lemma
A.19
, the asymptotic few-shot loss under Assumption
A.18
is

\displaystyle\mathcal{L}(\alpha,\beta,\gamma):=\lim_{n\to\infty}\displaystyle\mathbb{E}_{{\mathbf{Z}}_{[n]},{\mathbf{x}},y|{\mathbf{\theta}}_{0}}\left[\big(\hat{y}_{\mathrm{FS}}({\mathbf{Z}}_{[n]},{\mathbf{x}};{\mathbf{V}},{\mathbf{Q}})-y\big)^{2}\right]=\left\lVert{\mathbf{\theta}}_{0}\right\rVert_{2}^{2}\cdot(\gamma\alpha+\gamma-1)^{2}+\sigma^{2}.

(327)

One gradient descent step with step size
\eta
gives

\displaystyle\Delta\alpha

\displaystyle=-\eta\frac{\partial\mathcal{L}}{\partial\alpha}=-2\eta\gamma\big(\gamma\alpha+\gamma-1\big)\left\lVert{\mathbf{\theta}}_{0}\right\rVert_{2}^{2},\qquad\Delta\beta=0,\qquad\Delta\gamma=-\eta\frac{\partial\mathcal{L}}{\partial\gamma}=-2\eta(\alpha+1)\big(\gamma\alpha+\gamma-1\big)\left\lVert{\mathbf{\theta}}_{0}\right\rVert_{2}^{2}.

(328)

At the zero-shot optimum
(\alpha,\beta,\gamma)=(1,1,0)
, one gradient descent step gives
\Delta\alpha=0
and
\Delta\gamma=4\eta\|{\mathbf{\theta}}_{0}\|_{2}^{2}
,
so
(\alpha,\beta,\gamma)
is updated to
(1,1,4\eta\|{\mathbf{\theta}}_{0}\|_{2}^{2})
. Therefore,

\displaystyle\mathcal{E}(1,1,4\eta\|{\mathbf{\theta}}_{0}\|_{2}^{2})-\mathcal{E}(1,1,0)=(d+2)(d+4)\big(4\eta\|{\mathbf{\theta}}_{0}\|_{2}^{2}\big)^{2}\|{\mathbf{\theta}}_{0}\|_{2}^{2}=16(d+2)(d+4)\eta^{2}\|{\mathbf{\theta}}_{0}\|_{2}^{6}>0,

(329)

and by continuity the same holds in a neighborhood of
(1,1,0)
.

B.2
Experimental Setup and Additional Results for the MMLU Benchmark

Experimental Setup.

We use the LLaMAFactory framework
(
50
)
for all experiments. All runs are conducted on a single NVIDIA RTX 4090 GPU or NVIDIA RTX A5000 GPU.

We fine-tune
Qwen2.5-3B-Instruct

(
45
)
on the
Humanities
subset of MMLU
(
15
)
, which contains 1,000 training examples. For each fine-tuning instance, we use
gpt-4.1-mini

(
1
)
to generate a chain-of-thought rationale, and train the model on prompts that include both the final answer and the reasoning trace. Fine-tuning is performed for 5 epochs using low-rank adaptation (LoRA)
(
16
)
with rank
r=128
. We apply adapters either to all attention projection matrices or only to the query (Q), key (K), and value (V) projections. We adopt LoRA as a parameter-efficient approach for optimizing the zero-shot objective (ZS), which is also theoretically motivated by our analysis where the optimal parameter change admits a rank-one update under value-matrix fine-tuning.

We sweep the learning rate over
\{1\times 10^{-3},3\times 10^{-4},1\times 10^{-4},3\times 10^{-5},1\times 10^{-5}\}
and select the model that achieves the best zero-shot performance on the
Humanities
category. When using the zero-shot objective with the auxiliary few-shot objective (ZS+FS), we sweep the initial weight of the few-shot loss term over
\{0.25,0.50,0.75,1.00\}
and linearly anneal it to
0
within each epoch. We evaluate the resulting models on the MMLU test set across four categories (
Humanities
,
Social Sciences
,
STEM
, and
Other
), consisting of 1,000 examples in total. Inference is performed with a temperature of
0.05
, evaluation is repeated three times, and the mean accuracy is reported along with the standard error.

Additional Results.

Humanities

,

, and

+6.59
, and

+2.44

-5.05
