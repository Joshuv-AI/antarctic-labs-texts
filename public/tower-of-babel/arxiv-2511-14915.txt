H-invariance theory: A complete characterization of minimax optimal fixed-point algorithms
TaeHo Yoon tyoon7@jhu.edu, Ernest K. Ryu eryu@math.ucla.edu, Benjamin Grimmer grimmer@jhu.edu

Abstract
For nonexpansive fixed-point problems, Halpern’s method with optimal parameters, its so-called H-dual algorithm, and in fact, an infinite family of algorithms containing them, all exhibit the exactly minimax optimal convergence rates. In this work, we provide a characterization of the complete, exhaustive family of distinct algorithms using predetermined step-sizes, represented as lower triangular H-matrices, which attain the same optimal convergence rate. The characterization is based on polynomials in the entries of the H-matrix that we call H-invariants , whose values stay constant over all optimal H-matrices, together with H-certificates , of which nonnegativity precisely specifies the region of optimality within the common level set of H-invariants. The H-invariance theory we present offers a novel view of optimal acceleration in first-order optimization as a mathematical study of carefully selected invariants, certificates, and structures induced by them.

Introduction

In optimization, finding a minimax optimal, or worst-case optimal, algorithm for a given problem class is a standard goal of optimizers.
More formally, this goal can be stated as the meta-problem

\displaystyle\underset{{\mathcal{A}}\in\mathfrak{A}}{\text{minimize}}\,\,\underset{{\mathcal{P}}\in\mathfrak{P}}{\text{maximize}}\,\,{\mathcal{M}}\left({\mathcal{A}},{\mathcal{P}};N\right)

{\mathcal{M}}

{\mathcal{P}}

N

Key concepts and main results

We consider the fixed-point problems

\displaystyle\begin{array}[]{cc}\underset{y\in\mathbb{R}^{d}}{\textrm{find}}&y={\mathbb{T}}(y)\end{array}

where
{\mathbb{T}}\colon\mathbb{R}^{d}\to\mathbb{R}^{d}
is nonexpansive (1-Lipschitz):

\left\|{\mathbb{T}}x-{\mathbb{T}}y\right\|\leq\left\|x-y\right\|,\quad\forall x,y\in\mathbb{R}^{d}.

We measure an algorithm’s convergence via squared norm of the fixed-point residual,
\left\|y-{\mathbb{T}}y\right\|^{2}
.

Complexity lower bound.

There exists a lower bound,
Theorem

1
, for deterministic first-order algorithms for solving (

This result first considers the class of algorithms
\mathfrak{A}_{\text{span}}
satisfying the span condition

\displaystyle y_{k+1}\in y_{k}+\mathrm{span}\left\{y_{0}-{\mathbb{T}}y_{0},\dots,y_{k}-{\mathbb{T}}y_{k}\right\}

and then extends it to the class
\mathfrak{A}_{\text{det}}
of all deterministic first-order algorithms using the resisting oracle technique of
16

Theorem 1

(
(
19
)
)
.

Let
d\geq 2(N-1)
,
y_{0}\in\mathbb{R}^{d}
and

For any deterministic first-order algorithm using

{\mathbb{T}}\colon\mathbb{R}^{d}\to\mathbb{R}^{d}
with a fixed point

such that

\displaystyle\left\|y_{N-1}-{\mathbb{T}}y_{N-1}\right\|^{2}\geq\frac{4R^{2}}{N^{2}}=\frac{4\left\|y_{0}-y_{\star}\right\|^{2}}{N^{2}}.

Following the formulation and notation of (
1
), this states that when
\mathfrak{P}
is the class of all nonexpansive fixed-point problems (represented by the tuple
({\mathbb{T}},y_{0})
),
\mathfrak{A}=\mathfrak{A}_{\text{det}}
and
{\mathcal{M}}({\mathcal{A}},{\mathbb{T}},y_{0};N)=\frac{\left\|y_{N-1}-{\mathbb{T}}y_{N-1}\right\|^{2}}{\left\|y_{0}-y_{\star}\right\|^{2}}
, then for any

\max_{({\mathbb{T}},y_{0})\in\mathfrak{P}}{\mathcal{M}}({\mathcal{A}},{\mathbb{T}},y_{0};N)\geq\frac{4}{N^{2}}

Here we use the convention of denoting the squared fixed-point residual norm for

Optimal Halpern method exactly matches the lower bound.

The lower bound of

: for

\displaystyle y_{k+1}=\frac{1}{k+2}y_{0}+\frac{k+1}{k+2}{\mathbb{T}}y_{k}.

(OHM)

Theorem 2

(

Suppose

\displaystyle\|y_{N-1}-{\mathbb{T}}y_{N-1}\|^{2}\leq\frac{4\|y_{0}-y_{\star}\|^{2}}{N^{2}}.

(3)

Again using the notation of (

\max_{({\mathbb{T}},y_{0})\in\mathfrak{P}}{\mathcal{M}}({\mathcal{A}},{\mathbb{T}},y_{0};N)\leq\frac{4}{N^{2}}

\displaystyle\min_{{\mathcal{A}}\in\mathfrak{A}_{\text{det}}}\,\max_{({\mathbb{T}},y_{0})\in\mathfrak{P}}\,{\mathcal{M}}({\mathcal{A}},{\mathbb{T}},y_{0};N)=\frac{4}{N^{2}}.

Class of H-matrix representable algorithms.

OHM
is a fixed step-size algorithm that admits a representation of the form

\displaystyle y_{k+1}=y_{k}-\sum_{j=0}^{k}h_{k+1,j+1}\left(y_{j}-{\mathbb{T}}y_{j}\right)

(4)

with some predetermined
h_{k+1,j+1}\in\mathbb{R}
.
When an algorithm with
N-1
total iterations (operator evaluations of
{\mathbb{T}}
) is expressible in the format (
4
), we say it is
H-matrix representable
, and define its
H-matrix
as the lower triangular matrix
H\in\mathbb{R}^{(N-1)\times(N-1)}
with

\displaystyle(H)_{k,j}=\begin{cases}h_{k,j}&\text{if $j\leq k$}\\
0&\text{otherwise.}\end{cases}

For
OHM
, in particular, we have

\displaystyle\begin{split}&\left(H_{\text{OHM}}\right)_{k,j}=\begin{cases}-\frac{j}{k(k+1)}&\text{if }j<k\\
\frac{k}{k+1}&\text{if }j=k.\end{cases}\end{split}

We denote the class of H-matrix representable algorithms by
\mathfrak{A}_{\text{H}}
, so that we have
\mathfrak{A}_{\text{H}}\subset\mathfrak{A}_{\text{span}}\subset\mathfrak{A}_{\text{det}}
.

Non-uniqueness of minimax optimal algorithms via H-dual.

Interestingly,
29
showed that given a fixed
N
, a minimax optimal H-matrix representable algorithm satisfying (
3
) is not unique.
In particular, they introduced the
Dual-OHM
algorithm which exhibits the same rate (
3
) as OHM, defined as

\displaystyle y_{k+1}=y_{k}+\frac{N-k-1}{N-k}\left({\mathbb{T}}y_{k}-{\mathbb{T}}y_{k-1}\right),\quad k=0,\dots,N-2

(Dual-OHM)

where
{\mathbb{T}}y_{-1}=y_{0}
.

Dual-OHM
has the H-matrix

\displaystyle\begin{split}\left(H_{\text{Dual-OHM}}\right)_{k,j}=\begin{cases}-\frac{N-k}{(N-j)(N-j+1)}&\text{if }j<k\\
\frac{N-k}{N-k+1}&\text{if }j=k\end{cases}\end{split}

which is the anti-diagonal transpose of
H_{\text{OHM}}
, i.e., they are the reflections of each other along the anti-diagonal:

\displaystyle\left(H_{\text{Dual-OHM}}\right)_{k,j}=\left(H_{\text{OHM}}\right)_{N-j,N-k}.

In general, the
H-dual
of an algorithm in
\mathfrak{A}_{\mathrm{H}}
is an algorithm represented by the anti-diagonal transpose of its H-matrix—the terminology originated from
11
.

29

3
), admitting an
(N-2)
-dimensional open and convex parametrization.
At the same time, however, they showed that their family is incomplete, i.e., fails to capture all H-matrices with the rate (
3
).
Complete characterization of minimax optimal H-matrices, i.e., finding all solutions to (
1
) within
\mathfrak{A}_{\text{H}}
, thus has been left as an open problem.

Main contributions.

In this paper, we close the problem of identifying the set of all exact minimax optimal H-matrices for nonexpansive fixed-point problems.
The set is characterized as (a subset of) the intersection of level sets of
N-1
homogeneous polynomials
P(N-1,m;H)
of degree
m
(where
m
runs over
1,\dots,N-1
) in the entries of H-matrices.
We define them in
Section

3
, and name them
H-invariants
, as their values stay invariant over the set of optimal H-matrices.
We additionally define what we call
H-certificates

\lambda_{k,j}^{\star}(H)
(where
k=2,\dots,N
and
j=1,\dots,k-1
), which are multipliers coupled with inequalities used in its convergence proof, which should be nonnegative. They are also polynomials in the entries of
H
, and the inequality constraints
\lambda_{k,j}^{\star}(H)\geq 0
characterize a region of optimality within the common level set of H-invariants.
Using these algebraic quantities, we state our main result as follows.

Theorem 3
.

A fixed-point algorithm (
4
) achieves the exact optimal worst-case rate of
\left\|y_{N-1}-{\mathbb{T}}y_{N-1}\right\|^{2}\leq\frac{4\left\|y_{0}-y_{\star}\right\|^{2}}{N^{2}}
over the class of nonexpansive operators
{\mathbb{T}}\colon\mathbb{R}^{d}\to\mathbb{R}^{d}
if and only if

\displaystyle\begin{cases}P(N-1,m;H)=\frac{1}{N}\binom{N}{m+1},&m=1,\dots,N-1\\
\lambda_{k,j}^{\star}(H)\geq 0,&k=2,\dots,N,\,\,j=1,\dots,k-1.\end{cases}

As byproducts of this main characterization result, we obtain some interesting additional results.

•

We show that
OHM
is the only
anytime algorithm
, converging at the minimax optimal rate for all iterations
k
.

•

We provide a procedure for identifying new optimal algorithms, with explicit H-matrices, by requiring majority of H-certificates to be
0
(with only one nonzero
\lambda_{k,j}^{\star}(H)
per each
j=1,\dots,N-1
). These algorithms are equipped with simple convergence proofs involving only the corresponding sparse set of inequalities.
From this, we discover the first optimal algorithms that are self-H-dual or lack an optimal H-dual.

3
H-invariants and H-certificates: Motivation and definitions

3.1
H-invariants

H-invariants first appeared in
29
(without the name) as a tool to show that when the operator is linear, an algorithm in
\mathfrak{A}_{\mathrm{H}}
and its H-dual produce the exact same terminal iterates given the same initial points (while the intermediate trajectories may significantly differ).
We start with this discussion, and then naturally define H-invariants.

Suppose that
{\mathbb{T}}
is linear, so that there exists a matrix
G\in\mathbb{R}^{d\times d}
satisfying
{\mathbb{T}}y=(I-2G)y=y-2Gy
for all
y\in\mathbb{R}^{d}
, where
I
is the identity matrix.
Then we can write

\displaystyle y_{k+1}=y_{k}-\sum_{j=0}^{k}2h_{k+1,j+1}Gy_{j}.

Using induction, we can write for
k=0,\dots,N-1
,

\displaystyle y_{k}=\sum_{m=0}^{k}(-1)^{m}P(k,m;2H)G^{m}y_{0}

(5)

where
P(k,0;H)=1
and for
m=1,\dots,k
,

\displaystyle P(k,m;H)=\sum_{\begin{subarray}{c}1\leq j(1)\leq i(1)<j(2)\leq i(2)<\cdots\leq i(m-1)<j(m)\leq i(m)\leq k\end{subarray}}\prod_{r=1}^{m}h_{i(r),j(r)}.

The first few concrete expressions are as follows:

\displaystyle P(1,1;H)

\displaystyle=h_{1,1}

\displaystyle P(2,1;H)

\displaystyle=h_{1,1}+h_{2,1}+h_{2,2}

\displaystyle P(2,2;H)

\displaystyle=h_{1,1}h_{2,2}

\displaystyle P(3,1;H)

\displaystyle=h_{1,1}+h_{2,1}+h_{2,2}+h_{3,1}+h_{3,2}+h_{3,3}

\displaystyle P(3,2;H)

\displaystyle=h_{1,1}h_{2,2}+h_{1,1}h_{3,2}+h_{1,1}h_{3,3}+h_{2,1}h_{3,3}+h_{2,2}h_{3,3}

\displaystyle P(3,3;H)

\displaystyle=h_{1,1}h_{2,2}h_{3,3}.

By definition, algorithms with same values of
P(N-1,m;H)
for
m=1,\dots,N-1
produce the same terminal iterate
y_{N-1}
if
{\mathbb{T}}
is linear.
This is the case for algorithms in the H-dual relationship
(
29
, Proposition I.1)
.
Note that each
P(k,m;H)
is a homogeneous polynomial with degree
m
in entries of
H
, so the effect of scaling
H
is
P(k,m;cH)=c^{m}P(k,m;H)
for any
c\in\mathbb{R}
and
m=1,\dots,k
.

Definition 1
.

For an algorithm represented by a lower triangular
H\in\mathbb{R}^{(N-1)\times(N-1)}
, its
H-invariants
are the quantities
P(N-1,m;H)
for
m=1,\dots,N-1
.

3.2
H-certificates

Given a nonexpansive operator
{\mathbb{T}}
, define
{\mathbb{A}}=2({\mathbb{I}}+{\mathbb{T}})^{-1}-{\mathbb{I}}
(equivalently,
{\mathbb{T}}=2{\mathbb{J}}_{{\mathbb{A}}}-{\mathbb{I}}
where
{\mathbb{J}}_{{\mathbb{A}}}=({\mathbb{I}}+{\mathbb{A}})^{-1}
is the resolvent).
Here the inverse of
{\mathbb{I}}+{\mathbb{T}}
denotes the set-valued operator defined by

\displaystyle z\in({\mathbb{I}}+{\mathbb{T}})^{-1}(y)\iff({\mathbb{I}}+{\mathbb{T}})(z)=z+{\mathbb{T}}z=y.

Then
{\mathbb{A}}\colon\mathbb{R}^{d}\rightrightarrows\mathbb{R}^{d}
is a maximally monotone operator, satisfying
\left\langle u-v,x-y\right\rangle\geq 0
for any
u\in{\mathbb{A}}x
,
v\in{\mathbb{A}}y
.
For each
y_{k}
(
k=0,\dots,N-1
) generated by an H-matrix representable algorithm (
4
), define
x_{k+1}={\mathbb{J}}_{{\mathbb{A}}}y_{k}
and
g_{k+1}=y_{k}-x_{k+1}\in{\mathbb{A}}x_{k+1}
.
Then
{\mathbb{T}}y_{k}=x_{k+1}-g_{k+1}=y_{k}-2g_{k+1}
, so we can write

\displaystyle y_{k+1}=y_{k}-\sum_{j=0}^{k}2h_{k+1,j+1}g_{j+1}.

Furthermore, nonexpansivity inequalities for
{\mathbb{T}}
can be recast into monotonicity inequalities for
{\mathbb{A}}
as

\displaystyle\left\|y_{k-1}-y_{j-1}\right\|^{2}-\left\|{\mathbb{T}}y_{k-1}-{\mathbb{T}}y_{j-1}\right\|^{2}\geq 0

\displaystyle\iff\left\|x_{k}+g_{k}-x_{j}-g_{j}\right\|^{2}-\left\|x_{k}-g_{k}-x_{j}+g_{j}\right\|^{2}\geq 0

\displaystyle\iff\left\langle x_{k}-x_{j},g_{k}-g_{j}\right\rangle\geq 0

and similarly,

\displaystyle\left\|y_{k-1}-y_{\star}\right\|^{2}-\left\|{\mathbb{T}}y_{k-1}-y_{\star}\right\|^{2}\geq 0\iff\left\langle g_{k},x_{k}-y_{\star}\right\rangle\geq 0

for
k,j=1,\dots,N
and
y_{\star}\in\mathrm{Fix}\,{\mathbb{T}}
.
In
Theorem

5
, we prove that if
H
satisfies the
H-invariance conditions

P(N-1,m;H)=\frac{1}{N}\binom{N}{m+1}
for
m=1,\dots,N-1
, then there exist unique
\lambda_{k,j}
, given as explicit polynomials in the entries of
H
(whose precise forms are also given in
Theorem

5
) for
1\leq j<k\leq N
, satisfying

\displaystyle 0=N\left\|g_{N}\right\|^{2}+\left\langle g_{N},x_{N}-y_{0}\right\rangle+\sum_{k=1}^{N}\sum_{j=1}^{k-1}\lambda_{k,j}\left\langle x_{k}-x_{j},g_{k}-g_{j}\right\rangle.

(6)

Definition 2
.

For an H-matrix representable algorithm satisfying
P(N-1,m;H)=\frac{1}{N}\binom{N}{m+1}
for
m=1,\dots,N-1
, its
H-certificates
are the unique values
\lambda_{k,j}^{\star}(H)
of
\lambda_{k,j}
for each pair
(k,j)
of indices
1\leq j<k\leq N
satisfying (
6
).

If
\lambda_{k,j}^{\star}(H)\geq 0
for all
1\leq j<k\leq N
, then from (
6
) we have

\displaystyle 0

\displaystyle\geq N\left\|g_{N}\right\|^{2}+\left\langle g_{N},x_{N}-y_{0}\right\rangle\geq N\left\|g_{N}\right\|^{2}+\left\langle g_{N},y_{\star}-y_{0}\right\rangle\geq\frac{N}{2}\left\|g_{N}\right\|^{2}-\frac{1}{2N}\left\|y_{\star}-y_{0}\right\|^{2}

where the second inequality uses monotonicity of
{\mathbb{A}}
and the last inequality is Young’s inequality.
This, in turn, implies

\displaystyle\left\|y_{N-1}-{\mathbb{T}}y_{N-1}\right\|^{2}=4\left\|g_{N}\right\|^{2}\leq\frac{4\left\|y_{0}-y_{\star}\right\|^{2}}{N^{2}}.

The above discussion illustrates why H-invariance and nonnegative H-certificates together imply exact optimality of the algorithm defined by
H
, and indicates that the proof of its optimality is given by the form (
6
).

4
Necessity of H-invariance for optimality

This section is devoted to showing the following result, stating that H-invariance conditions are necessary for optimality.

Theorem 4
.

A fixed-point algorithm (
4
) achieves the exact optimal worst-case rate of
\left\|y_{N-1}-{\mathbb{T}}y_{N-1}\right\|^{2}\leq\frac{4\left\|y_{0}-y_{\star}\right\|^{2}}{N^{2}}
over the class of nonexpansive operators only if
P(N-1,m;H)=\frac{1}{N}\binom{N}{m+1}
for
m=1,\dots,N-1
.

Proof.

Consider the worst-case nonexpansive operator from
(
19
)
,
{\mathbb{T}}={\mathbb{I}}-2G\colon\mathbb{R}^{N}\to\mathbb{R}^{N}
where
G
is the linear operator represented by the matrix

\displaystyle G=\frac{1}{2}\begin{bmatrix}1&0&\cdots&0&1\\
-1&1&\cdots&0&0\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
0&0&\cdots&1&0\\
0&0&\cdots&-1&1\end{bmatrix}\in\mathbb{R}^{N\times N}.

The matrix
2G
has determinant 2, showing that
G
has a unique zero, i.e.,
{\mathbb{T}}
has a unique fixed point
y_{\star}=0
.

Let us denote the elementary basis vectors of
\mathbb{R}^{N}
by
e_{1},\dots,e_{N}
.
Observe that
G(e_{1}+\dots+e_{N})=e_{1}
, so

\displaystyle G^{-1}e_{1}=e_{1}+\dots+e_{N}=\begin{bmatrix}1\\
1\\
\vdots\\
1\end{bmatrix}\in\mathbb{R}^{N}.

Suppose that we run the algorithm (
4
) with
y_{0}=-\frac{R}{\sqrt{N}}G^{-1}e_{1}
.
(Note that with this choice, we have
\left\|y_{0}-y_{\star}\right\|=R
.)
By the definition of our update rules, we have

\displaystyle y_{k+1}\in y_{k}+\spann\{Gy_{0},Gy_{1},\dots,Gy_{k}\}

(7)

for
k=0,\dots,N-2
.
Using this and the induction arguments, we can show that

\displaystyle y_{j}\in y_{0}+\spann\{e_{1},\dots,e_{j}\}

(8)

for
j=1,\dots,N-1
.
The case
j=1
is immediate from (
7
) with
k=0
and
Gy_{0}\in\spann\{e_{1}\}
.
Next, suppose that (
8
) holds for
j=1,\dots,\ell
, where
\ell\leq N-2
.
Then by (
7
), we have

\displaystyle y_{\ell+1}

\displaystyle\in y_{\ell}+\spann\{Gy_{0},Gy_{1},\dots,Gy_{\ell}\}

\displaystyle\in y_{0}+\spann\{e_{1},\dots,e_{\ell}\}+\spann\{Gy_{0},Gy_{1},\dots,Gy_{\ell}\}.

By induction hypothesis, we have
Gy_{j}\in Gy_{0}+\spann\{Ge_{1},\dots,Ge_{j}\}
for
j=1,\dots,\ell
, and because
Ge_{j}=\frac{1}{2}e_{j}-\frac{1}{2}e_{j+1}
,

\displaystyle\spann\{Gy_{0},Gy_{1},\dots,Gy_{\ell}\}\in\spann\{e_{1},\dots,e_{\ell+1}\}.

Therefore
y_{\ell+1}\in y_{0}+\spann\{e_{1},\dots,e_{\ell+1}\}
, which completes the induction and thus proves (
8
).

Now by definition of
{\mathbb{T}}
and (
8
), we have

\displaystyle y_{N-1}-{\mathbb{T}}y_{N-1}=2Gy_{N-1}

\displaystyle\in 2Gy_{0}+\spann\{Ge_{1},\dots,Ge_{N-1}\}

\displaystyle=-\frac{2R}{\sqrt{N}}e_{1}+\spann\{Ge_{1},\dots,Ge_{N-1}\}.

Observe that
V=\spann\{Ge_{1},\dots,Ge_{N-1}\}
is an
(N-1)
-dimensional subspace of
\mathbb{R}^{N}
, and its orthogonal complement is
V^{\perp}=\spann\{e_{1}+\dots+e_{N}\}
.
Therefore,

\displaystyle\left\|y_{N-1}-{\mathbb{T}}y_{N-1}\right\|^{2}

\displaystyle=\left\|2Gy_{N-1}\right\|^{2}

\displaystyle=\left\|\Pi_{V}\left(2Gy_{N-1}\right)\right\|^{2}+\left\|\Pi_{V^{\perp}}\left(2Gy_{N-1}\right)\right\|^{2}

\displaystyle\geq\left\|\Pi_{V^{\perp}}\left(2Gy_{N-1}\right)\right\|^{2}

\displaystyle=\left\|\Pi_{V^{\perp}}\left(-\frac{2R}{\sqrt{N}}e_{1}\right)\right\|^{2}

\displaystyle=\left\|-\frac{2R}{N\sqrt{N}}(e_{1}+\dots+e_{N})\right\|^{2}

\displaystyle=\frac{4R^{2}}{N^{2}}

where
\Pi_{V}
and
\Pi_{V^{\perp}}
denote the projection maps onto the subspaces
V
and
V^{\perp}
, respectively.
If
y_{N-1}
is generated by an algorithm achieving the exact optimal worst case, then it must necessarily satisfy
\left\|y_{N-1}-{\mathbb{T}}y_{N-1}\right\|^{2}\leq\frac{4\left\|y_{0}-y_{\star}\right\|^{2}}{N^{2}}=\frac{4R^{2}}{N^{2}}
so the equality must hold.
This holds if and only if
\Pi_{V}(2Gy_{N-1})=0
, i.e., if and only if

\displaystyle Gy_{N-1}=\Pi_{V^{\perp}}(Gy_{N-1})=-\frac{R}{N\sqrt{N}}(e_{1}+\dots+e_{N}).

(9)

Now from (
5
) we have

\displaystyle Gy_{N-1}=\sum_{m=0}^{N-1}(-1)^{m}P(N-1,m;2H)G^{m+1}y_{0}.

(10)

Next, we show that

\displaystyle G^{m+1}y_{0}=-\frac{R}{\sqrt{N}}\frac{1}{2^{m}}\sum_{j=1}^{m+1}(-1)^{j-1}\binom{m}{j-1}e_{j}

(11)

for
m=0,1,\dots,N-1
.
The case
m=0
is immediate because
Gy_{0}=-\frac{R}{\sqrt{N}}e_{1}=-\frac{R}{\sqrt{N}}\frac{1}{2^{0}}\binom{0}{0}e_{1}
.
Now, to use induction, suppose that (
11
) holds for some
0\leq m\leq N-2
.
Then

\displaystyle G^{m+2}y_{0}

\displaystyle=G\left(G^{m+1}y_{0}\right)

\displaystyle=G\left(-\frac{R}{\sqrt{N}}\frac{1}{2^{m}}\sum_{j=1}^{m+1}(-1)^{j-1}\binom{m}{j-1}e_{j}\right)

\displaystyle=-\frac{R}{\sqrt{N}}\frac{1}{2^{m}}\sum_{j=1}^{m+1}(-1)^{j-1}\binom{m}{j-1}Ge_{j}

\displaystyle=-\frac{R}{\sqrt{N}}\frac{1}{2^{m}}\sum_{j=1}^{m+1}(-1)^{j-1}\binom{m}{j-1}\frac{e_{j}-e_{j+1}}{2}

\displaystyle=-\frac{R}{\sqrt{N}}\frac{1}{2^{m+1}}\sum_{j=1}^{m+1}(-1)^{j-1}\binom{m}{j-1}(e_{j}-e_{j+1})

\displaystyle=-\frac{R}{\sqrt{N}}\frac{1}{2^{m+1}}\left(e_{1}+\sum_{j=2}^{m+1}(-1)^{j-1}\left(\binom{m}{j-1}+\binom{m}{j-2}\right)e_{j}+(-1)^{m+1}e_{m+2}\right)

\displaystyle=-\frac{R}{\sqrt{N}}\frac{1}{2^{m+1}}\left(e_{1}+\sum_{j=2}^{m+1}(-1)^{j-1}\binom{m+1}{j-1}e_{j}+(-1)^{m+1}e_{m+2}\right)

\displaystyle=-\frac{R}{\sqrt{N}}\frac{1}{2^{m+1}}\sum_{j=1}^{m+2}(-1)^{j-1}\binom{m+1}{j-1}e_{j}

where for the second last equality we use the combinatorial identity
\binom{m}{j-1}+\binom{m}{j-2}=\binom{m+1}{j-1}
.
This completes the induction, and proves (
11
).
Now we plug (
11
) into (
10
) and use
P(N-1,m;2H)=2^{m}P(N-1,m;H)
to cancel out the
2^{m}
factor to obtain

\displaystyle Gy_{N-1}

\displaystyle=-\frac{R}{\sqrt{N}}\sum_{m=0}^{N-1}(-1)^{m}P(N-1,m;H)\sum_{j=1}^{m+1}(-1)^{j-1}\binom{m}{j-1}e_{j}

\displaystyle=-\frac{R}{\sqrt{N}}\sum_{j=1}^{N}\left[\sum_{m=j-1}^{N-1}(-1)^{m+j-1}\binom{m}{j-1}P(N-1,m;H)\right]e_{j}.

Therefore, (
9
) holds if and only if

\displaystyle\sum_{m=j-1}^{N-1}(-1)^{m+j-1}\binom{m}{j-1}P(N-1,m;H)=\frac{1}{N}

(12)

for
j=1,\dots,N
.
Starting with the case
j=N
, which yields

\binom{N-1}{N-1}P(N-1,N-1;H)=\frac{1}{N}\iff P(N-1,N-1;H)=\frac{1}{N}=\frac{1}{N}\binom{N}{N},

we can solve (
12
) in the order of
j=N,N-1,\dots,1
to determine the values of each
P(N-1,j;H)
—more formally, the system of linear equations (
12
) for
j=N,\dots,1
having
P(N-1,m;H)
(
m=N-1,N-2,\dots,0
) as variables, is lower triangular with nonnegative diagonals—so the values of
P(N-1,m;H)
satisfying (
12
) uniquely exists.
Now consider the combinatorial identity

\displaystyle\sum_{m=j-1}^{N-1}(-1)^{m+j-1}\binom{m}{j-1}\binom{N}{m+1}=1

for any fixed
j=1,\dots,N
, which follows by setting
a=-j
,
b=N
and
c=N-j
in
Lemma

11
—the standard Chu-Vandermonde identity derived from the binomial series expansion, provided in Appendix
A
—and then using the identities
\binom{-j}{i}=(-1)^{i}\binom{i+j-1}{i}=(-1)^{i}\binom{i+j-1}{j-1}
, applying the change of index
m=i+j-1
and using
\binom{N}{N-m-1}=\binom{N}{m+1}
.
This shows that (
12
) holds if and only if
P(N-1,m;H)=\frac{1}{N}\binom{N}{m+1}
for
m=0,\dots,N-1
, which proves
Theorem

4
.
Note that in the theorem statement, we do not include the case
m=0
which gives
P(N-1,0;H)=1
, as it holds trivially by definition.

∎

5
Optimality proof under H-invariance and nonnegative H-certificates

In the previous section, we have proved that the H-invariance conditions
P(N-1,m;H)=\frac{1}{N}\binom{N}{m+1}
(
m=1,\dots,N-1
) are necessary for exact optimality.
In this section, we prove its partial converse—an algorithm satisfying H-invariance achieves exact optimality
under the additional nonnegativity conditions
\lambda^{\star}_{k,j}(H)\geq 0
on H-certificates.
We illustrate how
\lambda^{\star}_{k,j}(H)
are characterized, and provide explicit algebraic formulas for them.
Then, by their construction, it becomes clear why H-invariance together with nonnegative H-certificates implies optimality.

5.1
\lambda^{\star}(H)
as a solution to linear system

We have seen in
Section

3.2
that if the key identity (
6
) is satisfied with
\lambda_{k,j}\geq 0
, then it implies the optimal rate.
To clarify, this identity indicates the equality between formal quadratic-form-like expressions involving the vector variables
g_{1},\dots,g_{N}
.
That is, by expanding (
6
) and regrouping the terms, we can rewrite (
6
) in the form

\displaystyle 0=\sum_{k=1}^{N}\sum_{j=1}^{k}s_{k,j}(H,\lambda)\left\langle g_{k},g_{j}\right\rangle,

(13)

and the equality is equivalent to the system of equations
s(H,\lambda)=0
, i.e.,
s_{k,j}(H,\lambda)=0
for all
k=1,\dots,N
and
j=1,\dots,k
.
Below, we provide the expressions for
s_{k,j}(H,\lambda)
, which reveals that
s(H,\lambda)=0
is a linear system in
\lambda
.

Lemma 1
.

The
s_{k,j}(H,\lambda)
’s in (
13
) have the explicit expressions

\displaystyle s_{N,N}(H,\lambda)

\displaystyle=N-1-\sum_{j=1}^{N-1}\lambda_{N,j}

(14)

\displaystyle s_{N,j}(H,\lambda)

\displaystyle=2\left(\lambda_{N,j}-\sum_{i=j}^{N-1}\sum_{k=1}^{i}h_{i,j}\lambda_{N,k}-\sum_{i=j}^{N-1}h_{i,j}\right),\quad j=1,\dots,N-1

(15)

\displaystyle s_{k,k}(H,\lambda)

\displaystyle=\sum_{i=k+1}^{N}\left(\sum_{j=k}^{i-1}2h_{j,k}-1\right)\lambda_{i,k}-\sum_{j=1}^{k-1}\lambda_{k,j},\quad k=1,\dots,N-1

(16)

\displaystyle s_{k,j}(H,\lambda)

\displaystyle=2\left(\lambda_{k,j}-\sum_{n=j}^{k-1}h_{n,j}\sum_{i=1}^{n}\lambda_{k,i}+c_{k,j}\right),\quad j=1,\dots,k-1

(17)

where
c_{k,j}=\sum_{m=k+1}^{N}\sum_{n=k}^{m-1}\left(h_{n,j}\lambda_{m,k}+h_{n,k}\lambda_{m,j}\right)
.

Remark.

Note that
c_{k,j}
depends only on
\lambda_{m,\cdot}
’s with
m>k
.

Proof.

For each
x_{k}
(
k=1,\dots,N
), we have

\displaystyle x_{k}=y_{k-1}-g_{k}=y_{0}+\sum_{i=1}^{k-1}(y_{i}-y_{i-1})-g_{k}=y_{0}-g_{k}-\sum_{i=1}^{k-1}\sum_{j=1}^{i}2h_{i,j}g_{j}.

Plugging this expression into (
6
) in places of
x_{N},x_{k},x_{j}
(with appropriate choice of summation indices to avoid overlapping), expanding all inner products and gathering the coefficients of each
\left\langle g_{k},g_{j}\right\rangle
, we obtain the desired expressions for
s_{k,j}
.
∎

The remaining step is to solve this symbolic linear system
s(H,\lambda)=0
in terms of
\lambda
.
That is, we express the (unique) solution
\lambda=\lambda^{\star}(H)
to
s(H,\lambda)=0
in an explicit form in terms of
H
.
This is the part that requires a significant technical effort, which we detail through the following Section
5.2
.

5.2
Explicit characterization of
\lambda^{\star}(H)

We define some additional expressions used for characterizing
\lambda^{\star}(H)
.
First, define

\displaystyle D(N;H)=\sum_{m=0}^{N-1}(-1)^{m}P(N-1,m;H).

Next, we define the
Q-functions
, which can be viewed as partial H-invariants, as

\displaystyle Q(k,m,j;H)=\sum_{\begin{subarray}{c}j=j(1)\leq i(1)<j(2)\leq i(2)<\cdots\leq i(m-1)<j(m)\leq i(m)\leq k\end{subarray}}\prod_{r=1}^{m}h_{i(r),j(r)}

for
k=1,\dots,N-1
and
m,j=1,\dots,k
.
Each
Q(k,m,j;H)
is the partial sum of terms consisting
P(k,m;H)
such that its smallest column index
j(1)
equals
j
.
Note that when
j>k-m+1
, the summation defining
Q(k,m,j;H)
becomes vacuous, and in this case we define
Q(k,m,j;H)=0
.

In the following, for simpler notations, we will fix
H
and drop the
H
-dependency within
P,Q,D,s
and
\lambda
.

Theorem 5
.

Suppose
P(N-1,m)=\frac{1}{N}\binom{N}{m+1}
for
m=1,\dots,N-1
.
Then the following are the unique solutions to the linear system
s(\lambda)=0
:

\displaystyle\lambda_{N,j}^{\star}=\frac{1}{D(N)}\sum_{m=1}^{N-1}(-1)^{m-1}Q(N-1,m,j)=N\sum_{m=1}^{N-j}(-1)^{m-1}Q(N-1,m,j),\quad j=1,\dots,N-1

and for
k=1,\dots,N-1
,

\displaystyle\lambda_{k,j}^{\star}

\displaystyle=\frac{1}{D(N)}\sum_{\ell=1}^{N-1}\sum_{m=1}^{N-1}(-1)^{\ell+m-1}\binom{\ell+m}{m}Q(N-1,\ell,j)Q(N-1,m,k)

\displaystyle=N\sum_{\ell=1}^{N-j}\sum_{m=1}^{N-k}(-1)^{\ell+m-1}\binom{\ell+m}{m}Q(N-1,\ell,j)Q(N-1,m,k),\quad j=1,\dots,k-1.

In the secondary expressions for
\lambda_{k,j}^{\star}
in
Theorem

5
, the scope of summation is reduced from
1,\dots,N-1
to
1,\dots,N-j
or
1,\dots,N-k
. This holds because
Q(N-1,m,j)=0
when
m+j>N
(in that case, the corresponding summation becomes vacuous).
We also use the fact that
D(N)=\frac{1}{N}
under H-invariance, which state in
Lemma

12
in Appendix
A
with its simple proof.

To prove
Theorem

5
, we first establish the following handy algebraic identities.

Lemma 2
.

For
k=1,\dots,N-1
and
m,j=1,\dots,k
, the following identities hold:

\displaystyle P(k,m)=\sum_{j=1}^{k}Q(k,m,j)

\displaystyle Q(k,m+1,j)=\sum_{\ell=j+1}^{k}\left(Q(k,m,\ell)\sum_{i=j}^{\ell-1}h_{i,j}\right)=\sum_{\ell=j+1}^{k-m+1}\left(Q(k,m,\ell)\sum_{i=j}^{\ell-1}h_{i,j}\right).

Proof.

Define the sets of sequences of indices
I(k,m)
and
I(k,m,j)
by

\displaystyle I(k,m)

\displaystyle=\left\{(i(1),j(1),\dots,i(m),j(m))\,|\,j(r)\leq i(r)<j(r+1)\leq i(r+1)\,\text{ for }\,r=1,\dots,m-1,\,\,i(m)\leq k\right\}

\displaystyle\subset\{1,\dots,k\}^{2m}

and

\displaystyle I(k,m,j)

\displaystyle=\left\{(i(1),j(1),\dots,i(m),j(m))\in I(k,m)\,|\,j(1)=j\right\}\subset\{1,\dots,k\}^{2m}.

Note that
I(k,m,j)
is possibly empty (if
m+j>k+1
).
By definition,
I(k,m)=\coprod_{j=1}^{k}I(k,m,j)
where
\coprod
is denotes the disjoint union.
Additionally, by definition we can write

\displaystyle P(k,m)

\displaystyle=\sum_{(i(1),j(1),\dots,i(m),j(m))\in I(k,m)}\prod_{r=1}^{m}h_{i(r),j(r)}

\displaystyle Q(k,m,j)

\displaystyle=\sum_{(i(1),j(1),\dots,i(m),j(m))\in I(k,m,j)}\prod_{r=1}^{m}h_{i(r),j(r)}

where any vacuous summation occurring in the case
I(k,m,j)=\emptyset
is treated as zero.
The first identity

\displaystyle P(k,m)=\sum_{j=1}^{k}Q(k,m,j)

follows directly from the fact that
I(k,m)
is the disjoint union of
I(k,m,j)
for
j=1,\dots,k
.

Next, observe that

\displaystyle Q(k,m+1,j)

\displaystyle=\sum_{(i(1),j(1),\dots,i(m+1),j(m+1))\in I(k,m+1,j)}\prod_{r=1}^{m+1}h_{i(r),j(r)}

\displaystyle=\sum_{\ell=j+1}^{k}\sum_{\begin{subarray}{c}(i(1),j(1),\dots,i(m+1),j(m+1))\in I(k,m+1,j)\\
j(2)=\ell\end{subarray}}\prod_{r=1}^{m+1}h_{i(r),j(r)}

\displaystyle=\sum_{\ell=j+1}^{k}\sum_{i=j}^{\ell-1}\sum_{\begin{subarray}{c}(i(1),j(1),\dots,i(m+1),j(m+1))\in I(k,m+1,j)\\
i(1)=i,\,\,j(2)=\ell\end{subarray}}\prod_{r=1}^{m+1}h_{i(r),j(r)}

\displaystyle=\sum_{\ell=j+1}^{k}\sum_{i=j}^{\ell-1}\sum_{\begin{subarray}{c}(i,j,i(2),j(2),\dots,i(m+1),j(m+1))\in I(k,m+1,j)\\
j(2)=\ell\end{subarray}}h_{i,j}\prod_{r=2}^{m+1}h_{i(r),j(r)}

\displaystyle=\sum_{\ell=j+1}^{k}\left(\sum_{i=j}^{\ell-1}h_{i,j}\right)\sum_{\begin{subarray}{c}(i(2),j(2),\dots,i(m+1),j(m+1))\in I(k,m,\ell)\end{subarray}}\prod_{r=2}^{m+1}h_{i(r),j(r)}

where the last line follows from the fact that the inner summation is independent of
(i(1),j(1))=(i,j)
, and

(i,j,i(2),j(2),\dots,i(m+1),j(m+1))\in I(k,m+1,j)\,\text{ with }\,j(2)=\ell

holds if and only if

\displaystyle\ell=j(2)\leq i(2)<j(3)\leq\cdots<j(m+1)\leq i(m+1)\leq k

\displaystyle\!\!\iff(i(2),j(2),\dots,i(m+1),j(m+1))\in I(k,m,\ell).

Finally, by definition of
Q(k,m,\ell)
we conclude that

\displaystyle Q(k,m+1,j)=\sum_{\ell=j+1}^{k}\left(\sum_{i=j}^{\ell-1}h_{i,j}\right)Q(k,m,\ell),

which proves the second identity.
∎

Proof of
Theorem

5
.

We first show that the proposed expressions for
\lambda^{\star}
satisfy
s(\lambda^{\star})=0
by plugging
\lambda^{\star}
into each line of
Lemma

1
and verifying that it simplifies to zero.

Part 1.

s_{N,N}(\lambda^{\star})=0
.
For this, observe that

\displaystyle\sum_{j=1}^{N-1}\lambda_{N,j}^{\star}

\displaystyle=\frac{1}{D(N)}\sum_{j=1}^{N-1}\sum_{m=1}^{N-1}(-1)^{m-1}Q(N-1,m,j)=\frac{1}{D(N)}\sum_{m=1}^{N-1}(-1)^{m-1}\sum_{j=1}^{N-1}Q(N-1,m,j)

\displaystyle=\frac{1}{D(N)}\sum_{m=1}^{N-1}(-1)^{m-1}P(N-1,m)=\frac{1-D(N)}{D(N)}=N-1.

where we use the first identity from
Lemma

2
and
Lemma

12
(
D(N)=\frac{1}{N}
).
This shows
s_{N,N}(\lambda^{\star})=N-1-\sum_{j=1}^{N-1}\lambda_{N,j}^{\star}=0
.

Part 2.

s_{N,j}(\lambda^{\star})=0
for
j=1,\dots,N-1
.
For any fixed
j\in\{1,\dots,N-1\}
, we have

\displaystyle\lambda_{N,j}^{\star}-\sum_{i=j}^{N-1}\sum_{k=1}^{i}h_{i,j}\lambda_{N,k}^{\star}

\displaystyle=\lambda_{N,j}^{\star}-\sum_{k=1}^{N-1}\sum_{i=\max\{k,j\}}^{N-1}h_{i,j}\lambda_{N,k}^{\star}

\displaystyle=\lambda_{N,j}^{\star}-\sum_{k=1}^{j}\sum_{i=j}^{N-1}h_{i,j}\lambda_{N,k}^{\star}-\sum_{k=j+1}^{N-1}\sum_{i=k}^{N-1}h_{i,j}\lambda_{N,k}^{\star}

\displaystyle=\lambda_{N,j}^{\star}-\sum_{k=1}^{j}\sum_{i=j}^{N-1}h_{i,j}\lambda_{N,k}^{\star}-\sum_{k=j+1}^{N-1}\sum_{i=j}^{N-1}h_{i,j}\lambda_{N,k}^{\star}-\sum_{k=j+1}^{N-1}\left(\sum_{i=k}^{N-1}h_{i,j}-\sum_{i=j}^{N-1}h_{i,j}\right)\lambda_{N,k}^{\star}

\displaystyle=\lambda_{N,j}^{\star}-\sum_{k=1}^{N-1}\sum_{i=j}^{N-1}h_{i,j}\lambda_{N,k}^{\star}+\sum_{k=j+1}^{N-1}\sum_{i=j}^{k-1}h_{i,j}\lambda_{N,k}^{\star}

\displaystyle=\lambda_{N,j}^{\star}-\sum_{k=1}^{N-1}\sum_{i=j}^{N-1}h_{i,j}\lambda_{N,k}^{\star}+\sum_{\ell=j+1}^{N-1}\sum_{i=j}^{\ell-1}h_{i,j}\lambda_{N,\ell}^{\star}

\displaystyle=\frac{1}{D(N)}\left[\sum_{m=1}^{N-1}(-1)^{m-1}Q(N-1,m,j)-\left(\sum_{i=j}^{N-1}h_{i,j}\right)\sum_{k=1}^{N-1}\sum_{m=1}^{N-1}(-1)^{m-1}Q(N-1,m,k)\right.

\displaystyle\qquad\qquad+\left.\sum_{\ell=j+1}^{N-1}\sum_{i=j}^{\ell-1}h_{i,j}\sum_{m=1}^{N-1}(-1)^{m-1}Q(N-1,m,\ell)\right]

\displaystyle\stackrel{{\scriptstyle(*)}}{{=}}\frac{1}{D(N)}\left[\sum_{m=1}^{N-1}(-1)^{m-1}Q(N-1,m,j)-\left(\sum_{i=j}^{N-1}h_{i,j}\right)\sum_{m=1}^{N-1}(-1)^{m-1}P(N-1,m)\right.

\displaystyle\qquad\qquad+\left.\sum_{m=1}^{N-1}(-1)^{m-1}Q(N-1,m+1,j)\right]

\displaystyle=\frac{1}{D(N)}\left[Q(N-1,1,j)+\left(\sum_{i=j}^{N-1}h_{i,j}\right)(D(N)-1)\right]

\displaystyle=\sum_{i=j}^{N-1}h_{i,j}

where
(*)
uses
Lemma

2
, and the last equality uses
Q(N-1,1,j)=\sum_{i=j}^{N-1}h_{i,j}
, which holds by definition.
This proves

\displaystyle s_{N,j}(\lambda^{\star})=2\left(\lambda_{N,j}^{\star}-\sum_{i=j}^{N-1}\sum_{k=1}^{i}h_{i,j}\lambda_{N,k}^{\star}-\sum_{i=j}^{N-1}h_{i,j}\right)=0.

Part 3.

s_{k,k}(\lambda^{\star})=0
for
k=1,\dots,N-1
.
To show this, first observe that

\displaystyle\sum_{j=1}^{k-1}\lambda_{k,j}^{\star}+\sum_{i=k+1}^{N}\lambda_{i,k}^{\star}

\displaystyle=\sum_{i=1}^{k-1}\lambda_{k,i}^{\star}+\sum_{i=k+1}^{N-1}\lambda_{i,k}^{\star}+\lambda_{N,k}^{\star}

\displaystyle\begin{aligned} &=\frac{1}{D(N)}\sum_{i=1}^{k-1}\sum_{\ell=1}^{N-1}\sum_{m=1}^{N-1}(-1)^{\ell+m-1}\binom{\ell+m}{m}Q(N-1,\ell,i)Q(N-1,m,k)\\
&\quad+\frac{1}{D(N)}\sum_{i=k+1}^{N-1}\sum_{m=1}^{N-1}\sum_{\ell=1}^{N-1}(-1)^{\ell+m-1}\binom{\ell+m}{\ell}Q(N-1,m,k)Q(N-1,\ell,i)\\
&\quad+\frac{1}{D(N)}\sum_{m=1}^{N-1}(-1)^{m-1}Q(N-1,m,k).\end{aligned}

(18)

Within the first and second summations of (
18
), the binomial coefficients
\binom{\ell+m}{m}
and
\binom{\ell+m}{\ell}
are the same, and
Q(N-1,m,k)
appears as a common factor in the summand. Therefore, we can merge these summations to obtain

\displaystyle\sum_{j=1}^{k-1}\lambda_{k,j}^{\star}+\sum_{i=k+1}^{N}\lambda_{i,k}^{\star}

\displaystyle=\frac{1}{D(N)}\sum_{\ell=1}^{N-1}\sum_{m=1}^{N-1}(-1)^{\ell+m-1}\binom{\ell+m}{m}Q(N-1,m,k)\left(\sum_{i=1}^{k-1}Q(N-1,\ell,i)+\sum_{i=k+1}^{N-1}Q(N-1,\ell,i)\right)

\displaystyle\quad+\frac{1}{D(N)}\sum_{m=1}^{N-1}(-1)^{m-1}Q(N-1,m,k)

\displaystyle\begin{aligned} &=\frac{1}{D(N)}\sum_{\ell=1}^{N-1}\sum_{m=1}^{N-1}(-1)^{\ell+m-1}\binom{\ell+m}{m}Q(N-1,m,k)\left(P(N-1,\ell)-Q(N-1,\ell,k)\right)\\

Now, we plug in the identities

\displaystyle\sum_{j=1}^{k-1}\lambda_{k,j}^{\star}+\sum_{i=k+1}^{N}\lambda_{i,k}^{\star}

Part 4.

Part 5 (Uniqueness).

What remains for completing the proof of
Theorem

5
is the uniqueness of
\lambda^{\star}
.
However, note that even without the uniqueness part, our arguments up to Part 4 already establish that
\lambda^{\star}
satisfies (
6
).
Therefore, the H-invariance identities, combined with nonnegativity of H-certificates
\lambda^{\star}
, imply optimality.

The key idea of the uniqueness proof is to subdivide the system
s(\lambda)=0
into
s_{k,j}(\lambda)=0
, for each fixed
k
and
j=1,\dots,k
, and run
k
backwards from
N
to
1
.
We sequentially solve the partial systems
s_{k,j}(\lambda)=0
, viewing only
\lambda_{k,1},\dots,\lambda_{k,k-1}
as variables and regarding
\lambda_{m,\cdot}
with
m>k
as constants, as their values are already determined from previous rounds.
Then we analyze the determinants of those partial systems to show that their solutions must be unique, if they are consistent.
In fact, we also need (a slightly generalized version of) this uniqueness result in
Section

6
—see
Lemma

7
and the remark following it—so we defer the detailed, self-contained proof of uniqueness to that point.

6
Completing the characterization of optimality

In this section, we prove the necessity of
\lambda_{i,j}^{\star}(H)\geq 0
for exact optimality.
Combined with the results from Sections
4
and
5
, this will complete the proof of
Theorem

3
.

Theorem 6
.

Suppose
P(N-1,m;H)=\frac{1}{N}\binom{N}{m+1}
for
m=1,\dots,N-1
.
If
\lambda_{i_{0},j_{0}}^{\star}(H)<0
for some
1\leq j_{0}<i_{0}\leq N
, then there exists a nonexpansive operator
{\mathbb{T}}\colon\mathbb{R}^{N+1}\to\mathbb{R}^{N+1}
such that
\left\|y_{0}-y_{\star}\right\|=1
and
\left\|y_{N-1}-{\mathbb{T}}y_{N-1}\right\|^{2}>\frac{4}{N^{2}}
.

6.1
Proof outline

Part 1: Reformulating the worst-case construction via Gram matrix.

Suppose that we are given an H-matrix
H
satisfying the H-invariance conditions but at least one of the H-certificates is negative.
Rather than specifying an explicit operator
{\mathbb{T}}
, we will show that there exist the values of
y_{0},y_{\star}\in\mathbb{R}^{N+1}
and
g_{1},\dots,g_{N}\in\mathbb{R}^{N+1}
such that
\left\|y_{0}-y_{\star}\right\|=1
,
\left\|g_{N}\right\|>\frac{1}{N}
, and if
y_{1},\dots,y_{N-1}
are defined as

\displaystyle y_{i}=y_{i-1}-\sum_{j=1}^{i}2h_{i,j}g_{j}

(28)

for
i=1,\dots,N-1
and
x_{i}=y_{i-1}-g_{i}
for
i=1,\dots,N
, then

\displaystyle\left\langle x_{i}-x_{j},g_{i}-g_{j}\right\rangle\geq 0\iff\left\|y_{i-1}-y_{j-1}\right\|^{2}-\left\|(y_{i-1}-2g_{i})-(y_{j-1}-2g_{j})\right\|^{2}\geq 0

(29)

and

\displaystyle\left\langle x_{i}-y_{\star},g_{i}\right\rangle\geq 0\iff\left\|y_{i-1}-y_{\star}\right\|^{2}-\left\|(y_{i-1}-2g_{i})-y_{\star}\right\|^{2}\geq 0

(30)

holds for all
i,j=1,\dots,N
.
When this holds, one can reconstruct a nonexpansive (1-Lipschitz) operator
{\mathbb{T}}\colon\mathbb{R}^{N+1}\to\mathbb{R}^{N+1}
such that
{\mathbb{T}}y_{\star}=y_{\star}
and
{\mathbb{T}}y_{i-1}=y_{i-1}-2g_{i}
for each
i=1,\dots,N
by the classical Kirszbraun–Valentine theorem
(
12
;
27
;
28
)
.
Now for such an operator
{\mathbb{T}}
, the algorithm defined by (
4
), if started at
y_{0}
, will precisely generate the sequence
y_{1},\dots,y_{N-1}
as its outputs.
Therefore,

\displaystyle\left\|y_{N-1}-{\mathbb{T}}y_{N-1}\right\|^{2}=4\left\|g_{N}\right\|^{2}>\frac{4}{N^{2}}=\frac{4\left\|y_{0}-y_{\star}\right\|^{2}}{N^{2}}

and the algorithm fails to have the exact optimal worst-case rate.

Instead of providing concrete values of
y_{0},y_{\star},g_{1},\dots,g_{N}\in\mathbb{R}^{d}
, it suffices to specify a positive semidefinite
Gram matrix

\displaystyle{\mathbf{G}}=\begin{bmatrix}\left\|g_{1}\right\|^{2}&\left\langle g_{1},g_{2}\right\rangle&\cdots&\left\langle g_{1},g_{N}\right\rangle&\left\langle g_{1},y_{0}-y_{\star}\right\rangle\\
\left\langle g_{2},g_{1}\right\rangle&\left\|g_{2}\right\|^{2}&\cdots&\left\langle g_{2},g_{N}\right\rangle&\left\langle g_{2},y_{0}-y_{\star}\right\rangle\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
\left\langle g_{N},g_{1}\right\rangle&\left\langle g_{N},g_{2}\right\rangle&\cdots&\left\|g_{N}\right\|^{2}&\left\langle g_{N},y_{0}-y_{\star}\right\rangle\\
\left\langle y_{0}-y_{\star},g_{1}\right\rangle&\left\langle y_{0}-y_{\star},g_{2}\right\rangle&\cdots&\left\langle y_{0}-y_{\star},g_{N}\right\rangle&\left\|y_{0}-y_{\star}\right\|^{2}\end{bmatrix}\in\mathbb{S}^{N+1}_{+}

because
y_{0}-y_{\star},g_{1},\dots,g_{N}\in\mathbb{R}^{N+1}
can be found using the Cholesky decomposition of
{\mathbf{G}}
(then
y_{\star}
can be chosen arbitrarily, e.g.,
y_{\star}=0
).
The equivalent conditions for
y_{0}-y_{\star},g_{1},\dots,g_{N}\in\mathbb{R}^{N+1}
constructed in this way satisfying (
29
) and (
30
) in terms of
{\mathbf{G}}
respectively are:

\displaystyle{\mathrm{Tr}}({\mathbf{G}}{\mathbf{A}}_{i,j})\geq 0\quad\text{and}\quad{\mathrm{Tr}}({\mathbf{G}}{\mathbf{B}}_{i})\geq 0

(31)

for
i=1,\dots,N
and
j=1,\dots,i-1
, where

\displaystyle{\mathbf{A}}_{i,j}

\displaystyle=\frac{1}{2}\left(({\mathbf{x}}_{i}-{\mathbf{x}}_{j})({\mathbf{g}}_{i}-{\mathbf{g}}_{j})^{\intercal}+({\mathbf{g}}_{i}-{\mathbf{g}}_{j})({\mathbf{x}}_{i}-{\mathbf{x}}_{j})^{\intercal}\right)\in\mathbb{S}^{N+1}

\displaystyle{\mathbf{B}}_{i}

\displaystyle=\frac{1}{2}\left(({\mathbf{x}}_{i}-{\mathbf{y}}_{\star})({\mathbf{g}}_{i}-{\mathbf{g}}_{\star})^{\intercal}+({\mathbf{g}}_{i}-{\mathbf{g}}_{\star})({\mathbf{x}}_{i}-{\mathbf{y}}_{\star})^{\intercal}\right)\in\mathbb{S}^{N+1}

with
{\mathbf{y}}_{\star}=0
,

\displaystyle a_{k,2}-\sum_{n=2}^{k-1}h_{n,2}\sum_{i=1}^{n}a_{k,i}=a_{k,2}-\sum_{i=1}^{k-1}\left(\sum_{n=\max\{i,2\}}^{k-1}h_{n,2}\right)a_{k,i}=-r_{k,2}

and so on, until the last row, which corresponds to the
j=k-1
case of (
42
), which is equivalent to

\displaystyle a_{k,k-1}-\sum_{n=k-1}^{k-1}h_{n,k-1}\sum_{i=1}^{n}a_{k,i}=a_{k,k-1}-\sum_{i=1}^{k-1}h_{k-1,k-1}a_{k,i}=-r_{k,k-1}.

By performing the elementary row operation of adding
(h_{j,j}+\dots+h_{k-1,j})
times the first row to the
j
-th row for
j=2,\dots,k-1
, we obtain

\displaystyle\begin{bmatrix}1&1&1&\cdots&1&1\\
0&1&h_{2,2}&\cdots&h_{2,2}+\dots+h_{k-3,2}&h_{2,2}+\cdots+h_{k-2,2}\\
0&0&1&\cdots&h_{3,3}+\dots+h_{k-3,3}&h_{3,3}+\dots+h_{k-2,3}\\
\vdots&\vdots&\vdots&\ddots&\vdots&\vdots\\
0&0&0&\cdots&1&h_{k-2,k-2}\\
0&0&0&\cdots&0&1\end{bmatrix}

and the determinant of this matrix is
1
.
This implies that if
a_{k,1},\dots,a_{k,k-1}
satisfying (
41
) and (
42
) exist, then it is unique (so
a_{k,1},\dots,a_{k,k-1}
are uniquely determined as functions of
a_{m,\cdot}
with
m>k
).
∎

Finally, it remains to show
Lemma

9
.
We first show a handy recursive formula for
D(k)
, and then prove
Lemma

9
.

Lemma 8
.

The following holds for
k=1,\dots,N-1
:

\displaystyle D(k+1)=D(k)-\sum_{j=1}^{k}h_{k,j}D(j)=(1-h_{k,k})D(k)-\sum_{j=1}^{k-1}h_{k,j}D(j).

Proof.

A monomial appearing in
D(k+1)=1+\sum_{m=1}^{k}(-1)^{m}P(k,m;H)
is of the form
(-1)^{m}\prod_{r=1}^{m}h_{i(r),j(r)}
for some
m\in\{1,\dots,k\}
and
j(r)\leq i(r)<j(r+1)\leq i(r+1)\leq k
for
r=1,\dots,m-1
.
We have two cases: either
i(m)\leq k-1
or
i(m)=k
.
In the former case,
(i(1),j(1),\dots,i(m),j(m))\in I(k-1,m)
, so
(-1)^{m}\prod_{r=1}^{m}h_{i(r),j(r)}
is a part of
D(k)
(using the same definition of the index set
I(\cdot,\cdot)
as in the proof of
Lemma

2
).
In the latter case, if
m\geq 2
,
i(m-1)<j(m)
, so

\displaystyle(i(1),j(1),\dots,i(m-1),j(m-1))\in I(j(m)-1,m-1).

Thus, we can write

\displaystyle D(k+1)

\displaystyle=D(k)-\sum_{j(1)=1}^{k}h_{k,j(1)}-\sum_{m=2}^{k}(-1)^{m-1}\sum_{j(m)=1}^{k}h_{k,j(m)}\sum_{(i(1),j(1),\dots,i(m-1),j(m-1))\in I(j(m)-1,m-1)}\prod_{r=1}^{m-1}h_{i(r),j(r)}

\displaystyle=D(k)-\sum_{j=1}^{k}h_{k,j}\bigg[1+\sum_{m=2}^{k}(-1)^{m-1}\underbrace{\sum_{(i(1),j(1),\dots,i(m-1),j(m-1))\in I(j-1,m-1)}\prod_{r=1}^{m-1}h_{i(r),j(r)}}_{=P(j-1,m-1)}\bigg]

\displaystyle=D(k)-\sum_{j=1}^{k}h_{k,j}\sum_{\ell=0}^{j-1}(-1)^{\ell}P(j-1,\ell)=D(k)-\sum_{j=1}^{k}h_{k,j}D(j)

where the third equality uses
P(j-1,0)=1
,
P(j-1,m-1)=0
for
m>j
, and makes the index change
\ell=m-1
.
∎

Lemma 9
.

Let
{\mathbf{M}}_{N}
be as in (
40
). Then
\det{\mathbf{M}}_{N}=D(N)
.

Proof.

Performing the elementary column operation of subtracting the last column from all remaining columns of
{\mathbf{M}}_{N}
, we obtain

\displaystyle\begin{bmatrix}1-h_{1,1}-\dots-h_{N-2,1}&-h_{2,1}-\dots-h_{N-2,1}&\cdots&-h_{N-2,1}&-h_{N-1,1}\\
-h_{2,2}-\dots-h_{N-2,2}&1-h_{2,2}-\dots-h_{N-2,2}&\cdots&-h_{N-2,2}&-h_{N-1,2}\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
-h_{N-2,N-2}&-h_{N-2,N-2}&\cdots&1-h_{N-2,N-2}&-h_{N-1,N-2}\\
-1&-1&\cdots&-1&1-h_{N-1,N-1}\end{bmatrix}.

(43)

Now subtracting the second last column of (
43
) from all columns up to
(N-3)
-th, we obtain

\displaystyle\begin{bmatrix}1-h_{1,1}-\dots-h_{N-3,1}&-h_{2,1}-\dots-h_{N-3,1}&\cdots&-h_{N-3,1}&-h_{N-2,1}&-h_{N-1,1}\\
-h_{2,2}-\dots-h_{N-3,2}&1-h_{2,2}-\dots-h_{N-3,2}&\cdots&-h_{N-3,2}&-h_{N-2,2}&-h_{N-1,2}\\
\vdots&\vdots&\ddots&\vdots&\vdots&\vdots\\
-h_{N-3,N-3}&-h_{N-3,N-3}&\cdots&1-h_{N-3,N-3}&-h_{N-2,N-3}&-h_{N-1,N-3}\\
-1&-1&\cdots&-1&1-h_{N-2,N-2}&-h_{N-1,N-2}\\
0&0&\cdots&0&-1&1-h_{N-1,N-1}\end{bmatrix}.

Continuing until the end, we obtain the matrix

\displaystyle{\mathbf{L}}_{N}=\begin{bmatrix}1-h_{1,1}&-h_{2,1}&\cdots&-h_{N-2,1}&-h_{N-1,1}\\
-1&1-h_{2,2}&\cdots&-h_{N-2,2}&-h_{N-1,2}\\
&\ddots&\ddots&\vdots&\vdots\\
&&\ddots&1-h_{N-2,N-2}&-h_{N-1,N-2}\\
&&&-1&1-h_{N-1,N-1}\end{bmatrix}.

Now we use induction to show that
\det{\mathbf{M}}_{N}=\det{\mathbf{L}}_{N}=D(N)
.
The base case is
N=2
, when we have
{\mathbf{L}}_{2}=\begin{bmatrix}1-h_{1,1}\end{bmatrix}
and thus, trivially,
\det{\mathbf{L}}_{2}=1-h_{1,1}=1-P(1,1)=D(2)
.
Now assuming that
\det{\mathbf{L}}_{k}=D(k)
for all
k=2,\dots,N-1
and taking the cofactor expansion of
{\mathbf{L}}_{N}
along the last row gives

\displaystyle\det{\mathbf{L}}_{N}

\displaystyle=(1-h_{N-1,N-1})\det\begin{bmatrix}1-h_{1,1}&-h_{2,1}&\cdots&-h_{N-2,1}\\
-1&1-h_{2,2}&\cdots&-h_{N-2,2}\\
&\ddots&\ddots&\vdots&\\
&&-1&1-h_{N-2,N-2}\end{bmatrix}

\displaystyle\quad+\det\underbrace{\begin{bmatrix}1-h_{1,1}&-h_{2,1}&\cdots&-h_{N-3,1}&-h_{N-1,1}\\
-1&1-h_{2,2}&\cdots&-h_{N-3,2}&-h_{N-1,2}\\
&\ddots&\ddots&\vdots&\vdots\\
&&\ddots&1-h_{N-3,N-3}&-h_{N-1,N-3}\\
&&&-1&-h_{N-1,N-2}\end{bmatrix}}_{\tilde{{\mathbf{L}}}_{N,N-1}}

\displaystyle=(1-h_{N-1,N-1})\det{\mathbf{L}}_{N-1}+\det\tilde{{\mathbf{L}}}_{N,N-1}.

Cofactor-expanding
\tilde{{\mathbf{L}}}_{N,N-1}
along the last row again, we obtain

\displaystyle\det\tilde{{\mathbf{L}}}_{N,N-1}=-h_{N-1,N-2}\det{\mathbf{L}}_{N-2}+\underbrace{\begin{bmatrix}1-h_{1,1}&-h_{2,1}&\cdots&-h_{N-4,1}&-h_{N-1,1}\\
-1&1-h_{2,2}&\cdots&-h_{N-4,2}&-h_{N-1,2}\\
&\ddots&\ddots&\vdots&\vdots\\
&&\ddots&1-h_{N-4,N-4}&-h_{N-1,N-4}\\
&&&-1&-h_{N-1,N-3}\end{bmatrix}}_{\tilde{{\mathbf{L}}}_{N,N-2}}.

Repeating the process, we have

\displaystyle\det{\mathbf{L}}_{N}

\displaystyle=(1-h_{N-1,N-1})\det{\mathbf{L}}_{N-1}-h_{N-1,N-2}\det{\mathbf{L}}_{N-2}-\dots-h_{N-1,2}\det{\mathbf{L}}_{2}-h_{N-1,1}

\displaystyle=(1-h_{N-1,N-1})D(N-1)-\sum_{k=1}^{N-2}h_{N-1,k}D(k)

\displaystyle=D(N)

where the second line uses the induction hypothesis and the last line follows from
Lemma

8
.
∎

7
Uniqueness of OHM as anytime optimal algorithm

We say that an algorithm having the form (
4
) with predetermined
h_{k+1,j+1}\in\mathbb{R}
(defined for all
k=0,1,2,\dots
and
j=0,1\dots,k
) is
anytime optimal
if

\displaystyle\left\|y_{k}-{\mathbb{T}}y_{k}\right\|^{2}\leq\frac{4\left\|y_{0}-y_{\star}\right\|^{2}}{(k+1)^{2}}

(44)

holds for all
k=0,1,\dots
, for any nonexpansive operator
{\mathbb{T}}\colon\mathbb{R}^{d}\to\mathbb{R}^{d}
and an initial point
y_{0}\in\mathbb{R}^{d}
.
If
N\in\mathbb{N}
and (
44
) holds for all
k=N-1,N,\dots
, i.e., for all iterates including and after
y_{N-1}
, then we say that the algorithm is
anytime-beyond-
N
-steps optimal
.

Theorem 7
.

OHM is the only anytime optimal algorithm of the form (
4
).
More generally, for any
N\geq 1
, if an algorithm of the form (
4
) is anytime-beyond-
N
-steps optimal, then it takes the form

\displaystyle y_{k+1}=\frac{1}{k+2}y_{0}+\frac{k+1}{k+2}{\mathbb{T}}y_{k}

for
k=N-1,N,\dots
.

Proof.

Suppose that the algorithm is anytime-beyond-
N
-steps optimal.
By
Theorem

4
, for any
k=N-1,N,\dots
, we must have
P(k,m)=\frac{1}{k+1}\binom{k+1}{m+1}
for all
m=1,\dots,k
(we drop the
H
-dependence throughout this proof).
This implies

\displaystyle h_{k+1,k+1}=\frac{h_{1,1}h_{2,2}\cdots h_{k+1,k+1}}{h_{1,1}h_{2,2}\cdots h_{k,k}}=\frac{P(k+1,k+1)}{P(k,k)}=\frac{\frac{1}{k+2}}{\frac{1}{k+1}}=\frac{k+1}{k+2}.

Next, we show that
h_{k+1,m}=-\frac{1}{k+2}\left(h_{m,m}+h_{m+1,m}+\dots+h_{k,m}\right)

for each
m=1,\dots,k
by backward induction on
m
(starting from
m=k
).
We state a useful lemma for this purpose, which we prove separately at the end of the section.

Lemma 10
.

For any
k=1,2,\dots
and
m=2,\dots,k+1
,

\displaystyle P(k+1,m)=\sum_{j=m-1}^{k}\left(\sum_{i=j+1}^{k+1}h_{i,j+1}\right)P(j,m-1).

Now to show the base case
m=k
, we use
Lemma

10
to obtain

\displaystyle P(k+1,k)

\displaystyle=\sum_{j=k-1}^{k}\left(\sum_{i=j+1}^{k+1}h_{i,j+1}\right)P(j,k-1)

\displaystyle=h_{k+1,k+1}P(k,k-1)+\left(h_{k,k}+h_{k+1,k}\right)P(k-1,k-1),

which implies

\displaystyle h_{k+1,k}

\displaystyle=\frac{1}{P(k-1,k-1)}\left(P(k+1,k)-h_{k+1,k+1}P(k,k-1)\right)-h_{k,k}

\displaystyle=\frac{1}{h_{1,1}h_{2,2}\dots h_{k-1,k-1}}\left(\frac{1}{k+2}\binom{k+2}{k+1}-\frac{k+1}{k+2}\frac{1}{k+1}\binom{k+1}{k}\right)-h_{k,k}

\displaystyle=\frac{h_{k,k}}{P(k,k)}\frac{1}{k+2}-h_{k,k}

\displaystyle=-\frac{1}{k+2}h_{k,k}

where the last equality holds because
P(k,k)=\frac{1}{k+1}
.

Let
2\leq m\leq k-1
and assume
h_{k+1,n}=-\frac{1}{k+2}\left(h_{n,n}+h_{n+1,n}+\dots+h_{k,n}\right)
holds for all
n=m+1,\dots,k
.
Applying
Lemma

10
again, we obtain

\displaystyle P(k+1,m)

\displaystyle=h_{k+1,k+1}P(k,m-1)+\left(h_{k,k}+h_{k+1,k}\right)P(k-1,m-1)+\dots+\left(h_{m+1,m+1}+\dots+h_{k+1,m+1}\right)P(m,m-1)

\displaystyle\quad+\left(h_{m,m}+\dots+h_{k+1,m}\right)P(m-1,m-1)

\displaystyle=\frac{k+1}{k+2}\frac{1}{k+1}\binom{k+1}{m}+\frac{k+1}{k+2}h_{k,k}P(k-1,m-1)+\dots+\frac{k+1}{k+2}\left(h_{m+1,m+1}+\dots+h_{k,m+1}\right)P(m,m-1)

\displaystyle\quad+\left(h_{m,m}+\dots+h_{k+1,m}\right)P(m-1,m-1)

\displaystyle=\frac{1}{k+2}\binom{k+1}{m}+\frac{k+1}{k+2}\sum_{j=m}^{k-1}\left(\sum_{i=j+1}^{k}h_{i,j+1}\right)P(j,m-1)+\left(h_{m,m}+\dots+h_{k+1,m}\right)P(m-1,m-1)

(45)

where we have used the induction hypothesis for the second equality. Now applying
Lemma

10
once again, with
k-1
in place of
k
, we have

\displaystyle\sum_{j=m-1}^{k-1}\left(\sum_{i=j+1}^{k}h_{i,j+1}\right)P(j,m-1)=P(k,m)=\frac{1}{k+1}\binom{k+1}{m+1}

\displaystyle\implies\sum_{j=m}^{k-1}\left(\sum_{i=j+1}^{k}h_{i,j+1}\right)P(j,m-1)=\frac{1}{k+1}\binom{k+1}{m+1}-\left(\sum_{i=m}^{k}h_{i,m}\right)P(m-1,m-1).

Plugging this into (
45
) and using the H-invariance condition for
P(k+1,m)
, we obtain

\displaystyle\frac{1}{k+2}\binom{k+2}{m+1}

\displaystyle=P(k+1,m)

\displaystyle=\frac{1}{k+2}\binom{k+1}{m}+\frac{k+1}{k+2}\left[\frac{1}{k+1}\binom{k+1}{m+1}-\left(\sum_{i=m}^{k}h_{i,m}\right)P(m-1,m-1)\right]

\displaystyle\quad+\left(h_{m,m}+\dots+h_{k+1,m}\right)P(m-1,m-1)

\displaystyle=\frac{1}{k+2}\left[\binom{k+1}{m}+\binom{k+1}{m+1}\right]+P(m-1,m-1)\left[\frac{1}{k+2}\left(h_{m,m}+\dots+h_{k,m}\right)+h_{k+1,m}\right].

Because
\binom{k+2}{m+1}=\binom{k+1}{m}+\binom{k+1}{m+1}
and
P(m-1,m-1)\neq 0
, we conclude that
h_{k+1,m}=-\frac{1}{k+2}\left(h_{m,m}+\dots+h_{k,m}\right)
.

Finally, assuming the induction hypothesis for all
m=2,\dots,k
, we have

\displaystyle h_{1,1}+h_{2,1}+\dots+h_{k+1,1}

\displaystyle=P(k+1,1)-\sum_{j=2}^{k}\sum_{m=j}^{k+1}h_{m,j}-h_{k+1,k+1}

\displaystyle=\frac{1}{k+2}\binom{k+2}{2}-\sum_{j=2}^{k}\frac{k+1}{k+2}\sum_{m=j}^{k}h_{m,j}-\frac{k+1}{k+2}

\displaystyle=\frac{k+1}{2}-\frac{k+1}{k+2}\left(P(k,1)-h_{1,1}-h_{2,1}-\dots-h_{k,1}\right)-\frac{k+1}{k+2}

\displaystyle=\frac{k+1}{2}-\frac{k+1}{k+2}\frac{1}{k+1}\binom{k+1}{2}+\frac{k+1}{k+2}(h_{1,1}+\dots+h_{k,1})-\frac{k+1}{k+2}

\displaystyle=\frac{k+1}{k+2}(h_{1,1}+\dots+h_{k,1})

and thus
h_{k+1,1}=-\frac{1}{k+2}(h_{1,1}+\dots+h_{k,1})
, completing the induction.

Now note that by the update rule (
4
),

\displaystyle y_{0}-y_{k}

\displaystyle=\sum_{i=1}^{k}\sum_{j=1}^{i}h_{i,j}(y_{j-1}-{\mathbb{T}}y_{j-1})

\displaystyle=\sum_{j=1}^{k}\sum_{i=j}^{k}h_{i,j}(y_{j-1}-{\mathbb{T}}y_{j-1})

\displaystyle=\sum_{j=1}^{k}(h_{j,j}+h_{j+1,j}+\dots+h_{k,j})(y_{j-1}-{\mathbb{T}}y_{j-1}).

This implies

\displaystyle y_{k+1}

\displaystyle=y_{k}-\sum_{j=1}^{k+1}h_{k+1,j}(y_{j-1}-{\mathbb{T}}y_{j-1})

\displaystyle=y_{k}+\frac{1}{k+2}\sum_{j=1}^{k}(h_{j,j}+h_{j+1,j}+\dots+h_{k,j})(y_{j-1}-{\mathbb{T}}y_{j-1})-\frac{k+1}{k+2}(y_{k}-{\mathbb{T}}y_{k})

\displaystyle=y_{k}+\frac{1}{k+2}(y_{0}-y_{k})-\frac{k+1}{k+2}(y_{k}-{\mathbb{T}}y_{k})

\displaystyle=\frac{1}{k+2}y_{0}+\frac{k+1}{k+2}{\mathbb{T}}y_{k}.

∎

Remark.
Conversely to
Theorem

7
, running any H-matrix representable algorithm for
N-1
iterations satisfying the conditions of
Theorem

3
, and using the OHM recursion
y_{k+1}=\frac{1}{k+2}y_{0}+\frac{k+1}{k+2}{\mathbb{T}}y_{k}
thereafter (for
k=N-1,N,\dots
) yields an anytime-beyond-
N
-steps optimal algorithm.
This can be seen from the proof format (
6
), which implies

\displaystyle N^{2}\left\|g_{N}\right\|^{2}+N\left\langle g_{N},x_{N}-y_{0}\right\rangle=N\left(N\left\|g_{N}\right\|^{2}+\left\langle g_{N},x_{N}-y_{0}\right\rangle\right)\leq 0,

together with the fact that the
Lyapunov function

\displaystyle V_{k}=k^{2}\left\|g_{k}\right\|^{2}+k\left\langle g_{k},x_{k}-y_{0}\right\rangle

is nonincreasing with the OHM updates (for
k=N,N+1,\dots
), because

\displaystyle V_{k}-V_{k+1}=k(k+1)\left\langle x_{k+1}-x_{k},g_{k+1}-g_{k}\right\rangle\geq 0.

(46)

This has been proved in
20
for the pure OHM, but even in our case—where we have the OHM recursion only after
N-1
updates—the same derivation applies, because that Lyapunov analysis does not depend on the history (previous iterates) of the algorithm besides
y_{0}
.

Proof of
Lemma

10
.

By definition, we have

\displaystyle P(k+1,m)=\sum_{(i(1),j(1),\dots,i(m),j(m))\in I(k+1,m)}\prod_{r=1}^{m}h_{i(r),j(r)}.

(47)

Now for each
(i(1),j(1),\dots,i(m),j(m))\in I(k+1,m)
we have
j(m)\geq m
, and for each
n=m,\dots,k+1
,

\displaystyle(i(1),j(1),\dots,i(m-1),j(m-1),i(m),n)\in I(k+1,m)

\displaystyle\iff(i(1),j(1),\dots,i(m-1),j(m-1))\in I(n-1,m-1)\,\,\,\text{and}\,\,\,n\leq i(m)\leq k+1.

Therefore, by partitioning
I(k+1,m)
based on the value of
j(m)
, we can rewrite (
47
) as

\displaystyle P(k+1,m)

\displaystyle=\sum_{n=m}^{k+1}\sum_{i(m)=n}^{k+1}h_{i(m),n}\left(\sum_{(i(1),j(1),\dots,i(m-1),j(m-1))\in I(n-1,m-1)}\prod_{r=1}^{m-1}h_{i(r),j(r)}\right)

\displaystyle=\sum_{n=m}^{k+1}\sum_{i=n}^{k+1}h_{i,n}P(n-1,m-1)

where we replace the index
i(m)
with
i
and use the definition of
P(n-1,m-1)
.
The desired result then follows by applying the index change
j=n-1
.
∎

8
New optimal algorithms with sparse H-certificates

In this section, we discover several new classes of optimal algorithms whose convergence proofs use minimal number of inequalities, i.e., the H-certificates
\lambda^{\star}(H)
are sparse.
To illustrate how a sparse
\lambda^{\star}(H)
(together with H-invariance) characterizes an H-matrix, we first revisit the cases of OHM and Dual-OHM.
Leveraging the insight from these cases, we then analyze some new sparsity patterns, which lead to novel algorithms.

Throughout this section, whenever clear from the context, we drop the dependence on
H
from all notations.
Proofs of the results in this section often involve tedious computations using combinatorial identities, which we mostly defer to
Appendix

B
for cleaner exposition.

8.1
Re-deriving OHM and Dual-OHM from sparsity pattern of
\lambda^{\star}

8.1.1
Case of OHM

The well-known convergence proof of OHM uses (
46
)—equivalently, the proof can be written in the form (
6
), where only
\lambda_{j+1,j}^{\star}>0
and all the other H-certificates are
0
.
In this section, we show that OHM can in fact be derived solely from this sparsity pattern of H-certificates, i.e., from the system of equations
\lambda_{k,j}^{\star}=0
for
j=1,\dots,N-2
and
k=j+2,\dots,N
.

Proposition 1
.

For each fixed
j=1,\dots,N-2
, viewing the Q-function values
Q(N-1,1,j),\dots,Q(N-1,N-j,j)
as variables, the quadratic system of
N-j-1
equations

\displaystyle\lambda^{\star}_{j+2,j}=\cdots=\lambda^{\star}_{N-1,j}=\lambda^{\star}_{N,j}=0

(top-sparsity)

is equivalent to a full-rank linear system (
58
) of
N-j-1
equations. Its (one-dimensional) solution is characterized by

\displaystyle Q(N-1,k,j)=\binom{N-j-1}{k-1}Q(N-1,N-j,j)

(48)

for
k=1,\dots,N-j-1
.

Combining
Proposition

1
with the H-invariance conditions

\displaystyle Q(N-1,m,1)+\dots+Q(N-1,m,N-m)=P(N-1,m)=\frac{1}{N}\binom{N}{m+1}

(49)

for
m=1,\dots,N-1
, we can uniquely determine the values of
Q(N-1,\cdot,\cdot)
via the following procedure:

1.

For each
1\leq j\leq N-1
, assuming that the value of
Q(N-1,N-j,j)
is known, we can also determine the values of
Q(N-1,k,j)
for
k=1,\dots,N-j-1
using (
48
).
Note that for the base case
j=1
, we indeed know that
Q(N-1,N-1,1)=h_{1,1}h_{2,2}\cdots h_{N-1,N-1}=P(N-1,N-1)=\frac{1}{N}
, so we can determine
Q(N-1,k,1)
for all
k=1,\dots,N-1
.

2.

Assuming that all values of
Q(N-1,k,i)
are found for
i=1,\dots,j
and
k=1,\dots,N-i
, we can determine the value of
Q(N-1,N-j-1,j+1)
using the identity (
49
) with
m=N-j-1
:

\displaystyle Q(N-1,N-j-1,j+1)=\frac{1}{N}\binom{N}{N-j}-\sum_{i=1}^{j}Q(N-1,N-j-1,i).

Return to Step 1, and repeat until all Q-function values are found.

Proposition 2
.

The conditions (
48
) from
Proposition

1
, together with H-invariance conditions (
49
), uniquely determine:
Q(N-1,k,j)=\frac{j}{N}\binom{N-j-1}{k-1}
for
j=1,\dots,N-1
and
k=1,\dots,N-j
.

Proof.

As the claimed formula trivially satisfies (
48
) for each
j=1,\dots,N-2
, it suffices to verify (
49
) (then these values must be the unique Q-function values that the above procedure produces).
This is an immediate application of
Lemma

14
(b) with
p=N-1,q=k-1
.
∎

Having all values of
Q(N-1,\dots,\dots)
determined, we can uniquely recover
H
through the following procedure: for each
k=1,\dots,N-1
, we determine the values of
h_{k,k},h_{k+1,k},\dots,h_{N-1,k}
in sequential order as following.

1.

First, if
k=N-1
, then
h_{N-1,N-1}=Q(N-1,1,N-1)
; otherwise
k<N-1
, so

\displaystyle h_{k,k}=\frac{h_{k,k}h_{k+1,k+1}\dots h_{N-1,N-1}}{h_{k+1,k+1}h_{k+2,k+2}\dots h_{N-1,N-1}}=\frac{Q(N-1,N-k,k)}{Q(N-1,N-k-1,k+1)}.

2.

For each
i=k+1,k+2,\dots,N-2
, we have

\displaystyle h_{i,k}=\frac{1}{Q(N-1,N-i-1,i+1)}\left[Q(N-1,N-i,k)-\sum_{\ell=k+1}^{i}\left(\sum_{m=k}^{\ell-1}h_{m,k}\right)Q(N-1,N-i-1,\ell)\right]-\sum_{m=k}^{i-1}h_{m,k},

which is a restatement of the second recursion in
Lemma

2
.
Note that this formula only relies on the values of
Q(N-1,\cdot,\cdot)
and
h_{m,k}
with
m=k,\dots,i-1
, which are assumed to be already found.

3.

Finally,
h_{N-1,k}=Q(N-1,1,k)-\sum_{m=k}^{N-2}h_{m,k}
.

Note that under H-invariance we have
Q(N-1,j,N-j)=h_{j,j}h_{j+1,j+1}\dots h_{N-1,N-1}\neq 0
for any
j=1,\dots,N-1
, so there is no issue with division by these terms.
In fact, the above procedure more broadly establishes the one-to-one correspondence between
H
with nonzero diagonal entries and
\big\{Q(N-1,k,j)\big\}_{\begin{subarray}{c}j=1,\dots,N-1\\
k=1,\dots,N-j\end{subarray}}
satisfying
Q(N-1,j,N-j)\neq 0
for all
j
, even without H-invariance (exact optimality).

Proposition 3
.

The unique optimal
H\in\mathbb{R}^{(N-1)\times(N-1)}
satisfying (
top-sparsity
) for
j=1,\dots,N-2
is that of OHM.

Although we can certainly verify this via direct computations, for simplicity, we instead leave a brief indirect “proof”: OHM is
an
exact optimal H-matrix representable algorithm that has the sparsity pattern of
Proposition

1
, and our discussion above shows that it is a unique such one.

8.1.2
Case of Dual-OHM

We can similarly derive Dual-OHM from its

-sparsity pattern:
\lambda_{k,j}^{\star}=0
for

and

Proposition 4
.

For each fixed

\displaystyle\lambda^{\star}_{j+1,j}=\lambda^{\star}_{j+2,j}=\cdots=\lambda^{\star}_{N-1,j}=0

(bottom-sparsity)

\displaystyle Q(N-1,k,j)=\frac{N-j+1}{k+1}\binom{N-j-1}{k-1}Q(N-1,N-j,j)

(50)

for

Proposition 5
.

The conditions (
50
) from
Proposition

4
and H-invariance (

) uniquely determine

for

and

The unique

8.2
New algorithms from mixed sparsity patterns

In the previous section, we discovered that the sparsity patterns (
top-sparsity
) and (
bottom-sparsity
) respectively reduce to explicit linear relations (
48
) and (
50
) for Q-functions.
In both of these cases, we can write

\displaystyle Q(N-1,k,j)=c_{k,j}Q(N-1,N-j,j)

(51)

for some constants
c_{k,j}
, where
c_{k,j}
is either
\binom{N-j-1}{k-1}
or
\frac{N-j+1}{k+1}\binom{N-j-1}{k-1}
, depending on which sparsity pattern is chosen for each
j=1,\dots,N-2
.

In this section, we will consider the mixed sparsity patterns where we choose (
top-sparsity
) for a subset of
j
’s and (
bottom-sparsity
) for the rest.
Combining the resulting linear relations (
51
) with the H-invariance condition (
49
), we can uniquely characterize
Q(N-1,\cdot,\cdot)
and
H
.
We show that the H-matrices produced by this process indeed define new optimal algorithms.

8.2.1
Selecting (
top-sparsity
) for
j=1,\dots,N^{\prime}-1
and (
bottom-sparsity
) for
j=N^{\prime},\dots,N-1

In this sparsity pattern, with a fixed
2\leq N^{\prime}\leq N-2
, we have
\lambda^{\star}_{j+1,j}\neq 0
for
j=1,\dots,N^{\prime}-1
,
\lambda^{\star}_{N,j}\neq 0
for
j=N^{\prime},\dots,N-1
, and all the other H-certificates are
0
.

Proposition 6
.

The unique set of values of the Q-functions
Q(N-1,\cdot,\cdot)
satisfying (
top-sparsity
) for
j=1,\dots,N^{\prime}-1
, (
bottom-sparsity
) for
j=N^{\prime},\dots,N-1
and the H-invariance condition (
49
) is given by

\displaystyle Q(N-1,k,j)=\begin{cases}\frac{j}{N}\binom{N-j-1}{k-1}&\text{for }j=1,\dots,N^{\prime}-1\\
\frac{N^{\prime}(N-N^{\prime}+1)}{N(k+1)}\binom{N-N^{\prime}-1}{k-1}&\text{for }j=N^{\prime}\\
\frac{1}{k+1}\binom{N-j-1}{k-1}&\text{for }j=N^{\prime}+1,\dots,N-1.\end{cases}

(52)

where
k=1,\dots,N-j
. With these Q-functions, we have
\lambda^{\star}_{j+1,j}>0
for
j=1,\dots,N^{\prime}-1
and
\lambda^{\star}_{N,j}>0
for
j=N^{\prime},\dots,N-1
, so the corresponding
H
represents a minimax optimal algorithm.

Note that in
Proposition

6
, we have verified the optimality of
H
using the information of its Q-functions only, without even computing
H
explicitly.
However, the precise form of
H
is of interest on its own, which we discuss next.
For convenience, denote the H-matrix of OHM up to
k
steps by
H_{\text{OHM}}(k)\in\mathbb{R}^{k\times k}
and its anti-diagonal transpose (H-dual) by
H_{\text{OHM}}^{\textsf{A}}(k)\in\mathbb{R}^{k\times k}
.

Proposition 7
.

The H-matrix corresponding to the Q-function profile (
52
) is given by

\displaystyle H=\begin{bmatrix}\begin{array}[]{c|cc}H_{\text{OHM}}(N^{\prime}-1)&\\
\begin{array}[]{ccc}h_{N^{\prime},1}&\cdots&h_{N^{\prime},N^{\prime}-1}\end{array}&h_{N^{\prime},N^{\prime}}\\
\hline\cr 0_{(N-N^{\prime}-1)\times(N^{\prime}-1)}&\begin{array}[]{c}h_{N^{\prime}+1,N^{\prime}}\\
\vdots\\
h_{N-1,N^{\prime}}\end{array}&H_{\text{OHM}}^{\textsf{A}}(N-N^{\prime}-1)\end{array}\end{bmatrix}

(53)

where
h_{N^{\prime},N^{\prime}}=\frac{N^{\prime}(N-N^{\prime})}{N}
and

\displaystyle\begin{cases}h_{N^{\prime},j}=j\left(\frac{1}{N}-\frac{1}{N^{\prime}}\right)&\text{for }j=1,\dots,N^{\prime}-1\\
h_{k,N^{\prime}}=(N-k)\left(\frac{1}{N}-\frac{1}{N-N^{\prime}}\right)&\text{for }k=N^{\prime}+1,\dots,N-1.\end{cases}

The characterization (
53
) shows that in particular, when
N
is even and
N^{\prime}=\frac{N}{2}
, we have
H=H^{\textsf{A}}
, i.e., the corresponding algorithm is
self-dual
with respect to the H-dual operation.

8.2.2
Selecting (
bottom-sparsity
) for
j=1,\dots,N^{\prime}-1
and (
top-sparsity
) for
j=N^{\prime},\dots,N-1

In this sparsity pattern, with a fixed
2\leq N^{\prime}\leq N-2
, we have
\lambda^{\star}_{N,j}\neq 0
for
j=1,\dots,N^{\prime}-1
,
\lambda^{\star}_{j+1,j}\neq 0
for
j=N^{\prime},\dots,N-1
, and all the other H-certificates are
0
.

Proposition 8
.

The unique set of values of the Q-functions
Q(N-1,\cdot,\cdot)
satisfying (
bottom-sparsity
) for
j=1,\dots,N^{\prime}-1
, (
top-sparsity
) for
j=N^{\prime},\dots,N-1
and the H-invariance condition (

) is given by

\displaystyle Q(N-1,k,j)=\begin{cases}\frac{1}{k+1}\binom{N-j-1}{k-1}&\text{for }j=1,\dots,N^{\prime}-1\\
\frac{j-N^{\prime}+1}{N-N^{\prime}+1}\binom{N-j-1}{k-1}&\text{for }j=N^{\prime},\dots,N-1.\end{cases}

(54)

where
k=1,\dots,N-j
. With these Q-functions, we have
\lambda^{\star}_{N,j}>0
for
j=1,\dots,N^{\prime}-1
and
\lambda^{\star}_{j+1,j}>0
for
j=N^{\prime},\dots,N-1
, so the corresponding
H
represents a minimax optimal algorithm.

As before, we provide the explicit expression for the associated
H
below.

Proposition 9
.

The H-matrix corresponding to the Q-function profile (
54
) is given by

\displaystyle H=\begin{bmatrix}\begin{array}[]{c|cc}\left[H_{\text{Dual-OHM}}(N-1)\right]_{1:N^{\prime}-1,1:N^{\prime}-1}\\
\hline\cr\begin{array}[]{ccc}-c_{1}&\cdots&-c_{N^{\prime}-1}\\
\vdots&&\vdots\\
-c_{1}&\cdots&-c_{N^{\prime}-1}\end{array}&H_{\text{OHM}}(N-N^{\prime})\end{array}\end{bmatrix}

(55)

where
\left[H_{\text{Dual-OHM}}(N-1)\right]_{1:N^{\prime}-1,1:N^{\prime}-1}
denotes the upper left
(N^{\prime}-1)\times(N^{\prime}-1)
submatrix of Dual-OHM’s H-matrix (with
N-1
iterations), and
h_{N^{\prime},j}=\cdots=h_{N-1,j}=-c_{j}=-\frac{N-N^{\prime}+1}{2(N-j)(N-j+1)}
for
j=1,\dots,N^{\prime}-1
.
In analytical form,

\displaystyle h_{k,j}=\begin{cases}\frac{N-k}{N-k+1}&\text{for }j=k\leq N^{\prime}-1\\
-\frac{N-k}{(N-j)(N-j+1)}&\text{for }j<k\leq N^{\prime}-1\\
\frac{k-N^{\prime}+1}{k-N^{\prime}+2}&\text{for }j=k\geq N^{\prime}\\
-\frac{j-N^{\prime}+1}{(k-N^{\prime}+1)(k-N^{\prime}+2)}&\text{for }N^{\prime}\leq j<k\\
-\frac{N-N^{\prime}+1}{2(N-j)(N-j+1)}&\text{for }k\geq N^{\prime},j\leq N^{\prime}-1.\end{cases}

Remark.
The H-dual of (
55
) is:

\displaystyle H^{\textsf{A}}=\begin{bmatrix}\begin{array}[]{c|cc}H_{\text{Dual-OHM}}(N-N^{\prime})\\
\hline\cr\begin{array}[]{ccc}-c_{N^{\prime}-1}&\cdots&-c_{N^{\prime}-1}\\
\vdots&&\vdots\\
-c_{1}&\cdots&-c_{1}\end{array}&\left[H_{\text{OHM}}(N-1)\right]_{N-N^{\prime}+1:N-1,N-N^{\prime}+1:N-1}\end{array}\end{bmatrix}

(56)

where
\left[H_{\text{OHM}}(N-1)\right]_{N-N^{\prime}+1:N-1,N-N^{\prime}+1:N-1}
denotes the lower right
(N^{\prime}-1)\times(N^{\prime}-1)
submatrix of OHM’s H-matrix with
N-1
iterations.
Interestingly, this is the H-matrix of the anytime-beyond-
(N-N^{\prime})
-steps optimal algorithm that runs Dual-OHM for
N-N^{\prime}
iterations and then proceeds with the OHM recursion from there on (we do not formally prove this fact, but it is not difficult to verify through direct calculations).
With this observation, one may be inclined to conjecture that H-dual of any optimal H-matrix representable algorithm is also optimal—e.g., the H-invariance conditions are preserved under the H-dual operation because H-invariants remain unchanged under the anti-diagonal transpose
(
29
)
.
However, we show in the following Section
8.3
that this is
not
the case because nonnegativity of H-certificates are not necessarily preserved under the H-dual.

8.3
An optimal algorithm whose H-dual is not optimal

In the case
N=4
, a generic H-matrix
H\in\mathbb{R}^{3\times 3}
is parametrized by entries (as it is lower triangular), and the optimal ones must satisfy the three H-invariance identities.
Using those identities to eliminate the last rows’ entries, one can parametrize the optimal H-matrix set
{\mathcal{H}}_{\star}\subset\mathbb{R}^{3\times 3}
using
(h_{1,1},h_{2,1},h_{2,2})\in\mathbb{R}^{3}
.
The conditions
\lambda^{\star}_{k,j}(H)\geq 0
characterize the boundary surfaces of
{\mathcal{H}}_{\star}
under this parametrization, which enclose a 3-dimensional solid altogether (
Fig.

1
).
We can enumerate the algorithms (and the associated sparsity patterns on
\lambda^{\star}
) corresponding to vertices of this 3D volume:

:
The optimal H-matrix set
{\mathcal{H}}_{\star}
for
N=4
, parametrized by
(h_{1,1},h_{2,1},h_{2,2})
, has six vertices with sparse
\lambda^{\star}
.

•

Vertex
A
: OHM with
N=4
,
\lambda^{\star}_{3,1}=\lambda^{\star}_{4,1}=\lambda^{\star}_{4,2}=0
.

•

Vertex

: Dual-OHM with
N=4
,
\lambda^{\star}_{2,1}=\lambda^{\star}_{3,1}=\lambda^{\star}_{3,2}=0
.

•

Vertex
C
: Algorithm of
Section

8.2.1
with
N=4,N^{\prime}=2
(which is self-H-dual),
\lambda^{\star}_{3,1}=\lambda^{\star}_{3,2}=\lambda^{\star}_{4,1}=0
.

•

Vertex

: Algorithm of

with

(Dual-OHM augmented by OHM),
\lambda^{\star}_{2,1}=\lambda^{\star}_{4,1}=\lambda^{\star}_{4,2}=0
.

However,
{\mathcal{H}}_{\star}
has one last vertex
F
that is not a member of this list, which corresponds to the sparsity pattern

\displaystyle\lambda^{\star}_{2,1}=\lambda^{\star}_{3,2}=\lambda^{\star}_{4,1}=0.

(57)

We explicitly compute the associated values of
Q(3,\cdot,\cdot)
by solving (
57
) as

\displaystyle Q(3,1,1)=\frac{5}{12},\quad Q(3,1,2)=\frac{1}{2},\quad Q(3,1,3)=\frac{7}{12},\quad Q(3,2,1)=\frac{2}{3},\quad Q(3,2,2)=\frac{1}{3},\quad Q(3,3,1)=\frac{1}{4}

and identify the corresponding H-matrix as

\displaystyle H_{\text{strange}}=\begin{bmatrix}\frac{3}{4}\\
-\frac{1}{4}&\frac{4}{7}\\
-\frac{1}{12}&-\frac{1}{14}&\frac{7}{12}\end{bmatrix}.

We call this algorithm the
strange 3-iterate algorithm
.

H_{\text{strange}}
is indeed optimal, as we can compute its H-certificates as

\displaystyle\lambda^{\star}_{4,3}=4Q(3,1,3)=\frac{7}{3}

\displaystyle\lambda^{\star}_{4,2}=4(Q(3,1,2)-Q(3,2,2))=\frac{2}{3}

\displaystyle\lambda^{\star}_{3,1}=4Q(3,1,3)(-2Q(3,1,1)+3Q(3,2,1)-4Q(3,3,1))=\frac{7}{18}

and the remaining ones are
0
by design (
57
), which are all nonnegative.

Now consider its H-dual

\displaystyle H_{\text{strange}}^{\textsf{A}}=\begin{bmatrix}\frac{7}{12}\\
-\frac{1}{14}&\frac{4}{7}\\
-\frac{1}{12}&-\frac{1}{4}&\frac{3}{4}\end{bmatrix}.

This matrix satisfies the H-invariance conditions, but its Q-functions
\tilde{Q}(3,\cdot,\cdot)=Q\left(3,\cdot,\cdot;H_{\text{strange}}^{\textsf{A}}\right)
are as following:

\displaystyle\tilde{Q}(3,1,1)=\frac{3}{7},\quad\tilde{Q}(3,1,2)=\frac{9}{28},\quad\tilde{Q}(3,1,3)=\frac{3}{4},\quad\tilde{Q}(3,2,1)=\frac{4}{7},\quad\tilde{Q}(3,2,2)=\frac{3}{7},\quad\tilde{Q}(3,3,1)=\frac{1}{4}

and from this we can deduce that
H_{\text{strange}}^{\textsf{A}}
is not optimal—e.g., we have
\lambda^{\star}_{4,2}\left(H_{\text{strange}}^{\textsf{A}}\right)=4(\tilde{Q}(3,1,2)-\tilde{Q}(3,2,2))=-\frac{3}{7}<0
.

9
Conclusion

We provide a complete characterization of the minimax optimal fixed-point algorithms admitting H-matrix representations via H-invariants and H-certificates.
In our view, this translates
the study of optimal optimization algorithms to a study of mathematical structures, providing a holistic understanding of them beyond analyzing each algorithm’s convergence in isolation.
For fixed-point algorithms, our study raises interesting questions including characterizing optimal algorithms that remain optimal under the H-dual, classifying all extremal elements—vertices—of the optimal H-matrix set, or identifying an operations beyond the H-dual that induce interesting symmetry among optimal algorithms.

We believe similar lines of thought can be extended beyond the problem setup considered in this work.
For instance, one may broaden the algorithm class to include, e.g., an adaptive (yet still minimax optimal) variant of OHM proposed in
(
23
, Theorem 7.2)
.
Nonsmooth convex minimization with bounded subgradients is another problem setup where exact minimax optimal algorithms are known to be non-unique
(
17
;
4
;
6
)
, and we expect an analogous characterization of optimal algorithms to be achievable there.
For smooth convex minimization, exact optimality is achieved by OGM
(
9
;
5
)
, and similar results are achieved under strong convexity by ITEM
(
25
)
or for composite minimization with an additional proximable term by OptISTA
(
8
)
.
To the best of our knowledge, it is unknown whether these algorithms are uniquely optimal for their respective problem classes—interestingly, for the case of OptISTA, it is reported in
8
that numerical evidence suggests that it is not unique.
Careful consideration of worst-case instances, as in our work, may pave the way toward answering these questions.
For smooth minimax optimization problems, up-to-constant optimal acceleration of gradient-norm reduction has been achieved
(
30
;
13
;
26
)
, and although exact optimality is not yet established, there seems to be a strong connection between (proximal) fixed-point and minimax optimization algorithms
(
31
;
15
)
; hence, we anticipate that our theory may extend to that setting as well.
Finally, we raise the question of whether our theory can be combined with the recently proposed concept of dynamic optimality based on the notion of subgame perfect equilibrium, which is stronger than minimax optimality
(
1
)
.

Appendix A
Useful combinatorial lemmas

Lemma 11

(Chu-Vandermonde)
.

For
a,b\in\mathbb{R}
and a nonnegative integer
c
,

\displaystyle\sum_{i=0}^{c}\binom{a}{i}\binom{b}{c-i}=\binom{a+b}{c}.

Proof.

Both sides represent the coefficient of
x^{c}
in the product of the binomial series expansions of
(1+x)^{a}
and
(1+x)^{b}
.
∎

Lemma 12
.

Suppose
P(N-1,m)=\frac{1}{N}\binom{N}{m+1}
for
m=0,\dots,N-1
. Then
D(N)=\frac{1}{N}
.

Proof.

Observe that
\sum_{m=0}^{N}(-1)^{m}\binom{N}{m}=(1-1)^{N}=0
. Therefore,

\displaystyle D(N)=\frac{1}{N}\sum_{m=0}^{N-1}(-1)^{m}\binom{N}{m+1}=\frac{1}{N}\left(1-\sum_{m=0}^{N}(-1)^{m}\binom{N}{m}\right)=\frac{1}{N}.

∎

Lemma 13
.

Let
q,r
be nonnegative integers and let
p
be an integer satisfying
p\geq q+r
. Then

\displaystyle\sum_{j=r}^{p-q}\binom{p-j}{q}\binom{j}{r}=\binom{p+1}{q+r+1}.

Proof.

Note that
\binom{p-j}{q}=(-1)^{p-q-j}\binom{-q-1}{p-q-j}
and
\binom{j}{r}=(-1)^{j-r}\binom{-r-1}{j-r}
.
Using
Lemma

11
with
a=-q-1
,
b=-r-1
and
c=p-q-r
we have

\displaystyle\sum_{i=0}^{p-q-r}\binom{-q-1}{i}\binom{-r-1}{p-q-r-i}=\binom{-q-r-2}{p-q-r}=(-1)^{p-q-r}\binom{p+1}{q+r+1}.

The conclusion follows by making the index change
j=p-q-i
.
∎

Lemma 14
.

Let
q
be a nonnegative integer. Then

(a)

For any integers
p\geq s\geq q
, we have
\sum_{i=s}^{p}\binom{i}{q}=\binom{p+1}{q+1}-\binom{s}{q+1}
. In particular,
\sum_{i=q}^{p}\binom{i}{q}=\binom{p+1}{q+1}
.

(b)

For any integers
p\geq q+1
and
1\leq s\leq p-q
,

\displaystyle\sum_{j=1}^{s}j\binom{p-j}{q}

\displaystyle=\binom{p+1}{q+2}-s\binom{p-s}{q+1}-\binom{p-s+1}{q+2}

\displaystyle\sum_{j=s+1}^{p-q}j\binom{p-j}{q}

\displaystyle=s\binom{p-s}{q+1}+\binom{p-s+1}{q+2}.

In particular,
\sum_{j=1}^{p-q}j\binom{p-j}{q}=\binom{p+1}{q+2}
.

(c)

For any integer
p\geq q
, we have
\sum_{i=q}^{p}(i+1)\binom{i}{q}=(q+1)\binom{p+2}{q+2}
.

Proof.

(a) Setting
r=0
in
Lemma

13
, we have
\sum_{j=0}^{p-q}\binom{p-j}{q}=\sum_{i=q}^{p}\binom{i}{q}=\binom{p+1}{q+1}
where we make the index change
i=p-j
. Replacing
p
with
s-1
gives
\sum_{i=q}^{s-1}\binom{i}{q}=\binom{s}{q+1}
, with the understanding that when
s=q
, the summation is vacuous and therefore is
0
. Subtracting the two identities yields
\sum_{i=s}^{p}\binom{i}{q}=\binom{p+1}{q+1}-\binom{s}{q+1}
.

(b) Setting
r=1
in
Lemma

13
, we have
\sum_{j=1}^{p-q}j\binom{p-j}{q}=\binom{p+1}{q+2}
.
Replacing
p
with
p-s
gives
\sum_{j=1}^{p-q-s}j\binom{p-s-j}{q}=\sum_{i=s+1}^{p-q}(i-s)\binom{p-i}{q}=\binom{p-s+1}{q+2}
(the case
s=p-q
yields vacuous summation
0
), where we substitute
i=s+j
.
This implies
\sum_{j=s+1}^{p-q}j\binom{p-j}{q}=s\sum_{j=s+1}^{p-q}\binom{p-j}{q}+\sum_{j=s+1}^{p-q}(j-s)\binom{p-j}{q}=s\sum_{i=q}^{p-s-1}\binom{i}{q}+\sum_{i=s+1}^{p-q}(i-s)\binom{p-i}{q}=s\binom{p-s}{q+1}+\binom{p-s+1}{q+2}
.
The first identity follows by subtracting this from
\sum_{j=1}^{p-q}j\binom{p-j}{q}=\binom{p+1}{q+2}
.

(c) Use
(i+1)\binom{i}{q}=(i+1)\frac{i!}{q!(i-q)!}=\frac{(i+1)!}{q!(i-q)!}=(q+1)\frac{(i+1)!}{(q+1)!(i-q)!}=(q+1)\binom{i+1}{q+1}
and apply (a) with
p\leftarrow p+1
,
q\leftarrow q+1
.
∎

, but switch the order of summations:

\displaystyle Q(N-1,m+1,N^{\prime})

\displaystyle=\sum_{\ell=N^{\prime}+1}^{N-m}Q(N-1,m,\ell)\sum_{i=N^{\prime}}^{\ell-1}h_{i,N^{\prime}}

\displaystyle=\sum_{i=N^{\prime}}^{N-m-1}h_{i,N^{\prime}}\sum_{\ell=i+1}^{N-m}Q(N-1,m,\ell)

\displaystyle=h_{N^{\prime},N^{\prime}}\sum_{\ell=N^{\prime}+1}^{N-m}Q(N-1,m,\ell)-\sum_{i=N^{\prime}+1}^{N-m-1}(N-i)\left(\frac{1}{N-N^{\prime}}-\frac{1}{N}\right)\sum_{\ell=i+1}^{N-m}Q(N-1,m,\ell)

\displaystyle=\frac{N^{\prime}(N-N^{\prime})}{N}\sum_{\ell=N^{\prime}+1}^{N-m}\frac{1}{m+1}\binom{N-\ell-1}{m-1}-\sum_{i=N^{\prime}+1}^{N-m-1}(N-i)\left(\frac{1}{N-N^{\prime}}-\frac{1}{N}\right)\sum_{\ell=i+1}^{N-m}\frac{1}{m+1}\binom{N-\ell-1}{m-1}

\displaystyle=\frac{N^{\prime}(N-N^{\prime})}{N(m+1)}\binom{N-N^{\prime}-1}{m}-\frac{N^{\prime}}{N(N-N^{\prime})(m+1)}\sum_{i=N^{\prime}+1}^{N-m-1}(N-i)\binom{N-i-1}{m}

where in the last line, we use
Lemma

14
(a) to simplify the summations over
\ell
.
Then we note that
\sum_{i=N^{\prime}+1}^{N-m-1}(N-i)\binom{N-i-1}{m}=\sum_{i^{\prime}=m}^{N-N^{\prime}-2}\binom{i^{\prime}+1}{m}
(by index change
i^{\prime}=N-i-1
), which can be simplified to
(m+1)\binom{N-N^{\prime}}{m+2}
using
Lemma

14
(c).
Plugging this back into the above expression we obtain

\displaystyle Q(N-1,m+1,N^{\prime})=\frac{N^{\prime}(N-N^{\prime})}{N(m+1)}\binom{N-N^{\prime}-1}{m}-\frac{N^{\prime}}{N(N-N^{\prime})}\binom{N-N^{\prime}}{m+2}=\frac{N^{\prime}(N-N^{\prime}+1)}{N(m+2)}\binom{N-N^{\prime}-1}{m}

where the last identity can be verified by expanding the binomial coefficients.
This completes the induction, and concludes the proof that (
53
) is the correct
H
with the desired sparsity pattern.

B.5
Proof of
Proposition

8

Our proposed Q-function profile

\displaystyle Q(N-1,k,j)=\begin{cases}\frac{1}{k+1}\binom{N-j-1}{k-1}&\text{for }j=1,\dots,N^{\prime}-1\\
\frac{j-N^{\prime}+1}{N-N^{\prime}+1}\binom{N-j-1}{k-1}&\text{for }j=N^{\prime},\dots,N-1\end{cases}

clearly satisfies (
51
) with

\displaystyle c_{k,j}=\begin{cases}\frac{N-j+1}{k+1}\binom{N-j-1}{k-1}&\text{for }j=1,\dots,N^{\prime}-1\\
\binom{N-j-1}{k-1}&\text{for }j=N^{\prime},\dots,N-1.\end{cases}

This implies that (
bottom-sparsity
) holds for
j=1,\dots,N^{\prime}-1
(by
Proposition

4
) and (
top-sparsity
) holds for
j=N^{\prime},\dots,N-1
(by
Proposition

1
).
Therefore, as before (with the procedure of Section
8.1.1
determining Q-profile), it only remains to check:
(i)
H-invariance condition (
49
) and
(ii)
positivity of the remaining H-certificates.

(i)

H-invariance.
For each
m=1,\dots,N-1
,

\displaystyle\sum_{j=1}^{N-m}Q(N-1,m,j)

\displaystyle=\sum_{j=1}^{N^{\prime}-1}\frac{1}{m+1}\binom{N-j-1}{m-1}+\sum_{j=N^{\prime}}^{N-m}\frac{j-N^{\prime}+1}{N-N^{\prime}+1}\binom{N-j-1}{m-1}

\displaystyle=\frac{1}{m+1}\sum_{i=N-N^{\prime}}^{N-2}\binom{i}{m-1}+\frac{1}{N-N^{\prime}+1}\sum_{i=1}^{N-N^{\prime}-m+1}i\binom{N-N^{\prime}-i}{m-1}

\displaystyle=\frac{1}{m+1}\left[\binom{N-1}{m}-\binom{N-N^{\prime}}{m}\right]+\frac{1}{N-N^{\prime}+1}\binom{N-N^{\prime}+1}{m+1}

where for the last equality, the first summation is simplified using
Lemma

14
(a) and the second summation uses
Lemma

14
(b).
Finally, because
\frac{1}{m+1}\binom{N-1}{m}=\frac{1}{N}\binom{N}{m+1}
and
\frac{1}{m+1}\binom{N-N^{\prime}}{m}=\frac{1}{N-N^{\prime}+1}\binom{N-N^{\prime}+1}{m+1}
we conclude that
\sum_{j=1}^{N-m}Q(N-1,m,j)=\frac{1}{N}\binom{N}{m+1}
as desired.

(ii)

Positivity of remaining
\lambda^{\star}
.
Because the values of
Q(N-1,k,j)
for
j=1,\dots,N^{\prime}-1
agree with those of Dual-OHM, the values of
\lambda^{\star}_{N,j}=N\sum_{\ell=1}^{N-j}(-1)^{\ell-1}Q(N-1,\ell,j)
also agree with those of Dual-OHM, and hence are positive.
Next,
\lambda^{\star}_{N,N-1}=N\cdot Q(N-1,1,N-1)>0
.
Finally, for
j=N^{\prime},\dots,N-2
, we have

\displaystyle\lambda^{\star}_{j+1,j}

\displaystyle=N\sum_{m=1}^{N-j-1}(-1)^{m-1}Q(N-1,m,j+1)\sum_{\ell=1}^{N-j}(-1)^{\ell}\binom{\ell+m}{m}Q(N-1,\ell,j)

\displaystyle=N\sum_{m=1}^{N-j-1}(-1)^{m-1}Q(N-1,m,j+1)\frac{j-N^{\prime}+1}{N-N^{\prime}+1}\underbrace{\sum_{\ell=1}^{N-j}(-1)^{\ell}\binom{\ell+m}{m}\binom{N-j-1}{\ell-1}}_{=\begin{cases}0&\text{if }m<N-j-1\\
(-1)^{N-j}&\text{if }m=N-j-1\end{cases}}

\displaystyle=N\cdot Q(N-1,N-j-1,j+1)\cdot\frac{j-N^{\prime}+1}{N-N^{\prime}+1}=\frac{N(j-N^{\prime}+2)(j-N^{\prime}+1)}{(N-N^{\prime}+1)^{2}}

\displaystyle>0

where the simplification of the second line follows by plugging
a=N-j-1
,
b=-m-1
,
c=N-j
into
Lemma

11
, making the change of index
\ell=N-j-i
and using
\binom{-m-1}{\ell}=(-1)^{\ell}\binom{\ell+m}{\ell}
; the summation becomes
\binom{N-j-m-2}{N-j}
, which is
0
for
m=1,\dots,N-j-2
and
\binom{-1}{N-j}=(-1)^{N-j}
when
m=N-j-1
.

B.6
Proof of
Proposition

9

For
j=N^{\prime},\dots,N-1
,
Q(N-1,k,j)
depends only on the lower right block of
H
, which equals
H_{\text{OHM}}(N-N^{\prime})
.
The rule determining the terms within
Q(N-1,k,j)
for (
55
) is the same as determining the terms within
Q(N-N^{\prime},k,j-N^{\prime}+1)
for
H_{\text{OHM}}(N-N^{\prime})
(note the index shift in the last argument).
Therefore, we have

\displaystyle Q(N-1,k,j;H)

\displaystyle=Q(N-N^{\prime},k,j-N^{\prime}+1;H_{\text{OHM}}(N-N^{\prime}))

\displaystyle=\frac{j-N^{\prime}+1}{N-N^{\prime}+1}\binom{(N-N^{\prime}+1)-(j-N^{\prime}+1)-1}{k-1}

\displaystyle=\frac{j-N^{\prime}+1}{N-N^{\prime}+1}\binom{N-j-1}{k-1}

which agrees with (
54
) for
j=N^{\prime},\dots,N-1
.

For
j=1,\dots,N^{\prime}-1
, we first see that

\displaystyle Q(N-1,1,j)

\displaystyle=h_{j,j}+\sum_{k=j+1}^{N^{\prime}-1}h_{k,j}+\sum_{k=N^{\prime}}^{N-1}h_{k,j}

\displaystyle=\frac{N-j}{N-j+1}-\sum_{k=j+1}^{N^{\prime}-1}\frac{N-k}{(N-j)(N-j+1)}-\sum_{k=N^{\prime}}^{N-1}\frac{N-N^{\prime}+1}{2(N-j)(N-j+1)}

\displaystyle=\frac{N-j}{N-j+1}-\frac{1}{(N-j)(N-j+1)}\frac{(N^{\prime}-j-1)(2N-N^{\prime}-j)}{2}-\frac{(N-N^{\prime}+1)(N-N^{\prime})}{2(N-j)(N-j+1)}

\displaystyle=\frac{1}{2(N-j)(N-j+1)}\underbrace{\left[2(N-j)^{2}-(N^{\prime}-j-1)(2N-N^{\prime}-j)-(N-N^{\prime}+1)(N-N^{\prime})\right]}_{=(N-j)(N-j+1)}

\displaystyle=\frac{1}{2}.

Next, we use induction on
m=1,\dots,N-1
to show that the values of
Q(N-1,m,j)
agree with those from (
54
) for any
j=1,\dots,N-m
.
(In fact, we only need to prove it for
j\leq N^{\prime}-1
.)
The case
m=1
is proved by the above argument.
Suppose the statement holds for some
m=1,\dots,N-2
and fix any
j\leq\min\{N^{\prime}-1,N-m-1\}
.
We use the recursion of
Q
-functions in
Lemma

2
with the order of summations switched:

\displaystyle Q(N-1,m+1,j)

\displaystyle=\sum_{\ell=j+1}^{N-m}Q(N-1,m,\ell)\sum_{i=j}^{\ell-1}h_{i,j}=\sum_{i=j}^{N-m-1}h_{i,j}\sum_{\ell=i+1}^{N-m}Q(N-1,m,\ell).

(66)

Given the induction hypothesis, when
i\geq N^{\prime}-1
, the inner summation can be simplified as

\displaystyle\sum_{\ell=i+1}^{N-m}Q(N-1,m,\ell)

\displaystyle=\sum_{\ell=i+1}^{N-m}\frac{\ell-N^{\prime}+1}{N-N^{\prime}+1}\binom{N-\ell-1}{m-1}

\displaystyle=\frac{1}{N-N^{\prime}+1}\sum_{j=i-N^{\prime}+2}^{N-N^{\prime}-m+1}j\binom{N-N^{\prime}-j}{m-1}

\displaystyle=\frac{1}{N-N^{\prime}+1}\left((i-N^{\prime}+1)\binom{N-i-1}{m}+\binom{N-i}{m+1}\right)

(67)

where the second line follows from the change of index
j=\ell-N^{\prime}+1
and the third line uses
Lemma

14
(b) with
p=N-N^{\prime}
,
q=m-1
and
s=i-N^{\prime}+1
.
When
i<N^{\prime}-1
, we have

\displaystyle\sum_{\ell=i+1}^{N-m}Q(N-1,m,\ell)

\displaystyle=\sum_{\ell=i+1}^{N^{\prime}-1}\frac{1}{m+1}\binom{N-\ell-1}{m-1}+\sum_{\ell=N^{\prime}}^{N-m}\frac{\ell-N^{\prime}+1}{N-N^{\prime}+1}\binom{N-\ell-1}{m-1}

\displaystyle=\frac{1}{m+1}\sum_{j=N-N^{\prime}}^{N-i-2}\binom{j}{m-1}+\frac{1}{N-N^{\prime}+1}\sum_{j=1}^{N-N^{\prime}-m+1}j\binom{N-N^{\prime}-j}{m-1}

\displaystyle=\frac{1}{m+1}\left[\binom{N-i-1}{m}-\binom{N-N^{\prime}}{m}\right]+\frac{1}{N-N^{\prime}+1}\binom{N-N^{\prime}+1}{m+1}

(68)

\displaystyle=\frac{1}{m+1}\binom{N-i-1}{m}

where the last identity holds because
\frac{1}{m+1}\binom{N-N^{\prime}}{m}=\frac{1}{N-N^{\prime}+1}\binom{N-N^{\prime}+1}{m+1}
.
Note that (
68
) yields the same result as (
67
) for
i=N^{\prime}-1
so we can use (
68
) even for
i=N^{\prime}-1
.
Now plugging these identities into (
66
) and using
h_{j,j}=\frac{N-j}{N-j+1},h_{i,j}=-\frac{N-i}{(N-j)(N-j+1)}
for
i=j+1,\dots,N^{\prime}-1
and
h_{i,j}=-\frac{N-N^{\prime}+1}{2(N-j)(N-j+1)}
for
i=N^{\prime},\dots,N-1
, we obtain

\displaystyle Q(N-1,m+1,j)

\displaystyle=\frac{N-j}{N-j+1}\frac{1}{m+1}\binom{N-j-1}{m}-\sum_{i=j+1}^{N^{\prime}-1}\frac{N-i}{(N-j)(N-j+1)}\frac{1}{m+1}\binom{N-i-1}{m}

\displaystyle\quad-\sum_{i=N^{\prime}}^{N-m-1}\frac{N-N^{\prime}+1}{2(N-j)(N-j+1)}\frac{1}{N-N^{\prime}+1}\left((i-N^{\prime}+1)\binom{N-i-1}{m}+\binom{N-i}{m+1}\right)

\displaystyle\begin{aligned} &=\frac{N-j}{(N-j+1)(m+1)}\binom{N-j-1}{m}-\frac{1}{(N-j)(N-j+1)(m+1)}\underbrace{\sum_{i=j+1}^{N^{\prime}-1}(N-i)\binom{N-i-1}{m}}_{(*)}\\
&\quad-\frac{1}{2(N-j)(N-j+1)}\bigg(\underbrace{\sum_{i=N^{\prime}}^{N-m-1}(i-N^{\prime}+1)\binom{N-i-1}{m}}_{=\binom{N-N^{\prime}+1}{m+2}}+\underbrace{\sum_{i=N^{\prime}}^{N-m-1}\binom{N-i}{m+1}}_{=\binom{N-N^{\prime}+1}{m+2}}\bigg)\end{aligned}

(69)

where the simplification of the last two terms respectively uses
Lemma

14
(b) and (a).
The summation
(*)
can be simplified as following, using the identity
(N-i)\binom{N-i-1}{m}=(m+1)\binom{N-i}{m+1}
:

\displaystyle(*)=\sum_{i=j+1}^{N^{\prime}-1}(m+1)\binom{N-i}{m+1}=(m+1)\sum_{\ell=N-N^{\prime}+1}^{N-j-1}\binom{\ell}{m+1}=(m+1)\left[\binom{N-j}{m+2}-\binom{N-N^{\prime}+1}{m+2}\right]

where we make the change of index

and use

(a).
Plugging this into (

\displaystyle Q(N-1,m+1,j)

\displaystyle=\frac{N-j}{(N-j+1)(m+1)}\binom{N-j-1}{m}-\frac{1}{(N-j)(N-j+1)}\binom{N-j}{m+2}

\displaystyle=\frac{N-j}{(N-j+1)(m+1)}\binom{N-j-1}{m}-\frac{N-j-m-1}{(N-j+1)(m+1)(m+2)}\binom{N-j-1}{m}

\displaystyle=\frac{(m+2)(N-j)-(N-j-m-1)}{(N-j+1)(m+1)(m+2)}\binom{N-j-1}{m}

\displaystyle=\frac{1}{m+2}\binom{N-j-1}{m}

which completes the induction, and thereby proves the correctness of (
