Range Avoidance in Boolean Circuits via Turan-type Bounds
Neha Kuntewar, Jayalal Sarma *

Abstract
Given a circuit C : { 0 , 1 } n → { 0 , 1 } m C:\{0,1\}^{n}\to\{0,1\}^{m} from a circuit class 𝒞 {\mathcal{C}} , with m > n m>n , finding a y ∈ { 0 , 1 } m y\in\{0,1\}^{m} such that ∀ x ∈ { 0 , 1 } n \forall x\in\{0,1\}^{n} , C ⁡ ( x ) ≠ y C(x)\neq y , is the range avoidance problem (denoted by 𝒞 {\cal C} - Avoid ). Deterministic polynomial time algorithms (even with access to 𝖭𝖯 {\mathsf{NP}} oracles) solving this problem are known to imply explicit constructions of various pseudorandom objects like hard Boolean functions, linear codes, PRGs etc. Deterministic polynomial time algorithms are known for 𝖭𝖢 2 0 {\mathsf{NC}}^{0}_{2} - Avoid when m > n m>n , and for 𝖭𝖢 3 0 {\mathsf{NC}}^{0}_{3} - Avoid when m ≥ n 2 log ⁡ n m\geq\frac{n^{2}}{\log n} , where 𝖭𝖢 k 0 {\mathsf{NC}}^{0}_{k} is the class of circuits with bounded fan-in which have constant depth and the output depends on at most k k of the input bits. On the other hand, it is also known that 𝖭𝖢 3 0 {\mathsf{NC}}^{0}_{3} - Avoid when m = n + O ⁡ ( n 2 / 3 ) m=n+O\left(n^{2/3}\right) is at least as hard as explicit construction of rigid matrices. In fact, algorithms for solving range avoidance for even 𝖭𝖢 4 0 {\mathsf{NC}}^{0}_{4} circuits imply new circuit lower bounds. In this paper, we propose a new approach to solving the range avoidance problem via hypergraphs. We formulate the problem in terms of Turan-type problems in hypergraphs of the following kind: for a fixed k k -uniform hypergraph H H , what is the maximum number of edges that can exist in H C H_{C} , which does not have a sub-hypergraph isomorphic to H H ? We show the following: • We first demonstrate the applicability of this approach by showing alternate proofs of some of the known results for the range avoidance problem using this framework. • We then use our approach to show (using several different hypergraph structures for which Turan-type bounds are known in the literature) that there is a constant c c such that Monotone - 𝖭𝖢 3 0 {\mathsf{NC}}^{0}_{3} - Avoid can be solved in deterministic polynomial time when m > c ​ n 2 m>cn^{2} . • To improve the stretch constraint to linear, more precisely, to m > n m>n , we show a new Turan-type theorem for a hypergraph structure (which we call the loose 𝒳 2 ​ ℓ {\cal X}\textrm{${}_{2\ell}$} -cycles ). More specifically, we prove that any connected 3-uniform linear hypergraph with m > n m>n edges must contain a loose 𝒳 2 ​ ℓ {\cal X}\textrm{${}_{2\ell}$} cycle. This may be of independent interest. • Using this, we show that Monotone - 𝖭𝖢 3 0 {\mathsf{NC}}^{0}_{3} - Avoid can be solved in deterministic polynomial time when m > n m>n , thus improving the known bounds of 𝖭𝖢 3 0 {\mathsf{NC}}^{0}_{3} - Avoid for the case of monotone circuits. In contrast, we note that efficient algorithms for solving Monotone - 𝖭𝖢 6 0 {\mathsf{NC}}^{0}_{6} - Avoid , already imply explicit constructions for rigid matrices. • We also generalise our argument to solve the special case of range avoidance for 𝖭𝖢 k 0 {\mathsf{NC}}^{0}_{k} where each output function computed by the circuit is the majority function on its inputs, where m > n 2 m>n^{2} .

, which is a contradiction.

Case 2

Suppose
k
is even. By the previous argument, for edges in
E_{2}
to get color
B
at least
k\left(\frac{k}{2}+1\right)
vertices should be colored
B
. For edges in
E_{1}
at least
k\left(\frac{k}{2}\right)
vertices should be colored

. So totally, there are at least

vertices in
V
, which is again a contradiction.

In either case, we obtain a contradiction. Hence,

is not a
MAJ
-coloring.
∎

By proposition
2.3
and lemma

, we have the following result:

Theorem 3.10
.

Let

be an instance of
\textrm{\sc One-Intersect-Maj}_{k}
-
Avoid
and
m>\frac{n(n-1)}{k(k-1)}

4.2

\textrm{\sc{MAJ}}_{3}
-
Avoid
with Quadratic Stretch

We show that there is a deterministic polynomial time algorithm for
\textrm{\sc{MAJ}}_{3}
-
Avoid
. Recall that
\textrm{\sc{MAJ}}_{3}
-
Avoid
instance is a circuit
C:\{0,1\}^{n}\to\{0,1\}^{m}
with constant depth, bounded fan-in and polynomial size, where each output function of the circuit is a majority of exactly three input variables. For each
i\in[m]
, let
f_{i}
denote the function corresponding to the
i
-th output bit, and let
I(f_{i})
denote the set of three variables that
f_{i}
depends on. We shall demonstrate the working of the algorithm in three steps.

For our purpose, we shall define sub-circuits of
C
called

(denoted by
K
) as follows: Let
{\cal O}=\{f_{1},\ldots f_{m}\}
be the set of output functions of
C
. We define the relation
R:{\cal O}\times{\cal O}
as follows: We say
(f_{i},f_{j})\in R
if
\exists
some input
x
that feeds into both
f_{i},f_{j}
for
i,j\in[m]
. Let
R^{\prime}
be the transitive closure of
R
. Observe that
R^{\prime}
is an equivalence relation. We define a cluster to be an equivalence class of
R^{\prime}
.

Step 1: Reduction to a single cluster:

The following lemma shows that
C
must contain a cluster with more outputs than inputs and hence we can concentrate on such a cluster.

Lemma 4.2
.

Let
C:\{0,1\}^{n}\rightarrow\{0,1\}^{m}
be a multi-output circuit with
m>n
, then there exists a cluster
K
such that
|K|>|I(K)|
where
I(K)=\cup_{f\in K}I(f)
.

Proof.

Let
K_{1},\ldots K_{t}
be the clusters such that
\cup_{i\in[t]}K_{i}
covers the set of output functions of
C
. Observe that
\cup_{i\in[t]}I(K_{i})
covers the input set of
C
. By definition,
\forall i,j\in[t]
such that
i\neq j
we have that
K_{i}\cap K_{j}=\emptyset
and
I(K_{i})\cap I(K_{j})=\emptyset
. Assume for the sake of contradiction that for each cluster
K_{i}
, we have
|K_{i}|\leq|I(K_{i})|
. Then by the above observation, we have that
\left|\cup_{i\in[t]}K_{i}\right|\leq\left|\cup_{i\in[t]}I(K_{i})\right|
implying that
m<n
, which is a contradiction.
∎

Let
K
be a cluster guaranteed by proposition
4.2
. Let
C_{K}
be the sub-circuit of
C
corresponding to the cluster
K
. Since,
|K|>|I(K)|
, there must be a string outside the range of
C_{K}
. Observe that if
y^{\prime}\in\{0,1\}^{|K|}\not\in{\sf Range}(C_{K})
then any
y\in\{0,1\}^{m}
which agrees with
y^{\prime}
is outside
{\sf Range}(C)
. Hence, it suffices to solve the problem on
C_{K}
.

It is easy to see that if there exist two output functions that intersect in three inputs, then we already have a string outside the range. Hence, we consider the cases when they intersect in fewer than three inputs. Motivated by this, we define the following problems:
\textrm{\sc Two-Intersect-Maj}_{3}
-
Avoid
(
\textrm{\sc One-Intersect-Maj}_{3}
-
Avoid

C:\{0,1\}^{n}\rightarrow\{0,1\}^{m}
such that output function is
\textrm{\sc{MAJ}}_{3}
function and any two functions share at most two (resp. one) inputs, the goal is to find
y\not\in{\sf Range}(C)
.

Step 2 : A reduction to
\textrm{\sc One-Intersect-Maj}_{3}
-
Avoid

For the rest of the proof,
C=C_{K}
,
m=m^{\prime}
and

. We show that there is a polynomial time reduction from

\textrm{\sc One-Intersect-Maj}_{3}

Avoid

Lemma 4.3
.

There is a polynomial time reduction from
\textrm{\sc Two-Intersect-Maj}_{3}\textrm{-}\textrm{\sc Avoid}
to

\textrm{\sc One-Intersect-Maj}_{3}\textrm{-}\textrm{\sc Avoid}

Proof.

Let
C:\{0,1\}^{n}\to\{0,1\}^{m}
be a circuit such that each output bit is computed by a
\textrm{\sc{MAJ}}_{3}
function where
m>n
. By step

, we know that the set of functions corresponding to
C
form some cluster
K
. Hence, we obtain
C
starting with an arbitrary function in
K
and iteratively adding a new function
f
to
\mathcal{O}
, such that
I(f)\cap I(\mathcal{O})\neq\emptyset
. Our algorithm will follow this construction procedure, and eliminate functions that appear in that order by setting input variables.

We start with the following claim that helps us eliminate functions from the circuit by setting input variables. Let
f_{1},f_{2}
be two output functions of
C
such that
|I(f_{1})\cap I(f_{2})|=2
. Initially
{\cal O}=\{f_{1},f_{2}\}
, and we iteratively apply the following claim for each function
g\in K\setminus{\cal O}
that is used to build the cluster by the above process. A variable in
I(K)
is said to be

Claim 4.4
.

\forall g\in K\setminus\mathcal{O}
such that
|I(g)\cap I({\mathcal{O}})|=2
, there is a setting of

and a consistent partial assignment to the input variables (or identification of variables), such that at most one variable in
\mathcal{O}
remains alive.

Proof.

We shall prove this by induction on the construction of the cluster. Initially, let
\mathcal{O}

=\{f_{1},f_{2}\}

I(f_{1})=\{x_{1},x_{2},x_{3}\}
and
I(f_{2})=\{x_{2},x_{3},x_{4}\}
. We observe that if
f_{1}=1
and
f_{2}=0
, then
x_{1}=1,x_{4}=0,x_{3}=\neg x_{2}
and the number of variables in
I(\mathcal{O})
is exactly
1
.

By hypothesis, the number of variables in

which are alive after

steps is at most
1
. Now consider a

such that

, we would like to show that there is an assignment of values to

(which also sets some input variables) such that in the new cluster,

, the number of variables that are alive is still at most

Case 1:

Both

are not alive:

There are two cases to consider. Suppose

.
The other case is when

,

Case 2:

z_{2}=x

Case 3:

Both
z_{1}

z_{2}

Now, we consider the functions

\overline{b}
and the input variables in

. Consider the other case when

is alive. Wlog let

. We set the output of

. In this case, we have not yet assigned a fixed

.

iterations, we would have fixed each of the inputs to one of

, which is guaranteed since

. Observe that
I(f)\subseteq I(\mathcal{O})
. Let
I(f)=\{x_{1},x_{2},x_{3}\}
. The following two cases arise based on the number of alive variables.

Case 1:

Suppose there is no variable in
\mathcal{O}
which is alive. Then the value of
f

. Wlog let this be

Case 2:

Suppose there is exactly one variable that is alive. Wlog let

.

Consider the case when

\overline{b}

f
to

.

, we reduce our problem to an instance of

gives a polynomial time algorithm for solving
\textrm{\sc One-Intersect-Maj}_{3}

.

In this section, we prove a new Turan-type theorem for

5.1
Extremal Bounds for Loose
{\cal X}\textrm{${}_{2\ell}$}
-Cycles

We first show an extremal bound for the loose
{\cal X}\textrm{${}_{2\ell}$}
cycle in a connected
3
-uniform linear hypergraph.

See
1.7

Proof.

Let
\mathcal{H}
be a connected 3-uniform linear hypergraph with
m>n
. We would like to show that there is a loose
{\cal X}\textrm{${}_{2\ell}$}
cycle in
\mathcal{H}
. Towards this, we construct
block graph

G
corresponding to
\mathcal{H}
as follows: let the set of
m
hyperedges in
\mathcal{H}
be the vertices of
G
and add an edge
(f,g)
if the hyperedges
f,g
intersect at a vertex. Note that
G
is a simple graph since
\mathcal{H}
is linear. Observe that
G
is connected. We have
|G|=m
since the vertices in
G
correspond to the hyperedges in
\mathcal{H}
. Now we shall argue that finding a copy of loose
{\cal X}\textrm{${}_{2\ell}$}
cycle in
\mathcal{H}
is equivalent to finding a subgraph
G^{\prime}
in
G
where
G^{\prime}
consists of an edge
(f,f^{\prime})
and distinct odd walks from
g
to
g^{\prime}
and
h
to
h^{\prime}
without using edge
(f,f^{\prime})
, where
g,h
and
g^{\prime},h^{\prime}
are neighbors of
f,f^{\prime}
respectively in
G
. The equivalence follows from the observation that a walk of length
\ell
corresponds to a walk of length
\ell-1
in
G
. Thus, our task is to show that
G^{\prime}\subseteq G
.

For each vertex
x_{i}
in
\mathcal{H}
, there is a clique of size
m_{i}
in
G
, where
i\in[n],1\leq m_{i}\leq m
. Furthermore, each vertex in
G
participates in
3
cliques, since
\mathcal{H}
is
3
-uniform. The number of edges in
G=\sum_{i\in[n]}{m_{i}\choose 2}
.

\displaystyle|E(G)|=\sum_{i\in[n]}{m_{i}\choose 2}

\displaystyle=\sum_{i\in[n]}\frac{m_{i}^{2}}{2}-\sum_{i\in[n]}\frac{m_{i}}{2}

\displaystyle=\sum_{i\in[n]}\frac{m_{i}^{2}}{2}-\frac{3m}{2}

\displaystyle\big(\because\sum_{i\in[n]}m_{i}=3m\big)

Lemma A.8

-odd butterfly. Then there is an edge coloring
\Gamma:E(\mathcal{H})\rightarrow\{R,B\}

Proof.

Let

be the two loose cycles of order

\mathcal{H}

C_{1}:=

u_{1}e_{1}u_{2}e_{2}\ldots u_{k}e_{k}u_{1}

C_{2}:=u_{1}f_{1}v_{2}f_{2}\ldots v_{\ell}f_{\ell}u_{1}

\Gamma:E\rightarrow\{R,B\}
is not a
MAJ
-coloring.

\Gamma(e_{i})=\begin{cases}R,&\textrm{ if $i$ is even}\\
B,&\textrm{ otherwise}\end{cases}

\Gamma(f_{i})=\begin{cases}R,&\textrm{ if $i$ is odd}\\
B,&\textrm{ otherwise}\end{cases}

where
i\in[k]
. First, we will show the following claim:

Claim A.9
.

Let
\Gamma:E\rightarrow\{R,B\}
be a
MAJ
-coloring under vertex coloring
\Pi:V\rightarrow\{R,B\}
such that
\Pi(u_{i})=c
and
\Gamma(e_{i})=\overline{c}
where

and
\overline{c}=\{R,B\}\setminus\{c\}
. Then
\Pi(u_{i+1})=\overline{c}
.

. Since
\Gamma
is a

-coloring satisfying

, the other two vertices in

Suppose

Definition A.10
.

Lemma A.11
.

Let
\mathcal{H}
be a
(k,\ell)
-odd kite. Then there exists an edge-coloring
\Gamma:E\rightarrow\{R,B\}
which is not a valid
MAJ
-coloring. Furthermore, we can find such a coloring in polynomial time.

Proof.

We will show that the following edge-coloring
\Gamma
is not a valid edge-coloring:

\Gamma(e)=\begin{cases}B,&\textrm{ if $e=e_{i}\in\{e_{1},\ldots e_{k}\}$ and $i$ is odd}\\
R,&\textrm{ if $e=e_{i}\in\{e_{1},\ldots e_{k}\}$ and $i$ is even}\\
R,&\textrm{ if $e=f_{j}\in\{f_{1},\ldots f_{\ell-1}\}$ and $j$ is odd}\\
B,&\textrm{ if $e=f_{j}\in\{f_{1},\ldots f_{\ell-1}\}$ and $j$ is even}\\
R,&\textrm{ if $e=e^{\prime}=\{u_{0},u_{i},v_{j}\}$ and $i$ is even}\\
B,&\textrm{ if $e=e^{\prime}=\{u_{0},u_{i},v_{j}\}$ and $i$ is odd}\end{cases}

We consider the following cases based on the colors of vertices
u_{1},u_{k}
:

Case
1
:
Suppose
\Pi(u_{1})=\Pi(u_{k})=R
. Since two of its vertices are colored

is

, which is a contradiction.

Case
2
:
Wlog let
\Pi(u_{1})=R,\Pi(u_{k})=B

Claim

A.9
in cycle

we get that
\Pi(u_{k})=R

A.9
on cycle

Since, in either case, we obtain a contradiction,

MAJ
-coloring.
∎
