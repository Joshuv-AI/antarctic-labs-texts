ButterflyMoE: Sub-Linear Ternary Experts via Structured Butterfly Orbits
Aryan Karmore

Abstract
Linear memory scaling stores N N independent expert weight matrices requiring 𝒪 ⁡ ( N ⋅ d 2 ) \mathcal{O}(N\cdot d^{2}) memory, which exceeds edge devices memory budget. Current compression methods like quantization, pruning and low-rank factorization reduce constant factors but leave the scaling bottleneck unresolved. We introduce ButterflyMoE, a method that treats experts not as independent weight matrices but as geometric reorientations of a unified shared quantized substrate. Diversity among experts arises from viewing different angles of shared capacity, not from redundant storage. By applying learned rotations to a shared ternary prototype, each expert yields 𝒪 ⁡ ( d 2 + N ⋅ d ​ log ⁡ d ) \mathcal{O}(d^{2}+N\cdot d\log d) memory—sub-linear in the number of experts. The key insight: training these rotations with quantization reduces activation outliers and stabilizes extreme low bit training, where static methods collapse. Across language modeling benchmarks, ButterflyMoE achieves 150 × \times memory reduction at 256 experts with negligible accuracy loss. ButterflyMoE allows multiple experts to fit on edge-constrained devices showing that geometric parameterization breaks linear scaling.

Introduction

A (Mixture of Expert) MoE layer with 64 experts having dimension
d=512
requires 256 MB of memory, exceeding edge device limits. This is the result of an architectural assumption that each expert requires separate parameters.

Current compression methods retain linear memory scaling. Quantization (QMoE
[
9
]
, MoQE
[
15
]
) reduces bit-width and achieves 4–5× compression but retains
O(N\cdot d^{2})
memory growth.Even 2-bit quantization requires 128 MB per layer at 256 experts. The structural question of whether
N
experts need
O(N)
separate parameter sets is not addressed.

In light of recent research on linear model connection, we propose that rather than being stored separately, experts can be formed from a shared prototype through straightforward transformations. This arrangement introduces sub-linear memory scaling.

ButterflyMoE parameterizes
N
experts as learned rotations of a single ternary-quantized substrate. Each expert
W_{i}
is defined as:

W_{i}=\mathcal{B}(\phi_{i})\cdot W_{\text{base}}\cdot\mathcal{B}(\theta_{i})^{T},

where
W_{\text{base}}\in\{-1,0,+1\}^{d\times d}
is a shared 1.58-bit weight matrix and
\mathcal{B}(\phi_{i}),\mathcal{B}(\theta_{i})
are expert-specific Butterfly matrices with
O(d\log d)
parameters. Experts are never explicitly materialized. Inference proceeds by applying a rotation and a ternary matrix multiply. This yields
O(d^{2}+N\cdot d\log d)
memory.

This structural change has three benefits:(i) Memory compression improves with expert count achieving a 150x compression at 256 experts, (ii) Per-expert input rotations suppress activation outliers,(iii) A ternary substrate with rotations reduce quantization error by 97% relative to post-training quantization.

ButterflyMoE equals dense accuracy on multi-domain language modeling while enabling deployments that were previously unattainable. On a Jetson Nano, the 64 expert model uses 1.9 MB of memory, compared to 256 MB for the baseline, and trains stably without recovery stages.

•

2.1
MoE Memory Compression

Existing compression methods remain limited due to linear expert scaling. Recent work has explored the following approaches:

•

Basic decomposition methods represent experts as linear combinations of shared basis. MoBE
[
4
]
decomposes
N

K

\mathcal{O}(K\cdot d^{2}+N\cdot K)
memory which is a 24–30% reduction. However, this remains linear in
N
when
K

[
18
]
achieve 2
\times

•

Expert Pruning and merging:PuzzleMoE
[
19
]
merges redundant experts and applies 3-bit quantization, achieving 50% sparsity and a 2
\times
with a tradeoff in accuracy. Expert trimming
[
11
]
drops underutilized experts retaining 77% memory but trading efficiency.

These approaches share a common structural limitation: expert identity is considered irreducible, which necessitates the explicit materialisation of each weight matrix.

2.2
Quantization for Model Compression

Low-bit quantization is a primary compression strategy for large language models. QMoE
[
9
]
achieves sub-1 bit compression through aggressive quantization yielding a 10-20
\times
memory reduction with a ¡2% accuracy loss. MoQE
[
15
]
applies 2-bit weight-only quantization to MoE models, achieving a 5.0
\times
compression ratio while surpassing dense baselines in accuracy. Mixture Compressor
[
14
]
employs mixed-precision quantization with an average of 2.54 bits, reducing model size to 76.6% of its original size.
However, quantization alone cannot break linear scaling. At 2 bits per weight, a 64-expert MoE still requires
\frac{N\cdot d^{2}}{16}
—e.g., 52 MB for
d=512
. Scaling to 256 experts requires 208 MB.Quantization reduces the constant factor but preserves
\mathcal{O}(N\cdot d^{2})
complexity.

Another limitation arises from outlier handling, activation distributions in transformers exhibit outliers, 10-100x times larger than the median
[
17
]
. QuaRot
[
2
]
applies a single global Hadamard rotation to suppress outliers before quantization. These methods assume outlier distributions remain stable during training,an assumption violated by channel drift during fine tuning. Moreover, global experts cannot capture per-expert specialization, the average case performance is optimized across all experts.

To the best of our knowledge, butterfly-structured matrices have not previously been used to parameterize expert identity in MoE architectures. Prior work uses them as drop-in substitutes for dense layers but does not tackle the problem of expert parameterization. LoRA

adds low-rank updates

2.4
ButterflyMoE

ButterflyMoE introduces a structural insight that experts in MoE models can be parameterized as orbital variations of a single quantized prototype under learned transformations. ButterflyMoE replaces expert storage with a group-orbit parameterization. This eliminates the need to materialize expert weights entirely.
Recent work on on linear mode connectivity
[
10
,
1
]
shows that distinct neural networks trained on similar data reside on permutation invariant subspaces. This observation is extended to MoE architecture by parameterizing
N
independent matrices
\{W_{i}\}
as:

W_{i}=\mathcal{B}(\phi_{i})\cdot W_{\text{base}}\cdot\mathcal{B}(\theta_{i})^{T}

where
W_{\text{base}}\in\{-1,0,+1\}^{d\times d}
is ternary-quantized (1.58 bits/weight) and
\mathcal{B}(\phi_{i}),\mathcal{B}(\theta_{i})
are expert-specific Butterfly matrices with
\mathcal{O}(\log d)
parameters each.

This achieves three properties simultaneously:

•

Sub-linear memory scaling:

\mathcal{O}(d^{2}+N\cdot d\log d)
versus
\mathcal{O}(N\cdot d^{2})

•

Dynamic outlier suppression:
Learned per-expert input rotations redistribute activation energy across dimensions during training, reducing quantization sensitivity.

•

Joint optimization:
The resulting parameterization naturally induces expert diversity while maintaining a shared quantization-friendly substrate

The result:
150\times
compression at 256 experts compared to standard MoE, enabling deployment scenarios that are not feasible under prior methods given current memory constraints. Unlike quantization only approaches, our compression ratio improves as
N
increases.

Methodology

3.1
Problem Setup

The current setup targets language modelling on edge constrained devices which are memory constrained.
Let
\mathcal{D}=\{(x^{(i)},y^{(i)})\}_{i=1}^{N}
denote a training corpus where

x^{(i)}\in\mathbb{Z}^{L}
is an input sequence of
L
tokens from vocabulary
\mathcal{V}
with
|\mathcal{V}|=V
,
and
y^{(i)}
are target tokens.

A standard Mixture-of-Experts(MoE) layer consists of
N_{E}
independent expert networks.
Let
g:\mathbb{R}^{d_{\text{model}}}\to\Delta^{N_{E}-1}
be a gating network that routes inputs to the top-
k
experts. The MoE output is given by:

y=\sum_{i\in\text{TopK}(g(x))}g_{i}(x)\cdot W_{i}x

where
W_{i}
denotes the parameters of the
i
-th expert.

This leads to a memory problem as, on edge devices with a RAM budget
M_{\text{device}}
, the memory footprint of the Mixture of Experts (MoE) is:

M_{\text{MoE}}=N_{E}\cdot d_{\text{ff}}\cdot d_{\text{model}}\cdot b_{\text{precision}}\text{ bytes}

where
b_{\text{precision}}=4
bytes (FP32) or
2
bytes (FP16).
For
N_{E}=8
experts with
d_{\text{model}}=512
, this yields
M_{\text{MoE}}\approx 32
MB (FP32),
exceeding the available memory on resource-constrained devices like ESP32 (512 KB) or Jetson Nano (4 GB with OS overhead).
The core objective is to find a parameterization that satisfies:

•

Sub-linear memory scaling

•

Expert diversity

•

Accuracy preservation

3.2
Why Standard MoE fails on Edge Devices

Standard MoE assume experts are independently parameterized with each
W_{i}
stored explicitly. This results in linear memory scaling
O(N_{E}\cdot d^{2})
which leads to two critical failures:

•

F1. Memory wall:

An 8-expert MoE with
d=512
occupies 32 MB in FP32. Scaling to 64 experts, is needed for fine-grained specialization across multi-lingual and multi-domain tasks. This requires 256 MB, which exceeds the capacity of most edge devices.

•

F2. Bandwidth bottleneck:

Even when the experts fit in DRAM, inference is dominated by memory bandwidth and energy costs due to repeated loading of
N_{E}
weight matrices from memory. Using a DRAM access energy of 6.4 pJ/bit
[
12
]
, a 256 MB MoE consumes
\sim
13 mJ per forward pass, unsuitable for battery powered devices.

3.3
Core Insight: Experts as Orbits of a Quantized Prototype

Recent studies on linear mode connectivity
[
10
,
1
]
show that neural networks trained on similar data lie on low dimensional manifolds through group transformations such as permutations of neurons, feature space rotations or rescalings.

This technique is used as instead of storing
N_{E}
independent matrices
\{W_{i}\}
, they are represented as orbital variations of a single quantized prototype
W_{\text{base}}
under learnable orthogonal transformations. This is given in the mathematical formulation:

Mathematical Formulation

Define each expert as:

W_{i}=\mathcal{R}_{i}^{\text{out}}\cdot W_{\text{base}}\cdot(\mathcal{R}_{i}^{\text{in}})^{T}

(1)

where:

•

W_{\text{base}}\in\{-1,0,+1\}^{d_{\text{ff}}\times d_{\text{model}}}
is a ternary-quantized substrate (1.58 bits/weight).

•

\mathcal{R}_{i}^{\text{in}},\mathcal{R}_{i}^{\text{out}}\in O(d)
are expert-specific orthogonal rotations.

This works because of the following reasons:

•

Shared capacity:

W_{\text{base}}
captures universal features such as syntax, basic semantics

•

Orbital diversity:
The rotations
\mathcal{R}_{i}
create different views of the shared parameter substrate,allowing each expert
i
to specialize by aligning
W_{\text{base}}
with domain-specific feature subspaces.

•

Quantization resilience:
Learned input rotations
\mathcal{R}_{i}^{\text{in}}
suppress activation outliers.

Storing
W_{\text{base}}
requires
O(d^{2})
bits (quantized), while rotations need only
O(\log d)
parameters when structured effectively using Butterfly matrices.

ButterflyMoE has three stages:

Stage 1: Prototype Quantization

Training

and quantizing to ternary values

\theta_{i}

\mathcal{B}(\theta_{i})

y_{i}=\mathcal{B}(\phi_{i})\left(Q(W_{\text{base}})\left(\mathcal{B}(\theta_{i})^{T}x\right)\right)

Stage 3: Gated Routing

A top-

Architectural Components.

ButterflyMoE does not introduce any new training new objectives or routing mechanisms beyond standard MoE. The main novelty lies in expert parameterization:

•

Butterfly-structured rotations:
O(d\log d)
parameterization of orthogonal transformations via hierarchical Givens rotations, enabling efficient on-the-fly expert synthesis.

•

Ternary quantization with learned alignment: Expert specific input rotations combined with 1.58 substrate dynamically suppress activation outliers.

•

Joint end-to-end training : Optimization of
W_{\text{base}}
, rotation parameters
\{\theta_{i},\phi_{i}\}
, and gating network simultaneously by standard cross-entropy loss with load balancing.

The key insight is that, instead of treating experts as independent vectors, we treat them as geometric rotations of a shared substrate, through this parameter sharing is achieved without sacrificing representational diversity. The substrate stores what to compute while the rotations determine how to orient.

3.5 Parameterization via Butterfly Matrices

Orthogonal transformations
\mathcal{R}\in O(d)
require
O(d^{2})
parameters and therefore offer no savings in memory footprint.
This can be solved using butterfly matrices
[
7
]
where rotations are parameterized with only
O(d\log d)
scalars through a recursive block diagonal decomposition
This is defined below:

A Butterfly matrix
\mathcal{B}(\theta)\in\mathbb{R}^{d\times d}
with
d=2^{m}
is:

\mathcal{B}(\theta)=\prod_{\ell=1}^{m}\mathcal{D}_{\ell}(\theta)\mathcal{P}_{\ell}

(3)

where:

•

\mathcal{D}_{\ell}(\theta)
is block-diagonal with
2^{\ell}\times 2^{\ell}
blocks, each applying a 2D Givens rotation:

\begin{bmatrix}\cos\alpha&-\sin\alpha\\
\sin\alpha&\cos\alpha\end{bmatrix}

(4)

•

\mathcal{P}_{\ell}
is a fixed permutation (perfect shuffle).

•

\theta=\{\alpha_{\ell,j}\}_{\ell=1,\ldots,m;j=1,\ldots,d/2}
are learnable angles.

Complexity

•

Storage:

O(d\log d)
parameters so for
d=512
,
512\log_{2}512=4608
angles.

•

Computation:

O(d\log d)
FLOPs per forward pass.

•

Expressivity:
Monarch matrices
[
6
]
shows that
O(\log d)
butterfly layers approximate a broad class of orthogonal transformations, with vanishing error as depth increases.

For a more practical implementation
\log_{2}d
layers are used, each parameterized by
d/2
Givens rotations
\alpha\in[-\pi,\pi]
optimized by standard gradient based methods.

3.6 Quantized Substrate and Outlier Suppression

3.6.1 Ternary Quantization

W_{\text{base}}
is quantized to
\{-1,0,+1\}
(1.58 bits per weight) via AbsMean scaling
[
16
]
:

Q(W)=\gamma\cdot\text{round}\left(\frac{W}{\gamma}\right),\quad\gamma=\frac{1}{d_{\text{ff}}\cdot d_{\text{model}}}\sum_{ij}|W_{ij}|

(5)

where
\text{round}(\cdot)
clips to
\{-1,0,+1\}
.

Straight-Through Estimator (STE)

During backpropagation,
\frac{\partial Q(W)}{\partial W}=I
is approximated, enabling gradient propagation despite the non-differentiability of the rounding operation
[
3
]
.

3.6.2 Rotations for Outlier Suppression?

Activation distributions in transformer architectures exhibit extreme outliers. These are values that are 10 to 100
\times
larger than the median

[
17
]
.

Approaches like clipping remove high magnitude values which destroys information.Another approach for outlier suppresion is per channel scaling. Per channel scaling acts independently on each dimension and hence cannot distribute energy across dimensions
[
2
]
.

Rotations would be ideal in this scenario as quantization error is basis dependent. Orthogonal transformations preserve representational capacity while rotating activations into quantization friendly bases.

Mechanism in ButterflyMoE

Each expert’s input rotation
\mathcal{B}(\theta_{i})
is trained jointly with
W_{\text{base}}
to minimize quantization error for tokens routed to expert
i
. During training, gradients
\frac{\partial\mathcal{L}}{\partial\theta_{i}}
learn to:

•

Distribute high magnitude activations across dimensions.

•

Align frequent activation patterns with low-error regions of the ternary grid.

This approach suppresses outliers dynamically without requiring clipping.

3.7 Training Objective and Orbital Initialization

3.7.1 Loss Function

The total loss combines cross-entropy and load balancing loss. Given below:

\mathcal{L}=\mathcal{L}_{\text{CE}}(y,\hat{y})+\lambda_{\text{balance}}\sum_{i=1}^{N_{E}}\left(\frac{n_{i}}{N_{\text{total}}}-\frac{1}{N_{E}}\right)^{2}

(6)

where
n_{i}
is the number of tokens routed to expert
i
, and
\lambda_{\text{balance}}=0.01
(standard in Switch Transformers
[
8
]
).

3.7.2 Preventing Expert Collapse

One of the key challenges were if all of the experts were initialized identically, the orbital rotations would converge to similar solutions, resulting in loss of expert diversity
[
5
]
.

This can be fixed as butterfly angles are initialized independently and randomly for each expert.
Given below:

\theta_{i},\phi_{i}\sim\mathcal{N}(0,0.01^{2})\quad\text{for each }i

(7)

This introduces different viewing angles of
W_{\text{base}}
which breaks symmetry and promotes expert specialization.

3.9 Theoretical Properties

Three theoretical properties define the memory, quantization, and computational behavior of ButterflyMoE. First, the exact memory scaling of the proposed orbital parameterization is derived. Then, an asymptotic compression ratio is established relative to standard MoE. Lastly, we describe the inference-time computational complexity under top-
k
routing.

Proposition 1

(Memory Scaling)
.

For
N_{E}
experts with dimensions
d_{\text{model}},d_{\text{ff}}
, ButterflyMoE memory is:

M=\frac{1.58}{8}d_{\text{ff}}d_{\text{model}}+N_{E}\cdot\left(\frac{d_{\text{model}}}{2}\log_{2}d_{\text{model}}+\frac{d_{\text{ff}}}{2}\log_{2}d_{\text{ff}}\right)\cdot 2

(8)

Justification:

The shared memory substrate contains
d_{\text{ff}}\times d_{\text{model}}
ternary weights which are stored at 1.58 bits per weight, yielding

\frac{1.58}{8}d_{\text{ff}}d_{\text{model}}
bytes.
Each expert uses by two Butterfly transformations: an input transformation with

\frac{d_{\text{model}}}{2}\log_{2}d_{\text{model}}
rotation angles and an output transformation with

\frac{d_{\text{ff}}}{2}\log_{2}d_{\text{ff}}
angles.
All angles are stored in FP16 (2 bytes), giving a total expert memory of

2\left(\frac{d_{\text{model}}}{2}\log_{2}d_{\text{model}}+\frac{d_{\text{ff}}}{2}\log_{2}d_{\text{ff}}\right)
bytes.
Multiplying by
N_{E}
gives the stated result.

5
Conclusion

ButterflyMoE achieves sub-linear memory scaling in MoE architectures through parameterization of experts as orbital transformations of a shared ternary substrate. This achieves a 150
\times

compression at 256 experts while maintaing accuracy. Learned per expert rotations enable quantization which suppress activation outliers, a problem that static rotation methods could not solve

ButterflyMoE enables deployment scenarios which were previously infeasible.
64-expert models fit in 1.9 MB, supporting 10,540 experts on a 4GB Jetson
Nano vs 819 for standard MoE. For edge devices with a memory budget,
sub-linear scaling is not an optimization but a requirement.

Inference is slower than dense baselines(upto 48.9
\times
on T4 GPUs without kernel support).
Ablations show 2 layer variations recover 2.5
\times
speedup. Another key limitaion is our experiments focused on small scale models due to hardware constraints. Scaling to billion parameter regimes and interpreting rotations remain open questions.

Instead of treating experts as independent parameter sets, ButterflyMoE imposes a geometric structure that avoids the linear memory barrier of sparse architectures. This positions group-orbit representations as a mechanism for extreme compression without expert collapse.
