Aura-CAPTCHA: A Reinforcement Learning and GAN-Enhanced Multi-Modal CAPTCHA System
Joydeep Chandra 1, Prabal Manhas 2, Ramanjot Kaur 3, Rashi Sahay 4

Abstract
Aura-CAPTCHA was developed as a multi-modal CAPTCHA system to address vulnerabilities in traditional methods that are increasingly bypassed by AI technologies, such as Optical Character Recognition (OCR) and adversarial image processing [ 6 ] , [ 9 ] , [ 13 ] . The design integrated Generative Adversarial Networks (GANs) for generating dynamic image challenges, Reinforcement Learning (RL) for adaptive difficulty tuning, and Large Language Models (LLMs) for creating text and audio prompts [ 12 ] , [ 15 ] , [ 19 ] . Visual challenges included 3x3 grid selections with at least three correct images, while audio challenges combined randomized numbers and words into a single task. RL adjusted difficulty based on incorrect attempts, response time, and suspicious user behavior [ 18 ] . Evaluations on real-world traffic demonstrated a 92% human success rate and a 10% bot bypass rate, significantly outperforming existing CAPTCHA systems [ 21 ] . The system provided a robust and scalable approach for securing online applications while remaining accessible to users, addressing gaps highlighted in previous research [ 11 ] , [ 13 ] , [ 17 ] .

Evaluation Metrics

To comprehensively evaluate the performance of Aura-CAPTCHA, we used the following metrics:

Bypass Rate:
The percentage of CAPTCHA challenges solved by automated bots.

•

The percentage of human users who successfully completed the CAPTCHA.

False Positive Rate (FPR):
The percentage of legitimate human users incorrectly flagged as bots.

4.2
Mathematical Model of Aura-CAPTCHA

The core of Aura-CAPTCHA is built upon a Reinforcement Learning (RL) model that dynamically adjusts the difficulty level of the CAPTCHA challenge based on user interaction data. The Q-learning approach is defined as:

Q(s,a)\leftarrow Q(s,a)+\alpha\left[r+\gamma\max_{a^{\prime}}Q(s^{\prime},a^{\prime})-Q(s,a)\right]

(1)

where:

•

Q(s,a)
: The Q-value representing the expected reward for taking action
a
in state
s
.

•

\alpha
: Learning rate, controlling how quickly the model updates the Q-values.

•

r
: Immediate reward, based on user behavior (e.g., correct response, time taken).

•

\gamma
: Discount factor, indicating the importance of future rewards.

•

\max_{a^{\prime}}Q(s^{\prime},a^{\prime})
: The maximum predicted Q-value for the next state
s^{\prime}
.

The immediate reward
r
is defined as:

r=\begin{cases}+1,&\text{if user response is correct and within time limit}\\
-1,&\text{if user response is incorrect or time exceeds limit}\\
0,&\text{if user interaction is ambiguous}\end{cases}

4.3
User Interaction Analysis

The User Interaction Analysis Module uses a hybrid approach combining heuristics and an SVM classifier. The feature vector
x
extracted from user interactions is defined as:

x=[\text{avg\_time\_interval},\text{std\_time\_interval},\text{total\_movement},\text{num\_clicks}]

The SVM decision function is given by:

f(x)=w\cdot x+b

(2)

where:

•

w
: Weight vector.

•

b
: Bias term.

•

x
: Feature vector.

A positive
f(x)
value indicates human interaction, while a negative value suggests bot-like behavior.

6
Conclusion

In this work, we presented Aura-CAPTCHA, an advanced, adaptive CAPTCHA system designed to address the growing challenge of distinguishing between human users and automated bots. By integrating Generative Adversarial Networks (GANs) for dynamic content creation and Reinforcement Learning (RL) for real-time difficulty adjustment, Aura-CAPTCHA offers a novel, multi-modal approach that effectively leverages both visual and auditory stimuli. Our extensive evaluation demonstrated that Aura-CAPTCHA significantly outperforms traditional CAPTCHA methods, achieving a low bypass rate of 5.2% while maintaining a high human success rate of 92.8%.

The core innovation of Aura-CAPTCHA lies in its ability to dynamically generate unique, synchronized audio-visual challenges that are difficult for bots to interpret yet intuitive for human users. The inclusion of an RL-based adaptive module further enhances the user experience by tailoring challenge complexity based on real-time user behavior, reducing response times and minimizing user frustration. Additionally, the hybrid user interaction analysis, combining heuristic rules with a machine learning classifier, demonstrated superior accuracy in detecting bot-like interactions, achieving a high F1 score of 96.2%.

Overall, Aura-CAPTCHA addresses several key limitations of existing CAPTCHA systems, including static content generation, lack of adaptability, and poor user experience. Our findings indicate that Aura-CAPTCHA offers a robust, user-friendly, and scalable solution for human verification, making it a promising candidate for deployment in high-security online environments.
