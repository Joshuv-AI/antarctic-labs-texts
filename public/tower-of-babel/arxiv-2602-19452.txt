Abstract
The recent hardware trend towards reduced precision computing has reignited the interest in numerical techniques that can be used to enhance the accuracy of floating point operations beyond what is natively supported for basic arithmetic operations on the hardware. In this work, we study the behavior of various compensated summation techniques, which can be used to enhance the accuracy for the summation operation, particularly in situations when the addends are not known a priori . Complete descriptions of the error behavior are provided for these techniques. In particular, the relationship between the intermediate results at two consecutive summing steps is provided, which is used to identify the operation that limits accuracy and guide the design of more nuanced techniques. The analysis relies on the work of Dekker [ 5 ] , which uses a special floating point number system that does not require uniqueness in the number representation. Despite this seemingly strange attribute, Dekker’s system is very convenient for the analysis here and allows general statements to be expressed succinctly compared to a number system that requires uniqueness. To prepare the foundation for discussion, we start by giving a thorough exhibition of Dekker’s number system and supply the details that were omitted in [ 5 ] . Numerical examples are designed to explain the inner workings of these compensated summation techniques, illustrate their efficacy, and empirically verify the analytical results derived. Discussions are also given on application scenarios where these techniques can be beneficial.

In recent years, because of the drastically increasing demand from artificial intelligence (AI) and machine learning (ML) applications, the computing
industry has gravitated towards data formats narrower than the IEEE double precision format that most computational scientists and engineers are accustomed to.
As a result, there has been a renewed interest in techniques that can enhance the accuracy of numerical operations. Iterative refinement

In this work, we focus on the compensated summation algorithms, which can be viewed as techniques that enhance the accuracy of the summation operation, but can also be applied more flexibly in situations such as ODE or PDE simulations.
These techniques date back to at least the 60s
[
17

21
]

The building blocks for the compensated summation algorithms are error free transformations (EFTs) over addition.
EFTs have often been attributed to Dekker’s work
[

Although Dekker did not coin the term EFT in

Two EFTs over addition were given in

The 3op version requires certain ordering on the two addends to work,

Dekker’s work
[

]
employs a unique floating point number system that does not require uniqueness in the number representation, which turns out to be very convenient for the analysis and allows more insights.
Moreover, the results derived from Dekker’s system can be transferred to the more familiar IEEE system with minimal effort since both systems address the same set of numbers.

Despite being instrumental, Dekker’s work

For this reason, we revisit Dekker’s system in Section

The comparison between Dekker’s system and the more familiar IEEE system is also given, along with their links.
Detailed proofs for the 3op and 6op EFTs over addition stated in Dekker’s system are then given in Section

These details are becoming increasingly important as adaptations or new designs of algorithms are being called upon to accommodate emerging hardware that may feature non-traditional data formats,

The next portion of this work applies the derived EFT results to the analysis of compensated summation algorithms. The classical error analysis from
[

and
[

is rather cumbersome and error-prone, which also tracks only the leading order term and addresses only the 3op-compensated recursive summation.
Its extension to the 6op-compensated recursive summation is extremely difficult.
Instead, we provide a cleaner analysis that makes use of the EFT property and give a complete description of the error behavior of the 6op-compensated recursive summation algorithm in Section

One particularly appealing aspect of our analysis is the derivation of the relation between the intermediate results at two neighboring steps, which reveals the pattern of error propagation and identifies the operation that limits the accuracy of the overall algorithm.

These more nuanced versions are also analyzed using the techniques developed here.
Full descriptions of their error behaviors are provided, including the error propagation patterns.
Aside from the improved accuracy, the small error bounds equipped with these advanced versions of compensated summation algorithms can also be leveraged in computer system validation tasks as explained in Section

Numerical examples are provided in the final portion of this work.
A pedagogical example is designed to help the readers understand the inner workings of these compensated summation algorithms as well as how their behaviors differ in certain situations.
A second example compares the accuracy of the various recursive summation algorithms, illustrating the benefit of compensation and verifying empirically that the advanced versions can achieve an accuracy as if a data format with twice the amount of mantissa bits has been used in the regular recursive summation.
A third example is given in the context of dynamical system simulation using a classical three-body configuration that admits a figure-eight shaped periodic orbit.

2  Floating point number system

In Dekker’s work
[
5
]
, the author presented a few techniques for error free transformation and multi-word arithmetic.
Dekker used a somewhat special floating point number system that does not require uniqueness in the number representation, which turns out to be quite convenient in proving results and making statements more general.
In the following, we first take a close look at Dekker’s system, which we rely on heavily in this work.

2.1 Numbers and representations

Elements of Dekker’s floating point number system have the following form:

x=m(x)\times\beta^{e(x)},

(1)

where
m(x)\in\mathbb{Z}
denotes the mantissa of
x

and
e(x)\in\mathbb{Z}
denotes the exponent of
x
, with
\mathbb{Z}
being the set of integers.
Dekker’s floating point number system is defined as

\left\{x\,|\,x=m(x)\times\beta^{e(x)},\,|m(x)|<M,\,E_{\min}\leq e(x)\leq E_{\max}\right\},

(2)

where
\beta
,
M
,
E_{\min}
, and
E_{\max}
are integers with
\beta>1
and
M>0
.
Denoting the number of mantissa digits as
t
, we assume
M=\beta^{t}
below, which is natural.

Our primary interest is in the binary floating point number system, i.e.,
\beta=2
.
However, we will keep the discussion general with respect to the base
\beta
and make it explicit when we specialize to the case
\beta=2
.
Even when we specialize to the case
\beta=2
, we may still use
\beta
to denote the base because it is immediately apparent that we are referring to the base of the system, whereas the number
2
may come from other contexts.

Before proceeding, we comment on the subtle distinction between a
number
and a
representation
of a number here.
A number is a unique entity in the number system, which can have multiple representations, e.g.,
\nicefrac{{1}}{{2}}
,
0.5
, and
5\times 10^{-1}
can all be used to represent the same number in the real number system.
Numbers can be compared to one another. We may also compare two representations, which really means comparing the underlying numbers that they represent. Specifically, all representations of the same number compare equal to one another.

In Dekker’s system, a floating point number is allowed to have multiple representations.
To familiarize ourselves with Dekker’s system, we may group the representations in it into different
bins
based on their exponent. For example, with
\beta=2
, the bin associated with an arbitrary exponent
E
, where
E_{\min}\leq E\leq E_{\max}
, is illustrated in (
3
).
To simplify the discussion, we include only the positive numbers in (
3
) and similar illustrations because Dekker’s system is symmetric.
Mantissas of these representations vary from
t
digits of
0
’s to
t
digits of
1
’s, which correspond to the smallest number
0
and the largest number
(\beta^{t}-1)\times\beta^{E}
representable in this bin, respectively.

\underbrace{0\cdots 0}_{\text{$t$ digits}}\times\,\beta^{E}\longleftrightarrow\underbrace{1\cdots 1}_{\text{$t$ digits}}\times\,\beta^{E}

(3)

If
t>1
, representations in this bin can be divided into two groups as illustrated in (
4
).
The group of representations in
(
4a
) has the leading digit in mantissa taking value
1
whereas
the group in
(
4b
) has the leading digit in mantissa taking value
0
.
Representations with a non-zero leading digit in mantissa, e.g., those in
(
4a
), are referred to as
normal
whereas
representations with a zero leading digit in mantissa, e.g., those in
(
4b
), are referred to as
subnormal
.
With
\beta=2
, there are equal amount of normal and subnormal representations in each bin.

\displaystyle 1\underbrace{0\cdots 0}_{\text{$t-1$}}\times\,\beta^{E}\longleftrightarrow 1\underbrace{1\cdots 1}_{\text{$t-1$}}\times\,\beta^{E}

(4a)

\displaystyle 0\underbrace{0\cdots 0}_{\text{$t-1$}}\times\,\beta^{E}\longleftrightarrow 0\underbrace{1\cdots 1}_{\text{$t-1$}}\times\,\beta^{E}

(4b)

Assuming
E-1\geq E_{\min}
, representations in
(

) admit equivalent representations as illustrated in (

), where all representations have one
trailing
zero with the first
t-1
digits of their mantissas vary from all
0

1

E-1
.

\underbrace{0\cdots 0}_{\text{$t-1$}}0\times\beta^{E-1}\longleftrightarrow\underbrace{1\cdots 1}_{\text{$t-1$}}0\times\beta^{E-1}

(5)

On the other hand, representations in
(
4a
) do not admit equivalent representations with exponent
E-1
in Dekker’s system because of the constraint
|m(x)|<M=\beta^{t}
from (
2
).

Imagine a process in which we list all representations in the system from bin
E_{\min}
to bin
E_{\max}
.
Based on the observation above, we have that with the exception of the first bin in this process where
E=E_{\min}
,
for each new bin introduced subsequently, the normal representations are new numbers added to the system whereas the subnormal representations have already appeared in previously introduced bins.

Notice also that the group of representations from (
4b
) can be further divided into two subgroups based on if the second leading digit is also zero.
The subgroup with two
leading
zeros also admits equivalent representations in bin
E-2
, assuming
E-2\geq E_{\min}
, each with two
trailing
zeros.
The overlapping pattern between different bins should be clear now and can be stated generally as follows:
Given
k\in\mathbb{Z}
, if
1\leq k\leq t
and
E-k\geq E_{\min}
, those representations in (
3
) with
k
leading zeros admit equivalent representations with exponent
E-k
. The fraction of these representations in the entire
\beta^{t}
representations of (
3
) is
\tfrac{1}{\beta^{k}}
.
In the case
k=t
, there is only one overlapping number, zero, between the two bins with exponents
E
and
E-k
.
When
k>t
, there is no overlapping number between the two bins.

Based on the observation above,
we have the following lemma on the uniqueness of normal representation.

Lemma 2.1

(Normal representation is unique)
.

A number from Dekker’s system can admit at most one normal representation.

Proof.

Suppose
m(a)\times\beta^{e(a)}
and
m(b)\times\beta^{e(b)}
are two distinct normal representations.
If
e(a)=e(b)
but
m(a)\neq m(b)
, it is obvious that these two representations cannot represent the same number.

If
e(a)\neq e(b)
, without loss of generality, assume
m(a)>0
,
m(b)>0
, and
e(a)<e(b)
.
On one hand, we have

m(a)\times\beta^{e(a)}<\beta^{t}\times\beta^{e(a)}

following
m(a)<M
.
On the other hand, we have

m(b)\times\beta^{e(b)}\geq\beta^{t-1}\times\beta^{e(b)}\geq\beta^{t}\times\beta^{e(a)}

following the normal assumption.
Combining the two inequalities, we have
m(b)\times\beta^{e(b)}>m(a)\times\beta^{e(a)}
and, thus, the two representations cannot possibly represent the same number.

End of proof for Lemma
2.1
.

Not all numbers in Dekker’s system admit normal representations.
The most notable example is zero, which necessarily has all zero digits in the mantissa.
In fact, all numbers in the following set do not admit normal representations

\left\{x\,|\,x=m(x)\times\beta^{E_{\min}},\,|m(x)|<\beta^{t-1}\right\}.

(6)

Definition 2.2

(Subnormal number)
.

A nonzero number is referred to as subnormal if it does not admit a normal representation in Dekker’s system.

It is worth mentioning that in Dekker’s system, subnormal numbers may still admit multiple
representations. For example, with a three-digit mantissa system, both
010\times\beta^{E_{\min}}
and
001\times\beta^{E_{\min}+1}
represent the same subnormal number.

Remark 1

(Subnormal numbers)
.

Historically, with certain hardware and compilers, the default behavior regarding subnormal numbers is
treat as zero
on input and
flush to zero
on output, forfeiting the gradual underflow design from the IEEE standard.
Operations involving subnormal numbers often incur heavy performance penalty as they are handled via microcode offloading. However, for reduced precision data formats, it is important to give subnormal numbers the proper treatment in hardware since they occupy a large portion of the number system and often cover an even larger portion of the representable range.
Interested readers may find more discussions on the merit of subnormal numbers in
[
23
, Appendix A]
and
[
6
]
.

End of Remark

, one may impose uniqueness on the number system by keeping only the normal representations, i.e., by requiring
|m(x)|\geq\beta^{t-1}
.
This strategy, however, would leave an undesirable gap between zero and the smallest positive normal number

(

Our main interest in exploring Dekker’s system is to understand the behavior of floating point numbers in numerical procedures, rather than their realization on hardware.
For our purpose, the analytical results obtained in Dekker’s system are transferrable to the IEEE system.
To give credence to this claim,
we first establish the fact that Dekker’s system and the proto-IEEE system contain the same numbers, which is provided in the following lemma using induction.

The two number sets from Dekker’s system (

Proof.

Imagine a process of adding numbers to these two sets bin by bin.
For the first bin

the proto-IEEE system has the following numbers

(9)

Clearly the two sets (

Assuming the two systems contain the same numbers up to bin

2.2 Arithmetic and rounding

In addition to the numbers and representations, a floating point number system
\mathbb{F}
is usually equipped with a set of arithmetic operations.
Definitions of these arithmetic operations can be derived from their counterparts in the real number system
\mathbb{R}
.
However,
\mathbb{F}
is usually not closed with respect to the arithmetic operations defined in
\mathbb{R}
.
For this reason, some mechanism is needed to close the floating point number system with respect to
arithmetic operations.
For floating point number systems, this can be
mostly
achieved by the operation of rounding with the possible exception of overflow.

Rounding maps
x\in\mathbb{R}
to
fl(x)\in\mathbb{F}
where
fl(x)
is close to
x
.
In Dekker’s system, when
x
overflows, i.e., falls outside the range of
\mathbb{F}
, rounding maps it to the nearest element in
\mathbb{F}
, i.e., one of
\pm(M-1)\times\beta^{E_{\max}}
depending on the sign of
x
.
This is sufficient to close the system for valid arithmetic operations defined in
\mathbb{R}
.
One may refer to the handling of overflow in Dekker’s system as
clipping
or
clamping
, which as a concept appears often in computer engineering practice. In contrast, the IEEE system handles overflow with
\pm\texttt{Inf}
.

The floating point arithmetic operations defined over a floating point number system
\mathbb{F}
are simply their counterparts in the real system
\mathbb{R}
followed by the rounding operation.
Two common notions pertaining to rounding are given below.

Definition 2.4

(Faithful)
.

For
x\in\mathbb{R}
, rounding is faithful if
fl(x)\in\mathbb{F}
is either the largest element of
\mathbb{F}
no larger than
x
or the smallest element of
\mathbb{F}
no smaller than
x
. As a consequence, if
x\in\mathbb{F}
, then
fl(x)=x
under faithfulness.

Definition 2.5

(Optimal)
.

For
x\in\mathbb{R}
, rounding is optimal if
fl(x)\in\mathbb{F}
is the nearest element to
x
.
Optimal rounding may also be referred to as nearest rounding.

When
x
lies at the exact middle of two consecutive members of
\mathbb{F}
, a tie-breaking criterion is needed. Possible tie-breaking criterions include rounding to even (or odd) last mantissa digit and rounding away from (or towards) zero.

Remark 4

(Tie-breaking)
.

Nearest rounding with the tie-breaking criterion of rounding to even last mantissa digit is the default rounding mode for binary formats in the IEEE standard
[
16
, Section 4.3]
and is prevalently supported on hardware.
It may not always be possible to round to a number with even last mantissa digit such as in the extreme case when
t=1
. A fallback criterion such as rounding away from zero may be used in such situations as suggested by the IEEE standard.

In Dekker’s system, rounding to even or odd last mantissa digit can be ambiguous because the same number may admit representations with both even and odd last mantissa digit, e.g., both
100\times\beta^{-2}
and
001\times\beta^{0}

from the system illustrated in Figure
3

represent the same number.
To remove this ambiguity, given
x\in\mathbb{R}
, tie-breaking should be performed on a representation of
x
that has
t
whole digits either with a non-zero leading digit or with exponent
E_{\min}
, possibly both.

Using the illustration in Figure
3
, this simply means when
x
can be enclosed in multiple intervals
\left[000,111\right)\times\beta^{E}
, where
E_{\min}\leq E\leq E_{\max}
, tie-breaking, and rounding in general, should be performed on a representation of
x
with the smallest exponent
E
possible.
This procedure will also deliver the rounding outcome consistent with the proto-IEEE system under nearest rounding with the same tie-breaking criterion.

In the following, when referring to tie-breaking with rounding to even or odd in Dekker’s system, the above procedure is implied and, more generally, the consistency of rounding outcome between Dekker’s system and the proto-IEEE system is assumed.
For tie-breaking criterions that bias towards a direction, there is no ambiguity in Dekker’s system and the rounding outcome is consistent between the two systems.

End of Remark

4
.

All commonly encountered rounding modes are at least faithful. In the following, the rounding mode, including the tie-breaking criterion if needed, is assumed to be fixed throughout the procedure under discussion and deterministic so that the rounding outcome is unique and depends on the input only.
To facilitate the discussion below, we assume that the following rule holds for floating point arithmetic operations.

Rule 2.6

(The
as if
rule)
.

The floating point arithmetic operation under consideration are performed as if an intermediate result correct to infinite precision and with unbounded range has been produced first, and then rounded to fit the destination format.

Rule
2.6
simplifies the discussion because it decouples rounding from the arithmetic operations and, thus, enables statements regarding rounding behavior to be made without specializing to a particular arithmetic operation.
This rule is stipulated in the IEEE-754 standard
[
16
]
for addition, subtraction, multiplication, division, square root, and fused multiply add (FMA), and is widely supported on modern hardware.

It is easy to see that under Rule
2.6
and with consistent rounding modes, floating point arithmetic operations in Dekker’s system and the proto-IEEE system deliver the same outcome since, first, the calculation of the infinitely precise intermediate result can be understood as being carried out in
\mathbb{R}
, i.e., independent of the floating point representation, and, second, the subsequent rounding outcome depends only on the rounding mode and number distribution in the system, which is the same according to Lemma
2.3
.

2.3 Preparatory results on rounding

Below, we provide a few lemmas on rounding that will be needed in the subsequent discussion.

Lemma 2.7

(Symmetry)
.

Assume
\mathbb{F}
is symmetric, i.e.,
the negative of any element of
\mathbb{F}
is also in
\mathbb{F}
.
Then
\forall x\in\mathbb{R}
, we have
fl(-x)=-fl(x)
under nearest rounding with a tie-breaking criterion that is consistent between the rounding of
-x
and
x
.
Such tie-breaking criteria include rounding to even or odd last mantissa digit or rounding towards or away from zero.

Proof.

For the special case
x=0
, we have
fl(x)=0
since
0\in\mathbb{F}
and the relation
fl(-x)=-fl(x)
clearly holds. When
x\neq 0
, we need only to consider the case
x>0
because both
\mathbb{R}
and
\mathbb{F}
are symmetric.
In this case, we have

|fl(x)-x|\leq|a-x|,\,\forall a\in\mathbb{F}

under nearest rounding, and hence

\left|\big(-fl(x)\big)-(-x)\right|\leq|(-a)-(-x)|,\,\forall(-a)\in\mathbb{F}.

In other words,
-fl(x)
is either
the
closest element in
\mathbb{F}
to
-x
, in which case we have
fl(-x)=-fl(x)
by the definition of nearest rounding, or one of the two closest elements when
-x
lies at the exact middle of two adjacent elements of
\mathbb{F}
.
In the later scenario,
fl(-x)=-fl(x)
follows the consistency in the tie-breaking criterion.

End of proof for Lemma
2.7
.

We note here that Lemma
2.7
does not hold under tie-breaking criteria such as rounding towards
-Inf
or
+Inf
.

Lemma 2.8

(Monotonicity)
.

For
x,y\in\mathbb{R}
, if
|x|\leq|y|
, then
|fl(x)|\leq|fl(y)|
under nearest rounding.

Proof.

We need only to consider the case
0\leq x\leq y
since, according to Lemma
2.7
, rounding is symmetric under nearest rounding.
Moreover, if
x=y
, then
fl(x)=fl(y)
since rounding leads to unique outcome. The result stated in this lemma clearly holds in this case.
Therefore, we can further restrict ourselves to considering only
0\leq x<y
.

By the definition of nearest rounding, we have

\displaystyle|fl(x)-x|

\displaystyle\leq|a-x|,\,\forall a\in\mathbb{F}\mathchar 24635\relax\;

(11a)

\displaystyle|fl(y)-y|

\displaystyle\leq|b-y|,\,\forall b\in\mathbb{F},

(11b)

and, consequently,

|fl(x)-x|+|fl(y)-y|\leq|a-x|+|b-y|,\,\forall a,b\in\mathbb{F}.

(12)

We proceed by contradiction in the separate cases below.

Case 1:
if
fl(x)>fl(y)\geq x
, this
contradicts with (
11a
)
as
fl(y)
is strictly closer to
x
than
fl(x)
.

Case 2(a):
if
fl(x)>fl(y)
,
fl(y)<x
, and
fl(x)\leq y
, this
contradicts with (
11b
)
as
fl(x)
is strictly closer to
y
than
fl(y)
.

Case 2(b):
if
fl(x)>fl(y)
,
fl(y)<x
, and
fl(x)>y
, we have

\displaystyle\big(y-fl(y)\big)+\big(fl(x)-x\big)

\displaystyle=\big(y-x+x-fl(y)\big)+\big(fl(x)-y+y-x\big)

\displaystyle=2\cdot(y-x)+\big(x-fl(y)\big)+\big(fl(x)-y\big)

\displaystyle>\big(x-fl(y)\big)+\big(fl(x)-y\big)

following
x<y
, which
contradicts with (
12
)
.
The above cases cover all possible positions of
fl(x)
and
fl(y)
in relation to
x
and
y
, which all leads to contradiction if
fl(x)>fl(y)
. Therefore, the result stated in this lemma must hold.

End of proof for Lemma
2.8
.

Lemma 2.9
.

If
\tilde{z}>0\in\mathbb{R}
can be expressed as

\tilde{z}=\zeta\times\beta^{e(z)}
with

\beta^{t-1}\leq\zeta\leq\beta^{t}
and

E_{\min}\leq e(z)<E_{\max}
,
then the number in
\mathbb{F}
closest to
\tilde{z}
is either
\lfloor\zeta\rfloor\times\beta^{e(z)}
or
\lceil\zeta\rceil\times\beta^{e(z)}
,
where, for
\zeta>0\in\mathbb{R}
,
\lfloor\zeta\rfloor
and
\lceil\zeta\rceil
are defined as

\lfloor\zeta\rfloor=\max\{i\,|\,i\in\mathbb{Z},i\leq\zeta\}

and

\lceil\zeta\rceil=\min\{i\,|\,i\in\mathbb{Z},i\geq\zeta\}
, respectively.

Proof.

The conditions
\beta^{t-1}\leq\zeta\leq\beta^{t}
and
E_{\min}\leq e(z)<E_{\max}
ensure that both
\lfloor\zeta\rfloor\times\beta^{e(z)}
and
\lceil\zeta\rceil\times\beta^{e(z)}
are in
\mathbb{F}
.
Consider now an arbitrary
w>0
in
\mathbb{F}
with a representation
w=m(w)\times\beta^{e(w)}
.

If
e(w)<e(z)
, we have
m(w)\times\beta^{e(w)}\leq(\beta^{t}-1)\times\beta^{e(z)-1}<\beta^{t-1}\times\beta^{e(z)}\leq\lfloor\zeta\rfloor\times\beta^{e(z)}\leq\zeta\times\beta^{e(z)}
. Therefore,
\lfloor\zeta\rfloor\times\beta^{e(z)}
is closer to
\tilde{z}
than
w
in this case.

If
e(w)\geq e(z)
, we can write
w=m(w)\cdot\beta^{h}\times\beta^{e(z)}
,
where
h=e(w)-e(z)\geq 0
and, therefore,
m(w)\cdot\beta^{h}\in\mathbb{Z}
.
Since
\lfloor\zeta\rfloor
and
\lceil\zeta\rceil
are consecutive integers, we have either

m(w)\cdot\beta^{h}\leq\lfloor\zeta\rfloor\leq\zeta
or

m(w)\cdot\beta^{h}\geq\lceil\zeta\rceil\geq\zeta
.
Therefore, either
\lfloor\zeta\rfloor\times\beta^{e(z)}
or
\lceil\zeta\rceil\times\beta^{e(z)}
is closest to
\tilde{z}
in this case.

End of proof for Lemma
2.9
.

We note here that in the statement of Lemma
2.9
,
\lfloor\zeta\rfloor\times\beta^{e(z)}
and
\lceil\zeta\rceil\times\beta^{e(z)}
are referred to as
numbers
rather than
representations
.
Specifically,
\lceil\zeta\rceil\times\beta^{e(z)}
is not necessarily a valid representation in
\mathbb{F}
, which happens when
\zeta>\beta^{t}-\tfrac{1}{2}
.
Moreover, Lemma
2.9
can be easily extended to include real numbers
\left\{\tilde{z}\,|\,\tilde{z}=\zeta\times\beta^{E_{\max}},\,\beta^{t-1}\leq\zeta\leq\beta^{t}-1\right\}
in the statement.
We opted for the weaker version for the clarity of its statement, which is sufficient for the subsequent proofs.

Lemma
2.9
covers the case where
\tilde{z}>0
.
The following corollary extends the result to
\tilde{z}<0
.
It can be proved by applying Lemma
2.9
to
-\tilde{z}
and using the argument that
\mathbb{R}
is symmetric with respect to zero.

Corollary 2.10
.

If
\tilde{z}<0\in\mathbb{R}
can be expressed as

\tilde{z}=\zeta\times\beta^{e(z)}
with

-\beta^{t-1}\geq\zeta\geq-\beta^{t}
and

E_{\min}\leq e(z)<E_{\max}
,
then the number in
\mathbb{F}
closest to
\tilde{z}
is either
-\lfloor-\zeta\rfloor\times\beta^{e(z)}
or
-\lceil-\zeta\rceil\times\beta^{e(z)}
.

For convenience, we introduce the notation
\mathbb{D}
to refer to Dekker’s system for the subsequent discussion to distinguish it from a generic floating point number system denoted by
\mathbb{F}
.
The following lemma allows us to reduce the reasoning of floating point rounding to integer rounding, which is considerably simpler.
It is relied upon heavily in the subsequent proofs.

Lemma 2.11
.

Under nearest rounding, given
\tilde{z}\in\mathbb{R}
and

|\tilde{z}|\leq(M-1)\times\beta^{E_{\max}}
,
i.e.,
\tilde{z}
does not overflow in Dekker’s system
\mathbb{D}
, if
z=fl(\tilde{z})
admits a representation
z=m(z)\times\beta^{e(z)}
, then expressing
\tilde{z}
as
\tilde{z}=\zeta\times\beta^{e(z)}
, we have

m(z)=round(\zeta),

(13)

where
round(\zeta)\in\mathbb{Z}
gives the nearest integer to
\zeta
with a tie-breaking criterion, if needed, consistent with that used for
fl(\tilde{z})
.

Proof.

It suffices to consider only the case
\tilde{z}>0
because both
\mathbb{R}
and
\mathbb{D}
are symmetric and the case
\tilde{z}=0
is trivial.

We start by showing that
round(\zeta)\times\beta^{e(z)}\in\mathbb{D}
.
Since
z=m(z)\times\beta^{e(z)}
is a valid representation in
\mathbb{D}
, we have
e(z)\in\left[E_{\min},E_{\max}\right]
.
Thus, we only need to show that
round(\zeta)\leq M-1
.
First, we consider the special case where
e(z)=E_{\max}
: the condition
|\tilde{z}|\leq(M-1)\times\beta^{E_{\max}}
implies that
\zeta\leq M-1
and, therefore, we have
round(\zeta)\leq M-1
as desired.
When
e(z)<E_{\max}
, we separate the discussion into three cases depending on the size of
\zeta
.

Case 1: if
\zeta<M-\nicefrac{{1}}{{2}}
, then we have the desired result
round(\zeta)\leq M-1
.

Case 2: if
\zeta>M-\nicefrac{{1}}{{2}}
, then we have

\zeta-m(z)\geq\zeta-(M-1)>|\zeta-M|.

In other words,
M\times\beta^{e(z)}=\tfrac{M}{\beta}\times\beta^{e(z)+1}\in\mathbb{D}

is closer to
\tilde{z}
than any valid representation in
\mathbb{D}
with exponent
e(z)
.
This contradicts the condition that
z
admits a representation in
\mathbb{D}
with exponent
e(z)
since
M\times\beta^{e(z)}
is not a valid representation itself.
Therefore, this is a null case.

Case 3: if
\zeta=M-\nicefrac{{1}}{{2}}
, then
M-1
and
M
are the two closest integers to
\zeta
with equal distance.
Moreover, from Lemma
2.9
,
we know that
(M-1)\times\beta^{e(z)}
and
\tfrac{M}{\beta}\times\beta^{e(z)+1}

are the two floating point numbers in
\mathbb{D}
closest to
\tilde{z}
with equal distance.
Furthermore, the condition that
z
admits a representation with exponent
e(z)
implies that the tie-breaking criterion rounds
\tilde{z}
to
(M-1)\times\beta^{e(z)}
instead of
\tfrac{M}{\beta}\times\beta^{e(z)+1}
. Since the tie-breaking criterion is assumed to be consistent when rounding
\tilde{z}
and
\zeta
,
we have
round(\zeta)=M-1
as desired.
We now have established that
round(\zeta)\times\beta^{e(z)}\in\mathbb{D}
.
Next, we proceed to show that
\tilde{z}
indeed rounds to
round(\zeta)\times\beta^{e(z)}
by contradiction.

Assuming

m(z)\neq round(\zeta)
, we have
|m(z)-round(\zeta)|\geq 1
since they are different integers.
This leads to

|m(z)-\zeta|\geq|m(z)-round(\zeta)|-|\zeta-round(\zeta)|\geq 1-\tfrac{1}{2}=\tfrac{1}{2},

(14)

where we have used
|\zeta-round(\zeta)|\leq\tfrac{1}{2}
.

If either

|m(z)-\zeta|>\tfrac{1}{2}
or

|round(\zeta)-\zeta|<\tfrac{1}{2}
holds, we have

|m(z)-\zeta|>|round(\zeta)-\zeta|
.
In other words,
round(\zeta)\times\beta^{e(z)}
would be closer to
\tilde{z}
than
m(z)\times\beta^{e(z)}
, which contradicts the condition that
m(z)\times\beta^{e(z)}
is a representation of
fl(\tilde{z})
.
The only remaining case is
|m(z)-\zeta|=\tfrac{1}{2}=|round(\zeta)-\zeta|
, which would contradict the condition that the tie-breaking criterion is consistent when rounding
\tilde{z}
and
\zeta
since
\tilde{z}
rounds to
m(z)\times\beta^{e(z)}
instead of
round(\zeta)\times\beta^{e(z)}
.
Hence, the
assumption

m(z)\neq round(\zeta)
must be incorrect and (
13
) must hold.

End of proof for Lemma
2.11
.

2.4 Preparatory results on addition

Below, we give a few results on the addition operation that are useful for the subsequent discussion.
The following lemma, although intuitive, is still worth a rigorous statement.

Lemma 2.12
.

Given
x,y\in\mathbb{D}
with
e(x)\geq e(y)
and
z
obtained via
z=fl(x+y)
, then
z
admits a representation in
\mathbb{D}
with
e(z)\leq e(x)+1
.

Proof.

Since
x,y\in\mathbb{D}
and
e(x)\geq e(y)
, we have

|x+y|\leq|x|+|y|\leq 2\cdot\left(M-1\right)\times\beta^{e(x)}\leq\left(M-1\right)\times\beta^{e(x)+1}.

Using Lemma
2.8
(Monotonicity) and recognizing that
\left(M-1\right)\times\beta^{e(x)+1}\in\mathbb{D}
if
e(x)<E_{\max}
, we arrive at

|z|=|fl(x+y)|\leq\left(M-1\right)\times\beta^{e(x)+1}

in this case and, hence,
z
admits a representation in
\mathbb{D}
with
e(z)\leq e(x)+1
.

If
e(x)=E_{\max}
, it is necessary that
e(z)\leq e(x)
and therefore the lemma still holds.
Overflow is not a special concern here because in Dekker’s system overflow leads to clipping. If overflow happens, it is necessary that
e(x)=E_{\max}
and
z
would take the value
\left(M-1\right)\times\beta^{E_{\max}}
.

End of proof for Lemma
2.12
.

The simple result below is interesting on its own and handy in the subsequent proofs as well.

Lemma 2.13
.

For
x,y\in\mathbb{D}
and
z=fl(x+y)
, if
z=x+y
, i.e., there is no rounding error committed when forming
z
, then the subsequent operation
z-x
or
z-y
commits no rounding error either.

Proof.

Since
z=x+y
, we have
z-x=y\in\mathbb{D}
, and, thus,
fl(z-x)=fl(y)=y
commits no rounding error. Similar argument can be made for
z-y
.

End of proof for Lemma
2.13
.

The following result is the counterpart of
[
14
, Theorem 2.4]
stated in Dekker’s system, which is more general in its statement and simpler in its proof thanks to the adoption of Dekker’s system.
Interested readers may also compare to its statement and proof from
[
8
]
and find its application in evaluating exponential functions there.
Faithful rounding is sufficient for the proof given below.

Lemma 2.14
.

For
x,y\in\mathbb{D}
and
z=fl(x+y)
, assuming overflow does not happen, if
x
,
y
, and
z
admit representations in
\mathbb{D}
such that
e(z)\leq min(e(x),e(y))
, then
z=x+y
, i.e., the addition is exact.

Proof.

We can express
x+y
as
\zeta\times\beta^{e(z)}
, where

\zeta=m(x)\cdot\beta^{e(x)-e(z)}+m(y)\cdot\beta^{e(y)-e(z)}.

(15)

Since
e(x)\geq e(z)
and
e(y)\geq e(z)
, we have
\zeta\in\mathbb{Z}
.

If
|\zeta|\geq M
,
\zeta\times\beta^{e(z)}

cannot
possibly round to a representation with exponent
e(z)
.
To see this more clearly and without loss of generality, assuming
\zeta\geq M
, then
\zeta\times\beta^{e(z)}
would be closer to
\frac{M}{\beta}\times\beta^{e(z)+1}
than to any valid representation in
\mathbb{D}
with exponent
e(z)
.
Thus, we have
|\zeta|<M
and hence
x+y=\zeta\times\beta^{e(z)}\in\mathbb{D}
. The statement in the lemma holds following faithful rounding.

End of proof for Lemma
2.14
.

The following result is a direct application of Lemma
2.14
. It is useful for including subnormal numbers in the discussion such as in the case of Corollary
3.7
.

Lemma 2.15
.

For
x,y\in\mathbb{D}
and
z=fl(x+y)
, if
z
admits a representation with exponent
E_{\min}
, then
z=x+y
, i.e., the addition is exact.

Proof.

For the representation of
z
with exponent
E_{\min}
, it is necessary that
e(x)\geq e(z)
and
e(y)\geq e(z)
, hence, Lemma
2.14
applies.

End of proof for Lemma
2.15
.

As a
special
case of the above lemma, we have that when
z=fl(x+y)
is a
subnormal
number, the addition
x+y
is exact, which is often the version stated in literature (e.g.,
[
11
, Theorem 3.4.1]
).

3  Error free transformation over addition

The following theorem is one of the building blocks of this work.
It has already appeared in Dekker’s work
[
5
]
, but lacks detail there.
We provide a detailed version of the proof below and build on it for our later results.
Interested readers may find in
[
17
,
21
,
19
]
other versions of this result in a less general setting.

Theorem 3.1

(3op EFT over addition in Dekker’s system)
.

Under Rule
2.6
and nearest rounding,
\forall x,y\in\mathbb{D}
with
e(x)\geq e(y)
, the following formulas achieve EFT
z+zz=x+y:

\displaystyle z

\displaystyle=fl(x+y)\mathchar 24635\relax\;

(16a)

\displaystyle w

\displaystyle=fl(z-x)\mathchar 24635\relax\;

(16b)

\displaystyle zz

\displaystyle=fl(y-w).

(16c)

Proof.

The gist of the proof below is to show that under the given conditions, neither (
16b
) nor (
16c
) commits rounding error.
Defining
d,f,g\in\mathbb{Z}
as follows,

\displaystyle d

\displaystyle=e(x)-e(y)\mathchar 24635\relax\;

(17a)

\displaystyle f

\displaystyle=e(x)-e(z)\mathchar 24635\relax\;

(17b)

\displaystyle g

\displaystyle=e(y)-e(z),

(17c)

we have
d\geq 0
from the condition
e(x)\geq e(y)
of the theorem
and the following equivalent ways of expressing
x
,
y
, and
z
:

\displaystyle x

\displaystyle\enskip=\enskip

\displaystyle m(x)\times\beta^{e(x)}

\displaystyle\enskip=\enskip

\displaystyle m(x)\cdot\beta^{d}\times\beta^{e(y)}

\displaystyle\enskip=\enskip

\displaystyle m(x)\cdot\beta^{f}\times\beta^{e(z)}

\displaystyle\mathchar 24635\relax\;

(18a)

\displaystyle y

\displaystyle\enskip=\enskip

\displaystyle m(y)\cdot\beta^{-d}\times\beta^{e(x)}

\displaystyle\enskip=\enskip

\displaystyle m(y)\times\beta^{e(y)}

\displaystyle\enskip=\enskip

\displaystyle m(y)\cdot\beta^{g}\times\beta^{e(z)}

\displaystyle\mathchar 24635\relax\;

(18b)

\displaystyle z

\displaystyle\enskip=\enskip

\displaystyle m(z)\cdot\beta^{-f}\times\beta^{e(x)}

\displaystyle\enskip=\enskip

\displaystyle m(z)\cdot\beta^{-g}\times\beta^{e(y)}

\displaystyle\enskip=\enskip

\displaystyle m(z)\times\beta^{e(z)}

.

(18c)

We note here that the above equalities are stated in
\mathbb{R}
rather than in
\mathbb{D}
because the mantissas may be out of range or no longer be integers.
From (
18a
) and (
18b
), we have

x+y=\left(m(x)\cdot\beta^{f}+m(y)\cdot\beta^{g}\right)\times\beta^{e(z)}.

(19)

Using Lemma
2.11
, we have

m(z)=round\left(m(x)\cdot\beta^{f}+m(y)\cdot\beta^{g}\right).

(20)

We introduce

\zeta=m(x)\cdot\beta^{f}+m(y)\cdot\beta^{g}

(21)

to simplify the notation below.

We proceed by showing that (
16b
), i.e., the calculation of
w
, commits no rounding error in all cases categorized by the signs of
f
and
g
.
From Lemma
2.12
, we know that
z
admits a representation with
e(z)\leq e(x)+1
in Dekker’s system.
We choose to work with such a representation of
z
for the discussion below, which is needed (only) in Case 4.
Moreover, we assume that overflow does not happen when forming
z
in (
16a
) for the cases below.
The special scenario of overflow is addressed immediately after the discussion of the cases below.

Case 1: if
f\geq 0
and
g\geq 0
, we have
\zeta\in\mathbb{Z}
and, therefore,
m(z)=\zeta
.
In other words,
z=x+y
is formed without rounding error in (
16a
).
According to Lemma
2.13
, (
16b
) also commits no rounding error.

Case 2: if
f\geq 0
and
g<0
,
\zeta
is no longer necessarily an integer.
From (
18
), we can write

z-x=\left(m(z)-m(x)\cdot\beta^{f}\right)\times\beta^{e(z)}.

(22)

Denoting
\omega=m(z)-m(x)\cdot\beta^{f}
, we have
\omega\in\mathbb{Z}
since
f\geq 0

and

\displaystyle\left|\omega\right|

\displaystyle=\left|m(z)-m(x)\cdot\beta^{f}-m(y)\cdot\beta^{g}+m(y)\cdot\beta^{g}\right|

\displaystyle\leq\left|round(\zeta)-\zeta\right|+\left|m(y)\cdot\beta^{g}\right|

\displaystyle\leq\tfrac{1}{2}+\tfrac{M-1}{\beta}\leq\tfrac{M}{2}.

We have
\tfrac{M}{2}\leq M-1
if
\beta\geq 2
and
t\geq 1
, which are satisfied for any natural floating point number system.
It follows that
z-x=\omega\times\beta^{e(z)}\in\mathbb{D}
, and hence
w=fl(z-x)
commits no rounding error.

Case 3: if
f<0
and
g\geq 0
, we have
d=f-g<0
, which contradicts with the condition
d\geq 0
.

Case 4: if
f<0
and
g<0
, recall that
e(z)\leq e(x)+1
, we have
f\geq-1
and, therefore,
f=-1
.
In general, we can write

z-x=\left(m(z)\cdot\beta^{-f}-m(x)\right)\times\beta^{e(x)}.

(23)

Denoting
\omega=m(z)\cdot\beta^{-f}-m(x)
, we have
\omega\in\mathbb{Z}
and

\displaystyle\left|\omega\right|

\displaystyle=\left|m(z)\cdot\beta^{-f}-m(x)\cdot\beta^{f}\cdot\beta^{-f}-m(y)\cdot\beta^{g}\cdot\beta^{-f}+m(y)\cdot\beta^{g}\cdot\beta^{-f}\right|

(24a)

\displaystyle=\left|\left(m(z)-m(x)\cdot\beta^{f}-m(y)\cdot\beta^{g}\right)\cdot\beta^{-f}\right|+\left|m(y)\cdot\beta^{-d}\right|

(24b)

\displaystyle\leq\tfrac{1}{2}\cdot\beta+(M-1),

(24c)

where we have used
f=-1
and
d\geq 0
to arrive at (
24c
).
So far, we have kept the discussion general with respect to
\beta
.
Here, we specialize to the case
\beta=2
, which leads to
|\omega|\leq M
following (
24c
).
If
|\omega|<M
, then
z-x=\omega\times\beta^{e(x)}
is a valid representation in
\mathbb{D}
;
if
|\omega|=M
, then
z-x=\text{sign}(\omega)\cdot\frac{M}{\beta}\times\beta^{e(z)}

is a valid representation in
\mathbb{D}
. In both cases, we have
w=fl(z-x)=z-x
as desired.

We now address the special scenario of
overflow
when forming
z
in (
16a
), i.e., when
|x+y|>(M-1)\times\beta^{E_{\max}}
.
If
f<0
, i.e., Cases 3 and 4 above, this cannot happen because

|x+y|\leq 2\cdot(M-1)\times\beta^{e(x)}\leq(M-1)\times\beta^{e(x)+1}\leq(M-1)\times\beta^{e(z)}\leq(M-1)\times\beta^{E_{\max}}.

If
f\geq 0
, i.e., Cases 1 and 2 above, overflow may happen in (
16a
), which leads to
|z|=(M-1)\times\beta^{E_{\max}}
in Dekker’s system.
Since
f=e(x)-e(z)\geq 0
, we have
e(x)=E_{\max}
as well.
Moreover, for overflow to happen,
x
and
y
must have the same sign.
Hence,
x
and
z
must also have the same sign.
Therefore, we have
|m(z)-m(x)|<|m(z)|=M-1
and that

z-x=\big(m(z)-m(x)\big)\times\beta^{E_{\max}}

is a valid representation in Dekker’s system.
To sum up, the claim that (
16b
) commits no rounding error still holds when
overflow
in
z
is considered.

We proceed to show that (
16c
) also commits no rounding error under the conditions stated in the theorem.
We first note that for all cases discussed above, including the special case of overflow,
w
admits a valid representation in
\mathbb{D}
with an exponent at least
e(y)
:
in Case 1, we have
w=y=m(y)\times\beta^{e(y)}
; in Case 2,
w
admits a representation in (
22
) with exponent
e(z)
, where
e(z)>e(y)
follows
g>0
;
Case 3 is a null case;
in Case 4,
w
admits a representation in (
23
) with exponent
e(x)
, where
e(x)\geq e(y)
follows
d\geq 0
;
in the special case of overflow,
w
admits a representation
\big(m(z)-m(x)\big)\times\beta^{E_{\max}}
, where
E_{\max}\geq e(y)
by definition.
Therefore, we can work with a representation
w=m(w)\times\beta^{e(w)}
, where
e(w)\geq e(y)
.

Introducing
h=e(w)-e(y)\geq 0
, we can write

w=m(w)\cdot\beta^{h}\times\beta^{e(y)}

and

y-w=\left(m(y)-m(w)\cdot\beta^{h}\right)\times\beta^{e(y)},

(25)

where
m(y)-m(w)\cdot\beta^{h}\in\mathbb{Z}
.
Moreover, we have

\displaystyle|y-w|

\displaystyle=|y-(z-x)|=|(x+y)-z|

(26a)

\displaystyle=|(x+y)-fl(x+y)|\leq|(x+y)-x|=|y|,

(26b)

where (
26a
) used the just proved result that
w=z-x
and (
26b
) used the nearest rounding property. It follows that
|m(y)-m(w)\cdot\beta^{h}|\leq|m(y)|\leq M-1
and, therefore,
y-w\in\mathbb{D}
with (
25
) being a valid representation.
In other words,
zz=fl(y-w)=y-w
.

End of proof for Theorem
3.1
.

Remark 5

(Generality)
.

The statement made in Theorem
3.1
is more general than what is typically stated in the literature, e.g.,
[
21
,
20
,
19
,
9
,
14
]
, which often imposes the stronger condition that
e(x)\geq e(y)
holds for the normal representations of
x
and
y
, or sometimes the even stronger one
|x|\geq|y|
.
Instead, Theorem
3.1
only requires that
x
and
y
admit a combination of representations such that
e(x)\geq e(y)
. They may very well admit representations such that the opposite is true. This generality is exploited in the proof of the following theorem.

End of Remark

5
.

We proceed to show that with three additional arithmetic operations as stated in the following theorem, the condition

from Theorem
3.1
can be removed.
This result has appeared in Dekker’s work
[
5
]
without a proof.
The proof given below uses the result of Theorem
3.1
and follows a similar pattern.
We assume
\beta=2
throughout the discussion of Theorem
3.2
and its associated lemmas.

Theorem 3.2

(6op EFT over addition in Dekker’s system)
.

Under Rule
2.6
and nearest rounding,
\forall x,y\in\mathbb{D}
, the following formulas achieve EFT

\displaystyle z

\displaystyle=fl(x+y)\mathchar 24635\relax\;

(27a)

\displaystyle w

\displaystyle=fl(z-x)\mathchar 24635\relax\;

(27b)

\displaystyle z1

\displaystyle=fl(y-w)\mathchar 24635\relax\;

(27c)

\displaystyle v

\displaystyle=fl(w-z)\mathchar 24635\relax\;

(27d)

\displaystyle z2

\displaystyle=fl(x+v)\mathchar 24635\relax\;

(27e)

\displaystyle zz

\displaystyle=fl(z1+z2).

(27f)

Proof.

The case when

and

admit representations with

has already been covered by the proof of Theorem

since it is easy to show that

following

in this case.
Therefore, we limit our discussion below to the complementary case, i.e., when

and

do not

In this scenario, aside from the obvious condition

cannot admit a representation with the exponent

since, otherwise, any representation of

would lead to

for this representation of

Consequently,

admits a normal representation in
\mathbb{D}
.
We work with this normal representation of

in the following.
In other words, when writing

below, the conditions

and

These conditions appear in Lemma
3.3
and Lemma

invoked in this proof.

The proof below consists of three parts:
first, we show that

under the above conditions;
second, we show that

by invoking Theorem
3.1
;
third, we show that
zz=z1+z2
.

We proceed to show that

still holds
by separating the discussion into four cases based on the signs of

and

, similar to that in the proof of Theorem
3.1
.
We assume that overflow does not happen when forming
z
for the four cases below.
The special scenario of overflow is addressed immediately after the discussion of these cases.

Case 1: if

and

as in Case 1 of Theorem

, where

. This leads to

Additionally, we also have

,

, and

.

Case 2: if

and

, which contradicts the assumption

Case 3: if

and

, recall that

, where

is defined in (

we have

\displaystyle z-x

\displaystyle=\left(m(z)-m(x)\cdot\beta^{f}\right)\times\beta^{e(z)}

(28a)

\displaystyle=\left(m(z)-m(x)\cdot\beta^{f}-m(y)\cdot\beta^{g}+m(y)\cdot\beta^{g}\right)\times\beta^{e(z)}

\displaystyle=y+\left(m(z)-m(x)\cdot\beta^{f}-m(y)\cdot\beta^{g}\right)\times\beta^{e(z)}

\displaystyle\in\left[y-\tfrac{1}{2}\times\beta^{e(z)},y+\tfrac{1}{2}\times\beta^{e(z)}\right]\subseteq\left[y-\tfrac{1}{2}\times\beta^{e(y)},y+\tfrac{1}{2}\times\beta^{e(y)}\right].

(28d)

From Lemma
3.3
presented after this theorem, we know
that

\pm 1\times\beta^{e(y)-1}
,

, or
\pm 1\times\beta^{e(y)}

.
Therefore, we have

as desired.

Case 4: if

and

, we have that

admits a representation with

following Lemma

.
Working with a representation of

implies that
e(z)=e(y)+1
.
Similar to (

), we have in this case

z-x\in\left[y-\tfrac{1}{2}\times\beta^{e(z)},y+\tfrac{1}{2}\times\beta^{e(z)}\right]=\left[y-1\times\beta^{e(y)},y+1\times\beta^{e(y)}\right],

(29)

where

is used for the last equality.
When

3.4
presented after this theorem to arrive at the desired result

as in Case 3.
The special situation

is addressed in Remark

following this theorem.

We now address the special scenario of

when forming

Notice that overflow cannot possibly happen in Cases 1 and 2 above because we have

under the combination of assumptions

and

Therefore, we need only to concentrate on Cases 3 and 4 above, where

.
Moreover, since

and

Because overflow leads to clipping in Dekker’s system, we have

Because of (

\displaystyle y

\displaystyle=\tilde{m}(y)\times\beta^{E_{\max}-1}\mathchar 24635\relax\;

\displaystyle=\tilde{m}(w)\times\beta^{E_{\max}-1},

This concludes the discussion for the special scenario of

.

Now that we completed the demonstration of

, we proceed to show that

When

When

Combined with

It remains to show that

) also commits no rounding error.
For all non-empty cases discussed above, including the special scenario of overflow when forming
z
and the special systems with

, we have that

with an exponent no less than

.
Since

\tilde{m}(z1)\times\beta^{e(x)}

.

Remark 6

(Special scenario:

We use this remark to address the special scenario when

in Case 4 of Theorem
3.2

When

, the mantissa can only take value

or

Given the above observation, we assume that

,
y
, and

Recall the conditions

and

|x|<|z|
and
|y|<|z|
, which imply that

and

,

, and

\tilde{z}=\zeta\times\beta^{e(z)}
, we have
m(z)=round(\zeta)
following Lemma
2.11
and, therefore,

|m(z)-\zeta|\leq\tfrac{1}{2}
.
It follows that

|z-\tilde{z}|=|m(z)-\zeta|\times\beta^{e(z)}\leq\tfrac{1}{2}\times\beta^{e(z)}
.

Notice that the result above holds for any valid representation of
z
. When
z
is not a subnormal number, working with its normal representation
m(z)\times\beta^{e(z)}
where
|m(z)|\geq\beta^{t-1}
, we have

|z-\tilde{z}|\leq\tfrac{1}{2}\times\beta^{e(z)}=\tfrac{1}{2}\cdot\beta^{1-t}\cdot\beta^{t-1}\times\beta^{e(z)}\leq\epsilon|z|
.

End of proof for Lemma
3.5
.

Lemma
3.5
provides a statement regarding rounding in general.
If the number to be rounded, i.e.,
\tilde{z}
, is the intermediate result from an addition (or subtraction) operation, the additional requirement that
z
is not a subnormal number
can be dropped from the statement, which is summarized below.

Lemma 3.6
.

Given
x,y\in\mathbb{D}
and
\tilde{z}=x+y\in\mathbb{R}
, which rounds to
z=m(z)\times\beta^{e(z)}
in
\mathbb{D}
,
if
|\tilde{z}|\leq(M-1)\times\beta^{E{\max}}
, i.e.,
\tilde{z}
does not overflow, we have
|z-\tilde{z}|\leq\tfrac{1}{2}\times\beta^{e(z)}
and
|z-\tilde{z}|\leq\epsilon|z|
.

Proof.

It suffices to consider only the case when
z
is a subnormal number.
In this case, we have
z=x+y=\tilde{z}
from Lemma
2.15
and, hence, the stated results still hold.

End of proof for Lemma
3.6
.

The following corollary results from a straightforward application of Lemma
3.6
by observing that
zz=x+y-z=x+y-fl(x+y)
when the conditions of Theorem
3.1
or Theorem
3.2
are met.

Corollary 3.7
.

Under the conditions of Theorem
3.1
or the conditions of Theorem
3.2
and assuming overflow does not happen when forming
z
, we have
|zz|\leq\tfrac{1}{2}\times\beta^{e(z)}
and
|zz|\leq\epsilon|z|
.

Lemma
3.6

bounds the error with the
output
of the floating point addition operation.
The lemma below bounds the error with the
inputs
of the addition operation.

Lemma 3.8
.

Given
x,y\in\mathbb{D}
and
\tilde{z}=x+y\in\mathbb{R}
, which rounds to
z
,
if
|\tilde{z}|\leq(M-1)\times\beta^{E{\max}}
, i.e.,
\tilde{z}
does not overflow, we have
|z-\tilde{z}|\leq\epsilon|\tilde{z}|
.

Proof.
It suffices to consider only the case
\tilde{z}\geq 0
since both
\mathbb{D}
and
\mathbb{R}
are symmetric. The two cases discussed below cover all possible outcomes of
x+y
that do not lead to overflow.

When
\tilde{z}\in\left[0,\beta^{t}\times\beta^{E_{\min}}\right]
, we can express
\tilde{z}
as
\zeta\times\beta^{E_{\min}}
, where
\zeta=m(x)\cdot\beta^{e(x)-E_{\min}}+m(y)\cdot\beta^{e(y)-E_{\min}}
.
Since
e(x),e(y)\geq E_{\min}
, we have that
\zeta\in\mathbb{Z}
and hence can take values
0,1,2,\cdots,\beta^{t}
. Since overflow has been precluded, these possible options of
\zeta
all lead to
\tilde{z}\in\mathbb{D}
and hence
z-\tilde{z}=0
.

When
\tilde{z}\in\left[\beta^{t-1}\times\beta^{E},\beta^{t}\times\beta^{E}\right]
for
E_{\min}<E\leq E_{\max}
,
noticing that the space between two adjacent floating point numbers in this interval is
1\times\beta^{E}
and since overflow has been precluded,
we have
|z-\tilde{z}|\leq\tfrac{1}{2}\times\beta^{E}
following nearest rounding and, therefore,

|z-\tilde{z}|\leq\tfrac{1}{2}\cdot\beta^{1-t}\cdot\beta^{t-1}\times\beta^{E}\leq\epsilon|\tilde{z}|
.
(In this case, we actually have a strict inequality

|z-\tilde{z}|<\epsilon|\tilde{z}|
because
z-\tilde{z}
would be zero if
\tilde{z}=\beta^{t-1}\times\beta^{E}
.)

End of proof for Lemma
3.8
.

The following corollary results from a straightforward application of Lemma
3.8
by observing that
zz=x+y-z=x+y-fl(x+y)
when the conditions of Theorem
3.1
or Theorem
3.2
are met.

Corollary 3.9
.

Under the conditions of Theorem
3.1
or the conditions of Theorem
3.2
and assuming overflow does not happen when forming
z
, we have
|zz|\leq\epsilon|\tilde{z}|
where
\tilde{z}=x+y
.

4  Application of the EFTs in summing a sequence of numbers

The EFTs presented in Section
3
can bring benefits in various applications; see
[
25
,
27
,
4
]
for a few examples.
One such application is summing a sequence of numbers, in particular, summing a sequence of numbers in the order that they are presented, which is referred to as recursive summation in Higham’s work
[
15
]
; see also
[
14
, P. 80]
.
Recursive summation is disadvantaged in accuracy when compared to the other summing strategies examined in
[
15
]
that require the control over the summing order.
However, for many applications, particularly those involving iterative procedures where the addends are produced on the fly, recursive summation is the only viable option.

The EFT from Theorem
3.1
can be used to improve the accuracy of recursive summation.
This has been recognized in the early work of Kahan
[
17
]
, which presented a technique often referred to as Kahan’s summation or Kahan’s compensated summation.
A proof about the error bound of Kahan’s summation can be found in
[
19
, P. 244]
and
[
9
]
.
In the following, we will start with formalizing the recursive summation problem in Section
4.1
and summarizing Kahan’s compensated summation algorithm in Section
4.2
. A natural extension of Kahan’s summation is examined in Section
4.3
.

More nuanced versions of compensated summation algorithms are then presented and analyzed in Sections
4.4
and
4.5
.
These more nuanced versions enjoy tighter error bounds, which can be particularly beneficial for designing validation tests for computer systems.
Thanks to the adoption of Dekker’s system and the theoretic results developed above,
the proofs provided below are simple to follow and
cover subnormal numbers naturally.
For the remainder of this section, we assume nearest rounding and no overflow.

assume any special relationship among the signs or magnitudes of the addends.

Under the moderate assumption that

\displaystyle\textstyle\left|s_{n}+e_{n}-\tilde{s}\right|

\displaystyle\textstyle=\left|\sum_{k=1}^{n}\alpha_{k}x_{k}+\theta_{n-k}x_{k}+\theta_{n-k}\alpha_{k}x_{k}\right|

\displaystyle\textstyle\leq\epsilon\sum_{k=1}^{n}|x_{k}|+\sum_{k=1}^{n}\frac{(n-k)\epsilon^{2}}{1-(n-k)\epsilon^{2}}|x_{k}|+\sum_{k=1}^{n}\frac{(n-k)\epsilon^{3}}{1-(n-k)\epsilon^{2}}|x_{k}|

\displaystyle\textstyle\leq\epsilon\sum_{k=1}^{n}|x_{k}|+\frac{(n-1)\epsilon^{2}}{1-(n-1)\epsilon^{2}}\sum_{k=1}^{n}|x_{k}|+\frac{(n-1)\epsilon^{3}}{1-(n-1)\epsilon^{2}}\sum_{k=1}^{n}|x_{k}|\,.

One possible exception is when using compensated summation to verify hardware or software correctness, where a more precise bound such as (

For some use cases, if we have the luxury to keep both

and

If only

is to be kept, we have from

\displaystyle\textstyle\leq(1+\epsilon)\left\{\epsilon\sum_{k=1}^{n}|x_{k}|+\frac{(n-1)\epsilon^{2}}{1-(n-1)\epsilon^{2}}\sum_{k=1}^{n}|x_{k}|+\frac{(n-1)\epsilon^{3}}{1-(n-1)\epsilon^{2}}\sum_{k=1}^{n}|x_{k}|\right\}+\epsilon\left|\sum_{k=1}^{n}x_{k}\right|\,.

or

Remark 8

(

End of Remark

.

Remark 9

On modern hardware, floating point operation count often has little impact on performance; it is the data movement that tends to dominate both the execution time and energy consumption.
Time spent on small amounts of floating point operations can often be hidden entirely by data movement due to overlapping executions.
The additional floating point operation count in Algorithm

and
4
. We start by deriving a recursive relation.
Attaching subscript index

to disambiguate variables from different iterations,
we can write

\displaystyle y_{i}

\displaystyle=(1+\alpha_{i})(e_{i-1}+x_{i})

\displaystyle u_{i}

\displaystyle=-\alpha_{i}(e_{i-1}+x_{i})

(60b)

\displaystyle t_{i}

\displaystyle=(1+\beta_{i})(s_{i-1}+y_{i})

(60c)

\displaystyle v_{i}

\displaystyle=-\beta_{i}(s_{i-1}+y_{i})

(60d)

\displaystyle w_{i}

\displaystyle=(1+\gamma_{i})(u_{i}+v_{i})

(60e)

\displaystyle s_{i}

\displaystyle=(1+\eta_{i})(t_{i}+w_{i})

(60f)

\displaystyle e_{i}

\displaystyle=-\eta_{i}(t_{i}+w_{i})

(60g)

with

following Lemma

and

\displaystyle s_{i}+e_{i}

\displaystyle=t_{i}+w_{i}

(61a)

\displaystyle=t_{i}+u_{i}+v_{i}+\gamma_{i}(u_{i}+v_{i})

(61b)

\displaystyle=s_{i-1}+y_{i}+u_{i}+\gamma_{i}(u_{i}+v_{i})

(61c)

\displaystyle=s_{i-1}+e_{i-1}+x_{i}+\gamma_{i}(u_{i}+v_{i})

(61d)

\displaystyle=(s_{i-1}+e_{i-1})+x_{i}-\gamma_{i}[\alpha_{i}(e_{i-1}+x_{i})+\beta_{i}(s_{i-1}+y_{i})]

(61e)

\displaystyle=(s_{i-1}+e_{i-1})+x_{i}-\gamma_{i}\alpha_{i}e_{i-1}-\gamma_{i}\alpha_{i}x_{i}-\gamma_{i}\beta_{i}(s_{i-1}+e_{i-1}+\alpha_{i}e_{i-1}+x_{i}+\alpha_{i}x_{i})

(61f)

\displaystyle=(1-\gamma_{i}\beta_{i})(s_{i-1}+e_{i-1})-(\gamma_{i}\alpha_{i}+\gamma_{i}\beta_{i}\alpha_{i})e_{i-1}+(1-\gamma_{i}\alpha_{i}-\gamma_{i}\beta_{i}-\gamma_{i}\beta_{i}\alpha_{i})x_{i}

\displaystyle=\left(1-\gamma_{i}\beta_{i}+\gamma_{i}\alpha_{i}\eta_{i-1}+\gamma_{i}\beta_{i}\alpha_{i}\eta_{i-1}\right)(s_{i-1}+e_{i-1})+(1-\gamma_{i}\alpha_{i}-\gamma_{i}\beta_{i}-\gamma_{i}\beta_{i}\alpha_{i})x_{i}\,.

evaluates to
1

.

Introducing

5.3 Dynamical system

Simulation of dynamical systems is a natural application for compensated summation algorithms, where the solution update can be viewed as a recursive summation with the addends being generated on the fly.
Compensated summation algorithms can be particularly beneficial for dynamical systems that are sensitive to small perturbations or require long simulation steps such as those arising in celestial mechanics.

In this example, we experiment with a classical three-body problem with a configuration of initial states that lead to periodic orbits resembling the figure-eight shape
[
3
]
.
The problem can be formulated as the following ODE system:

\left\{\begin{array}[]{lcr}\displaystyle\dot{R_{i}}&=&\displaystyle V_{i}\,\mathchar 24635\relax\\[2.15277pt]
\displaystyle\dot{V_{i}}&=&\displaystyle A_{i}\,,\end{array}\right.

(66)

where
i
ranges from
1
to
3
and identifies one of the three interacting bodies;
R_{i}
,
V_{i}
, and
A_{i}
are vectors with two components each, representing the position, velocity, and acceleration, respectively, of the
i
th body in the orbiting plane.
The acceleration
A_{i}
is calculated based on the following formula:

A_{i}=\sum_{j\neq i}\frac{R_{j}-R_{i}}{\|R_{j}-R_{i}\|^{3}}\,,

(67)

where
j
also goes through
1
to
3
.

The system (
66
) is integrated using the symplectic Euler method as follows:

\begin{array}[]{lcl}R_{i}^{(k+1)}&=&R_{i}^{(k)}+hV_{i}^{(k)}\,\mathchar 24635\relax\\[2.15277pt]
V_{i}^{(k+1)}&=&V_{i}^{(k)}+hA_{i}^{(k+1)}\,,\end{array}

(68)

where
k
indicates the time step and
h
is the step size.
The simulation is performed at fp32 with
h=2^{-11}
for 10000 periods, with each period being approximately 6.3259.
Results with Algorithm
1
(simple recursive summation without compensation) applied to (
68
) are shown in Figure
4
, with the plots illustrating the orbit of the first body at around the
0
th,
2000
th,
\cdots
,
8000
th period, respectively.
As can be observed from these plots, the simulation quickly deviates from the figure-eight shaped orbit that the bodies are supposed to follow.

The reason is evidenced in the error bounds given in (

) and (

To first-order approximation, the accumulation error is bounded by an
\epsilon

term for Algorithm

term for Algorithm
4

The absence of the
\epsilon

4

However, once another error on the order of
\epsilon

In the case of ODE simulations, this other error comes from the evaluation and assignment of the new addends, i.e.,
hV_{i}^{(k)}

6  Conclusions

Analysis of various compensated recursive summation algorithms is provided using the error free transformation results derived using Dekker’s floating point number system.
Our analysis differs from
previous efforts in that it provides a complete description of the error behavior instead of tracking the leading order term only.
Recursive relations that reveal the error propagation pattern are provided as part of the analysis, which can be used to identify the operation that limits the accuracy of the overall algorithm.
This information is used to design more nuanced compensated summation algorithms that remove the accuracy bottleneck.
Numerical evidence is provided to illustrate the efficacy of these algorithms, verifying empirically that in some cases, algorithmic improvement can achieve an accuracy as if a datatype with twice the amount of mantissa bits has been used.
