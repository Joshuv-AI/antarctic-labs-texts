MS-DGCNN++: A Multi-Scale Fusion Dynamic Graph Neural Network with Biological Knowledge Integration for LiDAR Tree Species Classification Journal: Information Fusion
Said Ohamouddou, Abdellatif El Afia, Hanaa El Afia, Raddouane Chiheb

Abstract
Tree species classification from terrestrial LiDAR point clouds is challenging because of the complex multi-scale geometric structures in forest environments. Existing approaches using multi-scale dynamic graph convolutional neural networks (MS-DGCNN) employ parallel multi-scale processing, which fails to capture the semantic relationships between the hierarchical levels of the tree architecture. We present MS-DGCNN++, a hierarchical multiscale fusion dynamic graph convolutional network that uses semantically meaningful feature extraction at local, branch, and canopy scales with cross-scale information propagation. Our method employs scale-specific feature engineering, including standard geometric features for the local scale, normalized relative vectors for the branch scale, and distance information for the canopy scale. This hierarchical approach replaces uniform parallel processing with semantically differentiated representations that are aligned with the natural tree structure. Under the same proposed tree species data augmentation strategy for all experiments, MS-DGCNN++ achieved an accuracy of 94.96 % on STPCTLS, outperforming DGCNN, MS-DGCNN, and the state-of-the-art model PPT. On FOR-species20K, it achieves 67.25% accuracy (6.1% improvement compared to MS-DGCNN). For standard 3D object recognition, our method outperformed DGCNN and MS-DGCNN with overall accuracies of 93.15% on ModelNet40 and 94.05% on ModelNet10. With lower parameters and reduced complexity compared to state-of-the-art transformer approaches, our method is suitable for resource-constrained applications while maintaining a competitive accuracy. Beyond tree classification, the method generalizes to standard 3D object recognition, establishing it as a versatile solution for diverse point cloud processing applications. The implementation code is publicly available at https://github.com/said-ohamouddou/MS-DGCNN2 .

Specifically, existing MS-DGCNN implementations employ parallel branches with marginally differentiated neighborhood sizes (e.g.,

These parallel branches process the same point and neighbor features without any scale-specific feature engineering, resulting in redundant feature extraction and limited scale differentiation. This approach fundamentally fails to capture the inherent hierarchical nature of 3D geometric structures, where local fine-grained details should progressively inform mid-level structural patterns and global shape understanding. Furthermore, the independent parallel processing of scales prevents cross-scale information flow, missing critical opportunities for feature refinement and contextual enhancement.

To address these limitations, we propose a new variant of MS-DGCNN, which we call MS-DGCNN++. This method explicitly models the natural tree-like organization of 3D objects through semantically meaningful scale separation: local scale (
k_{1}

Unlike conventional parallel multi-scale processing, which uses identical point and neighbor features across all scales, our implementation introduces scale-specific feature engineering. For the local scale, we used standard relative and absolute features. At the branch scale, we added normalized relative vectors to capture angular information and structural patterns. For the canopy scale, we included distance information to encode global spatial relationships. This hierarchical approach enables progressive feature refinement through cross-scale information propagation, which better reflects the natural hierarchical organization of 3D geometric data.

Related Work and Background

2.1
LiDAR tree species classification

Tree species classification approaches using LiDAR technology, including TLS, have evolved through three main methods: classical machine learning with handcrafted features, convolutional neural networks (CNNs) using 2D projections, and direct deep learning methods operating on 3D point clouds.

2.1.1
Classical machine learning

Classical machine learning methods for LiDAR-based tree species classification rely on handcrafted features derived from point cloud data.
[
14
]
utilized quantitative structure models to extract 17 structural features from TLS data, achieving classification success rates of approximately 80% for five tree species in a mixed deciduous forest.
[
5
]
conducted a comprehensive review of tree species classification based on airborne LiDAR data and applied classifiers, concluding that features extracted from full-waveform data lead to the highest overall accuracy, while radiometric features combined with height information also generate high species classification accuracies.

2.1.2
Convolutional neural networks with 2D projections

[
12
]
tested an image classification approach based on convolutional neural networks using 2D representations of 3D point clouds, achieving 86% classification accuracy for seven tree species and demonstrating computational efficiency advantages over 3D processing methods.
[
8
]
released the FOR-species20K benchmark dataset and compared seven leading deep learning models, finding that the 2D image-based model DetailView achieved higher overall accuracy (79.5%) than 3D point cloud-based models (72%) on average.
[
15
]
also used joint classification from multiple viewpoints to automatically classify tree species from laser scanning data in structurally complex Mediterranean forests, achieving high overall accuracy (80.6%) comparable to existing work.

2.1.3
Direct deep learning methods

The advent of deep learning has revolutionized LiDAR-based classification approaches by automatically learning optimal feature representations directly from raw point cloud data.
[
16
]
proposed LayerNet, a point-based deep neural network that divides overlapping layers in Euclidean space to capture local three-dimensional structural features, achieving a classification accuracy of 92.5%. Similarly,
[
17
]
applied PointNet++ to backpack laser scanning data, demonstrating the effectiveness of point cloud deep learning methods for tree species identification.
[
18
]
compared 13 machine learning and deep learning classifiers for nine species, finding that PointNet++ provided the best species classification performance with a mean Intersection over Union accuracy of 0.906. More recently,
[
9
]
introduced MFFTC-Net, which leverages a boundary-driven point sampling method and umbrella-repSurf module to capture local geometric features, achieving state-of-the-art performance on both self-built and the public datasets STPCTLS.

2.2
Fusion techniques in 3D point cloud

Recent advances in 3D point cloud processing have demonstrated the critical importance of feature fusion techniques for enhancing the classification, segmentation, and reconstruction tasks. Several approaches have focused on fusing geometric and semantic information at different scales and spaces.
[
19
]
proposed an adaptive feature fusion module that combines global and local features through a multi-scale transformation network, achieving 93.6% classification accuracy on ModelNet40. Similarly,
[
20
]
introduced PointGS, which establishes a mutual supervision mechanism to bridge geometric and semantic spaces, demonstrating that the synergistic fusion of dual-space information significantly improves point cloud analysis performance. Multi-scale feature fusion has also proven effective, as evidenced by
[
21
]
’s M-GCN framework, which extracts local geometric features through multi-scale graph convolution, and
[
22
]
’s LDGCNN approach that links hierarchical features from dynamic graphs to achieve state-of-the-art results. Additionally, geometric consistency-based fusion approaches, such as the rotation-invariant dual-view reconstruction method by
[
23
]
and the multi-level consistency framework by
[
24
]
, highlight the importance of maintaining structural coherence during feature aggregation. These studies collectively underscore that effective feature fusion, whether geometric or semantic, is fundamental to overcoming the inherent challenges of sparse, unordered point cloud data and achieving robust 3D understanding.

2.3
Dynamic Graph Convolutional Neural Network (DGCNN)

The Dynamic Graph CNN approach
[
7
]
represents an advancement over point-based deep learning methods such as PointNet
[
25
]
by addressing the limitation of processing points in isolation. Rather than handling each point independently, this technique captures local spatial relationships through (
k
-NN) graph construction within the feature representation space, followed by convolution-style operations termed “edge convolutions” along graph connections. This design achieves a balance between preserving the translation invariance and enabling non-local feature interactions.

2.3.1
Edge Convolution (EdgeConv)

Consider a point cloud
X=\{\mathbf{x}_{1},\ldots,\mathbf{x}_{n}\}\subseteq\mathbb{R}^{D}
containing
n
points in
D
-dimensional space. The method constructs a directed graph
\mathcal{G}=(\mathcal{V},\mathcal{E})
where each vertex is connected to its
k
closest neighbors based on the current feature representation. For every edge connection
(i,j)
, an edge feature is computed as

\mathbf{e}_{ij}=h_{\boldsymbol{\Theta}}(\mathbf{x}_{i},\mathbf{x}_{j})

(1)

A typical implementation uses the following:

h_{\boldsymbol{\Theta}}(\mathbf{x}_{i},\mathbf{x}_{j})=\bar{h}_{\boldsymbol{\Theta}}(\mathbf{x}_{i},\mathbf{x}_{j}-\mathbf{x}_{i}),

(2)

where
\bar{h}_{\boldsymbol{\Theta}}
represents a shared multi-layer perceptron (MLP) that processes both the reference point
\mathbf{x}_{i}
and displacement vector
\mathbf{x}_{j}-\mathbf{x}_{i}
. Subsequently, a symmetric aggregation function (such as the maximum or summation) combines the edge features for each vertex to produce updated point representations:

\mathbf{x}^{\prime}_{i}=\mathop{\text{agg}}_{j:(i,j)\in\mathcal{E}}h_{\boldsymbol{\Theta}}(\mathbf{x}_{i},\mathbf{x}_{j}).

(3)

2.3.2
Adaptive Graph Reconstruction

A key distinction from traditional graph-based CNNs is DGCNN’s dynamic graph updating mechanism of the DGCNN. Following each feature transformation layer, the
k
-NN relationships are recalculated within the transformed feature space, enabling points that are spatially distant in the original coordinate system to establish connections in the learned representation.

2.4
Multi-scale DGCNN (MS-DGCNN)

Drawing inspiration from hierarchical approaches, the MS-DGCNN
[
11
]
architecture employs Farthest Point Sampling (FPS) to select 512 representative points for local geometric feature extraction. The architecture incorporates three parallel EdgeConv branches operating at different scales (e.g.,
k=20,30,40
), where each branch utilizes distinct k-NN graph configurations to capture and aggregate the neighborhood features at varying resolutions. The multi-scale features are subsequently concatenated and processed through three shared MLP layers (448, 512, and 1024 dimensions), followed by global max pooling for semantic feature extraction. Finally, additional MLP layers (1024, 512, and 256 dimensions) transform the global features into classification outputs.

2.4.1
DGCNN for LiDAR Tree Species Classification

From the previous sections, we observe that methods based on multi-scale, hierarchical feature learning and feature fusion represent the prevailing trend in 3D learning fields, as they demonstrate improved performance. Specifically, for tree species classification, Multi-scale feature fusion-based methods such as PointNet++ and MFFTC-Net generally yield optimal performance. Although DGCNN exhibits superior performance compared to PointNet++ in standard benchmarking tasks, it demonstrates reduced performance in tree species classification compared to PointNet++ (68.3% vs. 75.6% in
[
8
]
). Similarly, the DGCNN shows inferior performance relative to MFFTC-Net (87.41% vs. 90.37%
[
9
]
).

Indeed, DGCNN encounters several obstacles that impede the precise identification of tree species. These obstacles include the irregular distribution of data points across different components of individual trees and missing or partial datasets
[
9
]
, as illustrated in Figure
1
. One potential solution involves the adoption of the MS-DGCNN. The baseline MS-DGCNN, while effective for general 3D point cloud classification tasks such as ModelNet10
[
11
]
, has inherent limitations when applied to tree species classification from LiDAR data. The baseline employs uniform multi-scale processing with fixed
k
-values (5, 20, and 50) across all geometric scales, treating all spatial relationships uniformly without considering the hierarchical nature of the tree architecture. This approach fails to capture the distinct geometric patterns that characterize different organizational levels of tree structures, from fine-scale features such as leaf arrangements and bark texture to medium-scale branch patterns and ultimately to large-scale canopy shapes that are crucial for species identification.

4.2
Data Preprocessing

4.2.1
downsimpling

We applied preprocessing to standardize the point cloud density across all datasets by downsampling the original scans to 1024 points using the farthest-point sampling (FPS) algorithm
[
42
]
. This technique systematically selects points that preserve the geometric structure by maximizing the inter-point distances, thereby maintaining the essential morphological features that are critical for LiDAR-based object classification. For the FOR-species20K dataset, owing to the substantial data volume and computational complexity associated with FPS, we implemented a two-stage approach: first, we applied recursive voxel downsampling to approximately 30,000 points with a tolerance threshold of 500, followed by the standard FPS procedure to achieve a target resolution of 1024 points.

4.2.2
Normalization

We normalized each point cloud to a unit sphere by translating the points to the origin and scaling them according to their furthest distance from the center. This normalization ensures consistent spatial dimensions across all samples, eliminating scale variations that could bias the classification process.

\mathbf{p}_{i}^{norm}=\frac{\mathbf{p}_{i}-\frac{1}{N}\sum_{j=1}^{N}\mathbf{p}_{j}}{\max_{k}\left\|\mathbf{p}_{k}-\frac{1}{N}\sum_{j=1}^{N}\mathbf{p}_{j}\right\|_{2}}

(4)

4.2.3
Balancing

To mitigate the class imbalance in the STPCTLS and FOR-species20K datasets, a class weighting strategy was incorporated into the loss function, specifically by employing a weighted cross-entropy loss. This strategy identifies minority classes by comparing their sample counts with the mean sample count per class. Classes with sample counts below the mean were assigned proportionally larger weights, ensuring that underrepresented classes were not neglected while avoiding excessive penalties for extremely small class sizes.

The class weighting mechanism is formulated as follows: Let
C
be the total number of classes, and let
n_{i}
denote the number of samples in class
i
. The mean sample count per class is computed as follows:

\bar{n}=\frac{1}{C}\sum_{i=1}^{C}n_{i}

(5)

The maximum class count is defined as

n_{\max}=\max_{i\in\{1,2,\ldots,C\}}n_{i}

(6)

For each class
i
, weight
w_{i}
is determined using the following conditional formula:

w_{i}=\begin{cases}\frac{n_{\max}}{\bar{n}}&\text{if }n_{i}<\bar{n}\\[5.0pt]
\frac{n_{\max}}{n_{i}}&\text{if }n_{i}\geq\bar{n}\end{cases}

(7)

These weights were then applied to the cross-entropy loss function during training to address class imbalance.

4.3
Evaluation Metrics

The following metrics were employed to assess the model performance and computational efficiency:

1.

Overall Accuracy (OA): The ratio of correctly classified samples to the total number of samples, expressed as a percentage (%).

OA=\frac{\sum_{i=1}^{C}TP_{i}}{\sum_{i=1}^{C}(TP_{i}+FP_{i})}\times 100\%

(8)

where
C
is the number of classes,
TP_{i}
is the true positive for class
i
, and
FP_{i}
is the false positive for class
i
.

2.

Balanced Accuracy (BA): The average of recall obtained on each class, providing a more robust measure for imbalanced datasets, expressed as a percentage (%).

BA=\frac{1}{C}\sum_{i=1}^{C}\frac{TP_{i}}{TP_{i}+FN_{i}}\times 100\%

(9)

where
FN_{i}
is the false negative for class
i
.

3.

Class Precision: The precision for each individual class, representing the ratio of correctly predicted samples for a specific class to the total number of samples predicted as that class, expressed as a percentage (%). For class
i
, this is denoted by the class name.

\text{Class Precision}_{i}=\frac{TP_{i}}{TP_{i}+FP_{i}}\times 100\%

(10)

4.

Kappa Coefficient (
\kappa
): Cohen’s kappa statistic measuring inter-rater agreement, accounting for chance agreement. The values range from -1 to 1, where 1 indicates perfect agreement.

\kappa=\frac{p_{o}-p_{e}}{1-p_{e}}

(11)

where
p_{o}=\frac{\sum_{i=1}^{C}x_{ii}}{N}
and
p_{e}=\frac{\sum_{i=1}^{C}x_{i+}\cdot x_{+i}}{N^{2}}
, with
x_{ii}
being diagonal elements of the confusion matrix,
x_{i+}
and
x_{+i}
being row and column sums, and
N
being the total number of samples.

5.

Parameter Count (PC): The total number of trainable parameters in the model, typically expressed in millions (M).

6.

Model Size (MS): The storage size of the trained model in megabytes (MB). This metric is particularly useful when compared with previously reported results, where model size information is available.

7.

Epoch Time (ET): The computational time required to complete one full training epoch, measured in seconds (s).

5.1
STPCTLS Dataset Results Analysis

We compared MS-DGCNN++(5,20,50)(
k_{1}=5,k_{2}=20,k_{3}=50

When we did not use augmentation, our method achieved an overall accuracy of 90.65 %, which was third place among all tested methods.

Data augmentation had a significant impact on the MS-DGCNN++ performance. When we used augmentation, the overall classification accuracy increased by 2.88 percentage points (from 90.65% to 93.53%). Cohen’s kappa improved by 3.71 points (from 88.17% to 91.88%). Balanced accuracy had the largest improvement of 5.97 points (from 84.82% to 90.79%).

When we examined how well the method worked for different tree species, MS-DGCNN++ achieved 100% accuracy for Douglas fir and Red Oak when we used augmentation. For other species, the results were also high: beech achieved 96.77% and spruce achieved 94.12%. Our method performed better than the standard DGCNN and MS-DGCNN methods and other approaches we tested.

Compared to transformer-based methods such as PointBert, PointGPT-S, and PPT, our method requires far fewer parameters (1.81M vs. 22.7M for PPT) but still achieves similar or better results. This makes our method suitable for real-world applications, where both accuracy and memory efficiency are important.

The results were statistically significant. Cohen’s kappa values were 91.88% (with augmentation) and 88.17% (without augmentation). Both values were above 0.80, indicating almost perfect agreement and showing that our results are trustworthy. These findings demonstrate that MS-DGCNN++ is an effective and efficient method for point cloud classification, particularly when used with appropriate data augmentation.

Moreover, we noticed that all models generally showed better performance when our data augmentation strategy was used.

Discussion

The experimental results demonstrate that MS-DGCNN++ addresses the key limitations of existing multi-scale approaches through hierarchical feature engineering and cross-scale information propagation. The superior performance of the method across diverse datasets (STPCTLS, FOR-species20K, ModelNet10/40) validates its effectiveness beyond tree species classification, establishing it as a robust solution for general 3D point cloud processing.

The comprehensive ablation study revealed that the optimal k-parameter selection significantly impacted both the accuracy and computational efficiency. The configuration MS-DGCNN++(5,20,30) emerged as the best balance, achieving 94.96% accuracy on STPCTLS and outperforming all other models while maintaining a reasonable computational overhead. This finding suggests that moderate neighborhood sizes at each scale provide sufficient geometric information without an unnecessary computational burden.

Our scale-specific feature engineering approach, which uses standard features for local scale, normalized relative vectors for branch scale, and distance information for canopy scale, is more effective than uniform parallel processing. This semantic differentiation aligns with the natural hierarchical structure of 3D objects, particularly trees, in which different levels of detail require distinct geometric representations.

The consistent performance improvements of the method (2.88% on STPCTLS with augmentation, 6.1% on FOR-species20K) demonstrate its robustness across varying point cloud densities and species diversity. The parameter efficiency advantage over transformer-based approaches (7.3 MB vs. 347.5 MB–613.7 MB model size) makes MS-DGCNN++ particularly suitable for resource-constrained applications while maintaining competitive accuracy.

However, the method still faces challenges with
k
-NN parameters
{k_{1},k_{2},k_{3}}
selection, as it requires extensive tuning. Future studies could explore adaptive k-parameter selection to address these limitations.

6
Conclusion

This study presents MS-DGCNN++, a novel hierarchical multiscale dynamic graph convolutional network that significantly advances tree species classification from terrestrial LiDAR point clouds. Our key innovation lies in replacing parallel multi-scale processing with semantically meaningful hierarchical feature extraction, incorporating scale-specific engineering at the local, branch, and canopy levels with cross-scale information propagation.

Experimental validation across four datasets demonstrated substantial improvements over state-of-the-art methods. MS-DGCNN++ achieves 93.53% accuracy on STPCTLS (surpassing previous best by 3.16%), 67.25% on FOR-species20K (6.1% improvement), and competitive performance on ModelNet benchmarks (94.05% on ModelNet10, 93.15% on ModelNet40). The comprehensive ablation study on the STPCTLS dataset provides practical guidance for optimal
k
-NN parameter selection, with MS-DGCNN++(5,20,30) achieving an overall accuracy of 94.96% as the best performance over all other state-of-the-art models.

The parameter efficiency of the method compared to transformer-based approaches makes it practical for real-world deployment while maintaining competitive accuracy.

The proposed data augmentation strategy, specifically designed for tree point clouds, contributes significantly to the performance improvements of all trained models in STPCTLS, addressing the inherent variability in LTS data.

Beyond tree species classification, the generalizability of MS-DGCNN++ to standard 3D object recognition benchmarks establishes it as a versatile solution for various point cloud processing applications.

Future research directions include exploring adaptive neighborhood selection mechanisms, integrating multimodal data fusion, and extending the framework to other forestry applications, such as tree health assessment and growth monitoring.
