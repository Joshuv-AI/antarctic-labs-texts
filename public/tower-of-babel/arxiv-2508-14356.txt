Efficient Size Constraint Community Search over Heterogeneous Information Networks
Xinjian Zhang, Lu Chen, Chengfei Liu, Rui Zhou, Bo Ning

Abstract
. The goal of community search in heterogeneous information networks (HINs) is to identify a set of closely related target nodes that includes a query target node. In practice, a size constraint is often imposed due to limited resources, which has been overlooked by most existing HIN community search works. In this paper, we introduce the size-bounded community search problem to HIN data. Specifically, we propose a refined ( k , 𝒫 ) \scriptstyle(k,\mathcal{P}) -truss model to measure community cohesiveness, aiming to identify the most cohesive community of size s \scriptstyle s that contains the query node. We prove that this problem is NP-hard. To solve this problem, we develop a novel B&B framework that efficiently generates target node sets of size s \scriptstyle s . We then tailor novel bounding, branching, total ordering, and candidate reduction optimisations, which enable the framework to efficiently lead to an optimum result. We also design a heuristic algorithm leveraging structural properties of HINs to efficiently obtain a high-quality initial solution, which serves as a global lower bound to further enhance the above optimisations. Building upon these, we propose two exact algorithms that enumerate combinations of edges and nodes, respectively. Extensive experiments on real-world datasets demonstrate the effectiveness and efficiency of the proposed methods.

Our community model
. We first introduce a refined

-truss model, which serves as a cohesiveness measure. Then, we discuss the size constraint and the optimisation objective.

Triangle connected

\scriptstyle\mathcal{P}
-pair. A set of
\scriptstyle\mathcal{P}
-pairs is called a

-truss if every

-pair in the set forms at least
\scriptstyle k

Based on the definition, given a query node
\scriptstyle q

Such a structure may not be ideal for the community search problem. Therefore, to further enhance the effectiveness of communities searched from a query node, we introduce the triangle connectivity into the
\scriptstyle(k,\mathcal{P})
-truss model
(
Yang et al. 2020
)
. For a set of
\scriptstyle\mathcal{P}
-pairs that is a
\scriptstyle(k,\mathcal{P})
-truss, it further enforces that every two triangles either share one
\scriptstyle\mathcal{P}
-pair or can be reached by a sequence of triangles s.t. the adjacent triangles in the sequence share one
\scriptstyle\mathcal{P}
-pair. By doing so, one query node can be part of multiple communities, and the community could be denser, making the community model more effective.

Size constraint and optimisation objective

\scriptstyle k^{*}

-truss containing the query node. We shorten our studied problem, i.e., the

-truss problem without a size constraint.

Technical gaps
. Although we can get ideas from
(
Yao and Chang 2021
)
and
(
Zhang et al. 2023
)

In fact, HINs possess certain desirable properties that can accelerate the search, which will be explored in this paper. Second, all existing works use an inclusion-and-exclusion-based node set generation framework, which is efficient for generating all combinations of
\scriptstyle n

\scriptstyle s

\scriptstyle n

\scriptstyle n

\scriptstyle n

Our solution
. To fill the above research gaps, we present a novel branch-and-bound algorithm for the SCSH problem based on the lexicographic generation framework. This naturally bounds the recursion depth in terms of
\scriptstyle s
. Such an improvement allows us to attempt both the edge set and the node set enumeration-based approaches.
In terms of bounding techniques, we first take advantage of the HIN property, i.e., taking polynomial time to get large pairwise connected
\scriptstyle\mathcal{P}
-pairs, to derive near-optimum results, serving as a lower bound.
This lower bound can greatly reduce the candidate size. We then devise novel and effective upper bounds for both node set and edge set enumeration approaches, taking into account triangle connectivity.
For the edge set enumeration, we propose an upper bound by enlarging the trussness of the edge in the partial result with the minimum trussness, considering the maximum triangle connected triangles that can be included from the candidate set.
However, the above upper bound cannot be applied to the node set enumeration approach.
This is because, for node set enumeration, we can remove some edges with low trussness from the node set induced subgraph to improve the result, i.e., deriving an upper bound on edges with minimum trussness does not make sense here.
We alternatively seek to increase the trussness of the high trussness edges in the partial result, in order to satisfy the necessary condition for improving the overall trussness and to derive a reasonable upper bound. Using the lower and upper bounds, we can effectively and efficiently bound the search towards the optimum result. Furthermore, we propose a novel total search order and branching strategy. Together with all these optimisations, the edge set generation based algorithm runs in
\scriptstyle\mathcal{O}(|N(q,G_{P})|\binom{|E(G)|}{\frac{(s-1)(s-2)}{2}}|E(G_{P})|^{1.5})
with the most advanced upper bounds and the node set generation based algorithm runs in
\scriptstyle\mathcal{O}(|N(q,G_{P})|\binom{|V(G)|}{s-2}|E(G_{P})|^{1.5})
with a reasonable upper bound, where
\scriptstyle G_{P}
is the virtual graph consisting of all
\scriptstyle\mathcal{P}
-pairs in HIN.
In practice, the node set generation approach runs one order of magnitude faster than the edge set generation approach, and the edge set generation approach is, on average, 40% faster than the method adapted from SOTA.

State-of-the-art framework

Size-bounded community search maximising cohesiveness has been explored extensively in homogeneous networks, particularly for the
\scriptstyle k
-core and
\scriptstyle k

We first retrace the methodological development of existing approaches and then discuss the rationales for the algorithms proposed for our problem.

Opportunities

First, although STOAs have made great efforts to prune unpromising recurrences, they only explore homogeneous graph properties. We explore HIN properties, which lead to an effective heuristic algorithm that can quickly find a near-optimal result.

The new framework for SCSH

Due to the NP-hardness of our studied problem, no polynomial algorithm exists for solving it.
As shown in SOTAs, we have to systematically try combinations of target nodes of size
\scriptstyle s

4.3.
Bounding techniques

In this subsection, we present how to utilise a known result (the heuristic result discussed previously), i.e., a (trussness) lower bound, to bound the search tree by comparing it to an upper bound.

Rationale
. Given a non-trivial recursion state with
\scriptstyle C
and
\scriptstyle R
(
\scriptstyle|C|<s
and
\scriptstyle|R|\geq s-|C|
), we want to optimistically estimate the best trussness after moving arbitrary
\scriptstyle s-|C|
nodes from
\scriptstyle R
to
\scriptstyle C
, i.e., an upper bound for this recursion state, denoted by
\scriptstyle UB(C,R)
.
Clearly, as long as
\scriptstyle UB(C,R)
is admissible, that is, 1)
\scriptstyle UB(C,R)
is no less than any results
1
1

1

in terms of trussness
induced by the current recursion state, and 2)
\scriptstyle UB(C,R)
is no greater than the current lower bound, we can stop branching at the current recursion state. Algorithm
2
can explore (backtrack to) other recursion states that cannot be bounded.

As discussed, SOTAs all involve the idea above. In
(
Yao and Chang 2021
)
, the main idea is as follows. It is assumed that 1)
\scriptstyle s
-
\scriptstyle|C|
nodes from
\scriptstyle R
that are mostly connected to
\scriptstyle C
would be added to
\scriptstyle C

\scriptstyle C
with the minimum coreness. The process of deriving the upper bound is dynamic, i.e., when all the nodes in
\scriptstyle C
with minimum coreness have been increased by 1, the remaining edges will be added to the minimum coreness nodes until all incident edges are consumed. After that, the updated minimum coreness among all nodes in
\scriptstyle C
serves as the upper bound.

On the other hand, STOA for truss-based model
(
Zhang et al. 2023
)
is mainly based on the current trussness of
\scriptstyle C
and the number of nodes in
\scriptstyle R
. It is based on the fact that when moving a node from
\scriptstyle R
to
\scriptstyle C
, the trussness of
\scriptstyle C
will be increased by at most
\scriptstyle 1
. Then, given the trussness of
\scriptstyle C
,
(
Zhang et al. 2023
)
computes how many nodes are needed, and if
\scriptstyle R
cannot provide sufficient nodes, the branch can be bounded. The admissibility of this bound lies in the fact that not every node can increase the trussness.

Clearly, the concept presented in
(
Yao and Chang 2021
)
is more refined, as it considers necessary structural conditions based on the cohesive subgraph model. If it can be adapted to our problem, we could attain a much tighter bound compared to
(
Zhang et al. 2023
)
.

We shall present two non-trivial upper bounds—one for ESG and one for NSG.
As mentioned, ESG is more natural when deriving the upper bound using the idea of
(
Yao and Chang 2021
)
. Our contributions for designing ESG upper bounds are twofold: 1) to address the challenges induced by the cohesiveness difference, and 2) to address the inconsistency between edge inclusion and node inclusion (i.e., adding an edge may not increase the size of
\scriptstyle C

Then, we propose a novel upper bound for NSG, which is more challenging since the results of our model are edge-induced graphs, i.e., when NSG generates a result
\scriptstyle C
(a node set), it is not necessarily true that all edges in
\scriptstyle G_{P}[C]

ESG upper bound computation
. The ESG upper bound is based on the accurate trussness for edges in
\scriptstyle C

\scriptstyle R

\scriptstyle C

The trussness for each edge in
\scriptstyle C

We can partition edges according to their trussness.
Our proposed upper bound starts with the minimum trussness edges in
\scriptstyle C
denoted by
\scriptstyle E_{min}
with trussness of
\scriptstyle\tau_{\triangle}(C)

\scriptstyle\tau_{\triangle}(C)

\scriptstyle C

To establish the optimistic while tight upper bounds, we assume edges in
\scriptstyle R
which can contribute to
\scriptstyle R
the most

(c-triangle), i.e., triangles consisting of edges with trussness no less than
\scriptstyle\tau_{\triangle}(C)
, will be added to
\scriptstyle C
. We also assume that all these capable triangles will contribute to
\scriptstyle E_{min}
up to the time. Additionally, since including an edge may or may not introduce a new node, the optimistic number of c-triangles is derived as follows.

Edges with no extra nodes
. For all these edges that form c-triangles with
\scriptstyle C
, newly induced c-triangles are assumed to contribute to the trussness of
\scriptstyle E_{min}
up to the time.

Edges with extra nodes
. For edges with extra nodes, for each of such extra node
\scriptstyle u
, we compute its score in terms of the number of c-triangles that
\scriptstyle u
contributes to
\scriptstyle C
(at least one of the nodes of such c-triangle is in
\scriptstyle V(C)

\scriptstyle C\cup R

\scriptstyle G_{P}
. For the top
\scriptstyle s-|V(C)|

\scriptstyle C
and contribute to the support of
\scriptstyle E_{min}
up to the time.

For these optimistically estimated c-triangles assumed to be added to
\scriptstyle C
, each edge in
\scriptstyle E_{min}
will consume one of the c-triangles up to the time.
When the support of every edge in
\scriptstyle E_{min}
has been increased by 1, the estimated upper bound is increased by 1.
Then
\scriptstyle E_{min}
is updated by including edges with minimum trussness up to the time.
We repeat this process until all the optimistically estimated c-triangles have been consumed.

Admissibility
. The above process naturally follows the trussness definition to optimistically estimate the trussness of enlarged
\scriptstyle C
. In fact, 1) the number of c-triangles assumed to be added is an overestimation, 2) not all the c-triangles happen to contribute to the edge with the minimum trussness, and 3) after enlarging
\scriptstyle C
,
\scriptstyle C
contains more edges while these edges are assumed to have high trussness.

Computational cost
.
The dominant cost of computing the upper bound is the number of triangles in
\scriptstyle C\cup R
induced subgraph of
\scriptstyle G_{P}
(edge induced subgraph), which is bounded by
\scriptstyle\mathcal{O}(|C\cup R|^{1.5})
.

Grouped ESG upper bound computation
. Given two edge sets
\scriptstyle C
and
\scriptstyle C^{\prime}
where
\scriptstyle C^{\prime}\subseteq C
, we have the fact that
\scriptstyle min\{C^{\prime}\}
is no less than
\scriptstyle min\{C\}
in terms of edge trussness.
This implies that the ESG upper bound computation can be applied to every subset of
\scriptstyle C
(denoted by
\scriptstyle C^{\prime}
) while the corresponding optimistically estimated c-triangles shall be constructed according to
\scriptstyle C^{\prime}
and
\scriptstyle R
.
Since each such
\scriptstyle C^{\prime}
leads to a feasible upper bound, by trying different
\scriptstyle C^{\prime}
, we may have a tighter lower bound.
Especially in the case where
\scriptstyle C^{\prime}
contains low trussness edges while weakly connecting to
\scriptstyle R
.
Observed this, we follow
(
Yao and Chang 2021
)
and apply edge upper bound for each subset of
\scriptstyle C^{\leq\tau}\in C
s.t. the maximum trussness of edges in
\scriptstyle C^{\leq\tau}\in C
is no greater than each
\scriptstyle\tau\in[\tau_{min}(C),\tau_{max}(C)]
.
The minimum upper bound among these serves as the grouped ESG upper bound.

Computational cost
. It calls the computation of edge upper bound at most
\scriptstyle|C|
times, leading to a total complexity of
\scriptstyle O(|C|\cdot\mathrm{ESG()})
, where
\scriptstyle\mathrm{ESG()}
is the complexity of ESG upper bound computation.

Potential of tightening the upper bound
. Since our search framework progressively enlarges
\scriptstyle C
via the depth-first conversion, we pass down the current tightest upper bound and compare it to the edge-grouped upper bound and see if the upper bound can be further refined.

ESG upper bound summary
. Given the fact that all the discussed upper bounds are feasible (including
(
Zhang et al. 2023
)
), we always apply the tightest one.

4.3.2.
Upper bound for NSG

Unfortunately, our proposed ESG upper bound does not work for NSG.
This is because these upper bounds are estimated by increasing the minimum edge trussness. In ESG, these bounds work since once an edge is included in
\scriptstyle C
, it cannot be removed from
\scriptstyle C
.
This is untrue when
\scriptstyle C
is a set of nodes because edges with low trussness could be removed, and only nodes added to
\scriptstyle C
cannot be removed.
Therefore, we shall devise upper bounds by exploring other properties.

Rationale
. Reminder that according to Definition
2.9
, the trussness of a node
\scriptstyle u
for
\scriptstyle C
is the maximum edge trussness for edges incident to
\scriptstyle u
in
\scriptstyle G_{P}[C]
. As such, to estimate an upper bound for NSG, we shall assume that triangles are added to edges incident to the node with the maximum trussness, which is totally different from edge-based upper bounds.

Besides, to secure the optimistic estimation, we shall consume the least number of triangles so that the trussness of a node can be increased. Luckily, one of the properties of the truss model provides us with such an opportunity, as shown below.

Property 1
.

For a (
\scriptstyle k,\mathcal{P}
)-truss, there must be at least
\scriptstyle\frac{k(k-1)}{2}
edges with
\scriptstyle\tau(u,v)\geq k
in
\scriptstyle G_{P}
.

Based on the above property, in order to increase the trussness of a subgraph with trussness of
\scriptstyle k
optimistically, we just need to ensure that there are
\scriptstyle\frac{(k+1)k}{2}
edges that are with trussness of
\scriptstyle k+1
after adding some triangles.

We are ready to show the upper bound for NSG given a non-trivial recursion state with
\scriptstyle C
and
\scriptstyle R
, where both
\scriptstyle C
and
\scriptstyle R
contain nodes only.

NSG upper bound
. The upper bound is based on the accurate
\scriptstyle\tau_{\triangle}(C)
in
\scriptstyle G_{P}[C]
, and how
\scriptstyle R
can maximally increase
\scriptstyle\tau_{\triangle}(C)
.

Capable triangle and edge of NSG
. A triangle is called capable if it is 1) formed by edges with trussness no less than
\scriptstyle\tau_{\triangle}(C)
, and 2) triangle reachable from
\scriptstyle C
via triangles satisfying condition 1). A capable edge is defined similarly to the capable triangle.

Optimistic number of capable triangles
.
For each node
\scriptstyle u\in R
, let its score be the number of capable triangles that
\scriptstyle u
is involved in
\scriptstyle G_{P}[C\cup R]
.
For the top
\scriptstyle s-|C|
nodes with the highest score in
\scriptstyle R
, they are assumed to move to
\scriptstyle C
, and the sum of their scores is the optimistic number of triangles that contribute to nodes in
\scriptstyle C
, denoted by
\scriptstyle|\triangle_{opt}|
.

Optimistic number of edges
. Additionally, we also need the top
\scriptstyle s-|C|
nodes in
\scriptstyle R
that can potentially contribute the highest number of capable edges, denoted by
\scriptstyle|E_{opt}|
.
We need
\scriptstyle|E_{opt}|
because we assume that edges incident to the
\scriptstyle s-|C|
nodes exhibit sufficiently high trussness. They may directly contribute to nodes in
\scriptstyle C
with the minimum trussness.

Unifying optimistic triangles and edges
. To ensure an optimistic result, we assume that there exists a size
\scriptstyle s-|C|
node set that is optimistic in terms of both capable edges and triangles.

How triangles and edges are optimistically consumed
. Based on the above discussion, given
\scriptstyle C
with trussness of
\scriptstyle k=\tau_{\triangle}(C)
, it is not in
\scriptstyle k+1
truss since it has less than
\scriptstyle\frac{k(k+1)}{2}
edges with trussness of
\scriptstyle k+1
shown in
Property

1

\scriptstyle\tau_{\triangle}(C)
, i.e.,
\scriptstyle k
.
Clearly, after adding the discussed
\scriptstyle s-|C|
nodes, it brings
\scriptstyle|E_{opt}|
edges with sufficiently large trussness. As such, we need at least
\scriptstyle\frac{k(k+1)}{2}-|E_{opt}|
(assuming
\scriptstyle|E_{opt}|
is smaller than
\scriptstyle\frac{k(k+1)}{2}
)
2

2

\scriptstyle k
till
\scriptstyle\frac{k(k+1)}{2}>|E_{opt}|
.

\scriptstyle k+1
to increase the trussness of
\scriptstyle C
by
\scriptstyle 1

\scriptstyle\triangle_{opt}
are used to increase the trussness of edges in
\scriptstyle G_{P}[C\cup R]
whose trussness is closest to
\scriptstyle k+1

\scriptstyle\triangle_{opt}
is consumed. If all triangles in
\scriptstyle\triangle_{opt}

Admissibility
. The admissibility is clear. First, the condition that we increase the trussness of

Due to the fact that we increase the trussness of edges with the maximum trussness,

Computational cost
. The time complexity of NSG upper bound is also dominated by triangles in
\scriptstyle G_{P}[C\cup R]

\scriptstyle\mathcal{O}(|E(G_{P}[C\cup R])|^{1.5})

4.4.
Branching strategy

We present a novel branching strategy in this subsection.

Rationale and SOTA
. Given a recursion state with
\scriptstyle C
and
\scriptstyle R
, and two nodes
\scriptstyle u
and
\scriptstyle v
in
\scriptstyle R
, if the cohesiveness of every result led by branching at
\scriptstyle v
with
\scriptstyle R\setminus\{u\}
is no more than that of the result by replacing
\scriptstyle u
to
\scriptstyle v
, then we can avoid branching at
\scriptstyle v
in the current recursion state while preserving the optimum results.

For both core and truss-based models, we can examine whether
\scriptstyle N(v)\subseteq N(u)
holds in
\scriptstyle G[C\cup R]
to see if
\scriptstyle v
can be avoided or not. This is referred to
\scriptstyle u
dominating
\scriptstyle v
. In this paper, we call such dominance as
\scriptstyle u
edge-dominating
\scriptstyle v
in
\scriptstyle G[C\cup R]
, denoted by
\scriptstyle u\succeq_{E}v
.

Based on the above discussion, within their framework, when branching at a node
\scriptstyle u
, every node
\scriptstyle v
dominated by
\scriptstyle u
will not be branched, and branches including each pair of
\scriptstyle\{u,v\}
will be attempted, in addition to the normal inclusion and exclusion branches.

We advance existing ideas in twofold. First, we propose a triangle-based dominance approach, which can be used to expand the node set that can be dominated by a node. Second, we propose a novel branching strategy that aims to minimise the number of branches as much as possible for each recursion state.

Triangle based dominance
. Given a recursion state
\scriptstyle C
and
\scriptstyle R
, let
\scriptstyle\triangle(u)
and
\scriptstyle\triangle(v)
denote the set of triangles that
\scriptstyle u
and
\scriptstyle v
involve in
\scriptstyle G[C\cup R]
, if
\scriptstyle\triangle(v)\subseteq\triangle(u)
,
\scriptstyle u
is triangle-dominating
\scriptstyle v
in
\scriptstyle G[C\cup R]
denoted by
\scriptstyle u\succeq_{\triangle}v
.

The above discussion is also correct under the context of
\scriptstyle G_{P}
.

Combining edge and triangle dominance
. It is trivial to see that triangle dominance has the same effect as edge dominance. However, since the conditions of triangle dominance are stricter, we must apply it carefully. For a node
\scriptstyle u\in R
, we first generate a node set that can be dominated by
\scriptstyle u
using edge-dominance, denoted by
\scriptstyle\Phi_{E}(u)
. Then, for nodes that cannot be edge-dominated by
\scriptstyle u
but have common neighbours with
\scriptstyle u
, we apply triangle-dominance to generate a node set that can be dominated by
\scriptstyle u
, denoted by
\scriptstyle\Phi_{\triangle}(u)
. Then
\scriptstyle\Phi(u)=\Phi_{E}(u)\cup\Phi_{\triangle}(u)
is set of nodes that can be dominated by
\scriptstyle u
.

Effectiveness
. It is easy to see
\scriptstyle\Phi(u)\supseteq\Phi_{E}(u)
always holds. This indicates that, using our proposed dominance, each node can potentially branch at fewer nodes in
\scriptstyle R
.

Now, we are ready to propose the novel branch strategy.

rule 1
.

Given a recursion state with
\scriptstyle C
and
\scriptstyle R
, select a node with the maximum dominance in
\scriptstyle R
, i.e.,
\scriptstyle u
is
\scriptstyle\argmax_{v}\{\Phi(v)|v\in R\}
. Then, for this recursion state, we only branch at each node
\scriptstyle u^{\prime}
in
\scriptstyle R\setminus\Phi(u)
,i.e., each induced subproblem has an input of
\scriptstyle C\cup\{u^{\prime}\}
and
\scriptstyle R
.

Rule

1
is a branching rule since it does not remove the dominated nodes from
\scriptstyle R
for the subproblems induced by the current recursion state. Its correctness is clear based on the discussed dominance.

Computational cost
. It is evident that the time complexity of computing triangle-based dominance is greater than that of edge-based dominance. Identifying all nodes involved in triangles requires
\scriptstyle O(|E(G_{P}[C\cup R])|^{1.5})
time, which dominates the overall cost.

.

\scriptstyle a_{3}

\scriptstyle a_{4}
dominates
\scriptstyle\{a_{1},a_{2},a_{3},a_{5}\}
, and
\scriptstyle a_{10}
dominates
\scriptstyle a_{11}

\scriptstyle a_{4}
is chosen to reduce the number of branches. Since all these dominances are triangle-based, this example does not clearly highlight the effectiveness of triangle-based dominance over edge-based dominance. But we can consider a simple modification: change the edge
\scriptstyle(a_{9},a_{7})
to
\scriptstyle(a_{9},a_{5})

\scriptstyle a_{10}

\scriptstyle a_{9}

\scriptstyle a_{9}

\scriptstyle(a_{9},a_{5})
does not participate in any triangle. As a result,
\scriptstyle\triangle(a_{9})\subseteq\triangle(a_{10})

\scriptstyle a_{9}

\scriptstyle a_{10}

\scriptstyle a_{10}

Triangle-based dominance can be applied to ESG. Due to the similarity, we do not repeat it.

4.5.
A total search order and early termination

Thanks to the new framework, we can enforce a total search order for our algorithm, which can improve time complexity as well as bring early termination opportunities. This idea is popular and critical for many other problems, such as maximal clique and biclique enumeration. We now introduce it to the size-bounded community search problem.

Our proposed ordering
\scriptstyle\mathcal{O}
. We propose a distance-first, truss-second-order. I.e., for
\scriptstyle R
that cannot be pruned, we first sort nodes in
\scriptstyle R
in non-decreasing order in terms of their distance to the query node
\scriptstyle q
. Then, for the nodes with the same distance, nodes are then sorted in non-increasing order in terms of their trussness in
\scriptstyle G_{P}[C\cup R]
.

It is trivial to see that using
\scriptstyle\mathcal{O}
as well as our introduced new framework, Algorithm
2
can terminate much earlier if one of the following conditions is satisfied in order.

Stop condition 1
.

For the current
\scriptstyle v
, if
\scriptstyle dist(v,q)>1
, Algorithm
2
can terminate.

Stop condition 2
.

For the current
\scriptstyle v
, if
\scriptstyle\tau_{\triangle}(v)
in
\scriptstyle G_{P}[C\cup R]
is no greater than
\scriptstyle\tau_{\triangle}(C^{*})
, Algorithm
2
can terminate.

Stop condition 3
.

If the condition in our bounding technique is satisfied, Algorithm
2
can terminate.

The correctness of the above conditions is clear. Later, when analysing the time complexity,
Stop condition
1 is critical for reducing the time complexity.

rule 2

Related Works

In this section, we review three categories of related works.

Size-bounded community search in homogeneous graphs.
In homogeneous graphs, many problems are related to community size, which can be broadly classified into the following categories. First, some studies impose explicit size constraints and aim to find the most cohesive communities satisfying conditions.
For example, in the
\scriptstyle k
-core model, the goal is to maximise
\scriptstyle k
under a given size bound.
(
Sozio and Gionis 2010
)
is the first to introduce an upper bound on community size, proposing two greedy algorithms to find the near-optimal minimum-degree subgraph.
Recently,
(
Yao and Chang 2021
)
extends this by introducing a size range
\scriptstyle[l,h]
and proposes both an improved greedy strategy and an exact algorithm.

(
Zhang et al. 2023
)
follows a similar approach but adopts the
\scriptstyle k
-truss model instead of the
\scriptstyle k
-core. Second, some approaches fix cohesiveness and aim to find the smallest possible community satisfying it.
(
Li et al. 2020
)
develops the PSA algorithm based on the
\scriptstyle k
-core, while
(
Zhu et al. 2019
)
focuses on minimising
\scriptstyle k
-truss-based communities. Finally, some studies
(
Liu et al. 2021
)
jointly enforce both size and cohesiveness constraints (without necessarily maximising
\scriptstyle k
or minimising size).

Community search in HINs.

(
Fang et al. 2021
)
categorises heterogeneous graphs into two types: bipartite graphs and general HINs. In recent years, bipartite graphs have gained increasing attention, leading to the development of various cohesive subgraph models, including the (
\scriptstyle\alpha
,
\scriptstyle\beta
)-core
(
Liu et al. 2020
)
,
\scriptstyle k
-bitruss
(
Wang et al. 2022
)
, and biclique
(
Lyu et al. 2020
;
Chen et al. 2021
;
Yu et al. 2025
)
. Based on these models, numerous community search methods have been proposed
(
Wang et al. 2021a
;
Wang et al. 2021b
;
Abidi et al. 2022
)
. For general HINs, several models have been introduced to support community search, such as the (
\scriptstyle k
,
\scriptstyle\mathcal{P}
)-core
(
Fang et al. 2020
)
, (
\scriptstyle k
,
\scriptstyle\mathcal{P}
)-truss
(
Yao and Chang 2021
)
, motif-clique
(
Hu et al. 2019
;
Zhou et al. 2024
)
, relational community
(
Jian et al. 2020
;
Liu et al. 2025
)
, and densest subgraph
(
Chen et al. 2023
)
. In addition, some methods focus on extra-specific objectives like significance
(
Liu et al. 2024
)
and influence
(
Zhou et al. 2023
)
.

Size-bounded community search in HINs.
So far, only
(
Zhang et al. 2024
)
has addressed size-bounded community search in bipartite graphs, which is a special case of HINs. This work is primarily based on the
\scriptstyle(\alpha,\beta)
-core model. Since the model involves two cohesiveness parameters, it is difficult to compare the cohesiveness of different cores (e.g., a
\scriptstyle(4,2)
-core vs. a
\scriptstyle(3,3)
-core). As a result,
(
Zhang et al. 2024
)
treats cohesiveness as a constraint rather than an optimisation objective.

7.
Conclusion

In this paper, we introduce the most cohesive size-bounded community search problem for HIN data, which is known to be NP-hard. To tackle this problem, we develop the
kcB&B
framework, which naturally generates
\scriptstyle s
node sets with a complexity of
\scriptstyle\mathcal{O}^{*}(\binom{n}{s})
. Based on this framework, two exact algorithms are proposed that enumerate edge sets and node sets, respectively. To enhance efficiency, we first develop a polynomial-time algorithm to find a feasible solution as a global lower bound by leveraging the properties of HINs. Additionally, based on triangles, we develop bounding and reduction techniques for both edge-based and node-based approaches, which, when combined with the lower bound, can significantly reduce the search space. In addition,
kcB&B
enables early termination and branching strategies, further enhancing overall efficiency. Extensive experiments validate the effectiveness and efficiency of the proposed methods.
