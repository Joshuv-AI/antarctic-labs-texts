Identifying good forecasters via adaptive cognitive tests


Abstract
Assessing forecasting proficiency is a time-intensive activity, often requiring us to wait months or years before we know whether or not the reported forecasts were good. In this study, we develop adaptive cognitive tests that predict forecasting proficiency without the need to wait for forecast outcomes. Our procedures provide information about which cognitive tests to administer to each individual, as well as how many cognitive tests to administer. Using item response models, we identify and tailor cognitive tests to assess forecasters of different skill levels, aiming to optimize accuracy and efficiency. We show how the procedures can select highly-informative cognitive tests from a larger battery of tests, reducing the time taken to administer the tests. We use a second, independent dataset to show that the selected tests yield scores that are highly related to forecasting proficiency. This approach enables real-time, adaptive testing, providing immediate insights into forecasting talent in practical contexts.

Adaptive cognitive tests

Researchers and practitioners have long relied on human judges to provide information about the likelihood of future events. These judgments are especially useful for non-repeatable events about, e.g., geopolitics or popular culture, where there is little existing data that can be used to build predictive models of the phenomenon. Even when data do exist to build predictive models, human judgments can be just as accurate
(
Benjamin et al. 2023
;
Zellner et al. 2021
)
. It is increasingly easy to obtain human forecasts remotely, so human judgments can be less costly than the expertise and technology required for predictive modeling, with little sacrifice in accuracy.

When recruiting human forecasters, we immediately take interest in individual differences among the forecasters. We want to focus our resources on forecasters who are exceptionally accurate and involved, which can allow us to select the best forecasters to rely on moving forward, or upweight their predictions in when aggregating groups of judgments
(
Himmelstein et al. 2023
)
. But assessment of forecasting accuracy takes time: it will often take months or years for forecasting questions have resolved, meaning it will often take months or years before we know which forecasters provide accurate forecasts. One solution to this dilemma involves proxy scoring
(e.g.,
Himmelstein et al. 2023a
;
Witkowski et al. 2017
)
, whereby we use assumed outcomes of questions before those outcomes are truly known, often based on a crowd consensus. We consider a second solution in this paper, which involves the use of cognitive tests to predict forecasting accuracy.

Cognitive tests are advantageous because they can be quickly administered and scored. Past research has shown that the tests are correlated with forecasting accuracy
(
Himmelstein et al. 2021
;
Mellers et al. 2015
)
, so that we can quickly obtain information about which forecasters will be accurate and which will be inaccurate. But there are many potential cognitive tests that we could use, without much information about which tests we should use. Further, specific cognitive tests could serve specific purposes for predicting forecasting accuracy. For example, certain cognitive tests can identify forecasters who may lack proficiency, while others distinguish top-tier forecasters, allowing for tailored assessments based on skill level. In this case, if we administer a large set of cognitive tests to all forecasters, then we are wasting resources because each test will only be relevant to assessing some forecasters. Further, we may want more information about good performers as compared to bad performers, so that good performers should take more cognitive tests than bad performers. We need ways to clarify which cognitive tests are good for which individuals, and to tailor administered tests to each individual’s performance.

This paper introduces adaptive cognitive testing procedures, using psychometric models to tailor cognitive tests to individual forecasters and to predict their forecasting skill levels. The ideas of selecting tests and tailoring tests to individual test-takers are related to adaptive testing procedures that have been developed in the context of item response modeling
(e.g.,
Drasgow & Olson-Buchanan 1999
;
Magis & Raîche 2012
;
Meijer & Nering 1999
;
1 1
;
Wainer 2000
)
. Many readers will have experienced adaptive tests that measure readiness for university studies or for graduate school. We extend these traditional adaptive testing procedures to the cognitive testing domain, and we then apply the procedures to predict forecasting accuracy across two sets of forecasters. We show how the procedures can yield accurate forecaster assessments in reduced amounts of time, and we also obtain results about which cognitive tests are better or worse for predicting forecasting accuracy.

In the pages below, we first give a conceptual overview of traditional adaptive testing methods. We then discuss how the methods can be extended to cognitive testing, and we describe an item response model that can handle scores that arise from cognitive tests. Next, we apply the model to two datasets, identifying which key cognitive tests most effectively predict forecasting skill, ultimately reducing testing time while maintaining accuracy. Next, we develop a fully adaptive testing procedure that tailors the sequence of cognitive tests to forecasters’ performance, and we show that the procedure can reduce the time spent on cognitive testing. Finally, we discuss limitations and potential future developments.

1
Adaptive Testing Overview

In this section, we give a brief conceptual overview of adaptive testing. We then deal with technical detail in the following section. The models that we consider are related to some that have been previously applied to forecasting by
Merkle et al. 2016
;
Merkle et al. 2017
and
Bo et al. 2017
, though those authors did not consider adaptive tests.

The idea of adaptive testing is to choose an item to present to a person during a test, based on known item characteristics and on the person’s previous responses during the test. If you have taken standardized tests like the GRE or GMAT, you may have experienced adaptive testing before. Adaptive testing is based on the notion that different items can provide different amounts of information about different individuals. For example, if a person has already answered many items incorrectly, then we do not learn much by giving that person a difficult item. We already know that the person will probably answer incorrectly. Similarly, if a person has already answered many items correctly, we do not learn much by giving that person an easy item. By adaptively presenting items that are uniquely suited to each individual, we can potentially obtain precise estimates of their proficiencies using shorter tests.

Adaptive testing works by first estimating item properties during an “item calibration” step. Calibration involves determining each test item’s difficulty and effectiveness across skill levels, which is used in later steps of the adaptive testing procedure. In this first step, no adaptive testing is used. We simply administer the items to a large group of representative people, fit item response models to their data, and then treat the resulting item parameter estimates as known.
Once we have item parameter estimates, we can use those to compute item
information functions
. These functions summarize the amount of information that each item provides about participants of different proficiencies.
They formalize the ideas presented in the previous section, where a difficult item provides more information about a person of high proficiency as compared to a person of low proficiency, and vice versa. Once we have the item information functions, they can be used to adaptively select items. That is, at each point of a test, we can compute an estimate of a person’s proficiency. With that estimate, we can use item information functions to determine which of the remaining items should provide the most information about the person.

Item information functions are related to the Fisher information matrix that is widely used to compute standard errors of maximum likelihood estimates. The intuition is that higher item information implies smaller standard errors, which implies that we gain more precise estimates of a person’s proficiency.
From a technical standpoint, item information functions involve second derivatives of an item response model’s log-likelihood, where the derivatives are taken with respect to the person proficiency parameter (this parameter is often denoted
\theta
in item response models). These derivatives have analytic forms for many item response models
(e.g.,
Wang et al. 2022
)
, which makes them suited for the adaptive testing purposes considered here.

2
Application to Forecasting

The discussion so far has focused on individual items administered in a single test. But for many cognitive tests, only an overall score is recorded. In this case, each cognitive test is treated as an individual item, with information functions indicating which tests are best suited to high- and low-proficiency forecasters.

We immediately encounter the problem of choosing a suitable item response model. For many cognitive tests, each person’s score is an integer that could potentially be treated as continuous. The simplest thing to do would be to treat the scores as continuous and fit a normal model, where the model has item and person parameters similar to traditional IRT models. But this ignores the fact that most cognitive tests have a predefined lower and upper bound.

To better characterize our bounded test scores, we employ a beta-distributed item response model
(
Noel & Dauvier 2007
)
. The beta distribution is particularly suited for bounded cognitive test scores, where a defined score range typically exists. The model’s technical details remain similar to traditional item response models, except the model likelihood involves the beta distribution instead of the binomial distribution. We specifically use a variation of the
Noel & Dauvier 2007
model that was recently described by
Molenaar et al. 2022
. For general information about modeling data via the beta distribution, see
Smithson & Verkuilen 2006
.

2.1
Model Definition

Let
y_{ij}
be the score of participant
i
on cognitive test
j
, where the scores have been scaled to lie in
[0,1]
. Let
z_{ij}
be a 3-category ordinal variable indicating whether
y_{ij}
is at a boundary or between the boundaries (1 if
y_{ij}=0
; 2 if
y_{ij}
is between 0 and 1; 3 if
y_{ij}=1
). Our model has two parts: one part that predicts
z_{ij}
, and one part that predicts values of
y_{ij}
between 0 and 1. As further described below, some parameters are shared between the two parts of the model.

Submodel for
z_{ij}

Following
Molenaar et al. 2022
, we use a graded response model to predict the chance that a person’s score is at the lower boundary, the upper boundary, or in between. This part of the model can be written as

P(z_{ij}\leq c|\theta_{i})=\text{logit}^{-1}(\gamma_{jc}-\alpha_{j}\theta_{i})\ \ c=1,2

where
\gamma_{j1}<\gamma_{j2}
. We obtain probabilities of assuming individual categories by subtracting successive terms and making use of the fact that the three probabilities must sum to 1:

\displaystyle P(z_{ij}=1|\theta_{i})

\displaystyle=\text{logit}^{-1}(\gamma_{j1}-\alpha_{j}\theta_{i})

(1)

\displaystyle P(z_{ij}=2|\theta_{i})

\displaystyle=\text{logit}^{-1}(\gamma_{j2}-\alpha_{j}\theta_{i})-\text{logit}^{-1}(\gamma_{j1}-\alpha_{j}\theta_{i})

(2)

\displaystyle P(z_{ij}=3|\theta_{i})

\displaystyle=1-\text{logit}^{-1}(\gamma_{j2}-\alpha_{j}\theta_{i}).

(3)

The
\alpha_{j}
parameter is commonly called the discrimination parameter, while the
\gamma_{j}
parameters help account for the base rates of boundary and non-boundary responses.

Submodel for Non-Boundary Responses

When
z_{ij}=2
, the response
y_{ij}
could lie anywhere between 0 and 1. We use a beta item response model here, where the
\alpha_{j}
and
\theta_{i}
parameters are shared with the graded response submodel described above. The beta item response model assumes independence of test scores given
\theta_{i}
:

y_{ij}\mid\theta_{i}\sim\text{Beta}(a_{ij},b_{ij})

(4)

where the Beta distribution follows the traditional parameterization, with two positive shape parameters
a
and
b
. Under this parameterization, our model assumes the following, unintuitive form:

\displaystyle a_{ij}

\displaystyle=\exp\left(\frac{\beta_{j}+\alpha_{j}\theta_{i}+\omega_{j}}{2}\right)

(5)

\displaystyle b_{ij}

\displaystyle=\exp\left(\frac{-(\beta_{j}+\alpha_{j}\theta_{i})+\omega_{j}}{2}\right).

(6)

These expressions are relatively simple, and they make it clear that there are three parameters per test and one parameter per person. But it is not so easy to recognize this as an item response model.

For the purposes of understanding the model, we write the mean of the beta distribution as
\mu_{ij}=a_{ij}/(a_{ij}+b_{ij})
. The expressions above lead us to a traditional, two-parameter item response function on
\mu_{ij}

(see
Noel & Dauvier 2007
)
:

\mu_{ij}=\text{logit}^{-1}(\beta_{j}+\alpha_{j}\theta_{i}),

(7)

where
\beta_{j}
is often called the “easiness” parameter, and
\alpha_{j}
is the discrimination parameter from the graded response submodel. Further,
\text{logit}^{-1}(x)=(1+\exp(-x))^{-1}
is the inverse logit link function, used to account for the fact that
\mu_{ij}
must lie in
(0,1)
.

Because the beta distribution is bounded on both sides, the variance of the beta distribution is partly influenced by
\mu_{ij}
. To account for response heterogeneity across cognitive tests, our third test parameter
\omega_{j}
helps predict the precision (inverse variance) of the beta distribution. With this parameter, the variance of the beta distribution is

\text{Var}(y_{ij}|\theta_{i})=\frac{\mu_{ij}(1-\mu_{ij})}{1+2\exp(\frac{\omega_{j}}{2})\cosh(\frac{\beta_{j}+\alpha_{j}\theta_{i}}{2})},

(8)

so that the variance becomes larger when
\mu_{ij}
is near .5 and when
\omega_{j}
is negative.

2.2
Information Functions

Combining the developments from the previous sections, we can write the overall model as

p(y_{ij}|\theta_{i})=\begin{cases}\text{logit}^{-1}(\gamma_{j1}-\alpha_{j}\theta_{i})&y_{ij}=0\\
\left(\text{logit}^{-1}(\gamma_{j2}-\alpha_{j}\theta_{i})-\text{logit}^{-1}(\gamma_{j1}+\alpha_{j}\theta_{i})\right)\times\text{Beta}(a_{ij},b_{ij})&0<y_{ij}<1\\
1-\text{logit}^{-1}(\gamma_{j2}-\alpha_{j}\theta_{i})&y_{ij}=1.\end{cases}

(9)

The information function for each cognitive test, which can be used for adaptive testing purposes, is obtained by taking second derivatives of the resulting model likelihood with respect to
\theta_{i}
.
Molenaar et al. 2022
shows that the information function is

\begin{split}I_{j}(\theta)=\alpha_{j}^{2}&\left(Q_{0}^{2}P_{0}+P_{1}^{2}Q_{1}-(P_{1}-P_{0})\left(\frac{P_{1}Q_{1}-P_{0}Q_{0}}{P_{1}-P_{0}}\right)^{2}-\right.\\

(10)

where

\displaystyle P_{0}

\displaystyle=\text{logit}^{-1}(\gamma_{j1}-\alpha_{j}\theta_{i})

\displaystyle Q_{0}

\displaystyle=1-\text{logit}^{-1}(\gamma_{j1}-\alpha_{j}\theta_{i})

\displaystyle P_{1}

\displaystyle=\text{logit}^{-1}(\gamma_{j2}-\alpha_{j}\theta_{i})

\displaystyle Q_{1}

\displaystyle=1-\text{logit}^{-1}(\gamma_{j2}-\alpha_{j}\theta_{i}),

and
\Omega()
is the trigamma function, which is a well-known mathematical series that can be closely approximated by most statistical software.

2.3
Model Discussion

In this section, we clarify and justify some specific modeling choices that we made. These choices involve the handling of boundary test scores, and the assumption that person proficiency is unidimensional. We address each choice separately below.

First, our model follows the work of
Molenaar et al. 2022
in that we explicitly model boundary responses. In traditional models involving the beta distribution, exact values of 0 and 1 are impossible. So it is customary to change 0s to .0001 or some other small value, and to change 1s to .9999 or some other large value. The cognitive tests that we employ in this paper do not always have hard boundary values, so we instead use empirical boundaries, i.e., the smallest and largest observed scores on each test. The use of empirical boundaries is imprecise because there remains the possibility that future respondents receive scores that are more extreme than the empirical boundaries. Such extreme scores would be censored to the empirical boundary that was already set, which makes it more difficult to assess respondents who are exceptionally skilled or exceptionally unskilled. While our current treatment of boundaries works reasonably well in the applications, we further consider this issue in the General Discussion.

Second, our model assumes that person proficiency is unidimensional. In other words, the model assumes that a single number fully describes each person’s proficiency across all the tests. This assumption is surely incorrect, because there are many aspects of a person’s proficiency that may lead them to do better or worse on specific tests. But we make this assumption for two reasons. First, our overall goal is to use the cognitive tests to gauge future forecasting accuracy, so it is beneficial to have a one-number summary of each person’s performance. In other words, we are asking the model to reduce all the cognitive test scores into the best one-number summary possible. Second, additional dimensions of proficiency can lead to noisier estimates for each dimension, which may hamper our ability to predict future forecasting accuracy. We also return to this issue in the General Discussion.

3
Application 1: Test Information and Correlates with Forecasting

We first fit the model to an initial dataset of 160 participants. This allows us to examine the model’s general fit to the cognitive test scores, and it also allows us to obtain preliminary information functions for each cognitive test.

3.1
Method

The first round of data collection was an exploratory pilot study. It included a screening survey, followed by three weekly surveys. A total of 160 participants were recruited on Facebook and responded to the surveys. One of the three surveys (after screening) involved forecasting tasks, while the other two surveys involved the cognitive tests that are of interest here. The cognitive tests were all intended to be simple measures of cognitive reasoning and/or numeracy. Table
1
shows the tests that were used, along with key references for the tests. The Adult Decision Making Competence test had three subscales, the Shipley test had two subscales, the Impossible Question test had three separate scores (one for the impossible questions and two for the “possible,” regular questions), and the Bayesian updating and denominator neglect tasks each had two versions. A more detailed description of the cognitive tasks can be found in the preregistration for a larger follow-up study (
https://osf.io/q2e94/
), which is considered in a later section of this paper.

The forecasting questions, which we will examine later, were selected from a pool of questions from previous forecasting tournaments. The questions involved a range of topics including economics, politics, and popular entertainment, all of which could be understood by laypeople. All of the questions involved time series, so that participants could always predict the value of the time series at a future date, and so that the questions could be reused for different resolution dates. Further detail about the data collection can be found in the project’s Open Science Foundation repository:
https://osf.io/q2e94/
.

Forecasts were elicited via quantile judgments, with forecast accuracy being measured via an
S-score

(
Chen et al. 2022
;
Grushka-Cockayne et al. 2017
;
Jose & Winkler 2009
)
. This is a strictly proper scoring rule for quantile forecasts that is based on the difference between each quantile estimate and the realized outcome, with larger penalties occurring when the outcome is extreme relative to the quantile estimates. Forecaster accuracy was summarized via an average S-score across questions. After fitting our model to the cognitive test scores, we examine the relationship between participants’ performance on the cognitive tests and their average S-score.

Our sample size of 160 participants is small for item response applications, an issue that we consider more later. About 11% of test scores were missing, and we did not do anything sophisticated to model missingness. The model estimation involves the traditional “missing at random” assumption, where we use all observed data and ignore missing data. We fit the model to the test scores via MCMC with Stan, saving 1,000 posterior samples from each of 3 chains after 1,000 warmup iterations. Model convergence was judged by the Rhat and effective sample size metrics
(e.g.,
Vehtari et al. 2021
)
, neither of which indicated any estimation problems. In our model, we used mildly informative prior distributions that constrain parameters to plausible values of the parameter space. Our specific prior distributions were

\displaystyle\beta_{j}

\displaystyle\sim\text{N}(0,2)

\displaystyle\alpha_{j}

\displaystyle\sim\text{logN}(0,1)

\displaystyle\omega_{j}

\displaystyle\sim\text{N}(0,10)

\displaystyle\gamma_{j1}

\displaystyle\sim\text{N}(-2,1)

\displaystyle\gamma_{j2}

\displaystyle\sim\text{N}(2,1),

where normal distributions are parameterized via standard deviations and where
j=1,\ldots,20
. These priors are on the logit scale, which is similar to the z-score (or probit) scale. So we generally expect model predictions to be between
-4
and
+4
(on the logit scale), with increases of 1 reflecting relatively large increases in model predictions. This implies that the above priors are not as informative as they may appear at first glance.

Test Selection

To select a subset of cognitive tests for administration, we can focus on the item information curves in Figure
5
. If we want to administer tests that are most informative about an average forecaster, we would find the curves that are highest for person proficiency of 0. These include cognitive reflection, denominator neglect, and Shipley vocabulary. If we want to administer tests that are most informative about the top 10% of forecasters, we find the curves that are highest for (say) person proficiency near 1.3 (this is the z-score that cuts off the top 10% of the distribution). These are generally the same tests, with the possible addition of Berlin numeracy. There are also some tests that provide little information across the full range of proficiency (Leapfrog, Impossible Question, General Knowledge calibration), suggesting that they could be safely removed.

To begin to explore the utility of these ideas, we computed each participant’s average standardized score on a subset of cognitive tests. Then we examined the relationship between these scores and their eventual forecasting S-scores. We expected that, if we maintain the most informative cognitive tests and discard the uninformative tests, we can maintain a relationship with forecasting performance while reducing the amount of time that it takes to administer cognitive tests. Based on the results shown in Figure
5
, we chose Cognitive Reflection, Denominator Neglect (A and B), Berlin Numeracy, Shipley Vocabulary, and Number Series as our subset of tests that provides the most information per minute. The time for completing this subset of tests is around 17 minutes (computed by summing median completion times for each individual test), whereas the time for completing all tests is around 103 minutes.

3.3
Summary

Our item response model of the Study 1 data provided a reasonable fit, provided evidence of tests that were more and less informative about respondent proficiency, and yielded scores that were highly predictive of later forecasting performance. But this was a small dataset as compared to most IRT applications. In the next section, we reproduce these results using a larger dataset, and we also compare model estimates across the two datasets.

4
Application 2: Larger Dataset

In this section, we fit the same model to a larger dataset of 1147 participants that was collected about eight months after the initial dataset. This allows us to examine stability of the model estimates across datasets, and it also allows us to score new participants using the parameter estimates from the previous study. These analyses provide further evidence of the model’s utility as we move towards adaptive testing, where cognitive tests are automatically selected based on a participant’s performance on previous tests.

4.1
Method

The data collection was similar to that of Application 1, with the exception that many more people and more forecasting tasks were involved. Our model, including prior distributions and estimation details, remained the same as Application 1. Traditional MCMC diagnostics again indicated that the model converged.

Now that we have two independent datasets, multiple options are available for scoring participants on the cognitive tests. As was done in Application 1, we can fit the IRT model to our new dataset and use the estimated
\theta_{i}
parameters as a measure of each participant’s overall performance. Alternatively, we can use the existing item parameter estimates from Application 1 to score participants from Application 2. This is advantageous because it does not require us to fit a new model to the Application 2 data, so it is fast and can be used for real-time scoring. To do the scoring, we take the log-likelihood function implied by Equation (
9
) and fix the item parameters to their posterior means from Study 1. We then numerically optimize the log-likelihood with respect to
\theta_{i}
, separately for each participant
i
. This one-dimensional optimization is very fast, much faster than fitting the full model to the new dataset.

4.2
Results

4.3
Summary

In fitting our model to the Study 2 data, we found that (i) item parameter estimates generally agreed with those of Study 1; (ii) information curves generally agreed with Study 1, with one exception; (iii) participant scores were nearly the same, regardless of whether we directly estimated the scores in the Study 2 model or estimated the scores using Study 1 item parameters; and (iv) participant scores remained strongly correlated with forecasting performance. The third result is especially important for adaptive testing because, if we can use previous estimates of item parameters, we can quickly score participants in real time and select cognitive tests accordingly. The fourth result is especially important for the overall goal of the study, which is to use cognitive tasks to predict forecasting performance. In the next section, we use results and data from the two studies to implement an adaptive testing scenario.

5
Adaptive Cognitive Testing

We now combine results from the previous sections to develop an adaptive testing procedure, and to apply the adaptive testing procedure to the Study 1 data. We examine how the procedure tailors the sequence of cognitive tests to each participant, and the time that it takes to achieve reliable estimates of participant performance.

5.1
Method

The adaptive testing procedure that we implemented includes the following steps:

1.

Start all participants on the test that is most informative for the average participant.

2.

Score each participant using all tests that they have completed so far.

3.

Based on each participant’s running score, administer the test that is expected to be most informative and that has not yet been administered to the participant.

4.

Repeat Steps 2 and 3 until all tests have been administered.

In Step 2 above, we use the estimated item parameters from Study 2 to score each participant (obtaining empirical Bayes estimates of their
\theta_{i}
parameters). In Step 3, we use two types of information from Study 2: the usual test information (shown in Figure
8
), and test information per minute (similar to Figure
5
). The latter may be useful because it attempts to gain the most information about each participant in the shortest amount of time.

We apply the adaptive testing procedure to all 97 Study 1 participants with complete data. We use 18 of the 20 test scores; we excluded the Impossible Question and General Knowledge Calibration tests because (i) they were generally uninformative and (ii) they come from the same task as the General Knowledge Percent Correct score, which would double-count the timing calculations that we present.

At the start of the adaptive testing procedure, we pretend that the participants have not completed any cognitive tests. We then sequentially reveal participants’ scores to the adaptive testing procedure, based on the tests that the procedure selects. In this way, we can examine how the procedure would have behaved, had we actually used it during the Study 1 data collection.

5.2
Results

Primary results appear in Figure

The x-axis represents the order/time of administration, where 1 is the first test selected and 18 is the last test selected, the y-axis shows the tests themselves, and each point represents a specific cognitive test selected for a specific participant at a specific timepoint. The left panel is for the adaptive testing procedure that uses test information, and the right panel is for the analogous procedure that uses test information per minute.

We see many similarities across the two panels. Denominator neglect (A or B) is selected first, because these are the two most informative tests. Denominator neglect A takes a longer time to complete than denominator neglect B, so the order of administration flips across the two panels (A before B using test information; B before A using test information per minute). The cognitive tests administered last are also similar across the two panels: ADMC resistance to framing, graph literacy, and leapfrog tend to be administered last.

We also see some differences across the two panels, especially for cognitive tests that took a long time to complete. The Shipley abstraction test is the fourth or fifth task administered using test information (left panel), but it becomes twelfth or thirteenth administered under information per minute (right panel). This is because Shipley abstraction takes nearly 10 minutes to complete, which is a large amount of time compared to others. Similarly, the Raven matrices have high information but also take about 11 minutes to complete, so they move further right in the second panel, as compared to the first. With information per minute, we generally see less variability in the cognitive tests that are selected, as compared to information alone.

6
General Discussion

In this paper, we applied item response models and adaptive testing principles to yield insights into the relationship between cognitive tests and forecasting proficiency. We applied a beta item response model to cognitive test scores and estimated the test information curves, which helped us discern the suitability of each test to participants of varying proficiencies. We used the information curves to select informative tests and discard uninformative tests, reducing the time taken to administer the tests with little sacrifice to predictive accuracy. We verified that these test selections remained worthwhile via a second, independent dataset, and we then showed how the information curves could be used to develop an adaptive testing procedure that works in real time. In this section, we consider limitations and future developments.

Limitations

While our model performance was reasonable, there are a few places where it could be improved and where our conclusions should be qualified. We expand on these points below.

First, the beta IRT model required us to set bounds on each cognitive test’s possible scores, and the exact bounds are not always well-defined. For example, the Leapfrog task has theoretical boundaries of 0 and 400, but it is nearly impossible to achieve a score near either bound. We therefore used empirical boundaries based on the Study 1 data. This use of empirical boundaries limits the possible scores that could be achieved in future scoring. For example, if a Study 2 participant scored higher than the empirical Study 1 upper bound, then that participant would be treated as though their score equaled the empirical Study 1 upper bound. This potentially limits our ability to distinguish between exceptional participants (exceptionally proficient or unproficient). An alternative would be to scrap the boundaries, employing a Gaussian IRT model in place of a beta IRT model. The information functions under a Gaussian model are flat, though, which prevents us from tailoring tests to different participants.

Related to the boundary issue, some of the cognitive test scores are defined as the number of items correct. For these tests, it may be better to use a binomial IRT model (setting the binomial
n
parameter to the total number of items) instead of a beta IRT model. Use of the binomial would remove the need to set bounds for some cognitive tests. The information functions would then be of a different form, depending on whether the cognitive test uses a beta or a binomial likelihood. These different information functions may further heighten our ability to predict forecasting accuracy.

Finally, as we mentioned near the start, our beta IRT model assumed a single dimension of proficiency across all the cognitive tests. This assumption helps limit the complexity of the model, which potentially improves model predictions (including test information) for new datasets
(e.g.,
Merkle et al. 2020
)
. But this assumption is sure to be incorrect, which qualifies our conclusions about the test information functions. There remains the possibility that some of the low-information tests from our study are informative about certain aspects of forecasting, but we cannot see that when we lump together all the cognitive tests in one dimension. It would be possible to fit beta IRT models with multiple dimensions of proficiency, with each test having a unique information function for each dimension. In designing an adaptive testing procedure, we then must decide which dimension(s) of proficiency to prioritize. There quickly become many possibilities here, both in number of proficiency dimensions and in cognitive test selection. The simplicity of a unidimensional model is advantageous here, in that it reduces the forking paths of modeling attributes and adaptive test designs.

Further Applications

Along with multidimensional IRT models, future work may involve applying these models to related datasets. First, while each participant currently receives a single score on each cognitive test, we can consider applying an IRT model to the individual items within each cognitive test. If there are a few highly-informative items in each test, such an IRT model would help us isolate those items, leading to an adaptive test administration that takes even less time than those examined here. Second, we may apply the adaptive testing approach to “repeatable” forecasting questions, such as questions that require forecasters to predict the value of a specific stock one month in advance. We could estimate the information of each forecasting question, then present different questions to forecasters based on their forecasting performance to date. Combining this idea with multidimensional IRT models, we may select questions for each forecaster depending on the specific dimensions where each forecaster excels. We anticipate that large datasets will be necessary to estimate the parameters of such a model with enough precision to be useful.

Summary

The models and procedures used in this paper appear fruitful for continued application to cognitive tests, to forecasting questions, and to combinations thereof. They help us find the best tests for assessing participants, and they also allow us to develop shorter administrations that are as good as longer administrations. The procedures are also efficient enough to be used in real time, after a model has been fit to a base dataset. We look forward to further developments along these lines in the future.
