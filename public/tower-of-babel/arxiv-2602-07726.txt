On the Digits of Partition Functions
Siddharth Iyer

Abstract
. We address a problem of Douglas and Ono concerning the determination of an upper bound for the smallest integer n n such that the partition function of n n begins with a string f f of digits in base b b . Here we improve previous results of Luca.

Introduction

For a natural number
n
, let
p(n)
denote the number of partitions of
n
, and let
PL(n)
denote the number of plane partitions of
n
(for more background see
[
1

[

the following problem was asked (here we generalize to include the function

Problem 1
.

Let
\mathbf{p}\in\{p(\cdot),PL(\cdot)\}
. For each string
f
in base
b
(not beginning with digit
0
), determine bounds for
N_{\mathbf{p}}(f,b)
with the property that there is a non-negative integer
n\leq\penalty\ \hskip-4.2679ptN_{\mathbf{p}}(f,b)
for which
\mathbf{p}(n)
begins with string
f
in base
b
.

In
[
3
]
Luca proves the choice
N_{p}(f,b)=\exp(2\cdot 10^{25}(t+12)(\log b)^{2})
, where
t
is the number of base
b
digits of
f
. In
[
2
]
he proves the choice
N_{PL}(f,b)=b^{51t+688}
. We will improve both his results.

Theorem 1.1
.

We can take

\displaystyle N_{p}(f,b)=\frac{290\cdot b^{2t}}{\log^{2}b}

and

\displaystyle N_{PL}(f,b)=\frac{29396\cdot b^{3t/2}}{\log^{3/2}b}.

Proof of Theorem
1.1

For an integer
b\geq 2
and
t\in{\mathbb{N}}
(if
b=2
,
t\geq 2
) let
\mathcal{D}_{b,t}
denote the set of integers of the form
\sum_{d=0}^{t-1}a_{d}\cdot b^{d}
, where
a_{i}\in\{0,\ldots,b-1\}
and
a_{t-1}\neq 0
. Define the function
C_{b,t}:\{b^{t-1},b^{t-1}+1,\ldots\}\rightarrow\mathcal{D}_{b,t}
. If
n
is an integer which is written as

\displaystyle n=\sum_{d=0}^{z+t-1}a_{d}\cdot b^{d},

where
z\in{\mathbb{N}}\cup\{0\}
,
a_{d}\in\{0,\ldots,b-1\}
and
a_{z+t-1}\neq 0
then

\displaystyle C_{b,t}(n)=\sum_{d=0}^{t-1}a_{d+z}\cdot b^{d}.

Here we remark that
C_{b,t}(n)
reveals the leading
t
digits of
n
in base
b
.

Lemma 2.1
.

Suppose that
n
is an integer with
n\geq b^{t-1}
. If
f\in\mathcal{D}_{b,t}
then
C_{b,t}(n)=f
if and only if

\displaystyle\{\log_{b}(n)\}\in[\log_{b}(f)-t+1,\log_{b}(f+1)-t+1)

Proof.

Note that if
C_{b,t}(n)=f
then

(2.1)

\displaystyle n\in[fb^{z},(f+1)b^{z})

for some
z\in\{0,1,\ldots\}
, which implies

(2.2)

\displaystyle\{\log_{b}(n)\}\in[\log_{b}(f)-t+1,\log_{b}(f+1)-t+1).

Conversely suppose that (
2.2
) holds, then (
2.1
) holds and therefore
C_{b,t}(n)=f
.‘

Lemma 2.2
.

For
|x|\leq 1/2

\displaystyle|\log(1+x)|\leq 2|x|

Proof.

Lemma 2.3
.

For
n\geq 4
we have the inequality

\displaystyle\left|\log_{b}(p(n))-\left(\frac{\pi\sqrt{24}}{6\log(b)}\sqrt{n}-\frac{\log(n)}{\log(b)}+\log_{b}\left(\frac{\sqrt{3}}{12}\right)\right)\right|\leq\frac{4}{n^{1/2}\log(b)}.

Proof.

Let
\mu(n)=\frac{\pi}{6}\sqrt{24n-1}
. For
n\geq 4
, by
[
3
, Lemma 1]
we have

\displaystyle\mu(n)+\log(\frac{\sqrt{3}}{12n}-\frac{\sqrt{3}}{12n^{3/2}})<\log(p(n))<\mu(n)+\log(\frac{\sqrt{3}}{12n}+\frac{\sqrt{3}}{12n^{3/2}}).

Now observe that

\displaystyle\log(\frac{\sqrt{3}}{12n}\pm\frac{\sqrt{3}}{12n^{3/2}})=\log(\frac{\sqrt{3}}{12n})+\log(1\pm\frac{1}{n^{1/2}}).

Note that by Lemma
2.2
we have

\displaystyle\left|\log(1\pm\frac{1}{n^{1/2}})\right|\leq\frac{2}{n^{1/2}}.

Also observe that

\displaystyle\frac{\pi\sqrt{24}}{6}\sqrt{n}-\frac{\pi}{6(\sqrt{24n}+\sqrt{24n-1})}=\mu(n)<\frac{\pi\sqrt{24}}{6}\sqrt{n}

Hence we have the inequality

\displaystyle\left|\mu(n)-\frac{\pi\sqrt{24}}{6}\sqrt{n}\right|\leq\frac{2}{\sqrt{n}}

Hence we have the estimate

\displaystyle\left|\log(p(n))-\left(\frac{\pi\sqrt{24}}{6}\sqrt{n}-\log(n)+\log\left(\frac{\sqrt{3}}{12}\right)\right)\right|\leq\frac{4}{n^{1/2}},

and the lemma follows by dividing this inequality by
\log(b)
.
