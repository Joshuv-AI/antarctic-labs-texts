Abstract
. In this paper, we study the necessary and sufficient conditions in the domain for Sobolev-type embedding of the space W 1 , Φ ⁡ ( ⋅ , ⋅ ) ​ ( Ω ) W^{1,\Phi(\cdot,\cdot)}(\Omega) where Φ ⁡ ( x , t ) := t p ⁡ ( x ) + a ⁡ ( x ) ​ t q ⁡ ( x ) ​ log r ⁡ ( x ) ⁡ ( e + t ) \Phi(x,t):=t^{p(x)}+a(x)t^{q(x)}\log^{r(x)}(e+t) with 1 ≤ p ⁡ ( x ) ≤ q ⁡ ( x ) . 1\leq p(x)\leq q(x). We have established subcritical embedding in bounded John domains under some regularity assumptions on exponents p , p, q , q, r r , and a a . Conversely, we have proved that if the embedding holds in any domain Ω \Omega in ℝ n , \mathbb{R}^{n}, then Ω \Omega must satisfy the log-measure density condition.

1.
Introduction

We assume throughout the paper that
\Omega
is an open subset of
\mathbb{R}^{n}
and we take the logarithmic variable exponent double phase function
\Phi(x,t)=t^{p(x)}+a(x)t^{q(x)}\ln^{r(x)}(e+t)
where
a(x)\geq 0
and the variable exponents p, q and r are continuous functions defined on
\Omega
or
\mathbb{R}^{n}
, satisfying

(p1)

1\leq p^{-}:=inf_{x\in\Omega}p(x)\leq sup_{x\in\Omega}p(x)=:p^{+}<\infty
,

(q1)

1\leq q^{-}:=inf_{x\in\Omega}q(x)\leq sup_{x\in\Omega}q(x)=:q^{+}<\infty
,

(r1)

-\infty<r^{-}:=inf_{x\in\Omega}r(x)\leq sup_{x\in\Omega}r(x)=:r^{+}<\infty
.

The following three conditions in
p,q,
and
r
will also be used; the first two in the literature are known as log-Hölder continuous, and the third one is known as log-log-Hölder continuous:

(p2)

|p(x)-p(y)|\leq\frac{C}{\log(e+1/|x-y|)}
whenever
x\in\Omega
and
y\in\Omega

(q2)

|q(x)-q(y)|\leq\frac{C}{\log(e+1/|x-y|)}
whenever
x\in\Omega
and
y\in\Omega

(r2)

|r(x)-r(y)|\leq\frac{C}{\log(e+\log(e+1/|x-y|))}
whenever
x\in\Omega
and
y\in\Omega
.

Definition 1.1
.

A bounded domain
\Omega\subset\mathbb{R}^{n}

Let

\Psi(x,t):=t^{p^{*}(x)}+(a(x))^{\frac{q^{*}(x)}{q(x)}}t^{q^{*}(x)}{(\log(e+\frac{t}{a(x)^{(q(x)-1)/q(x)}}))}^{r(x)q^{*}(x)/q(x)}

(i)

Theorem 1.3
.

Let

Notations ans Preliminaries

Definition 2.1
.

A function
f:(0,\infty)\rightarrow\mathbb{R}
is called almost increasing if there exists a constant
c_{1}\geq 1
such that
f(s)\leq c_{1}f(t)
for all
0<s<t
. Similarly, it is called almost decreasing if there exists a constant
c_{2}\geq 1
such that
c_{2}f(s)\geq f(t)
for all
0<s<t.

Definition 2.2
.

Let
f:\Omega\times(0,\infty)\rightarrow\mathbb{R}
and
p,q>0
.We say that f satisfies

(i)

(Inc)_{p},
if
\frac{f(x,t)}{t^{p}}
is increasing in the variable
t
;

(ii)

(aInc)_{p},
if
\frac{f(x,t)}{t^{p}}
is almost increasing in the variable
t
;

(iii)

(Dec)_{q},

\frac{f(x,t)}{t^{q}}
is decreasing in the variable
t
;

(iv)

(aDec)_{q},
if
\frac{f(x,t)}{t^{q}}

.

A weaker version of the measure density condition (defined in Section 1) is defined as follows.

Definition 2.3
.

A set
\Omega\subset\mathbb{R}^{n}

-measure density condition if there exist two constants

We say that the exponent

Let us recall the definition of a generalized Orlicz space or Musielak-Orlicz (M-O) space.

Definition 2.9
.

Let
\Phi\in\Phi_{w}(\Omega,\mu)
. F
f\in L^{0}(\Omega,\mu)
, the function

\rho_{\Phi}(f):=\int_{\Omega}\Phi(x,|f(x)|)d\mu(x)

is called a modular. The set

L^{\Phi(\cdot,\cdot)}(\Omega)
:=
\{f\in L^{0}(\Omega,\mu):\rho_{\Phi}(\lambda f)<\infty
for some
\lambda>0\}

is called a generalized Orlicz space or Musielak-Orlicz space. Note that
L^{\Phi(\cdot,\cdot)}(\Omega)
is a quasi-Banach space when equipped with the quasi-norm

||u||_{L^{\Phi(\cdot,\cdot)}(\Omega)}=\inf\{\lambda>0:\rho_{\Phi}(\frac{u}{\lambda})\leq 1\}.

Also, if
\Phi
is a generalized convex
\Phi
-function, then it becomes a Banach space. Furthermore, if
\Phi
satisfies
(aDec)
and
\mu
is separable, then
L^{\Phi(\cdot,\cdot)}(\Omega)
is separable; and if
\Phi
satisfies
(aDec)
and
(aInc)
, then it is reflexive.

Lemma 2.15
.

Let
\Omega\subset\mathbb{R}^{n},n\geq 2,
be a domain and
p,q,r\in C(\bar{\Omega})
with
1\leq p(x)\leq q(x)
for all
x\in\bar{\Omega}
,
r^{+}\geq 0
and
a\in L^{1}(\Omega)
; then
\Phi(x,t)
satisfies
(Inc)_{p^{-}},(Dec)_{p^{+}+r^{+}}
.

Proof.

First, note that

\frac{\Phi(x,t)}{t^{p^{-}}}=t^{p(x)-p^{-}}+a(x)t^{q(x)-p^{-}}{(\log(e+t))}^{r(x)}

is an increasing function. So
\Phi(x,t)
satisfies
(Inc)_{p^{-}}.

The condition
(Dec)_{p^{+}+r^{+}}
follows, since we have, for
0\leq s\leq t,

\displaystyle\frac{\Phi(x,t)}{t^{p^{+}+r^{+}}}

\displaystyle=

\displaystyle t^{p(x)-p^{+}-r^{+}}+a(x)t^{q(x)-p^{+}-r^{+}}{(\log(e+t))}^{r(x)}

\displaystyle\leq

\displaystyle s^{p(x)-p^{+}-r^{+}}+a(x)s^{q(x)-p^{+}-r^{+}}{(\log(e+s))}^{r(x)}

\displaystyle=

\displaystyle\frac{\Phi(x,s)}{s^{p^{+}+r^{+}}},

where we have used the fact that the function
t^{Q(x)}{\log^{r(x)}(e+t)}
is decreasing when
Q(x)+r^{+}\leq 0.

Proposition 2.16
.

Let
\Omega
be a domain in
\mathbb{R}^{n},

n\geq 2,
and

with
p(x)\leq q(x)
for all

,

and

is a separable, reflexive Banach space and we also have the following results:

(i)

\|u\|_{L^{\Phi(\cdot,\cdot)}(\Omega)}=\lambda\hskip 10.00002pt\text{if and only if }\varrho_{\Phi}\!\left(\tfrac{u}{\lambda}\right)=1\ \text{for }u\neq 0\text{ and }\lambda>0;

(ii)

\|u\|_{L^{\Phi(\cdot,\cdot)}(\Omega)}<1\ (\text{resp. }=1,>1)\ \text{if and only if }\varrho_{\Phi}(u)<1\ (\text{resp. }=1,>1);

(iii)

\min\big\{\|u\|^{p^{-}}_{L^{\Phi(\cdot,\cdot)}(\Omega)},\|u\|^{p^{+}+r^{+}}_{L^{\Phi(\cdot,\cdot)}(\Omega)}\big\}\leq\varrho_{\Phi}(u)\leq\max\big\{\|u\|^{p^{-}}_{L^{\Phi(\cdot,\cdot)}(\Omega)},\|u\|^{p^{+}+r^{+}}_{L^{\Phi(\cdot,\cdot)}(\Omega)}\big\}

\|u\|_{L^{\Phi(\cdot,\cdot)}(\Omega)}\to 0\ \text{if and only if }\varrho_{{\Phi}}(u)\to 0;

(v)

\|u\|_{L^{\Phi(\cdot,\cdot)}(\Omega)}\to\infty\ \text{if and only if }\varrho_{{\Phi}}(u)\to\infty.

First, by Definition
2.9
and Lemma
2.15

is a separable, reflexive Banach space.

For (i) and (ii), note that the function
\lambda\rightarrow\varrho_{{\Phi}}(\frac{u}{\lambda})

is continuous, convex and strictly increasing. This directly implies (i), and (i) with the strict increasing property yields (ii).

Finally, (iii) follows from
2.10
and Lemma
2.15
; and (iv) and (v) follow from (iii).

\frac{1}{p}
and
t\in[1,\frac{1}{|B|}],
see Lemma
2.22
. If
p(x)\geq p(y)
, then
t^{\frac{1}{p(x)}}\leq t^{\frac{1}{p(y)}}
since
t\geq 1
. So
t^{\frac{1}{p(x)}}\leq C_{1}t^{\frac{1}{p(y)}}
where
C_{1}=\min(1,C)
. Similarly, we can also show that
t^{\frac{1}{q(x)}-\frac{1}{q(y)}}\leq C_{2}
.

Thus, for condition
(A1)
we need to show that

\beta\min\{t^{\frac{1}{p(y)}-\frac{1}{q(y)}},\frac{1}{a(x)^{\frac{1}{q(x)}}(\log(e+\frac{t}{a(x)}))^{\frac{r(x)}{q(x)}}}\}\leq\min\{t^{\frac{1}{p(y)}-\frac{1}{q(y)}},\frac{1}{a(y)^{\frac{1}{q(y)}}(\log(e+\frac{t}{a(y)}))^{\frac{r(y)}{q(y)}}}\}
.

Aside from the trivial case
t^{\frac{1}{p(y)}-\frac{1}{q(y)}}\leq\frac{1}{a(y)^{\frac{1}{q(y)}}(\log(e+\frac{t}{a(y)}))^{\frac{r(y)}{q(y)}}}
, we get the equivalent condition

(3.2)

\beta^{\prime}a(y)^{\frac{1}{q(y)}}(\log(e+\frac{t}{a(y)}))^{\frac{r(y)}{q(y)}}\leq\max\{t^{\frac{1}{q(y)}-\frac{1}{p(y)}},a(x)^{\frac{1}{q(x)}}(\log(e+\frac{t}{a(x)}))^{\frac{r(x)}{q(x)}}\}

Denote
f(u)=u^{\frac{1}{q(y)}}(\log(e+\frac{1}{u}))^{\frac{r(y)}{q(y)}}
,
g(u)=\frac{u^{q(y)}}{(\log(e+\frac{1}{u}))^{r(y)}}
,
h(u)=u^{\frac{1}{q(x)}}(\log(e+\frac{1}{u}))^{\frac{r(x)}{q(x)}}
and
I(u)=\frac{u^{q(x)}}{(\log(e+\frac{1}{u}))^{r(x)}}
. Then

g(bf(u))\approx u

where the implicit constant depends on b. We can write (
3.2
) as

(3.3)

\beta^{\prime}t^{\frac{1}{q(y)}}f(\frac{a(y)}{t})\leq\max\{t^{\frac{1}{q(y)}-\frac{1}{p(y)}},t^{\frac{1}{q(x)}}h(\frac{a(x)}{t})\}.

Now, dividing both sides by
t^{\frac{1}{q(y)}}
we get

(3.4)

\beta^{\prime}f(\frac{a(y)}{t})\leq\max\{t^{\frac{-1}{p(y)}},t^{\frac{1}{q(x)}-{\frac{1}{q(y)}}}h(\frac{a(x)}{t})\}.

Now, applying the increasing function
g
to both sides of (
3.4
), we get the following:

\frac{a(y)}{t}\approx g(\beta^{\prime}f(\frac{a(y)}{t}))\leq\max\{g(t^{\frac{-1}{p(y)}}),g(t^{\frac{1}{q(x)}-{\frac{1}{q(y)}}}h(\frac{a(x)}{t}))\}

or, equivalently,

\displaystyle\beta a(y)\leq tg(t^{\frac{-1}{p(y)}})+tg(t^{\frac{1}{q(x)}-{\frac{1}{q(y)}}}h(\frac{a(x)}{t}))

\displaystyle\approx

\displaystyle\frac{1}{(\log(e+t^{\frac{1}{p(y)}}))^{r(y)}}+q(x)^{r(y)}a(x)^{\frac{q(y)}{q(x)}}(\log(e+\frac{t}{a(x)}))^{\frac{r(x)q(y)}{q(x)}}(\log(e+\frac{t^{\frac{q(x)}{q(y)}}}{a(x)}))^{-r(y)}

\displaystyle\approx

\displaystyle\frac{1}{(\log(e+t^{\frac{1}{p(y)}}))^{r(y)}}+q(x)^{r(y)}a(x)^{\frac{q(y)}{q(x)}}(\log(e+\frac{t}{a(x)}))^{\frac{r(x)q(y)-r(y)q(x)}{q(x)}}.

By log-Hölder continuity of
q(x)
we have
t\approx t^{\frac{q(x)}{q(y)}}
and hence

\beta a(y)^{\frac{1}{q(y)}}\leq\frac{1}{(\log(e+t^{\frac{1}{p(y)}}))^{\frac{r(y)}{q(y)}}}+q(x)^{\frac{r(y)}{q(y)}}a(x)^{\frac{1}{q(x)}}(\log(e+\frac{t}{a(x)}))^{\frac{r(x)}{q(x)}-\frac{r(y)}{q(y)}}.

By symmetry, we may assume that
\frac{r(x)}{q(x)}>\frac{r(y)}{q(y)}
. Then we get the equivalent condition

\displaystyle\beta a(y)^{\frac{1}{q(y)}}

\displaystyle\leq

\displaystyle\frac{1}{(\log(e+t^{\frac{1}{p(y)}}))^{\frac{1}{q(y)}}}+q(x)^{\frac{r(y)}{q(y)}}a(x)^{\frac{1}{q(x)}}.

Since we have
t\leq\frac{1}{|B|}\leq\frac{c}{|x-y|^{n}}
, we get the conditions as follows:

\beta a(y)^{\frac{1}{q(y)}}\lesssim{(\log(e+|x-y|^{\frac{-1}{p(y)}}))^{-\frac{1}{q(y)}}}+a(x)^{\frac{1}{q(x)}},

and hence finally, we get the equivalent condition given by:

\beta a(y)^{\frac{1}{q(y)}}\leq a(x)^{\frac{1}{q(x)}}+\frac{1}{\log(e+|x-y|^{-1})}.

∎

As a special case, we get the following lemma.

Lemma 3.4
.

Let
\Omega\subset\mathbb{R}^{n},n\geq 2,
be an unbounded domain. Assume that
0\leq a(\cdot)\in L^{\infty}(\Omega)
and
p:\bar{\Omega}\rightarrow[1,\infty),

q:\bar{\Omega}\rightarrow[1,\infty)
are log-Hölder continuous with
p(x)\leq q(x)
for all
x\in\bar{\Omega}
and also,
a:\bar{\Omega}\rightarrow[0,\infty)
is
q^{+}
-Hölder continuous. Then
\Phi(x,t):=t^{p(x)}+a(x)t^{q(x)}{\log^{r(x)}(e+t)}
, where
r(x)\geq 0
, satisfies
(A1)
.

Proof.

We will show that the inequality

|a(x)^{\frac{1}{q(x)}}-a(y)^{\frac{1}{q(y)}}|\leq\frac{C}{\log(e+|x-y|^{-1})}

holds for all
x
,
y
with
|x-y|\leq 1,
and then the condition
(A1)
will follow by the Lemma
3.3
. For this purpose, we first use the triangle inequality to obtain the following

(3.5)

\displaystyle|a(x)^{\frac{1}{q(x)}}-a(y)^{\frac{1}{q(y)}}|

\displaystyle=

\displaystyle|a(x)^{\frac{1}{q(x)}}-a(x)^{\frac{1}{q(y)}}+a(x)^{\frac{1}{q(y)}}-a(y)^{\frac{1}{q(y)}}|

\displaystyle\leq

\displaystyle|a(x)^{\frac{1}{q(x)}}-a(x)^{\frac{1}{q(y)}}|+|a(x)^{\frac{1}{q(y)}}-a(y)^{\frac{1}{q(y)}}|.

We estimate the first term on the right-hand side of (
3.5
). For the function
f(t)=b^{t},
we apply the mean value theorem to obtain
f(v)-f(u)=f^{\prime}(\eta)(v-u)
for some
\eta
between u and v. We choose
b=a(x),u=\frac{1}{q(x)}
and
v=\frac{1}{q(y)}
. Then
b\in[0,||a||_{\infty}]
and
u,v\in[\frac{1}{q^{+}},1].

Next, we will show that
|f^{\prime}(\eta)|
is bounded. If
b\geq 1
, then

|f^{\prime}(\eta)|=b^{\eta}\ln(b)\leq||a||_{\infty}\ln(||a||_{\infty}).

For
a\in[0,1)
, we obtain the following

|f^{\prime}(\eta)|=-b^{\eta}\ln(b)\leq-b^{\frac{1}{q^{+}}}\ln(b).

An easy calculation shows that the function
b\rightarrow-b^{\frac{1}{q^{+}}}\ln(b)
obtained its highest value in
[0,1]
at
e^{-q^{+}}.
Hence
|f^{\prime}(\eta)|\leq\frac{q^{+}}{e}
. Thus we have

(3.6)

|a(x)^{\frac{1}{q(x)}}-a(x)^{\frac{1}{q(y)}}|=|f(v)-f(u)|\leq c|\frac{1}{q(x)}-\frac{1}{q(x)}|\leq c|q(y)-q(x)|\leq\frac{c}{\log(e+|x-y|^{-1})},

where c is a constant depending on
b
and
q
.

Now we will estimate the second term of the right-hand side of (
3.5
). We use the inequality
|x^{k}-y^{k}|\leq|x-y|^{k},
where
x,y\geq 0
and
k\in(0,1]
, to obtain

(3.7)

|a(x)^{\frac{1}{q(y)}}-a(y)^{\frac{1}{q(y)}}|\leq|a(x)-a(y)|^{\frac{1}{q(y)}}\leq c_{a}^{\frac{1}{q^{-}}}|x-y|^{\frac{q^{+}}{q(y)}}\leq c_{a}^{\frac{1}{q^{-}}}|x-y|\leq\frac{c_{a}^{\frac{1}{q^{-}}}}{\log(e+|x-y|^{-1})},

where the constant
c_{a}
is from the
q^{+}
-Hölder continuity of
a(x)
.
Therefore, using (
3.6
) and (
3.7
) in (
3.5
) we get

|a(x)^{\frac{1}{q(x)}}-a(y)^{\frac{1}{q(y)}}|\leq\frac{c_{a}^{\frac{1}{q^{-}}}+c}{\log(e+|x-y|^{-1})}=\frac{C}{\log(e+|x-y|^{-1})}.

Now, if
C\leq 1
, then
\beta=1
works for both cases. If
C>1
, then there will be two cases.

Case I: If
a(x)^{\frac{1}{q(x)}}\leq a(y)^{\frac{1}{q(y)}}
then
\frac{a(y)^{\frac{1}{q(y)}}}{C}\leq\frac{a(x)^{\frac{1}{q(x)}}}{C}+\frac{1}{\log(e+|x-y|^{-1})}\leq a(x)^{\frac{1}{q(x)}}+\frac{1}{\log(e+|x-y|^{-1})}.
If we take
\beta=1/C
then we are done.

Case II: If
a(x)^{\frac{1}{q(x)}}>a(y)^{\frac{1}{q(y)}}
then
a(y)^{\frac{1}{q(y)}}<a(x)^{\frac{1}{q(x)}}+\frac{1}{\log(e+|x-y|^{-1})}.
Taking
\beta=1,
we complete the proof.
∎

Now we will show that
\Phi
also satisfies condition
(A2)
for both bounded and unbounded domains.

Lemma 3.5
.

Let
\Omega\subset\mathbb{R}^{n},n\geq 2,
be a bounded domain and
p,q,r\in C{(\bar{\Omega})}
with
1\leq p(x)\leq q(x)
for all
x\in\bar{\Omega}
,
r^{+}\geq 0
and
a\in L^{1}(\Omega)
. Then
\Phi(x,t)
satisfies
(A2)
.

Proof.

By Lemma
2.8
(iii), it is equivalent to checking condition
(A2)^{\prime}
.
For
(A2)^{\prime},
take
s=1,\phi_{\infty}(t)=t^{p^{+}+1}
and
\beta=1.
First note that
\phi_{\infty}(t)\leq 1
implies
t\leq 1.
Thus, by Young’s inequality

\displaystyle\Phi(x,\beta t)

\displaystyle\leq

\displaystyle[1+||a||_{\infty}\log^{r^{+}}(e+1)]t^{p(x)}

\displaystyle\leq

\displaystyle\frac{p(x)}{p^{+}+1}t^{p^{+}+1}+\frac{p^{+}-p(x)+1}{p^{+}+1}[1+||a||_{\infty}\log^{r^{+}}(e+1)]^{\frac{p^{+}+1}{p^{+}-p(x)+1}}

\displaystyle\leq

\displaystyle\phi_{\infty}(t)+[1+||a||_{\infty}\log^{r^{+}}(e+1)]^{p^{+}+1}.

Taking
h=[1+||a||_{\infty}\log^{r^{+}}(e+1)]^{p^{+}+1}
, we also have

\phi_{\infty}(\beta t)\leq t^{p(x)}\leq\Phi(x,t)+h(x).

which proves that
\Phi(x,t)
satisfies
(A2).

∎

In the above theorem, we have assumed the domain to be bounded. For unbounded domains, the condition
(A2)
follows if we assume one extra condition on
p,
namely the Nekvinda’s decay condition.

Lemma 3.6
.

Let
\Omega\subset\mathbb{R}^{n},n\geq 2,
be an unbounded domain. Assume that
p,q
and
a
are Hölder continuous functions while
r:\bar{\Omega}\rightarrow[0,\infty)
is a log-log-Hölder continuous function with
1\leq p(x)\leq q(x)
for all
x\in\bar{\Omega}
and

\big(\frac{q}{p}\big)^{+}<1+\frac{\gamma}{n},

where
\gamma
is the Hölder exponent of
a(x).
Assume also that
p
satisfies the Nekvinda’s decay condition. Then
\Phi(x,t):=t^{p(x)}+a(x)t^{q(x)}(\ln(e+t))^{r(x)}
satisfies
(A0),(A1),(A2),(aDec)
.

Proof.

The proof of
(A0),(aDec)
and
(A1)
is exactly the same as in Theorem
3.1
, Lemma
2.15
and Proposition
3.2
since they are valid even if
\Omega
is unbounded. Therefore, it remains to show the condition
(A2).

By Lemma
2.8
(iii), it is equivalent to prove the condition
(A2)^{\prime}.
Towards this end, take
s=1,

\phi_{\infty}(t)=t^{p_{\infty}}
and
\beta\leq 1.
Note that
\phi_{\infty}(t)\leq 1
implies
t\leq 1
. We will consider two cases. For all the points
x
where
p(x)<p_{\infty},
we have by Young’s inequality

\displaystyle\Phi(x,\beta t)

\displaystyle\leq

\displaystyle[1+||a||_{\infty}\log^{r^{+}}(e+1)]\beta^{p(x)}t^{p(x)}

\displaystyle\leq

\displaystyle\frac{p(x)}{p_{\infty}}t^{p_{\infty}}+\frac{p_{\infty}-p(x)}{p_{\infty}}[1+||a||_{\infty}\log^{r^{+}}(e+1)]^{\frac{p_{\infty}}{p_{\infty}-p(x)}}\beta^{\frac{1}{|\frac{1}{p(x)}-\frac{1}{p_{\infty}}|}}

\displaystyle\leq

\displaystyle\phi_{\infty}(t)+(\beta[1+||a||_{\infty}\log^{r^{+}}(e+1)])^{\frac{1}{|\frac{1}{p(x)}-\frac{1}{p_{\infty}}|}}.

Let us take

\beta<c[1+||a||_{\infty}\log^{r^{+}}(e+1)]^{-1},

and

h(x)=(\beta[1+||a||_{\infty}\log^{r^{+}}(e+1)])^{\frac{1}{|\frac{1}{p(x)}-\frac{1}{p_{\infty}}|}}
,

where
c\in(0,1)
is the constant from the Nekvinda’s condition. Then we have
h\in L^{1}(\Omega)\cap L^{\infty}(\Omega)
. For all those
x
where
p(x)\geq p_{\infty},
we have, after taking the same
\beta,

\Phi(x,\beta t)\leq[1+||a||_{\infty}\log^{r^{+}}(e+1)]\beta t^{p_{\infty}}\leq\phi_{\infty}(t).

We prove the other inequality similarly: when
p(x)\leq p_{\infty},
we have

\phi_{\infty}(\beta t)\leq t^{p(x)}\leq\Phi(x,t),

and when
p(x)>p_{\infty}
, we obtain using Young’s inequality

\phi_{\infty}(\beta t)\leq\frac{p_{\infty}}{p(x)}t^{p(x)}+\frac{{p(x)}-p_{\infty}}{{p(x)}}\beta^{\frac{1}{|\frac{1}{p(x)}-\frac{1}{p_{\infty}}|}}\leq\Phi(x,t)+h(x),

which proves that
\Phi(x,t)
satisfies
(A2).

∎

Now we will prove the sufficient part of the Logarithmic Variable Exponent Double Phase Embedding using the following theorem.

Theorem 3.7

(
Corollary 6.3.3 of HH19
)
.

Let
\Omega
be a John domain. Assume that
\Phi:\Omega\times[0,\infty)\rightarrow[0,\infty]
is a generalized weak
\Phi
-function that satisfies
(A0),(A1),(A2),(aInc)
and
(aDec)_{q},

q<n.
Suppose that
\Psi\in\Phi_{w}(\Omega)
satisfies
t^{\frac{-1}{n}}\Phi^{-1}(x,t)\approx\Psi^{-1}(x,t).
Then
W^{1,\Phi(\cdot,\cdot)}(\Omega)\hookrightarrow L^{\Psi(\cdot,\cdot)}(\Omega).

Proof of Theorem
1.2

Note that under the assumptions in (i),
\Phi(\cdot,\cdot)
satisfies
(A0),(A1),(A2),

(Inc)_{p^{-}},(Dec)_{p^{+}+r^{+}}
using the Lemmas
3.1
,
3.2
,
3.5
and
2.15
respectively and hence the embedding follows from Theorem
3.7
. For the second case, we use Lemma
3.4
instead of Lemma
3.2
to get the
(A1)
property of
\Phi(\cdot,\cdot)
and hence the embedding follows from Theorem
3.7
. ∎

4.
Necessary Part

In this section, we have shown that if the embedding holds for
W^{1,\Phi(\cdot,\cdot)}
, where
\Phi(x,t):=t^{p(x)}+a(x)t^{p(x)}(\log(e+t))^{r(x)}
then
\Omega
satisfies the measure density or log-measure density conditions depending on the exponent
r(\cdot).

We first prove three lemmas to estimate the norm of the characteristic function of a measurable set. Here and hereafter, for a measurable set
A\subset\Omega
and an exponent
p:\Omega\rightarrow[1,\infty),
we denote
p_{A}^{+}:=\sup_{x\in A}p(x)
and
p_{A}^{-}:=\inf_{x\in A}p(x).

Lemma 4.1
.

Let
\Phi:\Omega\times[0,\infty)\rightarrow[0,\infty]
be given by
\Phi(x,t):=t^{p(x)}+a(x)t^{p(x)}(\ln(e+t))^{r(x)}
with
r(x)\geq 0
for all
x
and let
A\subset\Omega
be a measurable set. Then

(4.1)

\min\{|A|^{\frac{1}{p_{A}^{+}}},|A|^{\frac{1}{p_{A}^{-}}}\}\leq\|1_{A}\|_{L^{\Phi(\cdot,\cdot)}(\Omega)}\leq 2(1+||a||_{\infty})^{\frac{1}{p_{A}^{-}}}\max\{|A|^{\frac{1}{p_{A}^{+}}}\log^{r_{A}^{+}}(e+\frac{1}{|A|}),|A|^{\frac{1}{p_{A}^{-}}}\log^{r_{A}^{+}}(1+e)\},

Proof.

We start with the proof of the second inequality of (
4.1
). Let
u>|A|
and assume first that
u\leq 1
. Then

\displaystyle\int_{A}\Phi\bigg(x,\frac{1}{2(1+||a||_{\infty})^{\frac{1}{p_{A}^{-}}}u^{\frac{1}{p_{A}^{+}}}(\log(e+\frac{1}{u}))^{r_{A}^{+}}}\bigg)dx

\displaystyle=

\displaystyle\int_{A}\frac{1}{2^{p(x)}(1+||a||_{\infty})^{\frac{p(x)}{p_{A}^{-}}}u^{\frac{p(x)}{p_{A}^{+}}}(\log(e+\frac{1}{u}))^{p(x)r_{A}^{+}}}

\displaystyle+

\displaystyle\frac{a(x)\bigg(\log\Big(e+\frac{1}{2(1+||a||_{\infty})^{\frac{1}{p_{A}^{-}}}u^{\frac{1}{p_{A}^{+}}}\big(\log(e+\frac{1}{u})\big)^{r_{A}^{+}}}\Big)\bigg)^{r(x)}}{2^{p(x)}(1+||a||_{\infty})^{\frac{p(x)}{p_{A}^{-}}}u^{\frac{p(x)}{p_{A}^{+}}}(\log(e+\frac{1}{u}))^{p(x)r_{A}^{+}}}dx

\displaystyle\leq

\displaystyle\frac{|A|}{2u(\log(e+\frac{1}{u}))^{r_{A}^{+}}}

\displaystyle+

\displaystyle\frac{|A|\bigg(\log\Big(e+\frac{1}{2(1+||a||_{\infty})^{\frac{1}{p_{A}^{-}}}u^{\frac{1}{p_{A}^{+}}}(\log(e+\frac{1}{u}))^{r_{A}^{+}}}\Big)\bigg)^{r_{A}^{+}}}{2u(\log(e+\frac{1}{u}))^{r_{A}^{+}}}

\displaystyle<

\displaystyle 1,

where in the final inequality, we have used the fact that
2(1+||a||_{\infty})^{\frac{1}{p_{A}^{-}}}u^{{\frac{1}{p_{A}^{+}}}-1}(\log(e+\frac{1}{u}))^{r_{A}^{+}}\geq 1
. Hence, we have
\|1_{A}\|_{L^{\Phi(\cdot,\cdot)}(\Omega)}\leq 2(1+||a||_{\infty})^{\frac{1}{p_{A}^{-}}}u^{\frac{1}{p_{A}^{+}}}(\log(e+\frac{1}{u}))^{r_{A}^{+}}
.
If
u>1
, we can similarly show that
\|1_{A}\|_{L^{\Phi(\cdot,\cdot)}(\Omega)}\leq 2(1+||a||_{\infty})^{\frac{1}{p_{A}^{-}}}u^{\frac{1}{p_{A}^{-}}}(\log(1+e))^{r_{A}^{+}}
. The second inequality follows as
u\rightarrow|A|^{+}
.

Let us then prove the first inequality of (
4.1
). Let
u<|A|
and assume first that
u\leq 1
. Then

(4.2)

\int_{A}\Phi\Big(x,\frac{1}{u^{\frac{1}{p_{A}^{-}}}}\Big)dx=\int_{A}\frac{1}{u^{\frac{p(x)}{p_{A}^{-}}}}+\frac{a(x)\Big(\log\big(e+\frac{1}{u^{\frac{1}{p_{A}^{-}}}}\big)\Big)^{r(x)}}{u^{\frac{p(x)}{p_{A}^{-}}}}dx\geq\frac{|A|}{u}>1.

Hence, we get

. If
u>1
, we can similarly show that
u^{\frac{1}{p_{A}^{+}}}\leq\|1_{A}\|_{L^{\Phi(\cdot,\cdot)}(\Omega)}
. The first inequality follows as

.
∎

Lemma 4.2
.

Let
\Phi:\Omega\times[0,\infty)\rightarrow[0,\infty]

\min\{|A|^{\frac{1}{p_{A}^{+}}},|A|^{\frac{1}{p_{A}^{-}}}\}\leq\|1_{A}\|_{L^{\Phi(\cdot,\cdot)}(\Omega)}\leq\max\{2(1+||a||_{\infty})^{\frac{1}{p_{A}^{-}}}|A|^{\frac{1}{p_{A}^{+}}},2(1+||a||_{\infty})^{\frac{1}{p_{A}^{-}}}|A|^{\frac{1}{p_{A}^{-}}}\},

We start with the proof of the second inequality of (

). Let

. Then we have

\displaystyle\frac{a(x)\big(\log(e+\frac{1}{2(1+||a||_{\infty})^{\frac{1}{p_{A}^{-}}}u^{\frac{1}{p_{A}^{+}}}})\big)^{r(x)}}{2^{p(x)}(1+||a||_{\infty})^{\frac{p(x)}{p_{A}^{-}}}u^{\frac{p(x)}{p_{A}^{+}}}}dx

.

Hence, we get

. If

. The first inequality follows as

.
∎

Lemma 4.3
.

Let
\Phi:\Omega\times[0,\infty)\rightarrow[0,\infty)
be given by
\Phi(x,t):=t^{p(x)}+a(x)t^{p(x)}(\log(e+t))^{r(x)}
where

for some

r(x)\geq 0
for some
x
. Assume

is a measurable set with

. Then, there exist constant

such that

(4.5)

|A|^{\frac{1}{p_{A}^{-}}}\leq\|1_{A}\|_{L^{\Phi(\cdot,\cdot)}(\Omega)}\leq b_{2}\max 4(1+||a||_{\infty})^{\frac{1}{p_{A}^{-}}}\{|A|^{\frac{1}{p_{A}^{+}}}\big(\log(e+\frac{1}{|A|})\big)^{r_{A}^{+}},|A|^{\frac{1}{p_{A}^{-}}}\big(\log(1+e)\big)^{r_{A}^{+}}\},

Proof.

We start with the proof of the second inequality of (
4.5
). Let
u>|A|
and assume first that

x\in\Omega
): Using the above inequality, one obtains

\displaystyle R_{i}-R_{i+1}

\displaystyle\leq

\displaystyle C_{1}(1+||a||_{\infty})^{\frac{1}{p^{-}}}2^{\frac{1}{p^{-}}-\frac{1}{n}+1}|A_{R_{i}}|^{\frac{1}{n}+\frac{1}{p_{A_{R_{i}}}^{+}}-\frac{1}{p_{A_{R_{i}}}^{-}}}(\log(e+\frac{1}{|A_{R_{i}}|}))^{r_{A_{R_{i}}}^{+}}

\displaystyle\leq

\displaystyle C_{1}(1+||a||_{\infty})^{\frac{1}{p^{-}}}2^{\frac{1}{p^{-}}-\frac{1}{n}+1}|A_{R_{i}}|^{\frac{1}{n}+\frac{1}{p_{A_{R}}^{+}}-\frac{1}{p_{A_{R}}^{-}}}(\log(e+\frac{1}{|A_{R_{i}}|}))^{r_{A_{R}}^{+}}

\displaystyle=

\displaystyle C_{1}(1+||a||_{\infty})^{\frac{1}{p^{-}}}2^{\frac{1}{p^{-}}-\frac{1}{n}+1}\frac{|A_{R}|^{\eta_{R}}}{2^{i\eta_{R}}}(\log(e+\frac{2^{i}}{|A_{R}|}))^{r_{A_{R}}^{+}},

\displaystyle\leq

\displaystyle c_{3}\frac{i^{q_{A_{R}}^{+}}|A_{R}|^{\eta_{R}}}{2^{i\eta_{R}}}(\log(e+\frac{1}{|A_{R}|}))^{r_{A_{R}}^{+}}

where
\eta_{R}:=\frac{1}{n}+\frac{1}{p_{A_{R}}^{+}}-\frac{1}{p_{A_{R}}^{-}}.

c_{3}={C_{1}}2^{r^{+}}.

Since we have
(\log(e+\frac{2^{i}}{|A_{R}|}))^{r_{A_{R}}^{+}}\leq i^{r_{A_{R}}^{+}}(\log(e+\frac{2}{|A_{R}|}))^{r_{A_{R}}^{+}}\leq 2^{r^{+}}i^{r_{A_{R}}^{+}}(\log(e+\frac{1}{|A_{R}|}))^{r_{A_{R}}^{+}}
for
i\geq 1,
we obtain

\displaystyle R_{i}-R_{i+1}

\displaystyle\leq

\displaystyle C_{1}\frac{|A_{R}|^{\eta_{R}}}{2^{i\eta_{R}}}(\log(e+\frac{2^{i}}{|A_{R}|}))^{r_{A_{R}}^{+}}

\displaystyle\leq

\displaystyle c_{3}\frac{i^{r_{A_{R}}^{+}}|A_{R}|^{\eta_{R}}}{2^{i\eta_{R}}}(\log(e+\frac{1}{|A_{R}|}))^{r_{A_{R}}^{+}},

\displaystyle\leq

\displaystyle c_{3}\frac{2^{r^{+}}i^{r_{A_{R}}^{+}}|A_{R}|^{\eta_{R}}}{2^{i\eta_{R}}}(\log(e+\frac{1}{|A_{R}|}))^{r_{A_{R}}^{+}},

where
c_{3}={C_{1}}(1+||a||_{\infty})^{\frac{1}{p^{-}}}2^{\frac{1}{p^{-}}-\frac{1}{n}+1}2^{r^{+}}.

Note that
\eta_{R}\geq\eta:=\frac{1}{n}+\frac{1}{p^{+}}-\frac{1}{p^{-}}
and by the integral test
\sum_{i=1}^{\infty}{i^{r_{A_{R}}^{+}}}{2^{-i\eta_{R}}}\leq\frac{(r_{A_{R}}^{+})!}{(\eta_{R}\ln 2)^{(r_{A_{R}}^{+}+1)}}
and hence

\displaystyle R=\sum_{i=0}^{\infty}(R_{i}-R_{i+1})

\displaystyle\leq

\displaystyle c_{3}|A_{R}|^{\eta_{R}}(\log(e+\frac{1}{|A_{R}|}))^{r_{A_{R}}^{+}}\Big(1+\sum_{i=1}^{\infty}{i^{r_{A_{R}}^{+}}}{2^{-i\eta_{R}}}\Big)

\displaystyle\leq

\displaystyle c_{3}|A_{R}|^{\eta_{R}}(\log(e+\frac{1}{|A_{R}|}))^{r_{A_{R}}^{+}}\Big(\frac{(r_{A_{R}}^{+})!}{(\eta_{R}\ln 2)^{(r_{A_{R}}^{+}+1)}}+1\Big)

\displaystyle\leq

\displaystyle c_{3}|A_{R}|^{\eta_{R}}(\log(e+\frac{1}{|A_{R}|}))^{r_{A_{R}}^{+}}\Big(\frac{(r_{A_{R}}^{+})!}{(\eta\ln 2)^{(r_{A_{R}}^{+}+1)}}+1\Big)

\displaystyle\leq

\displaystyle c_{3}|A_{R}|^{\eta_{R}}(\log(e+\frac{1}{|A_{R}|}))^{r_{A_{R}}^{+}}\Big(\frac{(r^{+})!}{({\min(1,\eta)}\ln 2)^{(r^{+}+1)}}+1\Big)

Moreover, since
c_{4}:=1/\max\Big\{1,\Big(\frac{c_{3}(r^{+})!}{({\min(1,\eta)}\ln 2)^{(r^{+}+1)}}+c_{3}\Big)\Big\}\leq 1
one has

(4.13)

\displaystyle|A_{R}|(\log(e+\frac{1}{|A_{R}|}))^{\frac{r_{A_{R}}^{+}}{\eta_{R}}}\geq c_{4}^{1/\eta_{R}}R^{1/\eta_{R}}\geq c_{4}^{1/\eta}R^{1/\eta_{R}}=c_{4}^{1/\eta}R^{n}R^{\beta_{R}/\eta_{R}},

where
\beta_{R}:=1-n\eta_{R}
. Now we can proceed in a similar way as in case-1 to obtain

. So,
\Omega
