On tested Bousfield–Friedlander localizations
Niall Taggart

Abstract
. We demonstrate that a Bousfield–Friedlander localization with a set of test morphisms in the sense introduced by Bandklayder, Bergner, Griffiths, Johnson, and Santhanam can also be characterized as a left Bousfield localization at the set of test morphisms. This viewpoint enables us to establish a homogeneous model structure associated with any calculus arising from a Bousfield–Friedlander localization of this form. As a corollary, we show that homogeneous functors in discrete calculus coincide up to homotopy with those in Goodwillie calculus. Finally, we illustrate this framework by proving that the polynomial model structure of Weiss calculus is a particular instance of tested Bousfield–Friedlander localization.



1.
Introduction

Given a model category
\mathcal{M}
and a (Quillen) idempotent monad
Q:\mathcal{M}\to\mathcal{M}
, the Bousfield–Friedlander localization of
\mathcal{M}
(if it exists) is a method for universally inverting those morphisms of
\mathcal{M}
which become equivalences after applying
Q
. These localizations have been ubiquitous throughout homotopy theory
[
BF78
,
Bou01
]
and are an important tool in constructing model categories for functor calculus
[
BCR07
,
BR14
,
BO13
]
. The localization process has many nice features
[
Sta08
]
, but it is not clear if localizations of this form preserves cofibrant generation. This presents a hurdle in fully understanding the model structure and our ability to preform subsequent (co)localizations is hindered.

Motivated by applications to functor calculus, Bandklayder, Bergner, Griffiths, Johnson and Santhanam
[
BBG+23
]
gave general criteria for when the Bousfield–Friedlander localization on a model category of simplicial functors is cofibrantly generated. These criteria included the existence of a set
T(Q)
of
test morphisms
in
{\mathsf{Fun}}(\mathcal{C},{\mathsf{sSets}})
which detect fibrations in the Bousfield–Friedlander localization. The first result of this note is that these
tested Bousfield–Friedlander localizations
are always left Bousfield localizations with respect to a specific set of maps given by tensoring the test morphisms along a set of homotopy generators for the target category. These results will be influential in joint work of the author with Bergner, Griffiths, Johnson and Santhanam on
testing for calculi
, i.e., constructing calculi from sets of test morphisms and on understanding better the relationship between various calculi.

Theorem A

(
2.2
)
.

Let
Q:{\mathsf{Fun}}(\mathcal{C},\mathcal{D})\to{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
be a tested Quillen idempotent monad. If
\mathcal{D}
is a proper cellular (resp. combinatorial) simplicial model category, then there exists a set
T_{\mathcal{D}}(Q)
of morphisms in
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
such that the Bousfield–Friedlander localization at
Q
is the left Bousfield localization of the underlying model structure at the set
T_{\mathcal{D}}(Q)
.

As a corollary, we obtain a strengthening of the main theorem of
[
BBG+23
]
under slightly different hypotheses, see
2.4
. Of course, our proof shows cofibrant generation in a much less direct manner than that of
[
BBG+23
, Theorem 8.3]
but comes with extra pay-offs.

Corollary B

(
2.3
)
.

If
\mathcal{D}
is a proper cellular (resp. combinatorial) simplicial model category, then a tested Bousfield–Friedlander localization of
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
is cellular (resp. combinatorial).

Bandklayder, Bergner, Griffiths, Johnson and Santhanam
[
BBG+23
]
applied their theory to two forms of functor calculus: Goodwillie calculus
[
Goo90
,
Goo92
,
Goo03
]
and the discrete calculus of Bauer, Johnson and McCarthy
[
BJM15
]
. In both cases the degree
n
model structures are constructed as a Bousfield–Friedlander localization
[
BCR07
,
BR14
,
BBG+23
]
and a set of test morphisms is provided. We show that when a calculus exists via tested Bousfield–Friedlander localizations, we can also produce a model structure that captures the homogeneous functors: those functors which are degree
n
and have trivial degree
(n-1)
approximation.

Theorem C

(
3.2
)
.

Under modest hypotheses, if a degree
n
model structure exists on
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
, then there is a model structure on
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
in which the bifibrant objects are the bifibrant
n
-homogeneous functors.

In
3.3
we leverage
C
to show that (up to homotopy) a functor is
n
-homogeneous in the sense of Goodwillie calculus if and only if it is
n
-homogeneous in the discrete calculus.

In Weiss calculus
[
Wei95
,
Wei98
]
, Barnes and Oman
[
BO13
]
constructed an
n
-polynomial model structure as both a left Bousfield localization (motivated by having the fibrant objects the
n
-polynomial functors) and a Bousfield–Friedlander localization (motivated by having the universal degree
n
approximation as a fibrant replacement) and showed that these model structures are identical by showing they have the same cofibrations and weak equivalences. This model structure is tested.

Theorem D

(
4.2
)
.

The
n
-polynomial model structure is a tested Bousfield–Friedlander localization.

Definition 2.1
.

A Quillen idempotent monad
Q
on
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
is said to be
tested
if there exists a collection
T(Q)
morphisms in
{\mathsf{Fun}}(\mathcal{C},{\mathsf{sSets}})
such that, for each fibration
F\rightarrow G
in
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})

{\lx@inpgf@ignorespaces QF}

{\lx@inpgf@ignorespaces QG}

. We will refer to the set

as a set of

and a Bousfield–Friedlander localization with a collection of test morphisms will be called

.

We now show that a tested Bousfield–Friedlander localization may be equivalently described as a left Bousfield localization “at” the set of test morphisms, where “at” has to be suitably interpreted since the test morphisms are not morphisms in the correct category. We state and prove the following result for the projective model structure on
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
but the proof makes it clear that it holds in any model structure on
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
which is proper and cellular (resp. combinatorial).

Theorem 2.2
.

Let
Q
be a tested Quillen idempotent monad on
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
. If
\mathcal{D}
is equipped with a proper cellular (resp. combinatorial) simplicial model structure, then there exists a set
T_{\mathcal{D}}(Q)
of morphisms in
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
such that the Bousfield–Friedlander localization
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})_{Q}
is the left Bousfield localization of the projective model structure on
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
at the set
T_{\mathcal{D}}(Q)
.

Proof.

Define

T_{\mathcal{D}}(Q)=\{G\otimes X\to G\otimes Y\mid G\in\mathcal{G},X\to Y\in T(Q)\},

where
\mathcal{G}
is a set of cofibrant homotopy generators for
\mathcal{D}
in the sense of
[
Dug01
, Proposition A.5]
, see also
[
Bal21
, Lemma 3.4.5]
, and
G\otimes X
is given by
(G\otimes X)(C)=G\otimes X(C)
, where
\otimes
denotes the tensoring of
\mathcal{D}
over simplicial sets. The existence of the set
T_{\mathcal{D}}(Q)
follows from the assumption that
\mathcal{D}
is left proper and cofibrantly generated. The assumptions on
\mathcal{D}
guarantee that the projective model structure on
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
is left proper and cellular (resp. combinatorial) by combining
[
Hir03
, Proposition 4.1.5]
with
[
Hir03
, Theorem 11.7.3]
. As such,
[
Hir03
, Theorem 4.1.1]
yields that the left Bousfield localization of
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
at the set
T_{\mathcal{D}}(Q)
exists.

It is left to show that the left Bousfield localized model structure agrees with the Bousfield–Friedlander model structure. Both model structures have the same cofibrations, namely those of the underlying model structure on
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
, so it suffices by
[
Bal21
, Proposition 2.1.11]
to show that they have the same fibrant objects.

The fibrant objects in the left Bousfield localization are the
T_{\mathcal{D}}(Q)
-local functors: a functor
F:\mathcal{C}\to\mathcal{D}
is
T_{\mathcal{D}}(Q)
-local if and only if
F
is underlying fibrant and the induced map

\Map_{{\mathsf{Fun}}(\mathcal{C},\mathcal{D})}(G\otimes Y,F)\longrightarrow\Map_{{\mathsf{Fun}}(\mathcal{C},\mathcal{D})}(G\otimes X,F)

for

in

is a weak equivalence of simplicial sets by
[
Hir03
, Example 17.1.4]
.
By adjunction
[
BBG+23
, Proposition 2.13]
, this is equivalent to asking that the map

\Map_{\mathcal{D}}(G,F^{Y})\longrightarrow\Map_{\mathcal{D}}(G,F^{X}),

be a weak equivalence of simplicial sets. Since
\mathcal{G}
is a set of cofibrant homotopy generators, it follows from
[
Dug01
, Proposition A.5]
that the above map is a weak equivalence if and only if

is a weak equivalence. Hence a functor

is

-local if and only if

is underlying fibrant and

is a weak equivalence for every

.

On the other hand,

is fibrant in the Bousfield–Friedlander localization if and only if

is underlying fibrant and the square

{\lx@inpgf@ignorespaces QF}
{\lx@inpgf@ignorespaces\ast}
{\lx@inpgf@ignorespaces{Q(\ast)}}

is a homotopy pullback square. By the existence of a set

being a homotopy pullback square for all test morphisms

Corollary 2.3
.

Let
Q
be a tested Quillen idempotent monad on
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
. If
\mathcal{D}
is equipped with a proper cellular (resp. combinatorial) simplicial model structure, then the Bousfield–Friedlander localization
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})_{Q}
is a proper cellular (resp. combinatorial) simplicial model category. In particular, the Bousfield–Friedlander localization is cofibrantly generated.

Remark 2.4
.

Our hypotheses are a little different to those of Bandklayder, Bergner, Griffiths, Johnson and Santhanam
[
BBG+23
, Theorem 8.3]
. Firstly, because of the known existence results for left Bousfield localizations
[
Hir03
, Theorem 4.1.1]
we have to require that
\mathcal{D}
is left proper and cellular (resp. combinatorial). Our right properness assumption is only used in an application of
[
BBG+23
, Proposition 2.3]
. On the other hand Theorem
8.3
of loc. cit. has many assumptions (see Conventions
2.8
,
3.1
,
5.7
, and
6.2
of loc. cit.) but upon close examination of the proof the authors only use that
\mathcal{D}
is a cofibrantly generated right proper simplicial model category such that the set
J_{\mathcal{D}}
of generating cofibrations of
\mathcal{D}
may be chosen such that the codomain of each map is finite relative to
J_{\mathcal{D}}
, and that
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
is cofibrantly generated right proper with fibrations also projective fibrations. This overstatement of the conventions required for Theorem
8.3
of loc. cit. follows from the intended applications, i.e., these assumptions are required when considering the homotopy functor and degree
n
model structures. Note also that our proof does not require the fibrations of
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
to be projective fibrations. This assumption in loc. cit. is an artifact of the method of proof via explicitly constructing a set of generating acyclic cofibrations.

3.
An application to functor calculus

Functor calculi are a family of homotopy theoretic abstractions of differential calculus. They have had wide ranging applications throughout mathematics including applications of Goodwillie calculus
[
Goo90
,
Goo92
,
Goo03
]
to algebraic
K
-theory
[
McC97
]
and applications of Weiss calculus to study problems of geometric origin
[
KRW21
,
Hu23
]
. To a functor
F
, a calculus assigns a sequence of functors approximating
F

{\lx@inpgf@ignorespaces F}
{\lx@inpgf@ignorespaces\cdots}
{\lx@inpgf@ignorespaces{P_{n}F}}
{\lx@inpgf@ignorespaces\cdots}
{\lx@inpgf@ignorespaces{P_{1}F}}
{\lx@inpgf@ignorespaces{P_{0}F}}

in a way analogous to the Taylor series for a function. The functor
P_{n}F
is the
universal degree
n
functor under
F
, where the definition of degree
n
is dependent on the choice of calculus. We will always assume that
P_{n}F
is fibrant, since this can be arranged
[
BBG+23
]
. Throughout this section we will assume the existence of such a calculus and a corresponding degree
n
model structure for comes to us as a tested Bousfield–Friedlander localization.

The Bousfield–Friedlander localization of a suitable model structure on a category of functors yields a model structure in which the fibrant objects are precisely the degree
n
functors. This approach has seen success in Goodwillie calculus by Biedermann, Chorny, and Röndigs
[
BCR07
,
BR14
]
and in Weiss calculus by Barnes and Oman
[
BO13
]
. The seminal work of Bandklayder, Bergner, Griffiths, Johnson and Santhanam
[
BBG+23
]
shows that the Bousfield–Friedlander localization in Goodwillie calculus is tested, and extends the theory to construct a degree
n
model structure for the discrete calculus of Bauer Johnson and McCarthy
[
BJM15
]
as a tested Bousfield–Friedlander localization. In
Section

4
we show that the corresponding localization in Weiss calculus is also tested. We summarise these results here.

Lemma 3.1
.

Under suitable hypotheses, the
n
-excisive model structure for Goodwillie calculus and the degree
n
model structure for discrete calculus are both tested Bousfield–Friedlander localizations of
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
which are in addition left Bousfield localizations.

Proof.

The model structures are tested Bousfield–Friedlander localizations by
[
BBG+23
, Proposition 9.2]
and
[
BBG+23
, Lemma 10.3]
, respectively, from which the reader may read off the required hypotheses. The result follows from
2.3
if
\mathcal{D}
is additionally left proper and cellular (resp. combinatorial).
∎

A functor
F:\mathcal{C}\to\mathcal{D}
is
n
-homogeneous if it is degree
n
(i.e.,
F\to P_{n}F
is an equivalence) and
n
-reduced
(i.e., the degree
(n-1)
approximation
P_{n-1}F
is trivial). By utilising the description of a tested Bousfield–Friedlander localization as a left Bousfield localization in
2.2
we can produce a model structure in which the bifibrant objects are the
n
-homogeneous functors.

Theorem 3.2
.

If for all
n\in\mathbb{N}
, there exists a proper cellular (resp. combinatorial) degree
n
model structure as a tested Bousfield–Friedlander localization, then there is a model structure on
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
in which the cofibrant objects are the underlying cofibrant
n
-reduced functors and the fibrations are the fibrations of the degree
n
model structure. In particular the bifibrant objects are the bifibrant
n
-homogeneous functors. We call this the
n
-homogeneous model structure.

Proof.

Let
T(P_{n})
denote the set of test morphisms for the degree
n
model structure. By
2.2
, the degree
n
model structure is the left Bousfield localization at the set

T_{\mathcal{D}}(P_{n})=\{G\otimes T\mid G\in\mathcal{G},T\in T(P_{n})\},

where
\mathcal{G}
is a set of cofibrant homotopy generators for
\mathcal{D}
. It follows from
2.3
that the degree
n
model structure is a right proper cellular model category. Let

K(P_{n-1})=\{\hocof(T)\mid T\in T(P_{n-1})\}

be the set of homotopy cofibres of the set of test morphisms for the degree
(n-1)
model structure, and let

K_{\mathcal{D}}(P_{n-1})=\{G\otimes K\mid G\in\mathcal{G},K\in K(P_{n})\}.

We claim that the required model structure is the right Bousfield localization of the degree
n
-model structure at the set
K_{\mathcal{D}}(P_{n-1})
. The right Bousfield localization exists by
[
Hir03
, Theorem 5.1.1]
and the fibrations follow immediately from loc. cit., hence it suffices to show that the cofibrant objects are the underlying cofibrant
n
-reduced functors.

We will show that a map
E\to F
is a cofibration in the
n
-homogeneous model structure if and only if
E\to F
is a underlying cofibration and a weak equivalence in the degree
(n-1)
model structure. Arguing analogously to
[
Tag22a
, Lemma 8.5]
, it suffices to show that a map
X\to Y
between degree
n
functors is an acyclic fibration in the
n
-homogeneous model structure if and only if
X\to Y
is a fibration between degree
n
functors in the degree
(n-1)
model structure.

Arguing analogously to
[
Tag22a
, Proposition 8.3]
we see that a map
X\to Y
is an acyclic fibration in the
n
-homogeneous model structure if and only if
X\to Y
is a fibration in the degree
(n-1)
model structure and a weak equivalence in the
n
-homogeneous model structure. So to complete the proof it suffices to show that if
X\to Y
is a fibration in the degree
(n-1)
model structure between degree
n
functors, then
X\to Y
is a weak equivalence in the
n
-homogeneous model structure.

Consider the commutative diagram

{\lx@inpgf@ignorespaces X}
{\lx@inpgf@ignorespaces{P_{n}X}}
{\lx@inpgf@ignorespaces{P_{n-1}X}}
{\lx@inpgf@ignorespaces Y}
{\lx@inpgf@ignorespaces{P_{n}Y}}
{\lx@inpgf@ignorespaces{P_{n-1}Y}}
\scriptstyle{\lx@inpgf@ignorespaces\simeq}
\scriptstyle{\lx@inpgf@ignorespaces\simeq}

in which the left-most horizontal maps are equivalences since
X
and
Y
are assumed degree
n
. Since
X\to Y
is assumed to be a fibration in the degree
(n-1)
-model structure the outer-most square is a homotopy pullback diagram and the left-most square is a homotopy pullback since two horizontal maps are equivalences. It follows that the right-most square is also a homotopy pullback. Since
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
is right proper, it now suffices to show that the map
P_{n-1}X\to P_{n-1}Y
is a weak equivalence in the
n
-homogeneous model structure.

By the general theory of right Bousfield localizations, a map
X\to Y
is a weak equivalence in the
n
-homogeneous model structure if and only if the induced map

\Map_{{\mathsf{Fun}}(\mathcal{C},\mathcal{D})}(G\otimes K,P_{n}X)\longrightarrow\Map_{{\mathsf{Fun}}(\mathcal{C},\mathcal{D})}(G\otimes K,P_{n}Y),

is a weak equivalence of simplicial sets. The map
P_{n-1}X\to P_{n-1}Y
is a weak equivalence in the
n
-homogeneous model structure since degree
(n-1)
functors are trivial in the
n
-homogeneous model structure. Indeed, for every
T:A\to B
in
T(P_{n-1})
, there is a homotopy fibre sequence

\Map_{{\mathsf{Fun}}(\mathcal{C},\mathcal{D})}(G\otimes\hocof(T),F)\longrightarrow\Map_{{\mathsf{Fun}}(\mathcal{C},\mathcal{D})}(G\otimes B,F)\longrightarrow\Map_{{\mathsf{Fun}}(\mathcal{C},\mathcal{D})}(G\otimes A,F),

in which the right-most map is an equivalence if
F
is a degree
(n-1)
functor by the fact that
T_{\mathcal{D}}(P_{n-1})
is a set of test morphisms for the degree
(n-1)
model structure. It follows that for every
G\otimes\hocof(T)\in K_{\mathcal{D}}(P_{n-1})
the simplicial set
\Map_{{\mathsf{Fun}}(\mathcal{C},\mathcal{D})}(G\otimes\hocof(T),F)
is contractible and hence
F
is trivial in the
n
-homogeneous model structure.
∎

As a corollary, we see that a functor is
n
-homogeneous in the discrete calculus if and only if it is
n
-homogeneous in Goodwillie calculus, an observation that we do not believe is present in the literature, and is a generalisation of a result original proven by Johnson and McCarthy in the abelian functor calculus
[
JM04
, Proposition 3.9]
.

Corollary 3.3
.

Under the hypotheses of
3.1
, the
n
-homogeneous model structure on
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
for the discrete calculus is identical the the
n
-homogeneous model structure on
{\mathsf{Fun}}(\mathcal{C},\mathcal{D})
for Goodwillie calculus.

Proof.

The test morphisms for degree
(n-1)
model structure in discrete calculus is given by

T(\Gamma_{n})=\left\{\underset{S\subseteq\underline{n}}{\hocolim}~R^{\bigvee_{i\in\underline{n}\setminus S}A}\longrightarrow R^{\bigvee_{i=1}^{n}A}\mid A\in\mathcal{C}\right\},

where
R^{X}
is the representable functor on
X
. It follows from a routine calculation that

K(\Gamma_{n})=\left\{\bigwedge_{i=1}^{n}R^{A}\mid A\in\mathcal{C}\right\}.

The right Bousfield localization at the set
K(\Gamma_{n})
yields the
n
-homogeneous model structure for discrete calculus by
3.2
, but also the
n
-homogeneous model structure for Goodwillie calculus by
[
BR14
, Theorem 6.4]
. The model structure of loc. cit. is identical to our
n
-homogeneous model structure for Goodwillie calculus since it has the same cofibrant objects and fibrations, see
[
BCR07
, Corollary 6.25]
.
∎

4.
An application to Weiss calculus

We can now show that the the polynomial model structures for Weiss calculus fit within the framework of
[
BBG+23
]
. We will only consider Weiss calculus
[
Wei95
,
Wei98
]
for functors with values in the category
{\mathsf{sSets}}
of simplicial sets since we have worked simplicially throughout this note. The proofs readily extend to the topological setting and to any known variant of Weiss calculus
[
Tag22a
,
Tag22b
,
Tag24
,
CT24
]
. Extensions to other target categories forms part of the work in progress of the author with Bergner, Griffiths, Johnson and Santhanam.

Denote by
\mathsf{Vect}_{\mathbb{k}}
the simplicial category of finite-dimensional inner product spaces over
\mathbb{k}
with linear isometric isomorphisms for
\mathbb{k}
either the reals, complex numbers or quaternions. The morphism simplicial set
\mathsf{Vect}_{\mathbb{k}}(V,W)
is given by applying the singular simplicial set functor to the Stiefel manifold of
\dim(V)
-frames in
W
.

Definition 4.1
.

A simplicial functor
F:\mathsf{Vect}_{\mathbb{k}}\to{\mathsf{sSets}}
is
n
-polynomial
if the canonical map

F(V)\longrightarrow\underset{0\neq U\subseteq\mathbb{k}^{n+1}}{\holim}~F(V\oplus U)=:T_{n}F(V),

is an equivalence, for all
V\in\mathsf{Vect}_{\mathbb{k}}
. The homotopy limit is taken over the category of non-zero linear subspaces of
\mathbb{k}^{n+1}
, see e.g.,
[
Wei98
]
for more on this homotopy limit and note that we have used different notation from loc. cit.

By the (evaluated cotensor version of) Yoneda Lemma
[
BBG+23
, Lemma 2.14]
and
[
BBG+23
, Proposition 2.18]
, a functor is
n
-polynomial if and only if the map

F^{\mathsf{Vect}_{\mathbb{k}}(V,-)}\longrightarrow F^{\hocolim_{0\neq U\subseteq\mathbb{k}^{n+1}}\mathsf{Vect}_{\mathbb{k}}(V\oplus U,-)}

is an equivalence for each
V\in\mathsf{Vect}_{\mathbb{k}}
. Define the universal
n
-polynomial approximation as

P_{n}F=\hocolim(F\to T_{n}F\to T_{n}^{2}F\to\cdots).

A proof that
P_{n}F
is
n
-polynomial may be found in
[
Wei98
]
. Barnes and Oman
[
BO13
, Proposition 6.5]
constructed an
n
-polynomial model structure for Weiss calculus by Bousfield–Friedlander localizing the projective model structure at the endofunctor
P_{n}
. They then go on to show
[
BO13
, Proposition 6.6]
that this model structure is a left Bousfield localization, which corrects the lack of cofibrant generation. Using
A
we give an alternative proof.

Theorem 4.2
.

The
n
-polynomial model structure is a tested Bousfield–Friedlander localization with set of test morphisms given by

T(P_{n})=\left\{\underset{0\neq U\subseteq\mathbb{k}^{n+1}}{\hocolim}~\mathsf{Vect}_{\mathbb{k}}(V\oplus U,-)\longrightarrow\mathsf{Vect}_{\mathbb{k}}(V,-)\mid V\in\mathsf{Vect}_{\mathbb{k}}\right\}.

In particular, the
n
-polynomial model structure is proper and cellular.

Proof.

With this choice of test morphisms, the discussion directly preceding the theorem statement reduces the proof to showing that for
F\to G
a projective fibration, the square

{\lx@inpgf@ignorespaces F}
{\lx@inpgf@ignorespaces{P_{n}F}}
{\lx@inpgf@ignorespaces G}
{\lx@inpgf@ignorespaces{P_{n}G}}

is a homotopy pullback if and only if the square

{\lx@inpgf@ignorespaces F}
{\lx@inpgf@ignorespaces{T_{n}F}}
{\lx@inpgf@ignorespaces G}
{\lx@inpgf@ignorespaces{T_{n}G}}

is a homotopy pullback. The proof of this biconditional statement follows analogously to
[
BBG+23
, Proposition 9.2]
since loc. cit. only uses intrinsic properties of a functor calculus.
∎
