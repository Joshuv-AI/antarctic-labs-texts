Abstract
. In this study, we explore the arithmetic properties of b 7 k ​ ( n ) b_{7^{k}}(n) for any k ≥ 1 k\geq 1 , which enumerates the partitions of n n where no part is divisible by 7 k 7^{k} . Introduction

A partition of a positive integer
n

n

p(n)
denote the number of partitions of
n

\sum\limits_{n\geq 0}p(n)q^{n}=\frac{1}{f_{1}}.

Throughout this paper, we define

f_{r}:=(q^{r};q^{r})_{\infty}=\prod\limits_{m=1}^{\infty}(1-q^{rm}).

Ramanujan

14

\ell\in\{5,7,11\}

0<\delta_{\ell,\beta}<\ell^{\beta}

n\geq 0

p\left(\ell^{\beta}n+\delta_{\ell,\beta}\right)\equiv 0\pmod{\ell^{\beta}}.

(1.1)

[
16

for the case
\ell=5

p(243)

7^{3}

\ell=7
and
\beta=3

p(7^{2k-1}n+\lambda_{2k-1})\equiv 0\pmod{7^{k}},

(1.2)

p(7^{2k}n+\lambda_{2k})\equiv 0\pmod{7^{k+1}},

(1.3)

Theorem 1.1
.

For each

2.
Preliminaries

In this section, we present several lemmas that serve as foundational tools for establishing our main results.
Let
H
be the “huffing” operator modulo
7
, that is,

H\left(\sum{a(n)q^{n}}\right)=\sum{a(7n)q^{7n}}.

Lemma 2.1

(
[
10
]
, Lemma 3.1 and 3.4)
.

If
\xi=\frac{f_{1}}{q^{2}f_{49}}
and
T=\frac{f_{7}^{4}}{q^{7}f_{49}^{4}}
, then

H\left(\xi^{-i}\right)=\sum_{j\geq 1}m_{i,j}T^{-j}

(2.1)

and

H\left(\xi^{-4i}\right)=\sum_{j\geq 1}m_{4i,i+j}T^{-i-j}.

(2.2)

Lemma 2.2
.

For all
i\geq 1
, we have

\displaystyle H\left(q^{i-2}\frac{f_{7}^{4i-1}}{f_{1}^{4i-1}}\right)

\displaystyle=\sum_{j\geq 1}m_{4i-1,i+j-1}q^{7j-7}\frac{f_{49}^{4j-3}}{f_{7}^{4j-3}},

(2.3)

\displaystyle H\left(q^{i+1}\frac{f_{7}^{4i-3}}{f_{1}^{4i-3}}\right)

\displaystyle=\sum_{j\geq 1}m_{4i-3,i+j-1}q^{7j}\frac{f_{49}^{4j-1}}{f_{7}^{4j-1}},

(2.4)

and

H\left(q^{i}\frac{f_{7}^{4i}}{f_{1}^{4i}}\right)=\sum_{j\geq 1}m_{4i,i+j}\,q^{7j}\frac{f_{49}^{4j}}{f_{7}^{4j}}.\\

(2.5)

Proof.

From (
2.1
), we have

H\left(q^{2i}\frac{f_{49}^{i}}{f_{1}^{i}}\right)=\sum_{j\geq 1}m_{i,j}\,q^{7j}\frac{f_{49}^{4j}}{f_{7}^{4j}}.

The fact that
m_{4i-1,j}=0
for
1\leq j<i
implies that

\displaystyle H\left(\left(q^{2}\frac{f_{49}}{f_{1}}\right)^{4i-1}\right)

\displaystyle=\sum_{j\geq i}m_{4i-1,j}\,q^{7j}\frac{f_{49}^{4j}}{f_{7}^{4j}}

\displaystyle=\sum_{j\geq 1}m_{4i-1,j+i-1}\,q^{7j+7i-7}\frac{f_{49}^{4j+4i-4}}{f_{7}^{4j+4i-4}},

which yields (
2.3
). Similarly, we can prove (
2.4
) and (
2.5
) follows from (
2.2
).
∎

3.
Generating functions

In this section, we establish generating functions for
b_{7^{\ell}}(n)
within specific arithmetic progressions.

Theorem 3.1
.

For each
\beta\geq 0
and
k\geq 1
, we have

\displaystyle\sum_{n\geq 0}b_{7^{2k-1}}\left(7^{2k+2\beta-1}n+\frac{18\cdot 7^{2k+2\beta-1}-7^{2k-1}+1}{24}\right)q^{n}

\displaystyle=\sum_{j\geq 1}y^{(2k-1)}_{2\beta+1,j}\,q^{j-1}\left(\frac{f_{7}}{f_{1}}\right)^{4j-1}

(3.1)

and

\sum_{n\geq 0}b_{7^{2k-1}}\left(7^{2k+2\beta}n+\frac{6\cdot 7^{2k+2\beta}-7^{2k-1}+1}{24}\right)q^{n}=\sum_{j\geq 1}y^{(2k-1)}_{2\beta+2,j}\,q^{j-1}\left(\frac{f_{7}}{f_{1}}\right)^{4j-3},

(3.2)

where the coefficient vectors are defined as follows:

y_{1,j}^{(2k-1)}=x_{2k-1,j}

(3.3)

and

y^{(2k-1)}_{\beta+1,j}=\begin{cases}\displaystyle\sum_{i\geq 1}y^{(2k-1)}_{\beta,i}m_{4i-1,i+j-1}\,\,\ &\text{if $\beta$ is odd},\\
\displaystyle\sum_{i\geq 1}y^{(2k-1)}_{\beta,i}m_{4i-3,i+j-1}\,\,\ &\text{if $\beta$ is even},\end{cases}

(3.4)

for all
\beta,j\geq 1
.

Proof.

From (
1.7
), we have

\sum\limits_{n\geq 0}b_{7^{2k-1}}(n)q^{n}=f_{7^{2k-1}}\sum\limits_{n\geq 0}p(n)q^{n}.

(3.5)

Extracting the terms involving
q^{7^{2k-1}n+\lambda_{2k-1}}
on both sides of (
3.5
) and dividing throughout by
q^{\lambda_{2k-1}}
, we obtain

\sum\limits_{n\geq 0}b_{7^{2k-1}}(7^{2k-1}n+\lambda_{2k-1})q^{7^{2k-1}n}=f_{7^{2k-1}}\sum\limits_{n\geq 0}p(7^{2k-1}n+\lambda_{2k-1})q^{7^{2k-1}n}.

If we replace
q^{7^{2k-1}}
by
q
and use (
1.4
), we get

\sum\limits_{n\geq 0}b_{7^{2k-1}}(7^{2k-1}n+\lambda_{2k-1})q^{n}=\sum_{j\geq 1}x_{2k-1,j}\,q^{j-1}\frac{f_{7}^{4j-1}}{f_{1}^{4j-1}},

which is the case
\beta=0
of (
3.1
).

We now assume that (
3.1
) is true for some integer
\beta\geq 0
. Applying the operator
H
to both sides, by (
2.3
), we have

\displaystyle\sum_{n\geq 0}b_{7^{2k-1}}\left(7^{2k+2\beta}n+\frac{6\cdot 7^{2k+2\beta}-7^{2k-1}+1}{24}\right)q^{7n}

\displaystyle=\sum_{i\geq 1}y^{(2k-1)}_{2\beta+1,i}\,H\left(q^{i-2}\frac{f_{7}^{4i-1}}{f_{1}^{4i-1}}\right)

\displaystyle=\sum_{i\geq 1}y^{(2k-1)}_{2\beta+1,i}\sum_{j\geq 1}m_{4i-1,i+j-1}\,q^{7j-7}\frac{f_{49}^{4j-3}}{f_{7}^{4j-3}}

\displaystyle=\sum_{j\geq 1}\left(\sum_{i\geq 1}y^{(2k-1)}_{2\beta+1,i}\,m_{4i-1,i+j-1}\right)q^{7j-7}\frac{f_{49}^{4j-3}}{f_{7}^{4j-3}}

\displaystyle=\sum_{j\geq 1}y^{(2k-1)}_{2\beta+2,j}\,q^{7j-7}\frac{f_{49}^{4j-3}}{f_{7}^{4j-3}}.

That is,

\sum_{n\geq 0}b_{7^{2k-1}}\left(7^{2k+2\beta}n+\frac{6\cdot 7^{2k+2\beta}-7^{2k-1}+1}{24}\right)q^{n}=\sum_{j\geq 1}y^{(2k-1)}_{2\beta+2,j}\,q^{j-1}\frac{f_{7}^{4j-3}}{f_{1}^{4j-3}}.

Hence if (
3.1
) is true for some integer
\beta\geq 0
, then (
3.2
) is true for
\beta
.
Suppose that (
3.2
) is true for some integer
\beta\geq 0
. Applying the operating
H
to both sides, by (
2.4
), we obtain

\displaystyle\sum_{n\geq 0}b_{7^{2k-1}}\left(7^{2k+2\beta+1}n+\frac{18\cdot 7^{2k+2\beta+1}-7^{2k-1}+1}{24}\right)q^{7n+7}

\displaystyle=\sum_{i\geq 1}y^{(2k-1)}_{2\beta+2,i}\sum_{j\geq 1}m_{4i-3,i+j-1}q^{7j}\,\frac{f_{49}^{4j-1}}{f_{7}^{4j-1}}

\displaystyle=\sum_{j\geq 1}\left(\sum_{i\geq 1}y^{(2k-1)}_{2\beta+2,i}\,m_{4i-3,i+j-1}\right)q^{7j}\,\frac{f_{49}^{4j-1}}{f_{7}^{4j-1}}

\displaystyle=\sum_{j\geq 1}y^{(2k-1)}_{2\beta+3,j}\,q^{7j}\,\frac{f_{49}^{4j-1}}{f_{7}^{4j-1}},

This is (

) with

\beta+1
