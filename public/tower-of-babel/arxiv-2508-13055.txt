Weighted Partition Vertex and Edge Cover
Rajni Dabas, Samir Khuller, Emilie Rivkin

Abstract
We study generalizations of the classical Vertex Cover and Edge Cover problems that incorporate group-wise coverage constraints. Our first focus is the Weighted Prize-Collecting Partition Vertex Cover (WP-PVC) problem: given a graph with weights on both vertices and edges, and a partition of the edge set into ω \omega groups, the goal is to select a minimum-weight subset of vertices such that, in each group, the total weight (profit) of covered edges meets a specified threshold. This formulation generalizes classical vertex cover, partial vertex cover and partition vertex cover. We present two algorithms for WP-PVC. The first is a simple 2-approximation that solves n ω n^{\omega} LP’s, improving over prior work by Bandyapadhyay et al. by removing an enumerative step and the extra ϵ \epsilon -factor in approximation, while also extending to the weighted setting. The second is a bi-criteria algorithm that applies when ω \omega is large, approximately meeting profit targets with a bounded LP-relative cost. We also study a natural generalization of the edge cover problem, the Weighted Partition Edge Cover (W-PEC) problem, where each edge has an associated weights, and the vertex set is partitioned into groups. For each group, the goal is to cover at least a specified number of vertices using incident edges, while minimizing the total weight of the selected edges. We present the first exact polynomial-time algorithm for the weighted case, improving runtime from O ⁡ ( ω ​ n 3 ) O(\omega n^{3}) to O ⁡ ( m ​ n + n 2 ​ log ⁡ n ) O(mn+n^{2}\log n) and simplifying the algorithmic structure over prior unweighted approaches. We also show that the prize-collecting variant of the W-PEC problem is NP-Complete via a reduction from the knapsack problem.

Partition Vertex Cover: 2-factor approximation

First, we state the LP relaxation of the integer linear program:

minimize

\displaystyle\sum_{v\in V}w\left({v}\right)y_{v}

subject to

\displaystyle\sum_{e\in{\mathcal{C}}_{g}}p\left({e}\right)x_{e}\geq\rho_{g}

\displaystyle\qquad\forall g\in\left\{{1,\ldots,\omega}\right\}

\displaystyle y_{u}+y_{v}\geq x_{e}

\displaystyle\qquad\forall e=\left\{{u,v}\right\}\in E

\displaystyle 0\leq x_{e},y_{v}\leq 1

\displaystyle\qquad\forall e\in E,v\in V

For the first step of the algorithm, we need to modify the instance by guessing
the heaviest
\omega
vertices, of which there are
O\left({n^{\omega}}\right)
; if
the number of vertices in the optimal solution is smaller than
\omega
,
we can iterate through the possible solutions.

For some guess, say that we select the set

V_{\omega}=\left\{{v^{\prime}_{1},\ldots,v^{\prime}_{\omega}}\right\}
with
v^{\prime}_{1}\leq\cdots\leq v^{\prime}_{\omega}
.
We create a modified instance of the problem by adjusting the weight
function:

w^{\prime}\left({v}\right)=\begin{cases}0&\text{if }v\in V_{\omega}\\
w\left({v}\right)&\text{if }w\left({v}\right)<w\left({v^{\prime}_{1}}\right)\\
\infty&\text{else}\end{cases}

Now, we take this instance
\left({V,E,w^{\prime},p}\right)
and compute a fractional solution to
the LP,
\left\langle{x^{\prime},y^{\prime}}\right\rangle
, which has cost
\operatorname{OPT}_{LP}
. Recall that this is a lower
bound on the integral optimal solution. Going forward, we assume that
we have the correct guess
V_{\omega}
. Since we have correctly identified the

\omega
most expensive vertices, reducing their cost to
0
, solving the
modified instance optimally with cost
\operatorname{OPT}^{\prime}
, and then adding back the guessed vertices will return the
original integral optimal solution, so

\operatorname{OPT}_{LP}+\sum_{v\in V_{\omega}}w\left({v}\right)\leq\operatorname{OPT}^{\prime}+\sum_{v\in V_{\omega}}w\left({v}\right)=\operatorname{OPT}.

Now that we have the solution
\left\langle{x^{\prime},y^{\prime}}\right\rangle
to the LP, we want to modify it to
concentrate the coverage of each edge into exactly one endpoint. In order to accomplish this, we use a weighted variant of Lemma 1 from
[
2
]
. Their proof generalizes to the weighted case, but we present it for completeness.

Lemma 7
.

[
2
]

There is a solution
\left\langle{\tilde{x},\tilde{y}}\right\rangle
with the folowing properties:

1.

\operatorname{cost}\left({\tilde{x},\tilde{y}}\right)\leq 2\operatorname{OPT}_{LP}
;

2.

there is a function
\varphi:E\to V
such that for each edge
e=\left({u,v}\right)
,
\varphi\left({e}\right)\in\left\{{u,v}\right\}
and
\tilde{x}_{e}=\tilde{y}_{\varphi\left({e}\right)}
;

3.

\left\langle{\tilde{x},\tilde{y}}\right\rangle
can be obtained in polynomial time.

Proof.

For each edge
e=\left({u,v}\right)
, we define
\varphi\left({e}\right)=\arg\max_{u,v}\left\{{y^{\prime}_{u},y^{\prime}_{v}}\right\}
. Then, let
\tilde{x}_{e}=\min\left\{{1,2y^{\prime}_{\varphi\left({e}\right)}}\right\}
for all
e\in E
and
\tilde{y}_{v}=\min\left\{{1,2y^{\prime}_{v}}\right\}
for all
v\in V
. Therefore, we have

\tilde{x}_{e}=\min\left\{{1,2y^{\prime}_{\varphi\left({e}\right)}}\right\}=\tilde{y}_{\varphi\left({e}\right)},

which completes the second property. Moreover, for each
e=\left({u,v}\right)
,

\tilde{x}_{e}=\tilde{y}_{\varphi\left({e}\right)}\leq\tilde{y}_{u}+\tilde{y}_{v}

and

\tilde{x}_{e}=\min\left\{{1,2y^{\prime}_{\varphi\left({e}\right)}}\right\}\geq 2y^{\prime}_{\varphi\left({e}\right)}\geq y^{\prime}_{u}+y^{\prime}_{v}\geq x^{\prime}_{e},

which implies that

\rho_{g}\leq\sum_{e\in{\mathcal{C}}_{g}}p\left({e}\right)x^{\prime}_{e}\leq\sum_{e\in{\mathcal{C}}_{g}}p\left({e}\right)\tilde{x}_{e}

for each group
{\mathcal{C}}_{g}
. As a result, the solution
\left\langle{\tilde{x},\tilde{y}}\right\rangle
is feasible. To compute the cost and check the first property, we have

\sum_{v\in V}w\left({v}\right)\tilde{y}_{v}=\sum_{v\in V}w\left({v}\right)\min\left\{{1,2y^{\prime}_{v}}\right\}\leq 2\sum_{v\in V}w\left({v}\right)y^{\prime}_{v}=2\operatorname{OPT}_{LP}.

Finally, we compute the new solution by going through each edge once and checking its endpoints, which satisfies the final property.

Proof.

V_{1}=\left\{{v\in V:\hat{z}_{v}=1}\right\}

\left|{V_{F}}\right|\leq\omega

2.1
Argument for simplicity

Our algorithm differs in two ways from the
\left({2+\epsilon}\right)
-approximation of
[
2
]
. First, we only enumerate through a fixed number of solutions. Rather than check solutions up through size
\omega/\epsilon
, we look at solutions up to size
\omega
every time.

On the other hand, while the
\left({2+\epsilon}\right)
-approximation only solves one full LP and one sparse LP, our approach solves
\binom{n}{\omega}
of each LP. However, by reframing the series of LPs to solve, we can reveal a structural simplicity. We can start by sorting the vertices in increasing order by weight, renaming the vertices so that
\left\{{v_{1},\ldots,v_{n}}\right\}
is in weight order. Any vertex with higher weight than the lowest-weight guessed vertex
v_{1}^{\prime}
is removed from the LP, so the size of the LP is determined by the position of
v_{1}^{\prime}
in the order. If
v_{1}^{\prime}=v_{k}
, then we construct the LP using the smaller
k-1
vertices. The size of the LP, the objective function, and most of the constraints are now fixed.

At this choice of
v_{1}^{\prime}
, there are
\binom{n-k}{\omega-1}
different choices for the remaining
\omega-1
guessed vertices.
We can think of guessing a vertex as removing it from the problem instance and subtracting the profit gained by each adjacent edge from the constraint corresponding to the edge group. Therefore, for each guess
V_{\omega}
, the profit constraints can be written as

\sum_{e\in{\mathcal{C}}_{g}}p\left({e}\right)x_{e}\geq\rho_{g}-\sum_{v\in V_{\omega}}\sum_{\begin{subarray}{c}e\in\delta\left({v}\right)\\
\text{s.t. }e\in{\mathcal{C}}_{g}\end{subarray}}p\left({e}\right).

With the structural similarity of the LPs, we can solve them in parallel for greater efficiency.

Alternatively, we can use the discussion of sensitivity analysis in
[
10
]
to see that we can reuse information gained about the solution in a previous LP to solve the next. In fact, between two “adjacent” LPs, only one guessed vertex is different. Therefore, the change in the right-hand-side constraints is limited by the change in profit incurred by moving the guess by one vertex.

Moreover, moving from
v_{1}^{\prime}=v_{k}
to
v_{1}^{\prime}=v_{k+1}
requires adding one variable for the vertex and one variable for each edge incident on the vertex. By maintaining the old dictionaries, we can start the solving process at a better feasible solution. We need to move
v_{1}^{\prime}
up from
v_{2}
to
v_{n-\omega+1}
to cover the full range of guesses.

Partition Vertex Cover: Bi-Criteria Approximation

In this section, we present a bi-criteria approximation algorithm for the
Weighted Prize-Collecting Partition Vertex Cover
(WP-PVC) problem. Our approach is based on solving the natural LP relaxation and then applying a simple threshold-based rounding scheme. The algorithm guarantees a constant approximation, while violating the group-wise edge coverage thresholds by at most a small multiplicative factor.

Let
\langle y^{*},x^{*}\rangle
be an optimal solution to the LP relaxation of WP-PVC. Fix a threshold parameter
\epsilon>0
. We round the fractional solution
y^{*}
as follows:

1.

Let
V_{o}=\{v\in V:y_{v}^{*}<\epsilon\}
be the set of vertices with small fractional value. We round these vertices down by setting
\hat{y}_{v}=0
for all
v\in V_{o}

2.

Let
V_{r}=V\setminus V_{o}=\{v\in V:y_{v}^{*}\geq\epsilon\}
. We round up all these vertices by setting
\hat{y}_{v}=1
for all
v\in V_{r}
.

Let
S=V_{r}
denote the final selected set of vertices.

Since we only round up fractional values
y_{v}^{*}\geq\epsilon
, we have:

\sum_{v\in S}w(v)\leq\sum_{v\in V_{r}}\frac{w(v)}{\epsilon}y_{v}^{*}\leq\frac{1}{\epsilon}\sum_{v\in V}w(v)y_{v}^{*}=\frac{\operatorname{OPT}_{LP}}{\epsilon}.

Let us now analyze the edge coverage in each group
\mathcal{C}_{g}
. An edge
e=(u,v)
is included in the rounded solution (i.e., covered) if either endpoint
u
or
v
lies in
S
.

Let
\mathcal{C}_{g}^{\text{out}}\subseteq\mathcal{C}_{g}
be the set of edges with both endpoints in
V_{o}
. These are the only edges potentially uncovered after rounding. For each such edge, since
y_{u}^{*}<\epsilon
and
y_{v}^{*}<\epsilon
, we have:

x_{e}^{*}\leq y_{u}^{*}+y_{v}^{*}<2\epsilon.

Hence, the total weight of uncovered edges in
\mathcal{C}_{g}
is:

\sum_{e\in\mathcal{C}_{g}^{\text{out}}}p(e)\leq\sum_{e\in\mathcal{C}_{g}^{\text{out}}}p(e)\frac{x_{e}^{*}}{2\epsilon}\leq 2\epsilon\rho_{g}.

Thus, the rounded solution covers at least:

\sum_{\begin{subarray}{c}e=(u,v)\in\mathcal{C}_{g}\\
u\in S\text{ or }v\in S\end{subarray}}p(e)\geq\sum_{e\in\mathcal{C}_{g}}p(e)x_{e}^{*}-2\epsilon\rho_{g}\geq(1-2\epsilon)\rho_{g}.

Hence, we achieve
3
. This result yields a clean bi-criteria approximation for WP-PVC that guarantees a constant approximation vertex cost and near-complete group-wise coverage. Notably, our guarantees hold even when the number of groups
\omega
is large or grows with the input size.

, and a parameter
r_{g}
for each group. We want to find a minimum-weight matching such that at least
r_{g}
vertices from group
S_{g}
are matched.

First, we note that the reduction between Partition-EC and Budgeted Matching in Lemma 5 of
[

holds in the weighted case.

Lemma 11
.

If Weighted Budgeted Matching can be solved in time
T\left({n,m}\right)
, then Partition-EC can be solved in time
T\left({2n,m+n}\right)+O\left({m+n}\right)
. Here
n
and
m
refer to the number of nodes and edges respectively.

In order to be matched or covered at minimum cost, a vertex will pay for its least expensive adjacent edge, so we can modify the reduction by giving the edge between each vertex and its auxillary vertex this minimum adjacent weight. Moreover, we eliminate the dependence on
\omega
.

Now, we give a simple reduction to the standard problem of finding a maximum weight matching in a graph. This allows us to generalize the problem to weighted graphs, improve the running time, and avoid the reduction to tropical matching completely. Our algorithm also admits the use of standard libraries for weighted matching.

Lemma 12

If maximum-weight matching can be solved in time

Lemma 13
.

In
\mathcal{M}_{H}
, at least
r_{g}
vertices from each group
S_{g}
are matched by edges from
G
.

Proof.

Let
\mathcal{M}^{*}\subseteq G
be an optimal solution to the budgeted matching problem. We now construct a matching
\mathcal{M}_{H}^{*}
in
H
by including all edges from
\mathcal{M}^{*}

not matched in
\mathcal{M}^{*}

S^{\prime}_{g}
.

Let

be the number of vertices in
S_{g}
matched by
\mathcal{M}^{*}
. Since
k_{g}^{*}\geq r_{g}
, we have,
|S_{g}|-k_{g}^{*}\leq|S_{g}|-r_{g}=|S^{\prime}_{g}|
, so there are enough auxiliary vertices in
S^{\prime}_{g}
to complete the matching without conflict. Thus,
\mathcal{M}_{H}^{*}
is a feasible matching in
H
that matches all the vertices in
S_{g}
for every

is strictly greater than
(n-1)M
since each matched node in

G
(that also belong to

Now consider the maximum weight matching
\mathcal{M}_{H}
in

Lemma 14
.

The matching
\mathcal{M}=\mathcal{M}_{H}\cap E(G)
with original edge weights has total weight equal to the optimum of the Weighted Budgeted Matching problem.

Proof.

Let
\mathcal{M}^{*}\subseteq G
be an optimal solution to the budgeted matching problem with total weight
OPT
. As in proof of Lemma
13
, we can extend
\mathcal{M}^{*}
to a matching
\mathcal{M}_{H}^{*}
in
H
by adding auxiliary edges of weight
M
to unmatched vertices in
V
. Since all
n=|V|
vertices in
V
are matched in
\mathcal{M}_{H}^{*}
, and exactly
n-2|\mathcal{M}^{*}|
auxiliary edges are used, the total weight of
\mathcal{M}_{H}^{*}
is:

\sum_{e\in\mathcal{M}_{H}^{*}}c_{H}(e)=\sum_{e\in\mathcal{M}^{*}}(2M-c\left({e}\right))+(n-2|\mathcal{M}^{*}|)M=nM-\text{OPT}.

Let
\mathcal{M}_{H}
be a maximum weight matching in
H
, and let
\mathcal{M}=\mathcal{M}_{H}\cap E(G)
. Note that
\mathcal{M}_{H}
also matches all
n

. Therefore,

\sum_{e\in\mathcal{M}_{H}}c_{H}(e)=\sum_{e\in\mathcal{M}}(2M-c\left({e}\right))+(n-2|\mathcal{M}|)M=nM-\sum_{e\in\mathcal{M}}c(e).

Since
\mathcal{M}_{H}
maximizes the weight,

\sum_{e\in\mathcal{M}_{H}}c_{H}(e)\geq\sum_{e\in\mathcal{M}_{H}^{*}}c_{H}(e)\Rightarrow\sum_{e\in\mathcal{M}}c(e)\leq\text{OPT}.

By Lemma

is a feasible solution to the budgeted matching problem, so equality must hold and

4.1
Argument for simplicity

Our reduction to maximum weight matching has the advantage of improved run time, extension of the original result to weighted graphs as well as mapping to a standard problem for which libraries can be used, rather than someone having to implement an algorithm for (weighted) tropical matching.

5
Prize-Collecting Partition Edge Cover: NP-Completeness

We start by defining the decision version of the Weighted Prize-Collecting Partition Edge Cover problem.

Definition 15

(Weighted Prize-Collecting Partition Edge Cover (WP-PEC))
.

Given a graph
G=(V,E)
, a profit function
p:V\rightarrow\mathbb{R}_{\geq 0}
on the vertices, a weight function
c:E\rightarrow\mathbb{R}_{\geq 0}
on the edges, and a partition of the vertex set into groups
V_{1},V_{2},\dots,V_{\omega}
, where each group
V_{g}
has an associated profit requirement
\rho_{g}\in\mathbb{R}_{\geq 0}
, does there exist a subset of edges
E^{\prime}\subseteq E
such that the total weight
\sum_{e\in E^{\prime}}c(e)
is at most a given budget
C
, and the total profit of covered vertices in each group meets the respective threshold, i.e.,

\sum_{v\in V_{g}\cap V(E^{\prime})}p(v)\geq\rho_{g}\quad\text{for all }g=1,\dots,\omega?

We next prove
6
using a reduction from the classical
Knapsack
problem, which is known to be NP-complete.

Knapsack Problem.

Given a set of
N
items, each with a profit
p_{i}\geq 0
and a cost
c_{i}\geq 0
, and given integers
P
and
C
, does there exist a subset of items
S\subseteq\{1,\dots,N\}
such that

\sum_{i\in S}p_{i}\geq P\quad\text{and}\quad\sum_{i\in S}c_{i}\leq C\ ?

Reduction.

From an instance of the Knapsack problem, we construct an instance of WP-PEC as follows.

We create a bipartite graph with
N
blue vertices
b_{1},\dots,b_{N}
(one for each item), each having profit
p(b_{i})=p_{i}
, and
N
red vertices
r_{1},\dots,r_{N}
, each having profit
p(r_{i})=0
. For each
i
, we add an edge
e_{i}=(b_{i},r_{i})
with weight
c(e_{i})=c_{i}
.

We define the two vertex groups as follows:

1.

V_{1}=\{b_{1},\dots,b_{N}\}
with requirement
\rho_{1}=P
;

2.

V_{2}=\{r_{1},\dots,r_{N}\}
with requirement
\rho_{2}=0
.

We set the total weight budget to
C
.

We now show that a solution to the Knapsack instance exists if and only if a solution to the constructed WP-PEC instance exists.

Lemma 16
.

If the Knapsack instance has a solution, then the corresponding WP-PEC instance has a solution.

Proof.

Suppose there exists a subset of items
S\subseteq\{1,\dots,N\}
such that
\sum_{i\in S}p_{i}\geq P
and
\sum_{i\in S}c_{i}\leq C
. Define
E^{\prime}=\{e_{i}\mid i\in S\}
.

We verify the WP-PEC conditions for
E^{\prime}
:

•

Cost bound:

\sum_{e\in E^{\prime}}c(e)=\sum_{i\in S}c_{i}\leq C
.

•

Group
V_{1}
requirement:
The blue vertices covered are
\{b_{i}\mid i\in S\}
, contributing total profit
\sum_{i\in S}p_{i}\geq P=\rho_{1}
.

•

Group
V_{2}
requirement:
The red vertices
\{r_{i}\mid i\in S\}
contribute
0
profit, which meets
\rho_{2}=0
.

Hence,
E^{\prime}
is a valid solution to the WP-PEC instance.
∎

Lemma 17
.

If the WP-PEC instance has a solution, then the corresponding Knapsack instance has a solution.

Proof.

Suppose
E^{\prime}\subseteq E
is a feasible solution to WP-PEC with total cost at most
C
and group requirements satisfied.

Let
S=\{i\mid e_{i}\in E^{\prime}\}
. Then:

•

Cost:

\sum_{i\in S}c_{i}=\sum_{e\in E^{\prime}}c(e)\leq C
.

•

Profit:
Since only blue nodes have nonzero profit, and
V_{1}
contains all blue nodes, we have:

\sum_{i\in S}p_{i}=\sum_{b_{i}\in V_{1}\cap V(E^{\prime})}p(b_{i})\geq\rho_{1}=P.

Thus,
S
is a feasible solution to the Knapsack problem.
∎

Finally, since the reduction is polynomial time, and verifying a solution to WP-PEC can easily be done in polynomial time, the problem lies in NP. This concludes the proof of
6
.

6
Conclusion

Partial vertex cover (when
\omega=1
) can be solved by a combinatorial algorithm without solving the LP, and this can be done using a primal dual approach, or local-ratio. One interesting question is if a purely combinatorial algorithm can be developed for this problem.
