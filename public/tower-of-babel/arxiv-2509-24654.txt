Limiting behaviour of pattern counts in biased binary strings
Jon V. Kogan and Nicolò Paviato

Abstract
For p ∈ ( 0 , 1 ) p\in(0,1) , sample a binary sequence from the infinite product measure of Bernoulli ( p ) (p) distributions. It is known that for p = 1 / 2 p=1/2 , almost every binary sequence is Poisson generic in the sense of Peres and Weiss, a property that reflects a specific statistical pattern in the frequency of finite substrings. However, this behaviour is highly exceptional: it fails for any p ≠ 1 / 2 p\neq 1/2 . In these other cases, we show that the frequency of substrings of almost every sequence has either trivial or peculiar behaviour. Nevertheless, the Poisson limiting regime can be recovered if one restricts attention to substrings with a fixed number of successes in the Bernoulli ( p ) (p) trials. 3 Introduction What properties does a typical element x ∈ { 0 , 1 } ℕ x\in\{0,1\}^{\mathbb{N}} satisfy? The simplest answer to this question is normality , which Borel [ 4 ] introduced more than a hundred years ago. Assuming p ∈ ( 0 , 1 ) p\in(0,1) and that every digit of x x is chosen independently with a Bernoulli ( p ) (p) distribution, so ℙ ⁡ ( 1 ) = p \mathbb{P}(1)=p , we say that x x is p p -normal if any finite word ω ∈ { 0 , 1 } k \omega\in\{0,1\}^{k} appears in x x with asymptotic frequency p | ω | ​ ( 1 − p ) k − | ω | p^{|\omega|}(1-p)^{k-|\omega|} , where | ω | |\omega| is the Hamming weight of ω \omega , that is the number of coordinates equal to one. Denoting with Ber ⁡ ( p ) \Ber(p) the Bernoulli ( p ) (p) probability measure, it follows from the ergodic theorem that Ber ⁡ ( p ) ℕ \Ber(p)^{\mathbb{N}} -almost every (a.e.) sequence is p p -normal. Given x ∈ { 0 , 1 } ℕ x\in\{0,1\}^{\mathbb{N}} , a natural follow up question is: choosing ω ∈ { 0 , 1 } k \omega\in\{0,1\}^{k} at random as above, how often does the word ω \omega appear in the sequence x x ? If every digit of x x and ω \omega is chosen independently uniformly and k ≥ 1 k\geq 1 is large, then the answer is almost surely given by the Poisson distribution. To be more precise, we recall the concept of Poisson genericity introduced by Zeev Rudnick (see [ 2 , Definition 1] ). Consider { N k } k ≥ 1 \{N_{k}\}_{k\geq 1} a sequence of positive integers. For a fixed x ∈ { 0 , 1 } ℕ x\in\{0,1\}^{\mathbb{N}} , we define M k x ​ ( ω ) = # ⁡ { 1 ≤ j ≤ N k : ( x j , … , x j + k − 1 ) = ω } , M_{k}^{x}(\omega)=\#\{1\leq j\leq N_{k}:(x_{j},\dots,x_{j+k-1})=\omega\}, (3.1) the number of occurrences of ω \omega in x x , up to N k N_{k} . Letting N k = 2 k N_{k}=2^{k} and picking ω ∈ { 0 , 1 } k \omega\in\{0,1\}^{k} uniformly, such an x x is said to be simply Poisson generic if M k x M_{k}^{x} converges in distribution to a Poisson random variable with parameter one (in short M k x → 𝑑 Poi ( 1 ) M_{k}^{x}\xrightarrow{d}\Po(1) ). That is, lim k → ∞ ℙ ⁡ ( M k x = n ) = 1 e ⋅ n ! , \lim_{k\to\infty}\mathbb{P}(M_{k}^{x}=n)=\frac{1}{e\cdot n!}, for every n ∈ ℕ ∪ { 0 } n\in\mathbb{N}\cup\{0\} . Following the notation of [ 7 ] , we sometimes omit the term “simply” and refer to such x x as Poisson normal for short. Note that unqualified the term Poisson generic has a stronger meaning in [ 2 ] . In an unpublished work, Peres and Weiss [ 11 , lecture] proved that Poisson normality is strictly stronger than normality, and that Ber ⁡ ( 1 / 2 ) ℕ \Ber(1/2)^{\mathbb{N}} -a.e. sequence is Poisson generic [ 2 ] . In a recent preprint this result was extended to settings with infinite alphabets and exponentially mixing probability measures [ 1 ] . It is relevant to mention that, in spite of the abundance of Poisson generic sequences, finding explicit examples is not trivial and the matter was solved in [ 3 ] for larger alphabets. A natural generalisation of this setting is to consider different probability measures. The first result in this direction is the preprint [ 7 ] , where the authors prove that almost sure Poisson normality is still satisfied if sequences are sampled by a non-stationary product measure which is sufficiently close to Ber ⁡ ( 1 / 2 ) ℕ \Ber(1/2)^{\mathbb{N}} . Here, every digit of the words ω ∈ { 0 , 1 } k \omega\in\{0,1\}^{k} is still sampled independently with probability p = 1 / 2 p=1/2 . On the other hand, the authors find a threshold for product measures on { 0 , 1 } ℕ \{0,1\}^{\mathbb{N}} above which almost sure Poisson genericity can break down. In this paper we consider new measures for both sequences and words, choosing the digits independently with a parameter p ∈ ( 0 , 1 ) ∖ { 1 / 2 } p\in(0,1)\setminus\{1/2\} . Without loss of generality, we henceforth assume p > 1 / 2 p>1/2 . All results apply to the p < 1 / 2 p<1/2 case by switching the labels of 0 0 and 1 1 , corresponding to a switch of of p p and 1 − p 1-p in the formulae.
