DrishtiKon: Multi-Granular Visual Grounding for Text-Rich Document Images
Badri Vishal Kasuba, Parag Chaudhuri, Ganesh Ramakrishnan, {badrivishalk, paragc, ganesh}@cse.iitb.ac.in

Abstract
Visual grounding in text-rich document images is a critical yet underexplored challenge for document intelligence and visual question answering (VQA) systems. We present DhrishtiKon , a multi-granular visual grounding framework designed to enhance interpretability and trust in VQA for complex, multilingual documents. Our approach integrates robust multi-lingual OCR, large language models, and a novel region matching algorithm to accurately localize answer spans at block, line, word, and point levels. We curate a new benchmark from the CircularsVQA test set, providing fine-grained, human-verified annotations across multiple granularities. Extensive experiments demonstrate that our method achieves state-of-the-art grounding accuracy, with line-level granularity offering the best trade-off between precision and recall. Ablation studies further highlight the benefits of multi-block and multi-line reasoning. Comparative evaluations with leading vision-language models reveal the limitations of current VLMs in precise localization, underscoring the effectiveness of our structured, alignment-based approach. Our findings pave the way for more robust and interpretable document understanding systems in real-world, text-centric scenarios. Code and dataset has been made available at https://github.com/kasuba-badri-vishal/DhrishtiKon .

Introduction

Visual Grounding is the task of locating specific visual elements in an image that correspond to a given text query/question in natural language as input to a corresponding probable answer that answers the query from the input image
[
8
]
.
This task is particularly relevant in the context of Visual Question Answering (VQA) task, where the goal is to provide accurate and contextually relevant answers based on the visual content of an image, providing both transparency and trust on top of the predicted answer’s relavance within the image.
Also, Grounded learning for the task allows for more accurate and contextually relevant responses, as it requires models to focus on the visual content directly related to the question to finding the grounded answers.
In this work, we will explore Visual Grounding task on
text-centric images
and also evaluate the performance on a constructed multi-granular grounding benchmark from the collection of Government Circular images.
We propose a Multi-granular Visual Grounding framework,
DhrishtiKon
which aims to enhance the model’s ability to ground answers in visual elements at multiple levels of granularity, supporting multiple pages which utilized a novel region matching algorithm to improve the grounding process.

3.1
Input Acquisition

We begin with an input image of a text-rich document, typically a scanned official circular or memorandum, which forms the visual basis for question answering. Accompanying the image is a natural language question that queries for any extractive information, such as specific data, references, or contextual details present in the document.The question is designed to be open-ended, allowing for a range of possible answers that may span multiple text blocks within the document, but extractive in nature intending to find specific phrases or data points within the image content.

3.2
Multi-Lingual Block-Level OCR

The input image is processed using a robust multi-lingual OCR system using DocTR
[
4
]
and Surya-OCR
[
5
]
that segments the document into block-level text regions via Layout prediction. Each region is encoded with its corresponding bounding box coordinates and transcribed content. This enables spatial decomposition of the document for fine-grained semantic grounding.

3.3
Question-Conditioned Answer Prediction

The extracted blocks, along with the user-input question, are fed into a large language model (LLM). We use LlaMA-3.1-8B instruct open-source model
[
2
]
as our model, which performs semantic reasoning over the textual content and outputs a predicted answer. This step simulates an MLLM (Multimodal Large Language Model) inference in purely textual modality, bypassing the need for visual input during answer generation as it takes OCR output as contextual information.

3.4
Candidate Region Matching Algorithm

To locate the predicted answer within the document, we implement a matching algorithm that loops over each probable text block extracted by the OCR engine. For each block, a composite matching score is calculated using the following components:

1.

Fuzzy Score:
Computed using both the partial match and token-based matching similarity between the predicted answer and block content.

2.

Length Factor:
Rewards blocks with reasonable length relative to the predicted answer with comparison of probable block matched text.

3.

Penalty Functions:
Down-ranks blocks with either excessively short bounding boxes (indicative of noise) or lacking contextual semantic overlap.

As described in the Algorithm
1
, Each candidate region is scored based on components which inturn have a scale of contribution, and those regions that scored above a pre-defined threshold are retained. The candidate blocks are sorted based on their composite scores. The top-k matched blocks are selected and visualized along with the predicted answer for interpretability. This allows the luxury to choose the number of multi-block predictions required based on the threshold parameters.

5
Conclusion and Future works

In this work, we presented
DhrishtiKon
, a multi-granular visual grounding framework designed to enhance the interpretability and trustworthiness of VQA systems on text-centric images.
By integrating multi-lingual OCR, LLMs, and a novel region matching algorithm, we demonstrated significant improvements in grounding accuracy across multiple levels of granularity.
Our experiments on a curated dataset derived from CircularsVQA testset showed that mid-level granularities (line-level) yield the best performance for document-based question answering tasks.
The ablation studies further validated the effectiveness of multi-block and multi-line reasoning in improving grounding precision and recall.
Also, the evaluations highlight that while large vision-language models can produce reasonable semantic predictions, they fall short in precise visual localization tasks without structured grounding mechanisms. Our Region Matching approach demonstrates that traditional alignment-based methods—when combined with robust OCR and textual matching—remain highly competitive for document understanding tasks that demand spatial fidelity.
