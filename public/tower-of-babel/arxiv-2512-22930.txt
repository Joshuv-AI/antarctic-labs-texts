PSPACE-Completeness of the Equational Theory of Relational Kleene Algebra with Graph Loop
Yoshiki Nakamura

Abstract
In this paper, we show that the equational theory of relational Kleene algebra with graph loop is PSpace -complete. Here, the graph loop is the unary operator that restricts a binary relation to the identity relation. We further show that this PSpace -completeness still holds by extending with top, tests, converse, and nominals. Notably, we also obtain that for Kleene algebra with tests (KAT), the equational theory of relational KAT with domain is PSpace -complete, whereas the equational theory of relational KAT with antidomain is ExpTime -complete. To this end, we introduce a novel automaton model on relational structures, named loop-automata . Loop-automata are obtained from non-deterministic finite string automata (NFA) by adding a transition type that tests whether the current vertex has a loop. Using this model, we give a polynomial-time reduction from the above equational theories to the language inclusion problem for 2-way alternating string automata.

3
Relational Kleene algebra with graph loop

In this section,
we define
relational Kleene algebra with graph loop
(
loop-RKA
).

Syntax

Given a set
\Sigma
of
variables
,
the set of
terms
over
\Sigma
is defined as the set of terms over the signature
\{\mathsf{0}_{(0)},\mathsf{I}_{(0)},\mathbin{+}_{(2)},\mathbin{;}_{(2)},\_^{*}_{(1)},\_^{\circlearrowleft}_{(1)}\}
:

\displaystyle t,s,{u}\quad\Coloneqq\quad a\mid\mathsf{0}\mid\mathsf{I}\mid t\mathbin{+}s\mid t\mathbin{;}s\mid t^{*}\mid t^{\circlearrowleft}.

(
a\in\Sigma
)

We often abbreviate
t\mathbin{;}s
to
ts

4
Automata expression for Loop-RKA

In this section,
we introduce an automata model, named
loop-automata
,
for representing the relational semantics of loop-RKA.
Given two finite sets
\Sigma
(of characters) and
Q
(of
states
),
we consider the following set of transition labels:

\immediate\immediate\immediate L_{\Sigma,Q}~\coloneq~\Sigma\mathop{\sqcup}\{\mathsf{I}\}\mathop{\sqcup}\{\ell_{\langle p,q\rangle}\mid\langle p,q\rangle\in Q^{2}\}.

Each label
a\in\Sigma

is employed for the standard transitions.
The label
\mathsf{I}
is employed for the “epsilon”-transitions:
transitions that do not consume any input symbol.
