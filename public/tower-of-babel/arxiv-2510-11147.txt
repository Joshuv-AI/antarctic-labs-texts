torchsom : The Reference PyTorch Library for Self-Organizing Maps
Louis Berthier louis-desire-romeo.berthier@michelin.com, Ahmed Shokry ahmed.shokry@polytechnique.edu, Maxime Moreaud maxime.moreaud@michelin.com, Guillaume Ramelet guillaume.ramelet@michelin.com, Eric Moulines eric.moulines@polytechnique.edu

Abstract
This paper introduces torchsom , an open-source Python library that provides a reference implementation of the Self-Organizing Map (SOM) 2in PyTorch . This package offers three main features: (i) dimensionality reduction, (ii) clustering, and (iii) friendly data visualization. It relies on a PyTorch backend, enabling (i) fast and efficient training of SOMs 2through GPU acceleration, and (ii) easy and scalable integrations with PyTorch ecosystem. Moreover, torchsom follows the scikit-learn API for ease of use and extensibility. The library is released under the Apache 2.0 license with 90% test coverage, and its source code and documentation are available at https://github.com/michelin/TorchSOM .

B.3.1
Learning Process

The weight updates in a
SOM
2follow a neighborhood-based with competitive learning approach highlithed in Equation
1
,
rather than relying on gradient descent-based optimization as in traditional
Artificial Neural Networks (ANNs)

w_{ij}(t+1)=w_{ij}(t)+\alpha(t)\cdot h_{ij}(t)\cdot(x-w_{ij}(t))

(1)

\displaystyle w_{ij}(t)\in\mathbb{R}^{k}:

\displaystyle\text{ weight of the neuron at row }i\text{ and column }j\text{ at iteration }t,

\displaystyle\alpha(t)\in\mathbb{R}:

\displaystyle\text{ learning rate},

\displaystyle h_{ij}(t)\in\mathbb{R}:

\displaystyle\text{ neighborhood function},

\displaystyle x\in\mathbb{R}^{k}:

\displaystyle\text{ input feature vector}.

The neighborhood function
h_{ij}

2
,
or similar radial basis function controlling the extent of weight updates.

h_{ij}(t)=\exp\left(-\frac{d_{ij}^{2}}{2\cdot{\sigma(t)}^{2}}\right)

(2)

\displaystyle\sigma(t)\in\mathbb{R}^{+}:

\displaystyle\text{ width of the neighborhood function},

\displaystyle d_{ij}\in\mathbb{R}^{+}:

\displaystyle\text{ distance between the \lx@glossaries@gls@link{acronym}{bmu}{{{}}BMU}2at position }(c_{x},c_{y})\text{ and neuron }w_{ij}.

Such a function is centered at the
BMU

\text{BMU}=w_{bmu}=\operatorname*{argmin}_{i,j}\|x-w_{ij}\|_{2}=\operatorname*{argmin}_{i,j}\sqrt{\sum_{l=1}^{k}{(x_{l}-w_{ij,l})}^{2}}

(3)

\displaystyle x\in\mathbb{R}^{k}:

\displaystyle\text{ input feature vector},

\displaystyle w_{ij}\in\mathbb{R}^{k}:

\displaystyle\text{ weight of the neuron at row }i\text{ and column }j.

While both the neighborhood function in Equation

The

In contrast, the neighborhood function uses the grid space distance to determine spatial relationships between neurons on the

d_{ij}=\sqrt{{(i-c_{x})}^{2}+{(j-c_{y})}^{2}}

B.3.2
Objective Functions

The primary objective function for
SOM
2training involves minimizing the
QE
2, as formulated in Equation
5
.
The
QE
2quantifies the fidelity of the
SOM
2representation by measuring how accurately the network captures
the input data distribution in the reduced-dimensional mapping space.
While a low
QE
2signifies superior data representation quality, it may also indicate potential overfitting to
the training data set.

Crucially, there exists a fundamental trade-off between representation fidelity, as measured by the
QE
2,
and topological preservation, as quantified by the
TE
2defined in Equation
6
.
Specifically, the
QE
2fails to capture information regarding the preservation of topological relationships between
input feature vectors within the
SOM
2grid structure.
The
TE
2quantifies the degree to which neighborhood relationships among samples in the original input space are
maintained following the dimensional projection, effectively measuring how consistently neighboring input vectors are
mapped to spatially adjacent neurons on the
SOM
2grid.
Mathematically, the
TE
2represents the fraction of input vectors for which the
BMU
2and second
BMU
2are
non-adjacent within the grid topology.
A low
TE
2value demonstrates effective preservation of the underlying topological structure from the input space
onto the
SOM
2grid representation.

\text{QE}=\frac{1}{N}\sum_{i=1}^{N}\|x_{i}-w_{\text{BMU}}(x_{i})\|_{2}

(5)

\text{TE}=\frac{1}{N}\sum_{i=1}^{N}\mathbb{I}\left(d_{\text{grid}}\left(w_{\text{BMU}}(x_{i}),w_{\text{2nd-BMU}}(x_{i})\right)>d_{\text{th}}\right)

(6)

\displaystyle N\in\mathbb{N}:

\displaystyle\text{ number of training samples},

\displaystyle x_{i}\in\mathbb{R}^{k}:

\displaystyle\text{ $i$-th input training sample},

\displaystyle w_{\text{BMU}}(x_{i})\in\mathbb{R}^{k}:

\displaystyle\text{ weight vector of the \lx@glossaries@gls@link{acronym}{bmu}{{{}}BMU}2for input }x_{i},

\displaystyle w_{\text{2nd-BMU}}(x_{i})\in\mathbb{R}^{k}:

\displaystyle\text{ weight vector of the second \lx@glossaries@gls@link{acronym}{bmu}{{{}}BMU}2for input }x_{i},

\displaystyle d_{\text{th}}\in\mathbb{R}^{+}:

\displaystyle\text{ threshold distance for topological adjacency (typically }d_{\text{th}}=1\text{)},

\displaystyle\mathbb{I}(\cdot)\in\{0,1\}:

indicator function

\displaystyle\|\cdot\|_{2}:

\displaystyle\text{ Euclidean norm in feature space},

\displaystyle d_{\text{grid}}\left(\cdot,\cdot\right):

\displaystyle\text{ grid space distance between \lx@glossaries@gls@link{acronym}{bmu}{{{}}BMUs}2of input }x_{i}.

B.3.5
Scheduler Functions

As the
SOM
2undergoes training, critical hyperparameters such as the learning rate
\alpha(t)
and neighborhood
width
\sigma(t)
must decrease systematically over time to ensure convergence while avoiding local minima.
This temporal reduction facilitates a two-phase learning paradigm: an initial exploratory phase characterized by
large parameter values that enable global map organization and topological ordering, followed by a refinement phase
where diminished parameters allow for fine-grained local optimization and weight stabilization.

The following decay schedulers are implemented to provide flexible control over hyperparameter evolution:
(i) inverse decay for gradual asymptotic reduction (Equations
15
and
17
),
(ii) linear decay for uniform parameter reduction (Equations
16
and
18
), and
(iii) asymptotic decay with a general dynamic parameter
\theta
for exponential-like convergence (Equation
19
).
These schedulers enable temporal control over the learning dynamics, accommodating diverse convergence requirements
across different data sets and applications.

Learning Rate Schedulers.

The learning rate
\alpha(t)
controls the magnitude of weight vector updates during training, directly influencing
convergence speed and final map quality.

torchsom
implements the following learning rate decay schedulers:

\alpha(t+1)=\alpha(t)\cdot\frac{\gamma}{\gamma+t}

(15)

\alpha(t+1)=\alpha(t)\cdot\left(1-\frac{t}{T}\right)

(16)

These schedulers guarantee convergence to
\alpha(T)=0
, corresponding to zero weight updates in the final training phase, which is essential for achieving precise local weight adjustments.

Neighborhood Width Schedulers.

The neighborhood width
\sigma(t)
governs the spatial extent of collaborative weight updates around the
BMU
2,
determining the degree of topological preservation during training.

torchsom
implements specialized schedulers for neighborhood width control:

\sigma(t+1)=\frac{\sigma(t)}{1+t\cdot\frac{\sigma(t)-1}{T}}

(17)

\sigma(t+1)=\sigma(t)+t\cdot\frac{1-\sigma(t)}{T}

(18)

These schedulers guarantee convergence to
\sigma(T)=1
, corresponding to single-neuron updates in the final training phase, which is essential for achieving precise local weight adjustments.

General Asymptotic Decay.

For arbitrary dynamic parameters requiring exponential-like decay characteristics,
torchsom
implements a
general asymptotic decay scheduler:

\theta(t+1)=\frac{\theta(t)}{1+\frac{t}{T/2}}

(19)

\displaystyle\alpha(t)\in\mathbb{R}^{+}:

\displaystyle\text{ learning rate at iteration }t,

\displaystyle\sigma(t)\in\mathbb{R}^{+}:

\displaystyle\text{ neighborhood function width at iteration }t,

\displaystyle\theta(t)\in\mathbb{R}^{+}:

\displaystyle\text{ general dynamic parameter at iteration }t,

\displaystyle T\in\mathbb{N}:

\displaystyle\text{ total number of training iterations},

\displaystyle t\in\{0,1,\ldots,T\}:

\displaystyle\text{ current iteration index},

\displaystyle\gamma\in\mathbb{R}^{+}:

\displaystyle\text{ inverse decay rate parameter, typically }\gamma=T/100.

The learning rate
\alpha(t)
modulates the magnitude of weight vector adjustments, ensuring stability as training
progresses by reducing update sensitivity.
The neighborhood width
\sigma(t)
determines the spatial extent of collaborative updates around the
BMU
2,
transitioning from broad initial influence to localized refinement.

Asymptotically, the learning rate schedulers ensure
\lim_{t\to\infty}\alpha(t)=0
, while the neighborhood
width schedulers guarantee
\lim_{t\to T}\sigma(t)=1
, corresponding to single-neuron updates in the final
training phase.
This systematic parameter reduction is fundamental to achieving stable map convergence and preserving topological
ordering in the learned representation.

Appendix C
torchsom
Visualization Examples

A major limitation of existing
SOM
2libraries lies in the lack of standardized, comprehensive, and high-quality
visualization utilities.
While most implementations provide only minimal or ad-hoc visualization routines,
torchsom
introduces a
comprehensive and extensible visualization suite designed to support interpretability, model diagnostics, and
performance assessment.
The package accommodates both rectangular and hexagonal topologies and is organized into nine categories, each targeting
a distinct aspect of interpretability, model diagnostics, and performance assessment:

1.

Learning curves
(Figure
3
):
Visualization of training dynamics in unsupervised settings, tracking the convergence behavior of the
quantization error (
QE
2) and topographic error (
TE
2). These curves allow practitioners to monitor
self-organization stability and detect under- or over-training.

2.

Distance map
(Figure
4
):
The unified distance matrix (U-matrix) representation in unsupervised settings, showing inter-neuron distances.
Distance maps highlight topological relationships, neighborhood continuity, and potential cluster boundaries.

3.

Hit map
(Figure
5
):
Frequency-based visualization of
BMU
2activations in unsupervised settings. Hit maps provide insights
into data distribution, neuron utilization, and possible dead units, serving as a diagnostic tool for
representation adequacy.

4.

Component planes
(Figure
6
):
Feature-specific visualization of learned weights in unsupervised settings. Each plane depicts the spatial
distribution of one input dimension, enabling direct inspection of feature gradients, redundancy, and
contribution to the learned topology.

5.

Metric map
(Figure
7
):
Statistical summaries for supervised regression with
JITL
2, visualizing neuron-wise target distributions
(mean or variance). These maps link latent representations to target patterns across the grid.

6.

Score map
(Figure
8
):
Reliability assessment for supervised regression using
JITL
2. Each neuron is scored according to local
variance, density, and statistical significance of its receptive field (see Eq.
20
),
highlighting robust versus unreliable regions of the map.

7.

Rank map
(Figure
9
):
Rank-based visualization for supervised regression, displaying the relative ordering of predicted values across
the topology. This reveals performance gradients and supports qualitative validation of monotonicity in
prediction landscapes.

8.

Classification map
(Figure
10
):
Class prediction visualization for supervised classification with
JITL
2. The map displays dominant classes,
and decision boundaries across the
SOM
2latent space.

9.

Cluster analysis
(Figures
11
,
12
,
13
):
Integrated clustering diagnostics for unsupervised analysis, consisting of:
(i) spatial visualization of discovered clusters,
(ii) elbow-criterion plots for estimating the optimal number of clusters, and
(iii) comparative evaluations across clustering algorithms using standardized metrics.

Quality Assessment Methodology.

The reliability of individual neurons is quantified using the score function defined in Eq. (
20
),
which balances local variance, sample density, and statistical significance:

S_{ij}=\frac{\sigma_{ij}}{\sqrt{n_{ij}}}\cdot\log\left(\frac{N}{n_{ij}}\right)

(20)

\displaystyle S_{ij}\in\mathbb{R}^{+}:

\displaystyle\text{ reliability score of neuron }w_{ij}\text{ at grid position }(i,j),

\displaystyle\sigma_{ij}\in\mathbb{R}^{+}:

\displaystyle\text{ standard deviation of target values assigned to neuron }w_{ij},

\displaystyle n_{ij}\in\mathbb{N}:

\displaystyle\text{ number of assigned samples to neuron }w_{ij},

\displaystyle N\in\mathbb{N}:

\displaystyle\text{ total number of samples in the latent space}.

This multi-criteria function penalizes high variance and low-density neurons while emphasizing statistical reliability
via density weighting. Lower scores correspond to stable, well-supported neurons; higher scores identify regions
with poor generalization or sensitivity to outliers.

Component Plane Analysis.

Component planes (
Component Planes (CPs)
2) provide an interpretable link between high-dimensional inputs and their low-dimensional
organization on the map. Each
CP
2corresponds to a single input feature, visualizing the spatial distribution of
its learned weights across the grid. This facilitates:
(i) detection of feature gradients,
(ii) identification of redundant or irrelevant features, and
(iii) assessment of individual feature contributions to the emergent topology.
In applied contexts, such as regression or classification tasks,
CPs
2enable domain experts to interpret latent
structures in terms of original variables, enhancing the explainability of the learned representation.

Clustering Diagnostics.

Cluster-based analysis (Figures
11
–
13
) extends interpretability beyond
local neuron inspection to global structure discovery.
torchsom
integrates cluster assignment visualization,
automatic elbow-criterion diagnostics, and algorithmic performance comparisons. This supports objective model
selection for downstream tasks such as segmentation, anomaly detection, and hierarchical structure discovery.

Taken together, these visualization tools position
torchsom
not only as an efficient and scalable
SOM
2implementation but also as the first library to provide a systematic, reproducible, and comprehensive visualization
framework for self-organizing models in both supervised and unsupervised regimes.
