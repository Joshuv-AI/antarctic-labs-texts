Exploring chordal sparsity in semidefinite programming with sparse plus low-rank data matrices
Tianyun Tang, Kim-Chuan Toh

Abstract
Semidefinite programming (SDP) problems are challenging to solve because of their high dimensionality. However, solving sparse SDP problems with small tree-width are known to be relatively easier because: (1) they can be decomposed into smaller multi-block SDP problems through chordal conversion; (2) they have low-rank optimal solutions. In this paper, we study more general SDP problems whose coefficient matrices have sparse plus low-rank (SPLR) structure. We develop a unified framework to convert such problems into sparse SDP problems with bounded tree-width. Based on this, we derive rank bounds for SDP problems with SPLR structure, which are tight in the worst case.

semidefinte programming, sparsity pattern, low-rank property

1.1
Linear SDP problem

Let

We consider the following linear semidefinite programming (SDP) problem,

\min\left\{\big\langle A_{0},X\big\rangle:\ \forall i\in[m]\ b_{i}^{l}\leq\big\langle A_{i},X\big\rangle\leq b_{i}^{u},\ X\in\mathbb{S}^{n}_{+}\right\},

The problem (

[

[

In this paper, we aim to develop a new technique to tackle SDP problems with sparse plus low-rank structure in the data matrices as we shell elaborate in the next few subsections.

1.3
SDP with sparse plus low-rank structure

In
[
37

[

Definition 1.1
.

Consider

We say that the problem (

The SPLR structure often appears in many SDP problems such as minimum bisection SDP
[
28
]

[
22
]

[

[

\min\left\{x^{\top}Qx+2c^{\top}x:\ Ax=b,\ x_{i}\in\{0,1\},\ \forall i\in B,\ x\in\mathbb{R}^{n}_{+}\right\},

\min\Bigg\{\left\langle\begin{bmatrix}0&c^{\top}\\

\left\langle\begin{bmatrix}-b^{\top}\\
A^{\top}\end{bmatrix}\left[-b,A\right],Y\right\rangle=0,\ Y\in\mathbb{S}^{n+1}_{+}\Bigg\}.

(2)

Let

One popular technique to improve the sparsity of (

The problem (

\min\left\{\big\langle PA_{0}P^{\top},Y\big\rangle:\ \forall i\in[m]\ b_{i}^{l}\leq\big\langle PA_{i}P^{\top},Y\big\rangle\leq b_{i}^{u},\ Y\in\mathbb{S}^{n}_{+}\right\}.

(3)

Suppose

Then for any

could be also sparse for any

Although congruent transformation can be an effective preprocessing technique in practice, this technique remains a heuristic that has only been applied successfully to highly specialized SPLR structure such as the SDP relaxation of minimum bisection problems which has a constraint matrix of the form
ee^{\top}
, where

is the matrix of all ones. To our best knowledge, there is currently no systematic way to select

Considering these two facts, it would be natural to ask the following question:

Question 1.2

Is there a systematic way to convert (

In this paper, we will answer the Question

1.4
Contribution 1: sparse extension

In Section
3
, we will propose a systematic method called “sparse extension” to transfer (
SDP
) with SPLR structure into a sparse SDP problem with bounded tree-width. Instead of using congruent transformation, the idea of “sparse extension” is to introduce auxiliary variables to extend (
SDP
) into a higher dimensional space where the low-rank data matrices are decomposed into several sparse matrices. In order to state our contribution as a theorem, we need the following definition.

Definition 1.3
.

Consider the following SDP problems

\min\left\{\big\langle\widehat{A}_{0},\widehat{X}\big\rangle:\ \forall i\in[\hat{m}],\ \widehat{b}_{i}^{l}\leq\big\langle\widehat{A}_{i},\widehat{X}\big\rangle\leq\widehat{b}_{i}^{u},\ \widehat{X}\in\mathbb{S}^{\hat{n}}_{+}\right\},

(SDPex)

where for any
i\in\{0\}\sqcup[\hat{m}],

\hat{A}_{i}\in\mathbb{S}^{\hat{n}}
and for any
i\in[\hat{m}],

-\infty\leq\widehat{b}_{i}^{l}\leq\widehat{b}_{i}^{u}<+\infty.
We call (
SDPex
) an
extension
of (
SDP
) if there exists an index set
\mathcal{I}{\subset}[\hat{n}]
such that for any feasible
\widehat{X}
of (
SDPex
),
\widehat{X}_{\mathcal{I},\mathcal{I}}
is feasible for (
SDP
) and
\langle\widehat{A}_{0},\widehat{X}\rangle=\langle A_{0},\widehat{X}_{\mathcal{I},\mathcal{I}}\rangle.
Also, for any feasible
X
for (
SDP
), there exists feasible solution
\widehat{X}
for (
SDPex
) such that
\widehat{X}_{\mathcal{I},\mathcal{I}}=X.

From Definition
1.3
, it is easy to see that (
SDPex
) and (
SDP
) are equivalent in the sense that they have the same optimal value. Also, suppose

is an optimal solution of (

), then
\widehat{X}_{\mathcal{I},\mathcal{I}}
is an optimal solution of (
SDP
). With Definition
1.3
, the property of our sparse extension can be summarized in the following theorem.

Theorem 1.4
.

Suppose the problem (
SDP
) has
(G,\ell)-
SPLR structure for some
\ell\in\mathbb{N}
. Let
\left(T,\mathcal{V}\right)
be a tree-decomposition of
G
such that
|T|=p
and its width

wid
(
T,{\cal V}
)
=
tw
(G). Then it has a sparse extension (
SDPex
), whose precise form is given
in (
25
),
with sparsity pattern
\widehat{G}=(\widehat{n},\widehat{E})
such that
\widehat{n}\leq n+{2p\cdot\ell}
and

Moreover, if T is a path and
{\rm tw}(G)={\rm pw}(G)
(path-width), then the bounds can be strengthened to
\hat{n}\leq n+{p\cdot\ell}

Theorem
1.4
answers the Question
1.2

This implies that an SDP problem with

and

1.5
Contribution 2: rank bound

Apart from chordal conversion, another popular dimension reduction technique is low-rank decomposition, that is, factorizing
X
into
RR^{\top},
where
R\in\mathbb{R}^{n\times r}
for some
r\ll n.
In this case, (
SDP
) is converted to the following
form:

\min\left\{\big\langle A_{0},RR^{\top}\big\rangle:\ \forall i\in[m],\ b_{i}^{l}\leq\big\langle A_{i},RR^{\top}\big\rangle\leq b_{i}^{u},\ R\in\mathbb{R}^{n\times r}\right\}.

(SDPLR)

This idea was first proposed by Burer and Monteiro in
[
5

6
]
two decades ago and has received significant attention
[

Because the problem (

) is only equivalent to (

the rank bound of (

) is an important research topic. The most famous rank bound for (

[

,
13
,
27
]
, which states that (

) has an optimal solution (if exists) of rank at most
\left\lfloor(\sqrt{8m+1}-1)/2\right\rfloor
. Despite of its wide usage, the Barvinok-Pataki bound is only related to the number of constraints while ignoring the structure of the data matrices. On the other hand, various data structures have been utilized to establish rank bounds for specific SDP problems
[
20
,
24
,
33
]
. One notable result is the Dancis theorem
[
9
]
, which says that (
SDP
) has an optimal solution of rank at most
{\rm tw}(G)+1
, which is smaller than the Barvinok-Pataki bound when
{\rm tw}(G)=\mathcal{O}(1)
. However, the Dancis theorem is not useful for SDP problems with SPLR-structure, for which it will give the trivial bound of

because of the presence of dense low-rank data matrices.

In Section
4
, we will derive new rank bounds for SDP problems with SPLR structure. In order to state our result, we need the following technical definition.

.

Define the mapping

\left\{Y\in\mathbb{S}^{2\ell}_{+}:\ U^{\top}YU=M,\ Y_{1:\ell,1:\ell}=I_{\ell},\ Y_{\ell+1:2\ell,\ell+1:2\ell}=I_{\ell}\right\}.

(4)

3
Sparse extension of SDP with SPLR structure

In this section, we describe our construction of sparse extension that decomposes a low-rank data matrix into several sparse data matrices. Because the sparse extension is a complicated procedure involving many matrix operations, we will first use a simple example to illustrate the main idea and later move on to the general case.

3.1
A simple example

Consider the following SDP problem:

\mathcal{B}:=\arg\min\left\{0:\ {\rm diag}(X)=e,\ \big\langle{\bf a}{\bf a}^{\top},X\big\rangle=b,\ X\in\mathbb{S}^{n}_{+}\right\},

(6)

where

It is easy to see that the SDP problem (

and a low-rank data matrix

Now we are going to add auxiliary variables to transfer the low-rank constraint

and

r\in\mathbb{N}^{+}.

5
Conclusion

In this study, we derive a unified framework called sparse extension to transfer an SDP problem with sparse plus low-rank data matrices into a sparse SDP problem with bounded tree-width. Based on this, we derive rank bounds for SDP problems with SPLR structure that are tight in the worst case. In the future, it would be interesting to design efficient algorithms for solving SDPs with SPLR structure and conduct computational complexity analysis.

Lemma C.1
.

For any

Proposition D.1
.

For any
\ell\in\mathbb{N}^{+},
the function
\varphi
defined in Definition
1.5
satisfies
\varphi(\ell)=\ell+1.

Proof.

By Proposition
1.7
, it suffices to prove that
\varphi(\ell)\leq\ell+1.
Let
U=[U_{1};U_{2}]\in\mathbb{R}^{2\ell\times\ell}
with
U_{1},U_{2}\in\mathbb{R}^{\ell\times\ell},
and suppose that the set (
4
) is nonempty. Choose an element
Y_{0}
of this set and define

P(t):=\begin{bmatrix}U_{1}\\
tU_{2}\end{bmatrix}^{\top}Y_{0}\begin{bmatrix}U_{1}\\
tU_{2}\end{bmatrix}\succeq 0,\qquad t\in\mathbb{R}.

By Hanselka and Sinn
[
16
, Corollary 3.8]
, there exists
Q(t)\in\mathbb{R}[t]^{(\ell+1)\times\ell}
such that
P(t)=Q(t)^{\top}Q(t).
Since
P
has degree at most two and each diagonal entry of
Q(t)^{\top}Q(t)
is a sum of squares,
Q
has degree at most one. Thus,

P(t)=(E_{1}+tE_{2})^{\top}(E_{1}+tE_{2}),\qquad E_{1},E_{2}\in\mathbb{R}^{(\ell+1)\times\ell}.

Comparing the constant and quadratic coefficients gives
E_{i}^{\top}E_{i}=U_{i}^{\top}U_{i}
for
i\in[2].
Hence the map
U_{i}x\mapsto E_{i}x
is a well-defined isometry on the column space of
U_{i}.
By completing orthonormal bases, it extends to an isometry from
\mathbb{R}^{\ell}
to
\mathbb{R}^{\ell+1},
whose matrix
V_{i}\in\mathbb{R}^{(\ell+1)\times\ell}
satisfies

V_{i}^{\top}V_{i}=I_{\ell},\qquad V_{i}U_{i}=E_{i},\qquad i\in[2].

Now set

Y_{*}:=[V_{1},V_{2}]^{\top}[V_{1},V_{2}]=\begin{bmatrix}I_{\ell}&V_{1}^{\top}V_{2}\\
V_{2}^{\top}V_{1}&I_{\ell}\end{bmatrix}.

Then
Y_{*}\succeq 0,

{\rm rank}(Y_{*})\leq\ell+1,
and

U^{\top}Y_{*}U=(E_{1}+E_{2})^{\top}(E_{1}+E_{2})=P(1)=U^{\top}Y_{0}U=M.

Therefore,
Y_{*}
belongs to the set (
4
), proving
\varphi(\ell)\leq\ell+1.
