Abstract
We show how to construct in linear time coresets of constant size for farthest point problems in fixed-dimensional hyperbolic space. Our coresets provide both an arbitrarily small relative error and additive error ε \varepsilon . More precisely, we are given a set P P of n n points in the hyperbolic space ℍ D \mathbb{H}^{D} , where D = O ⁡ ( 1 ) D=O(1) , and an error tolerance ε ∈ ( 0 , 1 ) \varepsilon\in(0,1) . Then we can construct in O ⁡ ( n / ε D ) O(n/\varepsilon^{D}) time a subset P ε ⊂ P P_{\varepsilon}\subset P of size O ⁡ ( 1 / ε D ) O(1/\varepsilon^{D}) such that for any query point q ∈ ℍ D q\in\mathbb{H}^{D} , there is a point p ε ∈ P ε p_{\varepsilon}\in P_{\varepsilon} that satisfies d H ​ ( q , p ε ) ⩾ ( 1 − ε ) ​ d H ​ ( q , f P ​ ( q ) ) d_{H}(q,p_{\varepsilon})\geqslant(1-\varepsilon)d_{H}(q,f_{P}(q)) and d H ​ ( q , p ε ) ⩾ d H ​ ( q , f P ​ ( q ) ) − ε d_{H}(q,p_{\varepsilon})\geqslant d_{H}(q,f_{P}(q))-\varepsilon , where d H d_{H} denotes the hyperbolic metric and f P ​ ( q ) f_{P}(q) is the point in P P that is farthest from q q according to this metric. This coreset allows us to answer approximate farthest-point queries in time O ⁡ ( 1 / ε D ) O(1/\varepsilon^{D}) after O ⁡ ( n / ε D ) O(n/\varepsilon^{D}) preprocessing time. It yields efficient approximation algorithms for the diameter, the center, and the maximum spanning tree problems in hyperbolic space.

Introduction

Nearest-neighbor searching is a fundamental problem in computational geometry where, given
a dataset
P
of
n
points, we want to quickly return a point of
P
that is closest to a query point
q
. If interpoint distances can be computed in
O(1)
time, a query can be answered by brute force in
O(n)
time, so the goal is to design data structures that answer queries in sublinear time after some preprocessing. For instance, in the Euclidean plane
\mathbb{R}^{2}
, nearest-neighbor queries can be answered in
O(\log n)
time after
O(n\log n)
preprocessing time by computing the Voronoi diagram of
P

[
3
]
.
Unfortunately, the worst case complexity of the the Voronoi diagram in the
D
-dimensional
Euclidean space
\mathbb{R}^{D}
is
\Theta(n^{\lceil D/2\rceil})
, so this approach is often impractical in dimension
D\geqslant 3
.

In order to address this issue, an approximate version of nearest-neighbor searching, called

approximate nearest-neighbor searching
(ANN) has been considered where, instead of returning the closest point to
q
, we return a point whose distance from
q
is at most
(1+\varepsilon)
times the optimal, for a given relative error tolerance
\varepsilon\in(0,1)
. Arya et al. showed that in fixed-dimensional Euclidean space (i.e. in
\mathbb{R}^{D}
where
D=O(1)
), ANN queries can be answered in
O(\log(n)/\varepsilon^{D})
time after
O(n\log n)
preprocessing time
[
2
]
.

A related problem is farthest-neighbor searching: Preprocess
P
so that a point in
P
that is farthest from a query point
q
can be found efficiently. This problem can be solved exactly using the
farthest-point Voronoi diagram
, but unfortunately, in the worst case, it has the same size
\Theta(n^{\lceil D/2\rceil})
as the Voronoi diagram in dimension
D
.

Agarwal et al.
[
1
]
gave an efficient data structure for
(1-\varepsilon)
-approximate farthest neighbors in fixed dimension: After
O(n/\varepsilon^{(D-1)/2})
preprocessing time, a point whose distance from
q
is at least
(1-\varepsilon)
times the maximum is returned in
O(1/\varepsilon^{(D-1)/2})
time. The idea is to compute the set
P_{\varepsilon}
of extreme points of
P
along

O(1/\varepsilon^{(D-1)/2})
directions distributed (roughly) uniformly on the unit sphere. This set
P_{\varepsilon}
has size
O(1/\varepsilon^{(D-1)/2})
, and for any query point
q
, an approximate farthest point is in
P_{\varepsilon}
. Thus, it is a
coreset
for farthest point problems: It is a small subset of
P
, such that if we want to answer an approximate farthest-neighbor query on
P
, we can return a point in
P_{\varepsilon}
that is farthest from the query point. Coresets have been used for approximating the solutions of several computational geometry problems
[
11
]
.

In this paper, we give a coreset of size
O(1/\varepsilon^{D})
for farthest-point problems in
fixed-dimensional hyperbolic space
\mathbb{H}^{D}
. This space is the unique
D
-dimensional
Riemannian manifold with sectional curvature -1 at every point. It has several
isometric models such as the hyperboloid model and the Poincaré half-space
model
[
18
]
.
For convenience, we will use the
Poincaré ball
model
(\mathbb{B}^{D},d_{H})
where
\mathbb{B}^{D}
is
the open unit ball of
\mathbb{R}^{D}
centered at the origin
O
, and
d_{H}
is the metric defined
as follows. (See Section
2.1
for a more detailed introduction to the Poincaré ball model.)

The hyperbolic length
L_{H}(\Gamma)
of a curve
\Gamma
in
\mathbb{B}^{D}
is given by the integral

L_{H}(\Gamma)=\int_{\Gamma}ds
where

ds^{2}=4\frac{dx_{1}^{2}+\dots+dx_{D}^{2}}{\left(1-(x_{1}^{2}+\dots+x_{D}^{2})\right)^{2}}.

(In the Euclidean case,
ds
is given by the relation
ds^{2}=dx_{1}^{2}+\dots+dx_{D}^{2}
.) For any two distinct points
u,v\in\mathbb{B}^{D}
, the curve
[u,v]
of minimum hyperbolic length between
u
and
v
is called a
geodesic
. The hyperbolic distance
d_{H}(u,v)
is the hyperbolic length of
[u,v]
.

Figure 1:
(a) A geodesic
[u,v]
in the Poincaré ball model
\mathbb{B}^{D}
.
(b) Cone based approach: The input points are in blue. We add the red points to the coreset.

The hyperbolic distance
d_{H}(u,v)
can be obtained by a closed formula.
(Equations (
1
)–(
3
) in Section
2.1
.) It can be shown that the geodesics are arcs of circles that are orthogonal to the unit sphere
\partial\mathbb{B}^{D}
.
(See Figure
1
a.) This metric space
(\mathbb{B}^{D},d_{H})
has several properties that make it very different from the Euclidean space. For instance, the volume of a ball is exponential in its radius, instead of being polynomial, and thus some packing or discretization arguments used in the Euclidean case break down. On the other hand, triangles in hyperbolic space are
thin
: There is a constant
\delta
such that for any
u,v,w\in\mathbb{B}^{D}
, and for any point
t\in[u,w]
, there is a point in
[u,v]\cup[v,w]
that is at distance at most
\delta
from
u
. (For a more precise statement, see Section
5.1
.)

One motivation for studying algorithms in hyperbolic spaces is that computer networks, and in particular the internet, are known to have better embeddings into hyperbolic space than into Euclidean spaces
[
19
]
. Recently, connections have also been found between machine learning and hyperbolic geometry, in particular in the context of hyperbolic neural
networks
[
8
,
14
]
.

Our results.

We assume that we are in fixed dimension
D=O(1)
, and that
\varepsilon\in(0,1)
.
We are given an input set
P
of
n
points in
\mathbb{B}^{D}
.
For any point
q\in\mathbb{B}^{D}
, we denote by
f_{P}(q)
a point in
P
that is
farthest from
q
:

d_{H}(q,f_{P}(q))=\max_{p\in P}d_{H}(q,p).

We show (Theorem
18
) how to construct in
O(n/\varepsilon^{D})
time a coreset

P_{\varepsilon}\subset P
such that for any query point
q
, there is a point
p_{\varepsilon}\in P_{\varepsilon}

that satisfies

d_{H}(q,p_{\varepsilon})\geqslant(1-\varepsilon)\max_{p\in P}d_{H}(q,f_{P}(q))\quad\text{ and }\quad d_{H}(q,p_{\varepsilon})\geqslant\max_{p\in P}d_{H}(q,f_{P}(q))-\varepsilon.

Thus, our coreset provides both a
(1-\varepsilon)
-
multiplicative
and an
\varepsilon
-
additive
error bound. It is obviously impossible to obtain a constant additive error in Euclidean space.

It directly allows us to answer approximate farthest-neighbor queries in time
O(1/\varepsilon^{D})
, after
O(n/\varepsilon^{D})
preprocessing time, by returning the point in
P_{\varepsilon}
that is farthest from the query point
q
. Again, we obtain both an additive and a multiplicative error bound.

Our coreset yields approximation algorithms for other problems in
\mathbb{H}^{D}
.

•

The
diameter

\mathrm{diam}(P)
of
P
is the maximum interpoint distance in
P
, so
\mathrm{diam}(P)=\max_{u,v\in P}d_{H}(u,v)
. We obtain a
(1-\varepsilon)
-multiplicative and
\varepsilon
-additive error to
\mathrm{diam}(P)
in
O(n/\varepsilon^{D})
time by performing an approximate farthest neighbor for each point in
P
, and returning the largest result.

•

A
center
of
P
is a point
c\in P
such that
d_{H}(c,f_{P}(c))
is minimized. We can find an approximate radius (both additive and multiplicative) in
O(n/\varepsilon^{D})
by performing an approximate farthest neighbor query on every point in
P
,

•

We can compute an approximate
bichromatic closest pair
in
O(n/\varepsilon^{D})
time and an approximate
maximum spanning tree
in
O(n\log^{2}(n)/\varepsilon^{D})
time using the reduction by Agarwal et al.
[
1
]
. For the maximum spanning tree problem, we only get a
(1-\varepsilon)
-multiplicative approximation, and not an additive error.

Our approach.

There are two main cases in our construction. In Section
3
, we deal with small diameter input. We observe that, after applying a suitable isometry, the hyperbolic distance is within a constant factor from the Euclidean metric. Then we obtain
P_{\varepsilon}
by a bucketing approach, using a regular grid of mesh size
O(\varepsilon)
. This is a well-known approach in geometric approximation algorithms
[
11
]
.

In Section
6
, we consider large diameter input, where
\mathrm{diam}(P)\geqslant 5
.
In order to handle query points at distance
O(1)
from
O
, we use a grid-based approach similar
to the small diameter case, which yields
O(1/\varepsilon^{D})
coreset points.
At large scale, a simple grid-based discretization fails as the volume of a hyperbolic ball grows exponentially with its radius. Instead, we use a cone-based approach.

We partition the space around
O
into
O(1/\varepsilon^{(D-1)/2})
cones of angular diameter
O(\sqrt{\varepsilon})
. In each cone, we add to our coreset the point that is farthest from
O
. (See Figure
1
b.) Then we show, based on geometric arguments presented in Section
4
, that the points we added to our coreset can handle query points
q
such that the geodesic
[q,f_{P}(q)]
passes close enough to
O
.

In order to reduce to the case where
[q,f_{P}(q)]
is close to
O
, we apply a set of
O(1/\varepsilon^{(D-1)/2})
isometries of
\mathbb{B}^{D}
, each isometry mapping to the origin
O
a point taken from an approximately uniform sample of a constant radius sphere centered at
O
. For each such translation, we apply the cone-based approach above. It yields
O(1/\varepsilon^{D-1})
more coreset points. Our correctness proof uses properties of Gromov-hyperbolic space, to which we give an introduction in Section
5
, including a linear-time algorithm by Chepoi et al.
[
4
]
for approximating the diameter of a Gromov-hyperbolic space.

Comparison with previous work.

Euclidean nearest-neighbor searching has been extensively studied. For instance, Clarkson gave a data structure with
O(\log n)
query time and
\tilde{O}(n^{\lceil D/2\rceil})
preprocessing time
[
5
]
. As mentioned above,
Arya et al.
[
2
]
gave a data structure for the approximate version (ANN) with approximation factor
(1+\varepsilon)
, query time
O(\log(n)/\varepsilon^{D})
time and
O(n\log n)
preprocessing time
[
2
]
.
A coreset other than the input set itself is not possible for ANN in Euclidean space, as any input point
p
is the result of the query
q=p
.

As mentioned above, Agarwal et al.
[
1
]
gave a coreset of size
O(1/\varepsilon^{(D-1)/2})
for farthest-neighbor queries in the Euclidean space
\mathbb{R}^{D}
. Their coreset only provides a
(1-\varepsilon)
-multiplicative error, as the only coreset with constant additive error in
\mathbb{R}^{D}
is
P_{\varepsilon}=P
in the worst case.
Another coreset for approximate farthest-neighbor searching was given recently by de Berg and Theocharou
[
7
]
. They showed how to construct a coreset of size
O(1/\varepsilon^{2})
for farthest-neighbor queries in a simple polygon, using the geodesic distance.
Pagh et al.
[
16
]
studied approximate farthest-neighbor searching in high dimension (i.e. when we do not assume that
D=O(1)
), with query time
\tilde{O}(n^{1/c^{2}})

and space usage
O(n^{1/(2c^{2})})
in dimension
O(\log n)
.

Recently, two-dimensional Voronoi diagrams
[
9
]
and farthest-point Voronoi diagrams
[
20
]
have been studied under the Hilbert metric. This metric generalizes the Cayley-Klein model of
\mathbb{H}^{D}
to any convex polygon, instead of the unit disk.

To the best of our knowledge, there is no previous work on farthest-neighbor searching in the hyperbolic space
\mathbb{H}^{D}
when
D\geqslant 3
. However, Chepoi et al.
[
4
]
studied related problems in the more general setting of Gromov
\delta
-hyperbolic spaces. A metric space
(X,d)
is

\delta
-hyperbolic if for any
t,u,v,w\in M
, the two largest sums among
d(t,u)+d(v,w)
,
d(t,v)+d(u,w)
and
d(t,w)+d(u,v)
differ by at most
2\delta
. The hyperbolic space
\mathbb{H}^{D}
is Gromov hyperbolic, with
\delta=\log 3
. (See Section
5
for a brief introduction to Gromov hyperbolic spaces, with an equivalent definition.)
Chepoi et al.
[
4
]
showed that the diameter of a
\delta
-hyperbolic space can be approximated with additive error
2\delta
in linear time. With our approach, the diameter of a subset of
\mathbb{H}^{D}
can be approximated in
O(n/\varepsilon^{D})
time with an additive error
\varepsilon
, so we obtain a better approximation error, but in a more restricted setting. They provide a similar result for approximating the radius and the eccentricities of all points, which we can improve in the same way, still in the special case of
\mathbb{H}^{D}
.

Approximate near-neighbor searching has also been studied in the context of hyperbolic spaces. Krauthgamer and Lee
[
13
]
gave a data structure for ANN in a special case of
\delta
-hyperbolic spaces, that applies to
\mathbb{H}^{D}
, with
O(\delta)
additive error,
O(n^{2})
space usage and
O(\log^{2}n)
query time. More recently,
Kisfaludi-Bak and Wordragen
[
12
]
gave an ANN data structure for
\mathbb{H}^{D}
with
(1+\varepsilon)
factor approximation,
O(n\log(1/\varepsilon)/\varepsilon^{D})
size
and
O(\log n\log(1/\varepsilon)/\varepsilon^{D})
query time. In our previous work
[
17
]
, we gave a data structure for ANN in
\mathbb{H}^{D}
with
O(1)
additive error,
O(\log n)
query time and
O(n\log n)
construction time.

Preliminaries

In this paper,
P=\{p_{1},...,p_{n}\}
denotes a set of
n
points in a metric space
(X,d)
.
This metric space will be either the Poincaré ball model
(\mathbb{B}^{D},d_{H})

of the
D
-dimensional hyperbolic space
\mathbb{H}^{D}

(Section
2.1
), or a Gromov hyperbolic space (Section
5
).
For any point
q\in X
, we denote by
f_{P}(q)
a point in
P
that is farthest to
q
, hence

d(f_{P}(q),q)=\max_{p\in P}d(p,q).

The
diameter
of
P
is the maximum distance

\mathrm{diam}(P)=\max_{p,q\in P}d(p,q),

and a
diametral pair
is a pair of points
a^{*},b^{*}\in P
such that
\mathrm{diam}(P)=d(a^{*},b^{*})
.

The metric space
(X,d)
is a
geodesic space
if,
between any two points
p
and
q
, there exists a shortest path
[p,q]\subset X
, called a
geodesic
.
More precisely, there is an isometry
\gamma:[0,d(p,q)]\to X
such that
\gamma(0)=p
and

\gamma(d(p,q))=q
.
For any 3 points
p,q,r\in X
, the
geodesic triangle

[p,q,r]
is the union of three geodesics

[p,q]
,
[q,r]
,
[r,p]
, called its
sides
.

In this paper, we use the natural logarithm, denoted by
\log(\cdot)=\log_{e}(\cdot)
.

2.1
The Poincaré Ball Model

The hyperbolic space
\mathbb{H}^{D}
is the
D
-dimensional space of constant sectional curvature -1.
Several isometric models of
\mathbb{H}^{D}
have been considered, including the
Poincaré half-space model and the hyperboloid model. We will use
the
Poincaré ball model
, also called
conformal ball model

[
18
]
.
In this model,
\mathbb{H}^{D}
is identified with the open unit ball

\mathbb{B}^{D}=\{x\in\mathbb{R}^{D}:\|x\|<1\}.

It is equipped with the
hyperbolic metric

d_{H}
, given by the expressions

\displaystyle d_{H}(u,v)

\displaystyle=\arcosh\left(1+\frac{2\|u-v\|^{2}}{(1-\|u\|^{2})(1-\|v\|^{2})}\right)

(1)

\displaystyle=2\log\frac{\|u-v\|+\sqrt{\|u\|^{2}\|v\|^{2}-2u\cdot v+1}}{\sqrt{(1-\|u\|^{2})(1-\|v\|^{2})}},

(2)

where
\|\cdot\|
is the Euclidean norm.
In the special case where
\|v\|=r
, we have

d_{H}(O,v)=2\artanh r=\log\left(\frac{1+r}{1-r}\right).

(3)

Using this metric
d_{H}
,
geodesics are arcs of circles orthogonal to the boundary sphere
\partial\mathbb{B}^{D}
.
The distance
d_{H}(u,v)
goes to infinity when
\|v\|
goes to 1, so the boundary
\partial\mathbb{B}^{D}
of the Poincaré ball can be regarded as the set of points at infinity.

Isometries.

We will need to be able to change the center
O=(0,\dots,0)
of the Poincaré ball in order
to simplify our calculations. More precisely,
let
h
be a point in
\mathbb{B}^{D}
. The
hyperbolic translation

\tau_{h}
is an isometry
of
(\mathbb{B}^{D},d_{H})
such that
\tau_{h}(O)=h
. It is given by the
expression
[
18
]
:

\tau_{h}(u)=\frac{(1-\|h\|^{2})u+(\|u\|^{2}+2\langle u,h\rangle+1)h}{\|h\|^{2}\|u\|^{2}+2\langle u,h\rangle+1}

where
\langle u,h\rangle
denotes the standard Euclidean inner product in
\mathbb{R}^{D}
.
This map can be computed in constant time, as well as its inverse
\mu_{h}=\tau_{h}^{-1}
. Then

\mu_{h}
is an isometry that maps
h
to
O
, and can be computed in constant time. It follows that:

Proposition 1
.

Let
h
be an arbitrary point in
\mathbb{B}^{D}
where
D=O(1)
.
There is an isometry
\mu_{h}
of
(\mathbb{B}^{D},d_{H})

such that
\mu_{h}(h)=O
, and for any point
p\in\mathbb{B}^{D}
, we can compute
\mu_{h}(p)
in

O(1)
time.

3
Small Diameter Input

In this section, we first deal with the case where the input point set
P
has constant
diameter. So we first compute
\Delta_{1}=d_{H}(p_{1},f_{P}(p_{1}))
, and thus

\Delta_{1}\leqslant\mathrm{diam}(P)\leqslant 2\Delta_{1}.

We assume that
\Delta_{1}\leqslant 5
, and we apply the isometry
\mu_{p_{1}}
so that
p_{1}

is the origin
O
of the Poincaré ball
\mathbb{B}^{D}
.
We first observe the following

Lemma 2
.

For any
q\in\mathbb{B}^{D}
, we have
d_{H}(q,f_{P}(q))\geqslant\Delta_{1}/2
.

Proof.

Let
q_{1}=f_{P}(p_{1})
. By the triangle inequality,

\Delta_{1}=d_{H}(p_{1},q_{1})\leqslant d_{H}(p_{1},q)+d_{H}(q,q_{1})
holds.
It implies that
d_{H}(p_{1},q)\geqslant\Delta_{1}/2
or
d_{H}(q,q_{1})\geqslant\Delta_{1}/2
,
and the result follows.
∎

Let
B_{H}(O,\Delta_{1})
be the ball centered at
O
with hyperbolic radius
\Delta_{1}
, and thus
with Euclidean radius
R=\tanh(\Delta_{1}/2)\leqslant\tanh(5/2)
.

Lemma 3
.

For any two points
u,v\in B_{H}(O,\Delta_{1})
, we have

2\|uv\|\leqslant d_{H}(u,v)<76\|uv\|.

Proof.

Let
[u,v]
be the geodesic from
u
to
v
and
\overline{uv}
be the line
segment from
u
to
v
. Then we have

2\|uv\|=\int_{\overline{uv}}2\|dx\|\leqslant\int_{[u,v]}2\|dx\|\leqslant\int_{[u,v]}\frac{2\|dx\|}{1-\|x\|^{2}}=d_{H}(u,v)

and

d_{H}(u,v)=\int_{[u,v]}\frac{2\|dx\|}{1-\|x\|^{2}}\leqslant\int_{\overline{uv}}\frac{2\|dx\|}{1-\|x\|^{2}}\leqslant\frac{2}{1-R^{2}}\int_{\overline{uv}}\|dx\|=\frac{2}{1-R^{2}}\|uv\|<76\|uv\|.

∎

The
\alpha
-grid
G_{\alpha}
in
\mathbb{R}^{D}
is the discrete set of points whose coordinates are
multiples of
\alpha
, so we have
G_{\alpha}=\alpha\mathbb{Z}^{D}
. For each point
p\in(\mathbb{R}^{+})^{D}
,
the point of
G_{\alpha}
obtained by rounding down each coordinate to the nearest multiple of

\alpha
is at Euclidean distance at most
\alpha\sqrt{D}
from
p
and is closer to
O
than
p
is.
It follows that

Proposition 4
.

For each point
p\in B_{H}(O,\Delta_{1})
, there is a point
p_{\alpha}\in G_{\alpha}\cap B_{H}(O,\Delta_{1})

such that
d_{H}(p,p_{\alpha})\leqslant 76\alpha\sqrt{D}
.

So we construct our coreset
P_{\varepsilon}
for farthest-point problems as follows. We set

\alpha=\varepsilon\Delta_{1}/(304\sqrt{D})
. We use a bucketing approach.
We place any two points
p,p^{\prime}\in P
such that
p_{\alpha}=p^{\prime}_{\alpha}

in the same bucket, and keep only one point from each bucket, obtaining a subset
P_{\varepsilon}\subset P

such that for any point in
p\in P
, there is a point
p^{\prime\prime}\in P_{\varepsilon}
that satisfies
p_{\alpha}=p^{\prime\prime}_{\alpha}
.
This construction can be done in
O(n)
time, and we have
|P_{\varepsilon}|=O(1/\alpha^{D})=O(1/\varepsilon^{D})
.

For any query point
q\in\mathbb{B}^{D}
, let
q^{\prime}=f_{P}(q)
. Then there is a point
q^{\prime\prime}\in P_{\varepsilon}

such that
q^{\prime}_{\alpha}=q^{\prime\prime}_{\alpha}
. It follows from Proposition
4
that

d_{H}(q^{\prime},q^{\prime\prime})\leqslant d_{H}(q^{\prime},q^{\prime}_{\alpha})+d_{H}(q^{\prime\prime}_{\alpha},q^{\prime\prime})\leqslant 152\alpha\sqrt{D}=\varepsilon\Delta_{1}/2.

Then by Lemma
2
,

d_{H}(q,q^{\prime\prime})\geqslant d_{H}(q,q^{\prime})-d_{H}(q^{\prime},q^{\prime\prime})\geqslant d_{H}(q,q^{\prime})-\varepsilon\Delta_{1}/2\geqslant(1-\varepsilon)d_{H}(q,q^{\prime})

and thus
q^{\prime\prime}
is an
\varepsilon
-approximate farthest neighbor of
q
in
P
. So we proved the following.

Lemma 5
.

Let
D
be a fixed integer and
0<\varepsilon<1
.
Let
P=\{p_{1},\dots,p_{n}\}
be a set of
n
points in
\mathbb{B}^{D}

such that
\Delta_{1}=d_{H}(p_{1},f_{P}(p_{1}))
satisfies
\Delta_{1}\leqslant 5
.
We can construct in
O(n)

5
Gromov Hyperbolic Spaces

Let
(X,d)
be a metric space. The
Gromov product
of two points
u,v\in X

with respect to
t\in X
is defined as

(u|v)_{t}=\frac{1}{2}\left(d(u,t)+d(v,t)-d(u,v)\right).

This metric space
(X,d)
is
\delta
-
hyperbolic
if for any 4 points
t,u,v,w\in X
, we have

(u|w)_{t}\geqslant\min\{(u|v)_{t},(v|w)_{t}\}-\delta.

(4)

An example of
\delta
-hyperbolic space is
\mathbb{B}^{D}

[
6
, Proposition 4.3]
:

Proposition 10
.

The space
(\mathbb{B}^{D},d_{H})
is
\delta
-hyperbolic, with
\delta=\log 3
.

Intuitively, Gromov-hyperbolic spaces behave like tree-metrics. More precisely,
it has been shown that any
n
-points
\delta
-hyperbolic space can be embedded
into a tree metric with
O(\delta\log n)
additive distortion
[
10
]
.
Also, a geodesic space is
\delta
-hyperbolic when all its triangles
are thin, as explained in Section
5.1
.

The Lemma below was proved by Chepoi et al.
[
4
]
. We include a shorter proof.

Lemma 11

(
[
4
]
)
.

Let
s,t,u,v
be 4 points in a
\delta
-hyperbolic space
(X,d)
. If

d(s,t)\geqslant\max\{d(s,u),d(s,v)\}
,
then
d(u,v)\leqslant\max\{d(t,u),d(t,v)\}+2\delta
.

Proof.

Without loss of generality, suppose that
(u|t)_{s}\geqslant(v|t)_{s}
. It follows from
the definition of Gromov hyperbolicity (
4
) that

(u|v)_{s}\geqslant(v|t)_{s}-\delta.

It can be rewritten

d(s,u)+d(s,v)-d(u,v)\geqslant d(s,v)+d(s,t)-d(t,v)-2\delta.

As
d(s,t)\geqslant d(s,u)
, it implies that
d(u,v)\leqslant d(t,v)+2\delta
.
∎

Let
a^{*},b^{*}
be a diametral pair of
P\subset X
,
\hat{a}=f_{P}(p_{1})
and
\hat{b}=f_{P}(\hat{a})
.
As was observed by Chepoi et al.
[
4
]
, by applying Lemma
11

with
s=\hat{a}
,
t=\hat{b}
,
u=a^{*}
and
v=b^{*}
,

\hat{a}
and
\hat{b}
form an approximate diametral pair in the following sense:

Corollary 12
.

If
(X,d)
is
\delta
-hyperbolic, then

d(\hat{a},\hat{b})\leqslant\mathrm{diam}(P)\leqslant d(\hat{a},\hat{b})+2\delta
.

5.1
Geodesic
\delta
-Hyperbolic Spaces

\delta
-thin geodesic triangle
[u,v,w]

Let
u,v,w
be three points in a geodesic
\delta
-hyperbolic space
(X,d)
.
Let
T
be a tree, called
tripod
, with leafs
u,v,w
, connected to a root node

such that
the length of the three edges are given by (see Figure

d(r,u)=\ell_{u}=(v|w)_{u},\quad d(r,v)=\ell_{v}=(u|w)_{v},\text{ and }d(r,w)=\ell_{w}=(u|v)_{w}.

It can be easily checked that the distances along this tree coincide with the metric
d
,
for instance
d(u,v)=\ell_{u}+\ell_{v}
.

There is a unique map
\varphi:[u,v,w]\to T
that sends
u,v
and
w
to the corresponding leafs
of
T
, and which is an isometry when restricted to each side
[u,v]
,
[v,w]
and
[u,w]
.
Intuitively, the geodesic triangle is folded onto the tripod, so that each point in the interior of
an edge of the tripod corresponds to two points of the triangle, taken from the two adjacent sides.

The triangle
[u,v,w]
is
\delta^{\prime}
-
thin
if for any two points
s,t\in[u,v,w]
,

\varphi(s)=\varphi(t)
implies
d(s,t)\leqslant\delta^{\prime}
. It has been shown that in a Gromov-hyperbolic
geodesic space, all triangles are thin
[
10
, Proposition 6.3C]
:

Proposition 13
.

If
(X,d)
is a geodesic
\delta
-hyperbolic metric space, then all the geodesic
triangles in
(X,d)
are
2\delta
-thin.

In the case of
\mathbb{B}^{D}
, the following is known
[
6
, Corollary 4.2]
.

Proposition 14
.

Every triangle in
(\mathbb{B}^{D},d_{H})
is
(\log 3)
-thin.

5.2
A Property of Approximate Diametral Pairs

We use the same notations as above, so

X
is a geodesic
\delta
-hyperbolic space,
P\subset X
and

,

\hat{m}

of

of an exact diametral pair

Lemma 15
.

Let
(X,d)
be a geodesic
\delta
-hyperbolic space such that every geodesic

\delta^{\prime}
-thin.
Let

,

and

Proof.

Without loss of generality, suppose that
d(a^{*},q^{\prime})\leqslant d(b^{*},q^{\prime})
. Then by Lemma
11
,

d(b^{*},q^{\prime})\leqslant\mathrm{diam}(P)\leqslant d(b^{*},q^{\prime})+2\delta.

(5)

Let
m
and
m_{1}
be the points at distance
\mathrm{diam}(P)/2-\delta
from
q^{\prime}

along a geodesic
[q^{\prime},q]
and a geodesic

As

\displaystyle(b^{*}|q)_{q^{\prime}}

\displaystyle=\left(d(b^{*},q^{\prime})+d(q,q^{\prime})-d(b^{*},q)\right)/2

\displaystyle\geqslant\mathrm{diam}(P)/2-\delta.

As the triangle
[b^{*},q,q^{\prime}]
is
\delta^{\prime}
-thin, it follows that

d(m,m_{1})\leqslant\delta^{\prime}.

(6)

We now consider the geodesic triangle

.

\displaystyle(a^{*}|q^{\prime})_{b^{*}}

\displaystyle=\left(d(a^{*},b^{*})+d(b^{*},q^{\prime})-d(a^{*},q^{\prime})\right)/2

\displaystyle=\left(\mathrm{diam}(P)+d(b^{*},q^{\prime})-d(a^{*},q^{\prime})\right)/2

\displaystyle\geqslant\mathrm{diam}(P)/2

Let
m_{2}
be the point along
[b^{*},q^{\prime}]
at distance
\mathrm{diam}(P)/2
from
b^{*}
.
As the triangle
[a^{*},b^{*},q^{\prime}]
is
\delta^{\prime}
-thin, we have

d(m_{2},m^{*})\leqslant\delta^{\prime}.

(7)

The points
m_{1}
and
m_{2}
are both along
[b^{*},q^{\prime}]
, with
m_{1}
being at distance

from
q^{\prime}
and
m_{2}
being at distance
\mathrm{diam}(P)/2
from

.
So we have

d(m_{1},m_{2})=|\mathrm{diam}(P)/2-\delta-d(b^{*},q^{\prime})+\mathrm{diam}(P)/2|=|\mathrm{diam}(P)-d(b^{*},q^{\prime})-\delta|.

By inequality (
5
), it follows that
d(m_{1},m_{2})\leqslant\delta
.
Then

follows from inequalities (
6
) and (

).
∎

be a geodesic

-hyperbolic space

6
Coreset for Large Diameter Input

We now consider farthest-neighbor searching when the input point set has diameter
larger than 5. So
P=\{p_{1},\dots,p_{n}\}
is a subset of
\mathbb{B}^{D}
, and
we assume that
\Delta_{1}\geqslant 5
, where
\Delta_{1}=d_{H}(p_{1},f_{P}(p_{1}))
,
which implies that
\mathrm{diam}(P)\geqslant 5
.
We describe below the construction of our coreset
P_{\varepsilon}
for farthest-point queries.

We first compute an approximate diametral pair
\hat{a},\hat{b}
, where
\hat{a}=f_{P}(p_{1})

and
\hat{b}=f_{P}(\hat{a})
. Let
\hat{m}
be the midpoint of
[\hat{a},\hat{b}]
. Without loss of generality, we assume that
\hat{m}=O
, as otherwise, we can apply the isometry
\mu_{\hat{m}}
to

.

In the same way as we did for the small diameter case (Proposition
4
),
we construct a set
G
of
O(1/\varepsilon^{D})
grid points in the hyperbolic ball

B_{0}=B_{H}(O,8\log 3)
such that for any point
p\in B_{0}
, there is a point
g\in G

that satisfies
d_{H}(p,g)\leqslant\varepsilon/2
. For each point in
g\in G
, we insert

f_{P}(g)
into our coreset
P_{\varepsilon}
. There are
O(1/\varepsilon^{D})
such points.

Let
S_{0}
be the sphere centered at
O=\hat{m}
with hyperbolic radius
7\log 3
.
We construct a set
H\subset S_{0}
, called a
\sqrt{\varepsilon}/(8\pi)
-net,
of size
O(1/\varepsilon^{(D-1)/2})
. It has the property that for any point
p\in S_{0}
, there
is a point
h\in H
such that
d_{H}(p,h)\leqslant\sqrt{\varepsilon}/(8\pi)
. Such a set can be easily constructed, for instance by constructing a regular grid of mesh
\Theta(\sqrt{\varepsilon})
on the box circumscribed to
S_{0}
, and projecting its vertices onto
S_{0}
.

For each point
h\in H
, we apply
\mu_{h}
to all the points in
P
, which takes
O(n)
time. After this transformation, we have
h=O
. Let
\mathcal{C}
be a partition of the space around
O
into
O(1/\varepsilon^{(D-1)/2})
simplicial cones of angular diameter
\sqrt{\varepsilon}/2
. This partition can be easily constructed using a grid circumscribed to
S_{0}
. (See a more detailed description in the book by Narasinham and Smid
[
15
]
.)

For each cone
C\in\mathcal{C}
that contains
at least one point of
\mu_{h}(P)
, we
insert into our coreset
P_{\varepsilon}
a point
p_{\varepsilon}\in P
such that
\mu_{h}(p_{\varepsilon})
is a point
in
C\cap\mu_{h}(P)
that is farthest from
O
. For each
h\in H
,
there are
O(1/\varepsilon^{(D-1)/2})
such points, so the size of
P_{\varepsilon}
remains
O(1/\varepsilon^{D})
.

It remains to prove that this construction is correct. So we need to argue that
for any query point
q\in\mathbb{B}^{D}
, there is a point
p_{\varepsilon}\in P_{\varepsilon}
such
that
d_{H}(q,p_{\varepsilon})\geqslant d_{H}(q,f_{P}(q))-\varepsilon
.

There are two cases. First, suppose that
q\in B_{0}
. Then there is a point
g\in G

such that
d_{H}(q,g)\leqslant\varepsilon/2
, and the point
g^{\prime}=f_{P}(g)
is in
P_{\varepsilon}
.
It follows that

\displaystyle d_{H}(q,g^{\prime})

\displaystyle\geqslant d_{H}(g,g^{\prime})-d_{H}(q,g)

\displaystyle\geqslant d_{H}(g,f_{P}(q))-\varepsilon/2

\displaystyle\geqslant d_{H}(q,f_{P}(q))-d_{H}(q,g)-\varepsilon/2

\displaystyle\geqslant d_{H}(q,f_{P}(q))-\varepsilon.

So we can take
p_{\varepsilon}=g^{\prime}
.

Now suppose that
q\notin B_{0}
. Let
q^{\prime}=f_{P}(q)
, and let
m
be the point along

[q,q^{\prime}]
that is at distance
\mathrm{diam}(P)/2-\log 3
from

.
By Lemma
16
, this point

is inside

, and thus
the geodesic
[q,q^{\prime}]
crosses

at a point

and

.
Then we must have

.

There is a point

and

,

and

,
we also have

.

Let

and

. As

and

are at hyperbolic distance at least

from

.

satisfies

.

Let
C
be the cone in
\mathcal{C}
that contains
q^{\prime}_{h}
. Let
c
denote the corresponding
point that we inserted into
P_{\varepsilon}
, so
c
is a point in
C\cap\mu_{h}(P)
that is furthest
from
O
. In particular, we have
d_{H}(O,c)\geqslant d_{H}(O,q^{\prime}_{h})
,
and there is a point
p_{\varepsilon}\in P_{\varepsilon}

such that
c=\mu_{h}(p_{\varepsilon})
. As
c
and
q^{\prime}_{h}
are in the same cone, the angle

\psi^{\prime}=\pi-\angle q_{h}Oc
satisfies
\psi^{\prime}\leqslant\psi+\sqrt{\varepsilon}/2\leqslant\sqrt{\varepsilon}
.
Then we have

\displaystyle d_{H}(q,p_{\varepsilon})

\displaystyle=d_{H}(q_{h},c)

\displaystyle\geqslant d_{H}(O,q_{h})+d_{H}(O,c)-\varepsilon

by lemma
7

\displaystyle\geqslant d_{H}(O,q_{h})+d_{H}(O,q^{\prime}_{h})-\varepsilon

\displaystyle\geqslant d_{H}(q_{h},q^{\prime}_{h})-\varepsilon

\displaystyle=d_{H}(q,q^{\prime})-\varepsilon

\displaystyle=d_{H}(q,f_{P}(q))-\varepsilon.

So we just proved the following:

Lemma 17
.

Let
P=\{p_{1},\dots,p_{n}\}
be a set of
n
points in
\mathbb{B}^{D}

such that
\Delta_{1}=d_{H}(p_{1},f_{P}(p_{1}))
satisfies
\Delta_{1}\geqslant 5
.
For any
\varepsilon
such that
0<\varepsilon<1
,
we can construct in
O\left(n/\varepsilon^{D}\right)
time a
coreset
P_{\varepsilon}\subset P
for farthest-point queries of
size
|P_{\varepsilon}|=O(1/\varepsilon^{D})
. In particular, for any query point
q\in\mathbb{B}^{D}
,
there is a point
p_{\varepsilon}\in P_{\varepsilon}
such that

d_{H}(q,p_{\varepsilon})\geqslant d_{H}(q,f_{P}(q))-\varepsilon.

We can now combine the result above for large diameter input with our result for small diameter.
When
\Delta_{1}\leqslant 5

.
In this case,
\mathrm{diam}(P)\leqslant 5

\varepsilon
.
When
\Delta_{1}\geqslant 5

17
. As
\mathrm{diam}(P)\geqslant 5
, it gives
an additive error at most
\varepsilon
. So we obtain the following:

Theorem 18
.

Let
D
be a fixed integer and
0<\varepsilon<1
.
Let
P
be a set of
n

\mathbb{B}^{D}
.
We can construct in

time a

P_{\varepsilon}\subset P

,

p_{\varepsilon}\in P_{\varepsilon}
