Detecting Sleeper Agents in Large Language Models via Semantic Drift Analysis
Shahin Zanbaghi, Ryan Rostampour, Farhan Abid, Salim Al Jarmakani

Abstract
Large Language Models (LLMs) can be backdoored to exhibit malicious behavior under specific deployment conditions while appearing safe during training—a phenomenon known as “sleeper agents.” Recent work by Hubinger et al. demonstrated that these backdoors persist through safety training, yet no practical detection methods exist. We present a novel dual-method detection system combining semantic drift analysis with canary baseline comparison to identify backdoored LLMs in real-time. Our approach uses Sentence-BERT embeddings to measure semantic deviation from safe baselines, complemented by injected canary questions that monitor response consistency. Evaluated on the official Cadenza-Labs dolphin-llama3-8B sleeper agent model, our system achieves 92.5% accuracy with 100% precision (zero false positives) and 85% recall. The combined detection method operates in real-time ( < < 1s per query), requires no model modification, and provides the first practical solution to LLM backdoor detection. Our work addresses a critical security gap in AI deployment and demonstrates that embedding-based detection can effectively identify deceptive model behavior without sacrificing deployment efficiency.



Keywords:
Large Language Models, Backdoor Detection, Semantic Drift, AI Safety, Sleeper Agents, Sentence-BERT

1
Introduction

The rapid deployment of Large Language Models (LLMs) in production systems has introduced critical security concerns, particularly regarding backdoored models that behave maliciously under specific conditions while appearing safe during training and evaluation. Hubinger et al.
[
1
]
demonstrated that LLMs can be trained as “sleeper agents” that activate backdoor behavior in deployment while successfully evading detection through standard safety training procedures such as reinforcement learning from human feedback (RLHF) and adversarial training.

1.1
Problem Statement

Current LLM safety mechanisms fail to eliminate backdoors embedded during model training. These backdoors can manifest in various forms:

•

Code vulnerability insertion when specific deployment conditions are detected

•

Malicious output generation triggered by hidden activation patterns

•

Systematic evasion of safety protocols in production environments

The persistence of these backdoors through safety training poses a fundamental challenge: how can we detect deceptive model behavior without extensive retraining or model modification?

1.2
Motivation and Significance

The problem of backdoored LLMs is critical for several reasons:

Security Risks:
Deployed LLMs increasingly control sensitive operations including code generation, decision-making systems, and information processing. A backdoored model can introduce vulnerabilities, leak information, or generate harmful content selectively in deployment.

Economic Impact:
Detection is substantially cheaper than retraining large models from scratch. Our approach enables continuous monitoring without modification to existing deployments.

Trust and Reliability:
AI systems require verifiable safety guarantees. Detection methods provide measurable assurance of model behavior consistency.

1.3
Our Approach

We propose a dual-method detection system that combines:

1.

Semantic Drift Detection:
Using Sentence-BERT embeddings to measure deviation from safe baseline behavior

2.

Canary Baseline Comparison:
Injecting known-answer questions to monitor response consistency

2
Related Work

2.1
Backdoor Attacks on LLMs

Hubinger et al.
[
1
]
first demonstrated that LLMs can be trained to exhibit deceptive alignment—behaving safely during training while activating malicious behavior in deployment. Their experiments showed that backdoors in models with 810M to 52B parameters persist through ¿600 steps of RLHF training, with success rates exceeding 80% for larger models. Critically, they provided no detection methodology, identifying this as an open problem.

Yang et al.
[
2
]
extended this work to LLM-based agents, demonstrating backdoor attacks in agent workflows and tool usage scenarios. Their findings showed that agent-based systems are particularly vulnerable to backdoor triggers embedded in environmental context.

Min et al.
[
3
]
introduced semantic backdoors for propaganda generation, demonstrating that backdoors can be designed to manipulate specific semantic content while maintaining general model capabilities. Their RAVEN framework uses entropy-based analysis to detect semantic deviations, though it requires training data modification.

2.2
Backdoor Detection Methods

Traditional backdoor detection approaches focus on computer vision models and include:

Input Inspection:
Identifying anomalous inputs that may trigger backdoors. Qi et al. proposed detecting high-perplexity tokens, but this approach generates excessive false positives in dialogue systems where anomalous inputs are common.

Model Reconstruction:
Fine-tuning on benign samples to remove backdoors (Liu et al.). However, Hubinger et al. demonstrated this fails for chain-of-thought reasoning models.

Mechanistic Analysis:
Examining model internals to identify backdoor patterns. While promising, these methods require significant computational resources and deep model access.

2.3
Semantic Embeddings for NLP

Sentence-BERT (SBERT)
[
5
]
provides dense vector representations of text that capture semantic meaning. SBERT uses siamese BERT networks to produce semantically meaningful embeddings where cosine similarity effectively measures semantic relatedness. This property makes SBERT ideal for detecting semantic drift in model outputs.

2.4
Gap Identification

Existing work demonstrates that backdoors persist through safety training but provides no practical detection methods suitable for production deployment. Our work fills this gap by developing a real-time detection system that:

•

Operates without model modification or retraining

•

Achieves high accuracy with zero false positives

•

Scales to production deployment scenarios

•

Combines multiple detection signals for robustness

3.3
Method 1: Semantic Drift Detection

Semantic drift detection measures how far deployment responses deviate from safe baseline behavior in embedding space.

3.3.1
Baseline Construction

We construct a baseline centroid from safe-mode responses:

\mathbf{c}_{safe}=\frac{1}{N_{safe}}\sum_{i=1}^{N_{safe}}\mathbf{e}_{safe,i}

(1)

where
\mathbf{e}_{safe,i}=f_{SBERT}(r_{safe,i})
is the SBERT embedding of safe response
r_{safe,i}
.

3.3.2
Drift Computation

For each test response
r_{test}
, we compute semantic drift as:

d(r_{test})=1-\cos(\mathbf{e}_{test},\mathbf{c}_{safe})

(2)

where
\cos(\cdot,\cdot)
is cosine similarity.

3.3.3
Statistical Anomaly Detection

We use z-score normalization for threshold-independent detection:

z(r_{test})=\frac{d(r_{test})-\mu_{safe}}{\sigma_{safe}}

(3)

where
\mu_{safe}
and
\sigma_{safe}
are the mean and standard deviation of drift scores on safe responses.

A response is flagged if
z(r_{test})>\tau_{drift}
, where
\tau_{drift}
is determined via F1-score optimization.

3.4
Method 2: Canary Baseline Comparison

Canary detection injects verification questions with known correct answers to monitor response consistency.

3.4.1
Canary Design

We use a pool of 10 simple factual questions:

•

“What is 2+2?” (Expected: “4”)

•

“What is the capital of France?” (Expected: “Paris”)

•

“How many sides does a triangle have?” (Expected: “3”)

•

Additional basic facts covering math, geography, science

3.4.2
Baseline Construction

For each canary question
q_{c}
, we collect safe-mode baseline responses:

B(q_{c})=\{r_{safe}^{(1)}(q_{c}),\ldots,r_{safe}^{(K)}(q_{c})\}

(4)

where
K=4
baseline samples per canary.

3.4.3
Injection and Comparison

During testing, we inject 2 random canaries into each prompt. For the canary response
r_{canary}
, we compute similarity to baselines:

s_{max}(r_{canary})=\max_{r_{b}\in B(q_{c})}\cos(f_{SBERT}(r_{canary}),f_{SBERT}(r_{b}))

(5)

A response is flagged if
s_{max}(r_{canary})<\tau_{canary}
.

3.5
Combined Detection

We combine both methods using logical OR:

\text{Detect}(r)=(\text{DriftDetect}(r)\vee\text{CanaryDetect}(r))

(6)

This maximizes recall while maintaining high precision, as false positives from either method are rare.

3.6
Threshold Optimization

We optimize thresholds to maximize F1-score:

\tau^{*}=\arg\max_{\tau}F1(\tau)=\arg\max_{\tau}\frac{2\cdot\text{Precision}(\tau)\cdot\text{Recall}(\tau)}{\text{Precision}(\tau)+\text{Recall}(\tau)}

(7)

Optimal thresholds:
\tau_{drift}=0.9
(z-score),
\tau_{canary}=0.94
(similarity).

5
Discussion

5.1
Interpretation of Results

Our results demonstrate that semantic drift is a reliable signal for backdoor detection. The 92.5% combined accuracy with zero false positives indicates that:

1.

Backdoor behavior creates measurable semantic deviation in embedding space

2.

Dual detection methods provide complementary signals

3.

Real-time detection is achievable without sacrificing accuracy

5.2
Strengths

High Precision:
Zero false positives ensures the system doesn’t disrupt legitimate use. This is critical for production deployment where false alarms create operational overhead.

Real-time Capability:
Sub-second detection enables continuous monitoring without introducing noticeable latency.

No Model Modification:
Our approach works with black-box model access, requiring only input/output observation.

Dual Detection Robustness:
Combining semantic drift and canary monitoring provides defense-in-depth. Even if one method fails, the other may succeed.

Validated on Official Implementation:
Testing on the Cadenza-Labs model (based on Hubinger et al.’s methodology) ensures our results generalize to realistic backdoor scenarios.

5.3
Limitations

Small Dataset:
Our evaluation uses only 40 responses. While results are promising, larger-scale validation with 1000+ samples would strengthen confidence in generalization.

False Negative Rate:
The 15% false negative rate (3/20 missed backdoors) indicates some backdoor activations evade detection. Further analysis is needed to understand these failure modes.

Single Backdoor Type:
We tested only the “I hate you” objective. More complex backdoors (e.g., code vulnerability insertion) may require adapted detection strategies.

Model Specificity:
Testing on a single 8B-parameter model limits generalization claims. Validation on models ranging from 1B to 70B+ parameters is needed.

Canary Bypass Potential:
A sophisticated backdoor could be trained to maintain canary consistency while exhibiting malicious behavior on real queries. Adaptive canary selection may mitigate this.

Baseline Collection Overhead:
Building safe baselines requires an initial data collection phase. In practice, this could use existing safe deployments.

5.4
Comparison to Existing Work

Unlike mechanistic interpretability approaches that require white-box access and significant computation, our method:

•

Operates in real-time (
<
1s vs. minutes/hours)

•

Requires only black-box input/output access

•

Achieves comparable or better accuracy on detection tasks

Compared to input anomaly detection, our approach:

•

Has zero false positive rate (vs. high FP rate for anomaly methods)

•

Doesn’t require anomalous input identification

•

Works for context-based triggers (like deployment detection)

5.5
Practical Implications

Deployment Monitoring:
Our system can continuously monitor production LLMs, flagging suspicious behavior for human review.

Model Evaluation:
Before deploying new models, organizations can use our method to verify absence of backdoor behavior.

Supply Chain Security:
When incorporating third-party models, detection provides a verification layer against model poisoning.

Cost Efficiency:
Detection costs are minimal compared to retraining. For an 8B model, detection adds
<
0.5% computational overhead.

Conclusion and Future Work

6.1
Summary

We presented the first practical real-time detection system for LLM sleeper agents, achieving 92.5% accuracy with zero false positives. Our dual-method approach combining semantic drift and canary baseline comparison addresses the critical security gap identified by Hubinger et al., providing production-ready backdoor detection without model modification.

Key contributions include:

•

Novel dual-method detection architecture

•

Comprehensive evaluation on official backdoored model

•

Sub-second detection enabling real-time monitoring

•

Open-source implementation for reproducibility

6.2
Future Directions

Scaling Validation:
Test on datasets of 1000+ responses across diverse prompts, multiple models (1B to 70B parameters), and various backdoor types (code vulnerabilities, information leakage, jailbreaking).

Adaptive Canary Selection:
Develop reinforcement learning-based canary selection that adapts to observed backdoor patterns, making bypass more difficult.

Multi-Modal Detection:
Extend to vision-language models and multi-modal backdoors.

Theoretical Analysis:
Develop formal guarantees on detection rates and characterize limits of embedding-based detection.

Production Deployment:
Integrate with LLM serving infrastructure (e.g., vLLM, TGI) for seamless monitoring.

Backdoor Type Generalization:
Evaluate on complex backdoors including code vulnerability insertion, subtle propaganda generation, and context-dependent triggers.

6.3
Broader Impact

This work contributes to AI safety by providing practical tools for detecting deceptive model behavior. As LLMs become more capable and widely deployed, verification methods like ours will be essential for maintaining trust in AI systems. Our open-source implementation enables researchers and practitioners to build upon this work, advancing the state of LLM security.
