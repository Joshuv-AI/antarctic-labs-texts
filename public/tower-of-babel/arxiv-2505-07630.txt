On the frequency of small gaps between primes


Abstract
In a recent work Friedlander studied the problem of how large consecutive prime gaps should be in order that the sum of the reciprocals should be divergent. Supposing a very deep Hypothesis, a generalization of the Hardy–Littlewood prime k k -tuple conjecture, he gave an almost precise answer for it. In the present work we give an unconditional answer for a much weaker form of the same problem. † † The first author was supported by Grant #854813 by the Simons Foundation. John Friedlander investigated in his recent work entitled “When Euler met Brun”

[
Fri2024
]
that how small one can choose
\lambda(p)
in order that

(1.1)

\sum_{p^{\prime}-p\leq\lambda(p)\log p}\frac{1}{p}=\infty

should still hold, where
p^{\prime}
denotes the prime following
p
(
p
runs over all primes).

The title is motivated by the famous result of Euler [Eul1737, Theorem 7]

(1.2)

\sum_{p}\frac{1}{p}=\infty

and that of Brun
[
Bru1915
]
that restricting the summation for the twin primes the corresponding sum is already convergent.
Brun’s method immediately yields that for every fixed
K
one has also

(1.3)

\sum_{p^{\prime}-p\leq K}\frac{1}{p}<\infty.

In order to determine the threshold of the function
\lambda(p)
Friedlander introduces the function

(1.4)

\log_{k}x=\log\log_{k-1}x,\ \ \ \log_{1}x=\log x

and what he calls the logorial function

(1.5)

\text{\rm Log}_{k}x=\prod_{2\leq j\leq k}\log_{j}x.

Using the above notation he proved [Fri2024, (3.8)] without any condition that with

y(p)=\lambda(p)\log p

(1.6)

\sum_{\begin{subarray}{c}p\\
p^{\prime}-p\leq y(p)\end{subarray}}\frac{1}{p}<\infty\ \text{ if }\ \lambda(p)=1\!\bigm/\!(\text{\rm Log}_{k}p)(\log_{k}p)^{\varepsilon}

for any
\varepsilon>0
.
If he supposes the generalization of a uniform version of Hardy–Littlewood’s prime
k
-tuple conjecture (cf. Hypothesis G below), then using a theorem of Gallagher
[
Gal1976
]
(and a corollary of that by K. Soundararajanan [Sou2007, Exercise 1.3], see also Goldston and Ledoan’s work
[
GL2012/13
]
) Friedlander derives the conditional result

(1.7)

\sum_{\begin{subarray}{c}p\leq x\\
p^{\prime}-p\leq y(p)\end{subarray}}\frac{1}{p}\sim\log_{k+1}x\to\infty\ \text{ for }\ \lambda(p)=1\!\bigm/\!\text{\rm Log}_{k}p

for any
k\geq 2
.

In order to formulate the Hypothesis G, let
\mathcal{H}=\{h_{1},\ldots,h_{k}\}
denote a set of distinct non-negative integers and let
\nu_{\mathcal{H}}(p)
denote the number of residue classes modulo
p
occupied by the
h_{i}
.
We call
\mathcal{H}

admissible
if
\nu_{\mathcal{H}}(p)<p
for all primes
p
.
The singular series
\mathfrak{S}(\mathcal{H})
is defined by

(1.8)

\mathfrak{S}(\mathcal{H})=\prod_{p}\left(1-\frac{\nu_{\mathcal{H}}(p)}{p}\right)\left(1-\frac{1}{p}\right)^{-k}.

This is positive iff the
k
-tuple
\mathcal{H}
is admissible.

Hypothesis G.

Let
\pi(x,\mathcal{H})
denote the number of integers
n\leq x
such that
n+h_{j}
is prime for all
h_{j}\in\mathcal{H}
.
Then

(1.9)

\pi(x,\mathcal{H})\sim\mathfrak{S}(\mathcal{H})\frac{x}{(\log x)^{k}}\ \ \text{ as }\ x\to\infty

uniformly for all
h_{1},\ldots,h_{k}\leq\lambda\log x
, where
\lambda>0
is fixed.

Theorem
(Gallagher)
.

Let
P_{k}(h,x)
denote the number of integers
n\leq x
such that
(n,n+h]
contains exactly
k
primes.
Then, under Hypothesis G we have for
h=\lambda\log x
,
\lambda>0
fixed

(1.10)

P_{k}(h,x)\sim xe^{-\lambda}\frac{\lambda^{k}}{k!}\ \ \text{ as }\ x\to\infty.

Soundararajanan (and also Goldston and Ledoan) derived from this the following

Corollary.

Under Hypothesis G, for fixed
\lambda>0
we have

(1.11)

\frac{1}{\pi(x)}\#\left\{p\leq x;\frac{p^{\prime}-p}{\log p}\leq\lambda\right\}\sim\int\limits_{0}^{\lambda}e^{-t}dt=1-e^{-\lambda}.

Friedlander supposed in his work a generalization of the above Corollary when
\lambda(x)
is allowed to tend to zero, if this convergence is sufficiently slow.

Hypothesis S.

If
\lambda(u)\to 0
as
u\to\infty
, but

(1.12)

\lambda(u)\gg\frac{1}{(\log\log u)^{2}},

then (
1.11
) remains valid with
\lambda(x)
instea of
\lambda
.

He also notes that for
\lambda\to 0
we have
1-e^{-\lambda}\sim\lambda
.
The unconditional result (
1.6
) and the conditional (
1.7
)
(see (3.8)–(3.9) of
[
Fri2024
]
) nearly exactly determine under Hypothesis H the threshold function
\lambda(p)
, therefore
y(p)
, for which the sum

(1.13)

\sum_{\begin{subarray}{c}p\\
p^{\prime}-p\leq y(p)\end{subarray}}\frac{1}{p}

is convergent, or divergent, respectively.

As quoted in
[
Fri2024
]
, an unconditional lower bound for the number of prime gaps smaller than
\lambda(p)\log p
was proved in
[
GPY2013
]
when
\lambda(p)=\lambda>0
is an arbitrary fixed constant.
Theorem 1 of
[
GPY2013
]
showed

(1.14)

\#\{p\leq x;p^{\prime}-p\leq\lambda\log p\}\gg_{\lambda}\pi(x)

which shows that a positive proportion of prime gaps is smaller than
\lambda\log p
for any fixed
\lambda>0
.
On the other hand it was also proved in [GPY2013, Theorem 3] that Selberg’s upper bound sieve coupled with Gallagher’s theorem
[
Gal1976
]

(1.15)

\sum_{\begin{subarray}{c}\mathcal{H}\subset[1,h]\\
|\mathcal{H}|=k\end{subarray}}\mathfrak{S}(\mathcal{H})\sim h^{k}\ \ \text{ for fixed }\ k\ \text{ as }\ h\to\infty,

together yield for any

(1.16)

\#\{p\leq x,p^{\prime}-p\leq h\}\ll\min\left(\frac{h}{\log x},1\right)\pi(x).

In particular, if

(1.17)

\#\{p\leq x;p^{\prime}-p\leq h\}=o(\pi(x)).

The goal of our present work is to extend (
1.14
) for the case of
\frac{c}{\log p}\leq\lambda(p)\ll 1
with an unconditional explicit lower bound on the RHS of (
1.14
) in dependence of the function
\lambda(p)
.
Theorem 2 of
[
GPY2013
]
contained already such an explicit estimate for
\lambda>0
fixed but the lower bound

(1.18)

\exp(-c\lambda^{-6})\pi(x)

was rather weak.

In the present work we will show the following

Theorem 1
.

If
N
is sufficiently large, that is
N>C_{1}
(explicitly calculable),

\eta=\eta(N)>C_{0}/\log N
(

explicitly computable positive constant), then

(1.19)

\sum_{\begin{subarray}{c}p\sim N\\
p^{\prime}-p\leq\eta\log N\end{subarray}}1>c_{0}\eta^{1879}\pi(N)

with an explicitly calculable

, where

means
N\leq n<2N
.

This result gives an improved generalization of the result (

) of
[
GPY2013
]
about the positive proportion of small gaps between primes (where small means of size
\leq\varepsilon\log p
for a given fixed

) and Zhang’s result
[
Zha2014
]
about the existence of infinitely many bounded gaps between primes.
(

) is namely valid for all gap sizes between
C_{0}
and
c^{\prime}(\log N)
.

Using the notation (

.

Let

.
Then we have for any

\sum_{\begin{subarray}{c}p\\
p^{\prime}-p\leq\lambda(p)\log p\end{subarray}}\frac{1}{p}=\infty\ \ \text{ if }\ \lambda(p)\geq\frac{c^{\prime}}{(\text{\rm Log}_{m}p)^{1/1879}}.

For a

2
Main ideas of the proof. Notation

In this section we outline the main ideas of the proof and introduce the notation used.
Our present work will be based on ideas and results of the two earlier works
[
Pin2010
]
and
[
GPY2013
]
, but the notation will just in part follow theirs.
Concerning the improvement the most crucial tool will be Zhang’s result
[
Zha2014
]
in the improved form by the Polymath 8 project
[
Pol2014a
]
about equidistribution of primes in arithmetic progressions which led to the proof of the existence of infinitely many bounded gaps between primes by Zhang
[
Zha2014
]
.

The starting point was to use a form of Selberg’s upper bound sieve to detect primes in “admissible”
k
-tuples
\mathcal{H}=\{h_{1},h_{2},\ldots,h_{k}\}
, more exactly in the sequence

where

runs through integers in an interval of type
[N,2N)
with a sufficiently large integer
N
, which will be abbreviated by
n\sim N
.
In several applications of the method the parameter

was chosen bounded as
N\to\infty
.
A hopeless final goal could be (at least some good approximation) of Hardy–Littlewood’s prime
k
-tuple conjecture, i.e., (
1.9
) for bounded
h_{k}
.

The tool, investigated in several works of Goldston and

[

]
,
[
GY2007a
]

[
GY2007b
]

(2.1)

\Lambda_{R}(n;\mathcal{H},k):=\sum_{\begin{subarray}{c}d\\
d\mid P_{\mathcal{H}}(n)\end{subarray}}\mu(d)\log^{k}\frac{R}{d},

where

(2.2)

P_{\mathcal{H}}(n):=\prod_{i=1}^{k}(n+h_{i}),\ \ \ R\leq N^{1/2}\mathcal{L}^{-c},\ \ \mathcal{L}=\log N.

This first attempt (in an unpublished manuscript) already improved the 15-year-old record of Helmut Maier
[
Mai1988
]
about

\Delta=\liminf_{n\to\infty}\frac{p_{n+1}-p_{n}}{\log p_{n}}\leq 0.2484\ldots,

but failed to prove

, that is, the existence of an infinite gap sequence of order

(which we will call informally

It was a little later when Goldston, Pintz and Yıldırım
[

]
used instead of (

) a

\Lambda_{R}(n;\mathcal{H},k+\ell)=\sum_{\begin{subarray}{c}d\\
d\mid P_{\mathcal{H}}(n)\end{subarray}}\mu(d)\log^{k+\ell}\frac{R}{d}

for the original

-dimensional problem which led to

\Delta=0.

We remark here that in order to reach
\Delta=0
one needed to choose

,

, but in order to show

,

(and

Using the very usual smooth weights

(2.6)

\theta(m)=\begin{cases}\log p&\text{ if }m=p\text{ is prime,}\\
0&\text{ otherwise,}\end{cases}

we investigate in the present work the two crucial sums
(similarly to
[

]
,
[

]
,

]
,

and

(2.8)

Here, similarly to
[

]
and

]
, and somewhat similarly to

,

On the other hand, similarly to

]

]

]
, but in contrast to

\mathfrak{S}(\mathcal{H}\cup h^{*})=0
the RHS is
o\bigl(N(\log R)^{k+2\ell+\kappa}\bigr)
.

4
Proof of Theorem 1

Let us denote

(4.1)

Q(N,h):=\sum_{\begin{subarray}{c}n\sim N\\
\pi(n+h)-\pi(n)>1\end{subarray}}\!\!\!1,\hskip 20.00003pt\Theta(n,h):=\sum_{h^{*}=1}^{h}\theta(n+h^{*}).

If
n
is counted by the sum, then we have a prime
p_{j}
with
n<p_{j}<p_{j+1}\leq n+h
.
Thus
p_{j+1}-p_{j}<h
and
p_{j+1}-h\leq n<p_{j}
so that to every such gap we have at most
\lfloor h\rfloor
such integers
n
.
Therefore we obtain from the PNT with error term used at the ends of such gaps:

(4.2)

Q(N,h)\leq h\sum_{\begin{subarray}{c}N<p_{j}\leq 2N\\
p_{j+1}-p_{j}\leq h\end{subarray}}1+O\bigl(Ne^{-c\sqrt{\log N}}\bigr).

We will investigate the quantity

(4.3)

S_{2}(h,\delta):=\frac{1}{Nh^{k}(\log R)^{k+2\ell}}\sum_{n\sim N}(\Theta(n,h)-\log 3N)\Bigl({\sum_{\mathcal{H}}}^{*}\Lambda_{R}^{2}(n,\mathcal{H},k+\ell)\Bigr)

where

(4.4)

{\sum_{\mathcal{H}}}^{*}:=\sum_{\begin{subarray}{c}\mathcal{H}\subseteq[1,h],|\mathcal{H}|=k\\
\mathcal{H}\text{ admissible}\\
(P_{\mathcal{H}}(n),P(R^{\delta}))=1\end{subarray}}.

From Lemmas 5, 6 and (
1.15
) we obtain a lower bound for
S_{2}(h,\delta)
counting
in (
3.7
) only the cases
h^{*}\in\mathcal{H}
:

(4.5)

\displaystyle S_{2}(h,\delta)

\displaystyle\geq\frac{(1+O(\delta))h^{k}}{Nh^{k}(\log R)^{k+2\ell}}\cdot\frac{N(\log R)^{k+2\ell+1}k}{(k+2\ell+1)!}{2(\ell+1)\choose\ell+1}

\displaystyle\hskip 10.00002pt-\frac{(1+O(\delta))h^{k}}{Nh^{k}(\log R)^{k+2\ell}}\cdot\frac{N(\log R)^{k+2\ell}\log N}{(k+2\ell)!}{2\ell\choose\ell}

\displaystyle=\frac{1+O(\delta)}{(k+2\ell)!}{2\ell\choose\ell}\left(\frac{k}{k+2\ell+1}\cdot\frac{2(2\ell+1)}{\ell+1}\log R-\log N\right).

This implies with the choice
R=N^{(\vartheta-\varepsilon)/(2+\delta)}

(4.6)

S_{2}(h,\delta)\gg_{k,\ell,\delta}\biggl(4\left(1-\frac{2\ell+1}{k+2\ell+1}\right)\left(1-\frac{1}{2\ell+2}\right)\frac{\vartheta-\varepsilon}{2+\delta}-1+O(\delta)\biggr)\mathcal{L}.

It is easy to check that with the choices

(4.7)

k=1880,\ \ \ell=21,\ \ \vartheta=\frac{157}{300}

we obtain

(4.8)

S_{2}(h,\delta)\gg_{k,\ell,\delta,\varepsilon}\mathcal{L}

if we choose additionally
\delta
and
\varepsilon
sufficiently small.

On the other hand we can prove an upper bound for
S_{2}(h,\delta)
as a function of
h,N,R,Q(N,h),k
and by using Lemmas 5 and 6 and Selberg’s upper bound sieve, which, combined with the lower bound (
4.6
), will yield a lower bound for
Q(N,h)
.
We have, namely

(4.9)

\displaystyle S_{2}(h,\delta)

\displaystyle\leq\frac{1}{Nh^{k}(\log R)^{k+2\ell}}\sum_{\begin{subarray}{c}n\sim N\\
\Theta(n,h)\geq(3/2)\log N\end{subarray}}\Theta(n,h){\sum_{\mathcal{H}}}^{*}\Lambda_{R}^{2}(n;\mathcal{H},k+\ell)

\displaystyle\leq\frac{1}{Nh^{k}(\log R)^{k+2\ell}}\biggl(\sum_{\begin{subarray}{c}n\sim N\\
\Theta(n,h)\geq(3/2)\log N\end{subarray}}\!\!\!\!1\biggr)^{\!\!1/2}\left\{\sum_{n\sim N}\Theta^{2}(n,h)\biggl({\sum_{\mathcal{H}}}^{*}\!\!\Lambda_{R}^{2}(n;\mathcal{H},k\!+\!\ell)\!\biggr)^{\!2}\right\}^{\!\!1/2}

\displaystyle:=\frac{(Q(N,h))^{1/2}}{Nh^{k}(\log R)^{k+2\ell}}I^{1/2}

where

(4.10)

I=\!\!\!\sum_{1\leq h^{\prime},h^{\prime\prime}\leq h}\sum_{\begin{subarray}{c}\mathcal{H}\subseteq[1,h],\mathcal{H}=k\\
\mathcal{H}_{i}\text{ admissible}\\
i=1,2\end{subarray}}\sum_{\begin{subarray}{c}n\sim N\\
\bigl(\!P_{\mathcal{H}_{1}\cup\mathcal{H}_{2}}(n),P(R^{\delta})\!\bigr)=1\end{subarray}}\!\!\!\!\!\!\!\!\!\!\!\!\!\theta(n+h^{\prime})\theta(n+h^{\prime\prime})\Lambda_{R}^{2}(n;\mathcal{H}_{1},\ell)\Lambda_{R}^{2}(n;\mathcal{H}_{2},\ell).

The first important observation is that we have for any
\mathcal{H}
in the above sum

(4.11)

\Lambda_{R}(n;\mathcal{H},k+\ell)\ll_{k,\ell,\delta}(\log R)^{k+\ell},

since all prime divisors of
P(\mathcal{H}_{i},n)
are at least
R^{\delta}
and
R\geq N^{c_{1}}
, due to the notation
{\sum\limits_{\mathcal{H}}}^{*}
in (
4.4
).
This implies with the notation
\mathcal{H}_{0}=\{h^{\prime}\}\cup\{h^{\prime\prime}\}\cup\mathcal{H}_{1}\cup\mathcal{H}_{2}

(4.12)

I\ll_{k,\ell,\delta}\mathcal{L}^{2}(\log R)^{4(k+\ell)}\sum_{1\leq h^{\prime},h^{\prime\prime}\leq h}\sum_{\begin{subarray}{c}\mathcal{H}_{i}\subseteq[1,h]|\mathcal{H}_{i}|=k\\
\mathcal{H}_{i}\text{ admissible}\\
i=1,2\end{subarray}}\sum_{\begin{subarray}{c}n\sim N\\
\bigl(P_{\mathcal{H}_{0}}(n),P(R^{\delta})\bigr)=1\end{subarray}}1.

For a given
\mathcal{H}_{0}\subseteq\{1,\ldots,h\}
we have
|\mathcal{H}_{0}|=k+r
,
0\leq r\leq k+2
and the total number
D(h,r)
of quadruples
h^{\prime},h^{\prime\prime},\mathcal{H}_{1},\mathcal{H}_{2}
corresponding to
\mathcal{H}_{0}
is
O_{k,r}(1)=O_{k}(1)
, so

(4.13)

I\ll_{k,\ell,\delta}\mathcal{L}^{2}(\log R)^{4(k+\ell)}\sum_{r=0}^{k+2}\sum_{|\mathcal{H}_{0}|=k+r}\sum_{\begin{subarray}{c}n\sim N\\
\bigl(P_{\mathcal{H}_{0}}(n)P(R^{\delta})\bigr)=1\end{subarray}}1.

For any given
\mathcal{H}_{0}
we can apply Selberg’s upper bound sieve (Theorem 5.1 of
[
HR1974
]
) to obtain

(4.14)

\sum_{\begin{subarray}{c}n\sim N\\
(P_{\mathcal{H}}(n),P(R^{\delta}))=1\end{subarray}}1\leq\frac{(1+o(1))N|\mathcal{H}|!\mathfrak{S}(\mathcal{H})}{(\log R^{\delta})^{|\mathcal{H}|}}.

For a given
r
summation over all
\mathcal{H}_{0}
with
|\mathcal{H}_{0}|=k+r
this gives by (
1.15
)

(4.15)

\displaystyle\sum_{\begin{subarray}{c}n\sim N,|\mathcal{H}_{0}|=k+r\\
\bigl(P_{\mathcal{H}_{0}}(n),P(R^{\delta})\bigr)=1\end{subarray}}\!\!\!1

\displaystyle\leq\sum_{|\mathcal{H}_{0}|=k+r}\frac{(1+o(1))(k+r)!\mathfrak{S}(\mathcal{H}_{0})}{(\delta\log R)^{k+r}}N

\displaystyle\ll_{k,\delta}\sum_{|\mathcal{H}_{0}|=k+r}\frac{\mathfrak{S}(\mathcal{H}_{0})}{(\log R)^{k+r}}N

\displaystyle\ll\sum_{r=0}^{k+2}\left(\frac{h}{\log R}\right)^{k+r}\ll\left(\frac{h}{\log R}\right)^{k}N,

due to
h\ll\log N\ll\log R
.
Hence, by (
4.13
)–(
4.15
) we have

(4.16)

I^{1/2}\ll_{k,\ell,\delta}\mathcal{L}h^{k/2}(\log R)^{3k/2+2\ell}N^{1/2}.

Together with (
4.6
) and (
4.9
) this implies

(4.17)

\mathcal{L}\ll_{k,\ell,\delta}S_{2}(h,\delta)\ll_{k,\ell,\delta}\mathcal{L}Q(N,h)^{1/2}\left(\frac{\log R}{h}\right)^{k/2}N^{-1/2},

consequently, by (
4.2
),

(4.18)

h\sum_{\begin{subarray}{c}N<p_{j}\leq 2N\\
p_{j+1}-p_{j}\leq h\end{subarray}}\!\!\!1\gg_{k,\ell,\delta}N\left(\frac{h}{\log R}\right)^{k}+O\bigl(Ne^{-c\sqrt{\mathcal{L}}}\bigr).

From this we obtain by
h/\log R\geq h/\log N\geq 1/\mathcal{L}

(4.19)

\hskip 20.00003pt\hskip 20.00003pt\sum_{\begin{subarray}{c}N<p_{j}\leq 2N\\
p_{j+1}-p_{j}\leq h\end{subarray}}1\gg_{k,\ell,\delta}\frac{\eta^{k}N}{h}=\eta^{k-1}\frac{N}{\mathcal{L}}\sim\eta^{k-1}\pi(N).\hskip 20.00003pt\hskip 20.00003pt\square
