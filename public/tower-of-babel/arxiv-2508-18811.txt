Quantum computing on encrypted data with arbitrary rotation gates Preprint: APS/123-QED
Mohit Joshi, Manoj Kumar Mishra, S. Karthikeyan

Abstract
An efficient technique of computing on encrypted data allows a client with limited capability to perform complex operations on a remote fault-tolerant server without leaking anything about the input or output. Quantum computing provides information-theoretic security to solve such a problem, and many such techniques have been proposed under the premises of half-blind quantum computation. However, they are dependent on a fixed non-parametric resource set that comprises some universal combination of H , S , T , C ​ X , C ​ Z H,S,T,CX,CZ or C ​ C ​ X CCX gates. In this study, we show that recursive decryption of the parametric gate, R z ​ ( θ ) R_{z}(\theta) , is possible exactly when θ = ± π / 2 m \theta=\pm\pi/2^{m} for m ∈ ℤ + m\in\mathbb{Z^{+}} , and approximately with arbitrary precision ϵ \epsilon for given θ \theta . We also show that a blind algorithm based on such a technique needs at most O ⁡ ( log 2 2 ⁡ ( π / ϵ ) ) O(\log_{2}^{2}(\pi/\epsilon)) computation steps and communication rounds, while the techniques based on a non-parametric resource set require O ⁡ ( ln 3.97 ⁡ ( 1 / ϵ ) ) O(\ln^{3.97}(1/\epsilon)) rounds. We use these results to propose a universal scheme of half-blind quantum computation for computing on encrypted data using arbitrary rotation gates. This substantial reduction in the depth of blind circuit is an affirmative step towards the practical application of such techniques in secure NISQ-era computing.

Introduction

In recent years, the presence of quantum platforms has increased under the cloud infrastructure from big providers like IBM, D-Wave, Rigetti, and Microsoft, providing quantum-as-a-service

With the anticipated interference of quantum internet, the fundamental limits of networking will change, giving birth to private and secure applications unachievable in the classical internet

The ability to securely delegate complex quantum operations by a limited-capability client on such infrastructure will lay the foundation of this secure distributed networking architecture.
Childs proposed a paradigm of privacy capable of providing information-theoretic security to the client’s input and output using Pauli’s
X

The general form of the Child’s blindness process can be represented as:

\displaystyle 2^{n}I=\sum_{j_{1},j_{2},...,j_{2n}\in\{0,1\}}\bigg(\bigotimes_{i=1}^{n}Z_{i}^{j_{2i}}X_{i}^{j_{2i-1}}\bigg)|\psi\rangle

\displaystyle\langle\psi|\bigg(\bigotimes_{i=1}^{n}X_{i}^{j_{2i-1}}Z_{i}^{j_{2i}}\bigg),

X

\ket{\psi}

The computation performed over some universal resource set using Child’s encrypted data provides security to the computation along with data, which is referred to as full-blind quantum computation (FBQC).
Broadbent et al. proposed the first universal resource state, the brickwork state, based on the measurement-based quantum computation for universal blind quantum computation
broadbent2009universal
.
Since then, many variants of universal blind quantum computation based on different models of quantum computation have been proposed.
Morimae et al. proposed two universal resource states, Raussendorf-Harrington-Goyal (RHG) state in 2012

, and Affleck-Kennedy-Lieb-Tasaki (AKLT) state in 2015
morimae2015ground

Sueki et al. proposed another approach based on an ancilla-driven model

However, these schemes are based on computationally heavy entangled graph states.
Ma et al. improved upon the structure of brickwork state by using the flexibility in one and two-qubit operations

Zhang et al. proposed a hybrid approach based on single-qubit gates performed on a circuit-based model and two-qubit gates being performed on measurement-based computing

Zhang et al. also proposed a circuit-based approach using

Liu et al. proposed a naive approach based on decryption of the ordered set of non-parametric
(H,S,CX,CZ,CCX)

Sano et al. proposed a technique using T-like gates in 2020

These developments have sparked many practical applications of blind quantum computation

In the Noisy-Intermediate-Scale Quantum (NISQ) device era, the partial security, that is, the security of only data, can be seen to have immense prospects for quantum computing on encrypted data. This type of security is called half-blind quantum computation (HBQC).
Fisher et al. in 2014 proposed the use of this technique for computing over encrypted data using the non-parametric universal resource set of
\{H,S,CX,T\}

. Tan and Zhou proposed another technique of universal half-blind quantum computation based on another resource set of
\{H,S,CX,CZ,CCX\}

Previous approaches to blind quantum computation are based on the assumption of non-parametric server resources.
This required the circuit to be decomposed to non-parametric gate sets like
\{H,S,T,CX,CZ,CCX\}
before decryption using decomposition techniques like Solovay-Kitaev decomposition

This non-parametric set of resource decomposition especially becomes a roadblock for practical variational circuit approaches like blind quantum machine learning, which are inherently based on parametric circuits

;
shingu2022variational
;
li2024blind

Moreover, in the NISQ era, parametric gates like

gates can be natively implemented in the hardware

;

Hence, the direct decryption of an arbitrary
R_{z}(\theta)

However, the question arises whether an efficient decryption technique for arbitrary
R_{z}(\theta)

In this study, we show that arbitrary
R_{z}(\theta)
can be recursively decrypted, and moving towards such a parameterized rotation resource set is an efficient approach, which makes the prospects of performing computation on encrypted data lucrative, especially for hybrid quantum-classical algorithms.

Based on the presented decryption technique of

\displaystyle R_{z}(\theta)

\displaystyle=D\cdot R_{z}(\theta)Z^{b}X^{a},

\displaystyle D^{\dagger}

\displaystyle=R_{z}(\theta)Z^{b}X^{a}R_{z}^{\dagger}(\theta),

\displaystyle D

\displaystyle=R_{z}(\theta)X^{a}Z^{b}R_{z}(-\theta).

Note that

Also,

\displaystyle D

\displaystyle=\begin{pmatrix}1-1_{a}&1_{a}e^{-i\theta}\\
