Equilibria and Learning in Modular Marketplaces
Kshipra Bhawalkar, Jeff Dean, Christopher Liaw, Aranyak Mehta, Neel Patel

Abstract
We envision a marketplace where diverse entities offer specialized “modules” through APIs, allowing users to compose the outputs of these modules for complex tasks within a given budget. This paper studies the market design problem in such an ecosystem, where module owners strategically set prices for their APIs (to maximize their profit) and a central platform orchestrates the aggregation of module outputs at query-time. One can also think about this as a first-price procurement auction with budgets. The first observation is that if the platform’s algorithm is to find the optimal set of modules then this could result in a poor outcome, in the sense that there are price equilibria which provide arbitrarily low value for the user. We show that under a suitable version of the “bang-per-buck” algorithm for the knapsack problem, an ε \varepsilon -approximate equilibrium always exists, for any arbitrary ε > 0 \varepsilon>0 . Further, our first main result shows that with this algorithm any such equilibrium provides a constant approximation to the optimal value that the buyer could get under various constraints including (i) a budget constraint and (ii) a budget and a matroid constraint. Finally, we demonstrate that these efficient equilibria can be learned through decentralized price adjustments by module owners using no-regret learning algorithms.

Introduction

Our work is inspired by a marketplace model where sellers may participate to provide some product or service for a fee and a budget-constrained buyer whose goal is to purchase from some subset of sellers to maximize some objective function. Our primary motivation is in a computing ecosystem where the sellers may be offering specialized “modules” which are accessed through Application Programming Interfaces (API). The sellers would offer a price which must be paid every time a buyer issues an API call to their module. These modules may be specialized for particular tasks and may be built with proprietary data or with proprietary techniques.

We define and study the market design problem inherent in building such an ecosystem. We consider the following setup:

(a)

Module owners provide their module API at a price per API call.

(b)

Users submit requests and a budget to a central platform.

(c)

The platform calls a feasible subset of available APIs, respecting the budget constraint.

(d)

The platform aggregates the results which is provided back to the user.

One particular example of such an ecosystem stems from the recent development of large language models (LLMs). While there may be a few flagship models that boast multiple generic capabilities, we are also witnessing a rise in specialized LLMs tailored for specific domains such as code generation (e.g.,

). In such an ecosystem, one can imagine that a user first enters a prompt into the generic LLM along with a budget constraint. Next, the generic LLM produces an answer by combining results from a subset of the available modules that respects the budget constraint.
Another example that fits into our marketplace model are labor markets such as Upwork
[
36
]
. In such a market, the platform may allow workers to post hourly wages and then buyers need to assemble teams based on the workers’ skills and a total budget.

The marketplace problem in this paper can also be thought of as a procurement auction. More specifically, the mechanism we consider in this paper is some type of a first-price auction. The vast majority of the literature on procurement auctions focuses on designing mechanisms that are truthful

1.1
Model and Results

In this model, API prices are set by the module owners. These prices depend on various factors.
First, module owners incur costs for module production and maintenance, including data licensing, partnerships, engineering, and compute. The module owner thus might have a private cost
c
per API call that it wishes to recoup. The module owner can post a price
p
per API call with the goal of optimizing its profit of
p-c
, whenever the API is called.

Depending on a particular request, the different modules may be complementary or substitutable. Going back to the modular LLM example in the introduction, it might be that the user issued a prompt to understand treatment options for some condition. A medical module may be used to help diagnose the patient while a legal module may be useful to clarify insurance policies. However, multiple medical or legal modules may provide limited value and thus are substitutable. We assume a value function that captures the value from any subset of modules. We also assume a budget
B
on the total that can be spent on any request. The goal is to pick a subset of modules to optimize the value subject to the budget constraint.

The value function and the budget create competition between the module owners and the module owners must strategically set their prices to maximize their profit while ensuring that they are selected. Our results concern the equilibria of this price setting game, where module owners facing repeated queries from the users do not wish to deviate from the API price they have set.

We would like to understand the existence, potential inefficiency, and learnability of such equilibria.
Our benchmark for inefficiency is
OPT
, which is the value obtained by the optimal allocation when each module owner sets their price equal to their cost
c
.
Our first, fairly trivial, result shows that the most natural selection rule fails miserably.

Result 1
.

If, given a set of prices, the platform always selects the optimal set of modules subject to the budget constraint then there is an equilibrium where all modules set prices equal to the budget and the user can obtain only one module.

To see this, imagine that there are
n
modules who all have cost
0
and our budget is
1
.
Module
1
has value
1+\varepsilon
while all other modules have value
1
.
The optimal value is
n+\varepsilon
but if all modules set a price of
1
then we only obtain module
1
for a value of
1+\varepsilon
.
Moreover, no module can deviate by itself to get selected so this is, in fact, an equilibrium.

At this point, the most pressing question is whether or not there even exists an allocation rule which guarantees that all equilibria are efficient.
A second question is whether or not the allocation can be computed efficiently.
Our main result is that there is an efficient algorithm, based on a natural greedy algorithm, that guarantees that all equilibria are approximately optimal.
This result holds for a large set of value functions generalizing additive values, as described next.

Generalized Additive Valuations

We assume that the value for a set of modules is additive over the set of selected modules.
Further, we also assume that there is a matroid constraint that specifies which subset of modules is feasible to select; this captures substitutability between modules.
Matroid feasibility constraints capture many diverse settings.
For instance, a linear matroid models scenarios where a set of modules
S_{1}
“covers” the content of another set
S_{2}

(e.g.,
S_{2}
is linearly dependent on
S_{1}
), rendering
S_{2}
redundant. A partition matroid, a special case, divides modules by expertise, allowing only one module per partition (e.g., medical or legal modules).

We consider the natural “bang-per-buck” algorithm,
\mathcal{A}_{BPB}
, which works as follows.
We first sort the modules from highest to lowest bang-per-buck (i.e.
\frac{\mathbf{v}(i)}{\mathbf{p}(i)}
).
Then we select modules in this order while maintaining both budget and matroid feasibility.
The stopping rule of this algorithm is the
first
time that the budget constraint is violated.
We give a precise definition of this algorithm can be found in Algorithm
1
.

Our first main result, stated informally here, is that for such a selection rule, equilibria exist.

Result 2
.

When the platform implements
\mathcal{A}_{BPB}
, equilibria exists where no seller can profitably deviate.

We note that our formal results prove the existence of “
\varepsilon
-equilibria” where no module can gain more than
\varepsilon
utility by deviating.
This is mainly to deal with tie-breaking and we can make
\varepsilon
arbitrarily small.
The formal results are stated in Theorem
4.1
(for only a budget constraint), Theorem
D.5
(for uniform values with matroid and budget constraints), and Theorem
5.2
(for general additive values with matroid and budget constraints).

Our second main result is that all equilibria are efficient.

Result 3
.

Suppose that the platform implements
\mathcal{A}_{BPB}
for module selection and that the cost of any module is at most
\lambda B
for some
\lambda<1
(that is, it is small relative to the budget).
Let
\OPT
be the maximum value achievable when the costs are
known
.
Then any equilibrium yields a value of at least:

•

\frac{(1-\lambda)^{2}}{2-\lambda}\cdot\OPT
when there is only a budget constraint (Theorem
4.5
);

•

\frac{(1-\lambda)^{2}}{2-\lambda}\cdot\OPT
when there is a matroid and a budget constraint but the values are uniform across all modules (Theorem
D.10
); and

•

\frac{(1-3\lambda)^{2}}{2-3\lambda}\cdot\OPT
when there is a matroid and a budget constraint. For this result, we also require
\lambda<1/3
(Theorem
5.3
).

Note that all bounds approach
\frac{1}{2}
as
\lambda\to 0
.

Note that the last approximation result stated above is a simplified but slightly worse version of the result in Theorem
5.3
.
Result
3
only shows that all equilibria are good.
However, it does not show how the market can achieve such any equilibrium.
Indeed, equilibrium prices are a complex function of all the parameters of the market, including the set of modules
M
, their private costs
\mathbf{c}
, the value function
\mathbf{v}
and the underlying constraint over the modules. It is impossible for market participants to compute an equilibrium with no prior knowledge of the parameters. However, one may expect module owners to employ algorithmic techniques to adjust prices through reasonable learning algorithms, especially if they anticipate long-term participation.
Such a learning algorithm would respond to the feedback obtained in past rounds at various price levels without knowledge of the other market participants or even the value function of the platform.

Our next result proves convergence guarantees if all modules use
multiplicative weight update
type no-regret learning algorithms.

Result 4
.

For any
\varepsilon>0
, if the platform implements
\mathcal{A}_{BPB}
for module selection and each module, unaware of market parameters, employs a multiplicative weight update-style price learning algorithm, then the price dynamics converges to an
\varepsilon
-equilibrium price with high probability under any arbitrary matroid constraint over the modules. Consequently as
\varepsilon\rightarrow 0
, the total expected value for a query for the platform is at least
\frac{(1-3\lambda)^{2}}{2-3\lambda}\cdot\OPT
, with high probability.

We note that our convergence results assumes that every round is identical in that the buyer’s valuation function does not change over each round. If there are multiple “types” of buyers, one can imagine that the type of the buyer is used as context for the learning agents. In such a setting, the problem reduces to the single buyer valuation setup in this paper.

Related Work

Procurement Auctions.

Our work fits into the literature of procurement auctions. There is a large body of work on designing procurement auctions subject to a budget constraint that was initiated by
Singer [31]
.
These procurement auctions can either be done via sealed-bid auctions
[
31
,
4
]
or descending clock auctions
[
3
,
13
,
7
,
18
]
.

When the buyer’s objective function is submodular,
Balkanski et al. [3]
designed deterministic clock auctions with an approximation ratio of 4.5, improving upon the approximation ratio of both deterministic and randomized mechanisms from a series of works including
[
4
,
17
]
. For the special case of submodular functions,
Leonardi et al. [20]
designed a
4
-approximation mechanism for unweighted matroid value functions, and
Gravin et al. [11]
designed an optimal
(1+\sqrt{2})
-approximate mechanism for additive valuations. In addition, a series of works
[
1
,
29
]
designed mechanisms with a small seller assumption
(\lambda\rightarrow 0)
and obtained an optimal
(1-1/e)
-approximation for additive valuations and a
1/2
-approximation for monotone submodular valuations. Our result on matroid value functions matches the current best-known bound under the small seller assumption.
1
1

1

In addition, we ensure that all potential price equilibria are
1/2
-approximate.

In this paper, our goal is to formally understand the marketplace model where module owners simply post a public price for their API call. This is a model that is currently being employed in the industry (e.g.
[
34
,
10
]
) due to its simplicity. Equivalently, our model is a first-price procurement auction with a budget constraint. In such a marketplaces, since the payment is decided by the sellers, the mechanism needs to ensure that all potential equilibria prices lead to efficient outcomes which is not necessarily satisfied by existing mechanisms.

Such a marketplace setting was formally studied by
Milgrom and Segal [25]
in their beautiful work which proposed a clean characterization of descending clock auctions.

Milgrom and Segal [25]
prove that the outcome of a descending clock auction can be converted to a first-price auction.
Moreover, the outcome of the descending clock auction corresponds to equilibrium bids in the first-price auction.
However, the allocation rule in the first-price auction is somewhat complex as it is defined by “simulating” a clock auction. A larger issue is that the conversion they describe may result in additional equilibria unless the allocation satisfies a “non-bossy” assumption
[
25
, Appendix E]
. This assumption requires that a bidder cannot change the allocation of any other bidder without changing their own allocation. This is a non-trivial assumption to satisfy. For example, the allocation in
[
3
]
, which achieves the best approximation ratio for procurement auctions, does not satisfy the non-bossy assumption. If the allocation rule does not satisfy the non-bossy condition then the additional equilibria may have poor efficiency. In fact, it is not difficult to observe that their allocation rule leads to an equilibria that obtains
O(1/n)
fraction of optimal value for the same example for which the optimal selection rule leads to inefficient outcome. Thus a contribution of our work can also be seen as designing allocation rules where all equilibria in a first-price auction are approximately efficient.

In another previous work,
Immorlica et al. [16]
study a first-price auction in a procurement auction setting, without a budget constraint.
They study path auctions where the agents correspond to edges and the constraint is a set of edges between a source and a sink with a specified flow capacity. This makes it a covering problem whereas we consider a packing problem.
In addition, the goal of the paper is to minimize the buyer’s cost while our goal is to maximize the buyer’s value.

Having a marketplace model also has practical implications in that it obviates the need for complex auction infrastructure such as second-price auctions or clock auctions.
While truthful reporting is no longer optimal, our results show that if the module owners simply implement some reasonable learning algorithm, they are guaranteed to converge to an equilibrium.
This essentially allows module owners to use learning algorithms to adjust their prices based on demand feedback.

Pricing and Bidding Dynamics.

One of the goals of this paper is to understand pricing dynamics in markets.
For Arrow-Debreu markets
[
23
,
2
]
, there is a large literature on understanding the dynamics that lead to equilibria (see for example,
[
27
,
5
]
and references therein).
However, the models studied in these papers assume that the goods are a finite resource and are divisible. In our setting, the goods are digital and are indivisible.
Furthermore, these papers assume that agents do not directly control prices, which are set in a centralized manner based on aggregate supply and demand. In contrast, our model allows agents to directly change their prices based on the response from the market.

Our work also fits into a growing literature of understanding bidding dynamics in auctions
[
8
,
6
,
19
]
.
These papers assume that bidders use some sort of no-regret or mean-based learning algorithm.

Feng et al. [8]
,
Deng et al. [6]
,
Kolumbus and Nisan [19]
aim to understand the convergence properties of these dynamics.
Kolumbus and Nisan [19]
also study the incentive properties of different auctions when an agent uses no-regret learning algorithms.
Our paper also assumes that agents use no-regret learning algorithms to adjust their prices.
However, a key difference is that, to the best of our knowledge, our work is the first to study no-regret dynamics in a procurement setting.

Our convergence result falls within the ”learning in games” literature
[
14
,
9
,
15
]
, which considers the setting where players have no information about game parameters and interact with the platform over multiple iterations, using an online learning algorithm to select actions from a finite set. Crucially, here the game does not change over the interactions. Our convergence result is interesting because
[
9
]
showed that if players implement a ”follow the regularized leader” type learning algorithm (which includes multiplicative weight update), then the dynamics converge to a strict-pure Nash equilibrium. However, in our setting, strict pure Nash equilibria do not exist. Instead, the ”stability” properties of our allocation rule and equilibrium prices ensure that the learning sellers converge to a pure equilibrium price.

Price Competition Game

Throughout this paper, we use buyer interchangeably with the platform and a seller interchangeably with a module owner.
An instance of the price competition game is defined by
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle
where
M=\{m_{1},\dots,m_{k}\}
are the set of modules,
\mathbf{v}(i)\in\mathbb{R}_{+}\cup\{0\}
is the value of module
m_{i}
for the buyer,
\mathbf{c}(i)\in\mathbb{R}_{+}\cup\{0\}
is the cost of module
m_{i}
,
\mathcal{I}\subseteq 2^{M}
is the set of feasible modules for the buyer, and
B
is the buyer’s budget.

For the given instance of a price competition game
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle
, we assume that each module owner has full information of the instance including the values
\mathbf{v}
, costs
\mathbf{c}
and constraints
\mathcal{I}
. We do note that full information about the valuation function of the buyer, constraint
\mathcal{I}
, and cost of other module owners is unrealistic. However, understanding the price competition game in the full-information setting already turns out to be non-trivial and acts as a building block towards understanding the modular marketplace where the module owners do not have any information about the price competition instance except their private costs. In addition, we assume that the buyer does have the information about the values
\mathbf{v}
, constraint
\mathcal{I}
, and budget
B
but does not have any information about the costs of the modules
\mathbf{c}
.

Given an instance of a price competition game
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle
, the strategy space of the module owner
m_{i}\in M
is a price of their module
\mathbf{p}(i)\in[\mathbf{c}(i),B]
.
2
2

2

Note that
\mathbf{p}(i)<\mathbf{c}(i)
is always dominated by setting a price of
\mathbf{c}(i)
since bidding less than
\mathbf{c}(i)
always results in non-positive utility for the seller.

We let
\mathcal{A}\colon\mathbb{R}_{+}^{M}\rightarrow 2^{M}
be the selection rule for the buyer that takes the prices of the modules
\mathbf{p}
as an input and outputs a set of modules such that for any price vector
\mathbf{p}
, we have (a)
\sum_{i\in\mathcal{A}(\mathbf{p})}\mathbf{p}(i)\leq B
and (b)
\mathcal{A}(\mathbf{p})\in\mathcal{I}
.

For the given price vector
\mathbf{p}
, we let
u_{i}^{\mathcal{A}}(\mathbf{p})=(\mathbf{p}(i)-\mathbf{c}(i))\cdot\mathbbm{1}[i\in\mathcal{A}(\mathbf{p})]
be the utility of module
i
when the buyer implements selection rule
\mathcal{A}
.
We say that
\mathbf{p}
is an equilibrium price for the price competition game if no module can deviate from its posted price and increase its utility, i.e. for all
i\in[k]
and
\mathbf{p}(i)^{\prime}\neq\mathbf{p}(i)
, we have,

u_{i}(\mathbf{p}(i)^{\prime},\mathbf{p}_{-i})\leq u_{i}(\mathbf{p}(i),\mathbf{p}_{-i})
. Similarly, for any
\varepsilon>0
, we say that the prices
\mathbf{p}
is an
\varepsilon
-equilibrium price if for all
i\in[k]
and
\mathbf{p}(i)^{\prime}\neq\mathbf{p}(i)
, we have,

u_{i}(\mathbf{p}(i)^{\prime},\mathbf{p}_{-i})\leq u_{i}(\mathbf{p}(i),\mathbf{p}_{-i})+\varepsilon
.

To evaluate the quality of the selection rule
\mathcal{A}
, we compare the value obtained by the buyers at any equilibrium to an omniscient benchmark
OPT
which is the best possible value achieved by the buyer in the case when it knows the costs of the modules
\mathbf{c}
, i.e.
\mathop{max}_{S\in\mathcal{I},\mathbf{c}(S)\leq B}\mathbf{v}(S).
We say that allocation rule
\mathcal{A}
has an
approximation ratio
of
\alpha\in[0,1]
if for any equilibrium price
\mathbf{p}
for the price competition instance
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle
with selection rule
\mathcal{A}
, we have
\sum_{i\in\mathcal{A}(\mathbf{p})}\mathbf{v}(i)\geq\alpha\cdot\textbf{OPT}
.

Learning Dynamics in the Price Competition Game

In the above discussion, we defined a price competition game between the modules where we assume that all the modules possess full information about the game instance
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle
. However, the cost of each module is private information, i.e. only module
m_{i}
has information of their private
\mathbf{c}(i)
, and the rest of the modules are unaware of the private cost of module
m_{i}
. In addition, the modules have no information about the value vector
\mathbf{v}
and underlying constraints
\mathcal{I}
. As a result, without full information about market parameters, the modules cannot implement equilibrium prices directly.

In this section, we formally define the learning dynamics of the price competition market, where each module owner employs a learning algorithm to set their prices. More specifically, we fix an instance of the price competition game
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle
, and we consider a setting where a single platform repeatedly interacts with the modules over
T
rounds. At each round, a price competition game instance
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle
is played.

We assume that module
m_{i}\in M
implements an
online learning algorithm

\mathcal{L}(i)
to set its price.
At round
t
, the algorithm selects a price
\mathbf{p}^{t}(i)
(possibly at random) from the set
\mathcal{B}=\{\delta,2\cdot\delta,\dots,B\}
,
where
\delta\in(0,1)
represents the minimum price increment.
The price
\mathbf{p}^{t}(i)
at round
t
is determined based on the history of the game up to round
t-1
. At each round
t
, the platform provides feedback to module
m_{i}
regarding the maximum price at which the module could have been selected in that round.
We denote the history at round
t
for module
m_{i}
as the set of prices, the set of selected modules, and the received feedback from the platform up to round
t-1
.

The goal of each module’s learning algorithm
\mathcal{L}(i)
is to adjust its price iteratively based on the feedback received, with the aim of converging towards an optimal pricing strategy. In particular, the platform’s feedback provides each module with information that helps refine its price selection to maximize its reward over time. This repeated interaction across
T
rounds allows modules to ”learn” about the market conditions and the behavior of competitors, even with incomplete information about other modules’ costs and the platform’s value structure.

Given the price competition game instance
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle
and learning algorithms of the modules
\{\mathcal{L}(i)\,:\,i\in M\}
induces a price dynamics denoted as a sequence of price vectors
\{\mathbf{p}^{t}\,:\,t=1,2,\dots\}
. We next define convergence of the price dynamics of the price competition game which is a generalization of the standard definition of convergence of the sequences.

Definition 2.1
.

The learning dynamics of the price competition game instance
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle
with learning algorithms of the modules
\{\mathcal{L}(i)\,:\,i\in M\}
converges to the price vector
\mathbf{p}
if for any
\gamma>0
, there exists
T^{*}\geq g(\gamma)
such that

\mathop{\mathbf{Pr}}\left[|\mathbf{p}^{t}(i)-\mathbf{p}(i)|\leq\sqrt{\delta}:\forall i\in M\text{ and }t\geq T^{*}\right]\geq 1-\gamma.

In this work, we consider the dynamics where each module implements
multiplicative weight update
type learning algorithm to set the price which we define in the following definition.

Definition 2.2

(Multiplicative Weight Type Learning Algorithm)
.

Given set of bids
\mathcal{B}
and total cumulative reward of price
p\in\mathcal{B}
denoted as
\sigma_{t}(a)=\sum_{t^{\prime}\leq t}u_{i}^{\mathcal{A}}(p,\mathbf{p}_{-i}^{t})
, we say that the algorithm
\mathcal{L}
is multiplicative weight type with learning rate
\gamma_{t}
if for any two prices
p,p^{\prime}\in\mathcal{A}
and some constant
\tau>0
, whenever
\sigma_{t}(p^{\prime})\leq\sigma_{t}(p)-\tau\cdot t
then the probability that the algorithm sets price
p^{\prime}
at round
t+1
is less than
\exp(-\gamma_{t}\cdot\tau\cdot t)
.

3.1
Existence of Equilibria

In this paper, we will give constructive proofs that
\varepsilon
-equilibria exist in the pricing game when the allocation rule is given by Algorithm

(see the formal results and proofs in Section

, Section

, and Section

).
In this section, we give a high-level intuition of how to make such constructions.
For simplicity, let us assume that the modules are sorted in increasing order of “cost-per-value” and that these values are distinct, i.e.
\frac{\mathbf{c}(1)}{\mathbf{v}(1)}<\ldots<\frac{\mathbf{c}(n)}{\mathbf{v}(n)}
.
Note that this is equivalent to decreasing bang-per-buck order.

First, assume there is no matroid constraint.
At a high-level, the algorithm starts by assuming every module bids their cost.
However, this means that the module with the highest cost-per-value (the inverse of the bang-per-buck) can raise its bid since it is the first module inspected by
\mathcal{A}_{BPB}
.
So it increases its cost-per-value up until the next module inspected by
\mathcal{A}_{BPB}
.
Then the two modules, as a coalition, increase their price to the third module inspected by
\mathcal{A}_{BPB}
.
This process continues until a step
k
where increasing modules
1,\ldots,k
to the cost-per-value of module
k+1
would cause the first
k+1
modules to exceed the budget constraint.
When this happens, we instead raise the cost-per-value of the first
k
modules as high as possible so that the first
k
modules fit within the budget constraint.
We note that the set of module which increases their price remains selected by the greedy algorithm. In addition, increasing the price of these module can only decrease the utility of the rest of the module. Therefore,
intuitively, this should be an equilibrium since no accepted module can increase their price while remaining accepted by
\mathcal{A}_{BPB}
and no rejected module is willing to lower their price since it is already bidding its cost.

The argument becomes more complex when a matroid constraint is introduced. Imagine we try to iteratively increase the prices of the modules, similar to how we did in the additive case. With a matroid constraint, a module (or set of modules) might have its price increased and still be selected by the greedy algorithm. This price update, however, could cause the algorithm to drop a module with the lowest bang-per-buck (due to the matroid constraint) and swap it for a module with a higher bang-per-buck that wasn’t previously selected at the original price.

This means that modules rejected earlier during the price update process can suddenly become “important” and might be willing to increase their prices in future updates. This “non-monotonic” behavior makes things tricky. To handle this, we have carefully designed an algorithm (Algorithm
3
) that keeps track of these modules that are suddenly selected. In our equilibrium construction, we make sure that if such modules exhibit profitable price deviations, we update their prices accordingly.

3.2
Quality of Equilibria

Characterizing worst-case equilibria.

Our first step to prove approximation results of equilibria is to first characterize the set of “worst-case” equilibria.
We first prove a technical result that shows that in the worst-case equilibria, roughly speaking, all rejected modules bid their cost.
This statement is exactly true in the setting without a matroid constraint and in the setting with a matroid constraint but with uniform values.
For the setting with general values, this statement is only partly true and we can only make this characterization up to a single module; we will leave the technical details of this to Section
5
.

Our overall approach is to demonstrate that, starting from any equilibrium price, we can reach another equilibrium through a sequence of price deviations. This sequence will ensure that all ”crucial” non-selected module sets have their prices equal to their costs, while simultaneously decreasing the total value for the platform. We then analyze the value of such equilibria using properties of the greedy algorithm, allowing us to directly compare it to the optimal value, OPT.

The main technical challenge lies in the following: once we update the price of a non-selected module to its cost, it can create several new potential profitable deviations for other modules. These deviations must be addressed to reach a new equilibrium without changing the price of the non-selected module we just adjusted. Our core technical analysis focuses on tracking all these potential new deviations and arguing that our specific sequence of deviations ultimately leads to an equilibrium where the ”crucial” non-selected modules have their prices set equal to their costs.

3.3
Convergence to Equilibria

Finally, we show that natural dynamics lead to convergence to an equilibrium in this pricing game.
In particular, we focus on the multiplicative weights update algorithm. More formally, for any price competition game instance
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle
with
\mathcal{I}
being a matroid constraint and budget
B=1
, we show that our dynamics convergences to an equilibrium that can be constructed via Algorithm
3
.

To begin with, we let
\mathbf{\overline{p}}
be the equilibrium price computed by Algorithm
3
and
S_{\mathbf{\overline{p}}}
be the set of selected modules at price
\mathbf{\overline{p}}
. For simplicity, we assume that
\mathbf{\overline{p}}(S_{\mathbf{\overline{p}}})=1
. We first, prove the following structural properties of the computed equilibrium price:

Weak-Dominance of
\mathbf{\overline{p}}
:

We show that if module
i\in S_{\mathbf{\overline{p}}}
gets selected at some price vector
\mathbf{p}
then it also gets selected at price
\mathbf{\overline{p}}(i)
. We emphasize that setting a price equal to
\mathbf{\overline{p}}(i)
is not a dominating strategy as bidding higher than
\mathbf{\overline{p}}(i)
can lead to higher utility.

Iterative Peeling of the Worst-Bid:

We show that given any price vector
\mathbf{p}
satisfying
\forall i\in S_{\mathbf{\overline{p}}}:\mathbf{p}(i)\geq\mathbf{\overline{p}}(i)
then the module with the module with worst-bang-per-buck at price
\mathbf{p}
from the set
S_{\mathbf{\overline{p}}}
does not get selected.

Stability of
\mathbf{\overline{p}}
:

Finally, we show that if all modules
i\in S_{\mathbf{\overline{p}}}
set their price
\mathbf{p}(i)\in[\mathbf{\overline{p}}(i)-\delta,\mathbf{\overline{p}}(i)+\delta]
then modules
i\in S_{\mathbf{\overline{p}}}
can always deviate to price
\mathbf{\overline{p}}(i)
and can get selected. In addition, no module
i\in S_{\mathbf{\overline{p}}}
can get selected if they set their price significantly higher than
\mathbf{\overline{p}}
.
Above, the second and the third property follows from the fact that
\mathbf{\overline{p}}(S_{\mathbf{\overline{p}}})=1
. When
\mathbf{\overline{p}}(S_{\mathbf{\overline{p}}})<1
, we prove such properties by leveraging the existence of a module that can swap module from
S_{\mathbf{\overline{p}}}
that sets price greater than
\mathbf{\overline{p}}(i)
. The first property is slightly tricky and relies on the invariant of the equilibrium construction algorithm (Algorithm
3
) proved in Claim
5.1
.

We assume that modules only place bids in a discretization of the unit interval, i.e.
\{\delta,2\delta,\ldots,1\}
for some small
\delta>0
.
Due to Property 1, we first observe that for module
i\in S_{\mathbf{\overline{p}}}
, its cumulative utility obtained by any price
p<\mathbf{\overline{p}}(i)
is strictly smaller than the cumulative utility of price
\mathbf{\overline{p}}(i)
. To steadily increase the difference in the cumulative utility
\sum_{t^{\prime}\leq t}u_{i}(\mathbf{\overline{p}}(i),\mathbf{p}_{-i}^{t})-u_{i}(p,\mathbf{p}_{-i}^{t})
, we slightly distort the payments by giving extra
\delta^{2}\cdot p
for any submitted price
p
. This essentially implies that after a sufficiently large number of rounds
\geq\poly\left(n,\frac{1}{\delta}\right)
, module
i\in S_{\mathbf{\overline{p}}}
will stop submitting price sufficiently smaller than
\mathbf{\overline{p}}(i)
with high probability.

Next, we then condition on the event that all modules
i\in S_{\mathbf{\overline{p}}}
sets their price at least
\mathbf{\overline{p}}(i)-O(\delta)
. Then we utilize the second property to iteratively rule out modules bidding that would lead to the worst bang-per-buck. More formally, we iteratively define a pair of modules and their bid and order them from the worst to the best bang-per-buck,

(b_{(k)},i_{(k)}):=\mathop{argmin}_{\{(b,i)\in\overline{\mathcal{B}}\setminus\{(b_{(1)},i_{(1)}),\dots,(b_{(k-1)},i_{(k-1)})\}\}}\left\{v(i)/b\right\}.

Here,
(b_{(1)},i_{(1)}):=\mathop{argmin}_{(b,i)\in\overline{\mathcal{B}}}\{\mathbf{v}(i)/b\}
and
\overline{\mathcal{B}}:=\bigcup_{i\in S_{\mathbf{\overline{p}}}^{\prime}}\{(\mathbf{\overline{p}}(i)+\delta,i),\dots,(1,i)\}
. We observe that once we condition on the event that all modules
i\in S_{\mathbf{\overline{p}}}
sets their price at least
\mathbf{\overline{p}}(i)-O(\delta)
, we observe that module
i_{(1)}
can not be selected at price
b_{(1)}
. Therefore, the gap in the cumulative utility of
\sum_{t^{\prime}\leq t}u_{i_{(1)}}(\mathbf{\overline{p}}(i_{(1)}),\mathbf{p}_{-i_{(1)}}^{t})-u_{i_{(1)}}(b_{(1)},\mathbf{p}_{-i_{(1)}}^{t})
keeps on growing. Again, to accelerate the convergence, we start incentivizing modules to lower their bid by paying extra
\frac{\delta^{4}}{b}
for bid
b
.
This essentially implies that after
\poly\left(n,\frac{1}{\delta}\right)
many rounds, module
i_{(1)}\in S_{\mathbf{\overline{p}}}
will stop submitting price
b_{(1)}
in future with sufficiently high probability using the property of multiplicative weight update algorithm. This argument can be repeated until we are at convergence. Once modules in
S_{\mathbf{\overline{p}}}
start submitting prices closer to their equilibrium price, Property 3 ensures that no module has an incentive to deviate from their convergent prices which are their constructed equilibrium prices.

6
Convergence Dynamics of Learning Modules

Our main result in this section shows that the learning dynamics of the price competition game
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle
with multiplicative weight learning algorithm
\{\mathcal{L}(i):i\in M\}
converges to the price
\overline{\mathbf{p}}
computed by Algorithm
5
under mild assumption on
\mathbf{c},\mathbf{v}
and disretization
\delta
, when
\mathcal{I}
is a matroid constraints and slightly distorted payments rule: for initial rounds
t\leq T_{0}
, each selected module
i\in M
gets payment of
\mathbf{p}^{t}(i)+\delta^{2}\cdot\mathbf{p}^{t}(i)
and the rest of the modules get payment of
\delta^{2}\cdot\mathbf{p}^{t}(i)
and later after round
t>T_{0}
, all selected module
m_{i}\in M
gets payment of
\mathbf{p}^{t}(i)+\frac{\delta^{4}}{\mathbf{p}^{t}(i)}
and the rest of the modules get payment of
\frac{\delta^{4}}{\mathbf{p}^{t}(i)}
.

The main reason for the distorted payment is the following: note that at the equilibrium price
\mathbf{\overline{p}}
computed by Algorithm
3
, all the modules which are selected at equilibrium prices
S_{\mathbf{\overline{p}}}
have identical bang-per-buck
OptBpb
while the not selected with
\frac{\mathbf{v}(i)}{\mathbf{c}(i)}<{\textsc{OptBpb}}
at price
\overline{p}
sets their price equals to their cost. Therefore to speed up the convergence, we initially incentivize modules in
S_{\mathbf{\overline{p}}}
to bid higher, and later once modules in
S_{\mathbf{\overline{p}}}
start bidding higher than their equilibrium prices, we then incentivize these modules to lower their price if they are bidding much higher than their equilibrium price. As a result, we distort the payment rule by an additive factor of
O(\delta^{3})
. It is easy to observe that if
\mathbf{S}_{\mathbf{p}}
is constructed via a greedy algorithm with budget
B-\delta
, and
\mathbf{p}
is an
\delta
-equilibrium price then the price vector
\mathbf{p}
is a
(\delta+\delta^{2})
-equilibrium price with the new payment rule.

The following is the main theorem of this section.

Theorem 6.1
.

Given the price competition instance
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle

1

\overline{\mathbf{p}}
computed by Algorithm
3

A.1
Necessity of
\varepsilon
-equilibrium

In this brief sub-section, we argue the necessity of studying
\varepsilon
-equilibria instead of exact equilibrium.
Consider the following example with three modules
A,B,C
.
The values are
v_{A}=v_{B}=v_{C}=1
so that the greedy algorithm simply selects modules in order of prices and a tie-breaking rule.
The costs are
c_{A}=2,c_{B}=3,c_{C}=4
while the budget is
10
.
Suppose that ties are broken in favor of modules
C
then
A
then
B
.
We consider a few cases.

Case 1: both
A
and
B
bid exactly
4
.

We consider two smaller subcases.
Suppose first that
C
also bids
4
.
Then the winners are
C
and
A
. But this means
B
can deviate, to
3.5
for example, to increase their utility.
On the other hand, if
C
bids strictly more than
4
then both
A
and
B
are selected.
However, both of these modules can slightly increase their bid to ensure they remain selected while being paid slightly more.
So there is no equilibrium where both
A
and
B
bid exactly

.

Case 2: at least one of
A
and
B
bid strictly more than
4
.

In this case, any equilibrium must include
C
as a winner because if
C
is not selected then it could always choose some bid strictly above

to be selected and thus obtain positive utility.
In general (not just in this case), any equilibrium must also include
A
and at a price of at least

because if not, it could just bid

for any
\varepsilon>0
.
Since
C
can never bid below
4
, the budget utilization when
A
is being considered is at most
4-\varepsilon
.
Thus, module
B
must be rejected but this is not an equilibrium since
B
can deviate to
3.5
to ensure it is selected at strictly above its price.

Case 3: at least one of
A
and
B
bids strictly less than
4
.

If either
A
or
B
bids strictly less than
4
then it is certainly accepted since
C
cannot bid less than
4
.
But if they do bid strictly less than
4
then they can slightly raise their bid to gain slightly more utility.

A.2
Necessity for a lower bound on cost

Here, we show that if we analyze
\varepsilon
-equilibria then it is necessary to assume a lower bound on the cost of each module.
Given any fixed
\varepsilon>0
, consider the following example where the budget is
1
.
There are
n+1
modules all with cost
0
.
Module
1
has value
1
while all other modules have value
\varepsilon/2
.
The optimal solution is to take all modules for a total value of

.
On the other hand, an
\varepsilon
-equilibrium is for all modules to set a price of

.
Module

is taken because it has the highest bang-per-buck.
For all the other modules, they need to set a bid of at most

\varepsilon/2

Note that this equilibrium receives only value

Matroid Theory Preliminaries

A
matroid

\mathcal{M}=(E,\mathcal{I})
is a structure with elements
E
and a family of independent sets
\mathcal{I}\subseteq 2^{E}
satisfying the three
matroid axioms
: (i)
\emptyset\in\mathcal{I}
, (ii) if
A\subseteq B
and
B\in\mathcal{I}
then
A\in\mathcal{I}
, and (iii) if
A,B\in\mathcal{I}
and
|A|<|B|
then there exists
x\in B\setminus A
such that
A\cup\{x\}\in\mathcal{I}
.
A
weighted matroid
incorporates a matroid
\mathcal{M}=(E,\mathcal{I})
with weights
w\in\mathbb{R}^{E}
for its elements.

The rank function of a matroid
\mathcal{M}=(E,\mathcal{I})
is denoted by
\textbf{Rank}^{\mathcal{M}}
, where
\textbf{Rank}^{\mathcal{M}}(S)\coloneqq\mathop{max}\{|T|:T\subseteq S,T\in\mathcal{I}\}
. The weighted version of the rank function
\textbf{Rank}_{w}^{\mathcal{M}}
is defined for weighted matroids
(\mathcal{M},w)
as
\textbf{Rank}^{\mathcal{M}}_{w}(S)=\mathop{max}\{w(T):T\subseteq S,T\in\mathcal{I}\}
. The span function of a matroid
\mathcal{M}
is defined as
\spn^{\mathcal{M}}(S)\coloneqq\{e\in E:\textbf{Rank}^{\mathcal{M}}(S\cup\{e\})=\textbf{Rank}^{\mathcal{M}}(S)\}
.

Our proofs will make use of the following basic fact that for a matroid if
S,A
are sets and
x
is an element such that (i)
S\in\mathcal{I}
, (ii) for every
a\in A
,
S\cup\{a\}\notin\mathcal{I}
, and (iii)
x\not in\spn(S)
, then
x\notin\spn(S)
.

Claim B.1
.

For any
G_{k}
be the set of selected elements by Algorithm
1
that satisfies
\mathbf{p}(G^{\prime}_{k})<B
then
G_{k}
is maximum weighted independent set in matroid
\mathcal{I}
restricted on
\pi[k]
.

Proof.

We prove this claim via induction on
k
. The claim trivially holds for

. Suppose, the claim holds until iteration

. In this case, we observe that
G^{k-1}
is a full rank set in matroid
\mathcal{I}
restricted on
\pi[k-1]
. If
\pi(k)\notin\spn(G^{k-1})
then maximum weight independent set in
\pi[k]
is
G^{k-1}\cup\pi[k]
which is precisely the set
G_{k+1}
.

In other case when
\pi(k)\in\spn(G^{k-1})
then due to
[
26
, Proposition 1.1.6]
,
\pi(k)
forms a unique circuit
C
with
G^{k-1}
. Now, we consider the classic greedy algorithm on matroid that orders elements in the decreasing order of weights and selects an element if it is not spanned by higher weight element. We note that minimum weight element

on circuit

We divide the proof of the main theorem of this section into two parts. First, in Subsection

\varepsilon

\varepsilon

D.1
Existence of Price Equilibrium

We begin our analysis by showing the existence of
\varepsilon
-equilibrium prices. To this end, we provide an algorithm that explicitly constructs an
\varepsilon
-equilibrium price vector for the pricing game between the modules.

Algorithm
5
shows how to construct an equilibrium.
In addition, to simplify the notations and reduce clutter, we assume that the buyer breaks ties in favor of modules with higher
\frac{\mathbf{v}(i)}{\mathbf{c}(i)}
and as a result, we show that Algorithm
5
converges to an exact equilibrium.
More specifically, we assume that the buyer breaks ties in the initial permutation
\pi^{0}
defined in Algorithm
5
.

We note that since the buyer has no information about the module’s private cost, the buyer cannot implement such a tie-breaking rule while selecting modules.
In order to simulate the desired tie-breaking rule, we can lower the price of accepted modules by an infintesimal amount which results in an
\varepsilon
-equilibrium for any small
\varepsilon>0
.

The algorithm begins by initializing
\mathbf{p}
as
\mathbf{p}=\mathbf{c}
and an ordering
\pi^{0}
which is decreasing in their bang-per-buck w.r.t.
\mathbf{p}
at round zero. We then define the set
T^{k}
that denotes the set of modules that increase their price at iteration
k
and
\pi^{k}
that denotes the bang-per-buck order over modules at the price
\mathbf{p}^{k}
. Throughout the algorithm, we maintain the following invariants at iteration
k
: (a) the price of modules
\pi^{0}(k),\dots,\pi^{0}(n)
are unchanged and equal to their cost, (b) the bang-per-buck of the modules higher than
\frac{\mathbf{v}(\pi(k))}{\mathbf{c}(\pi(k))}
remains higher than
\frac{\mathbf{v}(\pi(k))}{\mathbf{c}(\pi(k))}
at price
\mathbf{p}^{k}
, (c) for every module in
i\in T^{k}
, we have
\frac{\mathbf{v}(i)}{\mathbf{p}^{k}(i)}=\frac{\mathbf{v}(\pi^{0}(k))}{\mathbf{c}(\pi^{0}(k))}
.

We can describe the algorithm as follows.
First, we raise the prices of all modules in
T^{k-1}
so that their bang-per-buck meets that of module
\pi^{k}(k)
, whose price is still at its cost.
Next, we check whether or not
\pi^{k}(k)\in\spn(A^{k-1}\cup T^{k-1})
.
If not we add it to
T^{k-1}
to obtain
T^{k}
.
Otherwise, we find the (unique) circuit in
A^{k-1}\cup T^{k-1}\cup\{\pi^{k}(k)\}
and add it, without
\pi^{k}(k)
, to
A^{k-1}
to get
A^{k}
.
Doing so freezes the price of these modules.
We then remove
A^{k-1}
from
T^{k-1}
to get
T^{k}
, the set of modules which can still raise their prices.
Next, we check whether or not
A^{k}\cup T^{k}
can fit within the budget at the price
\mathbf{p}^{k}
.
If not then, if necessary, we lower the prices for
T^{k-1}
(whose prices we had just raised) so that
A^{k-1}\cup T^{k-1}
fits within the budget.
In effect, this ensures that
\mathcal{A}_{BPB}
rejects
\pi^{k}(k)
.

If the algorithm does manage to go through every module and
T^{n}\neq\emptyset
then we increase the price of every module in
T^{n}
until the price of all accepted modules in
A^{n}\cup T^{n}
is equal to the budget.

Let
\overline{\mathbf{p}}
be the price computed by Algorithm
5
. We first characterize

, the set of selected modules at the price, and obtain a structural decomposition of the set

in the given underlying matroid
\mathcal{M}

be the last iteration of the dynamics.

First, we show that after the price updates at iteration
k

k-1
and round
k
stays identical among the modules
\pi^{k-1}(1),\dots,\pi^{k-1}(k)
with top
k

increase their utility.

Claim D.1
.

For any iteration
k\leq k^{*}
, we have
S_{\mathbf{p}^{k-1}}\cap\pi^{k-1}([k-1])=S_{\mathbf{p}^{k}}\cap\pi^{k}([k-1])=A^{k-1}\cup T^{k-1}
.

Proof.

Define
R^{k}=\pi^{k}([k])\setminus(A^{k}\cup T^{k})
.
We think of
R^{k}
as the set of modules that
\mathcal{A}_{BPB}
is sure to reject.
We show that the following invariants hold:

1.

\pi^{k-1}([k-1])=\pi^{k}([k-1])
and
\pi^{k-1}(k)=\pi^{k}(k)
.

2.

when the prices are
\mathbf{p}^{k}
, the bang-per-buck of any module in
A^{k-1}
is at least that of any module in
T^{k-1}
.

3.

when the prices are
\mathbf{p}^{k}
, the bang-per-buck of any module in
T^{k-1}
is at least that of any module in
\pi^{k}([n])\setminus\pi^{k}([k])
.

4.

\mathbf{p}^{k}(A^{k-1}\cup T^{k-1})\leq B
.

5.

if
i\leq k
and
\pi^{k}(i)\in R^{k}
then
\pi^{k}(i)\in\spn(A^{k}\cap\pi^{k}([i-1]))
.

These invariants show that if
\mathcal{A}_{BPB}
follows the order of
\pi^{k}
then it accepts every module in
A^{k-1}\cup T^{k-1}
when the price vector is
\mathbf{p}^{k}
.
In other words,
S_{\mathbf{p}^{k-1}}\cap\pi^{k-1}([k-1])=S_{\mathbf{p}^{k}}\cap\pi^{k}([k-1])

The invariants are trivial if

.
We now assume that the invariant holds at iteration

and prove that it remains true at iteration

For the first invariant, the only modules that increase their price is

Since their bang-per-buck is at most that of module
\pi^{k-1}([k])
this means that all modules in
\pi^{k-1}([k-1])
still come before module
\pi^{k-1}([k])
.
So
\pi^{k-1}([k-1])=\pi^{k}([k-1])

The fact that
\pi^{k-1}(k)=\pi^{k}(k)

For the second invariant, we need the following claim.

Claim D.2
.

For all
i\in T^{k-1}
, we have
\mathbf{p}^{k}(i)\geq\mathbf{p}^{k-1}(i)
.

Proof.

Note that
\mathbf{p}^{k-1}(i)=\frac{\mathbf{p}(\pi^{k-1}(k-1))}{\mathbf{v}(\pi^{k-1}(k-1)))}\cdot\mathbf{v}(\pi^{k-1}(i))

We have that

\mathbf{p}^{k}(i)\geq\mathop{min}\left\{\mathbf{v}(i)\cdot\frac{B-\mathbf{v}^{k-1}(A^{k-1})}{\mathbf{v}(T^{k-1})},\frac{\mathbf{p}(\pi^{k}(k))}{\mathbf{v}(\pi^{k}(k)))}\cdot\mathbf{v}(\pi^{k}(i))\right\}.

The second term in the minimum is more than
\mathbf{p}^{k-1}(\pi^{k-1}(i))

\pi^{k-1}(k-1)
comes before
\pi^{k}(k)

For the first term, we know that

Since the bang-per-buck of any module in

when the price vector is

This shows that the second invariant holds.

The third invariant is because prices of modules in

The fourth invariant is trivial if Line

Otherwise, it is true because (i)
\mathbf{p}^{k-1}(A^{k-1})+\mathbf{p}^{k-1}(T^{k-1})
by the fact that the invariant holds for

\mathbf{p}^{k}(A^{k-1})+\mathbf{p}^{k}(A^{k-1})

Finally, for the fifth invariant, first suppose that
i\leq k-1

We have that
\pi^{k-1}(i)

The case

Claim D.3

Claim

Lemma D.4
.

We can decompose

Theorem D.5
.

The vector
\overline{\mathbf{p}}
is an equilibrium price.

Proof.

If
i\notin A^{k^{*}}\cup T^{k^{*}}\cup R^{k^{*}}=\pi^{k^{*}}([k^{*}])
then by Claim
D.3
, module
i
is not inspected by
\mathcal{A}_{BPB}
before the budget constraint is met. Since module
i
is already bidding its cost, it cannot deviate to get selected.

Suppose that
i\in R^{k^{*}}
.
By invariant
5
in the proof of Claim
D.1
, we have that
\pi^{k^{*}}(i)\in\spn(A^{k^{*}}\cap\pi^{k^{*}}([i-1]))
.
So
i
forms a circuit with
A^{k^{*}}\cap\pi^{k^{*}}([i-1])
and is inspected by
\mathcal{A}_{BPB}
after every other module in this circuit.
Since it is already bidding its cost, it cannot deviate to get selected by
\mathcal{A}_{BPB}
.

Now suppose
i\in A^{k^{*}}
.
This means there is some
k\in[k^{*}]
such that
i\in A_{k}\setminus A_{k-1}
.
At this point, there was a circuit
C\subseteq A^{k}\cup\{\pi^{k}(k)\}
that contained
i
and after iteration
k
all prices in
C
were never raised.
If module
i
raises its price then it would be inspected by
\mathcal{A}_{BPB}
after every other module in
C
and so it would be rejected. So
i
has no incentive to deviate.

Finally, suppose
i\in T^{k^{*}}
.
By construction all modules in
T^{k^{*}}
have the same bang-per-buck and have the lowest bang-per-buck among all modules selected by
\mathcal{A}_{BPB}
.
There are two cases.
If
\overline{\mathbf{p}}(A^{k^{*}}\cup T^{k^{*}})=B
then if
i
increases its price, it would be rejected by
\mathcal{A}_{BPB}
since there is no budget remaining when
i
is inspected (it could come after every other module in
A^{k^{*}}\cup T^{k^{*}}
).
If
\overline{\mathbf{p}}(A^{k^{*}}\cup T^{k^{*}})<B
then we must have entered the if condition in Line
14
.
Now in Line
16
, we must set
\mathbf{p}^{k^{*}}
to be the second term in the minimum.
If it was the first term, the budget constraint would be exactly met with modules
A^{k^{*}}\cup T^{k^{*}}
.
Note that
\pi^{k^{*}}(k^{*})\in\spn(A^{k^{*}}\cup T^{k^{*}})
.
To see this, note that if not, we would have
A^{k^{*}}\cup T^{k^{*}}=A^{k^{*}-1}\cup T^{k^{*}-1}
.
Since in Line
16
, we must set
\mathbf{p}^{k^{*}}
to be the second term in the minimum, this implies that
\mathbf{p}^{k^{*}}(A^{k^{*}}\cup T^{k^{*}})>B
.
We conclude then that
\overline{\mathbf{p}}(i)=\mathbf{p}^{k^{*}}(i)
.
In particular, this means that
i
has the same bang-per-buck as module
\pi^{k^{*}}(k^{*})
.
Now if
i
raises its price then it would be inspected by
\mathcal{A}_{BPB}
after
\pi^{k^{*}}(k^{*})
.
Since
\pi^{k^{*}}(k^{*})
does not form a circuit with
A_{k^{*}}\cup T_{k^{*}}

\mathcal{A}_{BPB}
would accept
\pi^{k^{*}}(k^{*})
but reject

.

cannot deviate.

D.2
Quality of Equilibria

First, we prove the following lemma that reduces our quality of equilibrium analysis to the case when the modules which are not selected at the equilibrium price sets their price equals to their respective cost.
In this section, we will assume that
\frac{\mathbf{v}(i)}{\mathbf{c}(i)}
are all distinct.

Lemma D.6
.

Let
\mathbf{p}
be an
\varepsilon
-equilibrium price and
S_{\mathbf{p}}
be the set of selected modules by
\mathcal{A}_{BPB}
. Then for any module
i\notin S_{\mathbf{p}}
, there exists an
\varepsilon
-equilibrium prices
\mathbf{\overline{p}}
such that (i)
\overline{\mathbf{p}}\leq\mathbf{c}(i)+\varepsilon
, (ii)

S_{\mathbf{\overline{p}}}\subseteq S_{\mathbf{p}}
, and (iii)
\overline{\mathbf{p}}\leq\mathbf{p}
.

Proof.

Let
\pi
be the ordering over the modules according to their bang-per-buck at price
\mathbf{p}
with ties broken in lexicographic order. Fix a module
i\notin S_{\mathbf{p}}
such that
\mathbf{p}(i)>\mathbf{c}(i)+\varepsilon
.
Since
\mathbf{p}
is an
\varepsilon
-equilibrium price, we have that
u_{i}(\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i})=0
. In particular, module
i
is not accepted even if it lowered its price to
\mathbf{c}(i)+\varepsilon
.
We now consider the deviation price vector
\mathbf{p}^{\prime}
where
\mathbf{p}^{\prime}(i)=\mathbf{c}(i)+\varepsilon
and
\mathbf{p}^{\prime}(k)=\mathbf{p}(k)
for
k\neq i
.

Let
\pi^{\prime}
be the new ordering of modules according to their bang-per-buck at price
(\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i})
and
j^{\prime}=\pi^{\prime-1}(i)
be the new position of module
i
in the new order
\pi^{\prime}
(again, breaking ties in lexicographic order). We observe that since
i\notin S_{\mathbf{p}}
, either (1)
i\in\spn(\{\pi^{\prime}(1),\dots,\pi^{\prime}(j^{\prime}-1)\})
or (2)
i\notin\spn(\{\pi^{\prime}(1),\dots,\pi^{\prime}(j^{\prime}-1)\})
and
\mathbf{c}(i)+\varepsilon+\mathbf{p}(S_{\mathbf{p}}\cap\{\pi^{\prime}(1),\dots,\pi^{\prime}(j^{\prime}-1)\})>B
. We analyze both cases separately.
In both cases, by definition,
i\notin S_{\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i}}
.

Case 1:
i\in\spn(\{\pi^{\prime}(1),\dots,\pi^{\prime}(j^{\prime}-1)\})
.

In this case, we claim that
S_{\mathbf{p}}=S_{\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i}}
. We prove the claim by showing that
S_{\mathbf{p}}\cap\{\pi(1),\dots,\pi(n)\}=S_{\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i}}\cap\{\pi^{\prime}(1),\dots,\pi^{\prime}(n)\}
where
n
is the size of the set
M
.

We first observe that
\pi(k)=\pi^{\prime}(k)
for
k<j^{\prime}
.
Therefore, we have
S_{\mathbf{p}}\cap\{\pi(1),\dots,\pi(k)\}=S_{\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i}}\cap\{\pi^{\prime}(1),\dots,\pi^{\prime}(k)\}
.
However, the modules
\pi(j^{\prime}),\dots,\pi(j-1)
have their position shifted up by one in the new ordering
\pi^{\prime}
.
Then we show that for
j^{\prime}\leq k<j
,
S_{\mathbf{p}}\cap\{\pi(1),\dots,\pi(k)\}=S_{\mathbf{c}(j)+\varepsilon,\mathbf{p}_{-j}}\cap\{\pi^{\prime}(1),\dots,\pi^{\prime}(k+1)\}
.
We prove this claim via induction on
k
.
We start with the base case where
k=j^{\prime}
.
Our assumption here is that
i\in\spn(\{\pi^{\prime}(1),\dots,\pi^{\prime}(j^{\prime}-1)\}
.
Now consider the module
\pi(j^{\prime})=\pi^{\prime}(j^{\prime}+1)
.
We have that

S_{\mathbf{p}}\cap\{\pi(1),\ldots,\pi(j^{\prime}-1)\}=S_{\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i}}\cap\{\pi^{\prime}(1)\,\ldots,\pi^{\prime}(j^{\prime})\}.

In other words, when
\mathcal{A}_{BPB}
inspects module
\pi(j^{\prime})=\pi^{\prime}(j^{\prime}+1)
, the set selected thus far is identical irrespective of whether the order
\pi
or
\pi^{\prime}
is used.
We conclude that
\pi(j^{\prime})\in S_{\mathbf{p}}
if and only if
\pi^{\prime}(j^{\prime}+1)\in S_{\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i}}
.

Next, consider any
k\in\{j^{\prime}+1,\ldots,j-1\}
and assume the induction hypothesis

S_{\mathbf{p}}\cap\{\pi(1),\ldots,\pi(k-1)\}=S_{\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i}}\cap\{\pi^{\prime}(1)\,\ldots,\pi^{\prime}(k)\}.

The argument here is identical to that in the previous paragraph.
When
\mathcal{A}_{BPB}
inspects module
\pi(k)=\pi^{\prime}(k+1)
, the selected thus far is identical irrespective of whether the order
\pi
or
\pi^{\prime}
is used.
We conclude that
\pi(k)\in S_{\mathbf{p}}
if and only if
\pi^{\prime}(k+1)\in S_{\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i}}
.

At this point, we have established that

S_{\mathbf{p}}\cap\{\pi(1),\ldots,\pi(j-1)\}=S_{\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i}}\cap\{\pi^{\prime}(1)\,\ldots,\pi^{\prime}(j)\}.

Our initial hypothesis of the lemma is that
j\notin S_{\mathbf{p}}
, whence we conclude that

S_{\mathbf{p}}\cap\{\pi(1),\ldots,\pi(j)\}=S_{\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i}}\cap\{\pi^{\prime}(1)\,\ldots,\pi^{\prime}(j)\}.

For
k>j
, we have
\pi(k)=\pi^{\prime}(k)
and so
\mathcal{A}_{BPB}
behaves identically irrespective of whether the ordering is
\pi
or
\pi^{\prime}
.

It remains to establish that
\mathbf{p}^{\prime}=(\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i})
is an
\varepsilon
-equilibrium price.
First, consider a module
i^{\prime}\notin S_{\mathbf{p}^{\prime}}
and
i^{\prime}\neq i
with
\mathbf{p}^{\prime}(i^{\prime})>\mathbf{c}(i^{\prime})+\varepsilon
.
We claim that
i^{\prime}
would remain rejected by
\mathcal{A}_{BPB}
if it lowered its price to
\mathbf{c}(i^{\prime})+\varepsilon
when the price vector of the remaining modules is
\mathbf{p}^{\prime}_{-i^{\prime}}
.
As we established above,
\mathcal{A}_{BPB}
makes identical decisions irrespective of whether the ordering is given by
\pi
or
\pi^{\prime}
.
In particular, the set of modules selected by
\mathcal{A}_{BPB}
when it inspects module
i^{\prime}
is identical when the price vector is
(\mathbf{c}(i^{\prime})+\varepsilon,\mathbf{p}_{-i^{\prime}})
or
(\mathbf{c}(i^{\prime})+\varepsilon,\mathbf{p}^{\prime}_{-i^{\prime}})
.
Thus, since
i^{\prime}
did not have a profitable deviation to
\mathbf{c}(i^{\prime})+\varepsilon
in
\mathbf{p}
, we conclude that it also does not have a profitable deviation to
\mathbf{c}(i^{\prime})+\varepsilon
in
\mathbf{p}^{\prime}
.

Now consider a module
i^{\prime}\in S_{\mathbf{p}^{\prime}}
.
Suppose that module
i^{\prime}
has a profitable deviation to
\mathbf{p}(i^{\prime})+\varepsilon
when the price vector is
\mathbf{p}^{\prime}
(recall that
\mathbf{p}(i^{\prime})=\mathbf{p}^{\prime}(i^{\prime})
for all
i^{\prime}\neq i
). We claim that this is only a profitable deviation for
i^{\prime}
when the price vector is
\mathbf{p}
which contradicts that
\mathbf{p}
is an
\varepsilon
-equilibrium.
To see this, note that
\mathbf{p}^{\prime}\leq\mathbf{p}
.
Thus, module
i^{\prime}
with its deviation, can only come earlier in the order inspected by
\mathcal{A}_{BPB}
in
\mathbf{p}
than in
\mathbf{p}^{\prime}
and the set of accepted modules so far in
\mathbf{p}
must be a subset of the set of accepted modules so far in
\mathbf{p}^{\prime}
.
Thus, module
i^{\prime}
’s deviation must also have been profitable in
\mathbf{p}
.

Case 2:
\mathbf{c}(i)+\mathbf{p}(S_{\mathbf{p}}\cap\{\pi^{\prime}(1),\dots,\pi^{\prime}(j^{\prime}-1)\})>B
.

Let
T\coloneqq S_{\mathbf{p}}\setminus S_{\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i}}
be the set of modules which are dropped from the selected set of modules after module
i
updated its price to
\mathbf{c}(i)+\varepsilon
.
Here, similar to the first case, we observe that
\pi(k^{\prime})=\pi^{\prime}(k^{\prime})
for all
k^{\prime}<j^{\prime}
. Hence, we have
S_{\mathbf{p}}\cap\{\pi(1),\dots,\pi(j-1)\}=S_{\mathbf{c}(i)+\varepsilon,\mathbf{p}_{-i}}\cap\{\pi(1),\dots,\pi(j-1)\}
. Therefore,
T\subseteq M\setminus\{\pi(1),\dots,\pi(j-1)\}
.
Define the price vector
\overline{\mathbf{p}}
as

\overline{\mathbf{p}}=\begin{cases}\mathop{max}\left\{\frac{\mathbf{p}(i)+\varepsilon}{\mathbf{v}(i)}\cdot\mathbf{v}(k),\mathbf{c}(k)\right\}&k\in T\\
\mathbf{c}(i)+\varepsilon&k=i\\
\mathbf{p}(k)&k\notin T\cup\{i\}\end{cases}.

We claim that the price
\mathbf{\overline{p}}
is an
\varepsilon
-equilibrium price.

We let
\overline{\pi}
be the bang-per-buck ordering of modules w.r.t. the price
\overline{\mathbf{p}}
. First, we notice that
\mathbf{\overline{p}}\leq\mathbf{p}
point-wise. We further observe that
\pi(k)=\overline{\pi}(k)
for all
k=1,\dots,j^{\prime}-1
. We consider any module
\overline{i}
with
\frac{\mathbf{v}(i)}{\overline{\mathbf{p}}(i)}<\frac{\mathbf{v}(\overline{i})}{\overline{\mathbf{p}}(\overline{i})}
.
By construction of
\overline{p}
, we have that
\overline{\pi}(\overline{i})<\overline{\pi}(i)
.
Therefore, we have that
\overline{i}\in S_{\mathbf{p}}
if and only if
\overline{i}\in S_{\overline{\mathbf{p}}}
as
\{\pi(1),\dots,\pi(j^{\prime}-1)\}=\{\overline{\pi}(1),\dots,\overline{\pi}(j^{\prime}-1)\}
. Therefore, if there exists a profitable deviation of at least
\varepsilon
for module
\overline{i}
at price
\overline{\mathbf{p}}
then the same price deviation is profitable of at least
\varepsilon
for module
\overline{i}
at price
\mathbf{p}
. This implies that there is no profitable deviation of at least
\varepsilon
for module
\overline{i}
at price
\mathbf{\overline{p}}
.

Next, we consider module
\overline{i}
such that
\frac{\mathbf{v}(i)}{\overline{\mathbf{p}}(i)}>\frac{\mathbf{v}(\overline{i})}{\overline{\mathbf{p}}(\overline{i})}
and
\overline{i}\notin S_{\mathbf{p}}
. Since
\mathbf{c}(i)+\mathbf{p}(S_{\mathbf{p}}\cap\{\pi^{\prime}(1),\dots,\pi^{\prime}(j^{\prime}-1)\})>B
and
\pi(k)=\overline{\pi}(k)
for all
k=1,\dots,j^{\prime}-1
, we have that
\overline{i}\notin S_{\mathbf{\overline{p}}}
. Since
\overline{\mathbf{p}}\leq\mathbf{p}
point-wise, we have that if there exists a profitable deviation (of at least
\varepsilon
) for module
\overline{i}
at price
\overline{\mathbf{p}}
then the same price deviation is profitable for module
\overline{i}
at price
\mathbf{p}
(of at least
\varepsilon
). This implies that there is no profitable deviation for module
\overline{i}
at price
\mathbf{\overline{p}}
of at least
\varepsilon
.

We then consider the module
\overline{i}
such that
\frac{\mathbf{v}(i)}{\overline{\mathbf{p}}(i)}>\frac{\mathbf{v}(\overline{i})}{\overline{\mathbf{p}}(\overline{i})}
and
\overline{i}\in S_{\mathbf{p}}
. We observe that
\overline{i}\in T
and since
\frac{\mathbf{v}(i)}{\overline{\mathbf{p}}(i)}>\frac{\mathbf{v}(\overline{i})}{\overline{\mathbf{p}}(\overline{i})}
, it must be the case that
\mathbf{\overline{p}}(\overline{i})=\mathbf{c}(\overline{i})
.

We finally consider the module
\overline{i}
such that
\frac{\mathbf{v}(i)}{\overline{\mathbf{p}}(i)}=\frac{\mathbf{v}(\overline{i})}{\overline{\mathbf{p}}(\overline{i})}
. We first observe that
\overline{i}\in T
and
\frac{\mathbf{v}(\overline{i})}{\mathbf{c}(\overline{i})}>\frac{\mathbf{v}(\overline{i})}{\mathbf{\overline{p}}(\overline{i})}=\frac{\mathbf{v}(i)}{\overline{\mathbf{p}(i)}}
. Therefore, module
\overline{i}
comes before module
i
in the ordering
\overline{\pi}
. We claim that the module
\overline{i}\in S_{\mathbf{\overline{p}}}
.

We observe that
\overline{i}
cannot form a circuit with modules with higher bang-per-buck at price
\overline{p}
than
\frac{\mathbf{v}(\overline{i})}{\mathbf{\overline{p}}(\overline{i})}
. For the sake of contradiction, let
\overline{i}
forms a circuit
C
with modules with higher bang-per-buck than
\frac{\mathbf{v}(\overline{i})}{\mathbf{\overline{p}}(\overline{i})}
. We note that
C\subseteq\{\overline{\pi}_{1},\dots,\overline{\pi}(j^{\prime}-1)\}\cup T
. Let
i^{*}:=\mathop{argmin}_{k\in T\cap C}\frac{\mathbf{v}(k)}{\mathbf{p}(k)}
. Since,
i^{*}
forms a circuit
C
with modules with higher bang-per-buck than
\frac{\mathbf{v}(i^{*})}{\mathbf{p}(i^{*})}
,
i^{*}\notin S_{\mathbf{\overline{p}}}
which is a contradiction.

Let
k
be the index of module
\overline{i}
on the order
\overline{\pi}
. We observe that
\{\overline{\pi}(1),\dots,\overline{\pi}(k-1)\}\subseteq\{\overline{\pi}(1),\dots,\overline{\pi}(j^{\prime}-1)\}\cup T
. Next, we claim that
\mathbf{\overline{p}}(S_{\mathbf{\overline{p}}}\cap\{\overline{\pi}(1),\dots,\overline{\pi}(k-1)\})+\mathbf{\overline{p}}(k)\leq B
. This follows since,

(S_{\mathbf{\overline{p}}}\cap\{\overline{\pi}(1),\dots,\overline{\pi}(k-1)\})\cup\overline{i}\subseteq S_{\mathbf{p}}\cap\{\overline{\pi}(1),\dots,\overline{\pi}(j^{\prime}-1)\}\cup T\subseteq S_{\mathbf{p}},

we conclude that
\mathbf{\overline{p}}(S_{\mathbf{\overline{p}}}\cap\{\overline{\pi}(1),\dots,\overline{\pi}(k-1)\})+\mathbf{\overline{p}}(k)\leq B
. This implies that
\overline{i}\in S_{\mathbf{\overline{p}}}
.

Next, we want to show that there is no profitable deviation for the module
\overline{i}
at price
\overline{p}
. If module
\overline{i}
increases its price to
\mathbf{\overline{p}}(i)+\varepsilon
then
\frac{\mathbf{v}(\overline{i})}{\mathbf{\overline{p}}(\overline{i})+\varepsilon}<\frac{\mathbf{v}(i)}{\mathbf{\overline{p}}(i)}
. Since
\mathbf{c}(i)+\mathbf{p}(S_{\mathbf{p}}\cap\{\pi^{\prime}(1),\dots,\pi^{\prime}(j^{\prime}-1)\})>B
,
\mathcal{A}_{BPB}
will not select module
\overline{i}
. This concludes that there is no profitable deviation for the module
\overline{i}
. Combining above arguments, we conclude that
\mathbf{\overline{p}}
is an
\varepsilon
-equilibrium price.

In both cases, we observe that
S_{\overline{\mathbf{p}}}\subseteq S_{\mathbf{p}}
where
\mathbf{\overline{p}}(i)\leq\mathbf{c}(i)+\varepsilon
. This completes the proof of the lemma.
∎

Due to the above lemma, we immediately obtain the following corollary.

Corollary D.7
.

Let
\mathbf{p}
be an
\varepsilon
-equilibrium price for the price competition game instance
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle
.
There exists an
\varepsilon
-equilibrium price
\mathbf{\overline{p}}
such that
\mathbf{\overline{p}}(i)\leq\mathbf{c}(i)+\varepsilon
for all
i\notin S_{\overline{\mathbf{p}}}
and
V(S_{\overline{\mathbf{p}}})\leq V(S_{\mathbf{p}})
.

Due to the above corollary, in order to bound the approximation ratio, it is sufficient to focus on the case where all non-selected modules at equilibrium price bid their private cost.
Next, we can characterize the equilibrium prices for the matroid rank valuations in the following lemma and show that all equilibrium of the pricing game have a constant approximation ratio.

Lemma D.8
.

Fix an instance
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle
of the price competition game where
\mathcal{I}
denotes a matroid.
Let
\lambda=\mathop{max}_{i}\mathbf{c}(i)/B
denote the maximum normalized cost of any module.
There is a sufficiently small
\varepsilon_{0}>0
(depending on
\mathbf{c},\mathbf{p}
) such that for all
\varepsilon\in(0,\varepsilon_{0})
, the following holds.
Let
\mathbf{p}
be an
\varepsilon
-equilibrium price and let
S_{\mathbf{p}}
be the set of modules selected by
\mathcal{A}_{BPB}
when
\mathbf{p}(i)\leq\mathbf{c}(i)+\varepsilon
for all
i\notin S_{\mathbf{p}}
.
Then

1.

S_{\mathbf{p}}\subseteq S_{\mathbf{c}}
;

2.

there exists
i\in S_{\mathbf{c}}
such that
S_{\mathbf{p}}=S_{\mathbf{c}}\cap\pi_{\mathbf{c}}[\pi_{\mathbf{c}}^{-1}(i)]
; and

3.

\mathbf{v}(S_{\mathbf{c}})\leq\left(1+\frac{B}{B-\lambda B-\varepsilon}\cdot\frac{\lambda B+\varepsilon}{\lambda B}\right)\mathbf{v}(S_{\mathbf{p}}).

The first assertion of Lemma
D.8
shows that the set of modules selected by
\mathcal{A}_{BPB}
in
\mathbf{p}
is a subset of the set of modules selected by
\mathcal{A}_{BPB}
in
\mathbf{c}
.
This is used as a stepping stone to prove the second assertion: that
\mathcal{A}_{BPB}
in
\mathbf{p}
actually selects a
prefix
of the modules selected by
\mathcal{A}_{BPB}
in
\mathbf{c}
.
Using this, we will prove that
\mathcal{A}_{BPB}
in
\mathbf{p}
gets, approximately, a
2
-approximation to
\mathcal{A}_{BPB}
in
\mathbf{c}
.

Proof.

We will choose
\varepsilon_{0}
such that for all
i\in[n-1]
, we have

\frac{\mathbf{v}(i)}{\mathbf{c}(i)+\varepsilon_{0}}>\frac{\mathbf{v}(i+1)}{\mathbf{c}(i+1)}.

Such an
\varepsilon_{0}>0
exists since we assume that
\frac{\mathbf{v}(i)}{\mathbf{c}(i)}>\frac{\mathbf{v}(i+1)}{\mathbf{c}(i+1)}
for all
i\in[n-1]
.

Now fix
\varepsilon\in(0,\varepsilon_{0})
. We begin with the first assertion that
S_{\mathbf{p}}\subseteq S_{\mathbf{c}}
.
For the sake of contradiction, suppose that
S_{\mathbf{p}}\setminus S_{\mathbf{c}}\neq\emptyset
and let
i\in S_{\mathbf{p}}\setminus S_{\mathbf{c}}
.
We consider two cases and show that neither case can happen.

Case 1:
\mathbf{c}(S_{\mathbf{c}}\cap\pi_{\mathbf{c}}[\pi_{\mathbf{c}}^{-1}(i)-1])+\mathbf{c}(i)>B
.

Observe that we have
\mathbf{p}(S_{\mathbf{p}}\cap\pi_{\mathbf{p}}[\pi_{\mathbf{p}}^{-1}(i)])\leq B
since we know that
i\in S_{\mathbf{p}}
.
For notation, let us write
S_{\mathbf{c}}^{\prime}=S_{\mathbf{c}}\cap\pi_{\mathbf{c}}[\pi_{\mathbf{c}}^{-1}(i)-1]
and
S_{\mathbf{p}}^{\prime}=S_{\mathbf{p}}\cap\pi_{\mathbf{p}}[\pi_{\mathbf{p}}^{-1}(i)-1]
.
We claim that
S_{\mathbf{c}}^{\prime}\setminus S_{\mathbf{p}}^{\prime}\neq\emptyset
.
If not then we would have
\mathbf{c}(S_{\mathbf{c}}^{\prime}\cup\{i\})\leq\mathbf{p}(S_{\mathbf{p}}^{\prime}\cup\{i\})\leq B
which contradicts the premise of the case.
Choose an arbitrary module
i^{\prime}\in S_{\mathbf{c}}^{\prime}\setminus S_{\mathbf{p}}^{\prime}
.
Note that module
i^{\prime}
comes before module
i
in the bang-per-buck order according to
\mathbf{c}
and if module
i^{\prime}
price is in
[\mathbf{c}(i^{\prime}),\mathbf{c}(i^{\prime})+\varepsilon]
then this ordering remains unchanged.
Further note that
\pi_{\mathbf{c}}[\pi_{\mathbf{c}}^{-1}(i^{\prime})-1]\supseteq\pi_{\mathbf{p}}[\pi_{\mathbf{p}}^{-1}(i^{\prime})-1]
as
\mathbf{p}\geq\mathbf{c}
coordinate-wise.
As
i^{\prime}\in S_{\mathbf{c}}^{\prime}
, we know that
i^{\prime}\notin\spn(\pi_{\mathbf{c}}[\pi_{\mathbf{c}}^{-1}(i^{\prime})-1])
and thus
i^{\prime}\notin\spn(\pi_{\mathbf{p}}[\pi_{\mathbf{p}}^{-1}(i^{\prime})-1])
.
This means that
i^{\prime}
is matroid-feasible in
\mathbf{p}
when inspected by
\mathcal{A}_{BPB}
but as it was not selected, the budget constraint must have already been violated which must have caused
\mathcal{A}_{BPB}
to terminate. As module
i
comes after module
i^{\prime}
, according to both
\pi_{\mathbf{c}}
and
\pi_{\mathbf{p}}
, this contradicts that
i\in S_{\mathbf{p}}
.
So the premise of the present case is impossible.

Case 2:
\mathbf{c}(S_{\mathbf{c}}\cap\pi_{\mathbf{c}}[\pi_{\mathbf{c}}^{-1}(i)-1])+\mathbf{c}(i)\leq B
.

In this case, module
i\in\spn(S_{\mathbf{c}}\cap\pi_{\mathbf{c}}[\pi_{\mathbf{c}}^{-1}(i)-1])
.
Let
C
be the unique circuit in
S_{\mathbf{c}}\cap\pi_{\mathbf{c}}[\pi_{\mathbf{c}}^{-1}(i)-1]\cup\{i\}
.
Note that module
i
has the lowest bang-per-buck, according to
\mathbf{c}
, in
C
.
Since
i\in S_{\mathbf{p}}
there must be another module
i^{\prime}\in C
such that
i^{\prime}\notin S_{\mathbf{p}}
.
We know that
\mathbf{p}(i^{\prime})\leq\mathbf{c}(i^{\prime})+\varepsilon
and
\frac{\mathbf{v}(i^{\prime})}{\mathbf{p}(i^{\prime})}\geq\frac{\mathbf{v}(i^{\prime})}{\mathbf{c}(i^{\prime})+\varepsilon}>\frac{\mathbf{v}(i)}{\mathbf{c}(i)}
.
Thus
i^{\prime}
comes before
i
in
\mathbf{p}
.
As in the previous case, since
i^{\prime}
is independent in
\mathbf{c}
when inspected by
\mathcal{A}_{BPB}
, it is also independent in
\mathbf{p}
when inspected by
\mathcal{A}_{BPB}
.
Thus,
i^{\prime}
must have either been accepted by
\mathcal{A}_{BPB}
or the budget constraint is violated.
In the former case, this contradicts that
i^{\prime}\notin S_{\mathbf{p}}
while in the latter case, this would contradict that
i\in S_{\mathbf{p}}
since
\mathcal{A}_{BPB}
would have terminated before inspecting module
i
.
In either case, the premise of this case is also impossible.

The two cases above prove that
S_{\mathbf{p}}\subseteq S_{\mathbf{c}}
.
We now prove the second assertion.
Suppose that the second assertion is false.
This means that there is some
i\in S_{\mathbf{p}}
and some
i^{\prime}\in S_{\mathbf{c}}\setminus S_{\mathbf{p}}
such that
\pi_{\mathbf{c}}^{-1}(i^{\prime})<\pi_{\mathbf{c}}^{-1}(i)
.
In other words, module
i^{\prime}
has better bang-per-buck than module
i
(according to
\mathbf{c}
) but module
i^{\prime}
is not selected by
\mathcal{A}_{BPB}
in
\mathbf{p}
while module
i
is selected by
\mathcal{A}_{BPB}
in
\mathbf{p}
.
Following a similar argument in the above case analysis, it must be that module
i^{\prime}
is inspected by
\mathcal{A}_{BPB}
before module
i
when the price vector is
\mathbf{p}
and
i^{\prime}
must be independent of the set selected by
\mathcal{A}_{BPB}
thus far.
Thus if
i^{\prime}
is not selected then it must be that the budget constraint would have been violated which further implies that
i
could not have been selected.
This would contradict that
i\in S_{\mathbf{p}}
.
This proves the second assertion.

Finally, we prove the last assertion.
If
S_{\mathbf{p}}=S_{\mathbf{c}}
there is nothing to prove.
So let
i
denote the module in the second assertion of the lemma and let
j=\mathop{argmax}_{j^{\prime}\in S_{\mathbf{c}}\setminus S_{\mathbf{p}}}\{\mathbf{v}(j^{\prime})/\mathbf{c}(j^{\prime})\}
; this is the next module in the bang-per-buck order according to
\mathbf{c}
.
By following a similar argument in the proof of the first assertion (particularly, for case 1),
since
j\notin\spn(S_{\mathbf{c}}\cap\pi_{\mathbf{c}}[\pi_{\mathbf{c}}^{-1}(i)])
, we also have
j\notin\spn(S_{\mathbf{p}}\cap\pi_{\mathbf{p}}[\pi_{\mathbf{p}}^{-1}(i)])
.
Thus, the reason that
j
is not accepted by
\mathcal{A}_{BPB}
in
\mathbf{p}
is because the budget constraint is violated if module
j
is taken.
Since
\mathbf{p}(j)\leq\mathbf{c}(j)+\varepsilon\leq\lambda B+\varepsilon
, we have
\mathbf{p}(S_{\mathbf{p}})\geq B-\mathbf{p}(j)\geq B-\lambda B-\varepsilon
.
Note also that
\frac{\mathbf{v}(j^{\prime})}{\mathbf{p}(j^{\prime})}\geq\frac{\mathbf{v}(j)}{\mathbf{c}(j)+\varepsilon}
for all
j^{\prime}\in S_{\mathbf{p}}
by definition of
\mathcal{A}_{BPB}
.
We conclude that

\displaystyle\mathbf{v}(S_{\mathbf{p}})

\displaystyle\geq\frac{\mathbf{v}(j)}{\mathbf{c}(j)+\varepsilon}\cdot(B-\lambda B-\varepsilon)

\displaystyle=\frac{\mathbf{v}(j)}{\mathbf{c}(j)}\cdot\frac{\mathbf{c}(j)}{\mathbf{c}(j)+\varepsilon}\cdot(B-\lambda B-\varepsilon)

\displaystyle\geq\frac{\mathbf{v}(j)}{\mathbf{c}(j)}\cdot\frac{\lambda B}{\lambda B+\varepsilon}\cdot(B-\lambda B-\varepsilon).

Next, we bound
\mathbf{v}(S_{\mathbf{c}}\setminus S_{\mathbf{p}})
.
Note that the highest bang-per-buck module (according to
\mathbf{c}
) in
S_{\mathbf{c}}\setminus S_{\mathbf{p}}
is module
j
.
This gives the trivial bound that

\mathbf{v}(S_{\mathbf{c}}\setminus S_{\mathbf{p}})\leq B\cdot\frac{\mathbf{v}(j)}{\mathbf{c}(j)}\leq\frac{B}{B-\lambda B-\varepsilon}\cdot\frac{\lambda B+\varepsilon}{\lambda B}\cdot\mathbf{v}(S_{\mathbf{p}}).

We conclude that

\mathbf{v}(S_{\mathbf{c}})=\mathbf{v}(S_{\mathbf{p}})+\mathbf{v}(S_{\mathbf{c}}\setminus S_{\mathbf{p}})\leq\left(1+\frac{B}{B-\lambda B-\varepsilon}\cdot\frac{\lambda B+\varepsilon}{\lambda B}\right)\mathbf{v}(S_{\mathbf{p}}).\qed

For the remainder of this section, we assume that
\mathbf{v}(i)=1
for all modules
i
.

Lemma D.9
.

Suppose that
\mathbf{v}(i)=1
for all modules
i
.
Further, suppose that
\mathbf{c}(i)/B\leq\lambda
for all
i
.
Let
S_{\mathbf{c}}
be the set selected by
\mathcal{A}_{BPB}
when the costs are
\mathbf{c}
and let
S_{\OPT}\in\mathop{argmax}\{|S|\,:\,\mathbf{c}(S)\leq B,S\in\mathcal{I}\}
. Then
|S_{\OPT}|\leq\left(1+\frac{\lambda}{1-\lambda}\right)|S_{\mathbf{c}}|
.

Proof.

If
\mathcal{A}_{BPB}
spends strictly less than
(1-\lambda)B
then it must be that
|S_{\mathbf{c}}|=|S_{\OPT}|
otherwise there was an independent module that could have been added, as the cost of all modules is strictly less than
\lambda B
.

So now suppose that
\mathbf{c}(S_{\mathbf{c}})\geq(1-\lambda)B
.
Suppose that modules are sorted such that
\mathbf{c}(1)\leq\ldots\leq\mathbf{c}(n)
and let
k=|S_{\mathbf{c}}|
.
We thus have that
k\geq\frac{(1-\lambda)B}{\mathbf{c}(k)}
.
Next, an upper bound on
|S_{\OPT}|
is to take the first
k+1
modules that form an independent set.
This will violate the budget constraint (otherwise
\mathcal{A}_{BPB}
would have picked it).
Thus,
|S_{\OPT}|-|S_{\mathbf{c}}|\leq 1\leq\frac{\lambda B}{\mathbf{c}(k^{*})}\leq\frac{\lambda}{1-\lambda}|S_{\mathbf{c}}|
.
Rearranging gives the lemma.
∎

By combining the above two lemmas we have the following.

Theorem D.10
.

Fix an instance
\langle M,\mathbf{v},\mathbf{c},\mathcal{I},B\rangle
where
\mathbf{v}(i)=1
for all
i
.
Further, suppose that
\mathbf{c}(i)/B\leq\lambda
for all
i
.
Let
\varepsilon>0
be sufficiently small, as required by Lemma
D.8
.
Let
\mathbf{p}
be an
\varepsilon
-equilibrium price, let
S_{\mathbf{p}}
be the set selected by
\mathcal{A}_{BPB}
when the prices are
\mathbf{p}
, and let
S_{\OPT}\in\mathop{argmax}\{|S|\,:\,\mathbf{c}(S)\leq B,S\in\mathcal{I}\}
. Then
|S_{\OPT}|\leq\left(1+\frac{\lambda}{1-\lambda}\right)\left(1+\frac{1}{1-\lambda-\varepsilon/B}\cdot\frac{\lambda+\varepsilon/B}{\lambda}\right)\cdot|S_{\mathbf{p}}|
.

In particular, for any fixed instance, as
\varepsilon\to 0
, the approximation ratio tends to
\frac{2-\lambda}{(1-\lambda)^{2}}
.

\displaystyle\leq\frac{C}{\gamma_{T_{k-1}}\cdot\delta}+\sum_{s\leq T_{k-1}}u_{i,s}(b_{(k-1)},\mathbf{p}^{s}_{-i_{(k-1)}})

\displaystyle=\frac{\sqrt{T_{k-1}}}{\delta}+(T_{k}-T_{k-1})\cdot\frac{\delta^{4}}{b_{i_{(k)}}}+\sum_{s\leq T_{k-1}}u_{i,s}(b_{(k-1)},\mathbf{p}^{s}_{-i_{(k-1)}})

\displaystyle\leq\frac{\sqrt{T_{k-1}}}{\delta}+(T_{k}-T_{k-1})\cdot\frac{\delta^{4}}{b_{i_{(k)}}}+\frac{(1+2\cdot\delta)}{b_{i_{(k)}}\delta^{2}}\cdot\sum_{i=1}^{(k-2)}\sqrt{T_{i}}+(T_{k-1}-T_{k})\cdot\frac{\delta^{4}}{b_{i_{(k)}}}+T_{0}

\displaystyle\leq\frac{\sqrt{T_{k-1}}}{\delta}+\frac{\sqrt{T_{k-1}}}{\delta^{2}\cdot b_{i_{(k)}}}+(T_{k}-T_{k-1})\cdot\frac{\delta^{4}}{b_{i_{(k)}}}

\displaystyle+\frac{(1+2\cdot\delta)}{b_{i_{(k)}}\delta^{2}}\cdot\sum_{i=1}^{(k-2)}\sqrt{T_{i}}+(T_{k-1}-T_{k})\cdot\frac{\delta^{4}}{b_{i_{(k)}}}+T_{0}

\displaystyle\leq\frac{(1+2\cdot\delta)}{b_{i_{(k)}}\delta^{2}}\cdot\sum_{i=1}^{(k-1)}\sqrt{T_{i}}+(T_{k}-T_{k-1})\cdot\frac{\delta^{4}}{b_{i_{(k)}}}+T_{0}.

Above, the first inequality holds by the definition of
T_{k-1}
and the fact that
i_{(k)}=i_{(k-1)}
, the equality holds because
u_{i_{(k-1)},s}(b_{(k)},\mathbf{b}_{-i_{(k-1)}})=\frac{\delta^{4}}{b_{i_{(k)}}}
for any
s\geq T_{k-1}
due to Observation
G.1
once conditioned on the event
\bigcap_{i=1}^{k-1}\mathcal{E}^{i}
. The second and third inequality holds due to inductive hypothesis since
T_{k-1}-T_{k-2}\leq\frac{1}{\delta^{4}}\cdot\sqrt{T_{k-1}}
.

Case-2 (
i_{(k)}\neq i_{(k-1)}

In this case, we let
\overline{k}
be the largest index such that
i_{\overline{k}}=i_{(k)}
. If such
\overline{k}
does not exist then we let
\overline{k}=1
. We observe that either
b_{(\overline{k})}=b_{(k)}+\delta
or
\overline{k}=1
since all possible prices are discretized within the additive factor of
\delta
and
b_{(1)}=1
.
We condition on the event
\bigcap_{i=1}^{k-1}\mathcal{E}^{i}
. We define for any
k^{\prime}\leq k
,
\widetilde{b}_{i_{(k^{\prime})}}=b_{i_{(k^{\prime})}}-\delta
.
For any
k^{\prime}\leq k
, by definition of
T_{k^{\prime}}
, we have,

\displaystyle\sum_{t<T_{\overline{k}}}u_{i_{(\overline{k})},t}(\widetilde{b}_{i_{(\overline{k})},t},\mathbf{p}^{s}_{-i_{(k-1)}})

\displaystyle+u_{i_{(\overline{k})},T_{\overline{k}}}(\widetilde{b}_{i_{(\overline{k})},T_{\overline{k}}},\mathbf{p}^{s}_{-i_{(k-1)}})\leq\frac{C}{\gamma_{T_{\overline{k}}}\cdot\delta}+\sum_{t<T_{\overline{k}}}u_{i_{(\overline{k})},t}(b_{i_{(\overline{k})}},\mathbf{p}^{s}_{-i_{(\overline{k})}})+1+\frac{\delta^{4}}{b_{i_{(\overline{k})}}}

\displaystyle\leq\frac{2\sqrt{T_{\overline{k}}}}{\delta}+\sum_{t\leq T_{\overline{k}}}u_{i_{(\overline{k})},t}(b_{i_{(\overline{k})}},\mathbf{p}^{s}_{-i_{(\overline{k})}})

\displaystyle\leq\frac{2\sqrt{T_{\overline{k}}}}{\delta}+\frac{(1+2\cdot\delta)}{b_{i_{(k)}}\delta^{2}}\cdot\sum_{i=1}^{(\overline{k}-1)}\sqrt{T_{i}}+(T_{\overline{k}}-T_{\overline{k}-1})\cdot\frac{\delta^{4}}{b_{i_{(\overline{k})}}}+T_{0}

\displaystyle\leq\frac{(1+2\cdot\delta)}{b_{i_{(k)}}\delta^{2}}\cdot\sum_{i=1}^{\overline{k}}\sqrt{T_{i}}+T_{0}

(G.3)

Above, the first inequality holds because
T_{\overline{k}}
be the smallest stage for which Condition
6.2
holds and the utility of module
i_{(\overline{k})}
at round
T_{\overline{k}}
can be at most
1+\frac{\delta^{4}}{b_{i_{(k)}}}
. The third inequality holds due to the inductive hypothesis. The second and last inequality holds because
T_{\overline{k}}>1
and
\delta<<\frac{1}{2}
.

Next, we claim that under event
\bigcap_{p=1}^{k}\mathcal{E}^{p}
, from rounds
T_{\overline{k}}
to
T_{k}
, price
\widetilde{b}_{i_{(\overline{k})}}=b_{i_{(k)}}
can not be the winning price for module
i_{(k)}
. Now, notice that under event
\bigcap_{p=1}^{k}\mathcal{E}^{p}
, after round
s>T_{(\overline{k})}
, module
i_{(\overline{k}-1)}
does not get selected and for bang-per-buck ordering
\pi_{s}
at round
s
with
\pi^{s}[\ell]=i_{(\overline{k}-1)}
, due to Lemma
6.3
, we have
\mathbf{p}^{s}(S^{*}[\ell])>B
where
S^{*}[\ell]
be the maximum weight independent set in matroid
\mathcal{I}
restricted to
\pi^{s}[\ell]
. Since,
b_{(k)}>\Delta_{i}+\sqrt{\delta}
, we have that if module
\overline{k}
gets selected at price
\widetilde{b}_{i_{(\overline{k})}}
then module
\mathbf{p}^{s}(S^{*}[\ell])\leq B
which is a contradiction. Therefore, we have,

\displaystyle\sum_{T_{\overline{k}}<t<T_{k}}u_{i_{(\overline{k})},t}(\widetilde{b}_{i_{(\overline{k})},t},\mathbf{p}^{s}_{-i_{(k-1)}})

\displaystyle\leq(T_{k}-T_{\overline{k}})\cdot\frac{\delta^{4}}{b_{(k)}}\leq(T_{k}-T_{k-1})\cdot\frac{\delta^{4}}{b_{(k)}}+\frac{(1+2\cdot\delta)}{b_{i_{(k)}}\delta^{2}}\cdot\sum_{i=\overline{k}+1}^{k-1}\sqrt{T_{i}}

(G.4)

Above, the second inequality holds due to the inductive hypothesis. Combining the Inequalities
G.3
,
G.4
, we obtain,

\displaystyle\sum_{s\leq T_{k}}u_{i_{(k)},s}(b_{(k)},\mathbf{p}^{s}_{-i_{(k)}})

\displaystyle=\sum_{T_{\overline{k}}<t<T_{k}}u_{i_{(\overline{k})},t}(\widetilde{b}_{i_{(\overline{k})},t},\mathbf{p}^{s}_{-i_{(k-1)}})+\sum_{t<T_{\overline{k}}}u_{i_{(\overline{k})},t}(\widetilde{b}_{i_{(\overline{k})},t},\mathbf{p}^{s}_{-i_{(k-1)}})

\displaystyle\leq\frac{(1+2\cdot\delta)}{b_{i_{(k)}}\delta^{2}}\cdot\sum_{i=1}^{(k-1)}\sqrt{T_{i}}+(T_{k}-T_{k-1})\cdot\frac{\delta^{4}}{b_{i_{(k)}}}+T_{0}

We then observe that module
i_{(k)}
can be selected at price
b_{i_{(k)}}
in less than

\frac{1}{b_{(k)}}\cdot\left(\frac{(1+2\cdot\delta)}{b_{i_{(k)}}\delta^{2}}\cdot\sum_{i=1}^{(k-1)}\sqrt{T_{i}}+T_{0}\right),

many rounds. Due to Lemma
6.2
, we have that whenever the module gets selected at price
b_{(k)}
, it also gets selected at price
\Delta_{i}
. Therefore, for any
T_{k}^{*}\geq\frac{1}{\delta^{6}}\cdot\left(\sum_{i=0}^{k-1}\sqrt{T_{i}}+(1+\delta^{2})\cdot T_{0}\right)
, we can bound the utility difference of
b_{(k)}
and
\Delta
as:

\displaystyle\sum_{s\leq T^{*}_{k}}(u_{i,s}(\Delta_{i},\mathbf{p}^{s}_{-i})-u_{i,s}(b_{i_{(k)}},\mathbf{p}^{s}_{-i}))-\delta^{6}\cdot T_{k^{*}}

\displaystyle\geq\left(\frac{(b_{(k)}-\Delta_{i})\cdot\delta^{4}}{b_{(k)}\cdot\Delta_{i}}-\delta^{6}\right)\cdot T_{k}^{*}-\frac{(b_{(k)}-\Delta_{i})}{b_{(k)}}\cdot\left(\frac{(1+2\cdot\delta)}{b_{i_{(k)}}\delta^{2}}\cdot\sum_{i=1}^{(k-1)}\sqrt{T_{i}}+T_{0}\right)

\displaystyle\geq\left(\frac{(b_{(k)}-\Delta_{i})\cdot\delta^{4}}{b_{(k)}\cdot\Delta_{i}}-\delta^{6}\right)\cdot\left(\frac{1}{\delta^{6}}\cdot\left(\sum_{i=0}^{k-1}\sqrt{T_{i}}+(1+\delta^{2})\cdot T_{0}\right)\right)-\frac{(b_{(k)}-\Delta_{i})}{b_{(k)}}\cdot\left(\frac{(1+2\cdot\delta)}{b_{i_{(k)}}\delta^{2}}\cdot\sum_{i=1}^{(k-1)}\sqrt{T_{i}}+T_{0}\right)

\displaystyle\geq\frac{(b_{(k)}-\Delta_{i})}{b_{(k)}\cdot\Delta_{i}}\cdot\left(\left(\frac{1}{\Delta_{i}\delta^{2}}-\frac{(1+2\cdot\delta)}{b_{i_{(k)}}\delta^{2}}-\frac{b_{(k)}\cdot\Delta_{i}}{(b_{(k)}-\Delta_{i})}\right)\cdot\sum_{i=1}^{(k-1)}\sqrt{T_{i}}+\left(\frac{1}{\delta^{2}}-(1+\delta^{2})\right)\cdot T_{0}\right)\geq 0.

Above, the second inequality holds because of the assumption on
T_{k}^{*}
, the third inequality holds because the factor in multiplication with
T_{0}
is positive and the final inequality holds because
\Delta_{i}>\mathbf{c}(i)>\sqrt{\delta}
and
b_{(k)}>\Delta_{i}+10\cdot\delta
. Since,
T_{k}\leq T_{k}^{*}
, this concludes the proof.
∎
The above lemma immediately implies the following bound on

.

Lemma G.3
.

Conditioned on the event
\bigcap_{p=0}^{k}\mathcal{E}^{p}
, we have
T_{k}\leq\frac{k^{2}\cdot T_{0}}{\delta^{13}}
with probability one.

Proof.

The lemma follows via induction on

. We get
T_{k}\leq\frac{k\cdot(k-1)}{\delta^{2.5}}+\frac{(1+\delta^{2})\cdot T_{0}}{\delta^{6}}\leq\frac{k^{2}\cdot T_{0}}{\delta^{13}}
.
∎

To complete the proof of Theorem
6.1
, we need to show that
\mathop{\mathbf{Pr}}\left[\bigcap_{i=0}^{K}\mathcal{E}^{i}\right]\geq 1-O\left(\poly\left(\frac{1}{\delta}\right)\cdot\exp\left(-\frac{1}{\delta}\right)\right).
Since
K\leq\frac{n}{\delta}
, we have
T_{K}\leq\poly\left(n,\poly\left(\frac{1}{\delta}\right)\right)
which will complete the proof that all modules will be setting prices
\geq\Delta_{i}-\delta
and
\leq\delta_{i}+10\cdot\Delta_{i}
with high probability after
\poly(1/\delta,n)
rounds.

Lemma G.4
.

For small enough
\delta>0
, we have
\mathop{\mathbf{Pr}}\left[\bigcap_{i=1}^{K}\mathcal{E}^{i}\mid\mathcal{E}^{0}\right]\geq 1-O\left(\poly\left(\frac{1}{\delta}\right)\cdot\exp\left(-\frac{1}{\delta}\right)\right).

Proof.

We show via induction that for any
t<K
, we have

\mathop{\mathbf{Pr}}\left[\mathcal{E}^{k}\mid\bigcap_{i=0}^{k-1}\mathcal{E}^{i}\right]\geq 1-\frac{(k^{2}+1)\cdot T_{1}}{\delta^{6}}\cdot\exp\left(-\frac{1}{\delta}\right).

For simplicity of notations, we let
\overline{\mathcal{E}}^{t}:=\bigcap_{i=0}^{t-1}\mathcal{E}^{i}
. We fix
T_{k}^{*}=\frac{k^{2}\cdot T_{0}}{\delta^{13}}
.

\displaystyle\mathop{\mathbf{Pr}}\left[\forall s\geq T_{k}:\bigwedge_{\ell=1}^{k}\mathbf{p}^{s}(i_{(\ell)})<b_{i_{(\ell)}}\mid\overline{\mathcal{E}}^{k}\right]

\displaystyle=\mathop{\mathbf{Pr}}\left[\forall s\geq T_{k}:\mathbf{p}^{s}(i_{(\ell)})<b_{i_{(k)}}\mid\overline{\mathcal{E}}^{k}\right]

\displaystyle=1-\mathop{\mathbf{Pr}}\left[\exists s\geq T_{k}:\mathbf{p}^{s}(i_{(\ell)})\geq b_{i_{(1)}}\mid\overline{\mathcal{E}}^{k}\right]

\displaystyle\geq 1-\sum_{T_{k}\leq s\leq T_{k}^{*}}\mathop{\mathbf{Pr}}\left[\mathbf{p}^{s}(i_{(\ell)})\geq b_{i_{(1)}}\mid\overline{\mathcal{E}}^{k}\right]

\displaystyle+\sum_{s\geq T_{k}^{*}}\mathop{\mathbf{Pr}}\left[\mathbf{p}^{s}(i_{(\ell)})\geq b_{i_{(1)}}\mid\overline{\mathcal{E}}^{k}\right]

\displaystyle\geq 1-T_{K}\cdot\exp\left(-\frac{1}{\delta}\right)-\sum_{s\geq T_{k}^{*}}\exp\left(-\gamma_{s}\cdot\delta^{6}\cdot s\right)

\displaystyle=1-\frac{(K^{2}+1)\cdot T_{0}}{\delta^{13}}\cdot\exp\left(-\frac{1}{\delta}\right)-\sum_{s\geq T_{k}^{*}}\exp\left(-C\cdot\delta^{6}\cdot\sqrt{s}\right)

\displaystyle\geq 1-\frac{2(k^{2}+1)\cdot T_{0}}{\delta^{13}}\cdot\exp\left(-\frac{1}{\sqrt{\delta}}\right).

Above, the first equality holds due to conditioned on the event
\overline{\mathcal{E}}^{k}
, second inequality holds due to union bound, the third inequality holds due to the inequality
\mathop{\mathbf{Pr}}[\mathbf{p}^{s}(i_{(\ell)})<b_{(k)}\mid\overline{\mathcal{E}}^{k}]\geq 1-\exp\left(-\frac{1}{\delta}\right)
for all
s\geq T_{k}
and
T_{k}^{*}\leq\frac{(k^{2}+1)\cdot T_{1}}{\delta^{6}}
. This completes the proof of the claim.
∎

Finally, we need to show that the probability of event
\mathcal{E}^{0}
is exponentially high.

Lower bounding
\mathop{\mathbf{Pr}}[\mathcal{E}^{0}]

To this end, we consider the following event

\mathcal{F}^{0}:=\left\{\forall i\in S_{\mathbf{\overline{p}}}:\text{$\Delta_{i}$ gets selected for $\leq\frac{T_{0}}{\delta^{16}}$ from first $\frac{T_{0}}{\delta^{20}}\cdot(1+\delta^{18}\cdot(1-5\delta))$ rounds}\right\}.

We let
\frac{T_{0}}{\delta^{\ell_{i}}}
be the number of times module
i
gets selected at price
\Delta_{i}
. We let
T^{\prime}_{i}=\frac{T_{0}\cdot\Delta_{i}}{\delta^{\ell_{i}+4}}\cdot(1+\delta^{\ell_{i}+2}\cdot(1-5\delta))
. We note that
\ell_{i}
is a random variable.

Note that once we conditioned on
\mathcal{F}^{0}
, we set
T_{i}=T_{i}^{*}=\frac{T_{0}\cdot\Delta_{i}}{\delta^{\ell_{i}+4}}\cdot(1+\delta^{\ell_{i}+2}\cdot(1-5\delta))

i\in S_{\mathbf{\overline{p}}}
and price

\displaystyle\sum_{s\leq T^{*}_{k}}(u_{i,s}(\Delta_{i},\mathbf{p}^{s}_{-i})-u_{i,s}(p,\mathbf{p}^{s}_{-i}))\geq\frac{(p-\Delta_{i})\cdot\delta^{4}}{p\cdot\Delta_{i}}\cdot(T_{k}^{*}-T_{0})-(p-\Delta_{i})\cdot\left(\frac{T_{0}}{\delta^{\ell_{i}}}\right)-(p-\Delta_{i})\cdot\delta^{2}\cdot T_{0}

\displaystyle\geq\frac{(p-\Delta_{i})\cdot\delta^{4}}{p\cdot\Delta_{i}}\cdot\left(\frac{T_{0}\cdot\Delta_{i}}{\delta^{\ell_{i}+4}}\cdot(1+\delta^{\ell_{i}+2}\cdot(1-5\delta))-T_{0}\right)-(p-\Delta_{i})\cdot\left(\frac{T_{0}}{\delta^{\ell_{i}}}\right)-(p-\Delta_{i})\cdot\delta^{2}\cdot T_{0}

\displaystyle\geq\left(\delta^{2}\left(\frac{1-5\delta}{p\cdot\Delta_{i}}\right)-1\right)\cdot T_{0}\geq\delta^{3}\cdot T_{0}

Above, the first inequality follows because
\Delta_{i}
gets selected at most

times and whenever the price by module

is not selected then price

In addition, for any bid
b<\Delta_{i}

\displaystyle\sum_{s\leq T^{*}_{k}}(u_{i,s}(\Delta_{i},\mathbf{p}^{s}_{-i})-u_{i,s}(p,\mathbf{p}^{s}_{-i}))

\displaystyle\geq(\Delta_{i}-p)\cdot\delta^{2}\cdot T_{0}+\frac{(\Delta_{i}-p)\cdot T_{0}}{\delta^{\ell_{i}}}-\frac{(\Delta_{i}-p)\cdot\delta^{4}}{p\cdot\Delta_{i}}\cdot(T_{k}^{*}-T_{0})

\displaystyle\geq(\Delta_{i}-p)\cdot\delta^{2}\cdot T_{0}+\frac{(\Delta_{i}-p)\cdot T_{0}}{\delta^{\ell_{i}}}-\frac{(\Delta_{i}-p)\cdot\delta^{4}}{p\cdot\Delta_{i}}\cdot\frac{T_{0}\cdot\Delta_{i}}{\delta^{\ell_{i}+4}}

\displaystyle=\frac{(p-\Delta_{i})}{\Delta_{i}}\cdot\left(\delta^{8}\cdot(1-5\delta)\right)\cdot T_{0}\geq\delta^{9}\cdot T_{0}.

(G.5)

This leads to the following lemma.

Lemma G.5
.

For
T_{0}\geq\frac{n^{2}}{\delta^{22}}
and conditioned on the event
\mathcal{F}^{0}
, for all the rounds from

to
\frac{T_{0}}{\delta^{6}}(1+\delta^{4}(1-5\delta))+T_{0}

sets prices between
[\Delta_{i}-10\cdot\delta,\Delta_{i}+10\cdot\delta]
with probability

.

Proof.

For any
s\geq T^{\prime}
, we let
\mathcal{H}^{s}(i)
be the event where module
i
submits price from the set
[\mathbf{\overline{p}}(i),\mathbf{\overline{p}}(i)+\sqrt{\delta}]
. Due to Lemma
6.4
,for any

, conditioning on event

\mathbf{\overline{p}}(i)
is accepted at any round

\mathbf{\overline{p}}(i)\sqrt{\delta}
is not accepted at round

\sum_{s\leq t}(u_{i,s}(\mathbf{\overline{p}}(i),\mathbf{p}^{s}_{-i})-u_{i,s}(p,\mathbf{p}^{s}_{-i}))\geq(t-T^{\prime})\cdot\delta+T_{0}\cdot\delta^{9}

This further implies that conditioned on the event
\bigcap_{i}\bigcup_{T^{\prime}\leq t\leq s}\mathcal{H}^{t}(i)
and property of multiplicative weight update algorithm, we have that

\displaystyle\mathop{\mathbf{Pr}}\left[\bigcap_{i}\mathcal{H}^{t}(i)\mid\bigcap_{i}\bigcap_{T^{\prime}<s<t}\mathcal{H}^{s}(i)\right]

\displaystyle\geq 1-2\cdot\frac{n}{\delta}\cdot\exp\left(-\frac{C\cdot(\delta^{9}\cdot T_{0}+\delta(t-T^{\prime})}{\sqrt{t}}\right)

\displaystyle\geq 1-2\cdot\frac{n}{\delta}\cdot\exp\left(-\frac{C\cdot(\frac{n^{2}}{\delta^{13}}+\delta(t-T^{\prime})}{\sqrt{t-T^{\prime}+\frac{n^{2}}{\delta^{22}}}}\right)

\displaystyle\geq 1-2\cdot\frac{n}{\delta}\cdot\exp\left(-C\cdot\left(\frac{n^{2}}{\delta}+\delta\sqrt{(t-T^{\prime})}\right)\right)

Next, via conditional expectations, and assuming

\mathop{\mathbf{Pr}}\left[\bigcap_{i}\bigcap_{s>T^{\prime}}\mathcal{H}^{s}(i)\right]\geq 1-\poly(1/\delta,n)\cdot\exp(-1/\sqrt{\delta}).

∎

On the other hand, when

\mathop{\mathbf{Pr}}\left[\mathcal{E}^{0}\right]>1-\poly(1/\delta,n)\cdot\exp\left(-\frac{1}{\sqrt{\delta}}\right)
