THRAISE: An automated and reproducible web platform for RNA-seq analysis
Authors: Hyeon Ho Heo, Soo-Jong Um
Published: 2025

ABSTRACT
Transcriptome-wide High-throughput RNA-seq Analysis Integrated System is a highly streamlined web platform for RNA-seq analysis that requires no programming expertise. Starting from raw NCBI Sequence Read Archive data, it performs the entire analysis pipeline, which includes quality control, alignment, quantification, differential expression, and functional enrichment using Gene Ontology, Kyoto Encyclopedia of Genes and Genomes, Reactome, and Gene Set Enrichment Analysis. For datasets with limited replicates (n = 1), an alternative workflow is also provided, based on transcripts per million. With real-time monitoring, interactive visualization, and a user-friendly interface, Transcriptome-wide High-throughput RNA-seq Analysis Integrated System enables accessible and reproducible RNA-seq analysis for all researchers.

INTRODUCTION

RNA sequencing (RNA-seq) is a powerful tool for transcriptome-wide gene expression profiling across diverse biological systems (Conesa et al., 2016, Wang et al., 2009). However, RNA-seq data analysis remains technically challenging, involving multiple steps such as data acquisition, quality control, alignment, quantification, and statistical testing, which often require programming skills and access to computational infrastructure. Although several web-based tools such as Galaxy, Basepair, DEApp, and iDEP have been developed to simplify RNA-seq analysis, they remain limited in automation and accessibility (Batut et al., 2021, Ge et al., 2018, Li and Andrade, 2017). Galaxy executes each analysis step separately and requires considerable configuration and parameter specification (Batut et al., 2021), while Basepair, a commercial platform, restricts general user access. DEApp and iDEP cannot perform direct analysis from raw Sequence Read Archive (SRA) files (Ge et al., 2018, Li and Andrade, 2017). To overcome these limitations, Transcriptome-wide High-throughput RNA-seq Analysis Integrated System (THRAISE) was developed to automatically perform data retrieval, alignment, quantification, and functional enrichment directly from NCBI BioProject accessions (Table 1). PLATFORM OVERVIEW

THRAISE is implemented as a web-based platform using Python for the user interface, Bash for task automation, and R for statistical analysis and visualization. It runs on a Linux environment and currently supports human (hg38), mouse (mm39), and Caenorhabditis elegans (ce11) reference genomes from University of California at Santa Cruz (Harris et al., 2014, Raney et al., 2024, Schneider et al., 2017). The platform integrates widely used bioinformatics tools at each step of the RNA-seq pipeline (Fig. 1). Specifically, raw SRA files are retrieved and validated via the SRA Toolkit (Leinonen et al., 2011), trimmed with Trimmomatic (Bolger et al., 2014), and aligned to the selected reference genome using Spliced Transcripts Alignment to a Reference (Dobin et al., 2013). Gene quantification is performed using featureCounts (Liao et al., 2014), followed by differential expression analysis with DESeq2 (Love et al., 2014). For datasets with a single biological replicate (n = 1), THRAISE provides transcripts per million (TPM)-based log₂ fold-change analysis for exploratory purposes only (Wagner et al., 2012). Because TPM values can be affected by batch differences and protocol variability, expression changes inferred from single-replicate data should be interpreted with caution and validated using independent assays. For functional enrichment, THRAISE utilizes clusterProfiler and ReactomePA to conduct Gene Ontology (GO), Kyoto Encyclopedia of Genes and Genomes (KEGG), Reactome, and Gene Set Enrichment Analysis (GSEA) analyses (Subramanian et al., 2005, Yu et al., 2012, Yu and He, 2016). An overview of the tools and their versions is provided in Table 2. Users initiate the analysis by entering BioProject accessions and assigning a custom nickname for result tracking (Fig. 2A). The system retrieves the corresponding SRR samples, from which users can select runs and assign them to experimental groups. Parameters such as reference genome and log₂ fold-change threshold can be adjusted using dropdown menus and input fields (Fig. 2B). Key user-defined parameters are summarized in Table 3. Currently, the log₂ fold-change threshold is the primary adjustable parameter, while other parameters, such as P-value and false discovery rate (FDR) cutoff, remain fixed at DESeq2 settings (P < .05, FDR < 0.1). RESULTS

To assess the performance of THRAISE, we analyzed 6 RNA-seq samples from the NCBI BioProject PRJNA979181 (Li et al., 2023). The platform automatically detects the read type of each sample and performs all processing steps, including trimming, alignment, quantification, and differential expression analysis, without requiring user intervention. Upon completion, users can access results by entering their assigned nickname on the homepage (Fig. 3A). The results interface provides a structured summary and downloadable output files, including TPM-based quantification tables, differentially expressed gene (DEG) lists, GO/KEGG/Reactome enrichment analyses, GSEA outputs, and visualization files (Fig. 3B). A quick preview panel displays key visual outputs, such as heatmaps, Principal Component Analysis plots, DEG tables, and functional enrichment dot plots for GO, KEGG, and Reactome pathways (Fig. 3C). VALIDATION OF THRAISE PERFORMANCE

THRAISE was evaluated using 2 publicly available RNA-seq datasets—including a single-replicate dataset (n = 1, PRJNA229743) and a dataset with biological replicates (n = 3, PRJNA979181) (Loh et al., 2014, Li et al., 2023). Each dataset was analyzed using both the THRAISE pipeline and a manually executed workflow with identical parameters. The DEGs (for the n = 3 dataset) and the TPM-based fold-change rankings (for the n = 1 dataset), as well as the corresponding enrichment results, were highly concordant between the 2 analyses, respectively. In PRJNA979181, CCND1 was identified as significantly regulated, consistent with the original publication, while TBXT (BRACHYURY) and NODAL were also detected in PRJNA229743. The analysis required approximately 2 hours for PRJNA229743 and 4 hours for PRJNA979181, compared with 12 and 20 hours for the manual analyses, respectively. CONCLUSION

THRAISE illustrates the feasibility of integrating a complete RNA-seq analysis workflow into a web-based platform, removing the need for manual setup or programming expertise. By consolidating best-practice tools into a cohesive and scalable framework, it supports consistent and reproducible interpretation of transcriptomic data across diverse studies. Its modular architecture also supports future expansion to additional model organisms, such as zebrafish and Drosophila melanogaster, thereby extending its applicability to comparative and developmental genomics (Adams et al., 2000, Howe et al., 2013). The current THRAISE server can process up to 12 samples concurrently through a managed job queue, with completed results retained for 30 days. Regular maintenance and software updates are scheduled to continuously improve the accessibility, reliability, and long-term stability of the web service. Future versions of THRAISE will allow users to modify additional statistical parameters (eg, P-value, FDR cutoff) for enhanced flexibility in differential expression analysis. As RNA-seq continues to expand in scope, platforms like THRAISE will play a critical role in enabling accessible, standardized, and scalable transcriptomic analysis.
