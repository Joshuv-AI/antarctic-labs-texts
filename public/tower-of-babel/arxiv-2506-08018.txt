KVmix: Gradient-Based Layer Importance-Aware Mixed-Precision Quantization for KV Cache
Fei Li Song Liu Weiguo Wu Shiqiang Nie Jinyu Wang

Abstract
The high memory demands of the Key-Value (KV) Cache during the inference of Large Language Models (LLMs) severely restrict their deployment in resource-constrained platforms. Quantization can effectively alleviate the memory pressure caused by KV Cache. However, existing methods either rely on static one-size-fits-all precision allocation or fail to dynamically prioritize critical KV in long-context tasks, forcing memory-accuracy-throughput tradeoffs. In this work, we propose a novel mixed-precision quantization method for KV Cache named KVmix. KVmix leverages gradient-based importance analysis to evaluate how individual Key and Value projection matrices affect the model loss, enabling layer-specific bit-width allocation for mix-precision quantization. It dynamically prioritizes higher precision for important layers while aggressively quantizing less influential ones, achieving a tunable balance between accuracy and efficiency. KVmix also introduces a dynamic long-context optimization strategy that adaptively keeps full-precision KV pairs for recent pivotal tokens and compresses older ones, achieving high-quality sequence generation with low memory usage. Additionally, KVmix provides efficient low-bit quantization and CUDA kernels to optimize computational overhead. On LLMs such as Llama and Mistral, KVmix achieves near-lossless inference performance with extremely low quantization configuration (Key 2.19bit Value 2.38bit), while delivering a remarkable 4.9× memory compression and a 5.3× speedup in inference throughput.

Introduction

Large Language Models (LLMs)
[
1
]
, such as GPT
[
2
]
, Llama
[

]
, and their derivatives, have significantly advanced the field of Natural Language Processing (NLP). These models exhibit outstanding performance
[
4
,
5
]
across a diverse array of tasks, including text generation, question answering, and machine translation. The Key-Value (KV) Cache plays an essential role in the autoregressive decoding process of LLMs. The KV Cache substantially reduces redundant computations in the attention mechanism by storing Key and Value states from preceding time steps for subsequent token generation, thereby significantly accelerating inference efficiency
[
6
]
. Nevertheless, as sequence lengths grow, the memory footprint of the KV Cache increases linearly, presenting a formidable challenge to hardware resources. For example, a model with 70 billion parameters may demand over 50GB of memory to maintain the KV Cache when generating a sequence of 20k tokens—a requirement that far exceeds the memory capacity of typical GPUs. In scenarios involving multiple concurrent requests, the KV Cache for each request cannot be shared due to its dependence on unique preceding prompts. Although model parameters can be reused, memory quickly becomes saturated due to the extensive KV Cache demands. Once memory is depleted, data is offloaded to system memory or even disks, resulting in frequent High Bandwidth Memory (HBM) exchanges with system memory. This process causes latency to surge exponentially, leading to catastrophic performance degradation.

The characteristics of the KV Cache outlined above severely restrict the practical deployment and inference efficiency of LLMs in resource-constrained environments, highlighting the pressing need for efficient memory optimization strategies
[
7
,
8
]
. In recent years, research tackling this issue has predominantly focused on reducing the memory overhead of the KV Cache through quantization and sparsification techniques
[
9
,
10
,
11
]
. Quantization methods, in particular, have gained widespread adoption in industry, significantly contributing to the scalability and accessibility of large-scale models
[
12
]
. By quantizing the KV Cache, memory usage can be markedly reduced—for instance, transitioning from FP16 to INT8 halves memory requirements while accelerating memory access and improving throughput. Existing quantization methods have demonstrated impressive model performance even at very low bit-widths. However, these methods either rely on static one-size-fits-all precision allocation schemes
[
13
,
14
]
, lacking flexibility and performance-aware adaptation capabilities, or suffer from the high computational overhead of dynamic quantization while failing to adaptively prioritize critical KV pairs in long-context tasks
[
15
,
16
]
. Therefore, they are forced to make suboptimal trade-offs among memory usage, model accuracy, and computational throughput.

To address these problems, this paper proposes KVmix, a novel mixed-precision quantization method for KV Cache. KVmix evaluates KV importance using gradient norms of Key and Value projection weights relative to the model’s loss function, enabling layer-specific mixed-precision quantization with flexible bit-width allocation. It proposes a dynamic long-context optimization strategy, keeping full-precision KV pairs for recent pivotal tokens while compressing older pairs. Additionally, KVmix offers low-bit compression strategies and efficient CUDA implementations. KVmix maximizes KV Cache compression and model throughput while maintaining controlled precision. Our specific contributions are as follows:

•

We propose a novel layer importance-aware mixed-precision quantization method. This method assesses the importance of KVs at each layer by computing the
L2
gradient norms of Key and Value projection weights with respect to the model’s loss function. Based thereon, it independently applies mixed-precision quantization to different layers, allocating higher bit-widths to critical layers and lower to less influential ones. Therefore, it provides the flexibility to balance between accuracy and resource efficiency across diverse inference scenarios.

•

We propose a dynamic pivotal context selection strategy to optimize long-context tasks. According to the KV importance analysis, it adaptively keeps full-precision KV pairs for recent pivotal tokens while aggressively compressing older pairs. This strategy ensures high-quality sequence generation in long-context inference scenarios while dynamically reducing the number of full-precision KV pairs for better memory optimization.

•

We design efficient CUDA implementations and a high-compression 3-bit quantization method for KVmix. Extensive experimental results show that KVmix achieves nearly lossless model accuracy across multiple LLMs and datasets, as well as a 4.9
\times
reduction in runtime memory usage and a 5.3
\times
speedup in inference efficiency, outperforming prior state-of-the-art (SOTA) quantization methods for KV Cache.

Related Work and Motivation

2.1
Related Work

To mitigate the memory challenges associated with KV Cache, researchers have developed a variety of optimization approaches, primarily centered on compression techniques and dynamic memory management
[
17
,
18
]
. We mainly discuss the KV Cache compression techniques related to this work. Existing compression approaches encompass quantization, sparsification, and KV Cache sharing
[
19
,
20
,
21
]
.

Extensive research has focused on reducing the memory overhead of KV Cache through quantization. For example, KIVI
[
13
]
introduced a 2-bit asymmetric quantization technique, employing per-channel quantization for Keys and per-token quantization for Values. This method substantially improves model throughput while preserving accuracy at low bit-widths. KVQuant
[
22
]
proposed a non-uniform quantization strategy, integrating pre-RoPE per-channel Key quantization with per-token Value quantization. It employs offline calibration to manage outliers, achieving robust performance in long-context inference scenarios. QAQ
[
15
]
developed a dynamic mixed-precision quantization method that calculates quantization bits for Keys and Values online and optimizes the trade-off between accuracy and compression ratio by predicting attention scores. Atom
[
23
]
investigated a mixed-precision scheme involving 4-bit and 8-bit activations, dynamically quantizing activations to adapt to input distributions. SKVQ
[
16
]
implemented a sliding window quantization method, maintaining high precision for recent KV pairs while reducing quantization errors through channel reordering. IntactKV
[
14
]
simplified the quantization process by preserving critical tokens (e.g., initial tokens) with full precision, thereby sustaining generation quality. WKVQuant
[
24
]
further compressed the KV Cache by incorporating weight quantization. Numerous other studies have also made significant contributions to KV Cache quantization
[
25
,
26
,
27
]
. These efforts generally aim to quantize as many KVs as possible to the lowest feasible bit-width. While methods such as KVQuant, QAQ, and Atom have introduced mixed-precision quantization for KV, their primary focus is on addressing outliers that are sensitive to precision changes. In contrast, this work proposes a more flexible quantization framework, enabling users to balance average quantization bit-width and model accuracy during deployment based on their specific needs.

In addition to quantization, sparsification techniques have been widely used to optimize KV Cache. These approaches typically leverage importance assessments derived from the attention weight to dynamically adjust KV storage requirements. H2O
[
28
]
introduced a resampling-based strategy that retains KV entries with high attention scores for efficient memory compression. Scissorhands
[
29
]
capitalized on the "importance persistence" hypothesis to dynamically evict low-importance KVs, which further improves sparsification efficiency. SnapKV
[
30
]
employed predictive modeling of future attention patterns to preemptively discard irrelevant KV entries, while PyramidInfer
[
31
]
extended H2O by recognizing that the number of critical KV entries diminishes with increasing model depth, progressively increasing sparsification across layers. We observe that evicting KV from shallow layers propagates the effect to deeper layers through hidden states. Unlike PyramidInfer, we use the contribution of KV to the model output to evaluate the importance of different layers. Our method is orthogonal to existing sparsification methods and can also be used as a guideline for KV sparsification to achieve more accurate KV eviction.

2.2
Motivation

Current KV Cache quantization methods depend on fixed quantization strategies, which uniformly apply the same bit-width to the Keys or Values across all layers of a model. These methods fail to account for the differing contributions of Keys and Values from various layers to the final output. For each layer of the KV Cache, the computation process is outlined as follows: at time step
t
and for the
i
-th layer, the input comprises hidden states (denoted as
H_{i-1,t}
), which are supplied by the output of the preceding layer. These hidden states are then utilized to compute the K and V for the current token:
K_{i,t}=W_{k_{i}}\cdot H_{i-1,t}
and
V_{i,t}=W_{v_{i}}\cdot H_{i-1,t}
, where
W_{k_{i}}
and
W_{v_{i}}
represent the projection weights for the K and V, respectively, at the
i
-th layer. Subsequently, the computed
K_{i,t}
and
V_{i,t}
are concatenated with the previously stored KV Cache, yielding the complete K and V sequences up to time step
t
:
K_{i,1:t}=[K_{i,1},K_{i,2},\dots,K_{i,t}]
and
V_{i,1:t}=[V_{i,1},V_{i,2},\dots,V_{i,t}]
. This computation process reveals that the projection weights
W_{k_{i}}
and
W_{v_{i}}
determine how the model extracts K and V information from the hidden states. These weights directly influence the quality of the KV generated within the attention mechanism, thereby forming the foundation of the layer’s computation. As a result, the weights of the KV affect the layer’s contribution to the model’s overall output.

To substantiate this analysis, Fig.
1
provides heatmaps of the projection weights
W_{k}
and
W_{v}
for the Llama 2-7B model
[
32
]
, with additional heatmaps for other models included in Appendix
A
. Examination of these heatmaps yields two critical insights: ①
There is considerable variation in the weight values of KV across different layers of the model.
②
Within the same layer, the Key and Value weights display distinct distributional patterns
. These observations highlight the fact that the influence of Keys and Values from different layers on the model’s final output is not uniform.

3
Methodology

3.1
KV Importance Analysis

In the self-attention mechanism, the Key and Value are computed by applying linear transformations to the hidden states of the previous layer using KV projection weight matrices and are subsequently combined with the Query to compute the attention output. Consequently, the magnitude of KV projection weights alone is insufficient to measure the importance of the Key and Value of each layer, and a more precise evaluation metric is needed. To address this problem, we propose the KVmix profiler, a gradient-based method that quantifies the contribution of each layer’s Key and Value to the model’s output, enabling a judicious mixed-precision quantization strategy. Specifically, we compute the
L2
norm of the gradients of the model’s loss function with respect to the Key and Value projection weight matrices for each model layer, and evaluate the importance of the Key and Value components based on these
L2
norm values. KVmix profiler captures the dynamic sensitivity of these parameters during the model inference process, and provides a layer-specific importance metric to support efficient mixed-precision quantization in subsequent inference stages.

The implementation of KVmix profiler consists of the following three key steps:
① Data preparation and forward propagation
. A full-precision model is loaded, and multiple prompts are randomly sampled from a target dataset to serve as input data. These prompts are tokenized into input tensors using the tokenizer. Leveraging the autoregressive property of LLMs, each input tensor is shifted left by one position to be used as the corresponding label tensor for computing the model’s loss function. Subsequently, the loss value for each input is determined through forward propagation.
② Gradient calculation and importance assessment
. For the
i
-layer of the model, the gradients of the losses with respect to the projection weights of the Key (
W_{k_{i}}
) and Value (
W_{v_{i}}
) are computed independently. This process begins with backpropagation to calculate the gradients, i.e.,
\nabla_{W_{k_{i}}}\mathcal{L}
and
\nabla_{W_{v_{i}}}\mathcal{L}
, where
\mathcal{L}
represents the loss function. The magnitude of these gradients is then evaluated using the
L2
norm, i.e.,
\|\nabla_{W_{k_{i}}}\mathcal{L}\|_{2}
and
\|\nabla_{W_{v_{i}}}\mathcal{L}\|_{2}
. The importance scores of the Keys and Values for each layer can be expressed as:

s_{k_{i}}=\|\nabla_{W_{k_{i}}}\mathcal{L}\|_{2},s_{v_{i}}=\|\nabla_{W_{v_{i}}}\mathcal{L}\|_{2}

(1)

A larger
s_{k_{i}}
or
s_{v_{i}}
signifies a greater impact of that
i
-th layer’s Key or Value on model’s output. To enhance assessment reliability, the gradient norms can be averaged across multiple prompts (
p
), yielding an average importance score for each layer’s Key and Value:

\bar{s}_{k_{i}}=\frac{1}{P}\sum_{p=1}^{P}s_{k_{i}}^{(p)},\bar{s}_{v_{i}}=\frac{1}{P}\sum_{p=1}^{P}s_{v_{i}}^{(p)}

(2)

Using the importance scores, we classify the importance of the Key and Value components across all model layers. The top 20% of the layers of
\bar{s}_{k_{i}}
and
\bar{s}_{v_{i}}
are quantized with high-bit representations (e.g., 3-bit or 4-bit), while the remaining 80% of layers adopt more aggressive low-bit quantization (e.g., 2-bit). This 20%-80% split is not fixed and can be dynamically adjusted according to the requirements to balance the trade-off between model accuracy and memory usage. Increasing the proportion of low-bit quantization layers can further reduce the memory footprint of the KV Cache, but may sacrifice some accuracy.
③Model Configuration and Inference
. The KV quantization configuration results derived from the above steps are incorporated into the model configuration, enabling the quantized model to be used for inference. The detailed workflow is depicted in Fig.
2
, with the algorithmic procedure outlined in Algorithm
B
of Appendix
B
. The profiling is performed offline and therefore does not affect the inference efficiency. In addition, it is once-and-for-all for the inference of the model.

3.2
Asymmetric Low-Bit Quantization

Asymmetric Quantization Strategy
. We use per-channel and per-token grouping quantization methods for Key and Value, respectively. The KV Cache has the shape
[B,nh,T,D]
, where
B
is the batch size,
nh
is the number of attention heads,
T
is the token sequence length, and
D
is the head dimension. When the Key is quantized per channel (
D
), the tensor is reshaped to
[B\times nh\times D,T]
, with each group comprising all tokens of a single channel. This approach is inspired by the distributional properties of the Key Cache that exhibit significant outliers in the channel dimension, i.e., certain channels exhibit significantly large magnitude values. Per-channel quantization isolates errors within each channel and prevents outliers from affecting other channels. When Value is quantized per token, the shape of the tensor is preserved, and each group contains all channels of a single token. Unlike the Key Cache, the Value Cache has no pronounced outliers, but plays a critical role in computing the attention output. Per-token quantization confines errors to individual tokens, preserving the integrity of other important tokens. This asymmetric quantization strategy effectively reduces errors introduced during KV Cache quantization.

Group-Wise Low-Bit Quantization
. To minimize the memory usage of the quantized KV Cache, we apply group-wise lowest possible bit quantization for KV. The quantization process is detailed as follows: ① Calculation of scaling factor. The input elements are divided into groups based on the asymmetric quantization strategy (e.g., per-channel for Key or per-token for Value). For each group, we first determine the minimum (
min\_val
) and maximum (
max\_val
) values. The scaling factor
s
is then calculated as:
s=\frac{max\_val-min\_val}{q_{max}}
, where
q_{max}
denotes the maximum quantized value. ② Element quantization. Each element is quantized using:
q=round\left(\frac{x-min\_val}{s}\right)
, where
x
represents the original element value, and
q
is the quantized value. ③ Clipping of quantized values. The quantized values are constrained to the range
[0,q_{max}]
through clipping:
q=\max(0,\min(q,{q_{max}}))
. ④ Storage and dequantization. The quantized values are stored using bit operations within a 32-bit integer (
int32
). For 4-bit, 2-bit, and 1-bit quantization, the number of elements in per
int32
is:
feat\_per\_int=32/bit
. During inference, dequantization is performed using:
x=q\cdot s+min\_val
.

For 3-bit quantization
, we introduce a new packing strategy to maximize memory efficiency. We organize the quantized elements into blocks of 11, each stored in a 32-bit integer, with the first 10 elements quantized to 3 bits and the 11th element to 2 bits. The clipping range is adjusted based on the element index:

q_{max}=\begin{cases}7,&i=0,1,...,9\\
3,&i=10\end{cases}

(3)

where
i
is the element index within a block. This method provides a 10% increase in packing density compared to a uniform 3-bit quantization that can only hold 10 elements per
int32
.

3.3
Dynamic Pivotal Context Selection

In the KV Cache, not all Keys and Values are equally important for generating future tokens. Recent tokens provide the most relevant contextual information for the generation of subsequent tokens, and usually have more impact on the upcoming tokens. We define the Keys and Values corresponding to these pivotal recent tokens as the Recent Pivotal Context (RPC). To optimize model performance while minimizing memory usage, we propose a dynamic RPC selection strategy based on the importance analysis provided by KVmix profiler. Specifically, for the
i
-layer, we assign it an RPC selection ratio
r
based on the
\bar{s}_{k_{i}}
and
\bar{s}_{v_{i}}
scores, with higher
\bar{s}_{k_{i}}
and
\bar{s}_{v_{i}}
resulting in larger
r
. The number of RPCs is computed by
num\_RPC=\lfloor r\times current\_RPC\rfloor
.
current\_RPC
is the sum of the number of new Key and Value states at current time step and the number of historical RPCs.

Figure 3:
Dynamic adjustment process of KV Cache quantization in the prefill and decoder phases.

The corresponding number of KV pairs is selected as RPCs based on
num\_RPC
. We keep full precision for the RPCs while performing the mixed quantization for the less critical and older KV pairs. This strategy ensures that the number of full-precision RPCs is dynamically reduced in real-time during long context inference, thus avoiding excessive memory pressure caused by preserving a large number of full-precision KV pairs, while maintaining high-quality sequence generation. In addition, since the importance of Keys and Values may differ within the same layer, the RPC selection ratio for Keys and Values varies within that layer. The RPC selection ratio can be adjusted to provide flexibility in the dynamic balance between inference accuracy and memory usage.

3.4
CUDA Implementation

During model inference, the quantization of the KV Cache introduces additional overhead from quantization and dequantization operations. To mitigate this overhead and enhance inference efficiency, we design efficient CUDA kernels for quantization, dequantization, and matrix-vector multiplication.
① Fusion of quantization and concatenation in the decoding phase
. In the decoding phase, the Key states and Value states of the current layer need to be concatenated with the historical KV Cache. Directly quantizing the current states before concatenation incurs additional memory access overhead. Therefore, we fuse the quantization process with the concatenation operation into a single CUDA kernel. Specifically, the kernel processes each element in a streaming manner: each element of the Key states and Value states is quantized and immediately appended to the quantized historical KV Cache, which reduces memory access overhead. We also leverage CUDA thread blocks to process data from different tokens in parallel and utilize shared memory to cache intermediate results, further improving data locality.
② Fusion of dequantization and matrix-vector multiplication in attention computation
. During attention computation, the quantized KV Cache must be dequantized before performing matrix-vector multiplication. Dequantizing the entire KV Cache prior to multiplication increases memory usage. To mitigate this issue, we fuse dequantization with matrix-vector multiplication. Specifically, each element is dequantized and immediately multiplied and accumulated with its corresponding element, minimizing additional memory overhead.
③ Efficient kernels for multi-bit quantization configurations
. To support the various quantization bit-widths of KVmix, we develop efficient CUDA kernels for 1-bit, 2-bit, 3-bit, and 4-bit quantization. Additionally, we implement customized matrix-vector multiplication kernels for each quantization configuration, ensuring compatibility with varying bit-widths.

Long Context

4.4
Inference Efficiency and Memory Usage Evaluation

We evaluated the inference throughput and memory usage of KVmix during inference on an NVIDIA RTX 4090 GPU (24GB). To ensure a fair comparison, we applied identical input data across all evaluated methods. The number of input tokens is 688, the maximum number of new tokens is set to 1024, and the model is Llama 2-7B-hf. We compared KVmix against the methods optimized for memory and throughput: KIVI
[
13
]
with 2-bit quantization (full precision residual of 64) and Atom
[
23
]
with 4-bit quantization. Memory usage results are illustrated in Fig.
6
, with a batch size fixed at 4. The reported memory usage represents the dynamic peak memory consumption during inference minus the memory occupied by the model before inference. To fully utilize the GPU memory, we incrementally increased the batch size to explore KVmix’s maximum inference throughput. The throughput results are shown in Fig.
6
. The baseline (FP16), Aotm-4bit, and KIVI-2bit-r64 reach out of memory at batch sizes of 4, 18, and 28, respectively, while the KVmix-k2.19v2.38 can reach a maximum batch size of 30 with an inference throughput of 1032 tokens per second.

The results reveal that KVmix-k2.19v2.38 achieves a 4.9
\times
reduction in inference runtime memory usage and up to a 5.3
\times
increase in throughput compared to the baseline. This efficient memory compression stems from KVmix’s extremely low bit quantization and dynamic RPC strategy, which progressively reduces the full-precision KV Cache as inference progresses. In contrast, KIVI employs a fixed full-precision residual strategy, unable to dynamically reduce the number of full-precision KVs. Thus, KVmix saves more memory than KIVI’s 2-bit quantization despite using Key-2.19 and Value-2.38 bit configuration. Meanwhile, Atom-4bit quantizes both model weights and activations while utilizing Tensor Cores for optimized kernel execution, achieving a higher throughput at the same batch size but incurring greater model accuracy degradation, for example, it has an average accuracy loss of nearly 10% using the Llama 2-7B-hf model on the Wikitext-2 dataset.

Conclusion

This paper addresses the memory bottleneck issue posed by the KV Cache during the inference of LLMs by proposing a novel mixed quantization method, KVmix. KVmix achieves layer importance-aware mixed-precision quantization by leveraging KV weight gradients. It also provides dynamic long-context optimization to reduce memory usage while preserving generation quality. Experiments show that KVmix, with an average of 2.19 bits for Keys and 2.38 bits for Values, reduces inference memory usage by 4.9
\times
and increases throughput by 5.3
\times
, while maintaining near-lossless inference quality. KVmix offers flexibility and ease of use, enabling the adjustment of quantization strategies based on specific application scenarios, thus effectively balancing model accuracy, inference efficiency, and memory usage. However, it has not yet achieved real-time mixed quantization during inference. Future work will explore lightweight mechanisms for real-time bit adjustments in mixed-precision quantization, enabling KVmix to dynamically respond to changing inference demands while maintaining efficiency.
