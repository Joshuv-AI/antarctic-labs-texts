When Many Trees Go to War
Mathias Weller, Norbert Zeh

Abstract
It is known that any two trees on the same n n leaves can be displayed by a network with n − 2 n-2 reticulations, and there are two trees that cannot be displayed by a network with fewer reticulations. But how many reticulations are needed to display multiple trees? For any set of t t trees on n n leaves, there is a trivial network with ( t − 1 ) ​ n (t-1)n reticulations that displays them. To do better, we have to exploit common structure of the trees to embed non-trivial subtrees of different trees into the same part of the network. In this paper, we show that for t ∈ o ⁡ ( log ⁡ n ) t\in o\left(\sqrt{\log n}\right) , there is a set of t t trees with virtually no common structure that could be exploited. More precisely, we show for any t ∈ o ⁡ ( log ⁡ n ) t\in o\left(\sqrt{\log n}\right) , there are t t trees such that any network displaying them has ( t − 1 ) ​ n − o ⁡ ( n ) (t-1)n-o(n) reticulations. For t ∈ o ⁡ ( log ⁡ n ) t\in o(\log n) , we obtain a slightly weaker bound. We also prove that already for t = c ​ log ⁡ n t=c\log n , for any constant c > 0 c>0 , there is a set of t t trees that cannot be displayed by a network with o ⁡ ( n ​ log ⁡ n ) o(n\log n) reticulations, matching up to constant factors the known upper bound of O ⁡ ( n ​ log ⁡ n ) O(n\log n) reticulations sufficient to display all trees with n n leaves. These results are based on simple counting arguments and extend to unrooted networks and trees.

Introduction

Phylogenetics is the study of evolutionary relationships among a set of taxa,
typically represented using tree-like structures that depict patterns of
descent from common ancestors.
Traditionally, these relationships have been modelled with phylogenetic trees,
which are rooted or unrooted trees whose leaves correspond to present-day taxa
and whose internal nodes represent ancestral lineages
[
20
]
.
However, due to processes such as hybridization, horizontal gene transfer, and
recombination, tree models often fail to capture the full complexity of
evolutionary histories
[
10
,
18
,
9
,
1
]
. This has led to the
development of phylogenetic networks, which are graphical models that
generalize trees by allowing for “reticulate” (non-tree-like)
events
[
13
,
19
]
.

Both rooted and unrooted versions of trees and networks are considered in
practice, depending on the data and the biological questions at hand. Rooted
structures incorporate ancestral/temporal directionality, which is important
for inferring evolutionary pathways, while unrooted structures are often used
when such directionality is unknown or when analyzing symmetric distance
data
[
21
,
14
]
.

A central concept in the analysis of phylogenetic networks is that of a network
“displaying” a tree: informally, a network displays a tree if the tree can be
embedded in the network in a way that respects its topology
[
13
]
. A
formal definition will be given in
section

2
.
This notion is at the heart of computational problems in phylogenetics like
comparing phylogenies or parsimoniously reconstructing networks
[
6
]
.
Indeed, the computational problems Tree Containment (decide whether a
given tree is embeddable into a given network)
[
15
,
22
,
8
,
12
,
11
,
26
]
and Hybridization Number (construct a smallest
network displaying all given
trees)
[
3
,
2
,
7
,
25
,
16
]

have been studied extensively.

There is a trivial network that displays any set of
t
trees without
exploiting any common structure (see
fig.

1
).
This network is obtained by simply

1.

taking the disjoint union of the
t
trees,

2.

adding a tree “cap” that joins the roots of the trees under a common root and, finally,

3.

adding reticulations to “merge” all copies of each leaf in the different trees.

This network has
(t-1)n
reticulations and conveys absolutely no information
about the similaries between the
t
trees.
In general, this is far from the minimum number of reticulations necessary to
display a set of trees: if multiple input trees share subtrees with the same
topology, then these subtrees can be embedded into the same part of the
network, which may allow us to save reticulations. An interesting question
then is whether there exist sets of trees with little enough common structure
to make the trivial network essentially the best possible.

\Citet

BSS05 answered this question in the affirmative for
t=2
, by showing
that there are two
n
-caterpillars requiring
n-2
reticulations.

Recently,
[
24
]
proved that even displaying
3
caterpillars without
restrictions on the type of network may require
(\nicefrac{{3}}{{2}}-o(1))n
reticulations. This left open the possibility that the number of
reticulations required to display
t
trees depends sublinearly on
t
, and
they explicity pose the general case of
t
trees as an open question. This
paper settles this question by showing that the dependence on
t
is linear
after all.

Another known special case is
t=(2n-3)!!
, that is, how many reticulations are
necessary to display
all
trees on the same
n
leaves?
\Citet
BS18
showed that this number is in
\Theta(n\log n)
even for tree-based networks,
but the
\Omega(n\log n)
lower bound is derived via a simple counting argument
applied to any type of network.
In this paper, we generalize this counting argument to the case of
t
trees.
We show that for
t\in o(\log n)
, there is a set of
t
trees for which the
trivial network (see
Figure

1
) is asymptotically optimal, in
the sense that there are
t
trees that cannot be displayed by a network with
fewer than
(t-1)n-o(tn)
reticulations. For
t\in o\left(\sqrt{\log n}\right)
, we
obtain the slightly stronger result that there are
t
trees that cannot be
displayed by a network with fewer than
(t-1)n-o(n)
reticulations.
Thus, we conclude that the trivial network is indeed
asymptotically

optimal in the worst case for displaying
t
trees.
The proof of these two results also shows that, for any constant
c>0
, there
is a set of
c\log n
trees that cannot be displayed by a network with
o(n\log n)
reticulations. One way to interpret this result is that “most” of
the reticulations in the
\Theta(n\log n)
-reticulation network of
[
5
]

that displays all trees on
n
leaves are caused by a small subset of only

O(\log n)
trees, and adding the remaining exponentially many trees increases
the number of reticulations necessary to display these trees by only
a constant factor.

As the results by
[
5
,
24
,
3
]
show, the question of how many
reticulations are necessary to display a set of
t
trees has been the focus of
previous work and is interesting in its own right. Our interest in this
question stems from its connection to cluster reduction. Cluster reduction is
a technique that has been verified experimentally to be the most important
technique for computing maximum agreement forests of two trees
efficiently
[
17
]
. Before this experimental study,
[
4
]
proved
that it can also be used to reduce the complexity of finding a network with the
minimum number of reticulations that displays two trees, owing to the fact that,
for two trees, computing such a network is equivalent to computing a particular
type of agreement forest
[
6
]
. We say that cluster reduction is
“safe” for two trees. But what happens for more than two trees? This
question is studied in
[
23
]
. One of the main results of that paper is
that cluster reduction fails to be safe for four or more trees, that is, the
use of cluster reduction may result in computing a network with more than the
minimum number of reticulations. The proof is via a reduction that starts with
a set of trees that require many reticulations to display and constructs from
it a new set of trees for which cluster reduction fails. This proof relies
directly on the results shown in this paper.

Preliminaries

An
unrooted phylogenetic network

N^{\text{u}}
(
unrooted network

for short) is a connected graph whose degree-one nodes (called
leaves
)
have unique labels and whose non-leaf nodes have degree at least
3
and are
unlabelled. If
N^{\text{u}}
does not contain cycles, then we
call
N^{\text{u}}
an unrooted phylogenetic tree (
unrooted tree
for
short). If the maximum degree in
N^{\text{u}}
is at most three, then we call

N^{\text{u}}

binary
.
A
rooted phylogenetic network

(
network
for short) is a
directed acyclic graph with a single source, called the
root
.
Its out-degree-
0
nodes, called
leaves
, have unique labels and
its non-leaf, non-root nodes are unlabelled and either have
in-degree
1
and out-degree at least
2
(
tree nodes
) or
out-degree
1
and in-degree at least
2
(
reticulations
).
If
N
has no reticulations, it is called a
rooted phylogenetic tree

(
tree
for short).
If both the maximum in-degree and the maximum out-degree of
N
are at most two,
then
N
is called
binary
.
We use
V(N)
,
E(N)
, and
\mathcal{L}(N)
to refer to the nodes, edges, and
leaves of a network
N
, respectively.
If
(u,v)
is an edge of
N
, then
u
is called a
parent
of
v
in
N

and
v
is called a
child
of
u
in
N
.
Similarly,
(u,v)
is called a
parent edge
of any edge
(v,w)

outgoing from
v
and
(v,w)
is called a
child edge
of
(u,v)
.

Throughout this paper, we will work with labellings of vertices and edges of
networks, which are mappings from the vertex or edge set of the network to some
label set
X
. When only a subset of the vertices or edges is labelled, we
extend this to a labelling of all vertices or edges by assigning the special
label
\bot
to unlabelled edges or vertices. Accordingly, we call the
vertices or edges with label
\bot

unlabelled
. For two mappings
\phi,\psi:A\to B
with
\bot\in B
, we say that
\psi

extends

\phi
,
or
\psi
is an
extension
of
\phi
, if
\psi(a)=\phi(a)
whenever

\phi(a)\neq\bot
. In other words,
\psi
may label more elements than
\phi

does but
\phi
and
\psi
agree on the labels of all elements that
\phi
does
label. Viewing
\phi
and
\psi
as relations, this implies that
\phi\setminus(A\times\{\bot\})\subseteq\psi\setminus(A\times\{\bot\})
.
Therefore, we write
\phi\subseteq\psi
whenever
\psi
is an extension of

\phi
.

We assume that all networks (rooted and unrooted) have their leaves labelled
with the integers
1
to
n
, where
n
is the number of leaves.
We use
[n]
to refer to the set
\{1,\ldots,n\}
.

A
graph isomorpism

\phi:G_{1}\to G_{2}
is a pair of isomorphisms

\phi_{V}:V(G_{1})\to V(G_{2})
and
\phi_{E}:E(G_{1})\to E(G_{2})
such that for

(u,v)\in E(G_{1})
,
\phi_{E}((u,v))=(\phi_{V}(u),\phi_{V}(v))
.
A

is a triple
(G,\lambda_{V},\lambda_{E})
, where
G
is a
graph,
\lambda_{V}:V(G)\to X
is a function assigning labels to the vertices
of
G
, and

G
.
An isomorphism between labelled graphs

is
a graph isomorphism
\phi:G\to G^{\prime}
with the added conditions

\lambda_{V}(v)=\lambda_{V}^{\prime}(\phi_{V}(v))

,
and
\lambda_{E}(e)=\lambda_{E}^{\prime}(\phi_{E}(e))

.
Throughout this paper, we consider isomorphic graphs to be the same graph.

A

of a (rooted or unrooted) tree

obtained by replacing each edge

with a path

If

.
Note that such a subdivision

.

A (rooted or unrooted) network

that is (isomorphic to) a subdivision of

.

Counting Rooted Trees and Networks

Our proof that some sets of trees cannot be displayed by networks with few
reticulations uses a simple counting argument.
First, we count the number of sets of
t
trees on
n
leaves.
Then, given some integer
r
, we count how many such sets can be displayed by any one network with at most
r
reticulations.
If
r
is the smallest integer such that each set of
t
trees on
n
leaves can be displayed by some network with
r
reticulations,
then there is a set of
t
trees on
n
leaves that cannot be displayed by a network with fewer than
r
reticulations.
Our goal in this paper is to obtain lower bounds on this number

.
We present the proof for rooted trees and networks in this section and consider the unrooted case in the next section.

.

n

|\mathcal{N}_{n,r}|\leq\frac{(2n+4r-3)!!}{r!}\leq n!\cdot(r-1)!\cdot 2^{2n+6r-3}

We refer to the networks in
\mathcal{N}_{n,r}

.
Since
\phi:(N,\lambda_{L})\to(N,\lambda_{L})
is an isomorphism,
it respects the labels of all leaves in
N
.
Therefore,
\phi(x)=x
for all
x\in\mathcal{L}(N)
,
so
v
is not a leaf of
N
.
Let
w
be a child of
v
.
If
w
has a single parent edge
e
, then
\phi(w)=w
as
\phi
is an isomorphism, so
\phi(e)=e
.
If
w
has two parent edges
e_{1}
and
e_{2}
, then
\lambda_{E}(e_{1})\neq\lambda_{E}(e_{2})
since
\lambda_{E}
is a reticulation labelling
(one of
\lambda_{E}(e_{1})
and
\lambda_{E}(e_{2})
is zero; the other, non-zero).
Since
\phi(w)=w
and
\phi
respects edge labels,
\phi(e_{1})=e_{1}
and
\phi(e_{2})=e_{2}
.
This shows that no matter whether
w
has one or two parents, we have
\phi(e)=e
,
for every parent edge
e
of
w
.
If we choose
e
to be the parent edge whose top endpoint is
v
,
then this implies that
\phi(v)=v
, contradicting our assumption.
Therefore,
\phi=1_{N}
and
\langle N,\lambda_{L},\lambda_{E}\rangle=\langle N^{\prime},\lambda_{L}^{\prime},\lambda_{E}^{\prime}\rangle
.

\lrcorner

Having shown (a) and (b), the proposition follows from

\displaystyle|\mathcal{N}_{n,r}|

\displaystyle\stackrel{{\scriptstyle\text{(a),(b)}}}{{\leq}}\frac{|\mathcal{T}_{n+2r}|}{r!}=\frac{(2n+4r-3)!!}{r!}

\displaystyle\stackrel{{\scriptstyle\text{Obs.~\ref{obs:double-fac-eq}}}}{{=}}\frac{(2n+4r-2)!}{2^{n+2r-1}(n+2r-1)!r!}\stackrel{{\scriptstyle\text{Obs.~\ref{obs:binom-bound}}}}{{\leq}}\frac{2^{2n+4r-2}((n+2r-1)!)^{2}}{2^{n+2r-1}(n+2r-1)!r!}=\frac{2^{n+2r-1}(n+2r-1)!}{r!}

\displaystyle\stackrel{{\scriptstyle\text{Obs.~\ref{obs:binom-bound}}}}{{\leq}}\frac{2^{2n+4r-2}n!(2r-1)!}{r!}\stackrel{{\scriptstyle\text{Obs.~\ref{obs:binom-bound}}}}{{\leq}}\frac{2^{2n+6r-3}n!r!(r-1)!}{r!}=2^{2n+6r-3}n!(r-1)!.\qed

Since each
n
-leaf network with
r
reticulations displays at most
2^{r}

trees, each such network displays at most
\binom{2^{r}}{t}\leq 2^{rt}
sets
of
t
trees. Thus, we immediately obtain the following corollary.

Corollary 7
.

Let
n,t,r\in\mdmathbb{N}^{+}
, and
let
\mathcal{M}_{n,t,r}
be the set of all pairs
(N,\mathcal{T})
such that

\mathcal{T}
is a set of
t

n

n

r

\mathcal{T}
.
Then
|\mathcal{M}_{n,t,r}|\leq 2^{rt}\cdot n!\cdot(r-1)!\cdot 2^{2n+6r-3}
.

Observation 8
.

Let

with

be the set of all

|\mathcal{S}_{n,t}|=\binom{(2n-3)!!}{t}\geq\left(\frac{(2n-3)!!}{t}\right)^{t}\stackrel{{\scriptstyle\text{Lem.~\ref{lem:double-fac-bound}}}}{{>}}\left(\frac{n}{2}\right)^{tn}\cdot t^{-t}.

Theorem 9
.

Let

such that

be the smallest integer such that

t

Then

r>\frac{(t-1)n\log n-6tn-t\log t}{\log n+t+\log t}\in(t-1)n-O\left(\frac{nt^{2}}{\log n+t}\right).

Proof.

Since every set of

[n]

1
), we have
r\leq(t-1)n
.
By the choice of

, each tree set
\mathcal{T}\in\mathcal{S}_{n,t}

with

(N,\mathcal{T})\in\mathcal{M}_{n,t,r}

Therefore,
|\mathcal{S}_{n,t}|\leq|\mathcal{M}_{n,t,r}|
, so

\displaystyle\left(\frac{n}{2}\right)^{tn}\cdot t^{-t}\stackrel{{\scriptstyle\text{Obs.~\ref{obs:num-trees}}}}{{<}}|\mathcal{S}_{n,t}|\leq|\mathcal{M}_{n,t,r}|\stackrel{{\scriptstyle\text{Cor.~\ref{cor:num-net-tree-pairs}}}}{{\leq}}2^{rt}\cdot n!\cdot(r-1)!\cdot 2^{2n+6r-3}.

By taking the base-2 logarithms on both sides, we get

\displaystyle tn\log n-tn-t\log t

\displaystyle<rt+\log n!+\log(r-1)!+2n+6r-3

\displaystyle\stackrel{{\scriptstyle\mathclap{\text{Lem.~\ref{lem:fac-bound}}}}}{{<}}rt+n\log n+r\log r+n+5r-3

\displaystyle=r(t+\log r+5)+n(\log n+1)-3

\displaystyle\stackrel{{\scriptstyle\mathclap{n+r\leq tn}}}{{<}}r(t+\log tn)+n(\log n+5t).

\displaystyle>\frac{tn\log n-tn-t\log t-n\log n-5tn}{\log n+t+\log t}=\frac{(t-1)n\log n-6tn-t\log t}{\log n+t+\log t}

\displaystyle=(t-1)n-\frac{(t-1)n(t+\log t)+6tn+t\log t}{\log n+t+\log t}\in(t-1)n-O\left(\frac{nt^{2}}{\log n+t}\right).\qed

4
Counting Unrooted Trees and Networks

The argument in the previous section applies to rooted trees but generalizes to unrooted trees fairly naturally.
In the unrooted case, there is no concept of reticulations, but we can define the reticulation number
of a network
N=(V,E)
as
r(N):=|E|-|V|+1
, that is,
as the number of edges that need to be deleted from
N
to obtain a tree.
This mirrors the rooted case in the sense that any rooting of a binary unrooted network
N
has
r(N)
reticulations.

The proof for rooted networks/trees had three main parts:

1.

bounding the number of networks
N
with reticulation number
r
,

2.

bounding the number of pairs
(N,\mathcal{T})
such that
\mathcal{T}
is a set of
t
trees on
n
leaves and
N
is a network with
r
reticulations that displays
\mathcal{T}
, and

3.

bounding the number of sets of
t
trees on the leaf set
[n]
.

Since there are
(2n-5)!!
unrooted trees with leaf set
[n]
, the number of
sets of
t
trees on the leaf set
[n]
is easy to bound:

Observation 10
.

Let
n,t\in\mdmathbb{N}^{+}
with
n\geq 6
, and
let
\mathcal{S}_{n,t}
be the set of all
sets of
t
unrooted binary trees on the leaf set
[n]
.
Then

|\mathcal{S}_{n,t}|=\binom{(2n-5)!!}{t}\geq\left(\frac{(2n-5)!!}{t}\right)^{t}\stackrel{{\scriptstyle\text{Lem.~\ref{lem:double-fac-bound}}}}{{>}}\left(\frac{n-1}{2}\right)^{t(n-1)}\cdot t^{-t}.

Next, we bound the number of unrooted binary networks with
n
leaves and reticulation
number
r
.
Such a bound is harder to obtain than for rooted networks, but for
the purpose of this paper, we can restrict our attention to a subclass of
unrooted networks, which we call
leaf-connecting
. A leaf-connecting
unrooted network has the property that every edge lies on a path between two
leaves. It is easy to see that if a set of unrooted trees
\mathcal{T}
is
displayed by an unrooted network
N
, then the subnetwork of
N
consisting of
all edges contained in the embedding of at least one tree in
\mathcal{T}

displays the trees in
\mathcal{T}
, is leaf-connecting, and has at most the
same reticulation number as
N
. Thus, a set of unrooted trees is displayed by
an unrooted network with reticulation number
r
if and only if it is displayed
by a leaf-connecting unrooted network with reticulation number
r
.

Proposition 11
.

Let
n,r\in\mdmathbb{N}^{+}
, and
let
\mathcal{N}^{\text{u}}_{n,r}
be the set of all leaf-connecting unrooted
networks with
n
leaves and reticulation number
r
.
Then
|\mathcal{N}_{n,r}|\leq\frac{(2n+4r-5)!!}{r!}\leq n!\cdot(r-2)!\cdot 2^{2n+6r-6}
.

Proof.

The proof follows the same approach as in the rooted case, with adjustments
to deal with the absence of edge directions.

A
switching
of a network
(N,\lambda_{L})\in\mathcal{N}^{\text{u}}_{n,r}
is a labelling
\sigma:E\to\{0,\bot\}

such that the labelled edges form a spanning tree of
N
. This means that
there are
r
unlabelled edges. As in the rooted case, a
reticulation
labelling

\lambda_{E}
of
(N,\lambda_{L})
is an extension of a switching

\sigma
of
(N,\lambda_{L})
that bijectively labels all edges left
unlabelled by
\sigma
with labels in
[r]
, and a reticulation-labelled
network is a triple
(N,\lambda_{L},\lambda_{E})
, where
\lambda_{E}
is a
reticulation labelling.
Also, as in the rooted case,
we fix a particular switching
\sigma_{(N,\lambda_{L})}

for each
(N,\lambda_{L})\in\mathcal{N}^{\text{u}}_{n,r}
,
we define
\mathcal{T}^{\text{u}}_{m}
as the set of unrooted trees with
m
leaves, and
we define the sets

\displaystyle\Lambda^{\text{u}}_{n,r}

\displaystyle:=\{(N,\lambda_{L},\lambda_{E})\mid(N,\lambda_{L})\in\mathcal{N}_{n,r}\;\land\;\lambda_{E}\text{ is a reticulation labelling}\;\land\;\sigma_{(N,\lambda_{L})}\subseteq\lambda_{E}\}\text{ and}

\displaystyle\Lambda^{\text{u}\prime}_{n,r}

\displaystyle:=\{\langle N,\lambda_{L},\lambda_{E}\rangle\mid(N,\lambda_{L})\in\mathcal{N}_{n,r}\;\land\;\lambda_{E}\text{ is a reticulation labelling}\;\land\;\sigma_{(N,\lambda_{L})}\subseteq\lambda_{E}\}.

Analogously to the proof of
6
, we show that

|\mathcal{N}^{\text{u}}_{n,r}|\cdot r!=|\Lambda^{\text{u}\prime}_{n,r}|\stackrel{{\scriptstyle\text{(a)}}}{{=}}|\Lambda^{\text{u}}_{n,r}|\stackrel{{\scriptstyle\text{(b)}}}{{\leq}}|\mathcal{T}^{\text{u}}_{n+2r}|.

Again, it is obvious that
|\mathcal{N}^{\text{u}}_{n,r}|\cdot r!=|\Lambda^{\text{u}\prime}_{n,r}|
because every switching

\sigma_{(N,\lambda_{L})}
has
r!
extensions that are reticulation
labellings.

(b):
The proof that
|\Lambda^{\text{u}}_{n,r}|\leq|\mathcal{T}^{\text{u}}_{n+2r}|

uses essentially the same
mapping
\tau:\Lambda^{\text{u}}_{n,r}\to\mathcal{T}^{\text{u}}_{n+2r}
as in the
rooted case, replacing every edge
e=\{u,v\}\in E(N)
with label

\lambda_{E}(e)>0
with two edges
\{u,z\}
and
\{v,z^{\prime}\}
, where
z
and

z^{\prime}
are two new leaves labelled
n+2\lambda_{E}(e)-1
and
n+2\lambda_{E}(e)
, respectively. Since it is once again easy to verify that each
reticulation-labelled network
(N,\lambda_{L},\lambda_{E})
can be recovered from
its image
\tau((N,\lambda_{L},\lambda_{E}))
, this mapping
\tau
is injective,
and we have
|\Lambda^{\text{u}}_{n,r}|\leq|\mathcal{T}^{\text{u}}_{n+2r}|
.

(a):
Finally, to show that
|\Lambda^{\text{u}}_{n,r}|=|\Lambda^{\text{u}\prime}_{n,r}|
,
we prove that the existance of
an isomorphism
\phi:(N,\lambda_{L},\lambda_{E})\to(N^{\prime},\lambda_{L}^{\prime},\lambda_{E}^{\prime})

between two reticulation-labelled unrooted
networks
(N,\lambda_{L},\lambda_{E})
and
(N^{\prime},\lambda_{L}^{\prime},\lambda_{E}^{\prime})
in
\Lambda^{\text{u}}_{n,r}

implies
\langle N,\lambda_{L},\lambda_{E}\rangle=\langle N^{\prime},\lambda_{L}^{\prime},\lambda_{E}^{\prime}\rangle
.
As in the rooted case,
\phi
is also an isomorphism
of
(N,\lambda_{L})
to
(N^{\prime},\lambda_{L}^{\prime})
,
so
(N,\lambda_{L})=(N^{\prime},\lambda_{L}^{\prime})
,
but proving that this implies
\phi=1_{N}

requires more care than in the rooted case.

Since
\phi
is an isomorphism of
(N,\lambda_{L})
to itself,
it respects the labels of all leaves,
so
\phi(x)=x
for all
x\in\mathcal{L}(N)
.
Now, assume for the sake of contradiction that
\phi\neq 1_{N}
.
As there are no parallel edges in
N
and
N
is leaf-connecting,
there is a path
P
between two leaves
x
and
y
in
N
that contains an
edge
\{u,v\}
with
\phi(u)=u
and
v^{\prime}=\phi(v)\neq v
.
Note that this implies that
\phi(\{u,v\})=\{u,v^{\prime}\}
and that
neither
v
nor
v^{\prime}
is a leaf of
N
.

Without loss of generality, suppose that
v
is on the subpath
Q
of
P
from
u
to
y
.
Then
Q^{\prime}:=\phi(Q)
is also a path from
u=\phi(u)
to
y=\phi(y)
.
Note that, for every edge
e\in Q

with
\lambda_{E}(e)\neq 0
, we have
\phi(e)=e
because
e

is the only edge with label
\lambda_{E}(e)
and
\phi
respects edge labels.
Thus, all edges in the symmetric difference
Q\oplus Q^{\prime}
of the edge sets of
Q
and
Q^{\prime}

are labelled
0
by
\lambda_{E}
.
Moreover,
Q\oplus Q^{\prime}
is non-empty because it contains the edges
\{u,v\}

and
\{u,v^{\prime}\}
, and every vertex is easily seen to have even degree in
Q\oplus Q^{\prime}
.
As every vertex in
N
has degree at most three,
Q\oplus Q^{\prime}
is
a non-empty collection of simple cycles all of whose edges are labelled
0
by
\lambda_{E}
,
contradicting the fact that the edges labelled
0
by
\lambda_{E}
form a spanning tree in
N
.

Having shown (a) and (b), we conclude that

\displaystyle|\mathcal{N}^{\text{u}}_{n,r}|

\displaystyle\stackrel{{\scriptstyle\text{(a),(b)}}}{{\leq}}\frac{|\mathcal{T}^{\text{u}}_{n+2r}|}{r!}=\frac{(2n+4r-5)!!}{r!}

\displaystyle\stackrel{{\scriptstyle\text{Obs.~\ref{obs:double-fac-eq}}}}{{=}}\frac{(2n+4r-4)!}{2^{n+2r-2}(n+2r-2)!r!}\stackrel{{\scriptstyle\text{Obs.~\ref{obs:binom-bound}}}}{{\leq}}\frac{2^{2n+4r-4}((n+2r-2)!)^{2}}{2^{n+2r-2}(n+2r-2)!r!}=\frac{2^{n+2r-2}(n+2r-2)!}{r!}

\displaystyle\stackrel{{\scriptstyle\text{Obs.~\ref{obs:binom-bound}}}}{{\leq}}\frac{2^{2n+4r-4}n!(2r-2)!}{r!}\stackrel{{\scriptstyle\text{Obs.~\ref{obs:binom-bound}}}}{{\leq}}\frac{2^{2n+6r-6}n!r!(r-2)!}{r!}=2^{2n+6r-6}n!(r-2)!.\qed

In addition to the bound on the number of networks with reticulation number
r

established by
11
, we need the following bound on the
number of trees displayed by each of them:

Proposition 12
.

Let
N\in\mathcal{N}_{n,r}
be a binary unrooted network with
n
leaves and reticulation number
r
.
Then
N
displays at most
\binom{n+3r-3}{r}\leq 2^{n+3r-3}
trees with
n
leaves.

Proof.

For every tree
T
displayed by
N
, there is a spanning tree of
N
that has a
subdivision of
T
as a subtree.
Conversely, for every spanning tree
T^{\prime}
of
N
,
there is exactly one tree displayed by
N
such that
T^{\prime}
has a subdivision
of this tree as a subtree.
Thus, the number of trees displayed by
N
is
at most the number of spanning trees of
N
.
We show that this number is at most
2^{n+3r-3}
.

As
N
is an unrooted binary network with
n
leaves and reticulation number
r
,
we know that
N
has exactly
2n+3r-3
edges, and every spanning tree of
N
is
obtained by deleting exactly
r
of them.
Further, exactly
n
edges of
N
are incident to leaves and are, therefore,
in every spanning tree of
N
.
Thus,
N
has at most
\binom{n+3r-3}{r}\leq 2^{n+3r-3}
spanning trees.
∎

9

Theorem 14
.

Let
n,t\in\mdmathbb{N}^{+}
such that
n\geq 6
, and
let
r
be the smallest integer such that
every set of
t
trees on the leaf set
[n]

is displayed by some network with
r
reticulations.
Then

r>\frac{(t-1)n\log n-t(8n+\log n+\log t-1)}{\log n+3t+\log t}\\
\in(t-1)n-O\left(\frac{nt^{2}}{\log n+t}\right).

Proof.

Similar to the rooted case, we have

\left(\frac{n-1}{2}\right)^{t(n-1)}\cdot t^{-t}\stackrel{{\scriptstyle\text{Obs.~\ref{obs:u-num-trees}}}}{{<}}\binom{(2n-5)!!}{t}=|\mathcal{S}^{\text{u}}_{n,t}|\leq|\mathcal{M}^{\text{u}}_{n,t,r}|\stackrel{{\scriptstyle\text{Cor.~\ref{cor:u-num-net-tree-pairs}}}}{{\leq}}2^{(t+2)(n+3r-3)}\cdot n!\cdot(r-2)!,

and we can assume that
n+r\leq tn
.
Taking base-2 logarithms again gives

\displaystyle t(n-1)\log(n-1)-t(n-1)-t\log t

\displaystyle<(t+2)(n+3r-3)+\log n!+\log(r-2)!

\displaystyle\stackrel{{\scriptstyle\mathclap{\text{Lem.~\ref{lem:fac-bound}}}}}{{<}}(t+1)n+(t+2)(3r-3)+n\log n+r\log r

\displaystyle=r(3t+\log r+6)+n(t+\log n+1)-3t-6

\displaystyle\stackrel{{\scriptstyle\mathclap{n+r\leq tn}}}{{<}}r(3t+\log tn)+n(\log n+7t)

and, thus,

\displaystyle r

\displaystyle>\frac{t(n-1)\log n-t(n-1)-t\log t-n\log n-7tn}{\log n+3t+\log t}=\frac{(t-1)n\log n-t(8n+\log n+\log t-1)}{\log n+3t+\log t}

\displaystyle=(t-1)n-\frac{(t-1)n(3t+\log t)+t(8n+\log n+\log t-1)}{\log n+3t+\log t}\in(t-1)n-O\left(\frac{nt^{2}}{\log n+t}\right).\qed

5
Conclusion

We have shown that, for any sub-logarithmic number of trees, there is some set
of trees for which the trivial network with
(t-1)n
reticulations is
the best possible network to display these trees, up to lower-order terms, which
means that these trees have almost no common structure.
In particular, this result holds for any constant number of trees, which,
as discussed in the introduction,
has the important implication that cluster reduction is not safe
for computing the hybridization number of four or more trees.

Further, there are sets of
c\log n
trees that cannot be displayed by
a network with
o(n\log n)
reticulations. This suggests that most of the
reticulations in the optimal network that displays
all
trees on
n
leaves,
which has
\Theta(n\log n)
reticulations
[
5
]
,
are due to only a tiny fraction of the exponentially many trees.

Two obvious open questions remain: First, for
t\in o(\log n)
, we believe that
there are sets of
t
trees that require
(t-1)n-o(n)
reticulations to
display, even though we were only able to prove the weaker bound of

(t-1)n-o(tn)
.
This is probably due to substantial overcounting of the number of sets of

t
trees that can be displayed by some network with
r
reticulations.
In particular, we bound the number of these sets by the number of pairs
(N,\mathcal{T})
such that
\mathcal{T}
is a set of
t
trees, and
N
is a network with
r

reticulations that displays
\mathcal{T}
.
We suspect that many such sets
\mathcal{T}
are displayed by many networks with

r
reticulations, so we count them often. There are other sources of
overcounting in our proofs, but this is most likely the most egregious.

The second open question concerns the bound on the number of reticulations
needed to display
c\log n
unrooted trees in
17
.
This bound is roughly one third of the bound for rooted trees shown in

corollary

3
.
We believe that this gap is a caveat of our proof and that
there is also a set of
c\log n
unrooted trees that require
close to
n\log n
reticulations to display as
c
increases.
