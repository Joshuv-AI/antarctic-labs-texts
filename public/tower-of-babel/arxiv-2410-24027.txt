On codes induced from Hadamard matrices
Ted Hurley

Abstract
Unit derived schemes applied to Hadamard matrices are used to construct and analyse linear block and convolutional codes. Codes are constructed to prescribed types, lengths and rates and multiple series of self-dual, dual-containing, linear complementary dual and quantum error-correcting of both linear block and convolutional codes are derived.



Keywords: Hadamard, code, linear, convolutional, self-dual, dual-containing, quantum code, linear complementary

AMS Classification 2020: 94B05, 94B10, 15B99

2
Linear block and convolutional codes induced from Hadamard matrices

The Walsh-Hadamard binary linear block codes
[2^{k},k,2^{k-1}]_{2}
and
[2^{k},k+1,2^{k-1}]_{2}
have very small rate but have found use probably on account of the distances and decoding methods available.
Codes from general Hadamard matrices as now described allow much more scope with much better rates, good distances, required types and both linear block and convolutional codes may be formed.

Let
H
be a Hadamard matrix with
HH\text{${}^{\text{T}}$}=nI_{n}
. Break
H
as
H=\left(\begin{smallmatrix}A\\
B\end{smallmatrix}\right)
for
A
an
r\times n
matrix and then
\left(\begin{smallmatrix}A\\
B\end{smallmatrix}\right)\left(\begin{smallmatrix}A\text{${}^{\text{T}}$}&B\text{${}^{\text{T}}$}\end{smallmatrix}\right)=nI_{n}
. When
n\neq 0
in the field under consideration, a code is obtained in which
A
is the generator matrix and
B\text{${}^{\text{T}}$}
is a check matrix. This is the basic method for producing the linear block codes from Hadamard matrices. A more general method is to take any
r
rows of the Hadamard matrix to generate a code and a check matrix is obtained by eliminating the corresponding columns of the transpose of the Hadamard matrix. The convolutional codes are essentially obtained from breaking the Hadamard matrix into blocks and using the blocks as ‘components’ of the generator matrix of a convolutional code. Properties of the Hadamard matrix are used to construct the
type
of code required.

Proposition 2.1
.

Let
H
be a Hadamard matrix of size
n
and
n\neq 0
in a field
\mathcal{F}
. Suppose
H
has the form

H=\left(\begin{smallmatrix}A\\
B\end{smallmatrix}\right)
, where
A
has size
r\times n
, implying
\left(\begin{smallmatrix}A\\
B\end{smallmatrix}\right)\left(\begin{smallmatrix}A\text{${}^{\text{T}}$}&B\text{${}^{\text{T}}$}\end{smallmatrix}\right)=nI_{n}
. Then the code generated by
A
over
\mathcal{F}
is an LCD
[n,r]
code
\mathcal{A}
and
B
generates the dual code of
\mathcal{A}
.

Proof.

Both
A
and
B
have full ranks as
H
is invertible. Now
AB\text{${}^{\text{T}}$}=0
and so
B\text{${}^{\text{T}}$}
is a control matrix for the code
\mathcal{A}
and thus
B
generates the dual code of
\mathcal{A}
. Since

is invertible in
\mathcal{F}
a combination of the rows of
A
cannot be a non-trivial combination of the rows of
B
and thus
\mathcal{A}
is an LCD code.

Proposition 2.2
.

Let
n\neq 0
in a field
\mathcal{F}
and
H
a Hadamard matrix with
HH\text{${}^{\text{T}}$}=nI_{n}
. Then there exists

Proof.

Let

.
Now
(I,\alpha H)\left(\begin{smallmatrix}I\\
\alpha H\text{${}^{\text{T}}$}\end{smallmatrix}\right)=I+\alpha^{2}nI=(1+\alpha^{2}n)I

(1+x^{2}n=0)
has a solution in

. Thus in
\mathcal{F}
or in a quadratic extension of

(I,\alpha H)\left(\begin{smallmatrix}I\\
\alpha H\text{${}^{\text{T}}$}\end{smallmatrix}\right)=0

\alpha H\text{${}^{\text{T}}$}\end{smallmatrix}\right)

generates the dual of the code and hence the code is self-dual.

Proposition 2.3
.

Let
H
be a Hadamard matrix of size
n
and
n\neq 0
in a field
\mathcal{F}
. Suppose

has the form

H=\left(\begin{smallmatrix}A\\
B\end{smallmatrix}\right)
implying
\left(\begin{smallmatrix}A\\
B\end{smallmatrix}\right)\left(\begin{smallmatrix}A\text{${}^{\text{T}}$}&B\text{${}^{\text{T}}$}\end{smallmatrix}\right)=nI_{n}

Now

and so

has a right polynomial inverse and thus the code generated by

The proof of the distance is straight forward and omitted.
