An algebraic description of the Page transition
Haocheng Zhong a

Abstract
In this work, we develop an algebraic description of the Page transition, a key feature in black hole evaporation where the entropy of Hawking radiation follows a unitary Page curve instead of monotonically increasing. By applying concepts from approximate quantum error correction with complementary recovery, we characterize the Page transition as a phase transition in channel recovery. We then generalize the description to infinite-dimensional settings using algebraic relative entropy, which remains valid even in type III factors. For type I/II factors, explicit probes based on relative entropy differences are derived, serving as indicators for the transition at the Page time.

Introduction

The Page curve
Page:1993wv
;
Page:2013dx
is a theoretical prediction for how the fine-grained entropy of Hawking radiation should behave over the lifetime of an evaporating black hole if the evaporation process is unitary (i.e., if information is conserved), which is central to modern discussions of the black hole information paradox

;

;

If this were true, when the black hole vanishes, the information about what fell into it would be irretrievably lost, violating the quantum mechanical principle of unitarity. On the other hand, the Page cure suggested that the entropy should reach a maximum at a point known as the Page time, after which the entropy monotonically decreases and returns to zero. Recently, the island formula

;

;

2.3
Algebraic entropies

In physics literatures, there exists three seemingly different definitions of “state”:

1.

A state is a vector
|\psi\rangle
normalized as
\langle\psi\vphantom{\psi}|\psi\vphantom{\psi}\rangle=1
in a Hilbert space
\mathcal{H}
.

2.

A state is a density operator (or density matrix)
\rho_{\psi;\mathcal{A}}\in\mathcal{A}
satisfying

\rho_{\psi;\mathcal{A}}=\rho_{\psi;\mathcal{A}}^{\dagger};\quad\rho_{\psi;\mathcal{A}}\geq 0;\quad\text{Tr}_{\mathcal{A}}\rho_{\psi;\mathcal{A}}=1.

(19)

3.

A state is a linear functional
\omega_{\psi}:\mathcal{A}\rightarrow\mathbb{C}
satisfying

\omega_{\psi}\geq 0;\quad\omega_{\psi}(\mathbbm{1})=1.

(20)

These three definitions are correlated to each other via the expectation value:

\left\langle\psi\vphantom{\mathcal{O}\psi}\right|\mathcal{O}\left|\psi\vphantom{\psi\mathcal{O}}\right\rangle=\text{Tr}_{\mathcal{A}}\left(\rho_{\psi;\mathcal{A}}\mathcal{O}\right)=\omega_{\psi}(\mathcal{O}),\quad\forall\mathcal{O}\in\mathcal{A}.

(21)

Note that the second definition based on density operators is not well-defined in factors of type III. Also note that, these three definitions are not completely equivalent. In the vector representation, one can always compute the expectation
\left\langle\psi\vphantom{\mathcal{O}\psi}\right|\mathcal{O}\left|\psi\vphantom{\psi\mathcal{O}}\right\rangle,~\mathcal{O}\notin\mathcal{A}
which makes no sense for the other two definitions. To be specific, the expectation value
\text{Tr}_{\mathcal{A}}\left(\rho_{\psi;\mathcal{A}}\mathcal{O}\right),~\mathcal{O}\notin\mathcal{A}
is ill-defined since
\rho_{\psi;\mathcal{A}}\mathcal{O}
may not belongs to
\mathcal{A}
then it is not in the domain of the trace function of
\mathcal{A}
. As for
\omega_{\psi}(\mathcal{O}),~\mathcal{O}\notin\mathcal{A}
, it is ill-defined since
\omega_{\psi}
is only a linear functional on
\mathcal{A}
. Nevertheless, we can extend the last two definitions via (
21
) such that the expectation values of the last two definitions are well-defined for a larger class of operators. We can simply define that

\omega_{\psi}(\mathcal{O})=\text{Tr}_{\mathcal{A}}\left(\rho_{\psi;\mathcal{A}}\mathcal{O}\right)=\left\langle\psi\vphantom{\mathcal{O}\psi}\right|\mathcal{O}\left|\psi\vphantom{\psi\mathcal{O}}\right\rangle,~\mathcal{O}\notin\mathcal{A}.

(22)

In the following discussions, we always assume the second and the third definitions are extended.

Recall that the quantum relative entropy is defined by

S_{\text{rel}}(\rho_{\psi}|\rho_{\phi})\equiv\text{Tr}\left[\rho_{\psi}\left(\log\rho_{\psi}-\log\rho_{\phi}\right)\right]

(23)

which measures how much the state
\psi
differs from another state
\phi
. Its algebraic generalization is defined due to Araki
araki1975relative
;
araki1975inequalities
:

S_{\text{rel}}(\psi|\phi;\mathcal{A})\equiv\left\langle\psi\vphantom{h_{\phi|\psi}\psi}\right|h_{\phi|\psi}\left|\psi\vphantom{\psi h_{\phi|\psi}}\right\rangle=\omega_{\psi}(h_{\phi|\psi})

(24)

with
|\psi\rangle
being cyclic and separating with respect to
\mathcal{A}
. See
Witten:2018zxz
for details about how the algebraic relative entropy coincides with the quantum relative entropy in finite-dimensional cases.

The von Neumann entropy is defined by

S(\rho_{\psi})\equiv-\text{Tr}\left(\rho_{\psi}\log\rho_{\psi}\right)

(25)

whose algebraic generalization in factors of type I/II is given by
segal1960note
;
ohya2004quantum
;
Longo:2022lod
:

S(\psi;\mathcal{A})\equiv-S_{\text{rel}}(\psi|\tau;\mathcal{A})=-\left\langle\psi\vphantom{h_{\tau|\psi}\psi}\right|h_{\tau|\psi}\left|\psi\vphantom{\psi h_{\tau|\psi}}\right\rangle=-\omega_{\psi}(h_{\tau|\psi})

(26)

where
|\psi\rangle
is cyclic and separating with respect to
\mathcal{A}
and
\tau
is a tracial state. A tracial state is a state
|\tau\rangle\in\mathcal{H}
satisfying

\left\langle\tau\vphantom{\mathcal{O}\mathcal{P}\tau}\right|\mathcal{O}\mathcal{P}\left|\tau\vphantom{\tau\mathcal{O}\mathcal{P}}\right\rangle=\left\langle\tau\vphantom{\mathcal{P}\mathcal{O}\tau}\right|\mathcal{P}\mathcal{O}\left|\tau\vphantom{\tau\mathcal{P}\mathcal{O}}\right\rangle,\quad\forall\mathcal{O},\mathcal{P}\in\mathcal{A}

(27)

and each tracial state defines a trace function on
\mathcal{A}
:

\text{Tr}_{\mathcal{A}}(\mathcal{O})\equiv\left\langle\tau\vphantom{\mathcal{O}\tau}\right|\mathcal{O}\left|\tau\vphantom{\tau\mathcal{O}}\right\rangle.

(28)

The trace function is unique up to a rescaling which may contributes to the algebraic von Neumann entropy an additional constant. Such constant does not cause the ambiguity of the algebraic von Neumann entropy, since only the difference between entropies has physical meanings. The non-existence of algebraic von Neumann entropy in factors of type III is due to the non-existence of tracial state or trace function.

A useful property of the tracial state is

Proposition 2.19
.

In factors of type I/II, we have a tracial state
\tau
such that

\Delta_{\tau|\psi}=\rho_{\psi;\mathcal{A}}^{-1}.

(29)

For all states
\psi
.

We can substitute it into (
26
) and find that the algebraic von Neumann entropy coincides with the usual von Neumann entropy defined in (
25
).

Note we also have (
53
) such that

S(\Phi^{\prime};\mathcal{A}_{\text{Rad}})-S(\Phi;\mathcal{A}_{\text{Rad}})=S(\widetilde{\Phi}^{\prime};\mathcal{A}_{I\cup R})-S(\widetilde{\Phi};\mathcal{A}_{I\cup R})+\Delta S_{1}(\Phi(t_{1}))-\Delta S_{1}(\Phi(t_{2})).

(63)

Combining it with (
59
) and (
62
), we have

\varepsilon~\omega_{\Psi}(h_{\tau|\Phi})+\varepsilon S(\Phi;\mathcal{A}_{\text{Rad}})=\varepsilon~\omega_{\widetilde{\Psi}}(h_{\widetilde{\tau}|\widetilde{\Phi}})+\varepsilon S(\widetilde{\Phi};\mathcal{A}_{I\cup R})+\Delta S_{1}(\Phi(t_{1}))-\Delta S_{1}(\Phi(t_{2})),

(64)

which further implies

\displaystyle\Rightarrow~\varepsilon~\omega_{\widetilde{\Psi}}\left(V^{\dagger}h_{\tau|\Phi}V-h_{\widetilde{\tau}|\widetilde{\Phi}}\right)

\displaystyle=\varepsilon\left(S(\widetilde{\Phi};\mathcal{A}_{I\cup R})-S(\Phi;\mathcal{A}_{\text{Rad}})\right)+\Delta S_{1}(\Phi(t_{1}))-\Delta S_{1}(\Phi(t_{2}))

(65)

\displaystyle=\varepsilon\Delta S_{1}(\Phi(t_{1}))+\Delta S_{1}(\Phi(t_{1}))-\Delta S_{1}(\Phi(t_{2}))

where we use (
53
) in the second equality. Finally, we continue (
57
) and arrive at

\displaystyle S_{\text{rel}}(\widetilde{\Psi}|\widetilde{\Phi};\mathcal{A}_{I\cup R})-S_{\text{rel}}(\Psi|\Phi;\mathcal{A}_{\text{Rad}})

(66)

\displaystyle=\omega_{\widetilde{\Psi}}\left(V^{\dagger}h_{\tau|\Phi}V-h_{\widetilde{\tau}|\widetilde{\Phi}}\right)-\Delta S_{2}(\Psi(t_{1}))

\displaystyle=\frac{1}{\varepsilon}\left[\Delta S_{1}(\Phi(t_{1}))-\Delta S_{1}(\Phi(t_{2}))\right]+\Delta S_{1}(\Phi(t_{1}))-\Delta S_{2}(\Psi(t_{1})).

As expected, the result is a sum of different
\Delta S_{1,2}
with the property (
52
) that they are non-vanishing and monotonically decreasing before
t_{P}
, then vanishes after
t_{P}
. Monotonicity ensures that the term with coefficient
1/\varepsilon
is non-negative (see also Fig.
3
), and it is comparably greater than the other terms due to
\varepsilon\rightarrow 0
. Therefore, we conclude that
S_{\text{rel}}(\widetilde{\Psi}|\widetilde{\Phi};\mathcal{A}_{I\cup R})-S_{\text{rel}}(\Psi|\Phi;\mathcal{A}_{\text{Rad}})
satisfies (
38
). Similar calculations can be performed to show that the other half of (
38
) also holds, which completes our arguments.

5
Discussions

In the paper, we have argued an algebraic generalization of a probe for the Page transition for von Neumann factors of type I/II:

\displaystyle S_{\text{rel}}(\widetilde{\Psi}|\widetilde{\Phi};\mathcal{A}_{I\cup R})-S_{\text{rel}}(\Psi|\Phi;\mathcal{A}_{\text{Rad}})

\displaystyle\begin{cases}>\delta,&\text{if $t<t_{P}$}\\
=\delta,&\text{if $t=t_{P}$}\\
\leq\delta,&\text{if $t>t_{P}$}\end{cases},

(67)

\displaystyle S_{\text{rel}}(\widetilde{\Psi}|\widetilde{\Phi};\mathcal{A}_{X})-S_{\text{rel}}(\Psi|\Phi;\mathcal{A}_{\text{BH}})

\displaystyle\begin{cases}>\epsilon,&\text{if $t<t_{P}$}\\
=\epsilon,&\text{if $t=t_{P}$}\\
\leq\epsilon,&\text{if $t>t_{P}$}\end{cases}

which can also be regarded as an algebraic generalization of the island formula describing the evaporating black hole. Similar ideas are also demonstrated in
Gomez:2024fij
;
Gomez:2024cjm
, where the author have introduced a quantity called Murray von Neumann parameter to describe the algebraic version of the Page curve for type II black holes. The author has shown that, the Page curve describes a phase transition with the transfer of information as order parameter, which coincides with the fact that (
67
) describes a phase transition of the exactness for channel recovery between different regions of the black hole.

Note that for factors of type III, these are some issues regarding the definitions in describing the Page transition. Especially, the island formulae (
1
) and (
2
) are no longer valid due to the ill-defined von Neumann entropy in factors of type III. Technically, one may introduces the crossed product to construct type II factors from the original type III factors, see also discussions in
Gomez:2024fij
;
Gomez:2024cjm
. On the other hand, one main advantage of (
67
) is exactly that the algebraic relative entropy is well-defined in a generic factor, such that (
67
) is expected to hold in describing type III black holes. Although the direct proof of (
67
) in type III factors is yet to be established, there are hints for the transfer of information in such cases. For example, the authors in
Engelhardt:2023xer
have interpreted the Page transition as the transfer of an emergent type III subalgebra of high complexity operators from the black hole to radiation. We expect to investigate more formal discussions about (
67
) on these issues in the future.
