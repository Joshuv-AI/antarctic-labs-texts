WavKinS.jl : an efficient and modular Julia software for solving wave kinetic equations
Giorgio Krstulovic, Vincent Labarre

Abstract
This article describes the Wave Kinetic Solver WavKinS.jl , a software developed in the Julia language for solving different types of wave kinetic equations in an efficient and modular manner. WavKinS.jl already solves the wave kinetic equation describing the interaction of waves in several physical systems, such as acoustic waves, Bose-Einstein condensates, internal gravity waves and many others. Thanks to the structures and routines already implemented in WavKinS.jl , we expect that developing a new solver for a specific physical system to be straightforward. WavKinS.jl is an Open Source project distributed with EUPL-1.2 license agreement. https://github.com/gkrstulovic/WavKinS.jl https://gkrstulovic.github.io/WavKinS.jl/

I  Introduction

I  General description

Wave kinetic equations arrive in many physical systems, such as plasmas, geophysical fluids, elastic plates, turbulent Bose-Einstein condensates, and many others
Galtier, 2003
;
L’vov and Nazarenko, 2010
;
Dyachenko et al., 1992
;
Zhu et al., 2023
. When the nonlinearity is small, the theory of Weak Wave Turbulence (WWT) provides a close equation describing the evolution of the wave spectrum, which relates to the wave amplitude or energy at a given scale
Zakharov et al., 1992
;
Nazarenko, 2011
.

This article does not aim to provide an introduction to WWT, we provide however the physical context where wave kinetic equations are found. Let’s start by considering a general non-linear wave system, where the amplitudes of the Fourier modes
a_{\textbf{k}}
, having a linear dispersion relation
\omega_{\textbf{k}}
are described by the following Hamiltonian

\displaystyle H

\displaystyle=

\displaystyle\sum_{\textbf{k}}\omega_{\textbf{k}}|a_{\textbf{k}}|^{2}+\sum_{\bf 123}V_{\bf 123}(a_{\bf 1}^{*}a_{\bf 2}a_{\bf 3}+c.c.)\delta^{\bf 1}_{\bf 23}

(1)

\displaystyle+\sum_{\bf 1234}T^{\bf 12}_{\bf 34}a_{\bf 1}a_{\bf 2}a_{\bf 3}^{*}a_{\bf 4}^{*}\delta^{\bf 12}_{\bf 34}

Here, we consider waves in a
d
-dimensional periodic box of size
L
, such that wavevectors
\textbf{k}\in\frac{2\pi}{L}\mathbb{Z}
. We denote
a_{\bf i}=a_{\bf k_{i}}
and use the same convention for summation indexes.
a_{\textbf{k}}^{*}
denotes the complex conjugate of
a_{\textbf{k}}
. The tensors
V_{\bf 123}
and
T^{\bf 12}_{\bf 34}
are the interaction matrices that contain all the physics of the system, which for simplicity we consider here fully symmetric. Finally,
\delta^{\bf 1}_{\bf 23}
and
\delta^{\bf 12}_{\bf 34}
are
\delta
-Kronecker such that they are non-zero and equal to one only if
\textbf{k}_{1}=\textbf{k}_{2}+\textbf{k}_{3}
and
\textbf{k}_{1}+\textbf{k}_{2}=\textbf{k}_{3}+\textbf{k}_{4}
, respectively. Note that the wave dynamics is simply given by
i\dot{a_{\textbf{k}}}=\frac{\partial H}{\partial a_{\textbf{k}}^{*}}
.

The WWT provides a statistical description for the waveaction spectrum
n_{\textbf{k}}=\frac{L^{d}}{(2\pi)^{d}}\langle|a_{\textbf{k}}|^{2}\rangle
in the limit of infinite box size and small nonlinearity (taken in that order). Rigorously,
\langle\,\,\rangle
denotes an average over initial conditions, although it is often considered as an average over different sources of fluctuations in the system. The statistical description of waves in the above mentioned limit is known as the kinetic description of weakly nonlinear waves. Note that if
V_{\bf 123}\neq 0
, then the quartic terms in the Hamiltonian can be neglected in this limit.
In the end, the WWT furnishes a closed equation for the waveaction spectrum called the wave kinetic equation (WKE)

\frac{\mathrm{d}n_{\bf k}}{\mathrm{d}t}=St_{\bf k},

(2)

where
St_{\bf k}
is the collisional integral. The collisional integral is a nonlinear integral functional of
n_{\bf k}
defined over a manifold, which will be discussed later.
Finally note that in the Hamiltonian (
1
), one could have considered more general terms, such as
U_{\bf 123}(a_{\bf 1}a_{\bf 2}a_{\bf 3}+c.c.)
, however the WWT shows that in the kinetic limit, only those present in (
1
) survive and contribute to the dynamics of
n_{\textbf{k}}
. Moreover, the Hamiltonian structure of the nonlinear wave system considerably simplifies the analytical computations, but it is not necessarily required in the derivation of the WKE.

The WKE can be classified by the number of waves interacting, which results in different degrees of nonlinearity and integrations to be performed. In the current version of
WavKinS.jl
, we consider two types of systems that can be generically written as follows.

-
3
-wave canonical systems:

In this case, the leading nonlinearity in (
1
) is cubic, and the collisional integral reads

St_{\bf k}=\int(\mathcal{R}^{\bf k}_{12}-\mathcal{R}^{1}_{2{\bf k}}-\mathcal{R}^{2}_{{\bf k}1})\mathrm{d}{\bf k}_{1}\mathrm{d}{\bf k}_{2}

(3)

with

\displaystyle\mathcal{R}^{\bf k}_{12}=

\displaystyle 2\pi|V_{{\bf k}12}|^{2}(n_{1}n_{2}-n_{1}n_{\bf k}-n_{\bf k}n_{2})

(4)

\displaystyle\times\delta({{\bf k}-{\bf k}_{1}-{\bf k}_{2}})\delta(\omega_{\bf k}-\omega_{1}-\omega_{2}).

The integrals in the collisional integral are performed over the so-called resonant manifold defined by two
\delta
-Dirac,

{\bf k}={\bf k}_{1}+{\bf k}_{2},\quad\omega_{\bf k}=\omega_{\bf 1}+\omega_{\bf 2},

(5)

and permutation of indexes.

The
3
-waves WKE conserves the total energy of the system given by

E=\int\omega_{\bf k}n_{\bf k}d{\bf k}.

(6)

Depending on the physical system, other invariants might exist.

Note that if wavevectors are in dimension
d
, then there are
2d-d-1=d-1
integrals to be performed for each value of a external wavevector
{\bf k}
. Therefore, if we use
M
points to discretise each coordinate of the wavevector space, then the numerical cost will be generically of the order of
M^{2d-1}
operations. However, by assuming full isotropy or isotropy in a plane one can drastically reduce the numerical cost, making calculations feasible.

-
4
-wave canonical systems:

In these systems, the cubic term in (
1
) is absent or the resonant manifold (
5
) is empty. In this case, the collisional integral is

\displaystyle St_{\bf k}=

\displaystyle\int|T^{{\bf k1}}_{\bf 23}|^{2}\delta({{\bf k}+{\bf k}_{1}-{\bf k}_{2}}-{\bf k}_{3})\delta(\omega^{{\bf k1}}_{\bf 23})n_{\bf k}n_{\bf 1}n_{\bf 2}n_{\bf 3}

(7)

\displaystyle\times\left(\frac{1}{n_{\bf k}}+\frac{1}{n_{\bf 1}}-\frac{1}{n_{\bf 2}}-\frac{1}{n_{\bf 3}}\right)\mathrm{d}{\bf k}_{1}\mathrm{d}{\bf k}_{2}\mathrm{d}{\bf k}_{2}

with
\omega^{{\bf k1}}_{\bf 23}=\omega_{\bf k}+\omega_{\bf 1}-\omega_{\bf 2}-\omega_{\bf 3}
. The resonant manifold is in this case

{{\bf k}+{\bf k}_{1}-{\bf k}_{2}}-{\bf k}_{3}=0,\quad\omega_{\bf k}+\omega_{\bf 1}-\omega_{\bf 2}-\omega_{\bf 3}=0

(8)

Besides the energy (
6
),
4
-waves WKEs also conserves the total waveaction of the system

N=\int n_{\bf k}d{\bf k}.

(9)

For
4
-wave systems there are
3d-d-1=2d-1
integrals to be performed, which implies in general a numerical cost of the order of
M^{3d-1}
operations per time step.

I  The Wave Kinetic Solver
WavKinS.jl

The Wave Kinetic Solver (
WavKinS.jl
) is a software developed in Julia language to solve WKEs of the kind (
3
) and (
7
). More precisely, it solves the following type of equations

\frac{\mathrm{d}n_{\bf k}}{\mathrm{d}t}=St_{\bf k}+f_{\bf k}-d_{\bf k}n_{\bf k},

(10)

where
f_{\bf k}
is a forcing term and
d_{\bf k}\geq 0
a dissipation coefficient. Their definitions depend on the physical problem.

WavKinS.jl
provides all the structures and functions needed to solve several types of wave kinetic equations. The code runs well on personal computers and shared-memory clusters.
WavKinS.jl
is conceived in such a way that implementing a new physical system should be straightforward, provided that some basic mathematical knowledge of the physical system has been previously achieved (e.g., parametrisation of resonant manifolds, study of possible singularities of the integrands, etc.).
WavKinS.jl
is available in
https://github.com/gkrstulovic/WavKinS.jl
and its documentation here
https://gkrstulovic.github.io/WavKinS.jl/
.
WavKinS.jl
is an Open Source project distributed with EUPL-1.2 license agreement.

In the following, we provide the list of currently implemented physical systems in
WavKinS.jl
. The specific details about their implementation can be found in the documentation.

- Acoustic waves

WavKinS.jl
solves the isotropic wave kinetic equation for acoustic waves in two and three dimensions. The dispersion relation is
\omega_{k}=c|k|
with
c
the speed of sound. The interaction matrix is
V_{123}=V_{0}\sqrt{k_{1}k_{2}k_{3}}
. The acoustic WKE is theoretically derived from a weakly dispersive system with dispersion relation
\omega_{k}=ck(1+a^{2}k^{2})
in the limit
a\to 0

Zakharov et al., 1992
;
Griffin et al., 2022
;
Zhu et al., 2024
. The collisional integral of the WKE is

St_{k}=\frac{C_{d}}{a^{3-d}k^{d-1}}\int\left(\mathcal{N}^{k}_{12}-\mathcal{N}^{1}_{2k}-\mathcal{N}^{2}_{k1}\right)(kk_{1}k_{2})^{d-2}\mathrm{d}k_{1}\mathrm{d}k_{2},

(11)

with
\mathcal{N}^{k}_{12}=|V_{k12}|^{2}(n_{1}n_{2}-n_{1}n_{k}-n_{k}n_{2})\delta(\omega_{k}-\omega_{1}-\omega_{2})
, and where
d=2
or
3
is the dimension. The prefactor is
C_{2}=2\pi/\sqrt{6}
and
C_{3}=4\pi^{2}
.

Because isotropy is assumed, the numerical cost is of the order of
M^{2}
operations per time step.

- Three-dimensional Bogoliubov waves

Bogoliubov waves are elementary excitations of Bose-Einstein condensates obtained from the linearised Nonlinear Schrodinger equation around a flat condensate state. The
3D
isotropic WKE collisional integral is

St_{k}=\frac{4\pi}{k^{2}}\int\left(\mathcal{N}^{k}_{12}-\mathcal{N}^{1}_{2k}-\mathcal{N}^{2}_{k1}\right)kk_{1}k_{2}\mathrm{d}k_{1}\mathrm{d}k_{2},

(12)

with
\mathcal{N}^{k}_{12}
as for acoustic waves, but with the Bogoliubov dispersion relation
\omega_{k}=ck\sqrt{1+\frac{1}{2}\xi^{2}k^{2}}
. For this system, the interaction matrix is

V_{12}^{k}=V_{0}\sqrt{kk_{1}k_{2}}\left[\frac{1}{2\sqrt{\eta_{k}\eta_{1}\eta_{2}}}+\frac{\sqrt{\eta_{k}\eta_{1}\eta_{2}}}{6kk_{1}k_{2}}\left(\frac{k^{3}}{\eta_{k}}-\frac{k^{3}}{\eta_{1}}-\frac{k^{3}}{\eta_{2}}\right)\right],

(13)

with
\eta_{k}=\sqrt{1+(k\xi)^{2}/2}
. Note that Bogoliubov WKE reduces to the acoustic WKE in the limit
\xi\to 0
. It has the same numerical cost than the acoustic WKE.

- MMT waves

The Majda-McLaughlin-Tabak (MMT) model was introduced by the authors as a simple and numerically affordable model to test the theory of wave turbulence
Majda et al., 1997
. It consists on a one-dimensional partial differential equation where the dispersion relation and the homogeneity degree of the non-linearity are tunable parameters. This model has triggered enormous research and opened the way to the study of solitonic turbulence. It is still the matter of recent academic research, both from mathematicians and theoretical physicists. For a complete review see
Zakharov et al., 2004
.

WavKinS.jl
solves the 1D-MMT WKE (
7
) with

\displaystyle\omega_{k}=k^{1/2},\quad{\rm and}\quad T^{12}_{34}=|k_{1}k_{2}k_{3}k_{4}|^{\beta/4}.

(14)

The full parametrisation of the resonant manifold is provided in the documentation. The numerical cost of the 1D-MMT WKE is of the order of
M^{2}
operations per time step.

- Nonlinear Schrödinger equation

The nonlinear Schrodinger (NLS) equation is one of the most important model in physics. Its applications vary from nonlinear optics, water waves to Bose-Einstein condensates. The equation is also known as the Gross-Pitaevskii equation, a fundamental equation describing superfluids. For a discussion on the wave kinetic description of the NLS equation, see
Dyachenko et al., 1992
;
Nazarenko, 2011
;
Zhu et al., 2023
.

WavKinS.jl
solves the isotropic 3D-NLS WKE, which corresponds to taking
\omega_{k}=k^{2}
and
T^{12}_{34}=1
in Eq. (
7
). Assuming isotropy, the 3D-NLS WKE collisional integral reduces to

\displaystyle St_{k}

\displaystyle=

\displaystyle\frac{4\pi^{3}}{k}\int\mathcal{S}^{k1}_{23}\delta(\omega^{k1}_{23})\,n_{k}n_{1}n_{2}n_{3}

(15)

\displaystyle\times\left(\frac{1}{n_{k}}+\frac{1}{n_{1}}-\frac{1}{n_{2}}-\frac{1}{n_{3}}\right)d\omega_{1}d\omega_{2}d\omega_{3},

with
\mathcal{S}^{k1}_{23}=\min{[k,\sqrt{\omega_{1}},\sqrt{\omega_{2}},\sqrt{\omega_{3}}]}
.

The numerical cost of the isotropic NLS WKE is of the order of
M^{3}
operations per time step.

- Petviashvilli waves

The Petviashvilli equation is an important model describing geophysical flows and fusion plasmas. In particular, it models drift waves in plasmas and Rossby waves in geophysical fluids
Nazarenko, 2011
.

WavKinS.jl
solves the Petviashvilli WKE for
n_{\bf k}
and
{\bf k}=(k_{x},k_{y})
, with
k_{x}>0
in the limit
k_{x}\ll|k_{y}|
, which corresponds to (
3
) with

\omega_{\bf k}=k_{x}k_{y}^{2},\quad{\rm and}\quad V_{{\bf 123}}=\frac{1}{2}\sqrt{k_{1x}k_{2x}k_{3x}}.

(16)

The parametrisation of the resonant manifold is provided in the documentation.
In addition to energy, the Petviashvilli WKE conserves the potential vorticity
\Omega
and the zonostrophy
\Phi
defined as

\Omega=\int_{k_{x}>0}k_{x}n_{\bf k}d{\bf k},\quad\Phi=\int_{k_{x}>0}\frac{k_{x}^{3}}{k_{y}^{2}}n_{\bf k}d{\bf k}.

(17)

The numerical cost of the WKE is of the order of
M^{3}
operations per time step.

- Stratified waves

Internal Gravity Waves (IGW) propagate in stratified flows like the oceans and atmospheres. They are therefore important for geophysical applications (see
Lvov et al., 2012
for a review).
WavKinS.jl
solves the IGW WKE in the strong anisotropy (or hydrostatic) limit, where we consider that the horizontal wave vector
k_{h}
is small compared to the vertical wave vector
k_{z}
.

The WKE for internal waves in the hydrostatic limit is given by equation (
3
) with

\displaystyle V_{k12}=\sqrt{\frac{k_{h}k_{1h}k_{2h}}{32}}\left(\frac{{\bf k}_{h}\cdot{\bf k}_{1h}}{k_{h}k_{1h}}\sqrt{\left|\frac{k_{2z}}{k_{z}k_{1z}}\right|}+\,permutations\,\right),

(18)

and
\omega_{k}=Nk_{h}/|k_{z}|
with
N
the buoyancy frequency
Lvov and Tabak, 2001
;
Labarre et al., 2024b

WavKinS.jl
assumes isotropy on the plane perpendicular to the vertical direction, which reduces the numerical cost of the WKE to roughly
M^{4}
operations per time step. The numerical integration is therefore costly, but feasible in shared memory clusters
Labarre et al., 2024a
. The equations solved by
WavKinS.jl
are explicitly given in the documentation.

- Smoluchowski kinetic equation

The Smoluchowski equation is a standard model of statistical physics. It describes coagulation processes such as droplets in clouds, blood clots, meteorite formation from stellar dust, and so on. Although it is not a wave kinetic equation, it shares a similar structure with the WKE, so all the routines implemented in
WavKinS.jl
can be used.

For the Smoluchowski equation,
k
denotes the particle mass and
n_{k}
is the particle mass distribution. The collision integral is

\displaystyle St_{k}=

\displaystyle\frac{1}{2}\int\limits_{0}^{k}~K(k-p,p)~n(k-p,t)~n(p,t)~\mathrm{d}p

(19)

\displaystyle-\int\limits_{0}^{\infty}~K(k,p)~n(k,t)~n(p,t)~\mathrm{d}p.

Some kernels
K
, quantifying the interaction between particles, are already implemented in
WavKinS.jl
, but the user can easily implement new ones and pass them as arguments.

Finally, the numerical cost of the Smoluchowski equation is of the order of
M^{2}
operations per time step.

I  Implementation and architecture

I  Numerical schemes

To simulate a WKE, one must first compute the collisional integral
St_{\bf k}
, which results in computing several integrals over the resonant manifold that is assumed to be known analytically. In order to perform such integrals, one also needs to interpolate the waveaction spectrum
n_{\bf k}
on intermesh values. Once
St_{\bf k}
is known, the time evolution of
n_{\bf k}
is obtained using a given time-stepping scheme.

In the following, we describe the basic methods used by
WavKinS.jl
. For the sake of simplicity, we reduce the discussion to systems where
n_{\bf k}
is a function of a single variable
k
(
1d
or isotropic spectra). The systems depending on two variables are straightforward generalisations and they are discussed in the documentation.

- Grids and basic fields

The basic structure of
WavKinS.jl
is the
wave_spectrum
Julia structure, which contains the waveaction spectrum
n_{k}
and the grid of wavevectors. The wavevector space is discretised using
M
nodes in a logarithmic grid:

k_{i}=k_{\rm min}\lambda^{i-1},\quad i=1,\ldots,M.

(20)

The structure can be constructed in different ways specified in the documentation.

- Integration

For integration, the codes uses by default a standard trapezoidal rule on the log-lattice. For instance, the integral over two mesh points is treated as

\displaystyle\int_{k_{i}}^{k_{i+1}}F(k)\mathrm{d}k

\displaystyle=

\displaystyle\log{\lambda}\int_{i}^{i+1}F(k(x))k(x)\mathrm{d}x

\displaystyle\approx

\displaystyle\frac{\log{\lambda}}{2}(F_{i+1}k_{i+1}+F_{i}k_{i}),

where
F_{i}=F(k_{i})
and we have performed the change of variable
k=k_{\rm min}\lambda^{x}
. For integrals on the interval
[0,k_{1}]
, the code uses directly a standard trapezoidal rule, where the value of
F
at
k=0
is obtained by linear extrapolation. In the tests, it is shown an excellent convergence of the method. Other integration schemes are also available.

- Interpolation

The default interpolation method is linear. It has the advantage of preserving positivity, a key property to ensure stability of the integration of the WKEs. Several other schemes are available, but they are less robust.

The errors in the computation of the WKE mainly come from interpolations, for instance, when using linear interpolation, the error in the conservation of invariants decrease as
M^{-2}
, where
M
is the number of mesh points per dimension. As a matter of example, in Fig.
2
we show the conservation errors for the Petviashvilli WKE invariants.

Figure 2:
Conservation errors of energy, potential vorticity and zonostrophy for the Petviashvilli WKE. The error is computed as
Error=(Q(t)-Q(0))/Q(0)
, where
Q(t)
is one of the invariants. The figure is taken from
WavKinS.jl
documentation.

For each physical system, the documentation contains a similar study of the invariant conservation. The respective scripts are also provided in the code.

- Temporal schemes

For all physical systems, several standard temporal schemes are available in
WavKinS.jl
(e.g. Euler, RK2, RK4, etc). Some solvers, like Petviashvilli waves, also offers more elaborated splitting methods for time stepping. The codes also includes an adaptive time-stepping method which allows for saving computational time.

I  Software architecture

The code is written in Julia language, and organised in the standard way of Julia projects. More precisely, it is structured in the following manner:

src

Source files of the code, organised as follows:

grid

: Structures and functions for the grids.

integration

Tools used for integrations, mainly for log grids.

interpolation

Tools used for interpolations, mainly for log grids.

physical_systems

Structures and necessary functions for the simulations of wave systems. We use a sub-folder for each system, which contains:

basics.jl

Definitions of the dispersion relation, interaction coefficients, resonant manifold, etc.

collision_integral.jl

Defines the method for computing for computing the collision integral
St_{k}
. The method is overloaded, allowing the same syntax for all solvers.

structure.jl

Main Julia structure for the physical system.

diagnostics.jl

Non-default diagnostics/functions.

Common definitions and structures used for several wave systems are given in
basics_all.jl
. Some wave systems contain multiple variations grouped in the same sub-folder for consistency (e.g.,
Acoustic
includes
2D
and
3D
isotropic acoustic wave systems with the same dispersion relation but differing in spatial dimension and/or forcing).

plot

Standard
WavKins
plots, created using the
Makie.jl
package with the
GLMakie.jl
backend.

time_stepping

Standard functions for time stepping.

WavKinS_diagnostics.jl

Definitions of default diagnostics (total waveaction, total energy, total energy dissipation, energy spectrum, waveaction fluxes, energy fluxes, etc.).

WavKinS_outputs.jl

Input/Output functions.

WavKinS_parameters.jl

Structures for simulation parameters (output directory, output selection, final time, etc.).

WavKinS_partitions_threads.jl

Tools for multithreading, including functions for partitioning nodes among threads.

WavKinS_structures.jl

Basic structures used in
WavKinS.jl
simulations (spectra, parameter containers, etc.).

run

Run simulations and test the code.

simple

Simple simulations for various physical systems.

tests

Test the different parts of the code (see the folder
src
) and next section.

postproc

Example scripts (Julia, Python, and Matlab) that show how we can analyze outputs of some simulations.

docs

Documentation.

I  Quality control

The current version of the code contains tests of the integration and interpolation schemes. Moreover, each physical system contains scripts to test the conservation of their respective invariants. The current version of the code does not have yet automatic unit tests.

Reuse potential

This code is a tool for simulating the wave kinetic equations of several physical systems, and can be thus used in scientific research.
To this date,
WavKinS.jl
has been used in two scientific publications
Labarre et al., 2024a
;
Zhu et al., 2024
. Any user with some basic experience in Julia can use the script provided in
WavKinS.jl
to completely reproduce the numerical results of these two works.

Several other physical systems are already implemented in
WavKinS.jl
and ready to be used.
WavKinS.jl
has been designed in a modular manner such that a user could use the basic structures of the code to easily implement new physical systems. In the documentation, we provide some basic guidelines on how this can be done, and give some general advice and good practices. There is no support for
WavKinS.jl
. However, users can contact the authors of this work for eventual help or new collaborations.
