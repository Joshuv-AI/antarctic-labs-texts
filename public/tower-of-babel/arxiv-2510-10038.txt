Longest paths in trees and isometricity of ultrametric spaces
Oleksiy Dovgoshey, Olga Rovenska

Abstract
Let T T be a tree of arbitrary finite or infinite order and let U ⁡ ( T ) U(T) be the set of all ultrametric spaces generated by vertex labelings of T T . Let 𝐔𝐒 {\bf US} denote the class of all ultrametric spaces generated by vertex labelings of star graphs. We prove that the inclusion U ⁡ ( T ) ⊆ 𝐔𝐒 U(T)\subseteq{\bf US} holds if and only if the longest path in T T has a length not exceeding three.

The main goal of the present paper is to describe, up to isomorphism, the structure of trees

T

2
Preliminaries.
Metric spaces and graphs

Let us denote by
\mathbb{R}^{+}
the set
[0,\infty)
.

An
ultrametric
on a nonempty set
X
is a function
d\colon X\times X\rightarrow\mathbb{R}^{+}
satisfying the following conditions for all

x
,
y
,
z\in X
:

(i)

d(x,y)=d(y,x)
, the symmetry property;

(ii)

(d(x,y)=0)\iff(x=y)
, the positivity property;

(iii)

d(x,y)\leq\max\{d(x,z),d(z,y)\}
, the strong triangle inequality.

Definition 2.1
.

Let
(X,d)
and
(Y,\rho)
be ultrametric spaces. A bijective mapping
\Phi\colon X\to Y
is called an
isometry
of
(X,d)
and
(Y,\rho)
if

d(x,y)=\rho(\Phi(x),\Phi(y))

holds for all
x
,
y\in X
. The ultrametric spaces are said to be
isometric
if there is an isometry of these spaces.

A
simple graph
is a pair
(V,E)
, where
V
is a nonempty set and
E
is a set of two-point subsets of
V
. For a simple graph
G=(V,E)
, the sets
V=V(G)
and
E=E(G)
are called the
vertex set
and the
edge set
, respectively. If
\{x,y\}\in E(G)
, then the vertices
x
and
y
are called
adjacent
. In what follows we will consider the simple graphs only. The
order
of a graph
G
is the cardinal number of the set
V(G)
.
The graph
G
is called
finite
if the order of
G
is finite. Let
v
be a vertex of
G
. The cardinal number of the set

\{u\in V(G):\{u,v\}\in E(G)\}

is called the
degree
of the vertex
v
. The degree of
v
will be denoted as
\operatorname{deg}v
.

Definition 2.2
.

Let
G_{1}
and
G_{2}
be graphs. A bijective mapping
\Phi\colon V(G_{1})\to V(G_{2})

is called an
isomorphism
of
G_{1}
and
G_{2}
if the equalence

\{u,v\}\in E(G_{1})\iff\{\Phi(u),\Phi(v)\}\in E(G_{2})

is true for all
u,v\in V(G_{1})
.
The graphs are said to be
isomorphic
if there is an isomorphism of these graphs.

Let
G
be a graph.
A graph
G_{1}
is a
subgraph
of
G
if

V(G_{1})\subseteq V(G)\quad\text{and}\quad E(G_{1})\subseteq E(G).

In this case we write
G_{1}\subseteq G
.

A
path
is a finite graph
P
whose vertices can be numbered without repetitions so that

V(P)=\{v_{1},\ldots,v_{k}\}\quad\text{and}\quad E(P)=\{\{v_{1},v_{2}\},\ldots,\{v_{k-1},v_{k}\}\}

(2.1)

with
k\geqslant 2
. We write
P=(v_{1},\ldots,v_{k})
if
P
is a path satisfying (
2.1
) and said that
P
is a
path joining
v_{1}
and
v_{k}
.
The
length
of the path
P
is the number of edges that
P
contains.
A path
P_{1}\subseteq G
is called to be the
longest path
in
G
if the inequality

|E(P)|\leq|E(P_{1})|

holds for every path
P\subseteq G
.

A finite graph
C
is a
cycle
if
|V(C)|\geq 3
and there exists an enumeration of its vertices without repetition such that

V(C)=\{v_{1},\ldots,v_{n}\},\quad E(C)=\{\{v_{1},v_{2}\},\ldots,\{v_{n-1},v_{n}\},\{v_{n},v_{1}\}\}.

A graph
G
is
connected
if for every two distinct vertices of
G
there is a path
P\subseteq G
joining these vertices.
A connected graph without cycles is called a
tree
.

By
labeled tree
we understand a pair
(T,l)
, where
T
is a tree and
l
is a vertex labeling

l\colon V(T)\to\mathbb{R}^{+}.
We will use the symbol
T(l)
to denote the labeled tree
(T,l)
.

Let
T(l)
be a labeled tree and
d_{l}\colon V(T)\times V(T)\to\mathbb{R}^{+}
be defined as

d_{l}(u,v):=\begin{cases}0,&\text{if }u=v,\\
\max\limits_{w\in V(P)}l(w),&\text{if }u\neq v,\end{cases}

(2.2)

where
P
is the unique path joining
u
and
v
in
T
.

A labeling
l\colon V(T)\to\mathbb{R}^{+}
is said to be
non-degenerate
if the inequality

\max\{l(u),l(v)\}>0

holds for every
\{u,v\}\in E(T)
.

The following theorem was proved in
[
2
]
.

Theorem 2.3
.

Let
T(l)
be a labeled tree and let
d_{l}
be deined by (
2.2
). Then
d_{l}
is an ultrametric on
V(T)
if and only if

l\colon V(T)\to\mathbb{R}^{+}
is non-degenerate.

Let
(X,d)
be an ultrametric space.
In what follows we say that
(X,d)
is
generated by labeled tree
if there exists a labeled tree
T(l)
such that
X=V(T)
and
(X,d)=(V(T),d_{l})
.

Let
L(T)
be the set of all non-degenerate labelings defined on the vertex set of a fixed tree
T
.
Then we use the symbol
U(T)
to denote the set of all ultrametric spaces
(V(T),d_{l})
with
l\in L(T)
,

U(T):=\{(V(T),d_{l}):l\in L(T)\}.

If an ultrametric
space
(X,d)
belongs
to
U(T)
, then we say that

(X,d)
is
generated by vertex
labeling of
T
.

Let us recall the concept of star graphs.

Definition 2.4
.

A tree
S
is a
star graph
if there exists a vertex
c\in V(S)
such that
c
is adjacent to every vertex of the set
V(S)\setminus\{c\}
, and no other edges exist.

Let us denote by
{\bf US}
the class of all ultrametric spaces generated by labeled star graphs.

The following result was proved in
[
8
]
.

Theorem 2.5
.

Let
(X,d)
be an ultrametric space. Then the following conditions are equivalent:

(i)

(X,d)\in{\bf US}
.

(ii)

There is
x_{0}\in X
such that the inequality
d(x_{0},x)\leq d(y,x)

holds whenever

x\neq y.

For the proof of the next result see Proposition 4.2 of
[
3
]
.

Theorem 2.6
.

Let (X,d) be an
US
-space.
Then
(Y,d|_{Y\times Y})
is also an
{\bf US}
-space for every finite non-empty
Y\subseteq X
.

Lemma 3.1

Let

.

|E(P_{1})|\geq 4.

Then there is also a path
P_{2}\subseteq P_{1}
having exactly four edges,

|E(P_{2})|=4.

is an ultrametric on

, where
d_{l_{2}}
defined by (

) with

and

.
Moreover, using Theorem

(V(P_{2}),d_{l_{2}})\notin{\bf US}.

(3.3)

It is easy to see that there exists a non-degenerate

Inclusion (

(V(T),d_{l})\in{\bf US}.

Hence the ultrametric space
(V(P_{2}),d_{l}\big|_{V(P_{2})\times V(P_{2})})

also belongs to

.
Using formula (

d_{l_{2}}=d_{l}\big|_{V(P_{2})\times V(P_{2})}.

(V(P_{2}),d_{l_{2}})\in{\bf US}.

The last statement contradicts relation (

) follows.

Lemma
3.1
implies that the length of the longest path
P^{*}\subseteq T
does not exceed three if

U(T)\subseteq{\bf US}.

The inequality
|E(P^{*})|\leq 3
gives us an information about vertices
u,v\in V(T)
whose degree is greater than one.

Lemma 3.2
.

Let
T
be a tree and let

|E(P)|\leq 3

(3.4)

holds for every path
P\subseteq T
.
Then
every two distinct vertices
u
and
v
whose degree is greater than one,

\operatorname{deg}u\geq 2\quad\text{and}\quad\operatorname{deg}v\geq 2,

(3.5)

are adjacent,

\{u,v\}\in E(T).

(3.6)

Proof.

Let distinct
u,v\in V(T)
satisfy (
3.5
).
Suppose that

\{u,v\}\notin E(T).

(3.7)

Since every tree is a connected graph, relation (
3.7
) implies the existence of a path
P^{0}\subseteq T
such that

P^{0}=(v_{1},\ldots,v_{n}),

with
v_{1}=u,

v_{n}=v
and
n\geq 3
.
Using inequalities (
3.5
) we can find some vertices
v_{0},v_{n+1}
of
T
such that

\{v_{0},v_{1}\}\in E(T),\quad\{v_{n},v_{n+1}\}\in E(T)

(3.8)

and

v_{0}\neq v_{2},\quad v_{n+1}\neq v_{n-1}.

(3.9)

The tree
T
is an acyclic graph. Consequently we also have

v_{0}\notin\{v_{2},\ldots,v_{n}\}\quad{\rm and}\quad v_{n+1}\notin\{v_{1},\ldots,v_{n-2}\}.

(3.10)

Now relations (
3.8
)–(
3.10
) imply that

P^{*}=(v_{0},v_{1},\ldots,v_{n},v_{n+1})

is a path joining
v_{0}
and
v_{n+1}
in
T
.
It is clear that
P^{0}\subseteq P^{*}\subseteq T
and

|E(P^{*})|=|E(P^{0})|+2.

(3.11)

Furthermore, the inequality

|E(P^{0})|\geq 2

holds by the definition of the path
P^{0}
. The last inequality and (
3.11
) give us the inequality

|E(P^{*})|\geq 4,

that contradicts (
3.4
).

Relation (
3.6
) follows.

∎

The next lemma almost directly follows from Lemma
3.2
.

Lemma 3.3
.

Let
T
be a tree and let inequality (
3.4
)
hold for every path
P\subseteq T
. Then
T
contains at most two vertices whose degree is greater than one.

Proof.

Suppose that
u,v,w\in V(T)
are distinct and that the inequality

\min\{\deg u,\deg v,\deg w\}\geq 2

holds. Then we have

\{\{u,v\},\{v,w\},\{w,u\}\}\subseteq E(T)

by Lemma
3.2
.
Consequently
T
contains the cycle
C
with

V(C)=\{u,v,w\},\quad E(C)=\{\{u,v\},\{v,w\},\{w,u\}\},

that is impossible by definition of trees. Thus
T
has at most two vertices whose degree is greater than one, as was stated.

∎

The following theorem is the main result of the present paper.

Theorem 3.4
.

Let
T
be a tree.
Then the following statements are equivalent:

(i)

The inclusion

U(T)\subseteq{\bf US}

(3.12)

holds.

(ii)

The inequality

|E(P)|\leq 3

holds for every path
P\subseteq T
.

(iii)

There exist at most two distinct vertices
u,v\in V(T)
such that

\deg u\geq 2\quad\text{and}\quad\deg v\geq 2.

(3.13)

Proof.

The implication
(i)\Rightarrow(ii)
is true by Lemma
3.1
.
Lemma
3.2
and Lemma
3.3
imply the validity of the implication
(ii)\Rightarrow(iii)
.
Thus we only need to prove that statement
(iii)
implies statement
(i)
.

Let statement
(iii)
be true. Suppose first that we have the inequality
\deg v\leq 1
for every
v\in T
.
Then, using Definition
2.4
, we see that
T
is a star graph, and, consequently (
3.12
) holds.
Analogously,

T
is a star graph and we have (
3.12
)
if there exists the unique vertex
v\in T
with
\deg v\geq 2
.

Let us consider now the case
where
T
contains two distinct
vertices
u
and
v

such that (
3.13
) holds. First of all we note that in this case statement
(iii)
implies membership relation

\{u,v\}\in E(T).

(3.14)

Let
L(T)
be the set of all non-degenerate labelings
defined on
V(T)
.
Inclusion (
3.12
) holds if and only if the relation

(V(T),d_{l})\in{\bf US}
is true for each
l\in L(T).

Let
l^{*}\in L(T)
be arbitrary.
Then, without loss of generality, we
can assume that the inequality

l^{*}(u)\leq l^{*}(v)

(3.15)

holds.
By Theorem
2.5
the membership relation

(V(T),d_{l^{*}})\in{\bf US}

holds if we have

d_{l^{*}}(u,w)\leq d_{l^{*}}(z,w)

(3.16)

whenever
z\in V(T)
and
z\neq w
.

Let us consider an arbitrary
w\in V(T)
.
If
w=u
holds, then (
3.16
) follows
from the positivity property of ultrametric spaces.

Analogously, (
3.16
) is trivially
valid if
z=w
.

Suppose now that
u,w
and
z

are pairwise distinct.

Let us first consider the case

\{u,v\}\in E(T)\quad\text{and}\quad\{u,z\}\in E(T).
