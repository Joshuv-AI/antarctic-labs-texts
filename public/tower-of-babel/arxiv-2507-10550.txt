The Value Problem for Weighted Timed Games with Two Clocks is Undecidable
Quentin Guilmant, Joël Ouaknine, Isa Vialard

Abstract
. The Value Problem for weighted timed games (WTGs) consists in determining, given a two-player weighted timed game with a reachability objective and a rational threshold, whether or not the value of the game exceeds the threshold. This problem was shown to be undecidable some ten years ago for WTGs making use of at least three clocks, and is known to be decidable for single-clock WTGs. In this paper, we establish undecidability for two-clock WTGs making use of non-negative weights, even in a time-bounded setting, closing the last remaining major gap in our algorithmic understanding of WTGs.



1.
Introduction

Real-time systems are not only ubiquitous in modern technological
society, they are in fact increasingly pervasive in critical applications —
from embedded controllers in automotive and avionics platforms to
resource-constrained communication protocols. In such systems,
exacting timing constraints and quantitative objectives must often be
met simultaneously. Weighted Timed Games (WTGs), introduced over two
decades
ago
(
Maler et al. 1995
;
Alur and Henzinger 1997
;
Henzinger et al. 1999
;
Alur et al. 2004
;
Bouyer et al. 2005
)
, provide a powerful
modelling framework for the automatic synthesis of controllers in such
settings: they combine the expressiveness of Alur and Dill’s
clock-based timed automata with
\mathbf{Min}
-
\mathbf{Max}
gameplay and
non-negative integer weights on both locations and transitions,
enabling one to reason about quantitative aspects such as energy consumption,
response times, or resource utilisation under adversarial
conditions.

A central algorithmic task for WTGs is the
Value Problem
: given
a two-player, turn-based WTG with a designated start configuration and
a rational threshold
c
, determine whether Player
\mathbf{Min}
can
guarantee reaching a goal location with cumulative cost at most
c
,
despite best adversarial play by Player
\mathbf{Max}
. This problem lies at
the heart of quantitative controller synthesis and performance
analysis for real-time systems.

Unfortunately, fundamental algorithmic barriers are well known. In
particular, the Value Problem is known to be undecidable in general,
both for WTGs making use of three or more
clocks
(
Bouyer et al. 2015
)
, as well as for two-clock extensions of WTGs
in which arbitrary integer (positive and negative) weights are
allowed
(
Brihaye et al. 2014
)
. In fact, even approximating the
value of three-clock WTGs with integer weights is known to be
computationally unsolvable
(
Guilmant and Ouaknine 2024
)
. On the positive side,
the Value Problem for WTGs making use of a single clock is decidable,
regardless of whether weights range over

\mathbb{N}
or

\mathbb{Z}

(
Bouyer et al. 2006
;
Monmege et al. 2022
)
. There is a voluminous
literature in this general area; for a comprehensive overview and
discussion of the state of the art, we refer the reader
to

)

The case of WTGs with exactly two clocks (and non-negative weights)
has remained stubbornly open. Resolving this question is
essential, since two clocks suffice to encode most practical timing
constraints (e.g., deadline plus cooldown), and efficient single-clock
algorithms cannot in general be lifted to richer timing scenarios. The
main contribution of this paper is to close this gap by establish undecidability:

Theorem 1.1.

The Value Problem for two-player, turn-based, time-bounded, two-clock,
weighted timed games with non-negative integer weights is undecidable.
The same holds for weighted timed games over unbounded time otherwise
satisfying the same hypotheses.

Our reduction is from the halting problem for deterministic
two-counter machines and proceeds via a careful encoding of counter
values in clock valuations, combined with “punishment” gadgets that
force faithful simulation or allow the adversary to drive the
accumulated cost up. Key technical novelties include:

•

Counter-Evolution Control (CEC) modules, which enforce precise
proportional delays encoding incrementation and decrementation of
counters.

•

Multiplication-Control (MC) gadgets, allowing the adversary to
verify whether simulated counter updates match exact multiplication
factors.

•

Zero and Non-Zero control schemes, enabling precise zero-testing
within the two-clock framework and ensuring that any deviation from
a faithful simulation triggers a cost penalty.

Together, these constructions fit within the two-clock timing
structure and utilise only non-negative integer weights, thereby
demonstrating that even the two-clock fragment — previously the only
remaining decidability candidate — admits no algorithmic solution for the
Value Problem. As a complementary result, we also show that the
related Existence Problem (does
\mathbf{Min}
have a strategy to achieve cost at
most
c
?) is undecidable under the same hypotheses.

Let us conclude by noting that our reduction is implemented via WTGs
having bounded duration by construction. This is notable in view of
the fact that many algorithmic problems for real-time and hybrid
systems that are known to be undecidable over unbounded time become
decidable in a time-bounded setting; see, e.g.,
(
Ouaknine et al. 2009
;
Ouaknine and Worrell 2010
;
Jenkins et al. 2010
;
Brihaye et al. 2011
;
Brihaye et al. 2013
)
.

Definition 2.1.

A

•

•

•

•

.

In the above, we assume that all data (set of locations, set of

Definition 2.2.

A WTG
\mathcal{G}=(L,G,\mathcal{X},T_{\mathbf{Min}},T_{\mathbf{Max}},w)
is said to be

if for any location
\ell\in L
the set of transitions from
\ell
is entirely contained either in

or
T_{\mathbf{Max}}
. In this case we may partition

into

and

\mathbf{Min}

Abusing notation, we may then equivalently refer to

as the tuple

.
Finally, a WTG which is not turn-based is called

. In the remainder of this paper, we shall
exclusively work with turn-based weighted timed games.

Let
\mathcal{G}=(L,G,\mathcal{X},T_{\mathbf{Min}},T_{\mathbf{Max}},w)
be
a weighted timed game. A
configuration
over

\mathcal{G}
is a pair
(\ell,\nu)
, where
\ell\in L
and
\nu

is a valuation on
\mathcal{X}
. We write

\mathscr{C}_{\mathcal{G}}=L\times\mathbb{R}_{\geq 0}^{\mathcal{X}}
to denote the set of configurations over
\mathcal{G}
. Let

be a

delay
and

be a discrete transition. One has a

(or simply a

. Intuitively,

which it transitions to location

,
resetting all the clocks in

to zero in the process. The

.

As noted in
(
Busatto-Gaston et al. 2023
)
,
without loss of generality one can assume that no
configuration (other than those associated with goal

\ell\in L\setminus G
and valuation

\nu\in\mathbb{R}_{\geq 0}^{\mathcal{X}}
, there exists

and

such that

1

In our
setting, this

Let

. A
run

\rho

|\rho|=k

\mathcal{G}
from a given configuration

is a sequence of matching delayed

\rho=(\ell_{0},\nu_{0})\xrightarrow{d_{0},t_{0}}(\ell_{1},\nu_{1})\xrightarrow{d_{1},t_{1}}\cdots\xrightarrow{d_{k-1},t_{k-1}}(\ell_{k},\nu_{k})\,.

We denote by

the

We also write

.
The

\mathsf{weight}(\rho)=\sum_{i=0}^{|\rho|-1}(d_{i}\cdot w(\ell_{i})+w(t_{i}))\,.

This definition can be extended to infinite runs;

.

A run is

2.3.
Strategies and value of a game

We now define the notion of
strategy
.
Recall that transitions of
\mathcal{G}
are partitioned into sets

and

\mathbf{Min}

\mathbf{Max}
.
Let Player

\sigma_{\mathsf{P}}(\rho)
and

Let us fix a starting configuration
(\ell_{0},\nu_{0})
, and let

\sigma_{\mathbf{Min}}
and
\sigma_{\mathbf{Max}}
be strategies for

\mathbf{Min}
and
\mathbf{Max}
respectively (one speaks of

\mathsf{play}_{\mathcal{G}}((\ell_{0},\nu_{0}),\sigma_{\mathbf{Min}},\sigma_{\mathbf{Max}})

and unfolding according to the strategy profile

for every strict finite prefix
\rho

in

, the delayed transition

Recall that the objective of Player

is to reach a goal

has an opposite objective, trying to avoid goal

any attendant play. This gives rise to the following symmetrical definitions:

\displaystyle\overline{{\mathsf{Val}}}_{\mathcal{G}}(\ell_{0},\nu_{0})

\displaystyle=\inf_{\sigma_{\mathbf{Min}}}\left\{\sup_{\sigma_{\mathbf{Max}}}\left\{\mathsf{weight}(\mathsf{play}_{\mathcal{G}}((\ell_{0},\nu_{0}),\sigma_{\mathbf{Min}},\sigma_{\mathbf{Max}}))\right\}\right\}\mbox{\ and}

\displaystyle\underline{{\mathsf{Val}}}_{\mathcal{G}}(\ell_{0},\nu_{0})

\displaystyle=\sup_{\sigma_{\mathbf{Max}}}\left\{\inf_{\sigma_{\mathbf{Min}}}\left\{\mathsf{weight}(\mathsf{play}_{\mathcal{G}}((\ell_{0},\nu_{0}),\sigma_{\mathbf{Min}},\sigma_{\mathbf{Max}}))\right\}\right\}\,.

\overline{\mathsf{Val}}_{\mathcal{G}}(\ell_{0},\nu_{0})
represents the smallest
possible weight that Player
\mathbf{Min}
can possibly achieve,
starting from configuration
(\ell_{0},\nu_{0})
,
against best play from Player
\mathbf{Max}
, and conversely for

\overline{\mathsf{Val}}_{\mathcal{G}}(\ell_{0},\nu_{0})
: the latter represents
the largest possible weight that Player
\mathbf{Max}
can enforce,
against best play from Player
\mathbf{Min}
.

3.
Undecidability

To establish our undecidability result, we reduce the Halting Problem for two-counter machines to the Value Problem.
A two-counter machine is a tuple
\mathcal{M}=(Q,q_{i},q_{h},T)

where
Q
is a finite set of states,
q_{i},q_{h}\in Q
are the initial and final state and
T\subseteq(Q\times\{c,d\}\times Q)\cup(Q\times\{c,d\}\times Q\times Q)
is a set of transitions.
A two-counter machine is deterministic if for any state
q
there is at most one transition
t\in T
which has
q
as first component.
As its name suggests, a two-counter machine comes equipped with two counters,
c
and
d
, which are variables with values in
\mathbb{N}
.
The semantics is as follows: a transition
(q,e,q^{\prime})
increases the
value of counter
e\in\{c,d\}
by
1
and moves to state
q^{\prime}
. A
transition
(q,e,q^{\prime},q^{\prime\prime})
moves to
q^{\prime}
if
e=0
and to
q^{\prime\prime}

otherwise. In the latter case, it also decreases the value of
e
by
1
.
The Halting Problem for (deterministic) two-counter machines is known to be undecidable
(see
(
Minsky 1967
, Thm. 14-1)
).

3.1.
Overview of the reduction

Let
\mathcal{M}
be a two-counter machine with counters
c
and

d
. We consider a WTG
\mathcal{G}_{\mathcal{M}}

between players
\mathbf{Min}
and
\mathbf{Max}
with two clocks
x
and
y
.

\mathbf{Min}
is in charge of simulating the two-counter machine

\mathcal{M}
while
\mathbf{Max}
has the opportunity to punish
\mathbf{Min}
’s
errors. In encoding
\mathcal{M}
as through
\mathcal{G}_{\mathcal{M}}
, some of the locations of

\mathcal{G}_{\mathcal{M}}
will represent states of
\mathcal{M}
. Upon
entering a location of
\mathcal{G}_{\mathcal{M}}
, a faithful encoding of
counters
c
and
d
is represented through a clock valuation in which

and

x=1-\frac{1}{2^{c}3^{d}5^{n}}\,,

where

is the number of steps of the execution of
\mathcal{M}

that have been simulated so far.
Furthermore, in order to simulate the next step faithfully,

•

If the current state requires
c
to be incremented,

\mathbf{Min}
should wait in this location until

reaches

1-\frac{1}{2^{c+1}3^{d}5^{n+1}}
; this means that
\mathbf{Min}
should wait
\frac{9}{10}(1-x)
time units.

•

If the current state requires
d
to be incremented,

\mathbf{Min}
should wait in this location until
x
reaches
value
1-\frac{1}{2^{c}3^{d+1}5^{n+1}}
; this means that
\mathbf{Min}
should wait
\frac{14}{15}(1-x)
time units.

•

If the current state requires
c
to be decremented,

\mathbf{Min}
should wait in this location until
x
reaches
value
1-\frac{1}{2^{c-1}3^{d}5^{n+1}}
; this means that
\mathbf{Min}
should wait
\frac{3}{5}(1-x)
time units.

•

If the current state requires
d
to be decremented,

\mathbf{Min}
should wait in this location until
x
reaches
value
1-\frac{1}{2^{c}3^{d-1}5^{n+1}}
; this means that
\mathbf{Min}
should wait
\frac{2}{5}(1-x)
time units.

•

If the current state is a succesful zero-test for
c
or

d
,
\mathbf{Min}
should wait in this location until
x

reaches value
1-\frac{1}{2^{c}3^{d}5^{n+1}}
; this means that
\mathbf{Min}
should wait
\frac{4}{5}(1-x)
time units.

After
\mathbf{Min}
has chosen the waiting time,
\mathbf{Max}
is given the opportunity to end the game with an increased cost if
\mathbf{Min}
“cheated”.
In the case of a zero-test, if
\mathbf{Min}
takes a transition towards the wrong state,
\mathbf{Max}
is also given the opportunity to end the game asking for a proof that the corresponding counter is indeed
0
(respectively not
0
). Finally, before simulating another step,
\mathbf{Min}
is also given the opportunity to exit the game. Note also that since the halting state of
\mathcal{M}
has no outgoing transitions,
\mathbf{Min}
will be forced to end the game if she reaches the location representing this state.

Theorem 3.9.

The Existence Problem for two-player, turn-based, time-bounded, two-clock,
weighted timed games with non-negative integer weights is undecidable.
The same holds for weighted timed games over unbounded time otherwise
satisfying the same hypotheses.

\mathcal{M}
