An Optimal Control Approach for Inverse Problems with Deep Learnable Regularizers
Wanyu Bian

Abstract
This paper introduces an optimal control framework to address the inverse problem using a learned regularizer, with applications in image reconstruction. We build upon the concept of Learnable Optimization Algorithms (LOA), which combine deep learning with traditional optimization schemes to improve convergence and stability in image reconstruction tasks such as CT and MRI. Our approach reformulates the inverse problem as a variational model where the regularization term is parameterized by a deep neural network (DNN). By viewing the parameter learning process as an optimal control problem, we leverage Pontryagin’s Maximum Principle (PMP) to derive necessary conditions for optimality. We propose the Method of Successive Approximations (MSA) to iteratively solve the control problem, optimizing both the DNN parameters and the reconstructed image. Additionally, we introduce an augmented reverse-state method to enhance memory efficiency without compromising the convergence guarantees of the LOA framework.

Solving the Inverse Problem from The Optimal Control Viewpoint

In this work we propose an optimal control framework to solve the inverse problem by minimize the following varitional model with learned parameters:

\mathcal{E}(\mathbf{x};\theta)=\mathcal{D}(\mathbf{x},\mathbf{b})+\lambda\mathcal{R}(\mathbf{x};\theta),

(1)

where
\mathcal{D}
is the data fidelity term to guarantee the recovered signal
\mathbf{x}
is consistent with the measurement
\mathbf{b}
, which is usually with the quadratic form
\frac{1}{2}\|A\mathbf{x}-\mathbf{b}\|_{2}^{2}
for the linear sampling problem and
A
is the corresponding measurement matrix.
Here
\mathcal{R}
is the regularization that aims to incorporate proper prior knowledge of the underlying
\mathbf{x}
, which is realized as a well-structured DNN with parameter
\theta
to be learned.

Minimizing the variational model (
1
) with the gradient flow method
[
38
]
, we obtain the following ODE

\dot{\mathbf{x}}(t)=f({\mathbf{x}}(t),\theta)\mathrel{\mathop{\ordinarycolon}}=-\nabla_{\mathbf{x}}\mathcal{E}(\mathbf{x}(t);\theta),\ \ t\in[0,T].

(2)

We can cast the process of learning the undetermined parameters as an optimal control problem
(P)
with control parameters
\theta
:

\displaystyle\min_{\theta\in\Theta}\quad

\displaystyle J(\theta)\mathrel{\mathop{\ordinarycolon}}=\Phi(\mathbf{x}(T))+\int_{0}^{T}r(\mathbf{x}(t),\theta)\dif t,\qquad\mbox{(P)}

s.t.

\displaystyle\begin{cases}\dot{\mathbf{x}}(t)=f(\mathbf{x}(t),\theta),&\quad 0\leq t\leq T,\\
\mathbf{x}(0)=\mathbf{x}^{0},&\end{cases}\qquad\mbox{(ODE)}

where
\Phi(\mathbf{x}(T))
is the terminal cost and
r(\mathbf{x}(t),\theta)
is the running cost which usually plays role as the regularizer. Besides,
\Theta
is the admissible set for the control parameters
\theta
and
\mathbf{x}^{0}
is the initial.

3
Pontryagin’s Maximum Principle

First we give the definition of the Hamiltonian function
H\mathrel{\mathop{\ordinarycolon}}\mathbb{R}^{n}\times\mathbb{R}^{n}\times\Theta\rightarrow\mathbb{R}
by

H(\mathbf{x};\mathbf{p};\theta)=\mathbf{p}^{\top}f(\mathbf{x},\theta)-r(\mathbf{x},\theta),

(3)

based on which we state the Pontryagin’s Maximum Principle (PMP) below

Theorem 3.1

(Pontryagin’s Maximum Principle, Informal Statement)
.

If
\theta^{*}
optimizes the optimal control problem
(P)
, and
\mathbf{x}^{*}(t)
is its corresponding state trajectory. Then, there exists an absolutely continuous co-state process
\mathbf{p}^{*}(t),t\in[0,T]
such that

\begin{cases}\dot{\mathbf{x}}^{*}(t)=\nabla_{\mathbf{p}}H(\mathbf{x}^{*}(t);\mathbf{p}^{*}(t);\theta^{*}),\ \ \mathbf{x}^{*}(0)=\mathbf{x}_{0},\qquad\mbox{(ODE)}\\
\dot{\mathbf{p}}^{*}(t)=-\nabla_{\mathbf{x}}H(\mathbf{x}^{*}(t);\mathbf{p}^{*}(t);\theta^{*}),\mathbf{p}^{*}(T)=-\nabla_{\mathbf{x}}\Phi(\mathbf{x}^{*}(T))^{\top},\qquad\mbox{(ADJ)}\\
H(\mathbf{x}^{*}(t);\mathbf{p}^{*}(t);\theta^{*})=\max_{\theta}H(\mathbf{x}^{*}(t);\mathbf{p}^{*}(t);\theta),\qquad\mbox{(MAX)}\end{cases}

are satisfied.

4.1
Basic MSA

In light by the PMP, the basic Method of Successive Approximations (MSA) proposed in
[

]
are summarized in Algorithm
1
with an initial guess
\theta^{0}

Algorithm 1

The Basic MSA
[
39
]
to Solve Inverse Problem

1:

Initialize

\theta^{0}
.

2:

for

k=1,2,\dots,K
(training iterations)
do

3:

Solve
\dot{\mathbf{x}}^{k}(t)=f({\mathbf{x}}^{k}(t),\theta^{k-1})
,
\mathbf{x}^{k}(0)=\mathbf{x}_{0}
;

4:

Solve
\dot{\mathbf{p}}^{k}(t)=-\nabla_{\mathbf{x}}H({\mathbf{x}}^{k}(t),\mathbf{p}^{k}(t),\theta^{k-1})

\mathbf{p}^{k}(T)=-\nabla\Phi(\mathbf{x}^{k}(T))^{\top}
;

5:

Set
\theta^{k}=\argmax_{\theta}\int_{0}^{T}H({\mathbf{x}}^{k}(t),\mathbf{p}^{k}(t),\theta)dt
;

6:

end

for

7:

output:

\theta^{K}
.

If we apply a gradient ascend step to solve the maximization of the Hamiltonian in Line 5 of Algorithm
1
, we will have the following update for
\theta
:

\theta^{k}=\theta^{k-1}+\eta_{k}\nabla_{\theta}\int_{0}^{T}H({\mathbf{x}}^{k}(t),\mathbf{p}^{k}(t),\theta^{k-1})dt,

(4)

where
\eta
is the step size. As proved in
[
39
]
, with a gradient ascent (
4
) to maximize the Hamiltonian, the Algorithm
1
is equivalent to gradient descent with back-propagation (BP).
The same as BP, one bottleneck of the basic MSA is the linear memory cost
\mathcal{O}(T)
to cache all the intermediate states
\{(\mathbf{x}^{k}(t),\mathbf{p}^{k}(t))\mathrel{\mathop{\ordinarycolon}}t\in[0,T]\}
.

4.2
MSA with Augmented Reverse-State

As an alternative perspective, (
4
) can also be viewed as solving the following ODE backward in time

\theta^{k}=\overline{\theta}^{k}(0),\ \ \mbox{where}\ \ \frac{d\overline{\theta}^{k}(t)}{dt}=\eta_{k}\nabla_{\theta}H({\mathbf{x}}^{k}(t),\mathbf{p}^{k}(t),\overline{\theta}^{k}(T)),\ \ \mbox{with}\ \ \overline{\theta}^{k}(T)=\theta^{k-1}.

(5)

Explain:
if we integrate (
5
) backward w.r.t. time
t
, we get

\displaystyle\overline{\theta}^{k}(t)

\displaystyle=\overline{\theta}^{k}(T)+\eta_{k}\int_{T}^{t}\nabla_{\theta}H({\mathbf{x}}^{k}(t),\mathbf{p}^{k}(t),\overline{\theta}^{k}(T))dt

(6a)

\displaystyle=\theta^{k-1}+\eta_{k}\int_{T}^{t}\nabla_{\theta}H({\mathbf{x}}^{k}(t),\mathbf{p}^{k}(t),\theta^{k-1})dt\qquad\mbox{(Because we set $\overline{\theta}^{k}(T)=\theta^{k-1}$)}

(6b)

Then

\theta^{k}=\overline{\theta}^{k}(0)=\theta^{k-1}+\eta_{k}\int_{T}^{0}\nabla_{\theta}H({\mathbf{x}}^{k}(t),\mathbf{p}^{k}(t),\theta^{k-1})dt

(7)

which is exactly the same as the gradient ascent of the Hamiltonian defined in (
4
).

From the definition of
H
, we know that
\nabla_{\theta}H({\mathbf{x}},\mathbf{p},\theta)=\mathbf{p}^{\top}\nabla_{\theta}f(\mathbf{x},\theta)
.

Instead of solving for co-state
\mathbf{p}
and control
\theta
separately, here we can solve for the augmented reverse-state
[\mathbf{p},\overline{\theta}]
backward in time

\theta^{k}=\overline{\theta}^{k}(0),\ \ \mbox{where}\ \ \frac{d}{dt}\left[\begin{array}[]{c}\mathbf{p}^{k}(t)\\
\overline{\theta}^{k}(t)\end{array}\right]=\left[\begin{array}[]{c}-\nabla_{\mathbf{x}}H({\mathbf{x}}^{k}(t),\mathbf{p}^{k}(t),\overline{\theta}^{k}(T))\\
\eta_{k}\nabla_{\theta}H({\mathbf{x}}^{k}(t),\mathbf{p}^{k}(t),\overline{\theta}^{k}(T))\end{array}\right],\ \ \left[\begin{array}[]{c}\mathbf{p}^{k}(T)\\
\overline{\theta}^{k}(T)\end{array}\right]=\left[\begin{array}[]{c}-\nabla\Phi(\mathbf{x}^{k}(T))^{\top}\\
\theta^{k-1}\end{array}\right],

(8)

which can be easily verified that its numerical result is identical to Algorithm
1
with Line 5 solved by (
4
). But the merit is that solving (
8
) only demands constant memory
\mathcal{O}(1)
to cache the augmented reverse-state
[\mathbf{p},\overline{\theta}]
. However, in (
8
) we still need linear memory
\mathcal{O}(T)
to store all intermediate forward state
\{\mathbf{x}^{k}(t)\mathrel{\mathop{\ordinarycolon}}t\in[0,T]\}
. One way to tackle this issue is to augment it with the reverse state and solve for
\mathbf{x}^{k}(t)
backward as well with backward initial
\mathbf{x}^{k}(T)
computed from the forward pass
[
40
]
, as shown in (
9
).

\theta^{k}=\overline{\theta}^{k}(0),\ \ \mbox{where}\ \ \frac{d}{dt}\left[\begin{array}[]{c}\mathbf{x}^{k}(t)\\
\mathbf{p}^{k}(t)\\
\overline{\theta}^{k}(t)\end{array}\right]=\left[\begin{array}[]{c}\nabla_{\mathbf{p}}H({\mathbf{x}}^{k}(t),\mathbf{p}^{k}(t),\overline{\theta}^{k}(T))\\
-\nabla_{\mathbf{x}}H({\mathbf{x}}^{k}(t),\mathbf{p}^{k}(t),\overline{\theta}^{k}(T))\\
\eta_{k}\nabla_{\theta}H({\mathbf{x}}^{k}(t),\mathbf{p}^{k}(t),\overline{\theta}^{k}(T))\end{array}\right],\ \ \left[\begin{array}[]{c}\mathbf{x}^{k}(T)\\
\mathbf{p}^{k}(T)\\
\overline{\theta}^{k}(T)\end{array}\right]=\left[\begin{array}[]{c}\mathbf{x}^{k}(T)\\
-\nabla\Phi(\mathbf{x}^{k}(T))^{\top}\\
\theta^{k-1}\end{array}\right].

(9)

The whole process of (
9
) has constant memory cost
\mathcal{O}(1)
which frees the space of
\{\mathbf{x}^{k}(t)\mathrel{\mathop{\ordinarycolon}}t\in[0,T]\}
. But as a sacrifice we do trade the time for space as solving for (
9
) requires the re-computation of
\mathbf{x}^{k}(t)
.

If we replace the Line 4-5 in Algorithm
1
by (
8
) or (
9
), we can get an more memory-efficient algorithm with identical numerical result.

4.3
MSA with Backward Control Flow

As a careful observation in (
5
)-(
9
) on the right-hand side of the ODEs, all partial derivatives of
H
are evalauted on the initial state
\overline{\theta}^{k}(T)
. In this work, we further free this constraint and give more freedom to the dynamical system. So instead of computing the partial derivative of
H
on the initial
\overline{\theta}^{k}(T)
, we compute it on the intermediate state
\overline{\theta}^{k}(t)
. As discussed in
[
41
]
, the basic idea of the successive approximation methods is to find the optimal parameters from the guess by successive projections onto the manifold defined by the ODEs. So intuitively a better guess will contribute to better convergence performance and even better result. Our modification here gives a better guess to the optimal parameter
\theta^{*}
for the Hamiltonian
H
at the intermediate time
t
, since
\overline{\theta}^{k}(t)
is optimized backward in time so
\overline{\theta}^{k}(t)
is usually a better estimation point than
\overline{\theta}^{k}(T)
. Along with (
8
), we summarize our proposed algorithm in Algorithm
2
. The forward pass is to compute the trajectory of
{\mathbf{x}}^{k}(t)
, the backward pass is to compute the gradient flow for the co-state
{\mathbf{p}}^{k}(t)
and control
\overline{\theta}^{k}(t)
. We would like to point out that here we did not extend (
9
) to the algorithm, because with changing to
\overline{\theta}^{k}(t)
, the trajectory of
\mathbf{x}^{k}(t)
might flow to somewhere else, we cannot guarantee
\mathbf{x}^{k}(0)=\mathbf{x}_{0}
anymore. And this might cause the algorithm unstable. We will leave this problem to the future work.

Algorithm 2

The MSA with Reverse Augmented State and Control Flow to Solve Inverse Problem

1:

Initialize

\theta^{0}
.

2:

for

k=1,2,\dots,K
(training iterations)
do

3:

Solve
\dot{\mathbf{x}}^{k}(t)=f({\mathbf{x}}^{k}(t),\theta^{k-1})
,
\mathbf{x}^{k}(0)=\mathbf{x}_{0}
;

4:

Solve
\frac{d}{dt}\left[\begin{array}[]{c}\mathbf{p}^{k}(t)\\
\overline{\theta}^{k}(t)\end{array}\right]=\left[\begin{array}[]{c}-\nabla_{\mathbf{x}}H({\mathbf{x}}^{k}(t),\mathbf{p}^{k}(t),\overline{\theta}^{k}(t))\\
\eta_{k}\nabla_{\theta}H({\mathbf{x}}^{k}(t),\mathbf{p}^{k}(t),\overline{\theta}^{k}(t))\end{array}\right],\ \ \left[\begin{array}[]{c}\mathbf{p}^{k}(T)\\
\overline{\theta}^{k}(T)\end{array}\right]=\left[\begin{array}[]{c}-\nabla\Phi(\mathbf{x}^{k}(T))^{\top}\\
\theta^{k-1}\end{array}\right]
;

5:

Set
\theta^{k}=\overline{\theta}^{k}(0)
.

6:

end

for

7:

output:

\theta^{K}
.

5
Design of the Regularizer in the Variational Model

In this study, we design the regularizer
\mathcal{R}
to take the form
\mathcal{R}(\mathbf{x})=\psi(\mathcal{G}(\mathbf{x}))\in\Re^{+}
, where
\mathcal{G}\mathrel{\mathop{\ordinarycolon}}\Re^{n}\rightarrow\Re^{n}
is a feature extraction operator achieved by deep neural network. To enforce the sparsity, the function
\psi
is defined as
\psi(\mathbf{x})=\sum_{i=1}^{n}\log\cosh(\mathbf{x}_{i})
, where
\log\cosh(x)
is a twice differentiable function approximately equal to
|x|-\log(2)
for large
x
and to
x^{2}/2
for small
x
.
Throughout this work, we parameterize the feature extraction operator
\mathcal{G}
as a vanilla
l
-layer convolutional neural network without bias separated by componentwise activation function as follows:

\mathcal{G}(\mathbf{x})=\mathbf{w}_{l}*\sigma...\ \sigma(\mathbf{w}_{3}*\sigma(\mathbf{w}_{2}*\sigma(\mathbf{w}_{1}*\mathbf{x}))),

(10)

where
\{\mathbf{w}_{k}\}_{k=1}^{l}
denote the convolution weights and
*
denotes the convolution operation.
Specifically, we parameterize the first convolution
\mathbf{w}_{0}
to be
d
kernels of size
3\times 3
and the last one
\mathbf{w}_{l}
with
1
kernel of size
3\times 3\times d
.
Besides, all hidden layers
\{\mathbf{w}_{k}\}_{k=2}^{l-1}
correspond to convolutions with
d
kernels of size
3\times 3\times d
.
Here,
\sigma
represents a componentwise activation function which is twice differentiable. In this work we adopt the twice differentiable function sigmoid-weighted linear unit (SiLU)
[
43
]
as the activation.
