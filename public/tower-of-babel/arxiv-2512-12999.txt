Universal Quantum Random Access Memory: A Data-Independent Unitary Construction
Leonardo Bohac

Abstract
We present a construction for Quantum Random Access Memory ( QRAM ) that achieves a single, data-independent unitary operator. Unlike routing-based approaches or circuit methods that yield data-dependent unitaries, our Universal QRAM encodes data in memory qubits that act as quantum control signals within a block-diagonal permutation structure. The key insight is that memory qubits serve as control signals, enabling coherent lookup when addresses are in superposition. For N N addresses with K K -bit data words, the construction requires log 2 ⁡ N + K + N ​ K \log_{2}N+K+NK qubits and decomposes into exactly N ​ K NK multi-controlled gates. We verify the construction for N ∈ { 2 , 4 , 8 , 16 } N\in\{2,4,8,16\} and K ∈ { 1 , 2 , 3 , 4 } K\in\{1,2,3,4\} , confirming that the resulting unitary is a pure permutation matrix with zero error across all data configurations. This approach simplifies QRAM implementation by separating fixed circuit structure from variable data encoding.

This separation between fixed circuit structure and variable data encoding offers both conceptual clarity and practical advantages.

2.2
Block-Diagonal Structure

The Universal
QRAM
unitary has a natural block-diagonal structure:

U_{\text{QRAM}}=\bigoplus_{\text{mem}=0}^{2^{NK}-1}\text{Block}_{\text{mem}}

(3)

There are
2^{NK}
blocks, one for each possible memory configuration. Each block has dimension
(N\cdot 2^{K})\times(N\cdot 2^{K})
, acting on the combined address-output space for a fixed memory state.

The key observation is that when memory qubits are in a computational basis state, only one block is “active.” However, quantum mechanics allows the memory to be prepared in any basis state, and the block-diagonal structure ensures each configuration is handled correctly in superposition.

2.3
Block Formula

Each block decomposes further into a direct sum over addresses:

\text{Block}_{\text{mem}}=\bigoplus_{a=0}^{N-1}\text{SubBlock}_{a}

(4)

The sub-block for address
a
performs the XOR operation on the
K
-bit output:

\text{SubBlock}_{a}=\bigotimes_{j=K-1}^{0}X^{m_{a}^{j}}

(5)

where
m_{a}^{j}
is the
j
-th bit of data stored at address
a
, and
X^{0}=I
(identity),
X^{1}=X
(Pauli-X).

In compact notation:

\boxed{U_{\text{QRAM}}=\bigoplus_{\text{mem}}\left[\bigoplus_{a=0}^{N-1}\left(\bigotimes_{j=K-1}^{0}X^{m_{a}^{j}}\right)\right]}

(6)

2.4
Special Case: Single-Bit Data (
K=1
)

For
K=1
, the formula simplifies considerably. Each sub-block is just
X^{m_{a}}
—either identity or bit-flip:

\text{Block}_{\text{mem}}=\bigoplus_{a=0}^{N-1}X^{m_{a}}=\begin{pmatrix}X^{m_{0}}&&\\
&X^{m_{1}}&\\
&&\ddots\\
&&&X^{m_{N-1}}\end{pmatrix}

(7)

This means the entire
QRAM
operation, for any data configuration, is simply: “for each address, flip the output qubit if and only if the corresponding memory bit is 1.”

3
Properties

3.1
Permutation Structure

A direct consequence of the construction is that
U_{\text{QRAM}}
is a
permutation matrix
—every row and column contains exactly one non-zero entry, and that entry equals 1. This follows because:

•

Each
X^{m_{a}^{j}}
is either
I
or
X
, both permutation matrices

•

Tensor products of permutations are permutations

•

Direct sums of permutations are permutations

The permutation property guarantees unitarity and implies that the operation is simply a relabeling of basis states with no complex phases or amplitude mixing.

3.2
Uniqueness

We discovered that the complete
QRAM
specification—testing both
\ket{a}\ket{0}
and
\ket{a}\ket{1}
input states—yields a
unique
solution with zero free parameters.

This contrasts with an “incomplete” specification that only tests
\ket{a}\ket{0}\to\ket{a}\ket{\text{data}[a]}
. The incomplete version leaves half the Hilbert space unconstrained, resulting in a continuous family of solutions with hundreds of free parameters.

The complete specification enforces:

\displaystyle\ket{a}\ket{0}

\displaystyle\to\ket{a}\ket{\text{data}[a]}

(8)

\displaystyle\ket{a}\ket{1}

\displaystyle\to\ket{a}\ket{1\oplus\text{data}[a]}

(9)

Together, these fully constrain the unitary to the unique permutation structure.

8
Discussion

8.1
Practical Considerations

State Preparation:
The Universal
QRAM
requires preparing the memory register in a computational basis state encoding the desired data. For
N
addresses with
K
bits each, this requires
NK
single-qubit operations (bit flips from
\ket{0}
to
\ket{1}
where needed). This is a one-time cost, amortized over multiple queries.

Memory Overhead:
Storing data in memory qubits requires
NK
physical qubits. This is comparable to classical RAM requirements and does not introduce fundamental overhead beyond what any
QRAM
requires.

Gate Depth:
The
NK
multi-controlled gates can be executed with depth
O(NK)
sequentially, or potentially
O(K)
with parallelization over addresses (since gates for different addresses commute).

8.2
Limitations

Memory Size:
The exponential scaling of
2^{NK}
blocks means explicit matrix construction is infeasible for large
NK
. However, the gate decomposition remains efficient.

Computational Basis States Only:
Our construction encodes data values in computational basis states (
\ket{0}
or
\ket{1}
). Storing arbitrary superpositions in the memory register would require different architectures and faces no-cloning restrictions.

Multi-Controlled Gates:
Each gate has
\log_{2}N+1
controls, requiring decomposition into native gates. The decomposition overhead depends on the target hardware.

8.3
Relation to Prior Work

QROM (Quantum Read-Only Memory):
Circuit-based QROM
[
5
,
6
]
uses
N
multi-controlled gates with identical activation logic to ours: flip output if (address match) AND (data bit set). However, each data configuration yields a different effective unitary
U_{x}
—a family of operators. Data is either compiled into circuit structure or provided as classical control signals, and changes require updating the classical control system between quantum computations. In Universal
QRAM
, one unitary
U_{\text{QRAM}}
handles all data configurations, with data encoded in quantum memory qubits that can be modified by quantum gates during computation.

Bucket-Brigade QRAM:
The bucket-brigade architecture
[
2
]
physically routes queries through a binary tree of
O(N)
routing nodes to reach data stored at leaf nodes. Like our approach, it provides a single unitary over all data configurations. Unlike ours, it enables storage of quantum data (arbitrary superpositions in memory cells), not just definite values. Our approach requires definite data values but offers a simpler circuit model.

Novelty:
The novelty is providing a single unitary
U_{\text{QRAM}}
(like bucket-brigade) using a circuit model (like QROM) with data in quantum memory qubits serving as quantum control lines. QROM provides a family of unitaries
\{U_{x}\}
; bucket-brigade uses physical routing; our approach yields one unitary with memory qubits in the Hilbert space. The closed-form decomposition into exactly
N\times K
multi-controlled gates is also new.

8.4
Trade-offs

Universal
QRAM
is best suited for scenarios where:

•

Data values are definite (not superpositions)

•

Data should reside in quantum memory qubits (part of the Hilbert space)

•

Memory may be prepared or modified by quantum operations

•

A unified quantum circuit model is preferred over classical/quantum hybrid control

When quantum data storage is required (arbitrary superpositions in memory cells), bucket-brigade remains the appropriate architecture. When data is static classical information, QROM with classical control signals may offer simpler implementation on specific hardware.

8.5
Integration Advantages

A key practical benefit of Universal
QRAM
is seamless integration with quantum algorithms. Because the construction is a standard unitary composed of multi-controlled gates:

•

No hybrid control:
The entire computation—including data loading—is a coherent quantum circuit with no classical intervention mid-execution.

•

Trivial uncomputation:
The self-inverse property (
U_{\text{QRAM}}=U_{\text{QRAM}}^{\dagger}
) means uncomputation requires no additional circuit design.

•

Composability:
Memory can be prepared by preceding quantum operations, enabling pipelines where one algorithm’s output becomes another’s data.

•

Simulator and hardware compatibility:
The gate decomposition uses only standard multi-controlled operations, compatible with any universal gate set.

These properties are particularly valuable for quantum machine learning, where algorithms typically require repeated data loading and uncomputation within a single coherent execution. The Grover’s oracle construction in Section
6
demonstrates this integration: the complete search algorithm—including oracle and diffusion—is a single quantum circuit with no classical feedback loops.
