NP-membership for the boundary-boundary art-gallery problem
Jack Stade

Abstract
The boundary-boundary art-gallery problem asks, given a polygon P P representing an art-gallery, for a minimal set of guards that can see the entire boundary of P P (the wall of the art gallery), where the guards must be placed on the boundary. We show that this art-gallery variant is in NP. In order to prove this, we develop a constraint-propagation procedure for continuous constraint satisfaction problems where each constraint involves at most 2 variables. The X-Y variant of the art-gallery problem is the one where the guards must lie in X and need to see all of Y. Each of X and Y can be either the vertices of the polygon, the boundary of the polygon, or the entire polygon, giving 9 different variants. Previously, it was known that X-vertex and vertex-Y variants are all NP-complete and that the point-point, point-boundary, and boundary-point variants are ∃ ℝ \exists\mathbb{R} -complete [Abrahamsen, Adamaszek, and Miltzow, JACM 2021][Stade, SoCG 2025]. However, the boundary-boundary variant was only known to lie somewhere between NP and ∃ ℝ \exists\mathbb{R} . The X-vertex and vertex-Y variants can be straightforwardly reduced to discrete set-cover instances. In contrast, we give example to show that a solution to an instance of the boundary-boundary art-gallery problem sometimes requires placing guards at irrational coordinates, so it unlikely that the problem can be easily discretized.

Background and related work

Biniaz, Maheshwari, Merrild, Mitchell, Odak, Polishchuk, Robson, Rysgaard, Schou, Shermer, Spalding-Jamieson, Svenning, and Zheng
[

recently gave a polynomial time algorithm for the

In addition to art-galleries, many other important problems are known to be
\exists\mathbb{R}
-complete, notable examples including packing
[
4
]
, drawing graphs with fixed edge lengths
[
23
]
, realizeability of line arrangements
[

,

[
3

. A recent survey by Cardinal, Miltzow and Schaefer
[

lists roughly 150
\exists\mathbb{R}

A constraint satisfaction problem (CSP) is a decision problem that asks whether there is an assignment of some variables that satisfies a set of constraints. A 2CSP is a CSP where each constraint involves at most 2 variables.

A
continuous constraint satisfaction problem
(CCSP) is a constraint satisfaction problem where the variables take values over a continuous domain, typically
\mathbb{R}
or a subset thereof. The constraints are typically represented by equalities and inequalities involving polynomials in the variables. A 2CCSP is a CCSP where each constraint involves at most 2 variables.

Discrete CSPs are typically in NP and are frequently NP-complete. Similarly, CCSPs are typically in
\exists\mathbb{R}
and are frequently
\exists\mathbb{R}
-complete. Miltzow and Schmiermann
[
19
]
showed that CCSPs typically become
\exists\mathbb{R}
-hard if constraints of form
x+y=z
can occur along with some nonlinear constraints. They conjecture that it is necessary to have a constraints that depends on
3
or more variables in order for a CCSP to be
\exists\mathbb{R}
-hard, as current techniques seem to be unable to show
\exists\mathbb{R}
-hardness for any 2CCSPs.

It has been know since at least 1967
[
15
]
that boolean 2CSPs can be decided in polynomial time. On the other hand, ternary 2CSPs are already NP-hard
[
6
]
. In 2000, Beckert, Hahnle and Manya
[
6
]
gave a polynomial-time algorithm for solving 2CSPS where the variables lie in a lattice and the constraints are disjunctions of terms of form
x\geq c
or
x\leq c
. Charatonik and Wrona
[
11
]
later gave a faster algorithm for these instances.

One very important example of a CCSP is linear programming. In 1983, Megiddo
[
18
]
gave a strongly polynomial time algorithm for determining feasibility of a linear programming instance where each constraint involves at most
2
variables. In 2023, Dadush, Koh, Natura, Olver, and Végh
[
12
]
gave a strongly polynomial time algorithm for determining optimality for these instances. The best known algorithms for general linear programming run in only weakly polynomial time.

A common technique for solving CSPs is
constraint propagation
: given an instance
\Gamma
, we can derive new constraints from the existing ones. A method for producing new constraints giving existing ones is called an
inference rule
. If we can derive the unsatisfiable clause
\emptyset
from the original instance using some set of inference rules, then we conclude that the instance is unsatisfiable. A derivation of
\emptyset
is called a
refutation
of the instance. A set of inference rules for a CSP is
refutation complete
if every unsatisfiable instance has a refutation.

In 1960, Davis and Putman
[
13
]
showed that the inference rule:

\frac{x\vee C\quad\neg x\vee D}{C\vee D}

is refutation-complete for boolean satisfiability. The notation here describes an inference rule (called binary resolution) that produces a constraint
C\vee D
given constraints
x\vee C
and
\neg x\vee D
, where
x
is a variable and
C
and
D
are (possibly empty) constraints. In general, there is no guarantee that a refutation has polynomial size or that one can be found efficiently if it exists. However, resolution leads to a polynomial-time algorithm for boolean 2SAT (see Krom 1967
[
15
]
).

In 2000, Beckert, Hahnle and Manya
[
6
]
extended binary resolution to the case where the variables take values in a finite lattice
N
, and the constraints are disjunctions of terms of form
x\leq c
or
x\geq c
, where
x
is a variable and
c\in N
. Specifically, they show that the inference rule:

\frac{(x\leq c)\vee C\quad(x\geq d)\vee D}{C\vee D}\quad\text{where }d>c

is refutation complete for these CSPs. In the case where each constraint involves at most 2 variables, they show that there is a polynomial-time algorithm for finding refutations if they exist.

A family of techniques for solving CCSPs is quantifier elimination: given some subset
S\subset\{x_{1},\dots,x_{n}\}
, we can try to find conditions that determine whether a given assignment of the variables in
S
extends to a satisfying assignment of the instance. The variables in
\{x_{1},\dots,x_{n}\}\setminus S
are said to be eliminated. If we can eliminate all the variables, then we can decide the truth value of the instance.

In 1948, Tarski
[
29
]
gave the first quantifier-elimination procedure for ETR. Given a formula:

\exists x_{n}:\Phi(x_{1},\dots,x_{n})

he shows how to compute an equivalent quantifier-free formula
\Psi(x_{1},\dots,x_{n-1})
. The formula
\Psi
represents a sort of algorithm for determining if an assignment of the variables
x_{1},\dots,x_{n-1}
can be extended to an assignment of
x_{1},\dots,x_{n}
that satisfies
\Phi
. The procedure can be repeated to eliminate any subset of the variables, though each elimination causes an exponential blow-up in the size of the formula.

Even if computing it is infeasible, the existence of a quantifier elimination can somtimes be used to bound the complexity of solutions if they exist. For example, if we eliminate all but one variable
x
using Tarski’s quantifier elimination procedure for ETR, then we obtain a formula only involving polynomials in
x
, showing that if a satisfying assignment exists, then one exists where
x
is an algebraic number. More usefully, Schaefef and Stefankovič
[
25
]
use the existence of certain a certain quantifier-elimination to show that ETR is
\exists\mathbb{R}
-complete even when the variables are restricted to the range
[-1,1]
.

1.2
Our results

We show that the boundary-boundary art-gallery problem is in NP. The proof is by a nondeterministic reduction to a particular 2CCSP problem that we call
\mathcal{M}-2\text{SAT}
, which is a 2CCSP where the constraints are given by (piecewise) fractional-linear functions. Most of the paper is devoted to showing that
\mathcal{M}-2\text{SAT}
is in NP. The strategy is to show that, if a solution exists, then there is a solution where the variables have form
p+q\sqrt{r}
, where
p
,
q
and
r
are rational numbers with a polynomially-bounded number of bits. Such solutions can be verified efficiently.

In order to prove this, we define a broad class of monotone CCSPs that contains
\mathcal{M}-2\text{SAT}
. In
Section

3
, we develop an inference system for this class based on function composition, and show that it is refutation-complete. This is proved by using a compactness argument to show that it is sufficient to look for refutations over some finite subset of
\mathbb{R}
. The results of
[
6
]
imply that binary resolution is refutation complete over this discrete subset, and we show that a refutation using binary resolution over a finite subset of the domain can be lifted to one using function composition.

The nature of a compactness argument means that we don’t get any useful bound on the length of refutations needed by our system. So in
Section

4
we extend our inference system to allow infinite compositions and
n
-way minimum operations. In the new inference system, we prove that it is sufficient to consider refutations that in some sense have logarithmic depth.

In
Section

5
, we use these results to give two upper bounds for
\mathcal{M}-2\text{SAT}
. First, we show that
\mathcal{M}-2\text{SAT}\in\text{NP}
. Second, we show that there is a quasi-polynomial-time algorithm for
\mathcal{M}-2\text{SAT}
.

The problem
\mathcal{M}-2\text{SAT}
will contain a range constraint
x\in[a,b]
for each variable. The construction in
Section

4
is used to construct a sort of circuit that determines the satisfiability of the instance given the values of
a
and
b
. If we set
a=b=c
, then this circuit determines whether
x=c
extends to a satisfying assignment of the instance, giving a method of quantifier elimination. We can bound the complexity of arithmetic operations performed by the circuit, giving us a bound on the complexity of solutions needed. We obtain
\mathcal{M}-2\text{SAT}\in\text{NP}
.

The quasi-polynomial-time algorithm for
\mathcal{M}-2\text{SAT}
is essentially straightforward to obtain from the results of
Section

4
.

It it is easy to construct instances of
\mathcal{M}-2\text{SAT}
where a solution requires irrational coordinates, but it is not immediately clear if such an instance can be realized as an instance of the boundary-boundary art-gallery problem. In
Section

6
, we give an example to show that a solution to the boundary-boundary art-gallery problem can require irrational coordinates.

2
The boundary-boundary art-gallery problem and
\mathcal{M}-2\text{SAT}

Let
\mathcal{F}
be a class of continuous increasing bijections
\mathbb{R}\rightarrow\mathbb{R}
. Then an instance of
\mathcal{F}-2\text{SAT}
consists of a set of variables
v_{1},\dots,v_{n}
, a closed interval
\text{range}(v_{i})
for each variable, and a set of constraints of form
x\leq f(y)
where

are
literals
, that is elements of
\{\pm v_{1},\dots,\pm v_{n}\}
. The problem asks whether there is an assignment of real values

that satisfy all the constraints. We write
\text{range}(-v_{i})=-\text{range}(v_{i})
.

Figure

1

In many cases, the constraint

already restricts

or

However, restricting the range of one variable might then required restricting the range of another variable, and this can lead to an infinite loop. This process does converge in some sense, but it isn’t clear that we can compute the limit.

If the functions in
\mathcal{F}
are very complicated, for example polynomial circuits, then there is a little hope of being able to decide

efficiently. The specific class of functions that we are most interested in are

\mathcal{M}-2\text{SAT}

,

3
The continuous inference system

In this section, we construct an inference system for
\mathcal{F}-2\text{SAT}
instances and prove that it is refutation complete.

Throughout this section, we work with
n
real variables
v_{1},\dots,v_{n}
, where
v_{i}
is restricted to a compact interval
\text{range}(v_{i})\subset\mathbb{R}
. In this section, a
formula
is a conjunction
clauses
that are each a conjunction of at most
2
terms of form
v_{i}\leq c
or
v_{i}\geq c
for some
c\in\mathbb{R}
. The empty clause
\emptyset
is unsatisfiable. A
continuous formula
is a conjunction of finitely many
constraints
, where a constraint is of form
x\leq f(y)
for some literals
x
and
y
, where
f
is a continuous strictly increasing bijection
\mathbb{R}\rightarrow\mathbb{R}
.

Theorem 2
.

(Beckert, Hahnle and Manya,
[
6
]
)
Let
N
be a lattice (that is, a partially ordered set where every pair of elements has a unique least upper bound and greatest lower bound), let
v_{1},\dots,v_{n}
be variables taking values in
N
, and let
\Gamma
be a conjunction of (finitely many) clauses each containing literals of form
x_{i}\leq c
or
x_{i}\geq c
for
c\in N
. If
\Gamma
is unsatisfiable, then the empty clause can be derived from
\Gamma
using the binary resolution rule:

\frac{(x_{1}\leq a)\vee T_{1}\quad(x_{1}\geq b)\vee T_{2}}{T_{1}\vee T_{2}}\text{ where }a<b

The authors of
[
6
]
restricted to the case where
N
is finite, but the proof works for
N

). In the case where
N\subset\mathbb{R}
is a compact interval, we can use a compactness argument to extend to the case where the number of clauses is infinite.

Lemma 3
.

For each real variable
v_{i}
, let
\text{range}(v_{i})\subset\mathbb{R}

or

\emptyset

Proof.

Let
D\subset\mathbb{R}^{n}
be the set of values
(v_{1},\dots,v_{n})
with each
v_{i}
in
\text{range}(v_{i})
. Since each
\text{range}(v_{i})

For each clause
C

\Xi

S(C)
in

\bigcap\{S(C):C\text{ a clause in }\Xi\}

\bigcup\{D\setminus S(C):C\text{ a clause in }\Xi\}=D\setminus\bigcap\{S(C):C\text{ a clause in }\Xi\}=D

Since each

By

\Xi^{\prime}

\Xi^{\prime}

We now write
x\leq f(y)

or

Lemma 4
.

Let
f:\mathbb{R}\rightarrow\mathbb{R}
be a continuous increasing bijection. Values

if and only if they satisfy
(x\leq f(c))\vee(y\geq c)

4
Bounded-depth refutations

In general, there is no way to bound the length of the refutation produced by
Lemma

8
. However, if a refutation is too large, then we might be able to simplify it. For example, a refutation might generate many different constraints of form
x\leq f(y)
, in which case we can replace constraints
x\leq f_{1}(y),\dots,x\leq f_{k}(y)
with a single constraint
x\leq\text{min}(f_{1},\dots,f_{k})(y)
.

If a constraint of form
x\leq f(x)
appears, then we can obtain
x\leq(f\circ\dots\circ f)(x)
. We may need many compositions of
f
in order to obtain a strong enough constraint, so this is another way that the length of a refutation can become very large. In these cases, we can compute (roughly) the limit of
f^{k}
as
k
goes to
\infty
. As we show in
Section

4.1
, the constraint
x\leq f^{\infty}(x)
and the tautology
x\leq x
are together stronger than any constraint of form
x\leq f^{k}(x)
, and so we are saved from having to compute an arbitrarily large
number of compositions of
f
.

In this section, we show that the addition of
k
-way minimum operations and infinite compositions allow us to produce a refutations where the depht of arithmetic operations required is at most logarithmic. For every pair of literals
x
and
y
, this refutation tries to calculate the function
\text{min}_{x\rightarrow y}
representing the infimum over all
f
such that the constraint
x\leq f(y)
can be derived.

Given an
\mathcal{F}-2\text{SAT}
instance
\Gamma
, let
G
be a graph with vertices representing literals
\pm v_{i}
and directed edges representing constraints, so that an edge from
x
to
y
represents a constraint of form
x\leq f(y)
in
\Gamma
. The constraints
x\leq f(y)
that can be derived from
\Gamma
correspond to paths from
x
to
y
in
G
.

If
x\leq f(y)
is a constraint that can be derived from
\Gamma
using the composition, minimum, and infinite composition operations, then the sequence of operations used to define
f
represents (in some sense) a regular expression matching paths in
G
, and
f
is the infimum of of the constraints represented by the paths matched by the regular expression. Given vertices
x
and
y
in
G
, it is possible (see Brzozowski and McCluskey
[
9
]
) to construct a regular expression matching all directed paths from
x
to
y
. However, the regular expression produced can be as long as
n^{n}
, which is not useful for us.

So instead, we construct a regular expression that matches the paths from
x
to
y
of length at most
2n
, so in particular it matches any non-repeating paths. We let
f_{x\rightarrow y}
be the function so that this regular expression constructs the constraint
x\leq f_{x\rightarrow y}(y)
. In
Section

4.2
, we show that, for a real number
c
,
\text{min}_{x\rightarrow y}(c)
is either
f_{x\rightarrow y}(c)
or
f_{x\rightarrow z}(d)
for some literal
z
, where
d
is an attracting fixed point of
f_{z\rightarrow z}
. In the case of
\mathcal{M}-2\text{SAT}
, this will give a bound on the complexity of coordinates required for a satisfying assignment, proving NP-membership for
\mathcal{M}-2\text{SAT}
.

For
\mathcal{M}-2\text{SAT}
, the refutations considered in
Section

4.2
can be explicitly constructed in time
n^{\mathcal{O}(\log(n))}
, allowing us to solve
\mathcal{M}-2\text{SAT}
in quasi-polynomial time. In particular,
\mathcal{M}-2\text{SAT}
isn’t NP-hard unless the exponential-time hypothesis is false. It seems to be difficult to perform these calculations in polynomial time, since the regular expression representing by
f_{x\rightarrow y}
is a monotone formula for solving directed st-connectivity. Such a formula must have size at least
n^{\Omega(\log(n))}
(see Karchmer and Wigderson
[
14
]
).

4.1
Infinite compositions

If a constraint of form
x\leq f(x)
appears, then we can obtain
x\leq(f\circ\dots\circ f)(x)
. We may need many compositions of
f
in order to obtain a strong enough constraint. Our strategy to handle this case is to compute (roughly) the limit of
f^{k}(x)
as
k
goes to
\infty
. As we show below, the constraint
x\leq f^{\infty}(x)
and the tautology
x\leq x
are together stronger than any constraint of form
x\leq f^{k}(x)
, so we are saved from having to compute an arbitrarily large number of compositions of
f
.

Given a function
f
, we now define precisely what we mean by the function
f^{\infty}
. Our precise definition is someone subtle, because we want
f^{\infty}
to be piecewise-constant. This might fail if
f
has infinitely many fixed points, for example if
f
is a piecewise linear function where one piece is
f(x)=x
.

If
f:\mathbb{R}\rightarrow\mathbb{R}
is a strictly increasing continuous bijection, then we define
f^{\infty}:\mathbb{R}\rightarrow\mathbb{R}\cup\{\pm\infty\}
by:

f^{\infty}(x)=\inf\{y\geq\sup\{z\leq x:z\leq f(z)\}:y>f(y)\}

here taking
\inf\{\emptyset\}=+\infty
and
\sup\{\emptyset\}=-\infty
.

Equivalently, we could define:

f^{\infty}(x)=\lim_{\epsilon\rightarrow 0^{+}}\lim_{k\rightarrow\infty}(f+\epsilon)^{\infty}(x)

but the first definition will be easier to work with.

Illustration of
f^{\infty}

We now prove some useful properties of this construction.

Lemma 10
.

If
f(x)<x
, then
f^{\infty}(x)\leq f(x)
.

Proof.

If
z
is such that
f(x)<z\leq x
then
f(z)\leq f(x)<z
. So
\sup\{z\leq x:z\leq f(z)\}\leq f(x)
. Since
f(x)<x
,
f(f(x))<f(x)
, so
f^{\infty}(x)\leq f(x)
.
∎

Lemma 11
.

x\leq f(x)
if and only if
x\leq f^{\infty}(x)
.

Proof.

If
x\leq f(x)
, then
\sup\{z\leq x:z\leq f(z)\}=x
, so
f^{\infty}(x)\geq x
.

If
x>f(x)
, then by
Lemma

10
,
f^{\infty}(x)\leq f(x)
, so
x>f^{\infty}(x)
.
∎

Lemma 12
.

For all
x\in\mathbb{R}
,
f^{\infty}(x)=\pm\infty
or
f^{\infty}(x)
is a locally maximal fixed point of
f
. That is,
f^{\infty}(x)+\epsilon
is not a fixed point of
f
for all sufficiently small
\epsilon>0
.

Also
f^{\infty}\circ f^{\infty}=f^{\infty}
.

Proof.

It is clear from the definition that
f(f^{\infty}(x)+\epsilon)>f(f^{\infty}(x))
for arbitrarily small
\epsilon>0
(when it is finite). By continuity of

,
f^{\infty}(x)
is a fixed point of
f
.

It is straightforward from the definition that
f^{\infty}(x)=x
when

is a locally maximal fixed point of

. So
f^{\infty}\circ f^{\infty}=f^{\infty}
.
∎

The values taken by

are always fixed points of

. Those fixed points of

that can occur as values of

are called

of

.

4.2
Compressing paths

Given two literals
x
and
y
, any function
f
such that
x\leq f(y)
can be derived from a continuous formula
\Gamma
can be written
f=f_{1}\circ\dots\circ f_{k}
for functions
f_{i}
from the original problem instance. We would like to compute the minimum (that is, infimum) of the possible functions
f
such that
x\leq f(y)
can be derived.

Given a continuous formula
\Gamma
, we say a
path
from a literal
x
to a literal
y
is a list of constraints
x=x_{1}\leq f_{1}(x_{2}),\dots,x_{k}\leq f_{k}(x_{k+1}=y)
. A path is non-repeating if
x_{i}\neq x_{j}
for
i\neq j
unless
\{i,j\}=\{1,k+1\}
(so a path from
x
to itself can be non-repeating by this definition). The resolution of a path is the clause
x\leq(f_{1}\circ\dots\circ f_{k})(y)
. We will sometimes write
p(y)
for
(f_{1}\circ\dots\circ f_{k})(y)
. The interior vertices of a path are the vertices
x_{2},\dots,x_{k-1}
.

The number of paths from
x
to
y
is infinite in general, but we hope to use infinite compositions in order to reduce this to a finite size. But there can still be roughly
n!
non-repeating paths between a given pair of literals.

We now introduce the minimum operation. If we have constraints
x\leq f_{1}(y),\dots,x\leq f_{k}(y)
, then we can replace them by
x\leq\text{min}(f_{1},\dots,f_{k})(y)
. Note that an expression like
\text{min}(f_{1},g_{1})\circ\dots\circ\text{min}(f_{n},g_{n})
can represent the minimum of an exponential number of paths in only polynomial size.

Given a continuous formula
\Gamma
, we produce a new continuous formula
H(\Gamma)
by the following process:

•

For each pair of constraints of form
x\leq f(y)
and
y\leq g(z)
with
y
not being the same literal as
x
or
z
, add the clause
x\leq f(g(z))
.

•

For every pair of (not necessarily distinct) literals
x
and
y
, write
\{x\leq f_{i}(y):i=1,\dots,k\}
for the set of constraints from
x
to
y
in
\Gamma
, and replace them with the single constraint
x\leq\min_{i}(f_{i})(y)
.

Lemma 13
.

H(\Gamma)
is satisfiable if an only if
\Gamma
is satisfiable.

Proof.

Whenever a constraint of form
x\leq f(y)
appears in
\Gamma
, a constraint
x\leq g(y)
appears in
H(\Gamma)
where
g(c)\leq f(c)
for all
c\in\mathbb{R}
. So if
H(\Gamma)
is satisfiable then
\Gamma
is.

If
x\leq f_{i}(y)
then
x\leq\min_{i}(f_{i})(y)
. So if
\Gamma
is satisfiable, then
H(\Gamma)
is.
∎

Write
H^{2}(\Gamma)=H(H(\Gamma))
and write
H^{k}(\Gamma)
for the result after applying this process
k
times.

Lemma 14

Let
\Gamma

Proof.

By induction, we show that for non-repeating path

Suppose this is true for some

Now let

Theorem 18
.

\mathcal{M}-2\text{SAT}
is in NP

Proof.

Let
\Gamma
be an instance of

with
n

The function

\text{min}_{-v_{1}\rightarrow x}(\text{max}(\text{range}(x)))\geq-c

The constraints in
\Gamma
are piecewise fractional linear, that is they are piecewise of form:

\frac{ax+b}{cx+d}

where
a,b,c
and

are integers with at most
\beta
bits each.

Taking the minimum of some of these constraints increases only the number of pieces and not the complexity of the pieces themselves. Composing two functions of this form causes the bit-complexity of the coefficients to grow by at most a factor of
3
, since:

\frac{a_{1}\left(\frac{a_{2}x+b_{2}}{c_{2}x+d_{2}}\right)+b_{1}}{c_{1}\left(\frac{a_{2}x+b_{2}}{c_{2}x+d_{2}}\right)+d_{1}}=\frac{(a_{1}a_{2}+b_{1}c_{2})x+(a_{1}b_{2}+b_{1}d_{2})}{(c_{1}a_{2}+d_{1}c_{2})x+(c_{1}b_{2}+d_{1}d_{2})}

In order to make
\Gamma
symmetric, we also need to compute
\widetilde{f}
for each constraint
x\leq f(y)
in
\Gamma
. The inverse of:

f(x)=\frac{ax+b}{cx+d}

is:

f^{-1}(x)=\frac{dx-b}{-cx+d}

so computing inverses doesn’t increase the bit complexity of a fractional linear function.

So
H(\Gamma)
has constraints that are piecewise fractional-linear with coefficients having at most
3\beta
bits each. So

has constraints that are piecewise of the same form, where the coefficients are integers with at most
\mathcal{O}(n^{\log_{2}(3)}\beta)
bits. Since the constraints should be continuous, the break points between two pieces are coincidence points of the functions on the those pieces.

By
Lemma

16
, the value of
\text{min}_{v_{1}\rightarrow x}(\text{max}(\text{range}(x)))

, an attracting point of

The equation:

\frac{ax+b}{cx+d}=x

yields a quadratic equation:

cx^{2}+(d-a)x-b=0

after clearing denominators. So a fractional-linear function is either the identity function
f(x)=x
or has at most
2
fixed points. In particular, each attracting point of a piecewise fractional-linear function is an isolated fixed point of one of the pieces. So the attracting points of each
f_{x\rightarrow y}
are of each form
p+q\sqrt{r}
, where
p
,
q
, and

are integers with a number of bits at most polynomial in

and
\beta
.

Applying a factional linear map to a number of form

yields a number of the same form, indeed:

\frac{a(p+q\sqrt{r})+b}{c(p+q\sqrt{r})+d}=\frac{((ap+b)+aq\sqrt{r})(cp+d-cq\sqrt{r})}{(cp+d)^{2}+rq^{2}c^{2}}=\frac{(ap+b)(cp+d)-acq^{2}r}{(cp+d)^{2}+rq^{2}c^{2}}+\frac{(ad-bc)}{(cp+d)^{2}+rq^{2}c^{2}}q\sqrt{r}

Since the endpoints of the interval
\text{range}(x)
are rational, we conclude that
\text{min}_{v_{1}\rightarrow x}(\text{max}(\text{range}(x)))
is a number of form
p+q\sqrt{r}
where
p
,
q
, and
r
have at most polynomially many bits. The same is true of locally extremal fixed points of
\text{min}_{v_{1}\rightarrow v_{2}}
and points where
\text{min}_{v_{1}\rightarrow-v_{1}}(-c)=c
or
\text{min}_{-v_{1}\rightarrow v_{1}}(c)=-c
(note that
\text{min}_{v_{1}\rightarrow-v_{1}}
is increasing, so there is at most one point where
\text{min}_{v_{1}\rightarrow-v_{1}}(-c)=c
). In particular, we can choose a value of

that has this form where

extends to a satisfying assignment of
\Gamma
.

We now repeat this process to set values of
v_{2},\dots,v_{n}
. The different now is that
\text{range}(v_{1})
may no longer be bounded by rational numbers, since we might have set
v_{1}
to an irrational value. But this is fine, because applying

to a number of form

still yields a number of the same form. Inductively, we conclude that if
\Gamma
has a satisfying assignment, then it has an assignment where are variables have form

Given an assignment of variables of this form, checking a constraint in

requires at most a constant number of arithmetic operations with numbers that roots of polynomials of degree at most

By

We can compute
G
in time
n^{\mathcal{O}(\log(n))}k\beta
, and so we can calculate each
G(x\rightarrow(y,d))
in quasi-polynomial time. The above calculation shows that this lets us calculate the functions
\text{min}_{x\rightarrow y}
. In order to determine if
\Gamma
is satisfiable, we just need to test if any of the conditions in
Lemma

17
occur. Since each
\text{min}_{x\rightarrow y}
is a piecewise-fractional-linear (though not necessarily continuous) function, this is straightforward. The entire computation runs in time
n^{\mathcal{O}(\log(n))}k\beta
.
∎

The minimum of
k
piecewise-fractional-linear functions with
k
pieces each is the lower envelope of an arrangement of
nk
arcs, where each pair of arcs has at most
2
intersection points. Results on Davenport-Schinzel sequences (see Sharir and Agarwal
[
26
]
) imply the number of pieces in the minimum is at most
\mathcal{O}(jk2^{\alpha(jk)})
, where
\alpha
is the inverse Ackermann function. Unless
k
is much much larger than
n
, this improves the bound used in the proof of
Theorem

19
, but the result of the theorem does not change qualitatively.
