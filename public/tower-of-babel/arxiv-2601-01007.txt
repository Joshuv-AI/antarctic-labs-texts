On solving nonlinear simultaneous equations arising from the double-exponential Sinc-collocation method for initial value problems
Yusaku Yamamoto

Abstract
The double-exponential Sinc-collocation method is known as a super-accurate method for solving initial value problems of ordinary differential equations, for which the error decreases almost exponentially as a function of the number of sample points in the temporal direction, N N . However, this method requires solving nonlinear simultaneous equations in n ​ N nN variables when the problem dimension is n n . Recently, Ogata pointed out that Gauss-Seidel type fixed-point iteration works surprisingly well for solving these equations, typically reducing the error by one or two orders of magnitude at each iteration. In this paper, we analyze the convergence of this iteration and give a sufficient condition for its global convergence. We also provide an upper bound on its convergence factor, which explains the efficiency of this iteration. Some numerical examples that illustrate the validity of our analysis are also provided.

Introduction

In this paper, we consider numerical solution of the initial value problem

\frac{{\rm d}{\bm{x}}}{{\rm d}t}={\bm{f}}(t,{\bm{x}})\quad(a\leq t\leq b),\quad{\bm{x}}(a)={\bm{x}}_{a}\in\mathbb{R}^{n},

(1)

where
{\bm{f}}(t,{\bm{x}})\in\mathbb{R}^{n+1}\rightarrow\mathbb{R}^{n}
. For this problem, several super-accurate quadrature-based numerical methods, for which the error decays nearly exponentially as a function of the number of sample points
N
in the interval
[a,b]
, have been proposed
Tanaka23
;
Stenger93
;
Nurmuhammad05
;
Okayama18
;
Ogata23
. For example, the method of Stenger
Stenger93
, which combines the Sinc-collocation method with the SE (single-exponential) transformation, achieves convergence rate of
O(\sqrt{N}\exp(-c\sqrt{N}))
, where
c
is some constant. Nurmuhammad et al.
Nurmuhammad05
propose to combine the Sinc-Nyström method with the SE or DE (double-exponential) transformation. Theoretical analysis of these methods is given by Okayama
Okayama18
for the special case where
{\bm{f}}(t,{\bm{x}})
is a linear function in
{\bm{x}}
and it is shown that the convergence rate is
O(\exp(-c\sqrt{N}))
and
O(\frac{\log N}{N}\exp(-cN/\log N))
for the SE and DE case, respectively. Note that the value of
c
differs for each method. Okayama
Okayama18
also proposes to replace the SE transformation in Stenger’s method with the DE transformation and show that the convergence rate of the resulting method, the DE Sinc-collocation method, is
O(\exp(-cN/\log N))
. More recently, Ogata
Ogata23
proposes to combine the periodic Sinc approximation with the IMT-type DE transformation. While the convergence of the resulting method is slightly slower (
O(N^{3/2}\log N\exp(-cN/\log^{2}N))
) than those of the DE Sinc-Nyström and DE Sinc-collocation methods, it has the advantage that truncation of the integral domain required by the DE transformation is not needed. Thus, the parameter to specify truncation is eliminated and the user needs to specify only one parameter,
N
.

All of these methods reduce the initial value problem (
1
) to a system of nonlinear equations in the values of
{\bm{x}}
at
N
sample points. Hence, nonlinear simultaneous equations in
nN
variables have to be solved and this usually accounts for most of the computational work. Several approaches such as the Newton method and Gaussian elimination (in the linear case)
Nurmuhammad05
can be used to solve these equations. Among them, Ogata
Ogata23
proposes to use fixed-point iteration, which corresponds to a discrete version of the Picard iteration. There are several variants of this iteration which differ in the way of updating the variables, and he reports that the Gauss-Seidel type variant works surprisingly well, reducing the error by one or two orders of magnitude at each iteration for the test problems. While this iteration was devised for the IMT-DE Sinc-collocation method, it can be applied to other numerical methods mentioned above as well.

In this paper, we analyze the convergence of this Gauss-Seidel type fixed-point iteration. As a target numerical method, we choose the DE Sinc-collocation method, because it is conceptually simple and easier to analyze. We assume that
{\bm{f}}(t,{\bm{x}})
is Lipschitz continuous in
{\bm{x}}
and derive a bound on the convergence rate in terms of
N
, the interval length
b-a
and the Lipschitz constant
L
. Contrary to the ordinary behavior of the Gauss-Seidel method, it is shown that the convergence gets faster as
N
increases. This theoretical prediction is confirmed by numerical experiments.

The rest of this paper is structured as follows. In Section
2
, we describe the DE Sinc-collocation method for initial value problems and the Gauss-Seidel type fixed-point iteration to solve the nonlinear simultaneous equations arising from it. Section
3
provides theoretical convergence analysis of the Gauss-Seidel type iteration. Numerical results that support our analysis are given in Section
4
. Finally Section
5
gives some conclusion.

A=(a_{ij})

2
The DE Sinc-collocation method for initial value problems

2.1
Sinc-collocation methods with variable transformation

Let us consider the initial value problem (
1
). We begin with describing a general procedure to solve this equation by the (periodic or non-periodic) Sinc-collocation methods with variable transformation. The first step is to rewrite it as an equivalent Volterra integral equation of the second kind:

{\bm{x}}(t)={\bm{x}}_{a}+\int_{a}^{t}{\bm{f}}(\tau,{\bm{x}}(\tau))\,{\rm d}\tau\quad(a\leq t\leq b).

(2)

Next, using some monotonically increasing function
\varphi
, we apply change of variables
\tau=\varphi(s)
to the integral in (
2
), obtaining

{\bm{x}}(t)={\bm{x}}_{a}+\int_{\varphi^{-1}(a)}^{\varphi^{-1}(t)}{\bm{f}}(\varphi(s),{\bm{x}}(\varphi(s)))\varphi^{\prime}(s)\,{\rm d}s\quad(a\leq t\leq b).

(3)

Now, by using the function values at some sample points
s_{N_{1}}<s_{N_{1}+1}<\ldots<s_{N_{2}}
on the
s
axis, we interpolate the integrand in (
3
) as

{\bm{f}}(\varphi(s),{\bm{x}}(\varphi(s)))\varphi^{\prime}(s)\simeq\sum_{j=N_{1}}^{N_{2}}{\bm{f}}(\varphi(s_{j}),{\bm{x}}(\varphi(s_{j})))\varphi^{\prime}(s_{j})p_{j}(s),

(4)

where
\{p_{j}(s)\}_{j=N_{1}}^{N_{2}}
are some interpolation functions that satisfy
p_{j}(s_{i})=\delta_{ij}
. Note that the function values
{\bm{x}}(\varphi(s_{j}))
are unknown at this stage. Substituting (
4
) into (
2
) and defining
P_{j}(s)
by

P_{j}(s)\equiv\int_{\varphi^{-1}(a)}^{s}p_{j}(s^{\prime})\,{\rm d}s^{\prime},

(5)

we can perform the integration to get

\int_{\varphi^{-1}(a)}^{\varphi^{-1}(t)}{\bm{f}}(\varphi(s),{\bm{x}}(\varphi(s)))\varphi^{\prime}(s)\,{\rm d}s\simeq\sum_{j=N_{1}}^{N_{2}}{\bm{f}}(\varphi(s_{j}),{\bm{x}}(\varphi(s_{j})))\varphi^{\prime}(s_{j})P_{j}(\varphi^{-1}(t))\quad(a\leq t\leq b).

(6)

Now, we insert the approximation (
6
) into (
3
) and equate the both sides at
N_{2}-N_{1}+1
points
t=\varphi(s_{1}),\ldots,\varphi(s_{M})
(the collocation method). Then, rewriting
{\bm{x}}(\varphi(s_{i}))
as
\widetilde{\bm{x}}_{i}
(
i=N_{1},N_{1}+1,\ldots,N_{2}
), we obtain the following nonlinear simultaneous equations in
\widetilde{\bm{x}}_{N_{1}},\widetilde{\bm{x}}_{N_{1}+1},\ldots\widetilde{\bm{x}}_{N_{2}}
.

\widetilde{\bm{x}}_{i}={\bm{x}}_{a}+\sum_{j=N_{1}}^{N_{2}}{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j})\varphi^{\prime}(s_{j})P_{j}(s_{i})\quad(i=N_{1},\ldots,N_{2}).

(7)

Solving these equations and substituting the results into (
6
) and (
3
), we obtain the following approximate solution of (
1
).

\widetilde{\bm{x}}(t)={\bm{x}}_{a}+\sum_{j=N_{1}}^{N_{2}}{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j})\varphi^{\prime}(s_{j})P_{j}(\varphi^{-1}(t))\quad(a\leq t\leq b).

(8)

Note that the approximate solution is given as a function of
t
, which is available at any point in
[a,b]
. This is one of the advantages of this type of numerical methods.

As examples of numerical methods based on this procedure, we can list the DE Sinc-collocation method by Okayama
Okayama18
and the IMT-DE periodic Sinc-collocation method by Ogata
Ogata23
. The former method uses the double-exponential transformation for
\varphi(s)
and the sample points
s_{j}=jh
(
j=-N,\ldots,N
), where
h
is the step size, and combines it with the Sinc interpolation formula. Thus,

\displaystyle\varphi(s)

\displaystyle=\varphi_{\rm DE}(s)\equiv\frac{b-a}{2}\tanh\left(\frac{\pi}{2}\sinh(s)\right)+\frac{b+a}{2},

(9)

\displaystyle p_{j}(s)

\displaystyle=S(j,h)(s)\equiv{\rm sinc}\left(\frac{s-jh}{h}\right)\quad(j=-N,\ldots,N),

(10)

where

{\rm sinc}(x)=\begin{cases}\sin(\pi x)/(\pi x),&x\neq 0,\\
1&x=0.\end{cases}

(11)

In this case,
P_{j}(s)
is given as

P_{j}(s)=J(j,h)(s)\equiv h\left\{\frac{1}{2}+\frac{1}{\pi}{\rm Si}\left(\frac{\pi(s-jh)}{h}\right)\right\},

(12)

where
{\rm Si}(x)=\int_{0}^{x}(\sin t/t){\rm d}t
is the sine integral. In the latter method, the IMT-DE type transformation is used as
\varphi(s)
and the sample points are chosen as
s_{j}=jh
(
j=0,1,\ldots,2N
,
h=1/(2N+1)
). For interpolation, the periodic Sinc function is used. Thus,

\displaystyle\varphi(s)

\displaystyle=\varphi_{\rm IMT-DE}(s)\equiv\frac{b-a}{2}\tanh\left(A\sinh B\left(\frac{1}{1-s}-\frac{1}{s}\right)\right)+\frac{b+a}{2},

(13)

\displaystyle p_{j}(s)

\displaystyle=S^{({\rm p})}(j,h)(s)\equiv h\frac{\sin\left(\frac{\pi}{h}(s-jh)\right)}{\sin\left(\pi(s-jh)\right)}\quad(j=0,1,\ldots,2N).

(14)

For this method,
P_{j}(s)
is given as

P_{j}^{({\rm p})}(s)=J^{({\rm p})}(j,h)(s)\equiv h\left\{s+\sum_{n=1}^{N}\frac{1}{n\pi}\left(\sin(2n\pi(s-jh))+\sin(2n\pi jh)\right)\right\}.

(15)

For these methods, it has been shown that under some technical conditions on
{\bm{f}}(t,{\bm{x}})
, the maximum error of the approximate solution
\widetilde{\bm{x}}(t)
in the interval
a\leq t\leq b
decreases almost exponentially with respect to
N

Okayama18
;
Ogata23
.

2.2
Solution of the nonlinear simultaneous equations

In the numerical methods outlined in the previous subsection, most of the computation time is spent for solving the nonlinear simultaneous equations (
7
). Hence, their efficient solution is of great importance. Several algorithms can be considered to solve (
7
), such as the Newton method and fixed-point iteration. Among them, Ogata proposes to use a Jacobi type iteration and Gauss-Seidel type iteration
Ogata23
. While he applies these iterations to the IMT-DE periodic Sinc-collocation method, they can be used for the DE Sinc-collocation method as well. Let the approximate solution of (
7
) at the
\nu
th iteration be denoted by
\widetilde{\bm{x}}_{i}^{(\nu)}
and let the initial values be
\widetilde{\bm{x}}_{i}^{(0)}={\bm{x}}_{a}
for
i=N_{1},\ldots,N_{2}
. Also, let

w_{ij}\equiv\varphi^{\prime}(s_{j})P_{j}(s_{i}).

(16)

Then, the recursion formula for the Jacobi type iteration reads

\widetilde{\bm{x}}_{i}^{(\nu+1)}={\bm{x}}_{a}+\sum_{j=N_{1}}^{N_{2}}w_{ij}{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j}^{(\nu)})\quad(i=N_{1},\ldots,N_{2}).

(17)

On the other hand, the Gauss-Sidel type iteration can be written as follows.

\widetilde{\bm{x}}_{i}^{(\nu+1)}={\bm{x}}_{a}+\sum_{j=N_{1}}^{i-1}w_{ij}{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j}^{(\nu+1)})+\sum_{j=i}^{N_{2}}w_{ij}{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j}^{(\nu)})\quad(i=N_{1},\ldots,N_{2}).

(18)

Ogata points out that the Jacobi type iteration (
17
) can be interpreted as a discrete version of the Picard iteration to solve the integral equation (
2
). Based on this observation, he analyzes the convergence of this iteration applied to the IMT-DE periodic Sinc-collocation method and concludes that the iterate
\widetilde{\bm{x}}_{i}^{(\nu)}
converges almost superlinearly to the solution of (
7
)
Ogata23
. For the Gauss-Seidel type iteration (
18
), Ogata does not provide an analysis, but reports that the convergence is extremely fast for the test problems, reducing the error by nearly two orders of magnitude at each iteration
Ogata23
. In the next section, we will analyze the convergence of this Gauss-Seidel type iteration theoretically, focusing mainly on the DE Sinc-collocation method.

3
Convergence analysis of the Gauss-Seidel type iteration for the DE Sinc-collocation method

It is well known in the context of iterative solution of linear systems that the Gauss-Seidel method is generally faster than the Jacobi method. For example, for a linear system arising from discretization of the 2-dimensional Poisson equation by the finite-difference method using 5-point stencil, if the coefficient matrix is consistently ordered, the convergence of the Gauss-Seidel method is twice as fast as that of the Jacobi method. On the other hand, in the present problem, the coefficient matrix
(w_{ij})
is dense, so the above argument does not apply. In addition, the equation to be solved is generally nonlinear. Yet, the numerical results given in
Ogata23
shows that the Gauss-Seidel type iteration is much more efficient than the Jacobi type iteration, requiring less than half the number of iterations of the latter. Hence, it should be of interest to elucidate the reason of this efficiency.

To start the analysis, we define the vector
\widetilde{\bm{X}}^{(\nu)}
, which is a collection of all the vectors at the
\nu
th iteration.

\widetilde{\bm{X}}^{(\nu)}=\left(\begin{array}[]{c}\widetilde{\bm{x}}_{N_{1}}^{(\nu)}\\
\vdots\\
\widetilde{\bm{x}}_{N_{2}}^{(\nu)}\end{array}\right)\in\mathbb{R}^{(N_{2}-N_{1}+1)n}

(19)

For a positive scalar
\rho
, we define a region
\mathcal{D}_{\rho}\subset\mathbb{R}\times\mathbb{R}^{n}
by

\mathcal{D}_{\rho}=\{(t,{\bm{x}})\,|\,t\in[a,b],\|{\bm{x}}-{\bm{x}}_{a}\|_{\infty}\leq\rho\}.

(20)

Also, let

w=\max_{N_{1}\leq i\leq N_{2}}\sum_{j=N_{1}}^{N_{2}}|w_{ij}|.

(21)

We make the following assumption throughout this section.

Assumption 1
.

There exists
\rho>0
such that the following conditions hold:

(i)

there exists a constant
M
such that
\|{\bm{f}}(t,{\bm{x}})\|_{\infty}\leq M
holds for
\forall(t,{\bm{x}})\in\mathcal{D}_{\rho}
,

(ii)

{\bm{f}}(t,x)
is Lipschitz continuous in
\mathcal{D}_{\rho}
, that is, there exists a constant
L>0
such that

\|{\bm{f}}(t,{\bm{x}})-{\bm{f}}(t,{\bm{x}}^{\prime})\|_{\infty}\leq L\|{\bm{x}}-{\bm{x}}^{\prime}\|_{\infty},\quad\forall(t,{\bm{x}}),(t,{\bm{x}}^{\prime})\in\mathcal{D}_{\rho},

(22)

(iii)

the constant
M
can be chosen so that
w\leq\frac{\rho}{M}
.

Note that this is a standard assumption used to prove the existence and uniqueness of the solution of the initial value problem (
1
), except that
w
is used instead of
b-a
in condition (iii). As we will see at the end of subsection
3.2
,
w
is roughly bounded by
b-a
for the DE Sinc-collocation method. Thus, Assumption
1
can be considered as a natural assumption. If the conditions (i) and (ii) hold but (iii) does not, one can consider shrinking the interval
[a,b]
to
[a,b^{\prime}]
, where
a<b^{\prime}<b
. Since
w
depends linearly on
b-a
(see the definition of
\varphi(s)
and (
16
)), one can always fulfill condition (iii) by making
b^{\prime}
sufficiently close to
a
. Of course, conditions (i) and (ii) remain to hold since the region
\mathcal{D}_{\rho}
shrinks.

We first prove the following lemma.

Lemma 1
.

For
\nu=0,1,2,\ldots
and
i=N_{1},N_{1}+1,\ldots,N_{2}
, the vector
\tilde{\bm{x}}_{i}^{(\nu)}
generated by the Gauss-Seidel type iteration (
18
) satisfies
(t,\tilde{\bm{x}}_{i}^{(\nu)})\in\mathcal{D}_{\rho}
for
\forall t\in[a,b]
.

Proof.

Let
\mathcal{D}_{\rho}^{\prime}=\{{\bm{x}}\in\mathbb{R}^{n}\,|\,\|{\bm{x}}-{\bm{x}}_{a}\|_{\infty}\leq\rho\}
. Also, let us introduce a total order
\prec
among the index pairs
\mathcal{I}\equiv\{(\nu,i)\}_{i=N_{1},\ldots,N_{2}}^{\nu=0,1,\ldots}
so that
(\nu^{\prime},i^{\prime})\prec(\nu,i)
when either
\nu^{\prime}<\nu
or
\nu^{\prime}=\nu
and
i^{\prime}<i
holds. Note that in the Gauss-Seidel type iteration (
18
),
\tilde{\bm{x}}_{i^{\prime}}^{(\nu^{\prime})}
is used in the computation of
\tilde{\bm{x}}_{i}^{(\nu)}
only when
(\nu^{\prime},i^{\prime})\in\mathcal{I}
and
(\nu^{\prime},i^{\prime})\prec(\nu,i)
. We show
\tilde{\bm{x}}_{i}^{(\nu)}\in\mathcal{D}_{\rho}^{\prime}
for
\forall(\nu,i)\in\mathcal{I}
by induction on this total order.

First, consider the cases of
\nu=0
and
i\in\{N_{1},N_{1}+1,\ldots,N_{2}\}
. In these cases,
\tilde{\bm{x}}_{i}^{(\nu)}\in\mathcal{D}_{\rho}^{\prime}
holds trivially since
\tilde{\bm{x}}_{i}^{(0)}={\bm{x}}_{a}
(
i=N_{1},\ldots,N_{2}
).

Next, let
\nu\geq 1
and
i\in\{N_{1},N_{1}+1,\ldots,N_{2}\}
and assume that
\tilde{\bm{x}}_{i^{\prime}}^{(\nu^{\prime})}\in\mathcal{D}_{\rho}^{\prime}
for any
(\nu^{\prime},i^{\prime})\in\mathcal{I}
with
(\nu^{\prime},i^{\prime})\prec(\nu,i)
. Note that this assumption holds when
\nu=0
and
i=N_{1}
, which corresponds to the first vector computed in the Gauss-Seidel type iteration. By combining this assumption with Assumption
1
and (
18
), we have

\displaystyle\|\widetilde{\bm{x}}_{i}^{(\nu)}-{\bm{x}}_{a}\|_{\infty}

\displaystyle\leq\sum_{j=N_{1}}^{i-1}|w_{ij}|\,\|{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j}^{(\nu)})\|_{\infty}+\sum_{j=i}^{N_{2}}|w_{ij}|\,\|{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j}^{(\nu-1)})\|_{\infty}

\displaystyle\leq M\sum_{j=N_{1}}^{N_{2}}|w_{ij}|

\displaystyle\leq\rho,

(23)

showing that
\tilde{\bm{x}}_{i}^{(\nu)}\in\mathcal{D}_{\rho}^{\prime}
.

Hence the induction is completed and we have
\tilde{\bm{x}}_{i}^{(\nu)}\in\mathcal{D}_{\rho}^{\prime}
for
\forall(\nu,i)\in\mathcal{I}
. Thus, by definition,
(t,\tilde{\bm{x}}_{i}^{(\nu)})\in\mathcal{D}_{\rho}
for
\forall t\in[a,b]
and
\forall(\nu,i)\in\mathcal{I}
.
∎

In the following, we write
(w_{ij})=(\varphi^{\prime}(s_{j})P_{j}(s_{i}))\in\mathbb{R}^{(N_{2}-N_{1}+1)\times(N_{2}-N_{1}+1)}
as

(w_{ij})=D+E+F,

(24)

where
D
,
E
and
F
are the diagonal part, the strictly lower triangular part and the strictly upper triangular part of
(w_{ij})
, respectively.

3.1
Global convergence of the Gauss-Seidel type iteration

First, we study global convergence property of the Gauss-Seidel type iteration (
18
). Consider an equation with
\nu
replaced by
\nu-1
in (
18
) and subtract it from (
18
) side by side. Then, we have

\displaystyle\widetilde{\bm{x}}_{i}^{(\nu+1)}-\widetilde{\bm{x}}_{i}^{(\nu)}

\displaystyle=\sum_{j=N_{1}}^{i-1}w_{ij}\left\{{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j}^{(\nu+1)})-{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j}^{(\nu)})\right\}

\displaystyle\quad+\sum_{j=i}^{N_{2}}w_{ij}\left\{{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j}^{(\nu)})-{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j}^{(\nu-1)})\right\}\quad(i=N_{1},\ldots,N_{2}).

(25)

Here,
(\varphi(s_{j}),\widetilde{\bm{x}}_{j}^{(\nu)})\in\mathcal{D}_{\rho}
for
\nu=0,1,\ldots
and
N_{1}\leq j\leq N_{2}
by Lemma
1
. Thus, by taking the infinity norm of both sides and using the Lipschitz continuity (
22
), we have

\displaystyle\left\|\widetilde{\bm{x}}_{i}^{(\nu+1)}-\widetilde{\bm{x}}_{i}^{(\nu)}\right\|_{\infty}

\displaystyle\leq\sum_{j=N_{1}}^{i-1}|w_{ij}|\left\|{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j}^{(\nu+1)})-{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j}^{(\nu)})\right\|_{\infty}

\displaystyle\quad+\sum_{j=i}^{N_{2}}|w_{ij}|\left\|{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j}^{(\nu)})-{\bm{f}}(\varphi(s_{j}),\widetilde{\bm{x}}_{j}^{(\nu-1)})\right\|_{\infty}

\displaystyle\leq L\sum_{j=N_{1}}^{i-1}|w_{ij}|\left\|\widetilde{\bm{x}}_{j}^{(\nu+1)}-\widetilde{\bm{x}}_{j}^{(\nu)}\right\|_{\infty}+L\sum_{j=i}^{N_{2}}|w_{ij}|\left\|\widetilde{\bm{x}}_{j}^{(\nu)}-\widetilde{\bm{x}}_{j}^{(\nu-1)}\right\|_{\infty}

\displaystyle\quad\quad(i=N_{1},\ldots,N_{2}).

(26)

By introducing a nonnegative vector
{\bm{Z}}^{(\nu)}
by

{\bm{Z}}^{(\nu)}=\left(\begin{array}[]{c}\left\|\widetilde{\bm{x}}_{N_{1}}^{(\nu)}-\widetilde{\bm{x}}_{N_{1}}^{(\nu-1)}\right\|_{\infty}\\
\vdots\\
\left\|\widetilde{\bm{x}}_{N_{2}}^{(\nu)}-\widetilde{\bm{x}}_{N_{2}}^{(\nu-1)}\right\|_{\infty}\end{array}\right)\in\mathbb{R}^{N_{2}-N_{1}+1},

(27)

we can rewrite (
26
) concisely as

{\bm{Z}}^{(\nu+1)}\leq L|E|{\bm{Z}}^{(\nu+1)}+L(|D|+|F|){\bm{Z}}^{(\nu)}.

(28)

Note that both sides of (
28
) are nonnegative. Also, since
L|E|
is a nonngative strictly lower triangular matrix, we have

(I-L|E|)^{-1}=\sum_{k=0}^{N_{2}-N_{1}}(L|E|)^{k}\geq O.

(29)

Thus, we can pre-multiply both sides of (
28
) by
(I-L|E|)^{-1}
to obtain

(I-L|E|)^{-1}{\bm{Z}}^{(\nu+1)}\leq(I-L|E|)^{-1}L|E|{\bm{Z}}^{(\nu+1)}+(I-L|E|)^{-1}L(|D|+|F|){\bm{Z}}^{(\nu)},

(30)

or

{\bm{Z}}^{(\nu+1)}\leq(I-L|E|)^{-1}L(|D|+|F|){\bm{Z}}^{(\nu)}.

(31)

Letting

M_{\rm GS}\equiv(I-L|E|)^{-1}L(|D|+|F|)

(32)

and taking the infinity norm of both sides of (
31
) yields

\left\|{\bm{Z}}^{(\nu+1)}\right\|_{\infty}\leq\left\|M_{\rm GS}\right\|_{\infty}\left\|{\bm{Z}}^{(\nu)}\right\|_{\infty}.

(33)

Now, assume that
\|M_{\rm GS}\|_{\infty}<1
. Then,

\left\|{\bm{Z}}^{(\nu)}\right\|_{\infty}\leq\left\|M_{\rm GS}\right\|_{\infty}^{\nu-1}\left\|{\bm{Z}}^{(1)}\right\|_{\infty}\rightarrow 0\quad(\nu\rightarrow\infty).

(34)

Using this, we have for
\mu>\nu\geq 0
,

\displaystyle\left\|\widetilde{\bm{X}}^{(\mu)}-\widetilde{\bm{X}}^{(\nu)}\right\|_{\infty}

\displaystyle\leq\sum_{k=\nu+1}^{\mu}\left\|\widetilde{\bm{X}}^{(k)}-\widetilde{\bm{X}}^{(k-1)}\right\|_{\infty}

\displaystyle=\sum_{k=\nu+1}^{\mu}\|{\bm{Z}}^{(k)}\|_{\infty}

\displaystyle\leq\sum_{k=\nu+1}^{\mu}\|M_{\rm GS}\|_{\infty}^{k-1}\|{\bm{Z}}^{(1)}\|_{\infty}

\displaystyle=\|M_{\rm GS}\|_{\infty}^{\nu}\,\frac{1-\|M_{\rm GS}\|_{\infty}^{\mu-\nu}}{1-\|M_{\rm GS}\|_{\infty}}\,\|{\bm{Z}}^{(1)}\|_{\infty}

(35)

Thus,
\left\|\widetilde{\bm{X}}^{(\mu)}-\widetilde{\bm{X}}^{(\nu)}\right\|_{\infty}\rightarrow 0
when
\mu,\nu\rightarrow\infty
and thus
\{\widetilde{\bm{X}}^{(\nu)}\}
is a Cauchy sequence. Hence there exists
\widetilde{\bm{X}}^{*}\in\mathbb{R}^{(N_{2}-N_{1}+1)n}
such that
\widetilde{\bm{X}}^{(\nu)}\rightarrow\widetilde{\bm{X}}^{*}
as
\nu\rightarrow\infty
.
\widetilde{\bm{X}}^{*}
is a fixed point of the Gauss-Seidel type iteration (
18
) and therefore the solution to (
7
). Furthermore, by taking the limit of
\mu\rightarrow\infty
in (
35
), we have for
\nu=1,2,\ldots
,

\left\|\widetilde{\bm{X}}^{(\nu)}-\widetilde{\bm{X}}^{*}\right\|_{\infty}\leq\frac{\|M_{\rm GS}\|_{\infty}^{\nu}}{1-\|M_{\rm GS}\|_{\infty}}\,\|{\bm{Z}}^{(1)}\|_{\infty}.

(36)

Theorem 1

Let

be a matrix defined by (

This theorem applies to both the DE Sinc-collocation method and the IMT-DE periodic Sinc-collocation method. Note that the matrix

3.2
Rate of convergence of the Gauss-Seidel type iteration for the DE Sinc-collocation method

Now we focus on the DE Sinc-collocation method and investigate the rate of convergence of the Gauss-Seidel type iteration (

) in more detail.

We start by evaluating the infinity norm of
|E|
. Since

is a part of
(w_{ij})=(\varphi^{\prime}(s_{j})P_{j}(s_{i}))
with
i>j
and
P_{j}(s_{i})=h\left\{\frac{1}{2}+\frac{1}{\pi}{\rm Si}(\pi(i-j))\right\}>0
when

is a nonnegative matrix. Also, it holds that
{\rm Si}(\pi k)<{\rm Si}(\pi)<1.86
for

. Using these facts, we can evaluate the sum of the elements in the
i
th row (
-N\leq i\leq N
) of

as

\displaystyle\sum_{j=-N}^{N}|e_{ij}|

\displaystyle=\sum_{j=-N}^{i-1}w_{ij}

\displaystyle=\frac{(b-a)}{2}\sum_{j=-N}^{i-1}\frac{\frac{\pi}{2}\cosh(jh)}{\cosh^{2}\left(\frac{\pi}{2}\sinh(jh)\right)}\cdot h\left\{\frac{1}{2}+\frac{1}{\pi}{\rm Si}(\pi(i-j))\right\}

\displaystyle\leq\frac{(b-a)}{2}\cdot\left\{\frac{1}{2}+\frac{1}{\pi}{\rm Si}(\pi)\right\}\cdot h\sum_{j=-N}^{i-1}\frac{\frac{\pi}{2}\cosh(jh)}{\cosh^{2}\left(\frac{\pi}{2}\sinh(jh)\right)}

\displaystyle\leq\frac{(b-a)}{2}\cdot 1.1\cdot h\sum_{j=-\infty}^{\infty}\frac{\frac{\pi}{2}\cosh(jh)}{\cosh^{2}\left(\frac{\pi}{2}\sinh(jh)\right)}

\displaystyle\simeq\frac{(b-a)}{2}\cdot 1.1\cdot\int_{-\infty}^{\infty}\frac{\frac{\pi}{2}\cosh(s)}{\cosh^{2}\left(\frac{\pi}{2}\sinh(s)\right)}\,{\rm d}s

\displaystyle=\frac{(b-a)}{2}\cdot 1.1\cdot\int_{-1}^{1}{\rm d}t

\displaystyle=1.1(b-a).

(37)

This leads to an upper bound on

as

\|E\|_{\infty}=\max_{-N\leq i\leq N}\sum_{j=-N}^{N}|e_{ij}|\leq 1.1(b-a).

(38)

Hence, if we choose the interval

so that

\displaystyle\|(I-L|E|)^{-1}\|_{\infty}

Next, we evaluate the infinity norm of
|D|+|F|

2

\displaystyle\sum_{j=-N}^{N}(|d_{ij}|+|f_{ij}|)

\displaystyle=\sum_{j=i}^{N}|w_{ij}|

\displaystyle=\frac{(b-a)}{2}\sum_{j=i}^{N}\frac{\frac{\pi}{2}\cosh(jh)}{\cosh^{2}\left(\frac{\pi}{2}\sinh(jh)\right)}\cdot h\left|\frac{1}{2}+\frac{1}{\pi}{\rm Si}(\pi(i-j))\right|

3.3
Intuitive explanation for the efficiency

Eqs. (
38
) and (
43
) suggest that the matrix
(w)_{ij}=D+E+F
is almost lower triangular and this is the reason for the high efficiency of the Gauss-Seidel type iteration. We will explain intuitively why this nearly lower triangular structure arises.

Let us consider a simplified fictitious method where the DE transformation (
9
) is replaced by the identity transformation
\varphi(s)=s
and
p_{j}(s)
is a piecewise linear function with
p_{j}(s_{i})=\delta_{ij}
. Then, it is easy to see that
P_{j}(s_{i})=0
for
i<j
and the matrix
(w_{ij})
is lower triangular. In fact, this method is nothing but the implicit Euler method and the lower triangularity means that the method respects causality, in the sense that it does not use the function values at the
j
th time step, where
j>i
, to compute the function values at the
i
th time step.

The DE Sinc-collocation method achieves very high accuracy by breaking this type of causality to a certain extent. But the weight of function values at future time steps (
P_{j}(s_{i})
for
i<j
) must be small because it is unnatural to use such information from a physical point of view. This explains the nearly lower triangular structure of
(w_{ij})
.

5
Conclusion

In this paper, we analyzed the convergence of Gauss-Seidel type iteration for solving nonlinear simultaneous equations arising from the double-exponential Sinc-collocation method for initial value problems. We derived a sufficient condition for convergence of this iteration and also provided an upper bound on its rate of convergence, which explains the rapid convergence of this iteration. Our theoretical results are supported by numerical examples. Our future work includes extending this analysis to other methods such as the IMT-DE-based method recently proposed by Ogata.

Proof of the lemma used in subsection

Lemma 2
.

When
x>0
, the following inequality holds.

\left|\frac{\pi}{2}-{\rm Si}(x)\right|\leq\frac{1}{x}.

(56)

Proof.

The proof that follows is a detailed version of the proof given in
stackexchange
. First, recall the following two equalities from
(
Abramowitz65
, Eqs. 5.2.12 and 5.2.13)
.

\displaystyle\int_{0}^{\infty}\frac{\sin s}{x+s}\,{\rm d}s

\displaystyle=\int_{0}^{\infty}\frac{e^{-xs}}{1+s^{2}}\,{\rm d}s,

(57)

\displaystyle\int_{0}^{\infty}\frac{\cos s}{x+s}\,{\rm d}s

\displaystyle=\int_{0}^{\infty}\frac{se^{-xs}}{1+s^{2}}\,{\rm d}s.

(58)

Using these, we have

\displaystyle\frac{\pi}{2}-{\rm Si}(x)

\displaystyle=\int_{0}^{\infty}\frac{\sin t}{t}\,{\rm d}t-\int_{0}^{x}\frac{\sin t}{t}\,{\rm d}t

\displaystyle=\int_{x}^{\infty}\frac{\sin t}{t}\,{\rm d}t

\displaystyle=\int_{0}^{\infty}\frac{\sin x\cos s+\cos x\sin s}{x+s}\,{\rm d}s

\displaystyle=\int_{0}^{\infty}\frac{\sin x\cos s+\cos x\sin s}{x+s}\,{\rm d}s

\displaystyle=\int_{0}^{\infty}\frac{s\sin x+\cos x}{1+s^{2}}\,e^{-xs}\,{\rm d}s.

Taking the absolute values of both sides and applying the Cauchy-Schwarz inequality to the numerator of the integrand in the right-hand side gives

\displaystyle\left|\frac{\pi}{2}-{\rm Si}(x)\right|

(60)

, we can show that
\{x_{\ell}(t)\}_{\ell=1}^{2m-1}
satisfy the Lotka-Volterra equation. The statement about the initial values follows naturally because
\{q_{k}(t)\}_{k=1}^{m}
and
\{e_{k}(t)\}_{k=1}^{m-1}
are connected with
\{x_{k}(t)\}_{k=1}^{2m-1}
through (
63
) for any
t
.
∎

Next, we describe how to solve the initial value problem of the Toda lattice equation (
62
). Let us define an
m\times m
tridiagonal matrix
A=A(t)
and its strictly lower triangular part
A_{-}=A_{-}(t)
by

A=\left(\begin{array}[]{cccc}q_{1}&1&&\\
e_{1}&q_{2}&\ddots&\\
&\ddots&\ddots&1\\
&&e_{m-1}&q_{m}\end{array}\right),\quad A_{-}=\left(\begin{array}[]{cccc}&&&\\
e_{1}&&&\\
&\ddots&&\\
&&e_{m-1}&\end{array}\right).

(72)

Then, it can easily be verified that the matrix differential equation

\frac{{\rm d}A}{{\rm d}t}=[A,A_{-}],

(73)

where
[A,B]=AB-BA
, is equivalent to the Toda lattice equation (
62
). More specifically, the differential equations for
q_{k}(t)
arise from the equalities among the diagonal elements of (
73
), while those for
e_{k}(t)
arise from the equalities among the lower subdiagonal elements of (
73
). Eq. (
73
) is called the Lax form of (
62
).

Once expressed in the form of (
73
), the Toda lattice equation can be solved by the group theoretic method
Kostant79
;
Nakamura18
. The procedure to compute
\{q_{k}(t)\}_{k=1}^{m}
and
\{e_{k}(t)\}_{k=1}^{m-1}
for given
t
is as follows.

(i)

Construct
A(0)
from
\{q_{k}(0)\}_{k=1}^{m}
and
\{e_{k}(0)\}_{k=1}^{m-1}
.

(ii)

Compute
\exp(tA(0))
and its
LR
decomposition
\exp(tA(0))=L_{t}R_{t}
, where
L_{t}
is a unit lower subdiagonal matrix and
R_{t}
is an upper bidiagonal matrix.

(iii)

Let
A(t)\equiv L_{t}^{-1}A(0)L_{t}
.

(iv)

Obtain
\{q_{k}(t)\}_{k=1}^{m}
and
\{e_{k}(t)\}_{k=1}^{m-1}
as the diagonal elements and the lower subdiagonal elements of
A(t)
, respectively.

By combining this procedure with Lemma
3
, we can construct an exact solution to the Lotka-Volterra equation.

For general
m
and
A(0)
, the matrix exponential
\exp(tA(0))
has to be calculated numerically. However, when
m=2
, everything can be computed analytically. Below, we will give a sample of such cases.

Example 1

Let us consider the case of
m=2
,
q_{1}^{(0)}=q_{2}^{(0)}=3
and
e_{1}^{(0)}=1
. Then, we have

A(0)=\left(\begin{array}[]{cc}3&1\\
1&3\end{array}\right)=\left(\begin{array}[]{cc}\frac{1}{\sqrt{2}}&\frac{1}{\sqrt{2}}\\
\frac{1}{\sqrt{2}}&-\frac{1}{\sqrt{2}}\end{array}\right)\left(\begin{array}[]{cc}4&0\\
0&2\end{array}\right)\left(\begin{array}[]{cc}\frac{1}{\sqrt{2}}&\frac{1}{\sqrt{2}}\\
\frac{1}{\sqrt{2}}&-\frac{1}{\sqrt{2}}\end{array}\right)^{-1}

(74)

and

\exp(tA(0))=\left(\begin{array}[]{cc}\frac{1}{\sqrt{2}}&\frac{1}{\sqrt{2}}\\
\frac{1}{\sqrt{2}}&-\frac{1}{\sqrt{2}}\end{array}\right)\left(\begin{array}[]{cc}e^{4t}&0\\
0&e^{2t}\end{array}\right)\left(\begin{array}[]{cc}\frac{1}{\sqrt{2}}&\frac{1}{\sqrt{2}}\\
\frac{1}{\sqrt{2}}&-\frac{1}{\sqrt{2}}\end{array}\right)^{-1}=\frac{1}{2}\left(\begin{array}[]{cc}e^{4t}+e^{2t}&e^{4t}-e^{2t}\\
e^{4t}-e^{2t}&e^{4t}+e^{2t}\end{array}\right).

(75)

Thus,

\exp(tA(0))=\left(\begin{array}[]{cc}1&0\\
\tanh t&1\end{array}\right)\left(\begin{array}[]{cc}\frac{e^{4t}+e^{2t}}{2}&\frac{e^{4t}-e^{2t}}{2}\\
0&\frac{e^{4t}+e^{2t}}{2}-\frac{(e^{4t}-e^{2t})^{2}}{2(e^{4t}+e^{2t})}\end{array}\right)=L_{t}R_{t}

(76)

and

\displaystyle A(t)=L_{t}^{-1}A(0)L_{t}

\displaystyle=\left(\begin{array}[]{cc}1&0\\
-\tanh t&1\end{array}\right)\left(\begin{array}[]{cc}3&1\\
1&3\end{array}\right)\left(\begin{array}[]{cc}1&0\\
\tanh t&1\end{array}\right)

\displaystyle=\left(\begin{array}[]{cc}3+\tanh t&1\\
\frac{1}{\cosh^{2}t}&3-\tanh t\end{array}\right).

This corresponds to the solution:

q_{1}(t)=3+\tanh t,\quad q_{2}(t)=3-\tanh t,\quad e_{1}(t)=\frac{1}{\cosh^{2}t}.

(85)

It is easy to verify that these functions actually satisfy the Toda lattice equation (
62
).

Furthermore, by invoking Lemma
3
, we can construct the corresponding solution of the Lotka-Volterra equation as follows.

\displaystyle x_{1}(t)

\displaystyle=q_{1}(t)-1=2+\tanh t,

(86)

\displaystyle x_{2}(t)

\displaystyle=\frac{e_{1}(t)}{u_{1}(t)}=\frac{1}{\cosh t(2\cosh t+\sinh t)},

(87)

\displaystyle x_{3}(t)

\displaystyle=q_{2}(t)-1-u_{2}(t)=2-\tanh t-\frac{1}{\cosh t(2\cosh t+\sinh t)}.

(88)

This is a solution corresponding to the initial condition
x_{1}^{(0)}=2
,
x_{2}^{(0)}=\frac{1}{2}
and
x_{3}^{(0)}=\frac{3}{2}
. We used this solution in Section
4
.
