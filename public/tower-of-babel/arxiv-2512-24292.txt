On maximum distance separable and completely regular codes Journal: Finite Fields and their Applications
Joaquim Borges, Josep Rifà, Victor A. Zinoviev

Abstract
We investigate when a maximum distance separable ( MDS \operatorname{MDS} ) code over 𝔽 q \mathbb{F}_{q} is also completely regular ( CR \operatorname{CR} ). For lengths n = q + 1 n=q+1 and n = q + 2 n=q+2 we provide a complete classification of the MDS \operatorname{MDS} codes that are CR \operatorname{CR} or at least uniformly packed in the wide sense ( UPWS \operatorname{UPWS} ). For the more restricted case n ≤ q n\leq q with q ≤ 5 q\leq 5 we obtain a full classification (up to equivalence) of all nontrivial MDS \operatorname{MDS} codes: there are none for q = 2 q=2 ; only the ternary Hamming code for q = 3 q=3 ; four nontrivial families for q = 4 q=4 ; and exactly six linear MDS \operatorname{MDS} codes for q = 5 q=5 (three of which are CR \operatorname{CR} and one admits a self-dual version). Additionally, we close two gaps left open in a previous classification of self-dual CR \operatorname{CR} codes with covering radius ρ ≤ 3 \rho\leq 3 : we precisely determine over which finite fields the MDS \operatorname{MDS} self-dual completely regular codes with parameters [ 2 , 1 , 2 ] q [2,1,2]_{q} and [ 4 , 2 , 3 ] q [4,2,3]_{q} exist.

Introduction

Let
\mathbb{F}_{q}
denote the finite field of order
q
, where
q
is a prime power, and let
\mathbb{F}_{q}^{*}=\mathbb{F}_{q}\setminus\{0\}
.
A linear
[n,k,d]_{q}
code

C
is a
k
-dimensional subspace of
\mathbb{F}_{q}^{n}
with minimum Hamming distance
d
.
For any
{\bf v}\in\mathbb{F}_{q}^{n}
its
distance
to the code
C
is
d({\bf v},C)=\min\{d({\bf v},{\bf x})\mid{\bf x}\in C\}
. Throughout the paper we assume
0<k<n
, thereby excluding the trivial codes consisting of only the zero codeword or the whole space
\mathbb{F}_{q}^{n}
.

The Euclidean
inner product
of two vectors
\mathbf{v},\mathbf{u}\in\mathbb{F}_{q}^{n}
is

\mathbf{v}\cdot\mathbf{u}=\sum_{i=1}^{n}v_{i}u_{i}\in\mathbb{F}_{q}.

The (Euclidean)
dual code
of a linear code
C
is

C^{\perp}=\{\mathbf{x}\in\mathbb{F}_{q}^{n}\mid\mathbf{x}\cdot\mathbf{v}=0\ \forall\mathbf{v}\in C\}.

We say that
C
is
self-dual
if
C=C^{\perp}
. The
external distance
of
C
(see
[
7
]
) is the number
s
of nonzero weights in
C^{\perp}
.

The
packing radius
of
C
is
e=\lfloor(d-1)/2\rfloor
and the
covering radius
is

\rho=\max_{\mathbf{v}\in\mathbb{F}_{q}^{n}}\{d({\bf v},C)\}.

Clearly
e\leq\rho
, with equality if and only if
C
is perfect. It is well known that any nontrivial perfect code (with more than two codewords) satisfies
e\leq 3

[
23
,
24
]
.

Linear perfect codes with
e=1
are the
Hamming codes
; they exist for length
n=(q^{m}-1)/(q-1)
(
m\geq 2
), dimension
k=n-m
, and minimum distance
d=3
. Their duals are the
simplex codes
with parameters
[n,m,q^{m-1}]_{q}
, which are equidistant
[
15
, Theorem 1.8.3]
(all nonzero codewords have weight
q^{m-1}
).

For any
{\bf v}\in\mathbb{F}^{n}_{q}
and any
t\in\{0,\ldots,n\}
, define
B_{{\bf v},t}=|\{{\bf x}\in C\mid d({\bf v},{\bf x})=t\}|
.

Definition 1
(
[
7
]
)

A code
C
is completely regular (
\operatorname{CR}
) if
B_{{\bf v},t}
depends only on
t
and
d({\bf v},C)
.

Remark 2

If
C
is linear, then Definition
1
is equivalent to say that any coset
C+{\bf x}
depends only on its minimum weight
d({\bf x},C)
.

For a more detailed description and basic properties of
\operatorname{CR}
codes over finite fields, see
[
5
,
6
]
, or
[
19
, Chap. 2]
, for example.

A more general class of codes is the class of uniformly packed codes in the wide sense
[
2
]
.

Definition 3
(
[
2
]
)

A code
C\subseteq\mathbb{F}_{q}^{n}
with covering radius
\rho
is uniformly packed in the wide sense (
\operatorname{UPWS}
) if there exist rational numbers
\beta_{0},\ldots,\beta_{\rho}
such that

\sum_{i=0}^{\rho}\beta_{i}B_{{\bf x},i}=1,

(1)

for any
{\bf x}\in\mathbb{F}^{n}_{q}
. The numbers
\beta_{0},\ldots,\beta_{\rho}
are called the packing coefficients.

If
C
is a
[n,k,d]_{q}
code, the Singleton bound
[
20
]
establishes that

d\leq n-k+1.

(2)

If
C
attains equality, then
C
is a
maximum distance separable
(
\operatorname{MDS}
) code.

The Griesmer bound
[
14
,
22
]
is

n\geq\sum_{i=0}^{k-1}\left\lceil\frac{d}{q^{i}}\right\rceil\;\;\;(k\geq 1).

(3)

If
C
attains equality, then
C
is a
Griesmer
code.

In this paper we study the possible parameters of
\operatorname{MDS}
codes (which are also Griesmer codes) over
\mathbb{F}_{q}
. For length
n=q+1
and
n=q+2
we give a complete classification of the
\operatorname{MDS}
codes that are completely regular or at least uniformly packed in the wide sense. For
q\leq 5
, we obtain a full classification (up to equivalence) of all nontrivial
\operatorname{MDS}
codes. For
q=2
, as is well known, there are only trivial cases. For
q=3
, there is only one nontrivial case, which is a self-dual Hamming code. For
q=4
, the nontrivial cases are a Hamming code, its dual code, a self-dual code, and the so-called hexacode. The case
q=5
being the most interesting. We determine that there are
6
nontrivial such codes in
\mathbb{F}_{5}
, up to equivalence. Three of them are
\operatorname{CR}
codes. In addition, we point out in which cases such codes are self-dual. Moreover, we specify exactly in which finite fields the
\operatorname{MDS}
codes with parameters
[2,1,2]_{q}
and
[4,2,3]_{q}
are also self-dual. Such codes are completely regular as stated in
[
6
]
.

The main conjecture on
\operatorname{MDS}
codes is the following

Conjecture 4

If
C
is a nontrivial
\operatorname{MDS}

[n,k,d]_{q}
code (
2\leq k\leq n-2
), then
n\leq q+1
unless
q
is even and
k=3
or
k=q-1
, in which case
n\leq q+2
.

Such conjecture was first considered by Segre
[
17
]
and is proven for a large number of cases. For our purposes, the following case, proven in
[
1
]
is useful.

Proposition 5

If
C
is an
\operatorname{MDS}

[n,k,d]_{p}
code with
p
prime and
2\leq k\leq n-2
, then
n\leq p+1
.

The paper is organized as follows.
In Section
2
we collect the basic definitions and known results that will be used throughout the paper, including some simple lemmas on equations over finite fields that allow us to precise, for the first time, the exact fields where self-dual
[4,2,3]_{q}

\operatorname{MDS}
codes exist.

Section
3
deals with the trivial
\operatorname{MDS}
codes (
k=1
or
k=n-1
).
We recall their covering radius and external distance and clarify when they are completely regular or uniformly packed.

In Section
4
we study nontrivial
\operatorname{MDS}
codes (
2\leq k\leq n-2
).
We first analyse the extremal cases allowed by the
\operatorname{MDS}
conjecture: length
n=q+2
(Subsection
4.1
) and length
n=q+1
(Subsection
4.2
).
For
n=q+1
we give a sharp characterisation of the parameters for which the code is uniformly packed in the wide sense (and hence, in some cases, completely regular), including the infinite family of completely regular doubly-extended Reed–Solomon codes of dimension
q-2
over even-order fields.
Subsection
4.3
is devoted to the short nontrivial
\operatorname{MDS}
codes (
n\leq q
).
We prove that all such codes are uniformly packed and, for the smallest fields
q\leq 5
, we obtain a complete classification (Theorem
23
for
q=5
being the most interesting case).

Section
5
summarises all families and sporadic examples obtained.

2
Preliminary results

2.1
Quadratic equations over finite fields

The next result can be derived from Remark 5.13 in
[
16
]
. However, we give here our own proof, which is very simple.

Proposition 6

Let
q
be an odd prime power. Then
-1
is a square in
\mathbb{F}_{q}
if and only if
q\equiv 1\pmod{4}
.

Proof.
Let
\xi
be a primitive element in
\mathbb{F}_{q}
. Since
\xi^{q-1}=1
, we have
\xi^{\frac{q-1}{2}}=-1
. But
-1
is a square if and only if there is some element
\xi^{i}\in\mathbb{F}_{q}
such that
\xi^{2i}=-1
. Therefore,
\frac{q-1}{2}
is even, implying
q-1\equiv 0\pmod{4}
, or the same,
q\equiv 1\pmod{4}
.
∎

Remark 7

If
q=p^{r}
, where
p
is an odd prime and
r>0
, then the condition
q\equiv 1\pmod{4}
is clearly equivalent to:

(i)

p\equiv 1\pmod{4}
, or

(ii)

p\equiv 3\pmod{4}
and
r
is even.

Recall that the quadratic character
\chi
of
\mathbb{F}_{q}
is defined as
\chi(a)=1
if
a
is a square, and
\chi(a)=-1
if
a
is not (
a\in\mathbb{F}_{q}^{*}
).
The next result is Lemma 6.24 in
[
16
]
.

Proposition 8

Let
q
be an odd prime power and
t,a_{1},a_{2}\in\mathbb{F}_{q}^{*}
.

The equation

a_{1}x_{1}^{2}+a_{2}x_{2}^{2}=t

(4)

has exactly
q-\chi(-a_{1}a_{2})
solutions, where
\chi
is the quadratic character of
\mathbb{F}_{q}
.

In
[
6
]
it is stated that any
[4,2,3]_{q}
code is
\operatorname{CR}
and taking a generator matrix of the form

G~=~\left(\begin{array}[]{cccc}~1&~0&~\alpha&~\beta\\
~0&~\xi&~\beta&~-\alpha\\
\end{array}\right),

(5)

where
\alpha,\beta\in\mathbb{F}^{*}_{q}
, such code is also self-dual if
1+\alpha^{2}+~\beta^{2}=0
and
\xi^{2}=1
. But in
[
6
]
it is not specified in which finite fields these conditions can be satisfied. By using Proposition
8
, we can precise such finite fields.

Corollary 9

A self-dual
[4,2,3]_{q}
code exists if and only if
q\notin\{2,5\}
.

Proof.
Consider, in
\mathbb{F}_{q}
, the equation

\alpha^{2}+\beta^{2}=-1.

(6)

If
q=2
, then it is clear that there is no solution such that
\alpha,\beta\neq 0
. For
q=2^{r}
(
r>1
), we always have solutions with
\alpha,\beta\neq 0
, since
\alpha^{2}+\beta^{2}=(\alpha+\beta)^{2}
. Hence, taking any
\alpha\notin\{0,1\}
we have the solution
(\alpha,\beta=1+\alpha)
, where indeed
\alpha,\beta\neq 0
.

Assume now that
q
is odd. By Proposition
8
, Eq. (
6
) has
q-\chi(-1)
solutions. However, the set of solutions can include cases where
\alpha
or
\beta
is
0
.

If
-1
is not a square then
\alpha
and
\beta
must be nonzero elements and, by Proposition
8
the number of solutions of Eq. (
6
) is
q+1
. Hence, in this case we always have solutions (with
\alpha,\beta\neq 0
).

If
-1
is a square, then let
\gamma\in\mathbb{F}_{q}^{*}
be such that
\gamma^{2}=-1
. Thus, we have four solutions where
\alpha
or
\beta
is
0
:

(\alpha,\beta)\in\{(\gamma,0),(-\gamma,0),(0,\gamma),(0,-\gamma)\}.

On the other hand, in this case, the total number of solutions is
q-1
, according to Proposition
8
. Therefore, Eq. (
6
) always has solutions with
\alpha,\beta\neq 0
if
q-1>4
, that is,
q>5
.

Note that
-1
is not a square in
\mathbb{F}_{3}
and it is a square in
\mathbb{F}_{5}
. We conclude that Eq. (
6
) always has solutions with
\alpha,\beta\neq 0
except in
\mathbb{F}_{2}
and
\mathbb{F}_{5}
.
∎

2.2
Properties of completely regular and Hamming codes

For completely regular codes, we will use the following properties.

Lemma 10

Let
C
be a linear code with minimum distance
d
, covering radius
\rho
, packing radius
e
and external distance
s
.

(i)

\rho\leq s

[
7
]
.

(ii)

If
d\geq 2s-1
, then
C
is
\operatorname{CR}

[
7
]
.

(iii)

\rho=s
if and only if
C
is
\operatorname{UPWS}

[
3
]
.

(iv)

If
C
is
\operatorname{CR}
, then
\rho=s

[
21
]
.

(v)

If
C
is
\operatorname{UPWS}
and
\rho=e+1
, then
C
is
\operatorname{CR}

[
13
,
18
]
.

(vi)

Let
C_{1}
and
C_{2}
be two cosets of
C
with the same minimum weight
w
. If
w\leq d-s
or
w=s
, then
C_{1}
and
C_{2}
have identical weight distribution
[
7
]
(see also
[
21
, Thm. 4.3]
).

Note that, by (iii) and (iv), a
\operatorname{CR}
code is always a
\operatorname{UPWS}
code.

The only self-dual perfect code is the ternary Hamming
[4,2,3]_{3}
code (see, for example,
[
6
, Lemma 13]
). Since a Hamming code has parameters
[n=(q^{m}-1)/(q-1),n-m,3]_{q}
, it is an
\operatorname{MDS}
code if and only if
m=2
. In such case, the parameters are
[q+1,q-1,3]_{q}
and the dual simplex code has parameters
[q+1,2,q]_{q}
. Since a simplex code has only one nonzero weight, Hamming codes have external distance
s=1
. Hence a Hamming code is
\operatorname{CR}
by Lemma
10
(ii).

2.3
\operatorname{MDS}
and Griesmer codes

The following equivalence is easy to see, but not usually mentioned.

Proposition 11

Let
C
be an
[n,k,d]_{q}
code with
k\geq 2
. Then
C
is an
\operatorname{MDS}
code if and only if
C
is a Griesmer code and
d\leq q
.

Proof.
If
C
is an
\operatorname{MDS}
code, then
n=d+k-1
. By the Griesmer bound
(\ref{griesmer})
we have

d+k-1\geq d+\sum_{i=1}^{k-1}\left\lceil\frac{d}{q^{i}}\right\rceil\;\;\;\Longrightarrow\;\;\;\left\lceil\frac{d}{q^{i}}\right\rceil=1\;\;\forall i=1\ldots k-1.

Thus
d\leq q
and the bound is attained.

Conversely, if
d\leq q
and
C
is a Griesmer code, then

n=\sum_{i=1}^{k-1}\left\lceil\frac{d}{q^{i}}\right\rceil=d+k-1.

Hence,
C
is an
\operatorname{MDS}
code.
∎

All the following results on
\operatorname{MDS}
codes can be found in
[
15
, Sect. 7.4]
.

Proposition 12

Let
C
be an
\operatorname{MDS}

[n,k,d]_{q}
.

(i)

C^{\perp}
is
\operatorname{MDS}
.

(ii)

The number of minimum weight codewords in
C
(i.e. codewords of weight
d
) is

A_{d}=\binom{n}{d}(q-1).

(iii)

If
2\leq k\leq n-2
, then
k\leq\min\{n-2,q-1\}
and
n\leq 2(q-1)
.

In
[
10
]
, the number of weights of
\operatorname{MDS}
codes is determined.

Proposition 13
(
[
10
]
)

Let
C
be an
\operatorname{MDS}

[n,k,d]_{q}
code and let
s^{\prime}
be the number of nonzero weights of
C
.

(i)

If
C
is an
[n,n-1,2]_{2}
code with
n>2
, then
s^{\prime}=\lfloor n/2\rfloor\not=k
.

(ii)

If
C
is a
[q+1,2,q]_{q}
code, then
s^{\prime}=1
.

(iii)

If
C
is a
[2^{m}+2,3,2^{m}]_{2^{m}}
code, then
s^{\prime}=2
.

In all other cases
s^{\prime}=k
, assuming that Conjecture
4
is true.

3
Trivial
\operatorname{MDS}
codes

Trivial
\operatorname{MDS}

[n,k,d]_{q}
codes are those with
k=1
or
k\geq n-1
.

For
k=1
, we have the
\operatorname{MDS}
repetition codes
C_{R}
with parameters
[n,1,n]_{q}
. Such codes and their duals, the
[n,n-1,2]_{q}
codes, are
\operatorname{CR}
(by Lemma
10
(ii), since the codes
C_{R}
have just one nonzero weight). For
q=2
,
C_{R}
codes have covering radius
\rho=\lfloor n/2\rfloor
(see
[
4
, Thm. 1]
) and identical external distance
s=\lfloor n/2\rfloor
by Proposition
13
. Hence, binary
C_{R}
codes are
\operatorname{UPWS}
by Lemma
10
(iii). Moreover, since the packing radius is
e=\lfloor(n-1)/2\rfloor
, we have that
e=\rho
if
n
is odd, and
e+1=\rho
if
n
is even. Therefore,
C_{R}
is a perfect code if
n
is odd, and a quasi-perfect
\operatorname{UPWS}
code if
n
is even. In any case,
C_{R}
is a
\operatorname{CR}
code by Lemma
10
.

For
q>2
and
n>2
, we have
\rho=n-\lceil n/q\rceil
(see
[
4
, Thm. 1]
) and the external distance is
s=n-1
(Proposition
13
). Hence,
C_{R}
is
\operatorname{UPWS}
if and only if
q\geq n
.

Example 14

The ternary code
C=\{0000,1111,2222\}
is not
\operatorname{CR}
: the vectors
{\bf v}=0011
and
{\bf u}=1200
are at distance 2 from
C
, but their distances to the codewords are
2,2,4
and
2,3,3
, respectively.

Note that if a
C_{R}
code is self-dual then
n=2
. In such case, the codes
[2,1,2]_{q}
are
\operatorname{CR}
: any vector
{\bf x}
is at distance 0 or 1 from
C
. It is esay to see that, if
{\bf x}
is at distance 0, then
B_{{\bf x},0}=1
,
B_{{\bf x},1}=0
, and
B_{{\bf x},2}=q-1
. If
{\bf x}
is at distance 1, then
B_{{\bf x},0}=0
,
B_{{\bf x},1}=2
, and
B_{{\bf x},2}=q-2
. Indeed, take a generator matrix
G=(1\;\;\alpha)
for a
[2,1,2]_{q}

C_{R}
code. Then
C_{R}
is self-dual if and only if
\alpha^{2}=-1
. In fact, these codes or direct sums of them are the only self-dual
\operatorname{CR}
codes with
d\leq 2
(see
[
6
, Thm. 36(i)]
). However, in
[
6
]
the finite fields where such codes exist are not specified. As a direct consequence of Proposition
6
we can establish the following result.

Theorem 15

Let
C
be a self-dual
\operatorname{CR}

[n,k,d]_{q}
code. If
d\leq 2
, then
C
is necessarily an
\operatorname{MDS}

[2,1,2]_{q}
code, or a direct sum of
j
codes with these parameters (and
C
is not
\operatorname{MDS}
for
j>1
). Such codes exist if and only if
q
is even or
q\equiv 1\pmod{4}
.

4
Nontrivial
\operatorname{MDS}
codes

Nontrivial
\operatorname{MDS}

[n,k,d]_{q}
codes are those with
2\leq k\leq n-2
. Assuming that the
\operatorname{MDS}
conjecture
(Conjecture

) is true, we have that

except in some exceptional cases where

. We start with these extremal cases.

4.1
\operatorname{MDS}
codes with length
n=q+2

According to Conjecture
4
, a nontrivial
\operatorname{MDS}
code of length

is a
[2^{m}+2,3,2^{m}]_{2^{m}}

[2^{m}+2,2^{m}-1,4]_{2^{m}}

.

Concerning complete regularity, we introduce the following result for such codes.

Theorem 16

Let
C
be an
\operatorname{MDS}

[q+2,k,d]_{q}
code, where

and

.

(i)

If
C
is an
\operatorname{MDS}

[2^{m}+2,3,2^{m}]_{2^{m}}

, then

is not
\operatorname{UPWS}
(and so, not
\operatorname{CR}
).

(ii)

If
C
is an
\operatorname{MDS}

[2^{m}+2,2^{m}-1,4]_{2^{m}}

is
\operatorname{CR}
.

Proof.
(i) By Proposition
13
,
C
has external distance

. For
m
odd, the covering radius of

is
\rho=2^{m}-2
by
[
12
, Thm. 4]
. Hence, by Lemma
10
(iii),
C
is not
\operatorname{UPWS}
.

(ii) In this case, by Proposition

,
C
has external distance

and thus
C
is
\operatorname{CR}
by Lemma
10
(ii).
∎

4.2
\operatorname{MDS}
codes with length
n=q+1

For
n=q+1
we have
\operatorname{MDS}
codes with parameters
[q+1,k,q-k+2]_{q}
. We start with the particular case
k=2
.

Proposition 17

Let
C
be an
\operatorname{MDS}

[q+1,2,q]_{q}
code

(i)

If
q
is odd, then
C
is
\operatorname{UPWS}
and
\operatorname{CR}
if and only if
q=3
.

(ii)

If
q
is even, then
C
is
\operatorname{UPWS}
. For
q=2^{2}
,

is
\operatorname{CR}
. For
q=2^{3}
,
C
is not
\operatorname{CR}
.

Proof.
The
[q+1,2,q]_{q}
code
C
is a simplex code since its dual is a
[q+1,q-1,3]_{q}
Hamming code.

(i) For odd
q
, the covering radius of
C
is
\rho=q-2=d-2
(see
[
4
, Thm. 10]
) and the external distance is
s=q-1=d-1
except for
q=3
(see Proposition

and apply it to the dual code). Hence, for

,
C
is not
\operatorname{UPWS}
by Lemma

(iii). For
q=3
,
C
is the self-dual Hamming
[4,2,3]_{3}
code which is perfect and so
\operatorname{CR}
.

(ii) For even
q
, we have
s=d-1
(again applying Proposition
13
) and
\rho=d-1

[
12
, Rem. 2]
. Hence
C
is an
\operatorname{UPWS}
code.
If
q=2^{2}
, the
[5,2,4]_{4}
code is
\operatorname{CR}
(it is a particular case of Theorem
18
(iii)). For
q=2^{3}
, we have computationally checked that a
[9,2,8]_{8}
code is not
\operatorname{CR}
.
∎

Now, we have the following strong result for any
k\geq 2
.

Theorem 18

If
C
is a nontrivial
\operatorname{MDS}

[q+1,k,q-k+2]_{q}
code, then
C
is not
\operatorname{UPWS}
(and so not
\operatorname{CR}
) with the following exceptions:

(i)

k=q-1
, in which case
C
is a Hamming perfect and
\operatorname{CR}
code.

(ii)

k=2
with
q
even or
q=3
, in which case
C
is
\operatorname{UPWS}
. For
q=3
,
C
is also
\operatorname{CR}
.

(iii)

k=q-2
with
q
even, in which case
C
is
\operatorname{UPWS}
. Moreover, for any
m>1
, there exists a
\operatorname{CR}

[q+1,q-2,4]_{q}
code, where
q=2^{m}
.

Proof.
(i) Trivial.

(ii) Directly from Proposition
17
.

(iii) In this case,
C
is a
[2^{m}+1,2^{m}-2,4]_{2^{m}}
code. By Proposition
13
, the external distance of
C
is
s=3=d-1
and, by
[
12
, Rem. 2]
, the covering radius of
C
is
\rho=d-1=3
. Hence,
C
is
\operatorname{UPWS}
.

Generalized Reed–Solomon (GRS) codes and their extensions are
\operatorname{MDS}
, in general. No
\operatorname{MDS}
codes with parameters other than those arising from GRS codes or their extensions are presently known
[
15
]
. Hence, almost all
[q+1,q-2,4]_{q}
maximum distance separable codes over
\mathbb{F}_{q}
are equivalent to doubly-extended Reed–Solomon codes.

By Lemma
10
(vi), the cosets of minimum weight
1
have identical weight distribution. Again, by Lemma
10
(vi), the cosets of weight
3
have also the same weight distribution.

The automorphism group of these doubly-extended Reed–Solomon codes is
G=P\Gamma\mathrm{L}_{2}(q)

[
9
]
. Consider the action of
G
over the cosets of
C
: for any
\sigma\in G
and any
{\bf x}\in\mathbb{F}_{q}^{n}
,
\sigma(C+{\bf x})=C+\sigma({\bf x})
.

Since
G
acts
2
-transitively on the
q+1
points of the projective line over
\mathbb{F}_{q}

[
8
]
, we conclude that the cosets of weight
2
are in the same
G
-orbit and hence they have identical weight distribution.

Therefore,
C
is
\operatorname{CR}
(see Remark
2
).

Assume now that
C
is not one of the cases (i)–(iii). Then,
s=q-k+1=d-1
by Proposition
13
. The covering radius of
C
is
\rho=d-2
(see
[
12
, Thm. 2]
). Therefore,
C
is not
\operatorname{UPWS}
by Lemma
10
(iii).
∎

Remark 19

The value
q=2^{2}
also shows that in Proposition 12 (ii) there exists a case where the code is completely regular.

4.3
\operatorname{MDS}
codes with length
n\leq q\leq 5

We begin establishing the following result.

Theorem 20

If
C
is an
\operatorname{MDS}

[n,k,d]_{q}
code with
n\leq q
, then
C
is
\operatorname{UPWS}
.

Proof.
By Proposition
13
,
s=n-k=d-1
. The covering radius is
\rho=d-1

[
12
, Thm. 1]
. Since
s=\rho
,
C
is
\operatorname{UPWS}
by Lemma
10
(iii).
∎

Remark 21

The result
\rho=d-1
in
[
12
, Thm. 1]
is true, provided that
C
can be embedded in an
[n,k+1,n-k]_{q}
code, which is true for any known nontrivial
\operatorname{MDS}
code of length
n\leq q
.

In general, it seems hard to determine in which cases an
\operatorname{MDS}
code
C
is also
\operatorname{CR}
. However, for small fields we may consider some particular cases.

It is well known that all binary
\operatorname{MDS}
codes are trivial. This is a direct consequence of the condition
d\leq q
for nontrivial
\operatorname{MDS}
codes (see Proposition
11
).

For
q=3
, we have
n\leq 4
, by Proposition
12
(iii). Hence, we have the only nontrivial case of
[4,2,3]_{3}
codes which are the self-dual
\operatorname{CR}
Hamming ternary codes.

If
q=4
then, by Proposition
12
(iii), we have
n\leq 6
. So, we have the possible parameters
[6,4,3]_{4}
,
[6,3,4]_{4}
,
[6,2,5]_{4}
,
[5,3,3]_{4}
,
[5,2,4]_{4}
and
[4,2,3]_{4}
. The case of a
[6,3,4]_{4}
code corresponds to the well-known two-weight
hexacode
(see, e.g.,
[
15
, p. 383]
). Such code is
\operatorname{CR}
by Lemma
10
(ii) since
s=2
. In fact, it is a particular case of Theorem
16
(ii). The other two cases with
n=6
can be discarded after the following result.

Lemma 22

There do not exist codes with parameters
[6,4,3]_{4}
or
[6,2,5]_{4}
.

Proof.
It is enough to prove the non existence of a
[6,2,5]_{4}
code since it implies the non existence of its dual, a
[6,4,3]_{4}
code. Assume that
C
is a
[6,2,5]_{4}
code. Since it would be
\operatorname{MDS}
, by Proposition
12
(ii), the number of codewords of weight 5 should be

A_{5}=3\binom{6}{5}=18.

However,
|C|=4^{2}=16
leading to a contradiction.
∎

For the remaining cases, note that a
[5,3,3]_{4}
code is a Hamming code and a
[5,2,4]_{4}
code is the corresponding simplex dual. Finally, a
[4,2,3]_{4}
code exists and it is
\operatorname{CR}
. In fact, any
[4,2,3]_{q}
code is
\operatorname{CR}
by Lemma
10
since
s\leq 2
(see also Proposition 23 in
[
6
]
). By Corollary
9
a
[4,2,3]_{4}
code is self-dual taking a generator matrix

G=\left(\begin{array}[]{cccc}1&0&\alpha&\alpha^{2}\\
0&1&\alpha^{2}&\alpha\\
\end{array}\right),

where
\alpha
is a primitive element in
\mathbb{F}_{4}
.

The next smallest interesting finite field where to study
\operatorname{MDS}
codes is
\mathbb{F}_{5}
.

Now, we determine the possible parameters for nontrivial
\operatorname{MDS}
codes over
\mathbb{F}_{5}
. Since Conjecture
4
is proven for prime fields, and applying Proposition
12
, we only have to consider the cases:

(n,k)\in\{(6,4),(6,3),(6,2),(5,3),(5,2),(4,2)\}.

Finally, we establish the main result for
\operatorname{MDS}
codes over
\mathbb{F}_{5}
.

Theorem 23

If
C
is a nontrivial
\operatorname{MDS}

[n,k,d]_{5}
code, then
C
is one of the following codes, up to equivalence:

(i)

A
\operatorname{CR}

[6,4,3]_{5}
code or its dual
[6,2,5]_{5}
which is not
\operatorname{UPWS}
.

(ii)

A
[6,3,4]_{5}
code, which is not
\operatorname{UPWS}
. A self-dual version of such code exists.

(iii)

A
\operatorname{CR}

[5,3,3]_{5}
code or its dual
[5,2,4]_{5}
which is
\operatorname{UPWS}
.

(iv)

A
[4,2,3]_{5}
code which is
\operatorname{CR}
and not self-dual.

Proof.
Let us see that all these codes exist.

(i) A
[6,4,3]_{5}
code is a Hamming code, which is a perfect code and hence
\operatorname{CR}
. The
[6,2,5]_{5}
is the corresponding simplex dual code, which is not
\operatorname{UPWS}
by Proposition
17
.

(ii) A
[6,3,4]_{5}
code cannot be
\operatorname{UPWS}
by Theorem
18
. A self-dual code with these parameters exists by
[
11
, Thm.1(iv) or (v)]
.

(iii) For the
[5,2,4]_{5}
code we can consider a generator matrix

G=\left(\begin{array}[]{ccccc}1&0&1&1&1\\
0&1&2&3&4\\
\end{array}\right).

Note that the code generated by
G
is indeed a
[5,2,4]_{5}
code, which is
\operatorname{UPWS}
by Theorem
20
. The corresponding dual code is a
[5,3,3]_{5}
code which is
\operatorname{CR}
by Lemma
10

(iv) Consider the generator matrix

G=\left(\begin{array}[]{cccc}1&0&1&1\\
0&1&2&3\\
\end{array}\right).

It is readily verified that the generated code is a
[4,2,3]_{5}
code
C
. The dual code
C^{\perp}
has the same parameters but
C\neq C^{\perp}
, i.e.,
C
is not self-dual. This is clear due to Corollary
9
. But the code is
\operatorname{CR}
by Lemma
10
. Indeed,
C
and
C^{\perp}
have external distance
s=2
by Proposition
13
. In fact,
C
and
C^{\perp}
have the same weight distribution, which is:

A_{3}=4\binom{4}{3}=16\;\;\mbox{ by Proposition \ref{MDSCodes} (ii), and }A_{4}=5^{2}-A_{3}-1=8.

∎

5
Summary

In summary we have found the following infinite families of
\operatorname{MDS}
codes which are
\operatorname{CR}
codes:

(i)

The trivial
[n,n-1,2]_{q}
codes for any
n
and
q
, and the
[n,1,n]_{2}
codes.

(ii)

Any
[2^{m}+2,2^{m}-1,4]_{2^{m}}
code for
m>0
.

(iii)

The Hamming
[q+1,q-1,3]_{q}
codes for any
q
.

(iv)

The
[2^{m}+1,2^{m}-2,4]_{2^{m}}
codes equivalent to doubly-extended Reed-Solomon codes, for any
m>1
.

In addition, for
n\leq q
, we have the sporadic codes (not included above) with parameters

1.

[4,2,3]_{4}
. The punctured code of a
[5,2,4]_{4}
CR code (item (iv) above, for
m=2
),

2.

[5,3,3]_{5}
. Theorem
23
(iii).

3.

[4,2,3]_{5}
. Theorem
23
(iv).
