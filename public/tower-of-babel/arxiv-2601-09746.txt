From Seen to Unseen: Collaborative Conceptual Anchoring for Few-Shot and Zero-Shot OOD Understanding
Philip Xu, Isabel Wagner, Eerke Boiten

Abstract
This paper introduces a novel Multi-Agent Cooperative Learning (MACL) framework to address cross-modal alignment collapse in vision-language models for OOD concepts. Four core agents (image, text, name, and coordination) collaboratively overcome modality imbalances via structured message-passing. Key contributions include a multi-agent feature space name learning framework, a context exchange-enhanced few-shot learning algorithm, and an adaptive dynamic balancing mechanism. Experiments on the VISTA-Beyond dataset show MACL significantly improves performance in few-shot and zero-shot settings, with 1–5% precision gains across diverse domains.

3.2
Preliminary

OpenCLIP, a reproducible implementation of the CLIP framework, integrates a dual-encoder architecture comprising a visual encoder
f
and a text encoder
g
. These encoders are jointly optimized on extensive image-text pairs
\{\bm{I}_{i},\bm{T}_{i}\}_{i=1}^{N}
from open-source corpora (e.g., LAION
[
31
]
), where the InfoNCE loss aligns normalized embeddings
f(\bm{I})
and
g(\bm{T})
by maximizing their cosine similarity. The trained model enables open-vocabulary inference through a probabilistic classification mechanism:

P_{V}^{(f,g)}(\bm{y}|\bm{I})=\frac{\exp\left(\gamma^{-1}\cdot\langle f(\bm{I}),\,g(\bm{T}(\bm{y}))\rangle\right)}{\sum_{\bm{y}_{i}\in V}\exp\left(\gamma^{-1}\cdot\langle f(\bm{I}),\,g(\bm{T}(\bm{y}_{i}))\rangle\right)},

(1)

where
\bm{T}(\bm{y})
represents a templated prompt (e.g., ”a photo of [
\bm{y}
]”) embedding the class label
\bm{y}
, and
V
defines the classification vocabulary.

Motivation

While conventional vision-language models restrict classification to pre-training text concepts
\{\bm{T}_{i}\}_{i=1}^{N}
, OpenCLIP’s vocabulary
V
inherently supports generalization to novel classes. This capability arises from its pre-trained cross-modal alignment, which bridges visual and semantic representations. To leverage this property, lightweight adaptation strategies—such as tuning task-specific prompts or auxiliary layers can refine the model’s discriminative power, balancing performance on both in-distribution (ID) and out-of-distribution (OOD) class predictions.

3.2.1
Agent Architecture

The core innovation of the MACL framework lies in the introduction of four specialized agents, each focusing on specific tasks while continuously collaborating:

Image Agent
(
\mathcal{A}_{I}
): Focuses on multi-strategy visual processing and feature extraction.

Text Agent
(
\mathcal{A}_{T}
): Responsible for generating text representations and integrating context.

Name Agent
(
\mathcal{A}_{N}
): Specializes in concept name learning and context exchange.

Coordinator Agent
(
\mathcal{A}_{C}
):Manages overall collaboration and optimization processes.
each agent
\mathcal{A}_{i}
can be represented as a function with memory:

\mathcal{A}_{i}:\mathcal{I}_{i}\times\mathcal{M}_{i}\rightarrow\mathcal{O}_{i}\times\mathcal{M}_{i}^{\prime}

(2)

where
\mathcal{I}_{i}
is the input space,
\mathcal{M}_{i}
is the current memory state,
\mathcal{O}_{i}
is the output space, and
\mathcal{M}_{i}^{\prime}
is the updated memory state. This design allows MACL to break through the limitations of traditional single-model approaches, achieving distributed collaborative learning more akin to human cognitive systems. Each agent can share information while processing its own tasks, thereby enhancing the overall system’s performance and efficiency, providing a solid foundation for solving the cross-modal alignment breakdown problem.

3.2.2
Message Passing Mechanism

We design a novel structured message-passing protocol to enable bidirectional information flow between agents, a key innovation that distinguishes the MACL framework from traditional methods. The message
m_{i\rightarrow j}
from agent
i
to agent
j
is formatted as:

m_{i\rightarrow j}=(i,j,\text{content})

(3)

where
content
includes feature representations, processing strategies, or metadata. This communication mechanism enables unprecedented cross-modal information exchange, such as passing visual perceptions to text processing or sharing concept representations across different modalities, effectively bridging the semantic gap between modalities.

3.2.3
Image Agent

The Image Agent proposes an innovative multi-strategy visual processing framework that automatically adjusts processing strategies based on sample complexity. Traditional visual encoders often suffer from unstable features and degraded representation quality when handling out-of-distribution (OOD) concepts. To address this critical challenge, we design a three-level progressive processing strategy:

Standard Encoding and Robust Encoding

The most basic processing method directly applies the visual encoder
f_{v}
to the input image
x
:
\phi_{\text{standard}}(x)=f_{v}(x)
To enhance feature stability, we further introduce feature normalization and residual connection mechanisms:

\phi_{\text{robust}}(x)=\frac{f_{v}(x)}{\|f_{v}(x)\|_{2}}+\alpha\cdot f_{v}(x)_{\text{detach}}

(4)

where
\alpha
controls the influence of residual features, and
f_{v}(x)_{\text{detach}}
represents feature representations that do not participate in gradient propagation. This design allows for finer control over the parameter update process, maintaining the stability of visual representations when processing OOD concepts and avoiding issues like gradient explosion or vanishing.
Difficulty Estimation
We propose a sample difficulty assessment mechanism based on feature distribution:

d(x)=\sigma(W_{2}\cdot\text{ReLU}(W_{1}\cdot\bar{f}_{v}(x)+b_{1})+b_{2})

(5)

where
\bar{f}_{v}(x)
represents the average feature in the batch, and
\sigma
is the Sigmoid activation function. This mechanism dynamically identifies hard-to-process samples, optimizing computational resource allocation and enabling the system to adaptively allocate more attention to high-difficulty samples. This not only improves the model’s robustness but also significantly enhances its adaptability when handling OOD concepts. Through this multi-level strategy framework, the Image Agent can effectively handle visual inputs of various complexities, particularly demonstrating significant advantages when processing OOD concepts. This innovative multi-strategy visual processing framework provides visual-language models with stronger representation capabilities and adaptability when facing unknown concepts, thereby enhancing the overall system’s cross-modal alignment capabilities.

3.2.4
Text Agent

The Text Agent is an enhanced text processing system specifically designed to address the issues traditional text encoders face when handling novel or rare (OOD) concepts. It consists of the following three core components:

Standard Encoding

The most basic text processing method directly inputs prompts and target text into the text encoder:

\psi_{\text{standard}}(p,t_{p})=f_{t}(p,t_{p})

(6)

where
p
is the prompt (e.g., ”a photo of a cat”),
t_{p}
is the target text (e.g., ”cat”), and
f_{t}
is the text encoder function.

Contextual Encoding

This is our key innovation, combining text and image information:

\psi_{\text{contextual}}(p,t_{p},c)=\lambda\cdot f_{t}(p,t_{p})+(1-\lambda)\cdot g_{\text{ctx}}([f_{t}(p,t_{p});c])

(7)

The specific working principle is as follows:
First, obtain the standard text encoding
f_{t}(p,t_{p})
.
Simultaneously, obtain visual context information
c
from the Image Agent.Concatenate text and visual features
[f_{t}(p,t_{p});c]
.Process these concatenated features through the context integration module
g_{\text{ctx}}
.Finally, use parameter
\lambda
to control the ratio of original text features to visually enhanced features.In this way, the Text Agent can ”see” image content, establishing more accurate concept representations even when encountering previously unseen concepts.

Context Integration Module

This is a two-layer neural network specifically designed to process and fuse text-visual information:

g_{\text{ctx}}(z)=W_{4}\cdot\text{ReLU}(W_{3}\cdot z+b_{3})+b_{4}

(8)

This module receives concatenated text-visual features
z
and organically fuses information from both modalities through nonlinear transformations (ReLU activation function) and weight matrices (
W_{3}
,
W_{4}
).Through this design, the Text Agent can leverage visual information to assist in understanding text, significantly improving the model’s performance, especially when handling novel or rare concepts. This addresses the inconsistency between text and image representations in traditional models, enabling better alignment between the two modalities.

3.2.5
Name Agent

The Name Agent is a core innovation of the MACL framework, specifically designed to address the representation learning problem for out-of-distribution (OOD) concepts. It operates through the following three key mechanisms:

Name Embedding Learning
creates dedicated word vector representations for each new concept:

E_{c}={e_{1}^{c},e_{2}^{c},\ldots,e_{n_{c}}^{c}}

Specifically, when the model encounters a completely new concept like ”flying saucer” (which does not exist in the pretrained vocabulary), the Name Agent creates a set of specific word vector representations for ”flying saucer.” These vectors capture the semantic features of the concept, enabling the model to understand this new concept even though it has never appeared in the training data. Name embedding learning allows the model to build effective representations for concepts completely outside the pretrained vocabulary, significantly expanding the model’s conceptual understanding capabilities.

Prompt Generation
uses predefined templates and learned name embeddings to generate diverse text prompts:
p_{c}=\text{template}(c,E_{c})
For example, the model can generate various prompts based on the learned representation of ”flying saucer,” such as ”a photo of a flying saucer” or ”a flying saucer in the sky.” These prompts help the model understand the new concept from different perspectives, providing diverse semantic information and enhancing the model’s generalization ability for new concepts.

Context Exchange Enhanced Learning
This is an innovative data augmentation technique that creates more learning samples by exchanging semantic contexts across different categories: Specific approach:1. First generate a standard description for concept
c
:
d_{c}=\text{template}_{c}(c)
(e.g., ”a flying saucer in flight”)
2. Then use templates from other concepts
c^{\prime}
to describe concept
c
:
d_{c^{\prime}}=\text{template}_{c^{\prime}}(c)
(e.g., using a bird template: ”a flying saucer perched on a branch”)This method greatly increases the diversity of training samples, enabling the model to quickly understand the essential features of new concepts even with very few samples, and to distinguish between core attributes and contextual attributes of concepts. Through context exchange, the model is exposed to more diverse semantic scenarios, allowing for a more comprehensive learning of new concepts.
Through the Name Agent, our model can effectively handle completely new concepts, accurately capturing key features and establishing effective representations even with very few samples.

3.2.6
Coordinator Agent

The Coordinator Agent manages system collaboration and implements adaptive optimization. Traditional contrastive learning methods typically use fixed parameter settings, unable to flexibly handle concepts of varying difficulty and changing data distributions. To address this issue, we designed the following adaptive adjustment mechanisms:Dynamic Temperature Scaling: Automatically adjusts the temperature parameter in contrastive learning to balance learning of easy and hard samples:
\tau=\text{clip}(\tau_{\text{param}},0.5,2.0)
Simply put, temperature parameter
\tau
controls the ”softness” of similarity calculations. Lower temperatures make the model more sensitive to similarity differences, while higher temperatures are more lenient. The Coordinator Agent automatically adjusts this parameter based on training conditions but limits it between 0.5 and 2.0 to prevent training instability from extreme values.

Contrastive Loss

Promotes alignment between images and text:

L_{\text{con}}=-\frac{1}{2N}\sum_{i=1}^{N}\left[\log\frac{\exp(s_{i,y_{i}}/\tau)}{\sum_{j}\exp(s_{i,j}/\tau)}+\log\frac{\exp(s_{y_{i},i}/\tau)}{\sum_{j}\exp(s_{j,i}/\tau)}\right]

(9)

The meaning of this formula is:
For each image-text pair, we want the similarity between matching images and text to be high (numerator). Simultaneously, we want the similarity between this image and all other texts to be low, and vice versa (denominator).
s_{i,j}=\tau\cdot f_{v}(x_{i})^{T}f_{t}(t_{j})
calculates the similarity between image
i
and text
j
.
y_{i}
is the correct matching index for sample
i
.

Auxiliary Classification Loss

Helps image features better distinguish between different categories:

L_{\text{cls}}=-\frac{1}{N}\sum_{i=1}^{N}\log\frac{\exp(W_{\text{cls}}f_{v}(x_{i})_{y_{i}})}{\sum_{j}\exp(W_{\text{cls}}f_{v}(x_{i})_{j})}

(10)

This is a standard classification loss that uses extracted image features to predict correct category labels.

Dynamic Loss Balancing

Automatically adjusts the weights of different loss terms based on training progress:

w_{\text{con}}=\frac{\text{clip}(w_{\text{con}}^{\text{param}},0.5,2.0)}{w_{\text{con}}^{\text{param}}+w_{\text{cls}}^{\text{param}}}

(11)

w_{\text{cls}}=\frac{\text{clip}(w_{\text{cls}}^{\text{param}},0.1,1.0)}{w_{\text{con}}^{\text{param}}+w_{\text{cls}}^{\text{param}}}

(12)

L=w_{\text{con}}\cdot L_{\text{con}}+w_{\text{cls}}\cdot L_{\text{cls}}

(13)

This automatic loss weight adjustment mechanism addresses common conflicts in multi-objective optimization. The system can. Just the importance of contrastive learning and classification learning based on the current learning phase.

Experiment setup

To understand component contributions in MACL, we conducted ablation studies verifying each agent’s role. Table

5
Conclusion

MACL overcomes cross-modal alignment collapse in vision-language models for unseen concepts by coordinating four specialized agents. Our approach enhances zero-shot and few-shot performance, yielding consistent 1–5% precision gains on the VISTA-Beyond dataset. This multi-agent collaboration offers a promising path toward robust, adaptive multimodal understanding.
