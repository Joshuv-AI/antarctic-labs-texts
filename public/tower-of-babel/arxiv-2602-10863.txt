ICA: Information-Aware Credit Assignment for Visually Grounded Long-Horizon Information-Seeking Agents
Cong Pang, Xuyu Feng, Yujie Yi, Zixuan Chen, Jiawei Hong, Tiankuo Yao, Nang Yuan, Jiapeng Luo, Lewei Lu, Xin Lou

Abstract
Despite the strong performance achieved by reinforcement learning–trained information-seeking agents, learning in open-ended web environments remains severely constrained by low signal-to-noise feedback. Text-based parsers often discard layout semantics and introduce unstructured noise, while long-horizon training typically relies on sparse outcome rewards that obscure which retrieval actions actually matter. We propose a visual-native search framework that represents webpages as visual snapshots, allowing agents to leverage layout cues to quickly localize salient evidence and suppress distractors. To learn effectively from these high-dimensional observations, we introduce Information-Aware Credit Assignment (ICA), a post-hoc method that estimates each retrieved snapshot’s contribution to the final outcome via posterior analysis and propagates dense learning signals back to key search turns. Integrated with a GRPO-based training pipeline, our approach consistently outperforms text-based baselines on diverse information-seeking benchmarks, providing evidence that visual snapshot grounding with information-level credit assignment alleviates the credit-assignment bottleneck in open-ended web environments. The code and datasets will be released in https://github.com/pc-inno/ICA_MM_deepsearch.git .

Introduction

In open-web information seeking, the central challenge extends beyond multi-turn interaction to the inherently low signal-to-noise ratio of web content: agents must distill noisy observations and attribute success to a small subset of genuinely informative retrieval steps. Recent systems built on large language models have advanced this paradigm toward increasingly sophisticated interactions with external web environments
(
7
;
30
;
37
;
38
;
44
)
, demonstrating strong performance on open-domain and multi-hop question answering benchmarks
(
10
;
24
;
18
;
35
;
3
;
23
)
that require iterative retrieval and reasoning. Nevertheless, despite powerful model backbones and carefully designed prompting strategies, agents often struggle in long-horizon trajectories under noisy information sources, where redundant, low-quality, or misleading observations accumulate and ultimately obscure the evidence most relevant to the final decision.

A key impediment to improving these agents via reinforcement learning is a persistent signal-to-noise bottleneck. On the observation front, most web agents
(
7
;
11
;
37
;
38
)
depend on text-based parsing pipelines that linearize visually rich webpages into unstructured sequences, thereby discarding layout semantics and interleaving salient evidence with boilerplate, navigation elements, and script-related artifacts. On the supervision front, long-horizon optimization is typically driven by sparse, terminal outcome rewards. In combination, noisy observations and delayed supervision render learning brittle: the reward signal reflects only final-answer correctness, providing limited attribution of success or failure to the specific retrieval decisions that surfaced informative evidence versus those that introduced distractors.

To address these limitations, we adopt a visual-native search framework in which webpages are represented as rendered snapshots rather than HTML-derived text. This representation preserves the page’s semantic organization as expressed through its visual layout, enabling agents to leverage stable structural cues (e.g., headings, tables, highlighted regions, and spatial grouping) to more reliably localize salient evidence while suppressing irrelevant content. Moreover, snapshots retain visually grounded information that is frequently distorted or discarded by text extraction pipelines, including figures, charts, and other non-textual elements that are often critical for verification. By obviating fragile parsing heuristics and model-dependent preprocessing, snapshot-based observations provide a more faithful and cross-trajectory-consistent interface to external evidence, thereby reducing spurious variability in the learning signal.

Building upon this representation, we propose Information-Aware Credit Assignment (ICA), a post-hoc credit attribution approach tailored to long-horizon retrieval. Instead of scoring actions online during rollout, ICA operates on completed trajectories to estimate the marginal contribution of each retrieved atomic evidence unit to the terminal outcome, and subsequently propagates the resulting dense learning signal to the upstream search turns responsible for acquiring high-utility information. We define an atomic evidence unit as the smallest identifiable, self-contained fragment of external information returned by tool interactions; concretely, under web search it corresponds to an individual result item, whereas under
Fetch
it corresponds to a retrieved webpage snapshot that preserves salient layout cues. By shifting credit assignment from the action level to a posterior, information-centric view, ICA converts sparse outcome supervision into more informative intermediate feedback, thereby explicitly emphasizing the retrieval decisions that are consequential under noisy exploration.

Finally, as illustrated in Figure
1
, we incorporate snapshots and ICA into a GRPO-based optimization pipeline and evaluate the resulting agents on a diverse suite of information-seeking benchmarks. Empirically, our approach yields consistent gains over text-based baselines across model scales, underscoring the value of grounding reinforcement learning in visually structured external observations and performing credit assignment at the granularity of acquired evidence.

In summary, this work makes the following contributions:

•

We introduce rendered webpage snapshots as a stable, information-complete modality for external observations, facilitating persistent identification and cross-trajectory comparison of acquired evidence without lossy, model-dependent preprocessing.

•

We propose Information-Aware Credit Assignment (ICA), a post-hoc, information-level credit assignment mechanism that estimates the utility of acquired information via posterior success association and propagates it back to the decisions that introduced it.

•

We integrate snapshots and ICA into a GRPO-based optimization framework and demonstrate consistent improvements on a diverse set of long-horizon information-seeking benchmarks compared to prior work.

Related Work

2.1
Information Seeking Agents

Information-seeking (IS) agents have advanced rapidly, driven by proprietary systems such as DeepResearch
(
20
)
and Grok-3
(
40
)
. But their training and tool-integration strategies remain opaque, which limits reproducibility. In contrast, open-source agents including WebDancer
(
37
)
, WebThinker
(
14
)
, and R1-Searcher
(
28
)
adopt the ReAct framework and achieve competitive results across diverse tasks, providing a solid basis for further study.

Despite this progress, existing agents still struggle to balance information adequacy with reasoning efficiency during tool–environment interaction. GLM
(
17
)
retrieves raw webpage content via search/click/open, but the resulting unfiltered text is noisy and can trigger context overflow. Tongyi DeepSearch
(
11
)
instead adopts a search-and-summary pipeline with a visit tool; however, summarizing raw HTML with heavy formatting noise often requires specialized models and adds latency. Search-R1
(
8
)
improves efficiency by chunking results and retrieving segments with a reranker, but performance becomes sensitive to chunking choices, potentially missing key evidence. Moreover, multimodal IS agents face cross-modal gaps: in MMSearch-R1
(
39
)
and DeepMMSearch-R1
(
19
)
, visual evidence is frequently compressed into text and weakened in the reasoning chain, leading to the loss of critical multimodal cues.

2.2
Information Seeking Benchmark

The landscape of information-seeking tasks has evolved from basic single-hop queries to complex, multi-hop reasoning, and eventually to highly nonlinear, deep-search challenges. Early single-hop benchmarks, such as NQ
(
10
)
, TriviaQA
(
9
)
, and SimpleQA-Verified
(
6
)
, primarily consist of questions resolvable through structured queries, simple search operations, or even the model’s internal parametric knowledge. Subsequent multi-hop datasets, including Bamboogle
(
25
)
, Xbench-DS
(
41
)
, and GAIA
(
18
)
, have significantly elevated the difficulty by introducing multi-step retrieval requirements and domain-specific annotations. These benchmarks rigorously test an agent’s capability in deep search and multi-turn tool utilization. At the frontier of this complexity are benchmarks like BrowseComp
(
35
)
and SealQA
(
23
)
, which represent the most formidable challenges for information-seeking agents. These tasks are characterized by highly nonlinear coupled sub-problems and deliberate information masking, introducing substantial uncertainty and search depth that push the boundaries of current agentic reasoning.

2.3
Reinforcement Learning in IS Agents

Reinforcement Learning has reshaped Large Language Models via RLHF
(
45
;
29
;
22
;
26
)
, improving alignment with human preferences. More recently, group-based RL methods such as GRPO
(
27
)
, Dr.GRPO
(
16
)
, and DAPO
(
42
)
have shown strong performance while avoiding an explicit value function, thereby reducing training overhead. However, applying RL to IS agents remains challenging in long-horizon trajectories. Outcome-only supervision often leads to sparse and noisy credit assignment, and its effectiveness decreases as trajectory length increases.

To obtain denser learning signals, recent work studies fine-grained credit assignment at additional cost. IGPO
(
34
)
rewards each turn by its marginal gain in correct-answer probability, while MT-PPO
(
36
)
uses an LLM-as-a-judge to score every step. GiGPO
(
4
)
further introduces anchor-state grouping to contrast actions across comparable states and stabilize signals, but it relies on trajectories containing highly similar states. In practical tool-use settings, small changes in tool-call parameters can alter responses and break state comparability, limiting the effectiveness of such grouping.

Preliminaries

We study an IS agent that interacts with external web resources to answer a user query

q\in\mathcal{Q}
. The agent incrementally acquires external information via tool invocations and reasons over the
accumulated results.

State with cumulative interaction history.

At turn
t
, the agent maintains a comprehensive state
s_{t}
encapsulated by the history
\mathcal{H}_{t-1}
, which consists of the original query
q
and the sequential trajectory of reasoning traces, actions, and observations from previous turns. Formally, we define the history as:

\mathcal{H}_{t-1}=\left(q,\{(\tau_{i},a_{i},o_{i})\}_{i=1}^{t-1}\right),\qquad s_{t}=\mathcal{H}_{t-1}.

(1)

Here,
\tau_{i}
,
\alpha_{i}
, and
o_{i}
denote the generated reasoning trace (thought), the executable action, and the external observation at step
i
, respectively. Importantly, this structure makes the context persistent. The agent conditions each generation step on the complete interaction history, allowing it to continually update and refine its policy using accumulated evidence and prior reasoning.

Action space.

At each turn, the agent selects an action

a_{t}\in\mathcal{A}=\{\textsc{Search},\textsc{Fetch},\textsc{Answer}\}.

(2)

Here,
Search
and
Fetch
correspond to interactions with external web resources, while
Answer
indicates the termination of the information-seeking process to return the final response to the user.

Web search.

When performing a web search action, the agent may issue multiple query reformulations.
The external environment returns a ranked list of search result entries:

o_{t}^{\text{search}}=\{r_{t,1},r_{t,2},\ldots,r_{t,n}\}.

(3)

Each search result
r_{t,i}
contains a webpage URL, a title, and a short snippet.

Fetch URL.

To access detailed information from external sources, the agent invokes a fetch action on a set of URLs

L_{t}\subseteq\{\ell_{t-1,1},\ell_{t-1,2},\ldots,\ell_{t-1,n}\}

derived from the search results of the immediately preceding turn
t-1
. The external environment returns the corresponding content for each URL in
L_{t}
:

o_{t}^{\text{fetch}}=\{\mathcal{C}(\ell)\mid\ell\in L_{t}\},

(4)

where
\mathcal{C}(\ell)
denotes the retrieved information associated with the URL, which may take different forms such as webpage text or rendered page snapshots.

Sequential information acquisition.

Across turns, the agent builds a cumulative context by appending the latest interaction tuple to the history:

\mathcal{H}_{t}=\mathcal{H}_{t-1}\cup\{(\tau_{t},a_{t},o_{t})\}.

(5)

The process terminates at step
T
when the agent triggers the
Answer
action. The final response
\hat{y}
is generated conditioned on the accumulated history up to that point:

a_{T}=\textsc{Answer},\qquad\hat{y}\sim\pi_{\theta}(\cdot\mid\mathcal{H}_{T-1},\tau_{T}).

(6)

4
Information-Aware Credit Assignment for Information-Seeking Agents

4.1
Information-Aware Credit Assignment (ICA)

To address the challenges identified in the introduction, we propose

Information-Aware Credit Assignment (ICA)
, a turn-level credit
assignment mechanism designed for long-horizon information-seeking agents.
Rather than attributing learning signals solely based on final task outcomes,
ICA assigns credit according to how individual decisions affect the acquisition
of external information that supports subsequent reasoning.

4.1.1
Information-Aware Turn Credit

ICA performs credit assignment in a post-hoc manner after a batch of
interaction trajectories has been fully collected.
Specifically, the agent first samples a set of
N
trajectories

\{\tau^{(1)},\tau^{(2)},\ldots,\tau^{(N)}\}

by executing the current policy, where each trajectory

\tau^{(n)}=\{(s_{t}^{(n)},a_{t}^{(n)},o_{t}^{(n)})\}_{t=1}^{T_{n}}

records the sequence of reasoning steps, tool invocations, and acquired external
information.
Only after all trajectories in the batch have terminated do we perform
Information-Aware credit assignment.
This design decouples information acquisition from credit estimation and avoids
introducing additional computational overhead during long-horizon rollouts.

Each information unit acquired during a trajectory is first evaluated based on
its contribution to the final reasoning outcome.
The resulting information-level credit is then propagated backward to the
decisions that introduced the information, providing learning signals to both
intermediate reasoning steps and tool-invocation actions according to their
downstream impact.

4.1.2
Turn-Level Credit Assignment

We instantiate the ICA framework with a concrete turn-level reward tailored for long-horizon information-seeking agents trained using GRPO. The core idea is to assign credit based on how strongly acquired external observations are associated with successful task completion, and to propagate this credit to earlier decisions at the turn level.

Trajectory outcomes.

Given a batch of completed trajectories, we partition them into successful and
unsuccessful sets according to the final task outcome. A trajectory is considered successful if the generated answer satisfies the task-specific correctness criterion; otherwise, it is labeled as unsuccessful. In practice, correctness is determined using LLM-as-a-Judge that evaluates the final answer against the task specification.

Atomic-Evidence Counterfactual Contribution

We define an atomic evidence unit
e\in\mathcal{E}
as the minimal
identifiable unit of external information that can be acquired and reused by the
agent. For each completed trajectory
\tau^{(n)}
, let
\mathcal{E}^{(n)}\subseteq\mathcal{E}

denote the set of atomic evidence units acquired at least once along the
trajectory, and define the acquisition indicator

I_{e}^{(n)}\;=\;\mathbb{I}\!\left[e\in\mathcal{E}^{(n)}\right]\in\{0,1\}.

(7)

Each trajectory is associated with a binary outcome
R^{(n)}\in\{0,1\}

indicating task success.

We estimate the empirical success probability conditioned on acquiring
e
as

\widehat{P}(R=1\mid I_{e}=1)\;=\;\frac{\sum_{n=1}^{N}I_{e}^{(n)}R^{(n)}}{\sum_{n=1}^{N}I_{e}^{(n)}},

(8)

and similarly, the success probability conditioned on not acquiring
e
as

\widehat{P}(R=1\mid I_{e}=0)\;=\;\frac{\sum_{n=1}^{N}\left(1-I_{e}^{(n)}\right)R^{(n)}}{\sum_{n=1}^{N}\left(1-I_{e}^{(n)}\right)}.

(9)

When the denominator of either estimator is zero, we fall back to the
batch-level success rate
\widehat{P}(R=1)\;=\;\frac{1}{N}\sum_{n=1}^{N}R^{(n)}
to ensure numerical stability.

The atomic-evidence counterfactual contribution of
e
is then defined as
the difference between these two conditional success probabilities:

\Delta_{e}\;=\;\widehat{P}(R=1\mid I_{e}=1)\;-\;\widehat{P}(R=1\mid I_{e}=0).

(10)

Turn-level Credit Aggregation

A single decision turn may introduce multiple atomic evidence units, either via
search results that provide brief summaries or via fetched documents that expose
detailed content. To obtain a unified learning signal at the turn level, ICA
aggregates atomic-evidence counterfactual contributions associated with the same
turn.

Let
\mathcal{E}_{t}^{(n)}\subseteq\mathcal{E}
denote the set of atomic
evidence units whose information is acquired at turn
t
in trajectory

\tau^{(n)}
. Each
e\in\mathcal{E}_{t}^{(n)}
is associated with an
atomic-evidence counterfactual contribution
\Delta_{e}
as defined in
Eq.
10
. The raw turn-level credit is computed as the average contribution over all
atomic units introduced at that turn:

r_{t}^{(n)}\;=\;\frac{1}{|\mathcal{E}_{t}^{(n)}|}\sum_{e\in\mathcal{E}_{t}^{(n)}}\Delta_{e}.

(11)

Although both search and fetch actions can introduce evidence that influences
the final answer, they differ in how this influence unfolds over time. Search
actions return brief snippets that are typically consumed immediately in
subsequent reasoning, whereas fetch actions materialize richer evidence units
whose content may be referenced and integrated over multiple later turns. To
reflect this difference, we apply temporal decay only to fetch turns.
Specifically, for fetch actions the aggregated credit is scaled as

\tilde{r}_{t}^{(n)}\;=\;r_{t}^{(n)}\cdot\Omega^{\,T_{n}-t-1},

(12)

where
T_{n}
denotes the total number of decision turns in trajectory

\tau^{(n)}
and
\Omega\in(0,1]
is a fixed decay factor. For search actions,
the aggregated credit
r_{t}^{(n)}
is used directly without temporal
attenuation.

This aggregation yields a single scalar credit for each decision turn, which is
subsequently used as a turn-level advantage signal for policy optimization.

Batch-level centering.

Since posterior success rates are estimated across trajectories, their scales may
vary across roll-outs, leading to batch-dependent bias in turn-level information
credits.
To reduce variance, ICA defines a unified normalized advantage
\hat{A}_{t}^{(n)}

for all turns, using different normalization statistics depending on the turn
type.

For an intermediate turn
t
in trajectory
\tau^{(n)}
that invokes tool
k
,

\hat{r}_{t}^{(n)}
is normalized using tool-wise statistics,

\hat{A}_{t}^{(n)}=\frac{r_{t}^{(n)}-\mu_{k}}{\sigma_{k}+\epsilon},

(13)

where
\mu_{k}=\mathbb{E}_{(n,t)\in\mathcal{T}_{k}}\!\left[r_{t}^{(n)}\right]
and
\sigma_{k}^{2}=\mathrm{Var}_{(n,t)\in\mathcal{T}_{k}}\!\left(r_{t}^{(n)}\right)
.
For the terminal turn
T_{n}
of trajectory
\tau^{(n)}
,
\hat{A}_{t}^{(n)}
is
defined using batch-wise normalization of the task outcome,

\hat{A}_{T_{n}}^{(n)}=\frac{R_{n}-\mu_{R}}{\sigma_{R}+\epsilon},

(14)

where
\mu_{R}=\mathbb{E}_{n}\!\left[R_{n}\right]
and
\sigma_{R}^{2}=\mathrm{Var}_{n}\!\left(R_{n}\right)
.

ICA-GRPO for Information-Seeking

Drawing inspiration from DAPO
(
42
)
for decoupled clipping and dynamic
sampling policy optimization, we propose a hybrid objective tailored to
information-seeking trajectories.
Given a question
q
, we sample a group of trajectories

\{\tau^{(n)}\}_{n=1}^{G}\sim\pi_{\theta_{\text{old}}}(\cdot\mid q)
.

To decouple global task success from local reasoning quality, we first compute the
task-level relative advantage
A_{n}
and the total decoupled advantage

\tilde{A}_{t}^{(n)}
:

\displaystyle A_{n}\;\triangleq\;\hat{A}_{T_{n}}^{(n)}

\displaystyle=\frac{R_{n}-\mu_{R}}{\sigma_{R}+\epsilon},

(15)

\displaystyle\tilde{A}_{t}^{(n)}

\displaystyle=A_{n}+\lambda\,\hat{A}_{t}^{(n)},

(16)

where
\lambda
is a hyperparameter that controls the relative contribution of
the local information-aware advantage
\hat{A}_{t}^{(n)}
to the overall learning signal.

Following DAPO’s strategy, the final objective is

\mathcal{J}(\theta)=\mathbb{E}_{n,t}\left[\frac{1}{\sum_{n}|\tau^{(n)}|}\sum_{n,t}\mathcal{L}_{\text{clip}}\!\left(r_{t}^{(n)}(\theta),\tilde{A}_{t}^{(n)}\right)\right]

(17)

where
|\tau^{(n)}|
denotes the total number of tokens in trajectory

\tau^{(n)}
, and the objective is normalized over all tokens across sampled
trajectories.
\mathcal{L}_{\text{clip}}
denotes the PPO surrogate loss with DAPO’s asymmetric
clipping bounds.

4.2
External Observations

Existing approaches commonly obtain web content in text-only form, either by summarizing webpages or retrieving a subset of passages via RAG-style pipelines
(
8
)
. Such representations introduce irreversible information loss at acquisition time, break cross-trajectory consistency for the same information source, and inject additional model bias through learned summarization or retrieval components, as illustrated in Figure
2
. These properties are fundamentally misaligned with ICA, which estimates the utility of external information units based on their aggregate contribution to successful outcomes across trajectories.

To address this issue, we model external observations as webpage snapshots rather than summarized or retrieved text. A snapshot preserves the full visible content of a webpage, including textual elements, layout structure, tables, and images, and is treated as a persistent external information unit in the agent’s memory, as illustrated in Figure
3
. Snapshots are returned directly by tool invocations and consumed by the agent without intermediate filtering or compression, allowing the agent to determine which information becomes relevant during downstream reasoning. This representation provides a stable and consistent basis for identifying recurring information units across trajectories, which is critical for estimating posterior success rates and applying repetition-aware discounting in ICA.

5.2
Data Curation

Supervised Finetuning Data.

To equip the model with basic web-interaction skills before reinforcement learning, we build a supervised fine-tuning dataset of tool-use trajectories for search and fetch, using information-seeking questions from ASearcher
(
5
)
across diverse domains and intents. For each question, we generate trajectories under two observation modalities: snapshot-based fetching, where pages are returned as webpage snapshots to preserve layout and structural cues, and text-based fetching, where relevant page content is extracted and reranked into concise textual observations. For the text setting, we apply a goal-guided reranking strategy to select the most relevant content, intentionally forming a strong text baseline and enabling a controlled comparison between text and snapshots under comparable information budgets. Overall, we construct about 12K supervised samples, aiming not to teach complex reasoning but to familiarize the model with the mechanics and semantics of web search and fetching for a stable RL initialization.

Reinforcement Learning Data.

We propose an automated framework for generating sophisticated evaluation tasks by integrating hierarchical knowledge extraction with adaptive web exploration. The methodology initiates with a recursive retrieval process on Wikipedia to harvest domain-specific entities and their semantic descriptions. To bypass the limitations of generic information, we implement a two-stage searching mechanism that utilizes adaptive query refinement to capture long-tail information complemented by a suitability-filtering sub-model within the Fetch tool to ensure data quality. These components are synthesized into a base query, which serves as the foundation for an autonomous, multi-turn exploration phase resulting in a comprehensive Complex Report. Finally, the framework leverages these reports to construct a dataset of 7.5k multi-layered complex problems.

6
Conclusion

This work targets long-horizon open-web information seeking, where learning is limited by sparse outcome rewards and noisy text-centric observations that lose layout semantics. We propose a visual-native pipeline that represents fetched pages as rendered snapshots, preserving structural and multimodal cues to support more reliable evidence grounding. Building on this, we introduce Information-Aware Credit Assignment (ICA), a post-hoc method that estimates the utility of each atomic evidence unit via posterior success association, then converts it into dense turn-level rewards for GRPO-style optimization. Experiments across multiple benchmarks show consistent gains from snapshot grounding and further improvements from ICA over standard policy optimization.

Impact Statement

This paper advances methods for training information-seeking agents by introducing Information-Aware Credit Assignment (ICA), which attributes outcome feedback to retrieved atomic evidence and propagates learning signals to the turns that introduced useful information. The primary intended impact is to improve the reliability and data-efficiency of agent learning in open-web settings, potentially benefiting applications such as question answering, research assistance, and domain-specific information discovery.

A.2
Tools Description

RAG tool

To robustly extract high-value evidence from noisy web corpora, we implement an intelligent retrieval and reranking module,
RAGTool
, built around a semantic reranking pipeline. The module performs content acquisition, text normalization/chunking, and relevance scoring in a unified workflow. For content acquisition, we employ a high-throughput crawler based on the httpx asynchronous framework, supporting up to
32 concurrent
requests to efficiently gather candidate pages. For access-restricted or unstable webpages (e.g., dynamic rendering, interstitials, or anti-bot behaviors), we incorporate the JINA API as a fallback mechanism to improve the robustness and coverage of raw text retrieval while maintaining a consistent downstream interface. Retrieved HTML is then cleaned and normalized (removing boilerplate and redundant markup) and segmented under a token-budget constraint to fit embedding/reranking context limitations. Concretely, the base chunk size is set to
256 tokens
, and a lightweight naive_merge strategy merges under-length segments with adjacent neighbors to reduce semantic fragmentation at chunk boundaries. For relevance estimation, we adopt
BAAI/bge-reranker-v2-m3
, which provides strong semantic matching and cross-lingual retrieval capabilities, to compute query–chunk relevance scores. Candidate chunks are ranked in descending order, and only the
Top-
K
high-confidence segments are retained (
K=10
). Finally, the concatenated evidence is dynamically truncated to a maximum context budget (default
2048 tokens
) so that limited downstream context is dominated by high-salience signals, thereby improving the effective signal-to-noise ratio for subsequent reasoning.

Snapshot tool

To mitigate resolution constraints and context loss when vision–language models process long webpages, we develop a visual perception component,
SnapshotTool
, that integrates high-fidelity rendering, adaptive slicing, and visual optimization within a single pipeline. The system is implemented with Playwright and maintains a
browser pool of 8 Chromium instances
, supporting up to
32 concurrent
rendering requests for scalable batch processing. During rendering, an auto-scrolling procedure is applied to trigger lazy-loaded elements and ensure comprehensive visual capture, while a lightweight denoising routine suppresses non-content overlays (e.g., cookie banners, modal dialogs, and popups) through targeted DOM manipulation and style injection to provide clean visual inputs. For long pages, we enforce a hard maximum rendering height of
20,000 pixels
, which covers the primary information region of most websites while bounding worst-case computation. Within this range, a sliding-window strategy produces a sequence of serialized screenshot slices with slice height
4,480 pixels
and vertical overlap
112 pixels
, reducing boundary truncation artifacts (e.g., text lines, figures, and tables split across slice edges) and preserving visual semantic continuity across slices. To reduce downstream VLM input overhead without sacrificing readability, each slice is uniformly downsampled by a
0.7
\times
factor using
LANCZOS
interpolation. When local rendering fails, the module falls back to the
Jina API
and applies the same slicing and compression logic, ensuring consistent output structure and comparable visual characteristics across rendering pathways.
