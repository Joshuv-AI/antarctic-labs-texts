On the Heine Binomial Operators
Ronald Orozco López

Abstract
In this paper, we introduce the Heine binomial operators H n ⁡ ( b ​ D q ) \mathop{\mbox{{H}}}\nolimits_{n}(bD_{q}) based on q q -differential operator D q D_{q} . The motivation for introducing the operators H n ⁡ ( b ​ D q ) \mathop{\mbox{{H}}}\nolimits_{n}(bD_{q}) is that their limit turns out to be the q q -exponential operator T ⁡ ( b ​ D q ) \mathrm{T}(bD_{q}) given by Chen. The Hahn polynomials Φ m ( q n ) ​ ( b , x | q ) \Phi_{m}^{(q^{n})}(b,x|q) can easily be represented by using the operators H n ⁡ ( b ​ D q ) \mathop{\mbox{{H}}}\nolimits_{n}(bD_{q}) . Here, we derive q q -exponential and ordinary generating function, Mehler’s formula, Rogers formula, and other identities for the polynomials Φ m ( q n ) ​ ( b , x | q ) \Phi_{m}^{(q^{n})}(b,x|q) .

Introduction

We begin with some notation and terminology for basic hypergeometric series
[
6
]

|q|<1

q

\displaystyle(a;q)_{n}

\displaystyle=\prod_{k=0}^{n-1}(1-q^{k}a),

\displaystyle(a;q)_{\infty}

\displaystyle=\lim_{n\rightarrow\infty}(a;q)_{n}=\prod_{k=0}^{\infty}(1-aq^{k}).

The multiple
q
-shifted factorial is defined by

(a_{1},a_{2},\ldots,a_{m};q)_{\infty}=(a_{1};q)_{\infty}(a_{2};q)_{\infty}\cdots(a_{m};q)_{\infty}.

The
q
-binomial coefficient is defined by

\genfrac{[}{]}{0.0pt}{}{n}{k}_{q}=\frac{(q;q)_{n}}{(q;q)_{k}(q;q)_{n-k}}.

The
{}_{r+1}\phi_{r}

{}_{r+1}\phi_{r}\left(\begin{array}[]{c}a_{1},a_{2},\ldots,a_{r+1}\\

In this paper, we will frequently use the
q
-binomial theorem:

{}_{1}\phi_{0}(a;q,z)=\frac{(az;q)_{\infty}}{(z;q)_{\infty}}=\sum_{n=0}^{\infty}\frac{(a;q)_{n}}{(q;q)_{n}}z^{n}.

(1)

The
q
-exponential
\mathrm{e}_{q}(z)

\mathrm{e}_{q}(z)=\sum_{n=0}^{\infty}\frac{z^{n}}{(q;q)_{n}}={}_{1}\phi_{0}\left(\begin{array}[]{c}0\\

\mathrm{E}_{q}(z)=\sum_{n=0}^{\infty}q^{\binom{n}{2}}\frac{z^{n}}{(q;q)_{n})}={}_{1}\phi_{1}\left(\begin{array}[]{c}0\\
0\end{array};q,-z\right)=(-z;q)_{\infty}.

The following easily verified identities will be frequently used in this paper:

\displaystyle(a;q)_{n}

\displaystyle=\frac{(a;q)_{\infty}}{(aq^{n};q)_{\infty}},

\displaystyle(a;q)_{n+k}

\displaystyle(a;q)_{n-k}

2
Heine binomial operators

The Heine binomial formula is

\frac{1}{(x;q)_{n}}=\sum_{k=0}^{\infty}\genfrac{[}{]}{0.0pt}{}{n+k-1}{k}_{q}x^{k}.

(6)

The function
q
-exponential
\mathrm{e}_{q}(x)
is the limit of the Heine binomial formula,

\mathrm{e}_{q}(x)=\sum_{n=0}^{\infty}\frac{x^{n}}{(q;q)_{n}}=\frac{1}{(x;q)_{\infty}}=\lim_{n\rightarrow\infty}\sum_{k=0}^{\infty}\genfrac{[}{]}{0.0pt}{}{n+k-1}{k}_{q}x^{k}.

Definition 1
.

We define the
n
-th Heine binomial operator based on
D_{q}
by

\mathop{\mbox{{H}}}\nolimits_{n}(bD_{q})=\sum_{k=0}^{\infty}\genfrac{[}{]}{0.0pt}{}{n+k-1}{k}_{q}(bD_{q})^{k}

(7)

\mathop{\mbox{{H}}}\nolimits_{n}(bD_{q})
can be written as

\mathop{\mbox{{H}}}\nolimits_{n}(bD_{q})=\sum_{k=0}^{\infty}\frac{(q^{n};q)_{k}}{(q,q)_{k}}(bD_{q})^{k}.

(8)

Using the Heine formula,
\mathop{\mbox{{H}}}\nolimits_{n}(bD_{q})
can also written as
1/(bD_{q};q)_{n}
.
The
q
-exponential operator
\mathrm{T}(bD_{q})
is the limit of the Heine binomial operators
\mathop{\mbox{{H}}}\nolimits_{n}(bD_{q})
,

\mathrm{T}(bD_{q})=\lim_{n\rightarrow\infty}\mathop{\mbox{{H}}}\nolimits_{n}(bD_{q}).

Theorem 1
.

\displaystyle\mathop{\mbox{{H}}}\nolimits_{n}(bD_{q})\{x^{m}\}=\begin{cases}x^{m},&\text{ if }n=0;\\
\Phi_{m}^{(q^{n})}(b,x|q)=\sum_{k=0}^{m}\genfrac{[}{]}{0.0pt}{}{m}{k}_{q}(q^{n};q)_{k}b^{k}x^{m-k},&\text{ if }n\geq 1;\\
\mathrm{r}_{m}(b,x|q),&\text{ if }n=\infty.\end{cases}

Proof.

\mathop{\mbox{{H}}}\nolimits_{0}(bD_{q})=1
is the identity operator. Then
\mathop{\mbox{{H}}}\nolimits_{0}(bD_{q})\{x^{m}\}=x^{m}
. For
n\neq 1

\displaystyle\mathop{\mbox{{H}}}\nolimits_{n}(bD_{q})\{x^{m}\}

\displaystyle=\sum_{k=0}^{\infty}\frac{(q^{n};q)_{k}}{(q;q)_{k}}b^{k}D_{q}^{k}x^{m}

\displaystyle=\sum_{k=0}^{m}\frac{(q^{n};q)_{k}}{(q;q)_{k}}\frac{(q;q)_{m}}{(q;q)_{m-k}}b^{k}x^{m-k}

\displaystyle=\sum_{k=0}^{m}\genfrac{[}{]}{0.0pt}{}{m}{k}_{q}(q^{n};q)_{k}b^{k}x^{m-k}

\displaystyle=\Phi_{m}^{(q^{n})}(b,x|q).

Finally,

\lim_{n\rightarrow\infty}\mathop{\mbox{{H}}}\nolimits_{n}(bD_{q})\{x^{m}\}=\sum_{k=0}^{m}\genfrac{[}{]}{0.0pt}{}{m}{k}_{q}b^{k}x^{m-k}=\mathrm{r}_{m}(x,b|q).

The proof is completed.
∎
