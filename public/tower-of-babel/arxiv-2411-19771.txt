The modulating function method for state estimation and feedback of infinite-dimensional systems
Folke Friedrich, Johann Reger, Timo Reis

Abstract
. We investigate state estimation and feedback for infinite-dimensional linear systems, including systems governed by partial differential equations with boundary control and observation. We extend the modulating function approach to infinite-dimensional systems. The basic idea is to reconstruct selected components of the state by convolving the input and output with null controls and corresponding outputs of the adjoint system. We further develop a distributional solution framework for the adjoint system that allows us to treat unbounded feedback operators. In particular, this framework enables the realisation of feedback involving spatial point evaluations for partial differential equations.



Keywords.
modulating function, infinite-dimensional systems, partial differential equations, boundary control, state feedback, state reconstruction

Mathematics Subject Classification (2020).
93C25, 93B53, 93B07, 93B28

1.
Introduction

The modulating function approach reconstructs selected components of the state by convolving the input and output with suitably chosen precomputed functions. More precisely, for a linear system

\displaystyle\dot{x}(t)

\displaystyle=Ax(t)+Bu(t),

(1.1)

\displaystyle y(t)

\displaystyle=Cx(t)+Du(t),

A\in\mathbb{R}^{n\times n}
,
B\in\mathbb{R}^{n\times m}
,

C\in\mathbb{R}^{p\times n}
,
D\in\mathbb{R}^{p\times m}
, the approach consists of constructing, for given
T>0
and
\varphi_{0}\in\mathbb{R}^{n}
, functions
\mu:[0,T]\to\mathbb{R}^{m}
and
\eta:[0,T]\to\mathbb{R}^{p}
such that every trajectory of (
1.1
) satisfies

\forall\,t\geq T:\quad\varphi_{0}^{\top}x(t)=\int_{0}^{T}u(t-\tau)^{\top}\mu(\tau)-y(t-\tau)^{\top}\eta(\tau){\rm d}\tau.

(1.2)

Thus,
\varphi_{0}^{\top}x(t)
, which represents a component of
x(t)
in the direction determined by
\varphi_{0}
, can be reconstructed from the input and output on the moving horizon
[t-T,t]
by evaluating the integral in (
1.2
). A straightforward integration by parts shows that suitable functions
\mu
and
\eta
are obtained by solving the following null-control problem for the adjoint system

\displaystyle\dot{\varphi}(t)

\displaystyle=A^{\top}\varphi(t)+C^{\top}\eta(t),\qquad\varphi(0)=\varphi_{0},\;\;\;\varphi(T)=0,

(1.3)

\displaystyle\mu(t)

\displaystyle=B^{\top}\varphi(t)+D^{\top}\eta(t).

Then
\mu
and
\eta
satisfy the reconstruction identity (
1.2
). Classical systems theory implies that the control problem (
1.3
) is solvable if the system (
1.1
) is observable. Moreover, the solution of (
1.3
) can be computed offline, so that the online reconstruction requires only the evaluation of the convolution integrals.
This approach can be used for two purposes:

(a)

State estimation:
By choosing a linearly independent family
(\varphi_{01},\ldots,\varphi_{0n})
and determining corresponding null controls
\eta_{1},\ldots,\eta_{n}
and outputs
\mu_{1},\ldots,\mu_{n}
of the adjoint system, we can reconstruct the scalars
\varphi_{0i}^{\top}x(t)
for
i=1,\ldots,n
. These values then allow us to determine
x(t)
. If only
N\leq n
such null controls are used, we obtain the orthogonal projection, and hence the best approximation, of
x(t)
onto the
N
-dimensional subspace
\operatorname{span}(\varphi_{01},\ldots,\varphi_{0N})
. The reconstruction is particularly simple if the initial values of the adjoint null-control problems form an orthonormal family.

(b)

State feedback:
Here, the aim is to realise the state feedback
u(t)=Fx(t)
,
F\in\mathbb{R}^{m\times n}
, using only the measured input and output. To achieve this, we solve
m
null control problems for the adjoint system, where the initial values
\varphi_{01},\ldots,\varphi_{0m}\in\mathbb{R}^{n}
are the transposes of the row vectors of
F
. Then (
1.2
) shows that the moving-horizon integrals of the input and output of (
1.1
) yield

\left(\begin{smallmatrix}\varphi_{01}^{\top}x(t)\\[-3.41432pt]
\vdots\\
\varphi_{0m}^{\top}x(t)\end{smallmatrix}\right)=\left[\begin{smallmatrix}\varphi_{01}^{\top}\\[-3.41432pt]
\vdots\\
\varphi_{0m}^{\top}\end{smallmatrix}\right]x(t)=Fx(t).

Although the modulating-function approach is relatively straightforward for finite-dimensional systems, its extension to infinite-dimensional systems involves substantial difficulties, particularly in the presence of boundary control or observation. To cover a broad class of infinite-dimensional linear systems, we employ the system-node framework developed by
Staffans
in
[
22
]
and related publications. Such systems are described by

\left(\begin{smallmatrix}\dot{x}(t)\\
y(t)\end{smallmatrix}\right)=\left[\begin{smallmatrix}A\&B\\[-2.84526pt]
\\
C\&D\end{smallmatrix}\right]\left(\begin{smallmatrix}{x}(t)\\
u(t)\end{smallmatrix}\right),

(1.4)

where
A\&B:X\times U\supset\operatorname{dom}(A\&B)\to X
and
C\&D:X\times U\supset\operatorname{dom}(C\&D)\to Y
are linear operators whose precise properties are specified in the next section. The symbols
\&
indicate that the domains of these operators need not be Cartesian products of subspaces of
X
and
U
. Although the comprehensive theory of system nodes developed in
[
22
]
contains only a few examples involving partial differential equations, many such systems can be incorporated naturally into this framework, including systems on multidimensional spatial domains. Examples include systems governed by the wave equation, advection–diffusion equations, Maxwell’s equations, the Oseen equations, and the Euler–Bernoulli and Timoshenko beam equations
[
18
,
16
,
5
,
17
]
.

A further important advantage is that the class of system nodes is closed under adjunction, which allows us to formulate an infinite-dimensional counterpart of the null-control problem (
1.3
).

The objective of this article is to develop a modulating-function framework for infinite-dimensional linear systems described by system nodes, with particular emphasis on state estimation and the realisation of state feedback using only input and output data.
For state estimation, we show that, for
\varphi_{0}\in X
and suitable functions
\mu\in L^{2}([0,T];U)
and
\eta\in L^{2}([0,T];Y)
arising from a null-control problem for the adjoint system,

\forall\,t\geq T:\quad\langle x(t),\varphi_{0}\rangle_{X}=\int_{0}^{T}\langle u(t-\tau),\mu(\tau)\rangle_{U}-\langle y(t-\tau),\eta(\tau)\rangle_{Y}{\rm d}\tau.

(1.5)

Applying this identity simultaneously to initial values
\varphi_{01},\ldots,\varphi_{0k}
of the adjoint null-control problem yields the orthogonal projection of
x(t)
onto
\operatorname{span}(\varphi_{01},\ldots,\varphi_{0k})
.

The application to state feedback becomes more involved when the feedback operator is unbounded. More precisely, we consider feedback laws of the form
u=Fx
, where
F
maps an intermediate space
\mathcal{V}
between
\operatorname{dom}(A)
and
X
into the input space
U
. In this setting,
U
is assumed to be finite-dimensional. For
U=\mathbb{R}^{m}
, the feedback operator
F
can be represented by an
m
-tuple of elements of
\mathcal{V}^{\prime}
,
where
\mathcal{V}^{\prime}
denotes the dual of
\mathcal{V}
with respect to the pivot space
X
. The space
\mathcal{V}^{\prime}
may be regarded as an extension of the state space of the adjoint system. We therefore seek inputs
\eta_{i}
that drive the adjoint system, formally initialised at
\varphi(0)=F_{i}
, to zero in an appropriate sense. Such null controls need not exist within a classical function-space setting. This motivates the extension of the solution theory for system nodes to distributional inputs and trajectories. In this distributional setting, the reconstruction identity (
1.5
) requires a more general interpretation. More precisely, the action of
F_{i}
on
x(t)
is represented by convolutions of the distributions
\eta_{i}
and
\mu_{i}
with the input
u
and the output
y
, rather than by moving-horizon
L^{2}
-inner products. The treatment of unbounded feedback operators is particularly important because it allows feedback laws involving spatial point evaluations for systems governed by partial differential equations.

We do not assume that the system or its adjoint is well-posed. Although well-posedness considerably simplifies the analysis, it restricts the class of systems under consideration, and suitable well-posedness criteria are not available for all systems of practical interest. By allowing non-well-posed system nodes, our framework applies to a broader class of boundary-controlled partial differential equations. This generality, together with the treatment of unbounded feedback operators, requires a more extensive theoretical framework.

The remainder of this article is organised as follows. Section
2
introduces the notation, function spaces, and operator-theoretic framework used throughout the article. In Section
3
, we recall the basic theory of system nodes and develop a distributional solution framework. Section
4
considers the adjoint system and its systems-theoretic properties and contains our main result on distributional partial-state reconstruction. Section
5
applies this result to state estimation, while Section
6
addresses the implementation of state feedback. Section
7
presents two examples. The first concerns the construction of an exponentially stabilising feedback law for a vibrating string with boundary force control and an interior velocity measurement. The second considers state estimation for a reaction–diffusion equation on a two-dimensional spatial domain with Dirichlet boundary control and Neumann boundary observation.

We conclude this introduction with a brief overview of the literature on the modulating-function approach. The method originates from the work of
Shinbrot

[
21
]
. Its basic idea is to use
modulating functions
to transform linear and certain nonlinear ordinary differential equations into algebraic equations, thereby enabling the application of regression methods to the estimation of unknown system parameters. In the following decades, the modulating-function method was applied to parameter estimation for increasingly broad classes of systems. Of particular relevance to the present work are the early applications to systems governed by partial differential equations by
Perdreauville
and
Goodson

[
15
]
and, subsequently, by
Fairman
and
Shen

[
4
]
. Subsequent developments largely focused on finite-dimensional systems and, in particular, on the choice of suitable modulating functions. The modulating-function method was first applied to state estimation for finite-dimensional systems in
[
14
,
10
]
, where modulating functions with non-zero boundary values were employed. Since the original work of
Shinbrot
, modulating functions have typically been required only to satisfy suitable homogeneous boundary conditions and differentiability assumptions, leaving their precise shape as a degree of freedom.

In
[
6
]
,
Fischer
and
Deutscher
developed a modulating-function-based fault-detection framework for systems governed by partial differential equations. Their approach transforms the differential equation into an algebraic relation that gives rise to a
kernel equation
, whose solution determines the modulating function. This approach was subsequently used in
[
7
]
to construct a state estimator for parabolic partial differential equations. The resulting estimate is given in terms of the coefficients of a truncated series expansion of the distributed state. The approach was extended to coupled parabolic systems in
[
19
]
and to parabolic systems with certain nonlinear reaction terms in
[
8
]
. To the best of our knowledge, a systematic and unified modulating-function framework for infinite-dimensional systems that accommodates boundary control and unbounded feedback operators has not yet been developed.

2.
Notation, function spaces, and operator-theoretic preliminaries

The sets of positive and non-negative integers are denoted by
\mathbb{N}
and
\mathbb{N}_{0}
, respectively. Unless stated otherwise, all Hilbert spaces considered in this article are real. By complexification, the results can also be formulated for complex Hilbert spaces. The norm on
X
is denoted by
\|\cdot\|_{X}
, or simply by
\|\cdot\|
if the underlying space is clear from the context. The identity operator on
X
is denoted by
I_{X}
, or simply by
I
.

The topological dual of
X
is denoted by
X^{\prime}
, and the corresponding duality pairing by
\langle\cdot,\cdot\rangle_{X^{\prime},X}
. Using the reflexivity of
X
, we set

\langle x,x^{\prime}\rangle_{X,X^{\prime}}\coloneqq\langle x^{\prime},x\rangle_{X^{\prime},X}
for all
x\in X
and
x^{\prime}\in X^{\prime}
.

The space of bounded linear operators from
X
to
Y
is denoted by
L(X,Y)
, and we write
L(X)\coloneqq L(X,X)
. The domain
\operatorname{dom}A
of a possibly unbounded linear operator
A:X\supset\operatorname{dom}A\to Y
is endowed with the graph norm

\|x\|_{\operatorname{dom}A}\coloneqq\big(\|x\|_{X}^{2}+\|Ax\|_{Y}^{2}\big)^{1/2}.

For a densely defined linear operator
A:X\supset\operatorname{dom}A\to Y
, its dual operator
A^{\prime}:Y^{\prime}\supset\operatorname{dom}A^{\prime}\to X^{\prime}
is defined by

\operatorname{dom}A^{\prime}=\left\{y^{\prime}\in Y^{\prime}\left|\vphantom{y^{\prime}\in Y^{\prime}}\exists\,z^{\prime}\in X^{\prime}\text{ s.t.\ }\forall\,x\in\operatorname{dom}A:\;\langle Ax,y^{\prime}\rangle_{Y,Y^{\prime}}=\langle z^{\prime},x\rangle_{X^{\prime},X}\right.\right\}.

For each
y^{\prime}\in\operatorname{dom}A^{\prime}
, the element
z^{\prime}\in X^{\prime}
in the above definition is uniquely determined, and we set
A^{\prime}y^{\prime}\coloneqq z^{\prime}
. If
X
and
Y
are identified with their dual spaces, the dual operator is called the
adjoint of
A
and is denoted by
A^{*}:Y\supset\operatorname{dom}A^{*}\to X
.

For Lebesgue and Sobolev spaces, we follow the notation of
Adams

[
1
]
. For spaces of functions taking values in a Hilbert space
X
, the target space is indicated after a semicolon. For example, the space of
p
-integrable
X
-valued functions on
\Omega
is denoted by
L^{p}(\Omega;X)
.

For
T>0
and
k\in\mathbb{N}
, we define

\displaystyle H^{k}_{0l}([0,T];X)

\displaystyle\coloneqq\left\{v\in H^{k}([0,T];X)\left|\vphantom{v\in H^{k}([0,T];X)}v(0)=\cdots=\tfrac{\mathrm{d}^{k-1}}{\mathrm{d}t^{k-1}}v(0)=0\right.\right\},

(2.1)

\displaystyle H^{k}_{0r}([0,T];X)

\displaystyle\coloneqq\left\{v\in H^{k}([0,T];X)\left|\vphantom{v\in H^{k}([0,T];X)}v(T)=\cdots=\tfrac{\mathrm{d}^{k-1}}{\mathrm{d}t^{k-1}}v(T)=0\right.\right\}.

(2.2)

These spaces will be used throughout the article. Both are closed subspaces of
H^{k}([0,T];X)
and hence Hilbert spaces with respect to the norm inherited from
H^{k}([0,T];X)
.

Using
L^{2}([0,T];X)
as the pivot space, we define the corresponding negative-order spaces by

H^{-k}_{0l}([0,T];X)\coloneqq H^{k}_{0r}([0,T];X)^{\prime},\qquad H^{-k}_{0r}([0,T];X)\coloneqq H^{k}_{0l}([0,T];X)^{\prime}.

(2.3)

For
k=0
, we set

H^{0}_{0l}([0,T];X)\coloneqq L^{2}([0,T];X)=:H^{0}_{0r}([0,T];X).

The Dirac distribution
\delta\in H^{-1}_{0l}([0,T])
is defined by

\langle\delta,w\rangle_{H^{-1}_{0l}([0,T]),H^{1}_{0r}([0,T])}=w(0)\qquad\forall\,w\in H^{1}_{0r}([0,T]).

For
k\geq 0
, the
left derivative

\big(\tfrac{\mathrm{d}}{\mathrm{d}t}\big)_{l}:H^{-k}_{0l}([0,T];X)\to H^{-k-1}_{0l}([0,T];X)

is defined as the negative dual of the right derivative, that is,

\displaystyle\begin{split}\left\langle\big(\tfrac{\mathrm{d}}{\mathrm{d}t}\big)_{l}v,w\right\rangle_{H^{-k-1}_{0l}([0,T];X),H^{k+1}_{0r}([0,T];X)}&\coloneqq-\left\langle v,\tfrac{\mathrm{d}}{\mathrm{d}t}w\right\rangle_{H^{-k}_{0l}([0,T];X),H^{k}_{0r}([0,T];X)}\\
&\hskip-56.9055pt\forall\,v\in H^{-k}_{0l}([0,T];X),\,w\in H^{k+1}_{0r}([0,T];X).\end{split}

(2.4)

For
v\in H^{k}_{0l}([0,T];X)
,
k\in\mathbb{N}
, the left derivative agrees with the conventional weak derivative. Consequently, for every
k\in\mathbb{Z}
,

\big(\tfrac{\mathrm{d}}{\mathrm{d}t}\big)_{l}
is a bounded bijective operator from

H^{k}_{0l}([0,T];X)
onto
H^{k-1}_{0l}([0,T];X)
.
The
right derivative

\big(\tfrac{\mathrm{d}}{\mathrm{d}t}\big)_{r}:H^{k}_{0r}([0,T];X)\to H^{k-1}_{0r}([0,T];X),\qquad k\in\mathbb{Z},

is defined analogously.

For
\tau\in[0,T]
, the
\tau
-right shift operator

S_{r,\tau}\in L(L^{2}([0,T];X))
maps
v\in L^{2}([0,T];X)
to the function
S_{r,\tau}v
defined by

(S_{r,\tau}v)(t)=\begin{cases}0,&t\in[0,\tau),\\
v(t-\tau),&t\in[\tau,T],\end{cases}

for almost every
t\in[0,T]
. Its restriction defines a bounded operator on
H^{k}_{0l}([0,T];X)
. Analogously, the
\tau
-left shift operator

S_{l,\tau}
defines a bounded operator on
H^{k}_{0r}([0,T];X)
. For
k\geq 0
, the
\tau
-right shift on
H^{-k}_{0l}([0,T];X)
is defined as the dual of the
\tau
-left shift on
H^{k}_{0r}([0,T];X)
. With this definition, the right shift on
L^{2}([0,T];X)
extends to the spaces
H^{-k}_{0l}([0,T];X)
.

Let
A\in L(X,Y)
and
k\in\mathbb{N}
. For
w\in H^{k}_{0l}([0,T];X)
, the pointwise application

Aw\coloneqq\big(t\mapsto Aw(t)\big)
belongs to
H^{k}_{0l}([0,T];Y)
. Likewise,
Aw\in H^{k}_{0r}([0,T];Y)
whenever
w\in H^{k}_{0r}([0,T];X)
. The pointwise application of
A
to an element
v\in H^{-k}_{0l}([0,T];X)
is defined by

\langle Av,w\rangle_{H^{-k}_{0l}([0,T];Y),H^{k}_{0r}([0,T];Y)}\coloneqq\langle v,A^{*}w\rangle_{H^{-k}_{0l}([0,T];X),H^{k}_{0r}([0,T];X)}\\
\forall\,v\in H^{-k}_{0l}([0,T];X),\,w\in H^{k}_{0r}([0,T];Y).

(2.5)

The pointwise application of
A
to elements of
H^{-k}_{0r}([0,T];X)
is defined analogously. With these definitions, the pointwise application of
A
commutes with both the left and the right derivative, that is,

\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}A=A\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l},\qquad\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{r}A=A\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{r}.

We next introduce function spaces on the infinite time horizon. The elements of the spaces defined above can be canonically identified with distributions in the sense of
Schwartz
. More precisely, an element of
H^{-k}_{0l}([0,T];X)
,
k\in\mathbb{N}
, defines a distribution on
(-\infty,T)
supported in
[0,T)
by

\langle v,\psi\rangle\coloneqq\langle v,\psi|_{[0,T]}\rangle_{H^{-k}_{0l}([0,T];X),H^{k}_{0r}([0,T];X)},\qquad\psi\in C^{\infty}_{0}((-\infty,T);X).

The elements of
H^{-k}_{0r}([0,T];X)
are identified analogously with distributions on
(0,\infty)
supported in
(0,T]
. Elements of non-negative order are regarded as regular distributions.

Accordingly, the support of an element of any of these spaces is understood as its distributional support in the sense of
Schwartz
; see
[
20
, Def. 6.22]
. Equivalently, for
v\in H^{-k}_{0l}([0,T];X)
, a relatively open set
J\subset[0,T)
is disjoint from
\supp v
if and only if

\langle v,w\rangle_{H^{-k}_{0l}([0,T];X),H^{k}_{0r}([0,T];X)}=0

for every
w\in H^{k}_{0r}([0,T];X)
with
\supp w\subset J
. The analogous characterisation applies to elements of
H^{-k}_{0r}([0,T];X)
.

For
k\in\mathbb{N}_{0}
, the space
H^{k}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};X)
consists of all
v\in L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0};X)
such that, for every
T>0
, the restriction of
v
to
[0,T]
belongs to
H^{k}_{0l}([0,T];X)
. We equip this space with the locally convex topology generated by the seminorms given by the
H^{k}_{0l}([0,T];X)
-norms of these restrictions; see
[
20
, Chap. 1]
.

To define
H^{-k}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};X)
for
k>0
, let
0<T_{1}<T_{2}
. Extension by zero on
[T_{1},T_{2}]
defines a continuous embedding of
H_{0r}^{k}([0,T_{1}];X)
into
H_{0r}^{k}([0,T_{2}];X)
. Its dual defines the restriction operator from
H_{0l}^{-k}([0,T_{2}];X)
to
H_{0l}^{-k}([0,T_{1}];X)
. An element
v\in H_{0,\mathrm{loc}}^{-k}(\mathbb{R}_{\geq 0};X)
is a family
(v_{T})_{T>0}
with
v_{T}\in H^{-k}_{0l}([0,T];X)
such that, whenever
0<T_{1}<T_{2}
, the restriction of
v_{T_{2}}
to
[0,T_{1}]
equals
v_{T_{1}}
. We equip this space with the locally convex topology generated by the seminorms

v\mapsto\|v_{T}\|_{H^{-k}_{0l}([0,T];X)},\qquad T>0.

The support of
v=(v_{T})_{T>0}
is defined by

\supp v\coloneqq\bigcup_{T>0}\big(\supp v_{T}\cap[0,T)\big).

With these definitions,
H_{0,\mathrm{loc}}^{0}(\mathbb{R}_{\geq 0};X)
is identified with
L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0};X)
.

The left derivative
\left(\frac{{\rm d}}{{\rm d}t}\right)_{l}
extends naturally to
H_{0,\mathrm{loc}}^{k}(\mathbb{R}_{\geq 0};X)
for every
k\in\mathbb{Z}
. It defines a continuous bijection from
H_{0,\mathrm{loc}}^{k}(\mathbb{R}_{\geq 0};X)
onto
H_{0,\mathrm{loc}}^{k-1}(\mathbb{R}_{\geq 0};X)
with continuous inverse. Similarly, the
\tau
-right shift defines a continuous operator on
H_{0,\mathrm{loc}}^{k}(\mathbb{R}_{\geq 0};X)
for every
k\in\mathbb{Z}
, as follows from its boundedness on finite time intervals.

We conclude these preliminaries by introducing convolution. For
v,w\in L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0};X)
, we define their convolution
v\ast w\in L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0})
by

(v\ast w)(t)=\int_{0}^{t}\langle v(\tau),w(t-\tau)\rangle_{X}\,{\rm d}\tau.

The convolution
v\ast w
is continuous. Moreover, convolution is bilinear and commutative and defines a continuous mapping from

L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0};X)\times L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0};X)

to
L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0})
. Its restriction to
[0,T]
depends only on the restrictions of
v
and
w
to
[0,T]
.

If
v\in H^{1}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};X)
and
w\in L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0};X)
, then

v\ast w\in H^{1}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0})
and

\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}(v\ast w)=\left(\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}v\right)\ast w.

Since the left derivative is a linear homeomorphism from
H^{k}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};X)
onto
H^{k-1}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};X)
for every
k\in\mathbb{Z}
, convolution extends uniquely to a continuous bilinear mapping

\ast:H^{k_{1}}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};X)\times H^{k_{2}}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};X)\to H^{k_{1}+k_{2}}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0})

defined by

\displaystyle\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}^{k_{1}+k_{2}}(v\ast w)

\displaystyle=\left(\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}^{k_{1}}v\right)\ast\left(\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}^{k_{2}}w\right)

(2.6)

for all
k_{1},k_{2}\in\mathbb{Z}
,
v\in H^{k_{1}}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};X)
, and
w\in H^{k_{2}}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};X)
. Here, negative powers of the left derivative denote powers of its continuous inverse.
The convolution
\varphi\ast v\in H^{k_{1}+k_{2}}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};X)
of a scalar element
\varphi\in H^{k_{1}}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0})
and an
X
-valued element
v\in H^{k_{2}}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};X)
is defined analogously.

3.
System nodes and trajectories

Let
X
,
U
, and
Y
be Hilbert spaces, and let

A\&B:\operatorname{dom}(A\&B)\subset X\times U\to X
and

C\&D:\operatorname{dom}(C\&D)\subset X\times U\to Y

be linear operators. In this section, we recall the basic concepts required for systems of the form (
1.4
).
In contrast to the finite-dimensional case, the operators
A\&B
and
C\&D
need not decompose into separate components associated with the state and the input. This feature is essential for the treatment of boundary control systems governed by partial differential equations.
The autonomous dynamics, corresponding to the trivial input

,
where
\operatorname{dom}(A)\coloneqq\left\{x\in X\left|\vphantom{x\in X}\left(\begin{smallmatrix}x\\

0\end{smallmatrix}\right)
for all

Definition 3.1

(System node)
.

A

on the triple
(X,U,Y)
of Hilbert spaces is a linear operator

C\&D\end{smallmatrix}\right]

(a)

A\&B
is closed.

(b)

C\&D\in L(\operatorname{dom}(A\&B),Y)
.

(c)

For every

x\in X
such that
\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)\in\operatorname{dom}(S)
.

(d)

The main operator

generates a strongly continuous semigroup

\mathfrak{A}(\cdot)\colon\mathbb{R}_{\geq 0}\to L(X)
on

.

These properties imply that

is closed and that
\operatorname{dom}(S)=\operatorname{dom}(A\&B)
.

We next introduce classical and generalised trajectories of (

The space

is equipped with the locally convex topology generated by the seminorms given by the maximum norm on intervals

Definition 3.2

(Classical/generalised trajectories)

Let

Any operator

(x,u)
of

\displaystyle\dot{x}=A\&B\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right).

(3.1)

We next recall a solvability result from

Proposition 3.3

Remark 3.5

(c)

Consider the autonomous case

If

(

To define the output for less regular initial states, fix

, let

Thus, the

\displaystyle\to\mathcal{Y}_{k},

(3.4)

\displaystyle x_{0}

\displaystyle\mapsto C\mathfrak{A}(\cdot)x_{0},

is well defined and continuous.

Remark

motivates the introduction of the continuous

\displaystyle\to L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0};X_{-1}),

\displaystyle u

Remark

u\end{smallmatrix}\right)

In this notation, well-posedness is equivalent to the following three

takes values in

, the map

takes values in

By shift invariance,

\forall\,u\in C_{0}^{\infty}(\mathbb{R}_{>0};U):\quad\mathfrak{S}\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}u=\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}\mathfrak{S}u.

For

\mathfrak{S}_{-m}u\coloneqq\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}^{m}\mathfrak{S}\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}^{-m}u

Thus, for every

\displaystyle\mathfrak{S}_{k}:\quad H^{k}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};U)

\displaystyle\to H^{k}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};X_{-1}),

where
\mathfrak{S}_{0}=\mathfrak{S}
.

Applying the same extension procedure to the continuous mapping

\left[\begin{smallmatrix}\mathfrak{S}_{k}\\
I\end{smallmatrix}\right]:H^{k}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};U)\to H^{k-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};\operatorname{dom}(A\&B))\quad\text{is continuous}.

(3.8)

The distributional input-to-state map commutes with scalar convolution.

Lemma 3.6
.

Let

be a system node on
(X,U,Y)
, let

, and let

Proof.

For

and

, the assertion follows from
(

and

in the corresponding spaces

4.
Duality and the modulating function

In this section, we develop the modulating-function framework for system nodes. We first introduce the adjoint system node and then formulate a distributional null-control problem that forms the basis of our reconstruction result.

Let
S=\left[\begin{smallmatrix}A\&B\\
C\&D\end{smallmatrix}\right]
be a system node on
(X,U,Y)
. Its
adjoint system node

S^{*}=\left(\left[\begin{smallmatrix}A\&B\\
C\&D\end{smallmatrix}\right]\right)^{*}

is again a system node by
[
22
, Lem. 6.2.14]
. We write

S^{*}=\left[\begin{smallmatrix}A^{d}\&B^{d}\\
C^{d}\&D^{d}\end{smallmatrix}\right]

(4.1)

and consider the corresponding
adjoint system

\left(\begin{smallmatrix}\dot{\varphi}(t)\\
\mu(t)\end{smallmatrix}\right)=\left[\begin{smallmatrix}A^{d}\&B^{d}\\
C^{d}\&D^{d}\end{smallmatrix}\right]\left(\begin{smallmatrix}\varphi(t)\\
\eta(t)\end{smallmatrix}\right).

(4.2)

Moreover,
[
22
, Lem. 6.2.14]
shows that the main operator of
S^{*}
is the adjoint of the main operator of
S
, that is,
A^{d}=A^{*}
.

We now formulate the main idea underlying the modulating-function approach. Our framework extends the classical theory in two respects: it applies to infinite-dimensional systems represented by system nodes, and it allows for distributional null controls.

Let
K\&L\in L(\operatorname{dom}(A\&B),\mathbb{R})=\operatorname{dom}(A\&B)^{\prime}
. For a system (
1.4
), we aim to reconstruct the additional output

z(t)=K\&L\left(\begin{smallmatrix}x(t)\\
u(t)\end{smallmatrix}\right)

(4.3)

from the past input
u
and output
y
. It follows directly from the definition of a system node that

S_{\rm ext}=\left[\begin{smallmatrix}A\&B\\
C\&D\\
K\&L\end{smallmatrix}\right]

(4.4)

is a system node on
(X,U,Y\times\mathbb{R})
.

Writing the adjoint of
S_{\rm ext}
as

S_{\rm ext}^{*}=\left[\begin{smallmatrix}A^{d}\&[B^{d}\,G]\\
C^{d}\&[D^{d}\,H]\end{smallmatrix}\right],

(4.5)

we consider a distributional input
\eta
such that

\left(\begin{smallmatrix}\dot{\varphi}\\
\mu\end{smallmatrix}\right)=\left[\begin{smallmatrix}A^{d}\&[B^{d}\,G]\\
C^{d}\&[D^{d}\,H]\end{smallmatrix}\right]\left(\begin{smallmatrix}\varphi\\
\eta\\
\delta\end{smallmatrix}\right),

(4.6)

where
\delta\in H^{-1}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0})
denotes the Dirac distribution at zero. We require
\varphi
,
\eta
, and
\mu
to vanish on
[T,\infty)
for some
T>0
.

More precisely, let
k\in\mathbb{N}_{0}
, let

\eta\in H^{-k}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};Y)
, and set

r\coloneqq\max\{k,1\}
.
Then

\left(\begin{smallmatrix}\eta\\
\delta\end{smallmatrix}\right)\in H^{-r}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};Y\times\mathbb{R}).

Let
\mathfrak{S}^{d}_{-r,{\rm ext}}
denote the distributional
input-to-state map associated with the system node
S_{\rm ext}^{*}
.
We require that there exist

\varphi\in H^{-k}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};X),\qquad\mu\in H^{-k-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};U),

such that

\left(\begin{smallmatrix}\varphi\\
\mu\end{smallmatrix}\right)=\left[\begin{smallmatrix}I\hskip 16.38895pt0\hskip 8.19447pt\\
C^{d}\&[D^{d}\,H]\end{smallmatrix}\right]\left[\begin{smallmatrix}\mathfrak{S}^{d}_{-r,{\rm ext}}\\
I\end{smallmatrix}\right]\left(\begin{smallmatrix}\eta\\
\delta\end{smallmatrix}\right),

(4.7)

and

\supp\varphi\subset[0,T],\qquad\supp\eta\subset[0,T],\qquad\supp\mu\subset[0,T].

(4.8)

An input
\eta
satisfying (
4.7
) and
(
4.8
) is called a
generalised null control in
time
T
.

This terminology is consistent with the classical notion of null control. If
\varphi
,
\eta
, and
\mu
are functions rather than genuine distributions, then (
4.8
) means that the state
\varphi
is driven to zero by time
T
.

A particularly important special case arises when the additional scalar output depends only on the state. Suppose that there exists some
\varphi_{0}\in X
such that

K\&L\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)=\langle x,\varphi_{0}\rangle_{X}\qquad\forall\,\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)\in\operatorname{dom}(A\&B).

Then
\operatorname{dom}(S_{\rm ext}^{*})=\operatorname{dom}(S^{*})\times\mathbb{R}

and

S_{\rm ext}^{*}\left(\begin{smallmatrix}\varphi\\
\eta\\
\lambda\end{smallmatrix}\right)=\left[\begin{smallmatrix}A^{d}\&B^{d}\\
C^{d}\&D^{d}\end{smallmatrix}\right]\left(\begin{smallmatrix}\varphi\\
\eta\end{smallmatrix}\right)+\left(\begin{smallmatrix}\lambda\varphi_{0}\\
0\end{smallmatrix}\right)

for all
\left(\begin{smallmatrix}\varphi\\
\eta\end{smallmatrix}\right)\in\operatorname{dom}(S^{*})
and
\lambda\in\mathbb{R}
. In this case, (
4.6
) describes the adjoint system with the initial state
\varphi_{0}
, which is driven to zero in time
T
.

In the distributional setting, the moving-horizon integral in (
1.5
) is replaced by the convolution expression
u\ast\mu-y\ast\eta
.
We say that this convolution coincides with the additional output

z=K\&L\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)
after time
T
if

\supp\big(u\ast\mu-y\ast\eta-z\big)\subset[0,T].

(4.9)

Thus, the two distributions agree on
(T,\infty)
.

We are now in a position to state the main result of this section. It shows that a generalised null control of the extended adjoint system yields a modulating distribution that reconstructs the additional output
z
. This distributional formulation substantially broadens the scope of the method and is particularly relevant for the realisation of unbounded state feedback considered in Section
6
.

Theorem 4.1
.

Let
S=\left[\begin{smallmatrix}A\&B\\[-5.69054pt]
\\

and let

be a generalised trajectory of (

be defined as in (

and that (

) and (

) hold.
Then, for

z=K\&L\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)\in H^{-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0})\subset H^{-k-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0}),

the identity (
4.9
) holds.

Proof.

We first prove the assertion under the additional assumption that

is a classical trajectory of (

Let
(\alpha_{n})
be a mollifier sequence in

Define

\eta_{n}\coloneqq\alpha_{n}\ast\eta
,

.
Since
\alpha_{n}\ast\delta=\alpha_{n}
, Lemma

,
(

), and (

), applied to the

\left(\begin{smallmatrix}\varphi_{n}\\
\eta_{n}\\
\alpha_{n}\end{smallmatrix}\right)=\alpha_{n}\ast\left(\begin{smallmatrix}\varphi\\
\eta\\
\delta\end{smallmatrix}\right)\in C^{\infty}(\mathbb{R}_{\geq 0};\operatorname{dom}(S_{\rm ext}^{*})).

In particular, the adjoint system equation holds pointwise:

\forall\,t\geq 0:\quad\left(\begin{smallmatrix}\dot{\varphi}_{n}(t)\\
\mu_{n}(t)\end{smallmatrix}\right)=S_{\rm ext}^{*}\left(\begin{smallmatrix}\varphi_{n}(t)\\
\eta_{n}(t)\\
\alpha_{n}(t)\end{smallmatrix}\right)=\left[\begin{smallmatrix}A^{d}\&[B^{d}\,G]\\
C^{d}\&[D^{d}\,H]\end{smallmatrix}\right]\left(\begin{smallmatrix}\varphi_{n}(t)\\
\eta_{n}(t)\\
\alpha_{n}(t)\end{smallmatrix}\right).

Moreover,
\varphi_{n}
vanishes in a neighbourhood of zero and hence

\varphi_{n}(0)=0
.

Using the support property of convolution, together with
(
4.8
) and

\supp\alpha_{n}\subset(0,1/n]
, gives

\supp\varphi_{n}\subset[0,T+1/n],\qquad\supp\eta_{n}\subset[0,T+1/n],\qquad\supp\mu_{n}\subset[0,T+1/n].

(4.10)

For
t\geq 0
and
\tau\in[0,t]
, the product rule yields

\displaystyle\phantom{=}\tfrac{\mathrm{d}}{\mathrm{d}\tau}\langle x(t-\tau),\varphi_{n}(\tau)\rangle_{X}

\displaystyle=\langle x(t-\tau),\dot{\varphi}_{n}(\tau)\rangle_{X}-\langle\dot{x}(t-\tau),\varphi_{n}(\tau)\rangle_{X}

\displaystyle=\left\langle x(t-\tau),A^{d}\&[B^{d}\,G]\left(\begin{smallmatrix}\varphi_{n}(\tau)\\
\eta_{n}(\tau)\\
\alpha_{n}(\tau)\end{smallmatrix}\right)\right\rangle_{X}-\left\langle A\&B\left(\begin{smallmatrix}x(t-\tau)\\
u(t-\tau)\end{smallmatrix}\right),\varphi_{n}(\tau)\right\rangle_{X}

\displaystyle=\underbrace{\left\langle\left(\begin{smallmatrix}x(t-\tau)\\
u(t-\tau)\end{smallmatrix}\right),S_{\rm ext}^{*}\left(\begin{smallmatrix}\varphi_{n}(\tau)\\
\eta_{n}(\tau)\\
\alpha_{n}(\tau)\end{smallmatrix}\right)\right\rangle_{X\times U}-\left\langle S_{\rm ext}\left(\begin{smallmatrix}x(t-\tau)\\
u(t-\tau)\end{smallmatrix}\right),\left(\begin{smallmatrix}\varphi_{n}(\tau)\\
\eta_{n}(\tau)\\
\alpha_{n}(\tau)\end{smallmatrix}\right)\right\rangle_{X\times Y\times\mathbb{R}}}_{=0}

\displaystyle\qquad-\langle u(t-\tau),\mu_{n}(\tau)\rangle_{U}+\langle y(t-\tau),\eta_{n}(\tau)\rangle_{Y}+\alpha_{n}(\tau)z(t-\tau).

Integrating with respect to
\tau
over
[0,t]
and using

\varphi_{n}(0)=0
, we obtain

\forall\,t\geq 0:\quad\langle x(0),\varphi_{n}(t)\rangle_{X}=-(u\ast\mu_{n})(t)+(y\ast\eta_{n})(t)+(\alpha_{n}\ast z)(t).

Since (
4.10
) implies that

\varphi_{n}(t)=0
for all
t\geq T+1/n
, it follows that

\supp\left(u\ast\mu_{n}-y\ast\eta_{n}-\alpha_{n}\ast z\right)\subset[0,T+1/n]\qquad\forall\,n\in\mathbb{N}.

(4.11)

By
[
2
, Thm. 4.15]
, for every Hilbert space
E
and every

w\in L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0};E)
,

\alpha_{n}\ast w\longrightarrow w\quad\text{in }L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0};E).

This approximation property extends to all orders of the Sobolev scale.
Indeed, let
j\in\mathbb{Z}
and

w\in H^{j}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};E)
. By (
2.6
),

\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}^{j}(\alpha_{n}\ast w)=\alpha_{n}\ast\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}^{j}w.

Since

\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}^{j}w\in L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0};E)

and

\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}^{j}

is a homeomorphism from

H^{j}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};E)
onto the space

L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0};E)
, it follows that

\alpha_{n}\ast w\longrightarrow w\quad\text{in }H^{j}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};E).

(4.12)

In particular,

\mu_{n}\longrightarrow\mu\;\text{in }H^{-k-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};U),\quad\eta_{n}\longrightarrow\eta\;\text{in }H^{-k}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};Y),\quad\alpha_{n}\ast z\longrightarrow z\;\text{in }H^{-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0}).

By continuity of convolution,

u\ast\mu_{n}\longrightarrow u\ast\mu\;\text{in }H^{-k-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0})\quad\text{and}\quad y\ast\eta_{n}\longrightarrow y\ast\eta\;\text{in }H^{-k}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0}).

Using the continuous embeddings

H^{-k}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0})\subset H^{-k-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0}),\qquad H^{-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0})\subset H^{-k-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0}),

we conclude that

u\ast\mu_{n}-y\ast\eta_{n}-\alpha_{n}\ast z\longrightarrow u\ast\mu-y\ast\eta-z\;\text{in }H^{-k-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0}).

Let
\psi
be a test function with compact support in
(T,\infty)
.
For all sufficiently large
n
, its support is disjoint from

[0,T+1/n]
. Hence, by (
4.11
),

\left\langle u\ast\mu_{n}-y\ast\eta_{n}-\alpha_{n}\ast z,\psi\right\rangle=0.

Passing to the limit gives

\left\langle u\ast\mu-y\ast\eta-z,\psi\right\rangle=0.

Therefore,

\supp\big(u\ast\mu-y\ast\eta-z\big)\subset[0,T],

which proves the assertion for classical trajectories.

Now let
(x,u,y)
be a generalised trajectory of
(
1.4
). By Definition
3.2
, there exists a
sequence of classical trajectories
(x_{j},u_{j},y_{j})
such that

x_{j}\to x\quad\text{in }C(\mathbb{R}_{\geq 0};X),\qquad u_{j}\to u\quad\text{in }L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0};U),\qquad y_{j}\to y\quad\text{in }L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0};Y).

Set
z_{j}\coloneqq K\&L\left(\begin{smallmatrix}x_{j}\\
u_{j}\end{smallmatrix}\right)
.
We claim that

z_{j}\to z\coloneqq K\&L\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)
in
H^{-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0})
.
Indeed, let

g_{j}\coloneqq\int_{0}^{\cdot}(\cdot-\tau)\left(\begin{smallmatrix}x_{j}(\tau)-x(\tau)\\
u_{j}(\tau)-u(\tau)\end{smallmatrix}\right)\,{\rm d}\tau.

Then
g_{j}
converges to zero locally in
X\times U
. Moreover, the
distributional state equation gives

A\&B\,g_{j}(t)=\int_{0}^{t}\big(x_{j}(\tau)-x(\tau)\big)\,{\rm d}\tau-t\big(x_{j}(0)-x(0)\big).

Consequently,
g_{j}\to 0
in
L^{2}_{\mathrm{loc}}(\mathbb{R}_{\geq 0};\operatorname{dom}(A\&B))
.
Since
K\&L\in L(\operatorname{dom}(A\&B),\mathbb{R})
, it follows that

z_{j}-z=\big(\tfrac{{\rm d}}{{\rm d}t}\big)_{l}^{2}(K\&L\,g_{j})\longrightarrow 0\;\text{in }H^{-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0}).

By continuity of convolution,

u_{j}\ast\mu-y_{j}\ast\eta-z_{j}\longrightarrow u\ast\mu-y\ast\eta-z\;\text{in }H^{-k-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0}).

The result already proved for
classical trajectories gives

\supp\big(u_{j}\ast\mu-y_{j}\ast\eta-z_{j}\big)\subset[0,T]\qquad\forall\,j\in\mathbb{N}.

Testing against functions with compact support in
(T,\infty)
and
passing to the limit therefore yields

\supp\big(u\ast\mu-y\ast\eta-z\big)\subset[0,T].

This proves (
4.9
) for generalised trajectories.
∎

5.
State estimation

Throughout this section, let
S
be a system node on
(X,U,Y)
, where the Hilbert space
X
is separable. Let
D\subset X
be a dense subspace, and let
T>0
. We assume that every
\varphi_{0}\in D
is distributionally null-controllable in time
T
by the adjoint system (
4.2
), in the following sense.

Let
\mathfrak{C}^{d}_{0}:X\to H^{-1}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};U)
denote the state-to-output map introduced in (
3.4
). For
k\in\mathbb{N}_{0}
, let
\mathfrak{S}_{-k}^{d}
denote the distributional input-to-state map of the adjoint system (
4.2
). For
\varphi_{0}\in X
and

\eta\in H^{-k}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};Y)
, set

\varphi\coloneqq\mathfrak{A}^{*}(\cdot)\varphi_{0}+\mathfrak{S}_{-k}^{d}\eta

and let

\mu\coloneqq\mathfrak{C}^{d}_{0}\varphi_{0}+C^{d}\&D^{d}\left(\begin{smallmatrix}\mathfrak{S}_{-k}^{d}\eta\\
\eta\end{smallmatrix}\right)

be the corresponding distributional output. The input
\eta
is called
a
distributional null control for
\varphi_{0}\in X
in time
T

if

\supp\varphi\subset[0,T],\qquad\supp\eta\subset[0,T],\qquad\supp\mu\subset[0,T].

If
\varphi
is represented by a continuous function, as is the case
for the state of a generalised trajectory of
(
4.2
), the first condition means that the initial state

\varphi_{0}
is driven to zero by time
T
. The above definition extends
this notion to the distributional setting.

Moreover, for
\varphi_{0}\in X
and

K\&L\in\operatorname{dom}(A\&B)^{\prime}
satisfying

K\&L\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)=\langle x,\varphi_{0}\rangle_{X}\qquad\forall\,\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)\in\operatorname{dom}(A\&B),

the distributional null-control problem introduced above is equivalent to the generalised null-control problem (
4.7
), (
4.8
).

Since
D
is dense in the separable Hilbert space
X
, the Gram–Schmidt procedure yields an orthonormal basis

(\varphi_{0j})_{j\in\mathbb{N}}
of
X
with

\varphi_{0j}\in D
for every
j\in\mathbb{N}
. For each
j\in\mathbb{N}
, let

\eta_{j}\in H^{-k_{j}}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};Y),\qquad k_{j}\in\mathbb{N}_{0},

be a distributional null control for
\varphi_{0j}
in time
T
, and let

\mu_{j}\in H^{-k_{j}-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};U)

be the corresponding output.

Let
(x,u,y)
be a generalised trajectory of (
1.4
). By Theorem
4.1
, the distribution

z_{j}\coloneqq u\ast\mu_{j}-y\ast\eta_{j}

coincides on
(T,\infty)
with the continuous function

t\mapsto\langle x(t),\varphi_{0j}\rangle_{X}.

Consequently, the restriction of
z_{j}
to
(T,\infty)
is represented by a continuous function. If, in addition,
\eta_{j}
and
\mu_{j}
belong to
L^{2}
, then (
1.5
) gives

\forall\,t\geq T:\quad\langle x(t),\varphi_{0j}\rangle_{X}=\int_{0}^{T}\langle u(t-\tau),\mu_{j}(\tau)\rangle_{U}-\langle y(t-\tau),\eta_{j}(\tau)\rangle_{Y}\,{\rm d}\tau.

Thus, the Fourier coefficients

\langle x(t),\varphi_{0j}\rangle_{X}

of the state can be reconstructed from the input and output of
(
1.4
) using precomputed null controls of the adjoint system. For
N\in\mathbb{N}
, define

w_{N}\coloneqq\sum_{j=1}^{N}\big(u\ast\mu_{j}-y\ast\eta_{j}\big)\varphi_{0j}.

On
(T,\infty)
, this distribution is represented by the continuous
X
-valued function

t\mapsto\sum_{j=1}^{N}\langle x(t),\varphi_{0j}\rangle_{X}\varphi_{0j},

which is the orthogonal projection of
x(t)
onto

\operatorname{span}(\varphi_{01},\ldots,\varphi_{0N})
.
If the null controls and their corresponding outputs belong to
L^{2}
, this reconstruction is given explicitly by

w_{N}(t)=\sum_{j=1}^{N}\left(\int_{0}^{T}\langle u(t-\tau),\mu_{j}(\tau)\rangle_{U}-\langle y(t-\tau),\eta_{j}(\tau)\rangle_{Y}\,{\rm d}\tau\right)\varphi_{0j}.

(5.1)

We conclude this section with two remarks on the state-reconstruction procedure.

Remark 5.1
.

(a)

The null control
\eta_{j}
associated with
\varphi_{0j}
is generally not unique. If null controls exist in the classical function-space setting, one possible choice is an optimal control obtained by solving

\displaystyle\text{minimise}

\displaystyle\frac{1}{2}\int_{0}^{T}\left(\|\eta_{j}(t)\|_{Y}^{2}+\|\mu_{j}(t)\|_{U}^{2}\right)\,{\rm d}t

\displaystyle\text{subject to}

\displaystyle\left(\begin{smallmatrix}\dot{\varphi}_{j}(t)\\
\mu_{j}(t)\end{smallmatrix}\right)=\left[\begin{smallmatrix}A^{d}\&B^{d}\\
C^{d}\&D^{d}\end{smallmatrix}\right]\left(\begin{smallmatrix}\varphi_{j}(t)\\
\eta_{j}(t)\end{smallmatrix}\right),\qquad\varphi_{j}(0)=\varphi_{0j},\qquad\varphi_{j}(T)=0.

According to
[
17
, Sec. 5]
, the optimal control is characterised by the boundary-value problem

\displaystyle\left(\begin{smallmatrix}\dot{\varphi}_{j}(t)\\
\mu_{j}(t)\end{smallmatrix}\right)

\displaystyle=\left[\begin{smallmatrix}A^{d}\&B^{d}\\
C^{d}\&D^{d}\end{smallmatrix}\right]\left(\begin{smallmatrix}\varphi_{j}(t)\\
\eta_{j}(t)\end{smallmatrix}\right),\qquad\varphi_{j}(0)=\varphi_{0j},\qquad\varphi_{j}(T)=0,

\displaystyle\left(\begin{smallmatrix}\dot{x}_{j}(t)\\
\eta_{j}(t)\end{smallmatrix}\right)

\displaystyle=-\left[\begin{smallmatrix}A\&B\\[-2.84526pt]
\\
C\&D\end{smallmatrix}\right]\left(\begin{smallmatrix}x_{j}(t)\\
\mu_{j}(t)\end{smallmatrix}\right).

(b)

The existence of a dense subspace
D\subset X
consisting of states that are distributionally null-controllable in time
T
by the adjoint system (
4.2
) implies that the system (
1.4
) is
reconstructable in time
T
. More precisely, for every
t\geq T
, the input and output on
[0,t]
uniquely determine the state
x(t)
. This property is also referred to as
final-state observability
; see
[
11
]
.

The corresponding property of the adjoint system may be regarded as
approximate null-controllability in time
T
, since every state can be approximated by states that are null-controllable in time
T
. It generalises
exact null-controllability in time
T
, which requires every state to be null-controllable in time
T
.

For well-posed systems, exact null-controllability of the adjoint system is equivalent to
exact reconstructability of (
1.4
) in time
T
; see
[
22
, Sec. 9.4]
. Here, exact reconstructability in time
T
means that there exists some
M>0
such that every classical, and hence every generalised, trajectory of (
1.4
) with
u\equiv 0
satisfies

\|x(T)\|_{X}\leq M\|y\|_{L^{2}([0,T];Y)}.

The above observation establishes a duality between reconstructability of (
1.4
) and approximate null-controllability of the adjoint system (
4.2
), without requiring the system to be well posed.

6.
State feedback

We now apply Theorem
4.1
to the implementation of state feedback. To this end, we introduce a subspace of
X
consisting of those states that are compatible with some input in the domain of
A\&B
. More precisely, let

\mathcal{V}=\left\{x\in X\left|\vphantom{x\in X}\exists\,u\in U\text{ such that }\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)\in\operatorname{dom}(A\&B)\right.\right\}.

(6.1a)

Equipped with the norm

\|x\|_{\mathcal{V}}=\inf\left\{\left\|\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)\right\|_{\operatorname{dom}(A\&B)}\left|\vphantom{\left\|\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)\right\|_{\operatorname{dom}(A\&B)}}\,u\in U\text{ such that }\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)\in\operatorname{dom}(A\&B)\right.\right\},

(6.1b)

the space
\mathcal{V}
is a Hilbert space; see

[
22
, Lem. 4.3.12]
. Moreover, the embeddings

\operatorname{dom}(A)\subset\mathcal{V}\subset X

are continuous.

The feedback operators considered below need not be bounded on
X
. Instead, they are assumed to be bounded from
\mathcal{V}
to the input space
U
. Recall from Remark
3.4
(
b
) that
A\&B
extends to

[A_{-1}\ B]\in L(X\times U,X_{-1}),

where

A_{-1}:X_{-1}\supset\operatorname{dom}(A_{-1})=X\to X_{-1}

is the extension of
A
.

We first specify what is meant by an admissible state feedback for the control system (
3.1
).

Definition 6.1

(Admissible state feedback)
.

Let
X
and
U
be Hilbert spaces, and assume that

A\&B:\operatorname{dom}(A\&B)\subset X\times U\to X

satisfies conditions (
a
), (
c
), and
(
d
) of Definition
3.1
.
Let
\mathcal{V}
be defined as in (
6.1
), and let

[A_{-1}\ B]\in L(X\times U,X_{-1})

be the extension of
A\&B
introduced in
Remark
3.4
(
b
).
An operator
F\in L(\mathcal{V},U)
is called an

admissible state feedback
for

\dot{x}(t)=A\&B\left(\begin{smallmatrix}x(t)\\
u(t)\end{smallmatrix}\right)

if the operator

A_{F}:\operatorname{dom}(A_{F})\subset X\to X
defined by

\displaystyle\operatorname{dom}(A_{F})

\displaystyle=\left\{x\in\mathcal{V}\left|\vphantom{x\in\mathcal{V}}A_{-1}x+BFx\in X\right.\right\},

\displaystyle A_{F}x

\displaystyle=A_{-1}x+BFx

generates a strongly continuous semigroup on
X
.

For further details on state feedback for system nodes, we refer to

[
22
, Sec. 7.3]
.

To apply Theorem
4.1
, we assume from now on that the input space is finite-dimensional. This assumption is natural for systems with finitely many actuators. After identifying
U
with
\mathbb{R}^{m}
, an admissible feedback operator

F\in L(\mathcal{V},\mathbb{R}^{m})

can be represented by an
m
-tuple

(F_{1},\ldots,F_{m})\in(\mathcal{V}^{\prime})^{m},\qquad F_{i}=e_{i}^{\top}F,\quad i=1,\ldots,m,

where
e_{i}\in\mathbb{R}^{m}
denotes the
i
th canonical unit vector. Consequently,

Fx=\sum_{i=1}^{m}\langle x,F_{i}\rangle_{\mathcal{V},\mathcal{V}^{\prime}}\,e_{i},\qquad x\in\mathcal{V}.

(6.2)

Let
T>0
. For each
i=1,\ldots,m
, define

(K\&L)_{i}\in\operatorname{dom}(A\&B)^{\prime}
by

(K\&L)_{i}\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)=\langle x,F_{i}\rangle_{\mathcal{V},\mathcal{V}^{\prime}}\qquad\forall\,\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)\in\operatorname{dom}(A\&B).

Suppose that, for each
i=1,\ldots,m
, there exists a generalised null control

\eta_{i}\in H^{-k_{i}}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};Y),\qquad k_{i}\in\mathbb{N}_{0},

in time
T
for the extended adjoint system corresponding to

K\&L=(K\&L)_{i}
, and let

\mu_{i}\in H^{-k_{i}-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};U)

denote the corresponding output.

Let
(x,u,y)
be a generalised trajectory of (
1.4
). For

i=1,\ldots,m
, define the distributional additional output

z_{i}\coloneqq(K\&L)_{i}\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)\in H^{-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0}).

By Theorem
4.1
,

\supp\big(u\ast\mu_{i}-y\ast\eta_{i}-z_{i}\big)\subset[0,T],\qquad i=1,\ldots,m.

If
\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)
is represented by a function with values in

\operatorname{dom}(A\&B)
, then

z_{i}(t)=\langle x(t),F_{i}\rangle_{\mathcal{V},\mathcal{V}^{\prime}}

for almost every
t\geq 0
. In particular, this identity holds for
classical trajectories.
Accordingly, the distributional extension of the feedback output is

Fx:=\sum_{i=1}^{m}z_{i}e_{i}\in H^{-2}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0};U).

Combining the above reconstruction identities yields

Fx=\sum_{i=1}^{m}\big(u\ast\mu_{i}-y\ast\eta_{i}\big)e_{i}\qquad\text{on }(T,\infty).

Consequently, the state feedback
u=Fx
can be realised by imposing

u=\sum_{i=1}^{m}\big(u\ast\mu_{i}-y\ast\eta_{i}\big)e_{i}\qquad\text{on }(T,\infty).

For classical trajectories, this relation realises the state feedback

u(t)=Fx(t)
pointwise. For generalised trajectories, it is understood
in the distributional sense described above.

Stabilisation of a vibrating string

\displaystyle u(t)

\displaystyle=-w^{\prime}(t,0),\qquad 0=w(t,\ell),

\displaystyle\in\mathbb{R}_{\geq 0},

\displaystyle=\dot{w}(t,\xi_{0}),

\displaystyle t

\displaystyle\in\mathbb{R}_{\geq 0}.

(7.2a)

\displaystyle A\&B\left(\begin{smallmatrix}q\\

\displaystyle=\left(\begin{smallmatrix}p^{\prime}\\
q^{\prime}\end{smallmatrix}\right),\qquad C\&D\left(\begin{smallmatrix}q\\
p\\
u\end{smallmatrix}\right)=p(\xi_{0}).

The fact that this defines a system node on

(L^{2}([0,\ell];\mathbb{R}^{2}),\mathbb{R},\mathbb{R})
can be established using the techniques
developed in
[
16
, Sec. 4.2]
. The class considered there
differs only in that the output is a boundary value. Replacing this
boundary output by the interior point evaluation above does not affect
the system-node property.

To reconstruct the velocity at the left endpoint, we introduce the
additional output (
4.3
) determined by

K\&L\in\operatorname{dom}(A\&B)^{\prime}
with

K\&L\left(\begin{smallmatrix}q\\
p\\
u\end{smallmatrix}\right)=p(0).

(7.2b)

We next determine the adjoint of the extended system node

S_{\rm ext}=\left[\begin{smallmatrix}A\&B\\
C\&D\\
K\&L\end{smallmatrix}\right].

Let

\varphi_{q},\varphi_{p}\in L^{2}([0,\ell])
and

\eta,\alpha\in\mathbb{R}
. Then

\displaystyle\left\langle\left(\begin{smallmatrix}\varphi_{q}\\
\varphi_{p}\\

C\&D\\
K\&L\end{smallmatrix}\right]\left(\begin{smallmatrix}q\\

\displaystyle=\left\langle\left(\begin{smallmatrix}\varphi_{q}\\

q^{\prime}\\
p(\xi_{0})\\

\displaystyle=\int_{0}^{\ell}\varphi_{q}(\xi)p^{\prime}(\xi)+\varphi_{p}(\xi)q^{\prime}(\xi)\,{\rm d}\xi+\eta p(\xi_{0})+\alpha p(0).

Assume that

\left(\begin{smallmatrix}\varphi_{q}\\
\varphi_{p}\\
\eta\\
\alpha\end{smallmatrix}\right)\in\operatorname{dom}(S_{\rm ext}^{*}).

Choosing
p,q\in C_{0}^{\infty}([0,\ell])
with

\xi_{0}\notin\supp(p)
and using the definition of the weak derivative
gives

\varphi_{p}\in H^{1}([0,\ell]),\qquad\varphi_{q}|_{[0,\xi_{0}]}\in H^{1}([0,\xi_{0}]),\qquad\varphi_{q}|_{[\xi_{0},\ell]}\in H^{1}([\xi_{0},\ell]).

(7.4)

We denote the left and right limits of a function
f
at
\xi_{0}
by

f(\xi_{0}^{-})
and
f(\xi_{0}^{+})
, respectively. Moreover,

\varphi_{q}^{\prime}\in L^{2}([0,\ell])
denotes the function that coincides
with the weak derivative of
\varphi_{q}|_{[0,\xi_{0}]}
on

[0,\xi_{0}]
and with that of
\varphi_{q}|_{[\xi_{0},\ell]}
on

[\xi_{0},\ell]
.

Using
p(\ell)=0
and
q(0)=-u
, the right-hand side of
(
7.3
) becomes

\displaystyle-\int_{0}^{\xi_{0}}\varphi_{q}^{\prime}(\xi)p(\xi)\,{\rm d}\xi+\varphi_{q}p\Big|_{0}^{\xi_{0}^{-}}-\int_{\xi_{0}}^{\ell}\varphi_{q}^{\prime}(\xi)p(\xi)\,{\rm d}\xi+\varphi_{q}p\Big|_{\xi_{0}^{+}}^{\ell}

\displaystyle\qquad-\int_{0}^{\ell}\varphi_{p}^{\prime}(\xi)q(\xi)\,{\rm d}\xi+\varphi_{p}q\Big|_{0}^{\ell}+\eta p(\xi_{0})+\alpha p(0)

\displaystyle=-\int_{0}^{\ell}\big(\varphi_{q}^{\prime}(\xi)p(\xi)+\varphi_{p}^{\prime}(\xi)q(\xi)\big)\,{\rm d}\xi

\displaystyle\qquad+\big(\varphi_{q}(\xi_{0}^{-})-\varphi_{q}(\xi_{0}^{+})+\eta\big)p(\xi_{0})+\big(\alpha-\varphi_{q}(0)\big)p(0)+\varphi_{p}(\ell)q(\ell)+\varphi_{p}(0)u.

Consequently,

\displaystyle\operatorname{dom}(S_{\rm ext}^{*})

\displaystyle=\left\{\left(\begin{smallmatrix}\varphi_{q}\\
\varphi_{p}\\
\eta\\
\alpha\end{smallmatrix}\right)\in L^{2}([0,\ell];\mathbb{R}^{2})\times\mathbb{R}^{2}\left|\vphantom{\left(\begin{smallmatrix}\varphi_{q}\\
\varphi_{p}\\
\eta\\
\alpha\end{smallmatrix}\right)\in L^{2}([0,\ell];\mathbb{R}^{2})\times\mathbb{R}^{2}}\begin{array}[]{l}\eqref{eq:phismooth}\text{ holds},\ \varphi_{p}(\ell)=0,\\
\alpha=\varphi_{q}(0),\ \eta=\varphi_{q}(\xi_{0}^{+})-\varphi_{q}(\xi_{0}^{-})\end{array}\right.\right\},

\displaystyle S_{\rm ext}^{*}\left(\begin{smallmatrix}\varphi_{q}\\
\varphi_{p}\\
\eta\\
\alpha\end{smallmatrix}\right)

\displaystyle=\left(\begin{smallmatrix}-\varphi_{p}^{\prime}\\
-\varphi_{q}^{\prime}\\
\varphi_{p}(0)\end{smallmatrix}\right).

Thus, the system governed by
S_{\rm ext}^{*}
is again a wave equation,
with a clamped condition at the right endpoint and force control at the
left endpoint, together with an interface condition at
\xi_{0}
. Define

\varphi_{w}:\mathbb{R}_{\geq 0}\to H^{1}([0,\ell])
by

\varphi_{w}(t,\xi)=\int_{\xi}^{\ell}\varphi_{q}(t,\zeta)\,{\rm d}\zeta.

(7.5)

The adjoint system can then be written as

\displaystyle\ddot{\varphi}_{w}(t,\xi)

\displaystyle=\phantom{-}\varphi_{w}^{\prime\prime}(t,\xi),

\displaystyle(t,\xi)\in\mathbb{R}_{\geq 0}\times\big((0,\xi_{0})\cup(\xi_{0},\ell)\big),

(7.6)

\displaystyle\alpha(t)

\displaystyle=-\varphi_{w}^{\prime}(t,0),

\displaystyle t\in\mathbb{R}_{\geq 0},

\displaystyle\eta(t)

\displaystyle=-\varphi_{w}^{\prime}(t,\xi_{0}^{+})+\varphi_{w}^{\prime}(t,\xi_{0}^{-}),

\displaystyle t\in\mathbb{R}_{\geq 0},

\displaystyle 0

\displaystyle=\phantom{-}\varphi_{w}(t,\ell),

\displaystyle t\in\mathbb{R}_{\geq 0},

\displaystyle\mu(t)

\displaystyle=\phantom{-}\dot{\varphi}_{w}(t,0),

\displaystyle t\in\mathbb{R}_{\geq 0}.

The input
\eta
may therefore be interpreted as a point force acting
at
\xi_{0}
.

We now construct a generalised null control. Set

h\coloneqq\frac{\ell}{q}
,
so that

\xi_{0}=ph
,
\ell=qh
.
We use the right-shift operator
S_{r,h}
introduced in
Section
2
. Thus,
S_{r,h}^{j}
represents a delay of length
jh
. In particular,
S_{r,h}^{j}\delta=\delta_{jh}
. For a polynomial
P(X)=p_{0}+p_{1}X+\cdots+p_{N}X^{N}
, we use the notation

P(S_{r,h})\coloneqq\sum_{j=0}^{N}p_{j}S_{r,h}^{j}.

Since
p
and
q
are coprime and at least one of them is
even, the polynomials

1+X^{2p}
,
1+X^{2q}
are coprime. Hence, there exist polynomials

P,Q\in\mathbb{R}[X]
satisfying the Bézout identity

P(X)(1+X^{2p})+Q(X)(1+X^{2q})=1.

(7.7)

To determine a corresponding null control, introduce the Riemann
invariants

R\coloneqq\dot{\varphi}_{w}+\varphi_{w}^{\prime},\qquad S\coloneqq\dot{\varphi}_{w}-\varphi_{w}^{\prime}.

On both subintervals
(0,\xi_{0})
and
(\xi_{0},\ell)
, they satisfy

\dot{R}-R^{\prime}=0,\qquad\dot{S}+S^{\prime}=0.

Thus,
R
and
S
represent left- and right-travelling waves,
respectively.
Consider a smooth input
\alpha\in C_{0}^{\infty}(\mathbb{R}_{>0})
and zero
initial conditions. At the interface, define

\displaystyle s_{-}(t)

\displaystyle\coloneqq S(t,\xi_{0}^{-}),

\displaystyle r_{+}(t)

\displaystyle\coloneqq R(t,\xi_{0}^{+}),

\displaystyle r_{-}(t)

\displaystyle\coloneqq R(t,\xi_{0}^{-}),

\displaystyle s_{+}(t)

\displaystyle\coloneqq S(t,\xi_{0}^{+}).

Continuity of
\dot{\varphi}_{w}
and the interface condition in
(
7.6
) yield

r_{-}=r_{+}+\eta,\qquad s_{+}=s_{-}+\eta.

(7.8)

Propagation between the interface and the two endpoints gives

s_{-}=S_{r,h}^{2p}r_{-}+2S_{r,h}^{p}\alpha,\qquad r_{+}=-S_{r,h}^{2(q-p)}s_{+}.

(7.9)

Indeed, the first identity describes propagation to the left endpoint
and back, together with the boundary input
\alpha
, whereas the
second identity incorporates the sign change caused by reflection at
the clamped endpoint.
Combining (
7.8
) and
(
7.9
), we obtain

\big(I+S_{r,h}^{2q}\big)s_{+}=2S_{r,h}^{p}\alpha+\big(I+S_{r,h}^{2p}\big)\eta.

(7.10)

Motivated by the Bézout identity (
7.7
), define

\eta_{\alpha}\coloneqq-2P(S_{r,h})S_{r,h}^{p}\alpha.

(7.11)

Then (
7.10
) and (
7.7
) give

\big(I+S_{r,h}^{2q}\big)s_{+}=2\big(I+S_{r,h}^{2q}\big)Q(S_{r,h})S_{r,h}^{p}\alpha.

Since
I+S_{r,h}^{2q}
is injective on causal distributions, it
follows that

s_{+}=2Q(S_{r,h})S_{r,h}^{p}\alpha.

The remaining travelling-wave components are therefore

\displaystyle r_{+}

\displaystyle=-2S_{r,h}^{2q-p}Q(S_{r,h})\alpha,

\displaystyle r_{-}

\displaystyle=-2S_{r,h}^{p}\big(P(S_{r,h})+S_{r,h}^{2(q-p)}Q(S_{r,h})\big)\alpha,

\displaystyle s_{-}

\displaystyle=2S_{r,h}^{p}\big(P(S_{r,h})+Q(S_{r,h})\big)\alpha.

Consequently, all travelling-wave components are finite linear
combinations of delayed copies of
\alpha
. In particular, the
corresponding adjoint state has compact temporal support.

At the left endpoint,

\alpha=\tfrac{1}{2}(S-R),\qquad\mu=\tfrac{1}{2}(S+R),

and the incoming left-travelling wave is given by

S_{r,h}^{p}r_{-}
. Hence,

\mu_{\alpha}=\alpha+S_{r,h}^{p}r_{-}.

Using (
7.7
), we obtain

\mu_{\alpha}=A(S_{r,h})\alpha,\qquad A(X)\coloneqq P(X)(1-X^{2p})+Q(X)(1-X^{2q}).

(7.12)

Equivalently,

A(X)=1-2X^{2p}P(X)-2X^{2q}Q(X).

Let
(\alpha_{n})
be a one-sided mollifier sequence satisfying

\supp\alpha_{n}\subset(0,h/n],\qquad\alpha_{n}\longrightarrow\delta\quad\text{in }H^{-1}_{0,\mathrm{loc}}(\mathbb{R}_{\geq 0}).

Define
\eta_{n}\coloneqq-2P(S_{r,h})S_{r,h}^{p}\alpha_{n}
,
\mu_{n}\coloneqq A(S_{r,h})\alpha_{n}
,
and let
\varphi_{n}
be the corresponding adjoint state. Since all
travelling-wave components consist of finitely many fixed delays of

\alpha_{n}
, there exists some
T>0
, independent of
n
, such that

\supp\varphi_{n}\subset[0,T],\qquad\supp\eta_{n}\subset[0,T],\qquad\supp\mu_{n}\subset[0,T].

Passing to the distributional limit gives

\eta=-2P(S_{r,h})S_{r,h}^{p}\delta,\qquad\mu=A(S_{r,h})\delta,

together with a corresponding adjoint state
\varphi
satisfying
\supp\varphi\subset[0,T]
.
Thus,
\eta
is a generalised null control satisfying the assumptions
of Theorem
4.1
, for instance with
k=1
.
Consequently, for every generalised trajectory of (
7.1
),
understood as a trajectory of the system node (
7.2
), the
distribution

u\ast\mu-y\ast\eta

coincides on
(T,\infty)
with the velocity at the left endpoint.
Therefore,

\dot{w}(\cdot,0)=A(S_{r,h})u+2P(S_{r,h})S_{r,h}^{p}y\qquad\text{on }(T,\infty).

(7.13)

The Bézout identity (
7.7
) evaluated at
X=0
gives

P(0)+Q(0)=1,

and hence
A(0)=1
. We may therefore write

A(X)=1+\widetilde{A}(X),\qquad\widetilde{A}(0)=0.

The exponentially stabilising feedback law

u(t)=-k\dot{w}(t,0),\qquad k>0,

can thus be realised, after time
T
, in the causal form

u=-\frac{k}{1+k}\left(\widetilde{A}(S_{r,h})u+2P(S_{r,h})S_{r,h}^{p}y\right).

(7.14)

Since
\widetilde{A}(0)=0
and
p\geq 1
, the right-hand side of
(
7.14
) contains only delayed values of the
input and output.

For example, if
\xi_{0}=\ell/2
, then
p=1
and
q=2
. One possible
choice in (
7.7
) is

P(X)=\tfrac{1}{2}-\tfrac{1}{2}X^{2}
,

Q(X)=\tfrac{1}{2}
.
In this case,

\eta=-\delta_{h}+\delta_{3h}
,
\mu=\delta-\delta_{2h}
.
The corresponding adjoint state is supported in
[0,3h]
. Hence,
Theorem
4.1
applies with

T=3h=\tfrac{3\ell}{2}
,
and (
7.13
) becomes

\dot{w}(t,0)=u(t)-u(t-2h)+y(t-h)-y(t-3h),\qquad t>3h.

Consequently, the stabilising feedback law

u(t)=-k\dot{w}(t,0)
can be implemented as

u(t)=\frac{k}{1+k}\left(u(t-\ell)-y\left(t-\tfrac{\ell}{2}\right)+y\left(t-\tfrac{3\ell}{2}\right)\right),\qquad t>\tfrac{3\ell}{2}.

7.2.
State reconstruction for a reaction–diffusion equation with Dirichlet boundary control

Consider a reaction–diffusion equation on the rectangular domain

\Omega=(0,L_{1})\times(0,L_{2})\subset\mathbb{R}^{2}
. The control acts through the
Dirichlet boundary values on the right-hand part of the boundary,

\Gamma=\{L_{1}\}\times[0,L_{2}]\subset\partial\Omega,

while homogeneous Dirichlet boundary conditions are imposed on

\partial\Omega\setminus\Gamma
. The output is given by the negative Neumann trace on
\Gamma
. We consider a unit diffusion coefficient and a spatially constant reaction coefficient
c\in\mathbb{R}
. Thus, the system is governed by

\displaystyle\dot{x}(t,\xi)

\displaystyle=\phantom{-}\Delta x(t,\xi)+cx(t,\xi),

\displaystyle(t,\xi)

\displaystyle\in\mathbb{R}_{\geq 0}\times\Omega,

(7.15)

\displaystyle u(t,\xi)

\displaystyle=\phantom{-}x(t,\xi),

\displaystyle(t,\xi)

\displaystyle\in\mathbb{R}_{\geq 0}\times\Gamma,

\displaystyle 0

\displaystyle=\phantom{-}x(t,\xi),

\displaystyle(t,\xi)

\displaystyle\in\mathbb{R}_{\geq 0}\times\big(\partial\Omega\setminus\Gamma\big),

\displaystyle y(t,\xi)

\displaystyle=-n^{\top}(\xi)\nabla x(t,\xi),

\displaystyle(t,\xi)

\displaystyle\in\mathbb{R}_{\geq 0}\times\Gamma,

where

denotes the outward unit
normal vector field on
\partial\Omega
.

We next formulate (
7.15
) as a system node. The state space is

L^{2}(\Omega)
. Since the full Dirichlet trace belongs to the fractional
Sobolev space
H^{1/2}(\partial\Omega)
; see

[
16
, Sec. 4.1]
, the input space is chosen as

H^{1/2}_{0}(\Gamma)
. This is the space of all elements of

whose extension by zero to

\partial\Omega\setminus\Gamma
belongs to

H^{1/2}(\partial\Omega)
; see also
[
18
]
. The output space is

H^{-1/2}(\Gamma)\coloneqq H^{1/2}_{0}(\Gamma)^{\prime}.

Let

\gamma:H^{1}(\Omega)\to H^{1/2}(\partial\Omega)

denote the
trace operator
, and define

H^{1}_{\Gamma}(\Omega)=\left\{x\in H^{1}(\Omega)\left|\vphantom{x\in H^{1}(\Omega)}(\gamma x)|_{\partial\Omega\setminus\Gamma}=0\right.\right\}.

The restricted trace operator

\gamma_{\Gamma}:H^{1}_{\Gamma}(\Omega)\to H^{1/2}_{0}(\Gamma)

maps a function to the restriction of its trace to
\Gamma
.
Furthermore, let
H_{\operatorname{div}}(\Omega)
denote the space of all vector
fields in
L^{2}(\Omega;\mathbb{R}^{2})
whose weak divergence belongs to

L^{2}(\Omega)
. The restricted normal trace operator is denoted by

\gamma_{\Gamma,n}:H_{\operatorname{div}}(\Omega)\to H^{-1/2}(\Gamma);

see
[
18
]
. For the basic properties of the normal trace
operator, we refer to
[
23
]
.

With these spaces and trace operators, the system node associated with

) is given by

\displaystyle\operatorname{dom}S=\operatorname{dom}(A\&B)

\displaystyle=\left\{\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)\in H^{1}_{\Gamma}(\Omega)\times H^{1/2}_{0}(\Gamma)\left|\vphantom{\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)\in H^{1}_{\Gamma}(\Omega)\times H^{1/2}_{0}(\Gamma)}\nabla x\in H_{\operatorname{div}}(\Omega)\ \wedge\ u=\gamma_{\Gamma}x\right.\right\},

\displaystyle A\&B\left(\begin{smallmatrix}x\\
u\end{smallmatrix}\right)

\mathcal{R}:H^{1/2}_{0}(\Gamma)\to H^{-1/2}(\Gamma)

\displaystyle(t,\xi)

\displaystyle\in\mathbb{R}_{\geq 0}\times\Omega,

\displaystyle(t,\xi)

\forall\,t\geq T:\quad\langle x(t),\varphi_{0}\rangle_{L^{2}}=\int_{0}^{T}\langle u(t-\tau),\mu(\tau)\rangle_{H^{1/2}}-\langle y(t-\tau),\eta(\tau)\rangle_{H^{-1/2}}\,{\rm d}\tau.

\forall\,v\in H^{-1/2}(\Gamma),\ w\in H^{1/2}_{0}(\Gamma):\quad\langle v,\mathcal{R}w\rangle_{H^{-1/2}}=\langle v,w\rangle_{H^{-1/2},H^{1/2}}=\langle\mathcal{R}^{-1}v,w\rangle_{H^{1/2}}.

\forall\,t\geq T:\quad\langle x(t),\varphi_{0}\rangle_{L^{2}}=\int_{0}^{T}\langle u(t-\tau),\widetilde{\mu}(\tau)\rangle_{H^{1/2},H^{-1/2}}-\langle y(t-\tau),\widetilde{\eta}(\tau)\rangle_{H^{-1/2},H^{1/2}}\,{\rm d}\tau.

Thus, the two terms in the integrand are duality pairings between the
Dirichlet and Neumann traces of the original and adjoint systems.

Conclusion

We have developed a modulating-function framework for partial state
reconstruction from past input and output data. The approach is based
on generalised null controls of the adjoint system and corresponding
convolutions with the input and output.

The first main contribution is a unified formulation for
infinite-dimensional linear systems in the system-node framework.
This framework requires comparatively few assumptions, is closed under
adjunction, and does not require the system to be well-posed. The
second contribution is a distributional extension of the
modulating-function method. The resulting modulating distributions
allow the reconstruction of additional outputs defined by unbounded
operators and are therefore particularly suitable for the
implementation of unbounded state feedback.

The theoretical results were illustrated by two examples. For a
vibrating string, the distributional approach was used to reconstruct a
boundary velocity from input and output data and thereby realise an
exponentially stabilising feedback law. For a reaction–diffusion
equation with Dirichlet boundary control and Neumann boundary
observation, the method was applied to finite-dimensional state
reconstruction and illustrated numerically.
