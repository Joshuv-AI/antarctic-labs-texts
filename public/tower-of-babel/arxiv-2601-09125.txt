Chip-firing on the Lattice of Nonnegative Integer Points
Ryota Inagaki, Tanya Khovanova, Austin Luo

Abstract
Chip-firing on a directed graph is a game in which chips, a discrete commodity, are placed on the vertices of the graph and are transferred between vertices. In this paper, we study a chip-firing game on the Hasse diagram of the lattice of nonnegative integer points on the plane, where we start with 2 n 2^{n} chips at the origin. When we fire a vertex v v , we send one chip to each out-neighbor. We fire until we reach a stable configuration, a distribution of chips where no vertex can fire. We study the intermediate firing configuration: a table that assigns to each vertex the total number of chips that pass through it. We prove that the nonzero entries of the stable configuration correspond to the odd entries of the intermediate configuration. The intermediate configuration consists of three parts: the top triangle, the midsection, and the bottom triangle. We describe properties of each part. We study properties of each row and the number of rows of the intermediate configuration. We also explore properties of the difference tables, which are tables of first differences of each row of the intermediate firing configuration.

Chip-firing is a game on a graph in which a discrete commodity, called chips, is placed on the vertices of the graph. A vertex

Despite the abundance of work on chip-firing on lattices and trees, relatively little has been written about the chip-firing game on directed graphs that are not trees. Indeed, one aspect that complicates chip-firing games on these graphs is the fact that some chips that diverge from a vertex may reconverge at a different vertex later.

Preliminaries

2.1
Unlabeled Chip-Firing

In the unlabeled chip-firing game on directed graphs, indistinguishable chips are put on the vertices of a directed graph
G=(V,E)
. Vertex
v
can fire if and only if it has at least
\outdeg(v)
chips. In other words, vertex
v
sends one chip to each out-neighbor and consequently loses
\outdeg(v)
chips.

A
configuration

\mathcal{C}
is a distribution of chips over the vertices of a graph. When the firing process reaches a state in which no vertex can fire, the distribution of chips over the vertices is a
stable configuration
.

A key property of unlabeled chip-firing on directed graphs is the following global confluence property, which is analogous to that of chip-firing on undirected graphs (which is similar to Theorem 2.2.2 of Klivans’
textbook
[
16
]
).

Theorem 2.1

(Theorem 1.1 of
[
5
]
)
.

For a directed graph
G
and initial configuration
\mathcal{C}
of chips on the graph, the unlabeled chip-firing game will either run forever or end after the same number of moves and at the same stable configuration. Furthermore, the number of times each vertex fires is the same regardless of the sequence of firings taken in the game.

2.2
Our Setup

We define the
Hasse diagram of
\mathbb{Z}_{\geq 0}^{2}
to be the graph whose vertex set is the set of integer points in the first quadrant, i.e.,
\{(x,y):x,y\in\mathbb{Z}_{\geq 0}\}
and whose edges are
\{(x,y)\to(x+1,y):x,y\in\mathbb{Z}_{\geq 0}\}
and
\{(x,y)\to(x,y+1):x,y\in\mathbb{Z}_{\geq 0}\}
. We say that a vertex
v=(v_{x},v_{y})
is in row
i
if
v_{x}+v_{y}=i
. For vertices
(a,b)
and
(c,d)
that are in the same row, we say that
(a,b)
is
left
of
(c,d)
if
b-a<d-c
, or equivalently
b<d
.

Our chip-firing game proceeds on the graph described above. We call the vertex
(0,0)

the root
.

In our chip-firing game, we denote the
initial configuration
of chip-firing as placing of
2^{n}
chips on the root. A vertex
v=(x,y)
can
fire
if and only if it has at least
2
chips. When vertex
v

fires
, it transfers a chip from itself to each of its
2
children.

.

We claim that if we start a chip-firing game with the initial configuration as above, it will always stabilize. Suppose, on the contrary, that we never reach a stable configuration. This means that the number of chips transferred from row
i
to row
i+1
must be the same from some row
N
onward. It means that no chip is left behind, and every vertex on rows
N
and later receives an even number of chips. Consider the leftmost vertex in row
N
; suppose it receives
a
chips. Thus, the leftmost vertex in the next row receives
\left\lfloor\frac{a}{2}\right\rfloor
chips. As this quantity decreases, eventually the leftmost vertex in some row has to receive an odd number of chips. This is a contradiction.

We observe that, as long as we start with the same number of chips at the root, all firing processes lead to the same stable configuration. This is a result of Theorem
2.1
.

The Total Number of Firings

Let us denote by
T(n)
the total number of firings when we start with
2^{n}
chips at the origin. We know that, from the confluence property of chip-firing on directed graphs (Theorem
2.1
), this number does not depend on the order of firings.

We calculated the first few values of this sequence starting from index 0 (the new sequence A389565 in the OEIS
[
18
]
):

0,\ 1,\ 5,\ 15,\ 52,\ 163,\ 458,\ 1359,\ 4296,\ 12890,\ 38570.

We would like to introduce the distribution of the number of chips in the stable configuration as a function of
y-x
. In other words, we denote by
D_{n}(i)
the number of chips in all the vertices
(x,y)
in the stable configuration such that
y-x=i
when we start with
2^{n}
chips. We call this distribution
the distance distribution
.

Example 2
.

We get that the distance distribution
D_{4}
is

2,\ 1,\ 2,\ 3,\ 0,\ 3,\ 2,\ 1,\ 2.

To see this, one can either do direct computation of the stable configuration or consider the table in Example
4
, which is the table for the maximum number of chips at each vertex in the firing process for
n=4
. The odd values in bold correspond to vertices that have one chip in the stable configuration, since each firing removes two chips from the vertex that is fired. One can sum the number of bold vertices in each column to obtain the distance distribution
D_{4}
.

Note that the distance distribution is symmetric with the middle value zero. Consider the second raw moment
\mu_{2}^{\prime}(n)
of the distribution
D_{n}(i)
:

\mu_{2}^{\prime}(n)=\sum_{i}i^{2}D_{n}(i).

Proposition 3.1
.

We have the following connection:

\mu_{2}^{\prime}(n)=2T(n).

Proof.

The second raw moment of the initial distribution is 0. We can consider the second raw moments of the resulting chip distribution after some number of firings. Suppose we have 2 chips at the vertex
(x,y)
. Before firing, they contribute
2(y-x)^{2}
to the second moment. After the firing, we have one chip at
(x+1,y)
and the other at
(x,y+1)
; they contribute

(y-x-1)^{2}+(y-x+1)^{2}=2(y-x)^{2}+2.

Thus, each firing increases the second moment by 2. The result follows.
∎

Example 3
.

From Example
2
, we get that

T(4)=\frac{\mu_{2}^{\prime}(4)}{2}=\frac{2\cdot 4^{2}+3^{2}+2\cdot 2^{2}+3\cdot 1+3\cdot 1+2\cdot 2^{2}+3^{2}+2\cdot 4^{2}}{2}=52.

The Intermediate Firing Configuration

4.1
General facts

For this section, we stabilize the chip-firing process on the quadrant lattice graph using the following strategy: starting from
i=0
and for each
i
, in increasing order, we repeatedly fire vertices in row
i
until no vertex in that row can fire anymore. In our study of chip-firing, ignoring the labels, it suffices to consider just this procedure, since Theorem
2.1
tells us that, regardless of the sequence of firings used to reach a stable configuration, the number of times each vertex fires is the same, and the final stable configuration is the same.

We define
F(x,y)
to be the number of chips at the vertex
(x,y)
after all rows with an index lower than
x+y
have finished firing and before the vertices in row
x+y
start to fire. Note that if the vertex
(x,y)
never receives chips, then
F(x,y)=0
. For
(x,y)\in\mathbb{Z}^{2}
not in the first quadrant, we assume that
F(x,y)=0
. We call
F(x,y)
the
intermediate firing configuration
.

The intermediate firing configuration is connected to the stable configuration as follows.

Theorem 4.1
.

If
F(x,y)
is odd, then, in the stable configuration, vertex
(x,y)
has one chip; otherwise, it has zero chips.

Proof.

Note that in our strategy, vertex
(x,y)
receives
F(x,y)
chips and then fires until it is no longer possible. Since outdegree of each vertex is
2
, vertex
(x,y)
fires
\left\lfloor\frac{F(x,y)}{2}\right\rfloor
times and loses
2\left\lfloor\frac{F(x,y)}{2}\right\rfloor
chips. Thus, in the stable configuration, it has
F(x,y)-2\left\lfloor\frac{F(x,y)}{2}\right\rfloor
chips. The result immediately follows.
∎

Proposition 4.2
.

The last row in the stable configuration is the same as the last nonzero row in
F
.

Proof.

Let
i
be the last row in
F(x,y)
with nonzero entries. The nonzero entries of
F
on that row must be equal to
1
; otherwise, there is a vertex in the
i
th row that can fire, moving chips to the next row. It follows that the
i
th row of the stable configuration is the same as the last nonzero row of
F(x,y)
.
∎

4.2
Symmetry

Our chip-firing process is symmetric with respect to swapping
x
and
y
. In other words,
y=x
is the line of symmetry. We have the following proposition.

Proposition 4.3
.

The intermediate configuration obtained is symmetric over the line
y=x
:

F(x,y)=F(y,x).

In particular, we have the following result.

Proposition 4.4
.

Let
x\geq 0
and
n\geq 1
, then
F(x,x)
is even.

Proof.

First note
F(0,0)=2^{n}
, which is even because
n\geq 1
. For the rest of the proof, assume that
x\geq 1
.

We observe that
F(x,x)=\left\lfloor\frac{F(x,x-1)}{2}\right\rfloor+\left\lfloor\frac{F(x-1,x)}{2}\right\rfloor=2\left\lfloor\frac{F(x,x-1)}{2}\right\rfloor
with the last equality resulting from Proposition
4.3
, which implies
F(x,x-1)=F(x-1,x)
. This completes the proof.
∎

The final stable configuration is symmetric with respect to the line
y=x
too. We have the following corollary from Theorem
4.1
and Proposition
4.4
.

Corollary 4.5
.

No chip in the stable configuration ends up on the line
y=x
.

5
Pascal’s Triangle and the Intermediate Firing Configuration

When we start with
2^{n}
chips, the top
n
rows are especially easy to describe. As we can see in the next proposition, for each
i\in\{0,1,\dots,n\}
, the
i
th row of Pascal’s triangle, scaled by
2^{n-i}
, appears as row
i
of the intermediate configuration.

Proposition 5.1
.

If we start with
2^{n}
chips at the root, then for each
i\in\{0,1,\dots,n\}
, the following is an intermediate configuration on row
i
. For
x\in\{0,1,\dots,i\}
, vertex
(x,i-x)
has
2^{n-i}\binom{i}{x}
chips:

F(x,i-x)=2^{n-i}\binom{i}{x}.

Proof.

We use induction. Consider the base case
i=0
. In the initial configuration of the chip-firing game, there are
2^{n}=2^{n-i}
chips at vertex
(0,0)
of row
0
, which matches our statement.

For our inductive step, we assume that for row
i\leq n
, vertex
(x,i-x)
has
2^{n-i}\binom{i}{x}
chips in the intermediate configuration.

Consider vertex
(x,i+1-x)
on row
i+1
.

First, suppose that
0<x<i+1
. It receives
2^{n-i-1}\binom{i}{x}
chips from vertex
(x,i-x)
and
2^{n-i-1}\binom{i}{x-1}
chips from
(x-1,i+1-x)
. Summing this up, the vertex gets the total of
2^{n-i-1}(\binom{i}{x}+\binom{i}{x-1})=2^{n-i-1}\binom{i+1}{x}
chips.

Now suppose that
x=i+1
. Here, we find that the vertex
(x,i+1-x)=(i+1,0)
receives exactly
\frac{1}{2}\cdot 2^{n-i}\binom{i}{0}=2^{n-i-1}\binom{i+1}{i+1}
chips from
(i,0)
and no other chips, as the in-degree of
(x,i+1-x)
is only
1
. The case
x=0
is resolved in a symmetric manner. This concludes the inductive step.
∎

In terms of parameters
(x,y)
, vertex
(x,y)
with
x+y\leq n
has
2^{n-x-y}\binom{x+y}{x}
chips.

Corollary 5.2
.

In the final stable configuration, the closest row to the root that contains chips is the
n
th row.

Proof.

From Proposition
5.1
, we know that in the intermediate configuration, the number of chips at each vertex on row
m<n
is divisible by
2^{n-m}
, implying that row
m
does not have any chips in the stable configuration. However, row
n
equals the
n
th row of the Pascal triangle; in particular, it starts with 1, implying by Theorem
4.1
that there are chips in row
n
of the stable configuration.
∎

This corollary explains the left triangle from Figure
4
consisting only of unfilled points.

6
The Middle of the Intermediate Firing Configuration

For the middle of the intermediate firing configuration table
F(x,y)
, it is hard to write the entries in a clean formula. After row
n
, the rows are no longer scaled versions of those of Pascal’s triangle. However, we find and establish here several relations between the entries of each row of
F(x,y)
.

6.1
General Structure of Rows

In the next proposition, we show that, in the left part of the intermediate configuration, the row entries increase by at least two, except at the very end, when the second entry is exactly in the middle, then the increase might be only by one.

Proposition 6.1
.

Each row of
F(x,y)
, starting with the leftmost nonzero entry, increases until the middle. Moreover, if
F(x+1,y-1)>0
, and
y<x
, then

F(x,y)-F(x+1,y-1)\geq 2.

(1)

If
y=x
, then

F(x,y)-F(x+1,y-1)\geq 1.

(2)

By symmetry, the entries decrease in the right half.

Proof.

We prove this via induction. For row
i=0
, the statement is true.

We now prove the inductive step. Suppose the statement is true for row
i-1
. Consider two points
(x+1,y-1)
and
(x,y)
on row
i
, where function
F
is nonzero. Given that
F(x+1,y-1)>0
, it follows that
F(x,y-1)>0
. If
F(x+1,y-2)=0
, then
F(x,y-1)>1
for
F(x+1,y-1)
to get any chips. In any case,
F(x,y-1)-F(x+1,y-2)\geq 2
.

Suppose
y<x-1
, then
F(x-1,y)
is to the left of the middle, then by the induction hypothesis
F(x-1,y)-F(x,y-1)\geq 2
. Combining this with
F(x,y-1)-F(x+1,y-2)\geq 2
, we deduce that
F(x-1,y)-F(x+1,y-2)\geq 4
, implying that

F(x,y)-F(x+1,y-1)=\left\lfloor\frac{F(x-1,y)}{2}\right\rfloor-\left\lfloor\frac{F(x+1,y-2)}{2}\right\rfloor\geq 2,

finishing the induction step.

Now, suppose
F(x-1,y)
is in the middle, or equivalently,
y=x-1
. Then the inductive hypothesis implies
F(x-1,y)-F(x,y-1)\geq 1
. Combining this with
F(x,y-1)-F(x+1,y-2)\geq 2
, we obtain
F(x-1,y)-F(x+1,y-2)\geq 3
. Adding the fact from Proposition
4.4
that
F(x-1,y)
is even, we obtain, again,

F(x,y)-F(x+1,y-1)=\left\lfloor\frac{F(x-1,y)}{2}\right\rfloor-\left\lfloor\frac{F(x+1,y-2)}{2}\right\rfloor\geq 2.

Now, we prove the last case that if
y=x
, then
F(x,y)-F(x+1,y-1)\geq 1
.

If
x=y
, then
F(x,y)=\left\lfloor\frac{F(x-1,y)}{2}\right\rfloor+\left\lfloor\frac{F(x,y-1)}{2}\right\rfloor=2\left\lfloor\frac{F(x,y-1)}{2}\right\rfloor
. Note that
F(x+1,y-1)=\left\lfloor\frac{F(x+1,y-2)}{2}\right\rfloor+\left\lfloor\frac{F(x,y-1)}{2}\right\rfloor
. Since both
\left\lfloor\frac{F(x+1,y-2)}{2}\right\rfloor
and
\left\lfloor\frac{F(x,y-1)}{2}\right\rfloor
are to the left of the middle, the inductive hypothesis implies the
F(x,y-1)-F(x+1,y-2)\geq 2
and, consequently,

F(x,y)-F(x+1,y-1)=\left\lfloor\frac{F(x,y-1)}{2}\right\rfloor-\left\lfloor\frac{F(x+1,y-2)}{2}\right\rfloor\geq 1.

By symmetry of entries in
F(x,y)
, we get the final claim, concluding the proof.
∎

6.2
Row length

Now we discuss the lengths of the rows, which is the number of nonzero entries in the row. We describe an example with a particular
n=9
to match Figure
4
.

Example 5
.

For
n=9
, in the top triangle, the row length starts with 1 and increases by 1 until it reaches
n+1=10
. This is our top triangle. Then, we have
13
rows where alternating terms slowly and weakly increase:

9,\ 10,\ 11,\ 10,\ 11,\ 10,\ 11,\ 12,\ 11,\ 12,\ 11,\ 12,\ 11.

This is the top of the middle part. Then, we have our rectangular shape with 57 rows that alternate between 12 and 13, starting with 12. In the bottom triangle, the row length decreases by 1, from 13 to 2.
The total number of rows is
10+13+57+12=92
.

In the example above, we see that the numbers of elements in two consecutive rows differ by 1.

Proposition 6.2
.

For any row
i
with at least one nonzero entry, the number of nonzero elements in row
i
of
F(x,y)
differs from the number of nonzero elements in row
i+1
of
F(x,y)
by exactly
+1
or
-1
.

Proof.

Let
F(x,y)
be the leftmost nonzero entry of the
i
th row. Consequently, the rightmost nonzero entry of the
i
th row is
F(y,x)=F(x,y)
. Then, by Proposition
6.1
, all entries between
(x,y)
and
(y,x)
are nonzero, implying that there are
x-y+1
nonzero terms in row
i
.

We consider two cases. First, suppose
F(x,y)\geq 2
. We find that
F(x+1,y)=\left\lfloor\frac{F(x,y)}{2}\right\rfloor+\left\lfloor\frac{F(x+1,y-1)}{2}\right\rfloor\geq 1
, and
F(x+1,y)
is the leftmost nonzero term of row
i+1
, implying that there are
x+2-y
nonzero terms in row
i+1
.

Now consider the case where
F(x,y)=1
. We find that
F(x+1,y)=\left\lfloor\frac{F(x,y)}{2}\right\rfloor=0
and
F(x,y+1)=\left\lfloor\frac{F(x,y)}{2}\right\rfloor+\left\lfloor\frac{F(x-1,y+1)}{2}\right\rfloor\geq 1
. The last inequality holds because, due to Proposition
6.1
, we have
F(x-1,y+1)>F(x,y)=1
. We thus deduce that
F(x,y+1)
is the leftmost nonzero entry of row
i+1
. Therefore, there are exactly
x-y-1+1=x-y
nonzero entries in row
i+1
.
∎

It follows that whenever the length of the row decreases, the previous row has one chip at the ends of the row in a stable configuration. It means the stable configuration has to be outlined by a boundary that contains chips.

In the middle of the intermediate configuration, we see a lot of cases when two rows that are two apart are the same length.

Proposition 6.3
.

If row
i
starts with
1
and
a
, where
4\leq a\leq 7
, then row
i+2
has the same length and also starts with
1
.

Proof.

Suppose the leftmost nonzero element in row
i
is
F(x,y)=1
, implying that the row length is
x-y+1
. Assume also that
F(x-1,y+1)=a
, where
4\leq a\leq 7
. Then the vertex
(x,y)
does not fire, and the leftmost nonzero term in row
i+1
is
F(x,y+1)=\left\lfloor\frac{F(x-1,y+1)}{2}\right\rfloor
. We have
2\leq\left\lfloor\frac{F(x-1,y+1)}{2}\right\rfloor=\left\lfloor\frac{a}{2}\right\rfloor\leq 3
. It follows that the leftmost element in row
i+2
is at the vertex
(x+1,y+1)
and is equal to
\left\lfloor\frac{F(x,y+1)}{2}\right\rfloor=1
. It also follows that the length of row
i+2
is
(x+1)-(y+1)+1=x-y+1
, the same as the length of row
i
.
∎

We also computed the length of the longest row, starting from index 0 (new sequence A390355 in the OEIS

1,\ 2,\ 3,\ 4,\ 5,\ 6,\ 7,\ 8,\ 10,\ 13,\ 15,\ 19,\ 24,\ 30,\ 37,\ 46,\ 58,\ 73,\ \ldots.

6.3
The number of nonzero rows of the intermediate firing configuration

We start by looking at central elements.

Proposition 6.4
.

If
F(x,x)>0
, then
F(x+1,x+1)\leq F(x,x)-2
.

Proof.

Suppose
F(x,x)>0
. We also know that
F(x,x)
is even by Proposition
4.4
, implying that
F(x+1,x)=F(x,x+1)=\left\lfloor\frac{F(x+1,x-1)}{2}\right\rfloor+\frac{F(x,x)}{2}
.

Now, by Proposition
6.1
, we have
F(x+1,x-1)<F(x,x)
. Because of this and since
F(x,x)
is even, we obtain that
\frac{F(x,x)}{2}>\left\lfloor\frac{F(x+1,x-1)}{2}\right\rfloor
. Consequently, we find that

F(x+1,x+1)=\left\lfloor\frac{F(x+1,x)}{2}\right\rfloor+\left\lfloor\frac{F(x,x+1)}{2}\right\rfloor=2\left\lfloor\frac{F(x+1,x)}{2}\right\rfloor=2\left\lfloor\frac{\left\lfloor\frac{F(x+1,x-1)}{2}\right\rfloor+\frac{F(x,x)}{2}}{2}\right\rfloor<F(x,x).

Knowing that both
F(x,x)
and
F(x+1,x+1)
are even, we find
F(x+1,x+1)\leq F(x,x)-2
.
∎

We establish an upper bound on the number of rows.

Proposition 6.5
.

Consider the stable configuration resulting from
2^{n}
chips starting at the root. The furthest chip from the root is at row equal to or above row
n+\binom{n}{n/2}
if
n
is even and equal to or above row
n+1+2\left\lfloor\binom{n}{\lfloor n/2\rfloor}/2\right\rfloor
if
n
is odd.

Proof.

We first consider the case where
n
is even. By Proposition
5.1
, the central element in row
i=n
is
F(\frac{n}{2},\frac{n}{2})=\binom{n}{n/2}
. Using the fact that
F(x+1,x+1)\leq F(x,x)-2
from Proposition
6.4
, and also the fact that
\binom{n}{n/2}
is even for
n>0
,
we get

F\left(\frac{n}{2}+\frac{\binom{n}{n/2}}{2},\frac{n}{2}+\frac{\binom{n}{n/2}}{2}\right)\leq 0.

As the central element in this row is zero, the entire row
n+\binom{n}{n/2}+1
consists of zeros.

Now consider the case where
n
is odd. We find that near the center of row
i=n
, we have
F(\lceil n/2\rceil,\left\lfloor n/2\right\rfloor)=F(\left\lfloor n/2\right\rfloor,\lceil n/2\rceil)=\binom{n}{\left\lfloor n/2\right\rfloor}
. Similar to above, we get that

F\left(\frac{n+1}{2}+\left\lfloor\binom{n}{\left\lfloor n/2\right\rfloor}/2\right\rfloor,\frac{n+1}{2}+\left\lfloor\binom{n}{\left\lfloor n/2\right\rfloor}/2\right\rfloor\right)\leq 0,

implying that row
n+2+2\left\lfloor\binom{n}{\lfloor n/2\rfloor}/2\right\rfloor
consists entirely of zeros.
∎

One can observe that if row
i
of
F
is nonzero, then all previous rows are nonzero. To see this, we observe that all vertices in row
i
received all of their chips from row
i-1
, since all in-neighbors of row
i
are from row
i-1
. It follows that if
F
has
x
nonzero rows, then the last row is row
x-1
.

We wrote a program to calculate the maximum number of nonzero rows in the table
F(x,y)
, starting from
n=0
(new sequence A390129 in the OEIS
[
18
]
):

1,\ 2,\ 4,\ 6,\ 10,\ 16,\ 24,\ 38,\ 60,\ 92,\ 144,\ 226,\ 362,\ 570,\ 906,\ 1430,\ \ldots.

Notice that starting from index
n=1
, the number of rows is even. The following sequence is half of the above for
n>0
:

1,\ 2,\ 3,\ 5,\ 8,\ 12,\ 19,\ 30,\ 46,\ 72,\ 113,\ 181,\ 270,\ 453,\ 715\ \ldots.

This is not a coincidence, as we prove in the following proposition.

Proposition 6.6
.

The number of nonzero rows in the intermediate firing configuration
F
is even for
n\geq 1
.

Proof.

We claim that the number of elements in each row alternates between odd and even. This is because if the number of elements in a row is even, then there are two copies of the largest element in the row in the center of the row. Once this row completely fires, the next row will have an odd number of elements with a unique element on the center line. Note that this unique element must be even by Proposition
4.4
and the largest element in the row by Proposition
6.1
.

Now, suppose the last row has an odd number of elements. Since there must be a unique element on the center line, it must be even. However, this means that we have at least two chips in the central vertex in the last row, which is a contradiction. Therefore, the last row must have an even number of elements, and the number of rows in the table of
F(x,y)
must be even since the first row has a single element.
∎

7
The Bottom Triangle

This section is devoted to the bottom rows of the table
F(x,y)
, which we also call the bottom triangle, where the lengths of the rows strictly decrease as one reads down the table.

We call a row of nonzero entries of length
j+1

minimal
if it has the smallest possible entries, is symmetric, and satisfies conditions of Proposition
6.1
. We denote such a row as
R(j)
.

We can see that if
j=2k-1
, then the row
R(j)
is

1,\ 3,\ 5,\ 7,\ \dots,\ j,\ j,\ \dots,\ 7,\ 5,\ 3,\ 1.

When
j=2k
, the row
R(j)
is

1,\ 3,\ 5,\ 7,\ \dots,\ j-1,\ j,\ j-1,\ \dots,\ 7,\ 5,\ 3,\ 1.

We define
the bottom triangle
as the largest set of rows at the bottom of
F(x,y)
such that each next row has one fewer entry than the previous one. We will later show that the bottom triangle consists of rows
R(j)
, where
R(1)
is the last row.

Let us calculate the number of chips in row
R(j)
. We denote this sum as
S(j)
. We see from examples that the sequence
S(j)
starts as

2,\ 4,\ 8,\ 12,\ 18,\ 24,\ 32,\ 40,\ 50,

and is sequence A007590 in the OEIS
[
18
]
. We have
S(2k-1)=2k^{2}
and
S(2k)=2k(k+1)
. Combining the formulas, we get

S(j)=\left\lfloor\frac{(j+1)^{2}}{2}\right\rfloor.

Lemma 7.1
.

If a row in a configuration is
R(j)
, then the next row is
R(j-1)
.

Proof.

The number of chips that stay at the vertices in row
R(j)
after firing is
2\left\lfloor\frac{j+1}{2}\right\rfloor
. Thus, the number of chips that move to the next row is
\left\lfloor\frac{(j+1)^{2}}{2}\right\rfloor-2\left\lfloor\frac{j+1}{2}\right\rfloor
.

If
j=2k-1
, the above equals
2k^{2}-2k=2k(k-1)=S(2k-2)=S(j-1)
. If
j=2k
, the above equals
2k^{2}+2k-2k=2k^{2}=S(2k-2)=S(j-1)
. We know that the length of a row can decrease by 1 at most, and the only row with at least
j
entries with
S(j-1)
chips is the minimal row
R(j-1)
.
∎

Proposition 7.2
.

If in an intermediate configuration
F(x,y)
, a row is
R(j)
and the previous row has
j+1
nonzero elements, then the previous row is
R(j+1)
.

Proof.

Row
R(j)
has
j+1
nonzero entries. Moreover, considering constraints in Proposition
6.1
, row
R(j)
has the smallest number of chips possible in each place for a row with the given number of entries.

On the other hand, given a row, the maximum total number of chips in the previous row happens when the previous row keeps one chip after firing whenever possible. This is possible for all entries except the middle one.

Suppose
j=2k
, then it has
2k+1
nonzero entries, and the previous row
2k+2
entries. The maximum possible number of chips in the previous row is

S(j)+2k+2=2k(k+1)+2k+2=2(k^{2}+k+k+1)=2(k+1)^{2}=S(j+1).

Similarly, if
j=2k-1
, then it has
2k
nonzero entries, and the previous row has
2k+1
entries. However, the middle entry has to be even; thus, the row can keep a maximum
2k
chips, so it can have at most

S(j)+2k=2k^{2}+2k=2k(k+1)=S(j+1)

chips. We see that the maximum possible number of chips in the previous row is the same as the minimum possible number of chips in a row, given the number of nonzero elements. Thus, that row can only be row
R(j+1)
.
∎

This means the bottom triangle consists solely of minimal rows.

When computing
F(x,y)
for
n
up to and including
12
, we observe that any configuration
F(x,y)
ends with the long rectangle followed by the bottom triangle. We also see that the rectangle is the widest part of the intermediate configuration. This inspires the following conjecture.

Conjecture 7.3
.

The number of rows in the bottom triangle equals the length of the longest row minus 1.

We now prove general properties of difference tables. The first is analogous to Proposition
4.3
. The symmetry of the intermediate configuration implies the symmetry of the corresponding difference table.

Proposition 9.1

(Symmetry)
.

For each
i\geq 1
and
j
, the
j
th leftmost element in row
i
of
F^{\prime}(n)
is the same up to a sign as the
j
th rightmost element in that row:
F^{\prime}(x,y)=-F^{\prime}(y,x)
.

It is not surprising that the maximum element in rows of the intermediate configuration is not increasing. The next proposition shows that the same is true for difference tables, explaining that the rows of the intermediate configuration are becoming flatter. Due to symmetry, the maximum absolute value in a row of the difference table is the same as the maximum value on the left side of the row.

Proposition 9.2
.

Let
n>2
and let
i>1
. The maximum element of the
(i+1)
st row of
F^{\prime}(n)
is no greater than that of row
i
of
F^{\prime}(n)
.

Proof.

We want to show that

F^{\prime}(x,y)\leq\max\{F^{\prime}(x-1,y),F^{\prime}(x,y-1)\}.

Due to symmetry, it is enough to look at the left side of the row. Suppose
a\leq b\leq c
are three consecutive elements in row
i
of
F
, which are all on the left side. Then the corresponding row in
F^{\prime}
has two consecutive elements
b-a
and
c-b
.

The next row in
F
has two consecutive elements
\left\lfloor\frac{a}{2}\right\rfloor+\left\lfloor\frac{b}{2}\right\rfloor
and
\left\lfloor\frac{b}{2}\right\rfloor+\left\lfloor\frac{c}{2}\right\rfloor
. The next row in
F^{\prime}
has an element
\left\lfloor\frac{c}{2}\right\rfloor-\left\lfloor\frac{a}{2}\right\rfloor
. We need to show that

\left\lfloor\frac{c}{2}\right\rfloor-\left\lfloor\frac{a}{2}\right\rfloor\leq\max\{b-a,c-b\}.

We have

\left\lfloor\frac{c}{2}\right\rfloor-\left\lfloor\frac{a}{2}\right\rfloor\leq\frac{c}{2}-\frac{a}{2}+\frac{1}{2}.

Suppose
b-a\neq c-b
, then
\max\{b-a,c-b\}\geq\frac{c-a}{2}+\frac{1}{2}
. If
b-a=c-b
, then
a
and
c
have the same parity, and
\left\lfloor\frac{c}{2}\right\rfloor-\left\lfloor\frac{a}{2}\right\rfloor=\frac{c}{2}-\frac{a}{2}=b-a=c-b
. The statement follows. By symmetry, we get the statement when
a\geq b\geq c
.

The only case that is left is when
a<b>c
. This only happens when
b
is the central element, implying that
a=c
. In this case,

\left\lfloor\frac{c}{2}\right\rfloor-\left\lfloor\frac{a}{2}\right\rfloor=0\leq\max\{b-a,c-b\},

finishing the proof.
∎

Each line of the table of intermediate configuration
F
behaves similarly to a Gaussian probability density function
f(x)=\frac{1}{\sqrt{2\pi}}e^{-\frac{x^{2}}{2}}
. Like the Gaussian function for

increases as we move rightwards towards the center. In the left half of each row of the difference table

is similar to the behavior of the derivative of the Gaussian

The following lemma shows that if three terms in the difference table weakly increase/decrease, then the two terms below also weakly increase/decrease.

Lemma 9.3
.

Suppose we have
F^{\prime}(x_{0},y_{0}+1)\leq F^{\prime}(x_{0}-1,y_{0}+2)\leq F^{\prime}(x_{0}-2,y_{0}+3)
, then
F^{\prime}(x_{0},y_{0}+2)\leq F^{\prime}(x_{0}-1,y_{0}+3)
. Similarly, if
F^{\prime}(x_{0},y_{0}+1)\geq F^{\prime}(x_{0}-1,y_{0}+2)\geq F^{\prime}(x_{0}-2,y_{0}+3)
, then
F^{\prime}(x_{0},y_{0}+2)\geq F^{\prime}(x_{0}-1,y_{0}+3)
.

Proof.

To de-clutter the proof, let us denote
F(x_{0},y_{0})
by
a
,
F^{\prime}(x_{0},y_{0}+1)
by
d_{1}
,
F^{\prime}(x_{0}-1,y_{0}+2)
by
d_{2}
, and
F^{\prime}(x_{0}-2,y_{0}+3)
by
d_{3}
. We have
d_{1}=F^{\prime}(x_{0},y_{0}+1)=F(x_{0}-1,y_{0}+1)-F(x_{0},y_{0})
,
d_{2}=F^{\prime}(x_{0}-1,y_{0}+2)=F(x_{0}-2,y_{0}+2)-F(x_{0}-1,y_{0}+1)
, and
d_{3}=F^{\prime}(x_{0}-2,y_{0}+3)=F(x_{0}-3,y_{0}+3)-F(x_{0}-2,y_{0}+2)
. In the first part of the lemma, we are given that
d_{1}\leq d_{2}\leq d_{3}
.

We have

F(x_{0}-1,y_{0}+1)=a+d_{1},

F(x_{0}-2,y_{0}+2)=a+d_{1}+d_{2},

F(x_{0}-3,y_{0}+3)=a+d_{1}+d_{2}+d_{3}.

Therefore,

F^{\prime}(x_{0},y_{0}+2)=\left\lfloor\frac{a+d_{1}+d_{2}}{2}\right\rfloor-\left\lfloor\frac{a}{2}\right\rfloor\leq\left\lfloor\frac{a+2d_{2}}{2}\right\rfloor-\left\lfloor\frac{a}{2}\right\rfloor=d_{2}

and

F^{\prime}(x_{0}-1,y_{0}+3)=\left\lfloor\frac{a+d_{1}+d_{2}+d_{3}}{2}\right\rfloor-\left\lfloor\frac{a+d_{1}}{2}\right\rfloor\geq\left\lfloor\frac{a+d_{1}+2d_{2}}{2}\right\rfloor-\left\lfloor\frac{a+d_{1}}{2}\right\rfloor=d_{2}.

The first part of the proposition follows. The second part follows by symmetry.
∎

Theorem 9.4
.

In the left half of the difference table, the entries weakly increase and then weakly decrease.

Proof.

We prove this via induction on row.

For the base case, we look at row
0
and directly observe that the statement is true for that row.

We can consider our rows to be infinite; we can assume that they start with zeros and end with zeros. Adding zeros at the beginning does not change the property that the row starts as weakly decreasing because nonzero terms at the beginning of the row are positive. For our inductive case, we suppose that the left half of row
i
of the difference table first increases weakly, then decreases weakly. We observe that from Lemma
9.3
, if we have three consecutive weakly increasing entries in the difference table, then, directly below, we have two consecutive weakly increasing entries in the next row. Similarly, if we have three consecutive weakly decreasing entries in the difference table, then, directly below, we have two consecutive weakly decreasing entries in the next row. Using this fact and how the difference table first increases weakly and then decreases weakly in the left half of row
i
, we know that the same applies for row
i+1
.
∎
