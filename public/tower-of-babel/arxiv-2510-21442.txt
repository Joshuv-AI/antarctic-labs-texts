Scalable Neural Incentive Design with Parameterized Mean-Field Approximation
Nathan Corecco, Batuhan Yardim *, Vinzenz Thoma, Zebang Shen, Niao He

Abstract
Designing incentives for a multi-agent system to induce a desirable Nash equilibrium is both a crucial and challenging problem appearing in many decision-making domains, especially for a large number of agents N N . Under the exchangeability assumption, we formalize this incentive design (ID) problem as a parameterized mean-field game (PMFG), aiming to reduce complexity via an infinite-population limit. We first show that when dynamics and rewards are Lipschitz, the finite- N N ID objective is approximated by the PMFG at rate 𝒪 ⁡ ( 1 / N ) \mathcal{O}(\nicefrac{{1}}{{\sqrt{N}}}) . Moreover, beyond the Lipschitz-continuous setting, we prove the same 𝒪 ⁡ ( 1 / N ) \mathcal{O}(\nicefrac{{1}}{{\sqrt{N}}}) decay for the important special case of sequential auctions, despite discontinuities in dynamics, through a tailored auction-specific analysis. Built on our novel approximation results, we further introduce our Adjoint Mean-Field Incentive Design (AMID) algorithm, which uses explicit differentiation of iterated equilibrium operators to compute gradients efficiently. By uniting approximation bounds with optimization guarantees, AMID delivers a powerful, scalable algorithmic tool for many-agent (large N N ) ID. Across diverse auction settings, the proposed AMID method substantially increases revenue over first-price formats and outperforms existing benchmark methods.

Introduction

Setting the right incentives in a game with many participants is a challenging and high-stakes problem.
Policymakers must frequently make choices that affect millions, for instance, planners must design rules for curtailing city traffic
ley2025less
,
set pricing to maximize effective bandwidth in telecommunications networks
basar2002revenue
, design spectrum auctions between telecom operators
Klemperer2002How

or manage supply and demand in energy grids
maharjan2013dependable
.

We study the
incentive design
(ID) problem.
Given an objective
G
, a parameterized
N
-player game
\mathcal{G}
, and player strategies
\pi_{1},\ldots,\pi_{N}
, ID solves the equilibrium constrained optimization problem:

\displaystyle\textbf{Maximize }G(\theta,\pi_{1},\ldots,\pi_{N})\textbf{ such that }(\pi_{1},\ldots,\pi_{N})\in\operatorname{Nash}_{\mathcal{G}}(\theta)

(ID)

where
\operatorname{Nash}_{\mathcal{G}}(\theta)
denotes the set of Nash equilibria (NE) of a game for the incentive parameter
\theta
(which is to be learned).
(
ID
) is also referred to in the literature as mathematical programming with equilibrium constraints (MPEC)
Luo1996Mathematical
.
Despite their relevance, MPECs are notoriously computationally challenging and in the general case NP-hard
Jeroslow1985polynomial
;
Luo1996Mathematical
.
Simply computing a Nash equilibrium for a fixed incentive parameter
\theta
is also
PPAD
-complete
daskalakis2009complexity
, even for 2 players
chen2009settling
.
For games with many players, as in many real-world problems, the so-called
curse of many agents

wang2020breaking
becomes an added challenge.
In such cases, computing
\operatorname{Nash}_{\mathcal{G}}(\theta)
becomes prohibitively expensive, let alone tackling (
ID
).

In this work, we take the approach of mean-field approximation for games with agent exchangeability (i.e., symmetry) to tackle this problem.
Instead of solving (
ID
) directly, we construct an appropriate mean-field game (MFG) approximation
\mathcal{M}
to
\mathcal{G}
and solve the mean-field ID (MID) problem:

\displaystyle\textbf{Maximize }G(\theta,\pi_{\text{MFG}})\textbf{ such that }\pi_{\text{MFG}}\in\operatorname{Nash}_{\mathcal{M}}(\theta).

(MID)

For the mean-field approximation (
MID
) to be meaningful, its solution should closely match that of the original
N
-player incentive design problem (
ID
), with the approximation error vanishing as
N\to\infty
. We formalize this requirement in the following desideratum.

Desideratum D1
(Approximation)

The solution of (
MID
) should be a good (approximate) solution for (
ID
), in particular when
N
is large, with explicit guarantees.

MFGs are known to approximate finite-player NEs with explicit bounds for large
N

saldi2018markov
;
carmona2013probabilistic
;
cui2021approximately
;
yardim2024meanfield
.
Under Lipschitz continuity, a non-asymptotic bound of
\mathcal{O}(\nicefrac{{1}}{{\sqrt{N}}})
in exploitability is obtained with a propagation-of-chaos type argument.
By contrast, our problem (
MID
) not only contains the classical MFG as a subproblem but also an incentive objective, accordingly, we must show that the approximation error still vanishes as
N\to\infty
.
Establishing this result is our first contribution.

Contribution 1: Lipschitz PMFGs and Approximation.

We formalize (
MID
) as a parameterized MFG (PMFG), and show that for Lipschitz PMFGs the (
MID
) problem approximates (
ID
) with a rate of
\mathcal{O}(\nicefrac{{1}}{{\sqrt{N}}})
, both in exploitability and optimality of the design objective.

While Lipschitz continuous MFGs cover a broad class of real-world games and are well-studied,
they exclude many important applications, notably large-scale auction design, where the transition dynamics are inherently correlated and non-Lipschitz.
Motivated by the ubiquity and impact of auctions, we analyze (
D1
) beyond Lipschitz PMFGs, which is our second contribution.

Contribution 2: Approximation beyond Lipschitz.

We identify a PMFG for sequential batched auctions (BA-MFG) with many bidders, and establish (
D1
) with an
\mathcal{O}(\nicefrac{{1}}{{\sqrt{N}}})
approximation rate, by identifying a set of “well-behaved” policies that is dense in the set of Nash equilibria.

Although (
D1
) guarantees that the mean-field approximation captures the fundamental solution structure of the
N
-player incentive design problem,
realizing practical benefits from this framework requires the following desideratum.

Desideratum D2
(Optimization)

We would like (
MID
) to be computationally tractable or easier to solve than (
ID
), specifically, admit an efficient first-order oracle that can be used for optimization.

Our algorithmic contribution is to satisfy this desideratum in both settings: (i) PMFGs under Lipschitz continuity assumptions, and (ii) mean-field auction design.

Contribution 3: Algorithmic Contribution.

We formulate our adjoint mean-field incentive design (
AMID
) algorithm for solving (
MID
) efficiently.

AMID
is a modification of backpropagation based on the adjoint method for computing (approximate) derivatives with Nash equilibrium constraints.
While naive autodiff-based approaches incur a large
\mathcal{O}(T)
memory footprint, our reformulation of the gradient computations reduces the memory footprint to
\mathcal{O}(\sqrt{T})
, with up to 80% savings in practice.

Contribution 4: Experimental Contribution.

Finally, we use
AMID
to (i) solve congestion pricing in the classical beach bar MFG, and (ii) design revenue-optimal mechanisms across a variety of sequential auctions with a neural network parameterization.
Our method consistently outperforms standard first-price mechanisms used in practice and other optimization approaches to solve (
MID
).

Beyond Lipschitz: Mechanism Design for Large-Scale Auctions

Auction design is a ubiquitous and well-studied problem of extraordinary economic interest
Krishna2002AuctionTheory
.
To analyze auctions at the mean-field regime, we move beyond the Lipschitz PMFG assumptions.
Designing auctions with maximum revenue in the resulting equilibrium can be framed as an instance of (
ID
) (see our discussion in
Appendix

C
), and with an appropriate PMFG, tackled using
AMID
.
Specifically, we consider the following sequential batched auction setting motivated by real-world formats used for selling government debt, broadcast licenses, mineral rights, art, fish, timber
Gale2001Sequential
, and including transactions in mined Ethereum blocks
Roughgarden2021Transaction
.

(Parameterized) batched auctions.

An
H
-round
N
-player batched auction with incentive parameter
\theta
is a PDG
\mathcal{G}_{\text{auc}}
with state space

\mathcal{S}=\mathcal{V}\cup\{\perp\}
(where the value space
\mathcal{V}:=\{0,...,\nicefrac{{(|\mathcal{V}|-1)}}{{|\mathcal{V}|}}\}
represents possible valuations and
\perp
denotes non-participation in the current round) and action space
\mathcal{A}=\{0,\dots,\nicefrac{{(|\mathcal{A}|-1)}}{{|\mathcal{A}|}}\}
(possible bids).
Each bidder
i\in[N]
at round
h\in[H]
has a private state
s_{h}^{i}\in\mathcal{S}
not revealed to the auctioneer or other bidders.
Overall, the auctioneer sells at most
\lceil\alpha_{\textrm{max}}N\rceil
goods (for some
\alpha_{\textrm{max}}\in(0,1)
) and chooses
\theta
, parameterizing the allocations and payments as outlined below.
The auction evolves for
h\in[H]
as follows:

1.

Initial states at
h=0
are independently sampled from distribution
\mu_{0}\in\Delta_{\mathcal{V}}
.

2.

At every round
h\in[H]
, bidders for which
s_{h}^{i}\neq\perp
submit their bids
a_{h}^{i}\in\mathcal{A}
.

3.

Observing the bid distributions
\widehat{\nu}^{-\perp}_{h}:=\tfrac{1}{N}\sum_{i\in[N]}\mathbf{e}_{a_{h}^{i}}\mathbbm{1}_{s_{h}^{i}\neq\perp}
, the mechanism decides on a ratio of goods to be sold this round,
\alpha_{h}^{\theta}(\widehat{\nu}^{-\perp}_{h})
.
Items are allocated to the highest
\lfloor\alpha_{h}^{\theta}(\widehat{\nu}^{-\perp}_{h})N\rfloor
bidders, with ties broken uniformly at random.

4.

Each bidder
i
who receives an item, makes a payment
p_{h}^{i}=p_{h}^{\theta}(a_{h}^{i},\widehat{\nu}^{-\perp}_{h})\in\mathbb{R}_{\geq 0}
.
A winning bidder receives utility
u_{h}(s_{h}^{i},p_{h}^{i})\in\mathbb{R}
and transitions to state
\perp
, while non-winning and non-participating bidders receive zero utility.

5.

Before proceeding to round
h+1
, each bidder transitions independently to a new state according to a dynamics function
w_{h}:\mathcal{S}\times\Delta_{\mathcal{S}}\rightarrow\Delta_{\mathcal{S}}
, which maps the agent’s current state and the empirical population distribution (after the allocation at round
h
) to a distribution over next states.

To ensure the mechanism can not sell more goods than are available (
\alpha_{\textrm{max}}
),
we assume that the parameterizations of
\alpha_{h}^{\theta}
are such that
\sum_{h}\alpha_{h}^{\theta}(\widehat{\nu}^{-\perp}_{h})\leq\alpha_{\textrm{max}}
almost surely.
This is can be ensured, for example, by parameterizing
\alpha_{h}^{\theta}
as a fraction of
remaining goods
at every
h
.

\mathcal{G}_{\text{auc}}
allows for complex valuation dynamics, such as single-minded bidders (who stay in
\perp
),
time-dependent or population-dependent evolving valuations,
as well as super and subadditive valuations over bundles of goods.
Under these dynamics, we denote the expected utility of player
i
and exploitability as
J_{\text{auc}}^{\tau,i},\mathcal{E}_{\text{auc}}^{\tau,i}
respectively, as defined in
Definition

1
.

We note that parameterizing
\alpha_{h}^{\theta},p_{h}^{\theta}
fully captures the intuition of
reserve prices
in the BA-MFG setting.
In many auction formats, a reserve price, i.e., a minimum price that bidders have to bid and pay to win, has been shown to increase revenue
Myerson1981Optimal
.
A reserve price
r_{h}\in\mathcal{A}
at round
h
can be implemented for example with
\alpha_{h}(\nu)=\sum_{a^{\prime}\geq r_{h}}\nu(a^{\prime})
and
p_{h}(a,\nu)=a
.

3.1
Auctions at the Mean-Field Regime

From the above description,
\mathcal{G}_{\text{auc}}
clearly has exchangeable agents.
However, the corresponding one-step state evolutions are not independent, making
Theorem

1
inapplicable here.
Motivated by the relevance of large-scale auction design, we show that PMFGs are still relevant and (
D1
) holds with a refined analysis of batched auctions in the following.
We begin by defining the correct MFG that characterizes the batch auction at the limit
N\rightarrow\infty
.
While the definition is symbol-laden, we state it for completeness.

Definition 3
(BA-MFG)

A Batched-Auction MFG (BA-MFG) is the PMFG
\mathcal{M}_{\text{mfa}}:=(\mathcal{S},\mathcal{A},H,\mu_{0},\Theta,\{P^{\text{mfa}}_{h,\theta}\}_{h=0}^{H-1},\{R^{\text{mfa}}_{h,\theta}\}_{h=0}^{H-1})

R^{\text{mfa}}_{\theta,h},P^{\text{mfa}}_{\theta,h}
are given by:

\displaystyle R^{\text{mfa}}_{\theta,h}(s,a,L)

\displaystyle:=p_{\text{win}}(s,a,L,\alpha_{h}^{\theta}(\nu^{-\perp}(L)))u_{h}(s,p_{h}(a,\nu^{-\perp}(L)))

\displaystyle P^{\text{mfa}}_{\theta,h}(s^{\prime}|s,a,L)

\displaystyle:=p_{\text{win}}(s,a,L,\alpha_{h}^{\theta}(\nu^{-\perp}(L)))w_{h}(s^{\prime}|\perp,\xi^{L,\theta})

\displaystyle\quad+(1-p_{\text{win}}(s,a,L,\alpha_{h}^{\theta}(\nu^{-\perp}(L))))w_{h}(s^{\prime}|s,\xi^{L,\theta}),

where
\nu^{-\perp}(L):=\sum_{s\neq\perp}L(s,\cdot)
,
\xi^{L,\theta}\in\Delta_{\mathcal{S}}
such that
\xi^{L,\theta}(\perp)=L(\perp)+\langle L,p_{\text{win}}(\cdot,\cdot,L,\alpha_{h}^{\theta}(\nu^{-\perp}(L)))\rangle
and
\xi(s)=\langle L(s,\cdot),p_{\text{win}}(s,\cdot,L,\alpha_{h}^{\theta}(\nu^{-\perp}(L)))\rangle
, and
p_{\text{win}}
defined as
2
2

2

In this definition we take
\nicefrac{{\varepsilon}}{{0}}=\infty

\varepsilon>0
and
\nicefrac{{0}}{{0}}=0

\displaystyle p_{\text{win}}(s,a,L,\alpha):=\mathbbm{1}_{s\neq\perp}\max\left\{0,\min\left\{1,\frac{\alpha-\sum_{s^{\prime}\in\mathcal{V},\,a^{\prime}>a}L(s^{\prime},a^{\prime})}{\nu^{-\perp}(L)(a)}\right\}\right\}.

We use
V_{\text{mfa}}^{\tau},\mathcal{E}_{\text{mfa}}^{\tau}

The intuition behind

In fact,

Existing approximation results (such as

No zero-dominance (NZD) policies, defined below, identify a subset of policy space

Definition 4
(No zero-dominance (NZD))

Let

be a BA-MFG and
\theta\in\Theta
.

\tau>0

Theorem 2
(Approximation for BA-MFG)

Let
\mathcal{M}_{\text{mfa}}
be a BA-MFG with Lipschitz-continuous

and let

Let

be a policy that satisfies the no zero-dominance property with respect to
\theta\in\Theta

Then, for
\boldsymbol{\pi}=(\pi,\dots,\pi)\in\Pi_{H}^{N}

1.

\mathcal{E}_{\text{auc}}^{\tau}(\boldsymbol{\pi}|\theta)\leq\mathcal{E}_{\text{mfa}}^{\tau}(\pi|\theta)+\mathcal{O}\left(\nicefrac{{1}}{{\sqrt{N}}}\right),
for any
\tau\geq 0
,

2.

\left|g(\theta,\Lambda_{\text{mfa}}(\pi|\theta))-G(\theta,\boldsymbol{\pi})\right|\leq\mathcal{O}\left(\nicefrac{{1}}{{\sqrt{N}}}\right)
.

Proof sketch:

The proof builds on (1) special handling of the correlated evolution of
s_{h}^{i}
at any round

The two conclusions are proved separately in Appendices

\square

Conclusion

In this work, we presented a novel method for ID relying on PMFGs.
In particular, we set forth two desiderata in order to use scalable first-order optimization to approximately solve ID problems.
Through new analyses, we demonstrated that these conditions hold in both classical Mean Field Game (MFG) settings and batched auction environments.
For both settings, we presented a unified algorithm, called
AMID
, which can solve a span of ID problems, such as congestion pricing or optimal auction design.
Overall, the AMID framework offers a flexible foundation for diverse incentive design applications, paving the way for future extensions.

Appendix C
Automated Mechanism Design as
ID

We note that in contrast to our approach many works on automated mechanism design focus on designing strategyproof auctions, i.e. auctions in which bidders bid truthful in equilibrium, relying on the so-called
revelation principle
[
20
,
18
,
49
]
. The revelation principle states that any non-strategyproof equilibrium of an auction can be implemented as an outcome equivalent strategyproof equilibrium of an adapted auction
[
43
]
.
Restricting to strategyproof mechanisms bypasses the need to differentiate through an equilibrium. Instead of a problem like (
ID
) where the outer objective depends on an inner equilibrium solution, the inner solution is already known–bid truthfully–and instead the problem becomes one of constrained optimization problem, where the so-called
incentive compatibility
(IC) constraints ensure that bidding truthfully is in fact an equilibrium
[
18
]
.

While restricting to strategyproof mechanisms foregoes the need to differentiate through an equilibrium, many real-world auctions are not strategyproof. In fact, in 2019 Google for example deliberately changed towards non-strategyproof first price auctions for selling ads, citing the increased transparency of simple, non-strategyproof format for the bidders
[
25
]
. In such cases without IC constraints, the question is how bidders will respond in equilibrium and in turn designing revenue-optimal auctions becomes an instance of (
ID
), which we tackle in
Sections

3
and
4
.

Preliminary Lemmas

We present several important lemmas that will be used later to prove the main convergence theorem.

Lemma 6
(Sensitivity of
\Xi_{\alpha}
to the Population)

Let
\alpha\in[0,1]
and let
d,d^{\prime}\in\Delta_{\mathcal{V}\times\mathcal{A}}^{\geq\alpha}
. Then
\Xi_{\alpha}
is Lipschitz-continuous with respect to the
\ell_{1}
-norm, with constant 1:

\|\Xi_{\alpha}(d)-\Xi_{\alpha}(d^{\prime})\|_{1}\leq\|d-d^{\prime}\|_{1}.

Proof:

It is straightforward to verify that
\Xi_{\alpha}
is continuous.
We verify that it is also Lipschitz continuous with modulus 1.
Assume
\alpha>0
, as otherwise
\Xi_{\alpha}(d)
is the identity map and the claim is trivial.
Denote the bids by
\mathcal{A}:=\{1,\ldots,A\}
, and let
S_{a}(d):=\sum_{s^{\prime}}\sum_{a^{\prime}\geq a}d(s^{\prime},a^{\prime})
with
S_{A+1}(d):=0
, and
r_{a}(d):=\sum_{s^{\prime}\in\mathcal{V}}d(s^{\prime},a)
.
For
\bar{a}\in\{1,\ldots,A+1\}
, define the regions

\displaystyle\mathcal{R}_{\bar{a}}:=\{d\in\Delta_{\mathcal{V}\times\mathcal{A}}^{\geq\alpha}:S_{\bar{a}}(d)\geq\alpha>S_{\bar{a}+1}(d)\}.

On the region
\mathcal{R}_{\bar{a}}
, the map
\Xi_{\alpha}(d)
is differentiable, in fact, for
d\in\mathcal{R}_{\bar{a}}
, it holds that
\bar{a}=\operatorname{Th}_{\alpha}(d)
and

\displaystyle\Xi_{\alpha}(d)(s,a)=\begin{cases}0&\text{if }a>\bar{a}\\
\frac{S_{\bar{a}}(d)-\alpha}{r_{\bar{a}}(d)}d(s,\bar{a})&\text{if }a=\bar{a}\\
d(s,a)&\text{otherwise}\end{cases}

We calculate the Jacobian of
\Xi_{\alpha}
and upper bound its operator norm
\|\nabla\Xi_{\alpha}\|_{1\rightarrow 1}
given by the max column sum
\|\nabla\Xi_{\alpha}\|_{1\rightarrow 1}=\max_{s,a}\sum_{s^{\prime},a^{\prime}}|(\nabla\Xi_{\alpha})_{s^{\prime}a^{\prime},sa}|.

We upper bound the column sums corresponding to
s,a
.

Case 1.

If
a<\bar{a}
, then
\frac{\partial\Xi_{\alpha}(d)(s^{\prime},a^{\prime})}{\partial d_{sa}}=0
for any
(s^{\prime},a^{\prime})\neq(s,a)
and
\frac{\partial\Xi_{\alpha}(d)(s,a)}{\partial d_{sa}}=1
, therefore the column sum is

\displaystyle\sum_{s^{\prime},a^{\prime}}\left|\frac{\partial\Xi_{\alpha}(d)(s^{\prime},a^{\prime})}{\partial d_{sa}}\right|=\left|\frac{\partial\Xi_{\alpha}(d)(s,a)}{\partial d_{sa}}\right|=1.

Case 2.

If
a=\bar{a}
, then
\frac{\partial\Xi_{\alpha}(d)(s^{\prime},a^{\prime})}{\partial d_{sa}}=0
if
a^{\prime}\neq\bar{a}
, therefore

\displaystyle\sum_{s^{\prime},a^{\prime}}\left|\frac{\partial\Xi_{\alpha}(d)(s^{\prime},a^{\prime})}{\partial d_{sa}}\right|

\displaystyle=\sum_{s^{\prime}}\left|\frac{\partial\Xi_{\alpha}(d)(s^{\prime},\bar{a})}{\partial d_{s\bar{a}}}\right|=\left|\frac{\partial\Xi_{\alpha}(d)(s,\bar{a})}{\partial d_{s\bar{a}}}\right|+\sum_{s^{\prime}\neq s}\left|\frac{\partial\Xi_{\alpha}(d)(s^{\prime},\bar{a})}{\partial d_{s\bar{a}}}\right|

\displaystyle=\left|\frac{S_{\bar{a}}(d)-\alpha}{r_{\bar{a}}(d)}+d(s,\bar{a})\frac{r_{\bar{a}}(d)-S_{\bar{a}}(d)+\alpha}{r_{\bar{a}}(d)^{2}}\right|

\displaystyle\quad+\sum_{s^{\prime}\neq s}\left|d(s^{\prime},\bar{a})\frac{r_{\bar{a}}(d)-S_{\bar{a}}(d)+\alpha}{r_{\bar{a}}(d)^{2}}\right|=1,

since all terms in the absolute values are nonnegative if
\bar{a}=\operatorname{Th}_{\alpha}(d)
.

Case 3.

If
a>\bar{a}
, then only the rows corresponding to the active action
\bar{a}
has nonzero gradient, and

\displaystyle\sum_{s^{\prime},a^{\prime}}\left|\frac{\partial\Xi_{\alpha}(d)(s^{\prime},a^{\prime})}{\partial d_{sa}}\right|

\displaystyle=\sum_{s^{\prime}}\left|\frac{\partial\Xi_{\alpha}(d)(s^{\prime},\bar{a})}{\partial d_{s\bar{a}}}\right|=\sum_{s^{\prime}}\frac{1}{\sum_{s^{\prime\prime}}d(s^{\prime\prime},\bar{a})}d(s,\bar{a})=1.

To conclude, it holds that on any arbitrary region
\mathcal{R}_{\bar{a}}
,

\displaystyle\|\nabla\Xi_{\alpha}\|_{1\rightarrow 1}=\max_{s,a}\sum_{s^{\prime},a^{\prime}}\left|\frac{\partial\Xi_{\alpha}(d)(s^{\prime},\bar{a})}{\partial d_{s\bar{a}}}\right|=1.

Therefore,
\|\nabla\Xi_{\alpha}\|_{1\rightarrow 1}\leq 1
on all regions
\mathcal{R}_{\bar{a}}
, and
\Xi_{\alpha}
is non-expansive in the
\ell_{1}
norm.

\square

Lemma 7
(Sensitivity of
\Xi_{\alpha}
to the Allocation Parameter)

Let
d\in\Delta_{\mathcal{V}\times\mathcal{A}}^{\leq 1}
arbitrary, let
\alpha_{1},\alpha_{2}\leq\|d\|_{1}
arbitrary. Then

\|\Xi_{\alpha_{1}}(d)-\Xi_{\alpha_{2}}(d)\|_{1}\leq|\alpha_{1}-\alpha_{2}|.

Proof:

As in
Lemma

6
, let
\mathcal{A}:=\{1,\ldots,A\}
, and let
S_{a}(d):=\sum_{s^{\prime}}\sum_{a^{\prime}\geq a}d(s^{\prime},a^{\prime})
with
S_{A+1}(d):=0
, and
r_{a}(d):=\sum_{s^{\prime}\in\mathcal{V}}d(s^{\prime},a)
.

For
\bar{a}\in\{1,\ldots,A+1\}
such that
r_{\bar{a}}(d)>0
, define the partition of the interval
[0,\|d\|_{1}]
into the intervals

\displaystyle\mathcal{R}_{\bar{a}}:=\{\alpha\in[0,\|d\|_{1}]:S_{\bar{a}}(d)\geq\alpha>S_{\bar{a}+1}(d)\}.

On the interval
\mathcal{R}_{\bar{a}}
, the map
\Xi_{\alpha}(d)
is differentiable in
\alpha
, and it holds that
\bar{a}=\operatorname{Th}_{\alpha}(d)
and

\displaystyle\Xi_{\alpha}(d)(s,a)=\begin{cases}0&\text{if }a>\bar{a}\\
\frac{S_{\bar{a}}(d)-\alpha}{r_{\bar{a}}(d)}d(s,\bar{a})&\text{if }a=\bar{a}\\
d(s,a)&\text{otherwise}\end{cases}

Then, again, we upper bound the operator norm of the Jacobian (in this case, gradient):

\displaystyle\|\nabla_{\alpha}\Xi_{\alpha}(d)\|_{1\rightarrow 1}=

\displaystyle\sum_{s^{\prime},a^{\prime}}\left|\frac{\partial\Xi_{\alpha}(d)(s^{\prime},a^{\prime})}{\partial\alpha}\right|=\sum_{s^{\prime}}\left|\frac{-1}{r_{\bar{a}}(d)}d(s^{\prime},\bar{a})\right|=1,

So
\|\nabla_{\alpha}\Xi_{\alpha}(d)\|_{1\rightarrow 1}\leq 1
, implying the claim of the lemma.

\square

For completeness, we state the simple corollaries of the above two sensitivity analyses in the following.

Corollary 1
(Lipschitz Continuity of
\Xi
)

Let
d,d^{\prime}\in\Delta_{\mathcal{V}\times\mathcal{A}}^{\leq 1},\alpha\in[0,\|d\|_{1}),
and
\alpha^{\prime}\in[0,\|d^{\prime}\|_{1})
arbitrary, then

\|\Xi_{\alpha}(d)-\Xi_{\alpha^{\prime}}(d^{\prime})\|_{1}\leq\|d-d^{\prime}\|_{1}+|\alpha-\alpha^{\prime}|.

Proof:

Let
d,d^{\prime}\in\Delta_{\mathcal{V}\times\mathcal{A}}^{\leq 1},\alpha\in[0,\|d\|_{1}),
and
\alpha^{\prime}\in[0,\|d^{\prime}\|_{1})
arbitrary. Without loss of generality assume
\|d\|_{1}\geq\|d^{\prime}\|_{1}
, then by applying triangular inequality we have

\displaystyle\|\Xi_{\alpha}(d)-\Xi_{\alpha^{\prime}}(d^{\prime})\|_{1}

\displaystyle\leq\|\Xi_{\alpha}(d)-\Xi_{\alpha^{\prime}}(d)\|_{1}+\|\Xi_{\alpha^{\prime}}(d)-\Xi_{\alpha^{\prime}}(d^{\prime})\|_{1}\leq|\alpha-\alpha^{\prime}|+\|d-d^{\prime}\|_{1},

where the last step follows from
Lemmas

6
and
7
.

\square

Corollary 2
(Lipschitz Continuity of
\Upsilon_{\alpha}
)

Let
d,d^{\prime}\in\Delta_{\mathcal{V}\times\mathcal{A}}^{\leq 1},\alpha\in[0,\|d\|_{1}),
and
\alpha^{\prime}\in[0,\|d^{\prime}\|_{1})
arbitrary, then
\Upsilon_{\alpha}
is non-expansive in the
\ell_{1}
norm, that is

\|\Upsilon_{\alpha}(d)-\Upsilon_{\alpha^{\prime}}(d^{\prime})\|_{1}\leq|\alpha-\alpha^{\prime}|+\|d-d^{\prime}\|_{1}.

Proof:

Let

and
\alpha^{\prime}\in[0,\|d^{\prime}\|_{1})
arbitrary, then

\displaystyle\|\Upsilon_{\alpha}(d)-\Upsilon_{\alpha^{\prime}}(d^{\prime})\|_{1}

\displaystyle=\left\|\sum_{a\in\mathcal{A}}\Xi_{\alpha}(d)(\cdot,a)-\sum_{a\in\mathcal{A}}\Xi_{\alpha^{\prime}}(d^{\prime})(\cdot,a)\right\|_{1}

\displaystyle\leq\sum_{a\in\mathcal{A}}\|\Xi_{\alpha}(d)(\cdot,a)-\Xi_{\alpha^{\prime}}(d^{\prime})(\cdot,a)\|_{1}=\|\Xi_{\alpha}(d)-\Xi_{\alpha^{\prime}}(d^{\prime})\|_{1}.

The upper bound follows by the result of

1
.

\square

Corollary 3
(Lipschitz Continuity of
\Gamma_{\alpha}
)

Let

, and suppose the threshold function

, and satisfies the feasibility condition

By

and the Lipschitz continuity of

, it follows that:

\displaystyle\|\Gamma_{\alpha}(d)-\Gamma_{\alpha}(d^{\prime})\|_{1}

In the next sequence of results, we deal with the stability of winning probabilities given by the function
p_{\text{win}}
.
In general,
p_{\text{win}}
is easily seen to have discontinuous jumps, however, a local stability result can be shown if the NZD condition holds.

Lemma 8
(Stability of Winning Probabilities)

Let
\mathcal{A}=\{a_{1},a_{2},\dots,a_{K}\}
be a finite set of actions with total order
a_{1}<a_{2}<\dots<a_{K}
, and let
\nu\in\Delta_{\mathcal{A}}^{\leq 1}
.
For any
\alpha\in[0,1]
, define the winning probability for action
a\in\mathcal{A}
as

\displaystyle p_{\text{win}}(a,\nu,\alpha):=\begin{cases}0&\text{if }\sum_{a^{\prime}>a}\nu(a^{\prime})\geq\alpha\text{ or }\alpha=0,\\
1&\text{if }\sum_{a^{\prime}\geq a}\nu(a^{\prime})\leq\alpha\text{ and }\alpha>0,\\
\frac{\alpha-\sum_{a^{\prime}>a}\nu(a^{\prime})}{\nu(a)}&\text{otherwise}.\end{cases}

Assume that
\alpha,\nu
satisfy the no zero-dominance property (i.e., for any
a\in\mathcal{A}
,
\nu(a)=0\Rightarrow\sum_{a^{\prime}>a}\nu(a^{\prime})<\alpha(\nu)
) and
\|\nu\|_{1}>0
.
Then for all
\nu^{\prime}\in\Delta_{\mathcal{A}}^{\leq 1},\alpha^{\prime}\in[0,1],a\in\mathcal{A}
,
p_{\text{win}}
satisfies

\displaystyle\left|p_{\text{win}}(a,\nu,\alpha)-p_{\text{win}}(a,\nu^{\prime},\alpha^{\prime})\right|\leq C_{\nu,\alpha}\|\nu-\nu^{\prime}\|_{1}+C_{\nu,\alpha}|\alpha-\alpha^{\prime}|,

where:

\displaystyle C_{\nu,\alpha}=\begin{cases}\frac{1}{\min\{\nu(a^{*})\}}&,\text{if }\alpha=0\\
\frac{1}{\min\{\nu(a^{*}),\nu(a^{-}),\Delta_{\nu,\alpha}\}}&,\text{if }\Delta_{\nu,\alpha}>0,a^{-}\neq\perp,\alpha>0\\
\frac{1}{\min\{\nu(a^{*}),\Delta_{\nu,\alpha}\}}&,\text{if }\Delta_{\nu,\alpha}>0,a^{-}=\perp,\alpha>0\\
\frac{1}{\min\{\nu(a^{*}),\nu(a^{-})\}}&,\text{if }\Delta_{\nu,\alpha}=0,a^{-}\neq\perp,\alpha>0\\
\frac{1}{\min\{\nu(a^{*})\}}&,\text{if }\Delta_{\nu,\alpha}=0,a^{-}=\perp,\alpha>0\\
\end{cases}

and where
a^{*}:=\operatorname{Th}_{\alpha}(\nu)
is the threshold action,

a^{-}
is the action just below the threshold (
a^{-}:=a_{k-1}
if
a^{*}=a_{k}
for some
k>1
and
a^{-}=\perp
if
a^{*}=a_{1}
),
and
\Delta_{\nu,\alpha}:=\min_{a\in\mathcal{A}}\left|\alpha-\sum_{a^{\prime}\succeq a}\nu(a^{\prime})\right|
.

Proof:

Importantly,
C_{\nu,\alpha}
is finite in each case if
\nu,L
satisfies the NZD condition.
The proof, while notionally dense, works on a simple idea: in general,
p_{\text{win}}
incorporates discontinuities where the winning probability of an action below the threshold might jump from
0
to
1
.
However, this does not happen
locally
when there is some probability mass on
a^{-}
just below the threshold action.
Note that when
\|\nu\|_{1}\neq 0
and NZD holds, it holds that
\nu(a^{*})>0,
and
\nu(a^{-})>0
if
a^{*}\neq a_{1}
and
\alpha>0
.
Furthermore, by NZD, if
\alpha=0
, it must hold that
\nu(a_{K})>0
and
a^{*}=a_{K}
by definition.
Define the useful constant

\displaystyle\delta:=\begin{cases}\Delta_{\nu,\alpha},&\text{ if }\Delta_{\nu,\alpha}>0,\\
\max\{\nicefrac{{1}}{{\nu(a^{*})}},\nicefrac{{1}}{{\nu(a^{-})}}\},&\text{ if }\Delta_{\nu,\alpha}=0,a^{-}\neq\perp\\
\nicefrac{{1}}{{\nu(a^{*})}},&\text{ if }\Delta_{\nu,\alpha}=0,a^{-}=\perp\\
\end{cases}

which will be the radius of the open set around which there are no discontinuities of
p_{\text{win}}
.

First, we show that
\left|p_{\text{win}}(a,\nu,\alpha)-p_{\text{win}}(a,\nu,\alpha^{\prime})\right|\leq C_{\nu,\alpha}|\alpha-\alpha^{\prime}|
for any
\alpha^{\prime}
.
Without loss of generality, we can assume that
\alpha\leq\|\nu\|_{1},\alpha^{\prime}\leq\|\nu\|_{1}
, as
p_{\text{win}}(a,\nu,\alpha^{\prime})=p_{\text{win}}(a,\nu,\min\{\alpha^{\prime},\|\nu\|_{1}\})
for any
\alpha^{\prime}
by definition, and
|\min\{\alpha,\|\nu\|_{1}\}-\min\{\alpha^{\prime},\|\nu\|_{1}\}|\leq|\alpha-\alpha^{\prime}|
.
If
|\alpha-\alpha^{\prime}|<\delta
, then
\alpha^{\prime}\in(\alpha-\delta,0,\alpha+\delta)\cap\mathbb{R}_{\geq 0}
.
On the interval
(\alpha-\delta,\alpha+\delta)\cap\mathbb{R}_{\geq 0}
,
p_{\text{win}}
is continuous for any
a
since

\displaystyle\text{For }a<a^{*},a\neq a^{-}:\quad

\displaystyle p_{\text{win}}(a,\nu,\alpha^{\prime})=0,

\displaystyle\text{For }a>a^{*}:\quad

\displaystyle p_{\text{win}}(a,\nu,\alpha^{\prime})=1,

\displaystyle\text{For }a=a^{*}:\quad

\displaystyle p_{\text{win}}(a^{*},\nu,\alpha^{\prime})=\begin{cases}1&\text{if }\sum_{a^{\prime}\geq a^{*}}\nu(a^{\prime})\leq\alpha^{\prime},\\
\frac{\alpha^{\prime}-\sum_{a^{\prime}>a^{*}}\nu(a^{\prime})}{\nu(a^{*})}&\text{otherwise}.\end{cases}

\displaystyle\text{For }a=a^{-},\text{ if }a^{-}\neq\perp:\quad

\displaystyle p_{\text{win}}(a^{-},\nu,\alpha^{\prime})=\begin{cases}0&\text{if }\sum_{a^{\prime}>a^{-}}\nu(a^{\prime})\geq\alpha^{\prime},\\
\frac{\alpha^{\prime}-\sum_{a^{\prime}>a^{-}}\nu(a^{\prime})}{\nu(a^{-})}&\text{otherwise}.\end{cases}

Moreover, from above,
p_{\text{win}}
is almost everywhere differentiable in
\alpha^{\prime}
in this interval with

\displaystyle\left|\frac{\partial p_{\text{win}}(a,\nu,\alpha)}{\partial\alpha}\right|\leq\begin{cases}\max\{\nicefrac{{1}}{{\nu(a^{-})}},\nicefrac{{1}}{{\nu(a^{*})}}\},\text{ if }a^{*}\neq a_{1},\alpha>0\\
\nicefrac{{1}}{{\nu(a^{*})}},\text{ otherwise }\end{cases}

as in this interval the “active” threshold action will always be either
a^{*}
of
a^{-}
.
Therefore,

\displaystyle\left|p_{\text{win}}(a,\nu,\alpha)-p_{\text{win}}(a,\nu,\alpha^{\prime})\right|\leq C_{\nu,\alpha}|\alpha-\alpha^{\prime}|.

If on the other hand
|\alpha-\alpha^{\prime}|\geq\delta
, then

\displaystyle\left|p_{\text{win}}(a,\nu,\alpha)-p_{\text{win}}(a,\nu,\alpha^{\prime})\right|\leq 1\leq\delta^{-1}|\alpha-\alpha^{\prime}|\leq C_{\nu,\alpha}|\alpha-\alpha^{\prime}|.

So in both cases it holds that
\left|p_{\text{win}}(a,\nu,\alpha)-p_{\text{win}}(a,\nu,\alpha^{\prime})\right|\leq C_{\nu,\alpha}|\alpha-\alpha^{\prime}|.

Next, we show the stability in
\nu
.
Once again, assume that
\|\nu^{\prime}-\nu\|_{1}<\delta
.
On the open set
\{\nu^{\prime}:\|\nu^{\prime}-\nu\|_{1}<\delta\}
the function
p_{\text{win}}(a,\cdot,\alpha)
is once again continuous in
\nu^{\prime}
for any
a
, and almost everywhere differentiable with

\displaystyle\left|\frac{\partial p_{\text{win}}(a,\nu^{\prime},\alpha)}{\partial\nu^{\prime}(a^{\prime})}\right|\leq\begin{cases}\frac{1}{\nu(a^{*})},&\text{ if }a^{-}=\perp\text{ or }\alpha=0\\
\frac{1}{\min\{\nu(a^{*}),\nu(a^{-})\}},&\text{ if }a^{-}\neq\perp,\alpha>0\\
\end{cases}

for almost every
\nu^{\prime}
.
Therefore, it holds that

\displaystyle\left|p_{\text{win}}(a,\nu^{\prime},\alpha)-p_{\text{win}}(a,\nu,\alpha)\right|\leq C_{\nu,\alpha}\|\nu-\nu^{\prime}\|_{1}.

On the other hand, if
\|\nu^{\prime}-\nu\|_{1}\geq\delta
, then

\displaystyle\left|p_{\text{win}}(a,\nu^{\prime},\alpha)-p_{\text{win}}(a,\nu,\alpha)\right|\leq 1\leq\delta^{-1}\|\nu-\nu^{\prime}\|_{1}.

To complete the proof, we use the triangle inequality:

\displaystyle\left|p_{\text{win}}(a,\nu^{\prime},\alpha^{\prime})-p_{\text{win}}(a,\nu,\alpha)\right|\leq\left|p_{\text{win}}(a,\nu,\alpha^{\prime})-p_{\text{win}}(a,\nu,\alpha)\right|+\left|p_{\text{win}}(a,\nu,\alpha^{\prime})-p_{\text{win}}(a,\nu^{\prime},\alpha^{\prime})\right|

\square

Lemma 9

Let
\mu,\mu^{\prime}\in\Delta_{\mathcal{S}}
be two arbitrary state distributions, and let
\pi,\pi^{\prime}\in\Pi
be two arbitrary policies. Define the corresponding state-action distributions
L,L^{\prime}\in\Delta_{\mathcal{S}\times\mathcal{A}}
as

L(s,a):=\mu(s)\pi(a|s),\qquad L^{\prime}(s,a):=\mu^{\prime}(s)\pi^{\prime}(a|s).

Then, it holds that

\|L-L^{\prime}\|_{1}\leq\sup_{s}\|\pi(\cdot|s)-\pi^{\prime}(\cdot|s)\|_{1}+\|\mu-\mu^{\prime}\|_{1}.

Proof:

We compute the total variation distance:

\displaystyle\|L-L^{\prime}\|_{1}

\displaystyle=\sum_{s,a}\left|\mu(s)\pi(a|s)-\mu^{\prime}(s)\pi^{\prime}(a|s)\right|

\displaystyle=\sum_{s,a}\left|\mu(s)\pi(a|s)-\mu(s)\pi^{\prime}(a|s)+\mu(s)\pi^{\prime}(a|s)-\mu^{\prime}(s)\pi^{\prime}(a|s)\right|

\displaystyle\leq\sum_{s}\mu(s)\sum_{a}\left|\pi(a|s)-\pi^{\prime}(a|s)\right|+\sum_{s}|\mu(s)-\mu^{\prime}(s)|\sum_{a}\pi^{\prime}(a|s)

\displaystyle=\sup_{s}\|\pi(\cdot|s)-\pi^{\prime}(\cdot|s)\|_{1}+\|\mu-\mu^{\prime}\|_{1},

where the last line uses that
\sum_{a}\pi^{\prime}(a|s)=1
for all
s
.

\square

E.3
Proof of
Theorem

2
, part 1 (Approximation in Exploitability)

The theorem considers BA-MFGs with Lipschitz-continuous reward, dynamics, and utility functions.
Let
K_{w}\in[0,2]
denote the Lipschitz modulus of the state dynamics
w_{h}
,

K_{p}
the Lipschitz modulus of the payment function
p_{h}
,

K_{u}
the Lipschitz modulus of the utility function
u_{h}
with respect to its second argument,
and
K_{\alpha}
be the Lipschitz modulus of the allocation funciton
\alpha_{h}
.
That is, for any
s\in\mathcal{V},a\in\mathcal{A},\nu,\nu^{\prime}\in\Delta_{\mathcal{A}},p,p^{\prime}\in\mathbb{R}_{\geq 0}
,

\displaystyle\left|u_{h}(s,p)-u_{h}(s,p^{\prime})\right|\leq K_{u}\cdot\left|p-p^{\prime}\right|,

\displaystyle\qquad\left|p_{h}(a,\nu)-p_{h}(a,\nu^{\prime})\right|\leq K_{p}\cdot\|\nu-\nu^{\prime}\|_{1},

\displaystyle\left|\alpha_{h}(\nu)-\alpha_{h}(\nu^{\prime})\right|

\displaystyle\leq K_{\alpha}\cdot\|\nu-\nu^{\prime}\|_{1}.

The composed function
u_{h}(s,p_{h}(a,\nu))
then is
also Lipschitz with modulus
K_{u}K_{p}
as

\left|u_{h}(s,p_{h}(a,\nu))-u_{h}(s,p_{h}(a,\nu^{\prime}))\right|\leq K_{u}\cdot\left|p_{h}(a,\nu)-p_{h}(a,\nu^{\prime})\right|\leq K_{u}K_{p}\cdot\|\nu-\nu^{\prime}\|_{1},

for all
\nu,\nu^{\prime}\in\Delta_{\mathcal{A}}^{\leq 1}
.

Additionally, let
B_{p}
be an upper bound on the absolute value of payments, i.e.,
|p_{h}(a,\nu)|\leq B_{p}
, and let
B_{u}
be an upper bound on the absolute value of utilities, i.e.,
|u_{h}(s,p)|\leq B_{u}
, for all
s,a,\nu,h
.
Such an upper bound always exists if
u_{h},p_{h}
are continuous in
\nu
, since
\Delta_{\mathcal{A}}^{\leq 1}
is a compact set.

The argument proceeds in three steps:

1.

First, we bound the expected deviation between the empirical distributions and their mean field counterparts.
That is, we show an upper bound on the deviation
\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]
.

2.

Second, we show that for policies satisfying the no zero-dominance property, the expected transition probabilities associated with item allocation, under both the mean field and finite-population settings, differ proportionally to the deviation in population distributions.

3.

Finally, we bound the exploitability of a single agent when all other agents follow a policy that satisfies the no zero-dominance property with respect to the mechanism.

In our analysis, we also make use of the population distribution
\xi_{h}
after item allocation at round
h
. In the mean field setting, this is defined as
\xi_{h}:=\Gamma_{\alpha_{h}}(L_{h})
,
where
L_{h}\in\Delta_{\mathcal{S}\times\mathcal{A}}
is the state-action distribution at round
h
, and the operator
\Gamma_{\alpha_{h}}
captures the expected post-allocation state distribution under the mechanism (e.g., by marking winners as inactive).
This quantity serves as the input to the state transition function
w_{h}
in the MFG dynamics. In the finite-agent setting, we denote the analogous empirical quantity by
\widehat{\xi}_{h}
, representing the empirical distribution over states immediately after allocation.
We also define the random variables
\{z_{h}^{i}\}
as
z_{h}^{i}=\perp
if agent
i
was not active in round
h
(i.e.
s_{h}^{i}=\perp
) or agent
i
won the the auction in round
h
, and
z_{h}^{i}=s_{h}^{i}
otherwise.
With this definition,

\displaystyle\widehat{\xi}_{h}=\frac{1}{N}\sum_{i=1}^{N}\mathbf{e}_{z_{h}^{i}}\in\Delta_{\mathcal{S}}.

Finally, we define the constants used in our convergence analysis as follows. Define

\displaystyle K_{s}

\displaystyle:=\sup_{s,s^{\prime},\xi}\|w(s,\xi)-w(s^{\prime},\xi)\|_{1},\quad K_{\xi}:=K_{w}+\frac{1}{2}K_{s}.

Step 1: Expected Deviation of Empirical Distributions

We derive explicit bounds on the expected deviation between the empirical distributions and their mean field counterparts. In particular, we bound the deviations for the state distribution and the state-action distribution.

Lemma 10

Let
\mathcal{M}_{\text{mfa}}=(\mathcal{S},\mathcal{A},H,\mu_{0},\{P^{\text{mfa}}_{h}\}_{h=0}^{H-1},\{R^{\text{mfa}}_{h}\}_{h=0}^{H-1})
define a BA-MFG.
Consider the corresponding finite-agent Batched Auction model with
N
agents,
\mathcal{G}_{\text{auc}}
, which is approximated by
\mathcal{M}_{\text{mfa}}
. Let
\boldsymbol{\pi}=\{\pi_{h}^{i}\}_{h=0,\dots,H-1,\,i\in[N]}\in\Pi_{H}^{N}
denote the joint policy of the population. Denote by
\widehat{\mu}_{h}\in\Delta_{\mathcal{S}}
the empirical state distribution and by
\widehat{L}_{h}\in\Delta_{\mathcal{S}\times\mathcal{A}}
the empirical state-action distribution at round
h
.

Let
\overline{\pi}\in\Pi_{H}
arbitrary, and define the associated mean field state-action distribution flow
L^{\overline{\pi}}:=\Lambda_{\text{mfa}}(\overline{\pi})
, with corresponding marginal state distribution
\mu_{h}^{\overline{\pi}}:=\sum_{a}L_{h}^{\overline{\pi}}(\cdot,a)
. Then, for all
h\in\{0,\dots,H-1\}
, the following bound holds:

\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]\leq\mathbb{E}\left[\|\mu_{h}^{\overline{\pi}}-\widehat{\mu}_{h}\|_{1}\right]+\frac{1}{N}\sum_{i\in[N]}\|\overline{\pi}_{h}-\pi_{h}^{i}\|_{1}+\sqrt{\frac{|\mathcal{A}||\mathcal{S}|}{N}}.

Proof:

We decompose the deviation:

\displaystyle\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\middle|\{s_{h}^{i}\}_{i,h}\right]

\displaystyle\leq\underbrace{\|L_{h}^{\overline{\pi}}-\mathbb{E}[\widehat{L}_{h}|\{s_{h}^{i}\}_{i,h}]\|_{1}}_{(\square)}+\underbrace{\mathbb{E}\left[\left\|\widehat{L}_{h}-\mathbb{E}[\widehat{L}_{h}|\{s_{h}^{i}\}_{i,h}]\right\|_{1}\middle|\{s_{h}^{i}\}_{i,h}\right]}_{(\triangle)}.

We bound the two terms separately.
For
(\square)
, define
L\in\Delta_{\mathcal{S}\times\mathcal{A}}
as
L(s,a)=\widehat{\mu}_{h}(s)\overline{\pi}(a|s)=\frac{1}{N}\sum_{i\in N}\mathbbm{1}_{s_{h}^{i}=s}\overline{\pi}(a|s)
.
We (almost surely) have:

\displaystyle\|L_{h}^{\overline{\pi}}-\mathbb{E}[\widehat{L}_{h}|\{s_{h}^{i}\}_{i,h}]\|_{1}

\displaystyle\leq\|L_{h}^{\overline{\pi}}-L\|_{1}+\|\mathbb{E}[\widehat{L}_{h}|\widehat{\mu}_{h}]-L\|_{1}

\displaystyle\leq\sum_{s\in\mathcal{S}}\sum_{a\in\mathcal{A}}|\mu_{h}^{\overline{\pi}}(s)\overline{\pi}(a|s)-\widehat{\mu}_{h}(s)\overline{\pi}(a|s)|+\|\mathbb{E}[\widehat{L}_{h}|\{s_{h}^{i}\}_{i,h}]-L\|_{1}

\displaystyle\leq\|\mu_{h}^{\overline{\pi}}-\widehat{\mu}_{h}\|_{1}+\frac{1}{N}\sum_{i\in[N]}\sum_{a\in\mathcal{A}}|\overline{\pi}(a|s_{h}^{i})-\pi_{h}^{i}(a|s_{h}^{i})|

\displaystyle\leq\|\mu_{h}^{\overline{\pi}}-\widehat{\mu}_{h}\|_{1}+\frac{1}{N}\sum_{i\in[N]}\|\overline{\pi}_{h}-\pi_{h}^{i}\|_{1}.

For the second term
(\triangle)
, by applying Jensen’s inequality, we have:

\displaystyle\mathbb{E}\left[\left\|\widehat{L}_{h}-\mathbb{E}[\widehat{L}_{h}|\{s_{h}^{i}\}_{i,h}]\right\|_{1}\middle|\{s_{h}^{i}\}_{i,h}\right]

\displaystyle=\sum_{s\in\mathcal{S}}\sum_{a\in\mathcal{A}}\mathbb{E}\left[\left|\widehat{L}_{h}(s,a)-\mathbb{E}[\widehat{L}_{h}(s,a)|\{s_{h}^{i}\}_{i,h}]\right|\middle|\{s_{h}^{i}\}_{i,h}\right]

\displaystyle\leq\sum_{s\in\mathcal{S}}\sum_{a\in\mathcal{A}}\sqrt{\Varop\mathopen{}\left[\widehat{L}_{h}(s,a)\middle|\{s_{h}^{i}\}_{i,h}\right]}

\displaystyle=\frac{1}{N}\sum_{s\in\mathcal{S}}\sum_{a\in\mathcal{A}}\sqrt{\sum_{i\in[N],s_{h}^{i}=s}\pi_{h}^{i}(a|s)(1-\pi_{h}^{i}(a|s))}.

Applying Cauchy-Schwarz’s inequality, we get for any
s\in\mathcal{S}
:

\displaystyle\sum_{a\in\mathcal{A}}\sqrt{\sum_{i\in[N],s_{h}^{i}=s}\pi_{h}^{i}(a|s)(1-\pi_{h}^{i}(a|s))}

\displaystyle\leq\sqrt{|\mathcal{A}|\sum_{a\in\mathcal{A}}\sum_{i\in[N],s_{h}^{i}=s}\pi_{h}^{i}(a|s)(1-\pi_{h}^{i}(a|s))}

\displaystyle\leq\sqrt{|\mathcal{A}|\sum_{a\in\mathcal{A}}\sum_{i\in[N],s_{h}^{i}=s}\pi_{h}^{i}(a|s)}

\displaystyle\leq\sqrt{N|\mathcal{A}|\widehat{\mu}_{h}(s)}.

By integrating this result into the previous computation and using Cauchy-Schwarz’s inequality, we get:

\displaystyle\mathbb{E}\left[\left\|\widehat{L}_{h}-\mathbb{E}[\widehat{L}_{h}|\{s_{h}^{i}\}_{i,h}]\right\|_{1}\middle|\{s_{h}^{i}\}_{i,h}\right]

\displaystyle=\frac{1}{N}\sum_{s\in\mathcal{S}}\sum_{a\in\mathcal{A}}\sqrt{\sum_{i\in[N],s_{h}^{i}=s}\pi_{h}^{i}(a|s)(1-\pi_{h}^{i}(a|s))}

\displaystyle\leq\frac{\sqrt{|\mathcal{A}|}}{\sqrt{N}}\sum_{s\in\mathcal{S}}\sqrt{\widehat{\mu}_{h}(s)}\leq\sqrt{\frac{|\mathcal{A}||\mathcal{S}|}{N}\sum_{s\in\mathcal{S}}\widehat{\mu}_{h}(s)}\leq\sqrt{\frac{|\mathcal{A}||\mathcal{S}|}{N}}.

Combining the upper bounds derived for terms
(\square)
and
(\triangle)
, we obtain the desired result, as
\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]=\mathbb{E}\left[\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\middle|\{s_{h}^{i}\}_{i,h}\right]\right]
.

\square

Lemma 11
(Deviation Between Empirical and Mean Field Population)

Let
\mathcal{M}_{\text{mfa}}=(\mathcal{S},\mathcal{A},H,\mu_{0},\{P^{\text{mfa}}_{h}\}_{h=0}^{H-1},\{R^{\text{mfa}}_{h}\}_{h=0}^{H-1})
be a BA-MFG.
Let
\{\alpha_{h}\}_{h=0}^{H-1}
,
\{w_{h}\}_{h=0}^{H-1}
,
\{p_{h}\}_{h=0}^{H-1}
, and
\{u_{h}\}_{h=0}^{H-1}
denote the allocation thresholds, transition dynamics, payment, and utility functions, respectively, from which
\{P^{\text{mfa}}_{h}\}_{h=0}^{H-1}
and
\{R^{\text{mfa}}_{h}\}_{h=0}^{H-1}
are derived. Assume these functions are Lipschitz continuous, with respective Lipschitz constants
K_{\alpha}
,
K_{w}
,
K_{p}
, and
K_{u}
.

Consider the corresponding finite-agent Batched Auction model with
N
agents
\mathcal{G}_{\text{auc}}
, which is approximated by
\mathcal{M}_{\text{mfa}}
. Let
\boldsymbol{\pi}=\{\pi_{h}^{i}\}_{h=0,\dots,H-1,\,i\in[N]}\in\Pi_{H}^{N}
denote the joint policy of the population. For each round
h
, denote by
\widehat{L}_{h}\in\Delta_{\mathcal{S}\times\mathcal{A}}
the empirical state-action distribution and by
\widehat{\mu}_{h}\in\Delta_{\mathcal{S}}
the corresponding empirical state distribution.

Let
\overline{\pi}\in\Pi_{H}
be an arbitrary policy, and define the associated mean field state-action distribution flow
L^{\overline{\pi}}:=\Lambda_{\text{mfa}}(\overline{\pi})
, with corresponding marginal state distribution
\mu_{h}^{\overline{\pi}}:=\sum_{a}L_{h}^{\overline{\pi}}(\cdot,a)
. Then, for all
h\in\{0,\dots,H-1\}
, it holds that

\displaystyle\mathbb{E}\left[\|\mu_{h}^{\overline{\pi}}-\widehat{\mu}_{h}\|_{1}\right]

\displaystyle\leq\frac{1-(K_{\xi}(1+K_{\alpha}))^{h+1}}{1-K_{\xi}(1+K_{\alpha})}\frac{\sqrt{|\mathcal{S}|}}{\sqrt{N}}

\displaystyle\quad+K_{\xi}\frac{1-(K_{\xi}(1+K_{\alpha}))^{h}}{1-K_{\xi}(1+K_{\alpha})}\biggl(\frac{\sqrt{|\mathcal{S}|}}{2\sqrt{N}}+\frac{1}{N}+(1+K_{\alpha})\frac{\sqrt{|\mathcal{S}||\mathcal{A}|}}{\sqrt{N}}\biggr)

\displaystyle\quad+\sum_{h^{\prime}<h}(K_{\xi}\cdot(K_{\alpha}+1))^{h-h^{\prime}}\cdot\frac{1}{N}\sum_{i\in[N]}\|\overline{\pi}_{h^{\prime}}-\pi_{h^{\prime}}^{i}\|_{1},

if
K_{\xi}(1+K_{\alpha})\neq 1
, and

\displaystyle\mathbb{E}\left[\|\mu_{h}^{\overline{\pi}}-\widehat{\mu}_{h}\|_{1}\right]

\displaystyle\leq(h+1)\frac{\sqrt{|\mathcal{S}|}}{\sqrt{N}}+h\frac{\sqrt{|\mathcal{S}||\mathcal{A}|}}{\sqrt{N}}+hK_{\xi}\biggl(\frac{\sqrt{|\mathcal{S}|}}{2\sqrt{N}}+\frac{1}{N}\biggr)

\displaystyle\quad+\sum_{h^{\prime}<h}\frac{1}{N}\sum_{i\in[N]}\|\overline{\pi}_{h^{\prime}}-\pi_{h^{\prime}}^{i}\|_{1},

if
K_{\xi}(1+K_{\alpha})=1
.

Proof:

Let
\{s_{h}^{i}\}_{h=0,\dots,H-1,i\in[N]},\{a_{h}^{i}\}_{h=0,\dots,H-1,i\in[N]}
and
\{z_{h}^{i}\}_{h=0,\dots,H-1,i\in[N]}
as in
Definition

6
.
We prove the lemma inductively over
h
.
For
h=0
we have
\mu_{0}^{\overline{\pi}}=\mu_{0}=\mathbb{E}[\widehat{\mu}_{0}]
.
Let
X_{s}:=\sum_{i\in[N]}\mathbbm{1}_{\{s_{0}^{i}=s\}}
, which is by definition
X_{s}
a binomial random variable with parameters
N
and
\mu_{0}(s)
.
Since it is a sum of independent Bernoulli random variables, its variance is
\Varop\mathopen{}\left[X_{s}\right]=N\mu_{0}(s)(1-\mu_{0}(s))
.
By using Jensen’s, we can upper bound the expected absolute deviation for each state
s\in\mathcal{V}

\displaystyle\mathbb{E}[|\mu_{0}(s)-\widehat{\mu}_{0}(s)|]\leq\sqrt{\Varop\mathopen{}\left[\widehat{\mu}_{0}(s)\right]}=\sqrt{\frac{\mu_{0}(s)(1-\mu_{0}(s))}{N}}\leq\sqrt{\frac{\mu_{0}(s)}{N}}

By summing over all states
s\in\mathcal{V}
and applying Cauchy-Schwarz’s inequality, we get:

\displaystyle\mathbb{E}[\|\mu_{0}-\widehat{\mu}_{0}\|_{1}]=\sum_{s\in\mathcal{V}}\mathbb{E}[|\mu_{0}(s)-\widehat{\mu}_{0}(s)|]\leq\sum_{s\in\mathcal{V}}\sqrt{\frac{\mu_{0}(s)}{N}}\stackrel{{\scriptstyle C.S.}}{{\leq}}\frac{\sqrt{|\mathcal{V}|}}{\sqrt{N}}.

Next, for
h\geq 0
, we compute an upper bound for the deviation at step
h+1
.
In particular, we analyze the conditional expectation

\displaystyle\mathbb{E}

\displaystyle\left[\|\mu_{h+1}^{\overline{\pi}}-\widehat{\mu}_{h+1}\|_{1}\big|\{z_{h}^{i}\}_{i=1}^{N}\right]

\displaystyle\quad\leq\underbrace{\mathbb{E}\left[\|\mu_{h+1}^{\overline{\pi}}-\mathbb{E}[\widehat{\mu}_{h+1}|\{z_{h}^{i}\}_{i=1}^{N}]\|_{1}\middle|\{z_{h}^{i}\}_{i=1}^{N}\right]}_{:=(\triangle)}+\underbrace{\mathbb{E}\left[\|\widehat{\mu}_{h+1}-\mathbb{E}[\widehat{\mu}_{h+1}|\{z_{h}^{i}\}_{i=1}^{N}]\|_{1}\middle|\{z_{h}^{i}\}_{i=1}^{N}\right]}_{:=(\square)},

almost surely,
where
\{z_{h}^{i}\}_{i=1}^{N}
are the states of agents after the item allocation in round
h
as before.
We upper bound the two terms
(\square)
and
(\triangle)
separately.
For
(\square)
we have:

\displaystyle(\square)

\displaystyle=\sum_{s\in\mathcal{S}}\mathbb{E}\left[|\widehat{\mu}_{h+1}(s)-\mathbb{E}[\widehat{\mu}_{h+1}(s)\,|\{z_{h}^{i}\}]|_{1}\middle|\{z_{h}^{i}\}\right]\leq\sum_{s\in\mathcal{S}}\sqrt{\Varop\mathopen{}\left[\widehat{\mu}_{h+1}(s)\middle|\{z_{h}^{i}\}\right]}.

For arbitrary
s\in\mathcal{S}
, noting that
\widehat{\xi}_{h}
is
\{z_{h}^{i}\}
-measurable,

\displaystyle\Varop\mathopen{}\left[\widehat{\mu}_{h+1}(s)\middle|\,\{z_{h}^{i}\}\right]

\displaystyle=\frac{1}{N^{2}}\sum_{s^{\prime}\in\mathcal{S}}N\widehat{\xi}_{h}(s^{\prime})w(s|s^{\prime},\widehat{\xi}_{h})(1-w(s|s^{\prime},\widehat{\xi}_{h}))\leq\frac{1}{N}\sum_{s^{\prime}\in\mathcal{S}}\widehat{\xi}_{h}(s^{\prime})w(s|s^{\prime},\widehat{\xi}_{h}).

By the Cauchy-Schwarz inequality, we have

\displaystyle\left(\sum_{s\in\mathcal{S}}\sqrt{\sum_{s^{\prime}\in\mathcal{S}}\widehat{\xi}_{h}(s^{\prime})w(s|s^{\prime},\widehat{\xi}_{h})}\right)^{2}\leq\left(\sum_{s\in\mathcal{S}}\sum_{s^{\prime}\in\mathcal{S}}\widehat{\xi}_{h}(s^{\prime})w(s|s^{\prime},\widehat{\xi}_{h}))\right)|\mathcal{S}|=|\mathcal{S}|.

Therefore, we (almost surely) have

\displaystyle(\square)

\displaystyle\leq\frac{1}{\sqrt{N}}\sum_{s\in\mathcal{S}}\sqrt{\sum_{s^{\prime}\in\mathcal{S}}\widehat{\xi}_{h}(s^{\prime})w(s|s^{\prime},\widehat{\xi}_{h})}\leq\frac{\sqrt{|\mathcal{S}|}}{\sqrt{N}}.

For
(\triangle)
it holds that

\displaystyle(\triangle)

\displaystyle=\mathbb{E}\left[\|\mu_{h+1}^{\overline{\pi}}-\mathbb{E}[\widehat{\mu}_{h+1}|\{z_{h}^{i}\}]\|_{1}\middle|\{z_{h}^{i}\}\right]=\|\mu_{h+1}^{\overline{\pi}}-\mathbb{E}[\widehat{\mu}_{h+1}|\{z_{h}^{i}\}]\|_{1}

\displaystyle=\left\|\Gamma_{g}(\xi_{h}^{\overline{\pi}})-\Gamma_{g}(\widehat{\xi}_{h})\right\|_{1}\leq\left(K_{w}+\frac{K_{s}}{2}\right)\|\xi_{h}^{\overline{\pi}}-\widehat{\xi}_{h}\|_{1},

where in the last step we applied Lemma 2.2 from
[
75
]
.
Merging the upper bounds for
(\triangle)
and
(\square)
and taking expectations, we obtain

\mathbb{E}\big[\|\mu_{h+1}^{\overline{\pi}}-\widehat{\mu}_{h+1}\|_{1}\big]\leq\frac{\sqrt{|\mathcal{S}|}}{\sqrt{N}}+\left(K_{w}+\frac{K_{s}}{2}\right)\mathbb{E}\left[\|\xi_{h}^{\overline{\pi}}-\widehat{\xi}_{h}\|_{1}\right].

Next, we bound the expected deviation between the post-allocation state distribution in the mean field model and its empirical counterpart in the finite-agent system.
Specifically, we consider
\mathbb{E}\left[\|\xi_{h}^{\overline{\pi}}-\widehat{\xi}_{h}\|_{1}\right]
,
where
\xi_{h}^{\overline{\pi}}:=\Gamma_{\alpha_{h}}(L_{h}^{\overline{\pi}})
is the mean field post-allocation distribution induced by policy
\overline{\pi}
, and
\widehat{\xi}_{h}
is the corresponding empirical distribution in the finite-agent auction, computed from realized allocations rather than via the operator
\Gamma_{\alpha_{h}}
.
Denote the
\sigma
-algebra induced by
\{s_{h}^{i},a_{h}^{i}\}_{i}
as
\mathcal{F}_{h}
for simplicity, then

\mathbb{E}\left[\|\xi_{h}^{\overline{\pi}}-\widehat{\xi}_{h}\|_{1}\big|\mathcal{F}_{h}\right]\leq\underbrace{\mathbb{E}\left[\|\xi_{h}^{\overline{\pi}}-\mathbb{E}[\widehat{\xi}_{h}|\mathcal{F}_{h}]\|_{1}\big|\mathcal{F}_{h}\right]}_{:=(\diamondsuit)}+\underbrace{\mathbb{E}\left[\|\widehat{\xi}_{h}-\mathbb{E}[\widehat{\xi}_{h}|\mathcal{F}_{h}]\|_{1}\big|\mathcal{F}_{h}\right]}_{:=(\heartsuit)}.

We upper-bound the two terms separately once again.
For
(\heartsuit)
we have:

\displaystyle(\heartsuit)=\mathbb{E}\left[\|\widehat{\xi}_{h}-\mathbb{E}[\widehat{\xi}_{h}|\mathcal{F}_{h}]\|_{1}\big|\mathcal{F}_{h}\right]

\displaystyle=\mathbb{E}\left[\sum_{s\in\mathcal{V}}\left|\widehat{\xi}_{h}(s)-\mathbb{E}[\widehat{\xi}_{h}(s)|\mathcal{F}_{h}]\right|\,\middle|\mathcal{F}_{h}\right]

\displaystyle=\sum_{s\in\mathcal{V}}\mathbb{E}\left[\left|\widehat{\xi}_{h}(s)-\mathbb{E}[\widehat{\xi}_{h}(s)|\mathcal{F}_{h}]\right|\,\middle|\mathcal{F}_{h}\right].

We establish an upper bound on the absolute deviation for each state
s\in\mathcal{V}
.
Let
s\in\mathcal{V}
be arbitrary.
Given the empirical state-action distribution
\widehat{L}_{h}\in\Delta_{\mathcal{S}\times\mathcal{A}}
, the corresponding empirical state distribution is given by marginalizing over actions:
\widehat{\mu}_{h}=\sum_{a\in\mathcal{A}}\widehat{L}_{h}(\cdot,a)
. By definition of
\widehat{\mu}_{h}
, there are
N\widehat{\mu}_{h}(s)
agents in state
s
at round
h
. Denoting these agents as
i_{1},\dots,i_{N\widehat{\mu}_{h}(s)}
, we can express
\widehat{\xi}_{h}(s)
as:

\widehat{\xi}_{h}(s)=\frac{1}{N}\sum_{j\in[N\widehat{\mu}_{h}(s)]}\mathbbm{1}_{z_{h}^{i_{j}}=s}

Two key observations can be made regarding these indicator variables:

1. The indicators are negatively correlated due to the structure of the auction. To illustrate this, assume without loss of generality that the first
M
agents have not won yet, i.e.,
s_{h}^{i}\neq\perp
for all
i\in[M]
. Since the number of items in each round is fixed, when conditioning on
\widehat{L}_{h}
, we have

\left\lfloor\alpha_{h}(\nu^{-\perp}(\widehat{L}_{h}))N\right\rfloor=\sum_{i=1}^{M}\mathbbm{1}_{z_{h}^{i}=\perp},

which implies that the indicator variables
\mathbbm{1}_{z_{h}^{i}=\perp}
are negatively correlated. Consequently, their complements
\mathbbm{1}_{z_{h}^{i}=s_{h}^{i}}=1-\mathbbm{1}_{z_{h}^{i}=\perp}
are also negatively correlated. This implies that any subset of these indicator variables retains this negative correlation property. Specifically, for every state
s
, the random variables
\mathbbm{1}_{z_{h}^{i_{j}}=s},\,j\in[N\widehat{\mu}_{h}(s)],
are negatively correlated.

2. Since these are Bernoulli random variables, their variance is at most
1/4
.

It follows from the two observations above that the variance of
\widehat{\xi}_{h}
conditioned on
\mathcal{F}_{h}
can be upper bounded almost surely as follows:

\displaystyle\Varop\mathopen{}\left[\widehat{\xi}_{h}(s)\middle|\mathcal{F}_{h}\right]

\displaystyle=\Varop\mathopen{}\left[\frac{1}{N}\sum_{j\in[N\widehat{\mu}_{h}(s)]}\mathbbm{1}_{z_{h}^{i_{j}}=s}\middle|\mathcal{F}_{h}\right]=\frac{1}{N^{2}}\Varop\mathopen{}\left[\sum_{j\in[N\widehat{\mu}_{h}(s)]}\mathbbm{1}_{z_{h}^{i_{j}}=s}\middle|\mathcal{F}_{h}\right]

\displaystyle\leq\frac{1}{N^{2}}\sum_{j\in[N\widehat{\mu}_{h}(s)]}\Varop\mathopen{}\left[\mathbbm{1}_{z_{h}^{i_{j}}=s}\middle|\mathcal{F}_{h}\right]\leq\frac{\widehat{\mu}_{h}(s)}{4N}.

Using Jensen’s inequality, we can bound the absolute deviation using the variance:

\displaystyle\mathbb{E}\left[\left|\widehat{\xi}_{h}(s)-\mathbb{E}[\widehat{\xi}_{h}(s)|\mathcal{F}_{h}]\right|\,\middle|\mathcal{F}_{h}\right]\leq\sqrt{\Varop\mathopen{}\left[\widehat{\xi}_{h}(s)\middle|\mathcal{F}_{h}\right]}\leq\sqrt{\frac{\widehat{\mu}_{h}(s)}{4N}}

Using this result, together with Cauchy-Schwarz’s inequality, we can further bound
(\heartsuit)
:

\displaystyle(\heartsuit)

\displaystyle=\sum_{s\in\mathcal{V}}\mathbb{E}\left[\left|\widehat{\xi}_{h}(s)-\mathbb{E}[\widehat{\xi}_{h}(s)|\mathcal{F}_{h}]\right|\,\middle|\mathcal{F}_{h}\right]\leq\sum_{s\in\mathcal{V}}\sqrt{\frac{\widehat{\mu}_{h}(s)}{4N}}\stackrel{{\scriptstyle C.S.}}{{\leq}}\frac{\sqrt{|\mathcal{V}|}}{2\sqrt{N}}

For the term
(\diamondsuit)
, applying the result of
Corollary

3
yields:

\displaystyle(\diamondsuit)=\mathbb{E}\left[\|\xi_{h}^{\overline{\pi}}-\mathbb{E}[\widehat{\xi}_{h}|\mathcal{F}_{h}]\|_{1}\big|\mathcal{F}_{h}\right]

\displaystyle=\|\Gamma_{\alpha_{h}}(L_{h}^{\overline{\pi}})-\Gamma_{\alpha_{h}}(\widehat{L}_{h})\|_{1}+\|\mathbb{E}[\widehat{\xi}_{h}|\mathcal{F}_{h}]-\Gamma_{\alpha_{h}}(\widehat{L}_{h})\|_{1}

\displaystyle\leq|\alpha_{h}(\nu^{-\perp}(L_{h}^{\overline{\pi}}))-\alpha_{h}(\nu^{-\perp}(\widehat{L}_{h}))|+\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}+\frac{1}{N}

\displaystyle\leq K_{\alpha}\|(\nu^{-\perp}(L_{h}^{\overline{\pi}})-(\nu^{-\perp}(\widehat{L}_{h})\|_{1}+\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}+\frac{1}{N}

\displaystyle\leq(K_{\alpha}+1)\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}+\frac{1}{N},

where the second to last step follows from the Lipschitz continuity of
\alpha_{h}
, while the last step follows from
\|(\nu^{-\perp}(L_{h}^{\overline{\pi}})-(\nu^{-\perp}(\widehat{L}_{h})\|_{1}\leq\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}.

Additionally,
\|\mathbb{E}[\widehat{\xi}_{h}|\mathcal{F}_{h}]-\Gamma_{\alpha_{h}}(\widehat{L}_{h})\|_{1}\leq\frac{1}{N}
comes from
Lemma

7
, as
|\lfloor N\alpha_{h}(\nu^{-\perp}(L_{h}^{\overline{\pi}}))\rfloor-N\alpha_{h}(\nu^{-\perp}(L_{h}^{\overline{\pi}}))|\leq 1
.

Combining the upper bounds for
(\heartsuit)
and
(\diamondsuit)
we get:

\displaystyle\mathbb{E}\bigl[\|\xi_{h}^{\overline{\pi}}-

\displaystyle\widehat{\xi}_{h}\|_{1}\bigr]

\displaystyle\leq(K_{\alpha}+1)\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]+\frac{\sqrt{|\mathcal{V}|}}{2\sqrt{N}}+\frac{1}{N}

\displaystyle\leq(K_{\alpha}+1)\biggl(\mathbb{E}\left[\|\mu_{h}^{\overline{\pi}}-\widehat{\mu}_{h}\|_{1}\right]+\frac{1}{N}\sum_{i\in[N]}\|\overline{\pi}_{h}-\pi_{h}^{i}\|_{1}+\sqrt{\frac{|\mathcal{A}|\cdot|\mathcal{V}|}{N}}\biggr)+\frac{\sqrt{|\mathcal{V}|}}{2\sqrt{N}}+\frac{1}{N},

where the last step follows from
Corollary

4
.

Combining this result with the bound on
\mathbb{E}[\|\mu_{h+1}^{\overline{\pi}}-\widehat{\mu}_{h+1}\|_{1}]
, we apply induction on
h
to conclude the proof of the lemma.

\square

Lemma 12
(Expected Deviation in Allocation Dynamics)

Let
\mathcal{M}_{\text{mfa}}=(\mathcal{S},\mathcal{A},H,\mu_{0},\{P^{\text{mfa}}_{h}\}_{h=0}^{H-1},\{R^{\text{mfa}}_{h}\}_{h=0}^{H-1})

\{\alpha_{h}\}_{h=0}^{H-1}
,
\{w_{h}\}_{h=0}^{H-1}
,
\{p_{h}\}_{h=0}^{H-1}
, and
\{u_{h}\}_{h=0}^{H-1}
denote the allocation thresholds, transition dynamics, payment, and utility functions, respectively, from which
\{P^{\text{mfa}}_{h}\}_{h=0}^{H-1}
and
\{R^{\text{mfa}}_{h}\}_{h=0}^{H-1}
are derived.
Assume these functions are Lipschitz continuous, with respective Lipschitz moduli
K_{\alpha}
,
K_{w}
,
K_{p}
, and
K_{u}
.
Consider the corresponding finite-agent Batched Auction model with
N
agents approximated by
\mathcal{M}_{\text{mfa}}
.
Let
\boldsymbol{\pi}=\{\pi_{h}^{i}\}_{h=0,\dots,H-1,\,i\in[N]}\in\Pi_{H}^{N}
denote the joint policy of the population, and let
\widehat{L}_{h}\in\Delta_{\mathcal{S}}
be the empirical state-action distribution at round
h
.

Let
\overline{\pi}\in\Pi_{H}
arbitrary, and define the associated mean field state-action distribution flow
L^{\overline{\pi}}:=\Lambda_{\text{mfa}}(\overline{\pi})
. Then, for all
h\in\{0,\dots,H-1\}
, the following bounds hold:

\displaystyle\mathbb{E}\Big[\big|p_{\text{win}}(s_{h}^{i},a_{h}^{i},L_{h}^{\overline{\pi}},\nu^{-\perp}(L_{h}^{\overline{\pi}}))

\displaystyle-p_{\text{win}}(s_{h}^{i},a_{h}^{i},\widehat{L}_{h},\tfrac{\lfloor N\nu^{-\perp}(\widehat{L}_{h})\rfloor}{N})\big|\Big]

\displaystyle\leq C_{L_{h}^{\overline{\pi}},\alpha_{h}}\cdot\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]+\frac{C_{L_{h}^{\overline{\pi}},\alpha_{h}}}{K_{\alpha}+1}\cdot\frac{1}{N}

and

\displaystyle\mathbb{E}\left[\|P_{\alpha_{h}}(s_{h}^{i},a_{h}^{i},L_{h}^{\overline{\pi}})-P_{N,\alpha_{h}}^{i}(\mathbf{s}_{h},\mathbf{a}_{h})\|_{1}\right]\leq 2C_{L_{h}^{\overline{\pi}},\alpha_{h}}\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]+2\frac{C_{L_{h}^{\overline{\pi}},\alpha_{h}}}{K_{\alpha}+1}\frac{1}{N},

where for an arbitrary state-action distribution
L\in\Delta_{\mathcal{S}\times\mathcal{A}}
and
\alpha:\Delta_{\mathcal{S}}^{\leq 1}\to[0,1]
, the constant
C_{L,\alpha}
is defined as in
Lemma

8
.

Proof:

For the first inequality, we have

\displaystyle\mathbb{E}\Big[\big|p_{\text{win}}(s_{h}^{i},a_{h}^{i},L_{h}^{\overline{\pi}},\nu^{-\perp}(L_{h}^{\overline{\pi}}))-p_{\text{win}}(s_{h}^{i},a_{h}^{i},\widehat{L}_{h},\tfrac{\lfloor N\nu^{-\perp}(\widehat{L}_{h})\rfloor}{N})\big|\Big]

\displaystyle\leq\sum_{s,a,L}\mathbb{P}[s_{h}^{i}=s,a_{h}^{i}=a,\widehat{L}_{h}=L]\left|p_{\text{win}}(s_{h}^{i},a_{h}^{i},L_{h}^{\overline{\pi}},\nu^{-\perp}(L_{h}^{\overline{\pi}}))-p_{\text{win}}(s_{h}^{i},a_{h}^{i},\widehat{L}_{h},\tfrac{\lfloor N\nu^{-\perp}(\widehat{L}_{h})\rfloor}{N})\right|

\displaystyle\leq\sum_{s,a,L}\mathbb{P}[s_{h}^{i}=s,a_{h}^{i}=a,\widehat{L}_{h}=L]C_{L_{h}^{\overline{\pi}},\alpha_{h}}\cdot\|L_{h}^{\overline{\pi}}-L\|_{1}+\frac{C_{L_{h}^{\overline{\pi}},\alpha_{h}}}{K_{\alpha}+1}\cdot\frac{1}{N}

\displaystyle\leq C_{L_{h}^{\overline{\pi}},\alpha_{h}}\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]+\frac{C_{L_{h}^{\overline{\pi}},\alpha_{h}}}{K_{\alpha}+1}\frac{1}{N},

where in the second-to-last step we used
Lemma

8
.

Additionally, for the allocation dynamics
P_{N,\alpha_{h}}
, since each state
s\in\mathcal{V}
can transition only either to itself or to the inactive state
\perp
, it follows that:

\displaystyle\mathbb{E}\left[\|P_{\alpha_{h}}(s_{h}^{i},a_{h}^{i},L_{h}^{\overline{\pi}})-P_{N,\alpha_{h}}^{i}(\mathbf{s}_{h},\mathbf{a}_{h})\|_{1}\right]

\displaystyle=\sum_{s\in\mathcal{S}}\mathbb{E}\left[\|P_{\alpha_{h}}(s|s_{h}^{i},a_{h}^{i},L_{h}^{\overline{\pi}})-P_{N,\alpha_{h}}^{i}(s|\mathbf{s}_{h},\mathbf{a}_{h})\|_{1}\right]

\displaystyle=\mathbb{E}\left[\|P_{\alpha_{h}}(s_{h}^{i}|s_{h}^{i},a_{h}^{i},L_{h}^{\overline{\pi}})-P_{N,\alpha_{h}}^{i}(s_{h}^{i}|\mathbf{s}_{h},\mathbf{a}_{h})\|_{1}\right]

\displaystyle\quad+\mathbb{E}\left[\|P_{\alpha_{h}}(\perp|s_{h}^{i},a_{h}^{i},L_{h}^{\overline{\pi}})-P_{N,\alpha_{h}}^{i}(\perp|\mathbf{s}_{h},\mathbf{a}_{h})\|_{1}\right]

\displaystyle=2\mathbb{E}\left[\|P_{\alpha_{h}}(\perp|s_{h}^{i},a_{h}^{i},L_{h}^{\overline{\pi}})-P_{N,\alpha_{h}}^{i}(\perp|\mathbf{s}_{h},\mathbf{a}_{h})\|_{1}\right].

Since the marginal probability of transitioning to the state
\perp
corresponds to the winning probability, the bound follows directly from the first inequality.

\square

E.3.3
Step 3: Exploitability Deviation for BA-MFG

Finally we prove the absolute difference in expected reward due to a single-side policy deviation.

Theorem 4

Let
\mathcal{M}_{\text{mfa}}=(\mathcal{S},\mathcal{A},H,\mu_{0},\{P^{\text{mfa}}_{h}\}_{h=0}^{H-1},\{R^{\text{mfa}}_{h}\}_{h=0}^{H-1})
be a Batched Auction Mean Field Game (BA-MFG). Let
\{\alpha_{h}\}_{h=0}^{H-1}
,
\{w_{h}\}_{h=0}^{H-1}
,
\{p_{h}\}_{h=0}^{H-1}
, and
\{u_{h}\}_{h=0}^{H-1}
denote the allocation thresholds, transition dynamics, payment, and utility functions, respectively, from which
\{P^{\text{mfa}}_{h}\}_{h=0}^{H-1}
and
\{R^{\text{mfa}}_{h}\}_{h=0}^{H-1}
are derived. Assume these functions are Lipschitz continuous, with respective Lipschitz constants
K_{\alpha}
,
K_{w}
,
K_{p}
, and
K_{u}
.

Consider the corresponding finite-agent Batched Auction
\mathcal{G}_{\text{auc}}
with
N
agents, which is approximated by
\mathcal{M}_{\text{mfa}}
. Let
\overline{\pi}\in\Pi_{H}
an arbitrary policy satisfying the no-zero dominance property. Then, for any policy
\pi\in\Pi_{H},\tau\geq 0
it holds

\displaystyle\biggl|V_{\text{mfa}}^{\tau}(\Lambda_{\text{mfa}}(\overline{\pi}),\pi)-J_{\text{auc}}^{\tau,1}(\pi,\underbrace{\overline{\pi},\dots,\overline{\pi}}_{N-1\text{ times}})\biggr|

\displaystyle=\mathcal{O}\left(\frac{1}{\sqrt{N}}\right)

Proof:

Define the random variables
\{s_{h}^{i},a_{h}^{i},z_{h}^{i}\}_{i\in[N],\,h\in\{0,\dots,H-1\}}
, along with
\{\widehat{L}_{h}\}_{h=0}^{H-1}
,
\{\widehat{\mu}_{h}\}_{h=0}^{H-1}
, and
\{\widehat{\xi}_{h}\}_{h=0}^{H-1}
, as in the definition of the
N
-player Batched Auction (see
Definition

6
). Here,
s_{h}^{i}
denotes the state of agent
i
at round
h
,
a_{h}^{i}
its action, and
z_{h}^{i}
its hidden state following the allocation step. The random variables
\widehat{L}_{h}
,
\widehat{\mu}_{h}
, and
\widehat{\xi}_{h}
represent, respectively, the empirical state-action distribution, the empirical state distribution, and the empirical post-allocation state distribution at round
h
.

For the Mean-Field Batched Auction, define
\{s_{h},a_{h},z_{h}\}_{h=0}^{H-1}
, where
s_{h}
and
a_{h}
represent the state and action of a representative agent at round
h
, and
z_{h}
denotes its post-allocation hidden state. These evolve deterministically according to the mean-field population flows
L^{\overline{\pi}},\mu^{\overline{\pi}},\xi^{\overline{\pi}}
induced by the population policy
\overline{\pi}
.

We divide the proof into three steps:

1.

We show that for every
h\in\{0,\dots,H-1\}
we have:

\displaystyle\bigl\|\mathbb{P}[s_{h}=\cdot]-

\displaystyle\mathbb{P}[s_{h}^{1}=\cdot]\bigr\|_{1}

\displaystyle\leq\sum_{h^{\prime}<h}\mathbb{E}\left[\|L_{h^{\prime}}^{\overline{\pi}}-\widehat{L}_{h^{\prime}}\|_{1}\right](K_{w}(K_{\alpha}+1)+2C_{L_{h^{\prime}}^{\overline{\pi}},\alpha_{h^{\prime}}})+\frac{2C_{L_{h^{\prime}}^{\overline{\pi}},\alpha_{h^{\prime}}}}{(K_{\alpha}+1)N}

\displaystyle\quad+hK_{w}\biggl(\frac{\sqrt{|\mathcal{S}|}}{2\sqrt{N}}+\frac{1}{N}\biggr)

2.

We show that for every
h\in\{0,\dots,H-1\}
we have:

\displaystyle\bigl|\mathbb{E}[R^{\text{mfa}}_{h}(s_{h},a_{h},L_{h}^{\overline{\pi}})-

\displaystyle R^{\text{mfa}}_{N,h}(s_{h}^{1},a_{h}^{1},\widehat{L}_{h})]\bigr|

\displaystyle\leq(K_{u}K_{p}+B_{u}C_{L_{h}^{\overline{\pi}},\alpha_{h}})\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]+\frac{C_{L_{h}^{\overline{\pi}},\alpha_{h}}}{K_{\alpha}+1}\frac{B_{u}}{N}

\displaystyle\quad+B_{u}\|\mathbb{P}[s_{h}=\cdot]-\mathbb{P}[s_{h}^{1}=\cdot]\|_{1}.

3.

In the last step we combine the results of the previous steps to prove the man claim of the theorem.

Step 1:
We prove the inequality by induction on
h
. For the base case
h=0
, we have
\|\mathbb{P}[s_{0}=\cdot]-\mathbb{P}[s_{0}^{1}=\cdot]\|_{1}=0
, since both distributions are equal to the initial distribution
\mu_{0}
. Now, assuming the bound holds for some
h\geq 0
, we show that it also holds for round
h+1
.

\displaystyle\|\mathbb{P}[s_{h+1}=\cdot]-\mathbb{P}[s_{h+1}^{1}=\cdot]\|_{1}

\displaystyle=\left\|\sum_{z,\xi}\mathbb{P}[z_{h}^{1}=z,\widehat{\xi}_{h}=\xi]w_{h}(z,\xi)-\sum_{z}\mathbb{P}[z_{h}=z]w_{h}(z,\xi_{h}^{\overline{\pi}})\right\|_{1}.

By adding and subtracting
\sum_{z,\xi}\mathbb{P}[z_{h}^{1}=z,\widehat{\xi}_{h}=\xi]w_{h}(z,\xi_{h}^{\overline{\pi}})=\sum_{z}\mathbb{P}[z_{h}^{1}=z]w_{h}(z,\xi_{h}^{\overline{\pi}}),
and applying triangular inequality, we get

\displaystyle\|\mathbb{P}[s_{h+1}=\cdot]-\mathbb{P}[s_{h+1}^{1}=\cdot]\|_{1}

\displaystyle\leq\Biggl\|\sum_{z,\xi}\mathbb{P}[z_{h}^{1}=z,\widehat{\xi}_{h}=\xi]\left(w_{h}(z,\xi)-w_{h}(z,\xi_{h}^{\overline{\pi}})\right)\Biggr\|_{1}

\displaystyle\quad+\Biggl\|\sum_{z}(\mathbb{P}[z_{h}=z]-\mathbb{P}[z_{h}^{1}=z])w_{h}(z,\xi_{h}^{\overline{\pi}})\Biggr\|_{1}

\displaystyle\leq K_{w}\mathbb{E}[\|\xi_{h}^{\overline{\pi}}-\widehat{\xi}_{h}\|_{1}]+\|\mathbb{P}[z_{h}=\cdot]-\mathbb{P}[z_{h}^{1}=\cdot]\|_{1}.

The term
\mathbb{E}[\|\xi_{h}^{\overline{\pi}}-\widehat{\xi}_{h}\|_{1}]
, using the same derivation as in the inductive step of
Lemma

11
, can be further upper bounded as

\mathbb{E}\left[\|\xi_{h}^{\overline{\pi}}-\widehat{\xi}_{h}\|_{1}\right]\leq(K_{\alpha}+1)\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]+\frac{\sqrt{|\mathcal{V}|}}{2\sqrt{N}}+\frac{1}{N}.

Finally applying a similar reasoning we can upper bound
\|\mathbb{P}[z_{h}=\cdot]-\mathbb{P}[z_{h}^{1}=\cdot]\|_{1}
.

\displaystyle\|\mathbb{P}[z_{h}=\cdot]-\mathbb{P}[z_{h}^{1}=\cdot]\|_{1}

\displaystyle=\Biggl\|\sum_{\mathbf{s},\mathbf{a}}\mathbb{P}[\mathbf{s}_{h}=\mathbf{s},\mathbf{a}_{h}=\mathbf{a}]P_{N,\alpha_{h}}^{1}(\mathbf{s},\mathbf{a})-\sum_{s,a}\mathbb{P}[s_{h}=s,a_{h}=a]P_{\alpha_{h}}(s,a,L_{h}^{\overline{\pi}})\Biggr\|_{1}.

By adding and subtracting
\sum_{\mathbf{s},\mathbf{a}}\mathbb{P}[\mathbf{s}_{h}=\mathbf{s},\mathbf{a}_{h}=\mathbf{a}]P_{\alpha_{h}}(s^{1},a^{1},L_{h}^{\overline{\pi}})=\sum_{s,a}\mathbb{P}[s_{h}^{1}=s,a_{h}^{1}=a]P_{\alpha_{h}}(s,a,L_{h}^{\overline{\pi}})
, and applying triangular inequality, we get

\displaystyle\|\mathbb{P}[z_{h}=\cdot]-\mathbb{P}[z_{h}^{1}=\cdot]\|_{1}

\displaystyle\leq\sum_{\mathbf{s},\mathbf{a}}\mathbb{P}[\mathbf{s}_{h}=\mathbf{s},\mathbf{a}_{h}=\mathbf{a}]\|P_{N,\alpha_{h}}^{1}(\mathbf{s},\mathbf{a})-P_{\alpha_{h}}(s^{1},a^{1},L_{h}^{\overline{\pi}})\|_{1}

\displaystyle\quad+\sum_{s,a}\|P_{\alpha_{h}}(s,a,L_{h}^{\overline{\pi}})\|_{1}|\mathbb{P}[s_{h}=s,a_{h}=a]-\mathbb{P}[s_{h}^{1}=s,a_{h}^{1}=a]|

\displaystyle\leq\mathbb{E}\left[\|P_{N,\alpha_{h}}^{1}(\mathbf{s}_{h},\mathbf{a}_{h})-P_{\alpha_{h}}(s_{h}^{1},a_{h}^{1},L_{h}^{\overline{\pi}})\|_{1}\right]

\displaystyle\quad+\sum_{s}|\mathbb{P}[s_{h}=s]-\mathbb{P}[s_{h}^{1}=s]|\sum_{a}\pi_{h}(a|s)\|P_{\alpha_{h}}(s,a,L_{h}^{\overline{\pi}})\|_{1}.

Applying
Lemma

12
it follows

\displaystyle\|\mathbb{P}[z_{h}=\cdot]-\mathbb{P}[z_{h}^{1}=\cdot]\|_{1}

\displaystyle\leq 2C_{L_{h}^{\overline{\pi}},\alpha_{h}}\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]+2\frac{C_{L_{h}^{\overline{\pi}},\alpha_{h}}}{K_{\alpha}+1}\frac{1}{N}+\|\mathbb{P}[s_{h}=\cdot]-\mathbb{P}[s_{h}^{1}=\cdot]\|_{1}.

By combining the two bounds, we obtain

\displaystyle\|\mathbb{P}[s_{h+1}=\cdot]-\mathbb{P}[s_{h+1}^{1}=\cdot]\|_{1}

\displaystyle\leq K_{w}\biggl((K_{\alpha}+1)\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]+\frac{\sqrt{|\mathcal{V}|}}{2\sqrt{N}}+\frac{1}{N}\biggr)

\displaystyle\quad+2C_{L_{h}^{\overline{\pi}},\alpha_{h}}\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]+\frac{2C_{L_{h}^{\overline{\pi}},\alpha_{h}}}{(K_{\alpha}+1)N}

\displaystyle\quad+\|\mathbb{P}[s_{h}=\cdot]-\mathbb{P}[s_{h}^{1}=\cdot]\|_{1}.

Applying the induction hypothesis completes the proof for round
h+1
.

Step 2:
We prove the inequality by using the result obtained in step 1. Let
h\in\{0,\dots,H-1\}
arbitrary, then

\displaystyle\bigl|\mathbb{E}[R^{\text{mfa}}_{h}(s_{h},a_{h},L_{h}^{\overline{\pi}})-R^{\text{mfa}}_{N,h}(s_{h}^{1},a_{h}^{1},\widehat{L}_{h})]\bigr|

\displaystyle\leq\underbrace{\bigl|\mathbb{E}[R^{\text{mfa}}_{h}(s_{h},a_{h},L_{h}^{\overline{\pi}})-R^{\text{mfa}}_{h}(s_{h}^{1},a_{h}^{1},L^{\overline{\pi}}_{h})]\bigr|}_{(\square)}+\underbrace{\bigl|\mathbb{E}[R^{\text{mfa}}_{h}(s_{h}^{1},a_{h}^{1},L^{\overline{\pi}}_{h})-R^{\text{mfa}}_{N,h}(s_{h}^{1},a_{h}^{1},\widehat{L}_{h})]\bigr|}_{(\triangle)}.

The first term
(\square)
can be upper bounded by

\displaystyle(\square)=\Bigl|\sum_{s}(\mathbb{P}[s_{h}=s]-\mathbb{P}[s_{h}^{1}=s])\sum_{a}\pi_{a}(a|s)R^{\text{mfa}}_{h}(s,a,L_{h}^{\overline{\pi}})\Bigr|\leq B_{u}\|\mathbb{P}[s_{h}=\cdot]-\mathbb{P}[s_{h}^{1}=\cdot]\|_{1}.

For the second term
(\triangle)
we have:

\displaystyle(\triangle)

\displaystyle\leq\sum_{s,a,L}\mathbb{P}[s_{h}^{1}=s,a_{h}^{1}=a,\widehat{L}=L]\bigl|R^{\text{mfa}}_{h}(s,a,L^{\overline{\pi}}_{h})-R^{\text{mfa}}_{N,h}(s,a,L)\bigr|

\displaystyle\leq\sum_{s,a,L}\mathbb{P}[s_{h}^{1}=s,a_{h}^{1}=a,\widehat{L}=L]\bigl|u_{h}(s,p_{h}(a,\nu^{-\perp}(L_{h}^{\overline{\pi}})))-u_{h}(s,p_{h}(a,\nu^{-\perp}(L)))\bigr|

\displaystyle\quad+B_{u}\mathbb{E}\Big[\big|p_{\text{win}}(s_{h}^{1},a_{h}^{1},L_{h}^{\overline{\pi}},\nu^{-\perp}(L_{h}^{\overline{\pi}}))-p_{\text{win}}(s_{h}^{1},a_{h}^{1},\widehat{L}_{h},\tfrac{\lfloor N\nu^{-\perp}(\widehat{L}_{h})\rfloor}{N})\big|\Big]

\displaystyle\leq K_{u}K_{p}\sum_{s,a,L}\mathbb{P}[s_{h}^{1}=s,a_{h}^{1}=a,\widehat{L}=L]\|L_{h}^{\overline{\pi}}-L\|_{1}

\displaystyle\quad+B_{u}C_{L_{h}^{\overline{\pi}},\alpha_{h}}\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]+\frac{C_{L_{h}^{\overline{\pi}},\alpha_{h}}}{K_{\alpha}+1}\frac{B_{u}}{N}

\displaystyle\leq(K_{u}K_{p}+B_{u}C_{L_{h}^{\overline{\pi}},\alpha_{h}})\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]+\frac{C_{L_{h}^{\overline{\pi}},\alpha_{h}}}{K_{\alpha}+1}\frac{B_{u}}{N},

where in the second to last step we used the Lipschitz continuity of
u\circ p
and
Lemma

12
. Combining both results we get:

\displaystyle\bigl|\mathbb{E}[R^{\text{mfa}}_{h}(s_{h},a_{h},L_{h}^{\overline{\pi}})-R^{\text{mfa}}_{N,h}(s_{h}^{1},a_{h}^{1},\widehat{L}_{h})]\bigr|

\displaystyle\leq(K_{u}K_{p}+B_{u}C_{L_{h}^{\overline{\pi}},\alpha_{h}})\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]+\frac{C_{L_{h}^{\overline{\pi}},\alpha_{h}}}{K_{\alpha}+1}\frac{B_{u}}{N}

\displaystyle\quad+B_{u}\|\mathbb{P}[s_{h}=\cdot]-\mathbb{P}[s_{h}^{1}=\cdot]\|_{1}.

Step 3:
We now combine the results from the previous two steps to establish the final bound stated in the theorem.

\displaystyle\biggl|V_{\text{mfa}}^{\tau}(\Lambda_{\text{mfa}}(\overline{\pi}),\pi)-J_{\text{auc}}^{\tau,1}(\pi,\overline{\pi},\dots,\overline{\pi})\biggr|

\displaystyle=\left|\mathbb{E}\left[\sum_{h=0}^{H-1}R^{\text{mfa}}_{h}(s_{h},a_{h},L_{h}^{\overline{\pi}})+\tau\mathcal{H}(\pi_{h}(s_{h}))-R^{\text{mfa}}_{N,h}(s_{h}^{1},a_{h}^{1},\widehat{L}_{h})-\tau\mathcal{H}(\pi_{h}(s_{h}^{1}))\right]\right|

\displaystyle\leq\sum_{h=0}^{H-1}\left|\mathbb{E}\left[R^{\text{mfa}}_{h}(s_{h},a_{h},L_{h}^{\overline{\pi}})+\tau\mathcal{H}(\pi_{h}(s_{h}))-R^{\text{mfa}}_{N,h}(s_{h}^{1},a_{h}^{1},\widehat{L}_{h})-\tau\mathcal{H}(\pi_{h}(s_{h}^{1}))\right]\right|.

We proceed by bounding each term individually for every round
h
. Let
h\in\{0,\dotsm H-1\}
arbitrary, then

\displaystyle\left|\mathbb{E}\left[R^{\text{mfa}}_{h}(s_{h},a_{h},L_{h}^{\overline{\pi}})+\tau\mathcal{H}(\pi_{h}(s_{h}))-R^{\text{mfa}}_{N,h}(s_{h}^{1},a_{h}^{1},\widehat{L}_{h})-\tau\mathcal{H}(\pi_{h}(s_{h}^{1}))\right]\right|

\displaystyle\leq\left|\mathbb{E}\left[R^{\text{mfa}}_{h}(s_{h},a_{h},L_{h}^{\overline{\pi}})-R^{\text{mfa}}_{N,h}(s_{h}^{1},a_{h}^{1},\widehat{L}_{h})\right]\right|+\tau\left|\mathbb{E}\left[\mathcal{H}(\pi_{h}(s_{h}))-\mathcal{H}(\pi_{h}(s_{h}^{1}))\right]\right|.

The first term is bounded using the result from Step 2, while the second term can be handled as follows:

\displaystyle\left|\mathbb{E}\left[\mathcal{H}(\pi_{h}(s_{h}))-\mathcal{H}(\pi_{h}(s_{h}^{1}))\right]\right|

\displaystyle\leq\sum_{s}|\mathbb{P}[s_{h}=s]-\mathbb{P}[s_{h}^{1}=s]\mathcal{H}(\pi_{h}(s))|

\displaystyle\leq\|\mathbb{P}[s_{h}=\cdot]-\mathbb{P}[s_{h}^{1}=\cdot]\|_{1}\log(|\mathcal{A}|).

Therefore the (entropy regularized) absolute difference in rewards at round
h
can be upper bounded by

\displaystyle\biggl|\mathbb{E}\biggl[R^{\text{mfa}}_{h}(s_{h},a_{h},L_{h}^{\overline{\pi}})+

\displaystyle\tau\mathcal{H}(\pi_{h}(s_{h}))-R^{\text{mfa}}_{N,h}(s_{h}^{1},a_{h}^{1},\widehat{L}_{h})-\tau\mathcal{H}(\pi_{h}(s_{h}^{1}))\biggr]\biggr|

\displaystyle\leq(K_{u}K_{p}+B_{u}C_{L_{h}^{\overline{\pi}},\alpha_{h}})\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]+\frac{C_{L_{h}^{\overline{\pi}},\alpha_{h}}}{K_{\alpha}+1}\frac{B_{u}}{N}

\displaystyle\quad+(B_{u}+\tau\log(|\mathcal{A}|))\|\mathbb{P}[s_{h}=\cdot]-\mathbb{P}[s_{h}^{1}=\cdot]\|_{1}.

By applying the bound on
|\mathbb{P}[s_{h}=\cdot]-\mathbb{P}[s_{h}^{1}=\cdot]|_{1}
derived in Step 1, and summing the per-round deviations over all
h
, it follows:

\displaystyle\biggl|V_{\text{mfa}}^{\tau}(\Lambda_{\text{mfa}}(\overline{\pi}),\pi)-J_{\text{auc}}^{\tau,1}(\pi,\underbrace{\overline{\pi},\dots,\overline{\pi}}_{N-1\text{ times}})\biggr|

\displaystyle\leq\sum_{h=0}^{H-1}(K_{u}K_{p}+B_{u}C_{L_{h}^{\overline{\pi}},\alpha_{h}})\mathbb{E}\left[\|L_{h}^{\overline{\pi}}-\widehat{L}_{h}\|_{1}\right]+\frac{C_{L_{h}^{\overline{\pi}},\alpha_{h}}}{K_{\alpha}+1}\frac{B_{u}}{N}

\displaystyle\quad+(B_{u}+\tau\log(|\mathcal{A}|))\sum_{h=0}^{H-1}\sum_{h^{\prime}<h}\mathbb{E}\left[\|L_{h^{\prime}}^{\overline{\pi}}-\widehat{L}_{h^{\prime}}\|_{1}\right](K_{w}(K_{\alpha}+1)+2C_{L_{h^{\prime}}^{\overline{\pi}},\alpha_{h^{\prime}}})+\frac{2C_{L_{h^{\prime}}^{\overline{\pi}},\alpha_{h^{\prime}}}}{(K_{\alpha}+1)N}

\displaystyle\quad+(B_{u}+\tau\log(|\mathcal{A}|))\frac{H(H-1)}{2}K_{w}\biggl(\frac{\sqrt{|\mathcal{S}|}}{2\sqrt{N}}+\frac{1}{N}\biggr)

In particular,
Corollary

4
implies that the total (entropy-regularized) reward difference is of order
\mathcal{O}(\tfrac{1}{\sqrt{N}})
.

\square

Conclusion and Statement of Result.
Let
\mathcal{M}_{\text{mfa}}
be a BA-MFG with Lipschitz-continuous
\{u_{h}\}_{h=0}^{H-1},\{w_{h}\}_{h=0}^{H-1},\{\alpha_{h}\}_{h=0}^{H-1},\{p_{h}\}_{h=0}^{H-1}
Let
\pi_{\delta}\in\Pi_{H}
be a policy that satisfy the no zero-dominance property. Let further assume
\pi_{\delta}
is a
\delta-
MFG-NE, namely

\delta\geq\max_{\pi^{\prime}\in\Pi_{H}}V_{\text{mfa}}^{\tau}(\Lambda_{\text{mfa}}(\pi_{\delta}),\pi^{\prime})-V_{\text{mfa}}^{\tau}(\Lambda_{\text{mfa}}(\pi_{\delta}),\pi_{\delta}).

Then, for
\boldsymbol{\pi}=(\pi_{\delta},\dots,\pi_{\delta})
, we have:

\displaystyle\max_{\pi^{\prime}\in\Pi_{H}}J_{\text{auc}}^{\tau,i}(\pi^{\prime},\boldsymbol{\pi}^{-i})-J_{\text{auc}}^{\tau,i}(\boldsymbol{\pi})

\displaystyle=\max_{\pi^{\prime}\in\Pi_{H}}J_{\text{auc}}^{\tau,i}(\pi^{\prime},\boldsymbol{\pi}^{-i})-J_{\text{auc}}^{\tau,i}(\boldsymbol{\pi})

\displaystyle\quad+V_{\text{mfa}}^{\tau}(\Lambda_{\text{mfa}}(\pi_{\delta}),\pi^{\prime})-V_{\text{mfa}}^{\tau}(\Lambda_{\text{mfa}}(\pi_{\delta}),\pi^{\prime})+V_{\text{mfa}}^{\tau}(\Lambda_{\text{mfa}}(\pi_{\delta}),\pi_{\delta})-V_{\text{mfa}}^{\tau}(\Lambda_{\text{mfa}}(\pi_{\delta}),\pi_{\delta})

\displaystyle\leq\max_{\pi^{\prime}\in\Pi_{H}}V_{\text{mfa}}^{\tau}(\Lambda_{\text{mfa}}(\pi_{\delta}),\pi^{\prime})-V_{\text{mfa}}^{\tau}(\Lambda_{\text{mfa}}(\pi_{\delta}),\pi_{\delta})

\displaystyle\quad+\left|V_{\text{mfa}}^{\tau}(\Lambda_{\text{mfa}}(\pi_{\delta}),\pi^{\prime})-J_{\text{auc}}^{\tau,i}(\pi^{\prime},\boldsymbol{\pi}^{-i})\right|+\left|V_{\text{mfa}}^{\tau}(\Lambda_{\text{mfa}}(\pi_{\delta}),\pi_{\delta})-J_{\text{auc}}^{\tau,i}(\boldsymbol{\pi})\right|

\displaystyle\leq\delta+\frac{C_{1}}{\sqrt{N}}+\frac{C_{2}}{N}=\delta+\mathcal{O}\left(\frac{1}{\sqrt{N}}\right).

In case
K_{\xi}(K_{\alpha}+1)\not=1
, the constants
C_{1}
and
C_{2}
are given by

\displaystyle C_{1}

E.4
Proof of
Theorem

2
, part 2 (Approximation in Objective)

We show that, under Lipschitz conditions, the objective computed under the mean field approximation closely matches its expected value under a finite population of agents.

Theorem 5
(Convergence of the Mechanism Objective)

Let
g:\Delta_{\mathcal{S}\times\mathcal{A}}^{H}\to\mathbb{R}
be a Lipschitz-continuous objective defined over the class of Batched Auction Mean Field Games (BA-MFGs). Let
\mathcal{M}_{\text{mfa}}
be a BA-MFG with Lipschitz-continuous
\{u_{h}\}_{h=0}^{H-1},\{w_{h}\}_{h=0}^{H-1},\{\alpha_{h}\}_{h=0}^{H-1},\{p_{h}\}_{h=0}^{H-1}
. Let
\boldsymbol{\pi}=(\pi,\dots,\pi)
be the joint population policy for some
\pi\in\Pi_{H}
. Then:

\left|g(\Lambda_{\text{mfa}}(\pi))-G(\boldsymbol{\pi})\right|=\mathcal{O}\left(\tfrac{1}{\sqrt{N}}\right),

where
G(\boldsymbol{\pi})=\mathbb{E}[g(\{\widehat{L}_{h}\}_{h=0}^{H-1})|\boldsymbol{\pi}]
.

Proof:

We use a decomposition over the support of
\widehat{\bm{L}}
and apply the triangle inequality:

\displaystyle\left|g(\Lambda_{\text{mfa}}(\pi))-G(\boldsymbol{\pi})\right|

\displaystyle=\left|\sum_{\bm{L}}\mathbb{P}[\widehat{\bm{L}}=\bm{L}|\boldsymbol{\pi}]\left(g(\Lambda_{\text{mfa}}(\pi))-g(\bm{L})\right)\right|

\displaystyle\leq\sum_{\bm{L}}\mathbb{P}[\widehat{\bm{L}}=\bm{L}|\boldsymbol{\pi}]\left|g(\Lambda_{\text{mfa}}(\pi))-g(\bm{L})\right|

\displaystyle\leq\sum_{\bm{L}}\mathbb{P}[\widehat{\bm{L}}=\bm{L}|\boldsymbol{\pi}]K_{g}\|\Lambda_{\text{mfa}}(\pi)-\bm{L}\|_{1}

\displaystyle=K_{g}\mathbb{E}\left[\|\Lambda_{\text{mfa}}(\pi)-\widehat{\bm{L}}\|_{1}\right],

where
K_{g}
is the Lipschitz constant of
g
. The result follows by applying the bound from
Corollary

4
.

\square

Lemma 13
(Lipschitz Continuity of Expected Revenue)

Let
g_{\text{rev}}
denote the expected revenue objective. Let
\mathcal{M}_{\text{mfa}}
be a BA-MFG with Lipschitz-continuous payment functions
\{p_{h}\}_{h=0}^{H-1}
and allocation functions
\{\alpha_{h}\}_{h=0}^{H-1}
. Let
\bm{L}=\{L_{h}\}_{h=0}^{H-1}
and
\bm{L}^{\prime}=\{L_{h}^{\prime}\}_{h=0}^{H-1}
be two arbitrary state-action distribution trajectories over
H
rounds. Then,

\left|g_{\text{rev}}(\bm{L})-g_{\text{rev}}(\bm{L}^{\prime})\right|\leq(B_{p}(2+K_{\alpha})+K_{p})\|\bm{L}-\bm{L}^{\prime}\|_{1},

where
B_{p}
is a uniform bound on the absolute value of the payment functions,
K_{p}
is their Lipschitz constant, and
K_{\alpha}
is the Lipschitz constant of the allocation threshold functions.

Proof:

The expected revenue, for
\bm{L}=\{L_{h}\}_{h=0}^{H-1}
, can be rewritten using the operator
\Xi

g_{\text{rev}}(\bm{L}):=\sum_{h=0}^{H-1}\sum_{s,a}\left(L_{h}(s,a)-\Xi_{\alpha_{h}(\nu^{-\perp}(L_{h}))}(L_{h})(s,a)\right)p_{h}\left(a,\nu^{-\perp}(L_{h})\right).

To simplify notation, we define

\overline{\Xi}_{\alpha}(L):=L-\Xi_{\alpha}(L),

representing the residual (unallocated) mass at each state-action pair. Applying the triangle inequality:

\displaystyle\left|g_{\text{rev}}(\bm{L})-g_{\text{rev}}(\bm{L}^{\prime})\right|

\displaystyle\leq\sum_{h=0}^{H-1}\Bigg|\sum_{s,a}\left(\overline{\Xi}_{\alpha_{h}(\nu^{-\perp}(L_{h}))}(L_{h})(s,a)\right)p_{h}(a,\nu^{-\perp}(L_{h}))

\displaystyle\quad\quad-\left(\overline{\Xi}_{\alpha_{h}(\nu^{-\perp}(L_{h}^{\prime}))}(L^{\prime}_{h})(s,a)\right)p_{h}(a,\nu^{-\perp}(L_{h}^{\prime}))\Bigg|

\displaystyle\leq\sum_{h=0}^{H-1}\sum_{s,a}\left|\overline{\Xi}_{\alpha_{h}(\nu^{-\perp}(L_{h}))}(L_{h})(s,a)-\overline{\Xi}_{\alpha_{h}(\nu^{-\perp}(L_{h}^{\prime}))}(L_{h}^{\prime})(s,a)\right|\left|p_{h}(a,\nu^{-\perp}(L_{h}))\right|

\displaystyle\quad+\sum_{h=0}^{H-1}\sum_{s,a}\overline{\Xi}_{\alpha_{h}(\nu^{-\perp}(L_{h}^{\prime}))}(L_{h}^{\prime})(s,a)\left|p_{h}(a,\nu^{-\perp}(L_{h}))-p_{h}(a,\nu^{-\perp}(L_{h}^{\prime}))\right|.

Using the boundedness of the payment function
p
and the Lipschitz continuity of the allocation operator
\Xi_{\alpha}
, the first term can be bounded by
B_{p}(2+K_{\alpha})\sum_{h=0}^{H-1}\|L_{h}-L_{h}^{\prime}\|_{1}
. For the second term, the Lipschitz property of
p
implies a bound of
\sum_{h=0}^{H-1}K_{p}\|L_{h}-L_{h}^{\prime}\|_{1}1
. Combining these, we conclude that the revenue objective
g_{\text{rev}}
is Lipschitz continuous with constant
B_{p}(2+K_{\alpha})+K_{p}
, and satisfies the bound

\left|g_{\text{rev}}(\bm{L})-g_{\text{rev}}(\bm{L}^{\prime})\right|\leq(B_{p}(2+K_{\alpha})+K_{p})\|\bm{L}-\bm{L}^{\prime}\|_{1}

\square

E.5
Proof of
Lemma

3

In this section, we prove that the (entropy regularized) q-functions are Lipschitz continuous with respect to the population policy, assuming full support. We begin by showing that the population flow is Lipschitz in the policy. Next, we establish that both the transition dynamics and the reward function are Lipschitz continuous with respect to the population distribution. Finally, we combine these results to derive a bound on the Lipschitz constant of the (entropy regularized) q-functions.

Lemma 14
(Lipschitz Continuity of Population Operator)

Let
\mathcal{M}_{\text{mfa}}=(\mathcal{S},\mathcal{A},H,\mu_{0},\{P^{\text{mfa}}_{h}\}_{h=0}^{H-1},\{R^{\text{mfa}}_{h}\}_{h=0}^{H-1})
be a Batched Auction Mean Field Game (BA-MFG). Let
\{\alpha_{h}\}_{h=0}^{H-1}
,
\{w_{h}\}_{h=0}^{H-1}
,
\{p_{h}\}_{h=0}^{H-1}
, and
\{u_{h}\}_{h=0}^{H-1}
denote the allocation thresholds, transition dynamics, payment, and utility functions, respectively, from which
\{P^{\text{mfa}}_{h}\}_{h=0}^{H-1}
and
\{R^{\text{mfa}}_{h}\}_{h=0}^{H-1}
are derived. Assume these functions are Lipschitz continuous. Consider two arbitrary policies
\pi,\pi^{\prime}\in\Pi_{H}
, then

\|\Lambda_{\text{mfa}}(\pi)-\Lambda_{\text{mfa}}(\pi^{\prime})\|_{1}\leq\sum_{h^{\prime}\leq h}(K_{\xi}(1+K_{\alpha}))^{h-h^{\prime}}\|\pi_{h^{\prime}}-\pi^{\prime}_{h^{\prime}}\|_{1}

Proof:

We prove the bound inductively. Let
L^{\pi}:=\Lambda_{\text{mfa}}(\pi)
and
L^{\pi^{\prime}}:=\Lambda_{\text{mfa}}(\pi^{\prime})
denote the population flows induced by policies
\pi
and
\pi^{\prime}
, respectively. Similarly, let
\mu^{\pi}
and
\mu^{\pi^{\prime}}
denote the corresponding marginal state distributions.

For
h=0
we have
\mu_{0}^{\pi}=\mu_{0}^{\pi^{\prime}}=\mu_{0}
. Therefore by
Lemma

9
we have
\|L_{0}^{\pi}-L_{0}^{\pi^{\prime}}\|_{1}\leq\|\pi_{0}-\pi_{0}^{\prime}\|_{1}
.

For
h+1>0
by applying the result of
Lemma

9
we have

\|L_{h+1}^{\pi}-L_{h+1}^{\pi^{\prime}}\|_{1}\leq\|\pi_{h+1}-\pi_{h+1}^{\prime}\|_{1}+\|\mu_{h+1}^{\pi}-\mu_{h+1}^{\pi^{\prime}}\|_{1}.

We then bound the variational difference in state distribution:

\displaystyle\|\mu_{h+1}^{\pi}-\mu_{h+1}^{\pi^{\prime}}\|_{1}

\displaystyle=\|\Gamma_{w}(\xi_{h}^{\pi})-\Gamma_{w}(\xi_{h}^{\pi^{\prime}})\|_{1}\leq K_{\xi}\|\xi_{h}^{\pi}-\xi_{h}^{\pi^{\prime}}\|_{1}

\displaystyle=K_{\xi}\|\Gamma_{\alpha_{h}}(L_{h}^{\pi})-\Gamma_{\alpha_{h}}(L_{h}^{\pi^{\prime}})\|_{1}\leq K_{\xi}(1+K_{\alpha})\|L_{h}^{\pi}-L_{h}^{\pi^{\prime}}\|_{1},

where in the last step we used
Corollary

3
.
By induction over
h
the claim follows.

\square

Lemma 15
(Lipschitz Continuity of Transitions and Rewards under Full-Support Policies)

Let
\mathcal{M}_{\text{mfa}}
be a BA-MFG with utility functions
\{u_{h}\}_{h=0}^{H-1}
, transition dynamics
\{w_{h}\}_{h=0}^{H-1}
, payment functions
\{p_{h}\}_{h=0}^{H-1}
, and allocation thresholds
\{\alpha_{h}\}_{h=0}^{H-1}
, all of which are Lipschitz-continuous with constants
K_{u}
,
K_{w}
,
K_{p}
, and
K_{\alpha}
, respectively. Consider two policies
\pi,\pi^{\prime}\in\Pi_{H}
with full support; that is, for all

,
a\in\mathcal{A}
, and
h\in{0,\dots,H-1}
, we have
\pi_{h}(a|s)>\epsilon
and
\pi_{h}^{\prime}(a|s)>\epsilon

. Then

\displaystyle\bigl|R^{\text{mfa}}_{h}(s,a,L_{h}^{\pi})-

\displaystyle R^{\text{mfa}}_{h}(s,a,L_{h}^{\pi^{\prime}})\bigr|

\displaystyle\bigl\|P^{\text{mfa}}_{h}(s,a,L_{h}^{\pi})-

\displaystyle P^{\text{mfa}}_{h}(s,a,L_{h}^{\pi^{\prime}})\bigr\|_{1}

Let

be two arbitrary policies with full support Let

and

and

.

Lemma 16
(Lipschitz Continuity of Regularized Value Functions)

Let
\mathcal{M}_{\text{mfa}}
be a BA-MFG with utility functions
\{u_{h}\}_{h=0}^{H-1}
, transition dynamics
\{w_{h}\}_{h=0}^{H-1}
, payment functions
\{p_{h}\}_{h=0}^{H-1}
, and allocation thresholds
\{\alpha_{h}\}_{h=0}^{H-1}
, all of which are Lipschitz-continuous with constants
K_{u}
,
K_{w}
,
K_{p}
, and
K_{\alpha}
, respectively.

Let
\pi,\pi^{\prime}\in\Pi_{H}
be two policies with full support, i.e., for some
\epsilon>0
,
\pi_{h}(a|s),\pi_{h}^{\prime}(a|s)>\epsilon
, for all
h,s,a
. Let
V_{h}^{\tau}(s|L^{\pi},\pi)
and
V_{h}^{\tau}(s|L^{\pi^{\prime}},\pi^{\prime})
denote the entropy-regularized value functions under policies
\pi
and
\pi^{\prime}
, defined recursively as

V_{h}^{\tau}(s|L^{\pi},\pi):=\tau H(\pi_{h}(s))+\sum_{a\in\mathcal{A}}\pi_{h}(a|s)\left[R^{\text{mfa}}_{h}(s,a,L_{h}^{\pi})+\sum_{s^{\prime}}P^{\text{mfa}}_{h}(s^{\prime}|s,a,L_{h}^{\pi})V_{h+1}^{\tau}(s^{\prime}|L^{\pi},\pi)\right],

where
\{L_{h}^{\pi}\}_{h=0}^{H-1}:=\Lambda_{\text{mfa}}(\pi)
is the population distribution induced by policy
\pi
.

Then, there exists a constant
C>0
such that for all
h
and all
s\in\mathcal{S}
, the following bound holds:

\displaystyle\left|V_{h}^{\tau}(s|L^{\pi},\pi)-V_{h}^{\tau}(s|L^{\pi^{\prime}},\pi^{\prime})\right|

\displaystyle\leq C\|\pi-\pi^{\prime}\|_{1},

where
C=\mathcal{O}(\frac{1}{\epsilon}H^{2})
when
K_{\xi}(1+K_{\alpha})=1
, and
C=\mathcal{O}(\frac{1}{\epsilon}H\tfrac{1-(K_{\xi}(1+K_{\alpha}))^{H}}{1-K_{\xi}(1+K_{\alpha})})
when
K_{\xi}(1+K_{\alpha})\not=1
.

Proof:

We prove a stronger inductive bound that implies the result of the lemma. To simplify notation, we introduce the following constants:

•

\beta:=K_{\xi}(1+K_{\alpha})
,

•

B:=B_{u}+\tau\log(|\mathcal{A}|)
,

•

g_{0}:=\frac{B_{u}}{(1-\alpha_{\max})\epsilon}+K_{u}K_{p}
,

•

g_{1}:=(B_{u}+\tau\log(|\mathcal{A}|))\left(\frac{2}{(1-\alpha_{\max})\epsilon}+K_{\alpha}+1\right)
.

We also define the following
h
-dependent quantities, which will be used in the inductive argument:

•

A_{h}:=\tau(\log(\tfrac{1}{\epsilon})+1)+(H-h)B
,

•

G_{h}:=g_{0}+g_{1}(H-h-1)
,

•

\Delta_{h}:=\|\pi_{h}-\pi_{h}^{\prime}\|_{1}
.

We proceed by backward induction on the round
h
, and show that the following bound holds:

\displaystyle\left|V_{h}^{\tau}(s\mid L^{\pi},\pi)-V_{h}^{\tau}(s\mid L^{\pi^{\prime}},\pi^{\prime})\right|\leq\sum_{h^{\prime}=h}^{H-1}A_{h^{\prime}}\Delta_{h^{\prime}}+\sum_{h^{\prime}=h}^{H-1}G_{h^{\prime}}\sum_{h^{\prime\prime}\leq h^{\prime}}\beta^{h^{\prime}-h^{\prime\prime}}\Delta_{h^{\prime\prime}}.

For
h=H
by definition, the value function at round
H
is zero for all states, i.e.,

V_{H}^{\tau}(s|L^{\pi},\pi)=V_{H}^{\tau}(s|L^{\pi},\pi)=0

Assume that for value function at time
h+1
,
V_{h+1}^{\tau}
the upper bound holds. We now prove the same for
V_{h}^{\tau}
.
The regularized value function is:

V_{h}^{\tau}(s|L^{\pi},\pi)=\tau\mathcal{H}(\pi_{h}(s))+\sum_{a}\pi_{h}(a|s)q_{h}^{\tau}(s,a|L^{\pi},\pi).

Then,

\displaystyle|V_{h}^{\tau}(s|L^{\pi},\pi)-V_{h}^{\tau}(s|L^{\pi^{\prime}},\pi^{\prime})|

\displaystyle\leq\underbrace{\tau|\mathcal{H}(\pi_{h}(s))-\mathcal{H}(\pi_{h}^{\prime}(s))|}_{:=(\square)}+\underbrace{\left|\sum_{a}\pi_{h}(a|s)q_{h}^{\tau}(s,a|L^{\pi},\pi)-\sum_{a}\pi_{h}^{\prime}(a|s)q_{h}^{\tau}(s,a|L^{\pi^{\prime}},\pi^{\prime})\right|}_{:=(\triangle)}.

For the entropy term
(\square)
we have

\tau|\mathcal{H}(\pi_{h}(s))-\mathcal{H}(\pi_{h}^{\prime}(s))|\leq\tau\left(\log(\tfrac{1}{\epsilon})+1\right)\|\pi_{h}(s)-\pi_{h}^{\prime}(s)\|_{1}

By applying triangular inequality we can upper bound
(\triangle)
as follows:

\displaystyle(\triangle)\leq\sum_{a}|\pi_{h}(a|s)-\pi_{h}^{\prime}(a|s)|q_{h}^{\tau}(s,a|L^{\pi},\pi)|+\sum_{a}\pi_{h}^{\prime}(a|s)|q_{h}^{\tau}(s,a|L^{\pi},\pi)-q_{h}^{\tau}(s,a|L^{\pi^{\prime}},\pi^{\prime})|

The first term can be bounded as a function of
H
and the maximal absolute utility
B_{u}
:

\displaystyle\sum_{a}|\pi(a|s)-\pi^{\prime}(a|s)|q_{h}^{\tau}(s,a|L^{\pi},\pi)|\leq(H-h)\left(B_{u}+\tau\log(|\mathcal{A}|)\right)\|\pi_{h}(s)-\pi_{h}^{\prime}(s)\|_{1},

where the term
\tau\log(|\mathcal{A}|)
comes from the maximal additional reward from the entropy regularizer.s

For the second term we bound the absolute difference in
q
functions:

\displaystyle|q_{h}^{\tau}(s,a|L^{\pi},\pi)-

\displaystyle q_{h}^{\tau}(s,a|L^{\pi^{\prime}},\pi^{\prime})|

\displaystyle\leq\bigl|R^{\text{mfa}}_{h}(s,a,L_{h}^{\pi})-R^{\text{mfa}}_{h}(s,a,L_{h}^{\pi^{\prime}})\bigr|

\displaystyle\quad+\sum_{s^{\prime}}|P^{\text{mfa}}_{h}(s^{\prime}|s,a,L_{h}^{\pi})-P^{\text{mfa}}_{h}(s^{\prime}|s,a,L_{h}^{\pi^{\prime}})||V_{h+1}^{\tau}(s,a|L^{\pi},\pi)|

\displaystyle\quad+\sum_{s}P^{\text{mfa}}_{h}(s^{\prime}|s,a,L_{h}^{\pi^{\prime}})|V_{h+1}^{\tau}(s^{\prime}|L^{\pi},\pi)-V_{h+1}^{\tau}(s^{\prime}|L^{\pi^{\prime}},\pi^{\prime})|

\displaystyle\leq\bigl|R^{\text{mfa}}_{h}(s,a,L_{h}^{\pi})-R^{\text{mfa}}_{h}(s,a,L_{h}^{\pi^{\prime}})\bigr|

\displaystyle\quad+(H-h-1)(B_{u}+\tau\log(|\mathcal{A}|))\|P^{\text{mfa}}_{h}(s,a,L_{h}^{\pi})-P^{\text{mfa}}_{h}(s,a,L_{h}^{\pi^{\prime}})\|_{1}

\displaystyle\quad\max_{s}|V_{h+1}^{\tau}(s^{\prime}|L^{\pi},\pi)-V_{h+1}^{\tau}(s^{\prime}|L^{\pi^{\prime}},\pi^{\prime})|.

By combining all intermediate bounds and applying
Lemma

15
we have

\displaystyle\left|V_{h}^{\tau}(s\mid L^{\pi},\pi)-V_{h}^{\tau}(s\mid L^{\pi^{\prime}},\pi^{\prime})\right|

\displaystyle\leq A_{h}\Delta_{h}+G_{h}\sum_{h^{\prime}\leq h}\beta^{h-h^{\prime}}\Delta_{h}^{\prime}

\displaystyle\quad+\max_{s}|V_{h+1}^{\tau}(s^{\prime}|L^{\pi},\pi)-V_{h+1}^{\tau}(s^{\prime}|L^{\pi^{\prime}},\pi^{\prime})|,

by induction the bound holds. As next we compute the global Lipschitz constant.

\displaystyle\left|V_{h}^{\tau}(s\mid L^{\pi},\pi)-V_{h}^{\tau}(s\mid L^{\pi^{\prime}},\pi^{\prime})\right|\leq\underbrace{\sum_{h^{\prime}=h}^{H-1}A_{h^{\prime}}\Delta_{h^{\prime}}}_{(\square)}+\underbrace{\sum_{h^{\prime}=h}^{H-1}G_{h^{\prime}}\sum_{h^{\prime\prime}\leq h^{\prime}}\beta^{h^{\prime}-h^{\prime\prime}}\Delta_{h^{\prime\prime}}}_{(\triangle)}.

For
(\square)
we have:

\displaystyle\sum_{h^{\prime}=h}^{H-1}A_{h^{\prime}}\Delta_{h^{\prime}}\leq\sum_{h=0}^{H-1}A_{h}\Delta_{h}\leq A_{0}\sum_{h=0}^{H-1}\Delta_{h}

For
(\triangle)
we have:

\displaystyle\sum_{h^{\prime}=h}^{H-1}G_{h^{\prime}}\sum_{h^{\prime\prime}\leq h^{\prime}}\beta^{h^{\prime}-h^{\prime\prime}}\Delta_{h^{\prime\prime}}

\displaystyle\leq\sum_{h=0}^{H-1}G_{h}\sum_{h^{\prime}\leq h}\beta^{h-h^{\prime}}\Delta_{h^{\prime}}

\displaystyle=\sum_{h^{\prime}=0}^{H-1}\Delta_{h^{\prime}}\sum_{j=0}^{H-1-h^{\prime}}G_{h^{\prime}+j}\beta^{j}

\displaystyle=\sum_{h^{\prime}=0}^{H-1}\Delta_{h^{\prime}}\left(G_{h^{\prime}}\sum_{j=0}^{H-1-h^{\prime}}\beta^{j}-g_{1}\sum_{j=0}^{H-1-h^{\prime}}j\beta^{j}\right)

\displaystyle\leq\sum_{h^{\prime}=0}^{H-1}\Delta_{h^{\prime}}G_{h^{\prime}}\sum_{j=0}^{H-1-h^{\prime}}\beta^{j}

Using the definition of the geometric sum, and observing that the constants
G_{h^{\prime}}
as well as the nested geometric sum decrease as
h^{\prime}
increases, we can further simplify the bound by pulling out the leading terms. For
\beta\not=1
:

\sum_{h^{\prime}=0}^{H-1}\Delta_{h^{\prime}}G_{h^{\prime}}\sum_{j=0}^{H-1-h^{\prime}}\beta^{j}\leq\frac{1-\beta^{H}}{1-\beta}(g_{0}+g_{1}(H-1))\sum_{h=0}^{H-1}\Delta_{h},

while for
\beta=1
:

\sum_{h^{\prime}=0}^{H-1}\Delta_{h^{\prime}}G_{h^{\prime}}\sum_{j=0}^{H-1-h^{\prime}}\beta^{j}\leq H(g_{0}+g_{1}(H-1))\sum_{h=0}^{H-1}\Delta_{h}.

Combining the results (for
\beta\not=1
) of
(\square)
and
(\triangle)
we have:

\displaystyle\left|V_{h}^{\tau}(s\mid L^{\pi},\pi)-V_{h}^{\tau}(s\mid L^{\pi^{\prime}},\pi^{\prime})\right|(\tau(\log(\tfrac{1}{\epsilon})+1)+HB+\frac{1-\beta^{H}}{1-\beta}(g_{0}+g_{1}(H-1)))\sum_{h=0}^{H-1}\Delta_{h}.

For
\beta=1
the geometric term is replaced by
H
. By the definitions of
B,g_{0}
and
g_{1}
the claim follows.

\square

Baseline algorithms.

For the zeroth-order baseline algorithms
0
-
SGD
and
0
-
Adam
, we use the standard 2-point (biased) gradient estimator

\displaystyle\widehat{\nabla}_{\theta}:=\frac{G^{T}_{\textrm{approx}}(\theta+u_{\text{zero}}z)-G^{T}_{\textrm{approx}}(\theta-u_{\text{zero}}z)}{2u_{\text{zero}}}Dz,

This estimator satisfies the well-known property

\displaystyle\Exop[\widehat{\nabla}_{\theta}]=\grad\Exop[G^{T}_{\textrm{approx}}(\theta+u_{\text{zero}}\macc@depth\char 1\relax\macc@set@skewchar\macc@nested@a 111{z})],\quad\macc@depth\char 1\relax\macc@set@skewchar\macc@nested@a 111{z}\propto\operatorname{Uniform}(\mathbb{B}_{D}).

That is,

is an unbiased estimator of the gradient of a smoothed version of the function

The bias is tunable by the parameter

Since a single evaluation of this gradient estimator takes 2 forward passes over

per iteration.
For the baseline
Anneal

After evaluating

for the tunable hyperparameter
\sigma_{\text{anneal}}>0
,

updates
\theta
to be the best among
\theta,\theta-\sigma_{\text{anneal}}n,\theta+\sigma_{\text{anneal}}n
