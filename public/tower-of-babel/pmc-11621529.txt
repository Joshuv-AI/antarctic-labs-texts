Experimental validation of model-free predictive control based on the active vector execution time for grid-connected system
Authors: Zakaria Lammouchi, Chouaib Labiod, Kamel Srairi, Mohamed Benbouzid, Abderrahmane Khechekhouche, Fahad Albalawi, Sherif S. M. Ghoneim, Enas Ali, Ahmed B. Abou Sharaf
Published: 2024

ABSTRACT
The application of Model-Free Predictive Control (MFPC) in power electronic systems has garnered increasing attention. In this paper, MFPC control based on replacing the classical factory model with an ultra-local model (ULM) is studied. Generally, the Integral Sliding Mode Observer (ISMO) is used to estimate the unknown part in the ULM where the non-physical factor in the ULM is selected with approximate values ​​ranging from the nominal value of the system which is contrary to the concept of MFPC control. In this research, an improved adaptive integral sliding mode observer (AISMO) based MFPC (AISMO-MFPC ) is proposed to estimate this factor with the unknown function in the ULM equation. The new observer design enables the estimation of this factor based on the current error, which allows for independent prposedcontrol of the system parameters.To obtain the lowest current ripple, the concept of active vector execution time (AVET ) has been incorporated into the proposed control where two vectors are selected in the sampling period to minimize the cost function instead of selecting a single vector. ULM is also used to calculate AVET which facilitates the implementation of the imposed control. The combination of the proposed AISMO-MFPC and AVET gives faster system response and reduces the current ripple and lower harmonics, especially in case of mismatch parameters. Finally, the effectiveness of the proposed control is confirmed under various conditions by the presented simulation and experimental results.

Introduction

Predictive control strategies have been developed over in recent years remarkably in power electronic, due to their crucial role in energy conversion, such as renewable energy systems, and grid-connected renewable energy systems1. Finite state model prediction control (FS-MPC) is one of the strategies model prediction control (MPC) that adopts the predictive model to achieve system control2, the FS-MPC is based on a cost function consisting of the error between the predicted variables and their reference values3–5. It is necessary to evaluate all vectors related of power electronic to determine the optimal effort6,7. Despite the good performance of MPC, this technique requires very accurate system parameters8,9, if these parameters contain measurement errors the performance of MPC can be greatly destroyed.

A recent approach known as Model-Free Predictive Control (MFPC) has emerged as an alternative to dealing with parameter variations and solving problems found in MPC10,11.the authors of12 proposed a MFPC approach where motor current variations are measured and dynamically stored in a look-up table. Using these measurements, the approach predicts current variations. However, the frequency with which measurements are updated significantly impacts the performance of this method. MFPC has been proposed proposed in13, which uses a recursive least-squares (RLS) algorithm in the current prediction model. This approach recursively predicts the next-step current based on previous current samples.

In14, the parameters of the autoregressive model with external inputs (ARX) are determined using an iterative least squares algorithm to control the current in the power converter. While this approach offers a significant advantage due to its high degree of flexibility and independence from specific system parameters and model phenomena15, it suffers from notable drawbacks, most notably its computational burden and dependence on the initial value.

Model-Free Predictive Control (MFPC) using an ultra-local model (ULM ) is an approach that bridges the gap between completely model-free techniques and those that utilize models is proposed in16. An ULM is a simplified or highly localized model of the system that only captures very short-term or local behavior rather than the full dynamics of the system, the input directly articulates the derivatives of the system output through a linear model ULM3. In this framework, an unknown part summarizes all unknown system dynamics and potential disturbances, which necessitates estimation through online identification techniques6,16, which needs a complex mathematical process and necessitates employing high-speed and costly numerical processors.

To overcome this problem, an observer-based MFPC scheme has been proposed in6, which estimates the unknown part of the system by a state observer. The extended state observer (ESO) has been applied in17,18 to determine the states of ULM. Although, the results in this work showed remarkably robustness of control, its drawbacks lie in that it is used as a sub-part rather than the main part of the prediction model in most researches19,20. In21, the ESO is proposed for ULM to simplify MFPC. In contrast, it finds that the unknown function in ULM has a non-linear character and does not have a constant value that may increase the estimation error. As discussed in22, the unknown part in ULM is estimated by using a sliding mode observer (SMO). However, the invariance principle is not preserved during the transition to the sliding manifold in the reaching phase. Fortunately, this issue can be effectively addressed through the utilization of an integral sliding mode observer (ISMO) based MFPC(ISMO-MFPC)23. ISMO is used to estimate the unknown part in the ULM where the non-physical factor in the ULM is selected with approximate values ​​ranging from the nominal value of the system. It is proved in24,25 that factor is chosen with approximate values ranging between \documentclass[12pt]{minimal} \usepackage{amsmath} \usepackage{wasysym} \usepackage{amsfonts} \usepackage{amssymb} \usepackage{amsbsy} \usepackage{mathrsfs} \usepackage{upgreek} \setlength{\oddsidemargin}{-69pt} \begin{document}$$\:\pm\:50\mathbf{\%}$$\end{document} of the nominal value of the system, which is contrary to the concept of MFPC control.This paper proposes an adaptive integral sliding mode observer (AISMO) based Model-Free Predictive Control (AISMO- MFPC) to estimate the unknown function and factor variation in ULM, where this factor depends on the error current.

In26, the MFPC control uses the sampling period to select one voltage vector for the all-candidate vectors according to minimize the cost function.The delay problem in the predictive controller may degrade the controller’s performance. Numerous efforts have been dedicated in literature to enhance switching sequences of the inverter such as the constant switching frequency has been proposed in27, or to improve the cost function such as the multi-objective cost function in7, in order to minimize output ripples.This paper introduces an approach termed Execution Time of Active Vector with Model-Free Predictive Control tailored for two-level inverters. The execution time AVET is calculated using the ULM equation. With the proposed control, there is good tracking and less computational burden as it uses only six voltage vectors instead of all eight candidate vectors in the cost function.

In this paper, the main contribution is to introduce an adaptive integral sliding mode observer based MFPC (AISMO-MFPC ) is proposed to estimate the non-physical factor in the ULM equation with the unknown function, since this factor has no depend with the system parameters. While it varys with the change of the current error, This variation appears when the current values ​​change or during the mismach parameters, leading to a faster response and reducing the resulting current ripple and lower harmonics.

Moreover, the integration of the concept of active vector execution time (AVET) in the proposed control contributes to reducing the computational time with better tracking where the cost function minimization process is done at this time with the least possible vectors for two-level inverter. Using ULM to calculate AVET also contributes to simplifying the implementation of the imposed control. The effectiveness and robustness of the proposed control are verified confirmed under various conditions by the presented simulation and experimental results .and compared with conventional methods.

Proposed AISMO–MFPC-(AVET) control

To improve control performance by reducing the output current ripple signal and the robustness in case parameter mismatch. An adaptive integral sliding mode observer based MFPC (AISMO-MFPC ) is proposed to estimate the non-physical factor in the ULM equation and the unknown function. Moreover, incorporating the concept of Active Vector Execution Time (AVET) into the proposed control helps reduce the computation time with better traceability as the cost function minimization process is done with fewer possible vectors for a two-level inverter than conventional control.

Conclusion

Model-free predictive control based on an adaptive observer using active vector execution time AISMO-MFPC-(AVET) is proposed in this paper to improve the model-free predictive control methods that use a ultra- local model. The design of the proposed adaptive observer is completely independent of the system parameters as it is based on the estimation of the unknown part and the non-physical factor in the ULM equation. To obtain the lowest current ripple, the concept of active vector execution time (AVET ) has been incorporated into the proposed control to minimize the cost function instead of selecting a single vector. ULM is also used to calculate AVET which facilitates the implementation of the imposed control.The comparative evaluation of AISMO-MFPC-(AVET) with ISMO-MFPC and conventional MPC approaches confirms the efficiency and effectiveness of the proposed control as well as its complete parameters independence, which enhances the robustness of the imposed control.The efficiency of the proposed control based on AISMO-MFPC-(AVET) has been verified experimentally using a TMS320F28379D digital processor with a two-level inverter. Experimental validation is a testament to the effectiveness of the AISMO-MFPC-(AVET) in real-time applications against parameters mismatch while providing superior control performance.Calculating some of the factors in the imposed observer and controller and estimating the unknown part in complex systems is a path for future research. The possibility of incorporating one of the artificial intelligence techniques into the imposed control provides a promising path for developing this method. Artificial neural network technology and reinforcement learning technology are advanced evaluations that improve control techniques’ performance. Which may lead to unprecedented levels of efficiency, accuracy, and robustness.
