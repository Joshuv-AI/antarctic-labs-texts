Sums and differences of sets: a further improvement over AlphaEvolve
Fan Zheng

Abstract
We present a new advancement in the sum and difference of sets problem, which improves upon recent results by both DeepMind’s AlphaEvolve ( θ = 1.1584 \theta=1.1584 ) and subsequent explicit constructions ( θ = 1.173050 \theta=1.173050 ). In this work, we construct a sequence of U U sets which in the limit establishes a new lower bound of θ = 1.173077 \theta=1.173077 .



Keywords and phrases:
Sumset, Difference set, AlphaEvolve

11B75

1
Introduction

Let
K>1
be a real number. In
[
2
]
, the authors studied the growth of sumsets and difference sets of integers and posed the problem of determining the largest possible exponent
\theta
such that, for arbitrarily large finite sets
A
and
B
of integers, the following holds for some constant
c(K)>0
:

|A+B|\leq K|A|\quad\text{and}\quad|A-B|\geq c(K)\cdot|A+B|^{\theta}.

(1)

They showed that for any finite set
U\subset\mathbb{N}
containing zero, the inequality

\theta\geq 1+\frac{\log\left(\frac{|U-U|}{|U+U|}\right)}{\log(2\max(U)+1)}

provides a lower bound on the attainable exponent
\theta
. Their constructions were based on a combinatorial set
V=V(m,L)\subset\mathbb{N}^{m}
defined by

V(m,L)=\left\{(x_{1},\ldots,x_{m})\in\mathbb{N}^{m}:x_{1}+\cdots+x_{m}\leq L\right\},

which satisfies
|V(m,L)|=\binom{m+L}{m}
. An injective mapping
f
was used to transform vectors into integers via

f(x_{1},\ldots,x_{m})=\sum_{k=0}^{m-1}x_{k}\cdot L_{k},\quad\text{with }L_{0}=1,\quad L_{k}=2L\cdot L_{k-1}+1\text{ for }k>0,

ensuring that
f
is injective on both
V+V
and
V-V
. The image
U=f(V)
then served as the key set for evaluating
\theta
. This approach established the bound
\theta\geq 1.14465
.

More recently, DeepMind’s AlphaEvolve system
[
4
]
applied large language models to this problem and achieved an improved bound of
\theta=1.1584
using a set of 54,265 integers. A subsequent explicit construction
[
1
]
raised this to
\theta=1.173050
using a
U
set with over
10^{43{,}546}
elements.

In this work, we construct a sequence of
U
sets which, in the limit, establishes a new lower bound of

\theta=1.173077.

Our approach builds on the previous combinatorial framework and extends it to
U
sets of arbitrarily large size. To achieve this, we analyze the asymptotic behavior of sets of the form

W(m,L,B)=\left\{x=(x_{1},\ldots,x_{m})\in V(m,L):x_{1}\leq B,\ldots,x_{m}\leq B\right\},

where each coordinate is individually bounded. Estimating the size of such sets for large
m
and
L
requires a new ingredient: large deviation estimates, which allow us to quantify the distribution of constrained integer partitions and obtain precise asymptotic counts necessary for bounding
\theta
.

2
Large deviation estimates

Let
m
,
L
and
B
be nonnegative integers. Define:

W(m,L,B)=\left\{x=(x_{1},\ldots,x_{m})\in V(m,L):x_{1}\leq B,\ldots,x_{m}\leq B\right\}.

Lemma 1
.

\lim_{m\to\infty}\frac{\log|W(m,\lfloor{rm}\rfloor,B)|}{m}=\log(B+1)-I(r,B),

where

I(c,B)=\begin{cases}0,&c\geq B/2,\\
\sup_{t}\left(tc-\log\frac{1+e^{t}+\dots+e^{Bt}}{B+1}\right),&c<B/2.\end{cases}

Proof.

We regard each
x_{i}
as an independent random variable uniformly distributed over the set
\{0,1,\dots,B\}
. Then the mean value of each
x_{i}
is
B/2
. By the law of large numbers, as
m\to\infty
,

\frac{|W(m,\lfloor{mB/2}\rfloor,B)|}{(B+1)^{m}}=\mathbb{P}(x_{1}+\dots+x_{m}\leq mB/2)\to\frac{1}{2}.

If
r\geq B/2
, then
W(m,\lfloor{rm}\rfloor,B)\supseteq W(m,\lfloor{mB/2}\rfloor,B)
, so

\liminf_{m\to\infty}\frac{|W(m,\lfloor{rm}\rfloor,B)|}{(B+1)^{m}}\geq\frac{1}{2}.

Then

\liminf_{m\to\infty}(\log|W(m,\lfloor{rm}\rfloor,B)|-m\log(B+1))\geq-\log 2.

Then

\liminf_{m\to\infty}\frac{\log|W(m,\lfloor{rm}\rfloor,B)|}{m}\geq\log(B+1).

On the other hand,

\frac{\log|W(m,\lfloor{rm}\rfloor,B)|}{m}\leq\frac{\log(B+1)^{m}}{m}=\log(B+1),

so

\lim_{m\to\infty}\frac{\log|W(m,\lfloor{rm}\rfloor,B)|}{m}=\log(B+1).

If
r<B/2
, note that
c\mapsto I(c,B)
is the Legendre transformation of the generating function of the random variable
x_{i}
, so by Cramer’s theorem
[
Cramer
]
,

\lim_{m\to\infty}\frac{\log\mathbb{P}(x_{1}+\dots+x_{m}\leq mB/2)}{m}=-I(r,B).

On the other hand,

\log\frac{\mathbb{P}(x_{1}+\dots+x_{m}\leq mB/2)}{m}=\frac{\log|W(m,\lfloor{mB/2}\rfloor,B)|}{m}-\log(B+1),

so

\lim_{m\to\infty}\frac{\log|W(m,\lfloor{rm}\rfloor,B)|}{m}=\log(B+1)-I(r,B).

∎

Lemma 2
.

For any
c_{0}>0
we have

\limsup_{c\to c_{0}}I(c,B)\leq I(c_{0},B).

Proof.

If
c_{0}>B/2
then both sides are zero so the inequality trivially holds.

If
c_{0}<B/2
, by the AM–GM inequality, for
t\geq 0
we have

tc_{0}-\log\frac{1+e^{t}+\dots+e^{Bt}}{B+1}\leq tc_{0}-\log e^{\frac{Bt}{2}}=t\left(c_{0}-\frac{B}{2}\right)\leq 0,

with equality attained when
t=0
. Hence for any
c<B/2
we have

I(c,B)=\sup_{t\leq 0}\left(tc-\log\frac{1+e^{t}+\dots+e^{Bt}}{B+1}\right).

On the other hand, if
c>c_{0}/2
and
t<-\frac{2\log(B+1)}{c_{0}}
then

tc-\log\frac{1+e^{t}+\dots+e^{Bt}}{B+1}<-\log(B+1)-\log\frac{1}{B+1}=0,

so for
c\in(c_{0}/2,B/2)
we have

I(c,B)=\sup_{t\in\left[-\frac{2\log(B+1)}{c_{0}},0\right]}\left(tc-\log\frac{1+e^{t}+\dots+e^{Bt}}{B+1}\right).

Then for any
\epsilon>0
there is
t_{0}\in\left[-\frac{2\log(B+1)}{c_{0}},0\right]
such that

t_{0}c-\log\frac{1+e^{t_{0}}+\dots+e^{Bt_{0}}}{B+1}>I(c,B)-\epsilon.

Then

t_{0}c_{0}-\log\frac{1+e^{t_{0}}+\dots+e^{Bt_{0}}}{B+1}>I(c,B)-\epsilon-\frac{2\log(B+1)}{c_{0}}|c-c_{0}|.

Then there is
\delta>0
such that for any
c\in(c_{0}-\delta,c_{0}+\delta)
we have

I(c_{0},B)\geq t_{0}c_{0}-\log\frac{1+e^{t_{0}}+\dots+e^{Bt_{0}}}{B+1}>I(c,B)-2\epsilon,

showing the claim.

If
c_{0}=B/2
, then for any
c\geq c_{0}
,
I(c,B)=0
, so

\limsup_{c\to c_{0}+}I(c,B)=I(c_{0},B)=0.

For
c\in(c_{0}/2,c_{0})
we also have

t_{0}c_{0}-\log\frac{1+e^{t_{0}}+\dots+e^{Bt_{0}}}{B+1}>I(c,B)-\epsilon-\frac{2\log(B+1)}{c_{0}}|c-c_{0}|.

On the other hand,

t_{0}c_{0}-\log\frac{1+e^{t_{0}}+\dots+e^{Bt_{0}}}{B+1}\leq t_{0}c_{0}-\log e^{\frac{Bt_{0}}{2}}=0,

so

I(c,B)\leq\epsilon+\frac{2\log(B+1)}{c_{0}}|c-c_{0}|,

and then

\limsup_{c\to c_{0}-}I(c,B)\leq 0=I(c_{0},B).

∎

3
Main result

Theorem 1
.

For the sums and differences of sets problem, we have
\theta\geq 1.173077
.

Proof.

Following
[
1
]
, we construct the set
U
as the image of
W(m,L,B)
under the map
g:(x_{1},\dots,x_{m})\mapsto\sum_{k=0}^{m-1}x_{k}(2B+1)^{k}
,
with
B>0
fixed and
m
and
L\to\infty
. Then according to
[
2
]
, we have

\theta\geq 1+\frac{\log d(U)-\log s(U)}{\log q(U)},

where
d(U)=|U-U|
,
s(U)=|U+U|
and
q(U)=2\max(U)+1
.

Since each coordinate
x_{k}\leq B
, we have

\max U\leq B\sum_{k=0}^{m-1}(2B+1)^{k}=B\frac{(2B+1)^{m}-1}{2B},

so
q(U)=2\max(U)+1\leq(2B+1)^{m}
, and then

\frac{\log q(U)}{m}\leq\log(2B+1).

(2)

In
[
1
]
it was shown that
s(U)=W(m,2L,2B)
. We now let
L=\lfloor{rm}\rfloor
.
Then
2L\leq\lfloor{2rm}\rfloor
, so
W(m,2L,2B)\subseteq W(m,\lfloor{2rm}\rfloor,2B)
,
so by Lemma
1
,

\limsup_{m\to\infty}\frac{\log s(U)}{m}\leq\lim_{m\to\infty}\frac{W(m,\lfloor{2rm}\rfloor,2B)}{m}=\log(2B+1)-I(2r,2B).

(3)

In
[
1
]
it was also shown that

d(U)=\sum_{k=0}^{\min(m,L)}{m\choose k}|W(k,L-k,B-1)||W(m-k,L,B)|.

Then for any
k=0,\dots,\min(m,L)
we have

d(U)\geq{m\choose k}|W(k,L-k,B-1)||W(m-k,L,B)|.

We now let
k=\lfloor{aL}\rfloor
, where
a\in(0,\min(1,1/r))
is to be determined.
Then

L-k\geq(1-a)L\geq\frac{1-a}{a}k\geq\lfloor{\frac{1-a}{a}k}\rfloor,

so
W(k,L-k,B-1)\supseteq W(k,\lfloor{\frac{1-a}{a}k}\rfloor,B-1)
.
By Lemma
1
then,

\liminf_{m\to\infty}\frac{\log|W(k,L-k,B-1)|}{k}\geq\log B-I\left(\frac{1-a}{a},B-1\right).

Since

k=\lfloor{aL}\rfloor>aL-1=a\lfloor{rm}\rfloor-1>arm-a-1,

we have
\frac{k}{m}\to ar
as
m\to\infty
, so

\liminf_{m\to\infty}\frac{\log|W(k,L-k,B-1)|}{m}\geq ar\left(\log B-I\left(\frac{1-a}{a},B-1\right)\right).

(4)

Note that in the set
W(m,k,1)
, exactly
k
of the
m
coordinates are 1,
and the rest are 0, so
{m\choose k}=W(m,k,1)
. Since
\frac{k}{m}\to ar

as
m\to\infty
, for any
c<ar
, if
m
is sufficiently large then
k>cm
,
so
W(m,k,1)\supseteq W(m,cm,1)
. By Lemma
1
then,

\liminf_{m\to\infty}\frac{\log{m\choose k}}{m}\geq\log 2-I\left(c,1\right).

(5)

By Lemma
2
, we then have

\liminf_{m\to\infty}\frac{\log{m\choose k}}{m}\geq\log 2-\limsup_{c\to ar-}I\left(c,1\right)\geq\log 2-I(ar,1).

Likewise,

m-k<m-aL+1<m-arm+a+1

so

\frac{L}{m-k}>\frac{rm-1}{m-arm+a+1}\to\frac{r}{1-ar}

as
m\to\infty
, so

\liminf_{m\to\infty}\frac{\log|W(m-k,L,B)|}{m-k}\geq\log(B+1)-I\left(\frac{r}{1-ar},B\right).

Since
\frac{m-k}{m}\to 1-ar
as
m\to\infty
,

\liminf_{m\to\infty}\frac{\log|W(m-k,L,B)|}{m}\geq(1-ar)\left(\log(B+1)-I\left(\frac{r}{1-ar},B\right)\right).

(6)

Adding (
5
), (
4
) and (
6
) we get

\displaystyle\liminf_{m\to\infty}\frac{d(U)}{m}

\displaystyle\geq\log 2+ar\log B+(1-ar)\log(B+1)-I(ar,1)

\displaystyle-arI\left(\frac{1-a}{a},B-1\right)-(1-ar)I\left(\frac{r}{1-ar},B\right).

(7)

Putting (
7
), (
3
) and (
2
) together we have

\theta\geq\tfrac{\log 2+ar\log B+(1-ar)\log(B+1)-I(ar,1)-arI\left(\frac{1-a}{a},B-1\right)-(1-ar)I\left(\frac{r}{1-ar},B\right)+I(2r,2B)}{\log(2B+1)}.

We first maximize in
a
over
(0,\min(1,1/r))
, then maximize in
r>0
,
and finally maximize in
B
. Thus theoretically we would have
\theta\geq\theta_{0}
,
where

\displaystyle\theta_{0}

\displaystyle=\sup_{B\geq 1}\sup_{r>0}\sup_{a\in(0,\min(1,1/r))}

\displaystyle\tfrac{\log 2+ar\log B+(1-ar)\log(B+1)-I(ar,1)-arI\left(\frac{1-a}{a},B-1\right)-(1-ar)I\left(\frac{r}{1-ar},B\right)+I(2r,2B)}{\log(2B+1)}.

In reality we maximize
\theta-1
and take the supreme in a more restricted yetrelevant region:

\displaystyle\theta_{0}-1

\displaystyle\geq\sup_{B=3}^{10}\sup_{r\in(0.5,2)}\sup_{a\in(0,\min(1,1/r))}

\displaystyle\tfrac{\log 2+ar\log B+(1-ar)\log(B+1)-I(ar,1)-arI\left(\frac{1-a}{a},B-1\right)-(1-ar)I\left(\frac{r}{1-ar},B\right)-\log(2B+1)+I(2r,2B)}{\log(2B+1)}.

,

The function
theta(B, eps)
computes the optimal value for a fixed
B

at a fixed tolerance
\epsilon
:

function ret = theta_eps(B, eps)
fun = @(r) -(logD(r, B, eps) - logW(2*r, 2*B, eps));
options = optimset(’TolX’, eps);
[~, val] = fminbnd(fun, 0.5, 2, options);

The function
logD(r, B, eps)
maximizes the value

\log 2+ar\log B+(1-ar)\log(B+1)-I(ar,1)-arI\left(\frac{1-a}{a},B-1\right)-(1-ar)I\left(\frac{r}{1-ar},B\right)

in

(0,\min(1,1/r))

:

function ret = logD(r, B, eps)
fun = @(a) -term(r, B, a, eps);
options = optimset(’TolX’, eps);
[~, val] = fminbnd(fun, 0, min(1, 1/r), options);
ret = -val;
end

The function
term(r, B, a, eps)
computes the value above, at a fixed tolerance
\epsilon
:

function ret = term(r, B, a, eps)
ret = logW(a*r, 1, eps);
ret = ret + a*r * logW(1/a-1, B-1, eps);
ret = ret + (1-a*r) * logW(1/(1/r-a), B, eps);
end

The function

computes the value

:

function ret = I(c, B, eps)
if c < B/2

Finally the function

computes the supremum

\sup_{t}\left(tc-\log\frac{1+e^{t}+\dots+e^{Bt}}{B+1}\right)

function ret = sup(c, B, eps)
logE = @(t) log(mean(exp(t * (0:B))));

’OptimalityTolerance’,eps,...
’StepTolerance’,eps,...
’FunctionTolerance’,eps);
[~, ret] = fminunc((@(t) logE(t) - t * c), 0, opt);
ret = -ret;
end
