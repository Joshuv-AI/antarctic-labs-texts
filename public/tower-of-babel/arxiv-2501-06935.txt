Feedback Arc Sets and Feedback Arc Set Decompositions in Weighted and Unweighted Oriented Graphs
Gregory Gutin, Mads Anker Nielsen, Anders Yeo, Yacong Zhou

Abstract
Let D = ( V ⁡ ( D ) , A ⁡ ( D ) ) D=(V(D),A(D)) be a digraph with at least one directed cycle. A set F F of arcs is a feedback arc set (FAS) if D − F D-F has no directed cycle. The FAS decomposition number fasd ⁡ ( D ) {\rm fasd}(D) of D D is the maximum number of pairwise disjoint FASs whose union is A ⁡ ( D ) A(D) . The directed girth g ⁡ ( D ) g(D) of D D is the minimum length of a directed cycle of D D . Note that fasd ⁡ ( D ) ≤ g ⁡ ( D ) . {\rm fasd}(D)\leq g(D). The FAS decomposition number appears in the well-known and far-from-solved conjecture of Woodall (1978) stating that for every planar digraph D D with at least one directed cycle, fasd ⁡ ( D ) = g ⁡ ( D ) . {\rm fasd}(D)=g(D). The degree of a vertex of D D is the sum of its in-degree and out-degree. Let D D be an arc-weighted digraph and let fas w ​ ( D ) {\rm fas}_{w}(D) denote the minimum weight of its FAS. In this paper, we study bounds on fasd ⁡ ( D ) {\rm fasd}(D) , fas w ​ ( D ) {\rm fas}_{w}(D) and fas ⁡ ( D ) {\rm fas}(D) for arc-weighted oriented graphs D D (i.e., digraphs without opposite arcs) with upper-bounded maximum degree Δ ⁡ ( D ) \Delta(D) and lower-bounded g ⁡ ( D ) g(D) . Note that these parameters are related: fas w ​ ( D ) ≤ w ⁡ ( D ) / fasd ⁡ ( D ) {\rm fas}_{w}(D)\leq w(D)/{\rm fasd}(D) , where w ⁡ ( D ) w(D) is the total weight of D D , and fas ⁡ ( D ) ≤ | A ⁡ ( D ) | / fasd ⁡ ( D ) . {\rm fas}(D)\leq|A(D)|/{\rm fasd}(D). In particular, we prove the following: (i) If Δ ⁡ ( D ) ≤ 4 \Delta(D)\leq\penalty\ 4 and g ⁡ ( D ) ≥ 3 g(D)\geq 3 , then fasd ⁡ ( D ) ≥ 3 {\rm fasd}(D)\geq 3 and therefore fas w ​ ( D ) ≤ w ⁡ ( D ) 3 {\rm fas}_{w}(D)\leq\frac{w(D)}{3} which generalizes a known tight bound for an unweighted oriented graph with maximum degree at most 4; (ii) If Δ ⁡ ( D ) ≤ 3 \Delta(D)\leq 3 and g ⁡ ( D ) ∈ { 3 , 4 , 5 } g(D)\in\{3,4,5\} , then fasd ⁡ ( D ) = g ⁡ ( D ) {\rm fasd}(D)=g(D) ; (iii) If Δ ⁡ ( D ) ≤ 3 \Delta(D)\leq 3 and g ⁡ ( D ) ≥ 8 g(D)\geq 8 then fasd ⁡ ( D ) < g ⁡ ( D ) . {\rm fasd}(D)<g(D). We also give some bounds for the cases when Δ \Delta or g g are large and state several open problems and a conjecture.

Introduction

For terminology and notation on digraphs not introduced in this paper, see

A digraph
D=(V(D),A(D))
is

if

is given together with a function

A set

of a digraph

feedback arc set (FAS)
if

D-F
is acyclic. In the
unweighted (weighted, respectively)
feedback arc set problem
, given an unweighted (weighted, respectively)
digraph
D
, we are to find an FAS
F
of minimum size
(weight, respectively), denoted by
{\rm{fas}}(D)
(
{\rm{fas}}_{w}(D)
, respectively). The problem is

[

,
8

and both unweighted and weighted

[
2

11
,
12
,
23

. As the problem
is of great theoretical and practical interest, its various aspects
have been studied including approximation, exact, heuristic, and
parameterized algorithms, computational complexity, and upper and lower bounds.

Lower and upper bounds are usually studied for
oriented graphs
(or,
orgraphs
) i.e. digraphs without directed 2-cycles because we can reduce the FAS problem on digraphs to that on orgraphs as follows:
If a digraph
D
is unweighted, we can delete all arcs in directed 2-cycles reducing the size of minimum FAS by the number of directed 2-cycles.
Indeed, exactly one of the two arcs in a directed 2-cycle is in any
minimal FAS. If
D
is weighted, for every directed 2-cycle
C
, we reduce the weights of
both arcs of
C
by subtracting from each weight the minimum weight of the two. Then the arcs with zero weight can be deleted.

While almost all research on upper and lower bounds for the problem has been on
unweighted orgraphs, in this paper, we study upper and lower bounds
for weighted orgraphs. We take into consideration not only arc weights,
but also the maximum degree (the
degree
of a vertex is the sum of its
in- and out-degrees) and directed girth (the minimum number of arcs in
a directed cycle or
\infty

orgraphs. The maximum degree already appeared in the the following
well-known upper bounds of Berger and Shor
[
6

7

{{\rm{fas}}}(D)\leq(\frac{1}{2}-\Omega(\frac{1}{\sqrt{\Delta}}))a(D),
where

D

[
2

{{\rm{fas}}_{w}(D)}\leq(\frac{1}{2}-\frac{1}{16\sqrt{2\Delta}})w(D),
where

is the sum
of weights of a weighted orgraph
D

\Delta

[

[

[

The result can be easily extended to directed multigraphs, since adding multiple arcs does not affect the size of minimum feedback vertex sets. Hence, the following corollary holds.

Corollary 2

Let
D
be a connected directed multigraph with
\Delta(D)\leq 4

Conclusion

In this paper, we introduced a new parameter
{\rm{fasd}}(D)
for orgraphs
D
,
through which we prove several results for the feedback arc sets of
weighted orgraphs with bounded maximum degree and girth. In particular, we
have shown that
{\rm{fasd}}(4,3)=3

{\rm{fasd}}(3,g)=g

that

\Delta\geq 3
and
g\geq 3

{\rm{fasd}}(\Delta,g)
when
\Delta

{\rm{fasd}}(\Delta,g)=2

\Delta\geq{1362}
and
g\geq 3

would be interesting to determine more values of
{\rm{fasd}}(\cdot,\cdot)
