The Observational Partial Order of Causal Structures with Latent Variables
Marina Maciel Ansanelli, Elie Wolfe, Robert W. Spekkens

Abstract
For two causal structures with the same set of visible variables, one is said to observationally dominate the other if the set of distributions over the visible variables realizable by the first contains the set of distributions over the visible variables realizable by the second. Knowing such dominance relations is useful for adjudicating between these structures given observational data. We here consider the problem of determining the partial order of equivalence classes of causal structures with latent variables relative to observational dominance. We provide a complete characterization of the dominance order in the case of three visible variables, and a partial characterization in the case of four visible variables. Our techniques also help to identify which observational equivalence classes have a set of realizable distributions that is characterized by nontrivial inequality constraints, analogous to Bell inequalities and instrumental inequalities. We find evidence that as one increases the number of visible variables, the equivalence classes satisfying nontrivial inequality constraints become ubiquitous. (Because such classes are the ones for which there can be a difference in the distributions that are quantumly and classically realizable, this implies that the potential for quantum-classical gaps is also ubiquitous.) Furthermore, we find evidence that constraint-based causal discovery algorithms that rely solely on conditional independence constraints have a significantly weaker distinguishing power among observational equivalence classes than algorithms that go beyond these (i.e., algorithms that also leverage nested Markov constraints and inequality constraints).

Introduction

One way to probe the causal influence of one variable on another is to intervene upon the first and see whether the distribution over the other changes. Interventions are the basis of the randomized control trial. While such schemes yield strong causal conclusions, they can be prohibitively expensive (e.g., a drug trial), unethical (e.g., deciding whether smoking causes lung cancer), or simply impossible (e.g., in observational astronomy). For this reason, it is useful to understand what causal conclusions can be drawn from purely observational data, that is, from the probability distribution over the visible variables.

The problem of determining which causal structures are viable explanations of a given distribution over visible variables is referred to as the problem of
causal discovery
. The set of probability distributions over the visible variables that can be causally explained by a given causal structure generally satisfy nontrivial constraints. We refer to these constraints as
causal-compatibility constraints
.

An important class of causal inference problems concern causal structures wherein some of the variables may be latent (i.e., unobserved).
In the special case where a causal structure does
not
include latent variables, it will be called latent-free. While the causal-compatibility constraints of a latent-free causal structure always take the form of equalities, a causal structure that has latent variables can also exhibit causal-compatibility constraints in the form of inequalities. We will refer to these two types of constraints as
equality constraints
and
inequality constraints
respectively. A complete solution of the causal discovery problem requires a characterization of all causal-compatibility constraints for each causal structure, which is a very difficult problem in general. This is because the inequality constraints are hard to find.

A more straightforward project is to simply
classify
the causal structures. This task requires determining when a pair of such causal structures can realize the
same
set of distributions over the visible variables, in which case they are termed
observationally equivalent
, and when they are observationally
in
equivalent. We can then classify these causal structures into
observational equivalence classes
. More generally, one wishes to know, for each pair of causal structures, whether the set of distributions realizable by one contains the set of distributions realizable by the other, in which case the first is said to
observationally dominate
the second. This dominance relation defines a partial order among the observational equivalence classes of causal structures, which we term the
observational partial order
. The determination of the observational partial order is the main aim of this article.

Of course, a determination of
all
of the causal-compatibility constraints for each causal structure would be
sufficient
for determining the observational partial order, but it is not
necessary
, and this is why the project of identifying the observational partial order is easier than the project of achieving a full characterization of the causal-compatibility constraints for each causal structure. The project of determining the observational partial order, however, has applications in causal discovery: given knowledge of when two causal structures are observationally equivalent, if we find a causal-compatibility constraint for one of them, we know it applies also to the other. In particular, a classification into observational equivalence classes is helpful for attesting the absence or presence of inequality constraints: if a causal structure is known to be observationally equivalent to another one that is latent-free, then we know that it cannot present inequality constraints.

Characterizing the observational partial order is also significant for identifying the best causal explanations of observational data.
It is standard to argue that if two causal structures can both realize a probability distribution, one should prefer the structure that is lower in the observational dominance order. (This is sometimes motivated by the fact that this structure is more falsifiable.). Identifying the set of causal structures that provide the best explanation of a given distribution, therefore, requires identifying the lowest elements in the observational dominance order that can realize the distribution. The observational partial order is particularly significant when implementing causal discovery on finite-run data, If a causal structure is found to

underfit
the data, then so too will all the causal structures below it in the observational partial order.
Moreover, if a causal structure
overfits
the data relative to another, then so too will all the causal structures above it in the observational partial order. In this way, a knowledge of the observational partial order permits a narrowing-down of the scope of possibilities for a good causal explanation of the data.

This work focuses on rules for proving that two causal structures are observationally equivalent, inequivalent, or that one dominates the other. With these rules, we aim to determine the resulting observational partial order. Sec.
3.5
will explain the precise procedure that we follow to do so.

We will use the convention adopted in the standard framework of causal inference, where a causal structure is represented by a Directed Acyclic Graph (DAG) whose nodes are associated to random variables and whose edges indicate direct causal influences. Here, we will refer to a DAG whose nodes are partitioned into two sets, one associated to latent variables and the other associated to visible variables, as a
partitioned DAG
(pDAG).

In short, our results prove that causal discovery algorithms that leverage only conditional independence constraints have a poor discriminatory power relative to algorithms that go beyond these for the case of four visible nodes, and this is likely to also be true for higher numbers of visible nodes.

Preliminaries

In this work, causal structures are represented by Directed Acyclic Graphs (DAGs), directed graphs that have no cycles. DAGs are composed of nodes and directed edges, specified as ordered pairs of nodes. Here, we will denote the set of nodes of a DAG
\mathcal{G}
as
\mathtt{nodes}(\mathcal{G})
. The set of edges of a DAG
\mathcal{G}
will be denoted
\mathtt{edges}(\mathcal{G})
.

Below, we define some terminology about DAGs.

Definition 1

(Children, Parents, Descendants, Ancestors)
.

Let
\mathcal{G}
be a DAG, and let
u,v,w\in\mathtt{nodes}(\mathcal{G})
.

If
\mathcal{G}
includes a directed edge
v\rightarrow w
, then
w
is called a
child
of
v
. Conversely, a node
u
that has
v
as a child is called a
parent
of
v
. The set of all children of
v
is denoted
\mathtt{ch}_{\mathcal{G}}(v)
, while the set of all parents of
v
is denoted
\mathtt{pa}_{\mathcal{G}}(v)
.

A node
w\in\mathtt{nodes}(\mathcal{G})
is a
descendant
of
v
if it can be reached from
v
by a sequence of nodes through directed edges pointing away from
v
. Conversely, a node
u\in\mathtt{nodes}(\mathcal{G})
that has
v
as a descendant is called an
ancestor
of
v
. The set of all descendants of
v
is denoted
\mathtt{des}_{\mathcal{G}}(v)
, and the set of all ancestors of
v
is denoted
\mathtt{an}_{\mathcal{G}}(v)
.

Definition 2

(Subgraph)
.

Let
\mathcal{G}
and
\mathcal{G}^{\prime}
be DAGs. If
\mathtt{nodes}(\mathcal{G}^{\prime})\subseteq\mathtt{nodes}(\mathcal{G})
and
\mathtt{edges}(\mathcal{G}^{\prime})\subseteq\mathtt{edges}(\mathcal{G})
, we say that
\mathcal{G^{\prime}}
is a subgraph of
\mathcal{G}
.

In particular, if we start from
\cal G
and delete all of the nodes that are
not
in a particular subset
S\in\mathtt{nodes}(\cal G)
(hence also deleting their incoming and outgoing edges), the resulting induced subgraph will be denoted by
\mathcal{G}_{S}
.

As already noted in the introduction, the causal structures that we consider in this work have two types of nodes: visible nodes, associated with variables that are observed, and latent nodes, associated with variables that are not observed. In order to save the term “DAG” for the mathematical object composed of nodes and edges, we define a new object to represent a DAG with a partitioned set of nodes:

Definition 3

(Partitioned DAG)
.

A
partitioned DAG (pDAG)

\mathcal{G}
is a DAG together with a partition of its nodes into two subsets. The first subset is referred to as the set of

visible
nodes, denoted
\mathtt{Vnodes}(\cal G)\subseteq\mathtt{nodes}(\cal G)
, and the second subset is referred to as the set of

latent
nodes, denoted
\mathtt{Lnodes}(\cal G)\subseteq\mathtt{nodes}(\cal G)
.

All of the notions defined above for DAGs also apply for pDAGs. In this paper, we denote visible nodes with white backgrounds and latent nodes with grey backgrounds (see, e.g., Fig.
1.1
). A pDAG that is composed only of visible nodes will be called a
latent-free
pDAG. Whenever two visible nodes of a pDAG are children of the same latent node, we will refer to the latent node as a
confounder
of the two children.

We now define one last preliminary notion, the notion of a set of pDAGs consistent with a fixed ordering of the visible nodes:

Definition 4

(Set of pDAGs consistent with a fixed nodal Ordering)
.

Consider a set
S
of pDAGs, all of which share the same set of visible nodes
\{v_{1},...,v_{n}\}
. We say that
S
is a
set of pDAGs consistent with a fixed nodal ordering
if there is an ordering of the nodes,
(v_{\Pi(1)},...,v_{\Pi(n)})
for some permutation
\Pi
, such that every pDAG of
S
is such that
v_{\Pi(j)}
is not an ancestor of
v_{\Pi(i)}
for all
i,j
such that
\Pi(i)<\Pi(j)
.

2.1
Explaining Observed Data with a Causal Structure

A natural experiment is one that that passively observes a set of variables over many runs. Such an experiment yields a statistical estimate of the probability distribution over the possible values of these variables. Determining which causal structures could have realized this distribution is the causal discovery problem.

To do so, one has to specify the
semantics
of this causal model
2
2

2

A causal structure is analogous to syntax in linguistics, which is the structural form of a sentence, while the semantics of a causal model is the analogue of semantics in linguistics. Semantics refers to a specific choice of objects that follow the structure defined by the syntax. In linguistics, semantics provides the meanings of the terms in a sentence. In causal modelling, it provides the parameters of the model.
We thank Nick Ormrod for the suggestion of this terminology.
, a description of what type of entities are associated to the nodes, and what type of mechanism determines how each node depends causally on its parents in the DAG, and of how to parametrize statistical uncertainty.

In this work, we will only consider causal model semantics of the
classical
type, wherein the entities that are associated with nodes are classical random variables. An alternative possibility, however, is the semantics used in quantum causal modelling. There, the entities that can be associated with nodes are quantum systems, each of which is described by a Hilbert space
3
3

3

The analogue of the cardinality of a random variable is the dimension of this Hilbert space. The analogue of an error variable of a given cardinality is an ancillary quantum system of a given dimension, and the analogue of a distribution over the error variable is a quantum state of the ancillary system. Finally, the analogue of a functional dependence between classical random variables is a unitary channel between quantum systems.
. See Refs.
[

for works on the causal discovery problem in causal models with quantum semantics.

The variables associated with visible nodes will be called

, and the variables associated with latent nodes will be called
latent variables
. For each
a\in\mathtt{nodes}(\mathcal{G})
, we denote the associated variable by

X_{S}

\mathcal{X}_{a}

Under this assumption,
the cardinality of each

is a natural number, so that the set of such cardinalities can be specified by a vector
\vec{c}\in\mathbb{N}^{|\mathtt{nodes}(\mathcal{G})|}
, where
|S|
denotes the cardinality of a set

\vec{c}
, the cardinality of the variables.

We also associate to each
a\in\mathtt{nodes}(\mathcal{G})
a random variable
E_{a}
, called an error variable, whose state space is denoted by
\mathcal{E}_{a}
. The variable
X_{a}
is determined by its associated error variable
E_{a}
and its causal parents
X_{\mathtt{pa}_{\mathcal{G}}(a)}
via a function
f_{a}:\mathcal{X}_{\mathtt{pa}_{\mathcal{G}}(a)}\times\mathcal{E}_{a}\rightarrow\mathcal{X}_{a}
, that is,

X_{a}=f_{a}(X_{\mathtt{pa}_{\mathcal{G}}(a)},E_{a})

(1)

Finally, to each error variable
E_{a}
, one associates a probability distribution
P(E_{a})
that stipulates how
E_{a}
is sampled. Thus, the inclusion of the error variable
E_{a}
allows for
X_{a}
to respond probabilistically to
X_{\mathtt{pa}_{\mathcal{G}}(a)}
, even though
f_{a}
is a deterministic function.

The cardinality of
the visible, latent and error variables, the functions, and the error-variable distributions are jointly termed the
parameters
of the causal model:

\mathtt{par}=\{(|\mathcal{X}_{a}|,|\mathcal{E}_{a}|,f_{a},P(E_{a})):a\in\mathtt{nodes}(\mathcal{G})\}

(2)

The semantics of the causal model stipulates the scope of possibilities for
\mathtt{par}
. For instance, the error variables could all be continuous, the functional dependences could all be linear, and the error-variable distributions could all be Gaussian.
It could also be the case that the scope of possibilities for
\mathtt{par}
is unrestricted. When this is the case,
we will say that the semantics is
classical unrestricted
. Note that there are still different options of classical unrestricted semantics, corresponding to different choices of cardinalities of the visible, latent and error variables.

In all of this work, we will be dealing only with classical unrestricted semantics. In general, one might be interested in the distributions over visible variables realizable by a pDAG for different types of classical unrestricted semantics; for example, when the latent nodes are associated with classical random variables that have specific fixed cardinalities. In the causal inference literature, the case of most common interest is when the latent nodes are allowed to take arbitrary cardinalities. We now turn to the notion of realizability of observational data under this type of model.

Definition 5

(Set of probability distributions with cardinality vector
\vec{c}_{\text{vis}}

Let
\mathcal{G}
be a pDAG. Associate it to a causal model with classical unrestricted semantics where the visible variables
\{X_{v}:v\in\mathtt{Vnodes}(\mathcal{G})\}
have cardinalities given by the vector
\vec{c}_{\text{vis}}\in\mathbb{N}^{|\mathtt{Vnodes}(\mathcal{G})|}
, and the latent variables are allowed to take arbitrary cardinalities.

The set of probability distributions on the visible variables that are realizable under passive observation by
\cal G
for this causal semantics, denoted
\mathcal{M(G},\vec{c}_{\text{vis}})
, is the set of all probability distributions
P

X_{\mathtt{Vnodes}(\cal G)}
that can be obtained as

\displaystyle P(X_{\mathtt{Vnodes}(\mathcal{G})})

\displaystyle=\sum_{X_{\mathtt{Lnodes}(\mathcal{G})}}\sum_{E_{\mathtt{nodes}(\mathcal{G})}}\prod_{a\in\mathtt{nodes}(\mathcal{G})}\delta_{X_{a},f_{a}(X_{\mathtt{pa}_{\mathcal{G}}(a)},E_{a})}P(E_{a})

(3)

for some choice of parameters, i.e., for some choice of the set
\{(|\mathcal{X}_{a}|,|\mathcal{E}_{a}|,f_{a},P(E_{a})):a\in\mathtt{nodes}(\mathcal{G})\}

We will refer to a distribution that is realizable by a pDAG under arbitrary cardinality of the latent variables simply as a distribution that is realizable by that pDAG.

If a given probability distribution over visible variables is not realizable in
a certain causal structure, then this causal structure is
not
a valid causal explanation for the statistical data on these variables. Causal structures that can realize

The set
\mathcal{M}(\mathcal{G},\vec{c}_{\text{vis}})

Since this tuple contains all the information that can be extracted from the causal structure by passive observations, we call it the
observational profile

Definition 6

(Observational profile)
.

Let
\mathcal{G}
be a pDAG. The

\cal G

\mathcal{M}{-}{\tt{profile}}(\mathcal{G})
, is the tuple

\mathcal{M}{-}{\tt{profile}}{(\mathcal{G})}\coloneqq\left\{\mathcal{M}(\mathcal{G},\vec{c}_{\text{vis}}):\vec{c}_{\text{vis}}\in\mathbb{N}^{|\mathtt{Vnodes}(\mathcal{G})|}\right\},

The mathematical constraints on the set of realizable probability distributions of a given causal structure can be sorted into trivial and nontrivial types. The trivial type merely follows from positivity of probabilities and normalization.
The nontrivial types of constraint are those that are implied by the causal structure, and are termed
causal-compatibility constraints
. Using the observational profile, as we will see now, it is possible to classify pDAGs based on the types of causal-compatibility constraints that they present.

The set
\mathcal{M}(\mathcal{G},\vec{c}_{\text{vis}})
is subject to both trivial and nontrivial constraints. To focus on the latter, we define
\tilde{\mathcal{M}}(\mathcal{G},\vec{c}_{\text{vis}})
as the set obeying
only
the nontrivial constraints. Note that, geometrically,
\mathcal{M}(\mathcal{G},\vec{c}_{\text{vis}})
can be recovered from
\tilde{\mathcal{M}}(\mathcal{G},\vec{c}_{\text{vis}})
simply by restricting the latter to the simplex defined by the positivity and normalization constraints.
Out of the trivial constraints, normalization is a linear equality and positivity is a linear inequality. In Ref.
[
16
]
, it is proven that for classical causal models, all nontrivial causal-compatibility constraints also take the form of polynomial equalities or inequalities. If all such constraints are equalities, then the set
\tilde{\mathcal{M}}(\mathcal{G},\vec{c}_{\text{vis}})

algebraic set
(also termed an algebraic variety), whereas if there are inequality constraints, then it is a

.
4
4

4

\mathcal{M}(\mathcal{G},\vec{c})

for the same pDAG have to be satisfied even when all variables have binary cardinalities.

Our definition of
algebraicness
is such that a pDAG only needs to present inequality constraints for
one
choice of cardinalities of the visible variables to be considered
nonalgebraic
; as of now, however, we do not have any known example of a pDAG that is definitively
nonalgebraic
while also being free of inequality constraints at binary cardinalities of the visible variables. In Section
7
, we will present possible candidates for such an example: the causal structures of Fig.
7.2
(a)-(d) are known to present inequality constraints at cardinalities
\vec{c}_{\text{vis}}=(3,2,2,2)
, but we still do not know if they present inequality constraints at cardinalities
\vec{c}_{\text{vis}}=(2,2,2,2)
.

Unlike inequality constraints, the validity of equality constraints imposed by causal structures is independent of the cardinality of the visible variables. Furthermore, it is much easier to obtain equality constraints than inequality constraints. The simplest type of equality constraints, namely the conditional independence relations, can be obtained from a graphical criterion called the
d-separation criterion

[
21
,
22
]
. Given a pDAG
\mathcal{G}
and three disjoint sets of visible nodes
A,B,C\in\mathtt{nodes}(\mathcal{G})
, the criterion returns whether
A
and
B
are “d-separated” by
C
or not. The affirmative case is denoted by
A\mathbin{\text{$\bot\mkern-8.0mu\bot$}_{\text{d}}}B|C
. As shown in Ref.
[
21
]
and reproduced in Theorem
1
below, a d-separation relation of a pDAG implies that the realizable distributions have to satisfy an associated conditonal independence relation. In a certain distribution
P
, the variable
X_{A}
is said to be independent of the variable
X_{B}
after conditioning on the variable
X_{C}
if:

P(X_{A}X_{B}|X_{C})=P(X_{A}|X_{C})P(X_{B}|X_{C}).

(5)

Such a conditional independence relation is denoted by
X_{A}\mathbin{\text{$\bot\mkern-8.0mu\bot$}}X_{B}|X_{C}
.

Theorem 1

(d-separation and conditional independence)
.

Let
\mathcal{G}
be a pDAG, and associate it to a classical unrestricted semantics under arbitrary cardinalities of the latent variables. Let
A
,
B
and
C
be three disjoint subsets of the set of visible nodes,
\mathtt{Vnodes}(\cal G)
. Then:

1.

If
P
is a probability distribution over
X_{\mathtt{Vnodes}(\mathcal{G})}
realizable by
\mathcal{G}
, then
A\mathbin{\text{$\bot\mkern-8.0mu\bot$}_{\text{d}}}B|C
in
\mathcal{G}
implies that
X_{A}\mathbin{\text{$\bot\mkern-8.0mu\bot$}}X_{B}|X_{C}
in
P
.

2.

If
X_{A}\mathbin{\text{$\bot\mkern-8.0mu\bot$}}X_{B}|X_{C}
for
every
probability distribution over
X_{\mathtt{Vnodes}(\mathcal{G})}
that is realizable by
\mathcal{G}
, then
A\mathbin{\text{$\bot\mkern-8.0mu\bot$}_{\text{d}}}B|C
.

As an example, both pDAGs of Fig.
1.1
present the d-separation relation
a\mathbin{\text{$\bot\mkern-8.0mu\bot$}_{\text{d}}}c|b
, and thus Theorem
1
implies that any distribution realizable by these DAGs must satisfy the conditional independence constraint
X_{a}\mathbin{\text{$\bot\mkern-8.0mu\bot$}}X_{b}|X_{c}
.

2.2
Observational Equivalence and Dominance

The central objective of this work is to determine the observational equivalence and dominance relations that hold between pDAGs, and so we turn now to defining these formally.

Definition 8

(Observational dominance and equivalence of pDAGs)
.

Let
\mathcal{G}
and
\mathcal{G}^{\prime}
be latent-permitting pDAGs such that
\mathtt{Vnodes}(\mathcal{G})=\mathtt{Vnodes}(\mathcal{G}^{\prime})
. We say that
\mathcal{G}

observationally dominates

\mathcal{G}^{\prime}
when the set of realizable distributions of
\mathcal{G}
includes the set of realizable distributions of
\mathcal{G}^{\prime}
, regardless of the cardinalities of the visible variables. That is, when

\mathcal{M}(\mathcal{G}^{\prime},\vec{c}_{\text{vis}})\subseteq\mathcal{M}(\mathcal{G},\vec{c}_{\text{vis}})\quad\forall\vec{c}_{\text{vis}}\in\mathbb{N}^{|\mathtt{Vnodes}(\mathcal{G})|}

(6)

or equivalently, when

\mathcal{M}{-}{\tt{profile}}(\cal G^{\prime})\subseteq_{\text{ew}}\mathcal{M}{-}{\tt{profile}}(\cal G),

(7)

where
\subseteq_{\text{ew}}
denotes element-wise set inclusion.
The observational dominance relation is denoted by
\mathcal{G}\succeq\mathcal{G}^{\prime}
.

We say that
\mathcal{G}
is
observationally equivalent
to
\mathcal{G}^{\prime}
when

\mathcal{M}(\mathcal{G}^{\prime},\vec{c}_{\text{vis}})=\mathcal{M}(\mathcal{G},\vec{c}_{\text{vis}})\quad\forall\vec{c}_{\text{vis}}\in\mathbb{N}^{|\mathtt{Vnodes}(\mathcal{G})|}

(8)

or equivalently, when

\mathcal{M}{-}{\tt{profile}}(\cal G^{\prime})=_{\text{ew}}\mathcal{M}{-}{\tt{profile}}(\cal G),

(9)

The observational equivalence relation is denoted by
\mathcal{G}\cong\mathcal{G}^{\prime}
.

If
\mathcal{G}\succeq\mathcal{G}^{\prime}
but
\mathcal{G}\not\cong\mathcal{G}^{\prime}
,
we say that
\mathcal{G}

strictly dominates

\mathcal{G}^{\prime}
and denote this relation as
\mathcal{G}\succ\mathcal{G}^{\prime}
.
If
\mathcal{G}\not\succeq\mathcal{G}^{\prime}
and
\mathcal{G}^{\prime}\not\succeq\mathcal{G}
, we say that
\mathcal{G}
and
\mathcal{G}^{\prime}
are
incomparable
.

Note that to prove observational equivalence, one must demonstrate that Eq. (
8
) holds true, which requires demonstrating equality for all possible cardinalities of the visible nodes.
To prove observational
in
equivalence, on the other hand, it suffices to show that
\exists\vec{c}_{\text{vis}}\in\mathbb{N}^{\mathtt{Vnodes}(\mathcal{G})}:\mathcal{M}(\mathcal{G},\vec{c}_{\text{vis}})\neq\mathcal{M}(\mathcal{G}^{\prime},\vec{c}_{\text{vis}})
, that is, it suffices to demonstrate inequality for just one particular assignment of cardinalities.
An example of two pDAGs
that are observationally equivalent to each other was given in Fig.
1.1
. Another example, involving
nonalgebraic
pDAGs, is given in Fig.
2.1
; the observational equivalence of the three pDAGs there presented will be formally justified in Section
6
.

Figure 2.1
:
An example of
nonalgebraic
pDAGs that are observationally equivalent. The first of this triple is generally known as the
instrumental scenario
.

Recall that if two pDAGs are observationally equivalent, they impose the same set of causal-compatibility constraints on the
probability distributions over the visible variables. Therefore, it is clear that all of the pDAGs that are observationally equivalent to an
algebraic
pDAG are also
algebraic
, and all of the pDAGs that are observationally equivalent to a
nonalgebraic
pDAG are also
nonalgebraic
.

Note that observational equivalence is
not
the same as Markov equivalence
[
9
,
23
]
. Two pDAGs are Markov equivalent if their sets of conditional independence constraints are the same. For two pDAGs to be observationally equivalent, on the other hand, their entire set of causal-compatibility constraints (including conditional independence constraints, nested Markov constraints and inequality constraints) need to coincide.

2.3
mDAGs

In this section, we recall the notion of an mDAG, defined in Ref.
[
24
]
. For each mDAG, we can associate a set of pDAGs. The pDAGs in such a set are not only observationally equivalent, but equivalent under any interventional probing scheme
[
25
]
.
That is, if two pDAGs are associated with the same mDAG, then they cannot be distinguished even when there is access to data from observations and arbitrary interventions. Therefore, the mDAG is a fundamental object in the causal discovery problem with latent variables. Note, however, that observational equivalence does not imply equivalence of the mDAG structure: there are different mDAGs which are observationally equivalent.

The definition of an mDAG is motivated by two graphical operations defined in Ref.
[
24
]
, here referred to as
exogenization of latent nodes
and
removal of redundant latent nodes
. Ref.
[
24
]
showed that these two graphical operations preserve the observational profile. That is, any two pDAGs related by such an operation are observationally equivalent. These operations are discussed separately from the rest of the rules for showing observational equivalence (which will be discussed in Section
4
) because they are more fundamental: as Ref.
[
25
]
showed, two pDAGs related by these operations are also indistinguishable under access to the strongest possible probing schemes on the visible variables, that is, the ones that include interventions and thus reveal the maximum amount of information about the causal structure and causal parameters. In this paper we are only concerned with observational data, and will not further discuss interventions.

Before defining these two operations in full generality, we can get a sense of their content by analyzing Fig.
2.2
. In Fig.
2.2
(a), we have a pDAG where the latent node
\alpha
is
endogenous
, since it has parents
\beta
and
c
in the pDAG. It passes information from
\beta
and
c
to its children
a
and
b
. In Fig.
2.2
(b), the latent node
\alpha
does not have parents anymore, but its children
a
and
b
now have direct access to the information about
\beta
and
c
. The operation of transitioning from the pDAG of Fig.
2.2
(a) to that of Fig.
2.2
(b) is an instance of what we term “exogenization of latent nodes. It consists in making the latent variables of a pDAG
exogenous
(parentless) while connecting their parents directly to their children.

In Fig.
2.2
(b), the latent node
\alpha
establishes a common cause between
a
and
b
. On the other hand, the latent node
\beta
establishes a common cause between
a
,
b
and
d
. Since we allow the cardinalities of latent variables to be arbitrary (Def.
5
), the latent node
\alpha
can be absorbed into
\beta
, thus leading to Fig.
2.2
(c). The operation of transitioning from the pDAG of Fig.
2.2
(a) to that of Fig.
2.2
(b) is an instance of what we term “removal of redundant latent nodes”. It consists in deleting latent nodes such as
\alpha
, whose set of children is a subset of the set of children of another latent node. The fact that these nodes only establish a confounder between nodes that already had a confounder is what justifies referring to them as redundant.

:
(a) A pDAG. (b) The pDAG obtained from (a) by exogenizing the latent node

The proof that these two operations always preserve observational equivalence was given in Lemmas 3.7 and 3.8 of Ref.
[
24
]
, reproduced below:

Lemma 1

(Exogenize Latent Nodes)
.

Let
\mathcal{G}
be a pDAG, and let
{\tt EndoLNodes}(\mathcal{G})\subseteq\mathtt{Lnodes}(\mathcal{G})
be the set of latent nodes of
\mathcal{G}
that are endogenous (i.e., they have one or more parents in
\cal G
). Construct the pDAG
{\tt Exog}(\mathcal{G})
as follows. For every
u\in{\tt EndoLNodes}(\mathcal{G})
, start from
\mathcal{G}
and: (i) delete all directed edges leading into
u
, (ii) add a directed edge from every parent of
u
to every child of
u
. The pDAG
{\tt Exog}(\mathcal{G})
so constructed is observationally equivalent to
\mathcal{G}
,
{\tt Exog}(\mathcal{G})\cong\mathcal{G}
.

Lemma 2

(Remove Redundant Latent Nodes)
.

Let
\mathcal{G}
be a pDAG where all latent nodes are exogenous.
Let
{\tt RedundLnodes}(\mathcal{G})\subset\mathtt{Lnodes}(\mathcal{G})
be a maximal subset of latent nodes such that their set of children is already common-cause-connected by another latent node.
(Note that there is ambiguity in the choice, since when two latent nodes have the same set of children, one can take either to be the redundant one.) Formally, we define such a subset of latent nodes of
\cal G
, denoted
{\tt RedundLnodes}(\mathcal{G})
, by the following two conditions:
(i) For every
u\in{\tt RedundLnodes}(\mathcal{G})
there exists some distinct latent node
v\in\mathtt{Lnodes}(\mathcal{G})
such that
\mathtt{ch}(u)\subseteq\mathtt{ch}(v)
. (ii)
{\tt RedundLnodes}(\mathcal{G})
is not a strict subset of any other set of latent nodes that obeys (i). Let
{\tt RemoveRedund}(\mathcal{G})
be the pDAG constructed by removing from
\mathcal{G}
every node in
{\tt RedundLnodes}(\mathcal{G})
. The pDAG
{\tt RemoveRedund}(\mathcal{G})
so constructed is observationally equivalent to
\cal G
, i.e.,

{\tt RemoveRedund}(\mathcal{G})\cong\mathcal{G}
.

For any pDAG
\mathcal{G}
, one can find another pDAG whose latent variables are all exogenous and non-redundant that is observationally equivalent to
\mathcal{G}
. Namely, it is the pDAG
{\tt RemoveRedund}\circ{\tt Exog}(\mathcal{G})
, which we will call the
RE
-reduction
of
\cal G
. Accordingly, the map
RE-reduce
is defined as:

\displaystyle{\tt RE{-}reduce}:={\tt RemoveRedund}\circ{\tt Exog}

(10)

It is easy to see that many different pDAGs have the same
RE
-reduction. A pDAG which is invariant under the
RE-reduce
map, i.e., such that
\mathcal{G}={\tt RE{-}reduce}(\cal G)
, will be called a
RE
-reduced
pDAG.

As noted in
[
24
]
, this justifies the introduction of a new structure for studying realizable distributions for pDAGs: the
marginalized DAG
(mDAG). The notion of an mDAG makes use of the concept of a
simplicial complex
:

Definition 9

(Simplicial complex)
.

A simplicial complex over a finite set
V
is a set
\mathcal{B}
of subsets of
V
such that

•

\{v\}\in\mathcal{B}
for all
v\in V
;

•

If
A\subseteq B\subseteq V
and
B\in\mathcal{B}
, then
A\in\mathcal{B}
.

The elements of
\mathcal{B}
are called faces. The inclusion-maximal elements of a simplicial complex (the faces that are maximal in the order over faces induced by subset inclusion) are called facets.

An mDAG is a pair
\mathfrak{G}=(\cal D,B)
, where
\cal D
is a DAG and
\cal B
is a simplicial complex over the set of nodes of
\cal D
. The DAG
\mathcal{D}
is called the
directed structure
of
\mathfrak{G}
. The nodes of
\cal D
will also be referred to as the nodes of
\mathfrak{G}
. The edges of
\cal D
will be referred to as the directed edges of
\mathfrak{G}
and denoted
{\tt DirectedEdges}(\mathfrak{G})
. Here, we will use the font
\mathfrak{G}
to denote mDAGs, while the font
\cal G
will continue to be used to denote DAGs and pDAGs.

With this notion in hand, we can introduce the map
\mathtt{LnodesToFaces}
that associates an mDAG to each pDAG:

Definition 10

(Map
\mathtt{LnodesToFaces}
from pDAGs to mDAGs)
.

Let
\mathcal{G}
be a pDAG, and let
\tilde{\mathcal{G}}
be the
RE
-reduction of
\mathcal{G}
, i.e.,

\tilde{\mathcal{G}}={\tt RE-reduce}(\mathcal{G})
. Recall that
\mathtt{Vnodes}(\tilde{\mathcal{G}})=\mathtt{Vnodes}({\mathcal{G}})
.
The
mDAG associated with
\mathcal{G}
, denoted by
\mathtt{LnodesToFaces}(\mathcal{G})
, is the pair
\mathcal{(D,B)}
where

•

\mathcal{D}
is a DAG such that
\mathtt{nodes}(\mathcal{D})=\mathtt{Vnodes}({\mathcal{G}})
and whose edges correspond to the edges between the visible nodes of
\tilde{\mathcal{G}}
.

•

\mathcal{B}
is a simplicial complex over
\mathtt{Vnodes}({\mathcal{G}})
. The facets of
\mathcal{B}
are the maximal subsets of
\mathtt{Vnodes}({\mathcal{G}})
that
are children of the same latent node in
\tilde{\mathcal{G}}
, i.e., for each
u\in\mathtt{Lnodes}(\tilde{\mathcal{G}})
, the set
\mathtt{ch}_{\tilde{\mathcal{G}}}(u)

is a facet of
\mathcal{B}
.

2.3

u
in the pDAG corresponds to a facet in the mDAG whose elements are the children of

in the pDAG.
One can conceptualize the mDAG as a hypergraph with two types of edges, namely, the directed edges and a set of undirected hyperedges, where the latter represent the facets of the simplicial complex and are depicted by red loops.

We now define the notion of
structural dominance
of one mDAG over another.

Definition 11

(Structural Dominance of mDAGs)
.

Let
\mathfrak{G}
and
\mathfrak{G}^{\prime}
be two mDAGs with the same sets of nodes.
\mathfrak{G}
is said to

\mathfrak{G}^{\prime}
if the following pair of conditions hold: (i) the directed structure of
\mathfrak{G}^{\prime}
can be obtained from the directed structure of
\mathfrak{G}
by dropping edges,
{\tt DirectedEdges}(\mathfrak{G}^{\prime})\subseteq{\tt DirectedEdges}(\mathfrak{G})
, and (ii) the simplicial complex of
\mathfrak{G}^{\prime}
can be obtained from the simplicial complex of
\mathfrak{G}
by dropping faces,
\mathcal{B}^{\prime}\subseteq\mathcal{B}
.

Note that the definition of structural dominance requires a subset inclusion relation for the
faces
, not the
facets
of the simplicial complexes.
For example, in Fig.
2.4
, the set of facets
of the simplicial complex of the mDAG
2.4
(a)
is not a subset of the set of facets of the simplicial complex of

(b), but the set of

(b) structurally dominates mDAG
2.4

[

[

Lemma 3

(Structural dominance
\Rightarrow
Observational dominance)
.

Let
\mathfrak{G}
and
\mathfrak{G}^{\prime}
be two mDAGs with the same sets of nodes. If
\mathfrak{G}
structurally dominates
\mathfrak{G}^{\prime}
, then it also observationally dominates it, i.e.,
\mathfrak{G}\succeq\mathfrak{G}^{\prime})
.

It is convenient to define a map that takes an mDAG to the
RE
-reduced pDAG that yields it. We will call this the
canonical pDAG
associated with the mDAG:

Definition 12

(Canonical pDAG)
.

Let
\mathfrak{G}=(\mathcal{D},\mathcal{B})
be an mDAG. The map
\mathtt{can}
is given by the following procedure: starting from
\cal D
, add one latent node
l
for each
facet

A\in\cal B
and add edges from
l
to each element of
A
so that
\mathtt{ch}(l)=A
. The resulting pDAG,
\mathtt{can}(\mathfrak{G})
, is the canonical pDAG associated with
\mathfrak{G}
.

Note that if
\mathfrak{G}^{\prime}
is structurally dominated by
\mathfrak{G}
, then
\mathtt{can}(\mathfrak{G}^{\prime})

is a subgraph (in the sense of Definition
2
) of
\mathtt{can}(\mathfrak{G})
.

The results and definitions that we presented for pDAGs are extended to mDAGs through their associated canonical pDAG. For example, if the canonical pDAG of a certain mDAG is
algebraic
, we say that the mDAG itself is
algebraic
. A pair of mDAGs stands in a relationship of one being a subgraph of another if this relationship holds between their canonical pDAGs. The mDAG associated with the subgraph
\mathtt{can}{(\mathfrak{G})}_{S}
for some subset
S\subseteq\mathtt{nodes}({\mathfrak{G}})
is clearly a subgraph of
\mathfrak{G}
. We will refer to it as the subgraph of
\mathfrak{G}
induced by
S
and we will denote it by
\mathfrak{G}_{S}
. When there is a confounder between nodes
a
and
b
in the canonical pDAG, i.e., when the simplicial complex of the mDAG has at least one facet that includes nodes
a
and
b
, then we say that there is a
confounder
between
a
and
b
in the mDAG. Similarly, a distribution is realizable by an mDAG if it is realizable by its canonical pDAG, an mDAG observationally dominates another if the observational dominance relation holds for their canonical pDAGs, and so on.

Lemmas
1
and
2
imply that whenever two latent-permitting pDAGs
\mathcal{G}
and
\mathcal{G}^{\prime}
are associated with the same mDAG, they are observationally equivalent.
Note, however, that if two latent-permitting pDAGs
\mathcal{G}
and
\mathcal{G}^{\prime}
are associated to
distinct
mDAGs, they may or may not be observationally equivalent. That is, a difference in the associated mDAGs is necessary but not sufficient for observational inequivalence of pDAGs.

The set of mDAGs that have a fixed number of nodes can, therefore, be organized into equivalence classes under the observational equivalence relation. These classes are called
observational equivalence classes
. In turn, the observational dominance relation defines a partial order among the observational equivalence classes, which we call the
observational partial order
. Our goal in this work is to characterize this partial order.

As will be justified in Section
3.1
, here we will only discuss the observational equivalence classes and the observational partial order that hold for a set of mDAGs that are consistent with a fixed nodal ordering, in the sense of Def.
4
. The simplest example of an observational partial order of this type is the one for mDAGs with two nodes. There are four mDAGs of two nodes that are consistent with a fixed nodal ordering. Three of these are saturating, i.e, the set of probability distributions over the visible variables that are realizable by them
is the set of
all
such distributions.
The remaining mDAG is the one where the two nodes are disconnected.
For it, the set of realizable
distributions is the set of all
factorizing
distributions.
Therefore, the partial order is the one depicted in Fig.
2.5
: the three mDAGs with connected nodes make up one observational equivalence class,
termed the
Saturated
class, while the mDAG with disconnected nodes defines the
Factorizing
class, and the former observationally dominates the latter.

3
Objectives and Methods

3.1
Restriction of scope to sets of mDAGs consistent with a fixed nodal ordering

In this work, we will take the nodal ordering of the visible variables to be fixed, and we will only compare candidate causal structures for which the visible nodes are consistent with this nodal ordering. There are several reasons why we restrict the set of causal structures appearing in our classification in this way. As we argued in Ref.
[
25
]
:

Clearly, if the variables of interest are temporally localized (and we do not need to take into account relativity theory, such as the possibility of space-like separation), then they will necessarily be temporally ordered. The reason typically given for why fixed nodal ordering should
not
be presumed
[
26
, Section 7.5.1]
is that the variables of interest may fail to be temporally localized, referring instead to properties that persist over time. An individual’s health and their exercise regime provides a good example. However, whenever the variables of interest are of this type, they can have a mutual influence on one another, and consequently one cannot restrict attention to directed graphs that are
acyclic
when considering the possibilities for the causal structure holding between them. Thus, if one is contemplating a causal discovery algorithm that returns only acyclic graphs (as we are doing here), then one should not apply it to variables that fail to be temporally localized.

One could still argue that, although the visible variables are temporally localized, for some reason we do not know the temporal order in which they were probed. However, one needs to have some knowledge about the probing scheme to be confident that it consists purely of passive observations. Situations where this is the case but one remains ignorant of when each variable was probed are likely to be the exception rather than the rule.

3.2
Special Cases: Confounder-free and Directed-edge-free mDAGs

In this section, we discuss two special cases whose observational partial order is completely solved for any number of visible nodes: the case of confounder-free mDAGs and the case of directed-edge-free mDAGs.

Most of the causal inference literature studying observational equivalence discusses only confounder-free mDAGs, or, equivalently, only latent-free pDAGs
[
9
,
27
,
28
]
. That literature, however, classifies the set of such mDAGs for
all
nodal orderings of the visible nodes rather than a fixed one. When we restrict our attention to one nodal ordering of the visible nodes, the organization of confounder-free mDAGs into observational equivalence classes is trivial: for a given nodal ordering of the nodes, if two confounder-free mDAGs are different then they are observationally inequivalent. This fact seems to be well-known; it is noted, for instance, below Theorem 1.2.8 in Ref.
[
26
]
. We also provided a proof of this fact in the Appendix C of our previous work
[
25
]
. Here, we adapt this proof to show something more, that finding the observational
partial order
is also simple when one is restricted to the confounder-free mDAGs for a fixed nodal ordering of the nodes:

Proposition 1
.

Let
\mathfrak{G}
and
\mathfrak{G}^{\prime}
be two confounder-free mDAGs that are consistent with the same nodal ordering. Then,
\mathfrak{G}
observationally dominates
\mathfrak{G}^{\prime}
if and only if it structurally dominates it.

Proof.

The “if” side follows from Lemma
3
. To prove the “only if” side, assume that
\mathfrak{G}

does not
structurally dominate
\mathfrak{G}^{\prime}
. Since they are confounder-free, this implies that there is an arrow between two nodes that is present in
\mathfrak{G}^{\prime}
but not in
\mathfrak{G}
. In the Appendix C of Ref.
[
25
]
, we showed that this implies that there is a d-separation relation that is implied by
\mathfrak{G}
but not by
\mathfrak{G}^{\prime}
. By Theorem
1
, this implies that there are probability distributions that are realizable by
\mathfrak{G}^{\prime}
but not by
\mathfrak{G}
, thus implying that
\mathfrak{G}

does not
observationally dominate
\mathfrak{G}^{\prime}
.
∎

Therefore, the observational partial order of the set of confounder-free mDAGs with a fixed nodal ordering is simply the partial order defined by structural dominance. The case of for 3-node and 4-node mDAGs of this type are shown in Figures 7.3(a) and 7.5 of Ref.
[
25
]
.

For the case of directed-edge-free mDAGs, the concept of nodal ordering is not relevant, since none of the visible nodes is an ancestor of any other visible node. In Proposition 6.8 of Ref.
[
24
]
, it was shown that two different directed-edge-free mDAGs are always observationally inequivalent. Here, we extend this idea to show that observational dominance for directed-edge-free mDAGs is determined by structural dominance:

Proposition 2
.

Let
\mathfrak{G}
and
\mathfrak{G}^{\prime}
be two directed-edge-free mDAGs. Then,
\mathfrak{G}
observationally dominates
\mathfrak{G}^{\prime}
if and only if it structurally dominates it.

Proof.

The “if” side follows from Lemma
3
. To prove the “only if” side, assume that
\mathfrak{G}

does not
structurally dominate
\mathfrak{G}^{\prime}
. Since they are directed-edge-free, this implies that there is a face that is present in the simplicial complex of
\mathfrak{G}^{\prime}
but not in the simplicial complex of
\mathfrak{G}
. That is, there is a set
S
of visible nodes in
\mathtt{can}(\mathfrak{G}^{\prime})
that shares a latent common cause, while it does not share a latent common cause in
\mathtt{can}(\mathfrak{G})
. Since there are no arrows between visible nodes, this implies that the nodes in
S
share a common ancestor in
\mathtt{can}(\mathfrak{G}^{\prime})
but not in
\mathtt{can}(\mathfrak{G})
.

In Example 2 of Ref.
[
29
]
, it was shown that a distribution where all the variables
\{X_{1},...,X_{n}\}
are perfectly correlated, i.e., where the only points with nonzero weight are those where
X_{1}=X_{2}=...=X_{n}
, is only realizable by causal structures where all the nodes corresponding to such variables share a common ancestor. Therefore,
\mathtt{can}(\mathfrak{G}^{\prime})
can explain perfect correlation between the variables of
X_{S}
, while
\mathtt{can}(\mathfrak{G})
cannot. Thus,
\mathfrak{G}

does not
observationally dominate
\mathfrak{G}^{\prime}
.
∎

Therefore, the observational partial order of directed-edge-free mDAGs is the partial order defined by structural dominance. The case of for 3-node and 4-node mDAGs of this type are shown in Figures 7.3(b) and 7.6 of Ref.
[
25
]
.

3.3
Full Solution of Observational Partial Order for 3-node mDAGs

Now, let us turn to the problem of classifying the entire set of mDAGs with a given number of nodes and a fixed nodal ordering. As we will see, this problem is still open for a general number of nodes: we do not yet know the necessary and sufficient conditions for two mDAGs to be observationally equivalent or to observationally dominate each other in the case of an arbitrary number of nodes.

For mDAGs with two nodes, of course, this problem is completely solved but the solution is rather trivial, as we saw in Fig.
2.5
. For mDAGs with three nodes, the problem is also completely solved, but the solution is more interesting in this case.
In this section, we will describe this order; the proofs of the ordering relations are postponed to Section

3.4
Significance of observational partial order for causal discovery

3.4.1
Model selection for probability distributions

We recall the problem of causal discovery:
the input data is a sample from a probability distribution over visible variables obtained from passive observations, and the objective is to determine the causal structures that can provide an
explanation of this data. We here explain how knowing the observational partial order is useful for this problem.

We begin with a limiting case of the causal discovery problem, namely, wherein the sample is infinite-run rather than finite-run. Only in this case
do the relative frequencies computed from the input data reflect the true probability distribution, whereas in the case of finite-run data, the relative frequencies merely yield an
estimate
of the true probability distribution. In other words, we begin by considering the version of the causal discovery problem wherein the input is the true probability distribution.

The most basic respect in which the observational partial order is relevant to this problem is the following. If one determines that a distribution is not realizable by a particular mDAG
\mathfrak{G}
, then one can conclude that it is also not realizable by any of the mDAGs that are
below

\mathfrak{G}
in the observational partial order.
Similarly, if one determines that a given distribution
is
realizable by a particular mDAG
\mathfrak{G}^{\prime}
, then one can conclude that it is also realizable by any of the mDAGs that are
above

\mathfrak{G}^{\prime}
in the observational partial order.

It is useful here to make use of the notions of
upward closure
and
downward closure
of a set of elements in a partial order.
If
S
denotes a set of elements of a partial order, then the upward closure of
S
, denoted
{\rm UC}(S)
, includes every
x
such that
x\succeq y
for some
y\in S
.
Similarly, the downward closure of
S
, denoted
{\rm DC}(S)
, includes every
x
such that
x\preceq y
for some
y\in S
.

Using these notions, if a distribution is known to be realizable by all of the mDAGs of a set
S
, then one can infer that it is also realizable by all of the mDAGs of
{\rm UC}(S)
.
Similarly, if a distribution is known to
not
be realizable by any mDAG in a set
S^{\prime}
, then one can infer that it is also not realizable by any mDAG in
{\rm DC}(S^{\prime})
.
If the union of
{\rm UC}(S)
and
{\rm DC}(S^{\prime})
is not the full set of mDAGs, then the remaining mDAGs are those for which one remains uncertain whether they can realize the distribution or not. Note that to specify what one knows about realizability, it suffices to specify the least elements of
{\rm UC}(S)
and the greatest elements of
{\rm DC}(S^{\prime})
. In general, each of these will be a set of incomparable elements.

The observational partial order of 3-node mDAGs, depicted in Fig.
3.1
, helps to illustrate the idea. For instance, it could be known that a probability distribution over three variables is realizable by
Collider C
but not by
Instrumental CAB
or
Instrumental ABC
.
In this case, one can infer that it is realizable by the upward closure of
Collider C
, namely,
Collider C
,
Triangle
and
Saturated
, and one can infer that it is not realizable by the downward closure of
Instrumental CAB
or
Instrumental ABC
. Meanwhile it will remain unknown whether it is realizable by any mDAG that is in neither of these sets, namely,
Instrumental ABC
and
Evans
.

Among all of the mDAGs that are compatible with a distribution, one might wonder whether any one of them provides as good of a causal explanation as any other. It is generally thought that this is not the case and that one should prefer causal structures that are lower in the observational partial order.

For instance, in Pearl’s textbook on causality
[
26
]
, he argues for this on the grounds that such causal models are
more falsifiable.
5
5

5

For instance, on p. 46 of Ref.
[
26
]
, he states:
“such theories are more constraining and thus more falsifiable; they provide the scientist with less opportunities to overfit the data ‘hindsightedly’ and therefore command greater credibility if a fit is found.”

Indeed, Pearl does not introduce any language for referring to observational dominance besides the language of preference. (Pearl’s order relation of preference is opposite to the order relation of observational dominance in the sense that
\mathfrak{G}
is preferred to
\mathfrak{G}^{\prime}
just in case
\mathfrak{G}^{\prime}
observationally dominates
\mathfrak{G}
.)

According to this proposal, the causal structures providing the best explanation of the distribution are the
least elements
in the upward-closed set of classes that can realize it.
This is referred to as the principle of
minimality
in Ref.
[
26
]
(see Definition 2.3.4).

It is worth noting that preferring causal models that satisfy the principle of
faithfulness

[
30
]
(referred to as
stability
in Ref.
[
26
]
and
no fine-tuning
in Ref.
[
18
]
) is an instance of preferring classes lower in the observational partial order.

3.4.2
Model selection for finite-run samples of probability distributions

We now turn to the problem of causal discovery based on finite-run data.
To adjudicate between different hypotheses about the causal structure, it is useful to use a standard technique of statistical model selection:
apply a train-and-test methodology to determine which hypothesis has the most predictive power, which is to say the lowest test error. Note that a structure
\mathfrak{G}^{\prime}
can have a higher test error than
\mathfrak{G}

because it underfits the data while
\mathfrak{G}
does not, but it may also have a higher test error because it
overfits
the data relative to
\mathfrak{G}
.

In the train-and-test methodology, the ensemble of observational data is divided into two sets, the first one being the
training set
and the second one being the
test set
.
For each of the candidate causal structures, we find the parameters
that provide the best fit to the training set.
One then compares the predictions of this best-fit model to the data in the test set to compute the test error.
One can then compare the test error of different causal structures to compare their predictive power.
Consider a comparison of two causal structures,
\mathfrak{G}
and
\mathfrak{G}^{\prime}
. If
\mathfrak{G}^{\prime}
has a higher test error than
\mathfrak{G}
but a lower training error, then this suggests that
\mathfrak{G}^{\prime}

overfits
the data relative to
\mathfrak{G}
.
The causal model associated to
\mathfrak{G}^{\prime}
is likely mistaking statistical fluctuations in the training data for real features while
\mathfrak{G}
is not. Fitting to these fluctuations leads to a lower training error for
\mathfrak{G}^{\prime}
, but given that the test data has different fluctuations from the training data,
\mathfrak{G}^{\prime}
is led to make worse predictions for the test data.
6
6

6

This is similar to the way in which the error of a polynomial fit to training data can be made to decrease by increasing the order of the polynomial, but because this low error is achieved by treating statistical fluctuations as real features, the fit will tend to have a large error for the test data.
. This train-and-test methodology was applied in Ref.
[
31
]
to adjudicate between different causal explanations of finite-run data in a quantum experiment that violated Bell inequalities.

We now turn to the significance of the observational partial order for such a train-and-test methodology.

If a causal structure
\mathfrak{G}

underfits
the finite-run data, i.e., if both the train and the test errors are large,
then so too will all the causal structures that are below it in the observational partial order. The reason is as follows. For
\mathfrak{G}
to
underfit
the finite-run data means that the finite-run data is improbable relative to all of the probability distributions realizable by
\mathfrak{G}
, i.e., it is unlikely that the finite-run data came from sampling from one of the probability distributions realizable by
\mathfrak{G}
.
But for all of the causal structures below
\mathfrak{G}
in the observational partial order, the set of probability distributions that they can realize is a
strict subset
of those that can be realized by
\mathfrak{G}
, and therefore the finite-run data must be improbable relative to all these distributions as well.

An analogous result holds for overfitting. Suppose
\mathfrak{G}^{\prime}
is above
\mathfrak{G}
is the observational partial order. If
\mathfrak{G}^{\prime}
overfits the data relative to
\mathfrak{G}
, then everything
above

\mathfrak{G}^{\prime}
in the order
also
overfits the data relative to
\mathfrak{G}
. The reason is that the extra expressive power of
\mathfrak{G}^{\prime}
relative to
\mathfrak{G}
(i..e., the additional probability distributions realizable by
\mathfrak{G}^{\prime}
) is what must
lead
\mathfrak{G}^{\prime}
to mistake statistical fluctuations for real features. But this extra expressive power is also present in all the structures above
\mathfrak{G}^{\prime}
in the observational partial order, and so these must be led to make the same mistake.

Note that if
\mathfrak{G}
fits the finite-run data, and
\mathfrak{G}^{\prime}
is a causal structure higher in the observational order, then
\mathfrak{G}^{\prime}

does not necessarily
overfit the data relative to
\mathfrak{G}
simply by virtue of having additional expressive power. This is because the extra expressive power may be of a type that does not lead
\mathfrak{G}^{\prime}
to mistake statistical fluctuations for real features. In this case,
\mathfrak{G}
and
\mathfrak{G}^{\prime}
will have roughly
equal
test errors.
This point was emphasized in Ref.
[
32
]
, in response to an article claiming the contrary (that one model being more expressive than another generically
did
cause the first to overfit the data relative to relative to the second.)
Nonetheless, it is worth considering the question of the circumstances in which one causal structure
does
tend to overfit the data relative to a causal structure that is directly below it in the observational partial order.

One such circumstance is if the lower causal structure implies an equality constraint on the realizable distributions that does not hold in the higher causal structure. Suppose that data is generated from the lower causal structure. Because it is finite-run, the equality constraint will generically not be satisfied exactly—there will be statistical fluctuations away from its exact satisfaction. Because the higher causal structure can realize distributions that violate the equality constraint, it can fall into the trap of mistaking such fluctuations for real features.

Consider, for example, the pair of observational equivalence classes
Collider C
and
Triangle
.
The class
Collider C
presents the d-separation relation
a\perp_{d}b
, so the set of distributions on three variables that are realizable by causal structures in that class satisfy

X_{a}\mathbin{\text{$\bot\mkern-8.0mu\bot$}}X_{b}
, that is, the equality constraint
P(X_{a}X_{b})=P(X_{a})P(X_{b})
. This describes an algebraic variety in the space of probability distribution that has a smaller dimension than the full space. The set of distributions realizable by the class
Triangle
, on the other hand, is
not
confined to this variety. Now suppose finite-run data is generated by a causal structure in the class
Collider C
, and that due to statistical fluctuation, the relative frequencies describe a point slightly outside of this variety. A causal structure in the
Triangle
class can fit this finite-run data to a probability distribution that is outside of this variety, and thereby interpret the statistical fluctuation as a real feature.
Clearly, the
Saturated
class is
also
prone to such overfitting, given that the set of distributions realizable by it are also not confined to this variety.
An example of this type, but involving a pair of 4-node mDAGs,
is discussed in Ref.
[
31
]
where such a train-and-test methodology is implemented on data from a quantum experiment.

A second circumstance in which one causal structure may overfit finite-run data relative to a causal structure that is directly below it in the observational partial order is when the two are distinguished by an inequality constraint. An inequality constraint does not lower the dimension of the space of realizable distributions, but it creates a boundary below which the distribution is realizable, and above which it is not. In this case, overfitting can arise when the causal structure generating the data implies an inequality constraint, but statistical fluctuations are taking the finite-run relative frequencies outside the boundary.

Suppose, for instance, that the
Instrumental BAC
class fits the data well, while the
Evans
class overfits it relative to
Instrumental BAC
. Because
Instrumental BAC
only has inequality constraints, it must be that statistical fluctuations away from their satisfaction in the finite-run data are being mistaken by
Evans
for genuine features, and leading to a high test error.

Of course, the data generated must be very close to the boundary described by the inequality constraint in order for statistical fluctuations to lead to a violation of this constraint in the finite-run relative frequencies. Consequently, we do not expect this circumstance to arise for generic parameter values (most of which lead to distributions that lie far from the boundary).
The possibility of this type of overfitting is discussed further in Appendix A.2 of Ref.
[
32
]
.

3.4.3
Attesting to the presence of inequality constraints

Another reason that classifying mDAGs into observational equivalence classes is useful is to identify which ones are
nonalgebraic
. In Ref.
[
33
]
it was proven that an mDAG is
algebraic

if and only if
it is observationally equivalent to some confounder-free mDAG. Note that this result does not require the confounder-free mDAG in question to be in the set of mDAGs consistent with a fixed nodal ordering that we have been considering in our observational partial order. In Fig.
3.1
, for example, the classes
Collider A
and
Collider B
do not include any confounder-free mDAG, but nevertheless their mDAGs are
algebraic
. This is so because each one of them is equivalent to a confounder-free mDAG that is not shown in this figure because it is not consistent with the stipulated nodal ordering.

However, it is possible to find a criterion for
algebraicness
based on observational equivalences within the set of mDAGs consistent with a fixed nodal ordering. In the example of
Collider A
and
Collider B
, note that for each mDAG
\mathfrak{G}
in one of those classes there is an mDAG
\mathfrak{G}^{\prime}
in
Collider C
that is related to
\mathfrak{G}
by a permutation of the nodes. The class
Collider C
includes one confounder-free mDAG, so we know that
\mathfrak{G}^{\prime}
must be
algebraic
. This implies that
\mathfrak{G}
is also
algebraic
. As it turns out, every instance where an mDAG is
algebraic
can be identified in this way:

Proposition 3
.

Consider a set
S
that includes all mDAGs consistent with a fixed nodal ordering, and let
\mathfrak{G}=(\cal D,B)\in S
be an mDAG of that set. The mDAG
\mathfrak{G}
is
algebraic
if and only if the set
S
contains mDAGs
\mathfrak{G}^{\prime}\in S
and
\mathfrak{H}^{\prime}\in S
such that
\mathfrak{H}^{\prime}
is confounder-free and
\mathfrak{G}^{\prime}
is related to
\mathfrak{G}
by a permutation of the nodes and is observationally equivalent to
\mathfrak{H}^{\prime}
, i.e.,
\mathfrak{G}^{\prime}\cong\mathfrak{H}^{\prime}
.

Proof.

If the set
S
contains mDAGs
\mathfrak{G}^{\prime}
and
\mathfrak{H}^{\prime}
as described, then it is clear that
\mathfrak{G}^{\prime}
is
algebraic
, because it is observationally equivalent to a confounder-free mDAG, which implies that
\mathfrak{G}
is
algebraic
, because it is obtained from a permutation of the nodes of
\mathfrak{G}^{\prime}
.

If the mDAG
\mathfrak{G}
is
algebraic
, then by Ref.
[
33
]
it must be observationally equivalent to a confounder-free mDAG
\mathfrak{H}
, i.e.,
\mathfrak{G}\cong\mathfrak{H}
. The problem is that
\mathfrak{H}
might not be an element of
S
, because it might not be consistent with the same nodal ordering as the other mDAGs of
S
.

Let
\cal H
be the latent-free canonical pDAG associated with the confounder-free mDAG
\mathfrak{H}
. The fact that
\mathfrak{G}\cong\mathfrak{H}
implies that
\cal D
, the directed structure of
\mathfrak{G}
, is observationally dominated by
\cal H
, i.e.,
\cal D\preceq H
. From Lemma 2 and Theorem 4 of Ref
[
28
]
, we learn that whenever there is a relationship of dominance
\cal D\preceq H
between two DAGs (i.e., latent-free pDAGs), it is possible to find another latent-free pDAG
\tilde{\cal H}
that is observationally equivalent to
\cal H
and that
structurally
dominates
\cal D
, that is,
\cal H\cong\tilde{\cal H}
and the set of edges of
\tilde{\cal H}
is a superset of the set of edges of
\cal D
.

Let
\Pi
be a permutation of the nodes that takes
\tilde{\cal H}
to a DAG
\Pi(\tilde{\cal H})
that is consistent with the stipulated nodal ordering of the set
S
. Here, the application of
\Pi
to
\tilde{\cal H}
means that every edge
a\rightarrow b
in
\tilde{\cal H}
is mapped to the edge
\Pi(a)\rightarrow\Pi(b)
. If
\tilde{\mathfrak{H}}
is defined as the confounder-free mDAG with
\tilde{\cal H}
as its directed structure and a trivial simplicial complex, then it is clear that the expressions
\mathfrak{G}\cong\mathfrak{H}
and
\cal H\cong\tilde{\cal H}
together imply
\Pi(\tilde{\mathfrak{H}})\cong\Pi(\mathfrak{G})
. By the definition of
\Pi
,
\Pi(\tilde{\mathfrak{H}})
is consistent with the stipulated nodal ordering of set
S
. Since the set of edges of
\cal D
is a subset of the set of edges of
\tilde{\cal H}
, we know that
\Pi(\mathfrak{G})
is also consistent with the stipulated nodal ordering of set
S
. Therefore,
\Pi(\mathfrak{G})
and
\Pi(\tilde{\mathfrak{H}})
satisfy the requirements for
\mathfrak{G}^{\prime}
and
\mathfrak{H}^{\prime}
of the statement.
∎

From Fig.
3.1
together with Proposition
3
, we can see that the only
nonalgebraic
equivalence classes of 3-node mDAGs consistent with a fixed nodal ordering are
Triangle
,
Evans
,
Instrumental BAC
,
Instrumental CAB
and
Instrumental ABC
. Indeed, the
nonalgebraicness
of all of these mDAGs was already known
[
2
,
20
,

.

3.5
How to Express Partial Information about the Observational Equivalence Partition

In Fig.
3.1
, we presented the complete observational partial order of 3-node mDAGs consistent with a fixed nodal ordering. This was only possible because, as will be made explicit in Section
6
, the set of rules to show observational dominance and nondominance that are currently known happen to be sufficient to completely determine the observational partial order in this case. However, in general there is not yet a set of rules that is proven to be necessary and sufficient. As we will see, there are sets of 4-node mDAGs consistent with a fixed nodal ordering whose observational equivalence remains uncertain.

The first step towards obtaining an observational partial order is to find the observational equivalence classes. These classes establish a partition of the set of all n-node mDAGs consistent with a fixed nodal ordering, which we will call the
observational equivalence partition
. An element of a partition is called a
block
. This section will give the means to express partial information about the observational equivalence partition partition, for cases where we cannot present its full characterization.

Fig.
3.2
illustrates how we express partial information about the observational equivalence partition. In this figure, the set of red points represent the set of n-node mDAGs consistent with a fixed nodal ordering, and the green dashed loops represent the observational equivalence partition. Partial information about the observational equivalence partition can be given in the form of two other partitions, which we term the
proven-equivalence partition
, where two mDAGs belong to
the same
block of the partition when they are proven to be equivalent, and the
proven-inequivalence partition
, where two mDAGs belong to
different
blocks of the partition when they are proven to be inequivalent. Examples are depicted in Fig.
3.2
by the pink and gray loops respectively.

Figure 3.2
:
The proven-equivalence partition (pink loops) is found by applying the equivalence rules of Section
4
. The proven-inequivalence partition (gray loops) is found by the inequivalence rules of Section
5
. The final goal is to find the observational equivalence partition (green dashed loops).

Each of the latter partitions can be built up in a step-wise fashion. For the proven-equivalence partition, one begins with a full partition of the mDAGs consistent with a fixed nodal ordering into singleton sets. When one proves that two mDAGs are observationally equivalent, one can merge the two blocks containing these mDAGs into a single block. The successive application of different rules for proving observational dominance (which will be presented in Section
4
) reveals more and more observational equivalences, thereby merging blocks of the proven-equivalence partition and lowering the total number of such blocks. This number is an upper bound on the number of observational equivalence classes. For a given set r of dominance-proving rules, the proven-equivalence partition one can obtain from this set is referred to as the proven-equivalence partition
induced by R
.

For the proven-inequivalence partition, one begins with a partition having all mDAGs in a single block. When one proves that two mDAGs are observationally inequivalent, one proves that they must be in different blocks of the proven-inequivalence partition. In fact, one thereby proves that the blocks of the proven-equivalence partition to which each of these mDAGs belong are observationally inequivalent. In other words, the blocks of the proven-inequivalence partition are always coarse-grainings of the blocks of the proven-equivalence partition.

Successive application of different rules for proving observational nondominance (which will be presented in Section
5
) reveals more and more observational inequivalences, thus splitting blocks of the proven-inequivalence partition and raising the total number of such blocks. This number is a lower bound on the number of observational equivalence classes. For a given set r of nondominance-proving rules, the proven-inequivalence partition one can obtain from this set is referred to as the proven-inequivalence partition
induced by R
.

As we will see, the comparison of the set of d-separation relations of each mDAG is a nondominance-proving rule. The blocks of the proven-inequivalence partition induced by the comparison of d-separation relations are what are conventionally referred to as the Markov equivalence classes
[
23
]

If a given set of mDAGs is a block of
both
the proven-equivalence partition and the proven-inequivalence partition, then it is a block of the observational equivalence partition. The leftmost block of Fig.

illustrates this circumstance.
This is the method we use to characterize what we can prove about the observational equivalence classes of 3-node and 4-node mDAGs consistent with a fixed nodal ordering.

To obtain the proven-equivalence partition from a set of dominance-proving rules, we start by constructing a partially ordered set of mDAGs with the partial order induced by such rules. This will be called the
proven-dominance partial order
. The proven-equivalence partition is then determined by taking pairs of mDAGs such that one dominates the other in the proven-dominance partial order to be part of the same block.

\mathfrak{G}^{\prime}

\mathfrak{G}^{\prime}

but not by
\mathfrak{G}^{\prime}

By the first point of Theorem
1

\mathfrak{G}

\mathfrak{G}

\mathfrak{G}^{\prime}

Let

5.1.5
Directed-edge-free rule

In this section, we discuss a rule for showing observational nondominance that is based on Proposition

Proposition 13

(Directed-edge-free Rule)
.

Let
\mathfrak{G}
and
\mathfrak{G}^{\prime}

\tilde{\mathfrak{G}}
structurally dominates
\tilde{\mathfrak{G}^{\prime}}
.

Proof.

This is a straightforward corollary of Proposition
2
.
∎

Note that this rule has a difference from the other graphical rules shown in this section: not all pairs of mDAGs are comparable by the rule articulated in Corollary
13

13
, on the other hand, only establishes comparisons between mDAGs that are equivalent to a directed-edge-free mDAG. This makes the implications of this rule for the proven-inequivalence partition a bit more subtle than before.

5.2
Comparison of unrealizable supports

In this section, we will present a rule to establish observational nondominance based on the work of Fraser
[
39
]
. This rule deals with the problem of
possibilistic causal realizability
, which we will define shortly.

An important
caveat
on this method is that it can only be applied when the visible variables have finite cardinalities. As already stated, this is not a problem for our purposes: to show observational inequivalence, it suffices to show that there is a difference in the set of realizable distributions for one specific assignment of cardinalities.

The problem that motivates the work of this paper is the problem of probabilistic causal realizability (Definition
5
), which asks whether a probability distribution is realizable by a causal structure or not. In this section, we turn our attention to a different, strictly weaker, question: the
possibilistic
causal realizability problem. To define it, let us first define the support of a probability distribution:

Definition 18

(Support)
.

Let
P:\mathcal{X}\rightarrow[0,1]
be a probability distribution. The elements of
\mathcal{X}
are called “events”. The
support
of
P
is the set of events that are deemed to be possible, in the sense of having nonzero probability:

\text{Supp}(P)=\{\omega\in\mathcal{X}|P(\omega)>0\}

A set of events
S
is said to be a realizable support of the pDAG
\cal G
if there is
some
distribution
P
that is realizable by
\cal G
such that
\text{Supp}(P)=S
. Let
\mathcal{S}(\mathcal{G},\vec{c}_{\text{vis}})
denote the set of all sets of events that are realizable by the pDAG
\cal G
for cardinalities of the visible variables given by
\vec{c}_{\text{vis}}
. Ref.
[
39
]
presented an algorithm to find the set
\mathcal{S}(\mathcal{G},\vec{c}_{\text{vis}})
. We refer to it here as
Fraser’s algorithm
. This algorithm is explained in Appendix
B
.

Just as we defined the observational profile
\mathcal{M}{-}{\tt{profile}}(\cal G)
of a pDAG
\cal G
, we can define
\cal G
’s
possibilistic observational profile
by:

\mathcal{S}{-}{\tt{profile}}(\mathcal{G})\coloneqq\left\{\mathcal{S}(\mathcal{G},\vec{c}_{\text{vis}}):\vec{c}_{\text{vis}}\in\mathbb{N}^{|\mathtt{Vnodes}(\mathcal{G})|}\right\}.

(11)

If the support of a probability distribution
P
is
not
realizable by
\cal G
, then clearly
P
is not realizable by
\cal G
. Thus, if there is some assignment of cardinalities for which a pDAG
\cal G
cannot realize a support that is realizable by another pDAG
\cal G^{\prime}
, then
\cal G
cannot observationally dominate
\cal G^{\prime}
. In other words, for some assignment of cardinalities of the visible variables, we have:

\displaystyle\mathcal{S}{-}{\tt{profile}}(\mathcal{G})\not\subseteq_{\text{ew}}\mathcal{S}{-}{\tt{profile}}(\mathcal{G}^{\prime})

\displaystyle\Rightarrow

(12)

\displaystyle\mathcal{M}{-}{\tt{profile}}(\mathcal{G})\not\subseteq_{\text{ew}}\mathcal{M}{-}{\tt{profile}}(\mathcal{G}^{\prime})

where
\not\subseteq_{\text{ew}}
denotes the failure of element-wise inclusion. From this implication, we know that the comparison of unrealizable supports gives us a nondominance-proving rule:

Proposition 14

(Comparison of unrealizable supports)
.

Let
\mathfrak{G}
and
\mathfrak{G}^{\prime}
be two mDAGs such that
\mathtt{nodes}(\mathfrak{G})=\mathtt{nodes}(\mathfrak{G}^{\prime})
. If there is a support that is realizable by
\mathfrak{G}^{\prime}
but not by
\mathfrak{G}

\mathfrak{G}

does not

\mathfrak{G}^{\prime}
, i.e.,
\mathfrak{G}\not\succeq\mathfrak{G}^{\prime}
.

Note that it is unclear whether the converse implication to that of (
12
) holds. We will discuss potential prospects to tackle this open question in Section
7.3
.

5.2.1
Subsumption of other nondominance-proving rules

In Lemmas
5
and
6
, we showed that the comparison of e-separation relations subsumes the comparison of skeletons and d-separation relations as rules to show observational nondominance. In this section, we discuss how the comparison of unrealizable supports subsumes other rules.

Since Fraser’s algorithm for unrealizable supports is a brute force search, one wants to apply as many of the weaker but computationally cheaper rules as possible before implementing the comparison of unrealizable supports. However, it is possible to show that all of the cheaper rules — comparison of e-separation relations, comparison of densely connected pairs of nodes, and the directed-edge-free rule — are subsumed by the comparison of unrealizable supports. In fact, to subsume the cheaper rules it is sufficient to look at supports at the level of binary visible variables; that is, whenever a nondominance can be shown by one of the cheaper rules, one can find a support with
\vec{c}_{\text{vis}}=(2,2,2,2)
that also shows said nondominance.

Lemma 7

(The comparison of unrealizable supports subsumes the comparison of e-separation relations)
.

Let
\mathfrak{G}
and
\mathfrak{G}^{\prime}
be two mDAGs that have different sets of e-separation relations. Then, it is possible to find a support which is realizable by one of these mDAGs but not by the other. In fact, it is possible to do find such a support even when all of the visible variables are binary, i.e.,
\vec{c}_{\text{vis}}=(2,2,2,2)
.

The proof is given in Appendix
C
. The idea behind this proof is that the set of e-separation relations of a given mDAG might already imply that some supports are unrealizable. As an example of this, imagine a causal structure that presents the d-separation relation
a\mathbin{\text{$\bot\mkern-8.0mu\bot$}_{\text{d}}}b
. Suppose that
S
is a support over binary variables
X_{a}
and
X_{b}
that does not contain any events involving
\{X_{a}=0,X_{b}=1\}
or
\{X_{a}=1,X_{b}=0\}
. This implies that in any probability distribution
P
that has the support
S
, i.e., where
\text{Supp}(P)=S
, the variables
X_{a}
and
X_{b}
are correlated. This is incompatible with
a\mathbin{\text{$\bot\mkern-8.0mu\bot$}_{\text{d}}}b
, thus the support
S
is ruled out by
a\mathbin{\text{$\bot\mkern-8.0mu\bot$}_{\text{d}}}b
. To save time in the computation, we only apply Fraser’s algorithm for supports that are not already ruled out by the e-separation relations of the mDAG in question.

Lemma 8

(The comparison of unrealizable supports subsumes the comparison of densely connected pairs of nodes)
.

Let
\mathfrak{G}
and
\mathfrak{G}^{\prime}
be two mDAGs such that
\mathfrak{G}
can be shown to
not
observationally dominate
\mathfrak{G}^{\prime}
by comparison of densely connected pairs of nodes. Then,
\mathfrak{G}
can also be shown to not observationally dominate
\mathfrak{G}^{\prime}
by comparison of unrealizable supports. In fact, it is possible to do so even when we are only comparing unrealizable supports where all of the visible variables are binary, i.e.,
\vec{c}_{\text{vis}}=(2,2,2,2)
.

The proof of this lemma is given in Appendix
C
.

Lemma 9

(The comparison of unrealizable supports subsumes the directed-edge-free rule)
.

Let
\mathfrak{G}
and
\mathfrak{G}^{\prime}
be two mDAGs such that
\mathfrak{G}
can be shown to
not
observationally dominate
\mathfrak{G}^{\prime}
by the directed-edge-free rule. Then,
\mathfrak{G}
can also be shown to not observationally dominate
\mathfrak{G}^{\prime}
by comparison of unrealizable supports. In fact, it is possible to do so even when we are only comparing unrealizable supports where all of the visible variables are binary, i.e.,
\vec{c}_{\text{vis}}=(2,2,2,2)
, and the supports are constituted by only two events.

The proof of this lemma is given in Appendix
C
.

The main point of Ref.

[
10

[
18
]
for the Bell causal structure can be extended to any observational equivalence class of causal structures that is
nonalgebraic
and is identified by d-separation alone. For such a class of causal structures, any distribution that satisfies all and only the conditional independence relations implied by the set of d-separation relations of that class, but that violates the inequality constraints of the class necessarily cannot be explained within the framework of classical causal models without fine-tuning.

7.2.1
Nonalgebraicness is Ubiquitous

As discussed in Section
3.3
, in the set of 3-node mDAGs consistent with a fixed nodal ordering, there are 15 observational equivalence classes and 5 of them are
nonalgebraic
. Therefore, for the case of three visible variables, the fraction of
nonalgebraic
classes among all classes of mDAGs consistent with a fixed nodal ordering is
1/3
. As we will see in this section, the fraction of
nonalgebraic
classes gets much bigger in the case of 4-node mDAGs consistent with a fixed nodal ordering.

Since we still have not obtained a complete characterization of the observational equivalence partition of 4-node mDAGs consistent with a fixed nodal ordering, the best we can do is to find a lower bound on the fraction of
nonalgebraic
equivalence classes. We will explain two methods for obtaining such a lower bound. We then pick the best lower bound out of the two results. Method 1 consists in obtaining a
lower bound on the number of
nonalgebraic
classes
, and dividing it by our best
upper bound
on the total number of observational equivalence classes (which is currently 1444). The resulting number
f_{1}
is a lower bound on the fraction of
nonalgebraic
classes. Method 2 consists in obtaining an
upper bound on the number of
algebraic
classes
, and dividing it by our best
lower bound
on the total number of observational equivalence classes (which is 1253). The resulting number
f_{2}
is such that
1-f_{2}
is a lower bound on the fraction of
nonalgebraic
classes.

We first implement method 1. An observational equivalence class of mDAGs consistent with a fixed nodal ordering is identified as
nonalgebraic
, according to Proposition
3
, when there is
no
other equivalence class of mDAGs consistent with the same fixed nodal ordering that simultaneously includes a confounder-free mDAG and an mDAG that can be obtained from one of the mDAGs of the class of interest by a permutation of the nodes. To obtain a lower bound on the number of
nonalgebraic
classes, we look at the proven-inequivalence partition and find all of the blocks thereof whose mDAGs are
not
related by permutation to any other mDAG lying in a proven-inequivalence block that includes a confounder-free mDAG. By Proposition
3
, all of the mDAGs in this special class of blocks of the proven-inequivalence partition are
nonalgebraic
. The number of blocks of this type is a lower bound on the number of
nonalgebraic
observational equivalence classes. Applying this method on the proven-inequivalence partition induced by all of the graphical rules of Section
5.1
together with comparison of unrealizable supports up to 8 events, we obtain the lower bound of 1137 on the number of
nonalgebraic
observational equivalence classes. Therefore, the lower bound on the fraction of
nonalgebraic
classes obtained by method 1 is
f_{1}=1137/1444\approx 78.7\%
.

Now we implement method 2, where we want to find an
upper bound
on the number of
algebraic
classes. As discussed in Section
3.4.3
, Ref.
[
33
]
proved that an mDAG
\mathfrak{G}
is

if and only if it is observationally equivalent to a confounder-free mDAG
\mathfrak{H}
. Recall that if we are considering a set of mDAGs that are consistent with a fixed nodal ordering, and
\mathfrak{G}
is in that set, then
\mathfrak{H}
need not be in that set. Thus,
\mathfrak{H}
need not appear in the observational partial order of mDAGs consistent with a fixed nodal ordering that we have constructed. Previously discussed examples include the classes

and

of Fig.
3.1

, but the confounder-free mDAGs that are observationally equivalent to them do not follow the nodal ordering
(a,b,c)

Collider B
are observationally equivalent to the confounder-free mDAG

, which is only consistent with the nodal orderings
(a,c,b)
and
(c,a,b)
. In general, we have:

Lemma 10
.

Let
\mathfrak{G}
be an

\mathtt{nodes}(\mathfrak{G})=\{a_{1},a_{2},...,a_{n}\}

\Pi

\mathfrak{G}

•

\mathfrak{G}

\Pi(a_{1},...,a_{n})

•

\mathfrak{H}

\Pi(a_{1},...,a_{n})

Proof.

This is a corollary of Proposition
3
. Let
\mathfrak{G}

(a_{1},...,a_{n})

7.2.2
Conditional Independence relations are not enough to single out most Observational Equivalence Classes

Even if inequality constraints are generic, it could still be the case that algorithms for constraint-based causal discovery that leverage only conditional independence constraints are capable of distinguishing most of the observational equivalence classes. That is, it could be the case that most equivalence classes can be singled out by their set of conditional independence constraints alone, even if they also present nested Markov constraints or inequality constraints. However, our analysis shows that this is
not
the case for 4-node mDAGs, and the comparison of the 3-node and 4-node cases leads us to believe that this is likely not the case for higher numbers of visible nodes either.

If one only analyses the conditional independence constraints satisfied by a set of data (and one does not investigate nested Markov constraints nor inequality constraints), it is possible to single out the correct observational equivalence class for this data
only if
the equivalence class
has a unique set of conditional independence relations. When this happens, using the language of Section
7.1
, the observational equivalence class is identified by the comparison of d-separation relations rule. We will say that such classes are
identified by conditional independence relations alone
.
If the conditional independence relations of the set of data do not correspond to those of any equivalence class that is identified by conditional independence relations alone,
then there is remaining ambiguity about the observational equivalence class that explains the data.

For the case of 2-node mDAGs there are no inequality constraints, so every observational equivalence class can be identified by conditional independence relations alone,
For the case of 3-node mDAGs consistent with a fixed nodal ordering, there are 10 equivalence classes that can be identified by d-separation alone. The remaining classes, namely,

Triangle
,
Evans
,
Instrumental BAC
,
Instrumental CAB
and
Saturated
, are all devoid of nontrivial d-separation relations. Therefore, for this case the fraction of causal structures that can be singled out by the analysis of conditional independence constraints alone is
2/3
. For the case of 4-node mDAGs consistent with a fixed nodal ordering, Table
5
shows that only 114 equivalence classes are identified by conditional independence relations alone.
This is less than 10% of our best lower bound on the total number of equivalence classes. Therefore, in most cases it will
not
be possible to discriminate between observationally inequivalent classes of causal structures if one only avails oneself of conditional independence relations.

Therefore, our analysis shows that, as well as the fraction of
nonalgebraic
classes increasing
with the number of nodes for the cases of 2, 3 and 4 nodes, the fraction of all observational equivalence classes that can be singled out by analysis of conditional independence relations alone drastically decreases with the number of nodes for the cases of 2, 3 and 4 nodes.

8
Conclusion

In this work, we have gathered all the currently known techniques to prove observational dominance or nondominance between causal structures, extended the scope of these techniques, proved logical implications among them, and applied them to causal structures with three and four visible nodes.

For the case of three visible variables, Fig. 13 of Ref.
[
24
]
had already presented representatives of blocks of a proven-equivalence partition. However, in Ref.
[
24
]
it was not explicitly shown that all of these were observational equivalence classes (i.e., that they were all observationally inequivalent), and the observational partial order was not studied. Here, we were able to deduce the observational equivalence classes and observational partial order for 3-node mDAGs.

For the case of four visible variables, we showed that the total number of observational equivalence classes for 4-node mDAGs consistent with a fixed nodal ordering is between
1253
and
1444
. Furthermore,
1156
observational equivalence classes are already identified.

Classifying the classical causal structures into observational equivalence classes and establishing the observational partial order among these classes is important for several reasons. For one, it drastically lowers the number of possible causal explanations to be considered for a set of data relative to the total number of mDAGs. For another, the dominance order can be used to simplify the task of model selection (as discussed in Section
3.4
).
It also helps in assessing how many classes present non-trivial inequality constraints.

Inequality constraints seem to be generic in the sense of the number of observational equivalence classes having inequality constraints growing
with the number of visible variables: it is
1/3
for 3-node mDAGs consistent with a fixed nodal ordering, and at least
85.2\%
for 4-node mDAGs consistent with a fixed nodal ordering. We also argued against relying only on conditional independence relations
for causal discovery on the basis that these constraints have a poor distinguishing power for observational equivalence classes: for 4-node mDAGs consistent with a fixed nodal ordering,
2/3
of the observational equivalence classes can be identified by conditional independence relations
alone; for 3-node mDAGs consistent with a fixed nodal ordering, however, this fraction drops to less than
10\%
. These arguments highlight the importance
of inequality constraints and nested Markov constraints for the task of classical causal discovery.

From the point of view of quantum causality, this result is also relevant because only the causal structures that exhibit inequality constraints have the potential of presenting quantum-classical gaps, that is, of being such that
the distributions realizable by quantum semantics are a superset of the distributions realizable by classical semantics. All of the
nonalgebraic
mDAGs that we identified here were already identified in Ref.
[
8
]
, but our classification shows that the
majority
of observational equivalence classes have the potential of presenting quantum-classical gaps. This shows that the property of exhibiting a quantum-classical gap might not be the exception, but rather the norm.

Another result from this work that is relevant to quantum physicists who are interested in causal inference is an identification of the set of all 4-node mDAGs consistent with a fixed nodal ordering that admit a fine-tuning theorem similar to the one that holds for Bell’s causal structure
[
18
]
. That is, if the set of conditional independence relations of an observed distribution matches exactly the set of d-separation relations of the mDAG but the distribution
violates
one of the inequality constraints of the mDAG, then this distribution
does not
admit any non-fine-tuned causal explanation in the classical framework for causal modelling. The mDAGs for which such an argument can be made are the ones that belong to observational equivalence classes identified by d-separation alone, one example being the
Square
structure of Fig.
7.1
(b). This result is of interest for quantum physicists, because many times quantum theory predicts such violations.

To finish the classification of structures with four visible nodes, there are two options: (i) we continue the comparison of unrealizable supports (Section
5.2
) but with higher cardinalities of the visible variables, that might complete the classification but will be computationally expensive. (ii) we find new dominance-proving or nondominance-proving rules that help us finish the classification. Note that these two options are not mutually exclusive: we might find a new nondominance-proving rule that helps us complete the classification, at the same time that a comparison of unrealizable supports at high enough cardinality would in principle also solve it.

Another open problem that this work has generated is the question of whether possibilistic equivalence implies probabilistic equivalence. In other words, if two causal structures have the same set of unrealizable supports for a certain assignment of cardinalities of the visible variables, does this mean that they have the same set of realizable distributions for those cardinalities? This problem was not solved here, but a possible route of investigation was outlined: all the mDAGs of Fig.
7.2
can realize every support on binary variables, even if there is currently no rule that shows that
7.2
(a)-(g) are observationally equivalent to the saturated class for binary variables. Therefore, if one can show that any of these mDAGs
cannot
realize every probability distribution on binary variables, one has found a counter-example to the conjecture that possibilistic equivalence implies probabilistic equivalence.

Appendix B
Fraser’s Algorithm for Feasible Supports

In this section, we present the algorithm of Ref.
[
39
]
for finding
\mathcal{S}(\mathcal{G},\vec{c}_{\text{vis}})
, the set of supports with cardinalities
\vec{c}_{\text{vis}}
of the visible variables that are realizable by a pDAG
\mathcal{G}
. This algorithm consists of enumerating all the possible responses that a visible variable can have to its parents, given that the cardinalities of the visible variables and the latent variables are fixed.

In Ref.
[
39
]
, it is shown that whenever the visible variables have finite cardinalities, we can assume the latent variables to have finite cardinalities without loss of generality. Furthermore, for a given number of events in the support, one gets an upper bound on the cardinality of the latent variables that has to be considered. This upper bound will be discussed after we describe the algorithm.

Given a pDAG
\mathcal{G}
:

1.

Fix the cardinalities of every latent variable to be
k
and the cardinality of each visible variable
v
to be
c_{v}
.

2.

For each visible variable, enumerate all possible response functions it can have to the valuations of its parents.

For example, if a visible
v
has only one parent and this parent is latent, it has
(c_{v})^{k}
possible response functions; we could have that
v
reacts with the each one of its
c_{v}
possible values for each one of the
k
possible valuations of its parent.

In general, if the total cardinality of the parents of
v
is
K(v)
, then we have
(c_{v})^{K(v)}
possibilities of response function for
v
.

3.

For each possibility of response functions of all the visible variables of
\mathcal{G}
, we compute the support: the set of visible events that occur under that response function, for some valuation of the latent variables.

The question that is left is how to choose
k
, the cardinality of latent variables. First we note that, if a support containing
s
events is realizable by
\mathcal{G}
, it will certainly be found with the algorithm for all
k\geq s
. Thus,
s
is an upper bound on the values of
k
that we need to consider.

Assuming that all the visible variables have the same cardinality
c
, and considering that the total number of visible variables is
|\mathtt{Vnodes}(\mathcal{G})|
, the maximum number of events that we can have is
c^{|\mathtt{Vnodes}(\mathcal{G})|}
. So, to be certain that we found all compatible supports, we should choose
k=c^{|\mathtt{Vnodes}(\mathcal{G})|}
.

Note that if
\mathcal{S}(\mathcal{G},\vec{c}_{\text{vis}}=(2,2,2,2))\neq\mathcal{S}(\mathcal{G}^{\prime},\vec{c}_{\text{vis}}=(2,2,2,2))
, i.e., if the set of realizable
binary
supports of
\cal G
and
\cal G^{\prime}
are different, then the sets of realizable supports will also be different when we go to higher cardinalities. This is so because we can simply gather events together (for example joining events
x
and
y
in
z=x\land y
) to go back to the binary case, where the difference is proven.
