Decentralized projected Riemannian stochastic recursive momentum method for smooth optimization on compact submanifolds
Kangkang Deng, Jiang Hu

Abstract
This paper studies decentralized optimization over a compact submanifold within a communication network of n n nodes, where each node possesses a smooth non-convex local cost function, and the goal is to jointly minimize the sum of these local costs. We focus particularly on the online setting, where local data is processed in real-time as it streams in, without the need for full data storage. We propose a decentralized projected Riemannian stochastic recursive momentum (DPRSRM) method that employs local hybrid stochastic gradient estimators and uses the network to track the global gradient. DPRSRM achieves an oracle complexity of 𝒪 ⁡ ( ϵ − 3 2 ) \mathcal{O}(\epsilon^{-\frac{3}{2}}) , outperforming existing methods that have at most 𝒪 ⁡ ( ϵ − 2 ) \mathcal{O}(\epsilon^{-2}) complexity. Our method requires only 𝒪 ⁡ ( 1 ) \mathcal{O}(1) gradient evaluations per iteration for each local node and does not require restarting with a large batch gradient. Furthermore, we demonstrate the effectiveness of our proposed methods compared to state-of-the-art ones through numerical experiments on principal component analysis problems and low-rank matrix completion. This revised version corrects the mean-square oracle condition and the estimator/tracking analysis, and replaces the original separate error summation by a coupled Lyapunov argument; Algorithm 1 and the 𝒪 ( ϵ − 3 / 2 ) \mathcal{O}(\epsilon^{-3/2}) oracle-complexity order are unchanged.

Introduction

Decentralized optimization has emerged as a prominent area of research, particularly for its application in large-scale systems, such as sensor networks, distributed computing, and machine learning. In these contexts, data is often partitioned across numerous nodes, rendering centralized optimization approaches impractical due to challenges such as privacy limitations and restricted computational resources. In this work, we are concerned with the distributed smooth optimization on a compact submanifold

Preliminary

2.1
Stationary point

Let
x_{1},\cdots,x_{n}\in\mathcal{M}
represent the local copies of each node.
Let
\mathcal{P}_{\mathcal{M}}
be the orthogonal projection onto
\mathcal{M}
. Note that for

{\rm argmin}_{y\in\mathcal{M}}\sum_{i=1}^{n}\|y-x_{i}\|^{2}=\mathcal{P}_{\mathcal{M}}(\hat{x}).

Any element

in
\mathcal{P}_{\mathcal{M}}(\hat{x})
is the induced arithmetic mean of
\{x_{i}\}_{i=1}^{n}
on
\mathcal{M}

[
26
]
.
Thus, for a single point

,
\mathrm{grad}f(z)=\frac{1}{n}\sum_{i=1}^{n}\mathrm{grad}f_{i}(z)
. The
\epsilon
-stationary point of problem (
1.1
) is defined as follows.

Definition 2.1
(
[
14
]
).

The set of points
\{x_{1},x_{2},\cdots,x_{n}\}\subset\mathcal{M}
is called an
\epsilon
-stationary point of (
1.1
) if there exists a
\bar{x}\in\mathcal{P}_{\mathcal{M}}(\hat{x})
such that

\mathbb{E}\left[\frac{1}{n}\sum_{i=1}^{n}\|x_{i}-\bar{x}\|^{2}\right]\leq\epsilon\quad{\rm and}\quad\mathbb{E}[\|\mathrm{grad}f(\bar{x})\|^{2}]\leq\epsilon.

We refer to these two terms as consensus error and optimality error, respectively.

2.2
Proximal smoothness

Proximal smoothness is an effective tool for addressing the nonconvex nature of manifold constraints within decentralized optimization settings
[
14
]
. Define the distance from a point
x\in\mathbb{R}^{d\times r}
to the manifold
\mathcal{M}
and the nearest-point projection of
x
onto
\mathcal{M}
as
\text{dist}(x,\mathcal{M}):=\inf_{y\in\mathcal{M}}\|y-x\|\;\;\text{and}\;\;\mathcal{P}_{\mathcal{M}}(x):=\arg\min_{y\in\mathcal{M}}\|y-x\|,

respectively. For a given number
R>0
, the
R
-tube around
\mathcal{M}
is defined as the set
U_{\mathcal{M}}(R):=\{x:\text{dist}(x,\mathcal{M})<R\}.

A closed set
\mathcal{M}
is said to be
R
-proximally smooth if the projection
\mathcal{P}_{\mathcal{M}}(x)
is unique whenever
\text{dist}(x,\mathcal{M})<R
. Following
[
9
]
, an
R
-proximally smooth set
\mathcal{M}
satisfies that for any real
{\delta}\in(0,R)
,

\left\|\mathcal{P}_{\mathcal{M}}(x)-\mathcal{P}_{\mathcal{M}}(y)\right\|\leq\frac{R}{R-{\delta}}\|x-y\|,~~\forall x,y\in\bar{U}_{\mathcal{M}}({\delta}),

(2.1)

where
\bar{U}_{\mathcal{M}}(\delta):=\{x:\text{dist}(x,\mathcal{M})\leq\delta\}
. For instance, the Stiefel manifold is known to be a 1-proximally smooth set
[
2
]
, which also provides additional examples of rank manifolds along with their specific proximal smoothness radii.

5.1
Decentralized principal component analysis

The decentralized principal component analysis (PCA) problem can be expressed mathematically as follows:

\min_{\mathbf{x}\in\mathcal{M}^{n}}-\frac{1}{2n}\sum_{i=1}^{n}\text{tr}(x_{i}^{\top}A_{i}^{\top}A_{i}x_{i}),\;\;\text{ s.t. }\;\;x_{1}=\ldots=x_{n},

(5.1)

where
\mathcal{M}
is the Stiefel manifold
\text{St}(d,r)
,
A_{i}\in\mathbb{R}^{m_{i}\times d}
is the data matrix corresponding to the
i
-th node, and
m_{i}
denotes the number of samples. It is worth noting that if
x^{*}
is a solution to this problem, then any transformation of
x^{*}
by an orthogonal matrix
Q\in\mathbb{R}^{r\times r}
is also a valid solution. The distance between two points
x
and
x^{*}
is then calculated as:

d_{s}(x,x^{*}):=\min_{Q\in\mathbb{R}^{r\times r},\;Q^{\top}Q=QQ^{\top}=I_{r}}\;\|xQ-x^{*}\|.

5.2
Low-rank matrix completion problem

The low-rank matrix completion (LRMC) problem aims to reconstruct a matrix
A\in\mathbb{R}^{d\times T}
with low rank from its partially observed entries. Let
\Omega
represent the set of indices corresponding to the observed entries in
A
. The LRMC problem of rank
r
can be expressed as:

\min_{X\in{\rm Gr}(d,r),V\in\mathbb{R}^{r\times T}}\quad\frac{1}{2}\|\mathcal{P}_{\Omega}(XV-A)\|^{2},

(5.2)

where
\text{Gr}(d,r)
represents the Grassmann manifold of
r
-dimensional subspaces in
\mathbb{R}^{d}
, and
\mathcal{P}_{\Omega}
is a projection operator that selects the elements of
A
indexed by
\Omega
, setting the rest to zero.

In a decentralized context, assume the matrix
\mathcal{P}_{\Omega}(A)
is divided into
n
equal parts by columns, labeled as
A_{1},A_{2},\ldots,A_{n}
, each part corresponding to a different node. Replacing the Grassmann manifold constraint with the Stiefel manifold, the decentralized LRMC problem
[
14
]
is therefore formulated as:

\displaystyle\min

\displaystyle\frac{1}{2}\sum_{i=1}^{n}\|\mathcal{P}_{\Omega_{i}}(X_{i}V_{i}(X)-A_{i})\|^{2},

(5.3)

\displaystyle\mathrm{s.t.}

\displaystyle X_{1}=X_{2}=\cdots=X_{n},

\displaystyle X_{i}\in{\rm St}(d,r),\quad\forall i\in[n],

where
\Omega_{i}
is the corresponding indices set of
\Omega
and
V_{i}(X):={\rm argmin}_{V}\|\mathcal{P}_{\Omega_{i}}(XV-A_{i})\|
.

For numerical tests, we consider random generated
A
. To be specific, we first generate two random matrices
L\in\mathbb{R}^{d\times r}
and
R\in\mathbb{R}^{r\times T}
, where each element obeys the standard Gaussian distribution. For the indices set
\Omega
, we generate a random matrix
B
with each element following from the uniform distribution, then set
\Omega_{ij}=1
if

and
0
otherwise. The parameter

is set to
r(d+T-r)/(dT)
. In the implementations, we set
T=1000,d=50,r=10
, and
\alpha=\frac{\hat{\beta}}{\sqrt{K}}
for all algorithms with

6
Conclusions and Limitations

This work develops a decentralized projection Riemannian stochastic recursive momentum method by assuming that each
node has access to a stochastic first-order oracle. Our algorithm
leverages local hybrid variance reduction and gradient tracking
to achieve a lower oracle complexity compared with the existing online
methods. It requires only
\mathcal{O}(1)
gradient evaluations per iteration for each local node and does not require restarting with a large batch gradient.

i\in[n]

\displaystyle\|\sum_{j=1}^{n}W_{ij}x_{j,k}-\alpha v_{i,k}-\bar{x}_{k}\|\leq

\displaystyle\|\sum_{j=1}^{n}W_{ij}(x_{j,k}-\bar{x}_{k})-\alpha v_{i,k}\|

\displaystyle\leq

\displaystyle\sum_{j=1}^{n}W_{ij}\|x_{j,k}-\bar{x}_{k}\|+\alpha\|v_{i,k}\|

\displaystyle\leq

\displaystyle\delta+\sqrt{nD_{B}}\alpha\leq 2\delta.

By
\delta<R/2
, we have

\sum_{j=1}^{n}W_{ij}x_{j,k}-\alpha v_{i,k}\in\bar{U}_{\mathcal{M}}(2\delta)
.
Moreover,
\max_{i}\|x_{i,k}-\bar{x}_{k}\|\leq\delta
, so

\hat{x}_{k}\in\bar{U}_{\mathcal{M}}(\delta)\subset\bar{U}_{\mathcal{M}}(2\delta)
.
The
\kappa_{M}
-Lipschitz property of
\mathcal{P}_{\mathcal{M}}
therefore gives

\displaystyle\|\mathbf{x}_{k+1}-\bar{\mathbf{x}}_{k+1}\|\leq\|\mathbf{x}_{k+1}-\bar{\mathbf{x}}_{k}\|

\displaystyle=\|\mathcal{P}_{\mathcal{M}^{n}}(\mathbf{W}\mathbf{x}_{k}-\alpha\mathbf{v}_{k})-\mathcal{P}_{\mathcal{M}^{n}}(\hat{\mathbf{x}}_{k})\|

\displaystyle\leq\frac{R}{R-2\delta}\|\mathbf{W}\mathbf{x}_{k}-\alpha\mathbf{v}_{k}-\hat{\mathbf{x}}_{k}\|

\displaystyle\leq\frac{R}{R-2\delta}\|[(W-J)\otimes I_{d}](\mathbf{x}_{k}-\hat{\mathbf{x}}_{k})-\alpha\mathbf{v}_{k}\|

\displaystyle\leq\frac{R\sigma_{2}}{R-2\delta}\|\mathbf{x}_{k}-\bar{\mathbf{x}}_{k}\|+\frac{R\alpha}{R-2\delta}\|\mathbf{v}_{k}\|

\displaystyle\leq\frac{R\sigma_{2}}{R-2\delta}\delta+\frac{R\alpha}{R-2\delta}\sqrt{nD_{B}}.

For a fixed
\delta
, the inequality

\|\mathbf{x}_{k+1}-\bar{\mathbf{x}}_{k+1}\|\leq\delta
holds provided that

\alpha\leq\frac{(R(1-\sigma_{2})-2\delta)\delta}{R\sqrt{nD_{B}}}.

(B.1)

The right-hand side is positive whenever

0<\delta<R(1-\sigma_{2})/2
, as required by (
3.14
).
This closes the induction.

B.2
Proof of Section
4.2

Proof of Lemma
4.3
.

We prove the four inequalities in turn. For the transition from
k
to

k+1
, all conditional expectations are taken with respect to

\mathcal{F}_{k+1}
, i.e., immediately before drawing

\bm{\xi}_{k+1}
. Thus,
\mathbf{x}_{k},\mathbf{x}_{k+1}
and
\mathbf{d}_{k}
are measurable
with respect to the conditioning sigma-algebra.

Step 1: estimator error.

Set

\Delta_{k}:=\mathbf{d}_{k}-\mathrm{grad}f(\mathbf{x}_{k}),\qquad\mathbf{g}_{k}^{\xi}:=\mathrm{grad}f(\mathbf{x}_{k},\bm{\xi}_{k+1}),\qquad\mathbf{g}_{k}:=\mathrm{grad}f(\mathbf{x}_{k}).

Since
B\geq G_{\max}
, every block of
\mathbf{g}_{k+1}
belongs to the clipping
ball. Blockwise nonexpansiveness of the Euclidean projection therefore gives

\|\mathbf{d}_{k+1}-\mathbf{g}_{k+1}\|^{2}\leq\|\mathbf{q}_{k+1}-\mathbf{g}_{k+1}\|^{2}.

(B.2)

The un-clipped error has the exact decomposition

\mathbf{q}_{k+1}-\mathbf{g}_{k+1}=(1-\tau)\Delta_{k}+\bm{\varepsilon}_{k+1},

(B.3)

where

\displaystyle\bm{\varepsilon}_{k+1}:={}

\displaystyle\tau(\mathbf{g}_{k+1}^{\xi}-\mathbf{g}_{k+1})

\displaystyle+(1-\tau)\{\mathbf{g}_{k+1}^{\xi}-\mathbf{g}_{k}^{\xi}-(\mathbf{g}_{k+1}-\mathbf{g}_{k})\}.

Both terms in braces are evaluated using the same fresh sample. Their sum is
conditionally centered, so

\mathbb{E}[\bm{\varepsilon}_{k+1}\mid\mathcal{F}_{k+1}]=0
and the cross term with

\Delta_{k}
in (
B.3
) vanishes. We do not assume
that the two fresh-sample terms are mutually independent. Instead,

\|a+b\|^{2}\leq 2\|a\|^{2}+2\|b\|^{2}
, conditional variance is bounded by the
corresponding second moment, and Assumption
3.4
give

\displaystyle\mathbb{E}[\|\bm{\varepsilon}_{k+1}\|^{2}\mid\mathcal{F}_{k+1}]\leq{}

\displaystyle 2n\tau^{2}\nu^{2}+2(1-\tau)^{2}\bar{L}^{2}\|\mathbf{x}_{k+1}-\mathbf{x}_{k}\|^{2}.

(B.4)

Taking full expectation in (
B.2
) and using
(
B.3
)–(
B.4
) yields

\mathsf{E}_{k+1}\leq(1-\tau)^{2}\mathsf{E}_{k}+2\tau^{2}\nu^{2}+\frac{2\bar{L}^{2}}{n}\mathbb{E}\|\mathbf{x}_{k+1}-\mathbf{x}_{k}\|^{2}.

(B.5)

This is the point at which the original proof introduced the spurious factor

\alpha^{2}
: mean-square Lipschitz continuity gives the last squared
iterate-difference directly.

For completeness, let
\mathrm{\bf y}_{k}:=\mathbf{W}\mathbf{x}_{k}-\alpha\mathbf{v}_{k}
. Since

\mathbf{x}_{k+1}=\mathcal{P}_{\mathcal{M}^{n}}(\mathrm{\bf y}_{k})
and
\mathbf{x}_{k}\in\mathcal{M}^{n}
, optimality of the
projection gives
\|\mathbf{x}_{k+1}-\mathrm{\bf y}_{k}\|\leq\|\mathbf{x}_{k}-\mathrm{\bf y}_{k}\|
. Hence,

\displaystyle\|\mathbf{x}_{k+1}-\mathbf{x}_{k}\|

\displaystyle\leq 2\|\mathrm{\bf y}_{k}-\mathbf{x}_{k}\|

\displaystyle\leq 2\|(I_{nd}-\mathbf{W})(\mathbf{x}_{k}-\bar{\mathbf{x}}_{k})+\alpha\mathbf{v}_{k}\|.

Because
\|I_{nd}-\mathbf{W}\|\leq 2
and

\|\mathbf{v}_{k}\|\leq\|\mathrm{\bf s}_{k}\|
, squaring the preceding display gives

\frac{1}{n}\mathbb{E}\|\mathbf{x}_{k+1}-\mathbf{x}_{k}\|^{2}\leq 32\mathsf{X}_{k}+8\alpha^{2}\mathsf{S}_{k}.

(B.6)

Combining (
B.5
) and
(
B.6
), and using
(1-\tau)^{2}\leq 1
in the
forcing term, proves (
4.6
).

Step 2: tracking error.

The identity
d_{i,k+1}=q_{i,k+1}
need not hold when clipping is active.
However,
d_{i,k}\in B\mathbb{B}
for every
k\geq 0
(at
k=0
this follows
from Assumption
3.4
), and therefore

\displaystyle\|d_{i,k+1}-d_{i,k}\|

\displaystyle=\|\mathcal{P}_{B\mathbb{B}}(q_{i,k+1})-\mathcal{P}_{B\mathbb{B}}(d_{i,k})\|

\displaystyle\leq\|q_{i,k+1}-d_{i,k}\|.

(B.7)

Expanding the last vector gives three terms:

\displaystyle q_{i,k+1}-d_{i,k}={}

\displaystyle\mathrm{grad}f_{i}(x_{i,k+1},\xi_{i,k+1})-\mathrm{grad}f_{i}(x_{i,k},\xi_{i,k+1})

\displaystyle+\tau\{\mathrm{grad}f_{i}(x_{i,k},\xi_{i,k+1})-\mathrm{grad}f_{i}(x_{i,k})\}+\tau\{\mathrm{grad}f_{i}(x_{i,k})-d_{i,k}\}.

Thus, by
\|a+b+c\|^{2}\leq 3(\|a\|^{2}+\|b\|^{2}+\|c\|^{2})
, the oracle
assumptions, and (
B.6
),

\frac{1}{n}\mathbb{E}\|\mathbf{d}_{k+1}-\mathbf{d}_{k}\|^{2}\leq 96\bar{L}^{2}\mathsf{X}_{k}+24\bar{L}^{2}\alpha^{2}\mathsf{S}_{k}+3\tau^{2}\mathsf{E}_{k}+3\tau^{2}\nu^{2}.

(B.8)

Double stochasticity and
\hat{\mathrm{\bf s}}_{k}=\hat{\mathbf{d}}_{k}
imply

\mathrm{\bf s}_{k+1}-\hat{\mathbf{d}}_{k+1}=((W-J)\otimes I_{d})(\mathrm{\bf s}_{k}-\hat{\mathbf{d}}_{k})+((I-J)\otimes I_{d})(\mathbf{d}_{k+1}-\mathbf{d}_{k}).

(B.9)

For
\sigma_{2}>0
, apply

\|a+b\|^{2}\leq(1+\zeta)\|a\|^{2}+(1+1/\zeta)\|b\|^{2}
with

\zeta_{T}:=\frac{1-\sigma_{2}^{2}}{2\sigma_{2}^{2}}.

Then

(1+\zeta_{T})\sigma_{2}^{2}=q_{T},\qquad 1+\frac{1}{\zeta_{T}}=h_{T}.

Using
\|I-J\|=1
in (
B.9
) and then
(
B.8
) proves (
4.7
). If

\sigma_{2}=0
, the first term in (
B.9
) vanishes;
the same displayed bound remains valid because
q_{T}=1/2
and
h_{T}=1
.

Step 3: dynamic consensus error.

The pathwise projection estimate already established in the proof of
Theorem
3.6
gives

\|\mathbf{x}_{k+1}-\bar{\mathbf{x}}_{k+1}\|\leq\rho\|\mathbf{x}_{k}-\bar{\mathbf{x}}_{k}\|+\kappa_{M}\alpha\|\mathrm{\bf s}_{k}\|.

(B.10)

Minkowski’s inequality in
L^{2}
, divided by
\sqrt{n}
, yields

\sqrt{\mathsf{X}_{k+1}}\leq\rho\sqrt{\mathsf{X}_{k}}+\kappa_{M}\alpha\sqrt{\mathsf{S}_{k}}.

When
\rho>0
, Young’s inequality with

\zeta_{X}=(1-\rho^{2})/(2\rho^{2})
gives

(1+\zeta_{X})\rho^{2}=q_{X}
and

(1+1/\zeta_{X})\kappa_{M}^{2}=c_{X}
, proving
(
4.8
). When
\rho=0
, direct squaring gives

\mathsf{X}_{k+1}\leq\kappa_{M}^{2}\alpha^{2}\mathsf{S}_{k}
, which is stronger than
(
4.8
) with
q_{X}=1/2
and
c_{X}=\kappa_{M}^{2}
.

Step 4: descent with explicit projection remainders.

We now derive (
4.9
) without hiding the geometric terms.
Define the ambient consensus residual and its tangent projection by

c_{i,k}:=x_{i,k}-\sum_{j=1}^{n}W_{ij}x_{j,k},\qquad\mathrm{grad}\phi_{i}(\mathbf{x}_{k}):=\mathcal{P}_{T_{x_{i,k}}\mathcal{M}}c_{i,k}.

Let
\mathbf{c}_{k}
denote the stack of the
c_{i,k}
. Then

\sum_{i}c_{i,k}=0
and

\|\mathbf{c}_{k}\|=\|((I-W)\otimes I_{d})\mathbf{x}_{k}\|\leq 2\|\mathbf{x}_{k}-\bar{\mathbf{x}}_{k}\|
. Since the tangent projector is Lipschitz on the
compact submanifold, there is
H_{T}>0
such that

\|\mathcal{P}_{T_{x}\mathcal{M}}-\mathcal{P}_{T_{y}\mathcal{M}}\|_{\rm op}\leq H_{T}\|x-y\|,\qquad x,y\in\mathcal{M}.

(B.11)

Consequently,

\displaystyle\left\|\sum_{i=1}^{n}\mathrm{grad}\phi_{i}(\mathbf{x}_{k})\right\|

\displaystyle=\left\|\sum_{i=1}^{n}(\mathcal{P}_{T_{x_{i,k}}\mathcal{M}}-\mathcal{P}_{T_{\bar{x}_{k}}\mathcal{M}})c_{i,k}\right\|

\displaystyle\leq 2H_{T}\|\mathbf{x}_{k}-\bar{\mathbf{x}}_{k}\|^{2}.

(B.12)

Put
w_{i,k}:=c_{i,k}+\alpha v_{i,k}
. By
(
3.15
) and (
4.1
),

\max_{1\leq i\leq n}\|w_{i,k}\|\leq C_{w}\alpha,\qquad C_{w}:=2\sqrt{nC_{B}}+\sqrt{nD_{B}}.

After reducing
\theta
if necessary, this quantity lies in the uniform
radius of the second-order projection estimate
(
A.6
). Define

r_{i,k}:=x_{i,k+1}-x_{i,k}+\mathrm{grad}\phi_{i}(\mathbf{x}_{k})+\alpha v_{i,k}.

Because
v_{i,k}\in T_{x_{i,k}}\mathcal{M}
,

\|r_{i,k}\|\leq Q\|w_{i,k}\|^{2}.

(B.13)

Writing
\hat{r}_{k}=n^{-1}\sum_{i}r_{i,k}
, using
(
B.12
), (
B.13
), and

\|\mathbf{v}_{k}\|\leq\|\mathrm{\bf s}_{k}\|
, we obtain

\displaystyle\|\hat{x}_{k+1}-\hat{x}_{k}+\alpha\hat{v}_{k}\|

\displaystyle\leq\frac{1}{n}\left\|\sum_{i}\mathrm{grad}\phi_{i}(\mathbf{x}_{k})\right\|+\frac{Q}{n}\sum_{i}\|w_{i,k}\|^{2}

\displaystyle\leq\frac{C_{m}}{n}\|\mathbf{x}_{k}-\bar{\mathbf{x}}_{k}\|^{2}+\frac{2Q\alpha^{2}}{n}\|\mathrm{\bf s}_{k}\|^{2},

(B.14)

where
C_{m}:=2H_{T}+8Q
; here we used

\sum_{i}\|w_{i,k}\|^{2}\leq 8\|\mathbf{x}_{k}-\bar{\mathbf{x}}_{k}\|^{2}+2\alpha^{2}\|\mathrm{\bf s}_{k}\|^{2}
.

Let

\delta_{k}:=\bar{x}_{k+1}-\bar{x}_{k}+\alpha\hat{v}_{k},\qquad\mathcal{C}_{k}:=\|\mathbf{x}_{k}-\bar{\mathbf{x}}_{k}\|^{2}.

The mean-versus-projected-mean estimate (
A.5
) and
(
B.14
) give

\|\delta_{k}\|\leq\frac{M_{2}+C_{m}}{n}\mathcal{C}_{k}+\frac{M_{2}}{n}\mathcal{C}_{k+1}+\frac{2Q\alpha^{2}}{n}\|\mathrm{\bf s}_{k}\|^{2}.

Therefore,

\|\delta_{k}\|^{2}\leq\frac{\Gamma_{1}}{n^{2}}\mathcal{C}_{k}^{2}+\frac{\Gamma_{2}}{n^{2}}\mathcal{C}_{k+1}^{2}+\frac{\Gamma_{3}\alpha^{4}}{n^{2}}\|\mathrm{\bf s}_{k}\|^{4},

(B.15)

where

\Gamma_{1}:=3(M_{2}+C_{m})^{2},\qquad\Gamma_{2}:=3M_{2}^{2},\qquad\Gamma_{3}:=12Q^{2}.

Moreover,

\|\bar{x}_{k+1}-\bar{x}_{k}\|^{2}\leq\frac{2\alpha^{2}}{n}\|\mathrm{\bf s}_{k}\|^{2}+2\|\delta_{k}\|^{2}.

(B.16)

Let
g_{k}:=\mathrm{grad}f(\bar{x}_{k})
and

\mathbf{g}_{k}^{\rm av}:=\mathbf{1}_{n}\otimes g_{k}
. The Riemannian quadratic
upper bound and the identity

-\alpha\langle g_{k},\hat{s}_{k}\rangle=-\frac{\alpha}{2}\|g_{k}\|^{2}-\frac{\alpha}{2n}\|\mathrm{\bf s}_{k}\|^{2}+\frac{\alpha}{2n}\|\mathbf{g}_{k}^{\rm av}-\mathrm{\bf s}_{k}\|^{2}

give

\displaystyle f(\bar{x}_{k+1})\leq{}

\displaystyle f(\bar{x}_{k})-\frac{\alpha}{4}\|g_{k}\|^{2}-\frac{\alpha}{2n}\|\mathrm{\bf s}_{k}\|^{2}+\frac{\alpha}{2n}\|\mathbf{g}_{k}^{\rm av}-\mathrm{\bf s}_{k}\|^{2}

To see this, insert

and

\hat{\mathbf{d}}_{k}=\mathbf{1}_{n}\otimes\hat{d}_{k}

\langle g_{k},s_{i,k}-v_{i,k}\rangle=\langle A_{i,k},s_{i,k}-v_{i,k}\rangle

\frac{\alpha}{n}\sum_{i=1}^{n}\mathbb{E}\langle g_{k},s_{i,k}-v_{i,k}\rangle\leq\frac{\alpha\eta}{2}\mathsf{S}_{k}+\frac{\alpha H_{N}^{2}}{2\eta}\mathsf{X}_{k}.

(B.20)

The factor

Choose
