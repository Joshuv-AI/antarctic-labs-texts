Abstract
We show that the existence of a node x x with attached formula ϕ ⁡ ( x ) \phi(x) in an acyclic graph such that neither ϕ ⁡ ( x ) \phi(x) nor its negation are consistent is equivalent to the existence of subgraph equivalent to Yablo’s construction. Our result is limited to pure conjunctions of the formulas.

1.1.1
A Comment on Logic

The following remarks are, or will be, largely more or less self-evident.

(1)

Yablo’s example is formulated in classical propositional logic, but
admitting
infinite formulas. (Infinite formulas are required.) When we speak about
finite fragments, the logic is classical in all aspects.

(2)

We will see how a graph with valuation defines a (propositional) theory
(see Definition
1.1
(page
1.1
), (3)).
Thus, when we discuss different such graphs, we have
different theories. An important part of the present article discusses
building Yablo-like graphs inductively
(see Section

2
(page

2
) and
Section

3
(page

3
)),
so we discuss
different corresponding theories, and their inductive development,
including
problems in the construction (escape possibilities,
see Definition
1.5
(page
1.5
)).
In particular, we do not only discuss the theory defined by Yablo’s
example.

(3)

We introduce a third truth value,
\xi,
which is only
an abbreviation: given a (classical) theory of a graph, a node
x
has
truth
value
\xi
iff the assumption that
x
is true leads to a (classical)
contradiction,
and so does the assumption that
x
is false. Of course, in finite
classical
propositional logic, this is impossible, but in the infinite version it is
possible, as Yablo has shown (in Yablo’s example, every node has truth
value
\xi).

We show certain qualities of
\xi,
which are directly
derived from the definition (and classical logic).
As pointed out by a referee, the properties of
\xi

are the same as those of
{\cal U}
in Kleene’s strong 3-valued
logic (it is easily shown that this must be so, but for our purposes it is
purely coincidental).
See Remark
1.2
(page
1.2
).

Again, this is just classical logic, with a little shorthand.
(It is almost like abbreviating “TRUE” to “
T
” - it stays the
same
logic.)

(The logical problems are trivial. The problems are combinatorial,
analysing the essential patters in the graphs.)

Basic Definitions and Facts

Definition 1.1

(1)

Background logic

The background logic is classical propositional logic, with perhaps
infinite formulas.

All notions like “contradiction”, “consequence” etc. are
with respect to this logic.

Implications will be written
\Rightarrow,

\Leftrightarrow,
etc., their negations
\not\Rightarrow,
etc.

(2)

Graphs

(2.1)

We consider directed, acyclic graphs, often noted
\Gamma
etc.
They will usually have one root, often called
x_{0}.

(2.2)

Paths will be written
x-y-z
,
\hskip 1.00006ptx\ldots.y\ldots.z
, etc. (read
from left to right).

(2.3)

The nodes will have labels, labels will be unique in a given graph.
For simplicity, we identify labels with the (names of the) nodes.
The labels will be the propositional variables in the (propositional)
language defined by the graph.

(3)

Valuations

(3.1)

We often associate a formula
\phi_{x}
with a node
x,
such that
the variables
contained in
\phi_{x}
are exactly the direct successors of
x
in the
graph.
The meaning is that
x
and
\phi_{x}
are logically equivalent,
x\Leftrightarrow\phi_{x}.

For simplicity, we often write
x=\phi
instead of
\phi_{x}=\phi.

(3.2)

The set of formulas
\phi_{x},

x
a node in
\Gamma
will be
called a valuation of

\Gamma,
or the theory of
\Gamma,

Th(\Gamma),
given such a valuation.
So

is a set of equivalences,
\{x\Leftrightarrow\phi_{x}:

x
a node
in
\Gamma\}.

Of course, usually
\Gamma
will have many different valuations.

(3.3)

Most of the time, valuations in this article will be of the
syntactic form

x\Leftrightarrow\bigwedge\{\neg x_{i}:i\in I\}\cup\bigwedge\{x_{j}:j\in J\}
or
even just
x\Leftrightarrow\bigwedge\{\neg x_{i}:i\in I\}.

In this case, we may write the valuation directly into the graph

\{x\not\rightarrow x_{i}:i\in I\}\cup\{x\rightarrow x_{j}:i\in J\}
or just
\{x\not\rightarrow x_{i}:i\in I\}.
This increases
readability considerably.

(4)

(4.1)

We need infinite depth and width in our constructions:

Fact 1.1

(1)

The construction needs infinite depth,

(2)

the logic as used in Yablo’s construction is not compact,

(3)

the construction needs infinite width, i.e. the logic cannot be
classical.

Proof

(1)

Let
x_{i}
be a minimal element, then we can chose an arbitrary truth
value

x_{i},
and propagate this value upwards. If there are no infinite
descending
chains, we can do this for the whole construction.

(2)

The logic as used in Yablo’s construction is not compact:

Trivial.
(Take
\{\bigvee\{\phi_{i}:i\in\omega\}\}\cup\{\neg\phi_{i}:i\in\omega\}.
This is obviously inconsistent,
but no finite subset is.).

(3)

It is impossible to construct a Yablo-like structure with classical logic:

Take an acyclic graph, and interpret it as in Yablo’s construction.
Wlog., we may assume the graph is connected. Suppose it shows that

x_{0}
cannot be given a truth value. Then the set of formulas showing
this does not have a model, so it is inconsistent. If the formulas were
classical, it would have a finite, inconsistent subset,
\Phi.
Define
the depth
of a formula as the shortest path from
x_{0}
to this formula.
There is a (finite)
n
such that all formulas in
\Phi
have depth
\leq n.

Give all formulas of depth
n
(arbitrary) truth values, and work
upwards using truth functions. As the graph is acyclic, this is possible.
Finally,
x_{0}
has a truth value.

Thus, we need the infinite
\bigwedge/\bigvee.

Consider as always graphs with attached formulas of the type
\bigwedge x_{i},

let the graph be finite.

Fix some node

Suppose we add at

new arrow, say

Then this is a restriction on

and

either a model of
\phi
or of

We underline this, as it

construction by decreasing the set of models of

and of

price of creating one or more new ones, eliminating the new ones, and so

This is what we do, and there is no other way.

The strategy is outlined in

1.3.2
(page

(page

x_{i}\vee(x_{j}\wedge\neg x_{j}\wedge\mbox{\boldmath$F$}).

More generally, if
\phi_{x}
is given for
\Gamma,
and we add some
x\rightarrow x_{j},

j\in J,
to
\Gamma,
then
we consider
\phi_{x}\wedge\bigwedge\{x_{j}\vee\neg x_{j}\vee\mbox{\boldmath$T$}:

j\in J\}.

By its logical neutrality, the addition does not interfere with the
constructions.

The Problem

Given an acyclic directed graph
\Gamma,
does it have a valuation of the
syntactic form
\bigwedge\neg x_{i}
or
\bigwedge\neg x_{i}\wedge(y\vee\neg y\vee\mbox{\boldmath$T$})
such that
there is a node with truth value
\xi?

We first show that, if there is a suitable injection from the Yablo
structure
YS into
\Gamma,
then
\Gamma
has a valuation as above with some
x,

\mid x\mid=\xi,
see
Section
4.1
(page
4.1
).

We then show, if a valuation as above exists for
\Gamma,
such that for
some

x

\mid x\mid=\xi,
then we can reconstruct YS inside
\Gamma,

and thus have again
a suitable injection, see
Section
4.2
(page
4.2
).

We did the main work
in Section

3
(page

3
).
We showed that all constructions with the Yablo Property
(see Definition

1.2
(page

1.2
))
contain the Yablo structure, Yablo has shown that this
structure has the Yablo Property.

So the question is: does a graph contain (a suitable image) of the
Yablo Structure? This is now easy.

4.1
A Suitable Injection From the Yablo Structure Proves One Direction

Consider Yablo’s original structure
\hskip 1.00006ptYS,
and some directed acyclic
graph
\Gamma

without valuation.

Then there is a valuation of
\Gamma
in the extended language as
described
in Remark
4.1
(page
4.1
)
which gives some element
x_{0}
the truth value
\xi

if the following conditions hold.

Condition 4.1

(1)

There is an injection
\mu
from
\hskip 1.00006ptYS
to
\Gamma,
more
precisely from
the nodes and paths of
\hskip 1.00006ptYS
to the nodes and paths of
\Gamma,

s.t.,
if there is a path
\sigma
from
x
to
y
in
\hskip 1.00006ptYS,

then there is a path
\mu(\sigma)
from
\mu(x)
to
\mu(y)
in
\Gamma,

and if
x^{\prime}
is an intermediate node on
\sigma,

\mu(x^{\prime})
will be an
intermediate
node on
\mu(\sigma)
(but
\mu(\sigma)
may have additional
intermediate nodes).

(2)

\mu
preserves
\hskip 1.00006ptpol
on paths:
pol(\sigma)=pol(\mu(\sigma)).

See Definition

1.3
(page

1.3
).

Thus, if
\sigma
contradicts
\sigma^{\prime},
so does
\mu(\sigma)
to
\mu(\sigma^{\prime}).

The second condition expresses “richness”, that we have enough
independent paths.

Example 4.1

Let
\sigma=x_{0}\not\rightarrow x_{1},

\sigma^{\prime}=x_{1}\not\rightarrow x_{2},

\tau=x_{0}\not\rightarrow x_{2},

\mu(\tau)=\mu(x_{0})\not\rightarrow x^{\prime}_{1}\not\rightarrow\mu(x_{2}),
then the
second condition fails for
\tau.

(It would not fail for
\mu(\tau)=\mu(x_{0})\not\rightarrow x^{\prime}_{1}\not\rightarrow x^{\prime\prime}_{1}\not\rightarrow\mu(x_{2}).)

Let
\mu[YS]
be the image of YS in
\Gamma.

Due to the syntactic restriction of the
\phi_{x}
’s,
\mu[YS]
has a
unique valuation,
which is a partial valuation for
\Gamma.

Definition 4.1

We extend this partial valuation in
\mu[YS]
to a total valuation in
\Gamma
as
follows:

(1)

If
x
is a node in
\Gamma-\mu[YS],
set

\phi_{x}

=

\bigwedge\{(y\vee\neg y\vee\mbox{\boldmath$T$}):
there is an arrow
x\rightarrow y
in
\Gamma\}.

(2)

If
x
is a node in
\mu[YS]:

We have already a formula
\phi_{x}^{\prime}
describing the behaviour for all
successors of
x
in
\mu[YS].
We now have to respect the other arrows
in
\Gamma,

and set

\phi_{x}

=

\phi_{x}^{\prime}

\wedge

\bigwedge\{(y\vee\neg y\vee\mbox{\boldmath$T$}):
there is an arrow
x\rightarrow y
in
\Gamma,
and
y

not a successor of
x
in
\mu[YS]

\}.

Fact 4.2

By Condition
4.1
(page
4.1
),
an above injection constructs a Yablo-like structure in
\Gamma,
by
Definition
4.1
(page
4.1
),
we have a full valuation of
\Gamma,
which preserves this structure.

4.2
For the Converse

Fact 4.3

Yablo’s structure is the simplest structure showing that both
x_{0}
and

\neg x_{0}

are contradictory, and contained in all such structures.

Proof

Earlier sections of this paper. More precisely:

(3)

(page

Fact 4.4

Suppose the graph
\Gamma
has a valuation with an element
\mid x_{0}\mid=\xi.

Then, we can reconstruct Yablo’s structure within
\Gamma
(and thus also

an injection as described in
Condition
4.1
(page

Proof

By Fact
4.3
(page
4.3
), or
directly by the construction
Construction
3.1
(page
3.1
)
inside
\Gamma,
we have an analogue of the Yablo structure in

We can eliminate the unnecessary parts as follows, (for ease of reading

Suppose we have
x_{i}=x_{i+1}\wedge x_{i}^{\prime},

Then replace
x_{i}^{\prime}

x_{i}=x_{i+1}\wedge(x_{i}^{\prime}\vee\neg x_{i}^{\prime}\vee\mbox{\boldmath$T$}).

4.1
(page
4.1

(page
