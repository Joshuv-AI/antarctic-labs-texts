Generalization of Variadic Structures with Binders: A Tool for Structural Code Comparison
Alexander Baumgartner, Temur Kutsia

Abstract
This paper introduces a novel anti-unification algorithm for the generalization of variadic structures with binders, designed as a flexible tool for structural code comparison. By combining nominal techniques for handling variable binding with support for variadic expressions (common in abstract syntax trees and programming languages), the approach addresses key challenges such as overemphasis on bound variable names and difficulty handling insertions or deletions in code fragments. The algorithm distinguishes between atoms and two kinds of variables (term and hedge variables) to compute best generalizations that maximally preserve structural similarities while abstracting systematic differences. It also provides detailed information to reconstruct original expressions and quantify structural differences. This information can be useful in tasks like code clone detection, refactoring, and program analysis. By introducing a parametrizable rigidity function, the technique offers fine-grained control over similarity criteria and reduces nondeterminism, enabling flexible adaptation to practical scenarios where trivial similarities should be discounted. Although demonstrated primarily in the context of code similarity detection, this framework is broadly applicable wherever precise comparison of variadic and binder-rich representations is required.

In the context of program analysis, atoms may represent program entities such as local variables or function arguments, while variables serve as meta-variables used to abstract over code fragments.

That is, a combination of variadic and nominal terms, called
variadic nominal terms
, is being considered.
To fully exploit variadicity, we distinguish between two kinds of variables:
individual variables
, which can be substituted by an individual term, and
hedge variables
, which can be substituted by a finite, possibly empty, sequence of terms, referred to as a
hedge

The algorithm computes least general generalizations for such variadic nominal terms: these generalizations are more general than the input expressions, and no strictly more specific generalization exists.

In addition to computing generalizations, the algorithm also captures information about how the original expressions differ and how they can be reconstructed from the generalization. This difference information is particularly useful for applications that aim to quantify the similarity or dissimilarity between structures.

To provide finer control over what is considered meaningful similarity during generalization (and to reduce nondeterminism), the algorithm is parametrized by a special function called the rigidity function. At each level of the term-trees being generalized, this function determines which nodes should be retained in the generalization. By varying the choice of rigidity function, we can obtain generalizations of differing granularity or precision. This flexibility is particularly useful in applications such as code clone detection, where it may be desirable to exclude trivial or insignificant similarities from being classified as clones.

Although our illustrative examples focus on code clone detection, we emphasize that the applicability of the technique developed in this paper extends well beyond this domain. The method provides a flexible and general-purpose framework for characterizing similarities and differences between formal structures with binders and variadic arity. As such, it can be applied in a wide range of contexts, including program analysis, automated refactoring, symbolic reasoning, and even in linguistic or mathematical domains where structural comparison and abstraction over variable binding and variadic constructs are essential.

Variadic Nominal Anti-Unification (
\mathsf{VNAU}
)

The rule-based algorithm
\mathsf{VNAU}
, described in this section, combines techniques from
[
21
]
and
[
20
]
.

The rules operate on states of the form
P;\;\allowbreak S;\;\allowbreak\Gamma;\;\allowbreak\sigma
, where
P
is the problem set,
S
is the store of already solved problems,
\Gamma
represents the freshness context computed so far, and
\sigma
is a substitution that represents the generalization computed so far.
P
and
S
are sets of anti-unification problems (AUPs) of the form
\chi\colon\mathcal{l}\triangleq\mathcal{r}
, where
\chi
is the generalization variable and
\mathcal{l},\mathcal{r}
are hedges or individual terms to be generalized. The notion of being based on a finite set of atoms
A
(i.e.,
A
-based) is naturally extended to AUPs and states, but we won’t mention it, if it’s clear from the context or irrelevant.

Given two
A
-based terms
\mathcal{l}
,
\mathcal{r}
, and an
A
-based freshness context
\nabla
, we create the
initial state

\{X\colon\mathcal{l}\triangleq\mathcal{r}\};\;\allowbreak\emptyset;\;\allowbreak\emptyset;\;\allowbreak id
, where
X
is a hedge variable, that neither occurs in
\mathcal{l},\mathcal{r}
, nor in
\nabla
. Then the state transformation rules defined below are being applied exhaustively, in all possible ways. When no more rule is applicable to a state, then a
final state
has been reached.
A
and
\nabla
are global parameters and unaffected by rule applications.
A variable is said to be
new
if it neither occurs in the current state nor in a global parameter.
\,\mathaccent 0{\cdot}\cup\,
is the disjoint union operation.

Tri-T:

Trivial Term Elimination

\{X\colon a\triangleq a\}\,\mathaccent 0{\cdot}\cup\,P;\;\allowbreak S;\;\allowbreak\Gamma;\;\allowbreak\sigma\Longrightarrow P;\;\allowbreak S;\;\allowbreak\Gamma;\;\allowbreak\sigma\{X\mapsto a\}.

Tri-H:

Trivial Hedge Elimination

\{X\colon\varepsilon\triangleq\varepsilon\}\,\mathaccent 0{\cdot}\cup\,P;\;\allowbreak S;\;\allowbreak\Gamma;\;\allowbreak\sigma\Longrightarrow P;\;\allowbreak S;\;\allowbreak\Gamma;\;\allowbreak\sigma\{X\mapsto\varepsilon\}.

Dec-T:

Term Decomposition

\{X\colon f(\tilde{s})\triangleq f(\tilde{q})\}\,\mathaccent 0{\cdot}\cup\,P;\;\allowbreak S;\;\allowbreak\Gamma;\;\allowbreak\sigma\Longrightarrow\\
\{Y\colon\tilde{s}\triangleq\tilde{q}\}\cup P;\;\allowbreak S;\;\allowbreak\Gamma;\;\allowbreak\sigma\{X\mapsto f(Y)\},
where
Y
is a new hedge variable.

Dec-H:

Hedge Decomposition

\{X\colon\tilde{s}_{1},\tilde{s}_{2}\triangleq\tilde{q}_{1},\tilde{q}_{2}\}\,\mathaccent 0{\cdot}\cup\,P;\;\allowbreak S;\;\allowbreak\Gamma;\;\allowbreak\sigma\Longrightarrow\\
\{Y_{1}\colon\tilde{s}_{1}\triangleq\tilde{q}_{1},\>\allowbreak Y_{2}\colon\tilde{s}_{2}\triangleq\tilde{q}_{2}\}\cup P;\;\allowbreak S;\;\allowbreak\Gamma;\;\allowbreak\sigma\{X\mapsto Y_{1},Y_{2}\},

where
|\tilde{s}_{1},\tilde{q}_{1}|=1
or
|\tilde{s}_{1}|=|\tilde{q}_{1}|=1
. Moreover,
|\tilde{s}_{2},\tilde{q}_{2}|\geq 1
and
Y_{1},Y_{2}
are new hedge variables.

Abs-T:

Term Abstraction

\{X\colon a.t_{1}\triangleq b.t_{2}\}\,\mathaccent 0{\cdot}\cup\,P;\;\allowbreak S;\;\allowbreak\Gamma;\;\allowbreak\sigma\Longrightarrow\\
\{Y\colon(c\>a){\cdot}t_{1}\triangleq(c\>b){\cdot}t_{2}\}\cup P;\;\allowbreak S;\;\allowbreak\Gamma;\;\allowbreak\sigma\{X\mapsto c.Y\},

where
c\in A
,
Y
is a new hedge variable,
\nabla\vdash c\#a.t_{1}
and
\nabla\vdash c\#b.t_{2}
.

Sol-T:

Term Solving

\{X\colon r_{1}\triangleq r_{2}\}\,\mathaccent 0{\cdot}\cup\,P;\;\allowbreak S;\;\allowbreak\Gamma;\;\allowbreak\sigma\Longrightarrow P;\;\allowbreak\{X\colon r_{1}\triangleq r_{2}\}\cup S;\;\allowbreak\{a\#X\mid a\in A,\nabla\vdash a\#r_{1}\,\wedge\,\nabla\vdash a\#r_{2}\}\cup\Gamma;\;\allowbreak\sigma,

where
r_{1}
and
r_{2}
are suspensions or
\mathsf{head}(r_{1})\neq\mathsf{head}(r_{2})
.

Sol-H:

Hedge Solving

\{X\colon\tilde{s}\triangleq\tilde{q}\}\,\mathaccent 0{\cdot}\cup\,P;\;\allowbreak S;\;\allowbreak\Gamma;\;\allowbreak\sigma\Longrightarrow P;\;\allowbreak\{X\colon\tilde{s}\triangleq\tilde{q}\}\cup S;\;\allowbreak\{a\#X\mid a\in A,\nabla\vdash a\#\tilde{s}\,\wedge\,\nabla\vdash a\#\tilde{q}\}\cup\Gamma;\;\allowbreak\sigma,

where
|\tilde{s},\tilde{q}|=1
.

Mer:

Term or Hedge Merging

P;\;\allowbreak\{\chi_{1}\colon\mathcal{l}_{1}\triangleq\mathcal{r}_{1},\chi_{2}\colon\mathcal{l}_{2}\triangleq\mathcal{r}_{2}\}\,\mathaccent 0{\cdot}\cup\,S;\;\allowbreak\Gamma;\;\allowbreak\sigma\Longrightarrow\\
P;\;\allowbreak\{{\chi_{1}:\mathcal{l}_{1}\triangleq\mathcal{r}_{1}}\}\cup S;\;\allowbreak\Gamma\{\chi_{2}\mapsto\pi{\cdot}\chi_{1}\};\;\allowbreak\sigma\{\chi_{2}\mapsto\pi{\cdot}\chi_{1}\},

where
\pi
is an
A
-based permutation such that
\nabla\vdash\pi{\cdot}\mathcal{l}_{1}\approx\mathcal{l}_{2}
and
\nabla\vdash\pi{\cdot}\mathcal{r}_{1}\approx\mathcal{r}_{2}
.

Nar-T:

Term Narrowing

P;\;\allowbreak\{X\colon t_{1}\triangleq t_{2}\}\,\mathaccent 0{\cdot}\cup\,S;\;\allowbreak\Gamma;\;\allowbreak\sigma\Longrightarrow\\
P;\;\allowbreak\{x\colon t_{1}\triangleq t_{2}\}\cup S;\;\allowbreak\Gamma\{X\mapsto x\};\;\allowbreak\sigma\{X\mapsto x\}.

When the transformation process of the initial state
\{X\colon\mathcal{l}\triangleq\penalty\mathcal{r}\};\,\emptyset;\,\emptyset;\,id
of some
A
-based
\mathcal{l}
,
\mathcal{r}
and
\nabla
leads to a final state
P;\,S;\,\Gamma;\,\sigma
, then the computed
A
-based generalization is
\langle\Gamma,\allowbreak X\sigma\rangle
. Moreover,
S
contains all the differences of the input terms
\mathcal{l}
and
\mathcal{r}
. Note that, for every final state
P=\emptyset
. The rule
Mer
involves deciding if an
A
-based permutation
\pi
exists such that
\nabla\vdash\pi{\cdot}\mathcal{l}_{1}\approx\mathcal{l}_{2}
and
\nabla\vdash\pi{\cdot}\mathcal{r}_{1}\approx\mathcal{r}_{2}
. This decision problem is called the equivariance problem. In
[
20
]
an algorithm is given for solving the equivariance problem. It can be trivially adapted to our setting, since there are no variable instantiations involved.

Since decomposing the hedges involves branching, all the produced generalizations are collected. As usual, some of the computed generalizations may not be lggs. However, below
we will prove that the computed set of generalizations is complete.
Minimizing the complete set of generalization can be done subsequently, utilizing a matching algorithm.

Now we illustrate the
\mathsf{VNAU}
algorithm with an example. For the sake of readability, we omit irrelevant assignments in the computed substitution. In particular, only the assignment that corresponds to the generalization variable
X
which is used in the initial state will be illustrated.

Now we address important properties of the algorithm: termination, soundness, and completeness.

The complexity measure
\mu:State\rightarrow(\mathbb{N},\mathbb{N},\mathbb{N},\mathbb{N},\mathbb{N})
, where
State
denotes some state
P;\,S;\,\Gamma;\,\sigma
, is defined component-wise in the following manner:

1.

Sum of all function symbol occurrences and all abstraction occurrences in all the AUPs of
P
.

2.

Sum of the squared problem lengths defined by
\{|\tilde{s},\tilde{q}|^{2}\mid X\colon\tilde{s}\triangleq\tilde{q}\in P\}
.

3.

Number of AUPs in
P
.

4.

Number of AUPs in
S
.

5.

Sum of hedge variable occurrences in all the AUPs of
S
.

Measures are ordered lexicographically. The ordering, denoted by
>
, is well-founded.
By the termination theorem, it directly follows that
\mathsf{VNAU}
terminates on any input.

Theorem 1

(Termination)
.

Let
P;S;\Gamma;\sigma
be an arbitrary state. There are finitely many possible rule applications
P;S;\Gamma;\sigma\overset{\mathsf{Appl}_{i}}{\Longrightarrow}P_{i};S_{i};\Gamma_{i};\sigma_{i},1\leq i\leq n
and
\mu(P;S;\Gamma;\sigma)>\mu(P_{i};S_{i};\Gamma_{i};\sigma_{i})
holds for all
1\leq i\leq n
.

Proof.

Assuming that
P
and
S
are finite, each rule can only be applied in finitely many ways to
P;\;\allowbreak S;\;\allowbreak\Gamma;\;\allowbreak\sigma
. Furthermore, each rule strictly reduces the measure
\mu
.
∎

Lemma 1
.

Given a state
P;\,S;\,\Gamma;\,\sigma
and a freshness context
\nabla
, everything based on a finite set of atoms
A
, such that, for all
\chi\colon\mathcal{l}\triangleq\mathcal{r}\in P\cup S
holds
\langle\Gamma,\allowbreak\chi\sigma\rangle
is an
A
-based generalization of
\langle\nabla,\allowbreak\mathcal{l}\rangle
and
\langle\nabla,\allowbreak\mathcal{r}\rangle
.

If
P;S;\Gamma;\sigma\Longrightarrow P^{\prime};S^{\prime};\Gamma^{\prime};\sigma^{\prime}
is a transformation by a
\mathsf{VNAU}
rule,
then, for all
\chi\colon\mathcal{l}\triangleq\penalty\mathcal{r}\in P\cup S\cup P^{\prime}\cup S^{\prime}
,
\langle\Gamma^{\prime},\allowbreak\chi\sigma^{\prime}\rangle
is an
A
-based generalization of
\langle\nabla,\allowbreak\mathcal{l}\rangle
and
\langle\nabla,\allowbreak\mathcal{r}\rangle
.

The proof of Lemma
1
uses two substitutions that can be obtained from any set
M
of AUPs:

\displaystyle\sigma_{L}(M)::=

\displaystyle\;\{\chi\mapsto\mathcal{l}\mid\chi\colon\mathcal{l}\triangleq\mathcal{r}\in M\}\text{ and }

\displaystyle\sigma_{R}(M)::=

\displaystyle\;\{\chi\mapsto\mathcal{r}\mid\chi\colon\mathcal{l}\triangleq\mathcal{r}\in M\}.

Proof.

Inspecting the rules, it is easy to see that each of them fulfills the invariant.
In particular, given a transformation
P;\,S;\,\Gamma;\,\sigma\Longrightarrow P^{\prime};\,S^{\prime};\,\Gamma^{\prime};\,\sigma^{\prime}
, every rule fulfills:

•

\mathcal{l}\approx\chi\sigma^{\prime}\sigma_{L}(P^{\prime}\cup S^{\prime})
and
\mathcal{r}\approx\chi\sigma^{\prime}\sigma_{R}(P^{\prime}\cup S^{\prime})
hold for all
\chi\colon\mathcal{l}\triangleq\mathcal{r}\in P\cup S
.

The second part, namely that for all
\chi\colon\mathcal{l}\triangleq\mathcal{r}\in P^{\prime}\cup S^{\prime}\text{ holds }\mathcal{l}\approx\chi\sigma^{\prime}\sigma_{L}(P^{\prime}\cup S^{\prime})\text{ and }\mathcal{r}\approx\chi\sigma^{\prime}\sigma_{R}(P^{\prime}\cup S^{\prime})
, is trivial since
\sigma^{\prime}
does not contain assignments for new generalization variables: it simply reduces to
\mathcal{l}\approx\chi\sigma_{L}(P^{\prime}\cup S^{\prime})\text{ and }\mathcal{r}\approx\chi\sigma_{R}(P^{\prime}\cup S^{\prime})
.
∎

The soundness theorem states that
\mathsf{VNAU}
computes
A
-based generalizations of the given
A
-based input terms-in-context.

Theorem 2

(Soundness)
.

Given two hedges or terms
\mathcal{l},\mathcal{r}
and a freshness context
\nabla
,
all based on a finite set of atoms
A
. If

\{X:\mathcal{l}\triangleq\mathcal{r}\};\,\emptyset;\,\emptyset;\,id\overset{+}{\Longrightarrow}\emptyset;\,S;\Gamma;\,\sigma

is a derivation obtained by an execution of
\mathsf{VNAU}
,
then
\langle\Gamma,\allowbreak X\sigma\rangle
is an
A
-based generalization of

\langle\nabla,\allowbreak\mathcal{l}\rangle
and
\langle\nabla,\allowbreak\mathcal{r}\rangle
.

Proof.

Follows from Lemma
1
, by induction on the derivation length.
∎

The completeness theorem states that, given two
A
-based terms-in-context and an arbitrary
A
-based generalization
G
of them,
\mathsf{VNAU}
computes an
A
-based generalization of the given terms-in-context that is less (or equi-) general than
G
.

Theorem 3

(Completeness)
.

Given two hedges or terms
\mathcal{l},\mathcal{r}
and a freshness context
\nabla
,
all based on a finite set of atoms
A
. If
G
is
an
A
-based generalization of
\langle\nabla,\allowbreak\mathcal{l}\rangle
and

\langle\nabla,\allowbreak\mathcal{r}\rangle
, then there exists a derivation

\{X:\mathcal{l}\triangleq\mathcal{r}\};\,\emptyset;\,\emptyset;\,id\overset{+}{\Longrightarrow}\emptyset;\,S;\Gamma;\,\sigma

obtained by an execution of
\mathsf{VNAU}
, such that

G\preceq\langle\Gamma,\allowbreak X\sigma\rangle
.

Proof sketch.

The idea is similar to the completeness proofs from
[
20
,
21
]
and proceeds by induction over the structure of the given generalization.
∎

Remark 1
.

Using binders helps identify similarities modulo bound atom names, which improves the precision of clone detection. However, this can sometimes backfire when the terms to be generalized have different abstraction lengths. For example, compare the generalization
\langle\{a\#x,c\#x,d\#x\},\allowbreak a.b.f(a,x)\rangle
of

of terms

and

(different abstraction lengths). The second one does not provide information about the structural similarity.

Such mismatches can occur when the procedures being compared have different numbers of arguments or local variables. In these cases, if we still wish to generalize the code fragments, we can use an alternative encoding that “frees” the previously bound atoms (or some of them, making the number of abstractions equal). Rigidity functions introduce a flexible mechanism for controlling similarity. For example, one can define a rigidity function that returns longest common subsequences above a specified minimal length, filtering out code fragments that are too short to be considered meaningful clones. The rigidity function can be also made to return singleton sets, making the algorithm deterministic and eliminating branching. Since rigidity functions operate on symbol sequences, they can rely on efficient string-based algorithms for their computation, offering the advantage of combining the speed of string-based techniques with the precision of tree-based methods.

Moreover, rigidity functions make it easy to incorporate approximate, quantitative string-based methods into the computation of similarity. This can significantly enhance the algorithm’s practical applicability, as it allows the detection of identifiers with similar, though not identical, names, which are often overlooked by purely syntactic approaches. The similarity information between such names can be learned using AI techniques, such as embedding-based models, learned edit distances, or character-level neural networks trained on large codebases. This opens the door to hybrid systems that combine symbolic structure-aware reasoning with data-driven name similarity, improving both precision and recall in clone detection.

VI
Allowing Consecutive Individual Variables

Rigid generalizations prohibit adjacent variables, which helps reduce the search space. However, there are cases where allowing variables to appear next to each other does not introduce significant computational overhead and can, in fact, improve the precision of the resulting generalizations. This applies in particular when the hedges abstracted by a hedge variable have exactly the same length. In such cases, the hedge variable can be replaced with a sequence of individual variables, one for each element of the hedge, enabling a more fine-grained generalization.

VII
Future work

Variadic nominal anti-unification considered in this paper works in the first-order setting. A drawback of first-order anti-unification methods is that they overlook similarities between two terms if their heads are different. If one takes a large term
t
and puts it under two different symbols
f
and
g
as
f(t)
and
g(t)
, their generalization will be just some variable
x
and the common part under the head symbols will be ignored. A way to address this problem is to bring higher-order variables in the language. The simplest such extension would be the introduction of function variables that stand only for function symbols. Rigid anti-unification, extended by such variables, can use a modified
Sol-T
rule, which does not immediately send AUPs like
f(t)\triangleq g(t)
to the store, but analyzes the arguments below
f
and
g
. If their similarity is above a predefined threshold (e.g., the alignment computed by rigidity function is “long enough”) , then
f
and
g
are generalized by some function variable and the process continues with their arguments. This is a relatively light-weight extension of variadic nominal generalization, whose formal properties and possible applications in program analysis are left for future work.

VIII
Conclusion

We have presented a framework for variadic nominal anti-unification, designed to detect structural similarity in tree-like expressions, with a particular focus on software code clone detection. Our approach generalizes syntactic structures while preserving the semantics of bound variables, relying on the expressive capabilities of nominal terms and variadic syntax.

We introduced a general anti-unification algorithm and established its termination, soundness, and completeness. To address practical challenges such as computational overhead and limited control over generalization precision, we proposed an extension based on rigidity functions. This refinement enhances efficiency and offers greater flexibility, enabling the algorithm to be tuned for specific applications. In particular, rigidity functions support hybrid approaches that combine the speed of string-based similarity techniques with the structural precision of tree-based methods. Their design also facilitates the integration of approximate and learnable similarity measures, allowing for the incorporation of AI-driven techniques.

The framework further supports extensions that enable fine-grained correspondence by replacing hedge variables with sequences of individual variables when the underlying hedges are of equal length, increasing the precision of generalizations. Additionally, we discussed a potential refinement involving function variables, which would allow the detection of similarities that occur under different function symbols, broadening the algorithm’s applicability to more diverse code patterns.
