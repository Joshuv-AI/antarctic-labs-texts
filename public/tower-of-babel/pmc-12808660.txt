A custom hash algorithm for hosting secure gray scale image repository in public cloud
Authors: Veenasri Murugesan, Nithya Chidambaram, Rengarajan Amirtharajan
Published: 2025

ABSTRACT
AbstractNowadays, Cloud computing is an essential platform for securing resources and effectively managing files. In digital technology, many data leaks or breaches frequently occur during the storage and transmission process. Several techniques for secure image transmission have been developed by researchers worldwide. In the traditional method, data loss prevention (DLP) is the best way to protect sensitive data from breaches. The massive amount of data is not feasible in the existing storage system. However, ensuring data security remains a severe challenge. Cloud infrastructure provides a more robust, reliable, and scalable solution to overcome attacks in developing regions. The primary objective of cloud storage is to provide affordable and easy access to storage, with a vast amount of data stored across multiple cloud storage services. This paper proposed a custom block-based hash algorithm that generates a digital fingerprint from the grayscale-scale image. The pivotal contribution presented in the proposed work lies in emphasising data integrity generation and validation, tamper detection, and accurate identification of the tampered region. The entire 256 × 256 image is considered for tamper-proofing, and the hash values generated are based on the proposed work. In the integrity validation process, it compares the digest with the original digest. The cloud environment provides scalable infrastructure for securely managing and storing the digital fingerprint. User-level authentication is also incorporated into the proposed framework. Additionally, a Graphical User Interface (GUI) application has been developed for generating a hash and verifying whether the image has been tampered with or not, with the tampered region marked by a bounding box. Various benchmark metrics are analysed for validating the outfit of the proposed algorithm. The metrics, including quantitative and qualitative tests for integrity codes, collision property, and avalanche effect, were analysed, and the proposed algorithm exhibits a good ability towards integrity validation.Keywords: Image hashing, Data integrity verification, Tamper detection, Cloud storageSubject terms: Engineering, Mathematics and computing

Introduction

In a modern digital ecosystem, multimedia plays a crucial role across various domains in the development of digital technologies. The advanced research innovation relies on a robust foundation of network and security systems. From a data protection perspective, information security is fundamental for safeguarding data across all resources. In contrast, network security is a component that focuses on protecting data during transmission and preventing unauthorised access over the network1.

The volume of images, videos, text, and other forms shared on social networks and public storage areas is increasing rapidly. During the data transmission over the network, it becomes more vulnerable to interception, modification, and retransmission by attackers. With the rapid growth of emerging technologies, numerous tools and applications are being introduced to drive innovative development. However, malicious applications are also being developed. If data is vulnerable, it can be easily compromised or breached through the network. Visual cryptography conceals sensitive images within standard visual content and divides them into smaller blocks for secure transformation2.

The Cloud environment delivers a framework for storing a collection of raw data, providing access to authorised users. One of the most popular cloud service providers, Amazon, offers storage applications such as Amazon Simple Storage Service (S3) and Amazon Elastic File System (EFS). It provides a scalable and flexible solution, ranging from low to high-level storage, while maintaining the delivery of reliable service to users, including early-stage startups, small and medium-sized enterprises (SMEs), and large organisations. The most common threat to cipher exposure occurs during the transfer, storage, retrieval, and manipulation of sensitive information. To overcome this attack and breach, the cloud interface is the best solution for securely archiving files and digital media3.

All users who need a cloud service must register for the environment. Every time they log in with the username and password, authentication takes place to mitigate unauthorised access. Using credentials, only authorised users are allowed to access all cloud services4. A hybrid cloud-based architecture (HCA) is most popular for enhancing an organisation to optimise security, scalability, and data security. It enables the implementation of advanced features, including computing capacity, data sovereignty, and hybrid cloud deployment. The growing complexity of digital attack points necessitates the development of resilient and sophisticated security solutions that can both restrict unauthorised access and maintain data integrity, confidentiality, and trust across the entire cloud computing ecosystem. Integrity verification takes place using scalable cloud services5. Recent advancements have created a stage for healthcare data to be available at all times and are preferred to be stored in cloud repositories. Again, trustworthy and privacy protection for sensitive data are huge threats. By customising the consensus mechanism and blockchain policy, the vulnerabilities can be addressed6. Related works

A recent scientific report reveals that digital images are largely vulnerable to manipulation by attackers. Ding et al. expressed the High-Resolution Remote Sensing (HRRS) image integrity authentication approach based on a sensitive hashing method. The framework utilises an Attention Gate–based improved M-Net architecture to extract key features from remote sensing images. This method prioritises the protection of semantically relevant features while disregarding less significant or irrelevant regions. Any modification to the critical content is flagged as tampering, whereas unchanged, irrelevant areas are not considered altered12. The integrity of remote sensing images faces challenges due to vulnerabilities in the storage and transmission of hash data. Xu and Dingjie resolved the issue by introducing integrity authentication based on blockchain applications and an advanced perceptual hashing algorithm, utilising the private InterPlanetary File System (IPFS) network and Hyperledger Fabric. Xu and Dingjie suggested that the NSCT-based method is used to detect tiny changes, making them easily and clearly visible in the image13.

Hanif et al. proposed a grayscale image encryption scheme that combines block-level pixel swapping with a chaotic system using the Intertwining Logistic Map (ILM) to generate three chaotic sequences14. These sequences guide pixel scrambling, and an XOR operation with a chaotic key image ensures the diffusion of information. To improve plaintext sensitivity, SHA-256 is integrated into the encryption process. Santos et al., introduced ChaSAM, a forensic system that utilises perceptual hashing algorithms (chHash and domiHash) to identify tampered or illicit content based on visual similarity, achieving high accuracy through parallel hashing. Hamadouche et al. proposed a replay attack detection method using a challenge-response mechanism and perceptual image hashing with DCT, DST, and luminance features15. The hash is embedded using reversible data hiding to improve image security. Another work introduced a reversible fragile watermarking method for medical images based on DWT, DFT, and logistic mapping. The state-of-the-art works exhibit precise tamper detection with high sensitivity and PSNR. In addition, tamper detection and encryption are used in various domains16 and17.

Hussan et al. suggested tamper detection using block-based hashing approach. Fragile watermarking is adopted to embed the hash value for further localisation. Using the DCT, DC coefficients were obtained for the chosen block, and a 16-bit hash value was generated, which was then self-embedded through the Arnold transform. Various security analyses were performed, and this work offers a low false positive rate (FPR: 4.6986)18. With the rapid growth of digital communication and image-sharing platforms, ensuring the integrity and authenticity of digital image content has become essential. While sharing the image, attackers can extract data from it, allowing the data to be leaked or modified during the process19. Introducing data integrity and image authentication is a process that involves verifying the data without altering the original data. By using this approach, the data becomes more secure and trustworthy during storage and transmission. A modified image encryption scheme based on a Skew Tent chaotic map was proposed for secure cloud storage20.

Ayhan et al. proposed a self-embedding fragile watermarking method for image authentication, utilising a Sudoku puzzle–based block structure. The grayscale image is divided into 5 × 5 blocks, and authentication data is generated using the MD5 hash algorithm, incorporating block positions, pixel values, and a secret key. The watermark is embedded into the least significant bits (LSBs) of sub-blocks to enable effective tamper detection. This approach demonstrates that the algorithm effectively detects tampering in images for various types of attacks21.

Kumar et al. proposed a cloud-based buyer–seller watermarking protocol (CB-BSWP) that utilises a semi-trusted intermediary to enhance privacy and protect against digital content piracy. This research work depicts hash-based watermarking influenced by the Diffie-Hellman key exchange mechanism for homomorphic encryption. As a third-party service, the work offers Infrastructure as a Service (IaaS) and Watermarking as a Service (WaaS)22.

Ozkaya and Aslantas experimented with a fragile watermarking process for embedding in grayscale images to detect tampering. It is a block-based self-embedding approach with DWT-based watermarking for tamper detection and recovery of tampered regions, as well as tamper detection and recovery of tampered regions23. Zeng et al., constructed an image encryption algorithm using parameterised pixel ratios in quantum and classical spaces. This method is a hybrid of both quantum walks and classical chaos-based encryption. This approach also claims that the complexity of utilising quantum resources is reduced, in addition to the reduction of resources24. Sharma et al. experimented with tamper-proofing for the secure transmission of satellite images. The region of interest is given high priority, and integrity validation is performed only for the RoI. With 90% accuracy, the suggested work localises the tampered region in the satellite images. To recover the tampered regions, the recovery bits and authentication bits were embedded into the non-interest region. This work exhibited an imperceptibility of nearly 60 dB, which is an indicator of a robust algorithm25. Sahu et al. suggested fragile watermarking with irreversible pixel pairs, which need to be consecutive in nature. Mirrored images are also used for recovering watermarked images. This experiment achieved an image quality of nearly 51 dB PSNR and excellent tamper detection and localisation26. Jagadeesh et al. proposed a semi-fragile watermarking framework that integrates the Slant Transform with DNA encoding to achieve secure tamper detection and self-recovery for medical images. The image is exactly divided into non-overlapping blocks, and Slant Transform coefficients are utilised to produce 8-bit authentication data, which are DNA-encoded and embedded into the LSBs of mapped blocks. During verification, the extracted watermark is decoded and compared with the regenerated data to detect and localise tampered regions, achieving 94.95% detection accuracy with precise localisation and high-quality recovery, demonstrating high robustness for medical image authentication27.

Xia et al. propose a fragile watermarking scheme designed for secure colour image authentication and recovery. This work utilised the feature extraction-based tamper detection and generated three digests through the Set Partitioning In Hierarchical Trees (SPIHT) Averaging (SIAG) approach. The method embeds watermarks using a hybrid approach at both block and pixel levels to preserve high image fidelity. Some geometric attacks and forgery attacks are applied to the image, which allows for the detection of the tampered region and the reconstruction of the modified block using the smoothing inpainting algorithm28.

An authentication approach for colour images was proposed to ensure grayscale preservation essential for medical imaging, by integrating Pixel Pair Matching (PPM) and LSB embedding, along with block classification, to achieve effective watermark insertion while retaining image fidelity. Accurately localises modifications and restores affected areas using embedded recovery codes, utilising demosaicing algorithms, achieving 99.99% detection accuracy for images with 40% tampering29. The framework applies the K-centre Diffie-Hellman (KCDH) algorithm for secure key exchange, and the RSA-based digital signature utilises HMAC-Rijndael encryption with block hashing for the data in the cloud. The cloud data in the form of an airport dataset is considered, which is a 1-dimensional dataset30.

After squeezing the concepts from other state-of-the-art works, it is identified that the hashing is one of the best approach to identify the tampering over an image. When the images are highly protected using cryptographical solutions then robustness of the algorithm defines only noisy image reproduction. For images that need to be shared in the public domain, it’s better to have a tamper-proof validation. The block-based hashing algorithms differ in their hash length for various input block sizes, which also varies the computational complexity. The main objective of the proposed approach is to host a tamper-proof image repository in a public cloud using one another block based hashing approach with reduced computational complexity. Proposed methodology

The proposed method emphasises image tamper detection using a hash-based approach, as shown in Fig. 1. This approach consists of integrity verification using a hash sequence generated for each image. This proposed approach generates a unique digital fingerprint (DF) for the image using 16 identical rounds of a set. Single round operation of the proposed approach illustrated in Fig. 2. Data integrity has been verified by comparing the hash value of the original image and the tampered image. During comparison, if the hash values are the same, it indicates that the data has not been tampered with; otherwise, it reports the tampering area with a bounding box. Moreover, the proposed framework has been interfaced with Amazon Web Services (AWS), one of the popular public cloud service providers. The image is stored as an object, along with its hash value, in AWS buckets. S3 is the best object storage service from AWS, where buckets are created to host images in the public sector.

Avalanche effect

Any hash algorithm needs to satisfy the condition that, even for a bit change in the input, the result changes by 50% or more in the output. This is known as the avalanche effect, a primary key feature of cryptographic hash functions. This test is conducted by finding the Hamming distance between any two hash values. The count of mismatched hash bits out of two different hash values is measured as the Hamming distance. Discussion of results

The proposed hash algorithm generates an image digest for non-overlapping blocks within an image. The Feistel pattern is adopted, for which the round secret keys were obtained using the custom equation developed. A GUI-based framework offers accessibility to people who are not experts in the domain. The proposed hashing algorithm achieves an average execution time of 0.5401 s for tamper detection without tampering. The proposed approach exhibits 0% FPR for a 25% attack. Due to the localisation proposed in this work, the variation of attack % will vary the FPR. However, TDR will be 100% effective for any percentage of attacks. The block-based approach is comparable to other state-of-the-art works, and it minimises the execution time due to the size of the image block, as shown in Table 9. The avalanche effect was also analysed for various types of adversarial scenarios, including tampering, cropping, forgery, filtering, reflection, and noise injection. The proposed hashing algorithm achieved an average value of 50.0323%, which is very close to 50%. The benchmark metric analysis demonstrates the effectiveness of the proposed hashing algorithm for hosting tamper-proof image repositories in public clouds.

Conclusion

In this paper, a tamper detection mechanism is proposed for hosting a secure cloud image repository, where a block-wise image digest is generated to locate the tampered region with greater specificity. The developed GUI, as part of the proposed integrity-driven framework, also made it user-friendly. The hash digest was generated for the images stored in the public Cloud as a synthetic image. With the help of tamper detection ability test metrics, it has been proven that the proposed hash-based image integrity framework is suitable for hosting public image repositories. The effectiveness of the proposed work was evaluated against the various image processing attacks, including image content embedding, elimination, and transformation. If an attack occurs, the existence of tampering is identified by validating the tampered region using an integrity code. The algorithm is well-suited for identifying tampered regions in an image. In the future, there will be a significant stage for public image repositories, where integrity validation is vital. The proposed tamper detection algorithm contained 32 rounds of operations with initial buffers of count 6 and secret key of count 32 and produced 192 bits of hash for the localised block of image. The localisation handled by the proposed algorithm increases the FPR for a particular case. The block-based hash algorithm can be tuned to achieve an unbiased FPR using reinforcement learning methods, thereby optimising localisation for tampering detection over an image. The proposed block-based custom hashing algorithm detects the tampered region but does not address the restoration of the tampered region. The reconstruction of the tampered region is given as the gap to be filled in the future. The proposed algorithm can be used to identify image imitations and offers opportunities for reconstructing the tampered regions of an image by leveraging the principles of machine learning or deep learning.
