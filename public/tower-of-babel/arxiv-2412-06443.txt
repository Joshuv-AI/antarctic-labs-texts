Description of fixed points of an infinite dimensional operator
Olimov Umrbek

Abstract
Аннотация We consider an infinite-dimensional non-linear operator related to a hard core (HC) model with a countable set ℕ \mathbb{N} of spin values. It is known that finding the fixed points of an infinite-dimensional operator is generally impossible. But we have fully analyzed the fixed points of an infinite-dimensional operator by applying a technique of reducing an infinite-dimensional operator to a two-dimensional operator. The set of parameters is divided into subsets A i , j , A_{i,j}, where the index i i means the number of fixed points on the line y = x y=x , j j means the number of fixed points outside of y = x . y=x. The number of fixed points can be up to seven, and the explicit form of each fixed point is found.

1. Introduction

Consider an operator
F
defined on a topological space
X
.

If
F(x)=x
then the point
x\in X
is called a fixed point for
F
.

In this paper we are interested to find fixed points of an infinite-dimensional non-linear operator mapping strictly positive sequences from
l_{1}
to itself.

Denote

l^{1}_{+}=\left\{x=(x_{1},x_{2},\dots,x_{n},\dots)\,:\,x_{i}>0,\,\|x\|=\sum_{j=1}^{\infty}x_{j}<\infty\right\}.

In this paper we study fixed points of the operator
F
defined on
l^{1}_{+}
as follows

F:\begin{array}[]{lll}x^{\prime}_{2n-1}=\lambda_{2n-1}\cdot\left(\dfrac{1+\sum_{j=1}^{\infty}x_{2j-1}}{1+\theta+\|x\|}\right)^{2},\\[5.69054pt]
x^{\prime}_{2n}=\lambda_{2n}\cdot\left(\dfrac{1+\sum_{j=1}^{\infty}x_{2j}}{1+\theta+\|x\|}\right)^{2},\end{array}

(1)

where
n=1,2,\dots
,
\theta>0
and
\lambda=(\lambda_{1},\lambda_{2},\dots)\in l^{1}_{+}
.

Note that these fixed points are very important to study Gibbs measures of a HC-model (see
[
1
]
).

The paper is organized as follows. In Section 2 we reduce our operator to a two-dimensional operator and show that finding fixed points of operator (
1
) is equivalent to finding of such points for the two-dimensional operator. In Section 3 we find some invariant sets and give full description of fixed points, the number of which is up to seven. Namely, we divide the set of parameters to seven subsets, for parameters from each set the number of fixed points is given (up to seven).

2. Restriction to two-dimensional operator

In this section we reduce our problem to a two-dimensional case.

Lemma 1.
If
\lambda=(\lambda_{1},\lambda_{2},\dots)\in l^{1}_{+}
then
F
maps
l^{1}_{+}
to itself.

Proof.

Follows from the straightforward inequalities:
x^{\prime}_{i}<\lambda_{i}
for any
i=1,2,\dots.

Recall definition of dynamical system
[
2
]
:

Let
F:X\rightarrow X
and
\forall x^{(0)}\in X
be given. Then the sequence
x^{(0)},x^{(1)}=F(x^{(0)}),x^{(2)}=F(x^{(1)}),...
is called a dynamical system (DS).

Define two-dimensional operator

W:z=(x,y)\in\mathbb{R}^{2}_{+}\to z^{\prime}=(x^{\prime},y^{\prime})=W(z)\in\mathbb{R}^{2}_{+}
by

W:\ \ \begin{array}[]{ll}x^{\prime}=L_{1}\cdot\left(\dfrac{1+x}{1+\theta+x+y}\right)^{2}\\[5.69054pt]
y^{\prime}=L_{2}\cdot\left(\dfrac{1+y}{1+\theta+x+y}\right)^{2},\end{array}

(2)

where
\theta>0
and
L_{i}>0
are parameters.

Lemma 2.
The infinite dimensional DS generated by the operator
F
is fully represented by the two-dimensional DS generated by the operator
W
.

Proof.

Introduce

M_{1}=\sum_{j=1}^{\infty}x_{2j-1},\ \ M_{2}=\sum_{j=1}^{\infty}x_{2j},

L_{1}=\sum_{j=1}^{\infty}\lambda_{2j-1},\ \ L_{2}=\sum_{j=1}^{\infty}\lambda_{2j}.

Note that
\|x\|=M_{1}+M_{2}
.

Then the operator (
1
) is reduced to

\begin{array}[]{lll}x^{\prime}_{2n-1}=\lambda_{2n-1}\left(\dfrac{1+M_{1}}{1+\theta+\|x\|}\right)^{2},\\[5.69054pt]
x_{2n}^{\prime}=\lambda_{2n}\left(\dfrac{1+M_{2}}{1+\theta+\|x\|}\right)^{2}.\end{array}

(3)

Denoting

M_{1}^{\prime}=\sum_{j=1}^{\infty}x^{\prime}_{2j-1},\ \ M_{2}^{\prime}=\sum_{j=1}^{\infty}x^{\prime}_{2j},

and summing the equalities (
3
) we get

\begin{array}[]{ll}M^{\prime}_{1}=L_{1}\left(\dfrac{1+M_{1}}{1+\theta+M_{1}+M_{2}}\right)^{2}\\[5.69054pt]
M^{\prime}_{2}=L_{2}\left(\dfrac{1+M_{2}}{1+\theta+M_{1}+M_{2}}\right)^{2}.\end{array}

(4)

This is the operator (
2
).
Now it is easy to see that each fixed point
(M_{1},M_{2})
to (
4
), by formula (
3
), uniquely defines a fixed point of operator (
1
).

Moreover, let
x^{(m)}=F^{m}(x^{(0)})
,
m\geq 1
be trajectory of the arbitrary point
x^{(0)}\in l^{1}_{+}
, i.e., coordinates of which satisfy

\begin{array}[]{lll}x^{(m+1)}_{2n-1}=\lambda_{2n-1}\cdot\left(\dfrac{1+\sum_{j=1}^{\infty}x^{(m)}_{2j-1}}{1+\theta+\|x^{(m)}\|}\right)^{2}=\lambda_{2n-1}\cdot\left(\dfrac{1+M_{1}^{(m)}}{1+\theta+M_{1}^{(m)}+M_{2}^{(m)}}\right)^{2},\\[5.69054pt]
x^{(m+1)}_{2n}=\lambda_{2n}\cdot\left(\dfrac{1+\sum_{j=1}^{\infty}x^{(m)}_{2j}}{1+\theta+\|x^{(m)}\|}\right)^{2}=\lambda_{2n}\cdot\left(\dfrac{1+M_{2}^{(m)}}{1+\theta+M_{1}^{(m)}+M_{2}^{(m)}}\right)^{2},\end{array}

(5)

Summing the last equalities we get

\begin{array}[]{ll}M^{(m+1)}_{1}=L_{1}\left(\dfrac{1+M^{(m)}_{1}}{1+\theta+M^{(m)}_{1}+M^{(m)}_{2}}\right)^{2}\\[5.69054pt]
M^{(m+1)}_{2}=L_{2}\left(\dfrac{1+M^{(m)}_{2}}{1+\theta+M^{(m)}_{1}+M^{(m)}_{2}}\right)^{2}.\end{array}

(6)

Using now (
6
) rewrite (
5
) as

\begin{array}[]{lll}x^{(m+1)}_{2n-1}=\lambda_{2n-1}\cdot{M_{1}^{(m+1)}\over L_{1}},\\[5.69054pt]
x^{(m+1)}_{2n}=\lambda_{2n}\cdot{M_{2}^{(m+1)}\over L_{2}}.\end{array}

(7)

Thus if we know behavior of
(M^{(m)}_{1},M^{(m)}_{2})
,
m=0,1,\dots
given by (
6
) then by formula (
7
) we can describe behavior of
x^{(m)}
. For example, if
\lim_{m\to\infty}(M^{(m)}_{1},M^{(m)}_{2})=(a,b)
then

\lim_{m\to\infty}x^{(m)}=\left({a\over L_{1}}\lambda_{1},{b\over L_{2}}\lambda_{2},{a\over L_{1}}\lambda_{3},{b\over L_{2}}\lambda_{4},\dots\right).

(8)

Lemma is proved.
