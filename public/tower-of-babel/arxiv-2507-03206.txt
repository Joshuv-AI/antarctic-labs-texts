Abstract
Weak form Scientific Machine Learning (WSciML) is a recently developed framework for data-driven modeling and scientific discovery. It leverages the weak form of equation error residuals to provide enhanced noise robustness in system identification via convolving model equations with test functions, reformulating the problem to avoid direct differentiation of data. The performance, however, relies on wisely choosing a set of compactly supported test functions. In this work, we mathematically motivate a novel data-driven method for constructing Single-scale-Local reference functions for creating the set of test functions. Our approach numerically approximates the integration error introduced by the quadrature and identifies the support size for which the error is minimal, without requiring access to the model parameter values. Through numerical experiments across various models, noise levels, and temporal resolutions, we demonstrate that the selected supports consistently align with regions of minimal parameter estimation error. We also compare the proposed method against the strategy for constructing Multi-scale-Global (and orthogonal) test functions introduced in our prior work, demonstrating the improved computational efficiency.

Introduction

Weak form Scientific Machine Learning (WSciML) is a recently developed framework for data-driven modeling and scientific discovery. Historically, the weak form of a model equation has been used as a tool to mathematically and computationally study solutions to the equation. Only recently has it been used to solve inverse problems in scientific machine learning.

Towards the goal of improving the performance of WSciML equation learning and parameter estimation, we propose a novel data-driven method for constructing
Single-scale-Local (SL)
test functions. Our approach is based on numerically estimating the integration error introduced by the quadrature. We derive mathematical justifications for criteria to determine, e.g., the support size for which the error is minimal. This is done based entirely on the measured data and without requiring access to the model parameter values. Through numerical experiments across various models, noise levels, and temporal resolutions, we demonstrate that the chosen hyperparameters consistently align with regions of minimal parameter estimation error. We also compare the proposed method against the strategy for constructing
Multi-scale Global (MG)
(and orthogonal) test functions introduced in our prior work, demonstrating the improved computational efficiency.

Historically, two main classes of methods have been used to solve this parameter estimation problem: Output Error (OE) and Equation Error (EE) approaches

OE methods propose a candidate parameter vector, numerically solve the ODE, compare (typically via a least squares loss function) the resulting solution to the observed data, and iteratively update the parameters (and the numerical solution) to reduce the loss. [
30

In contrast, EE methods completely bypass the need for a simulation by substituting noisy observations directly into the model and minimizing the residual of the differential equation. To extend this strategy to a

Remark 8
.

While the procedure constitutes a sweep over all values of radius

Remark 9
.

In practice, only noisy data

is available. Nonetheless, the same procedure can be applied by using

Remark 10
.

The truncation order

should ideally reflect the regularity of the data (see
appendix

H

was sufficient. For an

3.1
Order Selection

In this subsection, we discuss the test function order
p
by analyzing the integration error
\mathbf{e}_{\text{int}}(\phi,u^{\star})
, as defined in (
22
). Here,
\phi(t)
is a translation of the piecewise polynomial reference test function
\psi
introduced in (

). This analysis parallels results established in Lemma 2.3 of
[
24

The integration error due to trapezoidal discretization is

\displaystyle\mathbf{e}_{\text{int}}(\phi,u^{\star})

\displaystyle=\Delta t\sum_{m=0}^{M}{}^{\prime\prime}\phi(t_{m})\dot{u^{\star}}(t_{m})+\dot{\phi}(t_{m})u^{\star}(t_{m})

\displaystyle=\Delta t\sum_{m=0}^{M}{}^{\prime\prime}\frac{d}{dt}\left[\phi u^{\star}\right](t_{m}),

where the notation
\sum{}^{\prime\prime}
indicates that the first and last terms are halved before entering the sum. Applying the Euler–Maclaurin formula (
24
) to
\int_{0}^{T}\frac{d}{dt}\left[\phi u^{\star}\right]dt
yields

\displaystyle\mathbf{e}_{\text{int}}(\phi,u^{\star})=\sum_{s=1}^{\infty}\Delta t^{2s}\frac{B_{2s}}{(2s)!}\sum_{l=0}^{2s}\binom{2s}{l}\left.\left(\phi^{(l)}u^{\star(2k-l)}\right)\right|_{0}^{T}.

Because
\phi_{k}^{(l)}(0)=\phi_{k}^{(l)}(T)=0
for
0\leq l\leq p-1

p
is odd, the leading order integration error scales like
\mathcal{O}(\Delta t^{p+1})
, while for even
p
it scales like
\mathcal{O}(\Delta t^{p})
. In both cases, increasing the order
p
leads to improved accuracy, with errors potentially reaching machine precision for sufficiently high
p

can be selected based on the time step
\Delta t
to control the integration error. In all of the problems we consider, choosing

between
16
and
22
provides sufficiently accurate results. While determining an optimal value of

is outside the scope of this work, our experiments indicate that performance remains stable across a wide range of
p

5
Conclusions

Scientific Machine Learning (SciML) is a framework for blending well-established computational science methodologies with modern machine learning techniques. The recently developed weak form version (WSciML) leverages a weighted integral transform to yield highly robust algorithms. In particular, the Weak form Sparse Identification of Nonlinear Dynamics (WSINDy) for equation learning and Weak form Estimation of Nonlinear dynamics (WENDy) for parameter estimation both exhibit strong robustness. However, how to choose the test function (i.e., the weight function) in a data-driven manner has been an open question for some time. This paper is the first dedicated solely to answering this question.

In this work, we proposed a strategy for selecting the radius of Single-scale-Local (SL) test function set within the WENDy framework, with the goal of optimizing parameter recovery. Central to our approach is
2
, which states that the optimal radius for minimizing expected parameter error aligns with the changepoint in the weak-form integration error. Motivated by this conjecture, we perform a grid search over candidate radii, guided by a surrogate approximation of the weak-form integration error,

\mathbf{G}^{\star}\mathbf{w}^{\star}-\mathbf{b}^{\star}=\mathbf{\Phi}\mathbf{\Theta}(\mathbf{u}^{\star})\mathbf{w}^{\star}+\mathbf{\dot{\Phi}}\mathbf{u}^{\star},

without having access to either the true parameter
\mathbf{w}^{\star}
or noise-free data
\mathbf{u}^{\star}
. This approximation arises from an asymptotic expansion of the error introduced by discretizing the weak-form integrals. Specifically, for the piecewise polynomial test function, we provide detailed guidance on selecting both the radius
r
and the order
p
. Our method consistently identifies regions of low parameter error across a wide range of systems, time resolutions, and regression schemes. Compared to the previous Multi-scale-Global (MG) approach, our method achieves significantly faster runtimes while maintaining comparable or superior accuracy, especially under high-noise regimes.

While
2
is supported empirically, a rigorous mathematical or statistical justification remains open. Proving this conjecture, perhaps in the limit of continuum data, would substantially strengthen the theoretical foundations of our method.

Although our focus has been on radius selection, several important directions remain unexplored. We did not consider optimizing other aspects, such as the overlap between neighboring test functions or the placement of their centers. A rigorous treatment of these factors presents an interesting direction for future work. In addition, our proposed approximated integration error depends on several technical parameters, such as the truncation order in the Euler–Maclaurin expansion, the number of retained Fourier modes, and the finite difference order. While these parameters were selected empirically in this work, a better understanding of their influence, along with strategies for joint optimization, would provide more robust guidelines for our method.

Appendix E
Multiscale Orthonormal Test Functions

In addition to introducing the
C^{\infty}
bump function defined in (
21

[
3
]
outlines a two-stage procedure for constructing matrices of multiscale globally supported orthonormal test functions, which we refer to as the
Multiscale Global (MG)
approach. The first step involves identifying a minimum test function radius

such that the integration error, as defined in (

For a
1

, consider the

-th element of the integration error as defined in (

). Applying the product rule yields

\displaystyle\mathbf{e}_{\text{int}}(\phi_{k},u^{\star})=(\mathbf{G}^{\star}\mathbf{w}^{\star}-\mathbf{b}^{\star})_{k}

\displaystyle=\Delta t\sum_{m=0}^{M-1}\phi_{k}(t_{m})\dot{u}^{\star}(t_{m})+\dot{\phi}_{k}(t_{m})u^{\star}(t_{m})

(25)

\displaystyle=\frac{T}{M}\sum_{m=0}^{M-1}\frac{d}{dt}(\phi_{k}u^{\star})(t_{m}).

Rather than expressing
\phi_{k}
in terms of its Fourier series as shown in

3
, the derivative
\frac{d}{dt}(\phi_{k}u^{\star})(t)
is

\displaystyle\frac{d}{dt}(\phi_{k}u^{\star})(t)

\displaystyle=\frac{1}{\sqrt{T}}\sum_{n\in\mathbb{Z}}\frac{2\pi in}{T}\widehat{(\phi_{k}u^{\star})}_{n}e^{\frac{2\pi int}{T}}.

Substituting this back into (

\displaystyle\mathbf{e}_{\text{int}}(\phi_{k},u^{\star},M)

\displaystyle=\frac{T}{M\sqrt{T}}\sum_{n\in\mathbb{Z}}\frac{2\pi in}{T}\widehat{(\phi_{k}u^{\star})}_{n}\sum_{m=0}^{M-1}e^{\frac{2\pi int_{m}}{T}}

\displaystyle=\frac{2\pi i}{\sqrt{T}}\sum_{n\in\mathbb{Z}}n\widehat{(\phi_{k}u^{\star})}_{nM}.

This shows that the integration error depends solely on the

Fourier modes of

To estimate the integration error from discrete data, a subsampled grid is introduced, with spacing

\widehat{\mathbf{e}}_{\text{int}}(u^{\star},\phi_{k},\lfloor M/s\rfloor,s):=\frac{2\pi i}{\sqrt{T}}\sum_{n=-{\lfloor{s/2}\rfloor}}^{{\lfloor{s/2}\rfloor}}n\widehat{(\phi_{k}u^{\star})}_{n\lfloor M/s\rfloor}.

Since the Fourier coefficients decay as

\widehat{\mathbf{e}}_{\text{int}}(u^{\star},\phi_{k},\lfloor M/s\rfloor,s)\approx\mathbf{e}_{\text{int}}(\phi_{k},u^{\star},\lfloor M/s\rfloor).

For coarsening factors between 2 and 4, the sum above reduces to just the

\displaystyle\widehat{\mathbf{e}}_{\text{int}}(u^{\star},\phi_{k},\lfloor M/s\rfloor,s)

\displaystyle=\frac{2\pi i}{\sqrt{T}}\big(-\widehat{(\phi_{k}u^{\star})}_{-\lfloor M/s\rfloor}+\widehat{(\phi_{k}u^{\star})}_{\lfloor M/s\rfloor}\big)

\displaystyle=-\frac{4\pi}{\sqrt{T}}\text{Im}\{\widehat{(\phi_{k}u^{\star})}_{\lfloor M/s\rfloor}\},

. For each radius in

\mathbf{r}
, we build the corresponding test function matrices and vertically stack them:

\mathbf{\Phi}_{full}:=\begin{bmatrix}\mathbf{\Phi}_{0}^{T}&\mathbf{\Phi}_{1}^{T}&\mathbf{\Phi}_{2}^{T}&\mathbf{\Phi}_{3}^{T}\end{bmatrix}^{T},\quad\mathbf{\dot{\Phi}}_{full}:=\begin{bmatrix}\mathbf{\dot{\Phi}}_{0}^{T}&\mathbf{\dot{\Phi}}_{1}^{T}&\mathbf{\dot{\Phi}}_{2}^{T}&\mathbf{\dot{\Phi}}_{3}^{T}\end{bmatrix}^{T}.

Applying singular value decomposition to
\mathbf{\Phi}_{full}
yields

\mathbf{\Phi}_{full}=\mathbf{Q}\mathbf{\Sigma}\mathbf{V}^{T}.

Letting
k
denote the truncation index (e.g., the SVD “corner”), the final orthonormal test function matrices are computed by rescaling the projection onto the top
k
left singular vectors

\displaystyle\mathbf{\Phi}=\text{diag}\Big(\frac{1}{\sigma_{1}},\dots,\frac{1}{\sigma_{k}}\Big)\mathbf{Q}^{T}\mathbf{\Phi}_{full},\quad\mathbf{\dot{\Phi}}=\text{diag}\Big(\frac{1}{\sigma_{1}},\dots,\frac{1}{\sigma_{k}}\Big)\mathbf{Q}^{T}\mathbf{\dot{\Phi}}_{full}.

The resulting matrices form an orthonormal basis of test functions that capture information across multiple scales
[
42
]
. To conclude this section, we summarize the full procedure as the
Multi-scale-global (MG)
approach in
algorithm

3
. A detailed exposition of this method is provided in
[
3
]
.

Algorithm 3

Multiscale Global Approach (MG) (see
appendix

E
)

Input:
Data
\mathbf{U}
, coarsening factor
s

Output:
Test function matrices
\mathbf{\Phi}
,
\mathbf{\dot{\Phi}}

/* Compute minimum radius
r_{\text{min}}
*/

For each candidate radius
r=m\Delta t
, with
m=2,\cdots,\lfloor M/2\rfloor
:

•

Construct a candidate basis of test functions
\{\phi_{k}(r)\}_{k=1}^{K}

•

For each component of the data
\mathbf{U}_{i}
, compute
\widehat{\mathbf{e}}_{\text{int}}^{(i,k)}(r)
using:

\widehat{\mathbf{e}}_{\text{int}}^{(i,k)}(r):=-\frac{4\pi}{\sqrt{T}}\,\mathrm{Im}\left\{\widehat{(\phi_{k}(r)\mathbf{U}_{i})}_{\lfloor M/s\rfloor}\right\}.

•

Compute the root mean square of
\widehat{\mathbf{e}}_{\text{int}}^{(i,k)}(r)
across all variables and test functions:

\widehat{\mathbf{e}}_{\text{rms}}(r):=\sqrt{\frac{1}{K}\sum_{i=1}^{d}\sum_{k=1}^{K}\left(\widehat{\mathbf{e}}_{\text{int}}^{(i,k)}(r)\right)^{2}}.

Identify
r_{\text{min}}:=\text{changepoint}\left(\log(\widehat{\mathbf{e}}_{\text{rms}}(r))\right)
using
algorithm

2
.

/* Compute Multiscale Global Basis */

Construct test function matrices:

\mathbf{\Phi}_{\text{full}}:=\begin{bmatrix}\mathbf{\Phi}^{T}(r_{\text{min}})&\mathbf{\Phi}^{T}(2r_{\text{min}})&\mathbf{\Phi}^{T}(4r_{\text{min}})&\mathbf{\Phi}^{T}(8r_{\text{min}})\end{bmatrix}^{T},

\mathbf{\dot{\Phi}}_{\text{full}}:=\begin{bmatrix}\mathbf{\dot{\Phi}}^{T}(r_{\text{min}})&\mathbf{\dot{\Phi}}^{T}(2r_{\text{min}})&\mathbf{\dot{\Phi}}^{T}(4r_{\text{min}})&\mathbf{\dot{\Phi}}^{T}(8r_{\text{min}})\end{bmatrix}^{T}.

Perform SVD:
\mathbf{\Phi}_{\text{full}}=\mathbf{Q}\boldsymbol{\Sigma}\mathbf{V}^{T}
.

Select truncation index
k
, construct:

\mathbf{P}:=\text{diag}\left(\sigma_{1}^{-1},\dots,\sigma_{k}^{-1}\right)\mathbf{Q}^{T}
.

Compute
\mathbf{\Phi}:=\mathbf{P}\mathbf{Q}^{T}\mathbf{\Phi}_{\text{full}}\quad\mathbf{\dot{\Phi}}:=\mathbf{P}\mathbf{Q}^{T}\mathbf{\dot{\Phi}}_{\text{full}}

return

\mathbf{\Phi},\mathbf{\dot{\Phi}}
.

Appendix F
Proof of
proposition

4

Proof.

The expansion in
lemma

3
characterizes the integration error for a single test function
\phi
, and thus can be applied to each
\phi_{k}
to produce an expression for each component of the vector
\mathbf{e}_{\text{int}}
. From
definition

1
, we have
\phi_{k}(t)=\psi(t-t_{m_{k}})
, so the Fourier coefficients of
\phi_{k}
satisfy
\widehat{\phi_{k}}_{n}=e^{-\frac{2\pi inm_{k}}{M}}\widehat{\psi}_{n}
. Therefore, the
k
-th component of
\mathbf{e}_{\text{int}}
is

(\mathbf{e}_{\text{int}})_{k}:=\mathbf{e}_{\text{int}}(\phi_{k},u^{\star})=\frac{1}{\sqrt{T}}\sum_{n\in\mathbb{Z}}\widehat{\phi_{k}}_{n}I_{n}=\frac{1}{\sqrt{T}}\sum_{n\in\mathbb{Z}}e^{-\frac{2\pi inm_{k}}{M}}\widehat{\psi}_{n}I_{n}.

We truncate this infinite sum to retain only the
M
Fourier modes in the set of frequencies
\mathbf{n}
defined in (
11
). For a discussion of truncating beyond
M
modes, see
appendix

I
. The resulting approximation of the integration error for
\phi_{k}
is

\mathbf{\widehat{e}}_{\text{int}}(\phi_{k},u^{\star})=\frac{1}{\sqrt{T}}\sum_{n\in\mathbf{n}}e^{-\frac{2\pi inm_{k}}{M}}\widehat{\psi}_{n}I_{n},

Note that the vector
\left(e^{-\frac{2\pi inm_{k}}{M}}\right)_{n\in\mathbf{n}}
corresponds to the
m_{k}
-th row of the DFT matrix
\mathbf{F}
.

The approximation of each integral
I_{n}
is computed by truncating the Euler– Maclaurin expansion from
lemma

3
, with truncation order
S
and finite difference order
\boldsymbol{\mu}
:

I_{n}(u^{\star},S,\boldsymbol{\mu}):=u^{\star}|_{0}^{T}+\sum_{s=1}^{S}\Delta t^{2s}\frac{B_{2s}}{(2s)!}\left(\sum_{l=0}^{2s}\binom{2s}{l}\left(\frac{2\pi in}{T}\right)^{2s-l}\mathcal{D}^{l}_{\mu_{l}}[u^{\star}]|_{0}^{T}\right).

Concatenating these approximations over all
n\in\mathbf{n}
gives the vector
\mathbf{I}(u^{\star},S,\boldsymbol{\mu})
. Finally, stacking
\mathbf{\widehat{e}}_{\text{int}}(\phi_{k},u^{\star})

Appendix G
Proof of
proposition

11

Proof.

The reference test function is given by:

\psi(t;r)=\begin{cases}C(r^{2}-t^{2})^{p}\quad&t\in[-r,r]\\
\quad\quad 0\quad&\text{otherwise}\end{cases}

Since
\psi(t;r)
is an even function, its Fourier coefficients satisfies
\widehat{\psi}_{n}=\widehat{\psi}_{-n}
. For the case
n=0
, a simple change of variable
x=\frac{t}{r}
yields

\displaystyle\widehat{\psi}_{0}

\displaystyle=\frac{2C}{\sqrt{T}}\int_{0}^{r}(r^{2}-t^{2})^{p}dt=\frac{2C}{\sqrt{T}}r^{2p+1}\int_{0}^{1}(1-x^{2})^{p}dx

\displaystyle=\frac{2C}{\sqrt{T}}r^{2p+1}\sum_{j=0}^{p}\binom{p}{j}\frac{(-1)^{j}}{2j+1}.

For
n\geq 1
, we have that

\displaystyle\widehat{\psi}_{n}

\displaystyle=\frac{C}{\sqrt{T}}\int_{-r}^{r}(r^{2}-t^{2})^{p}e^{-\frac{2\pi int}{T}}dt

\displaystyle=\frac{C}{\sqrt{T}}\int_{-r}^{r}(r^{2}-t^{2})^{p}cos\bigg(\frac{2\pi nt}{T}\bigg)dt-\frac{iC}{\sqrt{T}}\int_{-r}^{r}(r^{2}-t^{2})^{p}sin\bigg(\frac{2\pi nt}{T}\bigg)dt

\displaystyle=\frac{C}{\sqrt{T}}\sqrt{\pi}\bigg(\frac{rT}{n\pi}\bigg)^{p+\frac{1}{2}}\Gamma(p+1)J_{p+\frac{1}{2}}\bigg(\frac{2\pi nr}{T}\bigg),

because
\psi
is even, which means the integral against the sin term vanishes. The remaining integral involving the cosine term follows from formula 3.771.8 in
[
9
]

\int_{0}^{u}(u^{2}-x^{2})^{\nu-\frac{1}{2}}cos(ax)d=\frac{\sqrt{\pi}}{2}\Big(\frac{2u}{a}\Big)^{\nu}\Gamma\Big(\nu+\frac{1}{2}\Big)J_{\nu}(au),

where
\Gamma
is the Gamma function and
J_{\nu}
is the Bessel function of the first kind.

The normalization
C
is given by
C=\frac{1}{\left\lVert\psi\right\rVert_{2}}
, where

\left\lVert\psi\right\rVert_{2}=r^{2p}\sqrt{2r}\sqrt{\sum_{k=0}^{2p}\binom{2p}{k}\frac{(-1)^{k}}{2k+1}}.

Appendix H
Choosing the truncation order
S

In this section, we provide a general guideline for selecting the truncation order
S
in the asymptotic expansion of
I_{n}
in Eq. (
14
). Ideally, this choice depends on the smoothness of
u
. If such information is available,
S
should be chosen accordingly to match the regularity of
u
.

In the absence of explicit smoothness information, a practical strategy is to incrementally increase
S
until the contribution of the
S
-th term becomes negligible relative to the cumulative contribution up to order
S-1
. Specifically, we select
S
such that the relative difference satisfies

\frac{|I_{n}(S)-I_{n}(S-1)|}{|I_{n}(S-1)|}<\tau,

for some tolerance
\tau
and
S>1
. This translates to

\displaystyle\frac{\bigg|\Delta t^{2S}\frac{B_{2S}}{(2S)!}\Big(\sum_{l=0}^{2S}\binom{2S}{l}\big(\frac{2\pi in}{T}\big)^{2S-l}u^{(l)}\big|_{0}^{T}\Big)\bigg|}{\big|I_{n}(S-1)\big|}<\tau.

In most practical scenarios, it is sufficient to estimate the dominant contributions without computing additional higher-order derivatives. For instance, we may approximate the truncation condition as

\displaystyle\frac{\bigg|\Delta t^{2S}\frac{B_{2S}}{(2S)!}\big(\frac{2\pi in}{T}\big)^{2S}u\big|_{0}^{T}\bigg|}{\big|I_{n}(S-1)\big|}<\tau,

which avoids the need to compute derivatives beyond order
2(S-1)
. In practice, we set the tolerance to
\tau=0.1
, and in all numerical examples presented in this work, a truncation order of
S=1
was found to be sufficient.

Appendix I
Approximation of the integration error with oversampled Fourier modes

According to
lemma

3
, the integration error
\mathbf{e}_{\text{int}}(\phi_{k},u^{\star})
can be expressed as an infinite sum, i.e., a linear combination of the Fourier coefficients of the reference test function
\psi
. The closed-form expression for these coefficients provided in
proposition

11
enables analytical computation of
\widehat{\psi}_{n}
, allowing us to construct a surrogate approximation
\widehat{\mathbf{e}}_{\text{int}}
beyond the usual resolution of
M
modes. Specifically, we extend this estimate to incorporate
\widetilde{M}>M
Fourier modes, as defined in the modified version of (
13
) as

\displaystyle\widehat{\mathbf{e}}_{\text{int}}(u^{\star},r,S,\widetilde{M},\boldsymbol{\mu}):=\mathbf{P}\mathbf{F}\mathbf{\widehat{\Psi}}(r,\widetilde{M})\mathbf{I}(u^{\star},S,\widetilde{M},\boldsymbol{\mu})\in\mathbb{R}^{K}.

(27)

Here,
\mathbf{I}(u^{\star},S,\widetilde{M},\boldsymbol{\mu})\in\mathbb{C}^{\widetilde{M}}
is the approximation of the integrals
I_{n}
(
23
),
defined analogous to (
14
) using
\widetilde{M}
frequency modes (
11
). Similarly, the diagonal matrix

\widehat{\psi}_{n}
up to frequency

\mathbf{P}
