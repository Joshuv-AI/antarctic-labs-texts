Extensions of 𝒦 ​ ℒ \mathcal{KL} and Lyapunov Functions for Discrete-time Dynamical System Peak Analysis
Assalé Adjé

Abstract
In this paper, we extend two classes of functions that are classically involved in asymptotic stability analyses.The purpose of this extension is to study a maximization problem on the reachable values of a discrete-time dynamical system. This particular maximization problem is called a peak computation problem. The problem consists in finding a couple composed of an initial state and a time that maximizes a given function over states. The paper focuses on the time component of the optimal solution, which is an integer as the time is discrete. We apply a method developed in previous papers to compute an upper bound of the greatest index maximizer of a real sequence. This previous method is based on a formula that requires a pair of a strictly increasing and continuous function on [ 0 , 1 ] [0,1] and a convergent geometric sequence that provides an upper bound of the analyzed sequence. This pair is proven to exist. However, in practice, the computation cannot be done in a general setting. In this paper, we developed two alternative methods. The first is based on discontinuous and non-strictly increasing/decreasing 𝒦 ​ ℒ \mathcal{KL} -like functions called 𝒦 ​ ℒ gen \mathcal{KL}_{\rm gen} functions. We prove that the existence of a 𝒦 ​ ℒ gen \mathcal{KL}_{\rm gen} upper bound is equivalent to the existence of a pair of a strictly increasing and continuous function on [ 0 , 1 ] [0,1] and a convergent geometric sequence. The construction of a strictly increasing continuous function from a 𝒦 ​ ℒ gen \mathcal{KL}_{\rm gen} function requires an extension of the famous Sontag’s lemma. Finally, we construct a new type of Lyapunov function that is well designed for our peak computation problem. These functions are called Opt-Lyapunov functions. Opt-Lyapunov functions are suitable as we establish an equivalence theorem between the existence of an Opt-Lyapunov function and that of a pair of a strictly increasing and continuous function on [ 0 , 1 ] [0,1] and a convergent geometric sequence. The construction of an Opt-Lyapunov function from a pair of a strictly increasing and continuous function on [ 0 , 1 ] [0,1] and a convergent geometric sequence is inspired by the Yoshizawa construction of Lyapunov functions.



Keywords
: Discrete-time, Peak Computation Problems, Supremum of real sequences, Lyapunov functions,
\mathcal{KL}
functions.

Introduction

In this paper, we study the problem of
peak
computation for discrete-time dynamical systems in finite-dimensional state spaces. A peak computation problem can be viewed as a particular maximization problem for which the constraint set is the reachable value set of a discrete-time dynamical system. The objective function of this optimization problem is a function of the states. This particular maximization problem can be used to model various situations in engineering, economics, physics, and biology… For example, in population dynamics, for a predator-prey system, one may be interested in the maximal size of each species, even if the system asymptotically oscillates between several equilibria. This problem boils down to maximizing each coordinate of the state variable separately over the system modeling the population dynamics.

Besides its importance in analyzing critical concrete situations, the literature on peak analysis problems in the community of dynamical systems analysis is quite limited. The peak computation problem appears in a discrete-time setting for linear systems, where the objective function is the Euclidean norm
[
APS18
]
. This problem also appears in the analysis of stable linear systems with general quadratic objective functions
[
Adj21
,
Adj25c
]
. A slightly different version of the problem was encountered in
[
AG24
]
. The difference arises from the fact that the state variable is constrained to remain in a given set. The problem was studied in a continuous-time setting and algebraically in a polynomial environment in
[
MHS20
]
. In
[
MHS20
]
, the authors address the problem of verifying safety properties (see e.g.,
[
BYG17
]
for verification problems on discrete-time systems) for dynamical systems and formulate the safety verification problem as a peak computation problem. Safety verification problems aim to prove that the trajectories of a system are contained in a safe set. A safety verification problem can be translated into a peak computation problem when the safe set is a sublevel of sufficiently regular function. In this case, the objective function of the peak computation problem is associated with the sublevel set. A safety analysis from the peak computation point of view was also proposed for switched systems
[
Adj17
]
and for program analysis in
[
AGM15
]
. For the safety analysis of dynamical systems, one can think that a reachability analysis (see e.g.,
[
RKML06
]
and references therein) equivalent to a feasibility analysis in our context is sufficient to prove some properties of the dynamical system. However, maximality in our context is synonymous with criticality. The optimal value in this situation can be viewed as the value which penalizes the most the system with respect to some criteria and
defines the extreme condition in which the system can enter.

In
[
MHS20
]
the authors are interested in computing an upper bound of the peak optimal value for the continuous case. The techniques used are based on sum-of-squares (SOS) and linear matrix inequality (LMI) formulations (the interested reader can consult
[
Las15
]
for those subjects). The same goal motivated the authors of
[
APS18
]
. They limited their study to linear systems and norm objective functions and directly used semidefinite programming (see
[
BTN01
]
for further details on the subject). Reference
[
AG24
]
cannot be fairly compared because of the additional constraint. Moreover, the studied systems are linear or piecewise linear, and the objective functions are linear. The goal of the current paper is to provide the theoretical bases to solve exactly a peak computation problem in a general way. The developments made in this paper can be viewed as a theoretical generalization of works done in
[
Adj21
,
Adj25c
,
Adj25a
]
and a specialization of
[
Adj25b
]
to specific sequences of optimal values arising in peak analysis computations.

In this paper, we propose to study peak computation problems from extensions of classical tools of dynamical systems stability theory (for example,
[
Ela05
, Chap. 4]
for discrete time). This approach is based on a simple observation: the existence of peaks depends on the asymptotic behavior of the system. The importance of stability analysis is time-tested, and stability analysis is a prerequisite for the implementation of numerical methods. Although general stability properties can be difficult to obtain, asymptotic stability properties can be easily presented and understood from
\mathcal{KL}
bounds (e.g.,
[
ATP10
]
or
[
NT04
]
), that is, the norms of the states are globally bounded from above by a
\mathcal{KL}
function. However, proving that a candidate
\mathcal{KL}
function is an upper bound over the norms of the state must be done for all integers, which can be difficult. In contrast, Lyapunov functions are functional certificates for system stability. Some results guarantee the existence of Lyapunov functions: a system is globally asymptotically stable if and only if there exists a Lyapunov function (see, e.g.,
[
Kha02
]
). Being a Lyapunov function is a timeless property that depends only on the dynamics. In a few advantageous situations, Lyapunov functions can be computed using numerical and optimization solvers (see the survey
[
GH15
]
).

Formally, the data of a peak computation problem are decomposed into an autonomous discrete-time dynamical system and an objective function
\varphi
over states. The dynamical system consists of a set of initial conditions
X^{\mathrm{in}}
and the dynamics of the system, that is, a function
T
that maps a state to a new state. The associated peak computation problem aims to maximize
\varphi(T^{k}(x))
under the constraints
x\in X^{\mathrm{in}}
and
k
is a natural integer. An optimal solution of a peak computation problem is then a couple
(x_{\rm opt},k_{\rm opt})
where
x_{\rm opt}\in X^{\mathrm{in}}
and
k_{\rm opt}
is a natural integer. Note that when an integer
k
is fixed, maximizing
\varphi(T^{k}(x))
over
x\in X^{\mathrm{in}}
is a standard maximization problem. The main difficulty of the peak computation problem is to compute an optimal
k_{\rm opt}
, that is, an integer
n
for which the supremum over
x\in X^{\mathrm{in}}
of
\varphi(T^{n}(x))
is the greatest. The optimal value of a peak computation problem can be interpreted as the sequence of the optimal value of standard maximization problems where the integer
k
is fixed. From this interpretation, the integer element
k_{\rm opt}
of an optimal solution becomes an index for which the associated term maximizes the sequence. Therefore, we can apply the method developed in
[
Adj25b
]
. It consists in computing an upper bound of the (greatest) index maximizer of a real sequence that is bounded from above. The computation of this upper bound is based on a formula involving a pair
(h,\beta)
where
h
is a strictly increasing continuous function on
[0,1]
and
\beta
is a scalar belonging to
(0,1)
. The pair
(h,\beta)
is also constrained to form a sequence
(h(\beta^{k}))_{k\in\mathbb{N}}
greater than the sequence of the suprema of
\varphi\circ T^{k}
over
X^{\mathrm{in}}
. To be applicable, the pair
(h,\beta)
has to be
useful
, that is,
h(0)
must be strictly smaller than, at least, a supremum of
\varphi\circ T^{k}
over
X^{\mathrm{in}}
. In
[
Adj25b
]
, we proved that such a pair
(h,\beta)
exists and can be even chosen to be optimal, meaning that the pair permits finding the greatest optimal integer. In practice, this pair is not computable. Therefore, we propose two additional methods for constructing useful pairs. First, we extend the class of
\mathcal{KL}
functions to the class of functions that are possibly discontinuous, unsigned (on the state variable but nonnegative on the time variable), increasing on states, and decreasing on time. We call this class of functions
\mathcal{KL}_{\rm gen}
. As for classical
\mathcal{KL}
functions, we use
\mathcal{KL}_{\rm gen}
functions as upper bounds on
\varphi(T^{k}(x))
(for the classical case with
\mathcal{K}\mathcal{L}
,
\varphi
is a norm). We establish an equivalence theorem, where we prove that a useful pair
(h,\beta)
can be constructed from a
\mathcal{KL}_{\rm gen}
upper bound function, and we can construct
\mathcal{KL}_{\rm gen}
upper bounds from useful pairs
(h,\beta)
. The construction of useful pairs
(h,\beta)
from
\mathcal{KL}_{\rm gen}
upper bound functions relies on an extension of Sontag’s result
[
Son98
, Prop. 7]
for
\mathcal{KL}_{\rm gen}
. Finally, we propose a new concept of Lyapunov functions
adapted for the peaks computation problem, namely, the Opt-Lyapunov functions. The word adapted means that the existence of an Opt-Lyapunov function is equivalent to the existence of a useful pair
(h,\beta)
. Once again, the proofs of all implications are constructive. The construction of an Opt-Lyapunov function from a useful pair
(h,\beta)
is inspired by the Yoshizawa construction of Lyapunov functions
[
Yos66
]
. The main difference between classical Lyapunov functions and this new concept is that we allow Opt-Lyapunov functions to have several zeros and take infinite values. These two new possibilities make the use of classical comparison functions irrelevant (see e.g.,
[
Kel14
]
for a comprehensive survey). In our context, when we have access to classical Lyapunov functions, we can link, when
\varphi
is continuous,
\varphi
with classical Lyapunov functions using comparison functions. Without this link, we must develop a concept of weaker relations between
\varphi
and an Opt-Lyapunov function. In this paper, we introduce the notion of a certificate of compatibility to overcome the loss of links.

In summary, this study makes two main contributions.

•

We generalize the concept of
\mathcal{K}\mathcal{L}
functions to
\mathcal{KL}_{\rm gen}
adapted to peaks computation problems for which we can formulate peaks computation problems as a
\mathcal{KL}_{\rm gen}
upper bounds existence.

•

We introduce a new concept of Lyapunov functions well designed for peaks computation problem for which the comparison functions approach is replaced by a compatibility notion.

The paper is organized as follows. Section
2
presents the peak computation problem addressed in this paper and the main difficulty related to the search for an integer as an optimal solution of the problem. In Section
3
, we introduce an illustrative example to which we apply the novel techniques in the following sections. This example is the simplest version of the Leslie model for studying the dynamics of a population decomposed into age classes. Then, in Section
4
, we introduce the new class
\mathcal{KL}_{\rm gen}
. We prove that the existence of
\mathcal{KL}_{\rm gen}
upper bounds on
\varphi(T^{k}(x))
is equivalent to the existence of a useful pair. In Section
5
, we present the concept of Opt-Lyapunov functions
well-designed for our maximization problem. The classical comparison functions associated with classical Lyapunov functions are replaced by a new notion called compatibility. We also prove that the existence of a compatible Opt-Lyapunov function is equivalent to the existence of a useful pair. In Section
6
, we summarize the results obtained, highlighting the concrete constructions between useful pairs of strictly increasing and continuous functions on
[0,1]
, convergent geometric sequences,
\mathcal{KL}_{\rm gen}
class, and Opt-Lyapunov functions.

2.1
The motivation : a discrete-time peak computation problem

2.1.1
Definition of the problem

Let us consider a discrete-time dynamical system
(X^{\mathrm{in}},T)
on
\mathbb{R}^{d}
where

•

X^{\mathrm{in}}
is the nonempty subset of
\mathbb{R}^{d}
of initial conditions;

•

is a nonzero self-map on
\mathbb{R}^{d}
that updates the state-variable.

The system is autonomous and evolves without control, disturbances, or external inputs. In this paper, we are interested in the reachable values that maximize a given function. Then, given

\begin{array}[]{lcl}\displaystyle{\operatorname*{Max}_{x,k}}&&\displaystyle{\varphi(T^{k}(x))}\\
&\text{ s. t.}&\displaystyle{x\in X^{\mathrm{in}},k\in\mathbb{N}}\end{array}

(DPCP)

where

Like any optimization problem, to solve a problem of the form (

•

its optimal value, i.e.,
\sup\{\varphi(T^{k}(x)):x\in X^{\mathrm{in}},\ k\in\mathbb{N}\}

•

its optimal solutions, i.e., couples

\varphi(T^{\overline{k}}(\overline{x}))=\sup\{\varphi(T^{k}(x)):x\in X^{\mathrm{in}},\ k\in\mathbb{N}\}.

An optimal solution

of Problem (

leading to a peak and its associated date

of peak-realization.

Without loss of generality, we can suppose that
\varphi(0)=0
; otherwise, we change
\varphi
for
\varphi-\varphi(0)
and then we add
\varphi(0)
at the end of the optimization procedure.
This is formulated in Assumption
1

Assumption 1
.

\varphi(0)=0
.

The approach developed in

{\mathrm{R}}_{\nu}^{s}:=\left\{k\in\mathbb{N}:\nu_{k}>\limsup_{n\to+\infty}\nu_{n}\right\}.

Proposition 1

If

One way to compute an element of

3
A running example from Leslie population evolution models

In this paper, we illustrate the new tools that we develop using a running example. This example comes from population ecology and is a model for studying the evolution of a population according to some period. The model studied here is called a
Leslie model
and was introduced in 40s
[
Les45
,
Les48
]
.

3.1
Introduction

Leslie population models analyze the growth of the population of a species structured in age classes. A class represents a stage of development of the species (juvenile, sub-adult, adult, etc.). From this structuration, the population is modeled as a vector of the sizes of the population of each age class. The evolution of the population is computed from a matrix called the
Leslie matrix
. The vector of the population sizes at a given year (or another time step) is the image of the vector of the population sizes of the previous year by the Leslie matrix. The coefficients of the first row are the fertility rates associated with each age class. Hence, those coefficients compute the number of individuals in the first age class that can be generated from each age class. The next rows attribute the survival rates to each age class. This rate aims to compute the number of individuals that pass from the current age class to the next. Hence, the survival rate belongs to
[0,1]
. We also note that this survival rate is the unique nonzero coefficient of the row.

Usually, the questions raised about Leslie population models are about the asymptotic behavior of the population, the maximal growth rates of the population of each class, and the asymptotic proportions of the population of each age class with respect to the total population. The question concerning the proportions can be addressed in a different way: what is the proportion of the juvenile (the first class) with respect to the others? In this paper, we are interested in the maximum proportion.
To illustrate our approach in the simplest way, we consider two age-class Leslie population models. This means that we only consider the juvenile and adult populations, and we are interested in the maximum proportion of juveniles over adults.

3.2

4.1
Revisiting

One of the limitations of using classical

\mathcal{K}\mathcal{L}

Definition 2

(The Class
\mathcal{KL}_{\rm gen}
)
.

A function

if

•

for all

,

•

for all

,
t\mapsto\gamma(s,t)
is decreasing.

Lemma 1
.

Let
f:\mathbb{R}_{+}\to\mathbb{R}
be a decreasing function and let
m\geq\inf_{\mathbb{R}_{+}}f
(
m
can be equal to
-\infty
if
\inf_{\mathbb{R}_{+}}f
is). There exists a function
g:\mathbb{R}_{+}\mapsto\mathbb{R}
that is strictly decreasing and continuous such that:

1.

f\leq g
;

2.

\inf_{\mathbb{R}_{+}}g=m
.

Proof.

If
m\geq f(0)
, the function
x\mapsto g(x)=m+1/(x+1)
satisfies the above properties. Note that this case includes the case where
f
is constant on
\mathbb{R}_{+}
.

Now assume that
f(0)>m\geq\inf_{\mathbb{R}_{+}}f
. We denote for all couple of pairs
\{(x,y),(z,t)\}
where
x,y,z,t\in\mathbb{R}
by
\mathrm{Aff}\{(x,y),(z,t)\}
the unique affine function
\ell:\mathbb{R}\mapsto\mathbb{R}
such that
\ell(x)=y
and
\ell(z)=t
. We define the functions
F_{0}
and
F_{n}
for all

as follows:

F_{0}=f(0)\mathbb{1}_{[0,1]}\text{ and }F_{n}=f(n-1)\mathbb{1}_{\left[n;n+\frac{1}{2}\right]}+\mathrm{Aff}\left\{\left(n+\frac{1}{2};f(n-1)\right);\left(n+1;f(n)\right)\right\}\mathbb{1}_{\left[n+\frac{1}{2};n+1\right]}

Finally, we define, for all
x\in\mathbb{R}_{+}
, the function
F
:

F(x)=\sum_{n\in\mathbb{N}}F_{n}(x)+\dfrac{1}{x+1}\text{ and note that}\sum_{n\in\mathbb{N}}F_{n}(x)=\left\{\begin{array}[]{lr}f(0)&\text{ if }x\in[0,1]\\
f(\lfloor x\rfloor-1)&\text{ if }x\in[\lfloor x\rfloor,\lfloor x\rfloor+1/2]\\
\ell\left(x\right)&\text{ if }x\in(\lfloor x\rfloor+1/2,\lfloor x\rfloor+1)\end{array}\right.

where
\ell=\mathrm{Aff}\left\{\left(\lfloor x\rfloor+1/2;f(\lfloor x\rfloor-1)\right);\left(\lfloor x\rfloor+1;f(\lfloor x\rfloor)\right)\right\}
.

The function
\sum_{n\in\mathbb{N}}F_{n}
is clearly continuous and decreasing (as

does) on
\mathbb{R}_{+}
. The function
\sum_{n\in\mathbb{N}}F_{n}
is not strictly decreasing, but adding

because

is decreasing. As

.
Finally, we have
\inf_{\mathbb{R}_{+}}F=\inf_{\mathbb{R}_{+}}f

n\in\mathbb{N}^{*}
and all

5
Lyapunov type Functions for Discrete-time Systems Maximization

Classically, Lyapunov functions (i.e., satisfying conditions (
12
) and (
13
)) are used as certificates of stability (see
[
Ela05
]
or
[
KP01
]
). They present a constructive approach to prove the stability of a dynamical system through converse Lyapunov theorems, which prove that stability notions are equivalent to the existence of Lyapunov functions
[
Kha02
]
. For some linear, polynomial, or piecewise polynomial systems, Lyapunov functions can be computed from numerical optimization solvers based on linear or semidefinite programming (for example, see
[
GH15
]
and references therein). This numerical opportunity has been exploited for specific peak computation problems. Indeed, in
[
Adj25c
]
quadratic Lyapunov functions were used to solve our problem when the dynamical system is stable and affine and the objective function is quadratic. Next, in
[
Adj25a
]
, we have proved
that more general (local) Lyapunov functions can be used to solve peak computation problems. In these previous works, we applied direct-like Lyapunov theorems. In Lyapunov stability theory, after obtaining direct theorems, we consider converse theorems. The question raised in this case is, which stability notions imply the existence of a Lyapunov function? In our context, the converse theorem relies on the following question: which properties of classical Lyapunov functions can be removed to obtain an equivalence between the existence of a useful pair
(h,\beta)\in\mathbb{\Gamma}(\nu)
and the existence of a weaker version of the Lyapunov function? In this section, we reply to this answer. First, in Subsection
5.1
, we define a more general class of Lyapunov functions called
Opt-Lyapunov
functions. The existence of these functions does not ensure the stability of the system, but only the finiteness of the limit superior of the sequence
\nu
defined in Eq. (
1
). Then, in Subsection
5.2
, we discuss the notion of usefulness and how it constrains the Opt-Lyapunov functions. In the classical case, usefulness constrains the sequence
\nu
to have some positive terms. We replace the functions
\alpha_{1},\alpha_{\varphi}
in (
16
) by a
certificate of compatibility
. Finally, in Subsection
5.3
, we establish an equivalence theorem between the existence of those Opt-Lyapunov functions and the existence of an element
(h,\beta)\in\mathbb{\Gamma}(\nu)
.

5.1

5.1.1
Definitions and Useful Facts

We recall that the

of function

is the set of

such that

the domain of a extended real valued function.

We extend the class of classical Lyapunov functions as follows: An Opt-Lyapunov function is still nonnegative but can be either strictly positive or can have several zeros and can take infinite values. The supremum of an Opt-Lyapunov function on the initial conditions set is non-null but smaller than 1. Opt-Lyapunov functions keep the decrease condition of classical Lyapunov functions.

Definition 4

(Opt-Lyapunov functions)

A function

(X^{\mathrm{in}},T)
if and only if

1.

2.

\overline{V_{X^{\mathrm{in}}}}\in(0,1]
;

3.

V\circ T\leq\lambda V
for some
\lambda\in(0,1)
.

5.1.2
Operator Ratios From Proper Positive Semidefinite Functions

We extend the concept of operator ratios developed in
[
Adj25a
]
(specialized at Eq. (
17
) for Lyapunov functions) for which the arguments are positive semidefinite functions rather than positive definite functions. The arguments can also be functions that take infinite values. Therefore, let us denote by
\mathcal{PSD}
the set of nonzero proper positive semidefinite functions from
\mathbb{R}^{d}
to
[0,+\infty]
, that is,

\mathcal{PSD}:=\{f:\mathbb{R}^{d}\mapsto[0,+\infty]:\exists\,x\in\mathbb{R}^{d},\ f(x)\in\mathbb{R}_{+}^{*}\}

(33)

We can extend the operator ratio function to
\mathcal{PSD}
functions.

Definition 5

(Operator Ratios PSD Based)
.

Let
U:\mathbb{R}^{d}\mapsto\mathbb{R}^{d}
. We associate to
U
the operator ratio function
\overline{N_{U}}:\mathcal{PSD}\mapsto[0,+\infty]
defined as follows:

\mathcal{PSD}\ni P\mapsto\overline{N_{U}}(P):=\sup_{P(x)\in\mathbb{R}_{+}^{*}}\dfrac{P(U(x))}{P(x)}

Recall that
\mathrm{Id}
denotes the identity function
\mathbb{R}^{d}\ni x:\mapsto x
. It is straightforward to see that if
P\in\mathcal{PSD}
,
\overline{N_{\mathrm{Id}}}(P)=1
.

The operator function is well-defined, but the inequality
\overline{N_{U^{k}}}(P)\leq\overline{N_{U}}(P)^{k}
can fail to be true, as shown in Example
5
.

Example 5

(A counterexample to the power commutation)
.

Let us consider the functions
U:x\mapsto-x
and
P:x\mapsto\max\{x,0\}
. We have
\overline{N_{U}}(P)=\sup_{P(x)>0}P(U(x))/P(x)=\sup_{x>0}P(-x)/x=\sup_{x>0}0/x=0
whereas
\overline{N_{U^{2}}}(P)=\sup_{x>0}P(x)/x=\sup_{x>0}x/x=1
. Finally, we have
\overline{N_{U^{2}}}(P)>\overline{N_{U}}(P)^{2}
.

To obtain the inequality
\overline{N_{U^{k}}}(P)\leq\overline{N_{U}}(P)^{k}
, we have to consider a smaller class of operators
P
and we introduce for a self-map
U:\mathbb{R}^{d}\mapsto\mathbb{R}^{d}
, the set
\mathcal{D}\left(U\right)
of operators defined as follows:

\mathcal{D}\left(U\right):=\{P\in\mathcal{PSD}:P(U(x))=0\implies P(U^{2}(x))=0\}

(34)

We remark that
P\in\mathcal{D}\left(U\right)
if and only if
P(U^{2}(x))\in(0,+\infty]\implies P(U(x))\in(0,+\infty]
. Moreover, if
P\in\mathcal{D}\left(U\right)
, this leads to for all
k\geq 1
,
P(U^{k+1}(x))\in(0,+\infty]\implies P(U^{k}(x))\in(0,+\infty]
and we also have if
P(U^{k}(x))\in(0,+\infty]
for some
k\geq 1
then
P(U^{j}(x))\in(0,+\infty]
for all
1\leq j\leq k
.

Example 6

(
P
not in
\mathcal{D}\left(U\right)
)
.

The functions
U
and
P
are the ones defined in Example
5
. Let
x>0
be strictly positive. Then,
P(U(x))=P(-x)=0
. However,
P(U^{2}(x))=P(x)=x>0
. So
P\notin\mathcal{D}\left(U\right)
.

Proposition 5
.

Let
U:\mathbb{R}^{d}\mapsto\mathbb{R}^{d}
and
P\in\mathcal{D}\left(U\right)
. Then, for all
k\in\mathbb{N}^{*}
,
\overline{N_{U^{k}}}(P)\leq\left(\overline{N_{U}}(P)\right)^{k}
and if
\overline{N_{U}}(P)
is finite this inequality holds for

.

Proof.

For
k=0
, the result holds as
\overline{N_{\mathrm{Id}}}(P)=1
and there exists

such that
P(x)>0
. If
\overline{N_{U}}(P)
is finite,
(\overline{N_{U}}(P))^{0}
is defined and equal to 1.

Now let
k\in\mathbb{N}^{*}
. If
\overline{N_{U}}(P)=+\infty
, then the inequality is obviously true. Suppose now that
\overline{N_{U}}(P)<+\infty
. From the defintion of
\overline{N_{U}}(P)
, we have for all
x\in\mathbb{R}^{d}
and all

The following assertions hold:

1.

A Technical Summary

In this paper, we have proposed a general method to solve optimization problems of the form (
DPCP
). More precisely, focusing on the integer component of the optimal solution, it is necessary to compute an index
k\in\mathbb{N}
for which the term of the sequence
\nu
(defined in (
1
)) is maximal. The method is based on a function
\mathfrak{F}_{\nu}
defined in
[
Adj25c
]
and quickly recalled in Eq. (
4
). This function
\mathfrak{F}_{\nu}
requires a pair
(h,\beta)
where
h
is a strictly increasing continuous function on
[0,1]
and
\beta\in(0,1)
such that
\nu_{k}\leq h(\beta^{k})
for all
k\in\mathbb{N}
. A key notion is the
usefulness
of
(h,\beta)
, that is, there exists some
k\in\mathbb{N}
such that
\nu_{k}>h(0)
. Without this condition, an upper bound of the greatest index maximizer of
\nu
cannot be computed from
(h,\beta)
. However, the existence theorem
[
Adj25c
, Th.2]
(partially recalled in Th
1
) is not totally constructive and computing
(h,\beta)\in\mathbb{\Gamma}(\nu)
has to follow an alternative methodology. We propose alternatives based on classical tools from the stability theory of difference equations. In
[
Adj25a
]
, we compute
(h,\beta)\in\mathbb{\Gamma}(\nu)
from classical
\mathcal{K}\mathcal{L}
and Lyapunov functions. However, this approach suffers from a lack of converse theorems. Indeed, some problems of the form (
DPCP
) (such as Problem (

⁢
D
P
C

P
ℓ

)) cannot be solved using these classes of functions.

The inequality
\varphi(T^{k}(x))\leq h(\beta^{k})
for all
x\in X^{\mathrm{in}}
and for all
k\in\mathbb{N}
can be viewed as a kind of
\mathcal{KL}
inequality that appears in asymptotic stability studies. Indeed,
h
is strictly increasing and continuous on
[0,1]
and
\beta\in(0,1)
making the sequence
(h(\beta^{k}))_{k}
strictly decreasing and convergent to

\gamma(u-z)+\alpha_{1}(z)=0
.
Indeed,
V(L^{j}x)\geq\alpha_{1}(\varphi(L^{j}x))
for all
j\in\mathbb{N}
and
x\in X_{\ell}
such that
\varphi(L^{j}x)\geq z-\eta
and
\varphi(x^{*})=z
with either
x^{*}\in X_{\ell}
if
z=\omega_{0}
or
x^{*}\in L(X_{\ell})
if

. From this, we have

\gamma(z-\eta-z)+\alpha_{1}(z)\leq-V(x^{*})+\alpha_{1}(z)\leq-\alpha_{1}(z)+\alpha_{1}(z)=0
. We also have
\gamma(z-z)+\alpha_{1}(z)>0
. Either,
u=z-\eta
or
-\eta\gamma+\alpha_{1}(z)<0
and
u\in(z-\eta,z)
. It follows from the strict positivity of
V_{\ell}
and the strict increase of

that for all

and all

such that
\varphi_{\ell}(L^{k}x)\leq u
,
\alpha_{1}(z)+\gamma(\varphi_{\ell}(L^{k}x)-z)\leq V_{\ell}(L^{k}x)
. We conclude that

\alpha:s\mapsto\left\{\begin{array}[]{lr}\dfrac{C}{M(1+s^{-2})}&\text{ if }s\geq z\\
\gamma(s-z)+\dfrac{C}{M^{2}(1+z^{-2})}&\text{ if }s<z\end{array}\right.

is a
(X_{\ell},L,\varphi_{\ell})
-certificate of compatibility for
V_{\ell}
.
