An exact multiple-time-step variational formulation for the committor and the transition rate
Chatipat Lorpaiboon, Jonathan Weare, Aaron R. Dinner

Abstract
For a transition between two stable states, the committor is the probability that the dynamics leads to one stable state before the other. It can be estimated from trajectory data by minimizing an expression for the transition rate that depends on a lag time. We show that an existing such expression is minimized by the exact committor only when the lag time is a single time step, resulting in a biased estimate in practical applications. We introduce an alternative expression that is minimized by the exact committor at any lag time. Numerical tests on benchmark systems demonstrate that our committor and resulting transition rate estimates are much less sensitive to the choice of lag time. We derive an additional expression for the transition rate, relate the transition rate expression to a variational approach for kinetic statistics based on the mean-squared residual, and discuss further numerical considerations with the aid of a decomposition of the error into dynamic modes.

We consider a discrete-time stationary ergodic Markov process

2.1
Committor

The forward committor
q(x)
is the probability that a system at

The backward committor
\bar{q}(x)
is the probability that a system at

Mathematically, they are defined as

\displaystyle q(x)

\displaystyle=\E[\mathds{1}_{B}(X_{S_{t}})\mid X_{t}=x],

(2)

\displaystyle\bar{q}(x)

\displaystyle=\E[\mathds{1}_{A}(X_{\bar{S}_{t}})\mid X_{t}=x],

(3)

where

\displaystyle S_{t}

\displaystyle=\min\{s\mid s\geq t,X_{s}\notin D\},

(4)

\displaystyle\bar{S}_{t}

\displaystyle=\max\{s\mid s\leq t,X_{s}\notin D\},

(5)

and

\mathds{1}_{C}(x)=\begin{cases}1&\text{if }x\in C,\\
0&\text{otherwise}.\end{cases}

(6)

When the dynamics obey detailed balance, the forward and backward committors are related by
\bar{q}=1-q
.

Committors can be estimated from single-step trajectories by solving the boundary value problems:

\displaystyle q(x)

\displaystyle=\E[q(X_{t+\epsilon})\mid X_{t}=x],

(7)

\displaystyle\bar{q}(x)

\displaystyle=\E[\bar{q}(X_{t-\epsilon})\mid X_{t}=x],

(8)

for

These boundary value problems follow from applying the law of total expectations (at times

We emphasize that (

Definining

\displaystyle q(x)

\displaystyle=\E[q(X_{(t+\tau)\wedge S_{t}})\mid X_{t}=x],

(9)

\displaystyle\bar{q}(x)

\displaystyle=\E[\bar{q}(X_{(t-\tau)\vee\bar{S}_{t}})\mid X_{t}=x],

(10)

with the same boundary conditions as the single time step case.
These boundary value problems follow from applying the law of total expectations (at times
(t+\tau)\wedge S_{t}
and
(t-\tau)\vee\bar{S}_{t}

2
) and (

They are exact for arbitrary

2.2
Transition rate

Denoting the number of transition paths from

This rate is symmetric with respect to

\displaystyle+\mathds{1}_{A}(X_{t\vee\bar{S}_{t^{\prime}}})q(X_{t^{\prime}})(\xi(X_{t^{\prime}})-0)

\displaystyle+\bar{q}(X_{t})\mathds{1}_{B}(X_{t^{\prime}\wedge S_{t}})(1-\xi(X_{t}))

\displaystyle+N_{AB}(X_{[t,t^{\prime}]}),

Expression (

\displaystyle\Phi

\displaystyle=\frac{1}{2\tau}\E[f(X_{[0,\tau]})+f(\bar{X}_{[0,\tau]})]

\displaystyle g(X_{[t,t^{\prime}]},u)=\frac{1}{2}(

\displaystyle+\mathds{1}_{D^{\mathsf{c}}}(X_{t^{\prime}\wedge S_{t}})(\mathds{1}_{B}(X_{t^{\prime}\wedge S_{t}})-u(X_{t}))^{2}

\displaystyle+\mathds{1}_{D^{\mathsf{c}}}(X_{t\vee\bar{S}_{t^{\prime}}})(u(X_{t^{\prime}})-\mathds{1}_{B}(X_{t\vee\bar{S}_{t^{\prime}}}))^{2}

\Phi=\frac{1}{2\epsilon}\E[(q(X_{\epsilon})-q(X_{0}))^{2}].

2.3
Variational loss functions

Expressions (
16
) and (
18
) can be used to optimize the committor and transition rate.
Given a model
u(x)
for the committor, we can define the loss function

\tilde{L}_{\tau}(u)=\frac{1}{\tau}\E[g(X_{[0,\tau]},u)].

(19)

We note that this loss function includes a soft penalty for the boundary conditions:

\displaystyle g(X_{[t,t^{\prime}]},u)

\displaystyle=g(X_{[t,t^{\prime}]},\hat{u})

\displaystyle\mathrel{\phantom{=}}{}+\frac{1}{2}\mathds{1}_{D^{\mathsf{c}}}(X_{t})(u(X_{t})-\mathds{1}_{B}(X_{t}))^{2}

\displaystyle\mathrel{\phantom{=}}{}+\frac{1}{2}\mathds{1}_{D^{\mathsf{c}}}(X_{t^{\prime}})(u(X_{t^{\prime}})-\mathds{1}_{B}(X_{t^{\prime}}))^{2},

(20)

where we have introduced the function
\hat{u}(x)
that is identical to
u(x)
for
x\in D
, but satisfies the boundary condition
\hat{u}(x)=\mathds{1}_{B}(x)
for
x\in D^{\mathsf{c}}
exactly.
The gradient of (
19
) with respect to parameters
\theta
is

\displaystyle\nabla_{\theta}\tilde{L}_{\tau}(u)=\frac{1}{\tau}\E[

\displaystyle\nabla_{\theta}u(X_{0})(u(X_{0})-\hat{u}(X_{\tau\wedge S_{0}}))

\displaystyle+\nabla_{\theta}u(X_{\tau})(u(X_{\tau})-\hat{u}(X_{0\vee\bar{S}_{\tau}}))],

(21)

which is zero when
u=q
by (
9
) and (
10

When
\tau=\epsilon
, (
19

\displaystyle L_{\tau}(u)=\frac{1}{2\tau}\E[

\displaystyle(\hat{u}(X_{\tau})-\hat{u}(X_{0}))^{2}

\displaystyle+\mathds{1}_{D^{\mathsf{c}}}(X_{0})(u(X_{0})-\mathds{1}_{B}(X_{0}))^{2}

\displaystyle+\mathds{1}_{D^{\mathsf{c}}}(X_{\tau})(u(X_{\tau})-\mathds{1}_{B}(X_{\tau}))^{2}].

(22)

The last two terms in the expectation impose a soft penalty for the boundary conditions.
The gradient of (
22
) is

\displaystyle\nabla_{\theta}L_{\tau}(u)=\frac{1}{\tau}\E[

\displaystyle\nabla_{\theta}u(X_{0})(u(X_{0})-(\mathds{1}_{B}(X_{0})+\mathds{1}_{D}(X_{0})\hat{u}(X_{\tau})))

\displaystyle+\nabla_{\theta}u(X_{\tau})(u(X_{\tau})-(\mathds{1}_{B}(X_{\tau})+\mathds{1}_{D}(X_{\tau})\hat{u}(X_{0})))],

(23)

which is zero when
\tau=\epsilon
and

because of (
7
) and (
8
).
We write these expression with
\tau
rather than
\epsilon

\tau>\epsilon
.
However, minimizing (
22

\tau>\epsilon
does not yield
q
in the infinite data limit.

In principle, the boundary condition penalties are not needed—in Ref.
18
, the authors minimized a variational expression that enforced boundary conditions directly on the model output and evaluated the loss only in
D
. However, we found that this approach often leads to non-physical (near) discontinuities close to
A

B

Because the variational expression in Ref.
18
was otherwise the same as (
22
), with
u
represented by a neural network, we follow them and term (

We now explicitly show that these loss functions are variational by analyzing how errors in the committor affect transition rate estimates.
The EVCN loss function (
19
) is minimized when
u=q
and
\tilde{L}_{\tau}(q)=\Phi
for all
\tau

By adding a perturbation
\eta
to
q
, we have

\displaystyle\tilde{L}_{\tau}(q+\eta)=\Phi+\frac{1}{2\tau}\E[

\displaystyle 2\hat{\eta}(X_{0})(q(X_{0})-q(X_{\tau\wedge S_{0}}))

\displaystyle+2\hat{\eta}(X_{\tau})(q(X_{\tau})-q(X_{0\vee\bar{S}_{\tau}}))

\displaystyle+\mathds{1}_{D}(X_{\tau\wedge S_{0}})(\hat{\eta}(X_{\tau})-\hat{\eta}(X_{0}))^{2}

\displaystyle+\mathds{1}_{D^{\mathsf{c}}}(X_{\tau\wedge S_{0}})\hat{\eta}(X_{0})^{2}

\displaystyle+\mathds{1}_{D^{\mathsf{c}}}(X_{0\vee\bar{S}_{\tau}})\hat{\eta}(X_{\tau})^{2}

\displaystyle+\mathds{1}_{D^{\mathsf{c}}}(X_{0})\eta(X_{0})^{2}

\displaystyle+\mathds{1}_{D^{\mathsf{c}}}(X_{\tau})\eta(X_{\tau})^{2}],

(24)

where
\hat{\eta}(x)=\mathds{1}_{D}(x)\eta(x)
.
The first two terms inside the expectation of (
24
) are zero because of (
9
) and (
10
), and the remaining terms are quadratic, so
\tilde{L}_{\tau}(u)\geq\Phi
and (
19
) is variational.
Because (
22
) derives from (
19
), it follows immediately that (
22
) is variational as well when
\tau=\epsilon
. When
\tau>\epsilon
, (
22
) is not variational and can underestimate
\Phi
.

The loss function in (
19
) is also closely related to that of Ref.
17
.
With infinite data, the two differ by a constant (they omit the
N_{AB}
and
N_{BA}
terms) and yield the same gradient.
Their method directly estimates the gradient from finite data using only the first term of (
21
), which is a consistent approximation of the true gradient but is not the gradient of any loss function on finite data (this issue does not arise in the limit of infinite data because both terms then have the same value due to detailed balance).
By symmetrizing the loss with time-reversed trajectories, we directly compute the gradient from a loss function on finite data.
Moreover, our loss is more interpretable, as its minimum is the transition rate and must be used when that quantity is of interest.

2.4
Mean squared error and alternative transition rate expression

To assess the accuracy of the committor in our numerical tests, we evaluate the mean squared error (MSE):

\MSE(u)=\langle u-q,u-q\rangle.

(25)

This is a natural metric for our method because we can rearrange (
24
) and take the limit
\tau\to\infty
to obtain

\lim_{\tau\to\infty}\tau(\tilde{L}_{\tau}(q+\eta)-\Phi)=\MSE(q+\eta).

(26)

This result follows from

\lim_{\tau\to\infty}\mathds{1}_{D}(X_{\tau\wedge S_{0}})=\mathds{1}_{D}(X_{S_{0}})=0
,

\lim_{\tau\to\infty}\mathds{1}_{D^{\mathsf{c}}}(X_{\tau\wedge S_{0}})=\mathds{1}_{D^{\mathsf{c}}}(X_{S_{0}})=1
,

\lim_{\tau\to\infty}\mathds{1}_{D^{\mathsf{c}}}(X_{0\vee\bar{S}_{\tau}})=\lim_{\tau\to\infty}\mathds{1}_{D^{\mathsf{c}}}(X_{\bar{S}_{\tau}})=1
,
and
\hat{\eta}(x)^{2}+\mathds{1}_{D^{\mathsf{c}}}(x)\eta(x)^{2}=\mathds{1}_{D}(x)\eta(x)^{2}+\mathds{1}_{D^{\mathsf{c}}}(x)\eta(x)^{2}=\eta(x)^{2}
.
As noted above, the first two terms inside the expectation of (
24
) are zero because of (
9
) and (
10
).

Because we typically do not have the true committor at each configuration, we must approximate the MSE.
If the dataset consists of long trajectories in equilibrium, we can estimate the MSE using

\displaystyle\MSE(u)

\displaystyle=\E[(u(X_{0})-\E[\mathds{1}_{B}(X_{S_{0}})\mid X_{0}])^{2}]

(27)

\displaystyle=\E[(u(X_{0})-\mathds{1}_{B}(X_{S_{0}}))(u(X_{0})-\mathds{1}_{B}(X_{\bar{S}_{0}}))].

(28)

As discussed in Refs.
15
;
16
, (
27
) cannot be estimated using
X_{S_{0}}
alone because of the double sampling problem (that is,
\E[\E[\mathds{1}_{B}(X_{S_{0}})\mid X_{0}]^{2}]\neq\E[\mathds{1}_{B}(X_{S_{0}})^{2}]
). We resolve this issue by using (
28
), which involves independent samples conditioned on
X_{0}
,

X_{S_{0}}
and
X_{\bar{S}_{0}}
.
The MSE estimated from (
28
) can be negative due to sampling error, which introduces a constant offset.
This is because the quantity in the expectation is not a squared difference but rather a product of two different differences.
Nonetheless, lower MSE values (closer to negative infinity) generally indicate better performance, even when they are negative.

If the dataset consists of many short trajectories, the MSE cannot be estimated using (
28
) because
S_{0}
and
\bar{S}_{0}
are not generally available.
Motivated by (
26
), we define approximations
\tilde{L}_{\tau_{1},\tau_{2}}(u)\approx\Phi
and
\MSE_{\tau_{1},\tau_{2}}(u)\approx\MSE(u)
by solving
\tau_{1}(\tilde{L}_{\tau_{1}}(u)-\tilde{L}_{\tau_{1},\tau_{2}}(u))=\MSE_{\tau_{1},\tau_{2}}(u)
and
\tau_{2}(\tilde{L}_{\tau_{2}}(u)-\tilde{L}_{\tau_{1},\tau_{2}}(u))=\MSE_{\tau_{1},\tau_{2}}(u)
:

\displaystyle\tilde{L}_{\tau_{1},\tau_{2}}(u)

\displaystyle=\frac{\tau_{1}\tilde{L}_{\tau_{1}}(u)-\tau_{2}\tilde{L}_{\tau_{2}}(u)}{\tau_{1}-\tau_{2}},

(29)

\displaystyle\MSE_{\tau_{1},\tau_{2}}(u)

\displaystyle=\frac{\tilde{L}_{\tau_{1}}(u)-\tilde{L}_{\tau_{2}}(u)}{1/\tau_{1}-1/\tau_{2}}.

(30)

In Appendix
C
, we show that
\tilde{L}_{\tau_{1},\tau_{2}}(u)
is an upper bound for
\Phi
and
\MSE_{\tau_{1},\tau_{2}}(u)
is a lower bound for
\MSE(u)
.
We relate
\MSE_{\tau_{1},\tau_{2}}(u)
to the mean squared residual loss function in Ref.
15
in Appendix
D
.

3
Numerical tests

In this section, we describe the neural network architecture and training procedure, introduce the test systems, and then discuss numerical results for the committor and transition rate. Because long trajectories are available for all of the systems, we can compare the results directly to the empirical rate, which we compute from the data as

\Phi_{\text{emp}}=\frac{1}{2T}[N_{AB}(X_{[0,T]})+N_{BA}(X_{[0,T]})],

(31)

where here
T
is the trajectory length.
Similarly, we compute the empirical committor as

q_{\text{emp}}(X_{t})=\frac{1}{2}[\mathds{1}_{B}(X_{S_{t}})+\mathds{1}_{B}(X_{\bar{S}_{t}})].

(32)

3.1
Neural networks

We approximate the committor using a multilayer perceptron with two hidden layers of 100 neurons each and SiLU activation functions, followed by a sigmoid function that constrains outputs to
[0,1]
.
The model is trained on either the VCN loss function (
22
) or the EVCN loss function (
19
).

Training the committor to convergence often requires many optimization steps (over
10^{4}
), especially at short lag times.
In this work, we trained models up to 20000 steps due to computational constraints.
However, training often becomes unstable after many steps: the loss spikes and recovers repeatedly without converging.
To mitigate this behavior, we found it essential to use a large batch size (at least 1000 trajectory segments), the Adam-atan2 optimizer
Everett et al. 2024
, and a small learning rate (
10^{-3}
, which is just below the threshold at which training becomes unstable).

To make metrics on the training and validation datasets comparable, we partition the trajectories into two subsets.
Five models are trained on each subset and validated on the other.
Each full trajectory is segmented into length
\tau
trajectory segments using a sliding window.
At each optimization step, 1000 trajectory segments
X_{[t,t+\tau]}
are uniformly sampled from the training dataset to compute the loss.
Checkpoints are saved after
\{1,2,5,10,20,50,\dots,20000\}
optimization steps, and the checkpoint with the best loss on the validation dataset is selected.
Unless otherwise indicated, metrics are averaged over the 10 models.

As we discuss further in Appendix
E
, overfitting is a major issue for both VCN and EVCN loss functions.
We thus tested a variety of regularization techniques.
Dropout degraded performance and slowed training.
Batch normalization
Ioffe and Szegedy 2015
and layer normalization
Ba et al. 2016
initially sped up training, but the models struggled to capture finer details in the committor.
Standard weight decay
Loshchilov and Hutter 2019
and weight decay toward initial parameters
Kumar et al. 2024
both worsened performance.
As such, we do not employ these methods.

For each residue

3.3
Committor

We examine the behavior of committors predicted using the VCN and EVCN loss functions at different lag times.
We compute committors for individual conformations in the sampled trajectories and then visualize the results in two ways. First, we plot the average committor for structures in a bin defined by a pair of CV values. Second, we partition the predicted committor into 20 uniformly spaced bins over
[0,1]
, and for each bin, we plot the mean empirical committor against the mean predicted committor. In the latter set of plots, which we term “reliability diagrams” in line with the machine learning literature (which also calls them “calibration curves”), each point is from a single model.
Perfect alignment between the predicted and empirical committors corresponds to points lying along the diagonal (shown in black).

We first look at AIB
9
(Fig.
1
).
At the shortest lag time (
1\text{\,}\mathrm{ps}
), CV projections of the predicted committor exhibit a checkered pattern reflecting the boundaries of the intermediate states.
The reliability diagrams show substantial noise, but the means follow the diagonal.
These artifacts arise because the VCN and EVCN losses are both relatively insensitive to slowly decaying modes, encouraging the committor to be flat within intermediate states at the expense of transition states between them.
At the intermediate lag time (
100\text{\,}\mathrm{ps}
), the committor becomes qualitatively accurate for both loss functions.
At the longest lag time (
10\text{\,}\mathrm{ns}
), the committor for EVCN remains accurate, while the committor for VCN appears flattened in the transition region and exhibits large jumps near the boundaries of states
A
and
B
.
These behaviors are reflected in the reliability diagrams.
We can explain this behavior by considering
\E[\hat{u}(X_{0})\hat{u}(X_{\tau})]\approx\E[\hat{u}(X_{0})]\E[\hat{u}(X_{\tau})]
as
\tau\to\infty
.
With this approximation, (
22
) is minimized when
u(x)=\mathds{1}_{B}(x)
for
x\notin D
and
u(x)=\E[\mathds{1}_{B}(X_{0})]/\E[\mathds{1}_{D^{\mathsf{c}}}(X_{0})]
otherwise.

Next, we look at Trp-cage (Fig.
2
).
At the
1\text{\,}\mathrm{ns}
lag time, both loss functions incorrectly predict the committor of the intermediate state above the folded basin in the CV projection to be near zero.
Reflecting this, the reliability diagram has most points above the diagonal, where the empirical committor is greater than the predicted committor.
At the
100\text{\,}\mathrm{ns}
lag time, both methods resolve the intermediate state but the VCN predictions are lower (darker CV projection). Correspondingly, the reliability diagram for VCN has more points above the diagonal. For EVCN, on the other hand, the points are noisy but do not show obvious bias.
With a
10\text{\,}\mathrm{\SIUnitSymbolMicro s}
lag time, VCN breaks down.
The CV projection shows that the predicted committor is flat in
D
, and the reliability diagram shows that all the predicted values (other than 0 in
A
and 1 in
B
) are clustered near a single value.
On the other hand, the CV projection of the EVCN result remains accurate, and the reliability diagram follows the diagonal with less noise than the
100\text{\,}\mathrm{ns}
lag time.

Villin (Fig.
3
) exhibits similar behavior to the previous systems.
For the
1\text{\,}\mathrm{ns}
lag time, both loss functions yield similar, good, predictions.
However, at the
100\text{\,}\mathrm{ns}
lag time, the EVCN prediction shows clear improvement over the VCN prediction, which is already beginning to flatten in the transition region.
In the reliability diagrams, EVCN predictions are near the diagonal, while VCN predictions visibly deviate.
At the
10\text{\,}\mathrm{\SIUnitSymbolMicro s}
lag time, the VCN prediction is again clustered around a single value, while the EVCN prediction remains accurate.

3.4
Transition rate

In Tables
1
,
2
, and
3
, we examine the transition rates predicted by the VCN and EVCN loss functions with various lag times. The loss function and lag time can affect the transition rates through both training the neural network for the committor and application of the rate formula given the trained committor. To distinguish these effects, we evaluate the rates using loss functions and lag times (columns) that are independent of those used to obtain the committors (rows).
Unsurprisingly, more accurate committors yield more accurate transition rates.
Still, even for a given committor (row), the loss function and lag time used to predict the rate (column) noticeably affect the result.
As in the previous section, rates are overestimated at short lag times and approach their correct values as lag times increase. At long lag times, the VCN loss predicts rates that go to zero (approximately proportional to
1/\tau
, as can be seen by substituting a constant committor value for
x\in D
, consistent with the flattening observed above), whereas the EVCN loss predicts rates that plateau near the true value.
The choice of input features has a larger impact at shorter lag times.
Less expressive input features—such as the CVs for AIB
9
and the RMSDs for Trp-cage and villin—tend to produce larger overestimates of the transition rate.

We examine the estimator in (
29
) in Tables
4
,
5
, and
6
.
We observe that using (
29
) with EVCN consistently yields more accurate rate estimates than (
19
) by itself.
Rates predicted using the VCN loss (
22
) or its counterpart with (
29
) are not variational and tend to underestimate the rate at all but the shortest lag times.
For both VCN and EVCN, the choice of the longer of the two lag times in (
29
) appears to matter more than the choice of the shorter of the two lag times.

4
Discussion

In this work, we derived an exact multiple-time-step expression for the transition rate and demonstrated, using models of molecular systems, that a variational scheme based on this expression yields accurate committors and transition rates with relatively little sensitivity to the choice of lag time.
Our approach extends previous methods
Chen et al. 2023
, which are valid only in the limit of a single-time-step lag time and break down at longer lag times.

We suggest several directions for improvement.
For datasets composed of short trajectories, long lag times are inaccessible and so the method may struggle to capture slow modes.
This may be addressed by using loss functions with greater sensitivity to these modes, such as (
29
).
More advanced approaches incorporating memory, such as those proposed for slow modes in Ref.
48
, may further improve accuracy.

Overfitting is also a challenge, and standard regularization techniques are often ineffective.
We expect that integrating over lag times, as in Ref.
49
, may reduce overfitting and improve robustness.
We are exploring regularization strategies that directly restrain the committor to depend on physical or learned CVs in a simple way.

Finally, the variational methods considered in the present study assume detailed balance and equilibrium sampling (or equilibrium reweighting). Theoretical
Cheng and Weare 2024
and empirical
Strahan et al. 2021
;
Strahan et al. 2023
evidence indicates that data distributed according to the equilibrium distribution are not sufficient to accurately learn rare-event statistics. The schemes proposed in Ref.
15
and Ref.
16
allow both non-equilibrium data distributions and irreversible dynamics, and have shown promise on several benchmark problems. However, these schemes have tradeoffs relative to the scheme proposed in this article.
The method proposed in Ref.
15
requires a trajectory dataset with multiple short forward simulations for every initial configuration, and the method proposed in Ref.
16
uses a training procedure that is not the gradient of any loss function when the data are non-equilibrium or the dynamics are irreversible, which can complicate training.
Developing a method that combines the strengths of all of these approaches remains an open problem.

Appendix A
Derivation of the transition rate

In this subsection, we use transition path theory to derive expressions for the transition rate in terms of committors and finite-length trajectories.
In brief, we first define the transition rate (
\Phi
) in terms of the number of transitions within a time interval, then express
\Phi
as an average of changes in a reaction coordinate over single and multiple time steps.

We denote discrete time intervals by
[t,t^{\prime}]=\{t,t+\epsilon,\dots,t^{\prime}\}
. A transition path is a trajectory segment
X_{[s,s^{\prime}]}=(X_{s},X_{s+\epsilon},\dots,X_{s^{\prime}})
with
X_{s}\in A
,
X_{s^{\prime}}\in B
, and
X_{t}\in D
for
s<t<s^{\prime}
.
We define

H_{AB}(X_{[s,s^{\prime}]})=\mathds{1}_{A}(X_{s})\prod_{t\in[s+\epsilon,s-\epsilon]}\mathds{1}_{D}(X_{t})\mathds{1}_{B}(X_{s^{\prime}}),

(35)

which is 1 if
X_{[s,s^{\prime}]}
is a transition path and 0 otherwise.
The number of transition paths from
A
to
B
within the trajectory segment
X_{[t,t^{\prime}]}
is

N_{AB}(X_{[t,t^{\prime}]})=\sum_{s\in[t,t^{\prime}-\epsilon]}\sum_{s^{\prime}\in[s+\epsilon,t^{\prime}]}H_{AB}(X_{[s,s^{\prime}]}),

(36)

and the transition rate
\Phi
is the mean of
N_{AB}
per time:

\Phi=\lim_{T\to\infty}\frac{1}{2T}N_{AB}(X_{[-T,T]}).

(37)

We now express (
37
) in terms of a reaction coordinate
\xi
that satisfies
\xi(x)=0
for
x\in A
and
\xi(x)=1
for
x\in B
.
We start with the identity

H_{AB}(X_{[s,s^{\prime}]})=H_{AB}(X_{[s,s^{\prime}]})\sum_{t\in[s,s^{\prime}-\epsilon]}(\xi(X_{t+\epsilon})-\xi(X_{t})),

(38)

which states that the total change in progress along a transition path is one.
Mathematically, the sum telescopes, and
\xi(X_{s^{\prime}})-\xi(X_{s})=1
for transition paths because
X_{s}\in A
and
X_{s^{\prime}}\in B
.
We substitute this identity into the summand of (
36
) and interchange the sums, yielding

N_{AB}(X_{[t,t^{\prime}]})=\sum_{t^{\prime\prime}\in[t,t^{\prime}-\epsilon]}\sum_{s\in[t,t^{\prime\prime}]}\sum_{s^{\prime}\in[t^{\prime\prime}+\epsilon,t^{\prime}]}H_{AB}(X_{[s,s^{\prime}]})(\xi(X_{t^{\prime\prime}+\epsilon})-\xi(X_{t^{\prime\prime}})).

(39)

We now set
t=-T
and
t^{\prime}=T
and let
T\to\infty
; (
37
) becomes

\Phi=\lim_{T\to\infty}\frac{1}{2T}\sum_{t\in[-T,T-\epsilon]}F_{t,t+\epsilon},

(40)

where
F_{t,t+\epsilon}
is the reaction progress from time
t
to time
t+\epsilon
:

F_{t,t+\epsilon}=\sum_{s\in[-\infty,t]}\sum_{s^{\prime}\in[t+\epsilon,\infty]}H_{AB}(X_{[s,s^{\prime}]})(\xi(X_{t+\epsilon})-\xi(X_{t})).

(41)

The standard transition path theory expression for the transition rate uses single-step trajectories.
In that case, the reaction progress (
41
) can be expressed as

F_{t,t+\epsilon}=\mathds{1}_{A}(X_{\bar{S}_{t}})\mathds{1}_{B}(X_{S_{t+\epsilon}})(\xi(X_{t+\epsilon})-\xi(X_{t})),

(42)

using the identities

\displaystyle\mathds{1}_{A}(X_{\bar{S}_{t}})

\displaystyle=\sum_{s\in[-\infty,t]}\mathds{1}_{A}(X_{s})\prod_{t^{\prime}\in[s+\epsilon,t]}\mathds{1}_{D}(X_{t^{\prime}}),

(43)

\displaystyle\mathds{1}_{B}(X_{S_{t}})

\displaystyle=\sum_{s\in[t,\infty]}\prod_{t^{\prime}\in[t,s-\epsilon]}\mathds{1}_{D}(X_{t^{\prime}})\mathds{1}_{B}(X_{s}).

(44)

Using (
2
) and (
3
), the expectation of (
42
) conditioned on single-step trajectories
X_{[t,t+\epsilon]}=(X_{t},X_{t+\epsilon})
, denoted by
f(X_{[t,t+\epsilon]})
, is

f(X_{[t,t+\epsilon]})=\bar{q}(X_{t})q(X_{t+\epsilon})(\xi(X_{t+\epsilon})-\xi(X_{t})).

(45)

We can then use ergodicity to express (
40
) as

\Phi=\frac{1}{\epsilon}\E[f(X_{[0,\epsilon]})],

(46)

where the expectation is over paths sampled at equilibrium.

In previous work, we proposed and applied a multiple-step expression for the transition rate.
Strahan et al. 2021
;
Antoszewski et al. 2021

There, we applied (
9
) and (
10
) to an average of (
46
):

\displaystyle\Phi

\displaystyle=\frac{1}{\tau}\sum_{t\in[0,\tau-\epsilon]}\E[f(X_{[t,t+\epsilon]})]

(47)

\displaystyle=\frac{1}{\tau}\sum_{t\in[0,\tau-\epsilon]}\E[\bar{q}(X_{0\vee\bar{S}_{t}})q(X_{\tau\wedge S_{t+\epsilon}})(\xi(X_{t+\epsilon})-\xi(X_{t}))].

(48)

In this work, we derive an equivalent expression that depends on committors only at the endpoints.
To this end, we note that the reaction progress from time
t
to time
t^{\prime}
can be written as a sum over single steps:

F_{t,t^{\prime}}=\sum_{t^{\prime\prime}\in[t,t^{\prime}-\epsilon]}F_{t^{\prime\prime},t^{\prime\prime}+\epsilon}.

(49)

We then substitute (
41
) into (
49
), split the sums by whether the transition path starts before time
t
and ends after time
t^{\prime}
, and interchange and telescope the sums. The result is

\displaystyle F_{t,t^{\prime}}

\displaystyle=\sum_{s\in[-\infty,t-\epsilon]}\sum_{s^{\prime}\in[t^{\prime}+\epsilon,\infty]}H_{AB}(X_{[s,s^{\prime}]})(\xi(X_{t^{\prime}})-\xi(X_{t}))

\displaystyle\mathrel{\phantom{=}}{}+\sum_{s\in[t,t^{\prime}]}\sum_{s^{\prime}\in[t^{\prime}+\epsilon,\infty]}H_{AB}(X_{[s,s^{\prime}]})(\xi(X_{t^{\prime}})-0)

\displaystyle\mathrel{\phantom{=}}{}+\sum_{s\in[-\infty,t-\epsilon]}\sum_{s^{\prime}\in[t,t^{\prime}]}H_{AB}(X_{[s,s^{\prime}]})(1-\xi(X_{t}))

\displaystyle\mathrel{\phantom{=}}{}+\sum_{s\in[t,t^{\prime}-\epsilon]}\sum_{s^{\prime}\in[s+\epsilon,t^{\prime}]}H_{AB}(X_{[s,s^{\prime}]})(1-0)

(50)

\displaystyle=\mathds{1}_{A}(X_{\bar{S}_{t}})\mathds{1}_{D}(X_{t^{\prime}\wedge S_{t}})\mathds{1}_{B}(X_{S_{t^{\prime}}})(\xi(X_{t^{\prime}})-\xi(X_{t}))

\displaystyle\mathrel{\phantom{=}}{}+\mathds{1}_{A}(X_{t\vee\bar{S}_{t^{\prime}}})\mathds{1}_{B}(X_{S_{t^{\prime}}})(\xi(X_{t})-0)

\displaystyle\mathrel{\phantom{=}}{}+\mathds{1}_{A}(X_{\bar{S}_{t}})\mathds{1}_{B}(X_{t^{\prime}\wedge S_{t}})(1-\xi(X_{t}))

\displaystyle\mathrel{\phantom{=}}{}+N_{AB}(X_{[t,t^{\prime}]}),

(51)

where we have used (
43
), (
44
), and

\displaystyle\mathds{1}_{A}(X_{t\vee\bar{S}_{t^{\prime}}})

\displaystyle=\sum_{s\in[t,t^{\prime}]}\mathds{1}_{A}(X_{s})\prod_{t^{\prime\prime}\in[s+\epsilon,t^{\prime}]}\mathds{1}_{D}(X_{t^{\prime\prime}}),

(52)

\displaystyle\mathds{1}_{B}(X_{t^{\prime}\wedge S_{t}})

\displaystyle=\sum_{s\in[t,t^{\prime}]}\prod_{t^{\prime\prime}\in[t,s-\epsilon]}\mathds{1}_{D}(X_{t^{\prime\prime}})\mathds{1}_{B}(X_{s}),

(53)

\displaystyle\mathds{1}_{D}(X_{t^{\prime}\wedge S_{t}})

\displaystyle=\mathds{1}_{D}(X_{t\vee\bar{S}_{t^{\prime}}})=\prod_{t^{\prime\prime}\in[t,t^{\prime}]}\mathds{1}_{D}(X_{t^{\prime\prime}}).

(54)

For times within the interval
[t,t^{\prime}]
, these indicator functions identify whether the system last exited
A
before time
t^{\prime}
, first entered
B
after time
t
, or was always in
D
, respectively.
The expectation of
F_{t,t^{\prime}}
conditioned on multiple-step trajectories
X_{[t,t^{\prime}]}
, denoted by
f(X_{[t,t^{\prime}]})
, is

\displaystyle f(X_{[t,t^{\prime}]})={}

\displaystyle\bar{q}(X_{t})\mathds{1}_{D}(X_{t^{\prime}\wedge S_{t}})q(X_{t^{\prime}})(\xi(X_{t^{\prime}})-\xi(X_{t}))

\displaystyle+\mathds{1}_{A}(X_{t\vee\bar{S}_{t^{\prime}}})q(X_{t^{\prime}})(\xi(X_{t^{\prime}})-0)

\displaystyle+\bar{q}(X_{t})\mathds{1}_{B}(X_{t^{\prime}\wedge S_{t}})(1-\xi(X_{t}))

\displaystyle+N_{AB}(X_{[t,t^{\prime}]}),

(55)

where we have used (
2
) and (
3
).
By ergodicity, (
40
) is

\Phi=\frac{1}{\tau}\E[f(X_{[0,\tau]})].

(56)

The key point is that transition paths observed in the time interval
[0,\tau]
can be classified into four cases by their starting and ending times: starting before
0
and ending after
\tau
, starting before
0
and ending within
[0,\tau]
, starting within
[0,\tau]
and ending after
\tau
, and both starting and ending within
[0,\tau]
.
Each term in (
13
) corresponds to one of these cases and represents the product of the probability of observing that type of transition path and the progress it contributes within the time interval
[0,\tau]
.

Appendix B
Mode decomposition of the variational loss function

When detailed balance is satisfied, we can write a perturbation
\eta
to
q
as in (
24
) as a sum over eigenvalues
\{e^{-\tau/\sigma_{k}}\}
and eigenfunctions
\{v_{k}\}
:

\E[\mathds{1}_{D}(X_{\tau\wedge S_{0}})\eta(X_{\tau})\mid X_{0}=x]=\sum_{k}e^{-\tau/\sigma_{k}}v_{k}(x)\langle v_{k},\eta\rangle,

(57)

where
\tau\geq 0
,

\langle v_{k},\eta\rangle=\int v_{k}(x)\eta(x)\pi(x)\mathop{}\!\mathrm{d}x
,

\langle v_{k},v_{l}\rangle=\delta_{kl}
,
and
\delta_{kl}
is the Kronecker delta.
The estimated transition rate is then

\displaystyle\tilde{L}_{\tau}(q+\eta)

\displaystyle=\Phi+\frac{1}{2\tau}\E[\eta(X_{0})^{2}+\eta(X_{\tau})^{2}-2\mathds{1}_{D}(X_{\tau\wedge S_{0}})\eta(X_{0})\eta(X_{\tau})]

(58)

\displaystyle=\Phi+\sum_{k}\frac{1-e^{-\tau/\sigma_{k}}}{\tau}\langle v_{k},\eta\rangle^{2}.

(59)

Since
\langle v_{k},\eta\rangle^{2}\geq 0
and
(1-e^{-\tau/\sigma_{k}})/\tau
is a nonnegative, monotonically decreasing function of
\tau
, the estimated transition rate decreases (and accuracy increases) with increasing
\tau
for fixed
\eta
.
For
\sigma_{k}\ll\tau
,
(1-e^{-\tau/\sigma_{k}})/\tau\approx 1/\tau
, while for
\sigma_{k}\gg\tau
,
(1-e^{-\tau/\sigma_{k}})/\tau\approx 1/\sigma_{k}
.
Thus, the loss is similarly sensitive to components of
\eta
with decay times shorter than
\tau
, and progressively less sensitive to those with longer decay times.

Appendix C
Mode decomposition of the mean squared error and alternative transition rate expression

As shown by the mode expansion in (
59
), transition rate estimates at short lag times tend to overestimate the true rate and can be improved by extrapolating the rate to infinite lag time.
We do so linearly using the points
(1/\tau_{1},\tilde{L}_{\tau_{1}}(u))
and
(1/\tau_{2},\tilde{L}_{\tau_{2}}(u))
:

\displaystyle\tilde{L}_{\tau_{1},\tau_{2}}(u)

\displaystyle=\tilde{L}_{\tau_{1}}(u)+\frac{\tilde{L}_{\tau_{2}}(u)-\tilde{L}_{\tau_{1}}(u)}{1/\tau_{2}-1/\tau_{1}}\Bigl(\frac{1}{\infty}-\frac{1}{\tau_{1}}\Bigr)

(60)

\displaystyle=\frac{\tau_{1}\tilde{L}_{\tau_{1}}(u)-\tau_{2}\tilde{L}_{\tau_{2}}(u)}{\tau_{1}-\tau_{2}}.

(61)

Surprisingly, (
61
) is variational: it satisfies
\tilde{L}_{\tau_{1},\tau_{2}}(u)\geq\Phi
for all
\tau_{1},\tau_{2}\geq 0
.
Using the mode expansion in (
59
), we find

\tilde{L}_{\tau_{1},\tau_{2}}(q+\eta)=\Phi+\sum_{k}\frac{e^{-\tau_{1}/\sigma_{k}}-e^{-\tau_{2}/\sigma_{k}}}{\tau_{2}-\tau_{1}}\langle v_{k},\eta\rangle^{2},

(62)

in which each coefficient of
\langle v_{k},\eta\rangle^{2}
is nonnegative.
By the same approach, it can be shown that (
61
) is, in fact, the minimum variational affine combination of
\tilde{L}_{\tau_{1}}
and
\tilde{L}_{\tau_{2}}
.
To the best of our knowledge, the variational expression in (
61
) has not been proposed previously.

We now examine how
\tilde{L}_{\tau_{1},\tau_{2}}(u)
varies with
\tau_{1}
and
\tau_{2}
.
It is symmetric (
\tilde{L}_{\tau_{1},\tau_{2}}(u)=\tilde{L}_{\tau_{2},\tau_{1}}(u)
), decreases with increasing
\tau_{1}
or
\tau_{2}
, and is bounded by

\tilde{L}_{\tau_{2}}(u)=\tilde{L}_{0,\tau_{2}}\geq\tilde{L}_{\tau_{1},\tau_{2}}(u)\geq\tilde{L}_{\infty,\tau_{2}}(u)=\Phi.

(63)

To understand the behavior away from these bounds, we consider a representative case
\tilde{L}_{\tau,\tau}(u)=\left.{\mathrm{d}(\tau\tilde{L}_{\tau}(u))}\middle/{\mathrm{d}\tau}\right.
, which has a simple mode expansion:

\tilde{L}_{\tau,\tau}(q+\eta)=\Phi+\sum_{k}\frac{e^{-\tau/\sigma_{k}}}{\sigma_{k}}\langle v_{k},\eta\rangle^{2}.

(64)

As
\tau
increases, each coefficient of
\langle v_{k},\eta\rangle^{2}
exponentially decays from
1/\sigma_{k}
to zero.
Unlike
\tilde{L}_{\tau}
,
\tilde{L}_{\tau,\tau}
is not monotonic in
\sigma_{k}
: the coefficient is zero at both
\sigma_{k}=0
and
\sigma_{k}=\infty
, and has a maximum of
1/(\tau e)
at
\sigma_{k}=\tau
.

Similarly, we can use the mode expansion in (
59
) to understand the associated approximation of the MSE in (
30
). To this end, we write

\displaystyle\MSE_{\tau_{1},\tau_{2}}(q+\eta)=\MSE(q+\eta)-\sum_{k}\frac{e^{-\tau_{1}/\sigma_{k}}/\tau_{1}-e^{-\tau_{2}/\sigma_{k}}/\tau_{2}}{1/\tau_{1}-1/\tau_{2}}\langle v_{k},\eta\rangle^{2}.

(65)

Note the mode expansion of the MSE is

\MSE(q+\eta)=\sum_{k}\langle v_{k},\eta\rangle^{2}.

(66)

Because
0\leq(e^{-\tau_{1}/\sigma_{k}}/\tau_{1}-e^{-\tau_{2}/\sigma_{k}}/\tau_{2})/(1/\tau_{1}-1/\tau_{2})\leq 1
, this expression always underestimates the MSE in the limit of infinite data.
It can be shown that (
30
) is the maximum linear combination of
\tilde{L}_{\tau_{1}}
and
\tilde{L}_{\tau_{2}}
that is a lower bound for the MSE.
More precisely,
\MSE_{\tau_{1},\tau_{2}}
is symmetric (
\MSE_{\tau_{1},\tau_{2}}(u)=\MSE_{\tau_{2},\tau_{1}}(u)
), increases with increasing
\tau_{1}
or
\tau_{2}
, and is bounded by

0=\MSE_{0,\tau_{2}}(u)\leq\MSE_{\tau_{1},\tau_{2}}(u)\leq\MSE_{\infty,\tau_{2}}(u)=\tau_{2}(\tilde{L}_{\tau_{2}}(u)-\Phi)\leq\MSE(u).

(67)

For
\tau_{1}
close to
\tau_{2}
, rather than near
0
or
\infty
, we consider a representative case
\MSE_{\tau,\tau}(u)=\left.{\mathrm{d}\tilde{L}_{\tau}(u)}\middle/{\mathrm{d}(1/\tau)}\right.
, which has a simple mode expansion:

\MSE_{\tau,\tau}(q+\eta)=\MSE(q+\eta)-\sum_{k}(1+\tau/\sigma_{k})e^{-\tau/\sigma_{k}}\langle v_{k},\eta\rangle^{2}.

(68)

We thus see that
\MSE_{\tau,\tau}(q+\eta)
performs well when
\tau\gg\sigma_{k}
, but performs poorly when
\tau\ll\sigma_{k}
, and therefore is insensitive to slowly decaying modes.

Appendix D
Connection to the mean squared residual

Another approach to solving for the committor is to minimize the mean squared residual (MSR)
Strahan et al. 2023
,

\MSR_{\tau}(u)=\int(u(x)-\E[\hat{u}(X_{\tau\wedge S_{0}})\mid X_{0}=x])^{2}\mu(x)\mathop{}\!\mathrm{d}x,

(69)

where
\mu
is an arbitrary distribution of initial states.
This objective typically requires two or more independent simulations from each starting configuration
x
to avoid bias due to the double sampling problem
Strahan et al. 2023
;
Strahan et al. 2023
.
However, when the dynamics satisfy detailed balance, forward-in-time and backward-in-time conditional expectations are equal, and so (
69
) with
\mu=\pi
can be expressed as

\MSR_{\tau}(u)=\E[(u(X_{\tau})-\hat{u}(X_{2\tau\wedge S_{\tau}}))(u(X_{\tau})-\hat{u}(X_{0\vee\bar{S}_{\tau}}))],

(70)

because
X_{2\tau\wedge S_{\tau}}
and
X_{0\vee\bar{S}_{\tau}}
are independent samples conditioned on
X_{\tau}
.
The squared residual can be written as

(u(X_{\tau})-\hat{u}(X_{2\tau\wedge S_{\tau}}))(u(X_{\tau})-\hat{u}(X_{0\vee\bar{S}_{\tau}}))=g(X_{[0,\tau]},u)+g(X_{[\tau,2\tau]},u)-g(X_{[0,2\tau]},u),

(71)

allowing the MSR to be expressed in terms of the EVCN loss (
19
):

\MSR_{\tau}(u)=2\tau(\tilde{L}_{\tau}(u)-\tilde{L}_{2\tau}(u))=\MSE_{\tau,2\tau}(u).

(72)

As discussed in Appendix
C
,
\MSE_{\tau,2\tau}(u)
is variational, and thus
\MSR_{\tau}(u)
is variational as well.

Appendix E
Further discussion of overfitting

The loss functions (
22
) and (
19
) can exhibit pathological overfitting when sampling is sparse, which is common for high-dimensional systems.
When no configuration appears more than once in a dataset, highly expressive models and input features (e.g., those from Ref.
52
) can identify the trajectory and time index of each configuration, ignoring the actual dynamics.

In the worst-case scenario, the dataset consists of a single trajectory
X_{[0,\tau]}
from each initial structure
X_{0}
, with no configuration appearing more than once.
With highly expressive models and input features, the loss can be minimized independently for each trajectory.
Under these conditions, the VCN loss is minimized at

\min_{u}L_{\tau}(u)=\frac{1}{2\tau}\E[\mathds{1}_{A}(X_{0})\mathds{1}_{B}(X_{\tau})+\mathds{1}_{B}(X_{0})\mathds{1}_{A}(X_{\tau})],

(73)

with
u(X_{0})=u(X_{\tau})
if
X_{0}\in D
and
X_{\tau}\in D
; otherwise,
u(X_{0})=\mathds{1}_{B}(X_{0})+\mathds{1}_{D}(X_{0})\mathds{1}_{B}(X_{\tau})
and
u(X_{\tau})=\mathds{1}_{B}(X_{\tau})+\mathds{1}_{D}(X_{\tau})\mathds{1}_{B}(X_{0})
.
The EVCN loss is minimized at

\min_{u}\tilde{L}_{\tau}(u)=\frac{1}{2\tau}\E[N_{AB}(X_{[0,\tau]})+N_{BA}(X_{[0,\tau]})],

(74)

with
u(X_{0})=u(X_{\tau})
if
X_{t}\in D
for all
t\in[0,\tau]
; otherwise,
u(X_{0})=\mathds{1}_{B}(X_{\tau\wedge S_{0}})
and
u(X_{\tau})=\mathds{1}_{B}(X_{0\vee\bar{S}_{\tau}})
.
For both loss functions, when
u(X_{0})=u(X_{\tau})
, the output is otherwise unconstrained and can take arbitrary values without affecting the loss.

These issues can arise even with long trajectories if each configuration still appears only once.
With a single long trajectory and a single-step lag time, minimizing the loss effectively reduces to solving for the committor along a 1D random walk on the time index.
At long lag times, the EVCN loss is minimized with the empirical committor
u(X_{t})=(\mathds{1}_{B}(X_{S(t)})+\mathds{1}_{B}(X_{\bar{S}(t)}))/2
, which takes values in
\{0,0.5,1\}
.

To mitigate these problems, we treated the number of optimization steps as a hyperparameter and selected it based on validation performance.
We also restricted the model’s flexibility by using a simple architecture and less expressive input features.
A more principled solution would be to explicitly regularize the model to prevent it from encoding the trajectory and time index, which we leave for future work.
