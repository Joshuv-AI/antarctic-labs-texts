When to Think Fast and Slow? AMOR: Entropy-Based Metacognitive Gate for Dynamic SSM-Attention Switching
Haoran Zheng

Abstract
Transformers allocate uniform computation to every position, regardless of difficulty. State Space Models (SSMs) offer efficient alternatives but struggle with precise information retrieval over a long horizon. Inspired by dual-process theories of cognition ( 16 ) , we propose Amor (Adaptive Metacognitive Output Router), a hybrid architecture that dynamically engages sparse attention only when an SSM backbone is “uncertain”—as measured by prediction entropy. Compared to standard transformers, Amor gains efficiency by projecting keys and values from SSM hidden states (Ghost KV), reusing the SSM’s O ⁡ ( n ) O(n) computation rather than requiring O ⁡ ( n 2 ) O(n^{2}) attention at every layer. On small-scale synthetic retrieval tasks, Amor outperforms both SSM-only and transformer-only baselines, achieving perfect retrieval accuracy while engaging attention on only 22% of positions. We validate that prediction entropy reliably signals retrieval need, with a gap of 1.09 nats (nearly half the entropy range) between retrieval and local positions. Additionally, our approach provides interpretable adaptive computation, where routing decisions can be understood in information-theoretic terms.

Introduction

Transformers
(
25
)
have become the dominant architecture for sequence modeling, achieving strong results across language, vision, and multimodal domains. Yet they allocate identical computation to every position in a sequence, whether predicting a common word from obvious context or retrieving a specific fact from long-range memory. This uniform allocation ignores that prediction difficulty varies across positions—some require only local context while others demand retrieval from distant memory.

Human cognition suggests an alternative.
16
distinguished between System 1 (fast, automatic, effortless) and System 2 (slow, deliberate, effortful) thinking. For instance, reading familiar prose is System 1: predictions flow automatically from context. Encountering an unfamiliar technical term triggers System 2: we pause, perhaps re-read, and retrieve relevant background. Notably, this switching is
metacognitive
: humans recognize uncertainty and engage deliberate processing accordingly.
5
suggested that neural networks might benefit from similar dual-process mechanisms, allocating deliberate computation where automatic processing falls short.

State Space Models (SSMs) offer a promising substrate for mimicking efficient System 1 processing. Mamba
(
14
)
, for instance, achieves linear complexity by compressing sequence history into a fixed-size recurrent state, excelling at local pattern modeling. But this compression comes at a cost: precise information from distant positions cannot always be recovered from a compressed state. Hybrid architectures like Jamba
(
19
)
and Griffin
(
7
)
emerged to address this tradeoff. These designs combine SSMs with attention, but still apply attention uniformly across sequences, without adapting to which positions actually need it.

Adaptive computation methods address this by varying computation based on input. Mixture-of-Depths
(
21
)
learns to route tokens around computation entirely, while PonderNet
(
2
)
learns when to stop iterating on a representation. These approaches achieve efficiency gains, but through learned routers whose decisions resist interpretation. Given a position that receives extra computation, we cannot easily say
why
. Moreover, they vary the amount of computation, not the type: there is no qualitative shift between processing modes as dual-process theory suggests.

This design has several appealing properties. The routing signal is
interpretable
: we can inspect entropy at each position and understand, in information-theoretic terms, why attention was triggered. Entropy is

Related Work

State Space Models.

Structured State Space Models (S4)
(
15
)
introduced efficient long-range sequence modeling through continuous-time formulations, achieving strong results on the Long Range Arena benchmark
(
24
)
. Mamba
(
14
)
extended this line of work with selective state spaces that condition parameters on input content, enabling content-based reasoning while maintaining linear complexity. The recent Mamba-2
(
6
)
established theoretical connections between SSMs and attention through structured state space duality, revealing that these seemingly distinct architectures share deep mathematical structure. Despite these advances, SSMs fundamentally compress sequence history into fixed-size state, which limits their ability to retrieve precise information from arbitrary past positions.

Hybrid Architectures.

Several architectures combine SSMs with attention to leverage both efficiency and retrieval capability. Jamba
(
19
)
interleaves Mamba and attention layers at a fixed 1:7 ratio, incorporating Mixture-of-Experts for additional capacity. Griffin
(
7
)
combines gated linear recurrences with local sliding-window attention, achieving strong performance on language modeling while reducing the quadratic cost of global attention. RWKV
(
20
)
reformulates attention as a linear recurrence, enabling RNN-style inference with transformer-quality results. More recent work explores different fusion strategies: Hymba
(
9
)
fuses attention and SSM heads in parallel within each layer, using learned meta tokens to reduce attention burden, while Zamba
(
12
)
takes a minimal approach with a Mamba backbone and single shared attention layer. These architectures use
static
patterns of interleaving—every sequence receives the same architectural treatment regardless of content.
Amor
differs in two ways: the SSM processes all positions while attention is
selectively engaged
only where the model’s own uncertainty signals retrieval is needed, and the routing decision is itself interpretable through entropy—a metacognitive signal that reveals
why
additional computation was allocated.

Adaptive Computation.

The idea of varying computation based on input difficulty has a rich history. Adaptive Computation Time (ACT)
(
13
)
pioneered variable-depth computation in RNNs by learning a halting mechanism. Universal Transformers
(
8
)
applied ACT to transformers, iterating over representations until a learned halting condition is met. PonderNet
(
2
)
improved on ACT with a probabilistic halting formulation that yields unbiased gradients. These approaches vary computation
depth
—how many times a representation is refined.
Amor
instead varies computation
type
at fixed depth: certain positions receive only SSM processing, while others additionally receive attention.

Concurrently, the Hierarchical Reasoning Model (HRM)
(
26
)
achieves impressive results on complex reasoning tasks (Sudoku, maze solving, ARC) with only 27M parameters, using interdependent transformer-based recurrent modules for slow planning and fast computation—a dual-process intuition similar to ours, though with different architectural realization.

Mixture-of-Depths (MoD)
(
21
)
is most closely related to our work, using top-k routing to dynamically skip computation at each layer. There are three key differences. First, MoD skips computation entirely for non-routed tokens, while
Amor
always processes through the SSM and selectively adds attention. Second, MoD uses a learned router whose decisions are not directly interpretable, while
Amor
uses entropy—a quantity with clear semantics as model uncertainty. Third, MoD operates within transformer layers, deciding which tokens participate in self-attention, while
Amor
gates an entirely separate attention module—purposefully instantiating the dual-process distinction where System 1 (SSM) and System 2 (attention) are architecturally separate rather than modulations of the same mechanism.

Mixture of Experts.

MoE architectures
(
22
;
10
)
route tokens to specialized expert networks, enabling models to scale parameters without proportionally scaling computation. Our gate mechanism borrows the Straight-Through Estimator
(
4
)
and balance loss from MoE training, as these techniques have proven effective for learning discrete routing decisions. However, MoE routing is typically learned end-to-end from task loss alone, producing routers whose decisions can be difficult to interpret. Our entropy-based gate provides explicit semantics: the gate fires when the SSM’s probability distribution over next tokens is diffuse rather than concentrated.

Efficient Attention.

Reducing the quadratic cost of attention has been a major research focus. Linformer
(
27
)
projects keys and values to lower dimensions, achieving linear complexity through low-rank approximation. Sparse attention patterns
(
29
;
3
)
attend to carefully chosen subsets of positions—local windows, global tokens, or random samples. Our sparse top-k attention builds on the insight that attending to fewer positions can outperform attending to many, particularly when the task requires precise retrieval.

KV Projection.

The practice of projecting hidden states to keys and values has deep roots. Bahdanau attention
(
1
)
originally computed attention over encoder hidden states in sequence-to-sequence models. Linear transformers
(
17
)
showed that attention can be reformulated as an RNN, revealing fundamental connections between attention and recurrence. RetNet
(
23
)
further develops this with retention mechanisms supporting both parallel and recurrent computation. Our Ghost KV cache extends this lineage: rather than discarding the SSM’s sequential processing, we project its hidden states to provide temporally-aware key-value representations for sparse attention.

Entropy and Uncertainty in Neural Networks.

Prediction entropy is a well-established measure of model uncertainty
(
18
;
11
)
, widely used for calibration analysis and active learning. DeeBERT
(
28
)
leverages entropy for adaptive inference, halting BERT’s forward pass at an early layer when prediction confidence is high. The connection to our work is direct: both approaches use entropy to make per-input computation decisions. The key difference lies in what happens when entropy is high. DeeBERT continues processing through remaining layers—essentially “trying harder” with the same architecture.
Amor
instead engages a qualitatively different mechanism: sparse attention over the Ghost KV cache. This reflects the dual-process view that high entropy signals a need for a different
kind
of computation (retrieval), not just more processing of the same kind—mirroring the cognitive distinction between effortful deliberation and automatic processing. Additionally, DeeBERT targets classification where early exit is natural;
Amor
targets sequence modeling where every position requires a prediction.

3
Method

3.1
Architecture Overview

Given input tokens
x=(x_{1},\ldots,x_{T})
,
Amor
processes the sequence as follows:

1.

SSM (System 1):
Process all positions, producing logits
\ell_{t}
and hidden states
h_{t}

2.

Entropy Gate:
Compute gate decision
g_{t}\in\{0,1\}
based on prediction entropy

3.

Sparse Attention (System 2):
Where
g_{t}=1
, attend over Ghost KV cache

4.

Combine:
Merge SSM and attention outputs for final prediction

3.2
System 1: SSM Backbone

We use a GRU for simplicity, though Mamba or other modern SSMs should be substituted. While GRUs are technically RNNs rather than SSMs (which derive from continuous-time state space equations), both compress sequence history into a fixed-size state—the key property our method exploits. The SSM maintains a compressed state that efficiently handles local patterns:

\displaystyle h_{t}

\displaystyle=\text{SSM}(e_{t},h_{t-1})

(1)

\displaystyle\ell_{t}

\displaystyle=W_{o}h_{t}

(2)

where
e_{t}=\text{Embed}(x_{t})
,
\ell_{t}\in\mathbb{R}^{|V|}
are logits over the vocabulary, and
\text{SSM}(\cdot)
denotes any recurrent update (GRU in our experiments).

3.3
Entropy-Based Metacognitive Gate

The core mechanism of
Amor
lies in using prediction entropy as the routing signal. We compute normalized entropy from SSM logits:

\displaystyle p_{t}

\displaystyle=\text{softmax}(\ell_{t})

(3)

\displaystyle\mathcal{H}(p_{t})

\displaystyle=-\sum_{i}p_{t,i}\log p_{t,i}

(4)

\displaystyle\hat{\mathcal{H}}_{t}

\displaystyle=\frac{\mathcal{H}(p_{t})}{\log|V|}

(5)

Normalized entropy
\hat{\mathcal{H}}_{t}\in[0,1]
provides scale-invariance across vocabulary sizes. The gate decision is:

\displaystyle g_{t}

\displaystyle=\mathbbm{1}\left[\sigma\left(\alpha(\hat{\mathcal{H}}_{t}-\tau)\right)>0.5\right]

(6)

where
\tau
is a learnable threshold and
\alpha
is a learnable scale parameter. We use the Straight-Through Estimator
(
4
)
for gradients: the hard decision
g_{t}\in\{0,1\}
is used in the forward pass, while gradients flow through the soft probability
\sigma(\cdot)
.

3.4
System 2: Sparse Attention with Ghost KV

When the gate fires (
g_{t}=1
), we perform sparse attention using a Ghost KV cache.

Ghost KV Cache.

We project keys and values from SSM hidden states rather than computing them fresh:

\displaystyle K

\displaystyle=W_{K}H,\quad V=W_{V}H

(7)

where
H\in\mathbb{R}^{T\times d}
contains SSM hidden states. The “ghost” terminology reflects that these KV pairs are projections of SSM states rather than fresh computations—echoes of what the SSM has already learned.

Sparse Top-k Attention.

We compute attention only over the top-
k
most relevant positions. Given a query from the current position:

\displaystyle Q_{t}

\displaystyle=W_{Q}h_{t}

(8)

\displaystyle\text{scores}_{t}

\displaystyle=\frac{Q_{t}K^{\top}}{\sqrt{d}}

(9)

\displaystyle\text{attn}_{t}

\displaystyle=\text{softmax}(\text{top-}k(\text{scores}_{t}))V

(10)

Sparse attention prevents dilution across many positions. In our experiments,
k=3
significantly outperforms
k=16
(Appendix
C.5
), as concentrating attention on the most relevant positions proves more effective than spreading it thinly.

Gated Output.

The attention output is masked by the gate decision, ensuring it only contributes when the gate fires:

\displaystyle o_{t}^{\text{attn}}

\displaystyle=g_{t}\cdot\text{attn}_{t}

(11)

When the gate outputs zero, the attention result does not contribute to the final prediction.

3.5
Combination and Prediction

Final predictions combine SSM and attention outputs through a learned projection:

\displaystyle h_{t}^{\text{combined}}

\displaystyle=W_{c}[h_{t}\|o_{t}^{\text{attn}}]

(12)

\displaystyle\text{logits}_{t}

\displaystyle=W_{\text{out}}h_{t}^{\text{combined}}

(13)

This combination allows the model to leverage both the SSM’s local pattern modeling and attention’s retrieval capability, weighted by the gate decision.

3.6
Training

We train end-to-end with cross-entropy loss plus a balance loss to prevent gate collapse:

\displaystyle\mathcal{L}

\displaystyle=\mathcal{L}_{\text{CE}}+\lambda\left(\bar{g}-r_{\text{target}}\right)^{2}

(14)

where
\bar{g}
is mean gate activation and
r_{\text{target}}
is the target rate (default 0.2). The balance loss, borrowed from MoE training
(
22
)
, encourages the gate to fire at a reasonable rate rather than collapsing to always-on or always-off.

3.7
Design Notes

A natural question arises: why not just use a standard transformer, given their proven strength at retrieval? The key advantage of
Amor
lies in efficiency while maintaining performance. In standard transformers, each layer projects K and V from the previous layer’s output—contextualized representations that themselves required
O(n^{2})
self-attention to compute. This cost compounds across layers.
Amor
’s Ghost KV instead projects from SSM hidden states, which cost only
O(n)
to produce through recurrent processing. The SSM has already built contextualized representations; Ghost KV reuses this work rather than requiring additional attention layers. In our experiments, projecting from SSM hidden states achieves 36% retrieval accuracy versus 6% from raw embeddings, and
Amor
outperforms both SSM-only and transformer-only baselines (Section
4
).

Our current implementation computes Ghost KV projections and attention scores for all positions, applying the gate as a post-hoc mask. This means when attention fires at position
t
, it can retrieve from any position
1
to
t-1
—the full sequence history remains available. The memory footprint is
O(n\cdot d)
for a single attention layer, with no accumulation across inference steps.

The remaining quadratic cost comes from attention computation itself: computing
QK^{\top}
scores and aggregating values. With conditional execution—skipping query projection, score computation, and value aggregation where
g_{t}=0
—
Amor
would reduce this to
O(r\cdot n^{2})
where
r
is the gate rate. At our observed 22% gate rate, this represents 78% reduction in attention computation. We leave this optimization to future work.

4
Experiments

We evaluate
Amor
on synthetic retrieval tasks designed to require both local pattern modeling and long-range information retrieval. Our experiments address three questions: Can entropy effectively signal retrieval need? Can
Amor
achieve high retrieval accuracy with selective attention? What are the boundaries of this approach?

4.1
Experimental Setup

We use two synthetic tasks of increasing difficulty:

Reconciling the Two Tasks.

The contrasting results between tasks reveal when entropy-based gating excels and where it struggles. On the Simple Task, SSM hidden states remain informative—the model maintains useful representations despite retrieval distances of 20–50 tokens. Here, broader firing (22%) provides extra context that benefits retrieval beyond what minimal gating achieves. On NeedleHaystack, extended noise (50–150 tokens) causes SSM states to decay globally, leaving the model uniformly uncertain. When entropy is high everywhere (80.97% gate rate), it loses discriminative power—the gate cannot distinguish positions that
need
retrieval from those that are simply uncertain due to state decay. This motivates proactive gating mechanisms that cache information
before
uncertainty manifests, rather than reacting to it.

Larger-scale experiments across different domains will be needed to test the practicality of
Amor
in real-world settings. Nevertheless, these results provide initial evidence that entropy-based metacognitive routing can improve retrieval performance while maintaining computational efficiency.

5
Discussion and Future Directions

5.1
Conditional Execution

The current
Amor
implementation computes Ghost KV and attention for all positions, applying the gate as a post-hoc mask. This validates the architectural mechanism but does not realize further wall-clock speedups.

Conditional execution would compute attention only where
g_{t}=1
, reducing attention cost to
O(r\cdot n^{2})
where
r
is the gate rate. At our observed 22% gate rate, this represents 78% reduction in attention computation. The implementation requires gathering gated positions, computing attention over variable-length sequences, and scattering results back. This is an engineering challenge rather than a research question—the mechanism is validated; optimization remains.

5.2
Persistent KV Storage: Beyond the State Horizon

Our experiments reveal a fundamental limitation: beyond approximately 50 tokens of intervening noise, SSM state decay makes retrieval unreliable—even with perfect gating (Appendix
C.3
). Since Ghost KV projects from SSM hidden states, it inherits this limitation. When the SSM has “forgotten” information, there is nothing useful to project.

A natural extension would add persistent KV storage alongside Ghost KV. The current Ghost KV—projected fresh from SSM states—remains effective for retrieval within the state retention horizon, providing temporally-aware representations for recent context. A persistent cache would complement this by storing KV pairs at selected positions during encoding, preserving information that would otherwise decay.

At retrieval time, attention could draw from both sources: Ghost KV for recent context (where SSM states remain informative) and the persistent cache for distant memories (where SSM states have decayed). This hybrid approach leverages Ghost KV’s strengths while extending retrieval capability beyond the state horizon.

Identifying what to cache.
A storage gate must identify positions worth remembering. Two complementary signals could drive this:

•

Reactive storage (
Amor
):
Cache positions where the model struggled (high entropy)—“I was uncertain here, this might be worth revisiting.”

•

Proactive storage:
Cache positions containing important information (low entropy but high future utility)—“This looks important; I may need it later.”

Proactive gating is crucial for extending the retrieval horizon: by caching KV at the moment information is encountered (before decay begins), the model preserves access for future retrieval. Training this requires predicting future utility rather than current uncertainty. Reinforcement learning with reward based on downstream retrieval success offers one path forward.

With selective caching, memory scales as
O(r_{s}\cdot n\cdot d)
where
r_{s}
is the storage rate, keeping the approach practical while extending retrieval capability. We leave this direction for future work.

5.3
State Feedback

For
Amor
, attention output does not currently feed back into SSM state—
h_{t+1}=\text{SSM}(e_{t+1},h_{t})
uses the raw SSM state, not
h_{t}^{\text{combined}}
. This preserves the SSM’s learned local dynamics but may limit tasks requiring iterative reasoning.

A feedback variant—where
h_{t+1}=\text{SSM}(e_{t+1},f(h_{t},o_{t}^{\text{attn}}))
for some learned projection
f
—could enable richer integration for real world tasks. This differs from existing hybrids: Jamba
(
19
)
and Zamba
(
12
)
interleave layers sequentially but never modify recurrent state with attention output; Hymba
(
9
)
fuses outputs but not dynamics. Recent work on context-selective SSMs
(
30
)
explores feedback mechanisms within SSM architectures, though attention-to-SSM state feedback in hybrid models remains largely unexplored.

6
Conclusion

We introduced
Amor
, a novel hybrid architecture that dynamically routes between SSM and attention based on prediction entropy—a principled, interpretable signal for model uncertainty. The core insight is simple: when an SSM is confident (low entropy), local context suffices; when uncertain (high entropy), the model engages attention to retrieve from its Ghost KV cache.

Our experiments validate three key findings. First, entropy reliably signals retrieval need: we observe a gap of 1.09 nats between retrieval and local positions—nearly half the entropy range—demonstrating that SSMs genuinely “know what they don’t know.” Second, selective attention suffices:
Amor
achieves perfect retrieval accuracy on synthetic tasks while engaging attention on only 22% of positions, compared to 100% for standard transformers. Third, Ghost KV provides meaningful efficiency gains: by projecting keys and values from SSM hidden states rather than computing fresh attention representations, we reuse
O(n)
computation rather than requiring
O(n^{2})
at every layer.

The approach has existing limitations. Beyond some intervening noise, SSM state decay degrades Ghost KV quality—a fundamental property of recurrent compression. Our reactive gating strategy, while effective within the state retention horizon, cannot anticipate retrieval needs before uncertainty manifests. The gap between Oracle (37%) and Entropy (10%) gating on hard tasks motivates proactive mechanisms that cache information preemptively.

More broadly,
Amor
demonstrates that the dual-process intuition from cognitive science—fast, automatic processing complemented by slow, deliberate retrieval—can be instantiated in neural architectures with interpretable routing decisions. Unlike learned routers whose behavior resists explanation, entropy provides clear semantics: we can inspect any position and understand, in information-theoretic terms, why attention was or was not engaged. This interpretability may prove valuable as models scale and understanding their computational allocation becomes increasingly important.

We hope
Amor
inspires further exploration of metacognitive mechanisms in neural sequence models—architectures that not only process information but reflect on their own uncertainty to allocate computation where it matters most.

python scripts/run_ablations.py --seed 42 # Ablation study
python scripts/run_needlehaystack_seeded.py # Hard task (seeded)
python scripts/compare_kv_methods_seeded.py # Ghost KV vs Raw Embedding
python scripts/diagnose_needlehaystack.py # Diagnostics (multi-seed)

The main paper reports seeded results (seed=42) for key comparisons to ensure reproducibility. Multi-seed experiments (5 seeds) are used for the noise sweep analysis to characterize variance. Results files are stored in
