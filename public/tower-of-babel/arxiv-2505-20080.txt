A note on helicity conservation for compressible Euler equations in a bounded domain with vacuum
Yulin Ye

Abstract
In this paper, we consider the helicity conservation of weak solutions for the compressible Euler equations in a bounded domain with general pressure law and vacuum. We deduce a sufficient condition for a weak solution conserving the helicity based on the interior Besov-VMO type regularity, the continuous conditions for velocity and vorticity near the boundary, and some regularities for density near vacuum.

(1.9)

\displaystyle v\in L^{3}(0,T;\underline{B}^{\frac{1}{3}}_{3,VMO}(\Omega))\ \text{and}~\omega\in L^{3}(0,T;L^{3}(\Omega)).

(ii)

(Continuous condition near the boundary )

\lim\limits_{\varepsilon\to 0}\int_{0}^{T}{\int\!\!\!\!\!\!-~}_{\frac{\varepsilon}{2}<d(x,\partial\Omega)<\varepsilon}\Big|\left(P(\rho)-\frac{1}{2}|v|^{2}\right)\omega\cdot\vec{n}(\sigma(x))+\left(\omega\cdot v\right)v\cdot\vec{n}(\sigma(x))\Big|dxdt=0,

.

(

Hence, Before we state our result, for the convenience of readers, we first give the definition of the weak solutions to compressible Euler equations (
1.1
).

Definition 2.1
.

A pair (
\rho,v
) is called a weak solution to the compressible Euler equations (
1.1
) if (
\rho,v
) satisfies

(i)

For any test function
\Phi\in C_{0}^{\infty}((0,t)\times\Omega)
, there holds

\int^{T}_{0}\int_{\Omega}\rho(t,x)\partial_{t}\Phi(t,x)+\rho(t,x)v(t,x)\nabla\Phi(t,x)dxdt=0

(2.33)

(ii)

For any test vector field
\Psi\in C_{0}^{\infty}((0,t)\times\Omega)
, there holds

\displaystyle\int_{0}^{T}\int_{\Omega}\rho(t,x)v(t,x)

\displaystyle\partial_{t}\Psi(t,x)+\Big(\rho(t,x)v(t,x)\otimes v(t,x)\Big)\nabla\Psi(t,x)

(2.34)

\displaystyle+

\displaystyle p(\rho)(t,x)\text{div}\Psi(t,x)dxdt=0.

(iii)

The energy inequality holds

\displaystyle\mathcal{E}(t)\leq\mathcal{E}(0),

(2.35)

where
\mathcal{E}(t)=\int_{\Omega}\Big(\frac{1}{2}\rho|v|^{2}+G(\rho)\Big)dx
, with
G(\rho)=\rho\int_{1}^{\rho}\frac{p(s)}{s^{2}}ds
.

3
Helicity conservation for the compressible Euler equations

This section is devoted to the proof of the helicity conservation of weak solutions for compressible Euler equations with density containing vacuum in a bounded domain. We will divide the proof into two steps. First, we need the following proposition.

Proposition 3.1
.

Let
(\rho,v)
be a weak solution of compressible Euler equations (
1.1
) in the sense of Definition
2.1
. Assume that

(i)

(Interior Besov regularity) if
(\rho,v)
satisfy

\displaystyle 0\leq\rho\leq c<\infty,~\rho\in L^{3}(0,T;B^{\frac{1}{3}}_{3,c(\mathbb{N})}(\Omega))\cap L^{\infty}(0,T;B^{\frac{1}{3}}_{\infty,\infty}(\Omega)),

(3.1)

\displaystyle v\in L^{3}(0,T;\underline{B}^{\frac{1}{3}}_{3,VMO}(\Omega))~\text{and}~\omega\in L^{\frac{3}{2}}(0,T;L^{\frac{3}{2}}(\Omega)),

(ii)

(Near the vacuum)for any
\delta>0
, if

\displaystyle\rho^{-1}{\bf 1}_{\rho\leq\delta}\in L^{r_{1}}(0,T;L^{r_{1}}(\Omega)),{\bf 1}_{\rho\leq\delta}\partial_{t}\rho\in L^{r_{2}}(0,T;L^{r_{2}}(\Omega)),\text{and}~{\bf 1}_{\rho\leq\delta}\nabla\rho\in L^{r_{3}}(0,T;L^{r_{3}}(\Omega)),

(3.2)

for some positive constant
c,r_{1},r_{2},r_{3}
and some sufficiently small constant
\delta>0
such that
\frac{1}{r_{1}}+\frac{1}{r_{2}}=\frac{2}{3}
and
\frac{1}{r_{1}}+\frac{1}{r_{3}}=\frac{1}{3}
. Assume further that
p\in C^{2}[c_{1},c_{2}]
, then
(\rho,v)
is also a weak solution of the following system in the sense of distributions on
(0,T)\times\Omega

\left\{\begin{aligned} &\rho_{t}+\nabla\cdot(\rho v)=0,\\
&v_{t}+v\cdot\nabla v+\nabla P(\rho)=0,\end{aligned}\right.

(3.3)

where
P(\rho)=\int_{1}^{\rho}\frac{p^{\prime}(s)}{s}ds
.

Proof.

First, to control the possible vacuum, we introduce the following cut-off function
\phi_{m}(z)
such that

0\leq\phi_{m}(z)\in C^{\infty}([0,\infty)),~\phi_{m}(z)=1~\text{for\ any}~z>\frac{1}{m},~\phi_{m}(z)=0~\text{for\ any}~z<\frac{1}{2m}.

(3.4)

It is easy to check that
\phi_{m}(z)\rightarrow 1
as
m\rightarrow+\infty
pointwise in
\Omega
and for any
z\in\Omega
, we have
z\nabla\phi_{m}(z)\leq C
. Then let
\varphi(t,x)\in C^{\infty}_{0}((0,T)\times\Omega)
with the support of which is strictly contained in an open set
(t_{1},t_{2})\times\Omega^{{}^{\prime}}\subset\subset(0,T)\times\Omega
, due to
(i)
in definition
2.1

First, by the Hölder inequality, one has

\displaystyle|I_{1}|\leq

\displaystyle C\|(\omega\times v)^{\varepsilon}-\omega^{\varepsilon}\times v^{\varepsilon}\|_{L^{\frac{3}{2}}(0,T;L^{\frac{3}{2}}(\Omega^{{}^{\prime}}))}\|\omega^{\varepsilon}\|_{L^{3}(0,T;L^{3}(\Omega^{{}^{\prime}}))},

(3.39)

which together with
v\in L^{3}(0,T;L^{3}(\Omega)),\ \omega\in L^{3}(0,T;L^{3}(\Omega))
and Lemma
2.2
gives

\|(\omega\times v)^{\varepsilon}-\omega^{\varepsilon}\times v^{\varepsilon}\|_{L^{\frac{3}{2}}(0,T;L^{\frac{3}{2}}(\Omega^{{}^{\prime}}))}\rightarrow 0,\ \ \text{as}\ \varepsilon\rightarrow 0.

Hence as
\varepsilon\to 0
, there holds

|I_{1}|\leq o(1).

(3.40)

For
I_{2}
, using the Lebesgue dominated convergence theorem, as
\varepsilon\to 0
, one has

\displaystyle I_{2}

\displaystyle=\int_{0}^{T}\int_{\Omega^{{}^{\prime}}}\left(P(\rho)+\frac{1}{2}|v|^{2}\right)^{\varepsilon}\omega^{\varepsilon}\cdot\nabla\phi(x)dxdt\to\int_{0}^{T}\int_{\Omega}\left(P(\rho)+\frac{1}{2}|v|^{2}\right)\omega\cdot\nabla\phi(x)dxdt.

(3.41)

Next, to control
I_{3}
, combining the Hölder inequality and Lemma
2.2
, we have

\displaystyle|I_{3}|=

\displaystyle|\int_{0}^{T}\int_{\Omega^{{}^{\prime}}}\left(\Big(v\times\omega\Big)^{\varepsilon}-v^{\varepsilon}\times\omega^{\varepsilon}\right)\cdot\Big(\nabla\phi(x)\times v^{\varepsilon}\Big)dxdt|

(3.42)

\displaystyle\leq

\displaystyle C\|\Big(\left(v\times\omega\right)^{\varepsilon}-v^{\varepsilon}\times\omega^{\varepsilon}\Big)\|_{L^{\frac{3}{2}}(0,T;L^{\frac{3}{2}}(\Omega^{{}^{\prime}}))}\|v^{\varepsilon}\|_{L^{3}(0,T;L^{3}(\Omega^{{}^{\prime}}))}\rightarrow 0,\ \text{as}\ \varepsilon\rightarrow 0.

Since for any vector field
\overrightarrow{u},\overrightarrow{v},\overrightarrow{w},\overrightarrow{x}
, the following identity holds

(\overrightarrow{u}\times\overrightarrow{v})\cdot(\overrightarrow{w}\times\overrightarrow{x})=(\overrightarrow{u}\cdot\overrightarrow{w})(\overrightarrow{v}\cdot\overrightarrow{x})-(\overrightarrow{u}\cdot\overrightarrow{x})(\overrightarrow{v}\cdot\overrightarrow{w}).

(3.43)

Then, taking into account (
3.43
) and Lebesgue dominated convergence theorem,
I_{4}
can be estimated as

\displaystyle I_{4}

\displaystyle=\int_{0}^{T}\int_{\Omega^{{}^{\prime}}}\left(v^{\varepsilon}\times\omega^{\varepsilon}\right)\cdot\Big(\nabla\phi(x)\times v^{\varepsilon}\Big)dxdt

(3.44)

\displaystyle=\int_{0}^{T}\int_{\Omega^{{}^{\prime}}}\Big(v^{\varepsilon}\cdot\nabla\phi(x)\Big)\left(\omega^{\varepsilon}\cdot v^{\varepsilon}\right)-\left(v^{\varepsilon}\cdot v^{\varepsilon}\right)\Big(\omega^{\varepsilon}\cdot\nabla\phi(x)\Big)dxdt

\displaystyle\to\int_{0}^{T}\int_{\Omega}\Big(v\cdot\nabla\phi(x)\Big)\left(\omega\cdot v\right)-\left(v\cdot v\right)\Big(\omega\cdot\nabla\phi(x)\Big)dxdt,\ \text{as}\ \varepsilon\to 0.

Then, combining the Lebesgue dominated convergence theorem once again and (
3.40
), (
3.41
), (
3.42
) and (
3.44
), we can get the local helicity conservation for compressible Euler equations, i.e. for any smooth function
\phi(x)\in C_{0}^{\infty}(\Omega)
, it holds that

\displaystyle\int_{\Omega}(v\cdot\omega)(T,x)\phi(x)dx-\int_{\Omega}(v\cdot\omega)(0,x)\phi(x)dx

(3.45)

\displaystyle-

\displaystyle\int_{0}^{T}\int_{\Omega}\left(P(\rho)-\frac{1}{2}|v|^{2}\right)\omega\cdot\nabla\phi(x)+\left(\omega\cdot v\right)\Big(v\cdot\nabla\phi(x)\Big)dxdt=0.

Step 2
: Next, we will extend the local helicity conservation to be a global one. Before we start the proof of this part, we recall the cut-off function used in

[
3
]
to capture the affect of the boundary.
Let
\Omega
be an open set with a bounded Lipschitz boundary
\partial\Omega
,
therefore the exterior normal vector to the boundary denoted by
\vec{n}(x)
is defined almost everywhere.
Then we observe that there exists
a (small enough)
\varepsilon_{0}
with the following properties: For
d(x,\partial\Omega)\leq\varepsilon_{0}
, the function
x\rightarrow d(x,\partial\Omega)

belongs to
W^{1,\infty}(\Omega)
and for almost every such
x
, there exists a unique point
\sigma(x)\in\partial\Omega
such that

d(x,\partial\Omega)<\varepsilon_{0}\Rightarrow d(x,\partial\Omega)=|x-\sigma(x)|\ \text{and}\ \nabla_{x}d(x,\partial\Omega)=-\vec{n}(\sigma(x)).

Before going further, we consider the smooth function
\psi(z)\in[0,1]
with

\psi(z)=0,z\in(-\infty,\frac{1}{2}]
and
\psi(z)=1,z\in[1,\infty).

Hence, for any
0<\varepsilon<\varepsilon_{0}
, we define the compactly supported function
\theta_{\varepsilon}(x)=\psi(\frac{d(x,\partial\Omega)}{\varepsilon})
which satisfies the following properties

\left\{\begin{aligned} &\theta_{\varepsilon}(x)=0,\ \text{if}\ x\in\Omega_{\frac{\varepsilon}{2}}\ \text{and}\ \theta_{\varepsilon}(x)=1,\ \text{if}\ x\in\Omega^{\varepsilon},\\
&\nabla\theta_{\varepsilon}(x)=-\frac{1}{\varepsilon}\psi^{\prime}(\frac{d(x,\partial\Omega)}{\varepsilon})\vec{n}(\sigma(x))\neq 0,\ \text{if}\ \frac{\varepsilon}{2}<d(x,\partial\Omega)<\varepsilon.\end{aligned}\right.

(3.46)

Then let
\phi(x)=\theta_{\varepsilon}(x)
in (
3.45
), we have

\displaystyle\int_{\Omega}(v\cdot\omega)(T,x)\theta_{\varepsilon}(x)dx-\int_{\Omega}(v\cdot\omega)(0,x)\theta_{\varepsilon}(x)dx

(3.47)

\displaystyle-

\displaystyle\int_{0}^{T}\int_{\Omega}\left(P(\rho)-\frac{1}{2}|v|^{2}\right)\omega\cdot\nabla\theta_{\varepsilon}(x)+\left(\omega\cdot v\right)\Big(v\cdot\nabla\theta_{\varepsilon}(x)\Big)dxdt=0.

For the third term of above equation, due to the continuous condition (
1.10
), we know that

\displaystyle|\int_{0}^{T}\int_{\Omega}\left(P(\rho)-\frac{1}{2}|v|^{2}\right)\omega\cdot\nabla\theta_{\varepsilon}(x)+\left(\omega\cdot v\right)\Big(v\cdot\nabla\theta_{\varepsilon}(x)\Big)dxdt|

(3.48)

\displaystyle\leq

\displaystyle C\int_{0}^{T}\frac{1}{\varepsilon}\int_{\frac{\varepsilon}{2}<d(x,\partial\Omega)<\varepsilon}\Big|\left(P(\rho)-\frac{1}{2}|v|^{2}\right)\omega\cdot\vec{n}(\sigma(x))+\left(\omega\cdot v\right)v\cdot\vec{n}(\sigma(x))\Big|dxdt\to 0.

Combining (
3.47
), (
3.48
) and the Lebesgue dominated convergence theorem, we have

\int_{\Omega}(v\cdot\omega)(T,x)dx=\int_{\Omega}(v\cdot\omega)(0,x)dx=0.

(3.49)

Thus the proof of Theorem
1.1
is completed.
