Abstract
. In an n × n n\times n array filled with symbols, a transversal is a collection of entries with distinct rows, columns and symbols. In this note we show that if no symbol appears more than β ​ n \beta n times, the array contains a transversal of size ( 1 − β / 4 − o ⁡ ( 1 ) ) ​ n (1-\beta/4-o(1))n . In particular, if the array is filled with n n symbols, each appearing n n times (an equi- n n square), we get transversals of size ( 3 / 4 − o ⁡ ( 1 ) ) ​ n (3/4-o(1))n . Moreover, our proof gives a deterministic algorithm with polynomial running time, that finds these transversals.

Theorem 1.4

Moving away from equi-

Theorem 1.5

For every

Theorem
