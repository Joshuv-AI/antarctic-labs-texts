Upper bounds on minimum size of feedback arc set of directed multigraphs with bounded degree
Gregory Gutin, Hui Lei, Anders Yeo, Yacong Zhou

Abstract
An oriented multigraph is a directed multigraph without directed 2-cycles. Let fas ⁡ ( D ) {\rm fas}(D) denote the minimum size of a feedback arc set in an oriented multigraph D D . The degree of a vertex is the sum of its out- and in-degrees. In several papers, upper bounds for fas ⁡ ( D ) {\rm fas}(D) were obtained for oriented multigraphs D D with maximum degree upper-bounded by a constant. Hanauer (2017) conjectured that fas ⁡ ( D ) ≤ 2.5 ​ n / 3 {\rm fas}(D)\leq 2.5n/3 for every oriented multigraph D D with n n vertices and maximum degree at most 5. We prove a strengthening of the conjecture: fas ⁡ ( D ) ≤ m / 3 {\rm fas}(D)\leq m/3 holds for every oriented multigraph D D with m m arcs and maximum degree at most 5. This bound is tight and improves a bound of Berger and Shor (1990,1997). It would be interesting to determine c c such that fas ⁡ ( D ) ≤ c ​ n {\rm fas}(D)\leq cn for every oriented multigraph D D with n n vertices and maximum degree at most 5 such that the bound is tight. We show that 5 7 ≤ c ≤ 24 29 < 2.5 3 \frac{5}{7}\leq c\leq\frac{24}{29}<\frac{2.5}{3} .

The

Studying heuristics for

[

For any digraph

Theorem
3
.

If

.

Proof.

Let

As

. Note that

Thus, by Lemma

.

Consider an auxiliary graph

with vertex set

if and only if

and there is no arcs between

and

in

is a set that satisfies the conditions in Lemma

. And the independent number of

is at least
|V(H)|/\chi(H)
. Thus, by Brooks’ Theorem, we only need to show
\Delta(H)\leq 57
.

Claim A:
Let

be an arbitary vertex in

. If

then

By the definition, we have
