Progressive Size-Adaptive Federated Learning: A Comprehensive Framework for Heterogeneous Multi-Modal Data Systems
Sajid Hussain, Muhammad Sohail, Nauman Ali Khan, Naima Iltaf, Ihtesham ul Islam

Abstract
Federated Learning (FL) has emerged as a transformative paradigm for distributed machine learning while preserving data privacy. However, existing approaches predominantly focus on model heterogeneity and aggregation techniques, largely overlooking the fundamental impact of dataset size characteristics on federated training dynamics. This paper introduces Size-Based Adaptive Federated Learning (SAFL), a novel progressive training framework that systematically organizes federated learning based on dataset size characteristics across heterogeneous multi-modal data. Our comprehensive experimental evaluation across 13 diverse datasets spanning 7 modalities (vision, text, time series, audio, sensor, medical vision, and multimodal) reveals critical insights: 1) an optimal dataset size range of 1000-1500 samples for federated learning effectiveness; 2) a clear modality performance hierarchy with structured data (time series, sensor) significantly outperforming unstructured data (text, multimodal); and 3) systematic performance degradation for large datasets exceeding 2000 samples. SAFL achieves an average accuracy of 87.68% across all datasets, with structured data modalities reaching 99%+ accuracy. The framework demonstrates superior communication efficiency, reducing total data transfer to 7.38 GB across 558 communications while maintaining high performance. Our real-time monitoring framework provides unprecedented insights into system resource utilization, network efficiency, and training dynamics. This work fills critical gaps in understanding how data characteristics should drive federated learning strategies, providing both theoretical insights and practical guidance for real-world FL deployments in neural network and learning systems.



Keywords:
Adaptive aggregation, distributed machine learning, federated learning, multi-modal learning, neural networks, progressive training, privacy-preserving learning.

Despite substantial theoretical advances and practical deployments in federated learning, contemporary research trajectories predominantly concentrate on algorithmic sophistication through model architecture heterogeneity

This paper addresses this critical knowledge gap by introducing
Size-Based Adaptive Federated Learning (SAFL)

•

Cross-Modal Performance Taxonomy

•

Integrated Real-Time Monitoring Infrastructure
: Developing end-to-end system, network, and training performance tracking with intelligent adaptive feedback mechanisms

2.1
Framework Architecture

The Size-Based Adaptive Federated Learning (SAFL) framework, illustrated in Figure
1
, introduces a systematic four-layer architecture that fundamentally reorganizes federated learning based on dataset size characteristics. Unlike conventional approaches that treat all participants uniformly, SAFL implements a progressive training strategy that optimizes federated learning effectiveness through data-driven parameter adaptation.

2.1.1
Layer 1: Multi-Modal Dataset Discovery

The foundation layer focuses on comprehensive dataset discovery and profiling across heterogeneous federated clients. Each client maintains multiple datasets spanning seven distinct modalities: vision, text, time series, audio, sensor, medical vision, and multimodal data. The framework systematically profiles each dataset according to:

\mathcal{P}_{i}=(n_{i},m_{i},\mathcal{C}(m_{i}),\mathcal{M}_{req},\mathcal{T}_{est})

where
n_{i}
represents dataset size,
m_{i}
denotes modality type,
\mathcal{C}(m_{i})
quantifies modality complexity,
\mathcal{M}_{req}
estimates memory requirements, and
\mathcal{T}_{est}
provides training time estimates.

The experimental setup demonstrates realistic federated scenarios with three device categories: mobile clients (950 samples), tablet clients (2100 samples), and desktop clients (6500 samples). Each device hosts multiple datasets, emphasizing the multi-modal nature of real-world federated deployments.

2.1.2
Layer 2: Progressive Training Strategy

The core innovation of SAFL lies in its size-based progressive training methodology. Rather than simultaneous training across all clients, the framework implements a systematic smallest-to-largest progression defined by the ordering function:

\sigma:n_{\sigma(1)}\leq n_{\sigma(2)}\leq\ldots\leq n_{\sigma(N)}

This progressive approach enables adaptive parameter selection based on dataset characteristics:

\displaystyle E_{i}

\displaystyle=E_{base}+\text{size\_category}(i)

(1)

\displaystyle B_{i}

\displaystyle=B_{base}\times 2^{\text{size\_category}(i)}

(2)

\displaystyle\eta_{i}

\displaystyle=\eta_{base}\times\alpha^{\text{size\_category}(i)}\times(1-0.2\times\mathcal{C}(m_{i}))

(3)

where
E_{i}
,
B_{i}
, and
\eta_{i}
represent local epochs, batch size, and learning rate respectively, with complexity-aware adjustments based on modality type.

2.1.3
Layer 3: Adaptive Aggregation

The aggregation layer implements intelligent algorithm selection based on modality complexity scores. The framework automatically selects appropriate aggregation methods:

\displaystyle\mathcal{A}(m_{i})=\begin{cases}\text{FedAvg}&\text{if }\mathcal{C}(m_{i})<0.5\\
\text{FedProx}&\text{if }0.5\leq\mathcal{C}(m_{i})<0.7\\
\text{SCAFFOLD}&\text{if }\mathcal{C}(m_{i})\geq 0.7\end{cases}

(4)

This adaptive selection ensures optimal convergence characteristics for different data modalities while maintaining computational efficiency.

2.1.4
Layer 4: Real-Time Monitoring

The monitoring layer provides comprehensive oversight across four critical dimensions: system resources (CPU, memory, GPU utilization), network metrics (bandwidth, latency, throughput), training progress (accuracy, loss, convergence), and performance analysis. This real-time feedback enables dynamic optimization and early intervention when performance degradation occurs.

2.2
Key Innovations

The SAFL framework introduces several fundamental innovations that distinguish it from existing federated learning approaches:

Size-Driven Organization
: The framework is the first to systematically organize federated training based on dataset size characteristics, revealing optimal size ranges (1000-1500 samples) for federated learning effectiveness.

Multi-Modal Integration
: Unlike single-modality approaches, SAFL explicitly handles seven distinct data modalities within a unified framework, establishing clear performance hierarchies and optimization strategies.

Progressive Training Logic
: The smallest-to-largest training progression ensures stable convergence while accommodating heterogeneous computational resources across federated participants.

Adaptive Parameter Selection
: Mathematical formulations enable automatic parameter adjustment based on both dataset size and modality complexity, eliminating manual hyperparameter tuning.

Intelligent Aggregation
: Complexity-aware aggregation method selection optimizes convergence characteristics for different data types without requiring domain expertise.

2.3
Experimental Validation

The framework validation encompasses 13 datasets across 7 modalities, demonstrating several critical findings:

Optimal Size Range
: Datasets containing 1000-1500 samples achieve optimal federated learning performance, with systematic degradation observed for larger datasets exceeding 2000 samples.

Modality Performance Hierarchy
: Clear performance rankings emerge with structured data (medical vision: 100%, time series: 99.9%, sensor: 99.2%) significantly outperforming unstructured data (text: 70.8%, multimodal: 56.5%).

Communication Efficiency
: The framework achieves 87.68% average accuracy while minimizing communication overhead to 7.38 GB across 558 communications with balanced bidirectional data transfer.

Resource Optimization
: Real-time monitoring reveals efficient resource utilization with average CPU usage of 2.1% and memory consumption of 8.7%, demonstrating scalability for resource-constrained environments.

2.4
Practical Implications

The SAFL framework provides actionable guidance for federated learning deployment:

Dataset Sizing Strategy
: Target 1000-1500 samples per client for optimal performance, with larger datasets requiring subdivision or hierarchical federated learning approaches.

Modality Prioritization
: Prioritize structured data modalities for initial federated learning implementations, with specialized approaches needed for text and multimodal applications.

Progressive Deployment
: Implement smallest-to-largest training progression to ensure stable convergence and accommodate heterogeneous client capabilities.

Adaptive Configuration
: Utilize complexity-aware parameter selection to eliminate manual hyperparameter tuning while maintaining optimal performance across diverse modalities.

The framework represents a paradigm shift from algorithm-centric to data-centric federated learning optimization, providing both theoretical insights and practical tools for real-world deployments.

This comprehensive framework overview establishes the foundation for the detailed algorithmic descriptions and experimental validation presented in subsequent sections. The layered architecture ensures systematic progression from data characteristics analysis through adaptive training to performance optimization, addressing fundamental gaps in current federated learning approaches.

4.1
Problem Formulation

Consider a federated learning system with
N
clients, where client
i
possesses a local dataset
\mathcal{D}_{i}
of size
|\mathcal{D}_{i}|=n_{i}
with modality
m_{i}
. The goal is to collaboratively learn a global model
w^{*}
that minimizes the global objective:

w^{*}=\arg\min_{w}F(w)=\sum_{i=1}^{N}\frac{n_{i}}{n}F_{i}(w)

(5)

where
F_{i}(w)=\mathbb{E}_{(x,y)\sim\mathcal{D}_{i}}[\ell(w;x,y)]
is the local objective function,
n=\sum_{i=1}^{N}n_{i}
is the total number of samples, and
\ell(\cdot)
is the loss function.

Traditional federated learning approaches treat all datasets uniformly regardless of their size characteristics. In contrast, SAFL introduces a size-based ordering function
\sigma:\{1,2,\ldots,N\}\rightarrow\{1,2,\ldots,N\}
such that
n_{\sigma(1)}\leq n_{\sigma(2)}\leq\ldots\leq n_{\sigma(N)}
.

6.6
Convergence Analysis

Our comprehensive evaluation reveals distinct convergence patterns across modalities. Structured data modalities (time series, sensor, medical vision) demonstrate rapid convergence within 15-17 rounds, achieving stable high performance. In contrast, text modalities exhibit higher variance and require longer convergence periods.

The size-based progressive training strategy contributes to improved convergence stability by ensuring that smaller, more manageable datasets establish strong initial model foundations before progressing to larger, more complex datasets.

Problem Case Analysis

Two datasets exhibited concerning performance degradation:

•

LargeText_Classification
: 12.3% accuracy - massive failure attributed to size-complexity interaction

•

VisionText_MultiModal
: 56.5% accuracy - multimodal fusion challenges in federated settings

These failures highlight critical limitations in current federated learning approaches for large-scale text and multimodal applications.

7
Discussion

7.1
Key Findings and Implications

Our comprehensive evaluation reveals several critical insights that challenge conventional assumptions about federated learning:

7.1.1
Optimal Dataset Size Range

The identification of an optimal size range (1000-1500 samples) represents a fundamental breakthrough in understanding federated learning dynamics. This finding has immediate practical implications for dataset partitioning strategies and client selection algorithms.

7.1.2
Modality Performance Hierarchy

The clear hierarchy with structured data (time series, sensor, medical vision) significantly outperforming unstructured data (text, multimodal) provides evidence-based guidance for federated learning deployment prioritization.

7.1.3
Scale-Dependent Failure Modes

The systematic performance degradation for datasets exceeding 2000 samples suggests fundamental limitations in current federated learning algorithms that require addressing through specialized approaches for large-scale data.

7.2
Theoretical Implications

Our results suggest that traditional federated learning convergence theory may be insufficient for heterogeneous multi-modal settings. The size-complexity interaction model provides a foundation for developing new theoretical frameworks that account for data characteristics.

7.3
Practical Deployment Guidelines

Based on our findings, we recommend:

•

Dataset Sizing
: Target 1000-1500 samples per client for optimal performance

•

Modality Prioritization
: Prioritize structured data modalities for federated learning applications

•

Large Dataset Handling
: Consider dataset splitting or hierarchical federated learning for datasets exceeding 2000 samples

•

Resource Planning
: Implement load balancing to prevent communication bottlenecks

7.4
Integration with Existing Approaches

SAFL is designed to be compatible with existing federated learning advances:

•

Progressive Training
: Can be combined with architecture-based progressive training for compound benefits

•

Adaptive Aggregation
: Provides data-driven guidance for aggregation method selection

•

Foundation Models
: Size-based insights apply to foundation model federated learning

7.5
Limitations and Future Work

Our study has several limitations that suggest directions for future research:

•

Scale Limitation
: Evaluation limited to datasets up to 2800 samples

•

Architecture Dependency
: Results may vary with different neural network architectures

•

Network Conditions
: Evaluation under single network configuration

•

Client Heterogeneity
: Limited exploration of extreme device heterogeneity

Future work should address these limitations while exploring integration opportunities with emerging federated learning paradigms.

8
Conclusion

This paper introduces Size-Based Adaptive Federated Learning (SAFL), a novel framework that systematically organizes federated training based on dataset size characteristics. Our comprehensive evaluation across 13 datasets spanning 7 modalities reveals critical insights that challenge conventional federated learning assumptions.

Key contributions include: (1) the first systematic size-based progressive training strategy, (2) comprehensive cross-modal performance hierarchy establishment, (3) integrated real-time monitoring framework, (4) size-complexity interaction analysis, and (5) robust experimental methodology.

Our results demonstrate that SAFL achieves 87.68% average accuracy while identifying optimal dataset size ranges (1000-1500 samples) and revealing significant performance hierarchies across modalities. The framework provides both theoretical insights and practical guidance for real-world federated learning deployments.

SAFL represents a paradigm shift in federated learning research by focusing on data characteristics rather than solely on algorithmic improvements. This work opens new research directions for adaptive federated learning while providing immediate value for practitioners deploying federated systems.

Future work will explore integration with foundation models, theoretical convergence analysis, and scaling to million-sample datasets while maintaining the practical insights demonstrated in this comprehensive study.
