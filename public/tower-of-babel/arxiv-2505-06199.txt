On Optimal Batch Size in Coded Computing
Swapnil Saha, Emina Soljanin, Philip Whiting

Abstract
We consider computing systems that partition jobs into tasks, add redundancy through coding, and assign the encoded tasks to different computing nodes for parallel execution. The expected execution time depends on the level of redundancy. The computing nodes execute large jobs in batches of tasks. We show that the expected execution time depends on the batch size as well. The optimal batch size that minimizes the execution time depends on the level of redundancy under a fixed number of parallel servers and other system parameters. Furthermore, we show how to (jointly) optimize the redundancy level and batch size to reduce the expected job completion time for two service-time distributions. The simulation presented helps us appreciate the claims.

We assume the job can be split into tasks up to some minimum task size. We refer to the minimum task size as

Erasure Coding Model:

To create redundant tasks, the job of size

Performance Metric: Job Completion Time

\mathchoice{\mathop{}\kern 4.65245pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}{\mathop{}\kern 4.65245pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}{\mathop{}\kern 4.18231pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}{\mathop{}\kern 4.18231pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}Y^{b}_{i}
. The batch generation completion time is then equal to the

-th fastest worker’s batch task completion time, denoted as
\mathchoice{\mathop{}\kern 4.65245pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}{\mathop{}\kern 4.65245pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}{\mathop{}\kern 4.18231pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}{\mathop{}\kern 4.18231pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}Y^{b}_{k:n}
. Mathematically,
\mathchoice{\mathop{}\kern 4.65245pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}{\mathop{}\kern 4.65245pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}{\mathop{}\kern 4.18231pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}{\mathop{}\kern 4.18231pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}Y^{b}_{k:n}
represents the

\mathchoice{\mathop{}\kern 6.72598pt\mathopen{\vphantom{Y}}^{\mathmakebox[0pt][l]{\mathmakebox[r]{G}}}}{\mathop{}\kern 6.72598pt\mathopen{\vphantom{Y}}^{\mathmakebox[0pt][l]{\mathmakebox[r]{G}}}}{\mathop{}\kern 8.30956pt\mathopen{\vphantom{Y}}^{\mathmakebox[0pt][l]{\mathmakebox[r]{G}}}}{\mathop{}\kern 9.32375pt\mathopen{\vphantom{Y}}^{\mathmakebox[0pt][l]{\mathmakebox[r]{G}}}}Y^{b}_{k:n}

\mathchoice{\mathop{}\kern 6.72598pt\mathopen{\vphantom{Y}}^{\mathmakebox[0pt][l]{\mathmakebox[r]{G}}}}{\mathop{}\kern 6.72598pt\mathopen{\vphantom{Y}}^{\mathmakebox[0pt][l]{\mathmakebox[r]{G}}}}{\mathop{}\kern 8.30956pt\mathopen{\vphantom{Y}}^{\mathmakebox[0pt][l]{\mathmakebox[r]{G}}}}{\mathop{}\kern 9.32375pt\mathopen{\vphantom{Y}}^{\mathmakebox[0pt][l]{\mathmakebox[r]{G}}}}Y^{b}_{k:n}=\sum_{g=1}^{G}\mathchoice{\mathop{}\kern 4.65245pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}{\mathop{}\kern 4.65245pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}{\mathop{}\kern 4.18231pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}{\mathop{}\kern 4.18231pt\mathopen{\vphantom{Y}}_{\mathmakebox[0pt][r]{g}}}Y^{b}_{k:n}
. Since every batch generation is executed independently, the expected job completion time can be expressed as:

\displaystyle\mathbb{E}\left[\mathchoice{\mathop{}\kern 6.72598pt\mathopen{\vphantom{Y}}^{\mathmakebox[0pt][l]{\mathmakebox[r]{G}}}}{\mathop{}\kern 6.72598pt\mathopen{\vphantom{Y}}^{\mathmakebox[0pt][l]{\mathmakebox[r]{G}}}}{\mathop{}\kern 8.30956pt\mathopen{\vphantom{Y}}^{\mathmakebox[0pt][l]{\mathmakebox[r]{G}}}}{\mathop{}\kern 9.32375pt\mathopen{\vphantom{Y}}^{\mathmakebox[0pt][l]{\mathmakebox[r]{G}}}}Y^{b}_{k:n}\right]=G\mathbb{E}\left[Y^{b}_{k:n}\right]=\frac{l}{Rb}\mathbb{E}\left[Y^{b}_{k:n}\right]
