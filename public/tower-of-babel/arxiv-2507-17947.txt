On ascent sequences avoiding 021 and a pattern of length four
Toufik Mansour

Abstract
Ascent sequences of length n n avoiding the pattern 021 021 are enumerated by the n n -th Catalan number C n = 1 n + 1 ​ ( 2 ​ n n ) C_{n}=\frac{1}{n+1}\binom{2n}{n} . In this paper, we extend this result and enumerate ascent sequences avoiding { 021 , τ } \{021,\tau\} , where τ \tau is a pattern of length four. We in turn identify all of the corresponding Wilf-equivalence classes and find generating function formulas corresponding to each class. In a couple of cases, we make use of an auxiliary statistic and the kernel method to ascertain the generating function. In several cases, our work of enumeration is shortened by establishing the equivalence of { 021 , τ } \{021,\tau\} - and { 021 , τ ′ } \{021,\tau^{\prime}\} -avoiders of a given length through an explicit bijection. As a consequence of our results, one obtains new combinatorial interpretations in terms of ascent sequences for several of the entries in the OEIS.



Keywords:
pattern avoidance, ascent sequence, generating function, bijective proof, kernel method.
