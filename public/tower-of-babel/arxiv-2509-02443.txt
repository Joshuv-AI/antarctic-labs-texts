On the complex moment problem as a dynamic inverse problem for a discrete system


Abstract

Abstract.
We consider the complex moment problem,
that is the problem of constructing a positive Borel measure on

\mathbb{C}
from a given set of moments. We relate this problem
to the dynamic inverse problem for the discrete system associated
with the complex Jacobi matrix. We show how the characterization
of dynamic inverse data in solving the inverse problem provides
sufficient conditions for solving the complex moment problem.

1.
Introduction.

The complex moment problem is: given a set of complex numbers

s_{0},s_{1},s_{2},\ldots
, to find a Borel measure
d\rho
on

\mathbb{C}
such that

(1.1)

s_{k}=\int_{\mathbb{C}}\lambda^{k}\,d\rho(\lambda),\quad k=0,1,2,\ldots.

If such a measure exists
s_{0},s_{1},s_{2},\ldots
are called moments
of this measure. The truncated moment problem is the problem of
finding a measure that satisfies a finite number of moment
equalities (
1.1
) for
k=0,1,\ldots,2N-2
for some

N\in\mathbb{N}
.

For a given sequence of complex numbers
\{a_{1},a_{2},\ldots\}
,

\{b_{1},b_{2},\ldots\}
,
a_{i}\not=0
, we define the complex
Jacobi matrix:

(1.2)

A=\begin{pmatrix}b_{1}&a_{1}&0&0&0&\ldots\\
a_{1}&b_{2}&a_{2}&0&0&\ldots\\
0&a_{2}&b_{3}&a_{3}&0&\ldots\\
\ldots&\ldots&\ldots&\ldots&\ldots&\ldots\end{pmatrix}.

For
N\in\mathbb{N}
, by
A^{N}
we denote the
N\times N
Jacobi
matrix which is a block of (
1.2
) consisting of the
intersection of first
N
columns with first
N
rows of
A
.

Associated with the matrix
A
and additional parameter

\mathbb{C}\ni a_{0}\not=0
is a dynamical system with discrete
time:

(1.3)

\begin{cases}u_{n,t+1}+u_{n,t-1}-a_{n}u_{n+1,t}-a_{n-1}u_{n-1,t}-b_{n}u_{n,t}=0,\quad n,t\in\mathbb{N},\\
u_{n,-1}=u_{n,0}=0,\quad n\in\mathbb{N},\\
u_{0,t}=f_{t},\quad t\in\mathbb{N}\cup\{0\},\end{cases}

which is a discrete analogue of the dynamical systems governed by
a wave equation on the semi-axis
[
1
,
3
]
. By analogy with
the continuous problems
[
2
]
, we consider the complex
sequence
f=(f_{0},f_{1},\ldots)
as a
boundary control
. The
solution to (
1.3
) we denote by
u^{f}_{n,t}
. We also
consider the dynamical system associated with finite matrix
A_{N}
:

(1.4)

\begin{cases}v_{n,t+1}+v_{n,t-1}-a_{n}v_{n+1,t}-a_{n-1}v_{n-1,t}-b_{n}v_{n,t}=0,\,\,t\in\mathbb{N}_{0},\,\,n\in 1,\ldots,N,\\
v_{n,\,-1}=v_{n,\,0}=0,\quad n=1,2,\ldots,N+1,\\
v_{0,\,t}=f_{t},\quad v_{N+1,\,t}=0,\quad t\in\mathbb{N}_{0},\end{cases}

which is a natural analog of the dynamical systems governed by a
wave equation on the interval, the solution to
(
1.4
) is denoted by
v^{f}
.

Fixing
T\in\mathbb{N}
, we associate the
response
operator
with (
1.3
), which maps the control

f=(f_{0},\ldots f_{T-1})
to
u^{f}_{1,t}
:

(1.5)

\left(R^{T}f\right)_{t}:=u^{f}_{1,t},\quad t=1,\ldots,T.

In the second section using the Autonne-Takagi
[
11
]

factorization, we derive a special ”spectral representation” for
the solution of (
1.4
).

In the third section we present results on the dynamic inverse
problem (IP) for the system (
1.3
) in accordance with

[
8
]
. This problems is a natural discrete analogue of the IP
for the wave equation on the half-axis, where the dynamic
Dirichlet to Neumann map is used as inverse data, see
[
2
]
.
The IP for the dynamical system (
1.3
) with real
Jacobi matrix is considered in
[
5
,
6
]
. The connections
between the IP for the system with real Jacobi matrix and
classical moment problems are described in
[
7
,
9
]
. The IP
for the dynamical system with complex Jacobi matrix is considered
in
[
8
]
.

In last section we describe connections between the IPs for
(
1.4
) and (
1.3
) and complex moment
problem and introduce a discrete Borel measure on
\mathbb{C}
,
concentrated on the finite set of point, associated with
(
1.4
), which is a solution to the truncated
complex moment problem. Letting
N
tend to infinity in
(
1.4
) we obtain a sequence of measures that
converges to a solution to the complex moment problem.

Another approach to the complex moment problem was proposed in

[
12
]
, where the author used the generalized spectral
function introduced in
[
4
]
as a basic tool and obtained
sufficient conditions on the moment sequence under the condition
that it is bounded. Note that our method do not require the
boundedness of
s_{k}
,
k\geqslant 0
.

If
H\in C^{n\times n}
then by
H^{*}
we denote the matrix
conjugate to
H
and recall that
H^{*}=\overline{H^{\top}}
, where

H^{\top}
is a transpose of
H
.

2.
Discrete dynamical system. Forward problem, special representation of the solution.

We first derive a special representation (Fourier-type expansion)

representation (Duhamel-type), important for solving the IP
obtained in
[

]

[
11
]

Theorem 1
.

Let
H\in\mathbb{C}^{n\times n}
be a complex symmetric matrix:

H^{*}=\overline{H}
, then there exists a unitary matrix
U
such
that

(2.1)

UHU^{\top}=D=\begin{pmatrix}d_{1}&0&\ldots&0\\
0&d_{2}&\ldots&0\\
\ldots&\ldots&\ldots&\ldots\\
0&0&\ldots&d_{n}\end{pmatrix},

where
d_{i}\geqslant 0,

i=1\ldots,n
.

We apply this theorem for the matrix
A^{N}
: there exist unitary

U^{N}
such that
U^{N}A^{N}\left(U^{N}\right)^{\top}
as in the theorem.
Note that in our case all
d_{i}>0
, since otherwise
A^{N}u=0

implies
\det A^{N}=0
, which in turn implies linear dependence of
some rows or columns of
A^{N}
, which is impossible. At the same
time some of the
d_{i}
can coincide. In the latter case we modify
the unitary matrix as follows: assume for example that
d_{1}=d_{2}
,
then, taking

U_{1}^{N}:=\begin{pmatrix}1&0&\ldots&0\\
0&e^{i\frac{\varphi_{1}}{2}}&\ldots&0\\
\ldots&\ldots&\ldots&\ldots\\
0&0&\ldots&1\end{pmatrix}U^{N},

we obtain that

U_{1}^{N}A^{N}\left(U_{1}^{N}\right)^{\top}=\begin{pmatrix}d_{1}&0&\ldots&0\\
0&d_{2}e^{i\varphi}&\ldots&0\\
\ldots&\ldots&\ldots&\ldots\\
0&0&\ldots&d_{n}\end{pmatrix}.

Using these arguments we can make all
d_{i}
in the representation
(
2.1
) distinct (but some of them can be complex). To
summarize what we did so far, in what follows we choose unitary

U
(we drop
N
) such that

(2.2)

UA^{N}U^{\top}=\begin{pmatrix}d_{1}&0&\ldots&0\\
0&d_{2}&\ldots&0\\
\ldots&\ldots&\ldots&\ldots\\
0&0&\ldots&d_{n}\end{pmatrix},\quad d_{i}\in\mathbb{C}\backslash\{0\},d_{i}\not=d_{j},\,i\not=j,\,i,j=1\ldots,N.

We introduce the vectors

e_{i}=\begin{pmatrix}0\\
\cdot\\
1\\
\cdot\\
0\end{pmatrix},\quad\text{with $1$ on i-th place},i=1,\ldots,N.

Then

UA^{N}U^{\top}e_{i}=d_{i}e_{i},

we multiply the equality above from the left by
U^{*}
and get

A^{N}U^{\top}e_{i}=d_{i}U^{*}e_{i}=d_{i}\overline{U^{\top}}e_{i},

Introducing the notation

U^{\top}=\left(\hat{u}^{1}\,|\,\hat{u}^{2}\,|\,\ldots\,|\,\hat{u}^{N}\right),\quad\hat{u}^{i}=\begin{pmatrix}\hat{u}^{i}_{1}\\
{\hat{u}}^{i}_{2}\\
\ldots\\
{\hat{u}}^{i}_{n}\end{pmatrix}

that is
\hat{u}^{i}
is a column in the matrix
U^{\top}
, we see
that
\hat{u}^{i}
satisfies:

(2.3)

A^{N}\hat{u}^{i}e_{i}=d_{i}\overline{\hat{u}^{i}},\quad A^{N}\begin{pmatrix}\hat{u}^{i}_{1}\\
{\hat{u}}^{i}_{2}\\
\ldots\\
{\hat{u}}^{i}_{n}\end{pmatrix}=d_{i}\begin{pmatrix}\overline{\hat{u}^{i}_{1}}\\
\overline{{u}^{i}_{2}}\\
\ldots\\
\overline{\hat{u}^{i}_{n}}\end{pmatrix}.

Note that the first components of all vectors are non-zero:

\hat{u}^{i}_{1}\not=0,\quad i=1,\ldots,N,

otherwise it immediately follows from (
2.3
)
that
\hat{u}^{i}=0
.

Thus, we can introduce the vectors which we use in the
Fourier-type expansion for the solution to (
1.4
)
in the following way:

u^{i}=\begin{pmatrix}0\\
\frac{\hat{u}^{i}_{1}}{\hat{u}^{i}_{1}}\\
\ldots\\
\frac{\hat{u}^{i}_{N}}{\hat{u}^{i}_{1}}\\
0\end{pmatrix},\quad i=1,\ldots,N,

so we formally add two values:
u^{i}_{0}=u^{i}_{N+1}=0
and normalize
vectors such that
u^{i}_{1}=1
.

We take some vector
(y_{0},y_{1},\ldots y_{N},y_{N+1})
, multiply the
equation in (
1.4
) by
y_{n}
, sum up and change the
order of summation:

\displaystyle 0=\sum_{n=1}^{N}\left(v_{n,t+1}y_{n}+v_{n,t-1}y_{n}-a_{n-1}v_{n,t}y_{n-1}-a_{n}v_{n,t}y_{n+1}-b_{n}v_{n,t}y_{n}\right)

\displaystyle-a_{N}v_{N+1,t}y_{N}-a_{0}v_{0,t}y_{1}+a_{0}v_{1,t}y_{0}+a_{N}v_{N,t}y_{N+1}.

Now we take
\left(y_{0},y_{1},\ldots y_{N},y_{N+1}\right)=\left(u^{i}_{0},u^{i}_{1},\ldots u^{i}_{N},u^{i}_{N+1}\right)
and evaluate counting
u^{i}_{1}=1
and the
values at
n=0
and
n=N+1
:

\displaystyle 0=\sum_{n=1}^{N}\left(v_{n,t+1}u^{i}_{n}+v_{n,t-1}u^{i}_{n}-v_{n,t}\left(a_{n-1}y^{i}_{n-1}+a_{n}vu^{i}_{n+1}+b_{n}u^{i}_{n}\right)\right)-a_{0}v_{0,t}u^{i}_{1}.

Counting (
2.3
) we get:

(2.4)

0=\sum_{n=1}^{N}\left(v_{n,t+1}u^{i}_{n}+v_{n,t-1}u^{i}_{n}-d_{i}v_{n,t}\overline{u^{i}_{n}}\right)-a_{0}f_{t}\quad i=1,\ldots,N.

Now we look for the solution to (
1.4
) in the
form:

(2.5)

v_{n,t}=\begin{cases}\sum_{k=1}^{N}c^{k}_{t}\overline{u^{k}_{n}},\\
f_{t},\quad n=0.\end{cases}

Plugging (
2.5
) into (
2.4
) we have:

(2.6)

\sum_{n=1}^{N}\left(\sum_{k=1}^{N}\left(c_{t+1}^{k}\overline{u^{k}_{n}}+c_{t-1}^{k}\overline{u^{k}_{n}}\right)u_{n}^{i}-d_{i}\sum_{k=1}^{N}c^{k}_{t}\overline{u^{k}_{n}}\overline{u^{i}_{n}}\right)=a_{0}f_{t}.

Introducing the notations

(2.7)

\displaystyle\sum_{n=1}^{N}\overline{u^{k}_{n}}u_{n}^{i}=\delta_{ki}\rho_{i},\quad i=1,\ldots,N,

(2.8)

\displaystyle H_{ki}=\sum_{n=1}^{N}\overline{u^{k}_{n}}\overline{u_{n}^{i}},\quad k,i=1,\ldots,N,

we rewrite (
2.6
) as:

\left(c_{t+1}^{k}+c_{t-1}^{k}\right)\delta_{ki}\rho_{i}-d_{i}\sum_{k=1}^{N}c^{k}_{t}H_{ki}=a_{0}f_{t},\quad t,k,i=1\ldots,N.

So we see that
c^{i}_{t}
are determined from

(2.9)

c_{t+1}^{i}+c_{t-1}^{i}-\frac{d_{i}}{\rho_{i}}\sum_{k=1}^{N}c^{k}_{t}H_{ki}=\frac{a_{0}}{\rho_{i}}f_{t},\quad t,i=1,\ldots,N.

We look for the solution to (
2.9
) in the form:

(2.10)

c_{t}^{i}=\frac{a_{0}}{\rho_{i}}\sum_{l=0}^{t}f_{l}T_{t-l}^{(i)},\quad t,i=1,\ldots,N.

Plugging this representation into (
2.9
) we get:

\frac{a_{0}}{\rho_{i}}\left(\sum_{l=0}^{t}f_{l}T_{t+1-l}^{(i)}+\sum_{l=0}^{t-1}f_{l}T_{t-1-l}^{(i)}-\sum_{k=1}^{N}d_{i}\frac{H_{ki}}{\rho_{k}}\sum_{l=0}^{t}f_{l}T_{t-l}^{(i)}\right)=\frac{a_{0}}{\rho_{i}}f_{t},

changing the order of summation (at this point we use the
additional value
T_{-1}^{(i)}
) we come to

(2.11)

\sum_{l=0}^{t}f_{l}\left(T_{t+1-l}^{(i)}+T_{t-1-l}^{(i)}-\left(\sum_{k=1}^{N}d_{i}\frac{H_{ki}}{\rho_{k}}\right)T_{t-l}^{(i)}\right)+f_{t+1}T_{0}^{(i)}-f_{t}T_{-1}^{(i)}=f_{t}.

We introduce the notation

(2.12)

\omega_{i}=\sum_{k=1}^{N}d_{i}\frac{H_{ki}}{\rho_{k}},\quad i=1,\ldots,N,

then (
2.11
) holds if
T^{(i)}_{t}
satisfies

(2.13)

\begin{cases}T_{t+1}^{(i)}+T_{t-1}^{(i)}-\omega_{i}T_{t}^{(i)}=0,\quad t=0,1\ldots,N,\\
T_{0}^{(i)}=0,\,\,T_{-1}^{(i)}=-1.\end{cases}

Or, in other words,

are simply the Chebyshev
polynomials of the first kind evaluated at points
\omega_{i}
:

T^{(i)}_{t}=T_{t}(\omega_{i})
.
