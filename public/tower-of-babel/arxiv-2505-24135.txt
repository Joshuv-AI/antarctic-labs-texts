Finitely Summable K K -homology, the Index Pairing, and Cantor Minimal Systems
Levi Lorenzo

Abstract
. We study index pairings for crossed-product C ∗ C^{*} -algebras arising from minimal actions on the Cantor set. We utilize Putnam’s orbit-breaking AF-subalgebras and embeddings to show we can compute any index pairing for Cantor minimal system crossed products using Connes’ trace formulas. In the case of odometers, we show that the associated algebras have uniformly finitely summable K K -homology.

1.
Introduction

We investigate index pairings between the
K
-theory and
K
-homology of
C^{*}
-algebras arising from
Cantor minimal systems
. In the analytic model,
K
-homology classes for a
C^{*}
-algebra are represented by
Fredholm modules
. Fredholm modules are required to satisfy certain conditions modulo the compact operators on a Hilbert space. However, when there is a dense
*
-subalgebra of the
C^{*}
-algebra on which these relations hold modulo a Schatten
p
-class, we say the Fredholm module is
p
-summable
on said subalgebra. If a Fredholm module is
p
-summable for some
p<\infty,
we say the Fredholm module is
finitely summable
. When a
K
-homology class has a finitely summable representative, we can use Connes’ trace formulas to compute index pairings between this class and
K
-theory classes generated by elements of (matrices over) the specified subalgebra
[
5
]
. Further, Connes shows that when a Fredholm module is finitely summable over a dense
*
-subalgebra, we can always enlarge the algebra to one whose matrix amplifications contain representatives of every
K
-theory class
[
4
]
.

Thus, if a
C^{*}
-algebra admits a dense subalgebra on which every
K
-homology class can be represented by a Fredholm module that is
p
-summable for some
p,
we can compute the pairing between any
K
-homology class and any
K
-theory class over this
C^{*}
-algebra using a particular trace formula. In this case, we say that the
C^{*}
-algebra admits
uniformly finitely summable
K
-homology
. Uniform finite summability has been studied for various classes of
C^{*}
-algebras by Connes
[
5
]
, Emerson and Nica
[
7
]
, Goffeng and Mesland
[
10
]
, Crisp
[
6
]
, Rave
[
21
]
, Gerontogiannis
[
9
]
, and Puschnigg
[
18
]
.

We study summability and the ability to compute index pairings using Connes’ trace formulas for
C^{*}
-algebras arising from
Cantor minimal systems
. Cantor minimal systems are dynamical systems where
X
is a Cantor set and
\varphi:X\to X
is a minimal homeomorphism. We form a
C^{*}
-algebra associated to this system using the crossed-product construction.

We seek to compute index pairings using Connes’ trace formulas for such algebras. We use novel methods to show that, when
(X,\varphi)
is a Cantor minimal system, we can compute any index pairing for
C(X)\rtimes_{\varphi}\mathbb{Z}
using trace formulas. The main results of this paper are:

Theorem
5.1.6
.

Any index pairing between a class in
K_{0}(C(X)\rtimes_{\varphi}\mathbb{Z})
and one in
K^{0}(C(X)\rtimes_{\varphi}\mathbb{Z})
can be computed using Connes’ trace formula for even cycles with
p>0.

Theorem
5.2.10
.

Let
x\in K^{1}(C(X)\rtimes_{\varphi}\mathbb{Z}).
Pairings of
x
with elements of
\langle[u]\rangle\cong K_{1}(C(X)\rtimes_{\varphi}\mathbb{Z})
can be computed using Connes’ trace formula for odd
p>0
summable cycles.

The even result is achieved using the orbit-breaking AF-algebras and sequences of Putnam
[
19
]
. Given a Cantor minimal system,
(X,\varphi),
Putnam constructs an AF-subalgebra,
A_{\{y\}},
of
C(X)\rtimes_{\varphi}\mathbb{Z}
obtained by “breaking orbits” at a point
y.
Further, Putnam constructs an embedding
\iota:C(X)\rtimes_{\varphi}\mathbb{Z}\to A_{\{y\}},
see Section
3.5
or
[
19
, Chapter 6]
. These embeddings induce isomorphisms on
K_{0}
and, in either order, compose to the identity on
K_{0}.
The UCT allows us to prove the analogous results in
K
-homology and show we can compute index pairings using these embeddings.

In the odd case, we show that, for each element in
\text{Hom}(K_{1}(C(X)\rtimes_{\varphi}\mathbb{Z}),\mathbb{Z})\cong\mathbb{Z},
we can produce a finitely summable odd cycle on
C(X)\rtimes_{\varphi}\mathbb{Z}
whose image in
\text{Hom}(K_{1}(C(X)\rtimes_{\varphi}\mathbb{Z}),\mathbb{Z})
in the UCT exact sequence is this element. Thus, we have produced finitely summable cycles to compute any index map with.

In the case of odometers, we obtain a stronger result. Odometers are precisely the minimal homeomorphisms on the Cantor set that are (metrically) equicontinuous, so we obtain:

Theorem
7.3.3
.

Let
\varphi:X\to X
be a metrically equicontinuous action on the Cantor Set (i.e. an odometer, Proposition
7.1.2
) and also use
\varphi:C(X)\to C(X)
to denote the induced automorphism
f\mapsto f\circ\varphi^{-1}.
Let
\mathscr{A}=\text{span}\{\chi_{C_{\mu}}|\mu\in Y\}.
Then, for every
x\in K^{*}(C(X)\rtimes_{\varphi}\mathbb{Z})
and each
p>1,
there is an unbounded Fredholm module representing
x
that is
p
-summable on
C_{c}(\mathbb{Z},\mathscr{A}).

We obtain this result by taking the bounded cycles of
[
21
, Theorem 4.2.1]
and lifting them to finitely summable unbounded cycles that exhaust
K^{0}(C(X)).
We then use the work of
[
12
]
to take the finitely summable unbounded cycles we constructed to exhaust
K^{0}(C(X))
and extend them to finitely summable unbounded cycles that exhaust
K^{1}(C(X)\rtimes_{\varphi}\mathbb{Z}).

This work suggests alternate approaches to computing index pairings for a
C^{*}
-algebra using Connes’ trace formulas when we have summable cycles related to the algebra but not necessarily a dense subalgebra on which the summability is uniform.

2.1.
Fredholm Modules and
K

The primary reference for analytic
K
-homology is
[
14
]
.
K
-homology classes are represented by
Fredholm modules
. Specifically,
K^{0}
is generated by equivalence classes of
graded
Fredholm modules while
K^{1}
is generated by equivalence classes of
ungraded
Fredholm modules.

Definition 2.1.1
.

Let
A
be a
C^{*}
-algebra. An ungraded
Fredholm module
over
A
is a triple
(H,\rho,F)
where:

•

H
is a separable Hilbert space

•

\rho:A\to B(H)
is a representation

•

F\in B(H)
satisfies:

(1)

(F^{2}-1)\rho(a)\in K(H)
for each
a\in A,

(2)

(F-F^{*})\rho(a)\in K(H)
for each
a\in A,
and

(3)

[F,\rho(a)]\in K(H)
for each
a\in A.

A
graded Fredholm module
is of the form:

(H,\rho,F)=\left(H_{+}\oplus H_{-},\rho_{+}\oplus\rho_{-},\begin{bmatrix}0&V\\
U&0\end{bmatrix}\right)

where
U-V^{*},V-U^{*},UV-1,VU-1\in\mathbb{K}
and
\rho_{+}(a)U-U\rho_{-}(a),V\rho_{-}(a)-\rho_{+}(a)V\in K(H)
for each

-algebras in this thesis, and the

.

For a

-algebra
A
and an action
\alpha\in\text{Aut}(A)
there is a Pimsner-Voiculescu exact sequence in K-homology for the crossed product
A\rtimes_{\varphi}\mathbb{Z}:

2.2.
Spectral Triples and Unbounded Fredholm modules

Some of the Fredholm modules in this paper arise from
spectral triples.

Definition 2.2.1
.

An (odd)
spectral triple
is a triple
(A,H,D)
where:

(1)

H
is a separable Hilbert space,

(2)

A
is a
*
-subalgebra of
B(H),
and

(3)

D
is an unbounded self-adjoint operator in
H
which satisfies, for each
a\in A
:

(a)

a\text{Dom}(D)\subseteq\text{Dom}(D),

(b)

[D,a]\in B(H),
and

(c)

a(1+D^{2})^{-1}\in K(H).

If
H
is equipped with a
\mathbb{Z}/2\mathbb{Z}
grading,
A
is an algebra of even operators, and
D
is odd, then
(A,H,D)
is an even spectral triple.

In the case of a
C^{*}
-algebra, spectral triples determine
unbounded Fredholm modules
:

Definition 2.2.2
.

Suppose
A
is a
C^{*}
-algebra,
\mathscr{A}\subseteq A
is dense, and
(\mathscr{A},H,D)
is a spectral triple. Denote by
\pi
the action of
\mathscr{A}
on
H,

\pi:\mathscr{A}\to B(H).
Then, we denote by
(H,\pi,D)
the
spectral triple
or
unbounded Fredholm module
on
\mathscr{A}
given by
(\mathscr{A},H,D).

There is a notion of summability for spectral triples:

Definition 2.2.3
.

If
A
is unital and
\text{Tr}(1+D^{2})^{-\frac{p}{2}}<\infty,
then
(A,H,D)
is
p-
summable. If such a
p<\infty
exists, we say
(A,H,D)
is finitely summable. The infimum of such
p
is called the
spectral dimension
of
(A,H,D).

Fredholm modules are obtained from spectral triples via the bounded transform:

Proposition 2.2.4
.

Let
A
be a
C^{*}
-algebra. Suppose
A
is represented on a Hilbert Space
H
via
\pi:A\to B(H)
. Further, suppose
\mathscr{A}\subseteq A
is dense and
(\pi(\mathscr{A}),H,D)
is an (even/odd) spectral triple. Then
\left(H,\pi,\frac{D}{(1+D^{2})^{\frac{1}{2}}}\right)
is an (even/odd) Fredholm module over
A,
called the
bounded transform
of
(\pi(\mathscr{A}),H,D).
In the case that
D
is invertible, we can use
D|D|^{-1}
instead of

\frac{D}{(1+D^{2})^{\frac{1}{2}}}.

2.3.
Index Pairings and Summability

Our work concerns the index pairing and circumstances in which we can make it more computable. For a more detailed exposition on index pairings and their formulas see
[
14
]
,
[
5
]
.

Definition 2.3.1
.

Let
A
be a separable
C^{*}
-algebra. Then there is a bilinear map
\langle-,-\rangle_{A}:K_{*}(A)\times K^{*}(A)\to\mathbb{Z}
called the
index pairing
.

The condition on Fredholm modules which facilitates computation of index pairings using trace formulas is
summability
.

Definition 2.3.2
.

An odd (even) Fredholm module
(H,\rho,F)
over a

C^{*}
-algebra
A
is
p
-summable
if there exists a dense sub-algebra
\mathscr{A}\subseteq A
such that, for all
a\in\mathscr{A}:

\rho(a)(F^{2}-1),\>\rho(a)(F-F^{*})\in L^{\frac{p}{2}}(H),\text{ and }[F,\rho(a)]\in L^{p}(H).

Specifically, index pairings with
p
-summable Fredholm modules can be computed using Connes’ trace formulas
[
5
]
:

Proposition 2.3.3
.

Suppose
(H,\rho,F)
is an odd Fredholm module that is
p
-summable over
\mathscr{A}\subseteq A
and
u\in\mathscr{A}
is a unitary. Then,

\langle[u],[H,\rho,F]\rangle=\frac{(-1)^{\frac{n-1}{2}-1}}{2^{n}}\text{Tr}(\rho(u^{*})([F,\rho(u)][F,\rho(u^{*})])^{\frac{n-1}{2}}[F,\rho(u)])

for
n>p
odd.

Proposition 2.3.4
.

Suppose
\left(H_{+}\oplus H_{-},\rho_{+}\oplus\rho_{-},\begin{bmatrix}0&U\\
V&0\end{bmatrix}\right)
is an even Fredholm module that is
p
-summable over
\mathscr{A}\subseteq A
and
p
is a projection in
\mathscr{A}.
Then,

\left\langle[p],\left[H_{+}\oplus H_{-},\rho_{+}\oplus\rho_{-},\begin{bmatrix}0&U\\
V&0\end{bmatrix}\right]\right\rangle=(-1)^{\frac{n(n-1)}{2}}\text{Tr}\left(\begin{bmatrix}1&0\\
0&-1\end{bmatrix}\rho_{+}\oplus\rho_{-}(p)\left(\left[\begin{bmatrix}0&U\\
V&0\end{bmatrix},\rho_{+}\oplus\rho_{-}(p)\right]\right)^{n}\right)

for
n>p
even.

In either case, we can extend these formulas to matrix amplifications over
\mathscr{A}.
Because they are given in terms of a trace, these formulas are often computable. The desire to compute index pairings using trace formulas motivates the study of
uniformly finitely summable

K
-homology:

Definition 2.3.5
.

A
C^{*}
- algebra
A
is said to have
uniformly
p
-summable

K
-homology if for
p>0
there is a dense
*
-subalgebra
\mathscr{A}\subseteq A
such that each class in
K^{*}(A)
(for
*=0
and
1
) can be represented by a Fredholm module which is
p
-summable on
\mathscr{A}.

Proposition 2.3.6
.

If
\mathscr{A}
is a dense
*
-subalgebra of
A
on which
K^{*}(A)
is
p
-summable, then there exists
\mathscr{A}\subseteq\mathcal{A}\subseteq A
where, for each
n,\>M_{n}(\mathscr{A})
is closed under the holomorphic functional calculus in
M_{n}(A)
so that
\iota_{*}:K_{*}(\mathscr{A})\to K_{*}(A)
is an isomorphism, and on which
K^{*}(A)
is
p
-summable
[
5
]
.

Thus, when a
C^{*}
-algebra
A
has uniformly
p
-summable
K
-homology, any index pairing between
K_{*}(A)
and
K^{*}(A)
can be computed via Connes’ trace formulas for
p
-summable Fredholm modules because
\bigcup_{k\in\mathbb{N}}M_{k}(\mathscr{A})
contains a representative of each
K_{*}(A)
class.

2.4.
KK
-Theory and the UCT

The tools of Kasparov’s
KK
-theory will be useful to translate results between
K
-theory and
K
-homology. For a full exposition on
KK
-theory, see
[
15
]
. Note that, for a separable
C^{*}
-algebra
A,\>KK_{*}(\mathbb{C},A)\cong K_{*}(A)
and
KK_{*}(A,\mathbb{C})\cong K^{*}(A).

KK
-theory has an associative product. We utilize a case of this product called the
cap product.

Definition 2.4.1
.

Let
A,B,D
be separable
C^{*}
-algebras. There is an associative product
-\otimes_{B}-:KK(A,B)\times KK(B,D)\to KK(A,D)
called the
cap product
.

Additionally, the index paring is an example of the Kasparov product:

Example 2.4.2
.

Let
x\in K_{*}(A),y\in K^{*}(A).
Then
\langle x,y\rangle_{A}=x\otimes_{A}y\in KK(\mathbb{C},\mathbb{C}).

Example 2.4.3
.

Classes in
KK(A,B)
represent ‘generalized morphisms’ from
A
to
B.
When
\varphi:A\to B
is a
*
-homomorphism,
[\varphi]=[B,\varphi,0]
is a
KK_{0}(A,B)
class. Further, the cap product satisfies:
[\varphi]\otimes_{B}-=\varphi^{*}(-):KK(B,D)\to KK(A,D),
while
-\otimes_{A}[\varphi]=\varphi_{*}(-):KK(D,A)\to KK(D,B),
which we utilize in Section 6.

2.5.
The Universal Coefficient Theorem

The tool we use to obtain results about
K
-homology from results on
K
-theory is the Universal Coefficient Theorem (UCT):

Definition 2.5.1
.

We say that a
C^{*}
-algebra
A

satisfies the UCT
if, for all separable
C^{*}
-algebras
B,
the following sequence is exact:

0\xrightarrow{}\text{Ext}_{\mathbb{Z}}^{1}(K_{*}(A),K_{*}(B))\xrightarrow{\delta}KK_{*}(A,B)\xrightarrow{\gamma}\text{Hom}(K_{*}(A),K_{*}(B))\xrightarrow{}0.

Recall that
\delta
has degree 1 and
\gamma
has degree 0.

All
C^{*}
-algebras in this paper will satisfy the UCT, in particular, AF-algebras do, commutative algebras do, and the property of satisfying the UCT is preserved when taking crossed products by
\mathbb{Z}

[
22
]
.

Definition 2.5.2
.

The map
\gamma
is given by
\gamma(x):=-\otimes_{A}[x]:KK(\mathbb{C},A)\to KK(\mathbb{C},B)
where
x\in KK(A,B).

Thus, in the case of Example
2.4.2
, we obtain:

Proposition 2.5.3
.

If
A
satisfies the UCT,
x\in K_{*}(A),
and
y\in K^{*}(A),
then
\langle x,y\rangle=\gamma(y)(x).

3.
Cantor Minimal Systems

The
C^{*}
-algebras we study in this paper arise from Cantor minimal systems. These are dynamical systems obtained from
minimal homeomorphisms
on the
Cantor set
.

Definition 3.0.1
.

A topological space
X
is called a
Cantor set
if it is a totally disconnected, compact, metrizable space with no isolated points. (There is a unique space with these properties, so we refer to
the
Cantor Set.)

We often use a symbolic representation of the Cantor set.

Example 3.0.2
.

Common models of the Cantor set include
\Omega^{\mathbb{Z}},\Omega^{\mathbb{N}},
or a closed subset of either for a finite set
\Omega.

•

The metric on
\Omega^{\mathbb{Z}}
(or a closed subset of
\Omega^{\mathbb{Z}})
is given by
d((x_{i}),(y_{i}))=2^{-\min\{|j|||x_{j}\neq y_{j}\}}.

•

The metric on
\Omega^{\mathbb{N}}
(or a closed subset of
\Omega^{\mathbb{N}}
) is given by
d((x_{i}),(y_{i}))=2^{-\min\{j||x_{j}\neq y_{j}\}+1}.

This topology can also be given by a basis of clopen sets.

Definition 3.0.3
.

Suppose
X\subseteq\Omega^{\mathbb{Z}}
is a Cantor set. Let
(x_{n})_{n\in\mathbb{Z}}\in X
and
a<b\in\mathbb{Z}.
We denote by
x_{[a,b]}=x_{a}x_{a+1}\cdots x_{b}.
Further
x_{(-\infty,b]}=\ldots x_{b-2}x_{b-1}x_{b}
and
x_{[b,\infty)}=x_{b}x_{b+1}\ldots
will denote the left and right tails of
x
respectively.

Definition 3.0.4
.

For any
x\in X,\>a<b\in\mathbb{Z},\>x_{[a,b]}
will denote a
word
in X. For such a word
\mu=x_{[a,b]},\>|\mu|=b-a+1,
is called the
length
of
\mu.
The empty word, denoted
\epsilon,
is the unique word of length 0.

Definition 3.0.5
.

We denote by
Y
the set of all words in
X:Y=\{x_{[a,b]}|x\in X,a<b\in\mathbb{Z}\}\cup\{\epsilon\}.

Definition 3.0.6
.

If
\mu,\nu\in Y
and
\nu=\mu a_{1}\cdots a_{k}
for
a_{1},\ldots,a_{k}\in\Omega,
we say that
\mu
is a
subword
of
\nu.
Notice that the empty word is a subword of every word in
Y.

Definition 3.0.7
.

For
\mu\in Y,
denote by
C_{\mu}
the
cylinder set defined by
\mu
:

•

If
X\subseteq\Omega^{\mathbb{N}},

C_{\mu}=\{x\in X|x_{[0,|\mu|-1]}=\mu\}.

•

If
X\subseteq\Omega^{\mathbb{Z}},|\mu|
odd:
C_{\mu}=\{x\in X|x_{[-\frac{|\mu|-1}{2},\frac{|\mu|-1}{2}]}=\mu\}.

•

If
X\subseteq\Omega^{\mathbb{Z}},|\mu|
even:
C_{\mu}=\{x\in X|x_{[-\frac{|\mu|-1}{2},\frac{|\mu|}{2}]}=\mu\}.

We collect a few facts below:

Proposition 3.0.8
.

Let
\mu\in Y.

•

In the metric topology, each
C_{\mu}
is clopen.

•

For any closed
X\subseteq\Omega^{\mathbb{Z}}
(or
\Omega^{\mathbb{N}}
), the collection
\{C_{\mu}|\mu\in Y\}
forms a basis for the topology on
X.

•

Further, for each
n,

\mathscr{C}_{n}=\{C_{\mu}|\>|\mu|=n\}
is a partition of
X.

•

These partitions are increasing, in the sense that, for each
m>n,
and each
Z\in\mathscr{C}_{m},
there is a
Z^{\prime}\in\mathscr{C}_{n}
such that
Z\subseteq Z^{\prime}.

Proposition 3.0.9
.

If
X
is the Cantor set,

K_{0}(C(X))\cong C(X,\mathbb{Z})\cong\text{span}\{\chi_{E}|E\text{ clopen }\subseteq X\},\>\>K_{1}(C(X))\cong\{0\}.

Thus, by the UCT

K^{0}(C(X))\cong\text{Hom}(C(X,\mathbb{Z}),\mathbb{Z}),\>\>K_{1}(C(X))\cong 0,

for example, see
[
19
]
or
[
1
]
.

3.1.
Odometers

Odometers are a particularly nice class of Cantor minimal systems. We can associate an odometer to each sequence of integers,
\{d_{i}\}_{i=1}^{\infty},d_{i}\geq 2

[
19
]
.

Definition 3.1.1
.

We let
X=\prod_{i=1}^{\infty}X_{i}
where
X_{i}=\{0,1,\ldots,d_{i}-1\}
and define
\varphi:X\to X
as follows. First,
\varphi(d_{1}-1,d_{2}-1,\ldots,d_{n}-1,\ldots)=(0,0,0,\ldots).
Now, suppose
(x_{1},x_{2},\ldots)\in X
where for some
j,x_{j}\neq d_{j}-1.
Then define
k=\min\{j|x_{j}\neq d_{j}-1\}
and
\varphi(x_{1},x_{2},\ldots)=(0,\ldots,0,x_{k}+1,x_{k+1},x_{k+2},\ldots),
i.e.
\varphi
acts on
X
via “add
(1,0,0,\ldots)
with carry.”

Definition 3.1.2
.

The topology on
X
is induced by a metric
d:X\times X\to\mathbb{R}_{\geq 0}.
The metric is defined by
d((x_{i}),(y_{i}))=2^{-\min\{j|x_{j}\neq y_{j}\}+1}.

This topology makes
X
into a Cantor set and makes
\varphi
a minimal homeomorphism.

3.2.
Ordered Bratteli diagrams and Bratteli-Vershik Systems

Bratteli diagrams (and their associated Bratteli-Vershik systems) are a valuable tool for studying Cantor minimal systems. For further details on such systems see
[
13
]
,
[
20
]
. In particular, every Cantor minimal system is conjugate to a Bratteli-Vershik system associated to a
properly ordered Bratteli diagram

[
13
, Theorem 4.6]
.

Definition 3.2.1
.

A
Bratteli diagram

(V,E)
consists of a set of vertices
V=\bigsqcup_{n=0}^{\infty}V_{n},
a set of edges
E=\bigsqcup_{n=1}^{\infty}E_{n},
and maps
s:E_{n}\to V_{n-1},r:E_{n}\to V_{n},
called the
range
and
source
maps. Moreover,
V_{n}
and
E_{n}
are finite non-empty disjoint sets and
V_{0}=\{v_{0}\}
is a one-point set.

Each edge
e_{n}\in E_{n}
connects the vertex
s(e_{n})\in V_{n-1}
to the vertex
r(e_{n})\in V_{n}.
We assume that
s^{-1}(v)\neq\emptyset
for all
v\in V
and
r^{-1}(v)\neq\emptyset
for all
v\not\in V_{0}.

Definition 3.2.2
.

If
|V_{n-1}|=k_{n-1},|V_{n}|=k_{n},
then

can be described by a

4.
Index Computations and Embeddings

In this section, we show how, in the absence of a dense subalgebra on which we have finite summability, we can use embeddings into

We also show we can exhaust any index pairing so long as we have enough cycles to surject onto the Hom-term in the UCT. We apply this result to Cantor minimal systems in the odd case in the next section.

4.2.
Index Pairings and the UCT

The next result shows that, for any
K
-homology class over a
C^{*}
-algebra that satisfies the UCT, one can compute index pairings with this class by computing with any other class that has the same image under
\gamma:KK(A,\mathbb{C})\to\text{Hom}(K_{*}(A),K_{*}(\mathbb{C})).

Lemma 4.2.1
.

Let
A
be in the UCT class. Let
x\in K^{*}(A).
Then, for any
z\in K^{*}(A)
such that
\gamma(z)=\gamma(x)
and any
y\in K_{*}(A),

\langle z,y\rangle=\langle x,y\rangle.

Proof.

For
x\in K^{*}(A),y\in K_{*}(A)

\gamma(x)(y)=x\otimes_{A}y=\langle x,y\rangle.

Thus, if
\gamma(x)=\gamma(z),\>\langle x,y\rangle=\gamma(x)(y)=\gamma(z)(y)=\langle z,y\rangle.

∎

Corollary 4.2.2
.

Let
x\in K^{*}(A).
Suppose there is a
z\in K^{*}(A)
and
\mathscr{A}\subseteq A
such that
z
is
p
-summable on
\mathscr{A}
and
\gamma(x)=\gamma(z).
Then pairings of
x
with
K_{*}(A)
classes represented by elements in
\mathscr{A}
can be computed using one of Connes’ trace formulas for
p
-summable cycles.

Proof.

Pairings with
z
and
K_{*}(A)
classes represented by elements in
\mathscr{A}
can be computed using Connes’ trace formula for
p
-summable cycles. By Lemma
4.2.1
, this pairing equals the pairing of this
K_{*}(A)
class with
z.

∎

K^{1},
we see that
K^{1}(A_{\{y\}})\cong\text{Ext}_{\mathbb{Z}}^{1}(K_{0}(A_{\{y\}}),\mathbb{Z}),
while

0\xrightarrow{}K^{1}(A_{\{y\}})\xrightarrow{}K^{1}(C(X)\rtimes_{\varphi}\mathbb{Z})\xrightarrow{}\mathbb{Z}\xrightarrow{}0

is exact. Since this sequences splits (though not naturally),
K^{1}(C(X)\rtimes_{\varphi}\mathbb{Z})\cong K^{1}(A_{\{y\}})\oplus\mathbb{Z}.

∎

5.1.
Even Case

We seek to compute even index pairings for
C(X)\rtimes_{\varphi}\mathbb{Z}
using summable cycles. To do so, we use the orbit-breaking algebra
A_{\{y\}}.
Because we are interested in the cycles representing classes in
K^{0},
we hope to identify a map inducing an isomorphism between
K^{0}(A_{\{y\}})
and
K^{0}(C(X)\rtimes_{\varphi}\mathbb{Z}).
As we would hope, the inclusion has this property:

Lemma 5.1.1
.

The map
\iota^{*}:K^{0}(A_{\{y\}})\to K^{0}(C(X)\rtimes_{\varphi}\mathbb{Z})
is an isomorphism.

Proof.

This is an application of Lemma
4.1.2
, noting that
\iota_{*}:K_{0}(A_{\{y\}})\to K_{0}(C(X)\rtimes_{\varphi}\mathbb{Z})
is an isomorphism and
K_{1}(A_{\{y\}})\cong\{0\},K_{1}(C(X)\rtimes_{\varphi}\mathbb{Z})\cong\mathbb{Z}.

∎

Thus, we can pull back
K
-homology classes along
\iota^{*}
to exhaust
K^{0}(C(X)\rtimes_{\varphi}\mathbb{Z}).
We seek to compute index pairings using these cycles. Towards this end:

Lemma 5.1.2
.

Letting
j:A_{\{y\}}\to C(X)\rtimes_{\varphi}\mathbb{Z}
denote the inclusion and
\iota:C(X)\rtimes_{\varphi}\mathbb{Z}\to A_{\{y\}}
be given by Proposition
3.5.1
. Then
\iota^{*}\circ j^{*}:K^{0}(C(X)\rtimes_{\varphi}\mathbb{Z})\to K^{0}(C(X)\rtimes_{\varphi}\mathbb{Z})
is the identity.

Proof.

This is an application of Lemma
4.1.4
, noting that
K_{1}(A_{\{y\}})\cong\{0\},\>K_{1}(C(X)\rtimes_{\varphi}\mathbb{Z})\cong\mathbb{Z},
and
\iota_{*}\circ j_{*}=\text{id}_{K_{0}(A)}
from
[
19
, proof of Theorem 6.7]
.
∎

Now, we can utilize this result to compute index pairings between the two algebras.

Corollary 5.1.3
.

Let
x\in K_{0}(A_{\{y\}})
and
z\in K^{0}(A_{\{y\}}).
Then

\langle\iota_{*}(x),j^{*}(y)\rangle_{C(X)\rtimes_{\varphi}\mathbb{Z}}=\langle x,y\rangle_{A_{\{y\}}}.

Proof.

This is an application of Lemma
4.1.6
with Lemma
5.1.2
.
∎

Corollary 5.1.4
.

Let
x\in K_{0}(C(X)\rtimes_{\varphi}\mathbb{Z})
and
y\in K^{0}(C(X)\rtimes_{\varphi}\mathbb{Z}).
Then

\langle\iota_{*}(x),j^{*}(y)\rangle_{A_{\{y\}}}=\left\langle x,y\right\rangle_{C(X)\rtimes_{\varphi}\mathbb{Z}}.

Proof.

This is a direct application of Lemma
4.1.6
with Lemma
5.1.2
.
∎

Recall that
K_{0}(C(X)\rtimes_{\varphi}\mathbb{Z})
is generated by equivalence classes of projections in
C(X,\mathbb{Z}).
Further, recall that
\iota_{*}
and
j^{*}
are isomorphisms in degree 0. Thus, we can compute index pairings of classes of projections with even Fredholm modules on
C(X)\rtimes_{\varphi}\mathbb{Z}
by pushing forward projections from
A_{\{y\}}
and pulling back Fredholm modules to
A_{\{y\}}.

Since
A_{\{y\}}
is AF, its
K
-homology is uniformly finitely summable on the union of finite-dimensional algebras dense in it
[
21
, Section 4]
. We seek to use this to apply Corollary
4.1.8
to compute index pairings over
C(X)\rtimes_{\varphi}\mathbb{Z}.
We use the AF-filtration,
A_{\{y\}}=\bigcup_{n}A_{n}
where each
A_{n}=A(Z_{n},P_{n})\cong C^{*}(\{\chi_{E}|E\in P_{n}\},uC_{0}(X-Z_{n}))
for
Z_{n}
clopen and
P_{n}
a partition is finite-dimensional. Then we have:

Lemma 5.1.5
.

Let
\iota:C(X)\rtimes_{\varphi}\mathbb{Z}
be as in Proposition
3.5.1
. Then
\iota^{-1}\left(\bigcup_{n}A_{n}\right)\cap C(X)
is dense in
C(X).
Further, projections in
\iota^{-1}\left(\bigcup_{n}A_{n}\right)
generate
K_{0}(C(X)\rtimes_{\varphi}\mathbb{Z}).

Proof.

Observe that, for each
n,\>A_{n}
contains
\chi_{E}
for each
E\in P_{n}.
By the construction of Proposition
3.5.1
, the sequence of partitions
\{P_{n}\}_{n}
is increasing and its union generates the topology of
X

[
19
]
. Then, by
[
19
, Lemma 6.4]
, if
f
is a function in
\text{span}\{\chi_{E}|\>E\in P_{n}\},\>f
commutes with
w_{m}
for all
m>n,
where the
w_{m}
are unitaries in
A_{m+1}
given in the construction of
[
19
, Chapter 6]
. Thus,

\iota(f)=\lim_{m}(w_{1}^{-1}\cdots w_{m}^{-1}fw_{m}\cdots w_{1})=w_{1}^{-1}\cdots w_{n}^{-1}fw_{n}\cdots w_{1}\in A_{n+1},

as
f\in A_{n+1}
and
w_{i}\in A_{n+1},
for each
1\leq i\leq n.
Thus
\iota\left(\bigcup_{n\in\mathbb{N}}\text{span}\{\chi_{E}|E\in P_{n}\}\right)\subseteq\bigcup_{n\in\mathbb{N}}A_{n}.
Further,
\bigcup_{n\in\mathbb{N}}\text{span}\{\chi_{E}|\>E\in P_{n}\}
is dense in
C(X).
Now, recall that
K^{0}(C(X)\rtimes_{\varphi}\mathbb{Z})=\text{im}(j_{*}(C(X))\cong\ker(1-\alpha_{*})(C(X))
where
j:C(X)\to C(X)\rtimes_{\varphi}\mathbb{Z}
is the inclusion
[
1
]
. Since
K_{0}(C(X))\cong C(X,\mathbb{Z}),
it is generated as a group by
\bigcup_{n\in\mathbb{N}}\text{span}\{\chi_{E}|\>E\in P_{n}\}.
Thus,
K_{0}(C(X)\rtimes_{\varphi}\mathbb{Z})
is generated by the classes of projections in
\iota^{-1}(\bigcup_{n\in\mathbb{N}}A_{n}).

∎

Since
K^{*}(A_{\{y\}})
is uniformly
p
-summable for all
p>0
on
\iota^{-1}(\cup_{n}A_{n})
, by Corollary
4.1.8
, we obtain the following:

Theorem 5.1.6
.

Suppose
(X,\varphi)
is a Cantor minimal system. Then any index pairing between a class in
K_{0}(C(X)\rtimes_{\varphi}\mathbb{Z})
and one in
K^{0}(C(X)\rtimes_{\varphi}\mathbb{Z})
can be computed using Connes’ trace formula for even cycles with
p>0.

Returning to the system of Example
3.2.6
and recalling the embedding of Example
3.5.5
:

Example 5.1.7
.

By
[
13
]
, the dimension group associated to
(V,E)
(as in Example
3.2.6
) is

K_{0}(V,E)\cong\varinjlim(\mathbb{Z}^{2}\xrightarrow{S}\mathbb{Z}^{2}\xrightarrow{S}\mathbb{Z}^{2}\cdots)\cong\mathbb{Z}^{2},

since
S
is invertible over
\mathbb{Z}.
Then, by
[
13
, Theorem 5.4(2)]
,
K_{0}(C(X)\rtimes_{\varphi}\mathbb{Z})\cong\mathbb{Z}^{2},
and
[

,
K_{1}(C(X)\rtimes_{\varphi}\mathbb{Z})\cong\mathbb{Z}.
Since
K_{0},K_{1}
are free abelian, the UCT gives that
K^{0}(C(X)\rtimes_{\varphi}\mathbb{Z})\cong K_{0}(C(X)\rtimes_{\varphi}\mathbb{Z})\cong\mathbb{Z}^{2},\>K^{1}(C(X)\rtimes_{\varphi}\mathbb{Z})\cong K^{1}(C(X)\rtimes_{\varphi}\mathbb{Z})\cong\mathbb{Z}.
Now, denote elements of
A_{\{y\}}
(with AF-filtration as in Example
3.5.5
) by
[a,b,c]
where

In this notation,

indicates the level of the filtration. Then
K_{0}(C(X)\rtimes_{\varphi}\mathbb{Z})
is generated by
\left[\begin{bmatrix}1&0&0&0&0\\

\left[0,\begin{bmatrix}1&0&0\\

That is,
K_{0}
is generated by the equivalence classes of the upper left projections in each coordinate in the 1st level of the filtration. Then
K^{0}(C(X)\rtimes_{\varphi}\mathbb{Z})
is generated by the classes of the Fredholm modules which pair to

with one generator and
0
to the other. We can construct such generators using the technique of
[

. For example, we can define Fredholm modules of the form
\left(H\oplus H,\varphi_{1}\oplus\varphi_{2},\begin{bmatrix}0&1\\

Then
\iota^{*}\left(H\oplus H,\varphi_{1}\oplus\varphi_{2},\begin{bmatrix}0&1\\

is
p
-summable for all
p>0
on

and

\left\langle j_{*}([p]),\iota^{*}\left(\left[\varphi_{1}\oplus\varphi_{2},\begin{bmatrix}0&1\\

1&0\end{bmatrix}\right]\right\rangle

for each

We can use these embeddings and Theorem
4.1.1
to compute index pairings between elements of
K_{0}(C(X)\rtimes_{\varphi}\mathbb{Z})
and
K^{0}(C(X)\rtimes_{\varphi}\mathbb{Z})
using Connes’ trace formulas.
