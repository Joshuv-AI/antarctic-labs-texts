Abstract
Kernel matrices are ubiquitous in computational mathematics, often arising from applications in machine learning and scientific computing. In two or three spatial or feature dimensions, such problems can be approximated efficiently by a class of matrices known as hierarchical matrices. A hierarchical matrix consists of a hierarchy of small near-field blocks (or sub-matrices) stored in a dense format and large far-field blocks approximated by low-rank matrices. Standard methods for forming hierarchical matrices do not account for the fact that kernel matrices depend on specific hyperparameters; for example, in the context of Gaussian processes, hyperparameters must be optimized over a fixed parameter space. We introduce a new class of hierarchical matrices, namely, parametric (parameter-dependent) hierarchical matrices. Members of this new class are parametric ℋ \mathcal{H} -matrices and parametric ℋ 2 \mathcal{H}^{2} -matrices. The construction of a parametric hierarchical matrix follows an offline-online paradigm. In the offline stage, the near-field and far-field blocks are approximated by using polynomial approximation and tensor compression. In the online stage, for a particular hyperparameter, the parametric hierarchical matrix is instantiated efficiently as a standard hierarchical matrix. The asymptotic costs for storage and computation in the offline stage are comparable to the corresponding standard approaches of forming a hierarchical matrix. However, the online stage of our approach requires no new kernel evaluations, and the far-field blocks can be computed more efficiently than standard approaches. Numerical experiments show over 100 × 100\times speedups compared with existing techniques.

Introduction

Kernel matrices are defined by a kernel function and a set of points, and the entries of these matrices are formed by pairwise kernel evaluations. They arise in a wide variety of applications, including integral equations, n-body computations, Gaussian processes (GPs), and inverse problems. A central computational bottleneck in dealing with kernel matrices is that they are typically dense. The cost of explicitly storing a dense
n\times n
matrix is
n^{2}
storage units, and the cost of a matrix-vector multiplication (or MVM) is
\mathcal{O}(n^{2})
floating-point operations (or FLOPs). This is computationally challenging, or even prohibitively expensive, if
n\gg 10^{4}
. A range of techniques has been developed for approximating kernel matrices, including low-rank techniques
[
36
,
40
,
11
]
, the fast multipole method (FMM)
[
17
]
, the black-box fast multipole method (BBFMM)
[
13
]
, hierarchical matrices
[
3
,
25
,
1
]
, and the nonuniform fast Fourier transforms
[
18
]
.
We note that the FMM is designed for certain kernels, while the other previously stated methods are black-box with regard to kernel choice. A more general treatment of matrices with hierarchical-like structure is given in
[
1
]
. In this work, we focus on hierarchical matrices, particularly the
\mathcal{H}
-matrix
[
24
,
23
]
and
\mathcal{H}^{2}
-matrix formats
[
21
]
. To summarize, a hierarchical matrix consists of a hierarchy of small near-field blocks (or sub-matrices) stored in a dense format and large far-field blocks approximated by low-rank matrices.

In many applications, the kernel depends on certain parameters, which we call hyperparameters. For example, in GPs and Bayesian inverse problems, in order to estimate the hyperparameters from the data, an optimization problem is solved (e.g., maximum likelihood or marginalized maximum a posteriori estimation), which requires repeatedly forming the kernel matrices for a range of parameters. Even though existing techniques for handling kernel matrices have linear or log-linear complexity in
n
, for each hyperparameter evaluation the approximations must be computed from “scratch,” which is computationally expensive. Thus, methods are needed that can efficiently approximate and store kernel matrices, not only for a single hyperparameter, but also for multiple hyperparameters.

For a formal definition, let
X=(\boldsymbol{x}_{i})_{i=1}^{n}
be a sequence of points where
\boldsymbol{x}_{i}\in\mathbb{R}^{d}
for
1\leq i\leq n
. A parametric kernel function is a function of type
\kappa:\mathbb{R}^{d}\times\mathbb{R}^{d}\times\Theta\rightarrow\mathbb{R}
, where
\Theta\subset\mathbb{R}^{d_{\theta}}
is the parameter space. For a parameter
\boldsymbol{\theta}\in\Theta
, the parametric kernel matrix
\boldsymbol{K}(X,X;\boldsymbol{\theta})\in\mathbb{R}^{n\times n}
is defined by the entries

[\boldsymbol{K}(X,X,\boldsymbol{\theta})]_{i,j}=\kappa(\boldsymbol{x}_{i},\boldsymbol{x}_{j};\boldsymbol{\theta}),\quad\quad 1\leq i\leq n,1\leq j\leq n.

Note that for a fixed parameter
\bar{\boldsymbol{\theta}}\in\Theta
, the function
\kappa(\cdot,\cdot,\bar{\boldsymbol{\theta}})
is a kernel function, and the matrix
\boldsymbol{K}({X},{X};\bar{\boldsymbol{\theta}})
is a kernel matrix.

We assume that the points in
X
are enclosed in a
d
-dimensional hypercube
B=\times_{i=1}^{d}[\alpha,\beta]
, where
\times_{i=1}^{d}
represents the iterated Cartesian product, and that

d_{\theta}

. In the context of the applications we consider, the spatial dimension

\kappa(\boldsymbol{x},\boldsymbol{y};\boldsymbol{\theta})=f_{\boldsymbol{\theta}}(\|\boldsymbol{x}-\boldsymbol{y}\|_{2})
for some parametric function
f_{\boldsymbol{\theta}}
. We also define the total dimension
\Delta
as the sum of the spatial dimensions and the parameter dimensions, that is,

\Delta=2d+d_{\theta}.

In the standard approach, a new hierarchical matrix approximation has to be constructed for each instance of the hyperparameter, and these methods can have optimal complexity with respect to
n

\Theta

\mathcal{O}(n\log(n))

where

Note, we will consider certain prefactor terms in the more detailed complexity estimates later in the paper.

Background

2.1
Tensor and Tensor Train Decomposition

Tensor
\boldsymbol{\mathcal{X}}\in\mathbb{R}^{m_{1}\times m_{2}\cdots\times m_{q}}
, where
q\in\mathbb{N}
, is defined to be a multidimensional array. Selecting the
(i_{1},i_{2},\dots,i_{q})
element of the tensor
\boldsymbol{\mathcal{X}}
is represented by
[\boldsymbol{\mathcal{X}}]_{i_{1},i_{2},\dots,i_{q}}
or
x_{i_{1},i_{2},\dots,i_{q}}
. In this paper, the Chebyshev norm is the only tensor-based norm that will be used, and it is defined as
\|\boldsymbol{\mathcal{X}}\|_{C}=\max_{i_{1},\dots,i_{q}}|[\boldsymbol{\mathcal{X}}]_{i_{1},i_{2},\dots,i_{q}}|.

Reshape Command

Let
(i_{1},i_{2},\ldots,i_{j})
be an arbitrary multi-index for
1\leq j\leq q
, where
1\leq i_{j}\leq m_{j}
. We denote the index
\overline{i_{1}i_{2}\cdots i_{j}}\in\mathbb{N}
to be the little endian flattening of the multi-index into a single index defined by the formula

\overline{i_{1}i_{2}\cdots i_{j}}=i_{1}+(i_{2}-1)m_{1}+(i_{3}-1)m_{1}m_{2}+\cdots+(i_{j}-1)m_{1}m_{2}\cdots m_{j-1}.

We denote
reshape
to be the MATLAB reshape command. For example, if
\boldsymbol{\mathcal{Y}}=\text{reshape}(\boldsymbol{\mathcal{X}},[m_{1},m_{2},m_{3},m_{4},\dots,m_{q}])
, then
\boldsymbol{\mathcal{Y}}\in\mathbb{R}^{m_{1}m_{2}\times m_{3}\times m_{4}\times\cdots\times m_{q}}
with entries

[\boldsymbol{\mathcal{Y}}]_{\overline{i_{1}i_{2}},i_{3},i_{4},\dots,i_{q}}=[\boldsymbol{\mathcal{X}}]_{i_{1},i_{2},\dots,i_{q}},\qquad 1\leq t\leq q,~1\leq i_{t}\leq m_{t}.

For integer
1\leq j\leq q
, another case of interest is
\boldsymbol{\mathcal{Y}}=\text{reshape}(\boldsymbol{\mathcal{X}},[\prod_{i=1}^{j}m_{i},\prod_{i=j+1}^{q}m_{i}])
, where
\boldsymbol{\mathcal{Y}}\in\mathbb{R}^{m_{1}m_{2}\cdots m_{j}\times m_{j+1}m_{j+2}\cdots m_{q}}
has entries

\boldsymbol{\mathcal{Y}}_{\overline{i_{1}i_{2}\dots i_{j}},\overline{i_{j+1}i_{j+2}\dots i_{q}}}=[\boldsymbol{\mathcal{X}}]_{i_{1},i_{2},\cdots,i_{q}},\qquad 1\leq i_{t}\leq m_{t}.

Mode-k Product

For a matrix
\boldsymbol{A}\in\mathbb{R}^{m\times m_{k}}
, one can define the mode-
k
product of
\boldsymbol{\mathcal{X}}
w.r.t.
\boldsymbol{A}
as

\boldsymbol{\mathcal{Y}}=\boldsymbol{\mathcal{X}}\times_{k}\boldsymbol{A}
, where the tensor
\boldsymbol{\mathcal{Y}}
has entries

y_{i_{1},\dots,i_{k-1},j,i_{k+1},\dots,i_{N}}=\sum^{m_{k}}_{i_{k}=1}x_{i_{1},\dots,i_{d}}[\boldsymbol{A}]_{j,i_{k}},\qquad 1\leq j\leq m.

Tensor Train Decomposition

The tensor train (TT) format was first introduced in
[
33
]
. The tensor
\boldsymbol{\mathcal{X}}
admits a TT-decomposition if it can be represented by a sequence of third-order tensors
\boldsymbol{\mathcal{G}}_{1},\dots,\boldsymbol{\mathcal{G}}_{q}
, where
\boldsymbol{\mathcal{G}}_{j}\in\mathbb{R}^{r_{j-1}\times m_{j}\times r_{j}}
for
1\leq j\leq q
is referred to as the TT-cores and
r_{0},\dots,r_{q}
as the TT-ranks (with the convention
r_{0}=r_{q}=1
). The entries of the tensor
\boldsymbol{\mathcal{X}}
are given by the formula

[\boldsymbol{\mathcal{X}}]_{i_{1},\dots,i_{q}}=\sum^{r_{1}}_{s_{1}=1}\dots\sum^{r_{q-1}}_{s_{q-1}=1}[\boldsymbol{\mathcal{G}}_{1}]_{1,i_{1},s_{1}}[\boldsymbol{\mathcal{G}}_{2}]_{s_{1},i_{2},s_{2}}\cdots[\boldsymbol{\mathcal{G}}_{q}]_{s_{q-1},i_{q},1},

where
1\leq j\leq q,~1\leq i_{j}\leq m_{j}
.
If
\boldsymbol{\mathcal{X}}
admits a TT-decomposition, then we denote it as

\boldsymbol{\mathcal{X}}=[\boldsymbol{\mathcal{G}}_{1},\boldsymbol{\mathcal{G}}_{2},\dots,\boldsymbol{\mathcal{G}}_{q}].

Often, the tensor
\boldsymbol{\mathcal{X}}
does not admit an exact TT-decomposition with small TT-ranks. We can obtain an approximation of
\boldsymbol{\mathcal{X}}
in the TT format using either the TT-SVD algorithm (see Algorithm 1 in
[
33
]
) or a variant of TT-cross
[
34
,
37
]
. The TT-SVD algorithm can be cost-prohibitive if the tensor is large; hence, in this paper, we use a variant of Algorithm 2 from
[
37
]
. The algorithm applies partially pivoted adaptive cross approximation (for example, Algorithm A.1 in
[
27
]
) to each of the super cores. Thus, the computational cost (in FLOPs) of the algorithm and the number of evaluations of tensor entries are

\mathcal{O}\!\Big(r^{2}(m_{1}+m_{q})+r^{3}\sum_{i=2}^{q-1}m_{i}\Big),\quad\mathcal{O}\!\Big(r(m_{1}+m_{q})+r^{2}\sum_{i=2}^{q-1}m_{i}\Big),

respectively, where
r=\max_{1\leq i\leq q}r_{i}
. The algorithm employs heuristics in order to estimate the relative error of the approximation
\widehat{\boldsymbol{\mathcal{X}}}
in the Chebyshev norm. In particular, we use Algorithm A.2 in
[
27
]
without line 1, since we initialize the cross approximation with a single index. In practice, we apply TT-rounding (Algorithm 2 in
[
33
]
) to
\widehat{\boldsymbol{\mathcal{X}}}
if it is obtained by using TT-cross. For ease of presentation, we will assume that no TT-rank reduction occurs during the TT-rounding algorithm.

Reshape Formula

Assume that
\boldsymbol{\mathcal{X}}
admits a TT-decomposition.
For a TT-core
\boldsymbol{\mathcal{G}}_{i}\in\mathbb{R}^{r_{i-1}\times m_{i}\times r_{i}}
, where
1\leq i\leq q
, the following notations are defined:

\boldsymbol{G}_{i}^{\{1\}}:=\text{reshape}(\boldsymbol{\mathcal{G}}_{i},[r_{i-1},m_{i}r_{i}]),~~\boldsymbol{G}_{i}^{\{2\}}:=\text{reshape}(\boldsymbol{\mathcal{G}}_{i},[r_{i-1}\cdot m_{i},r_{i}]).

Define the

\eta_{1}^{(B_{\sigma,1})}<\eta_{2}^{(B_{\sigma,1})}<\cdots<\eta_{p-1}^{(B_{\sigma,1})}<\eta_{p}^{(B_{\sigma,1})}.

\ell_{k}^{(B_{\sigma,1})}(x)=\prod_{\begin{subarray}{c}1\leq i\leq p\\
i\neq k\end{subarray}}\frac{x-\eta_{i}^{(B_{\sigma,1})}}{\eta_{k}^{(B_{\sigma,1})}-\eta_{i}^{(B_{\sigma,1})}}.

Repeat the same procedure for intervals
B_{\sigma,2},B_{\sigma,3},\dots,B_{\sigma,d}
, and construct their corresponding Chebyshev nodes and Lagrange polynomials. For the hypercube
B_{\sigma}
, we define the multidimensional Chebyshev nodes and Lagrange polynomials with the following formulas:

\displaystyle\boldsymbol{\eta}^{(B_{s})}_{\boldsymbol{\imath}}=

\displaystyle(\eta^{(B_{\sigma,1})}_{\imath_{1}},\eta^{(B_{\sigma,2})}_{\imath_{2}},\dots,\eta^{(B_{\sigma,d})}_{\imath_{d}}),

\displaystyle\Lambda_{\boldsymbol{\imath}}^{(B_{s})}(\boldsymbol{x})=

\displaystyle\ell_{\imath_{1}}^{(B_{\sigma,1})}(x_{1})\ell_{\imath_{2}}^{(B_{\sigma,2})}(x_{2})\cdots\ell_{\imath_{d}}^{{(B_{\sigma,d})}}(x_{d}),

where
\boldsymbol{x}\in B_{\sigma}
and
\boldsymbol{\imath}\in\{1,2,\dots,p_{s}\}^{d}
. For conciseness, denote
[k]^{d}=\{1,2,\dots,k\}^{d}
such that
k\in\mathbb{N}
.
Repeat the same procedures for the hypercubes
B_{\tau}
and
B_{\theta}
, and construct their corresponding multidimensional Lagrange polynomials and Chebyshev nodes, using
p_{s}
Chebyshev nodes for the hypercube
B_{\tau}
and
p_{\theta}
Chebyshev nodes for the hypercube
B_{\theta}
.

We can now define the multidimensional interpolants of
\kappa
that will be used in this paper. Let
\boldsymbol{x}\in B_{\sigma},\boldsymbol{y}\in B_{\tau}
, and
\boldsymbol{\theta}\in B_{\theta}
. The first formula interpolates in all three variables (
\boldsymbol{x}
,
\boldsymbol{y}
, and
\boldsymbol{\theta}

\displaystyle\phi^{(\sigma\times\tau)}(\boldsymbol{x},\boldsymbol{y};\boldsymbol{\theta})

\displaystyle=\sum_{\boldsymbol{\imath}\in[p_{s}]^{d}}\sum_{\boldsymbol{k}\in[p_{\theta}]^{d_{\theta}}}\sum_{\boldsymbol{\jmath}\in[p_{s}]^{d}}\kappa(\boldsymbol{\eta}^{(B_{\sigma})}_{\boldsymbol{\imath}},\boldsymbol{\eta}^{(B_{\tau})}_{\boldsymbol{\jmath}};\boldsymbol{\eta}_{\boldsymbol{k}}^{(B_{\theta})})

\displaystyle\quad\times\Lambda_{\boldsymbol{\imath}}^{(B_{\sigma})}(\boldsymbol{x})\,\Lambda^{(B_{\theta})}_{\boldsymbol{k}}(\boldsymbol{\theta})\,\Lambda_{\boldsymbol{\jmath}}^{(B_{\tau})}(\boldsymbol{y}).

(2)

The second formula interpolates only in the spatial variables (
\boldsymbol{x}
and
\boldsymbol{y}

\varphi^{(\sigma\times\tau)}(\boldsymbol{x},\boldsymbol{y};\boldsymbol{\theta})=\sum_{\boldsymbol{\imath}\in[p_{s}]^{d}}\sum_{\boldsymbol{\jmath}\in[p_{s}]^{d}}\kappa(\boldsymbol{\eta}^{(B_{\sigma})}_{\boldsymbol{\imath}},\boldsymbol{\eta}^{(B_{\tau})}_{\boldsymbol{\jmath}};\boldsymbol{\theta})\Lambda_{\boldsymbol{\imath}}^{(B_{s})}(\boldsymbol{x})\Lambda_{\boldsymbol{\jmath}}^{(B_{\tau})}(\boldsymbol{y}).

The third formula interpolates the kernel only in the parameter variables

3.

4.

Level:

5.

Leaf Set:

l=0,1,2
.

Note that we assume that the points
{X}
are uniformly distributed (although not necessarily uniformly spaced) in the hypercube

d=1
, then
x_{i}=\frac{1}{2^{i}}
for

. With these assumptions satisfied, the computational cost of Algorithm

\mathcal{O}(n\log(n))
FLOPs. Note that the tree
\mathcal{T}_{I}
is a
2^{d}
-ary tree and all leaves of the tree are at level

by construction.

Let
\sigma\in\mathcal{T}_{I}
with
\text{level}(\sigma)=l
. Algorithm
6

by dividing it into

hypercubes. Then, since the points in

Hence, all leaf nodes

In practice, for any value of

3.3
Cluster Basis

In this section, we discuss the formation of the cluster basis; the cluster basis plays an important role in constructing parametric hierarchical matrices. Formally, a cluster basis
\{\boldsymbol{U}_{\sigma}\}_{\sigma\in\mathcal{T}_{I}}
is a family of matrices that is indexed by nodes
\sigma\in\mathcal{T}_{I}
.

We will now demonstrate how to construct/instantiate the cluster basis
\{\boldsymbol{U}_{\sigma}\}_{\sigma\in\mathcal{T}_{I}}
. Let
\sigma\in\mathcal{T}_{I}
with the corresponding hypercube
B_{\sigma}=\times_{i=1}^{d}B_{\sigma,i}
. We define the factor matrices
\boldsymbol{U}_{\sigma,1},\boldsymbol{U}_{\sigma,2},\dots,\boldsymbol{U}_{\sigma,d}\in\mathbb{R}^{n_{\sigma}\times p_{s}}
with the following entries:

[\boldsymbol{U}_{\sigma,k}]_{i,j}=\ell_{j}^{(B_{\sigma,k})}([\boldsymbol{x}_{\sigma,i}]_{k}),\quad 1\leq i\leq n_{\sigma},~1\leq k\leq d,~1\leq j\leq p_{s}

where
\ell_{j}^{(B_{\sigma,k})}
is the
p_{s}-1
degree Lagrange polynomial with respect to
B_{\sigma,k}
; for more information, see Section
2.2
.
Now, the cluster basis matrix
\boldsymbol{U}_{\sigma}\in\mathbb{R}^{n_{\sigma}\times p_{s}^{d}}
can be defined in terms of the factor matrices with the formula

\boldsymbol{U}_{\sigma}=(\boldsymbol{U}_{\sigma,d}\ltimes\boldsymbol{U}_{\sigma,d-1}\ltimes\cdots\ltimes\boldsymbol{U}_{\sigma,1}),

where the symbol
\ltimes
denotes the face-splitting product from (
27
). In practice, the cluster basis matrix
\boldsymbol{U}_{\sigma}
is stored implicitly in terms of its factor matrices
\boldsymbol{U}_{\sigma,1},\boldsymbol{U}_{\sigma,2},\dots,\boldsymbol{U}_{\sigma,d}
.

3.5
\mathcal{H}
-matrices

We will now introduce
\mathcal{H}
-matrices. Let
\bar{\boldsymbol{\theta}}\in\Theta
be a fixed parameter.
Denote
\widetilde{\boldsymbol{K}}\in\mathbb{R}^{n\times n}
as a matrix that approximates the kernel matrix
\boldsymbol{K}({X},{X};\bar{\boldsymbol{\theta}})
. For a block cluster
b=\sigma\times\tau\in\mathcal{T}_{I\times I}
, we denote
(\widetilde{\boldsymbol{K}})_{b}\in\mathbb{R}^{n_{\sigma}\times n_{\tau}}
as a submatrix of
\widetilde{\boldsymbol{K}}
, where the rows are selected by
I_{\sigma}
and the columns are selected by
I_{\tau}
. The matrix
\widetilde{\boldsymbol{K}}
is an
\mathcal{H}
-matrix of rank
r_{0}
if

~\text{rank}((\widetilde{\boldsymbol{K}})_{b})\leq r_{0},\qquad\forall b\in A_{\mathcal{T}_{I\times I}}.

Given a block cluster tree, the construction of an
\mathcal{H}
-matrix is straightforward. We iterate over the block clusters in the tree and perform the following operations. For a near-field block cluster, we set
(\widetilde{\boldsymbol{K}})_{b}=\boldsymbol{K}({X}_{\sigma},{X}_{\tau};\bar{\boldsymbol{\theta}}).
For a far-field block cluster, we approximate the corresponding submatrix using a low-rank approximation technique. There are several techniques for low-rank approximations, such as SVD
[
9
]
, rank-revealing QR factorizations
[
20
]
, and adaptive cross approximation (ACA) methods
[
15
,
2
]
.

The main advantage of the
\mathcal{H}
-matrix approach is that it uses
\mathcal{O}(n\log n)
storage units rather than
n^{2}
storage units. This is achieved because for each far-field block cluster
b\in A_{\mathcal{T}_{I\times I}}
, there exists a low-rank factorization of the form

(\widetilde{\boldsymbol{K}})_{b}=\boldsymbol{V}_{b}\boldsymbol{Y}^{\top}_{b}.

Hence, we store the low-rank factor matrices
\boldsymbol{V}_{b}
and
\boldsymbol{Y}_{b}
rather than the full submatrix
(\widetilde{\boldsymbol{K}})_{b}
. Additionally, we can perform MVM with
\widetilde{\boldsymbol{K}}
in
\mathcal{O}(n\log n)
FLOPs rather than
\mathcal{O}(n^{2})
FLOPs using Algorithm
7
.

3.6
\mathcal{H}^{2}
-Matrices

We now introduce
\mathcal{H}^{2}
-matrices. Fix a parameter
\bar{\boldsymbol{\theta}}\in\Theta
. We will explicitly construct an
\mathcal{H}^{2}
-matrix
\widetilde{\boldsymbol{K}}
that approximates
\boldsymbol{K}({X},{X};\bar{\boldsymbol{\theta}})
using polynomial interpolation. The mathematical structures used when constructing this
\mathcal{H}^{2}
-matrix approximation will come in handy when constructing a parametric
\mathcal{H}^{2}
-matrix in Section
4
.

3.6.1
Transfer Matrices

Let
\sigma\in\mathcal{T}_{I}
with
\sigma^{\prime}\in\text{children}(\sigma)
. First, for the index sets
I_{\sigma}=\{i_{1},i_{2},\dots,i_{n_{\sigma}}\}
and
I_{\sigma^{\prime}}=\{i_{j_{1}},i_{j_{2}},\dots,i_{j_{n_{\sigma^{\prime}}}}\}
, where
i_{j_{1}}<i_{j_{2}}<\dots<i_{j_{n_{\sigma^{\prime}}}}
, define the row selection matrix
\boldsymbol{\Gamma}_{\sigma^{\prime}}\in\mathbb{R}^{n_{\sigma^{\prime}}\times n_{\sigma}}
that selects the rows
j_{1},j_{2},\dots j_{n_{\sigma^{\prime}}}
of
\boldsymbol{U}_{\sigma}
in that order. We say that the cluster basis
\{\boldsymbol{U}_{\sigma}\}_{\sigma\in\mathcal{T}_{I}}
is
nested
if there exists a transfer matrix
\boldsymbol{E}_{\sigma^{\prime}}\in\mathbb{R}^{p_{s}^{d}\times p_{s}^{d}}
such that

\boldsymbol{\Gamma}_{\sigma^{\prime}}\boldsymbol{U}_{\sigma}=\boldsymbol{U}_{\sigma^{\prime}}\boldsymbol{E}_{\sigma^{\prime}}.

We will now demonstrate how to construct such a transfer matrix. For integer
1\leq k\leq d
, define the factor matrix
\boldsymbol{E}_{\sigma^{\prime},k}\in\mathbb{R}^{p_{s}\times p_{s}}
with entries

[\boldsymbol{E}_{\sigma^{\prime},k}]_{i,j}=\ell_{i}^{(B_{\sigma,k})}(\eta^{(B_{\sigma^{\prime},k})}_{j}),\quad\text{where}~~1\leq i,~j\leq p_{s}.

We now define the transfer matrix
\boldsymbol{E}_{\sigma^{\prime}}\in\mathbb{R}^{p_{s}^{d}\times p_{s}^{d}}
with the formula

\boldsymbol{E}_{\sigma^{\prime}}=\boldsymbol{E}_{\sigma^{\prime},d}\otimes\boldsymbol{E}_{\sigma^{\prime},d-1}\cdots\otimes\boldsymbol{E}_{\sigma^{\prime},1},

where the symbol
\otimes
denotes the Kronecker product from (
25
). By Lemma
1
, the cluster basis
\{\boldsymbol{U}_{\sigma}\}_{\sigma\in\mathcal{T}_{I}}
is nested with transfer matrices
\{\boldsymbol{E}_{\sigma}\}_{\sigma\in\mathcal{T}_{I}-\{\text{root}(\mathcal{T}_{I})\}}
.
Note that the transfer matrices are stored implicitly, in terms of their factor matrices. Additionally, in practice, we need to store only the following subset of the cluster basis:
\{\boldsymbol{U}_{\sigma}\}_{\sigma\in L(\mathcal{T}_{I})}
, since every other cluster basis matrix can be constructed by using the transfer matrices.

3.6.2
Far-Field Approximations

Let
b=\sigma\times\tau\in A_{\mathcal{T}_{I\times I}}
be a far-field block cluster. To approximate the corresponding block from the kernel matrix, we use the spatial approximation of the kernel in (
3
).

First, define the
2d
dimensional tensor
\boldsymbol{\mathcal{W}}_{b}
with entries

[\boldsymbol{\mathcal{W}}_{b}]_{\imath_{1},\imath_{2},\dots,\imath_{d},\jmath_{1},\jmath_{2},\dots,\jmath_{d}}=\kappa(\boldsymbol{\eta}_{\boldsymbol{\imath}}^{(B_{\sigma})},\boldsymbol{\eta}_{\boldsymbol{\jmath}}^{(B_{\tau})};\bar{\boldsymbol{\theta}}),\qquad\boldsymbol{\imath},\boldsymbol{\jmath}\in[p_{s}]^{d}.

Then, define the matrix
\boldsymbol{W}_{b}\in\mathbb{R}^{p_{s}^{d}\times p_{s}^{d}}
with the formula

\boldsymbol{W}_{b}=\text{reshape}(\boldsymbol{\mathcal{W}}_{b},[p_{s}^{d},p_{s}^{d}]).
This gives the approximation to the kernel matrix by the factorization

\boldsymbol{K}({X}_{\sigma},{X}_{\tau};\bar{\boldsymbol{\theta}})\approx\boldsymbol{U}_{\sigma}\boldsymbol{W}_{b}\boldsymbol{U}_{\tau}^{\top},

where the matrices
\boldsymbol{U}_{\sigma}
and
\boldsymbol{V}_{\sigma}
are defined in Section
3.3
. Note that this approximation is a low-rank approximation if
p_{s}^{d}\ll\min\{n_{\sigma},n_{\tau}\}
. We refer to the set of matrices
\{\boldsymbol{W}_{b}\}_{b\in A_{\mathcal{T}_{I\times I}}}
as the coupling matrices, since they couple the interactions between cluster basis matrices.

3.6.3
Construction and Application

We now have all the components required to construct an
\mathcal{H}^{2}
-matrix
\widetilde{\boldsymbol{K}}
that approximates the kernel matrix
\boldsymbol{K}({X},{X};\bar{\boldsymbol{\theta}})
. Using the method in Section
3.3
, we construct the following subset of the cluster basis:
\{\boldsymbol{U}_{\sigma}\}_{\sigma\in L(\mathcal{T}_{I})}
. Next, using the method in Section
3.6.1
, for each
\sigma\in\mathcal{T}_{I}
with a parent node, we construct the transfer matrix
\boldsymbol{E}_{\sigma}
. Recall that the transfer matrices and the cluster basis are stored implicitly by their respective factor matrices.

Now, we will explicitly define an
\mathcal{H}^{2}
-matrix approximation
\widetilde{\boldsymbol{K}}
to the kernel matrix by iterating over each block cluster
b\in\mathcal{T}_{I\times I}
. Let
b=\sigma\times\tau\in\mathcal{T}_{I\times I}
. If
b\in D_{\mathcal{T}_{I\times I}}
, then set

(\widetilde{\boldsymbol{K}})_{b}=\boldsymbol{K}(\mathcal{X}_{\sigma},\mathcal{X}_{\tau};\bar{\boldsymbol{\theta}}).
If
b\in A_{\mathcal{T}_{I\times I}}
, then set
(\widetilde{\boldsymbol{K}})_{b}=\boldsymbol{U}_{\sigma}\boldsymbol{W}_{b}\boldsymbol{U}_{\tau}^{\top}.

With
\widetilde{\boldsymbol{K}}
, the MVM operation is performed in three stages: fast-forward, multiplication, and fast-backward. This is formalized in Algorithm
8
. We note that for both the fast-forward and fast-backward stages, a variation of Algorithm 1 in
[
10
]
is used to compute the matrix-vector product involving transfer matrices. We refer to this method as
FastKron
. The method will take as input the factor matrices associated with a transfer matrix and a vector. For
\sigma\in\mathcal{T}_{I}
and
\widehat{\boldsymbol{x}}_{\sigma}\in\mathbb{R}^{p_{s}^{d}}
, the important part is that it requires
\mathcal{O}(p_{s}^{d+1})
FLOPs to compute the expression
(\boldsymbol{E}_{\sigma,d}\otimes\boldsymbol{E}_{\sigma,d-1}\otimes\cdots\otimes\boldsymbol{E}_{\sigma,1})\widehat{\boldsymbol{x}}_{\sigma}
rather than the
\mathcal{O}(p_{s}^{2d})
FLOPs required for the naïve approach.

3.6.4
Computational and Storage Costs

For this section, we assume that
l_{\max}
is chosen such that
C_{\text{leaf}}\approx p_{s}^{d}
. Thus, storing the
\mathcal{H}^{2}
-matrix
\widetilde{\boldsymbol{K}}
requires
\mathcal{O}(p_{s}^{d}n)
storage units by Lemma 3.38 in
[
6
]
and Lemma
2
. Algorithm
8
is similar to Algorithm 8 in
[
6
]
. Importantly, the multiplication stages of both algorithms are equivalent, and this stage dominates the computational cost of performing MVM. Consequently, we can perform the MVM operation using the fact that
\widetilde{\boldsymbol{K}}
is an
\mathcal{H}^{2}
-matrix in
\mathcal{O}(np_{s}^{d})
FLOPs by Theorem 3.42 in
[
6
]
.

4.1.2
Parametric Hierarchical Matrix Method

The parametric hierarchical matrix method is split into two stages. In the offline stage, we compute the parametric hierarchical matrix
\widetilde{\boldsymbol{K}}(\boldsymbol{\theta})
over the parameter space
\Theta
. Then, in the computationally efficient online stage, for a particular parameter
\bar{\boldsymbol{\theta}}\in\Theta
, we induce a hierarchical matrix
\widetilde{\boldsymbol{K}}(\bar{\boldsymbol{\theta}})
that approximates the kernel matrix
\boldsymbol{K}({X},{X};\bar{\boldsymbol{\theta}})
. The offline/online stage of the parametric hierarchical matrices will be synonymous with the offline/online stage of the parametric hierarchical matrix method.

4.1.3
Parametric Vectors

For
\boldsymbol{\theta}\in\Theta
, all the methods presented below use polynomial approximations and require the computation of the parametric vectors
\{\boldsymbol{v}_{i}(\theta_{i})\}_{i=1}^{d_{\theta}}
defined in
A.4
. Constructing and storing these vectors are independent of the number of points
n
; and since they are formed only once in the offline stage, their cost is not included in our complexity estimates. Hence, we assume that these vectors have already been computed in the offline stage and are always available for use.

4.1.4
Outline

This section will proceed as follows. We first define the mathematical structures needed to construct
\widetilde{\boldsymbol{K}}(\boldsymbol{\theta})
such that it is a parametric hierarchical matrix.
This portion will be split into far-field approximations and near-field approximations; this will be accomplished in Section
4.2
and Section
4.3
, respectively. Next, we will summarize the offline and online stage of parametric
\mathcal{H}
-matrices and parametric
\mathcal{H}^{2}
-matrices in Section
4.4
. Lastly, for a particular parameter
\bar{\boldsymbol{\theta}}\in\Theta
, we will discuss how to perform MVM with
\widetilde{\boldsymbol{K}}(\bar{\boldsymbol{\theta}})
whenever
\widetilde{\boldsymbol{K}}(\boldsymbol{\theta})
is a parametric
\mathcal{H}
-matrix or a parametric
\mathcal{H}^{2}
-matrix in Section

.

For each far-field block cluster

4.2.1
PTTK Approximation

Consider a far-field block cluster
b=\sigma\times\tau\in A_{\mathcal{T}_{I\times I}}
. The main idea is to use a polynomial approximation of the kernel in the spatial variables
\boldsymbol{x},\boldsymbol{y}
and the parameter variables
\boldsymbol{\theta}
, as in (
2.2
). The resulting coefficient tensor
\boldsymbol{\mathcal{M}}_{b}
is defined in
A.4
. Since it is expensive to compute and store, we approximate it using TT-cross, with a user-defined error tolerance
\epsilon_{\mathrm{tol}}>0
:

\widehat{\boldsymbol{\mathcal{M}}}_{b}=[\boldsymbol{\mathcal{G}}_{b,1},\boldsymbol{\mathcal{G}}_{b,2},\dots,\boldsymbol{\mathcal{G}}_{b,\Delta}]
with TT-ranks
r_{b,0},r_{b,1},\dots,r_{b,\Delta}
. The matrices
\boldsymbol{L}_{b}\in\mathbb{R}^{p_{s}^{d}\times r_{b,d}}
and
\boldsymbol{R}_{b}\in\mathbb{R}^{p_{s}^{d}\times r_{b,d+d_{\theta}}}
can be defined in terms of the TT-cores
\{\boldsymbol{\mathcal{G}}_{b,i}\}_{i=1}^{d}
and
\{\boldsymbol{\mathcal{G}}_{b,i}\}_{i=d+d_{\theta}+1}^{\Delta}
, respectively. The matrix
\boldsymbol{H}_{b}(\boldsymbol{\theta})\in\mathbb{R}^{r_{b,d}\times r_{b,d+d_{\theta}}}
is expressed in terms of the TT-cores
\{\boldsymbol{\mathcal{G}}_{b,i}\}_{i=d+1}^{d+d_{\theta}}
and parametric vectors
\{\boldsymbol{v}_{i}(\theta_{i})\}_{i=1}^{d_{\theta}}
. Exact formulas for these matrices are given in
A.4
. From here, the PTTK method uses the TT-cores
\{\boldsymbol{\mathcal{G}}_{b,i}\}_{i=1}^{d}
and
\{\boldsymbol{\mathcal{G}}_{b,i}\}_{i=d+d_{\theta}+1}^{\Delta}
in conjunction with the factor matrices
\{\boldsymbol{U}_{\sigma,i}\}_{i=1}^{d}
and
\{\boldsymbol{U}_{\tau,i}\}_{i=1}^{d}
, defined in Section
3.3
, to efficiently form the matrices
\boldsymbol{S}_{b}\equiv\boldsymbol{U}_{\sigma}\boldsymbol{L}_{b}
and
\boldsymbol{T}_{b}\equiv\boldsymbol{U}_{\tau}\boldsymbol{R}_{b}
. The products
\boldsymbol{S}_{b}
and
\boldsymbol{T}_{b}
are computed in a special way, using Phase 3 in Algorithm
11
. The following parametric low-rank approximation is obtained:

\boldsymbol{K}({X}_{\sigma},{X}_{\tau};{\boldsymbol{\theta}})\approx(\widetilde{\boldsymbol{K}}(\boldsymbol{\theta}))_{b}=\boldsymbol{S}_{b}\boldsymbol{H}_{b}(\boldsymbol{\theta})\boldsymbol{T}_{b}^{\top}.

(13)

We assume
\kappa
is sufficiently smooth on the domain
B_{\sigma}\times B_{\tau}\times B_{\theta}
so that

\max_{1\leq i\leq\Delta}r_{b,i}\ll\min\{n_{\sigma},n_{\tau}\}.

For parametric
\mathcal{H}
-matrices, (
13
) is used to obtain parametric low-rank approximations for each far-field block cluster. Thus, we form and store only the matrices
\boldsymbol{S}_{b}
and
\boldsymbol{T}_{b}
, and we store the components that define the matrix
\boldsymbol{H}_{b}(\boldsymbol{\theta})
. During the online stage, we instantiate
\boldsymbol{H}_{b}(\bar{\boldsymbol{\theta}})
, for a particular
\bar{\boldsymbol{\theta}}\in\Theta
, using Algorithm
12
.

For parametric
\mathcal{H}^{2}
-matrices, the following parametric low-rank approximation is employed:

\boldsymbol{K}({X}_{\sigma},{X}_{\tau};{\boldsymbol{\theta}})\approx(\widetilde{\boldsymbol{K}}(\boldsymbol{\theta}))_{b}=\boldsymbol{U}_{\sigma}(\boldsymbol{L}_{b}\boldsymbol{H}_{b}(\boldsymbol{\theta})\boldsymbol{R}_{b})\boldsymbol{U}_{\tau}^{\top}.

(14)

The parametric coupling matrix
\boldsymbol{C}_{b}(\boldsymbol{\theta})
takes the form
\boldsymbol{C}_{b}(\boldsymbol{\theta})\equiv\boldsymbol{L}_{b}\boldsymbol{H}_{b}(\boldsymbol{\theta})\boldsymbol{R}_{b}^{\top}.
By definition of
\boldsymbol{C}_{b}(\boldsymbol{\theta})
,

\boldsymbol{U}_{\sigma}\boldsymbol{C}_{b}(\boldsymbol{\theta})\boldsymbol{U}_{\tau}^{\top}=\boldsymbol{S}_{b}\boldsymbol{H}_{b}(\boldsymbol{\theta})\boldsymbol{T}_{b}^{\top}
. During the offline stage, we store the matrix implicitly in terms of the TT-cores
\{\boldsymbol{\mathcal{G}}_{b,i}\}_{i=1}^{\Delta}
; hence, for the matrix
\boldsymbol{C}_{b}(\boldsymbol{\theta})
, we never form the factors
\boldsymbol{L}_{b}
and
\boldsymbol{R}_{b}
explicitly to take advantage of the compression offered by the TT-format. Then, during the online stage, we form the matrix
\boldsymbol{H}_{b}(\bar{\boldsymbol{\theta}})
, for a particular
\bar{\boldsymbol{\theta}}\in\Theta
, using Algorithm
12
, and we store the matrices
\boldsymbol{L}_{b}
and
\boldsymbol{R}_{b}
implicitly in terms of the required TT-cores.

In summary, for parametric
\mathcal{H}
-matrices, during the offline stage, Algorithm
11
is used, and during the online stage, Algorithm
12
is used. For parametric
\mathcal{H}^{2}
-matrices, during the offline stage, only Phase 2 of Algorithm
11
is used, and during the online stage, Algorithm
12
is used.

4.3
Near-Field Approximations

In this section, the following method is used to construct both parametric
\mathcal{H}
-matrices and parametric
\mathcal{H}^{2}
-matrices; hence, we do not distinguish between them in this section.
In particular, we demonstrate how to explicitly construct parametric approximations of the forms (
10
) and (
12
). Consider a near-field block cluster
b=\sigma\times\tau\in D_{\mathcal{T}_{I\times I}}
. For
\boldsymbol{\theta}\in\Theta
, we show how to obtain a parametric compressed approximation of the submatrix
\boldsymbol{K}({X}_{\sigma},{X}_{\tau};\boldsymbol{\theta})\in\mathbb{R}^{n_{\sigma}\times n_{\tau}}
.
For a fixed parameter
\bar{\boldsymbol{\theta}}\in\Theta
, the submatrix does not admit a low-rank approximation with sufficiently low ranks because it is induced by the near-field block cluster
b
.
Even so, we can still obtain a parametric compressed approximation using the following method, which is a new variant of the PTTK method. First, we motivate the use of this new variant. In Section
4.2
, the interpolant
\phi^{(b)}
is used, where we interpolate with respect to all coordinates of
\kappa
. Since
b
is a near-field block cluster, however,
\kappa
may not be smooth enough with respect to its spatial variables for the use of
\phi^{(b)}
to be applicable. Specifically, the tensor
\boldsymbol{\mathcal{M}}_{b}
may not admit a TT-approximation with small TT-ranks. Thus, we use the interpolant
\psi
, defined in Section
2.2
, to obtain a parametric approximation of
\boldsymbol{K}({X}_{\sigma},{X}_{\tau};\boldsymbol{\theta})\in\mathbb{R}^{n_{\sigma}\times n_{\tau}}
, taking advantage of the smoothness of the kernel in the parameter space.

Let
{X}_{\sigma}=(\boldsymbol{x}_{\sigma,i})_{i=1}^{n_{\sigma}}
and
{X}_{\tau}=(\boldsymbol{x}_{\tau,i})_{i=1}^{n_{\tau}}
. We interpolate the kernel in the parameter variables using the interpolation formula (
4
). First, define the
d_{\theta}+1
dimensional tensor
\boldsymbol{\mathcal{A}}_{b}
with entries

[\boldsymbol{\mathcal{A}}_{b}]_{\overline{ij},\imath_{1},\imath_{2},\dots,\imath_{d_{\theta}}}=\kappa(\boldsymbol{x}_{\sigma,i},\boldsymbol{x}_{\tau,j};\boldsymbol{\eta}^{(B_{\theta})}_{\boldsymbol{\imath}}),\qquad 1\leq i\leq n_{\sigma},1\leq j\leq n_{\tau},\boldsymbol{\imath}\in[p_{\theta}]^{d_{\theta}}.

Recall that for indices
i_{1},i_{2},\dots,i_{k}\in\mathbb{N}
, the index
\overline{i_{1}i_{2}\cdots i_{k}}\in\mathbb{N}
is defined in Section
2.1
.
Next, for
\boldsymbol{\theta}\in\Theta
, we define the parametric vector
\boldsymbol{a}_{b}(\boldsymbol{\theta})\in\mathbb{R}^{n_{\sigma}n_{\tau}}
with the formula

\boldsymbol{a}_{b}(\boldsymbol{\theta})=\boldsymbol{\mathcal{A}}_{b}\times_{2}\boldsymbol{v}_{1}(\theta_{1})\times_{3}\boldsymbol{v}_{2}(\theta_{2})\times_{4}\cdots\times_{d_{\theta}+1}\boldsymbol{v}_{d_{\theta}}(\theta_{d_{\theta}}),

where the parametric vectors
\{\boldsymbol{v}_{i}(\theta_{i})\}_{i=1}^{d_{\theta}}
are defined in
A.4
.
Observe that the entries of the parametric kernel matrix can be approximated as follows:

[\boldsymbol{K}({X}_{\sigma},{X}_{\tau};\boldsymbol{\theta})]_{i,j}\approx\psi(\boldsymbol{x}_{\sigma,i},\boldsymbol{x}_{\tau,j};\boldsymbol{\theta})=[\boldsymbol{a}_{b}(\boldsymbol{\theta})]_{\overline{ij}},\quad 1\leq i\leq n_{\sigma},1\leq j\leq n_{\tau}.

We obtain the following parametric approximation:

\boldsymbol{K}({X}_{\sigma},{X}_{\tau};\boldsymbol{\theta})\approx\text{reshape}(\boldsymbol{a}_{b}(\boldsymbol{\theta}),[n_{\sigma},n_{\tau}]).

(19)

Storing and forming
\boldsymbol{\mathcal{A}}_{b}
require
n_{\sigma}n_{\tau}p_{\theta}^{d_{\theta}+1}
storage units and
\mathcal{O}(n_{\sigma}n_{\tau}p_{\theta}^{d_{\theta}+1})
FLOPs, respectively.
To reduce these computational and storage costs, we use TT-cross to approximate
\boldsymbol{\mathcal{A}}_{b}
in TT-format; for more information on TT-cross, see Section
2.1
. We apply TT-cross, with some error tolerance
\epsilon_{\text{tol}}>0
to the tensor
\boldsymbol{\mathcal{A}}_{b}
:

\widehat{\boldsymbol{\mathcal{A}}}_{b}=[\boldsymbol{\mathcal{G}}_{b,1},\boldsymbol{\mathcal{G}}_{b,2},\dots,\boldsymbol{\mathcal{G}}_{b,d_{\theta}+1}],

with TT-ranks
r_{b,0},r_{b,1},r_{b,2}\dots,r_{b,d_{\theta}+1}
. We can now approximate
\boldsymbol{a}_{b}(\boldsymbol{\theta})
in terms of the TT-cores of
\bar{\boldsymbol{\mathcal{A}}}_{b}
,

\widehat{\boldsymbol{a}}_{b}(\boldsymbol{\theta})\;=\;\mathrm{reshape}\!\left(\boldsymbol{\mathcal{G}}_{b,1},\,[n_{\sigma}\cdot n_{\tau},r_{b,1}]\right)\;\bigtimes\;\biggl(\prod_{i=1}^{d_{\theta}}\bigl(\boldsymbol{\mathcal{G}}_{b,i+1}\times_{2}\boldsymbol{v}_{i}(\theta_{i})\bigr)\biggr).

We substitute
\widehat{\boldsymbol{a}}_{b}(\boldsymbol{\theta})
into (
19
) and obtain the following parametric compressed approximation:

\boldsymbol{K}({X}_{\sigma},{X}_{\tau};\boldsymbol{\theta})\approx\text{reshape}(\widehat{\boldsymbol{a}}_{b}(\boldsymbol{\theta}),[n_{\sigma},n_{\tau}]).

(20)

Consequently, the matrix
D_{b}(\boldsymbol{\theta})
in Definition
2
and Definition
3
takes the form
D_{b}(\boldsymbol{\theta})=\text{reshape}(\widehat{\boldsymbol{a}}_{b}(\boldsymbol{\theta}),[n_{\sigma},n_{\tau}])
.
For a particular parameter
\bar{\boldsymbol{\theta}}\in\Theta
, it is more efficient to evaluate (
20
) rather than (
19
). Additionally, evaluating (
20
) requires storing only the TT-cores
\{\boldsymbol{\mathcal{G}}_{b,i}\}_{i=1}^{d_{\theta}+1}
, assuming that the parametric vectors
\{\boldsymbol{v}_{i}(\theta_{i})\}_{i=1}^{d_{\theta}}
are already stored.

For a particular parameter
\bar{\boldsymbol{\theta}}\in\Theta
Evaluating (
20
) requires no new kernel evaluations, whereas naïvely forming
\boldsymbol{K}({X}_{\sigma},{X}_{\tau};\bar{\boldsymbol{\boldsymbol{\theta}}})
requires
n_{\sigma}n_{\tau}
kernel evaluation. In terms of FLOP count, however, the naïve approach is cheaper than evaluating (
20
); thus, any speedup when compared with naïvely forming the kernel matrix is due to reducing the number of kernel evaluations to zero. This can be computationally beneficial for kernels that are expensive to evaluate, such as the Matérn kernel; the computational benefit can be observed in Section
6
.

is a parametric
\mathcal{H}^{2}
-matrix. There are some slight subtleties when performing MVM with
\widetilde{\boldsymbol{K}}(\bar{\boldsymbol{\theta}})
because, for each far-field block cluster
b\in A_{\mathcal{T}_{I\times I}}

\boldsymbol{L}_{b}
and
\boldsymbol{R}_{b}
that defines
\boldsymbol{C}_{b}(\bar{\boldsymbol{\theta}})
implicitly. We state the formulas, from
A.4
, that define matrices
\boldsymbol{L}_{b}
and
\boldsymbol{R}_{b}

\boldsymbol{L}_{b}\;=\;\prod_{i=1}^{d-1}\bigl(\boldsymbol{I}_{p_{s}^{\,d-i}}\otimes\boldsymbol{G}_{b,i}^{\{2\}}\bigr)\,\boldsymbol{G}_{b,d}^{\{2\}},\qquad\boldsymbol{R}_{b}^{\top}\;=\;\boldsymbol{G}_{b,d+d_{\theta}+1}^{\{1\}}\,\prod_{i=1}^{d-1}\bigl(\boldsymbol{G}_{b,d+d_{\theta}+1+i}^{\{1\}}\otimes\boldsymbol{I}_{p_{s}^{\,i}}\bigr).

Recall that the coupling matrix is defined as
\boldsymbol{C}_{b}(\bar{\boldsymbol{\theta}})=\boldsymbol{L}_{b}\boldsymbol{H}_{b}(\bar{\boldsymbol{\theta}})\boldsymbol{R}_{b}^{\top}
.

We now demonstrate how to perform MVM with components of the coupling matrix being stored implicitly. We use Algorithm
10
and Algorithm
9
for the fast-backward and fast-forward stages, respectively. For the multiplication stage, however, we use a different method. The matrix-vector multiplication algorithm for
\widetilde{\boldsymbol{K}}(\bar{\boldsymbol{\theta}})
is formalized in Algorithm
5
. Let
\widehat{\boldsymbol{x}}\in\mathbb{R}^{p_{s}^{d}}
and
k=d_{\theta}+1
. We will refer to (
26
) as the vec-kron identity. The correctness of the multiplication stage of Algorithm
5
can be proved by using induction with repeated application of the vec-kron identity. We will now prove the base case for
d=2
. Assuming
d=2
, we compute

\boldsymbol{C}_{b}(\bar{\boldsymbol{\theta}})\widehat{\boldsymbol{x}}=\boldsymbol{L}_{b}\boldsymbol{H}_{b}(\bar{\boldsymbol{\theta}})\boldsymbol{R}_{b}\widehat{\boldsymbol{x}}=(\boldsymbol{I}\otimes\boldsymbol{G}_{b,1}^{\{2\}})\boldsymbol{G}_{b,2}^{\{2\}}\boldsymbol{H}_{b}(\bar{\boldsymbol{\theta}})\boldsymbol{G}_{b,k+1}^{\{1\}}(\boldsymbol{G}_{b,k+2}^{\{1\}}\otimes\boldsymbol{I})\widehat{\boldsymbol{x}}.

We can efficiently compute
(\boldsymbol{G}_{b,k+2}^{\{1\}}\otimes\boldsymbol{I})\widehat{\boldsymbol{x}}
using the vec-kron identity and obtain

\widehat{\boldsymbol{x}}_{1}=\text{vec}\!\left(\text{reshape}(\widehat{\boldsymbol{x}},[p_{s},p_{s}])(\boldsymbol{G}_{b,k+2}^{\{1\}})^{\top}\right).

Observe that
\widehat{\boldsymbol{x}}_{1}\in\mathbb{R}^{p_{s}r_{b,k+1}}

\widehat{\boldsymbol{x}}_{2}\in\mathbb{R}^{r_{b,1}p_{s}}

\boldsymbol{C}_{b}(\bar{\boldsymbol{\theta}})\widehat{\boldsymbol{x}}=(\boldsymbol{I}\otimes\boldsymbol{G}_{b,1}^{\{2\}})\widehat{\boldsymbol{x}}_{2}=\text{vec}\!\left(\boldsymbol{G}_{b,1}^{\{2\}}\text{reshape}(\widehat{\boldsymbol{x}}_{2},[r_{b,1},p_{s}])\right).

Computational and Storage Cost Analysis

5.1
Introduction

In this section we will go over the computational costs and storage costs associated with parametric
\mathcal{H}
-matrices and parametric
\mathcal{H}^{2}
-matrices that are constructed using the methods in Section
4
. For ease of presentation, we introduce (or sometimes recap) the following notation:

\begin{array}[]{lll}r_{\text{ff}}=\max_{b\in A_{\mathcal{T}_{I\times I}}}(\underset{1\leq i\leq\Delta}{\max}r_{b,i}),&r_{\text{nf}}=\max_{b\in D_{\mathcal{T}_{I\times I}}}(\underset{1\leq i\leq\Delta}{\max}r_{b,i}),&r:=\max\{r_{\text{ff}},r_{\text{nf}}\},\\[4.0pt]
N_{\text{ff}}:=\sum_{\sigma\times\tau\in A_{\mathcal{T}_{I\times I}}}1,&N_{\text{nf}}:=\sum_{\sigma\times\tau\in D_{\mathcal{T}_{I\times I}}}1,&p=\max\{p_{\theta},p_{s}\}.\\[4.0pt]
\end{array}

The values
N_{\text{ff}}
and
N_{\text{nf}}
denote the number of far-field and near-field block clusters, respectively. In practice,
C_{\text{leaf}}
is chosen to be proportional to the values
r
and
p
; for simplicity, we will assume that
C_{\text{leaf}}\geq\max\{r,p\}
. Note that differing choices of
C_{\text{leaf}}
will lead to different complexity estimates. Lastly, for ease of presentation, we fix
d=3
; this is the value of
d
that we take in Section
6
.

We define the near-field component as the set of matrices and tensors associated with near-field block clusters and the far-field component as the set of matrices and tensors associated with the far-field block clusters. Additionally, the cluster basis and transfer matrices are included in the far-field component, if applicable.

5.2
Translation Invariance

The kernel function
\kappa
is
translation-invariant
if for any
\boldsymbol{c}\in\mathbb{R}^{d}
and
\bar{\boldsymbol{\theta}}\in\Theta

\kappa(\boldsymbol{x}+\boldsymbol{c},\boldsymbol{y}+\boldsymbol{c};\bar{\boldsymbol{\theta}})=\kappa(\boldsymbol{x},\boldsymbol{y};\bar{\boldsymbol{\theta}}),\quad\boldsymbol{x},\boldsymbol{y}\in B.

We assume that
\kappa(\cdot,\cdot;\bar{\boldsymbol{\theta}})
is isotropic, and this implies that
\kappa(\cdot,\cdot;\bar{\boldsymbol{\theta}})
is translation-invariant as well. Following the arguments in
[
13
]
, if the kernel is translation-invariant, the number of unique coupling tensors
\boldsymbol{\mathcal{M}}_{b}
for
b\in A_{\mathcal{T}_{I\times I}}
, which we denote by
M_{A}
, is
\mathcal{O}(\log(n))
(compared with
\mathcal{O}(n)
in the general case).
Exploiting this observation is advantageous from a computational and storage perspective. Since all the kernels in the numerical experiments are translation-invariant, for the rest of this section, the cost estimates use this fact. A more general treatment of exploiting translation-invariance in the context of
\mathcal{H}^{2}
-matrices is given in
[
5
]
.

The coupling ratio is computed as follows. During the online stage, when an
\mathcal{H}^{2}
-matrix approximation is induced, we compute the ratio of the number of entries required to store the coupling matrices associated with all the far-field block clusters over the size of the kernel matrix

\frac{1}{n^{2}}\sum_{b\in A_{\mathcal{T}_{I\times I}}}\left(p_{s}\left(\sum_{i=1}^{3}r_{b,i-1}r_{b,i}\;+\;\sum_{i=3+d_{\theta}+1}^{\Delta-1}r_{b,i}r_{b,i+1}\right)\;+\;r_{b,3}r_{b,3+d_{\theta}}\right).

The coupling ratio gives us an idea of the compression afforded by the parametric
\mathcal{H}^{2}
-matrix method. In particular, the
\mathcal{H}^{2}
-matrix approximation induced by our method stores the coupling matrices implicitly in the TT-format, and storing it for an arbitrary far-field block cluster requires
\mathcal{O}(dp_{s}r_{\text{ff}}^{2})
storage units.

7
Conclusion

We proposed two new hierarchical matrix formats—parametric
\mathcal{H}
-matrix and parametric
\mathcal{H}^{2}
matrix—for kernel matrices that depend on parameters, and have described methods to construct them. In addition to inheriting the respective benefits of
\mathcal{H}
-matrix and
\mathcal{H}^{2}
-matrix formats, the new methods have low online cost when instantiated for a fixed parameter. Key to our approach is the PTTK method for parametric low-rank kernel approximations of far-field blocks; additionally, we introduced a parametric approximation for near-field blocks. Both methods use TT compression to compress the coefficient tensors. Numerical experiments on a range of kernels validate the proposed approaches and show large speedups compared with existing techniques.
Future work includes exploring different parametric low-rank approximations, developing extensions to non-stationary kernels, recompressing the parametric hierarchical matrices to have lower ranks but still maintain parameter dependence, and preserving parameter dependence under the algebraic operations supported by hierarchical matrices, such as inversion.

\boldsymbol{A}\otimes\boldsymbol{B}=\begin{bmatrix}a_{1,1}\boldsymbol{B}&a_{1,2}\boldsymbol{B}&\cdots&a_{1,m-1}\boldsymbol{B}&a_{1,m}\boldsymbol{B}\\
a_{2,1}\boldsymbol{B}&a_{2,2}\boldsymbol{B}&\cdots&a_{2,m-1}\boldsymbol{B}&a_{2,m}\boldsymbol{B}\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
a_{s,1}\boldsymbol{B}&a_{s,2}\boldsymbol{B}&\cdots&a_{s,m-1}\boldsymbol{B}&a_{s,m}\boldsymbol{B}\\
\end{bmatrix}.

(25)

Let,
\boldsymbol{X}\in\mathbb{R}^{m\times q}
. We define the vec-kron identity as follows,

\text{vec}(\boldsymbol{A}\boldsymbol{X}\boldsymbol{B})=(\boldsymbol{B}^{\top}\otimes\boldsymbol{A})\text{vec}(\boldsymbol{X}),

(26)

where
\text{vec}(\cdot)
is the vec operator.
Assume that
s=q
, and we now define the face-splitting product
\boldsymbol{A}\ltimes\boldsymbol{B}
to be a
\mathbb{R}^{q\times mk}
matrix with the formula

\boldsymbol{A}\ltimes\boldsymbol{B}=\begin{bmatrix}\boldsymbol{a}_{1}\otimes\boldsymbol{b}_{1}\\
\boldsymbol{a}_{2}\otimes\boldsymbol{b}_{2}\\
\vdots\\
\boldsymbol{a}_{q}\otimes\boldsymbol{b}_{q}\end{bmatrix},

(27)

where
\boldsymbol{a}_{i}
and
\boldsymbol{b}_{i}
denote the
i
’th row vector of
\boldsymbol{A}
and
\boldsymbol{B}
, respectively.

For two hypercubes

A.4
PTTK Method

We will now review the PTTK method that was first introduced in
[
27
]
. Components of the PTTK method will be utilized to construct both parametric
\mathcal{H}
-matrices and parametric
\mathcal{H}^{2}
-matrices. The PTTK method is split into two distinct stages: the offline stage and the online stage. The offline stage is the pre-computation stage, where computations are performed over the entire parameter space
\Theta
. Then, the online stage is where computations are performed for a particular parameter
\bar{\boldsymbol{\theta}}\in\Theta
.

A.4.1
Overview

Let,
b=\sigma\times\tau\in A_{\mathcal{T}_{I\times I}}
be a far-field block cluster.

Offline Stage

Define the
\Delta
dimensional tensor
\boldsymbol{\mathcal{M}}_{b}
with entries

[\boldsymbol{\mathcal{M}}_{b}]_{\imath_{1},\dots,\imath_{d},k_{1},\dots,k_{d_{\theta}},\jmath_{1},\dots,\jmath_{d}}=\kappa(\boldsymbol{\eta}^{(B_{\sigma})}_{\boldsymbol{\imath}},\boldsymbol{\eta}^{(B_{\tau})}_{\boldsymbol{\jmath}};\eta^{(B_{\theta})}_{\boldsymbol{k}}),\qquad\boldsymbol{\imath},\boldsymbol{\jmath}\in[p_{s}]^{d},\boldsymbol{k}\in[p_{\theta}]^{d_{\theta}}.

Storing the tensor
\boldsymbol{\mathcal{M}}_{b}
is computationally infeasible if
\boldsymbol{\mathcal{M}}_{b}
is large. Thus, we approximate the tensor
\boldsymbol{\mathcal{M}}_{b}
using TT-cross, with a tolerance
\epsilon_{\rm{tol}}>0
,

\widehat{\boldsymbol{\mathcal{M}}}_{b}=[\boldsymbol{\mathcal{G}}_{b,1},\boldsymbol{\mathcal{G}}_{b,2},\dots,\boldsymbol{\mathcal{G}}_{b,\Delta}].

The TT-ranks of
\widehat{\boldsymbol{\mathcal{M}}}_{b}
are
r_{b,0},r_{b,1},\dots,r_{b,\Delta}
(recall,
r_{b,0}=r_{b,\Delta}=1
). Now, for
\boldsymbol{\theta}\in\Theta
, we can approximate the entries of
\boldsymbol{K}(\mathcal{X}_{\sigma},\mathcal{X}_{\tau};\boldsymbol{\theta})
with the following approximations,

\displaystyle\left[\boldsymbol{K}({X}_{\sigma},{X}_{\tau};\boldsymbol{\theta})\right]_{i,j}

\displaystyle\approx\;\phi^{(b)}(\boldsymbol{x}_{\sigma,i},\boldsymbol{x}_{\tau,j};\boldsymbol{\theta})

(28)

\displaystyle\approx\sum_{\boldsymbol{\imath}\in[p_{s}]^{d}}\sum_{\boldsymbol{\jmath}\in[p_{s}]^{d}}\sum_{\boldsymbol{k}\in[p_{\theta}]^{d_{\theta}}}[\widehat{\boldsymbol{\mathcal{M}}}_{b}]_{\imath_{1},\dots,\imath_{d},\;k_{1},\dots,k_{d_{\theta}},\;\jmath_{1},\dots,\jmath_{d}}

\displaystyle\times\;\mathcal{L}_{\boldsymbol{\imath}}^{(B_{\sigma})}(\boldsymbol{x}_{\sigma,i})\,\mathcal{L}_{\boldsymbol{\jmath}}^{(B_{\tau})}(\boldsymbol{x}_{\tau,j})\,\mathcal{L}_{\boldsymbol{k}}^{(B_{\theta})}(\boldsymbol{\theta}),

where
\phi^{(b)}
is defined in Section
2.2
.

The following matrices are defined, in order to extend the entry-wise approximations in (
28
) onto the whole matrix. First, we define the parametric vectors
\boldsymbol{v}_{1}(\theta_{1}),\boldsymbol{v}_{2}(\theta_{2}),\dots,\boldsymbol{v}_{d_{\theta}}(\theta_{d_{\theta}})\in\mathbb{R}^{p_{\theta}}
, where
(\theta_{1},\theta_{2},\dots,\theta_{d_{\theta}})\in\Theta
, with entries

[\boldsymbol{v}_{k}(\theta_{k})]_{i}=\ell_{i}^{([\alpha^{\theta}_{k},\beta^{\theta}_{k}])}(\theta_{k}).

For
\boldsymbol{\theta}\in\Theta
, the matrix
\boldsymbol{H}_{b}(\boldsymbol{\theta})\in\mathbb{R}^{r_{d}\times r_{d+d_{\theta}}}
is defined by the formula

\boldsymbol{H}_{b}(\boldsymbol{\theta})=\prod_{i=1}^{d_{\theta}}\boldsymbol{\mathcal{G}}_{b,d+i}\times_{2}\boldsymbol{v}_{i}(\theta_{i}),

where
\times_{2}
is the mode-2 product defined in Section
2.1
. Next, define the matrices
\boldsymbol{L}_{b}\in\mathbb{R}^{n_{\sigma}\times r_{b,d}}
and
\boldsymbol{R}_{b}\in\mathbb{R}^{n_{\tau}\times r_{b,d+d_{\theta}}}
with the formulas

\boldsymbol{L}_{b}\;=\;\prod_{i=1}^{d-1}\bigl(I_{p_{s}^{\,d-i}}\otimes\boldsymbol{G}_{b,i}^{\{2\}}\bigr)\,\boldsymbol{G}_{b,d}^{\{2\}},\qquad\boldsymbol{R}_{b}^{\top}\;=\;\boldsymbol{G}_{b,d+d_{\theta}+1}^{\{1\}}\,\prod_{i=1}^{d-1}\bigl(\boldsymbol{G}_{b,d+d_{\theta}+1+i}^{\{1\}}\otimes I_{p_{s}^{\,i}}\bigr),

where the matrices
\boldsymbol{G}_{b,i}^{\{1\}}
for
1\leq i\leq d
and
\boldsymbol{G}_{b,i}^{\{2\}}
for
d+d_{\theta}+1\leq i\leq\Delta
are defined in Section
2.1
; additionally,
\boldsymbol{I}_{t}
is the
t\times t
identity matrix.
For
\boldsymbol{\theta}\in\Theta
, define the
2d
dimensional tensor
\widehat{\boldsymbol{\mathcal{M}}}_{b,F}(\boldsymbol{\theta})
, induced by
\widehat{\boldsymbol{\mathcal{M}}}_{b}
, with the entries

[\widehat{\boldsymbol{\mathcal{M}}}_{b,F}(\boldsymbol{\theta})]_{\imath_{1},\imath_{2},\dots,\imath_{d},\;\jmath_{1},\jmath_{2},\dots,\jmath_{d}}=\sum_{\boldsymbol{k}\in[p_{\theta}]^{d_{\theta}}}[\widehat{\boldsymbol{\mathcal{M}}}_{b}]_{\imath_{1},\imath_{2},\dots,\imath_{d},\;k_{1},k_{2},\dots,k_{d_{\theta}},\;\jmath_{1},\jmath_{2},\dots,\jmath_{d}}\\
\times\mathcal{L}_{\boldsymbol{k}}^{(B_{\theta})}(\boldsymbol{\theta}).

In Section 3.1 of
[
27
]
, it is demonstrated using Equation (38) from
[
38
]
that these matrices approximate the entries of
\widehat{\boldsymbol{\mathcal{M}}}_{b,F}(\boldsymbol{\theta})
:

[\widehat{\boldsymbol{\mathcal{M}}}_{b,F}(\boldsymbol{\theta})]_{\imath_{1},\imath_{2},\dots,\imath_{d},\;\jmath_{1},\jmath_{2},\dots,\jmath_{d}}\approx[\boldsymbol{L}_{b}\boldsymbol{H}_{b}(\boldsymbol{\theta})\boldsymbol{R}_{b}^{\top}]_{\overline{\imath_{1}\imath_{2}\dots\imath_{d}},\overline{\jmath_{1}\jmath_{2}\dots\jmath_{d}}}.

(29)

The equation (
29
) implies that
\text{reshape}(\boldsymbol{\mathcal{M}}_{b,F}(\boldsymbol{\theta}),[p_{s}^{d},p_{s}^{d}])\approx\boldsymbol{L}_{b}\boldsymbol{H}_{b}(\boldsymbol{\theta})\boldsymbol{R}_{b}^{\top}
. Now, we can finally obtain the initial parametric approximation

\boldsymbol{K}(X_{\sigma},X_{\tau};\boldsymbol{\theta})\approx\boldsymbol{U}_{\sigma}\boldsymbol{L}_{b}\boldsymbol{H}_{b}(\boldsymbol{\theta})\boldsymbol{R}_{b}^{\top}\boldsymbol{U}_{\tau}^{\top},

(30)

note that this is a parametric low-rank approximation if
p_{s}^{d}\ll\min\{n_{\sigma},n_{\tau}\}
. Lastly, we define the matrices
\boldsymbol{S}_{b}=\boldsymbol{U}_{\sigma}\boldsymbol{L}_{b}\in\mathbb{R}^{n_{\sigma}\times r_{b,d}}
and
\boldsymbol{T}_{b}=\boldsymbol{U}_{\tau}\boldsymbol{R}_{b}\in\mathbb{R}^{n_{\tau}\times r_{d+d_{\theta}}}
. It is important to note that the matrices
\boldsymbol{S}_{b}
and
\boldsymbol{T}_{b}
are efficiently computed in exact arithmetic using Phase 3 of
11

Online Stage

Fix a parameter
\bar{\boldsymbol{\theta}}\in\Theta
. We can form the matrix
\boldsymbol{H}_{b}(\bar{\boldsymbol{\theta}})

\boldsymbol{\mathcal{G}}_{b,d+1},\boldsymbol{\mathcal{G}}_{b,d+2},\dots,\boldsymbol{\mathcal{G}}_{b,d+d_{\theta}}

\boldsymbol{K}({X}_{\sigma},{X}_{\tau};\bar{\boldsymbol{\theta}})\approx\boldsymbol{S}_{b}\boldsymbol{H}_{b}(\bar{\boldsymbol{\theta}})\boldsymbol{T}_{b}^{\top}.

The online stage is formalized in Algorithm

A.5
General Estimates

Estimates relating to the number of tree nodes are provided for the cluster tree
\mathcal{T}_{I}
and the block cluster tree
\mathcal{T}_{I\times I}
. These estimates will be useful when analyzing the computational and storage costs of parametric hierarchical matrices. Many of these estimates are standard, and similar versions can be found in
[
25
,
6
]
.

Lemma 2
.

The following inequalities, related to the cluster tree
\mathcal{T}_{I}
, hold:

\displaystyle\sum_{\sigma\in\mathcal{T}_{I}}1

\displaystyle\leq\frac{2n}{C_{\text{leaf}}}

(31a)

\displaystyle\sum_{\sigma\in\mathcal{T}_{I}}n_{\sigma}

\displaystyle\leq(\log(n)+1)n.

(31b)

Proof.

First, we prove (
31a
). Recall, from Section
3.2
that
C_{\text{leaf}}=n/2^{dl_{\max}}
, which implies
n/C_{\text{leaf}}=2^{dl_{\max}}
. Thus,

\sum_{\sigma\in\mathcal{T}_{I}}1\leq\frac{2^{d(l_{\max}+1)}-1}{2^{d}-1}\leq 2^{d(l_{\max}+1)}\leq\frac{2n}{C_{\text{leaf}}}.

Now, we prove (
31b
). We compute

\sum_{\sigma\in\mathcal{T}_{I}}n_{\sigma}=\sum_{l=0}^{l_{\max}}\sum_{\begin{subarray}{c}\sigma\in\mathcal{T}_{I}\\
\scriptscriptstyle\text{level}(\sigma)=l\end{subarray}}n_{\sigma}=\sum_{l=0}^{l_{\max}}n\leq(l_{\max}+1)n\leq(\log_{2^{d}}(n)+1)n.

∎

Lemma 3
.

The following inequalities, related to the block cluster tree
\mathcal{T}_{I\times I}
, hold:

\displaystyle\sum_{\sigma\times\tau\in A_{\mathcal{T}_{I\times I}}}1

\displaystyle\;\leq\;\frac{2C_{\text{sp}}}{C_{\text{leaf}}}n,

(32a)

\displaystyle\sum_{\sigma\times\tau\in A_{\mathcal{T}_{I\times I}}}n_{\sigma}

\displaystyle\;\leq\;C_{\text{sp}}n(\log(n)+1),

(32b)

\displaystyle\sum_{\sigma\times\tau\in D_{\mathcal{T}_{I\times I}}}1

\displaystyle\;\leq\;\frac{C_{\text{sp}}}{C_{\text{leaf}}}n.

(32c)

Proof.

The following statement will be used throughout this proof. Fix
\hat{\sigma}\in\mathcal{T}_{I}
. Then, by the definition of
C_{\text{sp}}
,

\sum_{\hat{\sigma}\times\tau\in A_{\mathcal{T}_{I\times I}}}1\leq C_{\text{sp}},\qquad\sum_{\hat{\sigma}\times\tau\in D_{\mathcal{T}_{I\times I}}}1\leq C_{\text{sp}}.

We first prove the validity of Inequality (
32a
). We compute

\sum_{\sigma\times\tau\in A_{\mathcal{T}_{I\times I}}}1\;\leq\;\sum_{\sigma\in\mathcal{T}_{I}}\sum_{\sigma\times\tau\in A_{\mathcal{T}_{I\times I}}}1\;\leq\;C_{\text{sp}}\sum_{\sigma\in\mathcal{T}_{I}}1\;\leq\;\frac{2C_{\text{sp}}}{C_{\text{leaf}}}n.

The last inequality in the chain follows from (
31a
).
We now prove the validity of Inequality (
32b
),

\sum_{\sigma\times\tau\in A_{\mathcal{T}_{I\times I}}}n_{\sigma}\;\leq\;\sum_{\sigma\in\mathcal{T}_{I}}n_{\sigma}\sum_{\sigma\times\tau\in A_{\mathcal{T}_{I\times I}}}1\;\leq\;C_{\text{sp}}\sum_{\sigma\in\mathcal{T}_{I}}n_{\sigma}\;\leq\;C_{\text{sp}}\,n\,(\log_{2^{d}}(n)+1).

The last inequality in the chain follows from (
31b
).
We now prove the validity of Inequality (
32c
),

\sum_{\sigma\times\tau\in D_{\mathcal{T}_{I\times I}}}1\;\leq\;\sum_{\sigma\in L(\mathcal{T}_{I})}\sum_{\sigma\times\tau\in D_{\mathcal{T}_{I\times I}}}1\;\leq\;\sum_{\sigma\in L(\mathcal{T}_{I})}C_{\text{sp}}\;\leq\;\frac{C_{\text{sp}}}{C_{\text{leaf}}}n.

∎

Comparison Methods

We discuss the implementation details of

A.8.1
\mathcal{H}
-ACA Method

Fix a parameter
\bar{\boldsymbol{\theta}}\in\Theta
. For every far-field block cluster
b=\sigma\times\tau\in A_{\mathcal{T}_{I\times I}}
, we use the partially pivoted adaptive cross approximation (ACA) (Algorithm 1 in
[
31
]
) with tolerance
\epsilon_{\rm{tol}}
, to compute a low-rank approximation of the form

\boldsymbol{K}({X}_{\sigma},{X}_{\tau};\bar{\boldsymbol{\theta}})\approx\boldsymbol{V}_{b}\boldsymbol{Y}^{\top}_{b},\qquad\text{where }\boldsymbol{V}_{b}\in\mathbb{R}^{n_{\sigma}\times t_{b}},\boldsymbol{Y}_{b}\in\mathbb{R}^{n_{\tau}\times t_{b}}.

(33)

We store the factors
\boldsymbol{V}_{b}
and
\boldsymbol{Y}_{b}
. Computing this low-rank factorization takes
\mathcal{O}((n_{\sigma}+n_{\tau})t_{b}^{2})
FLOPs and
\mathcal{O}((n_{\sigma}+n_{\tau})t_{b})
kernel evaluations. For every near-field block cluster
b\in D_{\mathcal{T}_{I\times I}}
, we store the kernel matrix
\boldsymbol{K}({X}_{\sigma},{X}_{\tau};\bar{\boldsymbol{\theta}})
explicitly.

The
\mathcal{H}
-ACA method is chosen for comparison because it requires
\mathcal{O}(n\log(n)r)
FLOPs to obtain an
\mathcal{H}
-matrix approximation, where
r=\max_{b\in A_{\mathcal{T}_{I\times I}}}t_{b}
. Furthermore, the
\mathcal{H}
-ACA method uses ACA, which is an algebraic method, to obtain low-rank approximations. This means that the compression achieved is generally much stronger than the compression obtained by methods that first employ an analytic approximation of
\kappa
in order to obtain low-rank approximations. ACA is effective for kernel matrices induced by asymptotically smooth kernels
[
4
]
, which we consider in numerical experiments.

A.8.2
\mathcal{H}^{2}
-HCA Method

Fix a parameter
\bar{\boldsymbol{\theta}}\in\Theta
. We use the same procedure, with slight modifications, outlined in Section
3.6
to construct an
\mathcal{H}^{2}
-matrix approximation of
\boldsymbol{K}(X,X;\bar{\boldsymbol{\theta}})
. The modification is as follows. Fix a tolerance
\epsilon_{\text{tol}}>0
. For each far-field block cluster
b=\sigma\times\tau\in A_{\mathcal{T}_{I\times I}}
, we obtain a low-rank factorization of the matrix
\boldsymbol{W}_{b}
using ACA with tolerance
\epsilon_{\rm{tol}}
. Using ACA, we obtain a low-rank factorization of the form

\boldsymbol{X}_{b}\boldsymbol{Y}_{b}^{\top}\approx\text{reshape}(\boldsymbol{\mathcal{M}}_{b},[p_{s}^{d},p_{s}^{d}]),

where
\boldsymbol{X}_{b},\boldsymbol{Y}_{b}\in\mathbb{R}^{p_{s}^{d}\times t_{b}}
. This operation has a computational cost of

\mathcal{O}(p_{s}^{d}t_{b}^{2})
FLOPs and
\mathcal{O}(p_{s}^{d}t_{b})
kernel evaluations. Additionally, if the kernel is translation-invariant, then storing/computing all the low-rank factors
\boldsymbol{X}_{b},\boldsymbol{Y}_{b}
for each far-field block cluster
b\in A_{\mathcal{T}_{I\times I}}
requires
\mathcal{O}(\log(n)p_{s}^{d}\max_{b\in A_{\mathcal{T}_{I\times I}}}t_{b})
storage units/ FLOPs.
