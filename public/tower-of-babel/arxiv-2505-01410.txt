Towards Optimal Deterministic LOCAL Algorithms on Trees
Sebastian Brandt, Ananth Narayanan

Abstract
While obtaining optimal algorithms for the most important problems in the LOCAL model has been one of the central goals in the area of distributed algorithms since its infancy, tight complexity bounds are elusive for many problems even when considering deterministic complexities on trees . We take a step towards remedying this issue by providing a way to relate the complexity of a problem Π \Pi on trees to its truly local complexity, which is the (asymptotically) smallest function f f such that Π \Pi can be solved in O ⁡ ( f ⁡ ( Δ ) + log ∗ ⁡ n ) O(f(\Delta)+\log^{*}n) rounds. More specifically, we develop a transformation that takes an algorithm 𝒜 \mathcal{A} for Π \Pi with a runtime of O ⁡ ( f ⁡ ( Δ ) + log ∗ ⁡ n ) O(f(\Delta)+\log^{*}n) rounds as input and transforms it into an O ⁡ ( f ⁡ ( g ⁡ ( n ) ) + log ∗ ⁡ n ) O(f(g(n))+\log^{*}n) -round algorithm 𝒜 ′ \mathcal{A}^{\prime} on trees, where g g is the function that satisfies g ​ ( n ) f ⁡ ( g ⁡ ( n ) ) = n g(n)^{f(g(n))}=n . If f f is the truly local complexity of Π \Pi (i.e., if 𝒜 \mathcal{A} is asymptotically optimal), then 𝒜 ′ \mathcal{A}^{\prime} is an asymptotically optimal algorithm on trees, conditioned on a natural assumption on the nature of the worst-case instances of Π \Pi . Our transformation works for any member of a wide class of problems, including the most important symmetry-breaking problems. As an example of our transformation we obtain the first strongly sublogarithmic algorithm for ( edge-degree + 1 ) (\text{edge-degree + 1}) -edge coloring (and therefore also ( 2 ​ Δ − 1 ) (2\Delta-1) -edge coloring) on trees, exhibiting a runtime of O ⁡ ( log 12 / 13 ⁡ n ) O(\log^{12/13}n) rounds. This breaks through the Ω ⁡ ( log ⁡ n / log ⁡ log ​ n ) \Omega(\log n/\log\log n) -barrier that is a fundamental lower bound for other symmetry-breaking problems such as maximal independent set or maximal matching (that already holds on trees), and proves a separation between these problems and the aforementioned edge coloring problems on trees. We extend a subset of our results to graphs of bounded arboricity, obtaining, for instance, the aforementioned upper bound for edge colorings also on planar graphs.

and

, the decomposition obtained by this process can transformed into a decomposition as described above, via a careful distinction between different kinds of edges (one of which captures all edges between a node

We note that the two decompositions also differ in how the aforementioned “parts” of the decomposition are related: in the decomposition for

2
, they are

We believe that the clean structure of our approach will enable future work to build on it to achieve a similar transformation as captured by

2
for even wider classes of problems.
In particular, obtaining further decompositions similar to the ones we use seems to be a highly promising approach to this end.

Definition 4

Next, we define our model of computation formally.

Definition 5

(LOCAL model
[
31
,
36
]
)
.

The LOCAL model of computation is modeled by an undirected graph
G=(V,E)
in which each of the nodes represents a computational unit with unbounded computational power and memory. Each node knows the number of nodes
n
and the maximum degree
\Delta
of the graph. Each of the nodes has a globally unique identifier from
\{1,2\dots,n^{c}\}
for some large enough constant

. Depending on the problem to solve, there may be other inputs on nodes and edges. A
T

T

In each round, each node first sends (potentially different) messages of arbitrary size to its neighbors, then receives the information sent by its neighbors, and finally may perform some (arbitrarily complex) computation. At the end of T rounds, each node determines its output and terminates. Equivalently, each node learns all the information in its it
T
-hop neighborhood in
T
rounds (since the message size is unlimited) and decides on an output.
The definition of the LOCAL model extends to semi-graphs in the natural way, where the computational units are the nodes
V_{\operatorname{semi}}(S)
and messages can only be sent via edges of rank
2
.

Definition 6

(Node-edge-checkable problem)
.

A

\mathcal{E}_{\Pi}=\{\mathcal{E}_{\Pi}^{0},\mathcal{E}_{\Pi}^{1},\mathcal{E}_{\Pi}^{2}\}

\mathcal{E}_{\Pi}^{i}
is a collection of cardinality-

A valid solution to

on an input semi-graph

•

for every node

Definition 7

For a node-edge-checkable problem

•

\mathcal{L}_{\Pi}^{i}=\{\mathcal{N}_{\Pi,\psi}^{i}\mid\psi\in\mathcal{N}_{\Pi}^{j}\text{ for some }j\in\mathbb{Z}\}

for each

•

Intuitively, the problems defined in

8
should be understood as problems arising on a subsemi-graph of the input semi-graph

when the actual problem

that is supposed to be solved has already been solved on the part of

not belonging to the subsemi-graph.
Imagine an output for
\Pi
has been fixed on some half-edges such that

•

for each edge (of any rank), either all incident half-edges received an output label or none of them did, and

•

for each node and each edge of

for which the output has been fixed on all incident half-edges, the output is correct (i.e., is contained in the respective

or

Consider a node

.
Some of the half-edges incident to

If we wanted to characterize which possibilities are left for the labels on those incident half-edges that have not received their output, we might do so by assigning an input label to

This input label would essentially be a new collection of allowed label configurations that replaces the node constraint

corresponding to

Now Problem

can be seen as the problem that captures the task of solving all instances where each node is given such a new collection of label configurations that might come from the outlined scenario that the instance is actually part of a larger instance that has been partially solved.
From this perspective,

represents the “remaining unsolved” degree of a considered node,

the “solved” degree,

a possible output on the “solved” incident half-edges,

the set of all possible replacement collections of configurations, each of which comes from a possible way how the solved incident half-edges are fixed (specified by

the function assigning to each node its replacement collection, and so on.

The intuition for
Definition

is similar, with the essential difference being that the scenario to be imagined comes with the requirement that for each
node
(instead of for each

), either all incident half-edges received an output label or none of them did.

.

Proving

A key technique used in this section is the rake-and-compress technique on trees introduced in
[
33
]
. There are a number of variants of this method (see, e.g.,
[
14
,
32
]
), one of which
[
14
]
we will rely on heavily in this section and discuss below. The process takes as input a graph which is a tree and a parameter
k\geq 2
and outputs a partition of the nodes into layers. The process proceeds by iterative application of rake and compress operations which are defined as follows:

•

Rake operation
: Rake(
G
) marks a node
u\in V(G)
if the degree of
u
is at most 1.

•

Compress operation
: Compress(
G,k
) marks a node
u\in V(G)
if the degrees of
u
and all of its neighbors are at most
k
.

We say a node is
raked
if it is marked by a rake operation and a node is
compressed
if it is marked by a compress operation.
We may refer to them as raked nodes and compressed nodes respectively. We now formally define the rake-and-compress algorithm on trees from
[
14
]
.

Algorithm 1

Rake-and-Compress Algorithm

Let
G=(V,E)
be a tree. Set all nodes of
G
to be unmarked initially.

Set
V_{0}=V(G)
. For
i\in\{1,2\dots,\lceil\log_{k}n+1\rceil
, do the following:

1.

Set
C_{i}=\emptyset
,
R_{i}=\emptyset
.

2.

Perform Compress(
G[V_{i-1}],k
). Add the nodes marked in this compress step to
C_{i}
.

3.

Perform Rake(
G[V_{i-1}\setminus C_{i}]
). Add the nodes marked in this rake step to
R_{i}
.

4.

Set
V_{i}
to be the set of unmarked nodes in
V_{i-1}
.

Theorem 9 in
[
14
]
guarantees that
Algorithm

1
is sufficient to mark all the nodes.

Lemma 9

(
[
14
]
)
.

All nodes in the input tree are either raked or compressed by
Algorithm

1
.

We will refer to the sets

and
R_{i}
as

and

respectively. We will use simply the term

to refer to any of the compress and rake layers. We fix a total ordering on the layers in the following way: for two distinct layers

and

, we say that
L_{1}
is higher than
L_{2}
if nodes in
L_{1}
were marked after nodes in
L_{2}
. We may equivalently say
L_{2}
is lower than
L_{1}
. Similarly, we fix a total ordering on the nodes in the following way:
node
u
is lower than node
v
, or equivalently
node
v
is higher than node
u
if node
u
is in a lower layer than node
v
. If both nodes are in the same layer, the one with higher ID is considered to be the higher node. If
u
and
v
are neighbors with
u
higher than

, call

a higher neighbor of
v
, and
v
a lower neighbor of
u
. For an edge

, call

.

We now claim that the subtree of the input tree induced by the edges that have their lower endpoint in a compress layer has maximum degree bounded by

.

Lemma 10
.

The maximum degree of the graph induced by the edges that have their lower endpoint in one of the layers
C_{1},C_{2},\dots,C_{\lceil\log_{k}n+1\rceil}
is at most
k
.

Proof.

Let
E_{C}
denote the set of those edges that have their lower endpoint in one of the layers
C_{1},C_{2}\dots,C_{\lceil\log_{k}n+1\rceil}
. Assume for a contradiction that there is a node

with

. The design of

1
implies that

has at most
k

. Since all edges of

have their lower nodes in some compress layer, all lower neighbors of

are in compress layers. Let

, for some

was marked,

still had more than

would not have been marked in the respective compress operation, yielding a contradiction.
∎

Next we bound the diameter of the connected components in the graph induced by the raked nodes.

Lemma 11
.

The diameter of a connected component in the graph induced by the raked nodes is at most
4(\log_{k}n+1)+2
.

Proof.

Let
R
be the set of raked nodes, and let

be a node in a connected component

of

. Let

be the highest node in

. There must exist such an

is at distance at most

which would prove the claim. If

, we are done. Assume otherwise. Consider the unique path

of length

from

to

. Let

. Suppose

is higher than

. Since

has at most one neighbor higher than

(since

, and therefore also lower than

. By iterating this argument with increasing

is lower than

, which in turn is lower than

.

Moreover, if

is

5
Implications for Concrete Problems

In this section, we will finally apply
Theorem

15
to obtain our new upper bound for
(\text{edge-degree}+1)
-edge coloring.
We also show how our techniques can be used to obtain in a generic manner the tight

-round upper bound for maximal matching known from
[
8
]
.

For both problems, our first step is to phrase the problems in the node-edge-checkability formalism for semi-graphs defined in
Section

2

In other words, for either of the two problems we present a problem given in the formalism and then show that it is equivalent to
(\text{edge-degree}+1)
-edge coloring, resp. maximal matching, in the sense that a solution to the problem given in the formalism on a semi-graph can be transformed in at most
1
round into a solution to the edge coloring or matching problem on the underlying graph and vice versa.
Moreover, in order to show that the defined problems satisfy the conditions of
Theorem

15
we show that they can be solved in time
O(f(\Delta)+\log^{*}n)
for suitable functions

, and that their node-list variants admit a valid solution on any valid instance.
We cover
(\text{edge-degree}+1)
-edge coloring in
Section

5.1
and maximal matching in
Section

5.2
.

5.1

-Edge Coloring

We define a node-edge-checkable problem

•

\Sigma=\{(a,b)\mid a,b\in\mathbb{Z}_{>0}\}\cup\{D\}

Again, it follows directly from the definitions of the two problems that such an output label assignment is possible and must produce a valid solution.

Next, we consider the node-list variant
\Pi^{*}=\{\Sigma,\mathcal{L}_{\Pi},\mathcal{E}_{\Pi}\}
of problem
\Pi
. By definition of
\Pi^{*}
,
\mathcal{L}_{\Pi}=\{\mathcal{L}_{\Pi}^{1},\mathcal{L}_{\Pi}^{2},\dots\}
where
\mathcal{L}_{\Pi}^{i}=\{\mathcal{N}_{\Pi,\psi}^{i}\mid\psi\in\mathcal{N}_{\Pi}^{j}\text{ for some }j\in\mathbb{Z}\}
. We have that for
\psi=\{(x_{1},y_{1}),\dots,(x_{q},y_{q}),D\dots,D\}\in\mathcal{N}_{\Pi}^{j}
,

\mathcal{N}_{\Pi,\psi}^{i}=\{\{(a_{1},b_{1}),\dots,(a_{p},b_{p}),D,\dots D\}\mid\{(a_{1},b_{1}),\dots,(a_{p},b_{p}),(x_{1},y_{1}),\dots,(x_{q},y_{q}),D\dots,D\}\in\mathcal{N}_{\Pi}^{i+j}\}.

For a label
(a,b)
assigned to a half-edge

, we call

the
degree part
of the label and
b
the
color part
of the label. On a graph

, the constraints of problem
\Pi
translate to the statement that for an edge

incident on half-edges
h_{1}
and

h_{1}
and
h_{2}
is at least
1
greater than the color part which is common for
h_{1}
and
h_{2}
.
We show the following lemma.

Lemma 16
.

For any given instance
(G,h_{\operatorname{in}})
,
\Pi^{*}
admits a solution.

Proof.

Let
(e_{1},e_{2},\dots,e_{l})
and
(f_{1},f_{2},\dots,f_{m})
be orderings of rank-
2

1
edges respectively. We define a
labeling process
that goes through edges sequentially and assign labels to half-edges incident on them.

•

Go through edges
e_{1},e_{2},\dots,e_{l}
sequentially. For an edge
e=e_{t},t\leq l
, do the following. Let
v_{1}
and
v_{2}
be the nodes incident on
e
. Suppose that degree of
v_{1}
and
v_{2}
are
i_{1}
and
i_{2}
respectively. Suppose

and
h_{\operatorname{in}}(v_{2})=\mathcal{N}_{\Pi,\psi_{2}}^{i_{2}}
where
\psi_{1}\in\mathcal{N}_{\Pi}^{j_{1}}
and
\mathcal{N}_{\Pi}^{j_{2}}
. Let
\psi_{1}=\{(x_{1},y_{1}),\dots,(x_{b_{1}},y_{b_{1}}),D,\dots,D\}
and
\psi_{2}=\{(w_{1},z_{1}),\dots,(w_{b_{2}},z_{b_{2}}),D,\dots,D\}
. Let
\chi_{1}=\{(r_{1},s_{1}),\dots,(r_{d_{1}},s_{d_{1}})\}

) and
\chi_{2}=\{(p_{1},q_{1}),\dots,(p_{d_{2}},q_{d_{2}})\}

and

and
D\notin\chi_{2}

(i)

c\neq t

(ii)

Assign to

\{v_{2},e\}

(b_{1}+d_{1}+1,c)

Maximal Matching

We define the problem
\Pi=(\Sigma,\mathcal{N}_{\Pi},\mathcal{E}_{\Pi})
where

•

\Sigma=\{M,P,O,D\}

•

\mathcal{N}_{\Pi}=\{\mathcal{N}_{\Pi}^{0},\mathcal{N}_{\Pi}^{1},\dots\}
where
\mathcal{N}_{\Pi}^{i}=\{\{\chi_{1},\chi_{2},\dots,\chi_{i}\}\mid\chi_{1},\chi_{2},\dots,\chi_{i}\in\Sigma\text{ and either }(i)\ \chi_{j}=M\text{ for one }j\leq i,\chi_{k}\in\{P,O,D\}\text{ for }k\neq j,\text{ or }(ii)\ \chi_{i}\in\{O,D\}\text{ for all }k\leq i\}
.

•

\mathcal{E}_{\Pi}^{0}=\{\emptyset\}
,
\mathcal{E}_{\Pi}^{1}=\{\{D\}\}
, and
\mathcal{E}_{\Pi}^{2}=\{\{P,O\},\{M,M\},\{P,P\}\}
.

It is straightforward to transform any valid solution to
\Pi
on semi-graphs into a valid solution to maximal matching on graphs in
1
round: simply put an edge of the input graph into the matching if and only if the two labels assigned to the corresponding edge in the semi-graph on which a valid solution to
\Pi
is assumed to be given are both
M
.
The constraints of
\Pi
directly imply that the obtained solution is indeed a valid solution for maximal matching.

Vice versa, given a semi-graph
S
with underlying graph
G
, a valid solution to maximal matching can be straightforwardly transformed into a valid solution for
\Pi
on
S
in
1
round: on each half-edge incident to an edge of rank
1
, simply output
D
; for each edge
e
of rank
2
output
M
on both incident half-edges if
e
is matched in the given solution, and otherwise output

•

O
on each half-edge incident on
e
for which the incident node is not matched in the given solution, and

•

P
on each half-edge incident on
e
for which the incident node is matched in the given solution.

Again, the definitions of
\Pi
and maximal matching immediately imply that the obtained solution is indeed a valid solution on
S
.

Next, we consider the node-list variant
\Pi^{*}=\{\Sigma,\mathcal{L}_{\Pi},\mathcal{E}_{\Pi}\}
of problem
\Pi
. By definition of
\Pi^{*}
,
\mathcal{L}_{\Pi}=\{\mathcal{L}_{\Pi}^{1},\mathcal{L}_{\Pi}^{2},\dots\}
where
\mathcal{L}_{\Pi}^{i}=\{\mathcal{N}_{\Pi,\psi}^{i}:\psi\in\mathcal{N}_{\Pi}^{j}\text{ for some }j\in\mathbb{Z}\}
. We have that for
\psi=\{\psi_{1},\psi_{2},\dots,\psi_{j}\}\in\mathcal{N}_{\Pi}^{j}
,

\mathcal{N}_{\Pi,\psi}^{i}=\{\{\chi_{1},\dots,\chi_{i}\}\mid\{\chi_{1},\dots,\chi_{i},\psi_{1},\dots,\psi_{j}\}\in\mathcal{N}_{\Pi}^{i+j}\}.

We now claim the following.

Lemma 17
.

For any valid input instance
(G,h_{\operatorname{in}})
,
\Pi^{*}
admits a valid solution.

Proof.

Let
(e_{1},e_{2},\dots,e_{l})
and
(f_{1},f_{2},\dots,f_{m})
be orderings of rank
2
edges and rank
1
edges respectively. We define a
labeling process
that goes through edges sequentially and fix the labels of half-edges incident on them.

•

Go through edges
e_{1},e_{2},\dots,e_{l}
sequentially. For an edge
e=e_{t},t\leq i
, do the following. Let
v_{1}
and
v_{2}
be the nodes incident on
e
. Suppose
h_{\operatorname{in}}(v_{1})=\mathcal{N}_{\Pi,\psi_{1}}^{i_{1}}
and
h_{\operatorname{in}}(v_{2})=\mathcal{N}_{\Pi,\psi_{2}}^{i_{2}}
where
\psi_{1}\in\mathcal{N}_{\Pi}^{j_{1}}
and
\mathcal{N}_{\Pi}^{j_{2}}
. Let
\psi_{1}=\{x_{1}\dots,x_{b_{1}},D,\dots,D\}

\psi_{2}=\{w_{1}\dots,w_{b_{2}},D,\dots,D\}
. Let
\chi_{1}=\{r_{1}\dots,r_{d_{1}}\}
(for

) and
\chi_{2}=\{p_{1},\dots,p_{d_{2}}\}
(for
d_{2}\leq i_{2}
)be the multisets of labels already assigned to incident half-edges on

and
v_{2}
respectively. Note

and
D\notin\chi_{2}
since only edges of rank

have their incident half-edge labeled

and none of them have chosen a label for their incident half-edges. Now

–

Case 1
: If

to half-edges incident on

–

Case 2

to half-edge

–

Case 3:
If

and

P
to the half-edges incident on

.

We will now show that any node has a valid node configuration. Let
v
be a node of degree

. Let

In fact, as round elimination also requires problems to be phrased in node-edge-checkable form—though without the minor additional technicality that comes due to semi-graphs—, a description in this form on semi-graphs can be usually derived from the respective round elimination considerations in the literature.
