Palindromes Compression and Retrieval
Michael Itzhaki

Abstract
This paper introduces a novel method for compressing palindromic structures in strings, establishing upper and lower bounds for their efficient representation. We uncover a unique relationship between the Lempel-Ziv parsing of palindromes and the alphabet size, leveraging this insight to propose a compression algorithm that improves space efficiency of Manacher array. Additionally, we present a data structure capable of storing all maximal palindromes (Manacher array) in sublinear space with near-optimal access time. Our approach reduces the memory overhead of storing palindromes, offering a new avenue for optimizing compression algorithms in text processing applications.

Introduction

Palindromes are sequences of characters that read the same forward and backward and have fascinated mathematicians, computer scientists, and linguists for centuries due to their unique properties. They represent a simple yet profound form of symmetry found not only in language, but also in number theory, DNA sequences, and algorithmic patterns. Palindromes have applications ranging from error detection in coding theory to the study of self-replicating structures in bioinformatics. In linguistics, palindromic words are a standard example for context-free languages. The exploration of palindromes sheds light on fundamental principles of pattern recognition, sequence alignment, and combinatorics, making them a crucial concept in theoretical and applied disciplines.

Given that many different data structures and algorithms only address a string’s palindromes or palindromic structure, storing the string’s palindromic structure in a compressed form is an intuitive advancement. The compressed representation should leverage its lossy nature and possibly support standard palindromic queries in time proportional to the compressed size rather than the original text size.

Technical Overview.

The paper is consisted of three main sections. The first of them shows that the Manacher array can always be represented using
O(n)

Section

4

The algorithm presents a data structure that supports element access in

Retrieving periodic palindromes relies on several properties of periods:

1.

By the periodicity lemma, a given periodic string has exacly one minimal period.

2.

Using bit-vector operations, finding the starting position of a period can be performed in constant time.

3.

Given the periodic structure of a string, many palindromic lengths can be computed in constant time.

Altogether, the final data structure stores information about periodic indices, and information about non-periodic palindromes. When a center is queried for its maximal palindrome, a center laying within a non-periodic palindrome can be retrieved, and when the center is part of a periodic palindrome, it is computed on the fly in constant time.

Note on Palindromic Centers.
Palindromic centers can occur at non-integer indices, such as 1.5, when dealing with even-length palindromes. A common approach to simplify algorithmic processing is to insert a non-existing character (e.g.,

This technique facilitates algorithmic proofs and can be easily worked around in practice.

Entropy of Manacher’s Array

At first glance, it might seem that since the only property preserved in the Manacher array is the palindromic structure of the string, a universal compression is possible. However, the palindromic structure of a string over alphabet
|\Sigma|\leq 3
can be used to reconstruct the exact same string.

Lemma 3.1
.

Let
A
be the Manacher array of size
2n-1
of a string
S
with alphabet
|\Sigma|\leq 3
, the array
A
suffices to reconstruct the original string
S
, up to a permutation.

Proof.

We will prove this theorem by induction on the length of the original string,
n
.

Base Case:
First, verify the base case for
n=1
. The only valid string is
S=a
(up to a permutation). Thus, the base case holds true.

Inductive Hypothesis:
Assume that the statement holds for some
k\geq 1
, i.e. given an array
A
of size
2k-1
of a string
S
, there exists an algorithm that recovers
S
up to a permutation.

Inductive Step:
Let
A
be an array of size
2k+1
.

Let us assume the array
A
is transformed such that it only reflects the palindromes in the first
k
characters. Such a transformation is possible, as all palindromes ending at the
k
-th character of the string or before are not changed, and all palindromes ending at the
k+1
-th character of the string are reduced by one on both sides.

Now, let us recover the last character. If the character participates in a non-trivial palindrome, then there exists a
j
such that
S[k+1]=S[j]
, and we assumed
S[j]
to be recovered correctly.

If the character does not participate in any non-trivial palindrome, it implies
S[k+1]\neq S[k]
.

Let
j
be the highest index such that
S[j]\neq S[k]
, or
-1
if such index does not exist.

If
j=-1
, then the string is of the form
x^{k}y
, and any choice of
y\neq x
is the only recovery, up to a permutation.

If
j\neq-1
, the string is of the form
Pyx^{i}z
, with
y\neq x
and
z\neq x
, and
P
is some prefix of
S
.

The characters

equal if and only if there exists a palindrome of length
i+2
, ending at index
k+1
, hence verifying if the palindrome exists suffices to decide whether to choose for

the only option that equals neither
x
nor

, and we already covered previously the case where the substring

is a palindrome.
∎

The above proof shows that the Manacher array suffices to retrieve the original string up to writing down a permutation of three characters, that only has
3!=6
options.

However, the claim is not always valid for arrays with
|\Sigma|>3
. For example, any string with no palindromes can be recovered as

or as

Properties of Palindromic Arrays

The well-established logarithmic bounds for alphabet size in palindromic-equivalent structures are significant. However, more specific structures can be identified through detailed analysis. In this section, we present the combinatorial results that will aid in computing the Lempel-Ziv parsing of the palindromic array in the next section.
