On the Normalization of Confusion Matrices: Methods and Geometric Interpretations
Johan Erbani, Pierre-Edouard Portier, Elod Egyed-Zsigmond, Sonia Ben Mokhtar, Diana Nurbakova

Abstract
The confusion matrix is a standard tool for evaluating classifiers by providing insights into class-level errors. In heterogeneous settings, its values are shaped by two main factors: class similarity—how easily the model confuses two classes—and distribution bias, arising from skewed distributions in the training and test sets. However, confusion matrix values reflect a mix of both factors, making it difficult to disentangle their individual contributions. To address this, we introduce bistochastic normalization using Iterative Proportional Fitting, a generalization of row and column normalization. Unlike standard normalizations, this method recovers the underlying structure of class similarity. By disentangling error sources, it enables more accurate diagnosis of model behavior and supports more targeted improvements. We also show a correspondence between confusion matrix normalizations and the model’s internal class representations. Both standard and bistochastic normalizations can be interpreted geometrically in this space, offering a deeper understanding of what normalization reveals about a classifier.

In practice, machine learning workflows often apply row, column, or all normalization to confusion matrices:

\operatorname{row}(M)_{ij}=\frac{M_{ij}}{M_{i+}},\ \operatorname{col}(M)_{ij}=\frac{M_{ij}}{M_{+j}},\ \operatorname{all}(M)_{ij}=\frac{M_{ij}}{M_{++}},

Class similarities in the confusion matrix are visible when all rows and columns have the same total, which typically occurs when both the test and training sets are balanced. When the test set and predictions are imbalanced, a double normalization of rows and columns in the same time is needed to reveal these similarities. )

Conclusion

Normalizing contingency tables—especially confusion matrices—using IPF procedure is not a new idea; it is even considered a standard approach in some disciplines. However, to the best of our knowledge, no existing work in machine learning employs this normalization to separate the effects of distribution bias and class similarity within confusion matrix. This decomposition provides deeper insights into the sources of errors, helping to assess and improve the classifier.

To the best of our knowledge, no prior work has connected confusion matrix normalization to the structure of class representations in a model’s latent space. We introduce a geometric perspective that clarifies the meaning of standard and bistochastic normalizations, offering deeper insights into classifier behavior.

Bistochastic Normalization

In this section, we define the bistochastic normalization, outline the key properties it should satisfy, and show how the IPF procedure can compute it accordingly.

Theoretical analysis is simpler with positive matrices. Since a non-negative confusion matrix
M
and its strictly positive counterpart
M+\epsilon
(for small
\epsilon
) exhibit similar model behavior, we propose using
M+\epsilon
instead. Experimental results demonstrate that this approach achieves strong performance. Therefore, without loss of generality, we assume
M
is a positive confusion matrix.

Unformal Definition & Desirable Properties

This subsection provides an informal definition of bistochastic normalization and introduces three key properties it should satisfy.

Unformal Definition.

\operatorname{bis}(M)
is a confusion matrix that is both row and column normalized, such that
\operatorname{bis}(M)_{i+}=\operatorname{bis}(M)_{+j}=1
. It approximates the confusion matrix one would obtain under balanced label and prediction distributions, capturing the model’s class similarities.

We now describe three desirable properties that this normalization is expected to satisfy.

Idempotence.
Normalization maps the matrix to a fixed scale. Once normalized, further normalization should not modify the matrix. Formally, we require
\operatorname{bis}\circ\operatorname{bis}(M)=\operatorname{bis}(M)
. This property also holds for standard normalizations, since
\operatorname{row}\circ\operatorname{row}(M)=\operatorname{row}(M)
and
\operatorname{col}\circ\operatorname{col}(M)=\operatorname{col}(M)
, where
\circ
is the composition operator.

Class Distribution Invariance.

We illustrate this property with the simpler case of row normalization. Consider two large test sets with different label distributions, producing confusion matrices
S
and
T
for the same trained model. The error patterns across rows should remain similar, meaning
S_{i\cdot}\mathrel{\vbox{\halign{\hfil$#$\cr\propto\cr\kern 2.0pt\cr\sim\cr\kern-2.0pt\cr}}}T_{i\cdot}
for all
i
, where
\mathrel{\vbox{\halign{\hfil$#$\cr\propto\cr\kern 2.0pt\cr\sim\cr\kern-2.0pt\cr}}}
denotes approximate equality up to a positive scaling factor
4
4

4

For vectors or matrices
U
and
V
of the same size,
U\mathrel{\vbox{\halign{\hfil$#$\cr\propto\cr\kern 2.0pt\cr\sim\cr\kern-2.0pt\cr}}}V
means
U\approx\lambda V
for some scalar
\lambda>0
.
, and
S_{i\cdot}
and
T_{i\cdot}
are the
i

. Thus,
\operatorname{row}(S)\approx\operatorname{row}(T)
, showing that row normalization is invariant to changes in label distribution.

This invariance follows from invariance under left-multiplication by a positive diagonal matrix: for any diagonal matrix
\alpha\in\mathbb{R}_{>0}^{C\times C}

\operatorname{row}(\alpha M)=\operatorname{row}(M)
. Similarly, column normalization is invariant under right-multiplication by a positive diagonal matrix:
\operatorname{col}(M\beta)=\operatorname{col}(M)
for any diagonal matrix
\beta\in\mathbb{R}_{>0}^{C\times C}

\operatorname{bis}(\alpha M\beta)=\operatorname{bis}(M)

Information Preservation.

Normalization should preserve as much of the original matrix’s structure as possible. To quantify the similarity between the original and normalized matrices, we propose using the Kullback–Leibler (KL) divergence as a dissimilarity measure. Given specific row and/or column constraints, the normalized matrix should be the one closest to the original matrix in terms of KL divergence.

Let
M
be a positive confusion matrix. As shown in the appendix, the standard normalization methods satisfy this criterion:

\operatorname{all}(M)\in\quad\underset{\mathclap{\begin{array}[]{c}P\in\mathbb{R}_{>0}^{C\times C}:\\
P_{i+}=\frac{M_{i+}}{M_{++}},P_{+j}=\frac{M_{+j}}{M_{++}}\ \forall\,i,j\end{array}}}{\operatorname{argmin}}\quad\ D_{\mathrm{KL}}(P\|M),

\operatorname{row}(M)\in\quad\underset{\mathclap{\begin{array}[]{c}P\in\mathbb{R}_{>0}^{C\times C}:\\
P_{i+}=1,P_{+j}=\sum_{i}\frac{M_{ij}}{M_{i+}}\ \forall\,i,j\end{array}}}{\operatorname{argmin}}\quad\ D_{\mathrm{KL}}(P\|M),

\operatorname{col}(M)\in\quad\underset{\mathclap{\begin{array}[]{c}P\in\mathbb{R}_{>0}^{C\times C}:\\
P_{i+}=\sum_{j}\frac{M_{ij}}{M_{+j}},P_{+j}=1\ \forall\,i,j\end{array}}}{\operatorname{argmin}}\quad\ D_{\mathrm{KL}}(P\|M),

where

denote the KL divergence of

from

A Geometric View of Model Class Representations

This section introduces a geometric approach to capture class similarities in the model’s latent space. The key idea is to represent class clusters as histograms (viewed as volumes) and measure how much these volumes overlap. This information is used to construct the Geometric Confusion Matrix (GCM). In the experimental section, we show that the GCM closely mirrors normalized confusion matrices, offering a geometric interpretation of the normalization process. All technical details are presented in the appendix.

Representation Space & Dimensionality Reduction

Let
\Phi
be the trained model and
\mathcal{D}
the dataset used to plot the confusion matrix. We use the output of the final pre-logit layer as the class representation space. Let
\varepsilon
be the embedding function, so that
\Phi(x)=\operatorname{Softmax}\circ\operatorname{Logit}\circ\ \varepsilon(x)
, where
\varepsilon(x)\in\mathbb{R}^{n}
for each
(x,y)\in\mathcal{D}
.

To facilitate histogram construction, we project the embeddings into a lower-dimensional space using Principal Component Analysis (PCA). Let
P
be the projection matrix with
m<n
, so that
P\varepsilon(x)\in\mathbb{R}^{m}
.

Class Clusters & Histograms

For each class
i
, we define the cluster of projected embedded points with true label
i
as
\mathcal{C}_{i}=\{P\varepsilon(x):(x,y)\in\mathcal{D},\ y=i\}
. Likewise, the cluster of points predicted as class
j
is
\widehat{\mathcal{C}}_{j}=\{P\varepsilon(x):(x,y)\in\mathcal{D},\ \hat{y}=j\}
, where
\hat{y}
denotes the predicted label based on
\Phi(x)
.

We construct one histogram per cluster. First, the projection space is divided into a regular grid of
m
-dimensional hyperrectangles
6
6

6

In geometry, a hyperrectangle is a generalization of a rectangle in 2D and a rectangular cuboid in 3D to higher dimensions
(
Saye 2015
)
.
, which define the histogram bins. For each cluster, we count how many projected points fall into each bin. The height of each bin is the number of points in the associated cell. This results in a multidimensional, non-overlapping histogram
(
Thaper et al. 2002
)
. We interpret each histogram as a volume in
\mathbb{R}^{m+1}
, offering a geometric representation of clusters. An illustration is provided in the Appendix.

Scaled Histograms

To refine our geometric representation, we construct scaled histograms by assigning a weight to each point. Instead of counting the number of points per bin, we sum the weights of the points falling into each bin.

Let
r
be the volume of each hyperrectangle forming the bins; it is treated as a fixed parameter. Let
l,p\in\mathbb{R}^{C}_{>0}
be positive weight vectors. We define the weighting function
w_{l,p}
as:

\begin{array}[]{llll}w_{l,p}:&[C]\times[C]&\to&\mathbb{R}_{>0}\\
&(y,\hat{y})&\mapsto&(r\ l_{y}\ p_{\hat{y}})^{-1}\end{array}

Given
l
and
p
, the height of a bin in the scaled histogram is the sum of the weights
w_{l,p}(y,\hat{y})
of all points from the cluster under consideration that fall into that bin.

We denote by
V(\mathcal{C},l,p)
the volume in
\mathbb{R}^{m+1}
of the scaled histogram built from cluster
\mathcal{C}
using weights
w_{l,p}
. Several examples are given below.

Let
\mathbf{1}
be the all-ones vector of size
C
, and set
l=p=\mathbf{1}/\sqrt{r}
. Then,

V(\mathcal{C}_{i},\frac{\mathbf{1}}{\sqrt{r}},\frac{\mathbf{1}}{\sqrt{r}}),\quad\text{and }V(\widehat{\mathcal{C}}_{j},\frac{\mathbf{1}}{\sqrt{r}},\frac{\mathbf{1}}{\sqrt{r}})

correspond to the unnormalized histograms of
\mathcal{C}_{i}
and
\widehat{\mathcal{C}}_{j}
.

Alternatively, define
\mathbf{c}=(\#\mathcal{C}_{1},\ldots,\#\mathcal{C}_{C})
and
\widehat{\mathbf{c}}=(\#\widehat{\mathcal{C}}_{1},\ldots,\#\widehat{\mathcal{C}}_{C})
. Then,

V(\mathcal{C}_{i},\mathbf{c},\mathbf{1})

, and

correspond to normalized histograms (i.e., of volume
1
) for
\mathcal{C}_{i}
and
\widehat{\mathcal{C}}_{j}
, respectively.

Finally, using an algorithm equivalent to IPF, we estimate the unique weight vectors
\mathbf{a}
and
\mathbf{b}
such that, under the same weighting function
w_{\mathbf{a},\mathbf{b}}

V(\mathcal{C}_{i},\mathbf{a},\mathbf{b})
, and

V(\widehat{\mathcal{C}}_{j},\mathbf{a},\mathbf{b})

correspond to normalized histograms for
\mathcal{C}_{i}
and
\widehat{\mathcal{C}}_{j}
, respectively (see Appendix for details).

From Geometric Confusion Matrices to Confusion Matrices

The GCM is defined such that entry

quantifies the overlap between the scaled histogram of label cluster

\displaystyle\bigg(\operatorname{GCM}_{l,p}\bigg)_{ij}

\displaystyle=\lambda\bigg(V(\mathcal{C}_{i},l,p)\cap V(\widehat{\mathcal{C}}_{j},l,p)\bigg),

P
and
Q
be two confusion matrices in
\mathbb{R}_{\geq 0}^{C\times C}
, possibly already normalized.

To measure the similarity between confusion matrices, we use their overlap:

\operatorname{Overlap}(P,Q)=\sum_{ij}\min\left(\operatorname{all}(P)_{ij},\operatorname{all}(Q)_{ij}\right),

where
\min
denotes the element-wise minimum (see Appendix for the rationale behind reusing
\operatorname{all}
normalization). This score ranges from
0
to
1
, with higher values indicating greater similarity. It reaches
1
if and only if
P=Q
.

This metric is strictly equivalent to the
L^{1}
distance:
\|\operatorname{all}(P)-\operatorname{all}(Q)\|_{1}=2-2\operatorname{Overlap}(P,Q)
(see Appendix for proof).

Conclusion and Future Work

We revisited confusion matrix normalization and showed that bistochastic normalization provides a principled way to isolate class similarity from distribution bias. While the use of IPF for contingency tables is well-established in other fields, its value for interpreting classifier behavior in machine learning has been largely overlooked. We demonstrated that bistochastic normalization reveals class similarities more clearly than standard methods, especially in heterogeneous settings.

We also introduced a geometric interpretation of normalization methods based on class representations in the latent space. Our results suggest that normalized confusion matrices are not just tools for evaluation—they offer insight into how models internally represent classes.

An important next step is to explore how bistochastic normalization and geometric interpretations can inform model training, for instance through regularization objectives.

This section proves statement in Section
Bistochastic Normalization
.

We first introduce the following lemma:

Lemma 1.

Let M be a positive matrix in
\mathbb{R}_{>0}^{C\times C}
, and
r
and
p
, be two positive vectors in
\mathbb{R}_{>0}^{C}
such that
r_{+}=c_{+}
. Then, any matrix
M^{*}
of the form
M^{*}=D_{1}MD_{2}
, where
D_{1}
and
D_{2}
are positive diagonal matrices such that

(D_{1}MD_{2})_{i+}=r_{i}\quad\text{and}\quad(D_{1}MD_{2})_{+j}=c_{j}\quad\text{for all }i,j,

is the unique solution to the following problem:

M^{*}\in\quad\underset{\mathclap{\begin{array}[]{c}P\in\mathbb{R}_{>0}^{C\times C}:\\
P_{i+}=r_{i},P_{+j}=c_{j}\ \forall\,i,j\end{array}}}{\operatorname{argmin}}\quad\ D_{\mathrm{KL}}(P\|M)

See Section
Proof of Lemma 1
for demonstration. Note that this result is already known in a different form, referred to as equivalence scaling (see Section 3. Different approaches to equivalence scaling in
(
Idel 2016
)
). We do not claim to introduce a new result with this lemma; rather, we were unable to find this particular formulation in the literature.

The normalizations
\operatorname{row}
,
\operatorname{col}
, and
\operatorname{all}
are decomposable as follows:

\displaystyle\operatorname{row}(M)=\operatorname{diag}(M_{1+},M_{2+},\ldots,M_{C+})MI,

\displaystyle\operatorname{col}(M)=IM\operatorname{diag}(M_{+1},M_{+2},\ldots,M_{+C}),\text{ and }

\displaystyle\operatorname{all}(M)=IMI/M_{++},

where
\operatorname{diag}
denotes the operator that creates a diagonal matrix from its input vector, and
I
the identity matrix. According to Lemma
A
, and under the appropriate constraints defined in Subsection
Unformal Definition & Desirable Properties
, these normalizations minimize the KL divergence as expected.

In Proposition
Formal Definition, Theoretical Properties & Estimation
, we claim that bistochastic normalization is idempotent, i.e.,
\operatorname{bis}\circ\operatorname{bis}(M)=\operatorname{bis}(M)
. By definition,
\operatorname{bis}\circ\operatorname{bis}(M)
is the solution to the problem

\quad\underset{\mathclap{\begin{array}[]{c}P\in\mathbb{R}_{>0}^{C\times C}:\\
P_{i+}=P_{+j}=1\ \forall\,i,j\end{array}}}{\operatorname{argmin}}\quad\ D_{\mathrm{KL}}(P\|\operatorname{bis}(M))

Moreover, we observe that
I\operatorname{bis}(M)I
satisfies the marginal constraints and can be expressed as a product of diagonal matrices and the matrix
\operatorname{bis}(M)
. By Lemma
A
,
I\operatorname{bis}(M)I
solves the above problem, and since the solution is unique, we have

\operatorname{bis}\circ\operatorname{bis}(M)=I\,\operatorname{bis}(M)\,I=\operatorname{bis}(M),

which establishes the idempotence property.

In Proposition
Formal Definition, Theoretical Properties & Estimation
, we also claim that for any diagonal matrices
\alpha,\beta\in\mathbb{R}_{>0}^{C\times C}
,
\operatorname{bis}(\alpha M\beta)=\operatorname{bis}(M)
. By Lemma
A
, there exist diagonal matrices
D_{1}
and
D_{2}
such that

\operatorname{bis}(\alpha M\beta)=D_{1}\alpha M\beta D_{2}.

By definition of the bistochastic normalization, the row and column sums satisfy

(D_{1}\alpha M\beta D_{2})_{i+}=(D_{1}\alpha M\beta D_{2})_{+j}=1\quad\forall i,j.

Additionally,
D_{1}\alpha
and
\beta D_{2}
are diagonal.
Therefore, by Lemma
A
,
\operatorname{bis}(\alpha M\beta)
is the unique solution to

\quad\underset{\mathclap{\begin{array}[]{c}P\in\mathbb{R}_{>0}^{C\times C}:\\
P_{i+}=1,P_{+j}=1\ \forall\,i,j\end{array}}}{\operatorname{argmin}}\quad\ D_{\mathrm{KL}}(P\|M)

This implies

\operatorname{bis}(\alpha M\beta)=\operatorname{bis}(M),

completing the proof.

Appendix C
Geometric Confusion Matrix

This section establishes the volumes of the various scaled histograms introduced previously, and compares the analytical form of the classical confusion matrix with that of the geometric confusion matrix.

Histogram Volumes

In this paper, we interpret histograms as volumes and claim that

V(\mathcal{C}_{i},\tfrac{\mathbf{1}}{\sqrt{r}},\tfrac{\mathbf{1}}{\sqrt{r}})\quad\text{and}\quad V(\widehat{\mathcal{C}}_{j},\tfrac{\mathbf{1}}{\sqrt{r}},\tfrac{\mathbf{1}}{\sqrt{r}})

have the same volume as the unnormalized histograms of
\mathcal{C}_{i}
and
\widehat{\mathcal{C}}_{j}
. We also state that
V(\mathcal{C}_{i},\mathbf{c},\mathbf{1})
and
V(\widehat{\mathcal{C}}_{j},\mathbf{1},\widehat{\mathbf{c}})
correspond to histograms of volume 1. Finally, we claim that

V(\mathcal{C}_{i},\mathbf{a},\mathbf{b})\quad\text{and}\quad V(\widehat{\mathcal{C}}_{j},\mathbf{a},\mathbf{b})

also represent histograms of volume 1, where
\mathbf{a}
and
\mathbf{b}
are two weighting vectors not explicitly defined in the main body of the paper.

To justify these claims, we introduce the following lemma.

Lemma 2.

Let
\mathcal{C}
be a cluster of points in the model’s latent space, based on dataset
\mathcal{D}
. Let
P
be a projection matrix, and let
l,p\in\mathbb{R}^{C}_{>0}
be positive weighting vectors used in the weighting function
w_{l,p}
. Then,

\lambda(V(\mathcal{C},l,p))=\sum_{(x,y)\in\mathcal{D}}\frac{\mathbb{1}_{P\varepsilon(x)\in\mathcal{C}}}{l_{y}p_{\hat{y}}},

where
\lambda
denotes the Lebesgue measure and
\mathbb{1}
is the indicator function.

Proof.

We begin by decomposing the histogram into a union of hyperrectangles, denoted by
\mathcal{V}
. Since
\mathcal{D}
contains a finite number of points, the covering set
\mathcal{V}
is also finite. By construction of the weighted histogram, we have

\displaystyle V(\mathcal{C},l,p)

\displaystyle=\bigcup_{v\in\mathcal{V}}\left(V(\mathcal{C},l,p)\cap v\right)

\displaystyle=\bigcup_{v\in\mathcal{V}}r_{1}\times\cdots\times r_{m}\times\left[0,\sum_{(x,y)\in\mathcal{D}}\mathbb{1}_{P\varepsilon(x)\in\mathcal{C}\cap v}\,w_{l,p}(y,\hat{y})\right]

where
r_{1},\ldots,r_{m}
are the spatial dimensions of each hyperrectangle side.

While the bars of the histogram may slightly overlap, these intersections have zero measure and do not affect the total volume. Hence, the Lebesgue measure of the union is the sum of the measures:

\displaystyle\lambda(V(\mathcal{C},l,p))=

\displaystyle\sum_{v\in\mathcal{V}}\lambda(r_{1}\times\cdots\times r_{m}\times\left[0,\sum_{(x,y)\in\mathcal{D}}\mathbb{1}_{P\varepsilon(x)\in\mathcal{C}\cap v}\,w_{l,p}(y,\hat{y})\right])

The Lebesgue measure of a hyperrectangle is the product of its side lengths. Let
r=\prod_{i=1}^{m}r_{i}
. Then,

\displaystyle\lambda(V(\mathcal{C},l,p))

\displaystyle=\sum_{v\in\mathcal{V}}r\sum_{(x,y)\in\mathcal{D}}\mathbb{1}_{P\varepsilon(x)\in\mathcal{C}\cap v}\ w_{l,p}(y,\hat{y})

\displaystyle=\sum_{(x,y)\in\mathcal{D}}\frac{\sum_{v\in\mathcal{V}}\mathbb{1}_{P\varepsilon(x)\in\mathcal{C}\cap v}}{l_{y}p_{\hat{y}}}

\displaystyle=\sum_{(x,y)\in\mathcal{D}}\frac{\mathbb{1}_{P\varepsilon(x)\in\mathcal{C}}}{l_{y}p_{\hat{y}}},

which concludes the proof.
∎

According to Lemma
C
, we have

\lambda\left(V(\mathcal{C}_{i},\tfrac{\mathbf{1}}{\sqrt{r}},\tfrac{\mathbf{1}}{\sqrt{r}})\right)=r\sum_{(x,y)\in\mathcal{D}}\mathbb{1}_{P\varepsilon(x)\in\mathcal{C}_{i}},

which corresponds, as expected, to the volume of an unnormalized histogram. A direct application of the same lemma shows that the Lebesgue measure of
V(\mathcal{C}_{i},\mathbf{c},\mathbf{1})
and
V(\widehat{\mathcal{C}}_{j},\mathbf{1},\widehat{\mathbf{c}})
is equal to 1.

Additionally, by Lemma
A
, there exist positive diagonal matrices
D_{1}
and
D_{2}
such that
\operatorname{bis}(M)=D_{1}MD_{2}
. Let
\mathbf{a}
and
\mathbf{b}
denote the diagonals of
D_{1}^{-1}
and
D_{2}^{-1}
, respectively. By Lemma
C
, we have:

\displaystyle\lambda\left(V(\mathcal{C}_{i},\mathbf{a},\mathbf{b})\right)

\displaystyle=\sum_{(x,y)\in\mathcal{D}}\frac{\mathbb{1}_{P\varepsilon(x)\in\mathcal{C}_{i}}}{a_{y}b_{\hat{y}}}

\displaystyle=\sum_{(x,y)\in\mathcal{D}}\frac{\mathbb{1}_{y=i}}{a_{i}b_{\hat{y}}}

\displaystyle=\sum_{j=1}^{C}\sum_{(x,y)\in\mathcal{D}}\frac{\mathbb{1}_{y=i}\mathbb{1}_{\hat{y}=j}}{a_{i}b_{j}}

\displaystyle=\sum_{j=1}^{C}\frac{\sum_{(x,y)\in\mathcal{D}}\mathbb{1}_{y=i}\mathbb{1}_{\hat{y}=j}}{a_{i}b_{j}}

\displaystyle=\sum_{j=1}^{C}\frac{M_{ij}}{a_{i}b_{j}}

\displaystyle=\sum_{j=1}^{C}(D_{1})_{i}M_{ij}(D_{2})_{j}

\displaystyle=(D_{1}MD_{2})_{i+}=1,

as expected. To estimate
D_{1}
and
D_{2}
, we use the RAS method described in Algorithm

. This algorithm is equivalent to Algorithm

; see

for details.

Geometric Confusion Matrix

The Geometric Confusion Matrix is defined as

\displaystyle\bigg(\operatorname{GCM}_{l,p}\bigg)_{ij}

\displaystyle=\lambda\bigg(V(\mathcal{C}_{i},l,p)\cap V(\widehat{\mathcal{C}}_{j},l,p)\bigg)

We begin by deriving an explicit formula for
\operatorname{GCM}_{l,p}
. Following the same approach as in proof of Lemma
A
, and noting that the grid of hyperrectangles partitioning the projection space is shared across all histograms, the intersection of two histograms is given by:

\displaystyle V(\mathcal{C}_{i},l,p)\cap V(\widehat{\mathcal{C}}_{j},l,p)=

\displaystyle\bigcup_{v\in\mathcal{V}}r_{1}\times\cdots\times r_{m}\times\left[0,\sum_{(x,y)\in\mathcal{D}}\mathbb{1}_{P\varepsilon(x)\in\mathcal{C}_{i}\cap v}\,w_{l,p}(y,\hat{y})\right]

\displaystyle\bigcap

\displaystyle\bigcup_{v\in\mathcal{V}}r_{1}\times\cdots\times r_{m}\times\left[0,\sum_{(x,y)\in\mathcal{D}}\mathbb{1}_{P\varepsilon(x)\in\widehat{\mathcal{C}}_{j}\cap v}\,w_{l,p}(y,\hat{y})\right]

\displaystyle=

\displaystyle\bigcup_{v\in\mathcal{V}}r_{1}\times\cdots\times r_{m}\times\Bigg[0,

\displaystyle\min\Bigg(\sum_{(x,y)\in\mathcal{D}}\mathbb{1}_{P\varepsilon(x)\in\mathcal{C}_{i}\cap v}\,w_{l,p}(y,\hat{y}),

\displaystyle\sum_{(x,y)\in\mathcal{D}}\mathbb{1}_{P\varepsilon(x)\in\widehat{\mathcal{C}}_{j}\cap v}\,w_{l,p}(y,\hat{y})\Bigg)\Bigg]

As a result, the
(i,j)
entry of the geometric confusion matrix becomes:

\displaystyle\bigg(\operatorname{GCM}_{l,p}\bigg)_{ij}

\displaystyle=\sum_{v\in\mathcal{V}}\min\Bigg(\sum_{(x,y)\in\mathcal{D}}\frac{\mathbb{1}_{P\varepsilon(x)\in\mathcal{C}_{i}\cap v}}{l_{y}p_{\hat{y}}},\sum_{(x,y)\in\mathcal{D}}\frac{\mathbb{1}_{P\varepsilon(x)\in\widehat{\mathcal{C}}_{j}\cap v}}{l_{y}p_{\hat{y}}}\Bigg)

The standard confusion matrix can also be rewritten as a sum over grid cells, similarly to
\operatorname{GCM}_{l,p}
:

\displaystyle M_{ij}

\displaystyle=\sum_{(x,y)\in\mathcal{D}}\mathbb{1}_{y=i}\mathbb{1}_{\hat{y}=j}

\displaystyle=\sum_{(x,y)\in\mathcal{D}}\mathbb{1}_{P\varepsilon(x)\in\mathcal{C}_{i}\cap\widehat{\mathcal{C}}_{j}}

\displaystyle=\sum_{(x,y)\in\mathcal{D}}\sum_{v\in\mathcal{V}}\sum_{(x,y)\in\mathcal{D}}\mathbb{1}_{P\varepsilon(x)\in\mathcal{C}_{i}\cap\widehat{\mathcal{C}}_{j}}\mathbb{1}_{P\varepsilon(x)\in v}

\displaystyle=\sum_{v\in\mathcal{V}}\sum_{(x,y)\in\mathcal{D}}\mathbb{1}_{P\varepsilon(x)\in\mathcal{C}_{i}\cap\widehat{\mathcal{C}}_{j}\cap v}

This explicit formula for
\operatorname{GCM}_{l,p}
highlights how the geometric confusion matrix incorporates spatial information. Ignoring the normalization weights
l_{y}p_{\hat{y}}
, the geometric confusion matrix compares in each grid cell the number of points labeled
i
(regardless of prediction) with the number of points predicted as
j
(regardless of true label). As a result, in a grid cell containing only points with label
i
and prediction
j
, the contribution to
\operatorname{GCM}_{l,p}
matches that of the standard confusion matrix. In contrast, in a cell containing a mix of labels and predictions, the minimum operation produces a contribution that differs from the simple count of points labeled
i
and predicted as
j
—that is, from the contribution in the standard confusion matrix.

Appendix D
Overlap Metric

This section explains the rationale for normalizing confusion matrices when computing the Overlap metric, and shows its equivalence with the
L_{1}
distance.

Why Normalize?

The entries of a confusion matrix are only meaningful relative to each other; absolute values lack interpretability. For example,
P_{ii}=3
indicates perfect classification if
P_{i+}=3
, but poor performance if
P_{i+}=30
. More generally, for any
\lambda>0
,
P
and
\lambda P
represent the same model behavior.

Comparisons between two matrices are meaningful when they share the same total sum, i.e.,
P_{++}=Q_{++}
. For instance,
P_{ii}=1
may seem worse than
Q_{ii}=3
, but if
P_{++}=3
and
Q_{++}=30
, the relative accuracies are identical:
P_{ii}/P_{++}=Q_{ii}/Q_{++}
.

For consistency, we compare normalized confusion matrices:
\operatorname{all}(P)=P/P_{++}
and
\operatorname{all}(Q)=Q/Q_{++}
. This ensures that behaviors are preserved and enables consistent comparisons.

Equivalence with
L_{1}
Distance

Let
P
and
Q
be two matrices such that
P_{++}=Q_{++}=1
. Then,

\displaystyle\|P-Q\|_{1}

\displaystyle=\sum_{ij}|P_{ij}-Q_{ij}|

\displaystyle=\sum_{ij}\max(P_{ij},Q_{ij})-\min(P_{ij},Q_{ij})

\displaystyle=\sum_{ij:P_{ij}\geq Q_{ij}}P_{ij}-\min(P_{ij},Q_{ij})

\displaystyle+\sum_{ij:Q_{ij}>P_{ij}}Q_{ij}-\min(P_{ij},Q_{ij})

\displaystyle=\sum_{ij}P_{ij}-\min(P_{ij},Q_{ij})

\displaystyle+\sum_{ij}Q_{ij}-\min(P_{ij},Q_{ij})

\displaystyle=2-2\operatorname{Overlap}(P,Q)

Thus, the Overlap metric is directly related to the
L_{1}
distance.

Appendix G
Proof of Lemma
A

This section aims to solve the following constrained minimization problem:

M^{*}\in\quad\underset{\mathclap{\begin{array}[]{c}P\in\mathbb{R}_{>0}^{C\times C}:\\
P_{i+}=r_{i},P_{+j}=c_{j}\ \forall\,i,j\end{array}}}{\operatorname{argmin}}\quad\ D_{\mathrm{KL}}(P\|M),

where
M\in\mathbb{R}_{>0}^{C\times C}
and
r_{+}=c_{+}
.

Problem Reformulation

We use the method of Lagrange multipliers. We define the row constraints for
i=1,\ldots,C
as:

\begin{array}[]{llll}h_{i}:&\mathbb{R}_{>0}^{C\times C}&\to&\mathbb{R}\\
&P&\mapsto&P_{i+}-r_{i}\end{array}

and the column constraints for
j=1,\ldots,C
as:

\begin{array}[]{llll}g_{j}:&\mathbb{R}_{>0}^{C\times C}&\to&\mathbb{R}\\
&P&\mapsto&P_{+j}-c_{j}\end{array}

Since adding a constant to the objective function does not affect the arguments of the minima, we define
f(P):=D_{\mathrm{KL}}(P\|M)-1
to simplify the derivative calculations.

The optimization problem becomes:

M^{*}\in\quad\underset{\mathclap{\begin{array}[]{c}P\in\mathbb{R}_{>0}^{C\times C}:\\
h_{i}(P)=g_{j}(P)=0\ \forall\,i,j\end{array}}}{\operatorname{argmin}}\quad\ f(P)

The functions
f
,
h_{i}
, and
g_{j}
are continuously differentiable.

Karush-Kuhn-Tucker Conditions

To find a solution, we apply the Karush-Kuhn-Tucker (KKT) conditions (see
Section 5.5.3: KKT Optimality Conditions
in
(
Boyd and Vandenberghe 2004
)
). These conditions are necessary for a point
M^{*}
to be a local minimum when a constraint qualification is satisfied. In our case, the constraints
h_{i}
,
g_{j}
are affine. Therefore, the Linearity Constraint Qualification (LCQ) holds, making the KKT conditions necessary.

Moreover, since
f
is convex (as shown in a subsection below), and the constraint set is convex, the KKT conditions are also sufficient for optimality
(
Boyd and Vandenberghe 2004
)
. Thus, any point satisfying the KKT conditions is a global minimum.

In other words, any matrix
P^{*}
and multipliers
\mu^{*}
and
\nu^{*}
satisfying:

\nabla_{P}L(P^{*},\mu^{*},\nu^{*})=0

is a global minimum, where the Lagrangian is given by:

L(P,\mu,\nu)=f(P)+\sum_{i=1}^{C}\mu_{i}h_{i}(P)+\sum_{j=1}^{C}\nu_{j}g_{j}(P)

Since
f
is strictly convex (see Subsection
Convexity of
f
), this minimum is also unique.

Solution

Let
P
be an admissible point. We compute the gradient of the Lagrangian
8
8

8

Though the gradient is a vector, we index it here by
(i,j)
for clarity.
:

\nabla_{P}L(P,\mu,\nu)_{ij}=\left[\ln\left(\frac{P_{ij}}{M_{ij}}\right)+\mu_{i}+\nu_{j}\right]_{ij}

Setting the gradient to zero gives:

\displaystyle\ln\left(\frac{P_{ij}}{M_{ij}}\right)+\mu_{i}+\nu_{j}=0

\displaystyle\Leftrightarrow

\displaystyle P_{ij}=\exp(-\mu_{i})M_{ij}\exp(-\nu_{j})

We define diagonal matrices
D_{1}
and
D_{2}
with entries:

(D_{1})_{ii}=\exp(-\mu_{i}),\qquad(D_{2})_{jj}=\exp(-\nu_{j})

Then the solution takes the form:

P=D_{1}MD_{2}

In conclusion, any matrix of the form
D_{1}MD_{2}
that satisfies the given row and column constraints is the unique solution to the minimization problem.

Convexity of
f

Let
P,P^{\prime}\in\mathbb{R}_{>0}^{C\times C}
be two distinct matrices, and let
\lambda\in(0,1)
. The function
f
is strictly convex if and only if

f(\lambda P+(1-\lambda)P^{\prime})<\lambda f(P)+(1-\lambda)f(P^{\prime}).

We now prove this inequality. We first show that the KL divergence is strictly convex in
P
when
M
is fixed.

\displaystyle D_{\mathrm{KL}}(\lambda P+(1-\lambda)P^{\prime}\|M)

\displaystyle=\sum_{ij}\bigg(\lambda P+(1-\lambda)P^{\prime}\bigg)\ln\bigg(\frac{\lambda P+(1-\lambda)P^{\prime}}{\lambda M+(1-\lambda)M}\bigg)

\displaystyle<\sum_{ij}\lambda P\ln\bigg(\frac{P}{M}\bigg)+(1-\lambda)P^{\prime}\ln\bigg(\frac{P^{\prime}}{M}\bigg)

\displaystyle=\lambda D_{\mathrm{KL}}(P\|M)+(1-\lambda)D_{\mathrm{KL}}(P^{\prime}\|M)

where the strict inequality follows from the log-sum inequality, which becomes strict when
P\neq P^{\prime}
. This implies that
f
is strictly convex, which completes the proof.
