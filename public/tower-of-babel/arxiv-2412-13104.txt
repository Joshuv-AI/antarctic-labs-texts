Intermediate Relation Size Bounds for Select-Project-Join-Union Query Plans
Hubie Chen, Markus Schneider

Abstract
We study the problem of statically optimizing select-project-join-union (SPJU) plans where unary key constraints are allowed. A natural measure of a plan, which we call the output degree and which has been studied previously, is the minimum degree of a polynomial bounding the plan’s output relation, as a function of the input database’s maximum relation size. This measure is, by definition, invariant under passing from a plan to another plan that is semantically equivalent to the first. In this article, we consider a plan measure which we call the intermediate degree; this measure is defined to be the minimum degree of a polynomial bounding the size of all intermediate relations computed during a plan’s execution — again, as a function of the input database’s maximum relation size. We present an algorithm that, given an SPJU plan p p and a set Σ \Sigma of unary keys, computes an SPJU plan p ′ p^{\prime} that is semantically equivalent to p p (over databases satisfying Σ \Sigma ) and that has the minimum intermediate degree over all such semantically equivalent plans. For the types of plans considered, we thus obtain a complete and effective understanding of intermediate degree.

Introduction

Background and motivation.

Modern database systems capable of evaluating queries
of the standard query language SQL typically have,
as a key component, a query optimizer that synthesizes
execution plans consisting of basic operations from a
relational algebra; techniques for estimating and comparing the
costs of evaluating such plans are considered central
in the study of databases
[
1
, Chapter 6]
.
In this article, we study a basic measure
of execution plans:
the
intermediate size
, by which we mean
the maximum size
over all intermediate relations computed during a query’s execution,
relative to a database.
We view this as a natural and fundamental measure:
the intermediate size gives an obvious lower bound on the amount of time
needed to execute a plan, for algorithms that explicitly materialize
all intermediate relations; and, it characterizes the amount of space
needed to store the results of all such intermediate relations.

We study this size measure in an asymptotic setting,
as a function of the maximum relation size
M_{\mathbf{D}}
of a database
\mathbf{D}
.
We say that a plan
has
intermediate degree

d
when
d\geq 0
and
there exists a degree
d
polynomial upper bounding the plan’s intermediate size,
as a function of
M_{\mathbf{D}}
,
but no lower degree polynomial provides such a bound.
We study this measure for SPJU query plans,
which allow
select
,
project
,
join

and
union

as operations on relations. These plans
are semantically equivalent to unions of conjunctive queries,
and
are intensely studied throughout database theory.
We permit
unary key constraints
to be expressed on database relations.
In essence, a unary key constraint states
that there is a single coordinate of a relation where, for each tuple in the relation, knowing the value at the coordinate determines the entire tuple.

Having identified a relevant complexity measure of query plans—the intermediate degree—and a relevant class of query plans—the SPJU query plans, one of the most basic and natural questions one could ask, from the standpoint of query optimization, is this: is there an algorithm that receives a query plan as input, and reformulates it into a semantically equivalent query plan whose intermediate degree is minimal, over all such equivalent plans? That is, is there an algorithm that can statically analyze a given query plan, and reformulate it so as to optimally minimize the intermediate degree, without disrupting the plan’s semantics? A primary contribution of this article is a positive answer to this question.

Contributions.

Our main theorem presents a minimization algorithm that, given an SPJU plan
p

with a set
\Sigma
of unary key constraints,
computes an SPJU plan
p^{\prime}
that is semantically equivalent to
p
(with respect to databases satisfying the constraints
\Sigma
),
and has the lowest possible intermediate degree
over all SPJU plans that are so semantically equivalent to
p
.
This theorem thus yields, in the asymptotic setting considered,
a full understanding of how to
statically optimize the intermediate degree so that it is the minimum possible.
We remark that (to our knowledge) this type of understanding was not previously known even for SPJ plans (SPJU plans that do not use the union operator) and on databases without any constraints.
We view the definition of the
notion of
intermediate degree
,
and its supporting theory, as conceptual contributions of this work.

Our result showing how
to minimize the intermediate degree amounts to demonstrating how to compute,
for any given plan,
an asymptotically optimal procedure
in a restricted model of computation, namely, the class of SPJU plans.
Our focus on polynomial degree is aligned with the notion of
fixed-parameter tractability, whereby a problem is tractable essentially
when there is a degree
d
such that each so-called
slice

has an algorithm with running time bounded above by a degree
d
polynomial;
a
slice
is a set of all instances sharing the same
parameter
,
which is a value associated with each instance.

To prove our result, we make a number of technical contributions that we believe will be of significant utility in the future study of intermediate degree, which
we view as a highly natural measure of plan complexity.
One tool that we present (in Subsection
4.1
) is
a theorem showing how to convert an SPJ query plan to
a relational structure along with a certain form of tree decomposition
of the structure; this allows us to apply structural measures
based on tree decompositions to reason about the intermediate degree of plans.
As a first step towards our main result, we show a restricted version of the main theorem to SPJ plans, that is, an algorithm that, given an SPJ plan
p
and a set
\Sigma
of unary keys, outputs a semantically equivalent SPJ plan
p^{\prime}
(over all databases satisfying
\Sigma
) with the lowest possible intermediate degree.
While the way that this algorithm computes the minimized plan
p^{\prime}
from a given plan
p
is, on a high level, quite natural — essentially,
p^{\prime}
is based on the core of the chase of a relational structure naturally derived from
p
— the proof that
p^{\prime}
is minimal in the desired sense is non-trivial, since we have to reason about arbitrary plans that are semantically equivalent to
p^{\prime}
.
Intuitively, the core is a minimized version of a relational structure and the chase is a well-known procedure that enforces constraints on a relational structure.

As defined, the intermediate degree is a measure of query plans. It follows from our definitions that any
algorithm for evaluating a query plan
q
that materializes all intermediate relations must require time at least
\Omega(M_{\mathbf{D}}^{d})
, where
d
is the intermediate degree of
q
.
That is, the polynomial time
dependence on
M_{\mathbf{D}}
must be of degree at least
d
.
Having observed this lower bound, we are naturally led to the question of whether or not this bound is tight.
We present results indicating that it is, which renders the intermediate degree as an algorithmically meaningful measure.
When given a plan
p
, our minimization algorithm can always output a plan
p^{\prime}
with the properties described above, and with the additional syntactic property that
p^{\prime}
is
well-behaved
;
as we show, well-behavedness of a plan
q
implies that there is an evaluation algorithm for evaluating
q
on a database
\mathbf{D}

that always runs within time
M_{\mathbf{D}}^{d}
times a multiplicative overhead, where
d
is the intermediate degree of
q
. So, a well-behaved plan can be algorithmically evaluated in time close to
O(M_{\mathbf{D}}^{d})
, complementing the time lower bound of
\Omega(M_{\mathbf{D}}^{d})
discussed above.
We leave an analysis of the exact nature of the multiplicative overhead as a question for future work; we wish to emphasize here that the analysis of our evaluation algorithm and the resulting time bound are obtained in an elementary fashion.

Related Work.

Our work is inspired by and is closely related to
the work of Atserias, Grohe, and Marx
[
12
,
2
]
, as well as the follow-up work thereof by
Gottlob, Lee, Valiant, and Valiant
[
10
]
.
A main result shown by
[
2
]
yields a general upper bound—the
AGM bound
—on the
output size of any pure join plan
q
, namely, a bound of
M_{\mathbf{D}}^{\rho^{*}(q)}
, where
\rho^{*}(q)
is the so-called fractional edge cover number of the plan
q
.
They also supply an argument that this upper bound is tight.
Here, by a pure join plan, we mean
a plan that consists only of joins and basic relations of a database.

Let us define the
output degree
of a query to be the minimum degree of a polynomial bounding the query’s output relation, as a function of
the maximum relation size
M_{\mathbf{D}}
of a database
\mathbf{D}
.
Note that while the output degree is
clearly invariant under passing from a query to another query
that is semantically equivalent to the first, the intermediate degree
does not enjoy this invariance.
The AGM bound along with the argument that it is tight establish
\rho^{*}(q)
as the output degree
of a pure join plan
q
.
The article
[
2
]

also exhibits, for each such pure join plan, a semantically equivalent
join-project plan whose intermediate relations all have size
less than (or equal to) the output size, implying
a characterization of the
minimum
intermediate degree (over semantically equivalent plans) as the fractional edge cover number—for pure join plans.
We view the article
[
2
]
as begging the study of more
general classes of plans:
they show explicitly
the necessity of using projections in the plans witnessing
that the intermediate relation sizes can be made to be at most
the output size!

Extending the AGM bound, the work
[
10
]
characterizes
the output degree of any SPJ plan and considering databases where unary key constraints
can be expressed; this is done by identifying a measure called
the
color number
.
Note that this measure generalizes the fractional edge cover number
(as discussed in Section 4 of
[
10
]
).
Our work builds on this measure and the accompanying understanding of unary key constraints. In particular,
in the present work, we naturally extend the notion of color number
to define a measure of tree decompositions.
We remark that the results of
[
10
]

are phrased in terms of
conjunctive queries, which are semantically equivalent to SPJ plans.

An important and influential line of research emerging after
the work of Atserias, Grohe, and Marx presented new join algorithms,
so-called worst-case optimal join algorithms,
with running times shown to be bounded above by
the AGM bound—apart from a multiplicative overhead
(see for example
[
19
,
18
,
17
]
and the discussion therein).
Building on this work, further research presented algorithms, with
running time analyses, for more general forms of queries, including queries with
aggregates
[
13
,
14
]
.
The focus of these further works are on presenting algorithms and
upper bounding
their running time in terms of structural measures, generally without considering how to minimize queries up to semantic equivalence; the present article establishes a complementary result by showing, for each query plan
p
, a
tight lower bound
on the running time of a restricted class of procedures, namely, procedures that can be described by plans that are semantically equivalent to the given plan
p
.

Perspective.
One measure of query plans that has been studied heavily is
width
, which by now has a mature underlying theory (refer for example to
[
15
,
11
,
6
,
3
,
20
,
4
,
7
]
); while this measure is often defined on logical formulas (and is sometimes formulated as the
number of variables
), for a query plan the
width
amounts to the maximum arity over all subplans. The present article is a contribution to a general research direction whereby we hope to identify further meaningful and informative measures of query plans, and study how to minimize various classes of queries with respect to introduced measures.

Outline.

In Section

3
Degree Notions and Main Theorem Statement

3.1
Degree notions

A key measure in the context of query optimization is the size of the output of a query. Here, we are interested in an asymptotic measure: the output degree of a query plan
p
, which, informally, is the smallest possible degree of a polynomial bounding the output size of
p
on any structure
\mathbf{D}
satisfying given constraints, as a function of the maximum relation size
M_{\mathbf{D}}
; the formal definition is the following.

Definition 3.1

(Output Degree)
.

Let
\Sigma
be a set of keys over signature
\sigma
. Let
p
be a plan over
\sigma
, and let
d\in\mathbb{Q}
. The plan
p
has
output degree
\leq d
if there exists a function
h:\mathbb{N}\to\mathbb{N}
, with
h(M)\in O(M^{d})
, such that for every structure
\mathbf{D}
satisfying
\Sigma
, it holds that
|\mathsf{out}(p,\mathbf{D})|\leq h(M_{\mathbf{D}})
.
We say that
p
has
output degree
d
if it has output degree
\leq d
, but for all
\epsilon>0
, it does not have output degree
\leq(d-\epsilon)
.

Instead of just focusing on some plan as a whole, we are interested in bounding also the size of the output of every subplan of the original plan, or in other words, bounding the size of intermediate results obtained during the execution of the plan.
To do so, we say a plan
p
has intermediate degree
d
if there exists a degree
d
polynomial bounding the sizes of all intermediate relations computed during the execution of
p
on any structure
\mathbf{D}
satisfying given constraints, as a function of
M_{\mathbf{D}}
—and again, there is no lower degree polynomial providing such a bound.

Definition 3.2

(Intermediate Degree)
.

Let
\Sigma
be a set of keys over signature
\sigma
. Let
p
be a plan over
\sigma
, and let
d\in\mathbb{Q}
. The plan
p
has
intermediate degree
\leq d
if there exists a function
h:\mathbb{N}\to\mathbb{N}
, with
h(M)\in O(M^{d})
, such that for every structure
\mathbf{D}
satisfying
\Sigma
, and for every subplan
q
of
p
, it holds that
|\mathsf{out}(q,\mathbf{D})|\leq h(M_{\mathbf{D}})
.
We say that
p
has
intermediate degree
d
if it has intermediate degree
\leq d
, but for all
\epsilon>0
, it does not have intermediate degree
\leq(d-\epsilon)
.

Note that the above definitions of output degree and intermediate degree are with respect to the keys
\Sigma
, but we omit
\Sigma
when it is clear from context for the sake of readability.
Let
\Sigma
be a set of keys.
We say that a plan
p
has the
SPJ-best possible intermediate degree
if there exists
d\in\mathbb{Q}
such that
p
has intermediate degree
d
, and for every SPJ plan
p^{\prime}
that is
\Sigma
-semantically equivalent to
p
, there is no value
\epsilon>0
such that the plan
p^{\prime}
has intermediate degree
\leq(d-\epsilon)
.
In other words, no
\Sigma
-semantically equivalent SPJ plan achieves an intermediate degree that is strictly lower than that of
p
.
Analogously, we say that a plan
p
has the
SPJU-best possible intermediate degree
if there exists
d\in\mathbb{Q}
such that
p
has intermediate degree
d
, and for every SPJU plan
p^{\prime}
that is
\Sigma
-semantically equivalent to
p
, there is no value
\epsilon>0
such that the plan
p^{\prime}

has intermediate degree
\leq(d-\epsilon)
.

In the appendix, we give a number of examples of plans along with computations of the output degree and the best possible intermediate degree.

3.2
Main theorem statement

We are now ready to formulate our main theorem.

Theorem 3.3

(Main theorem)
.

There exists an exponential-time algorithm that, given a signature
\sigma
, a set
\Sigma
of unary keys over
\sigma
, and an SPJU plan
p
over
\sigma

satisfying the following properties:

•

p^{\prime}
is
\Sigma
-semantically equivalent to

•

By an exponential-time algorithm, we mean an algorithm that runs within time

, where

The principal argumentation needed to establish our main theorem is located in the case where this theorem is specialized to SPJ queries.
In this case, which we present next, we can describe the intermediate degree of the output plan quite directly, but require the following notion to do so.
A

of a plan

is an open structure
(\mathbf{A},\overline{a})
where, for any structure

\mathsf{out}(p,\mathbf{D})=\mathsf{homs}(\mathbf{A},\overline{a},\mathbf{D})
. A formal treatment of

Theorem 3.4
.

There exists an exponential-time algorithm that, given a signature
\sigma
, a set
\Sigma
of unary keys over
\sigma
, and an SPJ plan
p
over
\sigma
, outputs a SPJ plan

satisfying the following properties:

•

p^{\prime}
is
\Sigma
-semantically equivalent to
p
,

•

p^{\prime}
has the SPJ-best possible intermediate degree.

Moreover, suppose that
p
is an SPJ plan over
\sigma
and
that
(\mathbf{A},\overline{a})
is a

(\mathbf{C},\overline{c})
be a core of

, and let

.
Then, when the algorithm is given

Some remarks are in order. First, note that in Theorem

, the intermediate degree of each plan

can be described quite explicitly.
Note also that given an SPJ plan

of the plan

given by the algorithm of Theorem

is computable in exponential time from

In turn, given an SPJU plan

We also wish to remark that, while our main theorem only considers constraints which are unary keys, this limitation arises from the literature on output degree bounds; extending the literature’s bounds is likely to be challenging, for this would constitute significant progress towards a long-standing open problem in information theory

3.3
Algorithmic aspects

We here discuss algorithms for evaluating
well-behaved
plans in time that is close to a plan’s intermediate degree; this issue was motivated in the introduction.
We define a plan
p
to be
well-behaved

if for each subplan
q
that is a join
\Join_{\theta}(p_{1},\ldots,p_{\ell})
of plans
p_{1},\ldots,p_{\ell}
having arities
m_{1},\ldots,m_{\ell}
,
the following is satisfied, when we let

s
denote the sum
m_{1}+\cdots+m_{\ell}
:
there exists an index
k\in[s]
such that for each index
i\in[s]\setminus([m_{1}]\cup\{k\})
, there exists an index
j\in[m_{1}]\cup\{k\}
such that
(i=j)\in\theta
.
In words,
each join adds at most one column of new information
to the plan
p_{1}
: letting
J
denote the set containing
(1) the indices in
[m_{1}]
, which correspond to
p_{1}
,
and (2) another chosen index
k
; it must be that every
index
i\notin J
is equated with an index in
J
.
This property allows for the efficient computation of such joins and, thus, well-behaved plans; we will make this formal in Proposition
3.6
.
First, we point out that our minimization algorithms can be implemented in such a way that they always output well-behaved plans.

Theorem 3.5
.

The algorithms of Theorems
3.3
and
3.4

can be implemented in such a way so that each plan
p^{\prime}
output by them is well-behaved.

This easily follows from the fact that the algorithm of Theorem
4.7
always outputs well-behaved SPJ plans and that the SPJU plan output by the algorithm of Theorem
3.3
is simply the union of well-behaved SPJ plans, which is also a well-behaved plan.

The following proposition shows that, given a well-behaved plan, apart from a multiplicative overhead depending on the plan, the time needed to algorithmically evaluate the plan on a database
\mathbf{D}
is at most
|\mathsf{dom}(\mathbf{D})|*M_{\mathbf{D}}^{d}
, where
d
is the intermediate degree of the plan—so in essence, the intermediate degree of the plan dictates the polynomial degree of evaluation (as a function of
M_{\mathbf{D}}
).
To argue this, we in essence use the argumentation for
[
2
, Theorem 6]
, and we assume a standard random access model of computation, with a uniform cost measure.

Proposition 3.6
.

There exists an algorithm that, given a well-behaved SPJU plan
p
of intermediate degree
\leq d
and a structure
\mathbf{D}
, evaluates
p
on
\mathbf{D}
in time
O(|p|^{2}*|\mathsf{dom}(\mathbf{D})|*M_{\mathbf{D}}^{d})
.

To argue this proposition, we consider an algorithm that evaluates the plan
p
inductively. It suffices to show that each subplan
q\in\mathsf{subplans}(p)
can be computed in time
O(|p|*|\mathsf{dom}(\mathbf{D})|*M_{\mathbf{D}}^{d})
.
By the definition of intermediate degree, each subplan
q
has at most
O(M_{\mathbf{D}}^{d})
answers (tuples in
\mathsf{out}(p,\mathbf{D})
). When
q
is a basic plan, the required bound holds immediately. When
q
is a select or project subplan, i.e., of the form
\sigma_{\theta}(q^{\prime})
or
\pi_{j_{1},\ldots,j_{n}}(q^{\prime})
, respectively, the answers of
q
can be naturally derived from the answers of the immediate subplan
q^{\prime}
, within the given time bound. When
q
is a union subplan, i.e., of the form
q_{1}\cup q_{2}
, it is immediate that the answers of
q
can be derived by combining the answers of
q_{1}
and
q_{2}
and eliminating duplicates, which is feasible in the given time bound.
The key point is that, when
q
is a join subplan, by well-behavedness, it is of the form
\Join_{\theta}(q_{1},\ldots,q_{\ell})
and
\mathsf{out}(q,\mathbf{D})
can be computed by maintaining a relation that is a subset of
\mathsf{out}(q_{1},\mathbf{D})\times\mathsf{dom}(\mathbf{D})
. When evaluating the multiway join, we can thus evaluate the sequence of binary joins
\Join_{\theta_{\ell-1}}(\ldots(\Join_{\theta_{2}}(\Join_{\theta_{1}}(q_{1},q_{2}),q_{3}),\ldots),q_{\ell})
, where
\theta_{1},\ldots,\theta_{\ell-1}
are the corresponding equalities from
\theta
for the join partners in question. Each binary join can be evaluated in time
O(|\mathsf{dom}(\mathbf{D})|*M_{\mathbf{D}}^{d})
by
[
9
]
, and in total, there are at most
|p|
many joins, giving us the desired runtime of
O(|p|*|\mathsf{dom}(\mathbf{D})|*M_{\mathbf{D}}^{d})
to evaluate the subplan
q
.

4
SPJ Plans

This section is dedicated to proving Theorem
3.4
, which, apart from being of interest in its own right, serves as a building block towards proving our main result in the next section.

Proving Theorem
3.4
essentially requires us to show two statements: (i) we can synthesize a plan, which is

-equivalent to the original one and has intermediate degree
\leq d

To show the theorem, we make two more basic observations on the introduced degree notions.
We begin by presenting a definition that will aid us in arguing that a plan has a certain output degree. We say that
p
has

\geq d
if there exists a function
g:\mathbb{N}\to\mathbb{N}
with
g(M)\in\Omega(M^{d})
and there exists an infinite sequence

of structures with
M_{\mathbf{D}_{n}}
unbounded such that (for all

)

. We then have the following lemma.

Lemma 4.1
.

Let
d\geq 0
. If a plan has output degree
\geq d
, then for any
\epsilon>0
, it does not have output degree
\leq(d-\epsilon)
.

Next, we characterize the intermediate degree of a plan in terms of the output degrees of subplans, in the following sense.

Lemma 4.2
.

Let
d\geq 0
. A plan

has intermediate degree
\leq d
if and only if each subplan
q
of
p
has output degree
\leq d
.

Theorem
3.4
can then be argued as follows: Given a plan
p
, we first compute the open structure
(\mathbf{A},\overline{a})
, which can be done in polynomial time by Theorem
4.6
. Then, the algorithm of Theorem
3.4
computes
\textrm{Chase}_{\Sigma}(\mathbf{A},\overline{a})

From

Consider any plan

. By statement (ii), formalized in Theorem

,

4.1
Relating Queries to Structures

There is a known correspondence between Boolean SPJ plans and structures
[
5
]
; by a

. This correspondence yields that each such plan can be translated to a structure

such that, for an arbitrary structure

if and only if there is a homomorphism from

to

We prove a version of this correspondence in Theorem

for SPJ plans that can output relations of any finite arity, and not just relations of arity

Definition 4.3

(

over

over

Apart from showing that any SPJ plan

can be translated to a

-representation, we also want to provide a tree decomposition of this open structure with certain additional properties, which we call
p
-decomposition.
This allows us to relate plans to structural, decomposition-based measures.
While the translation that we present is, on a high level, along the lines of known translations from SPJ plans to conjunctive queries, we emphasize that our translation also provides a tree decomposition that will allow us to analyze the intermediate degree. In particular, for a given plan, each subplan will correspond to a vertex of the tree decomposition whose associated set of elements corresponds to the free variables of the subplan.

We say a tree decomposition

is

, called the root of

. The formal definition of

5

SPJU Plans

Building on the established understanding of intermediate degree for SPJ plans from the previous section, we are now ready to prove Theorem
3.3
.
It is well-known that each SPJU plan
p
is
\Sigma
-semantically equivalent to some plan
p^{\prime}
which is a union
p_{1}\cup\cdots\cup p_{m}
of SPJ plans.
Let us note that the output degree of an SPJU plan can then be characterized as follows:
for such a
\Sigma
-semantically equivalent plan
p^{\prime}
, the output degree of
p
is equal to the maximum output degree over the plans
p_{1},\ldots,p_{m}
.
To argue about the intermediate degree of an SPJU plan, we first give a theorem showing that a natural such translation to a union of SPJ plans exists and can be computed in exponential time, which has the additional property that the relation computed by a subplan of one of the SPJ plans is a subset of some relation computed by a subplan of the original SPJU plan; this inclusion then facilitates proving lower bounds on the intermediate degree of the original SPJU plan.

Theorem 5.1
.

There exists an exponential-time algorithm that, given an SPJU plan
p
, outputs a sequence of SPJ plans
p_{1},\ldots,p_{m}
, a sequence of maps
\alpha_{1},\ldots,\alpha_{m}
, and a sequence of open structures
(\mathbf{A}_{1},\overline{a_{1}}),\ldots,(\mathbf{A}_{m},\overline{a_{m}})
such that the following holds:

1.

p
is semantically equivalent to
p_{1}\cup\cdots\cup p_{m}
,

2.

for each
i=1,\ldots,m
, we have that
\alpha_{i}:\mathsf{subplans}(p_{i})\to\mathsf{subplans}(p)
is a map such that
(for each structure
\mathbf{D}
) when
q\in\mathsf{subplans}(p_{i})
,
the containment

\mathsf{out}(q,\mathbf{D})\subseteq\mathsf{out}(\alpha_{i}(q),\mathbf{D})
holds,

3.

for each
i=1,\ldots,m
, the open structure

(\mathbf{A}_{i},\overline{a_{i}})
is a
p_{i}
-representation,
and
i\neq j
implies that there is no homomorphism
from
(\mathbf{A}_{i},\overline{a_{i}})
to
(\mathbf{A}_{j},\overline{a_{j}})
.

On a high level, Theorem
3.3
can then be proved as follows. For some SPJU plan
p
, the algorithm first computes this convenient set of SPJ plans
p_{1},\ldots,p_{m}
via Theorem
5.1
.
Then, for each obtained plan
p_{i}
, it computes a core
(\mathbf{C}_{i},\overline{c_{i}})
of the chase of a
p
-representation, and then applies Theorem
3.4
to obtain a value
d_{i}
, and a plan
p^{\prime}_{i}
such that
p_{i}
,
d_{i}
, and
p^{\prime}_{i}
satisfy the properties given in that theorem statement.
The algorithm outputs the value
d=\max_{i\in[m]}d_{i}
and the plan
p^{\prime}=p^{\prime}_{1}\cup\cdots\cup p^{\prime}_{m}
.
Since this algorithm outputs a union of well-behaved SPJ plans, also the resulting SPJU plan is well-behaved.
It is easy to see that
p^{\prime}
has intermediate degree
d
, it just remains to show that
d
is indeed the SPJU-best possible intermediate degree. In essence, we prove that for any SPJU
q^{\prime}
that is semantically equivalent to
p^{\prime}
, we have that from the sequence of SPJ plans
q^{\prime}_{1},\ldots,q^{\prime}_{n}
obtained by applying Theorem
5.1
to
q^{\prime}
, there exists an index
\ell\in[n]
such that
q^{\prime}_{\ell}
does not have (for any
\epsilon>0
) intermediate degree
\leq(d-\epsilon)
implying by condition (2) of Theorem
5.1
that
q^{\prime}
does not have (for any
\epsilon>0
) intermediate degree
\leq(d-\epsilon)
. Full details can be found in the appendix.

6

Conclusion

The intermediate degree asymptotically characterizes the size of intermediate relations obtained during the execution of a query plan. For SPJU plans, we have shown how to optimize for this measure among all semantically equivalent SPJU plans with respect to a given set of unary key constraints. A natural way to extend our work is to consider either more expressive query languages, by adding more operators, or more expressive constraints, such as
arbitrary functional dependencies.

We show

]

.

We next present a complementary lemma that provides the matching lower bound and which again follows directly from Theorem 4.4 of

10
]

Lemma A.6

Let
\Sigma
be a set of unary keys over signature
\sigma
. Let
\mathbf{A}
be a structure over
\sigma
. For any open structure
(\mathbf{A},\overline{a})
, there exists a constant

unbounded, and where, for each

over
