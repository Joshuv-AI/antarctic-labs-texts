Automated Circuit Interpretation via Probe Prompting
Giuseppe Birardi

Abstract
Mechanistic interpretability aims to understand neural networks by identifying which learned features mediate specific behaviors. Attribution graphs reveal these feature pathways, but interpreting them requires extensive manual analysis—a single prompt can take approximately 2 hours for an experienced circuit tracer. We present probe prompting, an automated pipeline that transforms attribution graphs into compact, interpretable subgraphs built from concept-aligned supernodes. Starting from a seed prompt and target logit, we select high-influence features, generate concept-targeted yet context-varying probes, and group features by cross-prompt activation signatures into Semantic, Relationship, and Say-X categories using transparent decision rules. Across five prompts including classic “capitals” circuits, probe-prompted subgraphs preserve high explanatory coverage while compressing complexity (Completeness 0.83, mean across circuits; Replacement 0.54). Compared to geometric clustering baselines, concept-aligned groups exhibit higher behavioral coherence: 2.3 × \times higher peak-token consistency (0.425 vs 0.183) and 5.8 × \times higher activation-pattern similarity (0.762 vs 0.130), despite lower geometric compactness. Entity-swap tests reveal a layerwise hierarchy: early-layer features transfer robustly (64% transfer rate, mean layer 6.3), while late-layer Say-X features specialize for output promotion (mean layer 16.4), supporting a backbone-and-specialization view of transformer computation. We release code ( https://github.com/peppinob-ol/attribution-graph-probing ), an interactive demo ( https://huggingface.co/spaces/Peppinob/attribution-graph-probing ), and minimal artifacts enabling immediate reproduction and community adoption. Limitations include reliance on CLT features, narrow prompt families (factual recall), and correlational validation; we outline pre-specified causal interventions for future work. Probe prompting demonstrates that circuit-level interpretability can be partially automated using behavior-grounded metrics, reducing initial analysis time from hours to minutes while revealing systematic computational structure.

Introduction

Attribution graphs provide a structured view of which learned features mediate a model’s prediction for a given target logit
[
1
]
. In practice, interpreting these graphs remains bottlenecked by extensive manual analysis: identifying influential features, inferring their semantics from corpus activations, and assembling them into a legible subgraph. A typical workflow requires researchers to manually inspect activation patterns across dozens of context variations to determine whether a given feature encodes semantic content (e.g., ‘France’), relational structure (e.g., ‘capital-of’), or syntactic patterns (e.g., ‘says X’). As noted in the Neuronpedia podcast, analyzing a single prompt takes “approximately 2 hours for an experienced circuit tracer.” This process demands deep expertise and produces inconsistent taxonomies across researchers. As interpretability scales to larger model families and more complex behaviors, manual circuit analysis becomes increasingly infeasible.

We make three empirical claims about automated circuit interpretation. First, concept-aligned grouping based on behavioral signatures exhibits higher functional coherence than geometric clustering (C1): our supernodes show 2.3
\times
higher peak-token consistency (0.425 vs 0.183) and 5.8
\times

Third, entity-swap tests reveal a layerwise computational hierarchy (C3): early-layer features transfer robustly across entity substitutions (64% transfer, mean layer 6.3), while late-layer Say-X features specialize for output promotion (mean layer 16.4), supporting a backbone-and-specialization model of transformer computation (Table

3
Method

Probe prompting

Given an attribution graph for a seed prompt and target logit, we elicit candidate concepts via an instructed LLM. For each accepted concept, we create
probe prompts
that preserve syntactic structure while varying semantic content. We then measure feature activations on each probe using the Neuronpedia API, forming a set of
cross-prompt activation signatures
.

3.1
Core Definitions

Cross-prompt activation signature

A feature-specific behavioral profile measured across probe prompts. For each (feature, probe) pair, we record: (i) cosine similarity to seed activation pattern (how similar is activation to original prompt?), (ii) robust z-score relative to baseline distribution (how anomalous is activation?), (iii) peak token position and identity (which token activates most strongly?), (iv) activation density (fraction of tokens above 75th percentile), and (v) sparsity ratio
(\text{peak}-\text{mean})/\text{peak}
(how concentrated is activation?).

Aggregating across probes yields summary statistics: (i) peak-token consistency (fraction of probes peaking on same token type), (ii) number of distinct peak tokens (diversity of activation), (iii) functional vs semantic peak percentage (does feature peak on ‘is’/‘the’ or on content words?), and (iv) confidence scores when peaking on semantic or functional tokens (reliability of peak type). These signatures capture whether a feature responds consistently to a concept (high consistency, few peaks), covers multiple related tokens (moderate consistency, several semantic peaks), or activates diffusely across contexts (low sparsity, many peaks).

Functional vs semantic tokens

We label each token in the prompt as either
functional
(bridging/syntactic role: ‘is’, ‘the’, ‘of’, ‘and’, etc.) or
semantic
(content-bearing: entity names, concepts, attributes). This distinction is crucial for Say-X detection: features that consistently peak on functional tokens but map to nearby semantic targets (via directionality rules) are classified as output promoters. Complete functional vocabulary and mapping rules provided in Appendix
A.7
.

Replacement vs Completeness (Neuronpedia graph metrics)

Replacement
measures the fraction of end-to-end influence from input embeddings to target logit that routes through pinned features in the subgraph (high Replacement = features carry most causal pathways).
Completeness
measures the fraction of incoming edge influence to each node that is explained by upstream features/embeddings (high Completeness = few unexplained inputs, subgraph is self-contained). Both are computed via attribution path-tracing in replacement models
[
1
]
. Our subgraphs intentionally trade Replacement (
\sim
0.54) for Completeness (
\sim
0.83) and legibility: unpinned low-influence nodes are treated as error, reducing raw coverage but improving interpretability.

Node selection

We select candidate feature nodes with a cumulative influence threshold on the attribution graph. The threshold is chosen via a simple UI that visualizes node influence; selected nodes form the universe for cross-prompt measurement.

Cross-prompt signature metrics

For each feature and probe we record: (i) cosine similarity to the seed activation pattern, (ii) robust z-score relative to baseline, (iii) peak token, (iv) activation density (fraction above the 75th percentile), and (v) sparsity ratio
(\text{peak}-\text{mean})/\text{peak}
. Aggregating across probes yields: (i) peak consistency on concept tokens, (ii) number of distinct peaks, (iii) functional vs semantic peak percentage, and (iv) confidence scores when peaking on semantic or functional tokens.

Preprocessing

Tokens are labeled as
semantic
(content-bearing) or
functional
(bridging tokens such as “is” and “the”). When a feature peaks on a functional token, we identify the nearest semantic
target token
within a configurable window (default: 7 tokens), using directionality rules (“is”
\rightarrow
forward, “of”
\rightarrow
backward). See Appendix
A.7
for complete vocabulary and mapping rules.

3.2
Decision Rules and Classification Logic

We use transparent, rule-based thresholds rather than learned classifiers to ensure interpretability of the grouping process itself—a critical property for an interpretability tool. Learned cluster algorithms (k-means, DBSCAN, neural groupers) lack explicit decision criteria, making it difficult to understand
why
a feature was assigned to a category. Rule-based classification provides:

•

Transparency:
Each assignment can be traced to specific threshold crossings

•

Debuggability:
Misclassifications can be diagnosed by inspecting which condition failed

•

Editability:
Users can adjust thresholds for domain-specific needs

•

Communicability:
Rules can be stated in natural language

Thresholds were chosen via iterative refinement on held-out examples, balancing recall (capturing relevant features in each category) against precision (avoiding false groupings). While hand-tuned, they represent codified expert judgment. Classification proceeds hierarchically:

•

Semantic (Dictionary):
stable token detector for a specific wordform or name; peaks on the same token across contexts. Peak consistency
\geq 0.80
on a single token type; few distinct peaks (
\leq 1
).

•

Semantic (Concept):
category detector that fires on a set of semantically related content tokens (synonyms, inflections, near-neighbors).Lower layers (
\leq 3
) or high semantic confidence; can cover related content tokens.

•

Relationship:
sentence-spanning activations that accentuate conceptually linked tokens. Diffuse activations (median sparsity
<0.45
) across relation phrases; often early-layer.

•

Say-X:
output-promotion feature that pushes the model to emit a specific token or short phrase, typically via functional tokens. Functional dominance (
\geq 50\%
), high functional consistency (
\geq 0.90
), and layer
\geq 7
.

Conflict resolution

Features may satisfy multiple category conditions (e.g., high peak consistency for both semantic and functional tokens). We resolve conflicts via weighted alignment score combining: (i) peak consistency (weight 0.4), (ii) category-specific confidence (weight 0.3), (iii) layer prior (weight 0.2), and (iv) sparsity consistency (weight 0.1). Feature is assigned to highest-scoring category. Duplicate prevention ensures each feature belongs to exactly one supernode.

Cross-prompt stability requirement

Features must satisfy conditions on
\geq
60% of probes to avoid spurious groupings based on single-probe noise. Features failing this criterion are marked “ungrouped” and excluded from subgraph (typically 5–10% of candidate features).

Naming policy

Semantic nodes are named by their strongest semantic peak token; Say-X nodes are named by the target token discovered from functional peaks; Relationship nodes use aggregated activation over an extended vocabulary (format “(token) related”). We support a configurable blacklist for uninformative words.

Naming conventions and vocabulary

Functional token vocabulary (English prompts): ‘is’, ‘was’, ‘are’, ‘were’, ‘be’, ‘been’, ‘being’ (copulas); ‘the’, ‘a’, ‘an’ (articles); ‘of’, ‘in’, ‘on’, ‘at’, ‘to’, ‘for’, ‘with’, ‘by’, ‘from’, ‘as’ (prepositions); ‘and’, ‘or’, ‘but’ (conjunctions); ‘that’, ‘which’, ‘who’, ‘whose’, ‘where’, ‘when’ (relative pronouns). Full list in Appendix
A.7
.

Target-token mapping uses
\pm
5 token window with directionality: Forward: ‘is’, ‘was’, ‘are’
\rightarrow
look forward for nearest semantic token; Backward: ‘of’, ‘’s’ (possessive)
\rightarrow
look backward; Bidirectional: ‘,’
\rightarrow
nearest semantic token (either direction).

Cross-lingual note

Non-English prompts require adapted functional vocabularies. We encountered a notable failure when applying the English pipeline to the French prompt “le contraire de ‘petit’ est” using English probe prompts. The model produced incoherent activations with no valid supernode grouping, due to language mismatch and absence of French functional tokens. Performance improved after adding French probe prompts and expanding the blacklist, but the current prototype remains unreliable in multilingual contexts without explicit cross-lingual adaptation.

Metrics

We report Neuronpedia
Replacement
(fraction of end-to-end influence through features) and
Completeness
(fraction of incoming edge influence explained by features/tokens) on full graphs and subgraphs. For interpretability, we use: (i) peak token consistency, (ii) within-cluster activation similarity, and (iii) sparsity consistency. We compare against cosine-only and layer-adjacency baselines.

Results

Experimental setup

We evaluate on Gemma-2-2B-it using cross-layer transcoders (CLTs) as our feature dictionary. CLTs read from the residual stream at each layer and jointly reconstruct MLP outputs downstream, trained with JumpReLU activations and an explicit sparsity penalty. For Gemma-2 (2B), a published CLT suite contains 2.5M features in total, which we use to build local replacement models and attribution graphs. Prompt families span multiple domains to test generalization beyond single-circuit artifacts:

•

Geographic knowledge: “The capital of Texas is”
\rightarrow
Austin (Dallas variant), “The capital of California is”
\rightarrow
Sacramento (Oakland variant)

•

Sports entities: “Michael Jordan plays”
\rightarrow
Basketball

•

Semantic opposition: “The opposite of small is”
\rightarrow
large

•

Anatomical relations: “The muscle called the diaphragm”

Each circuit uses Neuronpedia’s attribution graph generation with replacement model (freezing attention patterns, layer norms). We select features via cumulative influence threshold (
\tau=0.60
–0.80, chosen to capture top 70–80% of influence). Probe prompts generated via Claude-3.5-Sonnet with temperature 0.7, manually reviewed for quality (rejecting semantically identical or syntactically malformed prompts). Activation measurements via Neuronpedia API (approximately 10–15 minutes on L4 GPU for 5 probes
\times
40 features). All experiments use fixed random seeds.

Interpretation (C2: Interpretability-Oriented Compression)

These results support our second claim that behavioral grouping enables interpretability-oriented compression. Completeness remains high (mean 0.83 vs 0.90 for full graphs,
\Delta=-0.07
), indicating concept-aligned subgraphs capture most incoming edge influence to nodes: the subgraph is largely self-contained with few unexplained inputs. Replacement drops more substantially (mean 0.54 vs 0.70,
\Delta=-0.16
), reflecting our deliberate choice to exclude low-influence nodes that contribute little to functional understanding but would inflate raw coverage.

This trade-off is intentional and aligns with interpretability goals. We prioritize legibility (30–50 interpretable supernodes with semantic labels) over exhaustive coverage (600+ unlabeled features). Replacement is computed against full end-to-end influence from input embeddings to target logit; unpinned nodes are treated as error, so lower Replacement indicates higher abstraction rather than lost explanatory power. A perfectly complete subgraph (Replacement = Completeness = 1.0) would be the full raw graph—maximally comprehensive but minimally interpretable.

The consistent 79–86% Completeness across all five prompts, despite varying Replacement scores (0.45–0.62), indicates that concept-aligned grouping successfully identifies features that explain model behavior, even when the simplified circuit doesn’t fully replicate it. This trade-off—interpretability vs. completeness—is acceptable for circuit analysis purposes where understanding causal structure matters more than perfect reconstruction.

Interpretation (C1: Behavioral Coherence)

These results support our first claim that concept-aligned grouping exhibits higher behavioral coherence than geometric clustering. Peak-token consistency (0.425 vs 0.183 for cosine, 2.3
\times
improvement) indicates concept-aligned features activate on the same tokens far more reliably across probes: 42.5% of features in a supernode peak on identical tokens, compared to 18.3% for cosine-clustered features. Activation-pattern similarity (0.762 vs 0.130 for cosine, 5.8
\times
improvement) indicates higher within-group activation vector correlation: features in a behavioral supernode respond similarly across contexts, while cosine-clustered features may be geometrically close but functionally diverse.

The trade-off is geometric compactness: concept-aligned grouping scores lower on Silhouette index (0.124 vs 0.707 for layer-adjacency), indicating groups are not spatially compact in activation vector space or layer-influence graph. This is expected and desirable: functional roles (semantic detection, relationship binding, output promotion) can span multiple layers and diverse activation patterns. Layer-adjacency clustering trivially achieves high Silhouette by grouping nearby layers, but this reflects geometric proximity rather than shared function—adjacent-layer features may perform unrelated computational roles.

Davies-Bouldin scores are comparable across methods (1.30 vs 1.58/0.49), suggesting reasonable within-group cohesion despite cross-layer membership. Sparsity consistency (0.255) is lower than baselines (0.335–0.399), indicating concept-aligned features concentrate activation on fewer tokens (lower is better for this metric). This aligns with the Say-X category: output promoters should activate sparsely on functional tokens, not diffusely across all tokens.

Important caveat: Neuronpedia Replacement/Completeness scores are near-invariant across the three methods (all pin the same 39 nodes) and thus do not discriminate grouping quality. The behavioral metrics above provide the actual comparison. Results are descriptive from a single circuit; broader validation needed.

These results support our third claim of a layerwise computational hierarchy. Features that transfer from Dallas

\rightarrow

This validates that transfer captures genuine functional equivalence, not spurious token overlap.

Compositional analysis

Examining feature categories, transferred features are predominantly Semantic (entity detectors: ‘capital’, ‘state’, ‘containing’) and Relationship (‘capital-of’ relation, copula binding). Failed-transfer features are predominantly Say-X (‘Say Austin’, ‘Say Texas’) concentrated in layers 14–18. This categorical separation supports the backbone-and-specialization model: early layers build task-general representations (entity detection, structural binding), late layers shape output distribution (token promotion, probability allocation).

Typical processing time: 2–5 minutes for graphs with 50–200 features.

5
Discussion

Interpretability vs completeness

Our subgraphs deliberately compress raw attribution graphs to emphasize functional roles and causal pathways. Completeness remains high, while Replacement drops due to unpinned nodes treated as error. This is an intended trade-off favoring legibility.

Early vs late hierarchy

Evidence supports a backbone of early-layer features that generalize across entity swaps and a specialization of late-layer features for output promotion (Say-X). This suggests a staged computation: early relational binding and semantic detection, followed by late-stage output shaping.

5.1
Implications for Interpretability Research

Our results suggest three actionable insights for mechanistic interpretability:

1. Automated first-pass analysis

Probe prompting reduces initial circuit interpretation from approximately 2 hours of manual analysis to 10–20 minutes of semi-automated processing (concept generation via LLM, probe execution via API, automated grouping). This speedup enables researchers to:

•

Rapid validation:
Quickly assess whether a circuit exhibits interpretable structure (clear Semantic/Relationship/Say-X separation) before committing to deep manual analysis. Circuits with diffuse, unstructured features may not be amenable to mechanistic decomposition.

•

Hypothesis generation:
Use automated supernode labels as initial hypotheses about feature roles, guiding targeted manual investigations. For example, feature 1_12928 received the generic autointerp label “AssemblyCulture” but our system labeled it “(texas) related”—examination of its top Neuronpedia activation revealed a Texas government document containing both “Texas” and “Austin”, grounding the interpretation in specific corpus content. This demonstrates how probe-based concept alignment can serve as both hypothesis generation and validation.

•

Scalability:
Extend interpretability efforts to larger model families where manual analysis per circuit is infeasible. Batch processing mode (
scripts/batch_run.py
) supports multi-circuit analysis with automated aggregation, enabling meta-studies of circuit structure across tasks.

The method is not a replacement for careful manual interpretation—human judgment remains essential for validating automated groupings, identifying edge cases, and generating causal hypotheses. Rather, probe prompting is a force multiplier that focuses human effort where it adds most value: ambiguity resolution, hypothesis refinement, and causal validation.

2. Standardized taxonomies

The Semantic/Relationship/Say-X framework provides a common vocabulary for describing feature roles across circuits. While domain-specific refinements may be needed (e.g., distinguishing ‘Entity’ from ‘Attribute’ within Semantic, or separating ‘Binding’ from ‘Selection’ within Relationship), a shared taxonomy enables:

•

Meta-analyses:
Compare circuit structure across tasks with consistent labels. Example: “Do all capital circuits concentrate Say-X features in layer 7+, or does this vary by model architecture / training data?” Aggregating findings requires consistent terminology.

•

Transfer learning:
Identify reusable computational motifs across circuits. If ‘capital-of’ Relationship features from geographic circuits activate similarly to ‘member-of’ features from sports circuits, this suggests shared relational structure that could inform circuit design or intervention strategies.

•

Communication:
Improve consistency in interpretability reporting. Current literature uses ad-hoc terminology (‘feature X detects France-ness’, ‘neuron Y promotes Paris’), making cross-paper synthesis difficult. Standardized categories facilitate clearer communication.

Future work could formalize this taxonomy into an ontology with hierarchical relationships (e.g., ‘Entity Detector’ is-a ‘Semantic Feature’), validation criteria (inter-rater reliability metrics for manual vs automated classification), and extension guidelines for new domains.

3. Computational hierarchies and safety implications

The early-vs-late transfer pattern suggests a general principle: early layers encode task-general structure (entity detection, relational binding), late layers specialize for task-specific outputs (token promotion, distribution shaping). If this generalizes beyond capitals circuits, it has implications for AI safety:

•

Localization of safety-relevant properties:
Deceptive reasoning, goal misrepresentation, or value misalignment may manifest in early-to-mid-layer Relationship features that encode strategic structure (‘if monitored, then comply; if unmonitored, then defect’). Late-layer Say-X features merely implement the output of this reasoning. Interventions targeting late layers (activation steering, weight editing) may be superficial, leaving underlying strategic computation intact.

•

Intervention stability:
Early-layer features that transfer robustly across contexts may be more stable targets for safety interventions. Steering ‘honesty’ features in early layers could generalize across diverse prompts. Late-layer steering may be fragile: a ‘refuse harmful request’ Say-X feature might only work for specific phrasings, failing under adversarial variation.

•

Mechanistic audits:
Different properties of interest may concentrate in different layer ranges. Auditing for world-modeling capabilities (factual knowledge, logical reasoning) likely requires analyzing early-to-mid layers. Auditing for output-control properties (refusal behavior, tone compliance) likely requires late-layer analysis. Efficient audits should prioritize layer ranges based on target property.

Testing this hierarchy across diverse task families (arithmetic, code generation, moral reasoning, long-horizon planning) is a key next step. If the pattern holds generally, it suggests interpretability research should stratify analyses by layer depth, with different methodologies for early-layer structure (causal tracing, intervention studies) vs late-layer output shaping (activation steering, logit lens).

5.2
Threats to Validity and Mitigation Strategies

We identify common failure modes and document current limitations:

Alternative explanations for behavioral metrics

Peak-token consistency and activation similarity could arise from coincidental token overlaps rather than genuine functional coherence. For example, if all probes happen to include the token ‘is’, features might spuriously show high consistency on ‘is’ without actually detecting that concept.

Current mitigation:
We employ systematic context variation in probe design: entities vary (Texas
\rightarrow
California
\rightarrow
France), syntax varies (declarative
\rightarrow
interrogative). Aggregation across 5–10 diverse probes per concept reduces coincidental overlap probability. Entity-swap validation provides cross-validation: if behavioral grouping were spurious, transferred features would fail to activate appropriately on new entities (but we observe 96% entity-appropriate activation). However, we cannot rule out all confounds; causal ablation studies (planned for future work) would provide stronger evidence of functional roles.

Sample size and statistical power

Sample sizes are modest: 5 circuits, 39 features in primary transfer study, 5–10 probes per concept. Results are descriptive rather than inferential; we avoid claiming statistical significance. Effect sizes are reported where applicable (layer difference
\Delta=10.1
, behavioral coherence 2.3
\times
/5.8
\times
improvements) but without formal significance tests or confidence intervals.

Current status:
We frame findings as proof-of-concept demonstrating feasibility, not definitive characterization. The transfer effect (10.1-layer difference) is large relative to variance (SD
\sim
6 layers), providing preliminary support for hierarchy hypothesis. Larger-scale validation across 20–50 circuits (planned as templated sweep over all US state-capital pairs) would better characterize method stability and failure modes. Current results should guide follow-up confirmatory studies, not stand alone as conclusive evidence.

Duplicate features and naming ambiguity

Classification can be ambiguous when features exhibit mixed behavior (e.g., peaking on both semantic and functional tokens with comparable confidence). We enforce duplicate prevention via weighted alignment scores, but edge cases remain.

Current mitigation:
Conflict resolution uses weighted scoring combining peak consistency (40%), category confidence (30%), layer prior (20%), and sparsity (10%). Ties are broken by highest absolute confidence score. Features failing to meet
\geq
60% cross-probe stability are marked “ungrouped” and excluded (typically 5–10% of candidates). Naming relies on single-token peaks; multi-token concepts (‘New York’, ‘United States’) require manual post-correction or longest-match heuristics (currently implemented as ‘use first token’). Future work could incorporate Neuronpedia autointerp descriptions to resolve ambiguity systematically.

Attention routing not modeled

CLT replacement models linearize residual stream pathways by freezing attention patterns and layer norms during attribution computation. This enables tractable causal tracing but may underestimate indirect effects where features modulate computation via attention pattern changes rather than direct residual contribution.

Current status:
Replacement models are standard in current interpretability literature and provide consistent attribution graphs across tools (Neuronpedia, TransformerLens). Our method operates on these graphs regardless of attribution method—alternative approaches (integrated gradients on attention weights, attention flow analysis) could be substituted. We focus on grouping and interpretation given an attribution graph, not proposing a new attribution method. Attention-aware variants could complement our approach; we document this as a known limitation.

Language and domain specificity

Current implementation is optimized for English prompts with explicit copulas (‘is’, ‘are’). We encountered a notable failure when testing the English pipeline on the French prompt “le contraire de ‘petit’ est”: the model produced incoherent activations with no valid supernode grouping due to language mismatch and absence of French functional tokens in preprocessing. Performance improved after adding French-language probe prompts and expanding the blacklist to include mixed English-French functional terms, but required manual refinement.

Current status:
We provide configurable functional token lists and directionality rules (Appendix
A.7
,
config/languages/
in GitHub). Users can adapt vocabularies for target languages via YAML config files. However, the current prototype remains unreliable in multilingual contexts without explicit cross-lingual adaptation. Domain specificity (code, math, vision-language models) may require analogous adaptations: code circuits might use ‘def’/‘return’ as functional markers, math circuits might use operators (‘+’, ‘=’) rather than words. Generalization testing is planned.

Threshold sensitivity and hyperparameter dependence

Decision rules rely on hand-tuned thresholds (peak consistency
\geq
0.80, Say-X layer
\geq
7, etc.). While chosen via iterative refinement on held-out examples, different thresholds could yield different groupings.

Current status:
Thresholds represent codified expert judgment informed by manual circuit analysis (including extensive “feature ethnography” where activations were printed and annotated by hand over several days). We do not claim these are globally optimal. For practical use, we recommend treating thresholds as configurable defaults that users can adjust for domain-specific needs (e.g., stricter Say-X layer prior for shallow models, looser peak consistency for polysemantic features). Interactive demo UI exposes threshold sliders for real-time exploration. Systematic sensitivity analysis planned for future work.

Baseline tuning documentation

We tuned geometric baselines (cosine clustering, layer-adjacency) to ensure fair comparison, selecting cluster counts and linkage methods to maximize geometric quality indices (Silhouette for cosine, modularity for adjacency). However, we have not exhaustively documented hyperparameter grid searches or sensitivity analysis for baselines.

Current status:
All three methods (concept-aligned, cosine, layer-adjacency) received comparable attention during development. We do not claim optimal hyperparameters for any method; rather, our goal was to ensure baselines were not trivially weak. Results in Table
2
are descriptive differences from a single circuit without significance tests. Systematic threshold optimization and baseline tuning documentation are planned for future work, along with proper train/validation/test splits across multiple circuits.

Baseline fairness

We document baseline hyperparameters and tuning effort to avoid under-tuning, particularly for cosine and adjacency clustering where parameter choices materially affect geometric indices.

Future work

We plan causal interventions (feature ablations, steering, cross-circuit transfer) and a templated sweep across many state–capital graphs to assess stability and generalization, including attention-aware variants.

A.4
Baseline Tuning and Hyperparameters

To ensure fair comparison, we tuned geometric baselines (cosine clustering, layer-adjacency) alongside our concept-aligned method. Below we document tuning approaches and acknowledge limitations.

Cosine Clustering (Activation-Vector Similarity)

Method: Hierarchical clustering on cosine distance of activation vectors (measured on seed prompt). Activation vector for feature
i
is its per-token activation:
\mathbf{a}_{i}\in\mathbb{R}^{n_{\text{ctx}}}
.

Tuning: We selected agglomerative clustering with cosine distance metric. Cluster count and linkage method were chosen to maximize Silhouette score on the Michael Jordan circuit. We tested common linkage methods (single, complete, average, ward) and selected the configuration yielding best geometric quality. Final configuration prioritized geometric compactness while maintaining interpretable cluster sizes (
\sim
7–10 clusters for comparability with concept-aligned groups).

Note: We did not perform exhaustive grid search across all hyperparameter combinations. Tuning was iterative and informed by standard clustering practices.

Layer-Adjacency Clustering (Influence-Graph Proximity)

Method: Hierarchical clustering on normalized [layer, influence] coordinates. Features close in layer depth and similar in influence magnitude are grouped together.

Tuning: We used Ward linkage to minimize within-cluster variance. Cluster count was chosen to approximately match the number of concept-aligned groups (
\sim
7–10) for comparability. Normalization applied to balance layer and influence contributions equally.

Note: Alternative algorithms (Louvain, spectral) were considered but not extensively compared. Ward linkage was selected based on prior experience with hierarchical methods.

Concept-Aligned Grouping (Our Method)

Method: Rule-based classification using cross-prompt behavioral signatures. Thresholds:

•

Semantic: peak_consistency
\geq
0.80, n_distinct_peaks
\leq
1, layer
\leq
3 OR semantic_conf
\geq
0.50

•

Say-X: func_vs_sem
\geq
50%, conf_functional
\geq
0.90, layer
\geq
7

•

Relationship: median_sparsity ¡0.45, typically layer
\leq
9
