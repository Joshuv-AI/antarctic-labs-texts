From Noise to Knowledge: System Identification with Systematic Polytope Construction via Cyclic Reformulation
Hiroshi Okajima, Shun Shirahama, Tatsunori Hayashi, Nobutomo Matsunaga

Abstract
Model-based control requires accurate mathematical models to guarantee control performance and stability. However, obtaining accurate models is challenging due to process and sensor noise. This paper proposes a novel identification algorithm that derives polytopic uncertainty models by interpreting noise-induced parameter fluctuations as intrinsic uncertainty. The method applies cyclic reformulation with period N N to linear time-invariant systems, yielding N N parameter sets with slight variations that serve as polytope vertices. This enables systematic polytopic model construction from a single identification experiment. Simulation results demonstrate significant improvements: the proposed method achieves higher parameter estimation accuracy and reduces prediction errors by approximately half compared to conventional approaches. The vertex count N N provides systematic control over the precision of uncertainty representation.

The main contributions of this work are threefold: (1) extending cyclic reformulation from its conventional use in periodic time-varying system identification to systematic polytope construction for time-invariant systems, (2) a constructive approach that exploits noise-induced parameter variations as polytope vertices rather than treating noise as disturbances to eliminate, and (3) numerical validation demonstrating consistent improvement over conventional single-model identification across various noise conditions.

MATRIX POLYTOPE REPRESENTATION OF PLANTS

2.1
Plant with Noise

In this section, we formulate the plant as a linear time-invariant system with noise. The plant
P
is given as an
n
-th order discrete-time linear time-invariant system as in (
2.1
).

\displaystyle x(k+1)

\displaystyle=

\displaystyle Ax(k)+Bu(k)+d_{u}(k)

\displaystyle y(k)

\displaystyle=

\displaystyle Cx(k)+Du(k)+d_{y}(k)

(1)

Here,
x(k)\in\mathbb{R}^{n\times 1}
is the state vector,
u(k)\in\mathbb{R}^{m\times 1}
is the input vector,
y(k)\in\mathbb{R}^{q\times 1}
is the output vector,
d_{u}(k)\in\mathbb{R}^{n\times 1}
is the process noise, and
d_{y}(k)\in\mathbb{R}^{q\times 1}
is the observation noise. The system matrices are
A\in\mathbb{R}^{n\times n}
,
B\in\mathbb{R}^{n\times m}
,
C\in\mathbb{R}^{q\times n}
, and
D\in\mathbb{R}^{q\times m}

(C,A)

(A,B)

The process noise

2.2
Matrix Polytope Representation

Matrix polytope representation is an effective method for expressing system uncertainty by enclosing it with vertex matrices. For a system with polytope-type uncertainty, we consider the discrete-time linear time-invariant system given by (
2.2
).

\displaystyle x(k+1)

\displaystyle=

\displaystyle A(\lambda)x(k)+B(\lambda)u(k)

\displaystyle y(k)

\displaystyle=

\displaystyle C(\lambda)x(k)+D(\lambda)u(k)

(2)

The matrix polytope representation is defined as:

\displaystyle A(\lambda)

\displaystyle:=

\displaystyle\sum_{i=0}^{N-1}\lambda_{i}A_{i},\quad B(\lambda):=\sum_{i=0}^{N-1}\lambda_{i}B_{i}

\displaystyle C(\lambda)

\displaystyle:=

\displaystyle\sum_{i=0}^{N-1}\lambda_{i}C_{i},\quad D(\lambda):=\sum_{i=0}^{N-1}\lambda_{i}D_{i}

\displaystyle\varepsilon

\displaystyle:=

\displaystyle\left\{\lambda\in\mathbb{R}^{N}:\lambda_{i}\geq 0,\sum_{i=0}^{N-1}\lambda_{i}=1\right\}

Here,
A_{i}\in\mathbb{R}^{n\times n}
,
B_{i}\in\mathbb{R}^{n\times m}
,
C_{i}\in\mathbb{R}^{q\times n}
, and
D_{i}\in\mathbb{R}^{q\times m}
are given matrices called vertex matrices. The set
\varepsilon
is called the standard simplex. It is assumed that the exact value of
\lambda
cannot be obtained, but the information that
\lambda\in\varepsilon
is available. The model without noise terms is considered for control design purposes.

The polytope representation enables systematic application of powerful control design techniques. Once a polytopic uncertainty model is obtained,

]
, stability analysis via common Lyapunov functions

14
,
15
,
42
]
.
Further extensions include gain-scheduled control
[

]
, multi-objective output-feedback design
[

]

[
18

. These PDLF-based methods exploit the polytope vertex structure to construct less conservative stability certificates

2.3
Parameter Estimation Error and Polytope Model Hypothesis

In practical system identification under noisy environments, conventional
methods yield a single parameter set
(A_{\text{conv}},B_{\text{conv}},C_{\text{conv}},D_{\text{conv}})
that deviates from the true system

(A,B,C,D)
due to process noise
d_{u}(k)
and observation noise
d_{y}(k)
.
The magnitude of these estimation errors depends on noise characteristics,
data length, and the identification algorithm employed.

We propose an alternative approach: construct a polytope model from multiple
parameter sets
\{(A_{mi},B_{mi},C_{mi},D_{mi})\}_{i=0}^{N-1}
obtained
through systematic identification, and search for the optimal combination:

\displaystyle\lambda^{*}=\arg\min_{\lambda\in\varepsilon}J\big(A(\lambda),B(\lambda),C(\lambda),D(\lambda)\big)

(4)

where
J(\cdot)
is a performance criterion (e.g., prediction error).
The optimal polytope model is:

\displaystyle A(\lambda^{*})

\displaystyle=

\displaystyle\sum_{i=0}^{N-1}\lambda_{i}^{*}A_{mi},\quad B(\lambda^{*})=\sum_{i=0}^{N-1}\lambda_{i}^{*}B_{mi}

\displaystyle C(\lambda^{*})

\displaystyle=

\displaystyle\sum_{i=0}^{N-1}\lambda_{i}^{*}C_{mi},\quad D(\lambda^{*})=\sum_{i=0}^{N-1}\lambda_{i}^{*}D_{mi}

(5)

Central Hypothesis
: The optimal polytope model

(A(\lambda^{*}),B(\lambda^{*}),C(\lambda^{*}),D(\lambda^{*}))
provides
superior approximation to the true system compared to any single
conventionally identified model. This superiority manifests across
multiple performance metrics including parameter accuracy and
prediction quality.

The theoretical basis is the averaging effect: each vertex estimate
contains the true system information corrupted by different random
noise realizations. The optimal convex combination reduces these
random errors through weighted averaging while preserving the
underlying system structure common to all vertices.
Section
5
validates this hypothesis.

Cyclic reformulation
[
35
]
transforms periodic time-varying systems with

[

]
. Our previous work developed
comprehensive identification frameworks for periodic systems
[

]

and extended this approach to multirate sensing environments
[

]
,
demonstrating the versatility and broad applicability of cyclic reformulation.

The present work applies this framework in a fundamentally different direction.
Rather than identifying periodic time-varying systems (the conventional use),
we apply cyclic reformulation with period
N
to linear time-invariant systems
for systematic polytope construction (Section

). Noise effects
naturally generate
N

The following subsections review the cyclic reformulation framework, providing

3.1
System Formulation and Cyclic Structure

Consider a linear periodic time-varying system with period
N
:

\displaystyle x(k+1)

\displaystyle=

\displaystyle A(k)x(k)+B(k)u(k)+d_{u}(k)

\displaystyle y(k)

\displaystyle=

\displaystyle C(k)x(k)+D(k)u(k)+d_{y}(k)

(6)

where the system matrices are periodic with period
N
:

\displaystyle A(k+N)

\displaystyle=

\displaystyle A(k),\quad B(k+N)=B(k)

\displaystyle C(k+N)

\displaystyle=

\displaystyle C(k),\quad D(k+N)=D(k)

(7)

Within each period, the system matrices can be expressed as:

\displaystyle A(k)

\displaystyle=

\displaystyle A_{i}\text{ with }i:=k\mod N

\displaystyle B(k)

\displaystyle=

\displaystyle B_{i}\text{ with }i:=k\mod N

\displaystyle C(k)

\displaystyle=

\displaystyle C_{i}\text{ with }i:=k\mod N

\displaystyle D(k)

\displaystyle=

\displaystyle D_{i}\text{ with }i:=k\mod N

This formulation captures the essential characteristic of periodic time-varying systems where the dynamics change cyclically over time with a known period
N
. Bittanti and Colaneri
[
35
]
established the theoretical foundation for cyclic reformulation of discrete-time periodic systems through invariant representations, demonstrating how periodic time-varying dynamics can be systematically transformed into time-invariant forms.

For a given period
N
, the cycled input signal
\check{u}(k)\in\mathbb{R}^{Nm}
is constructed from the original input
u(k)\in\mathbb{R}^{m}
as follows:

\displaystyle\check{u}(0)

\displaystyle=

\displaystyle\begin{bmatrix}u(0)\\
O_{m,1}\\
\vdots\\
O_{m,1}\end{bmatrix},\quad\check{u}(1)=\begin{bmatrix}O_{m,1}\\
u(1)\\
\vdots\\
O_{m,1}\end{bmatrix},

(8)

\displaystyle\cdots

\displaystyle,\quad\check{u}(N-1)=\begin{bmatrix}O_{m,1}\\
\vdots\\
O_{m,1}\\
u(N-1)\end{bmatrix}

The cycled input has a unique non-zero sub-vector at each time step, with the non-zero element cyclically shifting through the vector positions. Similarly, the cycled output
\check{y}(k)\in\mathbb{R}^{Nq}
and noise signals
\check{d}_{u}(k),\check{d}_{y}(k)
are constructed in the same manner.

The cyclic reformulation of the periodic time-varying system (
3.1
) with period
N
results in the following time-invariant representation:

\displaystyle\check{x}(k+1)

\displaystyle=

\displaystyle\check{A}\check{x}(k)+\check{B}\check{u}(k)+\check{d}_{u}(k)

\displaystyle\check{y}(k)

\displaystyle=

\displaystyle\check{C}\check{x}(k)+\check{D}\check{u}(k)+\check{d}_{y}(k)

(9)

where the system matrices have the following cyclic structure for periodic time-varying systems:

\displaystyle\check{A}

\displaystyle=

\displaystyle\begin{bmatrix}O_{n,n}&O_{n,n}&\cdots&O_{n,n}&A_{N-1}\\
A_{0}&O_{n,n}&\cdots&O_{n,n}&O_{n,n}\\
O_{n,n}&A_{1}&\cdots&O_{n,n}&O_{n,n}\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
O_{n,n}&O_{n,n}&\cdots&A_{N-2}&O_{n,n}\end{bmatrix}

\displaystyle\check{B}

\displaystyle=

\displaystyle\begin{bmatrix}O_{n,m}&O_{n,m}&\cdots&O_{n,m}&B_{N-1}\\
B_{0}&O_{n,m}&\cdots&O_{n,m}&O_{n,m}\\
O_{n,m}&B_{1}&\cdots&O_{n,m}&O_{n,m}\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
O_{n,m}&O_{n,m}&\cdots&B_{N-2}&O_{n,m}\end{bmatrix}

(10)

\displaystyle\check{C}

\displaystyle=

\displaystyle\text{diag}(C_{0},C_{1},\ldots,C_{N-1})

\displaystyle\check{D}

\displaystyle=

\displaystyle\text{diag}(D_{0},D_{1},\ldots,D_{N-1})

(11)

The dimensions of the cyclic system are:
\check{A}\in\mathbb{R}^{Nn\times Nn}
,
\check{B}\in\mathbb{R}^{Nn\times Nm}
,
\check{C}\in\mathbb{R}^{Nq\times Nn}
, and
\check{D}\in\mathbb{R}^{Nq\times Nm}
.

Cyclic Structure and Properties:

The cyclic reformulation transforms an
N
-periodic time-varying system into a time-invariant representation where system matrices
\check{A},\check{B},\check{C},\check{D}
exhibit characteristic cyclic and block-diagonal structures. Specifically, matrices
\check{A}
and
\check{B}
possess cyclic matrix structures as shown in (
3.1
), while
\check{C}
and
\check{D}
are block diagonal matrices as shown in (
3.1
). This structural property is fundamental to the identification process, as it enables the systematic extraction of time-varying parameters from the time-invariant representation through coordinate transformation and parameter extraction procedures described in the following subsections.

Markov Parameter Sparsity Properties:
Critical sparsity properties of Markov parameters under cyclic reformulation were rigorously analyzed.
These sparsity properties enable systematic extraction of time-varying
parameters from identified models. The cyclic shift matrix for dimension
parameter
d
is defined as an
Nd\times Nd
matrix:

\displaystyle\check{S}_{d}=\left[\begin{array}[]{ccccc}O_{d,d}&I_{d}&O_{d,d}&\cdots&O_{d,d}\\
O_{d,d}&O_{d,d}&I_{d}&\ddots&\vdots\\
\vdots&\ddots&\ddots&\ddots&O_{d,d}\\
O_{d,d}&\ddots&\ddots&\ddots&I_{d}\\
I_{d}&O_{d,d}&\cdots&\cdots&O_{d,d}\end{array}\right]\in\mathbb{R}^{Nd\times Nd}

where
d
takes values such as
q
(output dimension),
m
(input
dimension), or other structural parameters as needed.
I_{d}\in\mathbb{R}^{d\times d}
denotes the identity matrix.

The Markov parameters of the cycled system are defined as
\check{H}^{(0)}=\check{D}
and
\check{H}^{(i)}=\check{C}\check{A}^{i-1}\check{B}
for
i\geq 1
. It was proven
[
40
]
that matrices of the form
\check{S}_{q}^{i}\check{H}(i+j)\check{S}_{m}^{j}
exhibit block-diagonal structure for any
i,j=0,1,\ldots
, where
\check{H}(i)
represents the Markov parameters of the cycled system. These sparsity properties enable systematic extraction of time-varying parameters from identified models.

3.2
Subspace Identification with Cycled Signals

The subspace identification method is applied to the cycled input-output signals
\{\check{u}(k),\check{y}(k)\}
to obtain the system matrices. This approach leverages the time-invariant nature of the cyclic reformulation while preserving the essential dynamics of the original periodic time-varying system.

The subspace identification procedure yields estimated matrices
(\check{A}_{*},\check{B}_{*},\check{C}_{*},\check{D}_{*})
with dimensions corresponding to the cyclic system. However, these identified matrices typically do not exhibit the desired cyclic structure due to estimation errors and coordinate transformation freedom inherent in subspace methods.

3.3
Coordinate Transformation for Cyclic Structure Recovery

To recover the cyclic structure from the identified matrices, a coordinate transformation is applied using a transformation matrix
T\in\mathbb{R}^{Nn\times Nn}
:

\displaystyle\check{A}_{m}

\displaystyle=

\displaystyle T^{-1}\check{A}_{*}T

\displaystyle\check{B}_{m}

\displaystyle=

\displaystyle T^{-1}\check{B}_{*}

\displaystyle\check{C}_{m}

\displaystyle=

\displaystyle\check{C}_{*}T

\displaystyle\check{D}_{m}

\displaystyle=

\displaystyle\check{D}_{*}

(18)

The transformation matrix
T
is constructed to enforce the cyclic structure. Based on the observability properties of the system,
T^{-1}
is defined as:

\displaystyle T^{-1}=\sum_{j=0}^{n-1}\check{F}_{j}\check{S}_{q}^{j}\check{C}_{*}\check{A}_{*}^{j}

(19)

where
\check{F}_{j}
are appropriately chosen block diagonal matrices and
\check{S}_{q}
is a cyclic shift matrix (
3.1
) with
d=q
.
The following theorem, presented in
[
40
]
, provides the theoretical foundation by establishing that controllability and observability are sufficient conditions for the coordinate transformation to provably recover the cyclic reformulation structure, thereby enabling systematic extraction of individual time-varying matrices
A_{k},B_{k},C_{k},D_{k}
for
k=0,\ldots,N-1
.

Theorem 1

Assume that the parameters
(\check{A}_{*},\check{B}_{*},\check{C}_{*},\check{D}_{*})
are obtained via subspace identification based on cycled signals, and that the pairs
(\check{A}_{*},\check{B}_{*})
and
(\check{C}_{*},\check{A}_{*})
are controllable and observable, respectively. Then, the system matrices
(\check{A}_{m},\check{B}_{m},\check{C}_{m},\check{D}_{m})
obtained by the coordinate transformation (
3.3
) using the transformation matrix
T
from (
19
) exhibit the cyclic reformulation structure.

Theorem
1
is derived based on the Markov parameter sparsity Property. The proof relies on the observability Gramian properties under cyclic reformulation, which ensures that
T^{-1}
defined in (
19
)
has full rank. For detailed proof, see
[
40
]
.The key insight is that the matrices
\check{F}_{j}
are chosen such that: 1) the product
\check{F}_{j}\check{S}_{q}^{j}\check{C}_{*}\check{A}_{*}^{j}
extracts specific structural information from the identified system, 2) the sum over
j=0,\ldots,n-1
ensures that all observable modes are captured, and 3) the resulting
T^{-1}
in (
19
) has full rank
Nn
under the observability assumption. This construction ensures that the transformed system
(\check{A}_{m},\check{B}_{m},\check{C}_{m},\check{D}_{m})
exhibits the desired cyclic structure, enabling the extraction of individual time-varying parameters.

Alternatively, a dual approach based on controllability properties has been proposed in
[
41
]
. Instead of computing
T^{-1}
from observability as in (
19
), the transformation matrix
T
can be directly constructed using the controllability Gramian:

\displaystyle T=\sum_{j=0}^{n-1}\check{A}_{*}^{j}\check{B}_{*}\check{S}_{m}^{j+1}\check{G}_{j}

(20)

where
\check{G}_{j}
are appropriately chosen block diagonal matrices and
\check{S}_{m}
is a cyclic shift matrix (
3.1
) corresponding to the input space structure. This dual formulation exploits the controllability properties of the cycled system
(\check{A}_{*},\check{B}_{*})
, whereas the previous formulation (
19
) exploits the observability properties of
(\check{C}_{*},\check{A}_{*})
.

The two approaches are theoretically equivalent under the assumption that both controllability and observability conditions are satisfied, as stated in Theorem
1
. The choice between (
19
) and (
20
) depends on the numerical properties of the identified system and computational considerations. In practice, the observability-based approach (
19
) is often preferred when output measurements are more reliable, while the controllability-based approach (
20
) may be advantageous in input-dominant scenarios or multi-rate sampling environments as discussed in
[
41
]
.

3.4
Parameter Extraction for Periodic Time-Varying Systems

After the coordinate transformation (
3.3
), the resulting matrices
(\check{A}_{m},\check{B}_{m},\check{C}_{m},\check{D}_{m})
exhibit the desired cyclic structure corresponding to the periodic time-varying system. From these matrices,
N
different parameter sets can be extracted:

\displaystyle\{(A_{mi},B_{mi},C_{mi},D_{mi})\mid i=0,1,\ldots,N-1\}

(21)

These parameter sets correspond to the system matrices at different time instants within the period, representing the time-varying characteristics of the original periodic system. Each parameter set
(A_{mi},B_{mi},C_{mi},D_{mi})
captures the system dynamics at time instant
i
within the period
N
, thereby providing a complete characterization of the periodic time-varying behavior.

For periodic time-varying systems, this extraction process successfully recovers the time-varying parameters that describe the system’s evolution over each period. The cyclic reformulation framework thus enables the application of time-invariant identification techniques to periodic time-varying systems while preserving all essential dynamic information.

4
INTENTIONAL PERIODICITY INDUCTION FOR UNCERTAINTY QUANTIFICATION

4.1
Systematic Uncertainty Modeling via Cyclic Reformulation

Traditional cyclic reformulation transforms periodic time-varying systems into time-invariant forms (Section
3
). In this research, we extend this framework: deliberately applying cyclic reformulation to linear time-invariant systems to systematically capture noise-induced uncertainty. We term this approach intentional periodicity induction.

The key insight is recognizing that when a linear time-invariant system is subjected to cyclic reformulation with period
N
, two distinct situations arise depending on the presence of noise:

Ideal situation (noise-free)
: All
N
parameter sets extracted from the cyclic structure become identical, reflecting the true time-invariant nature of the system.

Practical situation (noisy)
:
N
parameter sets exhibit variations around the true values due to the influence of process and observation noise.

We constructively utilize these noise-induced variations as vertices of a polytopic uncertainty model, rather than treating them as undesirable disturbances to be eliminated. This approach differs from traditional methods that view noise as constraints to be bounded, instead transforming noise-induced variations into systematic uncertainty information for robust model construction.

4.2
Application to Linear Time-Invariant Systems

Consider the linear time-invariant system from (
2.1
). When we apply cyclic reformulation with an arbitrary period
N
to this system, we obtain:

\displaystyle\check{x}(k+1)

\displaystyle=

\displaystyle\check{A}_{LTI}\check{x}(k)+\check{B}_{LTI}\check{u}(k)+\check{d}_{u}(k)

\displaystyle\check{y}(k)

\displaystyle=

\displaystyle\check{C}_{LTI}\check{x}(k)+\check{D}_{LTI}\check{u}(k)+\check{d}_{y}(k)

(22)

In the ideal noise-free case, the cyclic matrices would have the following structure:

\displaystyle\check{A}_{LTI}

\displaystyle=

\displaystyle\begin{bmatrix}O_{n,n}&O_{n,n}&\cdots&O_{n,n}&A\\
A&O_{n,n}&\cdots&O_{n,n}&O_{n,n}\\
O_{n,n}&A&\cdots&O_{n,n}&O_{n,n}\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
O_{n,n}&O_{n,n}&\cdots&A&O_{n,n}\end{bmatrix}

\displaystyle\check{B}_{LTI}

\displaystyle=

\displaystyle\begin{bmatrix}O_{n,m}&O_{n,m}&\cdots&O_{n,m}&B\\
B&O_{n,m}&\cdots&O_{n,m}&O_{n,m}\\
O_{n,m}&B&\cdots&O_{n,m}&O_{n,m}\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
O_{n,m}&O_{n,m}&\cdots&B&O_{n,m}\end{bmatrix}

(23)

\displaystyle\check{C}_{LTI}

\displaystyle=

\displaystyle\text{diag}(C,C,\ldots,C)

\displaystyle\check{D}_{LTI}

\displaystyle=

\displaystyle\text{diag}(D,D,\ldots,D)

(24)

However, in practical noisy environments, the matrices obtained through identification exhibit the following structure after coordinate transformation:

\displaystyle\check{A}_{m}

\displaystyle=

\displaystyle\begin{bmatrix}O_{n,n}&\cdots&\cdots&O_{n,n}&A_{m(N-1)}\\
A_{m0}&O_{n,n}&\cdots&\cdots&O_{n,n}\\
O_{n,n}&A_{m1}&\ddots&\ddots&\vdots\\
\vdots&\ddots&\ddots&\ddots&\vdots\\
O_{n,n}&\cdots&O_{n,n}&A_{m(N-2)}&O_{n,n}\end{bmatrix}

\displaystyle\check{B}_{m}

\displaystyle=

\displaystyle\begin{bmatrix}O_{n,m}&\cdots&\cdots&O_{n,m}&B_{m(N-1)}\\
B_{m0}&O_{n,m}&\cdots&\cdots&O_{n,m}\\
O_{n,m}&B_{m1}&\ddots&\ddots&\vdots\\
\vdots&\ddots&\ddots&\ddots&\vdots\\
O_{n,m}&\cdots&O_{n,m}&B_{m(N-2)}&O_{n,m}\end{bmatrix}

\displaystyle\check{C}_{m}

\displaystyle=

\displaystyle\text{diag}(C_{m0},C_{m1},\ldots,C_{m(N-1)})

\displaystyle\check{D}_{m}

\displaystyle=

\displaystyle\text{diag}(D_{m0},D_{m1},\ldots,D_{m(N-1)})

where
A_{mi},B_{mi},C_{mi},D_{mi}

(i=0,\ldots,N-1)
are parameters that deviate slightly from the true values
(A,B,C,D)
due to noise effects.

4.3
Coordinate Transformation and Parameter Extraction

When applying the coordinate transformation framework established in Section
3
to linear time-invariant systems, subspace identification is applied to the cyclic input-output signals
\{\check{u}(k),\check{y}(k)\}
to obtain system matrices
(\check{A}_{*},\check{B}_{*},\check{C}_{*},\check{D}_{*})
. These matrices generally do not exhibit the ideal cyclic structure due to estimation errors and coordinate transformation ambiguities inherent in subspace methods.

The same coordinate transformation procedure as described in Section
3

is applied using a transformation matrix
T\in\mathbb{R}^{Nn\times Nn}
as in
(
3.3
). From the coordinate-transformed system matrices
(\check{A}_{m},\check{B}_{m},\check{C}_{m},\check{D}_{m})
, the following
N
parameter sets are extracted:

\displaystyle\{(A_{mi},B_{mi},C_{mi},D_{mi})\mid i=0,1,\ldots,N-1\}

(25)

Critical Difference from Periodic Time-Varying Case
: In the ideal noise-free case, all
N
parameter sets would be identical:
(A_{mi},B_{mi},C_{mi},D_{mi})=(A,B,C,D)
for all
i=0,\ldots,N-1
, reflecting the time-invariant nature of the true system. However, in the presence of noise, these parameter sets exhibit variations around the true values:
(A_{mi},B_{mi},C_{mi},D_{mi})\approx(A,B,C,D)+\delta_{i}
, where
\delta_{i}
represents the noise-induced variation component that differs for each
i
.

This deviation from the ideal identical parameter sets provides the foundation for systematic polytope construction, as the variations naturally distribute around the true system parameters due to random noise effects.

4.4
Polytope Construction and Theoretical Analysis

Using the extracted
N
parameter sets as vertices, we construct a polytope-type uncertainty model:

\displaystyle A(\lambda)

\displaystyle=\sum_{i=0}^{N-1}\lambda_{i}A_{mi},\quad B(\lambda)=\sum_{i=0}^{N-1}\lambda_{i}B_{mi}

\displaystyle C(\lambda)

\displaystyle=\sum_{i=0}^{N-1}\lambda_{i}C_{mi},\quad D(\lambda)=\sum_{i=0}^{N-1}\lambda_{i}D_{mi}

(26)

where
\lambda\in\varepsilon
.

The proposed method enables systematic generation of
N
vertices from a
single identification experiment, constructively utilizing noise-induced
variations rather than treating noise as disturbances to eliminate. This
single-experiment approach reduces experimental cost while providing
systematic uncertainty quantification suitable for robust control design.

The period
N
is a designer-selectable parameter that controls the number
of polytope vertices. Larger
N
provides more detailed uncertainty representation but increases computational cost as
O((Nn)^{3})
and requires
sufficient data length. The trade-offs between
N
, data requirements, and
representation quality are examined through numerical examples in Section
5
.

4.5
Algorithm

The proposed algorithm takes input-output data
\{u(k),y(k)\}_{k=1}^{N_{\text{data}}}
and period setting
N
as inputs, and outputs an
N
-vertex polytope-type uncertainty model through the following steps:

1.

Signal Transformation
: Convert input-output data to cyclic signals
\{\check{u}(k),\check{y}(k)\}

2.

Subspace Identification
: Apply subspace identification to cyclic signals to obtain
(\check{A}_{*},\check{B}_{*},\check{C}_{*},\check{D}_{*})

3.

Coordinate Transformation
: Recover cyclic structure using transformation matrix
T

4.

Parameter Extraction
: Extract
N
parameter sets
\{(A_{mi},B_{mi},C_{mi},D_{mi})\}_{i=0}^{N-1}
from cyclic matrices

5.

Polytope Construction
: Construct polytope-type uncertainty model using
N
sets as vertices

Computational Complexity
: Each step contributes to the overall computational cost as follows: signal transformation requires
O(N\cdot N_{\text{data}})
, subspace identification
O((Nn)^{3})
, coordinate transformation
O((Nn)^{3})
, and parameter extraction
O(N\cdot n^{2})
. The overall complexity is dominated by the
O((Nn)^{3})
terms from subspace identification and coordinate transformation. Since the augmented system has dimension
Nn
, larger period
N
significantly increases computational burden. The selection of
N
involves a trade-off between computational efficiency and polytope representation quality, with the feasible range depending on available data length
N_{\text{data}}
and system order
n
(detailed analysis in Section
5
).

5.1.1
Model Fit (FIT)

The FIT score quantifies the prediction accuracy of an identified model by
measuring the agreement between the model output and the true plant output
when subjected to validation input signals.
FIT is defined by the following equation:

\displaystyle\mathrm{FIT}=\left(1-\sqrt{\dfrac{\textstyle\sum_{k=1}^{N_{\text{data}}}(y(k)-\hat{y}(k))^{2}}{\textstyle\sum_{k=1}^{N_{\text{data}}}(y(k)-\overline{y})^{2}}}\right)\times 100[\%]

(27)

y(k)
and
\hat{y}(k)

k

\overline{y}
is the mean value of
y
. Also,
N_{\text{data}}
is the number of samples. When
y(k)
and
\hat{y}(k)
match, FIT reaches its maximum value of
100
, and a larger FIT value indicates a better model.

E=\|A-A_{m}\|_{F}^{2}+\|B-B_{m}\|_{F}^{2}+\|C-C_{m}\|_{F}^{2}+\|D-D_{m}\|_{F}^{2}

(28)

where

are the true system parameters and
(A_{m},B_{m},C_{m},D_{m})
are the identified parameters.

In addition, the following evaluation value is settled for
N
parameter sets

.

\displaystyle{\cal E}

\displaystyle=\sum_{i=0}^{N-1}\left(\|A-A_{mi}\|_{F}^{2}+\|B-B_{mi}\|_{F}^{2}\right.

(29)

\displaystyle\left.+\|C-C_{mi}\|_{F}^{2}+\|D-D_{mi}\|_{F}^{2}\right)

6
CONCLUSION

In this research, we proposed a method for deriving matrix polytope representations for linear time-invariant systems by utilizing cyclic reformulation. The key contribution is the systematic generation of polytopic uncertainty models from noise-induced parameter variations. When cyclic reformulation with period
N
is applied to a linear time-invariant system,
N
parameter sets are obtained that ideally should be identical but exhibit slight variations due to process and observation noise. The proposed method utilizes these
N
parameter sets as vertices of a polytopic uncertainty model.

Numerical validation confirmed that the PSO-optimized polytope model consistently outperforms conventional single-model identification, with FIT improvements of 0.17–2.42 percentage points across various noise conditions. The improvement margin increases under higher noise levels, confirming the effectiveness of exploiting noise-induced variations through optimal convex combination. The method enables systematic polytope construction from single identification experiments without requiring multiple separate experiments or a priori structural assumptions.

The method’s limitation lies in requiring
N_{\text{data}}>10(Nn)^{2}
for moderate accuracy and
N_{\text{data}}>25(Nn)^{2}
for high accuracy. Future work includes: (1) theoretical analysis of optimal period selection under given noise characteristics, (2) integration of polytopes constructed with different periods
N
for improved uncertainty representation, and (3) conservatism analysis to establish probabilistic guarantees that the constructed polytope contains the true system.
