Resource-Bounded Martin-Löf Type Theory: Compositional Cost Analysis for Dependent Types
Mirco A. Mannucci, Corey Thuro

Abstract
We extend resource-bounded type theory to Martin-Löf Type Theory (MLTT) with dependent types, enabling size-indexed cost bounds for programs over inductive families. Our calculus features dependent function types Π x : A b ⁡ ( x ) B ( x ) \Pi_{x:A}^{b(x)}B(x) where bounds b ⁡ ( x ) b(x) depend on the argument, dependent pair types Σ x : A B ( x ) \Sigma_{x:A}B(x) with additive cost composition, and inductive families (notably 𝖵𝖾𝖼 ⁡ ( A , n ) \mathsf{Vec}(A,n) and 𝖥𝗂𝗇 ⁡ ( n ) \mathsf{Fin}(n) ) with structurally recursive eliminators carrying size-dependent bounds. We introduce a resource-indexed universe hierarchy 𝒰 r \mathcal{U}_{r} where r ∈ L r\in L tracks the cost of type formation, and a graded modality □ r \Box_{r} for feasibility certification. Our main results are: (1) a cost soundness theorem establishing that synthesized bounds over-approximate operational costs, with bounds expressed as functions of size indices; (2) a semantic model in the presheaf topos 𝐒𝐞𝐭 L \mathbf{Set}^{L} extended with dependent presheaves and comprehension structure; (3) canonicity for the intensional fragment; and (4) initiality of the syntactic model. We demonstrate the framework with case studies including length-indexed vector operations with O ⁡ ( n ) O(n) bounds and binary search with O ⁡ ( log ⁡ n ) O(\log n) bounds expressed in the type. This work bridges the gap between dependent type theory and quantitative resource analysis, enabling certified cost bounds for size-dependent algorithms.

Introduction

In our previous work
[
1
]
, we developed resource-bounded type theory for the simply-typed lambda calculus, establishing compositional cost analysis via graded modalities over abstract resource lattices. While that framework handles first-order programs effectively, many algorithms have costs that depend on the
size
of their inputs: sorting takes
O(n\log n)
time, matrix multiplication takes
O(n^{3})
, and tree traversal takes
O(n)
where
n
is the number of nodes.

To express such size-dependent bounds
within the type system
, we need dependent types. This paper extends resource-bounded type theory to Martin-Löf Type Theory (MLTT), enabling:

•

Size-indexed bounds:
The type
\mathsf{Vec}(A,n)\to^{O(n)}B
expresses that a function on vectors of length
n
has cost linear in
n
.

•

Dependent cost functions:
Bounds
b(x)
that depend on term-level values, not just types.

•

Inductive families:

\mathsf{Vec}(A,n)
,
\mathsf{Fin}(n)
, and other indexed types with eliminators carrying precise bounds.

•

Universes with resource tracking:

\mathcal{U}_{r}
classifies types whose formation costs at most
r
.

Motivating example.

Consider a function that sums a length-indexed vector:

\mathsf{sum}:\Pi_{n:\mathbb{N}}^{\bot}\mathsf{Vec}(\mathbb{N},n)\to^{c\cdot n+d}\mathbb{N}

The type expresses: given any
n
(cost
\bot
to receive), and a vector of length
n
, the function returns a natural number with cost
c\cdot n+d
for constants
c,d
. The bound is
linear in
n
, and this linearity is visible in the type.

Design Principles

We extend the principles from
[
1
]
to the dependent setting:

P1.

Abstraction over concreteness.
Resources remain elements of an abstract lattice
L
.

P2.

Budgets are first-class.
Resource bounds appear in types, judgments, and now depend on term-level values.

P3.

Compositional rules.
Bound synthesis mirrors term structure, with dependent bounds for dependent types.

P4.

Size-indexed bounds.
Bounds may be functions

of the input, enabling
O(n)
,
O(n^{2})
,

P5.

Monotonicity preserved.
If

, then
\Box_{r_{1}}A\to\Box_{r_{2}}A
.

P6.

Universes track cost.
Type formation itself may have cost;

classifies types formable within budget

Judgments

We have four judgment forms:

Remark 3.1

(Role of the ambient budget)
.

In this paper all non-trivial information about resource usage is carried by the synthesized bound

1
]

We do

Future work may use

Definition 3.3

For

The application rule

Non-dependent case.

When

Definition 4.1

.

Bounds

\displaystyle b

\displaystyle::=r\mid\bot\mid b_{1}\oplus b_{2}\mid b_{1}\sqcup b_{2}\mid c\cdot n\mid b(t)\mid\mathsf{sum}_{i<n}b(i)

(n{+}1)\otimes b\triangleq b\oplus(n\otimes b)
. We also use the derived notation
n\otimes b
for the
n
-fold application of
\oplus
to a bound
b
:
0\otimes b\triangleq\bot

(n{+}1)\otimes b\triangleq b\oplus(n\otimes b)
.

4.3
Bound Inference Rules

For structured recursion, bounds are computed systematically:

Proposition 4.5

(Linear recursion bound)
.

If
\mathsf{natrec}(n,c_{z},c_{s})
has:

•

Base case cost
b_{z}

•

Step case cost
b_{s}
(constant per step)

Then the total bound is
b_{z}\oplus(n\otimes(b_{s}\oplus\delta_{\mathsf{natrec}}))\oplus\delta_{\mathsf{natrec}}
where
n\otimes b_{s}
denotes
n
-fold
\oplus
of
b_{s}
.

Proposition 4.6

(Divide-and-conquer bound)
.

If a function on input of size
n
has:

•

Division cost
d

•

Recursive call on size
\lfloor n/2\rfloor

•

Combination cost
c

Then the total bound satisfies

7
Semantic Model

We extend the presheaf model from
[
1
]
to dependent types. The key challenges are:

1.

Dependent types require presheaves over categories of elements

2.

Martin-Löf’s identity type has non-trivial structure (the J-eliminator)

3.

The internal lattice
\mathbb{L}
must be compatible with the groupoid structure

In the first paper
[
1
]
we worked in the presheaf topos
\mathbf{Set}^{L}
of set-valued functors
L\to\mathbf{Set}
.
For RB–MLTT we upgrade to the groupoid-valued presheaf category
\mathbf{Gpd}^{L}
in order to interpret dependent types and intensional identity types.
The inclusion of
\mathbf{Set}^{L}
into
\mathbf{Gpd}^{L}
as the full subcategory of discrete groupoids is fully faithful, so the RB–TT model from
[
1
]
appears as the
0
-truncated (set-valued) part of the groupoid model developed in this section.

To properly model intensional MLTT, we work with
groupoid-valued presheaves
rather than set-valued presheaves. This captures the fact that identity proofs can be non-trivial and compose.

7.1
Groupoid-Valued Presheaves

Definition 7.1

(The category
\mathbf{Gpd}
)
.

\mathbf{Gpd}
is the category of small groupoids and functors between them. A groupoid is a category where every morphism is an isomorphism.

Definition 7.2

(Groupoid-valued presheaves over
L
)
.

We work in the functor category
\mathbf{Gpd}^{L}
where:

•

Objects: functors
F:L\to\mathbf{Gpd}

•

Morphisms: natural transformations

For each
r\in L
,
F(r)
is a groupoid (not just a set). For
r_{1}\preceq r_{2}
, we have a functor
F(r_{1}\preceq r_{2}):F(r_{1})\to F(r_{2})
.

Remark 7.3

(Why groupoids?)
.

In intensional MLTT, the identity type
\mathsf{Id}_{A}(x,y)
may have multiple inhabitants (identity proofs), and these proofs have their own identity structure. The groupoid model captures:

•

Objects of
\llbracket A\rrbracket(r)
: elements of type
A
with cost
\preceq r

•

Morphisms in
\llbracket A\rrbracket(r)
: identity proofs between elements

•

Composition: transitivity of identity (
p:x=y
and
q:y=z
give
q\circ p:x=z
)

•

Inverses: symmetry (
p:x=y
gives
p^{-1}:y=x
)

This is the standard groupoid model of type theory
[
5
]
.

7.2
The Internal Lattice in the Groupoid Setting

Definition 7.4

(Internal lattice
\mathbb{L}
)
.

Define
\mathbb{L}:L\to\mathbf{Gpd}
by:

\mathbb{L}(r)=\mathsf{disc}(\{a\in L\mid a\preceq r\})

where
\mathsf{disc}(S)
is the discrete groupoid on set
S
(only identity morphisms).

Transition functors are inclusions:
\mathbb{L}(r_{1}\preceq r_{2}):a\mapsto a
.

The internal lattice is discrete because cost bounds have no non-trivial identities: if
a,b\in L
are equal as costs, they are
the same
cost. This is a crucial simplification.

Lemma 7.5
.

The lattice operations induce natural transformations in
\mathbf{Gpd}^{L}
:

•

\widetilde{\oplus}:\mathbb{L}\times\mathbb{L}\Rightarrow\mathbb{L}

•

\widetilde{\sqcup}:\mathbb{L}\times\mathbb{L}\Rightarrow\mathbb{L}

•

\widetilde{\bot}:\mathbf{1}\Rightarrow\mathbb{L}

Proof.

Since
\mathbb{L}(r)
is discrete for all
r
, functors between discrete groupoids are just functions on objects. The operations are well-defined by monotonicity of
\oplus
and
\sqcup
.
∎

7.3
Contexts as Groupoid-Valued Presheaves

Definition 7.6

(Context interpretation)
.

Contexts are interpreted as presheaves
\llbracket\Gamma\rrbracket:L\to\mathbf{Gpd}
by induction:

\displaystyle\llbracket\cdot\rrbracket(r)

\displaystyle=\mathbf{1}\quad\text{(terminal groupoid: one object, one morphism)}

\displaystyle\llbracket\Gamma,x:A\rrbracket(r)

\displaystyle=\int_{\gamma\in\llbracket\Gamma\rrbracket(r)}\llbracket A\rrbracket_{\gamma}(r)

where the right-hand side is the Grothendieck construction (total groupoid).

Definition 7.7

(Grothendieck construction for groupoids)
.

For
G
a groupoid and
F:G\to\mathbf{Gpd}
a functor, the total groupoid
\int_{G}F
has:

•

Objects: pairs
(\gamma,a)
with
\gamma\in\mathrm{ob}(G)
and
a\in\mathrm{ob}(F(\gamma))

•

Morphisms
(\gamma_{1},a_{1})\to(\gamma_{2},a_{2})
: pairs
(p,q)
where
p:\gamma_{1}\to\gamma_{2}
in
G
and
q:F(p)(a_{1})\to a_{2}
in
F(\gamma_{2})

7.4
Dependent Types as Fibrations

Definition 7.8

(Type interpretation)
.

For
\Gamma\vdash_{r;\,b}A\;\mathsf{type}
, define
\llbracket A\rrbracket:\int\llbracket\Gamma\rrbracket\to\mathbf{Gpd}
where
\int\llbracket\Gamma\rrbracket
is the Grothendieck construction over
L
:

\llbracket A\rrbracket(r,\gamma)=\text{groupoid of }\left\{\begin{array}[]{l}\text{Objects: }(v,b)\text{ with }\cdot\vdash_{r;\,b}v:A[\gamma],b\preceq r\\
\text{Morphisms }(v_{1},b_{1})\to(v_{2},b_{2}):\text{ proofs }p:\mathsf{Id}_{A[\gamma]}(v_{1},v_{2})\end{array}\right\}

Remark 7.9

(Morphisms track identity proofs)
.

A morphism
(v_{1},b_{1})\to(v_{2},b_{2})
in
\llbracket A\rrbracket(r,\gamma)
is an identity proof
p:v_{1}=_{A}v_{2}
. The cost of the proof
p
is bounded by
\max(b_{1},b_{2})\oplus\delta_{\mathsf{Id}}
. Composition of morphisms corresponds to transitivity; inverses correspond to symmetry.

7.5
The Cost Natural Transformation

Definition 7.10

(Cost as a natural transformation)
.

For each type
A
in context
\Gamma
:

\mathsf{cost}_{A}:\llbracket A\rrbracket\Rightarrow\mathbb{L}\circ\pi

where
\pi:\int\llbracket\Gamma\rrbracket\to L
is projection. On objects:
\mathsf{cost}_{A}(r,\gamma)(v,b)=b
. On morphisms: since
\mathbb{L}(r)
is discrete, all identity proofs map to the identity on the cost.

Lemma 7.11
.

\mathsf{cost}_{A}
is a natural transformation of groupoid-valued presheaves.

Proof.

We must show functoriality at each stage. For objects, this is immediate. For morphisms: if
p:(v_{1},b_{1})\to(v_{2},b_{2})
is an identity proof, then
\mathsf{cost}_{A}(p)
must be a morphism
b_{1}\to b_{2}
in
\mathbb{L}(r)
. Since
\mathbb{L}(r)
is discrete, this requires
b_{1}=b_{2}
.

This is achieved by defining the groupoid
\llbracket A\rrbracket(r,\gamma)
with morphisms only between pairs with the
same
cost bound, or by working with a lax version where cost can decrease along identity proofs. We adopt the first approach: identity proofs preserve certified bounds.
∎

7.6
Interpretation of Identity Types

The groupoid structure directly models identity types.

Definition 7.12

(Identity type interpretation)
.

For
\Gamma\vdash a,b:A

\llbracket\mathsf{Id}_{A}(a,b)\rrbracket(r,\gamma)=\mathsf{Hom}_{\llbracket A\rrbracket(r,\gamma)}(\llbracket a\rrbracket_{\gamma},\llbracket b\rrbracket_{\gamma})

This is a discrete groupoid (set) of morphisms in the groupoid
\llbracket A\rrbracket(r,\gamma)
from the interpretation of
a
to the interpretation of
b
.

Objects: identity proofs
p:a[\gamma]=_{A}b[\gamma]
with cost bound.

Lemma 7.13

(Reflexivity)
.

\mathsf{refl}_{a}
is interpreted as the identity morphism
\mathrm{id}_{\llbracket a\rrbracket_{\gamma}}
in the groupoid
\llbracket A\rrbracket(r,\gamma)
.

Theorem 7.14

(J-eliminator is sound)
.

The J-eliminator is modeled by the universal property of identity morphisms in groupoids: given a family
C
over the path space and
d:C(a,\mathsf{refl}_{a})
, we obtain
\mathsf{J}(p,d):C(b,p)
for any
p:a=b
by transport along
p
.

Proof.

In a groupoid
G
, for any functor
F:G\to\mathbf{Gpd}
and any morphism
p:x\to y
in
G
, there is an induced functor
F(p):F(x)\to F(y)
. The J-eliminator corresponds to:

\mathsf{J}(p,d)=F(p)(d)

where
F
interprets the motive
C
. The computation rule
\mathsf{J}(\mathsf{refl}_{a},d)=d
holds because
F(\mathrm{id}_{x})=\mathrm{id}_{F(x)}
.
∎

7.7
Interpretation of
\Pi

Definition 7.15

(
\Pi

.

\displaystyle\mathrm{ob}(\llbracket\Pi_{x:A}^{b(x)}B\rrbracket(r,\gamma))=

\displaystyle\quad\left\{(\lambda x.t,b_{\lambda})\,\middle|\,\begin{array}[]{l}\cdot\vdash_{r;\,b_{\lambda}}\lambda x.t:(\Pi_{x:A}^{b(x)}B)[\gamma]\\

Remark 7.16

.

The morphisms in

\llbracket\mathbb{N}\rrbracket(r)=\mathsf{disc}(\{(\mathsf{S}^{n}(\mathsf{Z}),\bot)\mid n\in\mathbb{N}\})

Vectors.

7.10

Definition 7.18

.

\mathrm{ob}(\llbracket\mathcal{U}_{s}\rrbracket(r))=\{(A,b)\mid A\text{ is a type code},\cdot\vdash_{r;\,b}A:\mathcal{U}_{s},b\preceq s\preceq r\}

Remark 7.19

In the groupoid model, morphisms in the universe are type isomorphisms (equivalences), but the univalence axiom (

7.11

Theorem 7.20

Case (

Theorem 7.25

(Initiality)
.

The syntactic RB-CwF-Gpd is initial: for any RB-CwF-Gpd
\mathcal{M}
, there exists a unique (up to isomorphism) morphism of RB-CwF-Gpds
\llbracket-\rrbracket_{\mathcal{M}}:\mathbf{Syn}\to\mathcal{M}
.

Proof.

By induction on syntax, now respecting the groupoid structure:

Contexts.

\llbracket\Gamma\rrbracket_{\mathcal{M}}
defined by comprehension.

Types.

\llbracket A\rrbracket_{\mathcal{M}}
defined using type formers in
\mathcal{M}
.

Terms.

\llbracket t\rrbracket_{\mathcal{M}}
defined using term formers. For identity proofs, use the groupoid structure.

Identity proofs.

For
p:a=b
in context
\Gamma
,
\llbracket p\rrbracket_{\mathcal{M}}
is a morphism
\llbracket a\rrbracket_{\mathcal{M}}\to\llbracket b\rrbracket_{\mathcal{M}}
in the groupoid
\mathsf{Tm}(\llbracket\Gamma\rrbracket_{\mathcal{M}},\llbracket A\rrbracket_{\mathcal{M}})
.

Cost preservation.

The cost functor commutes with interpretation:

\mathsf{cost}_{\llbracket A\rrbracket_{\mathcal{M}}}(\llbracket t\rrbracket_{\mathcal{M}})=\llbracket b\rrbracket_{\mathcal{M}}

where
\Gamma\vdash_{r;\,b}t:A
.

Uniqueness.

Up to natural isomorphism, forced by the universal properties of type formers and the groupoid structure.
∎

(Sound embedding)
.

\cdot\vdash_{r;\,b}t:A

Remark 7.27

.

\infty

12
Conclusion

We have extended resource-bounded type theory to Martin-Löf Type Theory, enabling size-indexed cost bounds for dependent types. The key innovations are:

1.

Dependent bounds:

\Pi_{x:A}^{b(x)}B
where
b(x)
depends on the argument

2.

Inductive families:

\mathsf{Vec}(A,n)
and
\mathsf{Fin}(n)
with size-dependent eliminator bounds

3.

Resource universes:

\mathcal{U}_{r}
tracking type formation cost

4.

Cost soundness:
Theorem
6.3
establishing bounds over-approximate costs

5.

Semantic model:
Presheaves with dependent structure and initiality

This bridges the gap between dependent type theory and quantitative resource analysis, enabling certified cost bounds for size-dependent algorithms expressed directly in types. The framework handles common complexity classes (
O(1)
,
O(n)
,
O(\log n)
,
O(n\log n)
,
O(n^{2})
,
O(n^{3})
) and validates bounds for fundamental algorithms including vector operations, binary search, and sorting.

Future work will extend the framework to Homotopy Type Theory (RB-HoTT), exploring resource-bounded paths and higher structure.
