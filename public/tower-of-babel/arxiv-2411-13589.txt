Abstract

Probability distribution theory helps in studying the impact of various dimensions in life while the Mittag-Leffler function and bicomplex are used in electromagnetism, quantum mechanics, and signal theory. Considering
the importance of both, the purpose of this paper is to introduce bicomplex Mittag-Leffler distribution theory with the help of the bicomplex Mittag-Leffler function. Moreover, it also tells us about the moment-generating
function, the first four moments, the mean, and the variance of this endeavour.

Introduction

As the importance of the Mittag-Leffler function is increasing in physical applications, many researchers are studying various extensions and applications of the Mittag-Leffler function. Some of them are the Incomplete Mittag-Leffler Function (Singh and Porwal 2013), a generalization of the Mittag-Leffler function and its properties ( Shukla and Prajapati 2007), and A singular integral equation with a generalized Mittag-Leffler function in the kernel (Prabhakar 1971).

The Mittag-Leffler function was first proposed by Swedish mathematician Gosta Mittag-Leffler in 1903 (Mittag-Leffler 1903).

{\mathbb{E}}_{\alpha}(z)=\sum_{k=0}^{\infty}\frac{z^{k}}{\Gamma(\alpha k+1)},\hskip 20.0ptz,\alpha\in\mathbb{C}

is called the Mittag Leffler function of order
\alpha
. The Mittag-Leffler function is the direct generalization of an exponential function

e^{z}=\sum_{k=0}^{\infty}\frac{z^{k}}{\Gamma(k+1)}.

The first generalization of the Mittag-Leffler function was given by A. Wiman ( Wiman 1905)

{\mathbb{E}}_{\alpha,\beta}(z)=\sum_{k=0}^{\infty}\frac{z^{k}}{\Gamma(\alpha k+\beta)},\hskip 20.0ptz,\alpha,\beta\in\mathbb{C},Re(\alpha)>0,Re(\beta)>0

is a two-parameter Mittag-Leffler function.

Bicomplex Number

In terms of real components, the set of bicomplex numbers is defined as

\mathbb{T}=\{\xi:\xi=x_{0}+i_{1}x_{1}+i_{2}x_{2}+jx_{3}\;|\;x_{0},x_{1},x_{2},x_{3}\in\mathbb{R}\},

and in terms of complex components, it can be written as

\mathbb{T}=\{\xi:\xi=z_{1}+i_{2}z_{2}\;|\;z_{1},z_{2}\in\mathbb{C}\}

x_{0}=Re(\xi),\;x_{1}=Im_{i_{1}}(\xi),\;x_{2}=Im_{i_{2}}(\xi),\;x_{3}=Im_{j}(\xi).

Null Cone

The set of all zero divisors is called a null cone defined as

\displaystyle\mathbb{NC}=\{z_{1}+i_{2}z_{2}\;|\;z_{1}^{2}+z_{2}^{2}=0\}.

Two non trivial zero divisors in
\mathbb{T}
, denoted by
e_{1}
and
e_{2}
are defined as follows

e_{1}=\frac{1+i_{1}i_{2}}{2}=\frac{1+j}{2},

e_{2}=\frac{1-i_{1}i_{2}}{2}=\frac{1-j}{2},

e_{1}.e_{2}=0,\;e_{1}+e_{2}=1,\;e_{1}^{2}=e_{1},\;e_{2}^{2}=e_{2}.

(1.1)

Idempotent Representation

Every element
\xi\in\mathbb{T}
has unique idempotent representation in terms of
e_{1}
and
e_{2}
defined by

\xi=z_{1}+i_{2}z_{2}=\xi_{1}e_{1}+\xi_{2}e_{2},

(1.2)

where

\xi_{1}=(z_{1}-i_{1}z_{2}),\;\xi_{2}=(z_{1}+i_{1}z_{2}).

Bicomplex Mittag-Leffler Function

The bicomplex one parameter Mittag-Leffler function is defined as

{\mathbb{E}}_{\alpha}(\xi)=\sum_{k=0}^{\infty}\frac{\xi^{k}}{\Gamma(\alpha k+1)},\hskip 20.0pt\xi,\alpha\in\mathbb{T},|Im_{j}(\alpha)|<Re(\alpha).

(1.3)

By using idempotent representation we can write
E_{\alpha}(\xi)
as follows

{\mathbb{E}}_{\alpha}(\xi)=\sum_{k=0}^{\infty}\frac{\xi_{1}^{k}}{\Gamma(\alpha_{1}k+1)}e_{1}+\sum_{k=0}^{\infty}\frac{\xi_{2}^{k}}{\Gamma(\alpha_{2}k+1)}e_{2}=E_{\alpha_{1}}(\xi_{1})e_{1}+E_{\alpha_{2}}(\xi_{2})e_{2}

(1.4)

where

\xi=\xi_{1}e_{1}+\xi_{2}e_{2},

(1.5)

\alpha=\alpha_{1}e_{1}+\alpha_{2}e_{2}.

(1.6)

Researchers have also studied various distributions involving the Mittag-Leffler function. Mittag-Leffler Functions and Their Applications (Haubold et al. 2011), On Mittag Leffler Functions and Related Distributions (Pillai 1990), On Mittag-Leffler type Poisson Distribution (Porwal and Dixit 2017), An Overview of Generalized Gamma Mittag-Leffler Model and its Applications (Nair 2015), The role of the Mittag-Leffler function in fractional Modeling ( Rogosin 2015).

Researchers have also explored Exotic Probability Theory, a branch of probability theory in which we study the probabilities that are outside the interval
[0,1]
. Mostly the work has been done where the probabilities are either negative or complex numbers. As Exploring Exotic Probability Theory (Yannan Lin 2020-21), Quantum Mechanics as an Exotic Probability Theory (Saul Youssef 1995).

This motivated us to define a probability density function that deals with bicomplex probabilities.
In this paper, we have introduced a new distribution named
Bicomplex Mittag-Leffler Distribution
that involves the Bicomplex Mittag-Leffler Function of one parameter (Agrwal et al. 2022). We have derived the Moment Generating Function, first four moments, Mean, and Variance of this distribution using the properties of bicomplex numbers (Agrwal et al. 2022).

Consider the probability density function

F(\xi)=(1+a)e^{-\xi}{\mathbb{E}}_{\alpha}(-a\xi^{\alpha}),

(1.7)

{\mathbb{E}}_{\alpha}(-a\xi^{\alpha})=\sum_{k=0}^{\infty}\frac{(-a\xi^{\alpha})^{k}}{\Gamma(\alpha k+1)},

\xi=z_{1}+i_{2}z_{2}

|Im_{j}(\alpha)|<\Re(\alpha).

If
\xi
is a continuous random variable with probability density function

F(\xi)
, then the moment generating function is defined as follows

M_{\xi}(t)=E(e^{\xi t}).

(1.8)

M_{\xi}(t)=\int_{-\infty}^{\infty}e^{\xi t}F(\xi)d\xi.

(1.9)

rth moment

If
\xi
is a continuous random variable with probability density function

F(\xi)

\mu_{r}^{{}^{\prime}}=E(\xi^{r})=\int_{-\infty}^{\infty}\xi^{r}F(\xi)d\xi.

(1.10)

2.1
Probability Density Function

The function defined in (1.7) is a probability density function since

\int_{0}^{\infty}F(\xi)d\xi=1.

Proof

\int_{0}^{\infty}F(\xi)d\xi=\int_{0}^{\infty}(1+a)e^{-\xi}{\mathbb{E}}_{\alpha}(-a\xi^{\alpha})d\xi

Using idempotent representation

=(1+a)\left[\left(\int_{0}^{\infty}e^{-\xi_{1}}{\mathbb{E}}_{\alpha}(-a\xi_{1}^{\alpha})d\xi_{1}\right)e_{1}+\left(\int_{0}^{\infty}e^{-\xi_{2}}{\mathbb{E}}_{\alpha}(-a\xi_{2}^{\alpha})d\xi_{2}\right)e_{2}\right]

=\sum_{k=0}^{\infty}(1+a)\left[\left(\int_{0}^{\infty}e^{-\xi_{1}}\frac{(-a)^{k}\xi_{1}^{\alpha k}}{\Gamma(\alpha k+1)}d\xi_{1}\right)e_{1}+\left(\int_{0}^{\infty}e^{-\xi_{2}}\frac{(-a)^{k}\xi_{2}^{\alpha k}}{\Gamma(\alpha k+1)}d\xi_{2}\right)e_{2}\right]

=\sum_{k=0}^{\infty}(1+a)\left[\left(\frac{(-a)^{k}}{\Gamma(\alpha k+1)}\Gamma(\alpha k+1)\right)e_{1}+\left(\frac{(-a)^{k}}{\Gamma(\alpha k+1)}\Gamma(\alpha k+1)\right)e_{2}\right]

=(1+a)\sum_{k=0}^{\infty}(-a)^{k}(e_{1}+e_{2}).

Using(1.1)

\int_{0}^{\infty}F(\xi)d\xi=1.

We have relaxed the condition
F(\xi)\geq 0
since we are dealing with the bicomplex probabilities that lie outside the region
[0,1]
.

2.2
Moment Generating Function

The moment generating function of the probability density function defined in (1.7) is given by

M_{\xi}(t)=E(e^{\xi t})

=\int_{0}^{\infty}e^{\xi t}F(\xi)d\xi

=\int_{0}^{\infty}e^{\xi t}(1+a)e^{-\xi}{\mathbb{E}}_{\alpha}(-a\xi^{\alpha})d\xi

=(1+a)\int_{0}^{\infty}e^{-\xi(1-t)}{\mathbb{E}}_{\alpha}(-a\xi^{\alpha})d\xi.

Using idempotent representation

M_{\xi}(t)=(1+a)\left[\left(\int_{0}^{\infty}e^{-\xi_{1}(1-t)}{\mathbb{E}}_{\alpha}(-a\xi_{1}^{\alpha})d\xi_{1}\right)e_{1}+\left(\int_{0}^{\infty}e^{-\xi_{2}(1-t)}{\mathbb{E}}_{\alpha}(-a\xi_{2}^{\alpha})d\xi_{2}\right)e_{2}\right]

=\sum_{k=0}^{\infty}(1+a)\left[\left(\int_{0}^{\infty}e^{-\xi_{1}(1-t)}\frac{(-a)^{k}\xi_{1}^{\alpha k}}{\Gamma(\alpha k+1)}d\xi_{1}\right)e_{1}+\left(\int_{0}^{\infty}e^{-\xi_{2}(1-t)}\frac{(-a)^{k}\xi_{2}^{\alpha k}}{\Gamma(\alpha k+1)}d\xi_{2}\right)e_{2}\right]

=\sum_{k=0}^{\infty}(1+a)(-a)^{k}\left[\left(\frac{1}{\Gamma(\alpha k+1)}\frac{\Gamma(\alpha k+1)}{(1-t)^{\alpha k+1}}\right)e_{1}+\left(\frac{1}{\Gamma(\alpha k+1)}\frac{\Gamma(\alpha k+1)}{(1-t)^{\alpha k+1}}\right)e_{2}\right]

=\sum_{k=0}^{\infty}(1+a)(-a)^{k}\left[\left(\frac{1}{(1-t)^{\alpha k+1}}\right)e_{1}+\left(\frac{1}{(1-t)^{\alpha k+1}}\right)e_{2}\right]

\displaystyle=(1+a)\left[\left(\frac{(1-t)^{\alpha-1}}{(1-t)^{\alpha}+a}\right)e_{1}+\left(\frac{(1-t)^{\alpha-1}}{(1-t)^{\alpha}+a}\right)e_{2}\right].

( where
\left|\frac{a}{(1-t)^{\alpha}}\right|<1
)

M_{\xi}(t)=\frac{(1+a)(1-t)^{\alpha-1}}{a+(1-t)^{\alpha}}(e_{1}+e_{2}).

Using(1.1)

M_{\xi}(t)=\frac{(1+a)(1-t)^{\alpha-1}}{a+(1-t)^{\alpha}}.
