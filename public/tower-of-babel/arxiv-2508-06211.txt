Matchings with prescribed color counts
Tudor Popescu

Abstract
. In this note, we prove an interesting result about perfect matchings in a K 2 ​ n , 2 ​ n K_{2n,2n} whose edges are colored in red and blue such that each vertex is part of n n red edges and n n blue edges.



1.
Introduction

A classical problem in complexity theory is the Exact Matching (EM) Problem, where given an edge-colored graph, with colors red and blue, and an integer
k,
the goal is to decide whether or not the graph contains a perfect matching with exactly
k
red edges. The problem was first introduced in 1982 by Papadimitriou and Yannakakis in
[2]
, and in 1987 Mulmuley, Vazirani, and Vazirani
[3]
showed that there is a randomized algorithm for this problem. We consider the complete bipartite (
K_{2n,2n}
) variant of this problem where each vertex is part of
n
blue edges and
n
red ones. In this paper, we will prove that if
k
is even, there always exists a perfect matching with
k
red edges and
2n-k
blue ones, and that the same holds when
k
is odd unless the graph has a very specific structure (if the graph formed by blue edges is disconnected).

3.
Concluding Remakrs

Remark 3.1
.

Let
G=(X,Y,E)
be a bipartite graph with
|X|=|Y|=2n
such that
\deg(v)=n,\forall v\in X\cup Y.
Then
G
is connected, unless
G
is isomorphic to a disjoint union of two copies of
K_{n,n}.

Proof.

Assume that
G
is disconnected. If there is no path between
x_{i}
and
x_{j}
, then
N(x_{i})\cap N(x_{j})=\emptyset.
Without loss of generality we can assume that
N(x_{i})=\{y_{1},\ldots,y_{n}\},N(x_{j})=\{y_{n+1},\ldots,y_{2n}\}.
Since there is no path between
x_{i}
and
x_{j},
we must have that
N(y_{a})\cap N(y_{b})=\emptyset,\forall a\in\{1,\ldots,n\},b\in\{n+1,2n\}.
But since
\deg(v)=n,\forall v,
we have that
N(y_{a_{1}})=N(y_{a_{2}}),\forall a_{1},a_{2}\in\{1,2,\ldots,n\}
and
N(y_{b_{1}})=N(y_{b_{2}}),\forall b\in\{n+1,2n\}.
Therefore, the graph is isomorphic to two copies of
K_{n,n}.
The proof when there is no path between
x_{i}
and
y_{j}
is analogous.

∎

Using the above remark, we easily obtain a reformulation of Theorem
2.1
:

Corollary 3.2
.

Let
k,n\in\mathbb{N}
with
k
odd. Color all the edges of a
K_{2n,2n}
with red and blue such that each vertex is part of
n
red edges and
n
blue ones. Then there exists a perfect matching with
k
red edges and
2n-k
blue ones if and only if the graph of blue edges is connected.

4.
Application to the permanent

There has been extensive research on the permanent of a matrix with
0,1
entries. In 1963, Minc conjectured that if
A
is a square binary matrix of size
n
and
r_{i}=a_{i,1}+\ldots+a_{i,n},
then
0\leq\text{per}(A)\leq\prod_{i=1}^{n}(r_{i}!)^{1/r_{i}};
this was proved by Bregman
[1]
in 1973. We can rephrase Theorem
2.1
as follows:

Corollary 4.1
.

Let
A
be a square matrix of size
2n
with
0,1
entries such that the sum of the entries in each row and column is
n.
Moreover, let
k
be an even integer,
0\leq k\leq n.
There is an algorithm that selects
k
zero entries, removes the rows and columns on which these entries lie, and assures that the remaining square binary matrix of size
2n-k
has nonzero permanent.
