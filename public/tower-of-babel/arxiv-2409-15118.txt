Solutions at vacuum and rarefaction waves in pressureless Euler alignment system Thanks: The authors acknowledge the helpful comments on this work by Jan Peszek, Changhui Tan and Bartosz Wróblewski.
Szymon Cygan ID, Grzegorz Karch ID

Abstract
. We construct global-in-time weak solutions to the pressureless Euler alignment system posed on the whole line and supplemented with initial conditions, where an initial density is an arbitrary, nonnegative, bounded, and integrable function (hence density at vacuum is allowed) and the corresponding initial velocity is determined by certain inequalities. Moreover, our setting covers the case where solutions to the pressureless Euler alignment system are known to be non-smooth. We also study an asymptotic behavior of constructed solutions and we show that, under a suitable rescaling, the density looks like a uniform distribution on a bounded, time dependent, expanding-in-time interval and the corresponding velocity approaches a rarefaction wave ( i.e. the well-known explicit solution to the inviscid Burgers equation).

1.
Introduction

Main results of this work

We study properties of global-in-time solutions to the following one dimensional (pressureless)
Euler alignment system

(1.1)

\displaystyle\begin{aligned} \rho_{t}+(\rho u)_{x}&=0,\\
u_{t}+uu_{x}&=\int_{\mathbb{R}}\varphi(y-x)\big(u(y,t)-u(x,t)\big)\rho(y,t)\,\text{d}y,\end{aligned}\qquad x\in\mathbb{R},\quad t>0,

with the singular interaction kernel

(1.2)

\displaystyle\varphi(x)=\frac{1}{\smash{|x|}^{1+\alpha}}\qquad\text{for some}\quad\alpha\in(0,1)

which describes the evolution of the density
\rho=\rho(x,t)
and the corresponding velocity
u=u(x,t)
.
Notice that the right-hand side of second equation in system (
1.1
) with singular kernel (
1.2
) resembles the fractional Laplacian defined by the formula

(1.3)

\displaystyle\Lambda^{\alpha}f(x)=\int_{\mathbb{R}}\frac{f(x)-f(y)}{|y-x|^{\alpha+1}}\,\text{d}y,

which we often use in this work.
We supplement this system with initial conditions

(1.4)

\displaystyle\rho(\cdot,0)=\rho_{0}\in{L^{\infty}(\mathbb{R})}\cap{L^{1}(\mathbb{R})},\qquad u(\cdot,0)=u_{0}\in{L^{\infty}(\mathbb{R})}

and under the assumption that there exists a constant
a>0
such that

(1.5)

\displaystyle 0\leqslant G_{0}(x)\equiv(u_{0})_{x}(x)-\Lambda^{\alpha}\rho_{0}(x)\leqslant a\rho_{0}(x)\quad\text{a.e.~in $x\in\mathbb{R}$,}

we construct a global-in-time weak solution

u\in L^{\infty}(\mathbb{R}\times[0,\infty)),\qquad\rho\in L^{\infty}\big([0,\infty),{L^{1}(\mathbb{R})}\cap{L^{\infty}(\mathbb{R})}\big)

to initial value problem (
1.1
)-(
1.4
)
(see Theorem
2.3
, below).

Then, in Theorem
2.7
, we study an asymptotic behavior of constructed solutions.
Assuming, moreover, that there are constants
a>0
,
b>0
such that

(1.6)

\displaystyle 0\leqslant b\rho_{0}(x)\leqslant G_{0}(x)\leqslant a\rho_{0}(x)\quad\text{a.e.~in $x\in\mathbb{R}$}

we show
that

(1.7)

\displaystyle\lambda\rho(\lambda x,\lambda t)\xrightarrow{\lambda\to\infty}\overline{\rho}(x,t)=\frac{M_{\rho}}{M_{G}}\begin{cases}0,&x\leqslant 0,\\
\frac{1}{t},&0<x\leqslant M_{G}t,\\
0,&x>M_{G}t,\end{cases}

and

(1.8)

\displaystyle u(\lambda x,\lambda t)

\displaystyle\xrightarrow{\lambda\to\infty}\overline{u}(x,t)=\begin{cases}0,&x\leqslant 0,\\
\frac{x}{t},&0<x\leqslant M_{G}t,\\
M_{G},&x>M_{G}t,\end{cases}

in suitable (weak) typologies and
with the numbers

M_{\rho}=\int_{\mathbb{R}}\rho_{0}(x)\,\text{d}x\quad\text{and}\quad M_{G}=\int_{\mathbb{R}}G_{0}(x)\,\text{d}x.

Let us briefly summarize how the results of this work contribute to the theory on the one-dimensional pressureless Euler alignment system (
1.1
)-(
1.2
) posed on the whole line
\mathbb{R}
.

We have obtained global-in-time weak solutions corresponding to initial conditions where the nonnegative density
\rho_{0}\in L^{1}(\mathbb{R})\cap L^{\infty}(\mathbb{R})
is arbitrary and
u_{0}
is determined by inequalities (
1.5
) which include solutions at vacuum,
i.e
initial densities satisfying
\rho_{0}(x)=0
at some
x\in\mathbb{R}
are allowed.
In this range of initial conditions, we construct weak solutions using methods analogous to those developed for the porous medium equation with a non-vocal pressure (see equation (
1.17
), below). Our functional setting covers the case when solutions of system (
1.1
)-(
1.2
) are not necessarily smooth (which is known in the case when
G_{0}\equiv 0
and when system (
1.1
)-(
1.2
) reduces to the porous medium equation with a non-local pressure, see the references below).

We also study the asymptotic behavior of the constructed solutions.
If initial conditions satisfy inequalities (
1.6
),
after suitable rescaling of a solution to system (
1.1
)-(
1.2
), the density
\rho(x,t)
looks like a uniform distribution on the interval
[0,M_{G}t]
and the corresponding velocity

u(x,t)
approaches
the rarefaction wave (
1.8
) which is the well-known solution of the Burgers equation
u_{t}+uu_{x}=0
.
Here, the lower bound
0\leqslant b\rho_{0}(x)\leqslant G_{0}(x)
in inequalities (
1.6
) with
b>0
and with a nontrivial
\rho_{0}
plays a pivotal role
because, for
G\equiv 0
, scaling limits of solutions to system (
1.1
)-(
1.2
) is different (see Remark
2.9
, below).

In this work, we consider system (
1.1
)
with the singular kernel (
1.2
) with
\alpha\in(0,1)
because only in this range, the quantity

G\equiv u_{x}-\Lambda^{\alpha}\rho\quad\text{written in the form}\quad\Lambda^{-\alpha}u_{x}\equiv\Lambda^{-\alpha}G+\rho

allows us to obtain suitable compactness estimates of
u(x,t)
in both results: on the existence of solutions and on their asymptotic behavior.

A detailed statement of these results is included in the next section.

Cucker–Smale model and Euler alignment system

Now, we briefly review the motivations for studying model (
1.1
) and we cite related references.
We refer to the recent monograph by Shvydkoy
[
35
]
for further details and additional references.

Model (
1.1
) arises as the macroscopic realisation of the Cucker and Smale agent-based model

(1.9)

\displaystyle x_{i}^{\prime}=v_{i},\qquad mv_{i}^{\prime}=\frac{1}{N}\sum_{j=1}^{N}\varphi(|x_{i}-x_{j}|)(v_{j}-v_{i})

which describes the collective motion of
N
individuals.
This system with a smooth kernel
\varphi
was first introduced by Cucker and Smale
[
13
,
14
]

who proved that every solution aligns
exponentially and flocks strongly, namely, it has the properties:

(1.10)

\displaystyle\lim_{t\to\infty}|v_{i}-\overline{v}|=0\quad\text{and}\quad\sup_{i,j}|x_{i}-x_{j}|\leqslant D<\infty,

see the monograph
[
35
]
as well as the papers

[
1
,
32
,
33
]

for a survey of known results.

For a large number of agents,
i.e.
when
N\to\infty
,
it is more efficient to consider the
mesoscopic description of the Cucker-Smale dynamics. The corresponding
kinetic formulation of system (
1.9
) can be derived formally via the BBGKY hierarchy to obtain
the following Vlasov-type model which
describes evolution of a probability distribution
f(x,v,t)
of agents in a phase
space
(x,v)
:

(1.11)

\partial_{t}f+v\cdot\nabla f+\lambda\nabla_{v}\big(fF(f)\big)=0,

where

(1.12)

F(f)(x,v,t)=\int_{\mathbb{R}^{2n}}\varphi(x,y)(w-v)f(y,w,t)\,\text{d}w\,\text{d}y.

This kinetic alignment model was first derived by Ha and Tadmor
[
24
]
and then studied
e.g.
in

[
23
,
12
]
.

By taking
v
-moments of equation (
1.11
)
and introducing the monokinetic density ansatz
concentrated at the macroscopic velocity
u
:

f(x,v,t)=\rho(x,t)\delta(v-u(x,t))

we obtain either the system

\displaystyle\rho_{t}+\nabla\cdot(\rho u)

\displaystyle=0,

\displaystyle(\rho u)_{t}+\nabla_{x}\cdot(\rho u\otimes u)

\displaystyle=\int_{\mathbb{R}^{n}}\rho(x)\rho(y)(u(y)-u(x))\varphi(x-y)\,\text{d}y,

or, after formally dividing by
\rho
,
the system

(1.13)

\displaystyle\rho_{t}+\nabla\cdot(\rho u)

\displaystyle=0,

(1.14)

\displaystyle u_{t}+u\cdot\nabla_{x}u

\displaystyle=\int_{\mathbb{R}^{n}}\rho(y)(u(y)-u(x))\varphi(x-y)\,\text{d}y,

which is called
the pressureless Euler alignment system
and which
describes the evolution of the density profile
\rho=\rho(x,t)
together with the associated velocity
u(x,t)
.
This system was derived by Ha and Tadmor
[
24
]
(see also
[
25
,
19
]
), and initial results regarding the existence of solutions (either local-in-time or global-in-time) with a smooth kernel
\varphi
and smooth, initial conditions have been presented in the works
[
21
,
22
,
29
]
.

Critical threshold conditions for the global regularity of solutions in the one-dimensional version of system (
1.13
)–(
1.14
), posed on the entire real line
\mathbb{R}
with a bounded positive kernel
\varphi
, first appeared in the work
[
43
]
. The sharp criterion was later identified in the paper
[
11
]
, accompanied by the proof that global-in-time regular solutions exist if and only if the initial data are “sub-critical” in the following sense:

(1.15)

(u_{0})_{x}(x)+\varphi*\rho_{0}(x)\geq 0\quad\text{for all}\quad x\in\mathbb{R}.

On the other hand, as seen in
[
36
]
, the one-dimensional model posed on the one-dimensional torus
\mathbb{T}
with the singular kernel
\varphi(x)=|x|^{-1-\alpha}
for
1\leqslant\alpha<2
, and subject to initial data
(u_{0},\rho_{0})\in H^{3}(\mathbb{T})\times H^{2+\alpha}(\mathbb{T})
, admits a global solution within the same class. Furthermore, still considering the one-dimensional model on the torus but with
\alpha\in(0,1)
, it was proven in
[
16
]
that the system, supplemented with smooth initial data
(\rho_{0},u_{0})
such that
\rho_{0}(x)>0
for all
x\in\mathbb{T}
, possesses a unique global smooth solution.
Other results regarding the existence and regularity of solutions to the one-dimensional model with
\alpha\in(0,2)
, on the torus and with no-vacuum initial data are contained in
[
37
,
38
,
30
]
. It is noteworthy that the singularity of the kernel
\varphi(x)=|x|^{-1-\alpha}

removes the requirement (
1.15
). The regularity result for
\alpha\in(0,1)
, first obtained in
[
16
]
, is even more surprising, because for the analogous model - the fractal Burgers equation - solutions develop shocks in finite time, as shown in
[
2
]
.

Finally, we recall recent results concerning the existence and regularity of solutions in the multidimensional case. In the work
[
15
]
, the system (
1.13
)–(
1.14
) with
\alpha\in(1,2)
is examined on the entire space
\mathbb{R}^{n}
with
n\geqslant 1
, and global-in-time regular solutions have been constructed under a smallness assumption imposed on
(u_{0},\rho_{0}-1)
. Then, the authors of
[
34
]
(see also
[
28
,
27
]
and the references therein) consider this system with
\alpha\in(0,2)
on the
n
-dimensional torus, obtaining local-in-time regular solutions corresponding to sufficiently regular initial conditions with no vacuum
(
i.e.
for
\rho_{0}(x)>0
for all
x
). Global-in-time weak solutions to the forced Euler-alignment system on the torus and without vacuum (this time, under the assumption
\rho_{0}^{-1}\in L^{\infty}(\mathbb{T})
) have been constructed in
[
30
]
.

Porous medium equation with the nonlocal pressure and Barenblatt self-similar profiles

In this work, we study
the Euler alignment system (
1.1
)-(
1.2
) written in the equivalent form (see comments below equations (
2.5
))

(1.16)

\displaystyle\rho_{t}+(\rho u)_{x}=0,\quad G_{t}+(Gu)_{x}=0,\quad u_{x}-\Lambda^{\alpha}\rho=G,

which for
G\equiv 0

reduces to
the so-called one dimensional
porous medium equation with the nonlocal pressure

(1.17)

\displaystyle\rho_{t}+(u\rho)_{x}=0\quad\text{with}\quad u_{x}=\Lambda^{\alpha}\rho\quad\text{for}\quad x\in\mathbb{R},\;t>0.

This equation, supplemented with an initial condition

(1.18)

\rho(\cdot,0)=\rho_{0}\in L^{1}(\mathbb{R})\cap L^{\infty}(\mathbb{R})

and motivated by the theory of dislocations, was considered by Biler, Karch, and Monneau
[
5
]
, who constructed a unique global-in-time viscosity solution
\rho=\rho(x,t)
. Then, the extension of model (
1.18
) to higher dimensions was introduced
by Caffarelli and Vázquez starting in
[
8
,
10
]
(followed by several other papers, see
e.g.

[
7
,
9
,
4
,
40
,
41
]

and references therein), where the existence of weak solutions,
the finite speed of propagation, local Hölder regularity, and asymptotic behaviour
were established.

From the left to the right: the Getoor function
\Phi_{\alpha}(x)
given by formula (
1.20
) with
\alpha=1/2
,

\Lambda^{\alpha}\Phi_{\alpha}(x)

1.22

In particular, the

contains a construction of
the following explicit self-similar solution of equation (

)

(1.19)

\displaystyle\rho(x,t)=t^{-\frac{1}{\alpha+1}}\Phi_{\alpha}\left({x}{t^{-\frac{1}{\alpha+1}}}\right),

with the profile

(1.20)

\Phi_{\alpha}(x)=K(\alpha,1)\left(1-|x|^{2}\right)_{+}^{\frac{\alpha}{2}},

and the constant

(1.21)

K(\alpha,1)=\Gamma\left(\frac{1}{2}\right)\left[2^{\alpha}\Gamma\left(1+\frac{\alpha}{2}\right)\Gamma\left(\frac{1+\alpha}{2}\right)\right]^{-1},

\Gamma
denotes the usual

(see also
[
4
]
for analogous explicit self-similar solutions of the higher dimensional counterpart of equation (

)).
This explicit solution generalizes the well-known Barenblatt self-similar solution of the classical porous medium equation.
On the other hand,
\Phi_{\alpha}(x)
is called the Getoor function and it has a probabilistic interpretation:
it express the
expected time of the first passage to the exterior of the unit ball of the symmetric
\alpha
-stable process starting at
x
.

It was proved by Getoor
[
20
, Thm 5.2]
that

(1.22)

\displaystyle\Lambda^{\alpha}\Phi_{\alpha}(x)=\begin{cases}1,&\text{for}\quad|x|<1,\\
H(x),&\text{for}\quad|x|>1,\end{cases}

where

H(x)=\left[\Gamma\left(-\frac{\alpha}{2}\right)\Gamma\left(\frac{3+\alpha}{2}\right)\right]^{-1}\Gamma\left(\frac{1}{2}\right)\cdot|x|^{-1-\alpha}\cdot F\left(\frac{2+\alpha}{2},\frac{1+\alpha}{2},\frac{1+\alpha}{2},|x|^{-2}\right)

and
F(a,b,c,x)
is the hypergeometric function.
Thus, applying the relation
u_{x}=\Lambda^{\alpha}\rho
to the self-similar solution
(
1.19
) we obtain the velocity in the explict self-similar form

(1.23)

\displaystyle u(x,t)=U\left({x}{t^{-\frac{1}{\alpha+1}}}\right)\quad\text{with}\quad U(x)=\int_{-\infty}^{x}\Lambda^{\alpha}\Phi_{\alpha}(y)\;\,\text{d}y.

Here, we emphasize that,
by properties of the function
H=H(x)
discussed in

[
20
, Thm. 5.2]
,
we obtain

•

U_{x}(x)<0
for
|x|\geqslant 1
;

•

U_{x}(x)\sim\frac{C}{|x|^{1+\alpha}}
when
|x|\to\infty
;

•

U_{x}(x)\sim C\left(1-|x|^{2}\right)^{-\frac{\alpha}{2}}
when
|x|\geqslant 1
and
|x|\to 1
.

Remark 1.1
.

Notice that if
\rho_{0}\in C^{1}(\mathbb{R})
is nonnegative and compactly supported, then the corresponding initial velocity
has similar properties:

(1.24)

(u_{0})_{x}(x)=\Lambda^{\alpha}\rho_{0}(x)\leqslant 0\quad\text{for all}\quad x\in\mathbb{R}\setminus{\rm supp}\,\rho_{0}

and

|\partial_{x}u_{0}(x)|\leqslant\frac{C}{|x|^{1+\alpha}}\quad\text{for all}\quad x\in\mathbb{R},

which is a direct consequence of the definition of the fractional Laplacian (

).

2.
Results and comments

Statement of the problem

We begin by writing the Euler alignment system with the strongly singular interaction kernel

(2.1)

\displaystyle\begin{aligned} \rho_{t}+(\rho u)_{x}&=0,\\
u_{t}+uu_{x}&=\int_{\mathbb{R}}\frac{1}{|y-x|^{1+\alpha}}\big(u(y,t)-u(x,t)\big)\rho(y,t)\,\text{d}y,\end{aligned}\qquad x\in\mathbb{R},\quad t>0,

using the relation

(2.2)

\displaystyle\big(u(y)-u(x)\big)\rho(y)=u(x)\big(\rho(x)-\rho(y)\big)-\big(u(x)\rho(x)-u(y)\rho(y)\big)

and the definition of the fractional Laplacian (
1.3
)
as the system

(2.3)

\displaystyle\begin{aligned} \rho_{t}+(\rho u)_{x}&=0,\\
u_{t}+u(u_{x}-\Lambda^{\alpha}\rho)+\Lambda^{\alpha}(\rho u)&=0,\end{aligned}\qquad x\in\mathbb{R},\quad t>0,

which we supplement with initial conditions

(2.4)

\displaystyle\rho(x,0)=\rho_{0}(x)\quad\text{and}\quad u(x,0)=u_{0}(x).

It is useful to study
system (
2.3
) expressed (by direct calculations) in the following formally equivalent form

(2.5)

\displaystyle\begin{aligned} \rho_{t}+(\rho u)_{x}&=0,\\
G_{t}+(Gu)_{x}&=0,\\
u_{x}-\Lambda^{\alpha}\rho&=G,\end{aligned}\qquad x\in\mathbb{R},\quad t>0,

together with initial conditions

(2.6)

\displaystyle\rho(x,0)=\rho_{0}(x)\quad\text{and}\quad G(x,0)=G_{0}(x).

Existence of solutions

Our first goal is to construct
functions

(\rho,u,G)=\big(\rho(x,t),u(x,t),G(x,t)\big)\quad\text{for all}\quad x\in\mathbb{R},\quad t\geqslant 0,

which satisfy both systems (
2.3
) and (
2.5
) in a weak sense, with
\alpha\in(0,1)
.
In fact, we can show that a weak solution of problem (
2.5
)–(
2.6
)
solves problem
(
2.3
)–(
2.4
)
in the same way as in the proof of Proposition
4.4
, below.
In the case when
the interaction kernel
\varphi(x)
is an integrable and bounded function,
the authors of
[
11
,
36
]
noticed that, these two systems are indeed equivalent which played an important role in their analysis.

We begin by definitions of weak solutions.

Definition 2.1
.

A couple
(u,\rho)
is a weak solutions to problem (
2.3
)–(
2.4
) with
initial conditions

\rho_{0}\in{L^{\infty}(\mathbb{R})}\cap{L^{1}(\mathbb{R})}
and
u_{0}\in{L^{\infty}(\mathbb{R})}

if

•

u\in L^{\infty}(\mathbb{R}\times[0,\infty))
and
\rho\in L^{q}\big([0,T],{L^{p}(\mathbb{R})}\big)
for all
p,q\in(1,\infty)
,
T>0
;

•

u\in C\big([0,T],L^{q}([-R,R])\big)
for each
T>0
,
R>0
, and
q\in\big(1/(1-\alpha),\infty\big)
;

•

u_{x}-\Lambda^{\alpha}\rho\in L^{q}\big([0,T],{L^{p}(\mathbb{R})}\big)
for all
p,q\in(1,\infty)
and each
T>0
;

•

the following equations hold true

(2.7)

\displaystyle\int_{0}^{\infty}\int_{\mathbb{R}}\rho\varphi_{t}\,\text{d}x\,\text{d}t+\int_{\mathbb{R}}\rho_{0}\varphi(\cdot,0)\,\text{d}x

\displaystyle+\int_{0}^{\infty}\int_{\mathbb{R}}\rho u\varphi_{x}\,\text{d}x\,\text{d}t=0,

\displaystyle\int_{0}^{\infty}\int_{\mathbb{R}}u\psi_{t}\,\text{d}x\,\text{d}t+\int_{\mathbb{R}}u_{0}\psi(\cdot,0)\,\text{d}x

\displaystyle-\int_{0}^{\infty}\int_{\mathbb{R}}u(u_{x}-\Lambda^{\alpha}\rho)\psi\,\text{d}x\,\text{d}t

\displaystyle-\int_{0}^{\infty}\int_{\mathbb{R}}u\rho\Lambda^{\alpha}\psi\,\text{d}x\,\text{d}t=0,

for all
\varphi,\psi\in C_{c}^{\infty}\big(\mathbb{R}\times[0,\infty)\big)
.

Definition 2.2
.

A triple
(u,\rho,G)
is a weak solution to problem (
2.5
)–(
2.6
) with initial conditions
\rho_{0},G_{0}\in{L^{\infty}(\mathbb{R})}\cap{L^{1}(\mathbb{R})}
if

•

u\in L^{\infty}(\mathbb{R}\times[0,\infty))
and
\rho,G\in L^{q}\big([0,T],{L^{p}(\mathbb{R})}\big)
for all
p,q\in(1,\infty)
,
T>0
;

•

u\in C\big([0,T],L^{q}([-R,R])\big)
for each
T>0
,
R>0
and
q\in\big(1/(1-\alpha),\infty\big)
;

•

the following equations hold true

(2.8)

\displaystyle\int_{0}^{\infty}\int_{\mathbb{R}}\rho\varphi_{t}\,\text{d}x\,\text{d}t+\int_{\mathbb{R}}\rho_{0}\varphi(\cdot,0)\,\text{d}x+\int_{0}^{\infty}\int_{\mathbb{R}}\rho u\varphi_{x}\,\text{d}x\,\text{d}t

\displaystyle=0,

\displaystyle\int_{0}^{\infty}\int_{\mathbb{R}}G\psi_{t}\,\text{d}x\,\text{d}t+\int_{\mathbb{R}}G_{0}\psi(\cdot,0)\,\text{d}x+\int_{0}^{\infty}\int_{\mathbb{R}}Gu\psi_{x}\,\text{d}x\,\text{d}t

\displaystyle=0,

\displaystyle\int_{0}^{\infty}\int_{\mathbb{R}}u\zeta_{x}\,\text{d}x\,\text{d}t+\int_{0}^{\infty}\int_{\mathbb{R}}\rho\Lambda^{\alpha}\zeta\,\text{d}x\,\text{d}t+\int_{0}^{\infty}\int_{\mathbb{R}}G\zeta\,\text{d}x\,\text{d}t

\displaystyle=0,

for all
\varphi,\psi,\zeta\in C_{c}^{\infty}\big(\mathbb{R}\times[0,\infty)\big)
.

We denote the masses of initial conditions by

(2.9)

\displaystyle M_{\rho}\equiv\int_{\mathbb{R}}{\rho_{0}}(x)\,\text{d}x\quad\text{and}\quad M_{G}\equiv\int_{\mathbb{R}}{G_{0}(x)}\,\text{d}x.

Theorem 2.3

(Existence of solutions)
.

Let
\alpha\in(0,1]
.
Assume that
u_{0}\in{L^{\infty}(\mathbb{R})}
and
\rho_{0}\in{L^{\infty}(\mathbb{R})}\cap{L^{1}(\mathbb{R})}
satisfy

G_{0}\equiv\partial_{x}u_{0}-\Lambda^{\alpha}\rho_{0}\in{L^{\infty}(\mathbb{R})}\cap{L^{1}(\mathbb{R})}
.
Suppose there exist a constant
a>0
such that

(2.10)

\displaystyle 0\leqslant G_{0}(x)\leq a\rho_{0}(x)\quad\text{a.e.~in}\quad x\in\mathbb{R}.

There exist a global-in-time weak solution
(\rho,u)
of problem (
2.3
)–(
2.4
) (cf. Def.

Lemma 3.1
.

Let
\alpha\in(0,1)
. There exists a constant
C>0
such that the inequality

(3.1)

\|\Lambda^{\alpha}f\|_{1}\leq C\left(\|f\|_{1}+\|\partial_{x}^{2}f\|_{1}\right)

holds true for all
f\in W^{2,1}(\mathbb{R})
.

Proof.

It suffices to prove the inequality

(3.2)

\|\Lambda^{\alpha}f\|_{1}\leq C\|f-\partial_{x}^{2}f\|_{1}

which is equivalent to the estimate

(3.3)

\|\Lambda^{\alpha}(I-\partial^{2}_{x})^{-1}g\|_{1}\leqslant C\|g\|_{1}

for each
g\in L^{1}(\mathbb{R})
. The operator
\Lambda^{\alpha}(I-\partial^{2}_{x})^{-1}
is a pseudo-differential operator
and, because
\alpha\in(0,1)
, its
symbol
m(\xi)

satisfies:

(3.4)

\displaystyle m(\xi)=\frac{|\xi|^{\alpha}}{1+|\xi|^{2}}\in L^{1}(\mathbb{R})\cap L^{\infty}(\mathbb{R})

and
\partial_{\xi}m\in{L^{p}(\mathbb{R})}
for each
p\in\big[1,\,1/(1-\alpha)\big)
. We show below, that
\widehat{m}\in{L^{1}(\mathbb{R})}
(notice that
\widehat{m}=\widecheck{m}
)
which will complete the proof because, by the Young inequality for convolution, we have

(3.5)

\displaystyle\|\Lambda^{\alpha}(I-\partial^{2}_{x})^{-1}g\|_{1}=\left\|(m\widehat{g})\widecheck{\,}\right\|_{1}=\left\|\widecheck{m}*g\right\|_{1}\leqslant\left\|\widecheck{m}\right\|_{1}\left\|g\right\|_{1}.

In order to show that
\left\|\widecheck{m}\right\|_{1}
is finite, we decompose

(3.6)

\displaystyle\int_{\mathbb{R}}|\widecheck{m}(x)|\,\text{d}x=\int_{|x|\leqslant 1}|\widecheck{m}(x)|\,\text{d}x+\int_{|x|>1}|\widecheck{m}(x)|\,\text{d}x.

Then

(3.7)

\displaystyle\int_{|x|\leqslant 1}|\widecheck{m}(x)|\,\text{d}x\leqslant 2\|\widecheck{m}\|_{\infty}\leqslant C\|m\|_{1}.

Next, by properties of the Fourier transform, the Hölder and Hausdorff-Young inequalities
with
p\in[1,1/(1-\alpha))
and
q=1-1/p
, we obtain

(3.8)

\displaystyle\int_{|x|>1}|\widecheck{m}(x)|\,\text{d}x

\displaystyle=\int_{|x|>1}\frac{|x\widecheck{m}(x)|}{|x|}\,\text{d}x=\int_{|x|>1}\frac{|\widecheck{(\partial_{\xi}m)}(x)|}{|x|}\,\text{d}x

\displaystyle\leqslant\left\||x|^{-1}\mathbf{1}_{|x|>1}\right\|_{p}\left\|\big(\widecheck{\partial_{\xi}m}\big)\right\|_{q}\leqslant C\left\|{\partial_{\xi}m}\right\|_{p}.

∎

Lemma 3.2
.

Let
\alpha\in(0,1)
.
For all

p\in\left(1,\ \frac{1}{1-\alpha}\right)\quad\text{and}\quad q\in(p,\infty)\quad\text{such that}\quad\frac{1}{q}=\frac{1}{p}-(1-\alpha)

there exist a constant
C=C(p,q,\alpha)>0
such that for arbitrary
f\in{L^{p}(\mathbb{R})}
we have

(3.9)

\displaystyle\|\partial^{-1}_{x}\Lambda^{\alpha}f\|_{q}\leqslant C\|f\|_{p}.

Moreover, for another constant
C>0
, we have

(3.10)

\displaystyle\|\partial^{-1}_{x}\Lambda^{\alpha}f\|_{\infty}\leqslant C\big(\|f\|_{1}+\|f\|_{\infty}\big).

Proof.

Suppose first that
f\in C_{c}^{\infty}(\mathbb{R})
and let us show that the integrand in the fractional Laplacian (
1.3
) satisfies

(3.11)

\displaystyle\frac{f(x)-f(y)}{|x-y|^{\alpha+1}}\in L^{1}(\mathbb{R}\times\mathbb{R}).

We fix
K>0
such that
f(x)=0
for
|x|>K
, hence,
the integrand in (
3.11
)
is equal to
0
for
|x|>K
and
|y|>K
.
Now, we consider the following three cases.

If
|x|\leqslant K
and
|y|\leqslant 2K
(or, analogously,
|x|\leqslant 2K
and
|y|\leqslant K
), by the mean value argument, we have

(3.12)

\displaystyle\frac{|f(x)-f(y)|}{|y-x|^{\alpha+1}}\leqslant\frac{\|f_{x}\|_{\infty}}{|y-x|^{\alpha}},

where the right hand side is integrable on the square
[-2K,2K]\times[-2K,2K]
. Indeed, by the direct calculation we have

(3.13)

\displaystyle\int_{-2K}^{2K}\int_{-2K}^{2K}\frac{1}{|x-y|^{\alpha}}\,\text{d}y\,\text{d}x

\displaystyle=2\int_{-2K}^{2K}\int_{-2K}^{x}\frac{1}{(x-y)^{\alpha}}\,\text{d}y\,\text{d}x

\displaystyle=\frac{2}{1-\alpha}\int_{-2K}^{2K}(x+2K)^{1-\alpha}\,\text{d}x=\frac{2(4K)^{2-\alpha}}{(1-\alpha)(2-\alpha)}.

Next, in the case
|x|\leqslant K
and
|y|>2K
(or, for
|y|\leqslant K
and
|x|>2K
) using the triangle inequality we obtain the estimate

(3.14)

\displaystyle\frac{|f(x)-f(y)|}{|x-y|^{\alpha+1}}\leqslant\frac{\left\|f\right\|_{\infty}}{|x-y|^{\alpha+1}}\leqslant\frac{\left\|f\right\|_{\infty}}{(|y|-|x|)^{\alpha+1}}\leqslant\frac{\left\|f\right\|_{\infty}}{(|y|-K)^{\alpha+1}}

where the last term is integrable on the strip
[-K,K]\times\big(\mathbb{R}\setminus[-2K,2K]\big)
.

Now, we write the fractional Laplacian (
1.3
) in the equivalent form

(3.15)

\displaystyle\Lambda^{\alpha}f(x)=\int_{\mathbb{R}}\frac{f(x)-f(x+y)}{|y|^{\alpha+1}}\,\text{d}y

and we introduce the primitive function
F(x)=\partial^{-1}f(x)=\int_{-\infty}^{x}f(x)\,\text{d}x
.
By the intergrability property (
3.11
) and the Fubini theorem, we conclude

(3.16)

\displaystyle\partial_{x}^{-1}\Lambda^{\alpha}f(x)=\int_{\mathbb{R}}\int_{-\infty}^{x}\frac{f(x)-f(x+y)}{|y|^{\alpha+1}}\,\text{d}x\,\text{d}y=\int_{\mathbb{R}}\frac{F(x)-F(x+y)}{|y|^{\alpha+1}}\,\text{d}y=\Lambda^{\alpha}F(x).

Now, since
\alpha-1\in(-1,0)
, we may use the Riesz potential operator
[
42
, Ch. V]
given by the formula

(3.17)

\displaystyle\Lambda^{\alpha-1}\varphi(x)=C(\alpha)\int_{\mathbb{R}}\frac{1}{|x-y|^{\alpha}}\varphi(y)\,\text{d}y

which, by properties of the Fourier transform of the fractional Laplacian, satisfies

(3.18)

\partial_{x}^{-1}\Lambda^{\alpha}f=\Lambda^{\alpha}F=\Lambda^{\alpha-1}\mathcal{H}\partial_{x}F=\Lambda^{\alpha-1}\mathcal{H}f,

where
\mathcal{H}
is the Hilbert transform,
i.e.
the pseudo-differential operator with the symbol
-i\,\text{sgn}(\xi)
, thus satisfying

\mathcal{H}\partial_{x}=\Lambda
.
The Hilbert transform is a bounded linear operator on
{L^{p}(\mathbb{R})}
for each
p\in(1,\infty)
, hence,
inequality (
3.9
) is an immediate consequence of the Hardy-Littlewood-Sobolev inequality for fractional integration

[
42
, Ch. V, Thm. 1]
.
We complete the proof of inequality (
3.2
) for arbitrary
f\in{L^{p}(\mathbb{R})}
by the usual density argument.

It follows from relation (
3.18
)
that

\widehat{(\partial_{x}^{-1}\Lambda^{\alpha}f)}(\xi)=\frac{-i\,\text{sgn}(\xi)}{|\xi|^{1-\alpha}}\widehat{f}(\xi).

Hence
\partial_{x}^{-1}\Lambda^{\alpha}f=K_{\alpha}*f
,
where
K_{\alpha}=K_{\alpha}(x)
is a locally integrable, homogeneous function of degree
-\alpha\in(-1,0)
.
Using the decomposition

K_{\alpha}=K_{\alpha}^{1}+K_{\alpha}^{2}

with

K_{\alpha}^{1}(x)=\begin{cases}K_{\alpha}(x),&|x|\leq 1,\\
0,&|x|\geq 1\end{cases}\quad\text{and}\quad K_{\alpha}^{2}=K_{\alpha}-K_{\alpha}^{1}

we prove inequality (
3.10
) immediately
by using the Hölder inequality .
∎

strongly in

.
Now, the usual diagonal argument gives a subsequence converging in
L^{q}([-R,R])
for each
R>0
.
∎

Finally, we recall two well-known inequalities involving the fractional Laplacian.

Lemma 3.7

(Stroock-Varopoulos inequality,
[
31
, Thm. 2.1]
)
.

Assume
\alpha\in(0,2)
and
p\in[1,\infty)
. The inequality

\int v^{p}\Lambda^{\alpha}v\,\text{d}x\geqslant 4\frac{p}{(p+1)^{2}}\int_{\mathbb{R}}\left(\Lambda^{\frac{\alpha}{2}}\left(v^{\frac{p+1}{2}}\right)\right)^{2}\,\text{d}x

holds true for each sufficiently regular
v=v(x)\geqslant 0
.

Lemma 3.8

(Gagiliardo–Nirenberg type inequality,
[
4
, Lemma 3.2]
)
.

Fix
r>2
and
q>1
such that
q<r<2q
. The inequality

\displaystyle\|v\|_{q}^{\theta_{1}}\leqslant C\left\|\Lambda^{\frac{\alpha}{2}}|v|^{\frac{r}{2}}\right\|_{2}^{2}\|v\|_{1}^{\theta_{2}}

holds true with

\displaystyle\theta_{1}=\frac{q}{q-1}(r-1+\alpha)\quad\text{and}\quad\theta_{2}=\theta_{1}-r=\frac{r+q(\alpha-1)}{q-1}.

Regularised system

4.1.
Existence of solutions

the

the estimates

We begin the proof of Theorems

by the following lemma, where we construct a local-in-time solution to system (

)-(
4.2
) via the Banach fixed point argument.

Lemma 4.3
.

Let
\alpha\in(0,1]
. For each
\rho_{0},G_{0}\in{L^{\infty}(\mathbb{R})}\cap{L^{1}(\mathbb{R})}
and each
\varepsilon>0
, there exist
T>0
and a unique mild solution
of the regularized problem (
4.1
)-(
4.2
)
:

(4.13)

\rho^{\varepsilon},G^{\varepsilon}\in C\big([0,T],{L^{1}(\mathbb{R})}\cap L^{p}(\mathbb{R})\big)\quad\text{for each $p\in(1,\infty)$}

and
u^{\varepsilon}\in L^{\infty}\big(\mathbb{R}\times[0,T]\big)
, satisfying weak formulation

(4.14)

\displaystyle-\int_{0}^{\infty}\int_{\mathbb{R}}\rho^{\varepsilon}\varphi_{t}\,\text{d}x\,\text{d}t-\int_{\mathbb{R}}\rho_{0}\varphi(\cdot,0)\,\text{d}x-\int_{0}^{\infty}\int_{\mathbb{R}}\rho^{\varepsilon}u^{\varepsilon}\varphi_{x}\,\text{d}x\,\text{d}t

\displaystyle=\varepsilon\int_{0}^{\infty}\int_{\mathbb{R}}\rho^{\varepsilon}\varphi_{xx}\,\text{d}x\,\text{d}t,

\displaystyle-\int_{0}^{\infty}\int_{\mathbb{R}}G^{\varepsilon}\psi_{t}\,\text{d}x\,\text{d}t-\int_{\mathbb{R}}G_{0}\psi(\cdot,0)\,\text{d}x-\int_{0}^{\infty}\int_{\mathbb{R}}G^{\varepsilon}u^{\varepsilon}\psi_{x}\,\text{d}x\,\text{d}t

\displaystyle=\varepsilon\int_{0}^{\infty}\int_{\mathbb{R}}G^{\varepsilon}\psi_{xx}\,\text{d}x\,\text{d}t,

\displaystyle-\int_{0}^{\infty}\int_{\mathbb{R}}u^{\varepsilon}\zeta_{x}\,\text{d}x\,\text{d}t-\int_{0}^{\infty}\int_{\mathbb{R}}\rho^{\varepsilon}\Lambda^{\alpha}\zeta\,\text{d}x\,\text{d}t

\displaystyle=\int_{0}^{\infty}\int_{\mathbb{R}}G^{\varepsilon}\zeta\,\text{d}x\,\text{d}t

for all
\varphi,\psi,\zeta\in C_{c}^{\infty}\big(\mathbb{R}\times[0,\infty)\big)
.
Moreover the solution has the following parabolic regularity

(4.15)

\rho^{\varepsilon},G^{\varepsilon}\in C\big((0,T],W^{2,p}(\mathbb{R})\big)\cap C^{1}\big((0,T],L^{p}(\mathbb{R})\big)

for each
p\in(1,\infty)
.

Proof.

Here, we consider a mild solution
i.e.
a solution to the following Duhamel formulation of problem (
4.1
)

(4.16)

\displaystyle\rho^{\varepsilon}(t)

\displaystyle=e^{\varepsilon t\Delta}\rho_{0}+\int_{0}^{t}\partial_{x}e^{\varepsilon(t-s)\Delta}(\rho^{\varepsilon}(s)u^{\varepsilon}(s))\,\text{d}s,

\displaystyle G^{\varepsilon}(t)

\displaystyle=e^{\varepsilon t\Delta}G_{0}+\int_{0}^{t}\partial_{x}e^{\varepsilon(t-s)\Delta}(G^{\varepsilon}(s)u^{\varepsilon}(s))\,\text{d}s,

\displaystyle u^{\varepsilon}

\displaystyle=\partial_{x}^{-1}G^{\varepsilon}+\partial_{x}^{-1}\Lambda^{\alpha}\rho^{\varepsilon}.

where the heat semigroup
e^{\varepsilon t\Delta}
is given as the convolution with the heat kernel
H(x,t)=({4\pi t)^{-{1}/{2}}}\exp\big(-|x|^{2}/(4t)\big)
.

It is the well-known
that for all
\varepsilon>0
, each
1\leq p\leq q\leq\infty
and all
v\in L^{p}(\mathbb{R})
the properties

e^{\varepsilon t\Delta}v\in C\big([0,\infty);L^{p}(\mathbb{R})\big),\qquad\|e^{\varepsilon t\Delta}v\|_{p}\leqslant\|v\|_{p}

and

\|\partial_{x}e^{\varepsilon t\Delta}v\|_{q}\leqslant C(\varepsilon t)^{\frac{1}{2}\left(\frac{1}{p}-\frac{1}{q}\right)-\frac{1}{2}}\|v\|_{p}.

hold true for all
t>0
. Moreover, by Lemma
3.2
,

\|\rho^{\varepsilon}u^{\varepsilon}\|_{s}\leqslant\|\rho^{\varepsilon}\|_{s}\|\partial_{x}^{-1}G^{\varepsilon}\|_{\infty}+\|\rho^{\varepsilon}\|_{p}\|\partial_{x}^{-1}\Lambda^{\alpha}\rho^{\varepsilon}\|_{q}\leqslant\|\rho^{\varepsilon}\|_{s}\|G^{\varepsilon}\|_{1}+C\|\rho^{\varepsilon}\|_{p}^{2}

for exponents
p,q,s\in(1,\infty)
satisfying

\frac{1}{s}=\frac{1}{p}+\frac{1}{q}\qquad\text{and}\qquad\frac{1}{q}=\frac{1}{p}-(1-\alpha).

Here, we recall also the interpolation inequality
\|v\|_{q}\leq\|v\|_{1}+\|v\|_{p}
with
1\leqslant q\leqslant p\leqslant\infty
.

Now, we consider the space

X_{T}^{p}\equiv L^{\infty}\big([0,T],{L^{1}(\mathbb{R})}\cap L^{p}(\mathbb{R})\big),

with the corresponding norm

\|v\|_{X^{p}_{T}}=\sup_{t\in[0,T]}(\left\|v(t)\right\|_{1}+\|v(t)\|_{p}).

Now, by direct calculation, we obtain the estimate

(4.17)

\displaystyle\left\|\int_{0}^{t}\partial_{x}e^{(t-s)\varepsilon\Delta}\big(\rho^{\varepsilon}(s)u^{\varepsilon}(s)\big)\,\text{d}s\right\|_{p}\leqslant

\displaystyle C(T,\varepsilon)\|\rho^{\varepsilon}\|_{X_{T}^{p}}^{2}\|G^{\varepsilon}\|_{X_{T}^{p}}^{2}\quad\text{for all}\quad t\in[0,T],

with
\lim\limits_{T\to 0}C(T,\varepsilon)=0
.
Analogously, we compute the
L^{p}
-norm of

\int_{0}^{t}\partial_{x}e^{(t-s)\varepsilon\Delta}\big(G^{\varepsilon}(s)u^{\varepsilon}(s)\big)\,\text{d}s.

It is routine to show, the operator

(4.18)

\displaystyle\mathcal{T}\begin{pmatrix}\rho\\
G\end{pmatrix}=\begin{pmatrix}e^{\varepsilon t\Delta}\rho_{0}+\int_{0}^{t}e^{\varepsilon(t-s)\Delta}(\rho^{\varepsilon}u^{\varepsilon})_{x}\,\text{d}s\\
e^{\varepsilon t\Delta}G_{0}+\int_{0}^{t}e^{\varepsilon(t-s)\Delta}(G^{\varepsilon}u^{\varepsilon})_{x}\,\text{d}s\end{pmatrix}

defines a contraction on a certain ball centered at

\left(e^{\varepsilon t\Delta}\rho_{0},e^{\varepsilon t\Delta}G_{0}\right)\in X_{T}^{p}\times X_{T}^{p}
,
for sufficiently small
T>0
. A standard proof of the uniqueness of these solutions in the space
X^{p}_{T}
is also based on these estimates and we skip it.

Similarly, it is routine to show that mild solutions are in fact weak solutions.
It follows from estimate (
3.10
) that
u^{\varepsilon}\in L^{\infty}(\mathbb{R}\times[0,T])
. Thus
the parabolic regularity of
\rho^{\varepsilon},G^{\varepsilon}
stated in (
4.15
) is classical because
these functions solve the parabolic equations in (
4.1
) supplemented with initial conditions
\rho_{0},G_{0}\in L^{p}(\mathbb{R})
.
∎

Next, we derive the equation for
u^{\varepsilon}
in the case of regularized system (
4.1
)–(
4.2
).

Proposition 4.4
.

Suppose that a triple
(u^{\varepsilon},\rho^{\varepsilon},G^{\varepsilon})
is a solution to the regularized problem (

)–(
4.2
).
Then

\big(u^{\varepsilon}_{t}+u^{\varepsilon}G^{\varepsilon}+\Lambda^{\alpha}(\rho^{\varepsilon}u^{\varepsilon})\big)_{x}=\varepsilon\big(u^{\varepsilon}_{xx}\big)_{x}

Proof.

For arbitrary
\zeta\in C^{\infty}_{c}(\mathbb{R}\times[0,\infty))
,
we choose
\varphi=\Lambda^{\alpha}\zeta
in first

). We
are allowed to do it by

Lemma 4.5
.

Let
(u^{\varepsilon},\rho^{\varepsilon},G^{\varepsilon})
be a local-in-time solution to problem (

)–(

Then

\|u^{\varepsilon}(t)\|_{\infty}\leqslant\|u_{0}\|_{\infty}\quad\text{for all}\quad t\in[0,T].

Proof.

This is more-or-less known reasoning, hence, we
present a draft of the
proof, only.
Mild solutions of the

4.1
)–(
4.2
)
depend continuously
(in the norms of the space in (

))
upon initial conditions.
Thus, approximating

\rho_{0}
and

by smooth smooth functions,
we may
assume that
\rho^{\varepsilon}
and

and, consequently, also

are as regular as

Thus, using equation (

u^{\varepsilon}

solves the initial value problem

(4.22)

\displaystyle

\displaystyle u^{\varepsilon}_{t}+u^{\varepsilon}G^{\varepsilon}+\Lambda^{\alpha}(\rho^{\varepsilon}u^{\varepsilon})=\varepsilon u^{\varepsilon}_{xx}

\displaystyle u^{\varepsilon}(x,0)=u_{0}(x)=\partial_{x}^{-1}\big(G_{0}(x)+\Lambda^{\alpha}\rho_{0}(x)\big),

where

for

and

Recall also, that

) and relation (

), first equation in (

We are going to show, following the reasoning
from
[
17
, Prop. 2]
, that
sufficiently regular solutions
of equation (

) satisfy estimate (
4.21
).

Fix
t>0
and assume

\sup\limits_{x\in\mathbb{R}}u^{\varepsilon}(x,t)>0
(the complementary inequality can be handled analogously).
Let

be
a sequence such that

\lim_{n\to\infty}u^{\varepsilon}(x_{n},t)=\sup_{x\in\mathbb{R}}u(x,t).

By
[
17

, we have

(4.24)

\lim_{n\to\infty}u^{\varepsilon}_{x}(x_{n},t)=0.

Moreover, repeating arguments
from
[
17
, Proof of Thm. 2]

we obtain

(4.25)

\liminf_{n\to\infty}u^{\varepsilon}_{xx}(x_{n},t)\leq 0

and

(4.26)

\liminf_{n\to\infty}\int_{\mathbb{R}}\frac{u^{\varepsilon}(y,t)-u^{\varepsilon}(x_{n},t)}{|x-y|^{1+\alpha}}\rho^{\varepsilon}(y,t)\,\text{d}y\leq 0.

Fix
a>0
.
For
u_{tt}
bounded on
\mathbb{R}\times[a,T]
,
for all
t\in(a,T)
and
\tau\in(a,t)
,
by the Taylor expansion,
we obtain

(4.27)

\displaystyle u(x_{n},t)

\displaystyle\leq u(x_{n},t-\tau)+\tau u_{t}(x_{n},t)+C\tau^{2}

\displaystyle\leq\sup_{x\in\mathbb{R}}u(x,t-\tau)+\tau u_{t}(x_{n},t)+C\tau^{2}.

Using equation (
4.23
) for

,
passing to

, and applying

4.24

or equivalently

It is easy to prove, that the function

The proof with “sup” replaced

\displaystyle\to\int_{0}^{\infty}\int_{\mathbb{R}}\overline{u}\varphi_{s}\,\text{d}y\,\text{d}s,

\displaystyle\int_{0}^{\infty}\int_{\mathbb{R}}u^{\lambda_{k}}\varphi_{s}\,\text{d}y\,\text{d}s

\displaystyle\to\int_{0}^{\infty}\int_{\mathbb{R}}\overline{u}\varphi_{y}\,\text{d}y\,\text{d}s.

Next, we deal with the integrals

(6.20)

\displaystyle\int_{0}^{\infty}\int_{\mathbb{R}}\rho^{\lambda_{k}}u^{\lambda_{k}}\varphi_{y}\,\text{d}y\,\text{d}s\quad\text{and}\quad\int_{0}^{\infty}\int_{\mathbb{R}}G^{\lambda_{k}}u^{\lambda_{k}}\varphi_{y}\,\text{d}y\,\text{d}s

in the analogous way, decomposing the interval with respect to
t\in[0,\delta]
and
t\in(\delta,T]
and using the weak convergence of
\varphi^{\lambda_{k}}
and
G^{\lambda_{k}}
together with the strong convergence of
u^{\lambda_{k}}
from (
6.8
).

Finally, notice that

G^{\lambda_{k}}=u_{y}^{\lambda_{k}}-{\lambda_{k}}^{-\alpha}\Lambda^{\alpha}\rho^{\lambda_{k}}.

Hence, the passage to the limit
\lambda_{k}\to\infty
in the third equation of (
6.7
) implies
G^{\lambda_{k}}\to\overline{G}=\overline{u}_{y}
weakly in
L^{r}\big([t_{1},t_{2}],{L^{p}(\mathbb{R})}\big)
.
Thus, analogously as in the case of the integrals in (
6.20
), we obtain that

(6.21)

\displaystyle\int_{0}^{\infty}\int_{\mathbb{R}}

\displaystyle u^{\lambda_{k}}\left(u^{\lambda_{k}}_{y}-\lambda^{-\alpha}\Lambda^{\alpha}\rho^{\lambda_{k}}\right)\varphi\,\text{d}y\,\text{d}s

\displaystyle=\int_{0}^{\infty}\int_{\mathbb{R}}u^{\lambda_{k}}G^{\lambda_{k}}\varphi\,\text{d}y\,\text{d}s\to\int_{0}^{\infty}\int_{\mathbb{R}}\overline{u}\overline{u}_{y}\varphi\,\text{d}y\,\text{d}s\quad\text{as}\quad\lambda_{k}\to\infty.

Summarizing, passing to the limit with
\lambda_{k}\to\infty
in formulas (
6.6
) and (
6.7
), we obtained
equations

(6.22)

\displaystyle-\int_{0}^{\infty}\int_{\mathbb{R}}\overline{\rho}\varphi_{s}\,\text{d}y\,\text{d}s-M_{\rho}\varphi(0,0)

\displaystyle-\int_{0}^{\infty}\int_{\mathbb{R}}\overline{\rho}\overline{u}\varphi_{y}\,\text{d}y\,\text{d}s=0,

\displaystyle-\int_{0}^{\infty}\int_{\mathbb{R}}\overline{u}\varphi_{s}\,\text{d}y\,\text{d}s-M_{G}\int_{0}^{\infty}\varphi(y,0)\,\text{d}y

\displaystyle-\int_{0}^{\infty}\int_{\mathbb{R}}\overline{u}\overline{u}_{y}\varphi\,\text{d}y\,\text{d}s=0,

and

(6.23)

\displaystyle-\int_{0}^{\infty}\int_{\mathbb{R}}\overline{\rho}\varphi_{s}\,\text{d}y\,\text{d}s-M_{\rho}\varphi(0,0)-\int_{0}^{\infty}\int_{\mathbb{R}}\overline{\rho}\overline{u}\varphi_{y}\,\text{d}y\,\text{d}s

\displaystyle=0,

\displaystyle-\int_{0}^{\infty}\int_{\mathbb{R}}\overline{G}\varphi_{s}\,\text{d}y\,\text{d}s-M_{G}\varphi(0,0)-\int_{0}^{\infty}\int_{\mathbb{R}}\overline{G}\overline{u}\varphi_{y}\,\text{d}y\,\text{d}s

\displaystyle=0,

\displaystyle-\int_{0}^{\infty}\int_{\mathbb{R}}\overline{u}\varphi_{y}\,\text{d}y\,\text{d}s-\int_{0}^{\infty}\int_{\mathbb{R}}\overline{G}\varphi\,\text{d}y\,\text{d}s

\displaystyle=0

for each
\varphi\in C_{c}^{\infty}\big(\mathbb{R}\times[0,\infty)\big)
.
Notice that these are the weak formulations of the systems

(6.24)

\displaystyle\overline{\rho}_{s}+(\overline{u}\overline{\rho})_{y}

\displaystyle=0,

\displaystyle\overline{u}_{s}+\overline{u}\overline{u}_{y}

\displaystyle=0,

and

(6.25)

\displaystyle\overline{\rho}_{s}+\left(\overline{u}\overline{\rho}\right)_{y}

\displaystyle=0,

\displaystyle\overline{G}_{s}+\left(\overline{u}\overline{G}\right)_{y}

\displaystyle=0,

\displaystyle\overline{u}_{y}

\displaystyle=\overline{G}.

with the initial conditions

(6.26)

\displaystyle\overline{\rho}(y,0)=M_{\rho}\delta_{0},\qquad\overline{G}(y,0)=M_{G}\delta_{0},\qquad\overline{u}(y,0)=\begin{cases}0,&y\leqslant 0,\\
M_{G},&y>0,\end{cases}

where
\delta_{0}
denoted the usual Dirac measure. Below, we will find an explicit unique solutions of these initial value problems.

Indeed, note that
\overline{u}\in L^{\infty}\big(\mathbb{R}\times(0,\infty)\big)
and
\overline{u}_{y}=\overline{G}\in L^{r}\big([t_{1},t_{2}],{L^{p}(\mathbb{R})}\big)
.
Hence, by
[
6
, Cor. 8.10]
, function
\overline{u}^{2}\in L^{r}\big([t_{1},t_{2}],W^{1,p}(\Omega)\big)
and, moreover, for each
\varphi\in C_{c}^{\infty}

(6.27)

\displaystyle\int_{0}^{\infty}\int_{\mathbb{R}}\overline{u}\overline{u}_{y}\varphi\,\text{d}y\,\text{d}s=-\int_{0}^{\infty}\int_{\mathbb{R}}\frac{\overline{u}^{2}}{2}\varphi_{y}\,\text{d}y\,\text{d}s.

Thus, the second equation in (
6.22
) means
\overline{u}\in L^{\infty}(\mathbb{R}\times[0,\infty))
is a weak solution of the initial value problem for the iniviscid Burgers equation

(6.28)

\displaystyle\overline{u}_{s}+\frac{(\overline{u}^{2})_{y}}{2}

\displaystyle=0,\qquad\overline{u}_{0}(y)=\begin{cases}0,&y\leqslant 0,\\
M_{G},&y>0\end{cases}

with
M_{G}=\int_{\mathbb{R}}G_{0}(x)\,\text{d}x>0
.
By the estimate of
G
in (
2.6
) with
p=\infty
, we obtain
\left\|{G}(\cdot,t)\right\|_{\infty}\leqslant Ct^{-1}
for all
t>0
and this estimate is preserved by the rescaling (Lemma

) as well as it is kept after passing to the week limit in (

).
Since,
\overline{G}=\overline{u}_{y}
, we obtain the Oleinik condition

(6.29)

\displaystyle\left\|\overline{u}_{y}(\cdot,s)\right\|_{\infty}=\left\|\overline{G}(\cdot,s)\right\|_{\infty}\leqslant Cs^{-1}\quad\text{for all}\quad s>0,

which implies (see
e.g.

[
18
, Ch. 3.4.4]
) that the function
\overline{u}
is a unique entropy solution of problem (
6.28
) given by the explicit formula

(6.30)

\displaystyle\overline{u}(y,s)=\begin{cases}0,&y\leqslant 0,\\
\frac{y}{s},&0<y\leqslant M_{G}s,\\
M_{G},&y>M_{G}s,\end{cases}

which is called as a
rarefaction wave
.

Using the relation
\overline{G}=\overline{u}_{y}
, we calculate

(6.31)

\displaystyle\overline{G}(y,s)=\begin{cases}0,&y\leqslant 0,\\
\frac{1}{s},&0<y\leqslant M_{G}s,\\
0,&y>M_{G}s.\end{cases}

Note that, for
M_{\rho}=M_{G}
, we obtain
\rho(x,t)=G(x,t)
for almost all
(x,t)\in\mathbb{R}\times[0,\infty)
because
both functions satisfy the same linear initial value problems: equations (

) supplemented with initial conditions (
6.26
) and with

\overline{u}
given by formula (
6.30
).
For arbitrary
M_{\rho}>0
and
M_{G}>0
, since the equations are linear, we put

(6.32)

\displaystyle\overline{\rho}(y,s)=\frac{M_{\rho}}{M_{G}}\overline{G}(y,s)=\frac{M_{\rho}}{M_{G}}\begin{cases}0,&y\leqslant 0,\\
\frac{1}{s},&0<y\leqslant M_{G}s,\\
0,&y>M_{G}s.\end{cases}
