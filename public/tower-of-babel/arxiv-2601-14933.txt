Rank-one Riemannian Subspace Descent for Nonlinear Matrix Equations
Yogesh Darmwal, Ketan Rajawat

Abstract
We propose a rank-one Riemannian subspace descent algorithm for computing symmetric positive definite (SPD) solutions to nonlinear matrix equations arising in control theory, dynamic programming, and stochastic filtering. For solution matrices of size n × n n\times n , standard approaches for dense matrix equations typically incur 𝒪 ⁡ ( n 3 ) {\mathcal{O}}(n^{3}) cost per-iteration, while the efficient 𝒪 ⁡ ( n 2 ) {\mathcal{O}}(n^{2}) methods either rely on sparsity or low-rank solutions, or have iteration counts that scale poorly. The proposed method entails updating along the dominant eigen-component of a transformed Riemannian gradient, identified using at most 𝒪 ⁡ ( log ⁡ ( n ) ) {\mathcal{O}}(\log(n)) power iterations. The update structure also enables exact step-size selection in many cases at minimal additional cost. For objectives defined as compositions of standard matrix operations, each iteration can be implemented using only matrix–vector products, yielding 𝒪 ⁡ ( n 2 ) {\mathcal{O}}(n^{2}) arithmetic cost. We prove an 𝒪 ⁡ ( n ) {\mathcal{O}}(n) iteration bound under standard smoothness assumptions, with improved bounds under geodesic strong convexity. Numerical experiments on large-scale CARE, DARE, and other nonlinear matrix equations show that the proposed algorithm solves instances (up to n = 10,000 n=10{,}000 in our tests) for which the compared solvers, including MATLAB’s icare , structure-preserving doubling, and subspace-descent baselines fail to return a solution. These results demonstrate that rank-one manifold updates provide a practical approach for high-dimensional and dense SPD-constrained matrix equations. MATLAB code implementation is publicly available on GitHub : https://github.com/yogeshd-iitk/nonlinear_matrix _equation_R1RSD

III
Riemannian subspace descent algorithm

In this section, we describe the proposed Riemannian subspace descent algorithm and show how it supports greedy direction selection while keeping the per-iteration cost to
{\mathcal{O}}(n^{2})
flops. Different from the classical RGD in (
7
), subspace descent algorithms update the iterate along a low-dimensional subspace, e.g., along one or a few coordinates, rather than moving along the full Riemannian gradient, thereby reducing the computational burden at each iteration. In the present case, we express the (transformed) Riemannian gradient as a sum of rank-one eigen-components and then update the iterate using only one selected component at each step. This decomposition allows us to identify the most promising descent component at low computational cost and efficiently maintain
{\mathbf{X}}_{t}
,
{\mathbf{X}}_{t}^{-1}
, and the Cholesky factor
{\mathbf{B}}_{t}={\mathcal{L}}({\mathbf{X}}_{t})
via rank-one updates. We remark that the proposed approach of selecting a direction from a structured set of candidate directions differs from the subspace/coordinate descent schemes in
[
47
,
48
,
49
,
50
]
which typically fix a basis for
T_{\mathbf{X}}{\mathbb{P}^{n}}
and then choose the update direction by projecting the Riemannian gradient onto the resulting subspace. The method is, however, closely related to
[
51
]
, and we discuss this connection at the end of the section.

III-A

Subspace selection

The subspace selection is motivated by the Spectral theorem: any symmetric matrix
{\mathbf{G}}
admits an orthogonal eigen-decomposition
{\mathbf{G}}=\sum_{i=1}^{n}\lambda^{(i)}{\mathbf{u}}^{(i)}({\mathbf{u}}^{(i)})^{\mathsf{T}}
. In other words,
{\mathbf{G}}
can be expressed as a sum of
n
rank-one terms
{\mathbf{u}}^{(i)}({\mathbf{u}}^{(i)})^{\mathsf{T}}
that are orthogonal in the Euclidean inner product, i.e.,
\mathrm{tr}\left({\mathbf{u}}^{(i)}({\mathbf{u}}^{(i)})^{\mathsf{T}}{\mathbf{u}}^{(j)}({\mathbf{u}}^{(j)})^{\mathsf{T}}\right)=0
for
i\neq j
and 1 for
i=j
. These properties suggest that eigen-decomposition can be used to obtain subspaces along which an iterate may be updated. Specifically, we consider the eigen-decomposition of the transformed Riemannian gradient
{\mathcal{C}}_{{\mathbf{X}}_{t}}({\text{grad}}^{R}\;f({\mathbf{X}}_{t}))
, which appears within the exponential in (
7
):

\displaystyle{\mathcal{C}}_{{\mathbf{X}}_{t}}({\text{grad}}^{R}f({\mathbf{X}}_{t}))

\displaystyle\stackrel{{\scriptstyle\text{\eqref{RiemanEuclideangrad}}}}{{=}}{\mathbf{B}}_{t}^{\mathsf{T}}{\text{grad}}f({\mathbf{X}}_{t}){\mathbf{B}}_{t}=\sum_{i=1}^{n}\lambda_{t}^{(i)}{\mathbf{x}}_{t}^{(i)}({\mathbf{x}}_{t}^{(i)})^{\mathsf{T}}

where
(\lambda_{t}^{(i)},{\mathbf{x}}_{t}^{(i)})
is an eigenpair. This eigen-decomposition induces the following Riemannian orthogonal decomposition of
{\text{grad}}^{R}f({\mathbf{X}}_{t})
:

\displaystyle{\text{grad}}^{R}f({\mathbf{X}}_{t})=\sum_{i=1}^{n}\lambda_{t}^{(i)}{\mathbf{H}}_{t}^{(i)}

(8)

where the rank-one tangent directions
{\mathbf{H}}_{t}^{(i)}:={\mathbf{B}}_{t}{\mathbf{x}}_{t}^{(i)}({\mathbf{x}}_{t}^{(i)})^{\mathsf{T}}{\mathbf{B}}_{t}^{\mathsf{T}}
are orthonormal with respect to the affine-invariant metric (
2

\displaystyle\langle{\mathbf{H}}_{t}^{(i)},

\displaystyle{\mathbf{H}}_{t}^{(j)}\rangle_{{\mathbf{X}}_{t}}=\mathrm{tr}\left({\mathcal{C}}_{{\mathbf{X}}_{t}}({\mathbf{H}}_{t}^{(i)}){\mathcal{C}}_{{\mathbf{X}}_{t}}({\mathbf{H}}_{t}^{(j)})\right)

\displaystyle=\mathrm{tr}\left({\mathbf{x}}_{t}^{(i)}({\mathbf{x}}_{t}^{(i)})^{\mathsf{T}}{\mathbf{x}}_{t}^{(j)}({\mathbf{x}}_{t}^{(j)})^{\mathsf{T}}\right)=(({\mathbf{x}}_{t}^{(i)})^{\mathsf{T}}{\mathbf{x}}_{t}^{(j)})^{2}

(9)

which is one for

and zero otherwise. Consequently, if
{\text{grad}}^{R}f({\mathbf{X}}_{t})\neq{\mathbf{0}}

-\lambda_{t}^{(i)}{\mathbf{H}}_{t}^{(i)}

\displaystyle Df_{{\mathbf{X}}_{t}}(-\lambda_{t}^{(i)}{\mathbf{H}}_{t}^{(i)})

\displaystyle=-\langle\sum_{j=1}^{n}\lambda_{t}^{(j)}{\mathbf{H}}_{t}^{(j)},\lambda_{t}^{(i)}{\mathbf{H}}_{t}^{(i)}\rangle_{{\mathbf{X}}_{t}}

\displaystyle=-(\lambda_{t}^{(i)})^{2}<0.

Indeed, since the magnitude of the directional derivative is exactly
(\lambda_{t}^{(i)})^{2}

(\lambda_{t}^{(1)},{\mathbf{x}}_{t}^{(1)})
denotes the dominant eigenvalue-eigenvector pair, then the proposed greedy subspace descent update can be written as

\displaystyle{\mathbf{X}}_{t+1}={\mathbf{B}}_{t}\exp\left(-\beta_{t}\lambda_{t}^{(1)}{\mathbf{x}}_{t}^{(1)}({\mathbf{x}}_{t}^{(1)})^{\mathsf{T}}\right){\mathbf{B}}_{t}^{\mathsf{T}}

(10)

where
\beta_{t}>0

III-B

Efficient Updates

In the current form, naive implementation of the update in (
10
) is still challenging as it seems to involve several operations whose complexity is generally
{\mathcal{O}}(n^{3})
: matrix exponential, Cholesky factorization, eigenvalue decomposition, and dense matrix multiplications. Even with
{\mathbf{X}}_{t}
and its Cholesky factor
{\mathbf{B}}_{t}
available, forming the transformed Riemannian gradient
{\mathbf{B}}_{t}^{\mathsf{T}}{\text{grad}}f({\mathbf{X}}_{t}){\mathbf{B}}_{t}
is not generally possible in
{\mathcal{O}}(n^{2})

10

{\mathcal{O}}(n^{2})

The key observation in (
10

[

:

\displaystyle{\mathbf{X}}_{t+1}

\displaystyle={\mathbf{X}}_{t}+\left[\exp(-\lambda_{t}^{(1)}\beta_{t})-1\right]{\mathbf{B}}_{t}{\mathbf{x}}_{t}^{(1)}({\mathbf{x}}_{t}^{(1)})^{\mathsf{T}}{\mathbf{B}}_{t}^{\mathsf{T}}

(11)

which, given
{\mathbf{B}}_{t}
and
{\mathbf{x}}_{t}
, requires only
O(n^{2})
flops. Next, the rank-one modification in (
11
) allows the Cholesky factor to be updated efficiently. In particular,
{\mathbf{B}}_{t+1}
can be obtained from
{\mathbf{B}}_{t}
using only
O(n^{2})
flops via a standard rank-one Cholesky update procedure
[
94
, Sec. 3]
, also available as MATLAB function
cholupdate
.

Calculation of the dominant eigenvalue-eigenvector pair is accomplished using the power method
[
95
]
. Starting with an random unit norm
{\mathbf{y}}_{t}^{(0)}\in{\mathbb{R}}^{n}
, the power iterations take the form:

\displaystyle{\mathbf{y}}_{t}^{(i)}=\frac{{\mathbf{B}}_{t}^{{\mathsf{T}}}{\text{grad}}f({\mathbf{X}}_{t}){\mathbf{B}}_{t}{\mathbf{y}}_{t}^{(i-1)}}{\|{\mathbf{B}}_{t}^{{\mathsf{T}}}{\text{grad}}f({\mathbf{X}}_{t}){\mathbf{B}}_{t}{\mathbf{y}}_{t}^{(i-1)}\|_{2}}

(12)

for
i=1,2,\ldots
. We terminate the method after
r
iterations and use
{\mathbf{y}}_{t}={\mathbf{y}}_{t}^{(r)}
as an approximation of
{\mathbf{x}}_{t}
in (
11
). The corresponding approximate eigenvalue can be calculated using the Rayleigh quotient as
\lambda_{t}={\mathbf{y}}_{t}^{\mathsf{T}}{\mathbf{B}}_{t}^{\mathsf{T}}{\text{grad}}f({\mathbf{X}}_{t}){\mathbf{B}}_{t}{\mathbf{y}}_{t}
. Hence, the approximate descent direction becomes

\displaystyle{\bm{\xi}}_{{\mathbf{X}}_{t}{\mathbf{X}}_{t+1}}=-\beta_{t}\lambda_{t}{\mathbf{B}}_{t}{\mathbf{y}}_{t}{\mathbf{y}}_{t}^{\mathsf{T}}{\mathbf{B}}_{t}^{\mathsf{T}}

(13)

Here, observe that if we can apply
{\text{grad}}f({\mathbf{X}}_{t})
to a vector in
{\mathcal{O}}(n^{2})
flops, each power iteration can be implemented using only three
{\mathcal{O}}(n^{2})
operations: namely
{\mathbf{v}}_{t}^{(i)}={\mathbf{B}}_{t}{\mathbf{y}}_{t}^{(i)}
,
{\mathbf{w}}_{t}^{(i)}={\text{grad}}f({\mathbf{X}}_{t}){\mathbf{v}}_{t}^{(i)}
, and
\tilde{{\mathbf{y}}}_{t}^{(i)}={\mathbf{B}}_{t}^{\mathsf{T}}{\mathbf{w}}_{t}^{(i)}
, followed by normalization. Hence, the overall per-iteration complexity of the proposed algorithm is
{\mathcal{O}}(rn^{2})
. The pseudo-code of the complete algorithm is summarized in Alg.
1
.

III-C

Calculation of
{\text{grad}}\;f({\mathbf{X}}_{t}){\mathbf{v}}_{t}^{(i)}

In this section, we specify the class of functions
{\mathcal{F}}
for which the gradient-vector product
{\text{grad}}\;f({\mathbf{X}}_{t}){\mathbf{v}}_{t}^{(i)}
can be computed in
{\mathcal{O}}(n^{2})
time for any SPD iterate
{\mathbf{X}}_{t}
and vector
{\mathbf{v}}_{t}^{(i)}
. We will maintain intermediate variables and matrix-vector products so as to avoid matrix-matrix multiplications required to explicitly form
{\text{grad}}f({\mathbf{X}}_{t})
. The key is to restrict
f
to compositions of basic matrix operations that (a) preserve symmetry and positive definiteness where required, and (b) admit efficient low-rank updates and matrix-vector application.

To this end, we represent
f
using a composition of several elementary layers. Specifically, we start with some tuple containing
{\mathbf{X}}
and constant matrices
{\mathbf{A}}
,
{\mathbf{B}}
,
{\mathbf{C}}
, etc.:

\displaystyle{\mathbf{M}}^{(0)}({\mathbf{X}}):=({\mathbf{X}},{\mathbf{A}},{\mathbf{B}},{\mathbf{C}},\ldots)

(14)

and apply
m
compositional operations of the form

\displaystyle{\mathbf{M}}^{(\ell)}({\mathbf{X}})

\displaystyle={\mathcal{T}}^{(\ell)}({\mathbf{M}}^{(\ell-1)}({\mathbf{X}})),

\displaystyle\ell=1,\ldots,m.

(15)

Here, the operation
{\mathcal{T}}^{(\ell)}
takes
{\mathbf{M}}^{(\ell-1)}({\mathbf{X}})
as input and produces an output tuple
{\mathbf{M}}^{(\ell)}({\mathbf{X}})
, whose elements can be obtained by copying, transposing, adding, multiplying, or inverting elements of the input tuple. Specifically, the
j
-th element of
{\mathbf{M}}^{(\ell)}({\mathbf{X}})
is given by one of the following operations (
i
and
k
are indices of the elements of
{\mathbf{M}}^{(\ell-1)}({\mathbf{X}})
):

•

Scaling:
{\mathbf{M}}_{j}^{(\ell)}=c{\mathbf{M}}_{i}^{(\ell-1)}
;

•

Scaling and Transpose:
{\mathbf{M}}_{j}^{(\ell)}=c({\mathbf{M}}_{i}^{(\ell-1)})^{{\mathsf{T}}}
;

•

Sum:
{\mathbf{M}}_{j}^{(\ell)}=\sum_{i}c_{i}{\mathbf{M}}_{i}^{(\ell-1)}({\mathbf{X}})
;

•

Product:
{\mathbf{M}}_{j}^{(\ell)}=c_{j}\prod_{q}{\mathbf{M}}_{i_{q}}^{(\ell-1)}({\mathbf{X}})
where
i_{q}
are indices of the elements of
{\mathbf{M}}^{(\ell-1)}({\mathbf{X}})
; and

•

Inverse:
{\mathbf{M}}_{j}^{(\ell)}=({\mathbf{M}}_{i}^{(\ell-1)})^{-1}
where
{\mathbf{M}}_{i}^{(\ell-1)}\succ{\mathbf{0}}
;

Finally, we apply scalar functions to the
J
components of
{\mathbf{M}}^{(m)}({\mathbf{X}})
, so as to form

\displaystyle f({\mathbf{X}})=\sum_{j=1}^{J}f_{j}({\mathbf{M}}_{j}^{(m)}({\mathbf{X}}))

(16)

where
f_{j}
is one of the following functions (a) trace, (b) squared Frobenius norm, or (c) log-det if
{\mathbf{M}}_{j}^{(m)}({\mathbf{X}})\succ{\mathbf{0}}
. As a simple example, consider the NME
f({\mathbf{X}})=\left\|{\mathbf{R}}({\mathbf{X}})\right\|_{F}^{2}
where
{\mathbf{R}}({\mathbf{X}})={\mathbf{X}}+{\mathbf{A}}^{\mathsf{T}}{\mathbf{X}}^{-1}{\mathbf{A}}-{\mathbf{Q}}
, for which the different layers are given by:

\displaystyle{\mathbf{M}}^{(0)}({\mathbf{X}})

\displaystyle=({\mathbf{X}},{\mathbf{A}},{\mathbf{Q}})

(17)

\displaystyle{\mathbf{M}}^{(1)}({\mathbf{X}})

\displaystyle=({\mathbf{X}},{\mathbf{A}}^{\mathsf{T}},{\mathbf{X}}^{-1},{\mathbf{A}},-{\mathbf{Q}})

(18)

\displaystyle{\mathbf{M}}^{(2)}({\mathbf{X}})

\displaystyle=({\mathbf{X}},{\mathbf{A}}^{\mathsf{T}}{\mathbf{X}}^{-1}{\mathbf{A}},-{\mathbf{Q}})

(19)

\displaystyle{\mathbf{M}}^{(3)}({\mathbf{X}})

\displaystyle=({\mathbf{X}}+{\mathbf{A}}^{\mathsf{T}}{\mathbf{X}}^{-1}{\mathbf{A}}-{\mathbf{Q}})

(20)

\displaystyle f({\mathbf{M}}^{(3)}({\mathbf{X}}))

\displaystyle=\|{\mathbf{M}}^{(3)}({\mathbf{X}})\|_{F}^{2}.

(21)

Given the compositional form, we can find the gradient of
f
with respect to
{\mathbf{X}}
using chain rule to each layer, and write the full gradient as sum of
\tilde{J}
terms:

\displaystyle{\text{grad}}f({\mathbf{X}})

\displaystyle=\sum_{j=1}^{\tilde{J}}\tilde{{\mathbf{M}}}_{j}^{(\tilde{m})}({\mathbf{X}})

(22)

\displaystyle\tilde{{\mathbf{M}}}^{(\tilde{m})}({\mathbf{X}})

\displaystyle=\tilde{{\mathcal{T}}}^{(\tilde{m})}(\tilde{{\mathcal{T}}}^{(\tilde{m}-1)}(\ldots\tilde{{\mathcal{T}}}^{(0)}({\mathbf{M}}^{(0)}({\mathbf{X}}))))

(23)

so that the gradient graph has layers
\tilde{{\mathbf{M}}}^{1},\ldots,\tilde{{\mathbf{M}}}^{(\tilde{m})}
, and the components of the last layer are summands of
{\text{grad}}f({\mathbf{X}})
. We note that each layer in the gradient function is also formed using the same primitive operations, namely sum, product, transpose, and inverse. Hence, we obtain the product as

\displaystyle{\text{grad}}f({\mathbf{X}}){\mathbf{v}}=\sum_{j=1}^{\tilde{J}}\tilde{{\mathbf{M}}}_{j}^{(\tilde{m})}({\mathbf{X}}){\mathbf{v}}

(24)

where each term is evaluated using only matrix-vector products and application of inverses, if needed, that must be separately maintained using low-rank updates. For the NME example earlier, we have that

\displaystyle{\text{grad}}f({\mathbf{X}})=2{\mathbf{R}}({\mathbf{X}})-2{\mathbf{X}}^{-1}{\mathbf{A}}{\mathbf{R}}({\mathbf{X}}){\mathbf{A}}^{\mathsf{T}}{\mathbf{X}}^{-1}

(25)

for which the different layers are given by:

\displaystyle\tilde{{\mathbf{M}}}^{(1)}({\mathbf{X}})

\displaystyle=({\mathbf{X}},{\mathbf{A}}^{\mathsf{T}},{\mathbf{X}}^{-1},{\mathbf{A}},-{\mathbf{Q}})

(26)

\displaystyle\tilde{{\mathbf{M}}}^{(2)}({\mathbf{X}})

\displaystyle=({\mathbf{X}},{\mathbf{A}}^{\mathsf{T}}{\mathbf{X}}^{-1}{\mathbf{A}},-{\mathbf{Q}},{\mathbf{X}}^{-1}{\mathbf{A}},{\mathbf{A}}^{\mathsf{T}}{\mathbf{X}}^{-1})

(27)

\displaystyle\tilde{{\mathbf{M}}}^{(3)}({\mathbf{X}})

\displaystyle=({\mathbf{R}}({\mathbf{X}}),{\mathbf{X}}^{-1}{\mathbf{A}},{\mathbf{A}}^{\mathsf{T}}{\mathbf{X}}^{-1})

(28)

\displaystyle\tilde{{\mathbf{M}}}^{(4)}({\mathbf{X}})

\displaystyle=(2{\mathbf{R}}({\mathbf{X}}),-2{\mathbf{X}}^{-1}{\mathbf{A}}{\mathbf{R}}({\mathbf{X}}){\mathbf{A}}^{\mathsf{T}}{\mathbf{X}}^{-1})

(29)

As there is only one inverse operator, we only need to maintain:

\displaystyle{\mathbf{X}}_{t+1}^{-1}

\displaystyle={\mathbf{X}}_{t}^{-1}+\left[\exp\!\left(\lambda_{t}^{(1)}\beta_{t}\right)-1\right]{\mathbf{B}}_{t}^{-{\mathsf{T}}}{\mathbf{x}}_{t}^{(1)}\big({\mathbf{x}}_{t}^{(1)}\big)^{\mathsf{T}}{\mathbf{B}}_{t}^{-1}

(30)

for each iteration, which incurs
{\mathcal{O}}(n^{2})
cost. Once
{\mathbf{X}}_{t+1}^{-1}
is available, the gradient-vector product can be calculated using matrix-vector products alone, and without needing any other
{\mathcal{O}}(n^{3})
operations, as shown in Appendix
B
.

More generally, inverse nodes are the sole source of potential
{\mathcal{O}}(n^{3})
cost. By maintaining the outputs of all inverse nodes, via low-rank updates, every term
\tilde{{\mathbf{M}}}_{j}^{(\tilde{m})}({\mathbf{X}}){\mathbf{v}}
can be evaluated using only matrix–vector products, yielding an overall
{\mathcal{O}}(n^{2})
gradient–vector product.

To summarize, for any
f\in{\mathcal{F}}
specified by the primitive-layer construction above, the gradient admits a compositional structure built from the same primitives. The product
\nabla f({\mathbf{X}}_{t}){\mathbf{v}}_{t}^{(i)}
is obtained by evaluating the gradient graph in a matrix–vector fashion, i.e., by applying each terminal summand
\tilde{{\mathbf{M}}}_{j}^{(\tilde{m})}({\mathbf{X}}_{t})
to
{\mathbf{v}}_{t}^{(i)}
and summing the results. Outputs of inverse nodes are maintained across iterations via low-rank updates and the full gradient-vector product is calculated in
{\mathcal{O}}(n^{2})
time.

IV
Performance Analysis

In this section, we analyze the performance of the proposed algorithm under certain regularity conditions on the objective function
f
. To this end, we will characterize the iteration complexity of Alg.
1
, which is the number of iterations required to ensure that
{\mathbf{X}}_{t}
is
\epsilon
-stationary on average. Compared to the analysis of RGD and subspace descent variants in the literature, the key complication here is that the random initialization required by the power method makes the subsequent steps as well as the overall behavior of the algorithm random. Hence, the performance analysis must involve expectations. We use
\mathbb{E}_{t}[\cdot]
to denote the expectation with respect to
{\mathbf{u}}_{t}
(cf. Step 3 in Alg.
1
) and
{\mathbb{E}}[\cdot]
to denote full expectation. We begin with stating the key assumptions, which are standard in the RGD and power method literature.

A1
.

The function
f:{\mathbb{P}^{n}}\rightarrow{\mathbb{R}}
is geodesically
\mu
-strongly convex, i.e., for any two arbitrary points
{\mathbf{X}}
,
{\mathbf{Y}}\in{\mathbb{P}^{n}}
, and connecting geodesic starting at
{\mathbf{X}}
with
\gamma^{\prime}(0)={\bm{\xi}}_{{\mathbf{X}}{\mathbf{Y}}}
, it holds that (
[
96
]
):

\displaystyle f({\mathbf{Y}})

\displaystyle\geq f({\mathbf{X}})+\langle{\text{grad}}^{R}f({\mathbf{X}}),{\bm{\xi}}_{{\mathbf{X}}{\mathbf{Y}}}\rangle_{{\mathbf{X}}}+\frac{\mu}{2}\|{\bm{\xi}}_{{\mathbf{X}}{\mathbf{Y}}}\|_{{\mathbf{X}}}^{2}.

(31)

A2
.

The function
f:{\mathbb{P}^{n}}\rightarrow\mathbb{R}
is geodesically
L
-smooth, i.e., for any two arbitrary points
{\mathbf{X}}
,
{\mathbf{Y}}\in{\mathbb{P}^{n}}
, and connecting geodesic starting at
{\mathbf{X}}
with
\gamma^{\prime}(0)={\bm{\xi}}_{{\mathbf{X}}{\mathbf{Y}}}
, it holds that (
[
96
]
):

\displaystyle f({\mathbf{Y}})\leq f({\mathbf{X}})+\langle{\text{grad}}^{R}f({\mathbf{X}}),{\bm{\xi}}_{{\mathbf{X}}{\mathbf{Y}}}\rangle_{{\mathbf{X}}}+\frac{L}{2}\|{\bm{\xi}}_{{\mathbf{X}}{\mathbf{Y}}}\|_{{\mathbf{X}}}^{2}.

(32)

Of these, the geodesic smoothness assumption is quite standard and applies to all the examples discussed so far. On the other hand, the geodesic strong convexity assumption is stronger. It clearly holds for the residual norm in the case of the Lyapunov function, but is difficult to verify for the other equations in Sec.
I
. The bounds will also depend on the initialization through
D_{0}:=f({\mathbf{X}}_{0})
. For the sake of convenience, the transformed gradient is denoted as

\displaystyle{\mathbf{P}}({\mathbf{X}}):={\mathcal{L}}({\mathbf{X}})^{\mathsf{T}}{\text{grad}}f({\mathbf{X}}){\mathcal{L}}({\mathbf{X}})

(33)

for any
{\mathbf{X}}\in{\mathbb{P}^{n}}
, so that
{\mathbf{P}}({\mathbf{X}}_{t})={\mathbf{B}}_{t}^{\mathsf{T}}{\text{grad}}f({\mathbf{X}}_{t}){\mathbf{B}}_{t}
. The final assumption is standard for analyzing the power method.

A3
.

The spectral gap of
{\mathbf{P}}({\mathbf{X}})
is non-trivial for all
{\mathbf{X}}
, i.e.,
\frac{\lvert\lambda^{(2)}({\mathbf{X}})\rvert}{\lvert\lambda^{(1)}({\mathbf{X}})\rvert}\leq\rho<1
for some
\rho
and all
{\mathbf{X}}\in{\mathbb{P}^{n}}
, where the eigenvalues of
{\mathbf{P}}({\mathbf{X}})
arranged such that
\lambda^{(1)}({\mathbf{X}})>\ldots\geq\lambda^{(n)}({\mathbf{X}})
.

We remark the gap-free analysis of power method is also possible but requires stronger assumption of positive semi-definiteness of
{\mathbf{P}}({\mathbf{X}})

[
97
, Sec. 6]
, which is unlikely to hold for all
{\mathbf{X}}
in the current setting. Hence, we resort to gap-dependent analysis, though Assumption
A3
may be difficult to verify in practice. Before establishing the required results, we state the following preliminary lemma that lower bounds the approximate Rayleight quotient
\lambda_{t}^{2}
obtained in Step 8 of Alg.
1
.

Lemma 1
.

Under Assumption
A3
for
{\mathbf{P}}_{t}={\mathbf{P}}({\mathbf{X}}_{t})
, after
r\geq\frac{1}{2}\log_{\frac{1}{\rho}}(8n)
iterations of the power method, it holds that

\displaystyle\mathbb{E}_{t}[\lambda_{t}^{2}]

\displaystyle\geq\frac{1}{48}(\lambda_{t}^{(1)})^{2}.

(34)

Proof:

Writing
{\mathbf{y}}_{t}^{(0)}=\sum_{i}c_{i}{\mathbf{x}}_{t}^{(i)}
for some coordinates
c_{i}
, we have that
[
98
, Thm. 8.3.1]
:

\displaystyle\lvert\lambda_{t}-\lambda_{t}^{(1)}\rvert\leq\max_{2\leq i\leq n}\lvert\lambda_{t}^{(1)}-\lambda_{t}^{(i)}\rvert\rho^{2r}\tan^{2}(\theta_{0})

(35)

where
\tan^{2}(\theta_{0})=\frac{1-c_{1}^{2}}{c_{1}^{2}}
. Since
\lvert\lambda_{t}^{(1)}-\lambda_{t}^{(i)}\rvert\leq 2\lvert\lambda_{t}^{(1)}\rvert
, we have

\displaystyle\lvert\lambda_{t}\rvert\geq\lvert\lambda_{t}^{(1)}\rvert-\lvert\lambda_{t}-\lambda_{t}^{(1)}\rvert\geq\lvert\lambda_{t}^{(1)}\rvert\left[1-2\tan^{2}(\theta_{0})\rho^{2r}\right]

(36)

which is vacuous if the right-hand side is non-positive. To convert this into a bound in expectation, let us consider the random variable
{\mathsf{Z}}
which takes the value one when
c_{1}^{2}\geq\frac{1}{2n}
and zero otherwise. If
{\mathsf{Z}}=1
, we have that
\tan^{2}(\theta_{0})=\frac{1}{c_{1}^{2}}-1\leq 2n
, which yields the bound

\displaystyle\mathbb{E}_{t}[\lambda_{t}^{2}]\geq\mathbb{E}_{t}[{\mathsf{Z}}](\lambda_{t}^{(1)})^{2}(\max\{0,1-4n\rho^{2r}\})^{2}.

(37)

Finally to bound
\mathbb{E}_{t}[{\mathsf{Z}}]
, we note that
c_{1}^{2}\sim\text{Beta}(\frac{1}{2},\frac{n-1}{2})

[
99
]
so that
\mathbb{E}_{t}[c_{1}^{2}]=\frac{1}{n}
and
\mathbb{E}_{t}[c_{1}^{4}]=\frac{3}{n(n+2)}
. Application of the Paley–Zygmund inequality
[
100
]
yields
\mathbb{P}[c_{1}^{2}\geq\frac{1}{2n}]\geq\frac{1}{4}\frac{n+2}{3n}\geq\frac{1}{12}
, which upon substituting in (
37
) gives

\displaystyle\mathbb{E}_{t}[\lambda_{t}^{2}]\geq\frac{1}{12}(\lambda_{t}^{(1)})^{2}(\max\{0,1-4n\rho^{2r}\})^{2}.

(38)

Finally, for
r=\frac{1}{2}\log_{\frac{1}{\rho}}(8n)
, we get
4n\rho^{2r}=\frac{1}{2}
, which results in the desired bound.
∎

IV-A

Minimizing geodesically smooth functions

We first consider the general case of geodesically
L
-smooth but possibly non-convex functions. In this case,
f
may have multiple stationary points that may not be a global minimum. However, as with all first-order algorithms, the proposed subspace descent algorithm can only guarantee an
\epsilon
-stationary point, i.e., one that satisfies:

\displaystyle{\mathbb{E}}\left[\min_{0\leq t\leq T-1}\left\|{\text{grad}}^{R}f({\mathbf{X}}_{t})\right\|_{{\mathbf{X}}_{t}}\right]\leq\epsilon.

(39)

We know that unless
f({\mathbf{X}}_{t})
is close to zero, the iterate
{\mathbf{X}}_{t}
is not globally optimum and does not solve (

P
e

). In such case, we may try again by restarting the algorithm from a different random initialization. The following theorem characterizes the iteration complexity of the proposed subspace descent algorithm.

Theorem 1
.

Under Assumptions
A2
and
A3
, the proposed algorithm yields an
\epsilon
-stationary point in
{\mathcal{O}}(\frac{nL}{\epsilon^{2}})
iterations and each iteration incurs
{\mathcal{O}}(n^{2}\log(n))
flops.

Proof.

For the sake of simplicity, we will use the step size
\beta_{t}=1/L
. We begin with using (
32
) between
{\mathbf{X}}_{t}
and
{\mathbf{X}}_{t+1}
as well as the definition of
{\bm{\xi}}_{{\mathbf{X}}_{t}{\mathbf{X}}_{t+1}}
in (
13
) to obtain

\displaystyle f({\mathbf{X}}_{t+1})-f({\mathbf{X}}_{t})

(40)

\displaystyle\leq\langle{\text{grad}}^{R}f({\mathbf{X}}_{t}),{\bm{\xi}}_{{\mathbf{X}}_{t}{\mathbf{X}}_{t+1}}\rangle_{{\mathbf{X}}_{t}}+\tfrac{L}{2}\|{\bm{\xi}}_{{\mathbf{X}}_{t}{\mathbf{X}}_{t+1}}\|_{{\mathbf{X}}_{t}}^{2}

\displaystyle\hskip-5.69054pt\stackrel{{\scriptstyle\text{\eqref{metric},\eqref{RiemanEuclideangrad},\eqref{xib}}}}{{\leq}}\hskip-8.53581pt-\tfrac{\lambda_{t}}{L}\mathrm{tr}\left({\mathbf{X}}_{t}{\text{grad}}\;f({\mathbf{X}}_{t}){\mathbf{X}}_{t}{\mathbf{X}}_{t}^{-1}{\mathbf{B}}_{t}{\mathbf{y}}_{t}{\mathbf{y}}_{t}^{\mathsf{T}}{\mathbf{B}}_{t}^{\mathsf{T}}{\mathbf{X}}_{t}^{-1}\right)

\displaystyle+\tfrac{\lambda_{t}^{2}}{2L}\mathrm{tr}\left({\mathbf{B}}_{t}{\mathbf{y}}_{t}{\mathbf{y}}_{t}^{\mathsf{T}}{\mathbf{B}}_{t}^{{\mathsf{T}}}{\mathbf{X}}^{-1}{\mathbf{B}}_{t}{\mathbf{y}}_{t}{\mathbf{y}}_{t}^{\mathsf{T}}{\mathbf{B}}_{t}^{{\mathsf{T}}}{\mathbf{X}}_{t}^{-1}\right)

(41)

\displaystyle=-\tfrac{\lambda_{t}}{L}\mathrm{tr}\left({\mathbf{y}}_{t}^{\mathsf{T}}{\mathbf{B}}_{t}^{\mathsf{T}}{\text{grad}}\;f({\mathbf{X}}_{t}){\mathbf{B}}_{t}{\mathbf{y}}_{t}\right)+\tfrac{\lambda_{t}^{2}}{2L}=-\tfrac{\lambda_{t}^{2}}{2L}.

(42)

That is, the per-iteration decrease in the function value is proportional to the square of the approximate Rayleigh quotient obtained from the power method.

Next, we bound the Riemannian gradient norm using (
6
):

\displaystyle\|{\text{grad}}^{R}f({\mathbf{X}}_{t})\|_{{\mathbf{X}}_{t}}^{2}\stackrel{{\scriptstyle\text{\eqref{metric},\eqref{RiemanEuclideangrad}}}}{{=}}\mathrm{tr}\left({\text{grad}}f({\mathbf{X}}_{t}){\mathbf{X}}_{t}{\text{grad}}f({\mathbf{X}}_{t}){\mathbf{X}}_{t}\right)

\displaystyle=\mathrm{tr}\left(({\mathbf{B}}_{t}^{\mathsf{T}}{\text{grad}}\;f({\mathbf{X}}_{t}){\mathbf{B}}_{t})^{2}\right)=\sum\nolimits_{i}(\lambda_{t}^{(i)})^{2}\leq n(\lambda_{t}^{(1)})^{2}

(43)

Taking expectation and applying the bound in Lemma
1
for
r\geq\frac{1}{2}\log_{\frac{1}{\rho}}(8n)
, we obtain

\displaystyle{\mathbb{E}}\|{\text{grad}}^{R}f({\mathbf{X}}_{t})\|_{{\mathbf{X}}_{t}}^{2}

\displaystyle\leq n{\mathbb{E}}[(\lambda_{t}^{(1)})^{2}]\stackrel{{\scriptstyle\text{\eqref{lamteq}}}}{{\leq}}48{\mathbb{E}}[\lambda_{t}^{2}]

(44)

\displaystyle\hskip-28.45274pt\stackrel{{\scriptstyle\text{\eqref{fdec}}}}{{\leq}}96nL({\mathbb{E}}[f({\mathbf{X}}_{t})]-{\mathbb{E}}[f({\mathbf{X}}_{t+1})]).

(45)

Therefore, taking sum over
t=1,\ldots,T
, dividing by
T
, and using the fact that
f({\mathbf{X}}_{T})\geq 0
, we obtain

\displaystyle{\mathbb{E}}[\min_{t}\|{\text{grad}}^{R}f({\mathbf{X}}_{t})\|_{{\mathbf{X}}_{t}}^{2}]

\displaystyle\leq\frac{1}{T}\sum_{t=0}^{T-1}{\mathbb{E}}\|{\text{grad}}^{R}f({\mathbf{X}}_{t})\|_{{\mathbf{X}}_{t}}^{2}

(46)

\displaystyle\leq\tfrac{96nLD_{0}}{T}

(47)

and subsequently from Cauchy-Schwarz inequality, we get

\displaystyle{\mathbb{E}}[\min_{t}\|{\text{grad}}^{R}f({\mathbf{X}}_{t})\|_{{\mathbf{X}}_{t}}]\leq\sqrt{\frac{96nLD_{0}}{T}}.

(48)

Equating the expression on the right with
\epsilon
yields the required iteration complexity. We note that for
r=\Theta(\log(n))
, the total flop count of the proposed algorithm becomes
{\mathcal{O}}(\frac{n^{3}\log(n)L}{\epsilon})
since each iteration incurs
\Theta(n^{2}\log(n))
flops.
∎

The result in Thm.
1
improves upon the
{\mathcal{O}}(\frac{\lvert{\mathcal{I}}\rvert L}{\epsilon^{2}})
iteration complexity of RCD algorithm in
[
43
, Thm. 4.1]
since the cardinality of the index set is
\lvert{\mathcal{I}}\rvert={\mathcal{O}}(n^{2})
. Likewise, the total flop count of Alg.
1
is
{\mathcal{O}}(n^{3}\log(n))
which is worse than the RGD flop count of
{\mathcal{O}}(n^{3})
but better than the
{\mathcal{O}}(n^{4})
count of RCD algorithm.

IV-B

Minimizing geodesically strongly convex and smooth functions

When
f
is geodesically strongly convex, (
1
) has a unique stationary point that solves (

P
e

), i.e.,
f({\mathbf{X}}^{\star})=0
. In this case, it suffices to characterize the number of iterations required to ensure that
f({\mathbf{X}}_{T})\leq\epsilon
. The following theorem provides required iteration complexity bound in terms of
\kappa=L/\mu
.

Theorem 2
.

Under Assumption
A1
-
A2
, the proposed algorithm has an iteration complexity of
{\mathcal{O}}\left(n\kappa\log\left(\frac{D_{0}}{\epsilon}\right)\right)
.

Proof.

Applying (
31
) to
f
from
{\mathbf{X}}\in{\mathbb{P}^{n}}
to
{\mathbf{X}}^{\star}
and using the fact that
f({\mathbf{X}})\geq f({\mathbf{X}}^{\star})=0
, we obtain

\displaystyle\frac{\mu}{2}\|{\bm{\xi}}_{{\mathbf{X}}{\mathbf{X}}^{\star}}\|_{{\mathbf{X}}}^{2}

\displaystyle\leq f({\mathbf{X}}^{\star})-f({\mathbf{X}})-\langle{\text{grad}}^{R}f({\mathbf{X}}),{\bm{\xi}}_{{\mathbf{X}}{\mathbf{X}}^{\star}}\rangle_{{\mathbf{X}}}

\displaystyle\leq\left\|{\text{grad}}^{R}f({\mathbf{X}})\right\|_{\mathbf{X}}\left\|{\bm{\xi}}_{{\mathbf{X}}{\mathbf{X}}^{\star}}\right\|_{{\mathbf{X}}}

(49)

where we have used the Cauchy-Schwarz inequality. Hence, if
{\mathbf{X}}\neq{\mathbf{X}}^{\star}
, it follows that
\|{\text{grad}}^{R}f({\mathbf{X}})\|_{{\mathbf{X}}}\geq\frac{\mu}{2}\|{\bm{\xi}}_{{\mathbf{X}}{\mathbf{X}}^{\star}}\|_{{\mathbf{X}}}
. Substituting back into (
49
) and using
f({\mathbf{X}}^{\star})=0
, we obtain

\displaystyle\frac{2}{\mu}\|{\text{grad}}^{R}f({\mathbf{X}})\|_{{\mathbf{X}}}^{2}\geq f({\mathbf{X}})

(50)

Writing (
50
) for
{\mathbf{X}}={\mathbf{X}}_{t}
, taking expectations, and combining with (
45
), we obtain

\displaystyle{\mathbb{E}}[f({\mathbf{X}}_{t+1})]

\displaystyle\leq\left(1-\tfrac{\mu}{192nL}\right){\mathbb{E}}[f({\mathbf{X}}_{t})]

(51)

\displaystyle\leq\left(1-\tfrac{\mu}{192nL}\right)^{t+1}D_{0}

(52)

Hence, to ensure that
{\mathbb{E}}[f({\mathbf{X}}_{T})]\leq\epsilon
, we need
T={\mathcal{O}}(n\kappa\log(D_{0}/\epsilon))
.
∎

Observe that Thm.
2
has the same dependence on
n
as Thm.
1
, but improved dependence on
\epsilon
. The overall flop count of
{\mathcal{O}}(n^{3}\kappa\log(nD_{0}/\epsilon))
is slightly worse than that of classical RGD, but the proposed algorithm has a lower per-iteration complexity allowing it to be applied to larger scale problems. We also note that the RRSD variants proposed in
[
51
]
also incur a per-iteration complexity of
{\mathcal{O}}(n^{3})
when applied to (
1
). In terms of total flop counts, the faster RRSD-multi algorithm in
[
51
]
requires
{\mathcal{O}}(n^{4}\log(D_{0}/\epsilon))
flops in the geodesically strongly convex and smooth case.

V-A

Implementation details

For the proposed as well as BMFC algorithms, we implement all the steps carefully so as to ensure that the per-iteration cost remains
{\mathcal{O}}(n^{2})
. To this end, we utilized the Woodbury identity to perform rank-one updates and maintained appropriate inverse matrices where required. The details of the updates are provided in the Appendices
A
,
B
, and
C
. For the purpose of implementation, we write the update as
{\mathbf{X}}_{t+1}={\mathbf{X}}_{t}+\alpha_{t}{\mathbf{B}}_{t}{\mathbf{y}}_{t}{\mathbf{y}}_{t}^{\mathsf{T}}{\mathbf{B}}_{t}^{\mathsf{T}}
and directly tune
\alpha_{t}
via line search. Interestingly, for the proposed algorithm, in all the three problems, the low-rank structure of the updates allows us to select the step-sizes via exact line search. Specifically, it is possible to find the step size that minimizes the objective along the descent direction without significant additional effort.

Exact line search is also possible for the BFMC algorithm for solving CARE and NME, but not for DARE, where Armijo line search must instead be used.
The Armijo line search method iteratively decreases the stepsize
\delta
by a factor
p
, until the following sufficient decease condition is satisfied along the descent direction
{\mathbf{D}}
:

\displaystyle f({\mathbf{Y}}_{t+1})\leq f({\mathbf{Y}}_{t})+\beta\delta\;\mathrm{tr}\left({\text{grad}}f({\mathbf{Y}})^{\mathsf{T}}{\mathbf{D}}\right)

(57)

We tested the performance of BMFC for different values of
\beta
and
p
. For the cyclic version of BMFC, varying
\beta\in\{1,0.1,0.01,0.001\}
showed no noticeable effect on convergence and hence we set
\beta=0.01
. We then tested for
p\in\{1/2,1/4,1/8,1/16,1/32,1/64,1/128\}
and found that
p=1/8
provides the best performance in terms of both total iterations and the number of Armijo line-search steps. For sampling
with replacement, the choice
\beta=0.1
and
p=1/8
yielded the best overall performance.

VI
Conclusion

In this work, we studied the computation of symmetric positive definition (SPD) solution of nonlinear matrix equations by recasting them as residual norm minimization problems on the SPD manifold. We proposed a rank-one Riemannian subspace descent method that updates the iterate along a dominant eigen-component of a transformed Riemannian gradient, identified via a small number of power iterations. The proposed updates admits exact step-size selection for broad classes of objectives, while still incurring only
{\mathcal{O}}(n^{2}\log(n))
cost per-iteration and requiring at most
{\mathcal{O}}(n)
iterations. Numerical experiments on large-scale CARE, DARE, and additional nonlinear matrix equations support the analysis and show that the method remains effective in dense regimes where cubic-cost iterations become impractical. In particular, the proposed algorithm solves instances up to
n=10{,}000
in our tests for which the compared solvers, including MATLAB’s
icare
, structure-preserving doubling algorithms, and subspace-descent baselines, do not return a solution under the same computational budget. These results indicate that rank-one manifold updates can serve as a viable alternative for high-dimensional SPD-constrained matrix equations found in control theory and related areas.
