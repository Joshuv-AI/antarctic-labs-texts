A brief note On learning problem with global perspectives
Getachew K. Befekadu

Abstract
This brief note considers the problem of learning with dynamic-optimizing principal-agent setting, in which the agents are allowed to have global perspectives about the learning process, i.e., the ability to view things according to their relative importances or in their true relations based-on some aggregated information shared by the principal. Whereas, the principal, which is exerting an influence on the learning process of the agents in the aggregation, is primarily tasked to solve a high-level optimization problem posed as an empirical-likelihood estimator under conditional moment restrictions model that also accounts information about the agents’ predictive performances on out-of-samples as well as a set of private datasets available only to the principal. In particular, we present a coherent mathematical argument which is necessary for characterizing the learning process behind this abstract principal-agent learning framework, although we acknowledge that there are a few conceptual and theoretical issues still need to be addressed.



keywords

Aggregation algorithm, empirical-likelihood estimators, expert advice, gradient systems, learning problem, modeling of nonlinear functions, moment restrictions model, principal-agent, point estimators.

In this section, we provide a formal problem statement that allows us to outline our abstract learning framework with global perspectives. In particular, the proposed learning framework, which exploits the dynamic-optimizing principal-agent setting, consists of the following core ideas: (i)

Here, we also assume that the principal uses a separate data

In terms of mathematical construct, searching for a set optimal parameter estimates
\theta^{\ast}\in\Theta

where the term

3.1
Parameter-updating model for the agents

), whose time-evolution is guided by its respective training dataset
D^{(i)}
, with
i\in\{1,2,\ldots,k\}
,, i.e.,

\displaystyle\theta_{t+1}^{(i)}=\bar{\theta}_{t}^{(i)}-\gamma_{t}^{(i)}\nabla_{\theta}J^{(i)}\bigl(\bar{\theta}_{t}^{(i)},D^{(i)}\bigr),\quad\text{with}\quad\bar{\theta}_{t}^{(i)}=\sum\nolimits_{j=1}^{k}p_{ij}\theta_{t}^{(j)},

(3)

where

–

\sum\nolimits_{j=1}^{k}p_{ij}=1
, with
p_{ij}\geq 0
, for
i,j\in\bigl\{1,\,2,\,\ldots,k\bigr\}
are the probability mass information (used for aggregating the agents’ parameter estimates) and shared with the agents at each iteration instant by the principal,

–

\bar{\theta}_{t}^{(i)}=\sum\nolimits_{j=1}^{k}\theta_{t}^{(j)}
, for
i=1
,
2
, …,
k
, are aggregated information used by the agents in their parameter updating model, and

–

\gamma_{t}^{(i)}
is a discretization time constant, i.e.,
\gamma_{t}^{(i)}=\tau_{t+1}-\tau_{t}
, for

,

,

i=1

Note that the probability mass information, with support on the parameter space as well as on a set of private datasets to the principal, are solutions arising from the high-level optimization problem which is tasked to the principal.

3.2
Optimization problem for the principal

In this subsection, we assume that the principal and the agents follow a
two-sided information sharing protocol
, i.e., a procedure on how they share their respective information between them. Suppose that, at the end of each iteration instant, all agents are simultaneously reporting their current updated parameter estimates to the principal. Then, the principal solves a high-level optimization problem which is posed as an empirical-likelihood estimator under conditional moment restrictions model that also accounts information about the agents’ predictive performances on out-of-samples as well as a set of private information available only to the principal. To be more specific, suppose we have
k
a set of independent parameter estimates
\bigl(\theta^{(1)},\,\theta^{(2)},\ldots,\theta^{(k)})
, with support
\Theta\subseteq\mathbb{R}^{d_{\theta}}
, and we then proceed with determining/estimating a set of unknown parameters
\beta=(\mu,\sigma^{2})\in\mathbb{B}\subseteq\mathbb{R}\times\mathbb{R}_{+}
under conditional moment restrictions model

E\left[g\bigl(\bigl(x_{n+1},y_{n+1}\bigr),\theta,\beta\bigr)\,\bigl|\,s\right]=\left[\begin{matrix}E\left[\bigl(y_{n+1}-h\bigl(x_{n+1};\theta\bigr)-\mu\bigr)\,\bigl|\,s\right]\\
E\left[\bigl(\bigl(y_{n+1}-h\bigl(x_{n+1};\theta\bigr)-\mu\bigr)^{2}-\sigma^{2}\bigr)\,\bigl|\,s\right]\end{matrix}\right]=0,

(4)

where the measurable function
g
is given by

g\bigl(\bigl(x_{n+1},y_{n+1}\bigr),\theta,\beta\bigr)=\left[\begin{matrix}\bigl(y_{n+1}-h\bigl(x_{n+1};\theta\bigr)-\mu\bigr)\\
\bigl(\bigl(y_{n+1}-h\bigl(x_{n+1};\theta\bigr)-\mu\bigr)^{2}-\sigma^{2}\bigr)\end{matrix}\right]\in\mathbb{R}^{d_{g}},

while the quantity
s
, with support from
\mathbb{R}^{d_{s}}
, is assumed to contain information that provides global perspectives to the agents. Note that the measurable function
g\colon(x,y)\times\Theta\times\mathbb{B}\to\mathbb{R}^{d_{g}}
(with
\mathbb{R}^{d_{g}}\equiv\mathbb{R}^{2}
) provides information about prediction errors with respect to the agent’s parameter estimate
\theta
.

In what follows, for each iteration instant
t=0
,
1
, …,
N-1
, let
p_{ij}
, for each
i,j\in\{1,2,\ldots,k\}
, be a probability mass placed at
\bigl(\theta_{t+1}^{(i)},s_{j}\bigr)
by a discrete probability distribution that has support on
\bigl\{\theta_{t+1}^{(1)},\,\theta_{t+1}^{(2)},\ldots,\theta_{t+1}^{(k)}\bigr\}\times\bigl\{s_{1},\,s_{2},\ldots,s_{k}\bigr\}
. Further, let
w_{ij}
be the weights given by

\displaystyle w_{ij}=\frac{\psi\bigl(\tfrac{s_{i}-s_{j}}{h_{bw}}\bigr)}{\sum\nolimits_{j=1}^{k}\psi\bigl(\tfrac{s_{i}-s_{j}}{h_{bw}}\bigr)},\quad i,j=1,2,\ldots,k,

(5)

for some appropriately chosen kernel function
\psi
and bandwidth
h_{bw}
. Moreover, if we define the following smoothed log-likelihood function
\ell_{\theta}\bigl(\beta_{t+1}\bigr)
,

\displaystyle\ell_{\theta}\bigl(\beta_{t+1}\bigr)=\sum\nolimits_{i=1}^{k}\sum\nolimits_{j=1}^{k}w_{ij}\log p_{ij}.

(6)

Then, we have the following optimization problem

\displaystyle\max_{\{p_{ij}\geq 0,\,|i,j=1,2,\ldots,k\},\beta_{t+1}}

\displaystyle\sum\nolimits_{i=1}^{k}\sum\nolimits_{j=1}^{k}w_{ij}\log p_{ij}

(7)

s.t.

\displaystyle\quad k\sum\nolimits_{j=1}^{k}g\bigl(\theta_{t+1}^{(j)},\beta_{t+1}\bigr)p_{ij}=0,

\displaystyle\quad\sum\nolimits_{j=1}^{k}p_{ij}=1,\quad\text{with}\quad p_{ij}\geq 1,~\text{for all}~i,j=1,2,\ldots,k,

that needs to be solved by the principal for each iteration instant
t=0
,
1
, …,
N-1
. Note that the above optimization problem in Equation
7
can be conveniently solved using Lagrange multipliers (i.e., based on the KKT’s optimality conditions (e.g., see
[
11
]
)) as follows

\displaystyle\mathscr{L}\bigl(\beta_{t+1}\bigr)=\sum\nolimits_{i=1}^{k}\sum\nolimits_{j=1}^{k}w_{ij}\log p_{ij}

\displaystyle-\sum\nolimits_{i=1}^{k}\eta_{i}\left(\sum\nolimits_{j=1}^{k}p_{ij}-1\right)

\displaystyle-k\sum\nolimits_{i=1}^{k}\lambda_{i}^{T}\sum\nolimits_{j=1}^{k}g\bigl(\theta_{t+1}^{(j)},\beta_{t+1}\bigr)p_{ij},

(8)

where
\lambda_{i}\in\mathbb{R}^{d_{g}}
and
\eta_{i}\in\mathbb{R}
, for
i=1
,
2
, …,
k
, are the Lagrange multipliers corresponding to the constraints in Equation
7
. Then, it is easy to see that the solutions are given by

\displaystyle\hat{p}_{ij}=\frac{w_{ij}}{1+\lambda_{i}^{T}g\bigl(\theta_{t+1}^{(j)},\beta_{t+1}\bigr)},\quad i,j=1,2,\ldots,k,

(9)

while for each
\beta\in\mathbb{B}
, the Lagrange multiplier
\lambda_{i}
, for
i=1
,
2
, …,
k
, solves

\displaystyle\sum\nolimits_{j=1}^{k}\frac{w_{ij}g\bigl(\theta_{t+1}^{(j)},\beta_{t+1}\bigr)}{1+\lambda_{i}^{T}g\bigl(\theta_{t+1}^{(j)},\beta_{t+1}\bigr)}=0.

(10)

Note that, for an initial value
\hat{\beta}^{0}
, starting with
s=0
, and for each iteration instant
t=0
,
1
, …,
N-1
, the following generic algorithm, that iterates between the following two coupled optimization steps

\displaystyle\hat{\lambda}_{i}^{s+1}=\argmax_{\lambda\in\mathbb{R}^{d_{g}}}\sum\nolimits_{j=1}^{k}w_{ij}\log\bigl(1+\lambda_{i}^{T}g\bigl(\theta_{t+1}^{(j)},\hat{\beta}^{s}\bigr),\quad i=1,2,\ldots,k

(11)

and

\displaystyle\hat{\beta}^{s+1}=\argmin_{\beta\in\mathbb{B}}-\sum\nolimits_{i=1}^{k}\sum\nolimits_{j=1}^{k}w_{ij}\log\bigl(1+\bigl(\hat{\lambda}_{i}^{s+1}\bigr)^{T}g\bigl(\theta_{t+1}^{(j)},\beta\bigr)\bigr)

(12)

can be used for determining a set of optimal solutions
\hat{\lambda}_{i,t+1}^{\ast}
, for
i=1
,
2
, …,
k
, and
\hat{\beta}_{t+1}^{\ast}
. Note that, during the next iteration cycle, based on
\bigl(\bigl\{\hat{\lambda}_{i,t+1}^{\ast}\bigr\}_{i=1}^{k},\hat{\beta}_{t+1}^{\ast}\bigr)
,
\bigl\{\theta_{t+1}^{(i)}\bigr\}_{i=1}^{k}
and
\bigl\{w_{i,j}\bigr\}_{i,j=1}^{k}
, the principal then shares information with each of the agents in the form of some aggregated information, i.e.,

\displaystyle\bar{\theta}_{t+1}^{(i)}=\sum\nolimits_{j=1}^{k}\hat{p}_{ij}\theta_{t+1}^{(j)},\quad i=1,2,\ldots,k,

(13)

with

\displaystyle\hat{p}_{ij}=\frac{w_{ij}}{1+\bigl(\hat{\lambda}_{i,t+1}^{\ast}\bigr)^{T}g\bigl(\theta_{t+1}^{(j)},\hat{\beta}_{t+1}^{\ast}\bigr)},\quad i,j=1,2,\ldots,k.

Finally, it is worth remarking that, when
t=N-1
, the log-likelihood function
\ell_{\theta}\bigl(\hat{\beta}_{N}^{\ast}\bigr)
satisfies the following upper bound

\displaystyle\ell_{\theta}\bigl(\beta_{N}^{\ast}\bigr)

\displaystyle=\sum\nolimits_{i=1}^{k}\sum\nolimits_{j=1}^{k}w_{ij}\log\hat{p}_{ij}

\displaystyle=\sum\nolimits_{i=1}^{k}\sum\nolimits_{j=1}^{k}\log\left(\frac{w_{ij}}{1+\bigl(\hat{\lambda}_{i,N}^{\ast}\bigr)^{T}g\bigl(\theta_{N}^{(j)},\hat{\beta}_{N}^{\ast}\bigr)}\right)

\displaystyle=\sum\nolimits_{i=1}^{k}\sum\nolimits_{j=1}^{k}\log w_{ij}-\sum\nolimits_{i=1}^{k}\sum\nolimits_{j=1}^{k}\log\left(1+\bigl(\hat{\lambda}_{i,N}^{\ast}\bigr)^{T}g\bigl(\theta_{N}^{(j)},\beta_{N}^{\ast}\bigr)\right)

\displaystyle\leq-\sum\nolimits_{i=1}^{k}\sum\nolimits_{j=1}^{k}\log\left(1+\bigl(\hat{\lambda}_{i,N}^{\ast}\bigr)^{T}g\bigl(\theta_{N}^{(j)},\beta_{N}^{\ast}\bigr)\right),

(14)

since
\sum\nolimits_{i=1}^{k}\sum\nolimits_{j=1}^{k}\log w_{ij}\leq 0
, due to
w_{ij}\in(0,1]
.

3.3
Algorithm

In this subsection, we present a generic algorithm that provides a viable way for implementing such a learning problem with global perspectives.

ALGORITHM:
Learning problem with global perspectives.

Inputs:

(i) Datasets for the agents:

k

n_{i}
,

, with
i=1,2,\ldots,k

(ii) An equidistant discretization time:

, with

A set of private datasets
\bigl\{s_{i}\bigr\}_{i=1}^{k}
and an additional data
\bigl(x_{n+1},y_{n+1}\bigr)
.

0.

Initialize:
Set
t=0
,
\theta_{0}^{(i)}=\theta_{0}
and
\hat{p}_{ij}=1/k
, for
i=1
,
2
,…,
k
. Compute the weights using

,

, …,

1.

Agents:
Update parameter estimates using

\displaystyle\theta_{t+1}^{(i)}=\bar{\theta}_{t}^{(i)}-\gamma\nabla_{\theta}J^{(i)}\bigl(\bar{\theta}_{t}^{(i)},D^{(i)}\bigr),\hskip 8.50012pt\text{with}\hskip 8.50012pt\bar{\theta}_{t}^{(i)}=\sum\nolimits_{j=1}^{k}\hat{p}_{ij}\theta_{t}^{(j)},

2.

Principal:
Solves the following optimization problem

\displaystyle\max_{\{p_{ij}\geq 0,\,|i,j=1,2,\ldots,k\},\beta_{t+1}}

\displaystyle\sum\nolimits_{i=1}^{k}\sum\nolimits_{j=1}^{k}w_{ij}\log p_{ij}

\displaystyle\hskip 8.50012ptk\sum\nolimits_{j=1}^{k}g\bigl(\theta_{t+1}^{(j)},\beta_{t+1}\bigr)p_{ij}=0,

2
(i) and Step
2
(ii), with an initial value
\hat{\beta}^{0}
, starting from

2 (i).

First compute

\displaystyle\hat{\lambda}_{i}^{s+1}=\argmax_{\lambda\in\mathbb{R}^{d_{g}}}\sum\nolimits_{j=1}^{k}w_{ij}\log\bigl(1+\lambda_{i}^{T}g\bigl(\theta_{t+1}^{(j)},\hat{\beta}^{s}\bigr),\hskip 8.50012pti=1,2,\ldots,k.

\hat{\beta}_{t+1}^{\ast}

\displaystyle\hat{\beta}^{s+1}=\argmin_{\beta\in\mathbb{B}}-\sum\nolimits_{i=1}^{k}\sum\nolimits_{j=1}^{k}w_{ij}\log\bigl(1+\bigl(\hat{\lambda}_{i}^{s+1}\bigr)^{T}g\bigl(\theta_{t+1}^{(j)},\beta\bigr)\bigr).

Repeat Step
2

\left(\bigl\{\hat{\lambda}_{i,t+1}^{s}\bigr\}_{i=1}^{k},\hat{\beta}_{t+1}^{s}\right)
