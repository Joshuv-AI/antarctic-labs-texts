On the computation of the MED closure of a numerical semigroup Thanks: This work was supported by the Ministerio de Ciencia e Innovación under Project PID2020-114613GB-I00 (MCIN/AEI/10.13039/501100011033).
Jorge Jiménez–Urroz, José M. Tornero

Abstract
. Maximally embedding dimension (MED) numerical semigroups are a wide and interesting family, with some remarkable algebraic and combinatorial properties. Associated to any numerical semigroup one can construct a MED closure, as it is well–known. This paper shows two different explicit methods to construct this closure which also sheds new light on the very nature of this object.

1.
Essential concepts

A semigroup is a pair
(X,\star)
, where
X
is a set and
\star
is an associative internal operation. Actually we will be considering monoids, that is, semigroups with unit element, but there are no substantial differences for our concerns. We will be particularly interested in the so–called numerical semigroups. Useful references for the basic concepts and for the results not proved here are
[
5
,
8
]
.

Definition 1.1
.

A numerical semigroup is an additive monoid
S\subset{\mathbb{Z}}_{\geq 0}
such that
{\mathbb{Z}}_{\geq 0}\setminus S
is a finite set.

Example 1.2
.

The first natural example of a semigroup in
{\mathbb{Z}}_{\geq 0}
is the semigroup generated by a set
\{a_{1},\ldots,a_{k}\big\}\subset{\mathbb{Z}}_{\geq 0}
, which is the set of linear combinations of these integers with non–negative integral coefficients:

\langle a_{1},\ldots,a_{k}\rangle=\left\{\lambda_{1}a_{1}+\cdots+\lambda_{k}a_{k}\;|\;\lambda_{i}\in{\mathbb{Z}}_{\geq 0}\right\}.

It turns out that this example is in fact the general case for a numerical semigroup.

Proposition 1.3
.

Every numerical semigroup
S
can be written in the form

S=\langle a_{1},\ldots,a_{k}\rangle,

with
\gcd(a_{1},\ldots,a_{k})=1
. We will call
\{a_{1},\ldots,a_{k}\}
a set of generators of
S
. There exists a unique minimal set of generators of
S
.

Note that, as
{\mathbb{Z}}_{\geq 0}\setminus S
is a finite set, there exists
N\in{\mathbb{Z}}
such that
x\in S
, for all
x\geq N
.

As
S=\langle\,a_{1},\ldots,a_{k}\,\rangle
is nothing but the set of non–negative integers that can be written as a linear combination (with non–negative coefficients) of
\{a_{1},\ldots,a_{k}\big\}
, the elements of
S
are often called
representable integers
(w.r.t.
\{a_{1},\ldots,a_{k}\big\}
). In the same fashion the elements of the (finite) set
{\mathbb{Z}}_{\geq 0}\setminus S
are called
non–representable integers
or
gaps
.

Definition 1.4
.

Some important invariants associated to a numerical semigroup
S
are:

•

The set of gaps, which is the finite set
{\mathbb{Z}}_{\geq 0}\setminus S
, noted
\operatorname{G}(S)
. Its cardinal is called the genus of
S
, noted
g(S)
.

•

The Frobenius number of
S
which is the maximum of
\operatorname{G}(S)
, noted
f(S)
. The conductor of
S
is
c(S)=f(S)+1
, and it is the smallest number verifying
c(S)+{\mathbb{Z}}_{\geq 0}\subset S
.

•

The set of sporadic (or left) elements, noted
N(S)
, which are elements of
S
smaller than
f(S)
, that is
N(S)=S\cap[0,f(S)]
. Its cardinal is noted
n(S)
(this invariant has not a properly stablished name in the literature) and verifies directly
n(S)+g(S)=c(S)
.

•

The set of pseudo-Frobenius numbers, which is

\operatorname{PF}(S)=\big\{x\in\operatorname{G}(S)\;|\;x+s\in S,\;\forall s\in S\setminus\{0\}\big\}.

Its cardinal is called the type of
S
, noted
t(S)
. Clearly
f(S)\in\operatorname{PF}(S)
.

•

The multiplicity of
S
, noted
m(S)
, which is the smallest non–zero element in
S
(obviously a generator in any case).

•

The embedding dimension of
S
, noted
e(S)
, which is the cardinal of the minimal set of generators.

An important object related to an element of a numerical semigroup is the so-called Apéry set, named after Roger Apéry and his seminal work relating numerical semigroups and resolution of curve singularities
[
1
]
.

Definition 1.5
.

With the previous notations, the Apéry set of
S
with respect to an element
s\in S\setminus\{0\}
can be defined as

\operatorname{Ap}(S,s)=\big\{0=w_{0},w_{1},\ldots,w_{s-1}\big\}

where
w_{i}
is the smallest element in
S
congruent with
i
modulo
s
.

In particular, mind that
\#\operatorname{Ap}(S,s)=s
. This set has an interesting equivalent definition, which we will review now.

Lemma 1.6
.

With the previous notations, for all
s\in S\setminus\{0\}
,

\operatorname{Ap}(S,s)=\big\{x\in S\;|\;x-s\notin S\big\}

Example 1.7
.

Let
S_{1}=\langle 7,9,11,15\rangle
. Some of the Apéry sets associated to its generators are:

\displaystyle\operatorname{Ap}(S_{1},7)

\displaystyle=

\displaystyle\big\{0,9,11,15,20,24,26\big\}

\displaystyle\operatorname{Ap}(S_{1},15)

\displaystyle=

\displaystyle\big\{0,7,9,11,14,16,18,20,21,23,25,27,28,32,34\big\}

Note that, from the definition, the minimal set of generators of
S
must be included in every Apéry set, except when the element is a generator itself, in which case it is replaced by
0
in the Apéry set. Because of this dichotomy we will sometimes use the following variant

\widehat{\operatorname{Ap}}(S,s)=\big\{x\in S\;|\;x-s\in\operatorname{G}(S)\cup\big\{0\big\}\big\},

which only changes
0
by
s
itself, and verifies that the minimal set of generators of
S
must be included in every
\widehat{\operatorname{Ap}}(S,s)
. This implies, in particular, that
e(S)\leq m(S)
, as
m(S)=\#\operatorname{Ap}(S,m(S))=\#\widehat{\operatorname{Ap}}(S,m(S))
.

If we define the partial ordering in
{\mathbb{Z}}
given by
a\leq_{S}b
if and only if
b-a\in S
, then the Apéry set verifies the following
[
4
]
:

•

The Apéry sets
\operatorname{Ap}(S,s)
are isolated w.r.t
\leq_{S}
that is, if
x\in\operatorname{Ap}(S,s)
and
y\leq_{S}x
, then
y\in\operatorname{Ap}(S,s)
.

•

The minimal set of generators is, for all
s\in S
,
\operatorname{Min}_{\leq_{S}}\operatorname{Ap}(S,s)
.

•

The set of pseudo–Frobenius elements is, for all
s\in S
,

\operatorname{PF}(S)=\left\{x-s\;\Big|\;x\in\operatorname{Max}_{\leq_{S}}\operatorname{Ap}(S,s)\right\}.

The Apéry set can be explicitely computed
[
3
,
6
]
, although its computation can be shown to be NP–hard, as it implies the calculation of
f(S)

[
7
]
.

Finally, let us recall the following definition.

Definition 1.8
.

Let
S
be a numerical semigroup. A set
I\subset S
is called an ideal (of
S
) if
I+S\subset I
, that is, for all
x\in I
and
y\in S
, we have
x+y\in I
.

Coherently, the conductor of the ideal, noted
c(I)
, is the smallest integer such that
c(I)+{\mathbb{Z}}_{\geq 0}\subset I
.

2.
MED closure of a numerical semigroup

This paper will deal with a specific family of numerical semigroups, which we proceed to define. The results not proved here can be found in
[
5
]
.

Definition 2.1
.

Let
S
be a numerical semigroup. We will say that
S
is a maximal embedding dimension (MED) semigroup if
e(S)=m(S)
. Equivalently,
S
is a MED semigroup when
\widehat{\operatorname{Ap}}(S,m(S))
is the minimal generating set of
S
.

MED semigroups are, not only a generalization of the two important families (Arf and saturated numerical semigroups), but also an interesting class of semigroups to work with on its own right.

Among some remarkable properties of these semigroups we would mention that if
S
is a MED semigroup with minimal generating set
a_{1}<\ldots<a_{k}
, then we have
f(S)=a_{k}-a_{1}
. As noted above, the problem of computing
f(S)
from
a_{1},\ldots,a_{k}
is NP–hard for general semigroups
[
7
]
.

In the same vein, the genus
g(S)
, for a MED semigroup generated by
a_{1}<\ldots<a_{k}
can be computed easily, as

g(S)=a_{k}-\left(\frac{a_{2}+\cdots+a_{k}}{a_{1}}+\frac{a_{1}+1}{2}\right).

Our next aim is to give a characterization for the MED semigroups, in terms of the Apéry sets, in order to be effective. We begin with a definition which puts the focus on the behaviour of single elements, instead of the full semigroup.

Definition 2.2
.

Let
S
be a numerical semigroup,
z\in S
. We will say that
z
is an Arf element of
S
if, for all
x,y\in S
with
x,y\geq z
,
x+y-z\in S
.

When all elements of
S
are Arf,
S
will be called an Arf semigroup.

If no confusion arises, we will simply say
z
is Arf
instead of
z
is an Arf element of
S
. Some immediate remarks from the definition are the following:

a)

It is equivalent to check the condition for
x,y>z
.

b)

If
z>f(S)
,
z
is Arf, as
x+y-z>f(S)
for all
x,y>z
.

Therefore, in order to see if
S
is an Arf semigroup, we only have to care about
N(S)
, the set of sporadic (or left) elements of
S
(actually the non-zero ones), which is in fact a finite set.

An easy equivalent definition, in terms of Apéry sets, is the following.

Proposition 2.3
.

Let
S
be a numerical semigroup,
z\in S\setminus\{0\}
. Then the following conditions are equivalent:

a)

z
is Arf.

b)

If
x,y\in\operatorname{Ap}(S,z)
, with
x,y>z
, then
x+y\notin\operatorname{Ap}(S,z)
.

Proof.

The direct implication is straightforward from the definitions of Arf elements and Apéry sets. Let us check the reverse one.

In order to show that
z
, verifying condition b), is Arf, let us take
x,y\in S
with
x,y>z
. Then, if
x\notin\operatorname{Ap}(S,z)
,
x-z\in S
and therefore
(x-z)+y\in S
. The same goes if
y\notin\operatorname{Ap}(S,z)
. Therefore, we only have to care about the case
x,y\in\operatorname{Ap}(S,z)
, in which case, condition b) implies
(x+y)-z\in S
. This finishes the proof.
∎

In more common terms in combinatorial number theory one could say that
z
is Arf if and only if

\{x\in\operatorname{Ap}(S,z)\;|\;x>z\big\}

is a sum–free set. Note that exactly the same result holds for
\widehat{\operatorname{Ap}}(S,z)
.

Remark 2.4
.

For an arbitrary element
s\in S
, being Arf and having
\widehat{\operatorname{Ap}}(S,s)
sum–free are not equivalent. For example
\widehat{\operatorname{Ap}}(S,2m(S))
is never sum–free, even if
S
is Arf.

The following result has a consequence which illustrates nicely the relationship between MED and Arf numerical semigroups. This result can be found in
[
5
]
, within a different context, including more equivalent conditions (which are of no use for our purposes). We include a direct proof for the convenience of the reader.

Proposition 2.5
.

S
is a MED numerical semigroup if and only if
m(S)
is Arf.

Proof.

Assume
S
is a MED numerical semigroup, minimally generated by
a_{1}<\ldots<a_{k}
(that is,
m(S)=a_{1}
). As
e(S)=m(S)=a_{1}
, the Apéry set
\operatorname{Ap}(S,a_{1})
must be

\operatorname{Ap}(S,a_{1})=\left\{0,a_{2},\ldots,a_{k}\right\}.

All the non-zero elements are bigger than
a_{1}
. If we take two of these elements, say
a_{i},a_{j}\in\operatorname{Ap}(S,a_{1})
, then
a_{i}+a_{j}\notin\operatorname{Ap}(S,a_{1})
, for otherwise the set of generators would not be minimal. Therefore,
a_{1}=m(S)
is Arf.

Conversely, assume
m(S)=a_{1}
is Arf and let its Apéry set be

\operatorname{Ap}(S,a_{1})=\left\{0=x_{1},x_{2},\ldots,x_{m(S)}\right\}.

This implies, as we saw above, that
\left\{a_{1},x_{2},\ldots,x_{m(S)}\right\}
is a generating set. But being
a_{1}
Arf, it is easy to see that
x_{2},\ldots,x_{m(S)}
cannot be expressed (in a non–trivial way) as a sum of elements of
S
. On the one hand,
x_{i}
is the minimal element of
S\cap(x_{i}+{\mathbb{Z}}/{\mathbb{Z}}a_{1})
, so it cannot be written as

x_{i}=y+\lambda a_{1},\mbox{ with }y\in S,\;\lambda\in{\mathbb{Z}}_{>0}.

On the other hand, from the Arf condition,
x_{i}
cannot be written as the sum of two elements of
S
of non–zero residue in
{\mathbb{Z}}/{\mathbb{Z}}a_{1}
. Therefore
\left\{a_{1},x_{2},\ldots,x_{m(S)}\right\}
is the minimal generating set, and
S
is a MED numerical semigroup.
∎

Therefore, all Arf semigroups are MED semigroups.

Example 2.6
.

Trivially
S_{1}
is not a MED numerical semigroup, since
e(S)<m(S)
. Note in this case that

\operatorname{Ap}(S_{1},7)=\big\{0,\mathbf{9},\mathbf{11},15,\mathbf{20},24,26\big\}.

Analogously,

S_{2}=\langle 9,13,14,16,17,19,20,21,24\rangle

is not Arf, as

\operatorname{Ap}(S_{2},13)=\big\{0,9,\mathbf{14},16,17,18,19,20,21,23,24,25,\mathbf{28}\big\},

but

\operatorname{Ap}(S_{2},9)=\big\{0,13,14,16,17,19,20,21,24\big\},

so it is MED (we could have also checked that the given generating system is minimal, of course).

If we consider
S_{3}=\langle 7,11,13,15,16,17,19\rangle
, we have

\operatorname{Ap}(S_{3},7)=\big\{0,11,13,15,16,17,19\big\},

so it is MED. Therefore
f(S_{3})=19-7=12
and
N(S_{3})=\big\{0,7,11\}
. We have already checked
7
is Arf, so it only remains to compute

\operatorname{Ap}(S_{3},11)=\big\{0,7,13,14,15,16,17,19,20,21,23\big\},

where the elements bigger than
11
are clearly a sum-free subset. Therefore,
S_{3}
is Arf.

So, we have translated both categories (MED and Arf semigroups) into similar conditions (some elements verifying the Arf property). While for MED semigroups the Arf property only must hold for
m(S)
, for Arf semigroups all the elements of
N(S)
must be Arf elements.

We finish this section by remembering two important results. The first one can be found in
[
9
]
, but we will include a proof, as the reference is apparently hard to access.

Theorem 2.7
.

Let
S
be a numerical semigroup,
m=m(S)
. There exists a MED semigroup, noted
\operatorname{MED}(S)
, which is the smallest MED semigroup contaning
S
with multiplicity
m(S)
. It is called the MED closure of
S
.

Proof.

Let us call

{\mathcal{A}}_{S}=\Big\{T\;\Big|\;m(T)=m,\;S\subset T,\;T\mbox{ is MED}\Big\}.

Clearly
{\mathcal{A}}_{S}
is finite, because there are only finitely many numerical semigroups containing
S
. Also,
{\mathcal{A}}_{S}\neq\varnothing
, because
T=\big\{0,m,\rightarrow\big\}\in{\mathcal{A}}_{S}
. Here the symbol
\rightarrow
means that all integers greater than the preceding number are in
T
.

Therefore it makes sense considering

S_{0}=\bigcap_{T\in{\mathcal{A}}_{S}}T,

which is clearly a numerical semigroup with
m(S_{0})=m
.
S_{0}
is also a MED semigroup, and this is easily checkable using the fact that
m
is an Arf element of
T
, for all
T\in{\mathcal{A}}_{S}
.

It is also immediate that
S\subset S_{0}\subset T
, for all
T\in{\mathcal{A}}_{S}
, by definition of
S_{0}
. Hence,
S_{0}
is the numerical semigroup
\operatorname{MED}(S)
.
∎

Lemma 2.8
.

Let
u\in\operatorname{MED}(S)
and
S_{u}
be the semigroup generetad by
S\cup\{u\}
. Then
\operatorname{MED}(S_{u})=\operatorname{MED}(S)
.

Proof.

First we note that
m(S_{u})=m(S)
and hence
{\mathcal{A}}_{S_{u}}\subset{\mathcal{A}}_{S}
. Moreover if
u\in\operatorname{MED}(S)
then
u\in T
for all
T\in{\mathcal{A}}_{S}
so
T\in{\mathcal{A}}_{S_{u}}
if and only if
T\in{\mathcal{A}}_{S}
. Hence

\operatorname{MED}(S)=\bigcap_{T\in{\mathcal{A}}_{S}}T=\bigcap_{T\in{\mathcal{A}}_{S_{u}}}T=\operatorname{MED}(S_{u}).

∎

Once this is done, one can compute
\operatorname{MED}(S)
in many cases, for a given semigroup
S
, thanks to this result from
[
9
, Thm.14]
:

Theorem 2.9
.

Let
m,r_{1},\ldots,r_{p}\in{\mathbb{N}}^{*}
such that
\gcd\left(m,r_{1},\ldots,r_{p}\right)=1
. Then

\operatorname{MED}\big(\langle m,m+r_{1},\ldots,m+r_{p}\rangle\big)=\big(m+\langle m,r_{1},\ldots,r_{p}\rangle\big)\cup\big\{0\big\}.

While this result is really useful and allows, for instance, to prove that, if
m(S),m(S)+1\in S
, then
\operatorname{MED}(S)=\big\{0,m,\rightarrow\big\}
, it does not necessarily gives a minimal system of generators for
\operatorname{MED}(S)
. The rest of the paper will be devoted to give two different, iterative processes to compute
\operatorname{MED}(S)
(given by a minimal system of generators) which will hopefully shed also some light on the nature of
\operatorname{MED}(S)
.

3.
Interlude: How to enlarge a numerical semigroup (carefully)

As our interest will lie on computing explicitely the MED closure, we must have a word on the problem of enlarging a numerical semigroup, in a controlled manner.

Adding (or removing) elements to a numerical semigroup while preserving the structure is a very interesting problem, with an obvious potential for induction–like strategies. In
[
10
]
, for instance, the problem of adding one element is considered. As for more complicated sets, we have the following.

Lemma 3.1

(
[
5
]
, Ex.1.6)
.

Let
S
be a numerical semigroup. Consider
\operatorname{PF}(S)=\big\{x_{1}=f(S)>x_{2}>\cdots>x_{t}\big\}
. Then, for every
r\leq t
,
T=S\cup\{x_{1},\ldots,x_{r}\}
is a numerical semigroup.

Proof.

Indeed the set of gaps of
T
is contained in
\operatorname{G}(S)
, hence is finite. Finally suppose
a,b\in T
. We have three options:

•

a,b\in S
. Then
a+b\in S\subset T
.

•

a\in S
,
b\notin S
. Then
b\in\operatorname{PF}(S)
and, either
a=0
and
a+b=b\in T
or, by definition
a+b\in S\subset T
.

•

a,b\notin S
. Then, for every
x\in S\setminus\{0\}
,
(a+b)+x=a+(b+x)\in S
, as
a\in\operatorname{PF}(S)
and
b+x\in S
. Hence
a+b\in\operatorname{PF}(S)
and, as
a+b>a,b
, it must hold
a+b\in T
.

The three cases above prove the result.
∎

Not only we have a bigger semigroup from
S
, we can also have some control on its main invariants. Let us name, following the above notation

\operatorname{PF}(S)_{r}=\big\{x_{1},\ldots,x_{r}\},

where
\operatorname{PF}(S)=\big\{x_{1}=f(S)>x_{2}>\cdots>x_{t}\big\}
, and
S_{r}=S\cup\operatorname{PF}(S)_{r}
. Then, by definition,

g(S_{r})=g(S)-r,

but also have the following result.

Theorem 3.2
.

With the notation as above we have

c(S)\leq 2g(S)-r+1.

Proof.

Let us consider the set
I=S\setminus\{0\}
which is clearly an ideal of
S
. Now, it is also obvious that
I
is an ideal of
S_{r}
.

Indeed, if
a\in I
and
b\in S_{r}
then either
b\in S
and then
a+b\in I
because
I
is an ideal of
S
, or
b\in\operatorname{PF}(S)_{r}
, and so
a+b\in S
and
a+b\neq 0
so
a+b\in I
. We can now apply the following result
[
2
, Thm.3]
:

Theorem 3.3
.

Let
H
be a numerical semigroup and
J\subset H
an ideal of
H
. Then
c(J)\leq 2g(H)+|H\setminus J|
.

We will apply the lemma for
J=I
and
H=S_{r}
. Now,
c(I)=c(S)
, while
g(S_{r})=g(S)-r
and
|S_{r}\setminus J|=r+1
and so

c(S)=c(I)\leq 2g(S_{r})+|S_{r}\setminus J|=2(g(S)-r)+r+1=2g(S)-r+1,

which proves the result.
∎

Corollary 3.4
.

Given a numerical semigroup
S
,
f(S)\leq 2g(S)-t(S)
, and

(1)

2n(S)+t(S)-1\leq c(S)\leq 2g(S)-t(S)+1.

Remark 3.5
.

For the so–called symmetric semigroups we have in fact an equality in (
1
) as they verify
[
5
, Ch.3.1]

g(S)=\frac{c(S)}{2},\quad t(S)=1,

and in fact any of these two conditions can be used to define the family of symmetric semigroups.

However, the equality in (
1
) is not a characterization of symmetric semigroups, as shown by

S_{5}=\langle 5,6,7,9\rangle=\big\{0,5,6,7,9,\rightarrow\big\},

with
f(S)=8
,
g(S)=5
,
\operatorname{PF}(S_{5})=\big\{4,8\big\}
.

In
[
2
, Thm.7]
we can find a (multiple) characterization of the equality case. Translated to our situation, we have an equality in (
1
) if and only if

\operatorname{PF}(S)=\Big\{a\in S_{t(S)}\;|\;2g-t(S)-1-a\in S_{t(S)}\Big\}.

In general, of course, if one adds elements outside
\operatorname{PF}(S)
(or if does not do in the orderly way depicted in the above lemma), the semigroup structure might well be lost. This will be illustrated in our first MED closure process.

4.
Computing
\operatorname{MED}(S)
: The Apéry saturation

We will use the Apéry sets for a general construction on this regard.

Definition 4.1
.

Let
S
be a numerical semigroup,
s\in S
, with

\widehat{\operatorname{Ap}}(S,s)=\big\{w_{1},\ldots,w_{s}\big\}.

We will call the Apéry saturation of
S
(w.r.t.
s
) the set

S\cup\big\{w_{k}-s\;\big|\;\mbox{exists }(w_{i},w_{j},w_{k})\mbox{ with }w_{i}+w_{j}=w_{k}\big\}.

We will give now an algorithm for computing
\operatorname{MED}(S)
for a given numerical semigroup
S
, with
m(S)=m
, based on the results from the previous sections. For a given numerical semigroup
S
, with
m(S)=m
, we consider the following operations:

Step 1)

Compute
\widehat{\operatorname{Ap}}(S,m)=\big\{m=a_{0},\ldots,a_{m-1}\big\}
, with
a_{i}\equiv i\mod m
.

Step 2)

Consider

\widehat{S}=\Big\langle S\cup\big\{a_{k}-m\;\big|\;\mbox{exists }(a_{i},a_{j},a_{k})\mbox{ with }a_{i}+a_{j}=a_{k}\big\}\Big\rangle,

And we define inductively the following sequence:

S^{1}=S,\quad S^{n+1}=\widehat{S^{n}},\;\;\forall n\geq 1.

First, let us mention some basic facts of this procedure:

•

For every
n\geq 1
,
m(S^{n})=m
, as in the Apéry saturation we are adding elements

a_{k}-m=(a_{i}+a_{j})-m,\mbox{ with }a_{i},a_{j}\geq m.

•

For every
n\geq 1
, we have that
S^{n}\subseteq S^{n+1}
. In fact,
S^{n+1}=S^{n}
if and only if
S^{n}
is a MED numerical semigroup, as it implies that
\widehat{\operatorname{Ap}}(S^{n},m)
is a sum–free set.

•

If we order
\widehat{\operatorname{Ap}}(S,m)
with the partial ordering
\leq_{S}
introduced at the end of Section 1, it is immediate to see that we are adding to the new semigroup
\widehat{S}
one element for every element in
\widehat{\operatorname{Ap}}(S,m)
which is not minimal. In particular, we are adding
\operatorname{PF}(S)
, except those of the form
a_{i}+m(S)
, where
a_{i}
is in the generating set.

•

The Apéry saturation is
not
, in general, a numerical semigroup (see Example
4.5
below)

We can show now the fundamental result of this section: that the previous algorithm computes, in fact,
\operatorname{MED}(S)
.

Theorem 4.2
.

The previous sequence becomes stationary

S=S^{1}\subsetneq S^{2}\subsetneq\ldots\subsetneq S^{l-1}\subsetneq S^{l}=S^{l+1}=\ldots,

with
S^{l}=\operatorname{MED}(S)
.

Proof.

The sequence is increasing with respect to set–inclusion and the set of numerical semigroups containing
S
with multiplicity
m
is finite, so we must get to a stationary term, therefore an element of
{\mathcal{A}}_{S}
(in the notation of Theorem
2.7
). We must prove that this stationary term is, in fact, the MED closure of
S
.

Assume then that
T\in{\mathcal{A}}_{S}
and suppose we have

\widehat{\operatorname{Ap}}(S,m)=\big\{m=a_{0},\ldots,a_{m-1}\big\}

with
a_{i}+a_{j}=a_{k}
for some
\{i,j,k\}\subset\big\{0,\ldots,m-1\}
. Then
a_{i},a_{j}\in T
and
T
is a MED numerical semigroup. Therefore
m
is an Arf element of
T
and

a_{i}+a_{j}-m=a_{k}-m\in T.

This shows that if
S\subset T
, then
\widehat{S}\subset T
as well and therefore
{\mathcal{A}}_{S}={\mathcal{A}}_{\widehat{S}}
. Inductively,

{\mathcal{A}}_{S}={\mathcal{A}}_{S^{1}}=\ldots={\mathcal{A}}_{S^{l}}

and therefore
\operatorname{MED}(S)=\operatorname{MED}(S^{1})=\ldots=\operatorname{MED}(S^{l})=S^{l}
. This finishes the proof.
∎

Let us give then some examples to illustrate how the procedure works.

Example 4.3
.

Take
S_{4}=\langle 7,24,33\rangle
, where

\widehat{\operatorname{Ap}}(S_{4},7)=\big\{7,57,72,24,81,33,48\big\}

We have the following sums in
\widehat{\operatorname{Ap}}(S_{4},7)
:

48=24+24,\quad 57=24+33,\quad 72=48+24,\quad 81=48+33.

Therefore we would have to add
41
,
50
,
65
and
74
to the generators of
S_{4}=S_{4}^{1}
in order to get
S_{4}^{2}
. In particular we are adding
\operatorname{PF}(S_{4})=\big\{65,74\big\}
, as expected (as neither 72, nor 81 are generators). Note, however, that
74
is redundant and hence

S_{4}^{2}=\langle 7,24,33,41,50,65\rangle.

Now,

\widehat{\operatorname{Ap}}(S_{4}^{2},7)=\big\{7,50,65,24,74,33,41\big\},

where we only have one sum, precisely
74=33+41=50+24
. That situation of having more than one sum giving the same element can easily happen, but we are actually only interested in
74
for the next step. Therefore,

S_{4}^{3}=\langle 7,24,33,41,50,65,67\rangle,

which is not MED, as

\widehat{\operatorname{Ap}}(S_{4}^{3},7)=\big\{7,50,\mathbf{65},\mathbf{24},67,33,\mathbf{41}\big\}.

Iterating one more time we finally get

S_{4}^{4}=\langle 7,24,33,41,50,58,67\rangle,

which is MED, as
\widehat{\operatorname{Ap}}(S_{4}^{3},7)
is precisely the set of minimal generators.

Example 4.4
.

The preceding example showed a sequence with a strictly increasing dimension (until it became stationary, of course). This might not be the case. Take, for instance:

S_{5}=\langle 4,7,17\rangle,

where

\widehat{\operatorname{Ap}}(S_{5},4)=\big\{4,17,14,7\big\},

and we have
14=7+7
and hence we have to add
10
to make the Apéry saturation, and then

S_{5}^{2}=\langle 4,7,10\rangle.

Example 4.5
.

It can happen that some elements in
\operatorname{PF}(S)
are not added to
\widehat{S}
. Take, for instance
[
5
, Ex.1.27]
,

S_{6}=\langle 11,12,13,32,53\rangle,

where
\operatorname{PF}(S_{6})=\big\{21,40,41,42\big\}
and

\widehat{\operatorname{Ap}}(S_{6},11)=\big\{11,12,13,25,26,38,39,51,52,53,32\big\}.

The Apéry saturation of
S_{6}
w.r.t. 11 is given by

S_{6}\cup\big\{14,15,27,28,40,41\big\},

so we have failed to add, not only all the set
\operatorname{PF}(S_{6})
, but
f(S_{6})=42
. However, once we consider the semigroup
S_{6}^{2}
, we have
42\in S_{6}^{2}
, but
\operatorname{PF}(S_{6})\not\subset S_{6}^{2}
as
21\notin S_{6}^{2}
.

Example 4.6
.

Consider again
S_{1}=\langle 7,9,11,15\rangle
, and remember

\widehat{\operatorname{Ap}}(S_{1},7)=\big\{7,15,9,24,11,26,20\big\},

therefore the Apéry saturation is

S_{1}\cup\big\{13,17,19\big\}

and we get to

\operatorname{MED}(S_{1})=\langle 7,9,11,13,15,17,19\rangle

5.
Computing
\operatorname{MED}(S)
: An effective solution

After giving an Apéry-based solution to the problem we aim to give an effective one, in the sense that we can control (or, at the very least, bound) the number of operations involved.

Remark 5.1
.

Let
S
be a numerical semigroup, and suppose
u,v\in G(S)
are such that
u>v
and
u\equiv v\pmod{m(S)}
. Then, as
u=v+km(S)
for some
k\geq 0
, we have
\langle S\cup\{u\}\rangle\subseteq\langle S\cup\{v\}\rangle
.

Lemma 5.2
.

Let
S
be a numerical semigroup, and
\{a_{1},\dots,a_{n}\}\subset S
. Then for every set of non negative integers
\{k_{1},\dots,k_{n}\}
with

K=\sum_{i=1}^{n}k_{i}\geq 2,

we have

\sum_{i=1}^{n}k_{i}a_{i}-(K-1)m(S)\in\operatorname{MED}(S).

Proof.

We will prove it by induction in
K
. If
K=2
the result follows since
m(S)
is Arf in
\operatorname{MED}(S)
.

Suppose it is true for a certain
K\geq 2
and we want to prove it for the next case
K+1=\sum_{i=1}^{n}k_{i}
. We can assume, without loss of generality, that
k_{1}\geq 1
. Then

\displaystyle\sum_{i=1}^{n}k_{i}a_{i}-Km(S)

\displaystyle=

\displaystyle a_{1}-m(S)+\sum_{i=1}^{n}k_{i}^{\prime}a_{i}-(K-1)m(S)

\displaystyle=

\displaystyle A_{1}+A_{2}-m(S),

where
k_{i}^{\prime}=k_{i}
if
i\geq 2
,
k_{1}^{\prime}=k_{1}-1
,

A_{2}=\sum_{i=1}^{n}k_{i}^{\prime}a_{i}-(K-1)m(S)\in\operatorname{MED}(S),

by the induction hypothesis and
A_{1}=a_{1}\in S\subset\operatorname{MED}(S)
. Hence

\sum_{i=1}^{n}k_{i}a_{i}-Km(S)\in\operatorname{MED}(\operatorname{MED}(S))=\operatorname{MED}(S)

as we wanted.
∎

Lemma 5.3
.

Let
a_{1}<\cdots<a_{n}
be a minimal set of generators of a semigroup
S
and suppose
a
is in the minimal set of generators of
\operatorname{MED}(S)
. Then we can write

a=\sum_{i=2}^{n}k_{i}a_{i}-(K-1)m(S),

for some
k_{i}\geq 0
, and

K=\sum_{i=2}^{n}k_{i}\leq\frac{c(S)}{a_{2}-m(S)}.

Proof.

By construction for
2\leq i\leq n
,
a_{i}=a_{1}+r_{i}
, where
r_{i}\geq 1
and such that
\gcd(a_{1},r_{2},\dots,r_{n})=1
. By Theorem
2.9

a=(d+1)a_{1}+\sum_{i=2}^{n}k_{i}r_{i},

for some
d,k_{i}\geq 0
for
i=2,\dots,n
. Letting
K=\sum_{i=2}^{n}k_{i}
we see that

a=dm(S)+\sum_{i=2}^{n}k_{i}(r_{i}+m(S))-(K-1)m(S).

But by the previous lemma,

\sum_{i=2}^{n}k_{i}(r_{i}+m(S))-(K-1)m(S)\in\operatorname{MED}(S),

and hence
d=0
by minimality of
a
and the first part of the lemma follows.

It remains to prove the upper bound. Now since
a
is a minimal generator of
\operatorname{MED}(S)
and must have been added in some Apéry saturation, it is direct that
a\leq c(S)+m(S)
. Writing as before

a=\sum_{i=2}^{n}k_{i}a_{i}-(K-1)m(S),

we have then

Ka_{2}-(K-1)m(S)\leq\sum_{i=2}^{n}k_{i}a_{i}-(K-1)m(S)=a\leq c(S)+m(S),

and the result now follows.
∎

In order to estimate complexity orders later on an upper bound for the conductor of the semigroup might be handy and there are many available such bounds in the literature depending on the usual invariants of
S
. For example we know by
[
11
]
that, if
S
is generated by
m(S)=a_{1}<\cdots<a_{n}
, then

(2)

c(S)\leq 2a_{n}\left[\frac{m(S)}{n}\right]-m(S)+1.

From this bound, and the previous result, let us write

d(S)=\frac{\displaystyle 2a_{n}\left[\frac{m(S)}{n}\right]-m(S)+1}{a_{2}-m(S)},

although the numerator can be modified to include any other bound (or expression) of
c(S)
, should this be convenient. In particular, note that
K\leq d(S)
in the statement of Lemma
5.3
.

We can now present an alternative algorithm to compute
\operatorname{MED}(S)
, one whose number of steps can be controlled by the previous results. The input will be
S
, given by a minimal set of generators
a_{1}<\cdots<a_{n}
. This system contains
n-1
non–zero classes modulo
a_{1}=m(S)
.

Lemma 5.4
.

Let
S=\{m=a_{1}<\dots<a_{n}\}
given by a minimal set of generators and
M=\{i_{1},\dots,i_{n-1}\}
the non–zero residue classes modulo
m
represented by the generators.

For each
1\leq i<m
, let us define
c_{i}
to be any element of
S
with
c_{i}\geq d(S)\sum_{i=2}^{n}a_{i}
and such that
c_{i}\equiv i\pmod{m}
.
Consider now

K_{i}=\max\left\{\sum_{j=1}^{n}k_{ij}\,:\,\sum_{j=1}^{n}k_{ij}a_{j}=c_{i}\right\}

and
g_{i}=c_{i}-(K_{i}-1)m
. Then

\operatorname{MED}(S)=\{m=g_{0},\dots,g_{m-1}\}.

Proof.

First note that
g_{i}
is independent of the selection of
c_{i}
. Indeed, by Lemma
5.3
we know that the minimal element of MED(S) in the congruent class
i
is of the

g_{i}=C_{i}-(K-1)m
for some

C_{i}=\sum_{j=2}^{n}k_{i}a_{i}\leq d(S)\sum_{j=2}^{n}a_{i}.

Hence for any
c_{i}
in the conditions of the lemma, we will have
c_{i}=C_{i}+tm
for some
t\geq 0
but then, writing
k_{1}=t
,

c_{i}=\sum_{j=1}^{n}k_{i}a_{i},\quad\sum_{j=1}^{n}k_{i}=K+t

and, therefore,

c_{i}-(t+K-1)m=C_{i}-(K-1)m=g_{i}.

Now, note that by Lemma
5.2
,
g_{i}\in\operatorname{MED}(S)
, and the semigroup generated by
\{m=g_{0},\dots,g_{m-1}\}
contains
S
, so the proof would end if we proof that
\{g_{0},\dots,g_{m-1}\}
is a sumfree set. But

g_{i}+g_{l}=c_{i}+c_{l}-(K_{i}+K_{l}-2)m>c_{i}+c_{l}-(K_{i}+K_{l}-1)m\geq c_{i}+c_{l}-(K_{i+l}-1)m=g_{i+l}.

For the last inequality note that we can take
c_{i+l}=c_{i}+c_{l}\geq d(S)\sum_{i=2}^{n}a_{i}
, hence

c_{i+l}=\sum_{j=1}^{n}\left(k_{ij}+k_{lj}\right)a_{j}

and then by maximality
\sum_{j=1}^{n}(k_{ij}+k_{lj})\leq K_{i+l}
, so the sum is not in
\{g_{0},\dots,g_{m-1}\}
.
∎

Theorem 5.5
.

Let
m
be a positive integer fixed and
S=\{m=a_{1}<\dots<a_{n}\}
be a semigroup given by a minimal set of generators. Then we can compute
\operatorname{MED}(S)
in time linear in the size of the generators.

Proof.

The first step in the algorithm will be selecting for each congruence class
1\leq i<m-1
an element
c_{i}\in S
,
c_{i}\geq d(S)\sum_{i=2}^{n}a_{i}
. Then we need to find the maximum
\sum_{i=1}^{n}k_{ij}
among the possible representations

c_{i}=\sum_{i=1}^{n}k_{ij}a_{j}.

It is clear that if
k_{ij}=r_{ij}+u_{ij}a_{1}
with
0\leq r_{ij}<m-1
, then

k_{i1}a_{1}+k_{ij}a_{j}=(k_{i1}+u_{ij}a_{j})a_{1}+r_{ij}a_{j}

and

(3)

k_{i1}+k_{ij}=k_{i1}+r_{ij}+u_{ij}a_{1}\leq k_{i1}+u_{ij}a_{j}+r_{ij}

In particular the maximum will be attained for some values
k_{ij}\leq m-1
for any
2\leq j\leq n
. Hence, we will select at random
k_{ij}
for
2\leq j\leq n-1
and

k_{in}\equiv i-\sum_{j=2}^{n-1}k_{ij}a_{j}.

Finally
k_{i1}=(\sum_{j=2}^{n}k_{ij}a_{j}-i)/a_{1}

Hence, since
k_{ij}\leq m-1
,

\sum_{j=2}^{n-1}k_{ij}\leq(n-2)(m-1),

so it is like selecting at most
(n-2)(m-1)
elements among
a_{2},\dots,a_{n-1}
with repetitions which is

\binom{(n-2)(m-1)}{n}<\frac{2^{n\log m}}{\sqrt{n}}

for the last inequality see
[
12
, p.309]
and we need to do it
m-2
times, one for each congruence class. Hence, since dividing
(\sum_{j=2}^{n}k_{ij}a_{j}-i)
by
a_{1}
takes
O(\log m\log a_{n})
bit operations, finding the maximum will be bouded by

O\left(\log m\log a_{n}+\frac{m}{\sqrt{n}}2^{n\log m}\right)

bit operations.
∎

6.
Final remarks

In this paper we have isolated the Arf property for elements of a numerical semigroup, a property can be expressed in terms of the Apéry set of the element. This allows us to illustrate clearly the difference between MED and Arf numerical semigroups.

As an application of this, we have described two new algorithms to compute the MED closure of a given semigroup, taking advantage of the previous description and highlighting some new features of the minimal system of generators of said clousure. For the last of them we can actually compute its complexity in terms of the generators. To our knowledge, it is the first result in the literature in this regard.
