Flow methods for cooperative games with generalized coalition configuration
Encarnación Algaba, Eric Rémila, Philippe Solal

Abstract
This paper introduces the class of cooperative games with generalized coalition configuration. This new class of games corresponds to cooperative games with coalition configuration and restricted cooperation. A coalition configuration is a collection of coalitions covering the agent set. The restriction of cooperation between agents is represented by a set system on each element of the coalition configuration. A coalition profile is a list of feasible coalitions, one for each element of the coalition configuration. A coalition profile function associates a worth with each coalition profile. Based on this framework, we define and axiomatically characterize marginal values whose coefficients induce a unitary flow on the product digraph obtained from these set systems. Next, we propose a two-step procedure, inspired by Owen’s procedure, to construct flow methods as above. Then, we show that the associated flow is decomposable into two flows. Finally, we use two axioms to characterize the flows that can be decomposed in this way, and hence the flow methods constructed using our procedure.

Introduction

Given a finite set of agents, a coalition configuration is a collection of coalitions on that set such that the union of these coalitions is equal to this set of agents (Albizuri et al.
[
2
]
).
We consider cooperative games with coalition configuration, with the novelty that for each element of the coalition configuration, a set system represents the set of coalitions that can be formed within this element, thus generalizing coalition configuration structures considered so far in the literature.
These structures are referred to as generalized coalition configurations. In this setting, a coalition profile is defined as a list of feasible coalitions, one for each element of the coalition configuration. This profile represents the way in which the population organizes itself to cooperate in each element of the coalition configuration. The coalition profile function associates a worth to each feasible coalition profile.
A value for these cooperative games with generalized coalition configuration is a function that associates a payoff vector to each game of this class. As a first step, we consider values that satisfy three principles inspired by the axioms for cooperative games with transferable utility (in short TU-games): Efficiency, Linearity and the Null agent principle. We show that these three principles induce marginalist values whose coefficients lead to a unitary flow on the product digraph constructed from the cartesian product of the covering relations of the set systems (Theorem
1
and Theorem

[

[

In a second step, we construct Owen-type values
[

]

The flow passes through the edges of the directed hypercube formed by all the coalition profiles that can be formed between the elements of the coalition configuration. In a second step of the procedure, the agents of each element of the coalition configuration play a cooperative game that takes into account both the cooperation restrictions in that element of the coalition configuration and the result of the previous step. A flow method is applied at this step of the procedure. The flow passes through the edges of the directed graph associated with the covering relation of the set system of this element of the coalition configuration. We obtain the following results.

Firstly, Theorem
3

Moreover, this flow can be decomposed into two flows. More precisely, it can be calculated as the product of the flow resulting from the first step of the procedure and the flow resulting from the second step of the procedure. 2.2
Flows

Given a normal set system and its associated directed graph
\Gamma_{\cal F}=({\cal F},E_{\cal F})
a
flow
on
\Gamma_{\cal{F}}
is a mapping
\Lambda:E_{\cal F}\longrightarrow\mathbb{R}
that satisfies the following

:

\forall K\not\in\{\emptyset,N\},\quad\sum_{(K^{\prime},K)\in E_{\cal F}}\Lambda(K^{\prime},K)=\sum_{(K,K^{\prime\prime})\in E_{\cal F}}\Lambda(K,K^{\prime\prime}).

The
value

V(\Lambda)
of a flow
\Lambda
on
\Gamma_{\cal F}
is given by

V(\Lambda)=\sum_{(\emptyset,K)\in E_{\cal F}}\Lambda(\emptyset,K)=\sum_{(K,N)\in E_{\cal F}}\Lambda(K,N).

A flow
\Lambda
is

V(\Lambda)=1
.

A

of
\Gamma_{\cal F}
is a partition of
{\cal F}
formed by two subsets
{\cal F}_{\emptyset}
and
{\cal F}_{N}
such that
\emptyset\in{\cal F}_{\emptyset}
and
N\in{\cal F}_{N}
. Indifferently, a cut
({\cal F}_{\emptyset},{\cal F}_{N})
is sometimes seen as the set of directed edges of

with an endpoint in
{\cal F}_{\emptyset}
and the other endpoint in
{\cal F}_{N}
.
The
value of a cut

({\cal F}_{\emptyset},{\cal F}_{N})
is defined as the net flow across the cut:

\sum_{(K^{\prime},K)\in E_{\cal F}\cap({\cal F}_{\emptyset}\times{\cal F}_{N})}\Lambda(K^{\prime},K)-\sum_{(K,K^{\prime})\in E_{\cal F}\cap({\cal F}_{N}\times{\cal F}_{\emptyset})}\Lambda(K,K^{\prime}).

It is known that the value
V(\Lambda)
of a flow
\Lambda
is equal to the value of any cut
({\cal F}_{\emptyset},{\cal F}_{N})
(see, e.g., Gross and Yellen
[
22
]
, Proposition 13-1-3):

V(\Lambda)=\sum_{(K^{\prime},K)\in E_{\cal F}\cap({\cal F}_{\emptyset}\times{\cal F}_{N})}\Lambda(K^{\prime},K)-\sum_{(K,K^{\prime})\in E_{\cal F}\cap({\cal F}_{N}\times{\cal F}_{\emptyset})}\Lambda(K,K^{\prime}).

Cooperative games with generalized coalition configuration

Let
N=\{1,2,\ldots,n\}
be a finite agent set of size
n\in\mathbb{N}
. Every subset of
N
is called a
coalition
.
Following Albizuri et al.
[
2
]
, a
coalition configuration
is a list
\mathcal{P}=(P_{1},P_{2},\ldots,P_{m})
,

N

\bigcup_{q=1}^{m}P_{q}=N.

These structures generalizes the so-called coalition structures introduced by Aumann and Drèze
[
13
]

coalition structure
is a coalition configuration
\mathcal{P}
that forms a partition of
N
.

However, the assumption of full cooperation within each coalition of a coalition configuration is not always realistic, as there may be asymmetries or incompatibilities between agents in each coalition of a coalition configuration.
This is why we introduce the notion of
generalized coalition configuration
which takes into account the possibilities of restricted cooperation in each element of the coalition configuration.
Hence, denote by
M=\{1,\ldots,m\}
the index set whose elements label the elements of
\mathcal{P}
. For each
q\in M
,
(P_{q},{\cal F}_{q})
represents a normal set system.
Each element of
{\cal F}_{q}
is a
feasible coalition
of
P_{q}
. Denote by
{\cal F}
the cartesian product

\prod_{q=1}^{m}{\cal F}_{q}.

A
feasible coalition profile
is an element

of
{\cal F}
, and
\emptyset_{M}
denote the empty coalition profile
(\emptyset,\ldots,\emptyset)
.
For each
{\cal K}
and

denotes the restricted profile without component
q

The

\mu({\cal K})=\bigl\{q\in M:K_{q}\not=\emptyset\bigr\}.

The set
{\cal F}
can be ordered through the product relation

\forall{\cal K},{\cal K}^{\prime}\in{\cal F},\quad{\cal K}\subseteq^{M}{\cal K}\,\,\mbox{ if }\,\,\forall q\in M,\,\,K_{q}\subseteq K^{\prime}_{q}.

We say that the coalition profile

. This is also the case for a normal augmenting system. An augmenting system is a convex geometry if and only if it is normal and closed under intersection (see Bilbao
[
17
]
).

A set system is
regular
if (g) it is normal and (h) each of its maximal paths is of length
n
.

Every convex geometry (normal augmenting set system respectively) is a regular set system but not the other way around. The marginalist values and flow methods for TU-games with convex geometry, TU-games with normal augmenting set system and regular TU-games are themselves a generalization of the marginalist values and flow methods for TU-games with no restriction on cooperation studied by Weber
[
31
]
.

Following Weber
[
31
]
, Bilbao
[
16
]
, Bilbao and Edelman
[
18
]
, Lange and Grabisch
[
24
]
, Bilbao and Ordóñez
[
19
]
, and Aguilera et al.
[
10
]
characterize the marginalist values by using two well-known principles: the linearity of the solution in
v
and the principle of null payoff for agents with null contributions. To obtain the family of flow methods, it is added the standard principle of efficiency establishing that the worth of the grand coalition
N
is fully redistributed to its members. In the next section, our purpose is to characterize marginalist values and flow methods using the same principles but adapting them to our broader context
{\cal G}_{N,{\cal P},{\cal F}}
.

5
Characterization of marginalist values and flow methods

We introduce the axioms of Linearity, Null agent, and Efficiency for a value on
{\cal G}_{N,{\cal P},{\cal F}}
. Linearity
is a straightforward generalization of the same principle for TU-games. The principle of null agent needs to be adapted and interpreted in this setting. An agent
i\in N
is called null in a game in
{\cal G}_{N,{\cal P},{\cal F}}
if the variation in worth induced by each pair of coalition profiles that are the endpoints of the directed edges
E_{\cal F}^{i}
of
\Gamma_{\cal F}^{i}
is null. In other words, each time
i
joins, possibly with other agents, a feasible coalition of an element
P_{q}
of
{\cal P}
to which it belongs, the variation in worth is null. In this sense, the arrival of this agent, possibly with other agents, in any feasible coalition of each element
P_{q}
to which it belongs adds no worth. The null agent axiom states that such a null agent obtains a null payoff. Efficiency states that the worth of the coalition configuration
{\cal P}
is fully redistributed to its members.

Linearity
. A value
\Phi
on
{\cal G}_{N,{\cal P},{\cal F}}
is linear if for each
(N,v,{\cal P},{\cal F})
and
(N,v^{\prime},{\cal P},{\cal F})
in
{\cal G}_{N,{\cal P},{\cal F}}
and
\alpha\in\mathbb{R}
, it holds that:

\Phi(N,\alpha v+v^{\prime},{\cal P},{\cal F})=\alpha\Phi(N,v,{\cal P},{\cal F})+\Phi(N,v^{\prime},{\cal P},{\cal F}),

where the coalition profile functions
\alpha v
and
v+v^{\prime}
are defined as
(\alpha v)({\cal K})=\alpha v({\cal K})
and
(v+v^{\prime})({\cal K})=v({\cal K})+v^{\prime}({\cal K}),
for each feasible coalition profile
{\cal K}\in{\cal F}
.

An agent is
null
in
(N,v,{\cal P},{\cal F})
if
v({\cal K})=v({\cal K}^{\prime})
for each
({\cal K},{\cal K^{\prime}})\in E_{\cal F}^{i}
.

Null agent axiom
. A value
\Phi
on
{\cal G}_{N,{\cal P},{\cal F}}
satisfies the Null agent axiom if for each
(N,v,{\cal F})\in{\cal G}_{N,{\cal P},{\cal F}}
and each null agent
i
in
(N,v,{\cal P},{\cal F})
, it holds that:

\Phi_{i}(N,v,{\cal P},{\cal F})=0.

Efficiency
. A value
\Phi
on
{\cal G}_{N,{\cal P},{\cal F}}
is Efficient if for each
(N,v,{\cal P},{\cal F})\in{\cal G}_{N,{\cal P},{\cal F}}
, it holds that:

\sum_{i\in N}\Phi_{i}(N,v,{\cal P},{\cal F})=v({\cal P}).

Theorem 1
.

A value
\Phi
on
{\cal G}_{N,{\cal P},{\cal F}}
is marginalist as defined in (
3

The above result relies on the following lemma.

Lemma 1

Let

Initialization

\displaystyle x(j)

\displaystyle=

\displaystyle x^{\prime}(j)-\frac{x(j_{0})}{d_{j_{0}}}

\displaystyle=

\displaystyle\sum_{j^{\prime}\in V\setminus j_{0}:(j^{\prime},j)\in E_{j_{0}}}\lambda_{(j,j^{\prime})}-\sum_{j^{\prime}\in V\setminus j_{0}:(j,j^{\prime})\in E_{j_{0}}}\lambda_{(j,j^{\prime})}-\lambda(j,j_{0})

\displaystyle\sum_{j^{\prime}\in V:(j^{\prime},j)\in E}\lambda_{(j,j^{\prime})}-\sum_{j^{\prime}\in V:(j,j^{\prime})\in E}\lambda_{(j,j^{\prime})}.

Obviously, for each other vertex

6
Two-step flow methods

When agents are arranged in a coalition configuration, the payoff allocation procedure can be designed as a two-step procedure. In the first step, the procedure settles the payoff allocation between the elements of the coalition configuration. In the second step, the procedure settles the payoff allocation between the agents in each element of the coalition configuration, taking into account the result of the first step.
In the particular case where the coalition configuration
{\cal P}
is a partition of the agent set
N
and the set function

is defined over
2^{N}
, that is
(N,v)
is a TU-game without restricted cooperation,
Owen
[
27
]
proposes such a procedure by applying the Shapley value (Shapley
[
28
]
) at each step. The resulting value is known as the Owen value. Note that the Shapley value is a flow method as it satisfies the principles of null agent, linearity and efficiency (see Weber
[
31
]
).
Albizuri et al.
[
2
]
apply Owen’s procedure to situations where
{\cal P}
is not necessarily a partition of
N
, but maintain the assumption that
(N,v)
is a TU-game without restricted cooperation. The resulting value is the configuration value.
Two-step procedures are subsequently used in a broader context where the TU-game
(N,v)
is augmented by a partition
{\cal P}
and a communication graph on
N
that represents the bilateral communication constraints among the agents. In this context, different values can be applied at each step such as the Myerson value (Myerson
[
26
]
) or the Average tree solution (Herings et al.
[
23
]
) (see, e.g., Vázquez-Brague et al.
[
30
]
, Brink van den et al.
[
20
]
, Alonso-Meijide et al.,
[
11
]
, Béal et al.
[
15
]
).

In this section, we design a two-step flow procedure for games in
{\cal G}_{N,{\cal P},{\cal F}}
where at each step of the procedure a flow method is applied. Pick any game
(N,v,{\cal P},{\cal F})\in{\cal G}_{N,{\cal P},{\cal F}}
. Denote by
M=\{1,\ldots,m\}
the index set of the elements of
{\cal P}
.
The procedure results in a two-step flow method where the flow passing through directed edges of the product digraph
\Gamma_{\cal F}
can be decomposed into two types of flows: a flow on the directed edges of the digraph induced by the set system
(M,(\{q\})_{q\in M})
and the flows passing trough the directed edges of each digraph
\Gamma_{{\cal F}_{q}}
associated with the set system
(P_{q},{\cal F}_{q})
,
q\in M
.

To construct two-step flow methods, we need to consider two other types of subdomains of
{\cal G}_{N,{\cal P},{\cal F}}
. These domains are constructed from
N
,
{\cal P}
and
{\cal F}
. To introduce them, some definitions are in order. Denote by
{\cal P}_{M}
the finest partition
(\{q\})_{q\in M}
of
M
and by
{\cal F}_{M}
the cartesian product of the trivial set systems
(\emptyset,\{q\})
,
q\in M
. We introduce:

– the subdomain
{\cal G}_{M,{\cal P}_{M},{\cal F}_{M}}
of games of the form
(M,v_{M},{\cal P}_{M},{\cal F}_{M})
, where only the coalition profile function
v_{M}:{\cal F}_{M}\longrightarrow\mathbb{R}
can vary. Note that the corresponding digraph
\Gamma_{{\cal F}_{M}}
is a directed hypercube of dimension
m
;

– for each
q\in M
, the subdomain
{\cal G}_{P_{q},(P_{q}),{\cal F}_{q}}
of games of the form
(P_{q},v_{q},(P_{q}),{\cal F}_{q})
where only the coalition profile function
v_{q}:{\cal F}_{q}\longrightarrow\mathbb{R}
can vary.

Following the usual terminology, games in
{\cal G}_{M,{\cal P}_{M},{\cal F}_{M}}
are
upper-games
of the original game and games in
{\cal G}_{P_{q},(P_{q}),{\cal F}_{q}}
are
q
-lower games
of the original game.

Notation
Since on each of these subdomains the corresponding digraph is fixed once and for all, coefficient functions of a marginalist value
\Phi
will be denoted by
\lambda_{i}^{\Phi}
without mentioning the label of the digraph. The context should clearly indicate if
\Phi
, and so
\lambda_{i}^{\Phi}
, is a value on
{\cal G}_{N,{\cal P},{\cal F}}
,
{\cal G}_{M,{\cal P}_{M},{\cal F}_{M}}
or
{\cal G}_{P_{q},(P_{q}),{\cal F}_{q}}
.

P_{r}

.

.

Denote by
\Phi^{M}
a flow method on

.

A value
\Phi^{0}
is a

on
{\cal G}_{N,{\cal P},{\cal F}}
if it exists

\Phi^{M}
on
{\cal G}_{M,{\cal P}_{M},{\cal F}_{M}}

\forall i\in N,\quad\Phi_{i}^{0}(N,v,{\cal P},{\cal F})=\sum_{q\in M:i\in P_{q}}\Phi_{i}^{q}(P_{q},v_{q},(P_{q}),{\cal F}_{q}),

(12)

where

\forall q\in M,\forall K_{q}\in{\cal F}_{q},\quad v_{q}(K_{q})=\Phi^{M}_{q}(M,v_{M}^{K_{q}},{\cal P}_{M},{\cal F}_{M}).

(13)

Remark 4
.

In any upper-game, the digraph
\Gamma_{{\cal F}_{M}}
corresponding to the set system

(M,{\cal F}_{M})
is the
m
-dimensional directed hypercube. It follows that
the coefficient function
\lambda_{q}^{\Phi^{M}}:E_{\Gamma_{{\cal F}_{M}}}^{q}\longrightarrow\mathbb{R}
associated with the flow method
\Phi^{M}
is such that

\forall{\cal R}_{S}\in{\cal F}_{M}:S\ni q,\quad\lambda_{q}^{\Phi^{M}}({\cal R}_{S\setminus q},{\cal R}_{S})=\Lambda^{\Phi^{M}}({\cal R}_{S\setminus q},{\cal R}_{S}).

Remark 5
.

The coalition profile function
v_{q}:{\cal F}_{M}\longrightarrow\mathbb{R}
in (

) is well-defined since

v_{q}(\emptyset_{M})=\Phi^{M}_{q}(M,v_{M}^{\emptyset},{\cal P}_{M},{\cal F}_{M})=0,

thanks to Remark
3
and the fact that any flow method satisfies the null agent axiom.

So an agent’s payoff in a game
(N,v,{\cal P},{\cal F})
is the sum of its payoffs in each
q
-lower game to which it belongs. For each
q
-lower game, the worth of a feasible coalition
K_{q}
is defined by the payoff obtained by the element
P_{q}
of the partition
{\cal P}
is the
K_{q}
-upper game, where
K_{q}
represents
P_{q}
. Furthermore, these payoffs result from flows passing through the directed edges of the digraphs
\Gamma_{{\cal F}_{q}}
and the directed hypercube associated with
(M,{\cal F}_{M})
.

To show that the above procedure induces well-defined flow methods on
{\cal G}_{N,{\cal P},{\cal F}}

\Phi^{0}
defined through the two-step procedure (

)-(

) is a marginalist value. In a second step, we show that
\Phi^{0}
is indeed a flow method.

Lemma 4
.

Let
\Phi^{0}
be a value on
{\cal G}_{N,{\cal P},{\cal F}}
defined through the two-step procedure (
12
)-(
13
). Then,
\Phi^{0}
is a marginalist value with coefficient functions

\lambda_{i}^{\Phi^{0}}:E_{\cal F}^{i}\longrightarrow\mathbb{R}
,
i\in N
, defined as follows: for each
({\cal K},{\cal K}^{\prime})\in E_{\cal F}^{i},

1.

if
({\cal K},{\cal K}^{\prime})\not\in E_{\cal F}^{R}\cap E_{\cal F}^{i}
, then
\lambda_{i}^{\Phi^{0}}({\cal K},{\cal K}^{\prime})=0
;

2.

if
({\cal K},{\cal K}^{\prime})=({\cal K}_{\mu({\cal K}^{\prime}),K_{q}},{\cal K}^{\prime}_{\mu({\cal K}^{\prime}),K^{\prime}_{q}})\in E_{\cal F}^{R}\cap E_{\cal F}^{i}
,
q\in\mu({\cal K}^{\prime})
, then

\lambda_{i}^{\Phi^{0}}({\cal K},{\cal K}^{\prime})=\Lambda^{\Phi^{M}}({\cal R}_{\mu({\cal K}^{\prime})\setminus q},{\cal R}_{\mu({\cal K}^{\prime})})\lambda_{i}^{\Phi^{q}}(K_{q},K^{\prime}_{q}).

Proof
Assume that
\Phi^{0}
is a value defined through the two-step procedure (
12
)-(
13
). Pick any game
(N,v,{\cal P},{\cal F})\in{\cal G}_{N,{\cal P},{\cal F}}
and
any
i\in N
. By definition (
12
)-(
13
) of
\Phi^{0}
, for each element
P_{q}\ni i
of
{\cal P}
, we have

\displaystyle\Phi_{i}^{q}(P_{q},v_{q},(P_{q}),{\cal F}_{q})

\displaystyle=

\displaystyle\sum_{(K_{q},K^{\prime}_{q})\in E^{i}_{{\cal F}_{q}}}\lambda^{q}_{i}(K_{q},K^{\prime}_{q})\bigl(v_{q}(K^{\prime}_{q})-v_{q}(K_{q})\bigr).

Using Remark
4
, the right-hand side of (
6
) writes

\displaystyle\sum_{(K_{q},K^{\prime}_{q})\in E^{i}_{{\cal F}_{q}}}\lambda^{q}_{i}(K_{q},K^{\prime}_{q})\biggl(\Phi^{M}_{q}(M,v_{M}^{K_{q}^{\prime}},{\cal P}_{M},{\cal F}_{M})-\Phi^{M}_{q}(M,v_{M}^{K_{q}},{\cal P}_{M},{\cal F}_{M})\biggr)

\displaystyle=

\displaystyle\sum_{(K_{q},K^{\prime}_{q})\in E^{i}_{{\cal F}_{q}}}\lambda^{q}_{i}(K_{q},K^{\prime}_{q})\biggl[\sum_{S\subseteq M:S\ni q}\Lambda^{\Phi^{M}}({\cal R}_{S\setminus q},{\cal R}_{S})\bigl(v_{M}^{K^{\prime}_{q}}({\cal R}_{S})-v_{M}^{K_{q}}({\cal R}_{S})\bigr)\biggr]

\displaystyle=

\displaystyle\sum_{(K_{q},K^{\prime}_{q})\in E^{i}_{{\cal F}_{q}}}\lambda^{q}_{i}(K_{q},K^{\prime}_{q})\biggl[\sum_{S\subseteq M:S\ni q}\Lambda^{\Phi^{M}}({\cal R}_{S\setminus q},{\cal R}_{S})\bigl(v({\cal K}_{S,K^{\prime}_{q}})-v({\cal K}_{S,K_{q}})\bigr)\biggr].

Taking into account Remark
2
, for each pair
((K_{q},K^{\prime}_{q}),{\cal R}_{S})\in E^{i}_{{\cal F}_{q}}\times{\cal F}_{M}
where
S\ni q
, there is a unique relevant directed edge
({\cal K},{\cal K}^{\prime})\in E^{R}\cap E^{i}_{\cal F}
such that

\mu({\cal K}^{\prime})=S
,
K_{q}
is the possibly empty coalition at coordinate
q
of
{\cal K}
and
K_{q}^{\prime}
is the nonempty coalition at coordinate
q
of
{\cal K}^{\prime}
. Conversely, for each relevant directed edge
({\cal K},{\cal K}^{\prime})\in E_{\cal F}^{R}\cap E^{i}_{\cal F}
such that
q_{({\cal K},{\cal K^{\prime}})}=q
, there is a pair
((K_{q},K^{\prime}_{q}),{\cal R}_{S})\in E^{i}_{{\cal F}_{q}}\times{\cal F}_{M}
such that
S\ni q
,
\mu({\cal K}^{\prime})=S
,
K_{q}
is possibly the empty coalition at coordinate
q
of
{\cal K}
and
K_{q}^{\prime}
is the coalition at coordinate
q
of
{\cal K}^{\prime}
.
Therefore, using (
6
), equation (
6
) can be rewritten as:

\Phi_{i}^{q}(P_{q},v_{q},(P_{q}),{\cal F}_{q})=\!\!\!\!\!\!\!\!\!\sum_{({\cal K},{\cal K^{\prime}})\in E^{R}_{\cal F}\cap E_{{\cal F}}^{i}:\atop q_{({\cal K},{\cal K^{\prime}})}=q}\lambda^{q}_{i}(K_{q},K^{\prime}_{q})\Lambda^{\Phi^{M}}({\cal R}_{\mu({\cal K}^{\prime})\setminus q},{\cal R}_{\mu({\cal K}^{\prime})})\bigl(v({\cal K}^{\prime})-v({\cal K})\bigr).

By definition,

\displaystyle\Phi^{0}_{i}(N,v,{\cal P},{\cal F})

\displaystyle=

\displaystyle\sum_{q\in M:i\in P_{q}}\Phi_{i}^{q}(P_{q},v_{q},(P_{q}),{\cal F}_{q}),

so that
\Phi^{0}_{i}(N,v,{\cal P},{\cal F})
is equal to

\sum_{q\in M:i\in P_{q}}\sum_{({\cal K},{\cal K^{\prime}})\in E^{R}_{\cal F}\cap E^{i}_{{\cal F}}:\atop q_{({\cal K},{\cal K^{\prime}})}=q}\lambda^{q}_{i}(K_{q},K^{\prime}_{q})\Lambda^{\Phi^{M}}({\cal R}_{\mu({\cal K}^{\prime})\setminus q},{\cal R}_{\mu({\cal K}^{\prime})})\bigl(v({\cal K}^{\prime})-v({\cal K})\bigr),

which shows that
\Phi^{0}
can be written as a marginalist value with coefficient functions
\lambda_{i}^{\Phi^{0}}:E_{\cal F}^{i}\longrightarrow\mathbb{R}
,
i\in N
, as in Point 1 and Point 2 of the statement of Lemma
4
.
∎From
\Phi^{0}
, define the function
\Lambda^{\Phi^{0}}:E_{\cal F}\to\mathbb{R}
as

\forall({\cal K},{\cal K^{\prime}})\in E_{\cal F},\quad\Lambda^{\Phi^{0}}({\cal K},{\cal K^{\prime}})=\sum_{i\in Q_{({\cal K},{\cal K^{\prime}})}}\lambda_{i}^{\Phi^{0}}({\cal K},{\cal K^{\prime}}),

(16)

where
\lambda_{i}^{\Phi^{0}}({\cal K},{\cal K^{\prime}})
is as in Point 1 and Point 2 of the statement of Lemma

.
The following theorem shows that

is a unitary flow on

, which admits a decomposition into two different types of unitary flows: the first type of flow consists on the unitary flow on the

-dimensional directed hypercube induced by the flow method
\Phi^{M}
applied to the upper games; the second type of flow corresponds to the unitary flows passing through the directed edges of the digraphs
\Gamma_{{\cal F}_{q}}
,
q\in M
. The latter flows are induced by the flow methods
\Phi^{q}
,
q\in M
, applied to the lower-games. Furthermore, if a directed edge of

\Gamma_{\cal F}
is not relevant, then the flow passing through it is null.

Theorem 3
.

Let
\Phi^{0}
be a value in
{\cal G}_{N,{\cal P},{\cal F}}
defined through the two-step procedure (
12
)-(
13
). Then,
\Phi^{0}
is a flow method such that
the flow
\Lambda^{\Phi^{0}}:E_{\cal F}\longrightarrow\mathbb{R}
is defined as:

1.

\forall({\cal K},{\cal K}^{\prime})=({\cal K}_{\mu({\cal K}^{\prime}),K_{q}},{\cal K}_{\mu({\cal K}^{\prime}),K^{\prime}_{q}})\in E_{\cal F}^{R},\,q\in\mu({\cal K}^{\prime})
,

\Lambda^{\Phi^{0}}({\cal K},{\cal K}^{\prime})=\Lambda^{\Phi^{M}}({\cal R}_{\mu({\cal K}^{\prime})\setminus q},{\cal R}_{\mu({\cal K}^{\prime})})\Lambda^{\Phi^{q}}(K_{q},K^{\prime}_{q});

2.

\Lambda^{\Phi^{0}}({\cal K},{\cal K}^{\prime})=0
, otherwise.

Proof
Consider any value
\Phi^{0}
in
{\cal G}_{N,{\cal P},{\cal F}}
defined through the two-step procedure (
12
)-(
13
). By Lemma
4
,
\Phi^{0}
is a marginalist
value with coefficient functions
\lambda_{i}^{0}
,
i\in N
, as in Point 1 and Point 2 of Lemma
4
. It remains to prove that the function
\Lambda^{\Phi^{0}}:E_{\cal F}\longrightarrow\mathbb{R}
defined as in (
16
) is a unitary flow. There are several cases to consider.

Case (a)
: if the coalition profile
{\cal K}\in{\cal F}
is not relevant. Then, by Point 1 of Lemma
4
,

\forall({\cal K},{\cal K}^{\prime})\in E_{\cal F},\quad\Lambda^{\Phi^{0}}({\cal K},{\cal K}^{\prime})=\sum_{i\in Q_{({\cal K},{\cal K^{\prime}})}}\lambda_{i}^{\Phi^{0}}({\cal K},{\cal K}^{\prime})=\sum_{i\in Q_{({\cal K},{\cal K}^{\prime})}}0=0,

and

\forall({\cal K}^{\prime},{\cal K})\in E_{\cal F},\quad\Lambda^{\Phi^{0}}({\cal K}^{\prime},{\cal K})=\sum_{i\in Q_{({\cal K^{\prime}},{\cal K})}}\lambda_{i}^{\Phi^{0}}({\cal K}^{\prime},{\cal K})=\sum_{i\in Q_{({\cal K},{\cal K^{\prime}})}}0=0,

so that the conservation constraints are trivially satisfied for any such coalition profile/vertex of
\Gamma_{\cal F}
.

Case (b)
: if the coalition profile
{\cal K}\in{\cal F}
is relevant, different from
\emptyset_{M}
,
{\cal P}
, and such for each
q\in\mu({\cal K})
,
K_{q}=P_{q}
, that is

{\cal K}={\cal K}_{\mu({\cal K})}
. In this case, if
({\cal K},{\cal K}^{\prime})\in E_{\cal F}
, then it is a relevant directed edge and
\mu({\cal K}^{\prime})=\mu({\cal K})\cup q
for some
q\in M\setminus\mu({\cal K})
. From this observation,
Lemma
4
and the definition of the flows
\Lambda^{\Phi^{q}}:E_{{\cal F}_{q}}\longrightarrow\mathbb{R}
, one obtains

\displaystyle\sum_{({\cal K},{\cal K}^{\prime})\in E_{\cal F}}\Lambda^{\Phi^{0}}({\cal K},{\cal K}^{\prime})

\displaystyle=

\displaystyle\sum_{({\cal K},{\cal K}^{\prime})\in E_{\cal F}}\sum_{i\in Q_{({\cal K},{\cal K}^{\prime})}}\lambda_{i}^{\Phi^{0}}({\cal K},{\cal K}^{\prime})

(17)

\displaystyle=

\displaystyle\!\!\!\!\!\sum_{q\in M\setminus\mu({\cal K})}\Lambda^{\Phi^{M}}({\cal R}_{\mu({\cal K})},{\cal R}_{\mu({\cal K})\cup q})\sum_{(\emptyset,K^{\prime}_{q})\in E_{{\cal F}_{q}}}\sum_{i\in K^{\prime}_{q}}\lambda_{i}^{\Phi^{q}}(\emptyset,K^{\prime}_{q})

\displaystyle=

\displaystyle\!\!\!\!\!\sum_{q\in M\setminus\mu({\cal K})}\Lambda^{\Phi^{M}}({\cal R}_{\mu({\cal K})},{\cal R}_{\mu({\cal K})\cup q})\sum_{(\emptyset,K^{\prime}_{q})\in E_{{\cal F}_{q}}}\Lambda^{\Phi^{q}}(\emptyset,K_{q}^{\prime}).

As
\Lambda^{\Phi^{q}}
defines a unitary flow on the digraph
\Gamma_{{\cal F}_{q}}
, (
17
) rewrites as

\sum_{({\cal K},{\cal K}^{\prime})\in E_{\cal F}}\Lambda^{\Phi^{0}}({\cal K},{\cal K}^{\prime})=\sum_{q\in M\setminus\mu({\cal K})}\Lambda^{\Phi^{M}}({\cal R}_{\mu({\cal K})},{\cal R}_{\mu({\cal K})\cup q}).

Proceeding in the same way for directed edges
({\cal K}^{\prime},{\cal K})\in E_{\cal F}
, one obtains,

\sum_{({\cal K}^{\prime},{\cal K})\in E_{\cal F}}\Lambda^{\Phi^{0}}({\cal K}^{\prime},{\cal K})=\sum_{q\in\mu({\cal K})}\Lambda^{\Phi^{M}}(\mu({\cal R}_{\mu({\cal K})\setminus q},{\cal R}_{\mu({\cal K})}).

As
\Lambda^{\Phi^{M}}
defines a unitary flow on the directed hypercube
\Gamma_{{\cal F}^{M}}
, it satisfies the conservation constraints and so

\displaystyle\sum_{({\cal K}^{\prime},{\cal K})\in E_{\cal F}}\Lambda^{\Phi^{0}}({\cal K}^{\prime},{\cal K})

\displaystyle=

\displaystyle\sum_{q\in\mu({\cal K})}\Lambda^{\Phi^{M}}(\mu({\cal R}_{\mu({\cal K})\setminus q},{\cal R}_{\mu({\cal K})})

\displaystyle=

\displaystyle\sum_{q\in M\setminus\mu({\cal K})}\Lambda^{\Phi^{M}}({\cal R}_{\mu({\cal K})},{\cal R}_{\mu({\cal K})\cup q})

\displaystyle=

\displaystyle\sum_{({\cal K},{\cal K}^{\prime})\in E_{\cal F}}\Lambda^{\Phi^{0}}({\cal K},{\cal K}^{\prime}).

Thus, the flow induced by
\Lambda^{\Phi^{0}}
and passing through such a
{\cal K}
satisfies the conservation constraints.

Case (c)
: Assume that the coalition profile
{\cal K}\in{\cal F}
is relevant, different from
\emptyset_{M}
,
{\cal P}
, and such that there is (a unique)
q\in\mu({\cal K})
such that
K_{q}\not=P_{q}
, that is

{\cal K}={\cal K}_{(\mu({\cal K}),K_{q})}
for some
K_{q}\in{\cal F}_{q}\setminus\{\emptyset,P_{q}\}
and
q\in\mu({\cal K})
. Then, a directed edge
({\cal K},{\cal K}^{\prime})\in E_{\cal F}
is relevant if and only if

\mu({\cal K})=\mu({\cal K}^{\prime})
,
{\cal K}^{\prime}_{-q}={\cal K}_{-q}
,
(K_{q},K^{\prime}_{q})\in E_{{\cal F}_{q}}
for some
K_{q}^{\prime}\in{\cal F}_{q}
. In such a case,
Q_{({\cal K},{\cal K}^{\prime})}=K_{q}^{\prime}\setminus K_{q}
. Therefore, by using Case (a) and the definition of the flow
\Lambda^{\Phi^{q}}
on
\Gamma_{{\cal F}_{q}}
, one obtains

\displaystyle\sum_{({\cal K},{\cal K}^{\prime})\in E_{\cal F}}\Lambda^{\Phi^{0}}({\cal K},{\cal K}^{\prime})

\displaystyle=

\displaystyle\sum_{({\cal K},{\cal K}^{\prime})\in E_{\cal F}^{R}}\Lambda^{\Phi^{0}}({\cal K},{\cal K}^{\prime})

\displaystyle=

\displaystyle\sum_{({\cal K},{\cal K}^{\prime})\in E_{\cal F}^{R}}\Lambda^{\Phi^{M}}({\cal R}_{\mu({\cal K})\setminus q},{\cal R}_{\mu({\cal K})})\sum_{i\in K_{q}^{\prime}\setminus K_{q}}\lambda_{i}^{\Phi^{0}}({\cal K},{\cal K}^{\prime})

\displaystyle=

\displaystyle\sum_{({\cal K},{\cal K}^{\prime})\in E_{\cal F}^{R}}\Lambda^{\Phi^{M}}({\cal R}_{\mu({\cal K})\setminus q},{\cal R}_{\mu({\cal K})})\Lambda^{\Phi^{q}}(K_{q},K_{q}^{\prime})

\displaystyle=

\displaystyle\Lambda^{\Phi^{M}}({\cal R}_{\mu({\cal K})\setminus q},{\cal R}_{\mu({\cal K})})\sum_{(K_{q},K_{q}^{\prime})\in E_{{\cal F}_{q}}}\Lambda^{\Phi^{q}}(K_{q},K_{q}^{\prime}).

Proceeding in a similar way for directed edges
({\cal K}^{\prime},{\cal K})\in E_{\cal F}
, one gets

\sum_{({\cal K}^{\prime},{\cal K})\in E_{\cal F}}\Lambda^{\Phi^{0}}({\cal K}^{\prime},{\cal K})=\Lambda^{\Phi^{M}}({\cal R}_{\mu({\cal K})\setminus q},{\cal R}_{\mu({\cal K})})\sum_{(K_{q}^{\prime},K_{q})\in E_{{\cal F}_{q}}}\Lambda^{\Phi^{q}}(K^{\prime}_{q},K_{q}).

Thanks to the conservation constraints applied to the flow
\Lambda^{\Phi^{q}}
,

\sum_{(K_{q}^{\prime},K_{q})\in E^{i}_{\cal F}}\Lambda^{\Phi^{q}}(K^{\prime}_{q},K_{q})=\sum_{(K_{q},K_{q}^{\prime})\in E^{i}_{{\cal F}_{q}}}\Lambda^{\Phi^{q}}(K_{q},K_{q}^{\prime})

one obtains

\sum_{({\cal K}^{\prime},{\cal K})\in E_{\cal F}}\Lambda^{\Phi^{0}}({\cal K}^{\prime},{\cal K})=\sum_{({\cal K},{\cal K}^{\prime})\in E_{\cal F}}\Lambda^{\Phi^{0}}({\cal K},{\cal K}^{\prime}),

showing that the flow induced by
\Lambda^{\Phi^{0}}
and passing through such a coalition profile
{\cal K}
satisfies the conservation constraints.

From Cases (a), (b) and (c), conclude that
\Lambda^{\Phi^{0}}:E_{\cal F}\longrightarrow\mathbb{R}
defined as in (
16
) is a flow. It remains to prove that this flow is unitary.

\sum_{(\emptyset_{M},{\cal K})\in E_{\cal F}}\Lambda^{\Phi^{0}}(\emptyset_{M},{\cal K})=\sum_{q\in M}\Lambda^{\Phi^{M}}(\emptyset_{M},{\cal R}_{q})\sum_{(\emptyset,K_{q})\in E_{{\cal F}_{q}}}\Lambda^{\Phi^{q}}(\emptyset,K_{q}).

Since
\Lambda^{\Phi^{M}}
and
\Lambda^{\Phi^{q}}
are unitary flows,

\sum_{(\emptyset_{M},{\cal K})\in E_{\cal F}}\Lambda^{\Phi^{0}}(\emptyset,{\cal K})=1,

as desired.
∎

According to Lemma
4
and Theorem
3
, a two-step flow method
\Phi^{0}
on
{\cal G}_{N,{\cal P},{\cal F}}

defined through the two-step procedure (
12
)-(
13
) can be expressed as:

\displaystyle\forall i\in N,\quad\Phi^{0}_{i}(N,v,{\cal P},{\cal F})

\displaystyle=

\displaystyle\sum_{q\in M:\atop i\in P_{q}}\Phi_{i}^{q}(P_{q},v_{q},(P_{q}),{\cal F}_{q}),

where

\Phi_{i}^{q}(P_{q},v_{q},(P_{q}),{\cal F}_{q})=\!\!\!\!\!\!\!\!\!\!\!\sum_{({\cal K},{\cal K^{\prime}})\in E^{R}_{\cal F}\cap E^{i}_{{\cal F}}:\atop q_{({\cal K},{\cal K^{\prime}})}=q}\Lambda^{\Phi^{M}}({\cal R}_{\mu({\cal K}^{\prime})\setminus q},{\cal R}_{\mu({\cal K}^{\prime})})\lambda^{q}_{i}(K_{q},K^{\prime}_{q})\bigl(v({\cal K}^{\prime})-v({\cal K})\bigr).

For each
q
and each directed edge
(K_{q},K_{q}^{\prime})\in E_{{\cal F}_{q}}
, the sum of the coefficients is equal to the flow induced by
\Phi^{q}
passing through the directed edges
(K_{q},K_{q}^{\prime})
, that is,

\sum_{i\in K_{q}^{\prime}\setminus K_{q}}\lambda_{i}^{\Phi^{q}}(K_{q},K_{q}^{\prime})=\Lambda^{\Phi^{q}}(K_{q},K_{q}^{\prime}).

Among the family of flow methods are those based on maximal paths, in the spirit of Shapley’s procedure, where the grand coalition
N
is formed step by step from a linear order on the agents in the set
N
. Inspired by this idea, Owen
[
27
]
and Albizuri et al.
[
2
]
(implicitly) construct their value from certain maximal paths and unitary flows on these paths.

In our context, consider a maximal path
W=(\emptyset_{M},\ldots,(\{1\},\ldots,\{m\}))
in the directed hypercube
\Gamma_{{\cal F}^{M}}
of dimension
m
.
There are exactly
m!
maximal paths in
\Gamma_{{\cal F}^{M}}
. Denote by
P_{\Gamma_{\cal F}}
the set of these
m!
maximal paths.
Define the unitary flow
\Lambda^{M}_{W}:E_{{\cal F}^{M}}\longrightarrow\mathbb{R}
such that
\Lambda^{M}_{W}({\cal R},{\cal R}^{\prime})=1

if the pair
({\cal R},{\cal R}^{\prime})
lies on the path and
\Lambda^{M}_{W}({\cal R},{\cal R}^{\prime})=0
otherwise.
Next, consider,

\Lambda^{M}=\frac{1}{m!}\sum_{W\in P_{\Gamma_{\cal F}}}\Lambda^{M}_{W}.

Note that
\Lambda^{M}
is still a unitary flow on
\Gamma_{{\cal F}^{M}}
since the set of flows on a digraph forms a linear subspace of
\mathbb{R}^{|E|}
where
|E|
is the number of directed edges of the digraph. Therefore,

\forall S\subseteq M,\forall q\in S,\quad\Lambda^{M}(\mathcal{R}_{S\setminus q},\mathcal{R}_{S})=\frac{(m-s)!(s-1)!}{m!},

where
(s-1)!
is the number of paths from
\emptyset_{M}
to
\mathcal{R}_{S\setminus q}
, and
(m-s)!
is the number of paths from
\mathcal{R}_{S}
to
(\{1\},\ldots,\{m\})
.
Consequently, the flow method
\Phi^{M}
is the extension of the Shapley value from TU-games to the upper-games
(M,v_{M},P_{M},{\cal F}_{M})
given by:

\forall q\in M,\quad\Phi_{q}^{M}(M,v_{M},P_{M},{\cal F}_{M})=\sum_{S\subseteq M:\atop q\in S}\frac{(m-s)!(s-1)!}{m!}\bigl(v_{M}(\mathcal{R}_{S})-v_{M}(\mathcal{R}_{S\setminus q})\bigr).

(18)

For each
q\in M
, proceed as above in each digraph
\Gamma_{{\cal F}_{q}}
. Denote by
\ell_{p}
the number of maximal paths in
\Gamma_{{\cal F}_{q}}
and, for each
(K_{q},K_{q}^{\prime})\in E_{{\cal F}_{q}}
,
\gamma_{q}(\emptyset,K_{q})
is the number of paths from
\emptyset
to
K_{q}
and
\gamma_{q}(K^{\prime}_{q},P_{q})
is the number of paths from
K_{q}^{\prime}
to
P_{q}
. This results in the unitary flow
\Lambda^{q}:E_{{\cal F}_{q}}\longrightarrow\mathbb{R}
defined as:

(K_{q},K_{q}^{\prime})\in E_{{\cal F}_{q}},\quad\Lambda^{q}(K_{q},K_{q}^{\prime})=\frac{\gamma_{q}(\emptyset,K_{q})\gamma_{q}(K_{q}^{\prime},P_{q})}{\ell_{p}}.

Assuming that the flow
\Lambda^{q}(K_{q},K_{q}^{\prime})
is distributed equally among the agents in
K_{q}^{\prime}\setminus K_{q}
, the resulting
flow method
\Phi^{q}(P_{q},(P_{q}),{\cal F}_{q})
is a Shapley-like value where all maximal paths have equal weight and where the contribution from the feasible coalition
K_{q}
to its cover
K_{q}^{\prime}
is shared equally among the agents in
K^{\prime}_{q}\setminus K_{q}
. In other words,
\Phi^{q}
can be viewed as the extension of the Shapley value from TU-games to TU-games with set system (see, Aguilera et al.,
[
10
]
, p.131):

\forall i\in P_{q},\,\,\Phi_{i}^{q}(P_{q},(P_{q}),{\cal F}_{q})=\!\!\!\sum_{(K_{q},K_{q}^{\prime})\in\Gamma_{{\cal F}_{q}}:\atop i\in K_{q}^{\prime}\setminus K_{q}}\frac{\gamma_{q}(\emptyset,K_{q})\gamma_{q}(K_{q}^{\prime},P_{q})}{\ell_{p}|K_{q}^{\prime}\setminus K_{q}|}\bigl(v_{q}(K^{\prime}_{q})-v_{q}(K_{q})\bigr).

(19)

Consequently, the two-step flow method
\Phi^{0}
on
{\cal G}_{N,{\cal P},{\cal F}}
is given by:

\forall i\in N,\quad\Phi^{0}_{i}(N,v,{\cal P},{\cal F})=

\sum_{q\in M:\atop i\in P_{q}}\sum_{S\subseteq M:\atop q\in S}\!\!\!\sum_{(K_{q},K_{q}^{\prime})\in E_{{\cal F}_{q}}}\frac{(m-s)!(s-1)!}{m!}\frac{\gamma_{q}(\emptyset,K_{q})\gamma_{q}(K_{q}^{\prime},P_{q})}{\ell_{p}|K_{q}^{\prime}\setminus K_{q}|}\bigl(v({\cal K}_{S,K_{q}^{\prime}})-v({\cal K}_{S,K_{q}})\bigr).

(20)

From (
18
) and (
19
),
\Phi^{0}
is computed from the two-step procedure (
12
)-(
13
) where at each step the Shapley-like value is applied. Equivalently, the two-step flow
\Lambda^{\Phi^{0}}
associated with
\Phi^{0}
is given, for each relevant edge, by

\displaystyle\Lambda^{\Phi^{0}}({\cal K}_{S,K_{q}},{\cal K}_{S,K^{\prime}_{q}})

\displaystyle=

\displaystyle\Lambda^{M}({\cal R}_{S\setminus q},{\cal R}_{S})\Lambda^{q}(K_{q},K_{q}^{\prime})

(21)

\displaystyle=

\displaystyle\frac{(m-s)!(s-1)!}{m!}\frac{\gamma_{q}(\emptyset,K_{q})\gamma_{q}(K_{q}^{\prime},P_{q})}{\ell_{p}}.

Characterization of two-step flow methods

We say that a flow
\Lambda^{0}
on the product digraph
\Gamma_{\cal F}
is a
two-step flow
if the flow is constructed from flows
\Lambda^{q}
on the digraphs
\Gamma_{{\cal F}_{q}}
,
q\in M
, and from a flow
\Lambda^{M}
on the directed hypercube
\Gamma_{{\cal F}^{M}}
in the following way:

\displaystyle 1.

\displaystyle\forall({\cal K},{\cal K}^{\prime})=({\cal K}_{\mu({\cal K}^{\prime}),K_{q}},{\cal K}^{\prime}_{\mu({\cal K}^{\prime}),K^{\prime}_{q}})\in E_{\cal F}^{R},\,q\in\mu({\cal K}^{\prime}),

\displaystyle\Lambda({\cal K},{\cal K}^{\prime})=\Lambda^{M}({\cal R}_{\mu({\cal K}^{\prime})\setminus q},{\cal R}_{\mu({\cal K}^{\prime})})\Lambda^{q}(K_{q},K^{\prime}_{q});

\displaystyle 2.

\displaystyle\Lambda({\cal K},{\cal K}^{\prime})=0,\mbox{ otherwise}.

(22)

By Theorem
3
, a two-step flow method
\Phi^{0}
on
{\cal G}_{N,{\cal P},{\cal F}}
induces a two-step flow
\Lambda^{\Phi^{0}}
on the product digraph
\Gamma_{\cal F}
. Reciprocally, from any two-step flow
\Lambda^{0}
on the product digraph
\Gamma_{\cal F}
, one can construct a two-step flow method
\Phi^{0}
on
{\cal G}_{N,{\cal P},{\cal F}}
. It turns out that the two-step flow methods can be characterized by two axioms for flows on
\Gamma_{\cal F}
. The first axiom stipulates that the flow passing through non-relevant directed edges of the product digraph is null. The second axiom expresses a principle of flow proportionality between relevant directed edges of the product digraph
\Gamma_{\cal F}
.

Null flow for non-relevant directed edges
. A flow
\Lambda
on
\Gamma_{\cal F}
satisfies null flow for non-relevant edges if for each non-relevant directed edge
({\cal K},{\cal K}^{\prime})\in E_{\cal F}\setminus E_{\cal F}^{R}
, it holds that
\Lambda({\cal K},{\cal K}^{\prime})=0
.

Flow proportionality
. A flow
\Lambda
on
\Gamma_{\cal F}
satisfies flow proportionality if for each
q\in M
, each pair of relevant directed edges
\{(K_{q},K_{q}^{\prime}),(L_{q},L_{q}^{\prime})\}\subseteq E_{{\cal F}_{q}}
of
\Gamma_{{\cal F}_{q}}
and each pair
\{S,S^{\prime}\}\subseteq M
such that
q\in S\cap S^{\prime}
, the following proportionality principle holds:

\Lambda({\cal K}_{S,K_{q}},{\cal K}_{S,K^{\prime}_{q}})\Lambda({\cal K}_{S^{\prime},L_{q}},{\cal K}_{S^{\prime},L^{\prime}_{q}})=\Lambda({\cal K}_{S^{\prime},K_{q}},{\cal K}_{S^{\prime},K^{\prime}_{q}})\Lambda({\cal K}_{S,L_{q}},{\cal K}_{S,L^{\prime}_{q}}).

Theorem 4
.

A flow
\Lambda
on the product digraph
\Gamma_{\cal F}
is a two-step flow as in (
22
) if and only if it satisfies Null flow for non-relevant directed edges and Flow proportionality.

The proof of Theorem
4
relies on an intermediary result.

Pick any
S\subseteq M
, any
q\in S
, and the relevant coalition profile
{\cal K}_{S}
. Define by
({\cal F}^{S\setminus q,S},E_{{\cal F}^{S\setminus q,S}})
the subdigraph of
\Gamma_{\cal F}
induced
by the subset
{\cal F}^{S\setminus q,S}\subseteq{\cal F}
of coalition profiles between
{\cal K}_{S\setminus q}
and
{\cal K}_{S}
,

{\cal F}^{S\setminus q,S}=\bigl\{{\cal K}\in{\cal F}:{\cal K}_{S\setminus q}\subseteq^{M}{\cal K}\subseteq^{M}{\cal K}_{S}\bigr\}.

Note that each element of
{\cal F}^{S\setminus q,S}
is a relevant coalition profile.

Lemma 5
.

Let
\Lambda
be a unitary flow on
\Gamma_{\cal F}
satisfying Null flow for non-relevant directed edges.
Then, the following two points hold.

1.

The unitary flow
\Lambda
on
\Gamma_{\cal F}
induces a flow on the subdigraph
({\cal F}^{S\setminus q,S},E_{{\cal F}^{S\setminus q,S}})
;

2.

Define the function
\Lambda^{M}
applied to the directed hypercube
\Gamma_{{\cal F}^{M}}
as

\forall S\subseteq M\setminus\emptyset,\forall q\in S,\quad\Lambda^{M}({\cal R}_{S\setminus q},{\cal R}_{S})=\sum_{K_{q}\in{\cal F}_{q}:\atop(\emptyset,K_{q})\in E_{{\cal F}_{q}}}\Lambda({\cal K}_{S\setminus q},{\cal K}_{S,K_{q}}),

(23)

or equivalently,

\Lambda^{M}({\cal R}_{S\setminus q},{\cal R}_{S})=\sum_{{\cal K}\subseteq^{M}{\cal K}_{S}:\atop({\cal K}_{S\setminus q},{\cal K})\in E_{\cal F}}\Lambda({\cal K}_{S\setminus q},{\cal K}).

Then,
\Lambda^{M}
is a unitary flow on
\Gamma_{{\cal F}^{M}}
.

Proof

Point 1
. Pick any
{\cal K}\in{\cal F}^{S\setminus q,S}
different from
{\cal K}_{S\setminus q}
and
{\cal K}_{S}
and any directed edge
({\cal K},{\cal K}^{\prime})\in E_{\cal F}
. Then
({\cal K},{\cal K}^{\prime})\in E_{{\cal F}^{S\setminus q,S}}
if and only if
{\cal K}^{\prime}
is relevant. By Null flow for non-relevant directed edges, it follows that

\sum_{{\cal K}^{\prime}\in{\cal F}:\atop({\cal K},{\cal K}^{\prime})\in E_{\cal F}}\Lambda({\cal K},{\cal K}^{\prime})=\sum_{{\cal K}^{\prime}\in{\cal F}:\atop({\cal K},{\cal K}^{\prime})\in E_{{\cal F}^{S\setminus q,S}}}\Lambda({\cal K},{\cal K}^{\prime}).

In the same way,

\sum_{{\cal K}^{\prime}\in{\cal F}:\atop({\cal K}^{\prime},{\cal K})\in E_{\cal F}}\Lambda({\cal K}^{\prime},{\cal K})=\sum_{{\cal K}^{\prime}\in{\cal F}:\atop({\cal K}^{\prime},{\cal K})\in E_{{\cal F}^{S\setminus q,S}}}\Lambda({\cal K}^{\prime},{\cal K}).

Since
\Lambda
is a flow on
\Gamma_{\cal F}
, it satisfies the conservation constraints so that

\sum_{{\cal K}^{\prime}\in{\cal F}^{S\setminus q,S}:\atop({\cal K},{\cal K}^{\prime})\in E_{{\cal F}^{S\setminus q,S}}}\Lambda({\cal K},{\cal K}^{\prime})=\sum_{{\cal K}^{\prime}\in{\cal F}^{S\setminus q,S}\atop({\cal K}^{\prime},{\cal K})\in E_{{\cal F}^{S\setminus q,S}}}\Lambda({\cal K}^{\prime},{\cal K}),

which means that the conservation constraints are also satisfied for each vertex of
({\cal F}^{S\setminus q,S},E_{{\cal F}^{S\setminus q,S}})
different from
{\cal K}_{S\setminus q}
and
{\cal K}_{S}
. Thus, by definition of a flow,

\Lambda
induces a flow on the subdigraph
({\cal F}^{S\setminus q,S},E_{{\cal F}^{S\setminus q,S}})
.

Point 2
. Consider the cut of
({\cal F}^{S\setminus q,S},E_{{\cal F}^{S\setminus q,S}})
formed by the coalition profile
{\cal K}_{S\setminus q}
and the coalition profiles
{\cal K}
such that
({\cal K}_{S\setminus q},{\cal K})\in E_{{\cal F}^{S\setminus q,S}}
. In a similar way, consider the cut of
({\cal F}^{S\setminus q,S},E_{{\cal F}^{S\setminus q,S}})
formed by the coalition profile
{\cal K}_{S}
and the coalition profiles
{\cal K}
such that
({\cal K},{\cal K}_{S})\in E_{{\cal F}^{S\setminus q,S}}
. As
\Lambda
induces a flow on the subdigraph
({\cal F}^{S\setminus q,S},E_{{\cal F}^{S\setminus q,S}})
by Point 1, and that
the value of a flow is equal to the value of any cut, one obtains:

\sum_{{\cal K}\in{\cal F}^{S\setminus q,S}:\atop({\cal K}_{S\setminus q},{\cal K})\in E_{{\cal F}^{S\setminus q,S}}}\Lambda({\cal K}_{S\setminus q},{\cal K})=\sum_{{\cal K}\in{\cal F}^{S\setminus q,S}:\atop({\cal K},{\cal K}_{S})\in E_{{\cal F}^{S\setminus q,S}}}\Lambda({\cal K},{\cal K}_{S}),

or equivalently

\sum_{{\cal K}\subseteq^{M}{\cal K}_{S}:\atop({\cal K}_{S\setminus q},{\cal K})\in E_{{\cal F}}}\Lambda({\cal K}_{S\setminus q},{\cal K})=\sum_{{\cal K}\supseteq^{M}{\cal K}_{S\setminus q}:\atop({\cal K},{\cal K}_{S})\in E_{{\cal F}}}\Lambda({\cal K},{\cal K}_{S}).

By definition (
23
) of
\Lambda^{M}
, the above quantity is equal to

\Lambda^{M}({\cal R}_{S\setminus q},{\cal R}_{S})
.
Next, consider the sum of the quantities

and

Remark 9
.

Flow methods on
{\cal G}_{N,{\cal F}^{0},{\cal P}}
are defined in analogous way to flow methods on
{\cal G}_{N,{\cal F},{\cal P}}
.
The main difference with Definition 2.4 of flow methods for TU-games with restricted cooperation in Aguilera et al.
[
10
]
is that they consider a flow on the digraph of the covering relation with respect to set inclusion of the elements of the set system. As showed in Remark
8
,
\Gamma_{{\cal F}^{0}}^{*}
may differ from
\Gamma_{{\cal F}^{0}}
.
To the contrary, we consider a flow passing through the directed edges of
\Gamma_{{\cal F}^{0}}^{*}
and not to the directed edges of
\Gamma_{{\cal F}^{0}}
.

Theorem 7
.

Assume that for each directed edge
({\cal K},{\cal K}^{\prime})\in E_{\cal F}
,

1.

either
u({\cal K})=u({\cal K}^{\prime}),

2.

or
u({\cal K}^{\prime})\setminus u({\cal K})=K_{q}^{\prime}\setminus K_{q}
and
q
is the only index in
M
such that
K_{q}^{\prime}\not=K_{q}
.

Then, for any flow method
\Phi
on
{\cal G}_{N,{\cal F},{\cal P}}
,
\phi\triangleleft\Phi
is a flow method on
{\cal G}_{N,{\cal F}^{0},{\cal P}}
whose associated flow
passes through the directed of edges of
\Gamma_{{\cal F}^{0}}^{*}
.

Proof
Assume that
\Gamma_{{\cal F}}
is as the statement of Theorem
7
. Pick any flow method
\Phi
on
{\cal G}_{N,{\cal F},{\cal P}}

and consider
\phi\triangleleft\Phi
on
{\cal G}_{N,{\cal F}^{0},{\cal P}}
. Then,

\forall(N,v,{\cal F}^{0},{\cal P})\in{\cal G}_{N,{\cal F}^{0},{\cal P}},\forall i\in N,\quad\phi_{i}(N,v,{\cal F}^{0},{\cal P})=\Phi_{i}(N,v^{*},{\cal F},{\cal P}),

that is, by definition of a flow method and
v^{*}
,

\displaystyle\phi_{i}(N,v,{\cal F}^{0},{\cal P})

\displaystyle=

\displaystyle\sum_{({\cal K},{\cal K}^{\prime})\in E_{\cal F}^{i}}\lambda_{i}^{\Phi}({\cal K},{\cal K}^{\prime})\bigl(v^{*}({\cal K}^{\prime})-v^{*}({\cal K})\bigr)

\displaystyle=

\displaystyle\sum_{(R,R^{\prime})\in E_{{\cal F}^{0}}^{*}}\sum_{({\cal K},{\cal K}^{\prime})\in E_{\cal F}^{i}:\atop u({\cal K})=R,u({\cal K}^{\prime})=R^{\prime}}\lambda_{i}^{\Phi}({\cal K},{\cal K}^{\prime})\bigl(v(R^{\prime})-v(R)\bigr).

By definition,
({\cal K},{\cal K}^{\prime})\in E_{\cal F}^{i}
if
i\in Q_{({\cal K},{\cal K}^{\prime})}
. Thus,
whenever
u({\cal K})\not=u({\cal K}^{\prime})
, Point 2 of the statement of Theorem
7
implies that
R^{\prime}\setminus R=Q_{({\cal K},{\cal K}^{\prime})}
, which leads to

\phi_{i}(N,v,{\cal F}^{0},{\cal P})=\sum_{(R,R^{\prime})\in E^{*}_{{\cal F}^{0}}:\atop i\in R^{\prime}\setminus R}\sum_{({\cal K},{\cal K}^{\prime})\in E_{\cal F}:\atop u({\cal K})=R,u({\cal K}^{\prime})=R^{\prime}}\lambda_{i}^{\Phi}({\cal K},{\cal K}^{\prime})\bigl(v(R^{\prime})-v(R)\bigr).

By setting,

\forall(R,R^{\prime})\in E_{{\cal F}^{0}}^{*}:i\in R^{\prime}\setminus R,\quad\lambda_{i}^{\phi}(R,R^{\prime})=\sum_{({\cal K},{\cal K}^{\prime})\in E_{\cal F}:\atop u({\cal K})=R,u({\cal K}^{\prime})=R^{\prime}}\lambda_{i}^{\Phi}({\cal K},{\cal K}^{\prime}),

we get

\phi_{i}(N,v,{\cal F}^{0},{\cal P})=\sum_{(R,R^{\prime})\in E_{{\cal F}^{0}}^{*}:\atop i\in R^{\prime}\setminus R}\lambda_{i}^{\phi}(R,R^{\prime})\bigl(v(R^{\prime})-v(R)\bigr),

from which one concludes that
\phi
is a marginalist value on
{\cal G}_{N,{\cal F}^{0},{\cal P}}
. Next, by Efficiency of
\Phi
, one obtains

\sum_{i\in N}\phi_{i}(N,v,{\cal F}^{0},{\cal P})=\sum_{i\in N}\Phi_{i}(N,v^{*},{\cal F},{\cal P})=v^{*}({\cal P})=v(u({\cal P}))=v(N).

Thus,
\phi
is Efficient. Next, proceeding as in the proof of Theorem
2
but for the digraph
\Gamma_{{\cal F}^{0}}^{*}
and for a coalition profile function
v:{\cal F}^{0}\longrightarrow\mathbb{R}
one obtains that
\phi
is a flow method on
{\cal G}_{N,{\cal F}^{0},{\cal P}}
whose associated flow
\Lambda^{\phi}:E_{{\cal F}^{0}}^{*}\longrightarrow\mathbb{R}
is given by

\forall(R,R^{\prime})\in E_{{\cal F}^{0}}^{*},\quad\Lambda^{\phi}(R,R^{\prime})=\sum_{i\in R^{\prime}\setminus R}\lambda_{i}^{\phi}(R,R^{\prime}).

This concludes the proof.

9
Conclusion

We introduce generalized coalition configurations in which the cooperation in each element of the coalition configuration is not necessarily total but takes into account the possible incompatibilities among the agents. This leads to a variety of novel situations depending on the particular set system in each element of the coalition configuration. First, we provide an axiomatic characterization of flow methods for cooperative games with generalized coalition configuration. Next, we look at a value construction procedure inspired by Owen’s two-step procedure
for TU-games with coalition structure (Owen
[
27
]
). This two-step procedure leads to a flow method whose flow can be decomposed into two flows. Such decomposable flows are characterized by two axioms for flows. Finally, we investigate the possibility of deriving a flow method for TU-games with generalized coalition configuration from a flow method for our class of cooperative games where the unit of cooperation is a coalition profile and not a coalition.
