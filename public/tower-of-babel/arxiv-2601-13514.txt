Post-selection inference for penalized M-estimators via score thinning
Ronan Perry, Snigdha Panigrahi, Daniela Witten

Abstract
We consider inference for M-estimators after model selection using a sparsity-inducing penalty. While existing methods for this task require bespoke inference procedures, we propose a simpler approach, which relies on two insights: (i) adding and subtracting carefully-constructed noise to a Gaussian random variable with unknown mean and known variance leads to two independent Gaussian random variables; and (ii) both the selection event resulting from penalized M-estimation, and the event that a standard (non-selective) confidence interval for an M-estimator covers its target, can be characterized in terms of an approximately normal “score variable”. We combine these insights to show that — when the noise is chosen carefully — there is asymptotic independence between the model selected using a noisy penalized M-estimator, and the event that a standard (non-selective) confidence interval on noisy data covers the selected parameter. Therefore, selecting a model via penalized M-estimation (e.g. glmnet in R ) on noisy data, and then conducting standard inference on the selected model (e.g. glm in R ) using noisy data, yields valid inference: no bespoke methods are required . Our results require independence of the observations, but only weak distributional requirements. We apply the proposed approach to conduct inference on the association between sex and smoking in a social network.

1.1
Existing approaches for inference after model selection

First, we review methods that are specifically tailored for inference on a model selected via penalized M-estimation.
The conditional selective inference proposal of
20
provides valid inference on linear contrasts of the mean of a Gaussian response vector when these contrasts were selected by the lasso; this is accomplished by characterizing the lasso selection event as a set of linear inequalities, and then deriving the distribution of the estimator conditional on the lasso selection event.
36
and
33
extend these results to provide asymptotic guarantees without distributional assumptions on the response vector, and
33
allow the number of features
p
to grow with the sample size
n
. These methods provide valid inference conditional on the event that a specific model was selected via the lasso using all of the data. However, this framework requires analytical characterization of the selection event for each model selection procedure; furthermore, it lacks power near the boundary of the selection event
(
16
)
.

To improve power, randomized conditional selective inference methods introduce noise into the selection process. In a distribution-free setting,
34
prove a selective central limit theorem which they use to derive a selective density by conditioning on having selected a model using an
L_{1}
-penalty. However, this selective density must be approximated via sampling. In a linear Gaussian model,
29

1

L_{1}
-penalized M-estimators. In the context of group-lasso-penalized M-estimators,
14

We now turn to approaches that split the data into two independent sets, so that the first can be used to select a model and the second to conduct inference. A major advantage of such approaches over the aforementioned (randomized) conditional selective inference approaches is that no bespoke methods for inference are required, i.e., the details of the selection procedure are unimportant.
Provided that

independent and identically-distributed random variables are available, sample splitting
(
5

31

7

Recent proposals have generalized sample splitting:

32

31

and

27

The distributional assumptions required for data thinning are restrictive, and recent work seeks to loosen these assumptions in exchange for asymptotic (rather than finite-sample) guarantees for i.i.d. data.
31

as though it were Gaussian and still obtain asymptotically valid inference on linear contrasts of

when the selection event is any function of the contrasts

under certain conditions, e.g., (i) when the selection event is that

lives in a convex set, or (ii) a total-variation bound requiring continuous errors
Y-\mathbb{E}[Y]

Finally, it bears mention that a line of work by
23
;
40
;
15

not
a function of the data, unlike the work discussed above.

1.2
Contributions of this paper

In this paper, we consider inference on a parameter in a model selected via penalized M-estimation, e.g., the lasso. We do not assume the distribution of the data, nor do we assume identically distributed observations.
Our developments rely upon a key insight: namely, that both selection and inference hinge upon the same approximately normal
score variable
,
\hat{Z}_{n}
.
In greater detail, our insights are as follows:

Insight 1.

Since
\hat{Z}_{n}
is approximately normal, it can be decomposed into two pieces,
\hat{Z}_{n}^{(1)}
and
\hat{Z}_{n}^{(2)}
, which are approximately normal and independent, up to appropriately vanishing remainders.

Insight 2.

The event that a particular model is selected via “noisy” penalized M-estimation is equivalent to an event involving
\hat{Z}_{n}^{(1)}
. Furthermore, the event that a standard (non-selective) confidence interval centered around a “noisy” M-estimator covers its target is equivalent to an event involving
\hat{Z}_{n}^{(2)}
.

Insight 3.

Combining Insights 1 and 2, if we select a model using a “noisy” penalized M-estimator, then a standard confidence interval centered around a “noisy” M-estimator attains the nominal coverage, conditional on the selection event.

Thus,
we can conduct valid post-selection inference for models selected via (noisy) penalized M-estimation using standard inference pipelines.
This is in marked contrast to the methods discussed in Section
1.1
, which require bespoke inference techniques
(

;

;

;

;

;

;

)

(

;

)
, or estimands that are limited to linear contrasts of i.i.d. outcomes
(

;
21
)

Now, suppose instead that

-penalty

2.2
The score variable

It should not be surprising that since

2.3

Recalling the definition of

3.2
Post-selection inference by noising the samples

The very simple strategy for post-selection inference for penalized M-estimators suggested by Theorem
6
requires the analyst to solve the randomized penalized M-estimation problem given in (
3.1
). In this section, we will present a corollary of Theorem
6
, which reveals that as long as the loss function takes an appropriate form, we can conduct post-selection inference for penalized M-estimators
without
needing to solve (
3.1
) at all. The key is to add noise to the data
Y
rather than to the penalized M-estimator optimization problem; this mirrors (but substantially generalizes) the approaches taken by
31
and
21
, and provides an asymptotic and distribution-free version of the finite-sample Gaussian guarantees of
31
.

Recall from Section
2.1
our random data
Y_{i}\in\mathbb{R}^{d}
. Let
\bar{\Sigma}_{n,i}\in\mathbb{R}^{d\times d}
be an estimate of the covariance
\Var(Y_{i})
; in many settings, we will have a homogeneous covariance estimate
\bar{\Sigma}_{n,i}=\bar{\Sigma}_{n}
, although we write our results here more generally to accommodate arbitrarily heterogeneous covariances. We construct auxiliary noise
\bar{W}_{n,i}\sim{\bf{\rm N}}\,(0,\bar{\Sigma}_{n,i})
, and define

\bar{\theta}_{n}^{(\lambda)}=\mathop{\mathrm{arg\,min}}_{\theta\in\mathbb{R}^{p}}\left\{\frac{1}{n}\sum_{i=1}^{n}\ell_{\theta}\left(Y_{i}+\gamma\bar{W}_{n,i}\right)+n^{-1/2}\rho_{\lambda}\left(\theta\right)\right\}

(3.4)

and

\bar{\theta}_{n}^{E}:=\mathop{\mathrm{arg\,min}}_{\theta\in\mathbb{R}^{\left|E\right|}}\left\{\frac{1}{n}\sum_{i=1}^{n}\ell_{\left(\theta,0_{p-\left|E\right|}\right)}\left(Y_{i}-\tfrac{1}{\gamma}\bar{W}_{n,i}\right)\right\}.

(3.5)

We require the following condition.

Condition 7
.

The loss function

\ell_{\theta}(Y_{i})=\theta^{\top}A_{i}Y_{i}+a_{\theta,i}
for some
A_{i}\in\mathbb{R}^{p\times d}
and
a_{\theta,i}\in\mathbb{R}
.

Under
7
, it is clear that

\ell_{\theta}(Y_{i}+\gamma\bar{W}_{n,i})=\ell_{\theta}(Y_{i})+\gamma\theta^{\top}A_{i}\bar{W}_{n,i}\quad\text{and}\quad\ell_{\theta}\left(Y_{i}-\tfrac{1}{\gamma}\bar{W}_{n,i}\right)=\ell_{\theta}(Y_{i})-\tfrac{1}{\gamma}\theta^{\top}A_{i}\bar{W}_{n,i},

where
A_{i}\bar{W}_{n,i}\sim{\bf{\rm N}}\,\left(0,A_{i}\bar{\Sigma}_{n,i}A_{i}^{\top}\right)
.
Thus, for
\hat{W}_{n}=n^{-1/2}\sum_{i=1}^{n}A_{i}\bar{W}_{n,i}
, where
\hat{W}_{n}
is the noise used to estimate
\hat{\theta}_{n}^{(\lambda)}
in
eq.

3.1
and
\hat{\theta}_{n}^{E}
in
eq.

3.2
, the objective function in
eq.

3.1
is equivalent to that of
eq.

3.4
, and
eq.

3.2
is equivalent to
eq.

3.5
. This implies that
theorem

6
holds.

Corollary 7

(Valid post-selection inference via a noisy response)
.

Under
7
, if
\hat{W}_{n}=n^{-1/2}\sum_{i=1}^{n}A_{i}\bar{W}_{n,i}
then
\bar{\theta}_{n}^{(\lambda)}=\hat{\theta}_{n}^{(\lambda)}
and
\bar{\theta}_{n}^{E}=\hat{\theta}_{n}^{E}
. Therefore, under Assumption
1
and Conditions
1
–
6
,

\displaystyle\lim_{n\to\infty}\Pr\left(\xi^{\top}\theta^{E,*}_{n}\in\mathrm{CI}_{n}^{\xi,\alpha}\left(\bar{\theta}_{n}^{E},\hat{S}_{n}^{E}\right)\middle|\,{\bf{\rm supp}}\left(\bar{\theta}_{n}^{(\lambda)}\right)=E\right)\geq 1-\alpha.

Thus, from a computational perspective, valid post-selection inference on a model selected via penalized M-estimation requires only software to compute a penalized M-estimator, provided that the loss function is of an appropriate form. We will see that this holds for a variety of common M-estimators such as generalized linear models with canonical link functions.

4
Application to generalized linear models

We now apply our results from previous sections to the setting of a fixed-
X
generalized linear model (GLM). Even in this very simple setting, existing selective inference tools are restrictive. For instance, consider logistic regression. Since the outcomes are Bernoulli, it is impossible to apply data thinning
(
7
)
, and the asymptotic results of
21
require outcomes with continuous errors. Data fission can be applied but requires the underlying model to be correctly specified
(
22
;
26
)
. The asymptotic results of
34
are applicable, but require complex sampling approaches from a correctly-specified selective density in order to conduct inference.
29
,
14
, and
1
extend these ideas to incorporate randomization.

We take our working model for
Y_{i}\in\mathbb{R}
to be a GLM with a canonical link function:

f_{\theta}(Y_{i})=\exp\left(\frac{Y_{i}X_{i}^{\top}\theta-b(X_{i}^{\top}\theta)}{\alpha}+c(Y_{i},\alpha)\right),

(4.1)

where
X_{i}\in\mathbb{R}^{p}
are fixed regressors,
b:\mathbb{R}\mapsto\mathbb{R}
,
and
\alpha
is an over-dispersion parameter for the variance.

Minimizing the negative log-likelihood
-\log f_{\theta}(Y_{i})
for the working model is equivalent to minimizing the loss

\ell_{\theta}(Y_{i}):=-Y_{i}X_{i}^{\top}\theta+b(X_{i}^{\top}\theta),

(4.2)

which yields the score variable

\hat{Z}_{n}:=\sqrt{n}P_{n}\dot{\ell}_{\check{\theta}^{E,*}_{n}}=\frac{1}{\sqrt{n}}\sum_{i=1}^{n}X_{i}\left(\dot{b}(X_{i}^{\top}\check{\theta}^{E,*}_{n})-Y_{i}\right),

where
\check{\theta}^{E,*}_{n}
was defined in
eq.

2.7
.

Our goal is valid post-selection inference with a GLM working model and an
L_{1}
penalty for selection. We already established in
proposition

3
that the
L_{1}
penalty satisfies
5
. Furthermore, examining the GLM loss function in
eq.

4.2
, it is clear that
7
is satisfied with
A_{i}=-X_{i}
and
a_{i,\theta}=b\left(X_{i}^{\top}\theta\right)
, and so valid inference can be obtained by adding noise to the outcomes as outlined in
corollary

7
. It remains to establish that the remaining conditions for
corollary

7
hold.

Since
X_{i}
is fixed,

\Sigma_{n}:=\Var\left(\hat{Z}_{n}\right)=\frac{1}{n}\sum_{i=1}^{n}\Var(Y_{i})X_{i}X_{i}^{\top}.

(4.3)

If
X^{\top}X
is positive definite, then
\Sigma_{n}
is invertible, satisfying
1
(i).
1
(ii) holds under mild regularity conditions.

4
involves a Taylor expansion of the loss around
\theta^{E,*}_{n}
and holds under standard assumptions for the theory of M-estimation
(
38

, as established by the following result.

Proposition 8
.

Suppose that
\ell
is thrice differentiable in
\theta
, and
\theta
is restricted to a compact subset

over which we have uniform convergence,

\sup_{\theta\in\Theta}\left[P_{n}\ell_{\theta}-\mathbb{E}P_{n}\ell_{\theta}\right]=o_{p}(1).

Furthermore, suppose that
\theta^{E,*}_{n}
in

Next, we turn to

(4.5)

In the following simulations, we generated outcomes from a generalized linear model with canonical link function, i.e.,

exact
same selection procedure as our approach (i), but for inference rely on bespoke conditional likelihoods implemented by the authors in the context of some commonly studied GLMs. Sample splitting (iv) uses half of the samples for selection and half for inference to match the choice of

To determine whether the association between sex and smoking persists after accounting for the friendship network,

First, since the graph is directed, the adjacency matrix is non-symmetric and thus the left and right singular vectors are different. Specifically, the former relate to outgoing edges in the network while the latter relate to incoming edges. Second, the number of singular vectors

The singular vectors selected via

(0.06,3.1)

6
Discussion

Our paper demonstrates the asymptotic validity of data thinning in the case of post-selection inference in penalized M-estimators. Validity hinges upon the crucial fact that selection and inference are functions of the same approximately normal score variable. While previous work on data thinning has shown its promise as an easy-to-use method for post-selection inference, its validity has been limited by the need for strong distributional assumptions. Our work clarifies a class of settings where this limitation may be overcome. Furthermore, our work demonstrates an equivalence between adding and subtracting noise from the outcome, as in Algorithm
4
, and adding and subtracting noise from the gradient, as in Algorithm
C
and other selective inference papers
(
34
;
29
;
14
)
. While the latter may be more widely applicable to penalized M-estimation problems, the former is often more practical as it avoids the need for bespoke software.

Our work opens many new questions. First, our theoretical results are limited to the setting where
n>p
, and yet the setting of
p>n
is also of much practical interest. Second, while
5
is satisfied by the
L_{1}
-penalty, it remains to show that it holds for other popular penalties such as the group lasso. Lastly, the idea of thinning statistics rather than the data is a widely applicable idea, which may allow for further development of strategies inspired by data thinning in the absence of distributional assumptions.

A.1
An extended Berry-Esseen bound

We first recall the multivariate Berry-Esseen Theorem.

Theorem A.1

(Berry-Esseen
[
30
]
)
.

Let
U_{i}
be independent mean zero random variables in
\mathbb{R}^{p}
and let
V_{n}:=\sum_{i=1}^{n}U_{i}
such that
\Var(V_{n})=\sum_{i=1}^{n}\Var(U_{i})=I_{p}
. Define
V\sim{\bf{\rm N}}\,(0,I_{p})
. For any measurable and convex set
A\subseteq\mathbb{R}^{p}
,

\left|\Pr\left(V_{n}\in A\right)-\Pr\left(V\in A\right)\right|\leq\left(42p^{1/4}+16\right)\sum_{i=1}^{n}\mathbb{E}\left\|U_{i}\right\|_{2}^{3}.

Equivalently, this result says that

\left|\Pr\left(V_{n}\in A\right)-\Pr\left(V\in A\right)\right|=O\left(p^{1/4}\sum_{i=1}^{n}\mathbb{E}\left\|U_{i}\right\|_{2}^{3}\right)

for any set
A\subseteq\mathbb{R}^{p}
that is convex and measurable.

The following lemma follows from
theorem

A.1
.

Lemma A.2
.

Let
U_{i}
be independent random variables in
\mathbb{R}^{p}
and assume that
\mu_{n,i}:=\mathbb{E}[U_{i}]
is finite. Define
\hat{V}_{n}:=n^{-1/2}\sum_{i=1}^{n}U_{i}
and assume
\Sigma_{n}:=\Var(\hat{V}_{n})=\frac{1}{n}\sum_{i=1}^{n}\Var(U_{i})
is invertible. Define
\mu_{n}:=\tfrac{1}{n}\sum_{i=1}^{n}\mu_{n,i}
and let
V_{n}\sim{\bf{\rm N}}\,(\sqrt{n}\mu_{n},\Sigma_{n})
. Then for any set
A\subseteq\mathbb{R}^{p}
which can be expressed as a union of
K
measurable almost surely disjoint and convex sets, it holds that

\left|\Pr\left(\hat{V}_{n}\in A\right)-\Pr\left(V_{n}\in A\right)\right|=O\left(Kp^{1/4}n^{-3/2}\lambda_{\mathrm{min}}^{-3/2}\left(\Sigma_{n}\right)\sum_{i=1}^{n}\mathbb{E}\left\|U_{i}-\mu_{n,i}\right\|_{2}^{3}\right).

Proof.

Define
\tilde{A}:=\left\{\Sigma_{n}^{-1/2}(a-\sqrt{n}\mu_{n}):a\in A\right\}
(omitting a dependence on
n
for brevity), and note that

\left|\Pr\left(\hat{V}_{n}\in A\right)-\Pr\left(V_{n}\in A\right)\right|=\left|\Pr\left(\Sigma_{n}^{-1/2}\left(\hat{V}_{n}-\sqrt{n}\mu_{n}\right)\in\tilde{A}\right)-\Pr\left(\Sigma_{n}^{-1/2}\left(V_{n}-\sqrt{n}\mu_{n}\right)\in\tilde{A}\right)\right|.

(A.1)

The term

\Sigma^{-1/2}_{n}\left(\hat{V}_{n}-\sqrt{n}\mu_{n}\right)=\sum_{i=1}^{n}n^{-1/2}\Sigma^{-1/2}_{n}\left(U_{i}-\mu_{n,i}\right)

is the sum of mean-zero and independent observations
n^{-1/2}\Sigma^{-1/2}_{n}\left(U_{i}-\mu_{n,i}\right)
. Furthermore,
\Var\left(\Sigma^{-1/2}_{n}\left(\hat{V}_{n}-\sqrt{n}\mu_{n}\right)\right)=I_{p}
and
\Sigma^{-1/2}_{n}\left(V_{n}-\sqrt{n}\mu_{n}\right)\sim{\bf{\rm N}}\,(0,I_{p})
.

By assumption,
\tilde{A}
remains a union of at most
K
almost surely disjoint, measurable, and convex sets, since the transformation induced by
\Sigma^{-1/2}_{n}
and
\mu_{n}
preserves these properties.
So, we can write
\tilde{A}=\bigcup_{k=1}^{K}\tilde{A}_{k}
where
\left\{\tilde{A}_{k}\right\}_{k=1}^{K}
are almost surely disjoint, measurable, and convex. It follows that

\displaystyle\left|\Pr\left(\Sigma^{-1/2}_{n}\left(\hat{V}_{n}-\sqrt{n}\mu_{n}\right)\in\tilde{A}\right)-\Pr\left(\Sigma^{-1/2}_{n}\left(V_{n}-\sqrt{n}\mu_{n}\right)\in\tilde{A}\right)\right|

\displaystyle=\left|\sum_{k=1}^{K}\left[\Pr\left(\Sigma^{-1/2}_{n}\left(\hat{V}_{n}-\sqrt{n}\mu_{n}\right)\in\tilde{A}_{k}\right)-\Pr\left(\Sigma^{-1/2}_{n}\left(V_{n}-\sqrt{n}\mu_{n}\right)\in\tilde{A}_{k}\right)\right]\right|

\displaystyle\leq\sum_{k=1}^{K}\left|\Pr\left(\Sigma^{-1/2}_{n}\left(\hat{V}_{n}-\sqrt{n}\mu_{n}\right)\in\tilde{A}_{k}\right)-\Pr\left(\Sigma^{-1/2}_{n}\left(V_{n}-\sqrt{n}\mu_{n}\right)\in\tilde{A}_{k}\right)\right|

\displaystyle\leq\sum_{k=1}^{K}O\left(p^{1/4}\sum_{i=1}^{n}\mathbb{E}\left\|n^{-1/2}\Sigma^{-1/2}_{n}\left(U_{i}-\mu_{n,i}\right)\right\|_{2}^{3}\right)

\displaystyle=O\left(Kp^{1/4}n^{-3/2}\lambda_{\mathrm{min}}^{-3/2}\left(\Sigma_{n}\right)\sum_{i=1}^{n}\mathbb{E}\left\|U_{i}-\mu_{n,i}\right\|_{2}^{3}\right).

Combining this with
eq.

A.1
, we obtain our bound.
∎

Lemma A.3

To bound each of the

Constructing an upper bound:

We first construct an upper bound on

For any

We obtain the bound

\displaystyle\Pr\left(\hat{Z}_{n}^{(1,2)}+r_{n}\in C_{n,k}\right)-\Pr\left(\hat{Z}_{n}^{(1,2)}\in C_{n,k}\right)

Proposition B.4

(Adapted from Proposition 2.5
[
4
]
)
.

For any convex set

We now wish to apply

B.4
to bound
\Pr\left(Z_{n}^{(1,2)}\in C_{n}^{\varepsilon_{1}}\setminus C_{n}^{-\varepsilon_{2}}\right)
for any
\varepsilon_{1},\varepsilon_{2}\geq 0
,
and thus must standardize

. Let
\tilde{C}_{n,k}:=\left\{\left(\Sigma_{n}^{(1,2)}\right)^{-1/2}\left(c-\mu_{n}^{(1,2)}\right):c\in C_{n,k}\right\}

\displaystyle\left\{\left(\Sigma_{n}^{(1,2)}\right)^{-1/2}\left(c-\mu_{n}^{(1,2)}\right):c\in C_{n,k}^{\varepsilon_{1}}\right\}

where the second line follows from the definition of

in

B.12

, given in

Similarly,

\displaystyle\left\{\left(\Sigma_{n}^{(1,2)}\right)^{-1/2}\left(c-\mu_{n}^{(1,2)}\right):c\in C_{n,k}^{-\varepsilon_{2}}\right\}

\displaystyle=\left\{\left(\Sigma_{n}^{(1,2)}\right)^{-1/2}\left(c-\mu_{n}^{(1,2)}\right):c+\mathbb{B}_{\varepsilon_{2}}\subset C_{n,k}\right\}

\displaystyle=\left\{c:c+\left\{\left(\Sigma_{n}^{(1,2)}\right)^{-1/2}r:r\in\mathbb{B}_{\varepsilon_{2}}\right\}\subset\tilde{C}_{n,k}\right\}

\displaystyle\supseteq\left\{c:c+\left\{\lambda_{\mathrm{max}}\left(\left(\Sigma_{n}^{(1,2)}\right)^{-1/2}\right)r:r\in\mathbb{B}_{\varepsilon_{2}}\right\}\subset\tilde{C}_{n,k}\right\}

\displaystyle=\tilde{C}_{n,k}^{-\varepsilon_{2}/\sqrt{\lambda_{\mathrm{min}}\left(\Sigma_{n}^{(1,2)}\right)}}

\mathbb{E}P_{n}\ell_{\theta}
(as the penalty and randomized terms are
o_{p}(1)
), it follows that
\hat{\theta}_{n}^{E}\xrightarrow{\mathrm{p}}\theta^{E,*}_{n}
and
\hat{\theta}_{n}^{(\lambda)}\xrightarrow{\mathrm{p}}\theta^{*}_{n}
.

Having established consistency, we are ready to show that
4
is met. The following results and conditions are standard (see
38
). By existence of third derivatives, for any
\theta
we can construct the following Taylor expansion of
P_{n}\dot{\ell}_{\theta}
around
\check{\theta}^{E,*}_{n}
defined in
eq.

2.7
:

\displaystyle P_{n}\dot{\ell}_{\theta}

\displaystyle=P_{n}\dot{\ell}_{\check{\theta}^{E,*}_{n}}+\left[P_{n}\ddot{\ell}_{\check{\theta}^{E,*}_{n}}\right](\theta-\check{\theta}^{E,*}_{n})+\tfrac{1}{2}(\theta-\check{\theta}^{E,*}_{n})^{\top}\left[P_{n}\dddot{\ell}_{\tilde{\theta}_{n}}\right](\theta-\check{\theta}^{E,*}_{n})

(B.50)

\displaystyle=P_{n}\dot{\ell}_{\check{\theta}^{E,*}_{n}}+H_{n}(\theta-\check{\theta}^{E,*}_{n})+r_{n}(\theta),

(B.51)

where

r_{n}(\theta):=\left(P_{n}\ddot{\ell}_{\check{\theta}^{E,*}_{n}}-H_{n}+\tfrac{1}{2}(\theta-\check{\theta}^{E,*}_{n})^{\top}\left[P_{n}\dddot{\ell}_{\tilde{\theta}_{n}}\right]\right)(\theta-\check{\theta}^{E,*}_{n})

(B.52)

for some
\tilde{\theta}_{n}
which lies on the line segment between
\theta
and
\check{\theta}^{E,*}_{n}
.

We now characterize terms in the above expressions.
By the law of large numbers,
P_{n}\ddot{\ell}_{\check{\theta}^{E,*}_{n}}-H_{n}=o_{p}(1)
where
H_{n}:=\mathbb{E}P_{n}\ddot{\ell}_{\check{\theta}^{E,*}_{n}}
. Lastly, provided that
\dddot{\ell}_{\tilde{\theta}_{n}}(Y_{i})
is dominated by some integrable function
\dddot{\ell}(Y_{i})
for any
\tilde{\theta}_{n}
in some neighborhood
\mathcal{N}_{n}
,

\sup_{\tilde{\theta}_{n}\in\mathcal{N}_{n}}\left\|P_{n}\dddot{\ell}_{\tilde{\theta}_{n}}\right\|_{F}\leq\left\|P_{n}\dddot{\ell}\right\|_{F}=O_{p}(1)

(B.53)

by the law of large numbers.
eq.

B.53
will clearly hold if such a
\dddot{\ell}_{\tilde{\theta}_{n}}(Y_{i})
exists for all
\tilde{\theta}_{n}\in\Theta
. Alternatively,
eq.

B.53
will hold with probability tending to one if
\mathcal{N}_{n}
is an appropriate neighborhood around
\theta^{*}_{n}
in the case of a Taylor expansion of
P_{n}\dot{\ell}_{\hat{\theta}_{n}^{(\lambda)}}
, or neighborhood around
\check{\theta}^{E,*}_{n}
in the case of
P_{n}\dot{\ell}_{\check{\theta}_{n}^{E}}
.

Analyzing the inference estimator
\check{\theta}_{n}^{E}
:

The first order optimality condition of
eq.

3.2
implies that

\sqrt{n}\left(P_{n}\dot{\ell}_{\check{\theta}_{n}^{E}}-\tfrac{1}{\gamma}\hat{W}_{n}\right)_{E}=0.

Replacing
P_{n}\dot{\ell}_{\check{\theta}_{n}^{E}}
with its Taylor expansion in
eq.

B.51
, we arrive at the classical results
\sqrt{n}\left(\hat{\theta}_{n}^{E}-\theta^{E,*}_{n}\right)=O_{p}(1)
. This turn implies that
\check{\theta}_{n}^{E}-\check{\theta}^{E,*}_{n}=O_{p}\left(n^{-1/2}\right)
, and furthermore that

r_{n}\left(\check{\theta}_{n}^{E}\right):=\left(P_{n}\ddot{\ell}_{\check{\theta}^{E,*}_{n}}-H_{n}+\tfrac{1}{2}(\check{\theta}_{n}^{E}-\check{\theta}^{E,*}_{n})^{\top}\left[P_{n}\dddot{\ell}_{\tilde{\theta}}\right]\right)(\check{\theta}_{n}^{E}-\check{\theta}^{E,*}_{n})=o_{p}\left(n^{-1/2}\right).

Analyzing the selection estimator
\hat{\theta}_{n}^{(\lambda)}
:

We now turn to analyzing
r_{n}\left(\hat{\theta}_{n}^{(\lambda)}\right)
. By the first order optimality condition of
eq.

3.1
,

\sqrt{n}P_{n}\dot{\ell}_{\hat{\theta}_{n}^{(\lambda)}}+\gamma\hat{W}_{n}+\eta=0,

for some
\eta\in\partial\rho_{\lambda}\left(\hat{\theta}_{n}^{(\lambda)}\right)
.

As a first step, show that under a local asymptotic setting,
\sqrt{n}\hat{\theta}_{n}^{(\lambda)}=O_{p}(1)
. We replace
P_{n}\dot{\ell}_{\hat{\theta}_{n}^{(\lambda)}}
with its Taylor expansion around
\theta^{*}_{n}
in
eq.

B.49
:

\sqrt{n}P_{n}\dot{\ell}_{\theta^{*}_{n}}+\gamma\hat{W}_{n}+\eta+\sqrt{n}(\hat{\theta}_{n}^{(\lambda)}-\theta^{*}_{n})\left[P_{n}\ddot{\ell}_{\theta^{*}_{n}}+\tfrac{1}{2}(\hat{\theta}_{n}^{(\lambda)}-\theta^{*}_{n})^{\top}\left[P_{n}\dddot{\ell}_{\tilde{\theta}_{n}^{\prime}}\right]\right]=0

for some
\tilde{\theta}_{n}^{\prime}
between
\hat{\theta}_{n}^{(\lambda)}
and
\theta^{*}_{n}
. Since
\hat{W}_{n}=O_{p}(1)
and
\eta
is bounded, under typical regularity conditions
\sqrt{n}P_{n}\dot{\ell}_{\theta^{*}_{n}}=O_{p}(1)
and it follows that
\sqrt{n}(\hat{\theta}_{n}^{(\lambda)}-\theta^{*}_{n})=O_{p}(1)
. Our assumed local alternative setting where
\sqrt{n}\theta^{*}_{n}=O(1)
implies that
\sqrt{n}\hat{\theta}_{n}^{(\lambda)}=O_{p}(1)
.

We now demonstrate that
r_{n}\left(\hat{\theta}_{n}^{(\lambda)}\right)=o_{p}\left(n^{-1/2}\right)
.
We replace
P_{n}\dot{\ell}_{\hat{\theta}_{n}^{(\lambda)}}
with its Taylor expansion in
eq.

B.50
:

\sqrt{n}P_{n}\dot{\ell}_{\check{\theta}^{E,*}_{n}}+\gamma\hat{W}_{n}+\eta+\sqrt{n}(\hat{\theta}_{n}^{(\lambda)}-\check{\theta}^{E,*}_{n})\left[P_{n}\ddot{\ell}_{\check{\theta}^{E,*}_{n}}+\tfrac{1}{2}(\hat{\theta}_{n}^{(\lambda)}-\check{\theta}^{E,*}_{n})^{\top}\left[P_{n}\dddot{\ell}_{\tilde{\theta}_{n}}\right]\right]=0

for some
\tilde{\theta}_{n}
between
\hat{\theta}_{n}^{(\lambda)}
and
\check{\theta}^{E,*}_{n}
. By
1
[i], we know that
\sqrt{n}\check{\theta}^{E,*}_{n}=O(1)
and thus that
\sqrt{n}(\hat{\theta}_{n}^{(\lambda)}-\check{\theta}^{E,*}_{n})=O_{p}(1)
.
This in turn implies that

\sqrt{n}r_{n}\left(\hat{\theta}_{n}^{(\lambda)}\right):=\sqrt{n}(\hat{\theta}_{n}^{(\lambda)}-\check{\theta}^{E,*}_{n})\left(P_{n}\ddot{\ell}_{\check{\theta}^{E,*}_{n}}-H_{n}+\tfrac{1}{2}(\hat{\theta}_{n}^{(\lambda)}-\check{\theta}^{E,*}_{n})^{\top}\left[P_{n}\dddot{\ell}_{\tilde{\theta}_{n}}\right]\right)=o_{p}\left(1\right)

as desired, since
P_{n}\ddot{\ell}_{\check{\theta}^{E,*}_{n}}-H_{n}=o_{p}(1)
by the law of large numbers and
P_{n}\dddot{\ell}_{\tilde{\theta}_{n}}=O_{p}(1)
.
∎

B.8
Proof of
proposition

3

Proof.

Recall that for
\rho_{\lambda}(\theta):=\lambda\left\|\theta\right\|_{1}
, for any
j\in[p]
,

[\partial\rho_{\lambda}(\theta)]_{j}:=\begin{cases}\lambda\,\mathrm{sign}(\theta_{j})&\text{if }\theta_{j}\neq 0\\
[-\lambda,\lambda]&\text{if }\theta_{j}=0\end{cases}.

For a fixed
\lambda
, this is clearly bounded and thus satisfies
5
(i). It remains to show that
5
(ii) holds, i.e.,
for any positive definite matrix
H\in\mathbb{R}^{p\times p}
,

\left\{H\theta+\eta:{\bf{\rm supp}}\left(\theta\right)=E,\eta\in\partial\rho_{\lambda}(\theta)\right\}

(B.54)

has a non-empty interior and can be written as the union of finitely many disjoint convex sets.

To begin, let
s_{E}\in\left\{-1,1\right\}^{|E|}
be one of the
2^{|E|}
possible combinations of signs of
\theta_{E}
,
\mathbb{R}_{E,s_{E}}^{p}:=\left\{\theta:{\bf{\rm supp}}(\theta)=E,\mathrm{sign}(\theta_{E})=s_{E}\right\}
be an orthant, and
\mathcal{E}_{E,s_{E}}:=\left\{\eta:\eta\in\partial\rho_{\lambda}(\theta),\theta\in\mathbb{R}_{E,s_{E}}^{p}\right\}
be a collection of subgradients.
We can then write

\displaystyle\left\{H\theta+\eta:{\bf{\rm supp}}\left(\theta\right)=E,\eta\in\partial\rho_{\lambda}(\theta)\right\}

\displaystyle=\bigcup_{s_{E}\in\left\{-1,1\right\}^{|E|}}\left\{H\theta+\eta:\theta\in\mathbb{R}_{E,s_{E}}^{p},\eta\in\partial\rho_{\lambda}(\theta)\right\}

\displaystyle=\bigcup_{s_{E}\in\left\{-1,1\right\}^{|E|}}\left\{H\theta:\theta\in\mathbb{R}_{E,s_{E}}^{p}\right\}+\mathcal{E}_{E,s_{E}},

where the final sum denotes the Minkowski sum, i.e., the pairwise sum of all points in the two sets.

First, we can see that
\left\{H\theta:\theta\in\mathbb{R}_{E,s_{E}}^{p}\right\}
is an affine transformation of a convex set,
\mathcal{E}_{E,s_{E}}
is a convex set, and so their Minkowski sum is a convex set. The union encompasses
2^{|E|}
such convex sets. To show that these sets are disjoint, for sake of contradiction assume that there is a point lying in two such sets. This implies that there exists some
s_{E}\neq s_{E}^{\prime}\in\left\{-1,1\right\}^{|E|}
and
\theta\in\mathbb{R}^{p}_{E,s_{E}},\theta^{\prime}\in\mathbb{R}^{p}_{E,s_{E}^{\prime}}
such that
H_{E,E}\theta_{E}+\lambda s_{E}=H_{E,E}\theta_{E}^{\prime}+\lambda s_{E}^{\prime}
. Rearranging,

H_{E,E}(\theta_{E}-\theta_{E}^{\prime})=\lambda(s_{E}^{\prime}-s_{E}).

Since
H
is positive definite,
(\theta_{E}-\theta_{E}^{\prime})^{\top}H_{E,E}(\theta_{E}-\theta_{E}^{\prime})>0
. However,
\lambda(\theta_{E}-\theta_{E}^{\prime})^{\top}(s_{E}^{\prime}-s_{E})<0
by definition of the signs. Thus, we have a contradiction and so
eq.

B.54
is the union of
2^{|E|}
disjoint convex sets.

It remains to show that these sets have non-empty interiors, for which it suffices to show that
\left\{H\theta:\theta\in\mathbb{R}_{E,s_{E}}^{p}\right\}+\mathcal{E}_{E,s_{E}}
contains a non-empty open set.
In the
E
coordinates of
\left\{H\theta:\theta\in\mathbb{R}_{E,s_{E}}^{p}\right\}
, since
\mathbb{R}_{E,s_{E}}^{p}
contains a non-empty open set, and
H
is positive definite,
\left\{(H\theta)_{E}:{\bf{\rm supp}}\left(\theta\right)=E,\mathrm{sign}(\theta_{E})=s_{E}\right\}
also contains a non-empty open set. In the
E^{c}
coordinates, we can clearly see that
\mathcal{E}_{E,s_{E}}
contains a non-empty open set and thus the Minkowski sum
\left\{(H\theta):\theta\in\mathbb{R}_{E,s_{E}}^{p}\right\}+\mathcal{E}_{E,s_{E}}
does too.
∎

Appendix C
An algorithm implementing
theorem

6
for
L_{1}
-penalized GLMs

Here, we additionally provide in Algorithm
C
the procedure for obtaining valid inference using
theorem

6
.

Algorithm 2: implementing
theorem

6
for
L_{1}
-penalized GLMs

Input:
Data
\left\{Y_{i},X_{i}\right\}
, penalty
\lambda
, information split
\gamma
.

1.

\tilde{\theta}_{n}\leftarrow\mathop{\mathrm{arg\,min}}_{\theta\in\mathbb{R}^{p}}P_{n}\ell_{\theta}
.

2.

Sample noise
\hat{W}_{n}\leftarrow{\bf{\rm N}}\,\left(0,\frac{1}{n}\sum_{i=1}^{n}X_{i}\,\ddot{b}\left(X_{i}^{\top}\tilde{\theta}_{n}\right)X_{i}^{\top}/\alpha\left(\tilde{\theta}_{n}\right)\right)
.

3.

Estimate
\hat{\theta}_{n}^{(\lambda)}
as in
eq.

3.1
and define
E:={\bf{\rm supp}}\left(\hat{\theta}_{n}^{(\lambda)}\right)
.

4.

Estimate
\hat{\theta}_{n}^{E}
as in
eq.

3.5
.

5.

Compute the modified sandwich variance estimator:

\hat{S}_{n}^{E}\leftarrow\left(H_{n,E,E}\left(\hat{\theta}_{n}^{E}\right)\right)^{-1}\tilde{\Sigma}_{n,E,E}\left(H_{n,E,E}\left(\hat{\theta}_{n}^{E}\right)\right)^{-1}

where

\tilde{\Sigma}_{n,E,E}\leftarrow\frac{1}{\gamma^{2}}\Var\left(\hat{W}_{n,E,E}\right)+\frac{1}{n}\sum_{i=1}^{n}\left(Y_{i}-\dot{b}(X_{i,E}^{\top}\hat{\theta}_{n}^{E})\right)^{2}X_{i,E}X_{i,E}^{\top}.

(C.1)

Output:
A confidence interval centered at
\hat{\theta}_{n}^{E}
,

\mathrm{CI}^{\xi,\alpha}_{n}\left(\hat{\theta}_{n}^{E},\hat{S}_{n}^{E}\right)=\left[\xi^{\top}\hat{\theta}_{n}^{E}\pm n^{-1/2}z_{1-\alpha/2}\left(\xi^{\top}\hat{S}_{n}^{E}\xi\right)^{1/2}\right].

Algorithm
C
is quite similar to Algorithm
4
. A minor but key differences lies in the sandwich variance estimator
\hat{S}_{n}^{E}
in Step 5. Algorithm
4
computes the “meat” of the sandwich using squared residuals relative to the noisy outcomes
\left\{Y_{i}-\tfrac{1}{\gamma}\tilde{W}_{n,i}\right\}_{i=1}^{n}
; this is the classical approach in the M-estimation literature
[
39
]
. However,
theorem

6
does not use noisy outcomes and so there is not an immediately natural estimator
\hat{S}_{n}^{E}
available satisfying
3
. As a solution, we use the estimator in
eq.

C.1
which involves squared residuals relative to the observed outcomes
\left\{Y_{i}\right\}_{i=1}^{n}
, and then additionally factor in the variance of the noise
\hat{W}_{n}
. The justification is as follows.

In the setting of
corollary

7
, the canonical sandwich estimator in Algorithm
4
takes the form

\frac{1}{n}\sum_{i=1}^{n}\left(Y_{i}-\frac{1}{\gamma}\tilde{W}_{n,i}-\dot{b}(X_{i,E}^{\top}\hat{\theta}_{n}^{E})\right)^{2}X_{i,E}X_{i,E}^{\top}.

Expanding the quadratic, this equals

\displaystyle\frac{1}{n}\sum_{i=1}^{n}\left[\left(Y_{i}-\dot{b}(X_{i,E}^{\top}\hat{\theta}_{n}^{E})\right)^{2}-2\frac{1}{\gamma}\tilde{W}_{n,i}Y_{i}+2\frac{1}{\gamma}\tilde{W}_{n,i}\dot{b}(X_{i,E}^{\top}\hat{\theta}_{n}^{E})+\frac{1}{\gamma^{2}}\tilde{W}_{n,i}^{2}\right]X_{i,E}X_{i,E}^{\top}.

Examining the terms in the quadratic expansion, note that

\mathbb{E}\left[\tilde{W}_{n,i}Y_{i}\right]=\mathbb{E}\left[\tilde{W}_{n,i}\dot{b}(X_{i,E}^{\top}\hat{\theta}_{n}^{E})\right]=0,

since
\tilde{W}_{n,i}
is scaled mean zero noise sampled independently from
Y_{i}
. Furthermore,

\frac{1}{n}\sum_{i=1}^{n}X_{i,E}\mathbb{E}\left[\tilde{W}_{n,i}^{2}\right]X_{i,E}^{\top}=\frac{1}{n}\sum_{i=1}^{n}X_{i,E}\Var\left(\tilde{W}_{n,i}\right)X_{i,E}^{\top}=\Var\left(\hat{W}_{n,E,E}\right),

since
\hat{W}_{n}:=n^{-1/2}\sum_{i=1}^{n}X_{i}\tilde{W}_{n,i}
as specified in
corollary

7
.
Thus,

\displaystyle\frac{1}{n}\sum_{i=1}^{n}\left(Y_{i}-\frac{1}{\gamma}\tilde{W}_{n,i}-\dot{b}(X_{i,E}^{\top}\hat{\theta}_{n}^{E})\right)^{2}X_{i,E}X_{i,E}^{\top}

\displaystyle=\frac{1}{\gamma^{2}}\Var\left(\hat{W}_{n,E,E}\right)+\frac{1}{n}\sum_{i=1}^{n}\left(Y_{i}-\dot{b}(X_{i,E}^{\top}\hat{\theta}_{n}^{E})\right)^{2}X_{i,E}X_{i,E}^{\top}+o_{p}(1),

and so the sandwich estimators in Algorithms
4
and
C
are equivalent up to an
o_{p}(1)
term.
