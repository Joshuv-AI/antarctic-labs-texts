Self-Boost via Optimal Retraining: An Analysis via Approximate Message Passing
Adel Javanmard, Rudrajit Das, Alessandro Epasto, Vahab Mirrokni

Abstract
Retraining a model using its own predictions together with the original, potentially noisy labels is a well-known strategy for improving the model’s performance. While prior works have demonstrated the benefits of specific heuristic retraining schemes, the question of how to optimally combine the model’s predictions and the provided labels remains largely open. This paper addresses this fundamental question for binary classification tasks. We develop a principled framework based on approximate message passing (AMP) to analyze iterative retraining procedures for two ground truth settings: Gaussian mixture model (GMM) and generalized linear model (GLM). Our main contribution is the derivation of the Bayes optimal aggregator function to combine the current model’s predictions and the given labels, which when used to retrain the same model, minimizes its prediction error. We also quantify the performance of this optimal retraining strategy over multiple rounds. We complement our theoretical results by proposing a practically usable version of the theoretically-optimal aggregator function for linear probing with the cross-entropy loss, and demonstrate its superiority over baseline methods in the high label noise regime.

Introduction

Learning effectively from data with noisy labels remains a significant challenge in supervised machine learning (ML). A simple approach to mitigate the impact of label noise involves leveraging the trained model’s own (soft or hard) predictions to ameliorate the learning process. More specifically, prior works
[

“
What is the optimal way to utilize the model’s predicted labels and the given labels?
”

In this work, we address this question for binary classification problems where the underlying ground truth model is: (
i
) a Gaussian mixture model (GMM), or (
ii
) a generalized linear model (GLM). Further, we also analyze the effect of multiple rounds of retraining. More specifically, for a sample
\bm{x}

y^{t}

t^{\text{th}}
round of retraining, then we derive the Bayes optimal aggregator function

3
Gaussian Mixture Model (GMM)

Data model.
We assume the training data
\{(\bm{x}_{i},y_{i})\}_{i=1}^{n}
are generated i.i.d according to a Gaussian mixture model. In this model, each data point belongs to one of two classes
\{\pm 1\}
with corresponding probabilities
\pi_{+}
,
\pi_{-}
, such that
\pi_{+}+\pi_{-}=1
. Denoting by
y_{i}\in\{-1,+1\}
the label for data point
i
, the features vectors
\bm{x}_{i}\in\mathbb{R}^{d}
, for
i\in[n]
, are generated independently as

\bm{x}=y{\bm{{\mu}}}+\bm{z},

(1)

where
\bm{z}\sim{\sf N}(\mathbf{0},\bm{I})
. In other words the mean of features vectors are
\pm{\bm{{\mu}}}
depending on its class. Throughout, we denote the features matrix and the labels vector by

{\bm{X}}=[\bm{x}_{1}|\dotsc|\bm{x}_{n}]^{\sf T}\in\mathbb{R}^{n\times d},\quad\bm{y}=[y_{1},\dotsc,y_{n}]^{\sf T}\in\mathbb{R}^{n}\,.

The learner does not observe the labels
y_{i}
, rather she has access to features vectors
\bm{x}_{i}
and noisy labels
\widehat{y}_{i}
which are generated according to the following model:

\displaystyle\widehat{y}_{i}=\begin{cases}y_{i}&\text{with probability }1-p\,,\\
-y_{i}&\text{with probability }p\,,\end{cases}

(2)

where
p<\frac{1}{2}
is the mislabeling or label flipping probability. Let
\widehat{\bm{y}}=[\widehat{y}_{1},\dotsc,\widehat{y}_{n}]^{\sf T}\in\mathbb{R}^{n}
denote the vector of the observed noisy labels.

Standard linear classifier model.
Let us first consider the following simple classifier model:

\displaystyle{\widehat{\bm{\theta}}}=\frac{1}{n}{\bm{X}}^{\sf T}\widehat{\bm{y}}.

(3)

The above model has been used before in
[
9
,
7
]
.
1
1

1

As mentioned in
[
9
]
, this is a reasonable simplification of the least squares’ solution for analysis purposes.

For a given point
\bm{x}
, the model’s soft prediction is
\bm{x}^{\sf T}{\widehat{\bm{\theta}}}
and its predicted label is
{\rm sign}(\bm{x}^{\sf T}{\widehat{\bm{\theta}}})
.

In this work, we consider a slightly different model inspired by Approximate Message Passing (AMP). Since our focus is on retraining over multiple rounds, we will delineate this as an iterative procedure.

3.1
Retraining Framework Inspired by Approximate Message Passing

For ease of exposition, we begin by giving a high-level outline of the retraining process. At iteration
t
of the process, let
\bm{\theta}^{t}\in\mathbb{R}^{d}
denote the current model and
\bm{y}^{t}\in\mathbb{R}^{n}
denote the vector of the soft predictions of the model on the training data. In the next iteration, the algorithm combines
\bm{y}^{t}
and the observed noisy labels
\widehat{\bm{y}}
using the function
g_{t}
to obtain
g_{t}(\bm{y}^{t},\widehat{\bm{y}})
which are the target labels for retraining in the
(t+1)^{\text{th}}
iteration. We refer to
g_{t}
as
aggregator
function and keep it general for now. We will later discuss different options for
g_{t}
, including the Bayes-optimal choice.

Let us now delve into the details. With an aggregator function
g_{t}
, we have the following update rule for
t\geq 0
:

\displaystyle\bm{\theta}^{t+1}

\displaystyle=\frac{1}{\sqrt{n}}{\bm{X}}^{\sf T}g_{t}(\bm{y}^{t},\widehat{\bm{y}})-C_{t}\bm{\theta}^{t}\quad\quad\quad\quad\quad\quad\text{ (model-update step),}

(4)

\displaystyle\bm{y}^{t+1}

\displaystyle=\frac{1}{\sqrt{n}}{\bm{X}}\bm{\theta}^{t+1}-g_{t}(\bm{y}^{t},\widehat{\bm{y}})\frac{d}{n}\quad\quad\quad\quad\quad\quad\;\text{(soft-prediction step).}\,

(5)

The function
g_{t}
is applied entry wise, i.e.,
g_{t}(\bm{y}^{t},\widehat{\bm{y}})
is the vector whose
i^{\text{th}}
(
i\in[n]
) entry is given by
g_{t}(y^{t}_{i},\widehat{y}_{i})
. The coefficient
C_{t}\in\mathbb{R}
is given by

C_{t}=\frac{1}{n}\sum_{i=1}^{n}\frac{\partial g_{t}}{\partial y}(y,\widehat{y}_{i})\Big|_{y=y^{t}_{i}}

We initialize this process with
g_{0}(\cdot,\widehat{\bm{y}})=\widehat{\bm{y}}
; notice that
C_{0}=0
.

There are two crucial differences from the standard model in (
3
): (
i
) instead of having a normalization factor of
{1}/{n}
in the model-update step, we split it between the model-update and soft-prediction steps in our process by incorporating a factor of
{1}/{\sqrt{n}}
at each step, and (
ii
) we have ‘memory correction’ terms (
-C_{t}\bm{\theta}^{t}
and
-g_{t}(\bm{y}^{t},\widehat{\bm{y}})\frac{d}{n}
) in both steps.

The updates (
4
) and (
5
) are in the form of Approximate Message Passing (AMP), which was introduced by adapting ideas from graphical models (belief
propagation) and statistical physics to estimation problems
[
13
,
36
,
18
]
.
The memory correction terms
-C_{t}\bm{\theta}^{t}
and
-g_{t}(\bm{y}^{t},\widehat{y})\frac{d}{n}
(also called ‘Onsager’ correction in statistical physics and the AMP literature) can be thought of as a momentum term, and plays a key role in ensuring that the asymptotic distributions of
(\bm{\theta}^{t},\bm{y}^{t})
are Gaussian. To build some insight on the role of these memory terms, note that the data matrix
{\bm{X}}
is fixed across iterations, and so
\bm{\theta}^{t}
,
\bm{y}^{t}
and
{\bm{X}}
are correlated, which induces some bias in the estimates. The memory terms
are designed specifically to act as debiasing terms to compensate for this dependence. Specifically, the effect of these corrections is the same as an iterative procedure without these terms, wherein the data matrix is resampled at every iteration, making it independent from the current estimates (as pointed out by
[
4
,
12
]
). Of course the latter is not a practical algorithm, since the data matrix is fixed, but it is shown that both will have the same limiting behavior.

3.2
Analysis of the Retraining Process

Assumption 1

We assume the following:

•

As
n,d\to\infty
, the ratio
d/n\to\alpha\in(0,\infty)
.

•

The empirical distributions of the entries of
(\sqrt{d}{\bm{{\mu}}})
(recall
\pm{\bm{{\mu}}}
are the class means; see (
1
)) converges weakly to a probability distribution
\nu_{M}
on
\mathbb{R}
with bounded second moment. Let
\gamma^{2}=\operatorname{\mathbb{E}}_{\nu_{M}}[M^{2}]
.

•

The function
g_{t}:\mathbb{R}\times\mathbb{R}\mapsto\mathbb{R}
is Lipschitz continuous.

We first characterize the test error of a model
\bm{\theta}
under our data model.

Test classification error.
For a model
\bm{\theta}
, its predicted label for a test point
\bm{x}
is given by
{\rm sign}(\bm{x}^{\sf T}\bm{\theta})
. Therefore, the classification error amounts to (recall that
\Phi(u)=\frac{1}{\sqrt{2\pi}}\int_{-\infty}^{u}e^{-t^{2}/2}{\rm d}t
):

\displaystyle P_{e}(\bm{\theta})=\mathbb{P}(y\bm{x}^{\sf T}\bm{\theta}<0)=\mathbb{P}(y(y{\bm{{\mu}}}^{\sf T}+{\bm{z}}^{\sf T})\bm{\theta}<0)=\mathbb{P}(y{\bm{z}}^{\sf T}\bm{\theta}<-{\bm{{\mu}}}^{\sf T}\bm{\theta})=\Phi\left(-\frac{{\bm{{\mu}}}^{\sf T}\bm{\theta}}{\left\|\bm{\theta}\right\|_{\ell_{2}}}\right)\,.

(6)

State evolution.

A remarkable property of AMP algorithms is that their high-dimensional behavior admits an
exact
description
. In essence, the vectors
\bm{\theta}^{t},\bm{y}^{t}
have asymptotically i.i.d. Gaussian entries in the asymptotic regime (Assumption
2
), at fixed
t
. The mean and variance of
\bm{\theta}^{t},\bm{y}^{t}
can be computed through a deterministic recursion called
state evolution
. The validity of state evolution has been proved for a broad class of random matrices. Before describing it for our current setting, we establish some notation.

Let
Y
be a random variable distributed as original labels, namely
\mathbb{P}(Y=1)=\pi_{+}
and
\mathbb{P}(Y=-1)=\pi_{-}
. Also, let
\widehat{Y}
be a random variable distributed as noisy labels, namely
\mathbb{P}(\widehat{Y}=Y)=(1-p)
and
\mathbb{P}(\widehat{Y}=-Y)=p
. The state evolution involves sequence of deterministic quantities
(m_{t},\sigma_{t})_{t\geq 0}
defined by the following recursions:

\displaystyle\bar{m}_{t}=\gamma\sqrt{\alpha}m_{t},\quad\bar{\sigma}_{t}^{2}=\alpha(m_{t}^{2}+\sigma_{t}^{2})

\displaystyle m_{t+1}=\frac{\gamma}{\sqrt{\alpha}}\operatorname{\mathbb{E}}\Big\{g_{t}(\bar{m}_{t}Y+\bar{\sigma}_{t}G,\widehat{Y})Y\Big\},\quad\sigma_{t+1}^{2}=\operatorname{\mathbb{E}}\Big\{g_{t}^{2}(\bar{m}_{t}Y+\bar{\sigma}_{t}G,\widehat{Y})\Big\}\,,

(7)

where
G\sim{\sf N}(0,1)
is independent of other random variables.

The next theorem (proved in Appendix
A
) states that the mean and the variance of
(\bm{\theta}^{t},\bm{y}^{t})
can be described by the state evolution sequence
(m_{t},\sigma_{t})
. In addition it characterizes the limiting behavior of
P_{e}(\bm{\theta})
(test error of the model) in terms of state evolution sequence.

Theorem 3.1

Let
(\bm{\theta}^{t},\bm{y}^{t})_{t\geq 0}
be the AMP iterates given by (
4
)-(
5
). Also let
(m_{t},\sigma_{t})_{t\geq 0}
be the state evolution recursions given by (
7
). Then under Assumption
1
, for any pseudo-Lipschitz function
\psi:\mathbb{R}^{2}\to\mathbb{R}
the following holds
almost surely for
t\geq 0
:

\displaystyle\lim_{n\to\infty}\left|\frac{1}{d}\sum_{i=1}^{d}\psi(\theta_{i}^{t},\sqrt{d}\mu_{i})-\operatorname{\mathbb{E}}\left[\psi\Big(\frac{m_{t}}{\gamma}M+\sigma_{t}G,M\Big)\right]\right|=0\,,

(8)

where
G\sim{\sf N}(0,1)
,
M\sim\nu_{M}
(see second bullet point of Assumption
1
) are independent.
Recall that
g_{0}(\cdot,\widehat{y})=\widehat{y}
, which corresponds to the initialization of state evolution recursion with
m_{1}=\gamma(1-2p)/\sqrt{\alpha}
and
\sigma_{1}=1
. In addition, we have almost surely:

\displaystyle\lim_{n\to\infty}P_{e}(\bm{\theta}^{t})=\Phi\left(-\frac{m_{t}\gamma}{\sqrt{m_{t}^{2}+\sigma_{t}^{2}}}\right)\,.

(9)

3.3
Optimal Choice of Aggregator Functions

In the AMP iterations (
4
) and (
5
),
\bm{\theta}^{t}
is the model estimate and
\bm{y}^{t}
is the soft predictions vector at iteration
t
. We will now discuss some examples of the
aggregator
function
g_{t}
; in particular, these examples describe the retraining methods proposed in
[
9
]
:
2
2

2

It is worth mentioning that
[
9
]
analyze the simple model in (
3
) and not our AMP-based model.

•

Full retraining
[
9
]
:
In this case,
g_{t}(\bm{y}^{t},\widehat{\bm{y}})={\rm sign}(\bm{y}^{t})
for
t\geq 1
. So in this type of retraining, the noisy labels are not used and only the current model’s predicted labels are used.

•

Consensus-based retraining
[
9
]
:
In this case,
g_{t}(\bm{y}^{t},\widehat{\bm{y}})=\widehat{\bm{y}}\mathbb{1}(\bm{y}^{t}\widehat{\bm{y}}>0)
for
t\geq 1
. So here, retraining is done only using the samples for which the predicted label matches the noisy labels.

Note that the result of Theorem
3.1
does not apply to these examples directly, because the
g_{t}
’s here are not Lipschitz. However, we can approximate them by Lipschitz functions, see (
33
) and Appendix
E
for further details.

In this section, we aim to derive the
optimal choice of aggregator functions
. Note that from Equation (
9
), the test error of
\bm{\theta}^{t}
is an increasing function of
m_{t}/\sigma_{t}
. Suppose that the retraining is run for
t
iterations, so
\bar{m}_{t},\bar{\sigma}_{t}
are determined. The optimal aggregator is the one that maximizes
m_{t}/\sigma_{t}
. Recalling the state evolution (
7
), we have

\displaystyle\frac{m_{t+1}^{2}}{\sigma_{t+1}^{2}}=\frac{\gamma^{2}}{\alpha}\frac{\operatorname{\mathbb{E}}\{g_{t}(\bar{m}_{t}Y+\bar{\sigma}_{t}G,\widehat{Y})Y\}^{2}}{\operatorname{\mathbb{E}}\{g_{t}^{2}(\bar{m}_{t}Y+\bar{\sigma}_{t}G,\widehat{Y})\}}\leq\frac{\gamma^{2}}{\alpha}\operatorname{\mathbb{E}}\{(2q_{t}-1)^{2}\}\,,

(10)

with
q_{t}:=\mathbb{P}(Y=1|\bar{m}_{t}Y+\bar{\sigma}_{t}G,\widehat{Y})
. The above inequality holds because by the law of iterated expectations, we have

\displaystyle\operatorname{\mathbb{E}}\{{g}_{t}(\bar{m}_{t}Y+\bar{\sigma}_{t}G,\widehat{Y})Y\}

\displaystyle=\operatorname{\mathbb{E}}\{{g}_{t}(\bar{m}_{t}Y+\bar{\sigma}_{t}G,\widehat{Y})\operatorname{\mathbb{E}}\{Y|\bar{m}_{t}Y+\bar{\sigma}_{t}G,\widehat{Y}\}\}

\displaystyle=\operatorname{\mathbb{E}}\{g_{t}(\bar{m}_{t}Y+\bar{\sigma}_{t}G,\widehat{Y})(2q_{t}-1)\}\,,

and so (
10
) follows from Cauchy-Schwarz inequality. Also, the upper bound is achieved when
g_{t}
is (any scaling of)
2q_{t}-1
. Therefore, for this optimal choice of
g_{t}^{*}
we have

\displaystyle m_{t+1}=\frac{\gamma}{\sqrt{\alpha}}\operatorname{\mathbb{E}}\Big\{\big(g^{*}_{t}(\bar{m}_{t}Y+\bar{\sigma}_{t}G,\widehat{Y})\big)^{2}\Big\},\quad\sigma_{t+1}^{2}=\operatorname{\mathbb{E}}\Big\{\big(g^{*}_{t}(\bar{m}_{t}Y+\bar{\sigma}_{t}G,\widehat{Y})\big)^{2}\Big\}\,,

(11)

and so
m_{t+1}=\frac{\gamma}{\sqrt{\alpha}}\sigma_{t+1}^{2}
. We let
\eta_{t}:=\frac{m_{t}}{\sigma_{t}}
and so

\displaystyle m_{t}=\frac{\sqrt{\alpha}}{\gamma}\eta_{t}^{2},\quad\sigma_{t}=\frac{\sqrt{\alpha}}{\gamma}\eta_{t},\quad\bar{m}_{t}=\alpha\eta_{t}^{2},\quad\bar{\sigma}_{t}^{2}=\frac{\alpha^{2}}{\gamma^{2}}\eta_{t}^{2}(\eta_{t}^{2}+1)\,.

(12)

Therefore, we can write the state evolution and the optimal aggregator, only in terms of
\eta_{t}
. We formally state it in the next theorem (proved in Appendix
B
).

Theorem 3.2

Recall that
\pi_{+},\pi_{-}
are the class probabilities and
p
is the label flipping probability. The optimal aggregator functions for the AMP-based procedure in (
4
)-(
5
) is given by:

\displaystyle g_{t}^{*}(y,\widehat{y})=\frac{2}{1+\big(\frac{p}{1-p}\big)^{\widehat{y}}\exp\Big(-\frac{2\gamma^{2}y}{\alpha(\eta_{t}^{2}+1)}\Big)\frac{\pi_{-}}{\pi_{+}}}-1\,,

(13)

for
t\geq 1
(recall that
g_{0}^{*}(\cdot,\widehat{y})=\widehat{y}
). In addition, we have:

P_{e}(\bm{\theta}^{t})\stackrel{{\scriptstyle p}}{{\longrightarrow}}\Phi\left(-\frac{\gamma\eta_{t}}{\sqrt{\eta_{t}^{2}+1}}\right)\,,

where
(\eta_{t})_{t\geq 1}
is given by the following state evolution recursion:

\displaystyle\eta_{t+1}^{2}=\frac{\gamma^{2}}{\alpha}\operatorname{\mathbb{E}}\left\{\Bigg(g_{t}^{*}\left(\alpha\eta_{t}^{2}Y+\frac{\alpha}{\gamma}\eta_{t}\sqrt{\eta_{t}^{2}+1}G,\widehat{Y}\right)\Bigg)^{2}\right\}\,,

(14)

with initialization
\eta_{1}=\gamma(1-2p)/\sqrt{\alpha}
.

We perform some simulations in Appendix
D
to verify our theory, and compare the performance of optimal aggregator with the full retraining and the consensus-bases retraining schemes.

Discussion.
The state evolution sequence
(\eta_{t})_{t\geq 0}
in (
14
) can be rewritten as
\eta_{t+1}^{2}=F(\eta_{t}^{2})
with

\displaystyle F(u)=\frac{\gamma^{2}}{\alpha}\operatorname{\mathbb{E}}\left\{\Big(\tilde{g}\left(\gamma^{2}\tfrac{u}{1+u}Y+\gamma\sqrt{\tfrac{u}{1+u}}G,\widehat{Y}\right)\Big)^{2}\right\}\,,\quad\tilde{g}(y,\widehat{y})=\frac{2}{1+(\frac{p}{1-p})^{\widehat{y}}e^{-2y}\frac{\pi_{-}}{\pi_{+}}}-1\,.

(15)

In Figure
1
, we illustrate an example of this mapping along with the sequence
(\eta_{t})_{t\geq 1}
(Cobweb diagram). As can be observed from the figure (and also formalized in Proposition
3.3
), the mapping
F
is non-decreasing. When
\eta_{1}
is small, the sequence
\eta_{t}
increases, while if
\eta_{1}
is large, the sequence decreases. Since the test error decreases as
\eta
increases, this leads to an interesting observation:
if the initial model is poor, retraining helps improve its performance, but if the initial model is already good, retraining can actually hurt its performance.
We formalize this observation in the next proposition (proved in Appendix
C
).

Proposition 3.3

The following statements hold:

(i) The function
F
defined in (
15
) is non-decreasing on
[0,\infty)
. Also, it has at least one fixed point, i.e., there exists a solution to
\eta^{2}=F(\eta^{2})
. Let
\eta_{*}^{2}
be the smallest fixed point. If
\eta_{1}\leq\eta_{*}
then the state evolution sequence
(\eta_{t})_{t\geq 1}
is non-decreasing, and hence retraining reduces the test error.

(ii) Suppose that
\gamma^{2}\geq\sqrt{\frac{\pi\alpha}{2}}
. A sufficient condition for the sequence
(\eta_{t})_{t\geq 1}
to be non-decreasing is that
p\in[p_{*},\frac{1}{2})
, with
p_{*}<\frac{1}{2}
being the unique solution of the equation:
\Phi\left(\frac{-\gamma^{2}(1-2p)}{\sqrt{\gamma^{2}(1-2p)^{2}+\alpha}}\right)=p
.

Generalized Linear Model (GLM)

Consider a data matrix
{\bm{X}}\in\mathbb{R}^{n\times d}
, with rows
\bm{x}_{1},\dotsc,\bm{x}_{n}\sim{\sf N}(0,\bm{I}_{d}/n)
,
3
3

3

The scaling of
1/n
in the covariance matrix is for ease of exposition. Our analysis can be extended even if the covariance matrix is
\bm{I}_{d}
at the cost of more tedious exposition.

and corresponding labels
\bm{y}=[y_{1},\dotsc,y_{n}]^{\top}\in\mathbb{R}^{n}
generated with the following probabilistic rule:

\mathbb{P}(y_{i}=1|\bm{x}_{i})=h(\bm{x}_{i}^{\sf T}\bbeta)\,,

for a known link function
h
. However, the learner observes noisy labels
\widehat{\bm{y}}=[\widehat{y}_{1},\dotsc,\widehat{y}_{n}]^{\sf T}\in\mathbb{R}^{n}
, where the
\widehat{y}_{i}
’s follow the same noise model as (
2
) with
p
being the label flipping probability.
We also define
\hat{h}_{p}(z):=(1-p)h(z)+p(1-h(z))
. Note that
\mathbb{P}(\widehat{y}_{i}=1|\bm{x}_{i})=\hat{h}_{p}(\bm{x}_{i}^{\sf T}\bbeta)
.

AMP-based update rule:
Similar to the AMP-based iterative update rule for GMM in (
4
)-(
5
), we progressively update our classifier
\bbeta^{t}
at iteration
t
with an aggregator function
g_{t}
as follows:

\displaystyle\bm{\beta}^{t+1}

\displaystyle=

\displaystyle{\bm{X}}^{\sf T}g_{t}(\bm{y}^{t},\widehat{\bm{y}})-C_{t}\bbeta^{t},

(16)

\displaystyle\bm{y}^{t+1}

\displaystyle=

\displaystyle{\bm{X}}\bbeta^{t+1}-g_{t}(\bm{y}^{t},\widehat{\bm{y}})\frac{d}{n}.\,

(17)

Similar to the GMM case, the aggregator function
g_{t}
is applied entry wise, the Onsager coefficient
C_{t}\in\mathbb{R}
is given by

C_{t}=\frac{1}{n}\sum_{i=1}^{n}\frac{\partial g_{t}}{\partial y}(y,\widehat{y}_{i})\Big|_{y=y^{t}_{i}},

and the process is initialized with
g_{0}(\cdot,\widehat{\bm{y}})=\widehat{\bm{y}}
.

We track the performance of the classifier
\bbeta^{t}
via its test error. For a model
\bm{\theta}
, its predicted label for a test point
\bm{x}
is given by
{\rm sign}(\bm{x}^{\sf T}\bm{\theta})
.
We first state the assumptions needed for our subsequent results.

Assumption 2

We assume the following:

•

As
n,d\to\infty
, the ratio
d/n\to\alpha\in(0,\infty)
.

•

The empirical distributions of the entries of
\bbeta
converges weakly to a probability distribution
\pi_{\bar{\beta}}
on
\mathbb{R}
with bounded second moment. Let
\gamma^{2}=\operatorname{\mathbb{E}}_{\pi_{\bar{\beta}}}[\bar{\beta}^{2}]
.

•

The function
g_{t}:\mathbb{R}\times\mathbb{R}\mapsto\mathbb{R}
is Lipschitz continuous.

Our next lemma (proved in Appendix
F
) characterizes the test error of a model
\bm{\theta}
.

Lemma 4.1

For a model
\bm{\theta}
, define its test error
P_{e}(\bm{\theta}):=\mathbb{P}(y\bm{x}^{\sf T}\bm{\theta}<0)
, where
(\bm{x},y)
is generated from the GLM. Define
\rho:=\bbeta^{\sf T}\bm{\theta}/(\left\|\bbeta\right\|_{\ell_{2}}\left\|\bm{\theta}\right\|_{\ell_{2}})
. Then,

\displaystyle P_{e}(\bm{\theta})=F(\rho):=\operatorname{\mathbb{E}}\left[\Phi\left(\frac{\rho Z}{\sqrt{1-\rho^{2}}}\right)\Big(1-h\big(\sqrt{\alpha}\gamma Z\big)\Big)+\Phi\left(\frac{-\rho Z}{\sqrt{1-\rho^{2}}}\right)h\big(\sqrt{\alpha}\gamma Z\big)\right]\,,

(18)

with
Z\sim{\sf N}(0,1)
. In addition,
F
is a decreasing function, if
h(u)>h(-u)
, for all
u>0
.

State evolution.
We will describe state evolution just as we did for the GMM case. The state evolution parameters
(\mu_{t},\sigma_{t})_{t\geq 1}
are recursively defined by:

\displaystyle\mu_{1}=\frac{2}{\alpha\gamma^{2}}\operatorname{\mathbb{E}}[Z\hat{h}_{p}(Z)],\quad\sigma_{1}=\sqrt{\alpha}

\displaystyle\mu_{t+1}=\operatorname{\mathbb{E}}\left[\frac{\operatorname{\mathbb{E}}(Z|Z_{t},\widehat{Y})-\operatorname{\mathbb{E}}(Z|Z_{t})}{\textrm{Var}(Z|Z_{t})}g_{t}(Z_{t},\widehat{Y})\right],\quad\sigma_{t+1}^{2}=\alpha\operatorname{\mathbb{E}}\big[g_{t}^{2}(Z_{t},\widehat{Y})\big]\,,

(19)

where
Z\sim{\sf N}(0,\alpha\gamma^{2})
and
Z_{t}=\mu_{t}Z+\sigma_{t}G
, where
G\sim{\sf N}(0,1)
is independent of other random variables. In addition,
\widehat{Y}\in\{-1,+1\}
with
\mathbb{P}(\widehat{Y}=1)=\hat{h}_{p}(Z)
.
Using the joint Gaussianity of
(Z_{t},Z)
, we can calculate
\operatorname{\mathbb{E}}(Z|Z_{t})
and
\textrm{Var}(Z|Z_{t})
more explicitly, as follows:

\displaystyle\operatorname{\mathbb{E}}(Z|Z_{t})=\frac{\alpha\mu_{t}\gamma^{2}}{\sigma_{t}^{2}+\alpha\mu_{t}^{2}\gamma^{2}}Z_{t},\quad\quad\textrm{Var}(Z|Z_{t})=\frac{\alpha\sigma_{t}^{2}\gamma^{2}}{\sigma_{t}^{2}+\alpha\mu_{t}^{2}\gamma^{2}}\,.

(20)

Using these identities, we can rewrite the state evolution recursion as:

\displaystyle\mu_{1}=\frac{2}{\alpha\gamma^{2}}\operatorname{\mathbb{E}}[Z\hat{h}_{p}(Z)],\quad\sigma_{1}=\sqrt{\alpha},

(21)

\displaystyle\mu_{t+1}=\Big(\frac{1}{\alpha\gamma^{2}}+\frac{\mu_{t}^{2}}{\sigma_{t}^{2}}\Big)\operatorname{\mathbb{E}}\left[\operatorname{\mathbb{E}}(Z|Z_{t},\widehat{Y})g_{t}(Z_{t},\widehat{Y})\right]-\frac{\mu_{t}}{\sigma_{t}^{2}}\operatorname{\mathbb{E}}\left[Z_{t}g_{t}(Z_{t},\widehat{Y})\right],\quad\sigma_{t+1}^{2}=\alpha\operatorname{\mathbb{E}}(g_{t}^{2}(Z_{t},\widehat{Y}))\,.

The next theorem establishes that for every fixed
t
, the asymptotic behavior of
\bbeta^{t}
is precisely characterized by the state evolution recursion, which in turn precisely provides the limiting behavior of the test error of
\bbeta^{t}
, for every fixed iteration
t
. The proof largely follows from the analysis of generalized AMP (GAMPs) algorithm proposed by
[
36
]
along with Stein’s lemma to further simplify the state evolution recursion (similar to
[
27
, Proposition 3.1]
). Please refer to Appendix
G
for further details and initialization of the state evolution.

Theorem 4.2

Let
(\bbeta^{t},\bm{y}^{t})_{t\geq 0}
be the AMP iterates given by (
16
)-(
17
). Also let
(\mu_{t},\sigma_{t})_{t\geq 0}
be the state evolution recursions given by (
21
). Then under Assumption
2
, for any pseudo-Lipschitz function
\psi:\mathbb{R}^{2}\to\mathbb{R}
the following holds
almost surely for
t\geq 0
:

\displaystyle\lim_{n\to\infty}\left|\frac{1}{d}\sum_{i=1}^{d}\psi(\beta_{i}^{t},\beta_{i})-\operatorname{\mathbb{E}}\left[\psi\Big(\mu_{t}\bar{\beta}+\frac{\sigma_{t}}{\sqrt{\alpha}}G,\bar{\beta}\Big)\right]\right|=0\,,

(22)

where
G\sim{\sf N}(0,1)
and
\bar{\beta}\sim\pi_{\bar{\beta}}
(see second bullet point of Assumption
2
) are independent. Recall that
g_{0}(\cdot,\widehat{y})=\widehat{y}
, which corresponds to the initialization of state evolution recursion with
\mu_{1}=\frac{2}{\alpha\gamma^{2}}\operatorname{\mathbb{E}}[Z\hat{h}_{p}(Z)]
where
Z\sim{\sf N}(0,\alpha\gamma^{2})
, and
\sigma_{1}=\sqrt{\alpha}
. In addition, we have almost surely,

\displaystyle\lim_{n\to\infty}P_{e}(\bbeta^{t})=F\left(\frac{\eta_{t}\gamma}{\sqrt{\eta_{t}^{2}\gamma^{2}+\frac{1}{\alpha}}}\right)\,,

(23)

where
\eta_{t}=\mu_{t}/\sigma_{t}
and
F(\rho)
is given by (
18
).

Optimal choice of aggregator functions
g_{t}
.
Using Equation
23
, and since
F
is a decreasing function, the optimal
g_{t}
is the one that, fixing the history of the algorithm, maximizes
\eta_{t+1}
. Invoking the state evolution (
19
), we have

\displaystyle\eta_{t+1}^{2}:=\frac{\mu_{t+1}^{2}}{\sigma_{t+1}^{2}}=\frac{\operatorname{\mathbb{E}}\left(\frac{\operatorname{\mathbb{E}}(Z|Z_{t},\widehat{Y})-\operatorname{\mathbb{E}}(Z|Z_{t})}{\textrm{Var}(Z|Z_{t})}g_{t}(Z_{t},\widehat{Y})\right)^{2}}{\alpha\operatorname{\mathbb{E}}(g_{t}^{2}(Z_{t},\widehat{Y}))}\leq\frac{1}{\alpha}\operatorname{\mathbb{E}}\left(\left[\frac{\operatorname{\mathbb{E}}(Z|Z_{t},\widehat{Y})-\operatorname{\mathbb{E}}(Z|Z_{t})}{\textrm{Var}(Z|Z_{t})}\right]^{2}\right)\,,

using the Cauchy-Schwarz inequality. The optimal aggregator for which the equality happens in the above equation, is when the aggregator is (any deterministic scalar) of

\displaystyle g^{*}_{t}(Z_{t},\widehat{Y})

\displaystyle=\frac{\operatorname{\mathbb{E}}(Z|Z_{t},\widehat{Y})-\operatorname{\mathbb{E}}(Z|Z_{t})}{\textrm{Var}(Z|Z_{t})}=\frac{\operatorname{\mathbb{E}}(Z|Z_{t},\widehat{Y})}{\frac{\alpha\sigma_{t}^{2}\gamma^{2}}{\sigma_{t}^{2}+\alpha\mu_{t}^{2}\gamma^{2}}}-\frac{\mu_{t}}{\sigma_{t}^{2}}Z_{t}=\left(\frac{1}{\alpha\gamma^{2}}+\frac{\mu_{t}^{2}}{\sigma_{t}^{2}}\right)\operatorname{\mathbb{E}}(Z|Z_{t},\widehat{Y})-\frac{\mu_{t}}{\sigma_{t}^{2}}Z_{t}\,.

(24)

We give a more explicit characterization of the optimal aggregator in the next proposition, by writing
\operatorname{\mathbb{E}}(Z|Z_{,}\widehat{Y})
explicitly using the Bayes rule. We also show that the state evolution for the optimal aggregator can be written directly in terms of

Theorem 4.3

The optimal aggregator functions in the AMP-based procedure is given by:

\displaystyle g^{*}_{t}(y,\widehat{y})=\left(\frac{1}{\alpha\gamma^{2}}+\eta_{t}^{2}\right)\frac{\int_{-\infty}^{\infty}ze^{-\frac{\eta_{t}^{2}z^{2}}{2}+\frac{yz}{\alpha}}\big(\hat{h}_{p}(z)\big)^{\frac{1+\widehat{y}}{2}}\big(1-\hat{h}_{p}(z)\big)^{\frac{1-\widehat{y}}{2}}e^{-\frac{z^{2}}{2\alpha\gamma^{2}}}{\rm d}z}{\int_{-\infty}^{\infty}e^{-\frac{\eta_{t}^{2}z^{2}}{2}+\frac{yz}{\alpha}}\big(\hat{h}_{p}(z)\big)^{\frac{1+\widehat{y}}{2}}\big(1-\hat{h}_{p}(z)\big)^{\frac{1-\widehat{y}}{2}}e^{-\frac{z^{2}}{2\alpha\gamma^{2}}}{\rm d}z}-\frac{y}{\alpha}\,,

(25)

for
t\geq 1
, and
{g}^{*}_{0}(\cdot,\widehat{y})=\widehat{y}
, where
(\eta_{t})_{t\geq 1}
is given by the following state evolution recursion:

\displaystyle\eta_{1}=\frac{2}{\alpha^{3/2}\gamma^{2}}\operatorname{\mathbb{E}}[Z\hat{h}_{p}(Z)],\quad\eta_{t+1}^{2}=\frac{1}{\alpha}\operatorname{\mathbb{E}}\Bigg\{\Big(g^{*}_{t}(\alpha\eta_{t}^{2}Z+\alpha\eta_{t}G,\widehat{Y})\Big)^{2}\Bigg\}\,,

(26)

where
Z\sim{\sf N}(0,\alpha\gamma^{2})
and

are independent of each other. In addition,
\widehat{Y}\in\{-1,+1\}
with
\mathbb{P}(\widehat{Y}=1|Z)=\hat{h}_{p}(Z)

6
Conclusion

In this paper, we analyzed optimal model retraining by deriving the Bayes optimal aggregator function to combine the given labels and model predictions for binary classification. Our framework quantified the performance of this strategy over multiple retraining iterations. We also proposed a practical variant for linear probing with the cross-entropy loss and showed that it outperforms existing baselines in the high noise regime.

We conclude by discussing some limitations of our work which pave the way for future directions of work. Our results in this work are for linear models and binary classification.
In the multi-class GMM case, the data matrix is a low rank perturbation of a Gaussian matrix. AMP has been studied for such settings
[
30
,
19
,
29
]
, so we can build on such results to derive the optimal aggregator in the future. Also, we would like to extend our results to label noise models beyond uniform noise. Further, we would like to propose variants for optimally retraining non-linear deep learning models.

Proof of Theorem
3.1

To build some intuition on the statement of the theorem and the choice of memory correction terms, we analyze the distribution of the first few estimate of the AMP updates in (
4
)-(
5
).

Since
g_{0}(\cdot,\widehat{y})=\widehat{y}
, we have
C_{0}=0
and

\bm{\theta}^{1}=\frac{1}{\sqrt{n}}{\bm{X}}^{\sf T}\widehat{\bm{y}}
. Under the GMM, we have
{\bm{X}}=\bm{y}{\bm{{\mu}}}^{\sf T}+\mathbb{Z}
with
Z_{ij}\sim{\sf N}(0,1)
, independently. Fixing
\bm{y}
, we have that
\widehat{\bm{y}}
and
\mathbb{Z}
are independent. We write

\displaystyle\bm{\theta}^{1}

\displaystyle=\frac{1}{\sqrt{n}}{\bm{X}}^{\sf T}\widehat{\bm{y}}

\displaystyle=\frac{({\bm{{\mu}}}\bm{y}^{\sf T}+\bm{Z}^{\sf T})\widehat{\bm{y}}}{\sqrt{n}}

\displaystyle=\sqrt{\frac{n}{d}}\sqrt{d}{\bm{{\mu}}}\frac{\bm{y}^{\sf T}\widehat{\bm{y}}}{n}+\frac{\bm{Z}^{\sf T}\widehat{\bm{y}}}{\sqrt{n}}\,.

(28)

By law of large number,
\frac{\bm{y}^{\sf T}\widehat{\bm{y}}}{n}\stackrel{{\scriptstyle p}}{{\to}}(1-2p)
. Also under Assumption
1
,
\frac{n}{d}\to\frac{1}{\alpha}
and the empirical distribution of
\sqrt{d}{\bm{{\mu}}}
converges weakly to distribution of
M\sim\nu_{M}
. Therefore the first term in the decomposition (
28
) converges to
(1-2p)\frac{M}{\sqrt{\alpha}}
. Given that
\widehat{y}
and
\mathbb{Z}
are independent, thee second term is distributed as
{\sf N}(0,1)
. This implies that the empirical distribution of
\bm{\theta}^{1}
converges weakly to
\frac{M}{\sqrt{\alpha}}(1-2p)+G
, with
G\sim{\sf N}(0,1)
. This implies the claim of the theorem for
t=1
, with
m_{1}=\gamma(1-2p)/\sqrt{\alpha}
and
\sigma_{1}=1
.

We next characterize the distribution of
\widehat{\bm{y}}^{1}=\frac{1}{\sqrt{n}}{\bm{X}}^{\sf T}\bm{\theta}^{1}-\frac{d}{n}\widehat{\bm{y}}
, which also sheds light on the choice of correction term
-\frac{d}{n}\widehat{\bm{y}}
. We have

\displaystyle\bm{y}^{1}

\displaystyle=\frac{1}{n}{\bm{X}}{\bm{X}}^{\sf T}\widehat{\bm{y}}-\frac{d}{n}\widehat{\bm{y}}

\displaystyle=\frac{1}{n}(\bm{y}{\bm{{\mu}}}^{\sf T}+\bm{Z})({\bm{{\mu}}}\bm{y}^{\sf T}+\bm{Z}^{\sf T})\widehat{\bm{y}}-\frac{d}{n}\widehat{\bm{y}}

\displaystyle=\frac{1}{n}(\bm{y}\bm{y}^{\sf T}\left\|{\bm{{\mu}}}\right\|_{\ell_{2}}^{2}+\bm{Z}{\bm{{\mu}}}\bm{y}^{\sf T}+\bm{y}{\bm{{\mu}}}^{\sf T}\bm{Z}^{\sf T}+\bm{Z}\bm{Z}^{\sf T})\widehat{\bm{y}}-\frac{d}{n}\widehat{\bm{y}}

\displaystyle=\left(\left\|{\bm{{\mu}}}\right\|_{\ell_{2}}^{2}\frac{\bm{y}^{\sf T}\widehat{\bm{y}}}{n}+\frac{1}{n}{\bm{{\mu}}}^{\sf T}\bm{Z}^{\sf T}\widehat{\bm{y}}\right)\bm{y}+\frac{\bm{Z}\bm{Z}^{\sf T}}{n}\widehat{\bm{y}}-\frac{d}{n}\widehat{\bm{y}}+\bm{Z}{\bm{{\mu}}}\frac{\bm{y}^{\sf T}\widehat{\bm{y}}}{n}

(29)

By law of large number and recalling Assumption
1
, we have
\left\|{\bm{{\mu}}}\right\|_{\ell_{2}}^{2}\frac{\bm{y}^{\sf T}\widehat{\bm{y}}}{n}\stackrel{{\scriptstyle p}}{{\to}}(1-2p)\gamma^{2}
. Also given that
\bm{Z}
and
\widehat{\bm{y}}
are independent,
\frac{\bm{Z}^{\sf T}\widehat{\bm{y}}}{\sqrt{n}}\sim{\sf N}(0,\bm{I}_{n})
. Since
\left\|{\bm{{\mu}}}\right\|_{\ell_{2}}^{2}\to\gamma
, which is of order one, we have
\frac{1}{n}{\bm{{\mu}}}^{\sf T}\bm{Z}^{\sf T}\widehat{\bm{y}}
converges to zero.

The remaining terms in (
29
) can be written as

\bm{\Delta}:=(\frac{\bm{Z}\bm{Z}^{\sf T}}{n}-\frac{d}{n}\bm{I}_{n}+\frac{\bm{Z}{\bm{{\mu}}}\bm{y}^{\sf T}}{n})\widehat{\bm{y}}
. Note that the term
\operatorname{\mathbb{E}}(\bm{Z}\bm{Z}^{\sf T}/n)=(d/n)\bm{I}_{n}
and so
\bm{\Delta}
is zero mean. (This also justifies the choice of correction term
-\frac{d}{n}\widehat{\bm{y}}
.) In addition, by virtue of the central limit theorem, each entry
\Delta_{i}
is approximately normal with variance
\alpha^{2}+(1-2p)^{2}\gamma^{2}
. This implies that the empirical distribution of entries
y^{1}
, converges to
\bar{m}_{1}Y+\bar{\sigma}_{1}G
, with

\bar{m}_{1}=\gamma^{2}(1-2p),\quad\bar{\sigma}_{1}^{2}=\alpha+\gamma^{2}(1-2p)^{2}\,.

The proof of Theorem
3.1
follows by adapting techniques from standard AMP analysis (see e.g.,
[
18
,
30
,
14
]
), and so omitted here. A major step in the proof to characterize the conditional distribution of
\bm{\theta}^{t},\bm{y}^{t}
given the previous
iterates
(\bm{\theta}^{\tau},\bm{y}^{\tau})_{\tau<t}
, and then show that the ‘non-Gaussian components’ thereof are
asymptotically canceled out by the memory correction terms. A technical challenge though is that in the AMP theory the initialization should be independent from the random matrix
{\bm{X}}
. Here the initial estimator is
\bm{\theta}^{1}={\bm{X}}^{\sf T}\widehat{\bm{y}}/\sqrt{n}
which depends on
{\bm{X}}
. The trick is to consider the AMP updates, starting from
t=0
with
\bm{\theta}^{0}=\bm{0}
and
g_{-1}(\cdot,\cdot)=0
. This way, the initialization is independent of
{\bm{X}}
and by update rule (
4
)-(
5
) we have
\bm{y}^{0}=\bm{0}
and with
g_{1}(y,\widehat{y})=\widehat{y}
we get
\bm{\theta}^{1}={\bm{X}}^{\sf T}\widehat{\bm{y}}/\sqrt{n}
so we will be on the trajectory of the updates.

To derive the limit of
P_{e}(\bm{\theta})
, we first note that the functions
\psi(x,y)=xy
and
\psi(x,y)=x^{2}
are pseudo-Lipschitz (of order 2). Therefore, using (
8
),
the following limits hold almost surely,

\displaystyle\lim_{n\to\infty}\frac{1}{d}\left\|\bm{\theta}\right\|_{\ell_{2}}^{2}

\displaystyle=\lim_{n\to\infty}\frac{1}{d}\sum_{i=1}^{d}|(\theta_{i}^{t})^{2}|=\operatorname{\mathbb{E}}\left[\left(\frac{m_{t}}{\gamma}M+\sigma_{t}G\right)^{2}\right]=m_{t}^{2}+\sigma_{t}^{2}\,,

\displaystyle\lim_{n\to\infty}\frac{1}{\sqrt{d}}{\bm{{\mu}}}^{\sf T}\bm{\theta}^{t}

\displaystyle=\lim_{n\to\infty}\frac{1}{d}\sum_{i=1}^{d}(\sqrt{d}\mu_{i}\theta^{t}_{i})=\operatorname{\mathbb{E}}\left[\left(\frac{m_{t}}{\gamma}M+\sigma_{t}G\right)M\right]=\frac{m_{t}}{\gamma}\operatorname{\mathbb{E}}[M^{2}]=m_{t}\gamma\,,

where we used the identity
\operatorname{\mathbb{E}}[M^{2}]=\gamma^{2}
(second bullet point in Assumption
1
). Hence, by using (
6
), we obtain

\displaystyle\lim_{n\to\infty}P_{e}(\bm{\theta})=\lim_{n\to\infty}\Phi\left(-\frac{{\bm{{\mu}}}^{\sf T}\bm{\theta}^{t}}{\left\|\bm{\theta}\right\|_{\ell_{2}}}\right)=\Phi\left(-\lim_{n\to\infty}\frac{{\bm{{\mu}}}^{\sf T}\bm{\theta}^{t}}{\left\|\bm{\theta}\right\|_{\ell_{2}}}\right)=\Phi\left(-\frac{m_{t}\gamma}{\sqrt{m_{t}^{2}+\sigma_{t}^{2}}}\right)\,,

where the second equality is by continuity of
\Phi
.

Appendix B
Proof of Theorem
3.2

Our derivation prior to the statement of Theorem
3.2
showed that the optimal aggregator
g^{*}_{t}
is given by any scaling of
2q_{t}-1
; we will set the scaling to 1 so that the output of
g^{*}_{t}\in[-1,1]
. By Bayes’ rule, we have

\displaystyle\begin{split}q_{t}(y,\widehat{y})&:=\mathbb{P}(Y=1|\bar{m}_{t}Y+\bar{\sigma}_{t}G=y,\widehat{Y}=\widehat{y})\\
&=\frac{\mathbb{P}\left(G=\tfrac{y-\bar{m}_{t}}{\bar{\sigma}_{t}},\widehat{Y}=\widehat{y}|Y=1\right)\mathbb{P}(Y=1)}{\mathbb{P}\left(G=\tfrac{y-\bar{m}_{t}}{\bar{\sigma}_{t}},\widehat{Y}=\widehat{y}\right)}\\
&=\frac{(1-p)^{\frac{1+\widehat{y}}{2}}p^{\frac{1-\widehat{y}}{2}}e^{-\frac{(y-\bar{m}_{t})^{2}}{2\bar{\sigma}_{t}^{2}}}\pi_{+}}{(1-p)^{\frac{1+\widehat{y}}{2}}p^{\frac{1-\widehat{y}}{2}}e^{-\frac{(y-\bar{m}_{t})^{2}}{2\bar{\sigma}_{t}^{2}}}\pi_{+}+(1-p)^{\frac{1-\widehat{y}}{2}}p^{\frac{1+\widehat{y}}{2}}e^{-\frac{(y+\bar{m}_{t})^{2}}{2\bar{\sigma}_{t}^{2}}}\pi_{-}}\\
&=\frac{1}{1+(\tfrac{p}{1-p})^{\widehat{y}}e^{-2y\frac{\bar{m}_{t}}{\bar{\sigma}_{t}^{2}}}\frac{\pi_{-}}{\pi_{+}}}\,.\end{split}

(30)

By invoking (
12
), we have

\frac{\bar{m}_{t}}{\bar{\sigma}_{t}^{2}}=\frac{\alpha\eta_{t}^{2}}{\frac{\alpha^{2}}{\gamma^{2}}\eta_{t}^{2}(\eta_{t}^{2}+1)}=\frac{\gamma^{2}}{\alpha(\eta_{t}^{2}+1)}\,,

which by plugging into (
30
) gives the desired result.

Next by Equation (
9
) we have

P_{e}(\bm{\theta}^{t})\stackrel{{\scriptstyle p}}{{\longrightarrow}}\Phi\left(-\frac{\gamma\eta_{t}}{\sqrt{\eta_{t}^{2}+1}}\right)\,.

For the sequence
(\eta_{t})_{t\geq 1}
, note that by (
11
), we have

\eta_{t+1}^{2}:=\frac{m_{t+1}^{2}}{\sigma_{t+1}^{2}}=\frac{\gamma^{2}}{\alpha}\operatorname{\mathbb{E}}\{g_{t}^{*}(\bar{m}_{t}Y+\bar{\sigma}_{t}G,\widehat{Y})^{2}\}\,,

which gives the result after substituting for
\bar{m}_{t}
and
\bar{\sigma}_{t}
from (
12
). Also from Theorem
3.1
, we have

\eta_{1}=m_{1}/\sigma_{1}=\gamma(1-2p)/\sqrt{\alpha}
. This concludes the proof of theorem.

Appendix C
Proof of Proposition
3.3

We start by proving the monotonicity of
F
in
(i)
. Since
\bar{\eta}=\gamma^{2}\frac{u}{1+u}
is increasing in
u
it suffices to show that
\operatorname{\mathbb{E}}\{\tilde{g}(\bar{\eta}Y+\sqrt{\bar{\eta}}\widehat{Y})^{2}\}
is non-decreasing in
\bar{\eta}
. Recall that
\tilde{g}
is the Bayes optimal estimator and can also be characterized as
\tilde{g}(\tilde{Y},\widehat{Y})=\operatorname{\mathbb{E}}[Y|\tilde{Y}=\bar{\eta}Y+\sqrt{\bar{\eta}}G,\widehat{Y}]
(see derivation
30
). Hence,
\operatorname{\mathbb{E}}[Y\tilde{g}(\tilde{Y},\widehat{Y})]=\operatorname{\mathbb{E}}[\tilde{g}(\tilde{Y},\widehat{Y})^{2}]
and we can write

\displaystyle\mathcal{R}(\bar{\eta}):=\operatorname{\mathbb{E}}[(Y-\tilde{g}(\tilde{Y},\widehat{Y}))^{2}]=1-\operatorname{\mathbb{E}}[\tilde{g}(\tilde{Y},\widehat{Y}))^{2}].

So we need to show that
\mathcal{R}(\bar{\eta})
is decreasing in
\bar{\eta}
.

Next note that by Bayes-optimality of
\tilde{g}
we have
\mathcal{R}(\bar{\eta})=\inf_{g}\operatorname{\mathbb{E}}[(Y-g(\tilde{Y},\widehat{Y}))^{2}]
where the infimum is with respect to all measurable functions
g
, and
\tilde{Y}=\bar{\eta}Y+\sqrt{\bar{\eta}}G
. Now take
\bar{\eta}_{1}<\bar{\eta}_{2}
. The following holds in distribution:

\bar{\eta}_{1}Y+\sqrt{\bar{\eta}_{1}}G\stackrel{{\scriptstyle d}}{{=}}\frac{\bar{\eta}_{1}}{\bar{\eta}_{2}}(\bar{\eta}_{2}Y+\sqrt{\bar{\eta}_{2}}G)+\sqrt{\bar{\eta}_{1}-\frac{\bar{\eta}_{1}^{2}}{\bar{\eta}_{2}}}Z\,,

where
G,Z\sim{\sf N}(0,1)
independent of each other. We then write

\displaystyle\mathcal{R}(\bar{\eta}_{1})

\displaystyle=\operatorname{\mathbb{E}}[(Y-\tilde{g}(\bar{\eta}_{1}Y+\sqrt{\bar{\eta}_{1}}G,\widehat{Y}))^{2}]

\displaystyle=\operatorname{\mathbb{E}}\Big[\operatorname{\mathbb{E}}\Big[\Big(Y-\tilde{g}\Big(\tfrac{\bar{\eta}_{1}}{\bar{\eta}_{2}}(\bar{\eta}_{2}Y+\sqrt{\bar{\eta}_{2}}G)+\sqrt{\bar{\eta}_{1}-\tfrac{\bar{\eta}_{1}^{2}}{\bar{\eta}_{2}}}z,\widehat{Y}\Big)\Big)^{2}\Big]\Big]\,,

(31)

where the inner expectation is conditional on
Z=z
and the outer expectation is with respect to
Z
. For a fixed
z
, define the function

h_{z}(y,\widehat{y})=\tilde{g}\Bigg(\tfrac{\bar{\eta}_{1}}{\bar{\eta}_{2}}y+\sqrt{\bar{\eta}_{1}-\tfrac{\bar{\eta}_{1}^{2}}{\bar{\eta}_{2}}}z,\widehat{y}\Bigg)\,.

Continuing from (
31
) we get

\displaystyle R(\bar{\eta}_{1})

\displaystyle=\operatorname{\mathbb{E}}\Big[\operatorname{\mathbb{E}}\Big[\Big(Y-h_{z}\Big(\bar{\eta}_{2}Y+\sqrt{\bar{\eta}_{2}}G,\widehat{Y}\Big)\Big)^{2}\Big]\Big]

\displaystyle\geq\inf_{g}\operatorname{\mathbb{E}}\Big[\Big(Y-g\Big(\bar{\eta}_{2}Y+\sqrt{\bar{\eta}_{2}}G,\widehat{Y}\Big)\Big)^{2}\Big]

\displaystyle=\mathcal{R}(\bar{\eta}_{2})\,,

where the inequality holds since
h_{z}
is measurable function. This completes the proof of the non-decreasing nature of
F
.

To prove the claim about fixed points in
(i)
, consider the function
H(u):=u-F(u)
. We have
F(0)=\frac{\gamma^{2}}{\alpha}\operatorname{\mathbb{E}}[\tilde{g}(0,\widehat{Y})^{2}]>0
and so
H(0)<0
. Also,
\lim_{u\to\infty}F(u)=\frac{\gamma^{2}}{\alpha}\operatorname{\mathbb{E}}[\tilde{g}(\gamma^{2}Y+\gamma,\widehat{Y})^{2}]<\frac{\gamma^{2}}{\alpha}
. Hence,
\lim_{u\to\infty}H(u)=\infty
and by the intermediate value theorem,
H(u)
has at least a zero which corresponds to a fixed point of
F
.

Let
\eta_{*}^{2}
be the smallest fixed point of
F
(and so
H(\eta_{*}^{2})=0
).
Then, for any
\eta<\eta_{*}
we have
H(\eta^{2})<0
and so
\eta^{2}<F(\eta^{2})
. This implies that if
\eta_{1}<\eta_{*}
, then
\eta_{1}^{2}<F(\eta_{1}^{2})=\eta_{2}^{2}
. Further, by monotonicity of
F
, per item (i), if
\eta_{t}^{2}\leq\eta_{t+1}^{2}
, then
\eta_{t+1}^{2}=F(\eta_{t}^{2})\leq F(\eta_{t+1}^{2})=\eta_{t+2}^{2}
, which proves that the sequence
(\eta_{t})_{t\geq 1}
is monotone non-decreasing. Hence, the first step strictly reduces the test error and the next rounds of retraining do not increase the test error.

We next proceed with
(ii)
. By the argument in
(i)
, if
\eta_{1}^{2}<F(\eta_{1}^{2})
then the sequence
(\eta_{t})_{t\geq 1}
will be non-decreasing. To this end, we derive a lower bound on
F
, such that
\tilde{F}(u)<F(u)
,
\forall u\geq 0
, and establish condition on the label flipping probability
p
, so that
\eta_{1}^{2}\leq\tilde{F}(\eta_{1}^{2})
with
\eta_{1}=\frac{\gamma}{\sqrt{\alpha}}(1-2p)
.

To construct
\tilde{F}
, recall that
\tilde{g}
is the Bayes-optimal aggregator given by
\tilde{g}(\tilde{Y},\widehat{Y})=\operatorname{\mathbb{E}}[Y|\tilde{Y}=\bar{\eta}Y+\sqrt{\bar{\eta}}G,\widehat{Y}]
. Using the Cauchy–Schwarz inequality for all
g
,

\displaystyle\operatorname{\mathbb{E}}[\tilde{g}(\tilde{Y},\widehat{Y})^{2}]\geq\frac{\operatorname{\mathbb{E}}[\operatorname{\mathbb{E}}[Y|\tilde{Y},\widehat{Y}]g(\tilde{Y},\widehat{Y})]^{2}}{\operatorname{\mathbb{E}}[g(\tilde{Y},\widehat{Y})^{2}]}=\frac{\operatorname{\mathbb{E}}[Yg(\tilde{Y},\widehat{Y})]^{2}}{\operatorname{\mathbb{E}}[g(\tilde{Y},\widehat{Y})^{2}]}

with
\tilde{g}
being the function for which the equality occurs. By choosing,
g(\tilde{Y},\widehat{Y})={\rm sign}(\tilde{Y})
, we obtain the following lower bound:

\operatorname{\mathbb{E}}[\tilde{g}(\bar{\eta}Y+\sqrt{\bar{\eta}}G,\widehat{Y})^{2}]\geq\operatorname{\mathbb{E}}[Y{\rm sign}(\bar{\eta}Y+\sqrt{\bar{\eta}}G)]^{2}=\operatorname{\mathbb{E}}[{\rm sign}(\bar{\eta}+\sqrt{\bar{\eta}}G)]^{2}\,,

since
Y\in\{-1,+1\}
is independent of
G\sim{\sf N}(0,1)
. This gives the following lower bound on
F(u)
,

\displaystyle F(u)

\displaystyle:=\frac{\gamma^{2}}{\alpha}\operatorname{\mathbb{E}}\Big\{\tilde{g}\Big(\gamma^{2}\frac{u}{1+u}Y+\gamma\sqrt{\frac{u}{1+u}}G,\widehat{Y}\Big)^{2}\Big\}

\displaystyle\geq\frac{\gamma^{2}}{\alpha}\operatorname{\mathbb{E}}\Big\{{\rm sign}\Big(\gamma^{2}\frac{u}{1+u}+\gamma\sqrt{\frac{u}{1+u}}G\Big)\Big\}^{2}:=\tilde{F}(u)\,.

We further simplify
\tilde{F}(u)
as

\tilde{F}(u)=\frac{\gamma^{2}}{\alpha}\left(1-2\mathbb{P}\Big(G<-\gamma\sqrt{\frac{u}{1+u}}\Big)\right)^{2}=\frac{\gamma^{2}}{\alpha}\left(1-2\Phi\Big(-\gamma\sqrt{\frac{u}{1+u}}\Big)\right)^{2}\,.

For
\eta_{1}=\frac{\gamma}{\sqrt{\alpha}}(1-2p)
, the condition
\eta_{1}^{2}\leq\tilde{F}(\eta_{1}^{2})
is equivalent to

\displaystyle p\geq\Phi\left(-\gamma\sqrt{\frac{\eta_{1}^{2}}{1+\eta^{2}}}\right)=\Phi\left(-\frac{\gamma^{2}(1-2p)}{\sqrt{\alpha+\gamma^{2}(1-2p)^{2}}}\right)

(32)

We next show that there is a unique
p_{*}\in(0,1/2)
for which the above inequality becomes equality. Define the function
h(p)=\Phi\left(-\frac{\gamma^{2}(1-2p)}{\sqrt{\alpha+\gamma^{2}(1-2p)^{2}}}\right)-p
. The first two derivatives are given by

\displaystyle h^{\prime}(p)

\displaystyle=\phi\left(-\frac{\gamma^{2}(1-2p)}{\sqrt{\alpha+\gamma^{2}(1-2p)^{2}}}\right)\frac{2\gamma^{2}\alpha}{(\alpha+\gamma^{2}(1-2p)^{2})^{3/2}}-1

\displaystyle h^{\prime\prime}(p)

\displaystyle=\phi\left(-\frac{\gamma^{2}(1-2p)}{\sqrt{\alpha+\gamma^{2}(1-2p)^{2}}}\right)\frac{2\gamma^{4}\alpha(1-2p)}{(\alpha+\gamma^{2}(1-2p)^{2})^{2}}+\phi\left(-\frac{\gamma^{2}(1-2p)}{\sqrt{\alpha+\gamma^{2}(1-2p)^{2}}}\right)\frac{12\gamma^{4}\alpha(1-2p)}{(\alpha+\gamma^{2}(1-2p)^{2})^{5/2}}

\displaystyle=\phi\left(-\frac{\gamma^{2}(1-2p)}{\sqrt{\alpha+\gamma^{2}(1-2p)^{2}}}\right)\frac{2\gamma^{4}\alpha(1-2p)}{(\alpha+\gamma^{2}(1-2p)^{2})^{2}}\left[1+\frac{6}{\sqrt{\alpha+\gamma^{2}(1-2p)^{2}}}\right]

We have
h^{\prime}(\frac{1}{2})=\frac{2\gamma^{2}}{\sqrt{\alpha}}\phi(0)-1=\sqrt{\frac{2}{\pi}}\frac{\gamma^{2}}{\sqrt{\alpha}}-1>0
. Also
h(\frac{1}{2})=0
, so
h
should be negative in neighborhood before
1/2
. Since
h(0)>0
, there should be a root
p_{*}
for
h
in
(0,\frac{1}{2})
. Therefore,
h
has at least two zeros,
p_{*}
and
\frac{1}{2}
. Also note that
h
is a convex function because
h^{\prime\prime}(p)>0
, and therefore, these are the only two zeros of
h
. These properties give a clear picture of the function
h
: it will be positive on
[0,p_{*})
, negative on
(p_{*},\frac{1}{2})
and positive afterward. Hence, condition (
32
), i.e.,
h(p)\leq 0
holds if
p\in[p_{*},\frac{1}{2})
, which completes the proof.

F_{\rm CT}
, there is a crossover point: before this,
F_{\rm CT}(\eta^{2})>F_{\rm FT}(\eta^{2})
, and after it,
F_{\rm CT}(\eta^{2})<F_{\rm FT}(\eta^{2})
. This is intuitive, because small
\eta
means that the current model quality is poor, so the consensus-based aggregator, which takes into account the noisy labels, works better. However, larger
\eta
means that the model quality is good enough that full-retraining, which ignores the noisy labels, works better. Furthermore, the crossover point depends on
p
: it increases as
p
decreases. This is also intuitive, because smaller
p
gives a larger range of
\eta
where considering noisy labels in the retraining step is beneficial.

Appendix F
Proof of Lemma
4.1

For a test data point
(\bm{x},y)
, we have
\widehat{y}={\rm sign}(\bm{x}^{\sf T}\bm{\theta})
and
\mathbb{P}(y=+1|\bm{x})=h(\bm{x}^{\sf T}\bbeta)
. We let
z_{\bm{\theta}}:=\sqrt{n}\bm{x}^{\sf T}\bm{\theta}
and
z_{\bbeta}=\sqrt{n}\bm{x}^{\sf T}\bbeta
. We have

\displaystyle P_{e}(\bm{\theta})

\displaystyle=\mathbb{P}(y\widehat{y}<0)

\displaystyle=\mathbb{P}(z_{\bm{\theta}}>0,y=-1)+\mathbb{P}(z_{\bm{\theta}}<0,y=1)

\displaystyle=\operatorname{\mathbb{E}}_{z_{\bbeta}}[\mathbb{P}(z_{\bm{\theta}}>0,y=-1|z_{\bbeta})+\mathbb{P}(z_{\bm{\theta}}<0,y=1|z_{\bbeta})]

We continue by calculating
\mathbb{P}(z_{\bm{\theta}}>0,y=-1|z_{\bbeta})
. Conditional on
z_{\bbeta}
,
y
and
z_{\bm{\theta}}
are independent. Therefore,

\mathbb{P}(z_{\bm{\theta}}>0,y=-1|z_{\bbeta})=\mathbb{P}(z_{\bm{\theta}}>0|z_{\bbeta})\mathbb{P}(y=-1|z_{\bbeta})\,.

We have
(z_{\bm{\theta}},z_{\bbeta})\sim{\sf N}(0,\begin{bmatrix}\left\|\bm{\theta}\right\|_{\ell_{2}}^{2}&\bbeta^{\sf T}\bm{\theta}\\
\bbeta^{\sf T}\bm{\theta}&\left\|\bbeta\right\|_{\ell_{2}}^{2}\end{bmatrix})
. Hence,

z_{\bm{\theta}}|z_{\bbeta}\sim{\sf N}(a,b),\quad a=\frac{\bbeta^{\sf T}\bm{\theta}}{\left\|\bbeta\right\|_{\ell_{2}}^{2}}z_{\bbeta},\quad b^{2}=\left\|\bm{\theta}\right\|_{\ell_{2}}^{2}-\frac{(\bbeta^{\sf T}\bm{\theta})^{2}}{\left\|\bbeta\right\|_{\ell_{2}}^{2}}\,.

Using this characterization, we get

\mathbb{P}(z_{\bm{\theta}}>0|z_{\bbeta})=\Phi(\frac{a}{b})=\Phi\Big(\frac{\rho}{\sqrt{1-\rho^{2}}}\frac{z_{\bbeta}}{\left\|\bbeta\right\|_{\ell_{2}}}\Big)

Also under our data generative model,
\mathbb{P}(y=-1|z_{\bbeta})=1-h(z_{\bbeta}/{\sqrt{n}})
. Note that
z_{\bbeta}\sim{\sf N}(0,\left\|\bbeta\right\|_{\ell_{2}}^{2})
and
\frac{\left\|\bbeta\right\|_{\ell_{2}}}{\sqrt{n}}\to\sqrt{\alpha}\gamma
, in probability. Hence, by Slutsky’s theorem,

\mathbb{P}(z_{\bm{\theta}}>0,y=-1|z_{\bbeta})\to\Phi\left(\frac{\rho Z}{\sqrt{1-\rho^{2}}}\right)(1-h(\sqrt{\alpha}\gamma Z))\,,

in distribution with
Z\sim{\sf N}(0,1)
. By a similar argument, we have

\mathbb{P}(z_{\bm{\theta}}<0,y=1|z_{\bbeta})\to\Phi\left(\frac{-\rho Z}{\sqrt{1-\rho^{2}}}\right)h(\sqrt{\alpha}\gamma Z)\,.

Adding the previous two equations, we obtain the desired result.

We next show that
F
is decreasing. Using the relation
\Phi(-x)=1-\Phi(x)
we can write
F(\rho)
as:

F(\rho)=\operatorname{\mathbb{E}}\left[h(\sqrt{\alpha}\gamma Z)+\Phi\left(\frac{\rho Z}{\sqrt{1-\rho^{2}}}\right)(1-2h(\sqrt{\alpha}\gamma Z))\right]\,.

Hence,

F^{\prime}(\rho)=\frac{1}{(1-\rho^{2})^{3/2}}\operatorname{\mathbb{E}}\left[Z\phi\left(\frac{\rho Z}{\sqrt{1-\rho^{2}}}\right)(1-2h(\sqrt{\alpha}\gamma Z))\right]\,,

with
\phi(u)=e^{-u^{2}/2}/\sqrt{2\pi}
. For any
z>0
, we have

\displaystyle z\phi\left(\frac{\rho z}{\sqrt{1-\rho^{2}}}\right)(1-2h(\sqrt{\alpha}\gamma z))-z\phi\left(\frac{-\rho z}{\sqrt{1-\rho^{2}}}\right)(1-2h(-\sqrt{\alpha}\gamma z))

\displaystyle=2z\phi\left(\frac{\rho z}{\sqrt{1-\rho^{2}}}\right)(h(-\sqrt{\alpha}\gamma z)-h(\sqrt{\alpha}\gamma z))<0\,,

(40)

since
z>0
and by assumption
h(u)>h(-u)
for all
u>0
. Also, since the Gaussian density is symmetric, (
40
) implies that
F^{\prime}(\rho)<0
, which completes the proof.

Proof of Proposition
I.1

Consider the GLM setting with
h(z)=\frac{1+{\rm sign}(z)}{2}
. In this case,
\hat{h}_{p}(z)=\frac{1}{2}+\frac{1-2p}{2}{\rm sign}(z)
. Also, note that the data generative process does not depend on
\gamma
(recall that
\left\|\bbeta\right\|_{\ell_{2}}^{2}/d\to\gamma^{2}
), since the sign function is invariant to scaling. Hence, for simplicity we take
\gamma=1
.

Before proceeding with this case, we derive an alternative expression for the optimal aggregator functions. We define the shorthand
s_{t}^{2}=(\frac{1}{\alpha}+\eta_{t}^{2})^{-1}
and
m_{t}=\frac{u}{\alpha}s_{t}^{2}
. Also let
f(z)=\hat{h}_{p}(z)^{\frac{1+\widehat{y}}{2}}(1-\hat{h}_{p}(z))^{\frac{1-\widehat{y}}{2}}
, where the explicit dependence on the parameters
p
and
\widehat{y}
is omitted in the notation for simplicity. The function
g_{t}^{*}
given by (
50
) can be written in terms of this notation as

\displaystyle g^{*}_{t}(u,\widehat{y})=\frac{1}{s_{t}^{2}}\frac{\int zf(z)e^{-\frac{(z-m_{t})^{2}}{2s_{t}^{2}}}{\rm d}z}{\int f(z)e^{-\frac{(z-m_{t})^{2}}{2s_{t}^{2}}}{\rm d}z}-\frac{u}{\alpha}

Let
Z_{t}=m_{t}+s_{t}Z
with
Z\sim{\sf N}(0,1)
. Then,

\displaystyle g^{*}_{t}(u,\widehat{y})

\displaystyle=\frac{1}{s_{t}^{2}}\frac{\operatorname{\mathbb{E}}[Z_{t}f(Z_{t})]}{\operatorname{\mathbb{E}}[f(Z_{t})]}-\frac{u}{\alpha}

\displaystyle=\frac{1}{s_{t}^{2}}\frac{\operatorname{\mathbb{E}}[(m_{t}+s_{t}Z)f(m_{t}+s_{t}Z)]}{\operatorname{\mathbb{E}}[f(m_{t}+s_{t}Z)]}-\frac{u}{\alpha}

\displaystyle=\frac{m_{t}}{s_{t}^{2}}-\frac{u}{\alpha}+\frac{1}{s_{t}^{2}}\frac{\operatorname{\mathbb{E}}[s_{t}Zf(m_{t}+s_{t}Z)]}{\operatorname{\mathbb{E}}[f(m_{t}+s_{t}Z)]}

\displaystyle=\frac{1}{s_{t}}\frac{\operatorname{\mathbb{E}}[Zf(m_{t}+s_{t}Z)]}{\operatorname{\mathbb{E}}[f(m_{t}+s_{t}Z)]}\,.

(54)

For the case of sign link function, where
h(z)=\frac{1+{\rm sign}(z)}{2}
, the function
f(z)
can be written as

f(z)=\hat{h}_{p}(z)^{\frac{1+\widehat{y}}{2}}(1-\hat{h}_{p}(z))^{\frac{1-\widehat{y}}{2}}=\frac{1}{2}+\frac{1-2p}{2}{\rm sign}(\widehat{y}z).

Using this expression in (
54
), we get

\displaystyle g_{t}^{*}(u,\widehat{y})

\displaystyle=\frac{1}{s_{t}}\frac{\operatorname{\mathbb{E}}\{Zf(m_{t}+s_{t}Z)\}}{\operatorname{\mathbb{E}}\{f(m_{t}+s_{t}Z)\}}

\displaystyle=\frac{1}{s_{t}}\cdot\frac{(1-2p)\operatorname{\mathbb{E}}[Z{\rm sign}(\widehat{y}(m_{t}+s_{t}Z))]}{1+(1-2p)\operatorname{\mathbb{E}}[{\rm sign}(\widehat{y}(m_{t}+s_{t}Z))]}

(55)

To calculate the expectation in the numerator, we write

\displaystyle\operatorname{\mathbb{E}}\{Z{\rm sign}(m_{t}+s_{t}Z)\}

\displaystyle=\int_{-m_{t}/s_{t}}^{\infty}z\frac{e^{-z^{2}/2}}{\sqrt{2\pi}}-\int_{-\infty}^{-m_{t}/s_{t}}z\frac{e^{-z^{2}/2}}{\sqrt{2\pi}}

\displaystyle=\int_{-m_{t}/s_{t}}^{\infty}z\frac{e^{-z^{2}/2}}{\sqrt{2\pi}}+\int_{\infty}^{m_{t}/s_{t}}z\frac{e^{-z^{2}/2}}{\sqrt{2\pi}}=\frac{2}{\sqrt{2\pi}}e^{-\frac{m_{t}^{2}}{2s_{t}^{2}}}\,.

To compute the expectation in the denominator, we write

\displaystyle\operatorname{\mathbb{E}}\{{\rm sign}(m_{t}+s_{t}Z)\}=\int_{-m_{t}/s_{t}}^{\infty}\frac{e^{-z^{2}/2}}{\sqrt{2\pi}}{\rm d}z-\int_{-\infty}^{-m_{t}/s_{t}}\frac{e^{-z^{2}/2}}{\sqrt{2\pi}}{\rm d}z=2\Phi(m_{t}/s_{t})-1\,.

Substituting the previous two identities in (
55
), we obtain

\displaystyle g^{*}_{t}(u,\widehat{y})

\displaystyle=\frac{1}{s_{t}}\cdot\frac{(1-2p)\widehat{y}\sqrt{2/\pi}e^{-\frac{m_{t}^{2}}{2s_{t}^{2}}}}{1+(1-2p)\widehat{y}(2\Phi(\frac{m_{t}}{s_{t}})-1)}

\displaystyle=\frac{1}{s_{t}}\cdot\frac{(1-2p)\widehat{y}\sqrt{\frac{2}{\pi}}e^{-\frac{u^{2}s_{t}^{2}}{2\alpha^{2}}}}{1+(1-2p)\widehat{y}(2\Phi(\frac{us_{t}}{\alpha})-1)}\,.

(56)

Next note that (
51
) and (
52
) follows from Theorem
4.3
where we can calculate
\eta_{1}
explicitly as (note that
\gamma=1
in the current case)

\displaystyle\eta_{1}

\displaystyle=\frac{2}{\alpha^{3/2}}\operatorname{\mathbb{E}}[Z\hat{h}_{p}(Z)]

\displaystyle=\frac{2}{\alpha^{3/2}}\operatorname{\mathbb{E}}\Big[Z\Big(\frac{1}{2}+\frac{1-2p}{2}{\rm sign}(Z)\Big)\Big]

\displaystyle=\frac{1-2p}{\alpha^{3/2}}\operatorname{\mathbb{E}}[|Z|]=\frac{1-2p}{\alpha\gamma}\operatorname{\mathbb{E}}[|Z_{0}|]=\sqrt{\frac{2}{\pi}}\frac{1-2p}{\alpha}\,.

To prove (
53
), note that under the GLM setting with sing link function, the true label of a features vector
\bm{x}
is given by
y={\rm sign}(\bm{x}^{\sf T}\bbeta)
, while the prediction by a model
\bbeta^{t}
are given by
{\rm sign}(\bm{x}^{\sf T}\bbeta^{t})
. Hence,

P_{e}(\bbeta^{t})=\mathbb{P}(\langle\bm{x},\bbeta^{t}\rangle\langle\bm{x},\bbeta\rangle<0)
. Since
\bm{x}\sim{\sf N}(0,\bm{I}_{d}/n)
, letting
Z_{1}=\sqrt{n}\langle\bm{x},\bbeta\rangle/\left\|\bbeta\right\|_{\ell_{2}}
and
Z_{2}=\sqrt{n}\langle\bm{x},\bbeta^{t}\rangle/\left\|\bbeta^{t}\right\|_{\ell_{2}}
, we have
(Z_{1},Z_{2})\sim{\sf N}(0,\begin{bmatrix}1&\rho\\
\rho&1\end{bmatrix})
with
\rho=\frac{\langle\bbeta^{t},\bbeta\rangle}{\left\|\bbeta\right\|_{\ell_{2}}\left\|\bbeta^{t}\right\|_{\ell_{2}}}
.
Hence,

P_{e}(\bbeta^{t})=\mathbb{P}(Z_{1}Z_{2}<0)=\frac{1}{\pi}\cos^{-1}(\rho)\,.

See e.g.
[
20
, Section 15.10]
. Using the result of Theorem
4.2
,we have

\rho\stackrel{{\scriptstyle p}}{{\to}}\frac{\mu_{t}\gamma^{2}}{\gamma\sqrt{\mu_{t}^{2}\gamma^{2}+\frac{\sigma_{t}^{2}}{\alpha}}}=\frac{\mu_{t}\gamma}{\sqrt{\mu_{t}^{2}\gamma^{2}+\frac{\sigma_{t}^{2}}{\alpha}}}=\frac{\eta_{t}\gamma}{\sqrt{\eta_{t}^{2}\gamma^{2}+\frac{1}{\alpha}}}=\frac{\eta_{t}}{\sqrt{\eta_{t}^{2}+\frac{1}{\alpha}}}\,,

since
\gamma=1
. This completes the proof.

Appendix K
Experimental Details

Our experiments were done using TensorFlow
and Keras on one 128 GB CPU and one 40 GB A100 GPU (per run). For initial training as well as for each iteration of retraining, the optimizer is Adam (with default values of
\beta_{1}
and
\beta_{2}
), batch size is 32, and the number of epochs = 10. We tune the learning rate by monitoring the accuracy on a small
clean
validation set (i.e., the labels of the validation set are not corrupted). For settings where we already know that the given labels will be noisy, we can manually clean up a small part of the dataset and use that as the validation set to mitigate overfitting. In each case, we tune the learning rate once for initial training and once for the first iteration of retraining and use that for all subsequent iterations; we call these two learning rate values
\eta_{0}
and
\eta_{1}
, respectively.
