Codes with symmetric distances
Gábor Hegedüs, Sho Suda, Ziqing Xiang

Abstract
For a code C C in a space with maximal distance n n , we say that C C has symmetric distances if its distance set S ⁡ ( C ) S(C) is symmetric with respect to n / 2 n/2 . In this paper, we prove that if C C is a binary code with length 2 ​ n 2n , constant weight n n and symmetric distances, then | C | ≤ ( 2 ​ n − 1 | S ⁡ ( C ) | ) . |C|\leq\binom{2n-1}{|S(C)|}. This result can be interpreted using the language of Johnson association schemes. More generally, we give a framework to study codes with symmetric distances in Q-bipartite Q-polynomial association schemes, and provide upper bounds for such codes. Moreover, we use number theoretic techniques to determine when the equality holds.

Introduction

One of the central problems in coding theory is to determine the maximal number of codewords of length
n
over
q
symbols, subject to specific constraints such as a given minimum distance, a specified number of distinct Hamming distances (denoted by
s
, known as the
degree

s
), or a constant weight
w
for each codeword. A code with a specified degree
s
is referred to as an
s
-distance set
, and finding the best possible upper bounds for
s
-distance sets is a fundamental challenge in coding theory.

A related problem involves studying distance sets on the real unit sphere
S^{n-1}
. A common approach to establishing upper bounds on the cardinality of distance sets
C
in various spaces
X
is to identify a finite-dimensional vector space
V
and a function
\varphi:X\rightarrow V
such that the image
\varphi(C)
forms a linearly independent set in
V
. This leads to the conclusion that
|C|\leq\dim V
.

For
s
-distance sets
C
in different spaces, the following upper bounds are known:

(i)

In the Hamming space
H(n,q):=\{1,\ldots,q\}^{n}
with Hamming distance
d_{H}(x,y)=|\{i:x_{i}\neq y_{i},1\leq i\leq n\}|
, the bound is:

|C|\leq\sum_{i=0}^{s}(q-1)^{i}\binom{n}{i},

(ii)

In the Johnson space
J(n,w):=\binom{[n]}{w}=\{x\subset\{1,\ldots,n\}:|x|=w\}
with distance
d_{J}(x,y)=w-|x\cap y|
, the bound is:

|C|\leq\binom{n}{s},

(iii)

On the unit sphere
S^{d-1}
, the bound is:

|C|\leq\binom{n-s+1}{s}-\binom{n-s+1}{s-1}.

An
s
-distance set is called
tight
if it achieves the corresponding upper bound. Examples of tight
s
-distance sets are rare and are often linked to algebraic structures, such as finite simple groups, lattices, or association schemes. The classification of tight
s
-distance sets is a compelling area of research. A well-known result in this context is the Lloyd-type theorem, which states that if a tight
s
-distance set exists in any of the aforementioned spaces, then the distances must correspond to the roots of certain orthogonal polynomials associated with each space. This theorem has been used to prove the non-existence of tight
s
-distance sets in various cases
[
3
,
4
,
14
]
. Note that tight
s
-distance sets are tight
2s
-designs in their spaces.

A notable class of binary codes is the
self-complementary code

[
15
]
. A binary code
C
is said to be self-complementary if for every codeword
x\in C
, its complement
{\bm{1}}+x
(where
{\bm{1}}
is the all-ones vector) also belongs to
C
. The problem of
s
-distance sets has also been studied in the context of self-complementary codes, which are essentially the counterparts of
s
-distance sets in
projective spaces

[
7
]
, with the case
s=2
corresponding to
equiangular lines

[
10
,
12
]
.

For a self-complementary code
C
of length
n
, the set
S(C)
of Hamming distances between distinct vectors in
C
satisfies the property that if
a\in S(C)\setminus\{n\}
, then
n-a\in S(C)
. For any self-complementary code
C
, there exists a “half” code
C^{\prime}
such that
C=C^{\prime}\cup({\bm{1}}+C^{\prime})
and
C^{\prime}\cap({\bm{1}}+C^{\prime})=\emptyset
. The set
C^{\prime}
satisfies the property that if
a\in S(C^{\prime})
, then
n-a\in S(C^{\prime})
.

1.1
Upper bounds for codes with symmetric distances

Recently, the first author used a linear algebraic method to prove the following theorem for codes with symmetric distances. (See also
[
1
, Theorem 3.2]
for self-complementary codes. The proof is valid for a half of a self-complementary code.)

Theorem 1.1

(
[
13
]
)
.

Let
n
be a positive integer, and
C
be a binary code of length
n
with degree
s
and degree set
S(C)=\{d_{H}(x,y):x,y\in C,x\neq y\}
satisfying that
n-a\in S(C)
if
a\in S(C)
.
Then

\displaystyle|C|\leq\sum_{\begin{subarray}{c}0\leq i\leq s\\
i\equiv s\pmod{2}\end{subarray}}\binom{n}{i}.

(1.1)

The first main result of this paper is an improvement of the upper bound in Theorem
1.1
under the assumption that
C
is a constant weight code with length
2n
and weight
n
.

Theorem 1.2
.

Let
n
be a positive integer, and
C
be a binary constant weight code of length
2n
and weight
n
with degree
s
and degree set
S(C)=\{d_{J}(x,y):x,y\in C,x\neq y\}
satisfying that
n-a\in S(C)
if
a\in S(C)
.
Then

\displaystyle|C|\leq\binom{2n-1}{s}.

(1.2)

Note that for the codewords
x,y
with the same weight,
d_{H}(x,y)=2d_{J}(x,y)
holds. In
Section

2
, we will give a direct proof of
Theorem

1.2
using a linear algebraic method.

The constant weight codes with length
2n
and weight
n
are just subsets of the Johnson association scheme
J(2n,n)
. In the framework of the association schemes,
Theorem

1.2
could be generalized. Moreover, this approach of the association schemes provides not only upper bounds on the corresponding codes, but also a necessarily condition when equality occurs. See
Section

3
for undefined terms on association schemes.

Theorem 1.3
.

Let
(X,\{R_{i}\}_{i=0}^{n})
be a
Q
-bipartite
Q
-polynomial association scheme, and let
C
be a symmetric inner distribution code with degree
s
. Then:

(i)

The following holds.

\displaystyle|C|\leq\sum_{\begin{subarray}{c}0\leq i\leq s\\
i\equiv s\pmod{2}\end{subarray}}m_{i}.

(1.3)

(ii)

Let

\Psi^{\ast}_{s}(x):=\sum_{\begin{subarray}{c}0\leq i\leq s\\
i\equiv s\pmod{2}\end{subarray}}v_{i}^{*}(x).

If equality holds in (
1.3
), then the zeros of
\Psi_{s}^{*}(x)
are distinct dual eigenvalues
\theta_{i}^{*}
,
i\in S
for some
s
-subset
S\subseteq\{1,\ldots,n-1\}
.

Theorem

1.3
will be proved at the end of
Section

3
. Note that both the binary Hamming scheme
H(n,2)
and the Johnson association scheme
J(2n,n)
are Q-bipartite Q-polynomial association scheme, hence
Theorem

1.3
could be applied to these schemes. For the binary Hamming scheme
H(n,2)
,
m_{i}={n\choose i}
, thus
Theorem

1.1
follows from
Theorem

1.3
immediately. For Johnson association scheme
J(2n,n)
,
m_{i}={2n\choose i}-{2n\choose i-1}
, thus
Theorem

1.2
follows from
Theorem

1.3
immediately.

1.2
Tight symmetric inner distribution codes

Our second main result is on tight symmetric inner distribution codes for Johnson schemes, namely the codes for which the equality holds in
Theorem

1.2
. With the help of the orthogonal polynomials for the association scheme
J(2n,n)
, we first give a strong necessary condition on when the equality holds in
Theorem

1.2
.

Theorem 1.4
.

Let
r,s
be positive integers, and let
n:=r+s
. Let

\Phi_{s}(z):=\sum_{i=0}^{s}(-1)^{s-i}z^{\underline{s-i}}p_{s,i}\in\QQ[z],

(1.4)

where

p_{s,i}:=\frac{{s\choose i}}{2^{i}}\frac{(r+i-1)^{\underline{\lfloor i/2\rfloor}}(r+1)^{\overline{i}}}{(r+1/2)^{\overline{\lfloor i/2\rfloor}}}.

Assume that there exist some tight symmetric inner distribution codes for the Johnson scheme
J(2n,n)
of degree
s
. Then, the polynomial
\Phi_{s}(z)
has distinct integral zeros. Moreover, the zeros are in the interval
[1,r+s-1]
.

The proof of
Theorem

1.4
will be given in
Section

4
.

From computer experiments, we found that the zeros of
\Phi_{s}(z)
are rarely all integers, unless when
s=1
or when
r=1
. We thus conjecture that all tight codes arise from these two cases.

Conjecture 1.5
.

Assume that there exist some tight symmetric inner distribution codes for the Johnson scheme
J(2n,n)
of degree
s
. Then, either
s=1
or
s=n-1
.

With the number theoretic techniques, we are able to give bounds on
s
and
r
. The proof of
Theorem

1.6
will be given in
Section

5
.

Theorem 1.6
.

Let
r,s
be positive integers. If
\Phi_{s}
has only integer zeros, then either
s=1
, or
r=1
, or
s\geq 5000r(14.5+\ln r)^{2}
.

Note that
5000(n-s)(14.5+\ln(n-s))^{2}\geq 2,000,000(n-s)
. Combining
Theorems

1.4
and
1.6
, we have a quick corollary, which verifies
Conjecture

1.5
when
n\leq 4,000,000
.

Corollary 1.7
.

Assume that there exist some tight symmetric inner distribution codes for the Johnson scheme
J(2n,n)
of degree
s
. Then, either
s=1
, or
s=n-1
, or
s>0.9999995n
. In particular,
Conjecture

1.5
is true when
n\leq 4,000,000
.

The two cases
s=1
and
s=n-1
in
Conjecture

1.5
are of special interests. We show below that the case
s=1
corresponds to Hadamard matrices, and the case
n-s=1
corresponds to maximal intersecting families.

Case

s=1
: Let
C
be such a code achieving
Theorem

1.2
with
s=1
. Then,
C
is a constant weight code with length
2n
and weight
n
, and
2n-1
codewords satisfying
S(C)=\{n/2\}
. Let
H
be an
(2n-1)\times 2n
matrix whose
i
-th row vector equals to the signed characteristic vector for the set corresponding
i
-th codeword in
C
. Then, the matrix
\begin{pmatrix}{\bf 1}^{\top}\\

is a Hadamard matrix of order
2n
.

Case

s=n-1
: Let
C
be such a code achieving
Theorem

1.2
with

, that is the code

is an

. The upper bound is the same as the Erdős–Ko–Rado upper bound in
[

. Examples

attaining (

.

A linear algebraic method

2.1
Functions on the finite sets

Let
\mbox{$\cal T$}\subseteq\{-1,1\}^{2n}
be a fixed subset. Denote by

{\mbox{{\sf func}}}(\mbox{$\cal T$},\mathbb{R}):=\{f:\mbox{$\cal T$}\to\mathbb{R}:f\mbox{ is a function}\}
the set of all functions from the set
\cal T
to the field
\mathbb{R}
.

For
k\in\{s-1,s\}
, let

\displaystyle\mbox{$\cal R$}(2n,k)

\displaystyle:=\left\{\alpha=(\alpha_{1},\ldots,\alpha_{2n})\in\{0,1\}^{2n}:\sum_{i=1}^{2n}\alpha_{i}\equiv k\pmod{2},\ \sum_{i=1}^{2n}\alpha_{i}\leq k\right\},

and let
S(2n,k)
denote the subspace of the vector space
{\mbox{{\sf func}}}(\{-1,1\}^{2n},\mathbb{R})
generated by the set of monomials

\{x^{\alpha}:\alpha\in\mbox{$\cal R$}(2n,k)\}.

Then it follows easily from
[
2
, Theorem 7.8]
and the definition of
\mbox{$\cal R$}(2n,k)
that

\displaystyle\dim(S(2n,k))=\sum_{\begin{subarray}{c}i=0,1,\ldots,k\\
i\equiv k\pmod{2}\end{subarray}}\binom{2n}{i}.

(2.1)

A
signed characteristic vector
of a subset
F
in
[2n]
is a function
\mathbf{v}
from the set
[2n]
to the real number field
\mathbb{R}
such that
\mathbf{v}(k)=1
for
k\in F
,
\mathbf{v}(k)=-1
otherwise.

For a polynomial
f=f(x_{1},\ldots,x_{2n})
, let
\overline{f}
denote the polynomial obtained from
f
by replacing each occurrence of
x_{j}^{2}
,
1\leq j\leq 2n
, by
1
.
Note that
f(\mathbf{v})=\overline{f}(\mathbf{v})
for any
(1,-1)
-vector
\mathbf{v}
.

Let
\mbox{$\cal V$}_{<n}:=\{\mathbf{u}\in\{-1,1\}^{2n}:|\{i:u_{i}=1\}|<n\}
where
\mathbf{u}=(u_{1},\ldots,u_{2n})
.
Let
t:=|\mbox{$\cal V$}_{<n}|
.
We can write up
\mbox{$\cal V$}_{<n}
as the set of vectors
\mbox{$\cal V$}_{<n}=\{\mathbf{w}_{1},\ldots,\mathbf{w}_{t}\}
. Define the polynomial
h(\mathbf{x}):=\sum_{i}x_{i}
. Clearly
h(\mathbf{w}_{j})\neq 0
for each
1\leq j\leq t
.
Let
\mbox{$\cal W$}:=\{\mathbf{u}\in\{-1,1\}^{2n}:|\{i:u_{i}=1\}|=n\}
.
Note that the signed characteristic vectors of
C
belong to
\cal W
and
h(\mathbf{w})=0
for each
\mathbf{w}\in\mbox{$\cal W$}
.

For
\alpha\in\mbox{$\cal R$}(2n,s-1)
, let
g_{\alpha}:=x^{\alpha}\cdot h
.
Clearly
g_{\alpha}
is a homogeneous polynomial and
\deg(g_{\alpha})\equiv s\pmod{2}
, hence
\overline{g}_{\alpha}\in S(2n,s)
.

Proposition 2.1
.

Let

\mbox{$\cal M$}:=\{\overline{g}_{\alpha}:\alpha\in\mbox{$\cal R$}(2n,s-1)\}.

Then
\cal M
is a linearly independent set of functions in the vector space
{\mbox{{\sf func}}}(\{-1,1\}^{2n},\mathbb{R})
.

Proof.

We can write up
S(2n,s-1)
as the set of monomials
S(2n,s-1)=\{x^{\alpha_{1}},\ldots,x^{\alpha_{z}}\}
, where
z:=|S(2n,s-1)|
.

Let
A,B
be the
t\times z
matrices defined by

A(i,j):=x^{\alpha_{j}}(\mathbf{w}_{i}),\quad B(i,j):=(h\cdot x^{\alpha_{j}})(\mathbf{w}_{i}),

where
i\in[t]
,
j\in[z]
. Then by
Eq.

2.1
,
\mbox{\rm rank}(A)=z
.

Since
h(\mathbf{w}_{i})\neq 0
for each
1\leq i\leq t
, hence each row of
B
is a nonzero multiple of the corresponding row of
A
. We get that
\mbox{\rm rank}(B)=z
. This means precisely that the set of polynomials

\{g_{\alpha}:\alpha\in\mbox{$\cal R$}(2n,s-1)\}

is a linearly independent set of functions in the vector space
{\mbox{{\sf func}}}(\mbox{$\cal V$}_{<n},\mathbb{R})
.

Hence the set of polynomials
\cal M
is a linearly independent set of functions in the vector space
{\mbox{{\sf func}}}(\mbox{$\cal V$}_{<n},\mathbb{R})
, consequently in the vector space
{\mbox{{\sf func}}}(\{-1,1\}^{2n},\mathbb{R})
.
∎

Proof of Theorem
1.2

Let
C=\{F_{1},\ldots,F_{m}\}

be a subset of
\binom{[2n]}{n}
with degree
s
and degree set
S(C)=\{n-|F\cap F^{\prime}|:F,F^{\prime}\in C,F\neq F^{\prime}\}
satisfying that
n-a\in S(C)
if
a\in S(C)
.
Let
\mathbf{v}_{i}
denote the signed characteristic vector of the subset
F_{i}\in C
in
[2n]
.
Consider the polynomials

P_{i}(x_{1},\ldots,x_{2n}):=\prod_{d\in S(C)}\Big(\langle\mathbf{x},\mathbf{v}_{i}\rangle-2(n-2d)\Big)\in\mathbb{R}[\mathbf{x}]

(2.2)

for each
1\leq i\leq m
, where
\langle\mathbf{x},\mathbf{v}_{i}\rangle
denotes the usual scalar product of the vectors
\mathbf{x}
and
\mathbf{v}_{i}
.
Clearly
\mbox{deg}(P_{i})\leq s
for each
1\leq i\leq m
.
Since
S(C)
is symmetric with respect to

, the set
\{2(n-2d):d\in S(C)\}
is symmetric with respect to

.
Then it follows that each
\overline{P}_{i}\in S(2n,s)
.

Claim 2.2
.

The set of polynomials
\{\overline{P}_{i}:1\leq i\leq m\}\cup\mbox{$\cal M$}
is a linearly independent set of functions in the vector space
{\mbox{{\sf func}}}(\{-1,1\}^{n},\mathbb{R})
.

Proof of Claim
2.2
.

Assume that

\sum_{i=1}^{m}\lambda_{i}\overline{P}_{i}+\sum_{\alpha\in\mbox{$\cal R$}(2n,s-1)}\mu_{\alpha}h\cdot x^{\alpha}=0

for some
\lambda_{i},\mu_{\alpha}\in\mathbb{R}
. Substituting
\mathbf{v}_{i}
, all terms in the second sum vanish, because
h(\mathbf{w})=0
for each
\mathbf{w}\in\mbox{$\cal W$}
, and only the term with subscript
i
remains of the first sum.
We infer that
\lambda_{i}=0
for each
i
because
\overline{P}_{i}(\mathbf{v}_{j})
is non-zero if

and zero otherwise.
Therefore the previous linear relation is only a relation among the polynomials
h\cdot x^{\alpha}
. Then the claim follows from Proposition
2.1
.
∎

We thus found
m+|\mbox{$\cal M$}|
linearly independent functions, all of which is an element of the set of polynomials

,
hence by
Eq.

2.1
with
|\mbox{$\cal M$}|=\dim(S(2n,s-1))
and the identity
[

, (5.16)]
,

m\leq\dim(S(2n,s))-\dim(S(2n,s-1))=\sum_{\begin{subarray}{c}0\leq i\leq s\\

.

Q-bipartite Q-polynomial association scheme approach

3.1
Association schemes

We refer the reader to
[
5
]
for more informations.
Let
X
be a finite set and
\{R_{0},R_{1},\ldots,R_{n}\}
be a set of non-empty subsets of
X\times X
.
Let
A_{i}
be the adjacency matrix of the graph
(X,R_{i})
.
The pair
(X,\{R_{i}\}_{i=0}^{n})
is a symmetric association scheme with class
n
if the following hold:

(i)

A_{0}
is the identity matrix;

(ii)

\sum_{i=0}^{n}A_{i}=J
, where
J
is the all ones matrix;

(iii)

A_{i}^{\top}=A_{i}
for
1\leq i\leq n
;

(iv)

A_{i}A_{j}
is a linear combination of
A_{0},A_{1},\ldots,A_{n}
for
0\leq i,j\leq n
.

The vector space
\mathcal{A}
spanned by the
A_{i}
over
\mathbb{R}
forms an algebra which is called the adjacency algebra of
(X,(X,\{R_{i}\}_{i=0}^{n}))
.
Since
\mathcal{A}
is commutative and semisimple, there exist primitive idempotents
\{E_{0},E_{1},\ldots,E_{n}\}
where
E_{0}=\frac{1}{|X|}J
.
Since the adjacency algebra
\mathcal{A}
is closed under the ordinary multiplication and entry-wise multiplication denoted by
\circ
,
we define the intersection numbers
p_{i,j}^{k}
and the Krein numbers
q_{i,j}^{k}
for
0\leq i,j,k\leq d
as follows;

\displaystyle A_{i}A_{j}=\sum_{k=0}^{n}p_{i,j}^{k}A_{k},\quad E_{i}\circ E_{j}=\frac{1}{|X|}\sum_{k=0}^{n}q_{i,j}^{k}E_{k}.

Since
\{A_{0},A_{1},\ldots,A_{n}\}
and
\{E_{0},E_{1},\ldots,E_{n}\}
form bases of
\mathcal{A}
, there exist change of bases matrices
P
and
Q
defined by

\displaystyle A_{i}=\sum_{j=0}^{n}P_{ji}E_{j},\quad E_{i}=\frac{1}{|X|}\sum_{j=0}^{n}Q_{ji}A_{j}.

The matrices
P
and
Q
are called the first and second eigenmatrices of
(X,\{R_{i}\}_{i=0}^{n})
respectively.
The multiplicity
m_{i}
is defined to be
m_{i}=Q_{0i}=\text{rank}E_{i}
.

The symmetric association scheme
(X,\{R_{i}\}_{i=0}^{n})
is said to be
Q
-polynomial
if for each
i\in\{0,1,\ldots,n\}
, there exists a polynomial
v_{i}^{*}(x)
with degree
i
such that
Q_{ji}=v_{i}^{*}(Q_{j1})
for all
j\in\{0,1,\ldots,n\}
.
If
(X,\{R_{i}\}_{i=0}^{n})
is
Q
-polynomial, we define
a_{i}^{*}=q_{1,i}^{i}
,
b_{i}^{*}=q_{1,i+1}^{i}
, and
c_{i}^{*}=q_{1,i-1}^{i}
.
Then
\{v_{i}^{*}(x)\}_{i=0}^{n}
satisfy that
v_{0}^{*}(x)=1
,
v_{1}^{*}(x)=x
and
xv_{i}^{*}(x)=c_{i+1}^{*}v_{i+1}^{*}(x)+a_{i}^{*}v_{i}^{*}(x)+b_{i-1}^{*}v_{i-1}^{*}(x)
for
1\leq i\leq n
, where
v_{n+1}^{*}(x)
is indeterminate.
When
(X,\{R_{i}\}_{i=0}^{n})
is
Q
-polynomial, set
\theta_{j}^{*}=Q_{j1}
for each
j\in\{0,1,\ldots,n\}
.

\theta_{j}^{*}
are called
dual-eigenvalues
of the
Q
-polynomial scheme.
The
Q
-polynomial scheme is said to be
Q
-bipartite
if
a_{i}^{*}=0
for
i=1,\ldots,n
.
Then it holds that
\theta^{*}_{n-i}=-\theta^{*}_{i}
for any
i
.
Define

4

We focus on the Johnson scheme

in this section. The goal is to provide an explicit formula for the polynomial

for Johnson scheme

. The dual orthogonal polynomials for

are

xv^{\ast}_{i}(x)=\frac{(2n-1)(i+1)(n-i)}{n(2n-2i-1)}v^{\ast}_{i+1}(x)+\frac{(2n-1)(n-i+1)(2n-i+2)}{n(2n-2i+3)}v^{\ast}_{i-1}(x)

and

.

The
Proposition

4.1
below proves that

is essentially the same with the polynomial
\Phi_{s}(z)
defined in

1.4
, up to some scalar and change of variable.
Theorem

1.4

and
1.3

Proposition 4.1
.

Let

. Then,

\Psi^{\ast}_{s}(\theta_{z})=\frac{2^{2s}}{s!}\frac{(n-1/2)^{\underline{s}}}{n^{\underline{s}}}\Phi_{s}(z).

Proof.

Substitute

into the recursion

4.1
for

, we obtain

(n-2z)v^{\ast}_{i}(\theta_{z})=\frac{(i+1)(n-i)}{2n-2i-1}v^{\ast}_{i+1}(\theta_{z})+\frac{(n-i+1)(2n-i+2)}{2n-2i+3}v^{\ast}_{i-1}(\theta_{z}),

(4.2)

with

and
v^{\ast}_{0}(\theta_{z})=1
. Thus, the polynomials

and the initial conditions.

Let

Note that

\displaystyle(n-2z)(\Phi^{\prime}_{s}(z)-\Phi^{\prime}_{s-2}(z))

(4.3)

\displaystyle=

\displaystyle\frac{(s+1)(n-s)}{2n-2s-1}(\Phi^{\prime}_{s+1}(z)-\Phi^{\prime}_{s-1}(z))+\frac{(n-s+1)(2n-s+2)}{2n-2s+3}(\Phi^{\prime}_{s-1}(z)-\Phi^{\prime}_{s-3}(z))

as elements in
\QQ(n)[z]
.

The set

is a basis of

, and

(n-2z)\left((-1)^{t}z^{\underline{t}}\right)=2\left((-1)^{t+1}z^{\underline{t+1}}\right)+(n-2t)\left((-1)^{t}z^{\underline{t}}\right).

By taking the coefficient of

and then divide by

, we see that

holds for all

, if and only if, for all

and

\displaystyle 2(\frac{\alpha_{s,s-t+1}}{\alpha_{s,s-t}}-\frac{\alpha_{s-2,s-t-1}}{\alpha_{s,s-t}})+(n-2t)(1-\frac{\alpha_{s-2,s-t-2}}{\alpha_{s,s-t}})

(4.4)

\displaystyle=

\displaystyle\frac{(s+1)(n-s)}{2n-2s-1}(\frac{\alpha_{s+1,s-t+1}}{\alpha_{s,s-t}}-\frac{\alpha_{s-1,s-t-1}}{\alpha_{s,s-t}})

\displaystyle+\frac{(n-s+1)(2n-s+2)}{2n-2s+3}(\frac{\alpha_{s-1,s-t-1}}{\alpha_{s,s-t}}-\frac{\alpha_{s-3,s-t-3}}{\alpha_{s,s-t}})

as elements in
\QQ(n)

For

and

such that

is even, every

is in

are actually rational functions in

5.2
Binomial coefficients for half-integers

In this subsection, we study the binomial coefficients for half-intergers

{n-1/2\choose m}=\frac{(2n-1)!!}{(2(n-m)-1)!!2^{m}m!}.

(5.1)

The
n
in this subsection is just a natural number, which is not the parameter
n
for the Johnson scheme
J(2n,n)
.

For a prime
p
, let
{\rm val}_{p}
be the
p
-adic valuation for rational numbers. In other words, it is the number of times that
p
divides a given rational number. Below is a generlaization of Kummer’s theorem to half-integers.

Lemma 5.2
.

Let
m
and
n
be natural numbers with
n\geq m
. Let
p
be a prime. Then,

{\rm val}_{p}({n-1/2\choose m})\leq\begin{cases}\lfloor\log_{p}(2n-1)\rfloor,&p\geq 3,\\
-2m+\lfloor\log_{2}(m+1)\rfloor,&p=2.\\
\end{cases}

Proof.

When
p=2
, the result follows from
Eq.

5.1
and the fact that

{\rm val}_{2}(m!)\geq m-\lfloor\log_{2}(m+1)\rfloor.

Now, assume that
p\geq 3
.

The Legendre’s formula for factorials says

{\rm val}_{p}(n!)=\sum_{i=1}^{\infty}\left\lfloor\frac{n}{p^{i}}\right\rfloor.

(5.2)

Following the idea of its proof, we obtain a generalization for double factorials as follows:

{\rm val}_{p}((2n-1)!!)=\sum_{i=1}^{\infty}\left\lceil\frac{1}{2}\left\lfloor\frac{2n-1}{p^{i}}\right\rfloor\right\rceil.

(5.3)

Substituting
Eqs.

5.2
and
5.3
into
Eq.

5.1
,

\displaystyle{\rm val}_{p}({n-1/2\choose m})=

\displaystyle{\rm val}_{p}((2n-1)!!)-{\rm val}_{p}((2(n-m)-1)!!)-{\rm val}_{p}(m!)

\displaystyle=

\displaystyle\sum_{i=1}^{\infty}\left(\left\lceil\frac{1}{2}\left\lfloor\frac{2n-1}{p^{i}}\right\rfloor\right\rceil-\left\lceil\frac{1}{2}\left\lfloor\frac{2(n-m)-1}{p^{i}}\right\rfloor\right\rceil-\left\lfloor\frac{m}{p^{i}}\right\rfloor\right),

\displaystyle=

\displaystyle\sum_{i=1}^{\infty}\left(\left\lceil\frac{1}{2}\left\lfloor a_{i}+b_{i}\right\rfloor\right\rceil-\left\lceil\frac{1}{2}\left\lfloor a_{i}\right\rfloor\right\rceil-\left\lfloor\frac{1}{2}b_{i}\right\rfloor\right),

where

a_{i}:=\frac{2(n-m)-1}{p^{i}}\quad\text{and}\quad b_{i}:=\frac{2m}{p^{i}}.

The result follows from the fact that each summand is either
0
or
1
, and that the summand is
0
unless
a_{i}+b_{i}\geq 1
.
∎

Now, we analyze when the binomial coefficients for half-integers have only small prime factors. We say that a rational number

is

if

for all primes

.

Proposition 5.3
.

Let

and

be natural numbers with

Assume in contrary that

We first give an upper bound for

\displaystyle\ln{n-1/2\choose m}=\sum_{p\leq 4m+1}{\rm val}_{p}({n-1/2\choose m})\ln p

\displaystyle\left(-2m+\lfloor\log_{2}(m+1)\rfloor\right)\ln 2+\sum_{3\leq p\leq 4m+1}\left\lfloor\log_{p}(2n-1)\right\rfloor\ln p

\displaystyle\pi(4m+1)\ln(n-1/2).

(since

We then give a lower bound for

\displaystyle\ln{n-1/2\choose m}

\displaystyle\left(1-\frac{1}{m}\frac{4m+1}{\ln(4m+1)}(1+\frac{1.2762}{\ln(4m+1)})\right)^{-1}(\ln m-\ln 2)

(estimate of

2\leq r\leq\frac{3}{4}s^{2}
, the numbers
p_{s,1},\dots,p_{s,s}
are never all integers at the same time.

Case 2.
2\leq r\leq s-1

We rewrite
p_{s,s}
as follows:

p_{s,s}=\frac{(r+1)\cdots(2r-1)\cdot r\cdots(r+s-1)}{(r+s+1)\ldots(2r+s-1)}.

Since
p_{s,s}
is an integer, neither of the numbers
r+s+1,\ldots 2r+s-1
could be a prime. Therefore, by
Proposition

5.1
,
r+s\geq\rho_{r}
, hence
s\geq\rho_{r}-r
.

Case 2.1
2\leq r\leq 287

It suffices to prove that
s\geq 5000r(14.5+\ln r)^{2}
. This can be done by a computer search over
2\leq r\leq 287
and
s\leq 5000r(14.5+\ln r)^{2}
. The numbers
p_{s,1},\dots,p_{s,s}
are never all integers at the same time.

Case 2.2
r\geq 288

In this case,
s\geq\rho_{r}-r\geq 5000r(14.6+\ln r)^{2}-r\geq 5000r(14.5+\ln r)^{2}
.
