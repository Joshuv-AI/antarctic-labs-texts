Compact Memory for Continual Logistic Regression
Yohan Jung, Hyungi Lee, Wenlong Chen, Thomas Möllenhoff, Yingzhen Li, Juho Lee, Mohammad Emtiyaz Khan

Abstract
Despite recent progress, continual learning still does not match the performance of batch training. To avoid catastrophic forgetting, we need to build compact memory of essential past knowledge, but no clear solution has yet emerged, even for shallow neural networks with just one or two layers. In this paper, we present a new method to build compact memory for logistic regression. Our method is based on a result by 11 who show the existence of optimal memory for such models. We formulate the search for the optimal memory as Hessian-matching and propose a probabilistic PCA method to estimate them. Our approach can drastically improve accuracy compared to Experience Replay. For instance, on Split-ImageNet, we get 60 % 60\% accuracy compared to 30 % 30\% obtained by replay with memory-size equivalent to 0.3 % 0.3\% of the data size. Increasing the memory size to 2 % 2\% further boosts the accuracy to 74 % 74\% , closing the gap to the batch accuracy of 77.6 % 77.6\% on this task. Our work opens a new direction for building compact memory that can also be useful in the future for continual deep learning.

Introduction

Continual learning aims for a continual lifelong acquisition of knowledge which is challenging because it requires a delicate balance between the old and new knowledge
(
18
)
. New knowledge can interfere with old knowledge
(
26
)
and lead to catastrophic forgetting
(
12
)
. Thus, it is necessary to compactly memorize all the past knowledge required in the future to quickly learn new things. This is a difficult problem and no
satisfactory solution has been found yet, even for simple cases such as logistic regression and shallow neural networks. The problem is important because solving it can also drastically reduce the cost and environmental impact of batch training which requires access to all of the data all the time.

The most straightforward method to build memory is to simply store old models and data examples, but such approaches do not perform as well as batch training. For instance, weight-regularization uses old parameters to regularize future training
(
12
;
16
;
13
;

;
10
;
22
;

)
. While this is memory efficient, it often performs worse than replay method that simply store old raw data for reuse in the future
(
23
;
17
;
6
;
29
;
4
;
20
;

)
. Many replay-based methods have been devised to effectively select past data points based on gradient
(

;
30
)
, interference
(
1
)
, information-theoretic metric
(

)
, and Bilevel optimization
(

. The memory cost of replay can be reduced by combining it with weight regularization, but so far the performance still lags behind the batch training
(
7

We build upon the work of
11
who show the existence of compact memory for logistic regression but do not give a practical method to estimate them. They propose a prior called the Knowledge-adaptation prior (K-prior) which uses a ‘memory’ set to approximate the full-batch gradient. More precisely, given parameter
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}
after training until task

, a subset
\mathcal{M}_{t}
of the past data
\mathcal{D}_{1:t}=\{\mathcal{D}_{1},\mathcal{D}_{2},\ldots,\mathcal{D}_{t}\}
is used to construct the K-prior
\mathcal{K}_{t}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{M}_{t})
such that the following holds:

\sum_{j=1}^{t}\nabla\bar{\ell}_{j}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{D}_{j})\approx\nabla\mathcal{K}_{t}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{M}_{t}),

(1)

where
\bar{\ell}_{j}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{D}_{j})
denotes the loss over examples in
\mathcal{D}_{j}
.
11

\mathcal{D}_{1:t}

In this paper, we reformulate the search for the optimal memory as Hessian-matching and propose a practical method to estimate them (

of the data size. A small memory size of

2
Compact Memory for Continual Learning

We consider continual learning for supervised problems where the data of the
j
’th task consists of
N_{j}
input-output pairs of form
(\mbox{$\mbox{$\mathbf{x}$}$}_{j},y_{j})
. The goal is to learn the parameter vector
\boldsymbol{\theta}
whose predictions closely match the true labels
y_{j}
. The empirical loss over task
j
is defined as

\bar{\ell}_{j}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{D}_{j})=\sum_{i\in\mathcal{D}_{j}}\mathcal{L}\left(y_{j},\hat{y}(f_{\boldsymbol{\theta}}(\mbox{$\mbox{$\mathbf{x}$}$}_{j}))\right),

(2)

where
\mathcal{L}(y,\hat{y})
is chosen to be the cross-entropy loss over predictions
\hat{y}
obtained by passing the logits
f_{\boldsymbol{\theta}}(\mbox{$\mbox{$\mathbf{x}$}$})
through the softmax function.
As discussed earlier, learning continually requires a delicate balance between old and new knowledge. Tasks may arrive one at a time and there may be little flexibility to revisit them again. This is unlike the standard ‘batch’ training where the goal is to obtain the parameter
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{T}^{*}
obtained by jointly training over the sum
\sum_{j=1}^{T}\bar{\ell}_{j}
over all
T
tasks. Such batch training typically requires access to all the data all the time. Continual learning eliminates this
requirements and aim to recover
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{T}^{*}
by incrementally training of tasks one at a time.

Continual learning however is extremely challenging, even for simple cases such as logistic regression and shallow neural networks. If new task interferes with the old knowledge, there is a chance the model may catastrophically forget the previously acquired knowledge. Because the tasks are not revisited, the model may never be able to relearn it. It is therefore important to compactly memorize all essential knowledge that may be needed to learn new things in the future. This is
challenging because the future is uncertain and new tasks may be very different from old ones. No satisfactory solution has been found yet to build compact memory that facilitates accurate continual learning.

Currently, there are two most popular methods to build memory and both do not perform as well as batch training. The first method is to store the old model parameters
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}
after training until task
t
and reuse it to train over the next task. For example, we can use a quadratic weight-regularizer:

\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}\leftarrow\underset{\text{$\mbox{$\mbox{$\boldsymbol{\theta}$}$}$}}{\arg\min}~\bar{\ell}_{t+1}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{D}_{t+1})+\mbox{$\frac{1}{2}$}\delta_{t}\|\mbox{$\mbox{$\boldsymbol{\theta}$}$}-\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}\|^{2},

(3)

where
\delta_{t}>0
is the regularization parameter. This is memory efficient because the memory cost does not grow with tasks and requires storing only one model parameters. It is also possible to use multiple checkpoints as long as the memory does not grow too fast.

The second method is to store old raw data, which is often not the most memory efficient approach. This is because the memory size could grow larger as new tasks are seen. However, in practice, the method often performs much better than weight regularization. The method is also easy to implement within standard stochastic training pipeline. For instance, given a set
\mathcal{E}_{t}
of replay examples, we can simply us the following update,

\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}\leftarrow\underset{\text{$\mbox{$\mbox{$\boldsymbol{\theta}$}$}$}}{\arg\min}~\bar{\ell}_{t+1}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{D}_{t+1})+\sum_{j\in\mathcal{E}_{t}}\mathcal{L}\left(y_{j},\hat{y}(f_{\boldsymbol{\theta}}(\mbox{$\mbox{$\mathbf{x}$}$}_{j}))\right).

(4)

Another alternative is to use a
function-space
regularizer, defined as
\mathcal{L}(\hat{y}(f_{\boldsymbol{\theta}_{t}}(\mbox{$\mbox{$\mathbf{x}$}$}_{j})),\hat{y}(f_{\boldsymbol{\theta}}(\mbox{$\mbox{$\mathbf{x}$}$}_{j})))
where instead of predicting the true labels
y_{j}
, we predict prediction
\hat{y}(f_{\boldsymbol{\theta}_{t}}(\mbox{$\mbox{$\mathbf{x}$}$}_{j}))
of
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}
. This also boosts performance in practice
(
29
;
4
;
20
;
24
)
. The memory efficiency of all of these methods can be reduced by combining them with weight regularization, which brings us to the
Knowledge-adaptation prior of
11
.

As discussed earlier, K-prior uses both
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}
and a memory set
\mathcal{M}_{t}
to approximate the full-batch gradient over the past tasks. The memory set consists of
K_{t}
vectors, that is,
\mathcal{M}_{t}=(\mbox{$\mbox{$\mathbf{u}$}$}_{1|t},\mbox{$\mbox{$\mathbf{u}$}$}_{2|t},\ldots,\mbox{$\mbox{$\mathbf{u}$}$}_{K_{t}|t})
where
\mbox{$\mbox{$\mathbf{u}$}$}_{k|t}
is the
k
’th memory vector. K-prior uses a combination of the weight-space and function-space regularizer to approximate the full-batch gradient. For instance, consider a regularized linear-regression problem with loss

\mathcal{L}(y_{j},\hat{y}(\mbox{$\mbox{$\boldsymbol{\phi}$}$}_{j}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$}))=\mbox{$\frac{1}{2}$}(y_{j}-\mbox{$\mbox{$\boldsymbol{\phi}$}$}_{j}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$})^{2}
for each
(\mbox{$\mbox{$\boldsymbol{\phi}$}$}_{j},y_{j})
pair, with a regularizer
\mbox{$\frac{1}{2}$}\delta_{t}\|\mbox{$\mbox{$\boldsymbol{\theta}$}$}\|^{2}
. For this model, we can use the following combination:

\mathcal{K}_{t}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{M}_{t})=\mbox{$\frac{1}{2}$}\delta_{t}\|\mbox{$\mbox{$\boldsymbol{\theta}$}$}-\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}\|^{2}+\sum_{k=1}^{K_{t}}\mbox{$\frac{1}{2}$}\left(\mbox{$\mbox{$\mathbf{u}$}$}_{k|t}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}-\mbox{$\mbox{$\mathbf{u}$}$}_{k|t}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$}\right)^{2}.

(5)

The first term ensures that new
\boldsymbol{\theta}
are close to old
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}
while the second term ensures the same for their predictions. We then use the following update for the next task,

\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}\leftarrow\underset{\text{$\mbox{$\mbox{$\boldsymbol{\theta}$}$}$}}{\arg\min}~\bar{\ell}_{t+1}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{D}_{t+1})+\mathcal{K}_{t}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{M}_{t}).

(6)

11
prove that, for generalized linear models, such an update can perfectly recover the exact gradient when
\mathcal{M}_{t}=\mathcal{D}_{1:t}
and
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}=\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}^{*}
(the batch solution over
\mathcal{D}_{1:t}
). Choosing a subset of
\mathcal{D}_{1:t}
as the memory set yields an approximation of the gradient whose accuracy can be controlled by carefully choosing the memory set, as long as

\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}
is close enough to
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}^{*}
.

Choosing
\mathcal{M}_{t}\subset\mathcal{D}_{1:t}
however is not the best choice.
11
show that it is also possible to construct a much more compact
optimal
memory set which can recover prefect gradients even when
|\mathcal{M}_{t}|\ll|\mathcal{D}_{1:t}|
. This can be done by setting
\mbox{$\mbox{$\mathbf{u}$}$}_{k|t}
to be the left singular vectors of the feature matrix. To be precise, denoting by
\mbox{$\mbox{$\boldsymbol{\Phi}$}$}_{1:t}
the feature matrix of containing features of inputs in
\mathcal{D}_{1:t}

as columns, we compute the following singular-value-decomposition (SVD),

\mbox{$\mbox{$\boldsymbol{\Phi}$}$}_{1:t}=\mbox{$\mbox{$\mathbf{U}$}$}_{t}^{*}\mbox{$\mbox{$\mathbf{S}$}$}_{t}^{*}(\mbox{$\mbox{$\mathbf{V}$}$}_{t}^{*})^{\top},\text{ where }\mbox{$\mbox{$\mathbf{U}$}$}_{t}^{*}=(\mbox{$\mbox{$\mathbf{u}$}$}_{1|t}^{*},\mbox{$\mbox{$\mathbf{u}$}$}_{2|t}^{*},\ldots\mbox{$\mbox{$\mathbf{u}$}$}_{K_{t}^{*}|t}^{*})\text{ and }\mbox{$\mbox{$\mathbf{V}$}$}_{t}^{*}=(\mbox{$\mbox{$\mathbf{v}$}$}_{1|t}^{*},\mbox{$\mbox{$\mathbf{v}$}$}_{2|t}^{*},\ldots,\mbox{$\mbox{$\mathbf{v}$}$}_{K_{t}^{*}|t}^{*}).

(7)

The left and right singular vectors are denoted by
\mbox{$\mbox{$\mathbf{u}$}$}_{k|t}^{*}
and
\mbox{$\mbox{$\mathbf{v}$}$}_{k|t}^{*}
respectively. The rank is denoted by
K_{t}^{*}
and
\mbox{$\mbox{$\mathbf{S}$}$}_{t}^{*}
is a diagonal matrix containing all
K_{t}^{*}
non-zero singular values denoted by
s_{k|t}^{*}
.
11
define the optimal memory to be
\mathcal{M}_{t}=\mbox{$\mbox{$\mathbf{U}$}$}_{t}^{*}
. Then, they construct the following optimal K-prior, denoted by
\mathcal{K}_{t}^{*}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mbox{$\mbox{$\mathbf{U}$}$}_{t}^{*})
, for binary
logistic regression,

\mathcal{K}_{t}^{*}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mbox{$\mbox{$\mathbf{U}$}$}_{t}^{*})=\mbox{$\frac{1}{2}$}\delta\|\mbox{$\mbox{$\boldsymbol{\theta}$}$}-\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}\|^{2}+\sum_{k=1}^{K_{t}^{*}}w_{k|t}^{*}\,\mathcal{L}\left(\hat{y}((\mbox{$\mbox{$\mathbf{u}$}$}_{k|t}^{*})^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t})\,,\,\hat{y}((\mbox{$\mbox{$\mathbf{u}$}$}_{k|t}^{*})^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$})\right),

(8)

and show that there exist scalars
w_{k|t}^{*}
for which it perfectly recovers the full-batch gradient at
\boldsymbol{\theta}
. Here,
\hat{y}(f)
denotes the prediction function which is the sigmoid function for binary logistic regression, that is,
\hat{y}(f)=\mbox{$\sigma$}(f)=1/(1+\exp(-f))
. The result shows that the optimal memory size is equal to
K_{t}^{*}
and perfect gradient recovery is possible by simply comparing
K_{t}^{*}
predictions at old and new models. This can be extremely cheap compared to the full batch gradient for long data streams whose intrinsic dimensionality is much smaller.

The main issue with the method is that computing
w_{k|t}^{*}
for each
\boldsymbol{\theta}
is infeasible in practice because it requires access to all of the past data. Specifically, the optimal value is given by

w^{*}_{k|t}=\frac{s_{k|t}^{*}(\mbox{$\mbox{$\mathbf{v}$}$}_{k|t}^{*})^{\top}\mbox{$\mbox{$\mathbf{d}$}$}_{x}}{\mbox{$\sigma$}(\mbox{$\mbox{$\mathbf{u}$}$}_{k|t}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$})-\mbox{$\sigma$}(\mbox{$\mbox{$\mathbf{u}$}$}_{k|t}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t})}

(9)

which require computation of the vector
\mbox{$\mbox{$\mathbf{d}$}$}_{x}
whose length is equal to the data size
|\mathcal{D}_{1:t}|
, with the
j
’th entry is equal to
\mbox{$\sigma$}(\mbox{$\mbox{$\boldsymbol{\phi}$}$}_{j}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$})-\mbox{$\sigma$}(\mbox{$\mbox{$\boldsymbol{\phi}$}$}_{j}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t})
. Since we do not have access to old features
\mbox{$\mbox{$\boldsymbol{\phi}$}$}_{j}
, it is impossible to find the optimal
w_{k|t}^{*}
for all
\boldsymbol{\theta}
values.
In what follows, we propose a practical method to estimate such compact memory for continual logistic regression, for both binary and multi-class cases. We do not aim to exactly obtain the optimal memory but still hope to keep the memory size small enough so that it is not much larger than the rank of the feature matrix. Our method uses Hessian matching which is related to other theoretical works
(
14
;
8
;
15
)
.

3
Compact Memory for K-prior

We now present a practical alternative to estimate the optimal memory for continual logistic regression. Throughout, we assume a quadratic regularizer
\mbox{$\frac{1}{2}$}\delta_{t}\|\mbox{$\mbox{$\boldsymbol{\theta}$}$}\|^{2}
needed for training at task
t
; the method can easily handle other regularizers as well.
Motivated by
Equation

8
, we propose to define the K-prior by using a set of
unit-norm
memory vectors
\mbox{$\mbox{$\mathbf{u}$}$}_{k|t}
and their weights
w_{k|t}
, as shown below:

\mathcal{K}_{t}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mbox{$\mbox{$\mathbf{U}$}$}_{t},\mbox{$\mbox{$\mathbf{w}$}$}_{t})=\mbox{$\frac{1}{2}$}\delta_{t}\|\mbox{$\mbox{$\boldsymbol{\theta}$}$}-\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}\|^{2}+\sum_{k=1}^{K_{t}}{\color[rgb]{1,0,0}w_{k|t}}\,\mathcal{L}\left(\hat{y}(\mbox{$\mbox{$\mathbf{u}$}$}_{k|t}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t})\,,\,\hat{y}(\mbox{$\mbox{$\mathbf{u}$}$}_{k|t}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$})\right),

(10)

The set of memory and weight vectors are respectively defined as follows,

\displaystyle\mbox{$\mbox{$\mathbf{U}$}$}_{t}=\left(\mbox{$\mbox{$\mathbf{u}$}$}_{1|t}\,\,\mbox{$\mbox{$\mathbf{u}$}$}_{2|t}\,\,\ldots\,\,\mbox{$\mbox{$\mathbf{u}$}$}_{K_{t}|t}\right)\qquad\text{ and }\qquad\mbox{$\mbox{$\mathbf{w}$}$}_{t}=\left(w_{1|t}\,\,w_{2|t}\,\,\ldots\,\,w_{K_{t}|t}\right),

(11)

and we denote by
\mbox{$\mbox{$\mathbf{W}$}$}_{t}
the diagonal matrix whose diagonal is the vector
\mbox{$\mbox{$\mathbf{w}$}$}_{t}
.
Clearly, a fixed
\mbox{$\mbox{$\mathbf{w}$}$}_{t}
will not yield the optimal K-prior but we still hope that it will make the memory more compact. To estimate the memory and weights, we start with an initial value of
(\mbox{$\mbox{$\mathbf{U}$}$}_{0},\mbox{$\mbox{$\mathbf{w}$}$}_{0})
at
t=0
and use the following iterative procedure (illustrated in
Figure

1
),

1.

Estimate
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}
by training over
\bar{\ell}_{t+1}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{D}_{t+1})+\mathcal{K}_{t}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mbox{$\mbox{$\mathbf{U}$}$}_{t},\mbox{$\mbox{$\mathbf{w}$}$}_{t})
.

2.

Estimate
(\mbox{$\mbox{$\mathbf{U}$}$}_{t+1},\mbox{$\mbox{$\mathbf{w}$}$}_{t+1})
by using Hessian matching (with PPCA).

The first step is simply the standard K-prior training as in
Equation

6
. Next, we motivate the second step on a linear regression problem and then present an extension for logistic regression.

3.1
Compact Memory for Linear Regression

We consider the following linear regression problem and show that estimating the second step can be realized via Hessian matching,

\sum_{j=0}^{t}\bar{\ell}_{j}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{D}_{j})=\mbox{$\frac{1}{2}$}\delta_{t}\|\mbox{$\mbox{$\boldsymbol{\theta}$}$}\|^{2}+\sum_{j=1}^{t}\sum_{i\in\mathcal{D}_{j}}\mathcal{L}\left(y_{i},\hat{y}(\mbox{$\mbox{$\boldsymbol{\phi}$}$}_{i}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$})\right),\quad\text{ where }\mathcal{L}(y,\hat{y})=\mbox{$\frac{1}{2}$}(y-\hat{y})^{2}.

(12)

Here, we denote the quadratic regularizer
\mbox{$\frac{1}{2}$}\delta_{t}\|\theta\|^{2}
by
\bar{\ell}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{D}_{0})
. For this problem, the K-prior can perfectly recover the joint loss if memory is chosen optimally, as stated in the following theorem.

Theorem 1

For the problem in
Equation

12
, the K-prior shown in
Equation

10
is equivalent to the original loss and takes a quadratic form if we set
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}\leftarrow\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}^{*}
,
\mbox{$\mbox{$\mathbf{U}$}$}_{t}\leftarrow\mbox{$\mbox{$\mathbf{U}$}$}_{t}^{*}
and
\mbox{$\mbox{$\mathbf{W}$}$}_{t}\leftarrow\mbox{$\mbox{$\mathbf{S}$}$}_{t}^{*}
, that is, we have

\sum_{j=0}^{t}\bar{\ell}_{j}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{D}_{j})=\mathcal{K}_{t}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mbox{$\mbox{$\mathbf{U}$}$}_{t},\mbox{$\mbox{$\mathbf{w}$}$}_{t})=\mbox{$\frac{1}{2}$}(\mbox{$\mbox{$\boldsymbol{\theta}$}$}-\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t})^{\top}\mbox{$\mbox{$\mathbf{H}$}$}(\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t})(\mbox{$\mbox{$\boldsymbol{\theta}$}$}-\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t}),

(13)

where
\mbox{$\mbox{$\mathbf{H}$}$}(\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t})=\mbox{$\mbox{$\boldsymbol{\Phi}$}$}_{1:t}\mbox{$\mbox{$\boldsymbol{\Phi}$}$}_{1:t}^{\top}+\delta_{t}\mbox{$\mbox{$\mathbf{I}$}$}
is the Hessian of the objective in
Equation

12
.

A proof is included in
Section

A.1
.

This result gives a clue on how to estimate the next
(\mbox{$\mbox{$\mathbf{U}$}$}_{t+1},\mbox{$\mbox{$\mathbf{w}$}$}_{t+1})
. Essentially, if
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}\leftarrow\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}^{*}
as well, then we should choose
(\mbox{$\mbox{$\mathbf{U}$}$}_{t+1},\mbox{$\mbox{$\mathbf{w}$}$}_{t+1})
such that the following holds for all
\boldsymbol{\theta}
,

\mathcal{K}_{t+1}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mbox{$\mbox{$\mathbf{U}$}$}_{t+1},\mbox{$\mbox{$\mathbf{w}$}$}_{t+1})=\bar{\ell}_{t+1}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mathcal{D}_{t+1})+\mathcal{K}_{t}(\mbox{$\mbox{$\boldsymbol{\theta}$}$};\mbox{$\mbox{$\mathbf{U}$}$}_{t},\mbox{$\mbox{$\mathbf{w}$}$}_{t}).

(14)

Such a choice will ensure that the batch training loss for tasks 1 to
t+1
is perfectly reconstructed with the new K-prior
\mathcal{K}_{t+1}
. For linear regression, this condition is satisfied by using the second-order optimality condition, obtained by taking the second derivative of both sides at
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}
. This is because the Hessian is independent of
\boldsymbol{\theta}
and Hessian matching yields

\mbox{$\mbox{$\mathbf{U}$}$}_{t+1}\mbox{$\mbox{$\mathbf{W}$}$}_{t+1}\mbox{$\mbox{$\mathbf{U}$}$}_{t+1}^{\top}+\epsilon_{t+1}\mbox{$\mbox{$\mathbf{I}$}$}=\mbox{$\mbox{$\boldsymbol{\Phi}$}$}_{t+1}\mbox{$\mbox{$\boldsymbol{\Phi}$}$}_{t+1}^{\top}+\mbox{$\mbox{$\mathbf{U}$}$}_{t}\mbox{$\mbox{$\mathbf{W}$}$}_{t}\mbox{$\mbox{$\mathbf{U}$}$}_{t}^{\top},

(15)

where
\epsilon_{t+1}=(\delta_{t+1}-\delta_{t})
. We note that this is not possible by using the first-order optimality condition because gradients are of the same size as
\boldsymbol{\theta}
, which is not enough to estimate a (larger)
\mbox{$\mbox{$\mathbf{U}$}$}_{t}
. In contrast, the condition above is sufficient and is just another way to formulate an online SVD procedure. Essentially, we can concatenate
(\mbox{$\mbox{$\boldsymbol{\Phi}$}$}_{t+1},\,\mbox{$\mbox{$\mathbf{U}$}$}_{t}\mbox{$\mbox{$\mathbf{W}$}$}_{t}^{1/2})
and apply SVD to it to obtain
\mbox{$\mbox{$\mathbf{U}$}$}_{t+1}
and
\mbox{$\mbox{$\mathbf{w}$}$}_{t+1}
. The last term
\epsilon_{t+1}
represents the error made in this process which can be driven to zero by choosing
K_{t+1}
appropriately. SVD can however be numerically unstable and we will use an alternative based on PPCA,
which is easier to implement and also have an intuitive interpretation.

3.2
Hessian Matching via Probabilistic PCA (PPCA)

Hessian matching can be formulated as Probabilistic PCA
(
28
)
and conveniently solved using the Expectation Maximization (EM) algorithm. Essentially, we aim to find
\mbox{$\mbox{$\mathbf{U}$}$}_{t+1}
whose columns can accurately predict the columns of
\mbox{$\mbox{$\boldsymbol{\Phi}$}$}_{t+1}
and
\mbox{$\mbox{$\mathbf{U}$}$}_{t}
. More formally, we define the following two matrices,

\mbox{$\mbox{$\mathbf{T}$}$}\leftarrow\sqrt{N}(\mbox{$\mbox{$\boldsymbol{\Phi}$}$}_{t+1},\,\,\mbox{$\mbox{$\mathbf{U}$}$}_{t}\mbox{$\mbox{$\mathbf{W}$}$}_{t}^{1/2}),

(16)

where
N\leftarrow K_{t}+|\mathcal{D}_{t+1}|
.
Then, we use the following PPCA model to predict the columns
\mbox{$\mbox{$\mathbf{t}$}$}_{i}
of
\mathbf{T}
,

\displaystyle\mbox{$\mbox{$\mathbf{t}$}$}_{i}=\mbox{$\mbox{$\mathbf{U}$}$}_{t+1}\mbox{$\mbox{$\mathbf{W}$}$}_{t+1}^{1/2}\mbox{$\mbox{$\mathbf{z}$}$}_{i}+\mbox{$\mbox{$\mathbf{e}$}$}_{i},\quad\text{ where }\mbox{$\mbox{$\mathbf{z}$}$}_{i}\sim\mbox{${\cal N}$}(0,\mbox{$\mbox{$\mathbf{I}$}$})\text{ and }\mbox{$\mbox{$\mathbf{e}$}$}_{i}\sim\mbox{${\cal N}$}(0,\epsilon_{t+1}\mbox{$\mbox{$\mathbf{I}$}$}).

(17)

We now show that maximum-likelihood estimation on this model can find
(\mbox{$\mbox{$\mathbf{U}$}$}_{t+1},\mbox{$\mbox{$\mathbf{w}$}$}_{t+1})
that solve
Equation

15
. As shown by
28

Then, taking the derivative and setting it to 0, we can show that the optimality condition is to set

Section

A.2
. Similarly to online SVD, maximum likelihood over PPCA also performs Hessian matching. PPCA also enables us to estimate

\epsilon

The main advantage of this formulation is that it leads to an easy-to-implement EM algorithm. Essentially, in the E-step, we find the posterior over
\mbox{$\mbox{$\mathbf{z}$}$}_{i}

\tilde{\mathbf{U}}\leftarrow\mbox{$\mbox{$\mathbf{S}$}$}\tilde{\mathbf{U}}(\epsilon\mbox{$\mbox{$\mathbf{I}$}$}+\mbox{$\mbox{$\mathbf{M}$}$}^{-1}\tilde{\mathbf{U}}^{\top}\mbox{$\mbox{$\mathbf{S}$}$}\tilde{\mathbf{U}})^{-1},\qquad\text{ where}\quad\mbox{$\mbox{$\mathbf{M}$}$}=\tilde{\mathbf{U}}^{\top}\tilde{\mathbf{U}}+\epsilon\mbox{$\mbox{$\mathbf{I}$}$}\quad\text{ and }\quad\mbox{$\mbox{$\mathbf{S}$}$}=\mbox{$\mbox{$\mathbf{T}$}$}\mbox{$\mbox{$\mathbf{T}$}$}^{\top}/N.

(19)

3.3
An Extension for Binary Logistic Regression

We now show an extension for binary logistic regression. The procedure also works for other generalized linear models but we omit it because the derivation is straightforward. We will however briefly discuss an extension to multi-class afterward.

For binary logistic regression, aiming for a recursion similar to
Equation

14
is challenging. As discussed earlier, this is because computing the optimal
w_{k|t}
is infeasible in practice. To simplify the estimation, we relax this requirement and aim for Hessian matching at
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}
. That is, we reformulate the search for
(\mbox{$\mbox{$\mathbf{U}$}$}_{t+1},\mbox{$\mbox{$\mathbf{w}$}$}_{t+1})
as the following Hessian-matching problem at
\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}
,

\nabla^{2}\mathcal{K}_{t+1}({\color[rgb]{1,0,0}\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}};\mbox{$\mbox{$\mathbf{U}$}$}_{t+1},\mbox{$\mbox{$\mathbf{w}$}$}_{t+1})=\nabla^{2}\bar{\ell}_{t+1}({\color[rgb]{1,0,0}\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}};\mathcal{D}_{t+1})+\nabla^{2}\mathcal{K}_{t}({\color[rgb]{1,0,0}\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}};\mbox{$\mbox{$\mathbf{U}$}$}_{t},\mbox{$\mbox{$\mathbf{w}$}$}_{t}).

(20)

This condition leads to an equation shown below which takes a form similar to
Equation

15
obtained for the linear regression case. A derivation is given in
Section

A.3
, where we show that the only difference is in the diagonal matrices which are defined differently:

\mbox{$\mbox{$\mathbf{U}$}$}_{t+1}\tilde{\mathbf{W}}_{t+1}\mbox{$\mbox{$\mathbf{U}$}$}_{t+1}^{\top}+\epsilon_{t+1}\mbox{$\mbox{$\mathbf{I}$}$}=\mbox{$\mbox{$\boldsymbol{\Phi}$}$}_{t+1}\mbox{$\mbox{$\mathbf{B}$}$}_{t+1}\mbox{$\mbox{$\boldsymbol{\Phi}$}$}_{t+1}^{\top}+\mbox{$\mbox{$\mathbf{U}$}$}_{t}\tilde{\mathbf{W}}_{t}\mbox{$\mbox{$\mathbf{U}$}$}_{t}^{\top},

(21)

where
\tilde{\mathbf{W}}_{t+1},\tilde{\mathbf{W}}_{t},
and
\mbox{$\mbox{$\mathbf{B}$}$}_{t+1}
are the diagonal matrices defined as follows:

\tilde{\mathbf{W}}_{t+1}=\mbox{$\mbox{$\mathbf{W}$}$}_{t+1}\,\hat{y}^{\prime}(\mbox{$\mbox{$\mathbf{U}$}$}^{\top}_{t+1}\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}),\,\,\,\,\,\tilde{\mathbf{W}}_{t}=\mbox{$\mbox{$\mathbf{W}$}$}_{t}\,\hat{y}^{\prime}(\mbox{$\mbox{$\mathbf{U}$}$}^{\top}_{t}\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}),\,\,\,\,\,\mbox{$\mbox{$\mathbf{B}$}$}_{t+1}=\mbox{$\mbox{Diag}$}[\hat{y}^{\prime}(\mbox{$\mbox{$\boldsymbol{\Phi}$}$}_{t+1}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1})].

(22)

Here, the function
\hat{y}^{\prime}(f)
denotes the first derivative of
\hat{y}(f)
with respect to
f
. For binary logistic regression,
\hat{y}(f)=\mbox{$\sigma$}(f)
, therefore
\hat{y}^{\prime}(f)=\mbox{$\sigma$}(f)(1-\mbox{$\sigma$}(f))
. When applied to a vector
\mathbf{f}
,
\hat{y}(\mbox{$\mbox{$\mathbf{f}$}$})
returns a vector of
\hat{y}(f_{j})
, which is the case for all the quantities used above. In last expression
\mbox{$\mbox{Diag}$}(\mbox{$\mbox{$\mathbf{f}$}$})
forms a diagonal matrix whose diagonal is the vector
\mathbf{f}
.

The new Hessian matching equation can also be solved using an algorithm similar to
Algorithm

1
, shown in
Algorithm

2
. We will now briefly describe how to derive the algorithm. First, instead of using
Equation

16
, we redefine
\mathbf{T}
as shown below where we include some vectors computed using the function
\hat{y}(\cdot)
,

\mbox{$\mbox{$\mathbf{T}$}$}\leftarrow\sqrt{N}(\mbox{$\mbox{$\boldsymbol{\Phi}$}$}_{t+1}\mbox{$\mbox{Diag}$}(\boldsymbol{\lambda}_{1})^{1/2},\,\,\mbox{$\mbox{$\mathbf{U}$}$}_{t}\mbox{$\mbox{$\mathbf{W}$}$}_{t}^{1/2}\boldsymbol{\lambda}_{2}^{1/2}),

(23)

where we use
\boldsymbol{\lambda}_{1}\leftarrow\hat{y}^{\prime}(\mbox{$\mbox{$\boldsymbol{\Phi}$}$}_{t+1}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1})
and
\boldsymbol{\lambda}_{2}\leftarrow\hat{y}^{\prime}(\mbox{$\mbox{$\mathbf{U}$}$}_{t}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1})
. With this change,
\mbox{$\mbox{$\mathbf{T}$}$}\mbox{$\mbox{$\mathbf{T}$}$}^{\top}/N
is equal to the matrix in the right hand side of
Equation

20
. This is done in line 2 and 3 of
Algorithm

2
. The next change is in the update of
\mbox{$\mbox{$\mathbf{U}$}$}_{t+1}
. Essentially, we redefine

\tilde{\mathbf{U}}_{t+1}\leftarrow\mbox{$\mbox{$\mathbf{U}$}$}_{t+1}\mbox{$\mbox{$\mathbf{W}$}$}_{t+1}^{1/2}\boldsymbol{\lambda}^{1/2}

(24)

where
\boldsymbol{\lambda}\leftarrow\hat{y}^{\prime}(\mbox{$\mbox{$\mathbf{U}$}$}_{t+1}^{\top}\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1})
. With this change, the left hand side in
Equation

20
becomes
\tilde{\mathbf{U}}\tilde{\mathbf{U}}^{\top}
, and then we can apply the update shown in
Equation

19
. This is done in line 6-8. Finally, because we need to recompute
\boldsymbol{\lambda}
every time we update
\tilde{\mathbf{U}}
, we regularly extract
(\mbox{$\mbox{$\mathbf{U}$}$}_{t+1},\mbox{$\mbox{$\mathbf{w}$}$}_{t+1})
from
\tilde{\mathbf{U}}_{t+1}
, which is done in line 9-12. One minor change is to
initialize the procedure in line 1.

The computational cost of the EM algorithm is dominated by the inversion in line 8 of a square matrix of size
K_{t+1}
. Therefore, the overall complexity is in
\mathcal{O}(IK_{t+1}^{3})
where
I
is the number of iterations. For small
K_{t+1}
and
I
, this cost is manageable and does not add a huge overhead to overall training.

3.4
Extensions for Multi-Class Logistic Regression and Other Generalized Linear Models

Algorithm

2
can be easily extended to estimate compact memory for other generalized linear models. The main change required is to appropriately define the function
\hat{y}^{\prime}(f)
. We demonstrate this for multi-class logistic regression with number of classes
C
. For this case, we define a parameter vector
\mbox{$\mbox{$\boldsymbol{\theta}$}$}^{(c)}
for each class
c
, giving rise to the matrix
\mbox{$\mbox{$\boldsymbol{\Theta}$}$}=(\mbox{$\mbox{$\boldsymbol{\theta}$}$}^{(1)}\,\ldots\,\mbox{$\mbox{$\boldsymbol{\theta}$}$}^{(C)})^{\top}
. The linear predictor
for a feature
\boldsymbol{\phi}
(of length P) is defined as
\mbox{$\mbox{$\mathbf{f}$}$}=\mbox{$\mbox{$\boldsymbol{\Theta}$}$}\mbox{$\mbox{$\boldsymbol{\phi}$}$}
and is of length
C
. Given such a linear predictor, the prediction function and its derivatives are defined through the softmax function as shown below,

\hat{y}(\mbox{$\mbox{$\mathbf{f}$}$})=\mbox{$\mbox{$\mathbf{p}$}$}\,\,\text{ and}\,\,\hat{y}^{\prime}(\mbox{$\mbox{$\mathbf{f}$}$})=\mbox{$\mbox{Diag}$}(\mbox{$\mbox{$\mathbf{p}$}$})-\mbox{$\mbox{$\mathbf{p}$}$}\mbox{$\mbox{$\mathbf{p}$}$}^{\top},\text{ where $c$'th entry of $\mbox{$\mbox{$\mathbf{p}$}$}$ is }p^{(c)}=\frac{\exp(f^{(c)})}{\sum_{c^{\prime}=1}^{C}\exp(f^{(c^{\prime}))}},

(25)

which are vector and matrix of size
P
, respectively.
The gradient and Hessian are given by

\frac{\partial\mathcal{L}(\mbox{$\mbox{$\mathbf{y}$}$},\hat{y}(\mbox{$\mbox{$\mathbf{f}$}$}))}{\partial\text{\mbox{$\mbox{$\boldsymbol{\theta}$}$}}^{(c)}}=[\hat{y}(f^{(c)})-y^{(c)}]\mbox{$\mbox{$\boldsymbol{\phi}$}$},\qquad\qquad\frac{\partial^{2}\mathcal{L}(\mbox{$\mbox{$\mathbf{y}$}$},\hat{y}(\mbox{$\mbox{$\mathbf{f}$}$}))}{\partial\text{\mbox{$\mbox{$\boldsymbol{\theta}$}$}}^{(c)}\partial{\text{\mbox{$\mbox{$\boldsymbol{\theta}$}$}}^{(c^{\prime})}}^{\top}}=[\hat{y}^{\prime}(\mbox{$\mbox{$\mathbf{f}$}$})]^{(c,c^{\prime})}\mbox{$\mbox{$\boldsymbol{\phi}$}$}\mbox{$\mbox{$\boldsymbol{\phi}$}$}^{\top},

where
[\hat{y}^{\prime}(\mbox{$\mbox{$\mathbf{f}$}$})]^{(c,c^{\prime})}
denotes the entry
(c,c^{\prime})
of the matrix.
As a result, the size of the Hessian of the loss
\mathcal{L}(y,\hat{y}(\mbox{$\mbox{$\mathbf{f}$}$}))
with respect to (vectorized)
\boldsymbol{\Theta}
is a
PC\times PC
matrix where
P
is the length of each
\mbox{$\mbox{$\boldsymbol{\theta}$}$}^{(c)}
. Since a
P\times P
matrix is sufficient to estimate the memory vectors of size
P\times K_{t+1}
, we choose to perform Hessian matching over the sum
\sum_{c=1}^{C}\frac{\partial^{2}\mathcal{L}}{\partial\text{\mbox{$\mbox{$\boldsymbol{\theta}$}$}}^{(c)}\partial{\text{\mbox{$\mbox{$\boldsymbol{\theta}$}$}}^{(c)}}^{\top}}
, that is, we use the
following,

\sum_{c=1}^{C}\nabla^{2}\mathcal{K}_{t+1}(\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}^{(c)};\mbox{$\mbox{$\mathbf{U}$}$}_{t+1},\mbox{$\mbox{$\mathbf{w}$}$}_{t+1})=\sum_{c=1}^{C}\left[\nabla^{2}\bar{\ell}_{t+1}(\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}^{(c)};\mathcal{D}_{t+1})+\nabla^{2}\mathcal{K}_{t}(\mbox{$\mbox{$\boldsymbol{\theta}$}$}_{t+1}^{(c)};\mbox{$\mbox{$\mathbf{U}$}$}_{t},\mbox{$\mbox{$\mathbf{w}$}$}_{t})\right].

(26)

This condition ignores the cross-derivatives between all pairs
c\neq c^{\prime}
, but the Hessian matching takes a similar form to
Equation

21
. Essentially, we can push the sum with respect to
c
inside because the only quantity that depends on
c
is
\hat{y}(f^{(c)})
. Due to this change, we need to redefine the diagonal entries of the matrices
\tilde{\mathbf{W}}_{t+1},\tilde{\mathbf{W}}_{t},
and
\mbox{$\mbox{$\mathbf{B}$}$}_{t+1}
by using the trace of
\hat{y}^{\prime}(\mbox{$\mbox{$\mathbf{f}$}$})
, as shown below
(details in
Section

A.4
):

\begin{split}&\tilde{\mathbf{W}}_{t+1}^{(kk)}=w_{k|t+1}\mbox{Tr}\left[\hat{y}^{\prime}(\mbox{$\mbox{$\boldsymbol{\Theta}$}$}_{t+1}\mbox{$\mbox{$\mathbf{u}$}$}_{k|t+1})\right],\qquad\tilde{\mathbf{W}}_{t}^{(kk)}=w_{k|t}\mbox{Tr}\left[\hat{y}^{\prime}(\mbox{$\mbox{$\boldsymbol{\Theta}$}$}_{t+1}\mbox{$\mbox{$\mathbf{u}$}$}_{k|t})\right],\\
&\mbox{$\mbox{$\mathbf{B}$}$}_{t+1}^{(jj)}=\mbox{Tr}\left[\hat{y}^{\prime}(\mbox{$\mbox{$\boldsymbol{\Theta}$}$}_{t+1}\mbox{$\mbox{$\boldsymbol{\phi}$}$}_{j})\right],\end{split}

(27)

where
k
runs from 1 to
K_{t}
(or
K_{t+1}
) and
j
runs from 1 to
|\mathcal{D}_{1+t}|
. The trace function is denoted by
\mbox{Tr}(\hat{y}^{\prime}(\mbox{$\mbox{$\mathbf{f}$}$}))=\sum_{c}p^{(c)}(1-p^{(c)})
which takes a similar form to the binary case. Essentially, a large value of this quantity indicates that the corresponding feature is important for at least one class.
To improve numerical stability, we clip the vector
\mathbf{p}
away from 1 or 0 by a small amount (we use
10^{-4}
). Overall, this example demonstrates how to extend our approach to other generalized linear models.

Discussion

As large pre-trained neural networks show remarkable performance, adaptation of these models to new environments is becoming increasingly important. However, even in the case of continual learning with a shallow neural network, the performance tends to degrade due to catastrophic forgetting issues. To remedy this issue, models require storing a substantial memory as the learning progresses, which makes continual learning less practical.

In this work, we present a Hessian matching method to obtain compact memory for continual logistic regression. We demonstrate that, this compact memory, seeking for accurate gradient reconstructions of past tasks’ losses, significantly boosts memory efficiency. We further show that the memory efficiency holds even when the compact memory is used jointly with the pre-trained neural network as a feature extractor. Although our algorithm is currently limited to the use of only the last-layer of a neural network with a frozen feature extractor, to ensure the principle of gradient reconstruction, we expect that this simple solution opens a new path to finding the compact memory for large-scale deep neural networks such as a foundation model, and that this compact memory enables these models to continually adapt to new tasks in a memory-efficient way.

The marginal likelihood in

\mbox{$\mbox{$\mathbf{e}$}$}_{i}

\mbox{$\mbox{$\mathbf{t}$}$}_{i}\sim\mbox{${\cal N}$}(0,\mbox{$\mbox{$\mathbf{C}$}$})

\begin{split}\log p(\mbox{$\mbox{$\mathbf{T}$}$}|\mbox{$\mbox{$\mathbf{U}$}$}_{t+1},\mbox{$\mbox{$\mathbf{W}$}$}_{t+1})&=\sum_{i=1}^{N}\log\mbox{${\cal N}$}(\mbox{$\mbox{$\mathbf{t}$}$}_{i}|0,\mbox{$\mbox{$\mathbf{C}$}$})=-\sum_{i=1}^{N}\left[\mbox{$\frac{1}{2}$}\log|\mbox{$\mbox{$\mathbf{C}$}$}|+\mbox{$\frac{1}{2}$}\mbox{$\mbox{$\mathbf{t}$}$}_{i}^{\top}\mbox{$\mbox{$\mathbf{C}$}$}^{-1}\mbox{$\mbox{$\mathbf{t}$}$}_{i}\right]+\text{cnst.}\\

\begin{split}\tilde{\mathbf{U}}_{t+1}&\leftarrow\left(\sum_{i=1}^{N}\mbox{$\mbox{$\mathbf{t}$}$}_{i}\mathbb{E}[\mbox{$\mbox{$\mathbf{z}$}$}_{i}]^{\top}\right)\left(\sum_{i=1}^{N}\mathbb{E}[\mbox{$\mbox{$\mathbf{z}$}$}_{i}\mbox{$\mbox{$\mathbf{z}$}$}^{\top}_{i}]\right)^{-1}\\

(33)
