Independent set sequence of some linear hypertrees
David Galvin, Courtney Sharpe

Abstract
The independent set sequence of trees has been well studied, with much effort devoted to the (still open) question of Alavi, Malde, Schwenk and Erdős on whether the independent set sequence of a tree is always unimodal. Much less attention has been given to the independent set sequence of hypertrees. Here we study some natural first questions in this realm. We show that the strong independent set sequences of linear hyperpaths and of linear hyperstars are unimodal (actually, log-concave). For uniform linear hyperpaths we obtain explicit expressions for the number of strong independent sets of each possible size, both via generating functions and via combinatorial arguments. We also consider the uniform linear hypercomb with n \displaystyle n edges on the spine, and show that its strong independent set sequence is unimodal except possibly for a portion of length o ⁡ ( n ) \displaystyle o(n) .

Introduction

In 1987 Alavi, Malde, Schwenk and Erdős considered the
vertex independent set sequence
, or simply
independent set sequence
, of a graph. This is the sequence
\displaystyle(i_{k}(G))_{k\geq 0}
where
\displaystyle i_{k}(G)
is the number of vertex independent sets (sets of pairwise non-adjacent vertices) of size
\displaystyle k
in a graph
\displaystyle G
. (Note that all graphs and hypergraphs in this paper are simple — all edges have multiplicity one — and undirected.)

The
edge independent set sequence
, better known as the
matching sequence
, is the sequence
\displaystyle(m_{k}(G))_{k\geq 0}
where
\displaystyle m_{k}(G)
is the number of matchings (sets of pairwise disjoint edges) of size
\displaystyle k
in
\displaystyle G
. A corollary of a seminal result of Heilmann and Lieb
[
18
]
is that the matching sequence is always unimodal, that is, that there is a mode
\displaystyle k
such that

m_{0}(G)\leq m_{1}(G)\leq\cdots\leq m_{k}(G)\geq m_{k+1}(G)\geq\cdots.

The notion of unimodality (and the related ideas of log-concavity and real-rootedness, to be discussed later) are ubiquitous in combinatorics; see for example the surveys
[
8
,
9
,
25
]
.

Wilf asked the question “is the independent set sequence of every graph similarly unimodal?”. In
[
1
]
it was reported that he was skeptical of an affirmative answer, and it turned out that his skepticism was justified. Alavi, Malde, Schwenk and Erdős
[
1
]
showed that the independent set sequence of a graph can fail spectacularly to be unimodal. Specifically they showed that for every
\displaystyle m
and every permutation
\displaystyle\pi
of
\displaystyle\{1,\ldots,m\}
there is a graph
\displaystyle G
whose largest independent set has size
\displaystyle m
and for which

i_{\pi(1)}(G)<i_{\pi(2)}(G)<\cdots<i_{\pi(m)}(G).

In other words, the independent set sequence can exhibit arbitrary rises and falls. (Note that we do not consider
\displaystyle i_{0}(G)
here as it always takes the smallest possible non-zero value,
\displaystyle 1
).

This “roller coaster” observation naturally led Alavi, Malde, Schwenk and Erdős to consider whether there are infinite families of graphs for which the independent set sequence
is
unimodal. Since the matching sequence of a graph is the independent set sequence of its line graph, it follows from Heilmann and Lieb’s result that line graphs have unimodal independent set sequences. This was generalized by Hamidoune
[
16
]
: claw-free graphs (graphs without an induced
\displaystyle K_{1,3}
) have unimodal independent set sequences.

Alavi, Malde, Schwenk and Erdős asked about another very basic family of graphs. It is easy to check that the independent set sequence of a path is unimodal, and even easier to check that the same is true of a star. That unimodality holds for these two most extreme trees provides some reason to expect that it holds for all trees.

Question 1.1
.

(
[
1
]
) Do all trees have unimodal independent set sequence? What about all forests?

The
independent set polynomial

\displaystyle p_{G}(x)
is the generating polynomial
\displaystyle\sum_{k\geq 0}i_{k}(G)x^{k}
. It is an easy check that if
\displaystyle G
has components
\displaystyle G_{1},\ldots,G_{m}
then
\displaystyle p_{G}(x)=p_{G_{1}}(x)\cdots p_{G_{m}}(x)
. Since the product of polynomials with unimodal coefficient sequences need not have a unimodal coefficient sequence, an affirmative answer to Question
1.1
for trees does not immediately imply an affirmative answer for forests. As an example of this phenomenon of unimodality not behaving well under multiplication, consider the graphs
\displaystyle G_{1}=K_{100}+3K_{7}
(the join of a clique on 100 vertices and a disjoint union of three cliques each on 7 vertices) and
\displaystyle G_{2}=K_{90}+3K_{7}
. We have

p_{G_{1}}(x)=1+121x+147x^{2}+343x^{3},~~~p_{G_{2}}(x)=1+111x+147x^{2}+343x^{3},

which are both unimodal, but

p_{G_{1}\cup G_{2}}(x)=p_{G_{1}}(x)p_{G_{2}}(x)=1+232x+13725x^{2}+34790x^{3}+101185x^{4}+100842x^{5}+117649x^{6},

which is not. (This example is due to Levit and Mandrescu
[
21
]
.)

Remarkably, Question
1.1
remains fairly wide open. It has been verified for some infinite, mostly recursively defined, families of trees (see e.g.
[
14
]
and the references therein). It has also been verified for all trees on 26 or fewer vertices
[
20
]
. Notably, although all trees on 25 or fewer vertices satisfy the stronger property that their independence polynomials are log-concave (i.e., satisfy
\displaystyle a_{k}^{2}\geq a_{k-1}a_{k+1}
for all
\displaystyle k\geq 1
), two trees on 26 vertices are found in
[
20
]
to have unimodal but not log-concave independent set sequences, and in
[
4
,
13
,
19
,
24
]
infinite families of trees with non-log-concave (though still unimodal) independent set sequences are found. This perhaps explains why Question
1.1
has proven to be so thorny — typically it is easier to demonstrate log-concavity than unimodality.

Even answering Question
1.1
for the uniform random labelled tree (i.e., showing that at least a proportion
\displaystyle 1-o(1)
of all labelled trees on
\displaystyle n
vertices have unimodal independent set sequences) has proven to be a difficult problem. See
[
3
,
17
]
where this question is addressed and only partial results are obtained.

1.1
Hypertrees

The goal of this paper is to begin the project of considering Alavi, Malde, Schwenk and Erdős’ question for
hypertrees
. A
hypergraph
is a pair
\displaystyle(V,E)
where
\displaystyle V
is a set of vertices and
\displaystyle E
is a set of
edges
, which are subsets of
\displaystyle V
. If all subsets have size
\displaystyle 2
then a hypergraph is simply a graph. A hypergraph
\displaystyle H
is a
hypertree
if there is a tree
\displaystyle{\rm tree}(H)
on vertex set
\displaystyle V(H)
with the property that for each
\displaystyle e\in E(H)
the subgraph of
\displaystyle{\rm tree}(H)
induced by
\displaystyle e
is connected. Every tree
\displaystyle T
is a hypertree — just take
\displaystyle{\rm tree}(T)=T
.

Before asking any question about independent sets in hypertrees, we need to clarify what we mean, since as is almost always the case when moving from graphs to hypergraphs there are competing definitions. A
weak independent set
in a hypergraph is a subset of vertices that does not contain all the vertices of any edge of the hypergraph, while a
strong independent set
is one that contains at most one vertex from each edge. Note that these two notions coincide for a graph.

Convention 1.2
.

In this paper we work exclusively with strong independent sets, and will simply refer to them as
independent sets
from here on.

It is not the case that every hypertree has unimodal independent set sequence. Indeed, consider the hypergraph on vertex set
\displaystyle\{v_{1},\ldots,v_{10},w_{1},\ldots,w_{6}\}
with
\displaystyle\{v_{1},\ldots,v_{10},w_{i}\}
an edge for each
\displaystyle i
. Independent sets of size
\displaystyle 2
or greater in this hypergraph cannot include any vertices from among
\displaystyle\{v_{1},\ldots,v_{10}\}
but can include vertices from
\displaystyle\{w_{1},\ldots,w_{6}\}
without restriction. It follows that the independent set sequence of the hypergraph is
\displaystyle(1,16,15,20,15,6,1)
, which is not unimodal.

To remove from consideration examples like this, our focus in this paper will be on linear hypertrees. A hypergraph is
linear
if any two edges intersect in at most one vertex. We begin by considering two infinite families of linear hypertrees, namely the linear hyperpaths and the linear hyperstars. Let integers
\displaystyle n\geq 1
and
\displaystyle s_{1},s_{2},\ldots,s_{n}\geq 2
be given.

•

The
linear hyperpath

\displaystyle P(s_{1},\ldots,s_{n})
is the hypergraph with
\displaystyle n
edges
\displaystyle e_{1},\ldots,e_{n}
, with
\displaystyle|e_{i}|=s_{i}
for each
\displaystyle i
, with
\displaystyle e_{i}
and
\displaystyle e_{i+1}
sharing a single vertex for each
\displaystyle i<n
, and with no other pairs of edges sharing a vertex.

•

If all
\displaystyle s_{i}=\ell
for some
\displaystyle\ell\geq 2
then we use the notation
\displaystyle P_{n,\ell}
, and refer to this hypergraph as the
\displaystyle\ell
-uniform,
\displaystyle n
-edge, linear hyperpath
(see Figure

•

The
linear hyperstar

\displaystyle S(s_{1},\ldots,s_{n})
is the hypergraph with
\displaystyle n
edges
\displaystyle e_{1},\ldots,e_{n}
, with
\displaystyle|e_{i}|=s_{i}
for each
\displaystyle i
, and with a single vertex (the
center
of the star) in common to all of the edges.

Note that
\displaystyle P_{n,2}

\displaystyle n

\displaystyle S(2,2,\ldots,2)
is the (graph) star on

Just as with trees, the unimodality of independent set sequences of linear hyperpaths and linear hyperstars is fairly straightforward. Before stating the result, we introduce some further concepts. A sequence
\displaystyle(a_{k})_{k=0}^{n}
of real numbers is
log-concave
if for all
\displaystyle 1\leq k\leq n-1
it holds that
\displaystyle a_{k}^{2}\geq a_{k-1}a_{k+1}
. If a log-concave sequence is non-negative and has no internal zeroes (meaning that there is no triple
\displaystyle 0\leq i\leq j\leq k\leq n
with
\displaystyle a_{i}>0
,
\displaystyle a_{j}=0
and
\displaystyle a_{k}>0
) then it is easy to check that the sequence is unimodal. Often log-concavity of a sequence is easier to establish than unimodality, since to verify unimodality one must identify the location of the mode, but there is no such difficulty when establishing log-concavity.

There is a stronger property of finite real sequences than log-concavity. A sequence
\displaystyle(a_{k})_{k=0}^{n}
is
real-rooted
if the polynomial
\displaystyle\sum_{k=0}^{n}a_{k}x^{k}
has only real roots. A result that ultimately goes back to Newton is that if a non-negative sequence is real-rooted, then it is log-concave, and in fact satisfies the stronger inequalities

a_{k}^{2}\geq\left(1+\frac{1}{k}\right)\left(1+\frac{1}{n-k}\right)a_{k-1}a_{k+1}

(1)

for all
\displaystyle 1\leq k\leq n-1
(see e.g.
[
6
, Section 9.3]
). We note incidentally that for a non-negative sequence with no internal zeros neither of the implications in the chain

real-rooted
\displaystyle\Rightarrow
log-concave
\displaystyle\Rightarrow
unimodal

can be reversed.

We now return to hyperstars and hyperpaths. Since the independent set sequences of
\displaystyle P(s_{1},\ldots,s_{n})
and
\displaystyle S(s_{1},\ldots,s_{n})
have no internal zeroes, our first result — Theorem
1.3
below — implies that these sequences are unimodal. The proof of Theorem
1.3
is given in Section
2.1
.

Theorem 1.3
.

For
\displaystyle n\geq 1
and
\displaystyle s_{1},s_{2},\ldots,s_{n}\geq 2

•

the independent set sequence of
\displaystyle P(s_{1},\ldots,s_{n})
is real-rooted, and

•

the independent set sequence of
\displaystyle S(s_{1},\ldots,s_{n})
is log-concave.

The bulk of this paper is concerned with

\displaystyle\ell=2

\displaystyle p_{n,2}^{k}

\displaystyle P_{n,2}

\displaystyle p_{n^{\prime},2}^{k^{\prime}}

p_{n,2}^{k}=\binom{n-k+2}{k}.

(2)

Things get more involved when
\displaystyle\ell\geq 3

\displaystyle p_{n,\ell}^{k}

]
who showed that the independent set sequence of a claw-free graph is real-rooted, and so in fact the independent set sequence of
\displaystyle P(s_{1},\ldots,s_{n})
is real-rooted.

We now move on to the linear hyperstar. Noting that other than the independent set of size
\displaystyle 1
that consists of the center of the star (vertex
\displaystyle v
, say), an independent set in
\displaystyle S(s_{1},s_{2},\ldots,s_{n})
is the union of arbitrary subsets of size
\displaystyle 0
or
\displaystyle 1
of
\displaystyle e_{i}\setminus\{v\}
as
\displaystyle i
runs between
\displaystyle 1
and
\displaystyle n
, we see that the independence polynomial of
\displaystyle S(s_{1},s_{2},\ldots,s_{n})
is

x+\prod_{i=1}^{n}(1+(s_{i}-1)x).

For
\displaystyle n=1,2
this polynomial is easy seen to be real-rooted and so has log-concave coefficient sequence. For
\displaystyle n\geq 3
the independence polynomial of
\displaystyle S(s_{1},\ldots,s_{n})
is not always real-rooted (consider
\displaystyle n=3
and
\displaystyle s_{1}=s_{2}=s_{3}=2
, for example), but we can still establish log-concavity of the coefficient sequence.

Let
\displaystyle a_{0},\ldots,a_{n}
be defined by

\prod_{i=1}^{n}(1+(s_{i}-1)x)=\sum_{j=0}^{n}a_{j}x^{j},

so that the independent set sequence of
\displaystyle S(s_{1},\ldots,s_{n})
is
\displaystyle(a_{0},1+a_{1},a_{2},\ldots,a_{n})
. Because
\displaystyle\prod_{i=1}^{n}(1+(s_{i}-1)x)
is real-rooted its coefficient sequence is log-concave, and this automatically gives us all of the log-concavity relations for the independent set sequence of
\displaystyle S(s_{1},\ldots,s_{n})
, except

a_{2}^{2}\geq(a_{1}+1)a_{3}~~~\mbox{and}~~~(a_{1}+1)^{2}\geq a_{0}a_{3}.

The second of these follows immediately from
\displaystyle a_{1}^{2}\geq a_{0}a_{3}
. For the first we use that in fact the coefficient sequence of
\displaystyle\prod_{i=1}^{n}(1+(s_{i}-1)x)
satisfies the Newton inequalities (
1
), so that

a_{2}^{2}\geq\left(\frac{3n-3}{2n-4}\right)a_{1}a_{3}.

The relation
\displaystyle a_{2}^{2}\geq(a_{1}+1)a_{3}
would thus follow from

\left(\frac{3n-3}{2n-4}\right)a_{1}a_{3}\geq(a_{1}+1)a_{3}

or equivalently
\displaystyle a_{1}\geq(2n-4)/(n+1)
. Since all
\displaystyle s_{i}\geq 2
and
\displaystyle n\geq 3
we have
\displaystyle a_{1}\geq 3
, and since
\displaystyle 3\geq(2n-4)/(n+1)
for all
\displaystyle n\geq 3
we indeed get
\displaystyle a_{1}\geq(2n-4)/(n+1)
. We conclude that the independent set sequence of
\displaystyle S(s_{1},\ldots,s_{n})
is log-concave.

2.2
Deriving a formula for
\displaystyle p_{n,\ell}^{k}

For ordinary paths there is a very simple recurrence for calculating
\displaystyle p^{k}_{n,2}
(once suitable initial conditions have been established), namely

p^{k}_{n,2}=p^{k}_{n-1,2}+p^{k-1}_{n-2,2},

obtained by considering whether or not the first vertex of the path is in the independent set. For
\displaystyle\ell\geq 3
we need to introduce an auxiliary hypergraph, which we denote by
\displaystyle Q_{n,\ell}
, that is obtained from the hyperpath
\displaystyle P_{n,\ell}
by removing the vertex
\displaystyle v_{1}
(so
\displaystyle Q_{n,\ell}
has one edge of size
\displaystyle\ell-1
, with the rest having size
\displaystyle\ell
; see Figure
1
). Let the edges of
\displaystyle Q_{n,\ell}
be
\displaystyle e_{1}^{\prime},e_{2},\ldots,e_{n}
, and denote by
\displaystyle q^{k}_{n,\ell}
the number of independent sets of size
\displaystyle k
in
\displaystyle Q_{n,\ell}
.

There are a pair of coupled recurrences for
\displaystyle p^{k}_{n,\ell}
and
\displaystyle q^{k}_{n,\ell}
, obtained by considering whether or not the independent set includes a vertex from
\displaystyle e_{1}\setminus\{v_{\ell}\}
or
\displaystyle e^{\prime}_{1}\setminus\{v_{\ell}\}
. Indeed, for
\displaystyle n,k\geq 2
we have

\begin{array}[]{rcl}p^{k}_{n,\ell}&=&p^{k}_{n-1,\ell}+(\ell-1)q^{k-1}_{n-1,\ell}\\
&\mbox{and}&\\
q^{k}_{n,\ell}&=&p^{k}_{n-1,\ell}+(\ell-2)q^{k-1}_{n-1,\ell}.\end{array}

(7)

Observe that when
\displaystyle\ell=2
the second relation above reduces to
\displaystyle q^{k}_{n,\ell}=p^{k}_{n-1,\ell}
, and the system above is easily seen to reduce to the standard recurrence for
\displaystyle p_{n,2}^{k}
.

The initial conditions for the recurrences for
\displaystyle p^{k}_{n,\ell}
and
\displaystyle q^{k}_{n,\ell}
are:

•

For
\displaystyle n=0
:
\displaystyle p^{0}_{0,\ell}=q^{0}_{0,\ell}=1
(due to the empty set) and
\displaystyle p^{k}_{0,\ell}=q^{k}_{0,\ell}=0
for
\displaystyle k\geq 1
.

•

For
\displaystyle n=1
:
\displaystyle p^{0}_{1,\ell}=q^{0}_{1,\ell}=1
,
\displaystyle p^{1}_{1,\ell}=\ell
,
\displaystyle q^{1}_{1,\ell}=\ell-1
, and
\displaystyle p^{k}_{1,\ell}=q^{k}_{1,\ell}=0
for
\displaystyle k\geq 2
.

•

For
\displaystyle k=0
:
\displaystyle p^{0}_{n,\ell}=q^{0}_{n,\ell}=1
.

•

For
\displaystyle k=1
:
\displaystyle p^{1}_{n,\ell}=n\ell-(n-1)
and
\displaystyle q^{1}_{n,\ell}=n\ell-n
for
\displaystyle n\geq 2
.

The recurrences (
7

\displaystyle p^{k}_{n,\ell}
and
\displaystyle q^{k}_{n,\ell}
can be decoupled to allow
\displaystyle p^{k}_{n,\ell}
to be expressed in terms of
\displaystyle p^{k^{\prime}}_{n^{\prime},\ell}
with
\displaystyle k^{\prime}+n^{\prime}<k+n
and with no reference to
\displaystyle q^{k^{\prime}}_{n^{\prime},\ell}
’s. To achieve this decoupling it is easiest to work with the independence polynomials of
\displaystyle P_{n,\ell}
and
\displaystyle Q_{n,\ell}
. Setting

P_{n,\ell}(x)=\sum_{k\geq 0}p^{k}_{n,\ell}x^{k}~\mbox{and}~Q_{n,\ell}(x)=\sum_{k\geq 0}q^{k}_{n,\ell}x^{k}

we have (as before by first considering those independent sets in which none of the vertices unique to the first edge are in the independent set, and then considering those in which one such vertex is in the independent set)

P_{n,\ell}(x)=P_{n-1,\ell}(x)+(\ell-1)xQ_{n-1,\ell}(x)

(8)

and

Q_{n,\ell}(x)=P_{n-1,\ell}(x)+(\ell-2)xQ_{n-1,\ell}(x)

(9)

for
\displaystyle n\geq 2
, with initial conditions

P_{0,\ell}(x)=Q_{0,\ell}(x)=1,P_{1,\ell}(x)=1+\ell x~\mbox{and}~Q_{1,\ell}(x)=1+(\ell-1)x.

From (
8

Q_{n-1,\ell}(x)=\frac{P_{n,\ell}(x)-P_{n-1,\ell}(x)}{(\ell-1)x}~~~\mbox{and}~~~Q_{n,\ell}(x)=\frac{P_{n+1,\ell}(x)-P_{n,\ell}(x)}{(\ell-1)x}.

Inserting these into (
9

\frac{P_{n+1,\ell}(x)-P_{n,\ell}(x)}{(\ell-1)x}=P_{n-1,\ell}(x)+\frac{(\ell-2)x\left(P_{n,\ell}(x)-P_{n-1,\ell}(x)\right)}{(\ell-1)x}.

After rearranging terms and shifting indices we get that for
\displaystyle n\geq 3
,

P_{n,\ell}(x)=(1+(\ell-2)x)P_{n-1,\ell}(x)+xP_{n-2,\ell}(x).

Combining this with the initial conditions
\displaystyle P_{0,\ell}(x)=1
and
\displaystyle P_{1,\ell}(x)=1+\ell x
(as introduced above) and

P_{2,\ell}(x)=1+(2\ell-1)x+(\ell-1)^{2}x^{2}

(an easy direct count) we have completely decoupled
\displaystyle P_{n,\ell}(x)
from
\displaystyle Q_{n,\ell}(x)
. Extracting the coefficient of
\displaystyle x^{n}
from both sides of (
5

4

2.3
Combinatorial proof of the formula for
\displaystyle p_{n,\ell}^{k}

In Section
2.2
we established (
3
) inductively.
Here we give a combinatorial proof of this formula. Let
\displaystyle{\mathcal{P}}_{n,\ell}^{k}
be the set of independent sets of size
\displaystyle k
in the hypergraph
\displaystyle P_{n,\ell}
. We will partition
\displaystyle{\mathcal{P}}_{n,\ell}^{k}
into
\displaystyle k-1
blocks,
\displaystyle{\mathcal{P}}_{n,\ell}^{k,0},{\mathcal{P}}_{n,\ell}^{k,1},\ldots,{\mathcal{P}}_{n,\ell}^{k,k-2}
, with the property that for each
\displaystyle j

\left|{\mathcal{P}}_{n,\ell}^{k,j}\right|=(\ell-1)^{2}(\ell-2)^{k-2-j}\binom{k-2}{j}\binom{n-j}{k}.

(15)

The partitioning will be done by identifying a statistic associated with an independent set (ranging from
\displaystyle 0
to
\displaystyle k-2
);
\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}
will be those independent sets with statistic
\displaystyle j
. We will then establish (
15
) by a direct count.

Let
\displaystyle I=\{v_{1},\ldots,v_{k}\}
be an independent set in
\displaystyle P_{n,\ell}
of size
\displaystyle k
, with
\displaystyle v_{1}<v_{2}<\cdots<v_{k}
in the natural linear order on the vertices of
\displaystyle P_{n,\ell}
. To
\displaystyle v_{i}
we associate a
marked
edge
\displaystyle e_{i}
of
\displaystyle P_{n,\ell}
via the following rule:

•

if there is a unique edge that contains
\displaystyle v_{i}
, then that unique edge is the marked edge; and

•

if
\displaystyle v_{i}
is in two edges of
\displaystyle P_{n,\ell}
, then the later (rightmost) edge of the two is the marked edge.

Note that the number of marked edges is
\displaystyle|I|
. We refer to the collection of marked edges as the
skeleton
of
\displaystyle I
. (See Figure
3
.)

Figure 3:

\displaystyle 4
in the hyperpath
\displaystyle P_{6,5}
. The marked edges (
\displaystyle e_{1},e_{2},e_{3}
and
\displaystyle e_{4}
) are shaded in teal. The vertex
\displaystyle v_{2}
is forced and the vertex
\displaystyle v_{3}

For
\displaystyle i=2,\ldots,k-1
, say that
\displaystyle v_{i}
is

if
\displaystyle v_{i}
is the leftmost vertex of
\displaystyle e_{i}
(so, the vertex that
\displaystyle e_{i}
has in common with the edge of
\displaystyle P_{n,\ell}
that comes immediately to its left), and
free
otherwise. (Again see Figure
3
.) Note that for
\displaystyle i=1
and
\displaystyle i=k
we do not define forced or free.

We are now ready to define the statistic
\displaystyle j
:

For
\displaystyle j=0,\ldots,k-2
, let
\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}
be the set of independent sets in
\displaystyle{\mathcal{P}}_{n,\ell}^{k}
that have exactly
\displaystyle j
forced vertices.

Claim 2.1
.

For each
\displaystyle n\geq 2,k\geq 2,\ell\geq 3
and
\displaystyle 0\leq j\leq k-2
, (
15
) holds.

This claim furnishes a combinatorial proof of (
3
).

Proof.

(Claim
2.1
.)
We will make extensive use of the following observation, which follows from a simple stars-and-bars argument:

\begin{array}[]{c}\mbox{The number of solutions to the equation $\displaystyle x_{1}+x_{2}+\cdots+x_{t}=m$, with all $\displaystyle x_{i}$'s}\\
\mbox{non-negative integers (and $\displaystyle m$ a non-negative integer), in which exactly $\displaystyle s$ of}\\
\mbox{the $\displaystyle x_{i}$'s are constrained to be at least $\displaystyle 1$, exactly $\displaystyle r$ of them are constrained }\\
\mbox{to be equal to $\displaystyle 0$, and the rest are constrained to be at least $\displaystyle 0$, is}\\
\mbox{$\displaystyle\binom{t-r-1+m-s}{t-r-1}$.}\end{array}

(16)

The relevance of this observation stems from the fact that the
\displaystyle k
edges in the skeleton give rise to a collection of
\displaystyle k+1
intervals of consecutive unmarked edges among the
\displaystyle n-k
unmarked edges. Specifically, the first interval is the collection of unmarked edges to the left of the first marked edge (this collection may be empty). The second interval is the collection of unmarked edges between the first marked edge and the second marked edge, not including the marked edges, and so on, up to the
\displaystyle(k+1)
st interval, which is the collection of unmarked edges to the right of the last marked edge. Letting
\displaystyle a_{i}
be the number of unmarked edges in the
\displaystyle i
th interval (so
\displaystyle a_{i}
is the number unmarked edges between
\displaystyle e_{i-1}
and
\displaystyle e_{i}
for
\displaystyle i=2,\ldots,k
) we get that each skeleton gives rise to an equation
\displaystyle a_{1}+a_{2}+\cdots+a_{k+1}=n-k
, with all the
\displaystyle a_{i}
’s integers greater than or equal to
\displaystyle 0
.

We further partition
\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}
into four blocks:

\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}(0,\geq 1)

is the set of independent sets in
\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}
in which
\displaystyle a_{k}=0
and
\displaystyle a_{k+1}\geq 1
.

\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}(0,0)

is the set of independent sets in
\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}
in which
\displaystyle a_{k}=a_{k+1}=0
.

\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}(\geq 1,\geq 1)

is the set of independent sets in
\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}
in which
\displaystyle a_{k},a_{k+1}\geq 1
.

\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}(\geq 1,0)

is the set of independent sets in
\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}
in which
\displaystyle a_{k}\geq 1
and
\displaystyle a_{k+1}=0
.

We start by enumerating
\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}(0,\geq 1)
. As described earlier, the skeleton induces a composition
\displaystyle a_{1}+a_{2}+\cdots+a_{k+1}=n-k
with all the
\displaystyle a_{i}
’s integers greater than or equal to
\displaystyle 0
. We have the specific restriction
\displaystyle a_{k}=0
.

Additionally, we have
\displaystyle j
forced vertices. When we force a vertex (say the first vertex of
\displaystyle e_{i}
), the edge to the left of
\displaystyle e_{i}
cannot be marked. Thus the interval of unmarked edges to the left of an edge that has a forced vertex must be non-empty, which means that
\displaystyle j
of the
\displaystyle a_{i}
’s must be at least
\displaystyle 1
. But we also in this case have unmarked edges following the last marked edge, leading to one more
\displaystyle a_{i}
that must be at least
\displaystyle 1
(specifically
\displaystyle a_{k+1}
). Notice the rest of the intervals have no constraints on their lengths — they may be empty or non-empty.

We may thus apply (
16
) with
\displaystyle m=n-k
,
\displaystyle t=k+1
,
\displaystyle s=j+1
and
\displaystyle r=1
to conclude that the number of skeletons in this case is given by
\displaystyle\binom{n-j-2}{k-1}
.

We must further decide where among the
\displaystyle k-2
middle edges of the skeleton the
\displaystyle j
edges that are forced occur, or, equivalently, where the
\displaystyle k-2-j
free edges occur. This is accounted for by a factor
\displaystyle\binom{k-2}{k-2-j}
.

Inside each of the
\displaystyle k-2-j
free edges in the skeleton we must choose which vertex from the edge is actually in the independent set. That vertex must be one of the
\displaystyle\ell-2
vertices in the center of the edge (since the edge is free, we cannot choose the first vertex, and we also cannot choose the last overlapping vertex, as that would be the marked vertex in the next edge). This leads to a factor of
\displaystyle(\ell-2)^{k-2-j}
.

Considering the first edge
\displaystyle e_{1}
, we must choose one of the vertices in that edge to be in the independent set. We cannot choose the final vertex of the edge; that would cause the edge immediately to the right of
\displaystyle e_{1}
to be marked, and
\displaystyle e_{1}
not to be marked. So we have
\displaystyle\ell-1
options.

The analysis of the previous three paragraphs will be common to all four cases, so it is convenient to set

A:=(\ell-1)(\ell-2)^{k-2-j}\binom{k-2}{k-2-j}.

(17)

Finally looking at edge
\displaystyle e_{k}
, the last marked edge: we cannot choose the first vertex of
\displaystyle e_{k}
to be in the independent set, or else the previous edge (immediately to the left of
\displaystyle e_{k}

\displaystyle e_{k}

\displaystyle e_{k}
to be in the independent set (if we did, that vertex would have caused the edge immediately to the right of
\displaystyle e_{k}
to have been the marked edge associated with that vertex). Thus we are left with
\displaystyle(\ell-2)
options to choose from for the vertex of the independent set that is in
\displaystyle e_{k}

It follows that

\left|{\mathcal{P}}_{n,\ell}^{k,j}(0,\geq 1)\right|=A(\ell-2)\binom{n-j-2}{k-1}.

(18)

We now move on to enumerating
\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}(0,0)
. Again the skeleton induces a composition
\displaystyle a_{1}+a_{2}+\cdots+a_{k+1}=n-k
with all the
\displaystyle a_{i}

\displaystyle 0
, and with the specific restriction
\displaystyle a_{k}=0
.

As before each of the
\displaystyle j
forced vertices gives rise to a restriction
\displaystyle a_{i}\geq 1
, and in this case there is no further such restriction. We may thus apply (

) with
\displaystyle m=n-k

\displaystyle t=k+1
,
\displaystyle s=j
and
\displaystyle r=1
to conclude that the number of skeletons in this case is given by
\displaystyle\binom{n-j-2}{k-2}
.

Deciding where among the
\displaystyle k-2
middle edges of the skeleton the
\displaystyle j
edges that are forced occur, choosing a vertex from inside each of the
\displaystyle k-2-j
free edges to be in the independent set, and choosing a vertex from
\displaystyle e_{1}
to be in the independent set, together give a contribution of
\displaystyle(\ell-1)(\ell-2)^{k-2-j}\binom{k-2}{k-2-j}
, as before.

To finish this case, again we look at the last marked edge
\displaystyle e_{k}
. Again we cannot choose the first vertex to be a part of the independent set, or else the previous edge could not be marked (contradicting
\displaystyle a_{k}=0
). Since the last vertex of
\displaystyle e_{k}
is not the first vertex of a later edge, we can choose the final vertex of
\displaystyle e_{k}
to be the vertex of the independent set from
\displaystyle e_{k}
. Thus in this case we have
\displaystyle(\ell-1)
options to choose from for the vertex of the independent set that is in
\displaystyle e_{k}
.

It follows that

\left|{\mathcal{P}}_{n,\ell}^{k,j}(0,0)\right|=A(\ell-1)\binom{n-j-2}{k-2}.

(19)

To enumerate

\displaystyle a_{k}=0

Deciding where among the
\displaystyle k-2
middle edges of the skeleton the
\displaystyle j
edges that are forced occur, choosing a vertex from inside each of the
\displaystyle k-2-j
free edges to be in the independent set, and choosing a vertex from
\displaystyle e_{1}
to be in the independent set, together give a contribution of
\displaystyle(\ell-1)(\ell-2)^{k-2-j}\binom{k-2}{k-2-j}

Now looking at
\displaystyle e_{k}

\displaystyle e_{k}
that causes it to be marked, since the edge immediately to the left of
\displaystyle e_{k}
is unmarked. And since there are edges in the hyperpath after (to the right of)
\displaystyle e_{k}
in this case, similar to our consideration of
\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}(0,\geq 1)

\displaystyle e_{k}

\displaystyle e_{k}

\displaystyle(\ell-1)
options for the vertex of the independent set coming from
\displaystyle e_{k}

It follows that

\left|{\mathcal{P}}_{n,\ell}^{k,j}(\geq 1,\geq 1)\right|=A(\ell-1)\binom{n-j-2}{k}.

(20)

Finally, we consider
\displaystyle{\mathcal{P}}_{n,\ell}^{k,j}(\geq 1,0)

\displaystyle r=1
and
\displaystyle s=j+1

\displaystyle\binom{n-j-2}{k-1}

As in all previous cases, deciding where among the

2.4
Proofs of (
4
) and (
5
)

In Section
2.2
we derived (
4
) by algebraic manipulation. Such a simple formula should admit a combinatorial explanation (and indeed, as we have observed, there is a very simple combinatorial explanation in the case
\displaystyle\ell=2
).

Here we present a bijection, due to Ferenc Bencs (see Note
1.6
), that directly explains (
4
). Recall that
\displaystyle P_{n,\ell}
has consecutive edges
\displaystyle e_{1},\ldots,e_{n}
. Let

•

\displaystyle v
be the unique vertex in common to
\displaystyle e_{n-1}
and
\displaystyle e_{n}
,

•

\displaystyle v_{1},\ldots,v_{\ell-2}
be the vertices of
\displaystyle e_{n-1}
that are only in
\displaystyle e_{n-1}
,

•

\displaystyle w
be a vertex chosen arbitrarily from
\displaystyle e_{n}\setminus\{v\}
, and

•

\displaystyle w_{1},\ldots,w_{\ell-2}
be the vertices of
\displaystyle e_{n}\setminus\{v,w\}
.

Let
\displaystyle{\mathcal{I}}^{k}_{n,\ell}
be the set of independent sets in
\displaystyle P_{n,\ell}
of size
\displaystyle k
. We partition
\displaystyle{\mathcal{I}}_{n,\ell}
into
\displaystyle 2\ell-2
blocks, falling into four categories (the first two consisting of one block each, the third and fourth consisting of
\displaystyle\ell-2
blocks each):

1.

\displaystyle{\mathcal{A}}^{k}_{n,\ell}
consists of those independent sets in
\displaystyle{\mathcal{I}}^{k}_{n,\ell}
that include
\displaystyle w
(and so necessarily do not include any of
\displaystyle w_{1},\ldots,w_{\ell-2}
or
\displaystyle v
) and include none of
\displaystyle v_{1},\ldots,v_{\ell-2}
. There is a simple bijection from
\displaystyle{\mathcal{A}}^{k}_{n,\ell}
to
\displaystyle{\mathcal{I}}^{k-1}_{n-2,\ell}
, obtained by deleting
\displaystyle w
from an independent set in
\displaystyle{\mathcal{A}}^{k}_{n,\ell}
. It follows that
\displaystyle|{\mathcal{A}}^{k}_{n,\ell}|=p^{k-1}_{n-2,\ell}
.

2.

\displaystyle{\mathcal{B}}^{k}_{n,\ell}
consists of those independent sets in
\displaystyle{\mathcal{I}}^{k}_{n,\ell}
that include none of
\displaystyle w
or
\displaystyle w_{1},\ldots,w_{\ell-2}
. The identity map is a bijection from
\displaystyle{\mathcal{B}}^{k}_{n,\ell}
to
\displaystyle{\mathcal{I}}^{k}_{n-1,\ell}
, so
\displaystyle|{\mathcal{B}}^{k}_{n,\ell}|=p^{k}_{n-1,\ell}
.

3.

For each
\displaystyle i=1,\ldots,\ell-2
,
\displaystyle{\mathcal{C}}^{k}_{n,\ell}(i)
consists of those independent sets in
\displaystyle{\mathcal{I}}^{k}_{n,\ell}
that include
\displaystyle w_{i}
(and so necessarily do not include any of
\displaystyle v,w
or
\displaystyle w_{j}
,
\displaystyle j\neq i
. The identity map is a bijection from
\displaystyle{\mathcal{C}}^{k}_{n,\ell}(i)
to

\{I\in{\mathcal{I}}^{k-1}_{n-1,\ell}:v\not\in I\}.

4.

For each
\displaystyle i=1,\ldots,\ell-2
,
\displaystyle{\mathcal{D}}^{k}_{n,\ell}(i)
consists of those independent sets in
\displaystyle{\mathcal{I}}^{k}_{n,\ell}
that include both
\displaystyle w
and
\displaystyle v_{i}
(and so necessarily do not include any of
\displaystyle v
,
\displaystyle w_{1},\ldots,w_{\ell-2}
, or
\displaystyle v_{j}
,
\displaystyle j\neq i
. There is a simple bijection from
\displaystyle{\mathcal{D}}^{k}_{n,\ell}(i)
to

\{I\in{\mathcal{I}}^{k-1}_{n-1,\ell}:v\in I\},

obtained by deleting
\displaystyle w
and
\displaystyle v_{i}
from an independent set in
\displaystyle{\mathcal{D}}^{k}_{n,\ell}(i)
, and adding
\displaystyle v
.

Combining the observations in points 3 and 4 above we obtain

\left|\cup_{i=1}^{\ell-2}\left({\mathcal{C}}^{k}_{n,\ell}(i)\cup{\mathcal{D}}^{k}_{n,\ell}(i)\right)\right|=(\ell-2)p^{k-1}_{n-1,\ell}.

Combining this with the observations in the points 1 and 2 above we obtain

p^{k}_{n,\ell}=p^{k}_{n-1,\ell}+p^{k-1}_{n-2,\ell}+(\ell-2)p^{k-1}_{n-1,\ell}.

2.5
The independent set sequence of hypercombs and related hypergraphs

We begin by describing the more general setting in which we will work, alluded to just after Note
1.9
. Let
\displaystyle G
be a hypergraph (not necessarily uniform, not necessarily a hypertree) with distinguished vertex
\displaystyle v
. For
\displaystyle\ell\geq 3
, let a sequence
\displaystyle(H_{n,\ell})_{n\geq 0}
of hypergraphs be defined as follows:

•

\displaystyle H_{0,\ell}
consists of a single copy of
\displaystyle G
.

•

\displaystyle H_{1,\ell}
consists of an edge of size
\displaystyle\ell
, together with two disjoint copies of
\displaystyle G

\displaystyle v

•

For
\displaystyle n\geq 2
,
\displaystyle H_{n,\ell}
starts with a copy of
\displaystyle P_{n,\ell}
. Let
\displaystyle w_{0}
be a vertex in
\displaystyle e_{1}\setminus e_{2}

\displaystyle i=1,\ldots,n-1
let
\displaystyle w_{i}
be the vertex in common to
\displaystyle e_{i}
and
\displaystyle e_{i+1}

\displaystyle w_{n}
be a vertex in
\displaystyle e_{n}\setminus e_{n-1}

\displaystyle P_{n,\ell}

\displaystyle n+1

\displaystyle G

\displaystyle G^{0},\ldots,G^{n}

\displaystyle w_{i}

\displaystyle\ell

\displaystyle H_{n,\ell}

\displaystyle C_{n,\ell}
for
\displaystyle n\geq 1

\displaystyle C_{0,\ell}(x)

\displaystyle P_{n,\ell}

In particular this means that

Let

\displaystyle H_{n,\ell}
and
\displaystyle D_{n,\ell}
respectively. Let also

•

\displaystyle G_{0}(x)
be the independence polynomial of
\displaystyle G
,

•

\displaystyle G_{1}(x)
be the independence polynomial of the hypergraph obtained from
\displaystyle G

\displaystyle v
(which reduces by
\displaystyle 1

\displaystyle G

\displaystyle v

•

\displaystyle G_{2}(x)

\displaystyle G

\displaystyle v
and all edges in
\displaystyle G
that include
\displaystyle v
.

We now observe that there are coupled recurrence relations for
\displaystyle H_{n,\ell}(x)
and
\displaystyle D_{n,\ell}(x)

\displaystyle n\geq 1

\displaystyle H_{n,\ell}(x)

\displaystyle\displaystyle H_{n,\ell}(x)

\displaystyle\displaystyle=

\displaystyle\displaystyle G_{1}(x)D_{n,\ell}(x)+xG_{1}(x)G_{2}(x)D_{n-1,\ell}(x)

(25)

\displaystyle\displaystyle=

\displaystyle\displaystyle G_{1}(x)\left(D_{n,\ell}(x)+xG_{2}(x)D_{n-1,\ell}(x)\right)

\displaystyle H_{n,\ell}(x)

(26)

\displaystyle\ell-2

\displaystyle G

\displaystyle n

\displaystyle n-1

\displaystyle\displaystyle D_{n,\ell}(x)+xG_{2}(x)D_{n-1,\ell}(x)

\displaystyle\displaystyle=

\displaystyle\displaystyle H_{n-1,\ell}(x)+x(\ell-2)G_{1}(x)D_{n-1,\ell}(x)

\displaystyle\displaystyle+xG_{2}(x)H_{n-2,\ell}(x)+x^{2}(\ell-2)G_{1}(x)G_{2}(x)D_{n-2,\ell}(x)

\displaystyle\displaystyle(1+(\ell-2)x)H_{n-1,\ell}(x)+xG_{2}(x)H_{n-2,\ell}(x).

In the second equality above we use (

(27)

Noting that when
\displaystyle G

H_{0,\ell}(x)=G_{0}(x)~~~\mbox{and}~~~H_{1,\ell}(x)=G_{0}(x)^{2}-x^{2}G_{2}(x)^{2}+(\ell-2)xG_{1}(x)^{2}.

\displaystyle G

\displaystyle H_{1,\ell}

We now move on to Corollary
1.8
, the partial unimodality of the independent set sequence of
\displaystyle C_{n,\ell}
. Note that the graph obtained from
\displaystyle C_{n,\ell}
by replacing each edge with a clique is not claw-free for
\displaystyle n\geq 2
, so we cannot apply the results of Hamidoune and of Chudnovsky and Seymour that we used for the linear hyperpath.

We work in the general setting of a sequence
\displaystyle(z_{n}(x))_{n\geq 0}
of polynomials with non-negative coefficients defined by the recurrence

z_{n}(x)=a(x)z_{n-1}(x)+b(x)z_{n-2}(x)

for
\displaystyle n\geq 2
, where
\displaystyle a(x),b(x)
are non-negative and non-zero polynomials. Our goal is to establish easy-to-check conditions on
\displaystyle a(x)
,
\displaystyle b(x)
,
\displaystyle z_{0}(x)
and
\displaystyle z_{1}(x)
that imply unimodality of all but a vanishing proportion of the coefficient sequence of
\displaystyle z_{n}(x)
. We briefly sketch the approach here.

•

First we explicitly solve the recurrence, to express
\displaystyle z_{n}(x)
as the sum of two polynomials,
\displaystyle W_{n}(x)
and
\displaystyle Y_{n}(x)
, each of which can be explicitly factored into a product of low-degree polynomials.

•

Assuming that each of these factors is log-concave we conclude that
\displaystyle W_{n}(x)
and
\displaystyle Y_{n}(x)
are log-concave and so unimodal.

•

Viewing
\displaystyle W_{n}
and
\displaystyle Y_{n}
as probability generating functions of discrete distributions we explicitly compute the expectations of
\displaystyle W_{n}
and
\displaystyle Y_{n}
and find that they are (asymptotically) the same.

•

We then appeal to a result of Bottomley, that shows that the expectation and the mode of a unimodal polynomial are (quantifiably) close to each other. We conclude that the modes of
\displaystyle W_{n}
and
\displaystyle Y_{n}
are close to each other.

•

Since the sum of two unimodal polynomials is increasing at least up to the smaller of the two modes, and is decreasing at least from the larger of the two modes on, we conclude that
\displaystyle z_{n}(x)=W_{n}(x)+Z_{n}(x)
is mostly unimodal (specifically, unimodal except possibly between the modes of
\displaystyle W_{n}(x)
and
\displaystyle Y_{n}(x)
).

This scheme leads to a general statement (Theorem
2.3
below) to the effect that if a particular collection of low-degree polynomials is log-concave, then
\displaystyle z_{n}(x)
is mostly unimodal for all
\displaystyle n
. We then apply this general result to the linear uniform hypercomb.

Let us now begin executing the above-described scheme. In the initial part of what follows we draw on the presentation given in
[
26
]
. First note that using standard recurrence relation techniques we have that for
\displaystyle n\geq 2

\displaystyle\displaystyle z_{n}(x)

\displaystyle\displaystyle=

\displaystyle\displaystyle\frac{(z_{1}(x)-z_{0}(x)\mu)\lambda(x)^{n}+(z_{0}(x)\lambda(x)-z_{1}(x))\mu(x)^{n}}{\lambda(x)-\mu(x)}

(28)

\displaystyle\displaystyle=

\displaystyle\displaystyle z_{1}(x)\left(\frac{\lambda(x)^{n}-\mu(x)^{n}}{\lambda(x)-\mu(x)}\right)-z_{0}(x)\lambda(x)\mu(x)\left(\frac{\lambda(x)^{n-1}-\mu(x)^{n-1}}{\lambda(x)-\mu(x)}\right)

where

\lambda(x)=\frac{a(x)+\sqrt{a^{2}(x)+4b(x)}}{2}~~~\mbox{and}~~~\mu(x)=\frac{a(x)-\sqrt{a^{2}(x)+4b(x)}}{2}

or equivalently

\lambda(x)+\mu(x)=a(x)~~~\mbox{and}~~~\lambda(x)\mu(x)=-b(x).

(See e.g.
[

\displaystyle a(x)

\displaystyle b(x)
are non-negative and non-zero we have
\displaystyle a^{2}(x)+4b(x)>0

\displaystyle x>0

\displaystyle\lambda(x)\neq\mu(x)
.

Next (see e.g.
[
2
, Chapter V.19]
), we have the following factorizations for arbitrary
\displaystyle p,q

\displaystyle p\neq q

\frac{p^{n}-q^{n}}{p-q}=\left\{\begin{array}[]{cc}\prod_{s=1}^{(n-1)/2}\left((p+q)^{2}-4pq\cos^{2}\left(\frac{s\pi}{n}\right)\right)&\mbox{if $\displaystyle n\geq 1$ is odd,}\\
(p+q)\prod_{s=1}^{(n-2)/2}\left((p+q)^{2}-4pq\cos^{2}\left(\frac{s\pi}{n}\right)\right)&\mbox{if $\displaystyle n\geq 2$ is even}\end{array}\right.

(here interpreting the empty product to be
\displaystyle 1

Combining this with (

z_{n}(x)=W_{n}(x)+Y_{n}(x)

for
\displaystyle n\geq 2

\displaystyle\displaystyle W_{n}(x)

\displaystyle\displaystyle=

\displaystyle\displaystyle\left\{\begin{array}[]{rl}z_{1}(x)a(x)\prod_{s=1}^{(n-2)/2}\left(a^{2}(x)+4b(x)\cos^{2}\left(\frac{s\pi}{n}\right)\right)&\mbox{if $\displaystyle n$ is even,}\\
z_{1}(x)\prod_{s=1}^{(n-1)/2}\left(a^{2}(x)+4b(x)\cos^{2}\left(\frac{s\pi}{n}\right)\right)&\mbox{if $\displaystyle n$ is odd}\end{array}\right.

and

\displaystyle\displaystyle Y_{n}(x)

\displaystyle\displaystyle=

\displaystyle\displaystyle\left\{\begin{array}[]{rl}z_{0}(x)b(x)\prod_{s=1}^{(n-2)/2}\left(a^{2}(x)+4b(x)\cos^{2}\left(\frac{s\pi}{n-1}\right)\right)&\mbox{if $\displaystyle n$ is even,}\\

Let us now assume that each of the following polynomials:

have log-concave coefficient sequences. Using the standard fact that the log-concavity of coefficient sequences of polynomials is preserved under multiplication (see e.g.
[

\displaystyle W_{n}(x)

\displaystyle Y_{n}(x)

Let
\displaystyle mw_{n}
be a mode of
\displaystyle W_{n}(x)
. That is, let
\displaystyle mw_{n}
be an integer satisfying that the coefficient sequence of
\displaystyle W_{n}(x)
is weakly increasing up to (and including) the coefficient of
\displaystyle x^{mw_{n}}
and is weakly decreasing starting from the coefficient of
\displaystyle x^{mw_{n}}
. Let
\displaystyle my_{n}
be a mode of
\displaystyle Y_{n}(x)
. Evidently the coefficient sequence of
\displaystyle z_{n}(x)
is weakly increasing at least up to the coefficient of
\displaystyle x^{\min\{mw_{n},my_{n}\}}
, and it is weakly decreasing at least from the coefficient of
\displaystyle x^{\max\{mw_{n},my_{n}\}}
on. So the smaller we can make
\displaystyle|mw_{n}-my_{n}|
, the closer we get to concluding unimodality of the coefficient sequence of
\displaystyle z_{n}(x)
.

Let us focus first on estimating
\displaystyle mw_{n}
in the case where
\displaystyle n
is even. Because
\displaystyle W_{n}(x)
is a non-negative and non-zero polynomial we may view
\displaystyle W_{n}(x)/W_{n}(1)
as the probability generating function of a discrete probability distribution
\displaystyle X_{n}
, supported on a finite subset of the natural numbers. In light of the factorization we have found for
\displaystyle W_{n}(x)
we see that

X_{n}=X_{n}^{0}+\sum_{s=1}^{(n-2)/2}X_{n}^{s}

where
\displaystyle X_{n}^{0}
has probability generating function
\displaystyle z_{1}(x)a(x)/(z_{1}(1)a(1))
,
\displaystyle X_{n}^{s}
has probability generating function
\displaystyle(a^{2}(x)+4b(x)\cos^{2}(s\pi/n))/((a^{2}(1)+4b(1)\cos^{2}(s\pi/n)))
for each
\displaystyle s
, and the
\displaystyle X_{n}^{i}
’s are independent.

We now use that if a distribution
\displaystyle X
has probability generating function
\displaystyle P_{X}(x)
then its expectation is given by
\displaystyle E(X)=P^{\prime}_{X}(x)|_{x=1}
, where
′
indicates derivative with respect to
\displaystyle x
. So

E(X_{n}^{0})=\frac{(z_{1}(x)a(x))^{\prime}|_{x=1}}{z_{1}(1)a(1)}:=c_{0}

and for
\displaystyle s\geq 1

E(X_{n}^{s})=\frac{c_{1}+c_{2}\cos^{2}(s\pi/n)}{c_{3}+c_{4}\cos^{2}(s\pi/n)}

where the
\displaystyle c_{i}
’s are constants that can be explicitly calculated from
\displaystyle a(x)
,
\displaystyle b(x)
and (in the case of
\displaystyle c_{0}
)
\displaystyle z_{1}(x)
, with
\displaystyle c_{3},c_{4}\neq 0
. It follows that

E(X_{n})=c_{0}+\sum_{s=1}^{(n-2)/2}\frac{c_{1}+c_{2}\cos^{2}(s\pi/n)}{c_{3}+c_{4}\cos^{2}(s\pi/n)}.

(35)

We estimate the sum in (
35
) using an integral. Setting
\displaystyle m=(n-2)/2
we have

\sum_{s=1}^{(n-2)/2}\frac{c_{1}+c_{2}\cos^{2}(s\pi/n)}{c_{3}+c_{4}\cos^{2}(s\pi/n)}=m\sum_{s=1}^{m}\frac{1}{m}\left(\frac{c_{1}+c_{2}\cos^{2}((2s/(2m+2))(\pi/2))}{c_{3}+c_{4}\cos^{2}((2s/(2m+2))(\pi/2))}\right).

(36)

Observing that

\frac{s-1}{m}\leq\frac{2s}{2m+2}\leq\frac{s}{m}

(37)

(the latter is always true, the former is true for
\displaystyle s\leq m+1
) we see that the summation on the right-hand side of (
36
) is a Riemann sum estimate for
\displaystyle\int_{0}^{1}f(t)~dt
where

f(t)=\frac{c_{1}+c_{2}\cos^{2}(t\pi/2)}{c_{3}+c_{4}\cos^{2}(t\pi/2)}.

Since
\displaystyle f^{\prime}(t)
is bounded above and below on the interval
\displaystyle[0,1]
by a constant depending on
\displaystyle c_{1}
,
\displaystyle c_{2}
,
\displaystyle c_{3}
and
\displaystyle c_{4}
, using standard Riemann sum error estimates we get

\sum_{s=1}^{m}\frac{1}{m}\left(\frac{c_{1}+c_{2}\cos^{2}((2s/(2m+2))(\pi/2))}{c_{3}+c_{4}\cos^{2}((2s/(2m+2))(\pi/2))}\right)=\int_{0}^{1}f(t)~dt\pm\frac{c_{5}}{m}

where
\displaystyle c_{5}
is a constant depending
\displaystyle c_{1}
,
\displaystyle c_{2}
,
\displaystyle c_{3}
and
\displaystyle c_{4}
. (Here we use the notation
\displaystyle A=B\pm C
as shorthand for
\displaystyle|A-B|\leq C
.) Returning to (
35
) and using that
\displaystyle m=n/2+O(1)
we conclude that (for even
\displaystyle n
) there is a constant
\displaystyle K
(depending only on
\displaystyle a(x)
,
\displaystyle b(x)
) such that

E(X_{n})=Kn+O(1),

where the implicit constant in the
\displaystyle O(1)
depends on
\displaystyle a(x)
,
\displaystyle b(x)
and
\displaystyle z_{1}(x)
. Specifically we have

K=\frac{1}{2}\int_{0}^{1}\left(\frac{c_{1}+c_{2}\cos^{2}(t\pi/2)}{c_{3}+c_{4}\cos^{2}(t\pi/2)}\right)dt.

Next we estimate the variance of
\displaystyle X_{n}
. By independence of the
\displaystyle X_{n}^{i}
’s we have

{\rm Var}(X_{n})={\rm Var}(X_{n}^{0})+\sum_{s=1}^{(n-2)/2}{\rm Var}(X_{n}^{s}).

We now use that if a distribution
\displaystyle X
has probability generating function
\displaystyle P_{X}(x)
then

{\rm Var}(X)=P^{\prime\prime}_{X}(x)|_{x=1}+P^{\prime}_{X}(x)|_{x=1}-(P^{\prime}_{X}(x)|_{x=1})^{2}.

From this it is immediate that
\displaystyle{\rm Var}(X_{n}^{0})
is a constant (depending on
\displaystyle a(x)
,
\displaystyle b(x)
and
\displaystyle z_{1}(x)
), and that for
\displaystyle s\geq 1

\displaystyle{\rm Var}(X_{n}^{s})
can be bounded above and below by constants independent of
\displaystyle s
(depending only on
\displaystyle a(x)
and
\displaystyle b(x)
). It follows that
\displaystyle\sigma(X_{n})
, the standard deviation of
\displaystyle X_{n}
, satisfies

\sigma(X_{n})\leq O(\sqrt{n})

where the implicit constant in the
\displaystyle O(\sqrt{n})
depends only on
\displaystyle a(x)
and
\displaystyle b(x)
.

We now appeal to a result of Bottomley
[
7
]
.

Theorem 2.2
.

Let
\displaystyle X
be a discrete probability distribution supported on the integers, that is unimodal in the sense that there is an integer
\displaystyle m(X)
(not necessarily unique) with
\displaystyle P(X=i-1)\leq P(X=i)
for all
\displaystyle i\leq m(X)
and
\displaystyle P(X=i)\geq P(X=i+1)
for all
\displaystyle i\geq m(X)
. If
\displaystyle X
has finite expectation
\displaystyle E(X)
and finite standard deviation
\displaystyle\sigma(X)
then

\left|E(X)-m(X)\right|\leq\sqrt{3}\sigma(X).

This may be viewed as an extension to arbitrary polynomials of a weak form of Darroch’s theorem
[
12
]
, which recall says that if
\displaystyle X
is finitely supported on the natural numbers and if furthermore the probability generating polynomial of
\displaystyle X
has all real roots (a stronger condition than unimodality) then
\displaystyle\left|E(X)-m(X)\right|\leq 1
.

Applying Theorem
2.2
to
\displaystyle X_{n}
(when
\displaystyle n
is even) we conclude that

\left|mw_{n}-Kn\right|\leq O(\sqrt{n}),

(38)

where the implicit constant in the
\displaystyle O(\sqrt{n})
depends only on
\displaystyle a(x)
and
\displaystyle b(x)
.

We can do an almost identical analysis for
\displaystyle Y_{n}
when
\displaystyle n
is even. In this case we still set
\displaystyle m=(n-2)/2
to get the analog of (
36
). To confirm that the summation on the right-hand side of the analog of (
36
) is still a Riemann sum estimate for
\displaystyle\int_{0}^{1}f(t)~dt
, we need to check an analog of (
37
), namely

\frac{s-1}{m}\leq\frac{2s}{2m+1}\leq\frac{s}{m}.

We conclude (routine analysis, very similar to that used in the derivation of (
38
), omitted) that

\left|my_{n}-Kn\right|\leq O(\sqrt{n})

(39)

for (crucially) the same constant
\displaystyle K
as in (
38
); and running through the analysis for
\displaystyle n
odd we find that (
38
) and (
39
) both hold for odd
\displaystyle n
, again with the same constant
\displaystyle K
. We conclude that the modes of
\displaystyle Y_{n}
and
\displaystyle W_{n}
differ by at most
\displaystyle O(\sqrt{n})
, and so the coefficient sequence of
\displaystyle z_{n}(x)
is unimodal except (possibly) for a
\displaystyle O(\sqrt{n})
portion around the
\displaystyle[Kn]
th term.

We summarize all of this in a theorem.

Theorem 2.3
.

Let
\displaystyle a(x)
and
\displaystyle b(x)
be polynomials with non-negative coefficients, each with at least one positive coefficient. Let
\displaystyle z_{0}(x)
and
\displaystyle z_{1}(x)
be polynomials with non-negative coefficients. For
\displaystyle n\geq 2
let the polynomial
\displaystyle z_{n}(x)
be defined by the recurrence

z_{n}(x)=a(x)z_{n-1}(x)+b(x)z_{n-2}(x).

Suppose that the coefficient sequences of each of
\displaystyle a(x)
,
\displaystyle b(x)
,
\displaystyle z_{0}(x)
and
\displaystyle z_{1}(x)
are log-concave, and also that the coefficient sequence of
\displaystyle a^{2}(x)+4b(x)y
is log-concave for all choices of
\displaystyle y\in[0,1]
. Then there are constants
\displaystyle K>0
and
\displaystyle L>0
, both depending only the coefficients of
\displaystyle a(x)
and
\displaystyle b(x)
, such that for all
\displaystyle n
the coefficient sequence of
\displaystyle z_{n}(x)
is

•

weakly increasing up to the coefficient of
\displaystyle x^{[Kn-L\sqrt{n}]}
and

•

weakly decreasing from the coefficient of
\displaystyle x^{[Kn+L\sqrt{n}]}
on.

Note 2.4
.

We can strengthen Theorem
2.3
very slightly by observing that we do not need
\displaystyle W_{n}(x)
and
\displaystyle Y_{n}(x)
to be log-concave, just unimodal, and then using the fact that the product of a unimodal polynomial and a log-concave polynomial is unimodal. So we can allow up to one of the factors in each of the four factorizations in (
2.5
), (
2.5
) to be unimodal but not necessarily log-concave, without changing the conclusion of the theorem.

We now apply Theorem
2.3
to the independent set sequence of the family of linear hypercombs, in order to prove Corollary
1.8
. In this case we have

a(x)=(1+(\ell-1)x)(1+(\ell-2)x),

b(x)=x(1+(\ell-1)x)

and

z_{0}(x)=C_{0,\ell}(x)=1+\ell x,

all three of which are easily seen to have log-concave independent set sequences for all
\displaystyle\ell
(for
\displaystyle a(x)
and
\displaystyle b(x)
we can use that log-concavity is preserved under multiplication, and that linear polynomials are trivially log-concave; for
\displaystyle z_{0}(x)
we need only use this second fact). We have

z_{1}(x)=C_{0,\ell}(x)=1+(3\ell-2)x+(2(\ell-1)(\ell-2)+(\ell-1)^{2}+2(\ell-1))x^{2}+(\ell-1)^{2}(\ell-2)x^{3}.

The two log-concavity relations that need to be checked here reduce to

6\ell^{2}-6\ell+1\geq 0

and

6\ell^{4}-22\ell^{3}+31\ell^{2}-20\ell+5\geq 0,

both of which are easily checked to hold for
\displaystyle\ell\geq 3
. Finally we have

a^{2}(x)+4b(x)y=(1+(\ell-1)x)(1+(3\ell-5+4y)x+(3\ell^{2}-10\ell+8)x^{2}+(\ell^{3}-5\ell^{2}+8\ell-4)x^{3}).

The first factor trivially has log-concave coefficient sequence. There are two relations that need to be checked to verify that the second factor has log-concave coefficient sequence, and these simplify to

6\ell^{2}-(20-24y)\ell++(17-40y)\geq 0

and

6\ell^{4}-(40+4y)\ell^{3}+(99+20y)\ell^{2}-(108+32y)\ell+(44+16y)\geq 0.

We appeal to
Mathematica
to minimize the left-hand side of both inequalities over
\displaystyle\ell\in[3,\infty]
and
\displaystyle y\in[0,1]
and see that the minima are both positive, but this could in principle also be done by hand.

The conditions of Theorem
2.3
having been verified, we conclude that for each
\displaystyle\ell\geq 3
there are constants
\displaystyle K_{\ell},L_{\ell}>0
such that the independent set sequence of the
\displaystyle\ell
-uniform linear hypercomb built on an
\displaystyle n
-edge spine is weakly increasing up to
\displaystyle K_{\ell}n-L_{\ell}\sqrt{n}
and weakly decreasing from
\displaystyle K_{\ell}n+L_{\ell}\sqrt{n}
, as asserted in Corollary
1.8
.
