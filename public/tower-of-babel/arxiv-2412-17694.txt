An efficient volume-preserving MBO scheme for data clustering and classification
Fabius Krämer, Tim Laux

Abstract
. We propose and study a novel efficient algorithm for clustering and classification tasks based on the famous MBO scheme. On the one hand, inspired by Jacobs et al. [J. Comp. Phys. 2018], we introduce constraints on the size of clusters leading to a linear integer problem. We prove that the solution to this problem is induced by a novel order statistic. This viewpoint allows us to develop exact and highly efficient algorithms to solve such constrained integer problems. On the other hand, we prove an estimate of the computational complexity of our scheme, which is better than any available provable bounds for the state of the art. This rigorous analysis is based on a variational viewpoint that connects this scheme to volume-preserving mean curvature flow in the big data and small time-step limit. Keywords: Clustering, Classification, semi-supervised learning, mean curvature flow, gradient flows. Mathematical Subject Classification (MSC2020) : 68Q25; 90C10; 53E10 (Primary); 58J35; 53Z50; 49Q20; 49Q05 (Secondary).



1.
Introduction

1.1.
Motivation

Many modern machine learning methods, such as classification via neural networks, rely on large amounts of labeled data.
However, for many applications, only little information is known about the data:
Only a few data are labeled, or only average information, such as the rough size of each class, is known.
Therefore, it is crucial to develop efficient methods that do not require many or any labeled data at all.
In this semi- or unsupervised learning regime, it is paramount to understand and exploit the geometry of the whole data cloud.
A successful avenue for this is graph-based learning, which equips the dataset with a graph structure by connecting data points according to some similarity measure.
Then, one aims to partition this similarity graph into clusters so that only few edges lead from one cluster to another while many edges connect points within each cluster
[
52
]
.

Finding these minimal cuts (with hard or soft constraints on the sizes of clusters) in large graphs gives rise to NP-hard problems
[
52
]
.
Therefore, efficient algorithms are needed that solve these problems approximately.
One of the most efficient methods to do this is the MBO scheme, which translates the original scheme of Merriman, Bence, and Osher
[
37
,
36
]
to the setting of graphs.
It was proposed by Bertozzi et al.
[
35
,
15
,
49
]
and has received continuous attention since then, see e.g.
[
19
,
20
]
.
The scheme uses the geometry of the dataset to improve an initial guess for a clustering or classification task (for example starting from random assignments or linear methods such as k-Means) by propagating label information from nearby data points.
More precisely, it iteratively improves this guess by alternating between linear diffusion of the labels and pointwise thresholding.
One drawback is that clusters may shrink or even disappear.

In the present paper, we propose a
provably efficient
and
exact
method to extend the MBO scheme to the case of volume constraints which in particular prevent this shrinkage.
The key algorithmic challenge is that the trivial thresholding step must be replaced by a linear integer program.
Our main contributions are (a) the development of efficient algorithms for a class of such linear integer programs and (b) a novel efficiency analysis that rigorously proves the observed speed-up of these algorithms in the volume-constrained MBO scheme.
Our complexity estimate relies on the variational structure of the algorithm as a minimizing movements scheme for Volume-Preserving Mean Curvature Flow.

1.2.
Our New Algorithm

The volume-preserving MBO scheme alternates between linear diffusion and pointwise thresholding, now at threshold values that are to be determined: Given an initial partition of the point cloud into clusters
X_{N}=\Omega_{1}^{0}\cup\ldots\cup\Omega_{P}^{0}
, diffuse each cluster independently for a short time using the heat semi-group
e^{-t\Delta_{N}}
associated to a graph Laplacian
\Delta_{N}
; then find suitable threshold values that lead to a partition of the same volumes.
More precisely, given a time-step size
h>0
for
\ell=1,2,\ldots

1.

Diffusion:
u^{\ell-1}_{i}:=e^{-h\Delta_{N}}\chi_{\Omega_{i}^{\ell-1}}\quad(1\leq i\leq P)
;

2.

Thresholding:

\Omega_{i}^{\ell}:=\{u^{\ell}_{i}-m^{\ell}_{i}>u^{\ell}_{j}-m^{\ell}_{j}\text{ for all }i\neq j\}
,
where the point
m^{\ell}=(m^{\ell}_{i})_{1\leq i\leq P}
needs to be chosen such that the number of points in each cluster
\#\Omega^{\ell}_{i}=V_{i}
is preserved.

Following Esedoğlu–Otto
[
12
]
and Jacobs–Merkurjev–Esedoğlu
[
20
]
, the second step can be formulated as a linear integer program with constraints:

(1)

\displaystyle\chi^{\ell}\in\argmax_{\chi:X_{N}\rightarrow\{0,1\}^{P}}

\displaystyle\sum_{i=1}^{P}\sum_{x\in X_{N}}\chi_{i}(x)u_{i}(x)

s.t.

\displaystyle\sum_{i=1}^{P}\chi_{i}(x)=1\quad\hskip 3.0pt\text{ for all }x\in X_{N},

\displaystyle\!\!\sum_{x\in X_{N}}\!\!\chi_{i}(x)=V_{i}\quad\text{ for all }i=1,\dots,P,

where
u=u^{\ell-1}
is given by Step 1. Jacobs–Merkurjev–Esedoğlu
[
20
]
interpret this optimization problem as an auction in which each cluster bids for data points; then they apply a black-box auction algorithm by Bertsekas
[
3
]
to solve this assignment problem approximately.

We propose a new algorithm for solving (
1

u^{\ell-1}
in the MBO scheme.
Our new algorithm (Algorithm
1

1

3
and Theorem
6

We present several approximations for computing the diffusion step and point out a family of sparse matrices for which the computational complexity of the matrix-vector multiplication matches the one of our algorithm for (
1

Although our algorithm was designed for the specific situation of the MBO scheme, it also performs very well on arbitrary data distributions
u
.
In particular, the extension to inequality constraints

(2)

\displaystyle\chi^{\ell}\in\argmax_{\chi:X_{N}\rightarrow\{0,1\}^{P}}

\displaystyle\sum_{i=1}^{P}\sum_{x\in X_{N}}\chi_{i}(x)u_{i}(x)

s.t.

\displaystyle\sum_{i=1}^{P}\chi_{i}(x)=1\quad\hskip 3.0pt\text{for all }x\in X_{N},

\displaystyle\hskip 20.5ptL_{i}\leq

\displaystyle\!\!\sum_{x\in X_{N}}\!\!\chi_{i}(x)\leq U_{i}\quad\text{for all }i=1,\dots,P.

O(N\log N)
for any given

while the state of the art needs
O(N^{2})
operations
[
20
]
.

A first intersting insight already appears in the scalar case when the dataset is partitioned into only two clusters, say, of equal size:
This is commonly done by sorting the points according to their diffused label value (e.g. using quick sort) at a cost of
\mathcal{O}(N\log N)
for
N
data points.
After this sorting procedure, the first half of the data points are assigned to the first cluster and the second half to the second one.
We claim that this whole procedure can be replaced by one that only needs
\mathcal{O}(N)
operations.
Indeed, it is sufficient to simply find the median of the diffused label values and then point-by-point threshold at this value.
Both steps, the median finding and the thresholding now only take
\mathcal{O}(N)
operations. Of course, the vectorial case is much more delicate, but the geometric interpretation of
m
as a vectorial median turns out to be an effective guiding principle for this task.

To describe our new algorithm, let us first focus on the simplest nontrivial case of three clusters and exactly prescribed sizes of the clusters (as opposed to more intricate inequality constraints described later, see Algorithm
1
) and that all clusters should be of equal size (which can easily be adapted to arbitrary assigned sizes).
In this case it is instructive to picture the standard simplex
\Sigma=\mathrm{conv}(e_{1},e_{2},e_{3})
in
\mathbb{R}^{3}
and think of each vertex representing one cluster.
(Indeed, this is precisely the image of the vector field of indicator functions
(\chi_{1},\chi_{2},\chi_{3})
.)
During the diffusion, the labels
u(x,t)=(e^{-t\Delta}\chi_{1}(x),e^{-t\Delta}\chi_{2}(x),e^{-t\Delta}\chi_{3}(x))
move away from the vertices towards the interior of the simplex, see Fig.
1
.
Now, after a short time
h
, we want to find a point
m
in
\Sigma
which is a vectorial median of the diffused vectorial labels
\{u(x,h)\colon x\in X\}
in the sense that the
Y
-shaped union of line segments through
m
in Fig.
3(b)
below divides the simplex
\Sigma
into three parts, each containing the same amount of points.
This can be achieved by the following iterative combinatorial process based on an elementary geometric intuition.

Starting from an initial guess for
m
for which, say, the first cluster is too small,
we want to move
m
in order to increase the size of this cluster.
As
m
passes points of a cluster with too many points, we simply move
m
past those points so that these points are now counted towards the previously too-small first cluster.
However, if
m
passes a point
u(x)
, say, in the second cluster and that cluster does not have too many points assigned to it, we do not want to reassign points between these two clusters as this may result in an endless loop of reassigning points.
Instead, we stop
m
here and move it into a different direction that leaves this point exactly at the border between Clusters 1 and 2.
We continue to move
m
until we hit a point of the third cluster.
As we only have three clusters, we know that Cluster 3 has too many points and will gladly give the point at the border to either Cluster 1 or 2, whoever is on the other side of the border.
In case this is Cluster 1, we achieved our goal: We increased the size of Cluster 1 by one data point without decreasing any other too-small cluster.
In case Cluster 2 is on the other side of this data point, we make a three-way swap: Cluster 3 gives the data point on its border to Cluster 2 which in turn gives the data point on its border to Cluster 1.
Iterating until all clusters have equal size gives us an
m
at which we can threshold and preserve the volume of each cluster.
Just as in the scalar case, this point
m
can be viewed as some sort of vectorial median of the diffused labels of the data points.

1.3.
Estimating the Computational Complexity Via Gradient Flow Techniques

Figure 1
.

e_{1},e_{2},e_{3}

This new simple algorithm is surprisingly efficient. One can easily see that it terminates in
\mathcal{O}(N\log N)
operations. Furthermore, we will prove that we only need
\mathcal{O}(\sqrt{h}N\log N)
operations to find the median
m
when starting the median search in the MBO scheme from the center of the simplex or from the median of the previous step, in a typical step.
The idea is that in case of the MBO scheme, most label values will remain close to the pure cluster points
e_{1},e_{2},e_{3}
and only few data points lay close the decision boundary and need to be considered in the above loop (see Fig.
1
).
Here,
\sqrt{h}
corresponds to the width of the heat kernel.
We show this rigorously for sufficiently large point clouds under the so-called manifold assumption stating that the data points are distributed according to some probability measure supported on some manifold.
Under these assumptions, it is known that in the large-data limit the unconstrained MBO scheme behaves like its natural mean-field limit—the MBO scheme on a weighted manifold
[
26
,
27
,
48
]
.
We will see easily that this is also true in the case of our volume-constrained MBO scheme.
Our rigorous proof of the speed-up by the factor
\sqrt{h}
then consists of three steps.

1.

We prove that in a typical iteration, the vectorial median of the mean-field MBO scheme is
\sqrt{h}
close to the center of the simplex. This is the most technical part of our proof and requires a careful
L^{2}
estimate of the Lagrange multiplier of the minimizing movements.

2.

We show that the discrete medians converge to their mean-field counterparts in the large-data limit. This follows from a careful analysis of the variational interpretation of our vectorial median, see Section
4.2
.

3.

Finally, we prove that since by
1
. and
2
., in a typical iteration, the discrete vectorial median is
\sqrt{h}
-close to the center of the simplex, the running time of the median find algorithm is sped up by the factor
\sqrt{h}
.

The analytically most challenging part is the
L^{2}
-estimate in Step
1
.
This result in particular generalizes previous work of Swartz and one of the authors
[
31
]
to (a) the vectorial case and (b) the case of (weighted) manifolds.
We are convinced that the techniques developed here will also lead to a convergence proof of the volume-preserving MBO scheme and the vectorial MBO scheme on weighted manifolds, which are both still open questions.

The efficiency of our median find algorithm gives rise to the question of whether the diffusion step can be carried out more efficiently so that both complexities are balanced.
The most efficient version we find is an approximation of the diffusion semi-group by a sparse matrix.
In addition, we show that the difference between two consecutive time steps of the scheme is sparse.
All in all, this turns the diffusion step into the multiplication of an
N\log N
-sparse
(N\times N)
-matrix with an
\varepsilon N
-sparse
N
-vector (where
\varepsilon
is the length scale in constructing the similarity graph). This can be carried out at the cost of
\mathcal{O}(\varepsilon N\log N)
, matching the cost of our median find algorithm when using the classical parabolic scaling regime
\varepsilon\sim\sqrt{h}
.
The
\varepsilon N
-sparsity of the increment is the result of an a-priori estimate and a simple interpolation, see Lemma
15
which is inspired by
[
28
]
.

1.4.
Context

The scheme and our results have connections to different seemingly disconnected communities. There is a lot of literature that connects the MBO scheme with graph learning and data science tasks.
The first to introduce the MBO scheme on graphs were Bertozzi et al.
[
35
,
15
,
34
]
where they used the scheme also for imaging tasks. Afterwards there have been several papers that modified the scheme like Jacobs
[
19
]
to a wide range of diffusion kernels, Jacobs-Merkurjev-Esedoglu
[
20
]
to volume constraints, and Calder-Cook-Thorpe-Slepčev PoissonMBO
[
7
]
making a connection to the Poisson equation and a different approach to impose volume constraints.
We also note that the influential work on diffusion maps by Coifman and Lafon et al.
[
9
,
46
,
10
]
already introduced a one-step version of the MBO scheme for classification in which the thresholding step is interpreted as a maximum a posteriori estimator; our algorithm can also be used in their context to preserve the sizes of classes.

Recently, there has also been a rising development in Big Data limits. This started with García Trillos and Slepčev who introduced the
TL^{p}
metric as framework for comparing discrete with continuous schemes.
\Gamma
-convergence of the thresholding energies, via the weak
TL^{2}
topology as first done by

]
, is also one of the building blocks to show our mean field limit of the scheme. To the best of our knowledge the present work is the first to use information on the Big Data limit to obtain a computational complexity estimate.

We want to point out that our volume constrained MBO scheme also has a less obvious connection to the well established method of spectral clustering
[

]
.
Indeed, writing the heat semigroup applied to some vector

For three phases with volumes

In the connection to spectral clustering above the limit

But to recover Volume-Preserving Mean Curvature Flow as the limit

Volume-Preserving Mean Curvature Flow first appeared in the differential geometry literature:

The New Algorithm

The main idea behind the new algorithm is a geometric interpretation of the linear integer problem (

For a given finite set

2.3.
Efficiency Analysis

For the running time analysis one observes that in every iteration (lines 2 to 17) of Algorithm
1
the energy (
7
) reduces by two. Thereby the asymptotic running time is given by
\frac{E(m)}{2}\cdot\mathcal{O}((\log(N)+P)P^{2})
where
m
is the initial guess for the order statistic. A priori one only has the worst case estimate
E(m)\leq N
. Our goal is to find a good initial guess that leads to a better estimate of
E(m)
.

So what is a good initial guess for
m
? This depends on the distribution of the data
\{u(x)\}_{x\in X_{N}}
. In our case the data is given by the MBO scheme, or more precisely by the convolution of the heat kernel
p(h,x,y)
with the characteristic function
\chi
. At least heuristically, the heat kernel only changes the values on a scale
\mathcal{O}(\sqrt{h})
around the interface between the phases given by
\chi
. Thus we expect that also the order statistic moves according to this length scale
\mathcal{O}(\sqrt{h})
which we make rigorous by the following strategy. We interpret the order statistic as a Lagrange multiplier by observing that property (
6
) is equivalent to

\displaystyle\chi^{\ell}\in\argmin_{\chi\in\{0,1\}^{P}}

\displaystyle\sum_{x\in X_{N}}\sum_{i=1}^{P}\chi_{i}(x)(u_{i}(x)+m^{*}_{i})\quad\text{ s.t. }\sum_{i=1}^{P}\ \chi_{i}(x)=1.

By using
u=e^{-h\Delta_{N}}\chi^{\ell-1}
and completing the square as in
[
12
,
31
,
20
]
(see Lemma
8
) it follows that this is equivalent to

\displaystyle\chi^{\ell}\in\argmin_{\chi}E_{h,N}(\chi)+\frac{1}{2h}d_{h,N}^{2}(\chi,\chi^{\ell-1})-\frac{2}{\sqrt{h}}m^{*}\cdot\frac{1}{N}\sum_{x\in X_{N}}\chi(x),

where
E_{h,N}
and
d_{h,N}
are the thresholding energy (
62
) and distance (
63
). Thus
2m^{*}/\sqrt{h}
is the Lagrange multiplier to the minimizing movement interpretation of the MBO scheme. It is hard to estimate the Lagrange multiplier directly in our discrete setting. We therefore take a different approach: Starting with the paper of García Trillos and Slepčev
[
16
]
a lot of big data limits to continuous models have been proven recently. We prove the convergence of the order statistic in this big data limit which yields together with the convergence of the MBO scheme by Lelmi and one of the authors
[
26
]
the convergence of our volume constrained MBO scheme (see Proposition
3
). The clou is that one can use variational techniques that are only available in the continuous setting to prove good bounds for the limiting Lagrange multiplier. To be more precise we improve an
L^{2}
-estimate of the continuous Lagrange multiplier of Swartz and one of the authors
[
31
]
to the multi-phase and spatially inhomogeneous setting (see Proposition
2
). As we are anyways interested in the running time for big
N
we thus can conclude from the convergence and the bound in the continuum that the Lagrange multiplier is also bounded in the discrete setting for big
N
.

To make this idea rigorous some assumptions on the distribution of the data
X_{N}
are necessary. The well established manifold assumption states that
X_{N}
are i.i.d. samples over a low-dimensional Riemannian manifold. This low-dimensionality is justified as data points might live in a high dimensional space but have within a cluster only few degrees of freedom such that they can actually be seen to be in a lower dimensional space. For example an image of a handwritten digit
1
of the MNIST dataset is in
\mathbb{R}^{28\times 28}
but can be roughly seen as a line with only the two parameters of length and angle. One also assumes that similarity between datapoints is expressed by the extrinsic Euclidean distance between points relative to some length scale
\varepsilon>0
. The exact assumptions are given in Assumption
1
. We can then answer the question of the choice of the initial guess
m^{0}
by stating a running time improvement of the factor
\sqrt{h}
if the initial guess is chosen as result of the previous iteration or as multiple of the vector
\mathbbold{1}
with only
1
s as entries:

Theorem

(Informal version of Theorem
6
)
.

Under the manifold assumption there is a scaling regime

\displaystyle h\ll 1,\quad N\gg 1,\quad\varepsilon\ll 1,

such that in a typical iteration of the volume constrained MBO scheme, the computational complexity of Algorithm
1
is

\displaystyle O(\sqrt{h}\,N\log N)

when starting from the center
m^{0}=\frac{1}{P}\mathbbold{1}
or the previous order statistic
m^{0}=m_{N}^{\ell-1}
.

For the above theorem also an assumption on the well preparedness of the initial clusterings is necessary. Out assumption is minimal and states that the initial cuts converge, in the correct topology, to a continuous initial clustering, with finite cut area as the number of data points goes to infinity. This assumption is for example satisfied for the standard initialization with
k
-means or Voronoi cells.

2.4.
Empirical Tests and Comparison to State-of-the-Art

In practice, the computation of the heat semigroup is expensive and thus not feasible for big datasets. We discuss and compare several possibilities to approximate the heat semigroup on graphs which leads to kernels that are cheaper to compute. One kernel will be motivated by Lelmi and one of the authors
[
27
]
where they show that one only needs the first
\log^{q}N
many summands for some scalar
q>0
in the spectral decomposition of the heat kernel (
3
) to get convergence of the MBO scheme to Mean Curvature Flow. The other type of approximations are connected to Taylor expansions of the exponential function. They have the advantage of being sparse which leads to fast computation. One can even improve this with a neat little trick by computing for an arbitrary approximation
A
of the heat semigroup the product with
\chi^{\ell}
by

\displaystyle A\chi^{\ell}=A(\chi^{\ell}-\chi^{\ell-1})+A\chi^{\ell-1}.

This is of interest as
A\chi^{\ell-1}
can be stored from the previous iteration and
A(\chi^{\ell}-\chi^{\ell-1})
can be computed more efficiently as
\chi^{\ell}-\chi^{\ell-1}
is sparse by our Lemma
15
.

Our results on three common datasets for semi supervised learning show that there is not the one approximation that is overall preferable but they all have there pros and cons on the different datasets. Our results support the choice of
[
20
]
where they used the squared weight matrix as approximation. We also compare briefly the results to other graph learning methods which shows that our method is comparable in accuracy while being computationally very efficient.

The rest of the paper is now structured as follows. Section
3
proves the correctness and running time of Algorithm
1
and Algorithm
2
which is done by showing that the algorithms find the respective order statistic. Section
4
improves then the running time analysis of Algorithm
1
by making connections to the underlying gradient flow structure of the limiting geometric evolution equation. Section
5.2
introduces several approximations of the heat kernel and compares them empirically on three standard datasets.

We first state the exact assumptions under which our results on the efficiency of Algorithm
1
hold.

Assumption 1
.

•

The points
X_{N}:=\{x_{1},\dots,x_{N}\}\subset\mathbb{R}^{D}
are i.i.d. samples of a probability measure
\mu=\rho\Vol_{M}
, with
M
a closed, smooth, connected

-dimensional Riemannian manifold and
\rho
a smooth and positive density. In particular it holds
0<\frac{1}{c}\leq\rho\leq c<\infty
.

•

The weights between points

are given by

w_{\varepsilon}(x,y)=\frac{1}{\varepsilon^{d}}\eta\left(\frac{|x-y|}{\varepsilon}\right).

where the kernel
\eta
satisfies

(34)

\displaystyle\eta(0)>0\text{ and }\eta\text{ is continuous at zero, }

(35)

\displaystyle\eta(t)\geq 0\text{ for every }t>0,\eta\text{ is non-increasing, }

(36)

\displaystyle\eta\text{ has exponential decay }.

•

The sequence of positive numbers
\{\varepsilon_{N}\}_{N}
satisfies

\displaystyle\lim_{N\rightarrow\infty}\varepsilon_{N}=0\text{ and }\lim_{N\rightarrow\infty}\frac{\varepsilon^{d}_{N}N}{\log(N)}=\infty.

•

The sequence of initial clusterings
\chi^{0}_{N}:X_{N}\rightarrow\{0,1\}^{P}
converge weakly in
TL^{2}
to some
\chi^{0}:M\rightarrow\{0,1\}^{P}
, i.e.

\displaystyle\chi^{0}_{N}\xrightharpoonup{TL^{2}}\chi^{0}.

See Definition
4
for more information on
TL^{2}
convergence. Additionally
\chi^{0}
is assumed to have finite perimeter, that is

\displaystyle\sum_{i=1}^{P}\int_{M}\rho\;d|\nabla\chi_{i}^{0}|<\infty.

•

The sequence of prescribed volume
\{V_{N}\}_{N}\subset\mathbb{N}^{P}
with
\sum_{i=1}^{P}V_{N,i}=N
in the volume-constrainted optimization problem (
1
) converges to some
V\in[0,1]^{P}
with
\sum_{i=1}^{P}V_{i}=1
, i.e.,

(37)

\frac{V_{N}}{N}\rightarrow V.

We give some remarks to the assumptions in order

Remark 1
.

•

The assumptions on the distribution of the datapoints in the so called data manifold is often refered to as manifold assumption. It is a reasonable assumption as although the data points are in a very high dimensional space
\mathbb{R}^{D}
the data points that are contain in the same class do not have many degrees of freedom to vary. Image for example a (american) handwritten digit
1
which might be determined only by its length and rotation.

•

The assumptions on the weights are also standard
[
16
,
26
]
. The hidden dimension
d
is for the analysis import but is not needed for computing the weights. For example when the graph Laplacia
\tilde{\Delta}_{N}=I-D^{-1}W
, with diagonal degree matrix
D_{xx}=\sum_{y\in X_{N}}w(x,y)
is used, then the
\frac{1}{\varepsilon^{d}}
factor cancels. For the Laplacian
\Delta_{N}=D-W
one observes that only the heat semigroup
e^{-h\Delta_{N}}
is needed for the computation of the scheme and
\varepsilon^{d}
is only a rescaling of time in the heat semigroup as both
D
and
W
have the prefactor
\frac{1}{\varepsilon^{d}}
.

•

The assumptions on
\varepsilon_{N}
are optimal. The limit
\varepsilon_{N}\rightarrow 0
is necessary to ensure localization in the limit. The condition
\lim_{N\rightarrow\infty}\frac{\varepsilon^{d}_{N}N}{\log(N)}=\infty
is the optimal sampling rate; it roughly says that
\log N
edges are connected to every node. A bigger
\varepsilon
would lead to more edges and thus a bigger computational cost. A smaller
\varepsilon
would yield with high probability a disconnected graph. For more information on the sampling rate see for example
[
16
]
.

•

The weak convergence in
TL^{2}
of the initial conditions is for example given for some
\chi^{0}\in C^{0}(M,\{0,1\}^{P})
and

Our results can also be used to improve the running time analysis of the auction dynamics algorithm presented in

]
. Their auction algorithm finds an approximated solution to the linear program (

in the sense that for a small parameter

for all

and

. From the inequalities (

and

such that
{\sum_{i=1}^{P}m_{i}=0}
and

\displaystyle|\tilde{m}_{i}-m_{i}|\leq C\varepsilon\quad\text{for all }i=1,\dots,P.

Let

denote the approximate order statistic returned by the auction algorithm. Note
\bar{m}
does not necessarily sum to

. To get an improved running time for the auction algorithm it is necessary to bound
\max_{i=1,\dots,P}\bar{m}_{i}
as this yields an upper bound on the number of bets during the algorithm. To be more precise one needs at most
PN\frac{\max_{i=1,\dots,P}\bar{m}_{i}}{\varepsilon}
many bets as at most
N
bets on one phase are necessary to rise the price on the phase by at least

. According to
[
20
]
the running time of one bet is given by

\mathcal{O}\left((\log N+P)PN\frac{\max_{i=1,\dots,P}\bar{m}_{i}}{\varepsilon}\right).

To obtain an upper bound on

we observe that by design of the auction dynamics, the last unassigned point will be assigned to a phase with price

. As all the other prices are non-negative as well we get

. Thus the mean
\frac{1}{P}\sum_{i=1}^{P}\bar{m}_{i}\leq\frac{P-1}{P}\max_{i=1,\dots,P}\bar{m}_{i}

\displaystyle\max_{i=1,\dots,P}\bar{m}_{i}

\displaystyle\leq\max_{i=1,\dots,P}\left(\bar{m}_{i}-\frac{1}{P}\sum_{j=1}^{P}\bar{m}_{j}\right)+\frac{1}{P}\sum_{j=1}^{P}\bar{m}_{j}

\displaystyle\leq\max_{i=1,\dots,P}\left(\bar{m}_{i}-\frac{1}{P}\sum_{j=1}^{P}\bar{m}_{j}\right)+\frac{P-1}{P}\max_{i=1,\dots,P}\bar{m}_{i}

and thus

\displaystyle\max_{i=1,\dots,P}\bar{m}_{i}\leq P\max_{i=1,\dots,P}\left(\bar{m}_{i}-\frac{1}{P}\sum_{j=1}^{P}\bar{m}_{j}\right).

By our previous observations we know that there exists an order statistic

that sums to zero that is
\varepsilon

. This yields a good estimate

\displaystyle\max_{i=1,\dots,P}\bar{m}_{i}\leq P\max_{i=1,\dots,P}m_{i}+\varepsilon PC\leq P|m|_{2}+\varepsilon CP.

By Proposition

together with Proposition

one gets, as in Theorem

where

for

, but

4.2.
Convergence to Continuous order Statistic

For proving convergence of the order statistic we begin by defining the volume constrained MBO scheme and the
V
-order statistic in the continuous setting of a Riemannian manifold. For that we first introduce the weighted Laplace operator on
(M,g,\mu)

Definition 2

(Weighted Laplace operator and heat kernel on Riemannian Manifold)
.

Let
\langle v,w\rangle_{x}:=g_{x}(v,w)
be the inner product on
v,w\in T_{x}M
given by the metric
g
. We use the usual gradient for a smooth function
f\in C^{\infty}(M)
defined uniquely by
\langle\nabla f(x),Y\rangle_{x}=d_{x}f(Y)\ \forall\ Y\in T_{x}M
. Also write
\Gamma(TM)
for the set of all smooth vector fields on
M
. Then the weighted divergence operator
\textup{div}_{\mu}:\Gamma(TM)\rightarrow C^{\infty}(M)
is defined by the duality formula

(52)

\int_{M}\langle\nabla f(x),Y(x)\rangle_{x}\,d\mu(x)=-\int_{M}f(x)\textup{div}_{\mu}Y(x)\,d\mu(x)\quad\text{ for all }Y\in T_{x}M.

Consequently, we define the weighted Laplacian
\Delta_{\mu}:C^{\infty}(M)\rightarrow C^{\infty}(M)
as
\Delta_{\mu}=-\textup{div}_{\mu}\circ\nabla
. All eigenvalues of the operator are non negative by the used sign convention.
On can then show, see
[
17
]
, that there exists a smooth map
p:(0,\infty)\times M\times M\rightarrow\mathbb{R}
such that
the solution
e^{-h\Delta_{\mu}}\chi
to the heat equation

\displaystyle\begin{cases}\frac{d}{dh}u=-\Delta_{\mu}u&\text{ on }M\times(0,T],\\
u(x,0)=\chi(x)&\text{ in }M\end{cases}

can be written as

(53)

e^{-h\Delta_{\mu}}\chi=\int_{M}p(h,x,y)\chi(y)\,d\mu(y).

We call
e^{-h\Delta_{\mu}}
the heat semigroup and
p
the heat kernel of
\Delta_{\mu}
.

The definition of the continuous volume constrained MBO scheme and order statistic is then analogous to the discrete case:

Definition 3

(Continuous volume constrained MBO scheme and order statistic)
.

Let volume fractions
\{V_{i}\}_{i=1}^{P}
with
\sum_{i=1}^{P}V_{i}=1
, a time-step size
h>0
, and initial conditions
\chi^{0}:M\rightarrow\{0,1\}^{P}
with
\sum_{i=1}^{P}\chi_{i}^{0}=1
be given. The volume constrained MBO scheme is defined by the following iterative procedure

(54)

\displaystyle\chi_{i}^{\ell}\in\argmax_{\chi:M\rightarrow\{0,1\}^{P}}

\displaystyle\sum_{i=1}^{P}\int_{M}\chi_{i}(x)u^{\ell-1}_{i}(x)\,d\mu(x)

s.t.

\displaystyle\sum_{i=1}^{P}\chi_{i}(x)=1\quad\hskip 3.0pt\text{ for all }x\in M,

\displaystyle\int_{M}\chi_{i}(x)\,dx=V_{i}\quad\text{ for all }i=1,\dots,P.

Here
u_{i}^{\ell-1}:=e^{-h\Delta_{\mu}}\chi^{\ell-1}_{i}
is the solution to the heat equation with initial condition given by the previous phase
\chi^{\ell-1}_{i}

Lemma 5

(Variational characterization of the order statistic)
.

Given volumes
\{V_{i}\}_{i=1}^{P}
the following two statements are equivalent:

i)

m_{\mu}
is a continuous
V
-order statistic.

ii)

m_{\mu}
is a minimizer of

(57)

F(m):=\int_{M}|u(x)-m|_{\triangle}\,d\mu(x)+V\cdot m,\quad m\in\mathbb{R}^{P}.

The essential idea of the proof is to derive the Euler–Lagrange equation for
F
. One needs to be careful as
\max_{i=1,\dots,P}v_{i}
is not differentiable on the sets
H_{ij}:=\{v\in\mathbb{R}^{P}:v_{i}=v_{j}\geq v_{k}\forall k\neq i,j\}
. Note that those sets may have positive mass under the pushforward measure
u_{\#}\mu
and can thus not be neglected.

But as
F
is a convex functional, techniques from convex analysis can be used to characterize the subdifferential of
F(m)
.

Proof.

We first define the family of linear functionals

\displaystyle F_{\chi}(m):=\sum_{i=1}^{P}\int_{M}(u_{i}(x)-m_{i})\chi_{i}(x)\,d\mu(x),\quad\chi:M\rightarrow\{0,1\}^{P},\sum_{i=1}^{P}\chi_{i}=1\text{ a.e.}

Maximizing
F_{\chi}(m)
over the set of clusterings
\chi
for fixed
m
reduces to a pointwise maximization of
\sum_{i=1}^{P}(u_{i}(x)-m_{i})\chi_{i}(x)
. Thus the maximizers are given by the
m
-induced clusterings (see the definition of
m
-induced cluster (
55
)), i.e.,

\displaystyle\argmax_{\chi:M\rightarrow\{0,1\}^{P},\,\sum_{i=1}^{P}\chi_{i}(x)=1}F_{\chi}(m)=\left\{\chi:\chi\text{ is }m\text{-induced}\right\}.

Also, the maximum value is equal to
F(m)-V\cdot m
:

\displaystyle\max_{\chi:M\rightarrow\{0,1\}^{P},\,\sum_{i=1}^{P}\chi_{i}=1}F_{\chi}(m)=\sum_{i=1}^{P}\int_{M}(u_{i}(x)-m_{i})\chi^{m}_{i}(x)\,d\mu(x)=F(m)-V\cdot m.

So
F(m)=\max_{\chi:M\rightarrow\{0,1\}^{P},\,\sum_{i=1}^{P}\chi_{i}=1}(F_{\chi}(m)+V\cdot m)
is a maximum over affine functions and thus the subdifferential can be calculated by

\displaystyle\partial F(m)

\displaystyle=\textbf{co}\left\{\nabla_{m}\left(F_{\chi}(m)+V\cdot m\right):F_{\chi}(m)=F(m)\right\}

(58)

\displaystyle=\textbf{co}\left\{V-\int_{M}\chi\,d\mu:\chi\text{ is }m\text{-induced}\right\}.

Here
co
denotes the convex hull.

If
i)
holds there is an
m_{\mu}
-induced clustering
\chi^{m_{\mu}}
, i.e.
V=\int_{M}\chi^{m_{\mu}}\,d\mu
. Thus
0\in\partial F(m_{\mu})
from which it follows that
m_{\mu}
is a minimizer of
F(m)
, i.e.
ii)
holds.

Now if
ii)
holds there must be
0\in\partial F(m_{\mu})
. By (
58
), there exists
m
-induced
\{\chi^{(k)}\}_{k=1,\dots,K}
and
\{\lambda^{(k)}\}_{k=1,\dots,K}
with
\sum_{k=1}^{K}\lambda^{(k)}=1
such that

\displaystyle 0=\sum_{k=1}^{K}\lambda^{(k)}\left(V-\int_{M}\chi^{(k)}(x)\,d\mu(x)\right)=V-\int_{M}\sum_{k=1}^{K}\lambda^{(k)}\chi^{(k)}(x)\,d\mu(x).

Thus
\sum_{k=1}^{K}\lambda^{(k)}\chi^{(k)}
has the correct volumes but does not necessarily has values in
\{0,1\}^{P}
. So it remains to prove that we can change
\lambda^{(k)}\chi^{(k)}
to values in
\{0,1\}^{P}
without changing its volumes.

For all

y\in A:=\{x\in M\,|\,\exists i\in\{1,\dots,P\}:\forall j\neq i,u_{i}(x)-{m_{\mu}}_{i}(x)>u_{j}(x)-{m_{\mu}}_{j}(x)\ \}

it already holds
\sum_{k=1}^{K}\lambda^{(k)}\chi^{(k)}(y)=\chi^{(1)}(y)\in\{0,1\}^{P}
as all
\chi^{(k)}
are
m_{\mu}
induced. So we can define the new clustering
\chi^{m_{\mu}}
by
\chi^{m_{\mu}}(y):=\sum_{k=1}^{K}\lambda^{(k)}\chi^{(k)}(y)
for all
y\in A
.

The remaining set
M\setminus A
is now partitioned into

\displaystyle H_{i_{1},\dots,i_{s}}(m_{\mu}):=\left\{u_{i_{1}}(\cdot)-m_{\mu,i_{1}}(\cdot)=\dots=u_{i_{s}}(\cdot)-m_{\mu,i_{s}}(\cdot)>u_{j}(\cdot)-m_{\mu,j}(\cdot)\ \forall j\notin\{i_{1},\dots,i_{s}\}\right\}

for
s=2,\dots,P,\ i_{1},\dots,i_{s}\in\{1,\dots,P\}
pairwise different.
Now define a partition
\chi^{m_{\mu}}\in\{0,1\}^{P}
on every
H_{i_{1},\dots,i_{s}}(m_{\mu})
such that

\displaystyle\int_{H_{i_{1},\dots,i_{s}}(m_{\mu})}\chi^{m_{\mu}}_{j}(x)\,d\mu(x)=\int_{H_{i_{1},\dots,i_{s}}(m_{\mu})}\sum_{k=1}^{K}\lambda^{(k)}\chi^{(k)}_{j}(x)\,d\mu(x)\ \forall j\in\{1,\dots,P\}

holds. This is possible as
\mu
is atomless by assumption and the mass on
H_{i_{1},\dots,i_{s}}(m_{\mu})
is preserved

\displaystyle\sum_{j=1}^{P}\int_{H_{i_{1},\dots,i_{s}}(m_{\mu})}\chi^{m_{\mu}}_{j}(x)\,d\mu(x)

\displaystyle=\mu(H_{i_{1},\dots,i_{s}}(m_{\mu}))

\displaystyle=\sum_{j=1}^{P}\int_{H_{i_{1},\dots,i_{s}}(m_{\mu})}\sum_{k=1}^{K}\lambda^{(k)}\chi^{(k)}_{j}(x)\,d\mu(x),

so that we can set
\chi_{j}^{m_{\mu}}(x)=1\Leftrightarrow x\in A_{j}
on
H_{i_{1},\dots,i_{s}}(m_{\mu})
, where
H_{i_{1},\dots,i_{s}}(m_{\mu})=A_{i_{1}}\dot{\cup}\dots\dot{\cup}A_{i_{s}}
is some partition s.t.
\mu(A_{j})=\int_{H_{i_{1},\dots,i_{s}}(m_{\mu})}\sum_{k=1}^{K}\lambda^{(k)}\chi_{j}^{(k)}
.
This definition directly ensures that the mass of
\chi^{m_{\mu}}
is equal to the mass of
\sum_{k=1}^{K}\lambda^{(k)}\chi^{(k)}
. Thus
\chi^{m_{\mu}}
is a
m_{\mu}
-induced clustering as
\chi^{m_{\mu}}=\chi^{(1)}
on
A
,
\chi^{m_{\mu}}
has the correct mass and
\chi^{m_{\mu}}\in\{0,1\}^{P}
. In a nutshell,
m_{\mu}
is a
V
-order statistic.
∎

Lemma 6

(Variational characterization of the discrete order statistic)
.

Given volumes
V=\{V_{i}\}_{i=1}^{P}
the following two statements are equivalent:

i)

m_{N}\in\mathbb{R}^{P}
is a discrete
V
-order statistic.

ii)

m_{N}\in\mathbb{R}^{P}
is a minimizer of

(59)

F_{N}(m):=\sum_{x\in X_{N}}|u(x)-m|_{\triangle}+V\cdot m.

Proof.

The proof is analogous to the proof of the continuous counterpart, Lemma
5
. The only part that takes some extra effort is to argue that the mass of convex-combinations
\lambda^{(k)}\chi^{(k)}
can be assumed to be an integer on
H_{i_{1},\dots,i_{s}}(m_{N})
. This is necessary as the empirical measure is not atomless any more. We give in the following a quick sketch of this part.

So assume we have a convex combination
\{\lambda^{(k)}\chi^{(k)}\}_{k}
with
\sum_{k=1}^{K}\sum_{x\in X_{N}}\lambda^{(k)}\chi^{(k)}=V
. Partition the edge cases into
H_{i_{1},\dots,i_{s}}(m_{N})
as done in the proof of Lemma
5
. Denote by

\displaystyle\mu_{N,j}(H_{i_{1},\dots,i_{s}}(m_{N})):=\sum_{k=1}^{K}\sum_{x\in X_{N}\cap H_{i_{1},\dots,i_{s}}(m_{N})}\lambda^{(k)}\chi_{j}^{(k)}(x)

the measure of the
j
-th phase on the edge case
H_{i_{1},\dots,i_{s}}(m_{N})
. We observe that

\displaystyle\sum_{j=1}^{P}\mu_{N,j}(H_{i_{1},\dots,i_{s}}(m_{N}))=\#\big(X_{N}\cap H_{i_{1},\dots,i_{s}}(m_{N})\big)

is an integer. Thus, if
\mu_{N,j_{0}}(H_{i_{1},\dots,i_{s}}(m_{N}))
is not an integer then there is a
j_{1}\neq j_{0}
s.t.
\mu_{N,j_{1}}(H_{i_{1},\dots,i_{s}}(m_{N}))
is not an integer either. Denote by

\displaystyle A_{j}:=A_{j}(m_{N}):=\left\{x\in X_{N}:u_{j}(x)-m_{N,j}(x)\geq u_{i}(x)-m_{N,i}\forall i\neq j\right\}

the domain of points that can potentially be assigned to phase
j\in\{1,\dots,P\}
. It also holds

\displaystyle\sum_{k=1}^{K}\sum_{x\in X_{N}\cap A_{j_{1}}}\lambda^{(k)}\chi_{j}^{(k)}(x)=V_{j}

which is an integer. Therefore, there has to be an edge case of
A_{j_{1}}
named
H_{i^{1}_{1},\dots,i^{1}_{s^{1}}}(m_{N})
with
\mu_{N,j_{1}}(H_{i^{1}_{1},\dots,i^{1}_{s^{1}}}(m_{N}))\notin\mathbb{N}
. Repeating this argument inductively one gets a cycle of indices
j_{a},j_{a+1},\dots,j_{b},j_{a}
with edge cases
H_{i^{\ell}_{1},\dots,i^{\ell}_{s^{\ell}}}(m_{N})
between
A_{\ell}
and
A_{\ell+1}
that are not integers. One then performs a circular change of fixed mass such that one of the
\mu_{N,j_{1}}(H_{i^{\ell}_{1},\dots,i^{\ell}_{s^{\ell}}}(m_{N}))
is an integer while the volume constraint
\sum_{x\in X_{N}}\tilde{\chi}=V
for the new phases
\tilde{\chi}
is contained. Thus there is one more edge case with integer mass. Note that it may happen that in the circular change, points have to separate their mass to different phases. This is not an issue, because after inductively applying the whole argument all edge case sets have integer mass such that the mass can be validly reassigned as in the proof of Lemma
5
.
∎

Existence:

converges weakly to
(u,\mu)
in
TL^{p}
if

u_{N}\circ T_{N}
converges to
u
weakly in
L^{2}(\mu)
. Here
T_{N}
denotes a
2
-stagnating transport map as in Proposition
7
.

We recall that the graph Laplacian is given by

(60)

\displaystyle\Delta_{N}u(x)=-\frac{1}{N\varepsilon^{2}_{N}}\sum_{y\in X_{N}}\frac{1}{\varepsilon_{N}^{d}}\eta\left(\frac{\textup{dist}_{M}(x,y)}{\varepsilon_{N}}\right)(u(y)-u(x)).

and the scaling of
\varepsilon_{N}
is given in Assumption
1
.
The convergence result of the heat semigroups of Laux and Lelmi
[
26
, Theorem 2]
with the improvement of
[
48
, Theorem 4.3]
then reads as follows:

Theorem 8

(Weak to strong convergence
[
26
,
48
]
)
.

Let Assumption
1
be in place. If

\displaystyle\chi_{N}\xrightharpoonup{TL^{2}(M,\mu)}\chi\quad\text{ weakly in }TL^{2}\text{ as }N\rightarrow\infty,

then almost surely for every
t>0
the solutions to heat equation converge strongly, i.e.,

\displaystyle e^{-t\Delta_{N}}\chi_{N}\xrightarrow{TL^{2}(M,\mu)}e^{-t\Delta_{\mu}}\chi\quad\text{ strongly in }TL^{2}\text{ as }N\rightarrow\infty.

The convergence of the volume constrained MBO scheme will be proven with the help of Theorem
8
and the minimizing movement interpretation of the MBO scheme. The minimizing movement interpretation was first given by Esedoḡlu and Otto
[
12
]
in the continuous setting and afterwards adapted to the discrete setting by Bertozzi et al.
[
35
]
. This interpretation shows that the volume MBO scheme is a time discretization of a gradient flow of the so-called tresholding energy. The thresholding energy in the continuous setting is given by

(61)

\displaystyle E_{h}(\chi):=\frac{1}{\sqrt{h}}\sum_{i\neq j}\int_{M}\chi_{i}(x)e^{-h\Delta_{\mu}}\chi_{j}(x)\,d\mu(x)

where
e^{-h\Delta_{\mu}}
is the semigroup generated by the Laplace operator
\Delta_{\mu}
on the manifold
(M,g,\mu)
. The metric in the minimizing movement scheme is given by

\displaystyle\frac{1}{2h}d_{h}^{2}(\chi,\tilde{\chi}):=-E_{h}(\chi-\tilde{\chi})=\frac{1}{\sqrt{h}}\sum_{i=1}^{P}\int_{M}(\chi_{i}-\tilde{\chi}_{i})(x)\left(e^{-h\Delta_{\mu}}(\chi_{i}-\tilde{\chi}_{i})\right)(x)\,d\mu(x).

For more information on why this term behaves like a distance see Section 5.3 in
[
12
]
.

The quantities are defined analogously in the discrete setting. The discrete thresholding energy is given by

(62)

\displaystyle E_{N,h}(\chi):=\frac{1}{\sqrt{h}}\sum_{i\neq j}\frac{1}{N}\sum_{x\in X_{N}}\chi_{i}(x)e^{-h\Delta_{N}}\chi_{j}(x)

while the discrete distance term is

(63)

\displaystyle\frac{1}{2h}d_{N,h}^{2}(\chi,\tilde{\chi}):=-E_{N,h}(\chi-\tilde{\chi})=\frac{1}{\sqrt{h}}\sum_{i=1}^{P}\frac{1}{N}\sum_{x\in X_{N}}(\chi_{i}-\tilde{\chi}_{i})(x)\left(e^{-h\Delta_{N}}(\chi_{i}-\tilde{\chi}_{i})\right)(x).

In the minimizing movement interpretation we will also see the role of the order statistic as rescaled Lagrange multiplier.

Lemma 8

(Continuous minimizing movement interpretation)
.

Let
m^{\ell}_{\mu}\in\mathbb{R}^{p}
be the
V
-order statistic for the continuous MBO scheme. Then for the Lagrange multiplier

(64)

\Lambda_{\mu}^{\ell}:=\frac{2}{\sqrt{h}}\left(m_{\mu}^{\ell}-\frac{1}{P}\mathbbold{1}\right)

it holds
\mathbbold{1}\cdot\Lambda_{\mu}^{\ell}=0
and we have the equivalence

(65)

\chi^{\ell}\in\argmin_{\int_{M}\chi\,d\mu=V}E_{h}(\chi)+\frac{1}{2h}d_{h}^{2}(\chi,\chi^{\ell-1})\\

if and only if

(66)

\chi^{\ell}\in\argmin_{\chi}E_{h}(\chi)+\frac{1}{2h}d_{h}^{2}(\chi,\chi^{\ell-1})+\Lambda_{\mu}^{\ell}\cdot\int_{M}\chi\,d\mu.

Proof.

By Definition
3
of the
V
-order statistic,

(67)

\chi^{\ell}\in\argmax_{\chi}\int_{M}\sum_{i=1}^{P}\chi_{i}(u_{i}^{\ell-1}-m_{\mu,i})\,d\mu

fulfills
\int_{M}\chi^{\ell}\,d\mu=V=\int_{M}\chi^{\ell-1}\,d\mu
where as always
u_{i}^{\ell-1}=e^{-h\Delta_{\mu}}\chi_{i}^{\ell-1}
.
By Lemma
7
such an
m_{\mu}^{\ell}
exists and is optimal in the sense that

\displaystyle\chi^{\ell}\in\argmax_{\chi}\int_{M}\sum_{i=1}^{P}\chi_{i}(u_{i}^{\ell-1}-m_{\mu,i}^{\ell})\,d\mu

\displaystyle\Longleftrightarrow

\displaystyle\chi^{\ell}\in\argmax_{\chi}\int_{M}\sum_{i=1}^{P}\chi_{i}u_{i}^{\ell-1}\,d\mu\quad\text{ s.t. }\int_{M}\chi^{\ell}\,d\mu=V=\int_{M}\chi^{\ell-1}\,d\mu

The proof for the optimality of
\chi^{m}
is analogous to the discrete proof of Theorem
1
.
Also note that
m_{\mu}^{\ell}
is optimal in the above sense if and only if
m_{\mu}^{\ell}+c\mathbbold{1}
is optimal with
c\in\mathbb{R}
. We pick
c=\frac{1}{P}
s.t.
\mathbbold{1}\cdot\Lambda_{\mu}^{\ell}=0
holds.
Then the result follows from the computation

\displaystyle E_{h}(\chi)-E_{h}(\chi-\chi^{\ell-1})+\Lambda_{\mu}^{\ell}\cdot\int_{M}\chi\,d\mu

\displaystyle=\frac{2}{\sqrt{h}}\sum_{i\neq j}\int_{M}\chi_{i}e^{-h\Delta_{\mu}}\chi_{j}^{\ell-1}\,d\mu+C+\Lambda_{\mu}^{\ell}\cdot\int_{M}\chi\,d\mu

\displaystyle=\frac{2}{\sqrt{h}}\sum_{i=1}^{P}\int_{M}(1-\chi_{i})e^{-h\Delta_{\mu}}\chi_{i}^{\ell-1}\,d\mu(x)+C+\frac{2}{\sqrt{h}}\left(m_{\mu}^{\ell}-\frac{1}{P}\mathbbold{1}\right)\cdot\int_{M}\chi\,d\mu

\displaystyle=-\frac{2}{\sqrt{h}}\int_{M}\sum_{i=1}^{P}\chi_{i}\left(u_{i}^{\ell-1}-m_{\mu,i}^{\ell}\right)\,d\mu+\tilde{C}.

Here,
C
and
\tilde{C}
denote constants independent of
\chi
.
∎

Lemma 9

(Discrete minimizing movement interpretation)
.

Let
m_{N}^{\ell}\in\mathbb{R}^{p}
be the
\{V_{N,i}\}_{i}
-order statistic for the continuous MBO scheme. Then for the Lagrange multiplier

(68)

\Lambda_{N}^{\ell}:=\frac{2}{\sqrt{h}}\left(m_{N}^{\ell}-\frac{1}{P}\mathbbold{1}\right)

it holds
\mathbbold{1}\cdot\Lambda_{N}^{\ell}=0
and we have the equivalence

(69)

\chi^{\ell}\in\argmin_{\chi}E_{N,h}(\chi)+\frac{1}{2h}d_{N,h}^{2}(\chi,\chi^{\ell-1})\text{ s.t. }\sum_{x\in X_{N}}\chi(x)=\sum_{x\in X_{N}}\chi^{\ell-1}(x)\\

if and only if

(70)

\chi^{\ell}\in\argmin_{\chi}E_{N,h}(\chi)+\frac{1}{2h}d_{N,h}^{2}(\chi,\chi^{\ell-1})+\Lambda_{N}^{\ell}\cdot\frac{1}{N}\sum_{x\in X_{N}}\chi(x).

Proof.

Analogous to the continuous case.
∎

Having done the preparation we are now in the position to prove the main result of the section, namely the convergence of the order statistic and the volume constrained MBO scheme.

Proof of Proposition
3
.

We start by proving the convergence of the order statistic. Remember, the order statistic is the unique minimizer of the continuous energy

\displaystyle F(m)=\int_{M}\max_{i=1,\dots,P}(u_{i}(x)-m_{i})\,d\mu(x)+V\cdot m

by the characterization in Lemma
5
. Therefore, it is enough to show that
F(m_{N})\xrightarrow{N\rightarrow\infty}F(m)
.

For showing the convergence of the order statistic we first notice that the lower bound

\displaystyle 0\leq F(m_{N})-F(m)

always holds as
m
is the minimizer of
F
. To derive a matching upper bound we rewrite

\displaystyle F_{N}(m_{N})

\displaystyle=\sum_{x\in X_{N}}\max_{i=1,\dots,P}(u_{N,i}(x)-m_{N,i})+V_{N}\cdot m_{N}

\displaystyle=N\int_{M}\max_{i=1,\dots,P}(\tilde{u}_{N,i}(x)-m_{N,i})\,d\mu(x)+V_{N}\cdot m_{N}.

Here
\tilde{u}_{N}:=u_{N}\circ T_{N}
where
T_{N}
is an arbitrary
2
-stagnating transport map as described in Theorem
7
. Theorem
8
yields the convergence of
\tilde{u}_{N}
pointwise a.e. for a subsequence to
u
. The subsequence is again denoted by the index
N\in\mathbb{N}
for easier readability. Using
F_{N}(m_{N})\leq F_{N}(m)
(by Lemma
6
) we compute

\displaystyle F(m_{N})-F(m)

\displaystyle=F(m_{N})-\frac{F_{N}(m_{N})}{N}+\frac{F_{N}(m_{N})}{N}-F(m)

\displaystyle\leq F(m_{N})-\frac{F_{N}(m_{N})}{N}+\frac{F_{N}(m)}{N}-F(m)

\displaystyle\leq(|m_{N}|+|m|)\Big|V-\frac{V_{N}}{N}\Big|+\int_{M}\max_{i=1,\dots,P}(u_{N,i}\circ T_{N}-u_{i})\,d\mu

\displaystyle\hskip 118.0pt+\int_{M}\max_{i=1,\dots,P}(u_{i}-u_{N,i}\circ T_{N})\,d\mu.

As the right-hand side goes to zero for
N\rightarrow\infty
(by the dominated convergence theorem), the convergence of the order statistic follows.

Again by Theorem
8
the thresholding energy converges continuously meaning that

\displaystyle E_{N,h}(\chi_{N})\xrightarrow{N\rightarrow\infty}E_{h}(\chi)\quad\text{ as }N\rightarrow\infty.

Together with the convergence of the order statistics it follows that

\displaystyle E_{N,h}(\bullet)+\frac{1}{2h}d^{2}_{N,h}(\bullet,\chi_{N})+\langle\Lambda_{N},\bullet\rangle_{L^{2}(X_{N})}\xrightharpoonup{\Gamma}E_{h}(\bullet)+\frac{1}{2h}d^{2}_{h}(\bullet,\chi)+\langle\Lambda_{\mu},\bullet\rangle_{L^{2}(M,\mu)}

in the weak
TL^{2}
-topology. The
\Gamma
-compactness follows from the fact that
\|\chi_{N}\circ T_{N}\|_{L^{2}(\mu_{N})}\leq 1
for arbitrary clusterings
\chi_{N}:X_{N}\rightarrow\{0,1\}^{P}
and transport maps
T_{N}
. Thus, the volume constrained MBO scheme converges up to subsequences. By induction the result holds also true for all later iterations for further subsequences.
∎

4.3.
L^{2}
-Estimate on the
V
-Order Statistic

The aim of this chapter is to introduce the necessary tools for the
L^{2}
-estimate, Proposition
2
, and then prove it.
We sketch our approach for the
L^{2}
-estimate for two phases in the sharp interface limit. These types of estimates are already well known in the community of volume-preserving mean curvature flow; see for example
[
47
,
38
,
31
]
. However, we find it instructive to think of the simplest case first, which unfortunately cannot be found in the literature. Hence we decide to sketch the idea of the proof in this simplest case: We take a volume-preserving mean curvature flow, say on the flat torus
M=\mathbb{T}^{d}
.

Assume that we have an open set
\Omega(t)
that evolves with volume-preserving mean curvature flow. The motion is then described by

(71)

v=-H+\Lambda\quad\text{ on }\Sigma(t)=\partial\Omega(t).

where
v
is the normal velocity,
H
is the mean curvature and
\Lambda=\frac{1}{\Area(\Sigma(t))}\int_{\Sigma(t)}H\,dS\in\mathbb{R}
is the Lagrange multiplier ensuring the mass conservation. Testing (
71
) with
\xi\cdot n
for an arbitrary vector field
\xi
and the normal
n
as well as using
\int_{\Sigma(t)}-H\xi\cdot n\,ds=\int_{\Sigma(t)}\mathop{\textup{}}{div}(\xi)\,dS
and Gauss’ Theorem yields

(72)

\int_{\Sigma(t)}v\xi\cdot n\,dS=\int_{\Sigma(t)}\mathop{\textup{}}{div}\xi\,dS+\Lambda(t)\int_{\Omega(t)}\mathop{\textup{}}{div}(\xi)\,ds.

The idea is to choose for every
t\in[0,T]
a test vector field
\xi
such that

(73)

\mathop{\textup{}}{div}(\xi)=\chi_{\Omega(t)}-\int\chi_{\Omega(t)}\,dx

and hope that
\|\xi\|_{\infty},\|\nabla\xi\|_{\infty}
are controlled. One gets by rearranging and squaring (
72
), integrating in time and using
\int\chi_{\Omega}\,dx=V\in(0,1)
for some fixed
V
that

\displaystyle V^{2}(1-V)^{2}\int_{0}^{T}\Lambda^{2}(t)\,dt\leq\|\xi\|_{\infty}^{2}\sup_{t}\Area(\Sigma(t))\int_{0}^{T}\int_{\Sigma(t)}v^{2}\,dS\,dt+\|\nabla\xi\|_{\infty}^{2}T^{2}\left(\sup_{t}\Area(\Sigma(t))\right)^{2}

As
\frac{d}{\,dt}\Area(\Sigma(t))=-\int_{\Sigma(t)}v^{2}\,dS
it follows
\int_{0}^{T}\int_{\Sigma(t)}v^{2}\,dS\,dt\leq\Area(\Sigma(0))=:E_{0}
and
\Area(\Sigma(t))\leq E_{0}
, which implies

(74)

\int_{0}^{T}\Lambda^{2}(t)\,dt\leq\frac{1}{V^{2}(1-V)^{2}}\|\xi\|_{C^{1,1}}^{2}T(1+T)E_{0}^{2}.

Note that (
73
) is underdetermined, so we make the Ansatz
\xi=\nabla\phi
. Then
\Delta\phi=\chi_{\Omega}-V
has a unique solution and elliptic regularity gives the sharp estimates (modulo mollifying the right-hand side on some scale
\varepsilon>0
).

The proof for the estimate of the Lagrange multiplier of the volume-constrained MBO scheme is similar to the presented proof sketch but has some further complications: The differential equation (
71
) is not valid for the MBO scheme. Thus we have to replace (
72
) by the Euler-Lagrange equation of the minimizing movement interpretation of the MBO scheme (see (
92
)). The estimates of the first variation of the energy and distance term in the Euler-Lagrange equation will be one of the main challenges of the proof later. The other hurdle will be the complications introduced by the multi-phase setting. This is solved by picking
\xi
as in (
73
) for every phase by its own and then finding a suitable linear combination to isolate a norm of
\Lambda
from the corresponding term in (
72
).

We begin by giving some more results on the minimizing movement interpretation we already witnessed in the previous section.
The minimizing movement interpretation is a strong tool that allows variational techniques to be used.

Iteratively testing the minimizing movement interpretation with the predecessor we immediately get the following a-priori energy dissipation estimate.

Lemma 10

(Energy dissipation estimate)
.

Let
\chi^{\ell}
result of
\ell
iterations of the MBO scheme then it holds

(75)

E_{h}(\chi^{L})+\frac{h}{2}\sum_{\ell=1}^{L}\left(\frac{d_{h}(\chi^{\ell},\chi^{\ell-1})}{h}\right)^{2}\leq E_{0}:=E_{h}(\chi^{0}).

In the next lemma we adapt the proof of Yip and one of the authors
[
32
]
of the monotonicity of a rescaled thresholding energy. The scaling is usually used for tresholding schemes in codimension 2. Although our scheme is “the classical one” in codimension 1 the monotonicity is still useful to compare energies at different scales. Note that the approximate monotonicity of Esedoḡlu and Otto
[
12
]
is not expected to hold in our case.

Lemma 11
.

Let
\chi
be fixed. Then for every
h>0
it holds

(76)

\displaystyle\frac{d}{dh}\left(\frac{1}{\sqrt{h}}E_{h}(\chi)\right)\leq 0,

(77)

\displaystyle\frac{d}{dh}\left(\sqrt{h}E_{h}(\chi)\right)\geq 0.

In particular for any constant
C>0
it holds

(78)

E_{Ch}(\chi)\leq\max\left\{\sqrt{C},\frac{1}{\sqrt{C}}\right\}E_{h}(\chi).

Proof.

We start by proving inequality (
76
). Denote by
\{\psi_{k}\}_{k\in\mathbb{N}}
an orthonormal basis of
L^{2}(M,\mu)
of eigenfunctions of
\Delta_{\mu}
, i.e.

\displaystyle\Delta_{\mu}\psi_{k}=\lambda_{k}\psi_{k},

where
0\leq\lambda_{1}\leq\lambda_{2}\leq\dots
. It then holds
e^{-h\Delta_{\mu}}\psi_{k}=e^{-\lambda_{k}h}\psi_{k}
as

\displaystyle\frac{d}{dh}e^{-\lambda_{k}h}\psi_{k}=-\lambda_{k}e^{-\lambda_{k}h}\psi_{k}=-\Delta_{\mu}e^{-\lambda_{k}h}\psi_{k}

is the unique solution to the heat equation on
M
.

Now the orthonormal basis is used to transform
\frac{1}{\sqrt{h}}E_{h}(\chi)
with similar ideas as used in Fourier analysis. Due to the orthonormality of the
\psi_{k}
, every function
f\in L^{2}(M,\mu)
can be written as

\displaystyle f(x)=\sum_{k=1}^{\infty}\langle\psi_{k},f\rangle_{L^{2}(M,\mu)}\psi_{k}(x)\quad\text{ and }\quad\langle f,g\rangle_{L^{2}(M,\mu)}=\sum_{k=1}^{\infty}\langle\psi_{k},f\rangle_{L^{2}(M,\mu)}\langle\psi_{k},g\rangle_{L^{2}(M,\mu)}.

Now this decomposition yields, using also
\int_{M}e^{-h\Delta_{\mu}}\chi_{i}\;d\mu=\int_{M}\chi_{i}\;d\mu=\int_{M}\chi_{i}^{2}\;d\mu
,

\displaystyle\frac{1}{\sqrt{h}}E_{h}(\chi)

\displaystyle=\frac{1}{h}\sum_{i\neq j}\int_{M}\chi_{j}(x)(e^{-h\Delta_{\mu}}\chi_{i})(x)\,d\mu(x)

\displaystyle=\frac{1}{h}\sum_{i=1}^{P}\left(\int_{M}\chi_{i}^{2}(x)\,d\mu(x)-\int_{M}\chi_{i}(x)(e^{-h\Delta_{\mu}}\chi_{i})(x)\,d\mu(x)\right)

\displaystyle=\sum_{i=1}^{P}\sum_{k=1}^{\infty}\langle\psi_{k},\chi_{i}\rangle_{L^{2}(M,\mu)}^{2}\lambda_{k}\left(\frac{1-e^{-\lambda_{k}h}}{\lambda_{k}h}\right).

Thus it remains to prove for inequality (
76
) that
\frac{1-e^{-\lambda_{k}h}}{\lambda_{k}h}
is non-increasing in
h
for every
k
. Denoting
s=h\lambda_{k}
this follows from the fact that
e^{-s}(1+s)\leq 1
for all
s\in\mathbb{R}
and the direct computation

\frac{d}{ds}\left(\frac{1-e^{-s}}{s}\right)=\frac{e^{-s}}{s}-\frac{1-e^{-s}}{s^{2}}=\frac{e^{-s}(1+s)-1}{s^{2}}\leq 0.

To prove inequality (
77
) we use the semi-group property to write

\displaystyle\sqrt{h}E_{h}(\chi)

\displaystyle=\sum_{i=1}^{P}\int_{M}(1-\chi_{i})e^{-h\Delta_{\mu}}\chi_{i}\,d\mu

\displaystyle=\sum_{i=1}^{P}\left(\int_{M}e^{-h\Delta_{\mu}}\chi_{i}\,d\mu-\int_{M}\chi_{i}e^{-\frac{h}{2}\Delta_{\mu}}e^{-\frac{h}{2}\Delta_{\mu}}\chi_{i}\,d\mu\right)

\displaystyle=\sum_{i=1}^{P}\int_{M}\chi_{i}\,d\mu-\sum_{i=1}^{P}\int_{M}\left(e^{-\frac{h}{2}\Delta_{\mu}}\chi_{i}\right)^{2}d\mu.

Now, by our sign convention of
\Delta_{\mu}=-\textup{div}_{\mu}\circ\nabla
inequality (
77
) follows immediately:

\displaystyle\frac{d}{dh}\left(\sqrt{h}E_{h}(\chi)\right)

\displaystyle=-\sum_{i=1}^{P}\int_{M}e^{-\frac{h}{2}\Delta_{\mu}}\chi_{i}(-\Delta_{\mu})e^{-\frac{h}{2}\Delta_{\mu}}\chi_{i}\,d\mu

\displaystyle=\int_{i=1}^{P}\int_{M}\left|\nabla e^{-\frac{h}{2}\Delta_{\mu}}\chi_{i}\right|^{2}\,d\mu

\displaystyle\geq 0.\qed

The previous lemma can only be used for time-scales that are comparable. To get some kind of monotonicity across scales in the tresholding energy we use the following comparison of the thresholding energy with the
L^{1}
-norm of the gradient. In the Euclidean case, it is easy to see that by the fundamental theorem of calculus, Fubini, and the translation invariance of
\int_{\mathbb{R}^{d}}dx

\displaystyle\int_{\mathbb{R}^{d}}\left|u-e^{-h\Delta}u\right|\,dx

\displaystyle\leq\int_{R^{d}}\int_{R^{d}}\frac{1}{(4\pi)^{\frac{d}{2}}}e^{-\frac{|z|^{2}}{4}}|u(x)-u(x-\sqrt{h}z)|\,dz\,dx

\displaystyle=\int_{R^{d}}\int_{R^{d}}\frac{1}{(4\pi)^{\frac{d}{2}}}e^{-\frac{|z|^{2}}{4}}\left|\int_{0}^{1}\frac{d}{dt}u(x+t\sqrt{h}z)\,dt\right|\,dz\,dx

\displaystyle\leq\int_{0}^{1}\int_{\mathbb{R}^{d}}\frac{1}{(4\pi)^{\frac{d}{2}}}e^{\frac{|z|^{2}}{4}}\sqrt{h}|z|\int_{\mathbb{R}^{d}}|\nabla u(x+t\sqrt{h}z)|\,dx\,dz\,dt

\displaystyle\leq\sqrt{h}\left(\int_{\mathbb{R}^{d}}\frac{1}{(4\pi)^{\frac{d}{2}}}|z|e^{-\frac{|z|^{2}}{4}}\,dz\right)\int_{\mathbb{R}^{d}}|\nabla u(x)|\,dx.

So in the Euclidean case, we have

\displaystyle\int_{\mathbb{R}^{d}}\left|u-e^{-h\Delta}u\right|\leq C\sqrt{h}\int_{\mathbb{R}^{d}}|\nabla u|

with
C
the first moment of the standard Gaussian.

The proof in our case of a (weighted) manifold is a careful adaptation of the proof of the Segment Inequality by Cheeger and Colding
[
8
]
. The only additional ingredient are Gaussian bounds on the heat kernel that were also used in
[
26
]
.

Lemma 12
.

For any

\displaystyle\int_{M}\left|u-e^{-h\Delta_{\mu}}u\right|\,d\mu\leq C(M,\mu)\sqrt{h}\left(\int_{M}\left|\nabla u\right|\,d\mu+1\right)

where
C(M,\mu)
is a constant that depends only on
M
and

but neither on

Remark 6
.

Proof of Lemma

.

We begin by using the heat kernel

\displaystyle\int_{M}\left|u-e^{-h\Delta_{\mu}}u\right|\,d\mu=\int_{M}\left|\int_{M}p(h,x,y)(u(x)-u(y))\,d\mu(x)\right|\,d\mu(y).

Next we use the Gaussian bound (
83
) to estimate the heat kernel by a kernel that looks similar to the Euclidean heat kernel. This yields

(85)

\displaystyle\int_{M}\left|u-e^{-h\Delta_{\mu}}u\right|\,d\mu\lesssim\int_{M}\int_{M}\frac{1}{\mu\big(B_{\sqrt{h}}(x)\big)}e^{-\frac{\textup{dist}_{M}^{2}(x,y)}{C_{4}h}}|u(x)-u(y)|\,d\mu(y)\,d\mu(x).

As we want to work with polar normal coordinates it is necessary to restrict the domain of integration to the set
\left\{x,y\in M:\textup{dist}_{M}(x,y)\leq\mathop{\textup{}}{inj}(M)\right\}
where
\mathop{\textup{}}{inj}(M)
is the injectivity radius of
M
. Therefore, we use the scaling property (
80
) and the fact that
\frac{1}{h^{d/2+1}}e^{-1/h}
is uniformly bounded in
h
to estimate the integral over the complementary set by

\displaystyle\int_{M}\int_{M\setminus B_{\mathop{\textup{}}{inj}(M)}(x)}\frac{1}{\mu\big(B_{\sqrt{h}}(x)\big)}e^{-\frac{\textup{dist}_{M}^{2}(x,y)}{C_{4}h}}|u(x)-u(y)|\,d\mu(y)\,d\mu(x)

\displaystyle\lesssim\sqrt{h}\int_{M}\int_{M\setminus B_{\mathop{\textup{}}{inj}(M)}(x)}\frac{1}{h^{\frac{d}{2}+1}}e^{-\frac{\mathop{\textup{}}{inj}(M)^{2}}{C_{4}h}}|u(x)-u(y)|\,d\mu(y)\,d\mu(x)

\displaystyle\lesssim\sqrt{h}.

Denote by
\gamma_{x,y}:[0,\textup{dist}(x,y)]\rightarrow M
the unit speed geodesic from
x\in M
to
y\in M
to estimate the remaining term of the right-hand side of (
85
) by

\displaystyle\int_{M}\int_{B_{\mathop{\textup{}}{inj}(M)}(x)}\frac{1}{\mu\left(B_{\sqrt{h}}(x)\right)}e^{-\frac{\textup{dist}_{M}^{2}(x,y)}{C_{4}h}}|u(x)-u(y)|\,d\mu(y)\,d\mu(x)

\displaystyle\leq\int_{M}\int_{B_{\mathop{\textup{}}{inj}(M)}(x)}\frac{1}{\mu\left(B_{\sqrt{h}}(x)\right)}e^{-\frac{\textup{dist}_{M}^{2}(x,y)}{C_{4}h}}\int_{0}^{\textup{dist}_{M}(x,y)}\left|\frac{d}{dt}u(\gamma_{x,y}(t))\right|\,dt\,d\mu(y)\,d\mu(x)

\displaystyle\leq\int_{M}\int_{B_{\mathop{\textup{}}{inj}(M)}(x)}\frac{1}{\mu\left(B_{\sqrt{h}}(x)\right)}e^{-\frac{\textup{dist}_{M}^{2}(x,y)}{C_{4}h}}\int_{0}^{\textup{dist}_{M}(x,y)}|\nabla u(\gamma_{x,y}(t))|\,dt\,d\mu(y)\,d\mu(x).

Now define

\displaystyle F(x,y)

\displaystyle:=\int_{0}^{\textup{dist}_{M}(x,y)}|\nabla u(\gamma_{x,y}(t))|\,dt,\quad\quad f(x,y)=h^{-\frac{d}{2}}e^{-\frac{\textup{dist}_{M}^{2}(x,y)}{C_{4}h}}

and, with a slight abuse of notation, denote by
\gamma_{x,\theta}:[0,\mathop{\textup{}}{inj}(M)]\rightarrow M
the unit speed geodesic starting in
x\in M
and going in direction
\theta\in T_{x}M
. Using polar normal coordinates with the area element
\mathcal{A}(\theta,s)
at radius
s
and direction
\theta\in\mathbb{S}^{d-1}
as well as once more the scaling property (
81
), it follows

\displaystyle\int_{M}\int_{B_{\mathop{\textup{}}{inj}(M)}(x)}\frac{1}{\mu\big(B_{\sqrt{h}}(x)\big)}e^{-\frac{\textup{dist}_{M}^{2}(x,y)}{C_{4}h}}|u(x)-u(y)|\,d\mu(x)\,d\mu(y)

\displaystyle\lesssim\int_{M}\int_{B_{\mathop{\textup{}}{inj}(M)}(x)}f(x,y)F(x,y)\,d\mu(x)\,d\mu(y)

(86)

\displaystyle=\int_{M}\int_{0}^{\mathop{\textup{}}{inj}(M)}\int_{\mathbb{S}^{d-1}}\mathcal{A}(\theta,s)f(x,\gamma_{x,\theta}(s))F(x,\gamma_{x,\theta}(s))\,d\mathcal{H}^{d-1}(\theta)\,ds\,d\mu(x).

By definition
f(x,\gamma_{x,\theta}(s))=h^{-\frac{d}{2}}e^{-\frac{s^{2}}{C_{4}h}}
is independent of
x
and
\theta
. It holds by the scaling properties of the area element (
81
) that

\displaystyle\mathcal{A}(\theta,s)=\mathcal{A}(\theta,t)\frac{\mathcal{A}(\theta,s)}{\mathcal{A}(\theta,t)}\lesssim\mathcal{A}(\theta,t)\frac{s^{d-1}}{t^{d-1}}.

Together with the obvious identity
\gamma_{x,\gamma_{x,\theta}(s)}(t)=\gamma_{x,\theta}(t)
and
t=\textup{dist}_{M}(x,\gamma_{x,\theta}(t))
it follows that

(87)

\mathcal{A}(\theta,s)F(x,\gamma_{x,\theta}(s))\lesssim s^{d-1}\int_{0}^{s}\mathcal{A}(\theta,t)\frac{\left|\nabla u\left(\gamma_{x,\theta}(t)\right)\right|}{\textup{dist}_{M}^{d-1}(x,\gamma_{x,\theta}(t))}\,dt.

Plugging inequality (
87
) into estimate (
86
) and recognizing that we can view
(\theta,t)
(instead of
(\theta,s)
) as polar coordinates
y=\gamma_{x,\theta}(t)
one arrives at

\displaystyle\int_{M}\int_{B_{\mathop{\textup{}}{inj}(M)}(x)}\frac{1}{\mu\big(B_{\sqrt{h}}(x)\big)}e^{-\frac{\textup{dist}_{M}^{2}(x,y)}{C_{4}h}}|u(x)-u(y)|\,d\mu(x)\,d\mu(y)

\displaystyle\lesssim\int_{0}^{\mathop{\textup{}}{inj}(M)}\frac{1}{\sqrt{h}^{d}}e^{-\frac{s^{2}}{C^{4}h}}\int_{M}\int_{B_{s}(x)}\frac{\left|\nabla u\left(y\right)\right|}{\textup{dist}_{M}^{d-1}(x,y)}\,d\mu(y)\,d\mu(x)\,ds

\displaystyle\lesssim\sqrt{h}\int_{0}^{\mathop{\textup{}}{inj}(M)}\frac{s^{d}}{\sqrt{h}^{d+1}}e^{-\frac{s^{2}}{C^{4}h}}\,ds\int_{M}\left|\nabla u\left(y\right)\right|\,d\mu(y),

where we used Fubini’s theorem in
x
and
y
in the last step and that since
\mathcal{A}(\theta,t)\lesssim t^{d-1}
by (
81
), we get for any
y\in M

\displaystyle\int_{B_{s}(y)}\frac{1}{\textup{dist}_{M}^{d-1}(x,y)}\,d\mu(x)

\displaystyle=\int_{\mathbb{S}^{d-1}}\int_{0}^{s}\frac{\mathcal{A}(\theta,t)}{t^{d-1}}\,dt\,d\mathcal{H}^{d-1}(\theta)\lesssim s.

The proof follows by the final estimate

\int_{0}^{\mathop{\textup{}}{inj}(M)}\frac{s^{d}}{\sqrt{h}^{d+1}}e^{-\frac{s^{2}}{C^{4}h}}\,ds\leq\int_{0}^{\infty}s^{d}e^{-\frac{s^{2}}{C^{4}}}\,ds<\infty.\qed

Using the previous lemma we get a similar monotonicity estimate for the thresholding energy as in Lemma
11
. The difference is that we can compare arbitrary times across scales and not only times that are scaled by a constant of
\mathcal{O}(1)
.

Lemma 13
.

For any
\chi:M\rightarrow\{0,1\}^{P}
with
\sum_{i=1}^{P}\chi_{i}=1
a.e. and any
0<h_{0}\leq h
it holds

(88)

E_{h}(\chi)\leq C(M,\mu)(E_{h_{0}}(\chi)+1).

Proof.

For any
\tilde{\chi}\in\{0,1\}
and
u\in[0,1]
it holds

(89)

|\tilde{\chi}-u|=(1-\tilde{\chi})u+\tilde{\chi}(1-u).

Thereby, thanks to the self-adjointness of
e^{-h\Delta_{\mu}}
, we get the following representation of the thresholding energy

\displaystyle E_{h}(\chi)=\frac{1}{\sqrt{h}}\sum_{i=1}^{P}\int_{M}\chi_{i}e^{-h\Delta_{\mu}}(1-\chi_{i})\,d\mu=\frac{1}{2\sqrt{h}}\sum_{i=1}^{P}\int_{M}\left|\chi_{i}-e^{-h\Delta_{\mu}}\chi_{i}\right|\,d\mu.

Using the triangle inequality, the semigroup property
e^{-(t+s)\Delta_{\mu}}=e^{-t\Delta_{\mu}}e^{-s\Delta_{\mu}}
, and Lemma
12
with
u=e^{-h_{0}\Delta_{\mu}}\chi_{i}
one concludes

\displaystyle E_{h}(\chi)

\displaystyle\lesssim\frac{1}{\sqrt{h_{0}}}\sum_{i=1}^{P}\int_{M}\left|\chi_{i}-e^{-h_{0}\Delta_{\mu}}\chi_{i}\right|\,d\mu+\frac{1}{\sqrt{h-h_{0}}}\sum_{i=1}^{P}\int_{M}\left|e^{-h_{0}\Delta_{\mu}}\chi_{i}-e^{-(h-h_{0})\Delta_{\mu}}e^{-h_{0}\Delta_{\mu}}\chi_{i}\right|\,d\mu

\displaystyle\lesssim E_{h_{0}}(\chi)+\sum_{i=1}^{P}\int_{M}\left|\nabla e^{-h_{0}\Delta_{\mu}}\chi_{i}\right|\,d\mu+1.

Using
\int_{M}\nabla_{x}p(h,x,y)\,d\mu=\nabla_{x}\int_{M}p(h,x,y)\,d\mu=0
as well as the Gaussian bounds (
83
) and (
84
) one computes

\displaystyle\sum_{i=1}^{P}\int_{M}\left|\nabla e^{-h_{0}\Delta_{\mu}}\chi_{i}\right|\,d\mu

\displaystyle=\sum_{i=1}^{P}\int_{M}\left|\int_{M}\nabla_{x}p\left(h_{0},x,y\right)(\chi_{i}(y)-\chi_{i}(x))\,d\mu(y)\right|\,d\mu(x)

\displaystyle\leq\frac{1}{h_{0}}\sum_{i=1}^{P}\int_{M}\int_{M}p\left(\frac{\tilde{C}_{2}}{C_{2}}h_{0},x,y\right)\left|\chi_{i}(y)-\chi_{i}(x)\right|\,d\mu(y)\,d\mu(x).

By Equation (
89
) and the monotonicity of Lemma
11
the proof is concluded with the calculation

\sum_{i=1}^{P}\int_{M}\left|\nabla e^{-h_{0}\Delta_{\mu}}\chi_{i}\right|\,d\mu\leq 2E_{\frac{\tilde{C}_{2}}{C_{2}}h_{0}}(\chi)\lesssim E_{h_{0}}(\chi).\qed

Next the first variation of the thresholding energy is defined. Note that this is done by inner variations such that the constraints
\chi_{s}\in\{0,1\}^{P}
and
\sum_{i=1}^{P}\chi_{s,i}=1
a.e. on
M
are always satisfied.

Definition 5
.

For any
\chi:M\rightarrow\{0,1\}^{P}
with
\sum_{i=1}^{P}\chi_{i}=1
a.e. on
M
and any given smooth vector field
\xi\in\Gamma(TM)
let
X_{s,i}
for
i=1,\dots,P
be generated by the flow of
\xi
, i.e.,
\chi_{0,i}=\chi_{i}
and
\chi_{s,i}
solves the following distributional equation:

(90)

\partial_{s}\chi_{s,i}+\xi\cdot\nabla\chi_{s,i}=0.

The first variation along this flow is denoted by

(91)

\delta E_{h}(\chi,\xi):=\frac{d}{ds}E_{h}(\chi_{s})\Big|_{s=0},\quad\delta\left(\frac{1}{2h}d_{h}^{2}(\cdot,\bar{\chi})\right)(\chi,\xi):=\frac{d}{ds}\frac{1}{2h}d_{h}^{2}(\chi_{s},\bar{\chi})\Big|_{s=0}

where
\bar{\chi}:M\rightarrow\in\{0,1\}^{P}
with
\sum_{i=1}^{P}\bar{\chi}_{i}=1
a.e. is fixed.

Due to the definition of the first variation we immediately get a Euler–Lagrange equation for the optimization problem (
66
) which is formulated in the next lemma.

Lemma 14

(Euler–Lagrange equation)
.

Let
\chi^{\ell}
be obtained by
\chi^{\ell-1}
through the volume constrained MBO scheme (
54
) with
V
-order statistic
m_{\mu}^{\ell}
. Then
\chi^{\ell}
solves the following Euler–Lagrange equation corresponding to (
66
)

(92)

\delta E_{h}(\chi^{\ell},\xi)+\delta\left(\frac{1}{2h}d_{h}^{2}(\cdot,\chi^{\ell-1})\right)(\chi^{\ell},\xi)+\Lambda_{\mu}^{\ell}\cdot\int_{M}\textup{div}_{\mu}(\xi)\,\chi^{\ell}\,d\mu=0.

The following proof of the
L^{2}
-estimate, Proposition
2
, is a generalization of Laux and Swartz
[
31
]
to the multi cluster setting on a Riemmanian manifold.

Proof of Proposition
2
.

Squaring the Euler–Lagrange equation (
92
) gives for any
\ell=1,\dots,L
and
\xi\in\Gamma(TM)

(93)

\left(\Lambda_{\mu}^{\ell}\cdot\int_{M}\textup{div}_{\mu}(\xi)\chi^{\ell}\,d\mu(x)\right)^{2}\lesssim(\delta E_{h}(\chi^{\ell},\xi))^{2}+\left(\delta\left(\frac{1}{2h}d_{h}^{2}(\cdot-\chi^{\ell-1})\right)(\chi^{\ell},\xi)\right)^{2}.

The proof strategy is now to bound the right-hand side from above for an arbitrary vector field
\xi\in\Gamma(TM)
and then construct specific vector fields to get a lower bound for the left-hand side.

For easier notation we write in the following

\displaystyle\left\lVert\xi\right\rVert:=\max\{\|\xi\|_{C^{0}},\|\textup{div}_{\mu}\xi\|_{C^{0}},\Lip(\xi)\}

with
\Lip(\xi)
the smallest constant such that

\displaystyle|\nabla_{v}\xi|_{x}\leq\Lip(\xi)|v|_{x}

for all
x\in M
and
v\in T_{x}M
. Here, we denoted by
\nabla:TM\times\Gamma(TM)\rightarrow\Gamma(TM)
the Levi–Civita connection.

Step 1: Estimates on
\delta E_{h}(\chi,\xi)
. For any
\chi:M\rightarrow\{0,1\}^{P}
with
\sum_{i=1}^{P}\chi_{i}=1
a.e. and any
\xi\in\Gamma(TM)
, we have

(94)

|\delta E_{h}(\chi,\xi)|\lesssim\left\lVert\xi\right\rVert(1+E_{h}(\chi)).

We use
-\langle\xi,\nabla\chi\rangle=-\textup{div}_{\mu}(\chi,\xi)+\textup{div}_{\mu}(\xi)\chi
to compute the first variation of the energy term by integration by parts:

(95)

\displaystyle\delta E_{h}(\chi,\xi)

\displaystyle=\frac{d}{ds}\frac{1}{\sqrt{h}}\sum_{i\neq j}\int_{M}\chi_{s,i}e^{-h\Delta_{\mu}}\chi_{s,j}\,d\mu(x)\Big|_{s=0}

\displaystyle=\frac{1}{\sqrt{h}}\sum_{i\neq j}\int_{M}\langle-\xi,\nabla\chi_{i}\rangle e^{-h\Delta_{\mu}}\chi_{j}+\chi_{i}e^{-h\Delta_{\mu}}\langle-\xi,\nabla\chi_{j}\rangle\,d\mu(x)

\displaystyle=\frac{1}{\sqrt{h}}\sum_{i\neq j}\int_{M}\int_{M}\begin{aligned} &(-\textup{div}_{\mu}(\chi_{i}\xi)(x)+\textup{div}_{\mu}(\xi)(x)\chi_{i}(x))p(h,x,y)\chi_{j}(y)\\
&+\chi_{i}(x)p(h,x,y)(-\textup{div}_{\mu}(\chi_{j}\xi)(y)+\textup{div}_{\mu}(\xi)(y)\chi_{j}(y)\,d\mu(x)\,d\mu(y)\end{aligned}

\displaystyle=\frac{1}{\sqrt{h}}\sum_{i\neq j}\int_{M}\int_{M}\begin{aligned} &\chi_{i}(x)\big(\langle\xi(x),\nabla_{x}p(h,x,y)\rangle_{x}+\langle\xi(y),\nabla_{y}p(h,x,y)\rangle_{y}\big)\chi_{j}(y)\\
&+\textup{div}_{\mu}(\xi)(x)\chi_{i}(x)p(h,x,y)\chi_{j}(y)+\chi_{i}(x)p(h,x,y)\textup{div}_{\mu}(\xi)(y)\chi_{j}(y)\,d\mu(x)\,d\mu(y).\end{aligned}

The two terms containing
\textup{div}_{\mu}\xi
can be estimated by

\displaystyle\left|\frac{1}{\sqrt{h}}\sum_{i\neq j}\int_{M}\int_{M}\textup{div}_{\mu}(\xi)(x)\chi_{i}(x)p(h,x,y)\chi_{j}(y)+\chi_{i}(x)p(h,x,y)\textup{div}_{\mu}(\xi)(y)\chi_{j}(y)\,d\mu(x)\,d\mu(y)\right|

\displaystyle\leq\|\textup{div}_{\mu}\xi\|_{C^{0}}\frac{1}{\sqrt{h}}\sum_{i\neq j}\int_{M}\int_{M}\chi_{i}(x)p(h,x,y)\chi_{j}(y)+\chi_{i}(x)p(h,x,y)\chi_{j}(y)\,d\mu(x)\,d\mu(y)

\displaystyle\lesssim\|\textup{div}_{\mu}\xi\|_{C^{0}}E_{h}(\chi).

For the remaining term we want to apply the asymptotic expansion (
82
) which only holds inside the injectivity radius. Thus we make the following splitting into near- and far-field contributions:

\displaystyle\frac{1}{\sqrt{h}}\sum_{i\neq j}\int_{M}\int_{M}\chi_{i}(x)\big(\langle\xi(x),\nabla_{x}p(h,x,y)\rangle_{x}+\langle\xi(y),\nabla_{y}p(h,x,y)\rangle_{y}\big)\chi_{j}(y)\,d\mu(x)\,d\mu(y)

\displaystyle=\frac{1}{\sqrt{h}}\sum_{i\neq j}\int_{M}\int_{M\setminus B_{\mathop{\textup{}}{inj}(M)}(x)}\chi_{i}(x)\big(\langle\xi(x),\nabla_{x}p(h,x,y)\rangle_{x})+\langle\xi(y),\nabla_{y}p(h,x,y)\rangle_{y}\big)\chi_{j}(y)\,d\mu(x)\,d\mu(y)

\displaystyle\hskip 12.0pt+\frac{1}{\sqrt{h}}\sum_{i\neq j}\int_{M}\int_{B_{\mathop{\textup{}}{inj}(M)}(x)}\chi_{i}(x)\big(\langle\xi(x),\nabla_{x}p(h,x,y)\rangle_{x}+\langle\xi(y),\nabla_{y}p(h,x,y)\rangle_{y}\big)\chi_{j}(y)\,d\mu(x)\,d\mu(y)

\displaystyle=:I+I\!I.

To bound the far field contribution
I
we use the Gaussian bounds (
83
) and (
84
) and the scaling property (
80
)

\displaystyle I

\displaystyle\leq\frac{\|\xi\|_{C^{0}}}{\sqrt{h}}\sum_{i\neq j}\int_{M}\int_{M\setminus B_{\mathop{\textup{}}{inj}(M)}(x)}\big(|\nabla_{x}p(h,x,y)|+|\nabla_{y}p(h,x,y)|\big)\,d\mu(x)\,d\mu(y)

\displaystyle\lesssim\frac{\|\xi\|_{C^{0}}}{\sqrt{h}}\sum_{i\neq j}\int_{M}\int_{M\setminus B_{\mathop{\textup{}}{inj}(M)}(x)}\frac{1}{\sqrt{h}\mu\left(B_{\sqrt{h}}(x)\right)}e^{-\frac{\mathop{\textup{}}{inj}(M)^{2}}{\tilde{C}_{2}h}}\,d\mu(x)\,d\mu(y)

\displaystyle\leq\|\xi\|_{C^{0}}\frac{P(P-1)}{h^{\frac{d}{2}+1}}e^{-\frac{\mathop{\textup{}}{inj}(M)^{2}}{\tilde{C}_{2}h}}

\displaystyle\lesssim\|\xi\|_{C^{0}}.

In fact we see that this term goes to
0
as
h
goes to
0
. Now we use the asymptotic expansion (
82
) with
K=\frac{d}{2}+2
for the near-field contribution
I\!I
and calculate

\displaystyle I\!I

\displaystyle\lesssim\frac{1}{\sqrt{h}}\sum_{i\neq j}\int_{M}\int_{B_{\mathop{\textup{}}{inj}(M)}(x)}\chi_{i}(x)\big(\langle\xi(x),\nabla_{x}p_{K}(h,x,y)\rangle_{x}+\langle\xi(y),\nabla_{y}p_{K}(h,x,y)\rangle_{y}\big)\chi_{j}(y)\,d\mu(x)\,d\mu(y)

\displaystyle\hskip 12.0pt+\|\xi\|_{C^{0}}.

Here we denoted the approximate heat kernel
p_{K}(h,x,y):=\frac{1}{(4\pi h)^{d/2}}e^{\frac{-\textup{dist}_{M}^{2}(x,y)}{4h}}\sum_{k=0}^{K}v_{k}(x,y)h^{k}
. With the approximate heat kernel we can now compute

\displaystyle\frac{1}{\sqrt{h}}\sum_{i\neq j}\int_{M}\int_{B_{\mathop{\textup{}}{inj}(M)}(x)}\chi_{i}(x)\big(\langle\xi(x),\nabla_{x}p_{K}(h,x,y)\rangle_{x}+\langle\xi(y),\nabla_{y}p_{K}(h,x,y)\rangle_{y}\big)\chi_{j}(y)\,d\mu(x)\,d\mu(y)

\displaystyle=\frac{1}{\sqrt{h}}\sum_{i\neq j}\int_{M}\int_{B_{\mathop{\textup{}}{inj}(M)}(x)}\begin{aligned} &\chi_{i}(x)\big(\big\langle\xi(x),\nabla_{x}\frac{1}{4h}\textup{dist}^{2}_{M}(x,y)\big\rangle_{x}+\big\langle\xi(y),\nabla_{y}\frac{1}{4h}\textup{dist}^{2}_{M}(x,y)\big\rangle_{y}\big)\\
\cdot&p_{K}(h,x,y)\chi_{j}(y)\,d\mu(x)\,d\mu(y)\end{aligned}

\displaystyle\hskip 12.0pt+\frac{1}{\sqrt{h}}\sum_{i\neq j}\int_{M}\int_{B_{\mathop{\textup{}}{inj}(M)}(x)}\begin{aligned} &\chi_{i}(x)\left(\langle\xi(x),\sum_{k=1}^{K}\nabla_{x}v_{k}(x,y)h^{k}\rangle_{x}+\langle\xi(y),\sum_{k=1}^{K}\nabla_{y}v_{k}(x,y)h^{k}\rangle_{y}\right)\\
\cdot&\frac{1}{(4\pi h)^{d/2}}e^{\frac{-\textup{dist}_{M}^{2}(x,y)}{4h}}\chi_{j}(y)\,d\mu(x)\,d\mu(y)\end{aligned}

\displaystyle=:I\!I^{\prime}+I\!I^{\prime\prime}.

For
I\!I^{\prime\prime}
we use that the coefficients
v_{k}(x,y)
are uniformly bounded for all
x,y\in M
as
M
is compact and the
v_{k}
’s are smooth. Together with the scaling property (
80
), the Gaussian bound (
83
), and Lemma
11
this yields

\displaystyle I\!I^{\prime\prime}\lesssim\frac{\|\xi\|_{C^{0}}}{\sqrt{h}}\sum_{i\neq j}\int_{M}\int_{B_{\mathop{\textup{}}{inj}(M)}(x)}\chi_{i}(x)p\left(\frac{4h}{C_{2}},x,y\right)\chi_{j}(y)\,d\mu(x)\,d\mu(y)\lesssim||\xi||_{C^{0}}E_{h}(\chi).

To deal with
I\!I^{\prime}
we claim that

(96)

\displaystyle\left|\langle\xi(x),\nabla_{x}\textup{dist}^{2}_{M}(x,y)\rangle_{x}+\langle\xi(y),\nabla_{y}\textup{dist}^{2}_{M}(x,y)\rangle_{y}\right|\leq 2\ \textup{dist}^{2}_{M}(x,y)\Lip(\xi).

To prove this claim we need the following ingredients:

1.

\nabla_{x}\textup{dist}_{M}^{2}(x,y)=-2\exp_{x}^{-1}(y)
for all
x,y\in M
with
\textup{dist}_{M}(x,y)\leq\mathop{\textup{}}{inj}(M)
. Here,
\exp
is the exponential function on the Riemannian manifold. This can be proven by using a geodesic variation of the geodesic connecting
x
to
y
.

2.

PT_{x\rightarrow y}^{\gamma}\left(-2\exp_{x}^{-1}(y)\right)=2\exp_{y}^{-1}(x)
where
PT_{x\rightarrow y}^{\gamma}
is the parallel transport (with respect to the Levi–Civita connection) from
x
to
y
along the geodesic
\gamma
connecting
x
and
y
. To see that this holds, note that
\dot{\gamma}(0)=\exp_{x}^{-1}(y)
and
\dot{\gamma}(1)=-\exp_{x}^{-1}(y)
.

3.

|PT_{x\rightarrow y}^{\gamma}(\xi(x))-\xi(y)|\leq\textup{dist}_{M}(x,y)\Lip(\xi)
. This holds true by Proposition 10.46 of
[
5
]
.

4.

\left|\exp_{x}^{-1}(y)\right|=\textup{dist}_{M}(x,y)
holds by definition of the exponential and distance function.

5.

\langle f(x),g(x)\rangle_{x}=\langle PT_{x\rightarrow y}^{\gamma}(f(x)),PT_{x\rightarrow y}^{\gamma}(g(x))\rangle_{y}
as the Levi–Civita connection preserves the Riemannian metric.

Combining all the ingredients we get indeed

\displaystyle\left|\langle\xi(x),\nabla_{x}\textup{dist}^{2}_{M}(x,y)\rangle_{x}+\langle\xi(y),\nabla_{y}\textup{dist}^{2}_{M}(x,y)\rangle_{y}\right|

\displaystyle=\left|\langle\xi(x),-2\exp_{x}^{-1}(y)\rangle_{x}+\langle\xi(y),-2\exp_{y}^{-1}(x)\rangle_{y}\right|

\displaystyle=\left|\langle PT_{x\rightarrow y}^{\gamma}(\xi(x)),PT_{x\rightarrow y}^{\gamma}\left(-2\exp_{x}^{-1}(y)\right)\rangle_{y}+\langle\xi(y),-2\exp_{y}^{-1}(x)\rangle_{y}\right|

\displaystyle=\left|\langle\xi(y)-PT_{x\rightarrow y}^{\gamma}(\xi(x)),-2\exp_{y}^{-1}(x)\rangle_{y}\right|

\displaystyle\leq|PT_{x\rightarrow y}^{\gamma}(\xi(x))-\xi(y)||2\exp_{y}^{-1}(x)|

\displaystyle\leq 2\ \textup{dist}^{2}_{M}(x,y)\Lip(\xi),

which is precisely the claim (
96
).

Now it follows by the claim (
96
), the Gaussian bound (
83
), the scaling property (
80
), and the uniform bound of the coefficient functions
v_{k}
that

\displaystyle\left(\big\langle\xi(x),\nabla_{x}\frac{1}{4h}\textup{dist}^{2}_{M}(x,y)\big\rangle_{x}+\big\langle\xi(y),\nabla_{y}\frac{1}{4h}\textup{dist}^{2}_{M}(x,y)\big\rangle_{y}\right)p_{K}(h,x,y)

\displaystyle\lesssim\frac{\textup{dist}_{M}^{2}(x,y)\Lip(\xi)}{h}\frac{1}{(4\pi h)^{d/2}}e^{\frac{-\textup{dist}_{M}^{2}(x,y)}{4h}}

\displaystyle\lesssim\frac{\Lip(\xi)}{(4\pi h)^{d/2}}e^{\frac{-\textup{dist}_{M}^{2}(x,y)}{2\cdot 4h}}

\displaystyle\lesssim\Lip(\xi)\,p\left(\frac{8h}{C_{2}},x,y\right).

So we can finally conclude with the monotonicity of Lemma
11
that

\displaystyle I\!I^{\prime}

\langle\chi_{i}^{\ell}\rangle=V_{i}
for all
i\in\{1,\dots,P\}
and
\ell\in\{1,\dots,L\}
, it holds for
i\neq j\in\{1,\dots,P-1\}
that

\displaystyle{A}_{i,j}

\displaystyle=\int_{M}\textup{div}_{\mu}(\xi_{i})\chi_{j}^{\ell}\,d\mu=\int_{M}(\chi_{i,\varepsilon}^{\ell}-\langle\chi_{i}^{\ell}\rangle)\chi_{j}^{\ell}\,d\mu

\displaystyle=\int_{M}(\chi_{i,\varepsilon}^{\ell}-V_{i})(\chi_{j}^{\ell}-V_{j})\,d\mu

\displaystyle=\int_{M}(\chi_{i}^{\ell}-V_{i})(\chi_{j}^{\ell}-V_{j})\,d\mu+\int_{M}(\chi_{i,\varepsilon}^{\ell}-\chi_{i}^{\ell})(\chi_{j}^{\ell}-V_{j})\,d\mu

\displaystyle=-V_{i}V_{j}+\int_{M}(\chi_{i,\varepsilon}^{\ell}-\chi_{i}^{\ell})(\chi_{j}^{\ell}-V_{j})\,d\mu.

Therefore, it holds

\displaystyle(A\Pi^{-1})_{i,j}

\displaystyle=A_{i,j}-A_{i,P}

\displaystyle=\left(-V_{i}V_{j}+V_{i}V_{P}\right)+\left(\int_{M}(\chi_{i,\varepsilon}^{\ell}-\chi_{i}^{\ell})(\chi_{j}^{\ell}-V_{j})\,d\mu-\int_{M}(\chi_{i,\varepsilon}^{\ell}-\chi_{i}^{\ell})(\chi_{P}^{\ell}-V_{P})\,d\mu\right)

\displaystyle=:A^{(0)}_{i,j}+A_{i,j}^{(\varepsilon)}.

The analogous computation for
i=j\in\{1,\dots,P-1\}
yields

\displaystyle(A\Pi^{-1})_{i,i}

\displaystyle=\left(V_{i}-V_{i}^{2}+V_{i}V_{P}\right)+\left(\int_{M}(\chi_{i,\varepsilon}^{\ell}-\chi_{i}^{\ell})(\chi_{i}^{\ell}-V_{i})\,d\mu-\int_{M}(\chi_{i,\varepsilon}^{\ell}-\chi_{i}^{\ell})(\chi_{P}^{\ell}-V_{P})\,d\mu\right)

\displaystyle=:A^{(0)}_{i,i}+A_{i,i}^{(\varepsilon)}.

Denote
V:=(V_{1},\dots,V_{P-1})^{\intercal}\in\mathbb{R}^{(P-1)}
to rewrite

\displaystyle A^{(0)}=\textup{diag}(V)-V(V-V_{P}\mathbbold{1})^{\intercal}.

Because

\displaystyle 1-(V-V_{P}\mathbbold{1})^{\intercal}\textup{diag}^{-1}(V)V=PV_{P}>0

it holds by the Sherman–Morrison formula
[
43
,
2
]
that
A^{(0)}
is invertible with inverse

\displaystyle\left(A^{(0)}\right)^{-1}=\textup{diag}^{-1}(V)+\frac{\mathbbold{1}\mathbbold{1}^{\intercal}-V_{P}\mathbbold{1}\mathbbold{1}^{\intercal}\textup{diag}^{-1}(V)}{PV_{P}}

Thus, the bound on the spectral norm of the inverse of
A^{(0)}
is given by

\displaystyle\left|\left(A^{(0)}\right)^{-1}\right|_{2}\leq\max_{i=1,\dots,P}\frac{3}{V_{i}}

To get invertibility of the whole matrix
A\Pi^{-1}
we use the Neumann series. It holds

\displaystyle A\Pi^{-1}=A^{(0)}+A^{(\varepsilon)}=A^{(0)}(I+\left(A^{(0)}\right)^{-1}A^{(\varepsilon)}).

The Neumann series converges to the inverse of
(I+{A^{(0)}}^{-1}A^{(\varepsilon)})
if
\left|\left(A^{(0)}\right)^{-1}A^{(\varepsilon)}\right|_{2}<1
. By equation (
100
) and
E_{h}(\chi^{\ell})\leq E_{0}
we get for
h\leq\varepsilon^{2}
that

\displaystyle\big|A^{(\varepsilon)}\big|_{2}\leq\big|A^{(\varepsilon)}\big|_{F}\leq 2\left(\sum_{i,j=1}^{P-1}\left|\int_{M}|\chi_{i,\varepsilon}^{\ell}-\chi_{i}^{\ell}|\,d\mu\right|^{2}\right)^{\frac{1}{2}}\leq 2P\textbf{C}\varepsilon(E_{0}+1).

Now pick
\varepsilon:=\frac{\min_{i=1,\dots,P}V_{i}}{12P\textbf{C}(E_{0}+1)}
such that

\displaystyle\Big|\left(A^{(0)}\right)^{-1}A^{(\varepsilon)}\Big|_{2}\leq\Big|\left(A^{(0)}\right)^{-1}\Big|_{2}\Big|A^{(\varepsilon)}\Big|_{2}\leq\varepsilon\frac{6P\textbf{C}(E_{0}+1)}{\min_{i=1,\dots,P}V_{i}}\leq\frac{1}{2}.

The Neumann series yields now

\displaystyle|(A\Pi^{-1})^{-1}|_{2}

\displaystyle=\Big|\left(A^{(0)}\right)^{-1}\Big|_{2}\Big|(I+\left(A^{(0)}\right)^{-1}A^{(\varepsilon)})^{-1}\Big|_{2}

\displaystyle\leq\max_{i=1,\dots,P}\frac{1}{V_{i}}\frac{1}{1-\Big|\left(A^{(0)}\right)^{-1}A^{(\varepsilon)}\Big|_{2}}

\displaystyle\leq\max_{i=1,\dots,P}\frac{2}{V_{i}}.

Finally we define
\eta_{\ell}^{\intercal}:={\Lambda_{\mu}^{\ell}}^{\intercal}\Pi^{-1}(A\Pi^{-1})^{-1}
to get

\displaystyle\eta_{\ell}^{\intercal}A\Lambda_{\mu}^{\ell}={\Lambda_{\mu}^{\ell}}^{\intercal}\Pi^{-1}(A\Pi^{-1})^{-1}A\Pi^{-1}\Pi\Lambda_{\mu}^{\ell}={\Lambda_{\mu}^{\ell}}^{\intercal}\Lambda_{\mu}^{\ell}=|\Lambda_{\mu}^{\ell}|_{2}^{2}

and

\displaystyle|\eta_{\ell}|_{2}\leq|\Lambda_{\mu}^{\ell}|_{2}|(A\Pi^{-1})^{-1}|_{2}\leq|\Lambda_{\mu}^{\ell}|_{2}\max_{i=1,\dots,P}\frac{2P}{V_{i}}.

Plugging everything into equation (
103
) and using the Cauchy–Schwarz inequality twice gives the claimed
L^{2}
-estimate, i.e.

\displaystyle\sum_{\ell=1}^{L}|\Lambda_{\mu}^{\ell}|^{2}_{2}

\displaystyle=\sum_{\ell=1}^{L}\sum_{i=1}^{P-1}\eta_{i,\ell}\Lambda_{\mu}^{\ell}\cdot\int_{M}\textup{div}_{\mu}(\xi_{i})\chi^{\ell}\,d\mu(x)

\displaystyle\leq\left(\sum_{\ell=1}^{L}\sum_{i=1}^{P-1}|\eta_{i,\ell}|^{2}\right)^{\frac{1}{2}}\left(\sum_{\ell=1}^{L}\sum_{i=1}^{P-1}\left(\Lambda_{\mu}^{\ell}\cdot\int_{M}\textup{div}_{\mu}(\xi_{i})\chi^{\ell}\,d\mu(x)\right)^{2}\right)^{\frac{1}{2}}

\displaystyle\leq\left(\max_{i=1,\dots,P}\frac{4P^{2}}{V_{i}^{2}}\sum_{\ell=1}^{L}|\Lambda_{\mu}^{\ell}|^{2}_{2}\right)^{\frac{1}{2}}\left(\frac{P^{2}}{h}\left(1+\frac{1}{\varepsilon}\right)^{2}\left(T(1+E_{0}^{2})+(1+E_{0}^{2})\right)\right)^{\frac{1}{2}}

\displaystyle\leq\frac{1}{h^{2}}\left(\sum_{\ell=1}^{L}|\Lambda_{\mu}^{\ell}|^{2}_{2}\right)^{\frac{1}{2}}\left(\max_{i=1,\dots,P}\frac{4P^{4}}{V_{i}^{2}}\left(1+\frac{12P\textbf{C}(E_{0}+1)}{V_{i}}\right)^{2}\left(T(1+E_{0}^{2})+(1+E_{0}^{2})\right)\right)^{\frac{1}{2}}

∎

5.
Numerics and Empirical Tests

5.1.
Computational Complexity

To compute the volume constrained MBO scheme it is necessary to calculate the diffused clusters
u=e^{-h\Delta_{N}}\chi
. But the calculation of the exponential matrix
e^{-h\Delta_{N}}
is infeasible in practice. To circumvent this cost, one can use simpler kernels. For example Jacobs, Merkurjev and Esedoḡlu used the squared weight matrix as kernel in their auction dynamics algorithm
[
20
]
.
We will discuss several possibilities of kernels that make to different degrees a trade-off between computational complexity and approximation accuracy of
e^{-h\Delta_{N}}
. The key property we do not want to violate is the unconditional stability stemming from the variational interpretation (
66
).

We start be introducing the volume constrained MBO scheme for arbitrary kernels. For some initial clustering
\chi^{0}:X_{N}\rightarrow\{0,1\}
and kernel
A:[0,\infty)\rightarrow\mathbb{R}^{N\times N}\cong(X_{N}\rightarrow X_{N})
that depends on the time step
h
, a clustering
\chi^{\ell-1}
is updated to
\chi^{\ell}
by

(104)

\displaystyle\chi^{\ell}\in\argmax_{\chi:X_{N}\rightarrow\{0,1\}^{P}}

\displaystyle\sum_{i=1}^{P}\sum_{x\in X_{N}}\chi_{i}(x)\big(A(h)\chi^{\ell-1}_{i}\big)(x)

s.t.

\displaystyle\sum_{i=1}^{P}\chi_{i}(x)=1\quad\hskip 3.0pt\text{ for all }x\in X_{N},

\displaystyle\!\!\sum_{x\in X_{N}}\!\!\chi_{i}(x)=V_{i}\quad\text{ for all }i=1,\dots,P.

The natural minimizing movement interpretation associated to the scheme (compare with Lemma
9
) is

(105)

\chi^{\ell}\in\argmin_{\chi:X_{N}\rightarrow\{0,1\}^{P},\sum_{x\in X_{N}}\chi(x)=V}E_{A(h)}(\chi)+\frac{1}{2h}d_{A(h)}^{2}(\chi,\chi^{\ell-1})

where the energy and distance term are given for some scaling function
s_{A}:(0,\infty)\rightarrow(0,\infty)
by

(106)

\displaystyle E_{A(h)}(\chi)

\displaystyle=\frac{1}{s_{A}(h)}\sum_{i\neq j}\frac{1}{N}\sum_{x\in X_{N}}\chi_{i}(x)(A(h)\chi_{j})(x),

(107)

\displaystyle\frac{1}{2h}d_{A(h)}^{2}(\chi,\tilde{\chi})

\displaystyle=\frac{1}{s_{A}(h)}\sum_{i=1}^{P}\frac{1}{N}\sum_{x\in X_{N}}(\chi_{i}-\tilde{\chi}_{i})(x)\big(A(h)(\chi_{i}-\tilde{\chi}_{i})\big)(x).

The computational complexity of the scheme consist of three parts, namely:

i)

Calculate once for all iterations the kernel
A=A(h)
, usually depending on the weights
w:X_{N}\times X_{N}\rightarrow[0,\infty)
. For example, for the in Section
4
discussed heat kernel matrix
e^{-h\Delta_{N}}
, one needs to compute the expensive exponential matrix of the scaled graph Laplacian
-h\Delta_{N}
.

ii)

Compute
A\chi_{i}
for all
i\in\{1,\dots,P\}
. These matrix vector multiplications take for the dense matrix
e^{-h\Delta_{N}}
naively
\mathcal{O}(PN^{2})
.

iii)

Solve the optimization problem (
104
) with Algorithm
1
. By the analysis of Section
4
we expect for the kernel
e^{-h\Delta_{N}}
a running time of
\mathcal{O}(\sqrt{h}N(\log N+P)P^{2})
for most iterations.

It would be optimal, in regard of balancing the complexity of item
ii)
and item
iii)
, to find a matrix
A
such that the matrix vector multiplication of item
ii)
can be computed in
\mathcal{O}(\sqrt{h}N\log N)
. To that aim we can use a simple trick: By the trivial identity

(108)

A\chi^{\ell}=A(\chi^{\ell}-\chi^{\ell-1})+A\chi^{\ell-1}

one can compute the matrix vector product
A\chi^{\ell}
by computing
A(\chi^{\ell}-\chi^{\ell-1})
and adding the stored product
A\chi^{\ell-1}
of the last iteration. The clou is now, when
A=e^{-h\Delta_{N}}
is used then
\chi^{\ell}-\chi^{\ell-1}
is expected to be
\sqrt{h}N
-sparse, meaning that the vector has only
\sqrt{h}N
many non-zero entries. If additional the columns of the matrix
A(h)
are
\log N
-sparse then the computation of
A(\chi^{\ell}-\chi^{\ell-1})
takes the sought after
\mathcal{O}(\sqrt{h}\log N)
running time. We make the
\sqrt{h}N
-sparsity of
A(\chi^{\ell}-\chi^{\ell-1})
rigorous in the following under mild assumptions on the kernel
A(h)
, but will later not completely reach our aim to find a well suited kernel with
\log N
-sparse columns.

Assumption 2
.

1.

Symmetry:
A(h)^{\intercal}=A(h)

2.

Conservation of mass:
A(h)\mathbbold{1}=\mathbbold{1}

3.

Energy scaling: There exists a function
s_{A}:(0,\infty)\rightarrow(0,\infty)
such that for all
\chi:X_{N}\rightarrow\{0,1\}^{P}
it holds

\displaystyle\limsup_{h\rightarrow 0}\limsup_{N\rightarrow\infty}\frac{1}{s_{A}(h)}\sum_{i\neq j}\frac{1}{N}\sum_{x\in X_{N}}\chi_{i}(x)\big(A(h)\chi_{j}\big)(x)<\infty.

Remark 7
.

For
A(h)=e^{-h\Delta_{N}}
all the properties of Assumption
2
are satisfied with
s_{A}(h)=\sqrt{h}
.

Lemma 15

(
L^{1}
estimate of
\chi^{\ell}-\chi^{\ell-1}
)
.

Denote by
\chi^{\ell}
the iterates of the MBO scheme (
104
) with arbitrary diffusion matrix
A(h)
that satisfies the Assumption
2
. Then it holds

\displaystyle|\chi^{\ell}-\chi^{\ell-1}|_{\ell^{1}(X_{N})}\leq 4s_{A}(h)E_{A(h)}(\chi^{0}).

Proof.

We follow the lines of
[
28
, Lemma 2.5]
. Adapting the minimizing movement interpretation of Lemma
9
yields

(109)

\displaystyle E_{A(h)}(\chi^{\ell})+\frac{1}{2h}d_{A(h)}^{2}(\chi^{\ell},\chi^{\ell-1})\leq E_{A(h)}(\chi^{\ell-1}).

We want to bound
|\chi^{\ell}-\chi^{\ell-1}|_{\ell^{1}(X_{N})}
in terms of
d_{A(h)}(\chi^{\ell},\chi^{\ell-1})
. To this aim, we observe that for any
\chi,\tilde{\chi}\in\{0,1\}
and any
u,\tilde{u}\in[0,1]
it holds

\displaystyle|\chi-\tilde{\chi}|

\displaystyle=(\chi-\tilde{\chi})(\chi-\tilde{\chi})

\displaystyle=(\chi-\tilde{\chi})(u-\tilde{u})+(\chi-\tilde{\chi})(\chi-u-(\tilde{\chi}-\tilde{u}))

\displaystyle\leq(\chi-\tilde{\chi})(u-\tilde{u})+|\chi-u|+|\tilde{\chi}-\tilde{u}|.

Hence for
\chi=\chi_{i}^{\ell},\tilde{\chi}=\chi_{i}^{\ell-1},u-\tilde{u}=A(h)(\chi_{i}^{\ell}-\chi_{i}^{\ell-1})
one concludes

\displaystyle|\chi_{i}^{\ell}-\chi_{i}^{\ell-1}|_{\ell^{1}(X_{N})}

\displaystyle=\frac{1}{N}\sum_{x\in X_{N}}|\chi_{i}^{\ell}(x)-\chi_{i}^{\ell-1}|

\displaystyle\leq\frac{1}{N}\sum_{x\in X_{N}}(\chi_{i}^{\ell}(x)-\chi_{i}^{\ell-1}(x))\big(A(h)(\chi_{i}^{\ell}-\chi_{i}^{\ell-1})\big)(x)

\displaystyle\hskip 12.0pt+\frac{1}{N}\sum_{x\in X_{N}}|\chi_{i}\ell(x)-\big(A(h)\chi_{i}^{\ell}\big)(x)|+|\chi_{i}^{\ell-1}(x)-\big(A(h)\chi_{i}^{\ell-1}\big)(x)|.

Summing over
i=1,\dots,P
, we observe that the first term is just
\frac{1}{2h}s_{A}(h)d_{A(h)}^{2}(\chi^{\ell},\chi^{\ell-1})
and for the second one we use
\chi_{i}^{\ell}\in\{0,1\}
and
A(h)\chi_{i}^{\ell}\in[0,1]
as well as
A(h)\mathbbold{1}=\mathbbold{1}
to calculate

\displaystyle\frac{1}{N}\sum_{x\in X_{N}}|\chi_{i}^{\ell-1}(x)-(A(h)\chi_{i}^{\ell-1})(x)|

\displaystyle=\frac{1}{N}\sum_{x\in X_{N}}\chi_{i}^{\ell-1}(x)(1-(A(h)\chi_{i}^{\ell-1})(x))+(1-\chi_{i}^{\ell-1}(x))(A(h)\chi_{i}^{\ell-1})(x)

\displaystyle=\frac{1}{N}\sum_{x\in X_{N}}\chi_{i}^{\ell-1}(x)(A(h)(1-\chi_{i}^{\ell-1}))(x)+(1-\chi_{i}^{\ell-1}(x))(A(h)\chi_{i}^{\ell-1})(x).

Summing over
i=1,\dots,P
, the right-hand side is equal to
2s_{A}(h)E_{A(h)}(\chi^{\ell})
.
Iterating inequality (
109
) yields
E_{A(h)}(\chi^{\ell})+\frac{1}{2h}d^{2}_{A(h)}(\chi^{\ell},\chi^{\ell-1})\leq E_{A(h)}(\chi^{0})
and thus we conclude

\displaystyle|\chi^{\ell}-\chi^{\ell-1}|_{\ell^{1}(X_{N})}

\displaystyle\leq\frac{1}{2h}s_{A}(h)d_{A(h)}^{2}(\chi^{\ell},\chi^{\ell-1})+2s_{A}(h)(E_{A(h)}(\chi^{\ell})+E_{A(h)}(\chi^{\ell-1}))

\displaystyle\leq 4s_{A}(h)E_{A(h)}(\chi^{0}).\qed

Remark 8
.

If
A(h)
is positive definite, one can also directly estimate the
\ell^{1}
-norm against the distance term:

\displaystyle|\chi^{\ell}-\chi^{\ell-1}|_{\ell^{1}(X_{N})}

\displaystyle=\frac{1}{N}\sum_{x\in X_{N}}|\chi^{\ell}(x)-\chi^{\ell-1}(x)|^{2}

\displaystyle\leq\frac{1}{\lambda_{min}N}\sum_{x\in X_{N}}(\chi^{\ell}(x)-\chi^{\ell-1}(x))A(h)(\chi^{\ell}(x)-\chi^{\ell-1}(x))

\displaystyle=\frac{s_{A}(h)}{\lambda_{min}}\frac{1}{2h}d_{A}(h)^{2}(\chi^{\ell},\chi^{\ell-1}).

For
A(h)=e^{-h\Delta_{N}}
one has with the correct scaling (see (
60
)) of the Laplacian that

\displaystyle\lim_{N\rightarrow\infty}\lambda_{min}(A(h))=0

such that for
N
big the estimate degenerates. Our statement in Lemma
15
is more robust.

5.2.
Different Diffusion Kernels

The first kernel we want to have a look at is the best possible approximation of
e^{-h\Delta_{N}}
with rank
K=\log N
. We will see that from a theoretical viewpoint this matrix has a lot of strong properties and leads to a run time of
\mathcal{O}(N\log N)
in the computation of the diffusion step (
ii)
).

Denote the eigenvalues and eigenvectors of the graph Laplacian
\Delta_{N}
by
\lambda_{1}\leq\dots\leq\lambda_{N}
and
v_{1},\dots,v_{N}
, respectively. Then the heat operator applied to some clustering
\chi
is given by

\displaystyle e^{-h\Delta_{N}}\chi_{i}(x)=\sum_{k=1}^{N}e^{-h\lambda_{i}}\langle v_{k},\chi_{i}\rangle_{\ell^{2}(X_{N})}v_{k}(x)\quad\text{ for all }x\in X_{N}.

As a cheaper approximation we take

\displaystyle e^{-h\Delta_{N}}_{K}\chi_{i}(x)=\sum_{k=1}^{K}e^{-h\lambda_{k}}\langle v_{k},\chi_{i}\rangle_{\ell^{2}(X_{N})}v_{k}(x)\quad\text{ for all }x\in X_{N}

with
K\approx\log(N)
. The matrix
e^{-h\Delta_{N}}_{K}
is the best rank-
K
approximation of
e^{-h\Delta_{N}}
which means that it is the matrix minimizing the distance to
e^{-h\Delta_{N}}
in the Frobenius norm under all matrices with rank
K
. We have three motivations for choosing
K\approx\log(N)
:

1.

Lelmi and the second author proved in
[
27
]
the convergence of the two phase MBO scheme to mean curvature flow viscosity solutions if
K\geq\log^{q}(N)
for an explicit exponent
q>0
.

2.

The computation of
e^{-h\Delta_{N}}_{K}\chi
requires
\mathcal{O}(NK)=\mathcal{O}(N\log(N))
time, which matches the asymptotic running time of our Algorithms
1
and
2
. Thus the diffusion step (
ii)
) and thresholding step (
iii)
) are balanced in worst case running time. However, for small time steps
h
we expect the thresholding step to be in
\mathcal{O}(\sqrt{h}N\log N)
while the diffusion still takes
\mathcal{O}(N\log N)
.

3.

The Johnson-Lindenstrauss lemma
[
21
,
25
]
states that one can almost isometrically embed
N
points into
\log(N)
dimensions. More precisely, given
N
points in
\mathbb{R}^{N}
, there exist
N
points of dimension
\mathcal{O}\left(\frac{\log(N)}{\delta^{2}}\right)
such that the distances between the points only changes by a factor of
(1\pm\delta)
. The lemma also tells that the scaling of
\frac{\log(N)}{\delta^{2}}
for the dimension (up to constants) is necessary to ensure this “almost isometry” property
[
25
]
. In our case, the graph Laplacian is an
(N\times N)
-matrix that gets compressed to the
\log(N)
-dimensional subspace spanned by the first
K
eigenvectors.

Note that the eigenvalues and eigenvectors only need to be computed once for a dataset. In our tests, the computational time for that was comparable to the assembly of the weight matrix when working with
k
-nearest-neighbor-graphs.

The only downside of the rank-
K
approximation is, that the sparsity of
\chi^{\ell}-\chi^{\ell-1}
of Theorem
15
doesn’t improve the running time of the matrix vector product as
e^{-h\Delta_{N}}_{K}
is only of low rank but not sparse.

Thus, we also pursue a second approach to get sparser matrices. Using the Taylor series of the matrix exponential one writes

(110)

e^{-h\Delta_{N}}=\sum_{j=0}^{\infty}\frac{(-h\Delta_{N})^{j}}{j!}.

For simplicity consider the random walk graph Laplacian
\Delta_{N}=I-D^{-1}W
with
D
the diagonal matrix with entries
d(x):=\sum_{y\in X_{N}}w(x,y)
and
W
the weight matrix with entries
w(x,y)
. The graph Laplacian
\Delta_{N}
is sparse when using
k
-nearest neighbor graphs. To be more precise it only has
Nk
non-zero entries with
k
non-zero entries in every row. By our manifold assumption, Assumption
1
, one also expects that every column has
\mathcal{O}(k)
non zero elements in every column. The number of neighbors
k
should be chosen at least by
k=\mathcal{O}(\log N)
as otherwise the resulting graph would be disconnected with high probability. Also in the case of random geometric graphs as in our Assumption
1
, the typical number of neighbors of a point is
\log N
. Thus, the approximation

(111)

\displaystyle e^{-h\Delta_{N}}_{Tay,J}:=\sum_{j=0}^{J}\frac{(-h\Delta_{N})^{j}}{j!}.

leads to a expected running time of
\mathcal{O}(\sqrt{h}N\log^{J}(N))
in the matrix vector multiplication (
ii)
). But, problematic with this choice of kernel for small
J
is no matter which choice of
h\in(0,\infty)
is taken, one either has problems with pinning or the kernel is not positive semi-definite. For example, regard the case
J=1
, that is
A(h)=(1-h)I+hD^{-1}W
. On the one hand, for
h\leq 0.5
the scheme is pinned, meaning that
\chi^{\ell}=\chi^{\ell-1}
, so the scheme frozen at the initial condition. On the other hand, for
h>0.5
the matrix is not positive semi-definite such that the distance term (
107
) is not guaranteed to be non-negative anymore. Thus the energy (
106
), which is in this case the for clustering very suited Graph Total Variation, doesn’t need to be dissipated. For bigger
J
the pinning problem gets only slightly better.

Therefore we propose another approach where we use that
e^{-h\Delta_{N}}=e^{-h}e^{hD^{-1}W}
which leads to the approximation

(112)

\displaystyle e^{-h\Delta_{N}}_{Pos,J}:=\frac{1}{\sum_{j=0}^{J}\frac{h^{j}}{j!}}\sum_{j=0}^{J}\frac{h^{j}\big(D^{-1}W\big)^{j}}{j!}.

Note the prefactor is chosen such that
e^{-h\Delta_{N}}_{Pos,J}\chi(x)\in[0,1]
for
\chi:X_{N}\rightarrow\{0,1\}
. For even
J
one can check that
e^{-h\Delta_{N}}_{Pos,J}
is positive semi-definite and therefore we have unconditional stability.

We will also have a look at just the matrix
(D^{-1}W)^{\intercal}D^{-1}W
which can be seen as the limit
h\rightarrow\infty
of
e^{-h\Delta_{N}}_{Pos,2}
and was used in
[
20
]
. The matrix-vector multiplication takes
\mathcal{O}(\varepsilon_{N}N\log^{2}(N))
and can be sped up by (
108
) as
\chi^{\ell}-\chi^{\ell-1}
is sparse, which follows from Lemma
15
and
s_{N}(h)=\varepsilon_{N}
, and
[
16
]
. In the spirit of Remark
8
on expects more sparsity in later iterations. Additionally also
((D^{-1}W)^{\intercal}D^{-1}W)^{2}=\lim_{h\rightarrow\infty}e^{-h\Delta_{N}}_{Pos,4}
is tested as this matrix connects nodes further apart in the graph and thus spreads more information. The running time for the matrix vector multiplication is similar to before given by
\mathcal{O}(\varepsilon_{N}N\log^{4}(N))
.

One can also expand the Taylor series around an other point than zero. Therefore one wants to use
e^{-h\Delta_{N}}=e^{-(h-r)I}e^{hD^{-1}W-rI}
. To get a positive semi-definite matrix, we use
e^{-(h-r)I}e^{h(D^{-1}W)^{\intercal}D^{-1}W-rI}
where
r=\lambda_{1}
, the smallest eigenvalue of
(D^{-1}W)^{\intercal}D^{-1}W
. This
r
is the biggest choice such that
(D^{-1}W)^{\intercal}D^{-1}W-rI
is positive semi-definite. Note that
\lambda_{1}
can be
0
but in practice even a
r>\lambda_{1}
worked well in our tests. The evolution of
e^{-(h-r)I}e^{h(D^{-1}W)^{\intercal}D^{-1}W-rI}
yields

(113)

\displaystyle\sum_{j=0}^{J}\frac{h^{j}\big((D^{-1}W)^{\intercal}D^{-1}W-rI\big)^{j}}{j!}.

The motivation behind this kernel is that by the subtraction of the identity one wants to prevent pinning. Mathematically speaking, a kernel with small but positive eigenvalues is ideal as it makes the distance- like term
\frac{1}{2h}d_{A(h)}^{2}(\cdot,\cdot)
in the minimizing movement interpretation (
109
) small, which means that larger energy barriers can be overcome and solutions with lower energy can be found. We again take the limiting kernel

(114)

\displaystyle(D^{-1}W)^{\intercal}D^{-1}W-rI

for our tests such that the matrix-vector multiplication is expected to be in
\mathcal{O}(\varepsilon_{N}N\log^{2}N)
.

5.3.
Test Setup

As initialization of our clusters we use a slight variation of Voronoi tessellation
[
19
]
which have been used in the auction dynamics
[
20
]
. Laguerre tesselations or sometimes called weighted tessellations have the advantage that they can be used to find an initial clustering that satisfies the volume constraints already. When the initial clustering doesn’t fulfill the volume constraints and a quite local kernel like
(D^{-1}W)^{\intercal}D^{-1}W
is used, it can happen that not enough nodes get information from a phase with not enough volume such that one is forced to add arbitrary points to it. This can lead to solutions with higher energy which is not favorable. To define Laguerre tesselations in the semi-supervised learning set up assume we have a fidelity set
Y\subset X_{N}
whose labels are known. Thus, it is given that
\chi(y)=e_{i}
for all
y\in Y_{i}
with
Y_{i}
the set of all points with label
i
and
\dot{\cup}_{i=1,\dots,P}Y_{i}=Y
. For our points
X_{N}
with labeled data
Y
the
i
-th Laguerre cell is

(115)

\displaystyle L_{i}(Y,m):=\Big\{x\in X_{N}:\textup{dist}(x,y_{i})-m_{i}\leq\textup{dist}(x,y_{j})-m_{j}\ \forall j\neq i,y_{i}\in Y_{i},y_{j}\in Y_{j}\Big\}.

The distance to the points can be computed efficiently using Dijkstra’s algorithm and the weights
m
such that the volume constraints are satisfied can be computed with our Algorithm
1
.
We use this initialization for all the kernels except for the best rank-
K
approximation (
111
). For the kernel (
111
) we use the approximate heat kernel to get an initial clustering by setting

\displaystyle\delta_{Y}(x):=\begin{cases}e_{i}&\text{ if }x\in Y_{i},\\
0&\text{ if }x\notin Y,\end{cases}

which is comparable to the union of discrete Dirac deltas of the points in
Y
. We then propose to take

(116)

\displaystyle\{\chi^{0}_{i}=1\}:=\left\{\left(e^{-h\Delta_{N}}_{K}\delta_{Y}\right)_{i}-m_{i}\geq\left(e^{-h\Delta_{N}}_{K}\delta_{Y}\right)_{j}-m_{j}\ \forall j\neq i\right\}.

as initial clustering in the spirit of Varadhan
[
50
]
, see also Crane et al.
[
11
]
. In the continuous, Euclidean setting with constant density this is equivalent to Laguerre tessellations as
e^{-h\Delta_{N}}_{K}\delta_{x}
is radially symmetric around
x
. But on the discrete data the heat kernel weights and considers all possible paths between two points and not only the shortest one like the distance function does. In Table
1
the accuracy of this initial clustering is compared to accuracy of the initial clustering by Voronoi regions as described in
[
19
]
. A comparison between Laguerre and Voronoi cells can be found in Table
1
.

As stopping criterion we use the relative change in the thresholding energy
E_{N,h}
of (
62
). Denoting by
\chi^{\ell}
the clustering in the
\ell
-th iteration of the volume constrained MBO scheme, our algorithm is stopped if
\left(E_{N,h}(\chi^{\ell+1})-E_{N,h}(\chi^{\ell})\right)/E_{N,h}(\chi^{\ell+1})<\varepsilon
for
\varepsilon\approx 10^{-4}
. Note that by the minimizing movement interpretation of Lemma
9
it is guaranteed that
\chi^{\ell}
converges to a local minimum. We test two diffusion times
h=1
and
h=100
.

We use three different datasets to test our kernels that have also been used in
[
20
]
for their tests.

MNIST
is a dataset of grayscale images of size
28\times 28
of handwritten digits. We combine the
60,000
training images with the
10,000
test images to one dataset of
70,000
images. Otherwise no changes are done to the dataset.

Opt-Digits
is also a dataset of of handwritten digits but with size
8\times 8
pixels and every pixel has values between
0
and
16
.

Three Moons
is a synthetic dataset that is constructed by sampling out of three half-circles and adding normal distributed noise. The centers of the circles are at
(0,0),(3,0)
and
(1.5,0.4)
with radii of
1,1
and
1.5
respectively. The first two half-circles are open to the bottom and the third is opened at the top. The two dimensional points are then embedded into
\mathbb{R}^{100}
and Gaussian noise with mean zero and standard deviation
0.14
is added. From each half-circle we sampled
500
points such that the dataset consists of
1500
points in total.

As weight matrix we take for easy comparison the weight matrix proposed in
[
7
]
. This means we take the
K
-nearest neighbor graph with weights given by

\displaystyle w(x,y)=e^{-\frac{4|x-y|^{2}}{d_{K}^{2}(x)}}.

Here, the euclidean norm was used and
d_{K}(x)=|x-x_{K}|
is a local scaling parameter where
x_{K}
denotes the
K
-th nearest neighbour of
x
. For all datasets we used
K=10
as in
[
7
]
. For best comparison to
[
7
]
on MNIST we used their pretrained variational autoencoder (for more information see
[
7
]
) to embed the points into a lower dimensional feature space before computing the weights. On Opt-Digits and Three Moons such an embedding was not done. In the end the matrix
W^{\prime}=(W^{\intercal}+W)/2
is used to ensure symmetry.

On all three datasets we once test with one known label per class and once with five known labels per class. We also state the results when temperature is introduced as it was done in
[
20
]
. Temperature is a random perturbation of the diffused values before the thresholding step is applied; it helps to escape local minimas which leads to solutions with lower energy. If temperature is used we use the clustering with lowest energy over a fixed number of
50
iterations. The volume constraints are chosen exact and it is assumed that the correct number of datapoints in every cluster is known. The results are given in Table
2
for MNIST, Table
3
for Opt-Digits and Table
4
for Three Moons.

5.4.
Results and Comparison to Other Methods

Overall, our results summerized in Tables
2
,
3
and
4
over the three datasets show that there is not a specific kernel that outperforms all other kernels. But some observations follow in order. First, subtracting a scaled identity matrix as done in (
114
) seems to be beneficial to prevent pinning which yields better accuracy although the matrix is not guaranteed to be positive definite. The best rank-
K
approximation (
111
) has its advantages on the Three Moons dataset when only one point per class is labeled. In comparison to the other kernels the rank-
K
approximation is a global kernel meaning that every node gets information from every other node in the diffusion step. This is helpful to prevent local minimas described by cutting moons with a straight line into two pieces. The kernel has, for
h=100
, also good accuracy when comparing to the other methods on MNIST dataset. The connection to spectral clustering for
h
large, analyzed in the Introduction
1.4
, explains the increase in accuracy when compared to
h=1
. Surprisingly, the kernel (
112
) of the positive Taylor expansion yields always worse results then simply using
(D^{-1}W)^{\intercal}D^{-1}W
. This is unexpected as the added
D^{-1}W
term included in (
112
) should help to minimize the Graph Cut energy which is ideal for clustering. One explanation for this observation could be that
D^{-1}W
is not positive definite and thus less energy is dissipated in every iteration compared to using the kernel
(D^{-1}W)^{\intercal}D^{-1}W
. On MNIST and Opt-Digits the
((D^{-1}W)^{\intercal}D^{-1}W)^{2}
kernel yields the best results but is also the most expensive to compute (see previous section). Compared to the other graph based methods (see Table
2
) it also has the highest accuracy of
97.5\%
when five points of every cluster are labeled. When only one point is labeled only the PoissonMBO
[
7
]
and the rank
K
approximation yield better results.

5.5.
Connection to Assignment Problem

Although not designed for it, from a theoretical perspective our algorithm is also efficient for the much studied assignment problem. The problem of solving (
1
) can be reduced to solving the assignment problem as done in
[
20
]
. The other way around, we can also use (
1
) to solve the assignment problem that reads as follows. Assume you have
N
workers
\{a_{i}\}_{i}
and
N
tasks
\{b_{i}\}_{i}
given and you want to assign to each task exactly one worker. Also assume that it costs
c(a,b)\geq 0
to assign worker
a
to task
b
. The assignment problem asks to find an assignment
f:\{a_{i}\}_{i}\rightarrow\{b_{i}\}_{i}
that minimizes the cost, i.e.

\displaystyle\argmin_{f:\{a_{i}\}_{i}\rightarrow\{b_{i}\}_{i}\text{ bijective}}\sum_{i=1}^{N}c(a_{i},f(a_{i})).

We can solve this problem by solving

\displaystyle\argmax_{\chi:\{a_{i}\}_{i}\rightarrow\{0,1\}^{N}}-\sum_{i=1}^{N}\sum_{j=1}^{N}\chi_{j}(a_{i})c(a_{i},b_{j})\quad\text{s.t. }

\displaystyle\sum_{i=1}^{N}\chi_{i}(a_{j})=1\ \forall j=1,\dots,N,

\displaystyle\sum_{j=1}^{N}\chi_{i}(a_{j})=1\ \forall i=1,\dots,N,

and setting
f(a_{i}):=b_{j(i)}
where
j(i)
is the index with
\chi_{j(i)}(a_{i})=1
. Using Algorithm
1
with
P=N
to solve this problem one gets a running time of
\mathcal{O}(N\log NP^{2}+NP^{3})=\mathcal{O}(N^{4})
. One can even improve this by recognizing that only
P
hyperplanes change in line
7
of Algorithm
1
. Thus finding the closest point to the hyperplane in the moved direction can be done by taking the minimum of the previous hyperplanes and the
P
changed hyperplanes. Using a priority queue to maintain the minimum yields a total running time of
\mathcal{O}(N\log NP^{2}+NP^{2}\log P)=\mathcal{O}(N^{3}\log N)
. The best known algorithm for the assignment problem is the “Hungarian method” with running time
\mathcal{O}(N^{3})

[
23
,
24
,
39
]
. So our algorithm is asymptotically only the factor
\mathcal{O}(\log(N))
slower, which is surprising as the algorithm is designed for the case
P\ll N
.
