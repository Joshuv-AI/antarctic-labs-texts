MPC-guided, Data-driven Fuzzy Controller Synthesis
Juan Augusto Paredes Salazar, Ankit Goel

Abstract
Model predictive control (MPC) is a powerful control technique for online optimization using system model-based predictions over a finite time horizon. However, the computational cost MPC requires can be prohibitive in resource-constrained computer systems. This paper presents a fuzzy controller synthesis framework guided by MPC. In the proposed framework, training data is obtained from MPC closed-loop simulations and is used to optimize a low computational complexity controller to emulate the response of MPC. In particular, autoregressive moving average (ARMA) controllers are trained using data obtained from MPC closed-loop simulations, such that each ARMA controller emulates the response of the MPC controller under particular desired conditions. Using a Takagi-Sugeno (T-S) fuzzy system, the responses of all the trained ARMA controllers are then weighted depending on the measured system conditions, resulting in the Fuzzy-Autoregressive Moving Average (F-ARMA) controller. The effectiveness of the trained F-ARMA controllers is illustrated via numerical examples.

Model predictive control (MPC) is a feedback control framework that can simultaneously minimize a user-defined, system output-dependent cost function over a future finite time horizon and satisfy user-defined constraints

In this work, an MPC-guided control synthesis procedure is used to synthesize a fuzzy controller that emulates the response of the original MPC controller.
The proposed synthesis procedure involves training autoregressive moving average (ARMA) controllers using data obtained from MPC closed-loop simulations, such that each ARMA controller emulates the response of the MPC controller under particular conditions.

IV-A

ARMA controllers

The F-ARMA controller consists of

Each ARMA controller is trained to emulate the response of the MPC controller under particular conditions.
The

u_{{\rm r},i,k}=\begin{cases}0,&k<\ell_{{\rm w},i},\\
\sum_{j=1}^{\ell_{{\rm w},i}}D_{i,j}u_{i,k-j}+\sum_{j=1}^{\ell_{{\rm w},i}}N_{i,j}z_{i,k-j},&k\geq\ell_{{\rm w},i},\end{cases}

where
\ell_{{\rm w},i}>0
is the window length of the ARMA controller,

N_{i,j}\in{\mathbb{R}}^{\ell_{u}\times\ell_{y}}
are controller coefficient matrices,
u_{i,k}\stackrel{{\scriptstyle\triangle}}{{=}}\sigma(u_{{\rm r},i,k})\in{\mathbb{R}}^{\ell_{u}}
is the constrained control input, and
z_{i,k}\in{\mathbb{R}}^{\ell_{y}}
is the performance variable of the
i
th ARMA controller.

To simplify notation, (
26

u_{{\rm r},i,k}=\begin{cases}0,&k<\ell_{{\rm w},i},\\
\phi_{i,k}\theta_{i},&k\geq\ell_{{\rm w},i},\end{cases}

(27)

where the regressor matrix
\phi_{i,k}\in{\mathbb{R}}^{\ell_{u}\times\ell_{\theta,i}}
is given by

\phi_{i,k}\stackrel{{\scriptstyle\triangle}}{{=}}I_{\ell_{u}}\otimes\begin{bmatrix}u_{i,k-1}^{\rm T}&\cdots&u_{i,k-\ell_{{\rm w},i}}^{\rm T}&z_{i,k-1}^{\rm T}&\cdots&z_{i,k-\ell_{{\rm w},i}}^{\rm T}\end{bmatrix},

the controller coefficient vector
\theta_{i}\in{\mathbb{R}}^{\ell_{\theta,i}}
is given by

\theta_{i}\stackrel{{\scriptstyle\triangle}}{{=}}{\rm vec}\begin{bmatrix}D_{i,1}&\cdots&D_{i,\ell_{{\rm w},i}}&N_{i,1}\cdots N_{i,\ell_{{\rm w},i}}\end{bmatrix}^{\rm T},

and
\ell_{\theta,i}\stackrel{{\scriptstyle\triangle}}{{=}}\ell_{{\rm w},i}\ell_{u}(\ell_{y}+\ell_{u}).

The performance variable of the
i
the ARMA controller

z_{i,k}\stackrel{{\scriptstyle\triangle}}{{=}}{\mathcal{Z}}_{i}(r_{k},y_{k})\in{\mathbb{R}}^{\ell_{y}},

where
{\mathcal{Z}}_{i}\colon{\mathbb{R}}^{\ell_{y}}\times{\mathbb{R}}^{\ell_{y}}\to{\mathbb{R}}^{\ell_{y}}
calculates the performance variable to meet the same tracking objective as
V
within the neighborhood in which the
i
-th ARMA controller is more favored by the F-ARMA controller to better emulate the response of the original MPC controller;
in most cases,
{\mathcal{Z}}_{i}(r_{k},y_{k})=r_{k}-y_{k}
for all
k\geq 0.

Note that, unlike the MPC techniques shown in Section
III
, the F-ARMA controllers use
y_{k}
and
r_{k}
as inputs, rather than
x_{k}
and
x_{{\rm r},k},
and thus would not require an observer for implementation.

IV-B

Fuzzy-ARMA Controller

Consider and T-S fuzzy system with
\ell_{\rm c}
rules associated with each of the ARMA controllers, let
\gamma_{k}\in{\mathbb{R}}^{\ell_{\gamma}}
the vector of decision variables chosen to determine the favored controller at each step
k\geq 0,
and, for all
j\in\{1,\ldots,\ell_{\gamma}\}
let
\gamma_{k,j}\in{\mathbb{R}}
be the
j
th component of
\gamma_{k},
such that
\gamma_{k}=\begin{bmatrix}\gamma_{k,1}&\cdots&\gamma_{k,\ell_{\gamma}}\end{bmatrix}^{\rm T}.

Then, rule
{\mathcal{R}}_{i}
can be written as

\displaystyle{\mathcal{R}}_{i}\colon\quad

\displaystyle\mbox{If }\gamma_{k,1}\mbox{ is }{\mathcal{F}}_{i,1}\mbox{ and }\gamma_{k,2}\mbox{ is }{\mathcal{F}}_{i,2}\mbox{ and }\cdots

\displaystyle\mbox{and }\gamma_{k,\ell_{\gamma}}\mbox{ is }{\mathcal{F}}_{i,\ell_{\gamma}},\mbox{ then }u_{{\rm r},i,k}=\phi_{i,k}\theta_{i},

(28)

where, for all
j\in\{1,\ldots,\ell_{\gamma}\},

{\mathcal{F}}_{i,j}
is a fuzzy set characterized by the membership function
\mu_{i,j}\colon{\mathbb{R}}\to{\mathbb{R}},
which quantifies how much
\gamma_{k,j}
belongs to
{\mathcal{F}}_{i,j}.

Next, considering a product T-norm as an implication method, let
w_{i,k}>0
be the weight associated with rule
{\mathcal{R}}_{i}
at step
k
and be given by

w_{i,k}\stackrel{{\scriptstyle\triangle}}{{=}}\prod_{j=1}^{\ell_{\gamma}}\mu_{i,j}(\gamma_{k,j}).

(29)

Then, the requested control input generated by F-ARMA is given by the weighted average of the constrained control inputs generated by each ARMA controller, that is,

u_{{\rm r},k}=\frac{\sum_{i=1}^{\ell_{\rm c}}w_{i,k}u_{i,k}}{\sum_{i=1}^{\ell_{\rm c}}w_{i,k}}=\frac{\sum_{i=1}^{\ell_{\rm c}}w_{i,k}\sigma(\phi_{i,k}\theta_{i})}{\sum_{i=1}^{\ell_{\rm c}}w_{i,k}}.

(30)

A method to obtain
\theta_{i}
from data samples acquired from MPC closed-loop simulations is introduced in Section
V
.
In this work, the vector
\gamma_{k},
the fuzzy rules
{\mathcal{R}}_{i},
and the membership functions
\mu_{i,j}
are defined arbitrarily by the user to better interpolate the linear behaviors of each ARMA controller.

V
Least-Squares Regression for ARMA Controller Synthesis

Let
i\in\{1,\ldots,\ell_{\rm c}\},
and
\ell_{{\rm tr},i}>0
be the number of data samples used for the training the
i
th ARMA controller.
For all
k\in[0,\ell_{{\rm tr},i}-1],
let
u_{{\rm tr},i,k}\in{\mathbb{R}}^{\ell_{u}}
and
y_{{\rm tr},i,k}\in{\mathbb{R}}^{\ell_{y}}
be the input and output data obtained from the implementation of MPC for closed-loop trajectory tracking, and let
r_{{\rm tr},i,k}\in{\mathbb{R}}^{\ell_{y}}
be the chosen reference to train the
i
th ARMA controller;
furthermore, let
z_{{\rm tr},i,k}\in{\mathbb{R}}^{\ell_{y}}
be the training performance variables given by
z_{{\rm tr},i,k}={\mathcal{Z}}_{i}(r_{{\rm tr},i,k},y_{{\rm tr},i,k}).

Then,
\theta_{i}
can be obtained by solving the least squares problem

\theta_{i}=\argmin_{\theta\in{\mathbb{R}}^{\ell_{\theta,i}}}\|\Phi_{{\rm tr},i}\theta-U_{{\rm tr},i}\|+\theta^{\rm T}R_{\theta,i}\theta,

(31)

where
R_{\theta,i}\in{\mathbb{R}}^{\ell_{\theta,i}\times\ell_{\theta,i}}
is a positive semidefinite, symmetric regularization matrix,

\Phi_{{\rm tr},i}\stackrel{{\scriptstyle\triangle}}{{=}}\begin{bmatrix}\phi_{{\rm tr},i,\ell_{{\rm w},i}}^{\rm T}&\cdots&\phi_{{\rm tr},i,\ell_{{\rm tr},i}-1}^{\rm T}\end{bmatrix}^{\rm T}\in{\mathbb{R}}^{\ell_{u}(\ell_{{\rm tr},i}-\ell_{{\rm w},i}-1)\times\ell_{\theta,i}},

\phi_{{\rm tr},i,k}\stackrel{{\scriptstyle\triangle}}{{=}}I_{\ell_{u}}\otimes\begin{bmatrix}u_{{\rm tr},i,k-1}^{\rm T}&\cdots&u_{{\rm tr},i,k-\ell_{{\rm w},i}}^{\rm T}&z_{{\rm tr},i,k-1}^{\rm T}&\cdots&z_{{\rm tr},i,k-\ell_{{\rm w},i}}^{\rm T}\end{bmatrix}

\hskip-161.50232pt\in{\mathbb{R}}^{\ell_{u}\times\ell_{\theta,i}},

U_{{\rm tr},i}\stackrel{{\scriptstyle\triangle}}{{=}}\begin{bmatrix}u_{{\rm tr},i,\ell_{{\rm w},i}}^{\rm T}&\cdots&u_{{\rm tr},i,\ell_{{\rm tr},i}-1}^{\rm T}\end{bmatrix}^{\rm T}\in{\mathbb{R}}^{\ell_{u}(\ell_{{\rm tr},i}-\ell_{{\rm w},i}-1)}.

While linear controllers cannot enforce input constraints, (
31
) can be formulated as a QP to obtain a controller that more easily meets the constraints shown in (
2
),(
3
).
Hence, (
31
) with input constraints can be reformulated as the following QP

\theta_{i}=\argmin_{\theta\in{\mathbb{R}}^{\ell_{\theta,i}}}\frac{1}{2}\theta^{\rm T}H_{{\rm tr},i}\theta+q_{{\rm tr},i}^{\rm T}\theta,

(32)

subject to

\Gamma_{{\rm tr},i}\theta\leq\nu_{{\rm tr},i},

(33)

where

\displaystyle H_{{\rm tr},i}

\displaystyle\stackrel{{\scriptstyle\triangle}}{{=}}2\Phi_{{\rm tr},i}^{\rm T}\Phi_{{\rm tr},i}+2R_{\theta,i}\in{\mathbb{R}}^{\ell_{\theta,i}\times\ell_{\theta,i}},

\displaystyle q_{{\rm tr},i}

\displaystyle\stackrel{{\scriptstyle\triangle}}{{=}}-2\Phi_{{\rm tr},i}^{\rm T}U_{{\rm tr},i}\in{\mathbb{R}}^{\ell_{\theta,i}},

\displaystyle\Gamma_{{\rm tr},i}

\displaystyle\stackrel{{\scriptstyle\triangle}}{{=}}\begin{bmatrix}\Phi_{{\rm tr},i}\\
-\Phi_{{\rm tr},i}\end{bmatrix}\in{\mathbb{R}}^{2\ell_{u}(\ell_{{\rm tr},i}-\ell_{{\rm w},i}-1)\times\ell_{\theta,i}},

\displaystyle\nu_{{\rm tr},i}

\displaystyle\stackrel{{\scriptstyle\triangle}}{{=}}\begin{bmatrix}\mathds{1}_{(\ell_{{\rm tr},i}-\ell_{{\rm w},i}-1)\times 1}\otimes u_{\max}\\
-\mathds{1}_{(\ell_{{\rm tr},i}-\ell_{{\rm w},i}-1)\times 1}\otimes u_{\min}\end{bmatrix}\in{\mathbb{R}}^{2\ell_{u}(\ell_{{\rm tr},i}-\ell_{{\rm w},i}-1)}.

The QP given by (
32
), (
33
) can be solved in Matlab using
quadprog
to obtain
\theta_{i}
corresponding to the
i
th ARMA controller of F-ARMA.

VII
Conclusions

This paper presented an MPC-guided fuzzy controller synthesis framework called the F-ARMA controller. In this framework, ARMA controllers are trained using data obtained from MPC closed-loop simulations, and each ARMA controller emulates the response of the MPC controller under some desirable conditions.
The responses of all the trained ARMA controllers is then weighted depending on the measured system conditions and interpolated using a T-S fuzzy system.
Numerical examples illustrate the MPC-guided controller synthesis framework and show that the trained F-ARMA controller is able to emulate the constrained response of the original MPC controller.

Future work will focus on implementing and validating the F-ARMA framework in physical experiments and automating the choice of the fuzzy system rules and membership function parameters by leveraging fuzzy system optimization techniques
[
37
,
38
]
.
