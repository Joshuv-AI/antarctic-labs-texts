Studying the Effects of Self-Attention on SAR Automatic Target Recognition
Jacob Fein-Ashley, Rajgopal Kannan, Viktor Prasanna, Jacob Fein-Ashley 1 , Rajgopal Kannan 2 , Viktor Prasanna 1

Abstract
Attention mechanisms are critically important in the advancement of synthetic aperture radar (SAR) automatic target recognition (ATR) systems. Traditional SAR ATR models often struggle with the noisy nature of the SAR data, frequently learning from background noise rather than the most relevant image features. Attention mechanisms address this limitation by focusing on crucial image components, such as the shadows and small parts of a vehicle, which are crucial for accurate target classification. By dynamically prioritizing these significant features, attention-based models can efficiently characterize the entire image with a few pixels, thus enhancing recognition performance. This capability allows for the discrimination of targets from background clutter, leading to more practical and robust SAR ATR models. We show that attention modules increase top-1 accuracy, improve input robustness, and are qualitatively more explainable on the MSTAR dataset.

The self-attention mechanism is a prediction technique that allows the model to focus on different parts of the input sequence. Visual attention mechanisms usually emphasize the essential parts of the data while reducing the importance of less critical parts. This process draws inspiration from the human cognitive system

Formulation of Self-Attention

Consider a CNN with
L

l

X^{(l)}\in\mathbb{R}^{C\times H\times W}
, where
C

H
and
W
are the height and width of the feature map, respectively. The self-attention mechanism is applied to the input
X^{(l)}
to produce the output
Y^{(l)}\in\mathbb{R}^{C\times H\times W}
. The self-attention mechanism is defined as:

Y^{(l)}=X^{(l)}+\text{SA}(X^{(l)}),

where
\text{SA}(\cdot)
is the self-attention mechanism. Thus, the output of the
l
-th layer is the sum of the input and the self-attention mechanism applied to the input. Furthermore, our studies use the self-attention mechanism proposed in
[
3
,
2
,
1
]
, recent state-of-the-art advances in self-attention. We explain these mechanisms in the following sections.

II-B

CBAM Model

The Convolutional Block Attention Module (CBAM)
[
2
]
is a lightweight yet effective attention module for feedforward convolutional neural networks. To refine feature maps, it sequentially infers attention maps along two separate dimensions, channel and spatial.

II-B
1
Channel Attention Module

The Channel Attention Module (CAM) generates an attention map along the channel dimension. It aggregates spatial information using average and max-pooling operations and then produces the attention map using a shared network.

\displaystyle\mathbf{F}_{avg}^{c}

\displaystyle\in\mathbb{R}^{C\times 1\times 1}=\text{AvgPool}(\mathbf{F})\in\mathbb{R}^{C\times H\times W}

\displaystyle\mathbf{F}_{max}^{c}

\displaystyle\in\mathbb{R}^{C\times 1\times 1}=\text{MaxPool}(\mathbf{F})\in\mathbb{R}^{C\times H\times W}

The shared network comprises a multilayer perceptron (MLP) with one hidden layer. The two aggregated features are passed through the MLP to produce the channel attention map.

\displaystyle\mathbf{M}_{c}(\mathbf{F})

\displaystyle\in\mathbb{R}^{C\times 1\times 1}=\sigma(\text{MLP}(\mathbf{F}_{avg}^{c})+\text{MLP}(\mathbf{F}_{max}^{c}))

\displaystyle\mathbf{F}_{c}^{\prime}

\displaystyle\in\mathbb{R}^{C\times H\times W}=\mathbf{M}_{c}(\mathbf{F})\otimes\mathbf{F}\in\mathbb{R}^{C\times H\times W}

Here,
\sigma
denotes the sigmoid function, and
\otimes
denotes element-wise multiplication.

II-B
2
Spatial Attention Module

The Spatial Attention Module (SAM) generates an attention map along the spatial dimension. It uses average-pooling and max-pooling operations along the channel axis to aggregate channel information and then concatenates the two aggregated features.

\displaystyle\mathbf{F}_{avg}^{s}

\displaystyle\in\mathbb{R}^{1\times H\times W}=\text{AvgPool}(\mathbf{F}_{c}^{\prime})

\displaystyle\mathbf{F}_{max}^{s}

\displaystyle\in\mathbb{R}^{1\times H\times W}=\text{MaxPool}(\mathbf{F}_{c}^{\prime})

The concatenated feature is then passed through a convolution layer to produce the spatial attention map.

\displaystyle\mathbf{M}_{s}(\mathbf{F}_{c}^{\prime})

\displaystyle\in\mathbb{R}^{1\times H\times W}=\sigma(\text{Conv}([\mathbf{F}_{avg}^{s};\mathbf{F}_{max}^{s}]))

\displaystyle\mathbf{F}_{s}^{\prime}

\displaystyle\in\mathbb{R}^{C\times H\times W}=\mathbf{M}_{s}(\mathbf{F}_{c}^{\prime})\otimes\mathbf{F}_{c}^{\prime}\in\mathbb{R}^{C\times H\times W}

Here,
[;]
denotes the concatenation along the channel axis.

II-B
3
Overall Process

The overall CBAM process can be summarized as follows:

1.

Apply the Channel Attention Module to the input feature map
\mathbf{F}
.

2.

Apply the Spatial Attention Module to the refined feature map from the Channel Attention Module.

After applying both attention modules, the refined feature map is the final output
\mathbf{F}_{s}^{\prime}\in\mathbb{R}^{C\times H\times W}
.

II-D

Squeeze-and-Excitation Network

The Squeeze-and-Excitation (SENet)
[
3
]
network introduces a lightweight gating mechanism that can be used to model channel-wise relationships adaptively.

SE Block Architecture.

The SE block can be divided into two main operations: Squeeze and excitation.

II-D
1
Squeeze Operation

The squeeze operation aggregates feature maps in spatial dimensions, producing a channel descriptor. For an input feature map
\mathbf{U}\in\mathbb{R}^{H\times W\times C}
, where
H
,
W
, and
C
are the height, width, and number of channels, respectively, the squeeze operation is defined as:

\mathbf{z}_{c}=\frac{1}{H\times W}\sum_{i=1}^{H}\sum_{j=1}^{W}\mathbf{U}_{i,j,c}

where
\mathbf{z}\in\mathbb{R}^{C}
is the channel descriptor.

II-D
2
Excitation Operation

The excitation operation captures channel-wise dependencies using fully connected (FC) layers. The channel descriptor
\mathbf{z}
is passed through two FC layers with nonlinearity (ReLU) between. The excitation operation is defined as:

\mathbf{s}=\sigma(\mathbf{W}_{2}\delta(\mathbf{W}_{1}\mathbf{z}))

where
\mathbf{W}_{1}\in\mathbb{R}^{\frac{C}{r}\times C}
and
\mathbf{W}_{2}\in\mathbb{R}^{C\times\frac{C}{r}}
are the weights of the FC layers,
\delta
denotes the ReLU function,
\sigma
denotes the sigmoid function, and
r
is the reduction ratio.

II-D
3
Recalibration

The final step is to recalibrate the input feature map
\mathbf{U}
using the excitation vector
\mathbf{s}
. This is achieved by channel-wise multiplication:

\mathbf{\hat{U}}_{c}=\mathbf{s}_{c}\mathbf{U}_{c}

where
\mathbf{\hat{U}}\in\mathbb{R}^{H\times W\times C}
is the recalibrated feature map.

II-E

ECA-Net

ECA-Net
[
1
]
employs a simple but efficient method to capture channel-wise dependencies. The key components of the ECA block are described below:

II-E
1
Channel Attention Mechanism

Given an input feature map
\mathbf{U}\in\mathbb{R}^{H\times W\times C}
, the channel attention mechanism in ECA-Net works as follows:

1.

Global Average Pooling:
First, a global average pooling operation is applied to the input feature map to produce a channel-wise descriptor:

\mathbf{z}_{c}=\frac{1}{H\times W}\sum_{i=1}^{H}\sum_{j=1}^{W}\mathbf{U}_{i,j,c}

where
\mathbf{z}\in\mathbb{R}^{C}
is the channel descriptor.

2.

Efficient Channel Attention:
Instead of using two fully connected (FC) layers, ECA-Net uses a 1D convolution with kernel size
k
to capture cross-channel interaction. The kernel size
k
is adaptively determined by a function of channel dimension
C
:

k=\psi(C)=\left\lceil\frac{C}{\gamma}\right\rceil\text{, where $\gamma$ is a constant.}

The efficient channel attention is computed as:

\mathbf{s}=\sigma(\text{Conv1D}(\mathbf{z},k))

where
Conv1D
denotes the 1D convolution operation and
\sigma
is the activation function of the sigmoid.

3.

Recalibration:
The recalibrated feature map is obtained by channel-wise multiplication:

\mathbf{\hat{U}}_{c}=\mathbf{s}_{c}\mathbf{U}_{c}

where
\mathbf{\hat{U}}\in\mathbb{R}^{H\times W\times C}
is the recalibrated feature map.

General Discussion

Although the attention modules only add small accuracy benefits for the backbone model we tested, the quantitative portion of this experiment highlights the benefits of including self-attention for SAR ATR. We notice that including self-attention allows each model to learn from the entire vehicle and slightly from the backscatter rather than from random parts of the image, which ResNet seemingly does. Learning in this manner allows for more explainable interactions between practitioners using SAR ATR and deep learning models. We hope that future SAR ATR models consider their design’s explainability.

IV
Conclusion and Future Work

This study evaluated the different mechanisms of self-attention in the computer vision community applied to SAR ATR. Applying self-attention modules for CNN-based architectures allows the model to be guided by vehicle parts rather than random parts of the image, which provides explainable interactions between practitioners and deep learning models. We verified that ResNet-18, as a baseline with added self-attention mechanisms, provides more accurate, robust, and explainable algorithms. Additionally, applying attention modules to SAR ATR algorithms can allow for a more robust model to input perturbations in the presence of noise.
